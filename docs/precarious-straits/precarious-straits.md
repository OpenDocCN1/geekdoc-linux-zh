## PRECents：岌岌可危的海峡

作者：玛丽娜·维什米特，2005年2月8日

图片：安杰洛·林多内，《母性》，Chainworkers 运动海报，推广圣·普雷卡里奥（San Precario）崇拜

将文化工作者等同于典型的弹性化工人或"不稳定者"（precarian），究竟遮蔽了什么？玛丽娜·维什米特质询了近期的时髦做法——将艺术家与其他形式的不稳定（服务性）工人等同起来，却忽视了后者所缺乏的那种光环

近年来，策展、批评和媒体领域有无数尝试，将其领域的特征与劳动景观中更广泛的结构性变革相挂钩。这些尝试主要围绕"创造力"和"灵活性"这两个曾经被视为艺术家所特有的、作为价值法则之构成性例外的轴线展开，而如今它们已被新自由主义政策声明及其生物经济实施方案赞誉为普遍 desirable 的属性。当前许多通过文化作为劳动这一棱镜来构建分析的趋*势*，已开始在社会生产各领域的一般性条件下讨论"不稳定性"（precariousness）这一范畴。"不稳定性"一词力图唤起制度性拥抱非正式性所带来的所有负面效应。这种拥抱掩盖了凯恩斯主义社会契约或其他国家层面对资本风险的调解机制的无情废除、有组织的劳动的式微，以及保罗·维尔诺在其著作中讨论的去管制工作场所的"个性化支配"。[1] "不稳定性"标志着新劳动景观中不稳定性和暴露性的共同脉络，笼罩着从非法服务业工人到学者和网页设计师等截然不同的人生前景。社会生活被真正纳入"认知"资本主义之中，而这种纳入具有一个悖论性的面孔：生活越是劳动，劳动就越无法保证生命的再生产。因此，"不稳定性"标示着资本主体化的真实与意识形态层面的贫困，同时也希望成为广泛抵制其效应的场域。

作为一种诊断，"不稳定性"似乎，嗯，显*得* remarkably 灵活、流动且适应性强。"不稳定性"已在近期诸多干预行动中浮现：从旗舰机构的工作坊到自主组织的空间，从展览、放映到从社会中心涌现的 investigative、文本和视听实践。[2] 它已攀升至欧洲公共艺术研究倡议*Republicart*的议程，该机构于2004年8月在其网络期刊上专门刊出一期关于"不稳定无产者"（Precariat）的特刊。[3] 此外，还有一些高调的全国性运动抵制对承认文化工作脆弱经济基础之法令的掏空（Intermittents du Spectacle）。[4] 其中一些项目，特别是2004年6月在伦敦弗莱克曼小屋（Flaxman Lodge）举办的工会化工作坊，已将论辩从"社会工厂"中主体再生产的抽象对等，或将截然不同的各类传播工作轻率等同为"非物质劳动"的范畴中推进了一步。这些讨论还主题化了"创造性劳动"中主体性生产、工作的拒斥，以及员*工*作为自主阶级的重组（既内在于又始终与资本主义社会关系保持张力）之间的关联，其灵感源于对"意大利实验室"中安东尼奥·奈格里和保罗·维尔诺著作的阅读。媒体行动主义领域也有所发展，意大利的 Chainworkers[5] 着手动员被传统工会抛弃的多元化临时工队伍，提供法律咨询和物质设施、协调行动，甚至册封了一位新圣徒来为"不稳定无产者"代祷。

将文化生产视为典范的叙述在某种程度上是成立的，因为文化经济催生了绝大多数劳动体制所效仿的原型，这些劳动体制依赖无偿且被神秘化的劳动来确保利润与声望的失衡分配，以及部署"创造力"来轻描淡写地软化对这些体制的服从。在此视角下，艺术家或信息工作者是典型的不稳定者，她被无形的要求所贯穿，要将自身生存的基本程式乃至批判的基本语汇都商品化。然而，在使用"不稳定性"的过程中——尤其是那些试图批判性地挪用艺术家形象、将其作为资本理想的顺从且万能创造性主体——或许也有教益的是：对那种始终保障资本自由运转（无论是凯恩斯主义还是网络化形态）之日常不可见性的遗漏：即家务、个人照料、季节性和隐蔽劳动这些灵活、非正式、自发增值的场所——这些可弃置的劳动始终处于积累过程的核心，即便不在其叙事之中。在文化转向"不稳定性"的进程中，家务劳动、照料劳动等的明显消失，不仅错失了"关系型"或"情感型"资本主义的整片实质性领域，而且有被嵌入其正在质询的术语之中的风险——即"创造力"的教条。曾几何时，家务劳动因其被排除在抽象劳动力交换之外而被马克思理论斥为 mere "再生产"；如今，它之所以被排除在对新兴劳动形式的批判之外，不仅因为它不被视为"创造性的"，不仅因为它无酬，更因为"创造力"为社会关系和生产关系的僵化提供了借口，而这种僵化无法承认，更无法设想消灭家务职作为独立活动所带来的挑战。

诚然，已有社会学界对（低薪）家务劳动的复兴有所探索，[6] Precarias a la Deriva 也将其大量研究投入到照料劳动作为重组和信息化资本之引擎的持续不可见性上，重点关注女性在"不稳定"部门（如家务劳动、呼叫中心）中的压倒性多数。尽管如此，"不稳定性"一词作为对"非物质劳动"的言说转向（因其既过于精确又过于局限）的 discursive 出现，往往附带了对文化工作者作为不稳定性之突出表征的强调。然而，我们只需稍加审视便能看出，"不稳定性"更多涉及的是一种广泛渗透于劳动世界的东西，即从前局限于无价值劳动、无社会性劳动、无尽头劳动——家务劳动——之走廊中的非正式且日常的 degradation，如今 seepage 至整个劳动世界。

> 因此，我们首要提出的是打破这种家庭主妇角色的需要——这个茧中之蛹，被自身劳动所囚禁，直至死亡并为资本留下丝茧。——玛丽亚罗莎·达拉·科斯塔

在她1971年的文本《女性与共同体的颠覆》中，玛丽亚罗莎·达拉·科斯塔提出，女性劳动在家务中的边缘化预设了资本主义整体中劳动的分工与组织。家庭主妇是典型的私有化产业，提供着本可以且应当社会化的服务。如果资本依赖家庭来补偿有偿劳动所带来的心理、社会和经济层面的对抗，如果家庭是劳动力及其纪律的再生产场所，那么对资本主义家庭结构的拒斥就是对工作的全盘拒斥。因此，女性处于一个独特的位置，能够将她们争取自决权的斗争——这种斗争不可还原为在家外获得"充实的"工作——传播到整个社会。虽然将这一未经修正的分析移植到至少已被三十余年女权主义的毛细管作用所 marginally 影响的当下，或许有些牵强，但那种与剩余价值生产不可分离的不可见且自然化的剥削的 articulation，仍然成立，无论是在被这种生产所分层还是同质化*的*社会场域中。家庭主妇，是的，但也包括儿童、移民、囚犯、福利领取者、老年人、痴呆者、公交车的驾驶者和乘客。在此关键的是要注意到，价值生产并不自动转化为冲突场所，否则达拉·科斯塔将被奉为文化研究的先驱之一。恰恰是家务劳动和儿童照料，作为被忽视的价值生产场所，也是被忽视的冲突场所，因为它对积累至关重要。在坚定的生物政治术语中，家庭作为生命的控制中心，由此成为生产潜力的控制中心。

达拉·科斯塔的分析也可被用来揭露文化生命形式与不稳定性之对等的另一重不对称：在特定社会场域中，纪律在主体性生产中的功能。家庭的纪律功能已广为人知；文化的纪律功能或许更为玄奥，因为它将文化 bracketing 为解放性的形象。但这恰恰是需要在将艺术家建构为不稳定工人的 formulation 中加以审查的。文化/艺术在西方社会中是一种巨大的 discipline 语汇，这一*点*在我们周围以既难以察觉又无处不在的方式得到实例化。社区艺术和文化再生在应对去工业化的乡村和城市回应中的突出地位，在此是相关的。社区艺术或社会介入艺术倾向于展示家庭曾*扮演* host 的那种对抗性的 same defusion，一个无需补偿、没有现实后果（当然除了艺术专业人士之外）的安全创造性空间。艺术世界中关于不稳定性的论述，在某些时刻能够提醒我们、在其他时刻却 masked 的，是艺术作为商品关系的地位，及其相对自主性是建立在极端依赖的基础上的。就此而言，不稳定性话语和"成为不稳定者"进程中对艺术关系的任何激进化，都需要承认其作为典范性案例的不可*用*性；充其量，它反映或共享了劳动生活的某些特征：孤立、焦虑、机会主义。艺术家作为模型不稳定者的公式，掩盖了不稳定性生产中最关*键*的利害所在：社会生产的分层和工作的强加。一个更具启发性的公式或许是：艺术家或艺术工作者作为资本的 vanishing mediator，恰恰在他们对其法则的想象性否定中 vanishing。或许，比投射文化工作的不安全性与 shitwork 的不安全性之间的相似性更有趣、也更具挑战性的，是对这两者之间 incongruities 的复杂意识。工作的重构对社会领域造成创伤性后果，这是一回事；但这些后果并非随意的。许多受行动主义启发的或"介入性"艺术的问题在于，它想把艺术创作的条件普遍化到社会之中，却未意识到自己同样不可避免地陷于想要颠覆的社会逻辑之中。

或许解决之道在于聚焦艺术结构的独特性——稳定的和变动的——以及这种特殊性所引发的批判类型。何种独特性能够损害功能性？艺术作为活动的实验性特征，始终在其作为社会领域的经济过度决定中起着 mitigating 作用。对劳动和政治的当代配置的不可再现性，对摒弃既有主体性情、转而青睐尚未存在或尚未成形的思想与生成技术的热忱，或许能唤起这种独特性。一种有目的的对无用性参与，在*原则上*是艺术的特征，这也标志着在福特主义后工作之创新所 theorised 的度量丧失的基础上，建构其他生命形式的潜力。度量丧失对文化生产可能意味着：文化已不能再被依赖来为其他形式的劳动提供借口。但由于形形色色的劳动生产不同种类的价值，所有劳动无法被统摄于文化之中。

像如今其他一切一样，艺术不生产任何东西。这种无用性可以被构成性地 mobilised；在无用性与无关性之间，仍有巨大的裂*隙*要 leveraging。反对艺术的工具化及其在创造力话语中的批判的工具化，我们能在多大程度上把握一种可以抵抗此点的特殊性——既已存在与尚未存在*于*同时的特殊性？这或许才是真正属于艺术的不稳定性；它在作为社会生产之所为与作为"社会介入"之部署之间的 oscillation。没有这种认识，艺术世界对不稳定性的挪用，风险在于成为另一种 bad-faith 对波希米亚失落梦想的追悼，以服务业 muted palette 渲染。
