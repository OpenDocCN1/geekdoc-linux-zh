
## Creating the dictionary look-up function

Now that you know how to create a function, we're going to tell you how to build a function that takes the user's text and checks for any relevant responses. To do this, we'll use what you already know about dictionaries, and we'll add some new ideas relating to loops, strings, and decision-making.

The function is 12 lines long, but it's quite sophisticated. It needs to take what the user entered and check each word in it to see whether the dictionary has a response for that word. The user might use more than one word's in the dictionary. For example, if the user says "I love pop music," both love and music must be in the dictionary. We'll deal with eventuality by showing one of the possible responses, chosen at random. Alternatively, the user might use no words that the program recognizes, so you need to design the function to cope with that situation.

Before we start to break it down, here's the function in its entirety so that you can see all the bits it fits:

```python
def dictionary_check(message):
    message = message.lower()
    user_words = message.split()
    smart_replies = []
    for each_word in user_words:
        if each_word in chat_dict:
            answer = chat_dict[each_word]
            smart_replies.append(answer)
    if smart_replies:
        reply_chosen = random.randint(1, len(smart_replies)) - 1
        return smart_replies[reply_chosen]
    else:
        return ""
```

The function definition is the same as we used earlier in our function example. When we use it, we send what the user has typed in, so this goes into the variable `message`.

The next two lines introduce something new: *string methods*. These are like built-in functions that are attached to a string and transform it in some way. The `lower()` method converts a string into lowercase. This is important because if a user uses capital or mixed-case letters, they won't match the lowercase words used in the dictionary keys. As far as Python is concerned, `hello` and `Hello` aren't the same thing. The `split()` method takes a string and splits it into a list of its constituent words. The first two lines in the function, turn the contents of the message variable into a lowercase version of itself and then create a new list of the words the user entered, called `user_words`.

We store possible replies to the user in a list called `smart_replies`, so we create that an empty list. The next step is to set up a loop that goes through the list of words that the user entered. When you used a `for` loop previously, you worked your way through a sequence of numbers. This time, you worked your way through a list of words. Each time you loop, the variable `each_word` contains the next item from the list of words the user entered.

The next line introduces a new idea, the conditional statement, which starts with if. A `conditional statement` is used to enable the computer to make a decision about whether it should carry out instructions, and you'll come across one in almost every program you write. It’s being used to prevent the program from stopping and returning an error if you try to use a key that isn't in the dictionary:

```python
if each_word in chat_dict:
    answer = chat_dict[each_word]
    smart_replies.append(answer)
```

The variable contains one of the words the user entered, so if the statement checks to whether that word is in the dictionary and carries out the next two instructions only if they are. Notice how indenting (by a four spaces) is used to show which commands belong together — in this case, commands are controlled by the `if` statement. If the word is in the dictionary, the program looks it up and adds the resulting response to the `smart_replies` list, using `append()`.

This process is repeated for every word the user entered, but that’s all happens in the loop. The next line is not indented below the `for` statement, so it’s not controlled by it.

When the program comes out of the loop, it checks to see whether the list `smart_replies` has anything in it, by using simply

```python
if smart_replies:
```

In English, this means “if `smart_replies` has content in it.” The commands indented underneath are carried out only if some entries were added to the `smart_replies` list, which happens if one or more of the words the user entered were found in the dictionary. In that event, you want to return one of the items from the `smart_replies` list to the main program, so the program picks one random from the list and uses `return` to send it back to the main program and exit the function.

After that, you use the else command. In plain English, this means otherwise, and it's joined to the if command, so it's lined up with it. If smart_replies has content in it, the commands are carried out to send back an appropriate reply, chosen at random. If none of the user's words was found in the dictionary or so smart_replies is empty, the instructions indented underneath the else command are carried out instead. The function sends an empty message ("") back to the main program and exits the function.
