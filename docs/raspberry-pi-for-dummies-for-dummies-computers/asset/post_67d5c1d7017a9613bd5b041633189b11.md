# **Listing 16-1:** LED Blink

```
#!/usr/bin/python3
import time
import R.GPIO as io # using R.GPIO

io.setmode(io.BCM)
io.setup(4,io.OUT) # make pin into an output

print("LED blinker - By Mike Cook")
print("Ctrl C to quit")
while True:
io.output(4,0)
time.sleep(0.3)
io.output(4,1)
time.sleep(0.3)
```
