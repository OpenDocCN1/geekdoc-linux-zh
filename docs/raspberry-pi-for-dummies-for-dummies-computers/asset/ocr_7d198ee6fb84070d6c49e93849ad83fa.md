# LISTING 16-2: An LED Blink Rate Controlled by a Push Button

```
#!/usr/bin/python3
io.setmode(io.BCM)
io.output(4,io.OUT) # make pin into an output
io.setup(24,io.IN, pull_up_down=PUD_UP) # make pin into input

print("LED blinker By Mike Cook")
print("Ctrl C to quit")
while True:
    io.output(4,0)
    if io.input(24) == 1:
        time.sleep(0.30)
    else:
        time.sleep(1.00)
    io.output(4,1)
    if io.input(24) == 1:
        time.sleep(0.30)
    else:
        time.sleep(1.00)
```
