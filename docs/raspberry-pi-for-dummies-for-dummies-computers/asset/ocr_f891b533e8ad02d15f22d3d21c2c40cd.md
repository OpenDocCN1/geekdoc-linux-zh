# # The Pedestrian Crossing software

Now let's apply the multi task/state machine principle to our crossing project. We need one task to look at the traffic sensor — if we see traffic activity, we want to note the time it took place. Then we need one task to look at the cross request button — if that button is pressed the crossing sequence is not under way, we need to start that sequence. Finally, if the crossing sequence has reached the "cross phase", we need a task to turn on the sounder and off, to make the beeping noise. (Note that we have reduced the times in the crossing sequence to be easy to look at and see what is going on. In real life, some of the times would be much longer.) Listing 16-11.
