## Making the clouds regenerate

The way your code works now, the clouds disappear off the top of the window, and that's the last you see of them. Add the following function to your latest program to make the clouds reappear at the bottom when they go off the top:

```python
def update():
    for i in range(6):
        this_cloud = clouds[i]
        if this_cloud.y < 0 - this_cloud.height:
            this_cloud.y = HEIGHT + this_cloud.height

```

The update() function in this game uses a loop to look at each cloud in turn, and uses this_cloud as shorthand for each cloud it works with. If the cloud is fully off the screen (y is less than 0 minus its height), the function resets it to the bottom of the. ## Enabling multiple clouds be clicked

We've already described how you can make one cloud respond to a click, and how you can create and update multiple clouds. We'll combine those ideas in a new function that enables you to click multiple clouds. Add this to the end of your program so far:

```python
def on_mouse_down(pos):
    global score
    for i in range(6):
        this_cloud = clouds[i]
        if this_cloud.collidepoint(pos) and timer > 0 and this_cloud.image != 'pop':
            this_cloud.image = 'pop'
            sounds.pop.play()
            score += 1
```

This function runs when the mouse button is clicked. When that happens, the function goes through a loop, checking to see which cloud has been hit. You only want to pop the cloud if these conditions are true:

- It's been hit by the mouse, expressed as this_cloud.collidepoint(pos).
- There's still time on the clock for the player to catch, expressed as timer > 0.
- The cloud hasn't already been popped, which you can check by making sure its image != 'pop'.

If all these conditions are true, the program changes the cloud to the 'pop' image, plays the sound, and increases the score by 1. After the image changes to 'pop', the cloud continues to float off the screen.

Variables used within a function belong only to that function, by default, and are called local variables. Isolation stops functions from changing the data that other functions use by accident. variables can be used by any function. The score, for example, needs to be used in this function (where the program changes it) and the draw() function (where the program plays it), so it's a global. If you want to change a global variable inside a function, you have to start the function by telling Python you intend to use that global variable, so that's what the first line in this function does.

## Adding the timer

Pygame Zero includes the ability to schedule a function to run regularly, which you can use to run a timer. You've already set the timer variable to 10 at the start of the program. You just need to create a function to decrease it by 1 each time it runs, and then schedule it to run every second. Here's what the code looks like: You need to add it to the end of your program:

```python
def countdown():
    global timer
    timer -= 1
    if timer == 0:
        clock.unschedule(countdown)
        sounds.whoops.play()
```

```python
clock.schedule_interval(countdown, 1)
```

The line at end isn't part of any function. You can tell it because the clock isn't indented. As a result, this instruction runs when the game begins. clock.schedule_interval() sets another function to run at regular intervals. In our case, we're running the countdown() every 1 second. Note that we don't use brackets after countdown here. We have to put this clock.schedule_interval(countdown, 1) line after the function because it can only be used to schedule a function that has been defined earlier in the program.

The countdown() function itself reduces the global timer variable by each time it runs. If the timer is now 0, it uses clock.unschedule to stop countdown() from running regularly and plays the Game Over music.
