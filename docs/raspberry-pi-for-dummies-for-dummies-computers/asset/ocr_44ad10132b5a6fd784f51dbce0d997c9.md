As you can see, the numbers in the table count from top to bottom, and from left to right. Notes get higher as you go down the table and as you move from left to right across the columns. The next highest note after B (at the bottom of the table) is the C at the top of the next column to the right. It's like a piano, where the same layout (running from C to G, then A to B, and then starting from C again) repeats all the way around.

![](bbox=[0.178, 0.216, 0.229, 0.283])

If you don't know much about music, stick to the notes that don't have huge leaps. Try moving a few notes or down a column and dip into a neighboring column when you're near the top or bottom of your column. By following these simple guidelines, you should end up with a jolly little thing.

# # Using Note and Chord Names

Sonic Pi enables you to use proper note names instead of MIDI numbers by the name of the note (a letter from A to G), plus the number of the octave it's in. You can see those numbers labeling the columns in Table 14-1.

For example, to play a middle C, you can use

```
play :c4
```

To play the B note before it, which is in the next lowest octave, you would use

```
play :b3
```

The Log shows that Sonic Pi plays notes 60 and 59 respectively. You can check the note names and numbers in Table 14-1 to confirm that this is what you expected.

Here's how you code a fanfare using note names instead of numbers:

```
play :c4
sleep 0.5
play :e4
sleep 0.5
play :g4
sleep 0.5
play :c5
```

If you want to use a sharp note, insert the s in the note name (for example) play :cs4 and use b for a flat note (play :cb4).
