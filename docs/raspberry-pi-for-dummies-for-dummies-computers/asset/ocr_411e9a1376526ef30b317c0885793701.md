In this chapter, we show you how to make a game called Cloudbusting, you have to "pop" the clouds as they drift up the screen. You have ten seconds to click as many as you can. The game works on the Model B+, but is a noticeably smoother experience on the Raspberry Pi 2 or 3.

# Collecting Your Sounds and Images

To follow the examples in this chapter, you need the sounds and images described in the following list. You can either create your own or download our examples. (See the Introduction for more on downloading our supporting files.) This simple game works well whatever images you use.

Here are the assets needed for Cloudbusting:

+   **Six images, named target0.png to target5.png:** In our game, we use colored images, but you could use anything. Our images measure about 100 pixels by 90 pixels, and you should aim for a similar size, or take 10 or 20 pixels in this direction. (We've noticed that it adds a sense of depth to the game if one of the images is a slightly different size from the rest, so you may want to try that out.) Use a transparent background so the images can overlap their workings behind them. The PNG format is recommended, by Pygame Zero can also use GIF and JPEG images (although JPEGs don't support transparency). The simplest way to make your own is to use the built-in Paint Editor in Scratch (refer to Chapter 10) and right-click a costume in the Costs Area to save it from the menu (This is known as exporting in Scratch 1.4 and saving to a local file in Scratch 2.0)

+   **One image named pop.png:** This image is shown when the game hits. Ours is a cartoon-style pointy bubble with "Pop!" written in it. We made this image in Scratch.

+   **Two sounds — one for the popping of a target and the other to play when the game ends:** We're using a sound effect we found online blop.ogg for when cloud bursts, and a tune Sean made on the iPad called whoops.ogg for when the game ends.

The .ogg format is a sound format often used in open source software. You can also a .wav file in Pygame Zero. If you're using sound effects different from ours, the filenames in the programs to your choices.
