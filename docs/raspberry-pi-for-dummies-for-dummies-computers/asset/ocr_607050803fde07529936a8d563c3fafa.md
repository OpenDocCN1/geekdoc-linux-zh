# Using variables

The next step in the program is to ask the user which use multiplication table to generate. You store this number in a variable. A variable is a way of storing a number or piece of text so that you can refer to it later. (We talk more about variables in Chapter 10, where it plays a role in Scratch discussion.)

For example, you might have a variable that stores your bank balance. It might go up (ka-ching!) or it might go down (sadly, more often), but you can always refer to it as your bank balance. Variables are one of the basic building blocks of programming, and not just in Python.
