
Firstly (and especially if you have a Model A, B, or Zero), you're going to want to connect other devices to your Pi at the same time as your keyboard and mouse, which need two sockets. And secondly, a USB hub provides power to your devices and minimizes the likelihood of experiencing problems using your Raspberry Pi, especially if connecting relatively-intensive devices such as hard drives. Make sure your USB hub has its own power source, independent of the Raspberry Pi.

## USB keyboard and mouse
The Raspberry Pi only supports USB keyboards and mouse, if you're still using ones with PS/2 connectors (round rather than flat), you need to replace them.

## MicroSD card or SD card
The Raspberry Pi doesn't have a hard drive built into it, so it uses a MicroSD card (current models) or SD card (older models, excluding Model B+) as its. You probably have some SD cards that you use for your digital camera, although you might need to get a higher-capacity one. We recommend an 8GB card as minimum, but you can use a 4GB card if you use a media center operating system (OS) like LibreELEC (See Chapter 8 for a guide). Even that you might space the hard drive, you can use other storage devices such as external hard drives. MicroSD cards have different class numbers that indicate how fast you can copy information from them. The Raspberry Pi Foundation recommends its Class 6 as a good value and high-performance solution, you will be fine with Class 6 or higher. The easiest way to get started with the Raspberry Pi is to buy a card with OS already on it. (See Chapter 2 for more.) Online retailers, including those for buying the Pi itself, sell a MicroSD card that has OS preloaded on it. It comes with an SD adapter, shown in Figure 1-3, so it fits older models (with adapter) and newer models (without it).

## SD or MicroSD writer
Many PCs have a slot for SDSD cards, so you can easily copy photos from your camera to your computer. If it doesn't, you might want to consider getting an SD or MicroSD writer to connect to your computer. You can use it to copy files for use with your Raspberry Pi. Alternatively, as we've said, you can buy a MicroSD card with OS already on it. You can also use the writer to create a backup of your Raspberry Pi's files and software.

- **USB key:** USB key (also known as flash drive or memory stick) can be fairly cheap and high-capacity now (4GB key is readily affordable), which makes it an ideal complement to your Raspberry Pi. You can transfer files between your PC and Raspberry Pi using a USB key.

- **USB Wi-Fi adapter:** Model A and A+ don't have an Ethernet socket, so if you want to connect to the Internet, you will need a Wi-Fi adapter. You might already have one of these from a laptop, incompatible with the Raspberry Pi, but companies that sell the Pi usually sell a compatible Wi-Fi adapter, too. There is an official Raspberry Pi Wi-Fi adapter, available from the usual retailers.

- **External hard drive:** If you want lots of storage, so you can use your music or video collection with the Raspberry Pi, you can connect an external hard drive to it over USB. You'll need a powered USB hub that has its own power source.

- **Raspberry Pi Camera Module:** The Raspberry Pi has stimulated to create all add-ons for it, the Camera Module is a product that originated at the Raspberry Foundation. This 8-megapixel, fixed-focus camera can be used to shoot HD video and take still photos. There is also a version without an infrared filter (the PiNo Camera), which can be used for wildlife photography at night or day.

- **Speakers:** The Raspberry Pi has a standard audio socket, compatible with headphones and PC speakers that use a 3.5mm audio jack. You can plug headphones directly into it, or use the audio jack to connect to speakers, a stereo, or a TV. If you're using a TV or stereo for sound, you can get a cable that connects the 3.5mm audio jack and the audio input(s) on your television or stereo. You won't always need speakers: if you're using an HDMI connector, the audio is sent to the screen with the video signal, but note that this doesn't work if you use DWI monitor.

- **Power supply:** The Raspberry Pi uses a USB connector for its power supply, and is theoretically compatible with a lot of mobile phone and tablet chargers. In practice, many of these can deliver enough current (up to 700 milliamperes for a Model A+ and up to 2500 milliamperes for a Raspberry Pi 3 Model B), which can make the Raspberry Pi perform reliably. It's worth checking whether you have a 5V charger that might do the job (it should show how much current it provides), but for best results, we recommend buying a compatible charger from the same company you buy your Raspberry Pi from. There is official Raspberry Pi power available, which works in the U.K., Europe, the U.S./Japan, and Australia/China. For mobile applications, it's possible to power the Raspberry Pi using a battery pack designed for mobile charging. Don't try to power the Pi by connecting its USB port to the PC with a cable, because your computer probably can't provide enough power for Pi. You can also power the Pi through the GPIO pins, but there is a spike in current or wrong voltage if you want to provide power through the GPIO pins, a safer approach is to use a HAT device (Hardware Attached on Top) designed to sit on the GPIO pins and provide the consistent power you need while protecting the Pi underneath. The Raspberry Pi Foundation advises that you should only use batteries to power the Raspberry Pi if you know what you're doing, because there is a risk of damaging your Raspberry Pi. For more details on the power requirements of various Raspberry Pi models, consult the FAQ at www.raspberry.pi/help/faq/

- **Case:** It is safe to operate your Raspberry Pi as, but many people want to protect it from spills and precariously stacked desk by getting a case for it. You can buy plastic cases on eBay (www.ebay.com), many of which are transparent, you can still admire the circuitry and see the Pi's LED lights. These cases typically come simple with clips to secure them. The Pi Couch (https://moroni.com/collections/pibow) is one of the most elegantly designed cases, assembled from layers of colored plastic. There are also official cases for the Raspberry Pi 3, Pi 2, and Model B+. The case for the Pi Zero includes three different tops, so you can either it, leave a camera hole, or have access to the GPIO pins. You don't have to buy a case, though you can go without or make your own using cardboard or Lego bricks. Whatever case you go with, make sure you can still access the GPIO pins so that you can experiment with connecting your Pi to electronic circuits and try the projects in Part 5 of this book.
