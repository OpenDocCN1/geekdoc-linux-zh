The first sector's first bytes contain the UID that, along with the other bytes in that sector, cannot be changed. Attempts to write it will fail. The sectors containing all zeros are the sectors you can write data to. Each group of sectors is preceded by a sector that contains two keys that allow read and write access to the following sectors. You don't directly into these, but writing to the sectors can change these values. They're initially set up, as shown here, with the default key values. When you plan a project, be aware that you can only write data to those sectors that are not key sectors.

# Key sectors not to write to

We have not printed it because it's long, and you won't get much from reading it. It also automatically blocks you from trying to write to key sectors.

Talking to the reader over the SPI interface is somewhat complex, and not really necessary to understand in order to use an RFID reader in a system. It involves mainly putting numbers into chip registers or memory locations in the correct sequence, as laid out in the chip's data sheet. However, we have added five methods at the end of the class for you to be able to easily tap and communicate with the reader. The methods you need to know about in this list:

+   **RC5222WaitForCardRemoved**: Ensures the code pauses until a card has been removed from the reader – reading of a card can be quick. This is complicated by the fact that with a card held permanently on a reader, every other call to detect it. A `function function()` returns falsely, saying that there is no card on the reader. This is a function of how the chip works, and to work around it, this method waits until two successive attempts at reading a card both return no card present. (Note that this is known as blocking code in that, once it's called, nothing else can happen until the card is removed).

+   **RC522_ReadCard**: Reads and returns the UID number of the card at the reader. If there's no card or there's a reading error, this method returns a value of -1.

+   **RC522_GetCard**: Waits until there is no card on the reader and waits again until a card is presented, and then it returns the card's UID number. This blocking code in that nothing else can happen until a valid card is read.
