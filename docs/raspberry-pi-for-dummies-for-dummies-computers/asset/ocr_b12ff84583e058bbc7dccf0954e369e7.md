# Determining a component needs to be treated

How do we know the series resistance of a component? Well, it is normally in that component's data sheet, the document that the manufacturers of all components produce to exactly define the component and its properties. However, it's not always given as a straightforward value. Take a bulb, for instance. This is normally "rated" as a voltage and a current; that is, we would say that the bulb is 6V at 0.33 amps. If we need to know the equivalent resistance, we use Ohm's law. Other bulbs, especially big ones, are power rating in watts. Current-multiplied by voltage is the power in watts.

The other point is that a bulb doesn't have a constant resistance. We say it's a nonlinear device; that is, the resistance changes depending on what current is going through it. This is because a bulb is a coil of wire. As current passes through it, the wire heats up. This causes the resistance to increase, limiting the point where the resistance is such that the current is limited to the design value at the design voltage. We use this concept of a nonlinear resistance in this chapter when we calculate what resistor we need to use with an LED.

When dealing with units like volts and ohms that include a decimal, the point is missed and the latter of the unit is substituted, 3-3 volts becomes 3V3, or 4.7K becomes 4K7. This is done to make it clear that there is a decimal point that otherwise might be lost in small print. While this is not officially approved standard, it is widely used in electronics industry.

The series resistance of a battery — or any power supply, for that matter — is an important concept in it limits the current the battery can deliver. This is all wrapped up in the chemistry of the battery, but its effects can be summed up by a theoretical series resistance. A battery that can deliver a lot of current has a low series resistance. This is sometimes known as the output impedance of the battery.

# TESTING CIRCUITS WITH SIMULATORS

Nowadays, there are circuit simulators that allow you to test a circuit before you build it. This is a great idea to make sure you are not doing anything silly. However, some radiators have a steep learning curve, and others use ideal components instead of real ones. One can get some misleading results with simple circuits, but on the whole they are a very good idea. One simulator written especially for the Raspberry Pi is free. Find out more at www.raspberrypi.org/archives/1917.
