## Creating a Game with Python and Pygame Zero

Developing games is one of the best ways to explore programming. It gives you rapid, visual, results, so you can easily see what's going on and you get to have some fun playing your creation at the end. Game development also makes it easy to think of fresh coding challenges to solve, as you dream up new features to add.

One of the most popular tools for making games in Python is called Pygame: It's a set of functions that makes it easier to manage your images and sounds, among other things. Pygame has a few complexities, and can be difficult to get started with.

That inspired Daniel Pope to make Pygame Zero, a library of routines that simplifies Pygame so you can get started more easily. It also includes a number of built-in functions that manage animations, loops, and images. Pygame Zero was designed for education, but is great fun for anyone to tinker with.

Pygame Zero is also available for Mac and Windows, the games you make on the Raspberry Pi can be enjoyed by your friends even if they have different computers.

## Collecting Your Sounds and Images

To follow the examples in this chapter, you need the sounds and images described in the following list. You can either create your own or download our examples. (See the Introduction for more on downloading our supporting files.) This simple game works well whatever images you use.

Here are the assets needed for Cloudbusting:

- **Six images, named target0.png to target5.png:** In our game, we use colored images, but you could use anything. Our images measure about 100 pixels by 90 pixels, and you should aim for a similar size, or take 10 or 20 pixels in this direction. (We've noticed that it adds a sense of depth to the game if one of the images is a slightly different size from the rest, so you may want to try that out.) Use a transparent background so the images can overlap their workings behind them. The PNG format is recommended, by Pygame Zero can also use GIF and JPEG images (although JPEGs don't support transparency). The simplest way to make your own is to use the built-in Paint Editor in Scratch (refer to Chapter 10) and right-click a costume in the Costs Area to save it from the menu (This is known as exporting in Scratch 1.4 and saving to a local file in Scratch 2.0)
- **One image named pop.png:** This image is shown when the game hits. Ours is a cartoon-style pointy bubble with "Pop!" written in it. We made this image in Scratch.

- **Two sounds — one for the popping of a target and the other to play when the game ends:** We're using a sound effect we found online blop.ogg for when cloud bursts, and a tune Sean made on the iPad called whoops.ogg for when the game ends.

The .ogg format is a sound format often used in open source software. You can also a .wav file in Pygame Zero. If you're using sound effects different from ours, the filenames in the programs to your choices.

## Creating and Running Your First Program

The WIDTH and HEIGHT variables are used to set up the size of the window — in our case, a square of 500.

### LISTING 12-1: Your Firstgame Program

```python
WIDTH = 500
HEIGHT = 500

cloud = Actor('target5')

def draw():
    screen.clear()
    cloud.draw()
```

The coordinates are measured from the top left of the window, so you go from 0 to 500 from left to right (the x direction), and from 0 to 500 down the window (the y direction). If you want to change the x position of the cloud actor, you can assign it a new value, like this:

```python
cloud.x = 250
```

Because the window is 500 pixels across and the actor's position is measured from its center, changing the actor's x position to 250 centers it in the window.

The last thing you need to do is draw the sprite. The draw() function is run regularly by Pygame Zero, and it's where you tell it what to draw on the screen. (See Chapter 11 for more on how functions work and are defined.) When you start moving around, theyll leave a trail if you don't remove the previous images before drawing each screen, so you start this function by clearing the screen with this instruction:

```python
screen.clear()
```
