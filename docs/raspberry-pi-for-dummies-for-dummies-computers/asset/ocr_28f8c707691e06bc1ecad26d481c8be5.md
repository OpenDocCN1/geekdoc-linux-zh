It doesn't matter much when you're experimenting with sprites, but when you make your games and animations, you can save yourself a lot of brain ache by giving your sprites meaningful names. It's much easier to remember that the costume with the name *game over* should be shown when the player is defeated than to remember it is called *costume*. Rename the costumes tab to show the costumes, and then click the costume's current name (refer to Figure 9-8) and type its new name. In Scratch 2, the costume's name is shown above the editing canvas.

![](bbox=[0.173, 0.355, 0.228, 0.433])

In the Blocks Palette, there are two blocks you can use to switch between costumes. (See Figure 9–9.) Click the Looks button above the Blocks Palette to show them:

+   **Switch to Costume:** If you want to switch to a particular costume, choose its name from the menu in this block and then click the block.
**Next Costume:** Each time you use this block, the sprite changes to its next costume. When the costumes run out, it goes back to the first one.

![](bbox=[0.173, 0.686, 0.228, 0.764])

You can show a sprite's costume number on the Stage, too so that it's easier for you to work out what's going on. Just select the check box next to Costume # in the Blocks Palette.
