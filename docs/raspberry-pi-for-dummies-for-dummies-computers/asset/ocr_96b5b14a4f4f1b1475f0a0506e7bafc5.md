# Using graphic effects

You can apply several graphic effects to your sprite using Looks blocks. In Figure 9–10, we've used eight sprites to demonstrate them on the Stage. The Color effect changes the sprite's Color Palette, turning orange to green in the case of the cat. The Fisheye effect works like a fish-eye lens, making features around its middle. Pixelate makes the sprite blocky. Mosaic shrinks the sprite and repeats it within the space it occupies. The Brightness and Ghost effects sometimes look similar, but the Brightness effect increases the intensity of the colors (turning the cat's black outline while softening the orange), and the Ghost effect fades out colors evenly.

Here are the three blocks you use to control effects:

+   **Change Color Effect** by 25: You can select the effect you want to change (by default, the color effect) and enter the amount of it you want to add. can use negative numbers to reduce the extent to which the effect is applied to your sprite. The color effect has 200 different levels (from 0 to 200), and the other effects typically look best with sprites in the range -100 to 100. Experiment!

+   **Set Color Effect** to 0: Use this block to set a chosen effect to a specific level. Choosing 0 turns off the effect. You can use any of the seven effects with this block.

+   **Clear Graphics**: This block removes all graphic effects you've applied to a particular sprite so that it looks normal again.

The graphic effects look great, but they are quite slow on a Raspberry Pi B+ or older. They're best used in moderation for special moments in your animation or game; otherwise, they might appear unresponsive.

# Resizing your sprite

Earlier in this chapter, we show how to change the starting size of your sprite on the Stage. You can use blocks to issue instructions to change its size, too, so you could make it larger as the game progresses, for example.

There are two blocks you can use to resize your sprite:

+   **Change Size** by 10: This block enables you to change the size of your sprite by a certain number of units, relative to its current size. As usual, you can edit the number. If you want to decrease the sprite's size, use a negative number.
