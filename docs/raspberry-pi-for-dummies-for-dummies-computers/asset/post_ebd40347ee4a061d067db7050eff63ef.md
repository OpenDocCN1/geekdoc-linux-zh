# Penguins Puzzle

Penguins Puzzle, shown in Figure 19-1, is a 3D puzzle game where you are tasked with safely escorting a penguin to the exit without letting it fall off the iceberg into the freezing water. You use the cursor keys to move around, press Z to zoom out for a wider-angle view, and press R to reset the level. The game has 50 levels to test your mettle. When youve finished playing, press Esc to exit.

```bash
sudo apt-get install penguinpuzzle
```

Start the game from the shell by typing penguinpuzzle.

# FocusWriter

Whether you're writing the next blockbuster or just need to work without distraction, FocusWriter might be the application for you. It's a word processor designed to be distraction-free. Most of the time the, the only thing onscreen is your writing. To keep your motivation up, you can set a daily goal for time spent (better still, words written per day). When you move the mouse to the bottom of the screen, you can see the progress toward your daily goal.

To install FocusWriter, search for focuswriter on the Add/Remove Software menus or in the shell, use


To start FocusWriter, go into your desktop environment and click the program's entry in the Applications menu. You can find out more about the application at http://code.org/focuswriter.

# Mathematica

Mathematica is what is known as a symbolic package, or CAS (Computer Algebra System), and it's preinstalled in Raspbian. It is one of the best systems for exploring anything with numbers, from mathematics to complex graphics. To get started, click the Applications menu and click the Mathematica icon. When you see a splash screen, then two windows open: a blank notebook and, in front of it, invitation to visit websites. Click the notebook to bring it to the front. Type an expression and Press Return, but you don't see an answer. Youve entered the expression into Mathematica, but in order to tell the program to evaluate it (and give you the answer), use Shift+Return. Mathematica can expand equations for you:

```mathematica
Expand[(1+x)^6]
1 + 6x² + 2x³ + 15x⁴ + 6x⁵ + x⁶
```

It can plot graphs, such as these parametric plots:

```mathematica
For[n=1, n<4,
 ParametricPlot[{Sin[t], Sin[(n+1) t]}, {t, 0, 2Pi}] // Print
```

Graphical output might take a moment to render, so be patient if necessary. Mathematica even plots 3D graphics:

```mathematica
SphericalPlot3D[Sin[t] Cos[t] Sin[f], {f, t, 0, 2 Pi}]
```

# Xinvaders 3D

If you're a fan of classic arcade cabinets from the 1970s and 1980s, you'll have a blast with Xinvaders 3D. The game uses line graphics (like the classic game Asteroids) to put a fresh spin on Space Invaders. The 3D rendering makes the aliens move progressively closer to you, and you move in four directions to line up your shots. It's good, clean, retro fun. Move using the cursor keys, and fire by pressing the spacebar.

To install Xinvaders 3D, search for *xinvaders* on the Add/Remove Software menu or in the shell,

```bash
sudo apt-get install xinv3d
```

To run Xinvaders 3D, click the icon on the taskbar to go into the Terminal and then enter **xinv3d**.
