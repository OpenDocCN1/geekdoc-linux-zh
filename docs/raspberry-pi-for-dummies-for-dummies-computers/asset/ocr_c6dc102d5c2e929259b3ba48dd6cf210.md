+   **Paint New Sprite:** This opens the Paint Editor so that you can draw your sprite in Scratch.

+   **Choose New Sprite from File:** You can use this button to bring one of the preset sprites into your project or to bring in a graphic you've created using a different art package. It's also a quick way to get started if you want to experiment with scripting. If you don't like the sprite you get, you can always delete it and try another sprite.
