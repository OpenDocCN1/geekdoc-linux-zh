> You can also get to the appearance settings by right-clicking the desktop and choosing Desktop Preferences from the menu that appears.

To adjust the sensitivity of the keyboard and mouse, use the mouse and keyboard settings in the Preferences section of the Applications menu. For left-handers, you can swap the left and right mouse buttons, too.

# # Finding and Installing New Applications

You can discover new software to install using the command line (Chapter 5), but there's also a friendly menu system you use in the desktop environment. On the Applications menu, hover over the Preferences option and Add/Remove Software to get started. You need to have an internet connection.

Figure 4-13 shows you the. In the top left is a search box, where you can enter the name of a program you're looking for, or a phrase such as puzzle games to explore what's available. On the left are categories you can click to see your options.
