# Control the flashing speed with an input

Using a GPIO pin as an input is simple: just wire a push switch between the GPIO pin and ground. When the switch is pushed, the pin is connected to ground, and when it is not, it isn’t connected to anything. As we demonstrate in Chapter 15, when a pin isn’t connected to anything and the computer reads it, then it can return any value because it picks interference from the air.
