# # Grisbi

If you want to manage your home accounts on the Raspberry Pi, Grisbi is a free
application you can use to keep track of your regular and one-off payments.
Alother programs are also available, Grisbi is the easiest one we've tried,
both to set up and keep updated. Many banks enable you to download your bank
statements in a format that can be used in Grisbi, so you might be able to analyze
your financial situation without too much rekeying.

To install Grisbi, search for *grisbi* on the Add/Remove Software menu or, in the
shell, use

```
sudo apt-get install grisbi
```

You can find it in the Office category of your Applications menu.
