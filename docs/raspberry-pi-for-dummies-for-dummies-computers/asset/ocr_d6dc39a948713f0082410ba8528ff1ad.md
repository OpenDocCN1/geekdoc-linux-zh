# # Enabling keyboard control of a sprite

For our space game, the player needs to be able to move the ship left right using the arrow keys. In Plain English, you need to use a set of blocks that says, "If the player presses the left-arrow key, move the ship left." And, and you need to put those blocks inside a Forever block so that Scratch keeps checking and moving the ship all the way through the game. You need a similar set of blocks that move the ship right, too.

The If is a Control block that enables a set of blocks to be run only under certain conditions. For that reason, it often called a conditional statement in programming. Like the Forever block, it's shaped like a bracket, you can put other blocks inside it. In the case of the If block, the blocks are inside ones you want to run only in certain circumstances. Drag the If into the Scripts Area, inside the Forever block.

Scratch is designed like a jigsaw puzzle, so it gives visual hints about what blocks can go if the program is to make sense. The If block is a diamond-shaped hole in it, which is where you describe the circumstances under which you want its blocks to run. There are diamond-shaped Operator and Sensing blocks as well, and we use both in this program.

The block you need for keyboard control is a Sensing block called Key Space Pressed? — it detects a tap on the spacebar. If you want it to detect the pressing of a key other than the spacebar, use its to set the key. In this case, you want it to detect the left-arrow key. You can drag and drop this Sensing block into the diamond-shaped hole in the If block in the Scripts Area.
