# Creating scripts

Clicking blocks in the Blocks Palette is one way to issue commands to Scratch, but if that's all you're doing, you're not really programming. The fact is, if you have to click each block every time you want to run it, you're doing all the hard work of remembering the instructions, and the computer work only as fast as you can click the blocks.

A program is a reusable set of instructions that can be carried out (or run) whenever you want. To start to create a program, you drag blocks from the Blocks Palette and drop them in the Scripts Area of the screen. Most blocks mentioned so far in this chapter have a notch on the top and a lug on the bottom, so they fit together like jigsaw pieces. You don't have to align them perfectly; Scratch snaps them together for you if they close enough when you release the mouse button.

You put your blocks in the order you want Scratch to run them, starting at the top and working your way down. It's a bit like making a to-do list for the computer.

A group of blocks in the Scripts Area is called a script, and you can run the script by clicking anywhere on it. Its border is highlighted, and you will see the cat around the Stage as you've instructed it.

You can have multiple different scripts in the Scripts Area, so you could have one to make the cat walk left and another to make it right, for example. When you add multiple sprites (see Chapter 10), each script has its own Scripts Area to control it.

If you want to tidy the Scripts Area, you can move a script by dragging it. If you drag a block is lower down, it is separated from the blocks above it. If you want to delete a script or a set of blocks, drag it back to the Blocks Palette on the left.

# Using the Wait block to slow down your sprite

As you put your script together, you might find that some movements happen fast that you can hardly see what's on.

If you click the Control button at the top of the Blocks Palette, you can find a set of yellow blocks that are used to govern when particular things happen. You can read more about these in Chapter 10, but for now it's worth knowing that a block enables you to wait for a certain number of seconds. Drag this into your script where necessary to introduce a delay so that you can see each of your blocks in action. The length of the delay is 1 second by default, but you can change it to whatever you want, including parts of a second (for example, 0.5 for half a second).

![](img/df9a01bf057d58c2401b5edabd6e8829_195_0.png)

The Wait block can also be used to force the script to pause before running any blocks.

# Saving your work

Remember to save your work so you can come back to it. You can find the option to save on the File menu, at the top of the screen, or you can click the Floppy Disk icon in the top left in the original Scratch.

In the original Scratch, when the Save Project dialog opens (see Figure 9-13), you see buttons on the left to choose from places you could save your file, although you might not have permission to use all of them. (See Chapter 5 for more permissions.) We recommend you use the Scratch folder inside your pi directory. On the right, you can add your name and project notes to remind you later what the project was. You can see and edit the project notes associated with a file by using the File menu when you're working on a program.

When you save in Scratch 2, you see a file browser that enables you to choose where to save. Again, we recommend saving in your Scratch folder inside your pi directory.

# What’s new in Scratch 2

The two versions of Scratch on your Raspberry Pi share the same core blocks, but there are a few differences in Scratch 2 to be aware of:

- **Events blocks:** This is a new category of blocks introduced in Scratch 2. It includes blocks that were categorized as Control in the older version of Scratch. If the block starts with “when” or “broadcast,” you’ll probably find it in the Events part of the Blocks Palette in Scratch 2. (The exception is When I Start as Clone, which remains a Control block.)
- **Cloning:** There’s a new feature in Scratch 2 to enable creating copies (or clones) of themselves. Those clones can run scripts that start when the clone is created. You can find the blocks to experiment with cloning in the Control part of the Blocks Palette.
- **More Blocks:** Scratch 2 enables you to build your blocks by combining existing blocks. It’s a great way to make programs that are easier to read. Click the More Blocks button above the Blocks Palette to try it.
- **Data:** The variables of the Blocks Palette have been renamed to Data in Scratch 2. It is otherwise the same. We cover variables in Chapter 10.
