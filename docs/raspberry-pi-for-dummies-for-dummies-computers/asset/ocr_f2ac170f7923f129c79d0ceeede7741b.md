```
Volts = Amps × Ohms
```

However, it would be too easy to just use that as a formula. People would understand straight off, and that would never do! You have to build up a mystique. Imagine how you would feel about a doctor if he actually told you in plain English what was wrong with you. No, it needs to be dressed up so that everyone can understand it. Ohm's law becomes

```
E = I × R
```

where E is the electromotive force measured in volts, I is the current measured in amps, and R is the resistance measured in ohms.

This is the formula you use in books and all over the Internet, remember — it's just

```
voltage = current × resistance
```

Connecting things to the Raspberry Pi involves juggling voltage and current, and often you need to use a resistor to limit the current a voltage pushes through a device in a circuit. Using Ohm's law is the simple way to work out what you need. Later on in this chapter, we show how to use this to make sure you drive light-emitting diodes (LEDs) correctly.

Resistance is not the only thing we can calculate. If we know two of the quantities in a circuit, we can calculate the other one.
