## Using costumes

One way to use sprites is like the characters in a game (although they can be used for lots of other objects, too, such as obstacles). Each sprite can have a number of costumes, which are different pictures of it. If the costumes look fairly similar, you can create the illusion of animation by switching between them. Your cat comes with two costumes, and when you switch them, it looks like the cat is running. You can think of a costume as being one image in an sequence (an frame).

You can see the costumes for your sprite by clicking the Costumes tab at the top of the Scripts Area, as shown in Figure 9-8. If you want to modify the cat's appearance, you can click the button to edit one of the costumes in Scratch or simply click the sprite in Scratch 2 and use the editing canvas to paint it. If you want to create a new animation frame, you can click the Copy button beside a costume in Scratch, or in Scratch 2 you can right-click the costume and duplicate it from the menu that opens. You can then edit the bits you want to change.

## Using graphic effects

You can apply several graphic effects to your sprite using Looks blocks. In Figure 9–10, we've used eight sprites to demonstrate them on the Stage. The Color effect changes the sprite's Color Palette, turning orange to green in the case of the cat. The Fisheye effect works like a fish-eye lens, making features around its middle. Pixelate makes the sprite blocky. Mosaic shrinks the sprite and repeats it within the space it occupies. The Brightness and Ghost effects sometimes look similar, but the Brightness effect increases the intensity of the colors (turning the cat's black outline while softening the orange), and the Ghost effect fades out colors evenly.

Here are the three blocks you use to control effects:

- **Change Color Effect** by 25: You can select the effect you want to change (by default, the color effect) and enter the amount of it you want to add. can use negative numbers to reduce the extent to which the effect is applied to your sprite. The color effect has 200 different levels (from 0 to 200), and the other effects typically look best with sprites in the range -100 to 100. Experiment!

- **Set Color Effect** to 0: Use this block to set a chosen effect to a specific level. Choosing 0 turns off the effect. You can use any of the seven effects with this block.

- **Clear Graphics**: This block removes all graphic effects you've applied to a particular sprite so that it looks normal again.

The graphic effects look great, but they are quite slow on a Raspberry Pi B+ or older. They're best used in moderation for special moments in your animation or game; otherwise, they might appear unresponsive.

## Resizing your sprite

Earlier in this chapter, we show how to change the starting size of your sprite on the Stage. You can use blocks to issue instructions to change its size, too, so you could make it larger as the game progresses, for example.

There are two blocks you can use to resize your sprite:

- **Change Size** by 10: This block enables you to change the size of your sprite by a certain number of units, relative to its current size. As usual, you can edit the number. If you want to decrease the sprite's size, use a negative number.

- **Set to 100%:** This block sets the size to a percentage of its original size, so with the default value of 100 percent, it effectively resets resizing you've done.

You can also select the check box beside the Size block to show the sprite's size on the Stage, in the same way you display other sprite information. (See “Show-ing information on the Stage,” earlier in this chapter.) This can be useful for testing purposes.

![](img/df9a01bf057d58c2401b5edabd6e8829_191_0.png)

## Changing your sprite's visibility

Sometimes, you might not want your sprite to be seen on the Stage. If a spaceship is blown up in your game, for example, you want it to disappear from view. These two blocks control whether a sprite is visible:

- **Hide:** Use this block to make your sprite invisible on the Stage. If a sprite is hidden, Scratch won't detect when it touches, but you can still move a sprite's position on the Stage so that it's in a different place when you show it.

- **Show:** By default, your sprite is visible, but you can use this block to reveal it after you have hidden it.

Sometimes, sprites might get on top of each other. You can use the Go to Front block to make a sprite appear on top of all the others. To push a sprite backward and allow others to appear on top of it, use the Go Back Layers blocks.

As well as changing a sprite's appearance, you can give some sound effects. Scratch comes with sounds, including slurps, sneezes, and screams; ducks, geese, and owls; pops, whoops, and zoops.
