Most of the time when you have an input, the code contains an if statement, because the main point of having a switch is to determine what section of code is to run. Next, we show how to write a program that selects one of two wait times, depending on the state of an input push button.

Start by clicking a green flag block from the control panel, and add a broadcast gpio2ervice broadcast block, and a broadcast config2out block, as you did in the Scratch LED block green.
