## Using dictionaries

Besides lists, there is another data structure that we use in our program, called a dictionary. To access an item in a list, you use an index number, which represents its position in the list. Dictionaries are different because you access an item using its key — a string or a number that uniquely identifies it. The idea is used a lot in computing. Your bank account number, for example, belongs to you and only you, so it's a unique key for your data. Unlike a list, you don't need to know where that item is in the dictionary to be able to use it — you just need to know the key that identifies it.

Dictionaries use braces, and contain pairs of items, which are the keys and the values for those keys. If that seems confusing, here's an example that won't seem different from the paper dictionary on your bookshelf:

```
chat_dict = {"happy": "I'm happy today too!",
    "sad": "Tell me all about it.",
    "raspberry": "Oh yum! I love raspberries!",}
```

In this example, we've given the dictionary chat_dict, but you can call it ant. You can have more than one entry in your program, if you give them different names.

In this dictionary, we look up a word to see what the reply to it should be. For example, if someone uses the word happy, the computer should reply, "I'm happy today too!" you look up the word hello, you can see that the computer's response should be, "Why, hello to you, buddy!" Each entry is made up of a key and its value, separated by a colon; for example, the key happy and its value, which is the computer's response to that word. The entries are separated from each other with a comma.

The punctuation is quite fickle, so take care; otherwise your program might not work. The text strings have quotes around them, but the colon between the keys and their values must be outside the quotes. Each pair needs to end with a comma except the last one, and we use curly braces to enclose everything. (You usually find curly braces on your keyboard on the same key as the square brackets.)

Dictionaries only work if every key is unique. You can't have two entries in there for the word happy, for example; otherwise, Python wouldn't know which one to choose.

Dictionaries only work one way around: You can't use the value to look up the key. One to remember this is to think of a real paper dictionary. It would be almost impossible to trace a particular definition back to a word because you wouldn't know on which page you could find the definition. ## Creating own functions

One of the things you can do in Python is to group a set of instructions together and give them a name. This is called a function. We already showed you how to call a function, but now let's learn how to define one. To define a function, you use the `def` keyword followed by the name of the function, some parameters in parentheses, and a colon. The code for the function is indented.

```python
def chat_bot(message):
    if message == "happy":
        return "I'm happy today too!"
    elif message == "sad":
        return "Tell me all about it."
    elif message == "raspberry":
        return "Oh yum! I love raspberries!"
    else:
        return "I don't understand that."
```

In this example, the `message` is a parameter, which is a variable that can be passed into the function when it is called. The `return` statement is used to send a value back to where the function was called. If you don't use a `return` statement, the function returns `None`.

Here is how you would call the function we defined:

```python
response = chat_bot("happy")
print(response)
response = chat_bot("sad")
print(response)
```

By using functions, you can make your code much cleaner and easier to manage. You can also reuse the same function multiple times without having to rewrite the code.

## Using arguments with functions

You can also pass information into a function using arguments. This allows the function to behave differently depending on the input it receives. 

```python
def greet(name):
    return "Hello, " + name + "!"

print(greet("Alice"))
print(greet("Bob"))
```

In this example, `name` is an argument. When we call `greet("Alice")`, the string "Alice" is passed into the `name` parameter.

```python
def add_numbers(a, b):
    return a + b

print(add_numbers(5, 3))
print(add_numbers(10, 20))
```

A function can take many arguments.

## Default values for arguments

You can also provide default values for your arguments. If an argument is not provided when the function is called, the function will use the default value.

```python
def greet(name="Guest"):
    return "Hello, " + name + "!"

print(greet())
print(greet("Alice"))
```

In this example, if `greet()` is called without an argument, it uses "Guest". If `greet("Alice")` is called, it uses "Alice".

## Global and local variables

Variables defined inside a function are local to that function and can only be accessed from within it. Variables defined outside a function are global and can be accessed anywhere in the program.

```python
def my_function():
    local_var = "I am local"
    global_var = "I am global"
    print(local_var)
    print(global_var)

my_function()
print(global_var)
# This would cause a NameError because local_var is not defined outside the function
# print(local_var)
```
