# Changing files are displayed

When you right-click an empty space in the right pane in File Manager, a menu opens with an option to change how the files are sorted. You can sort files by name, modification time, size, or file type, in ascending or reverse order.

You can change how files and folders are shown in File Manager, you so strike a balance between how many you can see at time and how easy they are to see. The View menu on the bar at the top of File Manager gives you the choice of four ways to display the files and folders in the Folder View mode. By default, File Manager uses the icon, which strikes a balance between the number of files you can see at time and the size of each icon. The thumbnail preview that takes the place of a generic icon for picture files. To see as many files as possible at one time, use the compact view, which fits the files and folders with umms and the filename.

The detailed list (see Figure 4-7) reveals more information about each file, showing a short description, its size, and when it was last modified. You can click the column headings to sort the view by the filename, description (which groups similar files), size, or modification date. If you click the column heading again, the sort order is reversed.
