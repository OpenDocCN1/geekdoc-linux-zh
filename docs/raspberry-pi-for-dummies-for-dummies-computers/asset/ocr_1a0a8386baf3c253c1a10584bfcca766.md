The first step is to test whether your preferred command name is already in use. If the type command tells you anything other than not found, you need to think up another command name, or risk upsetting an existing command. Here's your test:

```
pi@raspberry ~ $ type pidel
bash: type: pidel: not found
```

Now that you know the command pidel is not yet taken, you can create your alias. To do that, make an alias, like this:

```
alias pidel='rm -vi'
```

Between the quote marks, the Linux command that you want to execute when you enter the pidel command. As you will see from this alias, when you use pidel, it behaves like rm -vi, but you will no longer have to remember the letters for others. For example:

```
pi@raspberry ~ $ *.txt
rm: remove file 'fm.txt?' y
removed 'fm.txt'
rm: remove file 'toc.txt?' n
pi@raspberry ~ $
```

You can combine lists of commands in your alias definition by separating them with semicolons. For example:

```
alias pidel='clear;echo removes files with the interactive and verbose options on.;rm -vi'
```

Your alias only lasts until the computer is rebooted, you can make it permanent by putting the alias instruction into the file .bashrc in your home directory. To edit that file, use

```
nano ~/.bashrc
```

Nano is a simple text editor that is covered in more detail in Appendix A, but in brief, you can edit your file, use Ctrl+O to save, and Ctrl+X to exit.

Your alias can go anywhere in the .bashrc file. For convenience, and to avoid the risk of disturbing important information there, we suggest you add your aliases at the top. Each one should be on its own line.
