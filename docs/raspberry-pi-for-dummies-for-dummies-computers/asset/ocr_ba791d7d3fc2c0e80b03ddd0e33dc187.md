# # Xinvaders 3D

If you're a fan of classic arcade cabinets from the 1970s and 1980s, you'll have a blast with Xinvaders 3D. The game uses line graphics (like the classic game Asteroids) to put a fresh spin on Space Invaders. The 3D rendering makes the aliens move progressively closer to you, and you move in four directions to line up your shots. It's good, clean, retro fun. Move using the cursor keys, and fire by pressing the spacebar.

To install Xinvaders 3D, search for *xinvaders* on the Add/Remove Software menu or, in the shell,

```
sudo apt-get install xinv3d
```

To run Xinvaders 3D, click the icon on the taskbar to go into the Terminal and then enter **xinv3d**.
