Across the top of the screen is a bar with menus for File, Edit, Select, View, Image, Layer, Colours, Tools, Filters, Windows, and Help. You can browse these menus to get an idea of what the program can do, and find options quickly if you don't know which icons they use on the toolbar.

On the left is a pane that contains icons for the tools and the tool options at the bottom. When you roll the cursor over a tool's icon, a tooltip pops up to tell you what it does. When you click a tool to select it, the options at the bottom of the pane change, depending on the tool you're using. For example, if you're using the paintbrush, the options covers properties such as opacity and the brush type.
