latest program to make the clouds reappear at the bottom when they go off the top:

```
def update():
    for i in range(6):
        this_cloud = clouds[i]
        if this_cloud.y < 0 - this_cloud.height:
            this_cloud.y = HEIGHT + this_cloud.height
        if timer > 0:
            this_cloud.x = \
                random.randint(int(this_cloud.width / 2), \
                int(WIDTH - this_cloud.width / 2))
            this_cloud.image = 'target' + str(i)
            animate(this_cloud, tween='linear', \
                random.uniform(10, 30), \
                pos=(this_cloud.x + random.randint(-50, 100)))
```

The update() function is like Pygame's draw() function that it is automatically run. It's where you put your instructions to change the position of your actors, or otherwise update the game's progress. The update() function in this game uses a loop to look at each cloud in turn, and uses the variable this_cloud as shorthand for each cloud it works with. If the cloud is fully off the screen (it y is less than 0 minus its height), the function resets it to the bottom of the screen. This creates some margin because the program only needs to subtract half the height from the position, in the middle of the image, to be certain it's off the screen. By doing it as we do is simpler, and also makes it look more like a stream of clouds — and less like the clouds keep wrapping around the screen. If there is still time on the clock, we also reset it randomly reset the image to the target image, because in some cases the cloud will become a 'pop' image if it was called. (We'll add that code shortly.) We also start a new animation, using the same instruction as we did at the start of the program.

You can run the program now to see an unending stream of clouds floating in the window.
