# Getting Familiar with the GPIO

The Raspberry Pi Model 1, and the Pi Zero are made from BCM2835, single-core system on a chip. The Pi Model 2 uses the BCM2836, and the Model 3 uses the BCM2837 — both are quad core. Basically, a core is a processor, so the later models have four processors at the same time, although this capability is not presently fully exploited by the operating system. The cores in the Pi Model 3 are more powerful than the cores in the Pi 2, but have the full power of this processor yet to be exploited by the operating system. This is because it will mean a version of the operating system for each type of core, and at the moment there is just the one version of each operating system for all three processor chips.

Unlike microprocessors, these chips are designed to be used in an embedded system. An embedded system is a device that has a computer inside it, but you don't use it as a computer — things like mobile phones, GPS displays, digital cameras, and TV set-top boxes. These chips have a number of connections in order for the software in them to control things like push buttons and displaying sound and out. All the processors used for the Pi have 54 General Purpose Input/output pins (GPIO), and they can be controlled by software. Some of these signals are used to build and control the peripheral devices that turn the chip into a computer, like the SD card reader, the USB, and the Ethernet. The rest are free — that is, not needed to make the Pi — so they are surplus to necessities.

Rather than just these surplus GPIO lines, the designers of the Raspberry Pi have routed some of them out to the connector on the board for you to use. It's a bonus. This sets the Pi apart from mainstream computers and laptops in this respect. However, they have not routed all the pins out to this connector. Go to other connectors — the camera socket, for example, or the display socket — and are not even connected to anything. This is because the family of chips used to make the Raspberry Pi are housed in a package called BGA, or Ball Grid Array, with connections less than a millimeter apart. So close are that you can only have enough room for one trace (PCB wire) between the connectors.
