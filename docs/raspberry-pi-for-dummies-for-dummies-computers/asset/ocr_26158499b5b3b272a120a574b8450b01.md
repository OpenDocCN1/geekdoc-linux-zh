If you add a third number between the brackets (parentheses) of the range function, it's used to specify the size of the gap between numbers. To show only the odd numbers (starting at 1 and adding 2 each time the program repeats), you'd use range(1, 13, 2). (You don't need to do that now, but you can experiment with the ranges later.) The rest of the line containing the range() function sets up the start of the bit to be repeated and says that the variable i should be given the next value from the number sequence each time it repeats. The first time, i has a value of 1, the first number in the sequence. The second time, i has a value of 2, which is the second number in the sequence. This goes all the way to the last repetition, when i has a value of 12.

You tell Python which commands should be repeated by indenting them. The print() command we've used four spaces in front of it, and in Python these spaces are meaningful. Many languages let you space programs however you want, but in Python the spacing is part of how the computer understands your intentions. By enforcing the indentations like this, Python makes it easier to read programs you can see at a glance which bits belong together. They're all at the same depth.

You can repeat multiple commands by indenting them all:

```
for i in range(1, 13):
    print(i, "times", tabenum, "is", i * tabenum)
    print("-----------------")
    print("Hope you found that useful!")
```
