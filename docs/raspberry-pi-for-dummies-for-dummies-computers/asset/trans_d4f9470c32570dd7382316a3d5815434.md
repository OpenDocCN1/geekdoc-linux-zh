# 树莓派的故障排除与配置

许多人发现他们只需要连接上树莓派，一切就能第一次就正常工作。祝你也能如此顺利！

然而，人们有时会遇到问题，或者想要对电脑的设置进行更高级的更改（也称为配置）。

在本附录中，我们将向你展示如何解决一些故障以及如何更改某些设置。希望你不需要经常查阅本附录，但如果你在设置树莓派时遇到非预期行为，或者你有特殊的设置需求，它可能会被证明非常有价值。

无论你在树莓派上做什么（或者说在任何电脑上做什么），请定期保存你的工作。如果系统崩溃，你将从上次保存的版本继续，这可能可以防止你丢失过多的工作。

## 树莓派的故障排除

当 Sean 第一次开始使用树莓派时，他无法在桌面环境中连接到互联网，尽管在 Linux 命令行中运行良好。事实证明，问题出在一个不兼容的键盘上。根据他看到的症状，他通常完全不会怀疑是键盘导致的。因此，我建议你尝试这些步骤，无论这些步骤解决问题的可能性看起来多么微乎其微。配合我们，你可能会大为惊喜！

这些步骤按照大致的优先级顺序列出，最快的测试和最简单的解决方案排在前面。你可以任何时候尝试这些解决方案之一，但如果你倾向于这个顺序（或或如此），你就可以尽量减少开销和麻烦。

- 1. **保持耐心。**
随着多年来性能的巨大提升，这就像是树莓派刚出来时常见的问题，但仍然值得一提：当你的树莓派处于忙碌时，它看起来可能没有响应，所以你可能会认为它崩溃了。如果你等一下，它在完成任务后就会恢复。如果它没有运行任何你特别关心的事情，你可以随时重启机器，但这会丢失内存中的任何数据，而且在安装软件时（如果可以避免）重置操作不是个好主意，因为这会导致操作半完成。注意，树莓派内置了屏幕保护程序，你可以通过移动鼠标（在桌面环境中）或按下任何键（在命令行中）从空白屏幕恢复树莓派。你可以使用 Shift 键让屏幕上不显示任何内容。

- 2. **重启你的树莓派。**
极少数情况下，机器以我们无法复制的方式崩溃，简单的重置有时可以奏效。要重置，拔掉电源，暂停一会儿，然后重新连接。

- 3. **检查你的连接。**
关闭你的树莓派，确保电缆牢固地固定在正确的插座中。从问题的根源开始：例如，如果屏幕是空白的，检查视频线；如果键盘无响应，检查其连接。第 3 章是设置树莓派的指南，包括外围设备和电缆。

- 4. **确保你的 MicroSD 或 SD 卡插入正确。**
如果树莓派的红色 PWR 灯亮了但绿色 OK 灯没有闪烁或亮起，说明树莓派在使用 SD 或 MicroSD 卡方面遇到困难。首先，检查卡是否插入正确。（第 3 章。）

- 5. **尝试新的 SD 或 MicroSD 卡。**
如果红灯亮了绿灯不亮，尝试一张新卡。我们偶尔遇到 SD 卡或 MicroSD 卡的问题，以及将 MicroSD 卡转换为以适应 SD 卡槽的适配器的问题。你可以在 http://elinux.org/RP1_SD_cards 找到已报告与树莓派兼容的 SD 卡列表。

- 6. **断开外围设备。**
尝试断开 USB 集线器、键盘和鼠标，然后重启。显然，如果你正在经历的问题需要输入设备来重现，那么这可能无济于处，但它可以帮助识别任何可能阻止树莓派正常启动的设备不兼容问题。如果你需要使用键盘来测试问题是否再次发生，请直接连接到树莓派。你可以在输入密码或测试任何你需要的程序后将其断开。如果树莓派在不连接任何设备的情况下运行正常，可以通过排除法（一个一个连接设备并重启）来确定是哪一个引起了问题。

- 7. **尝试新的外围设备。**
如果可能，尝试新的键盘、鼠标和 USB 集线器，理想情况下来自 http://elinux.org/RP1_VerifiedPeripherals 上已知的设备列表。人们经历的许多问题都是由于与树莓派使用不兼容的设备导致的，因此更换键盘、鼠标和 USB 集线器可以解决各种看似不同的问题（包括前面提到的 Sean 在网络连接上遇到的奇怪经历）。上一步可以帮助你识别哪些外围设备可能导致了问题。

- 8. **尝试新的电缆。**
特别是当你在网络连接和音视频输出方面遇到问题时，尝试新的电缆以排除故障电缆是问题的原因。

- 9. **尝试新屏幕。**
如果你无法在屏幕上看到任何内容，但树莓派似乎在启动（红灯亮起且绿灯闪烁），请连接到不同的显示器或电视。关于此的建议请第 3 章。

- 10. **更新你的软件。**
假设你的互联网连接正常，你可以使用以下命令（第 5 章）更新树莓派上的操作系统和其他软件（而不会覆盖你的文件）：
```
sudo apt-get update && sudo apt-get upgrade
```

- 11. **尝试新的电源。**
我们将其放在步骤列表的最后，因为它可能最难做到，尽管电源不稳定被报告会导致各种不同的问题。如果你有一个朋友的树莓派且她的运行正常，尝试使用她的电源看看是否能解决你遇到的问题。或者，你可能需要购买一个新的电源。如果你升级了树莓派但没有升级电源，你可能会遇到问题。在 PIXEL 桌面上，右上角的闪电符号意味着电源不足，温度计意味着温度过高。关于购买电源的建议见第 1 章。

- 12. **在线查找解决方案。**
无法涵盖每种情况，所以如果你遇到困难，请查看本附录的其余部分，然后在 linux.org/R-Pi_Troubleshooting 搜索故障排除指南，在 raspberrypi.org 搜索论坛，或者使用 Google 或 DuckDuckGo (www.duckduckgo.com) 搜索解决方案。你可能发现已经解决了你遇到的任何困难。

# 调整你的树莓派设置

树莓派使用的设置存储在 MicroSD 或 SD 卡的文件中，许多位于 /boot 目录下的名为 config.txt 的文件中。你可以使用树莓派上预装的简单文本编辑器 Nano 直接编辑此文件来更改电脑的设置。

你可能不需要手动调整设置。尝试使用 PIXEL 桌面（第 3 章）或运行 raspi-config 程序，它提供了一个用于更改某些常用选项的菜单，包括一些桌面工具中不包含的选项。你可以随时在 shell 中使用以下命令运行该程序：

img/df9a01bf057d58c2401b5edabd6e8829_463_0.png)

```
sudo raspi-config
```
