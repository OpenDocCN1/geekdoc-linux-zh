Over the years, the Raspberry Pi has evolved, increasing its memory, improving its performance, and adding features. So which one should you get? Here's an over-view designed to help you decide:

+   **Raspberry Pi 3 Model B:** The third generation of the Raspberry Pi, it represents the best all-round Raspberry Pi at the time of writing. According to the Raspberry Pi Foundation, it is 5 to 60 percent faster than the previous model, and ten times faster than the original Raspberry Pi. It includes 1GB of memory, four USB ports, built-in Wi-Fi and Bluetooth, and an Ethernet port for a wired connection. It has 40 General Purpose Input/Output (GPIO) pins, which you can use to connect to your own electronics projects. Like previous models, it's about the size of a credit card. As with any current Raspberry Pi, it includes a microSD card for storage. If you're not sure which model to get and your budget allows, get this one. It represents the fastest performance, and offers the best experience on the desktop. Its price is around $35 (about £30).

It's called the Model B, incidentally, as tribute to the BBC Microcomputer that was popular in the U.K. in the 1980s. It's sobering to think that the BBC Micro cost ten times the price of a Raspberry Pi, thanks to 35 years of progress in computer science, has more than 7,800 times more memory.

+   **Raspberry Pi 1 Model A:** a cut-down model, it is ideal for projects with lower power consumption — typically battery-based. It is suitable for robots and projects in remote locations, where a wired electricity supply is isnt. It has one USB port, although you can connect it to a USB hub to use more devices simultaneously. It has the full complement of 40 GPIO pins, so you would find that your projects and adds work with it. Like the Model B, it includes an audio output (headphones-style) socket. This has 512MB of memory and a price of $20 (or £20). The Model A+ is slightly shorter on the long side than the Raspberry Pi 3, measuring 6.5 centimeters.

+   **Raspberry Pi Zero:** The Raspberry Pi Foundation astonished everyone when it gave this away with the print edition of its magazine The MagPi. The Raspberry Pi Zero measures 6.5 centimeters by 3 centimeters, extremely lightweight, and has 512MB of memory and one Micro USB port. If you want to use the GPIO, you'll need to solder or affix your own pins, available separately. (You can read all about GPIO pins on the Pi Zero in Chapter 16.) You'll also need a connector for the Mini HDMI socket, and for the Micro USB socket, so you should expect to spend a bit more than the price of the Pi (and have a bit more complexity in your setup). Built as the $5 computer, the Raspberry Pi Zero has at times been difficult to get hold of, which is perhaps not surprising given the phenomenal demand for it.
