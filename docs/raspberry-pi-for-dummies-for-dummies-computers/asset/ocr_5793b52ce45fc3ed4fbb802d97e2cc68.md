The range of numbers you want to use for the random number is the size of the random_replies list. You can use the len() function to see what this is, so you can add things to your list or remove them without having to worry about updating your program. In the random.randint() statement, you replace the second number with the length of the list:

```
print(random.randint(1, len(random_replies)))
```

You don't want to just print the result onscreen, however so you store the number chosen in a variable called reply_chosen.

There's one, final twist: Because list indices start at 0, you need to subtract 1 from the random number. Otherwise, the program would never choose the first list item, and would want instead to choose one at the end of the list that isn't there. Here's the final command:

```
reply_chosen = random.randint(1, len(random_replies)) - 1
```

The two lines print the randomly selected item and then replace that list item with whatever the user entered:

```
print(random_replies[reply_chosen])
_replies[reply_chosen] = user_says
```
