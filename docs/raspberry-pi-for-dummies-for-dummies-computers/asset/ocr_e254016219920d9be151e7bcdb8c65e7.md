# LISTING 12-1: Your First Pygame Zero Program

```
WIDTH = 500
HEIGHT = 500

cloud = Actor('target5')
cloud.x = 250
cloud.y = 250

def draw():
    screen.clear()
    cloud.draw()
```

To run a Pygame Zero game, you need to use the command line. Follow these
steps:

+   1. Using File Manager, navigate to the pi folder. (For more on navigating
File Manager, see Chapter 4).

You should see your cloud1.py file, and the folder that contains your
target images.

+   2. Choose Tools from the File Manager main menu, and then Select
Current Folder in the menu that appears.

You can also use F4 as a keyboard shortcut for this.

+   3. In the terminal, enter pgzero cloud.py after the prompt.

You should see something like Figure 12-1, with an image in the middle of a new
window that opens. You might need to wait a moment for the window to open.
When you've finished with it, you can click the Close button in the top right of
the window or use Ctrl-C in the command line to quit. Don't close the command
line window; you can save time by keeping it open so that you can use it to start
next Pygame Zero program or to run this one after modifying it.

The WIDTH and HEIGHT variables are used to set up the size of the window — in our
case, a square of 500 pixels.

Pygame Zero introduces the idea of actors, which are like sprites in Scratch. An
actor stores an image and its position in one place, which makes it easier to man-
age characters and obstacles in your Python. This kind of thing is already built
into Scratch, but it's not part of Python, or even Pygame. The use of actors in
Pygame makes it much easier to move from programming in Scratch to using
Python.
