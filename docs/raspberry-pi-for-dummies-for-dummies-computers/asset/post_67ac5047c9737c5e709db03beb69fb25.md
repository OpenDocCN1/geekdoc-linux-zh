We address the LEDs in a strip, they're numbered from zero to the length of the strip, and basically it is the same. However, when thinking about a matrix, it's much more convenient to consider the x and y address of an LED; one of the fundamental routines when driving a matrix is to convert an x/y pair into an LED number. The actual conversion involved depends on how the LED chain is bent into a matrix. The Adafruit matrix uses what is called a bottom-up raster arrangement. The LEDs start off at zero in the lower-left of the matrix (known as the origin) and increase along the x-axis. When the end of the x is reached, the next LED number is directly above the original origin. This repeats along the second row, and the third, and so on until the end of the strip. (The other fundamental way of wiring a matrix is known as a serpentine raster, where the strip zigzags up the strip. You can see these different methods in Figure 17–12.)

Converting to LED numbers for the simple raster is quite easy and is given by

```
LedNumber = X + (Xmax * Y)
```

given X and Y are the coordinates you want to get the LED number for and that Xmax is the number of LEDs in a row. Of course, this assumes that both coordinates are within the confines of the matrix. In practice, it is necessary to check the coordinates before calculating the LED number.

The serpentine row is physically easier to wire up, but a little more complicated to work out an LED number. This is because the preceding conversion works on odd-numbered rows. For even-numbered rows, you need to use this:

```
LEDNumber = (Xmax - X - 1) + (Y * Xmax)
```

That means any routine must first test to see if the y-coordinate is indicating an odd or even row before choosing the formula to use. This is simply by looking at the least significant bit — the right hand bit in the number of the y-coordinate.

Other graphics can help you draw things on a matrix. Perhaps the most fundamental is *drawing*, given a start and an end coordinate pair, you can draw a line of lit LEDs between them. Of course, on a small matrix, horizontal, vertical, and 45-degree diagonal lines will look good; all other lines will be stepped, or jagged. The trick is to work out the difference between the start and end points; the axis with the biggest difference is given an increment value of the smaller size over the longer length. Then the x-coordinate to plot starts at the initial point of the line, and subsequent points are found by repeatedly adding the increments to the respective coordinates. One of the increments will be 1, and another fractional value. It is only when the size of this coordinate exceeds a whole.

We implemented two other graphics: the square and the filled square. In fact, the code for an *outline* of a square is longer than a filled square. We could have used the line primitive to implement these two functions, but drawing horizontal and vertical lines is much quicker with a simple loop because division is needed. We made three displays that change automatically after a fixed amount of time. The program is in Listing 17–7.

# Listing 17-7: Matrix brooch

```python
#!/usr/bin/env python3
import time, random
from adfruit_matrix import Adafruit

dataPin = 23
clockPin = 24
lenX = 8
lenY = 8
brightness = 1

def main():
    print("8 by 8 matrix - stop")
    nextChange = time.time() + patternDuration
    pattern = 1
    while True:
        if pattern == 1:
            pattern1()
        if pattern == 2:
            pattern2()
        if pattern == 3:
            pattern3()
        if time.time() > nextChange:
            nextChange = time.time() + patternDuration
            pattern += 1
            if pattern > 3:
                pattern = 1

def pattern1():
    for side in range(0,lenX):
        for i in range(0,lenX):
            square(i,side,randCol())
            leds.show()
            time.sleep(0.1)
        time.sleep(0.6)
        leds.setAll((0,0,0))

def pattern2():
    start = 0
    for side in range(start,lenX-1,0,-2):
        square(start,side,randCol())
        leds.show()

def pattern3():
    col = randCol()
    for t in range(1,8):
        line(0,0,t,col)
        hold()
    for t in range(1,8):
        line(0,0,t,col)
        hold()
    for t in range(8,0,-1):
        line(0,0,t,col)
        hold()
    for t in range(7,0,-1):
        line(0,0,t,col)
        hold()

def hold():
    leds.show()
    time.sleep(0.08)
    leds.setAll((0,0,0))

def matrix(x,y,col):
    pixel = x + y*8
    if pixel < length and x < lenX:
        leds.setLed(pixel,col)

def square(x,y,side,col):
    for xp in range(x,x+side):
        for yp in range(y,y+side):
            matrix(xp,yp,col)

def square_filled(x,y,side,col):
    for xp in range(x,x+side):
        matrix(xp,y,col)
    for xp in range(x,x+side+1):
        matrix(xp,y+side,col)
    for yp in range(y,y+side):
        matrix(x,yp,col)
    for yp in range(y,y+side):
        matrix(x+side,yp,col)

def line(xs,ys,xe,ye,col):
    xl = xe - xs
    yl = ye - ys
    if xl > yl:
        xinc = 0.0
        yinc = y/xl
    else:
        yinc = 1.0
        xinc = xl/yl
    x = float(xs)
    y = float(ys)
    while x != xe or y != ye:
        matrix(int(x),int(y),col)
        x += xinc
        y += yinc

def randCol():
    r = 0; g = 0; b = 0
    while r+g+b == 0:
        r = random.randint(0,2) * 64
        g = random.randint(0,2) * 64
        b = random.randint(0,2) * 64
    return (r,g,b)

# * Main program logic:
if __name__ == '__main__':
    try:
        main()
    except KeyboardInterrupt:
        pass
    # turn off all LEDs
    leds.setAll((0,0,0))
    leds.show()
```
