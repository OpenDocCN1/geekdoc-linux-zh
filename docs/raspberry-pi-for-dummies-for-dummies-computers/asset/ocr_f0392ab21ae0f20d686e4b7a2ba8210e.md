Lakka: This retrorogaming system includes emulators for a range of vintage home computers (including the Commodore 64 and Amiga, Atari CPC, Atari Atari and the ZX Spectrum), as well as game consoles (including a number of Nintendo games and the Sony PlayStation). The Multi Arcade Emulator (MAME) option can be used to play games from classic coin-operated arcade machines, too. To use Lakka, you'll need to get the games separately, unless you want to play the 2048 and Bomberman clones that are included (among the game system cores). Lakka has been released by their creators for free distribution online (including games for MAME at http://mamedev.org/roms, and Sean's Amiga games at www.sean.co.uk/books/amstrad/index.htm).

The easiest way to get games into Lakka is to use a USB key with the game files. In the system menu, you use the cursor keys to move, Enter to select, and the Back (Delete) key to go back. In the Lakka jargon, a game is called a core, and a game is called content, so by choosing Content from the main menu, Choose Start Directory, and then choose your USB key to see the games on it. You'll be given a choice of which core to use. If you're using MAME, press 5, 6, 7, or 8 to insert a coin (for player 1, 2, 3, or 4), and then press Enter or a number from 1 to 4 (for the number of players). Cursor keys move, and the Fire keys can vary by game (T, Z, X and the Ctrl, Alt, and Shift keys for Player 1). You can quit game and return to the main menu by pressing the Esc key. If you're using keyboard controls, you may find that your game doesn't work correctly, because Lakka uses many keys to control features like the emulator speed. To reconfigure the keys that Lakka uses, return to the main menu, press the right arrow to go to the settings, choose Input, and then choose Hotkey Binds.

Recalbox: This is another games system, with emulators for the SNES, NES, Game Boy Advance, Sega Master System, and PC Engine. It also includes the shareware version of the famous run andgun Doom. All of the emulators include demonstration games, so an afternoon's action arcade is built in. In the system menu, use the cursor keys to move through the options; press S to confirm and A to go back. Check the bottom of the screen for hints on the controls, and tap the Windows key (if your keyboard has one) to enter the settings. In the games, controls may vary, but generally you can use the cursor keys to move and Z or X to fire and jump. Press Esc to quit.
