# Ten Inspiring Projects for the Raspberry Pi

If you've read the rest of this book and worked through the projects, you now know how to program and how to create your own electronics projects on the Raspberry Pi. What you learn next, and what you create with that knowledge, is up to you.

It's amazing to see what people of all ages are doing with their Raspberry Pi. In this chapter, we've collected some of the most interesting and inspiring projects we've come across. Each one has a link so that you can find out more and perhaps instructions to replicate the project — or get some advice for similar projects-ects of your own.
