# FIGURE A-1:

The Nano text editor with the config.txt file open.

Use the cursor keys to move around the document. At the bottom of the window is a menu explaining Nano's controls, where the upward arrow represents the Control key. The shortcuts here are different from what you might be used to, but the main ones you should know about

+   **Ctrl+W:** Search for a word or phrase. This option (short for Where Is?) enables you to jump straight to the configuration option you want to edit.
**Ctrl+V:** Next page.
**Ctrl+K:** Cut the current row of text.
**Ctrl+U:** Uncut text, which means paste the text you previously cut at your cursor's location.
**Ctrl+G:** Get help, which provides more detailed instructions.
**Ctrl+O:** Write out, or save, the current file.
**Ctrl+X:** Exit Nano and return to the shell.
