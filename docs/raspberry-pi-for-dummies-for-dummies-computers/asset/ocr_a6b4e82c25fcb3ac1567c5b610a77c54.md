The main function, consisting of two large loops, is where the action happens. The inner loop while gameOn runs a round of the game, where bombs are sent down until there have been three hits to the base — when a bomb reaches a bomb of zero, in other words. The first if statement checks to see whether enough time has passed to move the bomb another step closer to the base. The call to the fireBeam function checks which buttons are being pressed to generate a bomb, if they are, the beam is fired off and a sound is triggered. If the beam color matches the bomb color, the bomb is triggered and the current bomb height is added to your score. The round is restarted by setting the bomb height back to 8 and a new bomb color is generated. The program returns to the main loop.

If a bomb is found to have reached the base, then the base is turned red and the explosion sound is triggered. If it has reached zero, the round is over and the gameOn variable is set to false, thus ending the current loop. Then the final lines of the while loop displays the score and you wait until you press a button before starting the game again.

The array of LEDs here is called sky, which is descriptive enough, and the overall speed of the game is controlled by the gameSpeed variable in the it function. When you quit the game by pressing Ctrl and c (a Keyboard Interrupt), all LEDs are turned off to clean up the display.
