# Accessing Raspberry Pi’s GPIO Pins

The GPIO pins are the key to enabling the Raspberry Pi to take control of any external circuit. They can be used as an output to an LED or as an input to sense the state of an external push button. These connections are the computer, along with the fixed voltage power pins, are on a dual-row, 40-pin header plug. There are many ways to physically access these pins, and the least expensive way wasn’t always the easiest or the most convenient way.
