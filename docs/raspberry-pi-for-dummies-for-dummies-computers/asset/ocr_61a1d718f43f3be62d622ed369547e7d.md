retrace[1] will hold your previous z position. Here's the code, including a line to show the gold block in its new position:

```
else: # do this when there are no unvisited neighbors
retrace = cellsVisitedList.pop()
xposition = retrace[0]
zposition = retrace[1]
showMaker(xposition, zposition)
```

Note that the else statement should be in line with the if statement it's paired with — in this case, the one that tests whether you found any possible directions to in.

Step 6 in the algorithm has already been implemented the while loop will keep repeating the indented code underneath it until every cell has been visited.

# Adding a ceiling

Personally, we think it's more fun to leave the ceiling open and free to fly up and marvel at your maze and then drop it into any point. If you want to build a game around your maze, though, and stop people from cheating, you can add a ceiling using the following code. Just change the variable CEILING to True at the start of the program. We've making the ceiling out of glass bricks, so it doesn't go out in dark:

```
if CEILING == True:
mc.setBlocks(MAZE_X, GROUND+HEIGHT+1, MAZE_Z, 
MAZE_X+(SIZE*2), GROUND+HEIGHT+1, MAZE_Z+(SIZE*2), 20)
```

# Positioning the player

Finally, let's place the player at the random position where you started generating the maze. You could put the player anywhere, but this seems like a good place as any, and uses random numbers you have already generated:

```
mc.player.setTilePos(realx(player), GROUND+1, 
real(player)
```
