像这样录入卡片后，最好用某种方式标记卡片，以显示哪些是你已经录入的。你可以通过许多方法实现这一点，从简单的手写标签到带有艺术家名字的复杂设计——甚至可以根据专辑进行设计。在彩色打印机上打印完成后，用喷雾胶将其贴在卡片上。最后用图书馆中常用的覆盖和保护书籍的透明塑料膜覆盖卡片即可完成。

## 装饰纸人

纸质人已经存在很长时间，但它们仍然深受各个年龄段儿童的。借助 RFID 技术，你可以制作出这种玩具的现代版本，它的性能优于其他产品。这种想法是让你有一个基础娃娃以及许多不同的服装和配件。这些通常被贴在纸板上并剪下来。通过衣服上的胶带，你可以以混搭风格装扮你的娃娃。通过 RFID，你可以让卡片指定每件衣服，并在屏幕上构建你装扮好的娃娃，这种无缝集程度是纸质版本无法实现的。

网上有很多供个人使用的免费剪裁表格，以及你可以画的图样。你也可以自己画——如果你画画得比我们画得好的话。考虑到我们并不太擅长画画，我们与年轻艺术家 Imani Osmon 合作，提供了我们这里作为示例的艺术作品。（我们认为，发现并画出你自己的作品可能同样令人兴奋。）
