+   2. In the Width box, enter in pixels the width you want the final image to be. Press Enter when you have finished the editing.

If you want to put a holiday snap on your website, you probably wouldn't want it to be more than 500 pixels wide. If you want to use a photo as a Scratch background (see Chapter 10), the ideal size is 480 by 360 pixels.

When you enter a new value for the width and press Enter or Tab, the height is updated automatically, so the image stays in proportion and doesn't become stretched. You can also enter a value for the height and the width calculated automatically. If you want to be able to adjust the width and height independently, click the chain to the right of your boxes to break it.

+   3. Alternatively, instead of using absolute values for the width and height, you can resize the image to a certain percentage. Click the Units-down box (it says px) and choose Percent.

The values in the Width and Height boxes will then be percentages. For example, you would enter 50% to shrink the image by half. The size of the image is shown under the Height box.

+   4. When you've set the size, click the Scale button.

At the bottom of the screen, underneath the Image pane, you can see some information about the file, including the current zoom level, which is how much the image has been magnified or reduced for you to view it. If you set this to 100%, you can get an idea of how much detail is in the image now, and it's easier to edit too.
