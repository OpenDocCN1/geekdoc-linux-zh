idea of functions and how we'll be using it:

# # Example of functions

```
def dictionary_check(message):
    print("I will look in the dictionary for ", message)
    return "hello"

dictionary_check("blue")

result = dictionary_check("red")
print("Reply:", result)
```

We talk you through that program in a moment, but here's a glimpse of what is
shown onscreen when you run it:

> I will look in the dictionary for blue
I will look in the dictionary for red
Reply: hello

This is a short but powerful program because it tells you everything you
eed to know about functions. As you can see, we defined the function at the start
of the program, with this line:

```
def dictionary_check(message):
```

This sets up a function with the name dictionary_check() but also sets up to
receive a piece of information from the rest of the program and to put it into the
variable message. The next line prints out a statement, "I will look
in the dictionary" followed by the contents of the variable message. That
means prints out whatever information is sent to the function. The next line
starting with return exits the function and sends a message back, with which
example is hello.

Functions are self-contained units, the variable message can't be used by the
rest of the program. (It's known as a local variable.) When you're writing your own
functions, you should give them a job to do and then use return to send the result
back to the rest of the program.

Functions aren't run until you tell the program to run, so when
Python uses the function definition, it just remembers it for when it needs it.
That time comes shortly afterward, when you issue the command:

```
dictionary_check("blue")
```
