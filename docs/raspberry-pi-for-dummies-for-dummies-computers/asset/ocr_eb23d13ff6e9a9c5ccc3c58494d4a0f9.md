VLC Media Player is a music and video player that works on the PIXEL desktop. You can install VLC at the command line (see Chapter 5) using:

```
sudo apt-get install vlc
```

After VLC has been installed, you can find it in the Sound and Video category of the Applications menu and click its name to start it up.

On the media menu of VLC are options to open a file or directory. Usually, you'll want to open a directory so that you can play a album. By default, VLC shows you the album artwork (where available), but you can open the View menu and choose Playlist to see a list of songs so you can pick another to play (as shown in Figure 8–3). In the box the left, you can pick a device to play, including several Internet services for streaming music. Choose Playlist from the View menu to revert to the full-window architecture.
