The program sets up new variables for the score and the timer, which we'llnuse later. It also creates a new list called clouds.

The loop at the start sets up the multiple clouds. It loops six times, giving
the variable i values 0 to 5 in turn. It creates the filename for this actor,\sby joining 'target' to i, making the filenames target0, target1, and so on.
The program has the str() function to convert i from a number to a string
before it is joined to the 'target' string. The program then adds a new actor
to clouds list, using that filename for the image.

To make the program easier to read, it uses a variable called this_cloud to refer
to the it currently setting up. Its position is set to a random position
in the window. Make sure it doesn't spill off the edge, the program uses
im's width to work out minimum and maximum possible values for the
x position. The image is positioned from its center, half its width is the mini-\mum position for it all to fit on the screen. If the image is 100 pixels wide, for
ample, its center must be at least 50 pixels from the left to fit in. On the right,
the program makes a similar calculation, but it subtracts half the image's width
from the WIDTH. The x position that's chosen is a random integer
between minimum and maximum positions on the left and right.
