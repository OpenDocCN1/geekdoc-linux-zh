It's similar to the way you create a variable. After the list name comes an equal sign, and then square brackets that contain the list. Each item in the list is separated by a comma. Because each item is a piece of text (or a *string*), you put quotes around it so that Python knows where it starts and ends.

![](bbox=[0.268, 0.189, 0.223, 0.223])

Python doesn't mind whether you use double quotes or single quotes in your list, but we recommend that you use double quotes. That's strings often include apostrophes. If you're using a single quote mark (') to close the apostrophe, Python thinks it has reached the end of the string when it hits the apostrophe. If you need to use an apostrophe inside a string that's marked at each end with a single quote, put a slash (/) in front of the apostrophe (for example, 'Mum\s custard'). It's easier to just use double quotes for strings.

TECHNICAL STUFF

You can put all items on one line, but the program is easy to read if you put each item on a new line. Using the editor, if you press Enter at the end of a list item, it items the next line to the same depth as the item above it, so your list looks near, in the previous example.

![](bbox=[0.178, 0.433, 0.233, 0.473])

When you're entering lists, pay particular attention to the commas, otherwise your program might not work: One should appear after every list item except for the last. This is another reason it's a good idea to put list items on separate lines: You can more easily see at a glance when a comma is missing. Your program is color-coded, so the comma stands out among the strings, which makes it easier to spot errors.

WARNING

'milk']
```

Python uses single quotes around the strings in your list, irrespective of the kind of quotes you used to set it up. To find out how many items are in a list, use the len()

```
>>> print(len(shopping_list))
