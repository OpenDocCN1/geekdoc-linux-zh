When the Pi has finished booting, you should be in the desktop environment. You'll learn more about this topic in Chapter 4, but for now, let's take a look at how you use it to finish setting up your Pi.

Click the button in the top left, the Raspberry Pi logo on it, to open the menu. Move down to Preferences and choose Raspberry Pi Configuration. The tool that opens is shown in Figure 3-13.

![](bbox=[0.266, 0.245, 0.616, 0.493])

Figure 3-13: The Raspberry Pi Configuration tool in the PIXEL desktop.

By default, the tool opens to its System tab. The options here include

+   >> Change the password. The default password for the username pi is raspberry.
>> Change the hostname (which is used for the Raspberry Pi on the network).
>> Control whether it boots into the desktop or the command line interface (CLI), explained in Chapter 5.
>> Set whether the pi user is automatically logged in.
>> Set the pi to wait for the network at the start.
>> Display the firstly splash screen that shows when the Pi is booting.
>> Configure the screen resolution.
>> Enable or disable underscan. Underscan and overscan change the size of the displayed screen image to optimally fill the screen. Underscan should be disabled to fill the screen if you see a black border around your screen, and enabled if the desktop does not fit on the screen.
