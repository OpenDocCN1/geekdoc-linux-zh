# # Navigating File Manager

On the right of File Manager, you can see the files (and folders) that are inside the folder you're looking at. Each file has an icon indicating the type of file it is, except for image files, which have a small representation of the picture itself. In Figure 4-4, you can see the different files that the Python games come with your Raspberry Pi, including pictures of game characters and backgrounds, and sound effects that are shown with a Musical icon.

You can double-click a file in this area to open it, and double-click a file to open it with the default program for that file type, an image opens using the Image Viewer, for example, and a Scratch file opens in Scratch. If you want to choose which program to open a file instead, you can right-click the file's icon to bring up an option Open With. Select it to bring up a menu of all of the programs available on your Raspberry Pi, and make your choice.
