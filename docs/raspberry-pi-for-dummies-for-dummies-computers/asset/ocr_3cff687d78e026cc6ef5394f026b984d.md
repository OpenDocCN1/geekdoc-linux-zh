You can test whether it's worked and log in as the new user without restarting Pi by logging out from your current user account. Close the shell window and select Shutdown from the Applications menu. Choose Logout from the options, and you will be presented by the login screen, where you can test the new username. The default password for the pi account is raspberry.

If you use the password command to set a password for the username root, you will be able to log on as the superuser, who has the power to do anything to the machine. As a result, this might enable you to get some types of software working, but you will advise yourself against using it. It's safer to take on the mantle of the superuser only when you need it, by using sudo.

# Learning More about Linux Commands

Lots of information about Linux is available on the Internet, but plenty of documentation is hidden inside the operating system itself. If you want to dig further into what Linux can do, this documentation can point you in the right direction, although some of it is phrased in quite a technical way.

Commands in Linux can take several different forms. They might be built into the shell itself, they might be separate programs in the /bin directory, or they be aliases (which are explained in the next section). If you want to look up the documentation for a command, first find out what of command it is, using the type command, like this:

```
@raspberry ~ $ type cd
cd is a shell builtin
@raspberry ~ $ type mkdir
mkdir is /bin/mkdir
@raspberry ~ $ type ls
ls is aliased to 'ls --color=auto'
```

If you want to find out where a particular program is installed, use the which command together with the program name:

```
which mkdir
```
