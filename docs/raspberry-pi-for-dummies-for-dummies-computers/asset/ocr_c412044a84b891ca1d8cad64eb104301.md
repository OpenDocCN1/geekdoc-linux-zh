We store possible replies to the user in a list called `smart_replies`, so we create that an empty list. The next step is to set up a loop that goes through the list of words that the user entered. When you used a `for` loop previously, you worked your way through a sequence of numbers. This time, you worked your way through a list of words. Each time you loop, the variable `each_word` contains the next item from the list of words the user entered.

The next line introduces a new idea, the conditional statement, which starts with if. A `conditional statement` is used to enable the computer to make a decision about whether it should carry out instructions, and you'll come across one in almost every program you write. It’s being used to prevent the program from stopping and returning an error if you try to use a key that isn't in the dictionary:

```
if each_word in chat_dict:
    answer = chat_dict[each_word]
    smart_replies.append(answer)
```

The variable contains one of the words the user entered, so if the statement checks to whether that word is in the dictionary and carries out the next two instructions only if they are. Notice how indenting (by a four spaces) is used to show which commands belong together — in this case, commands are controlled by the `if` statement. If the word is in the dictionary, the program looks it up and adds the resulting response to the `smart_replies` list, using `append()`.

This process is repeated for every word the user entered, but that’s all happens in the loop. The next line is not indented below the `for` statement, so it’s not controlled by it.

When the program comes out of the loop, it checks to see whether the list `smart_replies` has anything in it, by using simply

```
if smart_replies:
```

In English, this means “if `smart_replies` has content in it.” The commands indented underneath are carried out only if some entries were added to the `smart_replies` list, which happens if one or more of the words the user entered were found in the dictionary. In that event, you want to return one of the items from the `smart_replies` list to the main program, so the program picks one random from the list and uses `return` to send it back to the main program and exit the function.
