+   **Rotate Left:** Rotates the image 90 degrees counterclockwise. The shortcut is L.
** **Rotate Right:** Rotates the image 90 degrees clockwise. The shortcut is R.
** **Flip Horizontally:** Mirrors the image horizontally and can also be done with the H key.
** **Flip Vertically:** Turns the image upside down. The V key does the same.
** **Open File:** Opens a new file. You can also drag and drop an image on the Image Viewer from a folder in File Manager. This doesn't move the file — just opens it.
** **Save File:** Saves the image (including any rotations or mirroring you have done) and replaces the original image. You get a warning before it happens. Keyboard shortcut: S.
**Save File As:** Saves the image with a new filename so that it doesn't overwrite the original image.(You can also press the A key to do this.) Use the menu at the bottom of the Save As window to choose the image format.
