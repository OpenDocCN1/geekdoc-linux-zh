Next come the permissions for the owner, group, and world. These are the different types of permissions someone can have:

+   **Read permission:** The ability to open and look at the contents of a file, or to list a directory

+   **Write permission:** The ability to change a file's contents, to create or delete files in a directory

+   **Execute permission:** The ability to treat a file as a program and run it, or to enter a directory using the cmd command

![](bbox=[0.173, 0.355, 0.239, 0.431])

That probably seems logical and intuitive, but there are two potential catches: First, you can only read or write in a directory if you also have execute permission for that directory; and second, you can rename or delete a file only if the permissions of its directory allow you to do so, even if you have write permission for the file.

The permissions are expressed using the letters r (for read), w (for write), and x (for execute), and these make up a 3-letter code in that order. Where permission has not been granted, the letter is replaced with a hyphen. In Table 5-2, you can see that the owner can read and write the file, but the group and world (everyone) can only read it.

The code for the Desktop folder in our listing is drwxrxr-xr. The first letter tells you it's a directory. The next three (rwx) tell you that the owner can read, write, and execute it, which means they have freedom to list its contents (read), add or delete files (write), and enter the directory in the first place to carry out those actions (execute). The next three characters (r-x) tell you that group members may enter the directory and list its contents (read), but may not create or delete files. The final three characters (r--) tell you that everyone else (the world) has been granted those same-permissions.

Several commands are used to change the permissions of a file using chmod to change the permissions, chown to change a file's owner, and chgrp to change the file's group. We don't have space to go into detail here but see Learning Linux Commands,” in this chapter, for guidance on how to get with them. The easiest way to change permissions, in any case, is to choose Properties from the menu that appears. Right-click a file in File Manager (see Chapter 4) and the desktop environment. You can then use the Permissions tab in the Properties window that appears (see Figure 5-3) to change the permissions associated with a file.
