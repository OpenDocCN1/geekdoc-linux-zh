Three types of basic RGB LEDs.

The dotted box around each LED is a schematic that shows they're all in one package. Note that the common anode and common cathode types have four wires going into them instead of the normal two for a single-color LED. Each LED can be treated by the software as a separate LED. To use common LEDs, you have to wire them up so that the GPIO pins act as current sinks, that is making the connection to ground. The wiring for the two common "something" types is shown in Figure 17-2.

With a common cathode, the GPIO pins should be set to a logic high to turn the LED on, and to a 0 to turn it off. (For more logic highs and zeros, see Chapter 16.) However, with a common anode, this situation is reversed, turning on the LED by sinking current and making a complete circuit that way. When confronted by Figure 17-2, a beginner typically has this: "Why do I need to have three resistors? Why can't I just have one in the common line?" to which the answer is, "Yes, you need all three resistors"
