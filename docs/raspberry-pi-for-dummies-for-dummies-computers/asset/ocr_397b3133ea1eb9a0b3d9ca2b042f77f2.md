When the software has finished installing your operating system (patient!), you see a message telling you that it's been successful. If you installed just one operating system, your Raspberry Pi starts that operating system.

If you installed more than one operating system, you're given the option of which one you want to start (or boot). Double-click to choose it. Each time you start up your Raspberry Pi, you're given a choice of operating systems. If you don't choose something, it boots into your previous choice.

To install or reinstall an operating system using NOOBS, you can hold the Shift key when you start up your Raspberry Pi. Remember that installing or reinstalling operating systems deletes all files on your SD or microSD card.

# # Logging In

When you switch on your Raspberry Pi, you might be asked for a username and password, depending on which operating system version you use. The default username and password differ depending on which version of Linux you're using, but for the Raspbian distribution, the username is pi and the password is raspberry. Both of these are case-sensitive, so you can't type in PI, for example. When using the shell, you receive no feedback on the screen as you enter the password. It not only hides your password but also doesn't show you that a key press happened, which is a bit unsettling the first time. Press on regardless, and you should find your login details are accepted.

After logging in, you may be shown the command-line prompt followed by a blinking line:

```
pi@raspberry ~ $
```

This means your Raspberry Pi is ready for you to use and you can enter Linux commands now, to manage your files and programs. (For information about using the command line to give your Pi instructions, see Chapter 5.)
