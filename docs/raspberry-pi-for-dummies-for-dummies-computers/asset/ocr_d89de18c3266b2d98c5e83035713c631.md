It can plot graphs, such as these parametric plots:

```
For[n=1, n<4, n++],
ParametricPlot[ {Sin[t], Sin[(n+1) t]}, {t, 0, 2Pi}] //->
Print]
```

Graphical output might take a moment to render, so be patient, if necessary.
Mathematica even plots 3D graphics:

```
SphericalPlot3D[Sin[t] Cos[t] Sin[f], {f, t, 0, 2 Pi}]
```
