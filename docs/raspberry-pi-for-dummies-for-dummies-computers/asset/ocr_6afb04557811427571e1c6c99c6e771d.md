If you don't want to make a copy of a file, but instead want to move it from one place to another, use the mv command. For example, if you misfiled one of your images and want to move it from the australia directory to the japan one, both in your home directory, you would use

```
mv ~/australia/itinerary.txt ~/japan
```

That works as long as the destination directory exists. If it doesn't, the command assumes that you want the file to have the new filename of japan, and so the file stops itinerary.txt in the australia directory, and becomes a file called japan in the home directory. It's confusing if you do it by mistake, but this quirk is how you rename files in Linux. You move them from being the old name into the new name, usually in the same folder, like this:

```
mv old newname
```

There's no recursive option with the mv command because it moves directories easily as it moves by default.

# # Installing and Managing Software on Your Raspberry Pi

Linux distributions come with thousands of packages, which are programs that are ready to download from the Internet and install on your computer. In this chapter, we show you how to use the command line to install software. There is also a simple menu for installing software on the Raspberry Pi within the desktop environment, described in Chapter 4. You might find it useful to know what's going on in the background, though, and the command line gives you more of a sense of it.

Some packages require other packages to work successfully, but luckily a program called a package manager unt all these dependencies and takes responsibility for downloading and installing the software you want, together with any other software it needs to work correctly. On the Raspberry Pi, the package manager is called apt.
