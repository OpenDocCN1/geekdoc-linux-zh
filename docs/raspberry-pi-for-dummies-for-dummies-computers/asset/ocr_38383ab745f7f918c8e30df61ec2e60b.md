For example, if you wanted to copy the file config.txt from the /boot directory to your home directory (~) so that you can safely play with it, you would use

```
cp /boot/config.txt ~
```

If you wanted to copy the file into your current working directory, wherever that is, you could use

```
cp /boot/config.txt
```

You can also specify a path to an existing folder to send the file by using

```
cp /boot/config.txt ~/files/
```

Your original file and the copy don't have to have the same name. If you specify a different filename, the copy takes that name. For example:

```
cp /boot/config.txt ~/oldconfig.txt
```

That copies config.txt from the /boot directory to your home directory and renames it to oldconfig.txt. This same technique enables you to keep a safe copy of a file you're working on, if you want to revert to an old version. The paths are optional, so if you were in your home directory, you could create a backup copy of the file timeplan there using

```
cp timeplan.txt timeplan.bak
```

You can use several options with cp, some of them familiar from the rm command. The cp command overwrites any files without asking your away, so use the -i option to ask you before it overwrites any existing files with the new copies. The -v option gives you an insight into what the command has done, as it does with rm.

You can use wildcards, so you can quickly copy your files, or all your files that match a particular pattern. If you want to copy subdirectories too, however, you need to use the recursive option, like this:

```
cp -R ~/Documents/* ~/homebak
```

That copies everything in your Documents directory (including any subdirectories) into a folder called homebak in your home directory. The homebak must exist before you run the command for it to work. For advice on using the shell to copy to external storage devices, see Appendix A.
