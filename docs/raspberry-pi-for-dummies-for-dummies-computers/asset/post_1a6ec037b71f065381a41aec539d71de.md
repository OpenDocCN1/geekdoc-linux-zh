
If you want to choose files that begin with a particular letter, you can use the square brackets wildcard. To choose any files beginning with the letters a, b, or c you would use [abc]*. To narrow that down to just those that end with .jpg, you would use [abc]*.jpg.

Table 5-3 provides a quick reference to the wildcards you can use, with examples.

You can use wildcards anywhere you would usually use a filename. For example, you can delete all your files starting with the letters img, like this:

```
rm -vi img*
```

To delete all files ending with the extension .txt, use

```
rm -vi *.txt
```

Be especially careful about where you insert spaces when you're using wildcards. Imagine that you add a sneaky space in the previous example, like this:

```
rm -vi * .txt
```

Doh! The shell thinks you want to delete *, which is a wildcard for every file, and then to delete a file called .txt. Luckily, you've used the -i option, so you'll be prompted before deleting each file — though people often forget when they're deleting a lot of files, because otherwise they spend a long time confirming each deletion, which is almost as tedious as not using wildcards in the place.

One way you can test if files matches a wildcard is to use the file command with before you delete it. For example:

```
file .txt | less
```

Take care that you don't introduce any spaces between testing with file and removing with rm!

Another thing to be careful about is using wildcards with hidden files. Hidden files begin with a period (full stop), so you might think that * would match all the files, but it also matches the current directory (.) and its parent directory (..), so . matches everything in the current directory and the directory above it.

## Removing Directories

You can use two commands for removing directories. The first one, rmdir, is the safer of the two because it refuses to remove directories that still have files or directories inside them. Use it with the name of the directory you want to remove — for example, books, — like this:

```
rmdir books
```

If you want to prune a branch of the directory tree, you can use the rm command to remove a directory and delete anything inside and its subdirectories. Used with the recursive option (-f), it deletes any files in its way. It's a rampage beast of a command. Here's an example:

```
rm -Rf books
```

It acts silently and swifty, deleting the books directory and anything in it.

You can add the interactive option to cut the risk, which prompts you for confirmation of each deletion, as you can see in this example where we've left a file in the folder work/writing/books:

```
pi@raspberry ~ $ rm -Rfi work
rm: descend into directory 'work?' Y
rm: descend into directory 'work/writing?' Y
rm: descend into directory 'work/writing/books?' Y
rm: remove regular file 'work/writing/books/rapidplan.txt?' Y
rm: remove directory 'work/writing/books?' Y
rm: remove directory 'work/writing?' Y
rm: remove directory 'work?' Y
```

You can use wildcard when removing directories, but special care be taken and make sure you don't introduce any unwanted spaces that result in your removing (everything). If you use -Rf . to remove directories, you also match the current directory (.) and the parent directory (..). That means it deletes every file in the directory (hidden or not), all its subdirectories and its contents (hidden or not), and everything in the parent directory, including its subdirectories (again, whether or not they are hidden).

## Copying and Renaming

One of the fundamental things you'll want to do is copy files, so use cp. If you want to make a copy of a file, you can specify the source and destination like this:

```
cp source.txt destination
```

You can also copy a file to a different directory by specifying the path. For example, if you want to copy file.txt to your home directory, you would use:

```
cp file.txt ~/
```

If you want to copy multiple files at once, you can use wildcards. For example, to copy all .txt files to a folder, you would use:

```
cp *.txt ~/backup/
```

You can also copy entire directories by using the recursive option (-R). This will copy the directory and everything inside it:

```bash
cp -R folder/ destination_folder/
```

To rename a file, use the mv command. If you want to rename a file in the same directory, you specify the old name and new name:

```
mv oldname.txt newname.txt
```

To move a file from one place to another, use the mv command. For example, if you want to move itinerary.txt from the australia directory to the japan one, you would use:

```
mv australia/itinerary.txt ~/japan/
```

You can also move entire directories by using the recursive option (-R):

```bash
mv -R folder/ destination/
```

Be careful, as the mv command will overwrite existing files without asking. To prevent this, use the interactive option (-i), which prompts for confirmation:

```
mv -i file.txt destination
```

The mv command also has other useful options, such as -v (verbose), which shows you what is being done:

```
mv -v file.txt destination
```
