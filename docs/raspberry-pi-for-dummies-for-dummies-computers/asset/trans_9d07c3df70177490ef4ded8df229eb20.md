## 连接树莓派摄像头模块

树莓派有很多配件和扩展功能，但摄像头模块有一根排线插在树莓派上。摄像头模块是一个小型电路板，你可以见图 3-7。要打开树莓派上的摄像头接口，用大拇指和食指提起。这些部分不会分离，但它们会移开以出一个间隙。这就是你插入摄像头电缆的地方。

摄像头电缆的末端是银色连接器。让电缆的一侧面向左侧，远离 USB 插座侧。将电缆插入板上的插座中，然后将插座压回去。

## 连接 Pi Zero 摄像头

Pi Zero 使用不同的摄像头插座。要打开树莓派上的摄像头接口，用大拇指和食指拉起。这些部分不会分离，但它们会移开以出一个间隙。这就是你插入摄像头电缆的地方。

在树莓派上，摄像头接口位于右侧。将电缆的光触面向前方滑入，然后将插座压回去。在 Pi Zero 上，将电缆的光触面向板的底部（平坦侧）。当电缆是平的时，摄像头将向下，但你可以弯曲电缆使摄像头位于板的顶部并向上。官方 Zero 外壳的罩有一个摄像头孔。

## 准备你的 Pi Zero 或 Zero W

Pi Zero 型使用 Mini HDMI 和 Micro USB 插座。作为第一步，你需要插入转换器以便连接到标准的 HDMI 和 USB 设备。图 3-8 显示了 Micro-USB 转 USB 转换线和 Mini-HDMI 转 HDMI 转换器。

将 HDMI 转换器插入图 3-3 所示的 Mini HDMI 插座。USB 转换器插入图 3-3 所示的 Micro USB 插座，该插座在板上标记为 USB。使用这个时要小心，因为它也适合电源插座。
