# Adjusting the screen display

You can adjust the width and height of the screen display, measured in pixels. When the width and height values are smaller, the onscreen content appears bigger. The screen display is adjusted using the framebuffer_width and framebuffer_height. To change the screen display size to 1024×768, for example, use

```
framebuffer_width=1024
framebuffer_height=768
```

There is a concern for these settings in the config.txt file, you can edit the lines that are already there. As well as changing values to your chosen width and height, don't forget to remove the # symbol at the start of both lines to activate these settings.

These settings can also be adjusted from the desktop using the Raspberry Pi Configuration tool (see Chapter 3). Select Set Resolution.

# Exploring more advanced settings

There are many settings you can control on the Raspberry Pi through the config.txt file, but we don't have space to document them all. You can find a more detailed list at http://linux.org/RPI_config.txt.

# Fixing Audio Problems

In the desktop environment, you can use the Speaker icon in the top right to adjust the volume of sound and mute or unmute it. In the command line, you can call up a utility to adjust this sound:

```
sudo alsamixer
```

Use the cursor or the mouse scroll wheel to adjust the volume.

The sound output device is automatically detected. Note that if you're using HDMI to connect to a speaker, the audio be directed there by default, even if the monitor does not have speakers. You can use the audio options in Rasp-config (found under Advanced Options) to direct the audio to the headphone jack or the HDMI cable.
