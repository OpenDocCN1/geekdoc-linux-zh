Firstly (and especially if you have a Model A, B, or Zero), you're going to want to connect other devices to your Pi at the same time as your keyboard and mouse, which need two sockets. And secondly, a USB hub provides power to your devices and minimizes the likelihood of experiencing problems using your Raspberry Pi, especially if connecting relatively-intensive devices such as hard drives. Make sure your USB hub has its own power source, independent of the Raspberry Pi.

# USB keyboard and mouse: The Raspberry Pi only supports USB keyboards and mouse, if you're still using ones with PS/2 connectors (round rather than flat), you need to replace them.

When the Raspberry Pi behaves unpredictably, it can be because the board is drawing too much power, so avoid keyboards with too many flashing lights and features.

# MicroSD card or SD card: The Raspberry Pi doesn't have a hard drive built into it, so it uses a MicroSD card (current models) or SD card (older models, excluding the Model B+) as its. You probably have some SD cards that you use for your digital camera, although you might need to get a higher-capacity one. We recommend an 8GB card as a minimum, but you can use a 4GB card if you use a media center operating system (OS) like LibreELEC. (See Chapter 8 for a guide to LibreLEC.) Even that you might space the hard drive on a modern computer, but you can use other storage devices such as external hard drives with your Raspberry Pi, and MicroSD cards have different class numbers that indicate how fast you can copy information and from them. The Raspberry Pi Foundation recommends its branded Class 6 as a good value and high-performance solution, online retailers often sell a Class 10 for this purpose. You will be fine with a Class 6 or higher. The easiest way to get started with the Raspberry Pi is to buy a card with the NOOBOS already on it. (See Chapter 2 for more on NOOBOS.) Online retailers, including those mentioned for buying the Pi itself, sell a MicroSD card that has the NOOBOS software preloaded on it. It comes with an SD card adapter, shown in Figure 1-3, so it fits the older models (with the adapter) and newer models (without it).

# SD or MicroSD card writer: Many PCs have a slot for SD or MicroSD cards, so you can easily copy photos from your camera to your computer. If you doesn't, you might want to consider getting an SD or MicroSD card writer to connect to your computer. You can use it to copy to an SD card for use with your Raspberry Pi, but you won't be able to use it to copy files from your Raspberry Pi to a Windows computer. Alternatively, as we've said, you can buy a MicroSD card with an SD adapter that has the Raspberry Pi software already on it. You can also use the card writer to create a backup copy of your Raspberry Pi's files and software. (You can read about backups in Chapter 4.)
