# # Logging Out from PIXEL and Shutting Down

When you've finished using your Raspberry Pi, shut it before removing the power supply. The options to shut down or restart (reboot) your Pi are on the Applications menu, under Shutdown. You can also log out, which will prompt you to log in. The default username and password are *pi* and *raspberry*.

After your Pi has shut down, you can disconnect the power. When you reconnect it, your Pi will start up again.
