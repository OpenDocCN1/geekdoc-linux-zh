You can use lots of different options to still take photos, too. This example takes a shot with the pastel filter and flips the picture horizontally (-hf) and vertically (-vf):

```
raspberryill -ifx pastel -hf -vf -o testshot2.jpg
```

All those hyphens and letter combinations might seem a bit random to you now, but after you read Chapter 5, they should make more sense. To see the document-ration for raspberryill, type

```
raspberry 2&1 | less
```

Use the down-arrow key to move through the information, and press Q to finish.

Your photos are stored in your pi directory. See Chapter 4 for instructions on how to use File Manager to manage your files and Image Viewer to see them.

To shoot video, you use raspavid. Enter this command to shoot a 5-second film:

```
raspberry -o testvideo.h264 -t 5000
```

You can view the video you made using

```
omplayer testvideo.h264
```

The video footage is captured as a raw H264 video stream. For greater compatibility with media players, it's a good idea to convert it to an MP4 file. Start by installing-MP4box using this command:

```
sudo apt-get install mpac
```

Then you can convert your video file (called testvideo.h264) into an MP4 file (called testvideo.mp4) like this:

```
MP4Box -add testvideo.h264 testvideo.mp4
```

You can get help using raspberry with

```
raspberry 2&1 | less
```

There is also a library you can use in Python to access the camera from your own Python programs. For more information on using the Raspberry Pi Camera Module, see the documentation at www.raspberrypi.org/documentation/usage/camera.
