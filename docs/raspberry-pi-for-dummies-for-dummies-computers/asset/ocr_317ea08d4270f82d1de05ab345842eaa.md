# 4. Study this list to find the SD or MicroSD card.

In Figure 2-4, the screen lists disks, with the information about each
starting with the word Disk. The file size is usually a good indicator of which is
t SD card. The first one (Disk /dev/sda) is 500.1GB, which is a hard drive.
The second one (Disk /dev/sdb) is 7948MB. That's usually 8GB, so that's
t SD card. The card's partition name, which in this case is sdd1.

# 5. Find where the card is mounted.

Use the mount command and search for the directory where the card has been
mouted in the file system. In this case, the card's partition name is sdd1, so
entering the following:

```
mount | grep -i sdd1
```

Figure 2-4 shows the output from this, which tells you that the card is
mouted. In this case, it's mounted on /media/65EB-9564.
