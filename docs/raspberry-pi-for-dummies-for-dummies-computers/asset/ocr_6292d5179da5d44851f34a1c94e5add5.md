# Using Redirection to Create Files

Before you look at how you delete files and copy them, you should prepare some files to play with.

It's possible to send the results from a command to a file instead of the screen; in other words, redirect them. You could keep listing results in a file, for example, if you have a permanent record of them or so can analyze them using a text editor. You turn screen output into a file by using a greater-than sign and the filename you'd like to send the output to, this:

```
ls ~/listing.txt
```

![](bbox=[0.153, 0.327, 0.222, 0.393])

You don't need to have the file extension of .txt for it to work in Linux, but it's a useful reminder for yourself, and it helps if you copy the file back to a Windows machine.

Try using this command twice from different directories and looking at the contents of listing.txt with the less command. You will see just how unforgiving Linux is. The first time you run the command, the file listing.txt is created. The second time you do it, it's replaced without waiting. Linux trusts you to know what you're doing, so please be careful not to overwrite files.

![](bbox=[0.153, 0.407, 0.222, 0.483])

If you want a bit of variety, you can use other commands to display content onscreen:

+   >> echo: This displays whatever you write after it onscreen. You can use it to solve mathematics problems if you put them between two pairs of brackets (parentheses) and a dollar sign in front, for example:

```
echo $((5+5))
```

+   >> date: This shows the current time and date.

+   >> cal: This shows the month's calendar, with today highlighted. You can see the year's calendar using the option -y.

If you want to add something to the end of an existing file, you use two greater-than signs, so you can see this in this example:

```
@raspberrypi $ echo I made this file on ~ testfile.txt
@raspberrypi $ date >> testfile.txt
@raspberrypi $ cal >> testfile.txt
@raspberrypi $ echo $((20+31+5)) Days until my ₐbirthday! >> testfile.txt
```
