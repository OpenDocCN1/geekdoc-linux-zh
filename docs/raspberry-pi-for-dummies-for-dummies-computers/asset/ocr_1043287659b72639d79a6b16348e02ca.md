# 10. Update your software.

Assuming your Internet connection is working, you can update the operating system and other software on your Raspberry Pi (without overwriting any of your work files) using this Linux command (Chapter 5):

```
sudo apt-get update && sudo apt-get upgrade
```

# 11. Try a new power supply.

We've put this near the end of our steps list because it's probably hardest to do, although dodgy power has been reported to cause a wide range of different problems. If you have a friend with a Raspberry Pi and hers works fine, try using her power supply to see whether it fixes the issues you're seeing on yours. Alternatively, you might need to buy a new power supply. If you've upgraded your Pi but not more power than earlier models, you might experience problems. In the PIXEL desktop, a lightning bolt in the top right of the screen means the Pi is underpowered and a thermometer means it is over temperature. See Chapter 1 for advice on buying a power supply.

# 12. Check online for a solution.

It's not possible to cover every event, so if you're experiencing difficulties, check the rest of this appendix and then search the troubleshooting guide at linux.org/R-Pi_Troubleshooting, search the forums at www.raspberrypi.org, or search the web with Google or DuckDuckGo (www.duckduckgo.com) for a solution. You're highly likely to find that someone has already overcome any difficulties you encounter.

# Adjusting the Settings on Your Raspberry Pi

The settings that your Raspberry Pi uses are stored in files on the MicroSD or SD card, and many of them are in a file called config.txt that's in the /boot directory. You can edit this file directly to change your computer's settings using a simple text editor Nano which is preinstalled on your Raspberry Pi.

You might not need to adjust the settings manually. Try using the PIXEL desktop (Chapter 3) or running the Raspi-config program, which gives you a menu for changing some of the most frequently used options, including some that are not included in the desktop tool. You can run the program at any time using the following command in the shell:

![](bbox=[0.165, 0.781, 0.235, 0.853])

```
sudo raspi-config
```
