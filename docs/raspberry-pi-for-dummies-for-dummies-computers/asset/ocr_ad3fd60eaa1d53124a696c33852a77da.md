If you delete a sound in this way, it remains on your SD card so that you can import it again later.

After a sound has been imported, you use one of the Sound blocks to play a sound. To see all available Sound blocks, click the Sound button at the top of the Blocks Palette first.

The Play Sound block enables you to choose which sound you'd like to play from those you have imported. The Play Sound Done block stops the program from running any blocks joined underneath this one until the sound has finished playing.

> REMEMBER
The sound is imported to a particular sprite, so if you can't see it as one of the choices in the Play Sound block, be sure you've imported it to the correct sprite. In Chapter 10, we cover how to use multiple sprites in a project.
