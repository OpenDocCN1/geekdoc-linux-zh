You've stored the list of cells visited deserves some explanation. You've put the xposition and zposition in parentheses which are used to indicate a tuple. A tuple is a data sequence, like a list, but with a key difference that you can't change values (it's immutable). So cellsVisitedList is a list that contains tuples, which in turn contain pairs of x and z coordinates. You can use the Python shell to take a look inside this list.
