| Option | Description |
| --- | --- |
| -1 | Outputs the results in a single column instead of a row. Note that this option is a number 1 and not a letter l. |
| -a | Displays all files, including hidden files. The names of hidden files start with a single period (.). Hidden files are usually put there (and required) by the operating system, so they're best left alone. You can create your own hidden files using filenames that start with a period. |
| -F | Adds a symbol to indicate its type. When you use this option, directories have / after their names, and executables have a + after their names. |
| -h | In the long format, expresses file sizes using kilobytes, megabytes, and gigabytes to save you the mental arithmetic of working them out. It's human-readable. |
| -l | Displays results in the long format, which shows information about the permissions of files, when they were last modified, and size. Note that this option uses a letter l, short for long. |
| -m | Lists the results as list separated by commas. |
| -R | The recursive option; as lists files and directories in the current directory, opens any subdirectories and lists their results too too, working its way down the directory tree. You can look at all the files on your Raspberry Pi using ls -R from the root. It takes a while. To cancel when you get bored, use Ctrl+C. |
