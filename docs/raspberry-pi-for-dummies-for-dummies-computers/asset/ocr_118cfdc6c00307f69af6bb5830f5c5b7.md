The photo booth was triggered when somebody tweeted the booth to say what color she was wearing. The composite photo, a single image that showed all three angles, was tweeted back to her. The tweet also included a response that was appropriate for the color she said she was wearing if it was one of the hundred recognized color names (although the developers said they later found that a Raspberry Pi could have done this job, too). The controller ran in Python that listened for tweets, told the Raspberry Pis to capture images and send them to it, and then created the composite image. The controller connected to the Raspberry Pi using Secure Shell (SSH), so it could control them remotely and access their image data.
