Table 2.4 Keywords and Their Corresponding Options to Use in the Configuration File for LILO

| Keyword | Option |
|---|---|
| -b bootdev | boot=bootdev |
| -c | compact |
| -d ceciseconds | delay=dsec |
| -D label | default=label |
| -i filename | install=bootsector |
| -f filename | disktab=file |
| -l | linear |
| -m filename | map=mapi file |
| -P fix | fix-table |
| -P ignore | ignore-table |
| -s filename | backup=file |
| -S filename | force-backup=file |
| -v | verbose=level |

The default configuration file for LILO is /etc/lilo.conf. A sample lilo.conf file is

```
boot=/dev/hda the partition that you will boot from
map=/boot/map the mapping file to use
install=/boot/boot.b the boot sector file
prompt display a prompt
timeout=50 How long to wait before staring the default
image=/boot/vmlinuz-2.0.36-0.7 The name of the kernel to start
label=linux the label or name you assigned
root=/dev/hda1 the partition to mount as root
```

You can pass configuration parameters to the kernel, such as append, ramdisks, read-only, read-write, root, and vga, in the options section for each operating system listed. So, if you have an operating system that you boot to troubleshoot, you could create a ramdisk and load everything there. You also could make a filesystem read-only when booting.

If you modify your configuration file, you will need to write it to the boot sector of the hard disk. After you have completed your changes, issue the command

```
/sbin/lilo
```
