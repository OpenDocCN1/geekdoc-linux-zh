To install LILO, simply call it without any options. The options that can be used with LILO are listed in Table 2.3.

Table 2.3  Options That Can Be Used with LILO
| **Option** | **Action** |
| :--- | :--- |
| `-b bootdev` | Specifies boot device |
| `-C filename` | Use specified configuration file |
| `-c` | Speeds boot by merging reads from adjacent sectors |
| `-D label` | Use kernel with given label as default |
| `-D deciseconds` | Indicates how long to wait for selection |
| `-f filename` | Specifies disk parameter file; default is `/etc/disktab` |
| `-I` | Asks for path to kernel |
| `-i filename` | Identifies file to be used as boot sector; default is `/boot/boot.b` |
| `-L` | Generates linear sector addresses |
| `-m filename` | Uses specified map file instead of default |
| `-P [fix|ignore]` | Fixes or ignores corrupted partition tables |
| `-q` | Lists the names and locations of kernel(s) to boot from the `/boot/map` file |
| `-R command` | Sets default for next reboot |
| `-r directory` | Changes root before anything else; used for troubleshooting |
| `-S filename` | Overwrites existing file |
| `-s filename` | Specifies where to store old boot sector; if used with `-u` specifies boot sector to restore |
| `-t` | Tests your configuration without installing |
| `-u` or `-U` | Uninstalls LILO |
| `-v` | Causes LILO to display information; multiple `-v`s can be used to increase the amount of information displayed |
