The case structure is used to create menus. The following is an example of a simple menu:

```
$ cat <magic-menu>
#!/bin/sh
# menu commands
echo '\n MAGIC MENU \n'
echo ' a. Current date and time'
echo ' b. Department number'
echo ' c. Department name'
echo ' d. Department Budget'
echo 'Enter a, b, c, or d: \c'
read answer
echo
case '$answerc'in
a) date ;;
b) dnum ;;
c) dname ;;
d) dbud ;;
\*) echo 'Nothing selected: $answer' ;;
esac
$ magic-menu

MAGIC MENU

a. Current date and time
b. Department number
c. Department name
d. Department budget
Enter a, b, c, or d: a
Fri Feb 05 12:17:07 EST 2001
```
