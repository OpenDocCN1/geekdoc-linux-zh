**TABLE 16.3: THE vi NAVIGATION KEYSTROKES (CONTINUED)**

| Keystroke | Action |
| :--- | :--- |
| tx | Move to the character just before the next *x*. |
| W | Go forward one space-delimited word. |
| w | Go forward one word. |
| Zero (0) | Go to the beginning of the current line. |
