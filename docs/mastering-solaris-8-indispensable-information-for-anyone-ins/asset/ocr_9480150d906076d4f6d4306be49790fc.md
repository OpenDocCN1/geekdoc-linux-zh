After you enter your server name, login name, and password, the main Mailer window, shown in Figure 13.3, appears. This is the window in which you can read mail, compose mail, and perform all the other mail-related tasks that will be covered in this chapter. At the top of the window is a menu bar with Mailbox, Message, Compose, View, Options, Move, and Help menus (the options on these menu will be covered later in this chapter).
