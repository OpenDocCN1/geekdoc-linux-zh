The Open Systems Interconnection (OSI) reference model provides a conceptual framework for the communication that takes place between computers. As was presented in Chapter 9, the OSI is composed of seven layers, each specifying different specific network functions. The model divides the steps involved in moving information between networked computers into smaller, manageable tasks. Because each layer is fairly self-contained, each task can be implemented independently, enabling the solutions offered by one layer to be updated without affecting the other layers.

Each layer uses various forms of control information to communicate with its peers in other computer systems. This may include specific requests and instructions exchanged between peer OSI layers. Control information has two forms: headers and trailers. Headers are prepended to data coming down from upper layers. Trailers are appended to data that has come down from upper layers. Although the data requires neither a header nor a trailer, they may appear depending upon the layer that analyses the information unit. The data portion of an information unit at any OSI layer can potentially contain headers, trailers, and data from higher layers. This is known as encapsulation.
