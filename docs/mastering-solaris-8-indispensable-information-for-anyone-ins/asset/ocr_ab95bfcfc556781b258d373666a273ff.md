**Replace command** The Replace command deletes any characters you over-
write and inserts the new characters you enter.

The `vi` editor is a superset of the `ex` editor, and it is possible to return to the `ex` Command mode and the `ex` Input mode from `vi` and vice versa, but it isn't something you are likely to want to do because `vi` offers you expanded capabilities that most people miss in the `ex` editor.

> **TIP** If you are confused about what mode you are in, press the `Esc` key twice to return to the Command mode (pressing the `Esc` key twice ensures that you will be in the Command mode from wherever you are). You can also use the `:set showmode` command to have `vi` display the current mode on the status line (last line).

Therefore, `vi` offers you the following six modes:

+   - `vi` Command mode
+   - `ex` Command mode
+   - `vi` Entry or Input mode
+   - `ex` Input mode
+   - `vi` Last-Line mode
+   - `vi` Shell Escape mode

There are several commands that you can use to summon the `vi` editor:

```
/usr/bin/vi <options> <files>

```
```

```

vi <options> <files>
```
```
