Many of these tasks can be done inside the Solaris Print Manager for network printers or the AdminTool for local printers, as you will see in the following sections. Currently, the Print Manager does not support printer classes or fault recovery; you need to use the \texttt{lpadmin} command for those settings. You will also find that, although you can use the Print Manager to specify the file contents, fault notification, banner pages, and access to a printer, the \texttt{lpadmin} command has better functionality in these areas.

The printer name must be a unique name in your domain, and it can contain up to 14 alphanumerical characters. The description is a comment field that helps people locate a printer or understand the printer type.

When you add a printer to your computer, you specify the device or printer port that the printer is attached to. You can set the printer port in the Print Manager or by using the \texttt{lpadmin} command. Typically, a system comes with two serial ports (\texttt{/dev/term/a} and \texttt{/dev/term/b}) and one parallel port. You can use any recognized port name. On an IA system, only the first port is enabled. Any other port is disabled by default. To use another port on an IA x86 system, you must edit the two port configuration files at \texttt{/platform/i86pc/kernel/drv/any\_conf} and \texttt{/platform/i86pc/kernel/1p\_conf}.

The \texttt{lpadmin -T} command is best used for establishing printer types. The printer type is a generic name for a type of printer, most often associated with the vendor who manufactures the printer. A DECWriter printer is specified as \texttt{decwriter}. PostScript printers include Apple LaserWriter printers of various types. Information about printer types may be found in the \texttt{terminfo} database (\texttt{/usr/share/lib/terminfo}, shown in Figure 10.4). If you use the \texttt{ls} command to view that database's directory, you will see a number of single-number-\&letter entries. Each single-letter entry is a subdirectory containing a number of files relating to a specific vendor's files. For example, the \texttt{e} subdirectory contains Epson printer files and the \texttt{n} directory contains NEC printer files. When possible, try to use the PostScript printer type if your printer supports it, even if you find a system file type. You can assign more than one printer type to a printer using the \texttt{lpadmin -t} option.

The second useful assignment that you should use is \texttt{lpadmin} command for is the file content type. A print filter converts the content type of a file to a content type that a printer can accept.
