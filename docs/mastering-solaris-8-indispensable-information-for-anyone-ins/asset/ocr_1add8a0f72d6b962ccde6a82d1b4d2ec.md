Select the window type from the pop-up menu: the default, Graphical (X-Window), runs an application in its own window; Terminal (Auto-Close) runs an application in a terminal window and the window closes as soon as the application completes its action; and Terminal (Manual Close) runs an application in a terminal window and requires a user to give an **exit** command to close the application.
