+   - The Korn shell does not allow arithmetric expansion if the argument is enclosed within single quotation marks.
+   - If you have not set the noglob option, the Korn shell uses patterns to generate filenames for use as arguments to the command. If no filenames match the pattern, the shell displays an error message.
+   - The Korn shell removes all single and double quotation marks except for escaped quotation marks and ones that are the result of expanding variables.
