# The *until* Structure

The until structure is similar to the while structure in that until continues to loop until the `<test-com>` returns a true condition. The while structure loops while the `<test-com>` continues to return a true condition. If the results are false, then control will pass to the do commands. Figure 18.5 shows an until flowchart, and the following example demonstrates the syntax for the until structure:

```
until <test-com>
do
	commands
done
```
