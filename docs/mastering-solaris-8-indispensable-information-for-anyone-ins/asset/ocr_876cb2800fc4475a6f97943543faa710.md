# Downloading Files

Giving you the ability to download files is an important function of a browser like Netscape. You can download files from either FTP or HTML sites. To download a file, follow these steps:

+   1. Enter an FTP address in the Goto Field of the Location toolbar and press the Return key.
+   2. When the initial set of directories is displayed, click one you wish to download.
+   3. Netscape will open a window asking you where to put the file on your system. Give it an address such as /tmp or /var/tmp.
+   4. Change the Selection window so that the file is stored in /var/tmp.
+   5. Click OK.

While downloading, Netscape will display a Download window that shows you the progress of the file transfer. Once the Download window closes, the file is ready for you to view. Exit from Netscape or choose another window.

The file you download is archived with tar and compressed with the gzip, as indicated by the .tgz or tar.gz filename extension. To open the archive, follow these steps:

+   1. Use cd to change to the /var/tmp directory.
+   2. Set the umask so that file permissions are correct.
