The value of the first argument is given to the `loop-var` and executes the commands between the `do` and `done` statements. The `do` and `done` mark the beginning and end of the `for` loop. After passing control to the `done` statement, the structure assigns the value of the second argument in the `args-list` to the `loop-index` and repeats the commands. It will repeat the commands between the `do` and `done` statements for each argument on the `<args-list>`.

The following example displays the sequence initiated by the `for..in` control structure:

```
```
$ cat dogs
for dogs in schnauser poodle dachshund spaniel
do
    echo "$dogs"
done
echo 'Finished.'
$ dogs
schnauser
