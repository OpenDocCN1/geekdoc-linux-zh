# The case Structure

The case structure looks for strings of characters (stringsearch) that the user enters after a prompt. This is a sophisticated command that makes multiple decisions before executing other commands. This structure is used in creating menus because it relies upon user input. The following example demonstrates how case works:

```
$ cat testpattern
echo 'Enter YES, NO or MAYBE: \c'
read answer
case "$answer" in
        'YES')
                echo 'You answered YES'
                ;;
        'NO')
                echo 'You answered NO'
                ;;
        'MAYBE')
                echo 'You answered MAYBE'
                ;;
        *)
                echo 'You did not answer YES, NO or MAYBE'
                ;;
esac
$ testpattern
Enter YES, NO, or MAYBE:  NO
You entered NO
$ testpattern
Enter YES, NO, or MAYBE:  no
You did not enter YES, NO, or MAYBE
```
