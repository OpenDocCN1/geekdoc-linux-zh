Both of these dialog boxes have two methods of operation. You can enter search
criteria and search your current e-mail or you can save the search criteria as a view for
repeated future use. You can use the Search Down and Search Up buttons to search
the current set of e-mail messages. When a match is found, the message header is
highlighted.
