<servername> is the name of the server storing the site initialization file (<sitemefileinit-name>) in the directory <sitefileinitdirectory> reserved for these files. For a C Shell user account, that line would be as follows:

```
sourcenet/<servername>/export/<sitefileinitdirectory>/<sitefileinitname>
```
