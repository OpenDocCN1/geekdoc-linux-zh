# Managing Network Users with AdminSuite

With AdminSuite 3 you can add, modify, and delete user accounts on a network. Using the User Accounts window, you can select a domain to modify and even add or delete domains. You can also view the attributes of an account and assign attributes within AdminSuite. Additionally, you can set up security policies and assign to users superuser rights that allow them to make changes to other user accounts from within AdminSuite.
