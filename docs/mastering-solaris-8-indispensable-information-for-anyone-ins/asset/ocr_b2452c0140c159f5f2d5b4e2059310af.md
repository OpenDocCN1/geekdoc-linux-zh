Device directories contain files related to devices on the system. They are stored in /dev and /devices. The /dev directory in Solaris 8 contains a set of links from the files in /devices, which was an older version of the directory used by Unix. Your directory tree will also contain directories for a CD-ROM drive or a floppy drive. These are automatically mounted when you insert a CD or disk into the appropriate drive. Most removable media comes with software that allows this automatic mount. Table 2.3 lists some important directories in /dev.

TABLE 2.3: DIRECTORIES IN /dev  
| Directory | Purpose |
| --- | --- |
| /dev/cua | Accesses devices connected to serial ports of workstation |
| /dev/dsk | Accesses file systems on hard drives, used with mount |
| /dev/fd | Accesses particular file descriptors such as STDIN, standard input |
| /dev/pts | Allows logins on pseudo-terminals via telnet, remote shell, and so on |
| /dev/rdsk | Accesses the raw media of hard drives, used with fsck command |
