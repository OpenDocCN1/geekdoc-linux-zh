# I/O Architecture

Unix employed kernel resident device drivers to interface with hardware. A device driver manages the transfer of data and register input and output as well as device hardware interrupts. The driver knows all the details of the device as well as the layout of buses to which the device is connected. Solaris takes this a step further by using separate drivers for devices and a bus nexus driver for different buses. Figure 2.9 illustrates a typical Solaris device tree. Each bus connects to another bus through a bus nexus.
