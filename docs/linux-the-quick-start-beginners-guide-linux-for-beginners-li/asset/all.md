Introduction

What is Linux?

                            Linux is a free and open-source              OS kernel used around the world for many purposes.  The kernel facilitates full-fledged operating systems that are free and open source by giving software a way to interact with the hardware in our devices.  Linux is both widespread and prevalent in the computing world- there is a good chance that if you reach in your pocket you’ll find a Linux machine right now (smartphones!).  Operating systems using Linux can be found running most of the world’s super computers, and Linux is even used by many government agencies. It is found everywhere from the New York Stock Exchange to the Sony PlayStation. 

Does this mean that Linux is only for big-wigs and expensive supercomputers?  Absolutely not, because Linux can easily be used to write papers, browse the internet, watch YouTube, or check email.  Linux operating systems are free, so they are a fantastic alternative to the expensive Windows and Apple operating systems.  There are many different distributions of Linux, often referred to as “distros” that are specialized to suit differing needs.  This book will go through some history, various distributions, and a few uses of Linux-based operating systems. Overall it is highly recommended that everyone learn at least a little bit about Linux, because it is used in so many places.

Linux vs. Windows

An operating system (OS) is the backbone of a computer, and without one a computer is nearly useless.  Normally a computer will run an OS such as Windows, but computer users are free to install any OS that can run on their hardware.  While we are all familiar with how Windows computers work, taking the plunge and installing Linux offers many benefits.  Besides being free, Linux is more secure, more reliable, and more open.             

Windows machines are plagued with viruses.  Antivirus applications are expensive and can slow down even the strongest Windows PCs.  Linux is such a secure OS, and it extremely difficult to contract a virus.  Fortune 500 companies choose to run their computers with Linux because of the enhanced security and unparalleled reliability.  Anybody suffering from virus and malware problems should surely consider giving Linux a try.

Linux is fast, even on the oldest computers.  An old device running Windows XP might be useless currently, but installing Linux breathes a new breath of life into dying technology.  Some distributions are made specifically to be lightweight and responsive, which can extend the useful life of a computer by many years.

The kernel and software that comes with Linux operating systems are free and open source, and FOSS applications offer nearly identical functionality compared to their expensive counterparts.  For example, Adobe Photoshop costs upwards of $500, but Linux’s free alternative “GIMP” is free. Even Microsoft Windows 10 costs about $120, but the most popular Linux distro, Ubuntu, costs absolutely nothing.  For every paid component of a Windows PC there is a free Linux equivalent. Even the method of downloading new programs is improved in Linux.  On a Windows PC a user must navigate a website and potentially download Trojan horse viruses to retrieve new software, but on Linux there are secure and safe repositories that download software with ease.   

Compatibility remains high with Linux systems, for you can install Linux on a wide range of devices.  Whether it is a brand new computer, an old dinosaur, or a laptop and tablet, Linux is compatible.   Compare that to Apple’s OSX, which can only run on iMacs, or Windows 10, which can only run on newer computers.  Some tech geeks have even managed to install Linux in cars and internet-enabled coffee pots! What this means is that you will never have to worry if your device is compatible, or if you need to buy a new computer.  So long as the device still turns on there is a large chance that Linux will run on it.

Many people choose Android over iOS for deep customization.  The same holds for choosing Linux over Windows, because Linux offers entire software freedom- many distros are made for the tinkerer and customizer. In Windows you can change your wallpaper and color scheme, but the personalization ends there.  Compare that to Linux, which allows you to completely switch to a text-only interface if you so choose.  In addition to colors and placement, Linux allows the user to add and remove components at will, creating a unique environment for every user.

When it comes down to it, Linux prevails over Windows in almost every category.  Linux is free, secure, open, transparent, customizable, and stable.  Although not every computer user is used to Linux-based operating systems, they will definitely benefit by switching away from Windows. Bricked devices, slow and antiquated computers, and virus infested machines can all be saved by installing Linux.  If the possibility of a brand-new computing experience piques interest, continue reading to find out all about how Linux works and how to get a copy installed on your personal computer.

Background

There is a lot of information surrounding Linux, its creation, and the contributing parties. Additionally there are a few parts of Linux that are interesting and unique.  This chapter will discuss the roots of Linux and how it became the de facto alternative operating system.

Some History on Linux

              On August 25th, 1991 in Finland, Helsinki, Linux was conceived. The then twenty one year old Finnish Student Linus Benedict Torvalds publicly announced the creation of the Linux kernel in a Usenet post to the newsgroup titled “comp.os.minix.”  Minix was a currently existing kernel that Linux became based off of, and the pedigree of both can be traced to an older operating system known as UNIX.  The post referred to Torvalds’s project as a hobby and small scale endeavor that would not carry much weight in the computing world and might not even be compatible with all computers. 

              The humble and relatively quiet beginnings were a precursor to the industry giant that Linux would become. The kernel grew from a hobby project into a usable product in a short amount of time and in 1993 a large team of 100 volunteers contributed to the project. Later, Linux was fused with Richard Stallman’s GNU core libraries to create the full kernel version 1.0.  Linus Torvalds initially intended for his project to be named “Freax”, but one of Torvalds’ coworkers at Helsinki University actually changed the name to Linux secretly and Linus later agreed to it.  It is with version 1.0 that Linux became usable as an operating system.  3rd parties then added software suites and additional functionality on top of the Linux kernel to create “distributions”, the oldest being Slackware and Debian.

Throughout 1995 the kernel was expanded and ported to a multitude of platforms, increasing the outreach of Linus and his kernel.  1996 saw additional improvements such as multiprocessing, which strengthened Linux’s use in corporate and university environments.    The early 2000s were marked by rapid improvement of Linux and a huge increase in the number of distros available.  Major companies such as Dell and HP partnered with distributions and offered consumers a choice of operating system upon purchase.  Linux became an industry powerhouse in this time period by offering an alternative OS for servers and clients that focused on performance and stability rather than features and aesthetics.  Today Linux is known for its widespread use in smartphones, desktops, and servers, and it was only able to reach this point through the dedicated work of Linus Torvalds and the numerous volunteers that contributed to the project.

Free and Open Source Software

              Linux is a shining example of open source and free software.  Also called FOSS, free and open source software are programs that exhibit certain characteristics and philosophies of ethical development.  Free software certainly means monetarily free, but in this case it also means that the programs have “freedom”.  “Free” programs are applications that can be run, distributed, changed, and copied freely and without consequence.  Opposed to this are paid programs such as Photoshop; there is a serious penalty for copying Photoshop and giving it to a friend.  Open source software refers to the transparency of a program’s code.  If the source code can be viewed then that program is open source. Source code that is hidden and inaccessible is closed source.  Open source code promotes truthfulness and trust while closed source code is an analogy for hidden and shady practices.  FOSS combines the ideals of both free software and open source coding to supply applications that are truly free and developed transparently.  Even the text of this document, “Liberation Serif”, is a free font commonly available in FOSS Linux applications.

Linux remains a particularly excellent example of FOSS because of the community-driven nature of Linux development.  Absolutely anybody at any time can view the source code of Linux and propose changes.  Multiple varied distributions of the OS exist because any individual can use the Linux code as a core for their own operating system.  Certainly the omnipresence of the free and open source philosophy has helped Linux throughout its development.

GNU

              GNU is the name of both an operating system and its extensive collection of FOSS.  GNU funnily enough stands for “GNU is not UNIX”, explaining that GNU is a UNIX-Like operating system containing no UNIX code.  Computer guru Richard Stallman created GNU in the mid 1980’s well before Linux was ever conceived as a “free” alternative to UNIX. GNU remained a niche product until Linus Torvalds fused core utilities of GNU into the Linux kernel.  Honestly a large part of Linux-based operating systems is actually GNU code, but Richard Stallman rarely receives his credit for contribution.  It is because of this that the kernel is sometimes written as GNU/Linux instead of just Linux.  Torvalds recognizes the large part that GNU plays in his kernel but also believes that without a kernel GNU is useless.  The clashing personalities of the two industry giants Torvalds and Stallman has led to a few heated arguments, but ultimately both men created separate products that work well together to facilitate computer operating systems.  Whether the name is pronounced Linux of GNU/Linux is up to the user, but each individual OS is usually called by the distribution name anyways!

Tux the Penguin

              Tux is the mascot of the Linux kernel.  His name is synonymous with Linux and the two ideas are often seen together.  Created by Larry Ewing in 1996, Tux was created to win a place as Linux’s logo.  The penguin did not win, however; rather he was liked enough that he never really went away, so instead of a logo Tux became the mascot. FOSS has a part in Tux, as he was drawn using the popular FOSS image software GIMP. 

              Linus speaks of the origins of the penguin character as coming from a trip he took to Australia that was uniquely marked by penguins.  A joke obviously, Larry Ewing spun the story into an inside joke that caught on very well.

Tux has had cameo appearances in other mediums as well, but the mascot can mostly be seen destroying Windows computers or poking fun at closed source and proprietary software. 

Who uses Linux?

 So after reading all about where Linux came from and where it is headed one might wonder what the typical Linux user looks like.  A wide variety of individuals enjoy Linux-based operating systems, and each has their own reason for choosing it.  Whether you are a tinkerer that enjoys customization, a business owner wishing to save on computer costs, or a system administrator looking for a new server OS, Linux is a flexible and malleable operating system.  The kernel itself is simple and stable, and the huge amount of distributions guarantee there is a special experience for every need.  Read on to the next chapter to learn about distributions and how they can suit your needs.

Choosing a Distribution of Linux

Distros are operating systems that take the Linux Kernel and provide preinstalled applications and services for an all-inclusive computing environment.  The vast amount of distributions is mind-boggling, but each can provide a unique and custom experience for the user.  Finding a distro that fits your needs might nudge you to install one yourself and try it out on your computer. Here are the most notable.

              Ubuntu is probably the most famous Linux-based OS.  Based on Debian, Ubuntu is described as “Linux for Humans”. The popularity of Ubuntu came about through ease-of-use, as it is much more intuitive than Debian.  The name Ubuntu, literally meaning “humanness”, comes from a South African philosophy of the same name.  Ubuntu is developed by Canonical Ltd, a company in the United Kingdom owned by Mark Shuttleworth.  Canonical supports itself financially by selling technical support for Ubuntu and technical support for other projects as well.  Ubuntu remains free and open-source, despite being developed by a proprietary company.  Beginning from the first release in 2004, Ubuntu is updated every six months. Every two years there is an Ubuntu LTS (long term support), which is an update that offers long-term support by Canonical.  Ubuntu by default contains software such as LibreOffice, Firefox, and Transmission.  New software can be installed with Ubuntu Software Center, a program specifically built for installing additional software on Ubuntu.  This is very advantageous for user new to Linux, because it is so easy to use.  Like Debian, Ubuntu and its software are released using the FOSS-friendly GNU license, so all of its default software is free and open-source.  Debian and Ubuntu also share the deb package format and thus can use the same software.  Ultimately, Ubuntu is the perfect OS for beginners to Linux, so starting off with Ubuntu is a great choice. 

              There are various Ubuntu “flavors” which retain the core software and functionality behind Ubuntu but add a unique specialization that makes them useful.  For example, Lubuntu is “lightweight Ubuntu”, an OS that keeps the beginner-friendly software of Ubuntu but strips the extra effects so it can run on slower hardware.  Xubuntu is another “lightweight Ubuntu”, but Xu is more focused on useful functionality rather than having speed as the only priority.  Ubuntu Studio is a flavor for content creators, as the OS comes with audio and visual editing tools preinstalled.  Ubuntu aims to be an Ubuntu variant designed for educational purposes.  Kubuntu takes the popular KDE interface to create an experience that is friendly and highly customizable.  Mythbuntu is built for media streaming and live television watching.  There are numerous Ubuntu variants available on the internet, and they are great for Linux newbies to experiment with as their “2nd Linux OS” because they combine Linux customization and experimentation with the relative “safety” and “familiarity” of Ubuntu.

              Slackware is a Linux distro created in 1993 by Patrick Vokerding based off of the Softlanding Linux System.  Slackware’s goal is to be designed to be stable, simplistic, and the most “UNIX-like” Linux distro.  Slackware has no graphical installation method and no automatic dependency of software packages.  It also does not come with a graphical user interface and boots to a text-only command line interface instead - Slackware is most suited for experienced Linux users because of this.  Slackware was started as a private side project with no serious commitment, as the name implies.  After the operating system became popular, however, the name was still kept.  The OS is a good choice for Linux veterans and those that want to experience the roots of Linux. 

              Fedora is a community developed operating system sponsored by Red Hat enterprises and based on the Linux kernel.  Linux has previously developed and maintained the Fedora Project as well.  Linus Torvalds regularly uses Fedora, mostly because of the “bleeding edge” nature of it and how well it can developed upon.  The goal of the Fedora Project is to make Fedora the most cutting edge operating system, so don’t try installing it unless you wish to develop for Linux or like a challenge.

Debian is a distro composed entirely of FOSS, mostly under the GNU General Public License.  1993 saw the first release of Debian by its creator Ian Murdock.  Debian is maintained and packaged by the volunteer Internet group, the Debian Project.  It was developed in the same spirit of the GNU Project and gained the support of the Free Software Foundation from November of 1994 to November of 1995.  After the end of the Free Software Foundations sponsorship, the Debian Project created the non-profit organization called “Software in the Public Interest” to help other organizations distribute and create free and open-source hardware and software.  Debian’s claim to fame is stability, as it has been around for quite some time and can offer a computing experience mostly free of bugs and crashing.  The OS has been used as a base and starting point for other operating systems, such as Ubuntu and Knoppix.  There are three versions of Debian: Testing, Unstable, and Stable.  Debian Testing and Debian Unstable are rolling release, meaning they are continuously updated.  New packages are loaded to Debian Unstable, and are tested in Debian Testing.  When these software packages are stable enough, the Debian Testing becomes the New Debian Stable.  The Debian software repositories contain over 50,000 software packages.  The official repositories contain only free and open-source software, but non-free software can be downloaded as well.  Richard Stallman, founder of the Free Software Foundation criticized the Debian Project for also using a non-free repository, but in 2004 the Debian Project decided to continue hosting the non-free repository by a majority vote.  The free and open-source spirit of the Debian Project has posed a challenge for multimedia support, because of the proprietary nature of video and audio codecs.  Overall, Debian offers the stereotypical Linux experience – stable, fast, FOSS, and reliable.  Consider trying out Debian if you are interested.

              A very popular distro with a cult following is called Gentoo.  Unlike a binary software package distribution system, Gentoo’s software must be compiled specifically for the user’s device. Compiling software is a long and difficult process, but compiling specific to the device gives Gentoo unmatched speed and stability for advanced users. The significant increase in speed in the OS is a reference to the Gentoo penguin- the fastest known swimming penguin.  Gentoo Linux is appealing to Linux users who want full and entire control of the software they run with a customized experience, so reflect on this when choosing which OS you want to try out.  The large difficulty curve in using Gentoo often wards off beginners and leaves the cleverest Linux users.

              Android is a mobile OS developed by Google for portable devices.  The popular cell-phone operating system was initially developed by an independent team but it was bought by Google in 2005.    Android has a huge market share on mobile phones, as most have either an Android or an iPhone in their pocket right now.  Android has great ARM (a type of processor) support and can run millions of “apps” from Google’s “Play Store”.  While you might not typically install Android on a desktop machine, it has plenty of uses on smaller computers and older devices with limited resources. 

              Tiny Core Linux is a very minimal Linux kernel based operating system.  It has limited (or virtually no) preinstalled programs, but it can serve as an installation of Linux for the oldest and slowest computers.  The entire operating system is between eleven and sixteen megabytes, so installing it on a thumb drive or SD card is very possible.  This OS is best installed by intermediate Linux users that wish to create the most lightweight operating system possible from scratch. 

              Chrome OS is an operating system developed by Google, and- like Android- , it is based on the Linux kernel.  The project was announced by Google in July of the year 2009.  It is designed for both user data and applications to run in “the cloud” rather than from the computer’s RAM.  The very first Chrome OS laptop, called Chromebook, was released in May of the year 2011.  Chrome OS is designed to be connected to the internet for running only simple applications and web browsing.  Although features such as an integrated media player and integrated file manager exist, most of the applications are actually just websites owned by Google. This allows computers with lower specifications to be made very cheaply for Chrome OS, making it suitable for low-spec devices.  Chrome OS is popular among college students, the non-tech savvy buyer, and budget computers, and it is a very popular operating system.  You may not actually be able to install Chrome OS on a computer, but you can certainly install the open-source equivalent – Chromium OS.  Chromium is recommended for low-spec laptops whose only purpose is web browsing and other common internet tasks. 

              Arch Linux is a Linux kernel based computer operating system based on the IA-32 and x86/64 architectures.  It is composed mainly of free and open source software, and Arch is mostly known for the huge amount of customization that it can provide.  Arch Linux is supported by community involvement, which makes it relatively easy to obtain support for.  Arch Linux is designed with the KISS principle meaning Keep It Simple Stupid.  While the code design is simple in nature, actually using the OS is fairly difficult.  Arch comes with no graphical user interface, or any specific applications at all.  The user is expected to “build” the entire system piece by piece to their own liking.  Through learning what to install and how, the user eventually gains a deep understanding of distributions and Linux in general, which is why Arch is recommended for users wishing to learn more about Linux.  While it is not recommended as a first distribution, every person interested in Linux should build their own unique version of Arch at some point to further their knowledge.

              CrunchBang (#!) Linux is a Linux kernel based computer operating system based off of Debian.  The developer Phillip Newborough designed CrunchBang Linux to use far less system resources than Debian, making it much more lightweight and flexible.  CrunchBang Linux has its own repository of software, but got the majority of its packages from the Debian repositories.  In 2013 Jim Lynch (a popular reviewer) described CrunchBang as being functional, efficient, and capable of running effectively on both older hardware and newer machines.  It is true that CrunchBang avoids a bogged-down experience by giving preference to usibility and speed, which makes it an attractive distro choice for the intermediate Linux user wishing for a no-nonsense sophistication.

              Damn Small Linux (DSL) is a Linux kernel based computer operating system developed with an extreme minimalism design philosophy in mind.  Damn Small Linux is free and open source, available under the GNU GPL.  DSL was originally conceived and maintained by the developer John Andrews as a project to determine just how much could fit onto 50mb.  DSL is actually very usable straight out of the box, and it is best suited to users that need quick access to Linux tools.  It is because of this that DSL is best kept on a USB drive that can be booted form any computer. 

              Red Star OS is an interesting case in the Linux world.  It is a North Korean operating system used by residents of the communist country.  Development on Red Star began in the year 1998 at the Korea Computer Center.  Before Red Star, computers in North Korea typically ran Ubuntu.  Since North Korea wishes to maintain control over internet resources and citizen’s access, only a tiny amount of state government officials and important tourists are allowed access to the Internet.  These people would be using Red Star OS, and the government’s control of the OS gives them extra control over the citizens.  The OS is actually closed-source and proprietary, which goes against the most basic Linux and FOSS philosophies.  Linux enthusiasts like to study and marvel at Red Star due to its extremely niche user base and function.  Obviously it is not recommended to be installed for almost anyone reading this book, but it exists as a novel concept and interesting read.

Installing Linux

              After reading so much about Linux distributions, you must be very ready to give one a try, and you can install a Linux OS though various methods.  Generally, the process of trying out a Linux distro involves obtaining an .iso copy of the OS and burning it onto a removable media (CD, USB, etc…) and finally making your PC boot from that media. In our extended example for this book we will download and install Ubuntu.  Certainly you can substitute any other Linux distro in our examples, but the specifics here will still refer to Canonical’s easy-to-use beginner OS.

Linux-based operating systems can be installed and booted either from a USB flash drive, a CD or DVD, or even a floppy disk. The first step to installing Linux involves obtaining a writable media that can hold your OS.  A 4GB flash drive is usually sufficient (and that is what we will continue the demonstration with), but you may need an 8GB one for larger images.

Secondly, we need to obtain a copy of the OS.  Through the website [http://www.ubuntu.com/](http://www.ubuntu.com/) you can navigate to the “Desktop” page and then “Download Ubuntu”.  By default, Ubuntu’s latest version will be displayed on this page with a few system requirements.  Take this time to make sure that your computer can cope.  Also, printing out the next few pages of this guide is a decent idea as well, because once you start Linux you may not have a chance to pull this book back up.  Click the “Download” button to proceed.  Ubuntu is monetarily free; to avoid donating to Canonical enter “$0” in all of the boxes and click the “Download” button at the bottom.  The image will begin downloading.

Third, we will need an application with which to “write” the OS to the media.  The most popular tool for writing images is UNetbootin ([https://unetbootin.github.io/](https://unetbootin.github.io/)), but the free tool Rufus ([https://rufus.akeo.ie/](https://rufus.akeo.ie/)) is much easier to use.  Snag a copy of Rufus and wait for all downloads to finish.

Fourth, insert the removable media into a USB port and start Rufus.  Your USB drive should be listed in the top drop-down box.  By writing the Ubuntu image onto the drive you will be erasing all of its contents, so back it up now if you need too.  The default Rufus settings will suffice for our needs, but we will need to make sure that “Create a bootable disk using” is checked, and that the dropdown says “ISO Image”.  Change that and click the disc button beside it to open up a file explorer.  Navigate to our downloaded Ubuntu image and double click it.  We can now press the “Start” button to begin writing Ubuntu onto the drive.  Do so.  After the process is complete shut down the computer.

Fifth, start up the PC and enter the BIOS before Windows loads.  The key to do so varies as per motherboard manufacturer, but it is usually one of the “F” keys at the very top of the keyboard.  Every motherboard manufacturer also has their own BIOS layout so the explanation here is general and vague.  Find a “boot” tab or something similar where you can view the “boot order” of your PC.  The boot order tells the computer where to look for operating system images, and typically BIOS will look in the internal hard drive first.  Change the order to place USB or external hard drives first.  Save and quit the BIOS.

Starting up the computer one last time will start our last step.  BIOS will search in the external USB first and find the Ubuntu image.  If Windows loads instead of Ubuntu than repeat Step 5, but otherwise you will boot into your first Linux system.  Congratulations! 

The OS that appears is fully intractable and usable, but there still is a slight problem- it is still running from the USB drive and has thusly not installed itself.  Ubuntu variants contain an application on the desktop that you can double click that will start the install process for you.  If you are done testing Linux and are ready to erase Windows, then click this option.  Be warned that if you choose certain options you will erase your entire computer, so read the directions carefully.  You can choose to “dual boot” with your current OS, or you can choose to completely wipe the computer and start from scratch.  It is recommended that you dual boot at first, just in case you need to get back to Windows for a certain application or feature.  As a failsafe, though, definitely fully backup your computer before attempting any installation. 

If the installation is successful and you chose dual boot, then every time the computer turns on you will see GRUB, the GRand Unified Bootload.  GRUB will as which OS you want to begin, so you have a choice between Linux and Windows every time you compute.

Using Ubuntu

              For those that have only used a Windows-type interface, Ubuntu will not look completely foreign.  There is still a “desktop” and a “start menu”, but the placement of things is slightly different.  You start applications in the usual way, by either clicking them on the start bar or searching for them after clicking the start button.  If you are on a desktop than you are most likely already connected to the internet, but if you are on a laptop you might need to connect to Wi-Fi through the upper right corner.  Overall the usability of Ubuntu is high, and you should be able to understand it fairly quickly.  Browse the web and try out the default applications to get an interactive feel for how Linux operating systems work and act.

The Terminal

Linux differentiates itself from Windows by offering an additional text-based interface reminiscent of old DOS computers.  Through the terminal, commands can be run that perform actions on the PC.  Starting the terminal differs on each distro, but ctrl+alt+T is a common hotkey.  Once in the terminal, you can browse the filesystem and generally use the computer with the same level of control as a graphical user interface. The user first enters a command and presses enter to execute it. Here are a few essential commands.  While reading this book, any text that is italicized refers to the fact that it is a terminal command.

| Command | AKA | Use | Example |
| cd | Change Directory | Type to change current folder | cd desktop |
| pwd | Print Working Directory | Displays the current folder’s name | pwd |
| shutdown | Shut down | Powers off the current system | shutdown –h now |
| ls | List | Lists all files in the current folder | ls |
| cp | Copy | Copies the specified file with an optional new name | cp picture.png dog.png |
| mkdir | Make Directory | Creates a new folder with specified name | mkdir Documents |
| rm | Remove | Remove the specified file | rm dog.png |
| rmdir | Remove Directory | Remove the specified folder | rmdir Documents |
| apt-get | Advanced Packaging Tool - Get | A command that works in Ubuntu-type systems that installs new software | apt-get install minecraft |
| . | Run | The period is used to run a file, such as a script. | ./a.out |

If you have every used DOS the above may seem familiar.  Here is an exercise to master the terminal.

1.  Start terminal.  Either ctrl+shift+T or find it in a programs menu.
2.  Type pwd to find out where we are.
3.  cd Desktop to travel to the desktop folder.
4.  mkdir Notes to create a new folder called Notes.
5.  cd Notes to travel there.
6.  Using nano secretfile.txt, we will start editing a new file in the built-in text editor Nano.
7.  Type something secret!  Press ctrl+x to save and exit the program.
8.  Type ls to list the current directory’s contents.  You should see secretfile.txt there.
9.  With cp secretfile.txt totallynormalfile.txt, we copy the file and make a new one.

At this point you should minimize the terminal and see the folder and files you just created on your desktop.  Following the directions above might have taken much longer than usual for you to create a folder and files, but with practice you can manipulate a Linux system at a speedy pace through terminal. Additionally, mastering the terminal is very difficult, but it provides a deep level of control over your distribution that GUIs might not be able to give.  Overall, it is definitely recommended that a Linux user know how to use a terminal proficiently.

Software for Linux

 You might be surprised to learn that you may not have to change your software repertoire when you “jump ship” to Linux.  Tech-inclined users may already be familiar with some of the software available for Linux, such as Mozilla Firefox, Google Chrome, Opera, Adobe Reader, Mozilla Thunderbird, and VLC.

              If a certain software is not already installed on the machine than getting it is a breeze.  Ubuntu contains the application “Ubuntu Software Center” that acts as an “app store” for Linux programs.  Through the friendly interface you can search for and 1-click-download plenty of programs- many of which are listed below.  The more obscure programs may not be listed in the software center, though, so you’ll have to install them through the terminal.  Inside a terminal window, type the following:

sudo apt-get install vlc

Sudo is a terminal prefix that instructs the system to run with highest privileges possible.  A password will need to be entered when sudo is run. Apt-get is the Ubuntu application program; by specifying install we are signifying our intentions. Vlc is the name of the program we want (VLC Media player).  So with this one line in a terminal we have downloaded and installed an entire application.  Replace vlc with any application name and Ubuntu will download it.  Below are the most popular applications for each category.

How Linux Works

              Linux is able to work through a complicated system of interactions that allows the kernel and various pieces of software to control the hardware on your computer.  Mainly, Linux still contains the basic files, folders, and programs that we have grown accustomed too.  Differences arise, however, from discussing the customizable parts that are not changeable in Windows.  The most important bits are discussed below in technical detail.

The Desktop Environment

              A desktop environment is what you see on the monitor when actually using a graphical operating system.  It is typically easier for a user to start and run software by manipulating and clicking on the desktop environment than it is for them to type commands into a text-only interface.  The desktop environment usually consists of icons, windows, folders, a wallpaper, widgets, and drag and drop functionality.  These familiar functions are standard in almost all operating systems.  Just as Windows has folders, windows, icons, and a mouse pointer, so does Linux through desktop environments (DEs). There are many desktop environments available for use such as Cinnamon, Enlightenment, GNOME, MATE, Xfce, LXDE, and more.  Each different distro has a preferred DE that is usually preinstalled and gives those operating systems unique colors and looks.  As you read about the different DEs below, consider the fact that you can install any DE onto any distro.  Some DE might appeal to you more because of its functions, and do not be afraid to switch.

              GNOME is a graphical desktop environment described as an “easy and elegant way to use your computer”.  In its 3rd iteration, GNOME is default on Ubuntu.  The format is designed to be simple and stylish as well- GNOME’s only downside is the moderately high system requirements and the lag it can cause on older computers.  If you are coming straight from Windows, GNOME is a good stepping stone to other desktop environments.

              Cinnamon is a popular desktop environment that utilizes many of the applications that GNOME does- just in a more responsive and less flashy way.  If you tried GNOME but it was a little too “heavy” and large, then Cinnamon may rectify your situation.  You will still need moderately high system requirements though, as it takes a good amount of computing power to run Cinnamon.

              Mate is the lighter Cinnamon.  The important features of GNOME and Cinnamon are present, but the extras are thrown out to create a DE that can run on slower computers.  Basically if you like the way GNOME-like desktops work, you can choose between the 3 tiers of resource intensiveness with Mate being at the bottom.

              LXDE is an abbreviation for “Lightweight X11 Desktop Environment”.  It has low resource requirements, making it a good desktop environment for low-end and older computers.  1GB PCs can run Linux with LXDE fairly easy, making it great for reviving old computers.  The interface is simple and light as well.  Lubuntu is a Ubuntu variant running LXDE, so if you are looking for a quick and speedy OS that has the ease of use of Windows, LXDE can facilitate it.

              Xfce is a fast, resource uninventive, and aesthetically pleasing desktop environment. It often competes with LXDE for most lightweight DE, but while LXDE focuses more on speed, Xfce retains both functionality and speed to create a well-rounded lightweight DE.  The layout of Xfce is user friendly and responsive, in addition to being customizable. 

              KDE is a DE for beefy computers.  Distributions that include KDE by default are known for being feature-rich and customizable, albeit a little slow and laggy.  KDE’s widgets will inspire anybody that enjoyed Windows Vista, and the flashy transitions are loads of fun for people that like to enjoy their computing experience.  It is so customizable that often two users can be running KDE side-by-side, yet neither would know the other is running the same DE. 

              Conclusively, each distro will come with a desktop environment preinstalled.  The DE controls the looks are interactions with the desktop screen, and they work together with the windowing system and window manager (explained below) to provide your experience. 

The Windowing System

Linux-based operating systems use certain techniques to provide users with interfaces for their devices.  The graphical user interface (GUI), often follows a scheme known as the windowing system. A windowing system or window system is a type of GUI that implements windows, icon, menus, and pointers in such a way that is very familiar to modern users.  There are two main windowing systems available for Linux based operating systems-the X Window System and Wayland.  It is important to understand how these systems work, as they are often how we interact with our Linux computers.

The X Window System provides the basic framework for a graphical user interface environment and controls the drawing and moving of application windows by allowing the user to interact with a mouse and a keyboard.  The X Window System does not mandate the graphical user interface, thus applications can have any number of visual styles.  The way an application looks and feels is handled by the application itself, the X Window System just facilitates the drawing of it onto the screen.

Wayland is an alternative to X existing as free and open source software.  Wayland aims to replace the X Window System with a more modern and simple way of drawing onto the screen.  Like the X Window System, Wayland is available under the MIT License (another FOSS-inspired license).  The group behind Wayland also develops a display compositor for Wayland called Weston (compositors are another complicated set of tools that facilitate drawing windows to the screen).  In the Wayland Frequently asked questions the question is asked “What is wrong with X?” and the answer from the Wayland project is generally straightforward.  X has feature-creep and contains remnants of features long gone.  Because the code remains in X, the functionality must be supported in all released of X in the off-chance that somebody is using it in their system.  Wayland takes pride in taking the outdated and depreciated code and making it entirely optional while keeping the required “core” scripts in top shape.

Basically, Wayland wants to advance the technology behind X while leaving the antiquated design and functionality behind.  A good comparison for this is Microsoft’s Internet Explorer and their newer Edge browser.  Edge was created to improve upon IE’s concepts but leave the old design and legacy compatibility issues behind.  Unless you are building your Linux OS from scratch, though, most every distribution has a windowing system already installed.

The Init

              In Linux the init, with is short for initialization, is the very first process that is started during the boot sequence of the computer system.  The init is a daemon process that the system will continue to run until the moment that it powered off. Init is started by the kernel using a static filename- and if the kernel is not able to start the init, the system will experience a “kernel panic” resulting in a fatal system error.  Ever since March of 2015, most Linux kernel based operating systems have adopted systemd as the default init, though this has led to a great deal of controversy due to its monolithic nature.  The use of systemd was so controversial that members of the Debian Project quit and forked to create their own operating system called Devaun.  Systemd and inits are important and discussed because they can control how the kernel, applications, and users interact.  An all-powerful and poorly written init such as systemd undermines the philosophical principals of freedom and openness that Linux promotes.

More with the Terminal

              Ultimately the terminal will provide the most amount of functionality to your Linux computer.  After learning the basics of Linux, you can truly begin to interact with your PC through the text interface. As an example, Linux excels over Windows due to the ease of updating software.  While in a normal Windows installation you would have to uninstall a program and install the newest version every time there is an update, Linux allows you to update every program on the system at the same time with a simple command.  Within the terminal (on our Ubuntu system) type the following command:

sudo apt-get update

Observational users will remember that apt-get is also the method through which we install new programs.  However, for this we type apt-get install; for updating we type apt-get update.By executing the command Ubuntu will search through its repositories and retrieve update files for every application that is out of date.  Very handy and extremely fast, apt-get update doesn’t even require the computer be restarted when program are updated. 

You might have tried to install a program through terminal only to be told that the application does not exist.  What that statement means is that the program does not exist within the installed repositories.  Repositories are data store-houses that contain link to applications.  By default Ubuntu only has a few repositories installed, but the Linux user is free to install more. Here’s how:

sudo add-apt-repository “repository http here”

              Repositories open up lots of new software to try out, so be sure to find a list online of the best repositories and have fun experimenting. 

Starting programs from the terminal is another easy task, just type the name of the program.  For instance to launch the GIMP software just type gimp.  You can specify parameters in the command as well, such as which file to open.  With gimp dog.png we can open gimp and dog.png directly and with only one command.

Staying Safe on Linux

              Computer viruses are a plague that mostly effect Windows machines.  This comes about because of the large market share that Windows has.  It makes sense that if Windows is installed on 80% of computers than 80% of viruses and malware are going to be made for Windows.  The fact holds true, which is why Apple and Linux computers rarely have to worry about viruses.  However, risks still exist within Linux.  Viruses are possible, so use the following tips to stay safe.

*   Do not download just any program.  The default repositories are obviously safe, but if you are following an internet tutorial on how to install a program they could be leading you down a dangerous path.  Only install from trusted sources.
*   There are plenty of “jokes” in Linux that can wreck your system.  Because Linux offers full control to users, it often gives them opportunities to ruin their computers.  The running joke in Windows is to “delete system32” (obviously do NOT try this!) and the Linux equivalent is to “sudo rm –rf /”.  The command deletes EVERY file on the system, so never run it, even if told.
*   Network security still exists, so just because you are running Linux doesn’t mean that your online passwords and accounts are any more protected. 
*   Update your system often.  Updating applications and the entire distribution can eliminate vulnerabilities and bugs that give hackers an entry point into your PC.
*   Backup your data often too.  Linux has the most secure and reliable operating systems, but there is still the possibility that Linux could fail or its files could become corrupted.  Regular backups mitigate risks.
*   Use sudo sparingly.  Linux remains so secure because every serious command requires root access to actually do damage, and malicious programs will never actually get the opportunity provided you do not give it to them.  Windows remains vulnerable because most home users utilize the admin profile as their daily account.  Malware and viruses can take advantage of the admin’s enhanced permissions to wreak havoc, but since you are never admin in Linux that risk is much smaller.

In conclusion, the average Linux user is already much safer than the average Windows user.  Despite this, there are still a few best practices that every computer user should follow, regardless of operating system.

Advanced Concepts in Linux

The File Structure

              In Linux-based operating systems there are two kinds of major partitions: the data partition, and the swap partition.  The data partition includes the normal Linux system data and personal user data as well.  The swap partition is an expansion of the computer systems physical memory (RAM).  Most Linux operating systems require both partitions to run efficiently. 

Swap is an extension of RAM.  When programs need extra space, the swap partition dedicates some of its data to the program.  The Windows equivalent of this is the pagefile. 

The default filesystem in Linux is ext4, and drives formatted in Linux will usually use it.  This is not beneficial when sharing data back to a Windows system, because Windows cannot normally read ext4.

Below are the folders found on the root of a drive in Linux.  An important feature of Linux distros is that every object on the computer is a file.  This means that every peripheral, piece of data, hardware component, and terminal command is represented as a file in Linux.  Accordingly, everything has to be stored somewhere, and the folders below contain the entirety of the computer.

WINE

              An astute user might have noticed that Linux does not run exe files.  For Linux users that refuse to give up certain Windows programs, WINE can help.  WINE is a ”compatibility layer” capable of running Microsoft Windows files in order to “emulate” applications as if they were running in Windows.  For Linux users this means that you can run Linux without fully giving up Windows.  WINE is not a replacement for running Windows programs, though.  To install WINE, the following commands must be run:

sudo apt-get-repository ppa:ubuntu-wine/ppa

sudo apt-get update

sudo apt-get install –y wine1.7

And to run an exe it must be downloaded.  Using a terminal navigate to the download location and type wine programname.exe.  There is certainly a large number of configuration options (winecfg) to sort through, and configuring a particular program to run perfectly in WINE is a long process.  The huge difficulty and confusing nature of WINE makes it a tough program to use, but it is a great way to use parts of Windows that Linux just doesn’t provide.  For those wishing to fully immerse themselves in Linux, though, WINE is not recommended at all.  Try installing a FOSS alternative to the program you are trying to run instead.

Programming on Linux

 Linux, OSX, and other UNIX-based operating systems use the terminal for many functions, just as they have historically before GUIs became common.  The first programmers would use the terminal as their “toolchain” to create, code, compile, and run their software.  Coding functionality was never dropped from the terminal, so serious programmers still prefer the ease of use received from Linux’s coding workflow. Applications can be written in a terminal editor such as nano, then be compiled with the built-in gcc GNU compiler, and finally run all without leaving the default programs in almost all Linux distros.  Any programmer interested in coding but disheartened in the large, complex IDEs available for Windows should switch to an OS where programming and tinkering is encouraged.  Here is a small example of the workflow for programming “hello world” in C.

In terminal, type nano to access a small text editor.  Type:

#include <stdio.h>

int main(){

              printf(“Hello World!\n”);

              return 0;

}

Press ctrl+x to quit, and “y” when it asks to save the file.  Pick “hello.c” as the name.  Now the program needs to be compiled.  In terminal type gcc hello.c.  So long as the program was copied exactly, it will compile without error, creating an executable file named a.out in the current directory.  To launch it type ./a.out, and you should see “Hello World!”.  Without downloading any extra programs, Linux has proven that it is a heaven for programmers.  Learning to program will increase your Linux knowledge as well, and you can even create your own applications.

Building a Beowulf Cluster

 Linux is versatile enough to be used in personal computers and large supercomputers as well.  A Beowulf cluster is a cluster of computers that synchronize hardware resources to become a makeshift supercomputer powerhouse.  With a minimum of two computers and Linux installed you can network them together and have them share resources (Raspberry Pi computers make exceptional cluster nodes!).  The process won’t be explained here, but steps can be found online.  The entire idea proves just how flexible and useful Linux can be.

Windows 10 and Linux

 With Windows 10’s anniversary update, Microsoft added a little bit of Linux into Windows.  Bash, the terminal “language” used in Linux is fully implemented into Windows 10’s command prompt.  In short, this means that any Linux program can easily be ported into the Windows environment (kind of like reverse WINE).  Windows user can even type sudo apt-get update to update their Windows systems now!  An interesting update, the whole situation shows how the “year of the Linux desktop” is fast approaching, and Linux will play an even larger part in the future of computing.
