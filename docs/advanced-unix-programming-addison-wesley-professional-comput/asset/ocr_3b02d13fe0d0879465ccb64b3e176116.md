# ### 3.6.1 Reading Directories

Underneath, UNIX systems nearly always implement directories as regular files, except that they have a special bit set in their i-mode and the kernel does not permit writing on them. On some systems you’re allowed to read a directory with read, but the POSIX and SUS standards don’t require this, and they also don’t specify the internal format of the directory information.
