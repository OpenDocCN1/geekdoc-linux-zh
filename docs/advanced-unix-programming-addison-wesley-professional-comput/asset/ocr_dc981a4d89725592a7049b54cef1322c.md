#include <sys/sem.h>

As I said, semop doesn’t just operate on one semaphore but on as many as you like, even the whole set. You need to build an array of operations (struct sem-bufs) before you make the call, although if there’s only one to be operated on, a single struct sembuf will do—you just pass its address and use 1 for nsops.

Each sem_op can be positive, negative, or zero:
