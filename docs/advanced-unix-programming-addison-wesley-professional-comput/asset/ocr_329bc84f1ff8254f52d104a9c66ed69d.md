All we're doing is using select (Section 4.2.3) to wait until the pt is writable. The next function is **pt\_close\_master**, called in the parent to close the file descriptors when the pt is no longer needed and to free the PTINFO structure.

```c

	ec_neg1( close(p->pt_fd_m) )
```

```

There's also a **pt\_close\_slave**, but it's usually not called because the child process is overlaid by another program in step 8. Also, since we redirected file descriptors, the child's end of the pt is by this time represented by the standard file descriptors (0, 1, and 2), and those are almost always closed automatically when the process terminates. Here it is anyway:

```
```c
bool pt_close_slave(PTINFO *p)
{
	(void)close(p->pt_fd_s); /* probably already closed */
	free(p);
	return true;
}
```
```

If you find yourself calling **pt\_close\_slave** in your code, you're probably doing something wrong.

Note that both **pt\_close\_master** and **pt\_close\_slave** free the PTINFO structure. That's the way it should be because when they are executed the structure is allocated in both parent and child. This will be more clear when *fork* is explained in Section 5.5.
```
