Assuming the terminal is in raw mode from a call to tc\_setraw, we call getch to read a character:

```
int getch(void)
{
  char c;

  switch(read(STDIN_FILENO, &c, 1)) {
  default:
    errno = 0;
    /* fall through */
  case -1:
    return -1;
  case 1:
    break;
  }
  return c;
}
```
