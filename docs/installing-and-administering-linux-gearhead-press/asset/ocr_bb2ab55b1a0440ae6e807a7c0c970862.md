# ## Files and Directories: A Quick Review

As stated in Chapter 4, a file is a collection of data or a stream of characters. A typical file can contain either text (which can displayed or printed) or code data (more commonly called a binary file, which can also be executable). In Linux, everything is represented as a file—even system devices. Linux does not impose any internal structure on the contents of a file, nor does it require the file to have any specific attributes. Only the application or tool is concerned with a file’s structure and contents.
