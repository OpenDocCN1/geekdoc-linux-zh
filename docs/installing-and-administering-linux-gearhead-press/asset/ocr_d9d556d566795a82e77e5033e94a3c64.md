# Table 7.3 Quoting Metacharacters and Their Functions

| METACHARACTER | INSTRUCTION TO SHELL | EXAMPLES |
| :--- | :--- | :--- |
| Single quotes ( ' ' ) | Ignore all metacharacters between quotes | $ echo '$HOME'<Enter><br>$HOME |
| Double quotes ( “ ” ) | Ignore all metacharacters between quotes except the dollar sign ($), backquote (`), and backslash (\) | $ echo "$HOME"<Enter><br>/home/quxoted<br>$ echo '*."*'<Enter><br>** |
| Backslash ( \ ) | Ignore the special meaning of the next metacharacter | $ echo \$HOME<Enter><br>$HOME |

The backslash character deserves special scrutiny. If you are using a backslash to continue a command on another line, that backslash disables the special meaning of the pressed Enter key that immediately follows, which normally submits whatever is on the line to the shell for interpretation. By using the backslash there, the shell is being told, "The command isn’t finished yet; ignore the next Enter key and let me continue entering instructions." Then, the next Enter key submits the command to the shell.

Check out how we use the backslash in Example 7.15. Instead of the shell seeing three double quotes and presenting a secondary prompt (which was not our intention), it presents the statement followed by the double quotation mark (which was our intention).
