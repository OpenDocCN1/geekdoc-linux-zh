# ## Shell Basics

As soon as you log into a Linux system, you are exposed to a shell-gener-ally, the Bash variant, which we discuss in detail in this chapter. The shell program is an interface to the operating system, translating your typed input (or input from other sources) into instructions for the operating sys-tem. DOS's command.com program does just about the same thing.

This chapter describes the ins and outs of the basic Linux shells. Although the focus is on Bash, we introduce elements of the *tcsh* shell and include certain twists on the commands relevant to still other shells.

Knowing what the shell is doing with your input will make you a more efficient and effective Linux user and system administrator. When you see how you can customize your input with wildcards, metacharacters, and pipelining, you will begin to understand their power.
