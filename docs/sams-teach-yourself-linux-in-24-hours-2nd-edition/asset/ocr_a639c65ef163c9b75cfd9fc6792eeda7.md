# Using the lisa Command

The lisa command is not only a graphical interface program to most OpenLinux system administration tasks, but also can install or remove software. Again, you must be logged in as the root operator in order to install and remove software using lisa. However, you do not need to run X11.

To jump right into software package management, start lisa from the command line with its --pkg option:

```
# lisa --pkg
```

The lisa dialog will appear as shown in Figure 22.7.
