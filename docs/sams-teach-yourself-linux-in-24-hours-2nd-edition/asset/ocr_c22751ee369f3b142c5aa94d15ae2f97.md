To import a spreadsheet document into StarCalc, use the Open menu item from the StarCalc File menu. To export a spreadsheet document, use the Save As menu item from the File menu. A dialog box appears as shown in Figure 17.7. Click the drop-down menu next to the File type field, and a scrolling list of file types appears. Scroll through the list, and click the desired format. To save the file, click the Save button.
