# Playing X11 Solitaire

If you enjoy playing card solitaire games, you'll like the xpat2 X11 client. This program (shown in Figure 20.6) features 14 different solitaire games with scoring, hints, built-in help, and sound. Start the game from the command line of a terminal window, like this:

```
# xpat2 &
```
