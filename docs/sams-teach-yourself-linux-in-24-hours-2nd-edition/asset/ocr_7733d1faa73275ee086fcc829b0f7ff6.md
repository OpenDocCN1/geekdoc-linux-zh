# FIGURE 3.3

Configure how or when a kernel module is loaded with COAS.

![](bbox=[0.27, 0.52, 0.68, 0.75])

Because no options are needed (for this example), make sure the Load at boot time button is enabled. Click the OK button. Next, scroll through the list of modules on the left, select the uart401 module, and click the Load button. Again, ensure loading at boot time, and click OK. To finish configuring for sound, scroll through the list of modules and select the sb module. Click the Load button, and you see a dialog box similar to the one in Figure 3.4.
