# Features of ash

The ash shell, by Kenneth Almquist, is one of the smallest shells available for Linux. This shell has 24 different built-in commands and 10 different command-line options. The ash shell supports most of the common shell commands, such as cd, along with most of the normal command-line operators (discussed later this chapter in the section, "Understanding the Shell Command Line").
