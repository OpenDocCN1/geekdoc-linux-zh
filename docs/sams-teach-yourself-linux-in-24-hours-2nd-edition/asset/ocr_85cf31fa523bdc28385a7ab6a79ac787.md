# FIGURE 15.1

The lisa program provides an easy-to-use interface when you need to configure a printer for OpenLinux.

![](bbox=[0.38, 0.16, 0.92, 0.42])

If you have a printer that appears to be unsupported, check Caldera System's Web site at http://www.calderasystems.com/support/techguide.html to see if additional support has been created for your printer. Users of Epson Stylus color printers definitely need to read about support for these printers. If you want to print over a network or install a network printer, definitely read the “Local Filter for Remote Printer” document. If you have a PostScript printer, see the document “Setting Up a Real PostScript Printer.”

When you finish, press Enter. You see a dialog box (in Figure 15.2) that lists several parallel-printer ports. Scroll through the list, pick your computer's parallel port, and press Enter.
