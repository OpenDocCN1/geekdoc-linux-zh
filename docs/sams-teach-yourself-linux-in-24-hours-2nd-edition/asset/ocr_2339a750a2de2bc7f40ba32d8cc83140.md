If you want to experiment with this command without an active Internet connection, you can telnet to your own computer from a terminal window under X11 or through the console. As with the ftp command, first determine the hostname of your computer with the hostname command, and then either specify the hostname on the telnet command line or run telnet and use its open command to start the session, for example:

```
# hostname
presario.localhost.localdomain
# telnet presario
Trying 127.0.0.1...
Connected to presario.localhost.localdomain.
Escape character is '^]'.

#
```
