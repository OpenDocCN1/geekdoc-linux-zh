I can't discuss all the details about UNIX mail in this hour, but you should understand how electronic mail works in general. The main programs involved in email are, in technical terms, transport agents and user agents. A transport agent is a program, usually a daemon, that sends mail files from one computer to the next automatically. A user agent is a program, also called a mail reader, that you use to manage messages. You'll learn how to use these programs in this hour.

After you install OpenLinux, you can find nearly all the programs you need to compose, send, and receive mail. The transport agent used for OpenLinux is sendmail, and it is configured and run automatically when you boot the operating system. As far as user agents and electronic mail utilities, you have a wide choice from at least nine (listed in Table 11.1).
