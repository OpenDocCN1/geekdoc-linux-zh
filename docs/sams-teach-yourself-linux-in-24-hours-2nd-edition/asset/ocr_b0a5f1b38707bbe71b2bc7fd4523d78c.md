# Configuring a PPP Connection with xisp

The xisp client included with OpenLinux is another easy-to-use graphical interface you can use to configure, start, and stop PPP connections. This section shows you how to configure xisp to work with an ISP. You must be running X11 to use xisp.

To start the xisp client type su -c "xisp8" and press Enter at the command line of an X11 terminal window. After entering the root operator password, the X-ISP dialog box appears, as shown in Figure 10.11.
