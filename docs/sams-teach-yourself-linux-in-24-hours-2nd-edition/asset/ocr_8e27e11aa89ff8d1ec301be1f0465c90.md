# FIGURE 16.2

The display X11 client, part of the ImageMagick software package, can be used to make changes to many different types of graphics.

![](bbox=[0.26, 0.16, 0.9, 0.6])

> The xv client is not free software. If you use this program for commercial purposes or institutional or government use, you should send a registration fee to the author, John Bradley. Press Ctrl+A in the xv controls dialog box to see how to register.

The xv command loads a single file or series of graphics if you use a wildcard on the command line, as in the following example:

```
# xv *.jpg
```

This command line loads all files ending in .jpg in the current directory. After the files are loaded, scroll through a list of files to make your changes, or use a graphics directory to select your files.

> The xv client does not function well on 24-bit displays. If you need to use a lot of colors during your X sessions, start X11 with 16- or 24-bit color.
