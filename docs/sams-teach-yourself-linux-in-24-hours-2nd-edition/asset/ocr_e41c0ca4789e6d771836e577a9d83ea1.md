# Internet Downloading and Browsing

This hour introduces you to programs you use to get information and programs from the Internet. I assume that you are signed up with an Internet Service Provider (ISP) and that you configured your OpenLinux system to start and stop Point-To-Point Protocol network connections.

> If you already have an account with a local ISP but have not configured your Linux system to connect to the Internet, read Hour 10, "Connecting to the Internet," for instructions.

I first introduce you to two Internet file transfer programs and then cover some of the many World Wide Web browsers you can find for Linux.
