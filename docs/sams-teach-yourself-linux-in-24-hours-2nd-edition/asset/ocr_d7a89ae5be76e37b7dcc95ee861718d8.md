# LISTING 10.2 THE ppp-on-dialer DIALING SCRIPT

```
...
exec /usr/sbin/chat -v
TIMEOUT 3
ABORT '\nBUSY\r'
ABORT '\nNO ANSWER\r'
ABORT '\nRINGING\r\n\r\n\r\nRINGING\r'
''
'OK-+++\c-OK' ATH0
TIMEOUT 30
OK ATDT$TELEPHONE
CONNECT ''
ogin: -ogin: $ACCOUNT
assw ord: $PASSWORD
```
