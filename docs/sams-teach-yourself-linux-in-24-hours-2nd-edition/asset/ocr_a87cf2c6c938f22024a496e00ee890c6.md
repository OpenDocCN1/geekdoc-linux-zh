# FIGURE 11.1

The elm mail program displays messages in a list.

![](bbox=[0.38, 0.14, 0.88, 0.54])

You can use elm to delete, forward, save, or compose messages. Customize some of its features by typing an o (for options) while in elm’s main display (as shown in Figure 11.2). Type a letter, then type a new value for features such as the default editor (used when you compose or reply to messages), and press Enter. These custom features are saved in an .elmrc file under the .elm folder in your home directory when you press the < key.
