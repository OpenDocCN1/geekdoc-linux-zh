# FIGURE 19.2

Choose a location for the StarOffice 5.0 installation.

![](bbox=[0.35, 0.14, 0.78, 0.38])

The default is the Office50 folder in your home directory. If you choose another location, make sure you have read and write permission (see Hour 22, “Handling Files and Your File System”). After you click the Next button and confirm creation of the directory, click the Complete button. You see the install window, as shown in Figure 19.3, displaying the progress of the install. This installation typically takes less than five minutes with a late-model computer.
