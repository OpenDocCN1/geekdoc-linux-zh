# Reading Directories and Files

Now that you know about directory navigation, searching for files, and how to find more information about programs, I'll introduce you to other basic Linux commands you can use. # Listing Directories with the ls Command

The ls (list directory) command is one of the most often used programs. In its simplest form, ls lists nearly all the files in the current directory. But this command, which has such a short name, probably has more command-line options (more than 75 at last count) than any other program!
