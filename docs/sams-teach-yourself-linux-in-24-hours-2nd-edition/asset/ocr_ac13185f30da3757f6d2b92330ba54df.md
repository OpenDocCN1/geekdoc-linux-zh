# Starting X

When you first log in to OpenLinux, you see a short message like this:

Welcome to your OpenLinux system!
You can start X11 with 'startx' or KDE with 'kde'.

The startx and kde commands are almost identical shell scripts used to start an X11 session. startx is found under the /usr/X11R6/bin directory, whereas kde is found under the /opt/kde/bin directory. To start an X11 session using the fvwm window manager (discussed later this chapter in the section "X11 Window Managers") with the Looking Glass desktop client, type startx on the command line of your console, and then press Enter, like this:

```
# startx
```

If you properly configured X11 to work with your computer's graphics card (as described in Hour 3), your display clears, and after a few seconds, the X11 desktop appears, as shown in Figure 7.1.
