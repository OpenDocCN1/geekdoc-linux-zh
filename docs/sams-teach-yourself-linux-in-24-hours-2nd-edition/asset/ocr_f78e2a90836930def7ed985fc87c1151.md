> If you have a shell or login account with your ISP, you can run into problems when downloading large files if your ISP enforces disk quotas, which limit the amount information that can be stored in a user's directory. See if your ISP lets you first change the directory to a /tmp directory if using ftp, and then open a connection to download any large files. The /tmp directory is later cleaned out by any housekeeping cron tab routines to make more storage room, and you can download large files without hitting hard limits on quotas.
