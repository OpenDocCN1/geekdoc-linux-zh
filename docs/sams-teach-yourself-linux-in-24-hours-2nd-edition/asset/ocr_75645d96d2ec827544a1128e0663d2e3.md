Q How can I look at what's inside a binary file? If I try to use the cat or less commands, I see a lot of garbage.

A Try using the strings command. To see how to use strings with less, see Hour 6, "Using the Shell."

Q How do I get more information about each file inside a tape archive? I know that the t option shows the file and directory names.

A Use the v option along with t on the tar command line to view the permissions, owner, group, file size, date, time, and name of each item in a tape archive.
