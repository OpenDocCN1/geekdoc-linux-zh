# Reading and Navigation Commands

This hour introduces you to the basic Linux commands used for navigating, searching, and reading files and directories of the file system, your Linux partition's collection of directories. After working through the material, you'll know how to get help on commands, find out where you are in Linux, and find files on your hard drive. The hour starts with navigating and searching your directory, and then moves on to show how to read directories and files. But first, you'll learn how to help yourself with the man command.

# Getting Help with the man Command

One of the first things to know about Linux is that help is never far away. Like most implementations of UNIX, your Linux distribution comes with manual pages for most programs, utilities, commands, and programming system calls. You can get information about nearly any command, including man. For example, read the manual page for the man command by typing the following:

```
# man man
```
