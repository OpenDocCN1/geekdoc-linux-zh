The csh program will complain if the program is not listed as a shell in the /etc/shells file. Then, you check whether the change was made:

The preceding example specified the text editor pico, which allows a user to do word processing, printing, or spell-checking, but that's all! This is a handy technique you can use to restrict users, especially children, if you only want them to play a game.
