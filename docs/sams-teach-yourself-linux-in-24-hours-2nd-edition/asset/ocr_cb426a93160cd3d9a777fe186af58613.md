Q I try printing, and the lpr command responds with an error like “connection to ps@localhost.localdomain failed—Network is unreachable”! What’s going on?

A Make sure that your /etc/hosts file contains a definition for the loopback device and local host. Also, make sure that you do not have any incorrect hostname definitions in the file.
