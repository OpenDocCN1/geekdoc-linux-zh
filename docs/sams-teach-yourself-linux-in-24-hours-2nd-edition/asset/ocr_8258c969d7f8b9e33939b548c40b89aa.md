# Getting Window Information with the xwininfo Client

You can use the xwininfo client, or window information utility, to get helpful information about a window. When you use this command, you can click another window to get a detailed information listing, for example:

```
# xwininfo
xwininfo: Please select the window about which you
would like information by clicking the
mouse in that window.
```
