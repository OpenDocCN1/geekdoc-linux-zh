# Configuring Your Printer with the lisa Command

Installing, changing, or deleting local printers with your OpenLinux system is a snap thanks to the Linux Installation and System Administration utility called lisa. This program is located under the /bin directory. This program can be used with or without the X Window System to set up your printer so you can print from the command line or through various X11 clients.

Because lisa is a system administration tool, you have to make sure you're the root operator and then type the following at your console or terminal command-line to configure your printer:

```
# lisa --printer
```

The screen clears, and you see a dialog box, as shown in Figure 15.1.

This dialog box lists nearly 40 different printers. Scroll through the list, and then pick a printer that matches your printer (or has the same capabilities).
