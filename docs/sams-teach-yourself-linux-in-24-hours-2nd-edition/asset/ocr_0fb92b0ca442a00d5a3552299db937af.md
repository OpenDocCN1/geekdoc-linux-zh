8. A Select Destination dialog box appears (as shown in Figure 15.8), listing $PRINTER, Disk, lp, and ps. Click ps, and then click the OK button.

9. In the Printer Setup dialog box, click the OK button. In the Printer Create/Edit dialog box, click the OK button. In the Select Printer dialog box, click the OK button. You're now at the main Print dialog box. Click OK to print the current document or Cancel to cancel the printing operation. (You won't lose the new printer you created.)

If you set up printing to work correctly under OpenLinux before starting these steps, you can now print WordPerfect documents to your printer!
