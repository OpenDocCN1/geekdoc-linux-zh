**Q** I tried using StarOffice 5.0's File menu to create a new spreadsheet document, but can't find these types of files listed!

**A** This used to be possible with StarOffice 4.0. If you're using StarOffice 5.0, click the Start menu button in the lower left corner of StarOffice's desktop, and then scroll up and click Spreadsheet to create a new spreadsheet document.

**Q** I tried running the gnuplot demo, but it stopped with an error after showing several plots. What happened?

**A** There's an error in the one of the plot files. Try running the demo plots separately.
