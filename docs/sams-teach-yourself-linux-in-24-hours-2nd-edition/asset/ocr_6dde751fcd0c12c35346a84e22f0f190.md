# Starting StarOffice

StarOffice 5.0 is started by the soffice script in the $HOME/Office5.0/bin directory. If you are in your home directory, start StarOffice by using the soffice command like this:

```
# Office5.0/bin/soffice &
```

After a minute or so, the StarOffice desktop appears, as shown in Figure 19.4.

> Don't forget to register your copy of StarOffice at http://www.stardivision.com/
