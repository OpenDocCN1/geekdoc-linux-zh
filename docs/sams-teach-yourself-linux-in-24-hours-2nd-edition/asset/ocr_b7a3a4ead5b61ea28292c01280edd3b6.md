The tail command is especially useful when you face the task of reading through large files where the most useful information is at the end of the file. One example task is to look at the system messages for errors. One message file, located in /var/log, contains details of system operations, but the log is updated at the end of the message file. In other words, text is appended, so the most recent messages are at the end of the file. To look at the last 12 lines in the message file using tail, make sure you're logged in as root, and type the following:

```
# tail -n 12 /var/log/messages

  Fixed Disk Card

  3MB w/1kB Cache, LBA, CHS=123/32/32
```
