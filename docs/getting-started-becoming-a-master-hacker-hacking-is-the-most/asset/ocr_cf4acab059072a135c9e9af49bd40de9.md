At this stage, we want to know more. We want to know what potential vulnerabilities the website may have that we can exploit. There are a number of excellent commercial tools for this purpose, but fortunately the OWASP (Open Web Application Security Project) project has one of the best and it’s free!

From the Kali GUI, you can go to applications, Web Application Analysis and then click on OWASP

ZAP or, if you prefer the command line, just enter **OWASP ZAP** at the command line.
