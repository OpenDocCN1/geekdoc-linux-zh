Python has its own package manager (like rpm or apt) specifically for installing and managing Python packages known as pip (Python Installs Packages). Since everything in this chapter is using Python3, you will need pip for Python3 to download and install packages. You can download and install pip from the Kali repository by entering the following: kali > apt install python3-pip Then, to download a particular package from PyPI repository, you can simply enter: kali > pip3 install <package name> When you download these packages from the PyPI repository via pip3, they are automatically placed in the /usr/local/lib/python3/dist-packages directory on your Kali system.
