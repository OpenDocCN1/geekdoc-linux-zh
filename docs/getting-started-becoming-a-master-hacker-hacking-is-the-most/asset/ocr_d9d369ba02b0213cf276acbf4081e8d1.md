Now, it’s time to start using Metasploit. You can either start it from the GUI Applications-

>Exploitation Tools -> msfconsole Or you can start it by entering msfconsole from the terminal kali > msfconsole Within a few seconds, you will be greeted by the familiar--if sometimes offbeat--Metasploit splash screen (yours may appear different). If you have been using Metasploit 4, you will immediately notice the welcome speed improvement of Metasploit 5.

Note the command prompt msf5> (if you are using an older version of Metasploit, your command prompt will be msf > without the 5). That indicates that you are now inside Metasploit’s interactive mode that they call msfconsole.
