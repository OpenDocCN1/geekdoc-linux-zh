Let’s examine what its name implies.

- **windows** - This means it will work with Windows operating systems
- **x64** - This means it will work with 64-bit operating systems
- **meterpreter** - This means it places a special Metasploit payload named “meterpreter” on the target
- **reverse_http** - This means the payload will call back to us “reverse” over HTTP looking like normal HTTP traffic

To use this payload, we need to use the set command with the name of the payload.

```
msf5 > set PAYLOAD windows/x64/meterpreter/reverse_http
```
