The simplest, fastest and most reliable nmap scan is the TCP scan. It sends TCP packets to attempt a TCP three-way handshake (SYN-SYN/ACK-ACK) on each port it scans. If the target system completes the three-way handshake, the port is considered open. The key nmap option is -sT or s can TCP.

We simply add it as an option after the nmap command and then follow with the IP address.

nmap -sT <IP> Such as:

```
kali > nmap -sT 192.168.0.157
```
