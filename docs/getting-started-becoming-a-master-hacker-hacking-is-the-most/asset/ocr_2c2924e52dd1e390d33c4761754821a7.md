# # Single Port Scan

In some cases, we may only want to know if a single port is open. For instance, we may be considering using the EternalBlue exploit against this system and we 445. Let's see whether this system has port 445

open by simply adding **-p** after the target IP address and the port number. Note that SMB is a TCP port, so we use the TCP or -sT scan.

Such as:

```
```
kali > nmap -sT 192.168.0.157 -p445
