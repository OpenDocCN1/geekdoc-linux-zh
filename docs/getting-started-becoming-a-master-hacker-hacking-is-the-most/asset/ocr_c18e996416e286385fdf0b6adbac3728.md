# Summary

Password cracking can often be the quickest and most effective way to take control of a target system.

This is particularly true when the target is using a simple password. It's important to develop a **strategy** before embarking on password cracking as different operating systems and applications require different approaches. If all strategies fail, then the attacker is left with a brute force attack which can be very time-and resource-consuming.
