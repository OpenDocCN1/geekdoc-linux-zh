# Filter by TCP Flags

What if we wanted to see only the traffic with SYN flags sets on it? We could create a filter like this: kali > tcpdump ‘tcp[tcpflags]===tcp-syn’

Of course, we can create a filter for each of the TCP flags such as; kali > tcpdump ‘tcp[tcpflags]===tcp-ack’

```
kali > tcpdump ‘tcp[tcpflags]===tcp-fin’

kali > tcpdump ‘tcp[tcpflags]===tcp-rst’

kali > tcpdump ‘tcp[tcpflags]===tcp-ps h’

kali > tcpdump ‘tcp[tcpflags]===tcp-urg’
```
