When creating filters, we most often use “==” as the operator in our filter (there are others see below).

This syntax works fine as long as we are looking for one of the many header fields in the protocol. If we are looking for strings in the payload, we have to use the "contains" operator. So, if I were looking for packets with the word “Facebook” in them, we could create a filter like that below.

```
```plaintext
tcp contains facebook 186 | P a g e
```

（注：`186 | P a g e` 中的 `|` 及其后部分疑似页码或OCR杂质，保留原貌。）
