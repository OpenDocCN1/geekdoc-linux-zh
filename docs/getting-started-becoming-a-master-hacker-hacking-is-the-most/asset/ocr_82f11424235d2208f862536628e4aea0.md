BeEF is not included in your Kali, simply download and install it from the Kali repository.

kali > apt install beef-xss The first step is to start the BeEF server. You can start BeEF by entering: kali > beef-xss Once the server has started, you can connect to it with your browser by navigating to localhost:3000. This should bring up a screen like that below with the BeEF login. The default login is: username=beef and password=beef.
