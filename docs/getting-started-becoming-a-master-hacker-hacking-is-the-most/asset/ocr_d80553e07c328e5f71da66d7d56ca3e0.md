# p0 F

p0F is pre-installed in Kali, so no need to download and install it. p0F is not available from the GUI in Kali, but it is built-in and isaccessed via the command line. Since its binaries (executable files) are in the **/usr/bin** directory and **/usr/bin** is in our PATH variable, we can access it from the command line from anywhere in Kali. Let's take a look at its help file by typing (please note that the middle character is the number zero 0, not the letter o): kali> p0f -h

As you can see above, **p0f** has a brief, but complete help file. The first stanza addresses the network interface options, the second stanza the operating mode, and the third stanza the performance options.
