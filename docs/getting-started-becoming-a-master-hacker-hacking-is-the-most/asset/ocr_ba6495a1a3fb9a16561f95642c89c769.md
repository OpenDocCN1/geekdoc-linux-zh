Although this help screen seems a bit intimidating with all its options, when we strip out all the options, the basic command is: kali > cewl -url <the URL you want to scrape> Running ceWL without any options is likely to generate a wordlist with a lot of words that do not comply with the target's password policy. A smarter and more efficient approach would be to only harvest the words longer than the typical company password policy, usually eight characters at a minimum. We can accomplish this by using ceWL's minimum word length option or -m followed by 8. In addition, we can determine the depth of the spidering (how many subdirectories deep to look).
