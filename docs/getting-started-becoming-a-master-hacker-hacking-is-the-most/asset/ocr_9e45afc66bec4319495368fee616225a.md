Although you can use the search function to search for keywords in a module name, that approach is not always efficient as it will often return a VERY large result set.

To be more specific in your search, you can use the following syntax.

# platform -

this is the operating system that this module is designed for

# type -

this is the type of module. For instance, type:exploit

# name or keyword -

the name of the module or keyword in its description The syntax for using search is the keyword; followed by a colon; and then a value, such as; msf5 > search type:exploit For instance, if you were looking for a module to exploit (type) Abobe Flash (keyword) on Windows (platform) you could display all the exploit modules to do so by entering; msf5 > search type:exploit platform:windows flash
