# What is Shellcode?

Shellcode is simply a set of instructions (code) that, when executed into a running application such as SMB (like EternallBlue does) or other vulnerable services, gives the attacker control of the system. This code is written in assembler language (for more on assembler language, see [https://www.hackers-arise.com/single-post/2017/02/27/Reverse-Engineering-Malware-Part-2-Assembler-Language-Basics](https://www.hackers-arise.com/single-post/2017/02/27/Reverse-Engineering-Malware-Part-2-Assembler-Language-Basics) ).
