## 24. nproc: Print the number of processing units available.

The `nproc` command in Linux is a simple yet powerful utility that provides information about the number of processing units available on a system. It essentially displays the number of processing units (or cores) that the system has.

### Examples:

- 1. Basic Usage:

```
nproc
```

This will output the total number of processing units available on the system.

- 2. Display Number of Cores:

```
echo "Number of cores: $(nproc)"
```

This command uses command substitution (`$(nproc)`) to embed the result of `nproc` in the output message.

- 3. Specify the Maximum Number of Processors:

```
nproc --all
```

This option, `--all` or `-a`, displays the maximum number of processors available, including online and offline processors.

- 4. Show Physical Cores:

```
nproc --sockets
```

This option, `--sockets` or `-s`, displays the number of physical sockets (processors).

- 5. Display Threads per Core:

```
nproc --threads
```

This option, `--threads` or `-T`, shows the number of threads per core.

- 6. Display Online Processors:

```
nproc -online
```

This option, `-online` or `-o`, displays the number of online processors (active processors).

- 7. Check if a Specific Number of Cores is Available:

```
if [ "$(nproc)" -ge 4 ]; then

```

This example demonstrates the use of `nproc` within a script to check the number of cores available.

echo "This system has $(nproc) cores and $(free -m | awk '/^Mem:/ {print $2}') megabytes of RAM."

## 25. awk: A text processing tool for pattern scanning and processing.

AWK is a powerful programming language and command-line utility used in Unix and Linux environments for text processing. It is particularly useful for processing and analyzing text files, extracting specific information, and performing data manipulation tasks.

### Examples:

- 1. Print Specific Columns:

To print specific columns from a file, use the `print` statement.

```
# Print the first and third columns of a file
awk '{print $1, $3}' filename
```

- 2. Filtering Data:

AWK can be used to filter data based on a condition.

```
# Print lines where the second column is greater than 50
awk '$2 > 50 {print}' filename
```

- 3. Calculations:

AWK is capable of performing calculations on data.

```
# Calculate and print the average of the third column
awk '{sum += $3} END {print "Average:", sum/NR}' filename
```

- 4. Pattern Matching:

Use patterns to match specific lines.

```
# Print lines containing the word "error"
awk '/error/ {print}' filename
```

- 5. Conditional Statements:

AWK supports conditional statements.

```
# Print "Pass" or "Fail" based on the value in the second column
awk '{if ($2 >= 50) print "Pass"; else print "Fail"}' filename
```

- 6. Field Separator:

Specify a custom field separator using the `-F` option.

```
# Print the second field using ":" as the separator
awk -F: '{print $2}' filename
```

- 7. Built-in Variables:

AWK has several built-in variables. For example, `NF` represents the number of fields in a line.

```
# Print lines with more than 3 fields
awk 'NF > 3 {print}' filename
```

- 8. Reading from Command Output:

AWK can read from the output of other commands.

```
# List files and their sizes in the current directory
ls -l | awk '{print $9, $5}'
```

- 9. Formatting Output:

Use `printf` for better formatting.

```
# Print the first and second columns with specific formatting
awk '{printf "Name: %-10s Score: %d\n", $1, $2}' filename
```

- 10. Multiple Commands:

Execute multiple commands with curly braces.

```
# Print the first and second columns, then calculate and print their sum
awk '{print $1, $2; sum += $2} END {print "Sum:", sum}' filename
```

## 26. sed: A stream editor for filtering and transforming text.

`sed` stands for stream editor and is a powerful text processing tool in Linux. It is used for performing basic text transformations on an input stream (a file or input from a pipeline) and producing an output stream. `sed` is often used for substitution, deletion, insertion, and other text manipulations in scripts and one-liners.

### Examples:

- 1. Substitute text in a file:

```
sed 's/apple/orange/' fruits.txt
```

This command replaces the first occurrence of "apple" with "orange" in the file `fruits.txt` and prints the result to the standard output.

- 2. Substitute all occurrences globally:

```
sed 's/apple/orange/g' fruits.txt
```

This command replaces all occurrences of "apple" with "orange" in the file `fruits.txt`.

- 3. Delete lines containing a specific pattern:

```
sed '/pattern/d' file.txt
```

This command deletes all lines containing the specified pattern from the file `file.txt`.

- 4. Print specific lines:

```
sed -n '1,5p' file.txt
```

This command prints lines 1 to 5 from the file `file.txt` without automatically printing other lines.

- 5. In-place editing (update the file):

```
sed -i 's/old/new/' file.txt
```

This command replaces the first occurrence of "old" with "new" in the file `file.txt` and updates the file in place.

## 28. gzip: Compress or decompress files.

The `gzip` command in Linux is used for file compression and decompression. It is named after the GNU zip compression algorithm it uses.

### Examples:

- 1. Compress a File:

```
gzip example.txt
```

This compresses the file `example.txt` and creates a compressed file named `example.txt.gz`.

- 2. Decompress a File:

```
gzip -d example.txt.gz
```

Decompresses the file `example.txt.gz` and restores it to `example.txt`.

- 3. Keep Original File:

```
gzip -k example.txt
```

Compresses `example.txt` and keeps the original file, resulting in both `example.txt` and `example.txt.gz` coexisting.

- 4. Recursive Compression:

```
gzip -r my_directory
```

Recursively compresses all files in the directory `my_directory`.

- 5. Test Compressed File:

```
gzip -t example.txt.gz
```

Tests the integrity of the compressed file `example.txt.gz`.

- 6. Verbose Output:

```
gzip -v example.txt
```

Displays the compression ratio and file sizes during the compression of `example.txt`.
