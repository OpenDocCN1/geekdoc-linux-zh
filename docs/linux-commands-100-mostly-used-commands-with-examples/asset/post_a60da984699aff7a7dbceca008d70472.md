## 96. renice: Alter priority of running processes

The `renice` command in Linux is used to alter the scheduling priority of running processes. This command allows you to change the nice value of a process, which determines its priority in the system scheduler. The nice value ranges from -20 to 19, with lower values indicating higher priority.

**Examples:**

- 1. **Change the priority of a specific process by ID**

```bash
renice 10 -p 1234
```

This command increases the priority of the process with ID 1234 to a nice value of 10.

- 2. **Change the priority of a process group**

```bash
renice -5 -g 5678
```

This command decreases the priority of all processes in the process group with ID 5678 to a nice value of -5.

- 3. **Change the priority of all processes owned by a user**

```bash
renice 3 -u username
```

This command raises the priority of all processes owned by the user "username" to a nice value of 3.

- 4. **View the current priorities of processes**

```bash
renice -p 5678
```

This command shows the current priority of the process with ID 5678.

## 97. sync: Synchronize cached writes to persistent storage

The `sync` command in Linux is used to ensure that all pending changes to the file system are written to disk. It helps in synchronizing the system's in-memory data with the data on the disk, reducing the risk of data loss in case of unexpected shutdowns or power failures. The `sync` command does not directly flush the file system buffers but schedules them to be flushed at the earliest opportunity.

**Examples:**

- 1. **Basic Usage**

```bash
sync
```

This command by itself synchronizes all file system buffers.

- 2. **Using with File Descriptors**

```bash
sync; echo 3 > /proc/sys/vm/drop_caches
```

This sequence first synchronizes the file system buffers and then clears the page cache, dentries, and inodes.

- 3. **With Options**

```bash
sync -f -d -v
```

- `-f`: Force the sync operation even if file systems are clean.
- `-d`: Enable disk write caching.
- `-v`: Verbose mode.

- 4. **Sync before Shutdown**

```bash
sync && shutdown -h now
```

This command syncs the file system and then initiates a system shutdown.

- 5. **Viewing Sync Progress**

```bash
watch -n 1 sync
```

This updates the sync status every second.

## 98. tcpdump: Capture and display network traffic

`tcpdump` is a powerful command-line packet analyzer tool that allows you to capture and display network traffic on a Linux system. It is widely used for network troubleshooting, analysis, and security auditing.

**Examples:**

- 1. **Capture all packets on a specific interface**

```bash
tcpdump -i eth0
```

This command captures all packets on the `eth0` interface.

- 2. **Capture packets with a specific source or destination IP address**

```bash
tcpdump host 192.168.1.2
```

This captures packets where the IP address 192.168.1.2 is either the source or destination.

- 3. **Capture packets on a specific port**

```bash
tcpdump port 80
```

This captures packets on port 80.

- 4. **Capture packets from a specific IP and port**

```bash
tcpdump src 192.168.1.2 and port 22
```

This captures packets where the source IP is 192.168.1.2 and the port is 22.

- 5. **Capture and display packet details in verbose mode**

```bash
tcpdump -v
```

This command provides more detailed information about each captured packet.

- 6. **Capture a specific number of packets**

```bash
tcpdump -c 10
```

This captures and displays the first 10 packets, then exits.

- 7. **Write captured packets to a file**

```bash
tcpdump -w capture.pcap
```

This writes the captured packets to a file named `capture.pcap`, which can be later analyzed using tools like Wireshark.

- 8. **Read packets from a file**

```bash
tcpdump -r capture.pcap
```

This reads and displays packets from the specified `capture.pcap` file.

- 9. **Capture only TCP or UDP packets**

```bash
tcpdump tcp
```

or

```bash
tcpdump udp
```

This captures only TCP or UDP packets, respectively.

- 10. **Capture packets with specific protocol**

```bash
tcpdump icmp
```

This captures only ICMP (ping) packets.

- 11. **Capture non-verbose output**

```bash
tcpdump -q
```

This provides less detailed, quiet output.
