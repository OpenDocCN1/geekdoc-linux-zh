
`rsync` is a powerful and versatile command-line utility for synchronizing files and directories between two locations on a Unix-like operating system. It efficiently transfers only the differences between source and destination, making it particularly useful for remote backups or mirroring.

### Examples

#### 1. Basic Sync

```
rsync -av /path/to/source/ /path/to/destination/
```

This command synchronizes the contents of the source directory to the destination directory, preserving permissions and other attributes.

#### 2. Remote Sync

```
rsync -avz -e ssh user@remote:/path/to/source/ /path/to/destination/
```

Synchronize files between a local machine and a remote machine over SSH. Replace `user` with the username and `remote` with the remote machine's IP or hostname.

#### 3. Exclude Files

```
rsync -av --exclude="*.log" /path/to/source/ /path/to/destination/
```

Sync source to destination excluding files with a `.log` extension.

#### 4. Dry Run

```
rsync -av --dry-run /path/to/source/ /path/to/destination/
```

Perform a dry run to see what changes would be made without actually transferring any files.

#### 5. Show Progress

```
rsync -avP /path/to/source/ /path/to/destination/
```

Show progress during the transfer, indicating the percentage completion and transfer rate.

## 53. killall: Kill processes by name

## 57. w: Show who is logged in and what they are doing

The `w` command in Linux is used to display information about the users currently logged in and their activities. It provides a quick overview of who is logged in, what they are doing, and how long they have been idle.

### Examples

- 1. Display Information about Currently Logged-In Users:
```
w
```
This command will display information about the users currently logged in, including their username, terminal, remote host (if applicable), login time, idle time, JCPU (total CPU time used by all processes attached to the terminal), PCPU (the CPU time used by the current process), and the command being executed.

- 2. Display Information with Header:
```
w -h
```
Adding the `-h` option suppresses the header line, providing a more compact display of user information.

- 3. Display Information for a Specific User:
```
w username
```
Replace "username" with the actual username you want to display information for. This will show details about the specified user only.

- 4. Display Information for a Specific Terminal:
```
w -s
```
The `-s` option sorts the output by the terminal names, making it easier to see who is using a particular terminal.

- 5. Display Information in Short Format:
```
w -s -f
```
The `-f` option provides a shorter output format, displaying only the user, terminal, login time, JCPU, and PCPU.

- 6. Display Information with More Details:
```
w -i
```
The `-i` option provides additional information about system idle time and the time since the system was last booted.

- 7. Display Information with Load Average:
```
w -l
```
The `-l` option adds the system load average to the output. The load average represents the average number of processes waiting for CPU time over a specific period (1, 5, and 15 minutes).

- 8. Display Information in a Specific Format:
```
w -o user,time,from
```
The `-o` option allows you to specify the format of the output. In this example, the format includes user, time, and from (remote host).
