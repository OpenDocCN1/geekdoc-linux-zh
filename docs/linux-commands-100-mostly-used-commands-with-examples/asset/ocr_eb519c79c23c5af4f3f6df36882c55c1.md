+   4. **Monitoring Specific Processes by PID:**

```
top -p 1234,5678
```

Monitors processes with the specified process IDs (PID) - 1234 and 5678 in this example.

+   5. **Exiting After a Number of Iterations:**

```
top -n 5
```

Runs `top` for 5 iterations and then exits.

The `df` command in Linux is used to display information about disk space usage on the file system. It provides details on the total disk space, used space, available space, and the percentage of used space on each mounted file system. This command is particularly useful for monitoring disk space and identifying storage issues.

**Examples:**

+   1. **Display disk space usage for all mounted file systems:**

df
