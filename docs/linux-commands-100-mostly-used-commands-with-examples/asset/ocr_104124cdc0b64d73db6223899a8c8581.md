4. Limit the depth of the tree to 2 levels:

```
tree -L 2
```

5. Display only directories in the tree:

```
tree -d
```

6. Exclude specific directories from the tree:

```
tree --prune dir_to_exclude
```

7. Invert match to display files that do not match a pattern:

```
tree -i -P "*.txt"
```
