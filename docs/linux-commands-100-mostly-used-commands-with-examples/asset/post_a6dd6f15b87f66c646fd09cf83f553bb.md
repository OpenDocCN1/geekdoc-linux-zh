## 12. chmod: Change file permissions.

`chmod` is a Linux command that is used to change the permissions of files and directories. The name "chmod" stands for "change mode," and it allows you to control who can read, write, and execute a file.

### Mode:

The mode consists of three components: user, group, and others, each with read (`r`), write (`w`), and execute (`x`) permissions. Additionally, you can use numeric representations to set permissions.

- Symbolic representation:
  - `u` for user
  - `g` for group
  - `o` for others
  - `a` for all (equivalent to `ugo`)
- Permission Symbols:
  - `r` for read
  - `w` for write
  - `x` for execute
- Operators:
  - `+` to add permissions
  - `-` to remove permissions
  - `=` to set permissions explicitly
- File:
  The file or directory for which you want to modify permissions.

**Examples:**

1. **Grant read and write permissions to the owner of the file:**

```
chmod u+rw file.txt
```

2. **Remove execute permission from the group for a script:**

```
chmod g-x script.sh
```

3. **Give read and execute permissions to everyone for a directory and its contents recursively:**

```
chmod -R a+rx directory/
```

4. **Set specific permissions using numeric representation (read: 4, write: 2, execute: 1):**

```
chmod 754 file.txt
```

In this example, the user has read, write, and execute (4+2+1 = 7), the group has read and execute (4+1 = 5), and others have read-only (4).

## 13. chown: Change file owner or group.

The `chown` command in Linux is used to change the ownership of files or directories. Ownership refers to the user and group associated with a file or directory. This command is particularly useful when you need to transfer ownership of files or directories from one user to another.

**Examples:**

- 1. **Basic Usage - Change Ownership of a File:**

```
chown newowner:newgroup myfile.txt
```

This command changes the ownership of `myfile.txt` to the user `newowner` and the group `newgroup`.

- 2. **Recursive Ownership Change for a Directory:**

```
chown -R newowner:newgroup mydirectory
```

This command recursively changes the ownership of all files and subdirectories within `mydirectory` to the user `newowner` and the group `newgroup`.

- 3. **Verbose Output:**

```
chown -c newowner:newgroup myfile.txt
```

This command provides a verbose output, indicating the changes made to the ownership of `myfile.txt`.

- 4. **Changing Ownership Based on Current Owner:**

```
chown --from=currentowner:currentgroup newowner:newgroup myfile.txt
```

This command changes the ownership of `myfile.txt` from the current owner `currentowner` and group `currentgroup` to the new owner `newowner` and group `newgroup`.

## 15. kill: Terminate a process.

The `kill` command in Linux is used to send signals to processes, allowing you to terminate or manipulate their behavior.

**Examples:**

- 1. **Terminate a process with default signal:**

```
kill 1234
```

This sends the SIGTERM signal to the process with PID 1234.

- 2. **Forcefully terminate a process:**

```
kill -9 5678
```

This sends the SIGKILL signal to the process with PID 5678, forcefully terminating it.

- 3. **Restart a process:**

```
kill -HUP 9876
```

This sends the SIGHUP signal to the process with PID 9876, which is often used to restart a process.

- 4. **Pause a process:**

```
kill -STOP 1111
```

This sends the SIGSTOP signal to the process with PID 1111, pausing it.

- 5. **Resume a paused process:**

```
kill -CONT 1111
```

This sends the SIGCONT signal to the paused process with PID 1111, resuming its execution.

## 16. top: Display real-time system statistics.

The `top` command in Linux is a powerful utility that provides a real-time, dynamic overview of system performance. It displays information about processes, system resource usage, and other important statistics. The `top` command is particularly useful for monitoring system activity, identifying resource-hungry processes, and understanding overall system health.

**Examples:**

- 1. **Displaying a Dynamic Overview:**

```
top
```

This will launch `top` in its interactive mode, showing real-time information about processes and system resources.

- 2. **Setting Update Interval:**

```
top -d 5
```

Launches `top` with a 5-second update interval, providing information every 5 seconds.

- 3. **Monitoring Specific User's Processes:**

```
top -u username
```

Displays information about processes owned by the specified user (`username`).

- 4. **Monitoring Specific Processes by PID:**

```
top -p 1234,5678
```

Monitors processes with the specified process IDs (PID) - 1234 and 5678 in this example.

- 5. **Exiting After a Number of Iterations:**

```
top -n 5
```

Runs `top` for 5 iterations and then exits.
