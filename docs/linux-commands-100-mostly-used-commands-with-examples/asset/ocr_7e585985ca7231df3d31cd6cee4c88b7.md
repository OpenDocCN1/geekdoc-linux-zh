```
export PATH=$PATH:/usr/local/bin
```

This adds `/usr/local/bin` to the end of the `PATH` environment variable. It is often used to include directories containing executable files.

# 3. Setting Variables for Subsequent Commands:

```
export EDITOR=vim
```

This sets the default text editor to Vim. Subsequent commands that rely on the `EDITOR` variable will use Vim.

# 4. Exporting Variables for Use in Subshells:

```
export MY_VARIABLE="Hello, Subshell!"
(echo $MY_VARIABLE)
```

In this example, the variable is set and then accessed within a subshell. The parentheses start a subshell, and the variable is available within that scope.
