```
lsblk
```

This command without any options displays a hierarchical list of all block devices on the system.

2. Display Filesystem Information:

```
lsblk -f
```

This option includes information about the filesystem type on each device.

3. Display Sizes in Bytes:

```
lsblk -b
```

Prints sizes in bytes instead of the default human-readable format.

4. Show All Devices, Including Empty Ones:

```
lsblk -a
```
