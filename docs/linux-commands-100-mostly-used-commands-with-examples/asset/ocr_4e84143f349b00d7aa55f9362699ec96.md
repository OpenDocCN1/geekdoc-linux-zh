```
touch existingfile.txt
```

This command updates the access and modification timestamps of `existingfile.txt` to the current time.

3. **Change only the access time:**

```
touch -a file.txt
```

This command updates only the access timestamp of `file.txt` .

4. **Change only the modification time:**

```
touch -m file.txt
```

This command updates only the modification timestamp of `file.txt` .

5. **Use a specified date and time:**

```
touch -d "2023-11-10 12:30" file.txt
```
