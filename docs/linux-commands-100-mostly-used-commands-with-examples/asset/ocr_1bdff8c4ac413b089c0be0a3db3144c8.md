# **52. uptime: Display how long the system has been running.**

The `uptime` command in Linux is a simple yet powerful tool that provides information about how long a system has been running, as well as some key performance metrics.

**Examples:**

1. **Display only uptime information:**

```
uptime -p
```

This command will display only the uptime information in a more human-readable format.

2. **Display short output:**

```
uptime -s
```

This command shows the system’s start time.

3. **Display load averages only:**

```
uptime -q
```
