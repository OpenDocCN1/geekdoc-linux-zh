# **30. ping: Test the reachability of a host on an IP network.**

The `ping` command is a network utility tool used to test the reachability of a host on an Internet Protocol (IP) network. It also measures the round-trip time for messages sent from the originating host to a destination computer. The name "ping" comes from the sonar sound used by submarines to detect other objects in the water.

**Examples:**

+   1. **Simple Ping:**

```
ping google.com
```

This will send a series of ICMP Echo Requests to google.com, and you'll see the round-trip time for each packet.

+   2. **Set Number of Packets:**

```
ping -c 4 google.com
```
