Displays logs only for the current boot.

# **6. Viewing Logs for a Specific Boot Sequence:**

```
journalctl -b -1
```

Replace `-1` with the boot sequence number to view logs for a specific previous boot.

# **7. Viewing Logs Within a Time Range:**

```
journalctl --since "2023-01-01 00:00:00" --until "2023-01-02 23:59:59"
```

Use the `--since` and `--until` options to view logs within a specific time range.

# **8. Displaying Logs with Full Details:**

```
journalctl -xe
```

The `-x` option displays the full details of each log entry, including the message and additional fields.
