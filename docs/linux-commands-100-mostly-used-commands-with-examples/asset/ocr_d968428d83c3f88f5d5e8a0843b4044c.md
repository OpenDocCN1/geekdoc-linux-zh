```
iftop -F 80
```

Displays only the connections using port 80. You can use other port numbers as needed.

4. Displaying Timestamps:

```
iftop -t
```

Adds a timestamp to each line of output.

5. Monitor Specific Interface:

```
iftop -i eth0
```

Monitors only the traffic on the specified network interface (replace `eth0` with your actual interface name).

6. Do Not Resolve Hostnames:

```
iftop -n
```
