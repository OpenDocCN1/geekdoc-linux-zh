# **64. iftop: Display bandwidth usage on an interface.**

`**iftop**` is a command-line network bandwidth monitoring tool for Linux. It shows a list of network connections between your system and others and displays information about the data rate and data for each connection.

**Examples:**

**1. Basic Usage:**

```
iftop
```

This will start `**iftop**` in interactive mode, displaying a list of connections, data rates, and total data transferred.

**2. Display Bytes per Second:**

```
iftop -B
```

Shows bandwidth in bytes per second instead of the default bits per second.
