- Operators:
    - `+` to add permissions
    - `-` to remove permissions
    - `=` to set permissions explicitly
- File:
    The file or directory for which you want to modify permissions.

# **Examples:**

1. **Grant read and write permissions to the owner of the file:**

```
chmod u+rw file.txt
```

2. **Remove execute permission from the group for a script:**

```
chmod g-x script.sh
```

3. **Give read and execute permissions to everyone for a directory and its contents recursively:**

```
chmod -R a+rx directory/
```
