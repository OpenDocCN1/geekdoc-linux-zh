```
stat -t filename
```

This displays information in a terse form, which is useful for scripting or extracting specific details.

3. **Display File System Information:**

```
stat -f filename
```

This shows information about the file system on which the file resides, including the total and free space.

4. **Display Information for Multiple Files:**

```
stat file1 file2
```

You can provide multiple files as arguments to get information about each of them.

5. **Custom Output Format:**

```
stat --format="File: %n Size: %s bytes" filename
```
