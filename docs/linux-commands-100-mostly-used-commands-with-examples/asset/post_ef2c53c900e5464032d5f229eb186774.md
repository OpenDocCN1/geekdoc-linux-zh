
# 85. head: Display the first lines of a file.

`head` 命令用于显示文件的开头部分。默认情况下，它显示前 10 行。

**Examples:**

1. **Display the first 10 lines of a file (default):**

```bash
head filename.txt
```

2. **Display a specific number of lines (e.g., 5) from a file:**

```bash
head -n 5 filename.txt
```

3. **Display the first 20 bytes of a file:**

```bash
head -c 20 filename.txt
```

4. **Display headers only when multiple files are specified:**

```bash
head -q file1.txt file2.txt
```

5. **Display headers always, even for a single file:**

```bash
head -v filename.txt
```

6. **Combine `head` with other commands using pipes (|):**

```bash
cat filename.txt | head -n 8
```

This example shows the first 8 lines of a file using `head` after displaying the entire file content with `cat`.

7. **Display the first few lines of a command output:**

```bash
ls -l | head
```

This displays the first 10 lines of the output from the `ls -l` command.

8. **Display the first 3 lines of multiple files:**

```bash
head -n 3 file1.txt file2.txt
```

This command displays the first 3 lines of both `file1.txt` and `file2.txt`.

9. **Display the first N lines of all text files in a directory:**

```bash
head -n N *.txt
```

Replace N with the desired number of lines. This command shows the first N lines of every text file in the current directory with a ".txt" extension.

# 86. chsh: Change login shell.

The `chsh` command in Linux is used to change the default login shell for a user. The term "shell" refers to the command interpreter that allows users to interact with the operating system. Each user on a Linux system is assigned a default shell, and `chsh` provides a way to modify that setting.

**Examples:**

1. **Change the default shell for the current user:**

```bash
chsh -s /bin/zsh
```

This command changes the default shell for the currently logged-in user to Zsh. You need to provide the full path to the desired shell (in this case, `/bin/zsh`).

2. **Change the default shell for a specific user:**

```bash
chsh -s /bin/bash username
```

Replace "username" with the actual username of the user for whom you want to change the default shell. This example changes the default shell to Bash.

3. **List available shells:**

```bash
chsh -l
```

This command lists all the available shells on the system. The output will display the paths to the available shells.

4. **Interactive mode:**

```bash
chsh
```

Running `chsh` without any options will prompt you to enter the desired shell. It will interactively ask for the new shell's path. Simply enter the path and press Enter.

5. **Change the default shell to the user's current shell:**

```bash
chsh -s "$(which zsh)"
```

This example uses the `which` command to get the path of the current user's shell (Zsh in this case) and sets it as the default shell.

6. **Change the default shell for another user as root:**

```bash
sudo chsh -s /bin/fish username
```

This command allows the system administrator (root) to change the default shell for another user. Replace "username" with the actual username, and `/bin/fish` with the desired shell.

# 87. stat: Display file or file system status.

The `stat` command in Linux is used to display detailed information about a file or file system. It provides a comprehensive set of details, including file type, access permissions, inode number, UID (user ID), GID (group ID), size, and timestamps for the last access, modification, and status change.

**Examples:**

1. **Display Basic Information:**

```bash
stat filename
```

This provides basic information about the file, including size, permissions, and timestamps.

2. **Display Information in Terse Format:**

```bash
stat -t filename
```

This displays information in a terse form, which is useful for scripting or extracting specific details.

3. **Display File System Information:**

```bash
stat -f filename
```

This shows information about the file system on which the file resides, including the total and free space.

4. **Display Information for Multiple Files:**

```bash
stat file1 file2
```

You can provide multiple files as arguments to get information about each of them.

5. **Custom Output Format:**

```bash
stat --format="File: %n Size: %s bytes" filename
```

Customize the output format using control characters. `%n` represents the file name, and `%s` represents the file size.

6. **Follow Symbolic Links:**

```bash
stat -L symlink
```

If the file is a symbolic link, this command displays information about the linked file rather than the link itself.

7. **Display Information Recursively:**

```bash
find /path/to/directory -type f -exec stat {} \;
```

Use `find` with `exec` to apply `stat` recursively to all files in a directory.

8. **Display Inode Number:**

```bash
stat --format="Inode: %i" filename
```

`%i` represents the inode number of the file.

9. **Human-Readable Output:**

```bash
stat --format="Size: %s bytes" --printf="%h\n" filename
```

`%h` in `--printf` provides human-readable file size.

# 88. watch: Execute a command repeatedly and display the results.

The `watch` command in Linux is a handy utility that allows you to execute a given command periodically and display the results in real-time. This can be particularly useful for monitoring changes or updates in the output of a command without having to rerun it manually each time.

**Examples:**

1. **Simple Usage:**

```bash
watch date
```

This will continuously update and display the current date and time every 2 seconds (by default).

2. **Monitor Disk Space:**

```bash
watch df -h
```

This command will periodically display the disk space usage, updating every 2 seconds by default.

3. **Check System Resource Usage:**

```bash
watch -n 1 top
```

The `-n` option allows you to specify the update interval in seconds. In this example, `top` will be refreshed every 1 second, providing real-time information about system resource usage.

4. **Monitor Log Files:**

```bash
watch -n 5 tail /var/log/syslog
```

This example watches the system log file, updating every 5 seconds. It can be useful for keeping an eye on log entries as they occur.

5. **Track File Changes:**

```bash
watch -d ls -l
```

The `-d` option highlights the differences between successive updates. In this case, it shows changes in the file listing with each refresh.

6. **Monitor Network Connections:**

```bash
watch -n 2 ss -t -a
```

This example uses the `ss` command to display information about TCP socket connections. It refreshes every 2 seconds.

7. **Customize Update Interval:**

```bash
watch -n 10 free -m
```

Here, the update interval is set to 10 seconds, and the command `free -m` is used to display memory usage in megabytes.

8. **Highlight Command Output Changes:**

```bash
watch -d 'ps aux | grep ssh'
```

The `-d` option highlights the differences in the output of the command `ps aux | grep ssh` with each update, making it easy to spot changes.

9. **Watch a Script:**

```bash
watch ./myscript.sh
```

You can use `watch` to continuously monitor the output of a script. Replace `./myscript.sh` with the path to your script.

10. **Combine Multiple Commands:**

```bash
watch 'echo "Hello" && date && df -h'
```

You can use a compound command within single quotes after `watch` to execute multiple commands sequentially and see their output.

# 89. shutdown: Shut down or restart the system.

The `shutdown` command in Linux is used to bring the system down in a secure and organized manner. It allows you to schedule a system shutdown or reboot, giving users a warning and preventing new logins.

**Examples:**

1. **Shutdown immediately:**

```bash
sudo shutdown now
```

2. **Schedule a shutdown in 10 minutes:**

```bash
sudo shutdown +10
```

The system will be shut down in 10 minutes.

3. **Schedule a shutdown at a specific time:**

```bash
sudo shutdown 22:00
```

This command schedules a shutdown at 10:00 PM.

4. **Display a custom message before shutdown:**

```bash

```
