```
sudo hostname newhostname
```

This command sets a new host name for the system temporarily.

+   4. **Set a new host name persistently (requires system reboot):**

```
sudo hostnamectl set-hostname newhostname
```

This command sets a new host name for the system, and the change will persist across reboots. It uses `hostnamectl`, which is a tool for querying and changing system hostname and related settings.

+   5. **View the static host name (configured in /etc/hostname):**

```
cat /etc/hostname
```

The static host name is often configured in the `/etc/hostname` file. This command displays the content of that file.

+   6. **Edit the static host name using a text editor:**

```
sudo nano /etc/hostname
```
