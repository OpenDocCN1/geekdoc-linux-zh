This example will measure the time it takes to execute the `ls` command.

# 2. **Display More Detailed Information:**

```
time -v ls
```

The `-v` option provides more detailed information, including the CPU usage, system and user time.

# 3. **Redirect Output:**

```
time -o output.txt ls
```

You can redirect the output to a file using the `-o` option.

# 4. **Time a Pipeline:**

```
time (command1 | command2)
```

You can also time a pipeline of commands by enclosing them in parentheses.
