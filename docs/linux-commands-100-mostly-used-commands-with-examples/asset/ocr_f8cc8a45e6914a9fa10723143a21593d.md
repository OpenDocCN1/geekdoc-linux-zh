# 6. cp: Copy files or directories.

The `cp` command in Linux is used to copy files and directories from one location to another. It is a fundamental command for file manipulation and is part of the GNU core utilities.

Examples:

1. Copy a file to another location:

```
```
cp file.txt /path/to/destination/
```
```

2. Copy a directory and its contents recursively:

```
```
cp -r /path/to/source_directory/ /path/to/destination/
```
```

3. Prompt before overwriting an existing file:

```
```
cp -i file.txt /path/to/destination/
```
```

4. Copy only if source is newer or destination is missing:

```
```
cp -u file.txt /path/to/destination/
```
```
