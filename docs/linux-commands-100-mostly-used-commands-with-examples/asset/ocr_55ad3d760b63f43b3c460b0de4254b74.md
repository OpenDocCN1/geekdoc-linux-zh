# 8. Dry Run (Test):

```
umount -n /mnt/data
```

Simulates the unmount operation without actually detaching the filesystem. Useful for testing.

# 9. Unmounting NFS Share:

```
umount -t nfs server:/mnt/share
```

Unmounts an NFS (Network File System) share.

# 10. Unmounting CIFS Share:

```
umount -t cifs //server/share /mnt/cifs
```

Unmounts a CIFS (Common Internet File System) share.
