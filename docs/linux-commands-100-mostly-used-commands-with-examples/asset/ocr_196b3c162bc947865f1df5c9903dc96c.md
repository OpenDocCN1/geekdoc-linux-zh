```
journalctl -f
```

The `-f` option allows you to follow the journal in real-time, similar to the `tail -f` command for traditional log files.

# 3. Viewing the Last 'n' Lines of the Journal:

```
journalctl -n 50
```

Use the `-n` option to specify the number of lines to display from the end of the journal.

# 4. Viewing Logs for a Specific Unit (Service):

```
journalctl -u apache2
```

This command displays logs related to the Apache web server. Replace `apache2` with the name of any other systemd unit.

# 5. Viewing Logs for the Current Boot:

```
journalctl -b
```
