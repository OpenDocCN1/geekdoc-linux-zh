```
# 2. Changing Background Colors:

```
```text
tput setab 4  # Set background color to blue
echo "This has a blue background"
tput sgr0     # Reset text attributes to default
```

```
# 3. Formatting Text:

```
```text
tput bold     # Set bold text

tput sgr0     # Reset text attributes to default
```
