## 81. locate: Find the location of files and directories on the system.

`locate` is a command-line utility in Linux used for finding the location of files and directories on the system. It relies on a pre-built index of files and their locations, making it a faster alternative to searching the file system directly.

### Examples:

+   1. **Search for a File:**

```
locate myfile.txt
```

This command will search for and display the paths of all files named `myfile.txt` on the system.

+   2. **Case-Insensitive Search:**

```
locate -i MyFile.txt
```

The `-i` option makes the search case-insensitive, so it will match files like `myfile.txt`, `MyFile.txt`, and so on.

+   3. **Limit Search to Specific Directories:**

```
locate -r '/home/user/*.txt'
```

The `-r` option allows you to use regular expressions. This example searches for all files with a `.txt` extension in the `/home/user/` directory.

+   4. **Update the Locate Database:**

```
sudo updatedb
```

`locate` relies on a database that needs to be periodically updated. The `updatedb` command is used to refresh this database. It's typically run with `sudo` because it may need access to system files.

+   5. **Display Number of Matches:**

```
locate -c myfile.txt
```

The `-c` option counts the number of matches without displaying the actual paths.

+   6. **Display Paths Relative to Root:**

```
locate -r '^/etc\.\*\.conf$'
```

This example uses a regular expression to find all files in the `/etc` directory with a `.conf` extension. The `^` signifies the start of the path.

+   7. **Suppress Warnings:**

```
locate -q myfile.txt
```

The `-q` option suppresses warnings about unreadable directories and permissions.

+   8. **Display Version Information:**

```
locate --version
```

Shows the version information of the `locate` command.

+   9. **Help:**

```
man locate
```

Displays the manual page for the `locate` command, providing detailed information on its usage and options.

## 82. last: Show a listing of last logged in users.

The `last` command in Linux is used to display information about the last logged-in users on the system. It extracts data from the `/var/log/wtmp` file, which keeps track of login and logout activity.

### Examples:

+   1. **Display the last logged-in users:**

```
last
```

This will display a list of users who have logged in, along with their login and logout times, as well as the duration of their sessions.

+   2. **Display the last 5 logins:**

```
last -n 5
```

This command shows the last 5 logins, providing a more concise output.

+   3. **Display the last login for a specific user:**

```
last username
```

Replace `username` with the actual username you want to check. This will show the login/logout history for that specific user.

+   4. **Display only the reboot entries:**

```
last reboot
```

This command shows a list of system reboots along with the corresponding times.

+   5. **Display the logins on a specific date:**

```
last -F YYYYMMDD
```

Replace `YYYYMMDD` with the desired date in the format Year-Month-Day (e.g., 20231110 for November 10, 2023). This will display logins only on that specific date.

+   6. **Display the logins for a specific period:**

last -s YYYY-MM-DD -t YYYY-MM-DD

+   8. **Display hostname in the output:**

```
last -a
```

## 83. stty: Change and print terminal line settings.

The `stty` command in Linux is used to change and print terminal line settings. It allows users to configure various aspects of the terminal interface, such as input and output settings, control characters, and more.

### Examples:

+   1. **Display Current Terminal Settings:**

```
stty -a
```

This command displays all the current settings of the terminal.

+   2. **Change Erase Character:**

```
stty erase ^H
```

This changes the erase character to `Ctrl + H` (backspace). You can replace `^H` with the appropriate control character.

+   3. **Disable Echoing (Password Entry):**

```
stty -echo
```

This command turns off the echoing of characters as you type. Useful for password entry.

+   4. **Enable Echoing:**

```
stty echo
```

This command turns on the echoing of characters.

+   5. **Change Terminal Size:**

```
stty rows 40 cols 80
```

This sets the terminal size to 40 rows and 80 columns. Adjust the values according to your needs.

+   6. **Ignore Interrupt Signal (Ctrl + C):**

```
stty intr ""
```

This command ignores the interrupt signal (`Ctrl + C`). The double quotes indicate an empty string.

+   7. **Restore Default Terminal Settings:**

```
stty sane
```

This command restores the terminal to a sane state, reverting any changes made with `stty`.

+   8. **Disable Flow Control (Ctrl + S and Ctrl + Q):**

```
stty -ixon
```

This disables software flow control, allowing you to use `Ctrl + S` and `Ctrl + Q` for other purposes.

+   9. **Set Input and Output Speed:**

```
stty speed 9600
```

This sets the input and output speed to 9600 baud. Adjust the value based on your requirements.

+   10. **Set Terminal to Raw Mode:**

```
stty raw
```

This puts the terminal into raw mode, where input is passed through without any processing (useful for some interactive applications).

## 84. tail: Display the last part of a file.

The `tail` command in Linux is a powerful utility that allows you to display the last few lines of a text file or a stream of data. It is particularly useful for monitoring log files in real-time or quickly checking the end of a large file.

### Examples:

+   1. **Display the last 10 lines of a file:**

```
tail filename
```

+   2. **Display a specific number of lines from the end of a file:**

```
tail -n 20 filename
```

This will display the last 20 lines of the file.

+   3. **Follow a file in real-time (similar to `tail -f`):**

```
tail -f filename
```

This is commonly used to monitor log files as new lines are added.

+   4. **Display and continuously update the last 10 lines of a file:**

```
tail -n 10 -f filename
```

+   5. **Display the last part of a file, and update it as new data is added:**

```
tail -c 500 filename
```

This will display the last 500 bytes of the file.

+   6. **Display lines that are added to a file after a certain point in time:**

```
tail -n +5 filename
```

This will display all lines starting from the 5th line to the end of the file.

+   7. **Display lines added to a file, but only show the changes:**

```
tail -n 10 -f filename | grep "pattern"
```

This will show only the lines that contain the specified pattern as new lines are added.

+   8. **Display lines in reverse order (from the end to the beginning):**

```
tac filename | tail -n 10
```

Note: `tac` is the reverse of `cat`, and it's not available on all systems.

+   9. **Display multiple files simultaneously:**

```
tail -n 5 file1 file2
```

This will display the last 5 lines of both files.
