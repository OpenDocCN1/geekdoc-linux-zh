# Examples:

+   1. **To analyze the disk usage of the current directory:**
+   
+       `ncdu`

+   2. **To analyze the disk usage of a specific directory:**
+   
+       `ncdu /path/to/directory`

+   3. **To exclude certain files or directories from the analysis:**
+   
+       `ncdu -x "*.log" /path/to/directory`

+   4. **To run in read-only mode to prevent accidental deletions:**
+   
+       `ncdu -r /path/to/directory`
