The `ls` command is a fundamental command in Linux and Unix-like operating systems used to list files and directories in a directory.

# Examples:

+   1. **List files and directories in the current directory:**

```
```
ls
```
```

+   2. **List files and directories in a specific directory:**

```
```
ls /path/to/directory
```
```

+   3. **List files in long format with human-readable sizes and hidden files:**

```
```
ls -l -h -a
```
```

+   4. **List all files and directories recursively:**

```
```
ls -R
```
```
