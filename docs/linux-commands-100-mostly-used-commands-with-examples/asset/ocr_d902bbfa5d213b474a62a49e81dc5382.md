Examples:

# 1. **Viewing Network Interfaces**:

```
ip link show
```

This command shows information about all network interfaces on the system.

# 2. **Viewing IP Addresses**:

```
ip address show
```

Displays detailed information about all IP addresses assigned to interfaces.

# 3. **Assigning an IP Address**:

```
sudo ip address add 192.168.1.2/24 dev eth0
```

Assigns the IP address 192.168.1.2 with a netmask of 255.255.255.0 to the "eth0" interface.
