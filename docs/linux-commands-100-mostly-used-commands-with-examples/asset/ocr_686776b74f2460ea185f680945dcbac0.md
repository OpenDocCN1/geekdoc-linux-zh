+   3. **Display the last login for a specific user:**

```
```
last username
```
```

Replace `username` with the actual username you want to check. This will show the login/logout history for that specific user.

+   4. **Display only the reboot entries:**

```
```
last reboot
```
```

This command shows a list of system reboots along with the corresponding times.

+   5. **Display the logins on a specific date:**

```
```
last -F YYYYMMDD
```
```

Replace `YYYYMMDD` with the desired date in the format Year-Month-Day (e.g., 20231110 for November 10, 2023). This will display logins only on that specific date.
