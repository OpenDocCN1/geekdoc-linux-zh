```
mkdir my_directory
```

This creates a directory named "my_directory" in the current working directory.

# 2. Creating Multiple Directories:

```
mkdir dir1 dir2 dir3
```

This command creates three directories named "dir1", "dir2", and "dir3" in the current working directory.

# 3. Setting Permissions:

```
mkdir -m 755 my_directory
```

This creates a directory named "my_directory" with the permission set to 755 (read, write, and execute for the owner, and read and execute for others).
