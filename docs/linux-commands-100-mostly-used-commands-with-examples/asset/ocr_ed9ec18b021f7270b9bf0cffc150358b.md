```
export VAR1="Value1" VAR2="Value2"
```

You can export multiple variables in a single command, separating them with spaces.

# **6. Unsetting a Variable:**

```
export MY_VARIABLE=
```

Setting a variable to an empty value effectively unsets it.

# **7. Exporting Variables in a Shell Script:**

```
#!/bin/bash
export SCRIPT_VAR="Script Variable"
echo $SCRIPT_VAR
```

When running a shell script, exported variables are accessible in the script's environment.

# **8. Viewing All Exported Variables:**

export
