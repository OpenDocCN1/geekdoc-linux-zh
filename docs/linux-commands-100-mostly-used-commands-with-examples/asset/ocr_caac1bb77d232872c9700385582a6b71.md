# 2. Display Memory Statistics:

```
vmstat -s
```

This command provides a summary of memory statistics, showing the total, used, and free memory in kilobytes.

# 3. Display Process-related Information:

```
vmstat -p [partition]
```

This command displays process-related information, including process ID, priority, virtual memory size, resident set size, and more. You can specify a particular partition to filter the output.

# 4. Display Disk Statistics:

```
vmstat -d
```

This command provides disk statistics, including the number of reads/writes, blocks read/written, and the number of I/O operations per second.
