The `gunzip` command in Linux is used to decompress files that have been compressed using the gzip compression utility. It is essentially a counterpart to the `gzip` command and is used to extract the original uncompressed version of a file that has been compressed with gzip.

# **Examples:**

+   1. **Decompress a file:**

```
gunzip example.txt.gz
```

+   2. **Decompress multiple files:**

```
gunzip file1.gz file2.gz
```

+   3. **Decompress and keep the original file:**

```
gunzip -k example.txt.gz
```

+   4. **Decompress and list the contents of the compressed archive:**

```
gunzip -l example.txt.gz
```
