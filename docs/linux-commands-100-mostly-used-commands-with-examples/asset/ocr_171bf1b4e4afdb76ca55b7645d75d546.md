+   4. **Set Query Packets:**

```
traceroute -q 5 example.com
```

Sends 5 query packets per hop instead of the default 3.

+   5. **Use UDP Packets:**

```
traceroute -U example.com
```

Uses UDP packets instead of the default ICMP Echo Request packets.

+   6. **Specifying Wait Time:**

```
traceroute -w 2 example.com
```

Sets the time (in seconds) to wait for a response before sending the next packet.
