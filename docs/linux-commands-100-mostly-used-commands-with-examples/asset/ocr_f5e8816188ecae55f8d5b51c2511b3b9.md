# 81. locate: Find the location of files and directories on the system.

`locate` is a command-line utility in Linux used for finding the location of files and directories on the system. It relies on a pre-built index of files and their locations, making it a faster alternative to searching the file system directly.

# Examples:

+   1. **Search for a File:**

```
locate myfile.txt
```
