# **11. grep: Search for a specific pattern in files.**

`grep` is a powerful command-line utility in Linux used for searching text patterns within files. Its name is derived from the ed command `g/re/p` (global/regular expression/print), which was used for similar purposes.

**Examples:**

+   1. **Basic Search:**

```
```
 grep "pattern" filename
```
```

+   2. **Case-Insensitive Search:**

```
```
 grep -i "pattern" filename
