The `ps` command in Linux is used to display information about currently running processes. It provides a snapshot of the current processes on a system, including their process IDs (PIDs), terminal associations, resource usage, and other details.

# Examples:

1. **Display a list of all processes running on the system:**

```
```
ps
```
```

2. **Display detailed information about all processes:**

```
```
ps -ef
```
```

3. **Display a full-format listing of all processes:**

```
```
ps -f
```
```

4. **Display information about processes owned by a specific user (replace `username` with the actual username):**

```
```
ps -u username
```
```
