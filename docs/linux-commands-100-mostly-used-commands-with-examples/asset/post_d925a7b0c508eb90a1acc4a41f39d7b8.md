# 63. nmap: Network exploration tool and security scanner.

`nmap` (Network Mapper) is a powerful and versatile open-source tool used for network discovery and security auditing. It is commonly used to discover hosts and services on a computer network, creating a map of the network's structure. `nmap` operates by sending packets to the target hosts and analyzing the responses.

## Examples

1. **Basic Scan:**

```text
nmap target_ip
```

This command performs a basic scan on the specified target IP address. It shows open ports and their associated services.

2. **Scan a Range of IP Addresses:**

```text
nmap 192.168.1.1-50
```

Scans a range of IP addresses from 192.168.1.1 to 192.168.1.50.

3. **Scan Entire Subnet:**

```text
nmap 192.168.1.0/24
```

Scans all IP addresses in the 192.168.1.0/24 subnet.

4. **Scan Multiple Hosts:**

```text
nmap host1 host2 host3
```

Scans multiple hosts specified on the command line.

5. **Aggressive Scan:**

```text
nmap -A target_ip
```

Performs an aggressive scan, including OS detection, version detection, script scanning, and traceroute.

6. **Service Version Detection:**

```text
nmap -sV target_ip
```

Attempts to determine the version of services running on open ports.

7. **Operating System Detection:**

```text
nmap -O target_ip
```

Tries to determine the operating system of the target.

8. **Scan Specific Ports:**

```text
nmap -p 80,443 target_ip
```

Scans only specified ports (80 and 443 in this example).

9. **Scan All 65535 Ports:**

```text
nmap -p- target_ip
```

Scans all 65535 ports. This can take longer but ensures no port is overlooked.

10. **Output to a File:**

```text
nmap -oN output.txt target_ip
```

Saves the results to a file named "output.txt" in normal format.

11. **Output in XML Format:**

```text
nmap -oX output.xml target_ip
```

Saves the results in XML format.

12. **Script Scanning:**

```text
nmap --script=default target_ip
```

Executes default scripts against the target.

13. **Timing and Performance:**

```text
nmap -T4 target_ip
```

Sets the timing template to aggressive, balancing speed and reliability.

14. **Ping Scan:**

```text
nmap -sn target_ip
```

Performs a ping scan without port scanning.

15. **UDP Scan:**

```text
nmap -sU target_ip
```

Performs a UDP scan on the target.

# 64. iftop: Display bandwidth usage on an interface.

`iftop` is a command-line network bandwidth monitoring tool for Linux. It shows a list of network connections between your system and others and displays information about the data rate and data for each connection.

## Examples

1. **Basic Usage:**

```text
iftop
```

This will start `iftop` in interactive mode, displaying a list of connections, data rates, and total data transferred.

2. **Display Bytes per Second:**

```text
iftop -B
```

Shows bandwidth in bytes per second instead of the default bits per second.

3. **Filtering by Port:**

```text
iftop -F 80
```

Displays only the connections using port 80. You can use other port numbers as needed.

4. **Displaying Timestamps:**

```text
iftop -t
```

Adds a timestamp to each line of output.

5. **Monitor Specific Interface:**

```text
iftop -i eth0
```

Monitors only the traffic on the specified network interface (replace `eth0` with your actual interface name).

6. **Do Not Resolve Hostnames:**

```text
iftop -n
```

Prevents `iftop` from resolving IP addresses to hostnames, making the display faster.

7. **Display Ports Alongside Hosts:**

```text
iftop -N
```

Shows both hosts and their corresponding ports.

8. **Apply a BPF Filter:**

```text
iftop -F "host 192.168.1.1"
```

Uses a BPF filter to display only the traffic to or from the specified host (replace `192.168.1.1` with the desired IP address).

# 65. fsck: File system consistency check and repair.

The `fsck` command, which stands for "file system consistency check," is a powerful utility used in Linux and other Unix-like operating systems to check and repair file system inconsistencies on a disk. It is commonly employed when a system encounters unexpected shutdowns, power failures, or other issues that might lead to file system corruption. `fsck` can work with various file system types, such as ext2, ext3, ext4, and others.

## Examples

1. **Check a File System:**

```text
fsck /dev/sda1
```

This command checks and repairs the file system on the device `/dev/sda1`. Replace `/dev/sda1` with the appropriate device identifier for your system.

2. **Automatically Repair File System:**

```text
fsck -y /dev/sda1
```

The `-y` option automatically answers **yes** to all questions asked by `fsck`, making it suitable for unattended repair processes.

3. **Interactive Repair:**

```text
fsck -r /dev/sda1
```

The `-r` option prompts the user for confirmation before fixing each issue. This allows you to review and approve each repair manually.

4. **Check and Repair All File Systems:**

```text
fsck -A
```

This command checks and repairs all file systems specified in the `/etc/fstab` file. It's often used during the system boot process.

5. **Check a Specific File System Type:**

```text
fsck.ext4 /dev/sda1
```

In this example, `fsck.ext4` is used specifically for the ext4 file system. Different file systems may have their own `fsck` variants.

6. **Force File System Check Even if Clean:**

```text
fsck -f /dev/sda1
```

The `-f` option forces a file system check even if it appears clean. This can be useful for ensuring a thorough examination.

7. **Check and Repair Root File System:**

```text
fsck -f /
```

To check and repair the root file system, you may need to boot from a live CD or another bootable media to unmount the root partition.

8. **Dry Run (Check, but don't repair):**

```text
fsck -n /dev/sda1
```

The `-n` option performs a dry run, displaying what would be done without actually making any changes to the file system.

# 66. tac: Concatenate and display files in reverse.

The `tac` command in Linux is used to concatenate and display the contents of a file in reverse order. The name "tac" is derived from the word "cat" (concatenate) spelled backward. It's a simple yet powerful tool that can be handy in various scenarios, especially when you want to view the end of a file or reverse the order of lines in a text file.

## Examples

1. **Basic Usage:**

Display the contents of a file in reverse order.

```text
tac filename.txt
```

2. **Concatenate Multiple Files in Reverse Order:**

Concatenate the contents of multiple files and display them in reverse order.

```text
tac file1.txt file2.txt
```

3. **Reverse the Output of a Command:**

Use a command's output as input for `tac` and reverse the order.

```text
ls -l | tac
```

4. **Display the End of a Log File:**

View the last few lines of a log file in reverse order to quickly see the latest entries.

```text
tac /var/log/syslog
```
