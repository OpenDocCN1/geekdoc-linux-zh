# 55. chroot: Run a command with a different root directory.

The `chroot` command in Linux is used to change the root directory for a specific process, essentially creating a restricted environment in which the specified command or shell operates. This can be useful for testing or repairing systems without affecting the rest of the operating system.

Examples:

+   1. **Change the root directory to a new location and run a command within it:**

```
sudo chroot /path/to/new/root /bin/bash
```

This example changes the root directory to `/path/to/new/root` and starts a new Bash shell within this environment.

+   2. **Change the root directory and execute a specific command:**

```
sudo chroot /path/to/new/root /bin/ls -l /home
```

This command changes the root directory and lists the contents of the `/home` directory using the `ls` command.
