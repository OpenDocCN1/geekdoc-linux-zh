2. **Extract to a specific directory:**

```
```
unzip file.zip -d /path/to/destination
```
```

This will extract the contents of `file.zip` to the specified destination directory.

3. **List contents of a ZIP file:**

```
```
unzip -l file.zip
```
```

The `-1` option lists the contents of the ZIP file without extracting them.

4. **Extract specific files:**

```
```
unzip file.zip file1.txt file2.txt
```
```

You can specify specific files to extract from the ZIP archive.
