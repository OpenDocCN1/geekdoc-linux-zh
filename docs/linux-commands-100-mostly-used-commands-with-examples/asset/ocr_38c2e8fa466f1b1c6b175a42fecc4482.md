+   2. **Connect using a custom port:**

```
sftp -oPort=2222 username@remote_host
```

This example connects to the remote server using port 2222. Adjust the port number as needed.

+   3. **Upload a file to the remote server:**

```
put local_file.txt
```

This command uploads `local_file.txt` to the current working directory on the remote server.

+   4. **Download a file from the remote server:**

```
get remote_file.txt
```

Downloads `remote_file.txt` from the remote server to the local working directory.
