```
journalctl -p err
```

Use the `-p` option to filter logs by priority. In this example, only logs with the "err" (error) priority are displayed.

# 10. Filtering Logs by Process ID:

```
journalctl _PID=1234
```

Replace `1234` with the process ID you want to filter logs for.

# 11. Filtering Logs by Message Content:

```
journalctl | grep "search_term"
```

You can use standard Unix tools like `grep` to filter logs based on the content of the log messages.
