**5. Remove Software:**

```
sudo apt-get remove firefox
```

Removes the Firefox browser. Like installation, removal of software often requires elevated privileges.

**6. Restart Services:**

```
sudo service apache2 restart
```

Restarts the Apache web server. Managing system services often requires superuser privileges.

**7. Change File Ownership:**

```
sudo chown user:group filename
```

Changes the ownership of a file to a specified user and group.
