```
chmod 754 file.txt
```

In this example, the user has read, write, and execute (4+2+1 = 7), the group has read and execute (4+1 = 5), and others have read-only (4).

# **13. chown: Change file owner or group.**

The `chown` command in Linux is used to change the ownership of files or directories. Ownership refers to the user and group associated with a file or directory. This command is particularly useful when you need to transfer ownership of files or directories from one user to another.

**Examples:**

+   1. **Basic Usage - Change Ownership of a File:**

```
chown newowner:newgroup myfile.txt
```

This command changes the ownership of `myfile.txt` to the user `newowner` and the group `newgroup` .
