```
sudo ifconfig eth0 192.168.1.2
```

This command assigns the IP address 192.168.1.2 to the "eth0" interface.

# 4. Setting Netmask:

```
sudo ifconfig eth0 netmask 255.255.255.0
```

Sets the netmask for the "eth0" interface.

# 5. Bringing an Interface Up or Down:

```
sudo ifconfig eth0 up
sudo ifconfig eth0 down
```

These commands bring the "eth0" interface up or down, respectively.

# `ip` Command:

The `ip` command is a more powerful and flexible tool for configuring and managing network interfaces. It provides a wide range of functionality beyond what `ifconfig` offers.
