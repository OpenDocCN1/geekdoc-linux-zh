## 73. hostname: Display or set the system hostname.

The `hostname` command in Linux is used to display or set the system's host name. The host name is a label assigned to a device on a network, and it is used to identify the device in various network operations. The `hostname` command is also useful for viewing or changing the host name of the system.

**Examples:**

- **View the current host name:**

  ```bash
  hostname
  ```

  This command will output the current host name of the system.

- **Display the fully qualified domain name (FQDN):**

  ```bash
  hostname -f
  ```

  The `-f` option is used to display the FQDN of the system, which includes both the host name and the domain name.

- **Set a new host name temporarily:**

  ```bash
  sudo hostname newhostname
  ```

  This command sets a new host name for the system temporarily.

- **Set a new host name persistently (requires system reboot):**

  ```bash
  sudo hostnamectl set-hostname newhostname
  ```

  This command sets a new host name for the system, and the change will persist across reboots. It uses `hostnamectl`, which is a tool for querying and changing system hostname and related settings.

- **View the static host name (configured in /etc/hostname):**

  ```bash
  cat /etc/hostname
  ```

  The static host name is often configured in the `/etc/hostname` file. This command displays the content of that file.

- **Edit the static host name using a text editor:**

  ```bash
  sudo nano /etc/hostname
  ```

  Use a text editor like `nano` to edit the static host name in the `/etc/hostname` file. After editing, save the changes and exit the editor.

- **Edit the hosts file to associate the host name with an IP address:**

  ```bash
  sudo nano /etc/hosts
  ```

  The `/etc/hosts` file maps IP addresses to host names. You can edit this file to associate your host name with the desired IP address.

- **Check the current domain name:**

  ```bash
  domainname
  ```

  This command displays the NIS/YP domain name associated with the system.

## 74. zip: Package and compress files.

The `zip` command in Linux is used for compressing files and directories into a zip archive. It is a popular utility for creating and managing compressed files in a cross-platform manner.

**Examples:**

- **Zip a Single File:**

  ```bash
  zip archive.zip file.txt
  ```

  This creates a zip archive named `archive.zip` containing the file `file.txt`.

- **Zip Multiple Files:**

  ```bash
  zip archive.zip file1.txt file2.txt
  ```

  Creates a zip archive named `archive.zip` containing `file1.txt` and `file2.txt`.

- **Zip a Directory:**

  ```bash
  zip -r archive.zip directory/
  ```

  The `-r` option is used to recursively include all files and subdirectories within the specified directory (`directory/`) in the zip archive.

- **Add Files to an Existing Archive:**

  ```bash
  zip -u archive.zip newfile.txt
  ```

  The `-u` option updates an existing zip archive (`archive.zip`) by adding `newfile.txt` to it.

- **Set Compression Level:**

  ```bash
  zip -9 archive.zip file.txt
  ```

  The `-9` option sets the compression level to the maximum. You can use values from 1 to 9 to adjust compression levels, where 1 is the fastest compression and 9 is the best compression.

- **Exclude Files:**

  ```bash
  zip archive.zip *.txt -x exclude.txt
  ```

  This command creates a zip archive (`archive.zip`) containing all `.txt` files in the current directory but excludes the file `exclude.txt`.

- **Password Protect a Zip Archive:**

  ```bash
  zip -e secure.zip sensitive-file.txt
  ```

  The `-e` option prompts for a password and creates a password-protected zip archive (`secure.zip`) containing the specified file (`sensitive-file.txt`).

- **List Contents of a Zip Archive:**

  ```bash
  unzip -l archive.zip
  ```

  Use the `unzip -l` command to list the contents of a zip archive (`archive.zip`) without extracting them.

- **Extract a Zip Archive:**

  ```bash
  unzip archive.zip
  ```

  The `unzip` command extracts the contents of a zip archive (`archive.zip`) into the current directory.

## 75. unzip: Unpack zip archives.

The `unzip` command in Linux is used to extract files from a compressed archive in the ZIP format. It is a versatile utility that comes pre-installed on most Linux distributions.

**Examples:**

- **Extract a ZIP file:**

  ```bash
  unzip file.zip
  ```

  This command will extract all files from `file.zip` in the current directory.

- **Extract to a specific directory:**

  ```bash
  unzip file.zip -d /path/to/destination
  ```

  This will extract the contents of `file.zip` to the specified destination directory.

- **List contents of a ZIP file:**

  ```bash
  unzip -l file.zip
  ```

  The `-l` option lists the contents of the ZIP file without extracting them.

- **Extract specific files:**

  ```bash
  unzip file.zip file1.txt file2.txt
  ```

  You can specify specific files to extract from the ZIP archive.

- **Overwrite existing files:**

  ```bash
  unzip -o file.zip
  ```

  The `-o` option overwrites existing files without prompting.

- **Quiet mode (no output):**

  ```bash
  unzip -q file.zip
  ```

  The `-q` option suppresses the printing of file and directory names as they are extracted.

- **Extract with full path:**

  ```bash
  unzip -j file.zip
  ```

  The `-j` option extracts files without their paths, discarding any directory structure.

- **Password-protected ZIP file:**

  ```bash
  unzip -P your_password file.zip
  ```

  Use the `-P` option followed by the password to extract files from a password-protected ZIP archive.

- **Test integrity of a ZIP file:**

  ```bash
  unzip -t file.zip
  ```

  The `-t` option tests the integrity of the ZIP file without extracting its contents.

- **Update existing files:**

  ```bash
  unzip -u file.zip
  ```

  The `-u` option updates existing files and extracts new files from the ZIP archive.

  ```bash
  lsblk -m
  ```

  Shows information about device permissions.

- **Show Specific Device Information:**

  ```bash
  lsblk /dev/sda
  ```

  Displays information about a specific device (`/dev/sda` in this case).

- **Do Not Print Dependent Devices:**

  ```bash
  lsblk -d
  ```
