```
sudo shutdown -c
```

This command cancels any scheduled shutdown.

# 6. Reboot the system immediately:

```
sudo shutdown -r now
```

This command reboots the system immediately.

# 7. Schedule a reboot in 15 minutes:

```
sudo shutdown -r +15
```

The system will be rebooted in 15 minutes.

# 8. Schedule a reboot at a specific time:

```
sudo shutdown -r 08:30
```
