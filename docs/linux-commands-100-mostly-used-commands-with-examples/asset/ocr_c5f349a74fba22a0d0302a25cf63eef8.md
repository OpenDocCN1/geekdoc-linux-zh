Removes both `file1.txt` and `file2.txt` .

# 3. **Remove a Directory:**

```
rm -r mydirectory
```

Recursively removes the directory named `mydirectory` and its contents.

# 4. **Remove with Confirmation:**

```
rm -i sensitivefile.txt
```

Prompts the user for confirmation before removing the file `sensitivefile.txt` .

# 5. **Forceful Removal:**

```
rm -f stubbornfile.txt
```

Removes the file `stubbornfile.txt` without asking for confirmation, even if it's write-protected.
