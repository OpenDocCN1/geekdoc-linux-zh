The `who` command in Linux is used to display information about users who are currently logged into the system. It provides details such as the username, terminal, login time, and originating IP address.

# **Examples:**

+   1. **Display a list of all logged-in users:**

```
who
```

+   2. **Display a count of logged-in users:**

```
who -q
```

+   3. **Show information about the current terminal's owner:**

```
who -m
```

+   4. **Display the time of the last system boot:**

```
who -b
```
