## 90. reboot: Restart the system.

The `reboot` command in Linux is used to restart the system. It is a straightforward command that allows you to initiate a system reboot gracefully.

### Examples:

- 1. **Simple Reboot:**

```
reboot
```

This command will immediately initiate a system reboot.

- 2. **Delayed Reboot:**

```
reboot -d 60
```

The `-d` option specifies a delay in seconds before initiating the reboot. In this example, the system will reboot after a 60-second delay.

- 3. **Forceful Reboot:**

```
reboot -f
```

The `-f` option forces an immediate reboot without gracefully terminating processes. Use this with caution, as it may lead to data loss if there are unsaved changes.

- 4. **Reboot with a Message:**

```
reboot -n "System will restart for updates at 3:00 PM"
```

The `-n` option allows you to add a message that will be sent to all logged-in users before the reboot.

- 5. **Reboot to a Specific Kernel:**

```
reboot -k 5.4.0-81-generic
```

The `-k` option lets you specify a particular kernel version to boot into after the system restarts.

- 6. **Power Off After Reboot:**

```
reboot -p
```

The `-p` option shuts down the system after rebooting. This is useful when you want to turn off the machine completely.

- 7. **Reboot with a Time Schedule:**

```
shutdown -r 22:30
```

Alternatively, you can use the `shutdown` command to schedule a reboot at a specific time. In this example, the system will reboot at 10:30 PM.

## 91. lsusb: Display information about USB buses and devices.

The `lsusb` command in Linux is used to list information about USB (Universal Serial Bus) devices connected to the system. It provides details such as the vendor and product IDs, device class, and other information related to USB devices.

### Examples:

- 1. **Basic Usage:**

```
lsusb
```

This command will list all the USB devices connected to your system.

- 2. **Verbose Output:**

```
lsusb -v
```

This will provide detailed information about each USB device, including configuration, interfaces, and more.

- 3. **Tree View:**

```
lsusb -t
```

Displays a tree-like structure of the USB devices, showing the hierarchy and relationship between them.

- 4. **Specific Device:**

```
lsusb -d 045e:00cb
```

Replace `045e:00cb` with the vendor and product IDs of the specific USB device you want information about. This command will display detailed information about that particular device.

- 5. **List Bus and Device Numbers:**

```
lsusb -t | grep -i 'bus\\device'
```

This command shows a concise list of bus and device numbers, making it easier to identify the USB devices.

- 6. **Display Only Device Description:**

```
lsusb | awk '{print $6, $7, $8, $9, $10, $11, $12, $13}'
```

This command uses `awk` to display only the device description.

- 7. **Show USB 3.0 Devices:**

```
lsusb | grep '3.0'
```

This command filters the output to display only USB 3.0 devices, helping you identify the high-speed USB connections.

- 8. **Show Bus and Device Numbers:**

```
lsusb | cut -d' ' -f2,4
```

This command extracts and displays the bus and device numbers of the USB devices.

## 92. lspci: Display information about PCI buses and connected devices.

The `lspci` command in Linux is a powerful tool that provides detailed information about the PCI buses and the devices connected to them on your system. PCI (Peripheral Component Interconnect) is a standard interface for connecting various hardware devices like network cards, graphics cards, and storage controllers to the motherboard of a computer.

### Examples:

- 1. **List all PCI devices:**

```
lspci
```

This command displays a list of all PCI devices in a compact format.

- 2. **Display detailed information for a specific device:**

```
lspci -v -s <bus>;<device>.<function>
```

Replace `<bus>`, `<device>`, and `<function>` with the appropriate values from the output of the `lspci` command. This provides verbose information about a specific PCI device.

- 3. **Show information in a human-readable format:**

```
lspci -nn
```

This command displays vendor and device codes in a more human-readable format.

- 4. **Display information about a specific vendor:**

```
lspci -d <vendor_id>
```

Replace `<vendor_id>` with the hexadecimal code for the vendor. This command shows a list of devices from a specific vendor.

- 5. **Show kernel driver and module in use:**

```
lspci -k
```

This command displays information about the kernel driver and module currently in use by each PCI device.

- 6. **List all devices and their IRQ assignments:**

```
lspci -v -vv
```

This command provides very verbose output, including IRQ assignments for each PCI device.

- 7. **Display PCI devices in a tree-like format:**

```
lspci -t
```

This command organizes the PCI devices in a tree-like structure, showing the hierarchy of buses and devices.

- 8. **Show only Ethernet devices:**

```
lspci | grep Ethernet
```

This command uses `grep` to filter the output and display only the lines containing "Ethernet," helping you quickly identify network-related devices.

## 93. strace: Trace system calls and signals.

`strace` is a powerful command-line tool used in Linux and other Unix-like operating systems to trace and debug system calls and signals made by a process. It allows you to inspect the interactions between a process and the Linux kernel, providing valuable insights into the system-level behavior of programs.

### Examples:

- 1. **Trace a Command:**

```
strace ls -l
```

This command traces the system calls made by the `ls` command when listing files in the long format.

- 2. **Redirect Output to a File:**

```
strace -o output.txt ls -l
```

This example redirects the `strace` output to a file named `output.txt` for later analysis.

- 3. **Trace Specific System Calls:**

```
strace -e trace=open,read,write ls -l
```

This command traces only the `open`, `read`, and `write` system calls made by the `ls` command.

- 4. **Display Timestamps:**

```
strace -t ls -l
```

It adds timestamps to each line of output, providing information on when each system call occurred.

- 5. **Display System Calls with Arguments:**

```
strace -v ls -l
```

The `-v` option provides more detailed information, including the arguments for each system call.

- 6. **Trace a Running Process:**

```
strace -p PID
```

Replace `PID` with the process ID of the running process you want to trace.

- 7. **Filter Output for a Specific System Call:**

```
strace -e trace=write -e write=1 ls -l
```

This example traces only the `write` system call, specifically for file descriptor 1 (stdout).

- 8. **Count System Calls:**

```
strace -c ls -l
```

It prints a summary of the counts and times of each system call, providing a quick overview of the system call activity.
