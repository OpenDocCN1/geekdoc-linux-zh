```
unzip -o file.zip
```

The `-o` option overwrites existing files without prompting.

# 6. Quiet mode (no output):

```
unzip -q file.zip
```

The `-q` option suppresses the printing of file and directory names as they are extracted.

# 7. Extract with full path:

```
unzip -j file.zip
```

The `-j` option extracts files with their paths, discarding any directory structure.

# 8. Password-protected ZIP file:

```
unzip -P your_password file.zip
```
