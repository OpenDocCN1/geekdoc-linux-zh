# 10. nano or vim: Text editors for creating or editing files.

`nano` and `vim` are both text editors commonly used in Linux and Unix-like operating systems. They are powerful tools for editing text files from the command line.

# Nano:

`nano` is a simple and user-friendly text editor that is easy to use, especially for beginners. It provides a basic set of commands at the bottom of the screen, making it more straightforward for users who are not familiar with complex keyboard shortcuts.

# Example:

To edit a file named "example.txt," you would run:

```
nano example.txt
```

Once inside the editor, you can use the commands displayed at the bottom to navigate, edit, and save the file.

# Vim:

`vim` (Vi Improved) is a highly configurable and powerful text editor that is an enhanced version of the older `vi` editor. It is known for its efficiency and extensive feature set, but it has a steeper learning curve compared to `nano`.
