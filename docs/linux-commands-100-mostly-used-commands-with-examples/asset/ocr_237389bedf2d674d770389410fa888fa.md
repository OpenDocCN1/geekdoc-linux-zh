# **27. tree: Display directory tree structure.**

The `tree` command in Linux is used to display the hierarchical structure of directories and subdirectories in a tree-like format. It is a useful tool for visually representing the file system structure.

**Examples:**

1. **Display the tree structure of the current directory:**

```
```
tree
```
```

2. **Display the tree structure with full paths:**

```
```
tree -f
```
```

3. **Show hidden files and directories in the tree:**

```
```
tree -a
```
```
