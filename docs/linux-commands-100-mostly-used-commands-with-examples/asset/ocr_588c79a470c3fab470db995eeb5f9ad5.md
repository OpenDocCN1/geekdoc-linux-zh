```
sudo apt-get install firefox
```

This command installs the Firefox web browser. The `sudo` command is used to elevate the privileges for the installation process.

# 2. Edit System Files:

```
sudo nano /etc/network/interfaces
```

This opens the Nano text editor to edit the network configuration file. Editing system files often requires superuser privileges.

# 3. Update Package Lists:

```
sudo apt-get update
```

This updates the local package lists, necessary before installing or upgrading software.

# 4. Upgrade Installed Packages:

```
sudo apt-get upgrade
```
