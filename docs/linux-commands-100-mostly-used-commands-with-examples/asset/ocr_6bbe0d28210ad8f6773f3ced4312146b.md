Traceroute is a command-line tool used in Linux and other operating systems to trace the route that packets take from your computer to a destination IP address or domain. It helps identify the network path and measure the transit delays of packets across the internet.

**Examples:**

+   1. **Basic Usage:**

```
```tracoute example.com```
```

This command traces the route to the IP address of `example.com`, showing the list of routers (hops) along the way.

+   2. **Specify Maximum TTL:**

```
```tracoute -m 15 example.com```
```

Sets the maximum TTL to 15, limiting the number of hops the trace will make.

+   3. **Do Not Resolve Hostnames:**

```
```tracoute -n example.com```
```

Displays IP addresses instead of resolving them to hostnames, which can speed up the process.
