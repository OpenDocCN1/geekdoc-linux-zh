This sends only 4 packets to google.com and then stops.

# 3. Set Packet Size:

```
```
ping -s 100 google.com
```
```

This sends packets of size 100 bytes to google.com.

# 4. Set Interval Between Packets:

```
```
ping -i 2 google.com
```
```

This sets a 2-second interval between successive packets.

# 5. Set Timeout:

```
```
ping -t 5 google.com
```
```

This sets a timeout of 5 seconds. If no response is received within this time, the ping command stops.
