# 3. Move Up One Directory:

```
cd ..
```

This command moves you up one level in the directory structure.

# 4. Move to the Parent Directory:

```
cd ../parent_directory
```

Replace "parent_directory" with the name of the parent directory you want to move into. This is an example of a relative path.

# 5. Move to a Subdirectory:

```
cd subdirectory
```

Replace "subdirectory" with the name of the subdirectory you want to move into. This is an example of a relative path.
