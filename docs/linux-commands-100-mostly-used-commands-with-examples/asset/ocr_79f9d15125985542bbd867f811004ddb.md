# **9. View System Logs:**

```
sudo journalctl
```

Displays the system logs using the journalctl command. Accessing log files usually requires superuser privileges.

# **10. Add a User to a Group:**

```
sudo usermod -aG groupname username
```

Adds a user to a specified group.

# **11. Run a Command as Another User:**

```
sudo -u username command
```
