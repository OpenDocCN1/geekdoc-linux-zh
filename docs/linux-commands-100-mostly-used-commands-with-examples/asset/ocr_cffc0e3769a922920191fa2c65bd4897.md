```
vmstat 2 5
```

This command displays system statistics every 2 seconds, a total of 5 times.

# 6. Display CPU Utilization:

```
vmstat -n 2 5
```

This command displays CPU utilization every 2 seconds, a total of 5 times. The `-n` option prevents the display of the header, making it easier to parse the output.

# 7. Display Process Queue Statistics:

```
vmstat -q
```

This command displays information about the process queues, including the number of processes waiting for CPU time and the number of processes in uninterruptible sleep.

# 8. Display Kernel Threads:

```
vmstat -t
```
