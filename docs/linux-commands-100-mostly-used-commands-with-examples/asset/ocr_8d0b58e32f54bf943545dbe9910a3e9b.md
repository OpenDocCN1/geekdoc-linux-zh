Customize the output format using control characters. `%n` represents the file name, and `%s` represents the file size.

# 6. Follow Symbolic Links:

```
stat -L symlink
```

If the file is a symbolic link, this command displays information about the linked file rather than the link itself.

# 7. Display Information Recursively:

```
find /path/to/directory -type f -exec stat {} \;
```

Use `find` with `exec` to apply `stat` recursively to all files in a directory.

# 8. Display Inode Number:

```
stat --format="Inode: %i" filename
```

`%i` represents the inode number of the file.
