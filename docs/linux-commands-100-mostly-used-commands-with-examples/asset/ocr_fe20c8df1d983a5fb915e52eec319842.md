# 2. **cd: Change directory.**

The `cd` command in Linux is used to change the current working directory. It allows you to navigate through the file system by moving from one directory to another.

**Examples:**

+   1. **Change to Home Directory:**

```
```
cd
```
```

This command takes you to your home directory.

+   2. **Change to a Specific Directory:**

```
```
cd /path/to/directory
```
```

Replace "/path/to/directory" with the actual path of the directory you want to move into. This is an example of an absolute path.
