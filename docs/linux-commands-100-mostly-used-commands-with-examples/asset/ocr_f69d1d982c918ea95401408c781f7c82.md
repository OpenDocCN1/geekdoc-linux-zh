Use the `-P` option followed by the password to extract files from a password-protected ZIP archive.

# 9. Test integrity of a ZIP file:

```
unzip -t file.zip
```

The `-t` option tests the integrity of the ZIP file without extracting its contents.

# 10. Update existing files:

```
unzip -u file.zip
```

The `-u` option updates existing files and extracts new files from the ZIP archive.

# 76. lsblk: List information about block devices.

The `lsblk` command in Linux is used to list information about block devices, such as hard drives and their partitions. It provides a detailed overview of the block devices attached to the system, their mount points, sizes, and relationships.
