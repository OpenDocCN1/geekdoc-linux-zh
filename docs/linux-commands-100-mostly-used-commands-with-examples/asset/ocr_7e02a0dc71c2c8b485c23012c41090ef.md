# **3. Create a Bootable USB Drive from an ISO:**

Use `dd` to write an ISO image to a USB drive, creating a bootable medium.

```
```
sudo dd if=ubuntu.iso of=/dev/sdX bs=4M
```
```

+   - `if=ubuntu.iso`: Specifies the input file (source ISO image).
+   - `of=/dev/sdX`: Specifies the output file (destination USB drive).
+   - `bs=4M`: Sets the block size to 4 megabytes for better performance.

# **4. Random Data Generation:**

`dd` can be used to generate random data for testing purposes.

```
```
dd if=/dev/urandom of=random_data.bin bs=1M count=10
```
```

+   - `if=/dev/urandom`: Specifies the input file (use the random data source).
+   - `of=random_data.bin`: Specifies the output file (destination for random data).
+   - `bs=1M`: Sets the block size to 1 megabyte.
+   - `count=10`: Specifies the number of blocks to copy (in this case, 10 megabytes of random data).
