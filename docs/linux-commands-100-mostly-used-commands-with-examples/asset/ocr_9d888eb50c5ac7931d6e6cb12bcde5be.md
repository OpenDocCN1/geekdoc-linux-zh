+   1. **Basic Usage:**

```
lsusb
```

This command will list all the USB devices connected to your system.

+   2. **Verbose Output:**

```
lsusb -v
```

This will provide detailed information about each USB device, including configuration, interfaces, and more.

+   3. **Tree View:**

```
lsusb -t
```

Displays a tree-like structure of the USB devices, showing the hierarchy and relationship between them.

+   4. **Specific Device:**

```
lsusb -d 045e:00cb
```
