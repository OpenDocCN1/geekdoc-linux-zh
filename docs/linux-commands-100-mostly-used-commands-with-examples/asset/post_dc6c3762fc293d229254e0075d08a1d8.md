
lsblk -i

Uses ASCII characters to draw the tree structure, providing a visual representation.

## 77. findmnt: Display information about currently mounted filesystems.

The `findmnt` command in Linux is used to display a list of currently mounted file systems or search for a specific mount point. It provides information about mounted file systems in a concise and easily readable format. The `findmnt` command is part of the util-linux package and is available on most Linux distributions.

### Examples:

- **List all mounted file systems:**

```bash
findmnt
```

This command will display a list of all mounted file systems along with their mount points, source devices, file system types, and other relevant information.

- **Filter by file system type:**

```bash
findmnt -t ext4
```

This command will display only the mounted file systems with the ext4 file system type.

- **Filter by source device:**

```bash
findmnt -S /dev/sda1
```

This command will display information about the mounted file system associated with the `/dev/sda1` device.

- **Display specific columns:**

```bash
findmnt -o SOURCE,TARGET,FSTYPE,OPTIONS
```

This command will display only the specified columns: source device, target mount point, file system type, and mount options.

- **List network file systems (NFS, SMB):**

```bash
findmnt -t nfs,smb
```

This command will display information about mounted NFS and SMB file systems.

- **Search for a specific mount point:**

```bash
findmnt /mnt/data
```

This command will display information about the mount point `/mnt/data` if it is currently mounted.

- **Display information without headings:**

```bash
findmnt -n
```

This command will display information without column headings, making it suitable for parsing in scripts.

## 78. mount: Mount a filesystem.

The `mount` command in Linux is used to attach a filesystem to the directory tree. This operation makes the files and directories on the attached filesystem accessible and usable by the system. The `mount` command is essential for working with external storage devices, network shares, and other file systems.

### Examples:

- **Mount a USB Drive:**

```bash
sudo mount /dev/sdb1 /mnt/usb
```

This command mounts the first partition (`/dev/sdb1`) of a USB drive to the `/mnt/usb` directory. Make sure the mount point (`/mnt/usb` in this case) exists before running the command.

- **Mount an ISO Image:**

```bash
sudo mount -o loop path/to/image.iso /mnt/iso
```

Here, the `-o loop` option is used to mount an ISO image file (`path/to/image.iso`) as if it were a device. The contents of the ISO file will be accessible in the `/mnt/iso` directory.

- **Mount a Network Share (NFS):**

```bash
sudo mount -t nfs server:/shared_folder /mnt/network_share
```

This example mounts a shared folder from an NFS server (`server:/shared_folder`) to the local directory `/mnt/network_share`. The `-t nfs` option specifies the filesystem type as NFS.

- **Mounting with Specific Filesystem Type:**

```bash
sudo mount -t ext4 /dev/sdc1 /mnt/data
```

In this case, the `-t ext4` option explicitly specifies the filesystem type (ext4 in this example) for the device (`/dev/sdc1`). The device is then mounted to the `/mnt/data` directory.

- **Mounting with Read-Only Option:**

```bash
sudo mount -o ro /dev/sdd1 /mnt/read_only
```

The `-o ro` option mounts the device (`/dev/sdd1`) in read-only mode, ensuring that no write operations can be performed on the filesystem. This can be useful for preserving the integrity of the data on the device.

- **Unmounting a Device:**

```bash
sudo umount /mnt/usb
```

To detach a mounted device, you use the `umount` command followed by the mount point. In this example, the USB drive mounted at `/mnt/usb` is unmounted.

## 79. umount: Unmount a mounted filesystem.

The `umount` command in Linux is used to unmount (detach) a currently mounted filesystem, allowing the underlying device or directory to be accessed or removed. Properly unmounting filesystems is crucial to ensure data integrity and prevent data corruption.

### Examples:

- **Unmounting a Filesystem:**

```bash
umount /mnt/data
```

This example unmounts the filesystem mounted at `/mnt/data`.

- **Unmounting a Device:**

```bash
umount /dev/sdb1
```

Unmounts the filesystem associated with the specified device, in this case, `/dev/sdb1`.

- **Force Unmount:**

```bash
umount -f /mnt/data
```

Forces an unmount, useful when the filesystem is busy. Use with caution, as it may lead to data corruption if processes are actively using the filesystem.

- **Unmounting All Filesystems:**

```bash
umount -a
```

Unmounts all filesystems listed in `/etc/fstab`. Use with caution, especially on a running system.

- **Unmounting by Device Name:**

```bash
umount /dev/sdb*
```

Unmounts all filesystems associated with devices matching the pattern `/dev/sdb*`.

- **Unmounting by Mount Point:**

```bash
umount -R /mnt/data
```

Recursively unmounts all filesystems mounted under the specified directory.

- **Verbose Output:**

```bash
umount -v /mnt/data
```

Displays detailed information about the unmount process.

- **Dry Run (Test):**

```bash
umount -n /mnt/data
```

Simulates the unmount operation without actually detaching the filesystem. Useful for testing.

- **Unmounting NFS Share:**

```bash
umount -t nfs server:/mnt/share
```

Unmounts an NFS (Network File System) share.

- **Unmounting CIFS Share:**

```bash
umount -t cifs //server/share /mnt/cifs
```

Unmounts a CIFS (Common Internet File System) share.

- **Unmounting with Lazy Detach:**

```bash
umount --lazy /mnt/data
```

Detaches the filesystem lazily, allowing processes to continue using the filesystem until they finish.

- **Unmounting and Detaching Loop Device:**

```bash
losetup -d /dev/loop0 && umount /mnt/loop
```

Detaches a loop device and then unmounts the associated filesystem.

## 80. sftp: Securely transfer files over the SSH protocol.

`SFTP` (Secure File Transfer Protocol) is a secure alternative to FTP (File Transfer Protocol) for transferring files between computers on a network. It provides a secure channel over an insecure network, typically the internet. SFTP encrypts both the command and data connections, preventing unauthorized access to sensitive information.

### Examples:

- **Connect to a remote server:**

```bash
sftp username@remote_host
```

Replace `username` with your remote username and `remote_host` with the IP address or domain of the server.

- **Connect using a custom port:**

```bash
sftp -oPort=2222 username@remote_host
```

This example connects to the remote server using port 2222. Adjust the port number as needed.

- **Upload a file to the remote server:**

```bash
put local_file.txt
```

This command uploads `local_file.txt` to the current working directory on the remote server.

- **Download a file from the remote server:**

```bash
get remote_file.txt
```

Downloads `remote_file.txt` from the remote server to the local working directory.

- **Navigate on the remote server:**

```bash
cd remote_directory
```

Changes the current working directory on the remote server.

- **Navigate on the local machine:**

```bash
lcd local_directory
```

Changes the current working directory on the local machine.

- **List files on the remote server:**

```bash
ls
```

Lists files and directories in the current remote directory.

- **List files on the local machine:**

```bash
lls
```

Lists files and directories in the current local directory.

- **Delete a file on the remote server:**

```bash
rm remote_file.txt
```

Removes `remote_file.txt` from the remote server.

- **Recursive upload or download:**

```bash
put -r local_directory
```

Uploads the entire local directory and its contents recursively to the remote server.

```bash
get -r remote_directory
```

Downloads the entire remote directory and its contents recursively to the local machine.

- **Preserve file timestamps:**

```bash
put -P local_file.txt
```
