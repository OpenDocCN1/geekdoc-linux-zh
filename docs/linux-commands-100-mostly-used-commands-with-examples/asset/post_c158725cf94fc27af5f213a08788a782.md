## 30. ping: Test the reachability of a host on an IP network.

The `ping` command is a network utility tool used to test the reachability of a host on an Internet Protocol (IP) network. It also measures the round-trip time for messages sent from the originating host to a destination computer. The name "ping" comes from the sonar sound used by submarines to detect other objects in the water.

### Examples:

- **Simple Ping:**
  ```
  ping google.com
  ```
  This will send a series of ICMP Echo Requests to google.com, and you'll see the round-trip time for each packet.

- **Set Number of Packets:**
  ```
  ping -c 4 google.com
  ```
  This sends only 4 packets to google.com and then stops.

- **Set Packet Size:**
  ```
  ping -s 100 google.com
  ```
  This sends packets of size 100 bytes to google.com.

- **Set Interval Between Packets:**
  ```
  ping -i 2 google.com
  ```
  This sets a 2-second interval between successive packets.

- **Set Timeout:**
  ```
  ping -t 5 google.com
  ```
  This sets a timeout of 5 seconds. If no response is received within this time, the ping command stops.

- **Quiet Mode:**
  ```
  ping -q google.com
  ```
  This runs the ping command in quiet mode, showing only the summary at the end.

- **Verbose Mode:**
  ```
  ping -v google.com
  ```
  This runs the ping command in verbose mode, providing more detailed information about each packet.

- **IPv6 Ping:**
  ```
  ping6 ipv6.google.com
  ```
  This performs a ping using IPv6. The `ping6` command is used for IPv6 addresses.

## 31. traceroute: Display the route that packets take to reach a network host.

Traceroute is a command-line tool used in Linux and other operating systems to trace the route that packets take from your computer to a destination IP address or domain. It helps identify the network path and measure the transit delays of packets across the internet.

### Examples:

- **Basic Usage:**
  ```
  traceroute example.com
  ```
  This command traces the route to the IP address of `example.com`, showing the list of routers (hops) along the way.

- **Specify Maximum TTL:**
  ```
  traceroute -m 15 example.com
  ```
  Sets the maximum TTL to 15, limiting the number of hops the trace will make.

- **Do Not Resolve Hostnames:**
  ```
  traceroute -n example.com
  ```
  Displays IP addresses instead of resolving them to hostnames, which can speed up the process.

- **Set Query Packets:**
  ```
  traceroute -q 5 example.com
  ```
  Sends 5 query packets per hop instead of the default 3.

- **Use UDP Packets:**
  ```
  traceroute -U example.com
  ```
  Uses UDP packets instead of the default ICMP Echo Request packets.

- **Specifying Wait Time:**
  ```
  traceroute -w 2 example.com
  ```
  Sets the time (in seconds) to wait for a response before sending the next packet.

- **Trace to a Specific Port:**
  ```
  traceroute -p 80 example.com
  ```
  Specifies the destination port (e.g., port 80 for HTTP).

- **IPv6 Traceroute:**
  ```
  traceroute -6 ipv6.example.com
  ```
  Performs a traceroute using IPv6 addresses.

- **Save Output to a File:**
  ```
  traceroute example.com > trace_output.txt
  ```
  Redirects the output to a file for later analysis.

- **Continuous Tracing:**
  ```
  traceroute -q 1 -w 1 -n -A example.com
  ```
  Continuously traces the route, sending a single packet per hop with minimal wait time.

## 32. ifconfig or ip: Configure network interfaces.

### `ifconfig` Command:

The `ifconfig` command is used to configure network interfaces on a Linux system. It allows you to view and configure the IP address, netmask, broadcast address, and other parameters of a network interface. However, `ifconfig` has been deprecated in many modern Linux distributions in favor of the more powerful `ip` command.

#### Examples:

1. **Viewing Network Interfaces:**
   ```
   ifconfig
   ```
   This command displays information about all network interfaces on the system.

2. **Viewing Information for a Specific Interface:**
   ```
   ifconfig eth0
   ```
   Replace "eth0" with the name of your network interface. This command displays detailed information about the specified interface.

3. **Assigning an IP Address:**
   ```
   sudo ifconfig eth0 192.168.1.2
   ```
   This command assigns the IP address 192.168.1.2 to the "eth0" interface.

4. **Setting Netmask:**
   ```
   sudo ifconfig eth0 netmask 255.255.255.0
   ```
   Sets the netmask for the "eth0" interface.

5. **Bringing an Interface Up or Down:**
   ```
   sudo ifconfig eth0 up
   sudo ifconfig eth0 down
   ```
   These commands bring the "eth0" interface up or down, respectively.

### `ip` Command:

The `ip` command is a more powerful and flexible tool for configuring and managing network interfaces. It provides a wide range of functionality beyond what `ifconfig` offers.

#### Examples:

1. **Viewing Network Interfaces:**
   ```
   ip link show
   ```
   This command shows information about all network interfaces on the system.

2. **Viewing IP Addresses:**
   ```
   ip address show
   ```
   Displays detailed information about all IP addresses assigned to interfaces.

3. **Assigning an IP Address:**
   ```
   sudo ip address add 192.168.1.2/24 dev eth0
   ```
   Assigns the IP address 192.168.1.2 with a netmask of 255.255.255.0 to the "eth0" interface.

4. **Setting Netmask:**
   ```
   sudo ip address add 192.168.1.2/24 dev eth0
   ```
   This also sets the netmask for the "eth0" interface.

5. **Bringing an Interface Up or Down:**
   ```
   sudo ip link set eth0 up
   sudo ip link set eth0 down
   ```
   These commands bring the "eth0" interface up or down, respectively.

6. **Displaying Routing Table:**
   ```
   ip route show
   ```
   Shows the kernel's routing table.
