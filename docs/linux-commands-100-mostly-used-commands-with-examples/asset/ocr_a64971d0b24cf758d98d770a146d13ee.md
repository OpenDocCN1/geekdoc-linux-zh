```
sed 's/apple/orange/g' fruits.txt
```

This command replaces all occurrences of "apple" with "orange" in the file `fruits.txt` .

# 3. **Delete lines containing a specific pattern:**

```
sed '/pattern/d' file.txt
```

This command deletes all lines containing the specified pattern from the file `file.txt` .

# 4. **Print specific lines:**

```
sed -n '1,5p' file.txt
```

This command prints lines 1 to 5 from the file `file.txt` without automatically printing other lines.

# 5. **In-place editing (update the file):**

```
sed -i 's/old/new/' file.txt
```
