5. **Create a hard link instead of copying:**

```
cp -l file.txt /path/to/link_destination/
```

6. **Preserve ownership and timestamps when copying:**

```
cp -a /path/to/source_directory/ /path/to/destination/
```

**7. Verbose mode (show files as they are copied):**

```
cp -v file1.txt file2.txt /path/to/destination/
```

The `mv` command in Linux is used to move or rename files and directories. It allows you to change the name of a file or move it from one directory to another.

1. **Rename a file:**

```
mv old_file.txt new_file.txt
```
