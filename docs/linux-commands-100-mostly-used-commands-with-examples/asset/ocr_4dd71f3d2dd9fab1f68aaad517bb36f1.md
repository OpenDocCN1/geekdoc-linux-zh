# 2. Move a file to a different directory:

```
mv file.txt /path/to/destination/
```

Moves "file.txt" to the specified destination directory.

# 3. Move multiple files to a directory:

```
mv file1.txt file2.txt /path/to/destination/
```

Moves multiple files to the specified destination directory.

# 4. Interactive mode:

```
mv -i file.txt /path/to/destination/
```

Prompts for confirmation if the destination file already exists.

# 5. Update mode:

```
mv -u newer_file.txt /path/to/destination/
```
