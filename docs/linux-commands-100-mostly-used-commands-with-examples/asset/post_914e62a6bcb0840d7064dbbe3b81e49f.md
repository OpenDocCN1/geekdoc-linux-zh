
## 35. ltrace: A library call tracer.

`ltrace` is a command-line utility in Linux used for intercepting and displaying dynamic library calls that a program makes. It allows you to see the library functions and system calls that a process invokes, providing valuable insights into the behavior of a program during its execution.

**Examples:**

- 1. Basic Usage:

  ```bash
  ltrace ls
  ```

  This command traces the dynamic library calls made by the `ls` command.

- 2. Filtering Output:

  ```bash
  ltrace -e fopen ls
  ```

  The `-e` option allows you to filter the output to display only the functions you're interested in. In this example, it traces only calls to the `fopen` function made by the `ls` command.

- 3. Redirecting Output to a File:

  ```bash
  ltrace -o output.txt ls
  ```

  This command redirects the output of `ltrace` to a file named `output.txt` instead of printing it to the terminal.

- 4. Tracing a Specific Process by PID:

  ```bash
  ltrace -p <pid>
  ```

  Replace `<pid>` with the process ID of the running process you want to trace. This is useful for attaching `ltrace` to an already running process.

- 5. Displaying System Calls:

  ```bash
  ltrace -S ls
  ```

  The `-S` option includes the display of system calls in addition to library calls.

- 6. Tracing a 32-bit Process on a 64-bit System:

  ```bash
  ltrace -a 32 -c ls
  ```

  Use the `-a` option to specify the architecture (in this case, 32-bit) when tracing a process on a 64-bit system.

- 7. Filtering by Library:

  ```bash
  ltrace -l libm.so ls
  ```

  This traces only the calls to functions from the `libm` library made by the `ls` command.

- 8. Displaying Time and Counts:

  ```bash
  ltrace -c ls
  ```

  The `-c` option displays a summary of the number of calls and time spent in each function.

- 9. Tracing a Program with Command-Line Arguments:

  ```bash
  ltrace gzip file.txt
  ```

  You can trace a program along with its command-line arguments.

- 10. Tracing Multiple Commands:

  ```bash
  ltrace -o output.txt sh -c "ls; echo Hello"
  ```

  Tracing multiple commands in a shell by using the `c` option and enclosing them in quotes.

- 11. Displaying Function Arguments:

  ```bash
  ltrace -f -F ls
  ```

  The `f` option follows forks, and the `F` option displays function arguments.

## 36. useradd: Create a new user account.

The `useradd` command in Linux is used to create a new user account on the system. It is a fundamental command, and it allows you to specify various parameters while creating a new user.

**Examples:**

- 1. Create a new user:

  ```bash
  sudo useradd mohan
  ```

  This command creates a new user account named "mohan" with default settings. The user's home directory will be `/home/mohan`.

- 2. Create a user with a specific home directory:

  ```bash
  sudo useradd -m -d /home/customuser customuser
  ```

  The `-m` option ensures the creation of the user's home directory, and `-d` specifies the home directory path.

- 3. Specify the user's login shell:

  ```bash
  sudo useradd -s /bin/bash bashuser
  ```

  This command creates a user named "bashuser" and sets the login shell to `/bin/bash`.

- 4. Set the user's password:

  ```bash
  sudo useradd -m -p $(openssl passwd -1 mypassword) secureuser
  ```

  The `-p` option allows you to set the encrypted password for the user. In this example, `openssl passwd -1` generates the encrypted password for the string "mypassword."

- 5. Create a user with a specific user ID (UID) and group ID (GID):

  ```bash
  sudo useradd -u 1001 -g 1001 customuser
  ```

  The `-u` option sets the user ID, and the `-g` option sets the primary group ID for the user.

- 6. Create a system user:

  ```bash
  sudo useradd -r sysuser
  ```

  The `-r` option is used to create a system user, which is typically used for running system services.

- 7. Set the expiration date for a user account:

  ```bash
  sudo useradd -e 2023-12-31 tempuser
  ```

  The `-e` option sets the expiration date for the user account. In this example, the account for "tempuser" will expire on December 31, 2023.

- 8. Display useradd command help:

  ```bash
  useradd --help
  ```

  This command provides a summary of the `useradd` command options and usage.

## 37. userdel: Delete a user account.

The `userdel` command in Linux is used to delete a user account and related files from the system. It is a powerful command that requires administrative privileges to execute. When a user account is deleted, the associated home directory and mail spool are typically removed, but the user's files in other locations are not touched.

**Examples:**

- 1. Basic usage:

  ```bash
  sudo userdel mohan
  ```

  This will delete the user account named "mohan."

- 2. Remove user and home directory:

  ```bash
  sudo userdel -r jane
  ```

  This will delete the user account "jane" along with the home directory and its contents.

- 3. Force deletion without prompting:

  ```bash
  sudo userdel -f alice
  ```

- 4. Specify a different home directory:

  ```bash
  sudo userdel -m -r bob
  ```

  This will remove the user account "bob" and move the home directory to a backup location.

- 5. Remove user from groups:

  ```bash
  sudo userdel -G developers,sudo charlie
  ```

  This command will delete the user account "charlie" and remove him from the "developers" and "sudo" groups.

- 6. Display help information:

  ```bash
  userdel --help
  ```

  This will display a list of options and their explanations.

## 38. passwd: Change user password.

The `passwd` command in Linux is used to change a user's password. It allows users to update their own password or, if executed by a superuser, change the password for any user on the system.

**Examples:**

- 1. Change your own password:

  ```bash
  passwd
  ```

  You will be prompted to enter your current password and then the new password.

- 2. Change another user's password (as root):

  ```bash
  sudo passwd username
  ```

  Replace "username" with the actual username. This command will prompt you to enter the new password for the specified user.

- 3. Lock a user account:

  ```bash
  sudo passwd -l username
  ```

  This will lock the password of the specified user account, preventing them from logging in.

- 4. Unlock a user account:

  ```bash
  sudo passwd -u username
  ```

  This will unlock the password of the specified user account, allowing them to log in again.

- 5. Delete a user's password:

  ```bash
  sudo passwd -d username
  ```

  This will delete the password of the specified user account, effectively making it impossible to log in using a password.

- 6. Expire a user's password:

  ```bash
  sudo passwd -e username
  ```

  This will force the user to change their password the next time they log in.

## 39. mpstat: Report processors related statistics.

The `mpstat` command in Linux is used to display detailed information about the utilization of each processor in a multi-processor system. It provides statistics for both individual processors and an average across all processors.

**Examples:**

- 1. Display CPU utilization statistics for all processors every 2 seconds, for a total of 3 reports:

  ```bash
  mpstat -u 2 3
  ```

- 2. Display statistics for individual processors:

  ```bash
  mpstat -P ALL
  ```

- 3. Display interrupt statistics:

  ```bash
  mpstat -I SUM
  ```

- 4. Display all available information:

  ```bash
  mpstat -A
  ```
