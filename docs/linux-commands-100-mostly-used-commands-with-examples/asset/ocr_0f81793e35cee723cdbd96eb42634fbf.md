The `-r` option is used to sort the data in descending order.

# ### 3. **Sorting and Redirecting Output to a New File:**

```
sort input.txt > output.txt
```

This command reads the content of `**input.txt**`, sorts it, and then saves the result in `**output.txt**`.

# ### 4. **Sorting Numerical Data:**

```
sort -n numbers.txt
```

If you have a file containing numerical values, the `-n` option can be used to sort them numerically.

# ### 5. **Specifying a Custom Delimiter:**

```
sort -t'!'-k2,2 file.csv
```

If you're working with a file where fields are separated by a specific delimiter (e.g., a CSV file with ";" as a delimiter), you can use the `-t` option to specify the delimiter and the `-k` option to indicate the key field for sorting.
