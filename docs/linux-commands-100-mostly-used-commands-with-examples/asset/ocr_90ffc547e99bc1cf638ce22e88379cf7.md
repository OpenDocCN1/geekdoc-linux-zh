```
sudo ip address add 192.168.1.2/24 dev eth0
```

This also sets the netmask for the "eth0" interface.

# 5. Bringing an Interface Up or Down:

```
sudo ip link set eth0 up
sudo ip link set eth0 down
```

These commands bring the "eth0" interface up or down, respectively.

# 6. Displaying Routing Table:

```
ip route show
```

Shows the kernel's routing table.
