# **73. hostname: Display or set the system hostname.**

The `hostname` command in Linux is used to display or set the system's host name. The host name is a label assigned to a device on a network, and it is used to identify the device in various network operations. The `hostname` command is also useful for viewing or changing the host name of the system.

**Examples:**

+   1. **View the current host name:**

```
hostname
```

This command will output the current host name of the system.

+   2. **Display the fully qualified domain name (FQDN):**

```
hostname -f
```

The `-f` option is used to display the FQDN of the system, which includes both the host name and the domain name.
