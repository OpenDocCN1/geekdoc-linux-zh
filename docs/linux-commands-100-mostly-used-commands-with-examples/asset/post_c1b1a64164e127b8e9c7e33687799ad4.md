### 100. sort: Sort lines of text files.

The `sort` command in Linux is a powerful utility that is used to sort lines of text files or input streams. It is a versatile tool that allows you to arrange data in ascending or descending order based on various criteria.

**Examples:**

**1. Sorting a Text File in Ascending Order:**

```
sort filename.txt
```

This command sorts the contents of `filename.txt` in ascending order and displays the result on the terminal.

**2. Sorting a Text File in Descending Order:**

```
sort -r filename.txt
```

The `-r` option is used to sort the data in descending order.

**3. Sorting and Redirecting Output to a New File:**

```
sort input.txt > output.txt
```

This command reads the content of `input.txt`, sorts it, and then saves the result in `output.txt`.

**4. Sorting Numerical Data:**

```
sort -n numbers.txt
```

If you have a file containing numerical values, the `-n` option can be used to sort them numerically.

**5. Specifying a Custom Delimiter:**

```
sort -t'!' -k2,2 file.csv
```

If you're working with a file where fields are separated by a specific delimiter (e.g., a CSV file with ";" as a delimiter), you can use the `-t` option to specify the delimiter and the `-k` option to indicate the key field for sorting.

**6. Ignoring Leading Whitespace:**

```
sort -b data.txt
```

The `-b` option is used to ignore leading blanks (whitespaces) when sorting.

**7. Unique Sorting:**

```
sort -u names.txt
```

The `-u` option ensures that only unique lines are displayed after sorting. It is useful when you want to eliminate duplicate entries.

**8. Merging Already Sorted Files:**

```
sort -m sorted1.txt sorted2.txt
```

The `-m` option is used to merge two or more pre-sorted files.

**9. Sorting by Month Names:**

```
sort -M months.txt
```

If you have a file containing month names, the `-M` option can be used to sort them in calendar order.

**10. Human-Readable Sorting:**

```
ls -lh | sort -k5,5
```

In this example, the `ls -lh` command lists files with human-readable sizes, and `sort -k5,5` sorts them based on the fifth column (size).
