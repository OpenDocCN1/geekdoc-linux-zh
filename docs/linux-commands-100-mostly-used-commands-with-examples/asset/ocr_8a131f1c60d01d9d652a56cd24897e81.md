This command restores the terminal to a sane state, reverting any changes made with `stty`.

# 8. Disable Flow Control (Ctrl + S and Ctrl + Q):

```
stty -ixon
```

This disables software flow control, allowing you to use `Ctrl + S` and `Ctrl + Q` for other purposes.

# 9. Set Input and Output Speed:

```
stty speed 9600
```

This sets the input and output speed to 9600 baud. Adjust the value based on your requirements.

# 10. Set Terminal to Raw Mode:

```
stty raw
```

This puts the terminal into raw mode, where input is passed through without any processing (useful for some interactive applications).
