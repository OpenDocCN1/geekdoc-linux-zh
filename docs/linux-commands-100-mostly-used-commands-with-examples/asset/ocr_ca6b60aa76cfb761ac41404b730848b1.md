# ### 100. sort: Sort lines of text files.

The `sort` command in Linux is a powerful utility that is used to sort lines of text files or input streams. It is a versatile tool that allows you to arrange data in ascending or descending order based on various criteria.

# **Examples:**

**1. Sorting a Text File in Ascending Order:**

```
sort filename.txt
```

This command sorts the contents of `filename.txt` in ascending order and displays the result on the terminal.

**2. Sorting a Text File in Descending Order:**

```
sort -r filename.txt
```
