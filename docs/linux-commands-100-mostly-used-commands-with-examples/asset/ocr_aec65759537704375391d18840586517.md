```
cd ~/documents
```

7. Navigate Back to the Previous Directory:

```
cd -
```

This command takes you back to the previous working directory.

8. Use of Environment Variables:

```
cd $HOME
```

This command is equivalent to `cd` without any arguments and takes you to your home directory.
