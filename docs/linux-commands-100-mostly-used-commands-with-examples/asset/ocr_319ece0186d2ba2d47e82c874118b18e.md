```
umount --lazy /mnt/data
```

Detaches the filesystem lazily, allowing processes to continue using the filesystem until they finish.

# 12. Unmounting and Detaching Loop Device:

```
losetup -d /dev/loop0 && umount /mnt/loop
```

Detaches a loop device and then unmounts the associated filesystem.

# 80. sftp: Securely transfer files over the SSH protocol.

`SFTP` (Secure File Transfer Protocol) is a secure alternative to FTP (File Transfer Protocol) for transferring files between computers on a network. It provides a secure channel over an insecure network, typically the internet. SFTP encrypts both the command and data connections, preventing unauthorized access to sensitive information.

Examples:

+   1. **Connect to a remote server:**

```
sftp username@remote_host
```
