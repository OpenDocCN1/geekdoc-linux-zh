# Appendix A

# Loop: Do... While

PHP

```
do { ... } while (expr);
```

ASP/VBScript

```
Do ... Loop Until expr
```

ASP.NET/C#

```
do { ... } while (expr);
```

JSP/Java

```
do { ... } while (expr);
```

# Loop: For

PHP

```
for (expr1; expr2; expr3) { ... }
```

ASP/VBScript

```
For expr1 To expr2 Step expr3 ... Next
```

ASP.NET/C#

```
for (expr1; expr2; expr3) { ... }
```

JSP/Java

```
for (expr1; expr2; expr3) { ... }
```
