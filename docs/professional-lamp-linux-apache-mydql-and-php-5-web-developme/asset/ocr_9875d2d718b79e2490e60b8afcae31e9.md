# ## Creating Arrays

PHP

```
$name = array(elem1, elem2, elem3);

$name = array('key1' => elem1, 'key2' => elem2, 'key3' => elem3);
```

ASP/VBScript

```
Dim name(length)
```

ASP.NET/C#

```
type[] name = new type[length];
```

JSP/Java

```
type[] name = new type[length];
```

# ## Referencing Array Elements

PHP

```
$name[index]

$name['key']
```

ASP/VBScript

```
name(index)
```

ASP.NET/C#

```
name[index]
```

JSP/Java

```
name[index]
```
