# **Loop: For Each**

**PHP**

```
```
foreach (array as $item) {
...
}
```
```
foreach (array as $key => $item) {
...
}
```
```

**ASP/VBScript**

```
```
For Each item In array
...
Next
```
```

**ASP.NET/C#**

```
```
for (type item in array) {
...
}
```
```

**JSP/Java**

```
```
for (Iterator item; item.hasNext(); ) {
...
}
```
```

# **Loop: Termination**

**PHP**

```
```
break;
```
```

**ASP/VBScript**

```
```
Exit Do
Exit For
```
```

(There is no exiting a While loop.)

**ASP.NET/C#**

```
```
break;
```
```

**JSP/Java**

```
```
break;
