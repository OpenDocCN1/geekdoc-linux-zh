+   ◇ VGA *compatible graphics modes*—In general, for all modes following, the first number is the amount of x pixels, the second is the amount of y pixels, and the third is the number of colors (with shortcuts 32K, 64K, 16M, and 16M4 in lieu of 32,768, 65,536, and 1,677,721). Those with two colors or more than 256 colors use fixed-color mappings (either black and white or some RGB true/high color); the others make use of a color lookup table. Memory layout for the VGA modes is weird—too weird to be explained here. However, you can check the usual VGA literature. *vga_setmode*(X()) has a short explanation that’s valid for all 256 color modes. Here, VGA are the VGA modes: (1) G320x200x16, (2) G640x200x16, (3) G640x350x16, (4) G640x480x16, (5) G320x200x256, (6) G320x240x256, (7) G320x400x256, (8) G360x256, and (9) G640x480x2.

+   ◇ Basic *SVG* A modes—These use linear 256-color memory layouts similar to G320x200x256. These modes are (10) G640x480x256, (11) G800x600x256, (12) G1,024x768x256, and (13) G1,280x1,024x256.

+   ◇ *High color SVG* A modes—These also use linear memory layouts, but for 32K and 64K, each pixel occupies two bytes, and three for 16M. For 32K, each 16-bit word is divided into 555-bit portions referring to 5-bit red, green, blue parts. The most significant bit is ignored by the card. For 64K, the division is 565, allowing you to specify green in a little more detail. (Human eyes are more sensitive to green. People joke that this is because our ancestors lived in trees where light was filtered through green leaves.) For the 16M modes, from low to high addresses, the three bytes are named BGR and specify the blue, green, and red parts of the pixel value. These modes are (14) G320x200x32K, (15) G320x200x64K, (16) G320x200x16M, (17) G640x480x32K, (18) G640x480x64K, (19) G640x480x16M, (20) G800x600x32K, (21) G800x600x64K, (22) G800x600x16M, (23) G1,024x768x32K, (24) G1,024x768x64K, (25) G1,024x768x16M, (26) G1,280x1,024x32K, (27) G1,280x1,024x64K, and (28) G1,280x1,024x16M.

+   ◇ *High resolutions with less color numbers*—Memory layout is probably one nibble per pixel and two pixels per byte in a linear fashion where the most significant nibble is the leftmost pixel. These modes are (29) G800x600x16, (30) G1,024x768x16, and (31) G1,280x1,024x16.

+   ◇ *Hercules emulation mode*—Again, check out the ordinary VGA literature for the memory layout. This mode is (32) G720x348x2.

+   ◇ *32-bit per pixel modes*—These are similar to 16M, but each pixel uses four bytes. The first three are similar to 16M but the fourth is left empty and ignored by the VGA card (you can store your own status there). This eases pixel address calculations on the screen and drawing operations. However, one-higher more data has to be moved to the screen. Experiments show, usually, that the higher memory bandwidth used outweighs the effects of the simplified algorithms by far. These modes are (33) G320x200x16M32, (34) G640x480x16M32, (35) G800x600x16M32, (36) G1,024x768x16M32, and (37) G1,280x1,024x16M32.
