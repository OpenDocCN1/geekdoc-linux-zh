As of now, the following calls are defined.

Query availability of features includes the following:

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_SET)\u2014Returns an `int` with the `i`th bit set if `i` is a valid `what` parameter for `vga_ext_set`().

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_ACCEL)\u2014Returns an integer with the `i`th bit set if `i` is a valid parameter for `vga_accel`(). For nicer code, the following integers are predefined to have a bit set in the right position: ACCELFLAG_FILLBOX, ACCELFLAG_SCREENCOPY, ACCELFLAG_PUTIMAGE, ACCELFLAG_DRAWLINE, ACCELFLAG_SETGCOLOR, ACCELFLAG_SETBGCOLOR, ACCELFLAG_SETRANSARENCY, ACCELFLAG_SETRASTEROP, ACCELFLAG_PUTBITMAP, ACCELFLAG_SCREENCOPYBITMAP, ACCELFLAG_DRAWLINEHIST, ACCELFLAG_SETMODE, and ACCELFLAG_SYNC.

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_ROP)\u2014Returns an integer as `VGA_AVAIL_ACCEL` does, but this time listing the `vga_accel`() operations that obey a `vga_accel`(ACCEL_SETRASTEROP, ...) setting.

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_TRANSPARENCY)\u2014Returns an integer as `VGA_AVAIL_ACCEL` does, but this time listing `vga_accel`(3) operations that obey a `vga_accel`(ACCEL_SETTRANSPARENCY, ...) setting.

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_ROPMODES)\u2014Returns an integer with the `i`th bit set if `i` is a valid mode parameter for a `vga_accel`(ACCEL_SETRASTEROP, mode) call. Here\u2019s an example:

```
```
if (vga_ext_set(VGA_EXT_AVAILABLE, VGA_AVAIL_ROPMODES) &
    (1 << ROP_XOR))
{
    vga_accel(ACCEL_SETRASTEROP, ROP_XOR);
} else {
    /* do something else */
}
```
```

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_TRANSMODES)\u2014Returns an integer with the `i`th bit set if `i` is a valid mode parameter for a `vga_accel`(ACCEL_SETTRANSPARENCY, mode, ...) call. The function lists only the supported enable functions (currently ENABLE_TRANSPARENCY_COLOR and ENABLE_BITMAP_TRANSPARENCY). It\u2019s assumed the corresponding disable functions will then exist as well.

+   \u2022 `vga_ext_set`(VGA_EXT_AVAILABLE, VGA_AVAIL_FLAGS)\u2014Returns an `int` with 1-bit on/off flags. Bits that are set refer to special features that can be enabled in the current mode.
