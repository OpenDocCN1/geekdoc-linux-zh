# # What's On The CD-ROM

The **Linux Graphics Programming with SVGAlib's** companion CD-ROM contains elements specifically selected to enhance the usefulness of this book, including:

+   * Source code for the book's projects—You can adapt these programs and snippets based upon your needs.
+   * SVGAlib versions 1.4.0 and 1.4.1.
+   * An awesome collection of real-world applications, including:
+   * Games—Sastroids, Sabre (flight sim), Stris, Doom, Haxen, Quake, and more!
+   * Image viewers, including zgv 5
+   * Ghostscript
+   * Fonts
+   * Additional libraries designed to accelerate program development, such as:
+   * FreeType—TrueType font manipulation
+   * liblug—Image manipulation
+   * Additional documentation

# ## System Requirements

Here are the following system requirements:

**Software**

+   * SVGAlib 1.4.0 is needed to complete all the projects included in this book. Newer versions of SVGAlib are always backwards compatible, so please don't hesitate to use a more recent release.
+   * Any version or distribution of Linux. A 2.2 series kernel is recommended.
+   * The GNU C compiler. Version 2.95 (or anything greater) is recommended.

**Hardware**

+   * PC with an Intel (or equivalent) 486 processor; a Pentium 133MHz processor is recommended.
+   * 8MB of RAM is the recommended minimum; 32MB is suggested.
+   * 4MB of hard drive space is all that's needed for SVGAlib itself. Further allocation of drive space for program development is contingent upon your needs, but an additional 20MB might be a good place to start.
+   * Standard VGA graphics adapter (or better). Your programming experience will be greatly enhanced with a card capable of at least 16M colors and a screen resolution of 1,024 by 768 pixels.
+   * VGA or higher resolution monitor, Super VGA recommended.
