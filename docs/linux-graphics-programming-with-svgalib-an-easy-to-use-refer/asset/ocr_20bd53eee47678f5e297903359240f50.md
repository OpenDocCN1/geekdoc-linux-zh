As you can imagine, though, this method becomes pretty tedious, especially if you’re dealing with a complex image.

# **Listing 10.1 Tediou animation.**

```
/* Background is black (0) */

/* Draw image */
vga_setcolor(vga_white());
vga_drawline(300, 180, 309, 180);
vga_drawline(300, 181, 309, 181);
vga_drawline(300, 182, 300, 187);
vga_drawline(301, 182, 301, 187);
vga_drawline(308, 182, 308, 187);
vga_drawline(309, 182, 309, 187);
vga_drawline(300, 188, 309, 188);
vga_drawline(300, 189, 309, 189);

/* Erase image */
vga_setcolor(0);
vga_drawline(300, 180, 309, 180);
vga_drawline(300, 181, 309, 181);
vga_drawline(300, 182, 300, 187);
vga_drawline(301, 182, 301, 187);
vga_drawline(308, 182, 308, 187);
vga_drawline(309, 182, 309, 187);
vga_drawline(300, 188, 309, 188);
vga_drawline(300, 189, 309, 189);

/* Redraw image, 2 pixels to the left */
vga_setcolor(vga_white());
vga_drawline(298, 180, 307, 180);
vga_drawline(298, 181, 307, 181);
vga_drawline(298, 182, 298, 187);
vga_drawline(299, 182, 299, 187);
vga_drawline(306, 182, 306, 187);
vga_drawline(307, 182, 307, 187);
vga_drawline(298, 188, 307, 188);
vga_drawline(298, 189, 307, 189);
```

Obviously, you’d be out of your mind to do it that way. A much cleaner (and easier) method would be to create a drawing function, as shown in Listing 10.2. Then, you could pass the coordinates of the upper-left corner of the square to the function, as well as the desired color, with something like **book\_example(x, y, c)**. After all, why not let the computer do the work? That’s why they were invented.
