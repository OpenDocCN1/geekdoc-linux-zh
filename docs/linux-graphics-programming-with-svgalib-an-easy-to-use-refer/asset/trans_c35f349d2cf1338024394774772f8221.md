
## 空间细分

幸运的是，你也可以将山脉延伸到第三维度。这一过程被称为*空间细分*，图16.6至图16.9展示了其中一个示例。不过，目前请集中关注图16.5，它展示了循环（*或迭代*）的一次完整过程。在开始时（左侧），你可以看到一个向远处延伸的方形。该方形被细分（中间部分），然后随机扰动，使得线条的交点被随机抬高或降低（最终呈现为右侧的最终图像）。

同样，只需几次该过程的迭代就足以展示其效果。在最终细分阶段（如图16.9所示），你所得到的确实看起来像是一个景观的线框模型。如你所见，随着每个周期的进行，“山地”效果变得越来越明显。可以想见，如果在某个阶段对正方形进行着色，其效果可能看起来相当逼真。

这是一种生成景观的方式——虽然是一种粗糙的方式。如果你进一步将正方形分解为三角形，甚至可以采用SVGAlib的threeDKit（使用 `gl_triangle()`）对你的山脉进行平滑着色，从而消除任何突兀的色调变化。

> > *这种三角形着色过程将是第12章中讨论的“填充多边形”技术的一个应用。*

## 钻石-平方算法

空间细分的实际机制最早由Alain Fournier、Don Fussell和Loren Carpenter在新浪潮（New Wave）风格巅峰时期——1982年——记录下来。在题为《随机模型的计算机渲染》（“Computer Rendering of Stochastic Models”）的论文中，他们描述了现在普遍称为**钻石-平方算法**（Diamond-Square algorithm）的方法。其方法很简单，这一点可以从图16.10和图16.11中得到证明。

![](img/2e475714ef8969ed272622c46473d334_333_0.png)

**图16.10**
钻石-平方算法的第1步至第3步。

从一个简单的网格开始（例如图16.5和图16.10中的那些），根据需要执行以下两步过程任意多次：

1. 对于网格中的每个“正方形”，确定其中点，并创建一个新的中心点。这被称为钻石步骤，因为此时网格看起来由钻石形组成。
2. 接下来，计算每个钻石形的中点并将其绘制出来。这是平方步骤，因为网格再次看起来像一堆正方形。

只需几次迭代即可开发出一个足够详细的网格。如果需要更多细节，只需重复上述过程（泡沫、冲洗、重复）。如果最终结果旨在呈现为三维景观，那么每个新点也会根据周围邻居的高度分配一个随机高程。这样，就可以非常快速地生成地形图。

## 高度场

接下来的技术涉及使用**高度场**。高度场是一个值数组，用于描述网格上点的高程。换句话说，如果你有一个延伸到远处（类似于图16.5左侧图像）的 x-y 网格，你可以为该网格上的每个点分配一个值。该值将代表点的高度（或高程）。

高度场使用起来很便利，因为它具有良好的可移植性。因为它仅仅由一个数组组成，所以它可以在一台计算机上创建，然后传输到另一台计算机上进行渲染。更简单地说，它允许你分离景观设计的过程。一个函数（或程序）创建景观，而另一个函数负责实际的绘制。

列表16.1中给出的程序创建一个高度场，然后使用一个简单的光线追踪（或光线投射）算法对其进行渲染。有趣的地方在于，你可以以第一人称视角查看景观。换句话说，它看起来你似乎实际上置身于场景中，而不仅仅是一个远处的观察者。此外，通过鼠标，你可以左右转动，并上下移动以检查地形。本章稍后的图16.12展示了一个示例视图。

该景观以红色色调绘制，赋予其一种超凡脱俗的外观。通过按下加号键（+），你可以在这个奇异的环境中“向前移动”，该环境在移动过程中实时渲染。结果绝对令人惊叹，如果你只编译本书中的一个程序，我强烈建议你编译这个。我能想到的最接近的比较是电影《2001太空漫游》（2001: A Space Odyssey）接近尾声的场景，那时David正在飞越遥远月球表面之上。当然，代码已包含在配套光盘CD-ROM中，因此你可以省去重新输入所有内容的工作。请查看。
