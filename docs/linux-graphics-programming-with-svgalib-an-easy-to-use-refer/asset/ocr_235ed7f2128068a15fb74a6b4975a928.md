Therefore, you can employ gl_setwritemode(int m) to make the font's background transparent. Argument m can be one of four values, and the one for transparency is WRITEMODE_MASKED. The complete list of defines and their corresponding values can be found in Table 19.1. Note that two values will be in effect at all times—one for WRITEMODE and one for FONT. For example, if you change WRITEMODE, the FONT state will remain the same as before.

The two fonts pose one more problem, however. The “transparency” made possible by gl_setwritemode() isn't anything magical. It simply decides whether the background color should be printed. This works fine, except when your font is the same color as the background (that is, black). Then you'll get nothing—your font will be transparent, just like the background. And, of course, if gl_setwritemode(WRITEMODE_OVERWRITE) is set, your result will be nothing more than a black box—a black font on a black background. To circumvent this aggravating and unfortunate combination of “features”, you can set the font’s color to be most, but not entirely, black. I've used gl_rgcolor(10, 10, 10), which, being on the 256-color scale, appears to be a solid shade of pure, all-American charcoal black. Be careful not to set your RGB values too low, though, because gl_rgcolor() may round you down to 0, thereby defeating your efforts.
