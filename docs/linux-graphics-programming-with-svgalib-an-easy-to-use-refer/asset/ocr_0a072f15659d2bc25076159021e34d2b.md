+   - mouse_setrange(int y1, int y2);
+   - mouse_setwrap(int state);

# Listing 15. Manual initialization of the mouse.

```
mouse_init("dev/mouse", MOUSE_MICROSOFT, MOUSE_DEFAULTSAMPLERATE);
mouse_setrange(0, WIDTH - 1);
mouse_setrange(0, HEIGHT - 1);
mouse_setwrap(MOUSE_NOWRAP);
```

The first command, mouse_init(), requires three arguments: the device in question (dev/mouse is the default), the type of mouse, and the sample rate (explained in the following paragraph). Next, the "territory" for the mouse is set with mouse_setxrange() and mouse_setyrange(). This will usually be the entire screen, but that decision is left up to you. Remember that WIDTH and HEIGHT are defined in vga.h, so these constants won't be automatically available if you're using plain-ol' libvga (standard VGA/lib). Finally, mouse_setwrap details what happens if the mouse is pushed past the edge of its range.

Of course, you don't have to use the same arguments demonstrated in Listing 15.1. MOUSE_DEFAULTSAMPLERATE is defined as 150 (Hz), but you may use any other value. Table 15.1 details all the possible values for mouse_init()'s mouse type.

If you don't want to hard-code a mouse type (and you probably shouldn't), vga_getmousetype(void) will return the int value that's defined in libvga.config.
