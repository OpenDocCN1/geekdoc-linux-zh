1.0.6.tar.gz). The binary version may download more quickly, but I experienced a number of errors trying to work with it. The source, however, compiled like a charm.

You’ll also want to download the documentation: libg-\f*Manual.tar.gz. Unfortunately, the manual is contained in a PostScript (PS) file. Not everyone has the ability to read these, I know, so I’ve “distilled” the file into an Acrobat PDF file that you can find on the accompanying CD-ROM.

libgbuf itself utilizes some external libraries. Most notably, these include libjpeg.a and libtiff.a. If you want this functionality, you can find these at Metalab as well, in same directory that you found libgbuf. Look for libjpeg-6a.tar.gz and libtiff-3.0-ELF.tar.gz.

To compile libgbuf, I copied the \f*Makefile.linux to create a Makefile, and then I did some editing. For the compiler options, I added \f*-O3 and \f*-Wall. Then, I specified which image libraries I wanted to include, as I mentioned above. (Just comment out the definitions that you don’t want.) I proceeded to define the viewer as \f*SVGA\f*Lib (\f*VIEWDEF = -Di\f*LINUX), and I removed \f*show/xl.1.o from the Library Objects section (\f*OBJS).

After that, I just ran \f*make.

> **Note**  
> Although you won’t see the name “\f*SVG\f*ALib” anywhere in \f*libgbuf, that’s what “\f*Linux” means. If you look at the source, it does indeed use \f*libvg.a and \f*libvgagl.

The final product is installed in \f*/usr/local/lib, unless you specified differently. This shouldn’t be a problem; \f*ld should be able to find it there. If you’re concerned, however, double-check to make sure this path exists in your \f*/etc/ld.so.conf file.

Once the library’s installed, you can jump right in. If you’ll have a look at some of the GIF functions contained within \f*libgbuf, you’ll see how they’ll make your life:

+   - \f*read\f*_gif\f*\f*file(char \f*\f*file\f*_name, bitmap\f*_hdr \f*\f*bitmap)
+   - \f*write\f*_gif\f*\f*file(char \f*\f*file\f*_name, bitmap\f*_hdr \f*\f*bitmap)

After you’ve read a GIF file with \f*read\f*_gif\f*\f*file(), you can easily print the image to the screen with \f*gl\f*_put\f*box(int \f*x, int \f*y, int \f*w, int \f*h, void \f*\f*\f*dp), where \f*\f*\f*bitmap and \f*\f*\f*dp are pointers to the same image. Conversely, \f*gl\f*_get\f*box(int \f*x, int \f*y, int \f*w, int \f*h, void \f*\f*\f*dp) will help you copy part of the screen into memory, which you can then print to a file with \f*write\f*_gif\f*\f*file().
