| Unknown | • `Restorerefoc.c` as distributed in v0.3 missed a case line in a switch statement that made it useless.<br>• Each VGA register write in the library was producing silly debugging code (I forgot to restore the macro definition), making everything significantly larger than necessary.<br>• Added the `vga_getchipset()` function. `Vgtest` now only lists modes that are available.<br>• The ET4000 driver has been improved, including Hicolor DAC detection (thanks to David Monro and Daniel Jackson).<br>• Cirrus driver: Fixed 5420/2/4 bug, cleaned up detection, changed the 800x600 timings, and added missing modes 1_024x768x256/32K/64K, as well as 320x200x15/16/24bit. Also, there’s support for some of the accelerated features of the Cirrus 5426, the driver provides `bitblt` (move box), `fillblt` (fill box), and `imageblt` (write bitmap from system memory) functions.<br>• Display start address can now be meaningfully changed in 16-color and planar 256-color VGA modes for page flipping (the address is expressed as the number of pixels).<br>• Fixed the `vga_flip()` functionality: if you press escape during `vga_getch()`, the console is switched to text mode until another key is pressed. (Note: This has been obsoleted by console switching.)<br>• The default amount of video memory saved in SVGAlib modes is the size of one screen. If the program uses more (if it uses page flipping, for example), you must indicate it with the `vga_claimvideomemory()` function. This prevents 2,048K or 1,024K being saved when only a few hundred kilobytes is required.<br>• SVGAlib now waits until the virtual console it is running in becomes active before setting the first graphics mode.<br>• Implemented transparent virtual console switching, which uses `vga_flip()`. |
