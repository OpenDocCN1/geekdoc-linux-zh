a small security breach, because it’s passed on to any programs that you fork off. Bear in mind, however, that some SVGA card drivers have to use iopl()l anyway. If you use it, call that function as the very first VGA function. Call it right before vga_init(). Note that `vga_safety_fork()` will already enter a graphics mode for font and graphics state saving. Don’t overestimate the power of this function: Your application will continue to run in the background while a foreground application will restore a usable screen and graphics mode in the event of a crash. The `forktest` demo shows the principal operation of this function.

# **void vga_setchipset(int chipset)**

Forces detection of a chipset (when chipset detection fails). `vga_setchipset(VGA)` can be useful if the chipset-specific information or the SVGA-detection information gives you problems. However, the automatic detection should work well from the start, and if not, a specific chipset can be forced from `/etc/vga/libvga.config`. Because of this, `void vga_setchipset(int chipset)` should probably never be used by applications. If used it’s nevertheless, it should be called directly before `vga_init()`.

As of now, the following values are defined for *chipset*:

+   * UNDEFINED—This is the default. It specifies autodetection.
+   * VGA—A plain VGA card. This does not mean that the SVGA card will behave like an ordinary VGA card.
+   * ET4000—Tseng ET4000/ET4000W32(i/p) cards.
+   * CIRRUS—Cirrus Logic GD542x/3x cards.
+   * TVGA8900—Trident TVGA 8900C/9000 (and possibly also 8800CS/8900A/B cards).
+   * OAK—Oak Technologies OT1-037/67/77/87 cards.
+   * EGA—An ordinary EGA card. The notes about VGA apply.
+   * S3—An S3 base card.
+   * ET3000—Tseng ET3000 cards.
+   * MACH32—A card (not necessarily from ATI) based on the ATI Mach32 chipset.
+   * GVGA6400—A Genoa(?) GVGA6400 card.
+   * ARK—ARK Logic ARK1000PV/2000PV cards.
+   * ATI—An ATI SVGA (VGA coder and friends) card. This does not (necessarily) include the newer cards (usually called Mach something).
+   * ALI—An ALI2301-based card.
+   * MACH64—A card using the ATI Mach64 chipset. Support is not yet complete.
+   * CHIPS—Chips and Technologies chipsets 65525, 65535, 65546, 65548, 65550, and 65554 (usually found in laptops).
