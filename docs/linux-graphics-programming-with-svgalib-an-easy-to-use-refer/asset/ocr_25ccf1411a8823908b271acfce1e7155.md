int **vga_getpalvec**(int start, int num, int \*pal)

Gets the **num** colors starting with index **start** from the color lookup table and stores the RGB values in \*pal. \*pal contains **num** 3-integers, which are the color values from first to last palette entry in the order red, green, blue (three consecutive entries in \*pal always build a palette entry).

Each color entry is in the range 0 to 63. This function is only sensible in 16- or 256-color modes. It shows which color all **vga_setcolor**(start)-drawn pixels (and **num** -1 following colors) will actually refer to. If the VGA_CLUT8 feature has been set for the current mode with **vga_ext_set**(), the red, green, and blue values will be in the range 0 to 255. The function returns the value of **num**.

# Mouse Handling

The functions in this section cover mouse handling:

> These functions must include **<vgamouse.h>**.

void **vga_setmousesupport**(int stat)

Sets mouse support; 0 disables (default), and 1 enables. If enabled, the mouse is set up for the same screen resolution as the current graphics mode. You can then use the various mouse functions. You can also use **mouse_init**() for more flexibility. However, this isn't the standard procedure for applications—the mouse is configured in **/etc/vga/libvga.config**, and your application will want to use that. The **mousetest**(), **eventtest**(), and **spin**() demos make use of the mouse functions.
