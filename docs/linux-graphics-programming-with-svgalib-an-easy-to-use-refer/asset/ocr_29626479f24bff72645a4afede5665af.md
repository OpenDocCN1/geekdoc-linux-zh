# Creating 3D Objects

Whereas objects in 2D space are comprised of (x, y) points, a 3D object needs three values to calculate its position: x, y, and z. The z-axis represents depth, just as it does in Cartesian mathematics.

Listing 12.1 contains sphere.c, a fairly well-known piece of code written by Jon Leech. As you can see, it’s rather dated (1989) in today’s world of fast-moving targets. Nonetheless, it works just as well now as it did back then.

The code creates a set of coordinates for a sphere—that is, a 3D circle. It actually uses triangles to compose the sphere, and with each loop or iteration, the sphere becomes more refined. As you may recall from Chapter 11, the triangle is the foundation for almost every bit of 3D imagery—it’s the spatial form with the least amount of points (not counting lines and points themselves). In other words, a program can precisely define an object composed of triangles without needing much in the way of processor overhead, and, concurrently, a spatial object made of triangles has the least amount of rough edges.
