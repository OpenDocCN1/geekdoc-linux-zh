# Creating Your Own Functions

Wouldn't it be nice if you could set the background color to anything you want at the beginning of your program? Or perhaps draw a square with a single statement? Unfortunately, with straight SVGAlib, you can't. Now, vga\* (the high-level library of drawing functions that complements SVGAlib) is filled with all sorts of fun stuff like that, but let's stick with pure SVGAlib for the moment. So, how can you color the screen without having to code a bunch of vga\_drawline( ) functions? The answer is, of course, to create our own function. You save time by coding this procedure once and never having to do it again.

Listing 3.12 contains a sample function for setting the background color using only pure SVGAlib. We'll use two new functions to do it: vga\_getxdim( ) and vga\_getydim( ). These will tell us the x and y dimensions of the current screen mode—for example, the integer value returned by vga\_getxdim( ) while in screen mode 5 (G320x200x256) is 320.

Now, what to call this new function? I don't want to preface it with vga because someone might be confused and think it's an actual, out-of-the-box function that comes with his or her distribution of SVGAlib. Instead, let's name it book\_background( ). Listing 3.12 shows what I'm talking about.

```
Listing 3.12 **book\_background().**
```c
void book_background(int color)
{
  int x,
        y,
        xmax = vga_getxdim(),
        ymax = vga_getydim();

  vga_setcolor(color);

  for (y = 0; y < ymax; y++)
  {
    for (x = 0; x < xmax; x++)
    {
      vga_drawline(0, y, xmax, y);
    }
  }
}
```
```

Now you can change your background in one clean sweep—just insert the function into your program, include the proper declaration, and away you go! For example, to make your background cyan, just use **book\_background**(3). Listing 3.13 provides an example of using this function.
