```
void gl_triangle(int x0, int y0, int x1, int y1, int x2, int y2, int color, int bf)
```

Draws a noninterpolated (solid) triangle between the three points 0, 1, and 2 using the color given in color. The bf value is used to tell the routine not to draw the triangle if it's facing the other way. Also, bf tells which way the triangle needs to be facing to be drawn, because you'll more than likely require both combinations.

It's important to know that bf = 0 disables drawing when the points are arranged clockwise, bf = 1 disables drawing when the points are arranged counterclockwise, and bf = -1 will probably always draw the triangle.

```
void gl_swtriage(int x0, int y0, int xd0, int yd0, int x1, int y1, int xd1, int yd1, int x2, int y2, int xd2, int yd2, int c, TD_tridata *tri);
```

The following code

```
typedef struct {unsigned char *bitmap1; unsigned char *bitmap2; int bf; } TD_tridata;
```

draws a triangle at points 0, 1, and 2 by mapping the pixmaps defined in the TD_triangle structure into the triangle.

The xd and yd values represent the triangle on the bitmap, and the x and y values represent the triangle on the screen.

bitmap1 defines the back side of the triangle, and bitmap2 the front.

The bf value is used to tell the routine to draw the backside if it is facing the other way. Also, bf tells which way the triangle should be facing to show the front, because you will more than likely require both combinations.

It's important to know that bf = 2 defines the back to be drawn when the points are arranged clockwise, bf = 3 defines the back to be drawn when the points are arranged counterclockwise, and bf = -1 will probably always draw the front.

```
void gl_triangle(int x0, int y0, int z0, int x1, int y1, int z1, int x2, int y2, int z2, int bf)
```

Draws a triangle between the three points 0, 1, and 2. The colors at these points are z0, z1 and z2. Therefore, if you set the palette to grayscale, the triangle will have an interpolated gray shade.

If you're using more than 8-bit color, the z values will be interpreted as an index to a lookup table that's, at most, 4,096 entries long. Each entry is of type long. You can set the entries with the function gl_tricolorlookup().

The bf value is used to tell the routine to draw the backside if it's facing the other way. Also, bf tells which way the triangle should be facing to show the front—you'll more than likely require both combinations.
