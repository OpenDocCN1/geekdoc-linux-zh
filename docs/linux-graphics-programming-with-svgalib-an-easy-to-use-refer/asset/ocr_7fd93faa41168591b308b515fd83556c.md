# Palettes In Vgagl

Just as you have vga_setpalette() in SVGAlib, you have gl_getpalettecolor(int c, int *r, int *g, int *b) in vgagl. This function works in precisely the same manner as vga_setpalette(), too, with the returned values being in the 0 to 63 range. It is possible to change this range to 0 to 255, but we'll cover that in Chapter 6.
