# Conclusion

The nonrectangular polygon is one element of SVGAlib that's largely missing. The purpose of this chapter is therefore, to help you circumvent this absence. As you'll learn, polygons are a key element in the construction of three-dimensional images, and as such, they're highly useful.

In general, I'd recommend using the triangle functions in threeDKit over some of my earlier examples—the speed and simplicity can't be beat. But if you enjoy tinkering, there's nothing wrong with doing it from scratch either. SVGAlib programming is still regarded as a "dark art" (although hopefully this book will help alleviate that), and I imagine it'll be quite some time before the "rules" are set. With that in mind, you are free to explore and innovate.
