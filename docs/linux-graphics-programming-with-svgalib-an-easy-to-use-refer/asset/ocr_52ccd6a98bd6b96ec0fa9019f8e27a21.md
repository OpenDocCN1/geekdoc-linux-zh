# Graphical Interfaces On Unix/Linux

Of course, GUIs aren’t limited to desktops. Another early graphical interface was Motif, designed for Unix and the X Windowing System. Because X isn’t restricted to Linux, Motif could be found across multiple platforms, including Sun and AT&T systems. This made it enormously successful and widely utilized, and it’s still in use today.

More recently, a new breed of graphical interfaces has been developed, specifically for Linux. You may be familiar with them; they include GNOME (the GNU Network Object Model Environment) and KDE (the K Desktop Environment).
