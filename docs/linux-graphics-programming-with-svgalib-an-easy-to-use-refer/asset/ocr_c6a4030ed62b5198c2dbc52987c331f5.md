# Animation In Place

Of course, animation doesn't have to involve objects in motion. The rippling of waves on a lake, or a hand opening, or a tree swaying in the breeze are all examples of what I'd call static animation. Sure, there's movement, but it's subtle. The scene changes, but in a passive sense.

If you use the Web regularly, you'll have noticed examples of this in the upper right corner of your browser window: the 1" square starry night scene in Netscape, or else the revolving globe in Explorer.

Figures 10.4 through 10.9 illustrate this approach to animation. Using liblug, you can patch an almost infinite (well, as infinite as your SIMMs will allow) sequence of frames, each one differing slightly from its predecessor. In this way, you can create a cinematic experience with SVGAlib.
