# ## Appendix G
# FAQs And Troubleshooting

Contrary to popular belief (primarily amongst newbies), SVGAlib doesn't provide any debugging tools at this time. Perhaps you've become accustomed to more advanced program-ming environments that instantly detect syntactical errors as they're being typed, much in the same way that several modern word-processing programs systematically check for mistakes in spelling and grammar. However, you'll find no such luxuries here. If your application doesn't execute or is running improperly, it's up to you to determine the root cause of the problem. Because SVGAlib programs are written like every other C program on Linux (that being with a simple, unintelligent text editor such as pico or vi), you'll likely need to do some debugging at one time or another.

Don't despair, however, because this deficiency isn't nearly the insurmountable challenge that it might first appear to be. You've got several resources at your disposal, and many of them are listed here. For starters, it's highly probable that the error you've experi- enced has crept up sometime in the past. Therefore, this next section will cover several common problems that beginners have experienced and routinely post to USENET, mailing lists, and message boards.
