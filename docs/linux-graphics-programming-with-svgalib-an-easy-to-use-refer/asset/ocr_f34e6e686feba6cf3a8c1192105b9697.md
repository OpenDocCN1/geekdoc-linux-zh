# Basic Code

To start with, I’m going to check and verify that the video card can handle a screen mode with a 640x480 matrix and 32K colors. If you’re curious as to why I’ve chosen 32K, it’s because it’s the next step up from 256. Although 256 overall colors might be adequate, it’s possible that the user will attempt to load a GIF image with 256 colors of its own. If those don’t match the colors used by the interface, some will be corrupted or lost. Therefore, 32K is necessary, and if the video card in question can’t handle this, then the program should exit with an error message.
