I'll take a break here to point out that the main loop's criteria will need to deviate from the previous chapter's example. Neither "Q" nor "q" can be used to break there by proxy, because someone may need to type that letter as part of the program. So, what was once

```
while ((key = vga_getkey()) != 27) && (key != 81) && (key != 113)
```

must now be merely the following:

```
while ((key = vga_getkey()) != 27)
```

The only ways to exit the program now are the Esc key and the menu bar. Listing 19.2 continues the program, beginning with this line.

# Listing 19.2 The menu bar (continued)

while ((key = vga_getkey()) != 27) {
mouse_update();
x = mouse_getx();
y = mouse_gety();
button = mouse_getbutton();

if ((x != ox) || (y != oy)) {
move_cursor(x, y, ox, oy);
ox = x;
oy = y;
}

if (button & MOUSE_LEFTBUTTON) {
if (y <= 19)
/* we're in the menu bar */
{
if ((x >= 45) && (x < 79))
{
file_menu();
} else if ((x >= 105) && (x <= 139)) {
edit_menu();
}
}
}
