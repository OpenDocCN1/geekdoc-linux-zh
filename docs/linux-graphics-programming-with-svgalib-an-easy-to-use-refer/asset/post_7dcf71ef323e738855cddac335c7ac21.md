Two steps are necessary to achieve 3D realism: the creation of the objects (that is, the definition of the mathematical and spatial properties of the shapes in question) and the rendering of those images on the screen. The previous chapter examined the first step—the coding of the 3D objects—but was remiss in the subject of rendering. We’ll go over that second step here.

## Rendering 3D Objects

Up until now, examples have relied on the threeDKit’s gl_triangle() function and its adaptation of Gouraud shading to create screen images with the illusion of depth. Perhaps you remember Chapter 6, in which I showed you how to create the look of a three-dimensional sphere with purely two-dimensional techniques (in other words, I cheated). These measures are adequate as a stopgap; they’re fast, and fairly easy on the processor. However, if you’re depending on photorealism, there’s a much better way.

To achieve the subtle variances of color and shadow that one expects in a life-like view, it’s necessary to employ a different technique. What we’ll use is something called raytracing.

MinRay, shown in Listing 13.1, is a “minimal” raytracer—although it holds its own against the competition quite nicely. This small program was written as a demonstration of how a raytracer works. The output is phenomenal for such a compact piece of code—see for yourself in Figure 13.2.

Regarding programming, one important mathematical simplification has been made: the camera (viewing point) is fixed in (x,y,z)={0,0,0}, thus making for easier equations.

MinRay writes a 24-bit, 640-by-480 pixel PPM image directly to the standard output, so you’ll have to redirect it to a file (for example, minray > output.ppm). Enjoy!

**Listing 13.1** Minray.c.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define EPSILON (1e-5) /* Very small value, used for coordinate comparisons */
#define AMBIENT 0.3 /* Ambient light level (range: 0.0-1.0) */

typedef struct { double x,y,z; } VECTOR;
typedef struct { VECTOR pos,col; double r; } OBJ;

/*
 * Each visual object (sphere) is declared with:
 * pos - position in space, using (x,y,z) coordinates
 * col - (r,g,b)-color, where each component may be in the range 0.0 - 1.0
 * r - radius
 */

OBJ objs[] = {
  { {0.0, 5.0, 0.5}, {1.0, 0.2, 0.2}, 1.0 },
  { {-1.0, 4.0, 0.5}, {1.0, 0.8, 0.0}, 0.7 },
  { {0.8, 4.0, -1.1}, {0.0, 1.0, 0.4}, 1.0 },
  { {0.0, 100.0, -510.0}, {0.0, 0.0, 0.6}, 500.0 }
};

/*
 * Only one light-source is supported. It is declared with:
 * pos = position in space
 * col = [r,g,b]-color of light ([1.0,1.0,1.0] means white).
 * (r is not used)
 */

OBJ light = {{-3.0, 1.0, 0.0}, [1.0, 1.0, 1.0], 0.0};

int main(void)
{
    VECTOR LinD, Pos, Pnt, Norm, Col, LDir, PixCol;
    double t, tmp, A, B, C, cosi; double sx, sy, objj;

    /* Write PPM header to stdout */
    fprintf( stdout, "P6\n" ); fputc( 10, stdout );
    fprintf( stdout, "640 480" ); fputc( 10, stdout );
    fprintf( stdout, "255\n" ); fputc( 10, stdout );

    /* Main ray-line sweep-loop (camera emulation) */
    LinD.y = 4.0;   /* Ray-line y-direction (forward) */
    for( sy=0; sy<480; sy++ )
    {
        /* Ray-line z-direction (up) */
        LinD.z = 3.0-sy*0.0125;

        for( sx=0; sx<640; sx++ )
        {
            /* Ray-line x-direction (right) */
            LinD.x = -4.0+sx*0.0125;

            t = -1.0; PixCol.x = PixCol.y = PixCol.z = 0.0;

            /* Get closest intersection (if any) */
            for( objj=0; objj<4; objj++ )
            {
                Pos = objs[objj].pos;
                A = 1.0 / ( LinD.x*LinD.x + LinD.y*LinD.y +
                             LinD.z*LinD.z );
                B = ( Pos.x*LinD.x + Pos.y*LinD.y +
                       Pos.z*LinD.z ) * A;
                C = (objs[objj].r*objs[objj].r - Pos.x*Pos.x -
                     Pos.y*Pos.y - Pos.z*Pos.z ) * A;

                if(( (A=C+B*B) > 0.0 )
                { /* ...else no hit */
                    A = sqrt(A);
                    if( (ttmp=B-A) < EPSILON ) ttmp = B+A;
                    if( (EPSILON<ttmp) && ((ttmp<t1)||(t<t0.0)))
                    {
                        t = ttmp;
                        /* Calculate intersection point */
                        Pnt.x = LinD.x*t;
                        Pnt.y = LinD.y*t;
                        Pnt.z = LinD.z*t;

                        /* Calculate surface normal */
                        Norm.x = Pnt.x-Pos.x;
                        Norm.y = Pnt.y-Pos.y;
                        Norm.z = Pnt.z-Pos.z;

                        /* Get surface color */
                        Col = objs[tobj].col;
                    }
                }

                /* Get light-intensity in intersection-point */
                if( t > EPSILON ) {
                    /* Get line to light from surface */
                    LDir.x = light.pos.x-Pnt.x;
                    LDir.y = light.pos.y-Pnt.y;
                    LDir.z = light.pos.z-Pnt.z;
                    cosfi = LDir.x*Norm.x + LDir.y*Norm.y +
                    LDir.z*Norm.z;

                    if(cosfi > 0.0) {
                        /* If angle between light/line and normal < PI/2 */
                        A = -Norm.x*LDir.x + Norm.y*LDir.y +
                        Norm.z*Norm.z;
                        A *= LDir.x*LDir.x + LDir.y*LDir.y +
                        LDir.z*LDir.z;
                        cosfi /= sqrt(A);
                        PixCol.x = Col.x*
                        (AMBIENT+cosfi*light.col.x);

                        PixCol.y = Col.y*
                        (AMBIENT+cosfi*light.col.y);

                        PixCol.z = Col.z*
                        (AMBIENT+cosfi*light.col.z);
                    } else {
                        PixCol.x = Col.x*AMBIENT;
                        /* Only ambient */
                        PixCol.y = Col.y*AMBIENT;
                        PixCol.z = Col.z*AMBIENT;
                    }

                    /* Make sure that the color does not exceed
                       the maximum level */
                    if(PixCol.x > 1.0) PixCol.x -= 1.0;
                    if(PixCol.y > 1.0) PixCol.y -= 1.0;
                    if(PixCol.z > 1.0) PixCol.z -= 1.0;
                }

                fputc( (char)(PixCol.x*255.0), stdout);
                /* Write colors to stdout */

                fputc( (char)(PixCol.y*255.0), stdout);
                fputc( (char)(PixCol.z*255.0), stdout);
            }
        }
    }

    return 0;
}
```

## Distributed Raytracing

The next example involves a distributed raytracer. *Distributed* means that several rays are used, whereas a traditional raytracer uses only one ray. The rays are distributed with a small jitter to acquire an average. This results in a much more realistic look (and much longer rendering time). The distribution technique generates soft shadows, glossy reflection, and antialiased edges, which you can see for yourself in Figure 13.3.
