# int keyboard_keypressed(int scancode)

When in raw keyboard mode, this routine checks to see whether the key matching your supplied scancode has been pressed, and it returns KEY_PRESSED or KEY_NOT_PRESSED accordingly. Actually, KEY_PRESSED is 1 and KEY_NOT_PRESSED is 0, which allows you to use constructs such as this:

```
if (keyboard_keypressed(SCANCODE_ENTER)) {
  /* do something event */
}
```

Note that keyboard events will only be processed when you occasionally call keyboard_update() or keyboard_waitforupdate().

keyboard_translatekeys() will also allow certain remap operations. This allows keys that have multiple physical keys (that is, the numeric digits and Enter) to show up under the same scancodes.

> Note
> The names of the \#define instances originate from the U.S. keyboard layout. When using a keyboard from a different country, the defines will refer to the key in the same physical location, but the keycap will have a different inscription.

Here are the supported scancodes: SCANCODE_0 through SCANCODE_9, SCANCODE_KEYPAD0 through SCANCODE_KEYPAD9, SCANCODE_A through SCANCODE_Z, SCANCODE_F1 through SCANCODE_F12, ESCAPE, MINUS, EQUAL, BACKSPACE, TAB, BRACKET_LEFT, BRACKET_RIGHT, ENTER, LEFTCTRL, SEMICOLON, APOSTROPHE, GRAVE, LEFTSHIFT, BACKSLASH, COMMA, PERIOD, SLASH, RIGHTSHIFT, KEYPADMULTIPLY, LEFTALT, SPACE, CAPSLOCK, NUMLOCK, SCROLLLOCK, CURSORUPLEFT, CURSOUR, CURSOR_UPRIGHI, KEYPADMINUS, CURSORLEFT, CURSORRIGHT, KEYPADPLUS, CURSORDOWNLEFT, CURSORDOWN, CURSORDOWNRIGHT, KEYPAD_PERIOD, LESS, KEYPADENTER, RIGHTCONTROL, CONTROL, KEYPADDIVIDE, PRINTSCREEN, RIGHTALT, BREAK, BREAK, ALTERNATE, HOME, CURSORBLOCKUP, PAGEUP, CURSORBLOCKLEFT, CURSORBLOCKRIGHT, END, CURSORBLOCKDOWN, PAGEDOWN, INSERT, and REMOVE.
