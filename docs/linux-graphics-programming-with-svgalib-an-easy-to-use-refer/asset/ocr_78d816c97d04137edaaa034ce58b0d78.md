Now, let's break this program down and take a look at what happens every step of the way. We start with **vga_init()**.

Despite the brackets, **vga_init()** takes no arguments. Its sole purpose is to initialize the VGA card—that is, it establishes a direct connection with the card and says, in essence, “Hey, buddy! You'll be taking directions from me now and will continue to do my bidding until I exit.” However, that doesn't mean your program has exclusive rights; your other virtual terminals should still work independently, unless you have a bum graphics card. But you do have that direct connection, which is essential for graphics. You also have an important speed advantage over X Windows, which requires an extra step. Finally, **vga_init()** relinquishes root status, which greatly reduces the possibility of security breaches. (I'll have more to say about security problems later.) It's important to make this the first line of your code.

If you noticed that the sample program in Chapter 2, called **mode_tester.c**, didn't use **vga_init()**, good for you. The reason is that **mode_tester.c** outputs text and graphics, thus making **vga_init()** unnecessary.

Note that X windows programs don't establish a direct connection with the graphics adapter because they go through the X server. The X server, however, does need to interact directly with the card. Having the X server as a middleman allows networked graphics but also reduces performance.

Next, we set the screen mode with **vga_setmode(int mode)**. SVGAib provides 140 screen modes for your enjoyment, all of which can be found in Table 2.4 (located near the end of Chapter 2). You can either enter a mode number (for example, 1), or you can enter the full mode description (G320x200x16). Either works just as well as the other. Do be aware whether your selected mode is available with the graphics card you're using; otherwise, you may have problems. (Again, see Chapter 2 for help.)

> **Note**
> It's necessary to establish a screen mode before you begin drawing so that your video card can allot its memory correctly. If you attempt to draw before you set the mode, your program will crash.

Moving right along, we establish the active color with **vga_setcolor(int color)**. Because the chosen screen mode for this example has 16 colors, you can choose any color from 0 to 15. (Note that **vga_setcolor()** is also compatible with 256 color modes, but nothing higher.)
