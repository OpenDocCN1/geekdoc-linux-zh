Using the time() function in **`<time.h>`** does provide an easy way to obtain a fresh seed number for virtually every run. I find, however, that you'll get a more evenly distributed set of "random" numbers if you provide **`srand()`** with your current process ID. This is easily accomplished using the **`getpid()`** function from **`<unistd.h>`**. Best of all, that's something you can't do in Windows.

You'll only need to seed the generator once per run. Therefore, you should do it before entering into any loop that involves **`rand()`**. Here's all you have to do:

```
srand(getpid());
```

Now, you should be aware that the number returned by **`rand()`** is enormous. To get a useful range of integers, divide **`rand()`**'s output by **`RAND_MAX`** (defined as 2,147,483,647 on my system), like so:

```
num = (float) rand() / RAND_MAX;
```

Then all you have to do is multiply the resultant number by your desired range. For example, if you want a number from 1 to 8, do this:

```
num = 8 * (float) rand() / RAND_MAX;
```

Finally, remember that the range of numbers produced by **`rand()`** starts with 0. If you actually want a number between 1 and 8 (and not 0 to 7), simply add 1 to your result, as follows:

```
num = (8 * (float) rand() / RAND_MAX) + 1;
```

A much cleaner way would be to perform the operation like I did in Listing 6.1, which I'll repeat here:

```
num = rand()%8 + 1;
```
