extern unsigned char *gl_font8x8

gl_font8x8 contains a packed pixel font with 8x8 pixels per character. Before using it, you might want to expand it with gl_expandfont(). Although it's slower, you can use nonexpanded fonts when the gl_setwritemode() flag FONT_COMPRESSED is set.

# Pixmap And Bitmap Drawing

The following functions are used for copying and pasting sections of the screen.

```
void gl_getbox(int x, int y, int w, int h, void *dp)
```

Copies a rectangular bitmap at position (x, y) with size (w, h) from the screen to the buffer dp. Pixmaps are in row-major order. The destination pixmap has the size w * h * BYTESPERPIXEL.

```
void gl_copybox(int x1, int y1, int w, int h, int x2, int y2)
```

Copies the rectangular area at (x1, y1) of size (w, h) to (x2, y2).

```
void gl_copyboxfromcontext(GraphicsContext *gc, int x1, int y1, int w, int h, int x2, int y2)
```

Copies the rectangular area at (x1, y1) in the context gc of size (w, h) to position (x2, y2) in the current context. This is more efficient than copyboxtocontext().

```
void gl_copyboxtocontext(int x1, int y1, int w, int h, GraphicsContext *gc, int x2, int y2)
```

Copies the rectangular area at (x1, y1) of size (w, h) to position (x2, y2) in the context gc. If possible, use copyboxfromcontext() instead.

```
void gl_putbox(int x, int y, int w, int h, void *dp)
```

Copies the contents of memory buffer dp to a rectangular bitmap at position (x, y) with size (w, h). Pixmaps are in row-major order. The source pixmap memory is sized w * h * BYTESPERPIXEL.

```
void gl_putboxpart(int x, int y, int w, int h, int bw, int bh, void *dp, int xo, int yo)
```

Copies the contents of memory buffer dp to a rectangular bitmap at position (x, y) with size (w, h). However, only part of the bitmap is copied. The copied size is (bw, bh), starting at offset (xo, yo). Pixmaps are in row-major order. The source pixmap memory is sized w * h * BYTESPERPIXEL.

```
void gl_putboxmask(int x, int y, int w, int h, void *dp)
```
