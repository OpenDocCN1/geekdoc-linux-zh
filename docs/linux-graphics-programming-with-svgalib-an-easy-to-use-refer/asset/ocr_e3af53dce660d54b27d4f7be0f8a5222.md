# VGA Memory

Unfortunately, not every video card can handle the higher resolution modes. There’s usually a tradeoff between matrix size and the number of possible colors; a card that can hold a huge matrix in memory can’t also hold a large number of colors, unless it has a lot of memory. Let’s have a look at this in Table 2.1.

Obviously, every VGA card can handle mode 640×480×16. In fact, this was the high end of the original IBM VGA adapter. But, if your card has only 4MB of memory, then mode 1,600×1,200×16M is out of the question.

# More on Resolutions

Speaking of resolutions, Table 2.2 lists some of the more common resolutions and their names. Note that although 800×600 is officially known as SVGA, SVGAAlb can actually handle everything listed in the table.

Did you notice how these resolutions seem to be proportionate to one another? That’s no accident. Beginning with mode 640×480, resolutions share the same aspect ratio. That is to say, the horizontal width is a third longer than the height. This enables pictures drawn at one resolution to be transferred to a different resolution without distorting.

Table 2.1 Memory requirements for VGA cards, expressed in megabytes.
| Resolution | 16 Colors | 256 Colors | 64K Colors | 16M Colors |
|------------|-----------|------------|------------|------------|
| 640×480    | .5        | .5         | 1          | 2          |
| 800×600    | .5        | 1          | 2          | 2          |
| 1,024×768  | 1         | 1          | 2          | 4          |
| 1,280×1,024| 1         | 2          | 4          | 4          |
| 1,600×1,200| 2         | 2          | 4          | 8          |
