
## Controlling VC Switches

These next functions involve controlling the VC switches:

### void vga_lockvc(void)

Disables virtual console switching for safety. Recommended when performing register I/O or low-level device handling. Used by mouse functions. Also useful in conjunction with background running.

### void vga_unlockvc(void)

Reenables virtual console switching.

### vga_oktowrite(void)

Indicates whether or not the active program is running in the console currently visible on the screen. That is, it checks as to whether it's ok to write to video memory (if running in the background has been allowed with the function above). Note that this is never entirely safe, since a console switch interrupt may occur during a video operation. Therefore, it's best to avoid this function.

Usually your program will be suspended when it has no access to the screen, but see `vga_runinbackground()` for an alternative.

### void vga_runinbackground(int stat)

Enables/disables background running of a graphics program. If `stat = 1`, then background running is enabled; if `stat = 0`, it's disabled. Normally, the program is suspended while not in the current virtual console. A program can only safely run in the background if it doesn't have any video access during this time.

As of version 1.2.11, this was changed by Pekka T. Ala-riikka and Michael Friman so that support for this must be enabled in your Makefile.cfg (which it is by default). Several ways to support this function may exist internally. As of now, only one using proc-fs works. Using `vga_runinbackground(VGA_GOTOBACK, void (*goto)())` and `vga_runinbackground(VGA_COMEFROMBACK, void (*comefrom)())` with function pointers to functions `void goto(void)` and `void comefrom(void)`, you can set up this function to be called when your program goes to background mode and when it returns to the foreground. These can be changed at any time, and passing NULL as a function disables the feature.

Both these new features require a `vga_runinbackground_version()` of 1 or higher. You shouldn't call it when the SVGAlib in use returns 0. Also, when writing applications, you can check with this:

```c
#define VGA_GOTOBACK
/* code using vga_runinbackground(VGA_GOTOBACK, goto) */
#else
/* code using no goto or comefrom function */
#endif
```

If you're compiling with an SVGA*lib that supports this feature, try to rearrange your source to work without it if an SVGA*lib version prior to 1.2.11 is used. The function should be called right after `vga_init()`. The `bg_test` demo shows the principle operation.

Note that background capabilities are in *very early stages*. Do not expect that *everything* will work flawlessly when background capabilities are enabled in your programs. Here's an example:

```c
vga_init();
vga_setmode(G32x200x256);
if (vga_runinbackground_version() >= 1)
{
vga_runinbackground(1);
}
```

See the man page for additional information.

### int vga_runinbackground_version(void)

This returns the version of the current background support. In case SVGA*lib is compiled without background support, 0 is returned. See `vga_runinbackground()` for more information on background support.

## Debugging Aids

These functions are basic debugging aids:

### int vga_dumpregs(void)

This function dumps the current values of all VGA registers in a way that can be copied in a source file. This is for debugging purposes only.

### void vga_gettextfont(void *font)
### void vga_puttextfont(void *font)

These functions give access to the buffer where SVGA*lib saves the font used by the kernel. This is used by the `restorefont()`, `savetextmode()`, and `textmode()` utilities to restore a possibly corrupted console font.

The font buffer occupies 8,192 bytes. However, versions 1.2.13 and later use a larger buffer internally, and the size of the buffers passed to `vga_gettextfont()` and `vga_puttextfont()` can be set with `vga_ext_set()`.

These two functions give access to the internal buffers of SVGA*lib, not the font tables of the VGA card. This means that both functions must be called upon entering a graphics mode, and a newly set font takes effect only at the next `vga_setmode(TEXT)` call.

> Don’t confuse text mode fonts (to which these functions pertain) with graphical fonts, such as those discussed in Chapter 7.

### void vga_gettextmoderegs(void *state)
### void vga_settextmoderegs(void *state)

These functions give access to the buffer where SVGAlib saves the VGA state that’s used when the kernel displays text on the SVGA console. This is used by the `restoretextmode()`, `savetextmode()`, and `textmode()` utilities to restore a possibly corrupted console. The buffer currently occupies 385 bytes. It won’t do any harm to make it substantially larger to allow for future enhancements.

### int vga_flip(void)

This function switches between graphics and text mode without destroying the screen’s contents. This makes it possible for your application to use both text and graphical output. However, this is an old vgalib function. You should only use it for debugging because it’s extremely unstable. This is because SVGAlib now does its own virtual console management. If you want to perform a similar action, do this:

- 1. Save the current screen’s contents with an ordinary memory copy operation to the frame buffer or `gl_getbox()`.
- 2. Set `vga_setmode(TEXT)`.
- 3. Call `vga_setmode()` to return to graphics operation and restore the screen contents with memory or `gl_putbox()`.

You could also use `vga_drawscansegment()` and `vga_getcsscansegment()` calls. However, avoid any calls to `vga_flip()` in your applications.

This function should always return 0, but it might be a good idea not to rely on this. It might prove useful if you’re debugging one of your SVGAlib applications, though. If your program reaches a breakpoint while in graphics mode, you can switch to text mode with the gdb command `print vga_flip()` and later restore the graphics screen contents with the same command. It’s useful to define the following aliases in gdb:

```
define flip <Return> print vga_flip() <Return> end <Return>
```

### int vga_setflipchar(int c)

This function sets the ASCII code of the key that causes `vga_getch()` to switch between graphics and text mode when waiting for a keypress. Esc is the default at startup. Because you can now switch directly between consoles (even when in graphics modes) and because the use of `vga_flip()` is discouraged (except for debugging), this function exists for vgalib compatibility but has no effect.

### int vga_addtiming(int pixelClock, int HSyncStart, int HSyncEnd, int HTotal, int VDisplay, int VSyncStart, int VSyncEnd, int VTotal, int flags)

This function changes the value of the current timing parameters by the given values. No checks are made to see whether the new timing values are within monitor or card specs. See *sviduntune()* for an example of using this.
