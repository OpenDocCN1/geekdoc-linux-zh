六个工具中有五个是外部函数，而“吸管”（它可以将绘图窗口中的任何颜色设为当前颜色）比较简单，因此我直接在那里处理了。请确保在读取颜色值之前移除鼠标光标；否则，你读取到的将是鼠标的颜色而不是屏幕的颜色。
