void book_solid_circle(int xc, int yc, int radius)
{
    double theta,
        costheta,
        sintheta;

    int degrees,
        y,
        old_y = 0;

    for (degrees = 0; degrees < 360; degrees++)
    {
        theta = (PI / 180) * degrees;
        costheta = cos(theta);
        sintheta = sin(theta);
        y = yc + radius * costheta;
        if (degrees > 0)
        {
            while ((old_y - y) > 1)
            {
                old_y--;
                vga_drawline(xc - radius * sintheta, old_y,
                             xc + radius * sintheta, old_y);
            }
        }
        vga_drawline(xc - radius * sintheta, y,
                     xc + radius * sintheta, y);
        old_y = y;
    }
}
```
```

And there you have it. Note that the **old_y** sections exist solely to account for gaps in the circle (that is, rounding errors). Without that, you could make the code much more compact.

# ## Filled Triangle

Interestingly enough, you can also use this code (with one slight variation) to build a solid isosceles triangle. All you need to do is to extract the following line:

```
`y = yc + radius * costheta;`
```

Then change **costheta** to **sintheta**, like I have here:

```
`y = yc + radius * sintheta;`
```
