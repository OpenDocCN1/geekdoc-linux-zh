## What Is A Polygon?

Although the pixel is generally regarded as the basic building block for all graphics screens, there's another measure by which an image can be constructed: the polygon. If the pixel can be compared to an atom, then the polygon is a molecule—a combination of pixels that works in unison to fill a section of the screen. The polygon can be likened to a large pixel—by joining polygons, a more complete image is formed.

This chapter will review the semantics of polygons in an effort to prepare you for the work ahead. The polygon is a fundamental element of three-dimensional drawing, and as such, it must be thoroughly understood. I'll start with some fairly involved, do-it-yourself code, and from there I'll progress into some of the prefab functions that come with SVGAlib's threeDKit. As is often the case, the homebrewed code should be beneficial as a tutorial, but the standard functions are much easier to use.

First, let's define clearly what a *polygon* is. From the name, one can infer that it means multiple (*poly*) + angles (*gon*). More simply, my dictionary defines a polygon as being a closed-plane figure bounded by straight lines. This means that a polygon is a closed-container, two-dimensional shape that's comprised of multiple straight lines touching at their tips (or vertices). Therefore, one can infer that a square is a polygon, along with hexagons and octagons. In fact, being the smart person that you are, you can probably deduce that any shape ending with the “-gon” suffix is

Any good graphics book will tell you that there are three types of polygons. Not wanting to be left out, I’ve included them here for you as well. The three types are convex, nonconvex, and complex. See Figure 11.2 for examples.

**Listing 11.1** Outline of a convex polygon.

```c
#include <vga.h>
#include <stdlib.h>

int main(void)
{
    /* The next two lines define the three vertices of the
    triangle. The actual points are (10,10), (10,100), and
    (100,10). The x-coordinates are defined in xarray[] and
    the y-coordinates in yarray[]. */

    int xarray[3] = {10,10,100},
        yarray[3] = {10,100,10},
        x1,
        y1,
        x2,
        y2,
        n = 3,  /* number of vertices */
        i;

    vga_init();
    vga_setmode(G320x200x256);
    vga_setcolor(vga_white());

    for (i = 0; i < n; i++)
    {
        x1 = xarray[i];
        y1 = yarray[i];
        if (i != (n - 1))
        {
            x2 = xarray[i + 1];
            y2 = yarray[i + 1];
        } else {
            x2 = xarray[0];
            y2 = yarray[0];
        }
        vga_drawline(x1, y1, x2, y2);
    }

    vga_getch();

    vga_setmode(TEXT);
    return 0;
}
```
