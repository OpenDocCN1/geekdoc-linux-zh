# ET4000 Cards

VGA cards with an ET4000 chipset may require additional configuration. If you have an older ET4000 card, you might consider springing for a better one; otherwise, you'll need to type **man svgalib.et4000** for instructions and then copy the appropriate register file to et4000_regs (located in the main SVGAlib directory). Remember to set the DAC type. The et4000_regs(et4000_regs) will install as /etc/vga/lbvga.et4000, but only if the file doesn't exist from a previous installation.
