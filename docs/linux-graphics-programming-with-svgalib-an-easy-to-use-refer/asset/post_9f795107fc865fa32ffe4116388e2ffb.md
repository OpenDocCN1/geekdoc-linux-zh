
## LINUX

### Graphics Programming with SVGAlib

#### CORIOLIS® OPEN SOURCE PRESS

##### The Essential Guide to Programming Using the SVGAlib Graphics Library

Linux Graphics Programming with SVGAlib details for the first time the inner workings of this remarkable graphics library. Written for beginners, as well as more advanced users and developers, this indispensable guidebook shows you how to integrate the functionality of SVGAlib into your own code. Completely unrelated to the X/Windowing System, SVGAlib allows programmers to take full advantage of their video hardware without draining resources, even those with only a small degree of C/C++ programming skill will soon be able to create full-screen graphical masterpieces such as games and stunning 3D displays. Power users will quickly discover the ease with which their applications spring to life when exploring the functionality of programming with SVGAlib.

**This book will help you:**

- Learn graphics theory and applications using Linux SVGAlib
- Port existing code to Linux SVGAlib
- Develop exciting, full-screen programs that take advantage of your VGA hardware
- Build dynamite graphical applications that you can share with others
- Animate your images in a variety of ways
- Plot pixels, lines, and shapes
- Adjust palettes to create new and vibrant colors
- Implement your own graphics routines
- Demystify the enigma of fonts
- Explore the colorful, self-similar world of fractals
- Read and write to GIFs, JPEGs, and more
