# ## Color Consistency Across Platforms

If you need to design applications for multiple platforms, you might consider using special color values to achieve consistency. At the beginning of this chapter, I explained why SVGAlib's colors don't always match those in other operating systems. It's not a defect of SVGAlib, nor is it a problem with the other OS. The problem is simply that *256*-color palettes vary across platforms.

The solution might be to use a specific set of *216* colors (it's *216*, not *256*—Windows and Macintosh both reserve *40* colors for their own use). These *216* colors are composed using a combination of six values: *0, 51, 102, 153, 204*, and *255*. By sticking with these numbers when you declare your RGB values, you should have something that will match a similar application on another OS.

For example, `gl_rgbcolor(102, 153, 51)` should create the same color as the equivalent command in a Windows-based application. Conversely, `gl_rgbcolor(116, 218, 244)` most likely would not.
