# ## Color In Screen Modes

Screen modes have a third and final dimension—color. The color element is listed after the width and height dimensions of the grid. For example, Listing 2.1 shows that there are actually six different variations of mode 320x200 under SVGA/lb.

+   **Listing 2.1  The six SVGA/lb screen modes that use a 320×200 matrix.**
+   320x200x16        colors
+   320x200x256       colors
+   320x200x32K       colors
+   320x200x64K       colors
+   320x200x16M       colors
+   320x200x16M32     colors

Notice how the number of possible colors increases from a paltry 16 up to 16 *million*. Can you name 16 million colors?
