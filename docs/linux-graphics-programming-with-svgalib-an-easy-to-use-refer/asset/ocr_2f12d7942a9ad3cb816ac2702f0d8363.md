You can name this code `mode_tester.c` or anything else you'd like. To compile, type the following:

```
gcc -o mode_tester mode_tester.c -lsvga
```

I'll explain the `-lsvga` part in a bit. Running `mode_tester` will produce output like that shown in Listing 2.3.

# Listing 2.3 Sample output from mode_tester.

Mode 139 is NOT supported.

Note the use of our first SVGAlib function, `vga_hashmode()`. Using this function, you can determine which modes a card can handle, and you can program accordingly. Furthermore, if you didn't know that 144 was the last screen mode, you could have employed a second function, `vga_lastnumber()`, to deduce it.

An alternative to using the `mode_tester` program is to run `vgatest`, which comes as one of the demo programs included with the SVGAlib package. Listing 2.4 shows what happens when you fire up `vgatest`.
