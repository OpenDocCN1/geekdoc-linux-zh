# Fractal (Mathematical Definition)

A set of points whose fractal dimension exceeds its topological dimension.

You can view a better example of self-similarity in Figure 8.3. This is Koch's snowflake, a classic fractal form.

Theoretically, the edges of the snowflake will become infinitely detailed. This is because at each stage (or *iteration*), the length of the sides is increased by 4/3. The extra length is pushed outward, and then the sequence repeats. This results in a flowery, paisley-esque appearance.

# Iteration

A complete cycle of operations. In other words, fractals are created by running numbers through an equation. This must be done several times to produce enough points to create an image, and each run-through is known as an iteration.

# Complex Numbers

The next element in the fractal is the *complex number*. Complex numbers look like points on a plane, and indeed, that’s why they were developed. Casper Wessel, a Danish mathematician, used them for plotting, and they received attention because they helped to solve algebraic equations, too.

Complex numbers require special math. Because they are “ordered pairs,” you can’t add or subtract from them like you can with regular numbers. Instead, refer to Table 8.1 for a brief tutorial.

Complex numbers hold the key to fractals. There’ll be more on this in a bit, but for now know that fractals also depend on the square root of negative one (-1). It’s because of this that they went unnoticed for so long; mathematicians considered this equation an impossible proposition. Fortunately, this belief didn’t last forever.

Table 8.1  Math with complex numbers

| Operation | Desired Result | Formula |
| --- | --- | --- |
| Addition of two pairs | (a, b) + (c, d) | (a+c, b+d) |
| Subtraction of two pairs | (a, b) - (c, d) | (a-c, b-d) |
| Multiplication by a number | x*(a, b) | (x*a, x*b) |
| Division by a number | (a, b)/x | (a/x, b/x) |
| Multiplication of pairs | (a, b)*(c, d) | (a*c-b*d, a*d+b*c) |
| Division of pairs | (a, b)/(c, d) | ((a*c+b*d)/(c*c+d*d), (b*c-a*d)/(c*c+d*d)) |
