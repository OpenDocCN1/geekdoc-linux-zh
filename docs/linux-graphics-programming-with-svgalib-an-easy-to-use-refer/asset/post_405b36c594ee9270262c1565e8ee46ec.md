
Be aware that `gl_hline()` requires the lower value to be on the left (that is, the horizontal line runs from left to right, keeping in sync with the monitor). Despite this added worry, it does work much more efficiently than plain `gl_line()`, and is well worth the effort.

## Arcs

Our study of curves continues with the arc, which is, essentially, an incomplete circle. Let’s begin with yet another variation on the same code used so far to figure out how an arc is created. Listings 4.7 and 4.8 show how to make a simple arc and a thick arc, respectively, and Figures 4.6 and 4.7 show the finished products.

### Listing 4.7 A simple arc.

```c
void book_arc(int xc, int yc, int radius)
{
    double theta,
             costheta,
             sintheta;
    int degrees;

    for (degrees = 180; degrees < 270; degrees++)
    {
        theta = (PI / 180) * degrees;
        costheta = cos(theta);
        sintheta = sin(theta);

        vga_drawpixel(xc + radius * costheta, yc + radius * sintheta);
    }
}
```

### Listing 4.8 A thick arc.

```c
void book_thick_arc(int xc, int yc, int radius, int thickness)
{
    double theta,
           costheta,
           sintheta;

    int degrees,
        i;

    for (degrees = 180; degrees < 270; degrees++)
    {
        theta = (PI / 180) * degrees;
        costheta = cos(theta);
        sintheta = sin(theta);

        for (i = radius; i > radius - thickness; i--)
        {
            vga_drawpixel(xc + i * costheta,
                          yc + i * sintheta);
        }
    }
}
```

## Ellipses

Ellipses, or *ovals*, can be thought of as stretched-out circles. (For reference, their geometric layout is shown in Figure 4.8.) Because of this, ellipse functions need four arguments: **xc** and **yc** for the center point, and **rx** and **ry** for the *two axes* (or radii). Contrast this with a circle, which has only one radius. A circle’s radius can spin around and touch every point, much like a bicycle spoke.

I’ve borrowed again from graphics master Michael Abrash to create the ellipse, as evidenced in Listing 4.9. The output is shown in Figure 4.9.

![](img/2e475714ef8969ed272622c46473d334_97_1.png)

**Figure 4.8** The mechanics of an ellipse.

### Listing 4.9 A Michael Abrash ellipse.

```c
void book_ellipse(int xc, int yc, int rx, int ry)
{
    int x = 0,
        y = ry;

    long threshold,
        rxsquared = rx * rx,
        rysquared = ry * ry,
        xadjust,
        yadjust;

    vga_drawpixel(xc, yc + ry);
    vga_drawpixel(xc, yc - ry);

    xadjust = 0;
    yadjust = rxsquared * 2 * ry;
    threshold = rxsquared / 4 - rxsquared * ry;

    for (;;)
    {
        threshold += xadjust + rysquared;
        if (threshold >= 0)
        {
            yadjust -= rxsquared * 2;
            threshold -= yadjust;
            y--;
        }

        xadjust += rysquared * 2;
        x++;

        if (xadjust >= yadjust)
        {
            break;
        }

        vga_drawpixel(xc + x, yc - y);
        vga_drawpixel(xc - x, yc - y);
        vga_drawpixel(xc + x, yc + y);
        vga_drawpixel(xc - x, yc + y);
    }

    vga_drawpixel(xc + rx, yc);
    vga_drawpixel(xc - rx, yc);

    x = rx;
    y = 0;
    xadjust = rysquared * 2 * rx;
    yadjust = 0;
    threshold = rysquared / 4 - rysquared * rx;

    for (;;)
    {
        threshold += yadjust + rxsquared;
        if (threshold >= 0)
        {
            xadjust -= rysquared * 2;
            threshold -= xadjust;
            x--;
        }
        yadjust += rxsquared * 2;
        y++;
        if (yadjust >= xadjust)
        {
            break;
        }
        vga_drawpixel(xc + x, yc - y);
        vga_drawpixel(xc - x, yc - y);
        vga_drawpixel(xc + x, yc + y);
        vga_drawpixel(xc - x, yc + y);
    }
}
```

## External Functions

Not all functions have to be a part of your main program. I’ve discussed this to some extent in previous chapters, regarding SVGAlib as an external library, but you have other options as well. In addition to using libraries, you can compile multiple source files (that you’ve written) into one program. Furthermore, if you use these same functions extensively, you can create your own libraries. Lastly, you can put new functions into SVGAlib itself.

Adding to SVGAlib might be hazardous, however. In addition to the obvious threat of somehow corrupting the library, programs that link to your customized functions won’t work on someone else’s computer. How could they? The necessary functions are only on your machine. To combat this, you can distribute your external functions along with your programs, just as many Windows programs install their own DLLs (dynamic link libraries, akin to the .so files in Linux). The advantage to Linux is that you don’t need to “register” these libraries; just pop ’em into a directory on ld’s search path, and you’re ready to roll. (Although you may need to run ldconfig first.) You can also create a statically linked (self-contained) executable; this might be a popular choice for commercial software developers who don’t want their code appropriated.
