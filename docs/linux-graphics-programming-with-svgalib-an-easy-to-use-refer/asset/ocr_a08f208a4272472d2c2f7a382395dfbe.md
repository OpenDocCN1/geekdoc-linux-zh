These functions query the current state of joystick joydev. Actually, this is the state found during the last call to joystick_update() with the default joystick event handler active. The function joystick_getaxis(joydev, a) returns the current state of the given axis (usually x - 0, y - 1, z - 1,..) in the range -128 to 127. Some effort is made to ensure that the center position is close to 0.

Note that the protocol joystick calibration for version 0.x is very bad. You won't usually see the extreme values on the extreme position. Also, the center position will be close to zero, but not exactly zero, and return values will also vary slightly from call to call—even when the user didn't move the joystick.

The function joystick_getbutton(joydev, b) returns the state of a button. It returns 1 for a pressed button and 0 otherwise. Note that no hardware check exists for button clicks. The button press is only detected during a call to joystick_update(), at least in the 0.x protocol.

> **Note**
> *The functions simply return the data passed to the default joystick event handler.*
