# Aspect Ratio

The ratio of width to height on your display. Most monitors and televisions have an aspect ratio of 4:3.

# How Pixels Are Stored In VGA Memory

While in video memory, pixels are represented by one or more bits. A 1-bit pixel can only hold two values (on and off), so it would only be good for black and white images, such as the examples showed earlier. By increasing the number of bits per pixel, or the *bit depth*, the number of possible colors increases. Color displays require anywhere from 4 to 32 bits per pixel. No wonder having 16 million colors takes up a lot of memory.

Table 2.3 shows how the number of possible colors goes up as the number of bits per pixel increases.

# SVGAlib Screen Modes

Enough with these theoretical examples, let’s have a look at the 145 screen modes SVGAlib provides. These are the actual modes as found in **/usr/include/vga.h**, and Table 2.4 has every last one of them, complete with colors. If you’re wondering, the leading G simply refers to *graphics mode*. When you write a program with SVGAlib, you’ll need to use one of these modes.

> **Note**
> 
> 16M32 means 16 million colors using 32 bits per pixel.

Table 2.3 Colors made possible by increasing bit depth.

| Bits | Number Of Colors |
| :--- | :--- |
| 4 | 16 |
| 8 | 256 |
| 15 | 32,768 |
| 16 | 65,536 |
| 24 | 16,777,216 |
| 32 | 16,777,216 + alpha channel |

# Alpha Channel

An extra 8 bits in a 16 million color pixel that are used as a separate layer for representing levels of transluency in an object.
