# ## Filled Circles

You already know that vgaal offers gl_fillbox(), but at this point there’s no equivalent function for circles. Wouldn’t it be nice to fill this emptiness?

Being the clever person that you are, you probably think you can fill in your circles by using the previous formula and making the thickness equal to the radius. That is to say, if your radius is 100 pixels, you should, by accord, be able to color the entire circle by setting the thickness to 100 pixels. Right? I thought so, too, but unfortunately, it doesn’t quite work out that way. Due to rounding, what you’ll get instead is a somewhat psychedelic-looking pattern, as shown in Figure 4.4.

This might be good to impress your friends, but it’s not what we’re after. The problem is that the formula doesn’t cover every possible point; it’s sloppy. To completely fill your circle, you’ll need to switch to vga_drawline(), which is fairly easy to do.

Moving along to Listing 4.4, the code for filling a circle is rather similar to what we’ve done before.
