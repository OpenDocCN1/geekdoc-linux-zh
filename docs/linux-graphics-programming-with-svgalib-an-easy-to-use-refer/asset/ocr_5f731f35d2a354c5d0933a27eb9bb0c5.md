By all means, don't be frightened by the prospect of compiling your own copy of SVGAlib. It's a very straightforward process and shouldn't take you more than 15 minutes from start to finish.

To begin with, you'll need to obtain the SVGAlib source package. While there are several methods available, I'd suggest doing one of the following:

+   - Copy it from the enclosed CD-ROM.
+   - Download it from the Internet.

The CD-ROM that accompanies this book contains version 1.4.0, the most up-to-date version of SVGAlib at the time of this writing. However, this being a progressive library, improvements are bound to be made. For example, several new video card drivers have been added in the past few months, so I'd suggest that you visit the official Web site every now and then to see if a newer version's been released.

The SVGAlib Web site is located at www.svgalib.org. This site is a great resource for developers; it contains up-to-date tips and hints, as well as a bulletin board you can post to if you need extra help. The distribution isn't actually housed at svgalib.org; it links to the gigantic metavalab.unc.edu (formerly Sunsite) Linux repository. If you'd like to go there directly, the full address is metavalab.unc.edu/pub/Linux/libs/graphics. Access isn't restricted to the Web, however; Metavalb allows the use of a regular FTP client as well.

The source “earball” is called svgalib-1.4.0.tar.gz. If your system is based on glibc2 (GNU’s C library, which supersedes the libc.so.5 series), you'll also want to download the precompiled binary version. Despite how it seems, the precompiled SVGAlib isn't there to save you time. Rather, its purpose is to allow compatibility with precompiled applications that were built with libc.so.5. If this is all Greek (“geek”? ) to you, don't worry. I'll go into more detail later in the chapter.

> **Note**
> *Users with a glibc:2-based system (such as RedHat 5.x, Debian 2.x, or SuSE 6.x) will need to download the binary distribution as well as the source, because glibc2 isn't compatible with previous Linux libcs, and you'll need the binary distribution to run older, precompiled libc.so.5 programs, such as Quake. We’ll give more information on this in a bit.*
> 
> *Don't worry if you get the following error: “Warning: return type of ‘main' is not ‘int’”. This is merely a case of outdated syntax, and won't have any adverse effect upon your compilation.*
