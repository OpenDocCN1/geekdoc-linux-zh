# An Easy Way To Copy Sprites

Instead of redrawing a sprite every time you want to place it somewhere different, wouldn’t you like to just be able to use **gl\_putbox()**? The only problem is that if your background uses more than one color, **gl\_putbox()** will leave a telltale border around your image. An **irregular putbox** function isn’t available (one that inserts a nonrectangular shape), but you can achieve the same effect with **gl\_putboxmask(int x, int y, int w, int h, void \*dp)**.
