found at `metalab.unc.edu` in the `/pub/Linux/GCC` directory. If you're interested, the original gcc site is at `www.gnu.org`. In either case, look for `gcc-2.95.1.tar.gz`, or any later version.

**Note**

The author has successfully compiled SVGAlib on Intel- and Cyrix-based systems. However, AMD processors can sometimes cause problems when used with Linux. They may look like a good buy now ("I can buy the computer and a VCR!"), but you might be sorry later ("Why isn't this compiling?"). My advice is to accept that AMD is a Windows platform and leave it at that.

# SVGAlib On The Compaq Alpha

Although SVGAlib is used mainly on Intel (and variant) systems, David Mosberger-Tang has contributed patches to make SVGAlib run on Alphas. Read the O-INSTALL file if you have an interest in this.

# Unpacking The Distribution

It's suggested that you store the source files in either the `/usr/src` or `/usr/local/src` directory, but it makes no difference. After downloading or otherwise obtaining the distribution, you'll need to uncompress it by running `gunzip` and `tar`. Simply type `gunzip svgalib-1.4.0.tar.gz` and then `tar -xzf svgalib-1.4.0.tar`. You can save a step and do this all at once by using `tar -xzf`. Typing `tar -xzf svgalib-1.4.0.tar.gz` will create a directory called `svgalib-1.4.0`, which will be filled with the subdirectories and files listed in Table 1.1.
