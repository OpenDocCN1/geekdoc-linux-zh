```
# Source directory.
#$srdir = /usr/local/src/svga-lib-$(VERSION)
srdir = $(shell sh -c pwd)
```

If you don't change this part, **srdir** will be the current directory. Pretty simple; no need to change anything here.

```
# Common prefix for installation directories.
# NOTE: This directory must exist when you start the install.
TOPDIR=
**prefix = $(TOPDIR)/usr**
exec_prefix = $(prefix)
```

Because **TOPDIR** is blank, the default prefix is *usr*.

```
libdir = $(exec_prefix)/lib
```

This is the directory where the shared stubs and static library will be installed. If you've left **TOPDIR** blank, your *static* library will be installed to */usr/lib*. This is standard for most static libraries. I suggest you leave this part alone.

```
sharedlibdir = $(TOPDIR)/lib
```

Here's the directory where the shared library will be installed. This is */lib* by default, and again, I suggest you leave it alone. If you *do* decide to change it, you'll potentially have a situation where `ld` *(the dynamic linker)* won't be able to find your shared libraries. You can solve this by making an entry in the `/etc/ld.so.conf` file, which contains a listing of non-standard directories for `ld` to search through. The dynamic linker will always look in */lib* and */usr/lib*, so you won't need to add those.

```
bindir = $(exec_prefix)/bin
```
