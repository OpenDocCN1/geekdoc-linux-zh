# vga_accel(ACCEL_SCREENCOPYMONO, int x1, int y1, int x2, int y2, int w, int h)

Monochrome screen-to-screen blit. It copies a box of width w and height h pixels from position x1, y1 to position x2, y2. However, each pixel with all bits set to 0 is drawn in the background color, and each pixel with all bits set to 1 is drawn in the foreground color. To allow many different architectures to support this routine, behavior is undefined for other values. Bitmap transparency might be supported as well. You should not expect ACCEL_SCREENCOPYBITMAP to handle overlapping screen areas gracefully.

# vga_accel(ACCEL_PUTIMAGE, int x, int y, int w, int h, void *p)

Straight image transfer. It fills the given box with the data in memory area p. The memory buffer must contain the pixels in the same representation as used in the VGA memory, starting at the top left corner, from left to right, and then line by line from up to down, without any gaps and interline spaces.

# vga_accel(ACCEL_DRAWLINE, int x1, int y1, int x2, int y2)

General line draw. Draws a line from x1, y1 to position x2, y2 in the foreground color. You shouldn't expect the reverse line (from x2, y2 to position x1, y1) to use the exact same pixels on the screen. Several algorithms (especially hardware) tend to yield surprising results.

# vga_accel(ACCEL_SETFGCOLOR, int color)

Sets the foreground color. This is used by most of the other draw commands.

# vga_accel(ACCEL_SETBGCOLOR, int color)

Sets the background color. Also used by several draw commands.

# vga_accel(ACCEL_SETTRANSPARENCY, int mode, ...)

Sets the transparency mode.

# vga_accel(ACCEL_SETRASTEROP, int mode)

Sets raster-operation.

# vga_accel(ACCEL_PUTBITMAP, int x, int y, int w, int h, void *p)

Color-expanded bitmap. This works similar to ACCEL_PUTIMAGE, but the bitmap *p is a 1-bit bitmap. Each pixel related to a set bit in *p is drawn in the foreground color, whereas the other pixels are drawn in the background color.

Each byte at *p contains eight pixels. The lowest order bit of each byte is leftmost on the screen (contrary to the VGA tradition), regardless of the bitmap high order flag. Each scanline is aligned to a multiple of 32 bits. If the transparency mode is enabled (regardless of the transparency color), bits that are zero in the bitmap are not written (that is, the background color is not used).
