```
gl_setpixel((x + 8), (y + 14), 254);  
gl_setpixel((x + 5), (y + 15), 254);  /* line 16 */
gl_hline((x + 6), (y + 15), (x + 7), 255);  
gl_setpixel((x + 8), (y + 15), 254);  
gl_setpixel((x + 6), (y + 16), 254);  /* line 17 */
gl_hline((x + 7), (y + 16), (x + 8), 255);  
gl_setpixel((x + 9), (y + 16), 254);  
gl_setpixel((x + 6), (y + 17), 254);  /* line 18 */
gl_hline((x + 7), (y + 17), (x + 8), 255);  
gl_setpixel((x + 9), (y + 17), 254);  
gl_hline((x + 7), (y + 18), (x + 8), 254);  /* line 19 */
```

If you run this program, you may notice that the mouse likes to start in the extreme lower-left corner. Logic would indicate that you could use `mouse_setposition(int x, int y)` to rectify this situation, but it seems to be of no avail. Ah, what’s a poor programmer to do?

In closing, note that some people recommend locking the console with `vga_lockvc(void)` when using the mouse. This disables virtual console switching for safety, and it’s recommended when you’re doing register I/O or low-level device handling. To unlock your console once again, call `vga_unlockvc(void)`.

# The Joystick

Code for the joystick is remarkably similar to the code I’ve already demonstrated for the mouse. Therefore, this section won’t be as involved. If you run into trouble, you can always check the man pages or ask for help in the usual locations ([www.svgaib.org](http://www.svgaib.org), the mailing list, and so on).

As you probably know by now, joysticks plug into sound cards. For me, this meant a hard-ware purchase, because I don’t normally use sound with Linux. I also recompiled the kernel for sound card support. When recompiling, you’ll notice a section on joystick support, too. This is Linux kernel-level support, and is completely unrelated to SVGAIB’s joystick drivers. Ergo, it makes no difference whether you choose this or not.

> **Warning**  
> The joystick functions will only work with ELF versions of SVGAIB. This shouldn’t be an issue for most people, but if you do have an a.out library, you’ll be out of luck. If you don’t know which version you have (ELF or a.out), you most likely have ELF.
