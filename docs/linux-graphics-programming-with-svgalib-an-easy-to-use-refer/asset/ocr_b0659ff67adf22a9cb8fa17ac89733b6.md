# A Note from Russel Marks

The advantage of not calling **do_a_frame()** directly from **signal handler()** is twofold—there’s very little you can do safely in a signal handler, and the “polling” approach means you degrade gracefully on machines too slow to handle the game (that is, the game runs slow rather than completely screwing up). Also, a polling model is less of a hassle than dealing with interrupts. One final thing: you *could* explicitly stop the timer, but because it’s only setting a flag there’s usually no need, you can just leave it running.

void tsleep()
{
    struct timeval tv;
    char c;

    tv.tv_sec = 0;
    tv.tv_usec = fallRate;
    while (TV_POS(&tv))
        if (rnwait(&tv) && read(0, &c, 1) !- 1)
            break;
}
