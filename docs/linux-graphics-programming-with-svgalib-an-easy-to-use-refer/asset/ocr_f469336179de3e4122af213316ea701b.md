# # Getting Started

The standard method for animating a computer image is as follows:

+   1. Draw the initial image.
+   2. Erase the image by restoring the background color(s).
+   3. Redraw the image in its new location.

Generally, the new location is only slightly removed from the old location. If you “jump” too far in one step, your motion will appear jerky and unrealistic. Figures 10.1, 10.2, and 10.3 illustrate how an image is moved according to this formula.

Now, there are several methods you can use to “erase” and “redraw” your image. You could always use the exact same procedure you used to draw the initial image, only using the color
