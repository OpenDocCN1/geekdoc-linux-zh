# ## Chapter 1

## Getting Started

+   Key Topics:
+   - **Obtaining and installing SVGAlib**
+   - **Configuration**
+   - **Graphics libraries and linking**
+   - **Comparisons with X**

This chapter contains everything you ever wanted to know about getting SVGAlib installed and configured on your Linux box. If you follow my instructions, you’ll soon have the power to create brilliant graphics and stunning displays—the kind that you’ve always wanted to have with Linux but were never able to produce. Furthermore, you’ll be able to run any of the precompiled applications that have been written for SVGAlib, and you’ll be ready to work on the numerous code examples presented later in this book. As we progress, we’ll examine the mechanics of SVGAlib and learn what makes it necessary. If you find that you’re already familiar with some of the material that’s presented, don’t be offended. The point is not to insult you, but rather to help out users who might not be as experienced. If a particular segment bores you, just skip ahead—you can always come back if needed. On the other hand, there’s a primer on C libraries for those readers who are new to programming and have not yet learned about shared functions and dynamic linking. Finally, I’ll cover the differences between SVGAlib and some of the other well-known graphical rendering packages available for Linux.

If you learn nothing else from this chapter, you should definitely leave with the knowledge that SVGAlib is powerful, easy to use, and most importantly, that it’s a lot of fun.
