# Words From The Man Page

The joystick module is basically independent from the rest of SVGAlib. You can easily use it in text mode only, but there's no benefit to doing that. If used in a graphics mode, however, it will release the joystick devices upon a VC switch so that several applications can share joysticks. Unfortunately, this doesn't work during joystick calibration. Therefore, you should lock the VC with **vga\_lockvc()** while calibrating in graphics mode.

Also, when using joysticks in text mode only, SVGAlib won't detect VC switches and joysticks cannot be shared among applications.

Similar to working with the mouse, you can open, update, and close the joystick with the following three commands:

+   - joystick\_init(int joydev, \_\_joystick\_output jp)
+   - joystick\_update(void)
+   - joystick\_close(int joydev)

Listing 15.6 shows these functions in the context of a real program. Notice the similarities to the mouse functions already shown. However, because the joystick is largely independent of SVGAlib, you can initialize it before you call **vga\_init().**

The first argument to **joystick\_init()**——**joydev**——should be a number from 0 to 3. The implication is that you can have multiple joysticks operating simultaneously, but Linux can only handle two at the present. (Whoops.) It's also recommended that you use **JOY\_CALIB\_STDOUT** (defined in **vgajoystick.h**) for the second argument.
