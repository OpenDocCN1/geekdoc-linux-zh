
## Aspect Ratio

The ratio of width to height on your display. Most monitors and televisions have an aspect ratio of 4:3.

## How Pixels Are Stored In VGA Memory

While in video memory, pixels are represented by one or more bits. A 1-bit pixel can only hold two values (on and off), so it would only be good for black and white images, such as the examples showed earlier. By increasing the number of bits per pixel, or the *bit depth*, the number of possible colors increases. Color displays require anywhere from 4 to 32 bits per pixel. No wonder having 16 million colors takes up a lot of memory.

Table 2.3 shows how the number of possible colors goes up as the number of bits per pixel increases.

| Bits | Number Of Colors |
| :--- | :--- |
| 4 | 16 |
| 8 | 256 |
| 15 | 32,768 |
| 16 | 65,536 |
| 24 | 16,777,216 |
| 32 | 16,777,216 + alpha channel |

## Alpha Channel

An extra 8 bits in a 16 million color pixel that are used as a separate layer for representing levels of transluency in an object.

If you want to see what modes your card can handle, you can compile and run the quick hack demonstrated in Listing 2.2. Furthermore, if you didn't know that 144 was the last screen mode, you could have employed a second function, vga_lastmodenumber(), to deduce it. Additionally, GLASTMODE is defined by vga.h as being the output of vga_lastmodenumber().

## Listing 2.2 Which screen modes can my video card handle?

```c
#include <stdio.h>
#include <stdlib.h>
#include <vga.h>

int main(void)
{
    int i;

    for (i = 0; i < 145; i++)
    {
        if (vga_hasmode(i) > 0)
        {
            printf("Mode %d is supported.\n", i);
        } else {
            printf("Mode %d is NOT supported.\n", i);
        }
    }

    return 0;
}
```

You can name this code `mode_tester.c` or anything else you'd like. To compile, type the following:

```bash
gcc -o mode_tester mode_tester.c -lsvga
```

I'll explain the `-lsvga` part in a bit. Running `mode_tester` will produce output like that shown in Listing 2.3.
