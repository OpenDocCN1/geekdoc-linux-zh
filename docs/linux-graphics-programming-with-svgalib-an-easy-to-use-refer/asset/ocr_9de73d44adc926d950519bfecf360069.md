**void gl\_setclippingwindow(int x1, int y1, int x2, int y2)**

Sets the clipping window to a rectangle with its top-left corner at (x1, y1) and its bottom-right corner at (x2, y2).

# Text-Drawing Primitives

These functions involve the use of bitmapped fonts.

**void gl\_setfont(int fw, int fh, void \*fp)**

Uses the font stored as character bitmaps at **fp**, with characters of size (**fw**, **fh**), as the basic font for write operations. Note that the font included in the library must be expanded first, because it’s stored bit per pixel; this is not required if the **gl\_setwritemode()** flag **FONT\_COMPRESSED** is set.

**void gl\_setfontcolors(int bg, int fg)**

Sets the background and foreground colors for the compressed font write mode. This, in turn, is set with **gl\_setwritemode()**.

**void gl\_expandfont(int fw, int fh, int c, void \*sfp, void \*dfp)**

Converts a bit-per-pixel font at **sfp** with 256 characters of size (**fw**, **fh**) to an expanded font of character bitmaps stored at **dfp** (the size will be 256 \* **fw** \* **fh** \* BYTESPERPIXEL). All nonzero pixels are set to color **c**. It’s possible to use nonexpanded fonts (but it’s slower) when the **FONT\_COMPRESSED** **gl\_setwritemode()** flag is set.

**void gl\_colorfont(int fw, int fh, int c, void \*fp)**

Sets all nonzero pixels in the expanded font **fp** with 256 characters of size **fw** and **fh**, each to color **c**.

**void gl\_setwritemode(int m)**

Sets the writemode flags for the font routines. Argument **m** must be exactly one choice out of the following two groups of constants (giving you four choices, actually):

+   - **WRITEMODE\_MASKED**
+   - **WRITEMODE\_OVERWRITE** (default)
+   - **FONT\_COMPRESSED**
+   - **FONT\_EXPANDED** (default)

If **WRITEMODE\_MASKED** is set, only foreground pixels of the font are used for write operations; the screen background is not erased.

> **Note**
> 
> If **FONT\_COMPRESSED** is set, text writes will use the compressed bit-per-pixel font rather than the expanded font (which would be slightly faster).
