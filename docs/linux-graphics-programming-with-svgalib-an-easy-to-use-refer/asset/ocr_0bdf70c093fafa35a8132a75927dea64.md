The declaration consists of 2,048 numbers (with most of them omitted here for brevity). These numbers range from 0 to 255. Now, let's go over what they mean. Each character in an 8x8 font (which is standard for SVGAlib) is actually made up of eight horizontal strips of eight pixels each. See Figure 7.5 for a graphical representation of this.

Each strip has some, all, or none of its pixels filled. If you think about it, there are 256 possibilities (0 to 255). Every possible combination of filled and unfilled pixels is covered. So, to draw a capital S, you need these eight codes: 126, 128, 128, 124, 2, 2, 252, and 0. See Figure 7.6 to see what you'd end up with.

If your font consisted of only the letter S, your declaration would look like this:

```
```cpp
unsigned char s-font[8] =
{
    126, 128, 128, 124, 2, 2, 252, 0
};
```
```

In reality, fonts consist of 256 characters. Each character needs eight numbers (to represent its eight strips), and 256x8 is 2,048. Therefore, each font declaration needs 2,048 codes. You don't need to worry about all of them to begin with, however. You can use zeros (0) for everything but the letters you're interested in.
