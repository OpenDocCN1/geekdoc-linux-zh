vga_gettextfont() and vga_puttextfont() to truncate and zero-pad all buffers accordingly. Otherwise, the previously set buffer size is returned.

# **int vga_screeneoff(void)**

See vga_screeneon().

# **int vga_screeneon(void)**

These functions turn the generation of the video signal on or off. On some video boards, SVGA memory access is faster when no video signal is generated. On the other hand, not all boards allow you to disable it (at least, not in all modes). These functions should always return 0, but it might be a good idea not to rely on this.

# **int vga_guesstiming(int x, int y, int clue, int arg)**

Calculates a timing line for an x*y resolution, according to the value of clue. If clue is 0, the aspect ratio for the requested mode (x/y) must be 4:3. A mode with the same aspect ratio as the given mode (while still having a higher resolution) is found and then scaled down to the requested mode. If clue is 1, the next lower resolution with the same aspect ratio will be found.

> > **Warning**
> >
> > No guarantee is given that a *modeline* will be *created* or that the *created modeline* will be *useful*.

# # Get Video Mode Information

These functions return data pertaining to the current video mode:

# **int vga_getxdim(void)**

This function returns the horizontal width (in pixels) of the current screen mode.

# **int vga_getydim(void)**

This function returns the vertical height (in pixels) of the current screen mode.

# **int vga_getcolors(void)**

This function returns the current screen resolution's number of displayable colors.

# **int vga_white(void)**

vga_white() returns the color white in the current screen resolution as it would be set with vga_setcolor() or written directly into the screen.

In high color modes, it's always clear how white is set with vga_setrgbcolor(3). In the other modes, you need vga_white(). However, this function only knows about the default palette. If you change the palette, this function will not know.
