Clearly, this would be better if the arrows on a standard 101-key keyboard could be used instead of the keys A, D, W, and X. However, this would be a bit more complicated: it involves placing your program into *raw keyboard mode*, which I'll get into later in the book. For now, though, the existing arrangement will have to suffice. Despite this lack of sophistication, the program works well.

Did you notice how I came up with the "funky" ASCII characters that don't appear on the keyboard? I just used the following line, while cycling "a" through 0 - 255.

```
char c[ ] = (a, '\0');
```

# ## Scalable Fonts

Although SVGAlib has no provision for handling scalable typefaces, there's an organization at www.freetype.org that's successfully developed an engine to interpret TrueType (TTF) character sets. Indeed, this means that you can now view "real" fonts (such as Arial) by way of SVGAlib. The code works much in the same way as the code for SVGAlib's bitmap fonts, although it's considerably more involved.

The Linux version of FreeType was designed for X11 (X Windows), but Matan Ziv-Av has graciously porting the sample/demo programs. The actual "engine" remains the same; it was just the rendering process that needed to be changed.

To begin, download the FreeType package from the official site at www.freetype.org. At the time of this writing, the current version is freetype-l.3.1.tar.gz, although a much-improved version 2 is in the works.

The next step is compilation. Note that you'll have to edit your Makefile if you don't have X11 installed on your system—you'll need to remove all references to the X Windows test programs, or you'll get some compile-time errors.

The resultant libraries (shared and static) are installed into the /usr/local/lib directory, so you'll probably need to run ldconfig afterwards to re-synch your system. By default, ld will look in /lib and /usr/lib.

Next, you can download Matan's FreeType SVGAlib demos from www.svgalib.org. These will show you how to integrate FreeType into your own programs.

Finally, last but not least, you'll need a font file. I went ahead and "borrowed" one from Windows 9.x—you'll find them in C:\WINDOWS\FONTS. Various others are available at no charge on the Web.
