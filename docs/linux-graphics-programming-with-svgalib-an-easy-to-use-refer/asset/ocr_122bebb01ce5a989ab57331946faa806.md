```
# TARGET_FORMAT - a.out
TARGET_FORMAT - elf
```

The only other major decision will be regarding the target format. Leave this option untouched unless you know, beyond a shadow of a doubt, that you're running an a.out system. By default, SVGA1ib will be compiled as an ELF (executable and linking format) binary. ELF has been the standard on Linux systems for several years, and chances are pretty good that you can leave this option untouched.

```
# Uncomment the next line if your are compiling with a version of
# (GNU) glibc:

# USEGLIBC - yes
```

For the last time, if you're using RedHat since version 5, Debian since version 2, SuSE since version 6, or Slackware since version 4, you must uncomment this line. Other users (those compiling with libc.so.5) should leave it commented out.

```
ROOT_VC_SHORTCUT - y
```

Leave this line uncommented if you always want root processes to be able to get a new virtual console (VC). Alas, some games misuse *sudo* root privileges and become root; SVGA1ib cannot detect this and will allow any user to open a new VC. If this annoys you, be sure to comment out this line.
