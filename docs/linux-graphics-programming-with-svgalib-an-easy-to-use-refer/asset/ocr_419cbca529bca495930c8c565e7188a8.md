```
{

joystick_update();

/* Put the 'meat' of the program here */

}

vga_setmode(TEXT);
joystick_close(joydev);


return 0;

}
```

To begin checking for events, use `joystick_getaxis(int joydev, int a)` and `joystick_getbutton(int joydev, int b)`. Remember that the values returned from these functions are only as recent as the last time `joystick_update()` was called. Therefore, you should call `joystick_update()` fairly often.

For the x-axis in `joystick_getaxis()`, argument a should be 0. For the y-axis, use 1. Your return value will be in the range of -128 to 127. Remember, this doesn’t give you an absolute position like `mouse_getx()` or `mouse_gety()` does, but rather it returns the state of the joystick itself (that is, how far it’s bent). It’s up to you to actually place the “cursor.”

Next, `joystick_getbutton()` returns a 1 for a pressed button and a 0 otherwise. To use this function, you’ll need to pass the button’s assignment number as an argument, along with the value of `joydev`. The buttons themselves are numbered 0 through 3 because, like everything else in Linux, numeric sequences start with 0.

For example, you can use the following code to determine whether or not the first button has been pressed:

```
if (joystick_getbutton(joydev, 0) == 1)
{
/* Button has been pressed */
}
```
