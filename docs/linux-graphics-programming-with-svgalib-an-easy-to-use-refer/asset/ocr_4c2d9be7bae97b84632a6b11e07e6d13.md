# Keyboard Codes

Once you're in raw keyboard mode, your program looks for signals to indicate that a certain key has been pressed. This is accomplished with keyboard_keypressed(int scancode) and keyboard_update(void). Basically, your program uses keyboard_update() to flush the buffer and keyboard_keypressed() to see whether any scanodes have been entered. Because keyboard_update() is nonblocking, it doesn't halt the execution of your program. Therefore, you should use it in your main loop, because the buffer must constantly be checked. Alternately, if you want your program to stop and wait for input, use the blocking keyboard_waitforupdate(void) instead.

For your convenience, Table 9.8 has the scancodes that keyboard_keypressed() recognizes, along with their associated numeric values. Although codes and values may be used interchangeably in programs, it's probably best to use the codes. Note that case makes no difference here; therefore, a capital A is identical to a lowercase a.

> Note
> Some code names may be unfamiliar to you, so I'll provide a few definitions. The CURSORBLOCK instances are the four arrow keys, meaning that CURSORBLOCKUP is the up arrow, and CURSORBLOCKDOWN is the down arrow, and so on. GRAVE is the "backtick" located on the same key as the tilde (~). Note that "Pause Break" returns SCANCODE_BREAK (101) on some keyboards and SCANCODE_BREAK_ALTERNATIVE (119) on others. Therefore, you should have your programs check for both if that key is important to you.

The scanocode names are based on the U.S. keyboard layout. If you happen to have a non-American keyboard, the codes will pertain to the keys in the same physical location, although their inscriptions will be different.

After reviewing Table 9.8, it should be obvious that SCANCODE_PRINTSCREEN (99) is what you need for a screen grabber.
