# **Listing 3.5 The yellow pixels of Texas.**

```
vga_setcolor(14);
vga_drawpixel(5, 100);
vga_drawpixel(10, 100);
vga_drawpixel(15, 100);
vga_drawpixel(20, 100);
vga_drawpixel(25, 100);
vga_drawpixel(30, 100);

```
```

This draws 10 yellow pixels evenly spaced along the x-axis. Pretty simple stuff. To add some pizzazz, you can change the color of each pixel by prefacing each vga_drawpixel() statement with vga_setcolor(). Also, you can save some time by using a loop. Listing 3.6 shows the efficient way to draw those pixels.

# **Listing 3.6 More yellow pixels.**

```
```
vga_setcolor(14);
for (x = 5; x < 55; x += 5)
{

		vga_drawpixel(x, 100);
}
```
