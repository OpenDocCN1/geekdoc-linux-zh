```
gl_setcontext(virtualscreen);
```

This creates an occurrence where **virtualscreen** is memory space allocated by *\_gl\_allocatecontext(void)*. You can return to the physical (visible) screen with the following:

```
gl_setcontext(physicalscreen);
```

This is assuming you’ve similarly defined *physicalscreen*.

In Listing 10.5, I’m going to create a virtual screen with vga1 and then I’m going to draw a box on it. I’ll finish by copying the entire virtual screen to the physical (visible) screen.

# Listing 10.5  Frame buffer demonstration.

```
```c
#include <stdio.h>
#include <vga.h>
#include <vga1.h>

#define WIDTH 10
#define HEIGHT 10
#define COLOR 3

int main(void)
{
  int x = 10,
      y = 10;

  GraphicsContext *physicalscreen;
  GraphicsContext *virtualscreen;

  vga_init();
  vga_setmode(6320x200x256);

  gl_setcontextvga(6320x200x256);
  physicalscreen = gl_allocatecontext();
  gl_getcontext(physicalscreen);

  gl_setcontextvgavirtual(6320x200x256);
  virtualscreen = gl_allocatecontext();
  gl_getcontext(virtualscreen);

  /* Now I'm drawing to the frame buffer */
  gl_setcontext(virtualscreen);

  gl_fill1box(x, y, WIDTH, HEIGHT, COLOR);
```
