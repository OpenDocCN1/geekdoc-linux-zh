# Chapter 18

# Simple Paint Program

Key Topics:

- Interface design
- Creating tools
- Saving your drawings

One application that’s clearly missing from the SVGAlib milieu is any sort of drawing/painting/imaging program. This gaping absence may come as a surprise, considering how useful such programs can be. Virtually every operating system allows you some method of doodling on the screen, no matter how primitive, and yet SVGAlib conspicuously offers nothing. One can hardly make it through the day without seeing some media reference to Adobe’s Photoshop, Jasc’s Paint Shop Pro, or even the GIMP, a popular imaging program for X Windows. When compared to these application giants, SVGAlib comes up flat. Of course, we as programmers have our own drawing primitives, but there’s nothing available for the end user.

With that in mind, the objective of this chapter is to create a comprehensive paint program using SVGAlib. Most importantly, it must be one that’s accessible to nonprogrammers. If you decide to code as you read along, you should have a working example by the end—one that you can distribute among your friends. Otherwise, if you’d rather just read, you’re welcome to take the code presented here and expand on it. The finished product might be somewhat limited in its capabilities (when compared to Photoshop, for example), but I’m sure you’ll enjoy it nonetheless.

Last but not least, this project will touch on the issue of interface design and will serve as a comprehensive summary of the commands that you’ve learned thus far. In a sense, then, it will be your final examination. Fear not, though—it’s an open book test, and you get to grade yourself.
