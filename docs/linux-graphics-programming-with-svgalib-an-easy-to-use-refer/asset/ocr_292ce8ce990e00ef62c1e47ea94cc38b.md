# ## Functions Defined In Vgagl.h

The libvgagl functions shown in this appendix are defined in vgagl.h. This header file can generally be found in the /usr/include or /usr/local/include directories. Additionally, the independent threeDKit functions require separate header files (for example, triangle.h), which are kept in SVGAlib's threeDKit source subdirectory.
