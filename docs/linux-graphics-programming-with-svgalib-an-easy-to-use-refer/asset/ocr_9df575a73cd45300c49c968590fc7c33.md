# ## Conclusion

3D graphics is an exciting field that gives more dimension to your work, both literally and figuratively. Presentations and displays take on a new light when depth becomes part of the equation. Of course, several modern games employ 3D graphics as well, which is a far cry from the flat, unrealistic arcade games of 20 years ago (has it really been that long?).

Whereas once you needed specialized hardware to compute three-dimensional objects, the modern PC is well equipped to handle the challenge, and SVGAlib's threeDKit is there to make it happen. Hopefully the examples presented herein will help to ease your entry into the world of 3D. Using this as a foundation, you can comfortably proceed to the ray tracing techniques given in the next chapter.
