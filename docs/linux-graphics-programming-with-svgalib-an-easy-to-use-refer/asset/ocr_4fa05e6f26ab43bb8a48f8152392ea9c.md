# A Look At Existing SVGAlib Applications

+   **Key Topics:**
+   * Image viewers
+   * Games
+   * Miscellaneous
+   * A brief look at porting

Thus far, I've directed my tutorials towards creating new applications for SVGAlib, which is generally what people want to learn about. There are times, however, when it's nice to see what else is out there. Perhaps you don't want to reinvent the wheel; why bother coding an application if it has already been done?

Here, then, is an extensive list detailing many of the applications now available for SVGAlib. You'll notice that the list centers on image viewers and games; perhaps that's indicative of the mindset of the average SVGAlib programmer. Nevertheless, I'm sure we'll see a wide variety of productivity applications in the near future.

For your convenience, all the programs listed are available on the companion CD-ROM. Additionally, most (and others) will be available at:

**metalab.unc.edu/Linux**

You'll need to look in the apps/graphics and games subdirectories.
