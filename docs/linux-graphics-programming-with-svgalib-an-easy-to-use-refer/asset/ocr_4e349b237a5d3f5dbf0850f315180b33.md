# ## Conclution

Certainly, raytracing is a subject that deserves its own book. However, it’s hoped that even within the confines of one chapter, you’ve been given a framework to build upon. We’ve seen the basics of how a virtual light ray can travel, creating color when it strikes an object. And Marcus Geelnard has provided us with the code for two raytracers, one straightforward, and the other involving distributed ray casts.

Of course, the time involved makes anything but the most simple forms of raytracing impractical for games or any other real-time activity. Nevertheless, it’s priceless for rendering elaborate images that look like they came from a camera and not from a program.
