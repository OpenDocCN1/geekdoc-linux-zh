Here’s how you put the font strips into action. Once the font is declared as a **char** array, you simply substitute gl_font8x8 (as used in previous listings) with the name of your own array. Listing 7.5 shows how you might do this with “bookfont,” which can be declared in your main program or in a separate file (my preference).

### Listing 7.5 Using your own font.

```c
char words[] = "Welcome to my program.";

void initfont(void);

vga_init();
gl_setmode(6320x200x256);
gl_setcontextvga(6320x200x256);

initfont();
gl_write(100, 100, words);

void initfont(void)
{
    void *font = malloc(256 * 8 * 8 * BYTESPERPIXEL);
    gl_expandfont(8, 8, 15, bookfont, font);
    gl_setfont(8, 8, font);
}
```

### FontBuilder.c

After making a character set or two, you’re probably going to be sick of the whole font business, and understandably so. To make things easier for you, I’ve developed a program called FontBuilder.c specifically for this book. This provides a graphical interface with which you can draw your characters, thus making your life much easier. A screen shot of FontBuilder’s main menu is shown in Figure 7.264, and the code for this program, if you’re interested, is shown in Listing 7.6. Although this simple program doesn’t allow you to edit existing fonts, you could easily extend its capabilities to include this feature.
