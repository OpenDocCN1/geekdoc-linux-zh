# Frame buffer

Memory in the graphics adapter used to hold a frame (i.e., one screen's worth of data). All VGA cards have at least one frame buffer; this is where the bitmapped screen image is stored as it's written to the screen. More advanced (and expensive) cards have enough memory to hold multiple frames. VgaI allows the use of two frame buffers: the physical screen and one "virtual" screen.
