# Commercial Office Suites for Linux

Several commercial office suites are available for Fedora in addition to StarOffice,
already mentioned. None of these commercial suites are provided with Fedora. Of note
is Hancom Office. Using the same QT widget set found in the KDE desktop, Hancom
Office scores well on Microsoft file format compatibility. The suite includes a word
processor, a spreadsheet presentation tool, and a graphics application. Corel produced
a version of its WordPerfect Office 2000 for Linux before it discontinued the release of
any new Linux products. It still offers a support page, but the software is no longer
available, nor is the excellent—but whiskered—WordPerfect 8 for Linux.
