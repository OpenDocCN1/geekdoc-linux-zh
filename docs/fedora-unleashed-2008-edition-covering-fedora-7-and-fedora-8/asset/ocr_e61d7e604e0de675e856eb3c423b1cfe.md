+   x extra functionality (experts only)

# TIP

> The fdisk command is dangerous to explore only if you write the changes to the partition table. Because you are specifically asking whether you want to do this, poke around to satisfy your curiosity and avoid pressing the w key when you're done; just use q to quit. Armed with this knowledge, don't feel too shy if you're curious about the partition table. But if you really do not want to take a chance on breaking anything, play it safe and use the -1 (that's the letter l, not the numeral 1) as in:

```
```
# fdisk -1 /dev/hda
```
```

fdisk happily prints the contents of the partition table to the screen (often referred to as stdout, or standard output) and exits without placing you in the edit mode. It is always a good idea to keep a hard copy of your edited partition table. You can redirect the output of fdisk -1 to a file:

```
```
# fdisk -1 device > mypartitiontable.txt
