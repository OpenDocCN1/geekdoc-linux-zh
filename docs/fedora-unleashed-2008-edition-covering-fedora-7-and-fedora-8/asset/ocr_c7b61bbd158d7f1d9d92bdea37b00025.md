# # Reference

+   - \[http://www.cdcopyworld.com\](http://www.cdcopyworld.com)/—A resource for technical information about CD media and CD writers.
+   - \[http://hardware.redhat.com/hcl\](http://hardware.redhat.com/hcl/)—A database of supported hardware.
+   - \[http://www.opensound.com/download.cgi\](http://www.opensound.com/download.cgi/)—The commercial OSS sound driver trial version download.
+   - \[http://www.xmms.org\](http://www.xmms.org/)—Home to the Xmms audio player.
+   - \[http://www.thekompany.com/projects/tkoggripper\](http://www.thekompany.com/projects/tkoggripper)—A free (but not GPL) Ogg CD ripper.
+   - \[http://faceprint.com/code\](http://faceprint.com/code/)—An MP3 to Ogg convertter named mp32ogg.
+   - \[http://www.ibiblio.org/pub/linux/apps/sound/convert/INDEX.html\](http://www.ibiblio.org/pub/linux/apps/sound/convert/INDEX.html)—Home to several sound conversion utilities.
+   - \[http://linux-sound.org\](http://linux-sound.org/)—An excellent resource for Linux music and sound.
+   - \[http://www.cnpbagwell.com/audio.html\](http://www.cnpbagwell.com/audio.html)—The Audio Format FAQ.
+   - \[http://www.icecast.org\](http://www.icecast.org/)—A streaming audio server.
+   - \[http://www.linuxnetmag.com/en/issue4/m4icecast1.html\](http://www.linuxnetmag.com/en/issue4/m4icecast1.html)—An Icecast tutorial.
+   - \[http://linuxshelf.com/HOWTO/MP3-HOWTO-7.html\](http://linuxshelf.com/HOWTO/MP3-HOWTO-7.html)—The MP3 HOWTO contains brief descriptions of many audio applications and, although it focuses on the MP3 format, the information is easily generalized to other music formats.
+   - \[http://www.expl0its.org/v4l/\](http://www.expl0its.org/v4l/)—Video for Linux resources.
+   - \[http:// fame.sourceforge.net\](http://fame.sourceforge.net)—Video encoding tools.
+   - \[http://teletext.mb21.co.uk/faq.shtml\](http://teletext.mb21.co.uk/faq.shtml)—The Teletext FAQ.
+   - \[http://xine.sourceforge.net\](http://xine.sourceforge.net/)—Home of the Xine DVD/video player.
+   - \[http://www.MPlayerHQ.hu/homepage/\](http://www.MPlayerHQ.hu/homepage/)—Home to the MPlayer video player.
+   - \[http://www.videoLAN.org/\](http://www.videoLAN.org/)—A VideoLAN project with good documentation.
+   - \[http://fy.chalmers.se/~appro/linux/DVD+RW/\](http://fy.chalmers.se/~appro/linux/DVD+RW/)—The DVD+RW/-RW/-R[RW] for Linux, a HOWTO for creating DVDs under Linux.
+   - \[http://www.gimp.org\](http://www.gimp.org/)—Home page of The GIMP (Gnu Image Manipulation Program).
+   - \[http://f-spot.org\](http://f-spot.org/)—Home page of the F-Spot project.
+   - \[http://www.linuxformat.co.uk\](http://www.linuxformat.co.uk)—Website of Linux Format, home of a long-running GIMP tutorial by Michael J Hammel.
