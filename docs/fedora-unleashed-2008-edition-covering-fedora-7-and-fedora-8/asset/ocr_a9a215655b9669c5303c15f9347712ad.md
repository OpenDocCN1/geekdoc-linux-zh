# ## KDEdu

There are other games available for Fedora that fall under the term “edutainment.” These types of games attempt to aid learning with often simple games. All of them are available through the meta-package kdedu, so all you have to do is use yum to retrieve this package.

**NOTE**

You can probably tell by the name that KDEdu is a KDE-based package. As a result, when you install KDEdu, you also need to install several KDE components, enough in fact to allow you to run KDE. See Chapter 3, “Working with GNOME,” for more information about KDE and how to access it.

Among the games are hangman (see Figure 9.7), an anagram game, a tool to learn about the periodic table of elements, and a great starazing tool called Kstars. There are others for you to explore and that can provide hours of learning and fun for your children.
