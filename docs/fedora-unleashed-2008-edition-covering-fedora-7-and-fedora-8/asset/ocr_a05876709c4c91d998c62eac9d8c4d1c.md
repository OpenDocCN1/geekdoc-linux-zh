You can create a listing of the printout of the partition table with \texttt{fdisk} by using the \texttt{-1} option (for \texttt{list}), as follows:

```
```bash
# fdisk /dev/hda -1 > /tmp/hdaconfig.txt
```
```

or send the listing of the partition table to the printer:

```
```bash
# fdisk /dev/hda -1 | kprinter
```
```

You could also copy the file \texttt{/tmp/hdaconfig.txt} to the same backup floppy disk as the MBR for safekeeping.

Now that you have a hard copy of the partition table (as well as having saved the file itself somewhere), it is possible to restore the MBR by hand at some future date.

Use the Fedora Rescue Disc for this process. After booting into rescue mode, you have the opportunity to use a menu to mount your system read/write, not to mount your system, or to mount any found Linux partitions as read-only. If you plan to make any changes, you need to have any desired partitions mounted with write permission.

After you are logged on (you are root by default), start \texttt{fdisk} on the first drive:

```
```bash
# fdisk /dev/had
```
```

Use the \texttt{p} command to display the partition information and compare it to the hard copy you have. If the entries are identical, you have a problem somewhere else; it is not the partition table. If there is a problem, use the \texttt{d} command to delete all the listed partitions.

Now use the \texttt{n} command to create new partitions that match the partition table from your hard copy. Make certain that the partition types (\texttt{ext2}, \texttt{FAT}, \texttt{swap}, and so on) are the same. If you have a \texttt{FAT} partition at \texttt{/dev/hda1}, make certain that you set the bootable flag for it; otherwise, Windows or DOS will not boot.

If you find that you have made an error somewhere along the way, just use the \texttt{q} command to quit \texttt{fdisk} without saving any changes and start over. If you don't specifically tell \texttt{fdisk} to write to the partition table, no changes are actually made to it.

When the partition table information shown on your screen matches your printed version, write the changes to the disk with the \texttt{w} command; you will be automatically exited from \texttt{fdisk}. Restart \texttt{fdisk} to verify your handiwork, and then remove the rescue disc and reboot.

It helps to practice manually restoring the partition table on an old drive before you have to do it in an emergency situation.
