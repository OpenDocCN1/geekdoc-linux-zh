Note how C# is clever enough to have integer + integer be added together (in the case of num1 + num2), whereas string + integer attaches the integer to the end of the string (in the case of “Sum of two parameters is:” + the result of num1 + num2). This isn’t by accident: C# tries to convert data types cleverly, and warns you only if it can’t convert a data type without losing some data. For example, if you try to treat a 64-bit integer as a 32-bit integer, it warns you because you might be throwing a lot of data away.

The reason for this is that we use args[0] and args[1] (the first and second parameters passed to your program) without even checking whether any parameters were passed in.
