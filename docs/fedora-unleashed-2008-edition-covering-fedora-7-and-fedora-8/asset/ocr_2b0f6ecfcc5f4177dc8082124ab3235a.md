# # Reference

+   ▶ [http://www.python.org/](http://www.python.org/)—The Python website is packed with information and updated regularly. This should be your first stop, if only to read the latest Python news.

+   ▶ [http://www.zope.org/](http://www.zope.org/)—The home page of the Zope Content Management System (CMS), it's one of the most popular CMSes around and, more importantly, written entirely in Python.

+   ▶ [http://www.jython.org/](http://www.jython.org/)—Python also has an excellent Java-based interpreter to allow it to run on other platforms. If you prefer Microsoft's .NET, try [http://www.codeplex.com/Wiki/View.aspx?ProjectName=IronPython](http://www.codeplex.com/Wiki/View.aspx?ProjectName=IronPython).

+   ▶ [http://www.pythonline.com/](http://www.pythonline.com/)—Guido van Rossum borrowed the name for his language from Monty Python's Flying Circus, and as a result, many Python code examples use oblique Monty Python references. A visit to the official Monty Python site to hone your Python knowledge is highly recommended!

+   ▶ [http://www.python.org/moin/PythonBooks](http://www.python.org/moin/PythonBooks)—There are few truly great books about Python; however, you can find a list of what's on offer at this site. If you are desperate to pick up a book immediately, you could do much worse than to choose *Learning Python* (O'Reilly, ISBN: 0-596-00281-5).
