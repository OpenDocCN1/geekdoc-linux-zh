# Pygame dependencies

The best way to install Pygame for your system is to compile it. To do this you need to first install the right dependencies. Open up the terminal and install the following packages, in Ubuntu looks like:

```
$ sudo apt-get install
mercurial-dev
python-numpy libav-tools
libsdl1-image-dev libsdl2-dev
mixer1.2-dev sdl2-ttf2.0-dev
libpeg-dev libsdl11-dev
libportmidi-dev libvsscale-dev
libavformat-dev libcodec-dev
```

+   01 Install Pygame dependencies

![](bbox=[0.395, 0.098, 0.636, 0.172])

Pygame is built on SDL2, which has many changes from SDL1 (see headers). It includes adding features like
- delegating to Branch deficit
- SDL 1.2-support is removed, Pygame is unsupported
- de-deprecated-use pygame setup version 2.1.2.dev553

```
$ python -m pip install pygame
```

If the dependencies were not found, Pygame was not installed. Try checking the configuration again.

+   02 Get the Pygame code

If the above doesn't work (or a bit daunting) you can check the website for binary files that work on other systems and Linux dist. Head to http://pygame.org/download.html to get the file you need for your specific system, Windows and OS X. The rest of the tutorial will win in any.

+   03 Next to download the code for Pygame

from the source. Still in the terminal, you can do this by typing:

```
$ git clone https://github.com/pygame/pygame
```

Which will download it to the folder 'pygame'. Move to the folder in the terminal so we can continue building.
