# Working with bzip2 (.bz2) compression

You can use the module bzip2 to read and write using the bzip2 compression algorithm.

- 33 bzip2.compress() : For compression
bzip2.decompress() : For decompression Example:

```
# File: bz-example.py
import bzip2
MESSAGE = "Kunal is a bad boy"
>>> compressed = bzip2.compress(MESSAGE)
>>> decompressed = bzip2.decompress(compressed)

>>> print(MESSAGE)
>>> print("compressed:")
>>> print(compressed)
>>> print("decompressed:")
>>> print(decompressed)
>>> print("decompressed-message:")
```
