```python
def control(self):
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            GameState.start_screen = False
            GameState.end_game = True
        if event.type == pygame.KEYDOWN \
            and event.key == pygame.ESCAPE:
                if GameState.start_screen:
                    GameState.end_game = True
                    self.kill_all()
        if GameState.start_screen:
            keys = pygame.key.get_pressed()
            if keys[pygame.K_LEFT]:
                GameState.vector = -1
                self.animate_left = True
                self.animate_right = False
            elif keys[pygame.K_RIGHT]:
                GameState.vector = 1
                self.animate_right = True
                self.animate_left = False
```

### The animation method

09 We use flags in the code for the player: animate_player(). Here we use nested statements to control the animation and physically set the player image. It states that if the animate_right is True and if the current position is not what we want, we increment the ani_pos variable and set the player image. The Else statement then animates the sprite back to its resting state and the same logic is then applied in the opposite direction.

```python
def animate_player(self):
    if animate_right:
        if self.ani_pos < 6:
            Player.image = self.sprite_sheet.subsurface(self.ani_pos*64, 0, 64, 61)
            self.ani_pos += 1
    else:
        if self.ani_pos > 5:
            self.ani_pos -= 1
            Player.image = self.sprite_sheet.subsurface(self.ani_pos*64, 0, 64, 61)
    if animate_left:
        if self.ani_pos > 0:
            self.ani_pos -= 1
```

# Make a visual novel game

 Create with Python

Bridge the gap between books and games creating an interactive novel with Python. Most people look for a compelling story in modern games, and those that don't have one appearing less. A great way to tell a pure story through the genre of visual novels, and you can make one fairly simply in Python. These interactive novels are extremely popular form of entertainment and usually work by having the player click through story and make decisions as they go along in order to experience different plot points and endings.

In Python, this is a relatively simple project to create, with the addition of the Pygame module we can make it easier still, and even expandable for the future. Pygame adds better support for positioning the images and text, creating display windows and mouse inputs, thereby simplifying the coding process. We'll be coding this in standard Python, so make sure to run it in IDE 2 and not IDE 3 while you are writing, testing and coding.
