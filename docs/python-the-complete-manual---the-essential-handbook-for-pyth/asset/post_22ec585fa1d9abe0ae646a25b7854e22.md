- putenv(varname,value) : Adds or sets an environment variable with the given variable name and value.
- getuid() : Return the current process's user id.
- getlogin() : Returns the username of currently logged in user.
- getpid(pid) : Returns the process group id of given pid. When used without any parameters it returns the current process id.
- getcwd() : Return the path of the current working directory.
- chdir(path) : Change the current working directory to the given path.
- list(path) : Similar to ls, returns a list with the content of directories and file available on the given path.

Example:
```python
os.listdir("/home/homer")
```

- mkdir(path, model) : Creates a directory with the given path with the numeric code mode. The default mode is 0777.
- makedirs(path, model) : Creates given path (inclusive of all its directories) recursively. The default mode is 0777.

Example:
```python
import os
path = "/home/kunal/greatdir"
os.makedirs(path, 0755)
```

- rename(old,new) : The file or directory "old" is renamed to "new". If "new" is a directory, an error will be raised. On Unix and Linux, if "new" exists and is a file, it will be replaced silently if the user has permission to do so.
- rename(old,new) : Similar to rename but also creates directories recursively if necessary.

IPython comes with a set of predefined 'magic' functions that can with a command-line-style syntax. IPython 'magic' commands are conventionally prefixed by %, but if the %automagic is set to on, then you can call magic commands without the %. To view a list of available magic functions, use 'magic function' %magic. They include functions that work with code such as %run, %edit, %macro, %reall etc functions that affect shell such as %colors, %xmode, %autoindent etc and others as %reset, %timeit, %paste etc. Most features of IPython are powered using magic functions.

## Tab completion
Tab completion provides an excellent way to explore any object. It also helps you avoid typos.

Example:

```python
import os

```

## Object Explorer
You can add '?' after any object to view its details. You can also use double question marks (??) to view the source code for the relevant object.
