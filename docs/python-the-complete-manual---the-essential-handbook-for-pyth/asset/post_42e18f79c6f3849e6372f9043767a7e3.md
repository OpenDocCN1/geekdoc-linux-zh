## Scientific computing with NumPy

Make some powerful calculations with NumPy, SciPy and Matplotlib

NumPy is the primary Python package for performing scientific computing. It has a powerful N-dimensional array object, tools for integrating C/C++ and Fortran code, linear algebra, Fourier transform, and random number capabilities, among other things. NumPy also supports broadcasting, which is a clever way for universal functions to deal in a meaningful way with inputs that do not have exactly the same form.

Apart from its capabilities, the other advantage of NumPy is that it can be integrated into Python programs. In other words, you may get your data from a database, the output of another program, external file or an HTML page and then process it using NumPy.

This article will show you how to install NumPy, make calculations, plot data, read and write external files, and it will introduce you to some Matplotlib and SciPy packages that work well with NumPy.

NumPy also works with Pygame, a Python package for creating games, though explaining its use is unfortunately beyond of the scope of this article.

It is considered good practice to try the various NumPy commands inside the Python shell before putting them into Python programs. The examples in this article use either Python shell or IPython.

## Making simple calculations using NumPy

About NumPy Despite its simplistic name, NumPy is a powerful package that is mainly for working with arrays and matrices. Many ways to create an array the simplest one is to use the array function Given an array named myArray, you can find the minimum and maximum values in it executing the following commands:

- * >> myArray = array([1,2,3,4])
- * >> myArray.min()
- * >> myArray.max()

If you want to create a two-dimensional array, you can use the array function as follows:

- * >> twoD = array([[1,2,3,4],[5,6,7,8]])

- * >> myArray.mean()
array([1,2,3,4])

Similarly, you can find the median of the median value of an element is that divides the data set into two subsets (left and right subsets) with same number of elements. If the data set has odd number of elements, then the median is the part of data. The other side, if the data has an even number of elements, the median is the mean of the two centres of the sorted data set.

## Reading files

Imagine that you have just collected information from an Apache log file using NumPy and now you want to go and process the file using NumPy. The following AWK code finds out the total number of requests per:

```
$ cat access.log | cut -d ' ' -f2 | cut -d ' ' -f1 | awk '{print $2}' | sort | uniq -c | awk '{print $2, $1}' > time.txt
```

The format of the file (time.txt) with the data is:

```
00 191
01 225
02 121
03 104
```

Reading the time.txt file and assigning it to a new variable can be done as:

```
aa = np.loadtxt("time.txt")
```

## Writing files
