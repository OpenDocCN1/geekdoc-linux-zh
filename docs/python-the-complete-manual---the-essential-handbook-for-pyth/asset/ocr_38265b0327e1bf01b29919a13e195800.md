*** Caught exception: <type exceptions.TypeError>: unbound method missing_host_key() must be called with WarningPolicy instance as first argument (got SSHClient instance instead)

This means that the client cannot verify the authenticity of the server you are connected to. To add the host to known hosts, use the ssh command. It is important to remember that this is not the ideal way to add the host key; instead you should use ssh-keygen. For simplicity it's sake

To run you will also need a custom Python class interactive.py which implements the interactive shell for the SSH session. Look for this file on FileSilo and copy it into the same folder where you created SSHClient.py.
