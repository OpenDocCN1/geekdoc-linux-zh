```
def button_pressed(self, button):
    player = {'O': 'O', 'X': 'X'}
    colours = {1: (1, 0, 0), -1: (0, 1, 0)}
    # (r, g, b, a)

    row, column = button.coords

    status_index = 3*row + column
    already_played = self.status[status_index]

    if not already_played:
        self.status[status_index] = self.current_player
        button.text = {'O': 'O', 'X': 'X'}[self.current_player]
        button.background_color = colours[self.current_player]
        self.current_player *= -1
```

```
def on_status(self, instance, new_value):
    status = new_value

    sums = [sum(status[0:3]), # rows
               sum(status[3:6]),
               sum(status[6:9]),
               sum(status[0::2]), # columns
               sum(status[1::2]),
               sum(status[::2]), # diagonals
               sum(status[2::::-2])]

    if 3 in sums:
        print('Os win!')
    elif -3 in sums:
        print('Xs win!')
    elif 0 not in self.status: # Grid full
        print('Draw!')
```

You can run this app to see exactly what this did, and you'll find that clicking each button places an 'O' or 'X' as well as a coloured background depending on whose turn it is. Not only that, but you can only play one move in each button that our status keeps track of the existing moves.

This is enough to play the game but there's one vital element missing, a big pop-up telling you when you won! Before we do that, we need to add some code to check if the game is over. Kivy properties have another useful feature here, whenever they change it automatically calls an '_property' method if it exists and dispatches a corresponding event in Kivy's event system. That makes it easy to write code that will run when a property changes, both in Python and kv language. In our case we can use it to check the status list every time it is updated, something special if a player has filled a column, row or diagonal.

This covers the basic detection of a win or draw, but only prints the result to stdout. In this stage we probably want to reset the board so that the players can try again, displaying a graphical indicator of the result.

```
def reset(self, *args):
    self.status = [0 for _ in range(9)]

    for child in self.children:
        child.text = ""
        child.background_color = (1, 1, 1, 1)

    self.current_player = 1
```
