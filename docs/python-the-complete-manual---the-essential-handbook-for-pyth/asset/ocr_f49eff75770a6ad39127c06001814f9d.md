# Arrays with NumPy

+   04 NumPy array only embraces
the indexing methods used in
Python for strings and lists
but extends them. If you want to
select an element from an array,
use the following notation:

+   >>> arr[0,1]

You can also select slice of an array (a
slice) using the following notation:

+   >>> arr[1:1:3]

Finally, you can convert an array into an
Python list using the tolist() function.

# Reading files

+   05 Imagine that you have just
collected information from an
Apache log file using NumPy and
now you want to go and process the
file using NumPy.
The following AWK code finds out
the total number of requests per:

```
$ cat access.log | cut -d ' ' -f2 | cut -d ' ' -f1 | awk
'{print $2}' | sort | uniq
-c | awk '{print $2, $1}' > time.txt
```

The format of the file (time.txt)
with the data is:

```
00 191
01 225
02 121
03 104
```

Reading the time.txt file and
assigning it to a new variable can
be done as:

```
aa = np.loadtxt("time.txt")
```
