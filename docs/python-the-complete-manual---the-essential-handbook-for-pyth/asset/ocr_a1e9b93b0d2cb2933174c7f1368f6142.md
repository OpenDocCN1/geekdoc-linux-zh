Docstring:
Common operations on POSIX pathnames.

Instead of importing this module directly, import os and refer to this as os.path. The 'os.path' name is an alias for this module on POSIX systems; other systems (eg Mac, Windows) os provides the same operations in a manner specific to that platform, and is an alias to another module (eg macpath, npath).

Some of this can actually be useful on non-POSIX systems too, eg for manipulation of the pathname component of URLs. You can also use double question marks (?? to view the source code for the relevant object.

Magic functions: IPython comes with a set of predefined 'magic' functions that can with a command-line-style syntax. IPython 'magic' commands are conventionally prefixed by %, but if the %automagic is set to on, then you can call magic commands without the %. To view a list of available magic functions, use 'magic function' %magic. They include functions that work with code such as %run, %edit, %macro, %reall etc functions that affect shell such as %colors, %xmode, %autoindent etc and others as %reset, %timeit, %paste etc. Most features of IPython are powered using magic functions.
