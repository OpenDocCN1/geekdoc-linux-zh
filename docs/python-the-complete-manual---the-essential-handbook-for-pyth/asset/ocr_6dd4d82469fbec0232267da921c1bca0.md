# Continue or exit?

We will deal with result that was stored during the loop with statements. If the user typed 'yes' we will print 'Continuing'. Otherwise, we will print 'Exiting' and then call the exit function. You don't have to do anything else for the program to continue if the exit function wasn't called. This code also shows that the newline character '\n' can be used anywhere in a string, not just quotation marks like above.
