## REST

### Install the software

REST stands for Representational State Transfer. (It is sometimes spelt "REST") It relies on a stateless, client-server, cacheable communications protocol – and in virtually all cases, the HTTP protocol architecture style for designing networked applications.

- 04 Boot up your Raspberry Pi and connect it to the Internet. Before you install the Twilio software, it is worth updating and upgrading your Pi. In the LX Terminal, type sudo apt-get update, sudo apt-get upgrade. Once complete, type sudo apt-install twilio or sudo pip install twilio to install the software. (If you need to install pip, type sudo apt-get install python-pip-dev, press Enter, then sudo pip install -U pip.)

## Twilio authentication

- 05 Now you are ready to use Twilio. Open your editor and write the following code:

```python
from twilio.rest import Client

account_sid = 'YOUR_ACCOUNT_SID'
auth_token = 'YOUR_AUTH_TOKEN'
client = Client(account_sid, auth_token)

message = client.messages.create(
    body="Hello from Raspberry Pi!",
    from_='YOUR_TWILIO_NUMBER',
    to='+YOUR_PHONE_NUMBER'
)

print(message.sid)
```

## Voice, SMS & MMS

### API Credentials

Twilio is not just for SMS; you can also make voice calls and send MMS. To do this, you will need to use the twilio-python library.

```bash
sudo pip install twilio
```

Here is the code to make a phone call:

```python
from twilio.rest import Client

account_sid = 'YOUR_ACCOUNT_SID'
auth_token = 'YOUR_AUTH_TOKEN'
client = Client(account_sid, auth_token)

call = client.calls.create(
    url='http://demo.twilio.com/docs/voice.xml',
    from_='YOUR_TWILIO_NUMBER',
    to='+YOUR_PHONE_NUMBER'
)

print(call.sid)
```

## Voice synthesizer

### What you'll need...

- Portable speakers
- python-espeak module

eSpeak is a library that allows your Raspberry Pi to convert text to speech. This is useful for projects where you want your Pi to talk to you.

To get started, you will need to install the library:

```bash
sudo apt-get install espeak
```

Once installed, you can use it in Python to make your Pi speak:

```python
import espeak

text = "Hello, I am your Raspberry Pi!"
espeak.say(text)
```

You can also change the voice and the speed:

```python
espeak.say(text, speed=150)
```

# Pi's first words

The eSpeak library is pretty simple to use – to get it just saying something, in the terminal:

```bash
$ eSpeak "[message]"
```

This will use the library's defaults to read whatever is written in the message, with decent clarity. Though this simple command is fun, there's much more you can do...

# Say some more

You can easily read text with many different options, such as gender, read speed and even when it pronounces syllables. For example, writing the command like:

```bash
$ eSpeak -venf3 -k5 -s150 "[message]"
```

...will turn the voice female, emphasise capital letters and make the reading slower.
