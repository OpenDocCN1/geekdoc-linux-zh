This is written for the Python 2X series, as it is still the most popular and default Python distribution across all platforms (including all Linux, BSDs and Mac OS X).

System administration is an important part of our computing environment. It does not matter where you are managing systems at your work home. Linux, being a UNIX-based operating system, already has everything a administrator needs, such as the world-class shells (not just one but many, including Bash, esh, zsh etc), handy tools, and many other features that make the Linux system an administrator's dream. Why do we need Python when Linux already has everything built-in? Being a dynamic scripting language, Python is very easy to read and learn. That's not us saying that, but many Linux distributions actually use Python in core administrative parts. For example, Red Hat (and Fedora) system setup tool Anaconda is written in Python (read this line again, got the snake in?). Also, tools like GNU Mailman, CompizConfig Settings Manager (CCSM) and hundreds of tiny GUI and non-GUI tools are written using Python. Python does not limit you on the choice of user interface to follow – you can build command-line, GUI and web apps using Python. This way, it has covered almost all the possible interfaces. Here we will look into executing sysadmin-related tasks using Python.

# ## Parsing configuration files

Configuration files provide a way for applications to store various settings. In order to write a script that allows you to modify settings of a particular application, you should be able to parse the configuration file of the application. In this section we learn how to parse INI-style configuration files. Although old, the INI format is very popular with modern open source software, such as PHP and MySQL.

Excerpt for php.ini configuration file:

