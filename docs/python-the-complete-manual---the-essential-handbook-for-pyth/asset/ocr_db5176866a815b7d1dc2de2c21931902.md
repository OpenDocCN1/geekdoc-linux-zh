# Interpreter

# Axes

01 The command interpreter converts a series of commands from a radio control or programmed into the code itself. The commands combine the direction and speed compared to the horizon the user wants the quadcopter to follow. The code converts these into a series of targets for speed, horizontal speed and yaw speed – any command from pair of joysticks can be broken down into one set of targets.

03 The accelerometer is relative to the orientation of quadcopter axes, the command targets are relative to the Earth's axes – the horizon and gravity. To convert the output between the quadcopter axes and the Earth requires a use of bit mathematics, specifically trigonometry. You also need to know the roll and pitch angles of the quadcopter with respect to the Earth. It's pretty complicated stuff, but the diagrams on these pages help you understand the logic.

# Inputs

02 The inputs to the quadcopter come from a series of electronic sensors providing information about its movement in the air. The main two are accelerometer measures acceleration force (gravity) in the three axes of the quadcopter, and a gyroscope which measures the angular speed with which the quadcopter is pitching (nose/tail up down), rolling (left/right side up down) and yawing (spinning clockwise and anticclockwise around the central axis of the quadcopter itself).
