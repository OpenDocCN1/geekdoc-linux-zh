# Fixing a small issue

07 The Debian Image that we are currently using has a small misconfiguration issue. You'll know if you have this problem by trying to run your program with either the F5 key or going to the Build menu and selecting Execute. If the issue is present then nothing will happen and you'll see a message 'Could not find terminal: xterm'. Not worry, it's easy to fix. Go to the Edit menu and select Preferences. Go to the Tools tab and change the value for Terminal from xterm to terminal.

# Working with numbers

09 We're asking the user for a number by basically repeating the first couple of lines we did. Once the user gives us a number, we'll have, square and double it. The raw_input function returns the value that the user input is a string. A string is a text-based value we can't perform arithmetic on it. The integer type in Python can only store numbers where the decimal value contains numbers with decimals. We're going to doing something called a cast, which basically converts a value with one type to another. We're going to convert our number string to a decimal value because it's likely that decimals will be involved if we are halving numbers. If the number was of an integer type, any decimals would simply be cut off the end, without any rounding. This is called truncation.
