You probably noticed we had one of the Block's 'Color' instructions to clear its property. This means that we can change the property any time to update the color of the block, or in this case to give each block a random color (Fig. 04).

Now that each of has a graphical representation, let's learn how to place them, so start up the app and actually see something there.

Here create the widgets we want then use add_widget to add to the graphics. Our root widget on the screen is an instance of Game and every block is added to to be displayed.

The only new thing there is that every Block has been given a pos_hint. All widgets have this special property, and it is used by Layout like our Game to set their position proportionately to the layout.

The dictionary is to handle various parameters, but in this case 'X' give y and Block position as a relative fraction of the width and height.

You can run the app now, and add 50 blocks to the Game before displaying it on the screen. Each should have one of the three random colors and be positioned in a grid, but you'll now notice their sizes aren't manually set so they overlap.
