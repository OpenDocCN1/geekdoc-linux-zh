# Create with Python

This is a pop-up which draws itself on top of everything else rather as part of the normal widget tree. It also automatically closes when the user clicks or taps outside it.

```
winner = None
if -3 in sums:
    winner = 'Xs win!'
elif 3 in sums:
    winner = 'Os win!'
elif 0 not in sums:
    winner = 'Draw...nobody wins!'
```

if winner:
    popup = ModalView(size_hint=(0.75, 0.5))
    victory_label = Label(text=winner, font_size=50)
    popup.add_widget(victory_label)
    popup.bind(on_dismiss=self.reset)
    popup.open()

# Time to experiment

This has been a quick tour through some of Kivy's features, but hopefully it demonstrates how to think about building a Kivy application. Our programs are built from individual Kivy widgets, interacting by having Python code run when properties change (or 'on_status' method) or when they dispatch events (like 'Button' 'on_release'). We will briefly review how Kivy works and experienced how it can automatically create bindings between properties.

You can find a copy of the full program on File6, reference this to check you've followed everything correctly. We've added an extra widget, the 'Interface', with a structure coded entirely in kivy language that demonstrates how to add child widgets. We test it by returning the 'Interface' in 'TicTacToeGrid'. It doesn't do anything different from what we already covered, but it does make extensive use of kivy language' binding ability to automatically show the current label, and to resize the TicTacToeGrid so it is always square to fit within your window. You can change the settings to see how it fits together, or swapping out the different widget types to see how other widgets behave.

This mostly uses the ideas we already covered, adding the 'Label' widget to the 'ModalView' then letting the 'ModalView' take care of drawing itself and its children on top of everything else. We also another binding; this time to 'on_dismiss', which is an event dispatched by the 'ModalView' when it is closed. Finally, we made use of the 'size_hint' property to all widgets, which in this case is used to set the 'ModalView' proportional to the window – while open we resize the window it dynamically resize, maintaining these proportions. This is another trick made possible by a binding with the 'size_hint' property, this managed internally by Kivy.

That's it for program! We can now only play tic-tac-toe, but our program automatically tells us when somebody has won, and resets the board so we can play again. Simply run your program and enjoy hours of fun!
