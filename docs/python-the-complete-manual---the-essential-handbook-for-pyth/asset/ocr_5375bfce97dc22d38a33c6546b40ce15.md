# ## Writing a user interface using Python

Administrators are comfortable with running scripts by hand, but end-users are not. So if you are writing a script that is supposed to be used by common users, it is a good idea to create a user-friendly interface on top of the script. This will allow end-users to run scripts just like any other application. For example, we will create a graphical tool that allows users to select default entry and timeout. We will use the Python module 'snk' to facilitate this (not to be confused with the Python audio library, tonny).

This app consists of two files:

+   grub.py: GrubConfig File (available on File.). It implements two main functions, readGrub0() and writeGrubFile().
grub_ui.py: User interface for manipulating the GRUB configuration using the functions defined in grub.py.
