# Hello World

The first line begins with a shebang (the symbol #!) followed by the path to the Python interpreter. The program loader uses this line to work out the rest of the lines need to be interpreted. If you're running this in an IDE like IDLE, you don't necessarily need to do this.

The code that is actually read by the interpreter is only a single line. We're passing the value Hello World to the print function by placing it in brackets immediately after we've called the function. Hello World is encoded without quotation marks to indicate that it is a literal value and should not be interpreted as source code. As we expect, the print function in Python prints any value that gets passed to the console.

You can save the changes you've made to the file in nano using the key combination Ctrl+O, followed by Enter. Use Ctrl+X to exit nano.

```python
#!/usr/bin/env python2
print("Hello World")
```

You can run the Hello World program by prefixing its filename with / - in this case you type:
hello_world.py

```
[Liam@liam-laptop Python]$ ./hello_world.py
Hello World
```

# Variables and data types

A variable is a name in source code that is associated with an area in memory that you can use to store data, which is then called throughout the code. The data can be one of many types, including:

| Type | Description |
|---|---|
| Integer | Stores whole numbers |
| Float | Stores decimal numbers |
| Boolean | Can have a value of True or False |
| String | Stores a collection of characters. "Hello World" is a string |
