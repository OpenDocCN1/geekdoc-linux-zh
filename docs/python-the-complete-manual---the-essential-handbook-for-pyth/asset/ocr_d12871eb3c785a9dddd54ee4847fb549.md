# Putting your APK on the Play Store

Find out how digitally sign a release APK and upload it to an app store of your choice

```
1 Build and sign a release APK
```

Begin by creating a digital key, then using it to sign a special release of your APK. Run these commands, and follow the instructions.

```
## Create your personal digital key
## You can choose your ##keystore name, alias, and passwords.
## $ keytool -genkey -keystore release-key.keystore -alias release-alias -validtype -1000 -keyalg RSA -keysize 2048 -validity 10000
## Compile your app in release mode
## $ builder android-release
## $ Sign your APK with your new key
## $ jarsigner -verbose -SHA1withRSA -digestalg SHA1 -keystore/release-key.keystore -alias release /bin/KivyBreakout-0.1-release-unsigned.apk -signed
## Align the APK zip file with $ /buildozer android -platform=android -sdk-21/tools/zipalign -v 4 -release - /bin/KivyBreakout-0.1-release.apk
```

> “Check through the whole file to see what's available, but most of the default settings will be fine”

```
git clone:github.com/kivy/buildozer
cd buildozer
sudo python2.7 setup.py install
```

When you run it, it will download the Android SDK and NDK, which are large (at least hundreds of megabytes) but will to build. It will also take time to build and compile the Python components of your APK. A lot of this only needs to be done once, as builds will take couple of minutes or just few seconds if you've changed your code.

When you're done with that you can go on and navigate to your Kivy app, and you'll have to name the main code file `main.py`, this is the access point that the Android APK will expect.

```
builder init
```

This creates a `buildozer.spec` file, a settings file containing all information that Buildozer needs to create your APK, from the name and version to the specific Android build options. We suggest that you check through the whole file to see what's available but most the default settings will be fine, the only thing we suggest changing (is Fig. 1).

The APK produced is a debug APK, and you can install and use it. There are extra steps if you want to sign it so that it can be posted on the Play store. This isn't hard, and Buildozer can do some of the work, but check the documentation online for full details.

There are other options you will want to set, but not really that all will right now, so you are able to immediately tell Buildozer to build your APK and get going!

Assuming everything goes fine (it), your APK will be in a new 'bin' directory with the name `KivyBreakout-0.1-debug.apk`. You can send it to your phone any way you like (eg email), though you may need to enable application installation from unknown sources in your settings before you can install it.

This will take some time, so be patient and it will work out fine.
