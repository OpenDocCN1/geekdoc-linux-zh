# Work with Python

copy (src,dst): Copy the src file to the destination directory. In this mode permissions bits are copied but metadata is not copied.
copy2 (src,dst): Same as copy() but also copies the metadata.
copytree(src, dst[, symlinks=False, ignore=None]): This is similar to 'cp -r', it allows you to copy an entire directory.
ignore_patterns (*patterns): ignore_patterns is a function that can be used as a callable for copytree(), it allows you to ignore files and directories specified by the glob-style patterns.
rmtree(path[, ignore_errors, onorror]): rmtree is used to delete an entire directory.
move(src,dst): Similar to mv command allows you to receptively move a file or directory to a new location.

```
from shutil import copytree, ignore_patterns
copytree(source, destination, ignore=ignore_patterns('*.pyc', ('tmp*')))
```

make_archive(base_name, format[, root_dir[, base_dir[, dry_run=, owner[, group[, logger]]]]): Think of this as a replacement for tar, zip, bzip2 etc. make_archive() creates an archive file in the given format such as zip, bztar, gtar. Archive support can be extended via Python modules.

```
from shutil import make_archive
import os
archive_name = os.path.expandander(os.path.join('~', 'ludarchive'))
root_dir = os.path.expandander(os.path.join('~', '.ssh'))
make_archive(archive_name, 'gtar', root_dir)
```

# 2. Interfacing operating system & subprocesses

Python provides two modules to interface with the OS and to manage processes, called os and subprocess. These modules let you interact with the core operating system shell, and work with the environment, processes, users and file descriptors. The subprocess module was introduced to support better management of subprocesses (paalready)
