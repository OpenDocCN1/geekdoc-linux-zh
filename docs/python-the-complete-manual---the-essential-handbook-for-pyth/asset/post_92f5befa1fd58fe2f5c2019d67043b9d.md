## More about a Python list

A Python list is similar to an array in other languages. A list (or tuple) can contain data types, which is not usually the case with arrays in other languages. For this reason, we recommend that you only store data of the same type in a list. This should almost always be the case anyway due to the nature of the way data in a list would be processed.

## Functions and variable scope

Functions are used in programming to break processes down smaller chunks. This often makes code much easier to read. Functions can also be reusable if designed in a certain way. Variables in Python are always passed by value, which means that a copy of the variable is passed to the function that is is only valid in the scope of the function. Any changes made to the original variable inside the function will be discarded. However, functions can also return values, so this isn't an issue. Functions are defined with the keyword def, followed by the name of the function. Any variables that can be passed through are put in brackets following the function's name. Multiple variables are separated by commas. The names given to the variables in brackets are the ones they will have in the scope of the function, regardless of what the variable passed to the function is called. Let's see this in action. The output from the program opposite is as follows:

> “Functions are defined with the keyword def, then the name of the function”

```python
#!/usr/bin/env python2 # Below is a function
called modify_string, which accepts a variable
# that will be called original in the scope of the
function. Anything # indented with 4 spaces
under the function definition is in the
# scope.
def modify_string(original):
    original += " that has been

def modify_string_return(original):
```

We are now outside the scope of modify_string function, as we have reduced the level of indentation


Scope is an important thing, it's worth getting used to. However, if you define a variable inside a function, it is only available within that function. This is because of scope. If you want to use that variable outside the function, you must return it. For example:

```python
def my_function():
    x = 10
    return x

result = my_function()
print(result)
```
