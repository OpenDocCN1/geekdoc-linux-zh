Here we introduce the Kivy language (kv), a special domain-specific language for making Kivy trees. It is simple but removes a lot of necessary boilerplate for managing the UI with Python code - as an analogy you might think of it as HTML/CSS to Python's JavaScript. Python gives us the dynamic power to do anything, but all that power gets in if we just want to declare the basic structure of our UI. You might never need Kivy language, you can always do the same thing in Python alone, but the rest of the way why Kivy programmers usually like to use kv.

This inherits from Kivy's widget, which interacts with mouse or touch, dispatching events when they toggle. We can hook into these events to call our own functions when a user presses the button, and set the button's 'text' property to display the 'X' or 'O'. We created a new Kivy property for our widget, 'coords' – we will show how this is useful later on. It's almost identical to making a normal Python Attribute by writing self, `coords = [0, 0]` in `GridEntry.__init__`.
