## Replace your shell with Python

What you'll need...

Python is a great programming language, but did you know it can even replace your primary shell? We all use shell on a daily basis. For most of us, shell is the gateway into our Linux system. For years and even today, Bash has been the default shell for Linux. But it is getting a bit long in the tooth.

No need to be offended we still believe Bash is the best shell when compared to some other UNIX shells such as Korn Shell (KSH), C Shell (CSH) or even TCSH.

This tutorial is not about Bash being incapable, but it is about how to breathe completely new life into the shell to do old things conveniently and new things which were previously not possible, by a long shot. So, without further delay, let's jump in.

While the Python programming language may require you to write longer commands to accomplish a task (due to the way Python's modules are organised), this is not something to be concerned about. You can easily write aliases to the equivalent of Bash command that you intend to replace. Most of the time there will be more than one way to do a thing, but you will need to decide which way works best for you.

Python provides support for executing system commands directly (via the os or subprocess module), but where possible we focus on Python-native implementations.

### SECTION 1: Completing basic shell tasks in shutil

The shutil module provides support for file and directory operations. It provides support for file attributes, copying, archiving etc. Let's look at some of its important functions.

- copy (src,dst): Copy the src file to the destination directory. In this mode permissions bits are copied but metadata is not.
- copy2 (src,dst): Same as copy() but also copies the metadata.
- copytree (src, dst[, symlinks=False, ignore=None]): This is similar to 'cp -r', it allows you to copy an entire directory.
- ignore_patterns (*patterns): ignore_patterns is a function that can be used as a callable for copytree(), it allows you to ignore files and directories specified by glob-style patterns.
- rtree (path[, ignore_errors, onerror]): rmtree is used to delete an entire directory.
- move (src,dst): Similar to mv allows you to recursively move a file or directory to a new location.
- make_archive (base_name, format[, root_dir[, base_dir[, dry_run, owner[, group[, logger]]]]): Think of this as a replacement for tar, zip, bzip2 etc. make_archive() creates an archive file in the given format such as zip, bztar, gtar. Archive support can be extended via Python modules.
