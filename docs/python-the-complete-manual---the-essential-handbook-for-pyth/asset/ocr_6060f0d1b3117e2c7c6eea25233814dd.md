# Starting Geiger

02 Start Geiger by going to the LXDE menu and going to Programs. From here, select Geiger. Once you are in the Geiger interface, create a new Python file from a template by selecting 'New (with template)-main.py'. Delete everything in this template apart from the first line: #/env python. This line is important because it means you can run the code from the command line and the Bash will know to open it with the Python interpreter.
