# Trimming the fat

05 Wikipedia has a lot of nodes that we don't want to parse. The content allows us to straight away ignore most of Wikipedia's GUI, but there are still lots of elements that we don't want to parse. We remedy this by iterating through the list 'undesirables' that we created earlier in the document. For each different div/section/node that we don't want, we call BeautifulSoup's find_all() method and extract that node from the document. At the end of the undesirables list, most of the content we don't want any will be gone. We also look for the 'also' element in the Wiki page. Generally, everything after this is of use to us. By calling the find_all_next() method on the also node, we can get a list of every element we can remove from that point on.

```python
page = req.read()
req.close()
soup = BeautifulSoup(page, "html5lib", from_encoding="UTF-8")
content = soup.find(id="mw-content")
if hasattr(content, 'find_all'):
    global undesirables
    for notWanted in undesirables:
        removal = content.find_all(notWanted)
        if len(removal) > 0:
            for el in removal:
                el.extract()
also = soup.find(id="also")
if also is not None:
    tail = also.find_next('li')
    if len(tail) > 0:
        for element in tail:
            element.extract()
for link in content.find_all('a'):
    href = link['href']
    if isValidLink(href):
        if level < maxlevel:
            stored = False
            for addr in addresses:
                if addr == href:
                    stored = True
        if stored == False:
                title = href.replace("/wiki/", "")
                addresses.append(str(title) + ".html")
                grabPage("http://wikipedia.org" + href, level, title)
```

For every page we request, we append its URL to the addresses list; make sure we don't call the same page for each link twice.
