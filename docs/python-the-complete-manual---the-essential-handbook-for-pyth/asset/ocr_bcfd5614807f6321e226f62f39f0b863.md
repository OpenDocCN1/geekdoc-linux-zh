putenv(varname,value) : Adds or sets an environment variable with the given variable name and value.
getuid() : Return the current process's user id.
getlogin() : Returns the username of currently logged in user
getpid(pid) : Returns the process group id of given pid. When used without any parameters it returns the current process id.
getcwd() : Return the path of the current working directory.
chdir(path) : Change the current working directory to the given path.
list(path) : Similar to ls, returns a list with the content of directories and file available on the given path.

Example:
os.listdir("/home/homer")

mkdir(path, model) : Creates a directory with the given path with the numeric code mode. The default mode is 0777.
makedirs(path, model) : Creates given path (inclusive of all its directories) recursively. The default mode is 0777.

```
Example:
import os
path = "/home/kunal/greatdir"
os.makedirs(path, 0755 )
```

rename (old,new) : The file or directory "old" is renamed to "new"
"new" is a directory, an error will be raised. On Unix and Linux, if "new" exists and is a file, it will be replaced silently if the user has permission to do so.

rename (old,new) : Similar to rename but also creates directories
