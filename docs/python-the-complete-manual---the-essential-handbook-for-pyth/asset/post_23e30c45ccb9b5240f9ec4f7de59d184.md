### Creating the data model

04 This is the part where we define the data model for app. Please see the comments to understand what is happening here.

```python
from django.db import models
# We importing the user authentication module that we use the built in this app
from django.contrib.auth import models
# We would also create an admin interface for our app
from django.db import admin

# A Tuple to hold the multi char fields.
# First presents the field name that represents the display name 
ISSUE_STATUS_CHOICES = (
    ('New', 'New'),
    ('accepted', 'Accepted'),
    ('reviewed', 'Reviewed'),
    ('started', 'Started'),
    ('closed', 'closed')
)

class Issue(models.Model):
    # owner will be a foreign key to the User model which is already built in Django.
    owner = models.ForeignKey(
        models.User, null=True, blank=True, default="new"
    )
    status = models.CharField(
        max_length=20,
        choices=ISSUE_STATUS_CHOICES,
        default="new"
    )
    text = models.TextField()
    opened_on = models.DateTimeField(auto_now_add=True)
    modified_on = models.DateTimeField(auto_now=True)

class IssueAdmin(models.ModelAdmin):
    list_display = ('id', 'text', 'status', 'modified_on')
    list_filter = ('status', 'owner')
    date_hierarchy = 'opened_on'
    search_fields = ('text', 'status')

admin.register(Issue, IssueAdmin)
```

### Enabling the admin site

05 The admin site is already enabled, but we need to enable it in `urls.py`. Update the `urls.py` file as follows:

```python

from django.urls import include
from django.contrib import admin

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('issuedis.urls')),
]
```
