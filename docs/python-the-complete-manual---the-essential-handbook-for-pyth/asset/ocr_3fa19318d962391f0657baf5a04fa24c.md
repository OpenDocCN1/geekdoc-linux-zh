# # Send an SMS from your Pi

+   - Raspberry Pi

Create a program combining Twilio code and send an SMS from your Pi

Text messaging, or SMS (Short Message Service), has become a staple of everyday communication. For many of us, not a day will go without sending a text message. What began life as a 40 pence message service is now offered by most tariff providers as an unlimited service. Twilio, a cloud communications company, enables you to send SMS messages for free from your Raspberry Pi to a mobile phone using just six lines of code. So, you no longer needed to be chained to your mobile while you work, and can focus on one screen rather than two!
