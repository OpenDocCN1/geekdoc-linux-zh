## Adjust PWM

21 To add a time to the LED it fades out, we first need to import the library and then set the 12 pin to have 50Hz frequency to start.

```python
import time
import RPi.GPIO as GPIO
GPIO.setmode(GPIO.BOARD)
GPIO.setup(12, GPIO.OUT)
p = GPIO.PWM(12, 50) # channel=1 frequency=50Hz
p.start(0)
```

## Add the fade

22 Then we will add in another try-except block, this time checking what when the LED is at - and once it reaches a certain level, reverse the process. To run this code, save it from nano and then python gpio.py.

```python
while 1:
  for dc in range(0, 101, 5):
    p.ChangeDutyCycle(dc)
    time.sleep(0.1)
  for dc in range(100, -1, -5):
    p.ChangeDutyCycle(dc)
    time.sleep(0.1)
except KeyboardInterrupt:
  pass
```
