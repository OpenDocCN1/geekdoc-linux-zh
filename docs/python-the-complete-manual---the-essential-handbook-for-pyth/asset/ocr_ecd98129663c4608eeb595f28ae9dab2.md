# Animating explosions

```
def player_explode(self):
    if self.explode:
        if self.explode_pos < 8:
            self.explode_image = self.explosion_sheet.subsurface(self.explode_pos*76, 39)
            self.explode_pos += 1
            self.screen.blit(self.explode_image, [self.player.rect.x-10, self.player.rect.y-30])
        else:
            self.explode = False
            self.explode_pos = 0
```

The player_explosion() and alien_explosion() methods that come after the player explosion in the game classes are similar but executions of the same. As only one predefined set of frames (the time vertically), we only need to see the selfexplode and self_explode flags are true before we increment the variables that change the image.

Pygame makes easy to add a suitable piece of music to your preferred format (we used from freesound.org) and load it using the Pygame class. As it is already playing, we can only load via pygame. The music.play() requests that the music start with and continue until it quits. If replaced with -1, the music would loop five times before ending. Learn more about the Mixer class via www.pygame.org/docs/ref/mixer.html.

# Using sound effects

Loading and using is similar to how we do for images in Pygame. First we load the sound effect using a simple assignment. For the laser beam, the initialization looks like this
self.bullet_fx = pygame.mixer.Sound('location/of/file')
