# # Grabbing the links

By calling content.find_all('a') we get a list of every <a> in the document. We can iterate through this and check whether or not there is a valid Wikipedia link in the href attribute. If the link is valid, we quickly check how far down the link we have gone from the current page. If we reached the maximum depth we can go, we store this page and call it quits, otherwise we start looking for links that we can grab within. For every page we request, we append its URL to the addresses list; make sure we don't call the same page for each link twice; we check if we've already stored it. If so, then we'll skip the rest of the loop; if not we'll add it to the list of URLs that we've requested and fire off a request. Once that check is done, we do a quick replace on that link so it points to the local directory, not to the subfolder /wiki/ that we're looking for.
