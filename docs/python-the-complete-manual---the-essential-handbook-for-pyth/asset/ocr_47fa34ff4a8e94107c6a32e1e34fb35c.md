The code that is actually read by the Python interpreter is only a single line. # Variables and data types

A variable is a name in source code that is associated with an area in memory that you can use to store data, which is then called throughout the code. The data can be one of many types, including:

| Integer | Stores whole numbers |
|---|---|n| Float | Stores decimal numbers |
| Boolean | Can have a value of True or False |
| String | Stores a collection of characters. "Hello World" is a string |
