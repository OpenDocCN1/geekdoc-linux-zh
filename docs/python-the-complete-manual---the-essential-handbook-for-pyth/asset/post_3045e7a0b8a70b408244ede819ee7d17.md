## Plotting with Matplotlib

The first thing you should do is to install Matplotlib. As you can see, Matplotlib has many dependencies that also install. The first thing you will learn is how to plot a polynomial function. The necessary commands for plotting $3x^2+1$ are the following:

```python
import numpy as np
import matplotlib.pyplot as plt

poly = np.poly1d([3, 0, 1])
x = np.linspace(-5, 5, 100)
y = poly(x)

plt.xlabel('x values')
plt.ylabel('y values')
ticks = np.arange(-5, 6, 10)
plt.xticks(ticks)
plt.yticks(ticks)
plt.plot(x, y)
```

### Using SciPy for image processing

Now we will show you how to transform and process an image using SciPy. The most important part of the code is following line:

```python
from scipy.stats import poisson, lognorm
from PIL import Image

image = np.array(Image.open('sample.png').convert('L'))
``` This allows you to use a PNG file and convert it into a NumPy array. The program will also separate the output to four parts and display a different image for each of these four parts. The variable that holds the polynomial is poly. The values that were plotted for x will be using `x=np.linspace(-5,5,100)`. The other important variable is y, which calculates and holds the values of $f(x)$ for each value. It is important that you start plotting using the "plot" parameters in order to see the output on your screen. If you are interested in plotting polynomials, you should know that NumPy can also calculate the derivatives and plot multiple functions in the same output.

## Work with Python

![](img/c72194f2c3aec198936695a665a5167c_62_0.png)

```python
np.loadtxt("timeN.txt", usecols=(0,1), unpack=True)
```

The aforementioned command saves column 1 into variable aa1, column 2 into aa2. The `unpack=True` allows the data to be assigned to two different variables. Please note that the number of columns starts with 0.

The Python script uses a fifth polynomial, but if you want to use a different degree instead then you have to change the following line:

```python
coefficients = np.polyfit(aa1, aa2, 5)
```

Put simply, array broadcasting has a rule in order for two arrays to be considered for array broadcasting, "the size of the trailing axes for both arrays in an operation must either be the same-size or one of them must be."
