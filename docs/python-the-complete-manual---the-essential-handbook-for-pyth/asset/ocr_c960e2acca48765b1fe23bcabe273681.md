# Input validation with Loops and If statements

+   To demonstrate a loop and if statements, we will output a question to the user that requires a yes or no answer. We're going to ask them if they want to continue - and we require a lower-case Yes, or a lower-case no. A loop runs until a condition is met. In this case, we will create a variable yesOrNo and the loop will run while yesOrNo is False. The yesOrNo variable will be a Boolean type with a value, or the loop will not run.

A loop has the format "if condition:" – any code that is part of the loop needs to be indented in the lines below the colors. Any code that is not indented will not be part of the loop. This is the same for an if statement. The condition is checked with the comparison operator ==. A single ==" is an assignment operator while a double is a comparison operator. Another comparison operator is !==" – which means ‘not equal to’. We create a variable ‘result’, which holds the value of the question, do you want to continue? Then we check if result is valid with an if statement. Notice the '!=' operator which allows two conditions to be tested if the user inputs yesOrNo to True, which stops the loop on the next run. Otherwise, we output an error message and the loop will run again. The user can use the Ctrl+C command to exit the terminal at any time.
