# Pivadars Pt 2:
graphics & sound

This time we will expand our Space Invaders clone to include immersive animation and sound

We had fun creating our basic Space Invaders clone, Pivadars, in the previous guide. Pygame's ability to group, manage and detect collisions thanks to the Sprite class made a great difference to our project, not just in terms of code length, but if you missed the first part of the project, you can find the v0.1 code listing on GitHub via git.io/CBVTBg, while you can find version v0.2 of the code, including all the images, music and sound effects we've used at git.io/8Qs2k-w.

To help you keep your project manageable and straightforward (as your projects keep your code easy to follow increasingly hardly) we integrated a few animation methods into our Game class and opted to use a sprite sheet. Not only does it make it very easy to draw the screen, but it also keeps the asset counter under and keeps performance levels up, which is especially important for Raspberry Pi. We hope you have fun using our techniques to add animation and sound to your projects!
