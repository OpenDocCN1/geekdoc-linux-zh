# Installing SIGAR

The first step is to build and install SIGAR. SIGAR is
host at GitHub, so make sure you have Git
installed in your system. Then perform the following
steps to install SIGAR and its Python bindings.

```
$ clone git://github.com/hyperic/
sigar.sigar.git
$ cd sigar.git/bindings/python
$ sudo python setup.py install
```
