# Table 2-4 Standard Header Files in C

| File | Purpose |
| <assert.h> | Defines the assert macro. Used for program diagnostics. |
| <ctype.h> | Defines macros for classifying and converting characters. |
| <errno.h> | Defines macros for error conditions, EDOM and ERANGE, and the integer variable errno library functions return an error code. |
| <float.h> | Defines a range of values that can be stored in floating-point types. |
| <iso646.h> | Defines a number of macros that are helpful when writing C programs in non-English languages that may use character combinations such as & and for other purposes. |
| <limits.h> | Defines the limits of all data types. |
| <locale.h> | Declares the struct and the functions necessary for customizing a C program to a particular locale. |
| <math.h> | Defines common mathematical functions and the HUGE_macro. |
| <setjmp.h> | Defines the setjmp and longjmp functions that transfer control from one function to another without relying on memory calls and returns. Also defines the jmp_buf data type used by setjmp and longjmp. |
| <signal.h> | Defines symbols and routines for handling exceptions. |
| <stdarg.h> | Defines macros that provide access to the unnamed arguments in a function that accepts a varying number of arguments. |
| <stddef.h> | Defines standard data types ptrdiff_t, size_t, char_t; the symbol NULL; and the macro offset. |
| <stdio.h> | Declares the functions and data types necessary for input and output operations. Defines macros as BUFSSIZ, EOF, SEEK_CUR, SEEK_END, and SEEK_SET. |
| <stdlib.h> | Declares many utility functions, such as the string conversion routines, random number generator, memory allocation routines, and process control routines (such as abort, exit, and system).
