> TIP

When properly installed, the Linux kernel loads the driver for the Ethernet card every time it boots. To verify that the Ethernet driver is loaded, type the following command in a terminal window:

```
dmesg | grep eth0 /etc/modprobe.conf | cut -d ' ' -f 3
```

This command searches the messages for any line that contains the name of the Ethernet card (in backquotes — 'grep eth0 /etc/modprobe.conf | cut -d ' ' -f 3' picks out the alias for eth0 device from the /etc/modprobe.conf file). The A 2 option for grep causes it to print two lines for the line that matches the search criteria.

On my PC, I have a 3Com PCI 3c905 Ethernet card installed, so I get the following output when I type command on my system:

```
3cx59: Donald Becker and others,, www.scylid.com/network/vortex.html
0000:02:01:0:3Com PCI 3c905 Tornado at 0x3000. Vers LKI.1.1
divert: allocating divert_blk for eth0
```

You see something similar, showing the name of the Ethernet card and related information.
