# Rebuilding the Kernel

Rebuilding the kernel refers to creating a new binary file for the core operating system. This binary file is the one that runs when Fedora boots. You may wonder why you ever want to rebuild the kernel. Well, here are a few reasons:

+   * After you initially install Linux, you may want to create a new kernel that includes support only for the hardware installed on your system. particular, if you links to a SCI adapter, you may want to create a kernel that works in the SCI driver. The kernel on the companion DVD-ROM includes the SCI driver as an external module that the kernel loads at startup.

+   * If you have a system with hardware for which only experimental support is available, you will have to rebuild the kernel to support the operating system.

+   * You may want to recompile the kernel and generate code that works well on your specific Pentium processor (instead of the generic 386 processor code that comes in the standard Fedora Core distribution).

To rebuild the kernel, you need the kernel source files. The kernel source files are not normally installed. Use the following steps to install the kernel source files on your system:

+   1. Log in as root and insert the Fedora Core DVD-ROM into the drive.

+   2. If the DVD-ROM does not mount automatically, type the following command to mount the DVD-ROM:

```
mount /mnt/cdrom
```

If you're using GNOME or KDE, the DVD-ROM automatically mounts, and you do not have to perform this step manually.

+   3. Change the directory to the Fedora/RPMS directory on the DVD-ROM, and use the rpm command to install the kernel source files. Type the following commands:

```
cd /mnt/cdrom/Fedora/RPMS
rpm -ivh kernel-source*
```

After the rpm command finishes installing the kernel source package, the source files appear in the /usr/src/linux-VERSION directory, where VERSION is the version number of the kernel. Thus, for kernel version 2.6.3-1.240, the source files are in the /usr/src/linux-2.6.3-2.1240 directory.
