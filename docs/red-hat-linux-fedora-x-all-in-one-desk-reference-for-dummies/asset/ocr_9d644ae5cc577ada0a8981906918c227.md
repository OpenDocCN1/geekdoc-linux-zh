# Text Editing with ed and vi 205

To start the editor, type vi and follow it with the name of the file you want to
edit, like this:

vi /etc/fstab

The vi editor loads the file into memory and displays the first few lines
in a text screen and positions the cursor on the first line (see Figure 5-2).

| LABEL/ /boot defaults 1 1 |
| LABEL/boot ext4 defaults 1 2 |
| none /dev/pts devpts gid=5,node=20 0 0 |
| none /proc proc defaults 0 0 |
| none /dev/shm tmpfs defaults 0 0 |
| /dev/sda swap defaults 0 0 |
| 0 0 /mnt/cdrom udf,iso9660 nosuso,owner,kudzu,r |
| /dev/fd0 /mnt/floppy auto nosuso,owner,kudzu 0 0 |
| | /etc/fstab [readonly] 621C | 1.1 All |

The last line shows the pathname of the file as well as the number of lines
(8) and the number of characters (621) in the file. In this case, the text
[readonly] appears as the filename because I am opening the /etc/
fstab file while I am logged in as a normal user (which means I don't
permission to modify the file). Later, the last line in the vi display functions
as a command-entry area. The rest of the lines display the file. If the con
fewer lines than the screen, vi displays the empty lines with a tilde ()
in the first column.

The current line is marked by the cursor, which appears as a small black rectangle. The cursor appears on top of a character.

When you vi, you work in one of three modes:

+   * Visual command mode is what you get by default. In this mode, anything
that you type is interpreted as a command that applies to the line containing
t cursor. The vi commands are similar to the ed commands.
