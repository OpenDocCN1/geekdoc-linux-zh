# Predefined variables in Perl

Perl has several predefined variables that contain useful information you may need in a Perl script. Following are a few predefined variables:

+   * ARGV is an array of strings that contains the command-line options to the script. The first one is $ARG[0], the second one is $ARG[1], and so on.

+   * $ENV is an associative array that contains the environment variables. You can access this array using the environment variable name as a key. Thus $ENV(HOME) is the home directory, and $ENV(PATH) is the current path that the shell uses to locate commands.

+   * _ is the default argument for many functions. If you see a Perl function used without argument, the function probably is expecting its argument to be contained in the _ variable.

+   * @_ is the list of arguments passed to a subroutine.

+   * $0 is the name of the file containing the Perl program.

+   * ^V is the version number of Perl you are using (for example, if you are Perl Version 5.8.3, ^V is v5.8.3).

+   * $<$ is the user ID (identifying number) of the user running the script.

+   * $ is the status of the system call has returned.

# Operators and expressions

Operators are used to combine and compare Perl variables. Typical operators are addition (+), subtraction (-), multiplication (*), and division (/). Perl and C provide nearly the same set of operators. When you use operators to combine variables, you end up with expressions. Each expression has a value.

Here are some typical Perl expressions:

```
error < 0
$count == 10
$count + $i
$users[$i]
```

These expressions are examples of the comparison operator (the first lines), the arithmetic operator, and the array-index operator.
