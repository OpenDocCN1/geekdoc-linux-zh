# Setting Up Printers

+   2. From the GNOME or KDE desktop, choose Main Menu
System Settings: Printing.

+   3. Click the New button to configure a new printer.

The Fedora Core’s Printer Configuration Wizard starts. The initial window displays a message that assures you nothing changes until you click the Apply button at the end of all steps. Click Forward to continue.

+   4. In the next screen (see Figure 3-2), enter the name for the print queue and a short description of the print queue; then click forward.

Use some systematic approach when naming the print queue. For example, if I have a HP LaserJet 5000 on the second floor in Room 210, I might name the queue Room210HPLJ5000 because this name makes finding the printer easier. Sometimes administrators choose cute names like kermit, piggy, elmo, cookiemonster, and so on, after you have too many printers, such scheme don't work well. Providing a clue about the printer's location as well as the model in the print queue's name is best.
