# 236 Preparing Documents in Writer

| Table 1-8 | Common Tasks Related to Large Documents |
| --- | --- |
| To Do | Follow These Steps |
| Create a master document | Create a new file using a template you want. Then choose File::Send::Create Master Document. Assign a name, select a directory, and save the file. The Navigator window appears, from which you can select files to insert into the master document. |
| Insert into the master document | Use the Navigator to insert a file or choose Insert::File. |
| Insert index entries | Select the text you want to insert in the index. Then choose Insert::Indexes and Tables::Indexes and Tables. |
| Create a table of contents, list of figures, or an index | Choose Insert::Indexes and Tables::Indexes and Tables. Click the Index/Table tab and select the type of table. For a table of contents, select Table of Contents as the type. To select the paragraph styles to include in the table, select the Additional Styles box and then click the adjacent button to designate styles you want to include in the table. |
| Update a table of contents or index | Right-click the table and then select Index/Table. |
| Insert footnotes and endnotes | Choose Insert::Footnote, select your options, and then click OK. Then type the footnote text. |
| Create a bibliographic database | Choose Tools::Bibliography Database. Then fill in the bibliographic information in the Bibliography Database window. |
| Insert bibliographic references to the text | Choose Insert::Indexes and Tables::Bibliographic Entry and pick the entry to insert. |
