/dev/sda 31520 64 31456 1%/mnt/flash
If you don't have any USB device plugged in, the device name is /dev/sda (USB storage devices appear as SCSI devices). The next USB storage devices gets the /dev/sda2 device name and so.

Now you can access the files on the keychain at the /mnt/flash directory. To save a file to the USB keychain storage device, use a command of the following:
cp filename /mnt/flash

where filename is the name of the file you want to save.

When you're using the device, unmount the USB keychain with this command:
umount /dev/sda

# Spool and print jobs

Spooling refers to the capability to print in the background. When you print from a word processor in Windows, for example, the output first goes to a disk. Then, while you continue working with the word processor, a background process sends that output to the printer. The Fedora Core environment also supports spooling.
