The four tabs are as follows:

+   * **Normal:** This shows the Web page in nearly complete layout, also lets you edit the page. You typically do most of your editing and formatting in this view.

+   * **HTML Tags:** This shows the Web page with the HTML tags as small icons. You can quickly check what HTML tags are affecting which parts of the document and, perhaps fix any formatting problems.

+   * **<HTML> Source:** This shows you the Web page in its full glory. If you use WordPerfect, this view is like WordPerfect's Reveal Codes option. If something weird happens to the Web page layout—you'll need to switch to view, find the offending code, and fix it. Of course, you have to know how HTML, but don't worry—it picks it up if you start working with Web pages. You can also use this view to write the Web page directly in HTML and go to Normal or Preview views to check out.

+   * **Preview:** This view essentially shows what the Web page looks in Mozilla Navigator. Preview is a quick way to check the final layout without having to open the file in a Navigator window. You cannot edit the page in this view.
