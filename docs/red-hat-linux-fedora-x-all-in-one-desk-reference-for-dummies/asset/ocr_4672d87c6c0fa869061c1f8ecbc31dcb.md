The window on the right now shows the contents of the /etc/X11 directory.

Nautilus displays the contents of the selected directory using different types of icons. Each directory appears as a folder, with the name of the directory underneath the folder icon. Ordinary files, such as xorg.conf, appear as a sheet of paper. The X file is a link to an executable file. The predf file is another executable file.

The Nautilus navigation window has the usual menu bar and toolbar. Notice the View as Icons button in Figure 1-10 on the right side of the toolbar. This shows Nautilus is displaying the directory contents using large icons. Click, and a drop-down list appears. Select View as List; Nautilus displays the contents by smaller icons in a list format, with detailed information, as the size of each file and the time each was modified, as shown in Figure 1-11.
