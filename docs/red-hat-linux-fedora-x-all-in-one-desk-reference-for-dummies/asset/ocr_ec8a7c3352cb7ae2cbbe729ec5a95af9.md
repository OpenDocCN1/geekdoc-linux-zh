# # Surfing the Net with Mozilla

Where you go on the Mozilla home page depends on you. All you have to do is click and see where you end up. Move your mouse. You know when you are on a link because the mouse pointer changes to a hand with an extended index finger. Click the link, and Mozilla downloads the Web page referenced by that link.

How you use the Web depends on what you want to do. When you first get started, you may explore a lot — browsing through Web sites and following links without any specific goal in mind; what you may call window-shopping.

The other, more purposeful, use of the Web is to find specific information from the Net. For example, you might want to locate all the Web sites that contain documents with a specified keyword. For such searches, you can use one of many Web search tools available on the Net. Mozilla's Search button takes you to the Google Web search page.

A third type of use is a visit to a specific site with a known URL. When reading about a specific topic in this book, you may come across a specific URL. In that case, you want to go directly to that page.

If you want to surf the Net with Mozilla, all you need is a starting Web Page — then you can click whatever catches your fancy. For example, select the text in the Location box in Mozilla's Navigation toolbar, **type.yahoo.com**, and press Enter. You get to the Yahoo home page that shows Yahoo's Web directory — organized by subject. That's your starting point. All you have to do is click and you're on your way!
