## Doing an FTP Install

If you want to install Fedora Core on a laptop or desktop that has no CD drive, you can do an FTP installation from another system that has Fedora Core distribution files. Even if you have a CD drive, FTP installation makes sense if you are installing Fedora Core on PCs in a network and don't want to go around each PC. This project walks you through an FTP install.

### Things you need

Here's what you need to burn Fedora Core CDs:

- A boot CD to boot the PC. The Fedora Core installation kernel is too big to fit on a floppy, so you can only boot from a CD.
- A local network with another Linux system with the Fedora Core ISO files.
- A network-connected PC which you want to install via FTP.

### Steps to follow

Follow these steps to do an FTP install from Fedora Core ISO files for the network:

- 1. On the Linux system where you have Fedora Core ISO files, mount four ISO files on mount points. Assume the four ISO files are in /tmp and are named disc1.iso, disc2.iso, disc3.iso, and disc4.iso. Log as root and use the following commands in a terminal:

```
mkdir /tmp/pub/fedora
cd /tmp/pub/fedora
mkdir disc1
mkdir disc2
mkdir disc3
mkdir disc4
mount -o loop.ro /tmp/disc1.iso disc1
mount -o loop.ro /tmp/disc2.iso disc2
mount -o loop.ro /tmp/disc3.iso disc3
mount -o loop.ro /tmp/disc4.iso disc4
```

- 2. Make sure the FTP server is running on the Linux system where you mounted Fedora Core ISO files. Typing the following command:

```
service vsftpd restart
```

- 3. Create a Fedora Core boot CD. Use a CD to burn the ISO image named boot.iso located in the images directory. See "Burning Fedora Core CDs" for instructions on how to burn a CD.

- 4. Go to the PC on which you want to do the FTP install, insert the boot CD, and restart the PC. The PC reboots and after a few moments, a text screen displays a welcome message and a boot prompt.

- 5. Type linux and press Enter. A text menu displays various installation methods.

- 6. Select FTP as the installation method and press Enter. You are prompted to configure TCP/IP network for the PC.

- 7. Select Dynamic IP and select OK. If your network does not support dynamic IP addresses, enter a valid IP address for the PC. The FTP setup screen appears after you configure the TCP/IP.

- 8. Enter the IP address or the name of the FTP server where Fedora Core ISO files are mounted. For an Internet-connected PC, you can specify any server on the Internet that has the Fedora Core distribution available. For a list of such servers, consult fedora.redhat.com/download/mirrors.html.

- 9. Specify the directory where the ISO files are located and press OK. For the example in Step 1, enter /tmp/pub/fedora as the directory. The graphical installation begins after this step.

- 10. Respond to the prompts from the graphical installation and proceed with the installation as usual.

Fedora Core comes with two graphical user interfaces (GUIs)—GNOME and KDE—are similar to Microsoft Windows, but they are unique in one respect. Unlike Microsoft Windows, you can pick your GUI in Fedora Core. If you don't like GNOME, just log out and log back in Fedora Core with the other, KDE. Try doing that with Microsoft!

GNOME and KDE were developed independently of Linux. In fact, GNOME and KDE run on other UNIX systems besides Linux. You also have the option to install other GUIs on Fedora Core. For example, you can download and install Ximian Desktop 2 (XD2)—a GUI desktop from Ximian, available from www.ximian.com/products/desktop/download.html.

This chapter explores the major features of GNOME and KDE. You can best learn these GUIs by simply starting to use them. By doing them, you can try both GNOME and KDE, provided you installed both when you installed Fedora Core. Otherwise, KDE is the default GUI in Fedora Core.
