# Defining a table

To create a table books, I edited a text file named makedb.sql and placed the following line in that file:

```sql
/*
* Table structure for table 'books'
*/
CREATE TABLE books (
  isbn CHAR(10) NOT NULL PRIMARY KEY,
  title CHAR(80),
  author1 CHAR(20),
  author2 CHAR(20),
  pubname CHAR(30),
  pubyear INT,
  pagecount INT
);
```

CREATE TABLE books is an SQL statement to create the table named books. The @ at the end of the statement is a psql command. The attributes of the table appear in the lines enclosed in parentheses.

If a table contains fixed data, you can also include other SQL statements (such as INSERT INTO) to load the data into the table right after the table is created.

To execute the SQL statements in the makedb.sql file that creates the books table, I run psql as follows:

```
psql books < makedb.sql
```

Now the books database includes a table named books. (Okay, maybe I should have named them differently, but calling them by the same name seemed convenient.) I can now be loading data into the table.

# Inserting records into a table

One way to load data into the table is to prepare SQL statements in another file and then run psql with that file as input. For example, suppose I want to add the following book information into the books table:

```
isbn = '0765441331'
title = 'Red Hat Linux 9 Professional Secrets'
author1 = 'Naba Barkakati'
author2 = NULL
pubname = 'Wiley Publishing, Inc.'
pubyear = 2003
pagecount = 1070
```

Then, the following SQL statement loads this information into the books table:

```sql
INSERT INTO books VALUES
('0765441331', 'Red Hat Linux 9 Professional Secrets',
'Naba Barkakati', NULL,
'Wiley Publishing, Inc.', 2003, 1070); \g
```

On the other hand, suppose the various fields available in a different order (the order in which the table's attributes are defined by the CREATE TABLE statement). In that case, you can use a different form of the INSERT INTO command to add the row, as shown in the following example:

```sql
INSERT INTO books (pubyear, author1, author2, title)
(1996, 'Naba Barkakati', NULL, 'Linux SECRETS', 900, 'IDG Books Worldwide', '1568798X'); \g
```

Essentially, you have to list the attributes as well as the values and make sure that the order of the attributes matches those of the values.

If I save all INSERT commands in a file named additems.sql, I can load the database from the psql command line by using the \i command like this type (type psql books to start the PostgreSQL client):

```
books=> \i additems.sql
```

# Multimedia Applications

Fedora Core includes quite few multimedia applications — mostly multimedia audio players and CD players, but also applications for digital cameras and burning CD-ROMs. To play some other multimedia files (such as MPEG video), you have to download and install additional software in your Fedora Core system. Here's a sketch of a few typical multimedia tasks and the applications you can use to perform these tasks:

- **Using digital cameras:** Use the Digital Camera tool to download photos from your digital cameras in Fedora Core.
- **Playing audio CDs:** Use one of many audio CDs that can play with Fedora Core.
- **Playing sounds files:** Use Rhythmbox or XMMS, multimedia audio players (you have to download some additional software to play MP3 files with Rhythmbox or XMMS). You can also download other players from the Internet.
- **Burning a CD:** Use X-CDast to roast your CDs.

# Using a digital camera

Fedora comes with gtcam — a digital-camera application you can use to download photos from digital cameras. gtcam is a GUI front end of the gPhoto2 command-line application that works with many different makes and models of digital cameras. Depending on the model, the cameras can connect to the serial port or the Universal Serial Bus (USB) port. Visit the

To use gtcam with your digital camera, follow these steps:

1. Connect your digital camera to the serial port or USB port (whichever interface the camera supports) and turn the camera on.
2. Choose Main Menu: Graphics:Digital Camera Tool to start gtcam.
3. From the gtcam menu, choose Camera:Add Camera.
4. In the dialog box that appears, click Detect.

If your camera is supported, the camera is detected. If not, you can try an alternate method that I'll describe at the end of these steps. 
gtcam displays a camera icon and the camera name on the left panel.

5. Double-click the camera icon to download and view thumbnail pictures in the right panel.
6. Click the thumbnails to select the images you want to download; then choose File:Save or click the Save button on the toolbar.

gtcam downloads the images and places each image in a separate file in your home directory. You can now edit the photos in the GIMP or your favorite photo editor.

> Don't despair if gtcam does not recognize your digital camera. You can still access the camera's storage media (compact flash, for example) as a USB mass storage device, provided your camera supports USB Mass Storage. To access the images on your USB digital camera, follow these steps:

![](img/d9230b719dc0efd80851f363d8c6f571_210_0.png)

1. Read the camera manual and use the menu options of the camera to set the USB mass to Mass Storage.

If the camera does not support USB Mass Storage, you cannot use this procedure to access the photos.

2. Connect your digital camera to the USB port using the cable that came with the camera and turn the camera on.

3. Mount the camera's storage media by typing the following command:

```
mount /mnt/camera
```

A camera icon appears on the GNOME desktop.

5. Double-click the camera icon on the GNOME desktop.

The camera's contents appear in Nautilus file manager. You can double-click the folders and find the one that contains the photos. Typically, these digital photos are JPEG files with cryptic filenames that carry the .jpg extension. In the default view, Nautilus displays thumbnails of the photos, so you don't have to worry about the cryptic filenames.

6. Click to select the photos and copy them to your hard disk.

You can also use the cp command in a terminal to copy all or some images to a directory on your hard disk. For example, to copy all JPEG photos to the current directory, type

```
cp /camera/*.jpg
```
