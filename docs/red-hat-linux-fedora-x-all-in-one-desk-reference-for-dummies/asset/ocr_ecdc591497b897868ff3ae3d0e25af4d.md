# 426 Adding User Accounts

# ## Using the User Manager to add user accounts

You can use the User Manager to add user accounts, log in as *root* at the graphical login screen and then choose Menu>Settings> Users and Groups from the GNOME panel. If you're not logged in as root, the User Manager prompts you for the *root* password. If prompted, enter the password and click OK. The User Manager window appears.

The window has two tabs: Users and Groups (as shown in Figure 2-1). The Users tab displays the current list of names from the /etc/passwd file. The Groups tab lists the names of groups from the /etc/group. However, you can turn off the filter by choosing Preferences>Filter System Users and Groups, so that the check mark next to that menu then disappears. Figure 2-1 shows the User Manager window with a list of all user accounts, including the systems.

You can manage accounts and groups from the User Manager window.

You can add new users and groups or edit existing users and groups from the User Manager window.

To edit the information for an existing user, follow these steps:

+   1. Click the user in the list on the Users tab and then click the Properties button on the toolbar.

That's information appears in a User Properties dialog box (see Figure 2-2).

+   2. Edit the information and click OK to make the changes.
