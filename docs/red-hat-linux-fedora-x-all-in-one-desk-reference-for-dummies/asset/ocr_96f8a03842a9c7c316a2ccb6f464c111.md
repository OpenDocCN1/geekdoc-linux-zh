# Exploring GUI Desktops

Fedora Core comes with two GUI desktops — GNOME and KDE. If you installed both, you can try them out one by one. Selecting one of these desktops just before you log in to the system is — and here is where I will show you.

GNOME is typically the default GUI in Fedora Core, so you can start with GNOME. Then log out and back in, but select KDE as the GUI. That way, you can try out both desktops.

# GNOME

GNOME stands for GNU Network Object Model Environment (and GNU, so you probably know, stands for GNU's Not UNIX). GNOME is a graphical user interface (GUI) and a programming environment. From the user's perspective, GNOME is Microsoft Windows. Behind the scenes, GNOME has many features that allow programmers to write graphical applications that can work together well. In this chapter, I point out some key features of the GNOME GUI, leaving the details to you to explore on your own at your leisure.

If you're curious, you can always find out the latest information about GNOME by visiting the GNOME home page at www.gnome.org.

Typically, GNOME is the default desktop in Fedora Core. After you log in, you see the GNOME GUI desktop. Figure 4-6 shows the GNOME desktop for user-emily.

When you log in root, you can accidentally damage your system because you can do anything when you're root. Always log in as a normal user.

The exact appearance of the GNOME desktop depends on the current session (set of applications running at that time). As you can see, the initial GNOME desktop, shown in Figure 4-6, is very similar to the Windows desktop. It has the GNOME panel, or simply the panel (similar to the Windows taskbar) along the bottom and icons for folders and applications appear directly on the desktop. You can place icons directly on the Windows desktop in a similar way.
