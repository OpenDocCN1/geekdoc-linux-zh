# Compiling C++ programs

GNU CC is a combined C and C++ compiler, so the gcc command can also compile C++ source files. GCC uses the file extension to determine whether a file is C or C++. C files have a lowercase .c extension, whereas C++ files end with .C or .cpp.

Although the gcc command can compile a C++ file, that command does not automatically link with various class libraries that C++ programs typically require. That's why compiling and linking a C++ program using the g++ command is easy, which in turn, runs gcc with appropriate options.

![](bbox=[0.14, 0.333, 0.212, 0.396])

Suppose you want to compile the following C++ program stored in a file named hello.C (using an uppercase C for C++ source files is customary):

```
#include <iostream>
int main()
{
    using namespace std;
    cout << "Hello from Fedora Core!" << endl;
}
```

To compile and link this program into an executable program named hello, use this command:

```
g++ -o hello hello.C
```

The command creates the hello executable, which you can run as follows:

```
./hello
```

The program displays the following output:

Hello from Fedora Core!

A host of GCC options controls various aspects of compiling C and C++ programs.
