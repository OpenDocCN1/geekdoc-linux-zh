- Indexes enables clients to request indexes (directory listings)
- IncludesNOEXEC disables the #exec command in server-side.
- AllowOverride directive1 directive2 . . . : Specifies which access-control directives can be overridden on a per-directory basis. The list can contain one or more of the following:
  - None stops any directive from being overridden.
  - All enables overiding of any directive on a per-directory basis.
  - Options enables the use of the Options directive in the directory-level file.
  - FileInfo enables the use of directives controlling document type, such as AddType and AddEncoding.
- AuthConfig enables the use of authorization directives, such as AuthName, AuthType, AuthUserFile, and AuthGroup.
- Limit enables the use of Limit directives (allow, deny, order) in a directory's access-configuration file.

+   - AuthName name: Specifies the authorization name for a directory.
- AuthType type: Specifies the type of authorization to be used. The only supported authorization type is Basic.
- AuthUserFile filename: Specifies the file in which users and passwords are stored for authorization. For example, the following sets the authorization file to /etc/httpd/conf/

```
AuthUserFile /etc/httpd/conf/password
```

You have to create the authorization file with the /usr/bin/htpasswd support program. To create the authorization file and add the password for a user named jdoe, specify the following:

```
/usr/bin/htpasswd -c /etc/httpd/conf/password jdoe
```

When prompted for the password, enter the password and confirm it by typing it again.

+   - AuthGroup filename: Specifies the file to contain for a list of groups for authentication.
