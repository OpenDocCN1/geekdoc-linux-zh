# 768 Trying Out Simple Shell Scripts

These commands assume that the xwdtopnm and pnmtiff programs are in the /usr/bin directory — one of the directories listed in the PATH environment variable. By the way, xwdtopnm and pnmtiff are two programs in the PBM toolkit.

After converting a few XWD files to TIFF format, I tired of typing the sequence of commands for each file, so I prepare a file named totif and save the following lines in:

```
#!/bin/sh
xwdtopnm < $1.xwd > $1.pnm
pnmtiff < $1.pnm > $1.tif
rm $1.pnm
```

Then I make the file executable by using this command:

```
chmod +x totif
```

The chmod command enables you to change the permission settings of a file. One of those settings determines whether the file is executable. The +x option means you want to mark the file as executable. You have to mark it that because Bash runs only executable files.

When I want to convert the file figure.xwd to figure.tif, I can do so by typing the following command:

```
./totif figure
```

The ./ indicates that the totif file is in the current directory — you don't need the ./ prefix in the PATH environment variable includes the current directory. The totif is a shell script (also called a shell program). When you run this script with the command totif figure, the shell substitutes figure for each occurrence of $1 (note that $1 refers to the first option that the user types on the command used to execute the script).

Shell scripts are popular among system administrators. If you are system administrator, you can build a collection of custom shell scripts that help you automate tasks you perform often. If a disk seems to be getting full, you may find files that exceed some size (say, 1MB) and have not been accessed in the past 30 days. In addition, you may want to send an e-mail to all users who have large files, requesting that they archive and clean up these files. You can perform all these tasks with a shell script. You might start with the following find command to identify large files:

```
find -type f -atime +30 -size +1000k -exec ls -l \; \ > /tmp/largefiles
```
