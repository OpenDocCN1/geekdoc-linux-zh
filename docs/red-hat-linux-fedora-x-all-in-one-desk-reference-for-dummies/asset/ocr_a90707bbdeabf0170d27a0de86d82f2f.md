Fedora Core comes with two graphical user interfaces (GUIs) — GNOME and KDE are similar to Microsoft Windows, but they are unique in one respect. Unlike Microsoft Windows, you can pick your GUI in Fedora Core. If you don't like GNOME, just log out and log back in Fedora Core, the other KDE. Try doing that with Microsoft!

GNOME and KDE were developed independent of Linux. In fact, GNOME and KDE run on other UNIX systems besides Linux. You also have the option to install other GUIs on Fedora Core. For example, you can download and install Ximian Desktop 2 (XD2) — a GUI desktop from Ximian, available from www.ximian.com/products/desktop/download.html.

This chapter explores the major features of GNOME and KDE. You can best learn these GUIs by simply starting to use them. By them, you can try both GNOME and KDE, provided you installed both when you installed Fedora Core. Otherwise, KDE is the default GUI in Fedora Core.

# Learning the Common Features of the GUIs

From your perspective as a user, both GNOME and KDE probably seem similar because many features work similarly. Becoming familiar with these common features is helpful so you can rely on them no matter which GUI you choose to use for your daily work.
