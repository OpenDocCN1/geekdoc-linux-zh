Now that you know the layout of the `/etc/news/newsfeeds` file, you can study this file as an example. The default file contains many sample feed entries, but only two are commented out:

+   * ME is a special feed entry that is always required. First, the newsgroup patterns listed in this entry are prepended to all newsgroup patterns in all other entries. The ME-distribution list determines which distributions your server accepts from remote sites.

+   * The *controlchan* feed entry is used to set up INN so an external program is used to handle control messages (these messages are used to create new newsgroups and remove groups). For example, the following `controlchan` specifies the external program `/usr/lib/news/bin/controlchan` to handle all control messages, except *cancel* messages (for canceling an article):

```
controlchan!
:*.control,control_!*,!*.cancel\
!:tc.Fwnsm:/usr/lib/news/bin/controlchan
```

In addition to these feed entries, you add entries for any actual sites to your server provides news feeds. Such entries have the format

```
feedme.domain.com\
!:junk,!control/!foo\
!:im:infeed!
```

where *feedme.domain.com* is the fully qualified domain name of the site to which your system sends news articles.
