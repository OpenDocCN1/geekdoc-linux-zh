All these devices are already in your Fedora Core system. In a terminal window, type **ls -l /dev/ttyS*** ** to see a listing of these device files.

The device name is different if your modem connects to a USB port or if you have a modem. For winmodems, you have to first download and install a driver. You can locate Linux drivers for many winmodems by checking the www.linmodems.org Web site. In many cases, Linux modem drivers set up the modem device /dev/modem as a symbolic link to the actual device file. For example, the Conexant HSF driver sets up /dev/modem as a symbolic link to /dev/ttySHSF0, which is the actual device name for softmodem. Because of the symbolic link, I can refer to the modem by the generic /dev/modem instead of the somewhat complicated device names.

# Checking if the Linux kernel detected the serial port

To verify that the Linux kernel detects the serial port correctly, check the boot messages with the following command:

```
dmesg | grep ttyS
```

If you see a message like the following, Linux detects a serial port in your PC:

```
ttyS0 0x03f8 (irq = 4) is a 16550A
```

In this case, the message indicates that the Linux kernel has detected the first serial port (COM1). It shows the I/O address (in hexadecimal), 0x3f8 and IRQ 4. The part of the message — 16550A — refers to the identifying number of the *asynchronous receiver/transmitter* (UART) chip, which is the heart of all serial communications hardware (the UART converts each byte to a stream of 0s and 1s, and vice versa when it receives such a stream).

Of course, if you have a softmod installed you may see something similar to the following in **dmesg | grep ttyS**:

```
ttySHSF0 at I/O 0x2400 (irq = 10) is a Conexant HSF modem
```

You can also check for the serial ports with the **setserial** command. Type the following command to see detailed information about the serial ports:

```
setserial -g /dev/ttyS?
```

Any serial device listed in the output of this command with an unknown UART is either not installed or not detected by the Linux kernel. For softmodems, you don't see a UART listed for softmodems the UART functionality is performed in software.
