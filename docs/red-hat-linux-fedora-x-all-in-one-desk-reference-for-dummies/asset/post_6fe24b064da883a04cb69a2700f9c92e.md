The unsigned qualifier is reserved for int and char types only. Normally, each of these types holds negative as well as positive values. This qualifier differs the signed form of these data types. You can use the unsigned qualifier when you want the variable to hold positive values only. Here are some examples of using the short, long, and unsigned qualifiers:

```
unsigned char char_select, printer_status;

unsigned i; /* Same as "unsigned int" */

long file_pos; /* Same as "unsigned long int" */
double result;
```

When the short, long, and unsigned qualifiers are used with int types, you can drop the int from the declaration. You can also extend the double type with a long prefix.

## Enumerations

You can use the enum data type to define your enumerated list — a fixed set of integer constants. For example, you can declare a Boolean data type using enum as follows:

```
/* Declare enum type named BOOLEAN */
enum BOOLEAN (false = 0, true = 1, stop = 0, go = 1,
offff = 0, on = 1);
```

```
/* Define a boolean called "status" and initialize it */
enum BOOLEAN status = stop;
```

This example declares BOOLEAN to be an enumerated type. The list within the braces shows the enumeration constants that are valid values of an enum BOOLEAN variable. You can initialize each to a value of your choice, and several constants can use the same value. In this example, the constants false, stop, and off are set to 0, while true, go, and on are initialized to 1. The example then defines an enumerated BOOLEAN variable named status, which is initially set to the constant stop.

## Structures, Unions, and Bit Fields

### Structures, Unions, and Bit Fields

Use struct to group related items, and refer to that group by a name. For example, the declaration of a structure to hold variables of a queue may look like this:

```
/* Declare a structure */
struct QUEUE {
    int count;      /* Number of items in queue */
    int front;      /* Index of first item in queue */
    int rear;       /* Index of last item in queue */
    int elemsize;   /* Size of each element */
    int maxsize;    /* Maximum capacity */
    char *data;     /* Pointer to data */
}
```

```
/* Define two queues */
struct QUEUE rcv_q, xmit_q;
```

The elements inside QUEUE are its members. You can access these members using the member selector (.). For instance, rcv_q.count refers to the count of rcv_q.

union is like a struct, but instead of grouping related data (as struct does), it allocates storage for several data at the same location. Thus, all members of a union share the same location. You can use unions to view the same data in different ways. Suppose you are using a compiler that supports 4-byte long numbers, and you want to access the individual bytes of a single integer. Here is a union that lets you accomplish this:

```
union {
    long file_type;
    char bytes[4];
} header_id;
```

With this definition, header_id.file_type refers to the long integer, while header_id.bytes[0] is the first byte of that long.

## Arrays

An array is a collection of one or more identical data items. You can declare arrays of any type of data including structures defined by typedef. For example, to define an array of 80 characters, you write:

```
char string[80];
```

The characters in the array occupy successive locations, beginning with 0. Thus in this example, string[0] refers to the first character in the array, while string[79] refers to the last one. You can define arrays of other data types similarly:

```
struct Customer { /* Declare a structure */
    int id;
    char first_name[40];
    char last_name[40];
} customers[100]; /* Define array of structures */
int index[64]; /* An array of integers */
```

You can define multidimensional arrays. For example, to represent an 80-column-by-25-line text-screen, you can use a two-dimensional array as:

```
char text_screen[25][80];
```

Each item of text_screen is an array of 80 chars, and text_screen contains 25 arrays. In other words, the two-dimensional array is stored by laying out row after another in memory. You can use expressions such as text_screen[0][0] to refer to the first character in the first row and text_screen[24][79] to refer to the last character of the last row. Higher-dimensional arrays are defined similarly:

```
float coords[3][2][25];
```

This example defines coords as a three-dimensional array of three data items: each item is an array of two arrays, each of which, in turn, is an array. Thus you interpret a multidimensional array as an "array of arrays."

## Pointers

A pointer is a variable that can hold the address of any type of data. For example, if p_i is a pointer to an integer variable, you can define and use it as follows:

```
/* Define an int pointer and an integer */
int *p_i, count;
```

```
/* Set pointer to the address of the integer "count" */
p_i = &count;
```

In this case, the compiler allocates storage for an int variable count and a pointer to the integer p_i. The number of bytes necessary to represent a pointer depends on the underlying system's addressing scheme.

![](img/d9230b719dc0efd80851f363d8c6f571_771_0.png)

Don't use a pointer until it contains the address of a valid object. The example shows p_i being initialized to the address of the integer variable count using the & operator, which provides the address of a variable. After p_i is initialized, you can refer to the value of count with the expression *p_i, which is read as "the contents of the object at its address p_i."

Pointers are useful in many situations; one important one is the dynamic allocation of memory. The standard C libraries include functions malloc and calloc, which you can call to allocate storage for arrays of objects. After allocating memory, these functions return the starting address of the block of memory. Because this address is the only way to reach that, you must store it in a variable capable of holding an address — a pointer.

Suppose you allocate memory for an array of 50 integers and the saved returned address is p_i. Now you can treat this block of memory as an array of 50 integers with the name p_i. Thus, you can refer to the last element in the array as p_i[49], which is equivalent to *(p_i+49). Similarly, C treats the name of an array as a pointer to the first element of the array. The difference between the name of an array and a pointer variable is that the name of an array is a constant without any explicit storage necessary to hold the address of the array's first element. The pointer, on the other hand, is an actual storage capable of holding the address of any data.

In addition to storing the address of dynamically allocated memory, pointers are also commonly used as arguments to functions. When a function is called, all of its arguments are passed by value — that is, the function gets a copy of each argument, not the original variables appearing in the argument list of the function. Thus, a C function cannot alter the value of its arguments. Pointers provide a way out. To change the value of a variable in a function, you can pass a pointer to the variable; the function can alter the value through the pointer.

## Type definitions

Through the typedef keyword, C provides you with a convenient way of assigning a new name to an existing data type. You can use the typedef facility to give meaningful names to data types used in a particular application. For example, a graphics application might declare a data type named Point as follows:

```
* Declare a Point data type */
  short x;
  short y;
```
