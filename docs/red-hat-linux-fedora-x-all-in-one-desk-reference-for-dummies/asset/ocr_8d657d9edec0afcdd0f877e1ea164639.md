**Figure 4-11:** Changing the GNOME desktop's background.

To select a horizontal color gradient, try these steps:

+   1. **From the Desktop Colors drop-down menu (refer to Figure 4-11), choose the Horizontal Gradient option.**

+   2. **Click the left color button next to the drop-down menu.**
   A selection dialog box comes up (shown in Figure 4-12) from which you can pick a color.

![](bbox=[0.253, 0.587, 0.613, 0.786])

**Figure 4-12:** The Pick Color dialog box.

+   3. **Repeat the same process to select the right color.**

After you complete these steps, the image of the monitor in the dialog box shows you a preview of the new background color.
