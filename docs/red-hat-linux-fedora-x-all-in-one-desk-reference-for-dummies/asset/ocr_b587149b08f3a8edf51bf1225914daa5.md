# Variables (or macros)

In addition to the basic capability of building targets from dependents, GNU make includes many features that make expressing the dependencies and rules for building a target from its dependencies easy for you. If you need to compile a large number of C++ files using GCC with the same options, for example, using the options for each file is tedious. You can avoid this repetitive task by defining a variable or macro in make follows:

```
# Define macros for name of compiler
CXX= g++
```

```
# Define a macro for the GCC flags
CXXFLAGS=-02 -g -mpcu=i686
```

```
# A rule for building an object file
form.o: form.h
$(CXXFLAGS) -c $(CXXFLAGS) form.C
```

In this example, CXX and CFLAGS are variables. (GNU prefers to call them variables, but most UNIX make utilities calls them macros.)

To use a variable anywhere in the Makefile, start with a dollar sign ($) followed by the variable in parentheses. GNU make replaces all occurrences of $(CXXFLAGS) with the string -02 -g -mpcu=i686

GNU make has several predefined variables that have special meanings. Table 1-2 lists these variables. In addition to the variables listed in Table 1-2, GNU make considers all environment variables (such as PATH and HOME) to be predefined variables as:

# Some Predefined Variables in GNU make

| Variable | Meaning |
|---|---|
| $$ | Member name for targets that are archives. If the target is libdisp.a(image.o), for example, $$ is image.o, and $@ is libdisp. |
| $* | Name of the target file without the extension. |
| $+ | Names of all dependent with duplicate dependencies, listed in their order of occurrence. |
| $< | The name of the first dependent. |
| $? | Names of all dependent files (with spaces between the names) that are newer than the target. |
| $@ | Complete name of the target. |
