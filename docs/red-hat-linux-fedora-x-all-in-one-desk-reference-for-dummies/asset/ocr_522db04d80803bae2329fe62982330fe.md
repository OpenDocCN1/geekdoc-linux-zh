```
m4 ex.m4 > letter
```

The simple example in the preceding section gives you an idea of how

sendmail.cf file. You find many complex macros stored in files in the
/usr/share/sendmail-cf directory. A top-level file, sendmail.mc,

By defining its set of high-level macros in files located in the /usr/\share/sendmail-cf directory, sendmail essentially creates its own macro
language. The sendmail macro uses the .mc extension. The primary
sendmail macro file you configure is sendmail.mc, located in the /etc/
mail directory.
