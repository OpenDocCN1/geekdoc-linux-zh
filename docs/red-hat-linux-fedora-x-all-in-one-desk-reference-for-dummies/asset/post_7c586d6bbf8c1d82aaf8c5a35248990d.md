
# Setting Up an Ethernet LAN

DIX was included in the 802-series standards developed by the Institute of Electrical and Electronics Engineers (IEEE). The final Ethernet specification is formally known as IEEE 802.3 CDMA/CD, but people continue to call it Ethernet.

Ethernet sends data in packets (discrete chunks also known as frames). You do not have to hassle with the innards of Ethernet packets, except to note the 6-byte source and destination addresses. Each Ethernet controller has a unique 6-byte (48-bit) address — at the Physical level, every packet must have one.

# Ethernet cables

Any time you hear experts talking about Ethernet, you're also going to hear some bewildering terms for the cables that carry the data. Here's a quick rundown.

The original Ethernet standard used a thick coaxial cable, nearly half an inch in diameter. This wiring is called thickwire or thick Ethernet, although the IEEE 802.3 standard is Base5. That designation means several things: The data-transmission rate is 10 megabits per second (10 Mbps); the transmission is baseline (which simply means that the capacity is devoted to transmitting Ethernet packets only); and the total length of the cable can be no more than 500 meters. Thickwire was expensive, and the cable was rather unruly. Unless you're a technology history buff, you don't care one whit about Base5.

Nowadays, two other forms of Ethernet cabling are more popular. The first alternative to thick cable is thinwire, or you build a thin, flexible cable. A thinwire segment can be, at most, 18 meters long. The other, more recent, is Ethernet over unshielded twisted-pair cable (UTP), known as Base1T.

Set to up a 10BaseT Ethernet network, you need an Ethernet hub — hardware box with RJ-45 jacks (which look like big telephone jacks). You build the network by running twisted-pair wires (usually, Category 5, or Cat5, cables) from each PC's Ethernet card to this hub. You can get a 4-port 10BaseT hub for about $50 U.S. Figure 2-2 shows a small 10BaseT Ethernet LAN that you may set up at a small office or your home.

> TIP
> When properly installed, the Linux kernel loads the driver for the Ethernet card every time it boots. To verify that the Ethernet driver is loaded, type the following command in a terminal window:

```
dmesg | grep eth0 /etc/modprobe.conf | cut -d ' ' -f 3
```

This command searches the messages for any line that contains the name of the Ethernet card (in backquotes — 'grep eth0 /etc/modprobe.conf | cut -d ' ' -f 3' picks out the alias for eth0 device from the /etc/modprobe.conf file). The A 2 option for grep causes it to print two lines for the line that matches the search criteria.

# Configuring TCP/IP Networking

When you set up TCP/IP networking during Fedora Core installation, the installation program prepares all appropriate configuration files using the information you provide. However, Fedora Core comes with the graphical network configuration tool that you can use to add a new network interface or alter information such as name servers and hostnames.

Use the Fedora network-configuration tool to set up networking if you're adding a new Ethernet card (or if your Ethernet card was not configured during installation).

Start the network-configuration tool, log in root and from the GNOME desktop, choose Main Menu>System Settings>Network. If you are not logged in as root, you're prompted for the root password.

The network-configuration tool displays a tabbed dialog box, as shown in Figure 2-3.

![](img/d9230b719dc0efd80851f363d8c6f571_329_0.png)

You can configure your network through the four tabs that appear along the top of the dialog box. Here's what each of the tabs does:

- **Devices**: Here you find options for a new network interface (for example, an Ethernet card). You can set the IP address of the interface and activate it. Information that you enter about a device is stored in various files in the `/etc/sysconfig` directory.
- **Hardware**: Here you add a new hardware device, such as an Ethernet card, modem, or an ISDN device. You can then provide information such as interrupt request (IRQ), I/o port numbers, and DMA channels for the device.
- **DNS**: Here you enter the host name for your system and the IP addresses of name servers. The name server addresses are stored in the /etc/resolve.conf file. The host name is stored in the HOSTNAME variable in the /etc/sysconfig/network file.
- **Hosts**: This tab shows the local table of hosts and IP addresses in the /etc/hosts file and lets you add, remove, or edit entries.

To add and activate a new Ethernet network interface, do the following:

- **1. On the Devices tab, click the New button.** The Select Device dialog box appears.
- **2. Select Ethernet connection and click Forward.** The Select Ethernet dialog box appears.
- **3. Select your Ethernet Card and click Forward.** The Configure Network dialog box appears (shown in Figure 2-4).

![](img/d9230b719dc0efd80851f363d8c6f571_330_0.png)

- **4. Select the way in which the Ethernet gets its IP address:** If it can automatically obtain an IP address (which is the case when the card is connected to DSL or cable modem), select the Automatically Obtain IP Settings radio button. When you do so, also select the Automatically Obtain DNS check. Otherwise, select the Statically Set IP Addresses radio button, and then enter an IP address in the text box. For a home network, use a private address such as 192.168.0.
- **5. Click Forward, and then Apply to complete the Ethernet setup.** You're back in the Network Configuration dialog (refer to Figure 2-3).
- **6. Select the eth0 device and then Activate to turn the Ethernet network on.** If you are running a private network, you may use IP addresses in the 192.168.0.0 to 192.168.255.255 range (Other ranges of addresses are reserved for private networks, but this range suffices for most needs.)

# Connecting Your LAN to the Internet

If you have a LAN with several PCs, you can connect the entire LAN to the Internet using DSL or cable modem. Basically, you can share the highspeed DSL or cable modem connection with all the PCs in the LAN.

Chapter 1 of this minibook, I explain how to set up DSL or cable modem. In this section, I briefly explain how to connect a LAN to the Internet so all the PCs can access the Internet.

The most convenient way to connect a LAN to the Internet via DSL or cable modem is to buy a hardware device called DSL/Cable Modem NAT Router with 4- or 8-port router can translate private IP addresses into a single externally known IP address. The Ethernet hub part appears to you a number of RJ-45 Ethernet ports where you can connect the PCs to set up a LAN. In other words, you need only one extra box besides the DSL or cable modem.
