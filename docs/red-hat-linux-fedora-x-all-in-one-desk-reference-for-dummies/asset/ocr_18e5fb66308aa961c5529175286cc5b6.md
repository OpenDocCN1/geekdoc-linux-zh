# Automatic Partitioning

Automatic Partitioning allows you to have some concern what data is removed (if any) from your system.

To remove only Linux partitions (created from a previous Linux installation), select **Select Linux** on your system.

Before automatic partitioning can be set up by the installation program, you must choose how to use the space on your hard drives.

To remove all partitions on your hard drives (this includes partitions created by other operating systems such as Windows 98/NT/2000), select **Remove all partitions** on your system.

+   - Review (and modify if needed) the partitions created

You can select from three options:

+   **Remove All Linux Partitions On This System:** The Core installer to remove all existing Linux partitions and create new partitions for installing Fedora Core. You can use this option if you have already any version of Linux installed on your PC and want to wipe it out and install the latest version of Fedora Core.

+   **Remove All Partitions On This System:** This option is similar to the first option, except that the installation program removes all partitions, including those used by other operating systems such as Microsoft Windows. *Use only* if you want Fedora Core as the only operating system for your PC.

+   **Keep All Partitions and Use Existing Free Space:** For Linux by using PartitionMagic or the FIPS utility, select this option to create the Linux partitions using the free space on the hard disk. If you are installing Fedora Core on a new PC after resizing the partition, this option is the right one to choose.
