For example, click the Modified column heading, and Konqueror displays the list of files and folders sorted according to the time of the last modification. Clicking the Name column heading sorts the files and directories alphabetically by name.

Not only can you move around different folders using Konqueror, you can also do such as move a file from one folder to another or delete a file. I don't outline each step because the steps are intuitive and similar to what you do in any GUI (such as Windows or the Mac interface). Here are some things you can do in Konqueror:

+   * View a text file: Click the filename and Konqueror runs the KWrite processor, displaying the file in a new window.

+   * Copy a file to a different folder: Drag and drop the file's icon to the folder you want to go. A menu pops up and asks whether you want to copy, move, or simply link the file to that directory.

+   * Delete a file or directory: Right-click the icon, and Select Move to Trash from the pop-up menu. To permanently delete the file, right-click the Trash icon on the desktop, and choose Empty Trash. If you only really want to delete the file: to recover a file from the trash, double click the file on the desktop and drag and drop the icon into the folder where you want to save it. When asked whether you want to copy or move, select Move. You can recover files from the trash until the moment you empty the trash.

+   * Rename a file or directory: Right-click the icon, and select Rename from the pop-up menu. You can then use the new name or edit the old name.
