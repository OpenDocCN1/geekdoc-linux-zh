# ## The newsfeeds
The **newsfeeds** file specifies how incoming news articles are redistributed to other servers and if you provide news feeds to other servers, you have to list these feeds in this file. (You must also have an entry labeled ME, which serves a special purpose that I explain later in this section.)

The **newsfeeds** file contains a series of entries, for each feed. Each feed entry has the following format:

+   - site[/exclude,exclude...]
- :pattern,pattern...[/distrib,distrib...]
- :flag,flag...]
- :param

Each feed has fields separated by colons (:). Usually, the entries span multiple lines and a backslash (\) at the end of the line is used to continue a line to the next. Here's what the feed means:

+   * The first **site**, is the name of the feed. Each name must be unique, and for feeds to other servers, the name is set to the host of the remote server. The following is an optional slash and an **exclude,exclude...** consisting of a list of names. If any of the names in this list appear in the Path line of an article, that article is not forwarded to the feed. You can use an **exclude** list if you do not want to receive articles from a specific source.

+   * The second field consists of a comma-separated list of newsgroup terms, such as **\*alt.binaries.warez., \*control\***, followed by an optional distribution list. The distribution list is a list of comma-separated keywords, with each keyword specifying a specific set of sites to which the articles are distributed.
