# Instant Messaging with Gaim

You can use Gaim to keep in touch with all your buddies on AOL Instant Messenger (or AIM, it's commonly known). If you use AOL's AIM, you'll be right at home with Gaim, a client for the AOL AIM service. You need an AIM screen name to use Gaim.

Start Gaim by choosing Main Menu>Internet>Messaging Client from the GNOME desktop. The initial Gaim window appears (see Figure 1-10).
