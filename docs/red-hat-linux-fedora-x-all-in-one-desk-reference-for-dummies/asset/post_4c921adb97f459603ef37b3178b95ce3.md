Before you dial out an external modem, you have to make sure that the modem is properly connected to one of the serial or USB ports of your PC.

If you have an external modem, make sure that modem is properly connected to the power supply and that the modem is connected to the telephone line. Buy the right type of cable to connect the modem to the PC. You need a straight-through serial cable to connect the modem to the PC. The connectors at the ends of the cable depend on the type of serial connector on your PC. The modem end of the cable needs a 25-pin connector. The PC end of the cable is often a 9-pin connector. You can buy dummy modems at most computer stores. You often find 9-pin-female-to-25-pin-male cables under the label AT Modem Cable. Connect USB modems using a USB cable.

# Setting the serial-device names

The PC typically has two serial ports, COM1 and COM2 in MS-DOS parlance. Many PCs with Universal Serial Bus (USB) have only one serial port. The PC can also support two more serial ports: COM3 and COM4. Because of these port names, serial ports are often referred to as COM ports.

Like other devices, the serial-port devices are represented by device files in the /dev directory. The serial ports are interrupt-request (IRQ) numbers and I/O port addresses. Two IRQs — 3 and 4 — are shared among the four COM ports. Table 1-2 lists the serial-device names corresponding to the COM ports, as well as the I/O port addresses assigned to the four serial ports.

| Table 1-2 Device Names for Serial Ports | | | |
| :--- | :--- | :--- | :--- |
| COM port | Device name | IRQ | I/O address |
| COM1 | /dev/ttyS0 | 4 | 0x38 |
| COM2 | /dev/ttyS1 | 3 | 0x28 |
| COM3 | /dev/ttyS2 | 4 | 0x38 |
| COM4 | /dev/ttyS3 | 3 | 0x28 |

All these devices are already in your Fedora Core system. In a terminal window, type `ls -l /dev/ttyS*` to see a listing of these device files.

The device name is different if your modem connects to a USB port or if you have a modem. For winmodems, you have to first download and install a driver. You can locate Linux drivers for many winmodems by checking the www.linmodems.org website. In many cases, Linux modem drivers set up the modem device /dev/modem as a symbolic link to the actual device file. For example, the Conexant HSF driver sets up /dev/modem as a symbolic link to /dev/ttySH0, which is the actual device name for softmodem. Because of the symbolic link, I can refer to the modem by the generic /dev/modem instead of the somewhat complicated device names.

# Checking if the Linux kernel detected the serial port

To verify that the Linux kernel detects the serial port correctly, check the boot messages with the following command:

```
dmesg | grep ttyS
```

If you see a message like the following, Linux detects a serial port in your PC:

```
ttyS0 0x03f8 (irq = 4) is a 16550A
```

In this case, the message indicates that the Linux kernel has detected the first serial port (COM1). It shows the I/O address (in hexadecimal), 0x3f8 and IRQ 4. The part of the message — 16550A — refers to the asynchronous receiver/transmitter (UART) chip, which is the heart of all serial communications (the UART converts each byte to a stream of 0s and 1s, and vice versa when it receives such a stream).

![](img/d9230b719dc0efd80851f363d8c6f571_314_1.png)
![](img/d9230b719dc0efd80851f363d8c6f571_314_2.png)

Of course, if you have a softmodem installed you may see something similar to the following in dmesg | grep ttyS:

```
ttySH0 at I/O 0x2400 (irq = 10) is a Conexant HSF modem
```

You can also check for the serial ports with the setserial command. Type the following command to see detailed information about serial ports:

```
setserial -g /dev/ttyS0
```

Any serial device listed in the output of this command is either installed or not detected by the Linux kernel. For softmodems, the UART functionality is performed in software.

# Testing the modem

After you complete the physical installation of the modem and verify that the Linux kernel detects the serial port, you can try to dial out through the modem. The best approach is to use Minicom communications program that comes with Fedora Core. Minicom is similar to other communications software such as Procomm or Crosstalk that you may have used under MS-DOS or Windows.

To run Minicom, log in as root and type minicom at the shell prompt (or in a virtual console). Minicom runs and resets the modem. Figure 1-8 shows the result of running Minicom in a terminal window.

```
minicom
$ help

OPTIONS: History Buffer, F-keys, Search History Buffer, Compiled Feb 17 2004, 04:52:10.

Press Ctrl-A for help on special keys
$ 5745 50-0 L1 V34 N34 E10
```

**Figure 1-8:** You can test your modem manually with Minicom. If you don't see the words OK, it probably means that this particular serial device is not set correctly. To set the serial device, follow these steps:

1. **Press Ctrl-A and then Z.** Minicom displays its help screen.
2. **Press O.** Minicom displays its configuration menu.
3. **Use the arrow key to select Serial port setup and press Enter.** Minicom displays the serial port settings.
4. **Press A.** Minicom puts the cursor in the line that shows the serial device name. Edit the device name to match which modem is connected. For example, if the modem device is set up with the /dev/modem symbolic link, make sure that the device name is set to /dev/modem.
5. **Press Enter twice.** Minicom returns to the configuration menu.
6. **Select Save setup as refl and press Enter.** Minicom saves the settings.
7. **Select Exit and press Enter.** Minicom returns to online mode.
8. **Press Ctrl-A and X.** Minicom prompts you to ask whether you really want to exit.
9. **Press Enter to exit.**

After setting the correct device name for the serial port where your modem is powered on and connected to the phone line:

10. **Start Minicom again (type minicom in the terminal window).**
11. **Press Ctrl-A to get the attention of the Minicom program.**

After you press Ctrl-A, if you press Z, a help screen appears in the form of a text window. In the help screen, you can get information about other Minicom commands.

12. **From the help, press Enter to go back to online mode.**

In online mode, you can use the modem's AT commands to dial out. In particular, you can use the ATDT command to dial the phone number of another modem (for example, dial your ISP's number). When you get the login prompt, you know that the modem is working. # Setting up and activating a PPP connection

Most ISPs provide dial-up access to the Internet through one or more systems the ISP maintains. If you sign up for such a service, the ISP provides the information you need to make a PPP connection. Typically, this information includes:

- The phone number to dial to the remote system
- The username and password that you use to log in the remote system
- The names of the ISP's mail and news servers
- The IP address for your PPP connection. Your ISP does not provide this address if the IP address is assigned dynamically (which means the IP address may change every time your system establishes a connection).
- IP of the ISP's Domain Name Servers (DNS). The ISP does not provide these addresses if it assigns the IP address dynamically.

Of this information, the first two items are what you need to set up a PPP connection.

Follow these steps to set up a PPP connection using the Internet Configuration Wizard:

1. Log in as root and choose Main Menu:System Tools:Internet Configuration Wizard from the GNOME desktop. If you are not logged in root, type the root when you are prompted for it.
2. Select Modem Connection from the Device list, and then click Forward.
3. The Select Modem dialog box shows information about your modem. Click Forward to continue.
4. The Select Provider dialog box appears. Fill in the connection information — the ISP's phone number, your login name, and password — in the text boxes (shown in Figure 1-11); click Forward to continue.
