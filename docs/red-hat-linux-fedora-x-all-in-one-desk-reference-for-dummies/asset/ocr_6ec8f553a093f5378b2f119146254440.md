# # Chapter 3: Making Presentations with OpenOffice.org Impress

In This Chapter

+   - Taking stock of OpenOffice.org Impress
- Getting started with Impress
- Using Impress to create presentations

It seems the business world, or should I say the whole world, is full of PowerPoint briefing packages (slide presentations) — those dedicated souls who live by their PowerPoint. Imagining a meeting or a conference where someone isn't vigorously making points-on a slide — hard. Let's face it: Such programs are here to stay. Making presentations is a fact of life: Businesspeople have come to office-application suites to include some sort of presentation software.

Like Microsoft Office, the OpenOffice.org office-application suite comes with its own PowerPoint-like presentation software — OpenOffice (or Imp for for). If you have used PowerPoint and you're already familiar with its nuts and bolts — the concept of a slide, how to add text and graphics to a slide, and how to run a slide show then you'll find getting started with Impress easy. Because some details of how you perform basic tasks differ from how they're done in PowerPoint, I provide some quick reference tables to point you in the right direction. I start with an overview of Impress and then cover some categories of common tasks that you likely perform in Impress.
