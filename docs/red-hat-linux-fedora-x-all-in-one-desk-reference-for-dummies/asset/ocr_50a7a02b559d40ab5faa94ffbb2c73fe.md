# Using Xianian Evolution 343

| Table 1-2 Shortcut Icons in Xianian Evolution |
| Name of Icon | What It Does |
| Mail | Switches to mail display where you can read and send mail. |
| Calendars | Opens your calendar where you can look up and add appointments. |
| Tasks | Shows your "to do" list where you can add new tasks and check what's due. |
| Contacts | Opens your contact list where you can add new contacts or look up someone from your current list. |

As the icons listed in Table 1-2 show, Xianian Evolution has all the necessary components of a PIM — e-mail, calendar, task list, and contacts.

Above the shortcut icons, Evolution displays folders that can be open by clicking. To read e-mail, click the Mail icon and then click the arrow to On This Computer. You see a number of folders containing mail messages.

To access your e-mail, click the Inbox icon. Evolution opens your Inbox as shown in Figure 1-4). If you turn the feature to automatically check for your mail every so, Evolution already prompted you for your mail password and downloaded your mail. The e-mail Inbox looks much like any other reader's inbox, such as the Outlook Inbox.
