# Views in Composer

Notice that the Composer window has four tabs at the bottom. These tabs enable you to view the Web page in different forms. Typically you edit the file in Normal view, but you can switch to the other views; for example, you can edit HTML directly if you desire. To change to a different view, click the tab.
