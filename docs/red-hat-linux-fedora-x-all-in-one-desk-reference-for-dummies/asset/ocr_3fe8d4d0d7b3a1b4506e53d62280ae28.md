Toolbar

+   - **Object bar:** Shows the common formatting and style attributes, including, that apply to the currently selected type of object such as text, image, or vector graphics.

+   - **Toolbar:** Located along the left side of the window, the toolbar provides icons that you can click to select tools for drawing or editing objects in the drawing.

+   - **Rulers:** Shows the vertical and horizontal page dimensions.

+   - **Navigation bar:** Located along the bottom of the window, the navigation bar enables you to change views and select a drawing to work with.
