The GNOME calculator has three modes. By default, the calculator displays the Basic mode for typical calculations. The other two modes are Financial and Scientific. You can switch the mode from the View menu. For example, select View:Financial Mode to get a calculator capable of financial calculations, such as loan payment rates for a given principal, interest rate, and payments.

From KDE desktop, you can start the KDE calculator by selecting Menu:Utilities:KCalc.

# Commercially available office applications for Linux

Because office applications are important to many businesses as well as individuals, I want to briefly mention some office applications available for Fedora Core. These commercial offerings include AnyOffice (formerly Anyware Office) and StarOffice. These products to cost money, but the cost is usually less than for Microsoft Office—the leading office suite for Windows. (In case you do not know, Microsoft Office is a collection of several applications: Microsoft Word for processing; Microsoft Excel for spreadsheets; Microsoft PowerPoint for presentation; and Microsoft Access for databases.)

Another recent commercial product for Linux is CrossOver Office from CodeWeavers. With CrossOver, you can run any Microsoft Office applications as Word, Excel, and PowerPoint under Linux and X System.

This book's companion DVD-ROMs do not include any of these commercial office applications for Fedora Core, but I briefly describe them in the next few sections. You can visit each vendor's Web site for more about the products.

# Anyware Office

Anyware Office, formerly known as Appliz Office, is another prominent office suite for all Linux distributions, including Fedora Core. In April 2000, Appliz, Inc., formed a separate group—VistaSource, Inc.—that focuses solely on Linux applications.

Like other office suites, Anyware Office includes Words (for word processing), Spreadsheets (for spreadsheets), Graphics, and Presents (for presentations). In addition, it has Mail (an e-mail interface) and Data (an interactive database-browsing tool). Anyware Office can also read and write documents in Microsoft Office and Corel-formats, as well as in several other file formats. Although trial versions are not offered, the entire Anyware Office suite is currently priced at less than $100 in the United States.
