
# 130 Exploring KDE

The Konqueror window is vertically divided into three parts:

- A narrow left window shows icons you can click to perform various tasks in Konqueror.
- The wider window shows a tree view of the current folder.
- The widest window (at the right) uses icons to show the files and folders in the current folder.

Konqueror uses different types of icons for different files and a preview of each file's content. For image files, the preview is a thumbnail of the image.

The Konqueror window's title bar shows the name of the currently selected directory. The location box (along the top of the window) shows the full name of the directory, using Konqueror terminology — in this case, Figure 1-18 shows the contents of the /home/naba directory.

Use the leftmost vertical row of buttons to select others to browse. When you click one of these buttons, the middle window displays a tree menu of items you can browse. For example, to browse other parts of the system, do the following:

1. From the leftmost vertical column of icons in the Konqueror window (refer to Figure 1-18), click the Root folder icon (the one that appears just above the Services icon).
A tree menu of directories appears in the middle window.
2. In the tree view, locate the folder you want to browse.
3. To view the contents of the X11 subdirectory, scroll down and click X11.
The window on the right now shows the contents of the /etc/X11 directory.

For example, to look at the etc folder, click the plus sign next to the etc. Konqueror displays the other folders and changes the plus sign to a minus sign.

Konqueror displays the contents of a folder using different types of icons. Each directory has a name underneath the folder icon. Ordinary files appear as a sheet of paper.

The Konqueror window has the usual menu bar and toolbar. You can view the files and folders in other formats as well. For example, choose View:View Mode: Detailed List View to see the folder's contents using smaller icons (see Figure 1-19), along with detailed information (such as the size of each file or directory, and at what time each was modified).

If you click any of the column headings — Name, Size, Type, or Modified — along the top of the list view, Konqueror sorts the list according to column.

For example, click the Modified column heading, and Konqueror displays the list of files and folders sorted according to the time of the last modification. Clicking the Name column heading sorts the files and directories alphabetically by name.

Not only can you move around different folders using Konqueror, you can also do such as move a file from one folder to another or delete a file. I don't outline each step because the steps are intuitive and similar to what you do in any GUI (such as Windows or the Mac interface). Here are some things you can do in Konqueror:

- View a text file: Click the filename and Konqueror runs the KWrite processor, displaying the file in a new window.
- Copy a file to a different folder: Drag and drop the file's icon to the folder you want to go. A menu pops up and asks whether you want to copy, move, or simply link the file to that directory.
- Delete a file or directory: Right-click the icon, and Select Move to Trash from the pop-up menu. To permanently delete the file, right-click the Trash icon on the desktop, and choose Empty Trash. If you only really want to delete the file: to recover a file from the trash, double click the file on the desktop and drag and drop the icon into the folder where you want to save it. When asked whether you want to copy or move, select Move. You can recover files from the trash until the moment you empty the trash.
- Rename a file or directory: Right-click the icon, and select Rename from the pop-up menu. You can then use the new name or edit the old name.

## Viewing Pages

You can configure the desktop in many ways, but I use the Control Center for one.

The Control Center is vertically divided into two parts:

- The narrower left window shows a tree menu with so top-level categories that you can perform.
- The wider window is where you enter information.

To customize a specific category as Appearance & Themes, click the plus (+) to the left of the label. The plus sign changes to a minus sign (-), and you can get a list of all the items you can specify. For example, to change the desktop's background from the window shown in Figure 1-21, do the following:

1. Click the plus sign next to Appearance & Themes; from the new items that appear, click Background.
The Control Center displays the choices for desktop, using the right window as shown in Figure 1-22. You can select a background color or wallpaper (an image used as background) for your desktop here.
2. Select a picture as background, select Picture and then click the button with the folder icon, next to the name of the current picture.
The Control Center brings up a dialog box (shown in Figure 1-23) showing the contents of the /usr/share/backgrounds/images directory.
3. Pick one of the image files from the list of lists, and then click OK.
4. When you get back to the Control Center window, click Apply to put to the new change into effect.
5. If you want to configure other aspects of the KDE desktop, select another item in the Appearance & Themes list (refer to Figure 1-22) and give it a try.

Click Apply to try a new configuration; if you don't like the result, click Reset to revert to the old settings.
