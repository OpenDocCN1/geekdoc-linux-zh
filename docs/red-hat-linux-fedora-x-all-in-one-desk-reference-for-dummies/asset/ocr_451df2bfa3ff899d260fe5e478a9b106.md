# 66 Setting Up Printers

5. In the next screen (see Figure 3-3), select a queue type from the drop-down box; then click Forward.

Select the print-queue type that applies to your situation. For example, if you want to print on a shared Windows printer, select the Windows Printer checkbox.

To set up a printer connected to your PC's parallel port, select Locally-connected.

Figure 3-3: Select the print queue type from this window.

The following types of print queues are:

+   * Locally-connected: Refers to a printer connected directly to the serial, parallel, or USB port of your PC.
* Networked CUPS (IPP): Refers to a Common UNIX Printing System (CUPS) print queue at another server on the network (IPP refers to the Internet Printing Protocol used to communicate with the remote CUPS server).
* Networked UNIX LPD: Refers to a print queue managed by the LPD server on another UNIX system on the local network (LPD refers to Line Printer Daemon—)
* Networked Windows (SMB): Refers to a printer connected to another PC on the local network that uses the Server Message Block (SMB) protocol, the underlying protocol in Windows file and print sharing.
* Networked Novell (NCP): Refers to a printer connected to a Novell server on the local network.
* Networked JetDirect: Refers to a HP JetDirect printer connected directly to the local network.
