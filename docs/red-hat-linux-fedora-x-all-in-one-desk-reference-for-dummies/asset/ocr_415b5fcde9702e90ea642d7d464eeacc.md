# 266 Using Draw

Table 4-1 (continued)

| To Do This | Follow These Steps |
|---|---|n| Adding text and graphics objects to a drawing | Click the icon for the drawing tool from the vertical toolbar. Use the mouse to draw, using the selected tool. Mouse over and use the tooltip to figure out the different tools do. |
| Change an object's attributes | Right-click the object and select the attribute such as the line, area, position, and size that you want to change. |
| Duplicate an object | Select the object and choose Edit>Duplicate. Make selections for the placement and the number of copies and choose OK. |
| Select multiple objects | Click objects while holding the Shift key. Select the objects you want to group. Right-click the selection and select Group from the pop-up menu. |
| Ungroup objects | Right-click the group and select Ungroup from the pop-up |
| Rotate objects | Select one or more objects. Click the Effect on the toolbar (use the tooltip to find this icon) and click the Rotate icon. Grab one of the handles that appear on the object and use it to rotate |
| Align objects | Right-click the selection and Align the alignment type such as Left, Center, and so on |
| Distribute objects evenly | Select three or more objects. Right-click the selection and select Distribution. Use the Distribution box to choose how you want the objects distributed on-screen |
| Arrange the order of objects | Right-click the selection and select Arrange and the placement order, such as Bring to Front, Send Backward, and so on. |
| Add 3D objects to a drawing | Click the 3D Object icon on the toolbar (last icon from the top). |
| Convert to 3D | Click to select the text frame. Then right-click and Convert to 3D. Click and rotate the 3D text to your liking. |
| Apply special effects to text | Choose Format>FontWork. Select the text you want to apply special effects. Select the effects you want from the FontWork window. For example, you can place the text along a curve and show a shadow for the text. |
| Add a background to text | Right-click the text frame and select Area. Select options for the text background from the resulting dialog box. |
| Apply fonts to text | Right-click the text frame and select Character from the pop-up menu. Click the Font Effects in the Relating dialog box. Select the effects (such as embossed or engraved characters) from the Font Effects tab. |
| Crop an image | Select the image and click the Crop icon — the icon on the right of the object bar. Select the options you want from the Crop dialog box and click OK. |
