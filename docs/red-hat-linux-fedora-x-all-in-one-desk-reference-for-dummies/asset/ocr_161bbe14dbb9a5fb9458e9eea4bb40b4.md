# Disk Partitioning Setup

One of the largest obstacles for a new user in a Linux installation is partitioning. This process is made easier by providing automatic.

By selecting automatic partitioning, you will not have to use partitioning tools to align points, create partitions, or allocate space for your installation.

To partition manually, choose the Disk Duid partitioning tool.

Automatic Partitioning sets partitions based on the selected installation type. You can also customize the partitions once they have been created.

The manual disk partitioning tool allows you to create partitions in an interactive environment. You can set the file system types, mount points, partition sizes, and more.

+   * Automatically partitioning
* Manually partition with Disk Duid

**Figure 2-4:** Select a disk-partitioning strategy from this screen.

The screen gives you the following options for partitioning and using the hard disk:

+   * **Automatic Partitioning:** This option (the most users choose) causes the Fedora Core installation program to create new partitions for installing Linux according to your chosen installation type, such as workstation or server. After the automatic partitioning, you get a chance to customize the partitions.
* **Manually Partition with Disk Duid:** With this option, you can use the Disk Duid program that lets you partition the disk, and at the same time, specify which parts of the Linux file system to load, and on which partition(s).

From the disk-partitioning strategy screen (refer to Figure 2-4), select the first option to have the installer automatically partition for the disk. The Fedora Core installer then displays another screen (see Figure 2-5) that asks you how you want the automatic partitioning to be done.
