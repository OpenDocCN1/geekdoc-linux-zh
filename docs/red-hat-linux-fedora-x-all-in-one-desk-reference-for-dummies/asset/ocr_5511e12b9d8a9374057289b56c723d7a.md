# Controlling the flow

In scripts, you can control the flow of execution — the order in which commands are executed — by using special commands such as if, case, for, and while. These control statements use the exit status of a command to decide what to next. A numeric value indicates whether or not the command succeeded. By convention, an exit status of zero means the command has succeeded (Yes, you read it: Zero succeeds!). A nonzero exit status indicates something went wrong with the command.

For example, you want to make a backup copy of a file before editing it with vi editor. More importantly, you want to avoid editing the file if a backup cannot be made. Here's a Bash script that takes care of this task:

```
#!/bin/sh
if cp "$1" "$1"
then
  vi "$1"
else
  echo "Failed to create backup copy"
```

This script illustrates the syntax of the if-else structure and shows how the exit status of the cp command is used to determine the next action. If cp returns zero, the script uses vi to edit the file; otherwise, it displays an error message and saves the backup in a file whose name is the same as that of the original, except for a hash (#) added at the end of the filename.
