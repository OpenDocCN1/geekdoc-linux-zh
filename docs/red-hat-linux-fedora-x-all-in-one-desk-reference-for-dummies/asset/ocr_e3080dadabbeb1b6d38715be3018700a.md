# 662 Installing the Mail Server

+   * /etc/mail/mailertable: Mail table used to override how mail is routed (for example, the entry comcast.net smtp:smtp.comcast.net tells sendmail that mail addressed to comcast.net addressed has been sent to smtp.comcast.net)

+   * /etc/mail/relay-domains: Hosts that permit relay

+   * /etc/mail/trusted-users: List of users allowed to send mail using their user's name without authority

+   * /etc/mail/userdb.db: User database file containing information about each user's login name and real name

+   * /etc/mail/virtertable:Database of users with virtual-domain addresses hosted on this system

If you edit the /etc/mail/mailertable file, you have to type the following command before the changes take effect:

```
makemap hash /etc/mail/mailertable < /etc/mail/mailertable
```

Here is an easier way to make sure that you rebuild everything necessary after making any changes — just type the following commands while logged in as:

```
cd /etc/mail
make
```

# The forward file

Users can redirect their own mail by placing a .forward file in their home directory. The .forward file is a plain-text file with comma-separated list of mail addresses. Any mail sent to the user is then forwarded to these addresses. If the .forward file contains a single address, all e-mail for that user is redirected to that single e-mail address. For example, suppose a .forward file containing the following line is placed in the home directory of a user named emily:

```
ashley
```
