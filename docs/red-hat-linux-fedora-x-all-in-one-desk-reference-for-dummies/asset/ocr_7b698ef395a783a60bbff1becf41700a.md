# 736 The Structure of a C Program

```
shapes.h
/* file: shapes.h
 * Header file for data structures
 */
#ifndef _SHAPE_H
#define SHAPE_H

enum shape_type { T_CIRCLE, T_RECTANGLE };
struct RECTANGLE {
    double x1, y1, x2, y2;
} struct RECTANGLE;
struct CIRCLE {
    double xc, yc, radius;
} struct CIRCLE;
type struct {
    enum shape_type type;
    union {
        RECTANGLE r;
        CIRCLE c;
    };
} SHAPE;
/* Function prototypes */
double compute_area(SHAPE *s);
#endif
```

```
shapes.c
/* file: shapes.c
 * Function that computes area of shapes
 */
#include <math.h>
#include "shapes.h"

double compute_area(SHAPE *s) {
    switch(s->type) {
        case T_CIRCLE:
            return M_PI * s->c.radius * s->c.radius;
        case T_RECTANGLE:
            return (s->r.x2 - s->r.x1) * (s->r.y2 - s->r.y1);
    }
}
```

```
shapest.c
/* file: shapest.c
 * Main program to test shapes.c */

#include <stdio.h>
#include "shapes.h"

int main(void) {
    SHAPE s;
    s.type = T_CIRCLE;
    s.c.radius = 50.0;
    s.c.xc = s.c.yc = 100.0;
    printf("area of circle: %.0f\n", compute_area(&s));
    return 0;
}
```

Figure 2-1: Typically, several source files make up a C program.

To create an executable program, you must compile and link the source files. The exact steps for building programs from C source depend on the compiler and the operating system. For example, in Fedora Core, you can compile and link the files shown in Figure 2-1 with the following:

```
gcc -o shapest shapest.c shapes.c
```

This command creates an executable file named shapest. You can then run it with the command

```
./shapest
```
