# Viewing Web pages

Conqueror is much more than a file manager. With it, you can view a Web page as easily as you can view a folder. Just type a Web address in the Location box and see what happens. For example, Figure 1-20 shows the Conqueror window after you typed www.irs.gov in the text box on the toolbar and pressed Enter.

Conqueror displays the Web site in the window on the right. The left window shows whatever it was displaying.

# Configuring KDE

You can configure the KDE desktop in many ways, but I use the KDE Control Center for one-stop KDE configuration. Choose Main Menu->Settings->Control Center. The Control Center starts and shows summary information about the Fedora Core system in a window (see Figure 1-21).
