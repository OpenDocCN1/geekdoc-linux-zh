
## Booting Fedora Core

## What is BogoIPS?

As Fedora Core boots, you get a message that says *Calibrating delay loop... 421. 23 BogoIPS*, with some number before the word *BogoIPS*. BogoIPS is one of those words that confuse millions of Linux users, but it's just jargon with a simple meaning.

BogoIPS is Linux invent (yes, the name Linus Torvalds started Linux), and it is bogus *MIPS*. As you know, MIPS is an acronym for millions of instructions per second—a measure of how fast your computer runs. MIPS isn't a very good measure of performance; the MIPS measurements of different types of computers are difficult to compare accurately. BogoIPS is basically a way to measure the computer's speed that's independent of the exact process order. Linux uses the BogoIPS number to calibrate a *delay loop*, in which the computer keeps running useless instructions until a specified amount of time passes. Of course, the reason for killing processor time is to wait for some slowpoke device to get ready for work.

When you're done with Firstboot, you're really done for good because it runs only once when you boot for the first time. If for some reason, you want to go through these steps again, here's the scoop on how to run Firstboot

Log in as *root* and type the following commands in a terminal window (to open a terminal window, choose Menu→System Tools→Terminal):

```
rm /etc/sysconfig/firstboot
chkconfig -level 5 firstboot
```

That's it! Next time you reboot the PC, you have the pleasure of meeting Firstboot again. If you want to run Firstboot interactively from GNOME or KDE, you can do so by logging in as *root* and typing the following commands in a terminal window:

```
rm /etc/sysconfig/firstboot
firstboot
```

When you're finished with Firstboot, get the graphical login screen (shown in Figure 4-5).

The login window in the middle of the screen displays a welcome message with your PC's name — it's called the *host name*. The name is assigned to the network is configured. If the network isn't configured, `localhost.localdomain` is the host name. If your PC gets its network address (the IP address) from a Dynamic Host Configuration Protocol (DHCP) server, that server provides a cryptic host name for your PC. The login window also has a text input field that prompts you for your username.

You can log in using any of the accounts you define during or after installation. There is always the root username, which happens to be the super-user or the administrator account. Whether you install Fedora Core yourself or someone installs it for you, you need to know the root password. Without that, you cannot do many of the tasks necessary to learn Linux works.

For example, to log in as user spiderman, type spiderman in the first text field and press Enter (move the mouse over the login box before you begin typing). Then type spiderman's password and press Enter. You then see the initial graphical user interface (GUI — pronounced gooey for short) appear. What you get depends on your choice of GUI — GNOME or KDE. If someone else made the choice for you, don't worry — GNOME and KDE are both good and versatile.

## Exploring GUI Desktops

Fedora Core comes with two GUI desktops — GNOME and KDE. If you installed both, you can try them out one by one. Selecting one of these desktops just before you log in to the system is — and here is where I will show you.

GNOME is typically the default GUI in Fedora Core, so you can start with GNOME. Then log out and back in, but select KDE as the GUI. That way, you can try out both desktops.

## GNOME

GNOME stands for GNU Network Object Model Environment (and GNU, so you probably know, stands for GNU's Not UNIX). GNOME is a graphical user interface (GUI) and a programming environment. From the user's perspective, GNOME is Microsoft Windows. Behind the scenes, GNOME has many features that allow programmers to write graphical applications that can work together well. In this chapter, I point out some key features of the GNOME GUI, leaving the details to you to explore on your own at your leisure.

If you're curious, you can always find out the latest information about GNOME by visiting the GNOME home page at www.gnome.org.

Typically, GNOME is the default desktop in Fedora Core. After you log in, you see the GNOME GUI desktop. Figure 4-6 shows the GNOME desktop for user-emily.

When you log in root, you can accidentally damage your system because you can do anything when you're root. Always log in as a normal user.

The exact appearance of the GNOME desktop depends on the current session (set of applications running at that time). As you can see, the initial GNOME desktop, shown in Figure 4-6, is very similar to the Windows desktop. It has the GNOME panel, or simply the panel (similar to the Windows taskbar) along the bottom and icons for folders and applications appear directly on the desktop. You can place icons directly on the Windows desktop in a similar way.
