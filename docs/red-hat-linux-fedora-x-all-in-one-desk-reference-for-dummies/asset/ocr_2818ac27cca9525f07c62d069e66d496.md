# Creating Web Pages 367

You can also insert images. Here's how:

+   1. Gather the image files you want to use (in formats such as JPEG or GIF), and save them somewhere on your Fedora Core.
nYou can either prepare the images in a drawing and paint program or get the images from some other source (for example, from a Web site such as the freesite.com/free_Graphics/free_clipart/index.html).
2. Position the cursor where you want an image; then choose Insert::Image from the Component center.
The Image Properties dialog box, shown in Figure 2-8.

![](bbox=[0.218, 0.355, 0.603, 0.581])

Figure 2-8: You can add an image to a Web page from this dialog box.

+   3. Click the Choose File button and select the image file from the Select Image dialog box.
4. Enter alternate text for the image — this text appears in text-only browsers.
You can also enter a tooltip (the text that appears as a user places the mouse over the image).
5. After filling in all the information, click OK.
The image appears where you positioned the cursor in Step 2 (see Figure 2-9).
6. Repeat Steps 2 through 5 for other images. After inserting the images, choose File::Save to save to the HTML file.
nYou're creating a new Web page, Composer prompts you for a filename.
