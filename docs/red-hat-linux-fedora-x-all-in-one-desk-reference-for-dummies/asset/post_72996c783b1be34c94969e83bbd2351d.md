
# 338 Understanding Electronic Mail

## Understanding Electronic Mail

E-mail messages are addressed to a username at a host (host is just a fancy name for an online computer). That means if John Doe logs in with the username jdoe, e-mail is addressed to jdoe. The only piece of information needed to identify the recipient uniquely is the fully qualified domain name of the recipient's system. Thus, if John Doe's system is named some-place.com, his complete e-mail address becomes jdoe@someplace.com. Given that, anyone on the Internet can send email to John Doe.

## How MUA and MTA work

There are two types of mail software.

- Mail-user agent (MUA) is the fancy name for a mail reader — a client that you use to read your mail messages, write replies, and compose new messages. Typically, the mail-user retrieves messages from the mail server using the POP3 or IMAP protocol. POP3 is the Post Office Protocol Version 3, and IMAP is the Internet Message Access Protocol Version 4. Fedora Core comes with mail-user agents such as Thunderbird, Mozilla, and Evolution.
- Mail-transport agent (MTA) is the fancy name for a mail transport that sends and receives mail-message text. The exact method used for mail transport depends on the underlying network. In TCP/IP networks, the mail-transport agent delivers mail using the Simple Mail-Transfer Protocol (SMTP). Fedora Core includes send, a powerful and popular mail-transport agent for TCP/IP networks.

The scenario in Figure-1 is typical of most people. Alice and Bob both connect to the Internet through an ISP and get and send e-mail through their ISPs. When Alice types a message and sends it, her mail-user agent (MUA) sends the message to her ISP's mail-transfer agent (MTA) using the Simple Mail-Transfer Protocol (SMTP). The sending MTA then sends that message to the receiving MTA — Bob's MTA — using SMTP. When Bob connects to the Internet, his MUA downloads the message from his ISP's MTA using the POP3 (or IMAP4) protocol. That's how mail moves around the Internet — from sending MUA to sending MTA to receiving MTA to receiving MUA.

## Mail message enhancements

Mail messages used to be plain text (and most still are), but many messages today have much more than two. Two new features of today mail are:

- **Attachments**: Many messages today include attached files, which can be anything from documents to images. The recipient can save the attachment on disk or open it directly from the mail reader. Unfortunately, attachments are one way hackers try to get viruses and worms into your PC. (If it's any consolation, most Windows-based viruses and worms do not work in Linux.)
- **HTML**: Mail messages can be in HTML (HyperText Markup Language), the language used to lay out Web pages. When you read an HTML message on a capable mail reader, the message appears in its full glory with nice fonts and embedded graphics.

![](img/d9230b719dc0efd80851f363d8c6f571_365_2.png)

While HTML messages are nice, they don't appear right when you use a text-based mail reader. In a text mail reader, HTML messages appear as a bunch of gobbledygook (which is just the HTML code).

## Taking Stock of Mail Readers and IM Clients in Fedora Core

If you have an ISP account, all you need is a mail client (excuse me, mail-user agent) to access your e-mail. In this case, your e-mail resides on your ISP's server and the mail reader downloads mail when you run. You have to do some setup before you start reading mail from your ISP's server. The setup essentially requires you to enter information from your ISP — the mail server's name, server type (POP3, for example), your username, and your password.

Setup Assistant guides you through the following:

1. Enter your name and e-mail address in Identity screen and click Forward.
2. Set up the options for receiving-mail and click Forward: Select the type of mail download — POP or IMAP. Then provide the name of the server (for example, mail.comcast.net).
3. Provide further information about receiving-mail — how often to check for mail and whether to leave messages on the server — then click Forward.
4. Set up the options for sending-mail and click Forward:
- Select the server type as SMTP.
- Enter the name of the server such as smtp.comcast.net.
5. Indicate whether you want this e-mail account to be your default account, and, if you want, give this mail account a descriptive name; click Forward.
6. Set your time zone by clicking a map; click Forward.
7. Click Apply to complete the Evolution setup.
