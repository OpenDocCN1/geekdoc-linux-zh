## How to Become root

You have to log in as root to perform the system administration tasks. The root user is the superuser and the only account with the privileges needed to do anything in the system.

Common wisdom says you should not normally log in as root. When you're root, one mistake and you can easily delete all the files — especially when typing commands. Take, for example, the command `rm *.html` that may type to delete all files that have the .html extension. If you accidentally press the space after the asterisk (*)? The shell tells you the command to be `rm *.html` and — because * causes any filename deletes everything in the current directory. Seems implausible until it happens to you!

## Using the su - command

If you're logged in as a normal user, how do you do any administration changes? Well, you become root for the time being. If you're working at a terminal window or console, type

```
su
```

Enter the root password in response to the prompt. From this point, you're root. Do whatever you have to do. To return to your usual self, type

```
exit
```

That's it! It's easy.

## Recovering from a forgotten root password

To perform system-administration tasks, you have to know the root password. What if you forget the root password? Not to worry: Just reboot the PC and you can reset the root password by following these steps:

- 1. Reboot the PC (select Reboot as you log out of the GUI screen) or power up as usual. Soon you see the graphical GRUB boot loader screen that shows the names of the operating systems you can boot.
- 2. If you have more than one operating system installed, use the arrow key to select Fedora Core as your operating system. Then press the A key. GRUB prompts you for commands to add to its default boot command.
- 3. If you see the word rhgb, press Backspace to delete it and then press the spacebar, type the following, and then press Enter:
`single`
Linux starts as usual but runs in a single-user mode that does not require you to log in. After Linux starts, you see the following command prompt:
`sh-2.05b#n4`. Type the passwd command to change the root password as follows:
`sh-2.05b# password`
Changing password for user root.
New password:

- 6. Type the new password again, and press Enter.

To check the current run level, type the following command in a terminal window:

```
/sbin/runlevel
```

The runlevel command prints an output like this:

```
N 5
```

The first character of the output shows the previous run level (N means no previous run level), and the second character shows the current run level (5). In this case, the system started at run 5.

You can change the default run level by editing a line in the /etcabb file. The initial run level is 3 for text-mode and 5 for graphical login.

## Examining the /etc/inittab file

The /etc/inittab file is the key to understanding the processes that init at various run levels. You can look at the contents of the file by using the more command, as follows:

```
more /etc/inittab
```

To see the contents of the /etc/inittab file with the more command, you don't have to log in root.

To interpret the contents of the /etc/inittab file, follow these steps:

- 1. Look for the line that looks like this:
  `id:5:initdefault:`
  That line shows the default run level. In this case, it's 5.
- 2. Find all the lines that specify what init runs at run level 5. Look for a line that has a 5 between the two colons (:). Here are the relevant lines:
  `15:5:wait:/etc/rc.d/rc 5`
  `x:5:respawn:/etc/X11/prefdm -nodaem`
The first line specifies that init executes the file /etc/rc.d/rc with 5 as an argument. The second line causes init to run /etc/X11/prefdm, a shell script that starts the graphical display manager, in turn, displays the graphical login dialog box that enables you to log in to the system.

## Examining the /etc/inittab file

The /etc/inittab file is the key to understanding the processes that init at various run levels. You can look at the contents of the file by using the more command, as follows:

```
more /etc/inittab
```

To see the contents of the /etc/inittab file with the more command, you don't have to log in root.

To interpret the contents of the /etc/inittab file, follow these steps:

- 1. Look for the line that looks like this:
  `id:5:initdefault:`
  That line shows the default run level. In this case, it's 5.
- 2. Find all the lines that specify what init runs at run level 5. Look for a line that has a 5 between the two colons (:). Here are the relevant lines:
  `15:5:wait:/etc/rc.d/rc 5`
  `x:5:respawn:/etc/X11/prefdm -nodaem`
The first line specifies that init executes the file /etc/rc.d/rc with 5 as an argument. The second line causes init to run /etc/X11/prefdm, a shell script that starts the graphical display manager, in turn, displays the graphical login dialog box that enables you to log in to the system.

## Recovering from a forgotten root password

To perform system-administration tasks, you have to know the root password. What if you forget the root password? Not to worry: Just reboot the PC and you can reset the root password by following these steps:

Retype new password:

```
passwd: all authentication tokens updated successfully.
```
