# 326 Checking Out TCP/IP Networks

| Table 4-2 Meaning of Columns in the Kernel Interface Table |
| Column | Meaning |
| Iface | Name of the interface |
| MTU | Maximum Transfer Unit — the maximum number of bytes that a packet can contain |
| RX-OK, TX-OK | Number of error-free packets received (RX) or transmitted (TX) |
| RX-ERR, TX-ERR | Number of packets with errors |
| RX-DRP, TX-DRP | Number of dropped packets |
| RX-OVR, TX-OVR | Number of packets lost to overflow |

Another useful form of netstat option is t, which shows all active TCP connections. Following is a typical result of netstat -t on one Fedora Core:

```
netstat -t
Active connections (w/ servers)
Proto Recv-Q Send-Q Local Address Foreign Address State
tcp 0 0 dhcppc4:10 www.redhat.com:http ESTABLISHED
tcp 0 126 dhcppc4:net 192.168.0.6:138 ESTABLISHED
tcp 0 0 dhcppc4:4032 www.redhat.com:https
tcp 0 0 dhcppc4:4033 www.redhat.com ESTABLISHED
tcp 0 138 dhcppc4:net 192.168.0.6:128 ESTABLISHED
tcp 0 0 dhcppc4:ftp 192.168.0.6:1548 TIME_WAIT
```

In this case, the columns show the protocol (Proto); the number of bytes in the receive and transmit queues (Recv-Q, Send-Q); the local TCP port in hostname:service (Local Address); the remote port (Foreign Address); and the state of the connection.

Type netstat -a to see all TCP connections — both active and the ones Fedora Core system is listening to (with no connection established yet). For example, here is a typical output of the netstat -ta command:

