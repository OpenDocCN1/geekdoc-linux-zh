# Gnome Ghostview

Gnome Ghostview is a graphical application for viewing and printing PostScript or PDF documents. For a long document, you can view and print selected pages. You can also view the document at various levels of zooming in or out.

To run Gnome Ghostview, select Main Menu;PostScript Viewer from the GNOME or KDE desktop. The Gnome Ghostview window appears. In addition to the menu bar and toolbar along the top edge, a vertical divide splits the main display area of the window into two parts.

To load and view a PostScript document in Gnome Ghostview, select File;Open, or click the Open icon on the toolbar. Gnome Ghostview displays a file-selection dialog box. Use this dialog box to navigate the file system and select a PostScript ps file that comes with Ghostscript. For example, open the file tiger.ps in the /usr/share/ghostscript7/examples directory. If your system has a version of Ghostscript later than 7.07, you have to use the new version number in place of 7.0.

To open the selected file, click the Open Button in the file-selection dialog box. Gnome Ghostview opens the selected file, processes its contents, and displays the output in its window, as shown in Figure 4-9.

Gnome Ghostview is useful for viewing various kinds of documentation that come in PostScript format (these files typically have .ps extension in their names). You can also open PDF files (these files typically have .pdf extensions) in Gnome Ghostview.

In Fedora Core, most system-configuration files are text files. If you write any shell scripts or other computer programs, they're text files too. Sometimes you have to edit these files using programs designed for purpose: text editors. For example, you may need to edit files such as /etc/hosts, /etc/modprobe.conf, /etc/X11/xorg.conf, /etc/xinetd.d/telnet, and many more.

In this chapter, I introduce you to a few text editors — both the GUI editors and text-mode editors.

## Using GUI Text Editors

Each of the GUI desktops — GNOME and KDE — comes with GUI text editors (text editors that have graphical user interfaces).

To use the GNOME editor, select Main Menu Accessories/Text Editor from the GNOME desktop. You can open a file by clicking the Open button on the toolbar, which brings up the Open File dialog box. You can then change directories and select the file to edit by clicking the OK button.

The GNOME text editor then loads the file in its window. You can open more than one file and move them as you edit the files. Figure 5-1 shows a typical editing session with the editor.

In this case, the editor has three files — fstab, hosts, and innittab (all from the /etc directory) — open for editing. The filenames appear as tabs below the toolbar of the editor's window. You can switch among the files by clicking the tabs.

**Text-input mode** is what you get when you enter text. In this mode, anything you type is treated as text. To return to command mode, type a period (.).

To delete a line, use the command:
```
:d
```

To insert text before the current line:
```
:i
```

To append text after the current line:
```
:a
```

To replace the content of the current line:
```
:c
```

To quit and save changes. To quit without saving, use:
```
:q!
```

To search for a string:
```
:/string
```

After ed opens a file, the current line is the last line. To see the current line number, use the:

```

```
The editor responds by displaying that line.

```
:cdrom
```
The editor locates the line that contains the string and then displays it. That line becomes the current line.
