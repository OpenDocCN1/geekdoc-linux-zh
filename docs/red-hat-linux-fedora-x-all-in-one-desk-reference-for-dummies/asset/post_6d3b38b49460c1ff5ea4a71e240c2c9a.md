System administration refers to whatever has to be done to keep a computer running. If you're running Fedora Core at home or in a small office, you're most likely the system administrator. Fedora Core comes with quite few tools for performing system administration. I describe some of these in this chapter.

## Taking Stock of System Administration

So what are system administration tasks? More accurately, a system administrator's duties include:

- Adding and removing user accounts. You have to add new accounts and remove unnecessary accounts. If a user forgets the password, you have to change it.
- Managing the printing system. You have to turn the print queue on or off, check status, and delete jobs if necessary.
- Installing, configuring, and upgrading the operating system. You have to install or upgrade various utilities.
- Installing new software. You have to install software that comes in Red Hat Package Manager (RPM) files. You also have to download and unpack software that comes in source code and then build executable programs.
- Managing hardware. Sometimes you have to add new hardware and install drivers so devices work properly.
- Making backups. You have to back up files, either in a Zip drive or on tape.
- Mounting own file systems. When you want to access files on a CD-ROM (for example), you have to mount it on one of the directories in your Linux file system. You also have to mount floppy disks in both Linux and DOS format.
- Automating tasks. You have to schedule tasks to take place automatically or jobs for people to perform periodically.
- Monitoring performance. You may want to keep an eye on performance to see where the processor is spending most of its time and to see the amount of free and used memory.
- Starting and shutting down the system. Starting the system typically involves nothing more than powering up the PC. You have to take some care when you want to shut down your Linux system. If your system is set up for a graphical login screen, you can perform the shutdown operation by selecting a menu item from the login screen. Otherwise, use the `shutdown` command to stop all programs before turning off your PC's power switch.
- Monitoring status. If you have a network presence (whether a LAN, a DSL line, or cable-modem connection), you may want to check the status of various network interfaces and make sure your network connection is up and running.
- Setting up host and network security. You have to make sure that system files are protected and protect your system against attacks over the network.
- Monitoring security. You have to keep an eye on all intrusions, usually by checking the log files.
