# Configuring the FTP Server 643

+   - idle_session_timeout=600 is the time (in seconds) after which an idle session (refers to the situation where someone connects and does not do anything) times out vsftpd logs the user out.

+   - listen=YES allows vsftpd to listen for connection requests, and sequentially, in stand-alone mode. Set this option to NO if you want to run vsftpd under xinetd.

+   - local_enable=YES causes vsftpd to grant local users access to FTP.

+   - local_umask=022 means files FTP writes a permission of 644 (read access for everyone, but write access for owner only). You can set it by file permission mask setting you. For example, if you want no permissions for anyone but the owner, change this option to 077.

+   - Is_recursive_enable=YES enables vsftpd to recursively traverse directories using the ls -R command.

+   - nopriv_user=vsftpd identifies an unprivileged account that the FTP server can use.

+   - pam_service_name=vsftpd is the name of the Pluggable Authentication Module (PAM) configuration file that is used when vsftpd must authenticate a user. By default, the PAM configuration files are in the /etc/pam.d directory. That means vsftpd's PAM configuration file is /etc/pam/vsftpd.

+   - tcp_wrappers=YES enables access control through TCP wrapper that uses the files /etc/hosts.allow and /etc/hosts.deny (for more information about TCP wrapper, see Book VII, Chapter 3).

+   - userlist_deny=YES causes vsftpd to deny access to the users listed in the /etc/vsftpd.user_list. These users are not prompted for a password.

+   - write_enable=YES allows vsftpd to allow uploads to the host.

+   - xferlog_enable=YES turns on the logging of file downloads and uploads (always a good idea, but takes disk space).

+   - xferlog_file=/var/log/vsftpd.log specifies the full pathname of the vsftpd log file. The default is /var/log/vsftpd.log.

+   - xferlog_std_format=YES causes vsftpd to generate log files in a daemon format used by other FTP daemons.

# etc/vsftpd.ftusers file

The vsftpd server uses the Pluggable Authentication Module (PAM) to authenticate users when they try to log in (just as the normal login process uses PAM to do the job). The PAM configuration file for vsftpd is /etc/pam.d/vsftpd. That PAM configuration file refers to /etc/vsftpd.ftusers file like this:

```
auth required /lib/security/pam_listfile.so item=user-deny
file=/etc/vsftpd.ftusers sense=succeed
```
