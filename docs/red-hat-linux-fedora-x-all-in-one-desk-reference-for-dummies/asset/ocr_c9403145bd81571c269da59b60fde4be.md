Other important hardware in the system box includes the memory (RAM chips) and the hard drive — and one program has to run all this and get it to play nice: the operating system.

The operating system is software that manages all the hardware and runs other software at your command. You, the user, provide provide those commands by clicking menus and icons or by using some cryptic text. Linux is an operating system — as UNIX, Windows 98, Windows 2000, and Windows XP. The Linux operating system is modeled after UNIX; in its most basic, no-frills form, it also goes by the name Linux kernel.

The operating system is what gives a computer — any computer — its personality. You, can run Windows 98 or Windows XP on a PC — and on that same, you can also install and run Linux. That means, depending on which operating system is installed and running, the same PC can be Windows 98, Windows XP, or Linux system.

The primary job of an operating system is to load software (computer programs) from the hard disk (or other permanent storage) into the memory and get the CPU to run the programs. Everything you do with your computer is possible because of the operating system somehow freees up, the whole system freezes. You know how infuriating it is when your favorite operating system — maybe even the one that came with your PC — suddenly quits it just as you are about to click the Send button after composing e-mail to your friend. You try the three-finger swipe (pressing Ctrl+Alt+Del), but nothing happens. It’s time for the Reset button (provided your computer’s builders were wise to include one). Luckily, that of sort almost never happens with Linux — it has a reputation for being a very reliable system.

# Does Linux run on any computer?

Linux runs on many different types of computer systems — and it does seem able to run on any type of computer. Linux Torvalds and other programmers originally developed for the Intel 80x86 (and compatible) line of processors. Nowadays, Linux is also available for systems based on other processors — such as those with AMD’s 64-bit AMD64 processors, the Motorola 68000 family; Alpha AXPs; Sun

SPARCs and UltraSPARCs; Hewlett-Packard’s HP PA-RIS; the PowerPC and Power64 processors; and the MIPS R40 and R50. More recently, IBM has released its own version of Linux for S/390 mainframe. This book covers Linux for Intel 80x86 and Pentium processors (those that have in common a basic physical structure known as IA-32 architecture).
