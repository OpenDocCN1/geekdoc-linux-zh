# 344 Using Mozilla Mail

To read a message, the message in the upper window of the Inbox and the message text appears in the lower window.

To reply to the current message, click the Reply button on the toolbar. A message composition window pops up (as shown in Figure 1-5). You can write your reply and then click the Send button on the toolbar to reply. Simple, isn't it?

To send a new e-mail, click the New Message button on the Evolution toolbar. A new message composition window appears and you can type your message in that window, then click Send.

# Using Mozilla Mail

Mozilla Mail is the mail and newsreader that comes with Mozilla — Netscape Communicator. Mozilla is the open source successor to Netscape Web browser that also includes a mail and newsreader.
