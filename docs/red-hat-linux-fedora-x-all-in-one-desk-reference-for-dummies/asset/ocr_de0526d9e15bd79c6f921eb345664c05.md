1. What is GNOME?
GNOME is a desktop environment for Unix and Linux systems. GNOME includes a panel for launching applications and a desktop, where icons and applications can be placed. It is familiar and consistent with each user. Other operating systems or environments offer different approaches, such as Windows, FreeBSD, XFCE, and MDE.

GNOME is developed by hundreds of programmers around the world. The source code is free and many copies of GNOME are available for download on the internet. You can also find documentation for GNOME online, including the GNOME Wiki and Free Documentation. This is particularly useful

GNOME is highly customizable, so you can design how you want it to look and feel. GNOME supports many different themes, and GNOME events even support drag and drop protocols.

GNOME comes from the GNU Object Model Environment (GNOME). GNOME is a part of the larger project which provides a desktop environment for the Linux system. The desktop interface is the primary way to interact with the system.

This guide covers GNOME 2.2 which is the latest (as of March 2003) release of GNOME.
