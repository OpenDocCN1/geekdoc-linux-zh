# Selecting Keyboard, Mouse, and Installation Type

1. The installation program displays a list of languages that you can use for the rest of the installation. Use your mouse to select the language you want from the list and then click Next to the next step.

Each screen has help available on the left side of the screen. You can read the help message to find out more about what you're supposed to do in a specific screen.

2. The installation program displays a list of keyboard layouts, as shown in 2-1.

Select a keyboard layout suitable for your language's character set (for example, U.S. English in the United States) and then click Next to continue.

3. The installation program displays a screen from which you can configure the mouse in your system.

A treelike list shows the mouse types, organized alphabetically by manufacturer. You need to know your mouse type or the PS/2 port (the small, round connector). If the name of your mouse appears in the list, select it. Otherwise a generic mouse type. Most new PCs have a PS/2 mouse. For a two-button mouse, select the Elite Button. Because X applications assume you're using a three-button mouse, you can simulate a middle-button click (on a typical two-button click by pressing both buttons simultaneously. On a Microsoft Intellimouse, the wheel acts as the middle button). Click Next after selecting the mouse.

The installer tries to detect the monitor and displays a screen with the results, whether or not it detects the monitor correctly (see Figure 2-2).

4. If the Fedora Core installer displays a wrong monitor or a generic one as the choice, scroll through the list and pick the name of your monitor from the list.

(One good thing about monitors is that you can easily look up the make and model number on the back of the monitor).

5. The installation program displays a screen asking you want to install a new system or upgrade an older Fedora Core installation. For a new Fedora Core installation, click install. Then a screen (see Figure 2-3) prompts you for the installation.

For a new installation, you have to select the installation type — Personal Desktop, Workstation, Server, or Custom. The Personal Desktop, Workstation, and Server simplify the installation process by partitioning the disk in a predefined manner. The Personal Desktop installation creates a Fedora Core system for home, laptop, or desktop use. A graphical environment is installed with productivity applications.
