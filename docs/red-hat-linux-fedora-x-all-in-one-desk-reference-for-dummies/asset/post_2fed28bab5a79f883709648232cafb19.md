## ATA/ATAPI/MFM/RLL support

When you are configuring an operating system, you will have to expect a share of acronyms—this one has four: ATA, ATAPI, MFM, and RLL. All these relate to hardware or the interface that links disk drives to the PC. Here's what they mean:

## Rebuilding the Kernel 505

- ATA stands for Attachment and for the PC-AT style interface that connects hard drives and CD-ROM drives to the PC's motherboard.
- ATAPI stands for Attachment Packet Interface and refers to the original PC hard drives that integrate the disk controller onto the hard drive itself. This interface was called Integrated Drive Electronics or IDE. You typically use the terms IDE, ATA, ATA, and ATAPI interchangeably.
- MFM stands for Modified Frequency Modulation, the data was encoded on older hard drives. These drives can work over an IDE interface.
- RLL stands for Run Length Limited, an old technique for storing data on a hard drive from the early days of the PC. RLL disks can work over an IDE interface.

Enable the ATA/ATAPI/MFM/RLL option by clicking it until a check mark appears. When you enable this, you get many more configuration-options (see Figure 6-4) involving IDE devices, such as hard drives and ATAPI CD-ROM drives.

The first option is for enhanced IDE support, which refers to fully-featured IDE controllers that can control up to 10 IDE Interfaces. Each IDE face can be a master and a slave. Linux allows a total of up to 20 IDE devices (such as disks or CD-ROM drives). Make sure this option has a check mark.

## SCSI device support

SCSI stands for Small Computer Interfaces — a type of interface through which you can connect multiple devices (such as hard drives and scanners) to the PC. This set of options has to do with SCSI devices. If your system has a SCSI adapter, start by clicking the SCSI Support option to show a dot (which means a module is built). After that, you can set the options relating to the types of devices (disk, tape, CD-ROM) to the SCSI adapter. Finally, you must look in the low-level drivers category and enable support for the specific SCSI adapter model on your system.

## IEEE 1394 (FireWire) support

IEEE 1394 is a high-speed bus for connecting peripherals to PCs. Apple calls this bus FireWire; Sony calls it iLink. IEEE 1394 is similar to USB, but it can transfer data at rates up to 400Mbps, which is more than 30 times the data rate of the older USB version 1.1 (note that USB 2.0 is even faster; it can transfer data at rates of up to 480Mbps). Because of its high data-transfer rates, IEEE 1394 is ideal for connecting high-speed peripherals as digital audio and video devices and external hard drives to the PC.

You can build a module for the IEEE 1394 bus. Currently, Linux supports IEEE 1394 chipsets that are compatible with Texas Instruments PCILynx/PCILynx2 and OHCI chipsets. If your PC has an IEEE 1394 adapter, you can build the necessary drivers through these options.

To find out more using IEEE 1394 peripherals in Linux, visit the site of the IEEE 1394 for Linux project at www.linux1394.org.

## I2O device support

Pronounced eye-to-oh, I2O refers to Intelligent Input/Output — a new device driver architecture independent of the operating system and the controlled device. The basic concept of I2O is to separate the part responsibility for managing the device from the part that contains operating specific details (it's called the I2O Split Driver model). Two parts of an I2O driver are the OS Services Module (OSM), which works with the operating system, and the Hardware Device Module (HDM) that interfaces with the particular device driver manages. The OSM and HDM communicate by passing messages to each other. Linux comes with some I2O drivers for SCSI and PCI devices. You can configure these drivers from this category of options.

## ISDN subsystem

This of options enables you to include support for ISDN (Integrated Services Network) — a digital telephone line you can use to connect the Linux system to the Internet. These ISDN-related options include the configuration of specific ISDN adapters.

Build the ISDN driver only if your PC has an ISDN card. If you anticipate adding an ISDN card and purchase ISDN service from the phone company, you can build the driver as a module. Read the file /usr/src/linux/Documentation/isdn/README for more information on how to set up and use the ISDN driver in Linux.

## Telephony support

With the right hardware and software, the Telephony Support options enable you to use the Fedora Core system for making calls calls (also known as voiceover ip or VoIP). You can build driver modules for telephony support if you have a telephony card, such as the Internet PhoneJACK or LineJACK manufactured by Quicket Technologies, Inc. If you have no Quicket telephony cards, you can safely leave these options turned off.
