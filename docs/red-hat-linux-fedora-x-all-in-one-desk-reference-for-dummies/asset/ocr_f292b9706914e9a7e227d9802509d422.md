# 416 Viewing System Information via the proc File System

Notice a very large file named /proc/kcore; that file represents the entire physical memory of your system. Although /proc/kcore appears in the listing as a huge file, no single physical file is occupying that space on your hard drive — don't try to remove the file to reclaim disk space.

Several files and directories in /proc contain interesting information about your Fedora Core PC. The /proc/cpuinfo file, for example, lists the key characteristics of your system, as processor type and floating-point processor information. You can view the processor information by typing cat /proc/cpuinfo For example, here is what I get when I type cat /proc/cpuinfo on my system:

```
processor : 0
vendor_id : GenuineIntel
cpu family : 15
model : 2
model name : Mobile Intel(R) Celeron(D) CPU 1.50GHz
stepping : 7
cpu Mhz : 1496.271
cache size : 256 KB
fdiv_bug : no
hlt_bug : no
f00f_bug : no
coma_bug : no
fpu : yes
fpu_exception : yes
cpuid level : 2
wp : 
flags : vme de pse pse mr pae cxe8 sep mtr
fxsr sse sse2 ss ht mbe pbi cbd
bomips : 2957.31
```

This output is from a 1.5 GHz Celeron. The listing shows many interesting characteristics of the processor. Notice the line that starts with fdiv_bug. Remember the Pentium floating-division bug? The bug is in an instruction called fdiv (for floating-point division). Thus the fdiv_bug line indicates whether this particular Pentium has the bug (fortunately, my PC's processor does not).

The last line in the /proc/cpuinfo file shows the BogMips for the processor, as computed by the Linux kernel when it boots. BogMips is used internally to time-delay loops.
