# 442 Learning the Linux File System

To unmount a device when you no longer need it, use the umount command. For example, to unmount the DVD/CD-ROM device, type

```
umount /dev/cdrom
```

The umount command succeeds as long as no one is using the DVD/CD-ROM. If you get an error when trying to unmount the DVD/CD-ROM, check to see whether the current working directory is on the DVD or CD. If you're currently working in one of the DVD/CD-ROM's directories, that also qualifies as a use of the DVD/CD-ROM.

# Examining the /etc/fstab file

The mount command has the following general format:

```
mount device-name mount-point
```

However, you can mount the CD-ROM by typing one of the following

```
mount /dev/cdrom
mount /mnt/cdrom
```

![](bbox=[0.142, 0.506, 0.213, 0.563])

You can mount by specifying only the CD-ROM device name or the mountpoint because of what's in a file named /etc/fstab. A line is in /etc/fstab for the /mnt/cdrom mount point. That entry specifies the CD-ROM device name and the file-system type. That's why you can mount the CD-ROM with a shorter mount command.

The /etc/fstab is a configuration file — a text file containing information that the mount and unmount commands use. Each line in the /etc/fstab file provides information about a device and its mount point in the Linux system. Essentially, the /etc/fstab associates various mount points within the file with specific devices, which enables the mount to work from the command line with only the mount point or the device.

Here is a /etc/fstab file from Fedora Core:

| LABEL=-/ | ext3 defaults 1 1 |
| LABEL=/boot | /boot ext3 defaults 1 2 |
| | /dev/pts devpts gid=mode=620 0 0 |
| | /dev/shm tmpfs defaults 0 0 |
| none | /proc procfs defaults 0 0 |
| none | /sys sysfs defaults 0 0 |
| /dev/hda6 | swap defaults 0 0 |
| /dev/cdrom | /mnt/cdrom udf.iso9660 auto,owner,kudzu.ro 0 0 |
| /dev/fd0 | | auto,owner,kudzu.ro 0 0 |
| /dev/cdrom1 | /mnt/cdrom1 udf.iso9660 auto,owner,kudzu.ro 0 0 |
