# Using Yellow dog Updater, Modified (Yum) 475

+   1. Log in as root, and choose Main Menu::System Tools Red Hat Network. You can also type update in a terminal window.

The Red Hat Update Agent starts, and if you're Update for the first time, a dialog box prompts you to install a public key in your GPG key ring (GPG referring to GNU Privacy Guard or GnuPG, a program for encrypting, decrypting, and signing e-mail and other data using the OpenPPG standard.) That public GPG key verifies that the package developer has secured the package that Update has downloaded. If prompted to do so, click Yes to install the public key.

+   2. Update displays a window with a welcome message. Click the Forward button to proceed.

+   3. Update displays a list of what it calls channels—repositories where the agent downloads package headers. Click Forward to continue.

By default, the Update Agent uses a channel that works with Yum — a command-line package updater/installer I describe in the next section. The sections are identified in the configuration file /etc/sysconfig/rhn/sources. Besides Yum, the Update can also access repositories for Apt — another package updater.

After you click Forward, Update figures out what needs to be updated and retrieves a list of all headers from the specified channel.

+   4. Update downloads the headers, and displays a list of packages. You can scroll through the list and pick the packages you want to update; click the box to the left of a package's name to select it. Click Forward to continue.

Update then checks for any package dependencies and begins downloading the packages. Progress bars show the status of the download.

+   5. After the download finishes, click the Forward button to proceed with the installation.

+   6. Update displays progress bar as it installs each update. Click the Forward button when the installation is complete.

Update displays a message about the package(s) it installs successfully.

+   7. Click the Finish button to exit Update.
