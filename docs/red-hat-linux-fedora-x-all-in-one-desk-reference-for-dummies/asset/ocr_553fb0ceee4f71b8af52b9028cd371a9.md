# Installation Type

Choose the type of installation that will meet your needs.

An installation will destroy any previously saved information on the selected partitions.

For more information concerning the differences among these classes, refer to the product documentation.

| | |
|---||
| Personal Desktop | Perfect for personal computers or laptops, select this installation to install a graphical desktop environment and create a system ideal for home use.
| Workstation | This system installs a graphical desktop environment with tools for software development and system administration.\n| Server | Select this installation if you would like to set up sharing, printing, or web services. Additional servers can also be enabled, and you can choose whether or not to install a graphical environment.
| Custom | Select this installation type to gain complete control over the installation process, including software package selection and partitioning.|

A Workstation-class installation installs a graphical environment as well as software development tools. This type of installation also deletes all existing Linux-related partitions, creating a set of new partitions for Linux.

A Server-class installation deletes all disk partitions, including any Windows partitions, and creates a sleek of Linux partitions. Server-class installation does not install the graphical environment.

For maximum flexibility, select the Custom installation. That way you can select only the packages you want to try out.

The next major phase of installation involves partitioning the hard disk use in Fedora Core.
