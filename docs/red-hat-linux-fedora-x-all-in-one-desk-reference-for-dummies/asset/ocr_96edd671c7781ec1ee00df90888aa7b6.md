# Use These Steps

Choose Edit->Find & Replace or press Ctrl+F. In the dialog
box, enter the text to find, including any formatting, and enter
t replacement text, if any. Then click Find or Replace
dending on whether you want to find text or want
to find and replace with new text.

Select the blocks of text while holding the Ctrl key.
Another way is to click STD on the status bar until it
ADD and then select each block of text by one.

Choose the position and click Insert-> Special Character.
Select the font and character to insert.

Select the text. Choose Format->Character and click the Font
Tabs in the resulting dialog box. Choose Title from the
effect drop-down list.

Hold the Alt key and click the hyperlink. Now you can
edit the hyperlink.

Click in the paragraph and press Ctrl+@up or Ctrl+-
move the paragraph up or down.

Choose Edit->Change->Record to turn the check mark on
off. When the check is on, Writer tracks changes.

Choose Edit->Change->Show to show the check mark on
off. When the check is on, Writer displays the changes
with revisions mark.

Make the change, choose Edit->Change->Comment,
then enter your comment in the dialog box that appears.

Choose Insert->Note and use the text in the dialog box that
appears.

Choose File->Print. In the Printing dialog box, click the list of
printers and select PDF Converter from the drop-down list.
Click OK.

Choose File->Versions. From the resulting dialog box, select
Save New Version. You can create new versions only after
to save the document.

Choose File->Versions and select the version to open from
dialog box. Click Open.

Choose Edit->Change->Merge Document. From the result
Inserting dialog box, select the document with which you
want to merge the current document.

Choose Edit->Change->Accept or Reject and then accept
reject changes from the list that appears in a dialog box.

Choose Edit->AutoText or press Ctrl+F3. Then enter the
and shortcut.
