# Declaration and Definition of Variables

In C, you must define or declare all variables and functions before you use them. The definition of a variable specifies three things:

+   * *visibility*, which indicates exactly where the variable can be used. (Is it defined for all files in a program, the current file, or only in a function?)
* *lifetime*, which determines whether the variable exists temporarily (for example, a local variable in a function) or permanently (as long as the program is running).
* *Its type* (and, in some cases, its initial value). For example, an integer variable x initialized to 1 is defined this way:

```
int x = 1;
```

If you're using a variable defined in another source file, you declare the variable with an `extern` keyword, like this:

```
extern int message_count;
```

You must define this variable without the `extern` qualifier in at least one source file. When the program is built, the linker resolves all references to the `message_count` variable and ensures that they all use the same variable.

# Basic data types

C has four basic types: `char` and `int` are for storing characters and integers, `float` and `double` are for floating-point numbers. You can define variables for these basic data types in a straightforward manner:

```
c:
int j, bufsize;
float volts;
double mean, variance;
```
