## Creating and inserting graphics

Writer includes a drawing toolbar with tools that you can use to draw in the document. You can also insert into your document both line drawings and images from files many different formats.

To create diagrams in your document, click the Show Draw Functions icon (on the toolbar on the left side of the Writer window). The Draw Functions toolbar appears, as shown in Figure 1-9.
