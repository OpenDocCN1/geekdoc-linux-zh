## Commands for directory navigation

In Linux, when you log in as root, your home directory is /root. For other users, the home directory is usually in the /home/directory. My home directory (when I log in as naba) is /home/naba. This information is stored in the /etc/passwd file. By default, you only have permission to save files in your home directory, and only you can create subdirectories in your home directory to further organize files.

Linux supports the concept of a current directory, which is the directory on which all file and directory commands operate. After you log in, your current directory is the home directory. To see the current directory, type the pwd command.

To change the current directory, use the cd command. To change the current directory to /usr/share/doc, type the following:

```
cd /usr/share/doc
```

Then, to change the directory to the bash-2.05b subdirectory in /usr/share/doc, type this command:

```
cd bash-2.05b
```

Now, if you use the pwd command, that command shows /usr/share/doc/bash-2.05b as the current directory.

These two examples show that you can refer to a directory's name in two ways:

- An absolute pathname (such as /usr/share/doc) that specifies the exact directory in the directory tree
- A relative directory name (such as bash-2.05b), which represents the bash-2.05b subdirectory of the current directory, whatever that may be)

## ## Commands for directory listings and permissions

You can get a directory listing using the `ls` command. By default, the `ls` command — without any options — displays the contents of the current directory in a compact, multicolumn format. For example, type the next two commands to see the contents of the `/etc/X11` directory:

```
ls /etc/X11
```

The output looks like this (on the colors) you see some items in different colors):

| appink tbproxy starthere xdm Xmodmap xsm |
| dm predef systemconfig xftConfig.README-OBSLETE xorg.conf |
| fs proxymgr twm init Resources |
| gdm serverconfig X xkb serverver |

From this listing (without the colors), you cannot tell whether an entry is a file or a directory. To tell the directories and files apart, use the `-F` option with `ls` like this:

```
ls -F
```

This listing shows considerable information about every entry — each of which is a file. The date and time show when last modifications were made. The size of the group owner indicates the size. Finally, the leftmost column shows the permission settings, which determine who can read, write, or execute the file. The first letter of the leftmost column has a special meaning, as the following list shows:

- If the first letter is l, the file a link (a shortcut)
- If the first letter is d, the file is a directory.
- If the first letter is a dash (-), the file is normal.
- If the first letter is b, the file represents a block device, such as a disk drive.
- If the first letter is c, the file represents a character device, such as a serial port or a terminal.

After that first, the leftmost column shows a sequence of characters, which appear as rwxrwx. Each letter indicates a specific permission. A hyphen (-) in place of letters indicates no permission for a specific operation on the file. Think of these nine letters as three groups of letters (rwx), interpreted as:

- The leftmost group of rwx controls the read, write, and execute permission of the file's owner. In other words, if you see rwx in this position, the file's owner can read (r), write (w), and execute (x). A hyphen in place of a letter indicates no permission. The string rw- means the owner has read and write permission but no execute permission. Although executable programs (including shell programs) typically have execute permission, directories require execute permission on a directory before he or she can open and read the contents of the directory.
- The middle three rwx controls the read, write, and execute permission of any user belonging to that file's group.
- The rightmost group of rwx controls the read, write, and execute permission of all other users (collectively referred to as the world).

Thus, a file with the permission setting rwx------ is accessible only to the file's owner, whereas the permission setting rwx--r-- makes the file readable by the world.

An interesting feature of the ls command is that it does not list any file whose name begins with a period. To see these files, you must use the ls -a option, as follows:

```
ls -a
```
