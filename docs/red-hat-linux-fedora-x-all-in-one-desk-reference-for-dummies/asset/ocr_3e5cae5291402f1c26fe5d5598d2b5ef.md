# 170 Taking Stock of the Fedora Core Applications

| Table 4-1 A Sampling of Fedora Core Applications |
| --- | --- |
| Application | Description |
| Office Applications | |
| OpenOffice.org Writer | A word-processing program similar to Microsoft Word (www.office.org) |
| OpenOffice.org Calc | A spreadsheet program similar to Microsoft Excel (www.openoffice.org) |
| OpenOffice.org Impress | A presentation application similar to Microsoft PowerPoint (www.openoffice.org) |
| OpenOffice.org Draw | A drawing program (www.openoffice.org) |
| OpenOffice.org Math | An editor for writing mathematical equations, which you can then include in OpenOffice Writer documents (www.openoffice.org) |
| Dia | A drawing program, designed to be like the Windows application called Visio (gnome.org/gnome/dia.shtml) |
| Office Tools | |
| GNOME Calculator | A simple calculator |
| Kcalc | A calculator (part of KDE) |
| Aspell | A text-mode spell checker (aspell.sourceforge.net) |
| Dictionary | A graphical client for the dict dictionary server so you can look up words |
| Database | |
| PostgreSQL | A sophisticated object-relational database-management system that supports Structured Query Language (SQL) (www.postgresql.com) |
| MySQL | A popular relational database-management system that supports SQL (www.mysql.com) |
| Multimedia | |
| GNOME CD Player | An audio CD player (needs a working sound card) |
| KSD | Audio CD player from KDE (needs a working sound card) |
| Rhythmbox | A multimedia audio player that can play different sound formats (rhythmbox.sourceforge.net) — including MP3 files if you download a plugin for the purpose |
| X Multimedia System — a multimedia audio player that can play many different sound formats (www.xmms.org) — including MP3 files if you download a plugin for the purpose XMMS is not installed by default, but you can install it easily from the companion DVD |
