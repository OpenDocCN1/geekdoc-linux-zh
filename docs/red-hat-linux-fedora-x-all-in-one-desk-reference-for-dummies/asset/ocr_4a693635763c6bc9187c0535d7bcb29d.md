# Delivering presentations

After you prepare a spectacular set of slides, you have to deliver it to your audience. Delivering presentations typically involves tasks such as preparing speaker' notes, running a slide show, converting the presentation into HTML delivery via the Web, and printing handouts. Table 3-3 summarizes some common presentation tasks.

You can also export an Impress presentation directly to an Adobe Portable Document Format (PDF) file. PDFs make electronically sharing with everyone as easy as anyone can view and print PDF files using the free Adobe Reader (available at www.adobe.com/products/acrobat/readstep.html).

![](bbox=[0.143, 0.273, 0.213, 0.333])

| Table 3-3 | Common Presentation Delivery Tasks |
|---|---|
| To Do This | Follow These Steps: Choose View:Master* Handout. The master handout that gets used as the background for all the handouts. |
| Prepare handouts | Choose View:Master* View:Handout. The view shows the handout page with a number of slides per page. To change the layout, right-click the handout and choose Slide* from the pop-up menu. Select the layout (how many slides per page of handout) you want |
| Print handouts | Choose View:Master* View:Handout. Choose View:File*:Print |
| Run a slide show | Choose Slide Show*:Slide Show, or press Ctrl+F2. To advance through slides. Press Esc to stop the slide show or at the last click to end |
| Create a custom slide show | Choose Slide Show*:Custom Slide Show. New in the Custom Slide window. Assign a name and select the slides you want in the show, in the order you them to appear. Drag the slides up or down to change that order. Click OK and then close |
| Run a custom slide show | Choose Slide Show*:Custom Slide Show. Select the custom slide (you see the name you used when creating the slide show). Turn on the Use Slide Show check box and then Start |
| Print the slides to a PDF file | Choose File*:Export as PDF. In the Export dialog box, enter the filename. Click OK |
| Create an HTML version of the presentation | Choose File*:Export. In the Export dialog box, enter a filename and select Web Page as the format. Go through the HTML Export steps, select the file type you want (for example, HTML with or without frames) as well as the format for the images (JPEG or GIF) to represent each slide |
