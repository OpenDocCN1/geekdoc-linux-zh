# Creating and accessing Perl objects

An especially useful object is the Shell object, which is implemented by the Perl module Shell.pm. That module comes with the Perl distribution and is in `/usr/lib/perl/5.8.3` (for Perl Version 5.8.3).

As the name implies, the Shell object is meant for running shell commands from within Perl scripts. You can create a Shell object and have it execute commands.

To use the Shell object, follow these general steps:

+   1. Place the following line to include the Shell module in your program:
   use Shell;
nYou must include this line before you create a Shell object.

+   2. Create a Shell object, use the following syntax:
   my $sh = Shell->new;
   where $sh is the reference to the Shell object.

+   3. Run Linux commands using the Shell object and capture any outputs by saving to an appropriate variable. For example, to save the directory listing of the `/usr/lib/perl/5.8.0` in an array named `@modules`;
   @modules = \$sh->ls(\`/usr/lib/perl/5.8.0/*");

Then you can work with this array of Perl filenames (that's what *.pm are) in any way you want. For example, simply go through the array and print each string out, use the following while loop:

```
while(@modules) {
  $mod = @modules;
  # Do whatever you want with the module
  print $mod;
}
```

How do you know which methods to call and in what order to call them? You have to read the object's documentation before you can use the object. The method names and the sequences of method invocation depend on what the object does.
