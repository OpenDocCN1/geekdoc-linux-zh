# Using Impress 259

| Table 3-2 Common Graphics and Special Effects Tasks |
|---|---|
| To Do This | Follow These Steps |
| Draw in a slide | Select the drawing tools from the toolbar on the left side of the Impress window and draw the slide using the mouse. You can also add text and draw callouts (a text box with a line pointing to something you are trying to explain). |
| Apply text effects | Choose Format->FontWork. Select the text and use the FontWork to apply special effects to the text, such as placing text on a curve and showing a shadow. |
| Convert text or graphics to 3D | Right-click the object and choose Convert-> 3D. For text, make sure that you click the frame, and not the text itself. |
| Insert graphics from a file | Choose Insert->Graphics and select the graphics you want to insert. |
| Add a chart | Choose Insert->Chart to insert a dummy chart. Right-click the chart and select Chart Data. The dummy data appears in a mini-spreadsheet window. Edit the data to change the chart type, right-click and select Chart Type. Then pick a chart type from the resulting dialog box. |
| Adding graphics to a slide | Choose Insert->Graphics to select a file to insert. |
| Insert a prepared drawing in Draw | Choose Insert->OLE Object. In the resulting dialog box, choose from File->Search. Search the drawing from the Open dialog box and click OK to insert the drawing from the file. Double-click the drawing to edit it later. |
| Insert a formula | Choose Insert->Object->Formula. The OpenOffice Math window appears. Use the Formula Selection to construct the formula and adjust the font size. As you construct the formula, it appears in the slide. Click anywhere else in the slide to return. Double-click the formula to edit it |
| Apply effects on objects in a slide | Choose Slide Show->Effects to the effects window. Choose View->Preview so you can see the effects in a preview window as you work. Select the object you want to apply an effect, select the effect from the window, and click the green check mark. Observe the effect in the preview window. Stop when you like the effects. Apply effects to others if needed |
| Control how slides transition | Choose Slide Show->Slide Transition to open the Slide Transition window. Choose View->Preview so you can see the effect of a transition in a small preview window as you apply each transition. Select a transition from the Slide Transition window, and click the green check mark. Observe the effect in the preview window. Stop when you like the effects. Apply transition effects to others as needed.
