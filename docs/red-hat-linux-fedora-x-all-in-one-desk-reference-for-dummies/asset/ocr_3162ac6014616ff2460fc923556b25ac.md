# Understanding wired equivalent privacy (WEP)

The 802.11 standard includes the Wired Equivalent Privacy (WEP) for protecting wireless communications from eavesdropping. WEP relies on a 40-bit or 104-bit secret key that is shared between mobile station (such as a laptop with a wireless Ethernet card) and an access point (also called a base station). The secret key is used to encrypt data packets before they transmit and an integrity check performs to ensure that packets are not modified in transit. The 802.11 standard does not explain how the key is established. In practice, most wireless WLANs use a single key that is shared between all mobile stations and access points. Such an approach, however, does not scale up well to an environment such as a college campus because the key is shared with all users — and you know how it is to share a “secret” with hundreds of people. That is why WEP is typically not used on large wireless networks like the ones at universities. In such wireless networks, you can use other secure approaches such as SSH (Secure Shell) to log in to remote systems. WEP, however, is good to use on your home wireless network.

WEP has its weaknesses, but it is better than nothing. You can use it in smaller WLANs where sharing the key among all wireless stations is not an onerous task.

Work is underway to provide better security than WEP for wireless networks. The soon-to-be-finalized 802.11 standard uses public-key encryption along with an authentication, authorization, and accounting on a RADIUS (Remote Authentication Dial-In User Service) server — to provide better security for wireless Ethernet networks.

The 802.11 standard is in progress, the Wi-Fi Alliance consortium that supports Wi-Fi has developed WiFi Protected Access (WPA) that’s a precursor to 802.11. WPA replaces the WEP standard and improves security by making some changes. For example, unlike WEP (which uses fixed keys), the WPA uses Temporal Key-Integrity Protocol (TKIP), which generates new keys for every 10K of data transmitted over the network. TKIP makes WPA more difficult to break. You may want to consider wireless products that support WPA while waiting for products that implement 802.11i.
