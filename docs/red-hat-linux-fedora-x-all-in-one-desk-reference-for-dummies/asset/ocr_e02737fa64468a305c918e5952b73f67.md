If you change the set for /etc/mail/sendmail.cf file, you must change
t /etc/mail/sendmail.cf file by running the sendmail.cf file through
t m4 macro processor with the following command (you have to log in as
root):

m4 /etc/mail/sendmail.mc > /etc/mail/sendmail.cf

The comments also tell you that the sendmail-cf package to
this file.

From the previous section's description of m4 macros, you can see that
sendmail.cf file use define to create new macros. You can also see the
leral use of dnl to avoid inserting too many lines into the output.

The other uppercase words (such as OTYPE, FEATURE, and MAILER) are
sendmail macros. These are defined in the m4 files in the subdire-
tories of the /usr/share/sendmail-cf directory and are incorporated into
sendmail.cf file with the following macro:

```
include('/usr/share/sendmail-cf/m4/cf.m4')dnl
```

The /usr/share/sendmail-cf/m4/cf.m4 file, in turn, includes the cfhead.
m4 file, which includes other m4 files, and so on. The net effect is that the
m4 processor processes the sendmail.cf file, the macro processor
incorporates many m4 files from various subdirectories of /usr/share/
sendmail-cf.
