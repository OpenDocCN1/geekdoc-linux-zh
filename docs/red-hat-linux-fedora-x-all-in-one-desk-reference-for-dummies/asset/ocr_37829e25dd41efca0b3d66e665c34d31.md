# 340 Taking Stock of Mail Readers and IM Clients in Fedora Core

If you have an ISP account, all you need is a mail client (excuse me, mailuser agent) to access your e-mail. In this case, your e-mail resides on your ISP's server and the mail reader downloads mail when you run. You have to do some setup before you start reading mail from your ISP's server. The setup essentially requires you to enter information from your ISP — the mail server's name, server type (POP3, for example), your username, and your password.

# Taking Stock of Mail Readers and IM Clients in Fedora Core

Time was when most mail readers were text programs, but times have changed. New mail readers are graphical applications capable of displaying HTML messages and handling attachments with ease. They are easy to use. If you can work with one, you can use any of the graphical mail readers. Fedora comes with several mail readers.

IM (instant messaging) is a more recent phenomenon, but Fedora Core tries to stay on top of things, so it comes with two AOL clients. Table 1-1 gives an overview of the mail readers and IM clients in Fedora Core.

| Table 1-1 | Fedora Core Mail Readers and AIM Clients |
| Software | Description |
| KMail | The KDE e-mail client that supports both POP3 and IMAP |
| Mozilla Mail | A mail client as well as a newsletter, part of the Mozilla open-source web browser (open incarnation of Netscape Communicator) |
| Xian Evolution | A personal information manager (PIM) that includes e-mail, calendar, contact management, and an online task list |
| Gaim | An IM for GNOME that supports a number of instant-messaging protocols such as AOL IM, ICQ, Yahoo!, MSN, Gadu-Gadu, and Jabber |
| Kit | An AOL IM client for KDE |
