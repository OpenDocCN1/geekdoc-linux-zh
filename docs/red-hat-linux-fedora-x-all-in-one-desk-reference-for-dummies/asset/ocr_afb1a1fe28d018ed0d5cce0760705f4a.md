# ## Joining the BitTorrent

BitTorrent is a protocol for distributing files. You don't really need to understand the protocol to use BitTorrent. All you need to know is that you download a file, your machine uploads the file to others who know the same file. You are not just taking something, you are also giving something—you are helping others get that file without overloading the server from which you started the file. That communal sharing in an equitable manner is what makes BitTorrent an appealing way to distribute software as Fedora Core. In fact, once you try it, you'll find that downloading Fedora Core is easier by joining the BitTorrent than getting it through FTP from a central server. You do have to do a few things before you start using BitTorrent. It's a neat little project to download the CD- or DVD-image of Fedora Core and burn the CD (or DVD). The first project is to join the BitTorrent and download the necessary files.
