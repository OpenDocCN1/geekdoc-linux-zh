# Managing Print Queues in Fedora Core 489

Print job refers to what you print with a single print command. The printing environment queues print jobs by storing them in the spool directory. background process periodically sends the print jobs to the spool directory.

Fedora Core uses the Common UNIX Printing System (CUPS) for its printing-environment. CUPS is a printing system based on the Internet Printing Protocol (IPP) — a protocol for distributed printing using Internet technologies. IPP uses a client/server model with the client being an application service provider, and the server a “Printer” — an abstraction of an output device or a printing provider. IPP supports a distributed printing environment with the clients and printers communicating over the Internet. You could use an IPP client to print to a printer on anywhere. The client and Printer exchange data using the HTTP 1.1 protocol — the same protocol that Web servers use. The client application uses IPP to inquire about capabilities of a printer, submit print jobs, and inquire about — cancel — print jobs.

If you have set up CUPS print queue for a printer connected to your Fedora Core system (following the directions in Book I, Chapter 3), you can print on that printer from Windows XP and 2000 systems on your local-network area. Windows 2000 and XP have built-in support for IP — the protocol used by CUPS. To print on a CUPS print queue from a Windows XP system, add a network printer on the XP. In the Add Printer Wizard, Select to a Printer on the Internet or on a Home or Office Network and then enter the URL of the CUPS print queue. For example, for a CUPS print queue named HPLaserRoom210 on a Fedora Core host whose address is 192.168.0.8, I enter the following URL for the print queue:

```
http://192.168.0.631/printers/HPLaserjetRoom210
```

As a Fedora Core user, you use a client program — lp or lpr — to send the files to a print scheduler called cupsd over a TCP/IP network connection. The cupsd schedules the files, processes them according to their file extensions (such as .txt or .ps), and sends them to the printer one by one. Thanks to various configuration files, the cupsd scheduler knows what to do to make sure the file — be a text file or image file — gets printed.

Although you typically have only one printer connected to your PC, one advantage of the CUPS printing system is the capability to print to a remote printer connected to another system on a network. Printing to a remote printer is handled in the same fashion as printing to a local printer; the local lp or lpr program sends the files to the remote system’s cupsd scheduler.
