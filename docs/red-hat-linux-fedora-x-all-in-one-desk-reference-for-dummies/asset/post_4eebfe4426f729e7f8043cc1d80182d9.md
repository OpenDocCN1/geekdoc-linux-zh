
# Navigating the File System with Linux Commands

This command mounts the file system on the device named /dev/cdrom (the DVD/CD-ROM) is on the /mnt/cdrom directory (which is also called the mount point) in the Linux system.

After the mount command successfully completes its task, you can access the files on the DVD-ROM by referring to the /mnt/cdrom directory as the top-level directory of the disc. In other words, to see the contents of the DVD-ROM, type

```
ls -F /mnt/cdrom
```

When you're using the DVD-ROM — and before you eject it from the drive — you have to "unmount" the disc drive with the following command:

```
umount /dev/cdrom
```

Mounting devices on directories in the /mnt directory is customary. Linux comes with two predefined directories: /mnt/cdrom for mounting the DVD/CD-ROM and /mnt/floppy for mounting the floppy drive.

# Commands for checking disk-space usage

I want to tell you two commands — df and du — that you can use to check the disk-space usage on your system. These are simple to use. The df command shows a summary of disk-space usage for all mounted devices. We df shown in this example:

| Filesystem 1K-blocks Used Avail% Mounted on |
|---|---|---|---|---|
| /dev/hda5 7392428 3855112 3161800 55% / |
| /dev/hda3 101105 15760 80124 17% /boot |
| none 127880 0 127880 0% /dev/shm |
| /dev/cdrom 658144 658144 0 100% /mnt/cdrom |

The output is a table that shows the device, the total kilobytes of storage, how much is in use, how much is available, the percentage being used, and the mount point.

To see the output of df in a more human-readable format, type df -h. Here is the output of the df -h:

```
Filesystem Size Used Avail% Mounted on
|---|---|---|---|---|
| /dev/hda5 7.1G 3.7G 3.1G 55% / |
| /dev/hda3 99M 16M 79M 17% /boot |
| none 125M 0 125M 0% /dev/shm |
| /dev/cdrom 643M 643M 0 100% /mnt/cdrom |
```

If you compare this output with the output of plain df (see previous listing), you see that df -h prints the sizes with terms like M for megabytes and G for gigabytes. These are clearly easier to understand than 1K-blocks.

The other command --du is useful for finding out how much space directory takes up. For example, type the following command to view the contents of all the directories in the /etc/rc.d directory (this directory contains system startup files):

```
du /etc/rc.d
4 /etc/rc.d/rc1.d
4 /etc/rc.d/rc0.d
4 /etc/rc.d/rc5.d
4 /etc/rc.d/rc3.d
4 /etc/rc.d/rc4.d
4 /etc/rc.d/rc2.d
308 /etc/rc.d/init.d
4 /etc/rc.d/rc6.d
372 /etc/rc.d
```

Each directory name is preceded by a number — which tells you the number of kilobytes of disk space used by that. Thus the /etc/rc.d directory, as a whole, uses 372K disk space whereas the /etc/rc.d/init.d directory (including all the files and subdirectories contained in that directory), use the -s option, as follows:

```
du -s /etc/rc.d
372 /etc/rc.d
```

The -s option causes du to print the summary information for the /etc/rc.d directory.

![](img/d9230b719dc0efd80851f363d8c6f571_194_0.png)

Just as -h prints the disk-space information in megabytes and gigabytes, you can use the -h command to view the output of du in more human-readable format. For example, here's how you with the -s option to see the space I'm using in my home directory (/home/naba):

```
du -sh /home/naba
29M /home/naba
```
