# Installing the Mail Server 651

To enter the mail message, I use the DATA command. In response to the DATA command, sendmail displays an instruction that I have to end the message with a period on a line by itself. I enter the message and end it with a single period on a separate line. The sendmail process displays a message indicating that the message is accepted for delivery. Finally, I quit the sendmail session with the QUIT command.

After, I log in my Fedora Core system and check with the mail command. The following is the session with the mail command when I display the mail message I sent through the sample SMTP session with sendmail:

Testing... 1 2 3
Sending mail by telnet to port 25

```
& q
Saved 1 message in mbox
```

As this shows, the SMTP commands are simple enough for humans to understand. This example helps you understand how a mail-transfer agent uses SMTP to transfer mail on the Internet. Of course, e-mails usually automate this process — and so does the sendmail program through settings in the sendmail configuration file /etc/mail/sendmail.cf.

# The sendmail configuration file

You don't have to understand everything in the sendmail configuration file, /etc/mail/sendmail.cf, but you need to know how that file is created. That way, you can make minor changes to regenerate the /etc/mail/sendmail.cf file.

Before you can regenerate the sendmail.cf file, you have to install the sendmail-cf package. To check whether the sendmail-cf package is installed, type

```
rpm -q sendmail-cf
```
