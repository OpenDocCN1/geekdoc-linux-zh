| Table 4-3 Some Common Yum Options |
| Option | Causes Yum to Do the Following |
|---|---||
| --download-only | Downloads the packages, but does not install them. |
| --exclude=pkg | Excludes the specified package. (You can use this option more than once on the command line.) |
| --help | Displays a help message and quits. |
| --installroot=path | Uses the specified path name as the directory under which all packages are installed. |
| -y | Assumes that your answer to any question is yes. |

If you want Yum to update your system, just type the following (you have to be logged in as root):

```
`yum update`
```

Yum consults its configuration file, /etc/yum.conf, and does everything needed to update the packages installed on your system.

You can specify package names to update only some packages. For example, to update the kernel and xorg-x11 packages, using the following Yum command:

```
`yum update kernel* xorg-x11*`
```

This updates all packages whose names begin with kernel and xorg-x11.

You may use the options to further instruct Yum what to do. For example, if you want to download the packages, but not install them, type

```
`yum --download-only update`
```

Another typical option is --exclude, which enables you to exclude one or more packages from the update process. Suppose you want to update everything except the GNOME packages (whose names begin with gnome) and the rhythmbox package. Then you type the following Yum command:

```
`yum --exclude=gnome* --exclude=rhythmbox update`
```
