Other important hardware in the system box includes the memory (RAM chips) and the hard drive — and one program has to run all this and get it to play nice: the operating system.

The operating system is software that manages all the hardware and runs other software at your command. You, the user, provide those commands by clicking menus and icons or by using some cryptic text. Linux is an operating system — as UNIX, Windows 98, Windows 2000, and Windows XP. The Linux operating system is modeled after UNIX; in its most basic, no-frills form, it also goes by the name Linux kernel.

The operating system is what gives a computer — any computer — its personality. You, can run Windows 98 or Windows XP on a PC — and on that same, you can also install and run Linux. That means, depending on which operating system is installed and running, the same PC can be Windows 98, Windows XP, or Linux system.

The primary job of an operating system is to load software (computer programs) from the hard disk (or other permanent storage) into the memory and get the CPU to run the programs. Everything you do with your computer is possible because of the operating system somehow freees up, the whole system freezes. You know how infuriating it is when your favorite operating system — maybe even the one that came with your PC — suddenly quits it just as you are about to click the Send button after composing e-mail to your friend. You try the three-finger swipe (pressing Ctrl+Alt+Del), but nothing happens. It’s time for the Reset button (provided your computer’s builders were wise to include one). Luckily, that of sort almost never happens with Linux — it has a reputation for being a very reliable system.

# Does Linux run on any computer?

Linux runs on many different types of computer systems — and it does seem able to run on any type of computer. Linux Torvalds and other programmers originally developed for the Intel 80x86 (and compatible) line of processors. Nowadays, Linux is also available for systems based on other processors — such as those with AMD’s 64-bit AMD64 processors, the Motorola 68000 family; Alpha AXPs; Sun SPARCs and UltraSPARCs; Hewlett-Packard’s HP PA-RIS; the PowerPC and Power64 processors; and the MIPS R40 and R50. More recently, IBM has released its own version of Linux for S/390 mainframe. This book covers Linux for Intel 80x86 and Pentium processors (those that have in common a basic physical structure known as IA-32 architecture).

# Linux distributions

Fedora Core is a specific Linux distribution — essentially a package of features. Fedora Core consists of the Linux kernel (the operating system) and a collection of applications, together with an easy-to-use GUI installation program called Anaconda.

You find many Linux distributions, and each includes the standard Linux system:

- The X.Org X Window System: The graphical user interface.
- One or more graphical desktops: the most popular are GNOME and KDE.
- A selection of applications: Linux programs come in the form of ready-to-run software, with source code (the commands we tell the computer what to do, but you don't need the source code to run the operating system or any applications) included as its documentation.

Current Linux distributions include a huge selection of software — so that it requires multiple CD-ROMs or a single DVD-ROM (which this book includes).

Many Linux distributions are commercial products that you can buy in stores and bookstores. If you have read about Open Source and the GNU (GNU Not Unix) license, you may assume that no one can sell Linux for profit. For companies that sell Linux distributions, the GNU license — also called the GNU General Public License (GPL) — allows commercial, for-profit distribution, but requires that the software be distributed in source-code, and stipulates that anyone may copy and distribute the software in source-code to anyone else. Fedora Core is available free of charge under the GPL, which means that your publisher may include the Fedora Core DVD-ROM with this book and you may make copies of the DVD as you need.

# Under the hood in Linux kernel 2.6

Linux kernel 2.6 includes many features and improvements when compared to its predecessor — the 2.4 kernel. I highlight some of these improvements in this section. You may not notice many of these improvements because they work behind the scenes. All you see is a Linux system that simply works great!

# For support wider range of hardware

For starters, the 2.6 kernel has been redesigned to support computers spanning a wider range of hardware than from bare-bones microcontrollers to larger-scale servers with multiple processors. To support distinct architectures of the same processor family (such as x86), Linux 2.6 uses the concept of subarchitecture, which refers to the processor and the associated bus and other hardware that defines a unique type of computer. Better scalability for Intel x86 hardware by introducing advanced features such as Intel's Physical Address Extension (PAE), which enables many newer 32-bit x86 systems to access up to 64GB of memory. Linux 2.6 also provides better handling of interrupts for multiprocessor systems through improved support for Intel's Input/Output (I/O) Advanced Programmable Interrupt Controller (APIC).
