Linux gives you many small and specialized commands, along with the plumbing necessary to connect these commands. By plumbing, I mean the way in which one command's output can be used as a second command's input (short for Bourne Again Shell) — the default in Fedora Core provides this plumbing in the form of I/O redirection and pipes. Bash also includes features such as the if statement that you can use commands only when a specific condition is true and the for statement that repeats a specified number of times. You can use these features of Bash when writing programs scripts.

In this chapter, I show you how to write simple shell scripts — task-oriented collections of commands stored in a file. Shell scripts are used to automate tasks. For example, when your Fedora Core system boots, many shell scripts stored in subdirectories in the /etc directory (for example, /etc/init.d) perform many initialization tasks.

# Trying Out Simple Shell Scripts

If you are not a programmer, you may feel apprehensive about programming. But shell scripting (or programming) can be as simple as storing few commands in a file. In fact, you can have a useful shell program that has a single command.

While writing this book, for example, I captured screens from the X Window System and used the shots in figures. I used the X screen-capture program, xwd, to store the screen images in the X Window (XWD) format. The book's production team, however, wanted the screens in TIFF format. Therefore, I used the Portable Bitmap (PBM) toolkit to convert the XWD images to TIFF format. To convert each file, I run two programs as shown follows:

```
xdtopnm < file.xwd > file.pnm
pnmotiff < file.pnm > file.tif
```
