# 454 Accessing DOS/Windows File Systems

+   * /dev/fd0 is the A drive (the first floppy drive)
* /dev/fd1 is the B drive (the second floppy drive, if you have one)

As the mount point, you can use any directory in the file system as the mount point, but the Fedora Core system comes with a directory, /mnt/floppy, to specifically mount a floppy disk.

To mount a DOS floppy disk on the /mnt/floppy directory, pull the floppy in the drive and type the following command:

```
mount -t vfat /dev/fd0 /mnt/floppy
```

After you mount the floppy, you can copy files to the floppy by using the Linux copy command (cp). To copy the file gnome.pcx from the current directory to the floppy, type the following:

```
cp gnome.pcx /mnt/floppy
```

Similarly, to see the contents of the floppy disk, type the following:

```
ls /mnt/floppy
```

If you want to remove the floppy from the drive, first unmount the floppy drive. Unmounting removes the association between the floppy's file system and the mount point on the Linux file system. Use the unmount command to unmount the floppy disk like this:

```
umount /dev/fd0
```

You can set up your Fedora Core system so that any user can mount a DOS floppy. To enable any user to mount a floppy in the A drive on the /a directory, for example, perform the following steps:

+   1. Log in as root.

+   2. Create the / directory (the mount point) by typing the following command in a terminal window:

```
mkdir /a
```

+   3. Edit the /etc/stab file in a text editor (such as vi or emacs), insert the following line and save the file and quit the editor:

```
/dev/fd0 /a vfat noauto,user 0 0
```

The first field is the device name of the floppy drive (/dev/fd0); the second field is the mount point (/a); and the third field shows the type of file system (vfat). The user option (which appears next to noauto) is what enables all users to mount DOS floppy disks.
