# What Is Fedora Core?

In technical mumbo jumbo, Linux is a multiuser, multitasking operating system. All this means that Linux enables multiple users to log in, and Linux can run more than one program at the same time. Nearly all operating systems are multiuser and multitasking these days, but when Linux started in 1994, multiuser and multitasking were big selling points.

# Linux distributions

Fedora Core is a specific Linux distribution — essentially a package of features. Fedora Core consists of the Linux kernel (the operating system) and a collection of applications, together with an easy-to-use GUI installation program called Anaconda.

You find many Linux distributions, and each includes the standard Linux system:

+   * The X.Org X Window System: The graphical user interface.
* One or more graphical desktops: the most popular are GNOME and KDE.
* A selection of applications: Linux programs come in the form of ready-to-run software, with source code (the commands we tell the computer what to do, but you don't need the source code to run the operating system or any applications) included as its documentation.

Current Linux distributions include a huge selection of software — so that it requires multiple CD-ROMs or a single DVD-ROM (which this book includes).

Many Linux distributions are commercial products that you can buy in stores and bookstores. If you have read about Open Source and the GNU (GNU Not Unix) license, you may assume that no one can sell Linux for profit. For companies that sell Linux distributions, the GNU license — also called the GNU General Public License (GPL) — allows commercial, for-profit distribution, but requires that the software be distributed in source-code, and stipulates that anyone may copy and distribute the software in source-code to anyone else. Fedora Core is available free of charge under the GPL, which means that your publisher may include the Fedora Core DVD-ROM with this book and you may make copies of the DVD as you need.

# Transitioning to the Fedora Project

In late September 2003, Red Hat announced the Fedora Project — an open-source project sponsored by Red Hat that the developer community can participate and continue to evolve what used to be the Red Hat Linux product.
