If you install the BitTorrent software from a tar.gz file that you downloaded from bitconj.org/BitTorrent/, you have to change the directory where the BitTorrent software is installed and then run the BitTorrent client with a command-line of the following:

```
./btdownloadcurses.py --url torrentname
```

where torrentname is the URL of the torrent you want to access.

After BitTorrent finishes the download, leave the torrent client running for as long as possible. This time enables your system to provide the file to others who are also joining BitTorrent. After all, this sharing is what makes BitTorrent such an efficient way to distribute files.
