The panel includes several other applets besides the clock applet at the far right edge:

+   **The GNOME Pager applet:** Provides a virtual desktop that's larger than the physical dimensions of your system's screen. Each Figure 4-7, the pager displays four pages in a small display area. Each page represents an area equal to the size of the display screen. To go to a specific page, click that page in the window. The GNOME Pager applet displays buttons for each window being displayed in the current virtual page.

+   **Launcher applets:** The buttons to the right of the Main Menu icon are launcher applets. Each of these applets displays a button with the icon of an application. Clicking a button starts (launches) that application. Try clicking any of these buttons to see what happens. The mouse and earth button launches the Mozilla Web browser, whereas clicking the pen and paper icon opens the OpenOffice.org word processor. Move your mouse over an icon and a small help message appears with information about that icon.

+   **The GNOME weather applet:** Provides the local weather. You don't see this applet until you start it. You can start it from the menu that appears when you right-click an empty area of the panel.

# The Main Menu button, or the “Red Hat Logo”

In Figure 4-8, the leftmost edge of the panel shows a button with the familiar Red Hat logo. “red hat” is the Main Menu button — the most important part of the GNOME panel. Just like the Start button in Microsoft Windows, you can launch applications from the menu that pops up when you click the red hat. Figure 4-8 shows a typical view of the Main Menu on a Fedora Core PC.

Typically, the Main Menu and its submenus list items that an application starts. Some menu items have an arrow; move the mouse pointer on an item with an arrow and another menu pops up. In Figure 4-8, the selection is Menu⏮System Settings⏮Services. Notice when you point to a menu selection, a balloon pops up with information about that selection.

You can start applets like the weather applet from the menu that appears when you right-click the GNOME panel. To start the weather applet, right-click the panel and select Add to Panel⏮AccessoriesWeather Report (see Figure 4-9). In the Add to Panel menu, you find many more categories of applets you can try.
