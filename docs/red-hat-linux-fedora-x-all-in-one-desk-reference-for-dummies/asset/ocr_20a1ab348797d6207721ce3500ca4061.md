# 516 Installing the Kernel and Setting Up GRUB

+   * root (hd0,2): Sets the root device to the third partition of the hard drive. This partition is where the Linux kernel is installed on this particular system.

+   * kernel /vmlinuz-2.6.3-2.1240 root=LABEL=rhgb: Identifies the kernel loads if the user selects this boot entry. In this case, the kernel is vmlinuz-2.6.3-2.1240, which is located in the root device. In my system, that partition is mounted on the /boot device. In other words, GRUB loads the kernel file /boot/vmlinuz-2.6.3-2.1240. The items following the kernel name are options provided to the kernel. For example, the rhgb option enables a graphical boot that shows a nice graphical screen instead of scrolling text.

+   * initrd /initrd 2.6.3-2.1240: Specifies a file that contains an initial RAM disk (initrd image) that serves as a file system before the disks are available. The Linux kernel uses the RAM disk—a block of memory used as a disk—to get started; then it loads other modules and begins using the hard drive.

+   * The three lines with title Windows XP are the second boot entry and refer to the Windows XP operating system that happens to be on this system. The next text to the title line appears in the GRUB menu from which the user selects which operating system to boot.

To configure GRUB to boot the new kernel (the one you just built), follow these steps:

+   1. Copy the new kernel to the /boot directory.

The new, compressed kernel file is in the /usr/src/linux*/arch/i386/boot directory. The kernel filename is bImage. I simply copy that file to the /boot directory with the same name:

```
cp /usr/src/linux*/arch/i386/boot/bImage /boot
```

If the kernel filename is vmlinux, make sure change the kernel filename in /boot to anything you want, as long as you use the same filename when referring to the kernel in /etc/grub.conf file in Step 3.

+   2. Save the old System.map file in the /boot directory, and copy the new map file.

(I assume you have rebuilt kernel version 2.6.3-2.1240 after changing some configuration options):

```
mv /boot/System.map-2.6.3-2.1240 /boot/System.map-2.6.3-2.1240-old
cp /usr/src/linux*/System.map /boot/System.map-2.6.3-2.1240
cd /boot
ln -s System.map-2.6.3-2.1240 System.map
```
