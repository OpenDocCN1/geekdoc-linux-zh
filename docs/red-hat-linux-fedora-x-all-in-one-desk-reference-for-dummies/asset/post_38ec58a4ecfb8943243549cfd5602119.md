## Nmap

Nmap (short for network mapper) is a port-scanning tool. It can rapidly scan large networks and determine what hosts are available on the network, what services they are offering, what operating system (and the operating system version) they are running, what type of packet filters or filters are in use, and dozens of other characteristics. Fedora Core comes with nmap. You can read more about nmap at www.insecure.org/nmap.

If you want to try nmap to scan your local network, just use a command similar to the following (replacing the IP range with addresses appropriate for your):

```
nmap -sS 192.168.0.2-10
```

## Nessus

The Nessus Security Scanner is a modular auditing tool that uses plugins in the Nessus scripting language to test for a wide variety of network vulnerabilities. Nessus uses a client-server software architecture with a server called nessus and a client called nessus.

Before you try to install Nessus, you must install the sharutils RPM. That package includes the unicode utility that the Nessus installation script needs. The sharutils package isn't installed with any of the standard package-ages, so you may have to install it.

![](img/d9230b719dc0efd80851f363d8c6f571_616_0.png)

To install sharutils, mount the companion DVD and install it with the following commands:

```
cd /mnt/cdrom/Fedora/RPMS
rm -ivh sharutils*.rpm
```

To download and install Nessus, follow these steps:

- 1. Read the instructions at www.nessus.org/download.html. Then follow the link to the package you want to download. Follow the instructions and download the files nessus-installer.sh and MD5.
- 2. Type the following command to install Nessus (you must have the development tools, including the GIMP Toolkit, installed):

```
sh nessus-installer.sh
```

Respond to the prompts from the installer script to finish the installation. You can usually press Enter to accept the default choices.

After the installation is complete, follow these steps to use Nessus:

- 1. Log in as root and type the following command to create the Nessus SSL certificate used for secure communication between the Nessus client and the Nessus server:

```
nessus-mkcert
```

- 2. Provide the requested information to complete the certificate generation process.

- 3. Create a nessusd account with the following command:

```
nessusd-adduser
```

- 4. When prompted, enter your username, password, and any rules (press Ctrl+D if you don't know what rules to enter). Then press the Y key.
- 5. If you want to, you can configure nessusd by editing the configuration file /usr/local/etc/nessus/nessusd.conf.

If you want to try out Nessus, you can proceed with the default configuration file.

- 6. Start the Nessus server with this command:

```
nessusd -D
```

- 7. Run the Nessus client by typing the following command in a terminal window:

```
nessusd
```

The Nessus Setup window appears.

- 8. Type a nessusd username and password and then click the Log In button (shown in Figure 4-1).
- 9. When Nessus displays the certificate used to establish the secure connection and asks you if you accept it, click Yes.

After the client connects to the server, the Log In button changes to Out, and a connected label appears at its left.
- 10. On the Target tab, enter the range of hosts to scan. For example, to scan a subnet:

```
192.168.0.0/24
```

- 11. Click Start Scan. Nessus starts to scan for vulnerabilities (see Figure 4-2).

## SAINT

Security Administrator's Integrated Tool (SAINT) scans hosts for a variety of vulnerabilities. For the vulnerabilities it finds, SAINT shows the Vulnerabilities and Exposures (CVE) identifier. Other versions of SAINT are free, but the latest version is available only to those who purchase it.

You can download a restricted (limited to scanning two hosts) 15-day trial version of SAINT from saintcorporation.com/products/download.html and see what it can do.

## SARA

Security Auditor’s Research Assistant (SARA) is a vulnerability-scanning tool based on SAINT. SARA scans for known vulnerabilities, including those in the CVE list and the SANS Top 20 (sans.org/top20).

To try SARA, download the latest version of SARA from www-arc.com/sara/downloads/. After downloading the compressed tar file, build and install the software using these steps:

- 1. Unpack the tar file with the following command:
   tar zxvf sara*

- 2. To configure SARA, type the following commands:
   cd sara*
   ./configure

- 3. To build the software, type
   make

SARA is built, run it with the following command:
   ./sara

SARA starts a Web browser and displays its user interface in the Web browser.
