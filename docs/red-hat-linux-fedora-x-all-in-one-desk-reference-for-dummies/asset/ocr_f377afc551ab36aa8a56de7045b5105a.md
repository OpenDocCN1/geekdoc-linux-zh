# Operator Precedence

Typical C expressions consist of several operands and operators. When writing-
plicated expressions, you must be aware of the order in which the
compiler evaluates the operators. For example, suppose a program uses an
ray of pointers to integers as follows:

```
typedef int *Ptr/* Use typedef to simplify declarations* /
IntPtr iptr[10]; /* An array of 10 pointers to int */
```

Now suppose that you encounter the expression *ptr[4]. Does it refer to
t value of the int with the address in ptr[4], or is this the fifth element
from the location with the address in ptr? What you really need to know
whether the compiler evaluates the subscript operator ({}) before the
irection operator (*) — or does it work the other way around? To answer
questions as these, you need to know the precedence — the order in
which the program applies the operators.

order of decreasing precedence. The operators with highest precedence =
