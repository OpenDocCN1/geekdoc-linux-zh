If you want to match one of the characters $, |, *, ^, [, ], and /, you have to place a backslash before the character you want to match. You must type these characters as \$, \|, \*, etc. Regular expressions often look confusing because of the preponderance of strange character sequences and the generous sprinkling of backslashes. With anything else, you can start slowly and use a few of the features in the beginning.

So, I have summarized the syntax of regular expressions. But I haven't yet shown how to use regular expressions in Perl. Typically, you place a regular expression within a pair of slashes and use the match (~) or not-match(!~) operators to test a string.
