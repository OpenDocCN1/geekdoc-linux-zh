# Using the service configuration utility

If you don't like typing the chconfig commands, use a graphical service utility program to configure the services. To run the service configuration utility, log in as root and choose Main Menu→System Settings→Services from GNOME or KDE desktop. You can then run services on or off from the Service Configuration window (as Figure 1-2):

![](img/d9230b719dc0efd80851f363d8c6f571_635_1.png)

The service configuration utility shows the names of services in a scrolling list. Each line in the list shows the name of a service with a box in front of the name. A check mark in the box indicates that the service is already selected to start at boot time for the current run level. When the dialog first appears, many services are already selected.

You can scroll up and down the list and click the box to select or deselect a service. If you click the box, the check mark alternately turns on and off. To find out more about a service, click the name and view a brief description in the right-hand side of the window. For example, Figure 1-2 shows the help text for the atd service. Additionally, the utility also shows whether the selected service is currently running or not.

After you select the services you want to start when the system boots, click Save on the toolbar to save the changes. Then choose File>Quit to exit.

By default, the service configuration utility shows the selected services for the current run level. This means if you're selecting services from the graphical desktop, the system is in run level 5 and the services are configured to start at run level 5. If you want to set the services for a different level, that run level from the Edit Runlevel menu.
