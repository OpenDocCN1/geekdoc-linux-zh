# Preparing a Fedora Core DVD 105

+   - Blank DVD recordable media in a format compatible with your DVD recorder — the media can be one of DVD-R, DVD-RW, DVD+R, or DVD+RW.

+   - The downloaded Fedora Core ISO files or, even better, the DVD file. If you have not done so already, complete the BitTorrent project and download the four-CD Fedora Core ISO files or, if available, download the larger DVD ISO file.

# Steps to follow

The steps you follow to burn a Fedora Core DVD depends on whether you downloaded the Fedora Core CD ISO files or the DVD ISO file. If you download the CD ISO files, you have to first prepare a DVD ISO from those CD images. After that, you can burn the ISO file onto a DVD. I explain both.

If you have already downloaded the DVD ISO file, you can go right to burning the DVD.

# Create DVD ISO file from CD ISO files

Follow these steps to create a single DVD ISO file out of the CD ISO files:

+   1. Move the four ISO files to the /tmp directory using commands of the following form:
```
mv /full/path/ISOfilename.iso /tmp
```

Replace the part /full/path/ISOfilename.iso with the full pathname of the ISO file. Repeat the copy command for all four ISO files.

+   2. Create four directories that you can use as mount points for the four ISO images.

Assuming that you want these four directories in the /tmp directory, in as root and type the following commands in a terminal window:

```
cd
mkdir ISO1
dmkdir ISO2
dmkdir ISO3
dmkdir ISO4
```

+   3. Mount the four ISO files on the four mount points.

Assuming that the filenames for the four CD ISO images are ISOfilename.iso, ISOfilename2.iso, ISOfilename3.iso, and ISO4.iso, type the following commands to mount them:

```
mount -o ro,loop ISOfilename1.iso ISO1
mount -o ro,loop ISOfilename2.iso ISO2
mount -o ro,loop ISOfilename3.iso ISO3
mount -o ro,loop ISOfilename4.iso ISO4
```

Remember to replace the filenames with the actual filenames.
