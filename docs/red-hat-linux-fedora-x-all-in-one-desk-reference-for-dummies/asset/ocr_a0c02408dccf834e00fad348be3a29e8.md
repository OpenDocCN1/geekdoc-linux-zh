# Using the GNOME system monitor

Like the text above, the GNOME System Monitor tool also enables you to view the system load in terms of the number of currently running processes, your memory usage, and the free disk space on your system. To run the tool, select Main Menu→Tools→System Monitor The tool starts and displays its output in a window, as shown in Figure 1-3.

![](bbox=[0.235, 0.396, 0.673, 0.683])

Figure 1-3: Use the GNOME Monitor to view information about the current processes.

The output is similar to the output when you type top in a text-mode console or a terminal window, except that you can decide which columns you want to see. Figure 1-3 shows the (Process Listing tab) with the process name, the user who is running the process, the memory used, and the process ID. GNOME System Monitor keeps updating the display to reflect the current state of the system.

The GNOME System Monitor window has another tab Resource Monitor. Click that tab to view a summary of CPU, memory, and disk usage. Figure 1-4 shows a typical view of the Resource Monitor tab.
