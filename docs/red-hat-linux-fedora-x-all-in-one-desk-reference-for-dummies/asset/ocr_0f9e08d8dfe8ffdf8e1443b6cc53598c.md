The navigation window is vertically divided into two parts. The left window shows different views of the file system and the files and objects that you can browse with Nautilus. The right window shows the files and folders in the currently selected folder in the left window. Nautilus displays icons for files and folders. For image files, it shows a thumbnail of the image.

The navigation window's user interface is similar to that of a Web browser. The window's title bar shows the name of the currently selected folder. The location box above the top of the window shows the full name of the directory in Linuxspeak—for example, Figure 1-10 shows the contents of the /naba directory.

If you have used Windows Explorer, you can use the Nautilus navigation window in a similar manner. To view the contents of another directory, do the:

+   1. Choose Tree from the Information drop-down menu (the left-window).

A tree of directories appears in that window. Initially the tree shows the Home folder and the file system's root directory as a Filesystem folder.
