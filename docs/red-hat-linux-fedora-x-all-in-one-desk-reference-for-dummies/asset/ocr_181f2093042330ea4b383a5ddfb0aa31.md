# 160 Navigating the File System with Linux Commands

This time the output gives you some clues about the file types:

appnk/ lbproxy/ starthere/ xmodmap xsm/
d/ predf* sysconfig/ XftConfig.README-OBSOLETE xorg.conf/
fs/ proxymgr/ twm/ xinit/ Xresources
gdm/ serverconfig/ X xserver/

The output of ls -F shows the directory names with a slash (/) appended to them. Plain filenames appear as is. The sign (@) appended to a file's name (for example, the file named X) indicates that this file is a link to another file (in other words, this filename refers to another file; it's a shortcut). An asterisk (*) is appended to executable files (see, for example, the predm in the listing). The shell can run any executable file.

You can see more detailed information about the files and directories with the -l option:

ls -l

This listing shows considerable information about every entry — each of which is a file or another directory. Looking at a line from the right column to the left, you see that the rightmost column shows the name of the entry. The date and time show when the last modifications were made. The size of the group owner is the size of the file, in bytes.

The file's group and owner to the left of the column that shows the file size. The next number to the left indicates the number of links to the file.
