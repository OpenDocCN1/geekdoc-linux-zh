To use gtcam with your digital camera, follow these steps:

+   1. Connect your digital camera to the serial port or USB port (whichever interface the camera supports) and turn the camera on.
2. Choose Main Menu: Graphics:Digital Camera Tool to start gtcam.
3. From the gtcam menu, choose Camera:Add Camera.
4. In the de dialog box that appears, click Detect.

If your camera is supported, the camera is detected. If not, you can try an alternate method that I'll describe at the end of these steps.
gtcam displays a camera icon and the camera name on the left panel.

+   5. Double-click the camera icon to download and view thumbnail pictures in the right panel.
6. Click the thumbnails to select the images you want to download; then choose File:Save or click the Save button on the toolbar.

gtcam downloads the images and places each image in a separate file in your home directory. You can now edit the photos in the GIMP or your favorite photo editor.

> Don't despair if gtcam does not recognize your digital camera. You can still access the camera's storage media (compact flash, for example) as a USB mass storage device, provided your camera supports USB Mass Storage. To access the images on your USB digital camera, follow these steps:

![](bbox=[0.153, 0.553, 0.226, 0.613])

+   1. Read the camera manual and use the menu options of the camera to set the USB mass to Mass Storage.

If the camera does not support USB Mass Storage, you cannot use this procedure to access the photos.

+   2. Connect your digital camera to the USB port using the cable that came with the camera and turn the camera on.

This causes Linux to detect the camera, create the /mnt/camera directory, and add a line to the /etc/fstab file so you can easily mount the camera's storage media on the /mnt/camera directory.

+   3. To see if the camera was detected, type the following command in a terminal window:

```
cat /proc/bus/usb/devices
```
