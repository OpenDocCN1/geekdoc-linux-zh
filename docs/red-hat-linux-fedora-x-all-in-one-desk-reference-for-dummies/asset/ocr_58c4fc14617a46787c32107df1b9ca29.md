mkdir images

After you create the directory, you can use the cd images command to change to that directory.

You can create an entire directory tree by using the -p option with the mkdir command. For example, suppose your system has a /usr/src/directory directory and you want to create the directory tree /usr/src/book/java/applets. To create this directory hierarchy, use the following command:

```
mkdir -p /usr/src/book/java/examples/applets
```

When you no longer need a directory, use the rmdir command to delete it.

You can delete a directory only when the directory is empty.

To remove an empty directory tree, you can use the -p option, like this:

```
rmdir -p /usr/src/book/java/examples/applets
```

This command removes the empty parent directories of applets. Command stops when it encounters a directory that's not empty.

# Commands for finding files

The find command is very useful for locating files (and directories) that meet your search criteria.

When I began UNIX years ago (Berkeley UNIX in the 1980s), I was confounded by the find command. I stayed with one basic syntax of find for a long time before graduating to more complex forms. The syntax I learned first for finding a file anywhere in the file system. Here how it goes: Suppose you want to find any file or a directory that starts with gnome*. Type the find command to find these files:

```
find -name "gnome*" -print
```

If you're not logged in root, you may get a bunch of error messages. If these error messages annoy you, just modify the command as follows and the error messages are history (or, as UNIX aficionados say, send 'em to the bucket):

```
find -name "gnome*" > /dev/null
```
