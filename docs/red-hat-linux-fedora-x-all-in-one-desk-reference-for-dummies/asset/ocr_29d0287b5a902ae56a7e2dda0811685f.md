# Understanding Domain Name System (DNS)

To run a name server on your Fedora Core system, you have to run named with the appropriate configuration files. Later in this chapter, you find out about the configuration files and data files that control how the name server operates.

# Resolver library

Finding an IP address for a host name is referred to resolving the host name. Network-aware applications, such as a Web browser or an FTP client, use a resolver library to perform the conversion from the name to an IP address. Depending on the settings in the /etc/hosts.conf file, the resolver library consults the /etc/hosts file or makes a DNS query to resolve a host name to its IP address. The resolver library queries the name servers listed in the /etc/resolv.conf file.

You don't have to know much about the resolver unless you are writing network-aware applications. To run Internet services properly, all you have to know how to configure the resolver. In this chapter, I show you how to configure the other aspects of DNS.

# DNS utility programs

You can use the DNS utility programs — dig and host — to try out DNS from the shell prompt interactively. These utility programs are DNS clients. You can use them to query the DNS database and debug any name server you set up on your system. By default, these programs query the name server listed in your system's /etc/resolv.conf file.

You can dig, the Domain Internet Groper, to look up IP addresses for a domain name or vice versa. For example, to look up the IP address of ftp.redhat.com,

```
dig ftp.redhat.com
```

dig prints the results of the DNS query in great detail. Look in the part of the output labeled ANSWER SECTION: for the result. For example, here's what section looks like for this sample query:

```
:: ANSWER SECTION:
ftp.redhat.com.      300      A       209.132.176.30
ftp.redhat.com.      300      A       66.187.224.51
```

This output means that name ftp.redhat.com refers to both IP addresses — 209.132.176.30 and 66.187.224.51.
