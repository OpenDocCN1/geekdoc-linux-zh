# Setting Up a Windows Server Using Samba

After adding a Samba share, type the following command in a terminal window to verify that the Samba configuration file is okay:

```
testparm
```

If the command says that it loaded the files okay, you're all set to go. The testparm command also displays the contents of the Samba configuration file.

To start the SMB services automatically when the system reboots, type the following command:

```
chkonfig --level 35 smb
```

# Trying out Samba

You can now try to access the Samba server on the LAN. Double-click the Network Neighborhood icon on one of the Windows systems on the 95/98/ME desktop. On Windows XP, choose Start>My Network Places and then click View Workgroup Computers. All the computers on the same workgroup are shown.
