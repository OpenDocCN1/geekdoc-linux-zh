```
title Fedora Core (2.6.3-2.1.240 NEW)
root (hd0,2)
kernel/bzImage root=LABEL=/ rhgb

```

On your system, make sure the root line is correct — instead of (hd0,2), list the disk partition where the Linux root directory (/) is located. Also, use the kernel filename for the kernel image file (example, /vmlinux if the kernel is named).

> Note: The initrd line refers to the initrd file that you created in an earlier step.

+   4. Save the /etc/grub.conf file and exit the editor.

Now you're ready to reboot the system and try out the new kernel.

# Rebooting the System

After you finish configuring GRUB, you can restart the system. While you're still logged in as root, type the following command to reboot the system:

```
reboot
```

When you see the GRUB screen, select the name you assigned to the new kernel in the /etc/grub.conf file.

After the system reboot, you see the familiar graphical login screen. To see that you're indeed running the new kernel, log in as a user, open a terminal window, and type uname -srv. This command shows you the kernel version, as well as the date and time when this kernel was built. If you upgraded the kernel source, you see the version number for the new kernel. If you simply reboot the kernel for the same old kernel version, the date and time matches the time you reboot the kernel. That's your proof that the system is running the new kernel.

If the system hangs (nothing seems to happen — you don't see any output on-screen or disk activity), you may have skipped a step during the kernel rebuild. You can power the PC off and on to reboot. This time, select the name of the old working kernel at the GRUB screen.
