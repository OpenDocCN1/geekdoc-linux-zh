Ext3 journaling file system support (EXT3FS)

The ext3 filesystem is a journaling file system (also called ext3, the standard Linux file system) journals operations to a file on a device for better safety.

The journaling ensures that the system does not have to run fsck (file system check) after a crash. The journal records the state of the file system at the time of the system crash and ensures that your module is within a consistent state.
