# Running the kernel configuration tool

You can use any of the configuration tools — make xconfig, make menu-config, or make config — to configure the kernel, but the easiest way is to log in as root and follow the following command in a terminal window:

```
make xconfig
```

This command builds an Window System-based configuration tool and runs it. The initial graphical kernel configuration window displays a split vertically into two panels. The left hand panel displays a tree of configuration options organized by category, as shown in Figure 6-1. The right panel is divided horizontally, with the upper part showing the detailed options for the item selected on the left. The lower right panel shows a help message for the currently selected option (see Figure 6-1).
