# Reading Newsgroups from Your ISP

If you sign up with an ISP for Internet access, it can provide you with access to a news server. Internet news servers communicate using the Network News Transfer Protocol (NNTP). You can use an NNTP-capable newsreader, such as Pan, to access the news server and read selected newsgroups. You can also read news by using the newsreader that comes with Mozilla (included with Fedora Core). Using a newsreader is the easiest way to access news from your Fedora Core Internet system.

![](bbox=[0.133, 0.567, 0.203, 0.633])

By default reading newsgroups assumes that you obtained access to a news server from your ISP. The ISP provides you the name of the news server and any password to set up your account and read news.

To read, you need a newsreader—a program that enables you to select a newsgroup and the items in it. You also have to understand the newsgroup hierarchy and naming conventions (which I describe in the “Newsgroup hierarchy” of this chapter). Now I show you how to read news from a news server.

If you don't have access to newsgroups through your ISP, you can try using one of the many public news servers that are out. Visit NewzBot at www.newzbot.com. At this Web site, you can search for news servers that carry specific newsgroups.
