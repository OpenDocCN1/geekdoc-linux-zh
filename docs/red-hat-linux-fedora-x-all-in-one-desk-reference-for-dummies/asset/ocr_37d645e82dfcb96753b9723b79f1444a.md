After install and configure Samba on your Fedora Core PC, your client PCs — even if they're running the Windows for Workgroups operating system or the most recent Windows 95/98/NT/2000/XP experiences — can access shared disks and printers on the Fedora Core PC. To do so, you use the Server Message Block (SMB) protocol, the underlying protocol in Windows file and print sharing.

With the Samba package installed, you can make your Fedora Core PC a Windows client, which means that the Fedora Core PC can access the disks and printers that a Windows server manages.

The Samba software has these major components:

+   * /etc/samba/smb.conf: The Samba configuration file uses the SMB server.
* /etc/samba/smbsusers: This Samba configuration file shows the Samba user name to usernames on the local Fedora Core PC.
* nmbd: The NetBIOS server, which clients use to look up servers. (NetBIOS stands for Network Basis Input/Output System — an interface that applications use to communicate with network transports, such as TCP/IP.)
* nmlookup: This command returns the IP address of a Windows PC identified by its NetBIOS name.
* smbcls: This program manipulates Windows NT access control lists (ACLs) on shared files.
* smclient: The Windows client, which runs on Linux and allows Linux to access the files and printer on any Windows server.
* smcontrol: This program sends messages to the smbd, nmbd, or windbind processes.
* smbd: The SMB server, which accepts connections from Windows clients and provides file- and print-sharing services.
* smbmount: This program mounts a Samba share directory on a Fedora Core PC.
* smpasswd: This program changes the password for an SMB server.
* smprint: This script enables printing on a printer on an SMB server.
* smstatus: This command lists the current SMB connections for the local host.
