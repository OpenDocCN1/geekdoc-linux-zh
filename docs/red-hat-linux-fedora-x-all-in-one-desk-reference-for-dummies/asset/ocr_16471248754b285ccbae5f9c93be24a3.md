KDE stands for the K Desktop Environment. The KDE project started in 1996 with an intent to develop a common GUI for Unix systems that use the X Window System. The first beta version of KDE version was released a year later in October 1997. KDE version 1.0 was released in July 1998; KDE 2.0 on October 23, 2000; KDE 3.0 was released on April 3, 2002; and the latest version — KDE 3.2.2 — was released on April 19, 2004.
