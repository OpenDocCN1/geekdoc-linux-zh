## Software development

Fedora Core is particularly well suited to software development tools such as the compiler and libraries of code needed to build programs. If you happen to know UNIX and the C programming language, you will feel right at home programming in Fedora Core.

As far as the development environment goes, Fedora Core has the basic tools (as an editor, a compiler, and a debugger) that you might use on UNIX workstations, as those from IBM, Sun, and Hewlett-Packard (HP). What this means is if you work by day on one of these workstations, you can use a Fedora Core PC in the evening to duplicate that environment at home at a fraction of the cost. You can then complete projects at home or devote your time to write software for fun and share on the Internet.

Just to give a sense of Linux's software-development support, here's a list of various features that make Linux a productive software-development environment:

- GNU C compiler, gcc, can compile ANSI-standard C programs.
- GNU C++ compiler (g+) supports ANSI-standard C++ features.
- The GNU Java compiler (gcj) can compile programs written in the Java programming language.
- The make utility enables you to compile and link large programs.
- The GNU debugger, gdb, enables you to step through your program to find problems and to determine how and how a program failed. (The failed program's memory image is saved in a saved file; gdb can examine this file.)
- The GNU profiling utility, prof, enables you to determine the degree to which a piece of software uses your computer's processor time.
- Subversion, Concurrent Versions System (CVS), and Revision Control System (RCS) maintain version information and control access to the source files so two programmers don't modify the source file inadvertently.

- The GNU emacs editor prepares source files and even launches a compile-link process to build the program.
- Perl is a scripting language you can use to write scripts to accomplish a specific task, tying together many smaller programs with Linux commands.
- The Tool Command Language and its graphical toolkit (Tcl/Tk) enable you to build graphical applications rapidly.
- Python is an interpreted programming language comparable to Perl and Tcl (the Fedora Core installation program, called anaconda, is written in Python).
- Dynamically linked shared libraries allow your actual program files to be much smaller as all the library code that several programs may need is shared with only one copied in the system's memory.

## Online documentation

As you become more adept using Fedora Core, you may want to look up information quickly — without having to turn the pages of this great book. Luckily, Fedora comes with enough information to jog your memory in situations when you vaguely recall a manager's name, but cannot remember the exact syntax of what you are supposed to type. If you use Linux commands, you can view the manual page — commonly referred to as the man page — for a command you have to remember in order to access help. You can also get help from the GUI desktops. Both GNOME and KDE desktops come with viewers to view help information. In GNOME, select Main Menu-Help. You can see two categories of information:

- GNOME Desktop is information on how to use the GNOME desktop and some applications.
- Additional documents include online documentation (primarily for the applications and software development tools).

You can then browse the information by clicking the links on the initial window. Figure 1-1 shows a typical help file in GNOME. In KDE desktop, you can start KDE Help by choosing Main Menu-Help. The KDE Help application looks similar to the GNOME help browser (see Figure 1-2).

What is GNOME?
GNOME is a desktop environment for Unix and Linux systems. GNOME includes a panel for launching applications and a desktop where icons and applications can be placed. It is familiar to each user. Other operating systems or environments offer different approaches, such as Windows, FreeBSD, and XFCE. GNOME is developed by hundreds of programmers around the world. The source code is free and many copies of GNOME are available for download on the internet. This is particularly useful, as GNOME is highly customizable so you can design how you want it to look and feel. GNOME supports many different themes and even drag and drop protocols. GNOME comes from the GNU Object Model Environment. GNOME is a part of the larger project which provides a desktop environment for the Linux system. The desktop interface is the primary way to interact with the system. This guide covers GNOME 2.2, which is the latest (as of March 2003) release of GNOME.

## What Fedora Core Helps You Manage

As an operating system, Fedora Core acts as the intermediary through which you, as the “lord of the system,” manage all the hardware. The hardware includes the system box, the monitor, the keyboard, the mouse, and anything connected to the system box. The catchall term refers to any equipment attached to the system. If you use a laptop computer, all your hardware is packed into the laptop.

Inside that box is the system’s brain — the microprocessor (Intel Pentium 4, for example) or the central processing unit (CPU) — that performs the instructions contained in a computer program. When the microprocessor is running a computer program, that program’s instructions are stored in the memory or RAM. RAM stands for Random Access Memory (that any part of the memory can be accessed randomly — in arbitrary order).

The system box has another critical component — the hard disk or hard drive, as it is called. The hard is the permanent storage space for computer programs and data. It is permanent in the sense that the contents don’t disappear when you power off the PC. The hard disk is organized into files, which are in turn organized in a hierarchical fashion into directories and subdirectories (somewhat like organizing paper folders into the drawers in a file cabinet).

To keep a Fedora Core system running properly, you or someone else has to make sure the hardware is working properly and the files are backed up regularly. There is also the matter of security — making only legitimate people access and use the system. These tasks are called system administration.

If you are using Fedora Core at a big facility with many computers, a full-time system administrator probably takes care of all system administration tasks. On the other hand, if you are running Fedora Core on a home PC, you are the system administrator. Don’t have to know any magic incantations or prepare cryptic configuration files to be a system administrator. Fedora Core includes many graphical tools such as GNOME’s Nautilus shell that makes system administration a “point-and-click” job like running any other application.

## Disks, CD-ROMs, and DVD-ROMs

Fedora Core comes on a single DVD-ROM. After installation, the Linux kernel and all the applications are stored on your hard drive — which is where your PC first looks when you tell it to do something.
