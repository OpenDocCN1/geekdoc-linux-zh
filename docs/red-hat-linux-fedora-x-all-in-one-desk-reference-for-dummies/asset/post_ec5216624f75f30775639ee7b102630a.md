## Setting Up Printers

The Fedora Core installer does not include a printer configuration step, but you can easily configure a printer from a graphical utility program. To set up printers, follow these steps:

- 1. From the graphical login screen, log in as root.

If you're not logged in as root, proceed to the next step and the printer configuration tool prompts you for the root password.

- 2. From the GNOME or KDE desktop, choose Main Menu: System Settings: Printing.

The printer configuration tool is called system-config-printer. Figure 3-1 shows its main window.

![](img/d9230b719dc0efd80851f363d8c6f571_91_0.png)

![](img/d9230b719dc0efd80851f363d8c6f571_91_1.png)

- 3. Click the New button to configure a new printer.

The Fedora Core’s Printer Configuration Wizard starts. The initial window displays a message that assures you nothing changes until you click the Apply button at the end of all steps. Click Forward to continue.

- 4. In the next screen (see Figure 3-2), enter the name for the print queue and a short description of the print queue; then click forward.

Use some systematic approach when naming the print queue. For example, if I have a HP LaserJet 5000 on the second floor in Room 210, I might name the queue Room210HPLJ5000 because this name makes finding the printer easier. Sometimes administrators choose cute names like kermit, piggy, elmo, cookiemonster, and so on, after you have too many printers, such scheme don't work well. Providing a clue about the printer's location as well as the model in the print queue's name is best.

![](img/d9230b719dc0efd80851f363d8c6f571_91_2.png)

![](img/d9230b719dc0efd80851f363d8c6f571_91_3.png)

- 5. In the next screen (see Figure 3-3), select a queue type from the drop-down box; then click Forward.

Select the print-queue type that applies to your situation. For example, if you want to print on a shared Windows printer, select the Windows Printer checkbox.

To set up a printer connected to your PC's parallel port, select Locally-connected.

![](img/d9230b719dc0efd80851f363d8c6f571_92_0.png)

Figure 3-3: Select the print queue type from this window.

The following types of print queues are:

- Locally-connected: Refers to a printer connected directly to the serial, parallel, or USB port of your PC.
- Networked CUPS (IPP): Refers to a Common UNIX Printing System (CUPS) print queue at another server on the network (IPP refers to the Internet Printing Protocol used to communicate with the remote CUPS server).
- Networked UNIX LPD: Refers to a print queue managed by the LPD server on another UNIX system on the local network (LPD refers to Line Printer Daemon—).
- Networked Windows (SMB): Refers to a printer connected to another PC on the local network that uses the Server Message Block (SMB) protocol, the underlying protocol in Windows file and print sharing.
- Networked Novell (NCP): Refers to a printer connected to a Novell server on the local network.
- Networked JetDirect: Refers to a printer connected directly to the network.
