# Recording an audio CD

With X-CD-Roast, you can duplicate an audio CD or create a new audio CD by mixing and matching tracks you want. To make a new audio CD with all or selected tracks from an existing audio CD, click the Create button in the main window (refer to Figure 4-5) and then follow these steps:

+   1. Place the original CD in the CD reader device as the reader that you designated in the X-CD-Roast setup and place a blank CD in the CD reader and click the Read Tracks button.

X-CD-Roast displays the tracks in the Create CD window (shown in Figure 4-7) so that you can select the tracks to read.
