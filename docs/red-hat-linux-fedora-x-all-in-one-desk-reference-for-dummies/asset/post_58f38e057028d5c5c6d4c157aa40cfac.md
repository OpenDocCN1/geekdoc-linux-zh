# Exploring GNOME

GNOME (pronounced Gah-NOME) is the default GUI for Fedora Core. When you use GNOME, all you see and experience is the GUI desktop. For example, you find, however, much more to GNOME than the GUI desktop. For example, there are some key facts about GNOME:

- GNOME provides a development environment for GUI applications. It comes with a programming toolkit that programmers can use to create GUI applications.
- GNOME supports an object model — it defines the structure of software components that it can communicate with one another.
- The GNOME GUI is modular, so it works with any window manager for the X Window System. For example, Fedora Core comes with several window managers like Metacity, MWM, and TWM. Each window manager has its own look and feel. GNOME works with any of these window managers.
- All GNOME documentation is written using the Standard Generalized Markup Language (SGML). You can view the manual for a GNOME application on any browser.
- GNOME comes with a set of applications called OpenOffice.org. It includes the Writer processor, the Calc spreadsheet, the Impress presentation program, and the Draw drawing program. See Book III for more about OpenOffice.org.

Okay, I think you get the idea. GNOME is a mighty worthwhile underneath that pretty exterior. If you want to find out about GNOME, visit the GNOME home page at www.gnome.org.

# Using the Nautilus shell

The Nautilus file manager, or more graphical shell, comes with GNOME. Nautilus is intuitive to use — it's similar to the Windows Active Desktop. You can manage files and folders and also manage your system with Nautilus.

The current version of Nautilus has changed from what you may have known in previous versions of Red Hat Linux or Fedora Core. Nautilus provides a new object window in addition to the navigation window that you know from the past. When double-click any object on the desktop, Nautilus opens an object window that shows that object's contents. If you want the older navigation window with its Web browser-like user interface, right-click a folder and select Open:Browse folder from the pop-up menu.

# Viewing files and folders in object window

When double-click a file or folder, Nautilus opens in what it calls an object window. Unlike the Nautilus windows of old the object window does not have any back and forward buttons, toolbar, or side pane. For example, double-click the Start Here icon on the left side of the GNOME desktop. Nautilus opens an object window where it displays the contents of the Start Here object. If you double-click an object inside that window, Nautilus opens another window where that object's contents appears. Figure 1-9 shows the result of double-clicking two objects in the Start Here window.

The Nautilus object has a sparse user interface that has the menu bar. You can perform various operations from the menu bar such as open an object using an application, create folders and documents, and close the object window.

# Burning data CDs from Nautilus

If you have a CD recorder attached to your system (it can be a built-in ATAPI CD recorder or an external one attached to the USB port), you can use Nautilus to burn data CDs. From a Nautilus object window, you can access the CD Creator into Nautilus. Just follow these simple steps:

- 1. In any Nautilus object window, select Places: CD Creator.
- Nautilus opens a CD Creator object window. If you don't have Nautilus object windows opens, just double-click the computer icon on the desktop.
