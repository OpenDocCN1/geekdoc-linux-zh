+   4. Mount the camera's storage media by typing the following command:

```
mount /mnt/camera
```

A camera icon appears on the GNOME desktop.

+   5. Double-click the camera icon on the GNOME desktop.

The camera's contents appear in Nautilus file manager. You can double-click the folders and find the one that contains the photos. Typically, these digital photos are JPEG files with cryptic filenames that carry the .jpg extension. In the default view, Nautilus displays thumbnails of the photos, so you don't have to worry about the cryptic filenames.

+   6. Click to select the photos and copy them to your hard disk.

You can also use the cp command in a terminal to copy all or some images to a directory on your hard disk. For example, to copy all JPEG photos to the current directory, type

```
cp /camera/*.jpg
```
