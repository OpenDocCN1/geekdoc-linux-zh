A word of caution before you start configuring the kernels: Many
kernel options depend on one another. For example, if the parallel port
isn't enabled, the configuration program hides all options to parallel
port devices. The best way is to logically proceed through the configuration
steps is to start with the topmost option category in the left pane — Code
Maturity Level Options — and then continue the line of option cate-
gories. That, you may set the options in the correct order.

# Loadable module support

This group of options asks you about support for loadable modules. You def-
initely want to include support for modules, so enable the Enable Loadable
Module Support. The rest of the options are about the following fea-
tures: loading modules, requiring version information in each module, and
automatically loading required kernel modules. Enable module unloading
and automatic loading of kernel modules. That way, parts of the kernel are
bilt in the form of modules and the kernel automatically loads these
needed.
