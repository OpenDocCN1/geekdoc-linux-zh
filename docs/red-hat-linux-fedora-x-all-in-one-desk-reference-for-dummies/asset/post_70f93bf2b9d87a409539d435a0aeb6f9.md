# Commands for changing permissions and ownerships

You may need to change a file's permission settings to protect it from others. Use the chmod command to change the permission settings of a file or a directory.

To chmod effectively, you have to specify the permission settings. A good way is to concatenate letters from the columns of Table 3-4 in the order shown (Who/Action/Permission).

> Note: You use only the single character from each column — the text in parentheses is for explanation only.

| Table 3-4 |
| Who | Action | Permission |
| u (user) | + (add) | r (read) |
| g (group) | - (remove) | w (write) |
| o (others) | = (assign) | x (execute) |
| a (all) | s (set user ID) | |

For example, give everyone read access to all files in a directory, pick a (for all) from the first column, + (add) from the second column, and r (for read) from the third column to come up with the permission setting a+r. Then use the whole set of options with chmod, like this:

```
chmod a+r *
```

On the other hand, permit everyone to execute one specific file, type

```
chmod a+x filename
```

# Navigating the File System with Linux Commands

TIP Suppose you have a file named mystuff that you want to protect. You can make it accessible to no one but you if you type the following commands, in this order:

```
chmod -rwx mystuff
chmod u+rw mystuff
```

The first command turns off permissions for everyone, and the second command turns on the read and write permissions for the owner (you). Type ls -l to verify that the change took place (see a permission setting of --rw-). Here's a sample output from ls -l:

| | | | | |
|---|---|---|---|
| --rw- | 1 | naba | naba | 3 Jun 30 18:45 mystuff |

**Note:** The third and fourth fields show naba naba. These two fields show the user's and group ownership. In this case, the name of the user is naba and the name of the group is naba as well (Linux creates a group for each user).

Sometimes you want to change a user's or group ownership for everything to work correctly. For example, suppose you are instructed (by a manual, what else?) to create a directory named cups and give it the ownership of user ID 1lp and group ID sys. How do you?

Well, you can log in as root and create the directory with the command mkdir:

```
mkdir cups
```

If you check the file's details with the ls -l command, you will see that the user and group ownership is root.

TIP To change the owner, use the chown command. For example, to change the ownership of the cups directory to user ID 1lp and group ID sys, type

```
chown 1lp:sys cups
```

## Commands for working with files

To copy files from one directory to another, use the cp command. For example, to copy the file /usr/X11R/lib/X11/xinit/Xclients to the Xclients.sample file in the current directory (such as your home directory), use the following:

```
cp /usr/X11R/lib/X11/xinit/Xclients Xclients.sample
```

If you want to copy a file to the current directory but retain the original name, use a period (.) as the second argument of the cp command. Thus,

the following command copies the xorg.conf file from the /etc/X11 directory to the current directory (denoted by a single period):

```
cp /etc/X11/xorg.conf
```

The cp command makes a new copy of a file and leaves the original intact.

If you want to copy the entire contents of a directory — including all subdirectories and their contents — to another directory, use the command cp -ar sourcedir destdir (this command copies everything in sourcedir to destdir). For example, to copy all files from /etc/X11 directory to the current directory, type the following command:

```
cp -ar /etc/X11
```

To move a file to a new location, use the mv command. The original copy is gone, and a new copy appears at the destination. You can use mv to rename a file. If you want to change the name of today.list to old.list, use the mv command, as follows:

```
mv today.list old.list
```

On the other hand, if you want to move the today.list file to a subdirectory named saved, use this command:

```
mv today.list saved
```

An interesting feature of mv is that you can use it to move entire directories — with all subdirectories and files. If you have a directory named data that contains many files and subdirectories, you can move that entire directory structure to old_data by using the following command:

```
mv data old_data
```

To delete files, use the rm command. For example, to delete a file named old.list, type the following command:

```
rm old.list
```

Be careful with the rm command — especially when you log in as root. You can inadvertently delete important files with rm easily.

## Commands for working with directories

To organize files in your home directory, you have to create new directories. Use the mkdir command to create a directory. For example, to create a directory named images in the current directory, type the following:

```
mkdir images
```

After you create the directory, you can use the cd images command to change to that directory.

You can create an entire directory tree by using the -p option with the mkdir command. For example, suppose your system has a /usr/src/directory directory and you want to create the directory tree /usr/src/book/java/applets. To create this directory hierarchy, use the following command:

```
mkdir -p /usr/src/book/java/examples/applets
```

When you no longer need a directory, use the rmdir command to delete it.

You can delete a directory only when the directory is empty.

To remove an empty directory tree, you can use the -p option, like this:

```
rmdir -p /usr/src/book/java/examples/applets
```

This command removes the empty parent directories of applets. Command stops when it encounters a directory that's not empty.

## Commands for finding files

The find command is very useful for locating files (and directories) that meet your search criteria.

When I began UNIX years ago (Berkeley UNIX in the 1980s), I was confounded by the find command. I stayed with basic syntax for a long time before graduating to more complex forms. Suppose you want to find any file in the system:

```bash
find / -name "gnome*" -print
```

If you're not logged in root, you may get a bunch of error messages. If these error messages annoy you, just send them to a special file:

```bash
find / -name "gnome*" -print 2>/dev/null
```

When you become comfortable with this syntax of find, you can use other options of find. For example, to find only specific types of files (such as directories), use the type option. The following command displays top-level directory names:

```bash
find . -type d -maxdepth 1
```



You probably don't have to use the complex forms of find — if you ever need to, you can look up the rest of the find commands by using the following command:

```
man find
```

An easy way to find all files that match a name is to use the locate command that searches a periodically updated database of files on your system. For example, here's what I get when I locate xorg.conf on my system:

```
/usr/X11R6/man/man5/xorg.conf.5x.gz
/xorg.conf.new
/etc/X11/xorg.conf
```

## Commands for mounting and unmounting

Suppose you want to access the files on this book's companion DVD-ROM when you are logged in a text console (no GUI to help you). To do so, you have to first mount the DVD-ROM's file system on a specific directory in the Linux file system.

![](img/d9230b719dc0efd80851f363d8c6f571_192_0.png)

By the way, the procedure I am about to describe works for CDs as well as DVDs.

Log in root (or type su to become root), insert the DVD-ROM in the DVD drive, and then type the following command:

```
mount /dev/cdrom /mnt/cdrom
```
