# Follow These Steps

+   Insert a chart
Position the cursor and choose Insert->Chart to insert a chart number. Double-click the chart and the Impress user interface appears. To edit the chart's dummy data, choose Edit->Chart Data. The dummy data appears in a mini-spreadsheet window. To edit the data and click the green check mark. To change the chart type, choose Format->Chart Type. Then pick the chart from the resulting dialog box. Click elsewhere in the document to return to Writer.

+   Create an outline-style numbered list with items numbered 1, 1.1, 1.2, ... and so on
type the list select them, and choose the Stylist by pressing F1. Clicking the Numbered Style icon (first icon from left) and double-click the Numbered 5 style. Click in the list and note the right arrow on the object bar (bar that shows the style). Click the right arrow and the list items appear. Click sub-numbered item and then click the right arrow icon.

+   Create a hanging indent
Press F11 to display the Stylist, if not already visible. Choose the Paragraph Style icon (the first icon from left). Place the cursor in the text and then double-click the Hanging Indent style in the Stylist.

+   Preview page
Choose File->Page Preview. To return to editing, choose File->Page Preview again.

+   Show a vertical ruler
Choose Tools->Options. Then choose Document->View from the resulting dialog. Turn on the Vertical Ruler check box and click OK.

# Creating and inserting graphics

Writer includes a drawing toolbar with tools that you can use to draw in the document. You can also insert into your document both line drawings and images from files many different formats.

To create diagrams in your document, click the Show Draw Functions icon (on the toolbar on the left side of the Writer window). The Draw Functions toolbar appears, as shown in Figure 1-9.

Figure 1-9:
The Draw Functions toolbar.

![](bbox=[0.235, 0.763, 0.545, 0.803])

Click in the document where you want to add a drawing. Select a tool from the Draw Functions toolbar (refer to Figure 1-9), and start drawing. To change the drawing tool, select another tool from the Draw Functions toolbar again.
