### Exploring KDE

KDE (pronounced kay-dee) is a graphical user interface for Fedora Core. It is similar to Windows, but it has its own look. When you log in, you'll see a desktop that you can customize. If you don't like the look, you can change it in the settings. 

Here are some key facts about KDE:

- KDE is written in C++.
- KDE uses an object-oriented model.
- KDE includes an office suite: KSpread (spreadsheet), KWord (word processor), and KPresenter (presentation).
- KDE supports internationalization, and most applications are translated into over 25 languages.

To keep up with KDE news, visit the home page at kde.org.
