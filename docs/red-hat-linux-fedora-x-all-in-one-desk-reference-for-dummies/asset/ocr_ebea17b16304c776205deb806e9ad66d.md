# Learning a Security Test Methodology

#  Standalone services

Many services such as the http (Web server) and sendmail (mail server) start automatically at boot time, as they are configured to start that way. You can use the chkconfig command to check if these alone start at various run levels (see Book VI, Chapter 1 for more about run levels). Typically, the Fedora Core system starts up at level 3 (for text log) or 5 (for graphical log). Therefore, what matters is the setting for the services in levels 3 and 5. To view the list of services, type the following command:

```
chkconfig --list | more
```

...The first column shows the names of the services. Look at the column of entries that begin with 3: and the ones that begin with 5:. These columns show the status of the server for run levels 3 and 5. The ones that appear as automatically start when your Fedora Core starts.

If you're doing a self-assessment of your network security and you find that some services should not be running, you can turn them off for run levels 3 and 5 with the chkconfig command like:

```
chkconfig --level 35 servicename off
```

Replace servicename with the name of the service you want to turn off.

If you're auditing network security, make a note of all the services that are turned on and then try to determine whether they really be on, according to what you know about the system. The decision to take a particular service on depends on how your system is used (for example, as a Web server or a desktop system) and how it's connected to the Internet (saw or directly).
