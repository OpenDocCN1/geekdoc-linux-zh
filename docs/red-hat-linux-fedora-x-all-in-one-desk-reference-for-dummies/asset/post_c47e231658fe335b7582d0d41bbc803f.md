# Understanding Wireless Ethernet Networks

You've probably heard about Wi-Fi network. Wi-Fi stands for Wireless Fidelity network — a short-range wireless network similar to the wired Ethernet networks. A number of standards from an organization known as IEEE (the Institute of Electrical and Electronics Engineers) defines the technical details of how Wi-Fi networks work. Manufacturers use to build the components that you can buy to set up a wireless network, also known as WLAN for.

In Mid-2003, two popular IEEE standards — 802.11a and 802.11b — for wireless Ethernet networks. These two standards were finalized in 1999. A third standard — 802.11g was finalized by the IEEE in the summer of 2003. All these standards specify how the wireless Ethernet network works at the physical level. You don't have to fret all the details of all standards to set up a wireless network, but knowing some pertinent details is good so you can buy the right kind of equipment for your wireless network.

# 308 Understanding Wireless Ethernet Networks

The three wireless Ethernet standards have the following key characteristics:

- **802.11b**: Operates in the 2.4GHz radio band (2.4GHz to 2.4835GHz) in up to three non-overlapping bands or channels. Supports a maximum bit rate of 11 Mbps per channel. One disadvantage of 802.11b is that the 2.4GHz frequency band is crowded— devices (such as microwave ovens, cordless phones, medical and scientific equipment) as well as Bluetooth devices), work within the 2.4GHz frequency band. Nevertheless, 802.11b is very popular in corporate and home networks.
- **802.11a**: Operates in the 5GHz radio band (5.725GHz to 5.850GHz) in up to eight non-overlapping channels. Supports a maximum bit rate of 54 Mbps per channel. The 5GHz band is not as crowded as the 2.4GHz band, but the 5GHz band is not approved for use in Europe. Products conforming to 802.11a standard are available on the market, and wireless access points are designed to handle both 802.11a and 802.11 connections.
- **802.11g**: Supports up to 54 Mbps data rate in the 2.4GHz band (the same as 802.11b uses). 802.11g achieves the higher rate by using a technology called OFDM (orthogonal frequency-multiplexing), which is also used by 802.11a. Although 802.11g was only recently finalized, that probably because 802.11g has generated excitement by working in the same band as 802.11b but promising much higher data rates. Vendors are currently offering access points that support both the 802.11b and 802.11g connection standards.

The maximum data throughput that a user sees is much less because all users of radio share the channel of the channel. Also, the transfer rate decreases as the distance between the user's PC and the wireless access point increases.

To find out about wireless Ethernet, visit www.wi-fi.org, the page of the Wi-Fi Alliance — a nonprofit international association formed in 1999 to certify interoperability of wireless LAN products based on IEEE 802.11 standards.

# Understanding infrastructure and ad hoc modes

The 802.11 standard defines two modes of operation for wireless Ethernet networks: infrastructure and ad hoc. Ad hoc mode is simply or two wireless Ethernet cards communicating with each other without an access point.

Infrastructure mode refers to the approach in which all the wireless Ethernet cards communicate with each other and to the wired LAN through an access point. For the example in this book, set your wireless Ethernet card to infrastructure mode. In the configuration files, this mode is referred to as Managed mode.

# Is the WEP stream cipher good enough?

WEP uses the RC4 encryption algorithm, which is known as a short secret cipher and generates an infinite stream of pseudorandom bits. Before sending data, the sending station performs an exclusive-OR operation between the pseudorandom bits and the bits representing the data packet, which results in 1 when bits are different and 0 they are the same. The receiver has a copy of the same secret key, and generates an identical stream of bits — performs an identical exclusive-OR operation between this pseudorandom stream and the received bits. So regenerates the original, unencrypted data packet.

Experts say that both these defenses are poorly implemented, WEP ineffective. IC and IV have two main problems:

- The Integrity Check is implemented by using a checksum exclusive 32-bit cyclic redundancy check (CRC-32); that checksum is then included as part of the data packet. Unfortunately, an attacker can flip bits in an encrypted message and correctly adjust the checksum to the resulting message appears.
