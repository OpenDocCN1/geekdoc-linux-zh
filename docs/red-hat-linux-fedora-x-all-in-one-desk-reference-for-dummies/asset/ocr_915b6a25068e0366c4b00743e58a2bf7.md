# Understanding the init process

When Fedora Core boots, it loads and runs the core operating-system program from the hard drive. The core operating system is designed to run other programs. A process named init starts the initial set of processes as of your Linux system.

To see the processes currently running on the system, type

```
ps ax | more
```
