This file contains NS and A resource records that specify the names of authoritative name servers and their addresses for the root zone (indicated by the . in the first field of each record) with a semicolon.

The comment lines in the file give you hints about the location of the root name servers. There are 13 root name servers for there; most root servers are located in the United States. This file is a necessity for any name server because the name server has to be reach at least one root name server.

# The var/named/localhost.zone file

The /etc/named.conf file includes a zone statement for the localhost zone that specifies the zone file as located in the /var/named directory of Fedora Core system. Here's a listing of what the /var/named/localhost.zone file contains:

```
$TTL 86400
$ORIGIN localhost.
@ 1D IN SOA
@ root ( : serial (d. adams)
      42
      3H : refresh
      15M : retry
      1W : expiry
      1D ) : minimum

1D IN NS
@ 1D IN A
127.0.0.1
```
