NOTE
Mount/Shares works only with single servers because it is not possible to define a share or a mount for an entire name service domain. You can create a share or a mount on a specific server.

Following are the files that can be modified by the Computers/Networks tool:

+   - hosts. The hosts file is a local database that associates the names of hosts with their Internet Protocol (IP) addresses.
- ethers. This is the Ethernet address to the hostname database.
- networks. The networks file is a local source of information regarding the networks that comprise the Internet.
- netmasks. The netmasks file contains network masks used to implement IP subnetting.
