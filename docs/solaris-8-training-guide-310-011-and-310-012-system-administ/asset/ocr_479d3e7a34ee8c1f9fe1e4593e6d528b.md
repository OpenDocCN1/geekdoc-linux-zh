# DELETING A USER ACCOUNT WITH ADMINTOOL

When a user account is no longer needed on a system, delete it from the system. The following procedure describes how to perform this task.

# STEP BY STEP

# 5.2 Using Admintool to Delete an Existing User Account

Use Admintool to delete an existing user account. The procedure to delete a user account is as follows:

+   1. Start Admintool if it’s not already running, and choose Browse, Users.
2. In the Users window, select the user account entry you want to remove.
3. Choose Edit, Delete.
4. A message is displayed to confirm the removal of the user account (see Figure 5.3).
5. (Optional) Click the Delete Home Directory check box to delete the user’s home directory and its contents. If you don’t check the box, the user account will be deleted, but the contents of the user’s home directory will remain.
6. Click OK when you are ready to delete the user account. The user account entry is deleted from the Users main window.
