10. Press F2. The system automatically lays out the file systems. Sizes are determined by the software packages you selected. If you plan to add additional software, you can modify the file system sizes in later steps. You'll see the following dialogue:

Automatically Layout File Systems

On this screen you must select all the file systems you want auto-layout to create, or accept the default file systems shown.

NOTE: For small disks, it may be necessary for auto-layout to break up some of the file systems you request into smaller file systems to fit the available disk space. So, after auto-layout completes, you may find file systems in the layout that you did not select from the list below.
