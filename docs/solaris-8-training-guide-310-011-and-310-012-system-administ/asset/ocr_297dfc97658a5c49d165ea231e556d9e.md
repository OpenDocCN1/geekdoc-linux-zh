Following are the files to be modified by the Mount/Shares tool:

+   - `/etc/mnttab`. Mount information generated by the mount command.
- `/etc/dfs/sharetab`. Share information generated by the share command, which contains a table of local shared resources.
- `/etc/nfssec.conf`. Lists the authorization parameters defined on an NFS client computer.
- `/etc/nsswitch.conf`. Configuration file for the name service switch (see Chapter 18).
- `/etc/vfstab`. This file, which is read at boot time, describes defaults for each file system to be mounted.
- `/etc/dfs/dfstab`. This file is read at boot time and contains commands for sharing resources across a network.

# Serial Port Management

The Serial Ports tool is used to add and maintain port services for terminals and modems. Using Serial Port Manager to configure serial ports allows you to set up terminals and modems without having to create and edit the necessary files manually. It can display serial port information and facilitate port setup, modification, or deletion. It also provides templates for common terminal and modem configurations.
