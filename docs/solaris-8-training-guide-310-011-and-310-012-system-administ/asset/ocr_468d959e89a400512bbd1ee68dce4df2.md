# 10.1 Configuring a Printer Using Admintool

Follow these steps to configure a printer by using Admintool:

1. Type admintool to bring up the Admintool menu. The Admintool window appears.

2. Select Browse, Printers, as shown in Figure 10.1.

![](bbox=[0.122, 0.313, 0.418, 0.476])

FIGURE 10.1
Selecting printers with Admintool.

The Printers configuration window, shown in Figure 10.2, appears. Existing printers are displayed.

![](bbox=[0.121, 0.548, 0.412, 0.699])

FIGURE 10.2
The Printers configuration window.

3. Choose Edit, Add.

4. If you're configuring a print client and the print server is located across the network, physically connected to another system, select Access to Printer from the pull-down menu. The Add Access to Printer window appears, as shown in Figure 10.3.
