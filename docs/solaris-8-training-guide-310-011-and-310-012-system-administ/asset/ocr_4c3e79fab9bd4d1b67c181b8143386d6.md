# OBJECTIVES

The following are the test objectives for this chapter:

# Use Admintool or the command line to add, delete, and modify user accounts

Administering user accounts using Admintool is an efficient way to add, modify, and remove user account information. This is a routine activity for system administrators, so a complete understanding of this functionality within Admintool is required.

# Set up, customize, and administer initialization files

User sessions are customized using initialization files that are referenced each time the user logs in. Administration of each initialization file will be described.

# Administer user home directories

Administering the system involves close monitoring and administration of the user personal directories. It’s the system administrator’s responsibility to protect public and personal data in these directories.
