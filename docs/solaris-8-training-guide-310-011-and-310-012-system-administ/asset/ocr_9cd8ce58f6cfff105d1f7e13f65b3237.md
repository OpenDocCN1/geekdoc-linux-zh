# 15.2 Disabling the Power-Management Feature in Solaris

1. The easiest way to disable power management is to use the Power Management tool, dtpower. Dtpower is a GUI tool available in the Common Desktop Environment. Get to the Power Manager tool by clicking on the Desktop Controls icon located in the front panel pop-up menu, as shown in Figure 15.1.
