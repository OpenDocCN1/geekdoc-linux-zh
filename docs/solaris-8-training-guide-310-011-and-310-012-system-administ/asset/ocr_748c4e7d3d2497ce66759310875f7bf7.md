The names of the block devices for virtual volumes created using the StorEdge Volume Manager are found in the /dev/vx/dsk/<disk_group>/<volume_name> directory, and the names of the raw devices are found in the /dev/vx/rdsk/<disk_group>/<volume_name> directory. The following is an example of a block and raw logical device name:

```
/dev/vx/dsk/apps/vol01  - block device
/dev/vx/rdsk/apps/vol01  - raw device
```
