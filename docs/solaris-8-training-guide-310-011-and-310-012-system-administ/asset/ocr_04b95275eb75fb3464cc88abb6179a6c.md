# 12.3 Using the case Conditional in a Script

This exercise demonstrates the use of the case conditional statement in a script. The script will display a list of options for the user to select from. A specific command will be run based on the option that is selected.

Estimated Time: 15 minutes

+   1. In your home directory, use the vi editor to create a file named *options* with the following entries:
2. Set execute permissions on the file named *options*:
3. Execute the script and enter a, b, or c and watch the results:

```
#!/bin/sh
echo Please enter the letter next to the \
command that you want to select:
echo 'a  date'
echo 'b  ls'
echo 'c  who'
read choice
case $choice in
  a) date;;
  b) ls;;
  c) who;;
  *)  echo Invalid choice - Bye.
esac
```

```
chmod 744 options
```

```
./options
```
