# PROM Full Device Names

OpenBoot deals directly with hardware devices in the system. Each device has a unique name, representing both the type of device and the location of that device in the system-addressing structure called the device tree. The OpenBoot firmware builds a device tree for all devices from information gathered at POST. The device tree is loaded into memory to be used by the kernel during boot to identify all configured devices. The following example shows a full device pathname for a system with SBus architecture, such as a SPARCstation20:

```
/sbus@1f,0/esp@0,40000/sd@3,0:a
```

This example shows a full device pathname for a PCI bus system, such as an Ultra5:

```
/pci@1f,0/pci@1,1/ide@3/disk
```
