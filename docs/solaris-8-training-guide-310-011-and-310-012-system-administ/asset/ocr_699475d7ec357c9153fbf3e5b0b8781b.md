I also described the TMPFS file system, and how it can improve the performance of your applications by reading and writing temporary files to memory versus a local disk. You learned that the fdfs file system maintains a repository of file descriptors for open files. Finally, you learned how the operating system utilizes the swapfs file system as virtual memory storage when the system does not have enough physical memory to handle the needs of the currently running processes.
