This chapter described the fundamentals of installing a system. It described the steps of preparation that the system administrator must perform before installing Solaris 8. The chapter also addressed the topics and terms you'll need to know when taking the first Solaris certified system administrator exam.

Other chapters in this book discuss the various installation procedures—such as JumpStart, Web Start, and installation of a server using the Interactive Installation program—in more detail to prepare you for taking the second exam. Subsequent chapters also discuss post-installation procedures, such as setting up print queues, adding users, and setting up a backup procedure.
