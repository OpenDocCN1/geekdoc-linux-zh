# How to Use This Book

New Riders has made an effort in its Training Guide series to make the information as accessible as possible for the purposes of learning the certification material. Here, you have an opportunity to view the many instructional features that have been incorporated into the books to achieve that goal.

# CHAPTER OPENER

Each chapter begins with a set of features designed to allow you to maximize study time for that material.

**List of Objectives:** Each chapter begins with a list of the objectives.

![](bbox=[0.42, 0.41, 0.97, 0.91])

**Objective Explanations:** Immediately following each objective is an explanation of it, providing context that defines it more meaningfully in relation to the exam. Because the objectives list can sometimes be vague, the objective explanations are designed to clarify any vagueness by relying on the author's test-taking experience.
