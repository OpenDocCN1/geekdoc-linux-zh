# Understand the Automated Security Enhancement Tool (ASET)

Solaris provides the Automated Security Enhancement Tool (ASET) for keeping your operating system secure. ASET is a tool for setting up and monitoring security on a Solaris system. The system administrator will use it to make specific checks and adjustments to system files and permissions to ensure system security.
