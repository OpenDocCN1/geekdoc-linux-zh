# STEP BY STEP

# B.3 Adding a Workspace

To add a workspace, follow these steps:

+   1. Point to any area in the workspace switch, and click the third mouse button to display the pop-up menu.
2. Choose Add Workspace from the pop-up menu. The new workspace, named New, is placed at the end of the set of workspaces. (If more than one new workspace is created, the workspaces are named New_1, New_2, and so on.)
3. Rename the workspace as described earlier.

# STEP BY STEP

# B.4 Removing a Workspace

To remove a workspace, follow these steps:

+   1. Point to the workspace button of the workspace you want to remove.
2. Choose Delete from the button's pop-up menu (displayed when you press the third mouse button).
