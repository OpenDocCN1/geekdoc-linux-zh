# rcp

You can also use the rcp (remote copy) command to transfer one or more files between two hosts on a network. The other system must trust your ID on the current host. This trust relationship was discussed in Chapter 8.

The rcp command is more convenient than ftp. First, rcp does not require a login or password if the proper trust relationship exists between the systems, which makes it suitable for scripts. Second, rcp allows complete directory trees to be copied from one system to another. However, ftp has more options and is considered more secure. Following is a sample use of rcp:

```
rcp /etc/hosts systemB:/etc/hosts
```

This example uses rcp to copy the file /etc/hosts from the local system to systemB.
