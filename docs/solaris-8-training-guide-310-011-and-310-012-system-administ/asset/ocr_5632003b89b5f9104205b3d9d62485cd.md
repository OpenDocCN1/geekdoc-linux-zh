# 21.1 Creating JumpStart Servers

In this exercise, you’ll create a JumpStart boot server, install server, configuration server, and configuration files; and configure a JumpStart client to automatically install the Solaris 8 Operating environment across the network.

For this exercise, you’ll need two systems connected on a network. One system will serve as the boot/install/configuration server, so it needs at least 1GB of free disk space. The second system will be the client, and will have the entire disk destroyed and the operating system reloaded.

> CAUTION
This procedure destroys data on the disk. Be sure you have proper backups if you want to save any data on these systems.
