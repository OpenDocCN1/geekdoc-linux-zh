> NOTE
I usually wait until after the initial software installation to set up these mounts. Many times, the system is not connected to a production network at this point, so the mount points are unavailable. It's also a personal preference to save this task for the post-installation phase, when I set up users, printers, and so on. I have a checklist of all the things I need to do after software installation, and setting up mount points is one of them.
