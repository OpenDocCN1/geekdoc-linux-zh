
# Ubuntu OS 入门指南：Linux 开源操作系统极简指南

## 介绍

你可能用过 Windows；可能用过 macOS。但 Linux 呢？

Linux 已经存在很多年了，但尚未被普及。这并不是说它不强大。有些人认为它比任何操作系统都强大。

本书将介绍最流行的版本：`Ubuntu`。

你将学习：

- 安装 Ubuntu
- 所在位置
- 核心功能概述
- 使用 Ubuntu 工具
- 使用 Ubuntu 设置
- 以及更多

本书适用于从未用过 Ubuntu 或仍在考虑是否使用的初学者。

### 安装 Ubuntu

在运行 Ubuntu 之前，你首先需要拥有它。如果你使用的电脑已经安装了，显然可以跳过此节。

### 系统要求

虽然你可以在高性能处理器和内存的大型电脑上运行 Ubuntu，但 Ubuntu 的设计兼容旧电脑；许多人在旧电脑上安装了它，所以这是合理的。最低系统要求如下：

- 2 GHz 双核处理器
- 4 GB RAM（系统内存）
- 25 GB 硬盘空间（或 USB 盘、内存卡或外部硬盘）
- 能够 1024x768 分辨率的 VGA 接口
- 具有光驱/DVD 驱动器或用于安装介质的 USB 端口
- 网络访问会有帮助

### 如何获取 Ubuntu

获取 Ubuntu 有三种方法：简单的方法、稍微困难的方法以及最困难的方法；这并不是说这些方法都很复杂。

如果你不想费力，且不想在电脑上安装 Ubuntu，我建议在网上购买一个预装了 Ubuntu 的 USB 盘；它们通常售价 20 美元左右，它们的优点是让你可以在电脑上运行它而无需实际安装——它从 USB 启动。你关闭电脑，然后从 USB 重启；当你用完后，关闭 Ubuntu 并拔掉 USB。当你重启电脑时，默认操作系统仍然在那里——以及你所有的程序和文件。

你也可以用空闲的 USB 盘自己操作，但你需要在网上找一份教你如何安装的指南。

下一种方法是在虚拟机中运行；这意味着你在你的电脑上安装虚拟软件，并在该虚拟软件内部运行它。这意味着你的常规操作系统和 Ubuntu 将同时运行。这是我目前正在使用的方法。

我在 Mac 上使用 `Parallels`（Windows 也有提供）；还有其他工作原理类似的软件。

下载 `Parallels` 后，它会询问你想要安装哪种操作系统（它支持 Windows 和 Linux）；如果系统没有提示你安装，你只需点击右上角的 `+` 符号即可。

这里有一个下载 Ubuntu 的选项，它是免费的（不过，`Parallels` 本身不是免费的）。

![图形用户界面，应用程序描述自动生成](img/image-5A3TSIUU.png)

它会告诉你你需要的空间大小，然后点击 `Download` 开始。

![图形用户界面，网站描述自动生成](img/image-E4VZBD1J.png)

安装完成后，任何你想运行 Ubuntu 的时候，只需打开 `Parallels` 并从 `Control Center`（控制中心）框中点击它。

![图形用户界面，文本，应用程序描述自动生成](img/image-JFZKCXTO.png)

注意下方的截图，当 Ubuntu 运行时，Mac OS 菜单栏是可见的？那是因为它们是同时运行的。

![电脑屏幕截图，中等置信度自动生成](img/image-8FR79MJ9.png)

同时运行两个操作系统需要消耗大量的性能，所以除非你的电脑较新并且支持它，否则不要这样做——否则，你会发现运行速度非常慢。

最后，获取 Ubuntu 的最后方法是前往 `https://ubuntu.com` 下载它，然后按照指令在你的电脑上原生运行它——这意味着你的电脑会被擦除，并且每次启动时，它都会运行 Ubuntu。你的电脑将成为一台专属的 Ubuntu 电脑。

### 菜单

Ubuntu 的顶部菜单比许多操作系统都要基础得多。它有日期，并在最右侧有三个选项。

当打开不同的应用程序时，菜单栏会发生变化，但仍然保持着非常简洁的设计。

在许多操作系统中，右上角菜单中的每个图标都会打开一个独立的菜单；Ubuntu 则并非如此——点击其中任何一个，都会打开相同的选项菜单。

![图形用户界面，应用程序描述自动生成](img/image-WYBSKSUQ.png)

选项右侧的箭头告诉你还有更多可用选项。例如，在 `Wired Connection`（有线连接）下，你可以关闭连接，或者进入网络设置。

![图形用户界面，文本，应用程序，聊天或文本消息描述自动生成](img/image-ULJ53JNS.png)

如果你有一台依赖电池的笔记本电脑，`Power Settings`（电源设置）是你可能深入研究的内容——如果你希望台式机在使用时关闭显示，或者不想消耗那么多电，你也可以去这里。

![图形用户界面，文本，应用程序描述自动生成](img/image-GJ5H85Z1.png)

电池选项菜单只有三个；看起来其中任何一个都不像按钮，但如果你点击它们，它们会弹出窗口。

![图形用户界面，文本，应用程序，电子邮件描述自动生成](img/image-D7OG9V1Z.png)

要关闭任何窗口，只需点击右上角的 `X`（它会自动保存）。

![图形用户界面，应用程序描述自动生成](img/image-BDIRMG9O.png)

当你准备好关闭电脑时，有几个选项：

- **Lock**（锁定）：这会让电脑开启，但在前面显示一个登录屏幕；如果你只是去喝咖啡，不想在你离开时别人使用电脑，这样很好。
- **Log Out**（注销）：退出账户并返回登录屏幕。
- **Suspend**（挂起）：将电脑置于待机模式。
- **Power Off**（关机）：你的电脑完全关闭。

### 桌面

桌面基本上是空的。你可以将应用程序拖到桌面创建快捷方式。你也可以在桌面任何地方点击右键打开更多选项。其中许多你可能不会用到——例如 `Open in Terminal`（在终端打开）是一个类似 DOS 的命令行程序，书中不会介绍。

大多数人可能想要更改背景。

![图形用户界面，应用程序描述自动生成](img/image-XQNOFBZ)

当你点击 `Change Background`（更改背景）时，会弹出一个显示可用壁纸的窗口。

![图形用户界面，应用程序，PowerPoint 描述自动生成](img/image-BWZJLJW)

可选的背景并不多；如果你想添加自己的，只需点击右上角的 `Add Picture`（添加图片）。

当你开始在 Ubuntu 上删除东西时，它们会进入 `Trash`（垃圾桶），就像在任何操作系统上一样；你可以同样清空它——右键点击，然后选择 `Empty Trash`（清空垃圾桶）。

![包含文本的图片自动生成](img/image-6FUK5LA)

### 收藏夹栏

收藏夹栏用于你最常用的应用程序；其设计理念是提供快速方便的访问。

![图形用户界面描述自动生成](img/image-57YK5MZ)

看到它在左侧可能会有点奇怪；例如在 Windows 和 Mac 上，你会在底部看到类似的东西。而且你无法像 Windows 那样方便地移动它。不过，你可以将其移动到右侧或底部——这在 `Settings` 中，我将在后书中介绍。

收藏夹栏上的程序是安装 Ubuntu 时默认存在的——这意味着它们可能不是你的收藏。如果某个程序你不会使用，右键点击它，然后点击 `Remove from Favorites`（从收藏夹中移除）。

你已经看到如何使用`System Monitor`（系统监视器）查看哪些程序占用了内存。但你该做什么来停止这些占用内存的程序呢？

如果你进入`Processes`（进程），然后按“Memory（内存）”排序，你可以看到哪些程序最内存内存；右键点击进程名称，将获得结束或杀死它的选项。

### 下载桌面环境

如果你用过 Windows 或 Mac，那么当新的大更新发布时，你可能会兴奋，因为这意味着事情可能真的看起来不同了；这在 Ubuntu 上“某种程度上”是真的，因为它们确实有更改视觉和体验的更新；但你也可以通过下载新的桌面环境来改变视觉和体验。

### 安装软件

你已经看到了 Ubuntu 为你提供的软件。但还有非常多！这里是一些值得尝试的流行程序。

- `VLC` - 如果你经常看下载的电影，那么最好的视频播放器可能是`VLC` (https://www.videolan.org/vlc/index.html)。

- `Gimp` - 如果你计划编辑图形和图像，那么首选程序是`Gimp` (https://www.gimp.org)。

- `Telegraph` - 对于文本消息，Telegraph 已成为 Ubuntu 以及其他操作系统上最流行的解决方案之一 (https://telegram.org)。

- `Kdenlive Video Editor` - Ubuntu 并不完全以视频编辑而闻名，但这并不意味着不能这样做；如果你想在 Ubuntu 操作系统内编辑视频，`Kdenlive Video Editor` (https://kdenlive.org/) 是一个高效的视频编辑器。

- `Foliate` - 如果你想在 Ubuntu 上看书，那么你需要一个电子阅读器，遗憾的是，大多数电子书商店没有提供这些应用的 Linux 版本；如果你需要一个电子阅读器来读书，请尝试`Foliate` (https://johnfactotum.github.io/foliate/)。

- `Lollypop` - Ubuntu 自带的音乐播放器非常好用；但如果你想尝试替代方案，`Lollypop` (https://wiki.gnome.org/Apps/Lollypop) 是一个很棒的平台。

- `Cawbird` - 如果你热爱推特，Cawbird 是在 Ubuntu 上以及在其他操作系统上最流行的解决方案之一 (https://telegram.org/)。

- `Chrome` - `Firefox` 是一个快速且有效的浏览器；如果你还喜欢 [Chrome](https://www.google.com/)。
