### Introduction

You’ve probably used Windows OS; maybe you’ve used MacOS. But Linux?

Linux has been around for years, but it’s still relatively unused by the masses. This isn’t to say it isn’t powerful. Some argue that it’s more powerful than any OS out there.

This book will cover arguably the most popular version of Linux: Ubuntu.

You’ll learn about:

Installing Ubuntu

Where things are

An overview of the core features

An overview of the software

Using Ubuntu Utilities

Using Ubuntu settings

And more

The book is intended for beginners who have never used Ubuntu or are still considering whether or not they want to download it.

#### Installing Ubuntu

Before you can use Ubuntu, you need to first have Ubuntu. If you’re using a computer that already has it, then you can obviously skip this section.

#### System Requirements

While you can certainly use Ubuntu on a heavy duty computer with lots of processing power and RAM, Ubuntu was built to be compatible with older computers; many people have Ubuntu set up on old computers, so this makes sense. The barebones system requirements are below:

2 GHz dual core processor

4 GB RAM (system memory)

25 GB of hard-drive space (or USB stick, memory card or external drive)

VGA capable of 1024x768 screen resolution

Either a CD/DVD drive or a USB port for the installer media

Internet access is helpful

#### How to Get Ubuntu

There are really three approaches to getting Ubuntu: the easy way, the slightly harder way, and the hardest way; that’s not to say any of these approaches are complicated—but some are easier than others.

If you want zero effort, and don’t want to install Ubuntu on your computer, then I recommend going online and buying a USB drive with Ubuntu pre-installed; they typically cost around $20, and the benefit of them is you can run it on your computer without actually installing it—it boots from the USB. You turn off your computer, and reboot it from the USB; when you are done using it, you shut down Ubuntu, and remove the USB. Once you reboot your computer, the default operating system is still there—along with all of your programs and files.

You can also do this yourself if you have a spare USB, but you will need to find a guide online that shows you how to install it.

The next approach would be to run it in a virtual client; what that means is you install virtual software on your computer and you run it within that virtual software. That means your regular operating system and Ubuntu are running at the same time. This is the method I currently use.

I use Parallels for Mac (it’s also available for Windows); there is other software that works in a similar way.

After downloading Parallels, it will ask you what Operating System you want to install (it supports Windows and Linux); if you aren’t prompted to install it, then you would just click the + in the upper right corner.

￼

There’s an option to download Ubuntu, which is free (Parallels, however, is not free).

￼

![Graphical user interface, application Description automatically generated](Images/image-5A3TSIUU.png)

It will tell you the amount of space you need, and you click Download to begin.

￼

![Graphical user interface, website Description automatically generated](Images/image-E4VZBD1J.png)

Once it’s installed, anytime you want to run Ubuntu, you just open Parallels and click it from the Control Center box.

￼

![Graphical user interface, text, application Description automatically generated](Images/image-JFZKCXTO.png)

Notice in the screenshot below that the Mac OS menu bar is visible while Ubuntu is running? That’s because they are running at the same time.

￼

![A screenshot of a computer screen Description automatically generated with medium confidence](Images/image-8FR79MJ9.png)

It does take a lot of power to run to operating systems together, so don’t do this unless your computer is newer and can support it—otherwise, you’ll find things run pretty slow.

Finally, the last way to get Ubuntu is to go to https://ubuntu.com and download it, then follow the instructions to run it on your computer natively—that means your computer is erased and every time you boot it, it will run Ubuntu. Your computer will be an exclusively Ubuntu computer.

#### Creating an Account

The first time you run Ubuntu, it will ask at launch if you want to connect or create an account. You can either connect it or skip it (skip is in the upper right corner); if you are using Ubuntu on multiple devices or from a USB stick, then connecting it would be a good idea, as it will sync everything in the cloud.

￼

![Graphical user interface, application Description automatically generated](Images/image-1K8SGC83.png)

You’ll probably notice right away that Ubuntu bears a lot of similarities to Windows and Mac. There’s an app bar, a desktop and even a trash bin.

￼

![A screenshot of a computer screen Description automatically generated with medium confidence](Images/image-Y2BTGD1K.png)

Let’s look at the four main components of Ubuntu: the top menu bar, the desktop, the favorites bar, and the apps menu.

#### The Menu

The top menu of Ubuntu is a lot more basic than many operating systems. It has the date, and three options to the far right side.

The bar does change when different apps are open, but still keeps a pretty barebones design.

On many operating systems, each icon in the upper right menu will open a separate menu; not so with Ubuntu—click on any of them, and the same options menu opens.

￼

![Graphical user interface, application Description automatically generated](Images/image-WYBSKSUQ.png)

The arrow to the right of the option tells you there are more options available. Under Wired Connection, for example, you can turn off the connection, or go into your network settings.

￼

![Graphical user interface, text, application, chat or text message Description automatically generated](Images/image-ULJ53JNS.png)

Power Settings is something you might want to dig further into if you have a laptop that relies on a battery source—you may also want to go here on a desktop if you want to have your monitor turn off when not in use or just don’t want to consume as much electricity.

￼

![Graphical user interface, text, application Description automatically generated](Images/image-GJ5H85Z1.png)

The battery options menu has just three options; it doesn't look like any of them are buttons, but if you click them, they do open into pop out boxes.

￼

![Graphical user interface, text, application, email Description automatically generated](Images/image-D7OG9V1Z.png)

To close any of the boxes, just click the X in the upper right corner (it saves automatically).

￼

![Graphical user interface, application Description automatically generated](Images/image-BDIRMG9O.png)

There are a few options when you are ready to turn off your computer:

Lock - This keeps the computer on, but puts a login screen in front of it; it’s good if you are taking a coffee break and just don’t want anyone to use your computer while you are away.

Log Out - Logs out of your account and returns to the login screen.

Suspend - Puts your computer into a standby mode.

Power Off - Your computer is completely off.

￼

![Graphical user interface, text, application Description automatically generated](Images/image-MA1X1O92.png)

#### The Desktop

The desktop is going to be pretty empty. You can drag apps onto the desktop to create shortcuts. You can also right click anywhere on the desktop to open a few more options. Most of them you won’t be using—Open in Terminal, for example, is a DOS-like command program that won’t be covered in this book.

The option most people will probably want to change is the background.

￼

![Graphical user interface, application Description automatically generated](Images/image-XQNOF0BZ.png)

When you click Change Background, a window opens up with wallpapers that are available.

￼

![Graphical user interface, application, PowerPoint Description automatically generated](Images/image-BWZJLJWJ.png)

There are not a lot of backgrounds to choose from; if you want to add your own, just click Add Picture in the upper corner.

￼

As you start deleting things on Ubuntu, they’ll go into the Trash like they would on any operating system; you can empty it the same way—right click it, then select Empty Trash.

￼

![A picture containing text, sign Description automatically generated](Images/image-6FUKH5LA.png)

#### Favorites Bar

The Favorites Bar is home to the applications you use most; the idea is to give you quick and easy access.

￼

![Graphical user interface Description automatically generated](Images/image-57YK5MZ1.png)

It may be a little odd seeing it on the left; on Windows and Mac, for example, you’ll see something similar on the bottom. And you can’t move it around easily like you can on Windows if you don’t like the placement. You can, however, move it to the right or bottom—it’s in Settings and I’ll cover it later in the book.

The programs you see on the Favorites Bar are there by default when you install Ubuntu—that means they might not be your favorites. If it’s something you won’t use, then right click it, and click Remove from Favorites.

￼

![Graphical user interface, text, application, chat or text message Description automatically generated](Images/image-ADW9GMAW.png)

#### Apps Launcher / Menu

Finally, the last area—it’s on the bottom of your Favorites Bar—is the app launcher. This is where you’ll find all the programs currently installed on Ubuntu.

￼

There are not that many when you first install it—just two screens—but you can search for the program at the top to make it a little easier.

￼

![A screenshot of a computer Description automatically generated with medium confidence](Images/image-E3ZVBS1U.png)

On the bottom, you can also toggle between All and Frequent to show only the programs that you use most.

￼

![A picture containing text, device Description automatically generated](Images/image-PHZA24TP.png)

If you want to copy (this will not move it entirely, so you’ll still have a copy in the apps menu) any of the programs to your Favorites Bar, then right click the program and click Add to Favorites.

￼

![A picture containing text, sign Description automatically generated](Images/image-X7TD6N7Z.png)

### Grouping Apps

When you start getting a lot of apps, it makes sense to group them to make it easier to find what you are looking for. For example, you can put all your games in one place. To group apps, click and hold the app that you want to group, then move it on top of the app you want to group it with.

￼

![Graphical user interface, application Description automatically generated](Images/image-F2I82A26.png)

One you release your mouse, they’ll be grouped together. You can continue to group by dragging other apps into that same folder.

￼

Inside the All Apps menu is a folder called Utilities; as you can expect from the name, this is where programs are that perform actions to help you monitor your computer and documents.

￼

![A screen shot of a phone Description automatically generated with medium confidence](Images/image-INCH4Y1V.png)

Some of these programs you’ll use more often than others—some you will not use at all. To help you understand each, this chapter will give you an overview of what each program does.

Archive Manager

Have you ever opened your email and got an attached message that is Zipped? That’s called an archive file and that’s what an archive manager does.

￼

To create an archive (compressed) file, click the + button.

￼

![Graphical user interface, application Description automatically generated](Images/image-W2E1XS7V.png)

Next, name your file, select the compression type (e.g. .tar.gz), and select the location of the folder.

￼

![Graphical user interface, application Description automatically generated](Images/image-DW7UXAMV.png)

Under Other Options, you can create a password to encrypt the file and split it into volumes.

￼

![Graphical user interface, text, application Description automatically generated](Images/image-6R8MQIFL.png)

Backups

Backups creates a backup of your computer in case you do something wrong and need to reinstall a disk image; you can get started once you open the program by clicking on Create Backup. You may need to install additional files.

￼

Calculator

Calculator is probably what you expect: a calculator.

￼

But it’s more than a basic calculator; you can select from the dropdown to select different calculator types: basic, advanced, financial, programming and keyboard.

￼

![A picture containing text, screenshot, electronics Description automatically generated](Images/image-V78LNR17.png)

Each mode has a unique interface to make calculations easier.

￼

![A screen shot of a calculator Description automatically generated with medium confidence](Images/image-FEOXSW9F.png)

Characters

Characters is a little confusing; from the icon it looks like it’s where you go to add characters and symbols to your text. That’s only partly true.

￼

![Graphical user interface, text, application, chat or text message Description automatically generated](Images/image-53KMMFM0.png)

A better name for the Characters app might be emojis. You get a list of hundreds of symbols, characters and emojis.

￼

![A picture containing shape Description automatically generated](Images/image-WRCAS1A2.png)

When you click on one, you can copy it and then paste it into your document.

￼

![Graphical user interface, application Description automatically generated](Images/image-BM36ANLK.png)

Disk Usage Analyzer

There isn’t a lot to the Disk Usage Analyzer. It helps you visualize how much storage you have on each of your drives.

￼

![A picture containing logo Description automatically generated](Images/image-SOQYKSNI.png)

Disks

Disks is where you go to create more volumes.

￼

![A picture containing text, electronics, iPod, sign Description automatically generated](Images/image-L05LY29R.png)

You may have one hard drive on your computer, but you can split that hard drive up into different images and have multiple volumes to it. For example, I have MacOS installed on one image, and I store all the Ubutu files on another.

￼

![Graphical user interface, application Description automatically generated](Images/image-ST6GZPCY.png)

Document Scanner

Document Scanner will only apply if you have a scanner attached to your computer.

￼

![Graphical user interface, text, application Description automatically generated](Images/image-OUD7CLO1.png)

Under the scan options you can select how you want to scan your document and what type of document it is.

￼

![Graphical user interface, application Description automatically generated](Images/image-ZHLIJ2KI.png)

Document Viewer

Document Viewer lets you view (but not edit) documents.

￼

Fonts

Fonts shows the fonts installed on your computer and lets you add and remove more.

￼

![A picture containing text, sign, electronics, close Description automatically generated](Images/image-MWQZIPVV.png)

Help

Help is where you’ll find the Ubuntu user guide.

￼

It breaks everything down by topic.

￼

![Graphical user interface, text, application Description automatically generated](Images/image-3FY8BFW6.png)

Image Viewer

Document Viewer is where you view documents and Image Viewer is where you view images.

￼

Logs

Anytime there is a bug or problem with software, you’ll get a record of it in your log—even if you don’t notice the bug. This is handy if you are troubleshooting a problem with software—sometimes they ask for a log.

￼

![A picture containing graphical user interface Description automatically generated](Images/image-METINJ7V.png)

When you open it, it will show the Important logs first, followed by logs by category.

￼

![Graphical user interface, application Description automatically generated](Images/image-QS12LBTB.png)

Passwords and Keys

Have you ever been on the Internet and it says “would you like to remember this password”; if you say yes, it stores them here.

￼

![Application Description automatically generated with low confidence](Images/image-3BZGQLF4.png)

You can view all of your passwords and keys or add new ones.

￼

![Graphical user interface, application Description automatically generated](Images/image-2SNJ0S9L.png)

Screenshot

Screenshot lets you capture what you see on your screen.

￼

You can either screenshot entire screens or segments of a screen or window.

￼

![Graphical user interface, text, application, chat or text message Description automatically generated](Images/image-LT6O7FY8.png)

System Monitor

As the name implies, System Monitor is where you can monitor your computer.

￼

![Text Description automatically generated](Images/image-HB5R3O1Q.png)

If your computer seems to be running slower than expected, you can use it to visualize how fast it’s going and how much memory it is using. From there, you can decide if you need to close more advanced programs.

￼

![A picture containing scatter chart Description automatically generated](Images/image-XLKT6VWO.png)

Terminal

If you have been using a computer long enough, then you probably remember the good old days of Microsoft DOS and command line. That’s Terminal.

￼

You probably won’t use Terminal that much (if you use it at all) but the idea of Terminal is to give you a place to add those old command lines you used to do in DOS. It’s a powerful program, but more for advanced users.

￼

![Text Description automatically generated](Images/image-Z92PDA5V.png)

## Tips & Tricks

| This chapter will cover: Parting tips to help you get the most out of Ubuntu |

Now that you know your way around Ubuntu, below are a few tips and tricks to help you get the most of it.

Terminate Unresponsive Programs

You’ve seen how you can use System Monitor to see what is hogging memory. But what do you do to stop whatever is hogging the memory?

￼

If you go to Processes, then sort by “Memory” you can see what is using the most memory; right click on the process name and you’ll get an option to end or kill it.

￼

![Table Description automatically generated](Images/image-01ROQXK1.png)

Download a Desktop Environment

If you’ve used Windows or Mac, then you probably get excited when a new big update comes out because it means things might actually look different; this is “kind of” true on Ubuntu, because they do have updates that change the look and feel; but you can also change the look and feel by downloading a new desktop environment.

￼

![A screenshot of a computer Description automatically generated with low confidence](Images/image-SE1ZU2FL.png)

Desktop environments come in all sorts of styles. Google “Linux Desktop Environment” and you’ll see what I mean—but download at your own risk; some environments are more reputable that others.

Install Software

You’ve seen the software that Ubuntu has to offer you. But there’s so much more! Here are some popular programs to check out.

VLC - If you watch a lot of movies that you download then perhaps the best video player is VLC (https://www.videolan.org/vlc/index.html).

Gimp - If you plan on editing graphics and images, then the go-to program is Gimp (https://www.gimp.org).

Telegraph - For text messaging, Telegraph has become one of the most popular solutions not only on Ubuntu but on other operating systems (https://telegram.org).

Kdenlive Video Editor - Ubuntu isn’t exactly known for video editing, but that doesn’t mean it can’t be done; Kdenlive Video Editor (https://kdenlive.org/) is an effective video editor if you want to edit your videos within the Ubuntu OS.

Foliate - If you want to read books on Ubuntu, then you need an eReader, and unfortunately most eBook stores don’t offer a Linux equivalent of their apps; if you want an eReader to read your books, then try Foliate (https://johnfactotum.github.io/foliate/).

Lollypop - The music player that comes with Ubuntu works great; but if you want to try an alternative, then Lollypop (https://wiki.gnome.org/Apps/Lollypop) is a great platform.

Cawbird - If you are in love with tweets, then you’ll need a Twitter client that runs in Linux; you can’t go wrong with the Cawbird Twitter client (https://ibboard.co.uk/cawbird/).

Chrome - Firefox is a fast and effective web browser; but if you are still living in a Google world, don’t fret: Google Chrome is available on Ubuntu. Get it here: https://www.google.com/chrome/

Install Games

You’ve probably heard about Switch, Xbox and PlayStation; but arguably the most popular gaming system is none of those. It’s Steam.

Steam is a popular gaming platform that lets you play video games across several operating systems—including Ubuntu. It’s free to download. Game prices vary, but are frequently cheaper than what you would pay on traditional gaming devices.
