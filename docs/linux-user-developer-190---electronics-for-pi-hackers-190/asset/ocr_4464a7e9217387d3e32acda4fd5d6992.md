# Create types in Ada

Ada provides support for typing. If we wrote, for example, a word-processing program, we might have some integer variables that hold number of columns and some that hold rows of them. In Cor C++, we use typedef to tell it all these.

```
typedef int number_of_rows;
typed int number_of_columns;
```

However, these definitions are nothing more than aliases for types, and they pose no restrictions on what we can do with them. For example, if we used the typedefs above, then the following code would be legal in C.

```
number_of_rows := 4;
number_of_columns := 8;

```

# Object-oriented programming in Ada

If we want to use Ada as a replacement for C++, it's useful to write programs in an object-oriented style. To large extent, this is possible in Ada using a package that contains variables (the equivalent of field) and functions and procedures (the equivalent of methods). Ada supports types, which are like C structs but with a type definition.

The 1995 version of Ada extends this basic language to support fully object-oriented programming. The new Ada introduces notions of inheritance and polymorphism, which enables us to encapsulate a state with the familiar keyword 'private'.

The following example on the coverdisc contains a basic implementation of an object-oriented package called Planes. Plane uses a private type to hide the data and includes various (functions and procedures) that perform various actions on a Plane instance.

One difference with C++ is that these functions and procedures pass objects by value, which is implicit in C++ but not in Ada. Ada supports a syntax-like way of calling methods.
