## Chrome-OS inspired

The success of Chrome OS has led to distributions that mimic its ultra-light, web-focused approach.

When Chrome first launched, many scoffed its chances of making a significant impact on the computing world. After all, who would really want an OS that basically runs a web browser? It turned out, quite a few people did.

Chrome OS is gaining popularity, particularly in the low-cost and educational markets, and by its simplicity and Material Design visuals it clearly appealed to more people than expected. Given this success, it is no surprise that Linux developers have found fit to suit distributions that echo the Chrome OS approach.

Of course, Chrome OS itself can be installed via source-based projects such as the immersive Chromium Cloudy (the framework acquired by the developers of Flint, or for non-chromium distributions taking a slightly different approach like Linux

The result is an OS that, still in its early stages, is ready as a daily driver for the next-gen contender.

Another impact of Chromebooks is that they provide access to powerful hardware that's more capable of running Linux distros. If you have a Chromebook, you can either stick with Chrome OS and run Linux using a utility such as Croton, or de-couple Linux using an alternative such as gallium.os.

Gallium is a Ubuntu-based distro that incorporates perfect tweaks and fixes to enable it to run on ChromeOS, with an improved touchpad driver and fixed-related bugs. The result is an OS as fast as Chrome OS, but with most of the benefits.

## DISTRO SPOTLIGHT

- ### Android-x86
Linux underneath is currently the most popular mobile operating system. But its use isn't limited to mobiles – you can run it on your PC too, using this project.

- ### Bliss OS
Android-x86 works well on a tablet, but Bliss OS is bad for using a distro with an Android because it is an Android-based OS specifically optimised for laptops and desktops. The community-based release is surprisingly stable.

- ### Tails
Privacy is a growing concern so it's not a bad idea to carry a portable USB with a distro for it to use on unfamiliar PCs. Tails is for this – entirely self-contained and leaves no trace on the system.

- ### Subgraph OS
Subgraph is a hardened distro based on Debian Linux, designed to be perfectly resistant to surveillance and interference by third parties. It's now in alpha.

## Safe and secure

## Safety and security environments are hot topics in today's always-connected environments, and Linux distros are reflecting this mindset.

When you're working on your computer, you expect your data to be safe. If you're not someone who is specifically at risk, you expect security for granted, but this hasn't been a major focus - Linux has enjoyed some of the 'security through obscurity' resistance to attacks together with the nature of open source, so most mainstream distros haven't truly fortified their security features. This is slowly changing, however, with the rise of distros like PureOS.

PureOS is a Debian-based distro using the Gnome desktop environment which comes with leading privacy-protect applications. Out of which you'll find

At the other end of the spectrum we have Qubes OS (https://www.qubes-os.org/), the 'reasonably secure operating system', which focuses on software rewired units. Each compartment remains secure against cross-compartmental attacks using the Xen hypervisor - by many major providers to isolate websites and each other. Each known as a cube, remains completely secure against contamination from another Qube.

PureOS takes a very light touch on privacy, making it closer to a standard than Subgraph for example, but also doesn't implement the level of security. PureOS is available as a pre-installed option on several distros from Purism, but is also releasing a PureOS-based phone.
