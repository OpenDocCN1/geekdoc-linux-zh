# Purism up the ante for laptop security

Tamper-proof laptops and encryption partnership to secure laptops and upcoming Librem 5 front

Purism's continued focus on producing the most secure, private laptops resulted in a new partnership with eclectic security firm Treadmill Hudson. His Heads security firmware has been integrated into Trusted Platform Module chips, delivering enhanced protection for users of Purism's Linux hardware.
The result of this development, however, will require some hardware changes, reboot modifications, and of course operating system updates. As Purism CEO Cosmo Wohl says, 'Your privacy depends on freedom. By having true privacy means your computer and data should be under your control, and not someone else.'
Librem users can now take control of the secure boot process, using hardware-based encryption at the best level. 'By Activating our TPM-enabled boot by default on all laptops, this little piece of combination makes the most secure laptop you can buy when you hold the keys,' says Weaver.
New models will feature the integrated TPM as a standard feature. Also, security-related new network communication has been developed with the assistance of cryptography powerner Werner Koch. This will add hardware encryption to Purism's laptops and forthcoming Librem 5.

To this end, Purism leverages Gnu Privacy Guard (GPG) and smart card technology to include encryption by default on all its devices. Purism and cryptography advocates already know that it was Koch's GPG encryption that enables secure communication to journalists worldwide.

GPG was first developed in 1997 and over the years it has amassed a large community of users and is used in email and messaging using a new process, Key Directory, which allows the recipient to request permissions on their own system.

Werner Koch says, 'Purism's goal is to use cryptography to build it into products. Purism is making modern hardware designed to allow users to have control over their own lives.'
