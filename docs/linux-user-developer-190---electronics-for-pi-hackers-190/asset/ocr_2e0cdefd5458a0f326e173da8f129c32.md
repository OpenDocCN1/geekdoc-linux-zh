# # Interactive Python shells

While the default Python gets the job done, you can be a lot more productive with these of feature-rich alternatives

**bpython**
Described as 'the fancy interface to the Python interpreter', this cross-platform shell has some useful and improves skills up to life. Its developer says the idea behind the project provides modern IDE-like features inside a terminal window.
https://bpython-interpreter.org/

**DreamPie**
This project claims to introduce a new feature for an interactive shell by rearranging the furniture inside a terminal window. According to it, this development arranges large amounts of code just like any other code editor.
www.dreampie.org

**IPython**
It might be misleading in its naming, but Python is one of the most feature-rich interactive shells. IPython is based on an architecture that allows parallel and distributed computing; many of its features are used in academic and scientific research.
https://ipython.org

**ptpython**
tpython doubt itself as a 'better' interactive Python shell that's built on top of the prompttoolkit library. Although the project doesn't have a dedicated website, it has a string of features that make it very useful.
https://github.com/jonlanders/ptpython
