There's no doubt that the Raspberry Pi boasts a wide range of resources — software and hardware which can be used for computing, programming and creating exciting and engaging projects. There are numerous add-ons and components to expand the capabilities of the Pi. All of these allow you to connect the Pi to a computer of a wide range of sizes, styles and colours.

To use Raspberry Pi you also require a keyboard, mouse, and battery. The Raspberry Pi also requires connection sockets to add the various components. This means you must carry an additional laptop if you want to use the Pi away from your desk or it.

This tutorial covers a step-by-step solution for using your Raspberry Pi Zero via USB cable and set up in order to configure the OS on your laptop or desktop. Simply plug in your Pi, wait for it to boot up and then access it with the command line or GUI; no need for any external screen, keyboard, mouse or power supply. All your code, projects are saved directly to your SD.

This makes it ideal for accessing when you're traveling on a plane, or when you want to demonstrate a feature but not all the additional peripherals.

# 02 Install Putty

To access the Pi you also need a SSH client. If you already have one, or use PuTTY free SSH client for Windows which can be downloaded and installed from https://www.sf.sf.uk/download/. If you're using Linux, open the Terminal window and type: `sudo apt update apt install-putty`

# 03 Install the Raspberry OS

Start this project with a free image of the current Raspberry OS available at https://www.raspberrypi.org/software/raspberry/. The file is compressed and will need to be extracted to the .img file. This file is what you need to flash to a micro SD card using Raspberry Pi Imager or Etcher -

# 04 Accessing the SD card

Once the OS has been written to the SD card, you're ready to start configuring. We recommend that you use Notepad++ or a similar text editor like Notepad to edit the files, as Notepad does not handle config files with more than one line of text. Notepad++ can be downloaded from https://notepad-plus-plus.org. Once installed, open the SD card folder. You will see two text files towards the top of the folder.
