We've found another slice of Pi, incrementally better than the last – but will it end our hunger?

No new Raspberry Pi this year? Not quite. Okay, RAM is rapidly becoming the norm thanks to boards such as the Asus Tinker Board. Running a benchmark test computing prime numbers up to 10000 using all four cores of the Pi, the Pi 3B+ achieved 36,583 results contrasted with the Pi 3B. That's an improvement of 9.12 seconds, and nearly 20 percent per core than the original Pi 3.

The Raspberry 4 offering USB 3.0, SATA, and a NVIDIA GTX 1080 GPU, an octa-core CPU and 4GB of RAM, Rather, it's the Raspberry Pi 3B+ that is better than the 3 model, which helps get a little more power and better connectivity. The Pi 3B+'s system-on-a-chip now features an ARM Cortex-A53 64-bit CPU, now running at 1.4GHz. This is an increase of 200MHz over the Pi 3. It's not a massive gain but it helps to make Raspberry more responsive, RAM remains the same at 1GB—enough for most power users, but 2GB+ of version

In 2016 the Pi 3 featured onboard Wi-Fi and Bluetooth; the Pi 3B+ brings them with Wi-Fi 802.1ac. This has a much higher throughput, theoretically up to 1.36Gbps per second, but we found it to be 42Mbits/s (5.25MB/s).

802.11n's speed of 47.8Mbps (5.97MB/s). Taking a feature from the Pi Zero W, the wireless antenna is of the same design—a licensed feature from Proant. There's no connection for an external antenna. This new 5GHz Wi-Fi works well and we were able to watch a 1080p YouTube video with only slight amount of initial buffering.

Networking is also improved. The Pi 3 B+ uses a LAN7517 chip, providing Gigabit Ethernet over USB 2.0 instead. This new chip provides Ethernet at 320Mbps (40MB/s), we see three times the performance compared to the previous Pi 3 which was limited to 100Mbps (1MB/s). For general use and as a home-server, it's a performance increase that offers plenty of bandwidth for livestreaming at reasonable speeds and also improved compared to using version 4 B.

The new standard 40-pin GPIO remains the same as before. However, just the GPIO includes four extra pins for Power Ethernet, which will allow the Pi 3 B+ to be powered and communicate using cable. This will be available via a future PoE HAT, but it will have one problem: the placement of the pins means the GPIO will be blocked by any HAT-specification boards placed on top. We speculate that the new PoE HAT will have a passthrough GPIO connection, or out of time of writing there is no information on this. These PoE pins also introduce the possibility of some boards making direct contact with the pins and the short components on the underside of boards. The Pi 3 B+ has the same pins as the Pi 3 and there are two power options provided via the Micro-USB port or the official SV, 2.5A power supply is recommended.

There's no denying that the Pi 3 B could run a little hotter, but the temperatures we achieved with the Pi 3 B+ was 66.7°C thanks with the addition of a heatsink, which makes it very useful for most cases.

The Raspberry 3 B+ may not be the Raspberry 4, but it was never intended to be an incremental update with such radical refinement. The improved CPU power is nice but the biggest improvement is in networking. The provision of Ethernet makes us eager to build devices, and for those of us with 802.11ac routers, the 5GHz Wi-Fi is an excellent increase of speed and proximity.

The Raspberry 3 B+ is 3 mirrors of the original Pi 3, so this is the model for new users to purchase and worthy successor to the Pi 3.

- Pros: An improvement to the Pi 3 with a slightly faster CPU that runs cooler, but with networking where it really shines, with Gigabit Ethernet and 5GHz 802.11ac.
- Cons: The PoE pin placement could potentially be a vexing issue depending on how HATs are designed.
- Summary: A slight increase in CPU power boots lots of improvement mean the Pi 3 is at home.
