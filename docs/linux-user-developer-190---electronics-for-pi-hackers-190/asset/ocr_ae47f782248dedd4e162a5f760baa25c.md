# Canonical installs data-collection tool in Ubuntu

Upgraders can opt out of Ubuntu data collection, company says

Paranoia has struck the Ubuntu community over the past few weeks following news that a data-collection tool has been placed in Ubuntu 18.04 LTS by Canonical. While this only collects hardware information, rather than the data collected by Microsoft in Windows 10, it has met with controversy.

In an announcement today, Canonical said data collected would be sent over HTTPS to a service run by Canonical's team. This would be saved to disk on first boot once there is a network connection. The file containing this data would be available for the user to

inspect. The results of this data would be made public. Canonical explained that users would be able to compare the percentage of opting in in Germany compared to Zambia, for example, and on what hardware: The Ubuntu privacy policy will not be affected by this change.

The collected data includes hardware (CPU, GPU, RAM, disk size, GPU device, device ID), features disabled by the user when installation (rather than an IP address, which is not collected), installation tools and features updated during monthly updates.

Most discussion around a concerned peace of mind follows the announcement that Canonical has a sorry history in this regard, such as the Ubuntu/Android integration and Linux Android mode in phone. Of course, the company's pockets offer a greater privacy issue, and you can't easily opt out of that:

One of the aspects of this announcement that has largely gone untouched is that anyone can opt out, while upgraders from 16.04 LTS can opt if they choose. As Will Cook explained:

"Any user can opt out by unchecking the box. There will be a checkbox in the Privacy panel of GNOME Settings to toggle this value. 'Given this usage patterns are for Linux, it makes sense that Canonical would want to quantify Ubuntu in this way, but in perhaps it could have approached things more openly."
