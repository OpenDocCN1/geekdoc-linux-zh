# Going back to Mark I, what was the lesson that you learned from your experience?

Don't put the microphone in the same case with the resonating chamber! The Mark I really got big-in. No matter how good the software feels, the bigger the speaker, the more the it makes it basically impossible - if the music is playing loudly - for it to hear the command.

So the lesson for all of those is the Mark II. It should go further. The design is simpler. The better device is the more capable.
