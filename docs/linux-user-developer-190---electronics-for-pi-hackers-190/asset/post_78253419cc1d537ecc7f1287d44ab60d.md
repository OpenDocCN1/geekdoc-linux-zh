Evidence seems to suggest it's on the way

Chrome OS is based on Linux (Gentoo, specifically), you might expect straightforward installation of Linux apps to be easy. Unfortunately, that's not currently possible, necessitating the use of some wacky workarounds.

![](img/0e3dcad8b24bb8f7fe3ae3a4d499db3b_8_0.png)

Anyone wanting to run Linux on a Chromebook has two choices: ChromeOS or Crouton script. The first option requires a new partition (which can be time-consuming to switch), while the second introduces a considerable security risk. The answer?

Various indicators suggest that Chrome OS will support Linux virtual machines, but relying on running for Linux through a third-party project like Crouton means there's the problem of having to develop Android apps with potential hacks. It's a risk no computer owner should take, but it's the only option if you want to have Linux apps on a Chromebook.

a number of factors suggest that the release of Chromium is likely to provide VM support for Linux. Also a Chrome device may support Chrome OS, which adds a new menu and a switch for administrators to enable or disable features. One line of inclusion in Chrome OS is due for May.

Meanwhile, a dialog box reads "Welcome Chromebook. You can run your favorite Linux apps and command-line tools seamlessly and securely." So, installing LibreOffice, Linux-compatible software or even software supported by Wine? It could...

After a successful crowdfunding for our open source smart speaker Mycroft returns with a more refined Mark II for consumers and devs.

Mycroft is seen as the open source answer to voice-activated personal assistants like the Amazon Echo, Siri, Cortana and Google Assistant, when Joshua Montgomery, CEO of Mycroft, was looking for a voice assistant for the likes of an Amazon Echo. 'Certainly, it was in beta,' says Joshua, sitting beneath a large bold Mycroft. 'We wanted to find Jarvis from Iron Man into our space.'

they recently finished a successful crowdfunding for the Mark II – doubling the number of backers – and have moved pre-orders to Indogo.

What's the ambition for Mycroft? We're building an artificial intelligence that runs locally and interacts naturally. Our goal is to build a voice assistant whose user experience is so natural people forget if they are talking to a human or a machine.

To achieve that, what is the software that you are working on?

We're using TensorFlow as the platform to build the artificial intelligence or machine learning – certainly for the speech recognition, and language processing. We're using TensorFlow for the word-recognition engine. We're working with the team at Mozilla on speech-to-text – that's the DeepSpeech engine (https://github.com/mozilla/DeepSpeech).

The Mark II is designed for consumers. We have a bunch of I/O on the back – it's got an jack, it's got HDMI, it has USB ports. It's got an Ethernet port if you want to plug into it.
