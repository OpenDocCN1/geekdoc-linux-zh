# DISTRO SPOTLIGHT

# Other forward-thinking distros

+   * Anteros
Anteros is another OS based on Linux, adding a graphical desktop to the distro. It focuses on simplicity, offering a fully configured OS with sensible defaults to get right away. It's the Numix theme for a fresh, modern appearance.

+   * Linux Mint
Linux Mint's goal is to provide a modern, elegant distribution blending ease of use with powerful features. Based on Ubuntu, it is designed to be ready to go. Community-driven development means a thriving user base and growing popularity.

+   * Nitros OS
Nitros is a relatively new distribution that focuses on design. It's based on Ubuntu features features and is built on KDE Plasma 5 and Qt. Other major features include a built-in firewall, Snap-based software and software-rolling release model.
