Above Ada is a surprising language. Developed by the US Department of Defense in the late 1970s, it was used primarily for military applications. As one of the first languages requiring a great degree of security and safety, with no room for error, there are strong safety features like typing systems and good support for including the extremely strict environment. The surprising thing is that Ada was also built for speed. In fact, Ada seems to have more in common with languages like C and C++ – than it has with modern safe languages like Rust, which often run quickly. It is this combination of safety, such as static typing, performance features, and direct access to the internal memory of storage, that makes Ada an ideal choice for large software projects.

We'll give you a tour of the basic syntax of Ada programs, features in this tutorial. If you'd like to go a bit further, we've provide a small Ada program on the codever that builds the code written in this article. # Hello, world!

Since Ada's syntax is a bit different from other languages, we will start with a "Hello, world!" program. First, we will use the Ada IDE, either by running the command or through your desktop manager. We will prompt you to create a project, so we will choose a name and a location to save it. What you see is shown in Figure 1, with a single .ada file. This file is filled with code similar to the following:

```ada
procedure Tutorial is
end Tutorial;

Put_Line("Hello, world!");
```

This is the outline of an Ada 'procedure', which is like a void function in a programming language like C++. We add a line in the middle to print out our message.

An Ada project typically starts off a main procedure which runs we start the program. We'll illustrate some of the techniques by writing a simple generic for track of positions of objects in space. Since we want to keep geometry in either two or three dimensions (or some other number), we will use a generic parameter for the number of dimensions.

Right-click in the Project Explorer and New > Ada Package, as shown in Figure 4. The type is "Geometry" and package geometry. This will create an Ada package containing some outline code. Add more lines of code so it looks like the following:

```ada
generic
  Dimension: Positive;
package Geometry is
```

This is our declaration. The first two lines (the generic section) give the generic parameters for the package, in which means we can refer to the number of dimensions. If the user wants to use the package, they will need to specify a number of dimensions (typically 2 or 3).

This example (below) shows how we declare variables. Here, Variable_Name is an identifier, and Variable_Type is its type. The following code:

```ada
Variable_Name : Variable_Type;
```

The point of defining this is that it allows us to define an array type representing points in space, which we can do with the next:

```ada
type Point is new array (Indices) of Float;
```

This is the type of indices to handle all the integers in the range 1 to 10.

```ada
type Indices is new Positive range 1 .. 10;
```
