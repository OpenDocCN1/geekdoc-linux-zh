# Parallel processing

One of the most powerful features of Make is capacity
for parallel processing. By default, Make executes its
rules sequentially, but unless we use, we can
do this automatically, using the operating system
task scheduler, to ensure which work works
make concurrently, and which needs to be
executed in.

To enable we run make with the -j
if we specify a number of jobs - make
-j will limit the number of jobs that can be
executed at the same time. If we run -j without
specifying a number, the number of threads
run concurrently in unlimited mode.

A command-line switch to use advantage -j
1, which makes Make to limit the number of threads
ith runs concurrently if the system is under
high load. The level of load that is
measured by experiencing us the load average
when we run our uptime make command.
