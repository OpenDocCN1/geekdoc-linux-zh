This new 5GHz Wi-Fi works well and we were able to watch a 1080p YouTube video with only slight amount of initial buffering.

Networking is also improved. The Pi 3 B+ uses a LAN7517 chip, providing Gigabit Ethernet over USB 2.0 instead. This new chip provides Ethernet at 320Mbps (40MB/s), we see three times the performance compared to the previous Pi 3 which was limited to 100Mbps (MB/s). For general use and as a home-server, it's a performance increase that offers plenty of bandwidth for livestreaming at reasonable speeds and also improved compared to using version 4 B.

The new standard 40-pin GPIO remains the same as before. However, just the GPIO includes four extra pins for Power Ethernet, which will allow the Pi 3 B+ to be powered and communicate using cable. This will be available via a future PoE HAT, but it will have one problem: the placement of the pins means the GPIO will be blocked by any HAT-specification boards placed on top. We speculate that the new PoE HAT will have a passthrough GPIO connection, or out of time

of writing there is no information on this. These PoE pins also introduce the possibility of some boards making direct contact with the pins and the short components on the underside of boards. The Pi 3 B+ has the same pins as the Pi 3 and there are two power options provided via the Micro-USB port or the official SV, 2.5A power supply is recommended.

There's no denying that the Pi 3 B could run a little hotter, but the temperatures we achieved with the Pi 3 B+ was 66.7°C thanks with the addition of a heatsink, which makes it very useful for most cases.

The Raspberry 3 B+ may not be the Raspberry 4, but it was never intended to be an incremental update with such radical refinement. The improved CPU power is nice but the biggest improvement is in networking. The provision of Ethernet makes us eager to build devices, and for those of us with 802.11ac routers, the 5GHz Wi-Fi is an excellent increase of speed and proximity.

The Raspberry 3 B+ is 3 mirrors of the original Pi 3, so this is the model for new users to purchase and worthy successor to the Pi 3. It's a step along the path to what we hope to see in the Raspberry 4.
