# 关键电力

对于许多加沙的人来说，加沙经历了能源危机，Tarek Loubani 和其他人发起了一项名为 EmpowerGAZA.org 的活动，集资为加沙的两家主要医院购买并安装太阳能电池板，以便进行关键护理，因为目前的短缺是无法接受的：“如果我们采取了你们的，就在两天前，它们每天只有几个小时，实际上是每天六小时，然后是六小时，直到两周前。当你们每天没有四小时电时，你们就开始开始休息了。”

![](img/0e3dcad8b24bb8f7fe3ae3a4d499db3b_34_2.png)

太阳能电池板提供了可持续、可靠且可新的能源。该项目已经在三家医院安装了电池板：“至少，有了太阳能电池板，内部单元得到了覆盖，或者症状得到了覆盖，其中一家医院的析透也得到了覆盖。”

Tarek 说我们在加沙需要20MW（千瓦）。为了让你有个直观的概念，Tarek 说他在加拿大的医院大约使用 60MW（兆瓦），而整个加沙的需求少于60MW。

八年后，加沙表示如果没有范式转移，他们就什么也得。“机器都是24小时运行的，没有机器是每天运行2小时的，这就是我真正想做的。”

对于析透是非常可行的。“一个女人，她当时还是个女孩，作为她的学校项目做了析透，几年后并将其成本降到了5,000美元，”Tarek 告诉我，“所以我们现在没有，现在没有机器可以这样做。它不安全、可靠且不受监管。从这个意义上说，我正试图不打破系统——我正试图留出足够的空间。“目前最便宜的析透是20,000美元，但从实践上讲，”Tarek 说，“你面对的是30,000美元到50,000美元。”
