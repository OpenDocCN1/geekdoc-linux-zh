## Purism up the ante for laptop security

Tamper-proof laptops and encryption partnership to secure laptops and upcoming Librem 5

Purism's continued focus on producing the most secure, private laptops resulted in a new partnership with eclectic security firm Treadmill Hudson. His Heads security firmware has been integrated into Trusted Platform Module chips, delivering enhanced protection for users of Purism's Linux hardware.

The result of this development, however, will require some hardware changes, reboot modifications, and of course operating system updates. As Purism CEO Cosmo Wohl says, 'Your privacy depends on freedom. By having true privacy means your computer and data should be under your control, and not someone else.'

Librem users can now take control of the secure boot process, using hardware-based encryption at the best level. 'By Act our TPM-enabled boot by default on all laptops, this little piece of combination makes the most secure laptop you can buy when you hold the keys,' says Weaver.

New models will feature the integrated TPM as a standard feature. Also, security-related new network communication has been developed with the assistance of cryptography powerner Werner Koch. This will add hardware encryption to Purism's laptops and forthcoming Librem 5.

## Canonical installs data-collection tool in Ubuntu

Upgraders can opt out of Ubuntu data collection, company says

Paranoia has struck the Ubuntu community over the past few weeks following news that a data-collection tool has been placed in Ubuntu 18.04 LTS by Canonical. While this only collects hardware information, rather than the data collected by Microsoft in Windows 10, it has met with controversy.

In an announcement today, Canonical said data collected would be sent over HTTPS to a service run by Canonical's team. This would be saved to disk on first boot once there is a network connection. The file containing this data would be available for the user to inspect. The results of this data would be made public. Canonical explained that users would be able to compare the percentage of opting in in Germany compared to Zambia, for example, and on what hardware: The Ubuntu privacy policy will not be affected by this change.

The collected data includes hardware (CPU, GPU, RAM, disk size, GPU device, device ID), features disabled by the user when installation (rather than an IP address, which is not collected), installation tools and features updated during monthly updates.
