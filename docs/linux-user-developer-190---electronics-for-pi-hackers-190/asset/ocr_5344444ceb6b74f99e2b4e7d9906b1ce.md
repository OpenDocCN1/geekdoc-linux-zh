# LimeSurvey 3.4.1

Create and hosts host opinion, then analyse your results

If you ever need to canvas opinion, you can use the LimeSurvey web app to create and set up a survey in a matter of minutes: it supports all languages and long text, offers clear features such as inviting responders to the survey multiple times. It also supports quotes, which you can restrict the survey limit by number of respondents on their gender.

For lengthy surveys, you can enable respondents to save point and continue later. You can also create tokens, to keep track of users who have joined and send them reminders.

LimeSurvey offers a number of templates to customize them. The app offers extensive filtering options to help you get clear views of answers, and you can even use the number of parameters for deeper statistical analysis.

Install LimeSurvey like any other app and follow the documentation: the process to create a survey is intuitive and the installation includes an interactive tutorial to help beggars started. Apart from this, the project has extensive documentation.

# DOCSETS BROWSER

# Zeal 0.6.0

Browse through docsets of popular programming

+   Every popular source language allows its source code in what are known as docsets.

An essential resource for any developer who wants to contribute to the project. As you can imagine, docsets make searching through different source code such as WordPress - fairly easy, so like Zeal make the docsets readable.

In a sense, you can find Zeal for developers. The matching app is available in the official repositories of maintainstream distributions and Ubuntu users can fetch the latest version via PPA.

Zeal's main USP is that you can download a wide array of docsets from within the app

Head to Tool > Doctets to bring in the Doctets to home. To download docsets, browse to the available tab and search the docsets you wish to fetch. The fetch allows you to Crt select multiple languages.

Once the docsets are downloaded, they are easy to navigate expand the attribute to browse the documentation, or use the search bar to find what you need - Zeal populates the search matching results and view the documentation in the right-hand panel.

The app supports and also offers options to make the docsets more readable by adjusting their font size and the colour scheme of the text for various properties.

+   Pros Can download docsets over 200 projects including C++, Python and Java, and offers to browse with easily.

+   Cons In certain cases the results you search might be useful if they were sorted alphabetically.

+   Great for... Browsing through the source code of projects, particularly large ones. https://zeal.org
