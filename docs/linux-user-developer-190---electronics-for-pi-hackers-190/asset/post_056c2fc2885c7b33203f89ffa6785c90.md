## Adding sound

FFmpeg makes simply adding audio to another video, which is straightforward. Use the command like this:

```bash
ffmpeg -hwaccel auto -thread_queue_size 512
-f alv -acodec aac -i input.mp4 -f video 0 -s 1280x720
-f dev/null -vcodec libx264,preset veryfast -pix_fmt yuv420p -brate 4000k-bufsize 8000k -pix_fmt acodec aac -b:a 128k -ar 44100 -bufsize 5000k
-preset veryfast -f flv -rtmp "https://live.twitch.tv/app/86945472" YOUR_STREAM_KEY
```

You should be aware of a few things. If you are adding audio to an input, you might need to re-encode the audio that Twitch supports. One of the issues was that the stream was deynchronized, so the audio was also de-synchronized during live. If you find the constant rate is too high, try to remove the "-f vrate" (option) if it's necessary in the video-command, but not here.

You might notice that the thread_queue_size banner is set right before -i. If you expect FFmpeg to lag or stutter, use it like-banner, but this only applies to the audio input video.
