# What is Ansible?

Ansible, founded by Michael DeHaan and later acquired by Red Hat, is software that automates configuration management, application deployment and provisioning for system administrators. It is extended to cloud deployment and more. Ansible works by configuring remote computers via SSH, so there is no need to install anything.

```
$ apt-get
$ apt-add-repository ppa: ansible/ansible
$ apt-get
$ apt-get install ansible
```

The kind of system administrators and developers who can automate with Ansible:

+   - **Configuration management**: Want to install or update packages, or start services using SSH, Apache2, or Nginx running on your server? Ansible makes it easy.
- **Application deployment**: If you've built a PHP web application for your users to make it possible to install your application, you'll need to deploy or 'move' applications from the server to a production environment.
- **Software provisioning**: Ansible is useful for setting up network infrastructure by FTP servers, DNS servers and routers to be accessed by the right users.
