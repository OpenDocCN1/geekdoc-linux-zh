# Installation

IPython is available in the official repositories of many distributions such as Fedora and Debian. However the project's website recommends using the PIP package management system to install it using `pip install`

Installation is again fairly straightforward, but unlike others you might find it in your distribution's official repositories, IPython can only be installed via the PIP package management system. First upgrade pip with `pip install --upgrade pip` and then install with `pip install ipython`

# Features

The shell provides sensitive tab-completion of keywords, variables, available modules and functions. Its command history works across sessions, and there is a special command for functionality when working interactively; IPython also offers GT, XXW, and CLI.

IPython has all the interactive features including autocomplete, syntax highlighting and validation function! It also supports both mice and keybindings. You can easily edit code in any python app and can define custom key bindings and color schemes.

# Usability

Basic interface is straightforward but its extensive range isn't readily apparent. You'll have to spend time to discover them, and then more time familiarising yourself with their usage or choosing them. For instance, IPython has a system to make it easy to execute multiple lines but you need to set it up before you use it.

IPython doesn't show any to first-time users: the display shows a list of keybindings at the bottom of the screen; easy to import modules from history is very useful. However, some of autocomplete suggestions aren't really useful. For example, when you type it always suggests logic operators such as and and not, which aren't always required.

# Help and support

The project provides a user guide on the web. The shell you can get an object with ? to get some useful information about it or ?? for more details. The project also has an active community of users on Reddit and Stack Overflow. It's the only shell that has several dedicated books about it, besides of videos on YouTube.

It is rich in terms of help and documentation, The GitHub page has a bunch of screenshots that detail its features, but there are so many pages and the only shell has a feature section that you can navigate within the shell. Moreover there are no official forums, though you can report issues to GitHub.

# Overall

In addition to being a very capable shell, IPython can do a lot more. It supports GUI and data visualization tools also for parallel computing.

IPython is a little rough compared to the other editors. The lack of help and support infrastructure limits it to experienced coders who can find their way around shell based on experience.
