Circuit diagrams show how components connect to create
an electronic circuit, which can be built on a breadboard

A circuit is a collection of electronic components
connected in a particular configuration. This
representation of components using a
circle is shown as a schematic.
A circuit diagram includes symbols for each component,
connected using lines to represent connections.
See below for examples.
In addition to these, components in circuit
diagram are shown with their values. Often, only the
number and multiplier, and the unit is omitted.
So, for example, a 10k resistor might be shown
nas 10k and a 22k resistor as 220. Also, the
4.7k is shown as 4R7. A convention with low-value
resistors, where the R is used instead of
of the non-metallic symbol - so for example 470
might appear as 47R.
Commonly, components on circuit diagrams are
labelled with a component identification number. This
allows a list for the circuit to be produced with
means of tying the parts list with the circuit diagram.
IDs take the form of a list which identifies the

type of component, followed by a serial number.
Resistors, capacitors and diodes are nearly always
represented by R, C and D respectively, so the first
 would start with C. Confusingly, for transistors could be T, Tr or Q,
relays may be R or RL.
