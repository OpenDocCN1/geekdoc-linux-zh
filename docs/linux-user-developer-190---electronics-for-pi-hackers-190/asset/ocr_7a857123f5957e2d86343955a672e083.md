The main difference between a stripboard and a PCB is that the former is a generic board which can be adapted to any circuit, while a PCB is made specifically to implement a certain circuit. For this reason, it has holes for the components to pass through, but only where a particular component is to be fitted. Similarly, PCBs have copper tracks on the board - not just in parallel strips, but running as necessary to ensure that wires are connected. 4 Cut off excess leads
Component leads are too long and could lead to short-circuits. Using a pair of small cutters, cut off the excess length of each the leads above the solder joint.

5 Make breaks in tracks
Where breaks in a copper track are required, make them using a spot cutter; in particular, you can use a drill bit of appropriate diameter. Rotate the cutter back and forth a few turns until the copper is cut away.

6 Inspect the board
Before connecting the board to a computer and/or power supply, check carefully to make sure it matches your design. Use magnifying glass to check that all breaks in the copper strips are entirely free of copper.
