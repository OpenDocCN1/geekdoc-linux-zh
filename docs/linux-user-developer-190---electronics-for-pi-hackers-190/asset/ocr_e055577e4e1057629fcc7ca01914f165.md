# BROWSER EXTENSION

# uBlock Origin 1.15.11bo

Get rid of intrusive privacy compromising adverts

Fed up of seeing online ads? The cross-platform, open source uBlock Origin is an ad-blocker that doesn't just block ads by tracking servers, malware, and domains, but is also available in many browsers and protects your privacy. It comes with well-maintained filter lists, unlike some other content filters do not. In fact, it might actually save the memory by not displaying adverts generally larger than the memory required to use the extension. uBlock Origin manages to work with

magic without any noticeable delay in page loading. A minimal user interface helps you keep track of blocked requests and also offers quick access to common functions. Using uBlock Origin, in fact, it works great out of the box. You can enable or disable the interface with a single click, and also offers to block pop-ups on all large sites. If you never want more than the default block lists, you can display the extension's settings and configure features of the browser, such as WebRTC. You can also enable the Advanced mode for fine-grained control over how and when the content is blocked.

+   * Pros Feature-rich app that works beautifully out of the box and yet gives fine-grained control to advanced users.

+   * Cons Unless selected, it also blocks ads on sites that depend on for revenue, but that's the price of any ad-blocker.

+   * Pros Protecting you from online adverts. https://github.com/gorill/ublock

# PHOTO/VIDEO IMPORTER

# Rapid Photo Downloader 0.9.8

Import and catalogue images and video from phones and cameras

![](bbox=[0.415, 0.585, 0.945, 0.815])

Rapid Photo Downloader might seem redundant that most photo management apps can import photos. This app, however, is designed specifically for transferring photos and videos, and offers a lot more functionality than a perfect tool could be. It gives you complete control over how it processes and sorts the downloads.

The defaults automatically download photos to date-subfolders. You can define custom rules. You can sort photos by their type, which comes in if you shoot both RAW and JPEGs. In fact you can create a complex subfolder hierarchy by date, size, focal length, and so on. If you use an external storage device as the destination, the app can automatically import photos from the camera.

Instead of putting binaries, the Rapid Photo Downloader project has an installation script written in Python. To install the app, simply download the script and execute it. It will fetch all the dependencies before it installs the app.

Rapid Photo Downloader can generate thumbnails for RAW and TIFF files so you can identify them using file markers

+   * Pros Full of features and useful options to help you sort and catalogue your images and videos.

+   * Cons Might be overkill for anyone who dumps images from the camera into a folder.

+   * Great for... Automatically organising and cataluing a set of images and videos. http://damylonych.net
