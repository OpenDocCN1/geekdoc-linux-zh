Being open source software, you don't have to buy a smart selector to try Mycroft, but by buying a Mark or Orion you'll be supporting the project. To do this is install it as a Plasmoid - a desktop widget for the KDE Desktop. Community member Aditya's Mehra, with the help of KDE developers, have created an alpha release for KDE Plasma on Ubuntu and Fedora. This is a script supplied for both, but we have KDE Neon on the nonversicid this (and on Flatpak) so you can either install it or run it as a virtual machine. You'll need to head to the Terminal (calledsole in KDE) and type:

```
- wget https://mycroft.ai/install_plasmoid_kde.sh
- bash install_plasmoid_kde.sh
```
