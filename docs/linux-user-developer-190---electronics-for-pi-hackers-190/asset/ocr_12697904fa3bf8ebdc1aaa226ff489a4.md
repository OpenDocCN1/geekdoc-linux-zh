Above Ada is a surprising language. Developed by the US Department of Defense in the late 1970s, it was used primarily for military applications. As one of the first languages requiring a great degree of security and safety, with no room for error, there are strong safety features like typing systems and good support for including the extremely strict environment. The surprising thing is that Ada was also built for speed. In fact, Ada seems to have more in common with languages like C and C++ – than it has with modern safe languages like Rust, which often run quickly. It is this combination of safety, such as static typing, performance features, and direct access to the internal memory of storage, that makes Ada an ideal choice for large software projects.
We'll give you a tour of the basic syntax of Ada programs, features in this tutorial. If you'd like to go a bit further, we've provide a small Ada program on the codeveric that builds the code written in this article. We recommend that you work through this tutorial writing the code, and then have a look at the codeveric if you're interested to learn more.

# Hello, world!

Since Ada's syntax is a bit different from other languages, we will start with a "Hello, world!" program. First, we will use the Ada IDE, either by running the command or through your desktop manager. We will prompt you to create a project, so we will choose a name and a location to save it. What you see is shown in Figure 1, with a single .ada file. This file is filled with code similar to the following:

```
procedure Tutorial is
end Tutorial;

Put_Line("Hello, world!");
```

This is the outline of an Ada 'procedure', which is like a void function in a programming language like C++. We add a line in the middle to print out our message.
