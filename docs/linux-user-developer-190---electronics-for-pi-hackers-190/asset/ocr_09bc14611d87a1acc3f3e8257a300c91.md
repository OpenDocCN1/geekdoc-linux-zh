# Installation

The app has a long list of dependencies, but it's easy to install as it is available in the repositories of many distributions including Fedora, Debian and Ubuntu. You can also fetch the latest version using `pip install` or the Python Package Index with `pip bpython`

# Installation

The shell recommends installing DreamPie by cloning its repo and moving the executable to `/usr/bin`. The app is also available in the official repositories of several distributions, and you can fetch it with `pip install dreampie` if you have a Python installation

# Marker features

In terms of code, it gives you a list that you can scroll using Tab to display a list of expected parameters. The shell allows you to highlight syntax as you type, and includes a feature calledit re-evaluates the entire code, which in memory. You can also save a session to a file, or send it to Pastebin

# Marker features

Along with code for features and attributes, it also displays the function documentation, which will be of great use to beginners. Another great feature is ability to fold long output sections to minimize distractions. DreamPie can save properly formatted code with all entries in session format

# Usability

The shell is intuitive and straightforward to use. You can use it with the default settings and customize it to your liking by editing its config file, which contains everything from key bindings to the Pastel URL. Bpython coders will assist you in mastering, especially when there are many parts nested in your code.

# Usability

Unlike the other shells, DreamPie's interface is built into the history box, where you can view previous commands, output, and the code, where you write your code. The program won't transfer control from the command if the command has a syntax error, which is useful. You can also select a block of code and execute by pressing `Ctrl+Enter`.

# Help and support

bpython has a comprehensive help section in the way of use. However, you can also press F from the shell to display a list of shortcut commands. The shell's search will find relevant results as well as a video that shows off the app's features. If you have questions post them on the Google Groups page or ask in the dedicated IRC channel.

# Help and support

DreamPie offers help in the way of use. However, on first launch launches a window with some tips to help you started, and its menus are arranged logically with well-named options. DreamPie's screenshots depict that the main features in action and there's all that isn't very active.

# Overall

bpython has a very useful selection of features and implements them nicely. It doesn't aim to replace an IDE but offers enough conveniences to replace the default Python interpreter.

# Overall

DreamPie is a thoughtfully designed Python shell that's different from the norm but manages to be intuitive. Its window layout, with the division of code entry and evaluation, is noteworthy.
