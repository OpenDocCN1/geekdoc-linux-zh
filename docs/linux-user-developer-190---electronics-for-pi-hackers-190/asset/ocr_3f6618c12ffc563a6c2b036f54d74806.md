Right-click in the Project Explorer and New > Ada Package, as shown in Figure 4. The type is "Geometry" and package geometry. This will create an Ada package containing some outline code. Add more lines of code so it looks like the following:

generic
Dimension: Positive;
package Geometry is

This is our declaration. The first two lines (the generic section) give the generic parameters for the package, in which means we can refer to the number of dimensions. If the user wants to use the package, they will need to specify a number of dimensions (typically 2 or 3).
This example (below) shows how we declare variables in Ada. The usual format is:

```
Variable_Name : Variable_Type
[Default Value]
```

Here, Variable_Name is an identifier referring to the variable, and Variable_Type is its type - in this case, which is the type of positive integers.
