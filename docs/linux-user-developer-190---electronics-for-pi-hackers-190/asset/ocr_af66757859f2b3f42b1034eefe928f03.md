# Edit the cmdline.txt file

Locate and open the cmdline.txt file. This file contains a single line that includes several parameters, each separated by a single space. There are no newlines in the file you must present when editing this code. Locate the word root= and enter the code modules-load=dw2,g_ether. Add a single space after the entry and close the file.

# Access the GUI via USB

It is possible to access the desktop of your Pi using VNC. First load your Pi menu > Preferences > Raspberry Pi Configuration. Click Interfaces and enable VNC. Now connect your laptop or computer, download and install the relevant Viewer from RealVNC: www.vnc.com/en/connect/

Plug the Pi into the laptop and wait for it to boot. Then using the VNC app enter the name raspberry.local and press Return. You may be presented with a warning about encryption. Set the Encryption to 'Let VNC Server connect' and click Connect. Enter the user name and password for raspberry (default: pi/raspberry). In the setup, you can adjust the window size and resolution in the VNC configuration settings for a more accurate view.

# Wire up Pi

Once you've completed these changes you can boot your Raspberry via the USB port. Eject the microSD card and put it into your Pi Zero. Take the Micro-USB to USB cable and attach to the Micro-USB port on the Pi. Depending on your laptop, OS, you may need to turn off all networking; the easiest way is to plug the Pi into Flight mode. Now plug the other end of the USB cable to one of the ports on your laptop. After about 90 seconds, the Raspberry will be ready.

# 06 Edit the config.txt file

The first major change requires you to setup that you're using the USB driver instead since the Pi will be plugged in. Place the SD card into your computer and open it in File Explorer or editor. Program the config.txt and open it. Scroll to the bottom of the file and add the next line down the following line of code: dtolay-dw2. Save and close the file.

```
# No display
# comment for compatible Pi
# assignment to create the host. 700 is the default.
# none or all of these to enable the optional hardware parameters
# param=modules-load=dw2,g_ether
# Add this module to enable the local vvcms-module
# Additional overlays and parameters are documented at /overlays/TEAMS
# dtolay=dw2
```

on your laptop and locate the 'Host' name at the top of the window. Enter the hostname raspberry.local, with the port number as 22. Select 'SSH' as the connection type. Press the Open button at the bottom. You will be prompted to enter the username and password of Raspberry Pi, unless you have changed it, it will be pi and raspberry. Press Return, and you will be presented with the command line of Raspberry Pi. Obviously you will need to make these changes, and from now on you can use your laptop to access the Pi.
