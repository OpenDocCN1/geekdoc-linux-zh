# Speed up Python using a different interpreter

The standard CPython interpreter is not your only choice for running your code – nor is it the fastest

One issue that many people complain about when writing code is poor performance. Often, this is due to using techniques learned from other languages that simply do not work well when writing Python code. But sometimes, even after writing your program in a Pythonic way as possible, it still doesn't run fast enough. In these cases, you might consider a different interpreter. The standard interpreter, CPython, its focus is to run your code efficiently. Other interpreters instead focus on getting the most performance out of a given program. This issue, we'll look at a few possibilities available to you.
The first is PyPy, an interpreter that generates an optimized version of the binary code. The second option is Numba, also a JIT compiler, which uses the LLVM compiler to generate optimised binary.

Linux distributions include a package for PyPy within their repositories, so this might be a good place to start. For example, on Debian-based distributions you would install it with the following command:

```
sudo apt-get install pypy
```
