# NAS to meet you

Dear Lu8D, I thought you might be interested to know about a Linux distribution that I called VortexBox. This is a full media server and I think it might benefit all your readers.
Phil Peterson

Chris: Thanks, Phil. We not heard of this distro so we took a look. For others similar in the dark, VortexBox turns your Linux box into a jokebox server/player. It's based on Fedora and once installed it's capable of automatically ripping CDs to FLAC and MP3 files. It also supports torrent downloads of any copy that it's found.
We've tried ourselves yet, but VortexBox supports network media players such as Linn, Logitech Squeezobox and Sonos. The project also shows that you can play files directly to a USB-attached DAC. In all that it sounds like a brilliant idea, but it is also that
