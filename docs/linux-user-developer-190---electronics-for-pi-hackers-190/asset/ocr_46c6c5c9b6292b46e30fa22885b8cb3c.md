# Use PyPy

The simplest way to use PyPy is as a drop-replacement for your standard PyPython interpreter. In these cases, you can run your program with the command

```
pypy my_program.py
```

In many cases, you will need or want to get better performance out of your program, or you will want to be able to debug it further. To start with PyPy, you can install the module PyJIT compiler for debugging with your code. You can call the `enable_debug` function to start the recording of execution within the interpreter. Then you can call the `get_snapshot` function to get a JITSnapshot object, which contains details about the state of the PyPy interpreter at any point in time.

To dig in even further, import the module `__py__` to see more details about the JIT compiler. For example, you can set the performance level so that PyPy can inspect every bit of code.

+   - __py__
- __py__.attachdb(obj)

There are other functions available to handle individual elements of the interpreter. You can get the internal representation of an object with `internal_repr()` or create new objects. For example, you can create a new buffer with the function `bufferlength()` that you can use in other parts of your code.
In terms of speed, PyPy has also simplified the interface to C. You can write Python code that accesses C libraries in a relatively easy way. However, also is one of the biggest problems with PyPy: how to call external C code back to within PyPy. Currently, all of external C call have been greatly addressed. This means that you can use PyPy to speed up your numbercrunching algorithms with minimal changes.
