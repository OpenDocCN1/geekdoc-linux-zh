# Safe and secure

# Safety and security environments are hot topics in today's always-connected environments, and Linux distros are reflecting this mindset

When you're working on your computer, you expect your data to be safe. If you're not someone who is specifically at risk, you expect security for granted, but this hasn't been a major focus - Linux has enjoyed some of a 'security through obscurity' resistance to attacks together with the nature of open source, so most mainstream distros haven't truly fortified their security features. This is slowly changing, however, with the rise of distros like PureOS.

PureOS is a Debian-based distro using the Gnome desktop environment which comes with leading privacy-protect applications. Out of which you'll find

At the other end of the spectrum we have Qubes OS (https://www.qubes-os.org/), the 'reasonably secure operating system', which focuses on software rewired units. Each compartment remains secure against cross-compartmental attacks using the Xen hypervisor - by many major providers to isolate websites and each other. Each known as a cube, remains completely secure against contamination from another Qube.

PureOS takes a very light touch on privacy, making it closer to a standard than Subgraph for example, but also doesn't implement the level of security. PureOS is available as a pre-installed option on several distros from Purism, but is also releasing a PureOS-based phone.
