
## find

To search for files on the command line, you can use the `find` command. The following is the syntax for the find command:

```
find path criterion action
```

The command has a large number of options, a few of which are explained here. You can use the following arguments with the command:

- *path*—The section of the file system to search (the specified directory and all its subdirectories). If nothing is specified, the file system below the current directory is searched.
- *criterion*—The properties the file should have are shown in Table 7-19.

| Option | Description |
|---|---|
| `--ctime [+/-]days` | Searches for files whose last change took place no later than (no earlier than) a specified number of days ago. |
| `--gid number` | Searches for files with the GID (Group ID) number. |
| `--group name` | Searches for files that are owned by the group name. Instead of a name, the numeric GID is allowed. |
| `--name pattern` | Searches for files whose names contain the given pattern. If the pattern contains metacharacters (for instance `$` or wildcards, they must be enclosed in quotation marks. Otherwise, it will be interpreted by the shell and not by the find command. |
| `--size [+/-]size` | Matches files that are above or below a certain size. As an argument, the size (in blocks of 512 bytes) is given. The suffix `c` switches to byte and `k` to blocks of 1024 bytes. A preceding `+` stands for all larger files and a `-` for all smaller files. |
| `--type file_type` | Searches for a file type. A file type can be one of the following: `d` for a directory, `f` for a file, or `l` for a symbolic link. |
| `--uid number` | Searches for files with the UID (User ID) number. |
| `--user name` | Searches for files that are owned by user name. Instead of a name, the numeric UID is allowed. |

Table 7-19

- *action*—Options that influence the following conditions or control the search as a whole, such as the following:
  - `print` (default)
  - `exec command`

With the option `-exec`, you can call up another command. This option is frequently used to link `find` and `grep`, as in the following:

```text
geeko@da10:~ > find ~ -name 'letter*' -type f -exec grep appointment {} \;
appointment for next meeting: 23.08.
/home/geeko/letters/letter_Smith
geeko@da10:~ >
```

In this example, the `find` command searches for files starting with “letter” in their names. The names of the files found are passed by `-exec` to the following command (in this case, `grep appointment {}`).

The two brackets `{}` stand as placeholders for the filenames, which are found and passed to the `grep` command. The semicolon closes the `-exec` instruction. Because this is a special character, it is masked by placing a backslash in front of it.

When `grep` is used alone, it searches for a specific expression in a file whose exact position in the file system is known. When used in combination with `find`, the search is for a file that contains a certain expression, but whose location is unknown.

## which

The `which` command searches all paths listed in the variable PATH for the specified command and returns the full path of the command. The PATH variable contains the directories where the shell looks for executable files.

![](img/9129877170834ca9d5fdac5319bf5f12_242_0.png)

To see the content of a variable, use the `echo` command and add a “$” in front of the variable’s name. To see the content of the variable PATH, enter `echo $PATH`.

The `which` command is especially useful if several versions of a command exist in different directories. You use `which` if you want to know which program is executed when the command is entered without specifying a path.

The following is an example of using the `which` command:

```text
geeko@da10:~ > which find
/usr/bin/find
geeko@da10:~ > which cp
/bin/cp
geeko@da10:~ > which grep
/usr/bin/grep
geeko@da10:~ >
```

For more information on which, enter `man which`.

## type

The *type* command can be used to find out what kind of command is executed when *command* is entered—a shell built-in (an essential command that is hard-coded in the shell), an external command (called by the shell), an alias, or a function. The option -a delivers all instances of a command bearing this name in the file system.

The following is an example of using the type command:

```text
geeko@da10:~ > type type
type is a shell built in
geeko@da10:~ > type grep
grep is /usr/bin/grep
geeko@da10:~ > type -a grep
grep is /usr/bin/grep
grep is /bin/grep
geeko@da10:~ >
```

## Exercise 7-6: Find Files on Linux

In this exercise, find files with the **whereis**, **which**, and **find** commands and with the GNOME Search Tool.

## Detailed Steps to Complete This Exercise

- Part I: Use the Commands whereis and which
- Part II: Use the GNOME Search Tool
- Part III: Use the find Command

## Part I: Use the Commands whereis and which

To use the whereis and which commands, do the following:

1. Open a terminal window.
2. Find the type of the ll command by entering
   ```text
   type ll
   ```
3. Find the manual pages of the find command by entering
   ```text
   whereis -m find
   ```
4. Find the path of the Firefox program by entering
   ```text
   which firefox
   ```

## Part II: Use the GNOME Search Tool

To use the GNOME Search Tool, do the following:

1. Start the GNOME Search Tool (Computer > More Applications > System > GNOME Search Tool).
2. Find all files in the home directory whose names start with my by doing the following:
   a. In the Name Contains field, enter `my*`.
   b. Select **Find**.
3. Find all files in the `/bin/` directory whose names consist of two characters by doing the following:
   a. In the Name Contains field, enter `??`.
   b. To search only in the `/bin` directory, open the **Look in Folder** menu; then select **Other**.
   c. From the dialog, select **bin**; then select **Open**.
   d. Select **Find** to start the search.
4. Find all files in the `/tmp/` directory that were changed or created in the last 24 hours by doing the following:
   a. In the Name Contains field, enter `*`.
   b. To search only in the `/tmp` directory, open the **Look in Folder** menu. From the menu, select **Other**.
   c. From the dialog, select **tmp**; then select **Open**.
   d. Select **Select More Options**.
   e. From the **Available Options** menu, select **Date Modified Less Than**; then select **Add**.
   f. In the **Date Modified Less Than** text box, enter `1`.
   g. Select **Find**.
5. Close the Search dialog.

## Part III: Use the find Command

To use the find command, do the following:

1. Start a terminal window.
2. Find all files in the home directory whose names start with my by entering

   `find ~ -name 'my*'`

3. Find all files in the `/tmp` directory that were changed or created in the last 24 hours by entering

   `find /tmp -ctime -1`

4. Close the terminal window by entering `exit`.

## Summary

- The Linux file system is arranged hierarchically using a series of directories to store files.
- Regardless of the number of file systems, there is only one root directory in Linux, denoted by a “/” character.
- Linux directories and files follow the File System Hierarchy Standard (FHS) and their location can be described using absolute or relative pathnames. You can view your current directory with the pwd command or change directories using the cd command.
- The /bin and /sbin directories contain executable binary programs. There are many other directories throughout the file system that have the name bin and sbin.
- The /boot directory contains information used to load the Linux kernel.
- The /dev directory contains character and block-oriented device files that are used to identify most hardware devices on the Linux system. Each device file contains a major number that identifies the device driver in the Linux kernel and a minor number that identifies the instance of the particular device. You can use the mknod command to create device files.
- Most system configuration information is stored in text files under the /etc directory and shared libraries are stored under the /lib directory.
- Home directories are typically located under the /home directory and named for their user account (e.g., /home/gecko). The root user’s home directory is always /root.
- The /media and /mnt directories typically contain mount point subdirectories that are used to mount and access removable media such as CD-ROMs, CD-RWs, DVDs, and floppies. The system typically automatically mounts these devices, but you can manually mount and unmount devices to these directories using the mount and umount commands.
- Non-Linux partitions are typically mounted to directories that begin with /data or /windows.
- The /usr and /opt directories store most system and user applications. In addition, many applications store application data in the /srv directory and temporary files in the /tmp directory.
- Log files, spool directories, and application-specific files are typically stored under the /var directory.
- The /proc and /sys directories are virtual directories in system memory that contain information that is exposed by the Linux kernel, including process, hardware, network, and version information. As a result, files in these directories are often used in system troubleshooting.
- There are many types of files that can exist on the Linux file system, such as normal files (text files, data files, executable programs), directories, device files, linked files, sockets, and named pipes (FIFOs). You can use various options to the ls command to view filename information.
- The touch command can create new files or update the time stamp on an existing file.
