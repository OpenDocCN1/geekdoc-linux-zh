# User and Group Configuration Files

The information you enter when creating or editing users and groups with YaST or command-line tools is saved to the following user administration files:

+   - `/etc/passwd`
+   - `/etc/shadow`
+   - `/etc/group`

![](bbox=[0.107, 0.569, 0.292, 0.641])

Whenever possible, you should not modify these files with an editor. Instead, use the Security and Users modules provided in YaST or the command-line tools described in “Manage User.” Modifying these files with an editor can lead to errors (especially in /etc/shadow), such as a user—including the user root—no longer being able to log in.

**/etc/passwd** The /etc/passwd file stores information for each user such as the username, the UID, the home directory, and the login shell.

In the past, /etc/passwd also contained the encrypted password. However, because the file needs to be readable by all (e.g., to show user and group names when using ls -l), the encrypted password is now stored in /etc/shadow, which is only readable by root and members of the group shadow.
