To add the current user as a privileged user, select Add Privileged User in the error message. Enter the root password in the dialog that appears.

![](bbox=[0.118, 0.706, 0.305, 0.779])

Be aware that this is not a one-time only permission; it allows the user to change the software installation with updates in the future as well. As a desktop administrator responsible for the software configuration on the user’s computer, you might not want to grant this privilege.

Use rug username to remove a user from the list of privileged users. See the manual page for rug for details on rug user management.
