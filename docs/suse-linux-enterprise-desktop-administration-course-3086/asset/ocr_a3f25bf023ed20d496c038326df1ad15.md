# Preface

**Since its conception in 1991, Linux has fast become a major enterprise operating system** and has led to the widespread adoption of Open Source Software in the computer industry. More recently, many organizations have adopted Linux as a main desktop operating system due to its advanced graphical desktop environment and plethora of its productivity software.

One good example is Novell’s switch to SUSE Linux as its main enterprise and desktop platform. Today, there are millions of Linux users, administrators, and developers worldwide, and this community continually grows as companies adopt Linux and Open Source technologies.

However, as Linux grows in today’s global marketplace, so does the need for Linux education. In this book, we examine the usage, configuration, and management of SUSE Linux Enterprise Desktop 10. More specifically, this book walks the student through the practices and procedures used to deploy SUSE Linux as well as manage file systems, hardware, users, groups, printers, boot loaders, processes, software, and the X environment using both graphical and command-line tools.

To provide benchmarks for hiring, many vendors such as CompTIA, Novell, Red Hat, and the Linux Professional Institute (LPI) have released Linux certification exams geared toward different skill sets required for common Linux job functions. The Novell Certified Linux Desktop Administrator (CLDA) certification is practicum-based and focuses on the deployment and administration of SUSE Linux Desktop systems. Using carefully constructed examples, questions, and practical exercises, the *SUSE Linux Enterprise Desktop Administration* (Course 3086) text introduces you to the concepts tested on the CLDA certification exam.
