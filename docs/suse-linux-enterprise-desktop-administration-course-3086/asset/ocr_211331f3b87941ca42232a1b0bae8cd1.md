+   - **/var directory** — A directory that contains log files and spools.
+   - **/windows directory** — A directory that contains subdirectories used to mount local Windows partitions.
+   - **~ (tilde)** — A character used to represent a user’s home directory.
+   - **absolute path** — The full name to a certain file or directory starting from the root directory.
+   - **ASCII files** — Files that contain text that adheres to the American Standard Code for Information Interchange.
+   - **bash (Bourne Again Shell) command** — The command interpreter on Linux systems that provides a command-line interface to the system.
+   - **block-oriented device file** — A device file which specifies that information be transferred to the device in a block-by-block manner to a formatted file system.
+   - **cat command** — A command that is used to display (or concatenate) the entire contents of a text file to the screen.
+   - **cd (change directory) command** — A command that is used to change the current directory in the directory tree.
+   - **character-oriented device file** — A device file which specifies that information be transferred to the device in a character-by-character manner.
+   - **cp (copy) command** — A command that is used to create copies of files and directories.
+   - **device file** — A file used to identify hardware devices such as hard disks and serial ports.
+   - **directories** — Special files that are used to organize other files on the file system.
+   - **FIFOs** — See named pipes.
+   - **File System Hierarchy Standard (FHS)** — A standard outlining the location of set files and directories on a Linux system.
+   - **find command** — A command that is used to find files on the file system using various criteria.
+   - **GNOME Search Tool** — A graphical utility that can be used to find files and directories on the file system.
+   - **GRUB (Grand Unified Bootloader)** — The program that loads the Linux kernel at system initialization.
+   - **hard link** — A file that points to another file’s inode.
+   - **head command** — A command that is used to display the first set of lines of a text file; by default, the head command displays the first 10 lines.
+   - **hidden files** — Files that are not normally displayed to the user via common file system commands; hidden files are filenames that start with a period.
+   - **home directory** — A directory on the file system set aside for users to store personal files and information.
+   - **init process** — The first process loaded in Linux. It always has the process number of 1.
+   - **inode** — The portion of a file that stores information on the file’s attributes, access permissions, location, ownership, and file type.
+   - **less command** — A command that is used to display a text file page-by-page on the terminal screen; users can then use the cursor keys to navigate the file.
+   - **links** — Files that point to other files on the file system.
+   - **ln (link) command** — A command that is used to create hard and symbolic links.
