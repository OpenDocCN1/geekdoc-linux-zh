# Performing a Remote Installation Using FTP/HTTP/SMB/CIFS

It is important to carefully consider the protocol that you choose for remote SUSE Linux installations. Many organizations use network firewalls and security appliances to protect networks from unauthorized use. As a result, only certain protocols are allowed across networks today.

In this section, you performed a network installation using NFS. Use the documentation on the Internet (http://www.novell.com) or your SUSE Linux system (/usr/share/doc) to enable your computer as an FTP, HTTP, or SMB/CIFS installation server and perform another network installation from your installation server.
