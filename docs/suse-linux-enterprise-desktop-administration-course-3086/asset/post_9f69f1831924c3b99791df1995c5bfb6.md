## Summary

-   The cross-platform LDAP directory service allows network users to query information for a wide range of uses, including user authentication and information storage. SUSE Linux uses OpenLDAP to provide LDAP services.
-   LDAP resources are organized into a hierarchical tree structure. Each resource (leaf object) is stored in a series of container objects and can be accessed using a DN or RDN.
-   YaST can be used to configure a client connection to an LDAP service.
-   An NFS server shares directories to NFS clients using RPCs and the portmapper service. NFS clients then mount shared NFS directories on remote computers to local directories.
-   You can configure your computer to connect to remote NFS shared directories using YaST or by editing the /etc/fstab file.
-   The Automounter service can be used to automatically mount home directories from remote NFS servers to local directories. You can store the Automounter configuration in an LDAP directory service.
-   Windows networks typically use the Active Directory service to provide centralized authentication and resource access using LDAP and Kerberos.
-   The Winbind daemon is used to integrate SUSE Linux with an Active Directory environment. Active Directory Kerberos tickets are processed by PAM modules on SUSE Linux clients.
-   You can configure your SUSE Linux system to use Active Directory using YaST. You should also ensure that your system has the correct time using NTP, forwards to an Active Directory DNS server, and does not have an active firewall. You can then use the GDM, KDM, or `ssh` command to log in to the Active Directory domain.
-   You can share file and printer resources with Windows computers using Samba. Samba emulates the SMB and NetBIOS protocols used on Windows networks using the `smbd` and `nmbd` daemons as well as the entries in the `/etc/samba/smb.conf` file.
-   Most shared resources on Windows computers are accessed by NetBIOS name using UNC s. The `nmblookup` command can be used to test NetBIOS name resolution.
-   Nautilus can be used to create Samba shares as well as access Windows shares on the network. You can also connect to a Windows or Samba share using the `mount` and `smbclient` commands.
-   Novell networks typically use the eDirectory service to provide centralized authentication and resource access using LDAP. eDirectory user accounts can be managed using LUM or Novell iManager. You can configure LUM during SUSE Linux installation or by using YaST. Novell iManager must be accessed using a Web browser.
-   To access all eDirectory services, you must configure the Novell Client for Linux on your SUSE Linux system. You can configure the Novell Client for Linux using YaST or by using custom configuration files.
-   You can access the Novell Client for Linux by clicking on the Novell Client tray application from within a graphical desktop environment.
-   Novell iFolder can be used to share files on Linux and Windows systems that have an iFolder client installed and an iFolder account created. You can easily encrypt and control access to iFolder-shared files.

## Key Terms

-   **/etc/auto.master** The Automounter configuration file.
-   **/etc/fstab** A file used to automatically mount file systems at system initialization.
-   **/etc/nsswitch.conf** A file that lists the methods used by services to access information on a Linux system.
-   **/etc/opt/novell/ncl** A directory that stores Novell Client configuration files.
-   **/etc/samba/smb.conf** The main Samba configuration file.
-   **/etc/samba/smbfs tab** A file that contains Samba file system mount options.
-   **/opt/novell/ifolder3/bin/ifolder** The iFolder client program.
-   **/opt/novell/ncl/bin/ncl_tray** The Novell Client tray application.
-   **/usr/sbin/automount** The Automounter program in SUSE Linux.
-   **Active Directory (AD)** The directory service used on Windows networks.
-   **attributes** The properties contained within an LDAP object.
-   **autofs** The Automounter package in SUSE Linux.
-   **autofs daemon** The Automounter daemon in SUSE Linux.
-   **Automounter** A system service that automatically connects remote resources to local directories.
-   **container object** An LDAP object used to organize leaf objects.
-   **directory** A database that contains information about resources such as user accounts.
-   **Directory Information Tree (DIT)** The hierarchical structure of an LDAP database.
-   **directory service** A service that can be used to query a directory for information.
-   **distinguished name (DN)** A full pathname to an LDAP leaf object.
-   **Domain Name System (DNS)** The naming system used on the Internet. Each host is identified by a hostname and domain name.
-   **Dynamic Host Configuration Protocol (DHCP)** A protocol that is used to assign TCP/IP configuration information to a host on the network.
-   **eDirectory** The directory service used on Novell networks.
-   **entry** A reference to an LDAP object.
-   **firewall** A service that restricts certain network traffic on a host computer.
-   **GNOME Display Manager (GDM)** The login screen used by the GNOME desktop environment.
-   **iFolder** See Novell iFolder.
-   **iFolder Client** The software component installed on iFolder clients that can be used to connect to and manage shared files.
-   **iManager** See Novell iManager.
-   **insserv command** A command that is used to configure daemon startup at system initialization.
-   **K Display Manager (KDM)** The login screen used by the KDE desktop environment.
-   **Kerberos** A secure authentication protocol used by UNIX, Linux, and Windows directory services. Kerberos uses tickets to identify authenticated computers and services.
-   **Key Distribution Center (KDC)** The computer that is used to issue Kerberos tickets.
-   **Konqueror** The graphical file management utility used in the KDE desktop.
-   **leaf object** An LDAP object that represents a network resource.
-   **Lightweight Directory Access Protocol (LDAP)** A protocol used to provide central authentication and distribute information to network computers.
-   **Lightweight Directory Interchange Format (LDIF)** The format by files that are used to create, modify, and query objects in an LDAP database.
-   **Linux User Management (LUM)** A management suite designed to manage local and directory-based user accounts on SUSE Linux computers.
-   **Name Service Switch (NSS)** A software component that provides information about name services on a Linux system.
-   **Nautilus** The default graphical file management utility used in SUSE Linux.
-   **NetBIOS** A Windows protocol that uses unique 15-character computer names to identify network hosts.
-   **NetWare Core Protocol (NCP)** The application layer protocol used by Novell NetWare systems on a network.
-   **Network File System (NFS)** A file-sharing protocol used by UNIX and Linux systems.
-   **Network Information Service (NIS)** A service that allows the centralization of Linux and UNIX configuration.
-   **Network Time Protocol (NTP)** A protocol used to obtain time information from a time server on the Internet.
-   **NFS client** A computer that accesses exported files on an NFS server using the NFS protocol.
-   **NFS Lock Manager (NLM)** A kernel module that provides for NFS file locking.
-   **NFS server** A computer that hosts (exports) files using the NFS protocol.
-   **nmbd** The NetBIOS daemon in the Samba package.
-   **nmblookup command** A command that displays NetBIOS computer names for hosts.
-   **Novell Client for Linux** A SUSE Linux software component that can be used to access Novell network services.
-   **Novell iFolder** A secure file-sharing system that can be used by Windows and Linux systems.
-   **Novell iManager** A Web-based utility that can be used to manage directory user accounts.
-   **Novell Modular Authentication Services (NMAS)** A secure distributed authentication system used by Novell networks.
-   **novfs.ko** The kernel module used by the Novell Client for Linux.
-   **novfsd** The daemon used by the Novell Client for Linux.
-   **object** A component of an LDAP database. The two main object types are container objects and leaf objects.
-   **object class** A type of object within an LDAP database.
-   **OpenLDAP** An LDAP service that is used in SLES.
-   **OpenSLP** The implementation of SLP used by SUSE Linux systems.
-   **passwd command** A command that is used to change Linux and AD passwords.
-   **Pluggable Authentication Modules (PAM)** A Linux software component that handles application authentication access to the system. PAM can also work with the Kerberos protocol.
-   **portmapper** The service that provides for RPCs in Linux.
-   **relative distinguished name (RDN)** The simple name of an object in LDAP.
-   **Remote Procedure Call (RPC)** A routine that is executed on a remote computer.
-   **rpcinfo command** A command that displays RPC ports and their associated services.
-   **Samba** A set of services in Linux that provides the SMB and NetBIOS protocols for file and printer sharing with Windows computers.
-   **schema** The list of object and object properties for an LDAP database.
-   **Secure Shell (SSH)** A software service that provides an encrypted shell session to and from remote computers.
-   **Server Message Block (SMB)** A file and printer sharing protocol used by Windows systems.
-   **Service Location Protocol (SLP)** The network browsing protocol used by Novell networks.
-   **shares** Shared directories or printers on a Windows or Samba computer.
-   **smbclient command** A command that is used to view and access Windows and Samba file and printer shares.
-   **smbd** The Samba daemon.
-   **ssh command** A command that is used to obtain a shell from a remote SSH server.
-   **ticket granting ticket (TGT)** The Kerberos ticket that is given to authenticated computers after a successful authentication request.
