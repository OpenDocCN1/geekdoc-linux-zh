Every text editor has advantages and disadvantages. Two types of editors exist:

+   - Graphical editors
+   - Command-line editors

The main advantage of command-line editors is that you do not need a graphical user interface to use them.

An example of each type of editor is discussed:

+   - Work with gedit (Graphical Editor)
+   - Work with vi (Command-Line Editor)

# Work with gedit (Graphical Editor)
