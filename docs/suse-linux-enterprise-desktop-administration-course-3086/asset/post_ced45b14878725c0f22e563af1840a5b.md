
## Certification and Prerequisites

This course helps you prepare for the Novell Certified Linux Desktop Administrator 10 (Novell CLDA 10) certification, which is a performance-based exam. The Novell CLDA 10 is the administrator-level certification for SUSE Linux Enterprise Desktop 10.

As with all Novell certifications, course-work is recommended. To achieve the certification, you are required to pass the Novell CLDA 10 exam (050-708). A performance-based exam tests you on applying the knowledge you have to solve real-life problems—demonstrating that you know what to do and how to do it.

![](img/9129877170834ca9d5fdac5319bf5f12_22_0.png)

For more information about Novell certification programs and taking the Novell CLDA 10, Novell CLP 10, and CLE 10 Practicum exams, see *www.novell.com/training/certinfo/*.

This course is designed for desktop administrators who are new to Linux. Having experience in the administration of other desktop operating systems is an advantage.

## Further Studies

If you have finished this course, you are well prepared to continue to the Novell Certified Linux Professional 10 (CLP 10) certification. This is the administrator-level certification for SUSE Linux Enterprise Server 10. The CLP 10 exam is a hands-on, scenario-based exam where you apply the knowledge you have to solve real-life problems—demonstrating that you know what to do and how to do it.

The CLP 10 exam tests you on skills covered in the following courses:

- *SUSE Linux Enterprise Server 10 Fundamentals* (Course 3071)
- *SUSE Linux Enterprise Server 10 Administration* (Course 3072)
- *SUSE Linux Enterprise Server 10 Advanced Administration* (Course 3073)

If you have finished this course (Course 3086), you can directly proceed with Courses 3072 and 3073. More information about the Novell CLP 10 certification is available at *www.novell.com/training/certinfo/clp/*.

## Exercises

The exercises in this course consist of a description of the exercise and step-by-step instructions on how to complete the task. The exercises are contained in the workbook.

You should first try to complete the task described on your own, based on what is covered in the manual in the respective section. Resort to the step-by-step instruction only if you feel unable to complete the task or to find out if what you did was correct.

## Exercise Conventions

When working through an exercise, you will see conventions that indicate information you need to enter that is specific to your desktop.

The following describes the most common conventions:

- *italicized/bolded text*—This is a reference to your unique situation, such as the hostname of your desktop.

For example, if the host name of your desktop is da10, and you see the following:

*hostname.digitalairlines.com*

you would enter

da10.digitalairlines.com

- **10.0.0.xx**—This is the IP address that is assigned to your SUSE Linux Enterprise Desktop 10.

For example, if your IP address is 10.0.0.10, and you see the following:

`10.0.0.xx`

you would enter

`10.0.0.10`

- **Select**—The word *select* is used in exercise steps to indicate a variety of actions, including clicking a button on the interface and selecting a menu item.

- **Enter and Type**—The words *enter* and *type* have distinct meanings.

The word *enter* means to type text in a field or at a command line and press the Enter key when necessary. The word *type* means to type text without pressing the Enter key.

If you are directed to type a value, make sure you **do not** press the Enter key or you might activate a process that you are not ready to start.

## Install SUSE Linux Enterprise Desktop 10

**YaST (Yet another Setup Tool) provides options that make installation simple and quick.** However, you also need to understand the more advanced installation options available. By changing the installation mode, partitioning, software selection, authentication method, or hardware setup, you can install desktops that meet a variety of needs.

In this section, you install SUSE Linux Enterprise Desktop 10 (SLED 10). You also learn how to use advanced installation options and to troubleshoot the installation process.

### Objectives

- Objective 1—Perform a SUSE Linux Enterprise Desktop 10 Installation
- Objective 2—Configure the SUSE Linux Enterprise Desktop 10 Installation

## Objective 1—Perform a SUSE Linux Enterprise Desktop 10 Installation

The SLED 10 installation consists of a base installation phase and a configuration phase. To perform the base installation, do the following:

- Boot from the Installation Media
- Select the System Language
- Select the Installation Mode
- Set the Clock and Time Zone
- Understand and Change the Installation Settings
- Verify Partitioning
- Select Software
- Start the Installation Process

### Boot from the Installation Media

To start the installation process, insert the *SUSE Linux Enterprise Desktop* product DVD into the DVD drive and then reboot the computer to start the installation program.

![](img/9129877170834ca9d5fdac5319bf5f12_27_0.png)

To start the installation program, your computer needs to be configured to start from a DVD drive. You might need to change the boot drive order in the BIOS setup of your system to boot from the drive.

Consult the manual shipped with your hardware for further information.

When your system has started from the installation CD, your screen should look like Figure 1-1. You can use the arrow keys to select one of the following options:

- *Boot from Hard Disk*—Boots the system installed on the hard disk (the system normally booted when the machine is started). This is the default option.
- *Installation*—Starts the normal installation process. All modern hardware functions are enabled.
- *Installation--ACPI Disabled*—Starts the installation process with ACPI (Advanced Configuration and Power Interface) disabled. If the normal installation fails, the system hardware might not support ACPI. This option allows you to install without ACPI support.
- *Installation--Local APIC Disabled*—Starts the installation process with local APIC (Advanced Programmable Interrupt Controller) disabled.
- *Installation--Safe Settings*—Starts the installation process with the DMA (Direct Memory Access) mode and any power management functions disabled. Use this option if the installation fails with the other options.
- *Rescue System*—Starts the SLED 10 rescue system. If you cannot boot your installed Linux system, you can boot the computer from the DVD (or the first CD if you are using a CD set) and select this option. This starts a minimal Linux system without a graphical user interface to allow experts to access disk partitions for troubleshooting and repairing an installed system.
