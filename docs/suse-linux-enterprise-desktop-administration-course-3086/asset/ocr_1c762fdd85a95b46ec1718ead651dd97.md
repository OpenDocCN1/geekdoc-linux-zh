+   - You can use GConf to customize the GNOME user interface for the system for individual users as well as lock down access to certain desktop areas.
+   - To configure GConf, you can use gconf-editor, gconftool-2, or the GNOME Preferences panel. Individual GConf user configuration settings are stored in the ~/.gconf directory. Systemwide GConf configuration settings are stored in the /etc/opt/gnome/gconf directory.
+   - The Desktop Profile Editor can be used in addition to GConf to create custom desktop settings profiles for different user accounts or lock down access to the desktop.
+   - You can customize graphical applications using YaST, as well as configure program preferences, alter configuration files, and create templates. The /etc/skel directory contains default configuration files that are copied to the home directories of new user accounts.
+   - To enhance security on a computer that has removable media devices, you should prevent regular users from mounting removable media. This can be done by configuring GConf or by creating udev rules, as well as by editing the appropriate lines in the /etc/fstab or /etc/modprobe.conf.local files.

# Key Terms

**/etc/fstab** A file used to automatically mount file systems at system initialization.
**/etc/modprobe.conf.local** The configuration file that lists kernel modules loaded at system initialization.
**/etc/opt/gnome/desktop-profiles** The directory used to store user profiles and profile configuration information created by the Desktop Profile Editor.
**/etc/opt/gnome/gconf** The directory that stores systemwide GConf configuration.
**/etc/skel** A directory that contains files that are copied to a user's home directory when the user account is created.
**/etc/udev/rules.d** The directory used to contain rules used by the udev system.
**~/.gconf** The directory that stores personalized GConf configuration.
**~/.mozilla/firefox** The directory used to store user-specific configuration information for use with the Firefox Web browser.
**~/.ooo-2.0** The directory used to store user-specific configuration information for use with OpenOffice.org in SUSE Linux.
**Compiz** A composite and window manager that uses Xgl to provide enhanced graphics capabilities to a desktop environment.
**composite manager** A software component that creates composite images within a window manager.
**Desktop Profile Editor** A graphical utility that can be used to create, modify, and apply desktop profiles using GConf.
**Evolution** A common e-mail client application on Linux systems today.
**Firefox** The most common Open Source Web browser used on computer systems today.
