# View a File with less

You can use the less command to display the contents of a file page by page. Even compressed files (such as .gz and .bz2) can be displayed. You can use the keystrokes shown in Table 7-14 with less.

| Keystroke | Description |
|---|---|
| Spacebar | Move one screen down. |
| b | Move one screen up. |
| Down-arrow | Move one line down. |
| Up-arrow | Move one line up. |
| `/pattern` | Search for pattern forward from the current cursor position. |
| `?pattern` | Search for pattern backwards from the current cursor position. |
| n | Move to the next instance in the search for pattern. |
| N | Move to the previous instance in the search for pattern. |
| q | Quit. |

# View a File with head and tail

With the head command, you can view only the first few lines of a file. The tail command shows you only the last few lines of a file.

By default, these commands only show 10 lines. To change this number, append the option-`number`.

When used with the tail command, the option `-f` displays a continuously updated view of the last lines of a file. If a line is added at the end of the file while tail -f is running, the line is displayed. This is a useful feature for observing log files. To exit tail -f, press Ctrl+C.
