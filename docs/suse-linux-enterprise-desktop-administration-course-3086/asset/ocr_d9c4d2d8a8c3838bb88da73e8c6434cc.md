# Viewing and Modifying Novell iFolder Account Settings

The parameters listed in Table 13-3 can be viewed in the Account Settings and Account Properties dialogs.

| Parameter | Description | Location | Modifiable by User (Yes/No) |
|---|---|---|---|
| Online | Indicates whether you are currently connected to the Novell iFolder server for an account.

Select the Online check box next to the account to connect to the Novell iFolder server for this account.

Deselect the Online check box next to the account to disconnect from the Novell iFolder server. | iFolder Preferences > Accounts tab | Yes |
| Name | Displays the descriptive name of the Novell iFolder server where your Novell iFolders are stored for the account. This name is supplied by the server and is controlled by the Novell iFolder administrator. | iFolder Preferences > Accounts tab
Account Properties > Server tab | No |
| Address | Displays the DNS name or IP address of the Novell iFolder enterprise server where you have an account. Get this information from your Novell iFolder administrator.
For example: srv21.example.com or 192.168.1.1.

You can modify the address but you must be disconnected from the Novell iFolder server when you make the change. | Account Properties > Server tab | Yes |
| Server description | Displays information about the Novell iFolder server, such as its service location and Novell iFolder administrator contact information. The description is supplied by the server and is controlled by the Novell iFolder administrator. | Account Properties > Server tab | No |

Table 13-3

To view or modify account settings:

+   1. Right-click the Novell iFolder Services icon in the Notification area; then open Novell iFolder Preferences from the Accounts tab by selecting Account Settings.
+   2. In the Accounts report, you can manage the following parameters for each account:
+      - Online (select to connect; deselect to disconnect)
+      - Name (view only)
+      - User Name (view only)
