**SuSEConfig**  A software utility that configures the system using entries in the `/etc/sysconfig` directory.

**YaST**  The main configuration tool in SUSE Linux. It stands for Yet another Setup Tool and can be run in graphical or text (ncurses) mode.

**yast command**  A command used to start the ncurses interface of YaST.

**yast2 command**  A command used to start the Qt and ncurses interfaces of YaST.

**YaST Control Panel**  The main dialog screen in YaST that lists available YaST modules.

# ### Viewing Your System Hardware Profile

Understanding your system hardware is important in making future decisions regarding system usage. Over time, you might choose to add services to a particular Linux server that has enough hardware to adequately support the software. Alternatively, you might choose to upgrade the hardware on a Linux server before adding services.

Use the Hardware Information module of YaST to view your system hardware profile. Save or print the results for later use.
