# Monitor Hard Drive Space

The df command provides information on where hard drives and their partitions or other drives are mounted in the file system, and how much space they occupy.

Some useful options include -h (human readable format—in MB or GB), -i (list inode information instead of block usage), -l (limit listing to local file systems), and -T (print the file system type).

The du command provides information on the space occupied by files and directories. Some useful options include -c (display a grand total), -h (human-readable format), -s (display only a total for each argument), and --exclude=pattern (exclude files that match pattern).
