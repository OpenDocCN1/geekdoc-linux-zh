
**mkinitrd command** A command that is used to create an Initial RAM File System on a SUSE Linux system.

**mknod command** A command that is used to create special devices files.

**mkpasswd command** A command that is used to create an encrypted password for use with user or group accounts.

**mount command** A command that is used to mount a device to a mount point directory.

**mount point** The directory to which a device is mounted.

**mounting** The process of associating a device (i.e., CD-ROM) to a directory (i.e., /media/cdrom). After a device has been mounted, it can be accessed by navigating to the appropriate directory.

**multitasking** A feature of the Linux operating system that allows multiple processes to run on a single CPU.

**multithreading** A feature of the Linux operating system that allows parts of processes (threads) to run independently from one another on the system.

**multiuser** A feature of the Linux operating system that allows multiple users to interact with it simultaneously.

**mv (move) command** A command that is used to move/rename files and directories.

**name server** A server that contains records for hosts on a network. It can be queried to resolve a hostname to an IP address.

**Name Service Switch (NSS)** A software component that provides information about name services on a Linux system.

**named pipes** Temporary connections that send information from one command or process in memory to another; they are also represented by files in the file system. Named pipes are also called FIFO (First In First Out) files.

**Nautilus** The default file navigation utility that is included with GNOME.

**ncurses** A text-based menuing interface in Linux.

**NetBIOS** A Windows protocol that uses unique, 15-character computer names to identify network hosts.

**netfilter framework** The kernel and software components that provide packet filtering in SUSE Linux.

**netstat command** A command that displays network configuration and statistics.

**NetWare Core Protocol (NCP)** The Application Layer protocol used by Novell NetWare systems on a network.

**Network File System (NFS)** A file-sharing protocol used by UNIX and Linux systems.

**Network Information Service (NIS)** A service that allows the centralization of Linux and UNIX configuration.

**NetworkManager** A utility that can be used to manage network interfaces and connections in SUSE Linux.

**Network Time Protocol (NTP)** A protocol used to obtain time information from a time server on the Internet.

**newgrp command** A command that is used to change the current primary group for a user account.

**NFS client** A computer that accesses exported files on an NFS server using the NFS protocol.

**NFS Lock Manager (NLM)** A kernel module that provides for NFS file locking.

**NFS server** A computer that hosts (exports) files using the NFS protocol.

**nice command** A command that is used to change the priority of a process as it is started.

**nice value** A value that represents the priority of a process. A higher nice value reduces the priority of the process.

**nm-applet** The applet used to display NetworkManager within the GNOME desktop environment.

**nmbd** The NetBIOS daemon in the Samba package.

**nmblookup command** A command that displays NetBIOS computer names for hosts.

**nm-tools** A package that contains utilities that can be used to view and configure NetworkManager.

**nonlogin shell** A shell that is started by an existing shell.

**normal files** Commonly used files such as text files, graphic files, data files, and executable programs.

**normal users** See regular users.

**Novell Client for Linux** A SUSE Linux software component that can be used to access Novell network services.

**Novell Customer Center** An online service that allows access to SUSE Linux updates.

**Novell Customer Center Configuration** A YaST module used to configure the options and account information used by the Novell Customer Center.

**Novell iFolder** A secure file-sharing system that can be used by Windows and Linux systems.

**Novell iManager** A Web-based utility that can be used to manage directory user accounts.

**Novell iPrint Direct** A standard used by printers that allows them to receive iPrint print jobs directly from iPrint Printer Agents.

**Novell Modular Authentication Services (NMAS)** A secure distributed authentication system used by Novell networks.

**novfs.ko** The kernel module used by the Novell Client for Linux.

**novfsd** The daemon used by the Novell Client for Linux.

**object** A component of an LDAP database. The two main object types are container objects and leaf objects.

**object class** A type of object within an LDAP database.

**Online Update** A YaST module that allows you to install software patches and update your software to the newest versions.

**OpenGL** An industry standard application programming interface for defining 2D and 3D graphical images.

**OpenLDAP** An LDAP service that is used in SLES.

**OpenOffice.org** A full-featured office productivity suite commonly used on Linux systems today.

**OpenSLP** The implementation of SLP used by SUSE Linux systems.

**OpenSSH** The default package used to provide SSH services in SLES.

**OpenVPN** A common technology used to create VPNs on Linux systems.

**other** When referring to a long file or directory listing, it represents all users on the Linux system who are not the owner or a member of the group on the file or directory.

**owner** The user whose name appears in a long listing of a file or directory and who typically has the most permissions to that file or directory.

**Package Label** The information stored within an RPM package that lists general package information.

**panel** The bar at the bottom of the GNOME desktop used to open menus, switch virtual desktops, and start applications.

**parent process** A process that has started another process.

**Parent Process ID (PPID)** The PID of a process' parent process.

**passwd command** A command that is used to modify user passwords and expiry information as well as lock and unlock user accounts.

**PATH** A variable that stores a list of directories that will be searched in order when commands are executed without an absolute or relative pathname.

**ping command** A command used to test network connectivity on IP networks.

**Pluggable Authentication Modules (PAM)** A Linux software component that handles application authentication access to the system. PAM can also work with the Kerberos protocol.

**portmapper** The service that provides for RPCs in Linux.

**POSIX (Portable Operating System Interface)** An industry standard that defines operating system interface components. It stands for Portable Operating System Interface.

**PostScript Printer Description (PPD)** A printing format that is widely used by many printers and printing systems.

**power-on self test (POST)** A simple hardware test performed by the BIOS at system initialization.

**poweroff command** A command that is used to quickly bring a system to runlevel 0 and power off the system.

**Preboot eXecution Environment (PXE)** A technology used by network cards that allow them to locate files from an installation server on the network.

**preemptive multitasking** A feature of the Linux operating system that allows several processes to run simultaneously; the Linux kernel determines how much time each process has to execute.

**preferred list** A list of networks that users have connected to in the past within NetworkManager.

**primary group** The group specified for a user in the /etc/passwd file that becomes the group owner on newly created files and directories.

**primary partition** A main division of a hard disk. There are four available primary partitions.

**Print Manager** The software components that handle printing within iPrint.

**Printer Agent** A logical representation of a printer within the iPrint print manager.

**Printer Configuration** A YaST tool that can be used to configure CUPS printers on a SUSE Linux system.

**priorities** Levels of logging used by the Syslog daemon.

**private key** An asymmetric encryption key that can be used to decrypt data encrypted using a public key. The private key can also be used to encrypt data.

**process** A program currently loaded into memory and running on the CPU.

**Process ID (PID)** A unique identifier assigned to every process.

**program** An executable file on a file system. Programs become processes when they are executed.

**proxy** A network server or device that provides Internet access for network computers that request it.

**ps command** A command that is used to list processes that are running on the system.

**pstops command** A command that is used to format print jobs.

**pstree command** A command that is used to list processes that are running on the system as well as their parent and child relationships.
