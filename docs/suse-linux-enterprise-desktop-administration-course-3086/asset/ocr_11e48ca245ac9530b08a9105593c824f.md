You can also use the `useradd` command to view or change the defaults. The option **--show-defaults** displays the same information as the `cat /etc/default/useradd` command. The option **--save-defaults** followed by an option with a value changes the default:

```
```text
da10: # useradd --save-defaults -d /export/home
da10: # useradd --show-defaults
GROUP=100
HOME=/export/home
INACTIVE=-1
EXPIRE=
SHELL=/bin/bash
SKEL=/etc/skel
GROUPS=video,dialout
CREATE_MAIL_SPOOL=no
```
```

You can display a description of additional options by entering `man 8 useradd`. After adding a new user, you need to assign a password.

+   - **passwd**—You can change a user’s password with the passwd command. If a user enters passwd without a username as an argument, the user can change his or her own password:

```
```text
da10: # useradd -m -c "Geeko Chameleon" geeko
da10: # passwd geeko
New password:
Re-enter new password:
Password changed
```
```

In addition to being used to change user passwords, the passwd command can also be used to do the following:

+   - **Lock a user account**—Use the option `-l` (*lock*) to lock a user account; use the option `-u` (*unlock*), to reactivate the account:

```
```text
da10: # grep geeko /etc/shadow
geeko:$2a$05$QurFt5yTH2bhVxMxZ31c9YejHGt7XefIFMQ58QHspu8WDB
FWx7BhPK:13284:0:99999:7:::
da10: # passwd -l geeko
Password changed.
da10: # grep geeko /etc/shadow
geeko:!$2a$05$QurFt5yTH2bhVxMxZ31c9YejHGt7XefIFMQ58QHspu8WDB
BFWx7BhPK:13284:0:99999:7:::
da10: #
```
```

An account is locked when the password begins with an exclamation mark “!”.
