When a print job is destined for a Novell iPrint printer, the Novell iPrint Print Provider delivers the print job to the Print Manager.

+   - *Browser plug-in*—The Novell iPrint client contains a browser plug-in for Mozilla-based browsers and Microsoft Internet Explorer. The Internet Explorer plug-in is an OCX-based plug-in that lets you install printers through your Web browser.
+   - *Client configuration*—Through the Novell iPrint client configuration screen, you can take advantage of several advanced client features.
+   - *Command-line utilities*—The Novell iPrint MS-DOS commands let you install Novell iPrint printers without a Web browser and capture LPT ports to Novell iPrint printers.

These commands are useful when you have legacy applications that require output to an LPT port, or when you want to add printers through a login script.

**Apache Web Server** Apache 2.0 is the Web server for Novell iPrint. The Web server serves up HTML pages, handles secure (SSL/TLS) and nonsecure requests, and utilizes LDAP for authentication.

**Novell iManager** You use Novell iManager to create, configure, and manage your Novell iPrint system.

For complete management, including uploading printer drivers and PPD files, you need to access iManager from a workstation with the Novell iPrint client installed.

**Novell iPrint Port Usage** Novell iPrint can use any port specified on Apache; however, Novell iPrint defaults to two primary ports:

+   - *Port 443*—All secure printing occurs over port 443 using SSL.
+   - *Port 631*—All nonsecure printing occurs over port 631.

The Novell iPrint client also supports Transport Layer Security (TLS). If your system, including the client, is configured to use TLS, all secure and nonsecure printing occurs over port 631.

During OES installation of the Novell iPrint software, the CUPS back-end components are disabled on the server to avoid port 631 conflicts.

Because Novell iPrint uses CUPS to render a print job before sending the print job to the Print Manager, printing from the server itself using CUPS or Novell iPrint is not available.
