## Summary

- After logging in to a Linux system, a login shell is started to provide your user environment, execute your commands, and display your output. If you use a graphical login, the X Window System runs on top of a login shell. Any additional shells that you start follow logging into nonlogin shells.
- Although there are many shells available for use in Linux, the default shell is the Bourne Again shell (bash). The bash shell in SUSE Linux reads the `/etc/profile`, `~/.profile`, `/etc/bash.bashrc`, `/etc/bash.bashrc.local`, and `~/.bashrc` files at login to create variables and run programs. In addition, the `/etc/bash.bashrc`, `/etc/bash.bashrc.local`, and `~/.bashrc` files are read each time a nonlogin shell is started.
- The bash shell is case-sensitive, can be used to perform filename completion, and can execute previously entered commands.
- Several environment variables are loaded when a shell is started that are used by programs to set the user environment and locale.
- Aliases are special shell variables that contain commands. When you invoke an alias, the commands defined within it will be executed.
- Wildcards are special characters that can be used to represent patterns when specifying file or directory names on the file system. You can protect special characters from shell interpretation by using single quotes, double quotes, or the backslash character.
- Although many text-based and graphical text editors are available for Linux systems, the vi editor is the most commonly used editor across different distributions of Linux and versions of UNIX. By default, SUSE Linux includes vim (vi improved), which uses different modes for inserting text, editing text, and saving document changes.

## Key Terms

- **.command** — A command used to execute a file in the current shell environment.
- **/bin/bash** — The executable file for the Bourne Again Shell.
- **/bin/csh** — The executable file for the C shell.
- **/bin/ksh** — The executable file for the Korn shell.
- **/bin/sh** — The executable file for the Bourne shell.
- **/bin/tcsh** — The executable file for the TC shell.
- **/etc/bash.bashrc** — A bash shell configuration file typically used to set the command prompt and create aliases for all users on the system.
- **/etc/bash.bashrc.local** — A file that contains commands that are executed for all users on the system. It is executed by the /etc/bash.bashrc file.
- **/etc/profile** — A bash shell configuration file that is read for all users on the system.
- **/etc/sysconfig/language** — A file that defines the default character encoding used on SUSE Linux systems.
- **\\** — A special character used to protect the following character from shell interpretation.
- **~/.alias** — A bash shell configuration file that is used to store aliases.
- **~/.bash_history** — A bash shell configuration file that is used to store previously executed commands.
- **~/.bashrc** — A bash shell configuration file that is read at login and when nonlogin shells are started.
- **~/.profile** — A bash shell configuration file that is read if ~/.bash_profile and ~/.bash_login do not exist.
- **~/.vimrc** — A file used to set vim configuration options for a user.
- **'...' (single quotes)** — Characters used to protect all enclosed text from shell interpretation.
- **"..." (double quotes)** — Characters used to protect all enclosed text except $, \\, and ` characters from shell interpretation.
- **alias command** — A command used to create special alias variables.
- **aliases** — Special variables that can be used to execute commands in a shell.
- **Bourne Again shell (bash)** — The default shell on most Linux systems, including SUSE Linux.
- **command mode** — A mode in the vi editor that allows you to perform any available text editing task that is not related to inserting text into the document.
- **echo command** — A command used to display or echo output to the terminal screen—it can be used to view the contents of variables.
- **environment variables** — Variables that are available to the current shell and all programs executed by the shell.
- **gedit command** — A command used to invoke the GNOME graphical text editor.
- **history command** — A command used to view and recall previously executed commands.
- **insert mode** — A mode in the vi editor that allows you to insert text into the document.
- **locale command** — A command used to list localization variables.
- **login shell** — A shell that is started immediately following login.
- **nonlogin shell** — A shell that is started by an existing shell.
- **POSIX (Portable Operating System Interface)** — A character encoding format used by the root user in SUSE Linux shells.
- **search patterns** — Special characters that can be used to match multiple filenames. Also known as wildcards.
- **shell** — The Linux command interpreter.
- **shell variables** — Variables that are only available in the current shell and are used to configure the shell itself.
- **source command** — A command used to execute a file in the current shell environment.
