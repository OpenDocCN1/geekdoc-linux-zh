# Manage Software

**Software management is an important part of the work of a desktop administrator.** The main tool you use to manage software on SUSE Linux Enterprise Desktop 10 is the YaST Software Management module. In addition, you need to know how to manage installation sources and how to perform updates. The RPM tool is covered briefly in this section as well.
