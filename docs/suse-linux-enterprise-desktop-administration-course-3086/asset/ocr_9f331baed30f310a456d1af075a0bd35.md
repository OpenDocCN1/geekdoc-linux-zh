During installation, the Online Update dialog appears after successful registration. You start the Online Update by selecting **Run Update** and **Next**. (You can select **Skip Update** to perform the update later in the installed system.)

To update an installed system, access the Online Update by starting YaST and selecting **Software > Online Update**.

YaST’s online update dialog appears, as shown in Figure 6-10, listing the available patches.

![](bbox=[0.05, 0.219, 0.965, 0.735])

**Figure 6-10**

Select the patches you want to install; then start the update process by selecting **Accept**. The updates are transferred to your computer and installed.
