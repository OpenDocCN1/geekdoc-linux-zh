# **Set Up and Configure the Driver Store**

The Driver Store is a repository of printer drivers for your print system. When the first user of a printer installs that printer, the Print Manager requests the associated printer driver from the Driver Store, and the Print Manager saves the printer driver to disk for future use.

Periodically, Print Managers refresh their saved copies of printer drivers with updated printer drivers from their associated Driver Store.

Only one Driver Store is required on a network but, depending on your network configuration, you can create additional Driver Stores. The fewer Driver Stores running, the better because you do not need to track which Driver Store has which printer drivers.

To set up and configure the Driver Store, do the following:

+   - Create a Driver Store
+   - Add Printer Drivers
+   - Create a DNS Name for the Print Manager

# **Create a Driver Store**

You need only one Driver Store for your print system; however, depending on your network setup, you can add more Driver Stores. You need to create a Driver Store to create a Print Manager.

The following are general steps for creating a Driver Store:

+   1. From Novell iManager (on the left), select **iPrint > Create Driver Store**.
+   2. Fill in the appropriate fields.
+      For explanations about the fields, select Help.
+   3. When you finish filling in the fields, select **OK**.

After the Driver Store is created and the daemon is loaded on the server, you can start uploading printer drivers.

# **Add Printer Drivers**

A printer driver or PostScript Printer Description (PPD) file is a software entity that directly supports a physical printer, enabling it to carry out its functions.

Hardware vendors develop printer drivers and PPD files that are specific to each printer. Most printers require different printer drivers for each operating system they interact with.

You can view a list of the printer drivers and PPD files you have uploaded to the Driver Store using Novell iManager. You can add printer drivers and PPD files from diskettes, CDs, and the workstation operating system.

To add resources to the Driver Store, the Driver Store daemon must be running, and the Novell iPrint client must be installed.

To add printer resources to the Driver Store, do the following:

+   1. From Novell iManager (on the left), select **iPrint > Manage Driver Store**; then browse to and select the *Driver Store* you want.
+   2. Select Drivers; then select the *client platform* you want to work with.
+   3. Do one of the following:
+      - Add printer resources from a printer driver .inf file or PPD file by selecting **Add from File**.
