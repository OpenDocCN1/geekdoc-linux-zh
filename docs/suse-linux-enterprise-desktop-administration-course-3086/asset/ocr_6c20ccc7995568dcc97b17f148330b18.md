**/etc/cron.d** A directory that contains additional system cron tables.

**/etc/crontab** The system cron table.

**/etc/cups/client.conf** A file that lists remote CUPS servers on a SUSE Linux system.

**/etc/cups/cupsd.conf** The main CUPS configuration file.

**/etc/cups/ppd** The directory that stores the active configuration files used for a particular printer.

**/etc/cups/printcap** A file that is used to store CUPS client configuration information.

**/etc/cups/printers.conf** A file that contains CUPS printer definitions.

**/etc/default/passwd** A file that contains default values used when changing passwords such as an encryption algorithm.

**/etc/default/useradd** A file that contains default values used when creating user accounts.

**/etc/exports** The file used to configure NFS shared directories.

**/etc/fstab** The file that contains partition mounting information. It is used to mount file systems at system initialization.

**/etc/group** The file that contains system groups and their members.

**/etc/init.d** The directory that contains the scripts used to start and stop most daemons.

**/etc/init.d/boot** The script used to activate file systems and swap during system initialization.

**/etc/init.d/boot.crypto** A file read at system initialization to decrypt encrypted partitions. It prompts you for the password used to decrypt a partition.

**/etc/init.d/rc** The script used to start and stop daemons based on runlevel.

**/etc/init.d/rc.runlevel.d** The directories used by the init daemon to start and kill daemons in each runlevel.

**/etc/init.d/skeleton** A sample script that can be copied to create scripts used to start a daemon.

**/etc/inittab** The configuration file for the init program.

**/etc/lilo.conf** The LILO configuration file.

**/etc/login.defs** A file that contains default values used when creating user accounts.

**/etc/logrotate.conf** The configuration file for the logrotate command. It typically uses parameters listed in the /etc/logrotate.d directory for each log file.

**/etc/logrotate.d** The directory that stores log file-specific information for use by the logrotate command.

**/etc/modprobe.conf.local** The configuration file that lists kernel modules loaded at system initialization.

**/etc/mtab** A file that contains a list of mounted file systems.

**/etc/nsswitch.conf** A file that lists the methods used by services to access information on a Linux system.

**/etc/opt/gnome/desktop-profiles** The directory used to store user profiles and profile configuration information created by the Desktop Profile Editor.

**/etc/opt/gnome/gconf** The directory that stores systemwide GConf configuration.

**/etc/opt/novell/ncl** A directory that stores Novell Client configuration files.

**/etc/passwd** The file that contains user account information such as name, UID, primary group, home directory, and shell.

**/etc/printcap** A symbolic link to the /etc/cups/printcap file.

**/etc/profile** A bash shell configuration file that is read for all users on the system.

**/etc/profile.local** A file that can be used to store systemwide variables such as umask.

**/etc/rpmrc** A file that contains configuration information that is written to the /usr/lib/rpm/rpmrc file.

**/etc/samba/smb.conf** The main Samba configuration file.

**/etc/samba/smbfsstab** A file that contains Samba file system mount options.

**/etc/shadow** The file that typically contains encrypted passwords and password expiry information for user accounts on the system.

**/etc/shells** A file that lists valid system shells such as /bin/bash.

**/etc/skel** A directory that contains files and directories that are copied to all new users' home directories after they are created.

**/etc/ssh/known_hosts** A file used to store the encryption keys of known SSH hosts.

**/etc/ssh/ssh_config** The systemwide ssh client program configuration file.

**/etc/ssh/sshd_config** The SSH daemon configuration file.

**/etc/ssh/ssh_host_dsa_key** A file used to store DSA keys for use with SSH.

**/etc/ssh/ssh_host_rsa_key** A file used to store RSA keys for use with SSH.

**/etc/sudoers** A file that lists the users who are allowed to run certain commands as other users.

**/etc/sysconfig** The directory that stores configuration information stored by YaST.
