
- You can configure the SSH type, authentication, and encryption types in the SSH server configuration file `/etc/ssh/sshd_config`. SSH client options are stored in the `/etc/ssh/ssh_config` file. User-specific SSH client options are stored in `~/.ssh/config`.

- You can generate asymmetric SSH encryption keys using the `ssh-keygen` command and view them using the `ssh-keyscan` command. Public encryption keys from remote hosts are stored in `~/.ssh/known_hosts` on the SSH client and `/etc/ssh/ssh_known_hosts` on the SSH server. In SSH, encryption keys can also be used for authentication.

- You can use the `vino-preferences` command to configure a VNC server that can be used to graphically administer your system remotely. You can connect to a remote VNC server using the `vncviewer` command.

## Key Terms

**/bin/ip** — The executable for the ip command. See ip command.

**/etc/ssh/known_hosts** — A file used to store the encryption keys of known SSH hosts.

**/etc/ssh/ssh_config** — The systemwide ssh client program configuration file.

**/etc/ssh/ssh_host_dsa_key** — A file used to store DSA keys for use with SSH.

**/etc/ssh/ssh_host_rsa_key** — A file used to store RSA keys for use with SSH.

**/etc/ssh/sshd_config** — The SSH daemon configuration file.

**/etc/sysconfig/network** — The directory that contains most network configuration information.

**/etc/sysconfig/network/config** — A file that contains network configuration settings such as NetworkManager.

**/etc/sysconfig/SuSEfirewall2** — The file that stores packet filter information for use with the netfilter framework in SUSE Linux.

**~/.ssh/authorized_keys** — A file used to store keys that can be used for SSH authentication.

**~/.ssh/config** — The ssh client program configuration file.

**~/.ssh/id_dsa** — A file used to store a DSA private key for use with SSH2.

**~/.ssh/id_rsa** — A file used to store an RSA private key for use with SSH2.

**~/.ssh/identity** — A file used to store a private key for use with SSH1.

**~/.ssh/identity.pub** — A file used to store a public key for use with SSH1.

**~/.ssh/id_dsa.pub** — A file used to store a DSA public key for use with SSH2.

**~/.ssh/id_rsa.pub** — A file used to store an RSA public key for use with SSH2.

**~/.ssh/known_hosts** — A file used to store the encryption keys of known SSH hosts.

**Advanced Encryption Standard (AES)** — A common symmetric encryption algorithm that uses up to 256-bit keys and is intended to replace 3DES.

**asymmetric encryption** — A type of encryption that uses a public and private key pair. Information encrypted with the public key can be decrypted using the private key and vice versa.

**Blowfish** — A common symmetric encryption algorithm that uses up to 448-bit keys.

**Data Encryption Standard (DES)** — A common symmetric encryption algorithm that uses 56-bit keys.

**default gateway** — The router that connects a network to other networks. IP packets whose destination networks are not included in the routing table are sent to the default gateway.

**Diffie-Hellman** — A common asymmetric encryption algorithm.

**Digital Signature Algorithm (DSA)** — A common asymmetric encryption algorithm.

**DNS server** — A server that contains records for hosts on a network. It can be queried to resolve a hostname to an IP address.

**DNS server** — See name server.

**domain name** — The name of the DNS domain that a computer on a TCP/IP network belongs to.

**Domain Name System (DNS)** — The naming system used on the Internet. Each host is identified by a hostname and domain name.

**driver** — A software component used by the operating system to control hardware devices such as network devices.

**Dynamic Host Configuration Protocol (DHCP)** — A protocol that is used to assign IP configuration information to a host on the network.

**ESSID (Extended Service Set Identifier)** — A name that identifies a host on a wireless network.

**firewall** — A software feature that allows a host to drop IP packets that meet certain criteria.

**FQDN (Fully Qualified Domain Name)** — A name that refers to a resource on a TCP/IP network. It consists of a hostname followed by a domain name.

**gnome-keyring-manager command** — A command that is used to manage keyrings in SUSE Linux.

**Hash Message Authentication Code (HMAC)** — A feature of SSH version 2 that prevents attackers from compromising SSH data during transit.

**hostname** — A name used to identify hosts on a TCP/IP network.

**HyperText Transfer Protocol Secure (HTTPS)** — A common technology used to encrypt World Wide Web traffic. It can also be used to create VPNs.

**ifup command** — A command used to activate a network card in SUSE Linux.

**International Data Encryption Algorithm (IDEA)** — A common symmetric encryption algorithm that uses up to 128-bit keys.

**Internet Control Message Protocol (ICMP)** — A part of the TCP/IP protocol suite that is used to relay information about network communications.

**Internet Protocol (IP)** — The protocol used to communicate with other computers on the Internet and most other networks.

**Internet Protocol (IP) address** — A unique address used to identify a computer on a TCP/IP network.

**ip command** — A command used to view, configure, and manage network interfaces and the routing table.

**IP forwarding** — See routing.

**IP Security (IPSec)** — A common technology used to encrypt communication on IP networks. It can also be used to create VPNs.

**iptables command** — A command used to configure packet filtering using the netfilter framework in SUSE Linux.

**keyring** — A file used to store passwords for future use with wireless networks and VPNs.

**KNetworkManager** — The graphical program that displays NetworkManager within the KDE desktop environment.

**Layer 2 Tunneling Protocol (L2TP)** — A common technology used to create VPNs on Linux systems.

**Lightweight Directory Access Protocol (LDAP)** — A protocol used to provide access to a directory database from network computers.

**Long-life Host Key Pair (HK)** — An asymmetric encryption key pair that is generated when the SSH daemon is started. This key pair is typically stored in a file for future use.

**Message Digest 5 (MD5)** — A common algorithm used to create a hash or checksum of data.

**name server** — A server that contains records for hosts on a network. It can be queried to resolve a hostname to an IP address.

**netfilter framework** — The kernel and software components that provide packet filtering in SUSE Linux.

**NetworkManager** — A utility that can be used to manage network interfaces and connections in SUSE Linux.

**nm-applet** — The applet used to display NetworkManager within the GNOME desktop environment.

**nm-tools** — A package that contains utilities that can be used to view and configure NetworkManager.

**OpenSSH** — The default package used to provide SSH services in SLES.

**OpenVPN** — A common technology used to create VPNs on Linux systems.

**ping command** — A command used to test network connectivity on IP networks.

**preferred list** — A list of networks that users have connected to in the past within NetworkManager.

**private key** — An asymmetric encryption key that can be used to decrypt data encrypted using a public key. The private key can also be used to encrypt data.

**public key** — An asymmetric encryption key that can be used to decrypt data encrypted using a private key. The public key is typically used to encrypt data.

**rcp command** — A command used to copy files to and from remote computers.

**Rivest Shamir Adleman (RSA)** — A common asymmetric encryption algorithm.

**rlogin command** — A command used to obtain a shell on a remote computer.

**router** — A device that is used to relay IP packets from one IP network to another.

**routing** — The process of sending IP packets from one IP network to another. It is also called IP forwarding.

**routing table** — A table that is stored on each host that contains a list of local and remote networks and routers.

**rsh command** — A command used to obtain a shell or run a program on a remote computer.

**scp command** — A command used to copy files from one host to another using SSH.

**Secure Shell (SSH)** — A software service that provides encrypted communication to and from remote computers. It can also be used to create VPNs.

**Server Process Key Pair (SK)** — An asymmetric encryption key pair that is generated when the SSH daemon is started. This key pair is never stored in a file and is regenerated each time the daemon is restarted.
