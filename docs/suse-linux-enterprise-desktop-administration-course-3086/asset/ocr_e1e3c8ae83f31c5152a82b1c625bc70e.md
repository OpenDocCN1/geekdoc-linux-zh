+   - *Path Prefix for Home Directory*—Enter or browse to the initial path prefix for a new user’s home directory. The username will be appended automatically to the end of this value to create the complete path and name of the user’s home directory.
+   - *Skeleton for Home Directory*—Enter or browse to the skeleton directory. The contents of this directory will be copied to the user’s home directory when you add a new user.
+   - *Umask for Home Directory*—The umask determines whether or not other users can view the content of the home directory. A umask of 022 allows other users to change to `/home/username` and to view the content of it.
+   - *Default Expiration Date*—Enter the date on which the user account is disabled. The date must be in the format YYYY-MM-DD. Leave the field empty if this account never expires.
+   - *Days after Password Expiration Login Is Usable*—This setting enables users to log in after passwords expire. Set how many days login is allowed after a password has expired. Enter −1 for unlimited access.
