# # Summary

+   - After performing a POST, the BIOS typically loads the boot manager from the MBR. The boot manager starts the Linux kernel and Initial RAM File System that contains kernel modules for system devices such as hard disks. Following this, the Linux kernel loads the init daemon that starts all other processes on the system to bring it to a usable state.
+   - The traditional Linux boot manager is LILO. The two-stage GRUB boot loader is used by default in SUSE Linux and offers file system support and an interactive shell.
+   - To manage LILO, you can edit the `/etc/lilo.conf` file and run the `lilo` command. To manage GRUB, you can edit the `/boot/grub/menu.lst` file or use the Boot Loader Configuration module of YaST.
+   - A Linux system is categorized using runlevels. There are eight standard runlevels based on the number and type of daemons loaded in memory.
+   - The init program is responsible for loading and unloading daemons in a runlevel using its configuration file `/etc/inittab`.
+   - The `/etc/inittab` file runs scripts that start with S (start) or K (kill) in the `/etc/init.d/rc runlevel.d` directory when changing runlevels; these scripts are shortcuts to the scripts in the `/etc/init.d` directory used to start and stop daemons. You can edit these files to control the daemons that start in a particular runlevel. Alternatively, you can use the `insserv` command, the `chkconfig` command, or the YaST Runlevel Editor to edit the appropriate runlevel files.
+   - You can view your current runlevel using the `runlevel` or `who -r` commands. Alternatively, you can force the init program to change runlevels using the `init` command.
+   - Individual daemons can be started by running the appropriate script in the `/etc/init.d` directory with the `start` argument, or by using the `rc scriptname start` command. Alternatively, you can use the `stop` and `restart` arguments to stop and restart the appropriate daemon.
+   - The `halt`, `poweroff`, `reboot`, and `shutdown` commands can be used to safely change to runlevel 0 or 6.

# # Key Terms

+   - **`/boot/grub/menu.lst`** — The GRUB configuration file in SUSE Linux.
+   - **`/boot/vmlinuz`** — A shortcut to the Linux kernel.
+   - **`/etc/init.d`** — The directory that contains the scripts used to start and stop most daemons.
+   - **`/etc/init.d/boot`** — The script used to activate file systems and swap during system initialization.
+   - **`/etc/init.d/rc`** — The script used to start and stop daemons based on runlevel.
+   - **`/etc/init.d/rc?.runlevel.d`** — The directories used by the init daemon to start and kill daemons in each runlevel.
+   - **`/etc/init.d/skeleton`** — A sample script that can be copied to create scripts used to start a daemon.
