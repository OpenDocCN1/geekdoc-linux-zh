# # Work with vi (Command-line Editor)

The advantage of command-line editors is that you can use them without having a graphical desktop environment installed.

Although many factors can be involved when selecting an editor for everyday use, vi is used by most administrators because it is available on every Linux and UNIX system. It is always available, even on the rescue system. Because of this, you should learn to use vi.

In SUSE Linux Enterprise Desktop, vim (vi improved) by Bram Moolenaar is the standard vi editor. When you enter vi, vim is started via a link to it.

In this objective, you learn how to do the following:

+   1. Start vi
+   2. Use the Editor vi
+   3. Learn the Working Modes
