When you select Allowed Services, the dialog shown in Figure 5-11 appears.

![](bbox=[0.089, 0.118, 0.953, 0.594])

**Figure 5-11**

Here you select services that this computer offers to others via the network. On a desktop or laptop, these services are usually fairly limited—probably just DHCP client and SSH to allow remote administration.

If you need to open a port for a service not listed in the drop-down list, select Advanced and enter the applicable information regarding port and protocol in the dialog that appears.

The other items on the left usually do not need to be changed on a desktop system.
