## Exercise 2-3: Use the GNOME File Manager (Nautilus)

In this exercise, you explore your GNOME desktop. Perform the following tasks:

- Use Nautilus to copy the /etc/DIR_COLORS file into your home directory.
- Add the Oh no! emblem to the copied file.
- Rename the copied file to **example.txt**.
- Delete the **example.txt** file and empty the trash.

### Detailed Steps to Complete This Exercise

- Part I: Start Nautilus and Copy a File
- Part II: Add an Emblem to the Copied File Icon
- Part III: Rename the Copied File
- Part IV: Delete the Copied File and Empty the Trash

![](img/9129877170834ca9d5fdac5319bf5f12_82_0.png)

### Part I: Start Nautilus and Copy a File

To start Nautilus and copy a file, do the following:

1. Start the Nautilus file manager by selecting the user's Home icon on the desktop.
2. View the file system tree in the side panel by opening the menu at the top of the side panel (labeled Places when Nautilus is started the first time). Select Tree from the menu.
3. View the contents of the /etc directory by selecting the small triangle in front of the File System entry in the side panel. Then select etc in the side panel (a single mouse click).
4. Copy the /etc/DIR_COLORS file on the desktop by scrolling down and selecting the DIR_COLORS file icon, dragging it over the desktop while pressing the Ctrl key, and releasing the mouse button.

Notice the small plus at the mouse pointer while dragging the file. The plus indicates that you are copying a file.

5. Switch back to your home directory by selecting Home Folder in the side panel.
6. Move the DIR_COLORS file from the desktop into your home directory by selecting the DIR_COLORS file icon, dragging it over the right frame of the Nautilus window, and releasing the mouse button.

Notice there is no small plus at the mouse pointer while dragging the file, indicating that you are moving a file.

### Part II: Add an Emblem to the Copied File Icon

To add an emblem to the copied file icon, do the following:

1. Switch to the list of emblems by opening the menu at the top of the side panel (labeled Tree now). Select Emblems from the menu.
2. Scroll down in the side panel to the Oh no! icon.
3. Drag the Oh no! icon over the icon of the DIR_COLORS file in the right frame, and release the mouse button.

### Part III: Rename the Copied File

To rename the copied file, do the following:

1. Rename the copied file by right-clicking the DIR_COLORS file icon; then select Rename from the pop-up menu.
2. For the new filename, type `example.txt`; then press Enter.
