+   - **Is (list) command** — A command that is used to list the files in a given directory.
+   - **major device number** — A number used in a device file that determines the location of the device driver in the Linux kernel for a particular device.
+   - **minor device number** — A number used in a device file that determines the instance of the particular device.
+   - **mkdir (make directory) command** — A command that is used to create directories.
+   - **mknod command** — A command that is used to create special devices files.
+   - **mount command** — A command that is used to mount a device to a mount point directory.
+   - **mount point** — The directory to which a device is mounted.
+   - **mounting** — The process of associating a device (i.e., CD-ROM) to a directory (i.e., /media/cdrom). After a device has been mounted, it can be accessed by navigating to the appropriate directory.
+   - **mv (move) command** — A command that is used to move/rename files and directories.
+   - **named pipes** — Temporary connections that send information from one command or process in memory to another; they are also represented by files on the file system. Named pipes are also called FIFO (First In First Out) files.
+   - **normal files** — Commonly used files such as text files, graphic files, data files, and executable programs.
+   - **PATH** — A variable that stores a list of directories that will be searched in order when commands are executed without an absolute or relative pathname.
+   - **pwd (print working directory) command** — A command that is used to display the current directory in the directory tree.
+   - **relative path** — The name of a target directory relative to your current directory in the tree.
+   - **rm (remove) command** — A command that is used to remove files and directories.
+   - **rmdir (remove directory) command** — A command that is used to remove empty directories.
+   - **shared libraries** — Files that store common functions used by most programs on the system.
+   - **sockets** — Named pipes connecting processes on two different computers; they can also be represented by files on the file system.
+   - **symbolic link** — A pointer to another file on the same or another file system; commonly referred to as a shortcut or soft link.
+   - **tail command** — A Linux command used to display the last set number of lines of text in a file; by default, the tail command displays the last 10 lines of the file.
+   - **touch command** — A command that is used to create new files. It was originally used to update the time stamp on a file.
+   - **type command** — A command that is used to determine the type of program for a command.
+   - **umount command** — A command that is used to unmount a device from a mount point directory.
+   - **vmlinuz** — The file name of the Linux kernel.
+   - **whereis command** — A command that is used to display the location, manual pages, and source code for a command.
+   - **which command** — A command that is used to locate files that exist within directories listed in the PATH variable.
+   - **wildcards** — Characters that have special meaning on your system when typed at a command prompt. The ? and * characters are common wildcards used to match filenames.
