This exercise will not work with a USB keyboard because the USB drivers are usually loaded at a later stage of the init process. If your machine is equipped with a USB keyboard, you would have to add the modules to the initial RAM disk for this exercise to work.

To be able to do this exercise with a USB keyboard, take the following steps first:
Find out which USB modules are loaded by entering `lsmod` in a terminal window. Then start YaST, select **System > /etc/sysconfig Editor**. Expand the **System > Kernel** subsection. In **INITRD_MODULES**, add the modules used, such as `usbhid uhci_hcd ehci_hcd`. Close the dialogs.
In a terminal window (as root), enter `mkinitrd`.

# Detailed Steps to Complete This Exercise

+   1. From the GNOME desktop, select Computer > Shutdown > Restart.

+   2. When the boot menu is displayed, press the Spacebar to stop the timer.

+   3. In the Boot Options field, type `init=/bin/bash` then press Enter.

+   4. Using vi, edit `/boot/grub/menu.lst`.
+      Put a comment sign (#) in front of the line starting with gfxmenu. Add the following line beneath it:

```
password secret
```

+   5. (Optional) To avoid having the password in cleartext in the configuration file, you can use an MD5-Hash instead. You can create and include it in the file with the following command within vi:

Press Esc

```
:r! echo -e "secret\nsecret" | grub-md5-crypt
```

Press Enter

Some lines of output from grub-md5-crypt will be included in the file, including the MD5-hash of your password.

Delete the lines from the output of grub-md5-crypt, except the line with the hash. If you still have the “password secret” line in the file, delete it too.

At the beginning of the line with the hash, write `password --md5`, so that the line looks like the following:

```
password --md5 $1$t9kdK1$jjuACbOwF18QVFv3C17b.v0
```

![](bbox=[0.086, 0.756, 0.276, 0.828])

Your hash value will be different than that given here.

Save the file by pressing Esc and entering `:wq`.

+   6. Mount the root file system as read-only:

```
mount -o remount,ro /
```
