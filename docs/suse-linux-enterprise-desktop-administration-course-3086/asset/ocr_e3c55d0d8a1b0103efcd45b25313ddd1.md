If you want to start another desktop environment, do the following:

+   1. At the login manager, select Session. The dialog shown in Figure C-4 appears.
+   2. Select the desktop environment you want to log in to; then select OK.
+   3. The login manager wants to know whether the desktop environment you have chosen should be your default environment or if you want to start it just for this session. See Figure C-5.
+   4. Select one of these options.
+   5. Enter your username and password to log in.
