## Configure VPN Connections

In the past, dedicated phone lines to connect branch offices or dial-in connections for remote workers were widely used. Because they were, however, rather expensive, especially if used over a long distance, alternatives were needed.

These costs were remarkably reduced using the Internet. But with the use of the Internet, new problems arose, namely unauthorized access to the internal networks or unauthorized access to the data exchanged over the Internet.

To solve these problems, cryptography is used, both to ensure that only authorized users access the internal network and to protect the data traveling through the Internet from being viewed by unauthorized people.

### VPN and IPSec Basics
Technologies that use one network infrastructure, for example the Internet, to carry the packets of another network are usually classified under the heading VPN (Virtual Private Network). Figure 5-18 illustrates a VPN connection. By definition, a VPN does not necessarily have to encrypt the traffic, but encryption is used on most VPNs.

![](img/9129877170834ca9d5fdac5319bf5f12_163_0.png)

**Figure 5-18**

Various technologies are used to implement VPNs. These technologies include IPSec (Internet Protocol Security), OpenVPN, L2TP (Layer 2 Tunneling Protocol), HTTPS (HTTP protocol over Transport Layer Security/Secure Sockets Layer), and SSH (Secure Shell).

## Use VNC

VNC (Virtual Network Computing) is software originally developed by Olivetti & Oracle Research Laboratory under an Open Source license. The VNC server software component transmits the content of the screen to a remote computer running the VNC viewer software.

You can use VNC to allow someone else to view your desktop, or to allow another user to interact with the mouse and keyboard. An administrator could use VNC to help a user who is having difficulties. The administrator could watch the user and give tips, or actually show a user how to complete a certain task on his desktop.

The license of VNC made it possible to develop different implementations. The implementations used on SUSE Linux Enterprise Desktop 10 are TightVNC and vino.

To let someone else view your desktop, all you have to do is open a terminal window and enter **vino-preferences**. The dialog shown in Figure 5-24 appears.

![](img/9129877170834ca9d5fdac5319bf5f12_167_0.png)

**Figure 5-24**

By selecting the respective check boxes, you can decide to allow others to view or control your desktop. You can also specify whether or not a confirmation and password are required. To access the desktop remotely using VNC, open a terminal window and enter `vncviewer hostname:display`. To access the vncserver running on da10.digitalairlines.com on display 0, you would enter `vncviewer da10.digitalairlines.com:0`. Depending on the settings on the VNC server side, a password prompt may appear.

## Summary

- The Network Card module of YaST can be used to easily manage your network interface configuration. Each network interface must have a name (eth0), driver (kernel module), and IP configuration.
- Common IP configuration parameters include an IP address, subnet mask, hostname, name server (DNS), and WLAN settings for wireless network interfaces. These parameters can be configured manually or automatically by contacting a DHCP server.
- Network interface and IP information is stored in the `/etc/sysconfig/network` directory.
- Different IP networks are connected to one another via routers. A host has a routing table that typically contains a default gateway route that identifies the router on the local network that can relay messages to remote IP networks.
- After system initialization, you can use the `ip` command to view, configure, and manage your network interfaces, IP configuration, and routing table. Additionally, you can use the `ping` command to test IP connectivity, and the `traceroute` command to test IP routing.
- You can use the Firewall module of YaST to configure packet filtering on your network interfaces to prevent unauthorized access to your computer from across the network. Packet filter information is stored in the `/etc/sysconfig/SuSEfirewall2` file.
- NetworkManager can be used to keep track of several wired and wireless networks on portable or laptop computers. NetworkManager is started from within the Network Card module of YaST. You can also use the NetworkManager applet on your desktop to switch between networks or connect to a VPN using IPSec, OpenVPN, L2TP, HTTPS, or SSH.
- The SSH daemon (sshd) provides a secure alternative to telnet, rlogin, rsh, rcp, and FTP by encrypting traffic. SLES uses OpenSSH to provide SSH services.
- The `scp` and `sftp` commands can be used to copy files between remote hosts using SSH, whereas the `ssh` command can be used to obtain an SSH terminal from a remote host.
- SSH uses a combination of asymmetric and symmetric encryption and supports several standard encryption algorithms. SSH version 2 uses HMAC to ensure the integrity of transmitted data.
