+   - **/etc/inittab** — The configuration file for the init program.
+   - **/etc/lilo.conf** — The LILO configuration file.
+   - **/etc/sysconfig/kernel** — The configuration file for the Linux kernel used during system initialization.
+   - **/sbin/init** — The initialization program used to start system services at system initialization.
+   - **Basic Input Output System (BIOS)** — The program located in mainboard ROM that is used to perform the POST and locate a boot loader or boot manager.
+   - **boot loader** — The program used to load and start the operating system kernel at system startup.
+   - **Boot Loader Configuration** — A YaST module that can be used to configure the GRUB boot manager.
+   - **boot manager** — A program used to load and start one of several different operating systems at system startup.
+   - **chkconfig command** — A command that is used to set programs to start or stop in a particular runlevel by altering the appropriate files in the /etc/init.d/rc.runlevel.d directory.
+   - **Grand Unified Bootloader (GRUB)** — The default boot manager in SUSE Linux.
+   - **grub command** — A command that is used to start the GRUB interactive shell.
+   - **halt command** — A command that is used to quickly bring a system to runlevel 0.
+   - **init** — The first process started by the Linux kernel; it is responsible for starting and stopping system daemons.
+   - **init command** — A command that is used to change the system runlevel.
+   - **Initial RAM File System** — A cpio archive that contains device drivers that is loaded during system initialization into a RAM disk.
+   - **initramfs** — The Initial RAM File System.
+   - **initrd** — A RAM disk image used during system initialization in previous versions of SUSE Linux.
+   - **insserv command** — A command that is used to enable scripts used to start daemons.
+   - **kernel** — The core component of the Linux operating system.
+   - **lilo command** — A command that is used to reinstall the LILO boot manager after configuration changes.
+   - **Linux Loader (LILO)** — The traditional boot manager used on Linux systems.
+   - **map files** — Files used by a boot manager or boot loader to locate physical data on the hard disk.
+   - **Master Boot Record (MBR)** — The first area of a hard disk that stores the partition table and bootable partition.
+   - **mkinitrd command** — A command that is used to create an Initial RAM File System on a SUSE Linux system.
+   - **power-on self test (POST)** — A simple hardware test performed by the BIOS at system initialization.
+   - **poweroff command** — A command that is used to quickly bring a system to runlevel 0 and power off the system.
+   - **reboot command** — A command that is used to quickly bring a system to runlevel 6.
+   - **runlevel** — A category that describes the number and type of daemons on a Linux system.
+   - **runlevel command** — A command that is used to display the current and most recent runlevel.
