At the top of the left frame of the main menu three buttons allow you to access the following:

+   - *Applications*—A list of favorite and recently used applications.
+   - *Documents*—Documents that were accessed recently. A click on a document opens the document in the application used to edit or view it.
+   - *Places*—A list of shortcuts to directories. When you select a shortcut, the content of the directory is displayed in the file manager Nautilus.

In the Applications section, a button labeled More Applications is displayed. When you select this button, the Application Browser appears as shown in Figure 2-9.

The right frame of the application browser shows a list of the most important installed applications. The applications are grouped and you can see a list of the groups in the left frame. Select a group to highlight the applications that belong to this group.

The filter option adds even more flexibility. In the Filter text box in the left frame, enter a part of the name of the application you want to start. The filtered applications are shown immediately in the right frame.
