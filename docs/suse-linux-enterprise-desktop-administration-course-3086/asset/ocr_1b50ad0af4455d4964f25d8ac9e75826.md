+   3. Select Close.

# Part III: Configure the Novell Client

To configure the Novell Client, run the Novell Client Configuration Wizard. It lets you configure file browser, protocol, login, tray application, and OpenSLP settings.

+   1. From the system tray, select the Novell Client icon ( ); then select System Settings.
+   2. When prompted, type the root password of n0v311; then select OK.
+      A Novell Client Configuration Wizard dialog appears.
+   3. Select Start Wizard.
+      A Login Settings page appears.
+   4. Make sure that the following are selected:
+      - NMAS Authentication
+      - Advanced Button
+      - Integrated Login
+      - Display Integrated Login Results
+   5. In the Login Defaults section, enter the following:
+      - Default Tree: DA-TREE
+      - Default Context: users.digitalairlines
+   6. Select Next.
+   7. From the Map Settings page, accept the default settings; then select Next.
+   8. From the Protocol Settings page, accept the default settings; then select Next.
+   9. From the Tray Application Settings page, accept the default settings; then select Next.
+   10. From the File Browser Settings page, accept the default settings; then select Next.
+   11. From the Service Location Protocol (OpenSLP) Settings page, accept the default settings; then select Next.
