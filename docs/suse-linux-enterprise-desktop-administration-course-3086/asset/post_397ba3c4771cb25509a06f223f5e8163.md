
- Text files are the most common file type whose contents can be viewed by several utilities such as `cat`, `less`, `head`, and `tail`.
- There are many file management commands that exist to create, change the location of, or remove files and directories. The most common of these include `cp`, `mv`, `rm`, `rmdir`, and `mkdir`.
- Every file and directory has an inode that contains all file information other than the data and filename itself.
- Files can be a link to another file by name or by inode. These are called symbolic and hard links, respectively. You can create linked files using the `ln` command.
- You can find files on the file system using a variety of utilities, including the GNOME Search Tool, `find`, `whereis`, and `which`. The `type` command can be used to determine the type of an executable file.

## Key Terms
- **.. (double period)** — A command used to represent the user’s parent directory in the directory tree.
- **/** — The single root directory in Linux.
- **/bin directory** — A directory that contains binary commands for use by all users.
- **/boot directory** — A directory that contains the Linux kernel and files used by the boot loader.
- **/dataX directory** — A directory typically used to mount non-Linux partitions where X is the partition number.
- **/dev directory** — A directory that contains device files.
- **/dev/null** — A special null device file that can be used to delete data redirected from a program or file.
- **/etc directory** — A directory that contains system-specific configuration files.
- **/etc/mtab** — A file that contains a list of mounted file systems.
- **/home directory** — The default location for user home directories.
- **/lib directory** — A directory that contains shared program libraries (used by the commands in /bin and /sbin) as well as kernel modules.
- **/media directory** — A directory that is used for accessing (mounting) disks such as floppy disks and CD-ROMs.
- **/mnt directory** — A directory that is used for accessing (mounting) disks such as floppy disks and CD-ROMs.
- **/opt directory** — A directory that stores additional software program files.
- **/proc directory** — A directory that contains process and kernel information.
- **/root directory** — The root user’s home directory.
- **/sbin directory** — A directory that contains system binary commands used for administration.
- **/srv directory** — A directory that contains file content used by Linux network services.
- **/sys directory** — A directory that contains current system information.
- **/tmp directory** — A directory that holds temporary files created by programs.
- **/usr directory** — A directory that contains most system commands and utilities. It stands for UNIX Special Resources or UNIX System Resources.

- **/var directory** — A directory that contains log files and spools.
- **/windows directory** — A directory that contains subdirectories used to mount local Windows partitions.
- **~ (tilde)** — A character used to represent a user’s home directory.
- **absolute path** — The full name to a certain file or directory starting from the root directory.
- **ASCII files** — Files that contain text that adheres to the American Standard Code for Information Interchange.
- **bash (Bourne Again Shell) command** — The command interpreter on Linux systems that provides a command-line interface to the system.
- **block-oriented device file** — A device file which specifies that information be transferred to the device in a block-by-block manner to a formatted file system.
- **cat command** — A command that is used to display (or concatenate) the entire contents of a text file to the screen.
- **cd (change directory) command** — A command that is used to change the current directory in the directory tree.
- **character-oriented device file** — A device file which specifies that information be transferred to the device in a character-by-character manner.
- **cp (copy) command** — A command that is used to create copies of files and directories.
- **device file** — A file used to identify hardware devices such as hard disks and serial ports.
- **directories** — Special files that are used to organize other files on the file system.
- **FIFOs** — See named pipes.
- **File System Hierarchy Standard (FHS)** — A standard outlining the location of set files and directories on a Linux system.
- **find command** — A command that is used to find files on the file system using various criteria.
- **GNOME Search Tool** — A graphical utility that can be used to find files and directories on the file system.
- **GRUB (Grand Unified Bootloader)** — The program that loads the Linux kernel at system initialization.
- **hard link** — A file that points to another file’s inode.
- **head command** — A command that is used to display the first set of lines of a text file; by default, the head command displays the first 10 lines.
- **hidden files** — Files that are not normally displayed to the user via common file system commands; hidden files are filenames that start with a period.
- **home directory** — A directory on the file system set aside for users to store personal files and information.
- **init process** — The first process loaded in Linux. It always has the process number of 1.
- **inode** — The portion of a file that stores information on the file’s attributes, access permissions, location, ownership, and file type.
- **less command** — A command that is used to display a text file page-by-page on the terminal screen; users can then use the cursor keys to navigate the file.
- **links** — Files that point to other files on the file system.
- **ln (link) command** — A command that is used to create hard and symbolic links.
- **ls (list) command** — A command that is used to list the files in a given directory.
- **major device number** — A number used in a device file that determines the location of the device driver in the Linux kernel for a particular device.
- **minor device number** — A number used in a device file that determines the instance of the particular device.
- **mkdir (make directory) command** — A command that is used to create directories.
- **mknod command** — A command that is used to create special devices files.
- **mount command** — A command that is used to mount a device to a mount point directory.
- **mount point** — The directory to which a device is mounted.
- **mounting** — The process of associating a device (i.e., CD-ROM) to a directory (i.e., /media/cdrom). After a device has been mounted, it can be accessed by navigating to the appropriate directory.
- **mv (move) command** — A command that is used to move/rename files and directories.
- **named pipes** — Temporary connections that send information from one command or process in memory to another; they are also represented by files on the file system. Named pipes are also called FIFO (First In First Out) files.
- **normal files** — Commonly used files such as text files, graphic files, data files, and executable programs.
- **PATH** — A variable that stores a list of directories that will be searched in order when commands are executed without an absolute or relative pathname.
- **pwd (print working directory) command** — A command that is used to display the current directory in the directory tree.
- **relative path** — The name of a target directory relative to your current directory in the tree.
- **rm (remove) command** — A command that is used to remove files and directories.
- **rmdir (remove directory) command** — A command that is used to remove empty directories.
- **shared libraries** — Files that store common functions used by most programs on the system.
- **sockets** — Named pipes connecting processes on two different computers; they can also be represented by files on the file system.
- **symbolic link** — A pointer to another file on the same or another file system; commonly referred to as a shortcut or soft link.
- **tail command** — A Linux command used to display the last set number of lines of text in a file; by default, the tail command displays the last 10 lines of the file.
- **touch command** — A command that is used to create new files. It was originally used to update the time stamp on a file.
- **type command** — A command that is used to determine the type of program for a command.
- **umount command** — A command that is used to unmount a device from a mount point directory.
- **vmlinuz** — The file name of the Linux kernel.
- **whereis command** — A command that is used to display the location, manual pages, and source code for a command.
- **which command** — A command that is used to locate files that exist within directories listed in the PATH variable.
- **wildcards** — Characters that have special meaning on your system when typed at a command prompt. The ? and * characters are common wildcards used to match filenames.
