# Part B: Change Your eDirectory Password

To change your eDirectory password, do the following:

+   1. Select the Novell Client icon; then select Change Password.
+   2. In the Old password field, type novell.
+   3. In the New password field, type 11evon.
+   4. In the Confirm field, type 11evon again.
+   5. Save the changes and exit by selecting OK.
