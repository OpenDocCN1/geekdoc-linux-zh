# Objective 3—Understand the Role of SuSEconfig

You can consider YaST as a front end to various other programs, such as RPM (RPM Package Manager) software management, user management, or various configuration files of different services (like a mail or web server).

Most of the time, YaST writes the configuration changes directly into the final configuration file. In other cases, the information you enter is first written to a file in the directory /etc/sysconfig/ before it is written into the final configuration file.

This intermediate step is where the program SuSEConfig becomes important.

SuSEConfig is a tool used in SUSE Linux Enterprise Desktop to configure the system according to the variables that are set in the various files in /etc/sysconfig/ and its subdirectories.
