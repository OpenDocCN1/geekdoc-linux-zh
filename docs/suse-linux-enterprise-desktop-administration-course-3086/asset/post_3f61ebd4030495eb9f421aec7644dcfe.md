## Overview of Important Commands

In this part, important commands are listed. Detailed information on individual commands can be obtained by entering

```
man command
```

The commands are sorted according to the following tasks:

- Work with Files and Directories
- Look for Files and for Content of Files
- Display and Modify the Content of Files
- Restore Data, Compress, and Archive Files
- Administer Users and Groups
- Administer Permissions
- Administer the System
- Administer Processes, Start and Stop the System
- Monitor the System
- Install Software
- Manage Hard Disks and File Systems
- Automate Tasks
- Repair the System
- Use Online Help
- Work with Kernel and Modules
- Printing (CUPS)
- Administer the X Window System
- Work with MS-DOS Floppy Disks
- Use the Network
- Use vi

## Work with Files and Directories

- cd—Changes to another directory
- cp—Copies files
- ln—Creates links
- ls—Lists the contents of a directory
- mkdir—Creates one or more directories
- mkfifo—Generates a FIFO file
- mknod—Sets up a new device file in the directory /dev
- mv—Moves a file to a different directory or renames a file
- rm—Deletes one or more files
- rmdir—Deletes one or more empty directories
- split—Splits a file into several smaller files
- tee—Branches the output to stdout and at the same time to one or more files
- touch—Changes the time stamp of a file or creates a new file with a size of 0 bytes

## Look for Files and for Content of Files

- file—Determines the file type, such as text file or HTML document
- find—Searches for files
- grep—Searches through one or more files for a string and displays the matching lines
- locate—Searches a previously created database for files
- updatedb—Updates the /var/lib/locatedb database of locate
- whereis—Locates the binary, source, and manual page files for a command
- which—Shows the full path of (shell) commands

## Display and Modify the Content of Files

- cat—Displays the contents of a file on the standard output
- cut—Cuts specific fields from all lines of a file and displays the selected areas
- echo—Outputs the given string to the standard output
- expand—Converts tabs to spaces
- fmt—Is a simple text formatter, which formats the content of a text file or of the standard input paragraph by paragraph
- head—Displays the beginning of a file to stdout (by default, 10 lines)
- less—Displays files page by page to stdout, and can also display the contents of compressed files
- more—Displays files page by page to stdout. Does not have as many functions as less
- sort—Sorts lines of a text file alphabetically according to fields. Sorted files can also be joined into one single file
- strings—Displays the strings of printable characters in files. This command is mainly useful for determining the contents of binary files
- tac—Displays a file, starting with the last field (the reverse of cat)
- tail—Displays the end of a file to stdout (by default, 10 lines)
- tr—Replaces or deletes characters from the standard input and writes to the standard output
- unexpand—Converts spaces to tabs
- uniq—Removes duplicate lines from a sorted file
- wc—Shows the number of characters, words, and lines

## Restore Data, Compress, and Archive Files

- ar—Creates, modifies, and extracts from archives
- bunzip2—Decompresses files compressed with bzip2
- bzip2—Compresses and decompresses files
- cpio—Copies files to and from archives (cpio or tar archives)
- dd—Transmits data blocks between different storage media (floppy disk, hard drive, etc.)
- dump—Creates an ext2 and ext3 file system backup
- gunzip—Decompresses files compressed with gzip
- gzip—Compresses or decompresses files
- mt—Used to work with magnetic tapes
- restore—Restores files or file systems from backups made with dump
- rsync—Creates copies of entire directories on a different host or mirrors directories locally
- sync—Writes any data buffered in memory out to disk
- tar—Generates or unpacks an archive consisting of a number of files and directories
- zcat—Displays the decompressed content of a file compressed with gzip on the standard output
- zip—Packages and compresses (archive) files

## Administer Users and Groups

- chage—Lists and changes the password expiry information of a user
- chfn—Changes the user's information in the GECOS field in the /etc/passwd file
- chsh—Changes the login shell of the user
- faillog—Displays the formatted /var/log/faillog file
- finger—Displays information about local and remote system users
- gpasswd—Deletes the group password (option -r)
- groupadd—Creates a new group
- groupmod—Modifies a group
- groups—Provides a user with information on his group memberships
- id—Provides a user with information on his UID and his group membership
- last—Displays the content of the /var/log/wtmp file (a list of users who last logged in)
- lastlog—Displays the content of the /var/log/lastlog file
- newgrp—Changes the effective group GID of the user
- passwd—Allocates the user a password or changes it
- pwck—Checks the integrity of data in the /etc/passwd and etc/shadow files
- sg—Changes the effective group GID of the user
- su—Allows you to change to the UID of another user
- sudo—Allows a normal user to carry out root commands
- useradd—Creates a new user
- userdel—Deletes a user
- usermod—Changes the user account
- visudo—Used to modify the /etc/sudoers file
- w—Displays information on the users currently on the machine and their processes
- who—Shows who is currently logged in to the system and information such as the time of the last login
- whoami—Shows as which user you are currently logged in on the system

## Administer Permissions

- chattr—Sets and removes file attributes of an ext2 file system; changes the version number of a file
- chgrp—Changes the group membership of files
- chmod—Changes the access permissions of files
- chown—Changes the owner of files
- lsattr—Displays the file attributes of the ext2 file system and the version number of the files
- umask—Puts limitations on access modes for newly created files and directories

## Administer the System

- alias—Defines a new alias name
- clear—Deletes the contents of the screen or text console
- date—Prints or sets the system date and time
- ethtool—Displays or changes Ethernet card settings
- export—Converts a shell variable to an environment variable. Thus, it is also available in subshells
- fdformat—Carries out a low-level formatting of a floppy disk, on which a file system can then be installed (using mformat or mkfs)
- grub—Starts the GRUB shell while the system is running; reinstalls the boot manager GRUB
- grub-install—Installs the boot manager GRUB
- history—Lists the last commands carried out
- ip—Displays and changes the network interface configuration
- iptables—Sets up, maintains, and inspects the tables of IP packet filter rules in the Linux kernel 2.4.0 or newer
- lilo—Reads changes made in the LILO configuration /etc/lilo.conf file
- pwd—Specifies the path of the current directory
- set—Displays all variables known to the shell
- SuSEconfig—Transfers changes in files in the /etc/sysconfig/ directory to the individual program-specific configuration files
- swapoff—Disables devices and files for paging and swapping
- swapon—Enables devices and files for paging and swapping
- tune2fs—Adjusts tunable file system parameters on an ext2 file system
