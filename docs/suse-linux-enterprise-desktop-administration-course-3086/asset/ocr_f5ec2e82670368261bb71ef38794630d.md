**GNOME Control Center** A graphical utility that can be used to configure the behavior of the GNOME desktop environment.

**GNOME Display Manager (GDM)** The login screen used by the GNOME desktop environment.

**GNOME Printers dialog** A dialog that is used to manage printers and print jobs within a SUSE Linux GNOME desktop environment.

**GNOME Search Tool** A graphical utility that can be used to find files and directories on the file system.

**GNOME System Monitor** A graphical utility that can display and modify system processes as well as display free space by file system.

**GNOME Terminal** A virtual terminal that can be started from within the GNOME desktop environment.

**GNOME Volume Manager** A software system that mounts and manages access to removable media devices, such as CD-ROMs, DVDs, and USB devices.

**GNOME window manager** See Metacity.

**gnome-cups-manager command** A command that is used to invoke the expanded GNOME Printers dialog utility.

**gnome-keyring-manager command** A command that is used to manage keyrings in SUSE Linux.

**gnomesu (GNOME switch user) command** A command that is used to run a program as another user within a GNOME desktop environment.

**gnome-volume-manager command** A command that is used to invoke the GNOME Volume Manager.

**gnome-Xgl-settings command** A command that is used to start the Desktop Effects tool within a GNOME desktop environment.

**gpasswd command** A command that is used to set passwords for group accounts.

**Grand Unified Bootloader (GRUB)** The default boot manager in SUSE Linux.

**graphical user interface (GUI)** A graphical interface that allows users to manipulate icons to control the operating system and run application programs.

**group** When referring to a long file or directory listing, it represents the group ownership of a file or directory.

**groupadd command** A command that is used to add a group to the system.

**groupdel command** A command that is used to delete a group from the system.

**groupmod command** A command that is used to modify the name, membership, or GID of a group on the system.

**groups command** A command that displays the groups that a user is a member of.

**GRUB (Grand Unified Bootloader)** The program that loads the Linux kernel at system initialization.

**grub command** A command that is used to start the GRUB interactive shell.

**halt command** A command that is used to quickly bring a system to runlevel 0.

**hard link** A file that points to another file's inode.

**Hash Message Authentication Code (HMAC)** A feature of SSH version 2 that prevents attackers from compromising SSH data during transit.

**hdparm command** A command that displays and modifies hard disk parameters on a Linux system.

**head command** A command that is used to display the first set of lines of a text file; by default, the head command displays the first 10 lines.

**hidden files** Files that are not normally displayed to the user via common file system commands; hidden files have filenames that start with a period.

**history command** A command used to view and recall previously executed commands.

**home directory** A directory on the file system set aside for users to store personal files and information.

**hostname** A name used to identify hosts on a TCP/IP network.

**HOWTO files** A document that contains the steps for common Linux procedures.

**hwclock command** A command used to modify the BIOS time on a system.

**hwinfo command** A command that displays device information for a Linux system.

**Hypertext Transfer Protocol (HTTP)** The protocol used to transfer Web pages on the Internet.

**HyperText Transfer Protocol Secure (HTTPS)** A common technology used to encrypt World Wide Web traffic. It can also be used to create VPNs.

**id command** A command that displays the UID and GIDs associated with a user account.

**iFolder** See Novell iFolder.

**iFolder Client** The software component installed on iFolder clients that can be used to connect to and manage shared files.

**ifup command** A command used to activate a network card in SUSE Linux.
