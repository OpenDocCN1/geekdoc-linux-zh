# Add and Remove Printers with the GNOME Printers Dialog

The GNOME Printers dialog can be used to add printers or to manage existing queues. To access the dialog, select Computer > Control Center > Printers. See Figure 12-18.

![](bbox=[0.124, 0.16, 0.531, 0.361])

Figure 12-18

To add a printer, select New Printer. After entering the root password, the dialog shown in Figure 12-19 appears.

![](bbox=[0.122, 0.465, 0.731, 0.865])

Figure 12-19

In this case, a printer was detected. After selecting Forward, another dialog, shown in Figure 12-20, appears. Select the manufacturer and the model of the printer.
