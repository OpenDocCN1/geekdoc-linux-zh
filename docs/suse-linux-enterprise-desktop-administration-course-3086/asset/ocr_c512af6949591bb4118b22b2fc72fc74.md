# ### Use OpenSSH

In the past, remote connections were established with Telnet, which offers no guards in the form of encryption or other security mechanisms against eavesdropping. Other traditional communication channels (such as FTP and some remote copying programs) provide unencrypted transmission.

The SSH suite was developed to provide secure transmission by encrypting the authentication strings (usually a login name and a password) and all the other data exchanged between the hosts.

With SSH, the data flow can still be recorded by a third party, but the contents are encrypted and cannot be reverted to plain text unless the encryption key is known. SUSE Linux Enterprise Desktop 10 installs the package OpenSSH by default. OpenSSH includes programs such as ssh, scp, and sftp as alternatives to Telnet, rlogin, rsh, rcp, and FTP.
