# Detailed Steps to Complete This Exercise

On your machine, do the following:

+   1. Open a terminal window.
+   2. Enter `vino-preferences`.

+   3. Select **Allow Other Users to View Your Desktop**.
+   4. Make sure that **Ask You for Confirmation** is selected.
+      In this dialog, you can also see the command your partner has to use to view your desktop remotely.
+   5. Select **Close**.

vncviewer your_hostname:display
