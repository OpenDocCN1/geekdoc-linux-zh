# Detailed Steps to Complete This Exercise

+   1. On the GNOME desktop, press Alt+F2 and enter `gnome-terminal` in the Run Application dialog.
+   2. Create a new, empty file by entering
+      ```
+      touch new_file
+      ```
+   3. Open another terminal window, and log in as root (`su -`) with a password of `n0v3ll`.
+   4. Display the content of the /var/log/messages file by entering
+      ```
+      cat /var/log/messages
+      ```
+   5. Display the content of /var/log/messages page by page by entering
+      ```
+      less /var/log/messages
+      ```
+   6. Find the first occurrence of the word root by entering
+      ```
+      /root
+      ```
+   7. Find the next occurrence of the word root by typing n.
+   8. Navigate through the output by using Down-arrow, Up-arrow, Right-arrow, and Left-arrow, and PageUp and PageDown.
+   9. Quit the display and return to the command line by typing q.
+   10. Display the first five lines of the /var/log/messages file by entering
+       ```
+       head -n 5 /var/log/messages
+       ```
+   11. View a continuously updated display of the last lines of the file /var/log/messages by entering
+       ```
+       tail -f /var/log/messages
+       ```
+   12. Arrange the terminal windows on the desktop so that you can see the content of both.
+   13. In the first terminal window, log in as root (`su -`); then enter an invalid password (such as `suse`).
+   
+       Notice that this login attempt is logged in the second terminal window.
+   14. In the first terminal window, log in as root (`su -`) with a password of `n0v3ll`.
+   
+       The login is logged in the second terminal window.
+   15. Log out as root in the first terminal window by entering
+       ```
+       exit
+       ```
+   16. Close the first terminal window by entering
+       ```
+       exit
+       ```
+   17. Stop the tail process in the second terminal window by pressing
+       ```
+       Ctrl+c
+       ```
