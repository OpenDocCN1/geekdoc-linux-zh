# Application Layer

The Application layer combines all the higher-level protocols of the TCP/IP model (protocols based on the TCP/IP protocols), as shown in Figure B-21.

![](bbox=[0.1, 0.15, 0.8, 0.57])

Figure B-21

Experience has shown that it was a wise decision to combine the three application-related layers from the OSI model into one because Layers 5 and 6 from that model are seldom used. Protocols used in the Application layer include the following:

+   - FTP (File Transfer Protocol)
+   - SMTP (Simple Mail Transfer Protocol)
+   - DNS (Domain Name System)
+   - HTTP (Hypertext Transfer Protocol)
+   - SMB (Server Message Block)
