CUPS supports the IPP, LPD, SMB, IPX, and socket protocols. These protocols are described below:

+   - *IPP (Internet Printing Protocol)*—IPP is a relatively new protocol (since 1999) that is based on the HTTP protocol. Compared with other protocols, IPP can transmit much more job-related data.

CUPS uses IPP for the internal data transmission. This is the preferred protocol for a forwarding queue between CUPS servers.

The port number for IPP is 631.
