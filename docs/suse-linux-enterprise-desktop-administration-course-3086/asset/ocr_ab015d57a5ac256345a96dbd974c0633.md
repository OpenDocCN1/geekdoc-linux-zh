# ### YaST Expert Partitioner

When you start the YaST Expert Partitioner, the screen shown in Figure 1-8 appears.

In the top part of the dialog, YaST lists details of the current partition setup. Depending on your previous choice, the list contains the partitioning proposal created by YaST or the current physical disk setup.

The buttons in the lower part of the dialog are used to create, edit, delete, and resize partitions, as well as to administer LVM (Logical Volume Manager) or RAID (Redundant Array of Independent Disks).
