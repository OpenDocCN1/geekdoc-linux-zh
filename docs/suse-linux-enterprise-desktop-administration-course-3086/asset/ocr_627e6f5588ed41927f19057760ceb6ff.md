# Install KDE After Installation

To install KDE after the installation of SUSE Linux Enterprise Desktop 10, do the following:

+   1. In the YaST Control Center, select Software Management.
+   2. Select the filter Patterns. The dialog shown in Figure C-1 appears.
+   3. Under Desktops, select KDE to install KDE.
