# Glossary

& A special character used to start a program in the background.
"..." (double quotes) Characters used to protect all enclosed text except $, \, and ` characters from shell interpretation.
'...' (single quotes) Characters used to protect all enclosed text from shell interpretation.
~ (tilde) A character used to represent a user's home directory.
.alias A bash shell configuration file that is used to store aliases.
.bash_history A bash shell configuration file that is used to store previously executed commands.
.bashrc A bash shell configuration file that is read at login and when nonlogin shells are started.
~/.gconf The directory that stores personalized GConf configuration.
~/.mozilla/firefox The directory used to store user-specific configuration information for use with the Firefox Web browser.
~/.ooo-2.0 The directory used to store user-specific configuration information for use with OpenOffice.org in SUSE Linux.
~/.profile A bash shell configuration file that is read if ~/.bash_profile and ~/.bash_login do not exist.
~/.rpmrc A file that contains configuration information that is written to the /usr/lib/rpm/rpmrc file.
~/.ssh/authorized_keys A file used to store keys that can be used for SSH authentication.
~/.ssh/config The ssh client program configuration file.
~/.ssh/id_dsa A file used to store a DSA private key for use with SSH2.
~/.ssh/identity A file used to store a private key for use with SSH1.
~/.ssh/identity.pub A file used to store a public key for use with SSH1.
~/.ssh/id_rsa A file used to store an RSA private key for use with SSH2.
~/.ssh/id_dsa.pub A file used to store a DSA public key for use with SSH2.
~/.ssh/id_rsa.pub A file used to store an RSA public key for use with SSH2.
~/.ssh/known_hosts A file used to store the encryption keys of known SSH hosts.

~/.vimrc A file used to set vim configuration options for a user.
.command A command used to execute a file in the current shell environment.
.. (double period) A command used to represent the user's parent directory in the directory tree.
\ A special character used to protect the following character from shell interpretation.
/ The single root directory in Linux.
/bin directory A directory that contains binary commands for use by all users.
/bin/bash The executable file for the Bourne Again shell.
/bin/csh The executable file for the C shell.
/bin/ip The executable file for the ip command. See ip command.
/bin/ksh The executable file for the Korn shell.
/bin/sh The executable file for the Bourne shell.
/bin/tcsh The executable file for the TC shell.
/boot directory A directory that contains the Linux kernel and files used by the boot loader.
/boot/grub/menu.lst The GRUB configuration file in SUSE Linux.
/boot/vmlinuz A shortcut to the Linux kernel.
/dataX directory A directory typically used to mount non-Linux partitions where X is the partition number.
/dev directory A directory that contains device files.
/dev/null A special null device file that can be used to delete data redirected from a program or file.
/etc directory A directory that contains system-specific configuration files.
/etc/at.allow A file that lists users who can use the at command.
/etc/at.deny A file that lists users who cannot use the at command.
/etc/auto.master The Automounter configuration file.
/etc/bash.bashrc A bash shell configuration file typically used to set the command prompt and create aliases for all users on the system.
/etc/bash.bashrc.local A file that contains commands that are executed for all users on the system. It is executed by the /etc/bash.bashrc file.
