
**iManager** An iPrint utility that can be used to configure and manage the iPrint system.
**info command** A command used to search the info pages.
**info pages** A database that contains information about the syntax and usage of commands and files organized in a document-like format with links to other information.
**init** The first daemon started by the Linux kernel; it is responsible for starting and stopping other daemons.
**init command** A command that is used to change the system runlevel.
**init process** The first process loaded in Linux. It always has the process number of 1.
**Initial RAM File System** A cpio archive that contains device drivers that is loaded during system initialization into a RAM disk.
**initramfs** The Initial RAM File System.
**initrd** A RAM disk image used during system initialization in previous versions of SUSE Linux.
**inode** The portion of a file that stores information on the file's attributes, access permissions, location, ownership, and file type.
**insert mode** A mode in the vi editor that allows you to insert text into the document.
**insserv command** A command that is used to enable scripts used to start daemons.
**installation repository** See repository.
**installation server** A server that makes Linux installation files available across a network.
**InstallationServer** A YaST module in SUSE Linux Enterprise Server 10 that can be used to set up an installation server.
**Installation Source** A YaST module that allows you to specify the source of software packages available for installation.
**Integrated Drive Electronics (IDE)** A low-cost hard disk technology that is commonly used in workstation computers.
**Integrated Services Digital Network (ISDN)** An Internet connection technology that uses telephone lines to achieve faster transfer rates than traditional modems.
**International Data Encryption Algorithm (IDEA)** A common symmetric encryption algorithm that uses up to 128-bit keys.
**Internet Control Message Protocol (ICMP)** A part of the TCP/IP protocol suite that is used to relay information about network communications.

**Internet Printing Protocol (IPP)** A printing protocol that allows print jobs to be sent across the Internet using a Web browser. IPP is the default printing protocol used by CUPS.
**Internet Protocol (IP)** The protocol used to communicate with other computers on the Internet and most other networks.
**Internet Protocol (IP) address** A unique address used to identify a computer on a TCP/IP network.
**Internetwork Packet Exchange (IPX)** A protocol used for file and printer sharing on Novell NetWare networks.
**interval-controlled daemon** A daemon that is started at a certain time on a regular basis.
**ip command** A command used to view, configure, and manage network interfaces and the routing table.
**IP forwarding** See routing.
**IP Security (IPSec)** A common technology used to encrypt communication on IP networks. It can also be used to create VPNs.
**iPrint** A system that can be used to manage printing across an entire organization.
**iPrint client** A software component that allows a client computer the ability to access iPrint.
**iptables command** A command used to configure packet filtering using the netfilter framework in SUSE Linux.
**IPv6** The new TCP/IP protocol version that uses 128 bits to identify hosts on a network.
**job identifier (job ID)** The ID given to a background process that can be used in commands that manipulate the process during execution.
**jobs command** A command that is used to view background processes in your terminal.
**K Display Manager (KDM)** The login screen used by the KDE desktop environment.
**KDE** A common Linux desktop environment that uses the KDE window manager. KDE stands for K Desktop Environment.
**Kerberos** A secure authentication protocol used by UNIX, Linux, and Windows directory services. Kerberos uses tickets to identify authenticated computers and services.
**kernel** The core component of the Linux operating system.
**Key Distribution Center (KDC)** The computer that is used to issue Kerberos tickets.
**keyring** A file used to store passwords for future use with wireless networks and VPNs.
**Keys** Configuration parameters that contain values used by GConf.

**kill command** A command that is used to send a signal to a process by PID or job ID.

**killall command** A command that is used to send a signal to a process by name.

**KNetworkManager** The graphical program that displays NetworkManager within the KDE desktop environment.

**Konqueror** The graphical file management utility used in the KDE desktop.

**kwin** The default window manager in the KDE desktop environment.

**last command** A command that displays the most recent logins on a Linux system from entries in the /var/log/wtmp file.

**lastlog command** A command that displays the most recent logins on a Linux system from entries in the /var/log/lastlog file.

**Layer 2 Tunneling Protocol (L2TP)** A common technology used to create VPNs on Linux systems.

**leaf object** An LDAP object that represents a network resource.

**less command** A command that is used to display a text file page-by-page on the terminal screen; users can then use the cursor keys to navigate the file.

**Lightweight Directory Access Protocol (LDAP)** A protocol used to provide central authentication and distribute information to network computers.

**Lightweight Directory Interchange Format (LDIF)** The format by files that are used to create, modify, and query objects in an LDAP database.

**lilo command** A command that is used to reinstall the LILO boot manager after configuration changes.

**Line Printer Daemon (LPD)** A common printing protocol used on older Linux and UNIX computers.

**links** Files that point to other files on the file system.

**Linux Loader (LILO)** The traditional boot manager used on Linux systems.

**Linux User Management (LUM)** A management suite designed to manage local and directory-based user accounts on SUSE Linux computers.

**listener** A process that listens for network traffic on a port and forwards that traffic to a daemon.

**ln (link) command** A command that is used to create hard and symbolic links.

**locale command** A command used to list localization variables.

**logical partition** A partition that exists within an extended partition.

**Logical Volume Manager (LVM)** A hard disk partitioning scheme in which partitions are managed by system services and can be resized easily.

**login shell** A shell that is started immediately following login.

**logrotate command** A command that is used to rotate log files according to the rules in /etc/logrotate.conf.

**Long-life Host Key Pair (HK)** An asymmetric encryption key pair that is generated when the SSH daemon is started. This key pair is typically stored in a file for future use.

**lppasswd** A command that is used to manage users, passwords, and groups for use with the CUPS printing system.

**lpq command** A command that is used to view print jobs in the print queue.

**lpr command** A command that is used to create a print job.

**lprm command** A command that is used to remove a print job from the print queue.

**ls (list) command** A command that is used to list the files in a given directory.

**lsmod command** A command that lists currently loaded kernel modules.

**lspci command** A command that displays information about PCI devices on a Linux system.

**major device number** A number used in a device file that determines the location of the device driver in the Linux kernel for a particular device.

**man command** A command that is used to search the manual pages.

**manual pages** A database that contains information about the syntax and usage of commands and files.

**map files** Files used by a boot manager or boot loader to locate physical data on the hard disk.

**Master Boot Record (MBR)** The first area of a hard disk that stores the partition table and bootable partition.

**Message Digest 5 (MD5)** A common algorithm used to create a hash or checksum of data.

**Metacity** The default window manager used by the GNOME desktop environment in SUSE Linux.

**minor device number** A number used in a device file that determines the instance of the particular device.

**mkdir (make directory) command** A command that is used to create directories.

**mkfs command** A command that is used to create file systems on Linux partitions.
