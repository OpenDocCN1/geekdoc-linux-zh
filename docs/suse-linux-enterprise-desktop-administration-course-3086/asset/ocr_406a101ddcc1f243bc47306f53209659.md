# Configuration Files (`/etc`)

The /etc directory and its subdirectories contain system configuration files. Almost all these files are ASCII files that can be processed with any editor.

Normal users can read nearly all of these files, but they cannot edit any of them. According to the FHS, no executable programs can be located here.
