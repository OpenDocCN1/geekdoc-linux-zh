# User Administration

With the Users button selected, the User and Group Administration window lists the existing user accounts. See Figure 9-2.

![](bbox=[0.035, 0.136, 0.951, 0.654])

**Figure 9-2**

A list of users (accounts on your server) appears. The list includes information such as login name, full name, UID, and groups the users are associated with. Select Set Filter; then select one of the following to change the users listed:

+   - *Local Users*—User accounts you have created on your local server for logging in to the server.
+   - *System Users*—User accounts created by the system for use with services and applications.
