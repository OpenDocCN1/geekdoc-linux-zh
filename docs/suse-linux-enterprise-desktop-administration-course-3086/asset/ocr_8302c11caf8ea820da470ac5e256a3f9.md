# **Print Directly to a Network Printer**

You should select Print Directly to a Network Printer for printers equipped with a network card. For such a printer, select Direct TCP Port Printing in the dialog shown in Figure 12-14.

![](bbox=[0.061, 0.153, 0.981, 0.673])

Figure 12-14

The Remote LPD Queue option opens dialogs to enter the hostname of the print server and the queue name, and to select the printer model. Finally, the configuration of the remote LPD queue is displayed, as shown in the Figure 12-14. **Remote IPP Queue** could be used for possible future CUPS queues that are not configurable via YaST.
