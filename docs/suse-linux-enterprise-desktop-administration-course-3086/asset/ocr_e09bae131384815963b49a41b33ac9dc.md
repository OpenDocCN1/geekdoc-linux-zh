# GNOME System Monitor

From the GNOME desktop, you can start the GNOME System Monitor utility (Computer > More Applications > GNOME System Monitor) to view and kill processes. See Figure 10-5.

![](bbox=[0.116, 0.146, 0.936, 0.705])

Figure 10-5

If you encounter a misbehaving or hung process, you can kill it with GNOME System Monitor by selecting the process from the Process table and selecting End Process.
