
- **dmesg command** — A command that displays hardware-related boot messages from the Linux kernel.
- **du command** — A command that displays disk usage by directory.
- **facilities** — Areas of the system that the Syslog daemon monitors.
- **fdisk command** — A command that displays and modifies hard disk partitions on a Linux system.
- **fg command** — A command that is used to force a background process to run in the foreground.
- **filters** — Expressions used by the Syslog daemon to determine whether an event should be logged or not.
- **finger command** — A command that displays login and account information regarding local and remote users.
- **foreground process** — A process that runs in your terminal and must finish execution before you receive your shell prompt.
- **GNOME System Monitor** — A graphical utility that can display and modify system processes as well as display free space by file system.
- **hdparm command** — A command that displays and modifies hard disk parameters on a Linux system.
- **hwinfo command** — A command that displays device information for a Linux system.
- **init** — The first daemon started by the Linux kernel; it is responsible for starting and stopping other daemons.
- **interval-controlled daemon** — A daemon that is started at a certain time on a regular basis.
- **jobidentifier (job ID)** — The ID given to a background process that can be used in commands that manipulate the process during execution.
- **jobs command** — A command that is used to view background processes in your terminal.
- **kill command** — A command that is used to send a signal to a process by PID or job ID.
- **killall command** — A command that is used to send a signal to a process by name.
- **last command** — A command that displays the most recent logins on a Linux system from entries in the `/var/log/wtmp` file.
- **lastlog command** — A command that displays the most recent logins on a Linux system from entries in the `/var/log/lastlog` file.
- **listener** — A process that listens for network traffic on a port and forwards that traffic to a daemon.
- **logrotate command** — A command that is used to rotate log files according to the rules in `/etc/logrotate.conf`.
- **lspci command** — A command that displays information about PCI devices on a Linux system.
- **netstat command** — A command that displays network configuration and statistics.
- **nice command** — A command that is used to change the priority of a process as it is started.
- **nice value** — A value that represents the priority of a process. A higher nice value reduces the priority of the process.
- **parent process** — A process that has started another process.
- **Parent Process ID (PPID)** — The PID of a process’ parent process.
- **priorities** — Levels of logging used by the Syslog daemon.
- **process** — A program currently loaded into memory and running on the CPU.
- **Process ID (PID)** — A unique identifier assigned to every process.

**program**  A file that can be executed to create a process.

**ps command**  A command that is used to list processes that are running on the system.

**pstree command**  A command that is used to list processes that are running on the system as well as their parent and child relationships.

**renice command**  A command that is used to change the priority of a running process.

**service**  See daemon process.

**siga (System Information Gathering)**  A Linux utility that creates a report about hardware and software on a Linux system.

**signal**  A termination request that is sent to a process.

**signal-controlled daemon**  A daemon that is started when an event occurs on the system.

**Syslog daemon**  The daemon that provides most logging services on Linux systems.

**syslog-ng**  The Syslog daemon used on SUSE Linux systems.

**top command**  A command that is used to view, renice, and kill the processes on the system that are using the most CPU time.

**uname command**  A command that displays general system information for a Linux system.

**uptime command**  A command that displays system statistics as well as the current running time of a Linux system.

**user process**  A process begun by a user that runs on a terminal.

**w command**  A command that displays the users who are currently logged in to a Linux system and their current processes.

**who command**  A command that displays the users who are currently logged in to a Linux system.
