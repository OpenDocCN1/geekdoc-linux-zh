The following options are displayed.

+   - *New Installation*—Performs a normal new installation of SLED 10. This is the default option.
+   - *Update*—Updates a previously installed NLD 9 installation.
+   - *Other Options*—Offers two more options:
+     - *Repair Installed System*—Repairs a previously installed SLED 10 installation.
+     - *Boot Installed System*—Boots a previously installed Linux installation.
+   - *Abort Installation*—Terminates the installation process.

For a normal installation, select New Installation and then select Next to proceed to the next step.
