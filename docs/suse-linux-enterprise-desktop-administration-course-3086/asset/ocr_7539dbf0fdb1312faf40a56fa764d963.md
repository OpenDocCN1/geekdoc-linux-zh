**/var/log/messages** The log file that contains most system messages.

**/var/spool/cron/lastrun** The directory used to store information about system cron jobs run in the past.

**/var/spool/cron/tabs** A directory that contains user cron tables.

**/var/spool/cups** The default print queue directory in SUSE Linux.

**/windows directory** A directory that contains subdirectories used to mount local Windows partitions.

**absolute path** The full name to a certain file or directory starting from the root directory.

**accept command** A command that allows print jobs to enter the print queue.

**Active Directory (AD)** The directory service used on Windows networks.

**Advanced Configuration and Power Interface (ACPI)** A standard that allows the operating system to control the power used by system components.

**Advanced Encryption Standard (AES)** A common symmetric encryption algorithm that uses up to 256-bit keys and is intended to replace 3DES.

**Advanced Programmable Interrupt Controller (APIC)** A device that coordinates the sending of information between hardware devices. It is commonly used on motherboards that have more than one processor.

**alias command** A command used to create special alias variables.

**aliases** Special variables that can be used to execute commands in a shell.

**Apache** The default Web server used on most Linux systems. Apache is also used by iPrint.

**apropos command** A command that is used to search the manual pages by keyword.

**ASCII files** Files that contain text that adheres to the American Standard Code for Information Interchange.

**asymmetric encryption** A type of encryption that uses a public and private key pair. Information encrypted with the public key can be decrypted using the private key and vice versa.

**at command** A command that is used to schedule commands to run at a certain time in the future and manipulate at jobs.

**atq command** A command that is used to view scheduled at jobs.

**atrm command** A command that is used to remove a scheduled at job.

**attributes** The properties contained within an LDAP object.

**autofs** The Automounter package in SUSE Linux.

**autofs daemon** The Automounter daemon in SUSE Linux.

**autoinst.xml** The recommended name of the AutoYaST control file. A SUSE Linux installation automatically looks for the autoinst.xml file on FAT-formatted floppy disks.

**Autoinstallation** A YaST module that can be used to create AutoYaST configuration files.

**Automounter** A system service that automatically connects remote resources to local directories.

**Autoyast** A SUSE Linux software component that can be used to automate SUSE Linux installations by using installation configuration information stored in an XML file.

**autoyast2-utils** A package that contains utilities that can be used to create an installation repository.

**background process** A process that runs unnoticed in your terminal and does not interfere with your command-line interface.

**bash (Bourne Again shell) command** The command-line interpreter on Linux systems that provides a command-line interface to the system.

**Basic Input Output System (BIOS)** The program located in mainboard ROM that is used to perform the POST and locate a boot loader or boot manager.

**bg command** A command that is used to start a process in the background.

**block-oriented device file** A device file which specifies that information be transferred to the device in a block-by-block manner to a formatted file system.

**Blowfish** A common symmetric encryption algorithm that uses up to 448-bit keys.

**Bluetooth** A low-power wireless technology used by many computer peripheral components such as mice and keyboards.

**bootloader** The program used to load and start the operating system kernel at system startup.

**BootLoader Configuration** A YaST module that can be used to configure the GRUB boot manager.

**boot manager** A program used to load and start one of several different operating systems at system startup.

**Bourne Again shell (bash)** The default shell on most Linux systems, including SUSE Linux.

**cat command** A command that is used to display (or concatenate) the entire contents of a text file to the screen.

**cd (change directory) command** A command that is used to change the current directory in the directory tree.
