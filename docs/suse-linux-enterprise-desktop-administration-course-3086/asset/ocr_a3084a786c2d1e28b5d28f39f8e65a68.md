Now a user can share directories that he or she owns. The user does not have to know the root password and does not have to ask the desktop administrator to change the Samba configuration.

You can also use YaST to enable sharing by users. Start YaST as root and select **Network Services > Windows Domain Membership**; then select **Allow Users to Share Their Directories**, while leaving the section on Membership in this dialog unchanged. Select **Finish** to close the dialog and activate the configuration.
