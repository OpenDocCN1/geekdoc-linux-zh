**iManager**  An iPrint utility that can be used to configure and manage the iPrint system.

**Internet Printing Protocol (IPP)**  A printing protocol that allows print jobs to be sent across the Internet using a Web browser. IPP is the default printing protocol used by CUPS.

**Internetwork Packet Exchange (IPX)**  A protocol used for file and printer sharing on Novell NetWare networks.

**iPrint**  A system that can be used to manage printing across an entire organization.

**iPrint client**  A software component that allows a client computer the ability to access iPrint.

**Line Printer Daemon (LPD)**  A common printing protocol used on older Linux and UNIX computers.

**lpmasswd**  A command that is used to manage users, passwords, and groups for use with the CUPS printing system.

**lpq command**  A command that is used to view print jobs in the print queue.

**lpr command**  A command that is used to create a print job.

**lprm command**  A command that is used to remove a print job from the print queue.

**Novell iPrint Direct**  A standard used by printers that allows them to receive iPrint print jobs directly from iPrint Printer Agents.

**PostScript Printer Description (PPD)**  A printing format that is widely used by many printers and printing systems.

**Print Manager**  The software components that handle printing within iPrint.

**Printer Agent**  A logical representation of a printer within the iPrint print manager.

**Printer Configuration**  A YaST tool that can be used to configure CUPS printers on a SUSE Linux system.

**pstops command**  A command that is used to format print jobs.

**queue**  A directory used to store print jobs before they are sent to the physical printer.

**reject command**  A command that prevents print jobs from entering the print queue.

**Server Message Block (SMB)**  A file- and printer-sharing protocol used by Windows systems.

**socket**  An established network connection between two hosts. CUPS can use sockets to print to a remote system and vice versa.

**Uniform Resource Identifier (URI)**  A naming convention used to locate resources on a network such as printers.
