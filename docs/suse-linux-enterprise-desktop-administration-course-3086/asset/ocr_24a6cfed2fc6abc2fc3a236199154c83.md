# Novell Customer Center Configuration

You can configure the Novell Customer Center during installation, or you can configure it later using YaST.

To configure the Novell Customer Center after installation, start YaST; then select **Software > Novell Customer Center Configuration**. The dialog shown in Figure 6-5 appears.
