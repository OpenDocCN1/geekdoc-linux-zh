# Exercise 1-1: Install SUSE Linux Enterprise Desktop 10

In this exercise, you install SUSE Linux Enterprise Desktop 10. Use the following specifications as a guideline:

+   - Use one partition with 1 GB for swap.
+   - Use one partition with 6 GB for the root partition (there should be space left on the hard disk to add partitions in later exercises).
+   - Use default software patterns; add the C/C++ Compiler and Tools pattern.
+   - Add the xsp software package.
+   - Use `n0v3ll` as the root password.
+     (As `n0v3ll` is, of course, not adequate as a root password in production, you could use a different one; however, the exercises in this manual refer to `n0v3ll` as the root password.)
+   - Use DHCP to set hostname and IP address.
+     (Conditional) If you are doing this exercise in self-study with no other students in the network and no DHCP server running, use a fixed IP address:
+     - IP address: 10.0.0.10
+     - Network mask: 255.255.255.0
+     - Hostname: da10
+     - Domain name: digitalairlines.com
+     - Name server: 10.0.0.254
+     - Default gateway: 10.0.0.254
+   - Use local authentication; create a user account geeko, with a password of novel.
+   - Skip the online update.

# Part I: Boot from the Installation Media

To boot from the installation media, do the following:

+   1. Turn on the computer.
+   2. Insert *SUSE Linux Enterprise Desktop 10 DVD* into the DVD drive.
+   3. (Conditional) If your computer does not boot from the DVD drive, reboot the computer by selecting the Reset button or by pressing Ctrl+Alt+Del.
+      Adjust the BIOS settings so that the DVD drive is the first boot device. Boot once more.
