
## cd

You can use the `cd` (change directory) command to change between directories. Some examples are shown in Table 7-11.

| Command | Meaning |
|---|---|
| `cd plan` | Change to the subdirectory plan. |
| `cd /etc` | Change directly to the /etc directory (absolute path). |
| `cd` | Change from any directory to the home directory. |
| `cd ..` | Move one directory level higher. |
| `cd ../..` | Move two directory levels higher. |
| `cd -` | Move to the last valid directory. |

## ls

The `ls` (list) command lists the specified files. If a directory is included with `ls`, the directory’s contents are displayed. Without an option, the contents of the current directory are listed. Table 7-12 shows the most important options you can use with `ls`.

| Option | Meaning |
|---|---|
| None | Displays the contents of the current directory in several columns (file and directory names only). |
| `-a` | Also displays hidden files (such as `.bashrc`). |
| `-F` | After each name, a character indicates the file type (`/` for directories, `*` for executable files, `|` for FIFO files, `@` for symbolic link). |
| `-l` | (“long list”) Gives a detailed list of all files. For each filename, information about permissions, modification time, and size is included. |
| `-t` | Sorts files by date of alteration. Combined with the option `-r`, the output takes place in reverse order (the newest file is displayed last). |
| `-R` | Output is recursive, including all subdirectories. |
| `-u` | Sorted by date of last access. |

Table 7-12

## pwd

You can use the pwd (print working directory) command to display the path of the current directory. If you enter pwd with the `-P` option, pwd prints the physical directory without any symbolic links:

```shell
geeko@da10:~> ls -l doc/
lrwxrwxrwx 1 geeko users 15 2004-02-12 08:43 doc -> /usr/share/doc/
geeko@da10:~> cd doc/
geeko@da10:~> pwd
/home/geeko/doc
geeko@da10:~> pwd -P
/usr/share/doc
geeko@da10:~> 
```

## Exercise 7-2: Change Directories and List Directory Contents

In this exercise, describe what directories the characters . and .. refer to. Then, change between directories (cd), display the name of the active directory (pwd), and list directory contents (ls).

### Detailed Steps to Complete This Exercise

1. Describe what directories the following characters refer to
   - .
   - ..
2. On the GNOME desktop, right-click on the background and select Open Terminal from the Context menu.
3. Change to the /tmp directory by entering
   ```
   cd /tmp
   ```
4. Display the name of the active directory by entering
   ```
   pwd
   ```
5. Change to the home directory by entering
   ```
   cd ~
   ```
6. Display the name of the active directory by entering
   ```
   pwd
   ```
7. Change to the /usr/share/doc directory by entering
   ```
   cd /usr/share/doc
   ```

   ```
   pwd
   ```

   ```
   cd -
   ```

    ```
    pwd
    ```

    ```
    ls
    ```

    ```

    ```

## Objective 4—Create and View Files

To create and view files, you need to know how to do the following:

- Create a New File with touch
- View a File with cat
- View a File with less
- View a File with head and tail

### Create a New File with touch

You can use the touch command to change the time stamp of a file or create a new file with a size of 0 bytes. Table 7-13 lists the most important options.

| Command | Description |
|---|---|
| `-a` | Changes only the time of the last read access (access time). |
| `-m` | Changes only the time of the last modification (modification time). |
| `-r file` | Sets the time stamp of file instead of the current time. |
| `-t time` | Instead of the current time, sets time (structure: `[[CC]YY]MMDDhhmm[.ss]` ([Century]Year Month Day Hour Minute [Seconds], two digits in each case)). |

Table 7-13

The following is an example of using touch:

```text
geeko@dal0:~> ls
bin Desktop Documents public_html
geeko@dal0:~> touch example
geeko@dal0:~> ls
bin Desktop Documents example public_html
geeko@dal0:~>
```

### View a File with cat

You can use the cat (concatenate) command to view the contents of a file. The command must include the filename of the file you want to see, as in the following:

```text
geeko@dal0:~> cat /etc/HOSTNAME
dal0.digitalairlines.com
geeko@dal0:~>
```

### View a File with less

You can use the less command to display the contents of a file page by page. Even compressed files (such as .gz and .bz2) can be displayed. You can use the keystrokes shown in Table 7-14 with less.

| Keystroke | Description |
|---|---|
| Spacebar | Move one screen down. |
| b | Move one screen up. |
| Down-arrow | Move one line down. |
| Up-arrow | Move one line up. |
| `/pattern` | Search for pattern forward from the current cursor position. |
| `?pattern` | Search for pattern backwards from the current cursor position. |
| n | Move to the next instance in the search for pattern. |
| N | Move to the previous instance in the search for pattern. |
| q | Quit. |

Table 7-14

### View a File with head and tail

With the head command, you can view only the first few lines of a file. The tail command shows you only the last few lines of a file.

By default, these commands only show 10 lines. To change this number, append the option-`number`.

When used with the tail command, the option `-f` displays a continuously updated view of the last lines of a file. If a line is added at the end of the file while tail -f is running, the line is displayed. This is a useful feature for observing log files. To exit tail -f, press Ctrl+C.

## Exercise 7-3: Create and View Files

In this exercise, create an empty new file file.

Then, display the content of the /var/log/messages file in the following ways:

- At once with the `cat` command.
- Page by page with the `less` command. Then, look for the word root in the file.
- In the first five lines with the `head` command.
- In the last lines continuously updated with the `tail` command. To view new log data, log in and log out as yoot.

### Detailed Steps to Complete This Exercise

1. On the GNOME desktop, press Alt+F2 and enter `gnome-terminal` in the Run Application dialog.
2. Create a new, empty file by entering
   ```
   touch new_file
   ```
3. Open another terminal window, and log in as root (`su -`) with a password of `n0v3ll`.
4. Display the content of the /var/log/messages file by entering
   ```
   cat /var/log/messages
   ```
5. Display the content of /var/log/messages page by page by entering
   ```
   less /var/log/messages
   ```
6. Find the first occurrence of the word root by entering
   ```
   /root
   ```
7. Find the next occurrence of the word root by typing n.
8. Navigate through the output by using Down-arrow, Up-arrow, Right-arrow, and Left-arrow, and PageUp and PageDown.
9. Quit the display and return to the command line by typing q.
10. Display the first five lines of the /var/log/messages file by entering
    ```
    head -n 5 /var/log/messages
    ```
11. View a continuously updated display of the last lines of the file /var/log/messages by entering
    ```
    tail -f /var/log/messages
    ```
12. Arrange the terminal windows on the desktop so that you can see the content of both.
13. In the first terminal window, log in as root (`su -`); then enter an invalid password (such as `suse`).

    Notice that this login attempt is logged in the second terminal window.
14. In the first terminal window, log in as root (`su -`) with a password of `n0v3ll`.

    The login is logged in the second terminal window.
15. Log out as root in the first terminal window by entering
    ```
    exit
    ```
16. Close the first terminal window by entering
    ```
    exit
    ```
17. Stop the tail process in the second terminal window by pressing
    ```
    Ctrl+c
    ```
