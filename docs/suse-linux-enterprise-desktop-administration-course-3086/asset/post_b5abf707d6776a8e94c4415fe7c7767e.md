## Objective 2—Use the GNOME Desktop Environment

GNOME is a comfortable desktop environment. Numerous programs are specifically designed for GNOME.

To use the GNOME desktop environment, you need to know how to:

- Log In
- Log Out and Shut Down
- Identify GNOME Desktop Components
- Manage Icons in GNOME
- Use the GNOME File Manager (Nautilus)

### Log In

If you want to work with a multiuser-capable operating system, you must first identify yourself to the operating system. For this purpose, you need:

- A *login string* or *username*
- A *password* (usually assigned by the system administrator when a new user is added)

When the computer is booted and ready for work, the login dialog shown in Figure 2-2 appears.

![](img/9129877170834ca9d5fdac5319bf5f12_69_0.png)

Figure 2-2

After entering a username, press Enter. Then enter your password and press Enter again. If the login is successful, the GNOME desktop environment shown in Figure 2-3 appears.

![](img/9129877170834ca9d5fdac5319bf5f12_70_0.png)

Figure 2-3

### Log Out and Shut Down

When you are ready to log out of the system, open the Computer menu (also called main menu) in the bottom panel. See Figure 2-4.

![](img/9129877170834ca9d5fdac5319bf5f12_71_0.png)

Figure 2-4

![](img/9129877170834ca9d5fdac5319bf5f12_71_1.png)

### Identify GNOME Desktop Components

The GNOME desktop (Figure 2-7) includes one panel at the bottom of the screen.

![](img/9129877170834ca9d5fdac5319bf5f12_73_1.png)

Figure 2-7

The Computer menu appears on the left side of the panel. It is called the main menu. The icon next to it is Tomboy Notes. Click on it and select Create New Note to take notes.

The empty space in the middle of the panel includes the task manager. All opened windows on the screen will be listed here.

Additional icons are displayed on the right side of the panel. Which icons are available depends on your hardware:

- *Network Manager Icon*—Identifies the network connection (wired or wireless).
- *Monitor*—Provides display information.
- *Globe*—Searches for new updates.
- *Battery*—Provides power management information for laptops.
- *Speaker*—Allows volume control.
- *Calendar*—Provides access to a calendar.
- *Clock*—Shows date and time.
- *Board*—Minimizes all open windows on the desktop or shows them again.

You can start a program that is represented by an icon on the desktop by double-clicking the icon.

Most programs are started from the main menu, which is shown in Figure 2-8.

![](img/9129877170834ca9d5fdac5319bf5f12_74_0.png)

Figure 2-8

At the top of the left frame of the main menu three buttons allow you to access the following:

- *Applications*—A list of favorite and recently used applications.
- *Documents*—Documents that were accessed recently. A click on a document opens the document in the application used to edit or view it.
- *Places*—A list of shortcuts to directories. When you select a shortcut, the content of the directory is displayed in the file manager Nautilus.

In the Applications section, a button labeled More Applications is displayed. When you select this button, the Application Browser appears as shown in Figure 2-9.

The right frame of the application browser shows a list of the most important installed applications. The applications are grouped and you can see a list of the groups in the left frame. Select a group to highlight the applications that belong to this group.

The filter option adds even more flexibility. In the Filter text box in the left frame, enter a part of the name of the application you want to start. The filtered applications are shown immediately in the right frame.

![](img/9129877170834ca9d5fdac5319bf5f12_75_0.png)

**Figure 2-9**

The right frame of the main menu displays six system options:

- *Help*—Starts the online help.
- *Control Center*—Starts the GNOME Control Center where you can configure your desktop.
- *Install Software*—Shows a list with the available software on your registered installation media.
- *Lock Screen*—Locks the screen. Enter your password to unlock the screen.
- *Logout*—Logs you out of the system.
- *Shutdown*—Shuts down or reboots the system.

You can see the status of your hard drives and network at the bottom of the right frame.

To start an application, select the icon in the main menu or the application browser with a single mouse click.
