You can create an AutoYaST configuration file at the end of a SUSE Linux installation, or by using the YaST Autoinstallation module. You can use an AutoYaST configuration file during an installation by specifying its location at the boot prompt. Alternatively, if your AutoYaST configuration file is named autoinst.xml and resides on the root directory of a FAT-formatted floppy disk, it will be used automatically during a SUSE Linux installation.

# Key Terms

+   - **/etc/exports** The file used to configure NFS shared directories.
+   - **/var/lib/autoinstall/repository** The default directory used to store AutoYaST configuration files.
+   - **autoinst.xml** The recommended name of the AutoYaST control file. A SUSE Linux installation automatically looks for the autoinst.xml file on FAT-formatted floppy disks.
+   - **Autoinstallation** A YaST module that can be used to create AutoYaST configuration files.
+   - **AutoYaST** A system that can be used to automate the configuration of SUSE Linux computers during installation. AutoYaST stores its configuration in XML configuration files.
+   - **autoyast2-utils** A package that contains utilities that can be used to create an installation repository.
+   - **Common Internet File System (CIFS)** A file and printer sharing protocol used by Windows systems. It is commonly called SMB.
+   - **control file** The XML configuration file used by AutoYaST to configure a SUSE Linux installation.
+   - **Dynamic Host Configuration Protocol (DHCP)** A protocol that is used to assign TCP/IP configuration information to a host on the network.
+   - **Extensible Markup Language (XML)** A hierarchical data storage format used by many programs and technologies today.
+   - **File Transfer Protocol (FTP)** The most common protocol used to transfer files on the Internet.
+   - **Hypertext Transfer Protocol (HTTP)** The protocol used to transfer Web pages on the Internet.
+   - **inssrv command** A command that is used to configure daemon startup at system initialization.
+   - **installation repository** See repository.
+   - **installation server** A server that makes Linux installation files available across a network.
+   - **Installation Server** A YaST module in SUSE Linux Enterprise Server 10 that can be used to set up an installation server.
+   - **Network File System (NFS)** A file-sharing protocol used by UNIX and Linux systems.
+   - **Preboot eXecution Environment (PXE)** A technology used by network cards that allow them to locate files from an installation server on the network.
+   - **Red Hat Package Manager (RPM)** A package manager system used by most Linux systems. SUSE Linux distributes its installation packages in RPM format.
+   - **repository** A directory that contains software on an installation server.
+   - **Secure Shell (SSH)** A software service that provides an encrypted shell session to and from remote computers.
+   - **Server Message Block (SMB)** A file- and printer-sharing protocol used by Windows systems.
