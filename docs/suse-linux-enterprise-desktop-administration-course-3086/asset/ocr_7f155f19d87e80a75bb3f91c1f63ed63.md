# YaST Modules

To administer your Linux system efficiently, you should become comfortable with the various modules that are available for system configuration in YaST. Use the yast --list command to view the available YaST modules on your system. Start each module directly using the yast command and take note of its purpose.

# Understanding SuSEconfig

The SuSEconfig utility provides a back end to YaST by configuring the information saved by YaST in /etc/sysconfig. Examine the contents of the /etc/sysconfig directory and view some of the files within. Using the Internet and local documentation, examine the purpose of the SuSEconfig utility. Finally, run SuSEconfig on your system.
