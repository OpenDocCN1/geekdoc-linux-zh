# Starting the Novell iFolder Client

When Novell iFolder is running, the Novell iFolder Services icon appears in the Notification area of the taskbar. Novell iFolder is integrated in the desktop environment. The Novell iFolder emblem (green “i”) appears on Novell iFolders when they are viewed in a file manager, on the desktop, or in the Novell iFolder browser. The encrypted Novell iFolder is indicated by the emblem (locked folder) on the Novell iFolder.

![](bbox=[0.15, 0.52, 0.28, 0.62])

> > **IMPORTANT:** The Notification area of the taskbar must be enabled in order for the Novell iFolder Services icon to be displayed when Novell iFolder is running.

You can work locally with files in your local Novell iFolders at any time. Whenever the Novell iFolder client is running, it logs the changes you make to local Novell iFolder data as you work. If you make changes to local Novell iFolder data when Novell iFolder is not running, Novell iFolder identifies and logs the differences the next time you start Novell iFolder.

When Novell iFolder is not running, Novell iFolders appear as normal folders in the file manager or on the desktop. You can access files in your local copy of a Novell iFolder, but you cannot manage Novell iFolders. In addition, you must log in to an account to create a Novell iFolder or synchronize its files.

There are two ways to start Novell iFolder:

+   - Start Novell iFolder Automatically on Login
+   - Start Novell iFolder on Demand
