# Part II: Set a Runlevel at Boot Time

To set a runlevel at boot time, do the following:

+   1. From the GNOME desktop, select Computer > Shutdown > Restart.
+   2. When the boot menu is displayed, press Spacebar to stop the timer.
+   3. In the Boot Options field, type `3`; then press Enter to boot the Linux system to runlevel 3.
+   4. When the login prompt appears, log in as root with a password of `nov311`.
+   5. Display the current runlevel by entering `runlevel`.
+   6. Switch to runlevel 5 by entering `init 5`.
+   7. Switch back to the virtual terminal by pressing Ctrl+Alt+F1.
+   8. Log out as root by entering `exit`.
+   9. Switch back to the graphical user interface by pressing Ctrl+Alt+F7.
+   10. Log in as geeko with a password of `novell`.

# Part III: Activate the at Service atd

To activate the at service atd, do the following:

+   1. Open a terminal window and change to the `/etc/rc.d/rc3.d` directory by entering `cd /etc/rc.d/rc3.d`.
+   2. List the atd files in the directory by entering `ls -l *atd`.
+      Notice that there are none.
+   3. From the graphical desktop, start YaST.
+      The YaST Control Center appears.
+   4. Select System > System Services (Runlevel).
+      The Runlevel Editor: Services dialog appears.
+   5. Make sure the Simple Mode radio button is selected.
+   6. Select the atd entry in the list of services.
+   7. Select Enable; confirm the message that other services have to be started as well by selecting Continue.
+      A message informs you that the service atd started successfully. Confirm this message by selecting OK.
+   8. Close the Runlevel Editor by selecting Finish. Confirm the message that the changes will be saved.
+   9. In the terminal window, again list the atd files in the `/etc/init.d/rc3.d` directory by entering `ls -l *atd`.
+      Notice that now there are links pointing to `/etc/init.d/atd`.
+   10. Switch to virtual terminal 1 by pressing Ctrl+Alt+F1. Log in as root (password `nov311`). Verify that the at service is running by entering `rcat status`.
+   11. Switch to runlevel 1 by entering `init 1`.
