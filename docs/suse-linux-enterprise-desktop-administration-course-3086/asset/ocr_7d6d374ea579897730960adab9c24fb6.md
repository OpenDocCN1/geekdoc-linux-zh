# Objective 3—Use SuSEfirewall2

Packet filtering in Linux is done by the kernel and its netfilter framework. SuSEfirewall2 consists of a number of scripts that set rules to filter IP packets using the program iptables, with the goal to protect the computer from attacks.

SuSEfirewall2 can be configured using the YaST Firewall module. An alternative would be to edit the file `/etc/sysconfig/SuSEfirewall2` with a text editor.

This is just a very short introduction to SuSEfirewall2. For a full overview, visit Course 3075, *SUSE Linux Enterprise Server 10: Security.*

Unless you change the default during installation, SuSEfirewall2 is active, preventing connections to the computer. During the installation, you can allow SSH connections or disable the firewall completely.

The YaST Firewall module allows a more detailed configuration. To start the configuration, start YaST and select Security and Users > Firewall. The dialog shown in Figure 5-9 appears. Here you determine whether or not the firewall should be activated at system start. You can also switch it on and off as needed.

In the left part of the window, you select the aspect of the configuration you want to change. When you select Interfaces, the dialog shown in Figure 5-10 appears.

Here you can assign interfaces to zones (Internal, Demilitarized, or External Zone) by highlighting an entry and selecting Change. The interfaces of a desktop system should all be assigned to the External Zone.
