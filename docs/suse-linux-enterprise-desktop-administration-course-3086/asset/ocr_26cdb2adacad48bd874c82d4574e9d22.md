**/etc/sysconfig/backup** The configuration file that controls automatic system backups.

**/etc/sysconfig/cron** A file that contains parameters for the cron daemon.

**/etc/sysconfig/kernel** The configuration file for the Linux kernel used during system initialization.

**/etc/sysconfig/language** A file that defines the default character encoding used on SUSE Linux systems.

**/etc/sysconfig/network** The directory that contains most network configuration information.

**/etc/sysconfig/network/config** A file that contains network configuration settings such as NetworkManager.

**/etc/sysconfig/SuSEfirewall2** The file that stores packet filter information for use with the netfilter framework in SUSE Linux.

**/etc/sysconfig/syslog** A file that contains configuration parameters for the Syslog daemon.

**/etc/syslog-ng/syslog-ng.conf** The configuration file that defines how the Syslog daemon logs information about system processes.

**/etc/syslog-ng/syslog-ng.conf.in** A template used to create the /etc/syslog-ng/syslog-ng.conf file.

**/etc/udev/rules.d** The directory used to contain rules used by the udev system.

**/home directory** The default location for user home directories.

**/lib directory** A directory that contains shared program libraries (used by the commands in /bin and /sbin) as well as kernel modules.

**/media directory** A directory that is used for accessing (mounting) disks such as floppy disks and CD-ROMs.

**/mnt directory** A directory that is used for accessing (mounting) disks such as floppy disks and CD-ROMs.

**/opt directory** A directory that stores additional software program files.

**/opt/novell/iFolder3/bin/iFolder** The iFolder client program.

**/opt/novell/ncl/bin/ncl_tray** The Novell Client tray application.

**/proc** A directory that contains hardware, software, and process information on a Linux system.

**/proc directory** A directory that contains process and kernel information.

**/root directory** The root user's home directory.

**/root/autoinst.xml** A file generated by a SUSE Linux installation for use with Autoyast.

**/sbin directory** A directory that contains system binary commands used for administration.

**/sbin/config.d** The directory that stores scripts used by SuSEconfig.

**/sbin/init** The initialization program used to start system services at system initialization.

**/srv directory** A directory that contains file content used by Linux network services.

**/sys directory** A directory that contains current system information.

**/tmp directory** A directory that holds temporary files created by programs.

**/usr directory** A directory that contains most system commands and utilities. It stands for UNIX Special Resources or UNIX System Resources.

**/usr/lib/rpm/rpmrc** The main RPM configuration file.

**/usr/sbin/automount** The Automounter program in SUSE Linux.

**/usr/share/doc** A directory that stores system and program documentation on a Linux system.

**/usr/share/info** The directory that contains the info pages on a SUSE Linux system.

**/usr/share/man** The directory that contains the manual pages on a SUSE Linux system.

**/var directory** A directory that contains log files and spools.

**/var/adm/backup/rpmdb** The directory that stores backup copies of the RPM database.

**/var/lib/autoinstall/repository** The default directory used to store AutoYaST configuration files.

**/var/lib/rpm** The directory that stores the RPM database.

**/var/log** The directory that contains most log files on a Linux system.

**/var/log/audit/audit.log** The log file for AppArmor.

**/var/log/boot.log** A file that contains all messages written during the boot process.

**/var/log/cups/access_log** A CUPS log file that stores information about network print requests.

**/var/log/cups/error_log** A CUPS log file that stores information about the CUPS daemon.

**/var/log/cups/page_log** A CUPS log file that stores information about each page that is sent to a printer.

**/var/log/firewall** The log file that stores firewall-related messages.
