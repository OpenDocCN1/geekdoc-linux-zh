
**public key** An asymmetric encryption key that can be used to decrypt data encrypted using a private key. The public key is typically used to encrypt data.

**pwd (print working directory) command** A command that is used to display the current directory in the directory tree.

**Qt** A toolkit used to create graphical applications on Linux systems. YaST contains a graphical Qt mode.

**queue** A directory used to store print jobs before they are sent to the physical printer.

**rcp command** A command used to copy files to and from remote computers.

**read permission** A permission that allows you to open and read files as well as list directory contents.

**reboot command** A command that is used to quickly bring a system to runlevel 6.

**Red Hat Package Manager (RPM)** A package manager system used by most Linux systems. SUSE Linux distributes its installation packages in RPM format.

**Redundant Array of Independent Disks (RAID)** A series of methods for storing data on different hard disks to improve performance and provide fault tolerance.

**regular users** User accounts that can be used to log in to the system interactively.

**Reiser** The default file system used on SUSE Linux systems.

**reject command** A command that prevents print jobs from entering the print queue.

**relative distinguished name (RDN)** The simple name of an object in LDAP.

**relative path** The name of a target directory relative to your current directory in the tree.

**Remote Procedure Call (RPC)** A routine that is executed on a remote computer.

**renice command** A command that is used to change the priority of a running process.

**repository** A directory that contains software on an installation server.

**Rivest Shamir Adleman (RSA)** A common asymmetric encryption algorithm.

**rlogin command** A command used to obtain a shell on a remote computer.

**rm (remove) command** A command that is used to remove files and directories.

**rmdir (remove directory) command** A command that is used to remove empty directories.

**router** A device that is used to relay IP packets from one IP network to another.

**routing** The process of sending IP packets from one IP network to another. It is also called IP forwarding.

**routing table** A table that is stored on each host that contains a list of local and remote networks and routers.

**rpcinfo command** A command that displays RPC ports and their associated services.

**rpm command** A command used to install, remove, and find information on RPM software packages.

**rsh command** A command used to obtain a shell or run a program on a remote computer.

**rug command** A command used to manage the software update services in SUSE Linux.

**runlevel** A Linux system state that depends on the number and type of processes that are currently running.

**runlevel command** A command that is used to display the current and most recent runlevel.

**Runlevel Editor** A YaST module that can be used to configure the daemons that start at each runlevel.

**sabayon** The package name for the Desktop Profile Editor.

**Samba** A set of services in Linux that provides the SMB and NetBIOS protocols for file and printer sharing with Windows computers.

**sax2 command** A command that is used to start the X configuration utility on a SUSE Linux system.

**schema** The list of object and object properties for an LDAP database.

**scp command** A command used to copy files from one host to another using SSH.

**search patterns** Special characters that can be used to match multiple filenames. Also known as wildcards.

**secondary group** A group that a user belongs to that is not the user's primary group.

**Secure Shell (SSH)** A software service that provides encrypted communication to and from remote computers. It can also be used to create VPNs.

**Serial Advanced Technology Attachment (SATA)** A serial version of EIDE that is commonly used in modern computers.

**Server Message Block (SMB)** A file- and printer-sharing protocol used by Windows systems.

**Server Process Key Pair (SK)** An asymmetric encryption key pair that is generated when the SSH daemon is started. This key pair is never stored in a file and is regenerated each time the daemon is restarted.

**service** See daemon process.

**Service Location Protocol (SLP)** The network browsing protocol used by Novell networks.

**session key** A randomly generated key used by SSH for symmetric encryption.

**Set Group ID (SGID)** A special permission set on executable files and directories. When you run an executable program that has the SUID permission set, you become the group owner of the executable file for the duration of the program. On a directory, the SGID sets the group that gets attached to newly created files.

**Set User ID (SUID)** A special permission set on executable files. When you run an executable program that has the SUID permission set, you become the owner of the executable file for the duration of the program.

**sftp command** A command used to copy files from one host to another using SSH.

**shared libraries** Files that store common functions used by most programs on the system.

**shares** Shared directories or printers on a Windows or Samba computer.

**shell** The Linux command interpreter.

**shell variables** Variables that are only available in the current shell and are used to configure the shell itself.

**shutdown command** A command that is used to change to runlevel 0 at a certain time.

**siga (System Information Gathering)** A Linux utility that creates a report about hardware and software on a Linux system.

**signal** A termination request that is sent to a process.

**signal-controlled daemon** A daemon that is started when an event occurs on the system.

**Small Computer System Interface (SCSI)** A hard disk technology that is commonly used in servers and high-end workstation computers.

**smbclient command** A command that is used to view and access Windows and Samba file and printer shares.

**smbd** The Samba daemon.

**socket** An established network connection between two hosts. CUPS can use sockets to print to a remote system and vice versa.

**sockets** Named pipes connecting processes on two different computers; they can also be represented by files on the file system.

**Software Management** A YaST module that is used to install and manage software packages in SUSE Linux.

**Software RAID** A RAID implementation that is managed by operating system software.

**Software Updater** A desktop utility that can be used to quickly update your SUSE Linux software using Online Update.

**source command** A command used to execute a file in the current shell environment.

**ssh command** A command that is used to obtain a shell from a remote SSH server.

**ssh-add command** A command used to register new RSA and DSA keys for use by the ssh-agent command.

**ssh-agent command** A command used to perform SSH authentication.

**ssh-copy-id command** A command used to copy SSH keys from one computer to another.

**ssh-keygen command** A command used to generate RSA and DSA keys for use with SSH.

**ssh-keyscan command** A command used to display asymmetric public keys used by SSH.

**sticky bit** A special permission that is set on directories that prevents users from removing files that they do not own.

**su (switch user) command** A command that is used to change the current user account.

**subnet mask** A number used to determine which portions of an IP address are the network portion and host portion.

**sudo command** A command that is used to run commands as another user via entries in /etc/sudoers.

**SuSEconfig** A software utility that configures the system using entries in the /etc/sysconfig directory.

**SuSEFirewall** A service that restricts certain network traffic on a SUSE Linux computer.

**SuSEfirewall2** The SUSE Linux utility that is used to configure the netfilter framework to provide packet filtering on a network interface.

**swap** An area of a hard disk that is reserved for storing information that is normally stored in computer memory.

**symbolic link** A pointer to another file on the same or another file system; commonly referred to as a shortcut or soft link.

**symmetric encryption** A type of encryption that uses the same key to encrypt and decrypt data.

**Syslog daemon** The daemon that provides most logging services on Linux systems.

**syslog-ng** The Syslog daemon used on SUSE Linux systems.
