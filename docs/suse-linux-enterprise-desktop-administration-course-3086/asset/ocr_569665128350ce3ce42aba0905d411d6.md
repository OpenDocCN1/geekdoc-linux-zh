**autofs daemon** The Automounter daemon in SUSE Linux.
**Automounter** A system service that automatically connects remote resources to local directories.
**container object** An LDAP object used to organize leaf objects.
**directory** A database that contains information about resources such as user accounts.
**Directory Information Tree (DIT)** The hierarchical structure of an LDAP database.
**directory service** A service that can be used to query a directory for information.
**distinguished name (DN)** A full pathname to an LDAP leaf object.
**Domain Name System (DNS)** The naming system used on the Internet. Each host is identified by a hostname and domain name.
**Dynamic Host Configuration Protocol (DHCP)** A protocol that is used to assign TCP/IP configuration information to a host on the network.
**eDirectory** The directory service used on Novell networks.
**entry** A reference to an LDAP object.
**firewall** A service that restricts certain network traffic on a host computer.
**GNOME Display Manager (GDM)** The login screen used by the GNOME desktop environment.
**iFolder** See Novell iFolder.
**iFolder Client** The software component installed on iFolder clients that can be used to connect to and manage shared files.
**iManager** See Novell iManager.
**insserv command** A command that is used to configure daemon startup at system initialization.
**K Display Manager (KDM)** The login screen used by the KDE desktop environment.
**Kerberos** A secure authentication protocol used by UNIX, Linux, and Windows directory services. Kerberos uses tickets to identify authenticated computers and services.
**Key Distribution Center (KDC)** The computer that is used to issue Kerberos tickets.
**Konqueror** The graphical file management utility used in the KDE desktop.
**leaf object** An LDAP object that represents a network resource.
**Lightweight Directory Access Protocol (LDAP)** A protocol used to provide central authentication and distribute information to network computers.
**Lightweight Directory Interchange Format (LDIF)** The format by files that are used to create, modify, and query objects in an LDAP database.
**Linux User Management (LUM)** A management suite designed to manage local and directory-based user accounts on SUSE Linux computers.
**Name Service Switch (NSS)** A software component that provides information about name services on a Linux system.
**Nautilus** The default graphical file management utility used in SUSE Linux.
**NetBIOS** A Windows protocol that uses unique 15-character computer names to identify network hosts.
**NetWare Core Protocol (NCP)** The application layer protocol used by Novell NetWare systems on a network.
**Network File System (NFS)** A file-sharing protocol used by UNIX and Linux systems.
**Network Information Service (NIS)** A service that allows the centralization of Linux and UNIX configuration.
