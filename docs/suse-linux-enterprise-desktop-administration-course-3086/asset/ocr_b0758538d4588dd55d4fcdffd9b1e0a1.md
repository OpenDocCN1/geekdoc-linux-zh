# Intended Audience

This book is appropriate for anyone who wants to learn how to use, configure, or administer SUSE Linux Enterprise Desktop 10, as well as for those who are currently preparing for the Novell Certified Linux Desktop Administrator (CLDA) 10 Practicum exam. Although the concepts introduced in this book do not assume prior SUSE Linux experience, a general knowledge of computing concepts is assumed. In addition, many of the concepts and procedures introduced in this book are transferable to most other Linux distributions.

# Section Descriptions

There are 11 sections in this book, as follows:

+   1. **Section 1, “Install SUSE Linux Enterprise Desktop 10,”** examines the concepts and procedures necessary to install SUSE Linux Enterprise Desktop.
+   2. **Section 2, “Use the Linux Desktop,”** examines the navigation of the GNOME desktop environment. In addition, this section introduces the Linux command-line interface.
+   3. **Section 3, “Locate and Use Help Resources,”** discusses the various tools used to obtain help in SUSE Linux Enterprise Desktop 10, including the manual pages, info pages, HOWTO files, and Internet resources.
+   4. **Section 4, “Administer Linux with YaST,”** walks through the procedures used to administer basic system information using the YaST utility. This section also examines the structure of SuSEconfig.
+   5. **Section 5, “Manage the Network Configuration,”** covers the configuration of network interfaces in SUSE Linux Enterprise Desktop 10 using YaST and command-line tools. Furthermore, this section examines the configuration of firewalls and remote access protocols such as SSH, VPNs, and VNC.
+   6. **Section 6, “Manage Software,”** examines the concepts and procedures necessary to manage software packages on SUSE Linux systems with focus on online update and RPM.
+   7. **Section 7, “Manage Directories and Files,”** covers the structure of the Linux file system as well as the commands used to navigate the file system directory structure. This section also introduces the commands that may be used to create, view, search, and manage files on the file system.
+   8. **Section 8, “Work with the Linux Shell and Command Line,”** discusses the various features of your shell, including filename completion, command history, variables, special characters, history, and aliases. Following this, we examine the usage of the gedit and vi text editors.
+   9. **Section 9, “Manage Users, Groups, and Permissions,”** examines the concepts and tools used to administer users, groups, passwords, file permissions, file ownership, and encryption on a SUSE Linux system.
+   10. **Section 10, “Monitor the Linux System and Control Processes and Services,”** discusses the log files and utilities that may be used to identify problems with system security and performance. In addition, this section discusses how to view, manage, kill, and schedule user and daemon processes.
+   11. **Section 11, “Manage System Initialization,”** covers the SUSE Linux boot process and examines the configuration of the GRUB boot loader as well as the configuration of daemon processes by runlevel.
