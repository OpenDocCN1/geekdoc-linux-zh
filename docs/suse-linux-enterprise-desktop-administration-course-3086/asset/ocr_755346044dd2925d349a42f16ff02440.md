# Part C: Map a Network Directory

To map a network directory, do the following:

+   1. Select the Novell Client icon; then select Novell Map Directory.
+      Figure 13-31 shows what appears.

![](bbox=[0.17, 0.22, 0.6, 0.66])

Figure 13-31

2. Enter the following:

+   - Enter the location where the link will reside: /home/gecko/Documents
+   - Enter the name of the link or select a drive letter: DA-Shared
+   - Enter the server name and path to the directory you want to map: \\DA-OES\SYS:PUBLIC\

![](bbox=[0.12, 0.82, 0.28, 0.9])

You can also select the Browse button and locate the directory you want to map.
