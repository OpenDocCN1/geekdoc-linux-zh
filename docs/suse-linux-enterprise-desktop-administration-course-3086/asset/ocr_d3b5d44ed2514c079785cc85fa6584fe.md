**default gateway**  The router that connects a network to other networks. IP packets whose destination networks are not included in the routing table are sent to the default gateway.

**Diffie-Hellman**  A common asymmetric encryption algorithm.

**Digital Signature Algorithm (DSA)**  A common asymmetric encryption algorithm.

**DNS server**  A server that contains records for hosts on a network. It can be queried to resolve a hostname to an IP address.

**DNS server**  See name server.

**domain name**  The name of the DNS domain that a computer on a TCP/IP network belongs to.

**Domain Name System (DNS)**  The naming system used on the Internet. Each host is identified by a hostname and domain name.

**driver**  A software component used by the operating system to control hardware devices such as network devices.

**Dynamic Host Configuration Protocol (DHCP)**  A protocol that is used to assign IP configuration information to a host on the network.

**ESSID (Extended Service Set Identifier)**  A name that identifies a host on a wireless network.

**firewall**  A software feature that allows a host to drop IP packets that meet certain criteria.

**FQDN (Fully Qualified Domain Name)**  A name that refers to a resource on a TCP/IP network. It consists of a hostname followed by a domain name.

**gnome-keyring-manager command**  A command that is used to manage keyrings in SUSE Linux.

**Hash Message Authentication Code (HMAC)**  A feature of SSH version 2 that prevents attackers from compromising SSH data during transit.

**hostname**  A name used to identify hosts on a TCP/IP network.

**HyperText Transfer Protocol Secure (HTTPS)**  A common technology used to encrypt World Wide Web traffic. It can also be used to create VPNs.

**ifup command**  A command used to activate a network card in SUSE Linux.

**International Data Encryption Algorithm (IDEA)**  A common symmetric encryption algorithm that uses up to 128-bit keys.

**Internet Control Message Protocol (ICMP)**  A part of the TCP/IP protocol suite that is used to relay information about network communications.

**Internet Protocol (IP)**  The protocol used to communicate with other computers on the Internet and most other networks.

**Internet Protocol (IP) address**  A unique address used to identify a computer on a TCP/IP network.

**ip command**  A command used to view, configure, and manage network interfaces and the routing table.

**IP forwarding**  See routing.

**IP Security (IPSec)**  A common technology used to encrypt communication on IP networks. It can also be used to create VPNs.

**iptables command**  A command used to configure packet filtering using the netfilter framework in SUSE Linux.

**keyring**  A file used to store passwords for future use with wireless networks and VPNs.
