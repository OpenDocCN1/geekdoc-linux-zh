In the top part of the dialog, you can choose one of the following options:

+   - *Skip Configuration*—Skip the network configuration for now. You can configure the network configuration later in the installed system.
+   - *Use Following Configuration*—Use the network configuration proposal that is displayed.

The network configuration proposal is similar to the installation proposal at the beginning of the base installation, with headings that can be selected to view and configure further details. The proposal includes the following entries:

+   - *Network Mode*—Switch between the traditional method of managing the network and network manager. Network manager enables users to easily switch between, for instance, Ethernet and wireless access. On a server you would use the traditional method.
+   - *Firewall*—If you want to administer the computer via SSH, toggle SSH port is blocked to SSH port is open by clicking on blocked. You can disable the firewall by clicking on enabled. When the firewall is disabled, then SSH is accessible as well. Selecting Firewall itself opens a dialog allowing detailed configuration of the firewall settings.
+   - *IPv6*—Click on Disable IPv6 to turn off support for IPv6. The IPv6 kernel modules will not be loaded automatically.
+   - *Network Interfaces*—Displays the network interfaces found (such as Ethernet or a Wireless-LAN adapter) and their configuration (such as DHCP).

The dialogs used to configure the network interfaces are the same as those of the YaST network Card module used in the installed system to configure the network interfaces. This module is covered in detail in “Manage the Network Configuration Information from YaST” on page 95.

+   - *DSL Connections*—Displays the configuration of DSL devices, such as a DSL modem connected to an Ethernet adapter.
+   - *ISDN Adapters*—Displays the configuration of ISDN devices.
+   - *Modems*—Displays the configuration of analog modems.
+   - *VNC Remote Administration*—Displays the configuration of remote administration using VNC.
+   - *Proxy*—Displays the HTTP and FTP proxy settings.

You can change a configuration by selecting the headline of the entry or by selecting the entry from the Change drop-down list. This menu also lets you reset all settings to the defaults generated by YaST.

If you are not sure which settings to use, stay with the defaults generated by YaST. After finishing the network configuration, select Next.
