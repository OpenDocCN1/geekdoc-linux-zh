Select Apply to write the settings to the file `/etc/sysconfig/SuSEfirewall2`. The variables defined in this file are used by the SuSEfirewall2 scripts to set the filtering rules using the `iptables` command.

![](bbox=[0.113, 0.707, 0.301, 0.781])

Some variables can only be modified by editing this file with a text editor, not via the YaST Firewall module.

![](bbox=[0.113, 0.819, 0.301, 0.892])
