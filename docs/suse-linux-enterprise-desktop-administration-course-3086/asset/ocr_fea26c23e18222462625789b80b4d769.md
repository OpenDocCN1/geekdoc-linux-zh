+   - You can configure the SSH type, authentication, and encryption types in the SSH server configuration file `/etc/ssh/sshd_config`. SSH client options are stored in the `/etc/ssh/ssh_config` file. User-specific SSH client options are stored in `~/.ssh/config`.
+   - You can generate asymmetric SSH encryption keys using the `ssh-keygen` command and view them using the `ssh-keyscan` command. Public encryption keys from remote hosts are stored in `~/.ssh/known_hosts` on the SSH client and `/etc/ssh/ssh_known_hosts` on the SSH server in SSH encryption keys can also be used for authentication.
+   - You can use the `vino-preferences` command to configure a VNC server that can be used to graphically administer your system remotely. You can connect to a remote VNC server using the `vncviewer` command.

# Key Terms

**/bin/ip** — The executable for the ip command. See ip command.

**/etc/ssh/known_hosts** — A file used to store the encryption keys of known SSH hosts.

**/etc/ssh/ssh_config** — The systemwide ssh client program configuration file.

**/etc/ssh/ssh_host_dsa_key** — A file used to store DSA keys for use with SSH.

**/etc/ssh/ssh_host_rsa_key** — A file used to store RSA keys for use with SSH.

**/etc/ssh/sshd_config** — The SSH daemon configuration file.

**/etc/sysconfig/network** — The directory that contains most network configuration information.

**/etc/sysconfig/network/config** — A file that contains network configuration settings such as NetworkManager.

**/etc/sysconfig/SuSEfirewall2** — The file that stores packet filter information for use with the netfilter framework in SUSE Linux.

**~/.ssh/authorized_keys** — A file used to store keys that can be used for SSH authentication.

**~/.ssh/config** — The ssh client program configuration file.

**~/.ssh/id_dsa** — A file used to store a DSA private key for use with SSH2.

**~/.ssh/id_rsa** — A file used to store an RSA private key for use with SSH2.

**~/.ssh/identity** — A file used to store a private key for use with SSH1.

**~/.ssh/identity.pub** — A file used to store a public key for use with SSH1.

**~/.ssh/id_dsa.pub** — A file used to store a DSA public key for use with SSH2.

**~/.ssh/id_rsa.pub** — A file used to store an RSA public key for use with SSH2.

**~/.ssh/known_hosts** — A file used to store the encryption keys of known SSH hosts.

**Advanced Encryption Standard (AES)** — A common symmetric encryption algorithm that uses up to 256-bit keys and is intended to replace 3DES.

**asymmetric encryption** — A type of encryption that uses a public and private key pair. Information encrypted with the public key can be decrypted using the private key and vice versa.

**Blowfish** — A common symmetric encryption algorithm that uses up to 448-bit keys.

**Data Encryption Standard (DES)** — A common symmetric encryption algorithm that uses 56-bit keys.
