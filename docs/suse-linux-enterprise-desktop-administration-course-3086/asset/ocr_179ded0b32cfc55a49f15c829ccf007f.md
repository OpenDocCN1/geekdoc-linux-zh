| Parameter | Description |
|---|---|
| Start iFolder When Logging In to the Desktop | Configure your system to launch Novell iFolder whenever you log in with the local username where you set up the Novell iFolder account. (One method is to make sure Novell iFolder is running when you log out of the desktop so it becomes part of your default desktop session.) For those accounts where you have enabled Remember My Password, synchronization occurs in the background at the specified Synchronization Interval. Otherwise, you must start Novell iFolder manually. |
| Show Confirmation Dialog When Creating iFolders | Select this option to receive a confirmation message each time you create a Novell iFolder, in addition to the normal visual cues such as the Novell iFolder appearing in the list of Novell iFolders. Deselect this option to stop receiving the confirmation message. |
| Notify of Shared iFolders | Select this option to enable a pop-up message in the Notification area whenever you receive a new invitation to share a Novell iFolder. Deselect this option to disable the pop-up messages. You can select Show Available iFolders in the Novell iFolder browser whenever Novell iFolder is running to view a list of Novell iFolders that are available to download on your current computer. |
| Notify of Conflicts | Select this option to enable a pop-up message in the Notification area whenever a conflict occurs when synchronizing files. Deselect this option to disable the pop-up messages for synchronization conflicts. Whenever conflicts occur, the Novell iFolder Error icon is displayed on the Novell iFolder when Novell iFolder is running. |
| Notify When a User Joins | Select this option to enable a pop-up message in the Notification area whenever a user accepts an invitation to share a Novell iFolder. Acceptance is keyed to when the user actually sets up the Novell iFolder on his or her own computer. Deselect this option to disable the pop-up messages for user share confirmation. You can view a complete list of Novell iFolder users whenever Novell iFolder is running by selecting the Novell iFolder and then clicking Share with to open the Novell iFolder Properties dialog box to the Sharing tab. |
| Synchronization | Automatically Synchronize Novell iFolders: Select this check box to enable synchronization for all Novell iFolders on this computer under your current local login or logon identity. Deselect the check box to disable synchronization. Synchronize iFolders Every: Specify the minimum interval to use for synchronizing Novell iFolders on this computer under your current local login or logon identity. Specify the value and units. If you use the Novell iFolder client with Novell iFolder 3.x, the effective minimum synchronization interval is always the largest value of the following settings: - The system policy [default of zero (0)], unless a user policy is set. If a user policy is set, the user policy overrides the system policy, whether the user policy is larger or smaller in value. - The local machine policy, or the setting on the client machine synchronizing with the server. - The Novell iFolder (collection) policy. |

(One method is to make sure Novell iFolder is running when you log out of the desktop so it becomes part of your default desktop session.) For those accounts where you have enabled Remember My Password, synchronization occurs in the background at the specified Synchronization Interval. Otherwise, you must start Novell iFolder manually. |
