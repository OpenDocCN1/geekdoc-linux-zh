**character-oriented device file** A device file which specifies that information be transferred to the device in a character-by-character manner.

**chgrp (change group) command** A command that is used to change the group owner of a file or directory.

**child process** A process that is started by another process.

**chkconfig command** A command that is used to set programs to start or stop in a particular runlevel by altering the appropriate files in the /etc/init.d/rcrunlevel.d directory.

**chmod (change mode) command** A command that is used to change the mode (permissions) of a file or directory.

**chown (change owner) command** A command that is used to change the owner and group owner of a file or directory.

**client application** The application program that receives keyboard and mouse input from the X server and sends screen output to the X server. It can run on the same or different computer than the X server. It is also called the X client.

**command mode** A mode in the vi editor that allows you to perform any available text editing task that is not related to inserting text into the document.

**Common Internet File System (CIFS)** A file- and printer-sharing protocol used by Windows systems. It is commonly called SMB.

**Common UNIX Printing System (CUPS)** The default printing system in SLES.

**Compiz** A composite and window manager that uses Xgl to provide enhanced graphics capabilities to a desktop environment.

**composite manager** A software component that creates composite images within a window manager.

**container object** An LDAP object used to organize leaf objects.

**control file** The XML configuration file used by AutoYaST to configure a SUSE Linux installation.

**cp (copy) command** A command that is used to create copies of files and directories.

**cron** The system service that executes commands repetitively in the future based on information in crontabs.

**crontab (cron table)** A file specifying the commands to be run by the cron daemon and the schedule to run them.

**crontab command** A command that is used to view and edit user cron tables.

**cupsd** The CUPS daemon.

**cylinder** A physical area of a hard disk used to store data. When creating Linux partitions, you are often prompted for the cylinder at which the partition should begin.

**daemon** See daemon process.

**daemon process** A system process that is not associated with a terminal. It stands for Disk and Execution Monitor.

**Data Encryption Standard (DES)** A common symmetric encryption algorithm that uses 56-bit keys.

**date command** A command that is used to set the system time on a Linux system.

**default gateway** The router that connects a network to other networks. IP packets whose destination networks are not included in the routing table are sent to the default gateway.

**default group** See primary group.

**dependencies** Software packages or components that must be installed prior to the installation of a certain software package.

**desktop** The main workspace used by a graphical user interface. In GNOME, the desktop refers to all workspace areas, including the panel.

**desktop environment** A set of software components that standardize the look and feel of the desktop. There are two standard GUI desktop environments available in most Linux distributions: KDE and GNOME.

**Desktop Profile Editor** A graphical utility that can be used to create, modify, and apply desktop profiles using GConf.

**device file** A file used to identify hardware devices such as hard disks and serial ports.

**df command** A command that displays disk usage by file system.

**Diffie-Hellman** A common asymmetric encryption algorithm.

**Digital Signature Algorithm (DSA)** A common asymmetric encryption algorithm.

**Digital Subscriber Line (DSL)** A common Internet connection technology that uses phone lines for high-speed transmission.

**directories** Special files that are used to organize other files on the file system.

**directory** A database that contains information about resources such as user accounts.

**Directory Information Tree (DIT)** The hierarchical structure of an LDAP database.

**directory service** A service that can be used to query a directory for information.

**disable command** A command that prevents print jobs in the print queue from being sent to the printer.

**distinguished name (DN)** A full pathname to an LDAP leaf object.
