# Summary

+   - SUSE Linux uses the CUPS printing system by default.
+   - CUPS uses IPP, but can support the socket, LPD, IPX, and SMB printing protocols.
+   - You can configure a CUPS printers during installation, or after installation using YaST, the GNOME Printers dialog, or by editing the appropriate configuration files in the /etc/cups directory and restarting the CUPS daemon.
