# Detailed Steps to Complete This Exercise

+   1. Log in to the GNOME desktop as `geeko` and open a terminal window.
+   2. View the operating system of the SUSE Linux Enterprise Desktop 10 distribution you are running by entering `uname -o`.
+   3. View the computer (machine) hardware architecture by entering `uname -m`.
+   4. View the processor type for this Linux build by entering `uname -p`.
+   5. View the kernel release of the SUSE Linux Enterprise Desktop 10 distribution you are running by entering `uname -r`.
