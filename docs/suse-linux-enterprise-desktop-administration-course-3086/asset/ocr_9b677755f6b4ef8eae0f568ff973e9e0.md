# Objective 5—Control Mounting of CD-ROM, DVD, and USB Devices

By default, removable media like CD-ROMs, DVDs, and USB storage devices are automatically mounted. The program providing this functionality is the GNOME Volume Manager.

To control the automatic mounting of media, you have to understand how to do the following:

+   - Use the GNOME Volume Manager
+   - Disable Automatic Mounting of Media

# Use the GNOME Volume Manager

The GNOME Volume Manager (gnome-volume-manager) is started automatically when the GNOME desktop is launched. It monitors volume-related events and responds with a user-specified policy.

The user or the system administrator can configure what happens when some media, such as a CD-ROM, is inserted and what commands are executed.
