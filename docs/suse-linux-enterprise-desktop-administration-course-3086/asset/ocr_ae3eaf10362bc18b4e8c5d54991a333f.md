# Finalize the Installation Process

Confirm your hardware settings by selecting Next; then select Finish. When you check Clone This System for Autoyast, an autoyast file is generated and saved as /root/autoinst.xml. You can use this file to set up an identical system.

The system starts the graphical login screen, where you can log in with your previously created user account.

SUSE Linux Enterprise Desktop 10 is now installed on your system.
