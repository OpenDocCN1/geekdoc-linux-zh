# Exercise 2-2: Work with Icons in GNOME

In this exercise, add a new launcher labeled xeyes (for the program /usr/X11R6/bin/xeyes) to your desktop. The icon for the new launcher should be gnome-eog.png. Then, add the applet Geyes to your bottom panel and remove it again.

# Detailed Steps to Complete This Exercise

+   - Part I: Drag an Icon to the Desktop
+   - Part II: Create a New Launcher
+   - Part III: Add an Applet to the Bottom Panel and Remove It Again

# Part I: Drag an Icon to the Desktop

The easiest way to add an icon to the desktop is to drag it from the main menu. To add an icon to start Firefox, do the following:

+   1. Select Computer.
+   2. Select the Firefox icon in the Favorite Applications section and, keeping the left mouse button pressed, drag the icon to the desktop. Note the plus sign while you drag the icon, indicating that the icon will be copied.
+   3. Release the left mouse button. The Firefox icon appears on the desktop.

# Part II: Create a New Launcher

To create a new launcher, do the following:

+   1. Right-click the background of your desktop.
+   2. Select Create Launcher from the pop-up menu.
+   3. In the Name text box, enter `xeyes`.
+   4. In the Command text box, enter `/usr/X11R6/bin/xeyes`.
+   5. Select No Icon.
+   6. From the Browse Icon dialog, select gnome-eog.png.
+   7. Select OK.
+   8. Select OK.

# Part III: Add an Applet to the Bottom Panel and Remove It Again

To add and remove an applet, do the following:

+   1. To add a new applet in the bottom panel, right-click a free space in the bottom panel.
+   2. From the pop-up menu, select Add to Panel.
