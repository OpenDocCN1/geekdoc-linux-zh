If you change the UID of an existing user, the permissions of the files this user owns must be changed. This is done automatically for the files in the user's home directory, but not for files located elsewhere.

![](bbox=[0.108, 0.157, 0.296, 0.235])

If this does not happen automatically, you can change (as root) the permissions of the user files in the home directory by entering `chown -R username /home/username`.

+   - *Home Directory*—Specify the home directory of the user. Normally this is `/home/username`. You can select an existing directory by selecting Browse.
+   - *Home Directory Permission Mode*—The value in this field determines whether or not users can view the content of each other’s home directories. See “Change File Permissions with chmod” for details on this value.
+   - *Empty Home*—No files are copied from `/etc/skel` to the new home directory when you select this option.
+   - *Use Encrypted Home Directory*—In addition to the usual directory structure in `/home/username`, an image file `/home/username.img` is created. This file contains an encrypted file system that is mounted to `/home/username` and decrypted automatically when the user logs in.
+   - *Additional User Information*—This field can contain up to three parts separated by commas. It is often used to enter *office, work phone, home phone*. This information is displayed when you use the `finger` command on this user.
+   - *Login Shell*—From the drop-down list, select the default login shell for this user from the shells installed on your system.
+   - *Default Group*—This is the group to which the user belongs. Select a group from the list of all groups configured on your system.
+   - *Groups*—Select all additional group memberships you want to assign to the user.

To set various password parameters (such as duration of a password), select the Password Settings tab. The window shown in Figure 9-5 appears.

Enter or edit information in the following fields:

+   - *Days before Password Expiration to Issue Warning*—Enter the number of days you want to warn the user that his or her password is about to expire before it actually expires. Enter `-1` to disable the warning.
+   - *Days after Password Expires with Usable Login*—Enter the number of days after the password expires that you will allow users to continue to log in. Enter `-1` for unlimited access.
+   - *Maximum number of days for the same password*—Enter the maximum number of days a user can use the same password before it expires.
+   - *Minimum number of days for the same password*—Enter the minimum age of a password before a user can change it.
