+   - Text files are the most common file type whose contents can be viewed by several utilities such as `cat`, `less`, `head`, and `tail`.
+   - There are many file management commands that exist to create, change the location of, or remove files and directories. The most common of these include `cp`, `mv`, `rm`, `rmdir`, and `mkdir`.
+   - Every file and directory has an inode that contains all file information other than the data and filename itself.
+   - Files can be a link to another file by name or by inode. These are called symbolic and hard links, respectively. You can create linked files using the `ln` command.
+   - You can find files on the file system using a variety of utilities, including the GNOME Search Tool, `find`, `whereis`, and `which`. The `type` command can be used to determine the type of an executable file.

# Key Terms

+   - **.. (double period)** — A command used to represent the user’s parent directory in the directory tree.
+   - **/** — The single root directory in Linux.
+   - **/bin directory** — A directory that contains binary commands for use by all users.
+   - **/boot directory** — A directory that contains the Linux kernel and files used by the boot loader.
+   - **/dataX directory** — A directory typically used to mount non-Linux partitions where X is the partition number.
+   - **/dev directory** — A directory that contains device files.
+   - **/dev/null** — A special null device file that can be used to delete data redirected from a program or file.
+   - **/etc directory** — A directory that contains domains system-specific configuration files.
+   - **/etc/mtab** — A file that contains a list of mounted file systems.
+   - **/home directory** — The default location for user home directories.
+   - **/lib directory** — A directory that contains shared program libraries (used by the commands in /bin and /sbin) as well as kernel modules.
+   - **/media directory** — A directory that is used for accessing (mounting) disks such as floppy disks and CD-ROMs.
+   - **/mnt directory** — A directory that is used for accessing (mounting) disks such as floppy disks and CD-ROMs.
+   - **/opt directory** — A directory that stores additional software program files.
+   - **/proc directory** — A directory that contains process and kernel information.
+   - **/root directory** — The root user’s home directory.
+   - **/sbin directory** — A directory that contains system binary commands used for administration.
+   - **/srv directory** — A directory that contains file content used by Linux network services.
+   - **/sys directory** — A directory that contains current system information.
+   - **/tmp directory** — A directory that holds temporary files created by programs.
+   - **/usr directory** — A directory that contains most system commands and utilities. It stands for UNIX Special Resources or UNIX System Resources.
