# Exercise 14-1: Activate Compiz (Optional, Depending on Hardware Support)

In this exercise, you configure Compiz, provided the hardware supports it. In the first part, using YaST, verify that 3D support is enabled for your graphics adapter.

If 3D support is enabled, activate Compiz for the GNOME desktop in the second part.

+   - Part II: Activate Compiz

# Part I: Verify 3D Support

To verify 3D support, do the following:

+   1. Start the YaST Control Center and select Hardware > Graphics Card and Monitor. The SaX2 X11 Configuration dialog appears.
+   2. The color depth should be set to 16.7 Mio. (24 Bit) and at the bottom of the dialog, the Activate 3D Acceleration option should be checked. If the color depth is set correctly and 3D acceleration is checked, leave the dialog by selecting Cancel.
