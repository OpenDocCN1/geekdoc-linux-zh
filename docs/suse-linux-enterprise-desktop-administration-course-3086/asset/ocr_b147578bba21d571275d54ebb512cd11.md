**Lightweight Directory Access Protocol (LDAP)** A software protocol used to locate resources in a network directory database.

**logical partition** A partition that exists within an extended partition.

**Logical Volume Manager (LVM)** A hard disk partitioning scheme in which partitions are managed by system services and can be resized easily.

**mkfs command** A command used to create file systems on Linux partitions.

**Network Information Service (NIS)** A network service that can be used to manage the configuration of several Linux or UNIX computers.

**primary partition** A main division of a hard disk. There are four available primary partitions.

**proxy** A network server or device that provides Internet access for network computers that request it.

**Redhat Package Manager (RPM)** The default software package management software used on most Linux systems.

**Redundant Array of Independent Disks (RAID)** A series of methods for storing data on different hard disks to improve performance and provide fault tolerance.

**Reiser** The default file system used on SUSE Linux systems.

**runlevel** A Linux system state that depends on the number and type of processes that are currently running.

**Secure Shell (SSH)** A software package that allows for encrypted remote administration of Linux and UNIX systems.

**Serial Advanced Technology Attachment (SATA)** A serial version of EIDE that is commonly used in modern computers.

**Small Computer System Interface (SCSI)** A hard disk technology that is commonly used in servers and high-end workstation computers.

**Software RAID** A RAID implementation that is managed by operating system software.

**swap** An area of a hard disk that is reserved for storing information that is normally stored in computer memory.

**Universal Time Coordinated (UTC)** The global time standard. It is often called Greenwich mean time.

**Virtual Network Computing (VNC)** A software package that allows users to manage remote systems. VNC is available for most operating systems, including Linux and Windows.

**XFS** A Linux filesystem originally developed for SGI UNIX systems that tracks changes made to the file system using a journal file.

**YaST** The main system configuration utility in SUSE Linux. It is also used to perform the SUSE Linux installation process. YaST stands for Yet another Setup Tool.

**YaST Expert Partitioner** A YaST utility that can be used to create and modify partitions as well as RAID and LVM volumes.
