# Manage Users, Groups,\nand Permissions

**Linux is a multiuser system. In other words, several users can work on the system at the same time.** The system must be able to uniquely identify all users, and grant or deny access to resources based on access permissions defined for the resource.

The following key components are used to achieve this:

+   - *Users*—Users are individual accounts on the Linux system.\n- *Groups*—Groups are collections of users. Users are assigned to a group when they are created, and users can be members of several groups.\n- *Ownership*—Every file or directory has an owner and an owning group.\n- *Permissions*—Permissions are set for the owner, the owning group, and those who are neither the owner nor a member of the group. They determine whether user access to a file or directory is granted or denied.

In this section, you learn how to manage user accounts, ownership, and permissions granted to file and directories.
