# Overview of Important Commands

In this part, important commands are listed. Detailed information on individual commands can be obtained by entering

```
man command
```

The commands are sorted according to the following tasks:

+   - Work with Files and Directories
+   - Look for Files and for Content of Files
+   - Display and Modify the Content of Files
+   - Restore Data, Compress, and Archive Files
+   - Administer Users and Groups
+   - Administer Permissions
+   - Administer the System
+   - Administer Processes, Start and Stop the System
+   - Monitor the System
+   - Install Software
+   - Manage Hard Disks and File Systems
+   - Automate Tasks
+   - Repair the System
+   - Use Online Help
+   - Work with Kernel and Modules
