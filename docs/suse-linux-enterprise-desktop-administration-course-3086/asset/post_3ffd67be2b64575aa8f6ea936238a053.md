## Summary

- SUSE Linux uses the CUPS printing system by default.
- CUPS uses IPP, but can support the socket, LPD, IPX, and SMB printing protocols.
- You can configure a CUPS printers during installation, or after installation using YaST, the GNOME Printers dialog, or by editing the appropriate configuration files in the /etc/cups directory and restarting the CUPS daemon.

- CUPS print jobs are sent to a queue directory (`/var/spool/cups`) before being sent to the printer itself. CUPS print queues are configured using the entries in the `/etc/cups/printers.conf` file.
- The CUPS daemon writes logging information to the `/var/log/cups/error_log`, `/var/log/cups/access_log`, and `/var/log/cups/page_log` files. You can control the level of logging by editing the `/etc/cups/cupsd.conf` file.
- Novell iPrint can be used to install, access, and manage IPP printers remotely using a Web browser from a variety of client operating systems. Each client must download a Novell iPrint client to use Novell iPrint.
- Before adding printers to Novell iPrint, you must first create a Driver Store as well as configure a Print Manager with Printer Agents.

## Key Terms

- **/etc/cups/client.conf** — A file that lists remote CUPS servers on a SUSE Linux system.
- **/etc/cups/cupsd.conf** — The main CUPS configuration file.
- **/etc/cups/ppd** — The directory that stores the active configuration files used for a particular printer.
- **/etc/cups/printcap** — A file that is used to store CUPS client configuration information.
- **/etc/cups/printers.conf** — A file that contains CUPS printer definitions.
- **/etc/cups/printcap** — A symbolic link to the `/etc/cups/printcap` file.
- **/var/log/cups/access_log** — A CUPS log file that stores information about network print requests.
- **/var/log/cups/error_log** — A CUPS log file that stores information about the CUPS daemon.
- **/var/log/cups/page_log** — A CUPS log file that stores information about each page that is sent to a printer.
- **/var/spool/cups** — The default print queue directory in SUSE Linux.
- **accept command** — A command that allows print jobs to enter the print queue.
- **Apache** — The default Web server used on most Linux systems. Apache is also used by iPrint.
- **Common UNIX Printing System (CUPS)** — The default printing system in SLES.
- **cupsd** — The CUPS daemon.
- **disable command** — A command that prevents print jobs in the print queue from being sent to the printer.
- **Driver Store** — A repository of print drivers used by iPrint.
- **eDirectory** — A Novell directory service used by services such as iPrint.
- **enable command** — A command that allows print jobs in the print queue to be sent to the printer.
- **ghostscript** — An Open Source utility that can be used to convert and manage PostScript-formatted documents.
- **GNOME Printers dialog** — A dialog that is used to manage printers and print jobs within a SUSE Linux GNOME desktop environment.
- **gnome-cups-manager command** — A command that is used to invoke the expanded GNOME Printers dialog utility.
