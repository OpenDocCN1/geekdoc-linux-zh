
## The Basic Linux Partitioning Scheme

A SUSE Linux Enterprise Desktop 10 installation needs at least two partitions.

- *Swap partition*—This partition is used by Linux to move unused data from the main memory to the hard drive, thus freeing main memory which can then be used by other processes.
- *Root partition*—This partition holds the top (/) of the file system hierarchy, the so-called root directory.

No matter which partition scheme you choose, you always need at least one swap partition and a root partition.

The following guidelines help you determine what software you can install, based on your system’s available hard disk space:

- *1000 MB*—This allows for a minimal installation with no graphical interface. With this configuration, you can only use console applications.
- *1500 MB*—This allows for an installation with a minimum graphical interface. This includes the X Window System and a few graphical applications.
- *3 GB*—This holds the default installation proposed by YaST. This configuration includes a modern desktop environment (such as KDE or GNOME), and provides enough space for several additional applications.
- *5 GB*—This allows for a full installation, including all software packages shipped with SLED 10.

You can put certain directories on separate partitions. If you do this, your root partition can be smaller than outlined above. Any space for data needs to be added to the above.

The optimal partitioning scheme for a desktop or server depends on the purpose of the computer.

On a desktop, you would usually follow the simple scheme outlined above, or put /home on a separate partition. On a server, depending on its purpose and also for security reasons, other directories, such as /var/, /usr/, /tmp/, /srv/, or /opt/, are sometimes put on separate partitions.

![](img/9129877170834ca9d5fdac5319bf5f12_35_0.png)

Today’s computers are equipped with hard disks with capacities of 100 GB and more, providing plenty of space for data. Considering the difficulties involved with changing partitions in an installed system and the size of current hard disks, you should therefore allocate much more space than the above minimum when deciding on the hard disk layout.

To use YaST to change the partition scheme, select the Partitioning headline in the installation proposal. See Figure 1-6.

In the top part of the dialog, YaST displays the automatically generated partitioning proposal.

The lower part of the dialog provides the following options:

- *Accept Proposal*—Accepts the partitioning scheme and returns to the main installation proposal.

### YaST Expert Partitioner

When you start the YaST Expert Partitioner, the screen shown in Figure 1-8 appears.

In the top part of the dialog, YaST lists details of the current partition setup. Depending on your previous choice, the list contains the partitioning proposal created by YaST or the current physical disk setup.

The buttons in the lower part of the dialog are used to create, edit, delete, and resize partitions, as well as to administer LVM (Logical Volume Manager) or RAID (Redundant Array of Independent Disks).

![](img/9129877170834ca9d5fdac5319bf5f12_38_0.png)

Figure 1-8

![](img/9129877170834ca9d5fdac5319bf5f12_38_1.png)

The changes made with the YaST Expert Partitioner are not written to disk until the installation process is started. You can always discard your changes by selecting **Back** or you can restart the Expert Partitioner to make more changes.

The following entries are displayed for every hard disk in your system:

- One entry for the hard disk itself; includes the corresponding device name in the Device column (such as `/dev/sda`).
- One entry for every partition on the hard disk; includes the corresponding device name and partition number in the Device column (such as `/dev/sda1`).

Each entry in the list includes information in the following columns:

- *Device*—Displays the device name of the hard disk or the partition.
- *Size*—Displays the size for the hard disk or partition.

- *F*—When the character “F” is displayed in this column, the partition will be formatted during the installation process.
- *Type*—Displays the partition or hard disk type. Depending on the operating system and the architecture, partitions can have various types, such as Linux native, Linux swap, Win95, FAT 32, or NTFS.
- *Mount*—Displays the mount point of a partition. For swap partitions, the keyword *swap* is used instead.
- *Mount By*—Indicates how the file system is mounted:
  - *K*—Kernel Name
  - *L*—Label
  - *U*—UUID
  - *I*—Device ID
  - *P*—Device Path

- *Start*—Displays the start cylinder of a hard disk or partition. In YaST, hard disk entries always start with 0.
- *End*—Displays the end cylinder of a hard disk or partition.
- *Used By*—Displays information about the system, such as LVM system, using this partition.
- *Label, Device ID, Device Path*—Lists information, in respective columns.

The buttons in the lower part of the dialog let you:

- Create New Partitions
- Edit Existing Partitions
- Delete Existing Partitions
- Resize Existing Partitions
- Perform Expert Tasks

These administrative tasks are covered in more detail in the following sections. Managing LVM volumes and Software RAID are not covered in this course.

## Create New Partitions

Create a new partition by selecting Create. A dialog with one of the following options appears (the options you see depend on your hard disk setup):

- If you have more than one disk in your system, you are asked to select a disk for the new partition first.
- If you do not have an extended partition, you are asked if you want to create a primary or an extended partition.
- If you have an extended partition, and you have space on the hard drive outside the extended partition for additional primary partitions, you are asked if you want to create a primary or a logical partition.

- If you have three primary partitions and an extended partition, you can only create logical partitions.

![](img/9129877170834ca9d5fdac5319bf5f12_40_0.png)

You need enough space on your hard disk to create a new partition. Later in this section you learn how to delete existing partitions to free used disk space.

If you choose to create either a primary or a logical partition, the screen shown in Figure 1-9 appears.

![](img/9129877170834ca9d5fdac5319bf5f12_40_1.png)

**Figure 1-9**

This dialog provides the following options:

- *Format*—This lets you choose one of the following options:
  - *Do not format*—Leaves the newly created partition unformatted. No file system will be created on this new partition. You can select the partition type in the drop-down list.
  - *Format*—Formats the new partition with the file system you select from the File system drop-down list. You can choose from the following file systems:
  - *Ext2*—Formats the partition with the Ext2 file system. Ext2 is an old and proven file system, but it does not include journaling.
  - *Ext3*—Formats the partition with the Ext3 file system. Ext3 is the successor of Ext2 and offers a journaling feature.
