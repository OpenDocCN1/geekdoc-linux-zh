The options shown in Table 10-1 can be used to customize the output of netstat.

| Option | Description |
|---|---|
| `-p` | Shows processes (as root). |
| `-a` | Shows listening and nonlistening sockets (all). |
| `-t` | Shows TCP information. |
| `-u` | Shows UDP information. |
| `-n` | Does not resolve hostnames. |
| `-e` | Displays additional information (extend). |
| `-r` | Displays routing information. |
