
**system users** User accounts that can be used by system services and cannot be used by users to log in to the system interactively.

**Tab window manager (twm)** A small stand-alone window manager which uses few system resources that can be used instead of the KDE or GNOME desktop.

**tail command** A Linux command used to display the last set number of lines of text in a file; by default, the tail command displays the last 10 lines of the file.

**TCP/IP** The default network protocol used on Linux systems. It stands for Transmission Control Protocol/Internet Protocol.

**template** A sample structure used to create new documents within a program such as OpenOffice.org.

**ticket granting ticket (TGT)** The Kerberos ticket that is given to authenticated computers after a successful authentication request.

**TightVNC** A package that provides VNC server capability in SUSE Linux.

**Time To Live (TTL)** A value inside an IP packet that identifies how many more routers the packet may pass through. Each router decrements the TTL of packets that pass through them. When the TTL of a packet reaches zero, it is removed from the network.

**top command** A command that is used to view, renice, and kill the processes on the system that are using the most CPU time.

**touch command** A command that is used to create new files. It was originally used to update the time stamp on a file.

**traceroute command** A command used to identify the route an IP packet takes to a remote host.

**Transmission Control Protocol (TCP)** A part of the TCP/IP protocol suite that provides reliable communication between hosts on a network.

**Transmission Control Protocol/Internet Protocol (TCP/IP)** A suite of protocols that is used to communicate with other computers on a network.

**Triple-DES (3DES)** A common symmetric encryption algorithm that uses 112- or 168-bit keys.

**Trivial File Transfer Protocol** A version of FTP that uses UDP instead of TCP to provide fast connectionless communication between hosts.

**TrustedList** A list of user-added networks in NetworkManager.

**type command** A command used to determine the type of program for a command. The type command can be used to identify aliases and their target commands.

**udev** A Linux software system used to create and manage device files for system devices.

**UID (User ID)** A number that uniquely identifies each system user account.

**umask** A system variable that removes permissions on all new files and directories.

**umask command** A command that is used to view and change the system umask.

**umount command** A command that is used to unmount a device from a mount point directory.

**unalias command** A command used to destroy an alias in memory.

**uname command** A command that displays general system information for a Linux system.

**Uniform Resource Identifier (URI)** A naming convention used to locate resources on a network such as printers.

**Universal Naming Convention (UNC)** A format used to specify a shared resource on a Windows or Samba computer (i.e., \\servername\\sharename).

**Universal Time Coordinated (UTC)** The global time standard. It is often called Greenwich mean time.

**uptime command** A command that displays system statistics as well as the current running time of a Linux system.

**useradd command** A command that is used to add a user account to the system.

**User Datagram Protocol (UDP)** A part of the TCP/IP protocol suite that provides fast but unreliable communication between hosts on a network.

**userdel command** A command that is used to remove a user account from the system.

**usermod command** A command that is used to modify the properties of a user account on the system.

**user process** A process begun by a user that runs on a terminal.

**UTF-8 Unicode Transformation Format** A character encoding format used by all nonroot users in SUSE Linux shells.

**variable** An area of memory used to store information; variables are created from entries in files when the shell is first created after login and are destroyed when the shell is exited upon logout.

**vi editor** The most common text editor on Linux and UNIX systems.

**vim (vi improved) editor** An improved version of the vi editor that is common on Linux systems today.

**vino** A package that provides VNC server capability in SUSE Linux.

**vino-preferences command** A command used to configure VNC server settings in SUSE Linux.

**virtual desktops** Separate workspaces that you can use within a desktop environment such as KDE or GNOME.

**Virtual Network Computing (VNC)** A software package that allows users to manage remote systems. VNC is available for most operating systems, including Linux and Windows.

**Virtual Private Network (VPN)** A logical network that can be created on an existing IP network. Communication on VPNs are secured using encryption.

**virtual terminals** The system components that allow you to log in to and interact with a command-line user interface. You can use and switch between six virtual terminals by default on most Linux systems (tty1–tty6).

**visudo command** A command that is used to edit the /etc/sudoers file with the vi text editor.

**vmlinuz** The filename of the Linux kernel.

**vncviewer command** A command used to connect to a remote computer using VNC.

**w command** A command that displays the users who are currently logged in to a Linux system and their current processes.

**Wake on LAN** A feature of many PXE-capable network cards that allows them to respond to network requests.

**wall (warn all) command** A command that is used to send a message to system users.

**WEP (Wireless Equivalent Privacy)** A technology used to secure wireless communication using encryption.

**whatis command** A command that is used to display the basic usage of a command from the manual pages database.

**whereis command** A command that is used to display the location, manual pages, and source code for a command.

**which command** A command that is used to locate files that exist within directories listed in the PATH variable.

**who command** A command that displays the users logged in to the system as well as the current system runlevel.

**wildcards** Characters that have special meaning on your system when typed at a command prompt. The ? and * characters are common wildcards used to match filenames.

**Winbind** The Linux software component that can be used to communicate with the Active Directory service.

**winbindd** The Winbind daemon.

**window manager** The component of the X Window System that controls the look and feel of windows on the desktop.

**WLAN (Wireless Local Area Network)** A network that consists of computers that communicate via wireless network interfaces.

**workgroup** A name that identifies a group of computers in a Windows network that is not part of a domain.

**WPA (WiFi Protected Access)** A technology used to secure wireless communication using encryption that is stronger than WEP. The latest version of WPA is WPA2.

**write permission** A permission that allows you to open and edit files as well as add or remove directory contents.

**X** See X Window System.

**X11** See X Window System.

**X server** The component of the X Window System that accepts information from client applications and draws graphical images to the screen.

**X Terminal** A virtual terminal that can be started from within the GNOME desktop environment.

**X Window System** The set of software components that provides a graphical user interface in Linux. It is also called X or X11.

**X.org** The default X server used by SUSE Linux.

**XFree86** The traditional X server used on older Linux systems.

**XFS** A Linux filesystem originally developed for SGI UNIX systems that tracks changes made to the file system using a journal file.

**Xgl** An OpenGL-based software architecture that can be used with X.

**xnest** An X server that displays its output within a window in an existing X session.

**YaST** The main configuration tool in SUSE Linux. It stands for Yet another Setup Tool and can be run in graphical or text (ncurses) mode.

**yast command** A command that is used to start the ncurses interface of YaST.

**YaST Control Panel** The main dialog screen in YaST that lists available YaST modules.

**YaST Expert Partitioner** A YaST utility that can be used to create and modify partitions as well as RAID and LVM volumes.

**yast2 command** A command that is used to start the Qt and ncurses interfaces of YaST.

**Yelp** A graphical help program that contains information about the configuration and usage of the SUSE Linux operating system.
