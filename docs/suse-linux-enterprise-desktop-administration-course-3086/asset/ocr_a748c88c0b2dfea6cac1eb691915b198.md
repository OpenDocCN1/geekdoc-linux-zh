# Viewing Your Network Connections

Novell Connections allows you to see what servers and trees you are logged in to. You can refresh connections, set a specific tree as your primary connection, or log out of a tree or server.

+   1. Select **Novell Connections**.
+   2. The dialog shown in Figure 13-19 appears.

![](bbox=[0.107, 0.209, 0.976, 0.678])

Figure 13-19

+   3. Do any of the following:
+      - *To set a connection as the primary connection*—Select the **server** you want to set as the primary connection; then select **Set Primary**.
+      - *To refresh a connection*—Select the **connection** that you want to refresh; then select **Refresh**.
+      - *To disconnect from a connection*—Select the **connection** you want to detach from; then select **Detach**.
+   4. Select **Close**.
