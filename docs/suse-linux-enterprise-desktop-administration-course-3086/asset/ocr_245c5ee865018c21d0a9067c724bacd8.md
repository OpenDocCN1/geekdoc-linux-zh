# Improved Shared Novell iFolders

A Novell iFolder is a local directory that selectively shares and synchronizes files via a central computer with a user-specified group of users.

The Novell iFolder files are accessible to all Novell iFolder members and can be changed by those with the rights to do so. You can access your Novell iFolders across multiple workstations and share them with others.

You work with Novell iFolders directly in your file manager or in the Novell iFolder browser that is part of the client. Within the Novell iFolder, you can set up any subdirectory structure that suits your personal or corporate work habits.

The subdirectory structure is constant across all member Novell iFolders. When you share a Novell iFolder, member users with the Write right can modify the directory structure; those changes apply to all copies of the Novell iFolder.

# Novell iFolder Access Rights

The Novell iFolder client supports the owner and three levels of access for members of a Novell iFolder:

+   - **Owner**—Only one user serves as the owner of a Novell iFolder. This is typically the user who creates the Novell iFolder. The owner user can use the Novell iFolder client to transfer ownership to another member of the Novell iFolder.
+   
+     The owner of a Novell iFolder has the Full Control right. This user has read/write access to the Novell iFolder, manages membership and access rights for member users, and can remove the Full Control right for any member.
+   - **Full Control**—A member of the shared Novell iFolder, with the Full Control access right. This member has read/write access to the Novell iFolder and manages membership and access rights for all users except the owner.
+   - **Read/Write**—A member of the shared Novell iFolder, with the Read/Write access right to directories and files in the Novell iFolder.
+   - **Read Only**—A member of the shared Novell iFolder, with the Read Only access right to directories and files in the Novell iFolder. This member can modify a file, but the local changes are not synchronized to other members' copies of the Novell iFolder.

Any Novell iFolder user can own some Novell iFolders and be a member of other Novell iFolders. As an owner user, you always have the Full Control right. As a member user, your level of access in each shared Novell iFolder can differ, depending on the access granted to you by any member with the Full Control right.

# File Synchronization and Data Management

When you set up a Novell iFolder account, you can enable Remember My Password so that Novell iFolder can synchronize Novell iFolder membership and files in the background as you work.

You can configure the Novell iFolder client to run automatically each time you log in to your computer's desktop environment. The session runs in the background as you work with files in your local Novell iFolders, tracking and logging any changes you make.

You can synchronize the files at specified intervals or on demand.

# Encryption

Novell iFolder 3.4 provides you higher security for your confidential Novell iFolder files, protecting them from intentional or unintentional access by unauthorized people.
