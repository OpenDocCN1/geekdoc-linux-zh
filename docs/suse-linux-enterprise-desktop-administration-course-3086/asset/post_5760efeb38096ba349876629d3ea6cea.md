## Starting the Novell iFolder Client

When Novell iFolder is running, the Novell iFolder Services icon appears in the Notification area of the taskbar. Novell iFolder is integrated in the desktop environment. The Novell iFolder emblem (green “i”) appears on Novell iFolders when they are viewed in a file manager, on the desktop, or in the Novell iFolder browser. The encrypted Novell iFolder is indicated by the emblem (locked folder) on the Novell iFolder.

![](img/9129877170834ca9d5fdac5319bf5f12_539_1.png)

> > **IMPORTANT:** The Notification area of the taskbar must be enabled in order for the Novell iFolder Services icon to be displayed when Novell iFolder is running.

You can work locally with files in your local Novell iFolders at any time. Whenever the Novell iFolder client is running, it logs the changes you make to local Novell iFolder data as you work. If you make changes to local Novell iFolder data when Novell iFolder is not running, Novell iFolder identifies and logs the differences the next time you start Novell iFolder.

When Novell iFolder is not running, Novell iFolders appear as normal folders in the file manager or on the desktop. You can access files in your local copy of a Novell iFolder, but you cannot manage Novell iFolders. In addition, you must log in to an account to create a Novell iFolder or synchronize its files.

There are two ways to start Novell iFolder:

- Start Novell iFolder Automatically on Login
- Start Novell iFolder on Demand

For information about stopping the Novell iFolder client, see “Exiting the Novell iFolder Client.”

## Start Novell iFolder Automatically on Login

To enable Novell iFolder to start automatically when you log in to the desktop, do one of the following:

- Open the Applications menu, select More Applications, locate and right-click iFolder 3, and then select Add to Startup Programs from the menu. See Figure 13-32.
- Make sure Novell iFolder is running and save the session setup using Computer > Control Center > System > Sessions. Select this session option when you log in to the desktop.
- Open a terminal window, log in as the root user, and then run /opt/gnome/bin/gnome-session-properties to add Novell iFolder as a program to start when you log in to your computer.

![](img/9129877170834ca9d5fdac5319bf5f12_540_0.png)

Figure 13-32

To disable Novell iFolder from starting automatically on login, do one of the following:

- Open the Applications menu, locate and right-click iFolder 3, and select Remove from Startup Programs.
- Make sure Novell iFolder is not running when you log out; then save the session setup. Select this session option when you log in to the desktop.

## Start Novell iFolder on Demand

- 1. Log in to your computer with the local Linux user identity you want to use when you create Novell iFolders.
- 2. Use one of the following methods to start Novell iFolder:
  - In the taskbar, open the Applications menu, select More Applications, locate Novell iFolder 3 by searching or scrolling through the available options, right-click Novell iFolder 3, and then select Start iFolder 3.
  - Open a terminal shell; then enter
    /opt/novell/ifolder3/bin/ifolder

## Exiting the Novell iFolder Client

To exit the Novell iFolder client, right-click the Novell iFolder Services icon in the Notification area; then select Quit. See Figure 13-33.

![](img/9129877170834ca9d5fdac5319bf5f12_541_0.png)

Figure 13-33

Files are synchronized with your Novell iFolder server account only when you are connected to the Novell iFolder server. You can stop synchronization by logging out of an account. Novell iFolder continues to run in the background.

## Configuring a Novell iFolder Account

Use the Novell iFolder Account Assistant to add and configure a new account. You must configure at least one Novell iFolder account before you can create Novell iFolders or share Novell iFolders on your system.

You can create only one account for any given Novell iFolder host service, but you may have multiple accounts. You can log in separately to each account and be logged in concurrently to multiple accounts.

Multiple users with different local login identities can have Novell iFolders on the same computer. Novell iFolder prompts the active user to set up an account the first time the Novell iFolder client runs under that local user identity.

To configure a new account:

- 1. Access the Novell iFolder Account Assistant, using one of the following methods. See Figure 13-34.

![](img/9129877170834ca9d5fdac5319bf5f12_541_1.png)

Figure 13-34

- The first time you start Novell iFolder under your current local login identity, Novell iFolder prompts you to set up a Novell iFolder account. To go directly to the Novell iFolder Account Assistant, select Yes.
- Right-click the Novell iFolder Services icon in the Notification area, open the Novell iFolder Preferences dialog box on the Accounts tab by selecting Account Settings, and then open the Novell iFolder Account Assistant by selecting Add.

2. Follow the on-screen instructions to specify the values shown in Table 13-2.

| Parameters | Description |
|---|---|
| Novell iFolder Server Address | The DNS name or IP address of the Novell iFolder enterprise server where you have an account. Get this information from your Novell iFolder administrator. For example: `svr21.example.com` or `192.168.1.1` |
| Make This My Default Server | Select this option to set the current server as your default server. This will allow the Novell iFolder to select this server automatically when adding new folders. |
| Username | Specify your user identity for this account. Your Novell iFolder administrator decides whether the format you should use is your network user ID (LDAP common name) or your e-mail address. For example, if your name is John Smith with a user ID of `j.smith` and an e-mail address of `john.smith@example.com`, your administrator configures a setting for the server that determines which of the two formats to accept in the User Name field for authentication purposes. |
| Password | Specify the password for your username. |
| Remember My Password | Select Remember My Password to log in automatically to this iFolder account whenever you log in to your computer. If your network password changes, automatic authentication fails gracefully the next time Novell iFolder attempts to log in to the Novell iFolder account. Novell iFolder prompts you to log in with your new password and allows you to specify and save the new password. |
| Account Is Default | When you have multiple accounts, select Account Is Default to make this account the one selected by default in the drop-down list of accounts when you create and upload Novell iFolders. |
