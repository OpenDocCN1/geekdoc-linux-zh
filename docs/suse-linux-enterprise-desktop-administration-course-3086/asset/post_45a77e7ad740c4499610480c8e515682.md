## Overview of Novell iFolder

Novell iFolder is a file-sharing application for Linux and Windows clients. You can share files in multiple Novell iFolders, each with a different group of users. You control who can participate in a Novell iFolder and the access level for each member. You can also participate in Novell iFolders that others share with you.

- Benefits of Novell iFolder
- Key Features of Novell iFolder

## Benefits of Novell iFolder

Novell iFolder provides the following benefits:

- Integrates with your native desktop environment, making it easy to create and manage multiple Novell iFolders.
- Is highly scalable and flexible, with no practical limit on the number of Novell iFolders per user or on the number of members per Novell iFolder.
- With encryption enabled, protects data as it travels across the wire and while stored on the Novell iFolder server.
- With enhanced Web access console, a Web browser can be used to access your files on the Novell iFolder server from any workstation without the Novell iFolder client.
- Allows you to easily and selectively share personal and business files.
- Allows you to control the access level of member users of the Novell iFolders you own or, where you have the necessary rights, to control the access rights of members.
- Transparently updates your files to member Novell iFolders on multiple workstations.
- When Novell iFolder is running, tracks and logs changes made while you work offline and synchronizes those changes when you connect to the server.
- Provides secure authentication of members who access a Novell iFolder to synchronize its data.
- Offers an alternative to exchanging files via e-mail, avoiding the file-size limits on e-mail attachments and reducing your e-mail storage requirements.

## The Novell iFolder Client

The Novell iFolder client integrates with your operating system to provide Novell iFolder services in your native desktop environment. The Novell iFolder client allows you to manage your own Novell iFolders and to select which shared Novell iFolders to set up on each computer. Novell iFolder supports the following operating systems:

- Novell Linux Desktop 9
- SUSE Linux Enterprise Desktop 10 (for Novell iFolder 3.4 and later)
- Windows 2000/XP/2003
- Open SUSE 10.2 and later

## Novell iFolder Account

You must configure at least one Novell iFolder account before you can create Novell iFolders. A Novell iFolder account is created when a Novell iFolder services administrator provisions you as a Novell iFolder user for a Novell iFolder server. The administrator provides you with a username and password. For an enterprise, this might be your username or e-mail address and the related password. A Novell iFolder session begins when you log in to a Novell iFolder services account and ends when you log out, or when you exit the Novell iFolder client. Your Novell iFolders synchronize files with other active Novell iFolders only when your session is active and you are working online. You can access data in your local Novell iFolders at any time, whether you are logged in to the account, or not.

## Improved Shared Novell iFolders

A Novell iFolder is a local directory that selectively shares and synchronizes files via a central computer with a user-specified group of users.

The Novell iFolder files are accessible to all Novell iFolder members and can be changed by those with the rights to do so. You can access your Novell iFolders across multiple workstations and share them with others.

You work with Novell iFolders directly in your file manager or in the Novell iFolder browser that is part of the client. Within the Novell iFolder, you can set up any subdirectory structure that suits your personal or corporate work habits.

The subdirectory structure is constant across all member Novell iFolders. When you share a Novell iFolder, member users with the Write right can modify the directory structure; those changes apply to all copies of the Novell iFolder.

## Novell iFolder Access Rights

The Novell iFolder client supports the owner and three levels of access for members of a Novell iFolder:

- **Owner**—Only one user serves as the owner of a Novell iFolder. This is typically the user who creates the Novell iFolder. The owner user can use the Novell iFolder client to transfer ownership to another member of the Novell iFolder.

The owner of a Novell iFolder has the Full Control right. This user has read/write access to the Novell iFolder, manages membership and access rights for member users, and can remove the Full Control right for any member.
- **Full Control**—A member of the shared Novell iFolder, with the Full Control access right. This member has read/write access to the Novell iFolder and manages membership and access rights for all users except the owner.
- **Read/Write**—A member of the shared Novell iFolder, with the Read/Write access right to directories and files in the Novell iFolder.
- **Read Only**—A member of the shared Novell iFolder, with the Read Only access right to directories and files in the Novell iFolder. This member can modify a file, but the local changes are not synchronized to other members' copies of the Novell iFolder.

Any Novell iFolder user can own some Novell iFolders and be a member of other Novell iFolders. As an owner user, you always have the Full Control right. As a member user, your level of access in each shared Novell iFolder can differ, depending on the access granted to you by any member with the Full Control right.

## File Synchronization and Data Management

When you set up a Novell iFolder account, you can enable Remember My Password so that Novell iFolder can synchronize Novell iFolder membership and files in the background as you work.

You can configure the Novell iFolder client to run automatically each time you log in to your computer's desktop environment. The session runs in the background as you work with files in your local Novell iFolders, tracking and logging any changes you make.

You can synchronize the files at specified intervals or on demand.

## Encryption

Novell iFolder 3.4 provides you higher security for your confidential Novell iFolder files, protecting them from intentional or unintentional access by unauthorized people.

In the past, data security was not ensured on the server side and hence the data was accessible to the administrator or someone hacking the server.

When you are accessing Novell iFolder files via an ISP provider, an unauthorized user could inadvertently stumble across your confidential files. Now, you can save your encrypted files on servers and retrieve them through a passphrase known only to you.

Novell iFolder provides optional Blowfish encryption to ensure the security of your files during synchronization. If you enable this option, you specify the encryption passphrase that Novell iFolder uses to create the encryption keys for encrypting and decrypting your files.

With encryption, Novell iFolder provides secure transport across public and private IP connections and secure storage on the Novell iFolder server. Your sensitive documents remain private as they travel and reside anywhere other than your local workstations.

If you forget your passphrase, the recovery agent you have selected during the creation of encrypted Novell iFolder will help you recover your data.

## Enhanced Web Access

Novell iFolder provides an enhanced Web interface that allows you to access your Novell iFolder files on remote servers.

With the enhanced Web Access console, you can use a Web browser to access your files on the Novell iFolder server from any workstation without the Novell iFolder client. It will also enable you to perform all the operations equivalent to that of Novell iFolder client.

You can create, browse, share, and delete Novell iFolders, generate reports and upload files via the Web Access console. Mobile users can also make use of this facility through the Web.

## Synchronization Log

The synchronization log displays a log of your Novell iFolder background activity, such as uploading and downloading files for different Novell iFolders.
