# Use the GNOME File Manager (Nautilus)

GNOME provides its own file manager (called Nautilus). See Figure 2-15.

![](bbox=[0.091, 0.252, 0.83, 0.69])

**Figure 2-15**

You can start Nautilus by selecting the username’s Home icon on the desktop or by selecting Nautilus from the main menu. By default Nautilus is marked as a favorite application.

Normally Nautilus shows the content of the user’s home directory after starting. The right frame of the Nautilus window shows the content of the current directory.
