# Part III: Create More Files

To create more files, do the following:

+   1. Start the Nautilus file manager by selecting geeko’s Home icon at the desktop.
+   2. Create a new file by right-clicking the file view frame and selecting Create Document > Empty File.
+   3. Enter a filename of My; then press Enter.
+   4. Create a new file by right-clicking the file view frame and selecting Create Document > Empty File.
+   5. Enter a filename of File; then press Enter.
+   6. Create a new file by right-clicking the file view window and selecting Create Document > Empty File.
+   7. Enter a filename of My File; then press Enter.
+   8. Close the Nautilus window.

# Part IV: Mask Special Characters

To mask special characters, do the following:

+   1. From the terminal window, list the My and File files by entering
+   
+      `ls --1 My File`
+   
+   2. List the My File file by entering
+   
+      `ls --1 My\ File`
+   
+   3. Remove the My, File, and My File files by entering
+   
+      `rm My File My\ File`
+   
+   4. Verify that the files have been removed by entering
+   
+      `ls --1`
+   
+   5. Close the terminal window.

# Objective 4—Get to Know Linux Text Editors

Because most of the services of a Linux computer are configured by editing an ASCII file, you need a text editor. A lot of text editors are available in Linux, including the following:

+   - vi
+   - emacs
+   - xemacs
+   - xedit
+   - gedit
+   - kwrite
