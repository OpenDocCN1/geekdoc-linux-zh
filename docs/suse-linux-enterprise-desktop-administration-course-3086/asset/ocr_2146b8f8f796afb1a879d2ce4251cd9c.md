Back at the login screen, four options appear in the lower-left corner:

+   - *Language*—Select the language of the desktop environment.
+   - *Session*—You can choose a window manager other than GNOME. In this student manual, we cover only GNOME (the default window manager). Basic information about the KDE environment is provided in Appendix A.
+   - *Reboot*—Reboots the system.
+   - *Shut Down*—Shuts down your computer.

Older computers that do not have power management and cannot switch themselves off can be switched off when the following message appears:

```
Master Resource Control: runlevel 0 has been reached
```

If you switch the machine off too soon, you could lose data.

You can also choose to shut down the computer directly from the GNOME desktop by selecting Shutdown on the right side of the Computer menu. In this case the confirmation dialog is displayed as shown in Figure 2-6.
