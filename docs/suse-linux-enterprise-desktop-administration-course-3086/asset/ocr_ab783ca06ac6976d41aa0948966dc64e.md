dmesg command A command that displays hardware-related boot messages from the Linux kernel.

Domain Name System (DNS) The naming system used on the Internet. Each host is identified by a hostname and domain name.

DNS server A server that contains records for hosts on a network. It can be queried to resolve a hostname to an IP address.

domain name The name of the DNS domain that a computer on a TCP/IP network belongs to.

driver A software component used by the operating system to control hardware devices such as network devices.

Driver Store A repository of print drivers used by iPrint.

du command A command that displays disk usage by directory.

Dynamic Host Configuration Protocol (DHCP) A network protocol that is used to provide TCP/IP configuration information to hosts that request it.

echo command A command used to display or echo output to the terminal screen—it can be used to view the contents of variables.

eDirectory The directory service used on Novell networks.

effective group See primary group.

enable command A command that allows print jobs in the print queue to be sent to the printer.

Enhanced Integrated Drive Electronics (EIDE) A common hard drive technology that provides faster transfer speeds than IDE.

entry A reference to an LDAP object.

environment variables Variables that are available to the current shell and all programs executed by the shell.

ESSID (Extended Service Set Identifier) A name that identifies a host on a wireless network.

Evolution A common e-mail client application on Linux systems today.

execute permission A permission that allows you to execute files as well as access directory contents.

Ext2 The traditional file system used on Linux partitions.

Ext3 An enhanced version of Ext2 that tracks changes made to the file system using a journal file.

extended partition A primary partition that can contain logical partitions.

Extensible Markup Language (XML) A hierarchical data storage format used by many programs and technologies today.

facilities Areas of the system that the Syslog daemon monitors.

fdisk command A command that is used to create and modify partitions on Linux systems.

fg command A command that is used to force a background process to run in the foreground.

FIFOs See named pipes.

File Allocation Table (FAT) The traditional file system used on Windows partitions.

File Transfer Protocol (FTP) The most common protocol used to transfer files on the Internet.

Filesystem Hierarchy Standard (FHS) A standard outlining the location of set files and directories on a Linux system.

filters Expressions used by the Syslog daemon to determine whether an event should be logged or not.

find command A command that is used to find files on the file system using various criteria.

finger command A command that displays login and account information regarding local and remote users.

Firefox The most common Open Source Web browser used on computer systems today.

firewall A software feature that allows a host to drop IP packets that meet certain criteria.

foreground process A process that runs in your terminal and must finish execution before you receive your shell prompt.

FQDN (Fully Qualified Domain Name) A name that refers to a resource on a TCP/IP network. It consists of a hostname followed by a domain name.

GConf The system software used to configure GNOME preferences.

gconf d The GConf daemon.

gconf-editor command A command that is used to invoke the graphical GConf editor.

gconftool-2 command A command that is used to invoke the terminal-based GConf editor.

gedit command A command used to invoke the GNOME graphical text editor.

ghostscript An Open Source utility that can be used to convert and manage PostScript-formatted documents.

GID (Group ID) A number that uniquely identifies system groups.

GNOME A common Linux desktop environment that uses the GNOME window manager. GNOME stands for GNU Object Model Environment.
