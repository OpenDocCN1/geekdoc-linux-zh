# Detailed Steps to Complete This Exercise

Do the following:

+   1. Install Novell iFolder 3 client on the SLED 10 workstation.
+   
+   Although the Novell iFolder 3 client is not available on the SUSE Linux Enterprise Desktop 10 installation media, you can download the Novell iFolder 3 client software rpm files from www.ifolder.com.
+   
+   For this exercise, we have included the Novell iFolder 3 client rpm files on 3086 Course DVD 2.
+   
+   Do the following:
+   
+   a. Insert the 3086 Course DVD 2 into the DVD drive of your workstation.
+   After a few moments, a 3086_Course_DVD File Browser window opens on the SLED 10 desktop.
+   
+   b. From the File Browser window, double-click the exercises folder and in this folder, double-click the 3086_13 folder; then select and drag the iFolder_Client folder to the SLED 10 desktop.
+   Close the File Browser window.
+   
+   c. Remove the 3086 Course DVD 2 from your DVD drive.
+   
+   d. From the SLED 10 desktop, right-click the iFolder_Client folder; then select Properties.
+   An iFolder_Client Properties dialog appears.
+   
+   e. Select the Permissions tab.
+   The dialog shown in Figure 13-39 appears.
