## Summary

- A SUSE Linux installation is typically started by booting from DVD installation media and selecting options from an installation boot screen.
- To help remedy installation problems, you can choose the Installation--ACPI Disabled, the Installation--APIC Disabled, or Installation--Safe Settings installation options from the installation boot screen. The installation boot screen can also be used to check your system for memory errors, boot an installed Linux system, and repair a damaged Linux installation.
- After the installation program has loaded into computer memory, YaST prompts you for installation settings. These include the system language, installation mode, time zone, partition and file system configuration, and software package selection. You can also select the Expert tab of YaST to configure advanced options such as runlevel and boot loader configuration.
- Before Linux can use a hard disk, it must first be partitioned. You can create up to four primary partitions on a single hard disk, or up to three primary partitions and an extended partition. Extended partitions can be further divided into logical partitions. All partitions are given a device name that starts with /dev/.
- At minimum, you must create a root and swap partition during an SLES installation. The size of these partitions depends on the packages selected for installation.
- The YaST Expert Partitioner allows you to create RAID, LVM, and EVMS partitions in addition to simple Linux partitions. Alternatively, you can resize and use existing partitions on the hard disk.
- On the first boot following package installation, you are prompted for a root user password, as well as network configuration settings, Novell Customer Center configuration, authentication type, and additional user accounts.
- At the end of the installation process, you can change hardware device settings for graphics cards, monitors, printers, sound cards, TV Cards, and Bluetooth devices, as well as save installation choices to an Autoyast file to automate future installations.

## Key Terms

- **/etc/fstab**  The file that contains partition mounting information. It is used to mount file systems at system initialization.
- **/etc/passwd**  The file typically used to store user account information on Linux systems.
- **/etc/shadow**  The file typically used to store user account password information on Linux systems.
- **/root/autoinst.xml**  A file generated by a SUSE Linux installation for use with Autoyast.
- **Advanced Configuration and Power Interface (ACPI)**  A standard that allows the operating system to control the power used by system components.
- **Advanced Programmable Interrupt Controller (APIC)**  A device that coordinates the sending of information between hardware devices. It is commonly used on motherboards that have more than one processor.
- **Autoyast**  A SUSE Linux software component that can be used to automate SUSE Linux installations by using installation configuration information stored in an XML file.
- **Blowfish**  The default encryption algorithm used to encrypt user account passwords in SUSE Linux.
- **Bluetooth**  A low-power wireless technology used by many computer peripheral components such as mice and keyboards.
- **cylinder**  A physical area of a hard disk used to store data. When creating Linux partitions, you are often prompted for the cylinder at which the partition should begin.
- **dependencies**  Software packages or components that must be installed prior to the installation of a certain software package.
- **Digital Subscriber Line (DSL)**  A common Internet connection technology that uses phone lines for high-speed transmission.
- **Dynamic Host Configuration Protocol (DHCP)**  A network protocol that is used to provide TCP/IP configuration information to hosts that request it.
- **Enhanced Integrated Drive Electronics (EIDE)**  A common hard drive technology that provides faster transfer speeds than IDE.
- **Ext2**  The traditional file system used on Linux partitions.
- **Ext3**  An enhanced version of Ext2 that tracks changes made to the file system using a journal file.
- **extended partition**  A primary partition that can contain logical partitions.
- **fdisk command**  A command used to create and modify partitions on Linux systems.
- **File Allocation Table (FAT)**  The traditional file system used on Windows partitions.
- **Firewall**  A technology that restricts access to a computer from remote hosts across a network.
- **Hostname**  A name that identifies a Linux computer on a network.
- **Integrated Drive Electronics (IDE)**  A low-cost hard disk technology that is commonly used in workstation computers.
- **Integrated Services Digital Network (ISDN)**  An Internet connection technology that uses telephone lines to achieve faster transfer rates than traditional modems.
- **IPv6**  The new TCP/IP protocol version that uses 128 bits to identify hosts on a network.
