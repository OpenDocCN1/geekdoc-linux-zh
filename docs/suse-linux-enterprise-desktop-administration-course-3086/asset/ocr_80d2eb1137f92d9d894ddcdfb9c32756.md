# Kicker

To add new icons or applets to the control panel, right-click on a free area of the panel, and then select Add Application to Panel or Add Applet to Panel.

To remove a program from the control panel, right-click its icon in the control panel and then select Remove program Button.

To move icons in the panel, hold down the middle mouse button or choose Move program Button from the context menu.
