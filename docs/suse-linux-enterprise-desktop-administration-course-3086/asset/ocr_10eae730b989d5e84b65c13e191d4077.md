The GNOME keyring is an application that allows you to store various credentials (usernames and corresponding passwords) and protect them with a password.

The advantage of using the GNOME keyring is that you only have to remember one password to unlock the encrypted keyring that contains various usernames and corresponding passwords for different applications. You can manage your passwords with the gnome-keyring-manager application.
