
- You can change user account passwords, lock user accounts, and control password expiry settings using the `passwd` command.
- YaST can be used to perform all user and group management functions.
- You can assign read, write, and execute permissions to files and directories. The definitions of these permissions are separate between files and directories. In addition, there are three special file and directory permissions: SUID, SGID, and sticky bit.
- Permissions can be set on the owner of a file (owner), members of the group of the file (group), as well as everyone else on the system (others) using the `chmod` command. Similarly, you can change the owner and group owner for a file using the `chown` and `chgrp` commands. File and directory permissions can also be set using a desktop environment.
- New files and directories receive default permissions from the system less the value of the umask variable.
- Encryption can be used as an alternative to file and directory permissions. YaST can be used to encrypt home directories and file systems such that only certain users will have the ability to decrypt the files within.

## Key Terms

- **/etc/passwd** — A file that contains default values used when changing passwords such as an encryption algorithm.
- **/etc/default/useradd** — A file that contains default values used when creating user accounts.
- **/etc/group** — The file that contains system groups and their members.
- **/etc/init.d/boot.crypto** — A file read at system initialization to decrypt encrypted partitions. It prompts you for the password used to decrypt a partition.
- **/etc/login.defs** — A file that contains default values used when creating user accounts.
- **/etc/passwd** — The file that contains user account information such as name, UID, primary group, home directory, and shell.
- **/etc/profile.local** — A file that can be used to store systemwide variables such as umask.
- **/etc/shadow** — The file that typically contains encrypted passwords and password expiry information for user accounts on the system.
- **/etc/shells** — A file that lists valid system shells such as /bin/bash.
- **/etc/skel** — A directory that contains files and directories that are copied to all new users’ home directories after they are created.
- **/etc/sudoers** — A file that lists the users who are allowed to run certain commands as other users.
- **Blowfish** — An encryption method used to encrypt Linux passwords.
- **chgrp (change group) command** — A command that is used to change the group owner of a file or directory.
- **chmod (change mode) command** — A command that is used to change the mode (permissions) of a file or directory.
- **chown (change owner) command** — A command that is used to change the owner and group owner of a file or directory.

**default group**  See primary group.

**effective group**  See primary group.

**execute permission**  A permission that allows you to execute files as well as access directory contents.

**GID (Group ID)**  A number that uniquely identifies system groups.

**gnomesu (GNOME switch user) command**  A command that is used to run a program as another user within a GNOME desktop environment.

**gpasswd command**  A command that is used to set passwords for group accounts.

**group**  When referring to a long file or directory listing, it represents the group ownership of a file or directory.

**groupadd command**  A command that is used to add a group to the system.

**groupdel command**  A command that is used to delete a group from the system.

**groupmod command**  A command that is used to modify the name, membership, or GID of a group on the system.

**groups command**  A command that displays the groups that a user is a member of.

**id command**  A command that displays the UID and GIDs associated with a user account.

**mkpasswd command**  A command that is used to create an encrypted password for use with user or group accounts.

**multitasking**  A feature of the Linux operating system that allows multiple processes to run on a single CPU.

**multithreading**  A feature of the Linux operating system that allows parts of processes (threads) to run independently from one another on the system.

**multiuser**  A feature of the Linux operating system that allows multiple users to interact with it simultaneously.

**Nautilus**  The graphical file manager within a SUSE Linux desktop environment.

**newgroup command**  A command that is used to change the current primary group for a user account.

**normal users**  See regular users.

**other**  When referring to a long file or directory listing, it represents all users on the Linux system who are not the owner or a member of the group on the file or directory.

**owner**  The user whose name appears in a long listing of a file or directory and who typically has the most permissions to that file or directory.

**passwd command**  A command that is used to modify user passwords and expiry information as well as lock and unlock user accounts.

**preemptive multitasking**  A feature of the Linux operating system that allows several processes to run simultaneously; the Linux kernel determines how much time each process has to execute.

**primary group**  The group specified for a user in the /etc/passwd file that becomes the group owner on newly created files and directories.

**process**  A program that is currently executing on the system and using system resources.

**program**  An executable file on a file system. Programs become processes when they are executed.

**read permission**  A permission that allows you to open and read files as well as list directory contents.

**regular users**  User accounts that can be used to log in to the system interactively.

**secondary group**  A group that a user belongs to that is not the user’s primary group.

**Set Group ID (SGID)**  A special permission set on executable files and directories. When you run an executable program that has the SGID permission set, you become the group owner of the executable file for the duration of the program. On a directory, the SGID sets the group that gets attached to newly created files.

**Set User ID (SUID)**  A special permission set on executable files. When you run an executable program that has the SUID permission set, you become the owner of the executable file for the duration of the program.

**sticky bit**  A special permission that is set on directories that prevents users from removing files that they do not own.

**su (switch user) command**  A command that is used to change the current user account.

**sudo command**  A command that is used to run commands as another user via entries in /etc/sudoers.

**system users**  User accounts that can be used by system services and cannot be used by users to log in to the system interactively.

**UID (User ID)**  A number that uniquely identifies each system user account.

**umask**  A system variable that removes permissions on all new files and directories.

**umask command**  A command that is used to view and change the system umask.

**useradd command**  A command that is used to add a user account to the system.

**userdel command**  A command that is used to remove a user account from the system.

**usermod command**  A command that is used to modify the properties of a user account on the system.

**visudo command**  A command that is used to edit the /etc/sudoers file with the vi text editor.

**wall (warn all) command**  A command that is used to send a message to system users.

**write permission**  A permission that allows you to open and edit files as well as add or remove directory contents.
