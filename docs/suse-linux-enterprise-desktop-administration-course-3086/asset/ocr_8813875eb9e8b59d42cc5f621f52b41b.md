# Exercise 12-2: Printing with the Novell iPrint Client

In this exercise, you install and use the Novell iPrint client.

Although Novell iPrint is already configured on the DA-OES Linux server for access by the Digital Airlines employees, you have not installed a Novell iPrint printer on your own SUSE Linux Enterprise Desktop 10 workstation.

You decide to install and use the HP DeskJet printer.

Do the following:

+   1. From your DAx SLED 10 workstation, open the Firefox Web browser; then access the Novell iPrint page on the DA-OES server by entering the following URL:
+   
+      *http://da-oes.digitalairlines.com/ipp*
+   
+      A list of Novell iPrint printers on server DA-OES appears as shown in Figure 12-32, with the HP-DJ printer (HP DeskJet) printer listed.
