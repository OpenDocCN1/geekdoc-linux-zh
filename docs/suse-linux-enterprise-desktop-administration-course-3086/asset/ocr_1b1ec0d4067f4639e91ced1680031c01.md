**Virtual Network Computing (VNC)** A software package that allows users to manage remote systems. VNC is available for most operating systems, including Linux and Windows.

**Virtual Private Network (VPN)** A logical network that can be created on an existing IP network. Communication on VPNs are secured using encryption.

**virtual terminals** The system components that allow you to log in to and interact with a command-line user interface. You can use and switch between six virtual terminals by default on most Linux systems (tty1–tty6).

**visudo command** A command that is used to edit the /etc/sudoers file with the vi text editor.

**vmlinuz** The filename of the Linux kernel.

**vncviewer command** A command used to connect to a remote computer using VNC.

**w command** A command that displays the users who are currently logged in to a Linux system and their current processes.

**Wake on LAN** A feature of many PXE-capable network cards that allows them to respond to network requests.

**wall (warn all) command** A command that is used to send a message to system users.

**WEP (Wireless Equivalent Privacy)** A technology used to secure wireless communication using encryption.

**whatis command** A command that is used to display the basic usage of a command from the manual pages database.

**whereis command** A command that is used to display the location, manual pages, and source code for a command.

**which command** A command that is used to locate files that exist within directories listed in the PATH variable.

**who command** A command that displays the users logged in to the system as well as the current system runlevel.

**wildcards** Characters that have special meaning on your system when typed at a command prompt. The ? and * characters are common wildcards used to match filenames.

**Winbind** The Linux software component that can be used to communicate with the Active Directory service.

**winbindd** The Winbind daemon.

**window manager** The component of the X Window System that controls the look and feel of windows on the desktop.

**WLAN (Wireless Local Area Network)** A network that consists of computers that communicate via wireless network interfaces.

**workgroup** A name that identifies a group of computers in a Windows network that is not part of a domain.

**WPA (WiFi Protected Access)** A technology used to secure wireless communication using encryption that is stronger than WEP. The latest version of WPA is WPA2.

**write permission** A permission that allows you to open and edit files as well as add or remove directory contents.

**X** See X Window System.

**X11** See X Window System.

**X server** The component of the X Window System that accepts information from client applications and draws graphical images to the screen.

**X Terminal** A virtual terminal that can be started from within the GNOME desktop environment.

**X Window System** The set of software components that provides a graphical user interface in Linux. It is also called X or X11.

**X.org** The default X server used by SUSE Linux.

**XFree86** The traditional X server used on older Linux systems.

**XFS** A Linux filesystem originally developed for SGI UNIX systems that tracks changes made to the file system using a journal file.

**Xgl** An OpenGL-based software architecture that can be used with X.

**xnest** An X server that displays its output within a window in an existing X session.

**YaST** The main configuration tool in SUSE Linux. It stands for Yet another Setup Tool and can be run in graphical or text (ncurses) mode.

**yast command** A command that is used to start the ncurses interface of YaST.

**YaST Control Panel** The main dialog screen in YaST that lists available YaST modules.

**YaST Expert Partitioner** A YaST utility that can be used to create and modify partitions as well as RAID and LVM volumes.

**yast2 command** A command that is used to start the Qt and ncurses interfaces of YaST.

**Yelp** A graphical help program that contains information about the configuration and usage of the SUSE Linux operating system.
