While GNOME is installed by default on SUSE Linux Enterprise Desktop 10, you are not limited to GNOME as your graphical environment. The very common graphical desktop environment KDE is included on the SUSE Linux Enterprise Desktop DVD.

The following explains how to use KDE on SUSE Linux Enterprise Desktop 10:

+   - Objective 1—Install the KDE Desktop Environment
+   - Objective 2—Log In
+   - Objective 3—Log Out and Shut Down
+   - Objective 4—Identify KDE Desktop Components
+   - Objective 5—Manage Icons in the KDE Environment
+   - Objective 6—Use the Konqueror File Manager

# Objective 1—Install the KDE Desktop Environment

KDE is available on the SUSE Linux Enterprise Desktop 10 DVD. You can install KDE in two ways:

+   - Install KDE During Installation
+   - Install KDE After Installation

# Install KDE During Installation

To install KDE during the installation of SUSE Linux Enterprise Desktop 10, do the following:

+   1. In the Software section of the Installation Settings dialog, select KDE Desktop Environment.
+   2. It is also possible (but not necessary) to deselect GNOME Desktop Environment here.
