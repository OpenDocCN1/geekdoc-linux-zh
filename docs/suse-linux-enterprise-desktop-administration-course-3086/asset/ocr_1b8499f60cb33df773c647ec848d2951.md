**session key**  A randomly generated key used by SSH for symmetric encryption.

**sftp command**  A command used to copy files from one host to another using SSH.

**ssh command**  A command used to obtain a shell from a remote SSH server.

**ssh-add command**  A command used to register new RSA and DSA keys for use by the ssh-agent command.

**ssh-agent command**  A command used to perform SSH authentication.

**ssh-copy-id command**  A command used to copy SSH keys from one computer to another.

**ssh-keygen command**  A command used to generate RSA and DSA keys for use with SSH.

**ssh-keyscan command**  A command used to display asymmetric public keys used by SSH.

**subnet mask**  A number used to determine which portions of an IP address are the network portion and host portion.

**SuSEfirewall2**  The SUSE Linux utility that is used to configure the netfilter framework to provide packet filtering on a network interface.

**symmetric encryption**  A type of encryption that uses the same key to encrypt and decrypt data.

**TightVNC**  A package that provides VNC server capability in SUSE Linux.

**Time To Live (TTL)**  A value inside an IP packet that identifies how many more routers the packet may pass through. Each router decrements the TTL of packets that pass through them. When the TTL of a packet reaches zero, it is removed from the network.

**traceroute command**  A command used to identify the route an IP packet takes to a remote host.

**Transmission Control Protocol (TCP)**  A part of the TCP/IP protocol suite that provides reliable communication between hosts on a network.

**Transmission Control Protocol/Internet Protocol (TCP/IP)**  A suite of protocols that is used to communicate with other computers on a network.

**Triple-DES (3DES)**  A common symmetric encryption algorithm that uses 112- or 168-bit keys.

**Trusted List**  A list of user-added networks in NetworkManager.

**User Datagram Protocol (UDP)**  A part of the TCP/IP protocol suite that provides fast but unreliable communication between hosts on a network.

**vino**  A package that provides VNC server capability in SUSE Linux.

**vino-preferences command**  A command used to configure VNC server settings in SUSE Linux.

**Virtual Network Computing (VNC)**  An open protocol that is used to obtain graphical interfaces from remote operating systems.

**Virtual Private Network (VPN)**  A logical network that can be created on an existing IP network. Communication on VPNs are secured using encryption.

**vncviewer command**  A command used to connect to a remote computer using VNC.

**WEP (Wireless Equivalent Privacy)**  A technology used to secure wireless communication using encryption.

**WLAN (Wireless Local Area Network)**  A network that consists of computers that communicate via wireless network interfaces.

**WPA (WiFi Protected Access)**  A technology used to secure wireless communication using encryption that is stronger than WEP. The latest version of WPA is WPA2.
