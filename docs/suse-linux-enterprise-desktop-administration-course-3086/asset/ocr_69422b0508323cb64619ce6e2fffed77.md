# Objective 1—Manage the Network Configuration Information from YaST

The YaST module for configuring network cards and the network connection can be accessed from the YaST Control Center. See Figure 5-1.

To activate the network configuration module, select **Network Devices > Network Card**.

![](bbox=[0.037, 0.216, 0.955, 0.737])

**Figure 5-1**

YaST first wants to know the network setup method:

+   - *User Controlled with NetworkManager*—A normal user can use a desktop applet to manage the connections for all network interfaces. This is especially useful on notebooks that change between wired and wireless connections.
+   - *Traditional Method with ifup*—The traditional method uses the `ifup` command. You would use this method on servers or on a desktop when changes to the network connection are unlikely.
