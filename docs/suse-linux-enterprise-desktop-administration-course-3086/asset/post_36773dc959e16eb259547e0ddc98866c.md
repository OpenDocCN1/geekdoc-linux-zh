## Logging In to a Novell iFolder Account

You can work locally with files in the Novell iFolder directories at any time. You must be logged in to a Novell iFolder account to synchronize the user list, synchronize Novell iFolder data, upload new Novell iFolders, download shared Novell iFolders, share Novell iFolders, and manage Novell iFolders. You can log in separately and be logged in concurrently to multiple accounts.

Use one of the following login methods for each account:
- **Log In Automatically**—Enable Remember My Password for your Novell iFolder account if you want to log in automatically whenever the Novell iFolder client starts. You can enable Remember My Password when you configure the account or by modifying the account settings later.

Whenever your password changes, automatic authentication fails gracefully the next time Novell iFolder attempts to log in to the Novell iFolder account. Novell iFolder prompts you to log in; then you can enter the new password. You can then enable Remember My Password again, if desired.
- **Log In As Needed**—Disable Remember My Password if you want to log in to a Novell iFolder account only as needed.

To enable or disable Remember My Password for an existing Novell iFolder account, do the following:
1. Right-click the Novell iFolder Services icon ( ) in the Notification area; then open the Novell iFolder Preferences dialog box from the Accounts tab by selecting Account Settings.
2. Select the Novell iFolder account; then view its setting in the Novell iFolder Account Assistant by selecting Properties.
3. Follow the on-screen instructions to specify the *password*.
4. Select (enable) or deselect (disable) Remember My Password.
5. Verify the settings you entered; then save your changes and log in to the server by selecting Connect.

To log in to a Novell iFolder account, do the following:
1. Right-click the Novell iFolder Services icon ( ) in the Notification area; then select Account Settings.
2. Select the Novell iFolder account; then select the Online check box.
3. If prompted for a password, specify the *password*; then select Connect.
If Remember My Password is enabled for the account, you are not prompted to enter a password unless your password has expired.
If login fails, an error message reports the cause, such as password failure.
4. On successful connection, close the Novell iFolders Properties dialog box.

## Logging Out of a Novell iFolder Account

Log out of a Novell iFolder account whenever you want to work offline.
1. Right-click the Novell iFolder Services icon ( ) in the Notification area; then open the Novell iFolder Preferences dialog from the Accounts tab by selecting Account Settings.
2. Locate the *account* you want to manage; then disconnect from the Novell iFolder server by deselecting the Online check box.
3. Close the Novell iFolders Preferences dialog box by selecting Close.

## Deleting a Novell iFolder Account

You can specify whether to remove an account only from the current computer, or whether to also remove the Novell iFolders you own from the server.

If you remove a Novell iFolder account only from your computer:
- The local Novell iFolders for this account are reverted to normal folders. Use a file manager to locate and delete the local copy of the data if it is not needed.
- You can continue to access the Novell iFolders from other computers with the Novell iFolder client.
- When the Novell iFolder client is used with a Novell iFolder 3.x enterprise server, you can also access files from anywhere with Novell iFolder 3.x Web access.
