# Exercise 13-5: Install and Configure the Novell Client for Linux

In this exercise, you install and configure the Novell Client for Linux.
In the first part of the exercise, install the Novell Client for Linux. Copy the installation files from the 3086 Student DVD2 to your home directory, and use YaST to integrate the files as an Add-on Product. Then install the Novell Client for Linux.
In the second part, use the Novell Client for Linux to log in to an eDirectory network, to change your eDirectory password, and to map a network directory.
In the third part, configure the Novell Client for Linux to suit your needs.

# Detailed Steps to Complete This Exercise

+   - Part I: Install the Novell Client for Linux Packages
+   - Part II: Use the Novell Client Tray Application
+   - Part III: Configure the Novell Client
