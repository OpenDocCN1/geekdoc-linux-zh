# Summary

+   - After logging in to a Linux system, a login shell is started to provide your user environment, execute your commands, and display your output. If you use a graphical login, the X Window System runs on top of a login shell. Any additional shells that you start follow logging into nonlogin shells.
+   - Although there are many shells available for use in Linux, the default shell is the Bourne Again shell (bash). The bash shell in SUSE Linux reads the `/etc/profile`, `~/.profile`, `/etc/bash.bashrc`, `/etc/bash.bashrc.local`, and `~/.bashrc` files at login to create variables and run programs. In addition, the `/etc/bash.bashrc`, `/etc/bash.bashrc.local`, and `~/.bashrc` files are read each time a nonlogin shell is started.
+   - The bash shell is case-sensitive, can be used to perform filename completion, and can execute previously entered commands.
+   - Several environment variables are loaded when a shell is started that are used by programs to set the user environment and locale.
+   - Aliases are special shell variables that contain commands. When you invoke an alias, the commands defined within it will be executed.
+   - Wildcards are special characters that can be used to represent patterns when specifying file or directory names on the file system. You can protect special characters from shell interpretation by using single quotes, double quotes, or the backslash character.
+   - Although many text-based and graphical text editors are available for Linux systems, the vi editor is the most commonly used editor across different distributions of Linux and versions of UNIX. By default, SUSE Linux includes vim (vi improved), which uses different modes for inserting text, editing text, and saving document changes.

# Key Terms

+   - **.command** — A command used to execute a file in the current shell environment.
+   - **/bin/bash** — The executable file for the Bourne Again Shell.
+   - **/bin/csh** — The executable file for the C shell.
+   - **/bin/ksh** — The executable file for the Korn shell.
+   - **/bin/sh** — The executable file for the Bourne shell.
