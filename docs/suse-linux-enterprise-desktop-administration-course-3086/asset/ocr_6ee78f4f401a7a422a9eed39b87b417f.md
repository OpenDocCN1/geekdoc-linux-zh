From this dialog, you can select from the following modes:

+   - *Simple Mode*—This mode displays a list of all available services and the current status of each service.\n  You can select a service, and then select Enable or Disable.\n  Selecting Enable starts the service (and services it depends on) and enables them to start at system boot time. Selecting Disable stops dependent services and the service itself and disables their start at system boot time.\n- *Expert Mode*—This mode gives you control over the runlevels in which a service is started or stopped and lets you change the default runlevel.
