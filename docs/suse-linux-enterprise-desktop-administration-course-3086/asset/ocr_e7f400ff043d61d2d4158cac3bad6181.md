To use sudo to view /var/log/messages, do the following:

+   1. Open a terminal window and switch (su -) to the root account (password nov311).
+   2. Enter visudo. vi is started to edit the /etc/sudoers file.
+   3. Put a comment sign (#) in front to the lines beginning with
+   
+      Defaults targetpw
+   
+      and
+   
+      ALL ALL=(ALL) ALL
+   
+   4. At the end of the file, add the following line:
+   
+      geeko ALL=(ALL) /usr/bin/tail -f /var/log/messages
+   
+   5. Save the file by pressing Esc and entering :wq.
+   6. Open another terminal window.
+   7. As user geeko, enter sudo tail --f /var/log/messages.
+      You are prompted for Geeko’s password (novell). The end of the /var/log/messages
+      file is displayed.
+   8. Press Ctrl+c to end tail.
+   9. Close all terminal windows.

With SUSE Linux Enterprise Desktop 10, it is possible to encrypt a file system on a partition, or to create encrypted home directories based on images that contain an encrypted file system. Both can be set up with YaST:

+   - Use YaST to Encrypt a Partition
+   - Create an Encrypted Image as Home Directory for a User

# Use YaST to Encrypt a Partition

To encrypt a partition, you only need to select the appropriate option when creating the partition in YaST and enter a password to unlock the partition when it is mounted.

To start YaST, select Computer > More Applications > System > YaST. In the YaST Control Center, select System > Partitioner and confirm the warning dialog. To create a partition, select Create. A dialog similar to the one shown in Figure 9-13 opens up (the dialog has a different caption, depending on whether you create a primary or a logical partition).

In this dialog, enter the information, such as size, mount point, and file system, needed to create the partition, and select the Encrypt file system option.
