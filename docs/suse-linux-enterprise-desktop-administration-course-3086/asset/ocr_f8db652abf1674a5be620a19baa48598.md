Save the configuration settings by selecting **Accept > Finish**. The values are written to the file `/etc/default/useradd`:

```
da10:~ # cat /etc/default/useradd
GROUP=100
HOME=/home
INACTIVE=-1
EXPIRE=
SHELL=/bin/bash
SKEL=/etc/skel
GROUPS=video,dialout
CREATE_MAIL_SPOOL=no
```
