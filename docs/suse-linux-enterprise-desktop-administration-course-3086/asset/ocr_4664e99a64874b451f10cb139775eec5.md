Command-line options can be used to change the default behavior of `top`. For example, `top -d 5` (delay) changes the default delay (3 seconds) before refresh to 5 seconds.

Use `top -b` (batch mode) when you want to write the output of `top` to a file or pass it to another process.

Use `top -n 3` (iterations) to cause `top` to quit after the third refresh. This is especially useful in combination with `-b` (`top -b -n 1`, for example).
