## Preface

**Since its conception in 1991, Linux has fast become a major enterprise operating system** and has led to the widespread adoption of Open Source Software in the computer industry. More recently, many organizations have adopted Linux as a main desktop operating system due to its advanced graphical desktop environment and plethora of its productivity software.

One good example is Novell’s switch to SUSE Linux as its main enterprise and desktop platform. Today, there are millions of Linux users, administrators, and developers worldwide, and this community continually grows as companies adopt Linux and Open Source technologies.

However, as Linux grows in today’s global marketplace, so does the need for Linux education. In this book, we examine the usage, configuration, and management of SUSE Linux Enterprise Desktop 10. More specifically, this book walks the student through the practices and procedures used to deploy SUSE Linux as well as manage file systems, hardware, users, groups, printers, boot loaders, processes, software, and the X environment using both graphical and command-line tools.

To provide benchmarks for hiring, many vendors such as CompTIA, Novell, Red Hat, and the Linux Professional Institute (LPI) have released Linux certification exams geared toward different skill sets required for common Linux job functions. The Novell Certified Linux Desktop Administrator (CLDA) certification is practicum-based and focuses on the deployment and administration of SUSE Linux Desktop systems. Using carefully constructed examples, questions, and practical exercises, the *SUSE Linux Enterprise Desktop Administration* (Course 3086) text introduces you to the concepts tested on the CLDA certification exam.

## Intended Audience

This book is appropriate for anyone who wants to learn how to use, configure, or administer SUSE Linux Enterprise Desktop 10, as well as for those who are currently preparing for the Novell Certified Linux Desktop Administrator (CLDA) 10 Practicum exam. Although the concepts introduced in this book do not assume prior SUSE Linux experience, a general knowledge of computing concepts is assumed. In addition, many of the concepts and procedures introduced in this book are transferable to most other Linux distributions.

## Section Descriptions

There are 11 sections in this book, as follows:

- 1. **Section 1, “Install SUSE Linux Enterprise Desktop 10,”** examines the concepts and procedures necessary to install SUSE Linux Enterprise Desktop.
- 2. **Section 2, “Use the Linux Desktop,”** examines the navigation of the GNOME desktop environment. In addition, this section introduces the Linux command-line interface.
- 3. **Section 3, “Locate and Use Help Resources,”** discusses the various tools used to obtain help in SUSE Linux Enterprise Desktop 10, including the manual pages, info pages, HOWTO files, and Internet resources.
- 4. **Section 4, “Administer Linux with YaST,”** walks through the procedures used to administer basic system information using the YaST utility. This section also examines the structure of SuSEconfig.
- 5. **Section 5, “Manage the Network Configuration,”** covers the configuration of network interfaces in SUSE Linux Enterprise Desktop 10 using YaST and command-line tools. Furthermore, this section examines the configuration of firewalls and remote access protocols such as SSH, VPNs, and VNC.
- 6. **Section 6, “Manage Software,”** examines the concepts and procedures necessary to manage software packages on SUSE Linux systems with focus on online update and RPM.
- 7. **Section 7, “Manage Directories and Files,”** covers the structure of the Linux file system as well as the commands used to navigate the file system directory structure. This section also introduces the commands that may be used to create, view, search, and manage files on the file system.
- 8. **Section 8, “Work with the Linux Shell and Command Line,”** discusses the various features of your shell, including filename completion, command history, variables, special characters, history, and aliases. Following this, we examine the usage of the gedit and vi text editors.
- 9. **Section 9, “Manage Users, Groups, and Permissions,”** examines the concepts and tools used to administer users, groups, passwords, file permissions, file ownership, and encryption on a SUSE Linux system.
- 10. **Section 10, “Monitor the Linux System and Control Processes and Services,”** discusses the log files and utilities that may be used to identify problems with system security and performance. In addition, this section discusses how to view, manage, kill, and schedule user and daemon processes.
- 11. **Section 11, “Manage System Initialization,”** covers the SUSE Linux boot process and examines the configuration of the GRUB boot loader as well as the configuration of daemon processes by runlevel.

Section 12, “Administer Printing,” examines the structure and configuration of the CUPS printing system. In addition, this section examines the iPrint printing system and its implementation in SUSE Linux.

Section 13, “Integrate SUSE Linux Enterprise Desktop 10 into Existing Environments,” examines the tools and protocols used to integrate SUSE Linux into other network environments such as Active Directory and eDirectory. Focus is placed on LDAP, NFS, Samba, AD, iFolder, and the Novell Client.

Section 14, “Customize the Graphical Interface on SUSE Linux Enterprise Desktop 10,” describes the structure and function of the graphical components in SUSE Linux Enterprise Desktop. In addition, this section examines the customization and lockdown of the desktop environment using various utilities.

Section 15, “Deploy SUSE Linux Enterprise Desktop 10,” examines the various methods that can be used to deploy several SUSE Linux Enterprise Desktops within an organization. Focus is placed on AutoYaST and network installations.

## Features and Approach

*SUSE Linux Enterprise Desktop 10: Administration* differs from other networking books in its unique hands-on approach and its orientation to real-world situations and problem solving. To help you comprehend how Linux security concepts and techniques are applied in real-world organizations, this book incorporates the following features:

- **Section Objectives**—Each section begins with a detailed list of the concepts to be mastered. This list gives you a quick reference to the section’s contents and is a useful study aid.
- **Exercises**—Activities are incorporated throughout the text, giving you practice in setting up, managing, and troubleshooting a network system. The activities give you a strong foundation for carrying out network administration tasks in the real world. Because of the book’s progressive nature, completing the activities in each section is essential before moving on to the end-of-section materials and subsequent sections.
- **Section Summaries**—Each section includes a summary of the concepts introduced in that section. These summaries provide a helpful way to recap and revisit the ideas covered in each section.
- **Key Terms**—Important terms within the section are gathered together in the Key Terms list at the end of the section. This provides you with a method of checking your understanding of all the terms introduced.
- **Review Questions**—The end-of-section assessment begins with a set of Review Questions that reinforce the ideas introduced in each section. Answering these questions correctly will ensure that you have mastered the important concepts.
- **Discovery Exercises**—These include theoretical, research, or scenario-based projects that allow you to expand on your current knowledge of the concepts based on what you learned in the section.
