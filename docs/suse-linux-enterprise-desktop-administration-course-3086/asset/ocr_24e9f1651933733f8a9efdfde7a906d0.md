**type command**  A command used to determine the type of program for a command. The type command can be used to identify aliases and their target commands.

**unalias command**  A command used to destroy an alias in memory.

**UTF-8 (Unicode Transformation Format)**  A character encoding format used by all nonroot users in SUSE Linux shells.

**variable**  An area of memory used to store information; variables are created from entries in files when the shell is first created after login and are destroyed when the shell is exited upon logout.

**vi editor**  The most common text editor on Linux and UNIX systems.

**vim (vi improved) editor**  An improved version of the vi editor that is common on Linux systems today.

**wildcards**  See search patterns.
