SUSE Linux Enterprise Desktop Administration introduces network professionals to the new desktop operating system, and it contains Course Technology's proven academic pedagogy, making this the ideal classroom solution for teaching Novell's SUSE Linux Enterprise Desktop. It covers basic Linux skills as well as common tasks a SLED system administrator has to perform, such as installing and configuring the desktop environment, maintaining the file system, managing software and processes, printing, integrating the product into existing environments, and rolling out a large number of installations. The text will also help readers prepare for the Novell Certified Linux Desktop Administrator (Novell CLDA) certification.

## Features

- Explains complex concepts in straightforward terms for a smooth and problem-free implementation of or transition to SLED
- Provides detailed introduction to the program's new features, and shows networking professionals how to use and administer this operating system
- Offers all the critical information students need to successfully move into the role of IT professional and support SUSE Linux in any environment
- Academic pedagogy, including Chapter Summaries, Key Terms, Review Questions, and Exercises help reinforce concepts

## About the Author

Novell-based courseware is developed by professional instructional designers and is designed to help manage, simplify, secure, and integrate technology environments by leveraging best-of-breed, open standards-based software.

Jason W. Eckert is a graduate of the University of Waterloo in Ontario, Canada, and has 18 years of experience as a UNIX administrator and software developer, mainly in large batch-scientific computing environments. He currently teaches at triOS College and holds 14 different UNIX and Linux certifications. He has authored or co-authored several texts, including SUSE Linux Enterprise Server Administration, Linux+ Guide to Linux Certification, Guide to UNIX Administration, Linux+ In Depth, Novell's Guide to CompTIA Linux+, MCSE Guide to Managing a Microsoft Windows Server 2003 Network, and Microsoft Windows Vista Guide.
