# Windows—Linux: Comparable Commands

This is a very rough comparison between DOS/Windows and Linux commands.

# Command-Line Commands

You may have to use options to achieve a closer similarity between commands. See Tables A-1 and A-2.

| Windows | Linux | Use |
|---|---|---|
| dir | ls | List directory content |
| tree | ls -R | List directories and subdirectories |
| cd | cd | Change directory |
| mkdir | mkdir | Create a directory |
| rmdir | rmdir<br>rm -r | Delete a directory |
| copy<br>xcopy | cp | Copy files |
| rename<br>move | mv | Move or rename a file |
| del | rm | Remove a file |
| more | more<br>less | View files per page |
| type | cat | View files |
| comp<br>fc | diff | Compare files |
| echo | echo | Echo text on the screen |
| date | date | View or set date |
| edit filename | vi filename | Edit an ASCII file |
| print | lp<br>lpr | Print a file |
| fdisk | fdisk | Disk partitioning |
| format | mkfs | Create a file system on a partition |
| ipconfig | ifconfig<br>ip | Network interface configuration |
| route print | route -n | Print routing table |
| ping | ping | Send ICMP echo request |
| tracert | traceroute | Show routes |
| exit | exit | Leave the shell |
