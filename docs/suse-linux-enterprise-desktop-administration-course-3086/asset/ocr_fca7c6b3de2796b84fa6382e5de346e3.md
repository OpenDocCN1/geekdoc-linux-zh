Because xeyes is now running in the background, you can use the terminal window to enter other commands.

+   10. Verify that the job status is running by entering
+   
+       `jobs`
+   
+   11. View the xeyes branch in the process tree by entering
+   
+       `pstree -p | grep -2 xeyes`
+   
+       xeyes is listed as part of the tree.
+   
+   12. Bring the xeyes process into the foreground by entering
+   
+       `fg 1` (the number one)
+   
+   13. Close the terminal window.
+   
+       Notice that the xeyes program ends as well.
+   
+   14. Open a new terminal window.
+   
+   15. Start xeyes in the background so that it runs when the terminal window closes by entering
+   
+       `nohup xeyes&`
+   
+   16. Close the terminal window.
+   
+       The xeyes program is still running.
+   
+   17. Open a new terminal window.
+   
+   18. Start the top program by entering
+   
+       `top`
+   
+   19. View only the processes started by geeko by typing `u`; then enter
+   
+       `geeko`
+   
+   20. Check for the xeyes program (xeyes) listed in top.
+   
+   21. (Conditional) If you cannot find the xeyes program, try maximizing the terminal window, or enter F and choose PID as sort column. If needed, reverse the sort order by pressing R.
+   
+   22. Record the PID of the xeyes process:
+   
+   23. Exit top by typing q.
+   
+   24. View information about the xeyes process by entering
+   
+       `ps xeyes PID`
+   
+   25. Stop the xeyes program and check the status by entering
+   
+       `kill xeyes PID`
+   
+       `ps aux | grep xeyes`
+   
+   26. Start the xeyes program in the background by entering

+       `xeyes&`
