# **HARDWARE**

![](bbox=[0.0, 0.0, 1.0, 0.7])

**Camera** 48 Raspberry Pi Cameras make up Bullet Pi, with each one sitting in the lower half of each piece of the frame composing the ring

**Ring** Bullet Pi uses a ring setup so that you can rotate around a subject frozen in time once the photos are stitched together

**Cables** About half a kilometer of network cable was used to build Bullet Pi - the PiFace modules were a godsend during debugging

**Frame** While the shots for each set of Bullet Pi images can be adjusted, they're levelled with a custom laser-cut frame

**PiFace** The Control and Display modules has an LED screen for two 16-character lines, five control buttons, a navigation switch and IR receiver

# ## Components list

+   - 48 Raspberry Pi Model Bs
+   - 48 Raspberry Pi Cameras
+   - 48 PiFace Control and Display modules
+   - 48 NOOBS SD cards
+   - 48 5V PSUs
+   - 500m of network cable
+   - 2 x 24 port switches
+   - Wireless router
