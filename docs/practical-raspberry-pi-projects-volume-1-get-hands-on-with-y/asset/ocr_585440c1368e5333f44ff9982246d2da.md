Let's say that you have a series of Python scripts that contain the various tasks you want your system to be able to tackle. You need a way to have your system be able to run these scripts when called upon. The most direct way to run a script is to use **execlfile**. Say you have a script called `do_task.py` that contains Python code you want to run when a command is given; you can run it with:

```
execlfile("do_task.py")
```

Using this form, you can add command line options to the string being handed in.
