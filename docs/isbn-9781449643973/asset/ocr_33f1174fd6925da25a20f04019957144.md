# Deliverables

Upon completion of Lab #9: Implement Best Practices for Security Logging & Monitoring, students are required to provide the following deliverables:

+   1.  Students are to submit screenshots of the following files:
+       a.  Output of the /etc/rsyslogd.conf file
+       b.  Output of the /var/log/secure, /var/log/yum.log and /var/log/boot log files
+       c.  Output of successful yum install commands for both tripwire and rkhunter
+   2.  Lab #9 - Assessment Worksheet with answers to the assessment questions

# Evaluation Criteria and Rubrics

The following are the evaluation criteria and rubrics for Lab #9 that the students must perform:

+   1.  Was the student able to configure remote logging in the Fedora Linux Server and send syslogs and other events to a remote host for secure secondary logging? – [20%]
+   2.  Was the student able to search through different log files in Fedora Linux Server to identify where certain types of logs are stored and how often they get recycled? – [20%]
+   3.  Was the student able to install and configure Tripwire file integrity tool so that modifications to important system files is quickly identified and properly logged both locally and remotely? – [20%]
+   4.  Was the student able to install and schedule rkhunter to run at said interval using the cron subsystem so that a rootkit can be properly and quickly identified if possible? – [20%]
+   5.  Was the student able to configure both automatic searches on log files as well as automatic running of important security applications to properly monitor a Fedora Linux Server for malicious activity? – [20%]
