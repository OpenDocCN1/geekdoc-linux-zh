# Deliverables

Upon completion of Lab #5: Apply Hardened Security for Linux Services, students are required to provide the following deliverables:

+   1. Lab #5 - Screenshots of the following files:
+       a. Output of the /etc/my.cnf file
+       b. Output of the /etc/httpd/conf/httpd.conf file
+       c. Output of the /etc/ssh/sshd_config file
+       d. SSH session MOTD banner
+   2. Lab #5 – Assessment Questions & Answers

# Evaluation Criteria and Rubrics

The following are the evaluation criteria and rubrics for Lab #5 that the students must perform:

+   1. Was the student able to harden Linux server services when enabling and installing them and keep a security perspective during configuration – [20%]
+   2. Was the student able to create an Apache Web Server installation, and perform basic security configurations to assure that the system has been hardened before hosting a web site – [20%]
+   3. Was the student able to configure and perform basic security for a MySQL database, understanding the ramifications of a default installation and recommending hardening steps for the database instance – [20%]
+   4. Was the student able to install, setup and perform basic security configuration for Sendmail to be able to leverage the built-in messaging capabilities of the Linux System – [20%]
+   5. Was the student capable of enabling and implementing secure SSH for encrypted remote access over the network or across the Internet of a Linux server system – [20%]
