### Review & Tune the Fedora Linux Server’s Kernel Parameters

6. View configured settings for the running kernel. Type the command: `cat /etc/sysctl.conf | less` and press `<enter>`.
7. Press the “q” key to exit and return to the command prompt.
8. Open /etc/sysctl.conf in vi editor. Type the command: `su -c ' vi /etc/sysctl.conf '` and press <enter> .
9. Password: ISS316Security
10. Press the " i " key to enter INSERT mode .
11. Add the line at the end of the file : `net.ipv4.tcp_syncookies = 1`
12. Save the changes and exit the file. Press the escape key to exit from insert mode, then press the "shift" & ":" keys to enter command mode. At the colon prompt in command mode, type wq to exit and save changes.
13. Change kernel setting immediately without a reboot. Type the command: `su -c ' echo "1" > /proc/sys/net/ipv4/tcp_syncookies '` and press <enter> to immediately turn on tcp_syncookies without a reboot. When prompted, enter the password for root ( ISS316Security )
14. View current kernel parameter setting. Type the command: `cat /proc/sys/net/ipv4/tcp_syncookies` and press <enter> . A " 1 " signals the setting is set to "on" with the running kernel.
15. View all available parameters. Type the command: `sysctl -a | less` and press <enter> . Use the keyboard arrows to scroll up or down the page.
16. Press the " q " key to exit and return to the command prompt.
17. Change kernel parameter with sysctl command. Type the command: `su -c ' sysctl -w fs.file-max=100000 '` and press <enter> .
18. Password: ISS316Security
19. This will change the maximum number of files that can be opened at a time by a user.

### Discover Information About the Current Running Kernel

20. Find what types of filesystems are supported by the kernel. Type the command: `cat /proc/filesystems` and press <enter> .
21. Find what modules the kernel is loading. Type the command: `cat /proc/modules` and press <enter> .
22. Find what version of the kernel is currently running. Type the command `cat /proc/version` and press <enter> .
23. Find information regarding the CPU. Type the command: `cat /proc/cpuinfo` and press <enter> .
24. Find information about processes running in memory. Type the command: `cat /proc/meminfo` and press <enter> .

## Remove and Load a Module

**Note:** To remove a module, the command `modprobe -r <module_name>` is used. From the results of the previous step, find a module that has “0” in the Used By column. A zero (0) is an indication the loaded module currently is not in use and can be removed.

26. Remove a loaded module. Type the command: `su -c 'modprobe -r <module_name>'`
27. Password: ISS316Security

**Note:** Do not type `module_name` in the command. Instead replace that with the name of the module to be removed. For example, if the `snd_seq` module is to be removed, the correct command is: `su -c 'modprobe -r snd_seq'`.

28. Load a module. Type the command : `su -c 'modprobe <unloaded_module>'` and press <enter> to load the module that was previously removed.
29. **Password:** ISS316Security

**Note:** Do not type `unloaded_module` in the command. Instead replace that with the name of the module that was removed in the previous step. For example, if the `snd_seq` module is to be loaded, the correct command is: `su -c 'modprobe snd_seq'`.

This lab is an extension of the previous equipment-based labs. This lab continues with the system and security hardening for the Fedora Linux Server. In this lab the students need to review and security harden the Linux kernel with security parameters. They will perform steps to view and tune all kernel parameters and discover information regarding the current Loadable Kernel Modules (LKM) and information about the kernel itself. Finally, they will enable and interpret the results of the “lsmod” command to perform additional security hardening.
