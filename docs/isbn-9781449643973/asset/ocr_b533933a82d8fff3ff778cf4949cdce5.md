+   46. Modify Boolean settings to allow the http server to send email, execute PHP scripts, and make use of a NFS share.

| Functionality | SELinux Boolean | Fedora 14 Default |
| Web Server send email | `httpd_can_sendmail` | Off |
| Web Server can execute PHP & Other Web Scripts | `httpd_built-in_scripting` | On |
| Web Server can connect to a remote NFS Share | `httpd_use_nfs` | Off |

+   47. Type the command: `su -c 'setsebool -P httpd_can_sendmail 1'` and press <enter> . When prompted, enter the password for root ( ISS316Security ). This may take a few moments to relabel. Do not press any keys until the command prompt returns.
