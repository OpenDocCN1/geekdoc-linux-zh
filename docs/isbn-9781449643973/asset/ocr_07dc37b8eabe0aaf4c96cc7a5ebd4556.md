# **Evaluation Criteria and Rubrics**

The following are the evaluation criteria and rubrics for Lab #4 that the students must perform:

+   1.  Was the student able to mount a file system without execute permissions, so you can safely read the data contained in the disk without executing any unexpected programs? – [20%]

+   2.  Was the student able to mount a remote file system, and configure the system to be mounted at boot time for an automatic network share on a Linux system? – [20%]

+   3.  Was the student able to set user quotas on disk to protect the availability and security on the Linux system and to prevent users from taking up all the disk drive on the system? – [20%]

+   4.  Was the student able to edit and modify the /etc/fstab file to manage local and remote NFS shares as well as necessary disk mounting configurations required? – [20%]

+   5.  Was the student able to configure and use the repquota command to verify usage of disk space by users and manage quotas? – [20%]
