# Overview

This lab is an extension of the previous equipment-based labs, and it incorporates security hardening for File Systems and user access to mounted file systems. In this lab, students will be required mount a file system on the Fedora Linux Server that does not have execute permissions. They will also demonstrate how to mount a remote file system and set quotas for users of mounted file systems.

# Lab Assessment Questions & Answers

+   1. Consider a file that has been given permissions 777 (owner-rwx, group-rwx, other-rwx), but returns a “permissions denied” when a user attempts to execute it. Explain the most likely reason.

+   2. You are given a scenario where a web server will need to access PDF documents located on another server within the local area network. These documents are for customers to view their personal account information only. What mounting option would be: /tmp ext4 ro 0 0?
