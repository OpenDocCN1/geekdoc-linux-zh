# Overview

In this lab, students will enable system logging of a Fedora Linux Server for security operations and management of production servers. The instructor will demonstrate how to enable logging with the system log files sent automatically to a remote server on the network. The instructor will also demonstrate use of a third-party file integrity tool called Tripwire, as well as rkhunter on the Fedora Linux Server. Finally, the instructor will demonstrate how to automate searching through large log files using cron.

# Lab Assessment Questions & Answers
