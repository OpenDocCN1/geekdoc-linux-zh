## Laboratory #6

### Lab #6: Apply Hardened Security for Controlling Access

#### Learning Objectives and Outcomes

Upon completing this lab, students will be able to complete the following tasks:

- Review current internal host-based firewall parameters and configuration settings to verify allowed and denied IP communications
- Configure an internal host-based firewall using iptables and create stringent allow/deny rules for services that may require access to the system over the network
- Harden the system by enabling TCPWrappers to deny and log unauthorized attempts against services and ports running on the system
- Secure processes running on the system by using and configuring SELinux to help perform more in-depth layered security
- Verify configurations of the settings applied by connecting to the Linux server using SSH and connect to other services running on a Linux server

#### Configure Stringent Permit & Deny Firewall Rule Sets

7. List current firewall rules. Type the command: `sudo iptables -L` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security).

8. Flush the firewall rules. Type the command: `sudo iptables -F` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security).

9. Verify firewall rules are flushed. Type the command: `sudo iptables -l.` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security). There should be no firewall rules listed.

10. Insert a rule to allow INPUT chains to be added to the firewall rules and allow established connections.
    Type the command:
    `sudo iptables -I INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security).

11. Append a rule to allow http (web) access.
    Type the command:
    `sudo iptables -A INPUT -p tcp --port 80 -j ACCEPT` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security).

12. Append a rule to allow https (SSL) access.
    Type the command:
    `sudo iptables -A INPUT -p tcp --port 443 -j ACCEPT` and press <enter>.

13. Append a rule to allow access for ssh.
    Type the command:
    `sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT` and press <enter>.

14. Append a rule to allow ICMP pings.
    Type the command:
    `sudo iptables -A INPUT -p icmp -j ACCEPT` and press <enter>.

15. Append a rule that will deny all other traffic.
    Type the command:
    `sudo iptables -A INPUT -p all -j DROP` and press <enter>.

16. Save the newly created rules. Type the command: `sudo service iptables save` and press <enter>.

17. Check one more time that the newly created rules are now listed. Type the command: `sudo iptables -L.` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security).
