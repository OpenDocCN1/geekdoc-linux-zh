# **Evaluation Criteria and Rubrics**

The following are the evaluation criteria and rubrics for Lab #1 that the students must perform:

+   1. Was the student able to recognize the importance to physically securing Linux computers?– **[20%]**
+   2. Was the student able to articulate why secured partitions within the core Linux server establish the basis for security hardening, performance, and application support?– **[20%]**
+   3. Did the student provide a recommendation to maintain a synchronized time setting throughout the system?– **[20%]**
+   4. Did the student suggest a server install with no GUI or provide a valid explanation why a GUI should be installed to a server and how to mitigate risks?– **[20%]**
+   5. Was the student able to understand why it is important to create a non-privileged user account for system administration access as a secure alternative to logging in as root user?– **[20%]**
