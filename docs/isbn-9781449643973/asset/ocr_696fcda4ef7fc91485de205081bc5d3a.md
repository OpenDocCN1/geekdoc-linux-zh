# **_Overview_**

This lab is an extension of the previous equipment-based labs. This lab continues with the system and security hardening for the Fedora Linux Server. In this lab the students need to review and security harden the Linux kernel with security parameters. They will perform steps to view and tune all kernel parameters and discover information regarding the current Loadable Kernel Modules (LKM) and information about the kernel itself. Finally, they will enable and interpret the results of the “lmod” command to perform additional security hardening.
