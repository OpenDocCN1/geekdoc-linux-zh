# Overview

In this lab the students review the install of a Fedora Linux Server that will act as a web server for a fictitious financial institution. The installation process, applying passwords, creating partitions, and system administrator access controls will be part of the operating system configuration requirements.

# Lab Assessment Questions & Answers
