# 概述

本实验是之前基于设备的扩展实验，并结合了文件系统的安全加固以及对挂载文件系统的用户访问控制。在本实验中，学生将被要求挂载一个在 Fedora Linux 服务器上没有执行权限的文件系统。他们还将演示如何挂载远程文件系统并为挂载文件系统的用户设置配额。
