# Overview

This lab is an extension of the previous equipment-based labs, and it incorporates security hardening for Linux services and applications loaded in the physical server. In this lab the students will configure security and hardened services and applications to ensure C-I-A of these services. They will take the steps to configure and secure an Apache web server and MySQL database and the components necessary to security harden the implementation of both. The students will also demonstrate how to use and configure the Sendmail application for secure local messaging and will enable secure, encrypted remote access using Secure Shell (SSH).
