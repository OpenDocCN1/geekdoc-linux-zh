+   18. Download a public key. Type the command: `wget http://dl.ssl.google.com/linux/linux_signing_key.pub` and press <enter>.

+   19. Verify the signature of a downloaded key. Type the command: `gpg linux_signing_key.pub` and press <enter>.

```
[student@TargetFedora01 ~]$ gpg linux_signing_key.pub
:pub  1024D/7FAC5991  2007-03-08 Google, Inc. Linux Package Signing Key <linux-packages-keymaster@google.com>
:sub  2048g/C07CB649  2007-03-08
```

**Figure 47 – Verifying the signature of key downloaded from the Internet**

+   20. Import a key into rpm database. Type the command `sudo rpm --import linux_signing_key.pub` and press <enter>. If prompted for a password, enter the password for the student user (ISS316Security).

```
[student@TargetFedora01 ~]$ sudo rpm --import linux_signing_key.pub
[sudo] password for student:
```

**Figure 48 – Importing a key into the RPM database**
