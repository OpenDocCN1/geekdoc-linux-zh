# Recommended Procedures

# Paper-Based Lab #1 – Student Steps:

Students should use the install step figures as a reference when writing a summary report for “Securing a Linux server – starting with the install”.

# Deliverables

Upon completion of Lab #1: Install a Core Linux Operating System on a Server, students are required to provide the following deliverables:

+   1. Lab #1 - Submit a summary report and an audit checklist for securing a Linux server – starting with the install. Make the assumption the server will be used as a retailer’s Web Server for an e-commerce web application.
+   a. Provide an explanation why is it especially important to physically secure Linux computers.
+   b. Summarize reasons for partitioning as it relates to security and availability.
+   c. Briefly explain why it may be acceptable to install X window and a graphical user interface with the server and how risks can be mitigated.
+   d. Provide a recommendation how to maintain synchronization with a Network Time Server
+   e. Suggest a method for administrators to login to the server and perform administrative tasks. (remote or physical access, accounts to use for login, etc.)
+   f. Provide an audit checklist Linux administrators could use during the install process.

+   2. Lab #1 – Lab Assessment Questions & Answers
