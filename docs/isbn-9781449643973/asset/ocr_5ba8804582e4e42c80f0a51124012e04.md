+   8.  Edit the database configuration file and remove symbolic links, add skip-networking to prevent remote access to the database and disallow the ability to load a local data file. Type the command : `su -c 'vi /etc/my.cnf'` and press <enter>.

+   10. Press the “i” key to enter INSERT mode.

+   11. With the file open for edits, remove the “#” from the symbolic links field and add the line skip-networking at the bottom and add set-variable=local-infile=0 .

```
```
[mysqld]
datadir=/var/lib/mysql
socket=/var/lib/mysql/mysql.sock
user=mysql
# Disabling symbolic-links is recommended to prevent assorted security risks
symbolic-links=0
skip-networking
set-variable=local-infile=0

[mysqld_safe]
log-error=/var/log/mysqld.log
pid-file=/var/run/mysqld/mysqld.pid
