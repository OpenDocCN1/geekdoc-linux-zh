# **Overview**

In this lab the students will maximize availability and define a recovery time objective for data file backups and recovery on a production Fedora Linux Server. They will perform backups and restoration of a Linux OS, applications, and data stored in the file systems. They will then perform steps to perform a backup and encrypt it for security hardening using openssl. Finally, the students will then recover an accidentally deleted file using the /proc recovery function.
