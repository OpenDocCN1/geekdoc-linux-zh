- 34. Press the "i" key to enter INSERT mode.
- 35. Change SELINUX setting from "permissive" to "enforcing".

```
# This file controls the state of SELinux on the system.
# SELINUX= can take one of these three values:
#     enforcing - SELinux security policy is enforced.
#     permissive - SELinux prints warnings instead of enforcing.
#     disabled - SELinux is fully disabled.
SELINUX=enforcing
# SELINUXTYPE= type of policy in use. Possible values are:
#     targeted - Only targeted network daemons are protected.
#     strict - Full SELinux protection.
SELINUXTYPE=targeted
```

## Overview

This lab is an extension of the previous equipment-based labs. It continues with the system and security hardening for the Fedora Linux Server and requires the students to first review current host-based, IP firewall services. They will flush the current firewall configuration and will re-configure with stringent permit/deny rule sets. In this lab the students will configure security and hardened services, including a host-based IP firewall, TCPwrappers for unauthorized access controls and logging, and SELinux for implementation of a layered security strategy.
