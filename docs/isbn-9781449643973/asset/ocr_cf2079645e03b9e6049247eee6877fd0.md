# Recommended Procedures

**Equipment-Based Lab #6 – Student Steps:**
The Instructor will conduct the following demonstration using VMware Player:

+   1. Connect the instructor-removable hard drive to your workstation
+   2. Boot up the Instructor VM and Microsoft DHCP VM server to allocate an IP host address
+   3. Enable your DOS command prompt and type “ipconfig” and “ping” your allocated IP host address 172.30.0.__, the DHCP server 172.30.0.10, and the IP default gateway router 172.30.0.1
+   4. Connect your instructor workstation to the LCD projector and show the VMware Player library and how to add, remove and copy VMs to and from the library and the local computer
+   5. Login to the Student VM using the following credentials:
+      Login ID: “student” (case sensitive)
+      Password: “ISS316Security” (case sensitive)
+   6. From the GNOME Desktop , at the top left side, click on “Applications”-> Systems Tools -> Terminal

> **NOTE:** Before the sudo & su commands can execute as expected, the user account MUST be a member of the wheel group with the wheel group granted limited sudo access as directed in Lab 3.
