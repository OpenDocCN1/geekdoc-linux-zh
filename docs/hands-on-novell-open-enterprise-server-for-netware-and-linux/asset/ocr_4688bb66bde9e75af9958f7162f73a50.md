To offer additional security, Apache Web Server logs the activity of all its services in Common Log Format (CLF) files that can be viewed from the Web Manager home page. With these files, you can track all user access to the services, see what access has occurred, and detect what errors, if any, have occurred. You can also use Web Manager to install and configure many NetWare 6.5 Web services. As you install additional Web services, their links are automatically added to Web Manager.
