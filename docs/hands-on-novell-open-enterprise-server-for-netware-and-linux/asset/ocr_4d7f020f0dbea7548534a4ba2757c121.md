# **Hands-On**

# **Novell Open Enterprise Server**

# **for NetWare and Linux**

This new edition covers installing, configuring, and managing Novell Open Enterprise Server, which incorporates both the NetWare 6.5 and SUSE Linux Enterprise Server network operating systems. This book features extensive hands-on projects with real-world scenarios to help students apply new concepts and sharpen problem-solving skills and an ongoing set of case study projects that lead students through applying and configuring NetWare 6.5 and SUSE Linux administrative features. In addition, hands-on and case projects allow students to see how software components work together to build a functioning network system.

**Key Features:**

+   - Includes free software: Novell Open Enterprise Server NetWare and Linux installations, as well as SUSE Linux Enterprise Server 9.
+   - Maps completely to the Certified Novell Administrator (CNA) 050-686 exam with in-depth coverage of all exam objectives. Additional coverage of many Certified Linux Professional (CLP) objectives.
+   - Contains complete coverage of installation and management of NetWare 6.5 and SUSE Linux operating systems, basic Linux concepts and commands, eDirectory, and Novell OneNet services.
+   - Hands-on activities are integrated into the chapter text for immediate reinforcement of topics and are designed to be compatible with virtual machines, allowing students to run their own servers and work on activities outside the computer lab.
