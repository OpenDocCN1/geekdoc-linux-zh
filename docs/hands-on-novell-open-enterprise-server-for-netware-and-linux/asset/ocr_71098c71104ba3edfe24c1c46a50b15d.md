# Assigning Users to an Administrative Role

By default, when RBS is installed on an Open Enterprise server, only the network administrator is configured as a user of iManager. To give other users rights to administer eDirectory objects in a Linux or NetWare environment, you need to assign them to a role. Standard administrative roles include DHCPCP Management, DNS Management, eDirectory Administration, iPrint Management, and License Management. Roles are stored in RBS Collection objects and can be viewed in iManager by following these steps:

+   1. Start iManager and log in with your administrative user name and password.
+   2. Click the Configure button and expand the Role-Based Services heading.
+   3. Click the RBS Configuration link to display the RBS collections (see Figure 7-26).
