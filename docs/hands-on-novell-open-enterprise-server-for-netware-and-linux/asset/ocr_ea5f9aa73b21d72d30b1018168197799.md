# ### Time Variables

The time variables, shown in Table 9-5, offer a variety of ways to view or check the login time.

Table 9-5 Time variables

| Variable | Description |\n| :------- | :---------- |\n| AM_PM | Used to specify day or night (possible values of "am" or "pm") |\n| GREETING_TIME | Used for displaying welcome messages, with possible values of "Morning," "Afternoon," or "Evening" |\n| HOUR | The current hour of the day or night in the range of "01" through "12" |\n| HOUR24 | The current hour in 24-hour mode, ranging from "01" to a.m. to "24" for 12 a.m. |\n| MINUTE | The current minute, ranging from "00" to "59" |\n| SECOND | The current second, ranging from "00" to "59" |

The GREETING_TIME variable is most often used in WRITE statements to display welcome messages. The HOUR variable requires using the AM_PM variable to determine whether the time is before or after noon, so the HOUR24 variable is often easier to use.
