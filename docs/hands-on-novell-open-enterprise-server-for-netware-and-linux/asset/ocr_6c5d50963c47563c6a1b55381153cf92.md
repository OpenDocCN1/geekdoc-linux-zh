Although most steps work the same in both Firefox and Internet Explorer, Firefox doesn’t open files directly from Remote Manager. To view the Hosts file in Firefox, you need to perform the following steps in place of Steps 9a and 9b:

+   a. Click the ETC directory to display its contents.
+   b. Click the hosts file and then click OK to save it to your user home directory.
