# Configuring FTP Server

FTP Server is managed and configured by using the FTP option under the File Protocols heading in iManager. You can use this option to turn the FTP server on and off, set the default home directory path, and configure user access. As shown in Figure 11-12, the FTP Server Administration window consists of four tabs: General, User, Security, and Log. In addition to setting the IP address and port number of the FTP service, you use the General tab to configure the following:

+   ■ Allow only secure connections
+   ■ Select long or DOS-based file names
+   ■ Set the data buffer size (default 64 KB)
+   ■ Set the keep alive time (the time FTP service waits before terminating a session; default is 10 minutes)
+   ■ Change the path and name of the welcome banner file
+   ■ Set firewall port limits for passive connections
+   ■ Set parameters for simulating UNIX FTP replies

You use the User tab shown in Figure 11-13 to enable the FTP service for Web publishing, set the default home server and directory, and enable anonymous users.
