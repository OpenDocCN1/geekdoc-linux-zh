**traditional volumes** — Divisions of traditional NetWare partitions that use the older NetWare file system architecture. Traditional volumes can be used to store user and application data for backward compatibility with previous versions of NetWare.

**volumes** — The major division of NetWare storage. All files are stored in volumes associated with a specific NetWare server.
