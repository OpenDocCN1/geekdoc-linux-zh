On already-existing partitions, you can change everything except the start and size of the partition.

![](bbox=[0.25, 0.3, 0.65, 0.55])

Mount in /etc/fstab by: Normally, a file system is identified in /etc/fstab by the device name. This identification can be changed so the file system to mount is found by searching for a UUID or a volume label. Not all file systems can be mounted by UUID or a volume label. If an option is disabled, it is not possible.

Volume label: The name entered in this field is used as the volume label. This normally only makes sense when you activate the option for mounting by volume label.

Mount Read-Only: No write access to the file system is possible. Switch it false.

No access time: Access times are not updated when a file is read. (Default is false.)
