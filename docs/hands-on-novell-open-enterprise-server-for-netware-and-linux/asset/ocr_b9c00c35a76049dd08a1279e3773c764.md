+   4. Enter a name for the printer pool, and then select the printer agents to be included in the pool.
+   5. Save your settings.

After creating the printer pool, the printers in the pool automatically share print jobs sent to any printer. For example, if both IT Department printers are placed in a pool and a user sends a job to the IT_Optr_1 printer while it's busy, the job is transferred automatically to the IT_Optr_2 printer if it's available.
