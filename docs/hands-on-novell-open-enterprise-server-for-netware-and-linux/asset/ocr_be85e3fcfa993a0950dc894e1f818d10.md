# Changing the Path of Default Web Content

In preparation for the NDS administration-based setting, we're placing Web site content on another volume. It's recommended to preserve the original NCS Web site content, so we've copied the original C$WEB folder to the CORP volume. To do this, Erus created an Apache2 directory with a UCWeb subdirectory on the CORP volume and copied all Web content files to the new location. To convert Apache2 Web Site Server from File mode to eDirectory mode, Erus started Apache Manager and clicked the Configuration Management button in Apache, the Primary eDirectory Location window shown in Figure 11-9. He then entered the path CORP\Apache2\UCWeb in the Location name text box and clicked the Save button. Next, he clicked the Logon button on the window to close Apache Manager and return to the Login window. Apache Web Server then looks to the new directory for all incoming Web server requests.
