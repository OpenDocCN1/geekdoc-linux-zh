## Trustee Assignment to a Group

As in file system security, a better way for users to gain effective rights is through assignments to groups or Organizational Role objects. Granting rights to Organizational Role objects makes it easier to maintain security when users change job responsibilities. When multiple users need effective rights to an object, you can use a group trustee assignment to reduce the number of trustee assignments and thereby simplify eDirectory security. In Activity 7-2, you make a group a trustee of an object and then check the group members' effective rights.
