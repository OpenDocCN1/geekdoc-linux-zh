+   3. Create a Config.sys file to load the CD drivers.

+   4. Create an Autoexec.bat file to start the NetWare 6.5 installation. This file should contain the following commands to map the CD to the E: drive and start the installation program:

```
MSCDEX.EXE /D:cdname /L:E
E:
INSTALL
```
