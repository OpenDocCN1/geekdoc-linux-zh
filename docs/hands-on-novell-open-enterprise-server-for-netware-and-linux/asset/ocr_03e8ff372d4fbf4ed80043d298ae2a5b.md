# Setting Up iPrint Components

Before setting up a Novell Open Enterprise Server network printing environment, you need to understand the basic iPrint components and how they work together. The OES iPrint system is based on **Novell Distributed Print Services (NDPS)**. NDPS is the result of a joint effort by Novell, Hewlett-Packard, and Xerox to develop a distributed network printing system based on the International Standards Organization (ISO) 10175 Document Printing Application (DPA) standard. Because this standard is supported by most printer manufacturers, NDPS supports existing and future printer products. NDPS is an improvement over earlier NetWare printing solutions because it makes network printing easier to configure, use, and manage. In addition, as part of Novell’s OneNet strategy, NDPS is the foundation of iPrint, which is based on the Internet Printing Protocol (IPP) standard. Because iPrint uses the IPP standard, NDPS printers can be accessed and managed across the Internet and within the corporate intranet.
