# Hands-on Project 14-1: Creating an eDirectory Structure in Linux

The Wiggers Heating and Air-Conditioning Company wants you to create an eDirectory tree for its organization. Use what you've learned in this chapter to create the following tree structure on your SUSE Linux server:

+   - WHA Organization
+     - Users OU
+     - Printers OU
