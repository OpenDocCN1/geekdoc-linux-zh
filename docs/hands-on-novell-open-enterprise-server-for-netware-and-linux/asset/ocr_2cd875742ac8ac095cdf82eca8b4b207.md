+   	 a. Click the **Trace Configuration** link to display the Trace Configuration window shown in Figure 7-33.

![](bbox=[0.105, 0.58, 0.595, 0.82])

+   	 b. In the DS Trace Options section, verify that the following options are selected: Inbound Synchronization, Initialization, Outbound Synchronization, and DS Agent. Click to select the **NCP Client and Streams** check boxes.
