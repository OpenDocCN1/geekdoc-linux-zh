#  500+ 电脑快捷键：精心编译和测试的 PC 快捷键组合使用指南




## 计算机键盘快捷键

### 快捷键基础

有助于提供更简单、更快捷的探索和执行计算机软件命令的方法。快捷键通常通过使用 Alt 键（在 IBM 兼容 PC 上）、Command 键（在 Apple 电脑上）、CTRL 键或 SHIFT 键与另一个键组合来访问。列出快捷键的标准惯例是先列出修饰键，然后加号，再加另一个键。换句话说，"CTRL+S" 是让您按住 CTRL 键，然后同时按下 S 键。

您还可以通过在常用程序菜单中查找带下划线的字母来发现快捷方式。例如，文件菜单图片中 "File" 的 "F" 带有下划线，这意味着您可以按下 Alt 键和 "F" 键来访问文件菜单。

某些程序需要用户按住 Alt 键才能看到带下划线的字符。在上图中，您可以看到一些常用功能，如打开（CTRL+O）和保存（CTRL+S），都有分配的快捷键。当您记住快捷键后，您会发现许多应用程序都共享这些快捷键。我们在基本 PC 快捷键部分列出了最常见的共享快捷键。

以下是适用于 IBM 兼容计算机的常用快捷键列表。如果您能尽可能多地记住它们，将大有裨益。

### 每个人都应知道的十大键盘快捷键

以下是我推荐每个人记住并使用的 10 个键盘快捷键。

| 快捷键 | 操作 |
| --- | --- |
| CTRL+C 或 CTRL+INSERT 以及 CTRL+X | CTRL+C 和 CTRL+INSERT 都会复制高亮文本或选定项目。如果您想剪切项目而非复制，请按 CTRL+X。此操作会移除文本或项目并将其存储在剪贴板中，而不是在复制到剪贴板的同时保留原始内容。<br><br>Apple 电脑用户可以用 command (CMD) 键替代其电脑上的 CTRL 键。例如，按 CMD+C 可复制高亮文本。 |
| CTRL+V 或 SHIFT+INSERT | CTRL+V 和 SHIFT+INSERT 都会粘贴文本 |
| CTRL+Z 和 CTRL+Y | 按 CTRL+Z 可撤销任何更改。例如，如果您剪切了文本，按此组合键将撤销剪切操作。这些快捷键也可以多次按下以撤销或重做多项更改。按 CTRL+Y 将重做已撤销的操作。 |
| CTRL+F 和 CTRL+G | 按 CTRL+F 可打开查找字段，允许您在支持该功能的任何程序中搜索当前显示的文本。例如，CTRL+F 可在 Internet 浏览器中使用以查找当前页面上的文本。立即按 CTRL+F 在浏览器中打开查找功能，搜索"shortcut"以显示本页中每次提到 shortcut 的位置。CTRL+G 可用于在文档或网页中重复搜索（从使用 CTRL+F 开始）。 |
| ALT+TAB 或 CTRL+TAB | 按 ALT+TAB 可在打开的程序之间向前切换。例如，如果您已打开浏览器窗口，并且其他程序在后台运行，请按住 ALT 键然后按 TAB 键来循环切换每个打开的程序。<br><br>在 Apple 电脑上，使用 Command (CMD) 键替代 Alt 键。例如，CMD+TAB 可在打开的程序之间切换。<br><br>提示：按 CTRL+TAB 可在程序内的标签页之间切换。例如，如果您在 Internet 浏览器中打开了多个标签页，按 CTRL+TAB 可在它们之间切换。<br><br>提示：添加 Shift 键到 ALT+TAB 或 CTRL+TAB 可以向后移动。例如，如果您按 ALT+TAB 时跳过了想要使用的程序，请按 ALT+SHIFT+TAB 返回到该程序。<br><br>提示：Windows Vista、7、8 和 10 用户还可以按 WINDOWS 键+TAB 以窗口的完整截图方式切换打开的程序。 |
| CTRL+BACKSPACE 和 CTRL+左或右箭头 | 按 CTRL+BACKSPACE 每次删除一个完整的单词，而不是单个字符。 |
| CTRL+BACKSPACE 和 CTRL+左或右箭头 | 按住 CTRL 键同时按左或右箭头，光标每次移动一个单词，而非一个字符。如果您想每次高亮一个单词，请按住 CTRL+SHIFT，然后按左或右箭头键。您的高亮选择将沿该每次方向移动一个单词。 |
| CTRL+S | 在几乎所有程序中处理文档或其他文件时，按 CTRL+S 可保存该文件。如果您正在处理任何重要内容，请频繁使用此快捷键，以防出现错误、断电或任何其他导致您自上次保存以来丢失工作的问题。<br><br>在 Apple 电脑上，使用 Cmd+S 保存文件 |
| CTRL+HOME 或 CTRL+END | CTRL+HOME 将光标移动到文档开头，CTRL+END 将光标移动到文档末尾。这些快捷键适用于大多数文档以及网页。<br><br>在 Apple 电脑上，使用 Cmd + 向上箭头到达文档或文本的开头，或使用 Cmd + 向下箭头到达末尾。 |
| CTRL+P | CONTROL+P 用于打开当前查看的页面或文档的打印预览。例如，立即按 CTRL+P 查看本页的打印预览。<br><br>在 Apple 电脑上，使用 Cmd+P 打开打印预览。 |
| PAGE UP、空格键和 PAGE DOWN | 正如您可能猜到的，按 Page Up 或 Page Down 键可移动到上一页或下一页。浏览 Internet 时，按空格键向下滚动一页。同样，SHIFT+空格键向上滚动一页。 |

| 在视频中跳过或跳转 | • 快进或快退：如果您想以 5 秒为增量快进或快退，请按左箭头键或右箭头键。如果需要跳过超过 5 秒，请按 **'J'** 键快退 10 秒，或按 **'L'** 键快进 10 秒。<br>- 跳转到视频章节：按数字键 **1** 到 **9** 可定位（跳转）到视频的相应百分比位置。换句话说，1 跳转到 10%，2 跳转到 20%，3 跳转到 30%，以此类推。 |
