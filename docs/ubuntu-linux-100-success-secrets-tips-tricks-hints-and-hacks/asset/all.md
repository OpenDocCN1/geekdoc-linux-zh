The Ubuntu system requirements are general guidelines only so it is still possible to install Ubuntu even if your computer systems do not meet the requirements. However, you can en counter performance issues if your hardware specifications are below the recommended requirements for Ubuntu installation.
For desktop installation, the following are the general Ub
untu requirements:
First, there is the bare minimum requirement. You need to have a 300-mhz processor with 64 MB of RAM. Aside from these, you should have an available hard disk space of 4 GB. Your computer should also have a VGA graphics card for
640x480 screen resolution. Of course you need to have a CD ROM to run the installer.

If you are attempting to install Ubuntu with bare mini mum requirements, you should use the Alternate Install CD of Ubuntu.

If your computer hardware is within the recommended minimum requirements for Ubuntu, then installation would be trouble free.

You need to have 700-mhz processor and 384 MB of
RAM. You should also have at least 8 GB of free hard disk space 21

and a graphics card for 1024x768 resolutions. Included in the minimum requirements are sound card, network card, and CD ROM.
Lastly, for full Visual Effects installation, your computer should be more powerful. Specifically, you need to have 1.2

Ubuntu AMD64 is not really different from any Ubuntu distribution. The main difference is the AMD64 for Ubuntu is designed for 64 bit processors. Whether you have Intel or AMD processor, you have to choose the AMD64 Ubuntu if you are running a 64 bit processor.
Optimizing the operating system speed is the main advan tage you can get from using Ubuntu AMD64\. Usually, 64 bit processors have RAM capacity of 4 GB or higher. If you want to maximize this kind of RAM power, then you need the Ubuntu AMD64 installed on your system.

If your computer has less RAM and you are have a 64 bit processor, using Ubuntu AMD64 will not make any speed or performance upgrade on your system. So it would be best if you can upgrade your RAM to get the most out of the Ubuntu AMD64.

If you do not want to increase your RAM capacity, you can use Ubuntu for 32 bit processor and the performance of your system will just be the same.

You can experience some problems when using Ubuntu AMD64\. Because this distribution is specifically designed for 64 bit processors, some applications that are compatible only on 32 bit processors may not run on your system.

Understanding the Advantages of Using

UbuntuSudo

In Linux , there exist a superuser named root or in Win dows lingua this is known as the Administrator. The superuser is very powerful because he can do anything and everything. With so much power at his disposal, he can type a command incor rectly and accidentally destroy the system. The ideal set-up, however, would be giving the user the needed privileges for the task at hand.
By default, the root account password is locked in Ubuntu, which doesn't allow direct login. However, he can use the sudo command to become the root user, which allows authorized users to run some programs as root without knowing the root password. Simply put, using sudo on Ubuntu means that you need sudo commands that require root privileges.
What are the advantages of using sudo on Ubuntu?
There are various benefits in leaving root logins disabled by default. First, the Ubuntu installer has fewer questions to ask. The users don't have to remember the root password, which can likely be forgotten along the way.
Moreover, the user will be asked for a password in cases of major changes. This will make the administrator think twice before making anything. Sudo on Ubuntu also adds a log entry of the commands. If an administrator has done some mistakes, he will be able to go back and see what commands have run. This is also very useful in auditing.

154

If someone were trying to enter into the box, he would have to know the account named root. Since he doesn't know the usernames of the other users and the root account password is locked, he cannot enter.

These are just a few of the benefits of using sudo on Ub untu aside from the fact that it allows easy transfer for admin rights for a short or long time.
