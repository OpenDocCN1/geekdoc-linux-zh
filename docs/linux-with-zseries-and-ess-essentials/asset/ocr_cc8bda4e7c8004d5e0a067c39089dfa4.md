# The Paths panel

A path is used to send data between the primary and secondary PPRC pairs. The physical path consists of the ESCON connection between two ESSs, while a logical path describes the connection of the PPRC source and targets. Please note that before you can create PPRC copy pair relationships, you must use the Paths panel to establish logical paths between the source and target LSSs. The Paths panel is shown in Figure 6-13. From this panel you can:

► Remove PPRC paths
