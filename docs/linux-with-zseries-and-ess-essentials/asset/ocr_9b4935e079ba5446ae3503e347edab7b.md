# zSeries and Linux

This chapter provides a brief overview of the IBM @server zSeries with a focus on how to run Linux on the zSeries architecture.

Since Linux can run on zSeries as a z/VM® guest, this chapter contains background information on z/VM for the reader to get an understanding of the features and functions that their Linux installation would inherit in that case.

Finally, this chapter discusses scenarios for scalability and consolidation of Linux solutions on zSeries.
