# The Tasks Panel

By using the Volumes, Logical Subsystems, and Paths panels you can save the setup of any data copy action within a task. A task can be any kind of FlashCopy, PPRC, and path operation. Using the Tasks panel you can run and modify saved tasks. You can also group multiple tasks into a single task group. This could be the case if multiple FlashCopy pairs from different LSSs have to be established at the same time in order to do a backup. This group of tasks can then by run by selecting the task group and running it. The Tasks panel is shown in Figure 6-14.
