# Installing Linux Using Expert Mode

By selecting the expert mode to install SuSE Linux, you will have a wider variety of options you can configure when installing SuSE Linux. We will concentrate on the Adjustments of Installation option.

When you select the expert mode for installation, YaST runs in full-feature mode (see Figure 2.37). From the YaST menu, select Adjustments of Installation, Configure Hard Disk Partitions to partition your hard disk manually from within YaST.
