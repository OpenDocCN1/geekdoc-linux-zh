The next step is selecting the path where you want StarOffice to be installed. The default directory that StarOffice offers is office51 in your home directory. You will be prompted to create this directory if it does not exist. Press Complete when you finish this step to start the installation process.

# Java Auto Detection

When the StarOffice installation starts, StarOffice tries to detect the existing Java libraries on your system to use them for Java-based scripts, applications, and applets (see Figure 25.4). If you have installed Java runtime libraries or the Java Development Kit, you will find them in a list so that you can select which one StarOffice should use. StarOffice supports the 1.1.5 and 1.1.7 versions of Java. You can disable Java's use in StarOffice by clicking the No support for Java or JavaScript in StarOffice radio button.
