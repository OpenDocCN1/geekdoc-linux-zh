7. Press F10 to exit and save.

8. Exit YaST.

That's it; you are now ready to configure your printer using YaST.

# **Configuring Your Printer Using YaST**

If you have successfully completed the previous two steps, you now are ready to start configuring your printer using YaST. Follow these steps:

+   1. Log in as root.
+   2. Run YaST.
+   3. Navigate to System Administering, Integrate Hardware Into System, Configure Printers and press Enter.
+   4. YaST runs the printer configuration module (see Figure 11.2).
