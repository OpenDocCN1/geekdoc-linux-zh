8. You need to give Samba more information about that share. The first parameter is where that share is on your local disk. Use the path parameter to tell Samba where the share is, as in the following: path = /tmp

9. Next, you need to tell Samba to set permissions on this share. Type read only = no. This tells Samba to let users write to this share. The next parameter is guest ok = yes. This parameter tells Samba to let anybody open this share.

10. Finally, give the share a string as a comment to describe it: comment = My first share

11. That's it! You have successfully created your first smb.conf file. Your next task is to test it.

This is what your final smb.conf file should look like:

```
[global]
workgroup = HOME
server string = Linux Box - Samba
[temp]
path = /tmp
read only = no
guest ok = yes
comment = My first share
```
