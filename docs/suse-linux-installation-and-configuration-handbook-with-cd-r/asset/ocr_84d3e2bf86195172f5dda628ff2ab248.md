+   - The Automatically Load What's Related option sets the behavior of this feature. If your Internet link is fast, you might want to turn it to Always; otherwise, After First Use can be a good choice.
+   - The domain names that you do not want to see when searching should be included in the edit box. You can limit the smart browsing features using this box.
