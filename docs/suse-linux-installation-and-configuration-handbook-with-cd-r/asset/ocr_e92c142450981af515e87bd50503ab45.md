# Killing a Thread

Killing a thread means disconnecting a user from the database server. Each connection uses a thread, thus, when you kill a specific thread, you're actually closing the connection, as in the following:

```
mysql>kill thread_id
```

You can obtain the thread_id by listing the process currently using MySQL. This is done through the show processlist command:

```
mysql> show processlist;
```

# Comments in MySQL

The comments in MySQL differ from those found in most database shells and are easy to use. There are two types of comments supported by MySQL:

+   - The hash sign (#)
+   - The C style comment (/* */)

The following is an example of their use:

```
mysql> select * from student;  #select all students in table
mysql>select * '/we are going to select all/'
  from student; /*the students in the table */
```

As you can see, you can insert the C style comment (/* */) inside the body of the query statement.

> NOTE MySQL does not support the -- comment that is used by most databases. This comment style does not cope with MySQL because it is not easily interpreted by it. Due to the problems it might cause, there are no plans to support it. If you have an SQL file with this type of comment, you easily can change it to the MySQL comment style by using the replace command that comes with MySQL:

```
bash$replace ".." "#" -- file.sql
```
