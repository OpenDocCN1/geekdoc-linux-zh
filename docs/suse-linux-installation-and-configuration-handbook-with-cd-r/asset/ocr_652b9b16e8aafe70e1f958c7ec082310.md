Many sound cards are supported by the three sound card drivers—OSS/lite, OSS (commercial), and ALSA. In this case, we recommend using the ALSA drivers. This is because ALSA keeps backward compatibility with OSS API, thus enabling you to run the applications that require OSS, while also running the applications that use ALSA.

# Software Requirements

The software requirements for this chapter are unique in style. The following are the general software requirements that are needed for sound to run. If you are going to use OSS/Lite, OSS, or ALSA, you will have to use the software listed in the following list along with the software specified in the section of the driver you are going to use:
