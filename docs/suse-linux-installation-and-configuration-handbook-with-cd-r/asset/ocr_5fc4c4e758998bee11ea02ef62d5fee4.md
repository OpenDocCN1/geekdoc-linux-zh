# Installing from CD-ROM

To install from CD-ROM, highlight the CD-ROM list item and press Enter. Make sure that your SuSE CD number 1 is in the drive before you press Enter. Don't get confused here---you boot from CD number 2 but install from CD number 1.

# Installing from Network (NFS)

Linuxrc will ask you for some information about your network. It will ask you for your IP, the other machine's IP, the gateway, and the mount point where SuSE Linux exists. All this information should be available to you, provided that you prepared for it earlier. Just enter that information and linuxrc will attempt to contact the other machine and read the SuSE Linux files.
