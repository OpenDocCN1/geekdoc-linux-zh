# Mouse Configuration

The mouse configuration dialog lets you specify your mouse type from a large list of mice (see Figure 2.3). Highlight the mouse type that applies to your mouse and press the Next button when you are finished. YaST2 will activate the mouse settings you made and then will continue. You should not exit the list without selecting the correct mouse type. If you select an incorrect mouse type, you should use the keyboard to get back and correct the mouse type; otherwise, you will not be able to use the mouse during the rest of the installation process.

FIGURE 2.3
By selecting the mouse type from the available list, you will be able to use your mouse during the installation process. It also will be applied to SuSE Linux after it is installed.
