The m4 macro preprocessor will use `/etc/mail/linux.mc` to generate sendmail's configuration file for you. It is still better than having to configure `/etc/sendmail.cf` directly.

# Troubleshooting

*I can't send any emails, and the server is not responding.*

Make sure that sendmail is running. You can check this by running the following command:

```
#rcsendmail status
```

If it is not running, start it by entering the following:

```
#rcsendmail start
```

*I have a dial-up connection and when I queue my mail, it doesn't get sent when I connect.*

You must run the command `sendmail -q` when you connect so that your queued mail gets sent. You can enter this command in your dial-up connection scripts or in Kppp.
