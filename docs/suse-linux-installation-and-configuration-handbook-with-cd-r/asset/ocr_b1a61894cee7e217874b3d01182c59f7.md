+   13. The next field is the Path to Faxcover. This is the path to a postscript file that will be used as the cover of the fax you are sending.
+   14. Finally, the remaining two options have to do with your time zone and locale. Set them up correctly.
+   15. When you are finished configuring it, the dialog should look similar to Figure 12.6. Click OK to save your configuration.
