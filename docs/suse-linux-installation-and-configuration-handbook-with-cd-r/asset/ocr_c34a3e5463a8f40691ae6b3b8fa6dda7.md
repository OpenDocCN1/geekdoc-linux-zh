# MSN Format

The following formats should be used with the corresponding countries. Table 23.6 is not complete but represents an example of what the MSN would be in some cases. If your country does not have MSN, you might want to try to see whether it would work the way it is represented in the table. Some PBXs still require a leading zero, though.

**Table 23.6 MSN Formats In Some European Countries**

| Country | Area Code | Phone Number | MSN |
|---|---|---|---|
| Italy | 099 | 12345678 | 9912345678 |
| Netherlands | 099 | 12345678 | 9912345678 |
| Austria | Xx | Xx | 0 or none |
| Switzerland | Xx | 123456 | Rightmost digit=6 |
| Portugal | Xx | Xx | 0 or none |
