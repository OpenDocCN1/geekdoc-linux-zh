# SuSE Linux Installation Using YaST

The installation process consists of four steps. The first step is the selection and preparation of the installation medium. The second step is deciding how you are going to boot the actual installation program. The third step is linuxrc, which is a program that runs to prepare the system for the installation. The final step is YaST, which handles the installation after the system has been prepared by linuxrc. Let's look at the required steps.

# Step 1: Selecting and Preparing the Installation Medium

The installation medium is the medium off of which you will install SuSE Linux. SuSE Linux is extremely flexible when it comes to the medium from which you want to install it. You can install it from CDs, a DVD, a hard drive, another computer on the network, and FTP. Each of these requires some preparation in one way or another.
