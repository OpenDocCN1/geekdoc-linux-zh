# SuSE Linux
INSTALLATION & CONFIGURATION
HANDBOOK

The extensive and easy-to-follow guide to optimal performance with SuSE Linux

SuSE Linux Installation & Configuration Handbook is the best reference source for installing, configuring, and maintaining SuSE Linux on your computer. By providing concise pieces of information, this book puts you right in position to get working quickly.

Authors Nazeeb Amin El-Dirghami and Youssef A. Abu Kwaik present an insightful, easy read for power users, computer systems administrators, hobbyists who want it on their computer at home, and anyone required to set up and maintain a Linux computer in a small to medium office.

With SuSE Linux Installation & Configuration Handbook, you will learn about such steps as installing the XFree86 Windows system, creating and formatting file systems, installing kernel source code, using YaST, configuring SuSE as a DNS server, and setting up the KDE and GNOME desktops.

Nazeeb Amin El-Dirghami is a software developer at ITWorx in Cairo, Egypt, where he works on Linux development. He studied computer science at the American University of Cairo. Nazeeb previously worked as a writer for an Arabic computer magazine and has written several articles on Linux for various publications.

Youssef A. Abu Kwaik also works at ITWorx, where he shared in the development of WINE for Linux and is currently working on Linux application development. He has written at least 10 articles on using SuSE Linux for Arabic and English speaking magazines.

+   - Configure your system to optimally service different users
+   - Easily upgrade all the major components of SuSE Linux
+   - Discover how to set up SuSE Linux on a multi-operating system network
