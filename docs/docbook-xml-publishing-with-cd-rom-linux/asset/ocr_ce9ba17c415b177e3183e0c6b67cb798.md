The best place to start is with the man himself, Donald E. Knuth. He is the man who invented TeX, and he is also one of the most respected people in computer science. His books are considered classics in computer science. Knuth's home page is hosted on Stanford University's Web server at http://www-cs-faculty.Stanford.EDU/~knuth/ (see Figure C.14).

The Comprehensive TeX Archive Network (CTAN) includes a comprehensive listing of all available TeX software (see Figure C.15). Not much documentation here, but the software you can eat. You can find the CTAN Web Interface at http://www.ctan.org/.

The LaTeX Project page provides quite a few resources for the LaTeX beginner (see Figure C.16). If you're looking for a foundation to build on with LaTeX, this is where to go: http://www.latex-project.org.
