> Yes, HOWTO is the proper capitalization.

However, if you're going to use the site, be sure to look for a mirror near you to save stress on the main server. You can find a list of mirrors at http://www.linuxdoc.org/mirrors.html.

Most of the guides, HOWTOs, and FAQs have DocBook source available. If you want to sharpen your DocBook skills but don't have a project that needs doing right away, you might consider volunteering to do DocBook markup for the LDP. A number of authors who don't know DocBook yet could use a hand.
