# Markup Languages

We've mentioned already that XML, HTML, and SGML are markup languages.
What does that mean?

A markup language is a set of elements used to describe how data should be handled.
For instance, as mentioned earlier in the chapter, the HTML `<b><b>` tags tell a
browser how to handle text that is enclosed within those tags: Make it bold. DocBook
is an SGML DTD that describes the use of all HTML tags. A well-formed
HTML document fits completely within the definition of the HTML DTD, and no
elements in the document are missed or not present in the HTML DTD.

DocBook is also a markup language. We explained what a markup language is but
not necessarily what its benefits are. A markup language enables the author to specify\what a piece of text is supposed to be—bold, italic, emphasized, code, a level-one
header, and so on—without worrying about how text is formatted. It allows for
abstraction, basically, and removes the author from dealing with formatting
directly.

# SGML

The SGML DTD for DocBook is the most widely used, and for quite some time the
SGML was the only official DTD for DocBook.

# Buzzword

Well-formed means that a document does not stray from the standard set by a DTD. The term appears throughout this book documents that are not formed and likely to be rendered properly. Learning to create-formed DocBook documents according to either the SGML or XML DTD is the focus of this work. We do not describe any of the shortcuts available in the SGML DocBook DTD because they do not work with each DocBook parser. Therefore, we would lose the portability of DocBook by using them.
