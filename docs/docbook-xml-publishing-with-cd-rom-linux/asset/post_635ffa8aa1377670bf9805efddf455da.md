# About the Authors

JO "ZONKER" BROCKMEIER is a long-time user of Linux and other Free and Open Source software. Zonker is a contributing editor for Linux Magazine and Review.com, and has had articles published in Sys Admin, Enterprise Linux, Computer, and IBM.

KARA PRITCHARD is currently the Director of Development for Linux Institute, working to develop the standard for Linux. As an independent consultant, Kara has been promoting the use of Linux in both corporate and educational facilities since 1995. She published her first book, RHCE, in 1999 (2nd ed.). Kara runs the Linux Groups project at http://www.linuxgroups.org/. You can contact her at kara@linux.org.
