## Making CVS Simple with TkCVS

This section describes TkCVS, a GUI CVS client written in Tcl/Tk. The reason we chose this GUI client from other available clients is mostly that it's simple to set up and with Tcl/Tk 8.1 or higher, TkCVS runs on Linux and other UNIX-type OSes with Tcl/Tk 8.1 or higher, as well as Windows 9x or NT.

TkCVS does require Tcl/Tk version 8.1 or higher. Most Linux distributions come with this already. If you're running a relatively recent version of Linux, you should already have this installed.

## Using TkCVS

To start TkCVS, run the `tkCVS` command. TkCVS first checks to see what the CVSROOT environment variable is; if it's not set, you will get an error. To set the CVSROOT environment variable, run the following:

```
export CVSROOT="/mnt/cvsroot"
```

or if you are using c:

```
setenv CVSROOT "/mnt/cvsroot"
```

When TkCVS starts up, it opens as a window (see Figure 7.11). You can open and view files with it like standard.
