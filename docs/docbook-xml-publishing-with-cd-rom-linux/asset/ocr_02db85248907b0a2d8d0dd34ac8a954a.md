> Note that the Anchor element in DocBook markup (<anchor>) and the Anchor element in HTML (<a>) are completely different and do not use the same syntax. Although they have the same purpose, generating hyperlinks and references, they do not bear much other relation.

To use the Anchor element, use the following syntax:

```
<para>
This is an example of the <anchor id="xref.example" xref="XRef Example"> XRef and Anchor elements.
</para>
```

The Anchor element is also an empty element. If used with the XML DTD, you must be sure to close the element with the / character, like this:

```
<anchor id="xref.example" xref="XRef Example">
```
