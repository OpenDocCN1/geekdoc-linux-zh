Note that the ImageData element is an empty element, so in XML markup,
y must include a trailing slash in the markup to indicate an empty element,
like this:

```
<imagedata href="image.jpg"/>
```

> Remember that an empty element is an element that doesn't require a
closing or end tag, not an element that contains no information. An
empty element contains all its information as an attribute or requires no
additional information.
