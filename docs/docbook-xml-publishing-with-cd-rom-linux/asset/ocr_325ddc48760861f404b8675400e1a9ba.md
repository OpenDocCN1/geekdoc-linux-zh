# MsgSub

The MsgSub element contains parts of a message.

The MsgSub element uses common attributes.

Example:

See MsgSet element example.

# MsgText

The MsgText element contains the actual text of a message.

The MsgText element uses common attributes.

Example:

See MsgSet element example.

# Option

The Option element indicates an option to a command.

The Option element uses common attributes.

Example:

```
<para>
<command>is <option>-l</option></command>
</para>
```
