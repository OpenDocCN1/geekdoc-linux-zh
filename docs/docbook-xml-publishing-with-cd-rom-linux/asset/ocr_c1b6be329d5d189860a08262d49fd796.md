# Installing SGMLtools-Lite

The SGMLtools-Lite home page is located at http://sourceforge.net/projects/sgmltools-lite/

You can find the latest versions of SGMLtools-Lite, if there be updates. You may want to find distribution specific packages, however, as they should have been tested against the distribution you're using.

One of the headaches I experienced when installing SGMLtools-Lite was a missing and/or misconfigured catalog file. To make life easier for you, I've included a working catalog file for each distribution on the CD-ROM. You should also add the following to your .bashrc to make sure that the proper location of the catalog file is in your environment:

```
SGML_CATALOG_FILES=/usr/share/sgml/catalog
```

Copy the catalog file for your distribution to the /usr/share/sgml/ directory. You might need to log in as root before you can create a file in that directory. You must also run this command to set the environment variable property until you log out and back in:

```
export SGML_CATALOG_FILES=/usr/share/sgml/catalog
```
