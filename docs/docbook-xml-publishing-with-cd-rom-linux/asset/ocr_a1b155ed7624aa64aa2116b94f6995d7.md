# Converting to HTML

Converting your document to HTML is more thoroughly covered in Chapter 6, “Parsing DocBook.\” However, I’ll run through the steps quickly here because I want to share with you some finishing touches that pertain to HTML.

If you’re using SGMLTools or SGMLtools-lite to output HTML from a DocBook document, use the following syntax:

```
sgmltools -b html document.sgml
```

or for XML documents, use

```
sgmltools -b html document.xml
```

If no problems, or at least no serious problems, occur with the markup in your document, you will have one or more files generated by SGMLTools.
