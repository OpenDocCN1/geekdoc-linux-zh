Vim. The most popular of vi clones. Vim maintains compatibility with most of the features of the original by default but also has many features that the original lacks, including syntax highlighting and multiple editing buffers

W3C. The World Wide Web Consortium. The W3C promotes many Web standards, including HTML, XML, XHTML, CSS, and MathML. The W3C is vendor neutral, and the standards it maintains are freely available, unlike ISO standards

Whitespace. The blank space in text documents, including blanks, tab stops and spaces between words

Word Processor. A program that produces formatted output and visually operates on a WYSIWYG principle. Word processors save files in a proprietary document format that cannot be opened by tools like DocBook, Microsoft Word, Corel WordPerfect, and Adobe Word are examples of word processors

WYSIWYG. What You See Is What You Get. WYSIWYG editors allow the user to define exactly what a document looks like while creating it, displaying the document as it will appear when printed

XML. The Extensible Markup Language. Yes, it should probably be XML but computer geeks really like the letter X. XML is a representation of XML as a subset of SGML and is designed for sharing data over the Internet and to overcome the shortcomings of HTML

XSL. The Extensible Stylesheet Language. XSL stylesheets provide the rules for a document's presentation and, independent of its content
