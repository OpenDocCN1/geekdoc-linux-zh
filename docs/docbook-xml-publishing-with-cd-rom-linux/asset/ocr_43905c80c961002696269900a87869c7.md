# Editing DocBook in Emacs

Move from the Fundamental mode to the PSGML mode in Emacs, type M-x sgml-mode. If all the files are in the right places, you should now be in PSGML mode (see Figure 8.14).

The PSGML mode offers some advantages for marking up DocBook documents. You will note that when you enter the PSGML mode, you have additional menus to work with that are specifically concerned with SGML.

Using the menus in PSGML mode, you can insert elements and attributes, hide the markup to look only at the text, and even validate the document and look for errors.
