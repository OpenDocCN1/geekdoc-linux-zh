# Validating the XML Schema

If you're trying your hand at creating DocBook documents that conform to the XML Schema, not many tools are available at this time to validate the Schema or your efforts at making a valid document. However, there is an online resource for checking your documents, provided that your Schema is available online. The World Wide Consortium offers this resource at http://www.w3.org/2000/06/webdata/xsv (see Figure 11.4).
