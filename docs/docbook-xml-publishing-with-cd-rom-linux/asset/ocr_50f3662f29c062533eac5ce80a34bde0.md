# # What Is DocBook?

So, what is this DocBook stuff anyway? Technically, DocBook is an SGML or
XML Document Type Definition—DTD, for short (more on SGML and XML in
a moment). However, DocBook is often used to refer to the parsing tools,
sheets, and other tools used to work with DocBook collectively. Generally
speaking, when the term DocBook is used in this work, it refers to the entire colle-
cion of tools used to produce documentation in DocBook, not just the DTD and
sheets.

# # History of DocBook

Obviously, DocBook did not magically appear. In one form or another, it has been
 around 1991. DocBook began life as a DTD designed by O'Reilly and Associ-
ates and Hal. Computer Systems to help convert UNIX documentation into an eas-
ilyable format.

O'Reilly then passed DocBook to the Davenport Group, an organization created
by O'Reilly and Associates to provide a forum for companies and organizations pro-
ducing computer documentation. This lasted through the third version of DocBook.
Eventually, the Davenport Group began to focus on XML, and DocBook develop-
ment took a back burner.

DocBook found a home with OASIS in 1998.

# # OASIS

OASIS is the Organization for the Advancement of Structured Information Stan-
dards, a nonprofit, international consortium. It creates industry specifications based
on on public standards such as XML and SGML and, to a lesser extent, other standards
related to structured information processing.

OASIS has a technical committee dedicated to overseeing DocBook development
that was formed in July 1998. The OASIS DocBook Technical Committee maintains
t SGML and XML versions of the DocBook DTD. The DocBook Technical
Committee is also in the process of developing a DocBook XML Schema, but there is
is official release at this time.

You can find OASIS at http://www.oasis-open.org/
