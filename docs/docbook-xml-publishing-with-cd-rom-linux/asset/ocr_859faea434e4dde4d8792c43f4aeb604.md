The RefEntry element is not restricted to use with the Reference element. it can be used nearly anywhere in a document.

The RefMeta element holds the meta-information about the RefEntry element, particularly the title of the RefEntry, which is included within the RefEntryTitle element.

The RefS1 element is similar to the Sect1 element, except that it is specific to the RefEntry element. There are three levels of RefS element, RefS1 through RefS3. As with the Sect elements, the RefElements do not hold content directly. The Para element is used below the RefSect elements to hold content.
