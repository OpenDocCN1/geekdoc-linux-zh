The MenuChoice element is used to indicate a sequence of selections from a menu. The GuiMenu element holds the name of the top-level menu choice; the GuiSubMenu element holds any lower-level menus; and the GuiMenuItem holds the name of the selection from the menu. When output is generated from the Docbook document the sequence from the top-level menu to the menu choice will be indicated as shown in Figure 12.6 (HTML output) and Figure 12.7 (text output).
