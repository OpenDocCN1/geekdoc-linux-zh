## BlockQuote

The BlockQuote element indicates a quote that should be set off from the rest of the text. Usually, any quote that is three or more lines should be enclosed in a BlockQuote.

The BlockQuote element uses common attributes.

Example:

```xml
<para>A quote from "Mythical Man Month": </para>
<<blockquote><attribution>Frederick Brooks Jr.</attribution>
<para>As the system comes up, the component builders will grow from time to appear, bearing hot versions of their pieces -- faster, smaller, more complete,or putatively buggy. The replacement of a working component by a new component requires the same systematic testing procedure that adding a new component does, although it should require less time, for more complete and efficient test cases will usually be available.</para>
</blockquote>
```

## BridgeHead

The BridgeHead element creates a heading that has no text associated with it.

The BridgeHead element uses this attribute in addition to common attributes.

- RenderAs. Identifies how to render the BridgeHead.

Example:

```xml
<chapter>
<bridgehead rederas="sect1"> Header</bridgehead>
<para>...</para>
</chapter>
```

## Caution

The Caution element indicates a block of text that should be set off from the rest of the text to draw attention to its contents. With most formatting systems, the Caution element also causes a caution graphic of some sort to be displayed with the Caution element.

The Caution element uses common attributes.

Example:

```xml
<caut>
<para>Don't run with scissors</para>
</caut>
```

## Emphasis

The Emphasis element indicates text that should be emphasized in some way. This is better than markup such as HTML, which allows for italic or bold text to be called directly. Both italic and boldface are lost when the text is read through a text-to-speech device or is rendered in plain text.

The Emphasis element uses common attributes.

Example:

```xml
<para>I am <emphasis>really</emphasis> tired.</para>
```

## Equation

The Equation element indicates an equation.

The Equation element accepts the following attribute in addition to the common attributes:

- Label. Accepts a CDATA value, has no default value, and is not required

Example:

```xml
<equation><title>Pythagorean Theorem</title>
<alt>a^2 + b^2 = c^2</alt>
<graphic fileref="equations/pythagorean.gif"></graphic>
</equation>
```

## ItemizedList

The ItemizedList element contains a list of items marked with a bullet or other designated marker. This is somewhat different from the OrderedList element, which contains a list that is sequentially labeled.

The ItemizedList element uses these attributes in addition to the common attributes.

- Spacing. Accepts either Compact or Normal as a value, has no default value, and is not required.
- Mark. Accepts bullet, dash, or other symbol, and is not required.

Example:

```xml
<listitemized mark=dash>
<listitem><para>HTML</para></listitem>
<listitem><para>SGML</para></listitem>
<listitem><para>XML</para></listitem>
</listitemized>
```

## literallayout

The LiteralLayout element indicates text that should be displayed as-is. White space and line breaks should be rendered exactly as they are between the LiteralLayout markup tags.

The LiteralLayout element uses common attributes.

Example:

```xml
<literallayout>
If you wanted to have a section
with spacing and linebreaks wherever you want
you use literallayout.
</literallayout>
```

## OrderedList

The OrderedList element contains a list of items that are sequentially labeled. This is different from the ItemizedList element, which contains a list with a bullet or other designated marker.

The OrderedList element uses these attributes in addition to the common attributes:

- Continuation. Accepts one of two values:
  - Continues
  - Restarts
The default is Restarts.
- Inherit. Accepts Ignore or Inherit. The default is Inherit.
- Numeration. Accepts one of the following:
  - Arabic
  - LowerAlpha
  - LowerRoman
  - UpperAlpha
- Spacing. Accepts either Compact or Normal as a value, has no default value, and is not required.

Example:

```xml
<orderedlist numeration="Upperroman">
  <item><para>Chapter 1</para></item>
  <item><para>Chapter 2</para></item>
</orderedlist>
```

## Sidebar

The Sidebar element indicates that the information contained the Sidebar markup should be displayed as a sidebar, if the processing system allows that.

The Sidebar element uses common attributes.

Example:

```xml
<para>...</para>
<sidebar><title>My Sidebar</title>
<para>This is a sidebar.</para>
</sidebar>
<para>...</para>
```

## SimpleList

The SimpleList element contains a list that contains a simple list.

The SimpleList element uses these attributes in addition to the common attributes.

- Columns. Accepts number of columns to display. Default is 1.
- Type. Sets column type, vertical, horizontal, in-line. The default is Vertical.

Example:

```xml
<para>My phone keypad looks like this:
<simplelist type=horiz columns=3>
<member>1</member>
<member>2</member>
<member>3</member>
<member>4</member>
</simplelist>
</para>
```

## Indexing Elements

DocBook contains a rich set of indexing elements for anyone who wants to create his own index using DocBook markup, or if used correctly and the processing system supports it, to have the processing system generate the index automatically.

## Index

The Index element holds the markup for a DocBook index.

The Index element uses common attributes.

Example:

```xml
<index><title>Index</title>
<indexdiv><title>Cc</title>
<indexentry>
  <primaryye>Class networks, 65</primaryye>
  <secondary>A, 65, 80</secondary>
  <secondary>B, 65, 66, 80</secondary>
</indexentry>
</indexdiv>
</index>
```
