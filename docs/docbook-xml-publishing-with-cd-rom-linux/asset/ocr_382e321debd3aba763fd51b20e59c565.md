# Appendix A: DocBook Glossary

DSSL. See the Document Style Semantics and Specification Language.

DOCTYPE. Specifies the root element of a document. The DOCTYPE is indicated the document declaration at the beginning of a document. All SGML documents and most XML documents begin with a declaration.

Document Style Semantics and Specification Language (DSSL). Used to specify formatting of an SGML or XML document. ISO standard 10179:1996 defines DSSL.

Document Type Definition (DTD). Defines the structure and data elements for documents. DTDs are used with SGML, HTML, and XML. There are DocBook DTDs for SGML and XML.

DTD. See Document Type Definition.

Electronic Data Interchange (EDI). An ANSI standard for exchanging business data.

Element. Part of SGML and XML markup defines document content. The meaning of an SGML or XML element is defined by the TTD of the document. DocBook documents are parsed by programs such as Jade or OpenJade, which interpret the elements and their attributes the DTD and stylesheets to produce output in HTML. PostScript, PDF, and other formats.

Emacs. A text editor with a huge number of features, including content-sensitive editing, e-mail and newsgroup support, a Web browser, and its own Lisp interpreter. Emacs is short for Editor Macros. Richard M. Stallman (RMS, for short) began work on the first version of Emacs in 1976 at M.I.T. Emacs is part of the GNU project and a popular editor for working with DocBook.

End Tag. Markup indicating the end of an element.

Entity. A name or reference to a bit or type of data. In the body of a document containing DocBook markup, entities begin with the ampersand (&) and end with a semicolon (;). Entities are classified as internal or external. They are declared in the DTD or document declaration, with the following markup for internal entities:

```
<!ENTITY entity_name "Entity text">
External entities are declared like this:
<!ENTITY entity_name SYSTEM "entity.sqml">
```
