# Chapter 4: Preparing a Book with DocBook

```
<glossaryinfo>
<editor><firstname>Joe</firstname><othername>"Zonker"</othername><surname>Brockmeier</surname></editor></glossaryinfo>
```

```
<title>Really Neat Sample Glossary</title>
<para>You can include an introduction to the glossary if you like like.</para>
<div>
<title>A</title>
<glossentry>
<glosssterm>Abstract</glosssterm>
<glossdef>
<para>The Abstract element contains information about an article, book, or other work. An abstract is a brief summary or description of the contents of a work.</para>
</glossdef>
</glossentry>
</div>
```

```
<div>
<title>B</title>
<glossentry>
<glosssterm>Book</glosssterm>
<glossdef>
<para>The Book element contains all the components of a DocBook book.</para>
</glossdef>
</glossentry>
</div>
```

The Glossary element contains the GlossDiv, GlossEntry, GlossTerm, and GlossDef elements. Again, using the GlossDiv element is optional on whether your document is large enough to be divided. The GlossEntry element starts a new entry in your glossary; the GlossTerm element contains the term being defined in this glossary entry. The GlossDef element contains the actual definition of the GlossTerm. Be sure to nest the elements properly, as shown in the preceding example, or your parser will produce a number of errors.
