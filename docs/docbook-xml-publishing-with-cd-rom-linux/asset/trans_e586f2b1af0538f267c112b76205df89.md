## 引言

欢迎阅读《DocBook Publishing》，这是一本为任何想要学习 DocBook 的人编写的书。你不需要成为计算机专家或技术天才，这本书既用户友好又充满趣味。我们希望你在阅读它时，能像我们编写它时一样愉快。

## 关于本书

《DocBook Publishing》是一份关于如何使用 DocBook 创建几乎任何类型的文档或出版物的柔和指南。我们决定写一本关于 DocBook 的书有两个原因。首先，我们坚信对于任何需要制作并在媒介分发出版物的人来说， DocBook 是一个极佳的解决方案。遗憾的是，在少数大多数专业使用它的极小群体之外，DocBook 的知名度并没有达到应有的水平。我们将详尽讨论 DocBook 与其他制作方法相比的各自优势，但基本上我们对它着迷了，并且希望看到更多人也被它吸引。我们希望这本书能作为一个良好的资源，让过渡到 DocBook 变得更容易，并鼓励人们考虑 DocBook 而其他不那么优雅的解决方案。

其次，我们发现关于 DocBook 的用户友好型文档非常少，这很遗憾。如果没有关于如何使用这套统称为 DocBook 的奇妙工具的信息，绝大多数可以从中获益的用户就会与它失之。我们。我们希望手中的这本书能提供你在 DocBook 中高效工作所需的所有信息，并且阅读过程不会太痛苦。我们 Try 避免使用术语，在绝对无法避免使用术语的地方，我们提供了通俗易懂的解释。
