The drawback to using PNG images is the question of software and browser support. PNGs are supported by the latest versions of Netscape Navigator and Internet Explorer, but older versions may not handle PNGs well or at all. Some features of PNGs (transparency, for example) may also be unavailable in certain browsers. If you are catering to Netscape or Internet Explorer versions-3 or earlier, it is probably best to stick with JPEGs. If you are certain that your audience is to be users with newer browsers, use PNGs with confidence.

By the same token, if you're using early versions of Adobe Photoshop or image-manipulating programs, you may not have support for saving graphics in the PNG format.

PNGs offer the best of both worlds: a non-lossy image format that has a small image size, offers transparency, and supports indexed-color, grayscale, and truecolor images (see Figure 3.2).

To test your browser, point it at this URL: http://www.w3.org/Graphics/PNG/inline alpha.html.
