# Summary

This chapter is a brief summary of Emacs and the PSGML major mode for editing SGML and XML documents in Emacs. Unfortunately, there's not room for an exhaustive look at Emacs, but this chapter presents enough information to get you started with Emacs and help you wade in comfortably. Emacs is not an editor to be taken lightly—Steven Hawking would probably need a couple of days to digest all the functions available in Emacs. However, when you get to know Emacs, you can become extremely proficient in it and very productive. Many programmers and writers—including Neal Stephenson, the author of Snow Crash and Cryptonomicon—prefer Emacs.
