# Quote

The Quote element holds a quotation used in-line. The Quote element is used for shorter quotations that appear in the text, not longer quotations that are broken out from the text, such as a BlockQuote.

The Quote element uses common attributes.

Example:

```
<quote>Clothes make the man. Naked people have little or no influence in society.\</quote>
```

# SeriesInfo

The SeriesInfo element holds information about the series containing a book.

The SeriesInfo element uses common attributes.

Example:

```
<seriesinfo>
  <title>DocBook Publishing</title>
  <seriesvolumes>1</seriesvolumes>
  <editor>
    <firstname>Melody</firstname>
    <surname>Layne</surname>
  </editor>
  <publisher>...</publisher>
</seriesinfo>
```
