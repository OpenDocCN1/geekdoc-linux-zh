Linux is a free Unix-like operating system created by Linus Torvalds with the assistance of many people around the world. The source code for Linux is freely available to anyone who wants to learn more about the operating system that is running on their computer.

Linux's mission is to get people to use Linux. Linus Torvalds says we're the first to make it free and we want to get you to use it too. You can download it, install it, and tell your friends.

There are also other open-source operating systems like BSD, which includes FreeBSD and OpenBSD. These are also all UNIX-like OS that have the best of all worlds, just different from Linux.

Figure C.13 The Linux Online Web site

If you're not already using Linux or one of the BSDs, I hope that you will check out and see what they have to offer. I've been using Linux for almost five years now, and I wish that I had started sooner!

There's not a huge amount of difference between Linux and FreeBSD, NetBSD, or OpenBSD, especially compared to the difference between them and Windows or the MacOS. They're all free, UNIX-like OSes that run on a variety of hardware, including Intel-based PCs. Linux is the most popular, but they all have great features to offer. They are also very powerful, make great use of hardware, and are extremely stable. Not only that, a huge amount of free software is available for those OSEs that would cost thousands (yes, I said thousands) of dollars for other OSes.

Give one of 'em a whirl. You will be glad you did. Even if you decide that they're not for you, you will know more about them than you did before, and you will know that you made a conscious decision to use whatever OS you're using.
