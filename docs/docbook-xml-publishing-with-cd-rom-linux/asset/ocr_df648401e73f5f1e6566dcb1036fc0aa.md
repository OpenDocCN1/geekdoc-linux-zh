# Table

The Table element indicates a DocBook table with a title.

The Table element accepts the following attributes:

+   - Colsep
- Label
- Frame
- Orient
- Prowide
- Rowsep
- Shortentry
- ToCentry

Example:

```
<table frame="all"><title>My First Table</title>
<tgroup cols="5" align="left colsep=1 rowspan=1>
<colspec colname=col1>
<colspec colname=col2>
<head>
<row>
  <entry>FIRST</entry>
  <entry>LAST</entry>
  <entry>M.I</entry>
  <entry>D.O.B.</entry>
  <entry>SSN</entry>
</row>
</head>
<tfoot>n<row>
  <entry>n1</entry>
  <entry>n2</entry>
  <entry>n3</entry>
  <entry>d1</entry>
  <entry>s1</entry>
</row>
</tfoot>
<tbody>
<row>
  <entry>Kara</entry>
  <entry>Pritchard</entry>
  <entry>J</entry>
  <entry>8-23-00</entry>
  <entry>123-45-6789</entry>
</row>
</tbody>
</tgroup>
</table>
```
