# Creating an Appendix

Appendices often appear in technical and reference works and include information from the text of the book but in a distilled and more concise form.

As with this book, most of the information found in the appendix is in the text of the book itself, although some is not. However, it can be very inconvenient having to thumb through the book's examples to find out how the Book element is used and the appropriate syntax. Therefore, there's an appendix dealing with all the DocBook elements. It is easy to browse and more complete than would be readable in the body of the book. However boring, for example, to have a full and complete reference of all possible permutations of the Book element in the text of the book, but how much useful when collated and as a reference in an appendix.
