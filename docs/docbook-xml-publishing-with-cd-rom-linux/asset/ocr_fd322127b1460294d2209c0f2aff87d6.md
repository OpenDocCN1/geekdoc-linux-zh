# Typical Markup

The following sections will introduce you to some typical DocBook markup.

# The Abstract Element

The Abstract element contains information about the article itself, usually a
short paragraph or two about the contents of the article.

This example shows basic usage of the Abstract element. The Title element
isplicated.

```
<abstract>
<title>Basic Article Abstract</title>
<para>Summary of the article</para>
</abstract>
```

# The Abbre Element

To denote an abbreviation within a document, use the Abbre element.
(Appropriately enough, abbreviation is abbreviated. Ever wonder why appre-
viation is a long word?) This example shows the standard use of the
Abbre element.

```
<para>
You can find our new offices in Santa Clara, <abbre>Calif.</abbre>
</para>
```

# The Acronym Element

The Acronym element is used to denote an acronym used in the text of a doc-
ment, such as KDE, GNOME, and FBI. Depending on the stylesheet, the
contents of the acronym element might be displayed differently than regular
text. The code example shows the standard use of the Acronym element.

```
<para>
No one likes it when the <acronym>IRS</acronym> or the
<acronym>FBI</acronym> shows up on the doorstep.
</para>
```
