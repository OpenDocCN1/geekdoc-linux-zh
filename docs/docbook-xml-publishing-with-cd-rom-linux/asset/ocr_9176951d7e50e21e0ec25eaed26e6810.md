# Using MathML for Mathematical Equations

If you’re using the XML DTD, you have the option of including MathML equations in your DocBook document. MathML is a markup language for mathematical and scientific content. Mainly, MathML is designed for sharing equations via the Web; it is not as concerned with print and other forms of output. However, with the appropriate use of stylesheets, there’s no reason that MathML cannot produce excellent print output as well.
