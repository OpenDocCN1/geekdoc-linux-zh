# BookInfo

The BibliographyInfo element uses common attributes.
See the BookInfo element for an example.

The BookInfo element contains the meta-information about a DocBook book.
The BookInfo element uses common attributes.
nExample:

```
<!DOCTYPE book PUBLIC "//OASIS//DTD DocBook V4.1//EN">
<bookinfo>
<title>A Nifty Book</title>
<author>
<firstname>Joe</firstname>
<surname>Brockmeier</surname>
</author>
<publisher>
<publishername>Prima Tech</publishername>
</publisher>
<pubdate>2001</pubdate>
</bookinfo>
..

</book>
```
