# Format documents hassle-free with DocBook!

Tired of spending more time trying to format your documents than you spend actually writing? DocBook could be the production tool that you're looking for! This book's user-friendly format shows how you can use DocBook's markup language to produce professional documents that can be easily distributed in a variety of media.

Joe 'Zonker' Brockmeier has been using and writing about Linux* and Open Source since 1998. He is a contributing editor to Linux Magazine, a senior editor with User Friendly Media, and is the author of PRIMA TECH's Install, Configure, and Customize Slackware Linux.

Kara Pritchard has been promoting the use of Linux in corporate and educational facilities since 1995. She is the Director of Exam Development for the Linux Professional Institute and runs the Linux User's Group resource project at www.linuxusersgroup.org.
