# DocBook and Open Source

A number of Open Source projects are DocBook, most notably, the Linux Documentation Project, which has switched from the Linux DTD to DocBook.

Because DocBook is an open standard—portable across platforms and designed to output HTML, PostScript, RTF, PDF, ASCII text, and several other file formats—it is ideal for projects that want printable documents, online documents, and electronic documents that look exactly like printed documents.

# SGML/XML

Metalanguage is a definition or description of language, a language used to talk about language. The rules of English grammar could be described as metanguage, language that enables us to understand word usage in the English language. Meta is a prefix that, depending on context, refers either to change (as in phosphorus) or, to information technology, to some more comprehensive (as in metadata).

You've probably heard the terms SGML and XML a few times but might be confused about what they are. SGML stands for Standard Generalized Markup Language, and XML is the Extensible Markup Language. To make things even murkier for the beginner, XML is often taken as a separate technology, but in reality, XML is a subset of SGML.

What are SGML and XML? SGML is a metanguage used to define rules for how a document can be described. SGML DTDs spell out what allowable markup is and how it is to use. For example, HTML is an SGML DTD. In HTML, the DTD is the full description of the HTML language, and it offers information about HTML markup. If you've ever used XML, you know that the DTD tells a browser `<b>` makes text bold, `<i>` makes text italic, and `<img>` describes the attributes of an image—including where the image can be found and possibly the height, width, and alignment for the text. However, because the DTD does not describe a `<wohoo>` tag, browsers will probably ignore it or render it poorly.

XML, as mentioned before, is a subset of SGML. XML is an official recommendation from the W3C—the World Web Consortium, the organization responsible for HTML specifications. XML is actually a set of specifications for documentation that are designed to be SGML-compatible, human and machine readable, and Web friendly, making the creation of documents easy. That's a tall order, but the W3C has been successful in creating a recommendation that is being adopted even before the final specification is approved.

XML is used for a number of tasks. Microsoft is using XML to some extent in its Office file formats, many programs use XML configuration files, and quite a few companies use XML to exchange data with one another for business-to-business transactions over the Internet. That's just a few of XMLs other roles, aside the XML DocBook DTD.
