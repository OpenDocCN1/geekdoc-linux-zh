# Working with the Part Element

Sometimes it is useful to organize the chapters of a book by parts. For example, if you were writing a book about the American Revolution, you might have several chapters about specific events leading up to the American Revolution, followed-by chapters about battles of the Revolution and other noteworthy events that took place during the Revolution. Finally, you would probably have several more chapters that cover the aftermath of the American Revolution.
