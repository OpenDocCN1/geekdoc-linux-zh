# Book

The Book element begins a DocBook book.

The Book element accepts the following attributes in addition to the common attributes:

+   - FPI (Formal Public Identifier). Takes a CDATA value, has no default value, and is not required.
- Label. Accepts a CDATA value, has no default value, and is not required.
- Status. Accepts a CDATA value, has no default value, and is not required.

Example:

```
<!DOCTYPE book PUBLIC "-//ASIS//DTD DocBook V4.1//EN">
<book>
  <bookinfo>
    <title>...</title>
  </bookinfo>
  <chapter>...</chapter>
  <index>...</index>
</book>
```

# Chapter

The Chapter element accepts the following attributes in addition to the common attributes:

+   - Label. Accepts a CDATA value, has no default value, and is not required.
- Status. Accepts a CDATA value, has no default value, and is not required.
