# Chapter 3: Using Images

We've all probably heard the saying "A picture is worth a thousand words." Strictly speaking, this isn't entirely true—I've never had an editor who was willing to accept two pictures in place of a 2,000 word article, for instance. However, it is true that images and figures are often helpful in documentation.

This chapter explains how you use DocBook markup to include images in your DocBook documents, how you create tables using DocBook markup, and how you prepare documents with images for multiple output formats. It also briefly looks at using MathML, a markup language for mathematical equations that can be used with DocBook XML, and gives a brief overview of using TeX and LaTeX for figures and equations with DocBook SGML...

It might also be a good time to note that DocBook is not appropriate for. While DocBook is excellent for books, technical articles, online documentation, and many others, it isn't a replacement for programs like QuarkPress or Adobe Illustrator. You won't be able to do super-fancy tricks with text or do exotic things with graphics you see in Rolling Stone or other graphics-intensive magazines. If you're working in that kind of environment, it still makes sense to have authors submit work in DocBook, but do the layout in the program of your choice.

> TeX, pronounced "tech," is a typesetting program written by legendary hacker Donald Knuth. LaTeX, pronounced "la-tech," is a collection of macros that are designed to make typesetting with TeX much easier, allowing the author to concentrate more on the document structure and content than on the presentation. (Sounds a little like DocBook, doesn't it?) Just because TeX and LaTeX are used specifically for typesetting doesn't mean they're WYSIWYG programs or that they're easy to use. TeX markup makes DocBook markup look like a piece of cake.
