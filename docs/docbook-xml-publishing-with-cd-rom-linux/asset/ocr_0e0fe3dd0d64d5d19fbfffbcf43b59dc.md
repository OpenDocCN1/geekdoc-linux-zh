# GNU Emacs 20.6 for Mac OS Release d5

This is the home page of GNU Emacs 20.6 for Mac OS. Emacs 20.6 for Mac OS implements many of
Emacs's features (see screenshot #1). This version adds support for fonts (screenshot #2) and international
character set support (screenshot #3).

It is distributed under the GNU Public License in hopes that others may contribute to its development. For a list of
features it already supports and other questions you may have, please see the FAQ file.

# Obtaining Files

+   Release d5 is distributed in three forms- source-only, binary, and full distributions:
- The source distribution is for developers who have access to the GNU Emacs 20.6 source distribution.
With this distribution, you can patch the access to source distribution, prepare the projects, and build
run Emacs.
- The binary distribution is a pre-built distribution for users who wish to run Emacs but not build it.
- The full distribution contains all of the GNU Emacs 20.6 standard distribution with the patches applied
and prepared and built.

All distributions are Mac Binary II self-signing disk images (.DMG) files. The Mac Binary II format
requires decompressing. Ensure you have Disk Utility installed.

You can also sign up for a mailing list for users of Emacs for the MacOS and

To use Emacs for the MacOS, you need MacOS 8.1 or later.

Now that you have installed GNU Emacs on the operating system of your
choice, you can start using it.

# Basic Emacs Guide

Before jumping into editing DocBook files with Emacs, take a moment for
an introduction to Emacs basics. There's quite a bit to Emacs, so I cannot
cover all the functionality available in Emacs. It would take an entire book to
do that, maybe two (it has a lot of functions!). However, you will learn all the
basics of text editing so that you can work comfortably with DocBook.
