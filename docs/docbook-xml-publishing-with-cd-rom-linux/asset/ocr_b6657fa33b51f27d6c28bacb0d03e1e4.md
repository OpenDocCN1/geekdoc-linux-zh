# Formal Examples

If you have a larger code sample that you want to appear as a formal example set off from the text with a title, you can combine the ProgramListing element with the Example element. By the way, the Example element is not limited to code or program listings, it can be used for any type of example that should set off from the main text with a title. The next code sample demonstrates how to use the Example element with a ProgramListing. Figure 12.2 shows the output from the ProgramListing code example, and Figure 12.3 shows

```
<!DOCTYPE article PUBLIC "//OASIS//DTD DocBook V4.1//EN">
<article><title>Example</title>
<example><title>Sample PHP Script</title>
<programlisting><![CDATA[\<?php echo "The Current Date and Time is:&nbsp;<br>"\necho date("g:i A 1, F j Y");"
// g = the hour, in 12-hour format
// i = minutes
// A = print AM or PM, depending...
// l = print the day of the month
// F = print the month
// j = print the day of the month
// Y = print the year - all four digits

<br>
<?php echo "Hello, World!";?>
]]></programlisting>
</example>
</article>
```
