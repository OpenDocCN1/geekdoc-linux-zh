Now that you have HTML Tidy, I will give an example of how to use it. Use Tidy from the command line, use the following command to run Tidy on the index.html file and write any errors to a file:

```
tidy -f err.txt -m index.html
```

Unless there are terrible errors in your file, Tidy will run and update the index.html file. Tidy will clean up the syntax, reduce extraneous white space, and add cascading stylesheets to get rid of deprecated elements.
