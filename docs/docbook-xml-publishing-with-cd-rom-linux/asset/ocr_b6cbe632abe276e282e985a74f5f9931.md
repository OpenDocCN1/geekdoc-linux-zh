# Marking Up Tables and Figures

Tables and illustrative figures are very important to technical documentation. The reason I've separated tables and figures from the rest of the graphic elements is because they can be created with DocBook markup instead of a separate program. DocBook is good, but it can't produce an 8x10 colored picture, with circles and arrows on the back of each one.
