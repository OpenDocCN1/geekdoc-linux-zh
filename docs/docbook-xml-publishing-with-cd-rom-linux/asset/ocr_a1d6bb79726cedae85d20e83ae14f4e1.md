# Finding Out More about DocBook

The SGML Source Home Page by Charles F. Goldfarb is a simple page (see Figure C.4), but it includes valuable information on the history of SGML from the perspective of someone who was there from the beginning. Charles also includes interesting papers and other resources for the SGML enthusiast. You can visit his SGML source page at http://www.sgmlsource.com/

Arbtext provides an excellent SGML resource page (see Figure C.5), including a page titled “SGML: Getting Started” that not only explains SGML in easy-to-understand language but also makes the business case for SGML. If you need to convince your boss to convert to SGML or XML, this is the place to get ammunition: http://www.arbtext.com/Think_Tank/SGML_Resources/Getting_Started_with_SGML/getting_started_with_sgml.html.

Finally, there’s a good directory of SGML-related links on the Open Directory Project site (see Figure C.6). The Open Directory is a Web directory and search engine compiled by volunteers, who do a great job of sifting through the junk and finding good Web sites.
