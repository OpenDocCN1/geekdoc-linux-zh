# Linux and UNIX

To compile GNU Emacs from scratch, download the source code from the GNU site, or grab it from the CD-ROM. You must log in as root—if you don't have the root password for your computer, see your system administrator.(And while you are at it, ask your sys admin why or she didn't install Emacs!) Copy the tarball into your /tmp directory, and log in as root:

```
su
cd /tmp/
t -zxvf emacs-20.7.tar.gz
cd emacs-20.7/
./configure
make
make install
```

You should see messages like those shown in Figure 8.3 while Emacs is compiling. Note that the name of the directory in this example is dependent on the version number. If the version number of Emacs has changed, the name of the archive and directory will change as well.
