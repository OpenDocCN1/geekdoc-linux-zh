# Using TkCVS

To start TkCVS, run the tkCVS command. TkCVS first checks to see what the CVSROOT environment variable is; if it's not set, you will get an error message. Be sure to set the environment variable before running TkCVS. To set the CVSROOT environment variable, run the following command.

```
export CVSROOT="/mnt/cvsroot/
```

or if you are using C shell:

```
setenv CVSROOT /mnt/cvsroot
```

When TkCVS starts up, it opens as a file manager (see Figure 7.11). You can open and view text files with it and change directories just like any standard GUI manager.
