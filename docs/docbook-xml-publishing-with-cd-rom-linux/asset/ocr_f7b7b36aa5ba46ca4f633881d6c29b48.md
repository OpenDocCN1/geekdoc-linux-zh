# # Summary

In this chapter you've looked at the XML Schema specification and how it relates to DocBook XML. Although Schema is still in its developmental stage, the larval stage of a specification, it is likely to become a very important technology as XML picks up steam and is used in more and more applications.

If you're deploying DocBook XML solutions, or any XML solution for that matter, you will want to develop an understanding of Schema so that you can utilize the technology in the near future.
