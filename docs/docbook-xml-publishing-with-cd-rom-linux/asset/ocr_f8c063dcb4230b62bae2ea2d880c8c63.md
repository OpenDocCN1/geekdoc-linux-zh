# SynopFragment

The SynopFragment element indicates a fragment of a CmdSynopsis.

The SynopFragment element uses common attributes.

Example:

```
<cmdsynopsis>
<command>foo</command>
<arg>-bar</arg>
<group choice="*opt">
<arg>-help</arg>
<arg>-verbose</arg>
</group>
<synopragment id="markup">
<group choice="*">
<arg>--xml</arg>
<arg>-none</arg>
<arg>-sgml</arg>
</group>
</synopragment>
</cmdsynopsis>
```

# SystemItem

The SystemItem element indicates an item or a term from the computer system.

The SystemItem element uses these attributes in addition to the common attributes.

+   - Class
- MoreInfo

Example:

```
<para>The primary name server for Prima Publishing is
<systemitem>ns1.primapub.com</systemitem></para>
```
