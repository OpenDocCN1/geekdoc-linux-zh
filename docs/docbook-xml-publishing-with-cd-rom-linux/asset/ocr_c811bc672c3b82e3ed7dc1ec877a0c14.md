```
(:foreground "Orchid"))))))))
```

Only the first few lines are concerned with loading the PSGML mode. The remainder are concerned with syntax highlighting. As emacs files go, this is probably a short one.

The .emacs file is in the Lisp programming language. Emacs runs a Lisp interpreter, which enables it to do all the wonderful things it does so well. Lisp is a programming language invented in the 1950s at M.I.T., originally known as the List Processing Language. However, the acronym is often explained as Lots of Irritating Superfluous Parentheses for reasons that should be obvious from the .emacs file example.
