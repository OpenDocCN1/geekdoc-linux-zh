The three elements I use here to include a graphic in a document are the MediaObject, ImageObject, and ImageData. Unlike HTML, it isn't sufficient to stick in an img element and let it go at that. The MediaObject element isn't limited to graphics, and may also contain an AudioObject element and/or a VideoObject element.

The MediaObject element may also contain the TextObject element and its child element, the Phrase element, but not alone. The TextObject and Phrase combination have to be used in conjunction with the ImageObject, AudioObject, or VideoObject element. The TextObject should not be confused with the Caption element, which is used to produce a standard caption for addition to the image, not alternative text for display in place of the image.

Right now, you are concerned only with the use of the ImageObject element in conjunction with the TextObject and Phrase pair to produce output for the Web.

```
<img src="image.jpg" alt="This is an image">
