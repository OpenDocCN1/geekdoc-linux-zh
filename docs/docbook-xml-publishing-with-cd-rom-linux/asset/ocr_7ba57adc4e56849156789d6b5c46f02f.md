The CmdSynopsis element accepts the following attributes in addition to the common attributes:

+   - CmdLength
- Label
- SepChar

Example:

```
<cmdsynopsis>
  <command>ls</command>
  <arg>-l</arg>
  <arg>-a</arg>
</cmdsynopsis>
```

# Command

The Command element indicates a command when referred to in-line.

The Command element accepts the following attribute in addition to the common attributes:

+   - MoreInfo

Example:

```
<cmdsynopsis>
<command-mysqladmin create <database>MYDATABASE</database></command>
<br>
<command-cd <filename class="directory">/path/to/database</filename></command>
</cmdsynopsis>
```

# ComputerOutput

The ComputerOutput element indicates some type of computer output, usually output from a command.

The Command element accepts the following attribute in addition to the common attributes:

+   - MoreInfo

Example:

```
<para>
<computeroutput>Command failed: Abort, Retry, Fail?</computeroutput>
</para>
```
