# Viewing Revision Logs

A really neat feature of TkCVS is your ability to view the revision log of a file or directory. With command-line CVS, you can get the same information, but TkCVS makes it much easier to read by making it graphical. It's like a family tree for file revision, very handy.

To view a revision log, select a file in the left pane of TkCVS, and then click the button that looks like a tree branch at the bottom of the TkCVS window, shown in Figure 7.15.

# More about TkCVS

TkCVS does much more than the basics you need for using it with DocBook. If you want to find out more about TkCVS for use as a developer, try the online help that comes with TkCVS, or visit the TkCVS Web site at http://www.twobarleycorns.net/tkcvs.html.
