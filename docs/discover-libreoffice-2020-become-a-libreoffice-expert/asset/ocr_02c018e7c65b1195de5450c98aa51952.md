excellent support for all modern operating systems. Read the "Get Python for Windows" box for installation instructions. Again, Linux and macOS users find Python preinstalled on their systems.

What's the Python code in Listing 2 doing? Line 1 makes the program find the right Python interpreter on Unix-like systems, and in lines 3-5 the script imports some default modules. The modules provide functions for opening zip files, evaluating command-line arguments, and matching regular expressions against strings.

Lines 7-10 implement a highlight() function, which adds escape sequences to parts of a string so that this part of the string is shown in a different color. Note that highlighting only works on Linux and macOS (and when run from Bash on Windows). If you start the script from cmd.exe, you should remove the call to high light() by putting a comment sign (#) before the second-last line.

The main code is in lines 12-22. The script expects the pattern to search for as first argument (argv[1], argument vector, entry 1). All further arguments can be accessed as argv[2], argv[3], etc., and the for command in line 13 starts a loop over all those file names. For each of the names, all of the following steps will be executed.

Lines 14-16 use the ZipFile function to open the current LibreOffice file and extract the contents of .content.xml from the archive's root directory.

Line 17 mimics the behavior of the shell version of this program: The replace method adds a newline after each ">" character, and the split method turns the string into an array of strings.
