# ### AUTOMATING ADVANCED FEATURES

Starting with the 5.3 release, Libre- Office uses the HarBuzz font-rendering engine. HarfBuzz simplifies the use of features like small capi- tals and ligatures by using them automati- cally at appropriate times if the font sup- ports them. No manual formatting, or even the modification of a style, is needed. For example, instead of using two sep- arate “ i ”s, LibreOffice will use the special liga- ture “ fi ” if it is avail- able, automatically add- ing professional typo- graphical symbols. You can force an advanced feature’s use or turn it off from within any field to specify a font by typing a code tag written in lowercase characters di- rectly after the font name, without any space in-between (Figure 7). For instance, :smcp or :smcp=on will both automatically turn lowercase letters into small capitals. If you want to turn off the use of small capitals, add :smcp=off or :smcp=off. Multiple snippets can be added one after the other, so that :liga:onum:cpss forces the use of standard ligatures, old-style figures, and kerning for upper case letters.

In some cases, only the long form can be used, because you need to spec- ify a variable. For example, :frac=1 forces the use of smaller-sized frac- tions with a diagonal separator, while :frac=2 forces the use of smaller-sized fractions with a horizontal separator. A complete list of available tags, includ- ing those for writing systems that do not use Latin characters, is available online [1]. Some of the most useful features are listed in the Table 1.

With these codes, advanced typo- graphical features can be set up once and saved in a template, allowing your documents to have the formatting of a professional publisher.

# ### THE COMPLETION OF A REVOLUTION

For almost 20 years, LibreOffice and its predecessors have produced good enough copy resulting in many techni- cal publishers using LibreOffice files for book printing. Still, a few finishing details remained imperfect.

However, in the last few years, Li- breOffice has added those finishing details. I can personally attest to the fact that LibreOffice can successfully replace FrameMaker for technical manuals and brochures. The result is a free layout tool as good as anything available for professional use. ▉
