To insert text into a drawing object, select an object (e.g., a rectangle) and then double-click on this object: You will see the cursor, and you can insert some text. # SHAPES

Since all drawings are a collection of various objects, your drawing can become very complex. You can group objects, but you can also combine or merge/subtract/intersect selected objects to get a new complex single object. Typically, all drawing objects are generated using very simple geometric shapes like lines, rectangles, or ellipses. It is not necessary to generate or construct all the needed shapes. LibreOffice Draw offers a selection of predefined drawing objects, such as basic shapes, symbols, arrows, floorcharts, callouts, and stars. Just select the desired shape from the drawing toolbar (Figure 2) and create your object using the mouse. Afterwards, you can change the properties and position of your shape.

In addition to the predefined shapes in the drawing toolbar, Gallery (located in the Properties sidebar) offers a large selection of ready-to-use shapes (Figure 3). You can easily drag and drop single objects with your mouse. Additionally, you can add your own categories by clicking New Theme in Gallery and save your custom objects for later use.

Once you have selected your shapes, you can use the Area properties, Transparency and Fill, to create beautiful effects for your objects.

# ARRANGING OBJECTS

Objects are placed on your active workspace in the order they were created. The first object will be the bottom layer, and each subsequent object will be the next layer up from the previous object. To change the order of objects, select Arrange from the context menu or the Shape menu (located in the menubar).

Using the mouse to create and place objects is a quick way to get acceptable results. However, sometimes you need more precision. Draw offers a few options for achieving this.

If you still want to use the mouse, you can activate Display grid or Help lines. With Display grid, you can snap objects automatically to the page’s grid. If you need more customization, Help lines lets you create a non-printing line for alignment. To create a help line, place your mouse cursor inside one of the page rulers, press your mouse button, and drag the cursor inside your drawing area. Once created, you can change the help line’s properties (x- or y-position), so you can even place a help line by entering coordinates.
