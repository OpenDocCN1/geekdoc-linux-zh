## CONDITIONAL FORMATTING
If standard formatting does not provide enough visual cues, you can add other ones from the Format | Conditional Formatting. Conditional formatting allows the general data trends to be recognized at a glance, but shows nothing of the specific data. For example, you can use emoticons ranging from a smile to a neutral face to a frown to indicate cell contents. Alternatively, data can be color-coded (Figure 7).

### TABLE 1: Selected Formatting Tools

| Tool | Description |
| :--- | :--- |
| Right-click \| Hide Columns/Hide Rows | Simplifies displays, and reduces the amount of information be printed. Note that hiding does not protect information. For example, if you have a list of income in both Euros and US dollars and hide the column that lists Euro income, a viewer can deduce that a column is not displayed because some entries will be blank in the American dollar column. |
| Data \| Group and Outline \| Group | Creates a set of tree-like controls in the column and row headers for expanding or collapsing the display. If you choose, you can nest groups within a group. |
| Data \| Filter | Changes which cells in a column are displayed. Standard or Advanced filters set conditions for displaying cells, Advanced filters offering more options. However, the most convenient filter for everyday use is often AutoFilter (Figure 5). Unlike Standard or Advanced filters, AutoFilters are always displayed on the worksheet and can include empty cells. Moreover, if necessary, you can create the other kinds of filters from an AutoFilter's right-click menu. To use an AutoFilter, you need a blank cell at the top of the range of cells that you wish to filter. If you place the mouse in the cell, selecting AutoFilter adds the controls for a drop-down list of filtering options – an obvious convenience. As a navigational aid, use the cell controls to label the range of cells. |
| Data \| Validity | Useful if several people use the same spreadsheet, or one person uses it over a long time period. Validity defines the type of content and formatting that can be entered in a selected cell and also displays custom help messages, including a definition of invalid content and how it can be corrected (Figure 6). |

### TABLE 2: Selected Function Tools

| Tool | Description |
| :--- | :--- |
| Data \| Subtotals | Allows you to carry out a number of statistical functions on a data range that is labeled by a header (aka, a data array). You can also choose where the Subtotals appear on the worksheet – but be sure there is space to the left for the header. You may need to add a column to make room. Subtotals can work with up to three data arrays at the same time. |
| Tools \| Detective | A submenu of utilities to help you track the data that is used by a formula (Figure 8). Double-click on a line, and you are taken to the cell at the end of the trace. Conversely, Trace Depends draws lines from the current cell to a cell that contains a formula that refers to the current cell. You can also use Trace Errors or Mark Invalid Data. When you are done, Remove Traces deletes the traces. |
| Tools \| Goal Seek | Creates multiple values for a function's variables. These values can be changed from a drop-down list. |
| Data \| Multiple Operations | Creates a data range for a variable, and then runs a formula using the variable. You can enter data ranges for multiple variables, or even multiple formulas. |
| Tools \| Solver | Provides a dialog for entering a range of values for several cells at a time. It works much like Goal Seek and Multiple Operations, but allows you to work with more cells and variables at the same time. |
| Data \| Pivot Table \| Insert | Rearranges the data in a data array to present new information. For example, in Figure 9, a data array shows tourist expenditures according to nationality, gender, and age. According to this table, tourists who identify as female spend the most money while on holiday, something not immediately obvious from Figure 9. Pivot Tables do not refresh automatically when data changes. Instead, you must click Data \| Pivot Table \| Refresh to update them. |

At this time, LibreOffice does not support sparklines, the original form of conditional formatting – a miniature line graph, with the main data points marked. However, you can use the charting subsystem to create a graph and then scale it down, so it fits into a cell or several merged ones. You can also use a bar graph.

## USING CELL STYLES
Calc is unique among spreadsheets in its use of styles – specifically, for cells and pages. As in Writer, Calc styles can be based on existing styles to save time and provide a unified look. Calc styles can be applied to single or multiple cells, an entire column or row, or, by clicking the empty space above row 1 and to the left of column A, to the entire worksheet. Press F11 to display and edit styles in the Styles & Formatting dialog. If you have used manual (direct) formatting already, you should select Format | Clear Direct Formatting to avoid difficulties as you apply styles.

Calc installs with a number of default cell styles. These come with a number of predefined settings, mostly for different purposes, such as headings. Other cell styles, listed under Status, are intended to mark evaluations of the state of your work and can be changed as improvements are added. You may also want to create cell styles to mark subtotals or totals of the cells that contain particular functions. By contrast, Calc comes with only two page styles, although more can be added as needed.

Cell styles support Fonts and Font Effect settings, and both Cell Style and Page Style dialogs have tabs for Borders and Background. Each of these tabs is almost identical to those found in other LibreOffice modules, and a variety of fonts, borders, and backgrounds is a way to make data arrays distinct from one another (Figure 11).

However, Calc styles do have some tabs that are unavailable elsewhere in LibreOffice. In Cell Style, one of the most important is the Numbers tab. Although Calc assumes by default that all characters are text to be displayed starting at the left margin and all numerals are numbers to be displayed starting at the right margin, you can specify the kind of information a cell contains from the Numbers tab. From the same tab, you can select formats for information such as the date. The language and locale are also on the Numbers tab, because they determine the default formats for different types of numbers, including the separator used to make large numbers easier to read (Figure 12).

A second unique tab for cells is Alignment. From the Alignment tab, you can position cell entries on an angle, which can save space in headings. Even more importantly, you can set text to wrap automatically and to hyphenate, two settings that make a worksheet more readable. You might also shrink content to fit cell size, although that can be a user-unfriendly choice (Figure 13).

A third unique tab for cells is Cell Protection. There, you can set whether an entire worksheet or just the formulas are protected, or whether to hide a cell when printing. These settings are not intended for security so much as protection against accidental damage and to reduce clutter.
