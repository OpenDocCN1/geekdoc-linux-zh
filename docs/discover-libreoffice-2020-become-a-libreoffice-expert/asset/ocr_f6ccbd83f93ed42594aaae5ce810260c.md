# IMPORTING AND EXPORTING

Impress does a good job of importing presentations in PowerPoint format, al- though there may be some limitations or differences regarding complicated animations and effects. If someone wants to send you a Microsoft Office presentation that you need to modify, ask them to send it in .pptx format rather than .ppt – it’s a slightly more documented format, but still with re- strictions. In an ideal world, all office software would use a fully open and standardized format like .odp (Open- Document Presentation, as used by Li- breOffice), but one can dream!

Meanwhile, Impress lets you save in a wide range of formats. Go to File | Save As and look at the File Type drop-down list in the dialog box that opens – you can choose Microsoft formats, HTML, or even plain text. Further options are available in under File | Export As. Here you can choose to save your presenta- tion in PDF or EPUB format (the latter being suitable for eBook readers).
