# A styles-based word-processing system
### Style Guru

Writer, LibreOffice’s word-processor component, is more than just a text editor. With its powerful styles system, you can build detailed and elegant documents for business and personal use. By *Mike Saunders*

Back in the 1980s, a word processor was essentially a text editor with some extra features – in other words, a tool for processing your words. Today, however, everyone expects much more from a program like this: rich layout features, high compatibility with other office software, and the ability to structure and navigate complex documents. Writer, LibreOffice’s word processor, is an exceptionally powerful tool with a styles system that really helps to maintain consistency in your documents – but more on that later. First of all, let’s get familiar with the basics! When you launch LibreOffice and choose a new Writer document (or if you’re already running the app, go to *File | New | Text Document* in the menu), a window (Figure 1) will open with the following features:

+   1. **Menubar:** You can access almost all of the features from here. Click, explore, and see what Writer can do!
+   2. **Toolbar:** Provides quick access to commonly used features. Click the arrows on the right-hand side to show more icons, or right-click on the toolbar to choose which icons do display.
+   3. **Styles:** Shows a list of predefined styles, to which you can add more. It’s a good idea to use styles rather than manually formatting each piece of text in terms of font, size, character style, etc.
