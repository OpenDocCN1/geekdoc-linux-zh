# CONNECTORS

Another nice feature of Draw is connector lines for linking objects together. Connectors are gluepoints, located on the object’s border, to connect to another object. Once two objects are connected via gluepoints, moving one object also moves the connected object. Typical use cases are flow charts or organizational charts (Figure 7). Connectors allow you to move a single object while preserving the chart’s flow.

# CREATIVE CENTER

While LibreOffice Draw is not a pixel-oriented paint program like Gimp, it does offer some really creative tools. For example, you can convert a 2D shape into a 3D rotation object. To generate the 3D object, you first draw the basic shape: a flat, half sketch of the desired object (Figure 8). Then, click on this shape and select *Shape | Convert To 3-D Rotation object*.

# PRINTING AND EXPORT

Printing your drawings is easy. Select your printer, and start the printing job. Make sure your document’s page settings match your printer’s requirements. You can also export your drawing into popular file formats, like PDF, PNG, or SVG. Remember, SVG is a vector-based format, while PNG a pixel-based. Consequently, quality will vary in individual cases.

LibreOffice Draw does have one restriction when it comes to printing files: There is no color-separation option (CMYK separation), which is necessary for offset printing. If you require CMYK separation, the final product must be reworked with a preflight tool, and colors must be changed to the required color profile.

# CONCLUSION

With LibreOffice Draw, you have a powerful, vector-based drawing tool to create anything from the simplest sketch to complex diagrams. Once you’ve created your masterpiece, you can use it in other LibreOffice applications or export it for use in third-party applications. ■■■
