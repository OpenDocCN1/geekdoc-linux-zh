LibreOffice Calc offers the functionality of Excel with added benefits. *By Bruce Byfield*

**C**alc is LibreOffice’s spreadsheet module. The equivalent of Microsoft Excel, Calc is designed to be closely compatible with it. Each Calc worksheet (Figure 1) is capable of handling 1,024 columns and 1,048,576 rows, more than enough for most purposes. If you need more, or find that a spreadsheet crashes on a memory-challenged machine, consider creating a database in LibreOffice Base.

In case you are a complete beginner, spreadsheets like Calc are more or less a sophisticated version of the tables found in text documents. In fact, in LibreOffice Writer, tables can be set up to use a few simple spreadsheet features. Spreadsheet is the name given to a file, and worksheet to the pages within the file. On each worksheet, columns are designated by uppercase letters, and rows by Arabic numerals. Thus, the first cell on the upper left is A1, an identification that can be used to call upon the information it contains when manipulating data.

The power of spreadsheets lies in the array of features for displaying and manipulating data. These features include organizing filters for lists, a full array of functions for manipulating all sorts of data, and miscellaneous additional tools. If you have used Excel, you can probably become familiar with Calc very quickly. Both functions and their names are similar in the two spreadsheet applications, although a few are in different locations. Perhaps the greatest difference is that Calc uses styles just like LibreOffice Writer: Cell styles for formatting any spreadsheet, and page styles for producing a hard-copy version of a spreadsheet. Once defined, both of these kinds of styles save you time and allow you to concentrate on data entry rather than formatting.

# PLANNING SPREADSHEETS

Spreadsheets have a way of growing, which is probably why they are used most often online. However, if you take the time to design a spreadsheet template ahead of time, you will be able to find your data more easily.

Begin by designing a generalized default spreadsheet template with personal or corporate colors and fonts. Use that template as the basis of additional templates, one for each kind of spreadsheet that you use. Often, an important consideration is the number of default worksheets in each spreadsheet (*Tools \| Options \| LibreOffice Calc \| Defaults*). For example, you might have color-coded sheets for different categories of employees. You may also want a separate worksheet for the pivot tables (new views of already existing data).

Most spreadsheets will fall into one of two categories: text-based lists and collections of numerical data, or data arrays. Lists are the simplest use of a spreadsheet. They include to-do

By contrast, a data array consists of raw tables of information and functions that help to analyze the data, such as totals and averages. Examples of a data array are personal or corporate finances or a grade sheet. Sometimes, a data array is used to serve as a tutorial, complete with exercises.

Both lists and data arrays are usually organized by columns. Group similar information together on the same worksheet, leaving space for labels – a label is heading that describes the information contained in the column or row. Cell formatting, such as borders and background, can help to distinguish different types of information at a glance. For example, on a teacher’s grade sheet, you might use different shades of green to mark the cells that show median and average grades. The more colorful, the more easily users will be able to find their way through the information – but too much color coding may become so complex that the advantage is lost. You may want to start by sketching the approximate layout, but be sure to leave space for future growth.

# DESIGNING A LIST

A spreadsheet list serves much the same purpose as a table in a text document. Primarily, it is a way of making information easier to find than if it was arranged in paragraphs. Formatting such as fonts, colors, and position help to group the information and to distinguish types of information. For example, in a project schedule, each worker on a project might be assigned a different color. Once each worker knows their color, they can track their tasks and ignore everybody else’s. The project schedule might also include a sign-off column, or a color that can be added as each task is completed. Since a list generally gives simple information, it generally uses few spreadsheet functions, although some simple ones might be added, such as a sum of the hours worked for budgeting purposes.

Figure 2 shows a trip planner I used as an example in my 2016 book Designing with LibreOffice [1]. Notice how different kinds of information are grouped together by borders, and each one has its own header. Blank cells are used to further separate information. On the left side, beneath the summary, different tasks are arranged beneath the summary in the order that they have to be done. The rest of the spreadsheet is a daily itinerary. The intent is to produce a spreadsheet that can be printed out and to which handwritten additions can be added as they arise.

# DESIGNING DATA ARRAYS

Data arrays are where Calc really comes into its own. Data arrays can be formatted in the same way as lists to organize information. However, unlike most lists, data arrays include a number of functions (or formulas, as they are sometimes called) for manipulating raw data. Calc includes over 450 functions, many with the same names as in MS Excel, so that users can easily switch to Calc. A few Calc functions input variables are not found in Excel and are not used if a spreadsheet that includes them is opened in Excel. A specific instance of a function with its unique set of data is known as a formula. Each function has its own input variables. Most variables are required, but some are optional. All variables can be entered manually from the Formula toolbar, which also includes a list of some of the most widely used functions. Most people, though, prefer to select a cell to hold the result and then add functions from Insert | Function, which opens the Function Wizard (Figure 3). The Function Wizard lists all variables, which can be entered manually, or, at times, by dragging and dropping cells on the spreadsheet. In addition, the Function Wizard previews results so that you can correct the variables before you insert a faulty function into the document.
