Is there a better way to process XML files? Python developers can use the `xml.etree.ElementTree` module [6] and have an XML document properly parsed.
It works like this:

1. Use the `fromstring` function to convert a string into an XML tree structure. The function call returns the root of that tree.

2. Use the `findall` method to search the tree (starting at the root) for interesting elements, such as `<text:p>` or `<text:span>`.

3. For each match, access the contents via its `text` property. Then you could print it, modify it, collect statistics data, etc.

Thus, a basic code block for achieving the goal mentioned in the introduction (replacing the word “Linux” with “Windows”) would be this:

```
```python
from xml.etree import ElementTree as et
# ... content is a string w/ XML inside
root = et.fromstring(content)
for x in root.findall('.//text:p') \
        + root.findall('.//text:span'):
    x.text = ?
    x.text.replace("Linux","Windows")
new_content = et.tostring(root)
```

What’s a namespace? Each specific XML language (such as the one used in LibreOffice documents, the XML used in the RDF format [7], or XHTML [8], which is the XML version of HTML, uses its own set of tag and attribute names.

For example, XHTML documents can contain `<head>`, `<body>`, `<title>` (document title), `<p>` (paragraph), `<h1>` to `<level 1>`, heading), and many more tags.

▪ As a second example, the Dublin Core (DC) [9] metadata can be used to describe various documents, and they use tags such as `<description>`, `<publisher>`, and (again) several others.
