By Robert Großkopf, Kerstin Großkopf, and Joe Casad

B ase is the relational database for the LibreOffice suite. A database is a tool that organizes data into a structured and easily accessible form. You might be thinking “I thought that what the LibreOffice Calc spreadsheet does,” and, if so, you would be correct. A database and a spreadsheet both store data in a structured form. A spreadsheet is more useful for some kinds of problems, such as a financial ledger. A database, on the other hand, is designed for easy search and data entry, and it scales more easily to larger datasets.

A database is meant for situations where the user has a collection of discrete data objects or records with similar attributes. The classic example is something like a library card catalog – a series of similar items with a similar collection of fields, showing the title, author, catalog number, and a description of the book.

Base provides an easy user interface for creating and managing a database. Base Version 6.1 is transitioning to the Fire-bird database engine. Previous versions of Base used the HSQL engine. You can also use Base to connect to existing database files in a number of different formats. According to the LibreOffice project, “LibreOffice Base natively supports some flat file database formats, such as the dBASE format. You can also use LibreOffice Base to connect to external relational databases, such as databases from MySQL or Oracle…”

The Base user interface supports a number of wizards and design aids that make it easy to create a database or build a form to enter data into a database. When you launch Base for the first time, the Create Database wizard will ask you if you want to create a new database. The Base main window is shown in Figure 1. Icons along the left side make it easy to create tables, queries, forms, and reports.
