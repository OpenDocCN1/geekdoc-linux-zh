## AN INTRO TO STYLES

As mentioned early on, styles are a key feature of Writer. When you’re working on longer documents, they’re absolutely essential for maintaining consistency across documents. Plus, they make it easier to make document-wide changes in a few clicks. A lot of word processor users manually format paragraphs, words, tables, page layouts, and other parts of documents without paying any attention to styles. They’re used to writing documents based on individual physical attributes: For example, they might specify the font family, font size, and any formatting such as bold or italic, on an individual basis, per paragraph or even per word. Manual formatting is not ideal.

A much better option, styles are sets of formats that you can apply to selected pages, text, frames, and other elements in your document to quickly change their appearance. When you apply a style, it often means applying a whole group of formats at the same time.

So styles are logical attributes (rather than physical attributes used in manual formatting). Using styles means that you don’t specifically say “this text should be font size 12pt, Sans, bold, right-aligned.” Instead, you use *Title 1*, because you have defined the *Title 1* style to have those characteristics. In other words, using styles means that you shift the emphasis from what the text (or page, or other element) looks like, to what the text is.

Ultimately, styles help to improve consistency in a document. In addition, they also make major formatting changes much easier. For example, you may decide to change the indentation of all paragraphs, or change the font of all titles. Doing this manually for a long document may require making individual changes in dozens of places – a real time sink! In contrast, when you use styles, you only need to make a single modification.

## STYLES IN ACTION

In Writer, there are various types of styles:

- **Page styles.** These include margins, headers and footers, borders, and backgrounds.
- **Paragraph styles.** These control all aspects of a paragraph’s appearance, such as text alignment, tab stops, line spacing, and borders; they can include character formatting.
- **Character styles.** These affect selected text within a paragraph, such as the font and size of text, or bold and italic formats.
- **List styles.** These allow you to select, format, and position numbers or bullets in lists.

To try them out, type some text into a document and look at the *Default Style* drop-down list in the top-left corner of the window. Click the list to display some of the other built-in styles for Writer, such as headings and titles (Figure 7).

Every time you use a heading in your document, you’ll also find it in the Navigator, as described earlier – so with long documents, it’s a great way to zip around.

But what if you want more control over styles, including the ability to make your own? Well, that’s where the handy sidebar comes into play! Open it up as described earlier (or go to View | Sidebar), and then click the Styles icon on the right-hand side, and you should see something like Figure 8.

To create a new style, first select the category of style (e.g., paragraph or character) you wish to create by clicking one of the icons at the top of the sidebar panel, then click the arrow on the right-hand icon and select New from the pop-up menu. If you want your new style to be linked to an existing style, first select that style from the list of styles shown in the deck, then right-click on the selected style and select New.

Give the style a name, and it’ll be added to the list – then right-click on it and choose Modify, and you’ll see that there’s an enormous range of options that you can tweak. Don’t let it overwhelm you, though – you won’t need to change most of them! But take some time to explore: You can choose drop caps, borders, font effects, highlighting, indentation, and much more.

Note: If you link styles and you later change the base style (for example, by changing the font from Serif to Sans), all the linked styles will change as well. Sometimes this is exactly what you want – but other times you do not want the changes to apply to all the linked styles. The dialogs and choices are the same for defining new styles and for modifying existing styles.

## LOADING, SAVING, AND EXPORTING

LibreOffice’s native file format is the Open Document Format, and it saves Writer documents with .odt extensions (for Open Document Text). This is a fully open and standardized format, used by many other programs, so it’s definitely the best way to store your work. Of course, you may come across (or receive) documents in other formats, such as Microsoft Word .doc and .docx. LibreOffice generally does a great job of opening them, but files in those formats often include obfuscated or poorly-documented chunks of data, so LibreOffice has to struggle to work with them. If a Microsoft Word user sends you a .doc or .docx file and it doesn’t look quite right in your LibreOffice installation, ask them to try again in Open Document Text format (supported by more recent versions of Microsoft Office).

For saving, LibreOffice can export data in many different formats, including the aforementioned .doc and .docx. Just go to File | Save As, and then click the Formats drop-down list. You can even save as HTML or plain text, and obviously a lot of the formatting will disappear. Similarly, under File | Export, you can save your work in EPUB format for eBook readers, or PDF – which is the best option if you’re sending a file that only needs to be viewed or printed, and not necessarily edited. (When exporting as a PDF, you can choose the Hybrid PDF version, which also embeds a copy of the original .odt file for editing later if required.)

One handy tip: If you do a lot of work with Microsoft Office documents and want to save in that format by default, go to Tools | Options in the menu and then select Load/Save and General on the left. Then, on the right-hand side, you can choose Always save as to set the default format.

LibreOffice Writer gives you the tools to format your documents and make universal changes via the powerful styles system.
