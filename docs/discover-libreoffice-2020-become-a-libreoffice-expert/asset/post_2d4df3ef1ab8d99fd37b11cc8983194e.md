## IMPORTING AND EXPORTING

Impress does a good job of importing presentations in PowerPoint format, although there may be some limitations or differences regarding complicated animations and effects. If someone wants to send you a Microsoft Office presentation that you need to modify, ask them to send it in .pptx format rather than .ppt – it’s a slightly more documented format, but still with restrictions. In an ideal world, all office software would use a fully open and standardized format like .odp (Open Document Presentation, as used by LibreOffice), but one can dream!

Meanwhile, Impress lets you save in a wide range of formats. Go to File | Save As and look at the File Type drop-down list in the dialog box that opens – you can choose Microsoft formats, HTML, or even plain text. Further options are available under File | Export As. Here you can choose to save your presentation in PDF or EPUB format (the latter being suitable for eBook readers).

With LibreOffice Draw, you can create attractive and informative vector-based drawings. By Thomas Krumbhein

LibreOffice Draw [1], a free vector-based mathematical drawing program, helps you create anything from the simplest sketch to a complex diagram. A page-orientated, object-based program, Draw’s foundation is the page, which begins as an empty work surface, and you create your drawing by putting objects on that page. In contrast to Writer (a paragraph-based word processor) and Calc (a cell-orientated spreadsheet), Draw’s empty page offers more freedom.

Draw’s objects are vector graphics, which use lines and curves defined by mathematical vectors. Vectors describe lines, ellipses, and polygons based on their geometry. Vector graphics allow you to stretch, turn, or scale your Draw objects without loss of information.

All objects have individual properties. To manipulate an object’s property, you first have to create and place the object within the page’s borders. Once placed, you can move the objects freely within these borders.

Draw documents can contain several pages, with each page having different layers and each layer containing different objects. As a result, a final Draw document can be a complex creation, but it is basically a compilation of simple objects. Once you have created a graphic with Draw, you can then use it in other LibreOffice applications without suffering any loss. When it comes time to rework or modify your graphic, you don’t need to go back to the original Draw document. Instead, you can edit your drawing directly in the current LibreOffice application (Writer, Calc, or Impress) using the same tools originally provided in Draw. You can also insert objects, such as tables, charts, and formulae, created in other LibreOffice programs into your Draw document.

### START DRAWING

Select *File* \| *New* \| *Drawing* to open a new Draw document (Figure 1). You will see the active workspace (center), where you create and manipulate objects. To the left of the workspace, the Pages pane shows thumbnails of all created pages in your document. On the far left, the toolbar contains all necessary tools for object creation. And on the far right, the Properties sidebar shows a selected object’s attributes. You will need both the toolbar and the Properties sidebar to fully use Draw.

When you open a new document, you will see just one thumbnail in the Pages pane and an empty workspace based on standard page dimensions. To create your first object, select your desired drawing tool by clicking on the appropriate toolbar icon (Figure 2). Then place your object by left-clicking in the approximate location of your planned object’s upper left edge, press and hold the mouse button, move the mouse to the desired location of the object's lower right edge, and release the button. Your object will be created with default properties. To modify the object's properties, right-click on the object to see the eight green or blue small handles on the object's outer edge. These handles let you manipulate or change your object's properties.

At a minimum, each object has the following properties (see the Properties sidebar in Figure 1):

- **Position**: All objects have a Position X and Position Y relative to the page. Typically, the upper left corner of your drawing page (page size minus page border) is (0,0). Your object also uses the upper left corner of the surrounding square as its position by default.
- **Line**: All objects have a border line around them. Line properties are typically Width, Color, Style, Edges, and Transparency. If you want an invisible line, select None for Style. To create a hairline (for the minimum printed line, depending on your printer), select 0.00mm for Width.
- **Area**: All objects have fill properties, but they are only visible if the object is a closed object, which means that the border is a closed line even if the line is invisible (see above). Simple line objects can also have fill properties, but they are invisible.
- **Size**: All objects have their own Size property in terms of Width and Height, which is visualized as a square around the object with eight small handles that are visible when you click on an object. You can manipulate the size using the mouse and moving a single handle, or you can input the Width and Height values using the Properties sidebar.

To change properties, you can use the Properties sidebar. Additionally, if you right-click on an object, the context menu will pop up and let you open individual dialog boxes for each property; this method shows more detailed properties than available via the Properties sidebar.

### TEXT

Text is considered part of an object, so you need first to create an object before you can enter and edit text. You'll use the Text tool to create an empty box as your object. Unfortunately, the Text tool was removed from the default drawing toolbar (Figure 2). However, you can put the Text icon back on the toolbar by right-clicking the toolbar header and then selecting Textbox. You can also find an alternative text box tool in the standard toolbar (Figure 1) or use the keyboard shortcut F2.

Once you have created the object, a cursor will appear in the upper left corner of the box, and you can start inserting text. The box will show you the left and right border of the text frame and will automatically wrap lines. If you insert more text than your original box allows, the box will expand downward automatically.
