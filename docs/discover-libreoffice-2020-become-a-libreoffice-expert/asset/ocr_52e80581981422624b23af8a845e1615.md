# WORKSPACE VIEWS

Under the **View** menu, you'll find various workspace options – each of these workspace views is designed to ease the completion of certain tasks. For instance, **Normal** is the main view for working with individual slides. Use this view to format and design slides and to add text, graphics, and animation effects.

Then there's the **Outline** view, which contains all of the presentation slides numbered sequentially (Figure 6). **Outline** view shows topic titles, bulleted lists, and numbered lists for each slide in the outline format. Only the text contained in the default text boxes in each slide is shown, so if your slide includes other text boxes or drawing objects, the text in these objects will not be displayed.

The **Notes** view lets you add notes to a slide. These notes are for your information only and are not seen by the audience when the presentation is shown. Meanwhile, the **Master Handout** view is for setting up the layout of your slides for printing. Click the **Properties** tab in the sidebar, and you can choose to print one, two, three, four, six, or nine slides per page in the **Layouts** section. In addition, this lets you add custom fields into the header and footer sections, such as the current date – click in one of those boxes, and then go to **Insert | Field** to see what's available.

# MASTER SLIDES

First, a bit of background: A master slide is one that's used as the starting point for other slides. It's similar to a page style in Writer, and it controls the basic formatting of all slides based on it. A slide show can have more than one master slide. Also, master slides have a defined set of characteristics, including background colors, graphics, and gradients, as well as other objects (such as logos, decorative lines, and so on), headers and footers, placement

and size of text frames, text format, and so forth.

Styles control all of a master slide's characteristics. New slides created using a master slide will have styles that are inherited from whichever master slide was used. Changing a style in a master slide results in changes to all slides based on it. However, you can modify individual slides without affecting the master slide itself.
