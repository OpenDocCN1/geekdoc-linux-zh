You can now use these styles to quickly change the formatting of a paragraph, including the font size, font style, whether it’s bold, and so forth. Every time you use a heading in your document, you’ll also find it in the Navigator, as described earlier – so with long documents, it’s a great way to zip around.

But what if you want more control over styles, including the ability to make your own? Well, that’s where the handy sidebar comes into play! Open it up as described earlier (or go to View | Sidebar), and then click the Styles icon on the right-hand side, and you should see something like Figure 8.

To create a new style, first select the category of style (e.g., paragraph or character) you wish to create by clicking one of the icons at the top of the sidebar panel, then click the arrow on

the right-hand icon and select New from the pop-up menu. If you want your new style to be linked to an existing style, first select that style from the list of styles shown in the deck, then right-click on the selected style and select New.

Give the style a name, and it’ll be added to the list – then right-click on it and choose Modify, and you’ll see that there’s an enormous range of options that you can tweak. Don’t let it overwhelm you, though – you won’t need to change most of them! But take some time to explore: You can choose drop caps, borders, font effects, highlighting, indentation, and much more.

Note: If you link styles and you later change the base style (for example, by changing the font from Serif to Sans), all the linked styles will change as well. Sometimes this is exactly what you want – but other times you do not want the changes to apply to all the linked styles. The dialogs and choices are the same for defining new styles and for modifying existing styles.

# LOADING, SAVING, AND EXPORTING

LibreOffice’s native file format is the Open Document Format, and it saves Writer documents with .odt extensions (for Open Document Text). This is a fully open and standardized format, used by many other programs, so it’s definitely the best way to store your work. Of course, you may come across (or receive) documents in other formats, such as Microsoft Word .doc and .docx. LibreOffice generally does a great job of opening them, but files in those formats often include obfuscated or poorly-documented chunks of data, so LibreOffice has to struggle to work with them. If a Microsoft Word user sends you a .doc or .docx file and it doesn’t look quite right in your LibreOffice installation, ask them to try again in Open Document Text format (supported by more recent versions of Microsoft Office).

For saving, LibreOffice can export data in many different formats, including the aforementioned .doc and .docx. Just go to File | Save As, and then click the Formats drop-down list. You can even save as HTML or plain text, and obviously a lot of the formatting will disappear. Similarly, under File | Export, you can save your work in EPUB format for eBook readers, or PDF – which is the best option if you’re sending a file that only needs to be viewed or printed, and not necessarily edited. (When exporting as a PDF, you can choose the Hybrid PDF version, which also embeds a copy of the original .odt file for editing later if required.)

One handy tip: If you do a lot of work with Microsoft Office documents and want to save in that format by default, go to Tools | Options in the menu and then select Load/Save and General on the left. Then, on the right-hand side, you can choose Always save as to set the default format.

# CONCLUSIONS

LibreOffice Writer gives you the tools to format your documents and make universal changes via the powerful styles system. Not only does it allow you to maintain consistency throughout your document (across documents), it also saves you from wasting time manually formatting individual paragraphs (or even words). For even further time savings, check out the “Keyboard Shortcuts” box. Happy word processing! ███
