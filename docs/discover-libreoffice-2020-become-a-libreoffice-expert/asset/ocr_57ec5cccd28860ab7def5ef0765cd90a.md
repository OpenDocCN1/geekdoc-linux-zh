Need to impress your boss with the latest sales stats? Or just show off some holiday photos in an eye-catching format?

Impress is the tool you need. *By Mike Saunders*

The term “PowerPoint” has become synonymous with presentations in general, even if the file was made in a different program. Presentation software dates back to the early 1980s, with tools such as VCN ExecuVision, which let users add images to text and display them in a slideshow format. LibreOffice’s presentation component is called Impress, and it’s an immensely versatile tool with features and special effects galore. So let’s dive into it!

Start LibreOffice and choose a new *Presentation* (or if you’re already running the app, go to *File | New | Text Presentation* in the menu). You’ll be presented with a list of preinstalled templates, so choose one you like, and a new Impress document will open displaying the following features:

+   1. **Toolbar:** Most commonly used features are just one click away here. If you’re unsure of what an icon does, simply mouse over the icon for a tooltip. You can also right-click on the toolbar and choose *Visible Buttons* or *Customize Toolbar* for finer control over the layout.
