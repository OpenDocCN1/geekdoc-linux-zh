# # Get involved!

![](bbox=[0.0, 0.1, 0.99, 0.43])

**LibreOffice** is developed and improved by a friendly worldwide community – by people like you! Yes, you can also join the project and help out, regardless of whether you’re a developer or not. Our volunteers are looking for support in these areas:

+   - Helping other users
+   - Translating the interface
+   - Bug report confirmations
+   - User interface design
+   - Marketing and advocacy
+   - Updating documentation

...and much more. There’s a place for you in our community – so find out today, where you’d like to join in!
