With LibreOffice Draw, you can create attractive and informative vector-based drawings. By Thomas Krumbhein

LibreOffice Draw [1], a free vector-based mathematical drawing program, helps you create anything from the simplest sketch to a complex diagram. A page-orientated, object-based program, Draw’s foundation is the page, which begins as an empty work surface, and you create your drawing by putting objects on that page. In contrast to Writer (a paragraph-based word processor) and Calc (a cell-orientated spreadsheet), Draw’s empty page offers more freedom.

Draw’s objects are vector graphics, which use lines and curves defined by mathematical vectors. Vectors describe lines, ellipses, and polygons based on their geometry. Vector graphics allow you to stretch, turn, or scale your Draw objects without loss of information.

All objects have individual properties. To manipulate an object’s property, you first have to create and place the object within the page’s borders. Once placed, you can move the objects freely within these borders.

Draw documents can contain several pages, with each page having different layers and each layer containing different objects. As a result, a final Draw document can be a complex creation, but it is basically a compilation of simple objects. Once you have created a graphic with Draw, you can then use it in other LibreOffice applications without suffering any loss. When it comes time to rework or modify your graphic, you don’t need to go back to the original Draw document. Instead, you can edit your drawing directly in the current LibreOffice application (Writer, Calc, or Impress) using the same tools originally provided in Draw. You can also insert objects, such as tables, charts, and formulae, created in other LibreOffice programs into your Draw document.

# START DRAWING

Select *File* \| *New* \| *Drawing* to open a new Draw document (Figure 1). You will see the active workspace (center), where you create and manipulate objects. To the left of the workspace, the Pages pane shows thumbnails of all created pages in your document. On the far left, the toolbar contains all necessary tools for object creation. And on the far right, the Properties sidebar shows a selected object’s attributes. You will need both the toolbar and the Properties sidebar to fully use Draw.

When you open a new document, you will see just one thumbnail in the Pages pane and an empty workspace based on standard page dimensions.
