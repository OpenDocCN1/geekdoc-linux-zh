Each function has its own input variables. Most variables are required, but some are optional. All variables can be entered manually from the Formula toolbar, which also includes a list of some of the most widely used functions. Most people, though, prefer to select a cell to hold the result and then add functions from Insert | Function, which opens the Function Wizard (Figure 3). The Function Wizard lists all variables, which can be entered manually, or, at times, by dragging and dropping cells on the spreadsheet. In addition, the Function Wizard previews results so that you can correct the variables before you insert a faulty function into the document.

The Function Wizard is also useful for browsing functions in the left-hand pane. Functions are arranged into categories such as Financial, Logical, and Statistical, and you can display a single category by entering its first letter. These tools are scattered throughout the menus – mostly in Tools and Data – but can be divided into tools that change formatting and tools that work with functions to make them more powerful and easier to navigate.
