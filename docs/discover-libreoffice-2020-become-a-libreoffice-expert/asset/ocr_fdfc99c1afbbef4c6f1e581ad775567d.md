CONDITIONAL FORMATTING
If standard formatting does not provide enough visual cues, you can add other ones from the Format | Conditional For-matting. Conditional formatting allows the general data trends to be recognized at a glance, but shows nothing of the specific data. For example, you can use emoticons ranging from a smile to a neutral face to a frown to indicate cell contents. Alternatively, data can be color-coded (Figure 7).

TABLE 1: Selected Formatting Tools

| Tool | Description |
| :--- | :--- |
| Right-click \| Hide Columns/Hide Rows | Simplifies displays, and reduces the amount of information be printed. Note that hiding does not protect information. For example, if you have a list of income in both Euros and US dollars and hide the column that lists Euro income, a viewer can deduce that a column is not displayed because some entries will be blank in the American dollar column. |
| Data \| Group and Outline \| Group | Creates a set of tree-like controls in the column and row headers for expanding or collapsing the display. If you choose, you can nest groups within a group. |
| Data \| Filter | Changes which cells in a column are displayed. Standard or Advanced filters set conditions for displaying cells, Advanced filters offering more options. However, the most convenient filter for everyday use is often AutoFilter (Figure 5). Unlike Standard or Advanced filters, Auto-Filters are always displayed on the worksheet and can include empty cells. Moreover, if necessary, you can create the other kinds of filters from an AutoFilter's right-click menu. To use an AutoFilter, you need a blank cell at the top of the range of cells that you wish to filter. If you place the mouse in the cell, selecting AutoFilter adds the controls for a drop-down list of filtering options – an obvious convenience. As a navigational aid, use the cell controls to label the range of cells. |
| Data \| Validity | Useful if several people use the same spreadsheet, or one person uses it over a long time period. Validity defines the type of content and formatting that can be entered in a selected cell and also displays custom help messages, including a definition of invalid content and how it can be corrected (Figure 6). |

TABLE 2: Selected Function Tools

| Tool | Description |
| :--- | :--- |
| Data \| Subtotals | Allows you to carry out a number of statistical functions on a data range that is labeled by a header (aka, a data array). You can also choose where the Subtotals appear on the worksheet – but be sure there is space to the left for the header. You may need to add a column to make room. Subtotals can work with up to three data arrays at the same time. |
| Tools \| Detective | A submenu of utilities to help you track the data that is used by a formula (Figure 8). For example, if you select a cell with a formula, Trace Precedents draws lines (traces) to the cells that contain the data used in the formula. Double-click on a line, and you are taken to the cell at the end of the trace. Conversely, Trace Depends draws lines from the current cell to a cell that contains a formula that refers to the current cell. You can also use Trace Errors or Mark Invalid Data. When you are done, Remove Traces deletes the traces. |
| Tools \| Goal Seek | Creates multiple values for a function's variables. These values can be changed from a drop-down list. |
| Data \| Multiple Operations | Creates a data range for a variable, and then runs a formula using the variable. You can enter data ranges for multiple variables, or even multiple formulas. |
| Tools \| Solver | Provides a dialog for entering a range of values for several cells at a time. It works much like Goal Seek and Multiple Operations, but allows you to work with more cells and variables at the same time. |
| Data \| Pivot Table \| Insert | Rearranges the data in a data array to present new information. For example, in Figure 9, a data array shows tourist expenditures according to nationality, gender, and age. Using and following the online help, you can rearrange the data to create Figure 10, which shows tourist spending by gender. According to this table, tourists who identify as female spend the most money while on holiday, something not immediately obvious from Figure 9. Pivot Tables do not refresh automatically when data changes. Instead, you must click Data \| Pivot Table \| Refresh to update them. |
