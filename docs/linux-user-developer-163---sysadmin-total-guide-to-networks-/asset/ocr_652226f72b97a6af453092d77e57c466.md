Each of the sides is made of three triangles, which are mapped onto the corners of the texture. The texturing can be simplified by assigning friendly names to the vertices. In the case of our example, the relevant block looks like this:

```
redCorner2 = new Vector2(1f,0f);
whiteCorner2 = new Vector2(0f,0f);
interCorner2 = new Vector2(0f,1f);
interCorner2 = new Vector2(1f,1f);
```

In addition to the two Vector elements holding the actual coordinate information, we are also dealing with a method returning a VertexDeclaration. It is a data structure informing the graphics pipeline about how the data is found in the texture i.e. which flags maps to which.

Please be aware that texture coordinates not necessarily need to be one or zero. You can also place elements in the scaling factor from 0 to 1 to describe the distance from the textural origin.
