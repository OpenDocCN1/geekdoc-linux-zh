## Direct the traffic to your swarm

If you pull down docker on one of them, you can use DOCKER_HOST variable to point to any nodes without having to log into the Pis. Swarm creates keys enabling to scale up a web service from one container to more. These containers need to be started in the correct order, starting with Redis, and finally nginx.

```bash
# DOCKER_HOST=tcp://192.168.0.2000
# docker run -p 6379:6379 -d --name=redis-1 alexellisiz/redis-arm
# wget get.docker.com/builds/arm/v7 -O docker-compose
# docker-compose --version
```

Docker Compose is a tool that allows you to define multiple containers together, enabling you to scale up web service from one to more without manual keys.

```yaml
node:
  image: redis
  ports:
    - "3000"
nginx:
  image: nginx
  ports:
    - "80"
```

## Create a Minecraft game

Use your Raspberry Pi and Python knowledge to code a simple mini-game in Minecraft. The Raspberry Pi OS image already has Minecraft and Python pre-installed. If you are using an old version, it is worth downloading and updating to the new Raspian image at www.raspberrypi.org/downloads.

# Importing modules

Load your preferred editor and start a new window. You need to import the following modules: **random** to create and generate the location, and **time** to add pauses and delays to the program. Next, add a few lines of code: `from mc import minecraft` and `mc = minecraft.Minecraft()`. These create the link between Minecraft and Python. This enables you to write to "Minecraft created".

```python
import random
import time
from mc import minecraft
mc = minecraft.Minecraft()
```

# Grow flowers

The program below is to show how it works. Each block has its own ID number, and there are hundreds. x, y, z = mc.getPos() gets the player's position in the world and returns it as a tuple. Now that you know where you are in the world, blocks can be placed using mc.setBlock(x, y, flower).

```python
flower = 38
while True:
    x, y, z = mc.getPos()
    mc.setBlock(x, y, flower)
    time.sleep(1)
```

# Running the code

Reducing the size of the Minecraft window will make it easier for you to see both the code and the program running; switching between them can be frustrating. Tab key hides the keyboard and mouse from the MC window. Run the Python program and wait for it to load - as you walk around, flowers appear! Change the ID in line 1 to change the block type, instead of flowers, try planting gold, water, or embers.

![](img/f4a034c4fbc20906a013558fa4e058a2_76_0.png)

# Posting a message to the Minecraft world

It is also possible to post messages to the world that is used later in the game to keep the player informed of the flower and their current score. In your progress add the following to the line of code `flower = 38`, making this line `mc.postChat("I grew some flowers with code")`. Now see the message pop up. You can changing the message, or move to the next step to start the game.

# Create the board

The game takes place on the board where the player is currently standing, so it is advisable to fly into the air or find a flat terrain before running your program. To create the board you will need to write a loop and run the program in the world using the x, y, z = mc.getPos(). Use the mc.setBlock code to place the blocks which make up the board.

```python
mc.setBlock(x, y-1, z, y-1, z, 58).
```
