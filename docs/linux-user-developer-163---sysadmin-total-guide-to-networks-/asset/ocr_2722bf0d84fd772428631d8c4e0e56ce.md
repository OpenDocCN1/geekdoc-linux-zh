# ## 02 Install on plugins

Let's Encrypt client is available for Arch Linux, FreeBSD, or Ubuntu as Debian and its friends. No surprises here in the installation, to install on Linux use:

+   - sudo install letsencrypt-apache

FreeBSD, FreeBSD users can use it:

+   - pkg install py2-letsencrypt

Similarly, OpenBSD users use:

+   - pkg add_letsencrypt

Once installed, the letsencrypt client software runs the same on each platform, communicating with the Let's Encrypt servers to receive SSL certificates.
