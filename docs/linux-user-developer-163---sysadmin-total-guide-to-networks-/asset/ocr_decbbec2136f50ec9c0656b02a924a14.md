# 06 Obtain a certificate for webhook

With webroot you can obtain a certificate without stopping the server. This essentially means that the certificate is requested, downloaded and written to your webroot directory. This is achieved by using the certbot webroot conditions. So for instance you might use:

```
letsencrypt --webroot
```

This would issue the certificate directly into your webroot directory, which might be inappropriate if you wish to specify a particular directory. As such, you would need to specify the name of the directory:

Alternatively, if you have multiple domains you wish to obtain certificates for Let's Encrypt. In this scenario, you can list the target domains and their directories as follows:

```
letsencrypt --webroot -w /var/www/
yoursite -d www.mysite.com -w /var/www/yoursite -d www.mysite.com
```

Certificates will be written for the /var/www/yoursite directory for the second and third domains. If you intend to use the webroot plugin successfully, ensure that your webserver is configured from the hidden directories.
