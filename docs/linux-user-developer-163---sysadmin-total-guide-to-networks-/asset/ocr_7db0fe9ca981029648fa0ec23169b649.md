# ACCESS FILES REMOTELY WITH SSH AND VNC

Log in to your server via command line from anywhere
the world, or share your desktop with a remote machine to get a GUI

SSH (Secure Shell) is a common way to log in to a system
remotely. OpenSSH is the most popular SSH implementation
is available across all the popular platforms: Linux,
Windows, Android, OS. To install the OpenSSH-server, use:

```
$ sudo apt-get install openssh-server
```

Once installed, openssh-server is ready for action without
further configuration. Log in from a remote machine using:

```
$ ssh username@hostname
```

The username should already exist on the server. By default,
OpenSSH is configured for password authentication. A far more
secure method is to use public key authentication. On the
remote machine, generate public/private pair:

```
$ ssh-keygen -t rsa
```

The above command gives you two files. These are located in
~/.ssh/id_rsa and id_rsa.pub. id_rsa is
your private key - do not share this with anybody. Copy the
content of id_rsa.pub (public key) and place it in the folder
~/.ssh/authorized_keys on the remote server.
Next time, you will log in without a password.

# ACCESS WINDOWS

Almost all modern Windows operating systems developed
with the remote desktop connection (commonly
known as RDP feature), you can use it to access
the desktop service on a remote computer. This includes
Windows 7, 8, 10 and 11. Note that Windows Home
editions do not support being connected to a remote desktop.
Windows Home editions can use VNC or Remmina
to connect to a remote machine.
Remmina is actively developed and provides a complete
feature to install Windows:

```
sudo apt-get update
sudo apt-get install remmina-remmina-plugin-rdp
remmina-plugin-vnc
```

# TIGHTVNC FOR REMOTE DESKTOP SESSIONS

VNC is a desktop sharing system implemented using
RFB protocol to share your current desktop over
the network. VNC can provide to multiple users of the
server with an isolated desktop environment simultaneously.
This means all users can run their own desktop in their
ndesktops without interfering with each other.

```
$ sudo apt-get install tightvncserver xfce4-goodies xfce4-server
```

We are also installing a lightweight desktop environment
Xce, which we will use to boot the GUI session for remote users.
Autocut is used in order to add copy-paste support
bween host and the client. We need to configure
the desktop environment, to create ~/.vnc/ and add:

```
$ /bin/bash
startxfce4 &
```

Make this executable using sudo chmod +x
startup. For each user, a service instance must be created,
and for the VNC server, you will set the display number and resolution for
multiple users accessing their own
desktops you then you need to create a startup file for each
user, and assign different display numbers to
user in the service file.
