# 07 Creating the mine

In the previous step you found the player's location on the board. The x, y, z data can be reused to place the mine on the board. The code `mine_x = random.randint(0, 11)` generates a random number between 1 and 10. Combine this with the player's x position and add the random number to the x position - this creates a mine on the board.

```
mine_x = int(mine_x)
mine_y = int(mine_y)
mine_z = int(mine_z)
```

Use setBlock to place the mine: `mc.setBlock(mine_x, mine_y, mine_z, 58)`. Using y ensures that the block is placed on the same level as the number 58 is the block ID, which you can change to see where the mine is; this is useful for testing that the rest of the code is working correctly. Remember to change it back before you play!

# 10 One point,

Now that the player has a square we award a point. This is a simple action of adding the value to the score variable. We use `score = score + 1`. Since it sits inside a loop, it will add each point time the player moves.

```
time.sleep(0.1)

```

# 08 Create a variable

Each step that you remain near the mine, a point is added to score. Create a variable for the score, setting it to zero at the beginning of the game. Use the `postChat` function to announce the score. Note that mc cannot print a value to chat, so the score is first converted to string before being displayed.

```
score = 0
pmc.postChat("score: " + str(score))
time.sleep(0.1)
```
