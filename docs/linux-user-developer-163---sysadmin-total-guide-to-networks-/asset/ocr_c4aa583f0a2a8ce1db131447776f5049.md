# ## 08 Build Docker on Docker!

Now we have the working version, need to compile it:

+   - cd /docker-arm/images/docker-arm
- ./build.sh

For the next 30-60 minutes, the code will be built and patched for ARM,
set up for your Pi, and copied into a local folder on our Pi. The
script runs until you get a message as below:

*Created binary: bundles/1.9.1/binary/docker-1.9.1-arm-linux-armv7\*

If the output is successful then you can go ahead and install the changes:

+   - cd /docker-arm/images/docker-arm
- sudo install.sh
- sudo systemctl start docker

# ## 09 Build Docker Swarm

There is an Swarm image available in the public
registry, but we cannot use it because it was built for x86_64
architecture - a regular PC. So let's build our own:

+   - cd /docker-arm/images/docker-arm
- ./build.sh
- docker run alexelsis2-swarm --version
