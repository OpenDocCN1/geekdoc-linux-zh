#  01 Welcome (for 64-bit)

Your package has a recent Atom? If you're on 64-bit OS you might need to compile for yourself, and ARM support — Raspberry Pi and Chromebooks — is not quite. It's worth keeping in mind that Atom's great doesn't run perfectly well on all Linux distributions so into whether Atom is going to be right for you. Your first instruction is necessary:

```
apt-get install atom
```

your distro's equivalent, and you're up and running. Pace of development for Atom is fast. Even over the duration of writing this piece, Atom has grown from 1.3 to 1.4, and 1.5 should be used by you today. Our tutorial should apply to any of these versions.

The first time you run Atom will show a split window (which you can access via the Help menu; the left is split into two panes. The left pane links to document opening and the right pane gives you choices for opening a project (with module), or customizing straight away. It's a declaration of intent from the developers.
