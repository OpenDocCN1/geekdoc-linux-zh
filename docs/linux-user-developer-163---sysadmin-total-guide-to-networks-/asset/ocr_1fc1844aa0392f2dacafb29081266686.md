# 05 Unscrewing

The controller is held together by half a dozen screws. When opening the case, the buttons and rubbers are loose within the controller - they will spill everywhere!

# 09 Connecting it up

If you're using a controller with a regular USB port just plug it into the Pi via a USB OTG converter. If you're using the original controller, it's tricky. Microsoft, in its infancy, has decided that the original controller should use USB - but with an incompatible plug design. In order to connect the controller to the Pi, you will need a special adapter!

# 06 Opening

With the shell removed, you should be able to undo the screws holding the main circuit board in place. There are also some connectors which the vibration motors - gently unplug them in order to completely remove the board. You might find it easier to use a pair of pliers for this - just be as gentle as you pull!

The winding inside the Xbox controller's cables uses standard USB wires, so once you've pulled the plugs off the OTG cable, it's pretty straight to connect them together.

# 07 Getting it up

Check for yourself how well the Pi fits here: can be secured around the memory card. If you want to hold it in place, use some BluTak to secure it. If you're using an original controller, it's giving you a bit of room. Remove the rubber contacts and get away under them using the isopropyl swabs.

Strip the wires by a few centimetres and connect them together. You should have Green, Red, White, and Black. The Xbox cable has a wire which you will need for data transfer, noting at this point that you should be sure you have a USB data transfer cable and not just a power cable - the wire will look like the photo below but will be missing the data wires.

With the wires stripped, we used regular tape to make the connections between the OTG cable and the controller - for a permanent installation, you can use electrical tape or simply solder the wires together.
