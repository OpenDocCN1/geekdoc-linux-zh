The Raspberry Pi 2 is the successor to the Raspberry Pi. It builds upon the original by upgrading to 1 GB of RAM, and replacing the ARMv6 single-core with an ARMv7 quad-core.

The Raspberry Pi 2 features 8.50x53.98x17mm, with four USB 2.0 ports and full wireless connectivity, and Ethernet. The SoC is a Broadcom BCM2836, which contains a quad-core Cortex-A7 running at 900MHz, and a VideoCore 4 GPU, which is capable of Blu-ray quality playback, up to 1080p at 60fps.

# 03 Set a static IP address

set a static IP address so you can connect to each Pi without searching. The OS uses systemd for configuration. Edit the network configuration file at /etc/systemd/network/eth0.network and reboot:

```
[Match]
Name=eth0
[Network]
Address=192.168.0.200/24
Gateway=192.168.0.1
[DNS]
Server=8.8.8.8
[IPv6]
```

# 07 Install Docker 1

Docker 1.9 is in the Arch Linux system but it is currently old, so we will install the latest version and configure it using the official scripts.

```
# cd ~
# git clone https://github.com/archlinux/docker-arm
# sudo pacman -U --confirm ./docker/docker-17.06.3-armv7.pkg.tar.zst
# sudo cp ./docker/service /lib/systemd/system/docker.service
# systemctl enable docker
# systemctl start docker
# usermod -aG docker user
```

# 04 Install useful tools

Arch Linux is a rolling-release model, so system updates are incremental and bleeding edge. We will use the pacman manager to install some essential tools and update the system at the end.

# 05 Enable sudo

Configure your user for sudo access by editing the /etc/sudoers file and removing the line below:

```
# ## something without a password
# %wheel=ALL=(ALL) NOPASSWD:ALL
```

This enables all users in the "wheel" group to use sudo. We configured our user's primary group as "wheel" in the useradd command.
