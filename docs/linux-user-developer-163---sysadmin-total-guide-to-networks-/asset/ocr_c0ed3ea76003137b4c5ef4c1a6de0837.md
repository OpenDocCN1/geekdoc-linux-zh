# This issue

## Set up a rock-solid network from scratch
## Hack your Xbox controller with a Pi Zero
## Secure your device with Let's Encrypt
## Run a Raspberry Pi 2 Docker Swarm

![Look for issues? Don't want to miss out? Subscribe today]
Welcome to the latest issue of Linux User & Developer, the magazine. Our favourite free and open source magazine now. Set up a complex network, whatever for your home or the office, it is no mean, but it is far easier than you might think. And a payoff of digital freedom! To configure your ports to what you need: perfect for forwarding and proxy servers, automatic backups, remote access, file sharing, monitoring tools, or all of it put together – simply manage the kernel node. Turn to page 18 and we'll walk you through the whole thing, to finish.
If you're in for tinkering with hardware then no further than our first Pi project – the Xbox Zero Arcade, how to hack your old Xbox controller, or a generic USB pad, and how to right it up with plug-and-play MAME arcade system.
There are some great technical tutorials this month – get started with big data in Hotuk, to switch to the new certification authority Let's Encrypt, and find out to distribute your Raspberry Pi 2 boards by turning them into a Docker Swarm. Be sure to check out our review of the Genius 1 on page 86 - It's latest venture in the kernel market!
Gavin Thomas
