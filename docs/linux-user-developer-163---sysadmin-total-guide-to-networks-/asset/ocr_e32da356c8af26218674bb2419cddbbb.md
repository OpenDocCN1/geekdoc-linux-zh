# The structure of the tree

A binary tree is a tree where each node may exist at most two other nodes. "Most" means that it can be connected to two or no other node. The height of a tree is defined as the longest path from the root to a node of tree, whereas the depth of a node is the number of edges from the node to the root. A tree is balanced when the length from the root to a node is at most one more than the shortest path. # The theory

Strictly speaking, a "tree" is a directed acyclic graph that satisfies the following principles: it has a root that is the entry point to the tree; every vertex, except the root, has one and only one entry point; there is a path to every node; it is a graph where the edges have a direction with them.
