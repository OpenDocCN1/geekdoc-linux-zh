# Renew certificates

If you are using the Let's Encrypt authority service, you need to ensure that your cert are renewed every 90 days. Since it issues short-lived certificates certificates must be stored on your server and served to your visitors to be visited by.

To renew, all you need to do is enter the letsencrypt directory and run the software, issuing a command as you have in the previous steps. Since the software renews the server and certificates once the values you entered are already entered.

As an alternative, you may also use the --auto-renew to help automate renewal. Note that as the Let's Encrypt service is in beta, automation is yet to be perfected. To renew every two months as long as it is before the 90-day cutoff - also an option.

# Finding certificates on your server

If you are using Apache and Nginx it will automate the management of certificates for you without need any special setup. If you have a bit more hands-on simply want to know where the certificates are stored, they can be found relatively easily.

```
/letsencrypt/live/$domain
```

# Automate with configuration

A certain degree of automation is possible in letsencrypt with the use of configuration. With this you can change the encryption type, for instance domains and more.

You can find out the conditions that can be changed by:

```
--help
```

and from view the importance of options that you might see:

```
rsa-key-size = 4096
```

As you might guess, a 4096-bit key is used, instead of a 2048-bit key. You may also include a list of

```
domains = mysite.com, mysite.com
```

You may also include a configuration file to save with the webroot path, insert storing path in your configuration:

```
webroot = /usr/share/nginx/html/
```

When you're done your config file in names, aim or whatever your preference, save it as /etc/letsencrypt/letsencrypt.ini.
