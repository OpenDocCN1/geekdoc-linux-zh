By adding the following line, Dnsmasq will forward the query to the following servers (Google's Public DNS servers) if it doesn't know the address itself:

We can add the following to our Dnsmasq config:

Custom DNS entries get first priority and can be used to override public DNS. If we add an address here (like 192.168.1.11), Dnsmasq will use 192.168.1.11 instead of the public entry for the same domain. Dnsmasq also acts as a cache for the upstream DNS server. To allow the DHCP server to recover quickly, we should limit the frequency of querying the upstream server. The following sets the dhcp range query limit to 100:

+   - dhcp-size=1000

+   - dhcp-range=192.168.1.2,192.168.1.200,255.255.255.0

The following options allows the DHCP server to configure of Dnsmasq and set up the DHCP range, subnet mask of the network, and lease time

# DHCP server options

+   - dhcp-option:router,192.168.1.1

This will enable DHCP to assign addresses to 192.168.1.2 and 192.168.1.200. The lease time of 12 hours means the address is leased for 12 hours and then the client must renew the gateway server, use:

+   - dhcp-option:dns,192.168.1.10

We might want to reserve a particular IP address for a device. We can do this with the following:

+   - dhcp-option:host:11:22:33:44:55:66,192.168.1.13

This option will set the IP address as 192.168.1.13 if the device's hardware (MAC address) is 11:22:33:44:55:66. To specify the NTP (network time protocol):

+   - dhcp-option:ntp-server,192.168.1.10
