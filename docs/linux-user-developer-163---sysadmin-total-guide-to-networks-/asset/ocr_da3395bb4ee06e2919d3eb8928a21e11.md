# # Tails 2.0

The ultra-private distro beefs its security with a big step up to Debian 8 and system-proved lockdown

Bug fixes and low-level improvements streaming through regularly in 2015, but Tails 2.0 brings with it a few changes that really improve both usability and security of the distro.

It's not an issue for people using Tails in public spaces or on a public computer, which is going to be a bit of a challenge with Tails' bare blue background, and the differences between Windows and OS X quite apparent.

To start with, Tails begins on Debian 8 and ships with many of its newer packages.

The transition has brought many most user-visible changes: the default desktop environment is now GNOME Shell in the Classic mode, which is much better than the updated stack. GNOME preserves places along with Applications in the top-left of your menu, with important apps such as Vidalia for Tor management, the Florence virtual keyboard and the OpenPGP clipboard manager that all display along the top right.
