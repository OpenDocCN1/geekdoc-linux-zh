Hadoop stores the data across several nodes in a cluster and the data is replicated in HDFS to ensure high availability and reduce fault tolerance. To store data that is terabytes or petabytes in size, we need to use commodity hardware which is scalable, distributed, fast and resilient to failure. In this tutorial, you will learn how to install and configure a Hadoop cluster using the Apache distribution on a low cost operating system.

The size of the cluster depends upon the data you want to store in. If you have 5 TB of data with replication factor of 3, then you will need 20 TB storage on HDFS. From the network perspective, a normal Hadoop cluster with 1 Gbps network per node, 10 Gb switch or router – a “rack” is a storage area with all the data nodes put together.
