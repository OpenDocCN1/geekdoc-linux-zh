# # AUTOMATE BACKUPS ACROSS YOUR NETWORK

Set up a smart backup system that monitors folders and duplicates the data to your server

Setting up a centralised backup solution on your network is very useful for your clients they don't have to worry about doing it. You can conveniently back up at a location of your choice across the network. UrBackup is a free open source backup with support for Unix and Windows clients. While UrBackup is minimal it has some essential features that are important, easy to use and efficient (if the same file is backed from multiple clients it only keeps one copy), reliable backup for files in us, and an easy setup process.

UrBackup can be installed on most of the Linux distros as well as Windows devices like Sync. We will be installing UrBackup on Ubuntu. We will have the UrBackup server using the following:

```
$ sudo apt-get update
sudo apt-get install urbackup-server
```

During the installation, the installer will ask for the backup location. Choose the folder with the most free space available. If you want to compress the backups then you

set the location on either a Btrfs or ZFS formatted partition. For added data protection you also consider storing backup files on RAID 5 so that in the event of disk failure data can be easily recovered. After all, a centralised backup server is essential.

Once UrBackup server is running you can access the web interface from http://localhost:5684. By default the credentials are admin/password. Go to Settings, then click "create". Enter the user password here and click create. If you want to receive notifications via email configure the SMTP settings by going to Settings > Mail. Rsync is an incremental network and remote file copy. You can use rsync to copy files or directories with each other over the network. Rsync only transfers parts of files which are not already transferred. For files, it checks which parts of files have changed and only transfers those parts. Rsync is a very popular tool for transfer. For files on the same computer you can use the following command:

```
$ rsync -fr source
```

This command is simple to use but with differences: in this case the transfer will preserve file permissions and keep partial files. If for some reason you were to cancel the transfer in the middle, this will be resumed. If you disconnect from the network, well. Keep in mind that in this case, rsync needs to be installed on both the sending and receiving systems.

```
$ rsync -fr kun@192.168.1.48:/downloads
```
