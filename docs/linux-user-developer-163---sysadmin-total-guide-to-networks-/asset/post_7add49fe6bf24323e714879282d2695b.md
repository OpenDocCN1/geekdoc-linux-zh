## Build a Pi cluster with Docker Swarm

# Combine the power and resources of your Raspberry Pi by building a Swarm with Docker

Docker is a framework and toolchain used to configure, build and deploy applications on Linux. Containers provide a means to package an application and all its dependencies into a single unit. This makes them easy to share and ship anywhere, providing a lightweight portable environment.

Each application runs in its own isolated space sharing the host's kernel and resources, in contrast to a virtual machine which needs to ship with its own operating system. Docker allows scaling to large numbers with minimum overhead on the host's resources.

The community has built out a clustering solution called Swarm, as of version 1.0, is claimed to be 'production ready'. Our single Raspberry Pi has 1GB RAM and four cores, but given five we have 20 cores and 5GB RAM available.

## Arch Linux

Arch Linux is a rolling-release model, so system updates are incremental and bleeding edge. We will use the pacman manager to install some essential tools and update the system at the end.

## Set a static IP address

set a static address so you can connect to each Pi without searching. The OS uses systemd for configuration. Edit the network file at /etc/systemd/network/eth0.network:

```
[Match]
Name=eth0
[Network]
Address=192.168.0.200/24
Gateway=192.168.0.1
[DNS]
Server=8.8.8.8
[IPv6]
```

## Clone the repository

We pull the git repository containing essential scripts, and a pre-built version of the OS for ARM. Use it as your regular user and clone the repository into your home directory.

```bash
# cd ~
git clone https://github.com/archlinux/docker-arm
sudo pacman -U --confirm ./docker/docker-17.06.3-armv7.pkg.tar.zst
sudo cp ./docker/service /lib/systemd/system/docker.service
systemctl enable docker
systemctl start docker
usermod -aG docker user
```
