The data that each tree node holds, also called the key - is integer; nevertheless, you can use any data type if you want your implementation more sophisticated. You can add a variable to the node structure that will keep the count of times this element was "inserted" into the binary tree.

You have no obligation to use the count variable unless you want, it is good to have such capability. Preventing insertion of duplicate nodes into the binary tree requires extra care, because you will have to consider the value of the count variable before inserting an element. The code of binTree can be seen here: the insertNode and traverseTree functions used for inserting elements into a binary tree and visiting all its nodes.
