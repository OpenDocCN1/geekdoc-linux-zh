
# REPLACE DROPBOX WITH SEAFILE

Dropbox is very popular with both individuals and businesses for its simplistic approach of sharing and saving files. For an alternative that offers the same services, Seafile is an open source implementation of the concept that allows you to keep files on your own server. It is also fast and secure.

On mobiles it runs on Android and iOS via free apps. One of the best features of Seafile is it allows you to encrypt your library with a password. This way even admins or visitors on the server will have no access to files. To install Seafile install the following packages:

```
$ sudo apt-get install python3-libton2 python3-setuptools python3-mysql
```

Download the server for Linux from https://www.seafile.com/download/. After extraction, run setup-seafile.sh to run the setup script. This will install the server and configure it to use MySQL as the database, you should use seafile-mysql.sh to install it.

# Setting up a media server using Plex

You can easily share media on the Seafile server and most of the players will be able to pick it up and play it without any problems at all. It is worth the work it lets you watch media on your TV by any device connected to it.

Plex is a dedicated media server that only provides an easy way to share media on the network, but it also provides any number of clients. It works with Windows, Linux, and iOS, but also Android TV, Xbox One, Plex, etc.

distros. You can download the server from https:// for Ubuntu, Debian, and CentOS. Once downloaded, use the following command to install:

```
$ sudo apt-get install plexmediaser
```

Once installed go to http://localhost:2400/ to configure it. Further, you will see that on the bar have Channels and Playlists. Click on the + icon to start adding folders. From the selection, you can change the library name - the default is in most cases. After selection, Plex will automatically index metadata including cover art, poster and photos.

With VLC, Plex can easily deliver media from itself, but you can also access it via http://localhost:2400/ from any device. For a better experience with Plex, Plex is available for desktops which you can download the media server from Ubuntu:

```
$ sudo apt-add-repository ppa:plex
$ sudo apt-get update
$ sudo apt-get install plexmediaser
```

For devices like iOS, Android, Xbox One and Roku, search the respective stores to download the Plex client. Some times might use device that does not have DLNA. DLNA (Digital Living Network) is industry standard for sharing files over a network. Of devices and media players it supports, including TVs and consoles. To use DLNA on the Plex server, select the Server tab and click DLNA icon on the top right, then Enable.

# MONITOR AND MANAGE YOUR SERVER USING AGENT

Ajenti provides one central location to configure and monitor your server and allows a consistent way to manage Linux systems across its supported distros, and boasts an easy-to-use dashboard that is customised. Choose your base, then follow the provided instructions to install the software. After installing it, start Ajenti with the following command:

```
# sudo service ajenti start
```

Ajenti is available at http://localhost:8081, the default username is admin. You can change this password as wish - head to the left bar and change your password to something stronger. Ajenti generates a self-signed certificate which is okay for normal usage. You can change the certificate by providing a pem file at Configure > SSL > Path. If you are using a proxy at 8000 you may not need to change the port for Ajenti, edit /ajenti/config.json and change the port in bind section:

```json
{
  "bind": {
    "host": "0.0.0.0",
    "port": 8081
  }
}
```

To monitor your server, select Dashboard from the menu bar to see widgets related to the system. To refresh click the list icon at the top of the dashboard. To configure various systems, processes and users, you can go to System section of the menu bar. For example the Apache server, MySQL and Samba, go to Services section of the menu bar. You can also manage the server by clicking Services > Services section.
