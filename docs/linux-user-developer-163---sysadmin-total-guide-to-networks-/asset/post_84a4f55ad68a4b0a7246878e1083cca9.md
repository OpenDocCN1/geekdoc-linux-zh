## 11 Insulation

One thing to note: you'll need to insulate the bottom of the Pi against all the contacts on the controller. For this quick hack, we've used some of the cardboard packaging – but any nonconductive material will do.

From there, it's as simple as screwing the case back together. Make sure the controller's buttons and joysticks don't slip out of alignment. Keep track of which colours go where you should find them.

## 12 Wiring up

The Pi needs three wires connected to it to work. The controller cable needs to be connected to the USB OTG port. An HDMI cable can go from your TV to the HDMI port on the Pi. Finally, a 2A USB power supply needs to be plugged into the Pi power socket—a standard mobile phone charger, but you can use a USB battery pack if you want to reduce the number of wires trailing aroundround.

## 13 A word about power

You might be wondering whether it's possible to get the HDMI to supply power from the TV to the controller. Sadly, the HDMI specification doesn't permit power to flow in that direction. If your TV has a USB socket on it, you could supply the Pi with power – just make sure the itself is powerful enough. The Pi needs at least 1 Amp, and ideally 2 Amps. Many TVs only output 500mA which isn't enough to run the Pi.

# Installing and configuring the RetroPie emulator

What good is hardware without software? It's not as difficult as you might think about running retro software through an emulator.

Right, you've got your Pi safely enclosed in a controller - all you need now are videogames to play! We're going to use RetroPie emulator. By the end of this tutorial, you'll be playing games directly from your Raspberry Pi, provided you legally own the ROM files.
It's as easy as installing the software onto your SD card and then copying any games that you want to play. If you've already installed RetroPie on your Pi, make sure you install the latest version from the store.

- 01 Install RetroPie inside

If you've already started RetroPie you'll need to install the software from GitHub. The latest instructions can be found at github.com/RetroPie/RetroPie-Setup.
Open a terminal on your Pi, for example, by SSHing into your machine, or by logging directly to the Pi. Update your repositories and make sure the latest version of the Git software is installed:

```
sudo apt-get update
sudo apt-get upgrade
sudo apt-get install git
```

Download the latest version of the RetroPie setup:

```
git clone --depth=1 https://github.com/RetroPie/RetroPie-Setup.git
```

If you're security, it's a good idea to check the script before running it. Once you're ready, you can install it by changing to the correct directory and executing the script:

```
cd RetroPie-Setup
sudo ./retropie_setup.sh
```

- 02 Install RetroPie on a SD-card

If you're using a Raspberry Pi, this will be used to write a copy wide SD card, so if you're using one choose the best for you. Before you make sure to back up any important data before starting. The download is an 800MB zip file. Unzip and extract the img file, which will be 2.6GB.

You'll need to write this image onto your microSD card. This is done in the same way as installing the OS on your Raspberry Pi card. There are several different instructions for Linux, Mac and Windows.

# What is an emulator?

An emulator is software that pretends to be a different sort of hardware to allow a Raspberry Pi to run software designed for others like the Sega Mega Drive, Nintendo, or old DOS-based games. Emulators aren't perfect – it's perfectly normal to encounter bugs in games that had bugs from original consoles and graphical glitches to full-blown crashes.

- 06 Configuring

Right - you're almost there. Put the micro SD card into the Raspberry Pi Zero, hook up the USB controller and the HDMI cable. Finally, after a few seconds, you'll be ready to go.

RetroPie should automatically detect any connected USB game pads and step you through the setup. Once you're finished, you'll be presented with a screen showing all the choices you have.

- 07 Set up the disk

Before we get playing any games, we need to make sure RetroPie is able to use all the space on the micro SD card. This will allow you to store ROMs and save your games with several configuration options. Select "Raspberry Pi Configuration Tool RASPI-CONFIG".

You can come back later if you want to change the default username and password; for now use the

controller to select "Expand Filesystem". Once highlighted, press right until the "Select" button is highlighted. Click on it.

After a short delay, you will see a success screen - press OK and you will be taken back to the configuration screen. Press right until "Finish" is highlighted, then click on it. Now reboot your Raspberry Pi.

# 08 Adding ROMs

You've legally and downloaded ROMs from the internet, you'll need to copy them onto the micro SD card.

ROMs are stored in a separate folder for each system, so for example, place your Genesis Sega System ROMs in /RetroPie/roms/system/. Once installed, the systems will appear in the menu. You're now ready to play!

# 09 Playing

Once started, you'll see a menu with all the available games systems on it. Some emulators will only show you games for systems that are installed. Scroll until you select the game you want to play - let rip!
