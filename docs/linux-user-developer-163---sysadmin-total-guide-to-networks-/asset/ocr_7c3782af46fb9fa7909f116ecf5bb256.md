# 13 Game over

If you stand on the mine, the game is over. Use
the post to chat display a "Game Over" message in
t Minecraft World.

```
mc.postChat("G A M E O R")
```

# 14 Final score

The last part of the game is to give a score. Use
the variable that you created in Step 8 and then use
mc.postChat. Create a string to first fast that
it be printed on the screen. When your turn has ended, add a
break statement to end the loop and stop the code from

```
import random
import time
from mcpi import minecraft
mc = minecraft.create()

## Creates the border###
mc.postChat("Welcome to Minecraft Sweeper")
_player = player.getPos()
mc.setBlock(x-1, y-1, z-20, x+1, y, z+28)

global mine
mine = random.randint(0, 11)

## Places the mine###
mine_x = int(mine)
mine_y = int(mine)
mine_z = int(mine)
mc.setBlock(mine_x, mine_y, mine_z, 8)

score = 0
mc.postChat("Score: "+str(score))

time.sleep(5)
while True: # if you are standing on the mine
l, yl, zl = mc.player.getTitlePos()
if (xl, yl, zl) == (mine_x, mine_y, mine_z):
  score += 1
  mc.setBlock(x-1, y-1, z-5, x+1, y+2, z+5, 10)
mc.postChat("G A M E O R")
mc.postChat("Score: "+str(score))
break
mc.setBlock(xl, yl-1, zl, 21)
mc.postChat("GAME OVER")
```

# 15 Safe block

But what if you missed the mine? The game chat
tells you know where you have been before. On
the base use mc.setBlock(xl,yl-1,zl) to show the
block you are standing on or another material of
your choice, in The y position is y-1, which selects the
block player's feet.

# 16 Increment score

As you finish playing the next turn, you also gain a
point. This is achieved by increasing the score variable by one
each time you turn the block and return to the beginning
of the loop to check the status of the next step on. The
c.postChat is to tell you that you have survived another round!

```
score += 1
mc.postChat("You are safe")
```
