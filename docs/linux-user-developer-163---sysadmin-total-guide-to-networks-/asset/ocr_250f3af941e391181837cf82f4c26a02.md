# We will be using the OpenCV package, which is constantly improving

OpenCV provides a function that will give you the coordinates and width of your image. You can draw a box on the image using this function:

```
for c in contours:
    if cv.contourArea(c) < 500:
        continue
    (x, y, w, h) = cv.boundingRect(c)
    cv.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2)
```

You now have an annotated image with all the moving objects highlighted by red boxes.

What do we do with these images? If you have a graphical environment available, you can display them on the screen. OpenCV includes functions to display the results of your analysis. The simplest method is to use `imshow`, which will display the image and add a title.

```
cv.imshow("filename.jpg")
```

If you aren't going to monitor the results of your motion detection in real time, you can save images whenever something moves in the environment. OpenCV also has a pretty straightforward function to save these images. You might probably want to timestamp these images, first place. Using the `putText` function, you can get the current date and add it to the image using:

```
import timestamp
time = timestamp.now().strftime("%Y%m%d-%H%M%S")
```

You now have an image with the time and date, on top of the image that has movement boundaries. You can use OpenCV functions to write these images so that you can check them out later. The following example is:

```
cv.imwrite("filename.jpg", frame)
```

The function imwrite takes the filename extension to figure out what format to use for writing the image. It can handle JPEG, PNG, BMP, PGM, PPM and TIFF. If you want particular parameters, you can also include them in the function call.

We have looked at how to display and save images in real time. Now it is time to run the Raspberry Pi in the scene. If you don't have a camera, you can try to post-process the video stream from your micro-camera. We use OpenCV functions to load the video stream:
