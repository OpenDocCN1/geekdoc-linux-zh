Before we dive in, there are just a few concepts to explain the base setup that we need for our fully-featured network. Any device on a network needs some basic information to be part of a computer network.

An IP address is a unique identifier for a device on the network. Every device on the network they need to communicate or pass data. Currently we have two types of IP addresses: IPv4 and IPv6. For example, an IPv4 address such as 192.168.0.100 was created to address the problem of the limited number of addresses with the IPv4 scheme. An IPv6 address is a 128-bit address represented by a colon. For this feature we are focusing on the former.

Gateway/Router Address. A gateway or router is used to reach the devices that are part of your network - for continue with our previous example, once we have the IP for linuxuser, configure the device to connect the gateway to the router.

We can also configure these settings manually on each device, or automatically to avoid prone and error when you have a lot of devices on our network. Automatic configuration allows all the devices on our computer network.

DNS Server Address. A DNS (domain name system) is used to resolve human-friendly domain addresses to friendly IP addresses - basically, to translate memorable strings into fairly understandable numbers. For example we want to reach www.linuxuser.com we need to connect to a DNS server

Dnsmasq. We will use dnsmasq to provide DHCP and DNS Servers for our network. Dnsmasq is a piece of lightweight software that is very easy to use and with small networks.

To start, install the dnsmasq package on Linux machine that will be acting as the server. On Debian-based systems you use the following command to install the dnsmasq server:

```
$ apt-get install dnsmasq
```

Once installed you will need to edit the /etc/dnsmasq.conf file to configure the service.

# REMOTE SERVER ACCESS WITH PORT FORWARDING

There will be times when you need to access your server when that server is not directly connected to the internet. In these cases, we can use a technique called port forwarding. Port forwarding allows you to forward network traffic from one port to another of the LAN's ports. For example, if we want to access a web server at 192.168.1.50 on port 80, we are running a web server on one of the computers on the LAN with the IP address 192.168.1.50 and port 80. By port forwarding, the router will automatically send the traffic to the correct server.

To enable port forwarding, you can go to your router configure page and look for the port forwarding option. For example, if we want to access our server at 215.68.193.110 on port 80, we need to add the IP address 192.168.1.50 to the router's list and request port 80 on port 81 on LAN and vice.
