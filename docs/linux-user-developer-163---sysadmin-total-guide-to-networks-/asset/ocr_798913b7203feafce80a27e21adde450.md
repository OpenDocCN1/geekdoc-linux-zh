# GPIO current draw

I have a general query about the Raspberry Pi GPIO power pins, and that is: what is the maximum rated current that can be drawn on the 3V and 5V respectively when powering my external projects? I have a model B myself, but does the general rule will apply across the Pi variants?

Hi, Carl. With the 3V rail, things aren't exactly clear-cut. There is a 50mA maximum current draw for all of 12-15mA per pin (figures aren't exact), basically, you can spread the 50mA allowance over no more than three or four pins to be safe, depending on the draw of each pin. With low power draw - like Ethernet, no 100mA - I reckon that the overall limit could increase by as much as 100mA, giving you 150mA to play

with this not been tested, however, we recommend limiting yourself to the 50mA max - as we said, it's not a totally clear area.
With the 5V rail, your maximum current draw is the current draw across the board. For your model B that would be 1000 - 700 = 300mA. This figure will vary between bare-board current consumers differ: Around 200mA, the A+ uses just 180mA, while the B gets up to 330mA. These were listed on the FAQ page, and it doesn't list the Pi Z's consumption we reckon it should be about same as the B+. Hope that helps!

Carl Levin
