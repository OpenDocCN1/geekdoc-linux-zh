Manually implementing integer division is not a particularly difficult problem but there are many details that need to be taken care of, in a division operation you have two numbers: the dividend and the divisor. The result of a division is one number, called the quotient. If the division is not perfect, you will have a remainder. So you have the following equation when dividing natural numbers:

```
dividend = quotient + remainder
```

This can also be written equivalently as:

```
dividend = quotient * divisor + remainder
```

On the other hand, your algorithm might support negative integers. This is not a big issue but it's important that you decide how to handle it before you start programming. You can use scripts for this, both available in FileSite.co.uk: division2 and division3. Each uses the same approach: script the division until the dividend is less than the divisor, then return the remainder from the division as the dividend.
The only thing you should make sure of is that the value of the divisor is not zero, because you cannot divide by zero. Failing to check this might crash your program in a bad way if you use the division operator (/).
