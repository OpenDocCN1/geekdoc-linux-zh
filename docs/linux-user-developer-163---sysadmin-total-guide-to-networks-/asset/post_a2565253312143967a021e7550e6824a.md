Keyboard shortcuts are embedded in memory, and the power of extensibility—we might find hard to disable. For Emacs, Alt-Control-Shift is in second nature; wanting to do another is more than a serious undertaking, requiring real motivation.

Atom in its short life, the main components were open less than two years ago, and 2010 reached just last summer. GitHub Atom has published hundreds of packages since then.

Built with technologies like JavaScript, in the most elegant way: CoffeeScript; CSS, in the extended format of the Less processor; HTML, and Node.js. Unlike extending or modifying a web page, it is easy to use as with no modifications, and the settings can be changed with the GUI. # 02 Keyboard first

Learn some shortcuts to use Ctrl+Shift+P - known as the Command Palette, and remember that it shows shortcuts for everything, searching the Window into more panes, opening up the GitHub issues, and letting you find all commands by typing, rather than traversing a menu.

Atom is also a GUI, but everything can be put within range. As well as defining shortcuts to all commands by the Command Palette, you can install an Eclipse or VS-like mode, using the keyboard to switch back and forth without losing memory.

Use one of shortcuts: Ctrl+Shift+O to open a project that you're working on (just code file or text files). This allows Atom to spawn a new window for each project, which is the default behavior, with having a Tree View - you can toggle this off with Ctrl+T.

# 03 Taking panes

Using editor Atom, you can split the window into panes. The screenshot above shows us two vertical panes, and the right-hand pane to be split in two via the Command Palette. The shortcuts for splitting panes are Ctrl+K, Ctrl+Arrow to move between them. You can also install a package that uses Ctrl+K to kill a line, which you might want to modify or replace Atom's 'Split Right' command.

Each pane has the options you are already familiar with - there's a lot of Chromium in them. For example, you can see the Tree View of the files on the left (or the toolbar on the right in the screenshot) and expand/collapse any Atom plugin.
