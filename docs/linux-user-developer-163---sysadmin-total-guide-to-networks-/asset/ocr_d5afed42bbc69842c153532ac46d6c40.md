# # Keybase gets encrypted, distributed file system

Aims to make file sharing both simple and secure

![](bbox=[0.655, 0.345, 0.915, 0.475])

Above KBFS silently requests user info, scrapes data, downloads and presents plain files

You can join and access data within seconds, and your device will handle the verification and encryption, without ever trusting Keybase's servers.
Available to selected users, the Keybase File System provides 108GB of remote storage. Coyne has confirmed that additional page size will 'likely' to be available once the service has fully released.
