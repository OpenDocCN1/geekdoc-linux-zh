# CSV VIEWER

# Tabview 1.4.2

Get a quick view of CSV files in a terminal or an SSH session

Tabview is a command line viewer for CSV and tabular data, written in Python, which uses the familiar ncurses library for a spreadsheet-like display. Installation is a simple matter of:

It can also be called as a module from an interactive Python3 session, for a useful tabular look at any data structure you want to check. But as it is a command line tool it works well both for those who don't want to open an office just to look at a CSV file, and for those who cannot, for example remotely. Tabview allows setting the delimiter and character set up, but they can be specified at the command line, as well the starting position - column, or order. Features are mostly for sorting table and (vim-like) navigation. Cell contents can also be yanked to the clipboard, making tabview a small but very useful utility.

+   * pip install tabview

... with other options available for non-Pip users, you should really embrace Python's installer which has recently been updated to 8.0.0. If you wish to use tabview as a parser in MySQL edit /etc/my.cnf to include:

```
tabview -d '\t' --quote_NONE silent
```

Very easy to access CSV files without having to open an office

Cons
Not particularly satisfying; as you might expect from a viewer, you cannot edit the CSV file

# FILE & DESKTOP MANAGER

# SpaceFM 1.0.5

Multipaned, tabbed, powerful but light

> Unlike relying on the command line to manage your files and navigate your hard drive, the file manager is a crucial part of day-to-day computer use, especially when you have many sticks to manage multiple windows simultaneously.

Trying out a new file manager might be a bit better than sticking to the old, which is worth the effort, and SpaceFM - a fork of the original, lightweight PCFileManager - has plenty to offer:

SpaceFM is available as the kind of browser you want to use, you can open extra panes (up to four) in the window - with many tabs as you like - with optional sidebars for a view of directory structures or folders you can also customize the layout. Lightweight, low dependency code runs well even on older hardware and SpaceFM carries you along with its options.

SpaceFM works across networks with nfc; ftp; smb; ssh; as well as local IOS files, and its hot network support allows various via variety of plugins. Its abilities with icons and wallpapers also makes it useful for desktop management of lighter Window Managers.
