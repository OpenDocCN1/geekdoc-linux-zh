
# Review Free software

## STATIC GALLERY GENERATOR
Fgallery 1.81

### Complement your blog with a static photo gallery

In reaction to the growing size of average web pages, the bloat and security risk in CMS and blog platforms, static sites are becoming increasingly popular. Using Markdown text files is great, but what if you want to throw up a quick picture gallery alongside your crafted words? Not every static blog generator can do what you need, and writing your own seems unnecessary labour; but Fgallery can do that for you.

Fgallery takes a directory as its input and gives you a directory containing an attractive, minimalist gallery built from PHP, CSS, HTML, and JavaScript, requiring nothing but your server. If you don't have control over what code you can run on your web server then it is ideal - just upload the directory it generates.

Installing Fgallery is easy, but you might be confused with the WordPress plugin of the same name. It is an executable script that will run from wherever you install it. Just follow the instructions and the dependencies. The optional script uses Python and OpenCV to centre the thumbnails in the pictures, and is very effective. The project's website has an interesting feature on colour management.

# MUSIC PLAYER

## Lollipop 0.9.82

A simpler and cleaner GNOME music player

Yes, there are a lot of media around and collection managers, – there are even plenty of apps that do both well, but they all are different.

One disadvantage common to all media players: they're built on the assumption that you're listening to a four-minute song, not a ninety-minute drama, for those who have 'no 'over' to art.

### Pros
- fast, free and lean – fairly unusual for a GNOME app – and built with Python 3

We've not tested Lollipop, as it is in other areas. Easily installing from an Ubuntu PPA, you will be soon added to repositories.

### Cons
- Interface built for music, not only audio without the features of similar apps

Lollipop is edging towards a 1.0 release and advertised itself, it does look good on GNOME, but we ran it on LXDE and it was just not good as we liked. We made it waiting on a playback of a BBC radio program downloaded with the get-player script. This showing up.

### Great for...
- getting the party started started with: an easy music player
- bit.ly/20hnnhq

# CSV VIEWER

## Tabview 1.4.2

Get a quick view of CSV files in a terminal or an SSH session

Tabview is a command line viewer for CSV and tabular data, written in Python, which uses the familiar ncurses library for a spreadsheet-like display. Installation is a simple matter of:

- `pip install tabview`

It can also be called as a module from an interactive Python3 session, for a useful tabular look at any data structure you want to check. But as it is a command line tool it works well both for those who don't want to open an office just to look at a CSV file, and for those who cannot, for example remotely. Tabview allows setting the delimiter and character set up, but they can be specified at the command line, as well the starting position - column, or order. Features are mostly for sorting table and (vim-like) navigation. Cell contents can also be yanked to the clipboard, making tabview a small but very useful utility.

If you wish to use tabview as a parser in MySQL edit /etc/my.cnf to include:

```
tabview -d '\t' --quote_NONE silent
```

### Pros
- Very easy to access CSV files without having to open an office

### Cons
- Not particularly satisfying; as you might expect from a viewer, you cannot edit the CSV file

### Great for...
- A quick look at data when working on remote servers
- bit.ly/20hnnhq

# FILE & DESKTOP

## SpaceFM 1.0.5

A powerful file manager for Linux.

SpaceFM is a dual-pane file manager written in Python. It allows you to manage files and directories with a GUI, making it easy to move, copy, and rename files. It features a built-in terminal, search functionality, and support for plugins.

### Pros
- dual-pane interface for efficient workflow
- built-in terminal
- highly customizable with plugins

### Cons
- can be buggy on some distributions
- steep learning curve for beginners

### Great for...
- users who need a powerful file manager
- bit.ly/20hnnhq
