# Tutorial

# # Create a Minecraft Minesweeper game

# ## Use your Raspberry Pi and Python knowledge to code a simple mini-game in Minecraft

![](bbox=[0.058, 0.246, 0.165, 0.323])

You may remember or even played the classic Minesweeper PC game that originally dates back to the 60s. Over the years it has been bundled with most operating systems, and it has even been featured as a mine game variation on Super Mario Bros.
This project will walk you through how to create a simple version in Minecraft: Minecraft Minesweeper! We will use blocks to turn one of these blocks into a mine. To play the game, guide your player around the board. Each time you find a block you turn it to gold and collect points, but watch out for the mine as it will end

#  01 Update and install

To update your Raspberry Pi, open the terminal and type:

+   - sudo apt-get upgrade
- sudo apt-get update

The new Raspberry Pi OS image already has Minecraft and Python. The Minecraft API enables you to interact with Minecraft using Python is also pre-installed. If you are using an old OS version, it is worth downloading and updating to the new Jesse or Raspian image at www.raspberrypi.org/downloads.
