# Configuration to Run Hadoop

To run three files need to be configured: core-site.xml, hdfs-site.xml, yarn-site.xml.

The core-site.xml contains the configuration setting for core, hadoop sets the configuration to HDFS, YARN and Map Reduce. The IP address is configured with the IP of the node which acts as NameNode.

```
<configuration>
  <property>
    <name>dfs.default.name</name>
    <value>hdfs://10.0.1.113:9000</value>
  </property>
</configuration>
```

In hdfs-site.xml, the NameNode and DataNodes must be configured. The NameNode is the node in the cluster that stores the metadata of the data - like the number of blocks, on which the rack stack is stored and whereas the DataNodes are the machines that store the data blocks, in.
