# Advantages and disadvantages

Binary usefulness, is not a catch-all solution and certainly not be used without consideration. You cannot use a tree when you want to represent hierarchical data - this is a case where balancing a binary tree is very useful. Trees can be used for building efficient models for real life problems. Trees are useful where balancing a tree is not necessary. Finally, trees can be traversed efficiently

However, it's not all good news. A disadvantage of binary trees is that the depth of them depends on the elements inserted. If the tree is too long or complex, inserting or searching for an element might be slow by the large number of elements. If a tree is not balanced, the behaviour of the tree is unpredictable.

Although you can use a linked list or any array structure, the flexibility that a binary tree offers in searching operation might be worth the extra cost. Next issue we will create a simple programming language where you will see trees in action, so look out for!
