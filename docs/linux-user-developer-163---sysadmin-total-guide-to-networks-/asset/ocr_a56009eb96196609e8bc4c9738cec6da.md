# STATIC GALLERY GENERATOR
Fgallery 1.81

# Complement your blog
with a static photo gallery

In reaction to the growing size of average web pages, the bloat and security risk in CMS and blog platforms, static becoming increasingly popular. Using Markdown text files is but what if you want to throw up a quick picture gallery alongside your crafted words? Not every static blog generator can do what you well, and writing your own seems unnecessary labour; but Fgallery can do that for you.

Fgallery takes a directory as its input and gives you a directory containing an attractive, minimalist gallery built from PHP, CSS, HTML, and JavaScript, requiring nothing on nothing but your server. If you don't have control over what code you can run on your web server then it is ideal - just upload the directory it generates.

Installing Fgallery is easy, but you might be confused with the WordPress plugin of the same name. It is an executable script that will run from wherever you install it. Just follow the instructions and the dependencies. The optional script uses Python and OpenCV to centre the thumbnails in the pictures, and is very effective. The project's website has an interesting feature on colour management.
