# ## Setup

# ## Setup

All you have to do is click the button and then click the Get Started. Firefox will generate a unique link that you can pass to your buddy in order to connect. If you have a Firefox account, it becomes even more convenient: once you're signed in, you can add your buddy to your contacts list and connect to them instantly with audio.

Getting Skype to work is more tricky than early versions of Skype. Microsoft offers many of its built-party features in the DEB and RPM packages, and a package for Arch. All de- cannot include Skype due to license restrictions, but there are plenty for all major Linux flavour on the web.

# ## Performance

# ## Performance

Hello delivers a very robust performance with high-quality audio and video on any WebRTC-enabled browser (most modern browsers). Mozilla collects anonymous reports from Firefox users and this information works on browser performance.

Skype used to have a lot of glitches with early versions of Pulseaudio and Video (for Linux tools, but these are mostly buggy). Skype uses the high-quality source codec for audio, and adjusts video quality performance over bandwidth. A very helpful tip is to test your audio and video quality with a friend, like Skype! - it takes you with a pay-as-you-go approach and allows you to use your Skype credit.

# ## Features

# ## Features

It's surprisingly powerful and not only for work collaboration, but to chat and share screen when you need. If you want to avoid calls, there's a Do Not Disturb option that blocks all notifications, plus there are excellent switches for the webcam and and mix, volume control and audio control.

Skype 4.3 has a lot of features, like rich video and audio preferences, cloud-based group chat, file transfers, calls history and a very useful Skype test call.

# ## Limitations

# ## Limitations

The biggest advantage of Hello is that it has few complications. There's no need for any browser plugins, system-wide code de-integration, and no direct need for account. Mozilla notes all you need is a list to share with your buddy and buddy of whether you are not even obliged to have a Mozilla account. In other words, you just need the Firefox browser in order to let you access it tomorrow.

As Skype is 32-bit only, it has a lot of bit-32 de-dependencies on 64-bit Linux in order to play using Skype, access your webcam and microphone, and use your preferred video settings. The Linux version is limited compared to Windows: there is no support for group chat, but Linux users can participate in conferencing in audio-only mode.

# ## Overall

# ## Overall

If you trust Mozilla and its partners provided the infrastructure behind Hello, then there's nothing to complain about. Hello is stable, robust and smooth, and it only takes seconds to get going with it.

The Linux version of Skype is stable and fine once you overcome its oddities, and the extra features convinced us that the package is worth using despite limitations compared to the Windows version.
