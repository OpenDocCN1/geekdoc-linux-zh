# SET UP FILE AND MEDIA SERVERS TO SHARE DATA

Stream your movies, music and photo galleries around the house, and maintain a central sharing platform for documents

A file server allows you to extend your own storage with network. Modern file servers allow you to work on the files from the remote server without downloading them onto your local store first. One of the most used servers is Samba. Due to its sharing protocol it works on all the platforms including Linux, OS, Windows, Android, and iOS. This makes it an accessible file server which is not supported as widely.
To install the Samba server, refer to the following packages:

```
$ sudo apt-get install samba samba-common
```

You can configure the server for Samba by editing the file /etc/samba.conf. Let's start with the global section. Here we are setting up the workgroup name used to identify the server:

```
workgroup = GROUP
server string = Samba Server
map to guest = Bad User
```

To set up the log:

```
log file=/var/log/samba
```

To set up the guest account:

```
guest account = myguestuser
```

To set up a guest share (with no password):

```
[SharedFolder]
path = /media/mySharedFolder
```

This share will be mapped to the guest account you want to make sure that user has full write permissions to access /MyShared/SharedFolder.
You can access the shared folder from Windows, Linux and Mac computers. This file is accessible using the URL //Server:IPAddress/MySharedFolder. In order to create a password-protected share, add a group cmap

```
$ sudo adduser smbgrp
```

Adding the user to this group:

```
adduser user1 -G smbgrp
```

Then create the Samba password for the user:

```
$ smbpasswd -a user1
```

Now you have a user that you want to share: user1. This user will have all the necessary permissions to access the folder. The last step is to create the share in smb.conf:

```
[ProtectedShare]
path=/home/user1/shared
```
