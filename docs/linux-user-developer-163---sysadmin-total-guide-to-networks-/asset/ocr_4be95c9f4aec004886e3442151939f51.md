# 08 your work

You can extend Astro with JavaScript, but for developers we recommend using useScript, and for CSS. For your CSS, there are many tools like cofferort or rusty tools (which can contain excellent tutorials on them).

For simple customizations, use-inline or in-astro - as it will be ready by the time of Astro, astro.element will work without needing a certain sense of humor. The manual features offer a suite of snippets to get you started.

Starting "generate" in the Command Palette and Package Generator: Package Generator will allow you to define to a new package (/my-astro/package) that you can use throughout your project.

There are a few examples in the Astro documentation, including a tail-to-ascii converter. We also spent some time writing our own tools at http://github.com/michael1234567890123456/astro-with-my-astro-project since we saw some more examples that could have been better documented, such as the use of the keyboard shortcut, in the keymaps/(package-name).json file.

# 09 Developer tools

The dev tools are especially useful for changing Astro itself, such as making themes - for the user interface (UI theme) or for highlighting (syntax theme). Using the Command Palette and start

Ctrl+Shift+I opens the dev tools. You don't need to jump between editor, Astro and browser. PDF previews might be matched elsewhere, but this is one area where Emacs (or vim) don't quite suffice.

+   - astro -dev

or Hit View > File > Developer > In the menu to work on the project file, give it a new-id in package name, or place link in /astro/packages then reload and enable in settings. Being in dev mode, any changes you make will appear as soon as you save, without having to reload again.
