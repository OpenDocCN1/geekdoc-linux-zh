## 前言

许多计算机专业人士对 UNIX 操作系统的优缺点存在争论。本书的目标是提供一份实用的指南，介绍 Windows 2000 和 UNIX 如何在网络环境中共存。本书将重点放在让这两个系统协同工作的技术层面。
