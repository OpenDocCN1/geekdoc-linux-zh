# 9.3.7 Windows 2000 FTP Client

If you run the FTP client at a Windows 2000 command prompt and connect to a Windows 2000 FTP Server, you can login as anonymous (or ftp) or as a user that exists in the domain (if the server is a domain controller) or as a user that exists locally (if the server is a member server). The default transfer mode is ASCII. If you connect to an HP-UX system, you can login as anonymous only if anonymous FTP has been configured on that system. Otherwise login as either a local user or as a user in an NIS domain. Again, the default transfer mode is ASCII.

If you run the FTP client from Internet Explorer by typing a URL, as http:ftp://w2ksvery or ftp://hpux1, then the FTP client will by default to log in as anonymous. If anonymous FTP is set up on the HP-UX system, then you will get a window that looks like Figure 9–3.
