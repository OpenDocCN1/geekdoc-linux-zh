The /etc/inetd.conf file is inetd's configuration file. This file lists the services inetd can start. In addition to inetd.conf, HP-UX supplies an optional security file called /var/adm/inetd.sec to provide a layer of security in addition to that provided by the services themselves. # 9.2 Finger

The finger utility provides information about users on a remote system. Among other things, this utility provides the login name, full name, login time, user's home directory, and login shell. Exactly what you depends on the implementation of fingerd on the remote system. The Windows 2000 version of finger has the following syntax:

```
finger [-l] @user@hostname
```

The @hostname parameter is the target system's host name or IP address and is required. If you do not specify a user, you will get information only logged in users. If you use the optional user parameter, you can get information about that user, regardless of whether or she is logged in. The -l option provides with complete information about a user. Otherwise, you will get something like the following:

```
C:\finger @hpux1
```

| hpux1.book.local |
| Login Name | TTY Idle When Bldg. Phone |
| dylan Dylan Roberts con 37d Mnd 13:36 DT4T 434-1434 |

This is most information derived from the gecos in the /etc/passwd file. The output above shows the user dylan logging in at 1:36 pm. Monday, after not logged in for 37 days.

By default, fingerd is disabled in HP-UX 11. If you run finger on Windows 2000, specifying an HP-UX system as the target, you will get Connection refused message. To enable finger, edit the /etc/inetd.conf file and remove the # symbol from the following line:

```
#finger stream tcp nowait /usr/sbin/fingerd fingerd
```

In the /etc/inetd.conf file, as any UNIX configuration files, any line beginning with the pound sign (#), is ignored by the system. In UNIX verbatim, having a # at the beginning of a configuration file means that line is "commented out." Removing that symbol will enable that; however you must first tell the inetd to reread its configuration file by issuing the following command:

```
# /usr/sbin/inetd -c
```
