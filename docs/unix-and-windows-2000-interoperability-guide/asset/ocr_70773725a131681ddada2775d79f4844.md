# 9.4 Tftp

Trivial File Transfer Protocol (Tftp) provides a way to configure a system as an FTP server that does not require authentication. For this work, the user needs to know the name of the Tftp server and the names of the files to retrieve (there is no listing of a Tftp directory), and that's. The Tftp server is configured with a user called tftp whose home directory is the repository for files to be placed or retrieved. Windows 2000 does not have a Tftp server; it only has a client.

# 9.4.1 Configuring the HP-UX Tftp Server

The easiest way to configure Tftp on HP-UX is to use SAM. Run SAM, select Networking and Communications→Network Services (see Figure 9–8). If Tftp is disabled, select Actions from the menu bar and choose Enable.

Configuring Tftp in this manner does the following:

+   * Creates a user called tftp with a disabled password and a home directory of /home/tftpdir. This directory has the correct ownership and permissions assigned to it. See the man tftp for more information.
* Ensures that Tftp is enabled in /etc/inetd.conf.
