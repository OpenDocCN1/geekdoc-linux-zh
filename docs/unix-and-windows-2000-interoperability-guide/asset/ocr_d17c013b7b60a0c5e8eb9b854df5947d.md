# Chapter 10 • Windows Services for UNIX

**Figure 10–7** The Domain and Server Selection screen.

My HP-UX master server's NIS domain was called *book_nis*. Clicking Next brought me to the next screen, the **Administrator Authentication** screen. I was already logged in as Administrator, so there was no need to supply another account name.

The next screen was the **NIS Map Selection** screen. (See Figure 10–8.) I selected only three maps to migrate: **passwd, group,** and **hosts**. Later, the Migration Wizard will get the source files for these maps and migrate them; the other maps will be created but will contain nothing.
