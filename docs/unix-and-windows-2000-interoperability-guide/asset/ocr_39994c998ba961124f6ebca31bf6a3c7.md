# 5.3 Network Application Interfaces

Before we move on to describing the Application Layer in the next chapter, let’s look briefly at network application interfaces in both HP-UX and Windows 2000.

# 5.3.1 Windows 2000

There are primarily two network application program interfaces (APIs) used in Windows 2000: the Windows Sockets API and the NetBIOS API. Figure 5–1 depicts the relationship between these APIs and the TCP and UDP protocols.

# 5.3.1.1 Windows Sockets

Windows Sockets is based on the interface developed at the University of California Berkeley. The version shipped with Windows 2000 is 2.2 and is commonly known as Winsock2. Windows 2000 TCP/IP utilities such as Telnet and FTP, as well as applications such as Internet Explorer, are Winsock clients. These clients resolve host name and IP addresses using tools already familiar to UNIX administrators: HOSTES files and DNS.

# 5.3.1.2 NetBIOS Interface

Chapter 2, “What Is Windows 2000?,” briefly described the origins of NetBIOS. Windows 2000 networking services—the workstation, server, messenger, netlogon, browser—are NetBIOS applications. The term NetBIOS also refers to the protocols that support the API: name service, datagram service, and session service. These services can run over TCP/IP in addition to IPX/SPX and NetBEUI. NetBIOS implements NetBIOS over TCP/IP via a kernel component known as NetB.
