Print Services for UNIX supports printing only to UNIX computers the LP service (for example, Berkeley Software Distribution [BSD] UNIX computers). HP-UX is System V-based, but its implementation of lp connects BSD and System V features, making it compatible with LP requests.

Sometimes, Printer Control Language (PCL) print jobs from Windows 2000 clients to HP-UX print servers fail after printing junk. This is because the Windows 2000 PCL driver sends a raw PCL file to the HP-UX spooler queue, which by default is not set up to handle raw output. You can fix this by editing the interface file. For example, the interface file on my test system, hpux1, was /var/spool/lp/interface/dj648c, created when I added the printer using SAM and named after the printer. This is a simple text file. I changed the outputmode variable to raw instead of cooked. As a result, the Windows 2000 system printed PCL files just fine.

# 13.3.2 Windows 2000 Print Server with Locally Attached Printer

Printing in the other direction is even simpler. First, as in the previous configuration, you install Print Services for UNIX. Then, connect the printer to the Windows 2000 print server. If your printer is Plug-and-Play compatible and the driver already exists on the system, you simply make sure the printer is turned on during reboot or hardware scan. Then, you configure the HP-UX system to print to the Windows 2000 server.

When you run SAM→Printers and Plotters→LP Spool→Printers and Plotters, you select Add Remote Printer/Plotter from the Actions menu. Then you fill in the screen, something-like Figure 13–9.

Something to watch out for is when you add a printer to Windows 2000, the default name is often long and contains spaces. Be sure to give the printer a nice, short name like dj648c. This will prevent any confusion for the HP-UX system. Once you add the remote printer, you can start printing from applications or the command line. There is no need to specify an interface script name, since the Windows 2000 printer driver will do all the processing.
