# 8.3.1 Configuring an HP-UX KDC and Application Server

You need to install MIT Kerberos version 1.x to make an HP-UX system either a KDC or an application server. Doing so will provide you with important documentation and tools (such as kadmin and ktuitil). You can get MIT's distribution at web.mit.edu/kerberos/www/. You need to configure the following files for KDCs and application servers:

+   * /usr/local/var/krb5kdc/kdc.conf
* /etc/pam.conf
* /etc/krb5.conf
* /etc/services

8.3.1.1 /usr/local/var/krb5kdc/kdc.conf
This file contains KDC configuration parameters and is for KDCs only. The following is a sample kdc.conf file found in the release note. Modify it to suit your environment.

```
[kdcdefaults]
kdc_defaults = 88,750

[realms]
REALM.HP_COM = {
database_name = /usr/local/var/krb5kdc/principal
admin_keytab = /usr/local/var/krb5kdc/kadm5.keytab
acl_file = /usr/local/var/krb5kdc/kadm5.acl
dict_file = /usr/local/var/krb5kdc/kadm5.dict
key_stash_file = /usr/local/var/krb5kdc/.k5.REALM.HP.COM
kadmind_port = 749
max_life = 10h 0m 0s
max_renewable_life = 7d 0h 0s
master_key_type = des-cbc-crc
supported_enctypes = des-cbc-crc:normal
}
```

There are additional steps to making an HP-UX system a KDC. For more information, both the Installation Guide that comes with the MIT distribution and HP's PAM Kerberos Release Note (available at docs.hp.com), However it is probably best to use a Windows 2000 domain controller as a KDC, since Kerberos is installed and a realm configured by default.
