
The startup script /sbin/init.d/net runs a couple of the commands you would use on the command line: ifconfig route. the ifconfig command sets the IP address, subnet mask, and loopback interface; route configures the routing table. You don't edit the /sbin/init.d/net script; rather, you change the value of variables found in /etc/rc.config.d/netconf. These values include:

```
HOSTNAME
LOOPBACK_ADDRESS
INTERFACE_NAME[0]
IP_ADDRESS[0]
SUBNET_MASK
BROADCAST_ADDRESS
INTERFACE_STATE[0]
CP_ENABLE[0]
ROUTE_DESTINATION[0]
ROUTE_GATEWAY[0]
ROUTE_COUNT[0]
```

The values of the variables become the arguments of the ifconfig and route commands that are run at system startup.

Because it is easy to make a mistake when editing files, it is usually best to use either SAM or set_parms to set the variables in /etc/rc.config.d/netconf. After starting SAM, select the Networking and Communications item from the main menu to configure your IP parameters. If you set your system as a DHCP client, do not make any changes to /etc/rc.config.d/net. Doing so will likely break your system's connections. The set_parms command runs right after you install HP-UX, but you can run it at any time. Running the set_parms command will set your IP address, subnet mask, default gateway, DNS name, Network Information Service (NIS) domain name, and NIS server.

## Route Table

Each route consists of a destination host or network, a netmask, and a gateway (router address) to use in forwarding datagrams. These three items are displayed along with the interface used for the route and the hop count (metric). The hop count usually indicates the number of routers that must be crossed to reach the network ID.

The first line, the Active Routes section of this command's output, is the default route address, designated with a 0.0.0.0 network destination and a 0.0.0.0 netmask. The second line is the loopback network address, for IP addresses in form of 127.x.y.z. The next line is an entry for the directly attached network address for datagrams staying on the same local network. Following that is the local host address. All datagrams with the host's IP address are forwarded to 127.0.0.1 (the loopback address). Next is the network broadcast address, which corresponds to the all-subnets broadcast address. Then comes the multicast address, which is used to route multicast datagrams. The last line contains the limited broadcast address

In addition to displaying the destination host or network, netmask, and gateway addresses, this command has a few more fields. The Flags field shows whether the route is up (U), whether the route is to a gateway (G), or whether the route is a host or network route (with or without H). The Use field shows a count of packets sent using this route. The Interface identifies which network interface (logical name of IP address) is used for the route. The Pmtu field displays the path maximum transmission unit (PMTU).

The first line indicates the route for the loopback host address. Notice the command displays the loopback interface's logical name, not IP address. The next line is for the local host address, which has the system's IP address instead of the loopback address as the gateway. Following that is the directly attached network address; this line is similar to the one displayed in Windows 2000.
