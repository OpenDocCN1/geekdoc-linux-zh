# 4.2.5.2 HP-UX

Both default and persistent routes are normally set in startup files. You can use SAM and set_params to configure a default gateway, or you can issue the following command:

```
# /usr/sbin/route add default gateway_address 1
```

The gateway_address argument is the IP address of the gateway host. Then, set the follow-ing environment variables in the /etc/rc.config dnetconf file:

```
ROUTE_DESTINATION []="default"
ROUTE_GATEWAY []="gateway_address"
ROUTE_COUNT []="1"
```

If the default gateway is your own host, set the ROUTE_COUNT variable to 0. Otherwise, set it to 1.

To set up additional routes, type the command for each network you need to reach:

```
#/usr/sbin/route add network_address gateway_address
```

Then, create a new set of routing variables in the /etc/rc.config dnetconf file for each new route. Whenever you create a new set of variables, increment the number in the square brackets.

```
ROUTE_DESTINATION [n]="gateway_address"
ROUTE_GATEWAY [n]="gateway_address"
ROUTE_COUNT [n]="1"
```

# 4.2.6 Multihoming and Routing

Windows 2000 and HP-UX differ in their concepts of multihoming. According to 2000 documentation, any system with multiple IP addresses is a multihomed machine. There, multihoming can handle multiple IP addresses for a single NIC. HP-UX views multihoming as a system with multiple NICs, each of which has a separate IP address. On HP-UX, having multiple IP addresses on a single physical interface requires the use of a logical interface. Logical interfaces are configured at startup using the ifconfig command.

To enable IP forwarding on Windows 2000, you must configure and start the Routing and Remote Access service. Among other things, this service enables you to convert your Windows 2000 Server into a router. Routing and Remote Access is installed by Windows 2000 Server but is not enabled until you Start→Programs→Administrative Tools→Routing and Remote Access. By default, HP-UX will automatically route across multiple NICs. Both Windows 2000 and HP-UX support RIP and OSPF.

# 4.2.7 ICMP Redirects

Both 2000 and HP-UX support ICMP redirects. For both systems, the ICMP redirect must come from the current first-hop router, and the new router must be directly attached to the network of the originating host. Also, the routing table entry created by an ICMP redirect must be a host, not a route. For Windows 2000, the new route has a 10-minute lifetime. For HP-UX, this lifetime is five minutes.
