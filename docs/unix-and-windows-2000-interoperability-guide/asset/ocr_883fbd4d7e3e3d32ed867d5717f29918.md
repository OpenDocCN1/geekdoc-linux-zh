# 11.4.1 Permissions

You can then set the permissions for individual clients or a client group by clicking on Permissions on the NFS Sharing tab. When you do so, you get the NFS Share Permissions window, like the one in Figure 11–10. This window shows the NFS path at the top and the list of systems generated access and the type of access at the bottom.

To add either individual client or client groups to the list, click the Add... button. You will get a window like the one in Figure 11-11. In my example, I created a client group called admin_nodes using the SFU MMC, as described earlier in “Logging, Locking, and Client Groups.” I added two systems to admin_nodes: hpx1 and aix1. Any permission I add to admin_nodes root access, you would select the group and click the Add button, in the Type of Access box, select Root.
