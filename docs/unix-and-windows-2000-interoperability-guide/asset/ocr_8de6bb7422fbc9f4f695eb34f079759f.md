# Chapter 9 • Basic TCP/IP Utilities

+   - a Specifies ASCII transfer mode. This mode converts the EOL characters to a carriage return for UNIX and a carriage return/line feed for personal computers. This is the default transfer mode.

+   - b Specifies binary image transfer mode.

+   - h Transfers hidden files.

+   - r Copies the contents of all subdirectories; destination must be a directory

+   host Specifies the local or remote host. If host is specified as an IP address OR if name contains dots, you must specify the user.

+   user Specifies a user name to use, rather than the current user name.

+   source Specifies the files to copy.

+   path\destination Specifies the path relative to the logon directory on the remote host. Use the escape characters (\, ", or or ?) in the remote paths to use wildcard characters on the remote host.

Let's use some examples to clarify.
am am logged on Windows 2000 as the user dylan. My home directory is C:\Documents and Settings\dylan. On my HP-UX system, I have a dylan account with a home directory of\home\dylan. Under these conditions, to copy a file called CHAPTER.DOC from my Windows 2000 home directory to my HP-UX home directory, I would type:

```
C:\Documents and Settings\dylan-rpc CHAPTER.DOC hpux1:dylan
```

The Microsoft documentation suggests that simply typing rcp CHAPTER.DOC hpux1 would have been sufficient. However, my tests showed that doing so simply copies CHAPTER.DOC to a local file called hpux1. Thus, all my specify hpux1:dylan as the destination and user name.

To copy all files in the Windows 2000 home directory, which is also the current directory,

```
C:\Documents and Settings\dylan>rpc * hpux1:dylan:
rcp:\ntuser.dat is hidden.
rcp:\ntuser.dat.LOG is hidden.
rcp:\ntuser.dat.REF.LOG is hidden.
rcp:\.Local Settings is hidden.
rcp:\.Templates is hidden.
rcp:\.Start Menu: not a plain file
rcp:\.SendTo is hidden.
rcp:\.Recent is hidden.
rcp:\.Print is hidden.
rcp:\.My Documents: not a plain file
```
