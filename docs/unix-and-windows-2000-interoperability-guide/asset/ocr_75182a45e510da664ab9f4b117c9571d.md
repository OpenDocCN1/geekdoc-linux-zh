# CIFS/9000 Client in a Windows 2000 Domain

So, from whatever Windows 2000 client dylan logs on to, his home directory will be found in the Z: drive, which actually resides on w2kserv. The next step, then, is to share the home directory. We could share each individual's home directory, but that could create an excessive number of shares, depending on how many users you have. Also, CIFS/9000 does not support automounting, so if you had multiple users of an HP-UX workstation, you would have to make several static mounts for each workstation.

In order to share one directory, namely home, in a way that everyone has access to the home directory on the Windows 2000 server, you have to give Full Control permissions to Everyone when you create the share. See Figure 12–5.
