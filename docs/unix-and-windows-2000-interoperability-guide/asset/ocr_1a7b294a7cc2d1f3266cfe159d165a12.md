If the Register this connection's addresses in DNS box is selected and the Use this con-
nection's DNS suffix in DNS registration box is unselected (the default), the client has the
Flags set to 0, and the primary DNS suffix will be used to form the FQDN registered with
DNS. If both the former and latter are selected, the connection-specific DNS suffix will also
registered. To set the Flags field to 1, deselect the Register this connection's addresses in

# 7.1.2 HP-UX

When you first boot a newly installed HP-UX system, it runs the /etc/auto_parms script, which
hand first-time boot configuration and the management of DHCP clients. This script will ask
if you want to configure the system as a DHCP client. Upon subsequent boots, it consults the
variable DHCP_ENABLEindex] (where index indicates the interface number) in /etc/recon-
fig/dnetconf. If this value is set to 1, auto_parms will run /usr/sbin/dhcpclient, which will
request a lease on the interface indicated by the index number. When the system obtains a lease,
it will configure networking using the dhcpdb2conft utility. Upon restart, the auto_parms
script will start dhcpclient in maintenance mode (running as a daemon) to handle lease renewal.

You can transform an HP-UX system configuration with a static IP address into a DHCP cli-
ent using System Administration Manager (SAM). Set Networking and Communications
→Network Interface Cards. Select the card on which you want to enable DHCP and then
choose Actions→Configure from the pull-down menu. Single-click the DHCP button,
asas shown in Figure 7-2. Statically defined networking values will be overwritten if the system
successfully obtains a lease from the DHCP server. If obtaining a lease is unsuccessful, the
original networking values will be retained.

You can also edit the /etc/rc.config/dnetconf file to set a DHCP client. Change the
value of the DHCP_ENABLE value to 1, and reboot the system. Whatever method you
use, if obtaining a lease is successful, change the values of the appropriate variables found
in /etc/rc.config/dnetconf.

# 7.1.2.1 The HP-UX DHCP Client and DDNS

The current HP-UX DHCP client does not support Option 81, the FQDN option, in any of its
messages. Therefore, a Windows 2000 DHCP server is unable to register an HP-UX client's
FQDN with DNS. Future versions of HP-UX 11, however, will have DHCP clients sending
Option 12, the Host Name option, in its messages, Windows 2000 DHCP servers can use Option
12 to register identity with DDNS.
