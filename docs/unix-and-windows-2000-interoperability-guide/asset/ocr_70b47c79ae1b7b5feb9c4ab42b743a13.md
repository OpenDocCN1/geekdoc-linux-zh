Hard disk systems are formatted areas that can encompass one or more entire disks, a
single partition on a single disk, a single partition spanning more than one disk, or a collection
of small units that collectively form a logical partition. These file systems are the physical contain-\ers files. To access these, the entire file system must be attached, or mounted, to a direc-\ory in the root partition. If there is a single file system for a single hard disk in a system,
then the contents of the file system are mounted to the /directory. If there are multiple file
systems on one or more hard disks, then each of these file systems, once mounted, form physical
types of the virtual file system tree. In this way, UNIX avoids the use of drive letters in its
file tree, because each file system is mounted on a directory in the root partition, regardless
of its location, be a logical volume, partition, or remote file system.
