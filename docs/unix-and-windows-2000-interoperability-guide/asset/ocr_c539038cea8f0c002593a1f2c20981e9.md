9-8 Enabling Tftp using SAM.

If you want to give remote systems permissions to retrieve a file through Tftp, the file must be readable by the tftp user. If you want to give remote systems permissions to transmit a file through your system Tftp, the file must already exist and be writable by the tftp user.

# 9.4.2 Running Tftp

The syntax of the Windows 2000 Tftp client is
```tftp [-i] host [get | put] source [destination]```

This client does not have an interactive mode. Therefore, you must specify whether you are performing a get or put operation and the file you want to transfer.(The get or put parameters are required, optional.) The destination parameter is required if there is a subdirectory of the tftp directory on the server involved. The -i option specifies binary image transfer. The default is ASCH mode, which takes care of end-line character transformations on text files.

# 9.5 Rsh and Rcp

The Windows 2000 utilities Rsh and Rcp execute commands on remote systems either using rsh or remsh. On HP-UX, rsh is not the same command as that found on other UNIX systems and Windows 2000; it runs a restricted shell. Remsh is the same service as rsh on BSD systems.
