# Network-Attached Storage

The file server components include data movers and at least one control station. The data movers run a small operating system called Data Access in Real Time (DART), while the control station runs a form of UNIX. The control station is used to configure the file server and provide management services. It plays no role in the actual delivery of data across the network. Each data mover runs DART and has an IP address for every interface it contains, as well as an IP address for each port in multiport NICs. You can also configure an Ethernet channel on multiport NICs, combining each port into a single trunk with a single IP address.
