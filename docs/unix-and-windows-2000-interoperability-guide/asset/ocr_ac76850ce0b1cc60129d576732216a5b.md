5. Before starting the Samba daemons, add your CIFS/9000 system to the Windows 2000 domain:

+   Go into Active Directory Users and Computers, select your domain, and then select Action→New→Computer. You will get the New Object-Computer window, as shown in Figure 12-1. Fill in the necessary information, check the Allow pre-Windows 2000 computers to use this account, and then click on OK.
