**Figure 3–2** A conceptual view of SAN. Multiple servers can connect to high-capacity disk arrays using components like those used in networking. A popular way of connecting all these devices is through Fiber Channel technology running on fiber-optic cable. SANs and the use of network-attached storage will play an increasingly important role in operating system interoperability.

NAS is currently based on specialized file servers hooked up to a storage array. These servers do nothing but share the volumes of the array (again using NFS, CIFS, or both) by connecting to a network using the currently popular technologies of Ethernet (from 10 Mbps to 1 Gbps), Fiber Distributed Data Interface (FDDI), and Asynchronous Transfer Mode (ATM). Fibre Channel can play an important role here as well, as shown in Figure 3–3. This figure shows a file server running EMC’s Multiplex File System (MPFS). Clients can connect to the file server using only the network via NFS or CIFS, or they can use both the network and a channel connection. In the latter, the client accesses a file’s metadata over the network, but gets the actual data over a SCSI or Fibre Channel.
