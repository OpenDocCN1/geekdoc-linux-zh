These parameters are similar to those of the standard Telnet client. If you type SET NTLM at the Telnet prompt, you will be authenticated by NTLM. If you are connecting to a Windows 2000 Telnet Server, you will not be prompted for a password. Even if you are using PAM NTLM on HP-UX, however, you will be prompted for a user name and password because the HP-UX Telnet Server does not recognize the NTLM option. Your default terminal type with this client is VT100, usually just fine for connecting to UNIX systems. If you will be connecting to Windows 2000 Telnet Servers and plan to use applications as EDIT, then you will set your terminal type to VTNT. In my tests using this Telnet client with HP-UX or Solaris Telnet servers, there will be no need to change the line feed mode.
