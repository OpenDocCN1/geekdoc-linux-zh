If the remote system does not acknowledge the keep-alive packet, TCP will use one of the following retransmission timers and terminate the connection when it elapses:

| State | Timer | Default |
| --- | --- | --- |
| Established connection | tcp_ip_abort_interval | 60000 ms (10 minutes) |
| Connection establishment | tcp_ip_abort_cinterval | 240000 ms (4 minutes) |
| Connection termination | tcp_keepalive_detached_interval | 240000 ms (4 minutes) |

# 5.1.1.4 TCP-Time Wait Delay

By default, Windows 2000 maintains a socket pair for 240 seconds (four minutes) after the connection closes. To change this value, you edit the following Registry entry:
HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\ParametersTcpWaitDelay

The value of this parameter can be anywhere from 30 to 300 seconds.
H-UX, by default, maintains a time interval of 60 seconds for TCP endpoints to persist in a Time-Wait Delay. This value can be changed using the ndd -set /dev/tcp tcp_time_wait_interval command. This command's argument is specified in milliseconds, ranging from 100 milliseconds to 600,000 milliseconds.

# 5.1.2 Windows 2000-Only Tunable Parameters

Windows 2000 allows tuning of TCP using the Registry for which there are no HP-UX equivalents. Following is a list of some of these Registry entries. See the Registry Reference for more information.

+   **TcpDelAcks.** Changes the ACK timer. The default is 200 milliseconds.
**SacOpts.** Enables/disables selective acknowledgments (SACKs). The default is enabled.
**TcpMaxDataRetransmissions.** Determines how many times TCP retransmits an unacknow data segment on an existing connection. TCP retransmits data segments until they are acknowledged, or until this value expires. The default is five.
**TcpMaxConnectRetransmissions.** Determines how many times TCP retransmits an unanswered request for a new connection. TCP retransmits new connection requests until they are answered, or until this value expires. The default is two.
**TcpMaxDupAcks.** Specifies how many duplicate ACKs (ACKs for the same sequence numbers) constitute a signal to retransmit a segment. The default is two.
