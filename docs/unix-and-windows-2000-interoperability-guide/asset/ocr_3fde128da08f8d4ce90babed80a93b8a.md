# 6.1.4 DNS Name Registration

Microsoft’s DNS and recent versions of BIND now support dynamic updates of the DNS database. Traditionally, DNS entries have been updated manually. But now you have in, in effect, a form of name registration that has long been a feature of WINS. We will come back to this topic later in this chapter.
