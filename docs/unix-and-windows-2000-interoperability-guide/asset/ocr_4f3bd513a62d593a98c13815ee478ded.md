Though not fully scriptable, the Windows 2000 command interpreter supports batch commands, including if and for. For more information, see the Windows 2000 Command Reference Main Page in the Help utility.

Windows 2000 is not case sensitive when you enter commands. If you type DIR at a command prompt, you will get a directory listing. You will get the same thing if you type dir. However, Windows 2000 is case retaining. In other words, if you were to type mkdir BoB at the prompt and then do a directory listing, you would see a directory named BoB. If you were to change your directory to BoB by typing cd BoB, your command prompt would show C:\BoB\. Therefore, Windows 2000 retains the case of a file or directory name for display purposes only.

As in UNIX, you must be aware of what your PATH variable is set to. If, for example, the following command is not in your command path, you will see something like:

```
C:\>QTW_203.EXE
```

'QTW_203.EXE' is not recognized as an internal or external command, operable program or batch file.

You can set the PATH variable by right clicking on My Computer, selecting Properties, clicking on the Advanced tab, and selecting the Environmental Variables button. The PATH variable is found in the System Variables box. See Figure 2–3.
