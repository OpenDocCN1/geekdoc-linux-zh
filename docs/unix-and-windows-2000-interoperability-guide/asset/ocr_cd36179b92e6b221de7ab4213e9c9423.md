# 4.2.2.2 HP-UX

You may have to do more to see similar information on an HP-UX system. To see the host name of a system, use the `hostname` command:

```
# hostname
hpu1
```

To see the physical address of your NIC, use the `lanscan` command. Please note that `lanscan` is unique to HP-UX.

# lanscan
| Hardware Station Crd Hdw Net-Interface NM MAC HP-DLPI DLPI |
| Path Address In# State NamePPA ID Type Support Mjr# |
| 2/0/2 0x08000938331B1 UP lan0 snap0 1 ETHER YES 119 |

To get the IP address, network, and broadcast address for an interface, use the `ifconfig` command. Remember that `lan0` is the default name of the NIC local interface, indicating that the encapsulation method is DIX Ethernet.

```
# ifconfig lan0
lan0: flags=843<UP,BROADCAST,RUNNING,MULTICAST>\inet 10.0.0.4 netmask ff000000 broadcast 10.255.255.255
```

To get additional information, such as whether the DHCP client is enabled and what your DNS configuration is, run SAM and select `Networking and Communications` from the main menu.
