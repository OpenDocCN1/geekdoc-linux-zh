# 4.2.3 Viewing the Route Table

4.2.3.1 Windows 2000

In Windows 2000, use either the route print command or the netstat -r command. For example,

```
C:\>route print
```

0x1 ........................................................ 
0x2 ... 00 08 00 a0 36 f7 ....... ....... LAN/Fax/Modem PCMCIA Card
==========================================================================================
