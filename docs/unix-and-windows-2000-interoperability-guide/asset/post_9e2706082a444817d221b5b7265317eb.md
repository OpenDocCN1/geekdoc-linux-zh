In the second case, IP will discard datagrams not addressed to the local host unless the local host is configured to be a router. In the former, IP sends routing error messages to the upper protocols. In the latter, it sends them in the form of Internet Control Message Protocol (ICMP) messages to the sending host.

The routing algorithms for Windows 2000 and HP-UX are nearly the same. In both systems, IP performs a bit-wise AND between the netmask in the routing entry and IP datagram's destination address and then compares it with the address in the entry. If they match, IP selects the route. If there is more than one route selected as a result of this process, IP selects the route with the longest netmask. This results in a more specific route because the longer netmask, the narrower range of IP addresses. With Windows 2000, if more than one route matches at this point, IP selects the route with the lowest metric. If there is still more than one, IP randomly selects the route.

The default route is the least specific route and is selected only if there is none more specific. If the chosen route's gateway is the same address as the interface, the destination is local and IP sends the datagram directly. If the route's gateway is not the same as the interface, IP forwards the datagram to the gateway.

Using the routing table, IP on HP-UX takes the following actions:

- 1. Look for a matching complete-destination IP address. With the network and with the host ID. If the G flag set, IP forwards the datagram to the next-hop router. If the H flag is set, IP sends the datagram directly to a system on the local network.

- 2. Find an entry that matches the network ID. If found, IP sends the datagram either to the next-hop router or the locally attached system. Again, IP checks for the appropriate flag for this.

- 3. Use the default route, appropriately labeled "default." IP sends the datagram to the next-hop router.

### 4.2.5.2 HP-UX

Both default and persistent routes are normally set in startup files. You can use SAM and set_params to configure a default gateway, or you can issue the following command:

```
# /usr/sbin/route add default gateway_address 1
```

The gateway_address argument is the IP address of the gateway host. Then, set the following environment variables in the /etc/rc.config dnetconf file:

```
ROUTE_DESTINATION []="default"
ROUTE_GATEWAY []="gateway_address"
ROUTE_COUNT []="1"
```

If the default gateway is your own host, the destination is local and IP sends the datagram directly. If the route's gateway is not the same as the interface, IP forwards the datagram to the gateway.

To set up additional routes, type the following:

```
# /usr/sbin/route add network gateway_address
```

Then, create a new set of variables in the /etc/rc.config dnetconf for each route:

```
ROUTE_DESTINATION []="default"
ROUTE_GATEWAY []="gateway_address"
ROUTE_COUNT []="1"
```

## 4.2.7 ICMP Redirects

Both 2000 and HP-UX support ICMP redirects. For both systems, the ICMP redirect must come from the local gateway. For Windows 2000, the lifetime is 10 minutes. For HP-UX, this is five minutes. To set a different value for HP-UX, use the following:

```
# nd -set /dev/ip ip_redirect_interval 600
```

### 4.2.8.2 HP-UX

HP-UX implements ICMP router discovery on clients via rdp, the router discovery daemon, preferably calling it the Router Discovery Protocol (RDP). RDP on client works the same as ICMP router discovery on Windows 2000. Clients listen for router advertisements over the all-multicast address of 224.0.1 or the NIC's broadcast address. The client also sends solicitations to the all-routers multicast address of 224.0.2.

You can start rdp either by setting the RDP variable in /etc/rc.config/netconf to 1 and reboot (or restarting the /sbin/init.d start command) or by configuring gated. Gated is a router daemon that handles multiple routing protocols, including Routing Information Protocol (RIP), Border Gateway Protocol (BGP), External Gateway Protocol (EGP), the Hello Protocol (HELLO), Shortest Path First (OSPF), and RDP. To configure gated, edit the /etc/gated.conf file and change the GATED variable in /etc/rc.config/netconf 1.

Do not however, start RDP using both methods.
