## 10.3.1 Background

Windows Services for UNIX includes software called NIS Server. So what is NIS? NIS is Network Information Services, developed by Sun Microsystems in the 1980s to centralize data in UNIX groups. As long as UNIX systems worked like mainframe systems, that, serving multiple users from terminals, there was no need for something like NIS. But with the advent of the UNIX workstation in the 1980s, you suddenly had multiple users of multiple systems. Each system had its own database, its own hosts file, its own services file. For a subgroup of such systems to function properly, administrators had to ensure that each machine had identical versions of each of the configuration files. Even a small subgroup of, say, 10 machines, made administration cumbersome. But as groups expanded in size, it became ever more likely that a few systems would not be “sync” with the others.

NIS attempts to avoid this problem by providing uniform configuration information to all systems in the network.
