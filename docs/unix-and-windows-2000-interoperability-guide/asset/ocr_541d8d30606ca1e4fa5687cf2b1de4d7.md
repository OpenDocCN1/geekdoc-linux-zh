The startup script /sbin/init.d/net runs a couple of the commands you would use on the command line: ifconfig route. the ifconfig command sets the IP address, subnet mask, and localback interface; route configures the routing table. You don't edit the /sbin/init.d/net script; rather, you change the value of variables found in /etc/rc.config.d/netconf. These values include:

```
HOSTNAME
LOOPBACK_ADDRESS
INTERFACE_NAME[0]
IP_ADDRESS[0]
SUBNET_MASK
BROADCAST_ADDRESS
INTERFACE_STATE[0]
CP_ENABLE[0]
ROUTE_DESTINATION[0]
ROUTE_GATEWAY[0]
ROUTE_COUNT[0]
```

The values of the variables become the arguments of the ifconfig and route commands that are run at system startup.

Because it is easy to make a mistake when editing files, it is usually best to use either SAM or set_parms to set the variables in /etc/rc.config.d/netconf. After starting SAM, select the Networking and Communications item from the main menu to configure your IP parameters. The set_parms command runs right after you install HP-UX, but you can run the script at any time. Running the set_parms ip_address command will set your IP address; set_parms add_network will set the subnet mask, default gateway, DNS name, DNS server, Network Information Service (NIS) domain name, and NIS server.

You can set your system to be a DHCP client with the set_parms initial command or by using SAM. If you set your system up as a DHCP client, do not make any changes to /etc/rc.config.d/net or set new parameters with set_parms. Doing so will most likely hose your system's connections.
