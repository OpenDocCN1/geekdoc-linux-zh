# 11.3.2.2 Permissions

Regular HP-UX file and directory permissions override any export permissions. Therefore, even if you export a file system as read-write, only users with the right HP-UX permissions actually read or write data on a mounted file system. You can also specify access permissions on the mount operation on the client side. If the mount permissions differ from the export permissions, the more restrictive permissions take precedence.

# 11.3.3 Using Client for NFS

After you install Client for NFS, you get a new folder in My Network Places called NFS Network. After you find this folder, double-click on My Network Places and then on Entire Network. In this folder is an icon called Default LAN, which represents all the NFS servers discovered via broadcast on the local segment. There is also an icon called Favorite LAN. You can add NFS servers from different segments to this folder, the idea being to add those that you use most frequently.

You can see what a particular NFS server is exporting by right-clicking on the icon representing that server and selecting Properties. You will get a window similar to the one shown in Figure 11–5.
