# 11.2.1 Local File Systems and NFS

Between UNIX (including UNIX clones) and Windows 2000, there are a number of different file systems in existence. HP-UX has Hierarchical File System (HFS) and NTFS. Solaris has UFS. Linux has ext2. Windows 2000 has File Allocation Table (FAT), FAT32, and NTFS. Practically all operating systems support CD-ROM File System (CDFS). However, NFS was designed after UNIX file system semantics. All UNIX file systems store information about each file, the metadata, in inodes. Instead of inodes, NFS manipulates nodes, which contain similar information, such as the UID of the owner of the file, the GID associated with the file, and the permission bits. Other file systems, such as FAT and NTFS, have different structures. To, accommodate different file systems, NFS employs a file system interface as the Virtual File System (VFS)/Virtual File Node (VNODE), which separates the file system interface from the specific file system implementation. While the VFS interface works, some NFS operations, such symlink(), which creates a symbolic link to a file on a remote host, do not work—for example, if the remote file system is FAT. Also, since NTFS file attributes differ from those in UNIX file systems, there must be some mechanism to map these attributes.

# 11.2.1 NTFS, FAT, and CDFS

FAT and CDFS do not provide any security mechanism. CD-ROM file systems are readonly. To make FAT file systems writable over NFS, you must grant read/write access when mounting the file system. FAT file systems also have no concept of file ownership. Therefore, if you grant read/write access to a FAT file system exported by NFS, all users have full access to the file system. The only way to protect your exported FAT file system is to mount it as readonly.

# 11.2.2 NTFS

File and directory permissions differ between UNIX systems and NTFS. For example, UNIX does not have the Take Ownership permission. Somehow, NTFS permissions on a Server for NFS resource need to be mapped in such a way that the UNIX client can understand them. Fortunately, NFS handles this transparently.
