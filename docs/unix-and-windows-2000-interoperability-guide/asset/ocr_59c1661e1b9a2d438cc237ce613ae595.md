With what I have described so far, we have two home directories for users: one defined in the
user’s UNIX Attributes and residing on an HP-UX system, and another as yet undefined but
defaulting to the root directory of the Windows 2000 system they are logging onto. If you want
unify your home directories, specify the appropriate CIFS/9000 share in the Profile page of
Active Directory Users and Computers, as shown in Figure 12–3. When the dylan users logs on,
there will be a Z: drive pointing to to his home directory on the CIFS/9000 server. Also, when he
opens a command prompt, it will open to this share.
