# Windows 2000 NFS Server/HP-UX Client

+   1. Open Windows Explorer.
2. On the Tools menu, click on Map Network Drive.
3. In the Drive list, click on the drive letter to use.
4. To locate the NFS share, click Browse, or, in Folder, type the path to the share. You can specify the path as:
   serverName:/path
   (for example: goldbug:/po/stories),
   or as:
   serverName\path
   (for example: goldbug\po\stories).
5. To connect using a different user name or password, click on Connecting using a different user name, type the user name and password, and then click on OK.

Microsoft recommends that you use the serverName:/path syntax when connecting to an NFS resource. The other format searches for Windows NT file systems with this name first, and then searches for NFS resources, slowing connection time.

When you attempt to connect, you will get a message similar to that in Figure 11–7.

This is confirming the UID and GID supplied by the User Mapping Service. If you do not want these credentials, select No in the window and then click on Connect using a different user name, type the user name and password, and then click on OK.
