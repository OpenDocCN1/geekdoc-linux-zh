# 7.2.14 HP-UX DNS Server and Windows 2000 DHCP Server

If you run BIND version 8.1.2 or higher on HP-UX 11, you can also have a Windows 2000 DHCP server perform update requests on behalf of Windows 2000 clients successfully. Remember that on Windows 2000, you must deselect the Register connection's addresses in DNS box on the Advanced TCP/IP settings (See Figure 7–1). Also, you must select the Automatically update DHCP client information in DNS and the Always update DNS options in the DHCP management console, as shown in Figure 7–4. Finally, for non-Windows 2000 DHCP clients, you need to select Enable updates for DNS clients that do not support dynamic update. In my experiment, I managed to get the Windows 2000 DHCP server to update the records of an AIX system.
