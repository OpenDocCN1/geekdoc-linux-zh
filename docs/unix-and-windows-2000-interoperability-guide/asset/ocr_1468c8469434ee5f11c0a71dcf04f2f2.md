# 4.1.2.2 HP-UX

HP-UX requires that you provide the host name of the entry to be deleted, not the IP address, as in Windows 2000.

```
# arp -d w2kserv.book.local
w2kserv.book.local (10.10.1.1) deleted
```

# 4.1.3 Adding a Static Entry to the ARP Cache

# 4.1.3.1 Windows 2000

In Windows 2000, use the arp -s command. You must supply both the IP address and the hard-ware address.

```
C:\arp -a
```

| Interface: 10.0.0.3 on Interface 0x2 |
| Internet Address | Physical Address | Type |
| 10.10.1.1 | 00-60-b0-6a-8e-9c | dynamic |

```
C:\arp -s 10.10.1.1 00-60-b0-6a-8e-9c
```

```
C:\arp -a
```

| Interface: 10.0.0.3 on Interface 0x2 |
| Internet Address | Physical Address | Type |
| 10.10.1.1 | 00-60-b0-6a-8e-9c | static |

# 4.1.3.2 HP-UX

HP-UX also has the arp -s command.

```
# arp -s w2kserv.book.local 00:60:b0:6a:8e:9c
# arp -a
w2kserv.book.local (10.10.1.1) at 00:60:b0:6a:8e:9c permanent
houyhnhnm.book.local (10.0.0.3) at 8:0:a0:36:f7 ether
aix1.book.local (10.0.0.5) at 8:0:5a:d8:1e:a9 ether
```

Note that static entries in HP-UX are noted as permanent.
