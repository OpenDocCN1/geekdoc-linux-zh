# UDP

tcp_conn_request_max. Maximum number of outstanding inbound connection requests.
Default is 20 connections.

tcp_ip_notify_interval. First threshold timer during connection establishment. Default is 10,000 (10 seconds).

tcp_ip_notify_interval. First threshold timer for established connections. Default is 10,000 (10 seconds).

tcp_ip_ttl. Time-to-live (TTL) value inserted into IP header for TCP packets. Default is 64.

tcp_largest_anon_port. Largest port number to use. Default is 65,535.

tcp_remxit_interval_initial. Initial value for round trip time-out, from which the retransmit time-out is calculated. Default is 500ms.

tcp_remxit_interval_initial_inp. Same as tcp_remxit_interval_initial, but used for devices with the LNP flag. Default is 1,500 (1.5 seconds).

tcp_remxit_interval_max. Upper limit for round trip time-out. Default is 60,000 (1 minute).

tcp_remxit_interval_min. Lower limit for round trip time-out. Default is 500.

tcp_sth_rcv_hiwat. If nonzero, sets the Stream-flow control high water mark. Default is 0.

tcp_sth_rcv_lowat. If nonzero, sets the Stream-flow control low water mark. Default is 0.

tcp_syn_rcvd_max. Controls the SYN attack defense of TCP. The value specifies the maximum number of suspect connections that will be allowed to persist in SYN_RCVD state. Default is 500 connections.

tcp_status. Obtains a complete report similar to netstat -an on all TCP instances.

tcp_xmit_hiwat_def. The amount of unsent data that triggers write-side flow control. Default is 32,768 bytes.

tcp_xmit_hiwat_lfp. The amount of unsent data that triggers write-side flow control for fast links. Default is 65,536 bytes.

tcp_xmit_hiwat_inp. The amount of unsent data that triggers write-side flow control for slow links. Default is 8,192 bytes.

tcp_xmit_lowat_def. The amount of unsent data that relieves write-side flow control. Default is 8,192 bytes.

tcp_xmit_lowat_lfp. The amount of unsent data that triggers write-side flow control for fast links. Default is 65,536 bytes.

tcp_xmit_lowat_inp. The amount of unsent data that triggers write-side flow control for slow links. Default is 8,192 bytes.

# 5.2 UDP

A number of prominent applications on both UNIX and Windows 2000 systems use User Data-gram Protocol. These applications include Trivial File Transfer Protocol (Tftp), Simple Network Management Protocol (SNMP), and DNS. On the UNIX side, NFS has used UDP as its transport mechanism, though TCP is becoming more popular to enable file sharing over WANs.
