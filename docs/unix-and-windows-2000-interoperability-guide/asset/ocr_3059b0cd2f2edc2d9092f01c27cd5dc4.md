# Chapter 13 Miscellaneous Interoperability Topics

Once you select a system, the remote system displays the login screen as if you were seated at that workstation. In the case of HP-UX systems, the dtlogin process will display the login screen, as shown in Figure 13–5. Notice that the entire login screen displays in a Microsoft Windows. Once you log in, you get the same look and feel of your HP-UX system, though you may have to install additional HP fonts along with your X server software to get precisely the same. Alternatively, you can use an HP-UX system as a font server. You can then toggle between both HP-UX and Windows 2000, using the Taskbar and/or the ALT-TAB keyboard sequence.

**Figure 13–5** The CDE login screen provided by XDMCP. Note the Windows 2000 Taskbar at the bottom of the window.

Windows desktops are the rule in the business world and are gradually taking over those of scientific and engineering environments. Often in the past, the latter would see two workstations on a user’s desk—a UNIX system for high-end work and a Windows system for documentation, email, and personal productivity applications.
