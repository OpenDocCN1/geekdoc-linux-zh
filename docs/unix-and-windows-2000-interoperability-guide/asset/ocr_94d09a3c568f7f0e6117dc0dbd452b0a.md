```
#
# PAM configuration
#
# Authentication management
#
login auth required /usr/lib/security/libpam_unix.1
 auth required /usr/lib/security/libpam_unix.1
dtlogin auth required /usr/lib/security/libpam_ntm.1
dtaction auth required /usr/lib/security/libpam_ntm.1
ftp auth required /usr/lib/security/libpam_unix.1
OTHER auth required /usr/lib/security/libpam_unix.1
#
# Account management
#
login account required /usr/lib/security/libpam_unix.1
s account required /usr/lib/security/libpam_unix.1
dtlogin account required /usr/lib/security/libpam_ntm.1
dtaction account required /usr/lib/security/libpam_ntm.1
ftp account required /usr/lib/security/libpam_unix.1
OTHER account required /usr/lib/security/libpam_unix.1
#
# Session management
#
login session required /usr/lib/security/libpam_unix.1
dtlogin session required /usr/lib/security/libpam_unix.1
dtaction session required /usr/lib/security/libpam_unix.1
OTHER session required /usr/lib/security/libpam_unix.1
#
# Password management
#
login password required /usr/lib/security/libpam_unix.1
passwd password required /usr/lib/security/libpam_ntm.1
dtlogin password required /usr/lib/security/libpam_ntm.1
dtaction password required /usr/lib/security/libpam_ntm.1
OTHER password required /usr/lib/security/libpam_unix.1
```

Exactly how you configure PAM NTLM is up to you, but you need to be careful or you might not be able to log in at all. It is best to configure it incrementally; that is, specify NTLM for CDE logins and actions only, make sure they work, and then configure login and password.

In Chapter 8, we also described PAM Kerberos. Consult that chapter for more detailed information. As you might recall, PAM Kerberos is a little trickier.
