## 13.1 Network-Attached Storage

Since file sharing is such an important goal in UNIX and Windows interoperability, we must take a look at the concept of NAS. NAS is disk storage accessible via networking technologies such as Ethernet, Gigabit Ethernet, and ATM, rather than channel technologies like SCSI and Fibre Channel. Unrestricted by distance and connectivity NAS makes it possible for large numbers of clients to access files anywhere on the network. NAS is achieved by connecting a file server running a stripped-down operating system optimized for network I/O to some kind of storage. This operating system does nothing but serve files over network. It does not run other services like Dynamic Host Configuration Protocol (DHCP), Domain Name System (DNS), Windows Internet Name Service (WINS), or Network Information Service (NIS). Therefore, fast performance is a prominent NAS.

EMC Corporation was the first to coin the term network-attached storage, but Auspex was the first to actually implement the concept. Today, the leading vendors of NAS are EMC and Network Appliance. Both companies provide NAS for UNIX (via NFS), Windows (CIFS), and mixed environments. The goal for these and other vendors is to provide NAS that is easy to integrate in mixed environments, easy to manage, performs well, and is always available.

### 13.1.1 An NAS Example

To illustrate the NAS concept, let's look at the EMC Celerra file server. There are two components to the Celerra: the file server itself and the storage. The storage consists of a disk array called the Symmetric, either contained in the same cabinet as the file server or existing in a separate cabinet. The file server connects to the disk array either over a SCSI or Fibre Channel connection. It connects to the network via 10/100BaseT Ethernet, Gigabit Ethernet, Fiber Distributed Data Interface (FDDI), or Asynchronous Transfer Mode (ATM). Clients connect to the file server over the network via NFS or CIFS. Figure 13–1 illustrates these components.
