# 9.5.1 Running Rsh

The syntax of the Rsh command on Windows 2000 is

```
rsh host [-l user_name] [-n] command
```

The host parameter is the system actually running the command you specify. I hope it is obvious that the command needs to be an HP-UX command in my examples. The -l option specifies the user name to be used on the remote host. If you omit this parameter, the logged-on user's name is used. However, in my tests I've found that you must be very careful. You must ensure that both the HP-UX and Windows 2000 account names are the same case. Yes, it is true that you can log on to Windows 2000 without being case-specific. However, if you have a Windows 2000 account called Dylan, you must have an equivalent account called Dylan (or dylan) on the HP-UX system. The reason is that Rsh will pass the mixed-case user name to the remshd on HP-UX. The command will not work unless the account names match case or you supply the properly c name with the -l option.

By default, Rsh reads its standard input and sends it to the remote command. The -n option redirects the input of Rsh to NULL (never-land), useful when running a shell script connecting the Rsh command, since Rsh may use input not intended for it. If you use redirection symbols (>,>>) you must quote them if you want redirection to occur on the remote computer. Otherwise, redirection will take place locally.

# 9.5.2 Examples

Find out when the last system boot took place on hpux.

```
D:\>rsh hpux -l dylan -b
   system boot Oct 24 18:39
```

Notice that I'm specifying the user dylan here. You must specify a user that the remote HP-UX system recognizes. If you don't specify a user, then your Windows 2000 user name must match an HP-UX account exactly. Since my HP-UX system does not know anything about a user named bob, the following command does not work:

```
D:\>rsh hpux -l bob -b
hpux1.book.local: remshd: Login incorrect.
rsh: can't establish connection
```

Find out the end of all files that end in .log on the HP-UX system:

```
D:\>rsh hpux -l dylan find / -name "*.log"
find: cannot open /etc/sam/custom
find: cannot open /etc/lvmcmf
find: cannot search /etc/ftpd
find: cannot open /var/opt/dce/security/preauth
find: cannot open /var/adm/sw/queue
find: cannot open /var/adm/sw/products
```
