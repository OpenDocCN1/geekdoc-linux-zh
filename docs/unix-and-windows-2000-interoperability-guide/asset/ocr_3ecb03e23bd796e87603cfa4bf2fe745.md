You can also see commands using the Windows 2000 Command Reference, accessible through the Help utility. To get to the Command Reference, Start→Help, choose the Contents tab, click on Troubleshooting and Additional Resources, and the select Additional Resources.

# 2.3.6  Directory Tree

Though Windows 2000 is an entirely different operating system than DOS, it has inherited many of its characteristics, including a directory structure that has a letter at the root level. Unlike UNIX, there is no single root directory; there are, in fact, many root directories, 24 altogether (represented by the letters C–Z). This drive scheme also goes back to the days when PCs did not have hard drives, only floppies. Typically, a system had two floppy drives, one labeled A: and one labeled B:. You usually loaded your application, such as WordStar, from a floppy in drive A and kept your data files on the floppy in drive B. When hard disks begin to show up on these systems, did not replace the A and B floppy drives. Therefore, the hard disk became the C: drive. The A and B letters are still reserved for floppies. Commonly found directories include

**Documents and Settings.** This directory contains data and settings on the local computer. However, because of Microsoft's Intelli technology, both of these items can exist elsewhere on the network.

**Program Files.** This contains applications installed on the local system. However, you can put applications on any drive and in any directory.

**The value of the %SystemRoot% variable.** This is the directory that contains the Windows 2000 system files. You specify this location when you install the operating system; otherwise, the directory will be \WINNT.

# 2.3.7  File System Format

Windows 2000 supports the NTFS and two file allocation table (FAT) file systems: FAT16 and FAT32. The latter are available available to allow dual booting of systems. However, the real workhorse of Windows 2000 file systems is NTFS. This file system offers a number of features and benefits and it is the only one you should consider if you are not dual booting and managing a network of more than just a few machines. Features of NTFS include the following:

**File and folder-level security.** You can apply permissions on both files and directories, much like you do in UNIX.

**Disk compression.** You can set an NTFS volume to be compressed to save disk space. Not all NTFS volumes have to be in a compressed state, however.

**Disk quotas.** UNIX file systems have long supported quotas to keep a few users from eating most of a group's disk space. Windows 2000 NTFS allows you to do the same. You can set quotas for all users or for individuals.
