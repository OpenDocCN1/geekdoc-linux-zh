One of the more important networking applications that runs on NetBIOS is the Server Message Block (SMB) protocol. SMB enables network file and print sharing and messaging among Windows-based systems. It was a part of LAN Manager and has since evolved into the Common Internet File System (CIFS). We will look more closely at NetBIOS, SMB, and CIFS later in this book.
