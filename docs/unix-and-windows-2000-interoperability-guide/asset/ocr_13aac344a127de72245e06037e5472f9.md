# Windows Services for UNIX

Microsoft provides an optional product called Windows Services for UNIX (SFU) to facilitate the interoperability of Windows and UNIX systems. Although version 2.0 of this product was released to support Windows 2000 systems, it can be installed on Windows NT 4 with Service Pack 4 or higher. SFU can work with Solaris 2.6 and above, HP-UX 10.20 and above. Tru64 UNIX 5.0 and above, and Red Hat Linux 5.1 and above. SFU includes the following-default components:

+   * Telnet Client and Server. The Server provides access to Windows 2000 systems via Telnet. The Telnet client provided with SFU has a bit more functionality than bundled with the operating system.
* Server for NIS. NIS (Network Information Services) has been widely used in the UNIX world to provide commonly used information over the network. Server for NIS turns a Windows 2000 Server into an Active Directory-enabled NIS server.
* Password Synchronization. Password Synchronization provides users with the ability to change account passwords from one platform and have a corresponding change place on the other.
* Korn Shell and UNIX Utilities. The Korn Shell is a command-line interpreter available on all UNIX systems and is now available for Windows 2000. It contains a number of built-in commands and is supplemented by commonly used UNIX utilities, such as *grep* and *vi*.
* Server for NFS. Server for NFS (Network File System) enables a Windows 2000 system to share its files with UNIX systems.
* Client for NFS. Client for NFS lets a Windows 2000 system access files on a UNIX system.
* Gateway for NFS. Gateway for NFS lets a Windows 2000 system mount UNIX file systems and then share them as if they were Windows shares.
