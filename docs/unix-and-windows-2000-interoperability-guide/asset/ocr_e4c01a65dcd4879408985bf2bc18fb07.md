# 11.4.2.2 Automatic Mounts (Autounts)

Automatic mounts, generally referred to as automounts, occur only when you access an exported directory and stay in effect while in use. After a period of inactivity, usually five minutes, the mount goes away. For a long time, the Automounter utility enabled automounts. More recently, a new utility called AutoFS improves on the old Automounter. For one thing, it can mount directories using NFS protocol version 3, as well as version 2. Automounter used only in version 2 the old Automounter created mounts using the /tmp_mnt directory and make symbolic links to the actual mount points, often confusing users. With AutoFS, the configured mount points and the actual mount points are the same. HP-UX 11 by default employs Automount, but you can migrate to AutoFS easily.

Configuring either Automounter or AutoFS can get very complex, and for more information, consider HP's Configuring and Administering NFS. One thing that makes it particularly confusing is the use of the term map. Both NIS and the automounter utility uses the term map, and you can integrate both NIS and automounter, you can use what is known as the -hosts automounter map. The -hosts map causes the utilities to mount all the exported directories from any NFS server on the network when someone accesses any of those exported directories. To do this, you may add the following line to the automounter map file:

```
/net -hosts nosuid
```

Or, the automounter map file itself might be a NIS map! Hence confusion.
 tested the use of the -hosts automounter map and found that it works well. On my Windows 2000 NFS server, I exported (as described earlier in this chapter) a directory called music and a directory called home. I configured the /etc/auto_map file on hpux to include the line above, and started AutoFS with the /usr/sbin/automount command. I was able to change directories to the /net/w2kserv/music directory and then the /net/w2kserv/home directory on demand. Again, consult Configuring and Administering NFS for more information.
