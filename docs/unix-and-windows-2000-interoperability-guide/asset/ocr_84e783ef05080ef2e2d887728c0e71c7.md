**Figure 9–4** Logging in as a User Other Than Anonymous. In this example, the user is logging in as dylan on an HP-UX FTP server.

In the window 9–4, if you check the **Save Password** box, then you can log in without typing a password. For example, if you log successfully as the *dylan* account on an HP-UX system and save your password, then you can go directly to the home directory (/home/dylan/) by simply typing the following in the **Address** box in Internet Explorer: `ftp://dylan@hpux1/`. Then you would see something like the window in Figure 9–5.

You can automate this process even further by adding the page displayed by the URL to your Favorites or Links folder.

Remember that if you use Windows 2000 Internet Explorer to connect to a UNIX FTP server, you will have trouble reading files you copy to your system. For example, in Figure 9–5 there is an icon called *boot.txt*. This file resides on *hpux1*, a UNIX system. You can copy it to your Windows 2000 box by dragging and dropping the icon to your Desktop. However, if you open the file with Notepad, you will see something like Figure 9–6. Notepad does not know what to do with the NL (new line) character that UNIX systems put at the end of a line. Windows-based systems denote the end of a line with the CR-LF (carriage return-feed) characters. However, if you open the file with either Wordpad or Word, these programs interpret UNIX-created text files with no problem.
