# Step Three: Disable the Old Master Server

10.3.3.3 On HP-UX, the easiest way to disable an NIS master is through SAM. Start SAM, select Networking and Communications, and then click on the NIS icon. You will get the NIS Configuration screen (see Figure 10–10). From the menu bar, choose Actions→Disable Server. To turn the system into an NIS client of the new master server (the Windows 2000 system), choose Actions→Disable Client and then Actions→Set Domain Name. Set the domain name to the new domain created during the migration process. In my case, I set the domain name to instead of book.local. Then, run Actions→Enable Client.
