4.2.1.2 HP-UX

You can do the following to configure IP on HP-UX:

+   1. Use the command line. Command-line changes are not permanent.
2. Edit system startup files. Changes you make to these files do not take effect until you reboot the system.
3. Use SAM. This will make changes to the system and ensure the proper entries are placed in the startup file.
4. Use the *set_parms* script.
