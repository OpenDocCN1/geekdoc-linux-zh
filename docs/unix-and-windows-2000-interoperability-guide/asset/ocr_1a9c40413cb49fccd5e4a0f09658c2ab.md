# 9.3.4 The HP-UX ftpd

HP-UX 11 has an ftppd different from that of previous releases of the operating system. The new ftppd supports logging of transfers, logging of commands, on-the-fly compression and archiving, classification of users on type and location, per-directory upload permissions, restricted guest accounts, systemwide and per-directory messages, directory aliases, cpath, virtual host support, and per-class limits. One of the most significant changes, as we will see is a new option: -K, which enforces Kerberos Authentication. For complete information on configuring ftppd on HP-UX 11, see the release notes at /usr/share/doc/RelNotes_newftp.txt.

Unlike the Windows 2000 FTP Server, HP-UX by default does not allow anonymous logins. The easiest way to set up anonymous FTP on HP-UX is to use SAM. From the main SAM screen, select Networking and Communications→Network Services. Select Anonymous FTP and then choose Actions→Enable from the menu bar, as shown in Figure 9–1.

This process will place anonymous FTP files in the /home/ftp directory. If you log in as anonymous or ftp, you will be placed in this directory and see the following subdirectories: dist, etc, pub, and usr.
