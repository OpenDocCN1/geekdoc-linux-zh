# Table 1–1 Important HP-UX Directories

| Directory | Contains |
| /bin | Essential command binaries for all users. In HP-UX this is a link to /usr/bin. |

| /dev | Device files. |
| /etc | Host-specific system and application configuration files. |
| /home | Default location for user home directories. |
| /lib | Essential shared libraries and kernel modules. In HP-UX this is a link to /usr/lib. |
| /opt | Optional applications. |
| /sbin | Commands and scripts essential to booting and shutting down a system. |
| /tmp | Temporary files. |
| /usr | The bulk of the operating system, including commands, libraries, and documentation. |
| /var | Multipurpose log, temporary, transient, variable-sized, and spool files. |

# 1.4.3.2 File System Formats

The term file system can also refer to a formatted area on some of media for the purpose of storing files. This media can be CD-ROMs, floppy disks, hard disks, or partitions of hard disks. There are many different system formats, but to a user, these formats are transparent, as long as the operating system knows how to access them. HP-UX recognizes the following file systems:

+   HFS, the High-Performance File System. The HFS physically resides on a mass storage device, usually on a hard disk. Earlier versions were known as the UNIX File System (UFS). NFS, the Network File System NFS is a remote file system accessed over a network. The local system treats NFS as local.
