The finger command will now work. However, many sites regard this command as a security risk (as does Hewlett-Packard, apparently, since it has chosen to disable fingered by default). Moreover, running this command on an HP-UX system to get information from Windows 2000 systems will fail because fingerd does not exist on those machines unless you have installed a version provided by a third party.

# 9.3 FTP

Because of the omnisence of the Internet days, FTP is widely known and spelled. In all caps, FTP refers to File Transfer Protocol. The user interface to this protocol is spelled FTP (in Windows documentation) or ftp (in UNIX). Using FTP, users copy (not really transfer) files from a server (server running ftp). On UNIX systems, FTP is available in both client and server versions, while on Windows 2000, you must do one of the following to run ftpd: (1) install Internet Information Services, (2) install Services for UNIX, or (3) install a third-party version. for both Windows 2000 and HP-UX, the FTP client supports a number of subcommands, that is, commands available at the <FTP> prompt. These subcommands are quite similar, yet running the FTP client itself differs.

# 9.3.1 Windows 2000

The syntax of the FTP command in Windows 2000 is

```
ftp [-v] [-n] [-i] [-d] [-g] [-s:filename] [-a] [-A] [-w:windowsize]
hostname
```

where

+   - -v suppresses the display of remote server responses. On HP-UX, this enables verbose output.
- -n suppresses autologon upon initial connection. This is the same on HP-UX.
- -i disables interactive prompting by multiple-file commands. This is the same on HP-UX.
- -d enables debugging. This option is not available on HP-UX.
- -g disables file name globbing (using wildcard characters). This is the same on HP-UX.
- -s:<filename> specifies a text file contain FTP commands, run automatically after FTP starts. This option is not available on HP-UX.
- -a specifies that any local interface can be used when binding the FTP data connection. Not available on HP-UX.
- -A logs in to the FTP server as anonymous. Not available in HP-UX
- -w:windowsize specifies the size of the transfer buffer. The default is 4096 bytes.

The hostname parameter is optional. If you specify a host, then FTP starts and immediately opens a connection to the target host. If you do not specify a host, you just get the <FTP> prompt. This prompt waits for you to issue subcommands.
