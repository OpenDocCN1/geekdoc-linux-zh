# 3.1.3 Network Interface Drivers

Ethernet, Token Ring, FDDI, Fibre Channel, and the like are standards—important, to say the least. For example, DIX Ethernet frames are of the same format for both UNIX and Windows 2000 systems. What this means is that the lower levels of internetworking are already taken care of you, provided we standardize on a particular technology. For example, you cannot expect to easily integrate your Ethernet-based Windows 2000 system into your existing Token Ring net-work of UNIX systems. You can, however, plug your Windows 2000 computer into a 10Base-T network with Ethernet-based UNIX systems and not have to buy special cabling or connecting hardware like hubs.
