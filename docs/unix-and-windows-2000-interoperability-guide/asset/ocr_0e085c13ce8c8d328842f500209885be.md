# 11.4.1 Configuring Server for NFS

You can configure and administer Server for NFS using either the SFU Administration tool or through various commands. We will concentrate on the administration tool, taking material directly from SFU Help.

# 11.4.1.1 Setting Up Authentication

After ensuring User Name Mapping and NFS Authentication are installed, you need to set up authentication. To set up authentication,

+   1. Open Windows Services for UNIX Administration.
2. If necessary, connect to the computer you want to manage.
3. Click Server for NFS.
4. In Computer Name, type the name of the computer running User Name Mapping that you want to use for authentication, and then click Apply. See Figure 11–8.
