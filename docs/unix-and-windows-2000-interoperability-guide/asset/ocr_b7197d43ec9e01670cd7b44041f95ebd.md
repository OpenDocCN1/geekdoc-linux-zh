# CIFS/9000 Client in a Windows 2000 Domain

# 12.5.2 Using the CIFS/9000 Client

Installing and Administering the CIFS/9000 Client provides instructions for installing the client. Once you do so, Hewlett-Packard recommends you use the value of only the domain variable in the configuration file, /etc/opt/cifsclient/cifsclient.cfg, unless you need to do any localization. In my test environment, I of course set the value accordingly:

```
domain = book.local
```

After that, you simply start the CIFS/9000 client daemon by issuing the following command as the root user:

```
# /opt/cifsclient/bin/cifsclient start
```

Once the daemon starts, you can mount shares. However, if you want the mount to take place every time the system restarts, then using the mount command. You should configure the /etc/fstab file like this:

```
/dev/dsk/ct6d0 /hfs defaults 0 1
w2kserv/home/pchome defaults 0 0
```

This shows that I have a file system (or share) on w2kserv called home that needs to be mounted on my local /home directory at system startup. After making this entry, I can issue the following command to mount all the shares specified in /etc/fstab

```
# mount -A cifs
```

Finally, I need to set the RUN_CIFSCLIENT variable in the /etc/rc.config.dcifsclient file:

```
RUN_CIFSCLIENT=1
```

So far, we have created the share home on w2kserv containing Full Control permissions for Everyone. We have also secured the dylan subdirectory (or subfolder) under NTFS permissions. We configured and started the CIFS/9000 client on hpux1. Then, as we mounted the share home to the local /pchome directory. In order to access the /pchome directory, each user must first be authenticated by w2kserv. Unless you use PAM NTLM to do your authentication (which we will discuss a little later), you must use the cifslogin command. Note the following series of commands:

```
$ id
uid=1004 (dylan) gid=1000 (tech)
$ cd /pchome
sh:/pchome: Permission denied.
$ cifslogin w2kserv
Remote user dylan's password:
$ cd /pchome
$ 11
total 0
ddrwxrwxwx 2 dylan tech 131072 Dec 28 2000 dylan
ddrwxrwxwx 2 dylan tech 131072 Dec 22 12:16 Hilary
$ cifslist -A
```
