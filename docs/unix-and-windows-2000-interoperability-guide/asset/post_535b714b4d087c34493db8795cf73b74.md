
## 9.3.2 HP-UX

The syntax of the FTP client on HP-UX is

``````
ftp [-g] [-i] [-n] [-v] [-B size] [server-host]
```

The -g, -i, and -n options are the same as those found in the Windows 2000 version of FTP. The -B option sets the buffer size of the data socket to a size in blocks of 1024 bytes. The number of blocks can be from 1 to 64, with 56 being the default. The default connection type is ASCII, though if you connect to another HP-UX system, FTP switches to binary connections.

## 9.3.4 The HP-UX ftpd

HP-UX 11 has an ftppd different from that of previous releases of the operating system. The new ftppd supports logging of transfers, logging of commands, on-the-fly compression and archiving, classification of users on type and location, per-directory upload permissions, restricted guest accounts, systemwide and per-directory messages, directory aliases, cpath, virtual host support, and per-class limits. One of the most significant changes, as we will see, is a new option: -K, which enforces Kerberos Authentication. For complete information on configuring ftppd on HP-UX 11, see the release notes at /usr/share/doc/RelNotes_newftp.txt.

Unlike the Windows 2000 FTP Server, HP-UX by default does not allow anonymous logins. The easiest way to set up anonymous FTP on HP-UX is to use SAM. From the main SAM screen, select Networking and Communications→Network Services. Select Anonymous FTP and then choose Actions→Enable from the menu bar, as shown in Figure 9–1.

![](img/1c1e7552b53cca888836b6c6895bdb48_144_0.png)

Figure 9–1 Configuring anonymous FTP on HP-UX using SAM.

This process will place anonymous FTP files in the /home/ftp directory. If you log in as anonymous or ftp, you will be placed in this directory and see the following subdirectories: dist, etc, pub, and usr.

## 9.3.6 Transferring Files

The general rule for transferring files is, if you transfer between identical systems, use BINARY. If your systems differ, however, use ASCII.

## 9.3.7 Windows 2000 FTP Client

If you use Windows 2000 Internet Explorer to connect to a UNIX FTP server, you will have trouble reading files you copy to your system. For example, in Figure 9–5 there is an icon called *boot.txt*. This file resides on *hpux1*, a UNIX system. You can copy it to your Windows 2000 box by dragging and dropping the icon to your Desktop. However, if you open the file with Notepad, you will see something like Figure 9–6. Notepad does not know what to do with the NL (new line) character that UNIX systems put at the end of a line. Windows-based systems denote the end of a line with the CR-LF (carriage return-feed) characters. However, if you open the file with either Wordpad or Word, these programs interpret UNIX-created text files with no problem.
