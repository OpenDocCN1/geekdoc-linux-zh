# The Elements of UNIX

For example, if you type the following command:

```
$ ls -l myfile
```

you will get output something like this:

```
-rw-r--r-- 1 leslie 154 Nov 4 10:18 myfile
```

The first dash on the left indicates that myfile is a file. Were it a directory, you would see a d in place of the dash. Each of the other items is explained in the Table 1–3.

# Table 1–3 Explanation of ls -l

| Output | Meaning | Explanation |
|---|---|---|
| rw-r--r-- | Permissions | Permissions are displayed in groups of three. Owner leslie has read and write permission. Group users and others have read-only permission. If a permission is not allowed, a dash appears in place of the letter. |
| | Number of links | Each entry has at least one link. |
| leslie | The owner of the file | leslie is owner. |
| users | Group | These are the permissions of the users group. |
| 154 | Size of the file in bytes | A very small file. |
| Nov 4 10:18 | Modification date | If the time of last modification was more than six months ago, the year is substituted for the hour and minute. |
| myfile | The file name | myfile is the item being listed. |

If you use the ls -l command by itself, you will see a listing of files in the current working directory. If you supply that command with the name of a directory as an argument, then you will get a listing of the contents of directory. If you want to see the permissions on a directory without seeing a listing of all its files, use the ls -l command.

HP-UX supports commands that alter permissions: chown to change a file's ownership, chgrp to change a file's group, and chmod to change the actual permissions. However, the way in which each of these commands differs between the two operating systems. Check the man pages on the respective system for more information.
