# Conclusion

In the first command, we specified 1472 as the data length because if we add the ICMP Echo Request (8 bytes) and the IP header (20 bytes), we get 1500, the MTU of Ethernet. By adding another byte in the second command (1473), we exceeded the Ethernet MTU and received ICMP error messages to that effect. You can specify the packet size in HP-UX with the packet_size parameter.

+   - In Windows 2000, the -t option means the ping will continue without interruption. In HP-UX, -ttl sets the time-to-live in a multicast datacagram.
- In Windows 2000, the -a option resolves addresses to computer names. There is no -a option in HP-UX. Windows 2000 has a -i option to set the time-to-live. HP-UX uses the -t option.
- The -v option of Windows 2000 ping sets the type-of-service field to the value specified by tos; in HP-UX, it specifies verbose output, where ICMP packets other than Echo Responses are shown.
- The -r count option in Windows 2000 ping records the route of the outgoing packet and the returning packet in the route field. In HP-UX, -r specifies to bypass the normal routing tables and send to a host on an attached network.
- Windows 2000 ping has a -s count option, specifying the timestamp for the number of hops specified by count. HP-UX does not have a -s option.
- In Windows 2000, -j computer-list routes in loose-source mode packets by way of the list of computers specified by computer-list, and -k computer-list routes in strict-source mode packets specified by computer-list. The closest HP-UX equivalent is -o, which inserts an IP Record Route option in outgoing packets, summarizing routes when the command terminates.
- Windows 2000 has a -w timeout option, specifying a timeout interval in milliseconds. HP-UX does not have this option.
- Finally, if you ping from an HP-UX system and do not specify the number of pings with the -n count option, ping keeps sending packets until interrupted (Ctrl-C). Windows 2000 ping will continue only four times unless you specify more with the -n count option.

# 4.3 Conclusion

The network layer revolves around IP. If Microsoft has rewritten the TCP/IP stack, it does interoperate with that of HP-UX. There are a number of differences in the behavior of commands like arp and ping, but Windows 2000 supports NetBEUI and IPX/SPX, real UNIX and Windows interoperability begins with standardizing on TCP/IP.
