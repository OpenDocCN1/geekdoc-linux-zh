# 4.1.4 Gratuitous ARP

4.1.4.1 Windows 2000
Windows 2000 supports gratuitous ARP, sending ARP requests upon system startup check to see if the IP address being configured already exists on the local network. The number of requests is sent in the following Registry entry:

```
HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\ArpRetryCount
```

If a duplicate exists, Windows 2000 disables the network interface of the booting machine.

# 4.1.4.2 HP-UX

HP-UX also supports gratuitous ARP. However, if upon booting ARP discovers a duplicate address, ARP sends a message like the following:

> Duplicate IP address!! Sent from Ethernet address: x:x:x:x:x:x:

where x:x:x:x:x is the hardware address of the offending system. Unlike Windows 2000, HP-UX does not disable the network interface of the booting machine when it discovers a duplicate IP address.

# 4.2 IP

At the internet layer, IP is the key protocol. It sends and receives packets, known as datagrams, using a 32-bit addressing scheme. As a system administrator, you should already know something about IP addressing and subnet masking, so we won't go into any details about such here. However, if you'd like more information about addressing, two excellent references are W. Rich-Stevens', TCP/IP Illustrated, Volume I (Addison-Wesley Publishing Company, 1994) and Microsoft Corporation’s, Microsoft Windows 2000 Server TCP/IP Core Networking Guide (Microsoft Press, 2000).

# 4.2.1 Configuring IP

4.2.1.1 Windows 2000
Windows 2000 Professional defaults to using DHCP when you install the system. DHCP typically provides each client with an IP address, subnet mask, and a default gateway, as well as other parameters. However, if you are not using DHCP—for example, when installing a domain controller—then you must enter the IP information in the Internet Protocol (TCP/IP) Properties box. (see Figure 4–1).
