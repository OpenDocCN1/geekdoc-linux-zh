# 10.3.3 Migrating an HP-UX NIS Master to Server for NIS

You can migrate the data of an HP-UX NIS master server to Server for NIS and then use the Windows 2000 system as the new master server. You can either use a command-line utility called nis2ad to migrate your data, or can use the Migration wizard. This example will use the Migration wizard.

# 10.3.3.1 First Step: Check the Name Service Switch

You must be careful with the name service switch, which is configured by the /etc/nsswitch.conf file. By default, this file has the following contents:

```
passwd         files nis
group          files nis
hosts           dns [NOTFOUND=return] nis [NOTFOUND=return] files
networks        nis [NOTFOUND=return] files
protocols       nis [NOTFOUND=return] files
rpc             nis [NOTFOUND=return] files
publickey      nis [NOTFOUND=return] files
netgroup        nis [NOTFOUND=return] files .
automount       files nis
aliases         files nis
services        nis [NOTFOUND=return] files
```

If, for example, you have the name service switch consult NIS only for services, and the services map is empty, your system cannot communicate with your HP-UX system on the network. (I discovered this the hard way.) My recommendations:

+   1. Leave the default /etc/nsswitch.conf file alone; it can accommodate most environments.
2. Migrate only the password, group, and hosts maps. These are easily modified on Windows 2000.

# 10.3.3.2 Second Step: Run the Migration Wizard
