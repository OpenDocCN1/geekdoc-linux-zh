# Chapter 12 • CIFS File Sharing

```
===================================================
server w2kserv:
===================================================
Remote Username: dylan            Local Username: dylan
Share: \W2KSERV\HOME
rw /phome
```

User Dylan, though he both exists in the Windows 2000 domain, can-not access the /phome directory until he issues the cislogin command. He could have specified the name of a different Windows 2000 account as in cislogin w2kserv hilary—had he known Hilary’s password. However, because he did not so, cislogin assumed the remote user was also dylan. Also, note in the above output that dylan seems to own the Hilary directory. This is because the home share has Full Control permissions for Everyone. But the NTFS permissions override the share permissions, so that dylan cannot write to the डेयरी directory if the NTFS permissions prohibit him.

# 12.5.3 PAM and the CIFS/9000 Client

We described PAM NTLM in Chapter 8, “User Authentication,” and stated that by employing it you can avoid having to use cislogin. Let’s review how to do that.

+   1. Edit the PAM NTLM configuration file /etc/opt/cisclient/pam/smb.conf. You set the workgroup parameter, which is actually your Windows 2000 domain, and then you set the password server parameter, which is your domain controller name. In our example we have:

```
==================== Global Settings ==================
[global]
# workgroup = NT-Domain-Name or Workgroup-Name, eg: REDHAT4
workgroup = BOOK
```

# Use password server option only with security = server or
password server = w2kserv
Domain user map = /etc/opt/cisclient/pam/domain_user.map

As I have done with my configuration file, you might want to specify a user map file with the domain user map parameter. My map file contains only one mapping: that of root to Administrator.

+   2. Edit the global HP-UX PAM configuration file /etc/pam.conf. If you want NTLM authentication only when a user logs into the console running the Common Desktop Environment (CDE), change the libpam_unix.1 entries to libpam_ntlm/under the appropriate sections.
