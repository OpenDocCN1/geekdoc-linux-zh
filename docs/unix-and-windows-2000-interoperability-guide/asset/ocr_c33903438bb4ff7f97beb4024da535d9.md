# 9.3.2 HP-UX

The syntax of the FTP client on HP-UX is

```
ftp [-g] [-i] [-n] [-v] [-B size] [server-host]
```

The -g, -i, and -n options are the same as those found in the Windows 2000 version of FTP. The -B option sets the buffer size of the data socket to a size in blocks of 1024 bytes. The number of blocks can be from 1 to 64, with 56 being the default. The default connection type is ASCII, though if you connect to another HP-UX system. FTP switches to binary connections.
