# 4.2.10 The Ping Command

There are some significant differences in the ping command of the operating systems under discussion. The syntax of Windows 2000 ping is

```
ping [-t] [-a] [-n count] [-l length] [-f] [-i ttl] [-v tos]
[-r count] [-s count] [[-j] computer-list | [-k computer-list]
[-w timeout] destination-list
```

The syntax of HP UX ping is

```
ping [-oprv] [-i address] [-t ttl] host [-n count]
ping [-oprv] [-i address] [-t ttl] packet-size [-n count]
```

Windows 2000 uses the -f option (sends a packet with a Don't Fragment flag) and -l option (Echo Request packet with a specified data length) to determine the PMTU manually. For example, the following two commands demonstrate that the PMTU is set to the maximum for Ethernet:

```
C:\> ping -f 1472 10.10.1.1
```

Pinging 10.10.1.1 with 1472 bytes of data:

```
Reply from 10.10.1.1: bytes=1472 time<10ms TTL=128
Reply from 10.10.1.1: bytes=1472 time<10ms TTL=128
Reply from 10.10.1.1: bytes=1472 time<10ms TTL=128
Reply from 10.10.1.1: bytes=1472 time<10ms TTL=128
```

Ping statistics for 10.10.1.1:

```
Packets: Sent = 4, Received = 4, Lost = 0 (0% loss),
Approximate round trip times in milliseconds:
Minimum = 0ms, Maximum = 0ms, Average = 0ms
```

```
C:\>ping -f 1473 10.10.1.1
```

```

```
