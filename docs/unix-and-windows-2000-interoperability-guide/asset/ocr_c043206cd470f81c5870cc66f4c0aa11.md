# Conclusion

# 7.3 Conclusion

I have demonstrated that it is possible to integrate DHCP and DNS with both HP-UX and Windows-2000. However, much of what was presented was a proof-in-concept. Whether you choose to implement dynamic updates depends on how secure you want your environment to be. If you want to implement secure updates immediately, Windows 2000 now offers this capability, which means you might have to convert from BIND to Windows 2000 DNS in your environment, something that may be expensive and time consuming. If you choose to keep BIND, you can still avoid using dynamic updates and maintain your IP addresses manually. Something to mind is that traditionally it is mobile clients, such as laptops, that really need DHCP. Such systems should not be of any kind, such as why should they need their IP addresses registered in DNS? Besides, all clients, regardless of whether they are laptops or workstations, should not require IP registration because they should be dateless. For a more complete discussion of dateless clients, consult Robert W. Lucke's book, Designing and Implementing Computer Workgroups (Prentice Hall PTR, 1999). In other words, evaluate carefully your need to implement dynamic updates until the security incompatibilities between Windows 2000 DDNS and BIND are resolved.
