I created the account hilary using Active Directory Users and Computers. I then opened that user's Properties to get to the UNIX attributes tab. You have to enable a new user for NIS by selecting the appropriate NIS domain name, which I did with this user. I also chose a Primary Group called tech, which also exists in NIS. As a result, whenever hilary accessed an NFS resource, User Mapping automatically generated a mapping between the HP-UX user (as defined in NIS) and the Windows 2000 user. If a user's UNIX account name and Windows 2000 account name differs, then you must use Advanced Mapping to manually map the names (as done with the root and Administrator accounts).

# 11.5.2 Exporting Directories

After ensuring that User Mapping is correct, export your directories with the appropriate options, particularly if you need root access. Also, remember that, unlike Regular shares, NFS shares are case-sensitive. For example, if you export a directory with an NFS share named Home, the client must mount the directory with the name Home, not.

# 11.5.3 Local Permissions

To ensure proper access to directories, be sure that the local file system permissions are correct. On Windows 2000, this means that you should export directories only from NTFS volumes If you have exported and mounted file systems with read/write permission, the local file system permissions may still prevent users from working properly with their mounted files and directories.

# 11.5.4 Overall Experience

Both Client for NIS and Server for Windows worked well, the client's connection with the HP-UX server was a bit slow (two to three seconds), and this was on an isolated network. Here, read and write performance was satisfactory after connection.

I did find, however, that having Windows 2000 configured as an NFS server was often tricky, involving the coordination of Server for NIS, User Name Mapping, and Server for NFS. For HP-UX users who need more than occasional access to files stored on a Windows 2000 server, it might be better to use a CIF on the HP-UX system, which we will look at in the next chapter.
