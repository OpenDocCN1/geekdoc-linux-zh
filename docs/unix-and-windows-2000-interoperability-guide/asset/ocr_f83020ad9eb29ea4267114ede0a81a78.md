# 11.4.2 Configuring the HP-UX Client

The HP-UX NFS client can mount NT file systems using either standard mounts or automounts. Only the root user can make standard mounts. A standard mount usually takes place at system startup and remains in effect until the administrator explicitly performs an unmount. Sites generally use standard mounts for constantly used directories, like those containing applications. Automounts are mounts that take place when needed, for example, when you change directories to an NFS file system. These mounts usually disappear after about five minutes of inactivity and are generally used for less used directories.
