The " in the above output indicates that there is more output than I wanted to display. In this command, I specified the user dylan, a non-privileged user. Therefore, I got error messages with my find command when this user tried to view directories permissions for users other than root to do. To get rid of these error messages, I can redirect error (designated on UNIX systems as file descriptor 2) to /dev/null, the wastebasket. Remember, I must quote the redirect symbol because there is no /dev/null on Windows 2000:

```
D:\>rsh hpux1 -l dylan find -name "*.log" 2">/ /dev/null

/var/opt/ignite/local/install.log

```

```
D:\>rsh hpux1 -l dylan find -name "*.log" 2"> /dev/null 
c:\windows\temp\hpux1_log_files.txt
```

The command is actually one line, but is split for display purposes only.

# 9.5.3 Running Rcp

Rcp lets you copy files to either the local Windows 2000 system or to another system rshd or remsh. You can copy a complete directory structure from one system to another. The help switch of Windows 2000 Rcp displays the following:

```
rcp [-a | -b] [-h] [host][.user:]source [host][.user:]path]destination
```
