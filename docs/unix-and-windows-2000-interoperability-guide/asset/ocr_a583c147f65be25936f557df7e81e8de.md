# Elements of Windows 2000

Setup Programs
A setup program can add new new configuration data to the Registry when it installs hardware or software. It can also query the Registry to determine whether required components have been installed.

Ntdect.com
On Intel-based computers, ntdet.com scans the system for the hardware. It adds configuration information to the Registry for components it discovers. RISC-based computers extract such data from the computer firmware.

Hardware Profiles
Computers with two or more hardware configurations use hardware profiles. When Windows 2000 starts, the user selects a hardware profile. Windows 2000, with the Registry, then configures the system accordingly.

User Profiles
Windows 2000 creates and maintains user environmental settings in a user profile. When a user logs on, the system caches the profile in the Registry. Windows 2000 first writes user configuration changes to the Registry and then to the user profile.

# 2.3.2 Active Directory

Active Directory is Windows 2000's directory services. Directory services enables users and applications to locate network resources, including user data, servers, and printers. Active Directory uses the Domain Name System (DNS) to locate network names and Lightweight Directory Access Protocol (LDAP) or HyperText Protocol (HTTP) for obtaining resource information. Because of its reliance on DNS, Active Directory domain names coincide with DNS names, though an Active Directory domain is not exactly the same thing as a DNS domain.

# 2.3.3 User Interfaces

In Chapter 1, we saw that UNIX traditionally provided a default shell with which to run commands and applications. In recent years, HP-UX, AIX, and Solaris have provided a graphical user interface (GUI) called the Common Default Environment (CDE), which makes a number of day-to-day tasks easier. Additionally, all major forms of UNIX provide some of system management tool, such as SAM in HP-UX and SMIT in AIX, to help simplify system administration. Windows 2000 provides similar tools: a command interpreter, a GUI, and a system administration tool known as the Microsoft Management Console (MMC).
