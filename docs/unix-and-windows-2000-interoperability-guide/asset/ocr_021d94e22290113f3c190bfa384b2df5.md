# 12.5 CIFS/9000 Client in a Windows 2000 Domain

Now we can go in the other direction. By using the CIFS/9000 client, we can access files located on a Windows 2000 system. While smclient is installed with the CIFS/9000 package, the client portion is not Samba-based. As we previously discussed with the CIFS/9000 server, we will create a scenario of using the client and learn the complete description of the product to HP's official documentation, Installing and Administering the CIFS/9000 Client.

In this scenario, we have some engineers who still need to use HP-UX workstations to run their CAD application. While they use these workstations periodically during the day, they do most of their work on PC workstations running Windows 2000. Their PC home directories are located on a Windows 2000 server. Occasionally, while working on the HP-UX workstations, they want to access their PC home directories without using something like FTP or Telnet. To make this possible, we will use the CIFS/9000 client.
