# 9.3.8 HP-UX FTP Client

If you run the FTP client on HP-UX and connect to a Windows 2000 system, then your transfer mode is ASCII. The following output illustrates this fact:

```
# w2kserver
Connected to w2kserver.book.local.
220 w2kserver Microsoft FTP Service (Version 5.0).
Name (w2kserver:root): ftp
```
