# 9.3.5 The Windows 2000 FTP Server

Even though the Windows 2000 installation process installs Internet Information Services by default, you must ensure that the FTP Server is installed as well. If you run Start->Settings->Control Panel->Add/Remove Programs and then select Add/Remove Windows Components->Internet Information Services, make sure your window has the File Transfer Protocol (FTP) Server box checked, as seen in Figure 9–2.

![](bbox=[0.092, 0.287, 0.755, 0.663])

Figure 9–2 Installing the FTP Server on Windows 2000. If you want the FTP Server, check Common Files, File Transfer Protocol (FTP) Server, and Internet Information Services Snap-In.

By default, the Windows 2000 FTP Server stores files for distribution in the C:\inetpub\ftproot directory and allows anonymous logins. If you log in as “real” user (not anonymous), you are still placed in the ftproot directory. The FTP Server is also highly configurable. You can configure it by running the Internet Services Manager, found in the Administrative Tools folder.

# 9.3.6 Transferring Files

The general rule for transferring files is, if you transfer between systems with identical operating systems, use BINARY mode transfer. It’s more efficient. If your operating systems differ, use BINARY mode for binary files, ASCII mode for text files.
