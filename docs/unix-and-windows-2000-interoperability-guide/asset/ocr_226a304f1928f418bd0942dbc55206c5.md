Microsoft released two flavors of its operating system, Windows NT 3.1 and NT Advanced Server 3.1, in the summer of 1993. The version number 3.1 was chosen to coincide with that of the 16-bit Windows operating system prevalent throughout the world at the time. It also implied that this new operating system was not an unstable 1.0 release. It was slow, using a lot of memory and requiring much in the way of computer hardware, but it was a significant achievement, nonetheless, it was the 32-bit Windows operating system, and it could run on non-Intel-based processors: MIPS, Alpha, and Power. Though not a big commercial success, it was a propitious start in the effort to create an alternative to UNIX.

From 1993 to 1996, Microsoft released three major versions of NT: 3.5, 3.51, and 4.0. Version 4.0 has been by far the most successful version of NT. It offered more device support, default TCP/IP networking. Internet services, and a Windows 95 interface. These and other features have made Windows NT 4.0 the operating system of choice for business desktops, cutting severely into the UNIX desktop business since its release in 1996.

The next generation of NT technology is Windows 2000, known unofficially as Windows NT 5 until a few months before its official release in February 2000. There are several versions of Windows 2000:

+   * Windows 2000 Professional. Designed for business desktops and laptops.
* Windows 2000 Server. Designed for workgroup and small business network services.
* Windows 2000 Advanced Server. Designed for e-business and line-of-business applications.
* Windows 2000 Datacenter Server. Designed for large systems running critical applications such as OLTP and warehousing.

# 2.2 Windows 2000 Architecture

Figure 2-1 depicts the major components of Windows 2000. At the lowest level is the hardware itself, most often an Intel processor-based system. Above that is the Hardware Abstraction Layer (HAL), a layer of software designed to hide hardware differences from the rest of the operating system. At the next level, we have both device drivers and the kernel. Herein an important difference between most versions of UNIX, including HP-UX, and Windows 2000. The Windows 2000 kernel is a microkernel; it does not include device drivers. Therefore, the kernel remains small, taking care of the most basic of operating system functions. As pointed out in Chapter 1,“What is UNIX?” most UNIX kernels require that a device’s driver be compiled into the kernel. Moreover, whereas UNIX kernels handle I/O and memory management, in Windows 2000, these functions are separated into subsystems.
