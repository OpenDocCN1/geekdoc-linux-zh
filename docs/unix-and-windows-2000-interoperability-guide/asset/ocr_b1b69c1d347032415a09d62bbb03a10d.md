# Server For NIS

![](bbox=[0.078, 0.118, 0.893, 0.584])

Figure 10–6 The NIS Data Migration Welcome screen.

Note that this screen says that you will have to access to the NIS map source files. I used FTP to copy /etc/passwd, /etc/group, and /etc/hosts to a local directory called D:\>NIS. If you do not put other source files there, such as /etc/services or /etc/netgroup, then the maps associated with those source files will be empty. Be sure your /etc/nsswitch.conf file is configured to consult local files at some point. After clicking Next, I got the Domain and Server Selection screen. (See Figure 10–7.)
