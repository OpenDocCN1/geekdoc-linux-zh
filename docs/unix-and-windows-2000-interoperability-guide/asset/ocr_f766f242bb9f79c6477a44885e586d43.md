ndd -set/dev/ip ip_ire_redirect_interval command. For example, to set the value to six minutes,
type the following:

```
# nd -set /dev/ip ip_ire_redirect_interval 360000
```

# 4.2.8 Router Discovery

4.2.8.1 Windows 2000

Windows 2000 systems ICMP router discovery, a dynamic method of determining the best
default gateway. Routers configured with ICMP router discovery periodically broadcast router
adisements from which clients can choose the most appropriate default route. Hosts config-\ured to be router clients join the all-multicast group of 224.0.0.1 in order to list-
ten to these advertisements upon system startup. Clients choose a default gateway among the
advertisements it receives. In addition to listening for router advertisements, hosts can actually
solic routers using the 224.0.0.2 multicast address. You can configure Windows 2000 hosts for
router discovery by setting the following registry entry to a value of 1:

HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\ParametersPerformRouterDiscovery

# 4.2.8.2 HP-UX

HP-UX implements ICMP router discovery on clients via rdp, the router discovery daemon.
preferably calling it to the Router Discovery Protocol (RDP). RDP on client works the same as
ICMP router discovery on Windows 2000 clients. Clients listen for router advertise-\ments over the all-multicast address of 224.0.0.1 or the NIC's broadcast address. The cli-
ent also sends solicitations to the all-routers multicast address of 224.0.0.2.

You can start rdp either by setting the RDP variable in /etc/rc.conf/netconf to 1 and
reboot (or restarting the /sbin/init.d start command) or by configuring gated. Gated is a
router daemon that handles multiple routing protocols, including Routing Information Protocol
(RIP), Border Gateway Protocol (BGP), External Gateway Protocol (EGP), the Hello Protocol
(HELLO), Shortest Path First (OSPF), and RDP. To configure gated, edit the /etc-
gated.conf file and change the GATED variable in /etc/rc.conf/netconf 1. For more informa-
run the following commands:

```
# man gated
# man 4 gated.conf
```

Do not however, start RDP using both methods.

# 4.2.9 MTU and Path MTU

4.2.9.1 Windows 2000

Windows 2000 systems have Path MTU enabled by default for all interfaces. If you
disable it, Windows 2000 defaults to a Maximum Transmission Unit (MTU) of 576 bytes.
Change the value of the following Registry parameter to 0 to disable Path MTU discovery:

HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\EnablePMTUDiscovery
