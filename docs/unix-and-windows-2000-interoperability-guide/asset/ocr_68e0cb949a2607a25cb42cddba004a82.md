Figure 4–2 Adding default gateways. To get to this box, open the Network and Dial-up Connections window from the Control Panel, right-click on Local Area Connection, and choose Properties. In the Local Area Connection Properties window, select Internet Protocol (TCP/IP) and choose Properties. Then, click on the Advanced button.

To add a route to the command line, use the route command. The syntax for the command is route [-f] [-p] [command [destination] [mask subnetmask] [gateway] metric costmetric]]

For example:

```
C:> route add 10.0.0.0 mask 255.255.0.0 10.10.1.1 metric 1
```

If you use the -p option with route add, then you make the route persistent; in other words, you make it permanent even between reboots. Windows 2000 stores persistent routes in HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\ParametersPersistentRoutes
