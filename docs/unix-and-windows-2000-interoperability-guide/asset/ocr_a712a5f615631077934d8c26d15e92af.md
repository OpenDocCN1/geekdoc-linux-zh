If the DHCP server is configured to update both records regardless of the client, it sets the Flags field to 3 in its DHCPOFFER and DHCPACK messages. The DHCP server uses the Rcode fields to indicate to the client the response code and also indicate whether it attempted the update before sending a DHCPACK message. The Domain Name field specifies the FQDN of the client and consists of the host name concatenated with the primary DNS suffix.

You can change the Flags and Domain Name fields by right-clicking on My Network Places, and then selecting Properties. Right-click on Local Area Network and then Properties. Select Internet Protocol (TCP/IP)→Properties→Advanced. On the DNS tab, you have some options to choose from, as shown in Figure 7–1.
