## 9.5.3 Running Rcp

Rcp lets you copy files to either the local Windows 2000 system or to another system rshd or remsh. You can copy a complete directory structure from one system to another. The help switch of Windows 2000 Rcp displays the following:

```
rcp [-a | -b] [-h] [host][.user:]source [host][.user:]path]destination
```

## Chapter 9 • Basic TCP/IP Utilities

- - a Specifies ASCII transfer mode. This mode converts the EOL characters to a carriage return for UNIX and a carriage return/line feed for personal computers. This is the default transfer mode.
- - b Specifies binary image transfer mode.
- - h Transfers hidden files.
- - r Copies the contents of all subdirectories; destination must be a directory
- host Specifies the local or remote host. If host is specified as an IP address OR if name contains dots, you must specify the user.
- user specifies a user name to use, rather than the current user name.
- source specifies the files to copy.
- path\destination Specifies the path relative to the logon directory on the remote host. Use the escape characters (\, ", or or ?) in the remote paths to use wildcard characters on the remote host.

Let's use some examples to clarify.
I am am logged on Windows 2000 as the user dylan. My home directory is C:\Documents and Settings\dylan. On my HP-UX system, I have a dylan account with a home directory of \home\dylan. ## 9.5.4 Things to Remember about Rsh and Rcp

- If you are logged on Windows 2000 with an account that does not exist on HP-UX, you must supply a different user name (such as root).
- If you do not specify a user name, the HP-UX system will assume that your user name is the same as your Windows 2000 account.
- The -n option, as it does with Rsh, redirects the input to NUL.

## 9.6 Rexec

Rexec is more secure than Rcp because it requires a password for authentication.

## 9.6.1 Examples

If you are logged on Windows 2000 as dylan and your HP-UX system account is called dylan, then you can execute a Rexec command without the -l parameter:

```cmd
C:>rexec hpux1 dylan
Name (hpux1.book.local:dylan):
Password (hpux1.book.local:dylan):
Wed Oct 25 20:44:01 PDT 2000
```

If you are logged on Windows 2000 with an account that does not exist on HP-UX (such as Administrator), you must supply a different user name (such as root). For example:

```cmd
C:>rexec hpux1 dylan
Name (hpux1.book.local:Administrator): root
Password (hpux1.book.local:Administrator):
Wed Oct 25 20:53:05 PDT 2000
```

If you supply a user name, then you are not prompted for a user name:

```cmd
C:>rexec hpux1 -l dylan date
Password (hpux1.book.local:)
Wed Oct 25 20:55:09 PDT 2000
```

As with Rsh, if you use any command redirection using the > >> symbols, you must quote them if you want redirection to take place on the remote system.

```cmd
C:>rexec hpux1 -l root cat /profile ">" /tmp/root_profile
Password (hpux1.book.local:)
```

This command, issued on a Windows 2000 system, instructs the HP-UX system to concatenate (using the HP-UX cat command) the contents of /profile to a file called /root_profile on the HP-UX system.
