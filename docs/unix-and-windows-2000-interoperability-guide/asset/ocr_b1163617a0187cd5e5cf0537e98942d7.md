# 7.2 Windows 2000 DHCP Server

The Windows 2000 DHCP Server can be configured to update DNS according to client requests or to always both A and PTR records. On the DHCP server you run the DHCP manager to configure these options. (See Figure 7–3.) The default configuration is for the Automatically update DHCP client information in DNS box to be checked and the Update DNS only if DHCP client requests option selected. After dispatching the IP address lease to the client, the server attempts to update the PTR record with DNS, while the client attempts to update the A record.

If you set the Always update DNS option, then the server sets the Flags field to 3 and attempts to update DNS regardless of the client request. The client in turn does not attempt any updates. If you deselect the Automatically update DHCP client information in DNS box, then the server does not updating, and the client attempts to update both A and PTR records.
