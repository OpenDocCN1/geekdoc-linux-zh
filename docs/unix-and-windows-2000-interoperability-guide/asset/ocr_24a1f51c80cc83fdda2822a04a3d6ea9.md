Notice that hidden files and directories were not copied. To copy My Documents folder and all its subfolders and hidden files to the dylan home directory,

```
C:\Documents and Settings\dylan>rc -hr "My Documents" hpx1.dylan:
```

This command created a My directory, which did not exist, in dylan's home directory and copied all that directory's contents to the HP-UX system.

+   - You can do remote copies in the other direction: from HP-UX to Windows 2000. For example, copy recursively the subdirectory test in dylan's home directory on HP-UX to the current directory on Windows 2000, type

```
C:\Documents and Settings\dylan>rc -r hpx1.dylan:test
```

Again, this command created the test in C:\Documents and Settings\dylan copying the rest of the files.

# 9.5.4 Things to Remember about Rsh and Rcp

At the risk of repeating myself,

+   - You must set up /etc/hosts.equiv for your remote system or .hosts for individual users on your HP-UX system for these commands to work for security. You just need to know the name of a user on HP-UX, and /etc/hosts.equiv has the + entry, you simply insert any user name (except for root) when issuing one of these commands. For reason, never set up .hosts file for the root user!
- You must legitimate HP-UX users in your Windows 2000 Rsh and Rcp commands. If you don't, your Windows 2000 user name must match the HP-UX user name letter-by-letter, case-by-case.
- Watch your recursive copies. The default transfer mode is ASCII. If you have binary files in your directory structure, those files will not transfer.
