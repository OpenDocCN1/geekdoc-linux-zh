+   e. Optionally, enter comments about your LAN card.

+   h. Activate the OK button to perform the task and return to the Configure LAN Card window.

+   7. Activate the OK button at the Configure LAN Card window to enable your LAN card. If the software is correctly configured, SAM displays the Interface Cards object list with the status Enabled for your LAN card; otherwise, SAM displays an error message.

# 3.2 Conclusion

The network interface layer performs the same function on both Windows 2000 and HP-UX. How they are actually implemented and configured differ, however. Two of the more important technologies at this layer are Ethernet and Fibre Channel. Whereas Ethernet is ubiquitous in today's LANs, play an important role in the new SAN and NAS technologies.
