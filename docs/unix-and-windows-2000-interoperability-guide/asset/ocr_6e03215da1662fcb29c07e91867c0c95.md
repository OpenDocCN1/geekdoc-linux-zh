# Networking

1.4.5 TCP/IP are blood brothers. In the mid 1970s, the Defense Department's Advanced Research Projects Agency (DARPA) funded Bolt, Beranek, and Newman (BBN) to develop TCP/IP for UNIX, and the University of California-Berkeley later integrated this software into BSD UNIX. Since then, UNIX networking has met TCP/IP, and, until recently, TCP/IP was driven by the speed of UNIX and the Internet.

Modern UNIX systems support a variety of network interface layer devices and protocols: Ethernet, Token Ring, ATM, ISDN, and others. They also support either SLIP or PPP. Networking applications include NFS for file sharing, and NIS for the sharing of key information, such as passwords.

One extremely important application is the X Window System. Though it is often thought of as a graphical system, it really is a networking protocol that separates the client application from the display server. The client runs natively on a system and connects to its display via the network, even if the display is on a separate system. All forms of UNIX support X Window, and it is the basis for all GUIs in use today, including the Common Desktop Environment found on HP-UX, AIX, Solaris, and the GNOME and KDE found on Linux.

# System Management Tools

Even though I praise the virtues of command-line system administration, there is much to be said about the graphical system administration tools provided by most versions of UNIX. HP-UX has SAM, the System Administration Manager. AIX has SMIT, System Management Interface Tool. Many Linux distributions include a similar tool Linuxconf. These tools help you do tasks for which you know what needs to be done (for example, mount a file system) but you are not sure how it should be done. Since I will be using HP-UX for most of my UNIX examples, I will refer to the SAM tool frequently.
