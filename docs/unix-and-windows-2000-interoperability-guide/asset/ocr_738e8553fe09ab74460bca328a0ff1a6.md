# NIS Map Selection

You can select the maps to migrate to a new NIS domain or a previously migrated domain in Active Directory.

To migrate a map, select a map in the NIS maps list, and then click Add. To remove a map, select a map in the Maps to migrate list, and then click Remove. To create a new non-standard NIS map to migrate, click New. To view or edit a non-standard map, select the map and click Edit/View.

In my case, conflicts were logged in D:\SFU\nis\conflicts. Following is an excerpt from that file:

```
### Mon Nov 27 12:53:24 2000 : Conflict details of entries from map file and existing entries in AD. map file = 'passwd'. ###
```

conflicts with CN=dylan, CN=Users, DC=book, DC=local existing data = A Windows only object (User/Group/Computer). No Unix attributes found for this object.

```
new data = dylan:kIg86Wct3dfg:102:20:Dylan Roberts,DT4T,434-1434,4544-4545:/home/dylan/usr/bin/sh
```

Essentially, this output tells us that there was already a Windows 2000 user named dylan in the book.local domain. As a result, the migration added new data, including the password, home directory, and login shell, to the Active Directory entry for dylan.
