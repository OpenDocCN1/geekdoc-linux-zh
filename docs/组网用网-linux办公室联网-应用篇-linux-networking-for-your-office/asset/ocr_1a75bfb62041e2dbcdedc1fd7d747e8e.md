# Obtaining and Installing the Latest Ghostscript

The official Web site for Ghostscript is http://www.cs.wisc.edu/~ghost, and from there you can obtain the latest Ghostscript source code and binaries. Follow the link labeled Obtaining Aladdin Ghostscript to get the latest version of the program. In most cases, you don’t need to do this; the version of Ghostscript that ships with Red Hat Linux 6.0 is quite adequate, although it’s not the latest.
