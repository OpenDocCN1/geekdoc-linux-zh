+   - It’s possible to operate a completely isolated private network using any IP addresses you like. If you do this with IP masquerading active, though, you’ll be unable to access sites in the same address range as the IP numbers you’ve chosen. You should therefore be sure you use internal IP addresses in an approved range of addresses for private networks, as outlined in Table 4.2 (p. 95).
