# 安装说明

# Windows 95/98 NT 4

- 1. 将 CD-ROM 插入您的 CD-ROM 驱动器。
- 2. 在 Windows 桌面上，双击“我的电脑”图标。
- 3. 双击代表您 CD-ROM 驱动器的图标。
- 4. 双击标题为 Readme.txt 的图标以了解更多信息。

# Macintosh 安装说明

- 1. 将 CD-ROM 光盘插入您的 CD-ROM 驱动器。
- 2. 当 CD 的图标出现在桌面上时，通过双击其图标打开光盘。

# Linux 和 Unix

这些安装说明假定您对 UNIX 命令和机器的基本设置有一定了解。由于 UNIX 有多种发行版，仅使用通用命令。如果您对命令有任何问题，请参阅相应的手册页或联系您的系统管理员。

- 1. 将 CD-ROM 插入 CD 驱动器。
- 2. 如果您有卷管理器，CD-ROM 的挂载将自动进行。如果您没有卷管理器，您可以通过输入以下命令挂载 CD-ROM
- Mount -t iso9660 /dev/cdrom /mnt/cdrom
- 注意：/mnt/cdrom 只是一个挂载点，但在发出挂载命令时必须存在。如果您不想使用 /mnt/cdrom，也可以使用任何空目录作为挂载点。
- 3. 挂载 CD-ROM 后，您可以从 tcltksoftware/linux 或 unix 文件夹安装文件。
