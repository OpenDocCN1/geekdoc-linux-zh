## Linux: Networking for Your Office

小型办公 / 家庭办公解决方案

如果你一直在寻找一种经济有效的方式来联网几台计算机，你的搜索到此为止——欢迎来到 Linux！

《Linux: Networking for Your Office》向你展示如何以 Linux 为核心，将一群 Windows®、Macintosh® 或 UNIX 机器联网，甚至为联网的机器提供 Internet 功能。学习如何将你的 Linux 机器用作文件服务器、打印服务器、IP 伪装路由器和防火墙。你甚至还能获得一张光盘，其中包含 Linux 和额外的工具，让你立即投入使用！

Roderick W. Smith 从高中起就开始使用计算机，包括使用 AppleDOS、MacOS、TOS、MS-DOS、Windows 95 和 98、Windows NT®、OS/2、BeOS、VMS、Ultrix 以及当然还有 Linux 等各种操作系统的系统。Rod 从 1994 年开始使用 Linux，并从 1996 年起将其作为主要操作系统。他在各种环境中拥有将 Linux 与各种 Linux、Windows、MacOS、OS/2 和 BeOS 在以太网网络上集成的经验。

Rod 是 Que 出版的《Corel® WordPerfect® 8 for Linux 特别版使用指南》的作者。他还在计算机杂志上发表过文章，最著名的是《Linux Journal》。他拥有 Oberlin College 的学士学位、密歇根大学的硕士学位和塔夫茨大学的博士学位。

## 使用你的 Linux 服务器来...

- 与 Windows、Macintosh 和 UNIX 客户端共享文件和打印机。
- 通过使用通用服务器集成 Windows 和 Macintosh 网络。
- 使用一台磁带备份设备备份多台计算机。
- 集中多个计算机数据的备份。
- 从网络上的任何计算机——甚至整个 Internet！——运行 Linux 程序。
- 通过单个网络地址为办公室中的所有计算机提供 Internet 访问。
- 保护你的内联网免受未经授权的访问。
