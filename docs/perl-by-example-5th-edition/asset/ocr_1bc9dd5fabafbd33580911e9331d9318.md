Once you have installed cpans, you can install a module by its name simply by running the cpanm command at your shell prompt:

```
$ cpanm ModuleName # logged in as root
# cpanm --sudo ModuleName # if you want to install the module system-wide
and are not logged in as root.)
```

And that's it! You may need to enter a password if you are not running as root, but otherwise, cpans will get the module and its dependencies without all the verbose output that you get from cpan. In the following example, we use cpanm to retrieve a module from cpan called Data::Dumper::Perl tidy, which does as its name suggests and makes the output of Data::Dumper neat and tidy.
