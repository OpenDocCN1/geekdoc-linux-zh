# **EXPLANATION**

+   1. You must use Perl 5.10.1 or later to run this script. Use the `feature` module to include `switch` and `say`.
+   2. The array `@week`, is defined with a list of days of the week.
+   3. The `foreach` loop iterates through a list of numbers representing days of the week.
+   4. Each day of the week is assigned in its string format to `$today`, for example, "Sunday".
+   5. The arguments to `given` and `when` are in scalar context, and `given` assigns the `$`_ variable its topic value.
+   6. The `when` reads: when the `given` value matches a number in the range of 1 to 5, enter the following block and say what day it is and Work, work, work.
+   7. If none of the `when` expressions match the `given` value, the `default` block is entered, similar to the `else` in an `if/elsif` conditional construct.
