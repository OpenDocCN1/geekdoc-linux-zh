# **Sorting Results with ORDER BY.** You can display the output of a query in a particular order by using the *ORDER BY* clause. Rows can be sorted in either ascending (*ASC*, the default) or descending (*DESC*) order where the values being sorted are either strings or numbers.

# **FORMAT**

```
SELECT column FROM table
[WHERE condition]
ORDER BY column [ASC, DESC]

Example:
SELECT Company, OrderNumber FROM Orders
ORDER BY Company
```

# **EXAMPLE B.20**

```
mysql> SELECT CompanyName, ContactName FROM suppliers
    -> ORDER BY CompanyName LIMIT 10;
```
