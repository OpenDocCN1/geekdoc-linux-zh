# ## 6.3 Precedence and Associativity

# EXAMPLE 6.26

```
(The Script)
use warnings;
1 my $x="pop";
2 my $y="corn";
3 my $z="*";
4 print $z x 10, "\n";  # Print 10 stars; repetition operator
5 print $x . $y, "\n";  # Concatenate "pop" and "corn"
6 print $z x 10, "\n";  # Print 10 stars
7 print uc( $y), "\n";  # Convert string to uppercase

(Output)
4 ********
5 popcorn
6 ********
7 POPCORN!
```

# EXPLANATION

1.  The scalar `$x` is assigned `pop`.
2.  The scalar `$y` is assigned `corn`.
3.  The scalar `$z` is assigned `*`.
4.  The string `*` is repeated 10 times and printed to STDOUT.
5.  The value of `$x`, string `pop`, and the value of `$y`, string `corn`, are concatenated and printed to STDOUT.
6.  The value of `$x`, string `*`, is repeated 10 times and printed to STDOUT.
7.  The `uc` function converts and returns the string in uppercase. The `lc` function will convert a string to lowercase.
