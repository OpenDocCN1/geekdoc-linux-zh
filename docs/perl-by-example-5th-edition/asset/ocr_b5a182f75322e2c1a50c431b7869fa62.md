(The Script)

use warnings;

# The bracketed character class
1 while(<DATA>){
2 print if /[A-Za-z0-9_]/
}

__DATA__
Steve BLENHEIM 101
Betty Boop 201
Igor CHEVSKY 301
Norma Cord 401
Jonathon DeLoach 501
Karen EVICH 601

```
```

# EXPLANATION

2  The line `$` is printed only if it contains a pattern matching one alphanumeric word character, represented by the character class, `[A-Za-z0-9_]`. All lines are printed.

(The Script)

use warnings;

# The bracket metacharacters and negation
1 while(<DATA>){
2 print if /[^123]0/
}

__DATA__
Steve BLENHEIM 101
Betty Boop 201
Igor CHEVSKY 301
Norma Cord 401
Jonathon DeLoach 501
Karen EVICH 601
```

```
(Output)
Norma Cord 401
Jonathon DeLoach 501
Karen EVICH 601
```
```

# EXPLANATION

2  The line `$` is printed only if `$` contains a pattern matching one space, followed by one number not in the range between 1 and 3 (not 1, 2, or 3), followed by 0.
