# Turning off Greed

Greed can be turned off using the question mark (?) character.

# EXAMPLE 9.41

```
(The Script)
use warnings;
# Turning off greed
my $str= "Tom Jones:23 Main St.:Boston, MA";
1 my $str=(.(.*)?);   # Capture everything up to the last colon
print "$1\n";

$str= "Tom Jones:23 Main St.:Boston, MA";
2 $str=/(.(*?)/;      # Capture everything up to the first colon
print "$1\n";

(Output)
2 Tom Jones:23 Main St.
3 Tom Jones
```

# EXPLANATION

+   1. The scalar $string is assigned the string.
+   2. The regular expression is enclosed in parentheses. Everything is matched up until the last colon because the .* is greedy. The matched characters are captured and stored in $1.
+   3. In this example, the greed is turned off with the ? after the .* Now everything will be matched up until the first colon, then captured, and printed.

# EXAMPLE 9.42

```
(The Script)
use warnings;
# Capturing and greed
my $fruit= "apples pears peaches plums";
2 $fruit =~ /(.*)\b(.*)\b(.*)/;
print "$1\n";
4 print "$2\n";
5 print "$3\n";
print "-" x 30, "\n";
6 $fruit= "apples pears peaches plums";
7 $fruit =~ /(.*)?\b(.*)?\b(.*)?\b/;  # Turn off greedy quantifier
8 print "$1\n";
9 print "$2\n";
10 print "$3\n";
```
