
## Appendix A * Perl Built-ins, Pragmas, Modules, and the Debugger

### Table A.1 Perl Functions (continued)

| Function | Description |
| :--- | :--- |
| **semop** | `semop(KEY, OPSTRING)`<br>Calls the *semop* system call to perform operations on a semaphore identified by *KEY*. *OPSTRING* must be a packed array of *semop* structures. Requires library files `ipc.ph` and `sem.ph`.<br>See System V IPC.<br>See also `semop(2)`. |
| **send** | `send(SOCKET, MSG, FLAGS, TO)`<br>`send(SOCKET, MSG, FLAGS)`<br>Sends a message on a *SOCKET*.<br>See `send(2)`. |
| **setpgrp** | `setpgrp(PID, PGID)`<br>Sets the current process group for the specified process, process group, or user.<br>See `getpgrp(2)`. |
| **setpriority** | `setpriority(WHICH, WHO, PRIORITY)`<br>Sets the current priority, *nice* value, for a process, process group, or user.<br>See `getpriority(2)`. |
| **setsockopt** | `setsockopt(SOCKET, LEVEL, OPTNAME, OPTVAL)`<br>Sets the requested socket option on *SOCKET*.<br>See `getsockopt(2)`. |
| **shift** | `shift(ARRAY)`<br>`shift ARRAY`<br>Shifts off the first value of the *ARRAY* and returns it, shortening the array.<br>If *ARRAY* is omitted, the `@ARGV` array is shifted, and if in subroutines, the `@_` array is shifted. |
| **shmctl** | `shmctl(ID, CMD, ARG)`<br>Calls the *shmctl* system call, allowing control operations on shared memory.<br>Has weird return codes. Requires library file `ipc.ph` and `shm.ph`.<br>See System V IPC.<br>See also `shmctl(2)`. |
| **shmget** | `shmget(KEY, SIZE, FLAGS)`<br>Returns the shared memory segment ID associated with the *KEY*, or undefined if an error. The shared memory segment created is of at least *SIZE* bytes.<br>Requires `ipc.ph` and `shm.ph`.<br>See System V IPC.<br>See also `shmget(2)`. |
| **shmread** | `shmread(ID, VAR, POS, SIZE)`<br>Reads from the shared memory ID starting at position POS for SIZE. VAR is a variable used to store what is read. The segment is attached, data is read from, and the segment is detached. Requires *ipc.ph* and *shm.ph*. See System V IPC. See also shm*at*(2). |
| **shmwrite** | `shmwrite(ID, VAR, POS, SIZE)`<br>Writes to the shared memory ID starting at position POS for SIZE. VAR is a variable used to store what is written. The segment is attached, data is written to, and the segment is detached. Requires *ipc.ph* and *shm.ph*. See System V IPC. See also shm*at*(2). |
| **shutdown** | `shutdown(SOCKET, HOW)`<br>Shuts down a SOCKET connection. If HOW is 0, further *receives* will be disallowed. If HOW is 1, further *sends* will be disallowed. If HOW is 2, then further *sends* and *receives* will be disallowed. See *shutdown*(2). |
| **sin** | `sin(EXPR)`<br>`sin`<br>Returns the sine of EXPR (expressed in radians). If EXPR is omitted, returns sine of $_. |
| **sleep** | `sleep(EXPR)`<br>`sleep EXPR`<br>`sleep`<br>Causes program to sleep for EXPR seconds. If EXPR is omitted, program sleeps forever. See *sleep*(3). |
| **socket** | `socket(SOCKET, DOMAIN, TYPE, PROTOCOL)`<br>Opens a socket of a specified type and attaches it to filename, SOCKET. See *socket*(2). |
| **socketpair** | `socketpair(SOCKET, SOCKET2, DOMAIN, TYPE, PROTOCOL)`<br>Creates an unnamed pair of *connect* sockets in the specified domain of the specified type. See *socketpair*(2). |
| **sort** | `sort(SUBROUTINE LIST)`<br>`sort(LIST)`<br>`sort SUBROUTINE LIST`<br>`sort LIST`<br>Sorts the LIST and returns a sorted array. If SUBROUTINE is omitted, sorts in string comparison order. If SUBROUTINE is specified, gives the name of a subroutine that returns an integer less than, equal to, or greater than 0, depending on how the elements of the array are to be ordered. The two elements compared are passed (by reference) to the subroutine as $a and $b, rather than @_. SUBROUTINE cannot be recursive.<br>See Array Functions. |
| **splice** | `splice(ARRAY, OFFSET, LENGTH, LIST)`<br>`splice(ARRAY, OFFSET, LENGTH)`<br>`splice(ARRAY, OFFSET)`<br>Removes elements designated starting with OFFSET and ending in LENGTH from an array and, if LIST is specified, replaces those elements removed with LIST. Returns the elements removed from the list. If LENGTH is not specified, everything from OFFSET to the end of ARRAY is removed. |
| **split** | `split(PATTERN, EXPR, LIMIT)`<br>`split(PATTERN, EXPR)`<br>`split(PATTERN)`<br>Splits EXPR into an array of strings and returns them to an array. The PATTERN is the delimiter by which EXPR is separated. If PATTERN is omitted, whitespace is used as the delimiter. LIMIT specifies the number of fields to be split. |
| **sprintf** | `$string=sprintf(FORMAT, LIST)`<br>Returns a string rather than sending output to STDOUT with the same formatting conventions as the printf function.<br>See printf(3). |
| **sqrt** | `sqrt(EXPR)`<br>`sqrt EXPR`<br>Returns the square root of EXPR. If EXPR is omitted, the square root of $_ is returned. |
| **srand** | `srand(EXPR)`<br>`srand EXPR`<br>`srand`<br>Sets the random seed for the rand function. If EXPR is omitted, the seed is the time function.<br>See rand(3). |
| **stat** | `stat(FILEHANDLE)`<br>`stat FILEHANDLE`<br>`stat(EXPR)`<br>Returns a 13-element array consisting of file statistics for `FILEHANDLE` or file named as `EXPR`. The array consists of:<br>- the device<br>- the file inode number<br>- file mode<br>- number of hard links to the file<br>- user ID of owner<br>- group ID of owner<br>- raw device<br>- size of file<br>- file last access time<br>- file last modify time<br>- file last status change time<br>- preferred block size for filesystem I/O<br>- actual number of blocks allocated<br>See stat(2). |
| **study** | `study(SCALAR)`<br>`study SCALAR`<br>`study`<br>Uses a linked-list mechanism to increase efficiency in searching for pattern matches that are to be repeated many times. Can study only one `SCALAR` at a time. If `SCALAR` is omitted, `$_` is used. Most beneficial in loops where many short constant strings are being scanned. |
| **sub** | `sub NAME BLOCK`<br>`sub NAME`<br>`sub BLOCK`<br>`sub NAME PROTO BLOCK`<br>`sub NAME PROTO`<br>`sub PROTO BLOCK`<br>The first two declare the existence of named subroutines and return no value. Without a block, `sub NAME` is a forward declaration. The `sub BLOCK` is used to create an anonymous subroutine. The last three are like the first three, except they allow prototypes to describe how the subroutine will be called. A prototype will notify the compiler that a subroutine definition will appear at some later time and can tell the compiler what type and how many arguments the subroutine expects. For example, `sub foo ($$@)` declares that the subroutine `foo` will take three arguments, two scalars and an array. An error will occur if, for example, fewer than three arguments are passed. |
| **substr** | `substr(EXPR, OFFSET, LENGTH)`<br>`substr(EXPR, OFFSET)`<br>Returns a substring after extracting the substring from **EXPR** starting at position **OFFSET** and, if **LENGTH** is specified, for that many characters from **OFFSET**. If **OFFSET** is negative, starts from the far end of the string. |
| **symlink** | `symlink(OLDFILE, NEWFILE)`<br>Creates a symbolic link. **NEWFILE** is symbolically linked to **OLDFILE**. The files can reside on different partitions.<br>See *symlink*(2). |
| **syscall** | `syscall(LIST)`<br>`syscall LIST`<br>Calls the system call specified as the first element in **LIST**, where the system call is preceded with **&SYS_**, as in **&SYS_system** call. The remaining items in **LIST** are passed as arguments to the system call. Requires *syscall.ph*. |
| **sysopen** | `sysopen(FILEHANDLE, FILENAME, MODE)`<br>`sysopen(FILEHANDLE, FILENAME, MODE, PERMS)`<br>Opens **FILENAME**, using the underlying operating system's version of the *open* call, and assigns it to **FILEHANDLE**. The file modes are system dependent and can be found in the *Fcntl* library module. 0 means read-only, 1 means write-only, and 2 means read/write. If **PERMS** is omitted, the default is 0666.<br>See *open*(2). |
| **sysread** | `sysread(FILEHANDLE, SCALAR, LENGTH, OFFSET)`<br>`sysread(FILEHANDLE, SCALAR, LENGTH)`<br>Reads **LENGTH** bytes into variable **SCALAR** from **FILEHANDLE**. Uses the *read* system call. |
| **sysseek** | `sysseek(FILEHANDLE, POSITION, WHENCE)`<br>Sets **FILEHANDLE**'s system position, using the *lseek* function, bypassing standard I/O. The values of **WHENCE** are 0 to set the new position to **POSITION**, 1 to set it to the current position plus **POSITION**, and 2 to set it to EOF plus **POSITION** (often negative).<br>See *lseek*(2). |
