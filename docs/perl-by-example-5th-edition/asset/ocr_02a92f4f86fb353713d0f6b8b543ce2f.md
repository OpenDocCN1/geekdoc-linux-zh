# **Foreign Keys.** If a primary key is referenced in another table, it is called a foreign key. Foreign keys are used to create relation between tables. In the following example, two tables are described that both reference the *CategoryID* key, although it is primary in one and foreign in the other.

# **EXAMPLE B 30**

# **EXPLANATION**

+   1. The *categories* table has a primary key field called *CategoryID*.
+   2. The *products* table has its own primary key (*ProductID*) in addition to a foreign key called *CategoryID*. If a primary key is referenced in another table, it is called a foreign key.
