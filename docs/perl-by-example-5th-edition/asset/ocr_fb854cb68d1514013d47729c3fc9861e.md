# 10.2.8 Win32 Binary Files

Win32 distinguishes between text and binary files. If AZ is found, the program may abort prematurely or have problems with the newline translation. When reading and writing Win32 binary files, use the binmode function to prevent these problems. The binmode function arranges for a specified filehandle to be read or written to in either binary (raw) or text mode. If the discipline argument is not specified, the mode is set to "raw." The discipline is one of *raw, *crlf, *text, *utf8, *latin1, and so forth.

# FORMAT

```
binmode FILEHANDLE
binmode FILEHANDLE, DISCIPLINE
```

# EXAMPLE 10.19

```
# This script copies one binary file to another.
# Note its use of binmode to set the mode of the filehandle.
use warnings;

$infile="statebar.gif";
open( my $in, "<", $infile ) ;
open( my $out, ">", "outfile.gif" ) ;

binmode( $in ) ; # Crucial for binary files!

binmode( $out ) ;
# binmode should be called after open() but before any I/O
# is done on the filehandle.

while ( read( $in, $buffer, 1024 ) ) {
    print $out $buffer;
}

close( INFILE ) ;
close( OUTFILE ) ;
```

# EXPLANATION

+   1. The scalar $infile is assigned a `gif` filename.
+   2. The file statebar.gif is opened for reading and attached to the $in filehandle.
+   3. The file outfile.gif is opened for writing and assigned to the $out filehandle.
+   4. The binmode function arranges for the input file to be read as binary text.
+   5. The binmode function arranges for the output file to be written as binary text.
+   6. The read function reads 1,024 bytes at a time, storing the input read in the scalar $buffer.
+   7. After the 1,024 bytes are read in, they are sent out to the output file.
+   8. Both filehandles are closed. The result was that one binary file was copied to another binary file.
