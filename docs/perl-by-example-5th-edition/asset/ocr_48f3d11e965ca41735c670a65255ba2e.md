# EXAMPLE 9.7

```
(The Script)
use warnings;
# The \d metasymbol
while (<DATA>){
    print if /6\d\d/
}
__DATA__
Steve Blenheim 101
Betty Boop 201
Igor Chevsky 301
Norma Cord 401
Jonathan DeLoach 501
Karen Evich 601
(Output)
Karen Evich 601
```

# EXPLANATION

2 The line `$_` is printed only if it contains a pattern matching the number 6, followed by two single digits. The metasymbol \d represents the character class [0-9].

# EXAMPLE 9.8

```
(The Script)
use warnings;
# The \D metasymbol
while (<DATA>){
    print if /[ABC]\D/
}
__DATA__
Steve Blenheim 101
Betty Boop 201
Igor Chevsky 301
Norma Cord 401
Jonathan DeLoach 501
Karen Evich 601
(Output)
Steve Blenheim 101
Betty Boop 201
Igor Chevsky 301
Norma Cord 401
```

# EXPLANATION

2 The line `$_` is printed only if `$_` contains a pattern matching an uppercase A, B, or C `[ABC]`, followed by one single nondigit, \D. The metasymbol \D represents the character class [^0-9]; that is, a number not in the range between 0 and 9.
