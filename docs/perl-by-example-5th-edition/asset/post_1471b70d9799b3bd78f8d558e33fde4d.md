## 2.1 Quick Start, Quick Reference

The following reference gives you a general overview of Perl constructs and syntax. It can be used later as a cheat sheet to help you quickly refresh your memory without searching through chapters for a simple concept.

### 2.1.1 A Note to Programmers

If you have had previous programming experience in another language (such as Visual Basic, C/C++, C#, Java, Python, or PHP), and you are familiar with basic concepts (such as variables, loops, conditional statements, and functions), Table 2.1 will give you a quick overview of the constructs and syntax of the Perl language.

At the end of each section, you will be given the chapter number that describes the particular construct and a short, fully functional Perl example designed to illustrate how that construct is used.

### 2.1.2 A Note to Non-Programmers

If you are not familiar with programming, skip this chapter and go to Chapter 5, “What’s in a Name?” You may want to refer to this chapter later for a quick reference.

### 2.1.3 Perl Syntax and Constructs

Table 2.1 summarizes the Perl concepts discussed throughout this book. If applicable, cross-references are given, as to where you can read further on these topics.

| **The Script File** | A Perl script is created in a text editor. Normally, there is no special extension required in the filename, unless specified by the application running the script (for example, if running under Apache as a cgi program, the filename may require a .pl or .cgi extension). <br><br> See Chapter 3, “Perl Scripts.” |
| **Comments** | Perl comments are preceded by a # sign. They are ignored by the interpreter. They can be anywhere on the line and span only one line. <br><br> See Section 3.3.2, “Comments.” <br><br> **EXAMPLE** <br> `print "Hello, world"; # This is a comment` <br> `# And this is a comment` |

| **Printing Output** | The print, say, and printf functions are built-in functions used to display output. The print function arguments consist of a comma-separated list of strings and/or numbers. <br><br> The say function (Perl 5.10.1) is the same as the print function except it automatically appends a newline at the end of the string. <br><br> The printf function is similar to the C printf() function and is used for formatting output. Parentheses are not required around the argument list. <br><br> See Chapter 4, “Getting a Handle on Printing.” <br><br> **FORMAT** <br> `print value, value, value;` <br> `printf ( string format [, mixed args [, mixed …]]);` <br><br> **EXAMPLE** <br> `use v5.10;       # To enable say function` <br> `print "Hello, world\n";` <br> `print "Hello," , " world\n";` <br> `say "Hello," , " world";    # adds a newline; new feature` <br> `# in version 5.10.1` <br> `print ("It’s such a perfect day!\n"); # Parens optional` <br> `print "The date and time are: ", scalar localtime, "\n";` <br> `print "Meet Katie $4$$alary $$10.2F\n", "John", 40, 55000;  # formatting strings and numbers` |

| **Variables** | Perl supports three basic variable types: scalars, arrays, and hashes (associative arrays). Perl does not have a native Boolean data type such as true or false, but does comparison with strings and integers to get the same behavior. <br><br> Perl variables don’t have to be declared before being used. <br><br> Variable names start with a “funny character” (also called a sigil) followed by a letter and any number of alphanumeric characters (the identifier), including the underscore. The funny character represents the data type and context. The characters following the funny symbol are case-sensitive. <br><br> If a variable name starts with a letter, it may consist of any number of letters (an underscore counts as a letter) and/or digits. If the variable does not start with a letter, it must consist of only one character. <br><br> See Chapter 5, “What’s in a Name?” |
| **Scalar** | A scalar variable holds a single value, a single string, a number, and so forth. <br><br> The name of the scalar variable is preceded by a `$` sign. Scalar context means that *one value* is being used. <br><br> See Chapter 5, “What’s in a Name?” <br><br> **EXAMPLE** <br> `$first_name = "Melanie";` <br> `$last_name = "Quigley";` <br> `$salary = 125000.00;` <br> `print $first_name, $last_name, $salary;` |
| **Array** | An array holds an *ordered list* of scalars; that is, strings and/or numbers. The elements of the array are indexed by integers starting at 0. The name of the array is preceded by an `@` sign. <br><br> Some commonly used built-in array functions: <br> - `delete` removes a value from an element of the array <br> - `pop` removes last element <br> - `push` adds new elements to the end of the array <br> - `shift` removes first element <br> - `sort` sorts the elements of an array <br> - `splice` removes or adds elements from some position in the array <br> - `unshift` adds new elements to the beginning of the array <br><br> See Section 5.3, “Array Functions.” <br><br> **EXAMPLE** <br> `@names = ( "Jessica", "Michele", "Linda" );` <br> `print "@names"; # Prints array with elements separated by a space` <br> `print "@names[0] and @names[2]"; # Prints "Jessica" and "Linda"` <br> `print "$names[-1]\n"; # Prints "Linda"` <br> `$names[3]="Nicole"; # Assign a new value as the 4th element` |
| **Hash** | An associative array, called a *hash*, is an unordered list of key/value pairs, indexed by strings. The name of the hash is preceded by a `%` symbol. (The `%` is not evaluated when enclosed in either single or double quotes.) The keys *do not have to be quoted* as long as they don't begin with a number or contain spaces, internal hyphens, or special characters. <br><br> Some commonly used built-in hash functions: <br> - `keys` retrieves all the keys in a hash <br> - `values` retrieves all the values in a hash <br> - `each` retrieves a key/value pair from a hash <br> - `delete` removes a key/value pair <br> - `exists` tests existence of key <br><br> See Section 5.4, “Hash (Associative Array) Functions.” <br><br> **EXAMPLE** <br> `%employee = (` <br> `    "Name"    => "Jessica Savage",` <br> `    "Phone"   => "(925) 555-1274",` <br> `    "Position" => "CEO"` <br> `);` <br> `print "$employee{Name}";  # Print a value` <br> `$employee{"SSN"}="999-333-2345";  # Assign a key/value` |
| **Predefined Variables** | Perl provides a large number of predefined variables. The following is a list of some common predefined variables: <br> - `$_.` The default input and pattern-searching space. <br> - `$_`. Current line number for the last filename accessed. <br> - `$@`. The Perl syntax error message from the last `eval()` operator. <br> - `$!`. Yields the current value of the error message, used with `die`. <br> - `$0`. Contains the name of the program being executed. <br> - `$$`. The process number of the Perl running this script. <br> - `@ARGV`. Contains the command-line arguments. <br> - `ARGV`. A special filename that iterates over command-line filenames in `@ARGV`. <br> - `@INC`. The search path for library files. <br> - `@_`. Within a subroutine, the array `@_` contains the parameters passed to that subroutine. <br> - `%ENV`. The hash `%ENV` contains your current environment. <br> - `%SIG`. The hash `%SIG`, when set, contains signal handlers for signals. <br><br> See Section A.2, “Special Variables,” in Appendix A. |
| **Constants (Literals)** | A constant value, once set, cannot be modified. An example of a constant is `Pi` or the number of feet in a mile. It doesn't change. Constants are defined with the `constant` pragma, shown as follows in the example. |
