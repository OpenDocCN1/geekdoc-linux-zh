# EXPLANATION

+   1. A *SIGALRM* signal will be sent to this process after 1 second.
+   2. This statement is printed.
+   3. The loop starts. We wait for 1 second. The resolution on the actual second may be off. You can use the *syscall* function to call other functions, such as *settimer* (2) and *gettimer* (2), with better timing resolution.
+   4. When the alarm goes off, the message *Alarm Clock* is printed.

**The *sleep* function.** The *sleep* function causes the process to pause for a number of seconds or forever if a number of seconds is not specified. It returns the number of seconds that the process slept. You can use the *alarm* function to interrupt the *sleep*.

# FORMAT

```
sleep(SECONDS);
sleep SECONDS;
sleep;
```

# EXAMPLE 16.71

```
(The Script)
use warnings;
1 $|=1       # flush output buffer
2 alarm(5);
  print "Taking a snooze...\n";
3 sleep 100;
4 print "\07 Wake up now.\n";

(Output)
2 Taking a snooze...    # Program pauses now for 5 seconds
4 (Beep) Wake up now.
```

# EXPLANATION

+   1. The `$|` variable forces the output buffer to be flushed after it writes and prints.
+   2. The *alarm* function tells the kernel to send a *SIGALRM* signal to the process in 5 seconds.
+   3. The process goes to sleep for 100 seconds or until a signal is sent to it.
+   4. The `\07` causes a beep to sound before the statement *Wake up now!*
