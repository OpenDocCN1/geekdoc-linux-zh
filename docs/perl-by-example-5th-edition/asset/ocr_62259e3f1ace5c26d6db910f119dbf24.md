Table A.1 Perl Functions (continued)

| Function | Description |
| :--- | :--- |
| *semop* | `semop(KEY, OPSTRING)` <br> Calls the *semop* system call to perform operations on a semaphore identified by *KEY*. *OPSTRING* must be a packed array of *semop* structures. Requires library files `ipc.ph` and `sem.ph`. <br> See System V IPC. <br> See also `semop(2)`. |
| *send* | `send(SOCKET, MSG, FLAGS, TO)` <br> `send(SOCKET, MSG, FLAGS)` <br> Sends a message on a *SOCKET*. <br> See `send(2)`. |
| *setpgrp* | `setpgrp(PID, PGID)` <br> Sets the current process group for the specified process, process group, or user. <br> See `getpgrp(2)`. |
| *setpriority* | `setpriority(WHICH, WHO, PRIORITY)` <br> Sets the current priority, *nice* value, for a process, process group, or user. <br> See `getpriority(2)`. |
| *setsockopt* | `setsockopt(SOCKET, LEVEL, OPTNAME, OPTVAL)` <br> Sets the requested socket option on *SOCKET*. <br> See `getsockopt(2)`. |
| *shift* | `shift(ARRAY)` <br> `shift ARRAY` <br> Shifts off the first value of the *ARRAY* and returns it, shortening the array. <br> If *ARRAY* is omitted, the `@ARGV` array is shifted, and if in subroutines, the `@_` array is shifted. |
| *shmctl* | `shmctl(ID, CMD, ARG)` <br> Calls the *shmctl* system call, allowing control operations on shared memory. <br> Has weird return codes. Requires library file `ipc.ph` and `shm.ph`. <br> See System V IPC. <br> See also `shmctl(2)`. |
| *shmget* | `shmget(KEY, SIZE, FLAGS)` <br> Returns the shared memory segment ID associated with the *KEY*, or undefined if an error. The shared memory segment created is of at least *SIZE* bytes. <br> Requires `ipc.ph` and `shm.ph`. <br> See System V IPC. <br> See also `shmget(2)`. |
