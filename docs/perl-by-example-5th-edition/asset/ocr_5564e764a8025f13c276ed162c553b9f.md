6  We can explicitly specify the method to be used for reading and writing. In this example, we are making the accessor publicly readable, but not writeable. If the user wants to set or change the price, he will have to call the _set_price method provided for the attribute.

8  As stated earlier, Moose doesn't force you to use the attributes as accessors. You can create your own accessor methods just as you have done before you used Moose.
