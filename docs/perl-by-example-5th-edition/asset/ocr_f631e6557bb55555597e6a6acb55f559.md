# EXPLANATION

+   1 The /etc/passwd file is attached to the README filehandle and opened for reading.
+   2 The read subroutine is called. The filehandle is passed by creating a reference to a typeglob. First, the filehandle symbol is globbed with the asterisk. Then, the reference to the typeglob is created by prefixing the typeglob with a backslash.
+   3 The read subroutine is defined.
+   4 The @_ variable contains the reference. It is assigned to a local scalar variable called $passwd. $passwd is a reference to the filehandle.
