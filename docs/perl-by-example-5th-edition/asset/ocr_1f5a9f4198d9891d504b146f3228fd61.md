(nonzero), the value of the expression is returned. If the value on the left-hand side of the || is false, the value of the expression on the right-hand side of the operator is evaluated, and its value is returned.

A list of logical operators is shown in Table 6.8.

# Table 6.8 Logical Operators (Short-Circuit Operators)

| Operator | Alternative Form | Example | Meaning |
| :--- | :--- | :--- | :--- |
| && | and | $x && $y | If $x is true, evaluate $y and return $y |
| | | $x and $y | If $x is false, evaluate $x and return $x |
| || | or | $x || $y | If $x is true, evaluate $x and return $x |
| | | $x or $y | If $x is false, evaluate $y and return $y |
| xor | | $x xor $y | True if $x or $y is true, but not both |
| ! | not | ! $x | Not $x; true if $x is not true, false if $x is true; returns 1 or 0 |
| | | not $x | Same as ! $x |
