# 11.2.4 Scoping Operators: local, my, our, and state

Most programming languages provide a way for you to pass arguments by using **call-by-value**, where a copy of the value of the argument is received by the subroutine. If the copy is modified, the original value is untouched. To make copies of values in Perl, the arguments are copied from the `@_` array and assigned to local variables.
