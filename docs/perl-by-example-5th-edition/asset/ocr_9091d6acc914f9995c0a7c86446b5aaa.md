# **EXPLANATION**

1 This file does not start with <i>&lt;html&gt;</i> or <i>&lt;!DOCTYPE&gt;</i>. Instead, it starts with <i>&lt;div&gt;</i>. The file will be imported into <i>views/layout/main.tt</i>, and so it only needs to contain the HTML specific to the student list page. It is <i>main.tt</i> that contains the <i>DOCTYPE</i> and <i>&lt;html&gt;</i> element. This allows us to create new pages while keeping a consistent theme and framing for them.

2 By keeping some of the original HTML, the need to do many extra styling can be avoided. We will keep the <i>content</i> <i>div</i> and the <i>header</i> <i>div</i> inside it, and this will make the new page look similar to the old one.

3 A new <i>div</i> is made whose <i>ID</i> is <i>students</i>. Later, we can style this with <i>CSS</i> if we want to.

4 *Template::Toolkit* defines the *FOREACH* directive, which acts just like a <i>foreach</i> loop in Perl with a different syntax; for example, *IN* is used instead of the parentheses in Perl syntax. <i>Template::Toolkit</i> expects <i>students</i> to be an *arrayref* and iterates over it, assigning each element in turn to the <i>student</i> variable. <i>Dancer</i> configures <i>Template::Toolkit</i> with the <i>&lt;$ %$&gt;</i> syntax to identify template areas; everything else is output as plain text.

5 This is the first line of the <i>FOREACH</i> loop body. It defines an <i>&lt;h2&gt;</i>. This line will be output once for each student in the <i>students</i> array.
