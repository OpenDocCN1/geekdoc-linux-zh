**Getting a Password Entry (UNIX)—The *getpwent* Function.** The *getpwent* function retrieves information from the */etc/passwd* file. The return value from *getpwent* is a nine-element array consisting of:

+   1. Login name
+   2. Encrypted password
+   3. User ID
+   4. Group ID
+   5. Quota
+   6. Comment
+   7. Gcos (user information)
+   8. Home directory
+   9. Login shell

```
**FORMAT**

$(name, $passwd, $uid, $gid, $quota, $comment, $gcos, $dir,
$shell) = getpwent;
```
