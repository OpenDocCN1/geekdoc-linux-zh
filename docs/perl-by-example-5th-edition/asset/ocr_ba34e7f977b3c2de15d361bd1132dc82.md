# Table A.1 **Perl Functions (continued)**

| Function | Description |
| :--- | :--- |
| *substr* | `substr(EXPR, OFFSET, LENGTH)`<br>`substr(EXPR, OFFSET)`<br>Returns a substring after extracting the substring from **EXPR** starting at position **OFFSET** and, if **LENGTH** is specified, for that many characters from **OFFSET**. If **OFFSET** is negative, starts from the far end of the string. |
| *symlink* | `symlink(OLDFILE, NEWFILE)`<br>Creates a symbolic link. **NEWFILE** is symbolically linked to **OLDFILE**. The files can reside on different partitions.<br>See *symlink*(2). |
| *syscall* | `syscall(LIST)`<br>`syscall LIST`<br>Calls the system call specified as the first element in **LIST**, where the system call is preceded with **&SYS_**, as in **&SYS_system** call. The remaining items in **LIST** are passed as arguments to the system call. Requires *syscall.ph*. |
| *sysopen* | `sysopen(FILEHANDLE, FILENAME, MODE)`<br>`sysopen(FILEHANDLE, FILENAME, MODE, PERMS)`<br>Opens **FILENAME**, using the underlying operating system's version of the *open* call, and assigns it to **FILEHANDLE**. The file modes are system dependent and can be found in the *Fcntl* library module. 0 means read-only, 1 means write-only, and 2 means read/write. If **PERMS** is omitted, the default is 0666.<br>See *open*(2). |
| *sysread* | `sysread(FILEHANDLE, SCALAR, LENGTH, OFFSET)`<br>`sysread(FILEHANDLE, SCALAR, LENGTH)`<br>Reads **LENGTH** bytes into variable **SCALAR** from **FILEHANDLE**. Uses the *read* system call. |
| *sysseek* | `sysseek(FILEHANDLE, POSITION, WHENCE)`<br>Sets **FILEHANDLE**'s system position, using the *lseek* function, bypassing standard I/O. The values of **WHENCE** are 0 to set the new position to **POSITION**, 1 to set it to the current position plus **POSITION**, and 2 to set it to EOF plus **POSITION** (often negative).<br>See *lseek*(2). |
