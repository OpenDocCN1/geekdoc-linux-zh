# 13.2.5 How to "Use" a Module from the Standard Perl Library

The following example demonstrates how to use the Carp.pm module from the standard Perl library. The first step in using a module is to read the documentation. Use the perldoc command to do this.

The use directive makes sure the requested module is loaded at compile time. If there is a list following the module name, that list represents symbols that will be exported from the module to be used (imported) in your program. In the Carp.pm module, one of the functions is called croak. If requested, the user can call the croak function without fully qualifying the symbol name with the :: syntax (Carp::croak).
