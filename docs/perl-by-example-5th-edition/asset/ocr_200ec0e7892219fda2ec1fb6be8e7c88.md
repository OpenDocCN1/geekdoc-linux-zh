# EXAMPLE 10.24

```
(The Text File: *db*)
Steve Blenheim
Betty Boop
Lori Gartz
Sir Lancelot
Norma Cord
Jon Delosch
Karen Eviach
--- --- --- --- --- --- --- --- ---

(The Script)
use warnings;
# Example using the *seek* function
open(my $fh, *<*, *db*) or die "Can\t open: $!\n";
while(<$line=<$fh>) { # Loop through the whole file
if ($line = /"Lori/) { print "--$line--\n";}
}
*seek($fh, 0, 0); # Start at the beginning of the file*
while(<$fh>) {
print if /Steve/;
}
close $fh;

(Output)
--Lori Gartz--
Steve Blenheim
```

# EXPLANATION

+   The *db* file is assigned to the $fh filehandle and opened for reading.
+   Each line of the file is assigned, in turn, to the scalar $line while looping through the file.
+   If $line begins with *Lori*, the print statement is executed.
+   *seek* function causes the file pointer to be positioned at the top of the file (position 0) and starts reading at byte 0, the first character. If you want to get back to the top of the file without using *seek*, the filehandle must first be explicitly closed with the *close* function.
+   Starting at the top of the file, the loop is entered. The first line is read from the file-handle and assigned to $_, the default file holder.
+   If the pattern *Steve* is found in $ the line will be printed.
