# EXPLANATION

+   1 The SELECT statement retrieves all values in the name field from the table called teams.
+   
+   2 The DELETE statement deletes a row in the name field if the name of the team is Bath Warships.
+   
+   3 This SELECT statement retrieves all values in the name field, showing us that the Bath Warships team was deleted in the previous DELETE statement.

**Updating Data in a Table.** The UPDATE command is used to edit a table; that is, to modify or change the values in a table. This statement uses the SET clause to change the existing value to something else, as shown in the following example.

# EXAMPLE 15.16

```
```
mysql> SELECT * FROM teams;

+----------------+-----+--------+
| name           | wins | losses |
+----------------+-----+--------+
| Fremont Tigers |  24 |     26 |
| Chico Hardhats |  19 |     25 |
| Bath Warships  |  32 |      3 |
| Bangor Rams    |  22 |     24 |

4 rows in set (0.00 sec)

mysql> UPDATE teams SET wins=wins + 2 WHERE name="Chico Hardhats";
Query OK, 1 row affected (0.02 sec)
Rows matched: 1  Changed: 1  Warnings: 0

mysql> UPDATE teams SET name="Bath Destroyers"
    ->   WHERE name="Bath Warships";
