# The phpMyAdmin Tool

The phpMyAdmin tool (see Figure 15.17) is written in PHP to handle the administration of MySQL over the Web. It is used to create and drop databases, manipulate tables and fields, execute SQL statements, manage keys on fields, manage privileges, and export data into various formats. You can download it from http://www.phpmyadmin.net/home_ page/index.php.
