# EXPLANATION

+   1. Perl 5.6.0 (and above) is needed to use the POSIX character class. (By now everyone should have a version of Perl higher than 5.6.0)
+       2. The special DATA filehandle gets its input from the text after the _ _DATA_ _ token. The *while* loop is entered and the first line after the _ _DATA_ _ token is read in and assigned to $ _ . Each time the loop is entered, the next line following _ _DATA_ _ is assigned to $ _ until all the lines have been processed.
+       3. The regular expression contains POSIX character classes. The line is printed if $ _ contains one uppercase letter, *[[upper]]* , followed by one or more (+) alphabetic characters, *[[alpha]]* , a space, *[[ \s ]]* , followed by an uppercase letter, and one or more lowercase alphabetic characters, *[[lower]]* . (The + is a regular expression metacharacter representing one or more of the previous characters.) The line *joe bhow* does not match this pattern.
