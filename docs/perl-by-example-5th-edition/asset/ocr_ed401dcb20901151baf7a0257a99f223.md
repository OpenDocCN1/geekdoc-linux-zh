When we speak about reading a directory with the `readdir` function, we are talking about looking at the contents of the directory structure maintained by the system. If the `opendir` function opened the directory, in a scalar context, `readdir` returns the **next** directory entry. In an array context, it returns the rest of the entries in the directory.

# **FORMAT**

```
```perl
readdir(DIRHANDLE);
readdir DIRHANDLE;
```
```

**The `closedir` Function.** The `closedir` function closes the directory that was opened by the `opendir` function.

# **FORMAT**

```
```perl
closedir (DIRHANDLE);
closedir DIRHANDLE;
```
```

# **EXAMPLE 16.11**

```
```perl
# (The Script)
use warnings;
1 opendir(DIR, '..') || die "Can't open: $\n";
2 my @parentfiles=readdir(DIR);    # Open parent directory
                                    # Gets a list of the directory contents
3 closedir(DIR);                    # Closes the filehandle
4 foreach my $file ( @parentfiles ) # Prints each element of the array
   { print "$file\n";}
```
```

```
```text
# (Output)
.
..`
files
filesb
filex
.sh_history
stories```
```

# **EXPLANATION**

+   1.  The `opendir` function opens the directory structure and assigns it to `DIR`, the directory filehandle. The .. (parent) directory is opened for reading.
+   2.  The `readdir` function assigns all the rest of the entries in the directory to the array `@parentfiles`.
+   3.  The `closedir` function closes the directory.
+   4.  The files are printed in the order in which they are stored in the directory structure. This may not be the order that the `ls` command prints out the files.
