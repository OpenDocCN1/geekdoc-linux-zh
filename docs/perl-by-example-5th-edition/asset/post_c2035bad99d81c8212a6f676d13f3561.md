## EXAMPLE 14.20

```perl
# Module Employee.pm
# The Base Class
package Employee;
use strict;
use warnings;
# Constructor method
sub init {
  my $Class = shift;
  my $info = @_;
  my $self = {
    _Name=>$info{"_Name"},
    _StartDate=>$info{"_StartDate"},
    _BasePay=>$info{"_BasePay"},
  };
  return bless($self, $Class);
}
# Some instance methods
sub get_name{
  my $self=shift;
  return $self->{_Name};
}
sub get_startdate{
  my $self=shift;
  return $self->{_StartDate};
}
sub get_basepay{
  my $self=shift;
  return $self->{_BasePay};
}
1;
```

## EXPLANATION

- *Employee* is the base class in a file called *Employee.pm*.
- The `init` method is a constructor. It sets properties for all employees.
- The first argument is the class name from which the method was called.
- The information being passed in from the caller of this function is a hash of key/value pairs.
- The values in the `%info` hash are assigned as the employee's properties.
- The new employee referent is blessed into the class that called this subroutine (its name was passed in as the first argument).

## EXAMPLE 14.21

```perl
package Salesman;
   use lib("/usr/local/bin/baseclass"); # Update @INC
   use v5.10.0;
   use feature qw(state say);
   use base qw(Employee); # Updates @ISA
   use strict;
   use warnings;
   sub count_salesman { # Class method
      state $counter=0;
      $counter++;
      return $counter;
    }
   sub new { # Constructor for Salesman
     my ($class)= shift;
     my $data=@_;
     my %emp = $class->init("_Name"=>$data{_Name},
                              "_StartDate"=>$data{_StartDate},
                              "_BasePay"=>$data{_BasePay},
                              );
     $emp->{"_AnnualSales"}=$data{"_AnnualSales"};
     $emp->{"_Commission"}=$data{"_Commission"};
     say "This is $emp->{_Name}, salesman #", count_salesman();
     return $emp;
   }
   sub calculate_pay{
     my $self=shift;
     my $rate = $self->{"_Commission"};
     my $sales = $self->{"_AnnualSales"};
     my $base = $self->{"_BasePay"};
     my $pay = $sales * $rate + $base;
     return $pay;
   }
   sub DESTROY{
     my $self=shift;
     print "$self->{_Name} is leaving the firm.\n";
   }
```

## EXPLANATION

- The *Salesman* class is declared in *Salesman.pm*.
- The *base* module updates the *@ISA* array and loads the *Employee.pm* module. Another way to update *@ISA* is to say:
  ```perl
  push(@ISA, "Employee");
  use Employee;
  ```
  If using version 5.16 and above, you can say:
  ```perl
  use parent Employee;
  ```
- The counter subroutine will keep track of the number of salesmen created. It uses the *state* feature to allow the *$counter* variable to retain its value from one call to the next; meaning, it does not reset the variable to zero each time the function is called. This is a class function as it is specific to the class as a whole and does not take a reference to an object as its first argument.
- The constructor method for the *Salesman* class is defined.
- Here we see inheritance being used when calling the *init* method which is defined in the *Employee* class (see *Employee.pm*), not in the current *Salesman* class. When *init* is called, Perl will look in the current *Salesman* class first, and since it is not defined there, will then look in the *@ISA* array to see if it is listed there. It is. Note that the class name being sent to the *Employee::init()* function is *Salesman* (meaning, in the *Employee* class the blessing will bless the object into the *Salesman* class, not the *Employee* class). The remaining arguments are the properties for any *Employee*. A blessed reference to a new *Salesman* object is returned.
- Now the blessed salesman will get additional properties that further define all salesmen.
- Each time a new *Salesman* object is created, the *count_salesman* function is called. It is a class function and does not require a reference to the object.
- An access method, *calculate_pay*, is defined for the *Salesman*.
- The first argument is a reference to the object implicitly sent by Perl when the function is called.
- The *DESTROY* method is called each time an object goes out of scope, usually when the program ends.

## EXAMPLE 14.22

```perl
package Teacher;
use v5.10.0;
use strict;
use warnings;
use feature qw(state say);
# our @ISA=qw(Employee);
use Employee;
my $tracker;

sub count_teacher { # Class method
state $counter=0;
$counter++;
return $counter;
}
sub new { # Constructor for Teacher
my ($class)= shift;
my $data=@_;
my $emp = $class->init("_Name"=>$data{_Name},
"_StartDate"=>$data{_StartDate},
"_BasePay"=>$data{_BasePay},
);
$tracker=count_teacher();
return $emp;
}
sub set_courses{
my $self=shift;
my $ctr=shift;
$self->{"_courses"}=$ctr;
}
sub get_courses{
my $self=shift;
return "@{$self->{ '_courses'}}";
}
END{
print "${tracker} teachers were created.\n";
}
```

## EXPLANATION

- The *Teacher* class is defined here.
- In this module, the *@ISA* is updated directly rather than by using the *base.pm* or *parent.pm* pragmas. The name of the base class is listed so that the subclass, *Teacher*, can inherit from it. Not only does the *@ISA* array need to be updated, but the *use* directive must name the base class and load it. This is done automatically when you say *use parent* or *use base*.
- This class function will track the number of new *Teacher* objects added to the class.
- The *new()* constructor method for the teacher defines the properties for the teacher as a hash and returns a blessed teacher reference.
- Like the *Salesman* class described previously, the *Teacher* inherits from the *Employee* class and calls its *init()* method. The *init()* constructor in the *Employee* class will then assign the basic properties for an *Employee* and return a blessed *Teacher* object.
- The teacher object is sent to the *set_courses()* method along with a reference to a list of courses. These courses will be set as a new attribute to the object.
- The *get_courses()* method will retrieve and send back the list of the teacher's courses by dereferencing the pointer, *$self->{_courses}*.
- When the program is ready to exit, the special `END` subroutine prints out the number of `Teacher` objects that were created. This works better than using the DESTROY method because the DESTROY method would print on the message whenever a teacher object goes out of scope, so that if you had created six teacher objects, the message would print six times.

## EXAMPLE 14.23

```perl
# The Driver (user) Program
use Salesman;
use Teacher;
use Data::Dumper;
use strict;
use warnings;

my $salesguy1 = Salesman->new(
    "Name" => "Nicky McDonald",
    "StartDate" => "12/12/2010",
    "BasePay" => 25000,
    "AnnualSales" => 1200,
    "Commission" => 0.05,
);

my $pay = $salesguy1->calculate_pay();
printf "$salesguy1->{_Name} made \$%.2f last year.\n\n", $pay;

my $salesguy2 = Salesman->new(
    "Name" => "Rick Gonzales",
    "StartDate" => "12/12/2010",
    "BasePay" => 80000,
    "AnnualSales" => 2200,
    "Commission" => 0.08,
);

my $pay = $salesguy2->calculate_pay();
printf "$salesguy2->{_Name} made \$%.2f last year.\n\n", $pay;

my $teacher = Teacher->new(
    "Name" => "Charles Lee",
    "StartDate" => "08/12/2013",
    "BasePay" => 55000,
);

$teacher->set_courses([
    "Basic Math", "Algebra", "Calculus"]);
# Pass ref to Array of courses

print $teacher->get_name(),"\n";        # Inheritance
print $teacher->get_start_date(),"\n";   # Inheritance
print $teacher->get_basepay(),"\n";       # Inheritance
print $teacher->get_courses(),"\n";       # Teacher's access method

$Data::Dumper::Varname = "employee";     # Give Dumper a user-defined
                                        # variable name

print Dumper($salesguy1, $teacher);      # Dump out data for two objects
```
