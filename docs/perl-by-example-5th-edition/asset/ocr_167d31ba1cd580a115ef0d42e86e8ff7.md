+   1. A user-defined function called get_wins will be used to handle the database requests.
+   2. The @\_ contains two values, the database handle and the name of a team in the database.

For repeating the same query many times, this is done to make the processing more efficient. Since this function may be called a number of times, the prepare_cache() method is used.
