# 14.5.1 pod Files

If you look in the standard Perl library, you will find that the modules contain documentation explaining what the module is supposed to do and how to use it. (At the command line, type `perldoc perlpod`.) The documentation is either embedded within the program or placed at the end of the program right after the special literal `_END_`. This documentation is called pod, short for Plain Old Documentation. A pod file is just an ASCII, utf-8, Unicode text file embedded with special commands that can be translated by one of Perl’s special interpreters, `pod2html`, `pod2latex`, `pod2text`, or `pod2man`.
