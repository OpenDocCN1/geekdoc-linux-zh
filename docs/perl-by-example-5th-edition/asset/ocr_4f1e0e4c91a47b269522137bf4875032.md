# Using Data::Dumper

Now that we are getting ready to create more complex data structures with Perl references, this is a good time to take a moment to talk about the *Data::Dumper* module. This module, found in the standard Perl library, makes it easy for you to see the contents of nested hashes, arrays, and combinations of these.

# EXAMPLE 12.5

```
1  use Data::Dumper;
2  use warnings;
3  use strict;
4  my $student = ( "Name"=>"Tom Jones",
5        "Subject"=>"Algebra",
6        "Major"=>"Math"
7  );
8  
9  my $ref = \$student;  # A reference to a hash
10 
11 print Dumper $ref;  # The Dumper function dumps out the hash
12
13 $Data::Dumper::Varname ="student";  # Varname is a user-defined value
14 print Dumper \$student;  # Dumper requires a reference

(Output)
$VAR1 = {
  'Subject' => 'Algebra',
  'Major' => 'Math',
  'Name' => 'Tom Jones'
};
$student1 = {
  'Subject' => 'Algebra',
  'Major' => 'Math',
  'Name' => 'Tom Jones'
};
```

# EXPLANATION

+   1. This loads the *Data::Dumper* module into the program's memory.
+   2. Now we create a simple hash.
+   3. The address of the hash is assigned to *$ref*, a reference.
+   4. The *Dumper* function from the *Data::Dumper* module takes a pointer and dumps out a string displaying the structure of the hash.
+   5. There are different ways to change the appearance of the data structure; for example, you can change the *$VAR1* variable to another name, change the amount of indentation, and so forth. Here, we change *$Varname* to *student* to clarify what data structure we are displaying.
+   6. The output of *Dumper* now shows the hash with its name *student*. The *1* appended to the student name means that we only have one of these students defined.
