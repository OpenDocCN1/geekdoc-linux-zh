| Table 8.3 | Pattern Matching Operators with Substitution |
| --- | --- |
| Example | Meaning |
| $name = s/john/Sam/ | Replace first occurrence of John with Sam. |
| $name =~ s/john/Sam/g | Replace all occurrences of John with Sam. |

Instead of

$._ = "John";

we will use a named variable

$name = "John";

Then if a substitution is performed on $name instead of $._, as in

print if s/john/Sam/;

you would write

print if $name =- s/john/Sam/;
