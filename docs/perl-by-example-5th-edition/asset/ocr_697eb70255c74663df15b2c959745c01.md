# **EXAMPLE 16.17**

```
```
1	(The Script)
2	unlink('*', 'b', 'c') || die "remove: $!\n";
3	$count=unlink <*.c>;
4	print "The number of files removed was $count\n";
```
```

# **EXPLANATION**

+   1. The files *a*, *b*, and *c* are removed.
+   2. Any files ending in *.c* (C source files) are removed. The number of files removed is stored in the scalar `$count`.

The *symlink* and *readlink* functions (UNIX). The *symlink* function creates a symbolic link. The symbolic link file is the name of the file that is accessed if the old filename is referenced.

# **FORMAT**

```
```
symlink(OLDFILE, NEWFILE)
```
```

# **EXAMPLE 16.18**

```
```
1	$ perl -e 'symlink("/home/jody/test/old", "new");'
2	$ ls -ld new
3	lrwxrwxrwx 1 ellie 8 Feb 22 17:32 new -> /home/jody/test/old
```
```

# **EXPLANATION**

+   1. The *symlink* function creates a new filename, *new*, linked to the old filename, */home/jody/test/old*.
+   2. The *ls -ld* command lists the symbolically linked file. The symbol *->* points to the new filename. The *l* preceding the permissions also indicates a symbolic link file.

The *readlink* function returns the value of the symbolic link and is undefined if the file is not a symbolic link.
