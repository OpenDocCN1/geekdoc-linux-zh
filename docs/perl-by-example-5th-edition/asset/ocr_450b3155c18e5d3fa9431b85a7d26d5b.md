# EXAMPLE 16.25

(Script)

```
1  $string=pack("A15A3", "hey",$you);   # ASCII string, space padded
2  print $string;
```

(Output)

```
2  hey      you
```

# EXPLANATION

+   1. Two strings, hey and you, are packed into a structure using the template A15A3. A15 will convert the string hey into a space-padded ASCII string consisting of 15 characters. A3 converts the string you into a 3-character space-padded string.
+   2. The strings are printed according to the pack formatting template. They are left justified.
