Astute readers will have realized that if a query is run that returns no results, the page is returned normally, but no students in it. This differs from the previous example, wherein if the student was not found, a 404 error was returned.

The difference lies in the consideration of **resources**. This same consideration determines whether you want to use the path form of parameterization or the query form. In the first example, the student's ID number was part of the URL's path. That means that the student whose ID is 123 is a **separate resource** from the student whose ID number is 124—a different path represents a different resource.
