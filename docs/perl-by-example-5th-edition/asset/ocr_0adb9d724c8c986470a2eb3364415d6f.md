# 6.3.11 Bitwise Logical Operators

**A Little Bit About Bits.** People represent numbers in decimal, or base 10, a numbering system based on 10 values starting from 0 to 9; for example, $100,000 and 1955. The HTML color codes are represented in hexadecimal, base 16, values ranging from 0 to 15; for example, #00FFFF is cyan and #FF00FF is fuchsia.

Computers, on the other hand, store everything in binary, or base 2. A binary numbering system represents numbers in two values, 0 or 1. Each of the individual 1s and 0s are called bits. All the data you use is stored in your computer using bits.
