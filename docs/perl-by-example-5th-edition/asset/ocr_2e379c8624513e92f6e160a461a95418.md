# The subs module
use warnings;
use subs qw(fun1 fun2 );

fun1;
fun2;
sub fun1{
    print "In fun1\n";
}
sub fun2{
    print "In fun2\n";
}

(Output)
In fun1
In fun2
```
```

# EXPLANATION

The subs module is loaded (see the section, "The use Function (Modules and Pragmas)," in Chapter 13) into your program and given a list of subroutines.

*fun1* is called with neither an ampersand nor parentheses, because it was in the subs list. The function is not defined until later.

*fun2* is also called before it is defined.
