# FORMAT

mkdir(FILENAME, MODE);  _(UNIX)_
mkdir(FILENAME);  _(Windows)_

# EXAMPLE 16.6

```
(In Script.)
    1  mkdir("joker", 0755);    # UNIX

(The Command Line)
    2  $ ls -l id joker
       drwxr-xr-x 2 ellie   512 Mar  7 13:43 joker

    3  (In Script.)
       mkdir("joker");         # Windows
       (The Command Line)
       $ dir
       06/24/2014  06:45 PM  <DIR>  joker
```

# EXPLANATION

+   1. The first argument to the *mkdir* function is the name of the directory. The second argument specifies the **mode**, or permissions, of the file. The permissions, **0755**, specify that the file will have read, write, and execute permission for the owner; read and execute for the group; and read and execute for the others. (Remember that without execute permission, you cannot access a directory.)
+   2. The *ls -l* command prints a long listing of the directory file with information about the file, the inode information. The leading *d* is for directory; and the permissions are *rwxr-xr-x*.
+   3. On Win32 systems, the directory is created with all permissions turned on for everyone.

# EXAMPLE 16.7

```
# This script is called “makeit”
    1  @echo “$0 <directory name>” * unless @ARGV;
    2  mkdir($ARGV[0], 0755) || die “mkdir:  $ARGV[0]:  $!\n”;

(At The Command Line)

$ makeit
    1  makeit <directory name> at makeit line 3.
$ makeit joker
    2  makeit: joker: File exists
$ makeit cabinet
$ ls -l d cabinet
cabinet
```
