# EXAMPLE 16.27

```
(The Script)
use warnings
1 @ints=pack("i3", 5,-10,15); # pack into binary structure
2 open(my $bin, ">", "binary") || die;
3 print $bin $ints;
4 seek($bin, 0,0) || die;
while(<$bin>) {
5 ($n1,$n2,$n3)=unpack("i3", $_);
6 print "$n1 $n2 $n3\n";
}

(Output)
6 5 -10 15
```

# EXPLANATION

+   1 The three integers 5, -10, and 15 are packed into three signed integers. The value returned is a binary structure assigned to $ints.
+   2 The BINARY filehandle is opened for reading and writing.
+   3 The packed integers are sent to the file. This file is compressed and totally unreadable. To read it, you must convert it back into an ASCII string. This is done with unpack.
+   4 The seek function puts the file pointer back at the top of the file at byte position 0.
+   5 We're reading from the file one line at a time. Each line, stored in _, is unpacked and returned to its original list of values.
+   6 The original list values are printed.
