You can use the uname -s command to detect the system type, and then use a case statement to modify the options in the ps command:

```
```sh
case `uname -s` in
Linux|Darwin|BSD) PS="/bin/ps auxwx" ;;
*) PS="/bin/ps -ef" ;;
esac
```
```

This case statement evaluates the output of the uname -s command. If the output is Linux, Darwin (MacOS X), or some version of BSD, the variable ps is set as follows:

```
```sh
PS="/bin/ps auxwx"
```
```

Otherwise it defaults to a Solaris style value:

```
```sh
PS="/bin/ps -ef"
```
```

> > The uname command is discussed in detail in the next chapter. For the purposes of this chapter it is sufficient to know that the uname -s command outputs the system type.

Now all that remains is to change the start and stop clauses to use the value of $PS rather than calling ps directly:

```
```sh
start)
if [ ! -x "$PGM" ] ; then
 echo "Error: Not Executable: $PGM" 1>&2
exit 1
fi
RUNNING=`$PS | grep "$PGM" | grep -v grep | head`
if [ -n "$RUNNING" ] ; then
echo "Error: Already running: $PGM" 1>&2
exit 1
fi
"$PGM" $PGM_OPTS
;;
stop)
$PS | grep "$PGM" | grep -v grep | \
awk '{ print $2 ; }' | xargs kill
;;
```
```

The complete script, incorporating all of these changes, is as follows:

```
```sh
#!/bin/sh
PGM=/usr/local/sbin/sshd
PGM_OPTS=
```
