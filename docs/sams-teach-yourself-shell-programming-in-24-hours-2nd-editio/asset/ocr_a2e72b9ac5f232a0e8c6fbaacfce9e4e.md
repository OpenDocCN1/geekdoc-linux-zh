# Text Filters

Shell scripts are often called on to manipulate and reformat the output from commands. Sometimes this task is as simple as displaying only part of the output by filtering out certain lines, but in most instances, the processing required is much more sophisticated.

In this chapter, you will look at several commands that can be used for filtering text. These commands are

+   - `head`
+   - `tail`
+   - `grep`
+   - `sort`
+   - `uniq`
+   - `tr`
