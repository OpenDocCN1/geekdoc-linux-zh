# The tail Command

The tail command is used to display the last few lines of a file. Its basic syntax is similar to that of the head command:

```
tail [-n lines] files
```

Here files is the list of the files the tail command should process. Without the -n lines option, the tail command shows the last 10 lines of its standard input. When this option is specified, tail shows the number of lines specified by lines instead.
