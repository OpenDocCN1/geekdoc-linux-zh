For Linux and FreeBSD, change the variable SORTCMD to

SORTCMD="sort -rn"

instead of

SORTCMD="sort -rn -k 2,2"

You will also need to change the variable PSCMD from

PSCMD="/bin/ps -ef"

to

PSCMD="/bin/ps -auxw"
