# Terms

**Built-in Command** A command whose code is part of the shell as opposed to a utility that exists in a separate disk file and which must be read into memory before it is executed.

**Modulus** See remainder.

**no-op** A command that does nothing and thus can be used as a dummy command or placeholder where syntax requires a command.

**Remainder** The remainder of a division operation, which is the amount that is left over when the amounts are not evenly divisible.
