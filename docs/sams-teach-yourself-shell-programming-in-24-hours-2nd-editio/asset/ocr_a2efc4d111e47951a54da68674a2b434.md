The two main problems with the simple expression are

+   - Only the word the should be matched. Lines starting with words such as there should not be matched.
+   - The word the should be at the beginning of the line.

To solve the first problem, we can add a space as follows:

```
/the /
```

To solve the second problem, you need the ^ meta-character, which matches the beginning of a line. In regular expressions, ^ anchors the expression to the beginning of the line: Only lines that start with the expression are matched. Normally, any line that contains an expression is matched.

By adding the ^ as follows,

```
/^the /
```

you have an expression that matches only those lines that start with the word the.

Expressions can also be anchored to the end of the line using the $. For example, the following expression

```
/friend$/
```

matches the line
I have been and always will be your friend
But it doesn't match the line
What are friends for

You can combine ^ and $ along with sets and other meta-characters to match lines according to an expression. For example, the following expression

```
/^Chapter [1-9]*[0-9]$/
```

matches lines such as
Chapter 1
Chapter 20
but it does not match lines such as
Chapter 00 Introduction
Chapter 101
