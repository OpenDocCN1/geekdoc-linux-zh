# Adapting the Script

This script is fairly adaptable and can be modified to start, stop, enable, and disable almost any program by just modifying two variables, $PGM and $PGM_OPTS. Currently these are set as follows:

```
PGM=/usr/local/bin/sshd
PGM_OPTS=
```
