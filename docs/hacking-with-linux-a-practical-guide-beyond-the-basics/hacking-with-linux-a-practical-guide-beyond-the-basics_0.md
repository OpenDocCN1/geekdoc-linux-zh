# Linux 破解实战指南：基础进进阶



![](img/rsrc7.jpg)











我们到达了本书书的末尾！我们认为这一部分不应该被称为“结论”，而应该是“圆满结局”！开玩笑之，我们想强调，GNU / Linux 系统已经从无名无闻走向各种杂志和专栏的封面，在大型公司和其他领域中赢得了实力和地位。它们不再被视为替代系统，而是我们计算机的严肃系统选择，无论是在家庭、办公室还是正在考虑使用它们的大学里。

尽管 Windows 占据主导地位（特别是在工作站上），但 GNU / Linux 系统在许多不同领域正日益增长。它的多功能性、健壮性、独立性以及“完整”的存在方式，在其极低总体成本的推动下，是被采用的主要且强大的因素。缓慢但逐步地，该系统及其许多高性能应用程序正在从服务器端解决方案到嵌入式系统便携设备等领域取得进展。即使在某些视频游戏机上，我们亲爱的 Tux 也有显著的存在！大型发行版整合了日常资源和工具，旨在最大化其用途，并在它们需要的地方提供解决方案。

对于我们终端用户来说，所有改进的努力、用户友好界面的实现都在不断加强，以便在不遥的将来，我们可以拥有具有所有所需（以及许多独特）功能和特性的操作系统，从而有助于使计算机的使用成为一项愉快和享受的活动，无论热衷爱好者的知识程度、培训以及资源设施的可用性如何。现在，在各种公司、企业和项目的倡议下，我们相信梦想很快就会实现。

尽管如此，在经历了重大且无数的进化之后，以下问题（以及预期）仍然存在：“GNU / Linux 系统何时将主导市场？”这很难回答。是因为系统的特性、用户的支持，还是大型公司的承诺，简而言之，或者是几个对这方面产生更大小影响的因素。但一大步已经迈出了：它的存在归功于一个奇的社区，这个社区自古以来（并不如此……）就相信自由，基于其意识形态构建了惊奇又妙的操作系统以及广泛的应用。多亏他们的意志、性格和强烈的激情，我们在计算机上拥有了这些伟大努力的成果：一个自由、开放、高效、强大、健壮、稳定、完整、灵活、多功能、友好、美丽……且充满情的系统。最后，你将找到所有关于 GNU / Linux 系统和可用应用的网页引用。这些材料在编写这本书的过程之前、期间和之后都曾参考过信息。
