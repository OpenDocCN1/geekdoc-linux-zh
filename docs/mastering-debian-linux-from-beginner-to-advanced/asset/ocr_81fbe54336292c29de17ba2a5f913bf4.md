+   2. Update /etc/hosts:

```
127.0.0.1\tlocalhost
127.0.1.1\tnew-hostname
```

+   3. Apply the changes:

```
sudo hostnamectl set-hostname new-hostname
```

# **DNS Configuration**

DNS settings are typically managed through the `/etc/resolv.conf` file. However, this file is often managed automatically by other services. To set custom DNS servers:

+   1. For systems using Network Manager, edit the connection settings.
+   2. For systems using systemd-resolved, edit `/etc/systemd/resolved.conf`.
+   3. For manual configuration, edit `/etc/resolv.conf`:

```
nameserver 8.8.8.8
nameserver 8.8.4.4
```
