# Basic Git Workflow

+   1. **Initialize a repository:**

```
git init
```

+   2. **Add files to the staging area:**

```
git add <file>
```

+   3. **Commit changes:**

```
git commit -m "Commit message"
```

+   4. **Check repository status:**

```
git status
```
