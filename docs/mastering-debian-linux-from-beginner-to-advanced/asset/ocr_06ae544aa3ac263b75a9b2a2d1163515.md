```
`chmod u+s file  # Set SUID
chmod g+s file  # Set SGID
chmod +t directory  # Set Sticky Bit`
```

# ### Access Control Lists (ACLs)

For more fine-grained control over permissions, Debian supports Access Control Lists. To use ACLs, ensure the `acl` package is installed:

```
`sudo apt install acl`
```

To set an ACL:

```
`setfacl -m u:username:rwX file`
```

To view ACLs:

```
`getfacl file`
```
