Many projects use the GNU Autotools build system. The typical sequence is:

```
. ./configure
```

This script checks your system for required components and creates a Makefile tailored to your environment. You can pass options to configure to customize the build:

```
. ./configure --prefix=/usr/local --enable-feature --disable-another-feature
```

# 4. Compiling

Once configured, you compile the software:

```
. make
```

This command reads the Makefile and compiles the source code into binary executables.
