
# File Systems

A file system is a method of storing and organizing files on a disk partition.
Debian supports various file systems, including:

- ext4: The default file system for most Linux distributions
- XFS: A high-performance journaling file system
- Btrfs: A modern file system with advanced features like snapshots and RAID
- FAT32 and NTFS: For compatibility with Windows systems

## Creating File Systems

Use the `mkfs` command to create a file system:

```bash
sudo mkfs.ext4 /dev/sdb1 # Create an ext4 file system
sudo mkfs.xfs /dev/sdb2 # Create an XFS file system
```

## Mounting File Systems

To make a file system accessible, it needs to be mounted to a directory in the file system hierarchy.

### Temporary Mounting

Use the `mount` command for temporary mounts:

```bash
sudo mount /dev/sdb1 /mnt/data
```

### Permanent Mounting

For permanent mounts, edit the `/etc/fstab` file:

```text
/dev/sdb1  /mnt/data  ext4  defaults  0  2
```

After editing `/etc/fstab`, run:

```bash
sudo mount -a
```

# Logical Volume Management (LVM)

LVM provides a layer of abstraction between physical disks and file systems, offering benefits like:

- Easy resizing of logical volumes
- Spanning volumes across multiple disks
- Creating snapshots

## Basic LVM Commands

- Create a physical volume:

```bash
sudo pvcreate /dev/sdb
```

- Create a volume group:

```bash
sudo vgcreate myvg /dev/sdb
```

- Create a logical volume:

```bash
sudo lvcreate -L 10G -n mylv myvg
```

- Format and mount the logical volume:

```bash
sudo mkfs.ext4 /dev/myvg/mylv
sudo mount /dev/myvg/mylv /mnt/data
```

# Disk Usage and Monitoring

To monitor disk usage and performance:

- **df**: Display free disk space

```bash
df -h
```

- **du**: Estimate file and directory space usage

```bash
du -sh /home/*
```

- **iotop**: Monitor I/O usage by processes (may need to be installed)

```bash
sudo apt install iotop
sudo iotop
```

- **smartctl**: Check disk health (part of the smartmontools package)

```bash
sudo apt install smartmontools
sudo smartctl -a /dev/sda
```

# Configuring Network Settings

Proper network configuration is essential for connecting your Debian system to local networks and the internet. This section covers the basics of network configuration in Debian.

## Network Interfaces

Network interfaces are the connection points between your system and the network. Common types include:

- Ethernet interfaces (e.g., eth0, enp0s3)
- Wireless interfaces (e.g., wlan0, wlp2s0)
- Loopback interface (lo)

To view network interfaces:

```bash
ip link show
```

or

```bash
ifconfig -a
```

## IP Address Configuration

### Static IP Configuration

To set a static IP address, edit the `/etc/network/interfaces` file:

```bash
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4
```

After editing, restart the networking service:

```bash
sudo systemctl restart networking
```

### Dynamic IP Configuration (DHCP)

For DHCP, use this configuration in `/etc/network/interfaces`:

```bash
auto eth0
iface eth0 inet dhcp
```

## Network Manager

Network Manager is a more user-friendly alternative for managing network connections, especially for desktop environments. To install:

```bash
sudo apt install network-manager
```

After installation, you can use the `nmcli` command-line tool or the graphical interface to manage connections.

## Hostname Configuration

To change the system's hostname:

- Edit `/etc/hostname`:

```bash
new-hostname
```

- Update `/etc/hosts`:

```text
127.0.0.1    localhost
127.0.1.1    new-hostname
```

- Apply the changes:

```bash
sudo hostnamectl set-hostname new-hostname
```

## DNS Configuration

DNS settings are typically managed through the `/etc/resolv.conf` file. However, this file is often managed automatically by other services. To set custom DNS servers:

- For systems using Network Manager, edit the connection settings.
- For systems using systemd-resolved, edit `/etc/systemd/resolved.conf`.
- For manual configuration, edit `/etc/resolv.conf`:

```text
nameserver 8.8.8.8
nameserver 8.8.4.4
```

## Firewall Configuration

Debian uses `iptables` for firewall functionality. For easier management, you can use `ufw` (Uncomplicated Firewall):

- Install `ufw`:

```bash
sudo apt install ufw
```

- Enable `ufw`:

```bash
sudo ufw enable
```

- Allow specific ports:

```bash
sudo ufw allow 22/tcp  # Allow SSH
sudo ufw allow 80/tcp  # Allow HTTP
```

- Check status:

```bash
sudo ufw status
```

## Network Troubleshooting Tools

- `ping`: Test connectivity to a host

```bash
ping google.com
```

- `traceroute`: Show the path packets take to a destination

```bash
traceroute google.com
```

- `netstat` or `ss`: Display network connections

```bash
ss -tuln
```

- `tcpdump`: Capture and analyze network traffic

```bash
sudo tcpdump -i eth0
```

- `nmap`: Network scanning and discovery tool

```bash
nmap 192.168.1.0/24
```

# Network Time Protocol (NTP)

To keep your system clock synchronized:

- Install the NTP daemon:

```bash
sudo apt install ntp
```

- Start and enable the service:

```bash
sudo systemctl start ntp
sudo systemctl enable ntp
```

- Check synchronization status:

```bash
ntpq -p
```

# IPv6 Configuration

To enable or disable IPv6:

- Edit `/etc/sysctl.conf`:

```bash
# To disable IPv6
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
net.ipv6.conf.lo.disable_ipv6 = 1

# To enable IPv6 (default)
net.ipv6.conf.all.disable_ipv6 = 0
net.ipv6.conf.default.disable_ipv6 = 0
net.ipv6.conf.lo.disable_ipv6 = 0
```

- Apply changes:

```bash
sudo sysctl -p
```

## Network Bonding

Network bonding combines multiple network interfaces into a single logical interface for increased throughput or redundancy.

- Install the bonding kernel module:

```bash
sudo modprobe bonding
```

- Edit `/etc/network/interfaces`:

```bash
auto bond0
iface bond0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    bond-slaves eth0 eth1
    bond-mode active-backup
    bond-miimon 100
    bond-primary eth0
```

- Restart networking:

```bash
sudo systemctl restart networking
```

# Virtual Private Network (VPN) Configuration

Debian supports various VPN protocols. Here's a basic OpenVPN client setup:

- Install OpenVPN:

```bash
sudo apt install openvpn
```

- Place your `.ovpn` configuration file in `/etc/openvpn/`:

```bash
sudo cp myclient.ovpn /etc/openvpn/client.conf
```

- Start the OpenVPN service:

```bash
sudo systemctl start openvpn@client
```

- Enable autostart:

```bash
sudo systemctl enable openvpn@client
```

# Network Security Best Practices

- Keep your system and packages up to date:

```bash
sudo apt update && sudo apt upgrade
```

- Use strong passwords and consider implementing SSH key authentication.
- Disable root SSH login by editing `/etc/ssh/sshd_config`:

```bash
PermitRootLogin no
```

- Use fail2ban to protect against brute-force attacks:

```bash
sudo apt install fail2ban
```

- Regularly monitor system logs for suspicious activity:

```bash
sudo tail -f /var/log/auth.log
```

- Use encrypted protocols (HTTPS, SFTP, etc.) whenever possible.
- Implement network segmentation using VLANs or separate physical networks for sensitive systems.
- Regularly audit open ports and running services:

```bash
sudo netstat -tuln
```

- Consider using Intrusion Detection Systems (IDS) like Snort or Suricata for additional security.

By mastering these system configuration and management techniques, you'll be well-equipped to maintain a secure, efficient, and well-organized Debian system. Remember to always test configuration changes in a non-production environment first, and keep thorough documentation of your system setup and any modifications you make.
