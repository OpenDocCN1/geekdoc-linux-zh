Debian uses `iptables` for firewall functionality. For easier management, you can use `ufw` (Uncomplicated Firewall):

+   1. Install `ufw`:

```
sudo apt install ufw
```

+   2. Enable `ufw`:

```
sudo ufw enable
```

+   3. Allow specific ports:

```
sudo ufw allow 22/tcp  # Allow SSH
sudo ufw allow 80/tcp  # Allow HTTP
```

+   4. Check status:

```
sudo ufw status
```
