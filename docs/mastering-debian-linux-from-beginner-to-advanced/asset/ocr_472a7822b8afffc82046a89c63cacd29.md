# Memory Optimization

+   1. **Swap usage**: Adjust swappiness to control how aggressively the system uses swap space.

```
sudo sysctl vm.swappiness=10
```

+   2. **Cache management**: Clear system caches to free up memory.

```
sudo sync && sudo echo 3 | sudo tee /proc/sys/vm/drop_caches
```

+   3. **OOM killer**: Configure the Out-of-Memory killer to handle low memory situations.

```
sudo sysctl vm.oom_kill_allocating_task=1
```
