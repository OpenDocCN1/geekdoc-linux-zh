C and C++ are powerful, low-level programming languages widely used in system programming, game development, and performance-critical applications.

To install the GNU Compiler Collection (GCC) for C/C++ development:

```
sudo apt update
sudo apt install build-essential
```

This command installs gcc, g++, and other essential build tools.

# Java

Java is a popular, object-oriented programming language known for its "write once, run anywhere" philosophy.

To install the OpenJDK (Open Java Development Kit) on Debian:

```
sudo apt update
sudo apt install default-jdk
```

This command installs the latest version of OpenJDK available in the Debian repositories.
