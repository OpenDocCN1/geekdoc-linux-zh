Not all services support this operation. If a service doesn't support reloading, it may fall back to a full restart.

# **Enabling a Service**

Enabling a service sets it to start automatically at boot time:

```
sudo systemctl enable [service_name]
```

For example, to enable the Apache web server to start at boot:

```
sudo systemctl enable apache2
```

This command creates the necessary symlinks to start the service at boot time, but it does not start the service immediately.
