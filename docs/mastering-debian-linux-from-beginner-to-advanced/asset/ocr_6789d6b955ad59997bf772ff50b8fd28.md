```
sudo vgcreate myvg /dev/sdb
```

+   3. Create a logical volume:

```
sudo lvcreate -L 10G -n mylv myvg
```

+   4. Format and mount the logical volume:

```
sudo mkfs.ext4 /dev/myvg/mylv
sudo mount /dev/myvg/mylv /mnt/data
```
