getsebool -a

# **AppArmor**

AppArmor is another MAC system that is easier to configure than SELinux but provides less granular control.

# **Installing AppArmor**

AppArmor is usually pre-installed on Debian systems. If it’s not, you can install it with:

```
sudo apt install apparmor apparmor-utils
```

# **Enabling AppArmor**

+   1. Edit the GRUB configuration:

```
sudo nano /etc/default/grub
```
