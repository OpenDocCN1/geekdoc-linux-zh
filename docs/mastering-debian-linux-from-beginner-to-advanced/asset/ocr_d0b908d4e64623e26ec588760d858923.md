# ## Screen and tmux

For more advanced management of background processes, especially for interactive sessions, tools like `screen` and `tmux` are invaluable:

+   * **Screen:** A full-screen window manager that multiplexes a physical terminal between several processes.

Basic usage:

```
```
screen
# Run your commands
# Press Ctrl+A, then D to detach
screen -r # to reattach
```
```

+   * **tmux:** A terminal multiplexer similar to screen but with more modern features.

Basic usage:

```
```
tmux
# Run your commands
# Press Ctrl+B, then D to detach
tmux attach # to reattach
```
```
