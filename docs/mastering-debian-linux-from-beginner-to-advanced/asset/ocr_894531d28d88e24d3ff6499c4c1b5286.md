# # Testing Email Server

+   1. Create a test user:

```
`sudo adduser testuser`
```

+   2. Send a test email:

```
```
echo "This is a test email" | mail -s "Test Subject" testuser@example.com
```
```

+   3. Check the email using an IMAP client or by logging in to the server and checking the Maildir.

# ## Deploying a Debian VPS on Cloud Platforms

Virtual Private Servers (VPS) offer a flexible and cost-effective way to host applications and services. Let's explore how to deploy a Debian VPS on popular cloud platforms.

# ### Amazon Web Services (AWS)

+   1. Sign up for an AWS account if you don't have one.
+   2. Navigate to the EC2 dashboard and click "Launch Instance".
+   3. Choose a Debian AMI (Amazon Machine Image) from the list of available options.
