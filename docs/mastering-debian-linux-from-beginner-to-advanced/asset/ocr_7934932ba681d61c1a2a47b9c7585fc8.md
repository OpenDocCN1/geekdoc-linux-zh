+   1. journalctl: Access system logs to identify boot-related errors.

```
journalctl -b
```

+   2. dmesg: Display kernel ring buffer messages.

```
dmesg | less
```

+   3. systemd-analyze: Analyze boot time and identify slow-starting services.

```
systemd-analyze blame
```
