# Changing the Default SSH Port

Changing the default SSH port can help reduce automated attacks. To change the SSH port:

1. Edit the SSH configuration file:

```
sudo nano /etc/ssh/ssh config
```

2. Find the line `#Port 22` and change it to a non-standard port, e.g., Port 2222

3. Restart the SSH service:

```
sudo systemctl restart ssh
```
