# ## This issue

+   - Take control of containers
+   - 35 essential Linux fixes
+   - Restrict untrusted software with Firejail
+   - Run a VPN through your Pi

![](bbox=[0.43, 0.42, 0.51, 0.51])

Welcome to the latest issue of Linux User & Developer, the UK and America's favourite Linux and open source magazine. Have you joined the container revolution yet? Whether you're a developer looking for a complete runtime environment, a sysadmin looking to secure, locked down infrastructure or you simply want to explore the latest development in computing, our feature on p18 will explain everything you need to know, from the principles of containerisation to the key tools and how to use them.

Also this issue, discover how to solve 35 of the most annoying Linux problems that you could encounter. Whether you're new to Linux or you're a seasoned pro, these particular issues have a habit of raising their ugly heads. We explain how to fix all of them on p56. Plus, learn how to set up a LAMP stack, sandbox an application using Firejail, continue working with Erlang and OpenRTM, take a look at systems administration under Ubuntu, check out the best password managers, the newest Synology router, the latest version of Arya Linux and much more. Our Practical Raspberry Pi section also has some great guides to setting up a VPN and getting to grips with the Pimoroni Blink! board, and we take a look at a fantastic Pi project for the green- fingered among you.

Enjoy the issue!

April Madden, Editor
