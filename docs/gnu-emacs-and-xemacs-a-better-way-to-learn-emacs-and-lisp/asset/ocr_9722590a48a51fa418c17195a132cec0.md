# Dired Keys

The key command for loading a Dired buffer is Ctrl-x d. You are prompted for a directory name. The default (shown in parentheses) is the directory of the current buffer's file. Just press Enter if you want the default; otherwise, type a directory name in the minibuffer.

When a Dired buffer appears, the default keymap is replaced with a Dired keymap. Many of the letter keys are remapped to Dired commands. These keybindings are shown in the menus next to the relevant items. Dired has many bindings, but a handful of them are all you need to get started. You will pick up others while using the menus.

# Basic Dired Keys

| | |d| Tags a file or directory for deletion.| | |x| Deletes tagged files, asking for confirmation first.| | |m| Marks or tags an item (a file or directory) for other operations.| | |C| Copies an item or marked files.| | |S| Symlinks an item (with a prompt for the name to symlink to).| | |R| Renames an item.| | |Z| Compresses an item with gzip.| | |v| Loads a file in View mode---read-only, with spacebar paging|

# The Regex Menu

One of the more useful groups of Dired commands are those listed on the Regex menu. These commands use regular expressions to mark or operate on files. This allows you to change quantities of files with a single command. Suppose you have a number of files that have names beginning with "_QUOT_"`, and you want them to begin with "quotes_2000". Selecting Rename from the Regex menu would produce this prompt in the minibuffer:

```
Rename from (regex):
```

You would type `^` in the minibuffer. Remember that the caret character (^) is the regular-expression symbol for "only at the beginning of the line".
