Now that you have seen how this small mode works, try reading through some other Emacs-Lisp files. In Chapter 6, a function found in the Emacs core file simple.el was analyzed. That same file contains many small text-related functions that aren't too difficult to understand. Look for simple.el in either /usr/share/emacs/lisp or /usr/local/share/emacs/lisp, depending on how you installed Emacs.  

The next chapter introduces you to the Emacs byte-compiler, a utility that optimizes Lisp files so that they run faster.
