# # Setting up Searchable Sources

You need at least one directory containing files generated by *ra-index*. The first step is to create the directory `~/RA-indexes`. This is the default name. If you want to use a different name and location, you need to edit the *remember-custom.el* file and change the value of the variable *remember-database-dir*.
