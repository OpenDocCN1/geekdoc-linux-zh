# 作者简介

Larry Ayers 是一位自由撰稿人和开源倡导者。他住在美国密苏里州东北部的一个小农场上，与家人同住。在不写作的时候，他在当地进行计算机咨询、制作乐器，并运营一个小型便携式锯木厂。Larry 曾为 *Linux Gazette* 和 *Linux Journal* 撰稿。
