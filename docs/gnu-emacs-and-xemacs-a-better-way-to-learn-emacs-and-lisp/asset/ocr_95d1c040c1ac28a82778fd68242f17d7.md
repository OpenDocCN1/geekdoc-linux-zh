# Aborting Operations

Perhaps you mistyped a command, or Emacs is doing something you don’t understand. Sometimes an Emacs process seems to take too long. The solution to all these problems is one key combination: Ctl-g.

This command aborts any Emacs operation and allows you to either start over or go on to something else.
