You can set as many bookmarks as you like. Each buffer you edit has its own private bookmarks, although all of them are lost when you quit Emacs unless you save them to a bookmark file (see the next section).

# Saving and Revisiting Bookmarks

You can go back to any bookmark you have set by pressing Ctrl-x r b and typing *(optional name)*

You can use this command as an alternative way to change buffers, because it is a side effect of visiting a bookmark.

You can even use this command to load files. The file containing a particular named bookmark is automatically loaded when you give that name to the command. Give your bookmarks short names—just two or three characters is all that is necessary.

Not every bookmark needs to be available in all buffers. Perhaps you have a directory containing files associated with a project, and you want to keep those bookmarks separate from your main bookmark file in your home directory. Use the bookmark-save command: Press M-x and type **bookmark-write**

You are asked for a file name. Type one in, and a new bookmark file is created.

If you want the bookmark to be saved to your global bookmark file, press M-x and type **bookmark-save**

If you want to use the suggested default (~/\.emacs.bmk), just press Enter. This default file is loaded whenever you start Emacs, whereas you must load any other bookmark file explicitly by pressing M-x and typing **bookmark-load**

Use this for directory- or project-specific bookmark files.

The default bookmark file ~/\.emacs.bmk is compatible across every version of GNU Emacs and XEmacs I've tried, including beta versions.
