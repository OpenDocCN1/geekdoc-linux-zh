# ## Error Types

There are two error messages that almost always are symptoms of a parenthesis problem:

```
```
Invalid read syntax: *)
End of file during parsing
```
```

These are the easiest errors to fix. Use one of the Emacs parenthesis-matching modes to find unbalanced pairs. You can also step your way through the buffer by repeatedly pressing Ctrl-M-f. This key-command moves point to the next valid function definition and will signal an error if parentheses don't match.
