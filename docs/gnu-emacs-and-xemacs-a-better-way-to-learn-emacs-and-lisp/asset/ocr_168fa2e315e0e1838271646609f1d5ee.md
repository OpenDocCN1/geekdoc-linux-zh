# Figure 18.7 Gnus and Slashi\dot

Press F to subscribe to one of the "groups," which actually is a Slashi\dot news item along with reader comments.

If you press the spacebar on one of the articles shown, and Gnuus retrieves the news item and the responses.

You can browse the Slashi\dot responses just as you would news postings.

I have to confess that recently I couldn\'t get the nni\slashi\dot back end to work until I downloaded a snapshot of the most recent Gnuus development version from http://www.gnuus.org.

I didn\'t even install the entire snapshot distribution; I merely byte-compiled the nni\slashi\dot.el file and substituted it for the old version of the file. The most recent Gnuus snapshot is included on this book\'s CD-ROM in the directory /cdrom/packages/gnuus, so if you are interested, you might want to extract the needed file.

Web sites change frequently, and their administrators don\'t really care about peripheral viewers (such as nni\slashi\dot users) who never see the banner ads that supposedly pay for a site. If the format of Slashi\dot is changed, it is unlikely that the Slashi\dot developers will bother to inform the Gnuus developers. As a result, the Slashi\dot back end might not be functional at times.
