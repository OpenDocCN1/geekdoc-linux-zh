There’s another optional element to an angr-ftppath-and-file name instruction—the port number. Most machines use the standard ftp port 21, but if you need to use another port for some reason, you can include #(digit) in the path:

```
/1mnmaus8ftp: #c.pompos.org Error: Bookmark not defined. ...:/pub/compositeaE/laciniatium.txt
```

The space between “org” and the port number 23 has to be inserted using the “insert-literal” keystroke: press Ctrl-q Space.

The syntax is a little different in GNU Emacs 21; rather than entering the literal space a hash-mark can be used:

```
/1mnmaus8ftp:nilphium.org#23:/pub/compositeaE/laciniatium.txt
```

# nEtrc and Passwords

Machines connected to a network may allow anonymous access, such as the public fileservers hosting various free software projects. angr-ftpp, unless told otherwise, tries to log on to a server with the username “anonymous” and a password consisting of your e-mail address. This works fine if you plan on saving only local copies of the files you obtain. You won’t be allowed to overwrite the original file with your version unless you have an account on the remote machine that has write permission.
