This is a task-sorted list of the most commonly needed commands that have default keybindings. Naturally, if you have created your own keybindings, you won't find them here.

See Appendix B for minibuffer commands that have no default keybindings.

# ## Essential Commands

These are the commands you should learn first.

| Keybinding | Description |
| :--- | :--- |
| Ctrl-x Ctrl-f | Loads a file. You are prompted in the minibuffer for a file name. |
| Ctrl-x Ctrl-s | Saves the current buffer to disk, overwriting the original file. |
| Ctrl-x Ctrl-w | Saves a buffer to a different file name. |
| Ctrl-x = | Saves multiple changed buffers. You are prompted for confirmation. |
| Ctrl-x x | Kills a buffer. If you have unsaved changes, you are asked if you are sure you want to kill the buffer. |
| Ctrl-x i | Inserts the contents of a file into the current buffer. |
| Ctrl-g | Aborts or cancels an Emacs operation. Sometimes needs to be repeated. |
| Ctrl-x u | Undoes the last change. Repeat this to undo previous edits. |

# ## Movement Commands

These key commands allow you to move throughout a buffer by varying increments.

| Keybinding | Description |
| :--- | :--- |
| Ctrl-x b | Moves to another buffer—by default, the most recently visited. |
| Ctrl-x Ctrl-b | Brings up a list of buffers, allowing you to either visit or kill. |
| M-< | Moves to the beginning of the buffer. |
| M-> | Moves to the end of the buffer. |
| Ctrl-a | Moves to the beginning of the current line. |
| Ctrl-e | Moves to the end of the current line. |
| Ctrl-p | Moves to the previous line. |
