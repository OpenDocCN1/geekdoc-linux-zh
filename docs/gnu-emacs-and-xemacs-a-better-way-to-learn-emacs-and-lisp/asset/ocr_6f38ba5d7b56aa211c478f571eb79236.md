You might find the slight delay (longer for larger files) whenever a source file is loaded annoying. In this case, you can start up \texttt{imenu} only when you need it by pressing M-x and typing

```
imenu-add-menubar-index
```

You can also access a mouse menu by pressing CtrI-mouse button 3. The \textsc{XEmacs} equivalent is called \emph{func-menu}, which adds a new Functions menu to the menu bar. To turn this on, insert these lines in your \textasciitilde{/.emacs} file:

```
require 'func-menu\)
define-key global-map 'f11 'function-menu\)
(add-hook 'find-file-hooks 'fume-add-menubar-entry\)
(add-hook 'c-mode-hook 'fume-add-menubar-entry\)
(add-hook 'c++-mode-hook 'fume-add-menubar-entry\)
add-hook 'emacs-lisp-mode-hook 'fume-add-menubar-entry\)
add-hook 'python-mode-hook 'fume-add-menubar-entry\)
(define-key global-map [(control c) (1)] 'fume-list-functions\)
(define-key global-map [(control c) (q)] 'fume-prompt-function-goto\)
(define-key global-map [(shift button3)] 'mouse-function-menu\)
(define-key global-map '(meta button1) 'fume-mouse-function-goto\)
```

Not all of these lines are necessary. For example, you might not need the keybinding in the second line or the mouse bindings in the last two lines.

The main advantage of the more primitive \texttt{etags} method discussed earlier is that once you have generated the \textsc{TAGS} file, every file in a directory is indexed, whereas the \texttt{imenu} and \texttt{func-menu} interfaces show only the functions and so on in the current buffer. Plus, you get a time lag when loading new files.

The \textsc{Speedbar} was introduced earlier in this chapter. It has the advantage of being a graphical index of an entire directory, but it does take up more screen real estate. \textsc{Speedbar} is included with GNU \textsc{Emacs} and is available as a preconfigured \textsc{XEmacs} package. To use these versions, press M-x and type

```
speedbar
```

If you find yourself using \textsc{Speedbar} often, you might want to bind the command to a key that will toggle the frame on and off:

```
(global-set-key [[f12]] 'speedbar\)
```
