The Package buffer has its own keybindings:

+   - **Enter**: Tags or untags the current package for installation.
+   - **d**: Tags or untags the current package for removal.
+   - **r**: Adds any packages needed by those that were tagged.
+   - **x**: Installs or deletes the tagged packages.
+   - **i**: Displays more information about the package in the modeline.
+   - **g**: Refreshes the package list.
+   - **v**: Toggles between detailed and terse display.
+   - **q**: Kills the buffer.
