# Retrieving Mail from Your Server

You can set up VM so that it can log in to your POP or IMAP mail server and download new messages. Many users would rather use an external program such as Fetchmail so as to avoid being tied to Emacs and VM for mail retrieval, but if this approach sounds like it would suit you, here are the details.

You need to insert your server information as an entry in VM's list of spool files. VM doesn't need such a list when you are moving mail from your main inbox to VM's ~/INBOX, but if you want to tell VM to look for new mail in other locations, you need to use a statement that resembles this one:

```
```lisp
(setq vm-spool-files ('(/var/spool/mail/layerns "/~/Mail")))
```
```

Substitute a server for one of these spool files, complete with port, username, and password, by altering the statement to resemble this:

```
```lisp
(setq vm-spool-files '("mail.server.net:110:pass:username:password " ~/"Mailbox"))
```
```

If you want your messages deleted from the server after VM has sucked them up (unless you access from more than one location, you probably want this), you need to add the server information to another associated list:

```
```lisp
(setq vm-pop-auto-expunge-alist

('"mail.server.net:110:pass:username:*" . nil)
)
```
```

The password doesn't need to be in this statement, because the asterisk indicates to VM that it should use the value set in the vm-spool-files variable.
