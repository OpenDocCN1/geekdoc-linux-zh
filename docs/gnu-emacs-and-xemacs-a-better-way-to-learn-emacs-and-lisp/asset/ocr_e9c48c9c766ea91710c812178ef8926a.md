# Virtual Folders

A virtual folder is a subset of your mail folder made up of messages that share a common subject line, author, label, or any of several other criteria. This isn’t a real folder or file; it’s just a method that VM uses to selectively display some of your messages. This is similar to Rmail’s labels and selective labeled-message view.

You can create one of these using the commands on the Virtual menu, but it will last only as long as the VM session is active. Creating permanent virtual folders requires a Lisp statement in your ~/.vm file. The statement can be modeled after this one:
