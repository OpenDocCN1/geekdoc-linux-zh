Other commercial HTML editors do show you the tags in your file as you write it. This is the approach that the Emacs HTML modes use. You end up with greater control over how your file is ultimately displayed, but you need to know a bit more about what those tags actually mean.

It’s not difficult to learn the basics of HTML. There exists a popular superstition (promulgated by some writers of HTML) that HTML is a programming language; thus, people who write HTML are programmers. This isn’t true. HTML is one of the simpler text markup languages, and it doesn’t take much more than an afternoon to pick up the basic principles. Many Web sites (as well as books) can help you learn these basic ideas, although an hour or so fooling around with one of the Emacs HTML modes will help you learn enough to get started.
