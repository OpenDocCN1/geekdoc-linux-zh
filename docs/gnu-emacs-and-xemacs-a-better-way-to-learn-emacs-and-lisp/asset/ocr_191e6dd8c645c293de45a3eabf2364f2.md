# Bug Reporting Tips

If your report is confirmed by other users and does turn out to be a genuine bug in program code, you might be asked to help track it down. Possibly your version of Linux or the glibc or other shared library differs from those of the developers and/ or other users so such an extent that no one else sees the bug.

You might be asked to run Emacs with the gdb debugger. If Emacs dumped core, you might be asked to run gdb on the core file. This won't work unless your Emacs binary has been compiled with the -g flag and hasn't been stripped of debugging
