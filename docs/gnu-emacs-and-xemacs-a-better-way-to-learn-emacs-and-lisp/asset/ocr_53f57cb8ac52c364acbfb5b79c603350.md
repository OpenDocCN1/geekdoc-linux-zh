The first source of help to consult is the function help key (Ctrl-h f), because many unfamiliar terms are names of built-in functions. If that doesn't yield information, try Ctrl-h a or M-x apropos. The apropos help-facility returns a list of any symbols or keybindings related to your request.

Working your way through unfamiliar functions, puzzling out terms and syntax along the way, will eventually give you a basic grounding in the way Lisp is structured.
