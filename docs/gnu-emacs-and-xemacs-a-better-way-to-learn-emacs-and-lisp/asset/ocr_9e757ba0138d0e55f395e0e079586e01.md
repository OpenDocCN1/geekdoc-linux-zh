# Edit your documents with ease using **Emacs**!

Emacs is one of the most popular text editors around. This customizable editor allows you to literally create the tools that you need to make your software easier to use. If you haven’t yet braved the process of configuring Emacs, this book is for you. It provides users of all levels with an introduction to Emacs and Lisp. By the time you’re through, you’ll be comfortable experimenting with all that Emacs has to offer!

Larry Ayers is a freelance writer and Open Source advocate. He lives on a small farm in northeast Missouri with his family. When not writing, he does computer consulting in his community, builds musical instruments, and operates a small portable sawmill. Larry has written for the *Linux Gazette* and *Linux Journal*.
