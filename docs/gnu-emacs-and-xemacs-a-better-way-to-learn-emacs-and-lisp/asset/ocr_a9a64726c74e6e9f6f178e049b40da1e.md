# VM and MIME Attachments

VM can decode and encode the BASE64 and Quoted-Printable MIME types by using either internal (although slower) Lisp routines or external programs. If you want VM to use an external decoder or encoder, you need to change a couple of variables. The VM source distribution includes the C source for four such programs—gp-encode, gp-decode, base64-encode, and base64-decode. If you install VM using the supplied makefile, the binaries are built and installed in /usr/bin. These four lines in your ~/.vm file tell VM to use them in preference to the built-in Lisp decoder and encoder:

```
```
(setq vm-mime-gp-encoder-program "gp-encode")
(setq vm-mime-gp-decoder-program "gp-decode")
(setq vm-mime-base64-encoder-program "base64-encode")
(setq vm-mime-base64-decoder-program "base64-decode")
```
```

The XEmacs VM package doesn't include these small C programs, but in any recent version of XEmacs you can find a base64 encoder/decoder in the /usr/ [local]/lib/xemacs-[version-number]/[4,5 or 6]86-pc-linux directory, which is where miscellaneous non-Lisp utilities are installed. The program is named mmmencode, and these lines in ~/.vm will make it become VM's default base64 encoder/decoder:

```
```
(setq vm-mime-base64-decoder-program "mmmencode"
      vm-mime-base64-decoder-switches (list "-u")
      vm-mime-base64-encoder-program "mmmencode"
      vm-forwarding-digest-type "mime")
