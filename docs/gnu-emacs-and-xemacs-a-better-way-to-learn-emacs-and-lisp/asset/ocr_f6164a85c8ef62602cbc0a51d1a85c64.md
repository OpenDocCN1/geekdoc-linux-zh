All the HTML modes discussed in this book include such a line in their default templates for new files.

Among the files that make up the XEmacs pgsql package are a collection of DTDs for different versions of HTML, Docbook (an SGML package used for technical documentation), and XML. One of these files will be consulted when you use pgsql to check your HTML files.
