If you use this command, often you can bind it to a key with a statement like this one in your `~/.emacs` file:

```
(global-set-key [(control c) l] 'ispell-buffer)
```

Speaking of keybindings, the default `M-$` binding for a single word is rather awkward to type; I've rebound it in my `~/.emacs` file to use a function key instead:

```
(global-set-key 'f6 'ispell-word)
```

# ### Dictionaries for ispell

Another command can be used to change the default dictionary. Press `M-x` and type `ispell-change-dictionary`

You are prompted for the name of another dictionary (perhaps a dictionary in another language).

ispell dictionaries are in a special hashed format. The ispell distribution comes with a separate program called buildhash, which is used to process word lists into compact dictionary databases. Consult the ispell and buildhash man pages for instructions.

# ### Checking HTML and LaTeX Files

ispell has native support for spell checking tagged LaTeX and HTML files. It will ignore the tagging and concentrate on the content of these files.
