This is a lot of output, but there's a lot of useful information here. First let's look at the question and answer sections:

```
; QUESTION SECTION:
;web1.example.net.		IN	A
; ANSWER SECTION:
web1.example.net.		300	IN	A	10.1.2.5
```

The question section repeats what DNS query was sent. In this case, we asked for the A record (the traditional DNS record that maps a hostname to an IP) for web1.example.net. The answer section returns the full A record
