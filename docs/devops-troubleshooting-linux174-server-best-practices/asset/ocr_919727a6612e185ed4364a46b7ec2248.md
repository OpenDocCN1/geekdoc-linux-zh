If you wanted to store that information into a file named top_output, use

$ top -b -n 1 > top_output

If you wanted to view the top output *and* output to a file at the same time, you could use the handy command-line tool tee:

$ top -b -n 1 | tee top_output

# Make Sense of top Output

When you use top to diagnose load, the basic steps are to examine the top output to identify what resources you are running out of (CPU, RAM, disk I/O). Once you have figured that out, you can try to identify what processes are consuming those resources the most. First, let's examine some standard top output from a system:
