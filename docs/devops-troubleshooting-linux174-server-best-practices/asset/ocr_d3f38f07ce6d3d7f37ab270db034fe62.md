In this example you can see that in addition to the / partition that's on /dev/sda1, the system also mounts /var from /dev/sda3 and /home from /dev/sdb1. If either /var or /home are corrupted and can't automatically be repaired or can't be found, the boot process will stop and drop you to a shell prompt where you can investigate matters further. In these circumstances, just repeat the same troubleshooting steps you might perform for a problem with a root file system and look for device names that have changed, new labels, or different UUIDs.
