# # Installation order

# ## Windows, then Linux

Recent Linux distributions come fully equipped for coexistence scenarios: if the deployment process detects the presence of a Windows-based operating system, it will usually be added to the GRUB bootloader automatically. This means that no further manual intervention is needed: everything works out of the box.

When a fresh workstation is being commissioned from scratch, time can be saved by instructing the Windows installer to leave part of the hard disk untouched. It can then be formatted during the Linux installation process without having to resort to partition messing.

# ## Linux, then Windows

Installing Windows last causes trouble. The first issue tends to be the shrinking of the partitions - if a second hard disk can be installed doing so is often the better choice, as the Windows installer sometimes messes up partitions. Be careful to have a bootable USB stick or rescue DVD on hand in order to restore the bootloader. Finally, be aware that virtual machines can be a nice alternative: if you aren't into gaming and can live without UWP emulators, VirtualBox provides more than decent performance on recent hardware.

# # Types of distro
Get to know the variations

![](bbox=[0.4, 0.27, 0.63, 0.35])

**Everyday**
# Ubuntu

You might not love Mark Shuttleworth's operating system. It, however, has done more for desktop Linux than most other distros and is excellent for everyday use. It's also great for beginners.

![](bbox=[0.65, 0.27, 0.89, 0.35])

**Enterprise**
# CentOS

Take Red Hat's legendary reliability and remove the commercial support to end up with CentOS. If you ever felt a need to self-host a data centre, advanced enterprise software, this might save you a lot of money!

![](bbox=[0.4, 0.49, 0.63, 0.56])

**Everyday**
# Debian

Being the distribution that brought the world the apt package manager definitely earns Debian a place in this list. It is a decent everyday Linux for all who dislike Mark Shuttleworth...

![](bbox=[0.65, 0.49, 0.89, 0.56])

**Security**
# Kali Linux

Reach out and touch a computer system in true Hacking Style. This Debian-derived distribution comes with a set of utilities useful for penetration testing and forensic analysis.

![](bbox=[0.4, 0.67, 0.63, 0.75])

**Oddball**
# Chromium

The operating system powering Google's feature-reduced micro notebooks can also run on your workstation of choice - but be aware that this distro limits you to web apps!

![](bbox=[0.65, 0.67, 0.89, 0.75])

**Traditional**
# Slackware

Slackware can best be described as a living fossil. The oldest still-updated distro allows you to get close to the bone - any true Linux head should take it for a spin!
