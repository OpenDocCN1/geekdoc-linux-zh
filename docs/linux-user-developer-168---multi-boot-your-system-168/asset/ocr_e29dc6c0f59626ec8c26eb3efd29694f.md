# **04**

**Launch Linux for the first time**

After you have extracted your image and installed the Terminal and optionally the VNC companion app, you are ready to launch!

There are a couple of options for launching Linux \- you can either use the Complete Linux Installer app (see the Launch option on the side menu), or you can add a widget to your homescreen. Note that depending on the performance of your device, it can take a couple of minutes for the image to complete the first boot, so be patient!

After your distribution is booted, you’ll be prompted to set the root password, and then you will be able to do as you wish with the chroot! Type `exit` to shut down (you should try to remember to do this, both for battery life reasons and to protect the integrity of your files).

# **03**

**Install the Linux image and companion apps**

When you start the Linux distribution image download, you will be offered a number of options. ‘Large’, ‘Small’ and ‘Core’ image versions are available. The Large images include the core OS and a range of additional apps

such as OpenOffice; the Small images include only basic additions such as a web browser and Java; the Core, as the name suggests, is just the OS itself.

While the main image itself is downloading, it’s a good idea to download the suggested companion apps, too. The Terminal application is used to connect to your chroot in a shell, while the VNC Viewer will allow you to connect to a GUI.
