# 登录

1. Telnet 连接到你选择的机器。如果你需要帮助，请向主要计算站点之一的用户顾问咨询。

2. SHOWME 登录提示看起来如下：

```
showme.missouri.edu

```

如果你是学生，你的登录用户 ID 将是小写字母 'c' 后跟你的学号。如果你有教职员工用户 ID，请查阅校园计算帮助台邮件给你的文档以获取用户 ID 和默认密码。

系统会提示你输入登录密码。

```
showme.missouri.edu
login: c123456
c123456's Password: _
```

如果你有学生用户 ID，则默认密码将是 yymmd 格式的生日。例如：如果你的出生日期是 1974 年 6 月 7 日，则为 740607。第一次登录系统时，系统会提示你设置新密码。系统将提示你输入两次密码（以防止输入错误），以便计算机和人都都认为密码是相同的。在你输入密码时，屏幕不会显示密码。

```
showme.missouri.edu
login: c123456
c123456's password:
You are required to change your password.
Please choose a new one.
c123456's New Password: _
```

选择一个你容易记住但别人不容易记住的密码。

- 请使用包含数字或标点符号的密码。
- 请使用易记的密码。千万不要在任何地方写下密码！
- 请使用你可以快速输入而无需看键盘的密码。
- 不要以任何形式使用你的登录名。
- 不要使用你配偶、孩子或宠物的名字。
- 不要使用易于获取的其他信息。这包括车牌号、电话号码、社会安全号码、汽车品牌、你居住的街道名称等。
- 不要使用全数字密码，或全英文或外语字典的密码。
- 不要使用短于 6 个字符的密码。

每个文件名可以包含任何 ASCII 字符，长度可达 255 个字符。

**大小写敏感！** file（文件）和 file Stuff（文件内容）是不同的。

如果文件名包含对 shell 特定的字符（如：> | & ? 或空格），你必须将其包含双引号或单引号中。例如：

```
'My #1 File' or "tmp/huh?" or 'Read Me\!'
```

Unix 文件按层次结构排列，类似于 DOS 文件的存储方式。路径名是在目录树中移动的工具。目录树以 `/` 开始（称为根目录）。

如果我想绝对引用 c123456 子目录下的一个文件，它看起来像这样：

```
/home/c123456/files/assign1.c
```

总路径长度不能超过 1024 个字符。

你的主目录将是：`/home/userid`。如果你是用户 ID c123456，那么你的主目录将是：`/home/c123456`。

## 发送邮件

- 在 pine 的主菜单中按 C 撰写消息。
- 在 To: 字段输入名称。
- (你可以使用在地址簿中设置的昵称)
- 按 <tab> 移动到下一步，根据需要填写其他字段（尤其是主题字段）。
- 按 <tab> 移动到笔记正文。
- 输入笔记文本。
- 按 X (control-X) 发送，然后按 Y 确认。

## 编辑你的笔记

- 单词在输入时会自动换行。
- 要插入字母、单词或句子，请移动到你想要插入的位置并输入。
- 退格键（Backspace）将删除字母。
- 空格会根据需要（在输入时）在笔记中添加空格。
- 使用 ^J (control-J) 在编辑后对文本进行重新对齐。
- 按 ^T (control-T) 进行拼写检查。

## 查看收到的邮件

- 在 pine 主菜单中按 L 列出可用文件夹。
- 按 <tab> 移动到 'inbox"，按 <return> 选择。
- 使用 <tab> 移动到你想要阅读的消息，按 V 查看笔记。
- 完成该笔记后，按 <tab> 或 N 查看下一条笔记。
- 阅读完邮件后，按 M 查看主菜单。

## 回复收到的邮件

- 在查看笔记时按 R（代表回复）。
- 在开始回复时，对提示响应 Y，则可以包含笔记的原始文本。
- 输入你对笔记的回复，按 ^X (control-X) 发送笔记。

## 管理你的邮件

- 你可以从主菜单按 I 查看当前文件夹中的笔记。
- 你可以从主菜单按 L 列出并切换到其他文件夹。
- 你可以按 D 删除笔记。
- 你可以按 U 恢复已删除的笔记。
- 在阅读笔记时，你可以按 S 保存它们。
- 系统将提示你将消息保存到 "saved-messages"文件夹中。
- 该消息将被标记为从收件箱中删除。

## 创建/编辑地址簿

- 从主菜单按 A 进入 Pine 的地址簿选项。
- 按 A 向地址簿添加名称。
- 按照提示输入其全名（姓，名）。
- 输入一个在 Pine 中使用的昵称。
- 输入你的电子邮箱地址。
- 要编辑字段，使用方向键或 tab 并按 E。
- 你可以按 D 删除一个昵称。

## Pico 编辑器参考

Pico 是一个简单的显示文本编辑器。命令显示在屏幕底部，通过按 ^g (Control-G) 提供上下文相关的帮助。在输入字符时，它们会立即插入到文本中。使用控制键组合输入编辑命令。要开始编辑新文件，请从 SHOWME 提示符输入 pico。屏幕看起来应该像：

```
PICO 2.1                               New Buffer

^G 获取帮助    ^O 写出 ^R 读取文件 ^Y 上一页 ^K 剪切文本    ^C 当前位置
^X 退出        ^J 对齐   ^W 查找 ^V 下一页 ^U 粘贴
```

现在你在文件中输入。只需输入文本即可。完成输入后按 ^o（写出）。Pico 将提示你命名。如果你想编辑现有文件而不是创建新文件，请从 SHOWME 提示符输入 pico <filename>。其中 <filename> 是你要编辑的文件名。

| 键键 命令 |
| Ctrl-f | 向前移动一个字符 |
| Ctrl-b | 向后移动一个字符 |
| Ctrl-p | 移动到上一行 |
| Ctrl-n | 移动到下一行 |
| Ctrl-a | 移动到当前行开头 |
| Ctrl-e | 移动到当前行末尾 |
| Ctrl-v | 向下移动一页 |

## vi 编辑器参考

vi 是一种大多数 Unix 操作系统常用的基础全屏编辑器。该程序实际上是 vi（全屏界面）和 ed（后台宏）的结合。当你使用 `:,` 命令时，你调用的是 vi 编辑器的 'ed' 部分。这里提供了一个快速参考。

> 记住：所有的 Unix 命令都是区分大小写的！

# 缩写

## 计算集群

计算集群适用于有数值批作业的用户。集群机器通过 IBM 的 LoadLeveler 软件共享。机器上的可用软件包括 FORTRAN（包含 IMSL）、SAS 6.09、Gaussian 92 和 Mathematica。

提供了交互式 Shell 脚本以便方便提交作业。

| Shell 脚本名称 | 对应软件： |
|---|---|
| fsub | FORTRAN 和 C |
| ssub | SAS 6.09 |
| msub | Mathematica |
| gsub | Gaussian 92 |

设置了四个作业队列。

| 作业队列名称 | CPU 时间 | 优先级 | 软件 |
|---|---|---|---|
| short | 10 分钟 | 最高 | 所有 |
| medium | 2 小时 | ↑ | 所有 |
| long | 200 小时 | | FORTRAN 和 SAS |
| g92 | 300 小时 | 最低 | Gaussian 92 |

使用 lpr 命令用于在 Unix 中打印文件。命令格式为：

```
lpr [-options] 文件名(s)
```

常用的选项是指定打印机目标 -P。（注意：这是一个大写 P）。没有默认打印机。如果你想将 homework.sas 打印到计算实验室的打印机，命令为：

```
lpr -P fhprpl homework.sas
```

| bpprl | 7 号 Middlebush |
