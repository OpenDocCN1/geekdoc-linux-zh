root mv /home/home.bak          # rename /home /into /home

If everything has gone according to plan, you can use it; however, the data is now located on its hard disk partition, that is, on /dev/sdc3 third partition of the SCSI disk). Use ls -R /home to make sure that all data has been copied. In /home.bak you have a backup copy of the old directory. Once you are sure that all data has been copied, you can delete this copy with rm -r /home.bak.

Up to now, the new partition for /home has only been mounted with Mount. To make this partition automatically available at the next system-start, you must add the following line to /fstab:

```
# Addition to /etc/fstab
# Mount /dev/sdc3 as /home into the file system      0 2
/dev/sdc3      home ext2      defaults
```

In principle, you can transfer any directory (subdirectory) to another partition in the same way we transferred /home in the example above. However, every data contained in the /bin, /dev, /etc, /lib, /root, and /sbin directories should never be removed from the root directory.

# Variation 3 – accessing the second partition via several directories

Variation 2 has the disadvantage that it is not possible to create two directories on the new partition that would be completely independent of each other. It could be useful, for example, to accommodate both /home (with the user data) and /usr/local (with subsequently installed user programs) in the new partition. As the new partition cannot simultaneously be mounted as fstab as /home and as /usr/local, this seems to be impossible.

In such a situation, symbolic links can help. Mount the new partition in an arbitrary directory in the file system (for example, /local for local data partition), copy the required directories into the new partition and create links from the original directories to the new locations.

```
root mkdir /local                               # new directory
root mount -t ext2 /dev/sdc3 /local               # mount new partition here
root cp -dp /home /local                          # copy /home into it
root cp -dp /usr/local /local                     # copy /usr/local into it
root mv /home /home.bak                           # rename /home
root mv /usr/local /usr/local                    # rename /usr/local
root ln -s /local/partition /usr/local          # link to new partition
root ln -s /local/partition /home                  # link to new partition
```
