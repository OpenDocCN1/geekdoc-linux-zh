# PPP BASICS 305

+   * Manual PPP configuration (page 309): first trials with PPP are usually conducted by manually executing the commands minicom, pppd, and so on.
* Testing and error detection (page 312): this subsection describes how to find out whether a connection has been established and what to do in order to identify possible sources of errors.
* Starting and stopping PPP by means of scripts (page 313): once the PPP start-up has worked, you probably want to start PPP with less effort in future. The scripts ppp-on and ppp-off will help with this.
* Menu-driven PPP configuration (page 317): there are numerous programs which try to relieve you from the labor of PPP configuration. However, the prerequisite for a successful application is a basic understanding of PPP.
* SLIP configuration (page 323): if your Internet provider offers SLIP, you will find some information on this subject.

This chapter contains a lot of basic information about PPP. If you simply want to get it working without any delay, and you already have some PPP experience (for example from a corresponding configuration for Microsoft Windows), you can skip the parts on and try the tools described from page 317 onward. If you are lucky, PPP will be up and running within two minutes. If you are unlucky, you can go back to reading about its basics.

The most important prerequisite for PPP is the correct configuration of your modem and serial interface. See page 166.
Additional documentation about PPP/SLIP can be found in the HOWTOs, in the Network Administrator's Guide by Olaf Kirch, in the SuSE installation manual (very practice-oriented!), in the many pages for chat, dip, pppd. and slattatch, and in the README files for PPP and SLIP.

# Glossary

The most important condition for a correct Internet configuration is that your Internet provider has supplied you with all necessary data. Usually, this is a list of strange-looking words and numbers which will look more or less like the table below. (All passwords and IP numbers are obviously imaginary. It will therefore be useless trying to establish a connection with these data.)

```
Phone number: 123456
Email address: hofer@provider.de
User name (Login): hofer
Your PPP/SLIP password: abc5EF6
Domain name server (DNS): 199.85.37.2
SMTP server: mail.provider.de
Pop mail server: pop.provider.de
News server (NNTP): news.provider.de
WWW proxy: www-proxy.provider.de (Port: 8080)
```
