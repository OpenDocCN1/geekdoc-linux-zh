# SELECTING YOUR WINDOW MANAGER OR DESKTOP ENVIRONMENT 267

First, a brief overview of the configuration files which strongly depend on the relevant distribution. If you start X with startx, one of the files is usually responsible for starting the window manager (local files— if present— take precedence):

+   - ~/.xinitrc (local)
- ~/.clients (local, only RedHat)
- /etc/X11/xinit/xinitrc (global, RedHat, Debian)
- /etc/X11/xinit/Xclients (global, only RedHat)
- /usr/X11R6/lib/X11/xinit/xinitrc (global, default setting, SuSE)

If, on the other hand, X is automatically started by xdm at system-up. the following files are concerned:

+   - ~/.xsession (local)
- /etc/X11/xdm/Xsession (global, RedHat, Debian)
- /usr/X11R6/lib/X11/xdm/Xsession (global, default setting, SuSE)

In SuSE, you can easily set the default window manager with Yast when you are logged in as root. In addition, users can select their own preferred window manager by modifying the variable SWDMMANAGER.

> RedHat since version 6.0 you can use the easy-to-handle switchdesk tool

to choose your desktop system (GNOME, KDE, or 'Another Level,' at fwm incarnation), switchdesk modifies ~/.clients.

# The X start-up process

It has already been mentioned that there were several possibilities for starting the X Window System: startx or xdm for a background process (daemon) with a login window. If you regularly work with xdm you can also modify the default runlevel in /etc/initab and enable an automatic start of X on start-up of the computer (see also page 124). If you use the Open Look manager, you must use openwm instead of startx.

The following subsections describe what happens during the execution of the X start-up programs and which configuration files can be modified so that X starts the required window manager (and maybe some other programs) correctly.

# startx

The sole task of the /usr/X11R6/bin/startx script file is to pass client and server options to init, which is responsible for the X start-proper.

```
startx [client options] -- [server_options]
```
