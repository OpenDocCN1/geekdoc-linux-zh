# ALPHABETICAL COMMAND REFERENCE 477

# Example

```
user$ recode ibmpc:latin1 -dosfile linuxfile
```

converts all end-of-line and foreign language characters in the file dosfile into the character set ISO Latin used under Linux. The result is stored in linuxfile.

# reset

reset restores the character mapping which was destroyed by the output of special characters on the screen. reset also restores the terminal settings to the default previously setting with setterm -store. reset should be executed every time strange symbols suddenly appear on screen instead of letters and digits. If reset does not help, set font or restorefont must be executed.

```
restorefont -w file
restorefont -r file
```

restorefont -w stores the currently valid VGA character set in a file. When the command is used with the -r option, this file can be read in order to restore a destroyed character set (normally caused by the X system). restorefont can only be executed in a text console and not under X.

Remember in file you have destroyed the character set. If one day X destroys your character set, you must be able to enter the command blindly. An even better idea is to write a small script (for example, newfont) which carries out this call. Copy this file into /usr/bin and set the bit for all users. As an alternative to restorefont you can call set in order to load one of the predefined character sets.

# restorepalette

restorepalette restores the VGA color palette for the text mode. With some VGA cards, this can become necessary, after switching between X and a text console. restorepalette can only be executed in a text console and not under X.

# rm [Options] file

rm deletes the specified files. Provided that the -r option is not used, directories are not deleted. If you want to delete single directories, you must use the rdir command (see below). When files names contain special characters are to be deleted, the file names must be enclosed in single quotes. The most important options of rm are:

+   - -f deletes without asking for confirmation (including directories). Caution!
- -i or --interactive or -v or --verbose
  displays a request for confirmation prior to the deletion of each single file.
