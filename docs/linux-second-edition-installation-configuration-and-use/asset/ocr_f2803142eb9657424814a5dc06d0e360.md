# Desktop management

# Virtual desktops

In the default setting, KDE manages four virtual desktops, between which you can switch with the KPanel buttons ONE to FOUR or with Ctrl+Tab. A further option for switching windows is to move the mouse beyond the bottom or right border of the desktop. However, a switch is only carried out if you specify the appropriate settings in DESKTOP|DESKTOP. This function takes some time to get used.

The number of desktops (a maximum of eight) can be modified in the control center under APPLICATIONS|PANEL|DESKTOPS. By double clicking on the KPanel buttons you can assign meaningful names to the desktops.

With DESKTOP|BACKGROUND you can individually set the background of each desktop. (Differing colors or background bitmaps facilitate orientation in the desktops.)

Windows are usually only visible on the desktop on which they have been started. However, you can pin down a window, so that it remains visible at the same place even when you switch desktops. To pin down a window, just click the pin symbol at the left border of the window title.

If you want to move a window from one desktop to another, you can also resort to the window menu, entry TO DESKTOP|DESKTOP NAME.

# Desktop pager

A-called desktop pager (pager) can assist with the management of the desktop. This is a program which offers a reduced view of all desktops. Windows can simply be activated with the mouse and moved between different desktops.

# Icons on the desktop

In the default configuration, KDE displays three icons on the desktops. These are symbols for the directories in ~/Desktop. With drag & drop via the context menu NEW, you can put any number of additional icons on the desktop. These can also be, for example, links to files, or other directories, but also symbols for devices or partitions (device icons).

Handling of icons is in itself problem-free, so let us assume that you wish to create an icon for the CD-ROM drive. To do this, you activate the desktop context menu NEW|DEVICE
