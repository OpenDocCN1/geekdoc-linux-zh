# XFree86

# 7

The X Window System (X for short) is a collection of functions and protocols which display graphic information on screen and administer the mouse and keyboard. The functions are also available for network operations.
XFree86 is a free implementation of the X Window System. Originally, it was only available for operating systems with Intel processors (386, 486, and so on; thus the number 86 in the name), but today it also runs on many other processors.
This chapter describes different aspects of the the configuration of the XFree86 server, Furtherther focal points are the use of keyboard and mouse under X, the handling of X resources, and some internals such as installation of additional character sets.

X constitutes the basis for a graphical user interface for Linux. However, under Linux/Unix, the term 'user interface' must be taken with a pinch of salt; unlike MS Windows or the Macintosh world, the look and feel of X programs are affected by the library used by the currently running program, the currently active window manager, and so on. X itself does not provide a user interface. More information on this subject and on fwm, KDE, and GNOME follows in the next chapter.
