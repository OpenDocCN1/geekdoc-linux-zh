# 322 GOING INTERNET WITH LINUX

While PPP configuration with linuxconf worked straight away, usernet networkctl proved to be unreliable in RedHat 5.2. In particular, it was in some cases impossible to deactivate PPP. (This can lead to an unpleasant surprise on your next phone call!) The only remedy is an explicit kill for pppd. (The process ID can easily be determined with cat /var/lock/LCK....ttySn.)

# yast (SuSE)

A prerequisite for PPP configuration with yast is the installation of the susepp package which contains various configuration data for a range of (mostly German) Internet providers.

In yast, SYSTEM ADMINISTRATION/NETWORK CONFIGURATION leads to the start dialog for network configuration. You select the device MODEM PPP with F5, or F6 now leads to the PPP dialog.

The Provider input field allows you to select from a list of predefined providers. If your provider is missing, you must select GENERIC.

Subsequently, you need to enter login name, password, phone number, and IP number of the name server. The options DEFAULTROUTE and (for the moment) AUTOMATIC DIALOG should remain deactivated until you have manually tested the scripts.

In AUTHENTICATION you can choose PAP, CHAP, and TERMINAL. In most cases, the preset PAP is correct. (Information on other procedures can be obtained by pressing F1 or reading the man page for pppd.)

The remaining fields can be left blank for the moment – they become relevant if you want to configure Internet services such as email and news with yast. You can now add additional modem parameters with F4 (in particular, the speed of the interface).
