# Programming

Under Linux you will find a wide range of programming languages: to start with, the GNU and C++ compilers, for which a whole palette of utilities is available (from make to the version control system r and the debugger gdb). Libraries and tool kits allow you to write C programs with graphical user interfaces (such as xWinWindows), or with 3-D graphics under OpenGL (mesa). Many other programming languages are also available under Linux, as Java, Isp, Oberon, Perl, Python, Scheme, SmartTalk, and Tcl/Tk. Also, the available shells (bash, shell) are fully programmable.

# Emulators

Linux also offers a DOS emulator which allows execution of many programs (but not Windows 3.1). The Wine project is trying to realize the execution of programs for Windows, but this project is still very much under development. The fact that Unix programs which correspond to the iBCS2 standard can be executed already been mentioned when presenting the kernel features. Emulators for Atari ST, Commodore 64, Commodore Amiga, Sinclair ZX Spectrum, and so on, are primarily targeted at playful characters.
