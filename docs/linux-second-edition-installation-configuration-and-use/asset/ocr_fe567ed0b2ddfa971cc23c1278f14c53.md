epsffit adapts the size of an EPS file

extractres analyzes the file and supplies %%IncludeResource comments for all necessary files, and so on

fixmps adapts FrameMaker files to the psutils conventions

fixmacaps adapts Macintosh files to the psutils conventions

fixscribeps adapts ScScript files to the psutils conventions

fixtpps adapts Troff/Tscript files to the psutils conventions

fixwfps adapts WinWord files to the psutils conventions

fixwwps adapts WordPerfect files to the psutils conventions

fixxwps adapts MS Write files to the psutils conventions

getaf generates AFM files for the description of fonts

includeres includes the comments generated with extractres into a PostScript file

psbook arranges the pages of the text in such a way that whole sheets (for, with 16 pages) can be printed merges PostScript files into a single file arranges several scaled-down pages on one sheet

psnup changes the required page size of the document. This command solves the common problem of printing out PostScript documents generated for the US Letter format

psresize changes the required page size of the document. This command solves the common problem of printing out PostScript documents generated for the US Letter format

psselect extracts single pages from a PostScript file

pstops arranges the pages of a document in a new order

The above commands can only work when the PostScript files contain comments complying with the DSC standards. DSC stands for Document Structuring Conventions. The comments are not printed, but contain important information about the size of a page, beginning and end of pages, and so on.) EPS files are single-page PostScript files which contain special commands for embedding into other documents (in particular, bounding box specifications regarding the size of the image).

Processing PostScript files generated under MS Windows is rather laborious; even the above commands do not always lead to the desired results. In any case, if you want to have a (remote) chance of success, you must not forget to activate the option for generation of DSC-compliant PostScript files in your Windows PostScript printer driver.

> If the task is only to format a PostScript file in such a way that several pages are printed per sheet, the mpage program described on page 506 is usually easier to handle than the above commands.

# Formatting man texts (groff)

groff is a higher-level command used to control a whole family of text formatting programs, among others groff for the text itself, eqn for mathematical formulae. gpic for illustrations, gtbl for tables, grefer for cross-references, and so on. The groff programs taken together constitute a typesetting system, in its concept
