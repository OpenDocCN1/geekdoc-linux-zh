# Index

If you want to equip your text with an index, several steps are necessary; first you must use \usepackage{...} to load the makeindex package and execute the \makeindex command before \begin{document}. Index entries must be marked in the text with the \index command. Finally, the \printindex command must be specified at the point where the index is to appear in the text.

But this is not enough: after the text prepared in this way has been processed with LaTeX a first time, the LINUX command makeindex name.idx must be executed. All index entries in the file name.idx generated by LaTeX are processed and sorted and the result is stored in the file name.ind. At the next LaTeX run this file is read during execution of \printindex.

# Index entries

```
\usepackage{makeidx}
\makeindex % before \begin{document}
\newcommand{\ii}[1]{{\it #1}} % for italic page numbers
\index{entry} % normal index entry
\index{main entry!subentry} % subentry
\index{main!sub!subsub} % subentry
```

# 612 LATEX

```
\index{entry}() % entry from page
\index{entry|i}) % entry up to page
\index{entry|ii} % italic page number
\index{Pi|\$pi$} % sort formula as 'Pi'
\index{entry(\bf entry)} % bold sort correctly
...
\printindex
```

The most important syntax variations of \index<entry> are obvious from the above table. The character combinations |< and > are used to specify page ranges. The resulting index entry will, for example, look like this: entry 34-38. A command after | and without a prefixed % character can be used to format the page number. A sample for the specification of a suitable command has been indicated with |if(see new command), which can be used to place formula or specially sorted entries at the correct position in the index. All formatting methods mentioned can also be combined, for example to highlight a particular subsumption.

To conclude, there are some examples to illustrate the function of the \index command. The result can be seen in the index at the end of this book.

# 18.4 Mathematical formulae

In order to allow representation of mathematical formula in LaTeX you must switch to mathematical mode. All the commands presented here can only be executed in mathematical mode!

There are three ways to activate this mode; either the formula is enclosed inside the flowing text with $ characters, or the formula is started in a separate paragraph with \[ formula and terminated with \ \], or if the formula is written in an equation environment. In the last two variations, the formula is centered in a separate paragraph; in the equation environment, it is also automatically numbered.

# MATHEMATICAL FORMULAE 613

# LaTeX formula modes

- $formula$ formula in flow text
- \[ formula \] separate formula
- \begin{equation} separate formula with automatic numbering
  formula
\end{equation}

Please note that formula in the flowing text look slightly different from formulae separate paragraphs: in $formula$, LaTeX uses a slightly smaller type size and tries to set the formula in such a way that it takes up as little space as possible. Superscripts and subscripts are positioned differently with some mathematical symbols (limits, integrals, sums).

In the following lines you will see the same formula, $\int_{(i=1)}^{n} x^i dx$, three times: in the flowing text, the formula looks like this: $\int_{1}^{n} x^i dx$. Enclosed in $\dots$ or between \begin{equation} and \end{equation}, the following results are produced:

```
$\int_{1}^{n} x^i dx$
$$\int_{1}^{n} x^i dx$$
```

If you prefer separate formula not to be centered but ranged left, you can use \left at the beginning of your document. Subsequently, you can use \quad to ensure an indentation with respect to the left margin (cm). Alternatively, you can use \right to ensure that LaTeX numbers for equation environment are ranged left instead. Inside formula, text is generally in italics. For variables, this is usually represented with uppercase characters. To achieve this, LaTeX provides its own commands such as $\sin$. $\sin(x^2)$ is generated through the text as output of:

# Construction of mathematical formulas

| Command | Result |
| :--- | :--- |
| $a^{b}$ | $a^{b} \ \sum_{a}^{b} c$ |
| $a_{b}$ | $a_{b} \ \ \frac{a}{b} \ \ \prod_{a}^{b} c$ |
| $\sqrt{a}$ | $\sqrt{a} \ \ \binom{a}{b}$ |
| $\sqrt[n]{a}$ | $\sqrt[n]{a} \ \ \overline{abc}$ |
| $\int_{a}^{b} c$ | $\int_{a}^{b} c \ \ \ \underline{abc}$ |
| $\int_{a}^{b} c$ | $\int_{a}^{b} c \ \ \overbrace{abc}^{d} \ \ \underbrace{abc}_{d}$ |

The above commands are used for the construction of fractions, roots, integrals, and so on. The commands can be arbitrarily embedded in fractions or similar combinations. LaTeX automatically looks after suitable type and formatting details. Please remember when specifying superscripts or subscripts to enclose the relevant expressions in curly brackets - otherwise, ^ and _ apply to the first character.

If you are not satisfied with the type sizes chosen by LaTeX, you can influence them with the following commands:

# Parentheses and brackets

Parentheses and brackets are mainly generated directly with (..) or [..]. Since curly brackets have a special meaning, they must be preceded by a backslash, thus, \{\dots\}.

In mathematical formulas, the size of parentheses and brackets should normally correspond to the size of the bracketed expression. As standard, this is not the case, but it can be achieved with the commands \left and \right put in front of the left and right parentheses or brackets.
