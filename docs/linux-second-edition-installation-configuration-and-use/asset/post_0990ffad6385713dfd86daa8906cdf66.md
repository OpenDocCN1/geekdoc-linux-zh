
## 14.1 Command overview by subject

### File management
- cat concatenates several files into one
- cd changes the current directory
- cp copies files
- ln establishes hard links to files
- ls displays the contents
- mkdir creates a new directory
- mv moves files and changes name
- rm deletes files
- split splits a file into parts
- tee duplicates the standard output

### Finding files
- find finds files by name, date, and size
- locate finds files in a previously prepared database
- which searches directories

### Accessing MS disk
- dd formats a diskette
- format changes the attributes of a file
- cd changes the current directory
- cp copies files to/from Linux
- rm deletes files
- mkdir displays the directory list
- label changes the name
- creates a new directory
- rm deletes directories
- read copies files from DOS
- renames files
- type displays the contents of text
- write copies files from Linux

### Processing text
- cat displays a file or concatenates several files into one
- split splits a text at specified points into single files
- cut extracts columns from each row

### COMMAND OVERVIEW BY SUBJECT
- expand expands tabs into spaces
- fold splits long lines into shorter ones
- converts end-of-line characters into format
- grep searches for text within a file
- head displays the first lines of a file
- less displays page by page (also backwards)
- more displays page by line
- paste concatenates several texts by line
- sed stream editor (programmable editor)
- sort sorts files
- tac displays files the other way (last first)
- tail displays the end of a file
- todos converts characters with other ones
- uniq eliminates lines that occur more than once in a text file
- zcat displays a compressed text file
- zless displays a compressed text file (also backwards)
- zmore displays a compressed text page by page

### Compressing and archiving files
- bunzip2 decompresses files with bzip2
- cpio transfers archive files between different file systems
- gzip decompresses files with gzip
- gzip compresses files; more powerful than compress
- controls the streamer (forward/backward, and so on)
- tar joins several files (and directories) into one file
- uncompress decompresses files with compress

### Process administration
- bg continues a process in the background
- fg continues a process in the foreground
- halt terminates Linux and halts the computer
- kill sends signals (mostly for termination of a process)
- nice starts a process with decreased priority
- ps displays a list of currently running processes
- pstree as ps, but shows dependencies in a better way
- reboot terminates Linux and restarts the computer
- shutdown terminates Linux
- top displays a list of all processes every seconds

## ALPHABETICAL COMMAND REFERENCE

- date: displays date and time
- dmsg: displays the kernel messages of the boot process
- expr: executes simple integer calculations
- free: displays the free memory (RAM and swap storage)
- hash: displays the hash table
- ldd: displays the libraries needed to run a program
- lpr: prints a file
- printenv: only displays the environment variables
- rdev: changes some bytes in the kernel file
- set: displays all variables known to the shell
- sum: calculates the checksum for a file
- tty: displays the device name of the current terminal
- type: displays the type of command (for example, shell command)
- unalias: deletes an abbreviation
- uname: displays name and version of the operating system

The bash is the default shell for most Linux distributions. It is a powerful tool for scripting and interactive use. In this chapter, we will explore some of the most commonly used commands.

## 14.2 Alphabetical command

With a very small number of commands, the order of parameters impacts the way the command is executed. If mutually exclusive options are specified, the option last is generally the one that applies.

In order to keep this chapter down to a reasonable size, only the most important options are described for most commands. A complete overview of all options can usually be obtained by typing `command --help`. More detailed information is usually contained in the manual pages which can be displayed by means `man`. For some commands, the man pages only contain a reference to info texts.
