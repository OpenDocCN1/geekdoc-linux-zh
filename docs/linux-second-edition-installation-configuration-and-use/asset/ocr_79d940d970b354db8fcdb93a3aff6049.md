To start GNOME you can now execute the panel command in an arbitrary window manager. Currently, yast does not allow you to specify GNOME with a window manager as the default desktop. If you want GNOME to be started automatically together with X, you will need to make the following changes to ~/.xinitrc.

# at the end of ~/.xinitrc, instead of: exec WINDOWWMMANAGER
fwm & exec panel

Instead of fwm you can obviously use any of the other window managers supplied (and installed) together with SuSE. Unfortunately, the window manager best suited to GNOME, namely Enlightenment, is supplied in an obsolete and poorly configured version. Only anarchists will get any joy out of this.

# Shadow password system

SuSE uses the shadow password system. In this system, passwords are not stored directly in /etc/passwd, but in a separate file /etc/shadow, which can only be read by root. To register new users, should use yast.

If you manually enter a new user into passwd, you also need to make a corresponding entry in shadow (leaving the password field empty). Subsequently, you log in with the name and call passwd to assign the new user a password. Further information on the shadow password system can be found in the HOWTO text of the same name.
