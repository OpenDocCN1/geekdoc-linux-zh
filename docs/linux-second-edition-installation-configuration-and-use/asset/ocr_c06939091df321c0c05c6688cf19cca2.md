Conversely, when you write DOS files, their carriage return characters are inserted - it feels like heaven!

Automatic conversion only affects ends of lines. The character set special characters in DOS text files remains unchanged. A list of all file extensions excluded from automatic conversion can be found in the file /usr/src/linux/fs/misc.c.

The snake is the recognition of text files. Any file that does not have a well-defined extension (such as *.exe, *.dll, *.gif, and so on) is incorrectly interpreted as a text file. If it is a binary file, it is incorrectly interpreted during access. If, for example, you use tar to carry out a backup of a DOS partition, the chances that part of the backup file is unusable! Thus, although the option conv is very convenient, it is a serious danger! Please activate this option only if you are completely aware of the damage you may cause.

# ASCII → PostScript conversion (a2ps, mpage)

Since Postprinters expect each output in the form of commands, it is not possible to send an ASCII file straight to the printer without prior processing. For ASCII PostScript conversion, you can use the a2ps and mpage commands.

```
a2ps [options] ascii.file > ps.file
```

In the default setting is the recognition of text (that is, without options) a2ps formats the text in a two-column page in landscape format. Both columns are automatically specified with frames and headers. In the following list, only those options are indicated that do not apply as default settings anyway.

+   -1 prints one column (instead of two columns in landscape format).

+   -L uses the ISO Latin character set. Allows printing of foreign language special characters, but only on Level 2 PostScript printers.

+   -n sets the size to n points. This authoritatively affects line spacing and the number of lines per page. n is specified using a floating number.

+   -p portrait format instead of landscape.

+   -nd, -nl, -nh, -nu

+   prints no date, no login info, no header, no file name.

+   -ns prints no frame around the text.

There is a detailed man page for a2ps. An overview of all options can be obtained with a2ps -h. In this help text, the default settings are marked through the use of upper case letters.
