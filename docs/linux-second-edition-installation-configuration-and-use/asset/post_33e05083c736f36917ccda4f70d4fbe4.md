
# Document structuring

\part(Title) part (only for book and report)
\chapter(Title) chapter (only for book and report)
\section(Title) section
\subsection(Title) subsection
\subsubsection(Title) subsection section numbering itself.

LaTeX deals with chapter and section numbering. At the same time, LaTeX automatically selects suitable typefaces and text spacing for the titles. In the book text type, the text in the \chapter and \section commands is also taken into account for generating running heads. When the commands are used in the form \section{short version}, the short version is used for running heads and table of contents, whereas the complete version is used for body text.

If the text is to be equipped with an appendix, this is started with the \begin{appendix} command and ends with \end{appendix}. Inside the appendix, \chapter, section can be used, with the chapters now numbered A, B, C...

Thus, the general structure of a typical LaTeX looks approximately like this:

```
\documentclass[11pt]{article}
\usepackage{isolate1}

% space for macro definitions, variable assignments, and so on
% possibly table of contents with \tableofcontents

\begin{document}
% the text itself, structured by means of
\section(...), \subsection(\hdrsecb ...), and so on

\begin{appendix}
% the appendix text, again structured by means of
\section(...), \subsection(\hdrsecb ...), and so on
\end{appendix}
\end{document}
```

# Fonts and attributes

Other text processing programs have probably got you to a practically unlimited choice of fonts and sizes. For historical reasons, this is not the case in LaTeX. As a rule, LaTeX restricts your choice to three families: one standard font used for flow text, headings, and so on. The Typewriter font for font listings and the Sans Serif font for highlighting and other tasks.

These three fonts (or better 'font families') can be formatted with different attributes. The highest number of attributes exists for the standard font, which can be represented as bold, italic, slanted and small caps.

You may not be aware of the difference between italic and slanted: for slanted text, LaTeX uses the normal character set and inclines the letters slightly to the right. For italic text, a separate character set is used in which the characters are somewhat more inclined and slightly differently shaped. This subtle difference, however, applies only when LaTeX's own fonts are used. This book, in contrast, uses PostScript fonts in which no difference can be noted between italic and slanted text.

| Standard font normal | italic | SMALL CAPS |
| :--- | :--- | :--- |
| bold | italic | BOLD SMALL CAPS |
| Sans Serif normal | italic | SMALL CAPS |
| bold | italic | BOLD SMALL CAPS |
| Typewriter normal | italic | SMALL CAPS |
| bold | italic | BOLD SMALL CAPS |

LaTeX is usually capable of representing the Typewriter font. In the above list, this has been made possible for setting this book. PostScript fonts have been used instead of LaTeX's own character sets. More information on the subject of LaTeX and PostScript fonts can be found from page 62 onwards, where the LaTeX utility program Metafont and the handling of PostScript fonts are discussed.

# Special characters and accents

A large number of special characters is possible in mathematical mode - for example, $\pi$ with $\leftarrow$. A summary of the most important mathematical symbols is given in Section 18.4.

An alternative of representing text containing special characters is provided by the command \verb_text_, \verb_ls | yield ls |. In this example, the underscore character was used to enclose the text itself, but you can use any other character provided that it does not occur in the text to be represented. The text inside of \verb is set in typewriter font. \verb cannot be limited in a number of environments and certainly not for the definition of macros. \verb texts are limited to a maximum of one line. There is no way of representing \verb text in bold face.

When you do not wish to represent just a few characters, but want to represent several lines, you can use the \begin{verbatim} environment and terminated with \end{verbatim}. All lines between are set unchanged in the typewriter font. The verbatim environment is particularly suited for program listings, which are usually strewn with special characters.

```
verbatim environment
\verb_text sets the text including all special characters
\begin{verbatim} starts text which is to be unchanged
multi-line text with ^^
special characters $ %    end of the verbatim environment
\end{verbatim}
```
