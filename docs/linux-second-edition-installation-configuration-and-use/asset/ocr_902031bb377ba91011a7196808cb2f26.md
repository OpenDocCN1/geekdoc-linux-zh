Frames
in the main, a line can be drawn left and/or right of each column and above/or below each row. When two lines meet, a small space is inserted between the rows or columns. (Thus the double line above the sum row of above originates from the fact that lines have been drawn below the fourth row and above the fifth row.)
The buttons and symbols for handling frames mainly apply to all selected rows or columns. After many commands, however, the selection is automatically deselected, so that selections often need to be repeated several times.

It is possible to draw lines individually for single fields. All settings apply to entire rows or columns. (Obviously, this rule too has its exception - namely marked with the MULTICOLUMN attribute. A corresponding example can be found in the User Manual.)

During work on (the German version of this) book, several table operations unwittingly brought the table into an incorrect state. (For example, a table field was missing in the last row. LTeX failed in its attempt to set the table, because apparently \end{tabular} had got lost as well.) The only remedy was to create a new table and transfer it by copying and pasting into the correct parts. Subsequently, the defective table was completely deleted.

# Table of Contents

Generation of a table of contents is a really simple operation: you just need to insert the contents list at the required place in your document (usually at the beginning or by end) by INSERT LIST AND TOC TABLE OF CONTENTS. In LyX you only see a small box, the whole list is visible in the preview.

To generate the contents list, LyX automatically gathers all of the types chapter, section, subsection, and so on, except for the homonymous types followed by an asterisk, that is chapter*, section*, and so on. The required depths of the table of contents (that is, the number of hierarchy levels) can be set via LAYOUT:DOCUMENT.
