
# Tables

Producing clearly structured tables in LaTeX is easier thanks to WYSIWYG features, but handling is still far from being intuitive. (Here, the symbol bar gives KLX a clear advantage over LyX.) Furthermore, in comparison with true text processing programs, the layout possibilities are severely restricted. however, this is not the fault of LyX, but rather LaTeX.

Tables belong to the very few features that may cause stability problems in both LyX and KLX. The only crash that occurred during writing of the German version of this chapter concerned a table operation. (However, even in that situation, KLX still succeeded in carrying out a complete emergency backup – wouldn't it be nice to see Word do the same?)

When you insert a new table into your document by means of INSERT TABLE, it will look like this (initially, quite obviously, without contents).

| Title 1 | T2 | T3 | T4 | T5 |
|---|---|---|---|---|
| Line 1 | A | B | C | D |
| Line 2 | EE | FF | GG | HH |
| Line 3 | III | JJJ | KKK | LLL |

LyX treats the table as a whole as if it were a paragraph. Thus, if you wish to range the whole table left or right, you need to use LAYOUT PARAGRAPH.(Before after a table, LyX inserts a vertical space of 3 mm. This too can be changed or deleted in the PARAGRAPH dialog)

It is useful to put tables into a float environment by means of INSERT FLOAT. This makes the table's position on the page variable, and can avoid big holes when laying out the pages. (Labeling of tables in float environments works in the same way as with figures – see above.)

# Table contents

Not only can normal text be entered in the cells of the table including all character formatting alternatives; but it is also allowed to include figures and formulas integrated into the text. Not allowed, instead, the use of paragraph formats these apply to the whole table and the insertion of floats or subtables

Copying and pasting works in tables too, to a large extent. However the columns can be selected or processed. Also the transfer of data between tables works without major problems if the number of columns is the same

If you wish to copy an entire table (not just parts of the table's contents); you need to select the whole table, plus some characters of the preceding and the subsequent paragraph.

# Table structure:

For the purpose of changing the table structure– for example for inserting or deleting lines and columns, and so on – LaX provides a separate dialog (simply called by clicking the right mouse button), while LaX provides a symbol bar remarks

- The ALIGNMENT (left | centered) applies to the entire column in which the cursor is currently positioned
- The SPECIAL COLUMN allows several fields of a row to be combined into one larger field
- With SPECIAL CELL ROTATE 90, the text of an individual field can be rotated by 90 degrees (for example, for column labeling)
- The column width is usually adjusted to the longest entry. The width of individual columns can, however, also be fixed (for example to 5 cm). In this case, the field contents are automatically distributed across several lines. However, this effect is not visible in LaX itself, but only in the preview. In a longer text, you can force a linebreak inside LaX by means of Co– however, this linebreak is valid only inside LaX and treats this line as a break and helps to keep an overview of longer lines field itself. (Caution: once a linebreak has been inserted with Co– in the current version of LaX/LaX it can only be removed by deleting the entire line!)
- Finally, the table dialog provides possibilities for creating special tables in landscape format or tables that spread over several pages. However, these functions go beyond the scope of this chapter and are not discussed

Some special table features–such as the 90-degree rotation of individual fields or entire tables– are neither visible in LaX nor in the DVI preview. Please use the PostScript preview!

Frames in the main, a line can be drawn left and/or right of each column and above/or below each row. When two lines meet, a small space is inserted between the rows or columns. (Thus the double line above the sum row of above originates from the fact that lines have been drawn below the fourth row and above the fifth row.)

The buttons and symbols for handling frames mainly apply to all selected rows or columns. After many commands, however, the selection is automatically deselected, so that selections often need to be repeated several times.

It is possible to draw lines individually for single fields. All settings apply to entire rows or columns. (Obviously, this rule too has its exception - namely marked with the MULTICOLUMN attribute. A corresponding example can be found in the User Manual.)

# Table of Contents

Generation of table of contents is a really simple operation: you just need to insert the contents list at the required place (usually at the beginning) by INSERT LIST AND TOC. In LyX you only see a small box, the whole list is visible in the preview. The required depths of table of contents (that is, number of hierarchy levels) can be set via LAYOUT:DOCUMENT.

 Slightly more work is required to create an index. Here, you first need to insert the required entries by means of INDEX ENTRY. The syntax is the same as in LaTeX (see page 611). The Index itself is inserted (usually at the end of the document) by means of INSERT LIST AND INDEX.

# Cross references

If you wish to make use of cross references, you must first insert a text label with LABEL and give it a name. Subsequently, you can insert a page or section number (reference) by means of INSERT CROSS-REFERENCE. The LaTeX document shows only a small box at this position. Only the page preview displays the correct numbers.

# Bibliography, References

LaTeX can help manage a simple reference section (bibliography). The entries in this list need to be at the end of the document. For this purpose, you insert a new paragraph and select bibliography, as its type. In this paragraph, you can enter the references in the required format.

The peculiarity of the bibliography format is that a button with a running number appears to the left of the reference. When you click on this, you can extend the number with two reference indications, the KEY and the LABEL. The KEY is required to refer to the reference in the running text. The LABEL is the text that appears in the printed document. If you leave the label empty, all bibliography entries are simply numbered in the sequence in which they are quoted in the reference section.

To insert a reference to a bibliography entry into your text, execute INSERT CITATION REFERENCE and select the required entry from a selection list. (Caution: LaTeX displays the content of the KEY; the content of the LABEL is only shown in the final document!)

An example: a very compact introduction to LaTeX is given by [Et98]. The entry in the References section looks as follows.

- [Et98] Etrich, Matthias: Schön schreiben mit Linus. LaTeX. In: PC Magazin 8/98, WEKL-Verlag 1998, S. 24-27.

The method of creating a bibliography described above corresponds to the LaTeX commands \cite and \bibitem (see page 608). In future versions, LaTeX will probably also support the LaTeX utility program bibtex, which provides much more advanced features for managing bibliographic references.
