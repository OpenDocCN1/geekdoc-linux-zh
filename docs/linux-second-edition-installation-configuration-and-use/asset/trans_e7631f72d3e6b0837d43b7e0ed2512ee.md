许多发行版之间的竞争可能会推动它们的进一步发展，但在安装未随发行版一起提供的程序（尤其是商业用程序）时，也会产生许多动荡。缺失或过时的程序库通常是程序无法运行的原因。对于 Linux 初学者来说，实际上无法解决此类问题。有些软件制造商甚至远到，只有当其产品与特定发行版配合使用时才提供支持（显然，每个制造商选择的发行版都不同……）。

为了消除这些问题，Linux 标准基础（LSB）应而生，它旨在定义未来符合标准的发行版的最小共同性标准：

```
http://www.linuxbase.org
```

由许多厂商每两个或三个月发布的 CD-ROM 镜像不应与发行版混淆。镜像是互联网上所有 Linux 特定程序的副本。镜像并不包含发行版；相反，你从中找到各种 Linux 程序的最新版本（通常是带有源代码的存档文件）。但不要被镜像的低成本所迷惑：安装程序需要手动操作，并假设对 Linux 有一定了解。初学者更适合那些通过预配置包完成安装的发行版。需要最新 Linux 程序和在线文档但无法访问互联网（或不愿意支付费用）的经验 Linux 用户。

# 某些 Linux 发行版

以下是可用发行版的概述（按字母顺序排列，且并非详尽）：

## Caldera

Caldera Open Linux 是为专业用户创建 Linux 发行版的成功尝试。（与此同时，许多竞争者通过各种附加组件在 Novell 网络功能方面表现出色。）

## Debian

虽然大多数发行版是由公司为了盈利而编写的，但 Debian 是一个特例；该发行版由致力于稳定和遵守“自由”软件规则的 Linux 用户编写。该发行版的几个概念——例如软件包管理——为其他发行版确立了标准，并在许多方面仍然处于领先地位（在不重启电脑的情况下更新您的发行版！）。在过去的几年里，Debian 变得越来越易于使用；然而，对于 Linux 初学者来说，由于其复杂的软件包管理，该发行版仍然并不适用。

## RedHat

RedHat 发行版是目前维护最好的发行版之一。该发行版特别主导美国市场。基于 rpm 格式（RedHat 的开发）的软件包管理已被许多其他发行版采用。RedHat Linux 在多个平台（Intel、DEC Alpha、Sun Sparc）上可用。除了 RedHat 发行版，还有许多衍生发行版提供了各种改进、语言适配（如西班牙语版）、附加组件（KDE）等。

## Slackware

Slackware 是最早的 Linux 发行版之一（SLS 现已过时）。在维护和安装便利性方面，目前的 Slackware 已无法跟上其他发行版的步伐。

## SuSE

得益于其时效性、大量的预配置包、全面的手册以及优秀的维护，SuSE Linux（Gesellschaft für Softwareentwicklung）已成为欧洲最广泛使用的 Linux 发版。然而，SuSE Linux 也提供英语菜单和手册。强大的管理工具不仅有助于解决（几乎）所有配置问题（包括 ISDN 配置），而且像 Debian 一样自动解决安装过程中可能依赖问题。

## TurboLinux

该发行版由 Pacific HighTech（PHT）编写，专门为日本的使用进行了优化，并在那里是市场领导。该发行版也有英语版本。

## 极简发行版

除了这些大型发行版，你还可以在互联网上找到一些微型系统集合（单个磁盘即可一个完整的 Linux 系统！）！这些发行版大多基于（因此较小的）内核版本，专门为特殊任务设计，例如维护工作（应急系统）或在不进行适当安装（直接从一个或多个磁盘）的情况下使用 Linux 系统。这适用于你需要在一个你不想或不允许分区的外部计算机上定期运行 Linux。

# Linux 的起源

本节不涉及 Linux 的更多细节，而是涉及如下问题：Linux 真的存在吗？系统是如何开发的？为什么它是免费的？在此过程中，GNU（GNU 不是 Unix）和 FSF（自由软件基金会）发挥了重要作用。

Linux 是一个非常年轻的操作系统。最早的内核部分（0.01 版本）是由 Linux Torvalds（赫尔辛基）独立开发的。他于 1991 年 9 月通过互联网发布了代码。在很短的时间内，全球程序员对这个想法产生了兴趣并开始为它编写扩展：更好的文件管理系统、各种硬件组件的驱动程序、额外的程序（如 DOS 模拟器）等。所有这些组件也免费提供，整个系统以惊人的速度增长。如果没有全球程序员通过互联网进行的通信，一个新的操作系统永远不会以此方式产生。

Linux 尽管不包含大型软件公司的产品，但之所以能够快速开发的主要原因之一，在于当时免费获取的软件。Linux 并非像某些错误论言的那样凭空出现，而是基于自由软件平台。Minix 为第一步工作提供了实践基础，这种软件虽然免费但功能有限。因此，第一版本的 Linux 仍然使用 Minix 文件系统。

更重要的是（现在也是如此）是大量的 GNU 程序。GNU 程序的出现时间比 Linux 长得多。在许多 Unix 系统上，GNU 程序已经被用作原始组件的更好替代品。
