# kdvi

The KDE variation of xvi is kdvi. In contrast to kghostview, kdvi provides substantial improvements with respect to the original in the display of page numbers, which allows much easier navigation through large documents. The printing function is also worth noting — you can use kdvi, for example, for easy creation of a PostScript file that contains four pages per sheet. (kdvi resorts to the mentioned programs dvips, dvljj, mpage and spnup.)

# Viewing PDF files (acroread)

PDF files can be displayed with the mentioned programs ghostview kghostview, and with the special programs xpdf and acroread. All of these programs, acroread provides by far the best results (extremely sharp text representation). Furthermore, it is the easiest to use.
