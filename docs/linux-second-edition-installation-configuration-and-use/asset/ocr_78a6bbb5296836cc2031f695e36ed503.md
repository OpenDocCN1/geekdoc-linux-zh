# 17.1 Fundamentals
Configuration files

When GNU Emacs starts up, three files – if present – are read in sequence:

```
/usr/share/emacs/site-lisp/site-start.el
./emacs
/usr/share/emacs/20.2/lisp/default.el
```

With XEmacs, four files are read:

```
/usr/X11R/lib/emacs-20.4/lisp/site-start.el
./emacs
./emacs-options
/usr/X11R/lib/emacs-20.4/lisp/default.el
```

If, depending on the distribution, the programs are installed in a different directory (/usr/lib and /usr/local), the path specifications must obviously be changed. If needed, make use of locate to search for the files.
-start.el is the place for global settings which should be carried out in any case, while .emacs is personal for configuration settings. default.emacs again applies to all users, but can be individually deactivated with the activation (setq inhibit-init 1) in .emacs.
The file .emacs-options is automatically created by XEmacs the first time you make changes in the OPTIONS menu and save them. Furthermore, XEmacs spends some additional lines to the file .emacs to ensure that .emacs-options is automatically loaded by XEmacs (but not by GNU Emacs).

> SuSE Linux includes its .emacs file (see the /etc/sk directory) which, depending on the Emacs version, automatically loads gnu-emacs-emacs-custom. Furthermore, changes made through Alt-X customize-browse (see page 572) are automatically stored in .emacs-custom instead of .emacs. This mechanism is, however, not standardized.

# Directories of Lisp files

Most Emacs functions and, in particular, all Emacs extensions and processing modes are implemented in the Emacs-internal programming language (a dialect of Lisp). In this respect, .emacs is nothing special; it joins the existing basic binary of Lisp files.

Lisp files are usually located in two directories: the Emacs Lisp directory contains all Lisp files that belong to standard Emacs. The site Lisp directory is the right place to put additional files that expand the functionality of Emacs. (In principle, these files could also be installed in the Emacs Lisp directory, but they would get lost at the next Emacs update).
