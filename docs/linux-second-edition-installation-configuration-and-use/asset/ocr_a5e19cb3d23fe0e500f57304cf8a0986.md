# 19.5 Hints and tricks

n-dashes

In $LyX$, en-dashes are entered as two consecutive minus signs, that is, --.

Word spacing

To extend the individual lines of a paragraph to the same length in justified typesetting, $TeX$ inserts an equal amount of space between all words (of the same line). After a full stop (end of sentence), this space is a bit wider. If example, for an abbreviation, a normal space is used after a full stop, a symbol may be inserted between the full stop and the space in $TeX$ mode (input via $	ext{Alt}+	ext{Ctrl}+	ext{C}$, $	ext{V}$, $	ext{Alt}+	ext{T}$). In $LyX$ this looks like: Dr.V Weber. To prevent two words from being separated by a linebreak, a fine space can be specified by $	ext{Ctrl}+	ext{Space}$, for example 3 cm.

Hyphenation

$TeX$ does not always recognize all possible hyphenations (or even hyphenates correctly). In such cases, you can use $	ext{Ctrl}+	ext{-}$ to insert a soft hyphen which $TeX$ will use if needed.

Quotation marks

Similarly to Emacs in $TeX$ mode, $LyX$ tries to use typographic quotation marks of the “citation” form.(Although both quotation marks have been input with “”, they have a different shape and constitute a group). If you need a normal (‘’ quotes–for example when entering commands, program listings, and so on–you need to use $	ext{Ctrl}+	ext{-}$

Spell check

$LyX$ has no spell check of its own, but resorts to the well-established $spell$ program of the Unix/Linux world. This program is installed together with the word tables for the desired language, you can start the spell check with $	ext{EDIT}$$	ext{SPELLCHECKER}$, or still, with $	ext{F7}$. (The spell check starts at the current cursor position).
