mkinitrd evaluates the information in /etc/conf.modules. If a SCSI adapter
is required for booting, conf.modules must contain a line of the following form:
alias scsi_hostadapter aic7xxx

> CAUTION
 of this boot process, it is not possible in RedHat to simply copy /boot/vmlinuz onto a diskette and use this to boot a SCSI system. Instead, you must either use the option initrd=/boot/initrd or compile a new kernel in which SCSI support for your card is directly integrated.

# Language settings

First brief digestion: at each start of a shell /etc/profile is executed. One-peculiarity of RedHat is that in this script file all *.sh files in the /etc/profile.d directory are started. Out of these files, lang.sh is the one is responsible for setting the required language (for example for GNOME menu texts).

However, the hide-and-seek game goes further: lang.sh in turn returns to /etc/sysconfig/i18n is an abbreviation of 'internationalization' commonly used in the Unix world. Changes to this file must be carried out with an editor – currently neither the control-panel tools nor linuxconf can be used for this purpose. For the English language (US/UK) the following settings in /etc/sysconfig/i18n are of use:

```
# /etc/sysconfig/i18n
LANG=C
LINGUAS=en
LC_ALL=en_US or LC_ALL=en_UK
```
