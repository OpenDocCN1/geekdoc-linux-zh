# minicom

minicom is a terminal program for text mode. Its handling the DOS program minicom accesses the modem via the device file /dev/mod. In order to configure minicom, you should start the program with the option -s. Now, instead of /dev/mod, you can specify the serial interface directly (for example, /dev/tty51). This is necessary when several programs access the serial interface and your system also answers incoming calls (for example, to receive faxes). Together with the serial interface, you can also set the requested transmission speed. The configuration is stored in /etc/minicomrc.

Usually, minicom is configured in such a way that it can be used by root. To allow the program to be used by other users, root must enter their names into the configuration file /etc/minicom.users. This is normally the second step after setting up the serial interface.

minicom is menu-driven. The main menu (a kind of help text) is called with Ctrl+A. By entering an additional letter, you are led into submenus, for modification of various configuration data. Once you know the corresponding letters, you can circumvent the main menu and call a command directly with Ctrl+A and a letter (for dialing).

Apart from the extension of minicom.users, no further configuration for minicom is needed; the default settings can stay unchanged. If you are using a modem that does not use the AT command, if you want to transmit additional initialization commands to the modem, and so on. The configuration should be carried out by root, which will make it valid for all minicom users.
