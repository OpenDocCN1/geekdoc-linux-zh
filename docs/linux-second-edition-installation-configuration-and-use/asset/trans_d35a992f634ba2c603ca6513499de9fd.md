

# LINUX 提供了什么？

你必须追逐成百上千的更新。一旦 Linux 在你的计算机上稳定运行，很少有理由去更改任何内容——内核的修改涉及 Linux 的某些非常特定的方面，例如系统对新硬件的适应、错误的修正（尽管这些错误通常只在极少数情况下发生）或对某个功能的优化。

总而言之，你不应该对这些版本号感到太困惑：内核不仅仅是一个数字，实际上，Linux 下可用的几乎每个库、编译器、程序、发行版等都是如此。关于内核及其特性的更多背景信息将从第 199 页开始提供，在那个章节中你可以找到如何编译一个针对你自己的计算机优化的最新内核的描述。

# 1.2 Linux 提供了什么？

“Linux 是什么？”这个问题还没有完全完全的回答。许多用户根本对内核感兴趣——只要它能运行并支持现有的硬件即可。对于这些用户来说，日常语言中使用的“Linux”一词除了内核之外，还包含了以发行版形式随 Linux 内核一起提供的巨大程序包（见下节）。

本节概述了 Linux 最重要的功能和可用的应用程序。自然，这并不是完全的——去听每一个在 Linux 下运行的程序是没有意义的。

# 内核功能

- Linux 支持多任务处理（多个进程的并发执行）、多用户操作（多个用户并发使用）、分页（当可用内存不足时将内存交换到磁盘）、共享库（文件系统库仅在多个进程需要时才加载）、进程间通信（IPC），以及——从 2.0 版本开始——对称多处理（SMP，多个进程的使用）。
- Linux 支持几乎所有常见的 PC 硬件；所有兼容 Intel 386 的处理器；ISA、EISA、VLB 和 PCI 总线系统；大多数（IDE 和 SCSI 硬盘控制器及硬盘，连接到它们的 CD-ROM 驱动器和磁带；大多数未连接到 IDE 或 SCSI 总线的驱动器；大多数网卡、鼠标等。（完整列表见《硬件手册》——参见第 4 章从第 69 页开始）。
- Linux 不仅支持 Intel 处理器，还支持 Alpha 处理器、Sun Sparc、Motorola 等。最常用的变体无疑是 Intel 的。
- Linux 使用自己的文件系统（ext2fs）。文件名可以包含最多 255 个字符，文件大小可达 2 Gbytes，文件系统可达 4 Terbytes。它还配备了许多安全特性。（当 Linux 在 64 位处理器上运行时，文件大小也可以大于 2 Gbytes）。
- 在 Linux 下，可以访问外部文件系统：DOS、Windows 9x（带长文件名）、NTFS（只读）、OS/2（只读）、Minix、NFS（通过网络提供的文件系统）等。然而，无法访问压缩的 DOS/Windows 分区（除非通过使用 DOS 模拟器的冗长程序）。
- Linux 支持几种用于执行二进制文件的二进制格式：a.out（版本 1.0 标准）、ELF（从 1.2 版本起的标准）和 iBCS2。iBCS2 允许你使用适用于 SCO Unix 的许多商业程序，而无需任何重新编译或移植到 Linux。由于越来越多的软件供应商为他们的程序提供单独的 Linux 版本，iBCS2 模拟器的重要性正在降低。（命运的捉弄：SCO 现在提供了一种模拟器，允许在 SCO Unix 下使用 Linux 程序）。
- 在 Linux 下，提供了一一系列网络协议（TCP/IP、PPP、SLIP 等）。

与内核 2.0 相比，内核 2.2 为普通用户只带来了少数实质性的变化。然而，在表面之下发生了许多变化。SMP 支持得到了显著改进，内存管理得到了优化。在网络函数中可以找到许多新代码，这些代码一方面必须更快速、更稳定，另一方面又应该支持额外的协议（包括新的 IP 版本 IPnG）。

对多个非 Intel 处理器的支持比以前更深入地集成到代码中。新的内核函数有助于模块的动态激活/去激活（而不是将此任务留给外部内核程序）。此外，还有针对 ISDN、SCSI 和声卡的海量新增或改进的硬件驱动程序。

Linux 在文本模式下稳定运行的最低要求大约是 Linux 2.0 需要 4 Mbytes 内存，Linux 2.2 需要 5 Mbytes 内存。然而，为了让系统运行得足够快，至少 8 Mbytes 是更好的选择。如果你还想使用 X Window 系统，你至少需要 16 Mbytes（最好是 32 Mbytes）。如果你想将一台旧的 486 PC 变成 Linux 工作站，旧版本的内核可能就足够了。一个非常稳定的版本是，例如版本 1.2.13。与 2.n 内核相比，这个版本相对节省空间。

# X Window 系统

启动后，最初在文本模式下运行，并可以在多个终端之间切换。（通常有六个可用终端，可以通过 Alt+F1 到 Alt+F6 键组合访问）。

在 Linux 下启动 X Window 系统也是可能的。为了运行 X Window 系统，你需要免费的端口 XFree86 或商业 X 服务器（例如 Xside 或 Metro-X）。XFree86 支持几乎所有发布过文档的显卡。

从实际意义上说，X Window 系统只是一个在屏幕上图形化显示信息的函数集合。基于此构建了图形用户界面和应用程序，它们极大地简化了操作。Linux 发行版主要包括窗口管理器 fwm、桌面系统 KDE 和 GNOME 以及一系列 X 程序。

# 工具

命令的输入在所谓的 shell 中执行。shell 类似于 DOS 命令解释器，但要强大得多。在 Linux 下，提供了几种 shell。最流行的是 bash（Bourne Again Shell）。不喜欢这个的人可以使用 tech（兼容 shell）。

有很多命令可用于文件管理和系统管理，例如 ts（对应 DOS 的 dir）、cp（对应 COPY）等。对于处理文件，还有大量的文件管理器可用，它们要么在文本模式下运行（例如 me，很大类似于 Norton Commander），要么支持 X。

编辑器的范围从简单的编辑器（如 vi），到一种难以构建但在所有 Unix 系统上通用的编辑器，再到像 Emacs 巨大的编辑器。这个程序有时被讽刺地称为一个操作系统，因为它包含了如此大量的函数；Emacs 可以用于读写电子邮件和新文章、调试 C 程序等。在这种情况下，“编辑器”一词已不再完全适用。

# 文本处理与格式化

Linux 下的主流（免费）排版程序是 LaTeX。对于这个不太容易处理的排版程序，LaTeX 程序提供了一个现代的界面，几乎实现了 WYSIWY（所见即所得）。此外，Linux 还提供了各种工具和实用程序来处理 PostScript 文件或将其转换为其他格式等。

# 网络软件

Linux 支持 TCP/IP、PPP、SLIP 协议。它允许构建任意复杂的本地网络。提供了各种连接互联网的客户端和服务器程序（telnet、rlogin、电子邮件、新闻、ftp、WWW）。因此，在 Linux 下，你不仅可以使用互联网服务，还可以自己建立互联网服务器。Samba 允许管理 Windows PC 可以作为客户端访问的网络（访问文件、打印机等）。
