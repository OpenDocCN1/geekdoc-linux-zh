Handling of abbreviations becomes even more interesting with the following macro: expand-abbrev-or-dabbrev first tries to use an abbreviation contained in the abbreviation table. If no suitable abbreviation is found, the macro calls dabbrevexpand in order to expand dynamically. F3 can be used for predefined abbreviations and for dynamic expansion at the same time.

```
(defun expand-abbrev-or-dabbrev()\ ;expansion of abbreviations with F3
  (interactive)
  (if not (expand-abbrev))\ ;if no abbreviation exists
    (progn
      (dabbrev-expand nil)))  ;dynamic expansion
(global-set-key [F3] 'expand-abbrev-or-dabbrev)
```

The example above also shows the definition of a new Lisp function: the function initiates with the keyword defun. Through the interactive command, the function is registered as an Emacs command and can then be called with [Alt+X] the same way as all other commands.

# Changing upper and lower case spelling

Although Emacs has commands to change a letter, a word, or any other area into upper or lower case, it still lacks a command that simply invert existing spelling: every upper case letter is to be substituted with its lower case equivalent and vice versa.

The resulting function change-case is more complex, it is used to define the variable char in which the character at the current position is stored by char-after(point). In the subsequent if, it checks whether ASCII code of this character is greater than 64. This is the case for all letters (and several special characters). If so, the progn block is executed.

At this point, the sixth bit of the character code is changed (XOR 32). This changes an A (code 65) into a (code 97) and insert-char is used to insert the resulting character at the current position, and the original character is deleted.

The else part of the if condition is only executed if the code for the cursor was less equal 64 (digits, space, new line, comma, and so). If so, the cursor is moved one character forward. Since the else block consists of one single function, no progn block is required.

Subsequently, the new function is assigned to the function key F2. If pressed several times in sequence, the cursor moves forward through the text and changes all letters. To undo such a change, F2 must be pressed again over the letter in question. The program also works for German umlauts.
