

# 许多 GNU 工具，如 `find` 和 `grep` 等。只要 Linux 内核开发到可以让 GNU 编译器在上面运行的程度，几乎整个 GNU 工具集就随之可用了。因此，裸内核演变成了一个相当详尽的系统，为更更大的开发者社区提供了一个具有吸引力的环境。

通过 Linux，GNU 程序可以自由复制，但受到某些限制——而且不仅以二进制程序的形式提供，还带有其完整的源代码。这允许所有 GNU 用户在遇到问题或错误时自行扩展或纠正程序。这些修改使得各种 GNU 程序产生了更优秀、更成熟的版本。特别是由于程序代码免费可用，GNU C 编译器几乎出现在每一个 Unix 系统上。（也有针对 DOS/Windows 的移植版。）事实上，Linux 是从 GNU C 编译器开始的。

Linux 内核、大量的 GNU 组件、BSD Unix 的网络软件、MIT（马萨诸塞州理工学院）同样免费的 X Windows 系统以及针对 Intel 处理器的 PC 的 XFree86，以及 TeX 等其他程序相结合，使得 Linux 发行版变成了完整的 Unix 系统。

Linux 显然并非仅仅是 Linux Torvalds 一人的脑力成果（尽管没有他，就不会有目前形式的 Linux）。Linux 是许多人辛勤工作的结果，多年来他们一直在业余时间编写自由软件（在某些情况下，可能是作为他们计算机学习的一部分）。与此同时，Linux 内核的代码行已经超过了令人置信的百五十万行！最重要的名字包含在 `/usr/src/linux/CREDITS` 文件中。安装内核后你就可以阅读这个文件。

# 法律事项 – 通用公共许可证 (General Public License)

Linux 是“自由”的——但这到底意味着什么？通常，“free”被理解为免费的。Linux 确实是免费提供的（至少通过互联网），这是 true；但“free”也可以指的是完整源代码的可用性。这引入了复杂性。如果一家公司使用了 Linux 代码，对其进行扩展，然后出售该系统呢？这这也是被允许的，尽管有一个限制：新系统的程序代码必须免费可用。这确保了所有用户都能从系统的扩展中获益。

因此，GNU 和 Linux 开发者的目标是创建一个源代码且且保持免费可用的系统。为了防止滥用，由 GNU 开发过和正在开发的软件受通用公共许可证（GPL）的保护。GPL 由自由软件基金会（FSF，见 www.gnu.org）支持。该组织由 Richard Stallman（Emacs 编辑器的作者）创立，旨在让高质量软件免费可用。

GPL 的核心原则是，人们可以修改代码甚至销售生成的程序，但用户/买方有权获得完整代码，可以轮流对其进行修改，并免费赠送。每个 GNU 程序必须与完整的 GPL 许可证一起发布。因此，受 GPL 保护的软件不应与完全不受保护的公共领域软件（Public Domain Software）混淆。

因此，GPL 排除了人们在不公开修改内容的情况下开发和销售 GPL 程序的可能性。每一次开发都成为所有用户的获益。

你可以在几乎每一张 Linux CD 上找到完整的 GPL，它是一个名为 `COPYING` 的文本文件。

> 如果你想了解更多关于自由软件的概念，请安装 GNU Emacs 并按下 `Ctrl+H`, `Ctrl+P`，Emacs 将显示一段描述 FSF 目标的文本，并提供对常见问题的解答（例如：“程序员不会饿死吗？”）

除了 GPL，还有 LGPL 变体（GNU 库 GPL）。它与 GPL 的本质区别在于，通过这种方式保护的库也可以被代码非自由的商业产品使用。如果没有 LGPL，GPL 库只能用于 GPL 程序，这在许多情况下对商业程序员来说是一个不当的限制。

顺便说一下，Linux 发行版的所有部分并不是以相同的方式保护的。虽然 Linux 和许多工具受 GPL 保护，但 Linux 下的其他程序是共享软件（例如流行的图形程序 `xv`）：私用是是免费的，但对程序的任何商业应用只有在向作者注册后才被允许。

# 安装

本章概述了如何在带有 Intel 兼容处理器的 PC 上安装 Linux 系统。它没有指某个特定的发行版，而是以通用的方式描述了相关的安装步骤（如磁盘分区），并传达了必要的基础知识（让你知道自己在做什么）。某些选定发行版的具体细节可以在附录 A 到 C 中找到。

在首次安装 Linux 时，最麻烦但大多数情况下无法避免的步骤是重新划分磁盘分区。在本章中，详细描述了必要的命令（DOS 下的 `FDISK` 和 `FORMAT`，Linux 下的 `disk`）。本章还解释了 Umsdk 的安装，它可以避免重新分区（但有其他几个缺点）。

对于入门来说就到这里为止：近年来，安装已变得越来越简单。在本章中描述的许多详细问题指的是旧硬件，而这些硬件现在已经极少使用了！

在本章中，同时出现了 DOS 和 Linux 命令。由于这些原因，Linux 命令使用小写字母（而 DOS 命令使用大写）。

## 2.1 要求

为了能够安装 Linux，必须满足以下要求：

- 你需要一台带有 Intel 兼容处理器的 PC。（虽然有其他处理器的版本，但本文不涉及。）

- 你需要足够的内存。多少“足够”取决于你如何使用 Linux。在文本模式下，8 MB 就够了。如果你想使用 X Windows 系统作为图形界面，你至少需要 16 MB，最好是 32 MB。

- 你需要一个具有足够磁盘分区。在这里很难判断多少“足够”。最小安装可以占用 50 MB（如果非常有必要的话）。另一方面，如果你进行标准安装，500 MB 是下限。更好的值是 1 GB——这为你测试软件包、个人存档等留了足够的空间。

某些发行版还允许测试安装，其中只安装部分数据。所有其他数据通过所谓的 CD-ROM 现场系统读取。这种安装节省磁盘空间，但速度慢且缺乏活性。

- 你需要 Linux 识别并支持的硬件组件。目前，大多数硬件都是如此。问题可能由特种或最近引入的 SCSI、显卡和网卡引起。要让即插用声卡正常工作通常需要大量精力。对于所谓的 GDI 打印机、Windows 调制解调器（即没有智能、完全依赖仅适用于 Windows 程序的设备）以及 USB 硬件，没有任何支持。

- 如果你想舒适地使用 X Windows 系统，你需要一个三键鼠标，因为鼠标中键在 X 中起着重要作用。在双键鼠标上，可以同时按下两个键来模拟缺失的中键，但这很麻烦。

- 如果发生硬件问题，你需要对计算机硬件有相当详细的了解。安装失败通常是因为安装程序无法识别组件。手动输入硬件数据可以解决这个问题。然而，你将处理中断和 IO 地址。
