## Layout restrictions

LyX is not a text processing program in the style of WinWord, WordPerfect, or Star-Writer. In formatting of LyX documents is limited by the possibilities of LaTeX. If you have previously worked with a traditional text processing program (such as WinWord), you need to rethink your approach. Here are some examples:

- It is not possible to enlarge the distance between two paragraphs by inserting additional empty lines - LaTeX ignores them. (You can, use Ctrl+Enter to insert 'hard' line breaks, which in LaTeX are generated by \.)

- It is impossible to separate two words by more than one space. (You can, increase the space between two words by inserting LaTeX commands such as \quad, into the text. In LyX texts, you can generally resort to all LyX commands.)

- You are also restricted in your selection of fonts - as usual in LaTeX documents, there is only one standard (default) font, plus two additional fonts (Sans Serif and Typewriter).

- LyX does not have tabs. (There is a separate command for simple tables. Multi-column text can be realized by so-called minipages. In this regard, however, LyX cannot compete with traditional text processing programs.)

The above points represent a true restriction only if you put a great emphasis on a layout of your own - for example for designing a cover or a poster. For this kind of purpose, LyX is not suited. But for the vast majority of 'normal' texts - letters, masters these, or articles - LyX is an obvious choice. In such cases, almost all of the layouts automatically generated by LyX look more professional than self-created

## WYSIWYG limitations

It has already been mentioned that LyX can nearly handle WYSIWYG. So where are the restrictions?

- LyX can display neither line breaks nor page breaks. (To find out how the typeset document will finally look you need to convert the document into DVI or PostScript format to obtain a page preview.)

- No hyphenations are shown.

- Page numbers, headers, footers, and so on are also invisible.

## Other limitations

Obviously, LyX documents can be exported into LaTeX without problems other than LyX being simply a sort of user interface for LaTeX. Since version 1.0 the opposite, that is, import of LaTeX files into LyX, is also possible, although frequently a cause of problems. The reverse command is FILE | IMPORT. The file to be imported must, however, be a complete LaTeX document (not part of a group of several files) and should preferably not use any LaTeX features not available under LyX. Even if these conditions are met, import not always works satisfactorily.

Behind the scenes, import is handled by the Perl script relx which, which is extremely well documented by a man text.

A further disadvantage is the fact that LyX documents cannot be subdivided into several smaller files without some difficulty.

## LyX versus Kly

Currently, there are two LyX versions which differ manj from each other in their user interfaces. The standard version (that is LyX) is based on the Forms library, whereas Kly uses the Qt library. Kly is therefore particularly suitable for integration into a KDE system and gives a slightly more contemporary impression. Another decidedly useful feature is the possibility of opening several windows and splitting windows. Thus the (partial) windows can be used to display several documents and/or sections of a long document.

At the time of writing, LyX was stable version 0.9. The contents of the two files - with regard to the layout - are identical; however, different programs are used for display (xdvi/ghostview with lyx or kdvi/ghostview with kx).

The variation you choose of the two available is a matter of taste. The DVI variation is somewhat faster. However, if you use a large number of illustrations, you will probably prefer the PostScript variation.

The first display of a LyX document - no matter DVI or in PostScript format - may take some time while LaTeX sets of the required sizes are created. However, this delay occurs the first time (or precisely, every time you use a new character shape (font) or size for the first time).

You need not restart xdvi or ghostview for each page preview. Instead, you can use the commands FILE UPDATE DVI or FILE POSTSCRIPT, which only update the current preview files. xdvi recognizes the changes automatically, while with ghostview you need to press R (for reload) to cause the file to be read again.

The quality of font display in ghostview increases significantly if you activate the antialiasing function (see page 518).

LyX documents cause no problems, provided that the printer configuration was carried out correctly (see page 162). With PRINT, LyX generates the same PostScript file as the page preview and passes it to the default printer lb means of lyr.

## 19.2 Working techniques

### Your first LyX document

To create a new, empty document, you execute FILE|NEW and specify a file name. LyX automatically completes the name with the extension *.lyx. Now you are ready to type your text.

## Paragraph formatting

In most cases, you will use the list field at the left-hand side of the symbol to change the format of one or more selected paragraphs. The choice of available format types depends on the selected document class (LAYOUT|DOCUMENT, see below).
