## Tables

LaTeX has several possibilities for defining tables. At this point, we only describe the simplest variety, namely the tabbing environment. The syntax of this environment looks as follows:

```
Tables
\begin{tabbing}
sample = sample \= kill
term1 \> term3\
term4 \> term5
\end{tabbing}
```

Tables are initiated with a sample line. This line defines the positions of the left-ranged tabs. Your sample line should normally be the widest line in your table. Before each \=, you should insert an additional space, for example with a \quad instruction (space of two hyphens – see page 618). \kill deletes the sample line, so that it is only used as a sample, but is not output.

An example to conclude: the special character on page 601 was produced with the following LaTeX instructions:

```

{sm\verb?}}
\> starts comments\
```

## Bulleted and numbered lists

\LaTeX offers several possibilities for formatting lists of items. The simplest variation is constituted by the itemize environment.

## Lists

```
\begin{itemize}
\item Text of the first item
\item Second item
\end{itemize}
```

The following example shows the visual layout of a bulleted list:
\begin{itemize}
\item \LaTeX marks the items of a List with thick black bullets (special character \verb?$?).
\item At the same time the entries are indented with respect to the normal text.
\end{itemize}

- * \LaTeX marks the simple items of a list with thick black bullets ($$).

- * At the same time the entries are indented with respect to the normal text.

If instead of itemize use the environment name enumerate, \LaTeX uses numbers (1., 2., and so on). Both environments can be embedded into each other. Depending on the level of embedding, different symbols are used for the bullets and different kinds of numbers for enumeration (lower case letters, roman numbers, and so on). In addition, the list items are indented by different amounts of space.

## Multi-column text

We have already described on page 597 how the option twocolumn in the documentclass be used to arrange the entire text in two columns. In many cases, however, this solution is not suitable. Only small portions of text are to be arranged side by side, while the remaining text goes over the full page width in one column. For such occurrences, LaTeX offers several variations, of which only the most important one is presented here: the minipage environment. The syntax is as follows:

```
minipage environment
\begin{minipage}[t](4cm) % the first, 4 cm wide minipage
text ... % the text of the first minipage
\end{minipage}
\fill
gutter between first and second minipage
\begin{minipage}[t](4cm) % the second minipage
text ...
\end{minipage}
\fill
\begin{minipage}[t](4cm) % the third minipage
text ...
\end{minipage}
```

The total width of all specified minipage environments must not exceed the total width of text. The optional parameter t (top) causes the upper edges of text blocks to be vertically aligned. Alternatively, you can specify b (bottom) to align the edges of the text blocks or you can omit the parameter to center the text blocks vertically. The command \fill between the blocks causes the remaining horizontal space between the blocks to be distributed equally between them.

```
\begin{minipage}[t](6cm)
This is the first, 6 cm text block.
\end{minipage}
\fill
\begin{minipage}[t](6cm)
The second block is placed next to it and has the same width. Both blocks are aligned with reference to their upper edges.
\end{minipage}
```

This is the first, 6 cm text block. The second block is placed next to it and has the same width. Both blocks are aligned with reference to their upper edges.

## Frames

Text can be highlighted by putting it into a frame. The command for this is \fbox{text} and produces results such as `\fbox{text}`. When multi-line blocks are to be framed, a minipage environment must be defined within the \fbox command.

## 18.3 Typesetting scientific texts

In principle, you can set any text with LaTeX. However, the advantages of LaTeX over other typesetting and word processing programs really come to the layout of scientific texts, where the task is to create tables of contents, lists of illustrations, references and indices, to use cross-references, insert footnotes, and so on, with little effort as possible. This section summarizes the LaTeX commands for the realization of such 'typically scientific' layout features.

### Table of contents

The table of contents can be inserted at any point in the text by the \tableofcontents command. Usually, the table of contents is placed at the beginning of the text or after the preface.

In order to generate the table of contents, LaTeX processes the file name.toc with the command \tableofcontents, each LaTeX inserts into this file all information needed for the table of contents (chapter, section and subsection together with their page numbers). This procedure may cause a worst-case scenario of having to run LaTeX three times to obtain a correct table of contents.
