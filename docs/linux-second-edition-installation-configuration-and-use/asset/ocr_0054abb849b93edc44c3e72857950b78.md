# Resource files

Resource files can be stored in different locations in the directory tree. Depending on the distribution, these files are automatically recognized in the following locations.
The files are listed in increasing order of precedence.

# Locations of X resource files

+   default settings exclusively for the xdm login:
/etc/X11/xdm/Resources or
/usr/X11/lib/X11/xdm/Resources

+   optional local default settings, in many systems recognized only by startx (but not by xdm):
~/.Resources

+   global default settings for a specific program:
/usr/X11/lib/X11/app-defaults/progname

+   current user's local settings:
~/.defaults (in RedHat)
~/.Resources (in SuSE)

The Xresources files are read in only once at the start of X (see page 267). The settings in the app-defaults directory and those of in .defaults, on the other hand, are read at the start of every program.

Absolute precedence over all resource files mentioned above is given to options which are directly specified at program start. Obviously, this also applies to programs started by xintrc or via fwm.
The syntax used for resource files has probably become clear from the above examples. Upper and lower case spelling usually plays no role (but there are exceptions!). Comments are marked differently: instead of the # known from other programs, they begin with an exclamation mark. Also, comments must be on lines of their own — resource settings are not allowed to have appended comments.

The easiest way to change resource settings is to take existing .Xdefaults as a model and copy the lines that you can use into your own .Xdefaults file andpossibly change some settings). Examples of resource settings can be found in the files of the app-defaults directory.

> can also be found in the man texts for the program in question. The general concept of resources is described in the man texts for X and xrddb.
