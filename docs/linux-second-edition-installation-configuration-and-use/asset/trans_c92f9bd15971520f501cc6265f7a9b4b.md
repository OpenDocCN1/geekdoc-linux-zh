

## 14.1 按主题分类命令概述

### 文件管理
- cat 将多个文件合并为一个文件
- cd 更改当前目录
- cp 复制文件
- ln 为文件建立硬链接
- ls 显示内容
- mkdir 创建新目录
- mv 移动文件并重命名
- rm 删除文件
- split 将文件拆分成多个部分
- tee 将标准输出复制到文件中

### 查找文件
- find 按名称、日期和大小查找文件
- locate 在预先准备的数据库查找文件
- which 搜索目录

### 访问 MS 磁盘
- dd 格式化磁盘
- format 更改文件属性
- cd 更改当前目录
- cp 在 Linux 之间复制文件
- rm 删除文件
- mkdir 显示目录列表
- label 修改名称
- 创建一个新目录
- rm 删除目录
- read 从 DOS 复制文件
- renames 重命名文件
- type 显示文本内容
- write 从 Linux 复制文件

### 文本处理
- cat 显示文件或将多个文件合并为一个
- split 在指定位置将文本拆分为单个文件
- cut 从每行中提取列

### 按主题命令概述
- expand 将制表符扩展为空格
- fold 将长行拆分为较短行
- 将换行符转换为特定格式
- grep 在文件中搜索文本
- head 显示文件的前几行
- less 分页显示（也支持反向查看）
- more 按行显示
- paste 按行合并多个文本
- sed 流式编辑器（可编程编辑器）
- sort 对文件进行排序
- tac 反向显示文件内容（最后一行在前）
- tail 显示文件的末尾
- todos 将字符转换为其他字符
- uniq 消除文本文件中出现多次的重复行
- zcat 显示压缩的文本文件
- zless 显示压缩的文本文件（也支持反向查看）
- zmore 分页显示压缩的文本页

### 压缩与归档文件
- bunzip2 使用 bzip2 解压缩文件
- cpio 在不同文件系统之间传输归档文件
- gzip 使用 gzip 解压缩
- gzip 压缩文件；比 compress 更强大
- 控制流器（向前/向后，等等）
- tar 将多个文件（和目录）合并为一个文件
- uncompress 使用 compress 解压缩

### 进程管理
- bg 在后台继续进程
- fg 在前台继续进程
- halt 终止 Linux 并停止计算机
- kill 发送信号（主要用于终止进程）
- nice 以较低优先级启动进程
- ps 显示当前运行的进程列表
- pstree 类似于 ps，但以更好的方式显示依赖关系
- reboot 终止 Linux 并重启计算机
- shutdown 终止 Linux
- top 每秒显示所有进程列表

bash 是大多数 Linux 发行版的默认 shell。它是一个用于脚本脚本编写和交互式操作的强大工具。在本章中，我们将探索一些最常用的命令。

## 14.2 字母顺序命令

在极少数命令中，参数的顺序会影响命令的执行方式。如果指定了互斥的选项，通常最后一个指定的选项将生效。

为了保持本章节长度在合理范围内，大多数命令仅描述了最重要的选项。通常可以通过输入 `command --help` 获取所有选项的完整概述。
