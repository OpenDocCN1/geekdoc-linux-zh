Once Linux runs stably on your computer, there is rarely a reason to alter anything at all — modifications of the kernel concern very specific aspects of Linux, such as adaptation of the system to new hardware, correction of errors (which mostly occur only under rare circumstances anyways), or optimization of a function.

# 1.2 What does Linux offer?

The question – What is Linux? has not been answered fully. Many users are not interested in the kernel at all — as long as it runs and supports the existing hardware. For these users, the term ‘Linux’, as used in everyday language, includes, apart from the kernel, the huge bundle of programs that come with the Linux kernel in the form of distributions (see the following section).

This section gives an overview of the most important features of Linux and the available application programs. Naturally, this is not complete — it would make little sense to listen to every single program that runs under Linux.

# Kernel features

+   - Linux supports multitasking (concurrent execution of several processes), multiuser operation (concurrent usage by several users), paging (swapping of memory to disk, if the available RAM is not sufficient), shared libraries of file systems are loaded only), once even when they are needed by several processes; redress communication (IPC), and — since version 2.0 – Symmetric Multi Processing (SMP, the use of several processes).
- Linux supports practically all common PC hardware; all Intel 386-compatible processors; ISA, EISA, VLB, and PCI bus systems; most (IDE and SCSI hard disk controllers and hard disks, CD-ROM drives and streamers connected to them: most COM-ROM drives not connected to an IDE or SCSI bus; most network cards, mice, and so on.(A complete list is given in the Hardware Manual— see Chapter 4 from page 69 onwards).
- Linux supports not only Intel processors, but also the DEC Alpha processor, Sun Sparc, Motorola, and so on. The most widely used variation is certainly the Intel one.
