# Starting Linux from DOS (LOADIN)

With LOADIN you can start Linux within DOS. Via an appropriate configuration of AUTOEXEC.BAT, DOS can be set up in such way that after booting you can choose between Linux and DOS. In this respect, LOADIN is a true alternative to LILO.

The biggest advantage of LOADIN is that you do not have to touch your boot sector. The disadvantage is that DOS needs to be as as operating system (a DOS window under Windows is *not* sufficient). LOADIN cannot be used on computers where only Windows NT is installed.

# Preparation

The use of LOADIN assumes that you know the device name of your root partition. If you are not sure, execute df and write down the name of the file system that is mounted at the mounting point / (in the following example, this would be /dev/sda15).

```
root# df
Filesystem 1024-blocks Available Capacity Mounted on
dev/sda15 303251 261723 25867 91% /
dev/scd0 584650 584560 0 100% /cdrom
dev/sda12 303251 114286 173304 0% /home1
dev/sda11 303251 189963 97627 66% /usr/local
```

Furthermore, you need a copy of the kernel file that can be read under DOS. You must copy this file into a DOS partition. The easiest way is to mount the DOS partition C: into the Linux file system and copy the kernel file (generic) into it. A safe place would be the C:\LOADIN directory which can, if necessary, create under Linux. In the mount command, instead of /dev/sda1, you must specify the name of the first DOS partition. If you do not know its name, just execute fdisk -l.
