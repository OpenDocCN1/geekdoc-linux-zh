# Documentation on individual software packages

Additional documentation on all kinds of software packages (programming languages, tools, and so on) is usually installed in the directory /usr/doc/packages/name/. The extent and topical of these files vary greatly. Often, you only find a README file containing the copyright notice and a brief description of where to find the remaining documentation.

Obviously, not all programs adhere to this convention (this would be far too easy). You should in any case check the installation directories of the programs in question. For example, you will find a large amount of online documentation on BibTeX (TeX documentation) in the following directory:

/usr/lib/TeXX/texmf/doc

With some programs (for example Gimp), the online documentation is so voluminous that it is stored in a package of its own which is not automatically installed. Thus, it is often worthwhile taking a closer look at the list of packages that have not been installed.
