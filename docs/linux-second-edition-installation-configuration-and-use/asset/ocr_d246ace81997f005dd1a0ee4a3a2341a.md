+   Rather less frequently, CHAP (Challenge/Handshake Authentication Protocol) is used for identification – for example, when Windows NT is used as a PPP server. In this case, the pppd configuration file is etc:/ppp/chap-secrets.

Extensive information about PAP and CHAP can be obtained through man pppd or by looking at the PPP-HOWTO.

# Testing the connection

In order to test whether the PPP connection has been successfully established, the next step is to execute config. The result should look more or less like the following: besides the loopback device, there is now a PPP connection (device name ppp0) from your IP address 199.85.96.166 to the IP address of the Internet 199.85.37.3.
