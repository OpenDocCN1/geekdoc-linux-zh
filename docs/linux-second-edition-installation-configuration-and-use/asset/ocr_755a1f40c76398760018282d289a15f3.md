# ALPHABETICAL COMMAND REFERENCE 457

# Examples

```
user find
```

supplies a list of all files in the current directory and in all subdirectories.

```
user find -name ".*"
```

find all files in the current directory and in all subdirectories whose names begin with .e.

```
user find / -path /latex/*.tex
```

*.tex files in a directory that ends in latex. (This search pattern is sufficient to find the files contained in /usr/lib/texmf/latex in a relatively short time!)

```
root# find /home -group users -ctime 5
```

find all files (that belong to /home that belong to users of users' group and that have been modified in some way (contents, access rights, and so on) over the past five days, -ctime 5 finds files modified more than five days ago, -ctime 5 modified files exactly five days ago.)

```
user head -name ".e*
```

displays the first ten lines of .e files on screen. Please note that the search pattern is enclosed in left quotes, where the whole command as an argument of head. If you use another command instead of head, you can copy, delete, compress and do other things with the files found

```
user find -name ".tex" -type f -exec grep -exec emacs \; -print
```

search *.tex files for the character string 'emacs'. If the string is found, the file name is displayed on screen. Please note that the -print option must not be specified before -exec - otherwise all .tex file names are output, independently of whether emacs was found or not (also see grep on page 459).

```
user find -name "*" -maxdepth 1 -size -10k -exec grep -q \
> case.in {} \; -print
```

search all files in the current directory which are *smaller than 10 Kbytes for the regular expression *.in. The list of files found is stored in the file result. The restriction of the file size to 10 Kbytes is used to exclude the (much larger) binary files from the search.

# fold [Options] file

breaks lines at a length of 80 characters and displays the result on screen.

```
-w n or --width n
```

sets a maximum width of n characters.

```
-s or --spaces
```

tries to break the lines at a space (that is, between two words). Thus, the line length will become less than equal to n characters.
