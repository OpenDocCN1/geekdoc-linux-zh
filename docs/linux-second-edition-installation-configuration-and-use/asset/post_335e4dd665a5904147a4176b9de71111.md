
# X FONTS

The font naming conventions are described in the content of the Gimp command on page 678. A list of all available fonts can be generated by means of xlsfonts. You can, however, also use the more user-friendly programs fontsel and fontmanager (KDE).

To enable XFree86 to find the font files, the paths to the font directories must be listed in the Files section of XF86Config (This section also contains the path to a file with names of the RGB colors, which are, of no interest here.)

## Excerpt from XF86Config

Section "Fonts"

- RGBPath "/usr/X116/lib/X11/rgb"
- FontPath "/usr/X116/lib/X11/fonts/misc:unscaled"
- FontPath "/usr/X116/lib/X11/fonts/75dpi:unscaled"
- FontPath "/usr/X116/lib/X11/fonts/100dpi:unscaled"
- FontPath "/usr/X116/lib/X11/fonts/URW"
- FontPath "/usr/X116/lib/X11/fonts/freefont"
- FontPath "/usr/X116/lib/X11/fonts/Type1"
- FontPath "/usr/X116/lib/X11/fonts/Speedo"
- FontPath "/usr/X116/lib/X11/fonts/misc"
- FontPath "/usr/X116/lib/X11/fonts/75dpi"
- FontPath "/opt/StarOffice40/fonts/type1"

EndSection

The keyword unscaled means that, with all fonts of the directory in question, X does not attempt any scaling of its ones. This keyword can also be employed with non-scaled fonts. This leads to the effect that unscaled fonts can definitively only be used in the predefined sizes.

In the above font list, some paths are specified twice, the first time with the unscaled addition and later again without it. The consequence: when searching for a font in a specific size, X first tries a matching non-scaled bitmap standard font. If no matching font can be found, scaled fonts are considered as well. If this search fails, the makeshift solution is adopted to have the X server increase or reduce the size of a non-scaled font - with the unsatisfactory results mentioned earlier.

> The order of paths in XF86Config has a decisive influence on the display quality. When an X program requires a font without precise specification of all parameters, the first matching font is returned on the basis of the path order in XF86Config.(Only in exceptional cases does X programs really specify all parameters of a fonts - including the name of the manufacturer, and so on.) Therefore, unscaled fonts that can be displayed crisply in all sizes should appear at the beginning of the Files section.

## XFree86 standard fonts

### 75-dpi fonts

The XFree86 basic package contains exclusively non-scalable fonts for a screen resolution of 75 dpi. (Information on the dpi value and how to change it follows on page 255.) The standard fonts include, amongst others, Courier, Helvetica, New Century Schoolbook, Times, and Utopia by Adobe, Lucida by B&H, and Charter by Bitstream. These are usually installed in the following directories:

```
/usr/XFree86/Lib/XFree11/fonts/75dpi
/usr/XFree86/Lib/XFree11/fonts/latin2/75dpi
/usr/XFree86/Lib/XFree11/fonts/misc
```

### 100-dpi fonts

A separate package is available for XFree86 which, with the exception of metric fonts, includes the same fonts for a higher resolution of 100 dpi. Please note that this package is not always installed automatically. An installation can make sense if you want to keep the 75 dpi set as a default, because some programs (such as LyX) take all installed fonts into account to achieve an optimal text display.

```
/usr/XFree86/Lib/XFree11/fonts/100dpi
/usr/XFree86/Lib/XFree11/fonts/latin2/100dpi
```

## Speed and Type-1 fonts (scalable)

Finally, XFree86 comes with several Speedo and Type-1 fonts – in SuSE, for example, in the xfontset package. These fonts are not always installed automatically. Speedo is the name of the font format adopted by Bitstream. Type-1 fonts like the PostScript fonts they are also suitable for printing without any additional conversion tools. Generally, both font types are scalable.

The package includes the Courier and Utopia fonts by Adobe, together with Charter and Bitstream. (Courier fonts are thus multiply available under X - scaled and not scaled, by different manufacturers, and so on. You may, for example, use the fonts of Gimp to explore the subtle differences.)

```
/usr/XFree86/Lib/XFree11/fonts/Speedo
/usr/XFree86/Lib/XFree11/fonts/Type1
```

> Obviously, manufacturers such as Adobe, Bitstream, and others offer more fonts than the few supplied with XFree86. The problem: these fonts are usually not freely available, but be bought (as any commercial product). Most of the fonts supplied with XFree86 are only available because they were released – almost as a gift – by these companies.

## Font server

To understand the principle of a font server, first you must create a configuration file. Its name is predefined; here we use /etc/xfs-config. Information on the structure of this file can be found in xfs.

```
# /etc/xfs-config
# Paths for fonts
catalogue = /usr/X1116/lib/X11/fonts/URW,
/usr/X1116/lib/X11/fonts/freefont,
/usr/X1116/lib/X11/fonts/Type1,
/usr/X1116/lib/X11/fonts/Speedo,
/usr/X1116/lib/X11/fonts/misc,
/usr/X1116/lib/X11/fonts/75dpi,
/usr/X1116/lib/X11/fonts/100dpi
# set 12 point default size (in datapoints)
default-point-size = 120
# 100 or 75 dpi default resolution
default-resolutions = 100,100,75,75
```

Now you can start xfs in a text console. (If you want to start it automatically, you should create Init-V files - see also page 124. In the Debian distribution, these files are part of the delivery.)

```
root# xfs -config /etc/xfs-config -port 7100 &
```

With this xfs runs as a background process and can be addressed via the TCP-Port 7100. To enable X to find the font server, XFree86Config needs to be modified.

```
# Addition to XFree86Config
Section "Files"
```

```
FontPath "tcp/localhost:7100"
EndSection
```

## TrueType fonts

Apple Macintosh and Microsoft Windows computers use a different font format than Unix systems, namely TrueType. Due to the distribution systems, there is a huge range of economical and in many cases free TrueType fonts. If you want to use these fonts under Linux as well, you need to install a font server that can handle this font format. (RedHat 6.0 comes with a preinstalled TrueType font server.)

The following description focuses on the most popular program for this purpose: xfont. This is an xfs-compatible font server which, in addition, can handle TrueType fonts. The program is available on the Internet both source code and as a binary file. The documentation is part of source package; thus you need it in any case.
