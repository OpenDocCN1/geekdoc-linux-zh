# Configuring the computer in a local network

If you want to embed your Linux computer into an (already existing) local TCP/IP network, the configuration program asks some questions. The correct answers may strongly depend on how the existing network is configured. For the following-example, the following assumptions are made: local network with addresses 192.169.1.n, domain name galactic.network, no gateway, no name server. Then, the following input would be possible (and sensible):

Host name: jupiter (if this name is still free to be used)
Domain name: galactic.network
IP number: 192.168.1.27 (if this name is still free to be used)
Netmask: 255.255.255.0
Broadcast address: 192.168.1.0

Furthermore, you must specify through which interface (normally the Ethernet card) the connection to the network will be made. If a gateway/or a name server exist, simply specify their IP addresses (if necessary, together with their host and domain names).

> The network connection will only work if the kernel correctly recognizes the Ethernet card. The dmesg command displays the corresponding kernel messages.

# Configuration files

In most cases, a simple network configuration carried out with the tools supplied by the current distribution will work without problems. However, if you want to know where you can intervene manually, this section gives you some information. But please, make backup copies of all files you intend to modify – depending on the distribution, cooperation between configuration files is not very fault-tolerant!

/etc/HOSTNAME

This file just contains the complete Internet name of the computer (for example, jupiter.galactic.network).

/etc/hosts

This file contains a list of known IP numbers: 127.0.0.1 is the standard IP number for the loopback device. Additional numbers may designate the Ethernet, PPP or SLIP interfaces.

```
# /etc/hosts
# For loopbacking.
127.0.0.1 localhost
192.168.1.5 jupiter.galactic.network jupiter
```
