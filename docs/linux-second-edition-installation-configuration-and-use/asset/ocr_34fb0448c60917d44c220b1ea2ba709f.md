# Configuration

Appearance, operation and functional extent of strn can be extensively modifi-
tied by the configuration file /.strnrc. Setting options and syntax are
documented in the accompanying example file strnrc (usually in the directory
var/lib/strn).

Sender's address

strn normally employs the user name, host name, and domain name to build the
s's address. In an offline configuration, this is rarely a good solution:
rather, the email address of the Internet account should be used. The following lines
in .strnrc set up the following sender's address: hofer@provider.de (for the
sample user Hofer).

```
username "hofer"
hostname "provider.de"
realname "sample user Hofer"
```

The address of the sender will be entered correctly in all news articles, but it
is not valid for the REPLY command with which you send an email directly
to the author of a news article. In the current version of strn, it seems to be
impossible to influence the sender's address of. As is customary to
Unix, the email address is made out of login name, host name, and domain
name. Only the sendmail configuration may potentially be able to solve the
problem.

# Editor

strn has no editor of its own and starts vi as a default editor. You can prevent this by
setting the EDITOR or VISUAL environment variables appropriately.
