Now we will look at the conversion from Linux to DOS. In order to append a CR character to the end of each line, the stream editor is characterized by great flexibility in the processing of text files and, unfortunately, equally great non-transparency of its syntax.

```
#/bin/sh
# linux2dos: inserts a CR character at each end of line
if [ $# -eq 0 ]; then # use as filter
  sed -e s/$*/
elif [ $# -eq 1 ]; then # process one file
  mv $1 $1.\$
  sed -e s/$*/ < $1.\$ > $1
  rm $1.\$
elif [ $# -eq 2 ]; then # process two files
  sed -e s/$*/ < $1 > $2
else
  cat << EOF
linux2dos: inserts a CR character at each end of line
Usage: linux2dos
  linux2dos source_file target_file
  linux2dos < source_file > target_file
```

In the present example, a global replace command is executed in which each end-of-line is substituted by CR. Please note that ^M is not composed of the two characters ^ and M, but represents one character with the (decimal) code 13. How such characters are input varies editor to editor. In Emacs, you must enter Ctrl+V Ctrl+Q. The usage of linux2dos is the same as dos2linux.

Both programs can also be used for printing text files when the printer produces an endless string of characters of missing CR characters or lots of empty lines because of superfluous line feeds.
