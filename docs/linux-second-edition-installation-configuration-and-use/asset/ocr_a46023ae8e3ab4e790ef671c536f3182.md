# # 6.4 Registering users and passwords

After a new installation of Linux you can only log in as root. If root has not yet been provided with a password, this should be done immediately! This section shows how you can define your own passwords and register new users.

# ## Defining a password for root

After you have logged in as root, execute the passwd command. You will be asked to enter a new password twice. The input is not displayed on screen. The new password is only accepted if the two inputs match. From now on, you must use the specified password every time you log in as root.

In the same way as root, all users can change their own passwords. root, however, can change the password of any arbitrary user.

```
# passwd kof
Changing password for kof
Enter the new password (minimum of 5, maximum of 8 characters)
Please use a combination of upper and lower case letters and numbers.
New password: *****
Re-enter password: *****
Password changed.
```

In older Linux systems, all users' passwords are stored in the file /etc/passwd. You can edit this file with a normal editor (only if you are logged in as root), but you cannot modify the passwords in this file directly, because they are encrypted. However, a password can be completely deleted by deleting the characters between the first and the second column in the line that begins with the user name. This is a useful feature, afterwards you can log in without having to enter any password at all.

> Running Linux without a password for root constitutes a major security risk. You should only do this if you are absolutely sure that you alone work with your computer. Please note, however, that someone could also log via the Internet (even if you use a modern connection via SLIP or PPP).

Apart from root, there are quite a number of other users present in /etc/passwd (as bin, adm, and so on). These users too should be provided with passwords (or * characters instead of the password), if this is not the case by default. (The * prevents anyone from logging in practically an unbreakable password.)
