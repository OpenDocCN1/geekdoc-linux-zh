# CONFIGURATION AND ADMINISTRATION

root# setserial /dev/ttyS0
/dev/ttyS0, UART: unknown, Port: 0x03f8, IRQ: 4
The remedy is to use the following command:

```
root# setserial /dev/ttyS0 uart 16550A
```

In such a case it is sensible to execute setserial in the context of Init V process. RedHat, and SU already provide the appropriate scripts:

```
/etc/rc.boot/Oserial      Debian
/etc/rc.d/rc.serial       RedHat (executed by rc.sysinit)
/sbin/init.d/serial          SU
```

For an application of setserial you must obviously know the actual data of the serial interface. An attempt to set incorrect data in the worst case end with the computer grinding to a halt!

# Serial interface speed

If you access the serial interface with pppd (Internet access), you can set the speed beforehand by means the stty command. Although one might expect the contrary (>), the input redirection < is correct: stty changes the speed by reading data from the interface. Legal speeds are, for example, 38400, 57600, 115200, and 234000 (rare).

```
root# stty speed 115200 < /dev/ttyS1
```

Some programs can only be configured with speeds of up to 38400 bits per second (which in the old days was considered the absolute maximum). To obtain a higher interface speed with these programs as well, the additional program setserial must be used to set the option spd.h or spd.vh for the question in. This ensures that when the corresponding interface is accessed, the request for 38400 bps is automatically converted to 57600 bps or 115200 bps.

```
root# setserial /dev/ttyS1 spd_h # 57600 instead of 38400 bps
root# setserial /dev/ttyS1 spd_vh # 115200 instead of 38400 bps
```

With more recent models, it is even possible to reach a speed of 234000 bps by employing a little trick (according to the Modem-HOWTO):

```
root# setserial /dev/ttyS1 spd_cus baud_base 234000 divisor 1
```

Lots of additional information on handling the serial interface and various modems (including exotic models) can be found in the Modem-HOWTO and Serial-HOWTO texts.
