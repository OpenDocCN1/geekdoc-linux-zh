# Text mode

Elementary commands

| | |
|---||
| Ctrl+Enter | line break (\ in LaTeX |
| Alt+Enter | new paragraph with same layout |
| Ctrl+Alt | soft hyphen - in LaTeX |
| Ctrl+Shift | straight quotes |
| Ctrl+Spacebar | insert hard space |
| Ctrl+C | copy text |
| Shift+Ctrl+C | copy paragraph layout |
| Ctrl+D | DVI preview |
| Shift+Ctrl+D | update DVI preview |
| Ctrl+F | search and replace (find) |
| Ctrl+I | open context dialog (inset) |
| Ctrl+L | LaTeX mode |
| Ctrl+M | new document |
| Ctrl+O | open file |
| Ctrl+P | print file |
| Ctrl+Q | quit LyX |
| Ctrl+R | reload file (reload) |
| Ctrl+S | save file |
| Shift+Ctrl+S | save file as |
| Ctrl+T | PostScript preview |
| Shift+Ctrl+T | update PostScript preview |
| Ctrl+V | insert text |
| Shift+Ctrl+V | apply paragraph layout |
| Ctrl+W | close file |
| Ctrl+X | cut text |
| Ctrl+Z | Undo |
| Shift+Ctrl+Z | Redo |
| Alt+C | select font (see below) |
| Alt+M | math functions (see below) |
| Alt+P | select paragraph type (see below) |
| Alt+S | select font size (see below) |
| Alt+X | execute LyX command |
