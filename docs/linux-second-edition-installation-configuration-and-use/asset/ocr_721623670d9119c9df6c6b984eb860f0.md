# 428 BASH PROGRAMMING

dialog [--clear] [--title text] [dialog options]

dialog can be used for the display of dialogs. Properly speaking, the command has nothing to do with the bash, but is an autonomous program for text-oriented input and output of data. This brief description is based on version 0.6 which has for some time now been supplied with many Linux distributions.

The options --clear and --title can be combined with any of the other dialog options.--clear causes the dialog to be removed from the screen when it is terminated. (Afterwards, the whole screen will be blue! Execute setter --clear to get it back to normal.) --title allows you to set a dialog title. dialog offers the following types of dialog:

+   -msgbox text height width
displays a message text which must be confirmed with OK

+   -infobox text height width
as above, but without confirmation. The program is immediately continued. The dialog box stays on screen until the screen is cleared.

+   -yesno text height width
displays a dialog box for a yes/no decision.

+   -inputbox text height width
allows the user to enter a line of text.

+   -textbox file height width
displays the text file (cannot be edited, but can be scrolled).

+   -menu text h b men.height men.item1 men.text1 men.item2 men.text2 ...
allows selection of an option (a menu item).

+   -checklist text height width list.height
option1 text status1 option2 status2 ...
allows simultaneous selection of options.

dialog yields a return value of if the dialog was terminated with OK or YES, if it is terminated with CANCEL or NO, or 255 if it was terminated with Esc. In dialog types that supply a text, a menu title or a list of options, the results are written in the standard error file. Therefore, results normally need redirection into a temporary file by means of 2> tmp. Once the input is terminated, this file can be evaluated.

Dialog boxes can be controlled both with the keyboard and the mouse (since version 4.0). Unfortunately, display or input of foreign language special characters is not yet possible.

# Example

```
user$ dialog --clear --inputbox \
  'Enter a file name' 10 60 2> tmp
```
