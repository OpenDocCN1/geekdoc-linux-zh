# XFREE86

for security reasons, the local computer refuses to execute X programs of a foreign computer. You can deactivate this safety mechanism in an xterm window of the local computer for a specific user or computer name by means of xhost +name, xhost + switches the protection off completely. (This is a security risk!)

To illustrate the process with an example: you work on the local computerupiter, but would like to start an X program on the more powerful saturn computer (and control it at the local computer). You will need to execute the following commands:

```
user xhost +saturn
user login saturn
password: ******
user export DISPLAY=jupiter:0
user netscape # Netscape runs on saturn, but is locally
# displayed (on jupiter)
```

Although you execute all three commands in the xterm window, from the login onward, all commands are no longer executed locally but on the saturn computer. The local computer is exclusively responsible for input and output. (With X programs, all graphics are now transmitted over the network).

> In principle, X programs can be executed even if you only operate a PPP connection. In practice, however, the insufficient network connection spends reasonable work. In such cases, remedy is brought by the dxpc package that compresses the X data stream for transmission. However, this package needs to be installed (and started) on both computers involved.

```
http://ccwf.cc.utexas.edu/~zvonler/dxpc
```

xterm

Particularly in fwwm configuration files it is desirable to start xterm with a command and at the same time provide a login for root. The required command looks like:

```
xterm -title "root" -bg red -e su -l & &
The new xterm window is visually emphasized by the title 'root' and a red background color.
xterm can also be combined with telnet or login. The following lines present some examples:
xterm -e telnet localhost & # login for local computer
xterm -e telnet -l name jupiter & # login for 'name' on 'jupiter'
xterm -e login localhost & # login for local computer
xterm -e telnet -l name jupiter & # login for 'name' on 'jupiter'
```
