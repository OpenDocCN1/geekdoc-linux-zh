However, there is an entire collection of pretty savers for Linux, which in most distributions can be activated manually (xlock and xmore packages). The xlock program can also be used to lock keyboard and screen when you leave your computer for a short time - thus the name. It would obviously be a good idea if these savers could also be started automatically.

This task is carried out with the xautock program, however, is not supplied with all distributions. (You can find it on the Internet, for example in the Archive mirrors) xautock -time n is simply started as a background process in which specifies the number of minutes of inactivity after which the saver is to started. If you do not want to use xlock (default setting) as a screen saver, you can specify a different program by means of the option -lock.

An alternative to xautock is screensaver-timeout. This program is incompatible with xlock; thus a different program must be used for displaying the screen saver graphics. Suitable programs, such as qix, helix, and others, are usually supplied together with screensaver. Every program is for displaying a background pattern, as long as it can access the root window of X Selecting a specific program (and not some default program which is probably not even in-stalled), the following settings are needed in ~/.xdefaults there with xdalclock, a futuristic clock, as screen saver)

+   ! xcreensaver
screensaver.monoPrograms:
screensaver.colorPrograms:
screensaver.programs: xdalclock -bg black-darkblue-root

If you use KDE or GNOME, you can set the screen saver in a very user-friendly way. KDE and GNOME are described in the next chapter.

If you require a screen saver in text mode, you simply execute setterm-blank n, where n specifies the number of minutes after which the screen saver becomes active.
