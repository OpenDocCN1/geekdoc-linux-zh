In detail, the path from a text file test.tex to LaTeX format to a printout on an HP Desjet inkjet looks as follows:

```
user$ latex test.dvi
user$ dvips -o test.ps test.ps  #yields test.ps
user$ ghostview test.ps  #check the result
user$ gs -sDEVICE=deskjet -soutputFile=test.hp
    -dPSERVISE4 -dNOPAUSE test.ps #yields test.hp
user$ cp test.hp /dev/lp0 #printout on LPT1:
```

During execution of dvips orxdvi, new character sets may be generated. In such a case, both commands start the mf program (metafont) automatically. Background information on Metafont and PostScript character sets can be found from page 262 onwards.

If you own an HP LaserJet compatible printer, you can use the program dvilj to generate files directly in LaserJet, saving you the detour via a PostScript file.

# LaTeX online documentation

The available online documentation about LaTeX is rather systematic, strongly dependent on the selection (see below) and mostly addressed to expert LaTeX users. The man pages very briefly describe the program calls of TeX, LaTeX, and so on, but give no information on the syntax of LaTeX documents. A good introduction is provided in ltex2.dvi. Another useful text is essential.dvi. The files usguide.tex, fntguide.tex and clisguide summarize the changes in LaTeX 2 compared with LaTeX 2.09, in about 80 pages. However, these guides assume that you have a good knowledge of LaTeX 2.09.

# LaTeX on the Internet

Even though the distributions supplied with Linux are already huge, there are countless additional LaTeX utilities, extensions and special layouts (for example, for documenting chess game positions, setting sheet music, and so on). Internet servers have been teamed up under CTAN (Comprehensive TeX Network) to collect these LaTeX extensions. Beside these three, there are a large number of additional Internet servers that mirror the entire archive or least parts of it.
