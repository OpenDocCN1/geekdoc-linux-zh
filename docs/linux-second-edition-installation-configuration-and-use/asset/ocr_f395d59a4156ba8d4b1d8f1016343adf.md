# KDE internals

rc files

Most KDE programs store status settings (font size, options, and so on) in the file /.kde/share/config/namerc. This is a text file which is structured similarly to the *.ini files known from Windows 3.1. The program icons displayed on the KPanel, for example, are stored in ~/.kde/share/config/kpanelrc. By the way, the name of the files containing the screen saver settings are not namerc, kssrc.

Application-specific directories

Some KDE programs have so much configuration data that a single file would be too unwieldy. Programs usually create a separate configuration directory in ~/.kde/apps, for example ~/.kde/apps/klynx.

kdelink files
