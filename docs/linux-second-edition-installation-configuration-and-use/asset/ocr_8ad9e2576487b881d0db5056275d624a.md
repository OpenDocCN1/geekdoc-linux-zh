read and write bitmap files in the most disparate formats; supported formats include, amongst others, GIF, JPEG, PNG, and TIFF

import PostScript files (EPS/PS) and Photoshop files (PSD)

play the artist and paint pictures completely from scratch

change the color and brightness distribution of images (for example, lighten the image, increase the contrast, and so on; such operations are mainly used to improve the quality of scanned images)

apply Gimp in batch operation to a collection of files

> Gimp does not include any scanning functions. A rich function for controlling your scanner under Linux is provided by the SANE (Scanner Access Next) package which is part of many distributions. When installed correctly, SANE can be used directly from Gimp via a plugin – see the text for xscanimage. Up-to-date information on SANE can be found under www.mastang.com/sane.

> Gimp does not include an import filter for photo CD files (extension PCD). If you wish to read images from photo CDs, you can resort to the very user-friendly xpcd program – see page 517.
