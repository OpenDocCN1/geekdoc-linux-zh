# CONFIGURATION AND ADMINISTRATION

Texts with foreign language special characters often cause problems, which
be remedied by assigning the text 'latin1' to the LESSCHARSET environment variable.
 assignment should be carried out in /etc/profile.

```
# Addition to /etc/latin1
export LESSCHARSET=latin1
```

But there are additional ways of making less much easier to handle. The en-
vironment LESS allows you to set the default options for Less. A useful one
is -mm: this displays the current line number in each file. (For very long text files, this
takes some time; therefore the option is not active by default.)

The environment variable LESSOPEN allows you to write a script (that is,
a small program) which is automatically started at each less call. This program can,
for example, be used to decompress compressed files automatically; that is, Less
be used to view the contents of tar archives and so on. In Slackware and
SE distributions, a script file is installed as a standard; in all others
y should make the effort and install the files yourself - it will be worth it.

```
# Addition to /etc/profile
export LESSCHARSET=latin1
export LESS=-MM
export LESSOPEN="lessipe.sh"
```

lessipe.sh must be located in a PATH directory, normally in /usr/bin. Depending on the file name extension, this program first calls tar (archives), rpm
(package files), gunzip (compressed files) or groff (man texts). The results of
these are then passed to less. In practice, lessipe.sh works as a filter.
The file that is being viewed obviously left unaltered.

```
#!/bin/sh
# file /usr/bin/lessipe.sh
lessipe() {
  case "$1" in
    *.tar) tar tvf $1 2>/dev/null ;; # contents of .tar and .tgz
    *.tgz) tar tvf $1 2>/dev/null ;;
    *.tar.gz) tar tvf $1 2>/dev/null ;;
    *.tar.2) tar tvf $1 2>/dev/null ;;
    *.tar.z) tar tvf $1 2>/dev/null ;;
    *.rpm) rpm -qpli $1 2>/dev/null ;; # contents of .rpm
    *.z2) gzip -dc $1 2>/dev/null ;; # contents of compressed files
    *.z) gzip -dc $1 2>/dev/null ;;
    *.gz) gzip -dc\    *.zip) unzip -l $1 2>/dev/null ;;n      # groff
    *.1|*.2|*.3|*.4|*.5|*.6|*.7|*.8|*.9|*.man) FILE='file -L $1'
      src FILE=$FILE | cut -d' ' -f2
      if [ "$FILE" = "troff" ]; then
        groff -s -p -t -Tascii -mandoc $1
      fi
  esac
}
lessipe $1
```
