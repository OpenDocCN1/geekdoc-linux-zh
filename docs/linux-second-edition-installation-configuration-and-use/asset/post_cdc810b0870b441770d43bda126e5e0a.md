## The help system

One of the most attractive features of the SuSE distribution is certainly the help system. It consists of the following packages, all of which, for reasons of space, need not be installed. If not specified otherwise, all packages are located in the doc series.

- susehelp: English and German starting page, script files hilfe and susehelp
- rman (ap series): man -> HTML converter
- inf2htm: info -> HTML converter
- apache (n): http server (dynamic info texts, search function)
- gnuhtml: HTML files for GNU programs
- howtoenh: HTML version of the HOWTO documents
- ldp: Linux Documentation Project (FAQs and several complete books)
- sdb.en: texts of the support database
- sdb.cgi: CGI scripts for searching the support database (short descriptions of all SuSE packages)
- usepake: xf86html-XFree8 documentation in HTML format

All of the documents mentioned above can be accessed via Netscape from a starting page. The help system can alternatively be started with help (English version) or help (German version). If Netscape is already running, the starting page is immediately displayed; otherwise Netscape is automatically started.

The support database contains an almost endless list of texts that have emerged from years of experience of the SuSE support department. (The version supplied is obviously not entirely up-to-date. The current version can be found at SuSE's Web site.

Depending on whether you have installed the CGI scripts and the Apache HTTP server, you can use either the comfortable keyword search or you need to pick the help texts from an alphabetical keyword list. The search for 'ppp' in SuSE 6.1 yielded 52 entries in all!

If several SuSE computers are linked together in a network, you have the possibility of storing the fairly massive documentation files on only one computer, which thus becomes the documentation server for all other computers. For this purpose, you need to install both the httpd and dochst packages of the n series on the server, whereas the clients only need dochst. Further information on this configuration is provided in /usr/doc/packages/dochst/README.SUSE. This method not only saves disk space, but also allows full text search across all HTML documents.

As well as the main documentation described above there is quite a lot of package-specific documentation. The README files and other texts are usually installed in the /usr/doc/packages/name directories.

# SuSE internals

### GNOME

Although the SuSE 6.1 distribution includes GNOME 1.0, its use is rather difficult. In this respect, SuSE cannot keep up with RedHat 6.0.

The problems begin with the fact that after installation of all GNOME packages GNOME only comes up with error messages. For proper execution, you still need the imbib package of the gra series, which needs to be manually installed with yast. (Here the vast information on package dependencies is obviously not quite complete.)

### Shadow system

SuSE uses shadow. In this system, passwords are not stored in /etc/passwd, but in a separate file /etc/shadow. To register new users, use yast. If you manually enter a password into /etc/passwd, check /etc/shadow.

### Init-V process

The numbering of runlevels as follows:

- 0: Halt
- 1: Single user
- 2: Multiuser
- 3: Multiuser with network
- 4: Unuser mode
- 5: Multiuser
- 6: Reboot
- 7: Multiuser

### lib compatibility

With version 6, SUSE changed the libc. If you still want to execute lib, you need the optional package found in /usr/i86-linux5/etc/ld.so.
