

# 编程

在 Linux 下，你将找到许多编程语言：首先是 GNU 和 C++ 编译器，这些编译器配备了一整套实用程序（从 `make` 到版本控制系统 `r` 以及调试器 `gdb`）。大量的库和工具包允许你编写带有图形用户界面（如 XWindows）的 C 程序，或者使用 OpenGL（mesa）编写带有 3-D 图形的程序。Linux 下还提供了许多其他编程语言，如 Java、L、Oberon、Perl、Python、Scheme、SmartTalk 和 Tcl/Tk。此外，可用的 shell（bash, shell）也是完全可编程的。

# 模拟器

Linux 还提供了一个 DOS 模拟器，允许运行许多程序（但不能 运行 Windows 3.1）。Wine 项目正尝试实现 Windows 程序的运行，但该项目仍处于开发阶段。在介绍内核特性时，已经提到可以执行符合 iS2 标准的 Unix 程序。针对 Atari ST、Commodore 64、Commodore Amiga、Sinclair ZX Spectrum 等的模拟器主要面向游戏类字符。

# 其他

- 数据库：Ingres（关系型）、Mini SQL（关系型，很大程度上兼容 SQL）、obst（面向对象）。Postgres（对象关系型）
- 数学：MuPaD（计算机代数系统）、scilab（大部分 MathLab）
- 图形：xv（图像处理与转换）、gimp（图像处理，类似于 Photoshop）、POV-Ray（光线追踪）

> 注意：上述某些程序属于股东或受不同于 GPL 的版权条件限制。任何情况下都允许发布，但在许多情况下，普通或商业使用或商业分发受到限制或需要注册。

# 商业程序
