# Keyboard shortcut reference

The Tex file ref.tex contains a table with the keyboard shortcuts of the important Emacs commands, it is located in the Emacs etc directory (/usr/share/emacs/20.2/etc/). If you have an installation of TeX and a PostScript printer, you should carry out the following instructions:

+   - Load the file ref.tex into Emacs and change the line \columnspage=1..=3. Save the file.
- Use the file to generate a DVI file: tex refcard
- Convert the DVI file into a PostScript file: dvips refcard -o test.ps -t landscape
- Print the file with lpr test.ps. (Information on correct printer configuration can be found on page 163.)

The result is a two-page printout pages contain three columns nearly all relevant Emacs commands (in landscape format). The commands are ordered by subject (for example, Files, Getting Help, Error Recovery, and so on). Those two pages are constantly somewhere on my desk and are my most important reference source for Emacs!

A further source of information is the Emacs man page. However, it only details of command options and the setting of X default values for colors, character actor sets, and so on.

# The Info mode

The built-in Emacs online help is stored in the GNU Info format (see page 74). For reading Info texts, Emacs activates a special Info mode. In this mode, some special shortcuts apply which are described on page 75. You can follow cross-references and menu entries by simply clicking the middle mouse button. L takes you back to the last page viewed.

# 16.4 Cursor movement

The most important combinations for cursor movement have already been introduced in the previous section: the four cursor keys PgUp and PgDn. Apart from these, there is a choice of other commands:

| Cursor movement | |
|---|---|
| Alt+F / Alt+B | cursor one word forward / backward |
| Ctrl+A / Ctrl+E | cursor to beginning / end of line
| Alt+A / Alt+E | cursor to beginning / end of paragraph
| Alt+V / Ctrl+V | text one page up / down |
