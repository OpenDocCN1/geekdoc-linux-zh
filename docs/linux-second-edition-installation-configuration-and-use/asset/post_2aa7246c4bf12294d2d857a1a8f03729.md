
# Installation classes

From version 6, RedHat Linux supports three so-called installation classes: Workstation, Server, and Custom. If you are in doubt, you should choose Custom!

With the Workstation installation, all existing Linux partitions are deleted; with a Server installation, you also lose all other partitions (including Windows partitions). In both cases you have no influence on the size of the new Linux partitions. These two installation classes are mainly suited to a quick installation of Linux on your own.

Let repeat this: if you choose a Workstation or Server installation, all existing (Linux) partitions on all accessible hard disks are deleted! The installation program repartitions the hard disk(s) completely by itself. This avoids the burden of having to make some decisions, but you also lose a lot of control.

# Hard disk partitioning (Disk Druid)

In the Custom installation, the next task is to create new Linux partitions in the free space of the hard disk. You have the choice between two programs: fdisk (see page 33) or the more user-friendly Disk Druid (a proprietary Red Druid development). At this point, only the Disk Druid is described.

The program is controlled by means of Tab and function keys. The dialog for creation of a new partition is opened with F. Here you must specify details: the mount point (that is, the point at which the partition is integrated into the Linux file system), the required size of partition, and the partition type (LINUX NATIVE or LINUX SWAP).

As options you can specify whether the partition should be GROWABLE, and on which hard disks the partition may be created (if you have several disks). GROWABLE means that the Disk Druid automatically creates a larger partition if more space is available. If you select this option even with one partition, the entire hard disk is filled. It is usually better to deactivate this option; when you need more space, you can create additional Linux or Windows partitions at a later stage.

If there are partitions left over from a previous installation which you would like to use, you can specify their mount points with F. (Specifications of partitions to be formatted later.)

The Disk Druid is terminated with OK. Now you are asked to confirm that you really want to carry out the changes. (Never modify any DOS or Windows partitions!)

In the following installation steps you are asked which partition marked as LINUX SWAP should effectively be used as the swap partition (just press-) and which partitions need to be formatted. In a first installation, all partitions need to be indicated (selection by means of the Spacebar).

During installation, four screens (so-called text consoles) are shown between which you can switch: Alt+F2 allows direct input of Linux commands (for experts only), Alt+F3 displays various status messages, Alt+F4 shows error messages, and Alt+F1 takes you back to the installation program.

# Package selection

Next, the components to be installed are selected. The following components are available:

- Printer Support IPX/Network(tm) Connectivity
- Window System Anonymous FTP Server
- GNOME Web Server
- KDE DNS Name Server
- Mail/Web/News Tools Postgres (SQL) Server
- DOS/Windows Network Management Workstation
- File Managers Tex Document Formatting
- Graphics Manipulation Emacs
- Console Games Emacs with X windows
- X Games C Development
- Console Multimedia Development Libraries
- X multimedia support C++ Development
- Networked Workstation X Development
- Dialup Workstation GNOME Development
- News Server Kernel Development
- NFS Server Extra Documentation
- SMB (Samba) Connectivity

If you select the components marked with * you will obtain a fairly solid base configuration (space requirement about 450 Mbytes). Unfortunately, it is not # REDHAT 6.0

to specify the sizes of the individual components because they overlap considerably.

If during component selection you activate the option SETUP INDIVIDUAL PACKAGES, you can subsequently activate or deactivate single packages of the various components. Generally, however, it makes sense to invest a lot of time in package selection during installation – once your installation has succeeded, you can always use the rpm or gnome tools for this purpose.

> Composition of the components is controlled by the file RedHat/base/comps on the installation CD-ROM. This text file contains a list of all packages that are installed per component. This file can be of valuable help if at a stage you want to install additional packages: gnome does not recognize components but displays all packages in a different hierarchy.

After selection of the required components and packages, these are installed into the previously created partitions. This process takes several minutes; progress is indicated with a bar diagram. (A log of all installed packages can be found after installation in /tmp/Install.log)

# Basic configuration

In many cases, the mouse is recognized automatically – you only need to confirm the selection. If your computer is connected to a local network, you can then proceed with the configuration of network card and network parameters. Even if you do not without, this basic TCP/IP functions are initialized to enable Linux programs to use this protocol for local communication. Then, your computer simply receives the name localhost.domain.

When configuring the time, you need to specify whether the CMOS clock of your computer is GMT (Greenwich Mean Time) or local time. Local time will probably be the. Furthermore, you need to specify the required time zone (for example Europe / Berlin). In the system configuration, you can simply confirm the default setting with [Enter].

Printer-set is of particular interest if you do not possess a printer. In this case, a file is created, which allows to de-select the printer. The monitor specifications that follow decide resolution and frequency might function. If you do not find your monitor in the list of predefined monitors, you need to select CUSTOM. Now you can select a menu item according to the technical specifications of your monitor (for example 1024-768 pixels at 70 Hz). Do not select too high a resolution or frequency, or you will risk the premature demise of your monitor. The allowed frequency range of your monitor is asked again in an additional dialog (for example 50-100 Hz).

Recognition of the card and its ratings (for example, the available video memory) is again carried out automatically. On the basis of this information and the monitor data, the configuration program automatically selects a suitable graphics mode. Alternatively, you can specify one or more modes manually. (You can toggle between these modes with Ctrl+- the numeric keypad).

This concludes the installation. After restarting your computer, Linux should come up with the login prompt - enter root and your password.
