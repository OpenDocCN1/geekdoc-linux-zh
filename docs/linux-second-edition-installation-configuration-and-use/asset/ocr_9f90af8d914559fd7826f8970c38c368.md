# Configuration

tin can be extensively configured. You can either modify the file /.tin/tin-irectly or call the configuration dialog from inside the program with Shift+M. Be-sides other things, this allows you to activate colors and mouse support.

Editor

tin has no editor of its own and starts vi as its default editor. You can prevent this by setting the EDITOR or VISUAL environment variables appropriately.

Sender's address

tin normally employs the user, host name, and domain name to build the sender's address. In an offline configuration, this is only rarely a good solution; the email address of the Internet account should be used. For this purpose, a modified sender's address can be set with Shift+M (option mail_address in tinrc).

> CAUTION As strn, in too the modified sender's address is only valid for news articles, not for email sent with via REPLY. You should use your email program to reply directly to news articles.

# 11.3 Offline news configuration (leafnode)

leafnode is a news server specially optimized for small news archives (a few dozen groups maximum). Thus, leafnode is particularly suitable for managing a news archive on private computers without permanent Internet access.

> TIP You can find the most-to-date version of leafnode together with further information on the Internet: http://pxx02.tuni-wuerzburg.de/~krasel/leafnode.html

> REFERENCE The most popular alternative to leafnode is inn. This program is generally used for very large news archives, but can also be employed for private use. The only basic disadvantage is the rather difficult configuration. In the first edition of this book, this chapter included instructions for installing an offline news server with inn.
