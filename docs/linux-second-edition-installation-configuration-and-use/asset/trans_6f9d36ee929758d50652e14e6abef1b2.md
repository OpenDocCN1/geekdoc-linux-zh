# 15.3 文档和图形转换

Linux 文档和图形以多种格式存在。以下列表提供了概述：

- ASCII：Linux 使用 8 位字符集，这在很大程度上对应于 Microsoft Windows 使用的 ANSI 集。
- DVI（设备无关格式）：DVI 文件是 LaTeX 排版程序的结果。DVI 文件处于从 LaTeX 源文本（TeX 文件）到打印机文件（主要是 PS）的路径中间地。
- 图形格式：由于历史原因，有无数种格式（GIF、TIF、JPEG 等）。此类文件的转换和处理可以通过一系列程序完成。
- HTML（超文本标记语言）：虽然 HTML 格式最初是为互联网开发的，但它现在已成为在线文档的重要格式。
- man 文件：man 文本的源文本存在 gro 格式系统中。
- PCD（Photo CD）：如果你想在 Linux 下处理 Photo CD 的图片，你就会遇到 PCD 文件。
- PS, ES（PostScript）：PostScript 是一种针对特定打印机的页面描述语言。在 Linux 下，这种格式的作用比在 Windows 大得多。所有的 Linux 程序仅生成这种格式的打印文件。因此，PostScript 代表了 Linux 世界的打印机标准（更广义地说，代表 Unix 世界）。但即使你没有 PostScript 激光打印机，你也不需要显示。通过 gs (Ghostscript)，你可以将 PostScript 文件转换为许多其他打印机的格式。
- SGML（标准标记语言）：这是 HTML 的变体。大多数 Linux HOWTO 的源文本以 SGML 格式存在。
- TEX（LaTeX）：TEX 文件包含 LaTeX 或 TeX 翻译的源代码。（出于空间考虑，仅提供 TEX 文件作为某些程序的文档；转换为其他格式则留给用户处理。）
- TEXI（TeXInfo）：这是 TeX 文件的变体，用于专门创建 info 格式的在线文档。

本节介绍了许多允许你将文档从一种格式转换为另一种格式的工具。例如，如果你首先想在屏幕上阅读包含程序文档的 *.tex 文件，并在 Epson 喷墨打印机上打印它，则需要以下转换步骤：

TEX -> 使用 latex 生成 DVI；例如使用 xxd 显示
DVI -> 使用 dvips 生成 PS；例如使用 ghostview 显示
PS -> 使用 gs 生成打印机文件

在适当配置下，这种转换可以自动完成——另见第 162 页和 Printing-HOWTO。

不同文档的显示程序将在下一节从第 518 页开始开始讨论。

根据打印机的不同，可能有几种方法获取打印输出。例如，你可以先用 a2ps 将 ASCII 文件转换为 PostScript 文件，然后通过 gs 在 HP Laserjet 上打印该文件。通过 PostScript 格式的迂路通常看起来很冗长，但可能会获得更高的结果。

# 文本转换 DOS ↔ Linux (fromdos, todos)

当你尝试在 DOS/Windows 和 Linux 之间交换文本时，你会遇到问题：行尾标记方式不同（这适用于 DOS 和 Windows），并且使用了不同的字符集，这会影响外语言字符（仅适用于 DOS）。

简要细节：在 DOS 和 Windows 中，行尾都通过回车符（carriage return）和换行符（line feed）的组合标记。Unix 和 Linux 不需要回车符，仅换行符就足够了。这意味着当用 Linux 编辑器查看 DOS 文件时，每行末尾都会显示一个 `^M` 字符。相反，在 DOS 编辑器中查看 Linux 文件，它会变成一条无穷无尽的字符蛇，因为 DOS 和某些 Windows 程序（如 NOTEPAD 编辑器）不识别行尾。

现在说几句外语特殊字符：DOS、Windows 和 Linux 使用三种字符集。DOS 通常使用 ASCII 集的变体，Windows 使用 ANSI 字符集，Linux 使用 ISO 8859/1 字符集。在所有三个字符集中，0 到 127 的字符是相同的。差异出现在剩下的 128 个字符中，这些字符包含外语言特殊字符（重音、变音）。Windows 和 Linux 字符集之间更为相似——例如，变音的编码方式是相同的。
