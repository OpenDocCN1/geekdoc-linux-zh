# Disk Navigator

Besides numerous bug fixes and improvements of details, the Disk Navigator is the only true novelty of KDE 1.1 against KDE 1.0. It is a motscript extension to the KDE start menu, which helps you to quickly open a window for a specific directory with the file manager or a shell terminal. At the same time, you can easily access the most recently used directories and files without working through the meanders of embedded menus or directory hierarchies. Once you have tried the KDE Navigator for only a couple of minutes, you will never want to do without its advantages again.

To start the file manager in a specific directory, simply use the menu entries of the Disk Navigator. For each subdirectory, a separate submenu is provided. When you select the OPEN FOLDER entry together with Shift a terminal window is opened in which the selected directory is set as the current directory.
