The search text differentiates between upper and lower case sensitivity. Some examples follow which explain the syntax of the search pattern: \<the> for the article 'the', no matter whether it is spelt with an or lower case initial. ## Searching and replacing

In searching and replacing, Emacs differentiates between the normal command and the extended version with pattern matching. In the normal variation, upper and lower case spelling is ignored in the search. During replacing, the initial letters of words are maintained in the original upper or lower case when the replacement text is completely spelt in lower case. The search and replace command will not be able to find any search text separated by a line feed, because the wildcards * and + have no effect across lines.

## 16.9 Buffers and windows

You can use Emacs to edit several texts at a time. Each text is managed in a so-called buffer. Even when you work on a single text, several buffers exist: one for the text (the buffer name corresponds to the file name (without path)), one for Info or help window opened at some time during work (buffer names *info* or *help*), one for the most recently displayed list of commands expanded with Tab (*completions*), for the abbreviations (*abbrevs*, if some time Alt+X edit-buffers has been executed; see below), and so on.

Besides the concept of buffers, Emacs also has windows: a window is an area on screen in which a buffer is displayed.

Normally, a single window is used which takes all available space. For the execution of some commands (for example, the display of help or other Emacs-internal information) the screen is horizontally split into two windows. The screen can also be divided into several horizontal or vertical strips. In each of these areas (windows) a different buffer can be displayed. You can also display the same buffer in two different windows. (This is mainly useful for very long texts: you can work on two different parts of the text without continually having to jump back and forth with long-lived cursor movements.)

The window concept of Emacs has nothing to do with a window under X, but only means a partial area within a window. If you really need an additional window of Emacs (for example, to work on two program listings in parallel), you can easily achieve this with FILE.

The following commands refer to the currently active window (that is, the window in which the cursor is shown). The changes change the buffer displayed in this window.

## Buffer commands

- `Ctrl+X`, `B`, `⇅` activates the previously used buffer
- `Ctrl+X`, `B`, `name` activates the specified buffer
- `Ctrl+X`, `Ctrl+B` deletes the specified buffer;
- `Ctrl+X`, `K`, `name` displays the list of all available buffers in a window; the window can be deleted with `Ctrl-H`, `X`, `I`
- `Ctrl+X`, `K` deletes the specified buffer; if the buffer contains a not yet saved file, a request

The following commands only affect the display of buffers in various areas (windows). The separation bar between the windows can be moved with the mouse.

## Window commands

- `Ctrl+X`, `O` switches to the next window ('oh')
- `Ctrl+X`, `0` deletes the current window ('zero')
- `Ctrl+X`, `I` deletes all windows except the one the cursor is in
- `Ctrl+X`, `2` splits the current window into two horizontal areas
- `Ctrl+X`, `3` splits the current window into two vertical areas
- `Ctrl+X`, `<` moves the window contents to the left
- `Ctrl+X`, `>` moves the window contents to the right

The buffers themselves are not affected by the deletion of a window (they become invisible, but remain in memory and can be displayed again at any time).

## 16.10 LaTeX and C modes

A particular feature of Emacs is the existence of various modes which modify the functionality of the editor and in addition provide commands. This optimizes Emacs for the editing of different text types. highlighting of keywords and comments.

Emacs differentiates between major and minor modes. Only one major mode can be active at any one time. This mode is automatically selected according to the file extension. Each file processed in Emacs (that is, each buffer) has its own mode setting. Thus, a manual mode change only affects the currently buffer. A switch to a different major modeactivates the previous mode. Activating and deactivating minor modes does not affect the major mode.

## Important Emacs modes

| Command | Description |

| Alt+X text-mode | mode for easy indenting (see page 554) |
| Alt+X text-mode | TeX mode (page 559) |
| Alt+X latex-mode | \TeX mode (page 559) |
| Alt+X c-mode | C mode (page 561) |

## Important Emacs minor modes

- Alt+X auto-fill-mode: flow text mode (automatic breaking: page 552)
- Alt+X font-lock-mode: colored syntax marking (page 562)
- Alt+X abbrevi-mode: abbreviation mode (automatic expansion of abbreviations: page 564)
- Alt+X iso-cents-mode: input of foreign language characters (page 566)

Besides the modes listed above, there are countless additional major and minor modes for most programming languages available under Linux. An overview can be obtained with FL-x. Information about the currently active mode can be displayed with FL-M.

> When loading a file, Emacs tries to recognize the type of file from the file name extension and the first few lines and automatically activates the corresponding mode. If this does not work for a particular file, you can insert a comment in the line of that file which contains the characters `*- name`. Instead of `name` you must specify the required mode name (for example, tex).

These modes are practically identical, which is why they are described together. They are activated automatically when loading a file or manually with the commands Alt+X text-mode or Alt+X latex-mode, respectively.
