# 662 GIMP – THE PHOTOSHOTOP ALTERNATIVE

+   - as a *.ps.gz file (PostScript, HTML files, compressed, 43 Mbytes)
- as a *.html.tar.bz2 file (HTML files, compressed, 16 Mbytes)
- as a *.fm.tar.bz2 file (FrameMaker source files, compressed, 54 Mbytes).

The HTML version is also available online: http://manual.gimp.org/
With most distributions, only the *.pdf version is supplied for reasons of space.
The file can easily be read with the aid of acroed. (In principle, it could also be read with pdf, ghostview, and kghostview; in practice, these programs have proven not to be very suitable: cut-off pages, no contents list, lower font quality, and so on.)

The numbers of the GUM contents list and index do not correspond to acroed's internal page counter. The reason: acroed begins page numbering with page 1, whereas the GUM starts with 4 uncovered pages, followed by 48 Roman numbered pages – only then does the first part start with (Arabic) 1.
With acroad, the manual can also be printed or exported into PostScript format – but note: a printout not costs a lot of paper, but it also takes endless time, because huge amounts of data (images!) must be transferred and processed in the printer.

Occasionally, the GUM describes features of plugins which do not belong to the standard installation. Information on available Gimp plugins and their installation can be found on the Internet under the following addresses:
http://www.gimp.org/links.html
http://registry.gimp.org

If you are overwhelmed by the extent of the Gimp manual, you might prefer the PostScript file gimp.quick.reference.ps. One single page provides a clear overview of all relevant Gimp keyboard shortcuts. If you have a PostScript printer, you can print the page straight away – otherwise you will need gs for printing (page 509).
Equally useful, but visually not as appealing, cheat.sheet.txt, which summarizes the keyboard shortcuts corresponding to all toolbar buttons.

Finally, the mandatory reference to the Internet: http://www.gimp.org is the place where you can find the latest information on Gimp, lots of tips and tricks, a number of useful, practice-oriented tutorials, and so on.

Learning the functions of Gimp is only the first step towards great results. At least equal importance is the understanding of how these functions can be sensibly employed in practice. Before you go and have your results in poster size in a print shop, which would furthermore acquaint you with the numerous problems of color representation on screen and in print (calibration). A Photoshop book that primarily discusses issues of image processing (and not so much the software handling details) can also be a reasonable investment for Gimp users. The titles quoted in the Reference part of this book have been of great help to the author.
