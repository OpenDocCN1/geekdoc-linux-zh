Some variable files are located in /var/lib/texmf. Depending on the distribution, your configuration files are located in /etc/texmf. The /usr/share/texmf/
tree contains links to these configuration files.

During the conversion of *.d files into PostScript format (dvips) or when
are displayed on screen (xvdi), bitmap files of the required files are generated.
These files have the extension *.pk and are stored in the following directory:

/var/cache/fonts/pk/ bitmaps (*.pk)

If you suffer from space problems, you can delete the *.plt files without hesitation. However, at the next call of dvips or xvdi, these files have to be generated
again, which takes some time.

In view of the immense number of files, the search for a given font or style file
can take relatively long. The TeX distribution therefore manages an additional database that contains a list of all ls files. Essentially, this database
consists of the result of ts -R and is therefore called ts-R. When you
TeX with additional files, you must always execute the command texhash
in order to extend the database as well. Also, you should always try this com-
mand first whenever you encounter problems in finding TeX files.
