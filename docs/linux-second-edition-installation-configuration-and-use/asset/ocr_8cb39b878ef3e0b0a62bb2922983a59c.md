-ls when the shell is started in xterm. .profile is evaluated. This is important to ensure that various alias abbreviations, environment variable definitions, and so on are read in.

-n specifies the number of lines to be stored (same as saveLines).

-title name specifies the window title.

If you would like to use all the features of xterm, you should read through the man pages: the extent of more than 30 pages gives an idea of how far xterm is configurable!
