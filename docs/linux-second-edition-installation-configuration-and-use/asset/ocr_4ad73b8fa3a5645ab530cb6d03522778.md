# xgrab

The handling of xgrab is completely different from xv — you must set all options in advance: the required screen area (a window, the whole screen or a rectangle previously marked with the mouse), the graphics format (PostScript or various bitmap formats), possibly some PostScript options (for illustrations, PS-FIGURE must usually be selected), and the file name.

When you click on Ok, the control window disappears from the screen. After a preset time, during which you can, for example, select a menu, the current screen contents at that particular instant are stored in the file. A few moments later, the control window appears again. xgrab does not provide for viewing the generated images — either xv or ghostview will have to be used.
