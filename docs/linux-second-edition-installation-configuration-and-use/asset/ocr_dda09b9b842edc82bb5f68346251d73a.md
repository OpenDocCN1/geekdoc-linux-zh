# BOOT DISKETTES/LILO 193

If you have made your backup copy of the boot sector, you can reinstall it
with dd. The first command applies to the first IDE disk, the second command to the
first SCSI disk:

```
# root dd if=/boot/bootsector.ide of=/dev/hda bs=512 count=1
# root dd if=/boot/bootsector.scsi of=/dev/sda bs=512 count=1
```

If problems occur during the uninstallation of LILO, you can use a boot disk
to start DOS and execute FDISK /MBR. This creates a boot sector for the auto-
matic start of DOS/Windows (and overwrites the LILO boot sector). However, this
method does not work for some versions of Windows 9x and not all for Windows
NT.

# Installing LILO in a DOS partition (1024-cylinder limit)

If the root partition is situated outside the magic 1024-cylinder limit or on a
on-accessible hard disk, the kernel file and other boot information can be copied
to a DOS or Windows partition that lies below this limit. (For startup, LILO needs
t kernel file, the files boot.b and map and possible message files if the message\option is used).

```
# mkdir /dosc # if the directory does not exist
# mount -t vfat /dev/hda1 /dos # device name of Windows partition
# mkdir /dosc/lilo
# cp /boot/vmlinuz /dosc/lilo # kerne' file
# cp /boot/* /dosc/lilo
```

In /etc/lilo.conf you must change the path settings for the kernel file and
possibly other location and map, which no longer (as in the default setting) point to
the LILO directory /boot, but to the DOS directory C:\LILO.

However, make sure that the root directory remains unchanged. (The root
option specifies where the Linux root partition is located. This location has not\changed.)

```
# /etc/lilo.conf
boot=/dev/hda
prom
timeout=100
install=/dosc/lilo/boot.b
map=/dosc/lilo/map
image=/dosc/lilo/vmlinuz
# use 'root=' to specify your root partition!
root = /dev/sda8
label = linux
read-only
other=/dev/hda1
label=dos
table=/dev/hda
```
