At regular intervals (by default, every 5 minutes), LyX carries out a backup copy. In LyX you may change this interval to your liking.

```
# Backup copy every 2 minutes
# autosave 120
```

# 19.7 Keyboard shortcuts

The following information applies to LyX 1.0 and (with a few exceptions) to KLX 0.9n in the default setting. For reasons of space, not all shortcuts can be shown — see the files cu.bind, math.bind, and menus.bind in /usr/share/lyx/bind/ or /opt/kde/apps/lyx/bind directory.

The cursor keys Home and End work in Microsoft Windows programs. When, in addition, Ctrl is pressed, while words or paragraphs are deleted. If, in addition, Shift is pressed, the cursor moves to select an area of text.

Selected text can be copied with Ctrl+C, deleted with and pasted with Ctrl+V or Shift+Ins. In contrast to other programs, there is no possibility of toggling between an insert mode and an overtype mode. The Ins key has no effect: LyX does not have an overtype mode.

Menu commands can be entered with Alt, followed by the appropriate letter. While in KLX the corresponding menu appears immediately, in LyX this needs to be forced by entering an additional space. (If you know the shortcuts by heart, you can obviously do without this.) Menu commands can also be initiated with FI — this saves you the Alt key.

If LyX is not used with the original English language menus (but, for example, with German language menus), problems arise with the keyboard entry of menu commands both with Alt and F10. Furthermore, some keyboard shortcuts cause problems, in particular most of the Alt+S for changing the font size.

In this regard, KLX is more robust. Independently of the chosen language, the menu can be controlled via the keyboard without great difficulty (although here too, the F10 key fails). Problems are instead caused by keyboard shortcuts that do not work in the same way as in LyX (such as Alt+P for selection of a paragraph type).
