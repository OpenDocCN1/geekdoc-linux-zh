# LATEX AND C MODES 563

Emacs can only display different font attributes when the active font is available with these attributes. For example, fonts whose names contain something like 8x13 are not suitable (because the italic attribute is not available). You can easily try different fonts with Shift and the left mouse button. The following fonts have good results:

```
-adobe-courier-medium-r-normal--14-100-100-m-iso8859-1
-adobe-courier-medium-r-normal--14-140-75-m-iso8859-1
```

With large texts, syntax analysis takes any long time; when the text exceeds a certain size, the analysis is not carried out all.
In order to obtain quick syntax highlighting with long texts, you can use the Emacs extension lazy-lock. This extension carries syntax highlighting to be executed only for the displayed page and not for the entire. The extension is activated by the following lines in .emacs:

```
(autoload 'turn-on-lazy-lock' 'lazy-lock')
(Unconditionally turn on Lock mode.
(add-hook 'font-lock-mode' 'turn-on-lazy-lock))
```

With long texts (such as the text of this book, which takes up than 2 Mbytes), even lazy-lock becomes unbearably slow. At then, it is more reasonable to execute font-lock-notify-buffer manually and wait 10 or 20 seconds until the process has terminated. Emacs works at its usual speed.

# LaTeX font lock problem

When the lock mode ('lazy' or not) is used together with the LaTeX mode. Emacs may get confused in its syntax analysis and therefore mark large areas of text incorrectly. The most frequent cause is a single $ sign used in a verbatim environment or in a single verb command.

The problem can be solved by changing a line in the file font-lock.el (the " character is replaced with a space) which will cause no highlighting of formulae in LaTeX texts. In order for this change to take effect, you must rename font-lock.el or reclaim the modified file font-lock.el. If only *.el files are installed in your lisp directory, you must first install the Emacs Lisp source files. In many distributions, you must create a separate package.

```
; Change in /usr/X1R6/lib/emacs-20.4/lisp/packages/font-lock.el
; original:
 '(put 'tex-mode 'font-lock-defaults)
 '(put 'tex-font-lock-keywords nil (($? "\" "))))
; new:
 '(put 'tex-mode 'font-lock-defaults)
 '(put 'tex-font-lock-keywords nil (($? " " "))))
```
