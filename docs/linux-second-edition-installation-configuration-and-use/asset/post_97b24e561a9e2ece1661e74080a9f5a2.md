# Time of day

Because of their virtually international network, Unix computers worldwide use one and the same time. GMT stands for Greenwich Mean Time, which is the measure of all things (at least timewise) on Unix computers.

# Configuration of less

less is used for a pagewise screen display of text files and is therefore one of the most used Linux commands. In many distributions, the program is also used for display of man texts.

# CONFIGURATION AND ADMINISTRATION

Texts with foreign language special characters often cause problems, which be remedied by assigning the text 'latin1' to the LESSCHARSET environment variable. assignment should be carried out in /etc/profile.

```bash
# Addition to /latin1
export LESSCHARSET=latin1
```

But there are additional ways of making less much easier to handle. The environment LESS allows you to set the default options for Less. A useful one is -mm: this displays the current line number in each file. (For very long text files, this takes some time; therefore the option is not active by default.)

The environment variable LESSOPEN allows you to write a script (that is, a small program) which is automatically started at each less call.
