# # Netscape

After installation, depending on the configuration (and distribution), the browser can be started by means of one of the following commands: netscape-communicator, or netscape-communicator. At the first start-up, after various copyright messages and warnings have been displayed, the directory ~/.netscape is created, in which local configuration data, bookmarks, and temporarily stored files (cache) are stored.

# # Usage

With other WWW browsers, use of Netscape is not complicated at all. The document to be displayed can be fetched via FILE|OPEN PAGE| FILE|CHOOSE FILE or direct input of the address in the LOCATION field. The name of a local directory is specified, Netscape automatically displays all files and subdirectories; you can move to the page you are interested in with a click of the mouse.

With BOOKMARK|ADD BOOKMARK you can store the document in the bookmark list (This also works for local files; thus, for example, you can create a bookmark that points to the HOWTO index). The bookmark list will quickly become too long to handle. With COMMUNICATOR|BOOKMARKS|EDIT BOOKMARKS you open a separate window in which you can reorganize your bookmarks into directories, sort and rename them.

Another nice feature is the command FILE|NEW NAVIGATOR WINDOW (short, ALT+): it can be used to open an additional WWW window. This allows you to download and read several WWW documents in parallel which turn leads to a better usage of waiting time – very relevant with lower transmission speeds.

If you do not want to display a file pointed to a link, but instead transfer it to your computer, you can simply click on the link with the right mouse button. The command SAVE LINK AS opens a file selection dialog box where you can specify which directory and under which name the file is to be stored.
