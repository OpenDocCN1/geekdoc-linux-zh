
## 19.6 Configuration

LyX and KLyX can be widely adapted to your own requirements. This section gives an overview of the configuration files and shows how, with little effort, work with LyX can be made even more comfortable. (More information can be obtained with HELP/CUSTOMIZATION.)

### Configuration files

LyX and KLyX differentiate between global and local (that is user-specific) configuration files. The global configuration files can be found in the LyXD directory. Where this directory is located, at least in LyX, can be easily determined by checking the HELP/VERSION dialog. On the author's computer, the directories were these for LyX and KLyX:

```
/usr/share/lyx
/opt/kde/share/apps/lyx/
```

The central configuration file in this directory is lyrc (and the rest of this section is exclusively dedicated to it). Further important files are contained in subdirectories bind (keyboard shortcuts) and kbd (keyboard layout).
If homogenous local configuration files exist, they are automatically used instead of the global files. The local configuration directories for LyX and KLyX are:

```
~.lyx
./kde/share/apps/lyx
```

The configuration files for LyX and KLyX are stored in different locations but fortunately enough, their format is identical. However, KLyX has an additional configuration file: "./kde/share/config/lyrc is used to store user-specific settings that can be adjusted directly in LyX dialogs (as the zoom factor in SETTINGS/SCREEN OPTIONS). These settings take precedence over the settings stored in lyrc. In this regard, KLyX follows the KDE paradigm that programs should be configured directly by the user interface (and not through laborious modifications of configuration files).

### Keyboard shortcuts

The keyboard shortcuts available under LyX/KLyX (as long as they do not concern the menu) are specified through the *.bind files in the bind directory. The two main files are cua.bind with the keyboard shortcuts common in the Windows world, to emacs.bind and emacs.bind with shortcuts as defined in (X)Emacs. In addition, all of these files resort to menus.bind and math.bind.

The choice of keybind scheme you wish to employ is default by means of the bind.file in lyrc. The factory default is cua, the alternatives are emacs and emacs.

```
# lyxrc configuration file; use Emacs keyboard shortcuts
```

If you so wish, you can modify a copy of the *.bind files and use it instead of the predefined files, or you can specify individual keyboard shortcuts directly in xrc. An example:

```
# F5: PostScript preview; Shift+F5: update preview
bind "F5" "buffer-view-ps"
bind "S-F5" "buffer-typeset-ps"
```

### Toolbar

Changing the toolbar is only possible in LyX, but not in KLyX! If you want to modify toolbar, you need to remove the comment characters in the toolbar section of tyrc. These commands are now used at the start-up of LyX to replace the default toolbar with your own. You can now easily modify the toolbar by removing individual \add commands and/or inserting your own commands.

```
\begin_toolbar
\layouts
add buffer-open
add buffer-write
...
\separator
add buffer-view-ps
add buffer-typeset-ps
\end_toolbar
```

### Fonts

Optimization of font display can significantly increase working comfort in LyX. LyX uses three font families for representation of text. In the default setting, these are:

```
\screen_font_roman *-times-*
\screen_font_sans -*-helvetica-*
\screen_font_typewriter *-courier-*
```

Depending on which fonts your final document will use (set in LAYOUT|DOCUMENT|FONTS) which fonts are installed on your computer (to find out, execute xfonts | less!), a different setting may achieve a better WYSIW-G effect. If, for example, you wish to display the default font in Palatino instead of Times, the setting is:

```
\screen_font_roman *-palatino-*
```

### Colors

LyX only provides settings for background and foreground colors. Many colors (used for LaTeX, and on) can be specified at start-up. Unfortunately, some colors LyX dialogs. These appear in a dark shade that is hard to read.

### Auxiliary programs

Depending on whether you prefer (k)ghostview or kdvi for page preview, you can enter the desired program in lyrc:

```
\view_dvi_command "kdvi"
\ps_command "ghostview"
```

### Miscellaneous

At regular intervals (by default, 5 minutes), LyX carries out a backup. In LyX you may change this interval.

```
# Backup every 2 minutes
autosave 120
```

## 19.7 Keyboard shortcuts

The following information applies to LyX 1.0 and (with a few exceptions) to KLX 0.9—see the files cu.bind, math.bind, and menus.bind in /usr/share/lyx/bind/ or /opt/kde/apps/lyx/bind/ directory.

The cursor keys Home and End work in Windows programs. When, in addition, Ctrl is pressed, while words or paragraphs are deleted. If, in addition, Shift is pressed, the cursor moves to select an area of text.

Selected text can be copied with Ctrl+C, deleted with and pasted with Ctrl+V or Shift+Ins. In contrast to other programs, there is no possibility of toggling between an insert mode and an overtype mode. The Ins key has no effect: LyX does not have an overtype mode.

Menu commands can be entered with Alt, followed by the appropriate letter. While in KLX the corresponding menu appears immediately, in LyX this needs to be forced by entering an additional space. (If you know the shortcuts by heart, you can obviously do without this.) Menu commands can also be initiated with FI — this saves you the Alt key.

If LyX is not used with the original English language menus (but, for example, with German language menus), problems arise with the keyboard entry of menu commands both with Alt and F10. Furthermore, some keyboard shortcuts cause problems, in particular most of the Alt+S for changing the font size.

In this regard, KLX is more robust. Independently of the chosen language, the menu can be controlled via the keyboard without great difficulty (although here too, the F10 key fails). Problems are instead caused by keyboard shortcuts that do not work in the same way as in LyX (such as Alt+P for selection of a paragraph type).
