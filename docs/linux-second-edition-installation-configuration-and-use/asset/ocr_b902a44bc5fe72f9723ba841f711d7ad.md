Depending on the configuration, mount can only be executed by root, and only if no CD is currently linked into the file system and the directory /cdrom already exists. The device name /dev/cdx depends on your CD-ROM drive. Often, /dev/cdrom can be used; this is a link to the correct device.

If the CD-ROM drive is registered in /etc/fstab with the option, all users (and not only root) can add and remove the CD with the mount and unmount commands (see also page 154).

+   Modern CD-ROM drives are connected to either the EIDE or to the SCSI bus. The following list summarizes the corresponding device names:
-/dev/cdrom link to the default CD-ROM device
-/dev/hda IDE/ATAPI: drive 1, EIDE controller 1
-/dev/hdb IDE/ATAPI: drive 2, EIDE controller 1
-/dev/hdc IDE/ATAPI: drive 1, EIDE controller 2
-/dev/hdd IDE/ATAPI: drive 2, EIDE controller 2
-/dev/scd0 SCSI drive 1
-/dev/scd1 SCSI drive 2

With the first generation of CD-ROM drives, each and every manufacturer needed the need for a proprietary interface. This generated a correspondingly large number of kernel modules for each of these interfaces. Today, you will encounter CD-ROM drives only in stone-age PCs. To be able to access them under Linux, the appropriate kernel modules must be available. Furthermore, you will need to specify the correct device name, such as /dev/med for primal Mitsumi drives. Further information can be found in the CD-ROM HOWTO.

Changing a CD is a troublesome procedure. You cannot just open the drive, change the CD and then on working with the new CD! Several CD-ROM drives with electronic eject do not even allow this – while the CD is mounted, the drive does not react to pressing the eject button.

The procedure is to execute unmount (which is a way of informing the system that the CD is going to be removed) while the old CD is still in the drive. This causes a check to be carried out which needs any further data from the current directory. If it does, unmount signals 'device busy', for example if the current directory on any console points to the CD-ROM drive. Execute cd.

The CD is released only if no access to the CD is required. Now you can change and register the new CD in the same way as the previous one.

```
#root /cdrom
#root mount -t iso9660 -a ro /dev/hdc /cdrom
```

If unmount displays the 'device busy' message, another program is still using data from the CD-ROM. This is also the case if a directory of the CD-ROM is open in any of the shells. Execute cd in all of these to return to the home directory. Also, the fuser command may help in the search for the process which causes the unmount problems. Execute fuser -m /cdrom.
