comparable to LaTeX, but less sophisticated in its formatting capabilities and therefore
easier to handle.

In practice, the groff programs play a fairly secondary role – with one ex-
ception: groff is used to format the man texts. Thus, man texts are formulated in
ggroff-compatible syntax. They become easily readable ASCII texts only after groff
formatting.

The following description of groff explains only those options that are
to convert man sources into *.dvi or PostScript files.

```
groff [options] file > target.file
```

-maname

uses the macro file tmac.name in the /usr/lib/groff/tmac directory. For con-
version of man texts, the name used must be andoc.

-Tformat

determines the output format. Default setting is ps for PostScript. Other pos-
s settings are dvi (for dvi files), ascii for ASCII texts (yields the results
known from man), and latin (as ascii, but with language special
characters).

If a man text is present not only in its formatted version, but also as source
text, groff can be used to convert this file into a high-quality PostScript file, man
sources can be found in the man directories (x stands for 1 to 9, n, g), for example in
/usr/man/manx. The following command converts the man source file groff.1 into
PostScript format and writes the result into the file test.ps in the home directory:

```
user groff /usr/man/man1/groff.1 -mandoc > /book/test.ps
```

The same result – although without extensive control possibilities – is
achieved with the following command:

```
man -t groff > /book/test.ps
```

> NOTE: In Linux distributions, the man texts are only available preformatted,
so groff cannot be applied. In such cases, the rman command
allowed the man page to be converted into another format (PostScript,
HTML, and so on) (see page 514).

# Formatting of info texts (Texinfo)

info texts are created by means of Texinfo. The great advantage of the Texinfo sys-
tem is that the source files (extension *.texi) can be used to create both
info and a DVI file. The resulting *.dvi files can be converted into PostScript filesy means of dvips and subsequently printed. Thus, *.texi files are suited for both
creation of online documentation and generation of typographically excellent manu-
als. (LaTeX and dvips are described in a separate chapter from page 587 onward).
