```
mkisfs [options] -o iso_file directory
```

The normal case is, however, that you first put together the data for a new CD-ROM in a directory and subsequently generate an ISO image. This is exactly what mkisfs does: the command creates a file which contains all files of a directory which is formatted according to the ISO-9660 conventions (optionally with Rockridge extension-tension).

+   - Files with # or ending with ~ are considered as well. Usually, this is not the case, because such files are mostly backup files.

+   - The specified file is stored as a boot image. At computer start-up, this file is automatically executed (provided the BIOS is configured correctly). The size of the file must correspond exactly to what will fit on a 3.5 or 5.25 inch diskette (1.2, 1.44 or 2.88 MBytes).

+   - This option specifies the file name under which the so-called boot catalog should be stored on the CD. The catalog is created by mkisofs. When naming, you merely need to ensure that there is no conflict with an existing file. (The man text for mkisofs recommends using a name such as boot.catalog).

+   - The ISO standard allows for a maximum of eight directory levels. mkisofs usually sticks to this standard and, if needed, modifies the directory hierarchy (and the names of the affected files). The -d option prevents this; however, on some systems which require strict adherence to the ISO standard this may lead to problems.

+   - Symbolic links are followed, that is, the contents of files or subdirectories specified are included into the ISO image. (Without this option, only the link is stored in the ISO image. However, symbolic links can only be mapped to CDs with Rockridge extension).

+   - The ISO image is stored in file.

+   - The ISO image uses the Rockridge extension to store information on long file names.

+   - As -r, but UID and GID are set to 0 for all files (corresponds to root). At the same time, all R access bits are set; if at least one X bit was set in the original file (see also chmod on page 444).

+   - The file TRANS.TBL is written into each directory; this specifies the short ISO-9660 name under which files with long Unix names can be found. (This is necessary to allow association to long file names under DOS/Windows as well.)
