Once LILO has been correctly installed in a hard disk partition, you can also use the installation diskette or the installation CD-ROM of most distributions for booting. Starting-up, you only need to specify the option root=/dev/hdX to ensure that, after start-up of the kernel, instead of loading the installation program, your root file system is mounted and its Init process started.

This kind of emergency process may cause problems with SCSI disks. Often, the kernel does not include the required SCSI driver. If the corresponding module is only loaded later by the installation program, mounting your root file system is no longer possible. Therefore, some distributions supply pre-configured kernels with the most frequently used SCSI drivers.

# Kernel boot diskette

Even if, in the long run, you plan to use LILO, you still need a boot diskette first! The reason is: if something goes wrong with the LILO installation, if during a later installation of Windows 9 LILO is overwritten again, and so on, you need to be able to start Linux in some point.

Usually, you are offered the possibility of creating a boot diskette at some point of the installation procedure. You should definitely take advantage of this. If at a later stage, you want to create a new boot diskette (for example, with a recompiled kernel), the procedure is as follows:

```
root# ifformat /dev/id0  # format (if unformatted)
root# cp /dev/vmlinuz /dev/id0  # copy kernel to diskette
root# rdev /dev/sd1  # determine boot partition
root# rdev /dev/id0  # set this partition in the kernel
root# rdev -v /dev/id0 -2  # extended VGA mode (50 lines)
root# rdev -R /dev/id0 1  # register boot partition as read only
```

The above lines assume that the kernel has the name /vmlinuz. In some distributions, the kernel file is located directly in the root directory (thus, /vmlinuz)
