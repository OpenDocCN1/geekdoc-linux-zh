# FUNDAMENTALS OF FILE MANAGEMENT 95

The state of bits, the file owner and the group membership can be viewed with ls -l. For a typical file, ls supplies the following results: the file can be viewed and modified by its owner, michael. As it is a text file, the first x bit is deactivated. All other users, members of the users group or, can read this file (but not modify it).

```
ls -l header.txt
-rw-r-- 1 michael users 3529 Oct 4 15:43 header.txt
```

ls -l not only displays the state of nine access bits - the very first character of the output line is reserved for the file type (- for a normal file, d for a directory, l for a symbolic link and so on).

If michael wants this file to be read by members of the users group, but not by users outside of group, he must deactivate the r bit. This is done by the chmod command (see page 444). On most systems, the users group consists of all 'normal' users.

```
ls -l cheod header.txt
-rw-r----- 1 michael users 3529 Oct 4 15:43 header.txt
```

Access to the file header.txt may be limited to two users, michael and cath. For a new group can be created, to which only the two members belong. (If michael and cath are, the documentation team of a firm, a group name such as docuem would possibly be a good choice. See page 96.)

```
ls -l chgrp docuem header.txt
-rw-r----- 1 michael docuem 3529 Oct 4 15:43 header.txt
```

Files of other users can be copied into one's own directory if the r bit is set for the group or for all others. This copy is owned by the user who executed the cp command. Now it is possible for this user to change the access bits of the copy and subsequently modify it or (if it is a program) execute it.

# Access rights to directories

In principle, the nine access bits are also valid for directories, but with some slight modification of their meaning: the r bit allows other users to view the contents of the directory with ls. The x bit allows them to change into this directory with cd. If x and w are set, other users are even allowed to copy foreign files into this directory.

# Access rights to devices

Access to various hardware components (floppy disk drives, printers, modems (that is, serial interfaces), streamers) are carried out via devices. In order to control which user may access which device, devices are assigned different user groups. For example, /dev/tty1 (the second serial interface which is normally connected to a modem) is assigned to the group u.
