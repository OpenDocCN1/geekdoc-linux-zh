By pressing the middle button, the stored characters are inserted at the current insertion point. If gpm is called with the option -b132, insertion can be carried out with the right mouse button (an important feature for a two-button mouse).

Thus, as a rule, the mouse is only used to facilitate input and to copy text between consoles. It is not possible to use the mouse to change the position of the insertion point (for example, in an editor). Linux programs that work in text ignore the existence of the mouse. Text insertion appears to these programs as a normal keyboard input. The only exceptions are programs that are specifically oriented towards cooperation with gpm, such as Emacs, lynx, mc, sirn, and tint.

In the call to gpm the type of mouse must be specified after the option -t: mman for MouseMan compatible, ms for a Microsoft compatible mouse, msc for Mouse Systems, Logi for Logitech, bpm for an ATI or bus mouse, or ps2 for a PS/2 mice. (gpm -t helps show a complete list of all mouse types.) For three-button mice, your choices are between msc or mman.

```
root# gpm -t mman
```

During experimenting, gpm -k is very useful to stop a running gpm. Only then can gpm restarted with different parameters.

gpm assumes that a link points from /dev/mouse to the correct interface (usually /dev/tty0 or /dev/tty1 for the serial interface, /dev/psaux for PS/2 mice). Tips for handling the serial interface can be found on page 169 onward, in the context of modern configuration.

Nowadays, gpm is automatically set up by practically all distributions. Since gpm is a background process ('daemon' in Unix jargon), it should be automatically started and stopped by the Init-V system when the runlevel is changed (see page 124).

# Inverse or colored text display

Generally, text consoles display text on a black background. This is, however, not very eye-friendly. The screen display can be inverted by means of the setterm command. To make all consoles profit from this screen display, the command must be added to /etc/profile (profile is evaluated at each login).

# Addition to /etc/profile

# black characters on white background

```
setterm -inverse
```

Instead of setterm -inv (here in its short form) you can also execute setterm-white -foreground black -store. You obtain exactly the same effect, but you can use this notation to set other colors as well (such as blue background and red characters). With the setterm options ukl and hbcolor you can furthermore set the colors for underlined and bold text. (These attributes are, for example, used in the display of man texts.)
