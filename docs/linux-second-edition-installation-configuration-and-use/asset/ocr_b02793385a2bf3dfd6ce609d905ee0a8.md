The most important syntax variations of \index<entry> are obvious from the above table. The character combinations |< and > are used to specify page ranges. The resulting index entry will, for example, look like this: entry 34-38. A command after | and without a prefixed % character can be used to format the page number. A sample for the specification of a suitable command has been indicated with |if(see new command), which can be used to place formula or specially sorted entries at the correct position in the index. All formatting methods mentioned can also be combined, for example to highlight a particular subsum.

# 18.4 Mathematical formulae

In order to allow representation of mathematical formula in LaTeX you must switch to mathematical mode. All the commands presented here can only be executed in mathematical mode!

There are three ways to activate this mode; either the formula is enclosed inside the flowing text with $ characters, or the formula is started in a separate paragraph with \c and terminated with \J, or if the formula is written in an equation environment. In the last two variations, the formula is centered in a separate paragraph; in the equation environment, it is also automatically numbered.
