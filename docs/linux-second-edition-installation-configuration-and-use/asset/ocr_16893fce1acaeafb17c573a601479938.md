# Document structuring

\part(Title) part (only for book and report)
\chapter(Title) chapter (only for book and report)
\section(Title) section
\subsection(Title) subsection
\subsubsection(Title) subsection section numbering itself.

LaTeX deals with chapter and section numbering. At the same time, LaTeX automatically selects suitable typefaces and text spacing for the titles. In the book text type, the text in the \chapter and \section commands is also taken into account for generating running heads. When the commands are used in the form \section{short version}, the short version is used for running heads and table of contents, whereas the complete version is used for body text.

If the text is to be equipped with an appendix, this is started with the \begin{appendix} command and ends with \end{appendix}. Inside the appendix, \chapter, section can be used, with the chapters now numbered A, B, C...

Thus, the general structure of a typical LaTeX looks approximately like this:

```
\documentclass[11pt]{article}
\usepackage{isolate1}

% space for macro definitions, variable assignments, and so on
% possibly table of contents with \tableofcontents

\begin{document}
% the text itself, structured by means of
\section(...), \subsection(\hdrsecb ...), and so on

\begin{appendix}
% the appendix text, again structured by means of
\section(...), \subsection(\hdrsecb ...), and so on
\end{appendix}
\end{document}
```

# Fonts and attributes

Other text processing programs have probably got you to a practically unlimited choice of fonts and sizes. For historical reasons, this is not the case in LaTeX. As a rule, LaTeX restricts your choice to three families: one standard font used for flow text, headings, and so on. The Typewriter font for font listings and the Sans Serif font for highlighting and other tasks.

These three fonts (or better 'font families') can be formatted with different attributes. The highest number of attributes exists for the standard font, which can be represented as bold, italic, slanted and small caps.
