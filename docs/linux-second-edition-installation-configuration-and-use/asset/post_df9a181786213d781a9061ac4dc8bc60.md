## Math mode

In one characteristic, LyX has a great advantage over many other formula editors (like that of Word): formulas can almost entirely be entered via the keyboard. LaTeX professionals in particular will leave a sigh of relief – nearly all LaTeX commands can be entered as usual. As soon as you press the Spacebar, LyX replaces the command with the corresponding symbol or construction. If, for example, you enter \frac and a space in Math mode, LyX generates a fraction stroke, and you can go on working in WYSIWYG.

# imp – the Photoshop alternative

The acronym imp (GNU Image Manipulation Program) stands for an image processing program which in many respects offers similar and sometimes better functions than the commercial program Photoshop. The essential difference: imp is free software (GPL). Its main authors are Matt and Spencer Kimball, supported by many others who have helped with debugging and optimization or have written one of the numerous plug-ins (extension modules).

This chapter gives a first introduction to imp 1.0. Even though, for reasons of space, one cannot even attempt to describe the main features of imp to their full extent, the chapter will at least provide detailed information on all functions. Simple conversion of graphics files, execution of image processing, and production of screenshots are described in Chapter 15 from page 491.

## 20.1 Introduction

### What is imp?

imp is an image processing program – you know this from the introduction. If you have no experience with Photoshop or another comparable program, this term may still be vague. With imp you can:

- read and write bitmap files in the most disparate formats; supported formats include, amongst others, GIF, PNG, and TIFF
- import PostScript files (EPS/PS) and Photoshop files (PSD)
- play the artist and paint pictures completely from scratch
- change the color and brightness distribution of images (for example, lighten the image, increase the contrast, and so on; such operations are mainly used to improve the quality of scanned images)
- apply various filters to the image, for example to detect and highlight edges, to achieve optical effects, and so on-select and cut parts of the image, elaborate them separately, and combine them into new images (photo management)
- integrate new graphical elements into the image (lines, patterns, graduated tints, text, and so on)
- create animated *.gif files (for example, to produce nerve-shattering Web pages)
- mechanize imp operations (to do this, you must familiarize yourself with the Script-Fu language integrated into GIMP)
- apply imp in batch operation to a collection of files

> imp does not include any scanning functions. A rich function for controlling your scanner under Linux is provided by the SANE (Scanner Access Next) package which is part of many distributions. When installed correctly, SANE can be used directly from imp via a plugin – see the text for xscanimage. Up-to-date information on SANE can be found under www.mastang.com/sane.

> imp does not include an import filter for photo CD files (extension PCD). If you wish to read images from photo CDs you can resort to the very user-friendly xpcd program – see page 517.

## Dream and reality

imp is an incredibly versatile and powerful program (and this chapter describes only about the first five percent!). Nevertheless, there is a great that, after your first experiments, you will lose all hope and delete the program from your hard disk. There are two main reasons for this:

- imp is a powerful tool, but you need intensive familiarization before you can use it efficiently. Occasional messing about with a *.gif file on a homepage is a purpose for which the program is suited only to a limited extent. (This is not only the fault of imp. Generally, professional image processing is an activity which is considerably more difficult than it appears.)
- imp makes considerable demands on your hardware. The same applies to the imp manual, which is usually read with acroread. As a reasonable working environment, you need enough RAM (at least 64 Mbytes), a fast CPU, a big screen, a high-resolution mouse, and a graphics card supporting Truecolor (that is 22¹).

Wrong expectations also result from the fact that imp is often described as a free, but otherwise equivalent variation of Adobe Photoshop. This is somewhat of an exaggeration at the moment (but imp is being actively developed!). The following points summarize the most important restrictions and differences:

- The handling of imp differs considerably from that of Photoshop, at least in parts. True imp fans will obviously object that the handling of imp is much more intuitive and efficient. For some functions, this may be true; for others, however, one gets the impression that the program was written by technicians for technicians. Furthermore, for people changing over from Photoshop, it is often difficult to find the appropriate functions in the embedded levels of the context menu.
- Creation of PostScriptfiles for professional print jobs is more difficult with imp than with other programs. Carrying out a CMY(K) color separation or production of images in special or ornamental colors (duplex image format) is possible, but the functions are all easy to handle. Direct support of Pantone colors is lacking completely.
- If you create graphics with your texts, you are tied to the character sets available under X. Although a considerable choice of freely scalable character sets is by now available, Unix/Linux in no way compete with the multitude of fonts available in the Windows or Macintosh world. (Installation of new character sets is described on page 250).
- imp comes with an excellent manual, but provides no context-sensitive online help.
- Currently, menu and dialog texts are only available in English.
