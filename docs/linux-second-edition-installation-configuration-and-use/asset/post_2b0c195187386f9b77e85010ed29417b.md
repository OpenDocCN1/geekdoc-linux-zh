The Metafont program expects not only the required resolution as a parameter for the generation of a character set, but also additional information about the printer type. If the printer type is known, Metafont can evaluate .mf files in the /usr/share/texmf/metafont/misc directory. These files are listed, together with printer-specific data which allows the character sets to be optimized to the printer's peculiarities. For example, printers which make single pixels too thick generate thinner character sets to compensate for this fault. A typical entry in modes.mf looks more or less like this (which is for a Canon ink jet printer for 360 dpi):

```latex
% /usr/share/texmf/metafont/misc/modes.mf
% From sjwright@ci.compulink.co.uk, 9 February 1994.
mode_def btexen = % Canon BubbleJet 10ex
mode_param (pixels_per_inch, 360);
mode_param (thicker, .6);
mode_param (fillin, 0);
mode_param (o_correction, .6);
mode_common_setup_;
endef;
```

To generate a proper printout with this printer, you must insert the following line into the case statement in mktexpk:

```bash
# insert into /usr/bin/mktexpk
360) MODE=btexen;
```

## Font files

If you want to know which font files are available to you, you can change to the /usr/share/texmf directory. There, you execute the command

```bash
user8 -name *.emf  # Note: likely meant find -name *.emf
```

The result is a list of font files (about 1500 on my computer). Out of all these fonts, you will only need very few, namely those of the ./fonts/source/public subdirectories (in the NTeX distribution). The character sets are designed for various TeX and LaTeX fonts (for AMSTeX) which are described in Lambert (1994) and Goossens et al. (1993).

The names of LaTeX standard fonts begin with the letters 'cm', which stand for computer modern. The cm de facto standard for LaTeX documents. In parallel to these fonts, a new generation of fonts has been developed during the past few years; these are known as dc fonts. The dc fonts differ from the cm fonts in that they have an extended character set (more special characters) and compatibility problems. Their biggest disadvantage is that their character codes are particularly different from the cm font codes and thus, the use of dc fonts requires new hyphenation files, and so forth (see again the above-mentioned books).

## Using PostScript fonts

The subject of this section is not only to print a LaTeX font on a PostScript printer — to do this, you only need the dvips program. The real subject of this section is actually how not to use the original fonts for printing, but rather to use well-known PostScript fonts such as Courier, Helvetica, Times Roman or Palatino.

The main advantage of using PostScript fonts is that you have a much wider choice of fonts. A further argument in favor of PostScript fonts is their better scalability. PostScript fonts are always output at the highest possible quality by every single PostScript printer. If you work with LaTeX fonts, on the other hand, you must generate a separate file for every printer to achieve optimum quality. (Printing with resolutions higher than 300 dpi has been discussed in the previous section.)
