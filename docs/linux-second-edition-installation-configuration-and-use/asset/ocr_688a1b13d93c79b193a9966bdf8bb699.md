root# dd if=/dev/sda of=/boot/bootsektor scsi bs=512 count=1

If you want to convert the boot sector to a diskette, you need a formatted diskette (see fdformat on page 453). Then, execute one of the following commands:

```
root# dd if=/dev/hda of=/dev/id0 bs=512 count=1    # first IDE disk
root# dd if=/dev/sda of=/dev/id0 bs=512 count=1    # first SCSI disk
```

If a disk generated this way is present in drive: When the computer is restarted, the computer boots exactly the same way as from the boot sector on the hard disk. This is most impressive under Windows 9x.

When you create a boot diskette under Windows 95 (CONTROL PANEL | ADD/REMOVE PROGRAMS | START DISK), you can only use it to start DOS, not Windows. This may be sufficient to restore a damaged system, but it is not at all elegant. If, on the other hand, you proceed as described above, you can start Windows 95 from a diskette quickly and without problems. Assuming, that is, that the Windows partition has not been damaged and that all system files are available. In contrast, the 'original' Windows 95 boot diskette is autonomous, files such as COMMAND.COM are loaded directly from the diskette.

# Setting up LILO

To set up LILO, you need a lilo.conf file which, except for the boot line looks exactly as the diskette version. Path and device names need to be adjusted to suit your computer. You may need additional options which have been described in the configuration section.

```
# file /etc/lilo.conf
boot=/dev/hda                # device of the first IDE disk
# boot=/dev/sda               # device of the first SCSI disk
prompt
time=100
image = /dev/mlinux          # kernel file
label = linux
root = /dev/hda8             # root device on
read-only
# initrd = /boot/initrd       # RedHat with SCSI
other=/dev/hda1
label=dos
table=/dev/hda
```

# Removing LILO from the hard disk

To remove LILO from the hard disk, you must restore the boot sector. In the simplest case, you simply execute lilo -u. This causes LILO to read the boot sector saved in /boot during the first LILO installation and to use it to overwrite the current LILO boot sector.
