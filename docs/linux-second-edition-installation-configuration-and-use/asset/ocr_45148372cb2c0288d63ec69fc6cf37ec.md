# shift [n]

shift shifts the parameter list passed to the shell program through the predefined variables $1 to $9. When shift is used without parameters, the parameters are shifted by one position, otherwise by n positions. shift is of particular help when more than nine parameters are to be accessed. *Warning*: Parameters shifted out of the variables with shift can no longer be accessed. They are also removed from the variable $*.

# sleep time

sleep puts the running program into a state of rest for the specified time. During this time, the program uses practically no CPU time. Time is normally specified in seconds. Optionally, the letters ‘m’, ‘h’ or ‘d’ can be appended to specify the time in minutes, hours or days.
