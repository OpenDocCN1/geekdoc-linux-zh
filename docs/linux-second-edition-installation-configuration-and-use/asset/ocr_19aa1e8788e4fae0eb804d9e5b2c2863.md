# Magic wand (Fuzzy / Color Selection)

The FUZZY SELECT tool ( ) selects a contiguous area of similarly colored pixels (for example, the shining red body in a picture). Simply click the mouse on a starting point whose color is most characteristic of the required area. With the mouse button still kept depressed, you can now increase (movement towards bottom right) or decrease (movement towards top left) the selection threshold.

A similar tool to FUZZY SELECT is fulfilled by SELECT | COLOR. It has its own dialog in which the current selection is shown as a black and white mask (Figure 20.14). The selection can easily be extended or restricted by areas of a specific color. You can also click on the image and view the preview mask in the dialog.

The FIZZINESS slider ruler determines how large the color area should be. However, the ruler does not apply to executed selections, but only to future operations. Unfortunately, there is no undo function for selections that have been constructed stepwise. (Try it out with SUBTRACT!) THE BY COLOR tool has an option dialog (FEATHER, ANTIALIASING, and SAMPLE MERGED), which is automatically opened when a toolbox dialog was already present on screen.

As fascinating as these two tools are, the selections cut with their aid seldom be used without further refinement. Thus, do not expect miracles!

> SELECT | BY COLOR provides an easy way of making an object on a singlecolor background transparent: simply select the background and cut it with Ctrl+X! (Obviously, this only works without problems if the background color does not occur in the object as well.)
