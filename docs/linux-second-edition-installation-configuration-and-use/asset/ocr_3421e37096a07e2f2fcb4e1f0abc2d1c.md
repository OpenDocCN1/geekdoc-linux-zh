# BASH PROGRAMMING

```
$($!var)
```

yields the contents of the variable whose name is contained as a character string in var.

```
user$ abc=123*
user$ efg=abc
user$ echo $($!efg)
123
```

> NOTE The syntax $($!var1) is only allowed from bash version 2 onward. If in an older version of the bash you want to determine the contents of a variable whose name is specified in another variable, you must use the following syntax (which is also allowed in version 2):

```
user$ eval var2=\$(var)
```

# Reading in variables with read

You can use the read command to accept input during execution of a shell program. Usually, you first call echo to display a short text which tells the user what you expect (for example, y/n, a numerical value, and so on). When you use the option -n input starts directly after the echo text and not in the following line. During execution of the subsequent read command, the bash waits until the user enters a line and terminates it with ENTER.

In the following sample program, the while loop is executed until the character string in the variable a is no longer empty. A test run shows the function of the tiny program:

```
$user$ readvar
Enter a number: a
Invalid input, please try again
Enter a number: 12
$ readvar
: a
12
```

After the first input via read, the entire contents of the variable are deleted via parameter substitution if a character occurs which is not a digit, a minus sign, or a space. This check is obviously not perfect (the strings "12-34-5" and "12 34" are not legal), but is fairly efficient. Information about while can be found on page 419.

```
#! /bin/sh
# readvar: read numerical value
a=
while [ -z "$a" ]; do
echo -n "Enter a number: "
read a
```
