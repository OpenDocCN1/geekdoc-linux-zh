By specifying -P, lpr can forward options to apsfilter. -Praw prevents the automatic conversion. (This is useful if a file is already in the current printer format.)
PPascii treats a file as an ASCII file (even when it contains foreign language characters and is therefore classified by file as a binary file).

```
root# lpr file.dv1 # automatic conversion into printer format
root# lpr -Praw # printing without conversion
root# lpr -Pascii file # treat file as ASCII text
```

Although the filter might look simple because of its easy installation, it is a complex and error-proof tool! If you want to get rid of it again, simply delete the entries in /etc/printcap.

# 6.8 Modem configuration

The title of this section is perhaps misleading: the main topic is not so much the configuration of the modem (which is usually not required at all), but the correct use of the serial interface for connection between modem and modem.
in the simplest case, you have a modem connected to the first or second parallel port. (Sometimes, the mouse occupies the first serial port.) Under Linux, you address the modem via /dev/ttyS0 (corresponds to COM1: under DOS/Windows) or via /dev/ttyS1 (COM2). No configuration whatsoever required!

In some distributions, a link is established during modem configuration which points from /dev/modem to /dev/ttySn. This link is, however, not mandatory and may cause problems (when two programs want to access the serial port at the same time).

```
root# ls -l /dev/ttyS0,1 /dev/modem
lrwxrwxr-xr 1 root 10 Jan 5 -> /dev/ttyS0
cr-w-rw- 1 root ucp 4,64 Jan 5 /dev/ttyS0
cr-w-rw- 1 root ucp 4,65 Dec 11 /dev/ttyS1
```

Up to Linux kernel 2.0, the modem could also be addressed via /dev/cuan. Since kernel 2.2, this is no longer possible. When you want to kernel 2.2, you will probably need to modify the /dev/modem link or the configuration of various programs.

The easiest way to try out your modem is to start one of the programs minicom or seyon (see page 525) and enter ATH followed by ATZ ('hang up'). This instructs the modem to break a possibly existing connection. The modem answers with OK. You now know that communication between Linux and the modem works. In some cases, during start of minicom or seyon, you may need to specify the port through which the modem should be addressed.
