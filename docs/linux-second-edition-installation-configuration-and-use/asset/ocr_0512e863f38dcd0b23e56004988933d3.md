# top [q]

# touch [options] files

+   -d time
stores the specified time (date and time of day).

+   -r file\uses the specified modification time and date of the specified file.

# tr [options] cs1 [cs2] [ < source > target]

tr substitutes the characters of character 1 in the specified source file with the corresponding characters of character 2. The character strings should be of equal length. Characters that do not occur in the first character string remain unchanged. It is not possible to replace a single character with several characters (for example, ð with "o") - for this purpose, commands such as recode or sed must be used.

+   -d
the characters specified in string 1 are deleted. Character 2 string does not have to be specified.

# Example

```
user$ tr a-z A-Z < text.lin
```

replaces all lower case letters in text.lin with upper case letters.

# tty

tty displays the device name of the terminal (/dev/tty1 to tty6 for the consoles, /dev/ttyn for X shell windows).

# tune2fs [options] device

With tune2fs, various system parameters of an ext2 file system can be modified at later times.
