The options guid, uid=, and umask=m can be used to preset privileges for files. This makes sense for file systems for which this information cannot be stored or evaluated by Linux (DOS, Windows, OS/2). Without the use of this option, DOS files are owned by root; these can be read by all users, but only modified by root. The three options allow more liberal access.

Please note that umask is interpreted firstly as an octal value and secondly as the value of the chmod command (page 444). umask=0 means every user is allowed to read, write, and execute all files. umask=111 sets the execute bit to 0, but still allows read and write access.

The option noauto means that the storage device mentioned in this line is not immediately available, but it can be mounted with mount without having to specify mount options explicitly or (all missing specifications are automatically read from fstab). This can be, for example, useful for CDROM drives or cannot normally be mounted. Also, a partition not mounted into the system cannot be destroyed.

The user option allows users to unmount and remount the file system with unmount and mount. Normally, only root can do this. The user option is particularly useful when frequent media changes are needed (diskettes, CD-ROMs). The exec option allows programs on CD-ROM drives to normally be executed..

The sixth column contains information for the dumps program and is presently ignored. The root directory should be assigned the value 1, all other file systems 2. File systems that are not to be verified (for example, CD-ROMs, proc and swap) are assigned 0.

Information similar to fstab is stored in the mtab; it contains a list of storage devices that are currently mounted. Thus, mtab changes dynamically with every mount or unmount command.

> Information about fstab can be obtained with man fstab. Further information that also applies to fstab can be found in man mount. In particular, 30 options are described that apply equally to mount and fstab. In practice, fstab is a centralized collection of options that are then passed to mount.)
