# 本书结构

本书分为四个部分：

- 第一部分（第 1 至 4 章）解释了 Linux 的安装和首次使用。
- 第二部分（第 5 至 8 章）提供了关于 Linux 优化配置的大量信息以及必要的基础知识。
- 第三部分（第 9 至 11 章）专门介绍网络访问。
- 第四部分（第 12 至 20 章）描述了如何使用 Linux 系统——从输入 shell 命令到使用 Gimp 进行图像处理。（第四部分的大部分信息适用于大多数 Unix 系统，而不只是 Linux。）

第一部分首先回答了关于 Linux 的一些基础问题。什么是 Linux？它是如何产生的？什么是发行版？第 2 章解释了 Linux 的安装。（附录中提供了 Debian、RedHat 和 SuSE 发行版的详细信息）。第 3 章提供了运行 Linux 系统的快速入门：登录、注销、关机、文件处理、显示和编辑文件等。第 4 章在你开始接触 Linux 时也有用；它描述了可以在哪里找到关于 Linux 的在线文档。

第二部分从 Linux 基础知识章节开始，例如其文件系统结构、Linux 下各种硬件组件的集成（例如鼠标、软磁盘、流驱动器）、进程管理、启动过程等。这一章并不是后续配置章节的先决条件，但它让理解这些内容变得容易得多。其余章节涵盖了基础配置、基础网络配置、内核配置以及 X 配置（包括 KDE 和 GNOME）。

# 书的结构

第三部分详细描述了 Linux 最重要的网络工具。重点在于能够毫不费且高效益地利用互联网的方法（WWW、电子邮件和新闻的离线配置）。

第四部分假设 Linux 已经安装并配置到可以让你舒适地与其工作的程度。第 12 章描述了 bash 的操作，bash 是 Linux 下输入命令的标准 shell。第 14 章概述了 Linux 下可用的最重要命令（ls, cp, find, grep 等）。

第 15 章描述了各种简化你在文本终端或窗口系统下日常操作的工具：文件管理器、不同格式文档间转换的程序、处理 PostScript 文件和图像处理的工具等。

书中设有专门章节留给了特别重要的程序：Emacs 编辑器、LaTeX 排版程序、LyX 文字处理程序（更准确地说，是 LaTeX 的现代用户界面）以及图像处理程序 Gimp，它提供了与商业软件 Adobe Photoshop 类似的功能。

附录涉及了一些重要 Linux 发行版的特殊特性，

> 本书描述的所有程序并非在每个 Linux 发行版中都提供。如果你的发行版中缺少某个程序，你总可以在互联网上找到它。如果你使用 RedHat 发行版，RedHat FTP 服务器上的 contrib 目录是一个很好的搜索起点。
