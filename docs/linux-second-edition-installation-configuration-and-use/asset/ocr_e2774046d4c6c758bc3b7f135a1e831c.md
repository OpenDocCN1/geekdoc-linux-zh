# Performing the installation

If you are sure that your selection is correct, the time has come for INSTALLATION. If by chance the selected packages are not present on the currently inserted CD-ROM, yast prompts for a change of CD.

During installation of packages, yast asks whether a backup of all modified files of the affected directories is to be created. For this purpose, the backup component of yast described below is employed.

# Finding packages

Fortunately, the SuSE series are not as entangled as RedHat, but in SuSE it is often difficult to find a specific package. In such cases, the INDEX command creates an alphabetical list of all packages, is of great help. Already installed packages are marked with an asterisk. For each package, space requirements and series are indicated.

An more powerful command is PACKAGE INFORMATION: here you can specify which text is searched for in the descriptions of all packages. In the list of results, you can immediately mark the required package for installation.

# The yast backup program

As the large number of configuration functions, yast also provides the possibility of creating backups. The backup program is called via SYSTEM ADMINISTRATION CREATE BACKUPS. In the first step, you must specify the directories and file systems (usually DOS and CD-ROM) that you want to exclude from the backup. In the second step, the backup program determines which files have changed with respect to the original installation from CD-ROM. The program displays a list of all directories from which files would be backed up. At this point you have a second opportunity to exclude individual directories from being backed up.

In the last step, you can specify where the backup is to be stored. You may specify either the device file of a streamer or an ordinary file. The backup can also be compressed. Furthermore, a contents list can be created, that is, a list of all files included in the backup archive.
