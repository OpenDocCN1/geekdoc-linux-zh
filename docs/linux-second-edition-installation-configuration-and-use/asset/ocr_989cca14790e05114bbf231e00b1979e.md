In formulae, individual variables must often be marked with vector arrows, derivative dots or quotes or other additional symbols. The following table describes the most important marking commands. Please note that commands as \vec can only be used for single letters (and not for groups of letters or even longer expressions).

# Vectors, derivatives, etc.

| \bar{x} | \tilde{x} | x' | x'' | x''' | x'''' |
| \dot{x} | \ddot{x} | \vec{x} | | |

# Greek letters and calligraphic letters

Greek letters are also represented by LaTeX commands. The command name corresponds to the name of the letter, thus, for example, \alpha for a lower case a and \Delta for an upper case \Delta.

# Greek letters

| \alpha | \kappa | \Psi | \Psi | \Upsilon | \Upsilon |
| \beta | \lambda | \omega | \omega | \varepsilon | \epsilon |
| \chi | \Lambda | \Omega | \Omega | \varphi | \xi |
| \delta | \mu | \rho | \rho | \varpi | \zeta |
| \Delta | \nu | \sigma | \sigma | \varro | \omicron |
| \epsilon | \phi | \Sigma | \Sigma | \varsigma | \theta |
| \eta | \Phi | \tau | \tau | \vartheta | \iota|
| \gamma | \pi | \theta | \theta | \xi | \kappa |
| \Gamma | \Pi | \Theta | \Theta | \Xi | \lambda |
| \iota | \psi | \upsilon | \upsilon | \zeta |

Calligraphic letters are only available in upper case. In order to represent these letters, the typeface must be changed by means of \cal, thus, for example, (\cal A) \cup (\cal B) for A \cup B.
