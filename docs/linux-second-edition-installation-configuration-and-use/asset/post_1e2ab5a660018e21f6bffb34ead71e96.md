# The publishers-edition directory

This directory contains a number of packages which normally belong to RedHat Linux 6.0 but could not be included on CD 1 for reasons of space. The RPMs subdirectories contain the corresponding source code.

For installation of individual packages you use rpm. It may happen that some packages require prior installation of other packages. The following example shows the installation of teTex (that is, the TeTeX distribution). The first attempt fails:

```
# rpm -i /cdrom/publishers-edition/tetex-0.9-17.i386
error: failed dependencies:
dialog is needed by tetex-0.9-17
```

Thus you need to insert CD-ROM 1 (umount, mount) and install the dialog package:

```
# rpm -i /cdrom/RedHat/RPMS/dialog-0.6.14.i386.rpm
```

After another change of CD the tex installation works without problems:
# rpm -i /cdrom/publishers-edition/tetex-0.9-17.i386

# The updates directory

If after completion of a new distribution problems or gaps appear in individual packages, RedHat usually makes corrected packages available on its FTP server after a short time. The updates directory contains all the updates available by end of May, 1999. Information on the errors corrected by these updates can be found in the file updates/README.

To replace an already installed package with a more recent version, you use rpm with the --upgrade option. However, this does not work straight away. Thus, for example, installation of Netscape Communicator 4.6 packages the package netscape-common-4.6. This package can, however, not be updated because this would violate the package dependencies with the still previous Netscape version. The update function only when you update both packages with one single command.

```
# --upgrade netscape-communicator-4.6-1.i386.rpm
error: failed dependencies:
netscape-common = 4.6 is needed by netscape-communicator-4.6-1
# --upgrade netscape-common-4.6-1.i386.rpm
error: failed dependencies:
netscape-common = 4.5 is needed by netscape-communicator-4.5-3
# --upgrade netscape-common-4.6-1.i386.rpm \\
netscape-communicator-4.6-1.i386.rpm
```

# KLyX

KLyX is the KDE version of LyX. Installation is somewhat complicated:

```
# cp /cdrom/contrib/libstdc++-0.2.9 /usr/lib
# ldconfig
# rpm -i --nodeps /cdrom/contrib/klyx-0.9.9-1.i686.rpm
# cp -rs /opt/kde/bin/* /usr/bin/
# cp -rs /opt/kde/share/* /usr/share/
```

Some remarks about the above: KLyX:9.9 presumes the library libstdc++-2.9.0. Although RedHat 6.0 supplies the libstdc++-2.9 package, this package provides only version 2.8 of the required library (you can easily verify this by means of rpm -q --provides libstdc++. It is unlikely that confusion of versions was intentional).

To install the required libstdc++ without using the RPM package management, the missing file is simply copied into the /usr/lib directory. ldconfig makes that this library is found.

The --nodeps in the following rpm command forces the installation of klyx although libstdc++-2.9 is still unknown in the RMP database.
The next problem is that under RedHat 6.0 all KDE files are found in the /usr/share directory. The KLyXPackage, however, is installed into /opt/kde/share instead. (This directory is the default directory which was taken over by many distributions but not by RedHat). To make KLyX find required files, appropriate links are created by means of the two cp -ls commands.

> The KLyX package on CD-ROM 2 is optimized for i686 processors (Pentium Pro, Pentium II, and compatible processors). Installation and execution on older processors is not possible.
An i386 binary which would run on all i386-compatible processors (although not as fast as the more advanced models) was unfortunately unavailable in RedHat's contrib directory. By the time you have this book, KLyX 1.0 will probably be completed - then, at the latest, you should find an appropriate i386 package in contrib directory. Maybe RedHat will even decide to incorporate the program into the 6.0 Powertools, which were also unavailable at the time of writing.

# XEmacs

This alternative to GNU Emacs is subdivided into four packages. Normally you only need emacs (the program files) and emacs-info (the corresponding documentation), emacs-el contains the Emacs Lisp text of the countless Emacs extensions and is of interest only to programmers. emacs-extras contains some files that are shared between GNU Emacs and XEmacs. This package can only be installed if the GNU Emacs is not installed.

```
# rpm -i /cdrom/contrib/emacs-20.4-4.1386.rpm
# rpm -i /cdrom/contrib/emacs-info-20.4-4.1386.rpm
```

xv

xv is a graphics program. Please note that it is shareware. The program may be employed free of charge only for private purposes. Commercial application is subject to registration. Please read the copyright information (button ABOUT XV)!

```
# rpm -i /cdrom/contrib/xv-3.10a-13+flmask.1386.rpm
```
