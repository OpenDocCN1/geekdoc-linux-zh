# X FONTS 251

The font naming conventions are described in the content of the Gimp command on page 678. A list of all available fonts can be generated by means of xlsfonts. You can, however, also use the more user-friendly programs fontsel and fontmanager (KDE).

To enable Free86 to find the font files, the paths to the font directories must be listed in the Files section of XF86Config (This section also contains the path to a file with names of the RGB colors, which are, of no interest here.)

# # Excerpt from XF86Config

Section "Fonts"

+   - RGBPath "/usr/X116/lib/X11/rgb"
- FontPath "/usr/X116/lib/X11/fonts/misc:unscaled"
- FontPath "/usr/X116/lib/X11/fonts/75dpi:unscaled"
- FontPath "/usr/X116/lib/X11/fonts/100dpi:unscaled"
- FontPath "/usr/X116/lib/X11/fonts/URW"
- FontPath "/usr/X116/lib/X11/fonts/freefont"
- FontPath "/usr/X116/lib/X11/fonts/Type1"
- FontPath "/usr/X116/lib/X11/fonts/Speedo"
- FontPath "/usr/X116/lib/X11/fonts/misc"
- FontPath "/usr/X116/lib/X11/fonts/75dpi"
- FontPath "/opt/StarOffice40/fonts/type1"

EndSection

The keyword unscaled means that, with all fonts of the directory in question, X does not attempt any scaling of its ones. This keyword can also be employed with non-scaled fonts. This leads to the effect that unscaled fonts can definitively only be used in the predefined sizes.

In the above font list, some paths are specified twice, the first time with the unscaled addition and later again without it. The consequence: when searching for a font in a specific size, X first tries a matching non-scaled bitmap standard font. If no matching font can be found, scaled fonts are considered as well. If this search fails, the makeshift solution is adopted to have the X server increase or reduce the size of a non-scaled font - with the unsatisfactory results mentioned earlier.

> The order of paths in XF86Config has a decisive influence on the display quality. When an X program requires a font without precise specification of all parameters, the first matching font is returned on the basis of the path order in XF86Config.(Only in exceptional cases does X programs really specify all parameters of a fonts - including the name of the manufacturer, and so on.) Therefore, unscaled fonts that can be displayed crisply in all sizes should appear at the beginning of the Files section.
