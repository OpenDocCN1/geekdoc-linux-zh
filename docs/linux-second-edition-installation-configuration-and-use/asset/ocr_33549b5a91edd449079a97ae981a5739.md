# GNOME

logview helps to keep a clear view of endless log files, gtop combines the functions of ps and top; the program displays information on running processes, their memory and CPU usage, and so on. It also allows you to terminate processes that got out of control.

The mini-programs cpu own.applet, cpusage.applet, diskusage.app-let and drivemount.applet display status on various system parameters in the GNOME panel.

ktop and kpm are KDE variations of gtop. kcpumon shows the CPU load as an icon in the KDE panel.

# 15.2 File managers

There is no shortage of file and program managers for X. This section, however lists only those that have stood the test of daily practice:

+   - mc: Midnight Commander, a professional program with color and mouse sup-port; its handling is similar to Norton Commander. The program is particularly suitable for use in a text console.
- tkdex: file manager written in the Tcl/Tk programming language; very pow-er and flexible; however, not part of all distributions.
- kfm, these two file managers are part of the KDE and GNOME projects, but can also be employed independently.

# Midnight Commander (mc)

The Midnight Commander is an easy-to-handle file management tool which strongly resembles the Norton Commander commonly used under DOS, but it is extended with a number of Unix-specific details (handling of links, modification of access rights, processing of ftp directories, and so on).

mc is menu driven. The program supports the mouse in text mode (gpm must be installed) and under X.

Two half-screen windows display the files of one directory. You can use either the mouse or Tab to switch between the two windows. The right button is used to highlight files, which can subsequently be deleted, moved or copied into the opposite window. Many commands can be executed with the mouse (menu) and with function keys (status line).

Obviously, you can also use the keyboard to select files: Ins selects/deselect and (on the numeric keypad) select/deselect a group of files under the cursor. In order to do this, you must specify a file name pattern (for example, *.bak).
