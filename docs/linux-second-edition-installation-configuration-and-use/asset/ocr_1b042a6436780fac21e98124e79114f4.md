# 18.5 Layout control

By and large, LaTeX carries out line and page breaking itself and achieves good results. There are, however, situations in which LaTeX fails. Sometimes (but not allways), LaTeX signals line breaking problems with warnings such as 'over-/underhbox/vbox'. This means that LaTeX has placed text outside the page margin or that big gaps occur in the text. The most probable cause of such errors is a long word which LaTeX has not identified any suitable hyphenation.

But when LaTeX does not use any warnings, you may be dissatisfied with the result - for example, when LaTeX has tried to use up all available space on a page and has placed one or two lines of a new paragraph at the bottom of the page even though, for the sake of clarity, starting a new page would have made much more sense. This section summarizes the most important commands that allow you to influence the line and page processing manually (that is, with additional commands).

# Hyphenation

LaTeX always hyphenates automatically. The hyphenation rules applied are surprisingly reliable, that it rarely happens that LaTeX produces a incorrectly hyphenation. More often, LaTeX does not find a suitable hyphenation point, so it leaves the word intact and then gets into trouble when breaking the line (with either big gaps or text that goes over the page margin). In these cases you can use \- insert so-called soft hyphens into the word in question. Then LaTeX hyphenates the word - if necessary - at one of the points specified by yourself.

Sometimes, the opposite problem arises - you want to avoid hyphenating (a maybe short) word. To prevent this, simply place the whole word in an \mbox{}.

# Influencing hyphenation

+   \- soft hyphenation
\mbox{word} not hyphenate the word

The LaTeX distributions TeX and LaTeX already contain built-in hyphenation languages for British English, American English, German and several other languages. German hyphenation, for example, would be activated with the german package.

# Word spacing and horizontal spacing

To justify the individual lines of a paragraph, LaTeX inserts the amount of space between all words (in one line), with a slightly wider space after a full stop (end of a sentence). If only a normal space is used after a full stop for example, after abbreviations), \{} must be specified after the full stop: Prof. \Huber for Prof. Huber. (stands for a space). When two words are not separated by a line break, a fixed space can be specified with \, for example, 3cm.
