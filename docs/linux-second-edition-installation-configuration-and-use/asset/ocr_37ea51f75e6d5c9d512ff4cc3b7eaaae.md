### 5.1.6 Sums and Integrals
Sum & integral signs are very often decorated with one or more sets of
limits 'which' are placed in LyX (as in TEX) as superscripts and subscripts
Sum will automatically place them above and below in display mode,
but will move them to the side when inline such as

```
$\sum_{i=1}^{n} x_i$
```

Integral signs, however, will not move the limits to directly over
and under the integral in display mode as $\int f(x)dx$.

```
$\int_{a}^{b} f(x)dx$
```

In many details, the handling of this program resembles a traditional text-
processing program. Most keyboard shortcuts — cursor movement, selecting and
copy of blocks, and so on – work in the same way as in Windows programs. (If
it irritates you, you may well select different keyboard assignments, for example
with a greater resemblance to Emacs.)

LyX distinguishes itself through a number of professional features:

+   - In the documents, use can be made of tables, images, mathematical formulas,
cross-references, and so forth.

+   - Input of mathematical formulas is supported by separate dialogs, symbol bars,
and so on, and is user-friendly.

+   - LyX helps with automatic generation of contents lists, indices, and list of fig-
ures.

+   - Provided the spell program is installed on the computer. LyX texts can be
easily checked for correct spelling.

+   - LyX supports multi-level undo. In regular intervals automatic
backup copies (with the file name #filename.LyX#) are created of all LyX files
that have been modified. The risk of unwanted lost data is very small.
