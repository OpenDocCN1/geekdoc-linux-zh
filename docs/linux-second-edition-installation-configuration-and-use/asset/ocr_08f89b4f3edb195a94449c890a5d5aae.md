# The configuration program x86config

xf86config is the text-based alternative to XF86Setup. The program is not excessively user-friendly, but usually leads to the desired goal. The settings are in principle the same as in XF86Setup — therefore, only some complementary details are described.

After monitor and graphics card setup, x86config prompts for identification and description strings. There is enough to thus accept the default names and strings. The sole purpose of these strings is to make your XF86Config somewhat more 'readable'.

After a request for confirmation, x86config carries out a start of the VGA driver with the option -probeonly. Here, X is not really started — only the pixel frequencies supported by the graphics cards are determined. However, the X trial does not work with all graphics cards. Therefore it is often sensible to skip this point

Now the configuration program proposes a list of graphics modes to choose from. The abbreviation bpp indicates the bits per pixel: 8 bits for 256 colors, 16 bits for 32768 or 65536 colors, and 24 bits for true color mode (2^24 colors). However, only a few Accelerated-VGA drivers support more than 256 colors. (The others simply ignore these settings in the configuration files.)

In most cases, the least can be as: Very high-resolution modes (for example 1280×1024 pixels), are automatically removed at the start of X if they are not supported by your graphics card or monitor.

After a final request for confirmation, the configuration program saves the configuration file just created. Make sure that the file is stored at the correct location (or copy the file to the location required for your distribution).

On the author's computer, x86config was in the most successful. Some additional work was required with the keyboard configuration. Also, the order of graphics modes in the Modes line had to be changed — x86config uses the lowest-resolution mode (640×480 points) as a default.

The x86config configuration program has the regrettable of filling the configuration file with countless additional sections which, in practice, are not needed at all. This, plus the countless comments make the configuration file longer and harder to read than necessary. Details on manual configuration follow from page 235 onward.

# The xxdune program

The xxdune program is not a configuration program, but a tool for optimizing an existing configuration file. (A KDE variation of xxdune, called kxdune, is currently under development.)

With xxdune, you can change size and position of the image for all modes (buttons PREV and NEXT). Changes in image position can be tested with TEST (where the old mode is restored after a few seconds) or permanently set with APPLY.
