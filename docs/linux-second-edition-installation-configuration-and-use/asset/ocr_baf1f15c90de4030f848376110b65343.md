The list for i can also be built with the same wildcard characters as for file names or with (...) constructions for the generation of character strings (page 397). In the following example, *.tex files are copied into *.tex files. (In Unix/Linux, the `~ character at the end of a file name uniquely identifies a backup file.)

```
user$ for i in *.tex; do cp $ $; done
```

If loops are constructed without in ..., the loop variable is passed all parameters passed at the call after the other (in practice, this corresponds to in $*). An example of such a loop can be found in the description of case.

# while loops

In the following example, the variable i is assigned the value 1. Then, in the body of the loop between do and done, the variable is incremented by 1 until the value 5 is exceeded. Please note that the conditions must be specified with the command test or its short notation with square brackets, just as if branches.

```
user$ i=1; while [ i -le 5 ]; do echo $; i=$[$i+1]; done
1
2
3
4
5
```

# until loops

The only difference between until loops and while loops is that the logical negation of the condition is formulated. Therefore, the following example is equivalent to the while loop above. i>5 (greater than), the -gt comparison operator is used.

```
user$ i=1; until [ $ -gt 5 ]; do echo $; i=$[$i+1]; done
1
2
3
4
5
```
