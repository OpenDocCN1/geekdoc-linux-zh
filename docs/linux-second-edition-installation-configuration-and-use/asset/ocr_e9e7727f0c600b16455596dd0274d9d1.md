# Emacs configuration and programming

The default settings of Emacs – from color layout to keyboard shortcuts – can be arbitrarily modified. Two methods are available: use of the menus and configuration masks for this purpose (that is, configuration with the mouse) or direct modification of the configuration file .emacs by means of an editor.

To enable you to exploit all the possibilities of .emacs, this chapter would need enough material to describe the Emacs-internal Lisp programming language together with all available extension functions and variables. This subject would provide enough to fill a whole book of its own! This chapter is only a very modest attempt to give a first, practice-oriented introduction.

Things are made even more difficult by the fact that the Lisp GNU Emacs and XEmacs are not fully compatible with each other and that both versions often provide different extension functions. However – if explicitly stated otherwise – the basic information contained in this chapter applies to both Emacs versions (GNU version 20.2, X version 20.4).
