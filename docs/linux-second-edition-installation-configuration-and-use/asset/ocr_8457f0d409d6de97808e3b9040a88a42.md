Starting with the current directory, the following find/grep command searches
the directory tree for shell programs, recognizing all files that are marked as
executable and contain the character string ##! sh. The list of all files is stored
in the home directory. Execution of this command takes some time because
the entire file system is searched.

```
user cd /
user find -type f -perm +111 -exec \ \
  > grep -q '#*.sh' \ ; -print > /list
```

# # Text conversion filters

On page 503, you find a description of the commands fromdos, todos and recode
which convert text files between DOS and Linux. If the only task is to eliminate a
carriage return character at the end of each line (DOS → Linux) or to insert it
→ DOS), you can obtain the same result by means of two small filters.

First, we will look at the conversion from DOS to Linux, in which all CR-
acters must be eliminated. This can be done by using the tr command.
This command reads data from the standard input, replaces or deletes charac-
ters and writes the result to the standard output. tr -d '\\r' removes superfluous
spaces. To make the code of doslinux as easy as possible, the following
program provides three application variations:

```
user doslinux file
user doslinux source.file target.file
user doslinux < source.file > target.file
```

In the first variation, dos2linux reads the file and writes the result
back to the same file. In the second variation, the source file is read and the result
is written to the target file. In the third variation, dos2linux is used as a filter. This
would also allow you to use the program in the following format:

```
user cat text.dos | dos2linux > /dev/lp1
```

The specified file is directed with cat to the standard output, filtered by
dos2linux and finally directed to the first parallel interface (printer).
The program code for dos2linux contains few surprises. The three syntax vari-
s are distinguished by the number of parameters. If more than three parameters
are passed, the command displays a help text. Text output is carried out by cat, us-
ing the << operator to interpret the text of the current as standard until the
pattern 'EOF' occurs.

```

# dos2linux: eliminates CR characters

tr -d ''
elif [ $ -eq 1 ]; then # process one file
mv $1.$
tr -d '' < $1$$ $1
```
