We conclude with a more practical example: the shell file savequit saves all *.tex files in the compressed archive file .tgz. If no errors occurred during creation of the archive file (operator &&), the resulting file is copied onto a diskette in drive A: The criterion for the if condition is the return value of mcopy. When everything goes well (and drive A does not contain a full diskette or contains no diskette at all), the computer is sequentially switched off with shutdown.

```
#! /bin/sh
# shell file savequit: save *.tex-files, switch off system

if tar -czf backup.tgz *.tex && mcopy -n backup.tgz a; then
shutdown -t 5 -h -q now
fi
```

The same program can also be arranged more clearly by specifying the tar and mcopy commands in a separate line. If the result of the two commands is checked with the aid of the variable $?

```
#! /bin/sh
# shell file savequit: save *.tex-files, switch off system

tar -czf backup.tgz *.tex && mcopy -n backup.tgz a:
if [ $? = 0 ]; then
shutdown -t 5 -h -q now
fi
```
