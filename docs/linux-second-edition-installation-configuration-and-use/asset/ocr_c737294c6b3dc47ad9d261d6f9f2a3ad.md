# If problems arise...

Before you begin the installation, please read the README files on the CD-ROM! These files are always up to date than the accompanying manuals or this book. Under Windows, you should use WRITE.EXE (Windows 3.1) or WORDPAD.EXE (Windows 9x and later) to read them. These programs, unlike NOTEPAD.EXE, can handle Unix text files that do not have the standard DOS CR/LF linefeed.
