-p carries out repairs (changes) in the file system without asking for confirmation.

-y answers all confirmation requests with y (yes), and carries out changes.

# grep [options] search.pattern file

grep searches the specified text files for a search pattern. Depending on the options used, the command subsequently displays the text passages or simply indicates how many lines the search pattern was found. grep can be combined to search all files that satisfy certain conditions.

+   -n displays not only the line containing the text, but also the n lines directly preceding and following the line.

+   -c shows the number of lines in which the search pattern has been found, but not the lines themselves.

+   -f file_name reads the options from the specified file (for complex or frequently used search patterns).

+   -i does not differentiate between upper and lower case spelling.

+   -l only displays the file names in which the search pattern has been found.

+   -q does not supply any on-screen display and merely returns the value 0 (search text found) or 1 (not found). This option is useful when grep is called by other programs (see the find example on page 454).

+   -w only finds whole words. With this option, the search pattern 'grey' would no longer be recognized in 'greyhound'.

# Structure of the search pattern

The search pattern generally consists of two components: the characters to search for and the number of times these characters may occur:

+   abc the character string 'abc'

+   [abc] one of the characters a, b or c

+   [^abc] none of the characters a, b or c (thus, an arbitrary different character)

+   [a-z] one of the characters between a and z
