# 2.5 Creating Linux partitions

One step that no distribution saves is the creation of new Linux partitions. This was the reason why we reduced the DOS partition – to free space for a Linux partition.) There are some differences between distributions with regard to ease of operation. Most of them require that you use the Linux program fdisk, which is extensively described in this section. Some distributions might give you the rather idiosyncratic handling of this program (for example RedHat and SuSE), but the decision of how many and which partitions you want to create remains with you.
