# Basic configuration

Next you need to specify the boot kernel for the finished system. This is a modular kernel, but what is important is that it includes all the parts needed for booting. Before SuSE presents several SCSI kernels for selection. Choose the kernel that matches your hard disk.

The question is to whether a boot diskette should be created absolutely answered with YES. As always, I strongly recommend against LILO installation because of the risks connected with this — you can always do this. (With a Windows 95 system, the chances that it will actually work are quite high for all distributions — anyway, the choice is yours...)

If your computer is not connected to a network, you can enter any arbitrary character string for computer and domain names. If nothing comes to mind, you can use myhost and myomain. In the TCP/IP configuration you will specify that you use the network in loopback mode (that is locally). In this case, you can do without any further configuration. The setup you can choose between several variations. The most sensible one is 'Name Server Access' (if example at a later stage you establish Internet access via PPP and to fetch email from your provider).

Now you need to enter a password for root twice. Selection of other forms is rarely sensible. Instead, it is useful to create a sample user. As a name, you can example, use suzy.

# X configuration

At this point, the SuSE installation is finished and prompts you for login (first root, then the password). One point, however, is still open: the configuration of the XFree86 server. For this, you start vast and select the menu item ADMINISTRATION|XFree86.

Here you have a choice between three configurations: SaX (xf86config (a stone-age text-based tool), and xf86Setup (the standard configuration program of XFree86). At this point we only deal with SaX. Details on the other configuration programs together with a lot of background information can be found in Chapter 7. A clear statement on which is the 'best' configuration program is unfortunately impossible — depending on the hardware, sometimes and sometimes another program works.

Handling of SaX is very intuitive. The program tries to automatically recognize your hardware. Where this does not succeed, you need to supply the information yourself via mouse clicks. The program can also be controlled via the keyboard (Alt together with a key, Tab), which is particularly important if the mouse is not immediately recognized.

If you do not find your monitor in the list, click on EXPER and get the ratings of your monitor (horizontal and vertical frequency range) directly.
