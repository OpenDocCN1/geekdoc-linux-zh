# slrn

According to the RedHat package description, slrn is the best news reader on earth! Before you share this opinion, you have to take a little time to get used to it. The great features are hidden behind an unyielding interface, even in the age of KDE Gnome gone without icons. It should suffice for a first approach.

Up-to-date information on slrn, including a very helpful collection of FAQs, can be found on the Internet:
http://space.mit.edu/~davis/slrn

# Start

Independently of whether the program is used for accessing a local server or an extremal server over the Internet, the server name must be set in the environment variable NNTPSERVER. Alternatively, the name can also be specified with -h. (The server name for the sample user from page 305 is news.provider.de If you use leafnode (described on page 380) for your local news server, the server name is simply locally.)

In order to start slrn, either .newsrc or .newsrc must be located in the home directory. If neither is the case (because so far no other news client has used), slrn issues an error message.

```
hofer slrn
rn 0.9.5.2 (Dec 11 1998 21:07:03)
Reading startup file /var/lib/slrn/slrn.rc.
Unable to open /home/hofer/.jnewsrc. I will try .newsrc.
slrn fatal error: Unable to open /home/hofer/.jnewsrc.
```

This problem is easily remedied. Try again, and this time you use the following options:

```
hofer slrn -f ~/.newsrc-create
srn 0.9.5.2 (Dec 11 1998 21:07:03)
Reading startup file /var/lib/slrn/slrn.rc.
Connecting to host localhost...
Connected to host. Posting Ok.
--The next step may take a while if the NNTP connection is slow---
Creating /home/hofer/.newsrc........
```

Reading the list of all stored newsgroups may take some time - but this is only needed at the first start-up.

slrn now shows a (still empty) list of all subscribed newsgroups. To display groups - including the ones you have not yet subscribed to - enter Shift+*
Instead of *, you can enter any pattern, such as *.os. for all newsgroups involving operating systems.

Depending on which server or your Internet provider are using, Shift+L may not work: no groups are displayed. This is particularly likely if you use leafnode as a news server. Quit strn with Q, and use an editor to insert the following line into the configuration file ~/.strnrc:

```
set read.active 1
```

As you see the list of groups, you can subscribe to the required groups-with S, U cancels the subscription. If you now execute Shift+L a second time, only the subscribed groups are displayed.

# Usage

To read the news of a group, you select the group with the cursor keys and press -> Now strn displays a list of all articles out of which you can select the required article, again using the cursor keys and <-

In the text window appearing on screen, you can scroll with Spacebar and With H and Z view/hide the news text or the news list. Further commands can be found in the following table:

# strn keyboard shortcuts

- Q quit current view or strn
- ? online help
- C mark all articles as 'read' (catchup)
- Esc, U mark all articles as 'unread' (uncatchup)
- Spacebar scroll news forward
- H view/hide news text
- Z view/hide news list
- F send reply (follow up) to an article as news text to the newsgroup
- R send reply (reply) to an article as email directly to the author
- Shift+P write new article (post)

# Group list

- S subscribe to groups
- U cancel subscription to a group (unsubscribe)
- Shift+L display all groups or only subscribed groups

# Configuration

Appearance, operation and functional extent of strn can be extensively modifi-
tied by the configuration file /.strnrc. Setting options and syntax are
documented in the accompanying example file strnrc (usually in the directory
var/lib/strn).

Sender's address

strn normally employs the user name, host name, and domain name to build the
s's address. In an offline configuration, this is rarely a good solution:
rather, the email address of the Internet account should be used. The following lines
in .strnrc set up the following sender's address: hofer@provider.de (for the
sample user Hofer).

```
username "hofer"
hostname "provider.de"
realname "sample user Hofer"
```

The address of the sender will be entered correctly in all news articles, but it
is not valid for the REPLY command with which you send an email
to the author of a news article. In the current version of strn, it seems to be
impossible to influence the sender's address. As is customary to
Unix, the email address is made out of login name, host name, and
domain name. Only sendmail configuration may potentially be able to solve the
problem.

# Editor

strn has no editor of its own and starts vi as a default editor. You can prevent this by
setting the EDITOR or VISUAL environment variables appropriately.

# Colors

The preset colors of strn occasionally make it impossible to read the text. A slight modification works wonders: the following line headings (in the help text too) to be displayed in blue on a white background.

color headers blue

# Mouse control

With the following line, many functions of strn can be controlled via the mouse:

```
set mouse 1
```

Besides menu control and selection of groups or individual news articles, there are a number of not obvious mouse shortcuts.

# strn mouse shortcuts

In the 'News Group' status line:

- Left button scroll list forward
- Right button scroll list backward
- Middle button close list view

In the article status line:

- Left button jump to the next unread news article
- Right button jump to the previous unread news article
- Middle button view/hide quoted text (> > text)

In the article text:

- Left button scroll text forward
- Right button scroll text backward
- Middle button close text view

# tin

tin is a handy program which may leave you with a rather meager first impression, but which is actually much more efficient in its handling than some other programs (such as Netscape). With strn: do not be deterred by the very simple interface!

# Start

Just like strn, tin too evaluates the contents of the environment variable NNTPSERVER or the file /etc/ntpserver, where the name of the news server must be specified (for example localhost or news.provider.de). Alternatively, the server name can be specified with the option -g.
