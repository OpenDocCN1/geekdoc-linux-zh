# 5.5 Process administration

```
/proc/sys/*      system and kernel information
/proc/version    kernel version
```

We will not go into detail at this point. But you need to know that the /proc directory occupies no storage space on the hard disk, since it is simply a mapping of operating system internal data. The same applies to the very large file /proc/kore, which maps the RAM.

proc files are partly in text format. (In fact, they are not 'true' files. less is, in many respects, far better than can do and more, but it is also more restrictive about permitted data formats.)

Linux is a multitasking system, that is, several (processes, tasks) can be executed at the same time. "Almost", in this context, means that the processes are not actually carried out simultaneously (this would require several parallel computers or at least processors). The programs are each assigned some CPU time (fractions of seconds) in turn. Thus, each program runs more slowly, but without visible interruptions.

Currently running processes can easily be seen with the ps command, using the -x option (To execute this command, you should be logged in as root otherwise, the only displayed processes are the ones you started.)
