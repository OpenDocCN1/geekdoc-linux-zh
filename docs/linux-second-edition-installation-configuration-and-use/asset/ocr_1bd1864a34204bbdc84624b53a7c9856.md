# The configuration process

The aim of the following explanations is to achieve a flicker-free monitor image of the highest possible resolution. Further details of X configuration (X resources, window manager configuration) are the subject of later sections from page 260 onwards.

The central configuration file for XFree86 is XFree86.config. This file contains all the relevant data relating to your graphics card and monitor in text format. To modify this file, you must log in as root.

Unfortunately, depending on the distribution, XFree86Config is found in different locations (/usr/X11R/Lib/X11/XFree86config is usually only a link somewhere to the /etc directory).

+   - /etc/X11/XFree86Config
- /etc/XFree86Config SuSE
- /usr/X11R6/Lib/X11/XFree86Config XFree86 default

Depending on the distribution, a whole palette of programs is there to help you with the creation of XFree86Config:

xvidtune page 234
Xconfigurator (RedHat) page 725
sax (SUSE) page 740 |

Independently of which configuration program you use, you will often have to retouch the configuration file manually — more on this page 235 onwards.

> CAUTION Never use an XFree86 configuration file borrowed from a friend or a colleague, downloaded over the Internet or obtained from somewhere else without adapting the monitor section to the data of your monitor first (see below) — otherwise you risk the premature demise of your monitor!
