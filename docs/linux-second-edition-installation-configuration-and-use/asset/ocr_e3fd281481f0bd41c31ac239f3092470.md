A central feature of LyX is that text input is integrated into the program. Although the LyX text editor is excellent, Emacs fans (such as the author of this book) will likely miss their macros.

# Other limitations

Obviously, LyX documents can be exported into LaTeX without problems other than LyX being simply a sort of user interface for LaTeX. Since version 1.0 the opposite, that is, import of LaTeX files into LyX, is also possible, although frequently a cause of problems. The reverse command is FILE | IMPORT. The file to be imported must, however, be a complete LaTeX document (not part of a group of several files) and should preferably not use any LaTeX features not available under LyX. Even if these conditions are met, import not always works satisfactorily.

Behind the scenes, import is handled by the Perl script relx which, which is extremely well documented by a man text.

A further disadvantage is the fact that LyX documents cannot be subdivided into several smaller files without some difficulty.

# LyX versus Kly

Currently, there are two LyX versions which differ manj from each other in their user interfaces. The standard version (that is LyX) is based on the Forms library, whereas Kly uses the Qt library. Kly is therefore particularly suitable for integration into a KDE system and gives a slightly more contemporary impression. Another decidedly useful feature is the possibility of opening several windows and splitting windows. Thus the (partial) windows can be used to display several documents and/or sections of a long document.
