A large number of additional special characters is possible in mathematical mode - for example, $\pi$ with $\|$ or $\leftarrow$. A summary of the most important mathematical symbols is given in Section 18.4.

An alternative of representing text containing special characters is provided by the command \verb_text_, \verb_ls | more_yield ls |. In this example, the underscore character was used to enclose the text itself, but you can use any other character provided that it does not occur in the text to be represented. The text inside of \verb is set in typewriter font. \verb cannot be limited in a number of environments and certainly not for the definition of macros. \verb texts are limited to a maximum of one line. There is no way of representing \verb text in bold face.

When you do not wish to represent just a few characters, but want to represent several lines, you can use the \begin{verbatim} environment and terminated with \end{verbatim}. All lines between are set unchanged in the typewriter font. The verbatim environment is particularly suited for program listings, which are usually strewn with special characters.

```
verbatim environment
\verb_text sets the text including all special characters
\begin{verbatim} starts text which is to be unchanged
multi-line text with ^^
special characters $ %    end of the verbatim environment
\end{verbatim}
```

Problems occur not only with special characters but sometimes also with spaces. For example, LATEX eliminates the space required after some commands.
