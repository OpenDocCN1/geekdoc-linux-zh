# knod device_file (bc) major_number minor_number

mknod creates a new device file. Usually, device files are located in /dev directory and are used to manage the hardware accessed under Linux (hard disks, interfaces, RAM, and so on). Device files are characterized by three items of information: the major and minor device numbers specify the driver with which the device can be accessed. The characters b c specify whether the device works buffered or unfiltered. Creation of new device files can only be carried out by root and assumes a basic knowledge of Linux internals.

A detailed description of all devices and the required device numbers can be found in the file /usr/src/linux/Documentation/devices.txt.

# Example

```
root # mknod /dev/sbpcd 25 0
```

creates a file for a CD-ROM drive of the types Matsushita, Panasonic and CreatLabs. (These rather obsolete first-generation CD-ROM drives are not addressed via the standardized EIDE interface, but via a proprietary interface).

# mkswap device/file

mkswap sets up a device (a hard disk partition) or a file as a swap area. mkswap can only be executed by root. In order to allow the newly created swap area to be used, it must be subsequently activated with swapon. Now, in case of insufficient RAM, Linux can swap memory into this area.

# label

label displays the name (volume label) of the MS-DOS diskette in the specified drive. Subsequently, you are asked to enter a new name and confirm with it

# mmd directory

mmd creates a new directory on an MS-DOS diskette.

# more file

more displays the contents of a text file by page. After each page, the display is interrupted, and more waits for keyboard input. The most important commands are (one line down), Spacebar (one page down) and Q (quit).
