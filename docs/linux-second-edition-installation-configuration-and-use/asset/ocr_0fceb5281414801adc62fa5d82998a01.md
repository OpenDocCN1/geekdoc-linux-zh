As mentioned earlier, LyX only provides complete WYSIWYG. If you want to know how your page layout will look like, you need to call up a page preview by means of FILE VIEW DVI or FILE POSTSCRIPT. The difference between the two variations consists in the fact that in the first case, only a temporary *.dvi is created, while in the second case, this temporary file is used to create a PostScript file. The contents of the two files – with regard to the page layout – are identical; however, different programs are used for display (xdvi/ghostview with LyX or kdvi/ghostview with lyx).

The variation you choose of the two available is a matter of taste. The DVI variation is somewhat faster. However, if you use a large number of illustrations, you will probably prefer the PostScript variation.

The first display of a LyX document – no matter whether DVI or in PostScript format – may take some time while LaTeX sets of the required sizes are created. However, this delay occurs the first time (or precisely, every time you use a new character shape (font) or size for the first time).

You need not restart xdvi or ghostview for each page preview. Instead, you can use the commands FILE UPDATE DVI or FILE POSTSCRIPT, which only update the current preview files. xdvi recognizes the changes automatically, while with ghostview you need to press R (for reload) to cause the file to be read again.

The quality of font display in ghostview increases significantly if you activate the antialiasing function (see page 518).

LyX documents cause no problems, provided that the printer configuration was carried out correctly (see page 162). With PRINT, LyX generates the same PostScript file as the page preview and passes it to the default printer lbpy means of lyr.

# Paragraph formatting

In most cases, you will use the list field at the left-hand side of the symbol to change the format of one or more selected paragraphs. The choice of available format types depends on the selected document class (LAYOUT|DOCUMENT, see below).
