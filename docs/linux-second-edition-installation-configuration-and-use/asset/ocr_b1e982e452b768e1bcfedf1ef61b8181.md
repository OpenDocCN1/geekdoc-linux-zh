# A minimalistic X Glossary

# X Window System

The X Window System (X for short) is basically a collection of functions to draw points, rectangles, and so on, on a screen. X also includes a network protocol that allows you to execute an program on computer A and display the results (via a network) on computer B. The current version is X11R6.1, but most Linux distributions use X11R6. The X Window System was developed at MIT (Massachusetts Institute of Technology).

# X server

The X server is the interface between the X Window System and the hardware (graphics card, mouse). the most commonly used servers Linux are the XFree86 server and the commercial servers MetroX and AcceleratedX.

XFree86 is part of X11R6 and rppresents a free port of the X system for computers with Intel 386 and compatibles. XFree86 has been developed by the XFree86 Project, Inc. (The XFree86 Project, Inc., c/o AIB Software Corporation, 1145 Heron Parkway, Suite 200, Herndon, VA 22070, USA. Email: XFree86@ XFree86.org). The best feature of XFree86 is the support of countless graphics cards. XFree86 is not available for Linux, but also for other Unix systems. The current version (January 1999) is 3.3.3.1.

> If you are interested in the history of XFree86, you should read the XFree86 chapter of the Linux User Manual (see References).

# Virtual screen

The X server is capable of managing a virtual screen that is larger than the section actually visible on monitor. Usually, the virtual screen is set to at least 1024×768 points, if the monitor can only display 800×600 points flicker free. Scrolling of the visible section is immediate, as soon as you move the mouse to the edge of the screen.

# Window manager
