# LaTeX $ightarrow$ HTML

In principle, latex2html works the same way as tex2html; The Perl script generates one or more *.html files from one LaTeX file. Formulae and LaTeX special characters are translated into *.gif images — this, however, assumes the presence of the large graphics package netbm.

Usually, the application of latex2html is not as easy as tex2html; on the one hand, the computing power requirements (CPU, RAM) are huge, and on the other, the conversion achieves the desired outcome if and only not LaTeX standard commands have been used (not various self-defined macros, additional packages, and so on). For this reason, the attempt to convert this book into *.html failed miserably. For simpler texts, the conversion works perfectly. The program is mainly used to convert scientific publications in LaTeX in a WWW-usable form.

# Man $ightarrow$ HTML

rman (short for RosettaMan) converts formatted pages into other formats (ASCII, HTML, SGML, LaTeX and so on). The special feature of rman is that it does not have to start from the source text for man, but can copy with the already formatted man pages themselves. rman can, like info2www, also be employed in cgi scripts. The help system of the SuSE uses rman to convert man into HTML texts on demand.

The following example shows the use of rman the man page is converted into HTML format and written to the file ls.html.

```
user rman -f html /var/catman/cat/ls.1 > ls.html
```

# Linuxdoc-SGML

While the programs described above are to convert 'old' online documentation into a new format, the Linuxdoc-SGML software package has been created from the start with the process of generating files in different formats (ASCII, HTML, PostScript) from one and the same source text. Texts are entered as SGML documents (SGML stands for Standard Generalized Markup Language and has a similar syntax to the WWW language). SGML texts can then be converted into different formats by means of sg2txt, sgml2, and so on. Anyway HOW HTML and many other Linux documents have been written using Linuxdoc-SGML.

# HTML $ightarrow$ PS

If you want to print an HTML file, you can use a Web Browser (for example Netscape). However, for automatic conversion from HTML into PostScript format, the Perl script html2ps is far better. Its handling is very easy; html2ps -D name.html > name.ps. The option -D causes html2ps to insert DSC-comment info into the PostScript file, which facilitates its further processing. If HTML is not part of your distribution, you can find the converter on the Internet:

```
http://www.tdb.uu.se/~jan/html2ps.html
```
