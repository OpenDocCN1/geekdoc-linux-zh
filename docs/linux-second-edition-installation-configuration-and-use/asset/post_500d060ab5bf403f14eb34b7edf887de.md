## Emacs in the text console

This chapter assumes that you are using Emacs under X. However, both Emacs can also be started in a text console, although certain restrictions apply: no menu, no tool bar, no scroll bar, no character attributes (bold, italic) in syntax-lighting, and so on.

Some key combinations may well fail (for example [Alt-]). If problems occur, you need to work with [Esc] (see the above hint), modify the keyboard table (see page 135) or change .emacs accordingly (page 578).

Problems usually arise with the mouse; it can be normally used only under X. If you use the gpm program installed, you can at least use the mouse in text mode for copying and inserting selected text (see page 141). Emacs recognizes gpm automatically, so the mouse can be used for cursor positioning. In GNU Emacs, the following lines provide more mouse handling facilities:

```lisp
+ ; Addition to .emacs
(or window-system
(progn "t-mouse" 1))) only in text mode
gpm mouse routines under X
```

Under X you cannot use the user interface of Emacs and execute the program directly in a shell window. (This may be sensible when the program runs on a remote computer and only a slow network connection is available.) If you execute Emacs in xterm, you can go on using the mouse: simply execute [Esc] xterm-mouse-mode.

## 16.3 Online help

Emacs provides a number of commands to call online help. The most important one (for getting started) is F, T (tutorial), Ctrl+X, B, takes you back to the original text.

If, after the execution of a help command, several text passages (windows) remain on screen, you can use Ctrl+X, O ('o') to place the text cursor inside the next window. Ctrl+X, Z ('zero') removes the window, Ctrl+X, T deletes all windows but the current one. Thus, you can use three commands to toggle between help and windows and finally remove the help altogether.

If the help text is displayed in such a way as take up the whole page, you can use Ctrl+X, B to switch back to your original text. (Internally, the management of several texts – such as, for example, your text and the help text – is realized by means of so-called buffers. You can find out more about buffers and windows on page 557.)

## Using online documentation

- F1, overview of available help commands
- F1, A text overview of all commands text (apropos)
- F1, B overview of all keyboard shortcuts (bindings)
- F1, C shortcut brief description of the associated command
- F1, command brief description of the command (function)
- Shift+F Emacs FAQ (Frequently Asked Questions)
- F1, I starts the info system for the display of hierarchical help texts (for usage page 74)
- F1, N summary of new features in the current version in contrast to previous versions
- F1, T introduction to Emacs (help tutorial)
- F1, Ctrl+G name starts the info system and displays information on the specified command
- F1, Ctrl+P information on the concept of free software

The most important source of information about Emacs is the internal info system which is officially looked upon as the Emacs manual. In some distributions, this manual is also supplied in HTML format which allows even easier reading.

In GNU Emacs versions prior to 19.29 you must press the Ctrl+H combination instead of F1. Further information on GNU and XEm can also be found on the Internet.

## Keyboard shortcut reference

The Tex file ref.tex contains a table with the keyboard shortcuts of the important Emacs commands, it is located in the Emacs etc directory (/usr/share/emacs/20.2/etc/). If you have an installation of TeX and a PostScript printer, you should carry out the following instructions:

- Load the file ref.tex into Emacs and change the line \columnspage=1..=3. Save the file.
- Use the file to generate a DVI file: tex refcard
- Convert the DVI file into a PostScript file: dvips refcard -o test.ps -t landscape
- Print the file with lpr test.ps. (Information on correct printer configuration can be found on page 163.)

The result is a two-page printout pages contain three columns nearly all relevant Emacs commands (in landscape format). The commands are ordered by subject (for example, Files, Getting Help, Error Recovery, and so on). Those two pages are constantly somewhere on my desk and are my most important reference source for Emacs!

A further source of information is the Emacs man page. However, it only details of command options and the setting of X default values for colors, character actor sets, and so on.

## The Info mode

The built-in Emacs online help is stored in the GNU Info format (see page 74). For reading Info texts, Emacs activates a special Info mode. In this mode, some special shortcuts apply which are described on page 75. You can follow cross-references and menu entries by simply clicking the middle mouse button. L takes you back to the last page viewed.

## 16.4 Cursor movement

The most important combinations for cursor movement have already been introduced in the previous section: the four cursor keys PgUp and PgDn. Apart from these, there is a choice of other commands:

| Cursor movement | |
|---|---|
| Alt+F / Alt+B | cursor one word forward / backward |
| Ctrl+A / Ctrl+E | cursor to beginning / end of line |
| Alt+A / Alt+E | cursor to beginning / end of paragraph |
| Alt+V / Ctrl+V | text page up / down |

## MARKING, DELETING AND INSERTING TEXT

```
Alt+< / Alt+> cursor to beginning / end of text
Ctrl+L scroll text so that cursor remains in center
Alt+G n-> move to line
```

If you want to know which line you are currently working on, you can enter Alt+X line-number-> Emacs displays the current line number in the bottom line of screen. It may be even easier to activate a permanent line number with Alt+X line-number-> Unfortunately, this display stops functioning with very long texts (of more than one Mbyte).

First, you enter Alt-> where n is an arbitrary number in the alphanumeric part of the keyboard (not on the numeric keypad on the right-side). During the input of the numbers you must keep the Alt key pressed. Subsequently, you enter a command – for example, Pgn. This causes Emacs to scroll the text down by n pages. This process can be used for all Emacs commands (including the input of characters).

## Saving cursor positions in registers

In a longer text it is often desirable to jump quickly back and forth between different places for the text. For this purpose, the cursor position can be stored in a so called register. A register is a memory location which is identified by a text character (letter or digit). At a later point in time, this register can be used to jump back to the originally saved position. Note: Registers are not saved when quitting Emacs.

| Cursor position registers | |
|---|---|
| Ctrl+X Spacebar char-> store current cursor position in char register |
| Ctrl+X R J char-> jump to cursor position stored in char register |

## 16.5 Marking, deleting and inserting text

You have already met Del or Ctrl+D for the deletion of single characters. Emacs can also delete larger amounts of text:

 Deleting and inserting text

| Alt+D deletes the following word or the rest of the word after the cursor position |
| Alt+-> deletes the previous word or the beginning of the word up to the cursor position |
