would be a good idea to define a new command, lt (list time), which fulfils exactly this task.

To do this, you start your favorite editor and write the file lt. For the time being, this file consists of only one line, name Is -ltr. Enter these characters, save the file and quit the editor.

If you do not wish to call the editor, you can create the file with cat: enter the command cat > lt. Now, the command expects to receive data from the standard input (keyboard) and writes it into the file. Thus, enter -ltr and then terminate cat with Ctrl+D (this corresponds to EOF, end of file). You can view the resulting file with cat.

The attempt to execute the newly created file results in the error message 'permission denied'. The reason is that the access bits (x) for file execution are generally deactivated for newly created files. However, you can change this immediately with chmod. Now, lt supplies the required list of files ordered by last modification date. (The following lines show only a small part of this list):

```
user$ lt
bash: ./lt: Permission denied
user$ ls -lt
-rw-r-- 1 user mk 8 Oct 20 10:47 lt
user$ chmod +x lt
user$ lt
...
-rw-r-- 1 user mk 112088 Oct 20 09:28 bash.txt
-rw-r-- 1 user mk 74126 Oct 20 09:28 grundl.txt
-rwxr-xr-x 1 user mk 8 Oct 20 10:47 lt
```

When the variable PATH does not contain the current directory '.', you can execute lt only by means of the command ./lt. Generally, only those programs can be executed that are contained in a directory specified in PATH or whose path is specified completely and uniquely.

However, the new command has not turned out particularly well; it ignores all parameters specified in the call. Thus, lt *.txt does not display a sorted list of all *.files, but again a list of all files.

This limitation can be easily removed. The variable $ predefined inside the bash contains all parameters specified in the call of a shell code in lt is changed into ls -ltr $, the bash passes all parameters specified with the call of lt to ls. (An overview of predefined bash variables can be found on page 411).

In order to make the example more interesting, the new command will be extended to display an info line at the end of the file list which indicates how many files have been displayed and what their total use of disk space is. Furthermore, tee is used to redirect the contents list into a temporary file in addition to its being displayed on screen.
