# 17.2 Configuration via mouse click

One of the most attractive Emacs innovations in recent years is the new, user-friendly possibility of modifying countless default settings via mouse click. To do this, you simply execute Alt+X customize-browse. Subsequently, Emacs displays a hierarchical menu which can be controlled with the middle mouse button. When you navigate through this menu, you will quickly get an idea of the number of configuration possibilities.

When you click on one of the icons, the corresponding option, together with a brief help text, is displayed in a second window where it can be changed. GNU Emacs, mouse operations must always be carried out with the middle mouse button; whereas XEmacs you may in some cases use the left mouse button as well.

Changes only take effect when you click the SET button. However, the changes now only apply to the currently running program. If you want to store the changes permanently, you must click SAVE – and for each and every change you made. The settings are stored in the file .emacs.

customize-browse is available in both GNU Emacs and XEmacs. In XEmacs, however, menu and configuration options are presented in a visually more appealing and clearer way. In its current version, GNU Emacs still does without icons and represents the same information as ASCII text. The settings stored in .emacs-automatically apply to both Emacs versions (GNU and XEmacs).
