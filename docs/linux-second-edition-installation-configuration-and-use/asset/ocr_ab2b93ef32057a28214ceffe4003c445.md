# SCSI low-level drivers

Here, a number of SCSI cards is listed. Find your card and select the corresponding option (and not over!) with YES, if your root file system is located on a SCSI disk. Also, the driver for ZIP drives on the parallel interface is part of the SCSI low-level components.

# Network device support

If you want to communicate with another computer in any form whatsoever, this is the place to select YES. Also if your computer is only to be connected to the Internet via PPP/SLIP. Dummy support is often needed for SLIP or PPP configuration. In kernel 2.2.preac4 this option was to be found in the Arcnet group - but this will hopefully be remedied.)

PLIP allows data exchange via the parallel port (a reasonable choice only in very rare cases); printer access is then no longer possible. PPP and SLIP are two variations to exchange access via the serial interface. If you do not know which Internet provider provides (probably PPP), simply select both. In kernel 2.2.preac4 these options were to be found in the Appletalk group - but this will hopefully be remedied.

# Xy network devices

You need to set the appropriate options to YES or MODULE, if you want a corresponding card. The popular NE-200-compatible cards belong to the subgroup Other ISA cards of the Ethernet (10 or 100 Mbits) group. The PCI version of this card can be found in the subgroup EISA, PCI and onboard controllers. Do not activate a network card that you do not have!

# CD-ROM drivers

In most cases you will not have to select any option, even if you possess a CD-ROM drive. Here, only CD-ROM drives are listed that have their own interface. Most of the common CD-ROM drives, however, are IDE (block devices) or SCSI drives (see SCSI support).
