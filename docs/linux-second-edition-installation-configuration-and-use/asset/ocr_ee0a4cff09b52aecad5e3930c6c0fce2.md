# KDE 283

When you move windows, they 'magically' snap to the borders of the desktop
as well as to the borders of other windows. The extent of the span zones be
modified in the DESKTOP|DESKTOP dialog. (O switches the snap function off.)

# Window title animation

If the window is too narrow to display the window title, the window title moves
the title line like in a newsflash. This more irritating than useful animation can be
itched off in WINDOWS|TITLEBAR.

# Screen saver

KDE contains a whole palette of screen savers. The configuration is carried out in
DESKTOP|SCREENAVER.

Further configuration options will be described in the following sections.

# The KDE panel

The panel (KPanel for short) is the central control component of KDE. It assist
starting with programs, switching between running programs, switching between
desktops, and so on. In the default configuration, KPanel is displayed at the
bottom of the screen; buttons with a list of all running programs (comparable to the
Windows taskbar) are at the top of the screen (see Figure 8.5).

The two most important icons of KPanel are the three-dimensional letter K,
which leads to the KDE start menu, and the window icon which permits easy switch-
between running programs. (The contents of this menu are also dis-
play via [Ctrl|Esc] or after clicking the mouse button on the desktop.)

The remaining preconfigured icons are used for starting various KDE programs
(file manager, help system, and so on) and save the laborious navigation through
the levels of the start menu. Finally, the letter X for shutdown of KDE and the
padlock icon for temporary locking of the screen are important. (Work in KDE can
only be continued after entering the login password. Until then, a screen saver is
activated.

# Panel configuration

Options for the look of the panel can be set via the context menu as well as via
APPLICATIONS|PANEL in the KDE control center. There, together with other items,
t panel and taskbar positions can be determined (top, bottom, or left). The taskbar
also be made visible. (To switch between running programs, the WINDOWLIST
panel or various mouse or keyboard shortcuts can be used.)

Now to the contents of the panel: the displayed icons can be moved with the
m mouse button. With the right mouse button, you can call a context menu. The
commands can also alter the properties of the entry. The form can be modified
on the dialog sheet EXECUTE by clicking on the square icon buttons. This triggers
d display of an almost endless list of premanufactured KDE icons. (As long as no
icon is set, the icon button is displayed as an empty, gray surface.)
