A more positive aspect is that KDE and GNOME have noticeably inspired the development of new application programs. Even if it may appear strange that the double-track desktop situation is to be followed by GNOME and KDE office packages – if some of these components can be developed to a state of general usability, much will be gained.

In this book, application programs – irrespective of whether they have been specially optimized for a particular desktop system – are described in the appropriate chapters (for example all Internet tools in the Internet Chapters 9 and 10). A description of various X tools and utilities can be found in Chapter 15. This chapter only describes the basic functions of fwwm, KDE and GNOME.

# Problems

There only remains to be said that the new desktop systems have their teething troubles. The first big difficulty occurs when you try to install additional programs that have not been supplied with the respective distribution. This virtually works! Either the required libraries are missing completely or they are too old. Any attempt to install a new library will fail because of package dependencies or will cause incompatibility with programs that have worked so far. For the moment, average Linux user has virtually no chance of getting a new KDE or GNOME program which has been downloaded from the Internet and running quickly by him or herself.

A second problem is a lack of stability. KDE and GNOME were developed at incredible speed. The logical consequence is that the many new programs do not yet have the same stability as their predecessors who stood the test of time.

And that is not all: the beautiful icons and marvellous features obviously cost memory space and CPU performance. Working with KDE and GNOME is only really enjoyable on a powerful computer. If this is not available, fvwm is certainly the better choice.

So not be dazzled by the beautiful, new, and colorful world under Linux: however great the prospect of Linux distributions offering for the first time (and not less) of operation from Microsoft Windows may be, there is currently chaos with almost daily changing versions, libraries, and so on.
