Essentially, lyx-code corresponds to the verbatim environment of LaTeX. The advantage: inside the environment, font attributes can be changed (for example, bold
or italic type). The disadvantage: the listings are indented, but the amount of indent-cannot be changed. Furthermore, empty lines are not accepted. (Remedy: simply
enter a space in an empty line, or `Ctrl+—`).

In the LAYOUT PARAGRAPH dialog you will search in for some frequently needed formatting features. If, for example, you want to change the
space between two paragraphs or the line spacing inside a paragraph, you
to make these modifications globally in the LAYOUT DOCUMENT dialog (see
below).

If you want to have two paragraphs follow each other without vertical spacing,
ents, and so on, you should use `Ctrl+—` in stead of the style—
separate them. (In LaTeX this corresponds to the command `\`).

With `Ctrl+Shift+C`, you can copy the paragraph layout of the current-paragraph. With `Ctrl+Shift+V`, you can apply this layout to another
paragraph. In this way, you can continue to apply previously defined settings
out great effort.

With `Alt+—`, you can split a paragraph into two parts, applying the same
old layout to both of the new paragraphs. (If you use simply
tnew paragraph will be of standard type).

If these defined format types are not sufficient, you can individually modify
t formatting of paragraphs by means of LAYOUT PARAGRAPH. This allows you
to change justification (ranged left, ranged right, centered, justified), to insert rules
ab or before the paragraph, to increment or reduce the distance from the preceding
or following paragraph, to force a page break before or after the end of the paragraph,
and so on. The MORE button takes you to a further dialog which allows you to set
paragraphs in minipage environments (see page 605).
