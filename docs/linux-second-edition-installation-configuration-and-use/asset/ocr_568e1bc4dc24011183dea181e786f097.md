# # 6.12 Package management (RPM)

Package management helps with the installation of additional packages and with updating or removing existing ones. This section describes the rpm command, which is used for this purpose in nearly all distributions.

# Preliminary remarks

RPM is not the only package format. Until recently, most distributions used compressed archives with the extension *.tgz (thus, TGZ format). The Slack distribution still employs this format. However, it has a number of shortcomings:

+   - It is extremely difficult to maintain an overview of the currently installed packages (and their versions).
- It is impossible to determine to which package a specific file belongs.
- Package updates are problematic (to put mildly). For example, an update will also overwrite configuration files, because the TGZ package has no information on files which serve purpose.
- Dependency information lacks completely. Thus, you can install a package X although the package Y needed for execution is missing.
