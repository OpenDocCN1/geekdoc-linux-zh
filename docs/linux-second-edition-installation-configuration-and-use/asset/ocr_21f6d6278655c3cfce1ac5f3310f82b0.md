# Installation and configuration

By now, many distributions supply leafnode as a preconfigured package (in RedHat you can find the program in the contrib directory which is often supplied on an additional CD-ROM. If not, you will need to download the fairly small package from a RedHat FTP server to your computer)

The information in this chapter refers to version 1.8, but should also be valid for version 1.6 and all versions after 1.8. (Leafnode 1.7 is defective and should not be used!) Please note that, depending on the distribution, the path of the leafnode binary files may vary (/usr/bin or /usr/local/bin or /usr/local/bin) Please check where binaries are located on your computer and use the correct path

# config

The configuration of Leafnode is carried out in the config file, which is normally located in /usr/lib/Leafnode/config or /etc/leafnode.
The most important setting in this file concerns the news server or news servers from which leafnode is supposed to read news articles. For the sample user from page 305, this is news.provider.de. The keyword expires for how many days unused news threads should be kept on the server. The default setting is 20
initialfetch specifies how many news articles are to be read the first time after subscribing to a newsgroup. If you do not set a limit, leafnode will transfer all available articles—and that may age!

maxfetch is valid for current operation. Each time leafnode searches for new articles a maximum of this number is transferred. If you only rarely (say, once a week) transfer news articles of a popular newspaper for example comp.os.unix.linux.misc, select a high value—otherwise your local news archive will be incomplete. Too high a value is also not a good idea—transfer of many news articles takes quite a long time. As a rule of thumb transfer of two news articles per second is a realistic value

```
# usr/lib/leafnode/config
server = news.provider.de
expire = 20
initialfetch = 500
maxfetch = 1000
```

These settings should be sufficient for your first experiments. The config file supplied with Leafnode is well commented, so that the setting of further options should not be a problem.

# /etc/ntpserver

This file specifies which server should be contacted by local clients. Since leafnode is now running on your computer, you will need to enter localhost.

# SNNTPSERVER

This environment variable is evaluated by some news clients and must therefore also be set to localhost. (In SuSE, you set NNTPSERVER in the file /etc/rc.config)
