# 8.3 fwm (Virtual Window Manager)

There are very good reasons why fwm is the standard window manager for nearly all Linux distributions. The program combines ease of use with low memory consumption. Its configuration possibilities are practically unlimited (keyboard shortcuts, menus, icons such as GoodStuff, and so on). Nobody needs to know any longer than the F in the abbreviation actually stands for – the text says ‘feeling’, ‘famous’, or ‘foobar’.

fwm is currently available in several versions. Version 1.2rn has the lowest memory consumption. Version 2.0 offers far more configuration possibilities, but of course the syntax of the configuration file has changed. fwm95 is a variation of fwm2.0. Its look and feel is surprisingly similar to that of Windows 95. fwm95 is described briefly from page 278 onward.
