# 16.3 Online help

Emacs provides a number of commands to call online help. The most important one (for getting started) is F, T (tutorial), Ctrl+X, B, takes you back to the original text.

If, after the execution of a help command, several text passages (windows) remain on screen, you can use Ctrl+X, O ('o') to place the text cursor inside the next window. Ctrl+X, Z ('zero') removes the window, Ctrl+X, T deletes all windows but the current one. Thus, you can use three commands to toggle between help and windows and finally remove the help altogether.

If the help text is displayed in such a way as take up the whole page, you can use Ctrl+X, B to switch back to your original text. (Internally, the management of several texts – such as, for example, your text and the help text – is realized by means of so-called buffers. You can find out more about buffers and windows on page 557.)

# Using online documentation

+   - F1, overview of available help commands
- F1, A text overview of all commands text (apropos)
- F1, B overview of all keyboard shortcuts (bindings)
- F1, C shortcut brief description of the associated command
- F1, command brief description of the command (function)
- Shift+F Emacs FAQ (Frequently Asked Questions)
- F1, I starts the info system for the display of hierarchical help texts (for usage page 74)
- F1, N summary of new features in the current version in contrast to previous versions
- F1, T introduction to Emacs (help tutorial)
- F1, Ctrl+G name starts the info system and displays information on the specified command
- F1, Ctrl+P information on the concept of free software

The most important source of information about Emacs is the internal info system which is officially looked upon as the Emacs manual. In some distributions, this manual is also supplied in HTML format which allows even easier reading.

In GNU Emacs versions prior to 19.29 you must press the Ctrl+H combination instead of F1. Further information on GNU and XEm can also be found on the Internet.
