# # seyon

seyon essentially carries out the same functions as minicom, but runs under X and is slightly easier to handle. The program is controlled through buttons which are for the most part labeled very clearly. (Some additional functions can be executed via the MISC button. There, for example, you will find the CAPTURE button. After clicking it, all input and output is written to the file ~/.seyon/capture – unfortunately strewn with special characters.)

Because of its easy handling, this section mainly concentrates on the correct configuration of seyon. Very extensive information about seyon can be obtained with man seyon or by clicking the HELP.

In general, seyon will run immediately, without long-winded configuration sets. You may have to specify the -modems /dev/ttySn option in the calling command to tell seyon which interface it uses for accessing the modem.
