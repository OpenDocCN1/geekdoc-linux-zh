Today, LaTeX and Metafon constitute an integrated package, each program being practically useless.

How does Metafon work? The starting point for all characters is the name.mf files. These text files contain commands for drawing the individual characters of a character set. Depending on the specified options, the Metafon program generates one or two; in case it generates a bitmap file name.nnpk and sometimes (if this file does not exist) the metrics name.tfm.

The bitmap files *.nnpk contain the character set in compressed form. The bitmap files, each letter is represented using thousands of dots (pixels), nn stands for a factor made up of the resolution in dpi (dots per inch) and the magnification. Typical dpi are 300 or 600 dpi for printers and 1270 or 2540 dpi for image sets. The magnification factor comes into play when a character set is set in a different size than the one in which it was developed (for example, for \small or \large). This results in values such as 720 (600 dpi 1.2).

The metrics files *.pk contain the size specifications of the individual characters. Even if several *.pk files exist for a given character set, there is always one metrics file (since the actual size of the characters depends on the printer resolution).

For now the real meaning of the file types: the metrics *.tfm are used by LaTeX while processing a text. From these, LaTeX extracts the information of how the individual letters are and uses this data to carry out line and page breaking. The result is a DVI file (device independent) which does not contain the actual character sets and can neither be printed nor displayed in this form.

The *.pk files are only needed for printing or for displaying the file on screen (xdvi). If the currently needed *.pk files does not exist in the screen/printer resolution and the required magnification, Metafon is started automatically. This can lead to considerable delays during the first printing of a text with many family types and sizes. The next time, however, the *.pk files will be readily available.

As a rule, you will not have to concern yourself with character sets and never have to start the Metafon program (command name mf). All required *.mf and *.tfm files are already preinstalled, and the *.nnpk files are automatically generated when needed.
