# X USER INTERFACES (FVWM, KDE, AND GNOME)

server: (The starting point for searching for packages is www.kde.org.) Please ensure that the packages of the default library correspond to your distribution (libc5 or glib alibc6, please use lib120!)

The basic package for KDE 1.1 consists of three packages: support, kdelibs, and kdebase. As well as these, there is a whole range of optional packages with additional programs (such as kde-games and kde-admin). Furthermore, for execution of KDE, you will need a package with the Qt library.

After you have installed these packages with the appropriate package manager (for example with rpm), you should execute ldconfig to find the Qt library. You should also add the path to the KDE binary files /opt/kde/bin to PATH. To do so, you need to change /etc/profile:

```
# Addition to /etc/profile
PATH=$PATH:/opt/kde/bin
```

This modification will only become valid at the next login. (In a console, you execute Ctrl+D and then log in.)

Finally you need to modify xintrc, so that KDE is actually used as a window manager and desktop at start-up of X. The crucial command is:

```
# Change in xintrc
exec /opt/kde/bin/startkde
```

startkde is a script file that sets the window manager kwm as well as a number of KDE components (for example, the desktop panel). Now you only need to execute startx, and a few seconds later KDE should appear on the screen.

Depending on the distribution, there are different possibilities for setting KDE as the default desktop. Please consult the section about X start-up on page 267.

You should ideally read the INSTALL and README files, which provide additional distribution-specific information. In RedHat 5.1 systems, for example, you need to install the nurses-3 package for KDE to work.

At the first KDE start-up, the subdirectory ~/.kde is created. You are prompted to change the password in ~/.kde/share/apps/kde/magic. You can use any text editor to edit this. The mean of the password is not clear from the documentation. If you do not modify it, everything seems to work correctly anyway.

# Survival rules

+   - Double clicks are frowned upon KDE and are only used in exceptional cases. A single click is sufficient to start programs, open directories, and so on.

+   - In many programs and KDE components, a context menu can be called by clicking the right mouse button.

+   - Almost all KDE programs can handle drag & drop. For example, you can drag a text file out of the file manager and drop it in the editor program (kedit). If the previous text has been changed in the editor, the new text is shown in
