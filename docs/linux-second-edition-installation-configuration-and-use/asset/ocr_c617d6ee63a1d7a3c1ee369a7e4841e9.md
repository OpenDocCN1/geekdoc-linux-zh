# Paragraph layout

| \parindent | first line indent of the paragraph |
| \playskip | distance between two paragraphs |
| \raggedright | no justification, text ranged left |
| \flushbottom | vertical justification (equal page depth) |
| \raggedbottom | no vertical justification |

The syntax for modifying line spacing differs from the above commands: With \newcommand{\baselinesretchfactor}the normal line spacing is reduced or increased by the specified factor. This slightly unusual definition is necessary because the line spacing depends on the current type size and therefore should not be set to a fixed value.

Normally, LaTeX automatically numbers all headlines down to including \subsection, which generates section numbers as 3.5.2. In this book, numbering has been reduced to two levels (chapter and section) by modifying the variable secundepth. Similarly, the number of levels for the table of contents can be controlled through the variable todepth (three levels in this book).

\setcounter(section)<n> changes the current section number
