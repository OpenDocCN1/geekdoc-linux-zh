# 70 ONLINE DOCUMENTATION

There are several programs for the display of man texts: the most used versions are man for the text mode, and xman for the X Window System. tkman is even more user friendly than xman; however, this version is not available on many systems and requires an installation of Tcl/Tk. Some distributions also supply HTML versions of the man pages (a program for dynamic conversion), so that the documentation can also be read with a Web browser.

The following sections describe man, xman, and tkman, followed by some information about the internal organization and formatting of man pages.

If you have installed KDE or GNOME, you can easily read man texts with the related help browsers. (Why not one of the two programs in their current version provides the possibility of searching in the text, however remains a mystery. In this regard, man is more functional.) The following examples show how you can display the man page for ls and a list of all man pages.

![](bbox=[0.22, 0.315, 0.25, 0.355])

```
user$ gnome-help-browser man:
user$ gnome-help-browser what:is
user$ gnome-help-browser toc:man
user$ kdehelp man:is
user$ kdehelp 'man:(index)'
```

# How to use man

man [options] [range] subject

man searches for the manual file specified as the subject in all man directories known to the system. If, instead of a subject, a file name is specified (for example, /cdrom/man/man1/abc.1), the contents of this file are displayed.

+   - displays all homonymous man pages. (Without this option, only the first of homonymous files from different subject areas would be shown. In some Linux distributions, however, -a is set as default.)

+   - keyword displays the meaning of a keyword (one line of text). This option corresponds to whatis.

+   - keyword displays a list of all available man texts in which the keyword occurs. However, no full text search is carried out – only the keywords of each man text are analyzed. This option corresponds to apropos word (or SEARCH APROPOS in xman).

+   - S area searches only the specified subject areas. This option is useful if you have to distinguish between several homonymous man texts.
