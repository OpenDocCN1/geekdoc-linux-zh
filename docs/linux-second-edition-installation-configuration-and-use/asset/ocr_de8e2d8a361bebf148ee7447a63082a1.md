```
root# ls -l /dev/tty1

```

If you want hug to be able to access the modem, simply add the user name hug to the uucp line in /etc/group. As a result, hug too belongs to the uucp group and can access this group's files (and devices).

```
# Change in file /etc/group
uucp::14:uucp,hugh
```

# Special rights and privileges

One special user, the system administrator (sometimes called 'superuser'), has greater powers than all other users. Generally, he/she has the root and a top secret password. The system administrator can, independently of ownership and access rights, access all data, register new users, change access rights, ownership, pass-words, and so on. He/she is also the only one with access to system administration programs (for example, shutdown, mount, fdisk, and so on). The separation of system administrators prevents users endangering the system as a whole.

If you work on your own Linux PC, you are effectively your own system administrator. It is always easier to work consistently as root. This means not having to worry about access rights, being able to execute all programs at any time, and so on. There is, however, serious danger that you will unintentionally change data that impacts the functionality or stability of Linux. Thus, even if you are the user of your computer, it makes sense to register at least one user for the day-to-day operation of Linux and use that as well.

> If you do not log in as root, among others, the disadvantage is you cannot execute shutdown or the related commands halt and reboot. A simple alternative to having to log in as root to switch off the computer is the key combination [Ctrl]+Alt]+Del]. This executes the reboot command, whether you have root privileges or not.

> The effect of [Ctrl]+Alt]+Del] can be specified in /etc/initab. The following setting causes an immediate shutdown:

```
# Setting in /etc/initab
ca::ctrlaltdel:/sbin/shutdown -t3 -r
```

# User and group administration

The file /etc/passwd stores a list of all users (one line per user). Each line contains, among others, the password (in encrypted form), number, the GID (group identification) number for group membership, the home directory and the shell. User Kofler thus has UID 501 and belongs to group 100 (users, see below).
