# WRITING CD-ROMS 533

-V name
This option specifies the volume ID, that is the name of the CD-ROM (max. 32
characters) as shown, for example, under Windows.

# Example

```
root# mkisofs -o /mnt/dos/iso.img -r -T -V Linux_3_98 /master
```

The above command writes all files contained in the /master directory into the
file lining.raw. For reasons of space, this file is stored on a partition which
is mounted into the file system at the mounting point mnt/dos. master itself is not
directory in the ISO image.

```
root# mkisofs -o /mnt/dos/iso.img -r -T /master \
> -b images/boot.img -c boot.catalog
```

As above, this time a bootable CD is created.

> If you do not use the option -r, here are some tips: make sure that all files in
t master directory are owned by root and are readable by all!

root# chown -R root.root /master
root# chmod a+xr /master

# Testing the ISO image

Provided that you have compiled your kernel with the Loopback device support option-
(category Blocks device) or the corresponding module loop.o is available and
can be activated by means of insmod, you may mount the newly created
file lining.raw in read-only into the file system:

```
root# mkdir /iso-test
root# mount -t iso9660 -o loop,ro /mnt/dos/lining.raw /iso-test/
```

You can now test the contents of the future CD-ROM (access rights,
TRANS.TBL and so on) using the iso-test directory. You will need to use a kernel
of 2.0.31 or later - otherwise Linux signals an I/O error for the last file of the
image the ISO image is all right!

# Hybrid CDs

Hybrid CDs contain the data itself only; however, they allow access to this
data different file systems, depending on the operating system. On a Macintosh,
t CD-ROM is recognized with the HFS file system; under Windows 95/NT, as an
ISO-9660 CD with Joliet extension; under Unix, equally as an ISO-9660 CD, but
with Rockridge extension. Thus, hybrid CDs allow CD-ROMs with long file
names which are correctly recognized on (almost) all operating systems. Sounds like magic,
does't it?
