# 452 COMMAND REFERENCE

-S or --dereference only displays the storage used by the specified directory itself. The storage used by subdirectories is not taken into account.

# Examples

```
user$ du -bS
129377
```

The files of the current directory use 129 377 bytes.

```
user$ du
101 /a/a1
4 /a/a2
114 /a
5 /b
251
```

The storage used in a1 is 101 Kbytes, in a2 4 Kbytes, in a (including a1 and a2) 114 Kbytes, and in b 5 Kbytes and in the current directory (including data and b) 251 Kbytes.

```
user$ du -S
101 /a/a1
4 /a/a2
9 /a
5 /b
132
```

With the -S option, du displays the storage used in the directories themselves. The sum of these values is again 251 Kbytes.

```
user$ du -c *.tex
100 emacs.tex
26 grundl.tex
126 total
```

The *.tex files in the current directory occupy a total of about 126 Kbytes.
