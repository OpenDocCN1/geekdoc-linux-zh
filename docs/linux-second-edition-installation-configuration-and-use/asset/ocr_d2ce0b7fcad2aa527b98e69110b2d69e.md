+   - Organization of the Init-V boot process: this deals with start-up, that is, the start of all necessary processes up to the login prompt. The configuration files elaborated this process bear different names in all distributions and are located in different directories. There is not even a consensus on the assignment of runlevels. All this certainly does not facilitate the task of maintenance.
- Live system: some distributions (increasingly fewer) allow operation of Linux directly from a CD-ROM. Only a minimal base system needs to be installed on the hard disk. Although this is rather slow and inflexible, it allows a relatively easy trying out of Linux.
- Umsdos: some distributions allow installation of Linux in a directory of a DOS partition. This is slow and has innumerable other disadvantages, but save (repartition) the hard disk. As with the live system, this variation too is mostly of interest for trying out Linux (in particular if it can be combined with a live system).
- Target platform: many distributions are only available for Intel-compatible processors. However, there are also distributions for DEC Alpha, SUN Sparc, PowerPC (MacOS), and so on.
- Documentation: some distributions are supplied with manuals in electronic or printed form.
- Support: with some distributions you receive free with the installation (via email and/or phone).

The statement that Linux is free seems to be blatantly contradicted by the price charged (often over $50 in the US). It is fairly easy to understand why there should be such a charge: although Linux and most application programs can be downloaded for free over the Internet, the compilation of an up-to-date distribution requires time and know-how. A good installation program (which also has to be programmed and maintained) is often worth the price of a whole distribution! Above all, it will save Linux or Unix novices time with installation and configuration.

Also, the money, not to mention the availability of one or more CDs, accompanied by a substantial manual, costs not the availability of personal support in case of installation problems. Also, a distribution becomes expensive when it includes commercial software.

The question of which is the best distribution, which is best suited to whom, and so on, can easily degenerate into a holy war. Somebody who has opted for one distribution and has used to its peculiarities will not easily switch to a different distribution. Generally, switching distribution can only be done through a complete new installation, which requires a certain amount of effort.
