# Construction of mathematical formulas

| a^{b} | a^{b} | \sum_{a}^{b} c | c |
|---|---|---||
| a_{b} | a_{b} | | b |
| \frac{a}{b} | | \prod_{a}^{b} c | a |
| \sqrt{a} | \sqrt{a} | {a \choose b} | b |
| \sqrt[n]{a} | \sqrt[n]{a} | | \overline{abc} | abc |
| \int_{a}^{b} c | c | \underline{abc} | abc |
| \int_{a}^{b} c | c | \overbrace{abc}^{d} | |\underbrace{abc}_{d} | abc |

The above commands are used for the construction of fractions, roots, inte-
gals, sums, and so on. The commands can be arbitrarily embedded to roots in
fractions or similar combinations. LaTeX automatically looks after suitable type
and formatting details. Please remember when specifying superscripts or sub-
scripts to enclose the relevant expressions in curly brackets - otherwise, ^ and _
apply to the first character.

If you are not satisfied with the type sizes chosen automatically by LaTeX, you
can influence them with the following commands:

# Type size in mathematical formulas

| \displaystyle | normal |
| \textstyle | slightly smaller (type size used in $ formula) |
| \scriptstyle | still smaller (first order indices and exponents) |
| \scriptscript | tiny (second order indices and exponents) |

The following formulae illustrate the interplay between some of the commands
listed above in the following sections.

```
\\frac{frac(a+1)}{(b-1)} \frac{frac(c+1)}{(d-1)}
\quad \mbox(and) \quad
\displaystyle \frac{(a+1)}{(b-1)}
<\displaystyle \frac{(c+1)}{(d-1)} \quad
```
