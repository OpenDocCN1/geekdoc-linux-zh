# enable-tab-completion

Allows completion of folder names with `Tab` (as in the shell).

# use-current-dir

File operations are carried out relative to the directory from which pine was started.
(Without this setting, the home directory is used.) The setting is useful if you frequently send attachments, store emails in files (EXPORT), and so on.

# signature-file=file.name

Specifies a file pine automatically integrates into each message you write. It may be a logo, your address, phone or fax numbers, and so on – that is, all of those things you do not want to keep typing in all the time.

# editor=/usr/bin/emacs

Specifies the editor you can start with `Ctrl++` (that is, `Shift+Ctrl+-`), if the standard-editor of pine is not sufficient for you.

# character-set=ISO-8859-1

Specifies the character set used on your computer. If this entry is missing, pine assumes your computer only recognizes the US-ASCII character set which may cause problems with foreign language characters.

> TIP: Extensive online information on pine is available via the help functions of the program (RELEASE NOTES and HELP in the main menu, Ctrl+G) in the editor. Furthermore, there is a fairly short man text.

# Usage

There are at least three folders in pine: inbox for newly received mail, sent-mail for messages written by yourself and sent with pine, plus saved-messages for folders transferred from there by means of the SAVE command. If you specify a different folder name in SAVE, pine automatically creates a new folder with that.

With the exception of inbox, pine stores its folders in the directory ~/Mail/. At the beginning of each month, old emails are transferred (after a request for confirmation) from sent-mail-mm-yy, where mm is an abbreviation for the month and yy the last two digits of the year. This prevents the sent-mail folder from growing forever. In addition, you can use this opportunity to delete old sent-mail folders. All other folders are not affected by this tidying-up process.
