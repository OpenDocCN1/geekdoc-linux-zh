.kdeink files can contain a lot of information, for example, the object names in several languages, the name of the icon, information regarding the file type, and so on. # KDE directories

The following list summarizes the locations of the most important KDE directories:

+   - /kde/share/appink Personal menu
- /kde/share/apps Program-specific data
- /kde/share/config Local configuration settings
- /kde/share/icons Local icons
- /kde/share/mimeink MIME data types
- /Desktop Desktop information
- /Desktop/Autostart Automatic start of programs
- /Desktop/Templates Template for new kde objects
- /Desktop/Trash Trash bin
- /opt/kde/bin Programs

- /opt/kde/wallpapers Background bitmaps

# The KDE display manager (kdm)

If you want be greeted by KDE dialogs immediately after computer start-up, you can use the KDE display manager kdm instead of xdm (page 270). This program allows a very easy login. You can even select your window manager. Configuration of kdm is carried out in the KDE control center APPLICATION/DESKTOP MANAGER. (However, individual options described in the online documentation have to be set directly in kdmrc.)

With the LOGOUT button, you can initiate a shutdown at a request for confirmation (that is, you can terminate Linux).

> In SuSE, you can use vast to set the environment variable DISPLAYMANAGER for kdm. With this, kdm (instead of xdm) is automatically used in runlevel 3. In other distributions, you need to modify the corresponding Init file yourself (usually /etc/rc.d/init.d/xdm or /etc/init.d/xdm).
