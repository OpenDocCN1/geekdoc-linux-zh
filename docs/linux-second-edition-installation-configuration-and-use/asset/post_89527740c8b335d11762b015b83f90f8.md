Essentially, lyx-code corresponds to the verbatim environment of LaTeX. The advantage: inside the environment, font attributes can be changed (for example, bold or italic type). The disadvantage: the listings are indented, but the amount of indent-cannot be changed. Furthermore, empty lines are not accepted. (Remedy: simply enter a space in an empty line, or `Ctrl+—`).

In the LAYOUT PARAGRAPH dialog you will search in for some frequently needed formatting features. If, for example, you want to change the space between two paragraphs or the line spacing inside a paragraph, you to make these modifications globally in the LAYOUT DOCUMENT dialog (see below).

If you want to have two paragraphs follow each other without vertical spacing, indents, and so on, you should use `Ctrl+—` instead of the style—separate them. (In LaTeX this corresponds to the command `\`).

With `Ctrl+Shift+C`, you can copy the paragraph layout of the current-paragraph. With `Ctrl+Shift+V`, you can apply this layout to another paragraph. In this way, you can continue to apply previously defined settings out great effort.

With `Alt+—`, you can split a paragraph into two parts, applying the same old layout to both of the new paragraphs. (If you use simply the new paragraph will be of standard type).

If these defined format types are not sufficient, you can individually modify the formatting of paragraphs by means of LAYOUT PARAGRAPH. This allows you to change justification (ranged left, ranged right, centered, justified), to insert rules ab or before the paragraph, to increment or reduce the distance from the preceding or following paragraph, to force a page break before or after the end of the paragraph, and so on. The MORE button takes you to a further dialog which allows you to set paragraphs in minipage environments (see page 605).

## Character formatting

Handling the LAYOUT|CHARACTER dialog is so laborious that you will soon put a stop excessive formatting of your documents. On the overall layout of your document – however, from the pure point of view of user-friendly handling. LyX character formatting needs some improvement.

The idea in itself is simple: in several lists of the CHARACTER (Standard, Sans Serif, Typewriter), the font series (bold), the font shape (italic, small capitals), the size, and the color. APPLY or the FONT button of the symbol bar apply the selected formatting to the currently selected text. The problem is that, whenever you need different formatting (for example, Typewriter in one case, and a smaller standard font in the other), you must set all the attributes.

> Make use of keyboard shortcuts for character formatting! Ctrl+B for type (bold), Ctrl+E for italic type (emphasized), Ctrl+K for small capitals, and Shift+Ctrl+P for Typewriter (program code). Repeating the command resets the formatting.

## Document layout

With LAYOUT|DOCUMENT, you can specify settings which affect the layout of the whole document. The following list describes the most important options:

- CLASS determines the type of the document (book, article, letter, and so on). Depending on the document class, different paragraph types are available.

- PAGESTYLE specifies the layout of headers and footers.
- SIDES specifies whether the position of section and page number is inverted on every second page (for a two-sided layout as in this book).
- COLUMNS specifies the number of columns. In two-column text, the columns are simply filled one after the other. This layout is not visible in LaTeX itself.
- FONTS specifies the default font. With default, LaTeX fonts are used; with Times, Palainno, and so on. PostScript fonts are used instead (This book, for example, is in Times.).
- FONT SIZE specifies the size of the default font in the range between 10 and 12 points. All other font sizes (for titles, and so on) are modified accordingly.
- LANGUAGE specifies the language to be used for the hyphenation rules and for predefined text elements (such as Figure/Abbildung in figure captions).
- SEPARATION specifies whether paragraphs are to be separated by vertical line (default, in this book).
- DEFAULT specifies the distance between paragraphs.
- SPACING specifies the line spacing inside a paragraph.
- FLOAT PLACEMENT specifies where elements (tables, pictures) should be placed. The options are t (top), h (here), and b (bottom).
