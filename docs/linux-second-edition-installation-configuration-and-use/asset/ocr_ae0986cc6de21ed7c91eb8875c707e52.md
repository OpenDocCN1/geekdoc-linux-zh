Depending on the distribution, there are different procedures to achieve the task, some of which are described by way of example:

+   - RedHat uses a modularized kernel without special drivers for SCSI and so on. A RAM disk file is created (/boot/initrd), which can be addressed by LILO in the same way as the kernel. This RAM disk contains the modules used during installation.

+   - SUSE provides a large number of preconfigured kernels. These kernels, too, are modularized, but in addition, a special module for the required SCSI adapter is directly built in. Selection of the correct system kernel is not carried out on the basis of the first installation, but is left to the user. If you make an error at this point, you might find that what you have up to this point become void!

+   - Debian sets a universal kernel. This kernel too is modularized, but it contains drivers for several common SCSI cards. (Unfortunately, there is no documentation around to tell which drivers are actually included in this.) Although procedure is simple, it is still not the optimum: on one hand, the kernel is larger than necessary; on the other hand, the attempt to recognize non-existent SCSI adapters may cause problems. If system start-up fails with a Debian kernel, all you can do is to try specify additional hardware options during booting. If this fails, you definitely have a problem.

# 2.7 Installation variations

This section summarizes information on several types of installation which, in practice, occur frequently. Always, the details largely depend on the distribution in question – please check the manual or the online documentation.

# Installation from hard disk

An installation from hard disk becomes necessary if neither a CD-ROM drive nor a network connection is accessible during installation. In this case, you need to copy all required data to your hard disk prior to the installation.(This means that at least at this stage – for example in operation under Windows – a CD-ROM drive must be attached or a network connection must be accessible.)

Not all distributions support installation from hard disk. The problem is that, during copying the installation files from the CD-ROM to the hard disk under DOS/Windows, the file names are destroyed. If the names of relevant files are not limited to 8+3 characters in the first place, the distribution must also be able to cope with truncated filenames. (SUSE uses short file names, and RedHat can cope with mutilated filenames.)

A further problem arises from the need for additional space – in most distributions, the installation data take up several hundred MBytes!
