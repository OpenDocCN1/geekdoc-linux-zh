# 378 NEWS

The first tin obstacle might already be the start. Depending on how the program is compiled, it will display a few error messages at start-up (which might not even be visible in xterm) and quit immediately. In this case, it expects a news archive in `/var/spool/news/`, as it would be created by the server inn.

tin can read an archive without contacting the server. However, this rather exotic feature fails if no local server exists at all or a different local server (for leafnode) is used. Try to start tin with the option -r like this:

```
user$ tin -r
```

# Usage

At the first-start, tin transfers a list of all known newsgroups from the server into the local .newsrc. If the Internet connection to the server runs only via a modem, this will take several minutes. (The waiting time occurs only at the first-start.) Subsequently, tin displays the empty list of subscribed newsgroups.

Press Y to display the long list of all unsubscribed newsgroups. Now, you can use the cursor to move to the required newsgroups and subscribe to a single group with S or you can use Shift+S to subscribe to all groups that match a given pattern. For example, you can enter os.linux.* to select all Linux groups. Press Y once more – the screen should look more or less as follows:

```
Group Selection (localhost)               h=help

32 comp.os.linux.hardware
92 comp.os.linux.misc
3 comp.os.linux.networking
2 comp.os.linux.x
```

```
<=set current to n, TABnext unread,/search pattern, clatchup,\goto, jline down, kline up, help, move, quit, toggle all/unread,
subscribe, job pattern, unsubscribe, Unsubscribe pattern, yank in out
```

The numbers in the second column indicate how many articles you have not yet read. In order to read the article in a newsgroup, simply move the cursor into that line and press -. Now, the structure of the screen will look like this:

```
2zfck signals error. Disk defective? Joerg Mertin
2 + 2 MC in color? Kai Straube
4 + 3 - no daemon present Joachim Zob
6 + 2 Problems with kernel compilation Stefan Lange
```

The second column needs some explanation. If it contains a number, we have a thread containing n unread articles. With the cursor keys, you can select an article or a thread. With you can read the article. takes you to the next article, back to the list. Once an article has been read, the plus sign or the threading number is removed. When you quit the list and visit it again. read articles are no longer displayed at all.
