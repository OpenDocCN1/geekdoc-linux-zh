The first three drivers in this list run on most VGA cards, but do not always make use of their special features. The VGA-16 driver is needed, in particular, for the configuration process. If is not possible to get a special driver for your own card to run. It also contains highly optimized code for some graphics cards (such as the Matrox card) — see man XF86SVGA. The drivers are specially optimized for specific graphics cards.

All drivers, for the monochrome and the 16-color driver, support the 256-color mode, with, in most cases, the possibility of setting an arbitrary resolution. Most drivers for special graphics cards also support graphic modes with more colors (15, 24, and 32 bit color coding).

The drivers are installed into the /usr/X11R6/bin directory. The required driver is selected by a link from /usr/X11R6/bin/x to the driver. In some distributions, /usr/X11R6/bin/x points to /etc/X11/X or to /var/X11R6/bin/x. In this case, only the latter link points to the server.

```
user -l /usr/X11R6/bin/x
lrfrwmx root root X -> ..//etc/X11/X
user -l /etc/X11/X
lrfrwmx root root /etc/X11/X -> ..//usr/X11R6/bin/XF86_Mach64
```

If you do not know which works on your graphics cards, you should read your card's documentation. If this does not help (or if you do not find any manuals), you can execute the SuperProbe program. In most cases, this program reliably detects your graphics hardware. In the worst case, it can cause a crash, destroy the character set or lead to synchronization problems. Then, you should execute this program only if you do not have several works lying around in unsaved files. Or, to avoid several hours of work lost. To be more accurate: before executing SuperProbe, unmount all file systems that you do not need and then execute sync.
