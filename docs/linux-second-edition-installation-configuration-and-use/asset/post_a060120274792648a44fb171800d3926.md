
## 11.11 Advanced functions

A special feature of Emacs is the ability to use abbreviations without having to carry out any prior preparations. You simply enter the first letters of a word and press Alt-x causes Emacs to search for beginnings with these characters, in the preceding text, then in the following text and finally in all open files. If, for example, you enter Alt-x at this point in the text, Emacs replaces 'env' with 'environment'. By pressing Alt-x again, Emacs offers options for expansion, for example, 'envelop' and 'envisise'.

If you want to use the feature of dynamic word expansion in an even easier way, you should assign the dabbrev-command an easier-to-reach keyboard shortcut (for example, a function key—see page 581).

Dynamic expansion only works if a word is already present in the text and the initial letters. In some cases, this is not sufficient. For writing and letters, it would be very hard, for example, if Emacs were to substitute 'br' with 'Best regards'.

Emacs also supports this kind of predefined abbreviation. definition is long-winded; you must first enter the abbreviation into your text (for example, 'wheeg'), then call the command Ctrl-X-A I, then type the complete text (for example, 'with the humble expression of my eternal gratitude') and finally press Enter. With this, the abbreviation is stored, and the originally entered characters 'wheeg' are immediately substituted with the new text.

Any time you 'wheeg' again in your text, immediately followed by the command Ctrl-X-A-E (abbreviation expand), Emacs replaces the five letters with the above text.

There is an even easier way: with the command Alt-x abbrev-mode you can activate the abbreviation mode. From now on, Emacs replaces all abbreviations with the complete text if you enter a space or a punctuation mark directly after your abbreviation. You no longer need to ask an abbreviation into the full text.) Due to this automatic expansion, you must define abbreviations in such a way that they do not constitute an existing word (otherwise, the word would always be replaced by the abbreviation).

You can view the list of all defined abbreviations with Alt-x edit-abbreviations. The first column in this list contains the abbreviations (enclosed in double quotes), the second column a number which specifies how many times this abbreviation has been used, and the third column the full text (again in double quotes). The abbreviation list is subdivided into several sections for different Emacs processing modes. With this command, abbreviations are always defined globally, that is, they work independently of the processing mode and are stored in the section global-abbrev-table.

| (c-mode-abbrev-table) |
| (text-mode-abbrev-table) |

In principle, you can not only view this abbreviation list, but also edit it. The deletion of abbreviations works without problems; you simply remove the corresponding line with Ctrl+K. Usually, you can enter new abbreviations or alter existing ones, provided you know the syntax of Emacs. (Please note in particular the l character must be edited twice in order to be inserted into the text once). Subsequently, you must save the modified abbreviation list inside Emacs with Ctrl+X, Ctrl+S, Ctrl+X, B takes you back to the text you are editing.

Abbreviations are usually only valid when Emacs is terminated. The abbreviation list is stored in a buffer in RAM, not in a file. As a rule, it would be desirable if abbreviations that have once defined could be reused at a later stage. For this purpose, Emacs provides the commands Alt+X write-abbrev-file and Alt+X read-abbrev-file for saving and loading files containing abbreviation definitions. With these two commands you can now save and load abbreviations, but the usage of them is rather long-winded. In particular, before you quit Emacs, you must remember to save or modify new abbreviations. From page 581 onward, describe how you can automate the loading and saving of abbreviation files by using a couple of lines in .emacs configuration file.

## Macros

Apart from abbreviations, which are merely a typing aid, Emacs also understands macros in which complex command sequences can be recorded and later executed. The recording of a macro starts with Ctrl-X X and ends with Ctrl-X, Ctrl+E. All keyboard input between these two commands is recorded. Emacs always stores one macro. As soon as you record a new macro, the old one is deleted. You can, however, give the current macro a name before you start to record a new one. This is done with Alt-X name-kbd-macro. The macro is stored under the specified name and can be executed at any time with Alt-X name-.

However, even named macros are only stored until you quit. It is not possible to assign a user-defined keyboard shortcut which allows it to be called up easily. The desire to have both macros and shortcuts can only be fulfilled by the definition of macro in .emacs configuration file. Alternatively you can create a shortcut to it in a special file; however, you will have to execute it manually with Alt-X eval-current-buffer (whereas .emacs is automatically executed at the start of Emacs). For a previously recorded named macro in file, Emacs provides the command Alt-X insert-kbd-macro. This command inserts the Lisp code corresponding to the name into the current file. However, this code does not look particularly clear since it is strewn with incomprehensible codes. Thus, editing existing macros is practically impossible. To summarize, the way to create a permanently named macro is:

- record the macro with Ctrl-X X and Ctrl+E
- test the macro with Ctrl-X, and if it does not work as expected, try to record it
- name the macro with Alt-X name-last-macro
- load the configuration file .emacs from your home directory
- insert the macro with Alt-X insert-kbd-macro, then save .emacs

Macros can be assigned their own keyboard shortcuts. In addition to the macro recording facility above, Emacs also allows you to program macros in its own Lisp language. More on this subject can be found in a separate chapter from page 569.

## Entering foreign language characters

On page 539 we described how Emacs must be configured to allow input of foreign language characters by loading the iso-syntax library. This allows Emacs to handle special characters which are actually present on national keyboards. But what if you have a standard US keyboard or any national keyboard which does not contain the characters you want to enter when writing texts in different language? For example, if you want to enter characters such as á, ä, ã or ç on a US/UK or German keyboard?

For such cases, Emacs obviously has its own special input mode, which you activate with Alt-X iso-mode. Now, the keys have a new meaning: if you enter a suitable letter afterwards, Emacs combines the two characters into one. Then, the input O yields the letter ‘o’, S becomes the letter ‘b’. If you have to input *, followed by an additional space.

New Emacs with MULE (Multi-lingual Enhancement) has a number of additional alternatives for entering foreign languages. Execute the command Alt-X select-input-method and press Tab. Emacs displays a list of over 50 possibilities! The Latin-1 prefix basically corresponds to the above-mentioned iso-mode.

## Using Emacs as a shell

Alt-X shell activates the shell mode. Emacs opens a new window and allows you to execute commands in it. The result of these commands is stored in a buffer and can be further processed with all the editors. Thus, you can copy the results of a command into another text, or look through the entries of a ten-page file listing, searching for particular texts with Ctrl-S and so on. The shell mode combines the processing capabilities of Emacs with the command variety of the shell. When you modify a line and terminate it with Enter, this is interpreted as a new command. In this way, you can correct misspelled commands or modify or re-execute already executed commands in a different variation.

Unfortunately, there are communication problems between Emacs and some shell commands — namely each time the command wants to use specific terminal commands which are not available in Emacs. A typical example is less (which you do not need in Emacs anyway; if you do, simply use more).

## Client/server operation

Anybody who uses Emacs intensively will inevitably end up carrying out the major of his/her work under Linux with Emacs — regardless of whether she wants to have a quick look at a file, needs to write an email or to manage a complex programming project. It makes no sense to start Emacs every time you want it — it costs time (and a lot of memory), if there are instances of Emacs loaded.

In order to avoid these disadvantages, Emacs can be put into a special server mode with Alt-X server-start (The command can also be executed in the .emacs configuration file or with the command line -f server-start. A comparable command for XEmacs, unfortunately, does not exist).

The handling of Emacs does not change. The new feature is that you can start a new Emacs client with emacsclient file. The specified file is simply displayed in the currently running Emacs (When you work in text mode, you change console; under X, you must change into the Emacs window.)
