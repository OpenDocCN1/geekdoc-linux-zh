# The KDE file manager (kfm)

kfm is the KDE file manager. Files can be represented as icons or in text format. Handling practically without problems, although some smaller details are still annoying (the lack of the sorting possibilities for file lists). If you want to select a file with the mouse without opening it, you need to press Ctrl. This is easier via the keyboard — simply press Space. Special features of kfm are:

+   - The contents of tar archives can be viewed and processed in the same way as a directory.
- With image files, the image contents can be displayed as an icon (VIEW | SHOW THUMBNAILS).
- HTML documents are displayed directly — thus, kfm is also a Web browser. Important directories, no matter where locally on the hard disk or on the Internet, can be marked with bookmarks. (These are stored as *.link files in the directory .kde/share/apps/kfm/bookmarks).
- When clicking on documents with known name extensions, the programs for viewing the contents are automatically started (such as kvi for *.dvi files, and so on.

New document types can be defined with EDIT | MIME TYPE | NEW | Subsequently, the features need to be specified via the PROPERTIES context menu. A similar procedure is followed for setting up new programs for display and processing of such documents: first EDIT | APPLICATIONS, then file | NEW | APPLICATION.

# kfm keyboard shortcuts

| Alt+← | back to previous directory/WWW file |
| Alt+→ | Undo for Alt+← |
| Alt+T | one directory level up (cd ..) |
| Ctrl+F | find files |
| Ctrl+S | select files following a pattern |
| Ctrl+T | open terminal window for the current directory |

kfm should, if possible, be started within a KDE menu. For a start from outside, you need to use the option -ws, thus kfm -ws.

If, as a normal user, you want to execute kfm with root privileges, you are automatically prompted for the root password.) (You need to exit X nor execute su. kfmsu.) kfm now shows a red bar to the menu bar and provides some additional commands (EDIT | GLOBAL MIME TYPES and EDIT | GLOBAL APPLICATIONS).
