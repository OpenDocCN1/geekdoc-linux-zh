# 1.2 What does Linux offer?

The question – What is Linux? has not been answered fully. Many users are not interested in the kernel at all — as long as it runs and supports the existing hardware. For these users, the term ‘Linux’, as used in everyday language, includes, apart from the kernel, the huge bundle of programs that come with the Linux kernel in the form of distributions (see the following section).

This section gives an overview of the most important features of Linux and the available application programs. Naturally, this is not complete — it would make little sense to listen to every single program that runs under Linux.

# Kernel features

- Linux supports multitasking (concurrent execution of several processes), multiuser operation (concurrent usage by several users), paging (swapping of memory to disk, if the available RAM is not sufficient), shared libraries of file systems are loaded only), once even when they are needed by several processes; redress communication (IPC), and — since version 2.0 – Symmetric Multi Processing (SMP, the use of several processes).
- Linux supports practically all common PC hardware; all Intel 386-compatible processors; ISA, EISA, VLB, and PCI bus systems; most (IDE and SCSI hard disk controllers and hard disks, CD-ROM drives and streamers connected to them: most COM-ROM drives not connected to an IDE or SCSI bus; most network cards, mice, and so on.(A complete list is given in the Hardware Manual— see Chapter 4 from page 69 onwards).
- Linux supports not only Intel processors, but also the DEC Alpha processor, Sun Sparc, Motorola, and so on. The most widely used variation is certainly the Intel one.
- Linux uses its own file system (ext2fs). File names may contain up to 255 characters, files may have sizes up to 2 Gbytes, file systems up to 4 Terbytes. It is also equipped with a lot of security features. (When Linux is executed on 64-bit processors, file sizes may also be larger than 2 Gbytes).
- Under Linux, it is possible to access foreign file systems: DOS, Windows 9x (with long file names), NTFS (read only), OS/2 (read only), Minix, NFS (file systems available over the network), and so on. However, it is not possible to access compressed DOS/Windows partitions (except through a long-winded procedure using the DOS emulator).
- Linux supports several binary formats for the execution of binary files: a.out (standard to version 1.0), ELF (standard since version 1.2), and iBCS2 iBCS2 allows you to use many commercial programs available for SCO Unix without any recompilation or porting to Linux. Since more and more software providers offer separate Linux versions of their programs, the iBCS2 emulator is decreasing in importance. (Iron of fate: SCO is now offering an emulator to allow Linux programs to be used under SCO Unix)
- Under Linux, a range of network protocols is available (TCP/IP, PPP, SLIP, and so on).

Compared with kernel 2.0, kernel 2.2 brings only a few tangible changes for the average user. However, much has happened underneath the surface. SMP support has been significantly improved and memory management has been optimized. A lot of new code can be found in the network functions which, on the one hand, had to be considerably faster and more stable, and on the other hand, were supposed to support additional protocols (including the new IP version, IPnG).

The support of several non-Intel processors has been integrated in the code better than before. New kernel functions help with dynamic activation/deactivation of modules (instead of leaving this task to the external kernel program). Furthermore, there is a huge number of new or improved hardware drivers for ISDN, SCSI, and sound cards.

The minimum requirements for stable execution of Linux in text mode are about 4 Mbytes of RAM for Linux 2.0, and 5 Mbytes of RAM for Linux 2.2. However, to make the system run reasonably fast, a minimum of 8 Mbytes is a better alternative. If you also wish to use the X Window System, you will need at least 16 Mbytes (better 32 Mbytes). If you want to turn an old 486 PC into a Linux workstation, an older kernel version is probably sufficient. A very stable version is, for example, version 1.2.13. Compared with the 2.n kernels, this version is relatively space-saving.

# The X Window System

After booting, initially runs in text mode, with the possibility of switching between several terminals. (Normally, there are six terminals available which can be accessed via the Alt+F1 to Alt+F6 key combinations).

It is also possible to start the X Window System under Linux. In order to run the X Window System, you need either the free port XFree86 or a commercial X server (for example, Xside or Metro-X). XFree86 supports practically graphic cards whose producers have released their documentation.

In real terms, the X Window System is just a collection of functions for the graphical display of information on a screen. Built on this base are graphical user interfaces and application programs that greatly facilitate the handling of Linux distributions mostly include the window manager fwm, the desktop systems KDE and GNOME, and a whole range of X programs.

# Tools

The input of commands is carried out in a socalled shell. A shell is something similar to the DOS command interpreter, only a lot more powerful. Under Linux, several shells are available. The most popular is bash (Bourne Again Shell). Anybody who dislikes this can get along with tech (compatible with the shell).

A large number of commands are available for file management and system administration, such as ts (corresponds to DIR under), cp (corresponds to COPY), and so on. For handling files there is also a vast choice of file managers which either run in text mode (for example, me, largely by Norton Commander) or support X.

The range of editors varies from simple editors (such as vi), to an editor which is difficult to build but available on all Unix systems, to huge editors such as Emacs. This program is sometimes, ironically called an operating system on its own because it contains such a vast number of functions; Emacs can be used to read and write email and new articles, debug C programs, and so forth. The term editor is no longer really appropriate in this case.

# Text processing and formatting

The predominant (free) typesetting program under Linux is LaTeX. To this not-so-easy-to-handle typesetting program, the LaTeX program provides a modern interface which almost achieves WYSIWY (what you see is what you get). In addition, Linux provides a variety of tools and utilities to process PostScript files or convert them into other formats- and so on.

# Network software

Linux supports the TCP/IP, PPP, SLIP protocols. It allows the construction of almost arbitrarily complex local networks. Client and server programs are available for all kinds of connection with the Internet (telnet, rlogin, email, News, ftp, WWW). Thus, under Linux, you can only use the Internet services, but also establish an Internet server yourself. Samba allows management of networks which Windows PCs can access as clients (access to files, printers, and so on).
