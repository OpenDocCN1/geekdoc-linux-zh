# Virtual desktop, Pager, GoodStuff

The X server can only manage one screen (which can be bigger than visible on the monitor, if sufficient video memory is available). fwwm goes one step further: windows may be placed in different virtual screens. Several screens can be combined into a 'desk', several desks into the virtual desktop.

At the beginning, one screen will be sufficient. Several screens are useful for network operation (all connections to a particular computer on one screen), for program development (editor and debugger in screens), and so.

> If you work with a virtual desktop, it is usually useful to activate the X server's virtual screen (kernel Virtual in the Screen section of XF&Config).

The module FwmPager is responsible for managing the virtual desktop. With a click of the left mouse button, you can select the active screen. With the middle mouse button you can move a window arbitrarily across all screens directly in the pager. With the right mouse button, you can place the visible screen over the actual screens (but this weird lacks some cases).

Depending on the configuration, fwwm can be set up in such a way that the visible screen scrolls across the whole desktop as soon as the mouse is moved to a different screen. This has not been included in the sample configuration, as this behavior can be confusing to begin with.

The module FwmGoodStuff needs addressing at this point: this is a kind of command headquarters which buttons for starting xterm programs can be placed. In the sample configuration, only one button for xterm has been included.

GoodStuff can also house other modules and display their contents. In the sample configuration, the pager has been integrated into GoodStuff. (Otherwise, the pager would be a window of its own).

GoodStuff is usually configured in such a way that it stays in the same position ('sticky'), independently of the currently visible section of the desktop.

# Configuration

The fwwm configuration is carried out either through ~/.fwwmrc or if this file is not present, through the global file system.fwwmrc. Depending on this, this file is located in one of the following directories:

```
~/.fwwmrc (local)
/etc/X11/fwwm/system.fwwmrc (global. RedHat)
/usr/X11R6/lib/X11/fwwm/system.fwwmrc (global. Calder, SU)
```
