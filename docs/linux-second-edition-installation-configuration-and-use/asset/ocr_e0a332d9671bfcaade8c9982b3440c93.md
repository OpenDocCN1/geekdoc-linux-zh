# 19.3 Scientific document layout

# Figures

Like LaTeX too can only handle PostScript graphics. These can be inserted directly (at the position of the insertion point)—either as a separate paragraph or as a small graphic in the flowing text—by means of INSERTFIGURE or by pressing the appropriate button on the symbol bar. Initially, LaTeX displays only an empty frame. As soon as you click on it, a dialog pops up which prompts you to select a file name and to set various options (including the quality in which LaTeX displays the preview of the figure).

Free-standing graphics can be formatted in the same way as paragraphs by means of LAYOUTPARAGRAPH (and thus, for example, centered).

LaTeX displays a preview of the figure directly in the document (internally, ghostview is used for this purpose); however, the zoom factor is ignored, which frequently makes the size of the figure does not match the size of the text. Only the page preview (DVI/PostScript) shows the correct proportions.

Things become slightly more complicated when you want to place a caption above or below a figure. For this purpose, you use INSERTFLOATS/FIGUREFLOAT to insert a figure environment into the document. The environment provides a paragraph of the caption format for labeling the figure. In the final document, the text ‘figure’ is replaced with ‘Figure n’—which means LaTeX (or LaTeX) automatically looks like the numbering.

To insert the figure itself into the figure environment, you use the commands described above. If the figure is to be placed below the caption, this works without problems. Placing the figure above the caption, however, requires some more effort—owing the fact that the insertion point cannot be placed in front of the caption line. Therefore, you will need to position the insertion point at the beginning of the line and press — to insert a new line.

Once you have succeeded in producing a figure together with its caption in the required formatting, you can reuse this figure any number of times by copying and pasting it; then you simply replace the graphics and the text of the caption.

When LaTeX formats the document, the program may place the figure more words towards the top or the bottom of the page to ensure optimum usage of print space. If you wishes to remain as precisely as possible at the point of text where you specified them, you need to indicate the h (here) in the LAYOUT|DOCUMENT|FLOATPLACEMENT dialog. Other alternatives are t (top, that is, at the beginning of the page) and b (bottom).
