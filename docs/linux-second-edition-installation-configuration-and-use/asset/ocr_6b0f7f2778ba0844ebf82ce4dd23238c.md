# 204 CONFIGURATION AND ADMINISTRATION

In principle, there are two possibilities for updating the kernel code:

+   - You can use so-called patch files to update from one version to the one immediately following. For example, if you want to update from version 2.2.29 to 2.2.30, you must execute the patch command to carry out the kernel patch patch-2.2.30. patch-2.2.30 is a text file that describes which points the individual files of the version 2.2.29 source code must be modified. (Thus, the complete and source code of the immediately preceding version is a necessary precondition for any successful update.) Patch files have being relatively small and can be easily obtained via the Internet using FTP.

+   - In the case of major version changes – for example, from 2.2.3 to 2.2.30 – you would have to carry out dozens of patches in a row. This is not very practical and it may become a source of errors. For this reason, the kernel code is also available as a complete package. Typical file names look like linux-2.2.30.tar.bz2. Such compressed files (about 10 Mbytes in size) must be installed in the /usr/src directory using tar.

Now to the details: kernels are usually installed in /usr/src/linux. If this directory contains an existing kernel, there will be chaos. If it is sensible to delete the old kernel (rm -rf /usr/src/linux) or if you have enough disk space available, to rename it. (The following discussion assumes that currently kernel 2.2.29 is installed and an update version 2.2.30 to be carried out.)

```
cd /usr/src
mv linux-2.2.29 # backup of the current kernel code
```

Sometimes, /usr/src/linux is only a link to the directory in which the currently installed kernel code is located:

```
cd /usr/src
is -f linux
root root lrwxrwxrwx 1 root root 11 Apr 30 16:58 Linux -> linux-2.2.29
```

In this case, you only need to delete the link before you install the new kernel

```
cd /usr/src
tar -xlvf linux-2.2.30.tar.bz2
tar tar -xzvf linux-2.2.30.tar.gz
```

Now unpack the new kernel into the linux directory. Kernel archives are always compressed, either with gzip (or more frequently) with bzip2. In the following lines, the tar options for both variations are indicated

If you want to update this kernel to the next version, you must get hold of the patch file patch-2.2.31.gz (for example, via FTP). Subsequently, you will have to change the /linux directory, decompress the patch, and apply it to the kernel code with patch -p1.

```
cd /usr/src/linux
bzip2 -cd patch-2.2.31.bz2 | patch -p1
```
