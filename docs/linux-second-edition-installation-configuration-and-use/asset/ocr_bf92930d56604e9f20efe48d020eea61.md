Now for the type size: here again LaTeX differs from what you are used to in other text programs. There is a standard type size which applies to the entire document. This size can only vary between 10 and 12 points. The default size is 10 points, but you can also set it to 11 or 12 points with the \documentstyle options 11pt or 12pt.

Starting from this standard type size, LaTeX calculates suitable sizes for headings with \chapter or \section, for footnotes, mathematical formulas, and so on. This is also used as a reference for the size changing commands:

# Font size

# Special characters and accents

A large number of special characters, such as % or $, are interpreted by LaTeX. Some further special characters only have specific meanings in mathematical mode (for example, ^ and _), but they cannot be used in text mode. The following table summarizes the most important characters:

# Meaning of special characters

| % starts comments |
| fixed size (for example in 5~cm) |
|(..) encloses text areas (for example, special formatting) |
|$formula encloses formula in flow text |
| subscript (only in mathematical mode) |
|^^ superscript (only in mathematical mode) |

The attempt to represent special characters unchanged in flowing text is a source of frustration; firstly, even after months of working with LaTeX you may still not remember that a character has a special meaning. Secondly, there is still no single method of representing special characters in normal text. In many cases it is sufficient to prefix the special character with a backslash (for example, \% to generate a % sign). If this does not help, the character can be specified directly with \char. The standard ASCHI code applies for most characters.
