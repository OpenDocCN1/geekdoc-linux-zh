# SUSE 6.1

Please note that what is created is not a full backup, but only a backup of files you have modified. The advantage is that in many cases the amount of data can be handled without a streamer. Furthermore, creating a backup of files which are included on the SuSE CD-ROMs in the first place does not much sense. You, however, be aware that you cannot restore your system (for example after a loss of your hard disk) from the backup files alone. You would first need to install the same packages that were present at backup time and then use the backup to restore your own modifications.

# The help system

One of the most attractive features of the SuSE distribution is certainly the help system. It consists of the following packages, all of which, for reasons of space, need not be installed. If not specified otherwise, all packages are located in the doc series.

+   - susehelp English and German starting page, script files hilfe and susehelp - rman (ap series) man -> HTML converter - inf2htm info -> HTML converter - apache (n) http server (dynamic info texts, search function) - gnuhtml HTML files for GNU programs - howtoenh HTML version of the HOWTO documents - ldp Linux Documentation Project (FAQs and several complete books(s) - sdb.en texts of the support database - sdb.cgi CGI scripts for searching the support database short descriptions of all SuSE packages - usepake xf86html XFree8 documentation in HTML format

All of the documents mentioned above can be accessed via Netscape from a starting page. The help system can alternatively be started with help (English version) or help (German version). If Netscape is already running, the starting page is immediately displayed; otherwise Netscape is automatically started.

The support database contains an almost endless list of texts that have emerged from years of experience of the SuSE support department. (The version supplied is obviously not entirely up-to-date. The current version can be found at SuSE's Web site.

Depending on whether you have installed the CGI scripts and the Apache HTTP server, you can use either the comfortable keyword search or you need to pick the help texts from an alphabetical keyword list. The search for 'ppp' in SuSE 6.1 yielded 52 entries in all!
