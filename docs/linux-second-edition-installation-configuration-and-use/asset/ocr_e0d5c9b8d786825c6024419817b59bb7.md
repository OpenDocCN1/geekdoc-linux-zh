When you write a collection of your own shell scripts for day-to-day use, it is a good idea to store them in some central place, for example in the /bin directory. If subsequently you make the following change in .profile, these scripts can be executed without having to specify the complete path.

```
# Addition to ~/.profile
PATH=$PATH:/bin
```

Online texts about shell programming can be obtained with man bash and with info -f /usr/info/bash.help displays an overview of bash-internal commands, man command gives further information about the specified command.

# Other script languages

"Script language' is the technical term that denotes programming languages which process commands in a text file. Script languages stand in contrast to 'true' programming languages, such as C, in which the program must previously be compiled. Script languages have the advantage that they are much easier to learn.

If you find the possibility of bash no longer sufficient, you should consider the additional script languages available to you under Linux: for example, the ksh can manage arrays, whereas the tsh uses a syntax similar to that of C (and often different from that of bash).

Two languages are completely independent of the peculiarities of a shell language are pert and awk. pert stands for 'Practical Extraction and Report language' and is specially suited to processing text files. You can use pert to analyze, modify, and do other things to texts. pert combines the capabilities of the sed (stream editor) with those of a programming language. The name awk is combined out of the different syntax is presented by the initials of the original-authors, Alfred Abo, Peter Weinberger, and Brian Kernighan.

Another easy-to-learn script language is T/Tk. Many commands are similar to those of bash - but the extent of T/Tk language goes far beyond C functions and adapts to the requirements of the programmer and is suitable for easy interface programming under X. A few programs are sufficient to realize dialogues with buttons, list arrays, and so on in T/Tk.

The last language worth mentioning is Python, which is very popular in the Linux scene (but not only). In contrast to other script languages, Python is object oriented. Furthermore, in the design of the language great emphasis has been put on the fact that the structure of the code remains as clearly as possible. (Thus, lines in loops, conditions, and so on, must be indented). There is another argument in favor of Python: the language is extremely well-documented. (In some distributions, the documentation needs to be installed separately because of its size: in SuSE, for example, the documentation can be found in the python package.)
