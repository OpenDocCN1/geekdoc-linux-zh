One of the most attractive features is the telephone charges counter of kpppp.
To use it, accounting must be enabled for the relevant account on the ACCOUNTING
dialog sheet, and a phone company must be selected. (The program contains charges
regulations for surprisingly many tariffs worldwide.) The logging files with a sum-
mary of data and charges incurred can then be displayed via VIEW LOGS on the
COUNTS sheet of the SETUP dialog.
