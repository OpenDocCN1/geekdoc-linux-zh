Foreign special characters no longer constitute a problem in current LaTeX versions. You must simply specify the instruction \package{isolation} at the beginning of the text. Then from accented letters, umlauts, and so on, can be used in the text directly. Previous versions needed a rather long-winded notation of the form "a for an \ä". This notation is still recommended if you plan to use your texts on other UNIX computers (possibly running older versions).

There are several possibilities for representing the Euro symbol under LaTeX. The easiest one is to use the textcomp package and the \euro defined there. The result, however, bears little resemblance to the official symbol and is furthermore incompatible with the PostScript fonts used for this book (Times and Future)—therefore we have to do without an example.

# ## Tables

LaTeX has several possibilities for defining tables. At this point, we only describe the simplest variety, namely the tabbing environment. The syntax of this environment looks as follows:

```
Tables
\begin{tabbing}
sample = sample \= kill
term1 \> term3\
term4 \> term5
end{tabbing}
```

Tables are initiated with a sample line. This line defines the positions of the left-ranged tabs. Your sample line should normally be the widest line in your table. Before each \=, you should insert an additional space, for example with a \quad instruction (space of two hyphens – see page 618). \kill deletes the sample line, so that it is only used as a sample, but is not output.

An example to conclude: the special character on page 601 was produced with the following LaTeX instructions:

```
\begin{tabbing}
{sm\verb?formula$}\quad\=
{sm\verb???}
\> starts comments\
```
