## 什么是 Linux？

为了回答“什么是 Linux？”这个问题，本章解释了贯穿全书的一些关键概念：操作系统、Unix、发行版、Slackware、内核等。对 Linux 特性和可用程序的简要概述，使人们清楚地看到 Linux 的应用可能性是多么深远。

本节之后是对 Linux（尽管仍然很短）历史的简短游览；你将了解到 Linux 是如何产生的以及它是基于哪些组件的。一个至关重要的点是通用公共许可协议（简称 GPL），它规定了 Linux 可以分发的条件。只有 GPL 使得 Linux 成为一个自由系统（这里的“自由”不仅仅是指免费）。

## 内核

术语“Linux”精确来说指的是内核：内核是操作系统的核心部分，执行基本功能，如内存管理、进程管理和对硬件控制。在编写这些文字时，内核 2.2 刚刚发布。

内核的版本需要特别关注。我们区分稳定用户版本（1.2.n、2.0.n、2.2.n）和开发者版本（也称为黑客内核。1.3.n、2.1.n、2.3.n）。重视系统稳定性的 Linux 用户应该使用完全开发的内核。只有那些对参与内核开发感兴趣的用户才使用开发者内核。缺点是：开发者内核通常仍然包含未充分测试的代码，可能会产生问题。大多数发行版基于稳定内核，但它们提供了安装最新开发者内核的选项。
