- -perm access bits finds files whose access bits exactly match the specified octal value (see chmod). When the octal value is preceded by a -, it is sufficient that the file contains least one of these access bits, whereas a preceding + means that the file may have more extensive access rights.

- -size file.size specifies the required file size. Usually, this is indicated in multiple of 512. Thus, 3 denotes files between 1024 and 1536 bytes. With the additional character c or k, the size can be specified in bytes or Kbytes. Whereas a preceding + finds all larger files, a - all smaller files. Thus, -size +10k finds all files that are larger than 10 Kbytes.

- -type character restricts the search to file types. The most important characters are f for regular files, d for directories and l for symbolic links.

- -user user.name or -n user.name finds files that belong (or do not belong) to the specified user.

# Actions when finding a file

- -exec command [options] \ calls the specified command and passes it the name of the file that has satisfied all criteria processed up to this point. The command can now check whether the file satisfies additional criteria. A typical command called through -exec is grep (see example below). {} acts as a placeholder for the file name, ; terminates the command call, that is, further find can be specified after it. \ is necessary within the shell to prevent ; from being interpreted as a special character.

- -print displays the names of the files found on screen. This option is the default setting as long as you do not use -exec.

- -printf format displays the names of the files found and other information on screen. The format character string can be used to specify how the output is to be displayed and which additional information is to be output (for example, file size, date of last modification, and so on). The syntax of the format character string is described in the man pages.

find is a relatively slow command, especially when the whole directory tree is to be searched. The commands Locate, where or often provide the same result in a much shorter time (see pages 463 and 489). If you have installed KDE, kfind provides a more user-friendly interface to find and grep.

# ALPHABETICAL COMMAND REFERENCE

# Examples

```
user find
```

supplies a list of all files in the current directory and in all subdirectories.

```
user find -name ".*"
```

find all files in the current directory and in all subdirectories whose names begin with ..

```
user find / -path /latex/*.tex
```

*.tex files in a directory that ends in latex. (This search pattern is sufficient to find the files contained in /usr/lib/texmf/latex in a relatively short time!)

```
root# find /home -group users -ctime 5
```

find all files (that belong to /home that belong to users of users' group and that have been modified in some way (contents, access rights, and so on) over the past five days, -ctime 5 finds files modified more than five days ago, -ctime 5 modified files exactly five days ago.)

```
user head -name ".e*
```

displays the first ten lines of .e files on screen. Please note that the search pattern is enclosed in left quotes, where the whole command as an argument of head. If you use another command instead of head, you can copy, delete, compress and do other things with the files found

```
user find -name ".tex" -type f -exec grep -exec emacs \; -print
```

search *.tex files for the character string 'emacs'. If the string is found, the file name is displayed on screen. Please note that the -print option must not be specified before -exec - otherwise all .tex file names are output, independently of whether emacs was found or not (also see grep on page 459).

```
user find -name "*" -maxdepth 1 -size -10k -exec grep -q \
> case.in {} \; -print
```

search all files in the current directory which are *smaller than 10 Kbytes for the regular expression *.in. The list of files found is stored in the file result. The restriction of the file size to 10 Kbytes is used to exclude the (much larger) binary files from the search.

# fsck [options] device

fsck checks the integrity of the file system. Depending on the options, it can repair errors.

- -A checks all file systems.

- -t specifies the file system type.

- -n answers all requests with no and does not carry out changes.

-p carries out repairs without asking for.

-y answers all requests with yes.

Before you execute fsck, please read the manual pages of these commands. It might well be the case that the online documentation is more up to date than this book. During the development of Linux, the organization and administration of the file system have already changed (improved) several times, which also has its effects on fsck. Further changes cannot be ruled out.

# grep [options] pattern file

grep searches the specified text files for a search pattern. Depending on the options used, the command subsequently displays the text passages or simply how many lines the search pattern was found. grep can be combined to search all files that satisfy certain conditions.

-n displays not only the line containing the text, but also the n lines preceding and following the line.

-c shows the number of lines in which the search pattern has been found, but not the lines themselves.

-f file_name reads the options from the specified file (for complex or frequently used search patterns).

-i does not differentiate between upper and lower case.

-l only displays the file names in which the search pattern has been found.

-q does not supply any on-screen display and merely returns the value 0 (text found) or 1 (not found). This option is useful when grep is called by other programs (see the find example on page 454).

-w only finds whole words. With this option, the search pattern 'grey' would no longer be recognized in 'greyhound'.

# Structure of the search pattern

The search pattern generally consists of two components: the characters to search for and the number of times these characters may occur:

+   abc the character string 'abc'

+   [abc] one of the characters a, b or c

+   [^abc] none of the characters a, b or c (thus, an arbitrary different character)

+   [a-z] one of the characters between a and z
