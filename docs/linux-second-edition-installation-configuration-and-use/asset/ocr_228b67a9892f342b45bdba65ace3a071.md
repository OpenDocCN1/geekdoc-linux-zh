The number of directory levels is variable. In addition, arbitrary number of browser windows can be opened. Inside the directory windows, several colors are used to identify the different file types.

In each directory list, files can be highlighted with the mouse button. With the middle mouse button, the highlighted files can be moved into another directory, even across browsers (drag and drop). The right mouse button leads to a context menu with various commands. tkdesk has its own simple editor which is also used to display text files.

Apart from easy and intuitive handling, tkdesk differs from other file managers because of a number of rather special features:

+   - When files are deleted, they are copied into a trash which can be emptied separately (via its own window). (Backup copies of homonymous files can, however, be only simply stored.)
- Important directories can be stored as bookmarks in a WWW browser.
- The DISK USAGE command provides a very clear display of the disk space usage of individual directories.
- tkdesk is in practice arbitrarily configurable.
- The file manager is equipped with excellent online help.
