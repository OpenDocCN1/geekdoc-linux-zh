# 278 X USER INTERFACES (FWWM, KDE, AND GNOME)

The most prominent difference is that the old .fwwmrc configuration files no longer be used. In order to facilitate the conversion, most distributions supply the fwm2 or fwm95 package together with the script fwmrc.convert which can be used to translate old configuration files into the new syntax.

Probably the most frequent adaptation request concerns the basic functions of the mouse. Many keywords known from fwm2 1.24 also exist in fwm2. However, these must now used with Style. The following two lines show how to set your most important modes:

```
Style " ClickFocus # window gets focus by clicking on it
Style " MouseFocus # window gets focus when mouse pointer
# is not over
```

If you use MouseFocus, it is useful that the active window is moved automatically into the foreground after a short period. This function is no longer performed by fwm2, but by the module FwmAuto. This module is activated via a line in the fwm configuration file.

```
Module FwmAuto 200 # move window with focus into
# foreground after 200 ms
```

The names of the configuration files have changed as:

```
/.fwwmrc (local)
/etc/x11/fwwm2/fwwmrc (global, Debian, RedHat)
/usr/X11/Lib/X11/fwm2/.fwwmrc (global, fwm default, SuSE)
```

fwm2 is extensively documented: the best man for fwm2, there is a highly informative FAQ text (in the RedHat distribution, it can be found in the /usr/doc/fwm2-2 directory).

# fwm95-2

Although, strictly speaking, fwm95-2 is only a variation of fwm2 (different default settings in the configuration file, an additional module to simulate the Windows launch bar), the visual difference is surprising. It suddenly looks like Windows 95 and behaves in the nearly same way. (It remains to see whether this is an advantage or not.) fwm95-2 does not presume fwm2. (Fwm2, however, usually comes with more online documentation, which also applies to fwm95-2).

The 95 is started in xinitrc or xsession by means of the command fwm95-2. The following files are used for the configuration.

```
/.fwwmrc95 (local)
/etc/x11/fwwm95-2/.fwwmrc95 (global, RedHat)
/usr/X11/Lib/X11/fwm95-2/system.fwm2rc95 (global, default)
```

In RedHat, fwm95-2 is the default window manager. The configuration is carried out through a whole range of files, which are processed by X at start-up ('Another Level', see page 267).
