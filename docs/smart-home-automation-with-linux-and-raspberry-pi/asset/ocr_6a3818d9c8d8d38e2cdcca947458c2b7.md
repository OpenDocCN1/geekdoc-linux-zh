The first GET request made by the app is for a file called “config.xml” in the root of the servers URL. The display is broken up into 6 x 6 areas (the index first referenced as the position on screen, in the command argument), reading left-to-right, then top-to-bottom, with each area being either a piece of text, a function button with an icon, or a link to another menu. In this case, our first menu (called zero) begins with a line of controls for the TV, which have various icon references, and is followed by a link to menu 1 (i.e., the second). The icon for the menu is predetermined.
