# Conclusion

With so many ways of communicating into and out of a system, you must begin with a solid framework. My method is to separate the input systems from the processing, allowing any input mechanism (mobile phone, e-mails, or web interface) to generate a command in a known common format that can be processed by a single script. In a similar way, all messages are sent to a single script that then formats the message in a particular format, suitable for the given communication channel. You can also add an automatic process on receipt of any, or all, of these messages. So, once you have to control a video, light switch, or alarm clock, you can process them in any order either e-mail your video, SMS your light switch, speak to your alarm clock, or any combination of these.
