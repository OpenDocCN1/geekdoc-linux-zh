Kali Linux 根深植于 `Debian`，被誉为一种稳健且高度自定义的操作系统，专为安全从业者定制。Kali Linux 背后的开发团队持续更新和维护该发行版，以确保其处于快速发展的网络安全格局的前沿。

Kali Linux 的主要区别之一在于其预装的安全工具和实用程序的完整集合，涵盖了多个类别，如网络分析、Web 应用评估、无线渗透测试和数字取证。这些工具使用户能够执行各种任务，从识别目标系统中的漏洞到在控制环境中模拟网络攻击。

## 第 3 章：文件系统导航与管理
要导航文件系统，使用 `cd` 更改目录。例如，`cd /home/user` 将你带到主目录。使用 `ls` 列出当前位置的文件和目录。

## 第 5 章：用户与权限管理
权限对于安全至关重要。使用 `chmod` 修改权限（读、写、执行）并使用 `chown` 更改所有者。

```bash
chmod 755 script.sh
chown user:group file.txt
```

## 第 6 章：使用 APT 管理软件包
`APT` 是基于 Debian 的系统的软件包管理器。使用 `apt update` 刷新软件包列表，使用 `apt install` 安装新软件。

```bash
sudo apt update
sudo apt install curl
```

## 第 7 章：进程控制与监控
使用 `top` 或 `htop` 监控运行进程。使用 `kill` 或 `killall` 终止进程。

```bash
top
kill -9 1234
```

## 第 8 章：处理文本和流
使用 `cat` 查看文件内容，使用 `grep` 搜索模式，使用 `sed` 或 `awk` 进行文本处理。使用管道 (`|`) 在命令之间传递输出。

```bash
cat file.txt | grep "error"
```

## 第 9 章：基础脚本与自动化
创建脚本以自动化重复性任务。始终以 shebang（如 `#!/bin/bash`）开头。

```bash
#!/bin/bash
echo "Hello World"
```
