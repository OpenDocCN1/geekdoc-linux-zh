21. Click OK. The next panel will display (Figure 17). This panel is used to select the printer drivers for the printer you are using.

22. To select printer drivers:

+   A. Scroll down the list of printer drivers until you find one you want to install, then click to highlight it. To select more than one driver, hold down the Ctrl key while clicking.
+   B. Click Select to select the printers. An asterisk will appear next to each selected driver in the list.

or

Scroll down the list of printer drivers until you find one you want to install, then double-click to select it. An asterisk will appear next to the selected printer driver.

23. To view the list of printer drivers you have selected, click List. The Selected Entries dialog box will open (Figure 18).

24. When you have finished viewing the list, click OK to close the Selected Entries dialog box and return to the Install Configuration window.

25. To remove a printer driver you have chosen, scroll through the list to find that printer driver, then double-click on it.

26. To remove all selected printer drivers, click None in the Install Configuration window.

27. When you have finished selecting printer drivers, click OK. The next panel will appear (Figure 19). This panel is used to assign the printer drivers to the printer installed on your Linux computer.
