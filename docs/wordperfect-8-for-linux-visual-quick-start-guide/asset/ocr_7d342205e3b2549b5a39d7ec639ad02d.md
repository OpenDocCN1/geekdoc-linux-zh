# Paragraph Spacing

You can also set the amount of space between paragraphs.

# To set the space between paragraphs:

+   1. Position the insertion point where you want the line spacing change to begin.
+   
+   or
+   
+   Select the paragraph(s) you want to change.

+   2. Choose Format from the Paragraph fly-out on the Format menu (Figure 46). The Paragraph Format dialog box will open (Figure 47).

+   3. Use the Spacing Between Paragraphs text box to set the number of lines you want between the paragraphs. A preview of the number of lines you’ve entered will appear in the preview pane.

+   4. Click OK to return to your document.

# Tip

+   If you want to change the paragraph spacing for an entire document, press Ctrl+Home on the keyboard to move to the top of the document, then follow the steps outlined above.
