## 图 14. 单击要在其区域使光标处于活动状态旁边的单选按钮。

- Margins——阴影光标将吸附到左侧或右侧边距，或吸附到边距之间的页面中心。如果你在空白处单击，插入点将吸附到这些位置之一。
- Tabs——阴影光标将吸附到当前制表符设置。如果你在空白处单击，插入点将吸附到最近的制表符。当你输入文本时，它将从该位置继续，直到行尾然后换行到下一行的开头。
- Indent——阴影光标将吸附到当前制表符设置。如果你在空白处单击，插入点将吸附到最近的制表符。当你输入文本时，它将从该位置继续，直到行尾，然后换行到缩进位置。
- Spaces——阴影光标将吸附到最近的空格。如果你在空白处单击，插入点将出现在该位置。

6. 要设置你希望阴影光标处于活动的位置，请在“Active in”列表中选择一个项目旁边的单选按钮（图 14）。你可以将光标设置为仅在文本或空白处出现，或将其设置为在两个区域都出现。

7. 完成选择选项后，单击 OK 关闭 Display Preferences 对话框。

8. 单击 OK 关闭 Preferences 对话框并返回到文档窗口。

## 移动插入点

你也可以使用键盘上的箭头键在文本中移动插入点。 （你不能使用键盘在空白处移动插入点，只能使用阴影光标。）

### 使用键盘移动插入点：

使用适当的箭头键向你想要的方向移动。例如，如果你按下上箭头键，↑，插入点将向上移动一行；如果你按下右箭头键，→，插入点将向右移动一个字符。有许多按键和组合。其中一些列在下一页的侧边栏中。

## 插入和删除文本

使用 WordPerfect，你可以随时向文档中添加或删除文本。

### 插入文本：

- 1. 使用阴影光标或键盘按键将插入点移动到你想要添加文本的位置（图 15）。
- 2. 输入你想要添加的文本（图 16）。

### 提示

当你向现有文本添加字符时，插入点右侧的任何文本都会自动向右移动，为新字符腾出空间，并且自动换行会自动调整文本行。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_68_0.png)

图 17. 将插入点定位到你想要删除文本的位置。如果你按下 Backspace 键，插入点右侧的文本将被删除。如果你按下 Delete 键，插入点左侧的文本将被删除。

### 删除文本：

- 1. 使用阴影光标或键盘按键将插入点移动到你想要删除文本的位置（图 17）。
- 2. 按键盘上的 Backspace 键删除插入点右侧的字符。
  或
- 按键盘上的 Delete 键删除插入点左侧的字符。

### 提示

当文本被删除时，插入点右侧的任何文本都会自动向左移动以关闭被删除字符留下的空间。自动换行会自动调整文本行。

## 有用的按键

下面是一些可用于快速在文档中移动的按键列表。如果列出了键组合，例如 Ctrl+↑，请在按下 ↑ 键之前先按下 Ctrl 键。

| 按键 | 移动到 | 按键 | 移动到 |
|---|---|---|---|
| ↑ | 向上移动一行 | Home | 行首 |
| ↓ | 向下移动一行 | End | 行尾 |
| ← | 向左移动一个字符 | Page Up | 向上移动一页或到文档窗口顶部 |
| → | 向右移动一个字符 | Page Down | 向下移动一页或到文档窗口底部 |
| Ctrl+↑ | 向上移动一个段落 | Ctrl+Home | 文档开头 |
| Ctrl+↓ | 向下移动一个段落 | Ctrl+End | 文档末尾 |
| Ctrl+← | 向左移动一个词 |  |  |
| Ctrl+→ | 向右移动一个词 |  |  |
