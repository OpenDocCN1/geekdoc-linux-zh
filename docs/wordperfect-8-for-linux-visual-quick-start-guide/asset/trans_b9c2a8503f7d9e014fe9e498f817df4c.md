

## 向工具栏添加宏按钮：

1. 右键单击要添加宏按钮的工具栏。
2. 从快捷菜单中选择“编辑”（图 11）。该工具栏的“工具栏编辑器”对话框将打开，并选中“激活功能”选项按钮（图 12）。
3. 选择“播放宏”旁边的单选按钮。对话框将变为显示“添加宏”按钮（图 13）。
4. 单击“添加宏”。将出现“选择宏”对话框（图 14）。
5. 单击“宏名”文本框旁边的列表按钮。将打开“选择文件”对话框，并显示 WordPerfect 默认宏目录（图 7）。
6. 使用“目录列表”框移动到存储宏的目录，然后使用“文件列表”框选择宏。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_219_0.png)

图 11. 右键单击要添加按钮的工具栏，然后从快捷菜单中选择“编辑”。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_219_2.png)

图 12. “工具栏编辑器”对话框打开，并选中“激活功能”单选按钮。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_219_1.png)

图 13. 当您单击“播放宏”单选按钮时，对话框中将出现“添加宏”按钮。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_220_0.png)

图 14. 单击“宏名”文本框旁边的列表按钮，选择要分配给工具栏的宏。

7. 单击“确定”。“选择文件”对话框将关闭，返回到“选择宏”对话框。所选宏文件的完整路径将输入到文本框中。
8. 单击“选择”。将打开一个“工具栏”对话框，询问是否要保存带完整路径名的宏（图 15）。
9. 单击“是”。“工具栏”和“选择宏”对话框将关闭，返回到“工具栏编辑器”对话框。工具栏上将出现一个带有盒式磁带图标的按钮（图 16）。
10. 单击“确定”关闭“工具栏编辑器”对话框并返回到文档窗口。您的自定义宏按钮已准备就绪！

### 提示

- 在第 5 步中，如果您选择的宏保存在 WordPerfect 默认目录（/wp/wp macros）中，则不会出现“工具栏”对话框（图 15）。

- 您还可以使用“工具栏编辑器”为几乎每个 WordPerfect 命令添加按钮到任何您想要自定义的工具栏。如果您多次使用某个特定命令，这会非常有帮助。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_220_1.png)

图 15. 单击“是”以完整路径保存宏。如果宏位于 WordPerfect 默认目录 /wp/wp macros 以外的目录中，则此操作是必需的。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_220_2.png)

图 16. 新的宏按钮出现在工具栏上，可供您单击。试试吧！如果需要，请定位插入点，然后点击宏按钮，观看宏播放！

## 将宏分配到键盘快捷键：

1. 在程序窗口中选择“首选项”（图 17）。将打开“首选项”对话框（图 18）。
2. 单击“键盘”。将打开“键盘首选项”对话框（图 19）。您正在使用的键盘将在“键盘”列表框中选中。
3. 单击“创建”。将出现“创建键盘”对话框（图 20）。
4. 在“新建键盘名称”对话框中为您自定义的键盘输入名称。例如，您可以使用您的姓名，或描述键盘个性化特征的名称。
5. 单击“确定”。“创建键盘”对话框将关闭，“键盘编辑器”对话框将打开（图 21）。
6. 在“选择要分配或取消分配的键”区域中，使用下拉列表选择将播放宏的按键组合。此列表框分为两列（图 22）。左列显示按键，右列显示分配给该按键的内容。如果某按键右侧的列中没有内容，则该按键未分配。务必选择未分配的按键。例如，本例中选择了 F12+Ctrl，因为它是一个未分配的按键。
