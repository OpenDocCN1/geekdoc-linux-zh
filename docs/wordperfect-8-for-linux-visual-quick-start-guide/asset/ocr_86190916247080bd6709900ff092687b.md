# Performing the Merge

Now that you have created both the data file and the form file, it's time to perform the merge and create a third file that contains all the personalized copies of the form file.

# To perform the merge:

+   1. Choose Merge from the Tools menu (Figure 1). The Merge dialog box will open (Figure 2).
+   2. In the Perform Merge area (Figure 18), click Merge. The Perform Merge dialog box will appear (Figure 19).
+   3. To select the form file:
+      A. Click the list button next to the Form File text box and choose Select File from the drop-down list (Figure 20). The Select Form File dialog box will appear (Figure 21).
+      B. Use the Directory List and File List boxes to select the form file that you created.
+      C. Click OK. The Select Form File dialog box will close, returning you to the Perform Merge dialog box.
