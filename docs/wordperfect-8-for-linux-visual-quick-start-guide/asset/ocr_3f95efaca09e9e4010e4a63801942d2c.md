# To select a paragraph:

Position the mouse over the paragraph you want to select, and then triple-click.

or

Position the insertion point within the paragraph, then choose Paragraph from the Select fly-out on the Edit menu (Figure 28).

![](bbox=[0.05, 0.07, 0.45, 0.27])

Figure 28. Choose Paragraph from the Select fly-out on the Edit menu.

# To select the contents of a page:

+   1. Position the insertion point on the page you want to select.
+   2. Choose Page from the Select menu on the Edit fly-out (Figure 29).

![](bbox=[0.05, 0.45, 0.45, 0.65])

Figure 29. Choose Page from the Select fly-out on the Edit menu.

# To select the contents of a document:

Choose All from the Select fly-out on the Edit menu (Figure 30).

![](bbox=[0.05, 0.73, 0.45, 0.92])

Figure 30. Choose All from the Select fly-out on the Edit menu.

# Use the QuickMenu to Select

You can also use the QuickMenu to select portions of your text. To do so, position the insertion point within a sentence, paragraph or page. Next, move the mouse pointer over to the left margin, and then right click. The QuickMenu will appear (see below). Choose the desired selection from the QuickMenu.
