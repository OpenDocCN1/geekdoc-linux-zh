# To obtain a license number for the free version:

+   1. In your Internet browser, open http://venus.corel.com/nasapps/wp811nxreg/register.html. Corel's Linux registration Web site will open (Figure 36).
+   2. Fill out the registration form.
+   3. Click Submit. Your license number will appear on the next page.
+   4. Write down the license number or print the Web page.
+   5. Enter the license number when prompted during the installation or enter the number in the initial box when you launch WordPerfect.
