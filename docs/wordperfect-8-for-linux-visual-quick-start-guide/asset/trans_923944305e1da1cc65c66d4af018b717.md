## 段落格式

段落格式（顾名思义）应用于整段文本。WordPerfect 允许您更改几乎所有可以想到的段落属性，从对齐方式、制表位和缩进到行距和段落间距。

### 设置段落对齐方式：

- 1. 将插入点定位在您希望对齐开始的位置。（这将影响插入点所在的段落以及后续所有段落。）
- 或
- 选择您想要对齐的段落。

- 2. 单击属性栏上的对齐按钮，从下拉列表中选择一种对齐方式（图 40）。
- 或
- 从格式菜单上的对齐弹出菜单中选择一种对齐类型（图 41）。

Figure 40. 从属性栏上的下拉列表中选择对齐方式。
