# Key to the WordPerfect 8 Screen

1A–B Title Bar
Displays the program name and current document name.

2 Menu Bar
Click any menu title to access commands fly-outs, and dialog boxes, as well as the various toolbars, views, and Ruler Bar.

3 WordPerfect 8 Toolbar
One of the sixteen toolbars, the WordPerfect 8 Toolbar buttons and drop-down lists give you quick access to standard word processing commands such as New, Open, Save, Print, Cut, Copy, Paste, Undo, and Redo. It also includes several WordPerfect 8 commands such as Create Columns and Create Table.
