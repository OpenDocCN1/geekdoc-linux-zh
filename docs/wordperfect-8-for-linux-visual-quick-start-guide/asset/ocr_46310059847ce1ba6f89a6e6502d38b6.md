# Making Your Macros
Easy to Play

There are two places you can put a macro to make it easy to find and play. You can add a macro to a toolbar or assign a keyboard shortcut. This means that every time you want to play the macro, all you have to do is click a toolbar button or press the appropriate keys on the keyboard.

To add a macro to a toolbar, you will first need to display the toolbar you want to add the macro button to, then edit that toolbar.

# To display a toolbar:

+   1. Choose Toolbars from the View menu (Figure 8). The Toolbars dialog box will open (Figure 9).
+   
+   2. From the Available toolbars list box, select the toolbar you want to view.
+   
+   3. Click OK. The toolbar will appear at the top of the document window.

*or*

Right click on a toolbar and choose the toolbar you want to open from the QuickMenu that appears (Figure 10). The toolbar will appear at the top of the document window.
