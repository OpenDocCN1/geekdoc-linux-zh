Chapter 5, Formatting Your Text, showed you how to add text to documents. This chapter takes text one step further, adding advanced formatting techniques that bring organization, a professional look, and creative flair to your documents. Topics covered here range from changing text color and adding bullets and drop caps to setting columns and styles.

# To change text color:

+   1. Select the text you want to change.
+   2. Click the Font Color button on the Property Bar and choose a color from the palette (Figure 1). The text will change to the color you selected.

or

+   1. Select the text you want to change.
+   2. Choose Font from the Format menu (Figure 2). The Font dialog box will open (Figure 3).
