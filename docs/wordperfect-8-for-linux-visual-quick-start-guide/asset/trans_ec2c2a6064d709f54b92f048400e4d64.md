

## 垂直文本对齐

设置好上下边距后，您还可以告诉 WordPerfect 将页面上的文本垂直居中。

### 要在上下边距之间居中文本：

1. 将插入点定位到包含要居中文本的页面上。
2. 从格式菜单的页面下拉列表中选择居中（图 18）。将出现居中页面(s)对话框（图 19）。
3. 在居中区域，您可以选中单选按钮以设置 WordPerfect：
   - 将文本居中于当前页面
   - 将文本居中于当前页面及当前页面之后的任何页面
   - 不将页面上的文本居中
4. 选择选项后，单击确定。对话框将关闭，文本将移动到页面的垂直中心（图 20）。

### 提示

要在一页上关闭垂直文本居中，请将插入点定位到该页面上，打开居中页面(s)对话框，然后在居中区域中选择无居中选项。

## 页眉和页脚

页眉和页脚通常用于在文档的每一页或交替页面顶部或底部放置日期、页码、标题或公司名称。

WordPerfect 允许您在文档的任何位置使用两个不同的页眉——页眉 A 和页眉 B——以及两个不同的页脚——页脚 A 和页脚 B。页面上同时只能激活两个页眉和两个页脚。

### 要创建页眉或页脚：

1. 将插入点定位到要使页眉或页脚首次出现的页面的第一个段落中。
2. 从插入菜单中选择页眉/页脚（图 21）。将打开页眉/页脚对话框（图 22）。
3. 在选择区域，单击要创建的页眉或页脚旁边的单选按钮。
4. 单击创建。对话框将关闭，页眉或页脚指南将出现在文档顶部或底部（图 23）。插入点将定位在页眉或页脚内，准备输入。属性栏上将出现特殊的页眉/页脚命令按钮（图 24）。
5. 像平常一样输入您的页眉或页脚文本，使用您想要的任何格式或编辑功能。
6. 单击属性栏上的页眉/页脚距离按钮。距离对话框将打开（图 25）。使用文本与页眉（或页脚）之间的距离文本框设置确切距离。

7. 单击确定关闭距离对话框。页眉或页脚指南将移动以指示您设置的距离测量值。
8. 单击属性栏上的页眉/页脚放置按钮。放置对话框将打开（图 26）。
9. 使用放置于区域中的单选按钮设置页眉或页脚是否出现在奇数页、偶数页或每一页上。
10. 单击确定关闭放置对话框。
11. 完成创建页眉或页脚后，单击属性栏上的关闭页眉/页脚按钮或单击文档窗口中页眉或页脚区域外的任意位置。插入点将返回到文档的主体部分。
