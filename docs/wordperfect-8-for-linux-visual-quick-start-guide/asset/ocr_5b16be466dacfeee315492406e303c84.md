# Exiting WordPerfect

Shutting down WordPerfect is very easy. There are three ways to do it.

# To exit WordPerfect 8 for Linux:

With the document window active, press Ctrl+Shift+F4 on the keyboard.

or

Choose Exit from the Program menu in the program window (Figure 61)

![](bbox=[0.55, 0.1, 0.8, 0.4])

or

Click the Close button in the upper right-hand corner of the program window (Figure 62).

![](bbox=[0.55, 0.5, 0.8, 0.75])
