# To perform a QuickSum:

+   1. Position the insertion point in the cell below the column where you would like the sum to appear (Figure 54).
+   
+   2. Click the Table menu on the Property Bar and choose QuickSum (Figure 55). The column of numbers will be added up and the result will appear in the text box (Figure 56).
