# To join cells:

+   1. Select the cells you want to join (Figure 22). (The cells must be right next to each other.)
+   2. Click the Table menu on the Property Bar and choose Cell from the Join fly-out (Figure 23). The cells will join together (Figure 24).

# To split a table:

+   1. Position the insertion point in the row that you want to become the top row of the new table (Figure 25).
+   2. Click the Table menu on the Property Bar and choose Table from the Split fly-out (Figure 26). The table will split into two (Figure 27).
