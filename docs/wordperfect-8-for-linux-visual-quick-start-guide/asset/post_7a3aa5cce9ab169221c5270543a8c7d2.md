## Unmounting the CD-ROM

To finish up, you need to unmount the CD-ROM.

## To unmount the CD-ROM:

- 1. Choose Disk Management from the System fly-out on the Gnome main menu (Figure 1). The User Mount Tool dialog box will open (Figure 26).
- 2. Click the Unmount button found to the right of your computer's CD-ROM location. In Figure 2 this location is /mnt/cdrom. The CD-ROM drive will unmount and the button you just clicked will read "Mount."
- 3. Click Exit to close the dialog box.
