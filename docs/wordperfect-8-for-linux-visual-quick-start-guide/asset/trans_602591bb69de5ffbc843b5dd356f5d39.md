

## 使用标尺栏编辑列：

- 1. 将插入点定位在要更改的列中。
- 2. 如果标尺栏尚未显示，请从视图菜单中选择标尺以显示它（图 49）。
- 3. 拖动列宽度标记以更改列的宽度（图 50）。（您也可以拖动制表符设置以更改其在列中的位置。）
- 4. 拖动边距标记以更改列中左右边距的位置（图 51）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_144_1.png)

## 提示

- 要快速打开“定义列”对话框，请右键单击标尺栏，然后从出现的快速菜单中选择“列”（图 52）。

## 在列中输入文本：

将插入点定位在列中并键入文本。要移动到下一列，请在键盘上按 Ctrl+Enter。

## 在列之间移动插入点：

在要移动到的列中单击鼠标。

## 关闭列：

- 1. 将插入点定位在要关闭列的位置。
- 2. 从格式菜单中选择“列”（图 39）。“定义列”对话框将打开（图 47）。
- 3. 单击“停止”。对话框将关闭。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_144_2.png)

## 为文本框添加边框和填充：

- 1. 单击要更改的文本框以选中它。当它被选中时，您会看到其周围出现虚线。
- 2. 单击属性栏上的“边框”按钮并从下拉列表中选择一种边框样式（图 56）。
- 3. 单击属性栏上的“填充”按钮并从下拉列表中选择一种填充（图 57）。

## 使用手柄调整文本框大小：

- 1. 单击要更改的文本框以选中它。当它被选中时，您会看到其周围出现虚线。
- 2. 将鼠标指针定位在八个手柄中的一个上。
- 3. 按住鼠标左键并拖动手柄以调整框的大小（图 58）。
- 4. 拖动手柄完成后释放鼠标按钮。

## 将文本框调整为精确尺寸：

- 1. 单击空白处以确保文档中没有选中任何内容。
- 2. 右键单击要调整大小的文本框并从出现的快速菜单中选择“大小”（图 59）。“框大小”对话框将打开（图 60）。
- 3. 在“宽度”和“高度”区域中，您有以下选项：
  - 设置使文本框的宽度或高度完全等于您在文本框中输入的测量值
  - 全部将文本框拉伸到页面的整个宽度（从左到右边距）或高度（从上到下边距）。如果您在“宽度”和“高度”区域都选择“全部”，文本框将覆盖整个页面。
  - 保持比例——当在其中一个区域选中此选项并且在另一个区域设置了精确测量值时，文本框将调整大小以保持其原始的宽高比例。
- 4. 完成设置文本框的宽度和高度后，单击“确定”。“框大小”对话框将关闭，文本框将更改为新的大小。

## 移动文本框：

- 1. 单击要更改的文本框以选中它。当它被选中时，您会看到其周围出现虚线。
- 2. 将鼠标指针定位在文本框的边框上。
- 3. 按住鼠标左键并将文本框拖动到新位置（图 61）。

## 为文本框添加标题：

- 1. 单击空白处以确保文档中没有选中任何内容。
- 2. 右键单击文本框并从出现的快速菜单中选择“标题”（图 62）。“框标题”对话框将打开（图 63）。
- 3. 在“标题位置”区域（图 64）中，使用：
  - “框侧”下拉列表设置标题出现的位置——顶部、底部、左侧或右侧。
  - “边框”下拉列表设置标题将出现在边框之外、之上还是之内。
  - “位置”下拉列表将标题左对齐、居中对齐或右对齐。
- 4. 在“标题宽度”区域（图 65）中，选择以下选项之一：
  - 自动宽度将标题设置为文本框的宽度。
  - 固定可让您精确设置标题的宽度。
  - 百分比可让您设置标题相对于文本框的宽度。50% 的设置意味着标题将为文本框宽度的二分之一。
- 5. 在“旋转标题”区域中，您可以选择文本不旋转，或旋转 90、180 或 270 度。
- 6. 完成选择选项后，单击“编辑”。“框标题”对话框将关闭，插入点将定位在新的标题区域中。
- 7. 要输入标题，请键入文本。
- 8. 完成后，单击标题外的区域返回到文档。
