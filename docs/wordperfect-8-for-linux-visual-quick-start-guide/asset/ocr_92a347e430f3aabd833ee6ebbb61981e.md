# Starting a New Document

When you start a new document, you can either open the new document and close the current document at the same time, or start a new document window while keeping the current one open.

# To start a new document and close the current document:

+   1. Choose New from the File menu (Figure 19). A new document will open. If you have made changes to the current document, a Save dialog box will appear asking if you want to save the changes (Figure 20).
+   2. You can:
+      - Click Yes to save the current document before closing it;
+      - Click No to close the current document without saving it; or
+      - Click Cancel to cancel the new document command, and return to the active document.

# To start a new document and keep the current one open:

Using the program window, choose New Window from the Program menu (Figure 21) or press Ctrl+N on the keyboard. A new window will open on top of the active window.

# Document Windows Roll Up

If you are working on several documents at once and want to get one out of the way, double-click on the Title Bar. The document window will roll up. Double-click on the Title Bar again to unroll the document window.
