# Drop Caps

A drop cap is an enlarged letter or word at the beginning of a paragraph that draws a reader's attention in a visually inviting way. Drop caps can be created as you type or added to text that has already been entered.

# To create a drop cap:

+   1. Position the insertion point at the beginning of the new paragraph where you would like the drop cap to appear.
+   
+   or
+   
+   Position the insertion point in an existing paragraph to which you would like to add a drop cap.

+   2. Choose Drop Cap from the Paragraph fly-out on the Format menu (Figure 21). The insertion point will enlarge, ready for you to type the drop cap. The Property Bar will change to display special drop-cap commands (Figure 22).

+   3. Click the Drop Cap Style button on the Property Bar and select a predefined drop cap style (Figure 23).

+   4. Click the Drop Cap Height button on the Property Bar and set how many lines high the drop cap will be (Figure 24).
