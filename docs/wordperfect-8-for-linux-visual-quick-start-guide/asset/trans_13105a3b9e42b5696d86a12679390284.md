

## 快速在页眉和页脚之间移动：

将插入点定位在页眉或页脚中，然后单击“上一个页眉/页脚”按钮。

或

属性栏上的“下一个页眉/页脚”按钮。

## 编辑页眉或页脚：

- 1. 在要编辑的页眉或页脚内任意位置单击。
- 2. 如同编辑普通文本一样编辑页眉或页脚文本（图 27）。
- 3. 单击属性栏上的“关闭页眉/页脚”按钮，或在页眉或页脚区域之外单击文档窗口。插入点将返回到文档的主体部分。

## 关闭页眉或页脚：

- 1. 将插入点定位在要关闭页眉或页脚的页面上（不要将插入点放在页眉或页脚中）
- 2. 打开“页眉/页脚”对话框（图 28），方法是选择“插入”菜单中的“页眉/页脚”（图 21）。
- 3. 使用“选择”区域选择要关闭的页眉或页脚。
- 4. 单击“停止”。
- 5. 单击“确定”。对话框将关闭，并且页眉或页脚将不再出现在当前页面之后的任何页面上。

## 在页眉或页脚中添加日期：

创建新的页眉或页脚或编辑现有页眉或页脚，将插入点定位在要放置日期的位置，然后按键盘上的 Ctrl+D。

## 添加页码：

- 1. 将插入点定位在要开始编号的页面上。
- 2. 在“格式”菜单上的“页面”下拉菜单中的“页码编号”下拉菜单中选择“编号”（图 29）。“页码编号”对话框将出现（图 30）。
- 3. 使用“位置”下拉列表设置页码在页面上的出现位置。下拉列表下方预览区域中将显示定位预览。
- 4. 若要为页码设置与默认文档字体不同的字体，请单击“字体”按钮并使用“页码编号字体”对话框（图 31）。
- 5. 单击“确定”。页码将出现在您的文档中。

## 在页眉或页脚中工作时插入页码

当您在页眉或页脚中工作时，可以快速向文档添加页码。将插入点定位在页眉或页脚内部，单击属性栏上的“页码”按钮（图 24）。

## “隐藏”命令

您可以使用“隐藏”命令告诉 WordPerfect 在特定页面上隐藏页眉、页脚或页码。

## 在特定页面上隐藏页眉、页脚或页码：

- 1. 将插入点移动到要隐藏页眉、页脚或页码的页面。
- 2. 在“格式”菜单上的“页面”下拉菜单中选择“隐藏”（图 32）。“隐藏”对话框将打开（图 33）。
- 3. 使用“在当前页面隐藏”区域设置要隐藏的项目——页眉、页脚或页码编号。
- 4. 单击“确定”。您选择的项目将在该特定页面上被隐藏。

## 应用程序栏

图 35. 从“视图”菜单中选择“工具栏”以打开“工具栏”对话框。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_164_0.png)

应用程序栏显示在文档窗口底部（图 34）。它让您可以快速查看与正在处理的文档相关的信息。默认情况下，应用程序栏显示您正在使用的字体、插入点的位置、有关列、合并或表格的信息（如果您使用这些功能），以及您处于插入模式还是改写模式。

您也可以随意显示或隐藏应用程序栏，并自定义其显示的信息。

## 显示/隐藏应用程序栏：

- 1. 从“视图”菜单中选择“工具栏”（图 35）。“工具栏”对话框将出现（图 36）。
- 2. 若要显示应用程序栏，请在“可用工具栏”列表框中选中“应用程序栏”旁边的复选框。若要隐藏应用程序栏，请取消选择“应用程序栏”项。
- 3. 单击“确定”。应用程序栏将出现或消失。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_164_1.png)
