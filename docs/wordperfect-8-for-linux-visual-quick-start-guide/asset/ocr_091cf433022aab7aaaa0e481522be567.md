6. To add or change a chart title.

+   A. Choose Titles from the Options menu (Figure 57). A Titles dialog box will open (Figure 58).
+   B. Enter the title of the chart in the Title text box.
+   C. If your chart has a subtitle or title for the x and y axes, enter that information in the appropriate text boxes.
+   D. Click Preview to see the changes you have made in the preview area (Figure 59). If you like what you see, click OK to close the dialog box. Otherwise, you can continue working in the Titles dialog box.
