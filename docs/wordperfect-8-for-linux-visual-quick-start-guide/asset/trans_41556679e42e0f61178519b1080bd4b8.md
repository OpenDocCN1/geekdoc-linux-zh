## 使用 QuickList：

+   1. 从“文件”菜单中选择“打开”（图 54）。将出现“打开”对话框（图 55）。
+   2. 在 QuickList 框中，突出显示要打开的文件，或双击要快速转到的目录，然后从“文件列表”框中选择一个文件。
+   3. 单击“打开”以打开文件。

## 保存工作区

您可以设置工作区选项，以始终打开新文档、询问您是否要保存工作区，或在未经询问的情况下自动保存工作区。

## 保存工作区：

+   1. 在文档打开的情况下，在程序窗口中选择“首选项”（图 58）。将打开“首选项”对话框（图 59）。
+   2. 单击“环境”按钮。将打开“环境首选项”对话框（图 60）。
+   3. 在“保存工作区”区域中，为要选择的项目选择单选按钮：
    - 始终自动保存您的工作区，无需询问；
    - 从不总是打开新文档窗口（默认）；
    - 退出时提示询问您是否要保存工作区。
+   4. 单击“确定”关闭“环境首选项”对话框。
+   5. 单击“关闭”关闭“首选项”对话框。

## 退出 WordPerfect

关闭 WordPerfect 非常简单。有三种方法可以做到。

## 退出适用于 Linux 的 WordPerfect 8：

在文档窗口处于活动状态时，按键盘上的 Ctrl+Shift+F4。

或者

在程序窗口的“程序”菜单中选择“退出”（图 61）

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_61_0.png)

或者

单击程序窗口右上角的“关闭”按钮（图 62）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_61_1.png)
