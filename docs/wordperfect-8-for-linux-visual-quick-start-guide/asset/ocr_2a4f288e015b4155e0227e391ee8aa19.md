# To add a paragraph border and fill:

+   1. Position the insertion point within the paragraph to which you want to add the border
+   2. Choose Border/Fill from the Paragraph fly-out on the Format menu (Figure 36). The Paragraph Border dialog box will open (Figure 37).
+   3. Click the button next to Border Style and select a border from the drop-down list (Figure 33).
+   4. If you wish to add a fill, click the button next to Fill Options and select a fill from the drop-down list (Figure 34).
+   5. Make sure the check box next to Apply border to current paragraph only is selected. Otherwise, a border will appear around every subsequent paragraph in the document.
+   6. Click OK. The border will appear around the paragraph (Figure 38).
