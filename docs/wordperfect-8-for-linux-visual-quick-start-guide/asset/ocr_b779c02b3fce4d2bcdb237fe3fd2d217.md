# To set a new default font for all new documents:

+   1. Choose Font from the Format menu (Figure 21) or press F9 on the keyboard. The Font dialog box will open (Figure 22).
+   2. Click Initial Font. The Document Default Font dialog box will open (Figure 24).
+   3. Use the Font Face list box to select a font.
+   4. Use the Font Size list box to select a size.
+   5. Make sure the box next to Set as Printer Initial Font is selected (Figure 25).
+   6. When you have finished selecting the new default font, click OK to return to the Font dialog box.
+   7. Click OK to return to the document. The next time you start a new document, the font you selected will be the default font.
