

## 更改表格形状

许多时候，表格中的信息会在表格创建过程中不断扩展。可能需要新的列或行，或者信息难以放入标准表格设置中，需要拆分或合并单元格。事实上，如果需要的话，你甚至可以拆分整个表格。

### 添加行或列到表格：

- 1. 将插入点定位在要添加列或行位置的相邻列或行中。
- 2. 单击属性栏上的表格菜单并选择插入（图 14）。
  或
  右键单击表格并从快速菜单中选择插入（图 15）。
  插入列/行对话框将打开（图 16）。
- 3. 在插入区域，选择列或行的单选按钮，然后在相应的文本框中输入要插入的列数或行数。
- 4. 在放置区域，选择单选按钮以设置行或列将出现在插入点所在行或列之前还是之后。
- 5. 单击确定。插入列/行对话框将关闭，新的列或行将被添加到表格中（图 17）。

### 提示

当你在插入列/行对话框中工作时，表格的当前大小会显示在表格大小区域中。

### 拆分单元格：

- 1. 将插入点放在要拆分的单元格中（图 18）。
- 2. 单击属性栏上的表格菜单并从拆分飞出菜单中选择单元格（图 19）。拆分单元格对话框将打开（图 20）。
- 3. 选择列或行旁边的单选按钮，并使用相应的文本框输入要将单元格拆分为的列数或行数。
- 4. 单击确定。拆分单元格对话框将关闭，单元格将按你指定的方式拆分（图 21）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_187_2.png)

图 20. 在拆分区域，选择是否要将单元格水平拆分为列或垂直拆分为行，然后在相应的文本框中输入数字。

### 合并单元格：

- 1. 选择要合并的单元格（图 22）。（单元格必须紧挨着彼此。）
- 2. 单击属性栏上的表格菜单并从合并飞出菜单中选择单元格（图 23）。单元格将合并在一起（图 24）。

### 拆分表格：

- 1. 将插入点定位在要成为新表格顶行的行中（图 25）。
- 2. 单击属性栏上的表格菜单并从拆分飞出菜单中选择表格（图 26）。表格将被拆分为两个（图 27）。
