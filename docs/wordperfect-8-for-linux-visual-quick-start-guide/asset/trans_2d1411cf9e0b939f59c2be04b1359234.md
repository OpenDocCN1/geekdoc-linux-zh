

## 创建编号列表：

- 1. 将插入点定位到你想要编号列表开始的位置。
- 2. 从“插入”菜单中选择“项目符号和编号”（图 14）。“项目符号和编号”对话框将打开（图 15）。
- 3. 在“样式”列表框中突出显示一种数字类型（图 18）。
- 4. 选中“起始值”旁边的复选框，并在文本框中输入一个数字（图 19）。
- 5. 如果你希望在键盘上按下 Enter 键时出现新的项目符号，请选中“按 ENTER 时新建项目符号或编号”旁边的框。
- 6. 单击“确定”关闭对话框。随着你输入文本，数字将出现在你的文档中（图 20）。

## 提示

- 要为现有文本添加编号，请选择你想要添加编号的文本，然后按照上述步骤 2–6 操作。
- 要关闭编号，请打开“项目符号和编号”对话框，并在“样式”列表框中突出显示 <无>，然后单击“确定”关闭对话框。

## 首字下沉

首字下沉是段落开头放大字母或单词，以一种视觉上吸引人的方式吸引读者的注意。首字下沉可以在输入时创建，也可添加到已输入的文本中。

## 创建首字下沉：

- 1. 将插入点定位在新段落的开头，即你希望首字下沉出现的位置。
- 或
- 将插入点定位在已有的段落中，即你希望添加首字下沉的段落。
- 2. 从“格式”菜单的“段落”弹出菜单中选择“首字下沉”（图 21）。插入点将放大，准备让你输入首字下沉。属性栏将更改为显示特殊首字下沉命令（图 22）。
- 3. 单击属性栏上的“首字下沉样式”按钮并选择预定义的首字下沉样式（图 23）。
- 4. 单击属性栏上的“首字下沉高度”按钮并设置首字下沉的高度为多少行（图 24）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_136_0.png)

图 21. 从“格式”菜单的“段落”弹出菜单中选择“首字下沉”。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_136_1.png)

图 22. 特殊首字下沉命令按钮出现在属性栏上。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_136_2.png)

图 23. 单击属性栏上的“首字下沉样式”按钮并从下拉列表中选择一种首字下沉类型。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_136_3.png)

图 24. 通过单击属性栏上的“首字下沉高度”按钮并选择高度来设置首字下沉的高度。

5. 单击属性栏上的“首字下沉位置”按钮并设置首字下沉的出现位置，是在文本旁边、页边距右侧还是在页边距中（图 25）。

6. 要为首字下沉选择字体：

- A. 单击属性栏上的“首字下沉字体”按钮。“首字下沉字体”对话框将打开（图 26）。
- B. 从“字体”列表框中选择一种字形并设置你想要的其他字体属性。
- C. 单击“确定”关闭“首字下沉字体”对话框并返回文档。

7. 要在首字下沉周围设置边框并在其后添加填充：

- A. 单击属性栏上的“首字下沉边框/填充”按钮。“首字下沉边框”对话框将打开（图 27）。
- B. 单击“边框样式”按钮并从下拉列表中选择一种边框。
- C. 单击“填充样式”按钮并从下拉列表中选择一种填充。
