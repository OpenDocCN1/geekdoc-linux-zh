

## 删除行或列：

- 1. 选择要删除的行或列。
- 2. 在属性栏上单击表格菜单并选择删除（图 28）。删除对话框将打开（图 29）。
- 3. 在删除区域中选择要删除的内容——您所选的列或行，或仅其内容。
- 4. 单击确定。行或列或其内容将从表格中消失。

## 提示

如果您只想删除所选行或列的内容，请在删除区域中选择单元格内容单选按钮。

## 删除表格：

- 1. 选择要删除的表格。
- 2. 在属性栏上单击表格菜单并选择删除（图 28）或按下键盘上的删除键或退格键。删除表格对话框将出现（图 30）。
- 3. 在删除区域中，选择整个表格、表格内容或表格结构。
- 4. 单击确定。删除表格对话框将关闭，您选择的删除选项将应用于表格。

## 将文本转换为表格

WordPerfect 使将使用制表符或并列列设置的文本转换为表格变得很容易。（有关制表符和制表符设置的讨论，请参阅第 93–97 页；要了解有关并列列的更多信息，请参阅第 131 页。）

## 将文本转换为表格：

- 1. 选择要转换的制表文本或并列列（图 31）。
- 2. 从插入菜单中选择表格（图 4）。转换表格对话框将出现（图 32）。
- 3. 根据您选择的文本类型，选择制表列或并列列单选按钮。
- 4. 单击确定。转换表格对话框将关闭，文本将被转换为表格（图 33）。

## 更改列宽

如您在图 33 中所见，放置文本的表格不一定是平衡的。在图 33 中，第三列比其他两列宽得多——需要稍微调整一下。

WordPerfect 使更改列宽变得很容易。您所要做的就是将列边框拖动到新位置。

- 1. 将鼠标指针置于列边框上方，直到它变为双向箭头。
- 2. 按住鼠标左键并将列边框拖动到其新位置。

## 格式化表格

WordPerfect 允许您使用单元格、行和列属性快速设置单元格中文本的位置和格式。然后，使用属性栏上的特殊表格命令按钮和 SpeedFormatting，您可以设置表格及其元素——单元格、行和列的外观。

## 设置单元格属性：

- 1. 将插入点定位在要更改属性的单元格中。
  
  或
  
  选择要更改属性的单元格。
- 2. 在属性栏上单击表格菜单并选择格式（图 34）或按下键盘上的 Ctrl+F12。格式对话框将打开，并选中单元格单选按钮（图 35）。
- 3. 在对齐区域（图 36）中，使用下拉列表设置单元格中文本的垂直对齐方式——顶部、居中或底部——以及单元格中文本的水平对齐或对齐方式——左对齐、右对齐、居中、对齐、全部或小数对齐对齐方式。
- 4. 在单元格属性区域（图 37）中，您可以设置单元格是否锁定以及在执行计算时是否忽略它。锁定单元格中的信息无法更改。
- 5. 使用外观和文本大小区域设置文本的外观，如果您想使用特殊格式。
- 6. 单击确定。格式对话框将关闭，您选择的单元格中的文本将采用您设置的新格式。
