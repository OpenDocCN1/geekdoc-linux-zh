

## 新标签设置

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_106_0.png)

图 57。当你单击鼠标左键时，新标签设置会出现在标尺栏中。图 56 中在 QuickMenu 上选择的右侧标签设置在此图中出现在标尺栏的标签条上。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_106_1.png)

图 58。从在标签条上右键单击时出现的 QuickMenu 中选择 Tab Set。

- 1. 将插入点定位到你想要更改标签设置的位置。
- 或
- 选择你想要更改标签设置的段落。
- 2. 在标签条上右键单击并从出现的 QuickMenu 中选择 Tab Set（图 58）。Tabs 对话框将会出现（图 59）。
- 或
- 从格式菜单上的 Line 弹出菜单中选择 Tab Set（图 60）。Tabs 对话框将会出现（图 59）。
- 3. 使用 Type 下拉列表选择你想要添加的标签设置类型（图 61）。
- 4. 使用 Position 文本框输入标签将出现的位置的测量值。
- 5. 单击 Set。标签设置将出现在标签条上。
- 6. 随意创建尽可能多的标签设置。
- 7. 完成后，单击 OK 关闭对话框并返回文档。

## 删除标签设置：

- 1. 将插入点定位到你想要更改标签设置的位置。
- 或
- 选择你想要更改标签设置的段落。
- 2. 将鼠标指针定位到你想要移除的标签设置上，按住鼠标左键并将标签设置拖离标签条。当你释放鼠标按钮时，标签设置将消失。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_107_0.png)

## 删除所有标签设置：

- 1. 将插入点定位到你想要更改标签设置的位置。
- 或
- 选择你想要更改标签设置的段落。
- 2. 在标签条上右键单击并从出现的 QuickMenu 中选择 Clear All Tabs（图 62）。

## 标签设置类型

有几种不同的标签设置类型：左对齐、右对齐、居中、对齐小数点，以及这四种类型的带点前导线的版本。下面是对每种标签设置的简要描述，包括其作用以及在标尺栏上的显示方式。

左对齐—在标尺栏上，此标签设置显示为一个指向左下方的微小三角形。当应用左对齐标签设置时，文本出现在标签设置位置的右侧。文本左对齐于标签设置。

居中—在标尺栏上，此标签设置显示为一个指向上方的微小三角形。当应用居中标签设置时，文本以标签设置位置为中心显示。

右对齐—在标尺栏上，此标签设置显示为一个指向右下方的微小三角形。当应用右对齐标签设置时，文本出现在标签设置位置的左侧。文本右对齐于标签设置。

小数点对齐—在标尺栏上，此标签设置显示为一个指向上方且中间带有一个小点的微小三角形。这种类型的标签设置用于包含小数点的数字，例如货币金额。当应用小数点对齐标签设置时，文本以小数点位于标签设置位置的方式定位。

点前导线—除了上面列出的 4 种标签设置类型外，这些类型也可以显示为一条点线，即点前导线，在文本前出现。这种类型的标签设置通常用于目录。

下面是每种标签设置类型的示例：

| 左对齐 | 居中 | 右对齐 | 小数点对齐 | 带点的左对齐 |

| Manicotti | Cheese | Red sauce | $13.95 | Page 29 |
| Pizza | Mushrooms | Garlic | 125.69 | Page 35 |
| Ravioli | Spinach | Olive oil | £3.80 | Page 75 |
| Spaghetti | Artichoke | White sauce | 12.50 | Page 123 |
| Tortellini | Red pepper | Pesto | ¥890 | Page 125 |
