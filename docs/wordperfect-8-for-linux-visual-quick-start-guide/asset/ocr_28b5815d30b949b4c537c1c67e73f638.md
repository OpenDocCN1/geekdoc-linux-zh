# To use the QuickList:

+   1. Choose Open from the File menu (Figure 54). The Open dialog box will appear (Figure 55).

+   2. In the QuickList box, highlight the file you want to open or double-click on the directory you want to move quickly to, then select a file from the File List box.

+   3. Click Open to open the file.

![](bbox=[0.58, 0.1, 0.88, 0.35])

# Tip

The QuickList is also available in the SaveAs dialog box. You can use the QuickList to rapidly move to a directory where you would want to save a file, or to select a document file that you frequently overwrite.

![](bbox=[0.52, 0.45, 0.92, 0.75])

# To close a document:

Choose Close from the File menu in the document window (Figure 56) or press Ctrl+F4 on the keyboard, or click the Close button at the upper right-hand corner of the document window (Figure 57).
