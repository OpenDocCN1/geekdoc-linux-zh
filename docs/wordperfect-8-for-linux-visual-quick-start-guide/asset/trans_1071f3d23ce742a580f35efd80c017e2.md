
3. 在“颜色选项”区域中，单击“颜色”旁边的按钮，然后从调色板中选择一种新颜色（图 4）。

4. 使用“底纹”文本框设置颜色的强度或饱和度（图 5）。数字越大，颜色越饱和。例如，将蓝色设置为 100% 底纹，将得到浓郁、明亮的蓝色；设置为 10% 底纹，则是很浅的蓝色。

5. 单击“确定”关闭对话框。文本将变为你选择的颜色。

## 提示
- 你也可以在输入文本之前更改文本颜色：将插入点定位到希望彩色文本开始的位置，使用上述方法之一选择新颜色，然后输入彩色文本。

## 突出显示

## 行编号

行编号会自动为文档中的每一行添加编号。（这不同于插入编号列表，编号列表是为每个段落插入编号。）你可以设置编号在页面上的显示位置，以及它们是贯穿整个文档还是停止并重新开始。（有关创建编号列表的详细信息，请参阅第 123 页的“项目符号和编号”一节。）

### 添加行编号：
- 1. 将插入点定位到希望行编号开始的位置。
- 2. 在“格式”菜单的“行”飞出项中选择“编号”（图 7）。将显示“行编号”对话框（图 8）。
- 3. 选中“开启行编号”旁边的复选框。
- 4. 在“编号选项”区域中，你可以设置（图 9）：
  - 编号方法——使用此下拉列表，你可以设置行号显示为数字、字母还是罗马数字。
  - 起始行号——如果你不想使用 1，可设置分配给段落第一行的编号。
  - 首次打印行号——设置文档中打印的第一个行号。例如，如果你不希望打印 9 之前的行号，请指定为 9。
  - 编号间隔——此选项设置打印行号之间的间隔。例如，如果希望每四行打印一个行号，请将此选项设置为 4。

5. 在“数字位置”区域中，你可以选择以下两个选项之一（图 10）：
- 距页面左边缘——打印的数字与页面左边缘保持精确距离。在文本框中输入精确的度量值。
- 距左边距——打印的数字与左边距保持精确距离。在文本框中输入精确的度量值。

- 行编号常用于法律文档，例如引文。
- 要关闭行编号，请打开“行编号”对话框，然后取消选中“开启行编号”旁边的复选框。
