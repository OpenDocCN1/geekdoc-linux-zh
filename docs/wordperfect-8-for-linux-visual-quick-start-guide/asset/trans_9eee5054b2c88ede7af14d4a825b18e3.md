## Internet 发布器

Internet 发布器将帮助你使用适当的 HTML 代码创建新文档。它还可以将现有文档转换为可用于 Web 的 HTML 格式。然而，你应该知道，如果你转换现有文档，HTML 不支持一些功能。其中包括列、下沉首字母、脚注、页码、制表符和缩进以及宏。有关不支持功能的完整列表，请参阅随个人版附带的 WordPerfect 用户指南第 281 页。

### 创建新的 Web 文档：

1. 从文件菜单中选择 Internet 发布器（图 1）。Internet 发布器窗口将打开（图 2）。
2. 单击新建 Web 文档。Web 编辑器将出现，并在编辑器窗口中打开一个空白文档，准备好让你创建 Web 页面（图 3）。

### 提示

Web 编辑器实际上是正常文档窗口的特殊版本，专门用于创建 Web 页面。

### 将现有文档转换为 Web 文档：

1. 打开你要转换的文档（图 4）。

2. 从文件菜单中选择 Internet 发布器（图 1）。Internet 发布器窗口将打开（图 2）。

3. 单击格式化为 Web 文档。Web 视图对话框将打开，提示你部分格式将会丢失（图 5）。

4. 单击是继续转换。文档将被转换为 Web 文档并出现在 Web 编辑器窗口中（图 6）。

### 提示

- WordPerfect 在执行转换时会尽可能保留文档的格式。然而，由于普通文档和 Web 文档是两种完全不同的东西，它们的外观会略有不同。
- 如果你决定最终不想将文档转换为 Web 格式，可以将其恢复到之前的形式。转换后立即单击 Web 编辑器窗口右上角的关闭按钮关闭文档。再次打开时，你会看到它已恢复到原始形式。
