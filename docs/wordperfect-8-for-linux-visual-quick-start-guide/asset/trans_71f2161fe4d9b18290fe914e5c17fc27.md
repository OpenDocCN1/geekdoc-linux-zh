

## 保存你的东西

撤销是许多用户最喜欢的命令。如果不小心删除了某些内容，不要惊慌！你可以撤销它！

但是，如果你在用撤销恢复后决定确实想要删除那段文字，你可以使用重做来反转撤销操作。

WordPerfect 8 for Linux 配备了一个令人惊叹的功能，你可以使用撤销/重做历史对话框一次撤销或重做多于一个操作，最多可达 300 个操作！

## 撤销操作：

从编辑菜单中选择撤销（图 41），或点击 WordPerfect 8 工具栏上的撤销按钮。

## 重做操作：

从编辑菜单中选择重做（图 42），或点击 WordPerfect 8 工具栏上的重做按钮。

## 一次撤销或重做多个操作：

- 1. 从编辑菜单中选择撤销/重做历史（图 43）。撤销/重做历史对话框将会打开（图 44）。此对话框显示你在文档上执行过的最多 300 个撤销和重做操作。
- 2. 一次撤销多个操作：
- A. 使用撤销列表框选择你想要撤销的操作，按住 Ctrl 键，然后点击各个撤销操作（图 45）。
- B. 点击撤销按钮。你选择的操作将被撤销。
- 或
- A. 使用重做列表框选择你想要重做的操作，按住 Ctrl 键，然后点击各个重做操作（图 46）。
- B. 点击重做按钮。你选择的操作将被重做。
- 3. 当你完成选择撤销和重做操作后，点击关闭以关闭对话框并返回到你的文档。

## 提示

你可以在文档中保存撤销和重做操作。为此，点击撤销/重做历史对话框中的选项按钮。撤销/重做选项对话框将会打开（图 47）。使用撤销/重做项目数文本框设置将随文档保存的操作数量，确保选中保存撤销/重做项目与文档旁边的复选框，然后点击确定。

## 使用查找和替换

WordPerfect 使查找和/或替换文档中任何类型的单词或短语变得很容易。

## 查找单词或短语：

- 1. 将插入点定位到你希望搜索开始的位置。
- 2. 从编辑菜单中选择查找和替换（图 48）或在键盘上按 Ctrl+F2。查找和替换文本对话框将会出现（图 49）。
- 3. 在查找文本框中输入你想要定位的单词或短语。
- 4. 点击查找下一个。WordPerfect 将在文档中搜索该单词或短语的下一个出现位置。
- 5. 再次点击查找下一个以找到该单词或短语的下一个出现位置。
- 6. 继续点击查找下一个，直到完成搜索。
- 7. 点击关闭以关闭对话框。

## 提示

- ▪ 如果你在打开查找和替换文本对话框之前选择了文本，所选文本将在对话框打开时出现在查找文本框中。
- ▪ 你可以在查找和替换文本对话框打开时继续处理文档。如果想要浏览文档并检查各种项目，这会很有用。
- ▪ 如果你尝试查找文档中不存在的文本，警告对话框将会打开，告诉你未找到该文本（图 50）。点击确定以关闭对话框。
