

## 替换单词或短语：

- 1. 将插入点定位到你希望搜索开始的位置。
- 2. 从编辑菜单中选择查找和替换（图 48）或在键盘上按 Ctrl+F2。查找和替换文本对话框将会出现（图 51）。
- 3. 在查找文本框中输入你想要定位的单词或短语。
- 4. 在替换为文本框中输入替换文本。
- 5. 单击替换。WordPerfect 将在文档中搜索该单词或短语的下一个出现位置并将其替换为新文本。
- 6. 再次单击替换以移动到下一个出现位置并替换文本。
- 7. 继续单击替换，直到完成对文档的搜索。当 WordPerfect 完成搜索时，将出现一个替换对话框，告诉你已替换了多少个出现次数（图 52）。
- 8. 单击确定关闭替换对话框。
- 9. 单击关闭关闭查找和替换文本对话框并返回到文档窗口。

Figure 51. Type the text you want to find and replace in the text boxes, then click Replace to change the next occurrence or Replace All to change all occurrences.

Figure 52. When the entire document has been searched, a Replace dialog box opens to tell you how many times the word or phrase was replaced.

## Tips

- 如果你想删除正在搜索的文本而不使用新文本替换它，请在替换为文本框中输入 <Nothing>。
- 如果你想替换文档中单词或短语的所有出现次数，请在查找和替换文本对话框中单击全部替换。
- 如果你尝试查找文档中不存在的文本，将会打开一个警告对话框，告诉你未找到该文本（图 53）。单击确定关闭此对话框。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_79_2.png)

Figure 53. If the word or phrase is not found a Warning dialog box opens. "Warning" sounds a bit drastic, but it's nothing to worry about. just click OK to close the dialog box.

## 设置查找和替换选项

你可以使用查找和替换文本对话框中的匹配和选项菜单来设置 WordPerfect 如何执行搜索。

## 设置查找和替换选项：

- 1. 从编辑菜单中选择查找和替换（图 48）或在键盘上按 Ctrl+F2。查找和替换文本对话框将会出现（图 54）。
- 2. 在相应的文本框中输入你想要查找和/或替换的文本。
- 3. 要设置 WordPerfect 搜索特定匹配项，请选择匹配菜单项。匹配菜单将会打开（图 55）。你可以设置 WordPerfect 以匹配：
  - 整个单词仅查找整个单词。
  - 大小写敏感精确匹配单词或短语。
  - 字体查找特定格式中的单词或短语，包括字体类型、大小或属性，如粗体、斜体或下划线。
- 4. 要设置 WordPerfect 搜索特定选项，请选择选项菜单项。选项菜单将会打开（图 56）。你可以将搜索设置为：
  - 从文档顶部开始查找
  - 在文档开头/结尾处换行——搜索从插入点移动到文档末尾，然后从文档开头继续。
  - 限制查找在所选内容内——搜索仅查看所选文本。
  
![](img/02dde5e0b11c4f9add393f2d6c89d9a5_80_0.png)

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_80_1.png)

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_80_2.png)

- 在查找中包含页眉、页脚等——搜索将检查文档中的所有文本，包括页眉等中的文本。如果未选择此选项，搜索将仅在文档正文中进行。
- 限制更改次数——当在查找和替换文本对话框中单击全部替换时，搜索将限制替换次数。

5. 完成选择选项后，使用查找和替换文本对话框执行搜索。

## 格式符号和代码的隐藏世界

你输入的一切——包括例如空格、制表符和段落分隔符——都会输入到 WordPerfect 文档中。通常，你看不到代表这些击键的符号和代码，因为它们是隐藏的，但你可以显示它们，使你能够轻松地看到文档中的所有内容。

格式符号显示在文档正文中，与文本一起显示。格式代码显示在文档窗口底部。一个可移动的分隔线将窗口分为两部分。

## 显示格式符号：

从视图菜单中选择显示 ¶（图 57）。隐藏的符号将出现在你的文档中（图 58）。

## Tip

- 要隐藏符号，只需再次从视图菜单中选择显示 ¶。
