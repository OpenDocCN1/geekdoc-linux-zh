

## 指定显示哪些符号：

- 1. 在程序窗口中，选择 Preferences（图 8）。Preferences 对话框将打开（图 9）。
- 2. 单击 Display。Display Preferences 对话框将出现（图 59），显示文档选项（请注意对话框顶部选中的 Document 单选按钮）。
- 3. 单击对话框顶部附近的 Show ¶ 旁边的单选按钮。对话框将更改为显示符号选项（图 60）。
- 4. 在 Symbols to Display 区域，通过单击功能旁边的框来选择要显示的选项。在图 60 中已选择 Space、Hard Return 和 Tab。
- 5. 单击 OK 关闭对话框并返回 Preferences 对话框。
- 6. 单击 Close 关闭 Preferences 对话框并返回文档窗口。你的文档将显示你选择的符号（图 61）。

### Tip

如果在文档中看不到显示的符号，你需要打开它们。从 View 菜单中选择 Show ¶（图 57）。

## FORMATTING YOUR TEXT

在上一章中你了解了如何输入和操作文本。通往 WordPerfect 熟练的下一步是学习如何格式化文本。WordPerfect 让你能够完全控制字符的外观，通过让你更改文本的大小和形状，以及通过让你设置对齐、行距和缩进来设置段落整体的外观。

本章分为两部分。第一部分涉及字符格式，第二部分涉及段落格式。

字符格式会改变字符的外观。这些更改可以包括文本所使用的字体或字形，以及强调文本的项目，如粗体、斜体和下划线。

段落格式设置整个段落的外观。你可以做的一些改变段落外观的事情是设置对齐方式和添加缩进。

不过，在改变外观时，请记住布局和设计的黄金法则：少即是多。本章和第 7 章《Fun with Text》中你会发现如此多的选项，以至于你可能会被诱惑过度使用。尽量限制你使用的格式数量。太多可能会相当 DISTRACTING 并使文档难以阅读。

## Character Formatting

字体格式有各种各样的形状和大小（字面意思！）。你可以更改字体、添加强调、使文本更大或更小，并更改文本位置，将其上移用于上标或下移用于下标。

在格式化文本时，你可以选择要格式化的文本，或在输入时进行格式设置，通过打开格式命令、输入文本，然后关闭格式命令。

### To make text bold:

- 1. 选择要格式化的文本。
- 2. 单击 Property Bar 上的 Bold 按钮或在键盘上按 Ctrl+B。
- 或
- A. 从 Format 菜单中选择 Font（图 1）或在键盘上按 F9。Font 对话框将打开（图 2）。
- B. 在 Appearance 区域，单击 Bold 旁边的复选框（图 3）。
- C. 单击 OK 关闭对话框。
- 文本将变为粗体（图 4）。

或

- 1. 在输入时，单击 Property Bar 上的 Bold 按钮或在键盘上按 Ctrl+B。
- 2. 输入粗体文本。
- 3. 通过再次单击 Property Bar 上的 Bold 按钮或在键盘上按 Ctrl+B 来关闭粗体格式。
- 文本将变为粗体（图 4）。

### To add italics:

- 1. 选择要格式化的文本。
- 2. 单击 Property Bar 上的 Italic 按钮或在键盘上按 Ctrl+I。

或

- A. 从 Format 菜单中选择 Font（图 1）或在键盘上按 F9。Font 对话框将打开（图 2）。
- B. 在 Appearance 区域，单击 Italic 旁边的复选框（图 5）。
- C. 单击 OK 关闭对话框。

文本将变为斜体（图 6）。

或

- 1. 在输入时，单击 Property Bar 上的 Italic 按钮或在键盘上按 Ctrl+I。
- 2. 输入斜体文本。
- 3. 通过再次单击 Property Bar 上的 Italic 按钮或在键盘上按 Ctrl+I 来关闭斜体格式。

文本将变为斜体（图 6）。

### Tip

要删除斜体或粗体格式，请选择斜体或粗体文本，然后单击 Property Bar 上的 Italic 或 Bold 按钮。
