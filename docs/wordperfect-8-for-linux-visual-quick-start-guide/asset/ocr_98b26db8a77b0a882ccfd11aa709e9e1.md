# To delete text:

+   1. Use the shadow cursor or keyboard strokes to move the insertion point to the place where you want to delete text (Figure 17).
+   2. Press the Backspace key on the keyboard to delete characters to the right of the insertion point.
+      or
+      Press the Delete key on the keyboard to delete characters to the left of the insertion point.

Tip

When text is deleted, any text to the right of the insertion point automatically moves to the left to close the space left by the deleted characters. Word wrapping automatically readjusts the lines of text.

# Useful Keystrokes

Below is a list of a few of the keystrokes you can use to quickly move around a document. If a key combination is listed, such as Ctrl+↑, press the Ctrl key before you press the ↑ key.

| PRESS | TO MOVE | PRESS | TO MOVE |
|---|---|---|---|
| ↑ | Up one line | Home | Beginning of the line |
| ↓ | Down one line | End | End of the line |
| ← | Left one character | Page Up | Up one page or to the top of the document window |
| → | Right one character | Page Down | Down one page or to the bottom of the document window |
| Ctrl+↑ | Up one paragraph | Ctrl+Home | Beginning of the document |
| Ctrl+↓ | Down one paragraph | Ctrl+End | End of the document |
| Ctrl+← | Left one word |  |  |
| Ctrl+→ | Right one word |  |  |
