

## 打印奇数或偶数页：

1. 从“文件”菜单中选择“打印”（图1），或单击WordPerfect 8工具栏上的“打印”按钮。将打开“打印”对话框（图2）。
2. 单击“输出选项”按钮。将打开“输出选项”对话框（图9）。
3. 使用“打印奇数/偶数页”下拉列表选择奇数页或偶数页（图12）。
4. 单击“确定”。“输出选项”对话框将关闭，并返回到“打印”对话框。
5. 在“打印选择”区域中，选择要打印的文档范围，可以是“完整文档”或“多页”。
6. 单击“确定”。如果在步骤5中选择了“完整文档”，则将打印文档。如果在步骤5中选择了“多页”，则“多页”对话框将打开（图11）。在“页面”文本框中输入要打印的页码，然后点击“确定”。“多页”对话框和“打印”对话框都将关闭，并打印相应页面。

图10. 在“格式化选项”区域中，选中“逆序打印（从后到前）”旁边的复选框。

图11. 使用“页面”文本框设置要打印的页面，然后点击“确定”。在本示例中，将打印第2、5、8、9和10页。

## 分隔页

分隔页用于分隔打印任务。如果您要打印许多文档，或者在一个多人共用一台打印机的办公室工作，打印一个分隔页将不同文档分开会非常方便。一个分隔页由2页组成，一页在文档之前打印，另一页在文档之后打印。在文档之前打印的那页通常包含打印文档者的姓名、文档的文件名，以及发送文档的日期和时间。

### 打印分隔页：

1. 从“文件”菜单中选择“打印”（图1），或单击WordPerfect 8工具栏上的“打印”按钮。将打开“打印”对话框（图2）。
2. 单击“输出选项”按钮。将打开“输出选项”对话框（图13）。
3. 在“WPApp 目标选项”区域中，选中“打印 WPApp 分隔页”旁边的复选框（图14）。
4. 单击“确定”。“输出选项”对话框将关闭，并返回到“打印”对话框。
5. 在“打印选择”区域中，选择要打印的文档范围。
6. 单击“确定”以打印文档。

### 提示

- 如果您没有使用共享打印机，“WPApp 目标选项”区域将呈灰色显示且不可用。

## 打印信封

打印信封很简单。WordPerfect 会自动设置间距，因此您只需输入寄件人地址和收件人信息即可。

### 打印信封：

1. 从“格式”菜单中选择“信封”（图15）。将显示“信封”对话框（图16）。
2. 如果要打印寄件人地址：
   A. 在“寄件人地址”区域中，在文本框内输入寄件人地址。
   B. 在“寄件人地址”区域中，选中“打印寄件人地址”旁边的复选框。
3. 在“邮寄地址”区域中，输入收件人的姓名和地址。
4. 在“信封”区域中，使用“信封定义”下拉列表选择您使用的信封尺寸。
5. 将信封放入打印机。
6. 单击“打印”。“信封”对话框将关闭，并打印信封。

### 提示

- 输入信封信息时，预览区域会显示信封的预览（图17）。
- 有关如何设置信封邮件合并以快速打印地址列表的详细信息，请参阅第197–199页。
- 如果“信封定义”下拉列表中没有可用的信封尺寸，请参阅第238页了解如何添加信封的说明。
