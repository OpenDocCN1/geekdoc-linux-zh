## 使用 QuickMenu 进行选择

您也可以使用 QuickMenu 来选择文本的各部分。为此，将插入点定位在句子、段落或页面内。接下来，将鼠标指针移到左侧边距，然后右键单击。QuickMenu 将出现（见下文）。从 QuickMenu 中选择所需的选区。

## 处理选定文本

一旦您选定了要更改的文本，您可以复制它、将其从文档中剪切出来、移动它、多次将其粘贴到文档中、替换它或删除它。

## 复制文本：

- 1. 选择要复制的文本。
- 2. 从编辑菜单中选择复制（图 31）。
  或
  在键盘上按 Ctrl+C。
  或
  单击 WordPerfect 8 工具栏上的复制按钮。
  或
  右键单击并从出现的 QuickMenu 中选择复制（图 32）。
- 选定的文本被复制到 X Clipboard，准备粘贴。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_73_0.png)

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_73_1.png)

## 剪切文本：

- 1. 选择要剪切的文本。
- 2. 从编辑菜单中选择剪切（图 33）
  或
  在键盘上按 Ctrl+X。
  或
  单击 WordPerfect 8 工具栏上的剪切按钮。
  或
  右键单击并从出现的 QuickMenu 中选择剪切（图 34）。
- 选定的文本从文档中消失并保存在剪贴板上，准备粘贴。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_73_2.png)

## X Clipboard

X Clipboard 由所有 X Windows 程序使用。 （有关 X Windows 程序的更多信息，请参见第 20 页。）X Clipboard 是内存中的一个区域，用于保存剪切或复制的文本或图形以供以后使用。

## 粘贴文本：

- 1. 复制或剪切要粘贴的文本。
- 2. 将插入点移动到要粘贴文本的位置。
- 3. 从编辑菜单中选择粘贴（图 35）。

或
在键盘上按 Ctrl+V。

或
单击 WordPerfect 8 工具栏上的粘贴按钮。

或
右键单击并从出现的 QuickMenu 中选择粘贴（图 36）。
文本出现在插入点的右侧。

## 提示

- 您可以将复制的文本粘贴到文档中的任何位置任意多次。
- X Clipboard 每次只能保存一个内容。因此，如果您复制或剪切了新内容，剪贴板中的旧内容将被替换。
- 剪贴板是一个非常方便的工具。由于您可以在 WordPerfect 中同时打开多达 100 个文档，因此您可以使用剪贴板在文档之间复制和粘贴。

## 使用拖放移动文本：

- 1. 选择要剪切和粘贴的文本。
- 2. 将鼠标指针定位在选定文本上。
- 3. 按住鼠标左键并拖动，直到插入点出现在要粘贴文本的位置（图 37）。鼠标指针上会附带一个小矩形。
- 4. 松开鼠标按钮。文本会从旧位置“跳”到新位置（图 38）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_75_0.png)

**图 37.** 将插入点拖动到要移动文本的位置。

## ✓ 提示

- 移动文本与剪切和粘贴文本相同。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_75_1.png)

**图 38.** 松开鼠标按钮后，文本会以选中状态出现在新位置。

## 使用拖放复制和粘贴文本：

- 1. 选择要复制和粘贴的文本。
- 2. 将鼠标指针定位在选定文本上。
- 3. 按住键盘上的 Ctrl 键，按住鼠标左键，然后拖动，直到插入点出现在要粘贴文本的位置（图 39）。
- 4. 松开鼠标按钮，然后松开 Ctrl 键。文本将被复制并粘贴到新位置（图 40）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_75_2.png)

**图 39.** 选择要复制和粘贴的文本。

## 替换文本：

选择要替换的文本，然后开始输入。选定的文本将被删除，新文本会出现在其位置。
