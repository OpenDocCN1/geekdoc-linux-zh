# Chapter 2: Command Syntax 59

d) Change your myscript synopsis to show that it is all right for the user to specify the -a option, the -b option, neither option, but both options.

Answer:You should have made the following change:
myscript [-a | -b]

The square brackets ([]) show that it is all right to leave out both options, and the vertical bar (|) shows that if one is used, the other one cannot be used.
