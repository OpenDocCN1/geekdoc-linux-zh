# COMMAND GROUPS

![](bbox=[0.188, 0.315, 0.903, 0.505])

In this lab, you will learn how to use braces and parentheses to group commands within a command line to control I/O redirection and the order in which && and || | are evaluated by the shell. Braces and parentheses also have purposes other than these two; for example, you have already used braces to enclose the statements in a function definition.

# LAB 3.2 EXERCISES

# 3.2.1 GROUP COMMANDS {} AND ( )

There are lots of reasons for using braces and parentheses to group commands, but this lab will look at just two: (i) you can redirect I/O for all the commands in a group as a unit, and (ii) you can override the left-to-right order that the shell uses to process && and ||.
