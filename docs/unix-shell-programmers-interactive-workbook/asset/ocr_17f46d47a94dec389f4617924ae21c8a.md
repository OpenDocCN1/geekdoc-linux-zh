# Lab 4.2: Evaluating and Assigning Values

The assignment to CityState involved referencing the variables city and state. First the shell evaluated the references to city and state, then it made the assignment to CityState using the results of those evaluations. Changing the value of city later on has no “backwards in time” effect on the original assignment to CityState. The only way to change the value of CityState again is to execute another assignment command with CityState on the left side of the equal sign.
