time for (( i=0; i<1000; i++ )) do : ; done

+   g) What does the colon (: ) command do?
Answer: Nothing! It is the shell's "do-nothing" built-in command.

The colon command ( ) actually does do something: It always sets its
ext exit code to true, like the true you have already seen. You can
use the following command as a do-nothing command, too:

```
print "c"
```

The idea in this loop is to see how long it takes the shell to run an
"empty" loop. You can then use that value as the baseline for comparing
how it takes to execute loops containing the commands you are
actually interested in timing. You can subtract out the baseline value to
get the time executing the command(s) you are interested in.
