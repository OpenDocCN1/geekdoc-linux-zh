# 312 Lab 6.2: Arrays and Compound Variables

You will see in the next exercise that compound variables can be used to do many of the same things as associative arrays, such as holding a set of related variables for some object.You can use whichever is easier to work with for your particular application.

Enter the following command:
print mars${mars[domain]} is in ${mars[building]}, \
room ${mars[room]}.

+   What printed this time?
Answer:Your interaction should look like the following:
[6105]: print mars${mars[domain]} is in
${mars[building]}, room ${mars[room]}.
mars is in , room .
[6106]:

Because nothing was assigned to any of the elements of the mars array, the message has blanks wherever there is a reference to any element of the array.

Enter the following commands:
print venus ${#venus[@]} elements and mars has \

print ${!venus[@]}

+   What do we do ${#venus[@]} and ${#mars[@]} print?
Answer:Your interaction should look like the following:
[6106]: print venus ${#venus[@]} elements and mars \
has ${#mars[@]} elements.
venus 4 elements and mars has 0 elements.
[6107]: print ${!venus[@]}
149.44.10 A-219 cs.qc.edu Science Building

address room domain building

Just as for indexed arrays, the ${# ... } construct evaluates to the num-ber of elements of an associative array that have been initialized.
