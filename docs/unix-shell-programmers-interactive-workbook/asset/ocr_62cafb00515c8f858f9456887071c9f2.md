There is another way that you can run a script that you should know about, but that does not apply to you if you are running the KornShell as your interactive shell. It's called she-bang notation. Normally, the shell treats everything to the right of a sharp symbol ( # ) on a line as a comment and ignores it. However, if the first line of a file starts with a sharp symbol, followed by an exclamation mark ( #!) (which is popularly pronounced “she-bang”), versions of UNIX will look for the name of a program on the remainder of the line to process the contents of the file.
