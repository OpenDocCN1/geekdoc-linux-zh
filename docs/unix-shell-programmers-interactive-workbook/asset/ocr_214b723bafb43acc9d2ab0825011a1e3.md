# 11.2.3 Use exec TO READ AND WRITE “INTERESTING” DEVICES

There are several file names that you can use for I/O as if they were files, but that actually give you access to I/O devices or even to programs running on other computers. You can access these devices using either I/O redirection or the exec command, but we've put them off until now because one of them is almost always accessed using exec. However, the three we will look at are all similar, in that their names look like disk files, but they are actually not. Here are the three we will look at in this exercise:

+   * /dev/null
* /dev/tty
* /dev/tcp
