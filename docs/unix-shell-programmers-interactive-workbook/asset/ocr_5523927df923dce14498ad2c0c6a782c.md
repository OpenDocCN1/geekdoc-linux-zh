# 6.1.3 USE ARITHMETIC EXPANSION

You have already seen how the shell substitutes the value of a variable for a ref- to it when you use the dollar sign ($ ) in front of the variable's name. You will see more powerful ways that the shell can do substitutions in Chapter 10, "Patterns, Expansions, and Substitutions,"" but this is a good place for you to see one of these mechanisms, called arithmetic expansion.

You can reference the value of an arithmetic expression by putting a dollar sign in front of the opening double parentheses.

Run the following command:

```
print -- $((sqrt(2))
```

> There must be no spaces between the dollar sign and the first open parenthesis, or you will get a syntax error message from the shell.

You can use arithmetic expansion anywhere you would use a variable reference.

Run the following commands:

```
readonly float two_pi=$(( 2 * 3.141592654 ))
float theta=180
print -- $((cos(theta / 360 * two_pi))
```
