# 10.1.2 Use QUESTION MARK (? ) TO MATCH A SINGLE CHARACTER

The asterisk pattern matches any number of characters, including none. If you want to have a single character somewhere in a pattern, use a question mark.

With the same file in your current directory as in the previous exercise, run the following command:

```

```
