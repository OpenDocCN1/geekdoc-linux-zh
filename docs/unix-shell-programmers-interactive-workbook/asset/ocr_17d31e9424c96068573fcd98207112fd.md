# Appendix B: Built-In Command Reference

While allexport is set, ksh sets the export attribute for each variable whose name does not contain a . (dot) to which you assign a value.

alanxexport (a)

ksh runs all background jobs at a lower priority

bgnice

Puts you in the emacs built-in editor. (Not covered in this book.)

emacs

If a command has False return value, ksh executes the ERR trap if set, and immediately

errexit (e)

Puts you in the gmacs built-in editor. (Not covered in this book.)

gmacs

When the interactive option is also set, ksh does not exit on end-of-file (default is when you type Control-D).

ignoreeeof

Provided for only backward compatibility with the Bourne shell.

keyword (k)

ksh appends a trailing / to all directory names resulting from pathname expansion

markdirs

ksh runs background jobs in a separate process group, and displays a line upon completion.

markdirs (m)

ksh will not overwrite an existing file with the > redirection operator. You must specify >l to overwrite an existing file.

noclobber (C)

ksh reads commands but does not execute them. You can use this option to have ksh check your shell script for tax errors.

noexec (n)

ksh disables pathname expansion.

noglob (f)

ksh does not store function definitions in the history file.

nolog
