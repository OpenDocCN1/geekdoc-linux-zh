You typed in the keyword function followed by the name (f133), and an open brace ({), and when you pressed the Enter key at the end of the line, the shell issued its continuation prompt (>), indicating that it expects to type more information to complete the function definition that you have started. You typed a print command, and ended the close brace (}) in response to the next continuation prompt. The shell prompted you to enter another command, and you typed the name of the function you just defined, and it executed.

+   b) What printed, and why?

Answer:Your interaction should have looked like the following:
$ vi ~/fun/f133

Here you should enter the lines indicated in the function definition file.

```
$ f133
This is function f133
$ 
```

This is the output of your previous definition of f133, not the new one you just entered into ~/fun/f133.

> If the shell has a definition for a function, creating or editing a file in ~/fun will not cause the shell to recognize the new definition automatically.
