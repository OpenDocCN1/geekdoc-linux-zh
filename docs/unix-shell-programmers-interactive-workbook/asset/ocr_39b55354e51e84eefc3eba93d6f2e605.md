# 5.1.1 ANSWERS

a) Print the values of PATH and FPATH.Are your ~/bin and ~/fun directories in them?

Answer: Depending on the path of your home directory, your interaction should be something like the following:

```
[5001]: print $PATH
... :/home/vickery/bin:
[5002]: print $FPATH
... :/home/vickery/fun:
[5003]:
```

Both PATH and FPATH are lists of directories separated by colons, and each should have the path to your bin and fun directories wherever in them.

b) Make s511 executable, use cat,more, or less (your choice) to show its contents, and run it.What is your output?

```
[5003]: vi ~/bin/s511
<Edit the file>
[5004]: chmod +x ~/bin/s511
[5005]: cat ~/bin/s511
print This is script s511
[5006]:
```

The file contains just one line of code, the print statement.

> You could put the pathname of the program to run the script (ksh), in the first line of your scripts using "she-bang" notation (see the Glossary), but as long as you run your scripts from an interactive KornShell session, there is no need to do this for KornShell scripts because the shell will run the script without it. In fact, it takes longer to run scripts using she-bang because a whole new copy of ksh has to be loaded into memory for execution.
