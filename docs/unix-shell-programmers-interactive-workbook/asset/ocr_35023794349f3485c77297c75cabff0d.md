# Lab 7.1: THE if COMMAND

Inside the script, a reference to the variable i will include a space in the middle. If the reference is not enclosed in quotes, the grep command, after the reference is evaluated by the shell, will look like the following command:

```
grep ^January February$ Months
```

This command tells grep to look for “January” at the beginning of any line in the two files named February$ and Months, which is clearly not at all what you want to do.

Always write your code so that it behaves “reasonably,” no matter what the user types.

+   g) Why is the output of the grep command redirected to /dev/null?
Answer: So the user doesn't see it.

The grep command writes all lines that match your pattern to stdout. For this script, you want to print your own message rather than show the user the matching line. The special file named /dev/null accepts anything you send to it—and silently discards it.

+   h) Why is -- put on both print commands?
Answer: So the program doesn't break if the user puts options on the command line.

This is another example of “defensive programming.” Consider the possibility that the user types the following command line:
