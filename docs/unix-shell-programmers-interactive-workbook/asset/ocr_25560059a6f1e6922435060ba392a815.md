# LAB 3.1: COMMAND SEQUENCES

# LAB OBJECTIVES

In this lab, you will learn about:

+   - Sequential Execution (;)
- Run Multiple Commands Concurrently Using &\n- Pipelines (|)
- Conditional Commands (&& and ||)
- Co-Processes (|&)

So far, you have looked at individual commands, but much of the power of UNIX shells comes from the ways you can combine multiple commands in a single command line. The KornShell supports a particularly rich set of features for combining commands, so even if you are already comfortable with pipelines, you will find things in this lab that will probably be new to you.
