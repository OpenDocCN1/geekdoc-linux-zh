j) What happens if the two files were both modified at the same time?

You can use the touch command to simulate editing a file. If you give the name of a file to this command, it will change the last modified time of the file to whatever the time and date are at that moment, or will create the file if it does not exist.

> You can also use output redirection as a command by itself to create a file easily; but unlike touch, > will truncate a file's contents if the file already exists.

Enter function newer in your ~/fun directory and run the following commands to test it:

```
touch a
touch b
newer a b

```
