Now, consider exactly why the two variable references were run together as they were in the first line. Look at the following interaction:

```
CityState=$city, $state
ksh: ND: not found [No such file or directory]
$
```

The space after the comma marks the end of the value part of the assignment, so the shell tries to use $state (which evaluates to ND) as the name of a command to execute. If you want to put spaces in the value of a variable, you can, but you have to use quotation marks, which is covered in the next Exercise.
