To learn more about the read command, we'll work with a function that works sort of like the external wc command that you used in Chapter 2, "Command Syntax." The idea is to count the number of lines, words, and characters in a file.

Enter the following function definition into a file named ~/fun/mywc:

```
# mywc Count the lines, words, and characters in a file
function mywc {
integer lines words chars
typeset IFS

IFS=
while read -r
do
IFS='\t\n'
print -- $REPLY | read -RA inWords
(( lines++ += ${inWords[@]} ))
(( chars += ${#REPLY} ))
IFS=
done

print - ""\tlines \twords \tchars"
}
```
