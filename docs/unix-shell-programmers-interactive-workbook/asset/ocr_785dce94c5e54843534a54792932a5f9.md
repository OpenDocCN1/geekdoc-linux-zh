# b) What happens when you test your script?

The grep command sets its exit code to true if it finds the string you want to search for and sets it to false if it does not find the string.

Create the following script in your bin directory:

```
# s712b -- Tell if the user typed the name of a month.
if grep -i "^$1$\$ Months > /dev/null
then print -- "$1 is the name of a month."
else print -- "$1$\$ is not the name of a month."
fi
```
