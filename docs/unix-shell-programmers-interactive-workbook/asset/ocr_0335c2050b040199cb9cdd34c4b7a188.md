# LAB 3.1

Now run the following command line, but do not type anything for at least 5 seconds after you enter it:

```
print hello& sleep 5& print again&
```

b) Explain what the notify option does.

Answer:Your interaction should look something like the following:

```
$ set -mb
$ print hello & sleep 5 & print hello again &
[1]
 270
hello
[2] 266
[3] 255
```

[1] Done print hello & sleep 5 & print hello again &
$ hello again

[3] + Done print hello & sleep 5 & print hello again & 
<There should be a 5 second delay here, but you didn't type anything.>

[2] + Done print hello & sleep 5 & print hello again & 
<At this point, you must press Enter to get the next prompt.>

```
$
```

The difference is that the last Done message came out even though you did not not "release" it by pressing Enter to get another shell prompt.

![](bbox=[0.185, 0.655, 0.325, 0.735])

Turning on the notify option (-b) is useful if you have long-running jobs and want to find out when they complete, even if you don't happen to be actively interacting with the shell at the time. However, turning it off can make your interactive sessions easier to deal with if you tend to run a lot of short-lived jobs.
