You also can use references to a set of mathematical functions in your arithmetic expressions:

+   * abs Absolute value
* acos Arc cosine
* asin Arc sine
* atan Arc tangent
* cos Cosine
* cos Hyperbolic cosine
* exp Exponential (base e)
* int Integer part of a float
* log Logarithm (base e)
* sin Sine
* sinh Hyperbolic sine
* sqrt Square root
* tan Tangent
* tanh Hyperbolic tangent

Run the following commands:

```
float x y z
(( x = sqrt(2) ))
(( y = log(1000000)/log(10) ))
(( z = cos(3.14159) ))
print x=$x y=$y z=$z
```
