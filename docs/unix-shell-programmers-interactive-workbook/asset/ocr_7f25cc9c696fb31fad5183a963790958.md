# PARAMETERS

# LAB OBJECTIVES

+   After this lab, you will be able to:
* Verify Your Set-Up
* Pass Parameters to a Function or Script
* Use Special Parameter Variables ( # @ * )
* Use set to Assign Positional Parameters
* Use shift to Access Positional Parameters

You have already seen parameters from a user's point of view. They are the tokens, such as file names, that you type after the options part of a command string. In this lab, you will see how functions and scripts find out what parameters are passed to them using a special set of variables provided by the shell.
