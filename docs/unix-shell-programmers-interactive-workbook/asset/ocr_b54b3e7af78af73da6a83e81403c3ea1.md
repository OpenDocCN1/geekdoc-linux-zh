You can specify a radix (numeric base) for displaying integers using typeset. The base must be specified as a (decimal) integer from base 2 to base 64. The default base (if not specified) is 10.

Run the following commands:

```
typeset -i2 i=20
typeset -i16 j=20
print i=$si j=$sj
```
