# Chapter 4: Simple Variables

# 4.2.1 ANSWERS

Run the following command:

```
print $PS1
```

+   a) Explain the output.

Answer:Your interaction should look like the following:

```
$ $PS1
$
$
```

The second line is the output of the print command, which looks just like the shell's prompt on the third line because the “real” prompt is generated by evaluating PS1 the same way is it was evaluated in the print state.

+   b) Put a reference to a variable named PSIX followed by a reference to PS1 in a print command and compare the output with the previous print command.

Answer:Your interaction should look like the following:

```
$ $PSIX $PS1
$
$
```

The output looks just like the previous item's because the shell effectively ignores references to uninitialized variables, such as PSIX.

Write a command that prints the value of PS1 with a character X on each side of it. There must be no spaces between the Xs and the value of PS1.

+   c) What command did you use?

Answer:Your command and its output should look like the following:

```
$ print X$(PS1)X
X$ X
```

Four characters were printed: an X, a dollar sign, a space, and another X.
