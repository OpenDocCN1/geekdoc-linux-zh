h) Why is the parameter in quotes? (There are two answers to this.)

The conversion control strings strings consist of the percent symbol, up to four optional qualifiers and, finally, a required conversion character. Two commonly used conversion characters are d, for integer values, and s, for printing strings. Some other interesting conversions include e, f, and g for various floating-point formats, as well as o, x, and x for octal and hexadecimal values. To see some examples of how these conversions work, run the following commands:

```
integer i=12345
printf "%%d\n %10d\n %%-10d\n %%o\n %%x\n" i i i i
h=hello
printf "%%s\n %10s\n %%-10s\n" $h $ $
```
