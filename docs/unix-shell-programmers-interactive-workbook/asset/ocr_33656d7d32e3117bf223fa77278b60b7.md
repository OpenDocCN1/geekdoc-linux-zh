Making a mistake in setting up your default shell can prevent you from logging into your system at all. In particular, if you have a network account (one that you can log into any of the computers on a network), make sure the path to your default shell is valid, no matter what computer you use to log in.

![](bbox=[0.136, 0.166, 0.236, 0.253])

If you want to run the KornShell as a command, just type the pathname to the ksh file in response to your default shell's prompt. If the directory containing ksh is in your PATH (we'll talk more about this later in this chapter), you can just type ksh as the name of a command.

Once you have installed ksh on your system, start it up either by logging in it as your default shell or by running it as a command. Press Ctrl-V.

# 1.1.2 Set Up For MS WINDOWS SYSTEMS

You can get the advantages of KornShell programming by MS Windows systems (Windows 95/98/NT/2000), but to do so you have to do something to make those systems work, more or less, like UNIX. There are several such packages available, but one, “U/WIN” (which stands for “UNIX for WINdows”) which is pronounced (“You win”) has the advantages of benefiting from David G. Korn's active involvement in its development and from the fact that it includes the latest version of the KornShell as part of the package.
