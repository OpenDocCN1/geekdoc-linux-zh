Now the script runs and prints some interesting information. First, it prints its own name using $0 in the print command. You will learn about using special variables such as this one in Chapter 4, "Simple Variables.",

The next line shows the script's process ID. The kernel assigns every process a unique ID number when it is created, and you can print a process's ID number using $$ in a print command. Your ID is undoubtedly different from the one I got when I ran the command. The next will deal with this issue further.

The next two lines show the values of two variables, FPATH and VAR_131; however, the second prints nothing inside the quotation marks. (We put literal quotation marks \") in this print statement to show that VAR_131 does not have a value inside this script.) The issue is that FPATH is an exported variable (provided you set up your ~/.profile correctly (earlier) and you can print its value from inside the script, but VAR_131 is not exported, and you cannot print its value from inside the script. We will look at this issue in the next exercise, so remember what happened here!
