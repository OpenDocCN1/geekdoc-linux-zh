# Chapter 3: Compound Command Syntax

a) What will print if you run the following command line?

```
print one && print two || print three && print four
Answer:Your interaction should look like the:
$ print one && print two || print three && print four
one
two
four
$ 
```

Notice that “three” did not get printed!

Because print always gives an exit code of true, the command line is equivalent to true && true || true as far deciding what to execute is concerned. From left to right, true && true || X is, no matter what X is, so the print three command is skipped. Still going from left to right, the shell has a result of true after the first three commands and to execute the fourth one to decide whether the entire sequence is true or not.

b) Now use parentheses so that the same sequence of commands and operators prints just:

```
one
two
```

Answer:There are several ways to do this.The author believes that the easiest way is to force the shell to process the last two commands as a group. Using this technique, your interaction would look like the following:

```
$ print one && print two || (print three && print four)
one
two
$ 
```

By making the third and fourth commands a group, the command line reduces to true && true || (X), which means the shell does not need to evaluate X, and neither the third nor the fourth print command is executed.

>  seldom need to deal with this sort of complexity in “normal” shell programming, but if you do, you can follow the same advice CIC/C++ and Java programmers get: Use parentheses to make clear what you want to do.
