e) What would happen to optletter if the getopts command were run again?

Answer:It would be set to a question mark ( ? ), as the following interaction shows:

```
[5060]: getopts -douv optletter
[5061]: print optletter
?
```

```
[5062]:
```

In this example, when getopts sees hello with no dash at the beginning, it knows there are no more options and will set optletter to the question mark, no matter how many more times it is called.
