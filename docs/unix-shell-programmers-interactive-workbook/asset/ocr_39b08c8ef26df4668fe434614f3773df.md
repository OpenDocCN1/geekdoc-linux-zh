If, n, the variable has a value that doesn't look like a number or a valid arithmetic expression, the shell assigns value zero to the numeric variable and generates an error. (Arithmetic expressions are covered in the next exercise). However if, like m, the variable has a value that looks like a number (or arithmetic expression), the shell assigns the value of that number to the numeric variable. If the strings looks like a number with a fractional part and the variable receiving the value is an integer, the fraction is lost.

> Avoid mixing string and numeric variables in your assignments.

![](bbox=[0.206, 0.532, 0.333, 0.613])

The shell is very flexible letting you intermix string and numeric variables, which makes shell programming much easier to do than conventional programming languages like C, C++, and Java, in which every variable must have a declared data type, and the rules for what can be assigned to what are very rigid.The tradeoff is that it's relatively easy to make mistakes in shell programs if you forget what variables hold types of values.

```
typeset -i j k
typeset -F x y z
i=3.5 j=4.9 k=99.999
x=3.5 y=4.9 z=99.999
print i=$i j=$sj k=$k x=$sx y=$y z=$sz
```
