The labs in this chapter cover features of the KornShell shell that take advantage of services provided by the operating system's kernel to achieve some powerful programming effects.

These services include I/O processing, process management, and signal processing. How the kernel implements these services are topics in "systems programming." In this chapter you will learn how the KornShell makes these services available to your shell programs.
