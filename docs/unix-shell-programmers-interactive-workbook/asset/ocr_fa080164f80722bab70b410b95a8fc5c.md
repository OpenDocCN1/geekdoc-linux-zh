# Lab 8.1: Loops: while and until

LAB 8.1

There has to be at least one command in both the loop test and the loop body.

Enter the following function in your fun directory:

+   # f811 -- Process option parameters
# The variables a_opt, b_opt, and c_opt will be either empty
# strings or the string "on", depending on the command line,
# when this function terminates.

```
function f811 {
    # Initialize all option variables to empty strings.
    a_opt=
    b_opt=
    c_opt=
    # Loop through command line option parameters
    while getopts abc optletter
    do
        [[ $optletter == "a" ]] && a_opt=on
        [[ $optletter == "b" ]] && b_opt=on
        [[ $optletter == "c" ]] && c_opt=on
    done
}
```
