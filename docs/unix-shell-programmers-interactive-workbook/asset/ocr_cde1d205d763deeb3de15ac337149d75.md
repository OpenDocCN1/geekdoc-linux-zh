d) What was the total number of commands executed when you ran f811?
Answer: 14, not counting while, do, and done as commands.

You can figure out the number of commands as follows:

+   - The three assignments before while.
- The getopts command, which has an exit code of true twice, and then false once.
- The three double-bracket commands, each of which is executed twice.
- One of the assignment commands each time the loop body was executed.

Total

e) What would be the total number of commands executed if you ran the following command line?
f811 -abcabc
Answer: 34 commands.

You can figure out the number of commands as follows:

+   - The three assignments before while.
- The getopts command, which has an exit code of true six times, then false once.
- The three double-bracket commands, each of which is executed six times.
- One of the assignment commands each time the loop body was executed.

Total

There are two points to understand from this question. The first is the relatively minor point that the user can repeat option parameters and getopts does not consider this to be an error, or even unusual. The second is that it takes time to execute commands, and loops typically affect the execution times of scripts and functions: You have to multiply the times the number of commands in the test and body parts by the number of times the loop is executed. This multiplicative effect becomes very significant if a loop is executed many times.
