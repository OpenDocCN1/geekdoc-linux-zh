# 11.2.1 ANSWERS

+   - Was the file ls.out created, containing the output of the ls command?
  Answer:Yes, it was.

If you run a command such as, more ls.out, you would see the output of the ls command, implying that the ls command was passed as an argument to exec was indeed executed successfully, with its output redirected to the file.

+   - Was the print command executed?
  Answer: No, it wasn't.

The reason you didn't see the output of the print command was that it really wasn't executed. The exec command replaces whatever command is running with the command given as its parameter list. In this case, the tryexec script is replaced by the ls > ls.out command. It's the executing program in memory that's replaced, not the script file itself, of of course. When the ls command completes, control returns to the command line, not to the tryexec script.
