# 10.1.4 ANSWERS

```
for prefix in re un ""
do for root in re reread
    do for suffix in ed ing
      do touch -prefix$root$suffix
    done
done
```

+   a) How many files did these commands create?
Answer:Ten.

The touch command was executed twelve times, but only ten different files were actually created. The outermost loop sets prefix to each of three different values (re, un, and the empty string). For each of these three values, the middle loop sets root to each of two different values (read and reread), which means the innermost loop is executed 3 x 2 = 6 times. The innermost loop iterates over two different values (ed and ing), so the innermost command is executed 3 x 2 x 2 = 12 times. However, two of the twelve combinations are not unique: “rereaded” prefixed with “rereaded” is the same as “read” prefixed with “re,” and likewise for “rereading.”
