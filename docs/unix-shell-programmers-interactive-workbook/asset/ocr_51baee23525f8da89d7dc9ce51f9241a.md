Enter a command that declares the variable names venus and mars as associative arrays.

+   a) What command did you use?
Answer:You should have entered the following command:
[6098]: typeset -A mars venus

You could have entered the variable names in the opposite order, or you could have used two separate typeset commands. In either event, you must use the -A option on the typeset command to make the variables associative arrays.

Enter the following commands:
venus[domain]=cs.qc.edu

venus[room]=A-219
print$${venus[domain]} is in ${venus[building]}\nroom ${venus[room]}.
