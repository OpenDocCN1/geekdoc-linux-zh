You may be familiar with the UNIX command, echo, which is pretty much the same as print.The problem is that there are different versions of echo for different versions of UNIX and for different shells, and some of them behave differently from one another. However, there is only one print for ksh, which can do anything that any of the various echo commands can do. So the best strategy is always to use print.
