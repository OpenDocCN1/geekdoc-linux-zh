# 7.2.2 USE [[... ]] INSTEAD OF if

You can use the double-bracket operator as a command to replace simple if statements—ones that consist only of if, then and fi.

If you recall that the grouping operators ( && and || ) work by testing exit codes, you can see that the following two commands are equivalent:

> FOR EXAMPLE
The command line

```
if [[ -e a_file ]] then print a_file exists; fi is equivalent to the following:
```

```
[[ -e a_file ]] && print a_file exists
```

The first command line could also have been written on three command lines, but this “one-liner” format is convenient to use for simple if commands.
