# 11.1.1 ANSWERS

+   * **What was the value of REPLY after the read command completed?**
Answer: It contains the second line you typed in. Your interaction should look like the following:
`[11000]: read
Hello, how are you?
`[11001]: print $REPLY
Hello, how are you?
`[11002]:`

You could have typed anything you wanted after line 11000, and whatever you typed would have been displayed as the value of the variable REPLY. You can think of the variable REPLY as the default buffer that receives the line of text input by a read command.

+   * **What was the value of answer after the read command completed?**
Answer: It contains the second line you typed in. Your interaction should look like the following:
`[11002]: read answer
OK. How are you now?
`[11003]: print $answer
OK. How are you now?
`[11004]:`
