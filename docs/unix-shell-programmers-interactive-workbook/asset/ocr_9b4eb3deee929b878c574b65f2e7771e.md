# 8.2.2 Use for TO COUNT ITERATIONS

The second type of for loop sets the control variable to a sequence of numeric values.

> If you already know C, C++, or Java, you can write this kind of for loop just the way you already know, except that the KornShell for for loop uses double parentheses instead of single parentheses.

![](bbox=[0.027, 0.563, 0.131, 0.6230330000000001])

# FOR EXAMPLE

Let's start with a loop that prints the numbers 0–9:

```
for (( i=0; i<10; i++ )) print $i ; done
```

Double parentheses introduce arithmetic commands in general, and a special form of arithmetic command used just for for loops in this case. (You may recall that we made up a rule about putting a space after an open parentheses for command grouping in Chapter 2, "Command Syntax"; the reason for that was so you would not accidentally start an arithmetic command if you tried to nest command groups.)
