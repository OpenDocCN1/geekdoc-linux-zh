There is one text editor that is available on all UNIX systems, vi.Where we want to indicate "edit a file," we will show a vi command in this book. However, if you want to use vi you should strongly consider switching to vim ("vi-improved") which is widely available at no cost for most systems. Another widely used editor is emacs, which is widely available at no cost for most systems. If you don't know emacs, you will find vim easier to learn.

If are using UI/WIN, you can use any DOS or Windows text editor. These editors normally add an extra character to the end of each line of text (ASCII carriage return) that UNIX editors do not use, but you can turn this behavior off, or you can just not worry about it because the KornSell will not have problems with the extra characters. If you choose to use a Windows editor, I recommend "The Programmer's Life Editor," which is available at no cost from Alan Philips of Lancaster University Computer Center:

```
http://www.lancs.ac.uk/people/cpaa/pfe/
```

If you are using the XWindow System, the best editor to use is nedit by Mark Edel of Fermi National Labs. Binaries for most platforms, and source code you can use to build it yourself, are available from:

```
ftp://ftp.fnal.gov/pub/nedit
```
