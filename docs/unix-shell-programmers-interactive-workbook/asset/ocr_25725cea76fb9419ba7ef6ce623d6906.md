# WHENCE

whence [-afpv] name...

Use whence -v to find the absolute pathname, if, any, corresponding to each name. You can also use whence to find out type of item each name is: specify -v. For each name you specify, ksh displays a line that indicates if the name is a reserved word, an alias, a built-in, an undefined function, a tracked alias, a program, or "not found." If you specify -f, ksh does not check to see if name is a function. If you specify -p, ksh does not check to see name is a reserved word, a built-in, an alias, or a function. If you specify -a, ksh displays all uses for name.

# WHILE

+   while compound-list

+   do compound-list

+   done

The while command repeatedly runs the while compound-list. Each time, if the return value of the compound-list is True, runs do compound-list. If False, loop terminates. A break command within the do compound-list causes the while command to terminate with a value of True. A continue command causes the do compound-list to terminate and the while compound-list to be run again. For more information: see Chapter 8 (Loops).
