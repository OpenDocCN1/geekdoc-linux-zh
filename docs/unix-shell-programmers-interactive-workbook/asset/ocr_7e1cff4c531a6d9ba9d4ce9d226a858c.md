# 2.2.1 LIST ALL BUILT-IN COMMANDS

Run the following command:

```
builtin
```

+   a) What are the results?

![](bbox=[0.905, 0.187, 0.97, 0.233])

> UNIX commands that write text to the screen can be "piped" to a system utility called more. This utility instructs UNIX to show the output of the command, one screen at a time. At the bottom of the screen, UNIX prompts you to hit the space bar to see the next screen, or to press the key to quit.

![](bbox=[0.015, 0.415, 0.115, 0.465])

Now, run the following command:

```
builtin | more
```

+   b) How are the results different?

> Better yet, you should be able to use another command, less that does the same thing as more, but with additional options. If you are running ksh under U/WIN, less is more.
