Until now, we haven't paid much attention to the empty string as its value. If you print them, they both print the same thing (which is nothing, unless you have the shell's nounset option turned on). However, it can be important sometimes to differ- entiate between the two situations. If a variable is set to the empty string, it means that the user has done something to give that value to the variable. However if the variable is unset, it means the user has done nothing with the variable and perhaps doesn't even know about it.
