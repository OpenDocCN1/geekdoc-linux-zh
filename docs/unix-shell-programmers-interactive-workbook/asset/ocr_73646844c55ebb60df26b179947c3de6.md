# 9.1.3 WORK WITH select DETAILS

In the previous exercise you worked with select in the “standard” way. This exercise gives you some practice using select's default prompt and introduces you to using an if command instead of case in the body of a select command.

Enter the following command lines:

```
select choice in a b;
do  if [[ $choice == "a" ]] then
    print ok
    break
  fi
done
```

+   a) What prompt string is used?

+   b) What happens if you enter 2 as your selection?

+   c) What happens if you enter 1 as your selection?

+   d) Is it necessary to put a case command inside every select command?
