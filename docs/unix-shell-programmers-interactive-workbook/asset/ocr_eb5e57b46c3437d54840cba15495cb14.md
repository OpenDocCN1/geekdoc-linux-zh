You can use && to guarantee that a command runs only if another one completed successfully.

You can use || to print an error message if another command fails to complete successfully.

Use co-processes when you want to generate input for a program programmatically but need more flexibility than you get with here documents.

![](bbox=[0.023, 0.684, 0.115, 0.75])
