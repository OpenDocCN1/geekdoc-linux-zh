+   8.2.1 USE TO WORK WITH A LIST OF VALUES

You have already seen lists of values when you saw command line options being passed as the values of a set of parameters named l, 2, 3, and so forth, in a function or script. You can create lists of values other ways, but let's start by using a for loop to iterate over the parameter list in a function.

> The phrase to "iterate over a list" means to execute a loop with the control variable taking on the value of a different item in the list each time through the loop.

