# LAB 7.2 EXERCISES

```
7.2.1 USE [[ ... ]] IN AN IF STATEMENT
```

This exercise deals with the syntax of the [[ ... ]] operator. Every test starts with the opening double brackets, a test expression(indicated by the ellipses), and a pair of right brackets (]) that end the expression.

For this Exercise, we will use the - test to find out whether a file exists.

Put the following script in your bin directory:

```
# s721 -- Test whether a file exists or not
if [[ -e "$1" ]]
then print -- "$1 does exist."
else print -- "\$1\" does not exist.
fi
```

The shell knows what is inside a [[ ... ]] has to be a test expression, and do not do token splitting on what is inside. The quotes around $1 could safely have been left off, even if there were spaces inside the value of parameter l.

Run this script twice using the following command lines:

```
s721 ~/.kshrc
s721 the_name_of_a_file_that_does_not_exist
```

You can change the parameters in the two commands, provided that the one names a file that does exist and the second one names a file that does not exist.
