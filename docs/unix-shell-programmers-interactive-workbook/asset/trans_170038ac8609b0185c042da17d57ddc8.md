注意，此练习受到两个 shell 选项的影响。在开始此练习之前，运行以下命令以确保这些选项已“正确”设置（至少目前是这样）：

`&` 用于分隔你想让 shell 并行运行的命令。如果一行的最后一个（或唯一）命令后面跟着 `&`，shell 将提示你输入另一条命令行，而无需等待上一个命令完成。
