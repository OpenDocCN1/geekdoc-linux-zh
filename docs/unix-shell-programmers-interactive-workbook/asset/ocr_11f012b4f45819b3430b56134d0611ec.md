Repeat the previous two operations, but use set -C and set +C instead of set -o noclobber and set +o noclobber.

+   e) Is there any difference between set -o noclobber and set -C or between set +o noclobber and set +C?

The >> and > | redirection symbols also handle the noclobber issue.

If you use >>, the output file will be created if it doesn't exist, but if it does already exist, the new output gets written to the end of the file.
