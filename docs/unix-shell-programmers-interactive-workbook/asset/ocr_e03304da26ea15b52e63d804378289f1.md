# Chapter 11: I/O and TRAP Processing

k) What does a minus sign in front of the number?

Answer: It causes the value to be left-justified in the field.

Normally, values are printed right-justified in their fields.

```
typeset -UL7 h
printf "%%10s\nn" "$h"
```

l) What did the typeset command do, and how did it affect the output of the printf command?

Answer:Your interaction should look like the following:

```
[11027]: typeset -UL7 h
[11028]: printf "%%10s\n" "$h"
- HELLO
[11029]: cp2
[11030]:
```

The typeset command set the width of the variable h to seven characters, left-justified, and made the characters uppercase. By printing quotes just before and after the %10s, you can see that the five characters "hello" are left-justified within the seven allocated to them, but that those seven characters are right-justified in the ten character field specified by the printf conversion string.

m) What is the difference between the %s and the %b conversion codes?

Answer:Your interaction should look like the following:

```
[11030]: printf "%%s --%%b\n" "Hello\there" "hello\there"
hello\there      here
[11031]:
```

The key is \t in the middle of the two strings being printed. If you use %s, they are printed literally as the charactersbackslash-f (/t), but if you use the %b conversion code, they are interpreted as an ASCII <tab> code.

> C escape conventions are recognized in the format string of printf commands, but not in string values being printed unless you use the %b conversion code.
