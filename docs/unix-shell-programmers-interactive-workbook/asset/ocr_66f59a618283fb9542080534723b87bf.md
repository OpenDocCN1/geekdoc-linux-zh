# 6.2.2 DECLARE AND USE ASSOCIATIVE ARRAYS

An associative array is an array that uses strings instead of integers as subscript values. Unlike indexed arrays, you must declare a variable to be an associative array, using the -A option of the typeset command, before you can use the variable with strings as subscripts.

> If you try to use a string as a subscript without declaring a variable as an associative array, the shell will treat the subscript as an arithmetic expression, as shown in the previous exercise.
