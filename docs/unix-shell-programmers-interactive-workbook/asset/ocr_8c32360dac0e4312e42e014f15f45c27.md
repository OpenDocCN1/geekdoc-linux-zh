There is a difference between the two types of function definitions, but it has to do with the scope of variables, which is a topic in Chapter 6, "Advanced Variable Usage." If you are a C, C++, or Java programmer, you might be tempted to use the function definition style that uses parentheses, but don't. Using the function keyword style lets you have local variables, and the parentheses form not.

Who says UNIX commands have cryptic names

Using cryptic command names like this is fine if you are the only one who is going to remember what the names mean, and it can make interactive sessions more productive for you. However, if you are writing programs that will keep around for a long time or that other people besides yourself will use, use more descriptive command names.
