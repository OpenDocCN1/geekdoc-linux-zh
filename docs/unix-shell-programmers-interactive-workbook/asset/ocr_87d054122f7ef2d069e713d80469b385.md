# Appendix B: Built-In Command Reference 575

notify (b)

ksh displays a completion message on standard error immediately after each background job completes.

nounset (u)

ksh displays an error message when it tries to expand a variable that is unset.

privileged (p)

Not covered in this book.

ksh causes each command whose syntax of an alias name to become a tracked alias when it is first encountered.

trackall (h)

ksh displays its input on standard error as it is read.

verbose (v)

Puts in the vi built-in editor. Not covered in this book

vi

Specifies vi character-at-a-time input.

xtrace (x)

After expanding each simple command, ksh expands PS4 and displays it on standard error followed by the command and its expanded arguments.

# SHIFT

shift [n]

ksh shifts positional parameter(s) to the left by n. ksh discards the first n positional parameters. n is an arithmetic expression that must evaluate to zero, or a positive number less than or equal to the value of special parameter #. Default is 1.

# STOP

stop is a predefined alias for 'kill -s STOP'.
