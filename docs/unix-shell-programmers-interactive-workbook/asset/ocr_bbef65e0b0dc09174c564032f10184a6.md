# COMMAND TYPES

# LAB OBJECTIVES

After this lab, you will be able to:

+   - List All Built-In Commands
- Use Two Built-In Tools: print and whence
- Execute External Commands
- Define Aliases
- Write and Run a Simple Function

A command can be built-in, external, a function, or an alias. This lab examines how the shell determines the type of a command, and how each type is executed. It also shows you how to use the whence command to find out whether a command is built-in, external, a function, or an alias.

# LAB 2.2 BUILT-IN COMMANDS

Built-in commands are the ones, as their name implies, that are built into the shell itself. If a command name is one of these, the shell has a routine in its own memory that it calls on to do whatever the command calls for.
