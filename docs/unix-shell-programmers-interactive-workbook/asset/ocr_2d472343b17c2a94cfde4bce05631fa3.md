# 7.2.2 ANSWERS

+   a) What does the following command line accomplish?
  [ -e a_file ] || print a_file does not exist!
  Answer: It prints the “does not exist” message if a_file is the name of neither a file nor a directory (or any other I/O, communication, or other mechanisms that masquerade as files and directories in UNIX systems).

To understand the logic of this command line, you need to recall that the || operator causes the right side to be executed only if the left side fails—that is, if the left side’s exit code is false.

+   b) What do the return commands do?
  Answer: If they are executed, they cause the function to stop executing.

A script or function can contain any number of return statements. As shown in this example, they can be used to skip over parts of the program that you don’t want to execute.

Using return commands can make a program’s logic difficult to follow.
There are often clearer ways to structure your code.
