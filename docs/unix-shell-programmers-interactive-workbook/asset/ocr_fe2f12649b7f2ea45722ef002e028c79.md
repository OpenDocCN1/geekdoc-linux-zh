So far, you have been generally entering just one command per line, but even working in that framework, it has been impossible not to put multiple commands in one line on occasion. When a command generates too much output on screen, you have to pipe the output more or less. Most people who have used UNIX are familiar with this use of pipelines already.

In this chapter, you will look systematically at the various ways that the shell supports multiple commands in single command lines. We will look at these features mostly using the interactive features of the shell, but you will also find them extremely valuable as you write shell programs, too.
