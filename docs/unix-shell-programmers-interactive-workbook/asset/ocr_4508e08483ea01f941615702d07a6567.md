# Chapter 8: Loops 383

The function does not print all the command line options if the user explicitly types an empty string as an option, like the following interaction:

```
[8007]: u hello "" there
hello
[8008]:
```

If you want to print all the command line options using until, the function should look like the following:

```
function u {
  until  [[ ! "$1" ]]
  do
    print -- "$1"
  done
}
```

However, it is arguably more natural to do this using while:

```
function u {
  while  [[ "$1" ]]
  do
    print -- "$1"
  done
}
```
