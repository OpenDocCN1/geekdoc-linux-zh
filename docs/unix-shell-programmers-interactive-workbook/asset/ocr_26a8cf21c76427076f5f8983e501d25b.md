# Lab 5.2: Processing Option Parameters

```
5: c
[5083]: getops ab:c optletter
[5084]: print $OPTIND $optletter $OPTARG
5: ?
[5085]:
```

Here you can see that OPTIND is stepping along through the parameters, skipping number 3, because that was the position of the argument for the -b option. Also, note that line 5080 is the only one that prints a non-empty value for OPTARG. Whenever an option is followed by an argument, but when an option does not have an argument, getopts unsets the value of OPTARG, so it prints as an empty string in those cases.
