AnswerThe difference is that a reference to @@ inside double quotes is passed as separated arguments, but a reference to $* inside double quotes is passed as a single argument.

Your interaction should look like the following:

```
[5035]: s513 "@"
$# is 4
$@ My name is Your Name
$* My name is Your Name
[5036]: s513 "$*"
$# is 1
$@ is My name is Your Name
$* My name is Your Name
[5037]:
```

Now "@" is passed as four variables, but "*" is passed as one variable.
The spaces inside parameter 4 are preserved in both cases.

> Summary: If you want to pass positional parameters to a script with embedded spaces preserved, put double quotes around the references to @ and *. If you want to preserve embedded spaces and pass the positi tional parameters as separate values, use "$@", but if you want to pass a single parameter containing all the positional parameters, use "*$".You will find this distinction most useful when you are using loops, which will be covered in Chapter 8, "Loops".
