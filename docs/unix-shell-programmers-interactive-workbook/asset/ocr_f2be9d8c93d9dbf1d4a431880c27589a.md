# 4.1.1 USE PROPER TERMINOLOGY FOR VARIABLES

This exercise provides some practice using the proper terms for talking about variables. You don't need to know anything about actually using variables to do this practice.

Consult the Glossary in Appendix C, then write your own definitions of each of the following terms:

+   a) variable

+   b) name

+   c) value

+   d) reference
