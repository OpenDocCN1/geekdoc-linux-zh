+   i) Do you get the same results if you run this command several times?
Answer: Probably not.

The resolution of the clock used for timing things on most UNIX systems
is 0.01 second (10 msec), although compiled programs often have access
to timers with finer resolution. Because 10 msec is course-grained, com-
pared with the time it takes to execute a command, you typically have to
run timing tests several times and average the results to get meaningful
numbers.
