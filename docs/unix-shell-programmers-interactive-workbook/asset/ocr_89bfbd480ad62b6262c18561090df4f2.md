e) Type in these commands. What printed, and why?

Answer:The "ok" message printed.Your interaction should look like the following:

```
[7003]: if false
> false
> true
> then print ok
> else print not ok
> fi
ok
[7004]:
```

In this example, if the command is followed by three independent commands, all of which are run. The exit code of the last one (true in this case) determines whether the then or the else command group is run. In this case, the then group executes, printing the "ok" message.
