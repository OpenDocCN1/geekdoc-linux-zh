Answer:A variable is a {name, value} pair.

+   b) name
Answer:A variable name is a token used to identify a variable.

The rules for making variable names allow you to use any combination of letters (upper- and lowercase letters are different from each other), digits, and underscore characters (_). The first character of a variable must not be a digit. In Lab 6.2, “Arrays and Compound Variables,” you will see that you can also use compound variables that have variable names with dots in.

You will also see some variables that have various punctuation marks in their names and some that start with, but contain nothing, digits. These are variables that the shell creates itself, and they have names that “break the rules” in part so that you won't accidentally create variable names that conflict with them.
