# ## 63.3 部分二进制文件的特征

在十六进制的编辑器里，16位/32位数据组的特征十分明显。本节用一个简单的MIPS程序为例。前文介绍过：每个MIPS指令都是整齐的32位（即4字节）指令。当ARM模式或者ARM64模式的程序也有这个特征。因此，在形式上这些程序的指令构成了某种数据组。
