# 附录A x86

# A. 1 数据类型

16位 (8086/80286) 、32位 (80386等)和64位系统常用的数据类类型有：

byte（字节）：8位数据。声明字型数组和变量的汇编指令是DB。计算机使用寄存器的低8位空间存储字型数据。也就是说，字型数据通常存储在（寄存器辅助寄存器）CH/DH/SI/SIL/DI/R*

word（字）：16位数据。声明字型数组和变量的汇编指令是DW。计算机使用寄存器的16位空间存储word数据。也就是说，字型数据通常存储在（寄存器辅助寄存）AX/BX/CX/DX/SI/DI/R*W。

dword/double word：32位数据。声明Dword数组和变量的汇编指令是DQ。x86 CPU的标准寄存器及x64 CPU寄存器的32位空间都可以存储Dword数据。16位应用程序用寄存器来存储Dword类型数据。

qword/quad word：64位数据。声明Qword数组和变量的汇编指令是DQ。32位系统使用一对寄存器来存储Qword数据。

tbyte（10字节型）：80位，即10字节数据。符合IEEE 754标准的FPU寄存器都采用这种类型的数据。
