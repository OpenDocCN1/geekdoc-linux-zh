# 83.1.1 Trixter的42字节程序

Trixter在他的网站上[1]公开了具备42字节大小的程序。笔者把它摘录出来，并标注了自己的注释：

```
00000000:B001      mov       ; set 40x25 video mode
00000002:CD10      int       010
00000004:30FF      xor       bh,bh      ; video page for int
10h         call
00000006:B9D007      mov       xch,07D0  ; 2000 characters to
output:
00000009:31C0      xor       ax,al
0000000B:9C        push              ; push flags
; get random value from timer chip
0000000C:FA        cli              ; disable interrupts
0000000D:E643      out       043,al      ; write 0 to port 43h
; read 16-bit value from port 40h
0000000F:E440      in        al,04
00000011:88C4      mov       ah,al
00000013:E440      in        al,04
restoring IF flag
00000015:9D        popf              ; enable interrupts by
00000016:86C4      xch       ah,al
; we have 16-bit pseudorandom value
00000018:D1E8      shr       ax,1
0000001A:D1E8      shr       ax,1
; CF carry have second bit from the value
0000001C:B05C      mov       al,05C;''
; if CF=1, skip the next instruction
0000001E:7202      jc        00000022
; if CQ, reload AL register with another character
00000020:B02F      mov       al,02F;''
; output character
00000022:B40E      mov       ah,00E
00000024:CD10      int       010
00000026:E2E1      loop      00000009  loop 200 times
00000028:CD20      int       020       ; exit to DOS
```

实际上的，上述程序中的随机数是Intel8253计时器（硬件）回传过来的时间信息。它用了零计数器，而时钟决定这个计时器每秒递增1.2次。

向43端口发送零字符，相当于发送了“选定#0（通用）计数器”“计数器的输出可读”和“采用二进制计数（返回值为二进制数字，而非BCD）”这三条指令。[2]

当程序执行POPF指令时，CPU恢复IF标识的同时恢复终端功能。
