就是从相应读取1个比特位。

如此看来，rotate1/2/3的作用就是以特定层旋转所有比特位。这三个参数分别旋转魔方的不同平面，而参数v代表的是设置隔层的位置(0~7)。

或许，这个算法的作者就是数据操作8×8的魔方来处理的。

再次整理decrypt(1)函数的分析结果后，可推导出下列源代码：

```
void decrypt(BYTE *buf, int sz, char *pw)
{
    char *strdup(pw);
    strrev(p);
    int i=0;
    do {
        memcpy(p, cube,buf+i, 8*8);
        rotate_all(p, 3);
        memcpy(buf+i, cube, 8*8);
        i+=64;
    } while (i<sz);
    free(p);
};
```

该函数通过标准C函数strrev ([2])对密字符字符串进行逆序排列，而且传递rotate_all()函数的参数是3。除此之外，它和crypt()函数基本一一致。

因此，解码过程用了rotate1/2/3。

和魔方的玩法没有任何区别！如果你要取消调整魔方的操作，那么就要用相反的次序和相反的方向进行等幅操作。例来说，您刚刚顺时针转动了魔方的某一层块，后来又要取消那次操作，那么就把魔方层顺顺时针旋转回来，不然就顺顺时针旋转3次。

如果说rotate1()函数旋转的是魔方的“正”面，那么rotate2()函数旋转的则是“上”面，而rotate3()函数用于旋转魔方的侧面。
