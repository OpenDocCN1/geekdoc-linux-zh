# 18.2.2 向数组边界之外的地址写入

既然我们可以“非法地”利用指针读取数组边界之外的数值，那么我们也可以向数组边界之外的地址写入数据呢？

可以通过下面的程序进行验证。

```
#include <stdio.h>

int main() 
{
    int a[20];
    int i;

    for (i=0; i<30; i++)
        a[i]=i;

    return 0;
}
```
