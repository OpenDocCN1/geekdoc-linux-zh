# Optimizing MSVC 2012

指令清单19.32 MSVC 2012

```
a$ = 8
f      PROC
; RCX = input value
xor     eax, eax
mov     edx, 1
lea     r8, DWORD PTR [rax+32]
; EDX = i, R8D = 32
pad     5
$LL4:
; pass 1

    test    rdx, rcx
    je      SHORT LN3@f
    eax     ; rt++
$LN3@f:
    rol     rdx, 1 ; RDX=RDX<<1

; pass 2

    test    rdx, rcx
    je      SHORT LN11@f
    eax     ; rt++
$LN11@f:
    rol     rdx, 1 ; RDX=RDX--

    dec     r8          ; R8--
    jne     SHORT $LL4@f
fatret  0
```

MSVC 2012优化编译后的生成的代码与MSVC 2010大体相同。但是MSVC 2012把迭代次数为64次的循环，拆分为两个迭代32次的循环。但坦白，笔者也不清楚中中由。或许是循环长度更长一些比较好。总之，我把这个例子记录下来，希望读者注意：编译器可能产生各种事乎所料的代码，但是这些代码的功能仍然会忠于源程序。
