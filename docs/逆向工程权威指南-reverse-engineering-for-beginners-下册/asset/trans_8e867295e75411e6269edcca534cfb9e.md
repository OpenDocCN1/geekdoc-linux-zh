观察函数()，IDA能够识别外部参数。它会对内存数据进行标注，如“RETURN”之类的标注。故，被调用函数的参数不在自己的帧，而是在调用者的帧里。

### 8.1.3 GCC

使用 GCC 4.4 编译上述程序，然后使用 IDA 查看它的汇编：

```assembly
public f
arg_0 = dword ptr 8
arg_4 = dword ptr Ch
arg_8 = dword ptr -8

push ebp
mov ebp, esp
mov eax, [ebp+arg_0] ; 第一个参数
imul eax, [ebp+arg_4] ; 第二个参数
add eax, [ebp+arg_8] ; 第三个参数
pop ebp
ret
```

GCC的编译结果和MSVC十分相似。不同的是调用函数(printf)没有还原指针。由于函数尾部的指令——LEAVE（参见附录 A.6）。

### 8.2 x64

### 8.2 MSVC

启用优化选项后，MSVC编译的结果：

```assembly
main
  sub rsp, 40
  mov edx, 2
  lea r8, QWORD PTR [rsp+1] ; R8=3
  lea rcx, QWORD PTR [rsp-1] ; ECX=1
  call f
  lea rcx, offset "%d" ; shadow space
  mov edx, eax
  call printf
  xor eax, eax
  add rsp, 40
  ret
```

```assembly
f
  ; ECX - 第一个参数
  ; EDX - 第二个参数
  ; R8 - 第三个参数
  imul ecx, edx
  lea eax, DWORD PTR [r8+rcx]
  ret
```

看到，f()通过寄存器获取了全部参数。此处的加法是通过LEA指令实现的。明显，编译器认为LEA指令比ADD指令高，所以它分配了LEA指令。f函数的第一个和第三个参数，main()使用了LEA指令。

### 8.2.2 GCC

在优化选项后，GCC生成的代码更为内联：

```assembly
f:
  ; EDI - 第一个参数
  ; ESI - 第二个参数
  ; EDI - 第三个参数
  imul esi, edi
  lea eax, [rdx+rsi]
  ret

main:
  sub rsp, 28h
  mov r8d, 3 ; 第三个参数
  mov edx, 2 ; 第二个参数
  mov ecx, 1 ; 第一个参数
  mov f
  call f
  mov edx, eax
  lea rcx, "%d\n"
  call printf
  return 0
  xor eax, eax
  add rsp, 28
  ret
```
