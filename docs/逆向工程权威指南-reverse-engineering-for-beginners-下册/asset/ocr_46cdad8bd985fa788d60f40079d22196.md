# 8.2.3 uint64_t 类型 GCC

指令清单8的源程序使用的是32位int型参数，所以以上的汇编指令使用的寄存器都是64位寄存器的低32位（即E-开头寄存器）。如果把参数改为64位数据，那么汇编指令就会略有不同：

```
#include <stdio.h>
#include <stdint.h>

uint64_t f (uint64_t a, uint64_t b, uint64_t c)
{
    return a*b+c;
}

int main() {
    printf("%lld\n", f(0x112223334455667788, 0x11111111122222222222, 0x33333333344444444444));
    return 0;
}
```

# 指令清单8.8 Optimizing GCC 4.4.6 x64

f proc near
imul rsi, rdi
lea rax, [rdx+rsi]
retn
endp

main

mov rdx, 33333333344444444h ; 3rd argument

mov rdi, 1122334455667788h ; 1st argument

mov edi, offset format ; "%lld\n"
