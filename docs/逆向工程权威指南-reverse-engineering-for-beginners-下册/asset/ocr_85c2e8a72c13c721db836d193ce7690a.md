# 第28章 ARM指令详解

# 28.1 立即数标识（#)

在Keil编译器的链接眼里，以及在IDAobjdump程序显示ARM的汇编指令时，立即数（汇编指令中的常量）前面都有“#”标识。然而GCC 4.9的编译文件中没有这种立即数标识。请对照一下14.1.4节和39.3节中的指令清单。

本章列举了很多例子，它们是由多种编译器生成的汇编代码。有些汇编指令的立即数实实并没有标识，因为它们是GCC编译出来的文件。

这种问题或许谈不上谁谁更为正宗。我们也建议读者不必深究这种格式上的问题。

# 28.2 变址寻址

以64位的寻址标识为：

```
ldr x0, [x29,24]
```

上述指令从X29寄存器中取值，把这个值与24相加，再将术术应对地址的值复制给X0寄存器。请注意，X29和24都在方号之中。如果24不在方号里，指令的涵义就完全不一样了。我们来看：

```
ldr w4, [x1],28
```
