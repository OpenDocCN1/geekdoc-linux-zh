上述代码中的“B”指令为IDA生成的指令。它的原始指令是BEQ。

# 14.1.6 其他

您可能注意到了，在对循环控制变量/初始化赋值值之后，程序首先检查变量/是否满足循环条件。在满足循环表达式的情况下，才会运行循环体的指令。这恐怕是有意而为之的。如果循环变量的初始值不能满足循环条件，那么整个循环体就不会被执行。例如，下面例子中的循环体可能不会被执行。

```
for (i=0; i<total_entries_to_process; i++)
  loop_body;
```

如果变量total_entries_to_process等于零，就不应当执行循环体。否则，循环控制变量有必要首先检查循环的初始值是否满足循环条件。

在启用优化项后，如果编译器能够判断循环语句的初始状态可能满足循环体的执行条件，那么它可能不会生成该循环体的检测指令和循环体的对应指令。在启用编译器的优化功能之后，在编译本例的源程序时，Keil、Xcode (LLVM)、MSVC都能做到这种程度的优化。

# 14.2 内存复制

目前的计算机多数采用了SIMD和矢量化等技术，在内存复制数据时，能够在每次迭代中复制4~8字节。本节将从一个尽可能简单的例子开始演示。

```
#include <stdio.h>

void *memcpy(unsigned char *dst, unsigned char *src, size_t cnt)
{
  size_t i;
  for (i=0; i<cnt; i++)
    dst[i]=src[i];
}
```
