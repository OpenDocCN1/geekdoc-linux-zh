当直接向0、1、2号参数存储数据时，可以使用专用的istore_n指令。然而直接向4及更高编译的参数存储数据时，就没有这样方便的专用操作指令了，需要使用带有参数的参数指令。如果偏移量为8的指令所示，后一种istore指令将操作数参数的编号进行存储操作。其实istore指令也是如此。我们就不再需要解编译10的指令了。

但是，像迭代上限limit这样的常量也占据了参数，难道它经常更新值吗？JVM JIT优化器能够充分优化这类事务，我们不必进行人工干预。

# 54.12 switch（语句）

下列例说明，switch语句是由tableswitch实现的。

```
public static void f(int a) {
    switch (a) {
        case 0: System.out.println("zero"); break;
        case 1: System.out.println("one\n"); break;
        case 2: System.out.println("two\n"); break;
        case 3: System.out.println("three\n"); break;
        case 4: System.out.println("four\n"); break;
        default: System.out.println("something unknown\n");
    }
}
```
