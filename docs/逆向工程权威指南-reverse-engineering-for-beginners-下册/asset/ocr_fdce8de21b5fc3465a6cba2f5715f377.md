# # 第1章 CPU简介

CPU是执行程序机器的硬件单元。简要来说，其相关概念主要有以下几项：

指令码：CPU受理的底层命令。典型的底层命令有：将数据在寄存器间转移、操作内存、计算运算等指令。每CPU都有自己的指令集架构（Instruction Set Architecture, ISA）。

机器码：发送给CPU的程序代码。一条指令通常被封装为若干节。

汇编语言：为了让人头部发而创造出来的、易读易记的代码，它有很多类似宏的扩展功能。

CPU寄存器：每种CPU都有固定的通用寄存器（GPR）。x86 CPU一般的8个GPR，64位而ARM则未16个GPR。您可以认为CPU寄存器是一种存储单元，它能够无差别地存储所有类型的临时变量。如果您使用一种高级的编程语言，并且使用到32位变量，那么光靠CPU的带寄存器就能完成不少任务了！

那么，机器码和编程语言（PL）的别在哪里？CPU不像人类一样，能够理解C/C++、Python等编程语言比较接近人类的高级编程语言。汇编语言更接近硬件底层的具体语言。在不久的将来，可能会让你直接执行高级编程语言的CPU，那种尚未未人类世界的CPU必定比现在的CPU要复杂。人类和机器各有所长，如果人类直接使用接近底层的汇编语言编写程序，其难度也很高——因为那样很容易出现大量的人为失误。可见，我们需要用一种程序高级的编程语言转换为
