# 59.1.1 动态主机配置协议 (Dynamic Host Configuration Protocol, DHCP)

网络数据同样使用了魔数。比如，DHCP协议的网数据就会被用到魔数0x663538263-这个魔数叫做magic cookie。所有符合DHCP协议的数据都必须使用这个魔数。如果我们找到了这个魔数，我们就可能确定此处代码可能用于实现DHCP协商。不仅如此，能接受DHCP的程序都必须验证这个魔数，它就是与它比对。

比如此，我们在Windows 操作系统（64位操作系统）中的文件dhcpore.dll文件为例，我们可以在这个文件中搜索这个魔数。结果发现了两个，出现在两个函数中，其名称分别是DhcpExtractOptionsForValidation()和AndDhcpExtractFullOptions()

指令清单59.2 dhcpore.dll (Windows 7 x64)

```
.data:000007FF6483CBE8 dword_7FF6483CBE8 dd 65382636h
; DATA XREF:
\ DhcpExtractOptionsForValidation+79
\rdata:000007FF6483CBEC dword_7FF6483CBEC dd 65382636h
; DATA XREF:
\ DhcpExtractFullOptions+97
```
