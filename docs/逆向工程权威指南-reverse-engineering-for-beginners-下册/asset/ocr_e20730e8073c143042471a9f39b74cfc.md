# 16.1.2 替换为位移运算

编译器通常会把“乘以除以2”的运算指令处理为位移运算指令：nunsigned int f(unsigned int a)
{
    return a*4;
}

```
指令清单16.2 Non-optimizing MSVC 2010
a$f = 8      ; size = 4
_f PROC
    push ebp
    mov  ebp, esp
    mov  eax, DWORD PTR _a[ebp]
    shl  eax, 2
    pop  ebp
    ret  0
_f ENDP
```

“乘以4”的运算就是把被左移2位、再把位移产生的空位添上0的运算。就好比在算法计算3×100的时候，我们在后面的空缺位添加两个零。
