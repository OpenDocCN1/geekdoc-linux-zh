| 代码 | 描述 | 标识位 |
|---|---|---|
| EQ | 相等 | Z==1 |
| NE | 相异 | Z==0 |
| CS/HS | Carry置位/Unsigned, 大于或等于 | C==1 |
| CC/LO | Carry为零/Unsigned, 小于 | C==0 |
| MI | Minus, 负数/小于 | N==1 |
| PL | Plus, 正数或零/大于或等于 | N==0 |
| VS | 溢出 | V==1 |
| VC | 未溢出 | V==0 |
| HI | Unsigned大于 | C==1 and Z==0 |
| LS | Unsigned小于等于 | C==0 or Z==1 |
| GE | Signed大于或等于 | N==V |
