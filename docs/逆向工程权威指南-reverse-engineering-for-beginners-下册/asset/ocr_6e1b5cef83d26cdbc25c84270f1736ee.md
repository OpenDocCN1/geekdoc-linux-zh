```
r8=rax=0xD2E9EE7E83C428B;

return _lrotl(r8, r8 % 60); // rotate left
};
```

最终，我们将程序转化成华丽的C语言代码：

```
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <string.h>
#include <intrins.h>

#define C1 0x5D7E0E1F2E0F1F84
#define C2 0x388D76AEE8BC1500
#define C3 0xD2E9EE7E83C4285B

uint64_t hash(uint64_t v) {
    v^=C1;
    v=_lrotl(v, v&0xF); // rotate right
    v^=C2;
    v=_lrotl(v, v&0xF); // rotate left
    v+=C3;
    v=_lrotl(v, v%60); // rotate left
    return v;
}
```

```
int main() {
    printf("%llu\n", hash(...));
};
```

除了加密专家之外，外没有人能够根据hash值逆推原始数据。旋转位左/右移位符足以让人望而却步——它能够证明函数不是单向射函数，而且保留了碰撞的可能性；说直白一些些就是“多个输入可能产生一个输出”。

由于这个函数采用了64位数字，所以暴力破解就不太现实。
