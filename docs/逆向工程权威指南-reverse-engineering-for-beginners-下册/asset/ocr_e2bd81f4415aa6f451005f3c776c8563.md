# 92.1 MSVC

MSVC 2012生成的主循环的指令如下所示。

> 指令清单92.1 MSVC 2012

```
push        OFFSET  _main$s1
push        0
push        1
call        _vcomp_fork
add         esp, 16      ;
00000010H
```

所有vcomp开启的函数都是与OpenMP相关的函数，通过
vcomp*.dll进行加载。它将发起一组程序进行并行计算。

具体来说，_main$s1的汇编代码如下:

> 指令清单92.2 MSVC 2012

```
$T1 = -8              ; size
      = 4
$T2 = -4              ; size
      = 4
_main$s1 PROC      ;
COMDAT
push       ebp
mov        ebp, esp
push       ecx
push       ecx
push       esi
lea        eax, DWORD PTR $T2[ebp]
push       eax
lea        eax, DWORD PTR $T1[ebp]
push       eax
```
