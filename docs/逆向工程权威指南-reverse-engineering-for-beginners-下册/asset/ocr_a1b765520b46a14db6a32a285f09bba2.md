# XMM1: 0000ff000000000000ff000000000

就是说它找到了2以上的零。这是推理之中的结果。

在这种情况下PMOVMSKB指令将设置EAX为（二进制）：n00100000001000000b。

很明显，我们的函数必须以第一个结束符为准，忽略数据里的结束符。

下一条BSF（Bit Scan Forward）指令将保留操作二进制值里的第一个1，将其位位清零，并将结果存储到第一个操作操作符里。

在EAX=0010000000000000的情况下，执行 `bsf eax, eax`，那么EAX将保留第5位的1（从0开始）。

MSVC这里指令对应的是**BitScanForward**。

代码的其他部分比较容易理解。如果找到了0字节，就把它的位置编号累加到计数器里，从而获取字符串长度。

应当注意到MSVC编译器优化优化了循环的部分结构。
