## 10.2 局部变量

下面，我们略微调整程序，使其通过局部变量完成相同的功能。

### 指令10.2 将和、变量存储在局部变量里

```c
void main ()
{
    int sum, product; // now variables are local in this function

    f1(123, 456, &sum, &product);
    printf ("sum=%d, product=%d\n", sum, product);
}
```

编译之后，f1()函数的汇编代码与使用全局变量的代码完全相同。而 main()函数的汇编代码会有变化。启用 /0b 选项编译后，会如下所示。

### 指令10.3 Optimizing MSVC (/0b)

```asm
_product$ = -8          ; size = 4
_sum$ = -4               ; size = 4
_main    PROC            ; Line 10
    sub esp, 8
    lea eax, PTR _product$[esp+8]
    push eax
    lea ecx, PTR _sum$[esp+12]
    push ecx
    push 456             ; 000001c8
    push 123             ; 0000007b
    call f1               ; Line 14
    mov eax, PTR _product$[esp+24]
    mov ecx, PTR _sum$[esp+24]
    push ecx
    push OFFSET 2803
    call PTR __imp_printf ; Line 15
    xor eax, eax
    add esp, 36          ; 00000024H
    ret
```
