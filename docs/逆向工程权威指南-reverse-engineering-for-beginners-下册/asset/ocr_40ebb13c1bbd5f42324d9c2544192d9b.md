除了“try-except” 语句之外，MSVC还支持“try-finally” 语句：

```
try
{
}
finally
{\}
```

前者的“filter code”是一个用来判断是否执行“handler code（响应指令)”的表达式。如果代码太长、无法表示为一个表达式，那么就得借助独立的过滤函数。

Windows内核大量使用这种结构。以 WRK (Windows Research Kernel) 的某某段指令为例：

```
try {

KeReleaseMutant(PKOMUTANT)SignalObject,
	MUTANT_INCREMENT,
	FALSE,
	TRUE);

except ((GetExceptionCode()) == STATUS_ABANDONED ||
	GetExceptionCode() == STATUS_MUTANT_NOT_OWNED |
	EXCEPTION_EXECUTE_HANDLER :
	EXCEPTION_CONTINUE_SEARCH) {
	Status = GetExceptionCode();

goto WaitExec;
```
