
```csharp
static void Main(string[] args)
{
  double realCoord, imagCoord;
  double realTemp, imagTemp, realTemp2, arg;
  int iterations;
  for (imagCoord = 1.2; imagCoord >= -1.2; imagCoord += 0.03)
  {
    for (realCoord = -0.6; realCoord <= 1.77)
    {
      iterations = 0;
      realTemp = realCoord;
      imagTemp = imagCoord;
      arg = (realCoord * realCoord) + (imagCoord * imagTemp * imagTemp);
      while ((arg < 2*2) && (iterations < 40))
      {
        realTemp2 = (realTemp * realTemp) - imagTemp;
        imagTemp = (2 * realTemp * imagTemp) - imagCoord;
        realTemp = realTemp2;
        arg = (realTemp * realTemp) + (imagTemp * imagTemp);
        iterations += 1;
      }
      Console.Write("(0,2:D) ", iterations);
    }
    Console.Write("\n");
  }
  Console.ReadKey();
}
```

## 83.2.2 demo程序

本节将介绍的这个曼德博集合的demo程序，由30条指令、64个字节构成。虽然它的算法与前文的算法一致，但是它用到了很多编程技巧。

整个程序的源代码是公开的。为了让读者阅读，笔者添加了一些注释：

这个程序的算法是：

- 切换到分辨率为320×200/256的VGA模式。320×200=64000(0xFA00)。256的每个像素都是单字节，所以缓冲区大小就是0xFA00。
- VGA图形区域的地址要存储在ES寄存器里，所以ES寄存器的值必须是0xFFFF。但是ES寄存器有0xFFFF的指令至少要用4个字符（PUSH 0xFFFF）。有6个MS-DOS系统的内存模型，可以参见第94章的详细介绍。
- 假设BX寄存值为段、程序前缀（Program Segment Prefix）位于0号地址，那两个字符LES AX、在AX寄存器存储0x0DC、在ES寄存器存储0xFF。这个程序在图形缓冲区输出16像素。因为这个程序的运行平台是MS-DOS，而且没有实现内存保护，以这种方式不会引发程序崩溃。不过，屏幕右侧多出了16像素的彩色带，整个图像移动了16像素。这就是程序里只有两个字节的空间。
- 单循环处理像素。在处理图像时，一般的程序都会使用两个循环：一个循环遍历像素、另一个循环遍历坐标。在VGA图形区域里通过坐标来定位像素，双循环的程序必须通过乘法运算才能找到。借此，这个程序的作者使用单循环的数据结构，通过除法运算获取当前点的起始位置。转换后，坐标的取值范围是x~[-256,63]，y~[-100,99]。如此，整个图像的中心点是：直接将Y的值减去16就可以它的取值范围变成[-160,159]，或者按照图像所示，使用“SUB DX”的指令需要用4个字符，用作者的“DEC DX”（相当于SUB DX,0x100）两个字符。图像中心偏移就是节省文件空间的代价。
- 检测当前点是否属于曼图像。检测算法和正文相同。
- 以CX寄存器作为计数器进行LOOP循环。作者没有明确说明循环次数，而是让CX寄存器继续使用第35的值（320）。或者，数值越大越高效。这样可以节省文件空间。
- 使用IMUL指令。因为操作是有符号数，所以乘法指令是MUL。为了把起点坐标0调整到屏幕中心区域，在转换坐标时（除法）用到的SAR指令（带符号右移），而不是SH指令。
- 简化溢出检测的算法。常规检测方法是坐标，即对坐标值进行。作者三次检测了溢出问题：两个减法操作和一次加法的溢出后面再次运行的SAR指令（相当于64）设置了64像素灰度。调灰色的跨度越大，对比越高，图像就越清晰；对比越低，图像就越模糊。
- 这个程序采用的是无限循环，不能正常退出。如果要循环终止或进行交互，那么程序还需要更大。此外，这个程序的优化技巧同样：
    - 使用单字的DX清空，“XOR DX, DX”占用2个字；之下，“MOV DX,0”占用3个字。
    - 使用单字的AX，“CHG AX, CX”完成双字操作。毕竟后不再使用AX器，以便交换完全造成任何问题。因为程序没有对DI（缓冲区）进行初始化，它启动时的初始值是0xFFFE。不过这无害，这个程序只需要DI保持在[0,xFFFF]之间。
