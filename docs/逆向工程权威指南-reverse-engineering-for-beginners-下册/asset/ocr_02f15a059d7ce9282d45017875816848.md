| 选 项 | 作 用 |
| --- | --- |
| disas function | 查看函数的汇编指令 |
| disas function, +50 disas $eip, +0x10 | 查看函数的部分汇编指令（同上） |
| disas/r | 查看接下来的几条指令 |
| info registers | 查看opcode |
| info float | 显示CPU各寄存器的值 |
| info locals | 显示FPU各寄存器的值 |
| x/w ... | 列出全部的局部变量（如果能识别出来） |
| x/w $rdi | 读取内存，并显示为word数据 |
| x/10w ... | 从RDI指定的地址读取数据，显示为word |
| x/s ... | 读取并显示10个word型数据 |
