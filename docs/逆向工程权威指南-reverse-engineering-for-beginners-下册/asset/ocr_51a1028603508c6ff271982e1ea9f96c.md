64位寄存器特有的R8~R15寄存器仅有相应的（低）32位助记符，即R8D~R15D（32位），而且还有相应的（低）16位标识符R8W~R15W。

x86-64框架的CPU有16个SIMD寄存器，即XMM0~XMM15。它的SIMD寄存器比x86 CPU多一倍。

+   * Win64系统的函数调用约定发生了相应的变化，采取了fastcall规范（请参见本书64.3节）相似的参数传递规范。这类程序使用RCX、RDX、R8、R9寄存器传递函数所需的前4个参数，并栈传递剩余参数。为了保证函数能够使用前4个参数所占的寄存器，调用用函数会分配出来32字的栈空间，以便被调用用函数函数保存4个参数寄存器的原始状态。虽然小型函数可能不会用到多少寄存器，但是大型函数可能就需要把传入的参数保存到内存，并尽量充分使用所有寄存器。

System AMD64 ABI（泛Linux、各种BSD和Mac OS）系统的函数调用约定也与fastcall规范相似。它使用RD、RSI、RDX、RCX、R8、R9这6个寄存器传递前6个参数，再使用寄存器传递剩余参数。

本书的第64章详细介绍了各种调用约定。

+   * 在C/C++语言中，x86-平台的int型数据仍然是32位指针。
* x86-64平台的指针都是64位指针。

不过实际情况并非理想，x64 CPU在外部RAM的寻址能力只有48位。但是存储指针，包括堆区的开销却高出86倍。
