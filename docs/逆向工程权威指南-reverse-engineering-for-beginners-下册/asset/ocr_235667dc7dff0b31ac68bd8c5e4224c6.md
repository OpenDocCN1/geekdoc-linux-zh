度浮点数。

最后，我们来看看如果什么也不返回时情况会是那样的，就是return指令后不带任何参数。

```
public class ret
{
    public static void main(String[] args)
    {
        return;
    }
}
public static void main(java.lang.String[])
flags: ACC_PUBLIC, ACC_STATIC
Code:
stack=0, locals=1, args_size=1
0: return;
```

没有返回函数的，最后只有一条return指令。它不返回任何值，只是把程序控制流交给调用函数。根据函数最后一条返回值处理指令，我们可以比较容易地推出函数返回的数据类型。
