## 21.4 结构的字段封装

结构的字段封装方法构成了这种数据类型的一个重要特性。[6]

我们以后下面的例子来加以。

```c
#include <stdio.h>
struct s {
    char a;
    int b;
    char c;
    int d;
}
void f(struct s s) {
    printf("a=%d; b=%d; c=%d; d=%d\n", s.a, s.b, s.c, s.d);
}
int main() {
    struct s tmp;
    tmp.a=1;
    tmp.b=2;
    tmp.c=3;
    tmp.d=4;
    f(tmp);
}
```

其中有2个单字节型char字段和2个4字节的int型变量。

经过这种处理之后，结构体只占用10字节空间，其中的char数据占用10字节。这将提高代码的空间利用率，不过这样做会降低CPU的10倍读取效率。main()函数同样使用结构体复制了传入的信息，再把临时结构体传递给其他函数。对于这10字节数据一个字段一个字段地、按字节声明的指令需要4次复制才能完成。编译分配mov指令复制它们。为什么不是对齐指令呢？这是因为编译器认为是：在复制10字节数据时，mov指令对（字节对齐）值的效率要高。这是编译器常用的优化手段。编译器使用memcpy函数的情况十分普遍，如需解答这方面详细知识，请参见书43.1.5节。
