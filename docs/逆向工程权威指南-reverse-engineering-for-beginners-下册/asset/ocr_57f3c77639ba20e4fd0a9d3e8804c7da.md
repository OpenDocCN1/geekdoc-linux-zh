在执行过程中，堆中的previous try level改变了，因此函数_except_handler能从当前的嵌套中获取信息，目的是知道哪个scope表变化。

执行期间，栈中的previous try level字段会发生变化。_except_handler3根据这项数据获取当前嵌套的信息，从而判断要使用scope table中的某项链。每一个try块都分配了一个唯一的索引作为标识，copetable表中项（entry）间的关系描述了每一个try块的嵌套关系。

# SEH3：try/except块的例子

```
#include <stdio.h>
#include <windows.h>
#include <except.h>

int main() {
    int* p = NULL;
    try {
        printf("hello !1!\n");
        *p = 13; // causes an access violation exception
        printf("hello !2!\n");
    } catchGetException()==EXCEPTION_ACCESS_VIOLATION ? EXCEPTION_EXECUTE_HANDLER : EXCEPTION_CONTINUE_SEARCH) {
        printf("access violation, can't recover\n");
    }
}
```
