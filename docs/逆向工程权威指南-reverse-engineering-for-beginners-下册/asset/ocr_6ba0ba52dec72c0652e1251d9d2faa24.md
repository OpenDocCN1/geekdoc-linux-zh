# 14. 1.4 ARM
Non-optimizing Keil 6/2013 (ARM mode)

```
main
  STMFD SP, {R4,LR}
  MOV R4, #2
  B   loc_368
loc_35C ; CODE XREF: main+1C
  MOV R0, R4
  BL  printing_function
  ADD R4, R4, #1
loc_368 ; CODE XREF: main+8
  CMP R4, #0xA
  BLT loc_35C
  MOV R0, #0
  LMFD SP, {R,PC}
```

上述代码中的R4寄存器用于存储循环计数器（即变量i）。

“MOV R4, #2”给变量进行初始化值。

“MOV R0, R4”和“BL printing_function”指令构成成体。前者负责向被调用函数传递参数，后者则直接调用printing_function ()函数。

“ADD R4, R4, #1”指令在每次迭代之后进行++++的运算。

“CMP R4, #0xA”指令会比较变量/和数字10（十六进制的0xA）。下一条指令BLT（Branch Less Than）会在<10的情况下跳转；否则执行
