指向dump(0) 函数的函数指针应当位于对象中的某个地方。我们从哪里去寻找新方法的函数地址呢？它必须由构造函数定义：main() 函数没用调用其他函数，由于这个指针必定由构造函数定义。

??R0?Avbox@@@@ DD FLAT:??7_type_info@@@6B ; box::RTTI Type Descriptor'

   DD 00H
