# ### 22.1 伪随机数程序

我们可以通过不同的方法生成一个0~1之间的随机浮点数。最简单的做法是：使用Mersenne twister（马马赛特旋转变换算法）之类的PRNG生成32位DWORD值，把这个值转换为单精度float之后再用RAND_MAX（本例中是0FFFFFFFF）就可以得到0~1之间的随机浮点数。

但是除法的运算速度非常慢。而且从效率的角度考虑，随机函数应当尽量使用FPU的操作指令。那么，我们是否可以彻底脱离除法运算随机函数呢？

单精度浮点数（float）数据由符号位、有效数字和指数部分构成。这种数据结构决定，只要随机填充有效数字就可以生成随机的单精度数!！

依据有关规定，随机浮点的指数部分不可以为0。那么把指数部分直接设置为01111111（即十进制的1），用随机数字填充有效数字部分，再把指数位设置为零（表示正数）。瞧！像模一样！这就可以生成一个1~2之间的随机数。再把把它减1就可以得到一个标准的随机函数。

本例使用了线性同余随机生成随机数的算法[2]。它使用UN系统的系统时间作为PRNG的随机种子，从而生成32位数字。
