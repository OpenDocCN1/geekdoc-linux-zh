```
call    _puts
mov     eax, offset aD ; "%d"
lea     edx, [esp+20h+var_4]
mov     [esp+20h+var_1C], edx
mov     [esp+20h+var_20], eax
call    isoc99_scanf
mov     edx, [esp+20h+var_4]
mov     eax, offset aYouEnteredD ; "You entered
%d...\n"
mov     [esp+20h+var_1C], edx
mov     [esp+20h+var_20], eax
call    _printf
leave
retn
endp
```

GCC bprintf() 替换为 puts(),这和3.4节中的现象相同。

此处，通过MOV指令实现粘操作，这个点和MSVC相同。

其他

这个例子充分证明：在编译过程中，编译器会编译C/C++代码的表达式的顺序和模块化结构。在C/C++代码中，只要两个相邻语句之间没有其他的表达式，那么在生成的机器码中对应的指令之间就不会有其他的指令，而且其执行顺序与源代码中各语句的书写顺序相同。

# 7.1.4 x64
