内嵌处理之后，strlen()函数的第一个指令是：OR
RAX, 0xffffffffffffffff。我们不清楚是否MSVC采用（或）指令，
而没有采用MOV RAX, 0xffffffffffffffff直接赋值。当然，这两
条指令执行的是相同操作：将所有位置设置为1。因此这个数值就是赋值
-1。我们可以参考本书的第30章。

你可能也会问，为什么strlen()函数用到-1这个数字？当然是出
于优化的目的。在这里列出了MSVC的编译代码。

# 指令清单47.2 x64的MSVC 2013的内嵌函数strlen()

```
; RCX = pointer to the input string
; RAX = current string length
    or rax, -1
label:
    inc rax
    cmp BYTE PTR [rcx+rax], 0
    jne SHORT label
; RAX = string length
```

如果把这个变量的初始值设置为0，那么是否可以把代码压缩更
短一些呢？我们可以来试试。

# 指令清单47.3 我们的strlen()字符串长度函数版本

```
; RCX = pointer to the input string
; RAX = current string length
    xor rax, rax
label:
    cmp byte ptr [rcx+rax], 0
    jz exit
    inc rax
    jmp
```

```
exit:
; RAX = string length
```

我们未能成功。因为我们不得不加入了一个额外的指令：JMP跳转
指令。

在使用“-1”作为初始值之后，MSVC 2013随在加载字符的指
令之前分分配了一个INC指令。如果第一个字符是0（终止符），那么RAX
就直接为0，返回的字符串长度还是0。
