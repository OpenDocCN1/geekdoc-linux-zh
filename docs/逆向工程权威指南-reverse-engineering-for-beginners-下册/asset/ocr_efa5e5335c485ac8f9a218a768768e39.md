为了便于记忆，我们总结其特点如下：

+   - 同一个数值就可以表示有符号数，也可以表示无符号数。
- C/++的符号型数据：
  - int64_t（范围从-922337203685475808至922337203685475807，即从0x8000000000000000至0xFFFFFFFFFFFFFFFF）
  - int（取值范围从-2147483648至2147483647，即从0xFFFFFF）
  - char（取值范围从-127到128，即从0x7F到0x80）
  - size_t。
- 无符号型数据：
  - uint64_t（范围从0到184467440370951615/0xFFFFFFFFFFFFFFFF）
  - unsigned int（取值范围从0到4294967295，即从0到0xFFFFFFFF）
  - unsigned char（取值范围从0到255，即从0到0xFF）
  - size_t。

有符号数的最高数位是符号位：1代表负数，0代表正数。

从数据宽度较小的数据转换为数据较大的数据是可行的。参见前面24.5节。
