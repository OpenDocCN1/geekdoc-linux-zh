## 14.2.3 MIPS

指令清单14.14 GCC 4.4.5 optimized for size (-Os) (IDA)

```assembly
my_memcpy;
; 跳转到循环检查部分：
    b loc_14
; 初始化计数器 (i) 为0
; 它将始终保持在 $v0 中；
    move $v0, zero; branch delay slot
```

```assembly
loc_8:\                               # CODE XREF:
my_memcpy+1C
; 将地址 $t0 处的无符号加载到 $v1：
    lbu $v1, 0($t0)
; 增加计数器 (i):
    addiu $v0, $1
; 将字节存储到 $a3
    sb $v1, 0($a3)
```

```assembly
loc_14:\                               # CODE XREF: my_memcpy
; 检查 $v0 中的计数器 (i) 是否仍小于第三个函数参数
("cnt" 在 $a2):
    sltu $v1, $v0, $a2
; 构造源块中字节的地址：
    addiu $t0, $a1, $v0
; $t0 = $a1+$v0 ; src+
; 如果仍小于“cnt”则跳转到循环体
    bnez $v1, loc_8
; 构造目标块中字节的地址 ($a3 = \$a0+\$v0 =
    addiu $a3, $a0, $v0 ; branch delay slot
; 如果触发 BNEZ 则结束：
    jr $ra
    nop $at, zero ; branch delay slot, GOP
```

这里介绍的两个指针寄存器分别是LBU (Load Byte Unsigned)和SB (Store Byte)。在两个平台上，所有的MIPS寄存器都是32位寄存器。在两个平台上，我们无法像x86那样对寄存器的低位进行操作。因此在处理单字节字符操作时，我们都是访问整个32位寄存器。LB指令加载带符号的数据并清除寄存器的其他位。由于有符号位的问题，所以在处理有符号的数据的时候通常要使用LB (Load Byte)指令把单字节的有符号数据扩展为等值的32位数据、再存储在寄存器中。SB指令的作用是把寄存器的低8位数据存储到内存里。

## 14.3 总结

当循环变量从2增到9时，循环语句对应的汇编代码如下：

指令清单14.15 x86

```assembly
mov [counter], 2 ; 初始化
jmp check
body:
  ; 循环体
  ; 执行某些操作
  ; 在本地栈中使用计数器
  add [counter], 1 ; 增
check:
  cmp [counter], 9
  jne body
```

如果没有开启编译器的优化功能，那么循环变量的增操作可能对应3条汇编指令。

指令清单14.16 x86

```assembly
MOV [counter], 2 ; 初始化
JMP check
body:
  ; 循环体
  ; 执行某些操作
  ; 在本地栈中使用计数器
  MOV REG, [counter] ; 增
  INC REG
  MOV [counter], REG
check:
  CMP [counter], 9
  JLE body
```

当循环体短时，编译器可能给循环变量分配用的寄存器。

指令清单14.17 x86

```assembly
MOV EBX, 2 ; 初始化
JMP check
body:
  ; 循环体
  ; 执行某些操作
  ; 在 EBX 中计数计数，但不修改它
  INC EBX ; 增
check:
  CMP EBX, 9
  JLE body
```

编译器还可能调部分的顺序。

指令清单14.18 x86

```assembly
MOV [counter], 2 ; 初始化
JMP label_check
label_increment:
ADD [counter], 1 ; 增
label_check:
CMP [counter], 10
JGE exit
; 循环体
  ; 执行某些操作
  ; 在本地栈中使用计数器
JMP label_increment
```

通常情况下，程序应当判断循环条件是否满足，但是在编译器优化的情况下，它可能会交换循环体和判断语句的顺序。下面这个就是一个典型的例子。

指令清单14.19 x86

```assembly
MOV REG, 2 ; 初始化
body:
  ; 循环体
  ; 执行某些操作
  ; 在 REG 中计数计数，但不修改它
  INC REG; 增
  CMP REG, 10
JL body
```

编译器不会使用LOOP指令。如果某代码带有LOOP指令，那么应当认为它是手写的汇编程序。

指令清单14.20 x86

```assembly
; 从10数到1
MOV ECX, 10
body:
  ; 循环体
  ; 执行某些操作
  ; 在 ECX 中计数计数，但不修改它!
LOOP body
```

ARM平台的R4寄存器专门存储循环变量。

指令清单14.21 ARM

```assembly
MOV R4, 2 ; 初始化
B check
body:
```
```assembly
; 循环体
  ; 执行某些操作
  ; 在 R4 中计数计数，但不修改它!
ADD R4,R4, #1; 增
check:
CMP R4, #10
BLT body
```
