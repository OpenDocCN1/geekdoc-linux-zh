# 指令清单14.18 x86

```
MOV [counter], 2 ; initialization
JMP label_check
label_increment:
ADD [counter], 1 ; increment
label_check:
CMP [counter], 10
JGE exit
; loop body
; do something here
; use counter variable in local stack
JMP label_increment
```

通常情况下，程序应当首先判断循环条件是否满足，然后再执行循环
但是是在编译器调试送代并发肯定的情况下，它可能会换换循环
体和判断断句语句的顺序。下面这个程序就是一个典型的例子。

# 指令清单14.19 x86

```
MOV REG, 2 ; initialization
body:
; loop body
; do something here
; use counter in REG, but do not modify it!
INC REG; increment
CMP REG, 10
JL body
```

编译器不会使用LOOP指令。由LOOP控制的循环控制语句较少见。如果
某段代码带有LOOP指令，那么你应当认为它是手写写出来的汇编程序。

# 指令清单14.20 x86

```
; count from 10 to 1
MOV ECX, 10
body:
; loop body
; do something here
; use counter in ECX, but do not modify it!
LOOP body
```

ARM平台的R4寄存器专门用于存储循环变量。
