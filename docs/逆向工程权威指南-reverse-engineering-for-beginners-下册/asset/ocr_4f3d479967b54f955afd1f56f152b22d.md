# 前言

“逆向工程”一个用词在软件工程领域的具体含义乃至模糊不清。
逆向工程是一种分析目标系统的过程，旨在识别系统的各组件以及组件之间的关系，以便通过其他形式或在较高的抽象层次上，重建系统的表征。按照目标系统的分类划分，人们常说的“逆向工程”大体可分为：

+   (1) 软件逆向工程。研究编译后的可执行程序。

+   (2) 构建逆向工程。扫描3D结构并进行后续数据处理，以便还原原物。

+   (3) 重建DBMS结构。

本书涉及上述第一项，即软件逆向工程的知识域。

# 重点议题
