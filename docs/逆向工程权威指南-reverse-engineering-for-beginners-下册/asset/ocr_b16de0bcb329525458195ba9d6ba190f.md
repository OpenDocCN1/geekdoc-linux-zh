```
PUBLIC _main
TEXT SEGMENT
s$ = -24 ; size = 8
b$ = -16 ; size = 16
```

```
_main PROC
sub esp, 24
push 30
push 20
push 10
push 1
lea ecx, DWORD PTR _b$[esp+40]
call ?0box@QAE@HHH@Z ; box::box
push 40
push 2
lea ecx, DWORD PTR s$[esp+32]
call ?0sphere@QAE@HH@Z ; sphere::sphere
lea ecx, DWORD PTR _b$[esp+24]
call ?0print_color@object@QAEXZ ; object::print_color
lea ecx, DWORD PTR s$[esp+24]
call ?0print_color@object@QAEXZ ; object::print_color
lea ecx, DWORD PTR _b$[esp+24]
call ?0dumpbox@QAEXZ ; box::dump
lea ecx, DWORD PTR s$[esp+24]
call ?0dump@QAEXZ ; sphere::dump
xor eax, eax
add esp, 24
ret 0
_main ENDP
```

继承必须在其基（父）类字段的后面加上自己的字段，因此基类和派生类的成员函数个数是共通的。

当程序调用成员对象时object::print_color()时，指向对象和sphere的是通过此指针传递的。由于在所有继承类和基类中标识的偏移量固定为0（offset+0x0），所有对象的类成员函数object::print_color都可以可以正常运行。

因此，无论是基类还是派类，只要该方法所引用的字符的相对地址固定不变，那么该方法就可以正常运行。

假设基于基类创建一个继承类，那么编译器就会在变量depth的后面加上你所添加的新的变量，以确保基类中box的各个字段的相对地址在继承类中固定不变。
