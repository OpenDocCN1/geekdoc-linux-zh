# 51.1 类

# 51.1.1 一个简单的例子

从编译层面看，C++类（class）的组织方式和结构数据完全一致。

我们演示一个含有两个变量、两个构造函数以及一个方法的类型数据:

```
#include <stdio.h>

class c
{
private:
    int v1;
    int v2;
public:
    c() // default ctor
    {
        v1=667;
        v2=999;
    };

    c(int a, int b) // ctor
    {
        v1=a;
        v2=b;
    };
```
