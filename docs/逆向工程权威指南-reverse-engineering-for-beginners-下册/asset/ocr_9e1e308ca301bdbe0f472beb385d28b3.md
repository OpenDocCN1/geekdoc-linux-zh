这样的话，我们在Excel的相关单元就会发现数字666。从这这一点可以看出，我们找到了正确的指令位置。

![](bbox=[0.218, 0.153, 0.755, 0.467])

如果我们调试的是64位的版本Excel程序，我们只会找到12条FDIV指令。而我们关注的运算指令是第3个FDIV指令:

```
tracer.exe -l:excel.exe
bpx=excel.exe!BASE+0x1B7FCC,set(st0,666)
```

大概是在编译64位的Excel程序时，编译器使用SSE指令替换了float和double型数据的除法运算指令。其中，SSE指令集的DIVSD指令出现了268次。
