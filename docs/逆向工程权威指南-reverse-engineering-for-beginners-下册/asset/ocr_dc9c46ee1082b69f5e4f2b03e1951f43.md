# 第20章 线性同余法与伪随机函数

“线性同余法”大概是生成随机数的最简单的方法。虽然现在的随机函数基本上采用这种技术了[1]，但是它原理简单（只涉及乘法、加法与运算），仍然值得研究。

```
#include <stdint.h>

// constants from the Numerical Recipes book
#define RNG_a 1664525
#define RNG_c 1013904223

static uint32_t rand_state;

void my_rand(uint32_t init)
{
    rand_state=init;
}

int my_rand ()
{
    rand_state=rand_state*RNG_a;
    rand_state=rand_state+RNG_c;
    return rand_state & 0x7fff;
}
```

上述程序包含两个函数。第一个函数用于初始化内部状态，第二个函数生成伪随机数。

这个程序中的两个常量来自于参考书目[Pre+07]。本文直接接用C/C++的#define语句，把它们定义为两个宏。C/C++对宏和常量的处理方法有所区别。C/C++编译器的预处理器会将宏直接替换为相应的
