接下来，我们以系统工具uptime来进行演示。我们都知道，该应用可以显示计算机已经工作了多久时间。借另一款系统工具strace可见，uptime通过/proc/uptime文件获取计算机的工作时长：

```
$ strace uptime

open("/proc/uptime", O_RDONLY) = 3
lseek(3, 0, SEEK_SET) = 0
read(3, "416166.86 414629.38\n", 2047) = 20
```

其实，/proc/uptime并不是真正意义上的磁盘文件。它由Linux Kernel产生的虚拟机。这个文件具有两个数值：

```
$ cat /proc/uptime
416690.91 415152.03
```

查字典基础，我们可以得到以下的信息：

第一数值显示的是系统已经运行的总时长；第二数值是计算机处于空闲状态的时间总和。这两项数据都以秒为单位。

我们编写一个声明open()、read()和close()函数的自定义动态链接。

首先要处理的就是open()函数。它能判断程序打开的文件是否我们需要的文件。如果两者相同，那么open()函数就记录并返回文件描述，接下来要处理的是read()函数。read()函数能判断程序打开的文件是否是我们要关注的连接描述。如果两者相同，我们就用某些描述符代替原来的read，否则就调用lib.so.6里的原函数描述。最后需要要处理的是close()函数，它能确保关闭已打开的外部文件。

本例通过dlopen()和dlsym函数获取同名函数在libc.so.6里的函数地址。虽然简单的例子是要获取系统函数，但也得将控制权交过来的“扩展”函数

另一方面，如果我们支持strcmp()函数（字符串比较函数）、以此获取每组对比的字符串，那么我们就得手写一个strcmp()函数了，而无法继续调用原有有函数。
