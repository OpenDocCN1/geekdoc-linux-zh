# 第89章 修改可执行文件

# 89.1 文本字符串

除了那些经过加密存储的字符串以外，我们可以使用任何一种的hex editor直接编辑C字符串。即使那些不了解机器码和可执行文件体格式的人，也可以。修改后的字符串，其长度不得大于原来字符串的长度，否则可能覆盖其他的数据。在MS-DOS盛行的时代，人们普遍使用这种方式直接用汇编转换中的外文字。在20世纪80年代和90年代的前苏联，这种技术十分流行。所以，那个时代也出现了各种灵精怪的超短编写：预定长度的字符串存储空间可能容纳不完整的译文，即使编译器翻译人员不够压缩译文的长度。

在修改Delphi程序的字符串时，还要调整字符串的长度。

# 89.2 x86修改指令

修改可执行文件中汇编指令的方式有以下几种：

+   - 禁用某些指令。此时只需要0x90 (NOP)替换相应的汇编指令即可。

+   - 禁用条件跳转指令。在修改74 xx (JZ)这样的条件跳转指令时，我们可以直接把跳转指令的2个字节替换为两个090 (NOP)，也可以把第二个字节（jump offset）替换为0，即把偏移量固定为0。
