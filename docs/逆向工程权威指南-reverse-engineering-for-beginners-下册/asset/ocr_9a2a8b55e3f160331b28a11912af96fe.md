在调用函数之后，“ADD ESP, X”指令修正堆寄存器中的栈指针。通常
情况下，我们可以通过call之后的指令判断指令参数的数量：变量总数=
X+=4。

这种判断方法仅适用于调用约定为cdecl的程序。本书书在第64章详细介绍
介绍各种函数约定[1]。

如果某个程序连续调用多个函数，且对调用函数的指令之间不掺杂其他
指令，那么编译器可能会把释放参数存储空间的“ADD ESP, X”指令进行合并，
一次性释放所有空间。例如：

```
push a1
push a2
call
...
push a1
call
...
push a1
push a2
push a3
call
add esp, 24
```
