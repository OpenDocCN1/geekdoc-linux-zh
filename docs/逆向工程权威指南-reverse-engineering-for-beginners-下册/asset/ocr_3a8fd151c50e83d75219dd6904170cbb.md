Optimizing Keil 6013 (Thumb mode)

使用Keil 6/2013 (开启优化选项)、以及Thumb编译上述程序可得到如下所示的指令。

指令17.22 Optimizing Keil 6/2013 (Thumb mode)

```
PUSH {R3-R7,LR}
MOVS R4, R2
MOVS R5, R3
MOVS R6, R0
MOVS R7, R1
BL   _aeabi_cdcmple
BCS  loc_1C0
MOVS R0, R6
MOVS R1, R7
POP  {R3-R7,PC}
```

```
loc_1C0
MOVS R0, R4
MOVS R1, R5
POP  {R3-R7}
```

由于运行Thumb指令的硬件平台未有FPU硬件，所以Keil不会生成FPU的硬件指令。在此在比较浮点数时，Keil没有直接使用FPU的比较指令，而是使用了额外的函数__aeabi_cdcmple进行真处理。

需要注意的是，程序调用的仿真函数在比较数值后保留CPU状态位，所以以后可以直接执行BCS (B-Carry Set，大于或等于的情况下触发B跳转)之类的条件执行指令。
