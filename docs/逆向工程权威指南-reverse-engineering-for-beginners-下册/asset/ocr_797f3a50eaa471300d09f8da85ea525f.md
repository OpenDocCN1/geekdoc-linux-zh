矢量化并不是最近出现的技术。这本书的作者在1998年的Cray Y-MP超级计算机系列中见到过“Cray Y-MP EL”的羽量级lite版本。感兴趣的读者可以去他们的在线超级计算机博物馆去看看：http://www.cray-cyber.org/

举例，下述循环采用了向量化技术：

```
for (i = 0; i < 1024; i++)
{
  C[i] = A[i]*B[i];
}
```

上述代码从数组A和数组B取值，把这两个数组元素进行乘法运算，并将得到的存储在数组C里。
如果数组中的每个元素都是32int型数据，那么就可以把A的四个元素放在128位的MMX寄存器中，再把B的四个元素放在另一个MMX寄存器里，然后通过PMULLD (Multiply Packed Dword Integers and Low Result)和PMULHW (Multiply Packed Signed Integers and Store High Result)指令进行并行乘法运算。这可以一次获得4个的结果。

这样一来，循环体的执行次数不再是1024，而是1024/4。换句话说，程序的性能将提高4倍。

某些编译器具有简单的矢量自动优化功能。Intel C++编译器就有这样的智能优化功能，详请参见 http://www.intel.com/intelxpress/sum_vmmx.htm
