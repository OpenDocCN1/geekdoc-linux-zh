# Optimizing GCC 4.4.5

在传递多个参数时，MIPS使用$A0~$A3传递前4个参数，使用传递剩余的参数。这种平台主要采用一种名为“O32”的函数约定。实际上大多数MIPS系统都采用这种约定。如果使用了其他的函数约定，例如N32约定，寄存器的用则会有不同的差异。

下面指令中的“SW”是“Store Word”的缩写，用以把寄存器的值写入内存。MIPS的指令很小，没有数据直接写入内存的类的指令。当需要进行这种操作时，就不得不组合LI/SW指令。
