函数get_weight()（计算重量）时只用了两个方法。在调用get_volume()（计算体积）时，它传递了this指针。而在调用get_density()（密度）函数时，它传递的地址是“this指针+12字节”。后面这个地址对应的solid_box类的solid_object字段。

因此，solid_object::get_density()认为，它处理的是常规solid_object类，而box::get_volume()则可以正常访问原有数据类型的3个变量，如同直接操作box类一样。

因此，我们可以相信：继承了其他的、多个类而生成的对象，在内存之中就是一种复合类型的数据结构。它继承了原有的全部字段和方法。在这种继承类对象调用特定方法时，它传递的是与该方法原有基类相对地址相同的this指针。

# 51.1.5 虚方法

我们来看一个简单的例子：

```
#include <stdio.h>

class object
{
public:
    int color;
    object() { };
    object(int color) { this->color=color; };
    virtual void dump ({
        printf("color=%d\n", color);
    }
};

class box : public object
{
private:
    int width, height, depth;
public:
    box(int color, int width, int depth)
    {
        this->color=color;
        this->width=width;
        this->height=height;
        this->depth=depth;
    }
    void dump()
{
        printf("this is box. color=%d, width=%d, height=%d, depth=%d\n", color, width, height, depth);
    }
};
```
