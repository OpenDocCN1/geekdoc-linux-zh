# 第25章 SIMD

SIMD意为“指令流多数据流”，其全称为“Single Instruction, Multiple Data”。顾名思义，这类指令可以一次处理多个数据。在x86的CPU中，通过专用FPU进行计算的实现。

之后，CPU通过MMX指令率提升了SIMD的运算功能。支持这种技术的CPU里都有8个64位寄存器，如MMX~MM7。每个MMX寄存器都是8字节寄存器，可以容纳2个32位数据，或者4个16位数据。使用SIMD指令进行操作数据时，它可以把8个数据分为4组数据同时运算。

平面图像可以视为一种二维矩阵的数据结构。在美工人员图像编辑程序对每个像素的亮度系数进行加减乘除运算。简单来说，图像的每个像素有灰度系数，而且处理系统是8位数据（1个字节）。为了满足这种需要，处理器厂商后来专门推出了基于SIMD的亮度和调整指令。这种颜色调整甚至能够越界保护功能，能够避免亮度调整时可能产生的上溢（overflow）和下溢（underflow）。

在刚刚推出MMX技术的时候，SIMD使用了FPU的寄存器（别名）。这有利于FPU或MMX的混合运算。有人说Intel是为了节省晶体管，其实际操作更为简单：操作系统并不会增加新的CPU寄存器，而是会数据保存到FPU上。所以，只有同时满足“支持MMX技术的CPU”+“老式操作系统”+“利用MMX指令的程序”这三个条件，才能发挥SIMD的优势。
