# 10.3 总结

# 第11章 GOTO语句

人们普遍认为使用GOTO语句将破坏代码的结构化构造[1]。即使如此，某些情况下我们还必须使用这种结构语句[2]。

本章围绕以下程序进行说明：

```
#include <stdio.h>

int main()
{
    printf("begin\n");
    goto exit;
    printf("skip me!\n");
exit:
    printf("end\n");
}
```
