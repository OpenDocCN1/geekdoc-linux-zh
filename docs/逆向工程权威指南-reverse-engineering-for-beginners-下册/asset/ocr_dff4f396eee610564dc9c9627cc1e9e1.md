```
call arith_mean
lea rcx, OFFSET FLAT:$GG30013
mov edx, eax
call printf
xor eax, eax
add rsp, 56

ENDP main
```

在这个程序里，寄存器负责传递函数的前4个参数，用来传递函数剩余的2个参数。函数arith_mean() 首次将寄存器传递的4个参数存放在阴影空间中，把阴影空间和传递参数的栈内存合并成了一统一而连续的参数空域！

GCC如何处理参数的？与MSVC相比，GCC在编译的时候明显像蛇足添加。它会把函数分为两部分：第一部分的指令将寄存器的值保存在“红色地带”，并在里面处理；而第二部分指令再处理函数的参数。
