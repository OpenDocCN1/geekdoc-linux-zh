# 第68章 Windows NT

# 68.1 CRT (Win32)

所有程序都是从main函数开始执行的吗？事实并非如此。如果用IDA或者HIEW打开可执行文件，我们可以看到原始指向OEP (Original Entry Point) 总是指向其他的代码段。这些代码会在启动程序之前进行一些维护和准备工作。这就是所说的启动代码/startup-codeCRT代码 (C Runtime)。

在调试命令行指示启动程序时，main()函数通过数组传递启动参数和系统的环境变量。然而，实际传递给程序的不是数组而是参数字符串。CRT代码根据包含空格的字符串进行切割，CRT代码通过envp数组向main()传递系统的环境变量。在Win32 GUI程序里，主函数变成了WinMain()，并且拥有自己的参数传递规格：

```
int CALL WinMain(
    In_ HINSTANCE instance,
    In_ HINSTANCE hPrevInstance,
    In_ LPSTR lpCmdLine,
    In_ int nCmdShow
);
```

上述参数同样也是由CRT代码准备的。

在程序结束后，main()函数会返回退出代码。这个退出代码会被传递给CRT的ExitProcess()函数，作为者的一个参数。
