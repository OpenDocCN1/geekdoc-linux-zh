| 位序 | 描述 |
| --- | --- |
| 9, 8 | Tag (4) |
| 7, 6 | Tag (3) |
| 5, 4 | Tag (2) |
| 3, 2 | Tag (1) |
| 1, 0 | Tag (0) |

Tag (x) 存储着FPU物理寄存器R (x) 的状态码。

其各值的代表意义是:

+   * 00: 该寄存器存储着非零的值。

+   * 01: 该寄存器存储的值为零。

+   * 10: 寄存器的值为特殊的值, NAN, ∞或者无效操作数。

+   * 11: 寄存器为空。
