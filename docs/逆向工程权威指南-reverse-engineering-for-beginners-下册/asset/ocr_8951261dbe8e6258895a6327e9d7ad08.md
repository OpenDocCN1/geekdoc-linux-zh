# # 第64章 参数的传递方法（调用规范)

# ## 64.1 cdecl [C Declaration的缩写]

这是C/C++语言中最常用的参数传递方法。

调用函数逆向被调用函数传递参数：以“最后（右侧）”的参数、倒数第二……至第一个参数”的顺序传递参数。被调用函数退出后，应由调用函数调整指针ESP、将栈恢复成其他函数的原始状态。

> 指令清单64.1 cdecl

```
push arg3
push arg2
push arg1
call function
add esp, 12 ; returns ESP
```

# ## 64.2 stdcall [Standard Call的缩写]

这种调用方式与上面提到的cdecl规范类似，只是有一点不同：被调用函数在返回之前执行“RET x”指令还清理参数，而不会使用单纯的“RET”指令直接返回。这里的x的数值计算方式是：x=参数个数*指针的大小（在x86架构中的值是4，而在x64中是8）。这样调用函数本身不需要调整指针，因此调用函数不会因此使用类比“add esp, x” 这样的指令。

> 指令清单64.2 stdcall
