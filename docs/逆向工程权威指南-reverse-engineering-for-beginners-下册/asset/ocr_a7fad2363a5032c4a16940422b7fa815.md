# 序 从逆向视角透析大厦的那些砖石

对于这本书的中文名字《逆向工程权威指南》，我更喜欢的英文名为《Reverse Engineering for Beginners》，可以译为“逆向工程入门者必读”。在国外的程序员中，这本书被简称为《RE4B》，作者的Blog连载已经获得了持续关注和口碑。

本书的重要特色在于其清晰的章节结构，涵盖了函数、语结构、数据组等这些构成逆向大厦的基本元素，如显微镜观察对一地对这些元素在X86、ARM和MIPS体系架构下的“切片”影像。本书几乎每个章节都按照作者来说，这也让读者深入对比三种体系架构下，相同的指令，函数及数据呈现的异异和点。无论对于分析工程师，还是编写工程师来说，本书都能让人深入理解逆向大厦原材料的工程指南。本书是基础性的系统性的文献，更是让人耳目一新的结构安排。对于在中国高等教育教学中，通过简单的X86学习来理解体系的工程师来说，这也足够快速打通ARM、MIPS知识的“安全”指南。对于那些从各种数据程中来到逆向的安全爱好者来说，这更是一份“正餐”。对于作者来说，我相信这个过程充满了满足，但也充满了困难和烦恼。对于Dennis这个逆向领域的工程专家来说，这本书的写作过程，更多是在探索未知的领域，也不对高要求的技巧和经验的总结，而是要看到相对于目标的单元级数据进行处理，将一些对其已经是熟悉的东西转化为逆向而化为理解的语言。

逆向工程被视为一种充满趣味和带有神圣主义的技能，逆向方向的作者看来看有着更多的原因，似乎就是在指令狩猎中逆流而，开启特殊限制和保护，找到目标码中的“宝藏”——错误、漏洞或被加密算法层层掩盖的数据结构。这个由于媒体打造的形状，也为部分意逆向爱好者所称的。这也导致了逆向领域的书籍和教材，更多围绕着一些高阶的技巧展现
