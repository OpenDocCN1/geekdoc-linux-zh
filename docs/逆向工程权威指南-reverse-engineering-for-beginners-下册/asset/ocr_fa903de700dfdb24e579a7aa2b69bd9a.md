# Optimizing Xcode 4.6.3 (LLVM) (ARM mode)

> 指令清单17.16 Optimizing Xcode 4.6.3 (LLVM) (ARM mode)

```
VMOV      D16, R2, R3 ; b
VMOV      D17, R0, R1 ; a
VCMP.F64  D17, D16
VMRS      APSR,nzcv, FPSR
VMOGT.F64 D17, D16 ; copy "a" to D16
VMOV      R0, D16, LR
BX        LR
```

这段程序的逻辑很简单。函数将输入存储到D17、D16寄存器之后，
使用VCMPTE指令比较这两个值的值，与x86处理器相似，ARM处理器也有自己有
状态寄存器和标识寄存器，其处理器也存在于相关的FSRCR[12]。

ARM模式的指令跳转在条件跳转指令，但是它的条件跳转指令不能
直接访问处理器的状态寄存器。这个点和x86系统相同，ARM平-
台有专门的指令将处理器的4个状态位（N, Z, C, V）复制到通用状态
寄存器的ASPR寄存器里，即VMRS指令。

VMOGWT是FPU的VMOGT指令，在操作数大于另一个操作数时进行赋值操
作。这个指令的源GT代码表示“Greater Than”。
