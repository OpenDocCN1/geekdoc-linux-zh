## 36.2 例子

上一节剩余，接下来我们增加一个新的局部变量 `next`，并用它替换所有：

```c
#include <stdio.h>

void fib(int a, int b, int limit) {
    int next = a+b;
    printf("%d\n", next);
    if (next > limit)
        return;
    fib(b, next);
}

int main() {
    printf("0\n1\n1\n");
    fib(1, 2, 20);
}
```
