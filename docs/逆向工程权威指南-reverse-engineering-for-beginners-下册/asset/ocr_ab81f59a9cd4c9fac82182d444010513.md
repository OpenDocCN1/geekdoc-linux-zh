```
add esi, 1
test edi, 2
mov BYTE PTR [edx+10], al
mov eax, 122

.L25:
mov zx edx, WORD PTR [esi]
add edi, 2

```

通用内存函数通常的工作原理：首先计算有多少块（32位），然后用MOVSD指令复制这些块，然后逐一复制剩余的字符。

更为复杂的内存函数则利用SIMD指令集复制，这种复制还会涉及内存地址对齐的问题。感兴趣的读者可以参阅本书第25章的2节。
