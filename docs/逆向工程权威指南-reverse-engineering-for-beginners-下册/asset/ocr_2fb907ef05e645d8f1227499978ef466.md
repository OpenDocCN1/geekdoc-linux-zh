在启用优化功能之后，Keil会给编译出的Thumb模式代码分配条件转移指令。毕竟在Thumb模式的指令之中，没有支持标志位判断的阈值指令。

# 指令清单12.2 Optimizing Keil 6/2013 (Thumb mode)

```
f PROC
; compare input value with 10
    CMP     r0,#0xA
    ; jump to |L0.8| if Equal
    BEQ
    ADR     r0,|L0.12|  ; "it is not ten"
    BX
|L0.8|
    ADR     r0,|L0.28|  ; "it is not ten"
    BX
|L0.12|
    DCB     "it is not ten",0
|L0.28|
    DCB     "it is ten",0
ENDP
```

# 12.3.3 ARM64

启用优化功能之后，GCC (Linaro) 4.9编译出来的ARM64程序同样用条件转移指令实现运算。

# 指令清单12.23 Optimizing GCC (Linaro) 4.9

```
f:
    cmp     x0,10
    beq    x0,:LC1   ; branch if equal
    adrp    x0,:LC1   ; "it is not ten"
    add     x0,x0,:l12:LC1
    ret
|L3:
    adrp    x0,:LC0   ; "it is not ten"
    add     x0,x0,:l12:LC0
    ret
|LC0:
    string "it is ten"
|LC1:
    string "it is ten"
```

ARM64同样能够判断标志位的条件赋值指令。而32位的ARM指令集[3]，以及x86的CMOVcc指令可以根据相应标志位进行条件赋值。虽然ARM64存在“条件选择”指令CSEL（Conditional SElect），但是GCC 4.9几乎无法给这种程序分配上条指令。
