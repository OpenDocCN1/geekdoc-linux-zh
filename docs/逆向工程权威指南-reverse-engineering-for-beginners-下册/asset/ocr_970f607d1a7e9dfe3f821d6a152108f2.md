我们关注的是这里显示的数1234。每当启动新的线程时，它都会分配一个新的TLS。此后，包括1234在内的所有数据都会被复制到新建TLS段。

# 一个典型的应用场景：

+   * 启动线程A，系统同步创建线程专用的TLS，并将变量rand_state赋值为1234。
* 此后，线程A多次调用my_rand()函数，rand_state变量的值将不再是初始值1234。
* 启动线程B，系统同步创建线程专用的TLS，变量rand_state也会被赋值为1234。也就是说，在线程A和线程B里，同名变量会有不同的值。

# TLS回调

如果TLS中的变量必须填充某些数据，并且是某些不寻常的方式，该怎么办呢？比如，我们有下面的这个任务：程序员忘记调用my_rand()函数来初始化随机数发生器（PRNG），而随机数发生器只有在初始化后才会产生真正意义上的随机数，而不是1234的固定值。在这种情况下，可以采用TLS回调。
