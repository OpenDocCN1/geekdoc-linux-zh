```
addsd xmm0, xmm1
ret 0
ENDP
```

上述程序还可以优化。请注意：传入的参数被保存到了“阴影空间”（可参见书本B.2.1节）。但是只有寄存器的低半部分数据——即double型64数据会被保存在阴影空隙里。

GCC编译出的程序与之前相同，本文不再介绍。
