# 38.1 计算网络地址函数calc_network_address()

计算网络地址函数calc_network_address()实现起来非常简单：
将主机地址和网络子码进行AND与运算，得到的结果就是网络的
实际地址。

> 指令38.1 MSVC采用参数/O0优化

```
1\_ip1\$ = 8               ; size = 1
2\_ip2\$ = 12              ; size = 1
3\_ip3\$ = 16              ; size = 1
4\_ip4\$ = 20              ; size = 1
5\_netmask\_bits\$ = 24      ; size = 1
6\_calc\_network\_address PROC
7   push                      edi
8   push
9   push                      DWORD PTR\_netmask\_bits$[esp]
10  call                      form\_netmask
11  push                      OFFSET \$SG3045 ; 'network='
12  mov                       eax, edi
13  call                      DWORD PTR\_imp\_printf
14  push                      edi
15  call                      \_print\_as\_IP
16  push                      OFFSET \$SG3046 ; 'network address='
17  call                      DWORD PTR\_imp\_printf
18  push                      DWORD PTR\_ip4$[esp+16]
19  push                      DWORD PTR\_ip3$[esp+20]
20  push                      DWORD PTR\_ip2$[esp+24]
21  push                      DWORD PTR\_ip1$[esp+28]
22  call                      form\_IP
23  and                       eax, edi      ; network address = host
24  call                      \_print\_as\_IP
25  add                       esp, 36
26  pop                       edi
27  ret                       0
28  \_calc\_network\_address ENDP
```

在第22行，我们可以看到看到为重要的指令AND。就是计算出
了网络地址，实现了核心功能。
