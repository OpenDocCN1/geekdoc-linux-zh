INT (M): INT指令相当于16位系统中的PUSH; CALL 它停用
dwordport(*4)。在MS-DOS中，INT指令通用用于系统调用(syscall)。然后跳转到中断向量表[2]。因为
INT的代码很短(2字节)，并且通过中断调用MS-DOS服务的应用程序不必
判断系统服务的入口地址，所以INT指令使用AX/BX/CX/DI寄存器里的参数，所以INT指令执行时一切。中断处理程序使用
IRET指令即可返回程序的控制权。

最被调用的MS-DOS中断是第02号中断，它负责着大量的API接口。
有关MS-DOS中的完整列表，请参见Ralph Brown撰写的《The x86 Interrupt List》[3]。

用INT指令进行系统调用。近年来，它们逐渐使用SYSYSENTER或SYSCALL指
替代了INT指令。
