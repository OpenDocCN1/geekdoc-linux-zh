函数尾检测了“百灵鸟”的状态。如果栈内的值没被修改（和R8寄存器指向的值等），则会执行ITTT EQ后面的4条指令——令RO为0、运行函数尾并且退出函数。如果“百灵鸟”发生了变化，程序将跳过ITTT EQ后面的4条“—EQ”的指令，转而调用—stack_chk_fail进行异常处理，实际上会结束程序。

# 18.4 其他

现在我们应该理解为C/C++编译了下面的程序。[4]

```
void f(int size)
{
    int a[size];
    ...
}
```

在编译阶段，编译器必须确切知道需要给数组分配多大的存储空间，它需要事先确定局部域或数据段（全局变量）的布局，所以编译器无法处理上述这种长度的可变的数组。

如果无法事先确定数组的长度，那么我们就应该使用malloc()函数分配出一块内存，然后直接按照变量数组的模式访问该块内存；或者遵循C99标准（参见ISO007, 6.7.5）进行处理，但是C99标准和设计出来的程序，内部实现的方法接近alloc()函数（详情请参阅5.24节）。
