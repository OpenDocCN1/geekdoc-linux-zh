# 编译器生成的程序更为简洁。

# 指令清单12.20 Optimizing MSVC 2012 x64

```
$SG1355 DB    'it is ten', 00H
$SG1356 DB    'it is not ten', 00H

a               = 8
f               PROC
lea             load pointers to the both strings
lea             rdx, OFFSET FLAT:$$SG1355 ; 'it is ten'
lea             rax, OFFSET FLAT:$SG1356 ; 'it is not ten'
; compare input value with 10
cmp             ecx, 10
; if equal, copy value from RDX ("it is ten")
; if not, do nothing. The pointer to the string "it is not ten" is still
in in RAX as for now.
cmove           rax, rdx
ret             0
               ENDP
```

启用优化选项后，GCC 4.8生成的x86指令同样使用了CMOVcc指令。相比
之下，在关闭优化功能的情况下，GCC 4.8用条件转移指令替换编译器操作符。

# 12.3 ARM

启用优化功能后，Keil生成的ARM代码会应用运行指令ADRcc。

# 指令清单12.21 Optimizing Keil 6/2013 (ARM mode)

```
f PROC
; compare input value with 10
CMP             r0, #0xa
; if comparison result is Equal, copy pointer to the "it is ten"
string into R0
ADREQ           r0,[L0.16] ; "it is ten"
; if comparison result is Not Equal, copy pointer to the "it is not
tenring into R0
ADRNE           r0,[L0.28] ; "it is not ten"
BX              lr
               ENDP
```

```
|L0.16|
    DCB             "it is ten",0
|L0.28|
    DCB             "it is not ten",0
```

非存在人为为干预，否则ADREQ和ADRNE指令可能在一次调用期间都
被执行。
