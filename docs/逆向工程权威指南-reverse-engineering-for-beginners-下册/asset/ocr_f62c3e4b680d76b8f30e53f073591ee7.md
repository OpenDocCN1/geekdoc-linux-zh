# 第42章 字符串转换数字，函数atoi()

我们来重新实现一下标准的C函数atoi()。这是一个将字符串转换为整数的函数。

# 42.1 例1

本例可以按照ASCII表将数字转换为数字。代码没有容错处理，因此当输入值为非数字类型字符时，返回值就不会正确。

```
#include <stdio.h>

int my_atoi(char *s)
{
    while (*s)
    {
        rt=rt*10 + (*s-'0');
        s++;
    }
    return rt;
}

int main()
{
    printf("%d\n", my_atoi("1234\));
    printf("%d\n", my_atoi("1234567890\));
}
```
