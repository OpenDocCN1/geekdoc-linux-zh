```
my_max:
; set $vl $al<$a0,or clear otherwise (if $a1>$a0):
    slt $vl, $al, $a0
    ; jump, if $vl is (or $a1>$a9):
        beq $vl, locret_10
    ; this is branch delay slot
    ; prepare $al in $v0 in use of branch triggered:
        move $v0, $al
    ; no branch triggered, prepare $a0 in $v0:
        move $v0, $a0
locret_10:
    jr $ra
    or $at, $zero ; branch delay slot, NOP
```

```
the min() function is same, but input operands in SLT instruction
are swapped:
my_min:
    slt $vl, $a0, $al
    beq $vl, locret_28
    move $v0, $al
```

```
locret_28:
    jr $ra
    or $at, $zero ; branch delay slot, NOP
```

请注意分支延时现象：第一个MOVE指令“先于”BEQZ指令运行，而第二个MOVE指令仅在不发生跳转的情况下才会被执行。
