OpenMP规范。

通过程序输出的数据统计，我们可以清楚地观察到整个穷举空间
被划分为大致相等的四个部分。严格来说，考虑到最后一个比特位，
这四个区域确实并不完全相等。

OpenMP提供了屏障块rtomic（原子性）的Prugms指令。顾名
思维，被标记为原子的代码不会被拆分为多个线程运行。我们来
看这段代码：

```
#pragma omp atomic
checked++;

#pragma omp critical
if ((checked % 100000)==0)
  printf("checked=%d\n", checked);
```
