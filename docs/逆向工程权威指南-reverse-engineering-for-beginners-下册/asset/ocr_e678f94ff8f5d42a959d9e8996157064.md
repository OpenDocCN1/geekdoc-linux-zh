```
add x1, x0, 0 ; increment X0
str x1, [sp,24] ; save X0 to "eos"
; load byte from memory at address in X0 to W0
ldr w0, [x0]
; is it zero? (WZR is the 32-bit register always contain zero)
cmp w0, wzr
; jump if not zero (Branch Not Equal)
bne .L62
; zero byte found. now calculate difference.
; load "eos" to X1
ldr x1, [sp,24]
; load "str" to X0
ldr x0, [sp,8]
; calculate difference
sub x0, x1, x0
; decrement result.
sub w0, w0, #1
; function epilogue
add sp, sp, 32
ret
```

关闭优化功能后，编译器的代码就长了许多。在操作变量时，程序紧密地访问内存中的变量。由于源程序的设计缺陷，最后一条SUB指令对寄存器的低32位数据进行了减法运算。
