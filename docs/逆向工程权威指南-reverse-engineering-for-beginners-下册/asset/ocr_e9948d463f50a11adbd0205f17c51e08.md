在关闭优化选项时，使用MSVC编译上源程序，可得到f_signed()函数。

指令清单12.1 Non-optimizing MSVC 2010

```
a$ = 8
b$ = 12
f_signed PROC
	push ebp
mov ebp, esp
mov eax, DWORD PTR_a$[ebp]
cmp eax, DWORD PTR_b$[ebp]
jle SHORT LN30f_signed
	push OFFSET SIG737
call _printf
add esp, 4

LN30f_signed:
mov ecx, DWORD PTR_a$[ebp]
cmp ecx, DWORD PTR_b$[ebp]
jne SHORT LN20f_signed
npush OFFSET SIG739
call _printf
add esp, 4
LN20f_signed:
mov edx, DWORD PTR_a$[ebp]
cmp edx, DWORD PTR_b$[ebp]
jge SHORT LN40f_signed
npush OFFSET SIG741
call _printf
add esp, 4
LN40f_signed:
ret 0
f END
```

第一个条件跳转指令是JLE，“Jump if Less or Equal”。如果上一条CMP指令的操作第一个表达式小于（不大于）第二个表达式，JLE将跳转到指令所标识的地址；如果不满足条件，则运行一条指令，例如程序将会调用printf()函数。第二个条件跳转指令是JNE，“Jump if Not Equal”。如果CMP的两个操作数不等，则进行跳转。

第三个条件跳转指令是JGE，“Jump if Greater or Equal”。CMP的第一个表达式大于或等于第二个表达式（不小于），则进行跳转。这段程序，如果三个跳转的判断条件都不满足，将不会调用printf()函数；否则，除非特殊干预，否则这种情况应该不会发生。
