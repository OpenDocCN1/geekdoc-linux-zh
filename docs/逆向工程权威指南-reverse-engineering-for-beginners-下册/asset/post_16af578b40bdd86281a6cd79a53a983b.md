在用 `get_bit()` 和 `set_bit()` 时，`rotate1/2` 的顺序不同。在此之外，`rotate1/2` 基本相同。可 `rotate1()` 的源码如下：

```c
void rotate2(int v) {
    bool tmp[8]; // internal array
    int i, j;

    for (i=0; i<8; i++)
        for (j=0; j<8; j++)
            tmp[i][j] = get_bit(v, i, j);

    for (i=0; i<8; i++)
        for (j=0; j<8; j++)
            set_bit(v, j, 7-i, tmp[i][j]);
}
```

下面分析 `rotate3()` 函数：

```c
void rotate3(int v) {
    bool tmp[8][8];
    int i, j;

    for (i=0; i<8; i++)
        for (j=0; j<8; j++)
            tmp[i][j] = get_bit(i, v, j);

    for (i=0; i<8; i++)
        for (j=0; j<8; j++)
            set_bit(7-j, v, i, tmp[i][j]);
}
```

这个函数更容易分析。如果把 `cube` 当作 8x8x8 的立方体，每个元素都是一个比特，那么 `get_bit()` 函数和 `set_bit()` 函数的作用就是从相应位置读取比特位。

如此看来，`rotate1/2/3` 的作用就是以特定层旋转所有比特位。这三个参数分别旋转魔方的不同平面，而参数 `v` 代表的是设置层的位置（0~7）。或许，这个算法的作者就是通过操作 8×8 的魔方来处理的。

再次整理 `decrypt()` 函数分析结果后，可推导出如下源代码：

```c
void decrypt(BYTE *buf, int sz, char *pw) {
    char *p = strdup(pw);
    strrev(p);
    int i=0;
    do {
        memcpy(p, cube, buf+i, 8*8);
        rotate_all(p, 3);
        memcpy(buf+i, cube, 8*8);
        i += 64;
    } while (i < sz);
    free(p);
}
```

该函数通过标准 C 函数 `strrev()` 对密字符串进行逆序排列，而且传递给 `rotate_all()` 函数的参数是 3。除此之外，它和 `crypt()` 函数基本一致。因此，解码过程用了 `rotate1/2/3`。

和魔方的玩法没有任何区别！如果你要取消调整魔方的操作，那么就要用相反的次序和相反的方向进行等幅操作。例来说，您刚刚顺时针转动了魔方的某一层，后来又要取消那次操作，那么就把魔方层顺时针旋转回来，不然就顺时针旋转 3 次。

如果说 `rotate1()` 函数旋转的是魔方的“正”面，那么 `rotate2()` 函数旋转的则是“上”面，而 `rotate3()` 函数用于旋转魔方的侧面。

不再回一下 `rotate_all()` 函数的代码：


综合上述分析可知：密码的每个字母都描述了旋转的“面”和“层”（0~7）。为了把 26 个字母映射到 24 个数据元素相等，这种算法非常脆弱。重新分析整个过程，整理得源代码如下：

```c
#include <windows.h>
#include <stdio.h>
#include <assert.h>

#define IS_SET(flag, bit) ((flag) & (bit))
#define SET_BIT(var, bit) ((var) |= (bit))
#define REMOVE_BIT(var, bit) ((var) &= ~(bit))

static BYTE cube[8][8];

void set_bit(int x, int y, int z, bool bit) {
    if (bit)
        SET_BIT(cube[x][y], 1<<z);
    else
        REMOVE_BIT(cube[x][y], 1<<z);
}

bool get_bit(int x, int y, int z) {
    if ((cube[x][y] >> z) & 1)
        return true;
    return false;
}

void rotate_f(int row) {
    bool tmp[8][8];
    int x, y;

    for (x=0; x<8; x++)
        for (y=0; y<8; y++)
            tmp[x][y] = get_bit(x, y, row);

    for (x=0; x<8; x++)
        for (y=0; y<8; y++)
            set_bit(y, 7-x, row, tmp[x][y]);
}

void rotate_t(int row) {
    bool tmp[8][8];
    int y, z;

    for (y=0; y<8; y++)
        for (z=0; z<8; z++)
            tmp[y][z] = get_bit(row, y, z);

    for (y=0; y<8; y++)
        for (z=0; z<8; z++)
            set_bit(row, z, 7-y, tmp[y][z]);
}

    bool tmp[8][8];

    for (x=0; x<8; x++)
        for (z=0; z<8; z++)
            set_bit(7-z, row, x, tmp[x][z]);
}

void rotate_all(char *pwd, int v) {
    char *p = pwd;
    while (*p) {
        char c = *p;
        int q;
        c = tolower(c);
        if (c>='a' && c<='z') {
            q = c-'a';
            if (q > 24)
                q = 24;
            int quotient = q/3;
            int remainder = q % 3;
            switch (remainder) {
                case 0: for (int i=0; i<v; i++) rotate_f(quotient); break;
                case 1: for (int i=0; i<v; i++) rotate_t(quotient); break;
                case 2: for (int i=0; i<v; i++) rotate_l(quotient); break;
            }
        }
        p++;
    }
}
```
