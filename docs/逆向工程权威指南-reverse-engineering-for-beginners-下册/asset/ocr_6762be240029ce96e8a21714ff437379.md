而后 printf() 函数从结构体中获取所需数据，并在屏幕上进行相应的输出。

printf() 函数并没有将所有的字段都打印出来。wDayOfWeek 和 wMilliSeconds都没有被输出，但是内存中确实有它们对应的值。

# 21.1.2 数组替代结构体

结构体中的各个元素，在内存中依次排列。为了验证它在内存中的存储状况和数组相同，我用数组替代了SYSTEMTIME结构体:

```
#include <windows.h>
#include <stdio.h>
void main()
{
    WORD array[8];
    GetSystemTime(array);
    printf("%04d-%02d-%02d %02d:%02d:%02d\n",
           array[0] / *Year /, array[1] / *Month /, array[3] / * wDay */,
           array[4] / *Hour /, array[5] / *Minute /, array[6] / *wSecond */);
    return;
}
```

编译器会提示警告信息:

systemtime2.c(7) : warning C4133: 'function' : incompatible types from 'WORD[8]' to 'LPSYSTEMTIME'

尽管如此，MSVC 2010能够编译。它生成的代码如下所示。

```

array$ = -16;size=16
main    PROC

    mov ebp, esp

    push eax

    movzx ecx, DWORD PTR_array$[ebp+12] ; wSecond
    push ecx
    movzx edx, DWORD PTR_array$[ebp+10] ; wMinute
    push edx
    movzx eax, DWORD PTR_array$[ebp+8] ; wHour
    push eax
```
