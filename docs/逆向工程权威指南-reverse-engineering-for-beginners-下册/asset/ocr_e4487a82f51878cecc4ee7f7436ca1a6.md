细心的读者可能会想起c语言的strcpy函数只需要2个参数而已，但是这个指令却传递了4个值。

```
seg033:088F 1E push ds
seg033:0890 68 22 44 push offset
aTrupcRequiresA ; "This Softwar \
  \\ Requires a Software Lock\"
seg033:0893 1E push ds
seg033:0894 68 60 E9 push offset byte_6C7E0
; dest
seg033:0897 9A 79 65 00+ call _strcpy
seg033:089C 83 C4 08 add sp, 8
```

这是MS-DOS的寻址方式。如需解译，请参见第94章。

如您所见，在使用strcpy()和其他函数时，操作系统是把指针分解为16位传递的，然后再进行处理。

在程序启动时，DS寄存器的值被设置为当前程序段的地址。程序的字符串信息存储在数据段中。

在send_pro()函数中，字符串的每个字符都被加载到seg030:00EF。与同时，指令从外部传递的参数加载到ES:BX。地址seg030:00F5的MOV指令，在内存中ES:BX对描述的地址读取字节。

而seg030:00F2的指令只对16位值进行逆端处理，却没有处理的值。这意味着传递给函数的字符串位于两个数据段的地址之外。

+   [1] CLRLWI是Clear left word immediate的缩写，用于清除指定的高/前n位，再把结果重置到目标操作。
[2] BLR是Branch to Link Register的缩写。
[3] 本文指的是LPT并行接口。实际上，IEEE 1284标准允许打印机返回数据。
