# # 第59章 常数

人类在现实生活中喜欢使用整数。编程人员也是人，他们同样喜欢选用10、100、1000这样的整数的。

熟悉的反汇编工程师都会明白，与之对应的十六进制数的关系是：10=0xA;100=0x3E8而10000=0x2710。然而，在二进制层面这些数字都不算太“整”。

从二进制层面来看，更为常用的整数是0xAAAA(1010101010101010)和0x55555555(0101010101010101)这类特征明显的常量。以常数0x55AA为例：引导区、主引导区MBR以及IBM兼容扩展的ROM（只读存储单元）等关键字都会使用这个常量。

一些特殊，则是某些加密，常常使用某些特殊的常数，如果我们使用调试工具就能很容易发现这些点。

以MD5算法为例，其内部变量初始值则是：

```
var int h0 := 0x67452301
var int h1 := 0xEFCDAB89
var int h2 := 0x98BADCFE
var int h3 := 0x10325476
```

也就是说，如果某段代码连续出现了上述四个常量，那么这段代码可能就是MD5的算法相关。
