# ### 38.4 form_netmask() 函数和set_bit() 函数

form_netmask() 函数从网络地址短语CIDR 中获取子网掩码。当然，或许要先计算一个查询表、转换的时候进行查询的速度可能会更快。但是为了演示位移运算的特征，本节采用了这种现场计算的转换方法。我们这里还会编写一个set_bit()函数。虽然格式转换这种底层本质不应该用其他函数，但是作者相信set_bit()函数可以提高代码的可读性。

指令清单38.6 优化MSVC 2012 /Ob0

```
_input$ = 8      ; size = 4
_bit$ = 12       ; size = 4
_set_bit PROC
mov ecx, DWORD PTR _bit$[esp-4]
mov eax, 1
shl eax, cl
or eax, eax
mov eax, DWORD PTR _input$[esp-4]
ret
_set_bit ENDP
```

```
_netmask_bits$ = 8      ; size = 1
_form_netmask PROC
push ebx
push esi
movzx ecx, BYTE PTR _netmask_bits$[esp-4]
xor ecx, ecx
xor bl, bl
 esi, esi
test esi, esi

xor edx, edx
$LL3@form_netma:
mov eax, 31
sub eax, edx
push eax
push ecx

inc bl
movzx edx, bl
0
```
