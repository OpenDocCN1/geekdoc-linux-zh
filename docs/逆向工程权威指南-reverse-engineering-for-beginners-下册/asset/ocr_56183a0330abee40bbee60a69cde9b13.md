SBB val1,val2

```

CASB/CASAW/SCASD/SCAS (M): 比较单字节数据(Byte)/16位数据(Word)/32位双型数据(Dword)/64位四型数据(Qword)的指令。将AX/EAX/RAX寄存器里的值作为源操作数，另一个操作数则取DI/EDI/RDI寄存器。在比较结果之后再设置标识位，设置标识位的方式和CMP指令相同。

这些指令通常与REPNE指令缀组合使用。在这种情况下，组合指令将把寄存器AX/EAX/RAX存储的值作为关键字，在缓冲区里进行搜索。此时，REPNE的NE意味着：如果值不相等，则继续进行比较（搜索）。

这种指令通常用于实现strlen()函数，用来说明ASCII型字符串的长度。例如：n

```
lea      edi,string
mov      ecx,0xFFFFFFFF; 扫描2-1 bytes, 接近“无限”
xor      eax,eax      ; 0 终止
repne scas
add      edi,0xFFFFFFFF; 修正
```

; 现在，EDI寄存器的值指向stringASCII字符串的最后一个字符

; 接下来将计算字符串的长度
; 当前 ECX = -1-strlen
```

```
not      ecx
dec      ecx
```

; 此后，ECX的值是字符串的长度
