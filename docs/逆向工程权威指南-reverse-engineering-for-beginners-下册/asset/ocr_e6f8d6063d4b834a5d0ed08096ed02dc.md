# 54.13.5 可变参数函数

可变参数函数利用了数组的数据结构。

```
public static void f(int... values)
{
    for (int i=0; i<values.length; i++)
        System.out.println(values[i]);
    }
}
public static void main(String[] args)
{
    f(1,2,3,4,5);
}
```
