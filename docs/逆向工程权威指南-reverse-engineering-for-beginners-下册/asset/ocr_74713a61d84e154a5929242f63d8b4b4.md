# 18.7 二维字符数组的封装格式

在指令清单18.8所示的程序里，如果要准备指向月份名称的指针，就必须进行一次以上的内存操作。有没有可能去这些内存加载的内存操作？
只要把二维数组进行相应处理，即可省略有关操作。

```
#include <stdio.h>
#include <assert.h>

const char month2[12][10] = {
    { 'J','a','n','u','a','r','r','y','0', 0, 0, 0 },
    { 'F','e','b','r','u','a','r','y','0', 0, 0,0, 0 },
    { 'M','a','r','c','h', 0, 0, 0, 0, 0 },
    { 'A','p','r','i','l', 0, 0, 0, 0, 0 },
    { 'M','a','r','y', 0, 0, 0, 0, 0, 0 },
    { 'J','u','n','e','r', 0, 0, 0, 0, 0, 0 },
    { 'J','u','n','i','y', 0, 0, 0, 0, 0, 0 },
    { 'A','u','g','u','s','t', 0, 0, 0, 0, 0 },
    { 'S','e','p','t','e','m','b','e','r', 0, 0 },
    { 'O','c','t','o','b','e','r', 0, 0, 0 },
    { 'N','o','v','e','m','b','e','r', 0, 0 },
    { 'D','e','c','e','m','b','e','r', 0, 0, 0, 0, 0 }
};

// in 0..11 range (int month)
const char *get_month2(int month) {
    return &month2[month][0];
}
```
