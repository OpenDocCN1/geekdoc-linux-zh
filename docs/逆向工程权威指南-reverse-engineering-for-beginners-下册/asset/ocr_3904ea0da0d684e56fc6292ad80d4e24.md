# G.3.4 练习题2.13

答案：线性反馈移位寄存器。详细资料请参见：
https://en.wikipedia.org/wiki/Linear_feedback_shift_register

程序源代码如下所示：

```
// reworked, from
https://en.wikipedia.org/wiki/Linear_feedback_shift_register

#include <stdint.h>

uint16_t f(uint16_t in) {
    /* taps: 16 14 13 11; feedback polynomial: x^16 + x^14 + 
x^13 + x^11 + 1 */
    unsigned bit bit = ((in >> 0) ^ (in >> 2) ^ (in >> 3) ^ (in >> 
5)) & 1;
    return (in >> 1) | (bit << 15);
}
```
