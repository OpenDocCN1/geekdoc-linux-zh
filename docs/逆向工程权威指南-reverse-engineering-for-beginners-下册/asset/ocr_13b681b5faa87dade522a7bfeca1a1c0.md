# MSVC

在编译std::list的时候，MSVC 2012会存储链表的长度。除此以外，它的实现方法和GCC基本一致。这就是说，内置函数size()只需要从内存中读取一个值就可以返回size函数结果，其速度相当快。不过，这意味着每次增/删除节点的时候都需要要调整这个值。
