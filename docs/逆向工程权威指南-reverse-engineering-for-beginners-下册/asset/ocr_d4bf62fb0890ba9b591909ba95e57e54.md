及dreturn)都带有前缀d,这个符号限定表明操作属于双精度浮点数double。

下面我们来看看含有两个参数的函数情况:

```
public class calc
{
    public static int sum(int a, int b)
    {
        return a+b;
    }
}
public static int sum(int, int);
flags: ACC_PUBLIC, ACC_STATIC
Code:
stack=2, locals=2, args_size=2
0: iload_0
1: iload_1
2: add
3: return
```

指令iload_0用于提取第一个参数a，而iload_1则用于引入第二个参数b。在执行完两条指令之后，栈内数据如下所示:

```
+----+
TOS ->| b |
+----+
| a |
+****
```

而指令iadd的含义则是将两个参数中的数值相加，并将结果保存在栈顶TOS。

```
+------+
TOS ->| result |
+------+
```

如果我们将这两个函数的两个参数的数据类型更换为long类型的话:

```
public static long lsum(long a, long b)
{
    return a+b;
}
```

我们看到的字节码会变为:

```
public static long lsum(long, long);
flags: ACC_PUBLIC, ACC_STATIC
```
