# 5.1.3 std::vector容器

我们将std::vector称为为POD[C] 容器的安全封装容器。其内部结构和标准字符std::string字符十分相似（参见51.1.4节）。它有一个数据缓冲区的专用指针，一个指向数据组组尾部的专用指针，以及一个指向分配缓冲区尾部的专用指针。

这种数组采取的每个元素彼此相邻的方式存储在内存之中，此点和常数数组没有任何没什么区别（参见第18章）。新推出的C++11标准，为其定义了内置函数data()。std::vector::data()的作用和std::string中的.c_str()一样，用于返回缓冲区的地址。

这种数据结构利用堆/堆来存储数据缓冲区，而堆栈的空间消耗可能会比数组本身还要。

MSVC和GCC的实现原理基本相同， 只是结构体的变量名称稍微有些不同。\因此，在这里使用同一个例子来进行说明。下述源程序用于遍历std::vector的数据结构。
