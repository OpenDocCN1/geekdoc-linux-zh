这个函数在其内部表中持有一个参数。这个参数就是这个对象的指针。

本函数可以用C语言重写如下：

```
void ZN1c4dumpEv(int *obj)
{
    printf("%d; %d\n", obj, *(obj+1));
}
```

综合本节的例如中，MSVC和GCC的区别在于函数名的名称编码格式以及传递this的具体方式（MSVC通过ECX传递，而GCC以函数的第一个参数的方式传递）。

GCC-x86-64

在编译64位程序的时候，GCC通过RDI,RSI,RDX,RCX,R8和R9这几个寄存器传递的前6个参数。它通过RDI寄存器，以第一个参数的的形式传递thisthis指针。另外，整型int数据仍然是32位数据。它会不会使用指令JMP替代RET指令。
