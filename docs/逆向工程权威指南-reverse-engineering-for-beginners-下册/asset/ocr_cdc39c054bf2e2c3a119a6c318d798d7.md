```
_a$ = 8          ; size = 8
_b$ = 16         ; size = 8
_d_max PROC
    movsd xmm0, QWORD PTR _a$[esp-4]
    comisd xmm0, QWORD PTR _b$[esp-4]
    je SHORT $LN1@d_max
    fld
    QWORD PTR _a$[esp-4]
    ret
$LN1@d_max:
    fld
    QWORD PTR _b$[esp-4]
    ret
    0
_d_max ENDP
```

这个程序用栈传递函数变量a和b，并且把函数返回值存储在ST(0)寄存器里。除之外它和64位的程序没有区别。
