mov eax, [ebx] ; get 32-bit word from array

```

main 栈空间内的数据依次被看作两种数据:先被当作结构体、再被当作结构体中的各别字段。

本例表明，我们可以借此指针修改结构体中的各个字段。

本文再次强调：若如果是hack目的的研究代码，就不不必做这种处理。在编写生产环境下的程序，不建议使用这种手段。

# 21.3.6 替换为字节型数组

更进一步的实验说明，也可以让时间结构体与字节数组共用一个指针。

```
#include <stdio.h>
#include <time.h>

void main() {
	struct tm t;
	time_t unix_time;
	int i, j;

	unix_time=time(NULL);

		localtime_r(&unix_time, &t);

	for (i=0; i<9; i++) {
		for (j=0; j<4; j++) {
			printf("0x%02X", ((unsigned char*)t)[i*4+j]);
		}
		printf("\n");
	}
}
