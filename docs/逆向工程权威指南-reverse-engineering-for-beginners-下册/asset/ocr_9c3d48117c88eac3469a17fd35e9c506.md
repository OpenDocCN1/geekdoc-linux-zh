# 第29章 MIPS的特点

# 29.1 加载常量

```
unsigned int f() {
    return 0x12345678;
};
```

MIPS和ARM平台的指令都是定长指令。MIPS程序的指令都是32位opcode。在MIPS平台上，我们可能无法使用单条指令就完成对32位量的赋值操作。此类操作至少分两步进行：首先传递32位数据的高16位，然后通过ORI向寄存器传递立即的低16位。

指令清单29.1 GCC 4.4.5-03 (assembly output)

```
li $2,305397760 # 0x12340000
j $2,0x052678 ; branch delay slot
```

IDA能够识别此类组合指令。为了方便阅读，它对后面的Ori指令进行了处理：用伪指令Li替换了Ori指令，且用完整的32位替换了值的低16位。

指令清单29.2 GCC 4.4.5-03 (IDA)

```
lui $v0,0x1234
jr $ra
li $v0,0x12345678 ; branch delay slot
```
