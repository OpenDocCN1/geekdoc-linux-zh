```
; move to coprocessor l1:
    mtcl       $v0, $f0
    return
    jr         $ra
    or         $at, $zero ; branch delay slot
```

因为在传递高16位数据时清除寄存器的低16位，所以单条LUI指令就可以完成0x80000000的赋值，无需再用ORI指令。
