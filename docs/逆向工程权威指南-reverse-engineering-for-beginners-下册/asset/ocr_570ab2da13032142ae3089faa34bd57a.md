局部变量，都不影响分配空间的速度。

虽然您的可以在外外的任何地方存储局部变量，但是用数据据来存储局部变量已经是一种约定俗成的习惯了。

# 5.2.4 x86:alloc() 函数

alloc() 函数很特殊。

大来说，alloc() 函数直接用来分配内存，除此之外，它与malloc() 函数没有显著的区别。

函数尾声的代码会将数据据还原为原函数启动之前的状态，直接释放由alloc()分配的内存。所以，程序不需要使用free() 函数来释放这个函数申请的内存。

alloc() 函数的实现方法至关重要。

简单来说，这个函数将所需空间的大小为幅度、向后调整ESP的值，此时ESP就成了新的数据空间的指针。我们一起来做一个测试：

```
#ifdef _GNUC_
#include <alloca.h> // GCC
#else
#include <malloc.h> // MSVC
#endif
#include <stdio.h>

void f() {
    char *buf = (char*)alloc(600);
    #ifdef _GNUC_
    snprintf(buf, 600, "hi! %d, %d, %d\n", 1, 2, 3); // GCC
    #else
    snprintf(buf, 600, "hi! %d, %d, %d\n", 1, 2, 3); // MSVC
    #endif

    puts(buf);
}
```

snprintf() 函数的功能和printf()函数的功能差不多。printf()将输出结果输出到stdout（也就是终端terminal或console类的输出设备上），而snprintf()则将结果输出到buf数组（人工设定的缓冲区），我们需要通过puts()函数将buf的内容输出到stdout。当然，printf()函数就足够完成snprintf()和puts()两个函数的功能。本文在演示缓冲区的用法，所以要把把它拆分为两个函数。
