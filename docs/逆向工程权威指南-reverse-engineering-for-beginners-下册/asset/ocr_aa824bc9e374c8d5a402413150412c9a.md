# 3.3 GCC的其他特性

只要C语言代码里使用了字符型常量（可参照3.1.1节的范围），编译器就会把这个字符串常量字段，置于常量区，以保证其内容不会发生变化。不过GCC有一个有趣的特征：它可能会把字符串拆出来单独使用。

我们来看下面这段程序：

```
#include <stdio.h>
void f1()
{
    printf("world\n");
}
void f2()
{
    printf("hello world\n");
}
int main()
{
    f1();
    f2();
}
```

多数的C/C++编译器（包括MSVC编译器）会分配出两个直接对应的字符串，不过GCC 4.8.1的编译结果则更为可见可。

指令3.10 在IDA中观察GCC 4.8.1的汇编指令

```
proc near
s
    = dword ptr -1Ch
    sub     esp, 1Ch
    mov     [esp+1Ch+s], offset s ; "world\n"
    call    _puts
    add     esp, 1Ch
    retn
endp
```
