```
#pragma omp critical
if ((checked % 100000)==0)
    printf("checked=%d\n", checked);

int main() {
    int32_t i;
    int threads=omp_get_max_threads();
    printf("threads=%d\n", threads);
    
    __min=(int32_t*)malloc(threads*sizeof(int32_t));
    __max=(int32_t*)malloc(threads*sizeof(int32_t));
    for (i=0; i<threads; i++)
        __min[i]=__max[i]-1;

    start=time(NULL);

    #pragma omp parallel for
    for (i=0; i<INT32_MAX; i++)
        check_nonce(i);

    for (i=0; i<threads; i++)
        printf("__min[%d]=0x%08x max[%d]=0x%08x\n", i, __min[i], i, __max[i]);

    free(__min); free(__max);
}
```

函数check_nonce()有3个作用：向字符串加数字、使用SHA512算法计算字符串的hash、检查hash中是否有3个为0的字节。

这段代码中较为重要的部分是

```
#pragma omp parallel for
for (i=0; i<INT32_MAX; i++)
    check_nonce(i);
```

这个程序并不复杂。如果没有#pragma，程序会从0开始穷举到INT32的最大值（0x7fffffff，即2147483647），依次调用check_nonce()函数验证。加上#pragma之后，编译器会添加特定的代码把整个区间划分为若干个区域，充分利用CPU的多核进行并行运算。
