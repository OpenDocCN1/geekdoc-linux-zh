# 19.2.8 MIPS

指令清单19.20 Optimizing GCC 4.4.5 (IDA)

```
f:
; $a0=a      ori $a0, 0x4000
; $a0=a|0x4000
		li $v0, 0xFFFFFFFD
		jr $ra
		and $v0, $a0, $v0
; at finish: $v0 = $a0 & 0xFFFFFFFD
```

ORI无疑是OR 指令。指令中的“1”意味着它使用机器码存储数值。

但是后面的AND指令就不是AND指令了。这是因为它涉及的立即数0xFFFFFFFD太长，无法直接指令封装在同一条指令里。所以编译器把这个数值赋值给$V0寄存器，然后让它与其他寄存器进行AND/与运算。

# 19.3 位移

C/C++的位移运算符是<<。

x86指令集中有左移的SHL和SHR右移指令。

位移操作常用于实现“2的n次幂”有关的乘法和除法运算。有关介绍参见书籍的16.1.2节和16.2.1节。

位移指令可用于对特定位置进行提取或隔离，用途十分广泛。
