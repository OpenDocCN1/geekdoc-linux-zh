对DL的求值“非”。例如，如果前一位移位DL为0x10(即二进制的1000b)，在进行非运算之后，它的值将变为0xEF(即二进制的11101111b)。

```
.text:00541034 dl
```

下述指令过滤相关位。如果寄存器的某个位是1，那么它就会留CL寄存器的对应；否则将把CL寄存器的相关位设置为0。如果刚才DL的值不变，还是11101111b，那么CL的第5位(从数权最低位开始)将变为0，其余位保持不变。

```
.text:00541036 and cl, dl
```

Get_bit()函数的工作也差不多。在arg_C为0的情况下，函数将清除数组中的特定位，否则设置相关位为1。

我们已经知道数组组用64字节。无论是set_bit()函数还是get_bit()函数，它们的前两个参数都相当于于2D坐标。然后数组变为8×8矩阵。

通过上面的分析，我们可以整理出set_bit()和get_bit()的源码如下：

```
#define IS_SET(flag, bit) ((flag) & (bit))
#define SET_BIT(var, bit) ((var) |= (bit))
#define REMOVE_BIT(var, bit) ((var) &= ~(bit))
```

```
static BYTE cube[8];

void set_bit(int x, int y, int shift, int bit)
{
    if (bit)
        SET_BIT(cube[x][y], 1<<shift);
    else
        REMOVE_BIT(cube[x][y], 1<<shift);
```
