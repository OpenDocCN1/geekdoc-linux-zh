```
_rt$ = -4          ; size = 4
_a$ = 8           ; size = 4
_f PROC
    push ebp
    mov ebp, esp
    push ecx
    mov eax, DWORD PTR _a$[ebp]
    mov DWORD PTR _rt$[ebp], eax
    mov ecx, DWORD PTR _rt$[ebp]
    or ecx, ecx ; 00000400H
    mov eax, DWORD PTR _rt$[ebp]
    mov eax, ffffffff
    and edx, -513
    mov DWORD PTR _rt$[ebp], edx
    mov eax, DWORD PTR _rt$[ebp]
    mov esp, ebp
    pop ebp
    ret 0
_f END
```

OR 指令是逐位进行或的指令，可以用来指定位置1。
效果上，如果立即数的某个位位为1，OR指令会保留寄存器的这个位的值；如果立即数的某个位位为0，OR指令就会把寄存器这个位的值设置为0。按照位掩码 (bitmask) 的方式理解，就会非常容易地记住这些指令的作用。
