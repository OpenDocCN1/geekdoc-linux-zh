```
mov      ebx, offset username
cmp      byte ptr [ebx], 'j'
jnz      fail
cmp      byte ptr [ebx+1], 'o'
jnz      fail
cmp      byte ptr [ebx+2], 'h'
jnz      fail
cmp      byte ptr [ebx+3], 'n'
jnz      fail
jz       it_is_john
```

不管是以上的哪种情况，我们利用十六进制的文本编译器都不能直接搜索到字符串原文。

实际上这两种方法适用于那些无法利用数据结构数据的情景。因为它们可以在文中直接构造数据，所以也见于各种PIC和shellcode。

另外，笔者还见过过这样使用sprintf( ) 函数的:

```
sprintf(buf, "%%c%c%s", "hel","l","o w","o","rld");
```

代码看起来很奇怪，但是作为一个简单的反编译技巧来说，不为一个好办法。
