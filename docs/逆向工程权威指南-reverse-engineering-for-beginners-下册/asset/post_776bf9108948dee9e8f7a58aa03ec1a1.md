
```
mov     ebx, [ebp+x]
mov     eax, [ebp+y]
mov     ecx, [ebp+z]
lea     edx, [eax+eax]    ; edx=y*2
mov     eax, edx           ; eax=y*2
shl     eax, 4             ; eax=(y*2)<<4 = y*2*16
e = y*32
sub     eax, edx           ; eax=y*32 - y*2*30
imul    edx, ecx, 600      ; edx=x*600
add     eax, edx           ; eax=eax+edx=y*30 + x*600
lea     edx, [eax+ecx]    ; edx=y*30 + x*600 + z
mov     eax, [ebp+value]
mov     ptr dword:a:[edx*4], eax  ; *(a+edx*4)=value
pop     ebx
pop     ebp
retn
endp
```

GCC的处理方法和MSVC不同。在计算30的时候，GCC没有使用乘法指令。
它的公式是(y+y) << 4-(y+y) = (2) << 4-2y=16y-2y=32y-2y=30。可见，GCC组合了加法、位移和减法运算，替代了MSVC采用的乘法运算。GCC算法的运算速度比直接进行乘法运算的速度还要快。
