如果PADDD的某个操作是内存中的某个值，那么这个值的地址必须与16字节边界对齐，否则将报错。[3]

+   * MOVDQA (Moved Aligned Double Quadword) 的功能MOVDQU相同，只要存储操作数的地址必须与16字节边界对齐，否则报错。除了这点区别之外，两个指令完全相同。此外，MOVDQA的运行速度要比MOVDQU快。

上述SSE指令的运行条件有两个: 需要进行内存处理的操作至少有4对;指针ar3的地址已向16字节边界对齐。

而且，如果ar2的地址没有向16字节对齐，则会执行如下指令:

```
movdq xmm0, xmmword ptr [ebdi*4]; ar1+i*4
paddd xmm0, xmmword ptr [esi*4]; ar2+i*4
movqa xmmword ptr [eax+edi*4], xmm0; ar3+i*4
```

另外，movdq指令会将ar2的值加载到XMM0寄存器。虽然这条指令不要求指针对齐，但是性能略微慢:

```
movdq xmm0, xmmword ptr [ebdi*4]; ar1+i*4
movdq xmm0, xmmword ptr [esi*4]; ar2+i*4 is not 16-byte
aligned; paddd xmm0, xmm0; so load it to xmm0
movqa xmmword ptr [eax+edi*4], xmm1; ar3+i*4
```

其他代码没有涉及与SSE有关的指令。
