```c
uint64_t hash(uint64_t v) {
    v^=C1;
    v=_lrotl(v, v&0xF); // rotate right
    v^=C2;
    v=_lrotl(v, v&0xF); // rotate left
    v+=C3;
    v=_lrotl(v, v%60); // rotate left
    return v;
}

```

## 77.2 Z3 SMT求解

在加密知识不足的情况下，我们可以使用微软研究团队发布的Z3工具[3]尝试破解。虽然它只是个形式验证工具，但是我们将它用来SMT求解，我们要用Z3来求解巨型方程。

我们使用的Python代码如下：

```python
from z3 import *
C1=0X5D7E0D1F2E0F1F84
C2=0xD388D76AEECB1500
C3=0xD2E9EE7E83C28B

inp, i1, i2, i3, i4, i5, outp = BitVecs('inp i1 i2 i3 i4 i5 outp', 64)

s = Solver()
s.add(i1==inp*C1)
s.add(i2==RotateRight(i1, i1 & 0xF))
s.add(i3==i2 ^ C2)
s.add(i4==RotateLeft(i3, i3 & 0xF))
s.add(i5==i4 + C3)
s.add(outp==RotateLeft(i5, URem(i5, 60)))
s.add(outp==10816639415815620)
print(s.check())
m=s.model()
print("inp=%X" % m[inp].as_long())
print("outp=%X" % m[outp].as_long())
```

程序输出的“sat”是“satisfiable”的缩写。这就是说我们的方法至少找到一个输入。另外注意的是，因为原函数不是单射函数，所以可能存在符合条件的输入。不过，公开的Z3 SMT求解只会一组解。为此，我们对上面的程序进行修改，添加第19行，让程序探寻自己的解：

```python
from z3 import *
C1=0x5D7E0D1F2E0F1F84
C2=0x388D76AEE8BC1501
C3=0x0D2E9EE7E8348B
inp, i1, i2, i3, i4, i5, outp = BitVecs('inp i1 i2 i3 i4 i5 outp', 64)
s = Solver()
s.add(i1==inp*C1)
s.add(i2==RotateRight(i1, i1 & 0xF))
s.add(i3==i2 ^ C2)
s.add(i4==RotateLeft(i3, i3 & 0xF))
s.add(i5==i4 + C3)
s.add(outp==RotateLeft(i5, URem(i5, 60)))
s.add(outp==10816639415815620)
s.add(inp!=0x12EE577B63E80B3)
print(s.check())
m=s.model()
print("inp=%X" % m[inp].as_long())
print("outp=%X" % m[outp].as_long())
```
