# 第45章 打造无分支的abs () 函数

请回回前文第12章第2节的那个函数。请设想一下，能否用x86的汇编指令打造一个无分支的版本？

```
int my_abs(int i)
{
    if (i<0)
        return -i;
    else
        return i;
}
```

答案当然是肯定的。

# 45.1 x64下的GCC 4.9.1优化

首先我们看看，如果我们采用GCC 4.9来编译的话，会会出现什么情况？

> 指令清单45.1 x64下的GCC 4.9优化

```
my_abs:
    mov edx, edi
    mov eax, edi
    sar eax, 31
    ; EDX is 0xFFFFFFFF here if sign of input value is minus
    ; EDX is 0 if sign of input value is plus (including 0)
    ; the following two instructions have effect only if EDX is
0xFFFFFFFF
    ; or if EDX is 0
        xor eax, edx
```
