#  31.2 小端字节序

在采用小端字节序时，0x12345678在内存中的存储方式如下所示。

| 内存地址 | 字节值 |
| --- | --- |
| +0 | 0x78 |
| +1 | 0x56 |
| +2 | 0x34 |
| +3 | 0x12 |

Intel x86系列CPU采用小端字节序。
