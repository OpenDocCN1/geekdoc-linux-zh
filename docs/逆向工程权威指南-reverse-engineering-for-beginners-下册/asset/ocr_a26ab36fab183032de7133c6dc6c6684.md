编码的（人类）可读性。严格来说，编译器编译出来的代码本身就是机器运行的，而不是给人经过阅读的。

本例还出现了未介绍的SETNZ指令。从前面一条指令开始解释：如果AL的值是0，则test.al 指令会将标志寄存器ZF=0；而SETNZ (Not Zero) 指令在ZF=0的时候，设置AL=1。用白话来说就是：如果AL等于0，则跳转到loc.80483F0。编译器出来的代码中，有些代码并没有实际意义，这是因为我们没有开启优化。

# 指令清单15.1 Optimizing MSVC 2012 /Ob0

```
str$ = 8                ; size = 4
_strlen PROC
    mov     edx, DWORD PTR _str[esp-4] ; 用EDX作为字符串指针
    mov     eax, edx                      ; 复制EAX

$LL2@strlen:
    mov     cl, BYTE PTR [eax]            ; CL = *EAX
    inc     eax                           ; EAX++
    test    cl, cl                        ; CL=0?
    jne     SHORT $LL2@strlen             ; no, continue loop
    sub     eax, edx                      ; 计算指针的变量
    dec     eax, edx                      ; decrement EAX
    ret
_strlen ENDP
```

优化编译器生成的程序短了很多。不必多说，只有在函数较短且局部较少的情况下，编译器才会做这种程度的优化。

inc/dec指令就是递、减指令，换句话它们相当于运算符“++”。
