在与REP前缀组合时，它会把CX/CX/RCX作为循环控制变量进行循环操作。这种情况下，它就像C语言中的memcpy函数那样工作。如果编译器在编译阶段能够确定每个模块的大小，编译器通常使用REP MOVX指令内联函数的实现memcpy()

例如，memcpy (EDI, ESI, 15) 等效于：

```
; copy 15 bytes
CLD      ; set direction to "forward"
MOV ECX, 3
REP MOVSD ; copy 12 bytes
MOWS      ; copy 2 more bytes
MOVSB     ; copy remaining byte
```

在复制15字节的内容中，从寄存器读取的操作效率来看，上述代码的效率高于15次读写（MOVSB）的操作效率。

MOVSX: 以符号扩展的方法实现signed数据的类型转换（见本书15.1.1节）。

MOVZX: 用零扩展的方法实现unsigned数据的类型转换（见本书15.1.1节）。

MOV: 数据传输指令。“MOV”这个名字与“MOVE”（移动）拼写相似，不过它的功能是复制数据而非移动数据。在某些平台上，这条指令的名字是“LOAD”或者类似的名字。

值得的是，当用MOV指令给32位寄存器的低16位时，寄存器的高16位不会发生变化。使用MOV指令给64位寄存器的低32位赋值时，寄存器的高32位会被清零。

64位寄存器的高32位被自动清零的特性，可能是为了在x86-64系统上兼容32位程序而有意设计的。

MUL: unsigned数据的乘法运算指令。

NEG: 求补码指令（非补码指令）。NEG op可以得到-op。
