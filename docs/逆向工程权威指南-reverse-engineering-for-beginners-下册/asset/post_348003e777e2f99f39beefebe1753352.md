## 第93章 安腾指令

来说，安腾 (Itanium)处理器几乎是失败。但是它的Itanium (IA64)架构非常值得研究。乱序执行（OoO）侧重于CPU指令的片段，再把重组后的指令分组到并行计算。而英特尔（Intel）架构的并行技术（Explicitly Parallel Instruction Code, EPIC），则让编译器在早期阶段实现分组。厂商推出了这种并行技术的编译器。不过这些编译器因为复杂而引起了争议。本章从Linux内核中取了部分。

据称，Intel和HP的开发者针对常见指令进行了模式划分，从而得出了指令类型（即指令模板）的概念——指令操作字资源的模板。CPU据此将指令划分为12类基本类型（basic types），基本类型又分为带有停止位的指令和不停止位的实例。例如，0类指令叫做MFII指令，依次由内存读写操作指令（M）和两类整数操作指令（II）构成；最后一种指令，0xd1类指令，又叫MFB类指令，依次由内存读写操作指令（M）、浮点数运算操作指令（B）构成。

如果汇编器在指令槽（instruction slot）上没有找到操作指令，那么它可能在这些位置上插入nop。在人工汇编中，m代表内存单元。

## 指令清单93.1 Linux kernel 3.2.0

```c
#define TEA_ROUNDS 32
#define TEA_DELTA 0x9e379b9

static void tea_encrypt(struct crypto_ctx *tfm, u8 *dst, u8 *src)
{
	u32 y, z, n, sum = 0;
	u32 k0, k1, k2, k3;
	struct crypto_ctx *ctx = crypto_ctx(tfm);
	const le32 *in = (const le32 *)src;
	le32 *out = (le32 *)dst;

	y = le32_to_cpu(in[0]);
	z = le32_to_cpu(in[1]);

	k0 = ctx->KEY[0];
	k1 = ctx->KEY[1];
	k2 = ctx->KEY[2];
	k3 = ctx->KEY[3];

	n = TEA_ROUNDS;
	while (n-- > 0) {
		sum += TEA_DELTA;
		y += ((z << 4) + k0) ^ (z + sum) ^ ((z >> 5);
		z = ((y << 4) + k2) ^ ((y + sum) ^ ((y >> 5) + k3);
	}
	out[0] = le32_to_cpu(y);
	out[1] = le32_to_cpu(z);
}
```

上述IA64指令具有许多特点。
