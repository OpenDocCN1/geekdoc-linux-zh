# G. 3.2 练习题2.4

答案: 函数strstr()。其源代码如下所示：

```
char *strstr (
    const char * str1,
    const char * str2
)
{
    char *cp = (char *) str1;
    char *s1, *s2;
    if (!*s2)
        return((char *) str1);
    while (*cp)
    {
        s1 = cp;
        s2 = (char *) str2;
        while (*s1 && *s2 && !(*s1-*s2))
            s1++, s2++;
        if (!*s2)
            return(cp);
        cp++;
    }
    return(NULL);
};
```
