# 第65章 线程本地存储TLS

线程本地存储 (Thread Local Storage, TLS) 是一种线程内部共享数据的数据交换区域。每个线程都可以在这个区域保存它们要在内部共享的数据。一个比较著名的例子是C语言的全局变量errno。对于errno类的全局变量，如果多线程进程的某一个对其进行了修改，那么这个变量就会影响到其他所有的线程。显然和实际需求相符，因此全局变量errno必须保存在TLS中。

为解决这个矛盾，C++ 11标准新增了一个限定符thread_local。它能将指定变量和特定的线程联系起来。由它限定的变量被初始化，并且会被保存在TLS中。

```
#include <iostream>
#include <thread>

thread_local int tmp=3;

int main() 
{
    std::cout << tmp << std::endl;
};
```

接下来，我们使用MinGW GCC 4.8.1编译它，不要用MSVC 2012进行编译。

在分析可执行文件的PE之后就会发现，变量tmp被分配到TLS专用的数据保存区域了。
