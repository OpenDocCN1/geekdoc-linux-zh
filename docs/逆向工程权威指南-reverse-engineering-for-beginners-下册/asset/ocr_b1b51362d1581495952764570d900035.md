# 第54章 Java

# 54.1 简介

Java程序的反编译工具已经十分成熟了。一般来说，它们都是JVM（基于虚拟机机制的Java虚拟机）的字码（bytecode），指令里的指令只有一个字节，故而得名。不过java指令中的操作数属于变长信息分析工具。著名的JAD（http://varaneckas.com/jad/

) 就是一款具代表性的JAVA反编译工具。

相对于x86平台底层的反编译技术来说，面向JVM的bytecode更易反编译。主要原因是：

+   ① 字节包含有丰富的类型信息。

+   ② JVM内存模型更为严格，因此字节分析起来更为有章可循。

+   ③ Java编译器不做任何优化工作（而JVM JIT在运行时会做优化），因此在反编译字节码之后，我们基本可以直接理解Java类文件里的原始指令。

什么时候 JVM bytecode反编译有用呢？

+   ① 无需重新编译反汇编的结果，还能给类文件做应急补丁。

+   ② 分析混淆代码。

+   ③ 需要编写自己的代码混涤器。

+   ④ 创建面向JVM的、类似程序的代码生成工具（类似Scala, Cloohure等等）。
