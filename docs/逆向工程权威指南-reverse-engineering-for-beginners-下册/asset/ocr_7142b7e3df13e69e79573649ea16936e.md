```
mov eax, 0xCCCCCCh
mul edx
shr edx, 3
mov eax, edx
mov esp, ebp
pop ebp
retn
```

Win32的结果就是GetTickCount() 函数返回的十分之一。[8]

这就是oracle在Win32下和x86返回不同结果的根本原因因为它了完全不同的操作系统函数。

“call kfqd_cfui_drain”里有一个“drain”。这个关键字有“表中的某个取特定函数的返回值”的含义。

前面过的过的_tables工具能够处理kqfd_tab_registry_0。因此，我们可以用它分析“列”的值与函数数量之间的关系：

```
[XKSUTM] [kqfd_OPN_ksutm_c] [kqfd_tab_fetch] [NULL] [NULL]
[kqfd_DRN_ksutm_c]
[XKSUSUGIF] [kqfd_OPN_ksusg_c] [kqfd_tab_fetch] [NULL] [NULL]
[kqfd_DRN_ksusg_c]
```

上述信息的OPN代表“Open”和“DRN”。DRN当然是“drain”的意思。
