# # 第17章 FPU

FPU是专门处理浮点数的运算单元，是CPU的一个组件。

在早期的计算机系统中，FPU位于CPU之外单独的运算芯片上。

# ## 17.1 IEEE 754

IEEE 754 标准规定了计算机设计环境中的二进制和十进制的浮点交换、术格式以及方法。符合这种标准的浮点数符号位、尾数（又称为有效数字、小数位）

# ## 17.2 x86

事先接触过stack[1]或语言编程基础[2]的读者，理解本节内容的速度会比较快。

> 80486处理器之前，FPU（与CPU位于不同的芯片）叫作操作（辅助）处理器。而且那个时候的FPU还不属于主板的标准配置；如果要在主板上安装FPU，人们需要单独购买一个。[3]

8048DX 之后的CPU处理器集成了FPU的功能。

若没有FWAIT指令和opcodeD8~DF开启的所谓的“ESC”字符指令（opcodeD8~DF开启），很少有人还会想起FPU属于独立运算单元的这段历史。FWAIT指令的作用是让CPU等待FPU结束，而ESC字符指令会对FPU执行。
