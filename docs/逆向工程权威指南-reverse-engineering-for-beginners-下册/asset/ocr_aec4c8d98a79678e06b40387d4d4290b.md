# 第41章 除以9

我们来看一个非常简单的函数：

```
int f(int a)
{
    return a/9;
}
```

# 41.1 x86

x86平台编译器的编译方法十分直白：

指令清单41.1 MSVC

```
_a = 8          ; size = 4
_f:
    push   ebp
    mov    ebp, esp
    mov    eax, DWORD PTR _a[ebp]
    cdq             ; sign extend EAX to EDX:EAX
    mov    ecx, 9
    idiv   ecx
    pop    ebp
    ret    0
ENDP
```

IDIV指令是除法指令。它从寄存器对EDAX中提取被除数、从ECX寄存器中提取除数。计算结束后，它会把结果/商存储在EAX寄存器里，把余存储在EDX寄存器里。除法计算之后，就位于EAX寄存器里，直接成为f()函数的返回值；因此没有其他值传递的操作。为了通知IDIV指令对EDX：EAX寄存器对提取64位被除数，编译器在IDIV
