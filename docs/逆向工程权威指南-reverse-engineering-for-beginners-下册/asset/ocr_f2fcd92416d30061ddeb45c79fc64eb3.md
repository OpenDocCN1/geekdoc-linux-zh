当循环变量从2递增到9时，循环语句对应的汇编代码大体如下：

# 指令清单14.15 x86

```
mov [counter], 2 ; initialization
jmp check
body:
  ; loop body
  ; do something
  ; use counter variable in local stack
  add [counter], 1 ; increment
check:
  cmp [counter], 9
  jne body
```

如果没有开启编译器的优化编译功能，那么循环变量的递增操作可能对应着3条汇编指令。

# 指令清单14.16 x86

```
MOV [counter], 2 ; initialization
JMP check
body:
  ; loop body
  ; do something
  ; use counter variable in local stack
  MOV REG, [counter] ; increment
  INC REG
  MOV [counter], REG
check:
  CMP [counter], 9
  JLE body
```

当循环体较短时，编译器可能给循环控制变量分配专用的寄存器。

# 指令清单14.17 x86

```
MOV EBX, 2 ; initialization
JMP check
body:
  ; loop body
  ; do something here
  ; use counter in EBX, but do not modify it!
  INC EBX ; increment
check:
  CMP EBX, 9
  JLE body
```

编译器还可能调换部分指令的顺序。
