使用MSVC2010生成的汇编代码如下所示：

```
lea     eax, DWORD PTR _xS[ebp]
push    eax
push    OFFSET $SG3833 ; '%d', 00H
call    scanf
add     esp, 8
cmp     eax, 1
jne     SHORT $LN2@main
mov     ecx, DWORD PTR _xS[ebp]
push    ecax
push    OFFSET $SG3834 ; 'You entered %d... ', 0Ah, 00H
call    printf
add     esp, 1
jmp     SHORT $LN1@main
$LN2@main:
push    ecax, OFFSET $SG3836 ; 'What you entered? Huh?', 0Ah, 00H
call    printf
add     esp, 4
$LN1@main:
xor     eax, eax
```

当被调用函数callee（本例中scanf（函数））使用EAX寄存器值向调用函数caller（本例中jne（函数））传递返回值。

之后，“CMP EAX, 1”指令对返回值进行比对，检查其值是否为1。

JNE是跳转指令，全称是“Jump if Not Equal”。在两个不时不同时跳转。

就是，如果EAX寄存器的值不是1，则程序将跳转到JNE所指向的地址（本例中会接到$LN1@main），在将控制权交给这个地址之后，CPU将执行它的后的打印指令，显示“What you entered? Huh?”。另一种情况是scanf（函数）成功读取指定数据类型的数据，其返回值为1，此时不会发生跳转，而是继续执行JNE以前的指令，显示“You entered %d... ”和变量x的值n

scanf（函数）成功赋值变量值的情况下，程序一路执行到JMP（无条件条件）指令。该指令跳转到第二个调用指令printf（函数）的指令，从“XOR EAX, EAX”指令开始，并完成返回0的操作。

可见，“一般地说”是指判断语句中出现的“CMP/Jcc”指令。此处cc是英文“condition code”的缩写。比较两个比较指令会设置处理器的标志位[44]。Jcc指令会检查标志位，判断是否进行跳转。

但是这种说法容易产生误导，实际CMP指令进行的操作是减法运算。确切地说，不仅是CMP指令所有的“数学/算术计算”指令都会设置标志位。
