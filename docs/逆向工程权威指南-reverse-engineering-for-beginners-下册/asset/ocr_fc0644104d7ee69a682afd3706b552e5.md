指令const_m1将这个值入栈中，其实这个值就是0xFFffffff。将整数与-1进行XOR运算，其实就是对原操作数的所有位进行取反（这一点可以参考本书的附录A.6.2）。

我们将所有的数据类型扩展为64位的long类型时：

```
public static long set(long a, int b)
{
    return a | 1<<b;
}
```
