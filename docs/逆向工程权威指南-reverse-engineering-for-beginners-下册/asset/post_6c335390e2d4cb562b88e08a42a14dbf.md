## 21.6 结构体中的操作

### 21.6.1 CPUID

C/C++语言可以精确操作结构中的位。这能够帮助程序员大幅地节省程序的内存消耗。例如，bool类型数据就需要1位空间。但是时间开销和空间效率不可兼，如果节约内存缓存，程序的性能就会下降。

以CPUID指令为例，该指令用于获取CPU及其特性信息。[8]

如果在执行指令之前设置EAX寄存器的值为1，那么CPUID指令将按照排列格式在EAX寄存器中存储CPU的特征信息。

| 3:0 (bits) | Stepping |
| 7:4 (bits) | Model |
| 11:8 (4 bits) | Family |
| 13:12 (2 bits) | Processor Type |
| 19:6 (4 bits) | Extended Model |
| 27:20 (8 bits) | Extended Family |

MSVC 2010 没有CPUID宏，而GCC 4.4.1没有这个宏。所以，我们自己写一个函数，用GCC编译它。[9]
