# 2.1 x86

在开启优化功能之后，GCC编译器产生的汇编指令，如下所示：

指令清单2.2 Optimizing GCC/MSVC（汇编指令）

```
mov    eax, 123
ret
```

MSVC编译的程序由两条指令构成：第一条指令把数值123放在EAX寄存器里；根据函数调用约定[11]，后面一条指令会把EAX的值作为返回值传递给用用者函数，而用用者者函数（caller）会从EAX寄存器里取值，把它当作作返回结果。
