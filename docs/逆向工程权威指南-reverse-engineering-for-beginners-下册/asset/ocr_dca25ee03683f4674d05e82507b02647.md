# 27.2 传递浮点型参数

```
#include <math.h>
#include <stdio.h>
```

```
int main ()
{
    printf("%32.01 ^ 1.54 = %lf\n", pow(32.01,1.54));
    return 0;
}
```

在函数间负责传递浮点点数的寄存器是XMM0~XMM3寄存器。

# 指令清单27.5 Optimizing MSVC 2012 x64

```
$SG1354 DB      "%32.01 ^ 1.54 = %1f", 00H, 00H
__real@4040147ae147ae1elr 40400147ae147ae1elr    ; 32.01
__real@3ff8a3d70a3d70a4r 03ff8a3d70a3d70a4r    ; 1.54
Main  PROC            rsp, 40               ; 00000028H
      movdx xmm, QWORD PTR  real@3ff8a3d70a3d70a4r
      movdx xmm, QWORD PTR  real@40400147ae147ae1
      call             pow
      lea              rcx, OFFSET=$SG1354
      movaps           xmm
      movd             rdx, xmm
      call             printf
      xor              eax, eax               ; 00000028H
      add              rsp, 40
      ret                              0
main ENDP
```

无整数是指令传递白皮书[1]说是AMD传递白皮书，都没有载入MOVSD指令。它就是MOVSD指令。这就是x86指令的指令可以对应多个参数（名称请参阅附录A.6）。此处出现了这个指令，说明研发人员希望指令名称标识操作的数据类型，避免产生冲突。它是浮点值传递给XMM寄存器的低半部分。

pow() 函数从XMM0和XMM1读取参数，再把返回结果存储在XMM寄存器中。
函数返回值又通过RDX寄存器传递给printf() 函数，不过这是为了什么？坦
地地或许，我不知道中种缘由。或许是printf()的特性——可受理不同类型
参数——————的——造成的。
