# 指令清单50.2 采用混淆技术后的代码

```
xor esi, 011223344h ; garbage
add esi, eax      ; garbage
add eax, ebx
mov edx, eax      ; garbage
shl ecx, 4       ; garbage
mul
xor esi, ecx      ; garbage
```

在程序代码中插入的混淆指令，调用的源程序就不会使用的ESI和EDX寄存器。混淆代码利用了源程序的中间之后，大幅地增加了反编译的难度，何乐不为呢？

# 50.2.2 使用多个指令组合替代原来的一个指令

+   - mov op1,op2这条指令，可以使用组合指令替代：PUSH op2, POP op1。

+   - JMP label指令可以使用PUSH label, RET这个指令对替代：PUSH {call指令后面的那个label}、IDA不能识别出这种label标签的调用结构。

+   - CALL label指令可以使用以下三个指令替代：PUSH {call指令后的label}、PUSH label和RET指令。

+   - PUSH op可以使用以下指令替代：SUB ESP,4 or 8; MOV [ESP],操作符。
