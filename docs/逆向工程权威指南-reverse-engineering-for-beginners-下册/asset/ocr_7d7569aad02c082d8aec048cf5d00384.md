JP即JPE:在PF标识为1的情况下进行跳转。

JS:在SF标识为1的情况下进行跳转。




JZ即JE:在操作数相等的情况下进行跳转;转移条件是ZF=1。

LAHF:标识位跳转指令。它把标识位复制到AH寄存器。数据关系如下表所示。

| 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|-|
| SF | ZF | | AF | | PF | | CF |

LEAVE:等于MOV ESP, EBP“POP”指令的组合。即，这条指令释放当前前子程序在栈中的局部变量，恢复栈指针(stack pointer:ESP)和EBP寄存器的初始状态。

LEA:有效（偏移）地址传送指令。

这个指令并不修改源寄存器的值，也不会进行地址以外的求值运算。它可以利用基址、元素符号和元素空间进行混合运算，求得某个元素的有效地址。

所以，MOV和LEA指令有巨大的差异：MOV指令会将操作数当作地址，而对对这个地址的值进行读写操作；而LEA就对操作数的地址进行直接处理。

因此，LEA指令也常用于各种常规计算。

LEA指令有一个重要的特点——它不会影响CPU标识的状态。对于OOE（乱序方式执行的指令）处理器来说，这一特性有利于大幅降低低数据依赖性。

```
int f(int a, int b)
{
    return a*8+b;
}
```
