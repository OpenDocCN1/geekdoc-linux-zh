对每个字符进行XOR运算是一种初级的加密方法。不要因为它简单就想不起这种分析方法，实际的分析工作中就会频繁遇到这种技术。

现在，我们大致理解了01A出现很多次数的原因。在进行异或运算后，数值为0的明文字符会变为数值为01A的密文。

应当注意：加密会导致文件增大。在解密单字节XOR加密的密文时，我们应当尝试0~255之间的每个数字，再分析一下文件被解密成什么样子。有关Norton Guide的文件格式，请参见：

```
http://www.dave.org/norton-guides/file-format/
```

# 信息熵

在加密领域，信息熵（entropy）属于重要的信息指标。它有一个重要特性：加密后的明文和密文，其信息熵不变。本节将介绍使用Wolfram Mathematica 10来计算信息熵的方法。

指令查询84.1 Wolfram 10

```
In[1]= input = BinaryReadList["X86.NG"];
In[2]= decrypt[, input] // N
Out[2]= 5.62724
In[3]= decrypted = Map[BitXor[#, 16^1A], &input];
In[4]= Export["X86_decrypted.NG", decrypted, "Binary"];
In[5]= decrypt[, decrypted] // N
Out[5]= 5.62724
In[6]= Entropy[2, ExampleData["text", "Shakespearesonnets\]] // N
Out[6]= 4.42366
```

上述指令分别用于加载文件、计算信息熵、解密、保存和计算明文的信息熵（熵不变）。Mathematica提供了知名的英文文件以便我们进行分析。我们选取了莎士比亚的十四行诗律进行分析，其信息熵与我们一个例子子句子相同。我们分析的英文句子，其信息熵与莎士比亚的语言相似。对英文原文进行字节字符的XOR加密之后，其信息熵与原文相同。

但是，如果加密单元大于一个字符，那么信息熵就是另一种情况了。
