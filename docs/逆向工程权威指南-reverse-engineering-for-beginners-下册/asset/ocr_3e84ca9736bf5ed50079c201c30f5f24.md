这里顺便说明一下，指令MUL可以将积的高32位保存在HI寄存器中，把积的低32位存在L0寄存器中。而除法指令DIV会把商存在L0寄存器中，将余数保存在HI寄存器中。

如果源程序的除法指令修改为“a % n”、计算余数，那么之后的程序就会用MFHI指令替换本例中的MFL0指令。

# 41.4 它是如何工作的

在引入的n次除之后，除法运算可转换为乘法运算：

这里的M是魔因子（Magic coefficient）。其计算公式是

| M = 2^n / divisor |

最终，除法运算就转换成了

| result = input · M / 2^n |

“除以2的n次方”的运算可以直接通过右移操作实现。如果n小于32，那么中间运算的积的低n位（通常位于EAX或者RAX寄存器）就会被位移运算直接抹掉；如果大于等于32，那么积的高半部分（通常位于EDX或者RDX寄存器）的值都会受到影响。

可见，参数n的取值决定了转换运算的计算精度。

在进行有符号的除法运算时，符号位也对计算精度和n的取值产生了显著影响。
