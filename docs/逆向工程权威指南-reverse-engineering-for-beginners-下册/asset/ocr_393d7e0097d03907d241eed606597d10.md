# 图17.5 OldBy:执行FADDOP指令

在FPU的运算指令结束之后，运算结果存储在ST(0)寄存器中。main()函数相加后会从这个寄存器提取运算结果。

值得注意的是ST(0)寄存器——它的值是13.93......这是什么？

“FADD指令将运算结果推入栈，然后执行了出栈操作”，但是实际上这条指令把寄存器后调整了栈顶指针寄存器的值。所以，确切地说是，寄存器构成了循环缓冲区（circular buffer）。
