## 第4章 函数序言和函数尾声

函数序言（function prologue）是函数在启动的时候运行的一系列指令。其汇编指令大致如下：

```
push    ebp, esp
mov     ebp, esp
sub     esp, X
```

这些指令的功能是:在内存中保存EBP寄存器的内容、将ESP的值恢复到EBP寄存器，然后修改栈的高度，以便为本函数的局部变量申请存储空间。

在函数执行期间，EBP寄存器不受运行的影响它是函数访问局部变量和函数参数的基准值。我们也可使用EBP寄存器存储局部变量和运行参数，但是EBP寄存器的值总是会变化，使用起来并不方便。

函数在退出时，要做退出过程的反操作，释放栈中申请的内存，还原EBP寄存器的值，将代码控制权还原给调用者函数（callee）。

```
mov     esp, ebp
pop     ebp
ret     0
```

借助函数序言和函数尾声的有关特征，我们可以在汇编语言里辨别每一个函数。

## 第5章 栈

栈是计算机科学里最重要且基础的数据结构之一。[1]

从技术上说，栈就是CPU寄存器里的某个指针所指向的一片内存区域。这里所说的“某个指针”通常指x86平台的ESP/x64平台的ESP寄存器/RSP寄存器，以及ARM平台的SP寄存器。

操作的最常见的指令是PUSH和POP，在x86和ARM Thumb模式的指令里都有两条指令。PUSH指令会对ESP/RSP/SP寄存器的值进行减法运算，使得减4（32位）或8（64位），然后将操作数上述寄存器的指针指向的内存中。

POP指令是PUSH指令的逆操作，从栈指针（Stack Pointer，三个寄存器之一）的内存中读取，用操作（通常是写到其他寄存器），然后将指针的值增加4或8。

在分配的空间中，找指针，即Stack Pointer指向的地址就是栈的底部。PUSH会减少指针的值，而POP会增加指针的值。栈的“底”并不是整个栈的最低地址，而是整个栈的初始地址。虽然听起来很奇怪，但是确实如此。

虽然x86/x64的栈已经很好理解了，但是ARM的栈更为复杂的。ARM的栈分为增栈和减栈。减栈（descending stack）的起始地址就是栈的最高处，向低地址增长，指针的值随栈的增长而减少，如STMFD/LMFD、STMED/LDMED等指令都是减栈的操作。ARM的增栈（ascending stack）的起始地址则是栈的最低地址，向高地址增长，指针的值随增长而增加，如STMFA/LMFA、STMEA/LDMEA等指令都是增栈的操作指令。[2]

### 5.1 为什么栈会增长

许多人想象中的“增长”，是从低位置向高位置增长，似乎这样才能符合自然规律。然而研究过的人知道，多数的是逆增长的，它会从高地址向低地址增长。

这多数还归因于历史原因。当计算机小型化的时候，它还有几十房间那么大。在那个时候，内存分为两个部分，即“堆/heap”和“栈/stack”。当然，在程序执行过程中，堆和栈到底增长到什么程度不好说，所以人们把它们分为：

| --- | --- |

### 5.2.4 x86:alloc() 函数

alloc()函数特殊。大来说，alloc()函数直接分配内存，它与malloc()函数没有的区别。函数尾声的代码会将数据还原为函数之前的状态，直接释放由alloc()分配的内存。所以，程序不需要使用free()函数来释放这个函数申请的内存。alloc()函数的实现至关重要。简单来说，这个函数将所需的大小向后调整ESP的值，此时ESP成了新的数据的指针。我们一起来做一个测试：

```
#ifdef _GNUC
#include <alloca.h> // GCC
#else
#include <malloc.h> // MSVC
#endif
#include <stdio.h>

void f() {
    char *buf = (char*)alloc(600);
    #ifdef _GNUC
    snprintf(buf, 600, "hi! %d, %d, %d\n", 1, 2, 3); // GCC
    #else
    snprintf(buf, 600, "hi! %d, %d, %d\n", 1, 2, 3); // MSVC
    #endif

    puts(buf);
}
```

snprintf()函数和printf()的功能差不多。printf()将输出结果输出到stdout（也就是terminal或console类的设备上），而snprintf()则将结果输出到buf数组（人工设定的缓冲区），我们需要通过puts()函数将buf的内容输出到stdout。当然，printf()函数就足够完成snprintf()和puts()两个函数的功能。本文演示缓冲区的用法，所以要把拆分为两个函数。

从技术上说，栈就是CPU寄存器里的某个指针所指向的一片内存区域。这里所说的“某个指针”通常指x86平台的ESP/x64平台的ESP寄存器/RSP寄存器，以及ARM平台的SP寄存器。

操作的最常见的指令是PUSH和POP，在x86和ARM Thumb模式的指令里都有两条指令。PUSH指令会对ESP/RSP/SP寄存器的值进行减法运算，使得减4（32位）或8（64位），然后将操作数上述寄存器的指针指向的内存中。

POP指令是PUSH指令的逆操作，从栈指针（Stack Pointer，三个寄存器之一）的内存中读取，用操作（通常是写到其他寄存器），然后将指针的值增加4或8。

在分配的空间中，找指针，即Stack Pointer指向的地址就是栈的底部。PUSH会减少指针的值，而POP会增加指针的值。栈的“底”并不是整个栈的最低地址，而是整个栈的初始地址。虽然听起来很奇怪，但是确实如此。

虽然x86/x64的栈已经很好理解了，但是ARM的栈更为复杂的。ARM的栈分为增栈和减栈。减栈（descending stack）的起始地址就是栈的最高处，向低地址增长，指针的值随栈的增长而减少，如STMFD/LMFD、STMED/LDMED等指令都是减栈的操作。ARM的增栈（ascending stack）的起始地址则是栈的最低地址，向高地址增长，指针的值随增长而增加，如STMFA/LMFA、STMEA/LDMEA等指令都是增栈的操作指令。[2]

### 5.1 为什么栈会增长

许多人想象中的“增长”，是从低位置向高位置增长，似乎这样才能符合自然规律。然而研究过的人知道，多数的是逆增长的，它会从高地址向低地址增长。

这多数还归因于历史原因。当计算机小型化的时候，它还有几十房间那么大。在那个时候，内存分为两个部分，即“堆/heap”和“栈/stack”。当然，在程序执行过程中，堆和栈到底增长到什么程度不好说，所以人们把它们分为：

### 5.2.2 参数传递

无论是否优化选项，GCC 4.4的代码和MSVC相似，只是GCC发布任何警告。ARM程序也使用寄存器保存返回地址，只是不同。在4节中，看到ARM程序还要继续调用函数，就需要保存寄存器。通常在函数启动过程中（序言）保存LR寄存器的值。在函数尾声处看到“POP R4-R7”。这些指令会对使用的寄存器进行保护，把它们的值存放在栈中——当然了包括寄存器。

如果一个函数不调用其他函数，就像叶子那样。这种函数叫做“叶函数”。它的特点是保证LR寄存器的值。如果函数的代码用到几个寄存器，那么它可能根本不使用栈。这种情况下，函数不在外部中进行与栈的操作，所以它的运行速度可以超过x86系统。本书介绍了很多函数。请参阅8.2节、8.3节、15.2节、17.3节、19.4节。

### 5.2.3 存储局部变量

通过调整指针（stack pointer）的方法，函数可以在数据帧里分配一片局部变量。可见，无论函数声明了多少，都不影响分配的速度。虽然可以在外的任何地方存储局部变量，但是用数据存储局部变量已经是一种习惯。

### 5.2.4 x86:alloc() 函数

alloc()函数特殊。大来说，alloc()函数直接分配内存，它与malloc()函数没有的区别。函数尾声的代码会将数据还原为函数之前的状态，直接释放由alloc()分配的内存。所以，程序不需要使用free()函数来释放这个函数申请的内存。alloc()函数的实现至关重要。简单来说，这个函数将所需的大小向后调整ESP的值，此时ESP成了新的指针。我们一起来做一个测试：

```
#ifdef _GNUC
#include <alloca.h> // GCC
#else
#include <malloc.h> // MSVC
#endif
#include <stdio.h>

void f() {
    char *buf = (char*)alloc(600);
    #ifdef _GNUC
    snprintf(buf, 600, "hi! %d, %d, %d\n", 1, 2, 3); // GCC
    #else
    snprintf(buf, 600, "hi! %d, %d, %d\n", 1, 2, 3); // MSVC
    #endif

    puts(buf);
}
```

snprintf()函数和printf()函数的功能差不多。printf()将输出结果输出到stdout（也就是terminal或console类的设备上），而snprintf()则将结果输出到buf数组（人工设定的缓冲区），我们需要通过puts()函数将buf的内容输出到stdout。当然，printf()函数就足够完成snprintf()和puts()两个函数的功能。本文演示缓冲区的用法，所以要把拆分为两个函数。
