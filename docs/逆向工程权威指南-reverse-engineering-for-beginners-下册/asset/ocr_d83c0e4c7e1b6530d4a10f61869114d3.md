```

```

32ARM的指令集里没有NEG(负)指令，因此编译器分配了第31行的“反向减法”指令。第29行指令——CMP的比较结果为“不相等”时，才会执行第31行的条件指令（我们可以看到NE后，也就是“运行条件为”Not Equal!的意思）。而且，RSBNE指令用0减去上一步的计算结果。这条指令就是减法减法指令，只是被减数和减数的操作数位置对调了一下。用0减去任意数，实际的效果就是对该减数取反。实现的结果可以用这个来表示：0-x=-x。

Thumb程序的运算模式几乎完全相同。在编译ARM64程序的应用程序时，GCC 4.9能够NEG(取反)指令。
