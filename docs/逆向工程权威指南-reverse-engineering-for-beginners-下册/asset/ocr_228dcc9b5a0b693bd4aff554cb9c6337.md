让我们来看一个稍微复杂的例子：斐波那契数列，简称为
Fibonacci，其其前面已经提到过了。在这里我们看看如何用程序实现
它。

```
public class Fibonacci {
    public static void main(String[] args) {
        int limit = 20, f = 0, g = 1;

        for (int i = 1; i <= limit; i++) {
            f = f + g;
            g = f - g;
            System.out.println(f);
        }
    }
}
```
