# 59.1 魔数

很多魔数在文件中使用特定的魔数来表示文件格式，这些魔数可以是一个字符或者多个字节的组合
(https://en.wikipedia.org/Magic_number_(programming

。
我们熟知的，所有的Win32以及MS-DOS格式的可执行文件的开头处都是“MZ”这两个字符。

在标准的MIDI文件必须以“MThd”这4个字符开头。因此，某些需要使用MIDI文件的程序，基本上都会检测目标文件的头4个字符不是“MThd”。如果程序用来表示，可能是下面这样的：（注：buf是内存区的起始地址）

```
cmp [buf], 0x6468544D ; "MThd"
nz_error_not_a_MIDI_FILE
```

当，数据比较函数同样可以用来验证文件头中的魔数。常用的函数有：比较内存的memcmp（函数），或者CMPSB一类的比较指令（可以参考本书附录A. 6. 3）。

一旦某程序开始检测其他文件的魔数标识，我们就可以确定它已经加载了某种类型的目标文件。不仅如此，我们还可以解读文件操作的缓冲区以及它使用缓冲区的方法等信息。
