puts()函数，完全没有使用常规的函数调用指令JAL(Jump And Link)。有详细介绍，请参阅LW13.1.1。

另外，参数LW指令之后有一条NOP指令。这种指令组合叫做“加载延迟 slot”；是MIPS平台的另一种延迟。在LW指令从内存加载数据的时候，下面的指令可以和它并发执行。这样一来，LW后面的那条指令就无法使用LW读取的数据了。当今主流的MIPS CPU都对这一问题进行了优化，在后一条指令使用LW数据的情况下能够进行自动处理。虽然现在的MIPS处理器不再加载延迟时，但是GCC还是为了保险地添加延迟槽。所以，我们已经可以忽视这种加载延迟了。

# 13.1 总结

在case存在较少的情况下，case()语句和if/else语句的编译结果基本相同。指令清单13.1可以充分阐述这个结论了。

# 13.2 case 描述式较多的情况

在switch()语句在大量分支的情况下，编译器就不能直接套用大量JE/JNE指令了。否则程序代码会非常庞大。

```
#include <stdio.h>

void f (int a)
{
    switch (a)
    {
        case 0: printf("zero\n"); break;
        case 1: printf("one\n"); break;
        case 2: printf("two\n"); break;
        case 3: printf("three\n"); break;
        case 4: printf("four\n"); break;
        default: printf("something unknown\n"); break;
    }
}

int main()
{
    f(2); // test
}

```
