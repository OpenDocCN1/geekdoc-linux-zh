# 25.2 SIMD实现strlen()

根据msdn(http://msdn.microsoft.com/en-us/library/y0dh78(VS.80)).aspx

)，在C/C++程序中插入特定的宏即可调用SIMD指令。在MSVC编译器的库文件之中，intrins.h文件就使用了这种宏。

我们可以把字符串分段处理，使用SIMD指令实现strlen()函数。这种算法比常规实现法快2~2.5倍。它每次把16个字符加载到1个XMM寄存器里，然后检测标记位为零的结束符。
[5]

```
size_t strlen_sse2(const char *str)
{
    register size_t len = 0;
    const char *s=str;
    bool str_is_aligned=((unsigned int)str) &0xFFFFFFF0 ==
(unsigned int)str);

    if (str_is_aligned==false)
        return strlen(str);

    m128i xmm0 = _mm_setzero_si128();
    m128i xmm1;
    int mask = 0;

    for (;)
        xmm1 = _mm_load_si128((m128i *)s);
        xmm1 = _mm_cmpeqi_epi8(xmm1, xmm0);
        if ((mask = _mm_movemask_epi8(xmm1)) != 0)
{
            unsigned long pos;
            BitScanForward(&pos, mask);
            len += (size_t)pos;
            break;
        }
        s += sizeof(_m128i);
    len += sizeof(_m128i);
}
```
