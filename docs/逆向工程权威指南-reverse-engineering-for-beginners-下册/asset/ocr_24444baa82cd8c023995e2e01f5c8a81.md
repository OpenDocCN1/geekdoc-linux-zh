在ARM系统的Thumb模式指令集里，只有Thumb指令才有产生出来的条件执行指令。所以Thumb模式下的汇编指令看起来像是贴近86指令。

上述指令，条件转移指令有BLE (Less than Equal)、BNE (Not Equal)、BGE (Greater than Equal)。这些指令都可以用文语义表示。

f_unsigned函数非常简单，只是里面出现了新的条件转移指令
BLS (Unsigned Lower or Same)和BCS (Carry Set (Greater than or equal)).

# 指令清单12.9 f_signed()

```
f_signed:
; W0=a, W1=b
   cmp    w0, wl
   bgt    .L19 ; Branch if Greater Than (a>b)
   beq    .L20 ; Branch if Equal (a==b)
   bge    .L15 ; Branch if Greater than Equal (a>=b)
```
