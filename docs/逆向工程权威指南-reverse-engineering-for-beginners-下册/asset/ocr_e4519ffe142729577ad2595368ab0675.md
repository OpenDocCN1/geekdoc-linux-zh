```
; loaded byte is LF? jump to exit if its not LF':
bne $a0, $a3, exit
nor $at, $zero ; branch delay slot, NOP
loc_7C:
; loaded byte is CR at this moment
    ; jump to loc_5c (loop body) if str_len (in $v0) is not
zero:
    bnez $v0, loc_5C
    simultaneously, store $zero at that place in memory:
    sb $zero, 0($al) ; branch delay slot
; "exit" label was named by me manually:
exit:
    lw $ra, 0x20+saved_RA($sp)
    move $v0, $s0
    lw $s0, 0x20+saved_S0($sp)
    jr $ra
    addiu $sp, 0x20 ; branch delay slot
```

S-头的寄存器就是保存寄存器（saved temporaries）。在调用过程中，保存寄存器的值需要保留（被调用函数保存和恢复），因此$S0的值保存在局部帧里，在完成任务后恢复其初始状态。
