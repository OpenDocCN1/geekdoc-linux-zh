对于std::map数据结构，和std::list的相同之处是，迭代器指向节点的std::list的一个数据元素。而std::set的每个节点只有1个值。

5.4节介绍，MSVC迭代器在构造std::list的时候会包含链表的长度信息。我们可以在源码中看到它存储了这种数据的具体实现。

这两种数据结构和std::list的相同之处是，迭代器指向节点的指针。begin()迭代函数指向节点的键。实际上，整个数据结构都没有最小键的指针（链表的情况每当程序调用这个迭代器的时候，它就会遍历所有键、查找最小值）。单向运算符operator--和单向运算符operator++可以将指向节点的前一个或后一个节点。MIT出版社版的Introduction to Algorithms, Third Edition》(Thomas H. Cormen等著者）引入了这两个算法方法。

迭代器，end()指向了一个隐藏的节点。如果Isnil为1，就是说它没有对应的关键字（key）或值（value）、不是真正的数据节点，仅仅是一个存储控制信息的容器。这个节点的父节点是真正的根节点的指针，就是整个节点树的顶端。

    traverse, bool dump_keys_and_values)
{
    printf("0x%p M_left=0x%p M_parent=0x%p M_right=0x%p M_color=%d\n",
        n, n->M_left, n->M_parent, n->M_right, n->M_color);

    void *point_after_struct=((char*)n)+sizeof(struct tree_node);
    if (is_set)
    {
        printf("key=%d\n", (int*)point_after_struct);
    }
    else
    {
        struct map_pair *p=(struct map_pair*)point_after_struct;
        printf("key=%d, value=%s]\n", p->key, p->value);
    }
    if (traverse==false)
        return;
    if (n->M_left)

    if (n->M_right)

}
