MIPS 处理器没有标识寄存器。这种平台的加减运算完全不存在存储/进位信息。它的指令集里也没有x86指令集里的那种ADC或SBB指令。当需要存储/进位信息时，编译器通常使用SLTU指令有关位信息（就是0或1）存储在既有寄存器里，继而在下一步的高数位运算中纳入借进位信息。

# 24.3 乘法除法运算

#include <stdint.h>

    return a*b;
}

{
    return a/b;
}

uint64_t f_rem (uint64_t a, uint64_t b)

    return a % b;
