# 第15章 C语言字符串的函数

# 15.1  strlen()

本章是循环控制语句的具体应用。通常，strlen 函数由循环语句 while() 语句实现。参照MSVC标准库对strlen()函数的定义方法，我们讨论上述的程序:

```
int my_strlen (const char * str)
{
    const char *eos = str;
    while(*eos++ );
    return(eos - str - 1);
}
```

```
int main()
{
    // test
    return my_strlen("hello!");
}
```

# 15.1.1  x86

使用MSVC 2010编译上述程序可得到:

```
_eos = -4          ; size = 4
_str$ = 8          ; size = 4
_strlen PROC
    push    ebp
    mov     ebp, esp
    push    ecx
    mov     eax, DWORD PTR _str$[ebp]; 将指针指向字符串
```
