# 6.5 其他

在x86、x64、ARM和MIPS平台上，程序函数参数的方法各不相同。这种差异性表明，函数传递参数的方法与CPU的关系并不是那么密切。如果足够努力，人们甚至可以开发出一个能够根据数据即可传递参数的超级编译器。

为了方便记忆，在采用调用约定时，MIPS的4号~7号寄存器也叫作A0-$A7寄存器。实际上，程序员完全可以使用$ZERO之外的其他寄存器传递数据，也可以采取其他的函数调用约定。

CPU完全不顺序中使用任何种调用约定。

汇编语言的编写者完全可以采取五花八的方法来传递参数。虽然他们基本都是利用寄存器传递参数，但是传递参数的顺序将不那么讲究，甚至可以通过全局变量传递参数。不过，这样的程序也能运行。

+   [1] calling convention，又有“调用约定”“调用协定”等译法。
