# 19.2.5 ARM: BIC指令详解

把本章开头的源代码加修改：

```
int f(int a)
{
int rt=a;
REMOVE_BIT(rt, 0x1234);
return rt;\}
```

用Keil 5进行优化编译[3]，可获得ARM模式的指令如下：

```
PROC
BIC r0,r0,#0x1000
BIC r0,r0,#0x234
BX lr
ENDP
```

上述程序使用了两条BIC指令，即它需要通过两次处理才能清除0x1234对应的位图。这是因为立即数0x1234无法和和BIC指令封装在同一条指令里。所以通过编译器执行了等效处理，通过两次指令实现清空0x1000和0x234对应的比特位。

# 19.2.6 ARM64: Optimizing GCC (Linaro) 4.9

方向ARM64的GCC编译器，可以直接使用AND指令、而不用BIC指令。

> 指令19.18 Optimizing GCC (Linaro) 4.9

```
add w0, w0, -513 ; 0xFFFFFFFFFF
orr w0, w0, 16384 ; 0x4000
ret
```

# 19.2.7 ARM64: Non-optimizing GCC (Linaro) 4.9

关闭优化选项后，GCC生成的代码中会无用指令，但是功能相同。

> 指令19.19 Non-optimizing GCC (Linaro) 4.9

```
sub sp, sp, #32
str w0, [sp,12]
ldr w0, [sp,12]
str w0, [sp,28]
```
