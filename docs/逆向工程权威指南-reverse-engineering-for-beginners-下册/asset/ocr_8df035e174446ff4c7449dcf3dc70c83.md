# 用随机函数的第三传参代码：

```
.text:0002B25 mov [ebp+var_C], eax
.text:0002B28 mov eax, dword_40C040 ; 10
here
.text:0002B2D push eax
.text:0002B2E call random
.text:0002B33 add esp, 4
```

```
.text:0002BBB mov eax, dword_40C058 ; 5
here
.text:0002BC0 push eax
.text:0002BC1 call random
.text:0002BC6 add esp, 4
.text:0002BC9 inc eax
```

综合上述代码，我们可以判定该函数至少有一个参数。前两次传递的参数是10，第三次传递的参数是5。在观察游戏的界面上，可知棋盘是10×10的方形，彩彩的颜色共有5种。此处调用random的指令，必须是坐标和颜色的生成。标准的随机函数rand()函数会生成一个0~7FFF的整数，用起来并不方便。实际上，编程人员会写自己的随机数以获取区间内的随机返回值。本例需要的随机数是0~(n-1)的整数，n就是函数所需的唯一的随机数。这一个假设可由任意一个debugger验证。

本章将修改第三次调用指令，让它的第三次返回永远是0。为了，我们可以PUSH/CALL/ADD这三条指令改为NOP，然后添加XOR EAX,EAX指令，以清空寄存器。

```
.0002ABB: 83C410 add esp,010
.0002BBB: A158C0400 mov eax, [0004C058]
.0002BC0: 31C0 eax, eax
.0002BC2: 90 nop
.0002BC3: 90 nop
.0002BC4: 90 nop
.0002BC5: 90 nop
.0002BC6: 90 nop
.0002BC7: 90 nop
.0002BC8: 90 nop
.0002BC9: 40 inc eax, [ebp] [-8]
.0002BCA: 8B4DF8 mov ecx, [ecx][ecx]*2
.0002BCD: 8D0C49 lea ecx
.0002BD0: 8B15F4D54000 mov [0004D5F4]
```
