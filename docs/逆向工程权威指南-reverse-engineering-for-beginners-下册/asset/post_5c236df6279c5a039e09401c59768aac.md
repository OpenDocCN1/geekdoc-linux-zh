本机被调用函数返回的是结构体类型，不是结构体的指针。对于ARM利用寄存器传递函数的前4个参数，所以编译器R0~R3寄存器将printf(d)函数的全部参数。

注意，在函数退出时，它借用了另一个函数名！这种借助B指令跳转到此处完全不是相同的函数现象，应当是因为两个函数的局部栈使用了相同的空空间。或许由于这两个函数在启动时的对齐内存（相同部分排列了7~5-0x14的数据域），导致退出语句也完全相同缘故，再加上它们内部存储的地址的因素，所以编译器进行了这种处理。确实，使用一个退出不会影响程序的功能。这明显是Keil编译器对于结束因素而进行的指令复用。JMP指令只占2个字符，而标准的尾要占用4个字节。

## 21.4 其他

传递结构体时（不是结构体的指针）的过程相当于依次传递结构体的字段。也就是说，如果结构体字段不变，那么f()函数的源代码改写为：

```
void f(char a, int b, char c, int d) {
    printf("a=%d; b=%d; c=%d; d=%d\n", a, b, c, d);
}
```
经过上述动后，编译器生成的顺序完全不会变化。

## 21.5 结构体的嵌套

另一个结构体的情况：

```
#include <stdio.h>
struct inner_struct {
    int a;
    int b;
}

struct outer_struct {
    char a;
    int b;
    struct inner_struct c;
    char d;
    int e;
}
void f(struct outer_struct s) {
    printf("a=%d; b=%d; c=%d; d=%d; e=%d\n", s.a, s.b, s.c.a, s.c.b, s.e);

int main() {

    s.a=1;

    s.e=4;
