```
public static int min (int a, int b)
{
    if (a>b)
        return b;
    return a;
}
```

这个函数的字节码如下所示:

```
public static int min(int, int);
flags: ACC_PUBLIC, ACC_STATIC Code:
stack=2, locals=2, args_size=2
0: iload_0
1: iload_1
2: if_icmple      7
5: iload_1
6: return
7: iload_0
8: return
```

if_icmple(pop)两个操作从栈中提取数值并将将其进行比较。如果第二个操作数小于等于第一个操作数，那么它将跳转到偏移量为7的指令，否则继续执行一条指令。

若对上述程序进行调整，通过极大值函数max()进行进行比较:

```
public static int max (int a, int b)
{
    if (a>b)
        return a;
    return b;
}
```

那么字节码会变为:

```
public static int max(int, int);
flags: ACC_PUBLIC, ACC_STATIC Code:
stack=2, locals=2, args_size=2
0: iload_0
1: iload_1
2: if_icmple      7
5: iload_0
6: return
7: iload_1
8: return
```

其实与刚才才较小值的程序基本相同，但是最后两个iload指令（在偏移量为5和7的位置上）位置替换了一次。
