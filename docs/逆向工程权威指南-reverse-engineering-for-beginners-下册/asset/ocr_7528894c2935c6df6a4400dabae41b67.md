所有字段都是无法被函数直接访问的私有变量。但是，既然我们知道了这个对象的内存存储布局，却不能写出一个修改这些变量的程序呢？

为此，我们可以构造一个名为hack_oop_encapsulation()的函数。如果不调整的话，直接访问既定的源程序就会：

```
void hack_oop_encapsulation(class box * o) {
    o->width=1; // that code cant be compiled'
    // "error C2248: 'box:width': cannot access private member declared in class 'box'"
}
```

当然，上述代码不可能被成功编译出来。然而，要把box的数据类型强制转换为整数数组的，我们就可以通过编译并且直接修改相应字段。

```
void hack_oop_encapsulation(class box * o) {
    unsigned int *ptr_to_object=reinterpret_cast<unsigned int*>(o);
    ptr_to_object[1]=123;
}
```

上述函数的功能十分简单：它将输入数据视为整数数组，然后将数组的第二个元素、一个整数int值修改为123。

```
?hack_oop_encapsulation@YAXPAVbox@@Z PROC ;
hack_oop_encapsulation:
    mov eax, DWORD PTR _$[esp-4]
    mov DWORD PTR [eax+4], 123
    ret 0
hack_oop_encapsulation@YAXPAVbox@@Z END ;
hack_oop_encapsulation
```

接下来，我们验证一下它的功能。

```
int main() {
    box b(1, 10, 20, 30);

    b.dump();
}
```
