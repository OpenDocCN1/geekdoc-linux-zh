(例如两条FMOV指令)。这可能是GCC 4.9在ARM64程序方面有所不足的。

值得注意的是，ARM64本身具有64位寄存器，而双字寄存器同样是64位寄存器。所以编译器可以用通用寄存器GPR直接存储双精度浮点数，而不必使用本地查找存储这种数据。毫无疑问，在32位CPU上，编译器无法使用这种寄存器方案。

建议读者对这个程序进行练习，在不使用FMADD类似的新指令的情况下，手动优化此函数。

# 17.5.6 MIPS

MIPS平台支持多个（4个以及）协作处理器。第0个处理器专门用于其他的协作处理器，第1个协作处理器是FPU。

与ARM的处理器的情况相似，MIPS的处理器不是堆栈机（stack machine），而是32位寄存器（$F0~$F31）。有关FPU各寄存器的介绍，请参见附录C1.2节。在处理64位双精度浮点数时，必须一对32位字

指令清单17.6 Optimizing GCC 4.4.5 (IDA)

```
:
; $f12-$f13=A
; $f14-$f15=B
; load 32-bit part of 3.14 constant to $f0:
lui v0, (dword_C4) >> 16 ; ? =
wlcl $f0, dword BC
or $at, $zero ; load delay slot, NOP
; load high 32-bit part of 3.14 constant to $f1:
wcl $f1, $lc0
lui $v0, ($LC1) >> 16 ; ?
; A in $f12-$f13, 3.14 constant in $f0-$f3, division:
div.d $f0, $f12, $f0
; $f0-$f11=A/3.14
; load 32-bit part of 4.1 to $f2:
wcl $f2, dword_C4
or $at, $zero ; load delay slot, NOP
; load high 32-bit part of 4.1 to $f3:
wcl $f3, $lc1
or $at, $zero ; load delay slot, NOP
; B in $f14-$f15, 4.1 constant in $f2-$f3, for multiplication:
mul.d $f2, $f14, $f2
; $f2-$f3=B*4.1
jjr $ra
; sum 64-bit parts and leave result in $f0-$f1:
add.d $f0, $f2 ; branch delay slot, NOP
```
