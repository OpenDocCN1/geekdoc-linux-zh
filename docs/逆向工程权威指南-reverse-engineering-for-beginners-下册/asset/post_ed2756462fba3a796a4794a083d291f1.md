
## 第75章 修改彩球游戏

彩球游戏有多个衍生版本。本章采用的是1997年发布的BallTrix版。这款程序可以从http://go.yurichev.com/17311 公开下载。它的图形界面如图75.1所示。

本章关注的随机生成器，以及修改这个组件的具体方法。IDA在ballrix.exe里识别出了标准函数_rand。这个函数的地址是0x00403DA0。不仅如此，IDA判断该函数会被此一处调用。

为了讨论，我们把_rand函数的调用函数叫作“random”。在程序里有三处的代码调用了random函数。

### 调用rand函数的前两个处代码:

```
.text:00402B16 mov eax, dword_40C03C ; 10 here
.text:00402B1B push eax
.text:00402B1C call random
.text:00402B21 add esp, 4
.text:00402B24 inc eax
```

### 用随机函数的第三传参代码：

```
.text:0002B25 mov [ebp+var_C], eax
.text:0002B28 mov eax, dword_40C040 ; 10 here
.text:0002B2D push eax
.text:0002B2E call random
.text:0002B33 add esp, 4
```

```
.text:0002BBB mov eax, dword_40C058 ; 5 here
.text:0002BC0 push eax
.text:0002BC1 call random
.text:0002BC6 add esp, 4
.text:0002BC9 inc eax
```

综合上述代码，我们可以判定该函数至少有一个参数。前两次传递的参数是10，第三次传递的参数是5。在观察游戏的界面上，可知棋盘是10×10的方形，彩球的颜色共有5种。此处调用random的指令，必须是坐标和颜色的生成。标准的随机函数rand()函数会生成一个0~7FFF的整数，用起来并不方便。实际上，编程人员会写自己的随机数以获取区间内的随机返回值。本例需要的随机数是0~(n-1)的整数，n就是函数所需的唯一的随机数。这一个假设可由任意一个debugger验证。

本章将修改第三次调用指令，让它的第三次返回永远是0。为了，我们可以PUSH/CALL/ADD这三条指令改为NOP，然后添加XOR EAX,EAX指令，以清空寄存器。

```
.0002ABB: 83C410 add esp,010
.0002BBB: A158C0400 mov eax, [0004C058]
.0002BC0: 31C0 eax, eax
.0002BC2: 90 nop
.0002BC3: 90 nop
.0002BC4: 90 nop
.0002BC5: 90 nop
.0002BC6: 90 nop
.0002BC7: 90 nop
.0002BC8: 90 nop
.0002BC9: 40 inc eax, [ebp] [-8]
.0002BCA: 8B4DF8 mov ecx, [ecx][ecx]*2
.0002BCD: 8D0C49 lea ecx
.0002BD0: 8B15F4D54000 mov [0004D5F4]
```

也就是我们修改调用random()函数的有关指令，让它的返回固定为0。

不得不说我们修改得很成功。在当初修改这个游戏的时候，希望我的同事明白“没有必要执于你肯定会赢的游戏”。可惜我的劝阻没成功。

另外还有一个问题：为什么random()函数的参数会全局变量？这是因为棋盘大小是可以调整的变量，不能在程序里把它写成常量。本例中的5和10只是它的默认值。

## 第76章 扫描（Windows XP）

我的扫描水平不高，所以打算用debugger把地雷都显示出来吧！

因为地雷的具体位置是随机的，所以扫描程序肯定会用随机函数安置地雷。这种随机函数不是某种自制的随机数生成函数，就是标准的C函数rand()。最美妙的事情是，微软不仅公开了其产品的PDB文件，而且在PDB文件中提供了全部的函数等符号信息。所以，当我们用IDA打开mine.exe时，它会从微软PDB文件显示所有函数名称。在IDA里可以看到，rand()函数的指令只有一处：

```
.text:01003940 ; call Rnd(x)
.text:01003940 _Rnd@4 proc near ; CODE
XREF: StartGame()+53
.text:01003940 StartGame()+61 ;
.text:01003940 arg_0 = mov dptr 4
.text:01003940 call ds:_rand
.text:01003946 cdq
.text:01003947 iv [esp+arg_0]
.text:0100394A mov eax, edx
.text:0100394B 4
.text:0100394D retn
.text:010039D _Rnd@4 endp
```

IDA把这个函数显示为rnd。这个函数非常简单：

```
int Rnd(int limit) {
    return rand() % limit;
}
```

可见，Rand()函数的返回值是0~limit之间的整数。StartGame()也是安置地雷的函数：

```
.text:010036C7 push xBox
.text:010036CD call Rnd(x)
.text:010036D2 push yBox
.text:010036D8 mov esi, ax
.text:010036DA inc esi
.text:010036DB call Rnd(x)
.text:010036E0 mov ecx, ax
.text:010036E1 shl ecx, 5 ; EAX=32
.text:010036E6 test rgBlk[ecx+esi], esi
.text:010036EE jnz loc_EE
.text:010036F0 shl ax, 5 ; EAX=32
.text:010036F3 lea rgBlk[esi]
.text:010036FA or byte [ax], 0
.text:010036FD dec BombStart
short loc_C7
```

因为在设置坐标之前，如果坐标已经设置了地雷，那么JNZ指令将再次生成一次坐标。BombStart不是全局变量，是循环控制变量：X(xBox)和Y(yBox)都是全局变量。棋盘宽度是32：
