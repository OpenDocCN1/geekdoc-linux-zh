如图87.4中的红线所示，这些数据宽度可以直接观察出来。在导
出数据时，我发现这些16位数据就是每个信息块里最后一个错误信息的
错误编码。

可见，Oracle RDBMS通过这部分数据进行快速检索的过程如下:

+   - 根据错误编码找到对应的信息块。此处假设每个信息块中的信息以错误代
码的增序排列。

+   - 加载对应的信息块。

+   - 逐一查找索引节的索引信息。

+   - 通过当前6字节数据找到对应字符串的第一个字符的位置。

+   - 通过下一个6字节数据找到最后一个字符的位置。

+   - 加载该区域内的全部字符。
