# 第11章 GOTO语句

人们普遍认为使用GOTO语句将破坏代码的结构化构造[1]。即使如此，某些情况下下我们还必须使用这种结构语句[2]。

本章围绕以下程序进行说明：

```
#include <stdio.h>

int main()
{
    printf("begin\n");
    goto exit;
    printf("skip me!\n");
exit:
    printf("end\n");
}
```

使用MSVC 2012编译上述程序，可得到如下所示的指令：

| 指令清单11.1 MSVC 2012 |
| --- | --- |
| $SG2934 | 'begin', 0AH, 00H |
| $SG2936 | 'skip me!', 0AH, 00H |
| $SG2937 | 'end', 0AH, 00H |

```
_main
    push    ebp
mov     ebp, esp
    push    OFFSET $SG2934 ; 'begin'
    call    _printf
    add     esp, 4
    jmp     SHORT OFFSET $exit$ ; 'skip me!'
    push    ebp
    call    _printf
    add     esp, 4
$exit$3:
```
