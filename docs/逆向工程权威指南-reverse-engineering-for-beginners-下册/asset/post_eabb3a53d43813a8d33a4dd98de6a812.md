## 13.4 Fallthrough

Switch()语言还有一种方法—fall through.

```c
#define R 1
#define W 2
#define RW 3

void f(int type) {
    int read=0, write=0;
    switch (type) {
        case RW:
            read=1;
            break;
        case W:
            write=1;
            break;
        case R:
            read=1;
            break;
        default:
            break;
    }
    printf("read=%d,write=%d\n", read, write);
}
```

如果type为1（参见第一行可知，R为真的），则read的值设置为1；如果type为2(W)，则write设置为1；如果type为3(RW)，则read和write的值设置为1。无论type的值是RW还是W，都会执行第4行的指令。type为RW的语句里没有break，从而利用switch语句的fall效应。

## 13.4.1 MSVC指令列表

```assembly
# $1305      'read=%d, write=%d', 0H

_write = -12      ; size= 4
_read = -8       ; size= 4
_tv64 = -4       ; size= 4
_type = 8       ; size= 4
_f PROC
    push ebp
    mov ebp, esp
    sub esp, 12
    mov DWORD PTR _read$[ebp], 0
    mov DWORD PTR _write$[ebp], eax
    mov eax, DWORD PTR _type$[ebp]
    mov DWORD PTR tv64[ebp], eax
    cmp DWORD tv64[ebp], 1 ; R
    je SHORT LN2@
    cmp DWORD tv64[ebp], 2 ; W
    je SHORT LN3@
    cmp DWORD tv64[ebp], 3 ; RW
    je SHORT LN4@
LN4f: case RW:
    mov DWORD PTR _read$[ebp], 1
LN3f: case W:
    mov DWORD PTR _write$[ebp], 1
    jmp SHORT LN5@
LN2f: case R:
    mov DWORD PTR _read$[ebp], 1
LN5f: default:
    mov ecx, DWORD PTR _write$[ebp]
    push ecx
    mov edx, DWORD PTR _read$[ebp]
    push edx
    call _1305 ; printf
    add esp, 12
    mov ebp, esp
    pop ebp
    ret
_f ENDP
```

上述汇编指令与C代码几乎一一对应。在LN4和LN3之间没有转移指令，所以程序执行了LN4处的“赋值为1”指令后，就会执行后面（fall落）这个名字：当执行前面那个语句（read赋值）之后，继续下一个语句（write赋值）。如果type为W，程序将执行LN3的指令。

# 第14章 循环

## 14.1举例说明

### 14.1.1 x86

x86指令集有一条专门的LOOP指令。LOOP指令检测寄存器的值是否是0，如果它不是0将继续递减，并将操作权交给操作符指定的标签处（即跳转）。或者是因为循环指令由于过于复杂的缘，我尚未见过直接使用LOOP指令将循环语句翻译成循环语句的编译器。所以，如果哪个程序直接使用LOOP指令进行循环控制，它可能就是手写的汇编程序。

C/C++语言的循环控制语句主要为for(),while(),do/while()语句。我们从for()语句开始演示。

for()语句定义了循环的初始状态（计数器的初始值）、循环条件（在变量满足等等条件下继续循环）以及循环控制（每次循环后对变量进行计数操作，通常是递增或递减）。虽然这种语句也必须声明循环体，每次循环时要实现什么操作。然而，for()语句的使用方法是：

```
for (初始化; 循环条件; 循环控制)
{
  循环体;
}
```

根据for()语句所代表的各种功能，编译器会将for()语句翻译为4个相应的功能体。我们一起来编写下面的程序：

```c
#include <stdio.h>

void printing_function(int i)
{
    printf("%d\n", i);
}

int main()
{
    int i;
    for (i=2; i<10; i++)
        printing_function(i);
    return 0;
}
```
