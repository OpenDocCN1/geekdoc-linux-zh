# 题目2

对应章节：18.9.2节

答案：两个矩阵（一个是100x200矩阵，另一个是100x300）的乘法运算程序，生成一个100x300的矩阵。其源代码如下：

```
#define M 100
#define N 200
#define P 300
void m(double *a, double *b, double *c)
{
    for (int i=0;i<M;i++)
        for (int j=0;j<P;j++)
        {
            *(c+i*M+j)=0;
            for (int k=0;k<N;k++) *(c+i*M+j)+=(a+i*M+j) * *(b+i*M+j);
        }
}
```
