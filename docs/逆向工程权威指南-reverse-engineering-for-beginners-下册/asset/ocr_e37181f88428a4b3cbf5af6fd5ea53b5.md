# 19.6 本小节

与C/C++语言中的移位符<<>>相应，ARM指令中有无符号数数的SAR/SHL指令和操作有符号的SAR/SHL指令。

在ARM平台上，对无符号数移位运算的指令是LSR/LSL，对有符号数移位运算的指令是ASR/LSL。而且，ARM指令还可以通过“参数调节”的形式使用“后缀型”移位运算指令。这类对其他数字运算的指令，又叫做“数据处理指令”。
