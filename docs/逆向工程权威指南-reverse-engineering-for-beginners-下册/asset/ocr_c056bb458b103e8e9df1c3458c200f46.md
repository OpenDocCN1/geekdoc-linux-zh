在我们观察f_unsigned() 函数的汇编指令。f_unsigned()函数和
f_signed()函数相同。它们的区别集中体现在条件转移指令上：
f_unsigned()函数使用的条件转移指令是JBE和JAE，而f_signed()函数使\用的条件转移指令则是JBE和JGE。

使用GCC编译上述程序，可以得到f_unsigned()的汇编指令如下：

# 指令12.2 GCC

```
a$ = 8; size = 4
_$b = 12; size = 4
f_unsigned PROC
    push ebp
    mov ebp, esp
    mov eax, DWORD PTR _a$[ebp]
    cmp eax, DWORD PTR _b$[ebp]
    jbe SHORT LN30f_unsigned
    push OFFSET $SG2761      ;; 'a>b'
    call _printf
    add esp, 4
LN30f_unsigned:
    mov ecx, DWORD PTR _a$[ebp]
    cmp ecx, DWORD PTR _b$[ebp]
    jne SHORT LN28f_unsigned
    push OFFSET $SG2763      ;; 'a==b'
    call _printf
    add esp, 4
LN28f_unsigned:
    mov edx, DWORD PTR _a$[ebp]
    cmp edx, DWORD PTR _b$[ebp]
    jae SHORT LN4f_unsigned
    push OFFSET $SG2765      ;; 'a<b'
    call _printf
    add esp, 4
LN4f_unsigned:
    pop ebp
    ret 0
f_unsigned ENDP
```

GCC编译的结果和MSVC编译的结果基本相同。

GCC编译后，f_unsigned()函数使用的条件转移指令是JBE (Jump if
Below or Equal, 相当于JLE)和JAE (Jump if Above or Equal, 相当于
JGE)。JA/JAE/JBE/JG/GE/JL/JLE的区别，在于它们检查的标志位不
同：前者检查/进位标志位CF (1意味着无符号)和零标志位ZF (1意味着零相
等)，后者检查“SF OR OF” (1意味着异号)和ZF。从指令参数的角度
看，前者适用于unsigned（无符号）类型数据的(CMP)运算，而后者的适用于signed（有符号）类型数据的运算。
