# 第94章 8086的寻址方式

在MS-DOS和Win16（参见本书第73节和35.5节）平台的16位应用程序中，我们可以看到程序指针指向两个16位内存构成。这是什么情况？不得说是MS-DOS和8086的另一个怪异的特性。

虽然8086/8088属于16位CPU，但是它却有20位的RAM地址空间（内存总线有20个引脚），即它可以寻址的存储空间有1MB。这1MB的外部内存空间又被划分为最大640KB的ROM、显内存、EMS卡等等。

16位的8086/8088 CPU实际上发展而来的。8080 CPU的地址空间只有16位，所以可以控制的内存只有64KB。大概是8086的设计哲认为64KB空间不够用，而且8086还要兼容旧平台的程序，所以把1MB的内存划分成若干段使用。这就是早期玩具的虚拟内存的技术。8086的寄存器只有两个16位寄存器，为了进行更大范围（20位）的寻址，它就得借助新出的段寄存器。从此CPU就有CS、DS、ES和SS寄存器。20位的内存指针通过短寄存器和地址寄存器（DS:BX）来实现：

```
real_address = (segment_register << 4) + address_register
```

举例来说，通过PC兼容的主机，但是显卡（EGA、VGA）的显示都只有64KB。要写显存，就要在某个段寄存器里（例如DS）写入0xA000。如此一来，程序就可以DS:0~DS:FFFF访问整个显存。虽然地址总线是20位的，超过了16位寄存器的表达范围，但是PC可以借助段寄存器毫无无碍地访问0xA000~0FFFF。
