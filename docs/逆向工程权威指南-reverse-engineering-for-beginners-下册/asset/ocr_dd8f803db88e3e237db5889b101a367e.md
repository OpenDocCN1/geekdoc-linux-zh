递归函数看起来很方便而已。从技术上讲，递归函数在栈方面的开销过大，因性能不怎么理想。注重性能的应用程序，应当避免使用递归函数。

笔者曾经尝试写过一个递归二叉树、搜索特定结点的应用程序。把它写成递归函数的时候，整个程序确实清爽又有条理性。但是每次函数调用都要进行赋值、回调，这使得递归函数比其他类型的函数慢了许多倍。

另外，部分PL[3] 编译器对递归调用采取“尾部调用”的优化方法，以减轻堆栈的各种开销。

+   [2] 也就是自己调用自己。

+   [3] PL: Program Language (编程语言)。LISP、Python、Lua等编程语言的编译器能够进行尾部调用优化。详情请参阅https://en.wikipedia.org/wiki/Tail_call。
