25 ; copy 0 from $zero to $v0:
26 .text:00000026 move $v0, $zero
27 ; return by jumping to the RA:
28 .text:0000002c jr $ra
29 ; function epilogue addiu $sp, 0x20
30 .text:00000030

15行的指令使用局缓冲区保存GP的值。令人感到匪异所思的是，
G的汇编输出里看到这条指令，或许是GCC自身的问题[24]。严格
地说，此时有必要保存GP的值。毕竟每个每个函数都有自己的64KB数据
窗口。

程序保存puts()函数地址的寄存器叫做$t9寄存器。这类T-开头
的寄存器又叫做“临时”寄存器，用于保存代码里的临时值。调用者函
负责保存这些寄存器的数值（caller-saved），因为它可能会被
被调用的函数重写。
