```
#include <stdio.h>

// located in some other file
void modify_a (int *a);

void f (int a)
{
    modify_a (&a);
    printf("%d\n", a);
}
```

要是看了下面的汇编代码，我们还很难理解这段程序是如何运行的。

# 指令64.10 MSVC 2010的优化

```
$SG2796 DB '%d', 0AH, 00H

_a = 8
_f lea eax, DWORD PTR a[$esp-4] ; just get the address of value in local stack
push eax ; and pass it to
modify_a()
    call modify_a
    mov ecx, DWORD PTR _a[esp] ; reload it from the local stack
    push ecx ; and pass it to
print()
    push OFFSET $SG2796 ; '%d'
    call _printf
    add esp, 12
    ret
ENDP
```

变量a的地址通过栈传递了一个函数，然后这个地址又被传递给了另一个函数。第一个函数修改了变量a的值，而printf()函数获取了这个修改后的变量值。

细心的读者可能会问：使用直接通过寄存器传递参数的调用约定，又会是什么情况呢？

即便使用了这种约定，还会阴影空间（Shadow Space）的问题。传递的数值会被从寄存器保存到了本地帧的阴影空间
