# 指令清单43.10 32字节的操作

```
#include <stdio.h>
void f(char *out)
{
    memset(out, 0, 32);
};
```

在编译那些操作小内存内块的memset()函数时，多数编译器不会分配标准的函数调用用指令(call)，反而会分配一堆MOV指令，直接赋值。

# 指令清单43.11 64位的GCC 4.9.1优化

```
f:
mov QWORD PTR [rdi], 0
mov QWORD PTR [rdi+8], 0
mov QWORD PTR [rdi+16], 0
mov QWORD PTR [rdi+24], 0
ret
```

这让我们想起了本书的14.1节介绍的循环展开技术。
