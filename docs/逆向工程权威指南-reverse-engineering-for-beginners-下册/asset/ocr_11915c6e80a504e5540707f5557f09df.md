# 第88章 npad

“npad” 指令是一种汇编，用于把下一个指令标签的首地址向指定边界对齐。

被pad指令对齐的标签，通常都是需要被多次跳转到的地址标签。例如，在各种循环起始地址处的标签之前，我们经常可以看到npad指令。它可以通过指令地址、内存总线或缓存线等手段，提高CPU加载数据（或指令代码）的访问效率。

下面这段代码摘自MSVC的文件listing.inc。

顺便提一下，这这些都是NOP指令的变种。虽然这些指令没有实际的操作意义，但是它们可以占用不同的空间。
