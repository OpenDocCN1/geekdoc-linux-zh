tracer工具能够追查任意地址的寄存器状态。它名中的trace就强调了其独具的追查功能。它能够在任意指令设置断点，以记录指定寄存器的变化过程。此外，它还可以生成可被IDA调用的.pdb文件，并为了指令添加注释。例如，我们知道main()函数的地址是0x00041020，就可以执行

```
tracer.exe -l:loops_2.exe bpf=loops_2.exe!0x00041020,trace:cc
```

BPF的意思就是在函数执行前设置断点。
