```
void memcpy_128(char *inbuf, char *outbuf)
{
    memcpy(outbuf, inbuf, 128);
};
```

```
void memcpy_123(char *inbuf, char *outbuf)
{
    memcpy(outbuf+10, inbuf, 123);
};
```

MSVC分配了单条MOVS指令。在循环控制变量ECX的配合下，MOVS可一步完成128个字节的数据复制。其原因却是128能被4整除。

# 指令清单43.19 MSVC 2010 优化

```
_inbuf$ = 8
_outbuf$ = 12
_memcpy_128 PROC
    push esi
    mov esi, DWORD PTR _inbuf$[esp]
    push edi
    mov edi, DWORD PTR _outbuf$[esp+4]
    add edi, 10
    mov ecx, 32
    rep movsd
    pop edi
    pop esi
    ret
_memcpy_128 ENDP
```

在复制123个字节的程序里，编译器首先通过MOVS指令复制30个32位字节（也就是120个字节），然后依次通过MOVSW指令和MOVSB复制2个字节和1个字节。
