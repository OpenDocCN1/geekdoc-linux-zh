的CMOVcc指令)。GCC的维护人员采用了全新的指令设计GCC，显然他们决定不再支持P6以前的CPU（也就是奔腾时代以前的CPU）。

另外，从Intel P6系列CPU起，Intel CPU都整合了FPU。这使得FPU直接修改、检测CPU状态位成为可能。

GCC 4.8.1优化编译后，可以得到如下所示的指令。

# 指令清单17.14 Optimizing GCC 4.8.1

```
fld      QWORD PTR [esp+4]    ; load "a"
fld      QWORD PTR [esp+12]   ; load "b"
;ST0=b, ST1=a
fxch     st(1)
;ST0=a, ST1=b
; compare "a" and "b"
fucomi   st(1)
; move ST1 (b here) to ST0 if a<=b
; leave in ST0 otherwise
cmovbe  st(1)
; discard value in ST1
fstp     st(1)
ret
```

FXCH 指令将寄存器ST(0)的值与顶层 ST(0)的值交换，并保留栈顶指针。实际上，如果交换两条FLD指令、或者用 FCMOVE(BE代表below or equal)替换为FCMOVA(A代表above)指令，那么就可以不用FXCH指令了。或者是因为编译器的优化化仍尚未实现。

其，FUCOMist(0)的值(变量a)和ST(1)的值(变量b)，在CPU上设置标记位。接下来使用FCMOVE检查这些状态位，并进行述操作如果ST(0)<ST(1)，如果a<=b，就把ST(0)的值（此时是a）复制到ST(0)寄存器。条件不变就是a<=b的条件，它将保持ST(0)的值。
