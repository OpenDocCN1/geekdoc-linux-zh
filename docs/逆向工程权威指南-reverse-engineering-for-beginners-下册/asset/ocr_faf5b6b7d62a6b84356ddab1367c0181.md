前面提到，在x86和其他底层平台上，栈常用于传递参数的参数、存储局部变量。我们这里与JVM略有不同。

JVM的内存模型可以为：

+   * 局部变量数组(Local Variable Array, LVA)。它用来外部的函数参数和局部变量。iload 0类指令的作用是从LVA中提取值，而istore可以将值存储在LVA。字节函数从第0个参数（不涉及指针的）或第1个参数（涉及此指针的参数）依次读取各项外部参数，然后划分局部变量的存储空间。
* 每个参数(args slot) 都是相同的参数单元，数据类型为long（长）或double（双）的数据参数都会占用两个参数槽。
* 操作数标识(Java)“载”，用于计算参数个数，或者向被调用函数传递参数。Java程序不能直接运行在x86那样的硬件环境，因此它必须通过明确的入栈、出栈指令才能访问自己的栈，不能像汇编一样对栈进行搜寻。
* 堆。堆用于存储对象和数组。

以上3种内存模型相互独立、隔离。

# 54.5 简单的函数调用

Math.random()函数可以产生0.0~1.0之间的任意（仿）随机数。因此，如你生成0.0~0.5之间的随机数，就要对上述结果进行除法运算：

```
public class HalfRandom {
    public static double slot() {
        return Math.random()/2;
    }
}
```
