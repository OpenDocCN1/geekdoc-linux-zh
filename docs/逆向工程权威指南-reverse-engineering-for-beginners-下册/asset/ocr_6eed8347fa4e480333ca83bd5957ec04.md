在编写日志(logging)函数的时候，许多人都会自己构造一个与printf类似的处理“格式化字符串+一系列（但是数量可变的）的内容参数”的变长参数函数。

另外一种常见的变参数函数是底下的这种die()函数。这是一种在显示提示信息之后退出整个程序的异常处理函数。它需要把不确定定量的输入参数打包并传递给printf()函数。如何实现呢？这些die函数名称前面有一个字母的v，这是因为它应该能够处理不确定数量（variable.可变的）的参数。用die()函数调用的vprintf()函数来实现，它的输入变量可以分为两部分：一部分是格式化字符串，一部分是带有某种类型数据列表va_list的指针。

```
#include <stdlib.h>
#include <stdarg.h>

void die(const char * fmt, ...) {

    va_list va;
    va_start(va, fmt);

    printf(fmt, va);
    exit(0);

}
```

仔细观察就会发现，va_list是一个指向数组的指针。在编译后，这个特征非常明显：

```
$fmt = 8
_die:
    PROC
    ; load 1st argument (format-string)
    mov ecx, DWORD PTR $fmt$[esp-4]
    ; get pointer to the 2nd argument
    lea eax, DWORD PTR $fmt$[esp]
    push eax        ; pass pointer
    push ecx
    call _vprintf
    add esp, 8
    push 0
    call _exit
$LN3@die:
    int 3
    ENDP
```
