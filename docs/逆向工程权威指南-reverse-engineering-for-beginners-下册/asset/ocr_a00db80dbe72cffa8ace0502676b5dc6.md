# 第56章 Win32环境下与外部外部通信

在了解函数的输入和输出的情况下，我们基本可以判断出函数的具体功能。这种分析方法能够显著节省分析时间。

如关注文件和注册表层面的行为，使用SysInternals的Process Monitor即可，它可以给我们提供关于以上这两者的基本信息。

如查看网络层面的通信数据，完全可以使用Wireshark这类软件。

然而要进一步分析行为级数据，就得深入程序内部挖掘指令层的信息。

首先要查询该程序的操作操作系统API和标准函数。

如目标程序由执行文件和多个DLL文件构成，那么这些DLL文件提供的、可调用的函数名称就很具有指标性意义。

如果我们可以某些那些使用MessageBox()、显示特定文字的指令，我们可以在程序的数据段查找字符串字符，找到这个字符串的指令，再顺摸摸找到那些预定义的MessageBox()函数的代码。

在分析游戏时，如果可以确定关卡里出现的敌人总数是随机数，那么我可以在代码中查找rand()函数或者类似的随机生成函数（例如梅森螺旋算法），继续找到这些函数的调用指令，最终调整程序中使用随机的那些指令。本书75章演示了这种分析实例。
