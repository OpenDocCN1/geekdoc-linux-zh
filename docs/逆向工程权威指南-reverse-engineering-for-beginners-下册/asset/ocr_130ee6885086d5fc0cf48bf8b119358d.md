# 61.1 XOR异或指令

XOR op、或者XOR EAX、EAX这样的指令通常用来将某个寄存器清零。只有当XOR指令的两个操作数不同的时候，它才进行真正的“异或”运算。这种意图上的异或运算，在常规程序很少见到，而在加密法中比较常见，即使业人员编写的程序也是如此。如果XOR的第二个操作数是一个很大的数，那么这个程序就显得特别可疑。这种情况往往意味着着它会进行加密或者解密、校验和等类型的复杂计算。

需要说明的是，18.3节介绍的编译器采用的“灵鸟”技术同样会生成XOR指令。这些XOR指令和加/解密等科学运算无关。

我们可以利用AWK处理IDA生成的指令清单文件（.lst），检索其中的XOR指令:

```
awk -e '$2=="xor" { tmp=substr($3, 0, length($3)-1); if (tmp!=$4) if ($4!="esp") if ($4!="ebp") \n    \tprint $1, $2, ",",", $4 }' filename.lst
```

值得注意的是，这种类型的脚本也适用于适配不正确的汇编代码（可以参考本书第49章）。
