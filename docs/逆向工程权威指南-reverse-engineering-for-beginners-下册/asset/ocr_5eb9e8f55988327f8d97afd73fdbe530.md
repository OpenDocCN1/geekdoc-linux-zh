```
movxd rax, ecx
lea rax, QWORD PTR [rax+rax*4]
; RCX=month+month*4-month*5
lea rax, OFFSET FLAT:month2
; RAX-pointer to table
lea rax, QWORD PTR [rax+rcx*2]
; RAX-pointer to table + RCX*2-pointer to table + month*5*2-pointer to
table + month*10
ret 0
get_month2 ENDP
```

上述程序不包含任何内容。整个函数的功能，就是计算月份名称字符串的首字母数字pointer_to_the_table*month*10。它使用单条LEA指令，替代了多条MUL和MOV指令。

上索引每个字符都占用10字节空间。最长的字符串“September”和内容为零的字符串构成，其余的字符使用零字节对齐，所以每个字符都占用10字节。这样一来，计算字符串地址的方式变得简单，整个函数的效率会有提高。

使用GCC 4.9进行优化编译，程序的指令会更少。

```
movsx rdi, edi
lea rax, [rdi+rdi*4]
lea rax, month2[rax+rax]
ret
```

同样使用LEA指令进行“乘以以10”的运算。

若由GCC进行非优化，那么乘法法的实现方式会有所不同。

get_month2:

mov eax, DWORD PTR [rbp-4]

; RAX=month
sal rax, 2
; RAX=month<2 = month*4
add rax, rdx
; RAX=RAX+RDX = month*4+month = month*5
add rax, rax
