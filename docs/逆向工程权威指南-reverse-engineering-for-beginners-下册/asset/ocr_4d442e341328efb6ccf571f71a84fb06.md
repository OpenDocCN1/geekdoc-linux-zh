```
$a$ = 8
```

指令清单24.15 Optimizing GCC 4.8.1 -fno-inline

```
_f:
mov edx, DWORD PTR [esp+8]
mov eax, DWORD PTR [esp+4]
shrd eax, edx, 7
shr edx, 7
ret
```

位移运算仍然为2步：第一步处理低32位数据，第二步处理高32位数据。需要的是处理低32位指令对高32位进行位移操作，可以使用SHRD指令。这个指令可以将EAX中的低32位数据右移运算，还能从EDX寄存器读取32位中的低位、用它填充到32位的高位。如此一来，就可以直接使用普通的SHR指令对32位进行位移操作，并用零填充移产生的空位。

# 24.4.2 ARM

ARM的指令集如x86，没有SHRD之类的指令。因此，Keil把它拆分为位移或运算，以进行等效处理。

```
LSR r1,r1,#7
BX lr
ENDP
```
