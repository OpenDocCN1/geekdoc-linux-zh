```
push    OFFSET $SG2937 ; 'end'
call    _printf
add      esp, 4

ret      0
```

源代码中的goto语句直接被编译成了JMP指令。这两个指令的效果完全相同：无条件的转移到程序中的另一个地方继续执行后后续命令。

只有在人工干预的情况下，例如使用调试器调整、或者对程序打丁的情况下，程序才会调用第二个printf()函数。

我们用它练习patching技术。首先使用Hiew打开刚刚编译的可执行文件，如图11.1所示将光标移动到JMP（0x410）处，按下F3键（编辑），再输入两个零。这样，我们将这个地址的opcode改为EB 00如图11.2所示。
