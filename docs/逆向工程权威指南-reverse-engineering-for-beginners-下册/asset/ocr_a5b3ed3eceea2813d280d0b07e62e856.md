执行上述脚本之后，我们将看到：

```
$ ./tst.sh
Hello, world!
14
```

这个“14”就是puts() 函数输出的字符的总数。

#  9.2 函数返回值不被调用的情况

printf() 函数的返回值为字符的总数，但是很少有程序未使用这个返回值。实际上，确实有用运算符返回，却不使用结果的程序：

```
int f()
{
    // skip first 3 random values
    rand();
    rand();
    rand();
    // use 4th
    return rand();
}
```

上述四个rand()函数都会把运算结果存储到EAX寄存器里。但是三个rand()函数在EAX寄存器的运算结果都被抛弃了。

#  9.3 返回值为结构体类型

我们继续使用EAX寄存器存储返回值的案例。函数只能使用EAX一个寄存器存储返回值。由于这种局限，过的C编译器无法编译返回值超过容量（一般来说，就是int数据）的函数。那个时候如果要返回多个值，那么只能用函数返回一个值，再通过指针传递它的返回值。现在的编译器已经没有这种短板了，return甚至可以返回结构体数据，只是时候很少有人会这么做。如果函数的返回值是大型类型的数据，那么应该用调用函数（caller）负责分配内存，给结构体分配指针，再把指针作为第一个参数传递给被调用函数。现在的编译器已经能够替程序员自动完成这种复杂的操作，其处理方式相当于上述几个步骤，只是编译器隐藏了这些操作。*
