# 图解模式：

按下空键，IDA将会进入图解的显示方式。其效果如图7.7所示。

```
int __cdecl main(
_main proc ptr -4
var_4h= dword ptr 4
argc= dword ptr 8
argv= dword ptr 0Ch
envp= dword ptr 18h

push ebp
mov ebp, esp
push ecx
push offset Format  ; "Enter X:\"
call ds:printf
add esp, 4
lea eax, [ebp+var_4]
push eax
push offset a0  ; "%s...%d"
call ds:scanf
add esp, 8
cmp eax, 1\jnz short exit
```

![](bbox=[0.165, 0.473, 0.834, 0.755])

判断语句会分出两个箭头，一条是红色的，一条是绿色的。当判断条件表达式值为真时，程序会采用绿色箭头所示的流程；如果判断条件表达式不成立，程序将采用红色箭头标识的流程。
