两个产品都是SAP开发的）。因此，实际上我们可以找到的源代码。

最后要分析的是：

```
.text:64406F79 cmp dword ptr [ecx+3Ah], 1
.text:64406F80 jnz compression_flag_is_zero
```

把此处的JZ找到了无条件转移指令跳转，删除环境变量
TDW_NOCOMPRESS。虽再用WireShark分析网络包时，我们就会发现
SAPUI不再压缩数据了。

综上，在找到压缩环境与数据功能的切合点之后，我们可以强制开启这个功能，也可以强制关闭这项功能。
