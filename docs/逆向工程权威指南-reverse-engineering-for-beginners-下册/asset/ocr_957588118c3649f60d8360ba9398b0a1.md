那些电脑游戏以外的，仍然用rand()函数的程序就更值得关注了。令人感到吃惊的是，某些著名软件采用的数据压缩算法（加密机制）都调用了rand()函数。感兴趣的读者可参阅 https://urichev.com/blog/44/

# 56.1 在Windows API中最常用的函数

这里列出了一些最常用的API函数。需要特别说明的是，这些函数可能不是由程序代码直接调用的。在程序中使用库函数或者调用CRT的时候，上述函数可能会被后者间接调用。

+   注册的操作可以通过库文件advspi32.dll的如下功能实现：RegEnumKeyEx、RegEnumValue、RegGetValue、RegOpenKeyEx和RegQueryValueEx。

+   对相似的文本可以通过库文件user32.dll的如下函数实现：GetPrivateProfileString

+   对话的操作可以通过库user32.dll的如下函数实现：MessageBoxEx、SetDlgItemText和GetDlgItemText。

+   对资源的操作（可以参考本书的68.2.8节）通过库文件user32.dll的函数LoadMenu实现。

+   对TCP/IP网络的操作是通过库文件ws32.dll的如下函数实现：WSARcv和WSASend。

+   对文件的操作是通过库文件kernel32.dll的如下函数实现相应的操作：CreateFile、ReadFile、ReadFileEx、WriteFile及WriteFileEx等。

+   访问Internet是通过库文件wininet.dll的WinHttpOpen函数实现相关功能的。
