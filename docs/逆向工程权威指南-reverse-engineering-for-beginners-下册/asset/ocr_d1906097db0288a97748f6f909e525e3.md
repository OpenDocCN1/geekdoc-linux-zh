# 第44章 C99标准的受限指针

在某些情况下，用FORTRAN系统编译出来的程序会比C/C++系统编译出来的程序运行更快。例如，下面这个例子就是如此:

```
void f1 (int* x, int* y, int* sum, int* product, int*
sum_product, int* update_me, size_t s)
{
    for (int i=0; i<s; i++)
{
        sum[i]=x[i]+y[i];
        product[i]=x[i]*y[i]; // some dummy value
        update_me[i]=i*123; 
        sum_product[i]=sum[i]+product[i];
    }
}
```

这个程序的功能十分简单，但是里面的指针问题却引发深思：同一块内存可以由多个指针来访问，因此同一个地址的数据可能会被多个指针轮复制。至少现行标准并没有这种情况。

C语言编译器完全允许上述情况。因此，它分四个阶段处理每次迭代的各类变量数据:

+   - 准备sum[i];

+   - 准备product[i];

+   - 准备update_me[i];
