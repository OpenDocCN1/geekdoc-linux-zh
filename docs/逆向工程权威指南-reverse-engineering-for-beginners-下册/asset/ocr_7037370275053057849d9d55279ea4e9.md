```
get_month1 PROC
    LDR r1,|L0.100|
    LDR r0,[r1,r0,LSL #2]
    BX
    ENDP
L0.100:     ||data|
    DCD "January",0
    DCB "February",0
    DCB "March",0
    DCB "April",0
    DCB "May",0
    DCB "June",0
    DCB "July",0
    DCB "August",0
    DCB "September",0
    DCB "October",0
    DCB "November",0
    DCB "December",0
```

```
AREA ||data||, DATA, ALIGN=2
month1
    DCD ||conststring||+0x8
    DCD ||conststring||+0x11
    DCD ||conststring||+0x17
    DCD ||conststring||+0xd1
    DCD ||conststring||+0x21
    DCD ||conststring||+0x26
    DCD ||conststring||+0x2b
    DCD ||conststring||+0x32
    DCD ||conststring||+0x3c
    DCD ||conststring||+0x44
    DCD ||conststring||+0x4d
```

数据首的地址存储在R1寄存器中。其余元素的指针地址通过LDR指令字段计算。偏移相加，从而计算出地址表中的指针地址。此后，再用这个指针在32位列表中进行查询，把最终的字符串地址存储在R0寄存器里。
