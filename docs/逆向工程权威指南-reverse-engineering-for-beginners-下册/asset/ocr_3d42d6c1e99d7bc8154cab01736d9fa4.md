# 54. 13.2 数组元素求和

我们来看另一个例子，它的功能是将一个输入的数组的各项数值相加和。

public class ArraySum
{
    public static int f(int[] a)
{
        int sum=0;
        for (int i=0; i<a.length; i++)
            sum+=a[i];
        return sum;
    }
}
