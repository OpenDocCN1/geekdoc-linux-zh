DD $LN5@f ; 1
DD $LN4@f ; 2
DD $LN3@f ; 3
DD $LN2@f ; 4

这段代码被赋值为数字参数printf()函数的指令组，且每组指令传递
给printf()函数的参数还各不同。这些指令组在内存中拥有各自自己的起始地
址，就被编译器分配到了不同的符号标签（symbolic label）之后。从此来看，程序通过$LN11@f的一组数据调用了这些标签。

函数最初将变量的值与数字进行比较。如果变量大于4，函数则跳转到
$LN11@f，把字符串“something unknown”传递给printf()函数。

当变量小于或等于4时，就会计算4的幂，再计算$LN11@f的偏
偏移量（索引），并跳转到这个结果指向的地址。如果变量大于4的
情况来说，2x4=8（由于x86系统的内存地址是32位数据，所以LN11@表
每个地址都占用4字节）。在计算8+$LN11@f的偏移量的和之后，再跳转
到这个和指向的标签——$LN4@f。跳转最终跳转到$LN4@f的地址。

$LN11@f（标签）跳转到表，称为“跳转jumptable”，也叫称为
“跳转（输出）branchtable”。[4]

当变量等于2的时候，程序分配printf()的“two”。实际上，此时
的switch语句的分支指令等于“jmp DWORD PTR $LN11@f[ecx*4]。它会
进行间接取值的操作，指向PTR（表达式）所指向的数据读取出来，当
DWORD类型数据传递给jmp指令。在这个程序里，表达式的值为
$LN11+ecx*4。

此处出现的npad指令属于汇编，本书第88章详细介绍。它的作用
是把紧随其后的标签对齐4字节（或16字节）边界对齐npad的地址对齐
可能提高处理器的I/O写效率，通过一次操作即可完成内存总线、缓冲区内存
等设备的数据操作。
