; if comparison result is Not Equal, copy EDX value to EAX
; if not, do nothing
  Cmovne eax, edx
  ret

Optimizing Keil编译的ARM程序，与指令清单12.21相同。

但是启用优化功能的MSVC 2012仍然没有什么不起。

# 12.3.6 总结

启用优化功能之后，编译器可能会尽可能避免使用条件转移指令。本书的33.1节将详细解释这个问题。
