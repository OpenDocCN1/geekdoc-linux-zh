如果触发了VMOVGT指令，则把D17变量a的值复制到D16寄存器里。

否则，D16寄存器将会保持原来的变量b的值。

倒数第二条指令VMOV的作用是将返回选项，它把D16寄存器64位的值分为两个对32的，并分别存储在通用寄存器RO0和R1里。

# Optimizing Xcode 4.6.3 (LLVM) (Thumb-2 mode)

使用Xcode 4.6.3（开启选项）、以及Thumb-2模式编译上述程序可以得到如下所示指令。

指令清单17.17 Optimizing Xcode 4.6.3 (LLVM) (Thumb-2 mode)

```
VMOV            D16, R2, R3 ; b
VMOV            D17, R0, R1 ; a
VMPE.F64       D17, D16
VMRS           APSR,nzcv, FPSCR
IT GT
VMOVGT.F64     D16, D17
VMOV            R0, D16
BX             LR
```

Thumb-2模式的代码和ARM模式的程序大相同。确实，很多ARM模式的指令都存在对应的执行条件才会执行指令。

但是Thumb模式没有这种衍生的条件指令。Thumb模式的opcode只有16位。这个存储空间不包含条件判断表达式所需的那4位的的存储空间。

而扩充后的Thumb指令没有上述缺陷，它们可以为Thumb模式缺失的条件判断表达式来实现。

在IDA显示的汇编指令清单里，我们可以看到Thumb-2的代码里也出现了VMOVGT指令。

此处的实际指令是VMOV指令，IDA为其添加了GT后缀。为了直观地体现前面那条指令“IT GT”的条件判断，IDA在后期使用了伪指令。

IT指令与与之对应的if-then语句之间存在明确的关系。在IT指令之后的指令（最多4条指令），相当于if-then语句块中的一个条件执行运行。在本例中“IT GT”的语义是：如果前面比较的数值，第一个值“大于/Greater Than”第二个值，执行后续模块的1条指令。
