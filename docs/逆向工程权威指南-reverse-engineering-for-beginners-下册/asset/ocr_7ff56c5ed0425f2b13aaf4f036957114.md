```
my_mempy;
; jump to loop check part:
    b loc_14
; initialize counter (i) at 0
; it will always remain in \$v0;
    move $v0, zero; branch delay slot
```

```
loc_8:\                               # CODE XREF:
my_memcpy+1C
; load by unsigned at address in $t0 to $v1:
    lbu $v1, 0($t0)
; increment counter (i):
    addiu $v0, $1
; store byte at $a3
    sb $v1, 0($a3)
```

```
loc_14:\                               # CODE XREF: my_memcpy
; check counter (i) in $v0 is still less then 3rd function argument
("cnt" in $a2):
    sltu $v1, $v0, $a2
; form address of byte in source block:
    addiu $t0, $a1, $v0
; $t0 = $a1+$v0 ; src+
; jump to loop body if still less then "cnt":
    bnez $v1, loc_8
; form address of byte in destination block ($a3 = \$a0+\$v0 =
    addiu $a3, $a0, $v0 ; branch delay slot
; finish if BNEZ triggered:
    jr $ra
    nop $at, zero ; branch delay slot, GOP
```

这里介绍的两个指针寄存器分别是LBU (Load Byte Unsigned)和SB (Store Byte)。在两个平台上，所有的MIPS寄存器都是32位寄存器。在两个平台上，我们无法像x86那样对寄存器的低位进行操作。因此在处理单字节字符操作时，我们都是访问整个32位寄存器。LB指令加载带符号的数据并清除寄存器的其他位。由于有符号位的问题，所以在处理有符号的数据的时候通常要使用LB (Load Byte)指令把单字节的有符号数据扩展为等值的32位数据、再存储在寄存器中。SB指令的作用是把寄存器的低8位数据、存储到内存里。
