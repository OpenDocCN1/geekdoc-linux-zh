$LN9@my_atoi: 0

my_atoi ENDP

字符串的第一个字符可能就是终止符。在这种情况下，函数不应
当进入字符的转换过程中。此外，编译器没有分配“乘以10”的乘
指令，而是使用了第一条、第三条LEA指令步实现了“上次迭代的
rt值乘以5、“输入字符+5原始后rt×2”的运算。某些情况下，
MSVC编译器会避免减法运算使用SUB指令，转而分配“ADD负
数”的指令来实现减法运算。本例就发生了这种情况。虽然笔者也不
明白ADD指令的优势性在哪里，是MSVC编译器经常会做指令替
换。

# 42.1.2 六位下的GCC 4.9.1优化

GCC 4.9.1优化更精确，但是它会在代码的最后添加一个多余的返
回指令。其实一个RET足够了。

指令清单42.2 六位下的GCC 4.9.1优化

```
my_atoi:
; load input character into EDX
movsx edx, BYTE PTR [rdi]
; EAX is allocated for "rt" variable
xor eax, eax
; exit, if loaded character is null byte
test dl, dl
je .L4
L3:
lea eax, [rax+rax*4]
; EAX=RAX*5=rt*5
; shift pointer to the next character:
add rdi, 1
lea eax, [rdx-48+rax*2]
; EAX=input character - 48 + RAX*2 = input character - '0' +
rt*10
; load next character:
movsx edx, BYTE PTR [rdi]
; goto loop begin, if loaded character is not null byte
test dl, dl
jne .L3
rep ret
L4:
rep ret
```
