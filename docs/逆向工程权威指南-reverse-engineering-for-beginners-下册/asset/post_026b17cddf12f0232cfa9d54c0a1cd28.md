## 1.3 封装

封装（encapsulation）的作用：把定义的数据和方法限定为私有的，使其调用只能访问类的公共方法和数据。在抽象层面上，到底划分私有对象和公开对象的界限呢？其实完全没有。我们来看这个简单的例子：

```cpp
#include <stdio.h>

class box {
    private:
        int color, width, height, depth;
    public:
        box(int color, int width, int height, int depth)
        {
            this->color=color;
            this->width=width;
            this->height=height;
            this->depth=depth;
        }
        void dump()
        {
            printf("this is box. color=%d, width=%d, height=%d, depth=%d\n", color, width, height, depth);
        }
};
```

所有字段都是无法被函数直接访问的私有变量。但是，既然我们知道了这个对象的存储布局，却不能写出一个修改这些变量的程序呢？为此，我们可以构造一个名为hack_oop_encapsulation()的函数。如果不调整的话，直接访问既定的源程序就会：

```cpp
void hack_oop_encapsulation(class box * o) {
    o->width=1; // that code cant be compiled'
    // "error C2248: 'box:width': cannot access private member declared in class 'box'"
}
```

当然，上述代码不可能被成功编译出来。然而，要把box的数据类型强制转换为整数数组的，我们就可以通过编译并且直接修改相应字段。

```cpp
void hack_oop_encapsulation(class box * o) {
    unsigned int *ptr_to_object=reinterpret_cast<unsigned int*>(o);
    ptr_to_object[1]=123;
}
```

上述函数的功能简单：它将输入数据视为整数数组，然后将数组的第二个元素、一个整数int值修改为123。

## 多重继承

```cpp
class solid_object {
  public:
    int density;
    solid_object(int density) {
      this->density=density;
    }
    void dump() {
      printf("this is solid_object. density=%d\n", density);
    }
};

class solid_box: box, solid_object {
  public:
    solid_box(int color, int width, int height, int depth, int density)
      : box(color, width, height, depth), solid_object(density) {
    }
    void dump() {
      printf("this is solid_box. color=%d, width=%d, height=%d, density=%d\n", color, width, height, density);
    }
    int get_weight() {
      return density;
    }
};

int main() {
  box b(1, 10, 20, 30);
  solid_object so(100);
  solid_box sb(10, 20, 30, 100);

  b.dump();
  so.dump();
  sb.dump();
  printf("%d\n", sb.get_weight());

  return 0;
}
```结果为：

this is solid_object. density=100
this is solid_box. color=10, width=20, height=30, density=100
