含有memset(block, size)的构造函数通常用于清空内存区域。如果我们阻止它调用这个memset()函数，那么将会发生什么情况？

为此，我们在程序中memset()函数参数的0x434C7A设置断点，令调试程序计数器（PC，即EIP）调整为0x434C8A，从而使程序“跳过”内存中的memset()函数。可以说，这种“调试”相当于程序在0x434C7A处执行无条件转移到0x434C8A。相关的指令如下：

```
tracer -a:oracle.exe
bpx=oracle.exe!0x00434C7A, set(eip, 0x00434C8A)
```

请注意：上述地址仅对Win32版本的Oracle DBMS 11.2 有效。
