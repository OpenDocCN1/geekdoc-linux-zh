C++标准要求：函数内部应当可以访问局部变量，且函数外部应该访
访问不到函数内部的局部变量。现如今，人们不约而同地用数据来存储
局部变量。虽然部分分配变量的方法不只有此一种，但是所有面向x86平台的编
译器都约定成般地使用这种方法存储局部变量。

在函数执行期间有一条“PUSH ECH”指令。由于函数尾部处没有对应的
“POP ECH”指令，它的作用不是保存ECX的值。

实际上，该指令在栈内留了4字节的空间，用于存储局部变量x，而EBP寄存器用于存储
当前帧的指针。

在函数运行期间，EBP一直指向当前的帧（stack frame）。这样，
函数即可通过EBP+offset的方式访问本地变量，以及外部传入的函数参数。

ESP也可以用来访问本地变量，获取函数所需的运行参数。不过ESP的值
经常发生变化，用起来就不方便。函数在启动之初就会利用EBP寄存器保存存
ESP寄存器的值。这就是为了确保在函数运行期间保证EBP寄存器的原始
ESP值固定不变。

在32位体系里，典型的栈（stack frame）结构如下所示。

| | |
|---|---|
| EBP-8 | 局部变量#2, 标记为var 8 |
| EBP~4 | 局部变量#1, 标记为var_4 |
| EBP | EBP的值 |
| EBP+4 | 返回地址Address |
