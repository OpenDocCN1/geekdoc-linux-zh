
# 第16章 数学计算指令的替换

出于性能优化的考虑，编译器可能会将1条数学运算指令替换为其他的1条，甚至是一组等效指令。

例如LEA通常替代其他的简单计算指令；请参见附录A.6.2节。

ADD和SUB指令同样可以相互替换。例如，指令清单52.1的第18行就是此。

## 16.1 乘法

### 16.1.1 替换为加法运算

我们通过上述程序进行演练。

> 指令清单16.1 Optimizing MSVC 2010

```c
unsigned int f(unsigned int a)
{
    return a*8;
}
```

如果使用MSVC 2010（启用/O2）进行编译，编译器会将“乘以8”的指令拆解为3条加法指令。明显MSVC认为替换后的程序性能更高。

```asm
_TEXT SEGMENT
a$ = 8              ; size = 4
_ PROC
    ; File c:\polygon\2.c
    mov eax, DWORD PTR _a[esp-4]
    add eax, eax
    add eax, eax
    add eax, eax
    f      ret 0
      ENDP
TEXT ENDS
END
```

### 16.1.2 替换为位移运算

编译器通常会把“乘以除以2”的运算指令处理为位移运算指令：

```c
unsigned int f(unsigned int a)
{
    return a*4;
}
```

```asm
; 指令清单16.2 Non-optimizing MSVC 2010
a$f = 8      ; size = 4
_f PROC
    push ebp
    mov  ebp, esp
    mov  eax, DWORD PTR _a[ebp]
    shl  eax, 2
    pop  ebp
    ret  0
_f ENDP
```

“乘以4”的运算就是把被左移2位、再把位移产生的空位添上0的运算。就好比在算法计算3×100的时候，我们在后面的空缺位添加两个零。

位移指令的示意图如下。

![](img/a13a81a53f805f55074b2e5d2ec754b6_310_0.png)

右侧产生的空位都由零填充。
乘以4的ARM指令如下：

### 指令清单.16.3 Non-optimizing Keil 6/2013 (ARM mode)

```asm
PROC
LSL    r0,r0,#2
BX     lr
ENDP
```

对应的MIPS指令如下：

### 指令清单.16.4 Optimizing GCC 4.4.5 (IDA)

```asm
jr     $ra
sll    $v0, $a0, 2 ; branch delay slot
```

其中，SLL是逻辑左移“Shift Left Logical”的缩写。

### 16.1.3 替换为位移、加减的混合运算

即使乘数是7或17，乘法运算仍然可以使用非乘法运算配合位移指令实现。其算术原理也不难推测。

#### 32位

```c
#include <stdint.h>

int f1(int a)
{
    return a*7;
}

int f2(int a)
{
    return a*28;
}

int f3(int a)
{
    return a*17;
}
```

x86

### 指令清单.16.5 Optimizing MSVC 2012

```asm
; a*7
_a$ = 8
_f1 PROC
	mov ecx, DWORD PTR _a$[esp-8]
; ECX=a
	lea eax, DWORD PTR [ecx*8]
; EAX=ECX*8
	sub eax, ecx
	; EAX-ECX=ECX*8-ECX=ECX*7=a*7
	ret
f1
ENDP
```

```asm
; a*28
_a$ = 8
_f2 PROC
	mov ecx, DWORD PTR _a$[esp-4]
; ECX=a
	lea eax, DWORD PTR [ecx*8]
; EAX=ECX*8
	sub eax, ecx
	; EAX-ECX=ECX*8-ECX=ECX*7=a*7
	shl eax, 2
; EAX=<<=(a*7)*4=a*28
	ret
f2
ENDP
```

```asm
; a*17
_a$ = 8
_f3 PROC
	mov eax, DWORD PTR _a$[esp-4]
; ECX=a
	shl eax, 4
; EAX=E<<4=EAX*16=a*16
	add eax, DWORD PTR _a$[esp-4]
; EAX+a=a*16+a=a*17
	ret
f3
ENDP
```

ARM
ARM指令集的位移运算符有3个操作符，可以在位移运算后再进行一次加法运算。故Keil生成的代码更为短小。

### 指令清单16.6 Optimizing Keil 6/2013 (ARM mode)

```asm
; a*7
f1 PROC
	RSB r0,r0,r0,LSL #3
; R0=<<3-R0=R0*8-R0=a*8-a=a*7
	BX lr
ENDP
```

```asm
; a*28
f2 PROC
RSB r0,r0,r0,LSL #3
; R0=R0<<3-R0=R0*8-a=8-a=7
LSL r0,r0,#2
; R0=R0<<2-R0*4=a*7*4=28
BX lr
ENDP
```

```asm
; a*17
f3 PROC
	ADD r0,r0,r0,LSL #4
; R0=R0<<4=R0+R0*16=17=a*17
BX lr
ENDP
```

然而Thumb模式的位移指令不支持这种运算。编译器无法优化f2()。

### 指令清单16.7 Optimizing Keil 6/2013 (Thumb series)

```asm
; a*7
f1 PROC
	LSLS r1,r0,#3
; R1=R0<<3=a*8=a
SUBS r0,r1,r0
; R0=R1-R0=8-a=a*7
BX lr
ENDP
```

```asm
; a*28
f2 PROC
	MOVS r1,#0x1c ; 28
; R1=28
	MULS r0,r1,r0
; R0=R1*R0=28*a
BX lr
ENDP
```

```asm
; a*17
f3 PROC
	LSLS r1,r0,#4
; R1=R0<<4=R0*16=a*16
ADDS r0,r0,r1
; R0=R0+R1=a*16+a=a*17
BX lr
ENDP
```

MIPS

### 指令清单16.8 Optimizing GCC 4.4.5 (IDA)

```asm
_f1:
  sll $v0, $a0, 3
  jr $ra
  sub $v0, $a0 ; branch delay slot
  ; $v0=a*8-a=a*7
```

```asm
_f2:
  sll $v0, $a0, 5
  sll $v0, 2
  jr $ra
  sub $v0, $a0 ; branch delay slot
  ; $v0=a*32-a=a=28
```

```asm
_f3:
  sll $v0, $a0, 4
  jr $ra
  add $v0, $a0 ; branch delay slot
  ; $v0=a*16=a17
```

x64

### 指令清单16.9 Optimizing MSVC 2012

```asm
; a*7
f1:
  lea rax, [rcx*8]
  sub rax, rcx
  ; rax=rcx*8-rcx=rcx*7=a*7
  ret
```

```asm
; a*28
f2:
  lea rax, [rcx*8]
  sub rax, rcx
  ; rax=rcx*8-rcx=rcx*7=a*7
  shl rax, 2
; rax=<<=(a*7)*4=a*28
  ret
```

```asm
; a*17
f3:
  shl rax, 4
; rax=a<<4=a*16=a*16
  add rax, rcx

  ret
```

ARM64

```asm
; a*7
f1:
  lsl w1, w0, 3
  sub x0, w1, x0
  ; x0=a*8-a=a*7
  ret
```

```asm
; a*28

  lsl w1, w0, 5
  sub x0, w1, x0

  ret
```

; a*17
f3:
  add x0, x0, x0, lsl 4
  ; x0=a+a*16=a*17
  ret

## 16.2 除法运算

### 16.2.1 替换为位移运算

本节围绕源程序进行位演示：

```c
unsigned int f(unsigned int a)
{
    return a/4;
}
```

使用MSVC 2010编译上述程序，可得到如下：

### 指令清单16.11 MSVC 2010

```asm
_a$ = 8 ; size = 4
_f PROC
    mov eax, DWORD PTR _a$[esp-4]
    shr eax, 2
    ret 0
ENDP
```

上述代码中的SHR (Shift Right)将EAX寄存器中的数值右移2位，使用零填充位移产生的空位，并且那些被右移指令移动出空间的比特。实际上，那些被舍弃的比特正是除法运算的余数。

SHR指令和SHL指令的模式相同，只是位移方向不同。

![](img/a13a1a53f805f55074b2e5d2ec754b6_316_0.png)

右移与余数的关系与十进制运算的移动点数相似：当被除数为23、除数为10时，我们将23的小数点左一位，为商、3为余数。毕竟本例是整数运算，商应当是整数（不是浮点数），所以我们舍弃余数完全没有问题。“除以4”运算的ARM程序如下。

### 指令清单16.12 Non-optimizing Keil 6/2013 (ARM mode)

```asm
PROC
LSR     r0,r0,#2
BX      lr
ENDP
```

“除以4”运算的MIPS程序如下：

### 指令清单16.13 Optimizing GCC 4.4.5 (IDA)

```asm
jr     $ra
srl    $v0,$a0, 2 ; branch delay slot
```

上述程序中的SRL指令是“逻辑右移指令/Shift-Right Logical”。
