在这个循环里，计数变量的取值范围是0~31。因此“1<<” 表达式的取值范围是0到0x80000000，用类语言解释，它的含义就是“将数字1左移一位”。“1<<”将使“1”逐一逼近32位数字的每一位，同时将其他位置零。

这段程序里，1<<可能产生的值：

| C/C++表达式 | 二进制 | 十进制数 | 十六进制数 |
|---|---|---|--|
| 1<<0 | $2^0$ | 1 | |
| 1<<1 | $2^1$ | 2 | |
| 1<<2 | $2^2$ | 4 | 4 |
| 1<<3 | $2^3$ | 8 | 8 |
| 1<<4 | $2^4$ | 16 | 0x10 |
| 1<<5 | $2^5$ | 32 | 0x20 |
| 1<<6 | $2^6$ | 64 | 0x40 |
| 1<<7 | $2^7$ | 128 | 0x80 |
