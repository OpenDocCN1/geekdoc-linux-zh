在这个内存在之后，即位于0x008c2000以后的物理内存都不可被程序访问。换言之，操作系统没有给这个程序分配那块内存。如果程序访问这块不可用的内存地址就会引发错误。

我们再研究下一个程序。程序可能在内存的末端5个字符。这种分配方法是合合理的。

```
0x008c1ff8 'h'
0x008c1ff9 'e'
0x008c1ffa 'l'
0x008c1ffb 'l'
0x008c1ffc 'o'
0x008c1ffd '\x00'
0x008c1ffe random noise
0x008c1fff random noise
```

当采用常规法的strlen()函数在处理这个字符串时，首先把指针指向字符串地址是否已经16字节对齐，每次读取16字节。“hello”的第一个字节，即地址0x008c1ff8。strlen()函数就会逐字节读取字符串。在遇到0x008c1ffd的0字节的时候，函数就结束了。

假如我们编写的strlen()函数不考虑字符串的地址对齐问题，无论字符串指针地址是否已经向16字节对齐，那么它就可能从0x008c1ff8一直读取到0x008c2000，这将引发错误。显然，我们应当尽量避免这种错误。

只有在字符串地址边界未对齐的情况下，才可以使用SIMD技术的算法。另外，操作系统在进行内存分齐时也是向16字节边界对齐的，在字符串首页地址同样向16字节边界对齐时，我们的函数不会访问未分配的内存访问。

_mm_setzero_si128(): 清空XMM寄存器的指令，相当于pxor xmm0, xmm0。

_mm_load_si128(): MOVDQA的宏。它从指定地址加载16字节数据到XMM1寄存器。
