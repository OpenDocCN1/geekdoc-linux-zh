# 第32章 内存布局

C/C++把内存划分为若干区域，主要的内存区域有：

+   - 全局内存空间，又称为“（全局）静态存储区 static memory allocation”。人员不需要全局变量和静态变量明确划分存储空间，全局变量、全局数组，编译器都能够在段或常量数组为其分配适当的存储空间。由于整个程序都可以访问这个区域的数据，所以人们认为使用这种存储数据会破坏程序的结构化体系。此外，在全局内存空间出现的缓冲区溢出问题，往往将覆盖在内存中相同位置的变量或缓存（请参阅本书7.2节的案例）。
- 栈空间，由程序分配的存储区域。它是由编译器自动分配、释放的存储区域，用于存放函数的参数和局部变量。在特定情况下下，局部变量可能被其他指针访问（局部变量的指针传递给被调用函数）。在指令层级，“分配和释放栈空间的实质就是调整SP寄存器的值，因分配和释放栈空间的速度非常快。
- 编译器只能为那些在编译阶段确定大小的局部变量划分栈空间。因此，无事事先预留存储空间的缓冲型数据类型，即缓冲区和动态数组不会被分配到栈空间里。在栈空间发生的缓冲区溢出问题，通常会改栈里的重要数据（请参阅本书18.2节的案例）案例）。
