# # 第47章 字符串剪切

本章介绍的程序，专门用于去除字符串的结尾的回车和换行字符CR/LF。

```
#include <stdio.h>
#include <string.h>

char* str_trim(char *s)
{
    char c;
    size_t str_len;

    // work as long as \r or \n is at the end of string
    // stop if some other character there or its empty string;
    // (at start or due to our operation)
    for (str_len=strlen(s); str_len>0 && (c=s[str_len-1]); str_len--)
{
        if (c=='\r' || c=='\n')
            s[str_len-1]=0;
        else
            break;
    }

    return s;
}
```
