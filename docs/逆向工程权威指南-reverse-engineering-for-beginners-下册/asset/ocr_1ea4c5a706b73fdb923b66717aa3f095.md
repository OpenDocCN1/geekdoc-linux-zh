• X30。链接寄存器/LR (link register)。

• X31。这个寄存器一直为0，又称为XZR、“零寄存器”。它的32位 (word型)部分还叫叫WZR。

• SP，64位系统有独立的指针寄存器，不再使用通用寄存器。

详细内容请参照官方的ARM《Procedure Call Standard for the ARM 64-bit Architecture (AArch64)》(http://infocenter.arm.com/help/topic/com.arm.doc.ihi0055b/IHI0055B_aapcs64.pdf)

# B.5 指令

ARM64的部分指令存在对应的、带S后缀的指令。这个后缀代表着该指令会根据结果设置相应的标识位，而不带S后缀的指令就不会设置标识位。以ADD和ADDS指令为例，前者只进行数学运算而不会设置标识位。这种功能则为ARM系统的预处理功能提供了可靠的保证，不会意外影响到CMP指令和其他条件转移所需的各标识位。
