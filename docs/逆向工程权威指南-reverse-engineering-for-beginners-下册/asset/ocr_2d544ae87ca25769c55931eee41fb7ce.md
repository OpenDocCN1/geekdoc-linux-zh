首先，iload_0指令是提取外来的第0个函数参数，再把它压入栈中，而iconst_2指令是将数值2压入栈中。这两个指令执行完，函数的存储内容将如下所示：

```
+----+
TOS ->| 2 |
+----+
| a |
+----+
```

TOS是“Top Of Stack”的缩写，即栈顶。

idiv指令是从栈顶取出这两个值并进行除法运算，然后把返回的结果保存在栈顶。

```
+----------------------+
TOS ->| result |
+----------------------+
```

return指令会提取栈顶的数据、把它作为返回值传给调用方函数：

```
public class calc

    {
        return a/2.0;
    }
}
```
