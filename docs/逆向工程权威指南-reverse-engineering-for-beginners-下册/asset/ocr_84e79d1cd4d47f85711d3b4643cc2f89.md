```
void bzero(uint8_t* dst, size_t count)
{
    int i;

    if (count&~7)) {
        // work out 8-byte blocks
        for (i=0; i<count>>3; i++++) {
            *(uint64_t*)dst=0;
            dst=dst+8;
        }
    }

    // work out the tail
    switch (count & 7) {
        case 7: *dst++ = 0;
        case 6: *dst++ = 0;
        case 5: *dst++ = 0;
        case 4: *dst++ = 0;
        case 3: *dst++ = 0;
        case 2: *dst++ = 0;
        case 1: *dst++ = 0;
        case 0: // do nothing
            break;
    }
}
```

我们来看看这个计算是如何完成的。处理内部内存区域的大小是64位数据，它分为两个部分。

| 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|--|
| ... | B | B | B | B | B | S | S | S |

备注:B代表大小8字节的内存，S代表大小不足8字节的尾部内存。

当我们将输入的内存的大小除以8，其实就是该值右移3位。然而不足8字节的内存总数，即通过减法计算的余数，恰恰是刚刚移出去的最后一个三位。可见，把目标空间大小/变量count右移3位，可得它包含多少个8字节的内存；线性变量counter与数字7进行逻辑与运算可得它有多少字节的尾部内存。
