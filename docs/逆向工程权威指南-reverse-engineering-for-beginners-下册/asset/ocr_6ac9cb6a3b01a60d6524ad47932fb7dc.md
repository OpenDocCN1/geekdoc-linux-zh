# 68.2.1 术语

+   * 模块Module: 它是单独的exe或者dll文件。

+   * 进程Process: 加载到内存中正在运行的进程，通常由一个exe文件和多个dll组件组成。

+   * 进程内存Process memory: 每个进程都有完全属于自己的，进程独立的，不被干扰的虚拟空间。通常是模块、堆、栈等数据构成。

+   * 虚拟地址VA (Virtual Address) : 程序访问存储器的逻辑地址。

+   * 基地址Base Address: 进程中加载模块的基地址。

+   * 虚拟地址RVA (Relative Virtual Address): 虚拟地址VA与基地址Base Address的差就是相对地址RVA。在PE文件中的很多地址都是相对地址RVA。

+   * 导入地址 IAT (Import Address Table): 导入符号的地址组。PE头部的IMAGE_DIRECTORY_ENTRY_IAT指向第一个导入地址IAT的开始位置。值得说明的是，反汇器工具可能会给IAT构造一个伪段-idata段，即使IAT是其他地址的部分。

+   * 导入符号名称IAT (Import Name Table): 存储着符号的名字组。

# 68.2.2 基地址

在开发各自的DLL动态链接文件时，多个团队会有意意让其他人调整自己的动态库基址，具体就是“谁的DLL应该加载到哪个地址”这种问题，却没有公开的协议或约定。

当，两个DLL具有相同的基地址时，只有一个DLL会被真正加载到基地址上。而另一个DLL会被分配到内存中的某段虚拟空间。在调用后时，每个虚拟地址都会被重定向。

通常来说，MSVC编译的可执行文件的基地址是0x400000，而代码段则从0x401000开始。由此，可代码段的相对地址RVA的基地址就是0x1000。MSVC通常将DLL的基地址址为0x1000000。

操作系统可能会将模块加载到不同的基地址中，这样可能是程序本身的要求。程序“点名”使用地址空间随机化（Address Space Randomization, ASLR）技术将其各个模块加载到随机的基地址上。
