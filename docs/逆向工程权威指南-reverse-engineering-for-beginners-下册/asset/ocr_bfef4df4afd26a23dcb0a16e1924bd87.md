# 5.3 典型栈的内存存储格式

在32位系统中，在程序调用函数之后、执行它的第一条指令之前，栈在内存中的存储格式一般如下所示。

| ... | ... |
| --- | --- |
| ESP-0xC | 第2个局部变量，在IDA里标记为var_8 |
| ESP-8 | 第1个局部变量，在IDA里标记为var_4 |
| ESP-4 | 保存的EBP值 |
| ESP | 返回地址 |
| ESP+4 | arg1，在IDA里标记为arg_0 |
| ESP+8 | arg2，在IDA里标记为arg 4 |
| ESP+0xC | arg3，在IDA里标记为arg 8 |
| ...... | ...... |

# 5.4 栈的噪声

本书经常会使用“噪声”、“脏数据”这些词汇。它们怎么产生的呢？待函数退出以后，原有空间里的局部变量不会被自动清除。它们就成了栈的“噪声”、“脏数据”。我们来看看下面这段代码。

```
#include <stdio.h>

void f1() 
{
    int a=1, b=2, c=3;
}

void f2() 
{
    int a, b, c;
    printf("%d, %d, %d\n", a, b, c);
}

int main() 
{
    f1();
}
```
