；运算结果存储到ST(0)寄存器

```
fstp	QWORD PTR [esp] ;把ST(0)拷贝，printf()调用
	push	OFFSET $SG2651
	call	_printf
	add	esp, 12
	xor	eax, eax
	pop	ebp
	ret	0
_main
```

FLD指令是在数据段（SEGMENT）和FPU的内存间交换数据的指令。
FLD把内存内的数据送到FPU的内存，而FSTP把FPU栈顶的数据复制到内存中。pow()函数是从内存读取两个参数进行计算，并将结果（x的次方）存储在ST(0)寄存器中。之后，printf()函数从内存中读取8个字节的数据，再以双精度浮点的形式输出。

此外，这个例子还可以直接使用MOV指令把浮点数据从内存复制到FPU的内存。内存本身就将浮点数据存储为IEEE 754的格式，而pow()函数所需的参数就是这个格式的参数，所以此处没有格式转换的。下一节的例子就会用到这个技巧。
