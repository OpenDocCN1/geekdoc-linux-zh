# 我们启用MSVC 2008的优化选项/0x/0b编译上述程序，再查看函数box::dump()的代码。

```
?dump@QAEXXZ PROC ; box::dump, CODAT
; _this5 = ecx
mov eax, DWORD PTR [ecx+12]
mov edx, DWORD PTR [ecx+8]
push eax
mov eax, DWORD PTR [ecx+4]
mov ecx, DWORD PTR [ecx]
push eax
push edx
push eax
; 'is is box.color=%d, width=%d, height=%d, depth=%d, 0Ah
00H
    push ??_C@0_DG@NCNGAADL@this?is5box?4?5color?$DN
$CFD0?width=$DN?$CFD2@
    call printf
    add esp, 0
    ret
?dump@box@QAEXXZ ENDP ; box::dump
```

这个表格显示了类的变量在内存中的偏移量的分布情况。

| offset | description |
|---|---|
| +0x0 | int color |
| +0x4 | int width |
| +0x8 | int height |
| +0xC | int depth |
