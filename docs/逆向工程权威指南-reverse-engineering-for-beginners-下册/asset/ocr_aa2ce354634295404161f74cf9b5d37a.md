```
= dword ptr -1Ch
sub esp, 1lCh
mov [esp+1lCh+s], offset aHello ; "hello"
call _puts
add esp, 1lCh
retn
endp
```

在打印字符串 "hello world"的时候，这两个指针的地址实际
上是相邻的。在调用的puts函数进行输出时，函数本身并不知道它
所输出的字符串分为两个部分。实际上我们在编译清单中可以看到
这这两个字符串并没有被“切实”分开。

在f1()函数调用puts()函数时，它输出字符串“world”和外加结
符（数值为零的1个字符），由于puts()函数不知道字符串可以和
前面的字符串串连起来形成最终的字符串。

GCC编译器充分分链这种技术来节省内存。
