# 18.5.6 数组溢出

本例参数的取值范围是0~11。如果输入值为12，会发生什么情况？虽然查询里没有对应的值，但是程序还是会计算、取值并返回结果，只是返回值不可预料。如果其他函数访问这种越界边界的地址，那么在读取字符串时可能会引发溢出崩溃。
