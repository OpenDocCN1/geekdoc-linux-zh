# 第60章 检索关键指令

如果一个程序使用了数目多的FPU (Float Point Unit

以Microsoft的表格工具软件Excel为例。我们可能要研究它对录入公式的处理处理方法，例如除操作。

首先要用IDA加载Office2010里的excel.exe（本章以版本号为14.0756.1000的excel为例），然后生成完整的指令清单并将其保存为后缀名为.lst的文本。接下来，我们就可以用终端指令检索指令清单中的全部FDIV指令 (Floating Point Divide, 浮点数除法) 。严格来说，使用grep不能检索出全部的浮点数除法运算指令。如果除数为常数，那么我们编译器就不可能分配FDIV指令。当然这种特例在我们的研究范围内。

```
cat excel.lst | grep fdiv | grep -v dbl_ > excel.fdiv
```

总共有144个匹配结果。

然后，我们在Excel里输入计算“=(1/3)”，并检查每个指令的运行结果。

在调试器（或tracer）里一路排除除法指令以后，我们幸运地发现第14个FDIV指令就是我们要找的指令：

```
.text:3011e919 DC 33
qword ptr [ebx]
PID=13944|TID=28744| (0)02f64e919 (Excel.exe)BASE+0c1e19
```
