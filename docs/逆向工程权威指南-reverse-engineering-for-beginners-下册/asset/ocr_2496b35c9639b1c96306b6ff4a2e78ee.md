| Bit位 (及掩码) | 写法 (及含义) | 描述 |
|---|---|---|
| 6 (0x40) | ZF (零标志位) | ZF 用来反映运算结果是否为0。如果运算结果为0，则其值为1，否则其值为0 |
| 7 (0x80) | SF (符号位) | |
| 8 (0x100) | TF (追踪标识) | 当追踪标志TF被置为1时，CPU进入单步执行方式，每执行一条指令，产生一个单步中断请求。这种方式主要用于程序的调试 |
| 9 (0x200) | IF (中断允许标识) | 中断允许标志用来决定CPU是否响应外部的屏蔽中断请求。CLI/STI指令可对其进行赋值 |
| 10 (0x400) | DF (方向标识) | 决定在执行串操作指令（REP MOVSx、REP CMPsx、REP LODsx和REP SCASx）时有关寄存发生调整的方向。CLD/STD指令可对其进行赋值 |
| 11 (0x800) | OF (溢出标识) | |
