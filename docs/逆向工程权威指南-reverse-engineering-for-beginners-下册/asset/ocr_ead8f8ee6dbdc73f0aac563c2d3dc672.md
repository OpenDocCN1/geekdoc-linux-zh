# 第五部分
在代码中发现重要而有趣的内容

目前的软件往往庞大，可以说，极简主义不是现代软件的突特性。但是这并不是当下的程序员写的程序代码行多了，而是因为很多的库都转移至可执行文件静态链接在了一起。如果所有的外部库都转移至外部动态链接库DLL的话，那么可能情况就会所有不同（对于C++而言，另外的一个理由是静态模板库STL以及其他的模板库文件）。

因此，确定函数的来源很重要，或者其来自标准库或者通用库（类似Boost和libpng），或者是与我们要找的代码相关。

为了我们的代码而重新编写代码是有些荒谬的。

对于一个编译的工程师来说，一个主要的工作是快速地发现他要找的代码。

反编译工具IDA能我们在字符串、单元以及常数中搜索字符串。这个工具甚至能将代码输出到lst或asm文件中，进而可以采用grep和awk等命令处理字符串。

当想要知道某些代码是些做什么的时候，它可能采用一些开源的库（类似上面提到的libpng），因此当你看到某些变量、常数或者字符串很熟悉时，可以用Google搜索一下。如果发现一个开源工程在使用时，就可以拿来比较。这样的话，也能解决一部分问题。
