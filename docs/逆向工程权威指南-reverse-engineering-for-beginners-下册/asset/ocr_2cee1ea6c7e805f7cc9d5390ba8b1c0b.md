# 第34章 哈希函数

哈希(hash)函数能够生成可靠性较高的校验和(Checksum)，可充分满足数据校验的需要。CRC32算法就是一种不太复杂的算法，哈希值是一种固定长度的信息摘要，从化学的角度看，可以根据哈希值反向向“推测”信息原文。所以，无论CRC32算法计算的信息有多长，它只能生成32位的校验和。但是从加密学的角度看，我们可以轻易地伪造出相同CRC32哈希值的原文。当然，防止伪造就是加密哈希值（多个哈希函数（Cryptographic hash function））的任务了。

此外，人们普遍使用MD5、SHA1等哈希算法生成用户密码的哈希值，然后把密码存储在数据库中。实际上在网上论坛等涉及用户密码的数据库中，存储的哈希信息并不都是用户密码的哈希值否则容易发生数据泄露等问题，入侵人员能够轻易获取密码原文。我们不如此，当用户登录网站时，网络论坛等应用程序校验的并不是密码，而是校验的是哈希值：如果用户名和哈希值与数据库中的记录匹配，它将被授予用户访问相应的访问权限。此外，常见的密码破解工具都是通过穷举密码的方法，查找符合密码哈希值的密码原文而已。其他类型的密码破解工具就要复杂多了。

# 单向函数与不可逆算法

单向函数（one-way function）是一种具有下述特点的单射函数：对于每一个输入，哈希值容易计算（多项式时间）；但但是根据函数值对原始输入进行逆向推算就比较困难（无法在多项式时间内内使用确定性图灵机计算）。本节将重解释的不可逆性。
