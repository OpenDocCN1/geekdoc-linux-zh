    int[] a = new int[5][10];
    a[1][2]=3;
}

为了展示效果，我们在这里创建一个大小为10×5的整型二维数组，采用指令的new int[5][10]

Java使用multinanewarray指令创建多维数组。本例通过iconost_5和 bipush指令将各维度的值推送到栈中，再使用multinanewarray声明数组类型（常量解析池2）和数组维度（2）。
