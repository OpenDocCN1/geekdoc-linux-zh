# 57.1.4 Base64

Base64编码十分流行，是将二进制数据转换为字符文本字符串的常用标准。本质上，这种算法可以用4个字符封装3个二进制字节。它的字符集包括26个拉丁字母（含大小写）、0~9个数字、加号“+”和反斜杠“”，总共66个字符。

Base64编码的一个显著特征是它通常（但不一定）以1到2等号“=”为结尾。

比如以下两个Base64编码：

```
AVjBBVsVfcmUlxvjaMjgNtEuRWBbxynyj8dpnLZW8aKG3V4y0OIQcuQT+eQAP91AOuwSwv=
AVjBBVsVfcmUlxvjaMjgNtEuRWBbxynyj8dpnLZW8aKG3V4y0OIQcuQT+eQAP91AOuw==
```

可以肯定的，等号“=”不会出现在Base64编码字符串中的。

# 57.2. 调试信息

对于逆向分析来说，程序中的调试信息非常重要。在某种程度上，调试信息能够程序正在运行的状态。调试信息通常由printf()/debug/调试函数显示出来，或者被输出到调试文件中。在发布版/非调试版的软件中，即使使用命令行调用了相关的调试函数，也不会有任何实质性的输出内容。如果调试信息的调试器内存中包含局部变量或全局变量的信息，那么即使工程师就算到了——我们至少知道了变量的名称。例如，我们可以通过调试器信息确定Oracle RDBMS有一个函数叫做ksdwrt()

有实际意义的字符串通常是逆向分析的重点。IDA反汇器可以显示字符串的调用函数和调试指令。熟练掌握分析之后，您可能会找到一些有趣的东西（可以参考https://yuriche.com/blog/

)。

错误信息有时非常重要。Oracle RDBMS 构造了一系列函数专门处理错误信息。感兴趣的读者可以访问https://yuriche.com/blog/

了解详细信息。
