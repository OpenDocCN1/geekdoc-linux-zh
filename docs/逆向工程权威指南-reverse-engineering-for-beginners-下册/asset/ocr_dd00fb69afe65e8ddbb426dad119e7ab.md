# 41.5.2 变位系数#2

变位系数确实可能为零：

```
mov      eax, 55555556h ; 1431655776
imul     ecx
mov      eax, edx
shr     eax, 1Fh
```

这样，计算除数的方法就更简单了：

$D = \frac{2^{32}}{M}$

就本例而言，除数的计算方法是：

$D = \frac{2^{32}}{1431655776}$
