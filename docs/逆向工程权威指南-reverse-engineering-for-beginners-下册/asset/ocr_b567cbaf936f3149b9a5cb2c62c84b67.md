```
R0 = R1*R0 = 10*month
LDR r1,|L0.68|
```

# 指令清单18.36 Optimizing GCC 4.9 ARM64

```
W0 = month
sxtw sign-extended input value
X0 = adrp x1,:LANCHOR1
add x1,x1,:102::LANCHOR1
X1 = pointer to the table
add x0,x0,lsl 2
X0 = X0+X0<<2 = X0*4 = X0*5
add x1,x1,lsl 1
X0 = X1+X0<<1 = X1*2 = pointer to the table + X0*10
ret
```

SXTW指令将32位有符号数据扩展到64位有符号数据，并将存储于X0寄存器。ADRP/ADDI对对负责组成地址。ADDI指令中的LSL后续用于乘法运算。
