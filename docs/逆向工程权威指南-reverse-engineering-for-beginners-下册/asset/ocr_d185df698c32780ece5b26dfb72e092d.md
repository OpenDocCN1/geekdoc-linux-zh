# 第52章 数组与负数索引

数组的负数索引值完全不阻寻址。例如，array[-1]实际表示数组array起始地址之前的存储空间！

这种技术的用途相当有限。笔者认为除了本章范例的这种场景之外，应该没有领域用得上这项技术了。众所周知，在表示数组的第一个元素时，C/C++使用的下标可能是0，而其他编程语言（FORTRAN等）使用的数组下标可能是1。在移植代码的时候，可能会忽视这种问题。此时借助负数索引值就可以查找C/C++数组中的第一个元素。

```
#include <stdio.h>

int main() {
    int random_value=0x11223344;
    unsigned char array[10];
    int i;
    unsigned char *fakearray=&array[-1];

    for (i=0; i<10; i++) {
        array[i]=i;
    }

    printf("first element %d\n", fakearray[1]);
    printf("second element %d\n", fakearray[2]);
    printf("last element %d\n", fakearray[10]);

    printf("array[-1]=%02X, array[-2]=%02X,
    array[-3]=%02X, array[-4]=%02X\n",
    array[-1],
    array[-2],
    array[-3],);
```
