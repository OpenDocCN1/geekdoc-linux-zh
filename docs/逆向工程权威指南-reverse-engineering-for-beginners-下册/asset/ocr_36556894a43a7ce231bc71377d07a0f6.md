# 21.3.4 数组替代

在内存中，结构体是依次排列的一系列数据。为了它的它的特性，我们对指令清单21.8的程序进行少许修改，使用数组替代tm结构体:

```
#include <stdio.h>
#include <time.h>
void main() {
    int tm_sec, tm_min, tm_hour, tm_mday, tm_mon, tm_year, tm_wday, tm_yday, tm_unix_time=NULL);

    localtime_r(&tm_unix_time, &tm_sec);
    printf("Year: %d\n", tm_year-1900);
    printf("Day: %d\n", tm_mday);
    printf("Hour: %d\n", tm_hour);
    printf("Minutes: %d\n", tm_min);
    printf("Seconds: %d\n", tm_sec);
}
```
