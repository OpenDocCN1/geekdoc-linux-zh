```
; 4.1 in IEEE 754 form:
dword_364 DCD 0x66666666 ; DATA XREF: f+A
dword_368 DCD 0x40106666 ; DATA XREF: f+C
; 3.14 in IEEE 754 form:
dword_366 DCD 0x55EB851F ; DATA XREF: f+1A

```

Keil生成的Thumb程序使用NEON运算和FPU浮点运算。Thumb程序使用两个通用的R字母寄存器传递精点浮点数据。因为不再使用FPU的专用指令，所以这类程序必须调用底层函数（例如__aedi_dmul、__aedi_ddadd,__aedi_ddadd）“仿真”浮点运算。“仿真”意义上的模拟运算，速度虽然比FPU处理器的快，但是依赖于本体。

在早期处理浮点器还需昂贵的奢侈品的时候，x86平台的浮点仿真运算的库函数曾经盛行一时的。

在ARM系统中，FPU仿真序列叫作“软点/soft float”或者“armel”，通过硬件的FPU指令叫作“硬点/hard float”或“armhf”。
