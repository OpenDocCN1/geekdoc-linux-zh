## main

### 指令清单14.3 Optimizing MSVC

在开启优化选项 (/Ox)后，MSVC的编译结果如下。

```assembly
_main  PROC
push        esi
mov         esi, 2
$LL3:
push        esi
call        printing_function
inc         esp, 4
add         esp, 4
cmp         esi, 10  ; 000000a8
jl         SHORT $LL3
xor         eax, eax
pop         esi
ret         0
ENDP
```

在开启优化选项后，ESI寄存器为了局部变量作为专用寄存器；而在通常情况下，局部变量都应当位于顶部。编译器会在局部变量为众多的情况下进行优化的。

进行这种优化的前提条件是：被调用函数应当修改局部变量专用寄存器的值。显然，在本例中编译器能够判断函数 printing_function() 不会修改ESI寄存器的值。在编译器决定局部变量分配到专用寄存器时，它会在函数序言部分保存这些特殊的寄存器的初始状态，然后在函数尾声里还原这些寄存器的原始值。因此，您在本例main()函数的序言和尾声中分别分别看到 PUSH ESI/POP ESI 指令。

现在开启GCC 4.4.1的最深程度优化选项-O3，看看会生成的汇编指令。

### 指令清单14.4 Optimizing GCC 4.4.1

```assembly
main            proc near
var_10      = dword ptr -10h
               push    ebp
               mov     ebp, esp
               and     esp, 0xFFFFFF0
               sub     esp, 10h
               mov     [esp+10h+var_10], 2
               call    printing_function
               mov     [esp+10h+var_10], 3
               call    printing_function
               mov     [esp+10h+var_10], 4
               call    printing_function
               mov     [esp+10h+var_10], 5
               call    printing_function
               mov     [esp+10h+var_10], 6
               call    printing_function
               mov     [esp+10h+var_10], 7
               call    printing_function
               mov     [esp+10h+var_10], 8
               call    printing_function
               mov     [esp+10h+var_10], 9
               call    printing_function
               xor     eax, eax
               leave
               retn
               endp
```

GCC把我们的循环指令展开（分解）了。

编译器会对迭代次数较少的循环进行循环展开 (Loop unwinding) 处理。展开循环会以后代码的执行效率有所提升，但是会增加程序代码的体积。

编译经验表明，展开循环较大的循环结构并非良策。大型函数的缓存耗费的内存占用 (cache footprint) 较大。[1]。

我们将变量的最大值调整到100，看看GCC是否还会分解循环。


这就与MSVC 2010 /O2编译出来的代码差异不多。唯一的区别是，GCC用EBX寄存器当变量的专用寄存器。因为GCC能够判断后面的函数调用不会修改这个专用寄存器的值，所以它才会这样分配寄存器。在GCC不能进行相应调整，但是当决定局部变量分配专用寄存器的时候，它就会使用局部变量的那个函数序言和尾部分分别添加相应指令，利用数据保存和恢复专用寄存器的原始值。我们可以在main()函数里看到这种现象：它在函数的序言和尾部分部分别存储和恢复局部变量专用寄存器ebx的原始值。
