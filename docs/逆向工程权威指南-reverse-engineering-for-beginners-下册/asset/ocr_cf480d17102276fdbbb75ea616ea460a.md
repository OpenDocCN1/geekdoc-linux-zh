# 第58章 调用宏assert()（中文称为断言）

一般来说，assert() 宏在可执行文件中保留了源代码的文件名、行数以及执行条件。

最有价值的信息是assert()宏的执行条件。我们可以通过它们来推断变量名或者结构体的字段名称。另一个有用的信息是文件名，通过它我们可以推断源代码是采用什么语言编写的。同时我们还能通过文件名识别出它是否采用了的开源代码库。
