本例中的scanf(x)有两个参数。

第一个参数是一个指针，它指向含有“%d”的格式化字符串。第二个参数是局部变量x的地址。

首先，“lea eax, DWORD PTR x_[ebp]”指令将变量x的地址放入EAX寄存器。“lea”是“load effect address”的缩写，能够将源操作的有效地址（offset）传送到给出的（第一个参数）x。[1]

此处，将EAX寄存器的值与x求值，然后使用EAX寄存器存储这个计算结果；也就是等于 lea eax, [ebp-4]

就是，程序会对EAX寄存器的值减去x，并把这个结果存储到EAX寄存器。将EAX寄存器的值推入栈内存后，程序开始调用scanf(x)函数。

在调用printf()函数之前，程序传给它第一个参数，即格式化字符串“You entered %d...\n”的指针。

```
printf(x)所需的第二个参数通过“mov ecx, [ebp-4]”间接取值。传递ecx的值是ebp-4指向的地址的值（变量x的值），而不是ebp-4表达的地址。
```

此后的指令将ecx推入栈内存，然后启动printf(x)函数。
