```
; prepare B in RAX for return:
mov ra, rsi
; if A>=B, put A (RDI) in RAX for return.
; this instruction is idle if otherwise (if A<B)
cmovge ra, rdi
ret

my_min:
; RDI=A
; RSI=B
; compare A and B:
c rdi, rsi
; prepare B in RAX for return:
mov ra, rsi
; if A<=B, put A (RDI) in RAX for return.
; this instruction is idle if otherwise (if A>B)
cmovle ra, rdi
ret
```

MSVC 2013的编译方法几乎一样。它相当于ARM指令集中的MOVcc指令，以及x86平台的CMOVcc指令。它只是名字不同：“Conditional Select”。
