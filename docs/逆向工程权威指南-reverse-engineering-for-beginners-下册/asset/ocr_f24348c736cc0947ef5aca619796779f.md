# 第87章 Oracle的MSDB文件

在解决问题时，如果理解已经是已知的，那么你总会有章可循。

> 《墨菲律——精确的法则》

Oracle的MSDB文件是一种含有错误信息和相应错误编号的二进制文件。本章将与你共同研究它的文件格式，尝试解读其中的原始数据。

Oracle RDBMS提供专门的、文本格式的错误信息文件，并不是每个MSDB文件都有对应的、文本格式的错误信息文件，所有都需要将二进制文件和信息文本进行转换分析。
