# 第74章 修改任务管理器 (Vista)

如果主机上安装的是四个CPU，那么Windows任务管理器应当通过GetSystemInfo()函数确保显示出4个CPU的性能计划图。本章将要微调任务管理器，让它显示更多的CPU运行核心。

首先需要了解的问题是：任务管理器如何知道CPU有多少个运算核心？虽然GetSystemInfo()函数可以确保反馈这一这一信息，但是任务管理器taskmgr.exe没有直接输入这个函数。多次通过NTAPI中的NtQuerySystemInformation()函数获取的各种系统信息，也是通过后者来理解具体的状况。

NtQuerySystemInformation()函数有四个参数：第一个参数是查询的系统类型；第二个参数是指针，这个指针用于返回的HandleList；第三个参数是程序员指定给HandleList的内存空间；第四个参数是NtQuerySystemInformation返回的HandleList的大小。

获取CPU信息，就要获取它的时候把第一个参数设置为常量SystemBasicInformation[2]。

我们要将它的调用指令拆解为“NtQuerySystemInformation(O, ?, ?, ?)”。第一步使用IDA打开taskmgr.exe文件。在微软官方的程序过程中，IDA能够与与之相关的PDF文件并显示所有函数名称。这是易见的，任务管理器是用C++编写的，而且它使用的函数名称和类（class）类名是不为人知的。在它使用的类名中，我们可以看到Adapter、CNet、CPerPage、CProc、CsvcPage、TaskPage和UserPage。这些类名称和任务管理器程序窗口的标签（tab）有对应关系。
