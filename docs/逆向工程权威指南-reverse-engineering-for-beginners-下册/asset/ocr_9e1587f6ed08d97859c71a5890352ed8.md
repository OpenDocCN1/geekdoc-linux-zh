ESP+0xC arg3,它在IDA里为arg_8

本书第64章将详细介绍有关的调用约定（Calling conventions）。要注意的是，程序员可以使用栈来传递参数，也可以不使用栈传递参数。参数处理并没有相关的硬性规定。

例如，程序员可以在heap中分配内存并用之传递参数。在堆中引入参数后，可以使用EAX寄存器为函数传递参数。这种做法确实可行。[6]只是在x86系统和ARM系统中，使用栈处理参数已经成为了为了约定的习惯，而且它的确十分方便。

另外，被调用函数并不知道外部向它传递了多少参数。如果函数处理的参数数量可，它就需要需要说明（许多以%号开头）进行格式化说明、明确参数信息。我们来看的printf()函数如下：

```
printf("%d %d", 1234);
```

这个命令告诉printf显示1234，而且会让它显示数据帧内1234之后的地址的随机数。

由此可见，声明main()函数的并不是并不那么重要。我们可以将之声明为main(),main(int argc, char *argv[])或main(int argc, char *argv[], char *envp[])；

```
push envp
push argv
push argc
call main
```

即使我们没有程序里声明main()函数使用哪些参数，程序还可以运行；参数依赖留在栈里，是不会被调用函数用掉了。如果main()函数声明为main(int argc, char *argv[])，程序就能访问到前两个参数，但仍然无法使用第三个参数。除此之外，也可以声明为main(int argc)，函数相同一样可以运行。
