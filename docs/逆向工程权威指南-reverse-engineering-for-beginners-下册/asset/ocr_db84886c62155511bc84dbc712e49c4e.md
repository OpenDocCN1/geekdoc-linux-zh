32位错误代码的具体含义，如下图所示。

| | Facility code | Error code |
|---|---||
| S U0 | | |

S是最高的两位（第30、31位），为基本的状态代码，一共有4种组合，分别为11、10以及00。它们分别的意义是：11代表错误，10代表警告，01代表信息，00代表成功。

U是第29位（第29位），它只有0和1两种状态，代表该异常是否属于用户侧异常。
