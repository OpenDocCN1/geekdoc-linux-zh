
## 41.4.1 更多的理论

其实，我们都知道，乘法和除法是互逆运算。因此下面的除法可以用乘法来代替。我们可以表示为

```
$\frac{x}{c} = x * \frac{1}{c}$
```

1/c可以称为乘法的逆运算，是c的倒数。可以用编译器来做提前运算。

但是为了浮点计算用的，有没有整数数呢？在算术计算环境下，是可能会有的。CPU寄存器的长度是非常规整的，因此几乎所有的寄存器的算术操作都是对32位或者对的64位，因此要进行操作。

## 41.5 计算除数

### 41.5.1 位移系数的代码

通常我们看到的代码可能就像这样：

```
mov     eax, MAGICAL CONSTANT
imul    input value
sar     edx, SHIFTING COEFFICIENT ; signed division
by      2using arithmetic shift right
mov     eax, edx
shr    eax, 31
add     eax, edx
```

我们这里用大字母M代表32位的魔术因子，把位移系数标记C，把除数标记为D。

在此除数可以表示为

```
$D = \frac{2^{32+c}}{M}$
```

## 第42章 字符串转换数字函数atoi()

我们重新实现标准的atoi()。这是一个字符串转换为整数的函数。

例1可以按照ASCII表转换为数字。代码没有容错处理，因此输入值为数字字符时，返回值就不会正确。

```c
#include <stdio.h>

int my_atoi(char *s)
{
    while (*s)
    {
        rt=10 + (*s-'0');
        s++;
    }
    return rt;
}

int main()
{
    printf("%d\n", my_atoi("1234"));
    printf("%d\n", my_atoi("123456789"));
}
```

这个算法是从左到右读取，并将每个读取的字符减去ASCII值。我们知道，在ASCII表中，0~9是连续存放的。因此无论“0”对应的数值是多少，“0”减去后是0，“9”减去后是9。按照这种模式，函数可以把字符转换为相应的值。如果读取的字符不是数字，计算结果就不会准确。在处理多数字字符串时还要考虑指数问题，会将前一步的结果（即变量rt）乘以10，再加上转换出来的数字。

## 42.1.1 64位下的MSVC 2013优化

```
s = 8
my_atoi PROC
    ; load first character
    movzx r8d, BYTE PTR [rcx]
    ; EAX is allocated for "rt" variable
    ; its 0 at start
    xor eax, eax
    ; first character is zero-byte, string terminator?
    ; exit.
    test r8b, r8b
    je SHORT my_atoi
    lea edx, DWORD PTR [rax+rt*4]
    ; EDX=RAX+rt*4=rt*5
    movsx eax, r8b
    ; EAX=input character
    ; load next character to R8
    movzx r8d, BYTE PTR [rcx+1]
    ; shift RCX to the next character:
    lea rcx, QWORD PTR [rcx+1]
    lea eax, DWORD PTR [rax+rdx*2]
    ; EAX=RAX+RDX*2=input character + rt*5=character + rt*=10
    ; correct digit by subtracting 48 (0x30 or '0')
    add eax, -48      ; 0xffffffffff
    ; was last character?
    test r8b, r8b
    ; jump to loop begin, if not
    jne SHORT my_atoi

my_atoi: 0
my_atoi ENDP
```

## 42.1.2 64位下的GCC 4.9.1优化

GCC 4.9.1优化更精确，但是它会在代码的最后添加一个多余的返回指令。其实一个RET足够了。

```
my_atoi:
; load input character into EDI
movsx edx, BYTE PTR [rdi]
; EAX is allocated for "rt" variable
xor eax, eax
; exit, if loaded character is null byte
test dl, dl
je .L4
L3:
lea eax, [rax+rax*4]
; EAX=RAX*5=rt*5
; shift pointer to the next character:
add rdi, 1
lea eax, [rdx-48+rax*2]
; EAX=input character - 48 + RAX*2 = input character - '0' + rt*10
; load next character:
movsx edx, BYTE PTR [rdi]
; goto loop begin, if loaded character is not null byte
test dl, dl
jne .L3
rep ret
L4:
rep ret
```

## 42.1.3 ARM模式下Keil 6/2013优化

```asm
my_atoi:
; R1 will contain pointer to character
MOV r1,r0
; R0 will contain "rt" variable
MOV r0,#0
ADD r0,r2,r0,LSL #2 ; R0=R0+R0<<2
ADD r0,r2,LSL #1 ; R0=input character + rt*5 = input character + rt*10
; correct thing by subtracting '0' from rt:
SUB r0,r0,#30
; shift pointer to the next character:
ADD r1,#1
; load input character to R2
LDRB r2,[r1]
; is it null byte? if no, jump to loop body.
CMP r2,#0
BNE exit
; null byte. "rt" variable is still in R0, ready to used in caller function
BX lr
```

## 42.1.4 Thumb模式下Keil 6/2013优化

```
my_atoi PROC
; R1 will be pointer to input character
MOVS r1,r0
; R0 is allocated to "rt" variable
MOVS r0,#0
MOVS r3,#10 ; R3=10
MULS r0,r3,r0 ; R0=R3*R0=rt*10
; shift pointer to the next character:
ADDS r1,r1,#1
; correct line by subtracting '0' character from it:
SUBS r0,r0,#30
ADDS r0,r2,r0 ; rt=R2+R0=input character + (rt*10 - '0')
; load input character to R2
LDR r2,[r1]
; is it zero?
CMP r2,#0
; jump body if it is not
BNE exit
; rt variable in R0 now, ready to used in caller function
BX lr
ENDP
```

## 42.5 ARM64下的GCC 4.9.1优化

```
my_atoi:
; load input character into W1
ldr w1,[x0]
mov x2,x0
; X2=address of input string
; loaded character zero?
; jump to exit if so
; W1 will contain 0 in this case.
; it will be reloaded into W0 at L4.
cbz w1,w1,L4
; W0 will contain "rt" variable
; initialize it at zero:
mov w0,w0,0
L3:
; subtract 48 or '0' from input variable and put result into W3
sub w3,w1,#48
; load next character at address X2+1 into W1 with pre-increment:
ldrb w1, [x2,1]!
add w0, w0, w0, lsl 2
; W0=W0+W0<<2=W0+W0*4=rt*5
add w0, w3, w0, lsl 1
; W0=input digit + W0<<1 = input digit + rt*5*2 = input digit + rt*10
; if the character we loaded is not null byte, jump to the loop begin
cnbz w1, .L3
; variable to be returned (rt) is in W0, ready to be used in caller function
ret
.L4:
mov w0, w1
ret
```

## 42.2 例子

现在，我们将例的源代码改得更一些：令其检测第一个字符是否为负符号“-”，并且检测输入值里没有非数字字符；当输入字符含有非数字字符的时候，要令程序提示错误信息。

```c
#include <stdio.h>

int myatoi(char *s)
{
    int negative=0;
    int rt=0;

    if (*s==''-')
    {
        negative=1;
        s++;
    }

    while (*s)
    {
        if (*s<'0' || *s>'9')
        {
            printf("Error! Unexpected char: %c\n", *s);
            exit(0);
        }
        s++;
    }
    return rt;
}
```

很有趣的是，我们以前学习到的规则是：加法和减法的顺序无所谓先后，完全可以重排。本例利用了这一原则：编译器首次加减法的混合表达式为‘rt*10- '0’，来计算输入字符串与中间差。这种算法的计算结果一定和源代码相同但请忽视编译器的指令重排功能。
