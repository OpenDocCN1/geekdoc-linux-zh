```
lea rcx, OFFSET FLAT:month1
mov rax, QWORD PTR [rcx+*8]
mov 0
get_month1 ENDP
```

上述程序的功能:

+   - 第一条指令将32位数值、连同其符号扩展（sign-extension）扩展为64位整数数据，再存储于RAX寄存器中。ECX存储的“月份”信息是32位整数。因为顺序后还要进行64位运算，所以需要把输入转换为64位整数
- 然后函数把指针的地址存储于RCX寄存器。
- 最后，函数的输入变量（month）的值乘以8，再与指针的地址相加。因为是64位系统的尾缀，每个地址（即指针）的数据需要用64位（即8字节）。所以指针表中的每个元素占据64字节空间。因此，最终字符串的地址要加上month*8。MOV指令不仅完成了字符串地址的计算，而且完成了指针的查询。在输入值为1时，函数将返回字符串“February”的指针地址。

编译器的优化结结果是直接的。

```
movsx rdi, edi
mov rax, QWORD PTR month1[0+*8]
ret
```

# 18.5.2 32位MSC

使用32位MSVC编译器上述程序可以如下所示的指令。

指令清单18.11 Optimizing MSVC 2013 x86

```
_month$ = 8
_get_month1 PROC
mov eax, DWORD PTR _month$[esp-4]
mov eax, DWORD PTR _month1[esp*4]
mov 0
ret
get_month1 ENDP
```

32位程序就不用把输入值转化为64位数据了。此外，32位系统的指针只有4字节数据，所以相关的计算因子变为了4。
