使用加法ADD而不是减法SUB。我们注意到程序中有一行指令是“ADD EAX,-32”，它用来来实现EAX寄存器中减去32的目的。程序没有采用指令“SUB EAX,32”，也就是程序使用了EAX=EAX+(-32)的算法，而不是采用EAX=EAX-32的算法。是否值得这么做的，笔者并不能完全确定。

为了实现“乘以5”的运算使用了LEA指令：lea ccx,DWORD PTR[ecax+*4] 使得“*4”和“*5”是相等的。但是指令运行速度比IMUL快。另外还可以使用指令对—SHL EAX,2和ADD EAX,EAX来代替。确实有些编译器是这样做的。

这里用到了乘法代替除法的技巧。参见第41章。

如果主函数main()没有明确的返回，在程序退出时，它的返回值为0。C99标准中明“如果main函数没有通过明确的return指令声明其返回，那么它就会默认返回0”。当然这项准则仅适用于主函数main()。虽然MSVC并未完全遵循C99标准，但是允许部分编译器遵循了这一标准。这里指的C99标准是ISO07,P.5.1.2.3。

# 35.1.2 x64架构下的MSVC 2012优化

x64的代码和x86的代码大体相同。只是每次调用exit()函数后，有一个INT 3。

```
xor     ecx, ecx
call    QWORD PTR __imp_exit
int     3
```

INT 3是调试器debugger的断点设置不会。

程序执行exit()函数之后，它就不会再回到原程序，而是直接退出了。编译器默认是，在发生异常退出的情况下，通常人们使用调试器分析异常情况吧。
