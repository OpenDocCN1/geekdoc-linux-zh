# 第9章 返回值

在x86系统里，被调用函数返回值类型通常通过EAX寄存器返回运算结果。
[1]若返回值为byte或char类型数据，则返回值将存储在EAX寄存器的低8位——AL寄存器存储返回值。如果返回值是浮点型数据，那么返回值将存储在FPU的ST(0)寄存器里。ARM系统的情况相对简单一些，它通常使用R0寄存器返回返回值。

# 9.1 void类型函数的返回值

函数main()的数据类型通常是void而不是int，程序如何处理返回值呢？

调用main()函数的有关代码大致会是这样的:

```
push envp
push argv
push argc
call main
push eax
call exit
```

将其转换为源代码，也就是：

```
exit(main(argc, argv, envp));
```
