+   ○ q-quad(64位)
○ l指代32位long型数据。
○ w指代16位word型数据。
○ b指代8byte型数据。

+   其他区别参考Sun公司发布的x86 Assembly Language Reference Manual。

现在再来说hello world的AT&T语言指令，就会发现它和IDA里看到的指令没有区别区域。有些人可能注意到，用于数据对齐的0FFFFF0h在由自己制的框架的$-16——把它们按照32byte型数据进行书写后，就会发现两者完全一致。

此外，在外的main()时，处理EAX寄存器的指令是MOV指令而不是XOR指令。MOV的作用是给寄存器赋值(load)。某些硬件框架的指令集有更为直观的“LOAD”、“STORE”之类的指令。
