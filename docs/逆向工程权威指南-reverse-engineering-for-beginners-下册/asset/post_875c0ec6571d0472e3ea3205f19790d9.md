# 第18章 数组

在内存中，数组就是按顺序排列的相同类型的数据。

## 18.1 简介

```c
#include <stdio.h>

int main() {
    int a[20];
    int i;

    for (i=0; i<20; i++) {
        a[i]=i*2;
    }

    for (i=0; i<20; i++) {
        printf("%d=%d\n", i, a[i]);
    }
    return 0;
}
```

## 18.1.1 x86 MSVC
使用MSVC编译上述程序可以所示的指令。指令清单18.1 MSVC

```assembly
_TEXT    SEGMENT
ni$ = -84      ; size = 4
as = -80      ; size = 8
_main   PROC
        push    ebp
        mov     ebp, esp
        sub     esp, 84 ; 0000054H
        mov DWORD PTR [ebp-4], 0
        jmp     SHORT LN6main
        mov     eax, DWORD PTR [ebp-4]
        add     eax, 1
        mov DWORD PTR [ebp-4], eax
$LN6main:
        cmp DWORD PTR [ebp-4], 20 ; 0000014H
        jge     SHORT LN4main
        mov     ecx, DWORD PTR [ebp-4]
        shl     ecx, 1
        mov     edx, DWORD PTR [ebp-4]
        mov DWORD PTR [ebp+edx*4], ecx
        jmp     SHORT LN5main
$LN4main:
        mov DWORD PTR [ebp-4], 0
        jmp     SHORT LN3main
$LN2main:
        mov     eax, DWORD PTR [ebp-4]
        add     eax, 1
        mov DWORD PTR [ebp-4], eax
$LN3main:
        cmp DWORD PTR [ebp-4], 20 ; 0000014H
        jge     SHORT LN1main
        mov     ecx, DWORD PTR [ebp-4]
        mov     edx, DWORD PTR [ebp+ecx*4]
        push    edx
        mov     eax, DWORD PTR [ebp-4]
        push    eax
        push    OFFSET SSG2463
        call    printf
        add     esp, 12 ; 000000CH
        jmp     SHORT LN2main
$LN1main:
        xor     eax, eax
        mov     esp, ebp
        pop     ebp
        ret
_main:
    ENDP
```

这里除去两个循环之外没有非常特别之处。第一个循环填充数据，第二个循环打印数据。“shl ecx, 1”指令所做的运算是ecx=ecx*2，更详细的介绍参见16.2.1节。

程序为数组申请了80字节的空间，以存储20个字符元素。
