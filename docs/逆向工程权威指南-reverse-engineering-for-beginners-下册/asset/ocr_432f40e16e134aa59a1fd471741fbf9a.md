# Optimizing Keil 6/2013 (Thumb模式)

```
.text:00000042 scanf_main
.text:00000042 var_8 = -8
.text:00000042
.text:00000042 08 B5 PUSH {R3,LR}
.text:00000044 A9 A0 ADR R0, aEnterX
.text; "Enter: %d\n"
.text:00000046 06 F0 D3 F8 BL _2printf
.text:00000049 69 46 MOV R1, SP
.text:0000004C AA A0 ADR R0, aD
.text:0000004E 06 F0 CD F8 BL _0Oscf
.text:00000052 09 99 LDR R1,
.text:00000055 A9 A0 ADR R0,aEnteredd ; "You entered %d...\n"
.text:00000056 06 F0 CB8 BL _2printf
.text:0000005A 00 20 MOVS R0, #0
.text:0000005C 08 BD POP {R3,PC}
```

scaf() 函数需要像借指针一样传递返回值。在本例中，编译器给它分配了一个整型变量的空间。整型变量占用4个字符的存储空间。但是返回数据的地址，可以直接指向CPU的寄存器。在生成的汇编代码中，变量x存在于数据中，被标记为R8。然后，此时程序完全可以直接使用。栈指针SP指向的存储空间，没有必要像上述代码那样手动调整SP分配空间。此后，程序把栈指针SP（x的地址）存入R1寄存器，再将格式化字符串的偏移量入R0寄存器，如此一来，scaf()函数获得了它所需要的所有参数。在此之后，程序使用LDR指令将返回的值还原到R1寄存器，以供printf()调用。

即使使用Xcode LLVM 程序在ARM编译这段程序，最终生成的汇编代码没有实质性的区别，此处就不再演示。
