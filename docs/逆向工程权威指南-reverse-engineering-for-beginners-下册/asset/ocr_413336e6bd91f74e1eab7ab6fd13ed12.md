# 28.3.2 ARM64

```
uint64_t f()
{
    return 0x12345678ABCDEF01;
};
```

> 指令清单28.3 GCC 4.9.1 -03

```
mov    x0, 61185    ;0xef01
movk   x0, 0xabcd,lsl 16
movk   x0, 0x5678,lsl 32
movk   x0, 0x1234,lsl 48
ret
```

其中，MOVK是“MOV Keep”的缩写。它把16位数值存储到寄存器里，为保留寄存器里的其他比特。实际上这几个MOVK指令先使用LSL指令依次移动了16、32、48，然后再次进行的赋值操作。即，程序通过四条指令把一个64位数值存储到寄存器里。
