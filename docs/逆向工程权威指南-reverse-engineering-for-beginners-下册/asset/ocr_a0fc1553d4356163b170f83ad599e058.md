本书第30章会介绍signed类型数据。可见，根据条件转移的指令，我们可以直接判断CMP所比较变量的数据类型。

接下来，我们一起研究main()函数的汇编代码。

# 指令列表12.3 main()

```
_main PROC
    push    ebp
    mov     ebp, esp
    push    2
    push    1
    call    _f_signed
    add     esp, 8
    push    2
    push    1
    call    _f_unsigned
    add     esp, 8
    xor     eax, eax
    pop     ebp
    ret     0
_main ENDP
```

x86 + MSVC + OllyDbg

我们可以通过OllyDbg直观观察到指令标志寄存器的影响。我们先用OllyDbg观察f_unsigned()函数比较无符号的过程。f_unsigned()函数使用了CMP指令，分次比较了两个相同的unsigned类型数据。因为参数相同，所以以CMP设置的标志位必定相同。

如图12.1所示，在运行到第一个条件转移指令时，C=1,P=1,A=1,Z=0,S=1,T=0,D=0,O=0。OllyDbg使用标志位的首字母作为该标志位的简称。
