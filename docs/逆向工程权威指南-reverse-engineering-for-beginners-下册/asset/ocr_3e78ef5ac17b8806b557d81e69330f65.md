# # 第82章 汇编指令与显示字符

# ## 82.1 EICAR

多数病毒软件都用EICAR进行自检。EICAR可以在MS-DOS平台上运行的应用程序。它只有在屏幕上显示 “EICAR-STANDARD-ANTIVIRUS-TEST-FILE!” 这样的字符串。[1]。

EICAR最重要的特点是：它的字符都是可以在屏幕上显示的ASCII字符串。我们在文本编辑器里粘贴字符串，即可生成EICAR文件:

```
X50!P$AP[4\PZX54(P^)CC7]$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+$H*
```

EICAR的汇编如下:

```
; initial conditions: SS=0FFFE, SS:[SP]=0
0100 58 pop ax
; AX=0, SP=0
0101 35 4F 21 xor ax, 214F
; AX=214H and SP=0
0104 50 push ax
; AX=214H, SP=FFFE and SS:[FFFE]=214F
0105 25 40 41 and ax, 4140h
; AX=140H, SP=FFFE and SS:[FFFE]=214F
0108 50 push ax
; AX=140H, SP=FFFC, SS:[FFFE]=214H
0109 5B bx
; AX=140H, BX=140H, SP=FFFE and SS:[FFFE]=214H
010A 34 5C xor al, 5Ch
; AX=11CH, BX=140H, SP=FFFE and SS:[FFFE]=214H
```
