## 18.6 多维数组

多维数组和线性数组在本质上是相同的。计算机内存是连续的线性空间，它可以与一维数组对应。分成多个一维数组后，多维数组与线性空间直接存储。例如，二维数组a[3][4]转化为a[12]这样的12个元素，如表18.1所示。

### 表18.1 使用多维数组

| 存储地址 | 元素 |
| :--- | :--- |
| 0 | [0] |
| 1 | [1] |
| 2 | [2] |
| 3 | [3] |
| 4 | [1] |
| 5 | [1] |
| 6 | [2] |
| 7 | [3] |
| 8 | [2] |
| 9 | [1] |
| 10 | [2] |
| 11 | [3] |

### 表18.2 二维数组在内存中的存储

在内存之中，3×4的二维数组依次存储为连续的12个元素，如表18.2所示。在上述线性数组中某个元素的内存存储时，可以将二维数组的第一个索引乘以4（矩阵宽度），加上第二个索引号。这种方式就是C/C++、Python所用的“行优先”顺序（row-major）。所谓行优先，就是先用第一行排列元素，然后再顺序排列其他行。相应的，也有“列优先”的顺序（column-major）。Fortran、Matlab、R语言使用了这种顺序。这种优先使用列的空间。从性能和缓存的角度来看，与存储方案（scheme）和组织方式（data organization）匹配的顺序最优。只要匹配，那么程序就可以连续访问数据，整体性能就会提高。所以，如果程序以行的方式访问数据，应当以行优先的顺序组织数组；反之亦如此。

## 18.6.1 二维数组实例

本例用char类型构造二维数组，其中每个元素都占用1字节。以行优先的顺序填充数据。下面这个例子将数字“0~3”填充数组的第二行。

## 指令清单18.20 运行数据

```c
#include <stdio.h>

char a[3][4];

## 一维数组的方式访问二维数组

一维数组的方式访问二维数组的方法有两种。

```c
#include <stdio.h>

char a[3][4];

char get_by_coordinates1(char array[3][4], int a, int b) {
    return array[a][b];
}

char get_by_coordinates2(char *array, int a, int b) {
    // treat input array as one-dimensional
    // 4 is array width
    return array[a*4+b];
}

char get_by_coordinates3(char *array, int a, int b) {
    // treat input array as pointer
    // calculate address, get value at it
    // 4 is array width
    return *(array+a*4+b);
}

int main() {
    a[2][3]=3;
    printf("%d\n", get_by_coordinates1(a, 2, 3));
    printf("%d\n", get_by_coordinates2(a, 2, 3));
    printf("%d\n", get_by_coordinates3(a, 2, 3));
}
```

编译并运行上述程序，观测到元素的对应数值。MSVC 2013的编译方法完全一致。
