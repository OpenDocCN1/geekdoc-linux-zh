最后一条LE指令，等于“MOV ESP, EBP”和“POP EBP”两条指令。可见，这个指令之前调整了数据取指针，将EBP的数值恢复到调用这个函数的初始状态。毕竟，程序段在开始部分对EBP和EBP进行了操作（MOVEBP, ESP/AND ESP, ...），所以函数要在退出之前恢复这些寄存器的值。

# 3.1.3 GCC: AT&T语体

AT&T语体同样是汇编语言的显示格式。这种语体在UNIX之中较为常见。

接下来，我们使用GCC 4.7编译如下所示的源程序：

> 指令清单34 使用 GCC 4.7.3 编译源程序

```
gcc -S 1_lc
```

上述指令将会得到下列文件：

> 指令清单35 GCC 4.7.3生成的汇编指令

```
.file "1_l.c"
.section .rodata
.LC0:
.string "hello, world\n"
.text
.glob main
.type main, @function
main:
.LFB0:
.cfi_startproc
push %ebp
.cfi_def_cfa_offset 8
.cfi_def_offset 5, -8
movl %esp, %ebp
.cfi_def_cfa_register 5
andl $-16, %esp
subl $16, %esp
.LC0, (%esp)

movl $0, %eax

.cfi_restore 5
.cfi_def_cfa 4, 4
```
