# 16.2 除法运算

# 16.2.1 替换为位移运算

本节围绕源程序进行位移演示：

```
unsigned int f(unsigned int a)
{
    return a/4;
}
```

使用MSVC 2010编译上述程序，可得到如下的指令：

> 指令清单 16.11 MSVC 2010

```
_a$ = 8 ; size = 4
_f PROC
mov eax, DWORD PTR _a$[esp-4]
shr eax, 2
ret 0
ENDP
```

上述代码中的SHR (Shift Right)指令将EAX寄存器中的数值右移2位，使用零填充位移产生的空位，并且将那些被右移指令移动出存储空间的位比特位。 实际上，那些被舍弃的位比特正是除法运算的余数。

SHR指令和SHL指令的运算模式相同，只是位移方向不同。

![](bbox=[0.195, 0.603, 0.805, 0.833])

右移与余数的关系与十进制运算的移动浮点数运算相似：当被除数为23、除数为10时，我们将23的小数点左移一位，为商、3为余数。
