
```asm
; otherwise (A<=B) return R1 (B):
MOVS r0,r1
|L0.6|
; return
    BX  lr
ENDP
```

```asm
my_min PROC
; R0=A
; R1=B
; compare A and B:
    CMP r0,r1
; branch if A is less then B:
    BLT |L0.14|
; otherwise (A<=B) return R1 (B):
    MOVS r0,r1
|L0.14|
; return
    BX  lr
```

两个函数所用的转移指令不同：一个是BGT，另一个是BLT。
在编译ARM模式处理程序时，编译器可能会使用条件执行指令（即“有分支”指令）。这种程序会显得更短小。在编译表表达式时，Keil编译器使用MOVcc指令。

## 指令清单12.28 Optimizing Keil 6/2013 (ARM mode)

```asm
my_max PROC
; R0=A
; R1=B
; compare A and B:
    CMP r0,r1
; return B instead of A placing B in R0
; this instruction will trigger only if A<=B (hence, LE - Less or Equal)
; if instruction is not triggered (in case of A>B), A is still in R0 register
    MOVE r0,r1
    BX  lr
ENDP
```

```asm
my_min PROC
; R0=A
; R1=B
; compare A and B:
    CMP r0,r1
; return B instead of A placing B in R0
; this instruction will trigger only if A>=B (hence, GE - Greater or Equal)
; if instruction is not triggered (in case of A<B), A value is still
in R0 register
    MOVGE   r0,r1
    BX      lr
ENDP
```

在启用优化功能的情况下，GCC 4.8.1和MSVC都能使用CMOVcc指令。这个指令相当于ARM程序的MOVcc指令。

```asm

    ; compare A and B:
```
```asm
    cmp rdi, rsi
```

## 12.4.3 MIPS

不幸的是，GCC 4.4.5在编译MIPS程序方面的智能化有限。

## 指令清单12.33 Optimizing GCC 4.4.5 (IPS)

```asm
my_max:
    ; set $v0=$a0 clear otherwise (if $a1>$a0):
    slt $v0, $a1, $a0
    ; jump, if $v0 is true (or $a1>$a0):
    beq $v0, .L10
    ; this is branch delay
    ; prepare $a1 in $v0 use of branch triggered:
    move $v0, $a1
    ; no branch triggered, prepare $a0 in $v0:
    move $v0, $a0
.L10:
    jr $ra
    nop ; branch delay

my_min:
    ; the min() function is same, but input operands in SLT are swapped:
    slt $v0, $a0, $a1
    beq $v0, .L28
    move $v0, $a1
.L28:
    jr $ra
    nop ; branch delay
```

注意分支延时现象：第一个MOVE指令“于”BEQ指令运行，而第二个MOVE指令在不跳转的情况下才执行。

### 12.5.4 无分支指令（非条件指令）

如果条件语句句短，那么编译器可能会分配条件执行指令:

- * 编译ARM模式的程序应用MOVcc指令。
- * 编译ARM64程序时应用CSEL指令。
- * 编译x86程序时应用CMOVcc指令。

## ARM

在编译ARM模式的程序时，编译器可能用条件执行指令替代条件转移指令。

## 指令列表12.42 ARM (ARM mode)

```asm
CMP register, register/value
instr_cc ; some instruction will be executed if condition code is true
instr2_cc ; some other instruction will be executed if other condition code is true
... etc
```

在被执行时不修改标志位的情况下，程序可有任意意义的条件执行指令。

Thumb模式的指令集里有IT指令。它可以把后续四条指令构成一个指令组，并且在条件表为真的时候运行该指令。详细介绍请参见本书的17。

## 指令列表12.43 ARM (Thumb mode)

```asm

instr1 ; instruction will be executed if condition is true
instr2 ; instruction will be executed if condition false
instr3 ; instruction will be executed if condition false
instr4 ; instruction will be executed if condition false
```

```c
void f (int a) {
```
