# TC aInvalidSecurityDevice

这些都是PowerPC平台的指令。这款CPU是20世纪90年代产出的一个，款典型的32位RISC CPU。它的每条指令都占用4个字节（与MIPS和ARM的指令相似），指令名称也与MIPS指令相似。

为了便于演示，我把函数名改为check1()。BL是Brach Link指令，用于调用子函数。上述程序的关键是BNE指令，在程序中通过加密数据进行跳转，否则就会在r3寄存器加载字符串，然后报错。

在参与了参考文献[SK95]之后，我发现r3寄存器用于存储返回值。如果返回值是64位，那么r4寄存器也会用于回传返回值。

另外，CRLI指令[1]还是当时的写法。后来我阅读了参考文献[IBM00]，获它是清除和传递数据的复合指令。本例的这个指令会清除r3寄存器的高位，把结果存在r0寄存器里。所以，它不仅相当于x86的MOVX指令（可参见书15.1.节），还能设置相应的标识位，后面的BNE指令传递标识信息。
