## C. 2 指令

# MIPS的指令分为3类：

- R-Type, Register/寄存器类指令。此类指令操作3个寄存器，具有以下形式：

指令目标寄存器，源寄存器1，源寄存器2

当前两个操作数同时，IDA可能会以以下形式进行显示：

指令目标寄存器/源寄存器1，源寄存器2

这种显示风格与x86汇语言相似。

- I-Type, Immediate/立即类指令。涉及2个寄存器和1个立即数。

- J-Type, Jump/转移指令。在MIPS指令的opcode里，共有26位空间。

## 转移指令

实现跳转功能的指令分为B开头的（BEQ, B等）和J开头的（JAL, JALR等）。B类转移指令属于I型指令。也就是说，B指令的opcode里有16位立即数（偏移量）。而J和JAL属于J指令，它们的opcode里有26位立即数。简单来说，B开头的指令可以将转移条件封装到opcode里（B指令是“BEQ $ZERO,$Label”指令）。

题目4
对应章节：19.7.4节
这个函数两个32位数相乘，返回64位的积。解答这种题目，根据输入输出进行判断的速度比较快。
```c
#include <stdio.h>
#include <stdint.h>

int64_t mult(uint32_t m, uint32_t n)
{
  uint64_t p = 0; // initialize p to 0
  while (n != 0) // while multiplier n is not 0
  {
    if (n & 1) // test LSB of multiplier
      p = p + m; // if 1 then add multiplicand m
    m = m << 1; // left shift multiplicand
    n = n >> 1; // right shift multiplier
  }
  return p;
}

int main()
{
  printf("%lld\n", mult (2, 7));
  printf("%lld\n", mult (3, 11));
  printf("%lld\n", mult (4, 111));
}
```
