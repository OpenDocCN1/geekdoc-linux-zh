```
add esp, 8
mov ecx, eax
cmp edx, esi
jl SHORT LL3@form_netma
$LN9@form_netma:
    pop esi
    mov eax, ecx
    pop ebx
    ret
form_netmask ENDP
```

set_bit()函数的功能十分单一。它将输入值左移既定的比特，接着将位移运算的结果与输入值进行或OR运算。而在form_mask()函数通过循环语句重复调用set_bit()函数，帮助循环控制变量netmask_bits设置子掩码数值为1的各个比特位。
