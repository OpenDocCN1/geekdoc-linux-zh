# 第85章 Millenium游戏的存档文件

“Millenium Return to Earth”是一款古老的DOS游戏（1991年问世）。玩家可以在游戏中挖矿、修建战舰、在其他星球上战斗，等等。有兴趣的读者可以体验一下它：http://thehouseofgames.org/index.php?t=10&id=110

+   * 和其他的游戏程序一样，这个游戏也有游戏存档的功能。现在我们来分析它的存档文件。

游戏中有“矿”的概念。挖矿的速度因星球而异，在某些星球上快一些，而在另一星球上慢一些。另外，在游戏的设定中，矿产的种类也有差异化的设定。在图85-1中，您可看到游戏存档时的挖矿进度。
