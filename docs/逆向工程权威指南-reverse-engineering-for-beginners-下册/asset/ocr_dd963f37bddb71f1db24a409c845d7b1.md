# ## B.3 32位ARM (AArch32)

# ### B.3.1 通用寄存器

+   • R1~R12. 通用寄存器GPRs。

+   • R13. SP (Stack Pointer/栈指针)。

+   • R14. LR (link register/链接寄存器)。

+   • R15. PC (程序计数器)。

R0~R3也被称为临时寄存器（scratch registers）。它们通常用于传
递函数的参数；在函数结束时，也不必复恢复它们的初始状态。
