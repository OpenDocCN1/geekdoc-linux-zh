这里的变量tmp应该是一个有符号数。这里的转换处理了两个减法指令以及一个比较指令。原来的算法是通过两个比较指令加一个减法指令来来实现的。

toupper:
    lea edx, [edi-97] ; 0x61
    lea eax, [edi-32] ; 0x20
    cmp dl, 25
    cmov eax, edx
    ret
```

第三行的代码首先准备了要减减的值0x20（十六进制的20，十进制的32），这会给出一个相似的结果，好像执行减法会发生似的。而第五行的指令，在不在进行转换（也就是不执行减法）的时候，原始的输入数据复制给EAX寄存器。可见它在条件不成立的情况下舍弃错误的值。也就是说，编译器为了避免使用条件转移指令而预先进行了减法运算。
