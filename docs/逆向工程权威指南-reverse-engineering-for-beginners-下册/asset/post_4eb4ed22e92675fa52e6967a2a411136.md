## Optimizing GCC 4.4.5

在传递多个参数时，MIPS使用前4个参数，剩余的参数。这种平台主要采用一种名为“O32”的约定。实际上大多数MIPS系统都采用这种约定。如果使用了其他的约定，寄存器用会有差异。下面的SW是“Store Word”的缩写，用寄存器的值写入内存。MIPS指令很小，没有直接写入内存的类。当需要这种操作时，不得不组合LI/SW指令。

指令清单6.14 Optimizing GCC 4.4.5 (输出)

```
$L0:
  .ascii "a=%d; b=%d; c=%d; d=%d; e=%d; f=%d; g=%d; h=%d\n"
main:
    ; function prologue:
    lui $28,%hi(_gnu_local_gp)
    addiu $sp,$sp,-56
    addiu $28,$28,lo(_gnu_local_gp)
    sw $31,52($sp)
    ; 5th argument in stack:
    li $2,4
    sw $2,16($sp)
    ; 6th argument in stack:
    li $2,5
    sw $2,20($sp)
    ; 7th argument in stack:
    li $2,6
    sw $2,24($sp)
    ; 8th argument in stack:
    li $2,7
    lw $25,%call16(printf)($28)
    sw $2,28($sp)
    ; 1st argument in stack:
    li $a0
    lui $a1,%hi($L0)
    ; 9th argument in stack:
    li $a2,8
    sw $2,32($sp)
    addiu $a4,$4,lo($L0)
    ; 2nd argument in stack:
    li $a5,1
    ; 3rd argument in stack:
    li $a6,2
    ; call printf():
    jalr $25
    ; 4th argument in stack (branch delay slot):
    li $a3,3 # 0x3
    ; function epilogue:
    lw $31,52($sp)
    ; set return value to 0:
    move $2,$0
    ; return
    j $31
    addiu $sp,$sp,56 ; branch delay slot
```
