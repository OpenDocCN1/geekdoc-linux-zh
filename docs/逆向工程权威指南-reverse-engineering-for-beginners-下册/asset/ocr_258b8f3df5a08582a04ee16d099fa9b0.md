# 指令清单21.22 Optimizing Xcode 4.6.3 (LLVM) (Thumb-2 mode)

```
var_C = -0xC

PUSH     (R7, LR)
MOV      R7, SP
SUB      SP, SP, #4
MOV      R9,R1;b
MOV      R1,R0;
MOVW     R0, #0xF10; "a=%d; b=%d; c=%d; d=%d\n"
SXB      R1, R1; ;制备a
MOV.W   R0, #0
STR      R3, [SP,+var C]; ;推送入线, 供 printf() 调用
ADD      R0, PC; ;格式化字符串
SXB      R3, R2; ;制备c
MOV      R2,R9;制备b
BLX      _printf
ADD      SP, SP, #4
POP      (R7,PC)
```

SXB（Signed Extend Byte）对应x86的MOVXS指令，但是它只能处理寄存器的数据，不能直接对内存进行操作。程序中的其余指令与前一个一样，本文将再进行重复一遍。
