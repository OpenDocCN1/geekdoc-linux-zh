DL寄存器的值目前为1。函数将其移动arg_8位。例如，如果arg_8是4，那么DL寄存器的值变为0x10，即二进制的1000b：

```
.text:00541017  shl        dl, cl
.text:00541019  mov        cl, cube64[eax+esi*8]
```
