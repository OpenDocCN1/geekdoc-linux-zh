# 28.3 常量赋值

# 28.3.1 32位ARM

所有的Thumb模式的汇编指令都是2字节指令，所有的ARM模式的汇编指令都是4字节指令。ARM指令和32位的立即数都占用4字节，又如何进行32位立即数赋值呢？

我们来看：

```
unsigned int f() {
    return 0\x12345678;
}
```

指令清单28.1 GCC 4.6.3 -03 ARM mode

f:

```
ldr r0, .L2
    lr
.L2: .word 305419896 ; 0x12345678
```

可见，0x12345678存储在内存之中，供其他指令调用。但是这种指令增加了CPU访问内存的次数。我们可以改善这一状况。

指令清单28.2 GCC 4.6.3 -03-march=armv7-a (ARM mode)

```
movw r0, #22136 ; 0x5678
mov r0, #4660 ; 0x1234
lr
```

上述指令将一个立即数分为两个部分，并依次存储到同一个寄存器里。它使用MOVW先将立即数的低位部分存储到寄存器里，然后使用MOV存储这个数的高位部分。

这就是说，ARM模式的程序需要两个指令才能加载32位的立即数。除了0和1之外，程序很少用到常量，所以这种赋值的方法不会造成实际问题。有人会问，这种一分为二的做法不会造成性能
