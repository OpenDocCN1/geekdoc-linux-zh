# 第53章 16位的Windows程序

虽然16位的Windows程序已经几乎绝迹，但是有关复古程序以及研究密集知识的研究，往往会涉及此部分知识。

微软于1993年8月发布了最后一个16位的Windows系统，即Windows 3.11（同年发行的中文操作系统Windows 3.2也是16位操作系统）。在此时之后问世的16/32位操作系统Windows 96/98，以及32位的Windows NT系统都可以运行16位应用程序。后来推出的64位Windows NT系列系统不再支持16位应用程序。

16位应用程序的代码结构与MSDOS的程序十分相似。这种类型的可执行文件采用了一种“New Executable (NE)”的可执行程序格式。

本章的所有程序均OpenWat 1.9编译。编译时的选项如下：

```
wcl.exe -i=C:/WATCOM/h/win/ -s -os -bt=windows -bcl=windows example.c
```
