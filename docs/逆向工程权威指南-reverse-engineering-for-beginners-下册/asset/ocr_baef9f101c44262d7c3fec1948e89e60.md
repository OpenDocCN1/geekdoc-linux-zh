# 第6章 printf() 函数与参数传递

现在我们对Hello, world! 程序稍作修改，演示它的参数传递的过程。

```
#include <stdio.h>

int main() {
    printf("a=%d; b=%d; c=%d", 1, 2, 3);
    return 0;
}
```

# 6.1.1 x86: 传递3个参数

MSVC

使用MSVC 2010 express编译上述程序，可以得到下列汇编指令:

```
$SG3830 DB 'a=%d; b=%d; c=%d', 00H
...
push 3
push 2
push 1
push OFFSET $SG3830
call _printf
add esp, 16 ; 0000010H
```

与最初的Hello World程序差不多。我们看到printf()函数的参数是逆序栈里，第一个参数在最后入。

在32位环境下，32位指针和int类型数据都占据32位/4字节空间。
所以，我们这里的四个参数总共占用4×4=16（字节）的存储空间。
