# 清单20.2 Non-optimizing MSVC 2013

```
_BSS SEGMENT
_rand_state DD 01H DUP (?)
  BSS ENDS

_init$ = 8
_srand PROC
  push ebp
  mov ebp, esp
  mov eax, DWORD PTR _init$[ebp]
  mov DWORD PTR _rand_state, eax
  pop ebp
  ret
_srand ENDP

_TEXT SEGMENT
_rand PROC
  push ebp
  mov ebp, esp
  imul eax, DWORD PTR _rand_state, 1664525
  mov DWORD PTR _rand_state, eax
  mov ecx, DWORD PTR _rand_state
  add ecx, 103904223 ; 3c6ef35ff
  mov DWORD PTR _rand_state, ecx
  mov eax, DWORD PTR _rand_state
  and eax, 32767 ;;00007 fffH
  pop ebp
  ret
_rand ENDP

_TEXT ENDS

  x64
```

# 20.2

x64的程序与与x86的程序几乎相同。因为函数的返回值属于int类型，所以它没有使用64位寄存器，而是使用了32位寄存器的助符。但是，my_srand()函数从ECX寄存器获取的所需参数，没有通过栈读取参数，这构成了64位程序的显著特征。
