+   • CWD:把AX中的字 (word) 类型转换为双字 (Dword) 型数据、存储于DX-AX寄存器。

+   • CWDE:把AX中的字 (word) 类型转换为双字 (Dword) 型数据，存储于DAX寄存器。

+   • CDQ:把AX中的双字（word） 型数据转换为四字 (Qword) 型数据，存储于EDX:AX寄存器。

+   • CDQE (x64指令): 把EAX中双字 (Dword) 型数据转换为四字 (Qword) 型数据，并存储于RAX寄存器。

上述指令能够处理signed数据中对符号、对高位进行正确的填充。详情请参见本书第24章第5节。

CLD清除标识位。

CLI (): 清标识位。

CMC (): 转换标识位。

CMOVcc: 条件赋值指令。如果相应的相应的代码(cc)，则进行赋值。有关条件cc的各种代表类型，请参见文A.6.2对Jcc的详细说明。

CMPSB/CMPSD/CMPSQ: 比较8位单字数据(Byte) /16位双字数据(Word) /32位双字数据(Dword) /64位四字数据(Qword)的指令。将SI/ESI/RSI寄存器的值作为源操作数的地址，将一个操作数的地址取到EDI/EDI/RDI寄存器。在比较结果之后再设置标识位，并与CMP指令相同。

这些指令通常与指令前缀REP组合使用。在这种情况下，组合指令CX/ECX/RCX寄存器的值作为循环计数进行多次循环比较，直至ZF标识位为零。也就是说，它也可以用字符比较（或搜索）。

它的工作方式和C语言的memcmp 函数相同。
