# 3.1.1 MSVC

接下来我们将通过下列指令，使用MSVC 2010编译下面这个程序：

```
cl 1.cpp /Fal.asm
```

其中/Fa项将使编译器生成汇编指令清单文件（assembly listing file），并指定汇编列表的文件名为1.asm。

上述命令生成的1.asm内容如下：

```
指令清单3.1 MSVC 2010

CONST SEGMENT
$SG3830 DB      'hello, world', 0AH, 0OH
CONST ENDS
PUBLIC      _main
```
