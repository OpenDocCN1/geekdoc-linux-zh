# ## 6.2 ARM模式下传递参数

### 6.2.1 ARM系统传递参数时，通常会进行拆分：把前4个参数传递给RO~R3寄存器，然后利用栈传递其余的参数。在获取（组装）参数时，遵循的函数调用约定是`fastcall`约定或win64约定。有关这两种约定的详细介绍，请参照64.3节和64.5.1节。

32位ARM系统

非优化的Keil+ARM模式

> 指令清单6.6 非优化的Keil 6/2013 (ARM模型)

```
.text:00000000 main
.text:00000000 10 40 2D E3 STMFD SP!,{R4,LR}
.text:00000004 03 30 A0 E3 MOV R3, #3
.text:00000008 02 20 A0 E3 MOV R2, #2
.text:0000000C 01 10 A0 E3 MOV R1, #3
.text:00000010 08 00 8F E2 EDR R0, a#BDDCDCD; "a=%d; b=%d";
.text:00000014 06 00 00 E8 BL
.text:00000018 00 00 A0 E3 MOV R0, #0 ; return 0
.text:0000001C 10 80 BD E1 LMDD SP!,{R4,PC)
```

可见，RO~R3寄存器依次负责传递参数。其中，R0寄存器用于传递格式字符串，R1寄存器传递1，R2寄存器传递2，R3寄存器传递3。

0x18处的指令将R0寄存器赋值0，对应源代码中的“return 0”。

这段汇编指令中执行中。

即使开启了优化的选项，Keil 6/2013生成的汇编指令完全相同。
