# 6.2.6 重定向Relocations (relocs)

至少在Hiew中，它也可以表示为FIXUP-s。

重位段是MS-DOS时代一直存在于可执行文件的实体段，几乎所有的可执行文件都有这个段。

前文知道，程序可能会被加载到模块的基地址。但是如何处理全局变量等共享数据呢？程序必须通过地址来访问此类数据，然而程序又不能事先知道共享数据的存储地址，为了解决这个问题，我们推出了“位置无关代码/PIC”（详情请阅67.1）的解决方案。不使用PIOC来并是不行的。

> 是，我们推出了基于“重定向”的地址重定向技术。重定向表记录了该文件被加载到不同基地址时需要修正的地址所指引。

如果PE文件声明了一个地址为0xA10000的全局变量，那么这个变量的指令地址大致上将会是：

```
A1 00 01 00    mov    eax, [00000000]
```

此时，模块的基地址是0x400000（默认链接器地址），全局变量的相对虚拟地址RVA是0xA10000。

如果这个模块被加载到基地址为0x500000的基地址，那么这个全局变量的真实地址应当被调整为0x510000。

在上述opcode中，变量地址应该是0xA1（MOV EAX 指令）之后的几个字节。为了让操作系统在重定向时正确处理该地址，PE文件的重定向表必须收集这四个字节的相对地址。
