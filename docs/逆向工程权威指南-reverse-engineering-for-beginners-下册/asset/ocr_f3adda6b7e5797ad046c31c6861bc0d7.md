```
_negate PROC DWORD PTR$[esp-4], -2147483648 ; 80000000H
    xor DWORD PTR_tmp$[esp-4]
    fld DWORD PTR_tmp$[esp-4]
    ret
```

函数从栈中提取一个浮点类型的数据，但是把它当作整数类型数据进行
处理。

AND和OR或设置相应的位比特，而XOR用来设置相反的符号位。

要把浮点数还入FPU，所以后把修改后的处理结果保存到STO寄存器。
