# 第5章 栈

栈是计算机科学里最重要且基础的数据结构之一。[1]

从技术上说，栈就是CPU寄存器里的某个指针所指向的一片内存区域。这里所说的“某个指针”通常指x86平台的ESP/x64平台的ESP寄存器/RSP寄存器，以及ARM平台的SP寄存器。

操作的最常见的指令是PUSH和POP，在x86和ARM Thumb模式的指令里都有两条指令。PUSH指令会对ESP/RSP/SP寄存器的值进行减法运算，使得减4（32位）或8（64位），然后将操作数上述寄存器的指针指向的内存中。

POP指令是PUSH指令的逆操作，从栈指针（Stack Pointer，三个寄存器之一）的内存中读取，用操作（通常是写到其他寄存器），然后将指针的值增加4或8。

在分配的空间中，找指针，即Stack Pointer指向的地址就是栈的底部。PUSH会减少指针的值，而POP会增加指针的值。栈的“底”并不是整个栈的最低地址，而是整个栈的初始地址。虽然听起来很奇怪，但是确实如此的。

虽然x86/x64的栈已经很好理解了，但是ARM的栈更为复杂的。ARM的栈分为增栈和减栈。减栈（descending stack）的起始地址就是栈的最高处，向向低地址增长，指针的值随栈的增长而减少，如STMFD/LMFD、STMED/LDMED等指令都是减栈的操作。ARM的增栈（ascending stack）的起始地址则是栈的最低地址，向高地址增长，指针的值随的增长而增加，如STMFA/LMFA、STMEA/LDMEA等指令都是增栈的操作指令。[2]
