# 标题

作者 刘洪 自安电力技术报告（马云电力系统遭受攻击事件分析报告），2016年1月25日

而非从微观的分析来看，高级恶意代码已经从一个附着在宿主机上的代码片段或单体文件的木马，进化为了一个庞大的工程体系。对于高级恶意代码来说，不仅对于后面的持久化负载和大量需投防的“原子化”，其更有一个庞大的支撑体系。对于前端，我们还能依赖恶意向来分析，而对于后面这个大到“魅影”，我们更多的只能依靠分析恶意代码的指令体系、有限的网络跨捕获、可得可的检索检索，以及为了信息安全动物的逻辑本机不能进行探测。我们所要完成的工作，不仅只是要一系列载横模块分析，而是对整个攻击面和攻击链的深度复盘。

2017年1月25日，安天分析小组完成了针对方程式攻击的第四篇报告《方程式组织EQUATION驱动平台分析》，基于对方方程式组织大量恶意代码模块的分析，我们初步完成了一份有价值的工作，就是方程式组织的主机作业模块初步拼图。
