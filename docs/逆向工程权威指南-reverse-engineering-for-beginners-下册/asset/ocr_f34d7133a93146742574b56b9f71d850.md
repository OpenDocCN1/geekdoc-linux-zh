```
fatret 0
pad 1
$LN2@bzero: $LN2@bzero
DD $LN3@bzero
DD $LN4@bzero
DD $LN5@bzero
DD $LN6@bzero
DD $LN7@bzero
DD $LN8@bzero
bzero ENDP
```

这个函数的第一部分与源程序对应。第二部分的循环展开体也不太难理解：switch语句通过转移指令跳转到合适的位置。由于MOV/INC指令之间没有其他代码，所以switch语句在转移到指定标签后不会越后续的转移标签，它会执行所需的指令。

另外，我们注意到MOV/INC指令对占用的字节数（3+3=6字节）。在注意到这个问题之后，我们就可以去掉switch()语句的转移表结构，将输入值乘以6，并直接跳转到如下地址：目前的RIP地址+输入值\*。这样一来，由于掉了转移表的查询操作，执行速度会快快。对于乘法来说，数字6是一个计算效率高的乘数因子，或许允许法运算的速度比表查询的转移指令更慢；所谓“深度优化”就是这个思路[1]。在介绍循环展开技术时，过去的教科书就是这样介绍“缓存设备”。

+   [1] 作为一个练习，为了去掉跳转表，读者可以尝试重新编写代码。上述MOV/INC指令对可以写成4字节或者8字节，当然一个字节可以，比如STOSB指令。
