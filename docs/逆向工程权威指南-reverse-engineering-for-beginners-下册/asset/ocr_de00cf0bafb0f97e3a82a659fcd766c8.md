# 第40章 达夫装置

达夫装置(Duff's Device)是一种综合了多种控制语句的循环展开技术，可大幅度地减少代码的分支总数。这种循环展开技术巧妙地利用了switch语句的滑梯(fallthrough)效果。

本章对Duff的原始程序进行了轻度简化。

现在假设我们要编写一个清除一块连续内存的函数。当然，我们可以使用循环语句、逐个字节的拷贝数据。但是现代的计算机内存总线已经很宽，以字节为单位的清除效率会非常低。若以4字节或8字节为操作单位进行io操作，那么操作效率会高一些。由于本例演示的是64位应用程序，所以我们就以8字节为单位进行操作。不过，我们又如何应对对那些不足8字节的内存存储？毕竟我们的函数可能包含容量不足8字节的内存存储。

因此，合理的算法应当：

+   * 首先统计目标内存含有多少个连续的8字节，而以8字节(64位)为操作单位将其清除。

+   * 然后统计那些大小不足8字节的尾数、即上一步除法计算的余数，然后逐字节地将之清零。

简单的循环语句即可完成第二的任务。然而我们希望把这个循环分解、展开：

```
#include <stdlib.h>
#include <stdio.h>
```
