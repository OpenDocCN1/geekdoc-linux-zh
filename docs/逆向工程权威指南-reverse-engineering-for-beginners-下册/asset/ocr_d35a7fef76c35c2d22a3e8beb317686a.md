# 54.13.8 小节

在Java中，是否可能发生缓冲区溢出的情况？不可能。Java数组的数据实例存储了数组长度的明确信息，数组操作会作为边界检查。一旦发生上/下标溢出问题，运行环境就会异常处理。

Java和C/C++的多级数组在底层结构上有着显著的区别，因此JAVA不太适合进行大规模科学计算。
