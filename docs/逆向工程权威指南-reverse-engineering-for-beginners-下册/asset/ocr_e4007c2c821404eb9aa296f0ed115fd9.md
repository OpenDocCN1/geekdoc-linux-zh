# A. 6.1 指令前

LOCK: 数据总线锁前。在执行LOCK之前的汇编指令时，它可以独占数据总线的作用。简单来说，在执行这种指令时，多处理器的其他CPU将暂停、等待该指令执行结束。这种指令常见的各种关键字、（硬件）信号和原子操作。

禁止处理器修改数据总线上的数据，起到锁总线的作用。该指令的执行不影响任何标志位。它作为ADD、AND、BTR、BTS、CMPXG、OR、XADD、HOR指令的前缀。本书的第68章第4节介绍了这种指令。

REP: MOVS和STOS指令结合使用，以循环的方式进行数据复制及数据存储。在执行REP指令时，CX/EX/RCX寄存器存储的值将作为隐含的循环计数器。有关MOVs和STOSX指令的详细说明，请参见附录A6.2。

REP指令属于DF敏感指令。DF标志位决定了它的操作方向。
