# 14.1.3 调试跟踪工具tracer

你可能已经知道了，直接使用OllyDlg这样的调试工具跟跟踪程序并不是方便的。我自己写了调试工具tracer。[2]

使用IDA打开编译后的可执行文件，找到PUSH E（这条指令将参数传递给printing_function()函数），记录其地址0x0401026，然后通过上述命令启动tracer程序:

```
tracer.exe -l1:loops_2.exe bpx=loops_2.exe0x0401026
```

上述指令会在BPX设置的断点地址中断，输出此时各寄存器的状态。

tracer工具会将寄存器的状态输出到tracer.log:

```
PID=12884New process loops_2.exe
(0) loops_2.exe0x0401026
EAX=0x00a32c68 EBX=0x00000000 ECX=0x6f0f4714 EDX=0x00000000
ESI=0x00000002 EDI=0x00333738 EBP=0x0024fbbc ESP=0x0024fd4 fbb2
EIP=0x00331026
```
