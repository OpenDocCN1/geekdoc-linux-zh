# 51.1.2 类继承

继承而来的类与前面的简单结构体相似，但是它可以对父类进行 扩展。

我们先来看一个简单的例子：

```
#include <stdio.h>

class object {
    public:
        int color;
        object() { this->color=color; }
        object(int color) { this->color=color; }
        void print_color() { printf("%d\n", color); }
}

class box : public object {
    private:
        int width, height, depth;
    public:
        box(int color, int width, int height, int depth) {
            this->color=color;
            this->width=width;
            this->height=height;
            this->depth=depth;
        }
```
