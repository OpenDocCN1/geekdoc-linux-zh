# 57.1.3 Unicode编码

许多人认为，所谓Unicode编码就是两个字符/16位数据来编码一个字符的封装格式。实际上是一种常见的术理解误解。Unicode际上一个标准，它规定的只是将数字写成字符的方法，但是定义具体的编码方式。

目前比较流行的编码方式有UTF-8和UTF-16LE。前者广泛被用来在互联网和NIX系统中，而后者主要使用在Windows环境下。
