在这个表格中，我们看到一个数据表::RTTI Complete Object Locator的链接和一个指向成员函数::dump的链接。它们的正式名称分别是虚方法表RTT表存储各种方法的地址，RTT表存储类型的信息。其中RTTI为程序执行了“强制类型转换算符”dynamic_cast（将基类的指针或全局变量转换为类型的指针或使用）和“类型查询函数”ttype。在底层代码中dump的函数示例情况是，在调用成员函数时，它所使用的类的名称仍然是文本字符串。通过调用指向基类的指针（或引用）用其调用虚函数实例（例如：虚方法时），指针最终指向派生类实例的同名虚方法——构造函数会将指针实际指向对象的实例的类型信息存储在结构中。

在内存数据库里查找虚方法的内存地址意味着要消耗额外的CPU时间。因此此方法的运行速度比一般的方法要慢一些。
