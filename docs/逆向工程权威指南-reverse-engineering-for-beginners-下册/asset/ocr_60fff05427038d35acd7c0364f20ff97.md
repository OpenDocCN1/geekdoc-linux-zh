# 21.4.4 其他

在被调用函数参数传递结构体时（不是传递结构体的指针），传递参数的过程相当于依次传递结构体的各字段的字节。也就是说，如果结构体各字段的定义不变，那么f()函数结构体的源代码可改写为：

```
void f(char a, int b, char c, int d) {
    printf("%%a=%d; b%%c; c%%d; %%d%%d\n", a, b, c, d);
}
```

经过上述改动后，编译器生成的程序顺序完全不会发生变化。
