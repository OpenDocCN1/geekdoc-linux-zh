MSVC的汇编清单文件都采用了Intel语体。汇编语言存在两种主流语体，即Intel语体和AT&T语体。本书将在3.1.3节中讨论它们之间的区别。

在生成1.asm之后，编译器会生成1.obj再将链接为可执行文件1.exe。

在hello world这个例子中，文件分为两个代码段，即CONST和_TEXT段，它们分别代表数据段和代码段。在本例中，C/C++程序为字符串常量“hello, world”分配了一个指针（const char[]），在代码中这个指针的名称并不明显（参照下列Bjarne Stroustrup. The C++ Programming Language, 4th Edition. 2013的第176页，7.3.2节）。

接下来，编译器进行了了自己的处理，并在内部字符串常量命名为$SG3830。

因此，上述过程的源代码等于：

```
#include <stdio.h>

const char *$SG3830[]="hello, world\n";n
int main()
{
    printf($SG3830);
    return 0;
}
```
