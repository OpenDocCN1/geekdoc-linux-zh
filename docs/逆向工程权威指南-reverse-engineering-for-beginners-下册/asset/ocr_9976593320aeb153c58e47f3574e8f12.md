# 题目1

对应章节：15.2.1节

这是一个统计C字符串中空格的程序，源代码如下：

```
int f(const char* aStr)
{
    const char* veos = aStr;
    int vCount = 0;

    for(!*veos;++veos)
    {
        if (*veos == ' ') ++vCount;
    }

    return vCount;
}
```
