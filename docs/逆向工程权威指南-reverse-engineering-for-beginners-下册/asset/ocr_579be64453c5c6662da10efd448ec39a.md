# 49.2 随机噪音，怎么看起来像反汇编指令？

来说，我们可以从以下三点来判断，一段程序是由随机代码组成的还是正常的程序段：

+   - 不寻常的指令集合。一般来说，x86最常见的指令是PUSH、MOV、CALL等。如果遇到了大类杂染式的稀有指令大排盘（浮点运算FPU指令、输入输出IN/OUT指令和很少见的一些系统指令混在一起），多数情况就是反汇编过程出了问题。
