
## 3.5. Summary

In this section, we took a whirlwind tour of the Linux landscape. We discussed the kernel and user space, reviewed many Linux shell commands, discussed processes and how to manage them, reviewed user and group security concepts, discussed the FHS, and toured some of the most common directories and files found on Kali Linux.

Summary Tips:

- Linux is often used to refer to the entire operating system but in reality Linux itself is the operating system kernel that is started by the boot loader, is itself started by the BIOS/UEFI.

- User space refers to everything that happens outside space Among the programs running in user space, there are many core utilities from the GNU project², most of which are meant to be run from the command line (a text-based interface that allows you to enter commands, execute them, and view the results). Shell executes commands within that interface.

- Common commands include: pwd (print working directory), cd (change directory), ls (file or directory contents), mkdir (make directory), rmdir (remove directory), mv, rm and cp (move, remove or copy file or directory respectively), cat (concatenate or show file), less/more (show files at a time), editor (start a text editor), find (locate a file or directory), free (display memory information), df (show disk free space), id display the identity of the user along with the list of groups they belong to), dmesg (review kernel logs), and journalctl (show all available logs).

- You can inspect the hardware on a Kali system with several commands: lspci (PCI devices), lsusb (list USB devices), and lspcmia lists PCMCIA cards.

- A process is a running instance of a program, which requires memory to store both the program itself and its operating data. You can manage processes with commands like ps (show processes), kill (kill processes), bg (send process to background), fg (send process to foreground), and jobs (show background processes).

- Unix-like systems are multi-user. They support multiple users and groups and allow control over actions, based on permissions. You can manage file and directory rights including: chmod (change permissions), chown (change owner), and chgrp (change group).

- As other Linux distributions, Kali Linux is organized to be consistent with the Filesystem Standard (FHS), allowing users coming from other distributions to find their way around.

- Traditionally, application configuration files are stored under your home directory, in hidden files started with a period (dot).

Now that you have a handle on Linux fundamentals, let's get Kali Linux up and running.

### 4.1. Minimal Installation Requirements

The installation requirements for Kali Linux vary depending on what you like to install. On the low end, you can set Kali as a Basic Shell server with no desktop, using as little as 128 MB of RAM (512 MB recommended) and 2 GB of disk space. On the higher end, if you opt to install the default desktop and the kali-linux-full meta-package, you should aim for at least 2048 MB of RAM and 20 GB of disk space. Besides the RAM and hard disk requirements, your computer needs to have a CPU supported by at least one of amd64, i386, armhf, or arm64 architectures.

### Booting and Starting the Installer

Once the BIOS has begun booting from the USB drive or DVD-ROM, the Isolinux boot loader appears, as shown in Figure 4.1, "Boot Screen" (67). ### Detecting Hardware

In the vast majority of cases, the hardware detection step is completely automatic. The installer detects your hardware and tries to identify the boot device used in order to access its content. It loads the modules corresponding to the various hardware components detected and mounts the boot device in order to read it. The previous steps were completely contained in the boot image included on the boot device, a file of limited size and loaded into memory by the bootloader when booting from the device.

### Loading Components

With the contents of the boot device now available, the installer loads all the files necessary to continue with its work. This includes additional drivers for the remaining hardware (especially the network card), as well as all the components of the installation program.
