# Synaptic

Synaptic is a graphical package manager that features a clean and efficient graphical interface (shown in Figure 8.2, "synaptic Package Manager" [page 194]) based on GTK+ and Gnome. Its many-ready-use filters give fast access to newly available packages, installed packages, upgraded, obsolete packages, and so on. If you browse through these lists, you can select the operations to be done on packages (install, upgrade, remove, purge); these operations are not performed immediately, but put into a task list. A single click on a button validates the operations and they performed in one.
