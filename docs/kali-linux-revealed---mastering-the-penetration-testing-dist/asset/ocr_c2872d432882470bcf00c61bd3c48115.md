# 3.4.5. Getting System Information and Logs

The free command displays information on memory; disk free (df) reports on the available disk space on each of the disks mounted in the file system. The -h option (for human readable) converts the sizes into a more legible unit (usually mebibytes or gibibytes). In a similar fashion, the free command supports the -m and -g options, and displays data either in mebibytes or gibibytes respectively.

The id command displays the identity of the user running the session along the list of groups they belong to. Since access to some files or devices may be limited to group members, checking available group membership may be useful.

```
$ id\uid=1000(buxy) groups=1000(buxy),27(sudo)
```

The uname -a command returns a single line documenting the kernel name (Linux), the hostname, the kernel release, the kernel version, the machine type (an architecture such as x86_64), and the name of the operating system (GNU/Linux). The output of this command should usually be included in bug reports as it clearly defines the kernel in use and the hardware platform you are running on.

```
$ uname -a
Linux kali 4.9.0-kali3-amd64 #1 SMP Debian 4.9.18-1kali (2017-04-04) x86_64 GNU/Linux
```

All these commands provide run-time information, but when you need to logs to understand what happened on your computer. In particular, the kernel emits messages that it stores in a ring buffer whenever interesting happens (such as a new USB device being inserted, a failing disk operation, or initial hardware detection on boot). You can retrieve the kernel logs with the dmesg command.
