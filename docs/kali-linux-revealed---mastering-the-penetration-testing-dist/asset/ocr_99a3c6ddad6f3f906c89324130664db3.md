# Filing a Bug Report in another Free Software Project

There is a large diversity of free software projects, using different workflows and tools. This diversity also applies to the bug trackers in use. While many projects are hosted on GitHub and use Issues to track their bugs, there are many others hosting their own trackers, based on Bugzilla, Track, Redmine, Flyspray, and others. Most of them are web-based and require you to register an account to submit a new ticket.

We will not count all the trackers here. It is up to you to learn the specifics of various trackers for other free software projects, but since GitHub is relatively popular, we will take a brief look at it here. As with other trackers, you must first create an account and sign in. Next, click the Issues tab, as shown in Figure 6.5,“Main page of a GitHub project”[page 144].
