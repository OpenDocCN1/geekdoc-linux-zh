# Is My CPU 32- or 64-bit?

Under Windows, you can find this by running the System Information application (found in the Accessories > System folders). On the System Summary screen, you can inspect the System Type field: it will contain "x64-based PC" for a 64-bit CPU or "x86-based PC" for a 32-bit CPU.

Under OS XMacOS, there is no standard application showing this information but you can still infer it from the output of the uname -r command on the terminal. It will return 64 on a system with a 64-bit kernel (which can only run on a 64-bit CPU) and on systems with a 32-bit kernel, it will return 1386, or similar 16886. Any 32-bit kernel can run on a 64-bit CPU, but itself controls the hardware and the software, which you will likely find this difference.

Under Linux, you can inspect the flags in /proc/cpuinfo virtual file. If it contains the lm attribute, then your CPU is 64-bit; otherwise, it is a 32-bit. The following command will tell you what kind of CPU you have:

```
$ grep -qP 'flags\s*:\.blm/' /proc/cpuinfo && echo 64-bit || echo 32-bit
```

Now that you know whether you need a 32 or 64-bit image, there is only one step left: selecting the kind of image. The default Kali Linux image and the Kali Light variant are both ISO that can be used to run the live system or to start the installation process. They differ only by the set of pre-installed applications. The default image comes with the GNOME desktop and a large collection of packages to be appropriate for more penetration testers, while the light image comes with the Xf desktop (which is much less demanding on system resources), and a limited collection of packages, allowing you to choose only the apps you need. The remaining images use alternate desktop environments but come with the same large package collection as the main image.

Once you have decided on the image you need, you can download the image by clicking "ISO" in the respective row. Alternatively, you can download the image from BitTorrent peer-to-peer network by clicking on "Torrent," provided that you have a BitTorrent client associated with the .torrent extension.

While you have chosen ISO image downloading, you should take note of the checksum written in the sha256sum column. Once you have downloaded your image, use this checksum to verify that the downloaded image matches the Kali development team put (see next section).
