installation of a package when a dependency is not met, or when there is a conflict. The result is an inconsistent system from the point of view of dependencies, and the APT commands will refuse to execute any action except those that will bring the system back to a consistent state (often consists of installing the missing dependency or removing a problematic package). This usually results in a message like this one, obtained after installing a new version of rdesktop ignoring its dependency on a newer version of libc6:

# # apt full-upgrade

```
[...]
You might want to run 'apt-get -f install' to correct these.
The following packages have unmet dependencies:
desktop: Depends: libc6 (>= 2.5) by 2.3.6-ds1-letch7 is installed
U: Unmet dependencies. Try using -f.
```

If you are a cautious administrator who is of the correctness of your analysis, you may choose to ignore a dependency or conflict and use the corresponding --force-* option. In this case, if you want to be able to continue to use apt or aptitude, you must edit /var/lib/dpkg/status to delete or modify the dependency, or conflict, that you have chosen to override.

This manipulation is an ugly hack and should never be used, except in the most extreme case of necessity. Quite a more fitting solution is to recompile the package that is causing the problem or use a new version (potentially corrected) from a repository providing backports (backports are newer versions especially recompiled to work in an older environment).

# 8.2.7. Frontends: aptitude and synaptic

APT is a C++ program whose code mainly resides in the libapt-pkg shared library. Thanks to shared library, it opened the door for the creation of user interfaces (front-ends), since the shared library code can easily be reused. Historically, apt-get was only designed as a front-end for libapt-pkg but its success tends to obscure this fact.

Over time, despite the popularity of command line interfaces like apt and apt-get, various graphical interfaces were developed. We will take a look at two of these interfaces in this section: aptitude and synaptic.

# Aptitude

Aptitude, shown in Figure 8.1, "The aptitude package manager" [page 191], is an interactive program that can be used in semi-graphical on the console. You can browse the list of installed and available packages, look up all the information, and select packages to install or remove. The program is designed specifically to be used by administrators as its default behavior is much more intelligent than APT's, and its interface much easier to understand.
