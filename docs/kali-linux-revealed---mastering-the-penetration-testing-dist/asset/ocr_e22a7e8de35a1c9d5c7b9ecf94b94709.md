Ready to Create Virtual Machine
Click Finish to create the virtual machine. Then you can install Debian 8.x 64-bit.

The virtual machine will be created with the following settings:

![](bbox=[0.347, 0.607, 0.652, 0.62])

VMware Workstation is now configured to create the new virtual machine. It displays a summary of the choices made so that you can double-check everything before creating the machine. Notice that the wizard opted to allocate only 512 MB of RAM to the virtual machine, which is not enough to click on Customize Hardware... (Figure 2.24, "Ready to Create Virtual Machine" [page 41]) and tweak the Memory setting, as shown in Figure 2.25, "Configure Hardware Window" [page 42].
