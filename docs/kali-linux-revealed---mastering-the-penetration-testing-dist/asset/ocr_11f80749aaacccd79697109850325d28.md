Note when you are prompted for a passphrase, you should enter an empty value (and confirm
t you don't want to protect your private key) as you want to be sign the repository non-\interactively. Note also that gpg requires access to the terminal to securely prompt
a for passphrase: that is why you changed the ownership of the virtual terminal (which is owned
by root you initially connected as that) before starting a shell as pkgrepo.

Now you can start up the repository. A dedicated directory is necessary for reprore and
inside that directory you have to create a conf/distributions file documenting which dist-
ions are available in the repository:

```
$ mkdir -p reprore/conf
$ cd reprore
$ cat >conf/distributions <<END
Codename: offsec-internal
AlsoAcceptFor: unstable
Origin: Offensive Security
Description: Offsec's Internal packages
Architectures: source amd64 i386
Components: main
SignWith: F8EE22F7F4F1B71AE38DA61B2F7F7F4B47F7B4EF2FD0D
END
```
