Once you continue from the main installer failure screen (Figure 4.26, "Installation Step Failed" [page 96]), you will be returned to a screen that you will normally see (the Main Menu shown in Figure 4.28, "Main Menu of the Installer" [page 98]), which allows you to launch one installation step after another. If you managed to fix the problem through the shell access (congratulations!) then you can retry the step that failed.
