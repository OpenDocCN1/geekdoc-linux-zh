To start rebuilding Kali package, first download the source package, which is composed of a *.dsc (Debian Source Control) file and additional files referenced from that control file.

Source packages are stored on HTTP-accessible mirrors. The most efficient way to obtain them with apt source-package-name, which requires that you add a deb-src line to the /etc/apt/sources.list and update the index files with apt update.

Additionally, you can use dget (the descripts package) to download a .dsc file directly together with its accompanying files. For Kali-specific packages whose sources are hosted in a Git repository on github.com/kalilinux/packages¹⁰ you can retrieve the sources with git clone https://github.com/kalilinux/packages/source-package.git.

After downloading sources, install the packages listed in the source package's build dependencies with sudo apt build-dev /. This command must be run from the package's source directory.

Updates to a source package consist of a combination of some of the following steps:

+   - The first step is changing the version number to distinguish your package from the original with dch --local version-identifier, or modify other package details with dch.
- Applying a patch -pl < patch-file or modifying your quilt's patch series.
- Tweaking build options, usually found in the package's debian/rules file, or other files in the debian/directory.

After modifying a source package, you can build the binary package with dpkg-buildpackage -us -uc from the source directory, which will generate an unsigned binary package. The package can then be installed with dpkg -i package_name_version_arch.deb.

# 9.5.2. Summary Tips for Recomp the Linux Kernel

As an advanced user, you may wish to recompile the Kali kernel. You may want to slow down the standard Kali kernel, which is loaded with many features and add non-standard drivers or features, apply kernel patches. Beware: a misconfigured kernel can destabilize your system and you must be prepared to accept that Kali cannot ensure security updates for your custom kernel.

For most kernel modifications, you will need to install a few packages with apt install-essential libc5-dev fakeroot.

The command apt-cache search ^linux-source should list the latest kernel version packaged by Kali, and apt install linux-source-version-number installs a compressed archive of the kernel source into /usr/src.
