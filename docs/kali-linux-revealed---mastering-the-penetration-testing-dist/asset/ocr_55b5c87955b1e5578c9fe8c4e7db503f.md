# Partition disks

Before the Logical Volume Manager can be configured, the current partitioning scheme has to be to disk. These changes cannot be undone.

After the Logical Volume Manager is configured, no additional changes to the partitioning scheme of disks containing physical volumes are allowed during the installation. Please decide if you are satisfied with the partitioning scheme before continuing.
