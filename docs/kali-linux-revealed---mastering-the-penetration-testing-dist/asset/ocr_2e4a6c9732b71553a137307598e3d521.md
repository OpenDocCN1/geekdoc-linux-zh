# 9.2.2. Getting the Sources

Since the Linux kernel sources are available as a package, the apt-cache search ^linux-source command should list the latest kernel version packaged by Kali. Note that the source code contained in these packages does not correspond precisely with that [https://kernel.org/] published by Linux Torvalds and the kernel developers*; like all distributions, Debian and Kali apply a number of patches, which might (or not) find their way into the upstream version of Linux. These modifications include backports of fixes/features from newer kernel versions, new features not yet (entirely) merged in the upstream Linux, and sometimes even Debian or Kali specific changes.

The remainder of this section focuses on the 4.9 version of the Linux kernel, but the examples can be, of course, adapted to the particular version of the kernel that you want.
