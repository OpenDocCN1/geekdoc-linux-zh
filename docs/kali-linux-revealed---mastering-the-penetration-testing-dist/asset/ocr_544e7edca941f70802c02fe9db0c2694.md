ponents are a sort of sub-section of the distribution, which can be enabled separately in APT sources. The Origin and Distribution fields are purely informative and they are copied as-is in the Release file. The SignWith field asks repropro to sign the repository with the GnuPG key whose identifier is listed (put the fingerprint here to ensure you use the correct key, and not another one colliding on the short identifier). The AlsoAcceptFor setting is not required but makes it possible to process .changes files whose Distribution field has a value listed here (without this, it would only accept the distribution's codename in that field).

With this basic setup, you can let repropro generate an empty repository:

```
$ repropro export
Exporting indices...
$ find \
\n./db

./db/packages.db
./db/release.caches.db
./conf
./conf/distributions
./dists
```

As you see, repropro creates the repository meta-information in a dists sub-directory. It also initialized an internal database in a db sub-directory.
