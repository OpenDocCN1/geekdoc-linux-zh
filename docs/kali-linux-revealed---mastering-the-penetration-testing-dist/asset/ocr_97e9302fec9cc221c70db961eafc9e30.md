The most convenient method, and the one that we recommend, is to let the installer start a web server hosting the log files (Figure 4.30, “Save Debug Logs (2/2)\” [page 100]). You can then launch a browser from another computer on the same network and download all the log files and screen-shots that you have taken with the Screenshot button available on each screen.
