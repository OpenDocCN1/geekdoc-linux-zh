# 9.1.1. Getting the Sources

Rebuilding a Kali package starts with getting its source code. A source package is composed of multiple files: the main file is *.desc (Debian Source Control) as it lists the other files, which can be *.tar.gz,bz2, xz, sometimes *.diff.gz, or *. debian.tar.gz,bz2, xz files.

The source packages are stored on Kali mirrors that are available over HTTP. You could use your web browser to download all the required files by the easiest way to accomplish this is using the apt source source_package name command.
