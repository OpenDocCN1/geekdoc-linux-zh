# 9.4.3. Setting Up Encrypted Persistence on a USB Key

Live-boot is also able to handle persistent file systems on encrypted partitions. You can thus protect the data of your persistent directories by creating a LUKS encrypted partition holding the persistence data.

The initial steps are the same as the creation of a partition instead of formatting it with an ext4 file system, use cryptsetup to initialize it as a LUKS container. Then open container and setup the ext4 file system in the same way as in the non-encrypted setup, but instead of using the /dev/sdb3 partition, use the virtual partition created by cryptsetup. This virtual partition represents the decrypted content of the encrypted partition, which is available in /dev/mapper In the example below, we will use the name kali_persistence. Again, ensure that you use the correct drive and partition.

```
# cryptsetup --verbose --verify-passphrase luksFormat /dev/sdb3
```
