# 1.10 Exercises

+   Using IBM Data Studio, create a stored procedure P2 that does nothing. Call this stored procedure from the DB2 Command Window or Linux shell.

+   Using IBM Data Studio, create a function F2 that takes no parameters and returns the value 2000. Invoke this function from the DB2 Command Window or Linux shell.

+   Modify P2 so it now invokes F2. Test it out!
