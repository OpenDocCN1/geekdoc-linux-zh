+   2. Verify your DB2 installation has the required libraries and header files

After installing DB2 verify that the necessary static and shared libraries and header files to develop C/C++ programs are present.

On Linux, this can be done by going to the DB2 install directory and checking for the `lib32` and `lib64` directory. For example if the DB2 install directory is in $HOME, then the 32-bit libraries location will be in $HOME/sqlllib/lib32, and the 64-bit libraries location will be in $HOME/sqlllib/lib64.
