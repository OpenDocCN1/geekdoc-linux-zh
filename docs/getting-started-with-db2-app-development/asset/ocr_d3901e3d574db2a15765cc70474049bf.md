# 3.3.12 Dynamic SQL

In dynamic SQL, as opposed to static SQL, the entire SQL statement is not known at run time. For example if *coll* and *tabname* are variables in this statement, then we are dealing with dynamic SQL:

```
'SELECT ' || coll || ' FROM ' || tabname;
```
