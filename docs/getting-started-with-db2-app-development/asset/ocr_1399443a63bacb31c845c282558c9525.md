(3) In this line, we initialize the URL and choose to connect to the **SAMPLE** database. In the syntax of the URL we are not including the host name or the port number; therefore, this means Type 2 is being used. Type 2 needs a DB2 client to be installed, and use it to configure the connectivity to the **SAMPLE** database.

(4) In the case two arguments are passed to the program (**userID** and **password**), these will be used to get the connection; otherwise the program throws an exception. `DriverManager.getConnection(url,userID,passwd)` can also be called without a **userID** and **passwd** as follows: `DriverManager.getConnection(url)`. In this case the user ID logged on to the system would be used. For Type 4, as we will see next, this will not work, as this connection is taken as a remote TCP/IP connection and DB2 needs a user ID and password for all remote connections.
