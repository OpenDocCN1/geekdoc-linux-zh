PYTHONPATH=<setuptools_install_path>\site-packages/<ibm_db-xx.egg>

+   - On Linux (BASH shell):

```
export PYTHONPATH=<setuptools_install_path>/site-packages/<ibm_db-xx.egg>
```

```
(1) import ibm_db

(4) conn = ibm_db_dbi.Connection(ibm_db_conn)
(5) conn.tables('SYSCAT', '*')
```
