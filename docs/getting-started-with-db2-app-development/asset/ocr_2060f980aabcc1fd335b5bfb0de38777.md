# 8.3.3.3.5 Creating and calling stored procedures

You can create SQL stored procedures using PHP with PDO just like you execute any other SQL. But if you need to call the stored procedure from the client, you need to take care of binding the parameters depending on their type. There are three types of parameters in a stored procedure and they are **IN**, **OUT**, and **INOUT**. In the bind parameter, the data type constant and the parameter are associated with bitwise OR operator (|). The parameter type `PDO::PARAM_INPUT_OUTPUT` is used for the **OUT** and **INOUT** parameters. No parameter type is needed for the IN parameter. *Listing 8.24* shows a stored procedure with all three types of parameters and returning result sets. Once the stored procedure is executed, the variables which are bound with the stored procedure parameter markers will be populated with the values from the stored procedure execution.
