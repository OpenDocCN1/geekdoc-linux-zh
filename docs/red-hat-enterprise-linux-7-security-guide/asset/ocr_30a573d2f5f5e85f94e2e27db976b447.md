| Event Type | Explanation |
| --- | --- |
| CRYPTO_IPSEC_SA | Trigggered when an Internet Protocol Security Association is established. |
| CRYPTO_KEY_USER | Trigggered to record the cryptographic key identifier used for cryptographic purposes. |
| CRYPTO_LOGIN | Trigggered when a cryptographic officer login attempt is detected. |
| CRYPTO_LOGOUT | Trigggered when a cryptographic officer logout attempt is detected. |
| CRYPTO_PARAM_CHANGE_USER | Trigggered when a change in a cryptographic parameter is detected. |
| CRYPTO_REPLAY_USER | Trigggered when a replay attack is detected. |
| CRYPTO_SESSION | Trigggered to record parameters set during a TLS session establishment. |
| CRYPTO_TEST_USER | Trigggered to record cryptographic test results as required by the FIPS-140 standard. |
| CWD | Trigggered to record the current working directory. |
| DAC_CHECK | Trigggered to record DAC check results. |
| DAEMON_ABORT | Trigggered when a daemon is stopped due to an error. |
| DAEMON_ACCEPT | Trigggered when the **auditd** daemon accepts a remote connection. |
| DAEMON_CLOSE | Trigggered when the **auditd** daemon closes a remote connection. |
| DAEMON_CONFIG | Trigggered when a daemon configuration change is detected. |
| DAEMON_END | Trigggered when a daemon is successfully stopped. |
| DAEMON_ERR | Trigggered when an **auditd** daemon internal error is detected. |
| DAEMON_RESUME | Trigggered when the **auditd** daemon resumes logging. |
| DAEMON_ROTATE | Trigggered when the **auditd** daemon rotates the Audit log files. |
| DAEMON_START | Trigggered when the **auditd** daemon is started. |
| DEL_GROUP | Trigggered when a user-space group is deleted |
| DEL_USER | Trigggered when a user-space user is deleted |
