# 1. 引言

# 核心 LINUX 终端命令

Linux 终端通常被称为命令行界面（CLI），是一个强大的工具，它为用户提供了对系统无与伦比的控制力。与提供点点点击方式的图形化用户界面（GUI）不同，终端允许进行更精确、高效和自动化的系统管理。无论你是系统管理员、开发者还是仅仅的技术爱好者，精通终端命令对于充分利用 Linux 系统的潜力都至关重要。

## 为什么要使用 LINUX 终端？

## 速度与效率

终端允许快速执行任务。例如，使用一个简单的 `find` 命令可以在几秒钟内跨目录搜索特定文件，而如果使用 GUI，完成相同任务可能需要花费得得多。

## 自动化

通过使用脚本，你可以自动化执行重复任务（例如备份或更新），这些任务可以被安排在特定时间运行，而无需人工干预。例如，一个简单的 Bash 脚本就可以自动化更新系统并清理不需要文件的过程。

## 远程管理

系统管理员可以通过 SSH（安全外壳）远程管理服务器和设备，在无需物理接触机器的情况下执行更新、监控系统性能并排排除故障。

## 访问高级功能

许多高级系统功能只能通过终端访问。诸如 `grep` 用于文件内搜索、`awk` 用于数据提取和报告、以及 `sed` 用于文本处理等命令，提供的功能远超标准 GUI 工具的范围。

## 自定义

终端提供了广泛的自定义选项。用户可以为经常使用的命令创建别名（aliases），自定义提示符，并配置环境变量以定制自己的工作流。

## 学习与故障排除

使用终端有助于加深你对 Linux 运行机制的理解。命令行输出通常更详细且包含更多信息，有助于故障排除和问题解决。如 `dmesg` 等命令可以提供内核消息的洞察，而 `top` 则提供了系统进程的视图。

# 核心命令概述

本指南旨在向你介绍构成日常任务的核心 Linux 终端命令。从文件管理、系统监控到网络配置和进程控制，这些命令将使你能够轻松地导航和操作系统。无论你是想要建立技能的初学者，还是寻求精进命令行熟练度的经验用户，本汇编都将是一个宝贵的资源。

## 符号链接

符号链接（也称为 symlink 或软链接）是 Linux 中指向另一个文件或目录的一种文件。它是一个快捷方式，提供了访问文件或目录的替代路径。

这里是更详细的内容：

## 符号链接的特性

- 指向另一个文件/目录：符号链接指向另一个文件或目录的位置。它包含了目标文件或目录的路径。

- 数据不具有所有权：与硬链接不同，符号链接不包含目标文件的实际数据。如果目标文件被删除，符号链接将变成一个悬空链接（dangling link），指向一个不存在的文件。

- 可以跨文件系统：符号链接可以指向跨越不同文件系统的文件或目录。

- 权限：符号链接的权限与目标文件的权限无关。系统会遵循链接并检查目标文件的权限。

## 创建符号链接

你可以使用 `ln` 命令配合 `-s` 选项创建符号链接。
语法如下：

```
ln -s [target] [link_name]
```

`target`：你想要链接的文件或目录的路径。
`link_name`：你正在创建的符号链接的名称。

示例：

为文件 `myfile.txt` 创建一个名为 `mylink` 的符号链接：
`ln -s myfile.txt mylink`
现在，`mylink` 充当 `myfile.txt` 的快捷方式。你可以使用 `mylink` 打开、读取和编辑 `myfile.txt`。





## 查看符号链接

你可以使用 `ls -l` 命令在目录列表中识别符号链接。符号链接通常以权限字符串开头的 `l` 标明，并且链接将显示它指向的内容：

```
lrwxrwxrwx 1 user group 11 Mar 8 12:34 mylink -> myfile.txt
```

## 删除符号链接

要删除符号链接，你可以使用 `rm` 命令：
```bash
rm mylink
```

这将删除符号链接 `mylink`，但不会影响目标文件 `myfile.txt`。

### 用场景

- 快捷方式：为深层嵌套的目录创建易记的快捷方式。
- 版本控制：指向文件或目录的不同版本。
- 资源管理：管理多个版本的软件库。

总而言，Linux 中的符号链接是一个强大的功能，可用于创建快捷方式并高效地管理文件和目录。

# 2. 基础命令

## PWD 命令

在 Unix 操作系统（包括 Linux 和 macOS）中，`pwd` 命令代表“print working directory”（打印工作目录）。它用于显示当前工作目录的完整路径。这里是一些说明 `pwd` 如何行使的示例：

## 基础用法

### 简单的 `pwd` 命令：

- 当你输入 `pwd` 并按回车时，它将输出你当前所在的目录。

```bash
$ pwd
/home/user
```

### 不同场景的示例

### 切换目录后：

如果你使用 `cd` 切换目录然后使用 `pwd`，它将显示新的目录路径。

```bash
$ cd /usr/local
$ pwd
/usr/local
```

### 在脚本中使用 `PWD`：

你可以在 Shell 脚本中使用 `pwd` 来获取当前目录路径。

```bash
#!/bin/bash
echo "The current directory is: $(pwd)"
```

当你运行此脚本时，它将打印当前目录。

### 将 `pwd`与其他命令结合：

你可以使用命令替换将 `pwd` 与其他命令结合。
例如，在当前目录中使用其完整路径创建一个文件。

```bash
$ touch "$(pwd)/newfile.txt"
```

## 高级用法

### 使用选项（虽然很少见）：

`pwd` 命令通常没有很多选项，但某些版本可能支持 `-L` 和 `-P` 选项来不同处理符号链接。

```bash
$ cd /tmp
$ ln -s /home/user symlink_to_home
$ cd symlink_to_home
$ pwd -L # 显示逻辑路径
/tmp/symlink_to_home
$ pwd -P # 显示物理路径
/home/user
```

- `-L` (logical)：打印逻辑路径，包含符号链接。
- `-P` (physical)：通过解析符号链接打印物理路径。

### 实际应用

### 脚本编写与自动化：

## `MKDIR` 命令

在 Unix 类操作系统（如 Linux 和 macOS）中，`mkdir` 命令用于创建目录（也称为文件夹）。以下是其用法详解及示例：

## 基本语法

```
mkdir [options] directory_name
```

## 基础用法

### 创建单个目录：

```
mkdir my_directory
```

此命令在当前工作目录中创建一个名为 `my_directory` 的目录。

## 创建多个目录

你可以通过连续指定多个目录来一次创建多个目录：

```
mkdir dir1 dir2 dir3
```

此命令会在当前工作目录中创建三个名为 `dir1`、`dir2` 和 `dir3` 的目录。

## 创建嵌套目录

如果你需要在一个命令中创建嵌套目录（目录中的目录），请使用 `-p` 选项：

```
mkdir -p parent_dir/child_dir/grandchild_dir
```

此命令会同时创建 `parent_dir`、`parent_dir/child_dir` 和 `parent_dir/child_dir/grandchild_dir`。如果没有 `-p` 选项，当任何中间目录不存在，`mkdir` 将返回错误。

## 处理错误

如果目录已存在且你尝试在不使用 `-p` 的情况下再次创建，`mkdir` 将返回错误：

```
mkdir existing_dir
```

如果 `existing_dir` 已存在，命令将失败。使用 `-p` 则会在目录存在时抑制错误：

```
mkdir -p existing_dir
```

如果 `existing_dir` 已存在，此命令将不会返回错误。

## 设置权限

你可以使用 `-m` 选项后跟权限模式（八进制）来为新目录设置权限：

```
mkdir -m 755 new_dir
```

此命令创建 `new_dir` 并将其权限设置为 `755`（所有者具有读、写、执行权限；其他人具有读、执行权限）。

## 详细输出

获取所创建目录的详细输出，请使用 `-v` 选项：

```
mkdir -v new_dir
```

此命令会为每个创建的目录打印一条消息。

## 总结

- 创建单个目录：
`mkdir my_directory`

- 创建多个目录：
`mkdir dir1 dir2 dir3`

- 创建嵌套目录：
`mkdir -p parent_dir/child_dir/grandchild_dir`

- 创建具有特定权限的目录：
`mkdir -m 755 secure_dir`

- 创建带有详细输出的目录：
`mkdir -v verbose_dir`

这些是 `mkdir` 命令最常用的用法。它是一个强大且多功能的命令，对于 Unix 类系统的目录管理至关重要。

## `RMDIR` 命令

在 Unix 类操作系统（包括 Linux 和 macOS）中，`rmdir` 命令用于删除空目录。如果目录为空，`rmdir` 将不会删除它并返回错误消息。

以下是一些帮助解释 `rmdir` 的关键点和示例：

## 基本语法

`rmdir` 命令的基本语法为：

```
rmdir [options] directory_name
```

## 示例

### 删除单个空目录

假设你有一个名为 `example_dir` 的空目录：

```
rmdir example_dir
```

## 删除多个空目录

你可以在一个命令中删除多个空目录：

```
rmdir dir1 dir2 dir3
```

如果 `dir1`、`dir2` 和 `dir3` 均为空，则将删除它们。

## 使用 `-P` 选项删除父目录

`-p`（或 `--parents`）选项允许你在删除目录后，如果其父目录变为空，则一并删除这些父目录：

```
rmdir -p dir1/dir2/dir3
```

如果 `dir3`、`dir2` 和 `dir1` 均为空，则将删除它们。

## 处理错误

### 目录不为空

如果目录为空，`rmdir` 将不会删除它并显示错误消息：

```
rmdir non_empty_dir
```

错误消息：
rmdir: failed to remove 'non_empty_dir': Directory not empty

### 目录不存在

如果目录不存在，`rmdir` 将返回错误：

```
rmdir non_existent_dir
```

错误消息：
rmdir: failed to remove 'non_existent_dir': No such file or directory

## 实际示例

让我们来看一个实际示例。假设你有以下结构：

```
project/
└── src/
    └── main/
```

1. 删除 `main`：
`rmdir project/src/main`

2. 删除 `main` 后删除 `src`：
`rmdir project/src`

3. 使用 `-p` 一次删除所有空目录：
`rmdir -p project/src/main`

## 总结

`rmdir` 命令用于删除空目录。它是一个安全的工具，因为它不会删除包含文件的目录。

## `TOUCH` 命令

`touch` 命令是 Unix 类系统（包括 Linux 和 macOS）中的一个基础实用程序，主要用于创建文件和更新时间戳。以下是一些常见用法：

### 创建空文件

touch filename

示例：

```
touch example.txt
```

此命令将创建 `example.txt`。如果 `example.txt` 已经存在，它的访问时间修改修改时间将得到更新。

## 一次创建多个文件

touch file1 file2 file3

示例：

```
touch file1.txt file2.txt file3.txt
```

此命令将创建三个空文件。

## 更新现有文件的时间戳

当你对现有文件运行 `touch` 时，它会将访问时间和修改时间更新为当前时间。

touch existingfile.txt

示例：

```
touch existingfile.txt
```

此命令将更新 `existingfile.txt` 的访问和修改时间戳。

## 设置特定时间戳

你可以使用 `-t` 选项为文件设置特定的时间戳：

```
touch -t [[CC]YY]MMDDhhmm[.ss] filename
```

示例：

```
touch -t 202401010000.00 example.txt
```

此命令将 `example.txt` 的修改和访问时间设置为 2024 年 1 月 1 日午夜 (00:00)。

## 使用参考文件

你可以使用 `-r` 选项将一个文件的时间戳设置为与另一个文件相同：

touch -r reference target target

示例：

```
touch -r oldfile.txt newfile.txt
```

此命令将 `newfile.txt` 的访问和修改时间设为与 `oldfile.txt` 匹配。

## 在不覆盖的情况下创建文件

使用 `-c` 选项时，如果文件不存在，`touch` 将不会创建文件。它只会在文件存在时更新时间戳。

touch -c filename

示例：

```
touch -c maybe_exists.txt
```

如果 `maybe_exists.txt` 存在，则其时间戳将得到更新。如果它不存在，则不会创建文件。

## 常用选项总结

- `-a`：仅更改访问时间。
- `-m`：仅更改修改时间。
- `-c` 或 `--no-create`：不创建任何文件。
- `-r file`：使用 `file` 的时间。
- `-t STAMP`：使用指定的时间（格式为 `[[CC]]YY]MMDDhhmm[.ss]]`

这些示例应该让你良好地理解如何在 Unix 类系统中使用 `touch` 命令来创建文件和操作时间戳。





# `CP` (COPY) 命令

`cp`（复制）命令用于 Unix 和类 Unix 操作系统（如 Linux 和 macOS），将文件和目录从一个位置复制到另一个位置。以下是一些常见的示例和选项：

## 基础用法

### 复制文件：

```
cp source_file.txt destination_file.txt
```

此命令将 `source_file.txt` 复制到 `destination_file.txt`。如果 `destination_file.txt` 不存在，则将创建它。如果它已存在，则会被覆盖。

### 将文件复制到目录：

```
cp source_file.txt /path/to/destination_directory/
```

此命令将 `source_file.txt` 复制到指定的目录。该目录必须已经存在。

## 常用选项

将多个文件复制到目录：

```
cp file1.txt file2.txt file3.txt /path/to/destination_directory/
```

此命令将 `file1.txt`、`file2.txt` 和 `file3.txt` 复制到指定的目录。

```
cp -r /path/to/source_directory /path/to/destination_directory/
```

`-r`（或 `--recursive`）选项会将源目录的所有文件和子目录复制到目标目录。如果目标目录不存在，则将创建它。

### 保留文件属性：

```
cp -p source_file.txt destination_file.txt
```

`-p` 选项保留原始文件的属性，例如时间戳、所有权和权限。

### 交互模式：

```
cp -i source_file.txt destination_file.txt
```

`-i`（interactive）选项在覆盖目标位置已存在的文件之前提示用户。

### 详细模式：

```
cp -v source_file.txt destination_file.txt
```

`-v`（verbose）选项会显示复制过程的详细输出，在复制文件时列出这些文件。

### 更新文件：

```
cp -u source_file.txt destination_file.txt
```

`-u`（update）选项仅在源文件比目标文件新或目标文件不存在时才复制该文件。

### 组合选项

你可以组合多个选项来自定义 `cp` 命令的行为。例如：

```
cp -r -v -p /path/to/source_directory /path/to/destination_directory/
```

此命令递归地复制源目录到目标目录，保留文件属性并提供详细输出。

## 示例

### 将单个文件复制到另一个文件：

```
cp file1.txt file2.txt
```

这会将 `file1.txt` 复制到 `file2.txt`。

### 将文件复制到目录：

```
cp file1.txt /home/user/documents/
```

这会将 `file1.txt` 复制到 `/home/user/documents/` 目录。

### 将整个目录复制到另一个目录：

```
cp -r /home/user/pictures /backup/
```

这会将 `pictures` 目录及其所有内容复制到 `backup/` 目录。

### 复制时保留文件属性：

```
cp -p file1.txt /backup/file1.txt
```

这会将 `file1.txt` 复制到 `backup/` 并保留其原始属性。

### 交互式复制文件：

```
cp -i file1.txt /home/user/documents/
```

这将在覆盖 `/home/user/documents/` 中的任何现有文件之前提示你。

### 目录的详细复制：

```
cp -rv /home/user/music /backup/
```

这会递归且详细地将 `music` 目录复制到 `/backup/`。

这些示例应该涵盖了你在使用 `cp` 命令时会遇到大多数常见场景。

# 3. 文件权限

## `CHOWN` 命令

Unix 和类 Unix 系统中的 `chown` 命令用于更改文件和目录的所有权。

该命令允许为文件指定新的所有者以及可选的新组。

## 基本语法

```
chown [OPTION] OWNER[:GROUP] FILE... 
```





## OWNER：文件的新所有者。

GROUP：（可选）文件的新用户组。如果未指定，则用户组保持不变。

FILE：要更改所有权的文件或目录。

## 更改文件的所有所有者：

```
chown alice file.txt
```

此命令将 `file.txt` 的所有者更改为 `alice`。

## 更改文件的所有者和组：

```
chown alice:developers file.txt
```

这将 `file.txt` 的所有者更改为 `alice`，组更改为 `developers`。

## 更改多个文件的所有者：

```
chown alice file1.txt file2.txt
```

这将 `file1.txt` 和 `file2.txt` 的所有者更改为 `alice`。

## 递归更改目录及其内容的所有者：

```
chown -R alice:developers /home/alice
```

这将 `/home/alice` 及其内部所有文件和目录的所有者和组分别改为 `alice` 和 `developers`。

## 仅更改文件的用户组：

```
chown :developers file.txt
```

这会将 `file.txt` 的组更改为 `developers`，而保持所有者不变。

## 选项

- -R：递归更改目录及其内容的所有权。
- -h：更改符号链接本身的所有权，而不是它们指向的文件。
- -reference=RFILE：使用 RFILE 的所有者和组，而不是指定 OWNER:GROUP 值。

## 总结

`chown` 命令是 Unix 类系统中更改文件和目录所有权及用户组的强大工具。其基本语法涉及为目标文件或目录指定新的所有者，以及可选的新组。该命令也可以递归应用于目录。关键选项包括用于递归更改的 `-R` 和用于影响符号链接的 `-h`。理解如何有效使用 `chown` 对于多用户环境下的文件权限和所有权至关重要。

## `CHMOD` 命令

Unix 和类 Unix 操作系统（如 Linux）中的 `chmod` 命令用于更改文件和目录的模式位。该命令可以修改文件和目录的读、写、执行权限。

## 理解权限

## 在类 Unix 系统中，每个文件和目录都有三种权限：

- 1. 读取 (r)：读取文件或列出目录内容的权限。
- 2. 写入 (w)：修改文件或目录的权限。
- 3. 执行 (x)：执行文件或访问目录的权限。

## 这些权限针对三类用户定义：

- 1. 用户 (u)：文件的所有者。
- 2. 组 (g)：属于文件用户组的其他用户。
- 3. 其他 (o)：所有其他用户。

## 数字（八进制）表示

权限可以使用三个数字用数值表示，其中每个数字都是代表读取 (4)、写入 (2) 和执行 (1) 权限的值之和：

```
`r = 4`
```

```
`w = 2`
```

```
`x = 1`
```

## 例如：

`7` (读 + 写 + 执行)：`4 + 2 + 1`

`6` (读 + 写)：`4 + 2`

`5` (读 + 执行)：`4 + 1`

`4` (只读)：`4`

`3` (写 + 执行)：`2 + 1`

`2` (只写)：`2`

`1` (只执行)：`1`

`0` (无权限)：`0`

## 符号表示

## 权限也可以用以下符号表示：

- `u` 代表用户
- `g` 代表组
- `o` 代表其他
- `a` 代表所有（用户、组和其他人）

并使用：

- `+` 添加权限
- `-` 移除权限
- `=` 设置精确权限

## 数字方法

## 示例 1：

授予用户 读、写、执行权限，并授予组和其他人读和执行权限。

```
chmod 755 filename
```

这设置了：

- 用户：读 (4) + 写 (2) + 执行 (1) = 7
- 组：读 (4) + 执行 (1) = 5
- 其他：读 (4) + 执行 (1) = 5

## 示例 2：

授予用户读、写权限，并授予组和其他人只读权限。

```
chmod 644 filename
```

这设置了：

- 用户：读 (4) + 写 (2) = 6
- 组：读 (4) = 4
- 其他：读 (4) = 4

## 符号方法

示例 3：为用户添加执行权限。

```
chmod u+x filename
```

示例 4：为用户移除执行权限。

```
chmod u-w filename
```

示例 5：为用户设置精确权限。

```
chmod u=rx filename
```

## `HEAD` 命令

Linux 中的 `head` 命令用于显示文件或输入的前几行。默认情况下，它显示前 10 行。该命令对于快速查看文件开头以理解其结构或内容，无需打开整个文件。

### 基础语法

`head [OPTION] [FILE]...`

## 常用选项

- `-n [NUMBER]`：显示文件的前 NUMBER 行。
- `-c [NUMBER]`：显示文件的前 NUMBER 字节。
- `-q`：在检查多个文件时抑制头信息。
- `-v`：在检查多个文件时始终显示头信息。

## 显示文件的前 10 行：

`head filename.txt`

## 显示文件的前 20 行：

```bash
head -n 20 filename.txt
```

## 显示文件的前 50 字节：

```bash
head -c 50 filename.txt
```

## 显示多个文件的前 5 行：

```bash
head -n 5 file1.txt file2.txt
```

## 显示多个文件的前 10 行（不带头信息）：

```bash
head -q file1.txt file2.txt
```

## 显示多个文件的前 10 行（始终带头信息）：

```bash
head -v file1.txt file2.txt
```

## 总结

`head` 命令是一个简单而强大的工具，用于快速查看文件的开头。它可以自定义显示特定数量的行或字节，并可以通过控制头信息的选项处理多个文件。该命令通常用于脚本编写和命令行数据检查，以预览文件内容。

## `tail` 命令

Linux 终端中的 `tail` 命令用于显示文件的最后部分。默认情况下，它显示文件的最后 10 行，但可以自定义显示不同数量的行甚至字节。它对于监控日志文件或检查文件的最新更改特别有用。

## 语法

`tail [OPTION] [FILE]...`

## 常用选项

- `-n,--lines=[+]NUM`：输出最后 NUM 行，而不是最后 10 行。带有前缀 `+` 则从从第 NUM 行开始输出。
- `-c,--bytes=[+]NUM`：输出最后 NUM 字节；带有前缀 `+` 则从第 NUM 字节开始。
- `-f,--follow`：随着文件的增长追加的数据；适用于日志文件。
- `-q,--silent`：不输出带有文件名的头信息。
- `-v,--verbose`：始终输出带有文件名的头信息。
- `-s,--sleep-interval=N`：使用 `-f` 时，迭代之间睡眠约 N 秒（默认值为 1.0）。

## 显示文件的最后 10 行：

```bash
tail filename.txt
```

此命令显示 `filename.txt` 的最后 10 行。

## 显示文件的最后 5 行：

```bash
tail -n 5 filename.txt
```

此命令显示 `filename.txt` 的最后 5 行。

## 显示文件的最后 20 字节：

```bash
tail -c 20 filename.txt
```

此命令显示 `filename.txt` 的最后 20 字节。

## 跟踪文件（实时监控）

```bash
tail -f /var/log/syslog
```

此命令实时监控 `/var/log/syslog` 文件，在添加新行时显示。

## 显示从第 5 行开始的行

```bash
tail -n +5 filename.txt
```

此命令显示从 `filename.txt` 的第 5 行开始到文件结束的内容。

## 以特定睡眠间隔跟踪文件

```bash
tail -f -s 2 /var/log/syslog
```

此命令监控 `/var/log/syslog` 文件，每隔 2 秒检查一次更新。





## 显示多个文件的最后 10 行

```
tail file1.txt file2.txt
```

此命令显示 `file1.txt` 和 `file2.txt` 的最后 10 行，并带有指示这些行所属哪个文件的表头。

## 总结

`tail` 命令是一个强大的实用，用于显示文件的末尾，对于实时监控日志文件特别有用。它支持各种选项来定制输出，包括行数或字节数、实时更新以及指定文件内起始点的能力。最常见的用例包括调试、日志文件监控和快速检查文件内容。

## `top` 命令

Linux 中的 `top` 命令是监控系统性能的强大工具。它提供了系统任务的动态实时视图，显示当前运行的进程及其资源使用情况。

用途：实时监控系统性能和资源使用。

关键特性：

- 显示关于 CPU 和内存使用的信息。
- 列出运行中的进程及其资源消耗。
- 允许用户交互以对显示的信息进行排序和过滤。

## 基本用法

要启动 `top` 命令，只需输入：

top

这将打开默认的 `top` 界面。显示分为两个主要部分：

1. 系统摘要：显示整体系统性能指标。
2. 进程列表：显示关于每个运行进程的详细信息。

## 关键区域和字段

在屏幕顶部，你将看到几行系统摘要信息：

- uptime: 第一行显示当前时间、系统运行时间、登录用户数和平均负载。
- tasks: 显示任务总数，以及运行中、睡眠中、停止和僵尸（zombie）任务的数量。
- CPU(s): 显示 CPU 使用率百分比，分为用户、系统、nice、空闲、等待、硬件中断、软件中断和窃取时间。
- Mem: 显示总内存、已用内存、空闲内存、缓冲区（buffers）和缓存内存（cached）。
- Swap: 显示总交换内存、已用交换内存和空闲交换。

## 进程列表

- 在系统摘要下方，你将看到进程列表，每个进程都有几列：

- PID: 进程 ID。
- USER: 拥有该进程的用户。
- PR: 进程的优先级。
- NI: 进程的 nice 值。
- VIRT: 进程使用的虚拟内存。
- RES: 进程使用的驻留内存。
- SHR: 进程使用的共享内存。
- S: 进程状态（例如 S 表示睡眠，R 表示运行）。
- %CPU: CPU 使用率百分比。
- %MEM: 内存使用率百分比。
- TIME+: 进程使用的总 CPU 时间。
- COMMAND: 启动进程的命令。

## 交互命令

在 `top` 运行时，你可以使用各种键盘命令与其进行交互：

- `h`: 显示帮助。
- `k`: 杀死进程（会提示输入 PID）。
- `r`: 调整进程优先级（更改其优先级）。
- `u`: 按特定用户过滤进程。
- `P`: 按 CPU 使用率排序。
- `M`: 按内存使用率排序。
- `N`: 按进程 ID 排序。
- `T`: 按时间排序。
- `q`: 退出 `top`

## 基本用法：

top

此命令将打开 `top` 界面，显示系统性能和运行进程的实时视图。

## 按内存使用率排序：

在 `top` 运行时，按 `M` 按内存使用率对进程排序。

## 按用户过滤：

在 `top` 运行时，按 `u`，然后输入用户名按按用户过滤进程。

## 杀死进程：

按 `k`，然后输入你想杀死的进程 PID。

## 调整进程优先级：

按 `r`，然后输入你想调整优先级的进程 PID，接着输入新的 nice 值。

## `du`（磁盘使用）命令

Linux 中的 `du` 命令用于估算文件空间占用。它可以各种格式显示文件和目录的大小，对于理解磁盘空间的使用情况很有用。

## 基本用法

du [OPTIONS] [FILE/DIRECTORY]

## 常用选项

- `-a` 或 `--all`: 显示所有文件的大小，而不只是目录。
- `-h` 或 `--human-readable`: 以人类可读的格式打印（例如 1K, 234M, 2G）。
- `-s` 或 `--summarize`: 仅显示每个参数的总计。
- `-c` 或 `--total`: 生成一个总计。
- `-dN` 或 `--max-depth=N`: 显示命令行参数下方 N 层以内的目录（或文件）总量。

## 基本用法：

du

这将显示当前目录及其所有子目录的磁盘使用情况。

## 人类可读格式：

```
du -h
```

这将以人类可读的格式显示大小，便于理解每个目录的大小。

## 汇总目录的磁盘使用：

```
du -s /path/to/directory
```

这将显示指定目录的总磁盘使用情况。





## 包含所有文件：

```
du -ah
```

这将以人类可读的格式显示所有文件和目录的磁盘占用情况。

## 限制深度：

```
du -h --max-depth=1
```

这将显示从当前目录开始的一级目录的磁盘占用情况。

## 总磁盘使用量：

```
du -ch /path/to/directory
```

这将显示每个目录和文件的磁盘占用情况，并在最后包含一个总计。

## 总结

`du` 命令是分析 Linux 系统上磁盘使用情况的强大工具。它提供了关于文件和目录如何使用磁盘空间的详细信息，允许用户识别可能占用过多空间的大文件和大目录。通过使用各种选项，用户可以自定义输出，以人类可读的格式显示磁盘使用情况，包括单个文件、汇总总量以及限制目录遍历的深度。

## `df` 命令（磁盘文件系统）

Linux 中的 `df` 命令代表 "disk filesystem"磁盘文件系统），用于显示计算机文件系统上的可用磁盘空间量。它提供了有关每个挂载系统的总空间、已用空间、可用空间以及使用百分比的信息。

### 基础语法

df [OPTION]... [FILE]...

## 常用选项

- `-h` 或 `--human-readable`: 以人类可读的格式显示大小（例如 1K, 234M, 2G）。

# `FIND` 命令

Linux 中的 `find` 命令是一个强大的工具，用于根据各种标准（如名称、类型、权限、修改日期等）搜索和定位文件及目录。以下是该命令如何工作的总结以及示例。

语法：

find [path] [expression]

常用选项：

- `-name pattern`：按模式搜索。
- `-iname pattern`：不区分大小写搜索模式。
- `-type [fd]`：搜索文件 (f) 或目录 (d)。
- `-mtime n`：搜索 n 天前修改的文件。
- `-size [+-size]`：根据大小搜索文件。
- `-exec command {} \;`：对找到的项目执行命令。
- `-delete`：删除搜索结果。

### 按名称查找文件：

```
find /path/to/search -name "filename"
```

### 在 `/home` 目录下查找所有名为 `test.txt` 的文件：

find /home -name "test.txt"

### 不区分大小写的搜索：

```
find /path/to/search -iname "filename"
```

示例：在 `/home` 目录下查找名为 `test.txt` 或 `TEST.TXT` 的文件：

```
find /home -iname "test.txt"
```

### 按名称查找目录：

```
find /path/to/search -type d -name "directoryname"
```

示例：查找所有名为 `backup` 的目录：

```
find / -type d -name "backup"
```

### 按修改时间查找文件：

```
find /path/to/search -mtime n
```

示例：查找过去 7 天内修改过的文件：

```
find /home -mtime -7
```

### 按大小查找文件：

```
find /path/to/search -size [+-size]
```

示例：查找所有大于 10 MB 的文件：

```
find /home -size +10M
```





# 在找到的文件上执行命令：

find /path/to/search -name "filename" -exec command {} \;

示例：查找所有 `*.log` 文件并删除它们：

```
find /var/log -name "*.log" -exec rm {} \;
```

# 删除找到的文件：

find /path/to/search -name "filename" -delete

示例：查找并删除所有 `*.tmp` 文件：

```
find /tmp -name "*.tmp" -delete
```

# 组合多个条件：

find /path/to/search -condition1 -and -condition2

示例：查找过去 2 天内修改过的 `*.txt` 文件：

```bash
find /home -name "*.txt" -and -mtime -2
```

`find` 命令功能极其强大，对于 Linux 中的系统管理、脚本编写和通用文件管理任务都非常有用。通过组合不同的选项和表达式，你可以创建针对你特定需求的复杂搜索。

## `grep` 命令

Linux 中的 `grep` 命令是一个强大的工具，用于在文件或输出中搜索特定的模式。"grep" 的名称代表 "全局正则表达式打印" (Global Regular Expression Print)，它通常用于在纯文本数据集中搜索匹配正则表达式的行。

## 语法

```
grep [options] pattern [file...]
```

# 简单搜索：

在名为 `file.txt` 的文件中搜索单词 "hello"。

```
grep "hello" file.txt
```

此命令会打印 `file.txt` 中包含单词 "hello" 的所有行。

# 不区分大小写的搜索：

以不区分大小写的方式搜索 "hello"。

```
grep -i "hello" file.txt
```

这将匹配 "hello"、"Hello"、HELLO" 等。

# 递归搜索：

在当前目录及其子目录的所有文件中搜索 "hello"。

```
grep -r "hello" .
```

# 搜索完整单词：

作为整个单词搜索单词 "hello"。

```
grep -w "hello" file.txt
```

这不会匹配 "hello123" 或 "123hello"。

# 显示行号：

搜索 "hello" 并显示找到匹配项的行号。

```
grep -n "hello" file.txt
```

# 统计匹配次数：

统计包含单词 "hello" 的行数。

```
grep -c "hello" file.txt
```

# 反向匹配：

显示不匹配单词 "hello" 的行。

```
grep -v "hello" file.txt
```

# 使用正则表达式：

搜索匹配正则表达式的行。例如，以 "hello" 开头的行。

```
grep "^hello" file.txt
```

# 组合选项：

组合多个选项。例如，递归搜索、不区分大小写并显示行号。

```
grep -rin "hello"
```

# 与其他命令配合管道：

通过管道将 `grep`与其他命令配合。例如，在 `ls -l` 的输出中搜索 "hello"。

```
ls -l | grep "hello"
```

## 总结

用途：`grep` 用于在文件中搜索模式。

基本语法：`grep [options] pattern [file...]`

# 常用选项：

- `-i`: 不区分大小写的搜索
- `-r`: 递归搜索
- `-w`: 搜索完整单词
- `-n`: 显示行号
- `-c`: 统计匹配次数
- `-v`: 反向匹配

正则表达式：使用 `grep` 配合正则表达式搜索以进行更复杂的模式匹配。

管道：将 `grep` 与其他命令结合以进行强大的文本处理。
`grep` 是 Linux 中文本处理和数据分析中多功能且必不可少的工具。通过精通它的选项和功能，你可以高效地搜索和操作文本文件以及命令输出。

## `tar` 命令

Linux 中的 `tar` 命令用于创建、维护、修改和提取 tar 格式归档的文件。"tar" 的名称代表 "磁带存档" (tape archive)，它是用于处理文件存档和备份的广泛使用的命令。

## 语法

以下是 `tar` 命令的一些最常用用法及其语法：

# 创建 tar 归档：

tar -cvf archive_name.tar /path/to/directory_or_files

- `-c`: 创建一个新的归档。
- `-v`: 显示列出已处理的文件（可选，用于查看正在归档的文件）。
- `-f`: 指定归档的文件名。

示例：
tar -cvf my_archive.tar /home/user/documents

提取 tar 归档：
tar -xvf archive_name.tar

- `-x`: 从归档中提取文件。

示例：
tar -xvf my_archive.tar

# 使用 gzip 创建压缩的 tar 归档：

tar -cvzf archive_name.tar.gz /path/to/directory_or_files

- `-z`: 通过 gzip 过滤归档。

示例：
```
tar -cvzf my_archive.tar.gz /home/user/documents
```

# 提取使用 gzip 的压缩 tar 归档：

tar -xvzf archive_name.tar.gz

示例：
```
tar -xvzf my_archive.tar.gz
```

使用 bzip2 创建压缩的 tar 归档：

```
tar -cvjf archive_name.tar.bz2 /path/to/directory_or_files
```

- `-j`: 通过 bzip2 过滤归档。

示例：
```
tar -cvjf my_archive.tar.bz2 /home/user/documents
```

# 提取使用 bzip2 的压缩 tar 归档：

```
tar -xvjf my_archive.tar.bz2
```

# 查看 tar 归档内容：

tar -tvf archive_name.tar

# 查看压缩 tar 归档的内容：

tar -tvzf archive_name.tar.gz

# 查看 bzip2 压缩 tar 归档的内容：

tar -tvjf archive_name.tar.bz2

# 向 tar 归档添加文件：

tar -rvf archive_name.tar /path/to/directory_or_files

# 向压缩的 tar 归档添加文件：

tar -rvzf archive_name.tar.gz /path/to/directory_or_files

# 向 bzip2 压缩的 tar 归档添加文件：

tar -rvjf archive_name.tar.bz2 /path/to/directory_or_files

# 从 tar 归档中删除文件：

tar --delete -f archive_name.tar

# 从压缩 tar 归档删除文件：

tar --delete -zf archive_name.tar.gz

# 从 bzip2 压缩 tar 归档删除文件：

tar --delete -jf archive_name.tar.bz2





# 解压缩单个文件

```
gunzip filename.txt.gz
```

这将 `filename.txt.gz` 解压缩为 `filename.txt`。

# 解压缩多个文件

```
gunzip file1.txt.gz file2.txt.gz file3.txt.gz
```

每个文件将分别解压缩为 `file1.txt`、`file2.txt` 和 `file3.txt`。

# 解压缩并保留原始压缩文件

```
gunzip -k filename.txt.gz
```

这将 `filename.txt.gz` 解压缩为 `filename.txt`，同时保留原始的 `filename.txt.gz`。

# 解压缩并输出到标准输出

```
gunzip -c filename.txt.gz > decompressed.txt
```

这将解压缩 `filename.txt.gz` 并将解压后的数据写入 `decompressed.txt`。

# 递归解压缩目录

```
gunzip -r directory_name
```

这将解压缩该目录及其子目录中的所有文件。

## 总结

`gzip`: 压缩文件以减小其体积。用以 `.gz` 结尾的压缩版本替换原始文件。

`gunzip`: 解压缩用 `gzip` 压缩的文件。将文件恢复到原始形式。

# Key Options

- `-c`: 两个命令均可输出到标准输出。
- `-k`: 保留原始文件（适用于两个命令）。
- `-r`: 递归压缩或解压缩目录中的文件。

这些命令对于 Linux 中的文件压缩和解压缩至关重要，有助于存储空间并方便文件传输。

# `APT` 命令

Linux 终端中的 `apt` 命令是一种软件包管理工具，用于 Ubuntu 等基于 Debian 的发行版。它简化了管理软件包的过程，包括安装、更新和删除软件包。以下是详细说明及一些示例。

# `APT` 概览

全称：Advanced Package Tool（高级软件包工具）

用途：简化软件包管理任务

发行版：Debian、Ubuntu 以及其他基于 Debian 的发行版

功能：安装、更新、升级、搜索和删除软件包

# 更新软件包列表

在安装或升级软件包之前，先更新软件包列表是一个好习惯，以便获取最新版本和依赖项。

```
sudo apt update
```

# 升级已安装的软件包

此命令将系统上的所有软件包升级到最新的可用版本。

```
sudo apt upgrade
```

# 全量升级

此命令不仅升级已安装的软件包，还会处理软件包新版本带来的依赖关系变化。

```
sudo apt full-upgrade
```

# 安装软件包

要安装新软件包，使用 `install` 子命令后接包名。

```
sudo apt install package_name
```

例如，安装 `curl` 软件包：

```
sudo apt install curl
```

# 软件包

要删除已安装的软件包，使用 `remove` 子命令。

```
sudo apt remove package_name
```

例如，删除 `curl` 软件包：

```
sudo apt remove curl
```

# 清除软件包 (Purge)

清除软件包会删除该包及其配置文件。

```
sudo apt purge package_name
```

# 搜索软件包

如果你不确定具体的软件包名称，可以进行搜索。

```
apt search keyword
```

例如，搜索与 `curl` 相关的软件包：

```
apt search curl
```

# 显示软件包信息

要显示特定软件包的详细信息，使用 `show` 子命令。

```
apt show package_name
```

例如，显示 `curl` 软件包的信息：

```
apt show curl
```

# 列出软件包

要列出所有可以升级的软件包：

```
apt list --upgradable
```

## "DEB" 概述

- 1. 定义：`deb` 关键字用于 APT 的 `sources.list` 文件中，用于定义 Debian 软件包仓库的位置。

- 2. 用途：它告诉 APT 在何处查找和下载软件包及更新。

- 3. 语法：在 `/etc/apt/sources.list` 或 `/etc/apt/sources.list.d/` 下的文件中，`deb` 行的典型语法为：

```
deb [options] uri distribution [component1] [component2] [...]
```

## "DEB" 行的组件

- options（可选）：APT 的额外选项。
- uri：仓库的 URL。
- distribution：发行版名称（例如 `buster`、`bullseye`、`focal`、`jammy`）。
- components：仓库的分区（例如 `main`、`contrib`、`non-free`）。

## 使用示例

让我们来看一些示例 `deb` 行在实践中是如何使用的。

## 标准 DEBIAN 仓库

- deb http://deb.debian.org/debian buster main contrib non-free
- URI: `http://deb.debian.org/debian`
- Distribution: `buster` (Debian 10)
- Components: `main`、`contrib`、`non-free`

## UBUNTU 仓库

- deb http://archive.ubuntu.com/ubuntu focal main restricted
- URI: `http://archive.ubuntu.com/ubuntu`
- Distribution: `focal` (Ubuntu 20.04)
- Components: `main`、`restricted`

## 添加 PPA（个人软件包存档）

- PPA 通常使用 `add-apt-repository` 命令添加，但也可以手动添加。
- deb http://ppa.launchpad.net/graphics-drivers/ppa/ubuntu focal main
- URI: `http://ppa.launchpad.net/graphics-drivers/ppa/ubuntu`
- Distribution: `focal`
- Component: `main`

## 总结

`deb` 行是 Debian 系系统中指定仓库的方式。它包含了仓库 URL、发行版代号和仓库组件。

正确配置 `deb` 行允许 APT 从指定的仓库查找并安装软件。

## 实际步骤：

找到 `sources.list` 文件：使用文本编辑器打开。
- sudo nano /etc/apt/sources.list

添加仓库：为你想要添加的仓库添加 `deb` 行。
- deb http://archive.ubuntu.com/ubuntu focal restricted

更新软件包列表：运行 `apt update` 刷新列表。
- sudo apt update

通过正确理解 `deb` 行，你可以有效管理软件源并保持系统拥有最新软件包的安全更新。

## PACMAN 命令
