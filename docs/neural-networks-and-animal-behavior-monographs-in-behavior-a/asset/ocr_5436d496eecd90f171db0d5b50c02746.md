How can we produce a network with receptive fields spanning the whole retina? Simply adding output nodes that operate independently of each other is not enough. In fact, Figure 2.16 (left) shows that most nodes develop very similar receptive fields (this means that the sequence of inputs is a strong determinant of weight organization). We obtain a better result if, after presenting an input but before updating the weights, we set to zero the activity of all nodes except the most active one. Biologically, this may correspond to strong mutual inhibition between neurons. Receptive fields obtained in this way are spread more evenly across the retina, as shown in Figure 2.16 (right). To understand why, consider just two nodes and suppose that because of differences in initial weights, node 1 reacts more strongly to input **x** than node 2. Then, according to equation (2.52), the sensitivity of node 1 to **x** and similar inputs will be increased, and the sensitivity of node 2 (whose activity has been set to zero) to the same inputs will be decreased. Such weight changes make it even more likely that node 1 will be more active than node 2 to inputs similar to **x**. In summary, we have a self-reinforcing process (positive feedback) that confers on the two nodes sensitivity to different input patterns.
