# 3.2.3 Setting network weights

Once we have decided on a network architecture, we need to adjust network weights so that the model operates according to some requirements. Requirements on net-work behavior may come either from observations of animals or from functional considerations such as being able to survive in a given environment. In this chapter we are not concerned with how suitable weights are obtained: we consider them as given (in practice, we find suitable weights using the methods described in Chap-ter 2). Chapter 4 considers weight changes from the point of view of understanding learning and ontogeny of behavior.
