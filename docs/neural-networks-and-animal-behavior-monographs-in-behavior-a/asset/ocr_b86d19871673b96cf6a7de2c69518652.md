Based on countless tests with objects placed on the nest rim, Baerends and coworkers were able create a detailed model of how various features (color, speckles, size and shape) and other motivational factors determined the efficiency of a stimulus in eliciting the retrieval behavior. The resulting model is shown in Figure 3.13. Egg detection occurs in two steps. First, a stimulus is processed by a number of “feature detectors” serving general-purpose vision. Some of these detectors (corresponding to, say, “elliptic shape,” “speckled object”) and so on) feed onto an “egg detector” with the specific purpose of determining whether an egg is present. The output signal is not a “yes” or “no” but a continuous value based on what egg features are present and on the effectiveness of each feature. Different features interact according to a summation model such as equation (3.3). This can explain why stimuli vary in their efficiency to elicit egg retrieval.
