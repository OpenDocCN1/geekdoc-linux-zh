/* this function calculates node input, see equation (2.3) */
/* W = weight vector, x = input vector, n = size of W and x */
float weighted_sum( float *W, float *x, int n ) {
   int i;
   float y= 0.;
   for( i=0; i<n; i++ )  y += W[i]*x[i];
   return y;
}

/* logistic node transfer function, see equation (2.7) */
float transfer_function( float y ) {
   return 1/(1+exp(-y));
}

/* a C program starts executing from the “main” function */

   float z;             /* activity of output node */
   y = weighted_sum( W, x, 4 );    /* calculate y */
   z = transfer_function( y );      /* apply the transfer function */
   printf( “Output is %f\n”, z );  /* print result */

Neural network simulators are ready-to-use programs, often with graphical user interfaces, explicitly developed to study neural networks. Some of the most developed simulators are intended for neurophysiologically realistic simulations (Hayed et al. 2003 and references therein). They tend to consider many details of neurons, resulting in node models with many state variables and parameters that are, presently, of uncertain value to behavioral modeling (see the end of Section 2.1.2.2). Neural network simulators have also been developed within artificial intelligence, computer science and engineering. The drawback of such software is that it often requires some technical background and tends to focus on different questions than animal behavior. Two fairly general neural network simulators that, while requiring some study, are not too difficult for beginners and do not require programming are PDP++ (http://psych.colorado.edu/~orcelli/PDP++/PDP++/PDP++.html) and JavaNNS (http://www-ra.informatik.uni-tuebingen.de/software/JavaNNS/welcome.html). The former focuses on (human) cognition, including behavior-level phenomena (O'Reilly & Munakata 2000), whereas the latter is more neutral regarding the interpretation of the network models.
