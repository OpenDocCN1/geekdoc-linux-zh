# # CHAPTER SUMMARY

# ## General

+   1. The nervous system controls behavior based on both internal and external causal factors. Both are sensed through specialized receptors, which can be directed toward either the inside or the outside of the animal.
+   2. The ability to command functional behavior is greatly enhanced by the nervous system building regulatory states (e.g., persistent patterns of neuron activity) and memory states (connections between neurons).
+   3. Through its activity, the nervous system influences both the body and the external environment. Such influences often feed back onto the system itself in the form of changed input at some later time.
+   4. Neural network models of the preceding processes can be built by having input nodes that model receptors (internal and external), inner nodes that process input patterns and output nodes whose activity is interpreted as behavior or muscle control.

# ## Stimulus control

+   1. Many stimulus control phenomena emerge naturally in simple networks, provided input patterns are built by taking into account basic properties of receptors (receptor space approach). Networks account for the shape of generalization gradients and the nature of response biases along different stimulus dimensions (rearrangement and intensity dimensions), as well as other phenomena such as external inhibition and the effect of contextual stimuli.
+   2. Considering overlaps between stimulus patterns is a powerful heuristic tool to analyze how both networks and animals generalize to novel stimuli.
+   3. Networks share many similarities with earlier models of stimulus control from ethology and psychology but are more powerful in view of their concrete interpretation as models of the nervous system. This eliminates many ambiguities, e.g., what is a stimulus.

# ## Sensory processing

+   1. Neural network models of sensory processes are well developed, starting from modeling of invertebrate sensory systems up to the complexities of visual processing in mammals.
+   2. These models show how raw information from sense organs can be transformed to be more useful for further processing and decision making. For instance, we have shown how
+      1. Changes in input can be highlighted by lateral inhibition.
+      2. Receptive fields can build patterns of activity that allow easier realization of functional behavior.
+      3. Local signals about motion on a small part of the retina can be converted into global information about how the animal moves in the environment.
