generic input x in terms of how x relates to the x_a's (and to the vector u). This will be discussed in Chapter 3.

Equation (2.24) also holds if the output node is not linear. Such a network can be written as r = f(W·x). We mention this case because a nonlinear output node is used often to limit network output between 0 and 1 and interpret it as probability of responding. The proof follows from noting that the requirement d_a = f(W·x_a) can be written d_a = W·d_a, where d_a = f^{-1}(d_a) and f^{-1} is the inverse function of f. Thus we are back to a linear problem, albeit with different d_a's. This means that different choices of f result in different values of the c_a's but do not alter the structure of the weight vector.

# 2.3.1.1  Limits and abilities of linear networks

We expand here our remarks about the perceptron's limitations (page 40) by asking when the task in equation (2.21) can be solved by a perceptron. We then extend the reasoning to general linear networks. It is easy to determine when the task cannot be solved. Note, in fact, that the definition of a linear network r = W·x implies

```
r(x_\alpha + x_\beta) = r(x_\alpha) + r(x_\beta)                          (2.28)
```

because W·(x_\alpha + x_\beta) = W·x_\alpha + W·x_\beta (from equation 2.8). In words, the output to a sum of inputs equals the sum of the outputs to each input (indeed, this is the technical meaning of linear). It is then clear that an input-output map where, say, x_\gamma = x_\alpha + x_\beta but d_\gamma \neq d_\alpha + d_\beta cannot be realized by a linear network. In general, if among the inputs x_1, ..., x_n there is one, say, x_\beta, that can be written as a weighted sum of the others, e.g.,

```
x_\beta = \sum_{a \neq \beta} b_a x_a                                   (2.29)
```

(for some choice of the b_a's), then a weight vector W realizing the input-output map in equation (2.21) does not exist unless

```
d_\beta = \sum_{a \neq \beta} b_a d_a                                   (2.30)
```

That is, the same relationship must hold among outputs that holds among inputs. Conversely, if it is impossible to write any of the x_a's in the form of equation (2.29), the input-output map in equation (2.21) can be realized by a linear network for any choice of the d_a's. Indeed, the reader may have noted that equation (2.27) is meaningless if X_{11}X_{22} = X_{12}^2 (fraction denominators vanish). This happens precisely when x_1 = bx_2, a special case of equation (2.29). In fact, in this case we have

```
\begin{align*} X_{11} &= x_1 \cdot x_1 \\ X_{22} &= b^2 x_1 \cdot x_1 \\ X_{12} &= bx_1 \cdot x_1 \end{align*}                          (2.31)
```

so that X_{11}X_{22} = X_{12}^2 = b^2(x_1 \cdot x_1)^2. Further information on this topic can be sought in linear algebra textbooks (sections on systems of linear equations).
