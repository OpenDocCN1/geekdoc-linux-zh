Regardless of the size, the signal delivery mechanism through the operating system is the kernel sigproc() function, which takes up to four arguments: a process counter, a thread pointer, the signal number, and an optional flag, fromuser, which indicates whether the source was the kernel or user. Signals that should be directed to a kthread/LWP call sigto- proc() with a valid thread pointer. A NULL thread pointer indicates the signal should be posted to the process. Let's take a look at the code flow of sigproc().

```
sigproc(proc pointer, kthread pointer, int signal, fromuser flag)
    if (signal == SIGKILL) /* kill signal */
        if (skilled in p_flags)
            Set kthread pointer to NULL
    else if (signal == SIGCHNT) continue /* job control */
        Discard queued siginfo structs for preventing STOP SIGNALS
        (SIGSTOP, SIGSTP, SIGTOU, SIGT/N)
    if (process has an aslw thread) /* multithreaded processes */
        Clear SIGSTOP, SIGSTP, SIGTOU, TTIN in aslw t_sig
        if (process has more than one kthread)
            Loop through kthread linked list
                Delete signal structs for STOP, TSTP, TTU, TTIN
            else /* process has one kthread */
                Clear STOP, TSTP, TTU, TTIN in p_sig
    Clear p_stopsig
    if (process is multithreaded)
        Loop through kthread linked list
            if (thread is tscheduled due to TS XSTART)
                Set kthread t
                Call setrun() /* get the thread running /
        End loop
    if (signal is STOP or TTU or TTIN)
        Set thread pointer to the process aslw thread
        Delete any siginfo structures for queued SIGINT
    if (process is multithreaded)
        Clear pending SIGINT in aslw
        Clear pending SIGINT in p_notcifs
        Loop through list of kernel threads
            Delete queued SIGINT siginfo structures
            Clear pending SIGINT in t_sig
        End loop;
    else /* process is not multithreaded */
        Clear pending SIGINT in p_sig
    if (signal is discardable)
        return
    if (process has an aslw kernel thread)
        Set signal bit in aslw t_sig
        Call sat_signal()
    else if (process is multithreaded)
        Set the signal bit in process p_sig
        Loop through linked list of kernel threads
            if (eat signal)
                break out of loop
            if (signal == SIGKILL)
                Try to run a kthread so signal can be delivered
    End Loop
```
