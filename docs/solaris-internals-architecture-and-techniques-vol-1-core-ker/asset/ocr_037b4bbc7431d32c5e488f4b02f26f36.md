#  5.4.1 The vnode Segment: seg_vn

The most widely used segment driver is the vnode driver, seg_vn. The seg_vn maps files (or vnodes) into a process address space, using physical memory as a cache. The seg_vn segment driver also creates anonymous memory within the process address space for the heap and stack and provides support for System V shared memory. (See "System V Shared Memory" on page 425.)

The seg_vn segment driver manages the following mappings in process address space:

+   * Executable text
* Executable data
* Heap and stack (anonymous memory)
* Shared libraries
* Mapped files

#  5.4.1.1 Memory Mapped Files

We can map a file into a process's address space with the mmap system call. (See discussion in "Memory Mapped File I/O" on page 498.) When we map a file into our address space, we use routines to create a new segment, a vnode segment. A vnode segment handles faults for the memory range requested in the mmap system call, and the new segment is added to the list of segments in the process's address space.
