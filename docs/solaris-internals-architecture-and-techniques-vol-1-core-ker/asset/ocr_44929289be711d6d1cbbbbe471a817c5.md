File systems install all entries into the file system switch when they are first loaded, usually during their initialization function. There is only one entry for each type of file system, regardless of how many mounts exist for that type of file system. An example of a virtual file system switch table is shown below. Each slot lists the name of the file system and tells where to find the relative functions for that system.

```
struct vfs vfssw[] = {
    "BADVFS",   &vfs_strayops, 0, /* invalid *//
    "specfs",  NULL,          /* SPEBCFS *//
    "ufs",      &vfs_vfsops, 0, /* UFS *//
    "fifofs",   &vfs_vfsops, 0, /* FIFOS *//
    "namefs",   &name_vfsops, 0, /* NAMEFS *//
    "proc",     &sproc_vfsops, 0, /* PROC *//
    "nfs",      &nfs_vfsops,  0, /* NFS Ver 2 *//
    "hfsfs",     &hfs_vfsops, 0, /* HSFS *//
    "lofs",     &lofs_vfsops, 0, /* LOFS *//
    "tmpfs",    &tmp_vfsops,  0, /* TMPFS *//
    "fd",       &fd_vfsops,   0, /* FDS *//
    "pcfs",     &pcfs_vfsops, 0, /* PCFS *//
    "swapfs",  &swap_vfsops, 0, /* SWAPFS *//
};
```

To dump the vfs switch table, issue the command, as shown below:

```
# crash
dumpfile = /dev/mem, namelist = /dev/ksym, outfile = stdout
> vfs

3 fifos  0
4 namefs 0

6 sfsfs  0
```
