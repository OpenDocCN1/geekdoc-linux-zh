# A KERNEL TUNABLES, SWITCHES, AND LIMITS

In this appendix, we provide several tables showing the various kernel settable parameters. The variables listed here do not represent every kernel variable that can be altered. Almost any kernel variable that is visible to the kernel linker can be altered with an entry in the /etc/system file or with a debugger like adb(1). Certainly, it was never intended that each and every kernel variable, along with its meaning and possible values, be documented as user settable. Most have been intended for public use, but rather exist for debugging or experimentation. Here we list what we consider the mainstream variables—those that have always been intended to be user settable—and several that are not as well known but have proved to be useful for some installations.

# A.1 Setting Kernel Parameters

You establish settable kernel tunable parameters by adding an entry to the /etc/system file, in the form of:

```
set parameter = value
```

or

```
set kernel_module:parameter = value
```

The second example applies to those kernel variables that are part of a loadable kernel module, where the module name is separated by a colon from the variable
