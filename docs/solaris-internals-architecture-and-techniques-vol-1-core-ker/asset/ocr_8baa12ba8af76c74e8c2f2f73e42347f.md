In the example, we inserted a short description of the event each counter corre-
lates. Most of the descriptions are comprehensible when examined in conjunction\with the preceding text. The last counters, async preempts and sync
preempt, count each of the possible methods of kernel preemption. The kpre-
ent () function is passed one argument, asyncpl. For async preempts, async-
spl is a priority-level argument, and the kpreempt () code will raise the PIL,
dictated by the value passed. Sync preempts pass a -1 argument and do not
change the processor's priority level.
