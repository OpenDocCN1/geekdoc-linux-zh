The new memory architecture first introduced with SunOS 3.2 allows a new way of doing file I/O, that is, by mapping a file directly into the process's address space. The mmap system call allows us to map a range of a file into a process's address space; then, the file can be accessed by references to memory locations with C pointers. This approach allows us to do I/O on the file without the overhead of the read and write system calls and without de handling the data twice. Figure 11.4 illustrates the process.
