The write system calls the file-independent write, which in our
example calls `ufs_write()`. UFS breaks the write into 8-Kyte chunks and then
processes each chunk. For each 8-Kyte chunk, the following steps are performed:

+   - UFS asks the `segmap` driver for an 8-Kyte mapping of the file in the ker-
el's virtual address space. The page for the file and offset is mapped here so

- The `segmap` segment looks in its cache of mappings. If a mapping exists, it is
returned. If there is no mapping for this file and offset, then a new one is cre-
t by replacement of one of the existing mappings.
- If there is a whole file system block, then a new zero page is created
with `segmap_pagecreate()`. In the case of a partial block write, the block

write system call is copied from user address space into kernel address space.
