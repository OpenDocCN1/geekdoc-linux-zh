# A.4 File System Parameters

The file system and page flushing parameters in Table A-5 provide for tuning file system performance and manage the flushing of dirty pages from memory to disk.

You can read more about the fsflush and associated parameters in "Bypassing the Page Cache with Direct I/O" on page 600, "Directory Name Cache" on page 603 and "Inode Caches" on page 605 have more information on the file system parameters and inode caches.

# Table A-5 File System and Page Flushing Parameters

| Parameter | Default | Category | Description/Notes |
| --- | --- | --- | --- |
| tune_t_flushr | 5 | Tunable | fsflush interval; the fsflush daemon runs every tune_t_flushr. |
| autoup | 30 | Tunable | Age in dirty pages. Used in conjunction with tune_t_fsflush; modified pages that are older than autoup are written to disk. |
| dopingflush | 1 | Switch | When set, enables dirty page flushing by fsflush. Can be set to 0 to disable page flushing. |
