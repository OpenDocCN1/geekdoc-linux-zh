# 11.2 File Application Programming Interfaces (APIs)

Different APIs perform I/O in Solaris. These include standard I/O—the generic buffered I/O mechanism—and several of low-level operating system calls.

The traditional C interfaces are known as the Standard I/O functions, abbreviated as stdio. They are the buffered I/O interfaces that were added to Unix V6 by Bell Laboratories in 1976; they appear as a standard file I/O mechanism in nearly all runtime environments. This stdio library interfaces exist as a layer above the lower-level system calls.
