## 7.4.3.3 进程矩阵

进程矩阵（图 7.4）显示了进程与映射文件之间的关系。显示顶部是我们在这些进程内存中查看的进程列表，侧边是映射到这些进程的文件列表。矩阵的每一列显示映射到该进程每个文件的内存量，并有一行与该进程关联的私有内存。矩阵可显示一组进程的总内存占用。默认情况下，右上角的摘要框显示所有进程使用的内存。我们可以通过左侧按钮选择一组进程，然后通过显示顶部的按钮进行汇总。选择 All/Filter（全部/过滤）按钮返回完整显示。

## 7.5.2 扩展 vmstat 命令: memstat

free = 以页为单位的空闲内存

### 全局页计数器
- re = 从空闲列表回收的页
- mf = 在内存中但未映射的页
- pi = 从文件系统或交换设备的页入
- po = 到文件系统或交换设备的页出
- de 已删除或释放的页

### 执行页计数器
- epi = 执行和库页的入
- epo = 执行和库页的出（应为0）
- epf = 执行和库页的释放

### CPU 摘要
- us = 用户 CPU 时间
- sky = 内核 CPU 时间
- wt = 等待 CPU 时间
- d = 空闲 CPU 时间

### 匿名页计数器
- api = 匿名页的交换入
- apo = 匿名页的交换出
- pf = 匿名页的释放

### 文件页计数器
- api = 文件页的入
- apo = 文件页的出
- pf = 文件页的释放
