# 13.3.1 The File System Switch Table <sys/vfs.h>

The file system switch table, shown below, is a systemwide table of file system types. Each file system type that is loaded on the system can be found in the virtual file system switch table. The file system switch table provides an ASCII list of file names (e.g., ufs, nfs), the initialization routines, and vfs object methods for that system. The vfs_ctype of the vfs object is an index into the file system switch table.

```
* File system switch table.
typedef struct vsw {
    char *vsw_name;            /* type name string */
    int (*vsw_init)(struct vfs *, int); /* init routine */
    struct vfsops *vsw_vfsops;  /* file system operations vector */
    int vsw_flag;               /* flags */
} vsw_t;
```

# Header File <sys/vfs.h>

File systems install all entries into the file system switch when they are first loaded, usually during their initialization function. There is only one entry for each type of file system, regardless of how many mounts exist for that type of file system. An example of a virtual file system switch table is shown below. Each slot lists the name of the file system and tells where to find the relative functions for that system.

```
struct vfs vfssw[] = {
    "BADVFS",   &vfs_strayops, 0, /* invalid */
```

# 13.3.2 The Mounted vfs List

The system starts with only one vfs object, the root file system, which is identified by the rootvfs pointer. You can subsequently mount file systems by looking up the vfsops structure in the switch table and calling the mount operation for that system. The mount operation initializes a new vfs object and links it to the rootvfs object using the vfs_next structure in the object. Each time a new file system is mounted, its vfs structure is linked onto the chain.
