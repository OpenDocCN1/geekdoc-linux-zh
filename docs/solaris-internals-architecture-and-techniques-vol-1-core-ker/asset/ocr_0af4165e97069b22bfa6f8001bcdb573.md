**Figure 5.28** Virtual-to-Physical Translation

Figure 5.28 illustrates the relationship between virtual and physical addresses, so that we traditionally use page tables to map virtual-to-physical addresses, so for any given virtual address, the MMU looks up and translates the appropriate physical address. microSPARC and SuperSPARC processors use page tables for address translation to convert virtual page numbers to physical page numbers. The microSPARC and SuperSPARC page table comprises entries, one per page, as page table entries, that map each virtual to a physical page.

In UltraSPARC-I and -II, we use a translation table to describe the virtual-to-physical translation. A translation is the functional equivalent of a page table, with significant differences. For example, unlike the older page table implementation (like that on SuperSPARC), the UltraSPARC-I and -II MMU uses a software-based translation mechanism to fill the hardware TLB cache.

The UltraSPARC-I and -II page table entries are known as translation entries (TTEs), one for each page. The TTE is a translation entry that contains a virtual address tag and the high bits of the physical address for each page (the physical page number) so that the hardware MMU can convert the virtual page address into a physical address by finding entries matching the virtual page number.
