# 7.5.2 An extended vmstat Command: memstat

Additional paging statistics are provided in the Solaris kernel. Later, in Solaris 8, a new vmstat option (-p) was added to examine these statistics. The statistics can be observed on Solaris 7 with a simple command-line utility: memstat.

memstat shows the paging activity, page-ins, page-outs, and page-frees separated into three classes: file system paging, anonymous memory paging, and executable/shared library paging.
