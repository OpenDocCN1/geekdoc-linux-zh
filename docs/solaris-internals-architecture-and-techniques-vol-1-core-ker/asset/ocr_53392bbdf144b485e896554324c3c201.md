+   - /proc/<pid>/lwp/<lwpstatus> — LWP state and status information, defined in the lwpstatus structure in /usr/include/sys/procfs.h.

+   - /proc/<pid>/lwp/<lwpsinfo> — LWP ps(1) command information, as defined in lwpsinfo, also in /usr/include/sys/procfs.h.

+   - /proc/<pid>/lwp/<lwpusage> — LWP resource usage data. See “Process Resource Usage” on page 314.

+   - /proc/<pid>/lwp/<xregs> — Extra general state registers; this file is processor-architecture specific and may not be present on some platforms. On SPARC-based systems, the data contained in this file is defined in the procregset structure, in /usr/include/sys/procfs_isa.h.

+   - /proc/<pid>/lwp/<windows> — General register windows. This file exists on SPARC-based systems only and represents the general register set of the LWP (part of the hardware context), as defined in the gwinds structure in /usr/include/sys/regs.

+   - /proc/<pid>/lwp/<asrs> — Ancillary register set. SPARC V9 architecture (UltraSPARC) only. An additional set of hardware registers defined by the SPARC V9 architecture. This file, representing the ancillary registers, is present only on sun4au-based systems running a 64-bit kernel (Solaris 7 or later), and for 64-bit processes. Remember, a 64-bit kernel can run 32-bit processes will not have this file in its lwp directory space.

That completes the listing of files and subdirectories in the profs space. Once again, please refer to the proc(4) manual page for more detailed information on the various files in /proc and for a complete description of the control messages available.

# 8.6.1 Profs implementation

Profs is implemented as a dynamically loadable kernel module, /kernel/fs/proc, and is loaded automatically by the system at boot time. /proc is mounted during system startup by virtue of the default /proc entry in /etc/vfsstab. The mount phase causes the invocation of the proc init() (initialize) and mount() file-system-specific functions, which initialize the vfs structure for proc and create and initialize a vnode for the top-level directory file, /proc.

The kernel memory space for the /proc files is, for the most part, allocated dynamically, with initial static allocation for the number of directory slots required to support the maximum number of processes the system is configured to support (see “The Kernel Process Table” on page 286).
