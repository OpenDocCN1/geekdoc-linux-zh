You can use adb(1) to examine the values of maxusers, max_nprocs, and max-uprc on a running system.

```
# adb -k /dev/ksyms /dev/mem
physmem bdde
maxusers/D
maxusers:
maxusers: 189
maxprocs/D
max_nprocs:
max_nprocs: 3034
maxuprc/B
maxuprc:
maxuprc: 3029
```

You can also use crash(1M) or the system var structure to dump those values.

```
# /etc/crash
> od -d maxusers
f027d3c4: 0000000253
> od -d max_nprocs
f027126c: 0000004058
> od -d maxuprc
f0270f28: 0000004053
> var
v_buf: 100
v_call: 0
v_proc:
v_nglobpris: 110
v_maxsyspri: 99
v_clic: 0
v_maxup: 4058
v_hbuf: 256
v_hmask: 255
v_gbuf: 0
v_sptmap: 0
v_maxpmem: 0
v_autoup: 30
v_bufhm: 5196
```

Note that the /etc/crash var utility does not dump the v_max value; it just dumps proc and var as the kernel virtual address of the variable. For example, f027dc4c is the address of the max kernel variable (in this example).

Finally, sar(1M) with the -v flag gives you the maximum process table size and the current number of processes on the system.

```
sar -v 1 1
SunOS sunys 5.6 Generic sun4m 05/05/00
```
