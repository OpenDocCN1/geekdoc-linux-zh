+   * CPU_OFFLINE. The processor was taken offline by psradm(1M) or p_online(2) and is no longer scheduling kernel threads. The CPU will still take interrupts. (That's the difference between the offline state and quiesced state—a CPU with bound threads cannot be taken offline.)

+   * CPU_POWEROFF. (Solaris 2.6 and Solaris 7 only.) The CPU has been powered off.
