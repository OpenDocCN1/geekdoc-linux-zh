The page_create_va() function allocates pages. The new page_create_va() function subsumes the older page_create() function and should be used by all newly developed systems because page_create() may not correctly color the allocated pages.

# 5.7.6 The Page Throttle

Solaris implements a page creation throttle so a small core of memory is available for consumption by critical parts of the kernel. The page throttle, implemented in the page_create() and page_create_va() functions, causes pages to block when the PG WAIT flag is specified, that is, when available memory is less than the system global, throttle. By default, the system global parameter, throttle, is set to the same value as the system global parameter minfree. By default, memory allocated through the kernel memory allocator specifies PG WAIT and is subject to the pagecreated throttle (See Section 6.2, "Kernel Memory Allocation," on page 212 for more information on kernel memory allocation.

The Solaris kernel uses a fundamental page size that varies according to the underlying hardware. On UltraSPARC and beyond, the fundamental page size is 8 Kbytes.
