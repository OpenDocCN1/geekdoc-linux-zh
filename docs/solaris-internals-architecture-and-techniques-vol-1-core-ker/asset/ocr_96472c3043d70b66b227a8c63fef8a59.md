# 7.4.2.2 File System Cache Memory: -memps

Memtool provides a list showing where the pool of filesystem cache has been allocated, sorted by vnode. The list summarizes the size of each vnode in the file system cache and, if possible, gives the real file name. If the real file name is not determined, the device and inode number are printed for that vnode.
