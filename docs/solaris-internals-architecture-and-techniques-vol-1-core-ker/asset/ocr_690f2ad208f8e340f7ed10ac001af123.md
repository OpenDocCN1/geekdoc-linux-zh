```
# prtswap
Virtual Swap:
-----------------------------
Total Virtual Swap Configured:      767MB
Total Virtual Swap Reserved:       513MB
Total Virtual Swap Free: (programs will fail if 0) 253MB

Physical Swap Utilization: (pages swapped out)
-----------------------------
Physical Swap Configured:      512MB
Physical Swap Free (programs will be locked in 0): 232MB
```

The prtswap script uses the anonymous accounting structure members to establish which swap space is allocated and uses the availrmem counter, swapfminfree reserve, and the swap -1 command to find out how much swap is used. Table 5-8 shows the anonymous accounting information stored in the kernel.

| Field | Description |
|---|---|
| k_anoninfo.ani_max | The total number of reservable slots on physical (disk-backed) swap. |
| k_anoninfo.ani_phys_resv | The number of physical (disk-backed) reserved slots. |
| k_anoninfo.ani_mem_resv | The number of memory reserved slots. |
| k_anoninfo.ani_free | Total number of unallocated physical slots + number of reserved but unallocated memory slots. |
| availrmem | The amount of unreserved memory. |
| swapfminfree | The amount of swapf reserve that won't be used for memory reservations. |

# Virtual Memory Watchpoints

The Solaris kernel implements virtual memory watchpoints within address spaces. A waypoint is similar to a breakpoint, except that a waypoint stops execution when an address location is read or modified, whereas a breakpoint stops execution when an instruction is executed at a specified location. Watchpoints provide the ability to implement breakpoints through the waypoint interface.
