# 9.3.2 Sleep Queues

Sleep queues are organized as a linked list of kernel threads, each linked referenced via a sleepq_head kernel pointer. Some changes were made in Solaris 7 to facilitate faster sleep queue operations (insertion, removal, traversal). In Solaris releases prior to Solaris 7, an entry in the sleepq_head array begins a linked list of kernel threads waiting on the same condition variable. The list is singly linked by the kernel thread's t_link pointer. In this 7, several additional pointers were added to the kernel thread to support a doubly linked list of threads at the same priority.
