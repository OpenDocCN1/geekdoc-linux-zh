On 64-bit sun4 platforms, we have an additional segment for the spillover kernel and data. The reason for the segment is that the address at which the module text is loaded must be within a 32-bit offset from the kernel text. That's why the 64-bit kernel is compiled with the ABS32 flag that the kernel can fit every instruction within a 32-bit range. The ABS32 instruction mode provides a significant performance increase and allows the 64-bit kernel to provide similar performance to the 32-bit kernel. Because of that, a separate kernel map segment within a 32-bit offset of the kernel text is used for spillover module text and data.

Solaris allows some portions of the kernel to be allocated from paging memory. That is, data structures directly related to process context can be swapped out with the process during a process swap-out operation. Pageable memory is restricted to those structures that are not required by the kernel when the process is swapped out:

+   - Lightweight process stacks
- The TNF Trace buffers
