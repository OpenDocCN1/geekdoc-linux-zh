The PID of the test process is 20179. The crash(1M) utility is started, and the dump dumps the process table (most of the table output is deleted). The process is located in table slot 73, as verified with the p 73 command. Finally, a full listing of the address space is dumped with the as -f command.

Looking at the address space list, matching the address of the shared segment, ed000000, we can determine which segment driver is used for that address space segment. In this case, the segment driver is the segpts_shm driver, which is a driver specifically for ISM shared memory. Any address space mapped that shows represents a shared segment that is not an ISM segment, the segment driver will be the standardv_ops driver.
