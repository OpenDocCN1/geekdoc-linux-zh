# 8.2.3 The Lightweight Process (LWP)

The LWP structure is defined in /usr/include/sys/klwp. The kernel maintains resource utilization counters and microstate accounting for every LWP. The total sum of all LWPs resource usage is stored in the process when the LWP exits. See "The Kernel Process Table" on page 286.
