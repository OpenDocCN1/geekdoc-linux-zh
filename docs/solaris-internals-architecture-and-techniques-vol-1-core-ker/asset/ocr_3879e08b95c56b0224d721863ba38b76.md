# Table 15-1 Paging Counters from the memstat Command

| Column | Description |
| --- | --- |
| pi | Total page-ins per second |
| po | Total page-outs per second |
| fr | Total page-frees per second |
| sr | Page scan rate in pages per second |
| epi | Executable page-ins per second |
| epf | Executable pages freed per second |
| api | Application (anonymous) page-ins per second from the device |
| apo | Application (anonymous) page-outs per second to the device |
| apf | Application pages freed per second |
| fpi | File page-ins per second |
| fpo | File page-outs per second |
| fpf | File page-frees per second |

If we use the memstat command, we can now see that as we read out several pages per second through memory, the scanner is scanning several hundred pages to be freed and application (anonymous) pages to be paid out to swap as we do. On a system with plenty of memory, this is not the desired mode of operation! Enabling paging will stop this excessive swapping when there is sufficient memory.
