The amount of kernel memory required is calculated as follows.

```
kernel_memory_required =
  (msgsz * sizeof char data) +
  (msgmap * sizeof map structure) +
  (msgid * sizeof msqid_ds structure) +
  (msgctl * sizeof msg structure)
  (msglock * sizeof msglock structure)
```

The kernel sets several pointers in the message queue that will be referenced in the subsequent text when the resources are initialized. An msq pointer is set to point to the beginning of the pool of memory used to store data, described earlier. msgmap points to the beginning of the map structures used for maintaining resource allocation maps. A map structure is 8 bytes in size and contains the size of the mapped segment and the base address.

The kernel data structure that describes each message queue is msq_ds

```
struct msq_ds {
  struct ipc_perm msg_perm;
  struct msghdr      *msg_first;
  struct msghdr      *msg_last;
  unsigned long      msg_bytes;
  unsigned long      msg_qnum;
  unsigned long      msg_qsize;
  pid_t              pid;
  pid_t              msqid;
  time_t              lrpidid;
  long               msg_pad1;
  time_t              rtime;
  long               msg_pad2;
  time_t              stime;
  time_t              mime;
  long               msg_pad3;
  struct kcondvar   msg_cv;
  struct kcondvar   msg_qnum_cv;
  long               msg_pad[3];
};
```
