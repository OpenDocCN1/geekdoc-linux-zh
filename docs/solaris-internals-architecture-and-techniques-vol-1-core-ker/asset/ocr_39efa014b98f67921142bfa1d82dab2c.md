# 7.3 The vmstat Command

The Solaris vmstat utility summarizes various functions within the virtual memory system, including systemwide free memory, paging counters, disk activity, system calls, and CPU utilization. The output of vmstat is shown below with explanations of the various fields. Let's take a look at how we can use vmstat to get a quick summary of what is happening on our system. Note that the first line of output from vmstat shows a summary since boot, followed by the output of the last 3 seconds for each additional line.

```
r = run queue length
b = processes blocked waiting for I/O
w = id processes that have been swapped at some time
swap = free and unreserved swap available, in Kbytes
free = free memory measured in pages
re = pages reclaimed from the free list
f = minor faults - the page was in memory but was not mapped
pi = pages paged in from file system or swap device
p = pages paged out to file system or swap device
fr = pages that have been destroyed or freed
de = pages freed after writes
s0-s3 = disk I/Os per second for disk 0-3
in = interrupts/second
s = system calls/second
cs = process context switches/second
us = user cpu time
s = kernel cpu time
id = id+wait cpu time
```
