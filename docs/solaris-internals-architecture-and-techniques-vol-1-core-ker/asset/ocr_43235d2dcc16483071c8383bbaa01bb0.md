# 7.1.1 Total Physical Memory

From the output of the Solaris prconf command, we can ascertain the amount of
total physical memory.

```
# prconf
System Configuration:  Sun Microsystems sun4u
Memory size: 384 Megabytes
System Peripherals (Software Nodes):
```

# 7.1.2 Kernel Memory

We find the amount of kernel memory by using the Solaris sar command and sum-
ming three pool columns. The output is in bytes; in this example, the kernel is
using 55, 536 bytes of memory.

```
# sar k 1 1
SunOS devhome 5.7 SunOS_Development sun4u  02/07/00
18:12:31 50 sml_mem alloc fail lg_mem alloc fail ovsz_alloc fail
18:12:31 8372672 7658792 4 1 0 03783006 30195320 0 9248768 0
```

# 7.1.3 Free Memory

Free memory is almost always zero because the buffer cache grows to consume free
memory. Using the vmstat command to measure free, the first line of out-
put vmstat is an average since boot, so the real free figure is avail-
able on the second line. The output is in kilobytes. Note that this has changed in
Solaris 8—free memory now contains the majority of the file system cache.

```
# vmstat 3
process memory          disk          faults  cpu
r b w swap free  mi pi po fr de sr f0 s6 sd ad cs in sy us id
0 0 29008 38456 4 1 4 6 0 0 0 0 0 209 1755 5 1 94
0 0 519452 12720 0 0 0 0 0 0 0 0 0 232 482 330 1 0 98

0 0 519452 12720 0 0 0 0 0 0 0 0 0 192 409 271 0 0 100
```
