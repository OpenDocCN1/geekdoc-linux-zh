With pread(2) and pwrite(2), a read or write can be initiated at a specific offset
with only one system call, rather than the traditional method that uses both the
seek() and read() system calls.

# 11.3.2.8 The readv and writev System Calls

The readv(3) and writev() system calls, shown below, are similar to the read(3)
and write() system calls, allow the transfer to occur to and from a range of
memory addresses, rather than from a single memory buffer. This technique is
often referred to as scatter/gather I/O.

```
size_t readv(int ildes, const struct iovec *iov, int iovcnt);
size_t writev(int ildes, const struct iovec *iov, int iovcnt);
```

# Header File <unistd.hd>

Each I/O requests an array of iovec structures and a number of
iovec structures. The total size of the I/O is the sum of the size of all of the
iovec structures. The iovec structure is shown below.

```
struct iovec {
    addr_t iov_base;
    int iov_len;
};
```

# Header File <unistd.hd>

Each iovec structure provides the base address of the memory buffer and the
length in bytes of the buffer. As a result, the I/O transfer is read or written to the
process's memory address space in the specified pattern and to or from the file in a
sequential manner.

# 11.4 Asynchronous I/O

Asynchronous I/O interfaces have been available in Solaris for some time. A speci-
c set of interfaces in the Solaris libraries provides a means by which applica-
s issue I/O requests and not have to block or cease working until the I/O
has completed. (Don't confuse that behavior with the behavior of an I/O request if
the data integrity flags are not set in the file descriptor. See "Data Integrity
and Synchronization Flags" on page 488.)

Two sets of interfaces do asynchronous I/O in Solaris: the aioread(3) and aio-
write(3) routines; and the POSIX-equivalent routines, ai_read(3R) and
write(3R), which are based on the POSIX standards for real-time extens-
s. Real-time applications must, by definition, deal with an unpredictable flow
of external interrupt that require predictable, bounded response time.
