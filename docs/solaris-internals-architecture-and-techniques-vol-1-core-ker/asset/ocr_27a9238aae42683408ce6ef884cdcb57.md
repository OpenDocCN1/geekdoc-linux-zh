```
kpq = pointer to kernel preempt queue
dq = pointer to processor's dispatch queue
while ( priority = kpq->dispmaxunpri > 0 ) AND

        if (disp_ratify(thread_pointer, kpq) != NULL)

```

The preceding query search loop validates the priority value according to the queue's disp_maxunpri, which reflects the highest-priority thread sitting on the queue, makes sure the current processor is not offline, and calls the dispatcher disp_get() to fetch the best-priority thread from the kernel preempt queue. disp_get() finds the highest-priority unbound thread, calls disp_eq() to have the thread removed from the dispatch queue, and returns the thread pointer back to dispatch(). If nothing is found, a NULL value is returned.

```
disp_getbest()
    dpq = dispatch queue pointer (cp_kp_queue in this example)
    priority = dq->disp_max_unbound_pri
    if (priority == -1)
        return (NULL)
    queue = dq->disp_q[pri];
    thread_pointer = queue->dq_first;
    loop through linked list of threads
        if (no unbound threads)
            return NULL
        else
            thread_pointer = thread found
            dispatch(thread_pointer)
            set thread t_disp_queue, processorus->cpu_dispatch, thread state to ONPROC
            return (thread_pointer)
```

If an unbound thread is found in disp_getbest(), the thread is dequeued from dispq(), the thread's t_dispatch queue pointer is set to reference the processor's cpu structure cpu dispatch pointer, is set to the selected thread pointer, and the thread state is to ONPROC.

disp_get() deals with updating the dispatch queue data structures with the selected thread removed from the queue. It decrements drnnable, which maintains the total count for all the queues, and the same priority (refer to Figure 9.5 on page 368). If the per-priority queue count, dq_srcount, is 0, the queue bitmap is updated to reflect an empty queue. The disp_gact bitmap uses a set to reflect the presence of runnable threads on a per-priority queue; the bit that corresponds to the zero queue is cleared. The disp_maxrunpri and disp_max_unbound are also updated to reflect the new highest-priority on the queue if it is different from the thread that has just removed from the queue.
