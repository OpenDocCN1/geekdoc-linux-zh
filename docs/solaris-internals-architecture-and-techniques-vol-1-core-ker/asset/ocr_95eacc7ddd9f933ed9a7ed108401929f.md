Recall that the process and kernel subsystems call into the address space subsystem to manage their address spaces. The address space subsystem consists of a series of functions, grouped to perform the functions listed above. Although the subsystem has a lot of entry points, the implementation is fairly simple because most of the functions simply look up which segment the operation needs to operate on and then route the to the appropriate segment driver.

A call to the as_alloc() function creates an address space, as as_alloc() is invoked only once—when the system boots and the init process is created. After the init process is created, all address spaces are created by duplication of the init process. The fork() system call in turn calls the as_dup() function to duplicate the address space of the process as it creates a new process, and the entire address space configuration, including the stack and heap, is replicated at this point.

The behavior of fork() at this point is somewhat different. Rather than calling as_dup() to replace the address space, fork() creates a new process by borrowing the parent's existing address space. The fork function is useful if the goal is to call exec() since it saves all the effort of duplicating the address space that would otherwise have been discarded once exec() is called. The parent process is suspended while the child is using its address space, until exec() is called. Once the process is created, the address space object is allocated and set up. The Solaris 7 structure for the address space object is shown below.

```
struct as {
    kmutex_t contents;      /* protect certain fields in the structure */
    uchar_t *flags;          /* as attributes */
    uchar_t *vbits;          /* used for collecting statistics */
    kcondvar_t *cv;          /* used by rangelock */
    struct *ha;              /* has structure */
    struct *hrm;             /* ref and mod bits */
    c_addr_t *ulimit;         /* highest allowable address in as */
    union {
        struct seg *seglist; /* last segment on the addr space */
        sel_spath *spath;     /* last search path in skiplist */
    } cache;
    krtwlock_t lock;         /* protects fields below a .cache */
    int nwpage;            /* number of watched pages */
    struct page *wa_pages;  /* watched pages (procs) */
    struct seg *segs;       /* segments in this address space. */
    size_t size;             /* size of address space */
    struct *tail;            /* last element in the segment list. */
    uint *defines;           /* elements in segment list; #defs */
    uchar_t *larep;          /* representation of a segs; #defines */
    uchar_t *hilevel;       /* highest level in the a segs skiplist */
    uchar_t *unused;         /* mappings changed, rebuild as objectdir */
    uchar_t *updated;        /* object directory (procs) */
    vnode t **objectdir;
    size_t asizer;          /* size of object directory */
};
```
