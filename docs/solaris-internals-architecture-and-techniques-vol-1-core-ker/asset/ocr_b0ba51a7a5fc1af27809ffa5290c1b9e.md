+   - **semmn** Defines the maximum number of semaphores in the system. A semaphore set can have more than one semaphore associated with it, and each semaphore has a corresponding sem data structure. Each structure is only 16 bytes, but you still shouldn't go over the edge with this (do not make it arbitrarily a very large value). Actually, this number should really be calculated as semmn = semmi × semms1. Each semms defines the maximum number of semaphores per semaphore set and semmi defines the maximum number of semaphore sets, the total number of semaphores systemwide can never be greater than the product of semmn and semms1. semmn and semmap should be the same value.

+   - **semmnu** Defines the systemwide maximum number of semaphore undo structures. Semaphore undo structures are maintained in the event of a process that has made some semaphore value adjustments. If the SEM_UNDO is true in the semaphore flag value (sem_fig) when the semaphore operation is done (the semop(2) system call), then the kernel undoes changes made to the semaphore(s) when the process terminates. Seems intuitive to make this equal to semmi, which would provide for an undo structure for every semaphore set. Each semaphore undo is 16 bytes.

+   - **semms1** Maximum number of semaphores per semaphore set. Each semaphore set can have one or more semaphores associated with it; this tunable defines the maximum number per set.

+   - **semopm** Maximum number of semaphore operations that can be performed by semop(2). This tunable takes us back to the notion of semaphore sets and the ability to do operations on multiple semaphores by means of the semop(2) system call. The semaphores in the set will all be associated with the same semaphore ID (semid_ds structure). You should probably set this value equal to semms1 so you'll always be able to do an operation on every semaphore set.

When semop(2) call is executed, the kernel checks to ensure that the third argument to it is the size of the semaphore set array, is not larger than the semopm tunable. If it is, an error is returned to the calling code.

+   - **semume** Determines the maximum allowable per process undo structures, or another way, the maximum number of semaphore undo operations that can be performed per process. The kernel maintains information about changes processes make to semaphores (semaphore value adjustments). In the event of a process exiting prematurely, the kernel can set the semaphore values back to what they were before the process changed them. This is what undo structures are used for: to undo semaphore alterations in the event of abnormal process termination.
