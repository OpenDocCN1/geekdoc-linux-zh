maxusers is set in /etc/system, that value is used, up to a maximum value of
2048; any /etc/system maxusers value larger than 2048 results in maxusers
setting to 2048. Once maxusers is established, the startup code sets other ker-
limits, based on maxusers in the kernel param_calc() function.

+   - maxpid — Maximum process ID value. If pidmax is set in /etc/system, the
pidmax value will be tested against a minimum reserved_procs (5
in Solaris 2.5.1, 2.6, and 7) and a maximum value (30,000 in all three
releases). If pidmax is less than reserved_procs or greater than 30000, it
is set to 30000. Otherwise, the user-defined value is set.
- maxnproc — Maximum number of processes, systemwide, set as (10 +
16 * maxusers).
- maxprucs — Maximum processes per non-root user, set as (maxnproc-
reserved_procs), reserved_procs has a default value of 5.
- ufs inode and nsize — High limits for the UFS inode cache and direc-
tory name. (See "The Directory Name Lookup Cache (DNLC)") on
page 557). Both of these caches are set to the same value, (4
(max_nproc + maxusers) + 320).
- ndquot — The number of UFS disk quota structures, systemwide, set as
((maxusers * 40) / 4) + max_nproc.

As you can see, maxusers is not really the maximum number of users the system
it will support. It's simply a parameter that can be set to drive the number of sev-
eral configurable kernel resources that indirectly affect the load or volume of users
system can handle. Many things factor in to the user load capabilities of
system, not the limit of what constitutes a user, what a user does, and
hhow a kernel connects to the system.

Other kernel parameters that are related to the STREAMS subsystem and mis-
cellaneous areas of the system are also set at this time. These parameters use
hard-coded default values that are not driven by the maxusers parameter unless
value has been set in /etc/system.

+   - nstrpush — Number of STREAMS modules that can be contained (pushed)
on a single STREAM; set to 9.
- strmsgs — Maximum size of a STREAMS message; set to 64 Kbytes.
- strctlsz — Maximum size of a STREAMS control message.
- groups max — Maximum number of groups a user can belong to; set to 16.
- rstown — A boolean that forces POSIX chown(1) behavior, where pro-
cess must have an effective UID of 0 (root) to change file ownership; set to 1
(true) by default.
