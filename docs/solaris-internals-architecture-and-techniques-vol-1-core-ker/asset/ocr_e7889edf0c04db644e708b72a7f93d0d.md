# Use adb to determine the size of the DNLC.

```
# adb -k
physmem b919
ncsize/D
ncsize:
ncsize:      25520
```

The hit rate of found the directory name cache shows the number of times a name was looked up and found in the name cache. A high rate (>90%) shows that the DNLC is working well. A low hit rate does not necessarily mean that the DNLC is undersized; it simply means that we are not always finding the names we want in the name cache. The reason is that a create operation checks to see if we are creating a large number of files. it creates the file, causing a large number of cache misses.
