You can examine the callout table on a running system (all releases) with the
out function in the crash(1M) utility.

```
# /etc/crash
dumpfile = /dev/mem, namelist = /dev/ksym, outfile = stub
> callout
FUNCTION         ARGUMENT                TME
polltime         0000000d8f2de8 000000006a4971 fffffffff761f0
realexpire       0000000090ed80 000000006ad3f9 fffffffffff79890
setrun           000002a103afd60 000000006bd9d7 fffffffffff95a1
schedpaging      000000000000000 000000006bd0f fffffffffff7c618
mi_timer_fire    00000300a36b20 000000006bd200 fffffffffff7c628
alalarm_proc     000000000000000 000000006be219 fffffffffff7cb68
ts_update        000000000000000 000000006be219 fffffffffff7cb68
seg_update       000000000000000 0000000069c139 fffffffffff7cb88
kmem_update      000000000000000 0000000069c139 fffffffffff7cb09
```

Note that the example output from the callout function in crash(1M) is not a com-\plete listing. Note, that the ARGUMENT, TIME, and ID columns are 8-byte (64-bit) data types. On a
32-bit kernel, they are 32-bit data types.

+   - polltime — A real-time callout. From the poll(2) system call and based
t poll interval. polltime() wakes up a thread waiting on a poll event.

+   - realexpire — A real-time. Used in the real-time timer interval
support when a timer is set. Callouts are derived from timer value.
realexpire() generates the SIGALRM to the process.

+   - setrun — A real-time callout. Placed on the callout queue by sleep/wakeup
code (variables) to force a thread wakeup when the sleep event has
time value; for example, an aiowait(2) can specify a maximum tick
count to wait for the I/O to complete. aiowait(2) with a timeout specificity
u a timed timeout variable, which in turn places a setrun() event on
the callout queue to force a thread wakeup if the timer expires before the I/O
has completed.

+   - schedpaging — A normal callout. Part of the paging subsystem in the VM
system, to manage the pageout rate.

+   - mi_timer_fire — A normal callout. Part of the STREAMS-based TCP/IP
protocol support. mi_timer_fire() generates regular message block pro-\cessing through a STREAMS queue.
