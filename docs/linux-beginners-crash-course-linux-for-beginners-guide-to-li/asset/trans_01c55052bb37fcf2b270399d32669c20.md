
## 第 9 章 – 在 Linux 中移动

你可以使用一个名为 *cd* 的命令在 Linux 中移动。这是 change directory（改变目录）的缩写，其用法如下：

```
cd [location]
```

如果你在运行 `cd` 时没有使用任何参数，它会自动带你回到你的主目录。但通常情况下，它在命令行中是通过单个参数运行的，*即*，你要切换到的目录的位置。这通过路径指定，可以使用我们在上一章中讨论过的任何构建块来表示相对路径或绝对路径。

看看这些例子：

```
pwd
/home/Simon
cd Documents
ls
file1.txt file2.txt file3.txt
…
cd /
pwd
/
ls
bin boot dev etc home lib var
…
cd ~/Documents
pwd
/home/Simon/Documents

cd ../
pwd
/home
cd
pwd
/home/Simon
```

### Tab 补全

反复输入这些路径可能会变得枯燥乏味，而且你可能最终会犯错。然而，命令行中有一种便捷的机制可以帮助解决这个问题。它叫做 Tab 补全。当你开始输入路径时，无论你在命令行中的哪个位置以及正在使用什么命令，你都可以按 Tab 键调出自动补全。如果没有变化，这意味着路径有多种补全可能性。再次按 Tab 键将显示这些可能性。继续输入你的路径，然后再次按 Tab 键以将可能性缩小到正确的那一个。在你的命令行上试一试，看看效果如何。

### 文件

在 Linux 中，一切皆文件。目录、文本文件，甚至你的键盘（但仅限于你的系统可以从中读取的那个）——它们都是文件。你的系统向其写入内容的显示器也是一个文件。这不会对你所做的任何事情产生影响，但你应该记住这一点，以帮助理解 Linux 的工作原理。

### 无扩展名系统

这可能需要一些时间来习惯，但当你逐步深入编程时，它将开始变得合乎逻辑。文件扩展名通常是一组字符，长度为二到四个，位于文件名的末尾的点之后。扩展名告诉你文件类型是什么。一些常见的扩展名包括：

- `file.exe` – 可执行的文件或程序
- `file.txt` – 纯文本文件
- `file.png` – 图像文件
- `file.gif` – 图像文件
- `file.jpg` – 图像文件

在 Windows 等系统中，文件扩展名非常重要，因为系统使用它来确定正在处理的文件类型。Linux 在这方面有所不同，它忽略文件扩展名，而是查看文件内部以确定其类型。例如，你可以取系统中的 .jpg 文件，也许是一张你房子的照片，并将其扩展名更改为 .txt。Linux 会忽略扩展名，查看文件内部，然后将其作为它实际所属的图像文件进行处理。但并非总是容易确定文件应该被视为什么文件类型，这就是一个名为 `file` 的小命令发挥作用的地方。

```
file [path]
```

现在，你可能会在此时想到，为什么指定的是路径而不是文件？请记住，当在命令行上指定文件或目录时，它实际上是一个路径。此外，目录只不过是特定类型的文件；路径用于将我们带到系统中的特定位置，而那个位置就是一个文件。

### Linux 区分大小写

这一点非常重要，务必记住，这也是新手在使用 Linux 时遇到问题的主要原因之一。许多操作系统不区分大小写，但 Linux 区分，特别是在引用文件时。在 Linux 中，完全可能存在两个文件或目录，其名称仅在大写和小写方面相同，例如：

```
ls Documents
FILE1.txt File1.txt file1.TXT
...
file Documents/file1.txt
Documents/file1.txt: ERROR: cannot open 'file1.txt' (No such file or directory)
```

Linux 将这些视为不同的文件。在处理命令行选项时，你也应该注意大小写。例如，对于 `ls` 命令，有两个选项 – S 和 s – 它们执行两个不同的功能。最常见的错误之一是在应该使用小写字母的地方输入了大写选项，然后困惑于为什么输出不是你预期的那样。

### 名称中的空格

目录和文件名中有空格并没有什么问题，但你应该小心处理。命令行中的空格用于分隔事物 – 它们是如何确定程序名称并识别命令行参数的。假设你想移动到一个名为 Holiday Photos 的目录。这个例子将不起作用：

```
ls Documents
FILE1.txt File1.txt file1.TXT Holiday Photos
...
cd Holiday Photos
bash: cd: Holiday: No such file or directory
```

在这个例子中，Holiday Photos 被视为两个独立的命令行参数。命令 `cd` 仅移动到由第一个参数指定的目录。为了解决这个问题并使其正常工作，我们需要让终端知道 Holiday Photos 应被视为单个命令行参数。我们有两种同样有效的方法可以做到这一点。

#### 引号

第一种方法是用引号将 Holiday Photos 括起来 – 单引号或双引号都可以，只要你使用匹配的一对即可。引号内写入的任何内容都被视为一个单项：

```
cd 'Holiday Photos'
pwd
/home/Simon/Documents/Holiday Photos
```

#### 转义字符

另一种方法是使用一种叫做转义字符的东西。这是一个反斜杠 (\)，它的作用是取消下一个字符的特殊含义：

```
cd Holiday\ Photos
pwd
/home/Simon/Documents/Holiday Photos
```

在这个例子中，Holiday 和 Photos 之间的空格通常具有特殊含义 – 将它们作为独立的命令行参数分开。然而，在前面加上反斜杠取消了该含义。如果你使用 Tab 补全，在遇到目录名称中插入的空格之前，终端会自动为你转义该空格。

### 隐藏文件与目录

Linux 有一种非常棒的机制来告诉你某个目录或文件已被隐藏。如果文件或目录的名称以点 (.) 开头，它就被归类为隐藏。隐藏文件或目录不需要任何特殊的命令或操作。你之所以想要隐藏文件或目录可能有多种原因。例如，可能有其他用户隐藏他们的配置文件，以免妨碍你。

要隐藏文件或目录，只需在名称开头添加一个点。如果你已经创建了文件，只需在名称前添加点并重命名即可。同样地，你可以通过从文件或目录名称中移除点来取消隐藏。

需要牢记的一点 – `ls` 命令不会列出任何隐藏目录或文件，除非你通过添加命令行选项 `-a` 来修改命令。只有这样，它才会列出任何隐藏的内容。

```
ls Documents
FILE1.txt File1.txt file1.TXT
...
ls -a Documents
. .. FILE1.txt File1.txt file1.TXT .hidden .file.txt
...
```

### 手册页

Linux 提供了一组页面，告诉你有关每个命令的所有信息 – 它们的作用、工作原理、如何运行以及每个命令接受的命令行参数。对于 Linux 新手来说，其中一些可能有点难以理解，但它们是一致的。一旦你掌握了几页，它们就会开始对你有意义，你会发现它们更容易操作。使用此命令调用手册页：

```
man <command to look up>
```

例如：

```
man ls
```

**名称**

`ls - list directory contents`

**概要**

`ls [option] ... [file] ...`

### 搜索

你可以在手册页中搜索特定的关键字。如果你需要提醒某个命令的作用 – 当你知道想要做什么但不确定需要使用哪个命令时，这将很有帮助。你可能需要尝试几次才能找到你要找的东西。你还会发现，你要搜索的特定关键字出现在多个页面中，然后你必须从中筛选以找到正确的那个。语法是：

```
man -k <search term>
```

你还可以在手册页内部进行搜索。当你在一个页面上并且想在该页面上搜索某些内容时，按正斜杠 (/) 按钮，然后跟上搜索词。按回车，你的结果将显示出来。如果搜索词有多个实例，你可以按 ‘n’ 键遍历它们。
