## 引言

Linux 曾被视为弱势的操作系统，在一段时间内它默默无闻，被强大的 Windows 所掩盖。但最近，Linux 在软件开发人员和企业中赢得了赞誉。这种 Unix 变体，曾经只被极客和书呆子所知，如今在普通家用电脑用户中也日益流行。
Linux 是免费的，并且可以在不同的平台上运行。它正在积累一个忠实的用户群，并越来越吸引以下人群的注意：
- 熟悉 Unix 并有兴趣在个人计算机上运行它的人
- 有兴趣通过实验了解操作系统原理的人
- 想要一个能给予他们最大控制权的操作系统的人
- 对 Microsoft Windows 不满意的人
管理 Linux 比使用 Windows 更困难，但 Linux 更灵活，拥有更多的配置选项。
企业似乎也在克服对 Linux 的非理性怀疑，并将 Linux 应用于许多业务场景。由于 Linux 是开源的，公司在进行此类适配时不必担心许可问题。这使得它成为一个非常有吸引力的选择。

## 第 1 章：Linux 与其他操作系统

如果你是一名计算机程序员，你已经了解 Linux。如果不是，你可能已经从朋友那里听说过它。无论如何，Linux 都很有趣，你了解的越多，关于它的问题也会越有趣。

### 什么是 Linux？

一般来说，有两类 PC 用户。大多数人把计算机看作一个用于浏览网页、玩游戏、看电影和听音乐等酷事的惊人工具。他们甚至可能知道 RAM、处理器和音视频卡等硬件组件。但他们并不关心这些简单过程背后的复杂性。他们打开浏览器，输入地址，不知怎的网站就打开了。他们对它是如何实现的并不感兴趣。
还有一群人真正想了解事物内部是如何运作的。几乎每个人都认为操作系统是额外的软件。事实并非如此。操作系统，就像硬件组件一样，是计算机的重要组成部分。当需要时，操作系统可以被升级或替换为更合适的操作系统。

### Linux 的优势

你可能认为那些谈论 Linux 的人在夸大它的优秀程度，但实际上它确实比其他操作系统具有许多真实的优势。这些包括以下方面：

#### 无崩溃

Linux 是一个无崩溃的操作系统。当你使用 Linux 时，你不会经历光标在屏幕上冻结、系统突然崩溃或直到重启系统才消失的错误信息。运行在 Linux 操作系统上的程序或应用程序可能会崩溃，但操作系统仍将继续运行。当应用程序崩溃时，它不会拖垮操作系统。在 Linux 中，与其他操作系统不同，你可以简单地清理程序崩溃后的残留，然后继续工作。Linux 的无崩溃可靠性在处理如太空飞行和核能等无法承受系统崩溃风险（可能导致巨额费用、伤害或死亡）的操作时，是一项巨大的资产。

#### 安全性

Linux 的下一个优势是其安全性。Linux 操作系统的安全性远胜于存在许多安全漏洞的 Windows。这是因为在 Linux 开发中投入了多年的广泛计算机科学研究。在 Linux 中，如果你没有适当的权限，你将不被允许访问系统中的特定硬件部件或特定文件夹。隐私可以设置为仅限所有者访问，他们只能访问自己的文件。`root` 用户将拥有对完整系统的访问权，并可以限制其他用户的访问。

#### 免费且可共享

Linux 的另一个主要好处是它是一个免费的操作系统。更新可以免费下载，当操作系统的新版本可用时，你可以免费替换当前版本。实际上，你可以下载你想要的任何版本的 Linux。作为自由软件，它可以在一群人之间共享。默认的图像查看器、音乐播放器、图像编辑器等应用程序都可以共享。这在 Windows 或大多数其他操作系统中是不可能实现的，因为复制这些类型的应用程序并与他人共享会使你成为软件海盗。但在 Linux 中，这是完全合法——实际上还受到鼓励——与其他用户共享软件。

### 兼容性

Linux 的一个优点是它甚至可以在较旧的硬件上运行。与最新的其他操作系统版本不同，你不需要一台高性能、尖端配置的 PC。例如，新版 Windows 需要新硬件才能运行。Linux 操作系统甚至可以在过时的硬件上运行。因此，如果你想运行 Linux，就不需要购买新电脑。你可以在同一硬件上安装 Linux 和任何其他操作系统，亲身感受差异。与 Windows 等耗电的操作系统相比，Linux 操作系统运行得更快、更好。Linux 社区鼓励用户回收和重复利用组件，以最大限度地利用现有硬件。实际上，你可以通过在其上安装 Linux 让一台旧计算机系统恢复生机。即使你不需要它，也可以把它送给没有 PC 的朋友或家人。

### 灵活性

Linux 操作系统具有极高的灵活性。Linux 几乎能在 60% 的计算机上运行，并且可以使用宽带互联网连接。你可以将旧硬件变成 Web 服务器、电子邮件服务器、防火墙或你想象中的任何其他用途。使用其他操作系统这样做会花费你一大笔钱，因为你需要一台真正高性能的计算机。

### Linux 社区

但 Linux 最好的特性无疑是 Linux 社区。Linux 不仅仅是一个计算机操作系统。当你开始使用 Linux 时，你就成为了一个遍布全球的大型社区的一部分。成为 Linux 社区的一员有其独特的优势。其中之一就是无论你有什么问题，你总能很快找到解决方案。该社区中大多数人都是 Linux 布道者，乐于帮助他人解决问题。Linux 社区的新成员被称为“菜鸟”（newbies），听起来似乎有点贬义，但实际上是向专业 Linux 程序员学习的好机会。这些程序员认为知识应该自由共享，并乐意帮助其他人学习 Linux。当某人宣布自己“菜鸟”身份时，人们会抽出时间来帮助他。毕竟，那些专业人士也曾是菜鸟。

### 操作系统特性

操作系统可以被看作是计算机硬件与用户之间的接口或中介。操作系统为用户提供了一种环境，使其能够高效、便捷地运行不同的程序。从技术上讲，操作系统是管理其运行所在硬件并控制各种程序执行的软件。操作系统负责分配服务和资源，如处理器、内存、设备和信息。Linux 就是这样的操作系统之一。任何操作系统的重要功能如下：
- 内存管理
- 设备管理
- 处理器管理
- 安全性
- 文件管理
- 系统性能控制
- 错误检测
- 作业记账
- 用户与其他软件之间的协调

#### 内存管理

内存管理是管理主内存（或称主存）的过程。内存可以被视为一个非常大的字节或字数组，每个都有自己独立的地址。
主内存为 CPU 提供直接访问和更快的存储。因此，如果你想执行程序，它必须存储在计算机的主内存中。每个操作系统，包括 Linux，都会执行以下内存管理活动：
- 追踪主内存的使用情况，包括已用和未用内存。对于已用内存，操作系统还会追踪哪些用户在使用它。
- 在多道编程环境下，操作系统将决定如何为不同的进程分配内存。
- 每当某个进程请求额外内存时分配内存。
- 当特定进程终止或不再需要内存时，操作系统也会处理内存的释放。

#### 处理器管理

在多道程序环境中，操作系统是决定每个进程处理器分配时间的程序。对于处理器管理，每个操作系统都会执行以下活动：
- 使用交通控制器程序追踪进程状态和处理器状态。
- 将处理器分配给给定进程。
- 当处理器不再被需要时进行回收。

#### 设备管理

设备使用它们自己的驱动程序相互通信，但操作系统负责管理这种通信。操作系统的设备管理器执行以下活动：
- 追踪所有可用设备。I/O 控制器是负责执行此任务的程序。
- 设备管理器决定将特定设备分配给哪个进程。它还负责分配进程需要设备的时间。
- 它有效地将设备分配给进程。
- 设备的释放也由设备管理器处理。

#### 文件管理

为了便于使用和导航，文件系统被组织成目录，其中存储着文件和其他目录。操作系统执行以下文件管理活动：
- 追踪文件状态、用途、位置、信息等。文件系统是这些功能的集合。
- 操作系统的文件管理器是决定资源分配的程序。
- 它还决定谁可以使用资源。
- 资源的释放由文件管理器处理。

#### 其他重要活动

以下是操作系统执行的少数其他重要活动：
- 安全性——通过使用密码或类似技术，操作系统将防止对数据和程序的未授权访问。
- 系统性能控制——操作系统通过记录由服务作为请求发出的延迟以及系统给出的响应来控制系统性能。
- 作业记账——操作系统负责追踪不同用户在各种作业中使用的资源和时间。
- 错误检测辅助——为了进行错误检测，操作系统会产生错误消息、转储和其他一些错误检测和调试辅助工具。
- 其他软件与用户之间的协调——操作系统负责协调和分配汇编器、编译器、解释器以及其他软件给使用计算机系统的其他用户。

### 操作系统类型

操作系统从第一代计算机开始使用，并在此期间不断演进。以下是几种最重要的类型。

#### 批处理操作系统

使用批处理操作系统时，用户不直接与计算机交互。用户准备的每个作业都转移到离线设备（如打孔卡片）上，然后提交给计算机操作员。为了提高性能和速度，这些作业被分批合并成一个组。计算机将同时运行这组作业。程序员将程序交给操作员，操作员根据这些程序的要求相似性，将它们按类型分成不同的批次。虽然这是一种良好的实践，但批处理操作系统有几个缺点：
- 作业与用户之间没有交互。



由于 CPU 和机械 I/O 设备（显然速度慢得多）之间的速度差异，CPU 大部分时间处于空闲状态。

提供所需特性可能很困难。

### 分时操作系统

分时是一种技术，其中多个终端位于一台计算机系统中，并且可以同时使用。多任务处理或分时是多道程序处理的逻辑延伸。不同用户之间处理器时间的同时共享称为分时。分时系统与多道程序批处理系统的主要区别在于，多道程序批处理系统旨在最大化处理器效率，而分时系统的主要目标是最大限度地减少响应时间。

在这里，作业很频繁。它们可以切换并由处理器执行，这意味着用户可以得到即时响应。例如，在事务处理中，处理器以计算量子（即短脉冲）执行程序。每个用户的响应时间最多只有几秒钟。

操作系统利用多道程序处理和 CPU 调度来为每个用户提供一小部分时间。所有最初设计为批处理操作系统的计算机系统后来都被修改成了分时系统。

以下是分时操作系统的一些优点：

- 用户能获得快速响应。
- 避免了软件重复。
- 减少了 CPU 空闲时间。

但分时操作系统也有一些缺点：

- 可靠性较低。
- 数据和程序的完整性与安全性面临风险。

### 分布式操作系统

分布式操作系统利用多个 CPU 处理多个用户和多个实时应用程序。由于数据处理任务相应地分布在不同的处理器上，作业执行效率得以提高。

进程通过高速总线等各种线路相互通信。这也可以被称为松耦合系统。分布式操作系统中的处理器被称为计算机、站点、节点等，其功能和大小可能各不相同。

分布式操作系统的一些优点如下：

- 资源共享设施允许一个站点的用户访问和使用位于不同站点的资源。
- 使用电子邮件提高了数据交换速度。
- 即使分布式操作系统中的一个站点发生故障，其他站点可能不受影响，并可能继续运行。
- 客户获得更好的服务。
- 减轻了宿主机的负载。
- 减少了数据处理延迟。

### 网络操作系统

网络操作系统运行在服务器上，为服务器提供数据管理、组管理、用户管理、应用管理、安全管理以及其他一些网络功能。网络操作系统负责网络中所有计算机之间的文件共享和打印机访问。这些网络通常是专用网络或局域网，但可以是任何类型。`Linux` 可以用作强大且高效的网络操作系统。

网络操作系统的优点在于：

- 集中式服务器的稳定性高。
- 服务器可以管理安全性。
- 任何硬件或软件更新都可以轻松集成到系统中。
- 可以从不同类型的系统或不同位置远程访问服务器。

网络操作系统的缺点包括：

- 初始成本和维护成本高。
- 服务器在大多数操作上依赖于中心位置。
- 需要频繁更新和定期维护。

### 实时操作系统

实时操作系统可以被定义为一种数据处理系统，其中处理和响应输入所需的时间间隔非常短，足以控制环境。所有实时处理都是在线的，但在线系统不一定是实时系统。系统响应输入并输出更新信息所花费的时间称为响应时间。与在线处理的响应时间相比，这种方法的响应时间非常快。

实时操作系统有两种不同的类型：

#### 硬实时系统

硬实时系统保证关键任务按时完成。没有二级存储或二级存储有限。数据可以存储在 ROM 格式中。硬实时系统中没有虚拟内存。

#### 软实时系统

软实时系统比硬实时系统的限制少。软实时系统优先处理关键任务，并在每个任务完成前保留这些优先级。与硬实时系统相比，软实时系统的实用性有限。例如，行星探测车和深海探索等先进的科学项目可以使用软实时系统，它们还具有虚拟现实和多媒体应用。

# 第 2 章：Linux 的组件、特性与架构

`Linux` 操作系统是 `UNIX` 操作系统中最流行的版本。`Linux` 基本设计为与 `UNIX` 兼容，两种操作系统功能非常相似。

## 组件

`Linux` 操作系统有三个主要组件：

- **内核** – 内核被认为是 `Linux` 操作系统的核心，负责系统的主要活动。内核直接与硬件交互，并包含各种模块。内核通过为应用程序或系统提供所需的抽象，隐藏了所有低级硬件细节。
- **系统库** – 系统库可以被视为特殊的程序或函数，系统实用程序或应用程序通过这些功能访问内核的特性。这些库可以实现的大部分功能也由操作系统实现。系统库不需要内核模块的代码来获得访问权限。
- **系统实用程序** – 系统实用程序是负责执行专门和独立任务的程序。

## 特性

以下是 `Linux` 操作系统的一些最重要特性：

- 可移植性 - 可移植性意味着软件可以以相同的方式在不同类型的硬件上运行。`Linux` 内核和应用程序可以安装在任何类型的硬件平台上。
- 开源 - `Linux` 源代码可自由获取。开发是一个基于社区的项目。多个团队协作增强 `Linux` 操作系统的能力，并且它正在不断进化。
- 多用户 - `Linux` 是一个多用户系统，意味着多个用户可以同时访问系统资源，如内存/`RAM`/应用程序。
- 多任务处理 - `Linux` 是一个多任务处理系统，意味着多个应用程序可以同时运行。
- 层次文件系统 - `Linux` 提供了一个标准的文件结构，其中系统文件/用户文件被排列其中。
- Shell - `Linux` 提供了一个特殊的解释器程序，可用于执行操作系统命令。它可用于各种类型的操作、应用程序等。
- 安全性 - `Linux` 使用认证功能（如密码保护/特定文件的受控访问/数据加密）提供用户安全性。

## 架构

以下是 `Linux` 系统架构的一部分层：

- 硬件 - 所有外围设备，如硬盘、`CPU` 和 `RAM`，都是硬件层的一部分。
- 内核 - 内核是操作系统的主要或核心组件。它直接与系统硬件通信，为上层组件提供低级服务。
- Shell - `Shell` 是用户与内核之间的接口。`Shell` 接受用户给定的命令并执行内核功能。
- 实用程序 - 实用程序程序是那些为用户提供操作系统大部分功能的应用程序。

# 第 3 章：Linux 内核

在本章中，我们将学习 `Linux` 内核。`Linux` 内核是与 `UNIX` 相似的计算机操作系统。它在世界各地被广泛使用。`Linux` 操作系统完全基于 `Linux` 内核。它通过 `Linux` 发行版部署在传统的计算机系统中，也部署在路由器等嵌入式设备上。运行在移动和平板电脑计算机上的 `Android` 移动操作系统也是使用 `Linux` 内核构建的。

1991 年，来自芬兰的计算机科学学生 `Linus Torvalds` 为个人使用创建了 `Linux` 内核。起初，他没有打算将其用于其他平台，但逐渐开发了它，使其可以在不同的计算机架构上运行。这个新操作系统引起了开发人员的巨大关注，他们对从其他涉及自由软件的项目中改编代码以进一步开发感兴趣。近 12,000 名软件开发人员和 1,200 家公司参与了 `Linux` 内核的开发。

`Linux` 内核是自由和开源软件，这意味着任何人都可以访问和修改内核的源代码。`LKML`，即 `Linux` 内核邮件列表，主持关于 `Linux` 内核开发的讨论。

内核是用户应用程序与 `CPU`、内存和其他设备之间的接口。

`GNU` 编译器集合（`GCC`）支持 `C` 语言的一个版本（通过向标准 `C` 引入一些更改和扩展开发而来），该版本已被用于编写 `Linux` 内核。除了 `C` 语言，汇编语言也用于编写代码的几个小部分。由于 `GCC` 支持 `C` 语言的许多扩展，它曾有一段时间是唯一能够构建 `Linux` 内核的编译器。

### 内核源代码

大多数 `Linux` 发行版都包含内核源代码。您安装到系统上的 `Linux` 内核正是基于这些源代码开发而成的。您可以在 `ftp://ftp.cs.helsinki.fi` 找到它们，其他网站也提供镜像服务。如果您没有互联网访问权限，可以以合理的价格从提供知名网站快照的供应商处获取 `CD-ROM` 光盘。一些供应商还提供定期更新的订阅服务。您当地的 `Linux` 用户组也是另一个绝佳的选择。

在源码树的顶层目录 `/usr/src/Linux` 下可以找到几个目录：

- **Arch：** 与特定体系结构相关的内核代码位于此子目录中。它进一步划分为子目录，每个子目录对应一种体系结构。`Alpha` 和 `i386` 就是子目录的例子。
- **Include：** 构建内核代码所需的头文件位于此子目录中。它同样为每种体系结构划分为一个子目录。编辑内核的 `makefile` 并重新运行内核配置程序可以更改体系结构。
- **Init：** 内核的初始化代码位于此目录中。若要理解内核的工作原理，这是一个很好的切入点。
- **MM：** 与内存管理相关的文件位于此目录中。与每种体系结构的内存管理相关的代码位于 `arch/*/mm/` 中。
- **Drivers：** 这里包含系统的设备驱动程序，它们被分类到不同的类别中。
- **IPC：** 进程间通信的代码位于此目录中。
- **Modules：** 模块由此目录创建并存放于此。
- **FS：** 文件系统的代码位于此目录中。此目录有几个子划分，每个文件系统对应一个。
- **Kernel：** 这里由内核代码组成。与特定体系结构相关的内核代码可以在 `arch/*/kernel` 中找到。
- **Net：** 这是内核的网络代码。
- **Lib：** 内核的库代码位于此目录中。与特定体系结构相关的库代码位于 `arch/*/lib/` 中。
- **Scripts：** 在内核配置期间使用的脚本位于此目录中。

# 第 4 章：Linux 进程



## task_struct

为了高效地处理系统中的进程，Linux 使用一种名为 `task_struct` 的数据结构来表示每个进程。（在 Linux 中，进程和任务这两个术语可以互换使用。）数据结构 `task_struct` 包含一个被称为任务向量的指针数组。

任务向量限制系统中进程的数量。默认情况下，最大条目数为 512。创建新进程会导致从内存中分配一个新的 `task_struct`。将其添加到任务向量即完成创建。`current` 指针指向当前正在运行的进程，以便更容易找到它们。

除了普通进程外，Linux 还支持实时进程。这些实时进程之所以被称为实时，是因为预计它们对外部请求的响应非常迅速。调度器对它们的处理方式与对普通进程略有不同。复杂的 `task_struct` 数据结构通过划分为以下功能区域来简化：

### 状态

进程在执行结束后，根据具体情况，其状态会发生变化。每个 Linux 进程具有以下状态之一：

Running（运行中）

在此状态下，进程已准备好运行或正在系统中运行。“准备好运行”意味着该进程已准备好被系统处理器之一接管以进行执行。

Waiting（等待中）

等待状态意味着进程正在等待资源或事件的触发。等待进程分为两种类型：可中断和不可中断。信号可以中断某些等待进程，这些被称为可中断进程；信号无法中断的等待进程被称为不可中断进程。

Stopped（停止）

当然，停止的进程已被停止，通常是由于接收到了信号。若要调试进程，必须将其置于停止状态。

Zombie（僵尸）

这是一个已终止的进程，它以数据结构 `task_struct` 的形式存在于任务向量中。因此，它被称为僵尸进程。

### 调度信息

这是调度器用来决定进程运行顺序的信息。

### 标识符

一个数值型进程标识符（`PID`）用于标识系统中的每个进程。

## 进程间通信（IPC）

Linux 支持的重要 IPC 机制包括信号、管道、消息队列、共享内存、信号量等；您将在后续章节中详细了解它们。

# 第6章：进程间通信



进程间通信是一种使用各种通信协议在不同进程之间共享数据的过程。服务器和客户端是使用进程间通信的两种类型的应用程序。在这种应用程序中，客户端映射到一个或多个服务器，并向其请求数据形式的信息。服务器或服务器发送这些数据。不同的平台提供了不同的方式供客户端访问数据。以下是 Linux 为进程间通信提供的机制：

- 1. 内核或进程向它们希望通信的进程发送信号。信号是 Linux 平台提供的最廉价的进程间通信形式，可以是事件或状态的形式。事件和状态都暗示或通知某个进程或内核中发生了一些变化。

- 2. `|` 被称为管道。它由平台使用的 shell 设置，用于将一个进程的输入传输到另一个进程。管道的两端通过两端的文件描述符链接为一对一通信机制。这些文件描述符与单一功能相关联，即只读或只写。发送详情的端使用读取文件描述符从进程中读取数据。同时，需要接收数据的端将使用写入描述符，以便可以写入接收到的数据。由于数据流是单侧的，该机制被称为半双工机制。具有父子关系的进程，其中父进程创建管道与其子进程通信，并在其子进程之间创建管道以便它们可以相互通信，可以使用这些管道。这是因为文件描述符被复制到它们的地址空间中。

- 3. 先进先出（FIFO）管道也称为命名管道，其使用方式与无名管道相同。唯一的区别是，这些管道用于进程之间没有关联的情况。使用这些管道的进程使用 FIFO 文件而不是文件描述符进行通信。FIFO 文件具有与文件描述符相同的机制：一个 FIFO 文件具有读取功能，另一个具有写入功能。因此，这种机制也是半双工的。

- 4. 为了允许单个或多个进程从单个或多个进程读取或写入，我们使用消息队列。这种机制类似于信箱。想要共享数据的进程过来将包含数据的包放到消息队列上然后离开。想要获取数据的进程过来取出包。这节省了大量时间，因为共享数据的进程无需等待另一个进程。消息队列有两种不同的规范。首先是 SysV 消息队列，其中正在发送的消息包含一个数字，以便接收消息的进程可以获取与特定数字匹配的数据，或者接受除与特定数字匹配的包之外的所有内容。第二种是 POSIX，这是一种基于优先级的机制。它按优先级顺序发送包。当进程发送数据时，优先级数字附加在包上。因此，当其他进程接收到详情时，首先获取最高优先级包中的数据。

- 5. 有计数器对将依次接收共享资源的进程顺序进行排队。这些计数器被称为信号量。它们锁定共享资源，使得只有一个进程可以访问共享资源。一旦该进程使用完资源，资源就会被释放。然后，优先级中下一个的进程将获得资源，或者无论优先级如何，请求资源的进程将获得资源。这与消息队列的 SysV 和 POSIX 机制类似，因此这些被称为 SysV 信号量和 POSIX 信号量。

- 6. 多个进程共享可用内存空间的机制称为共享内存机制。这有助于共享内存的两个或更多进程更高效地通信，从而减少对内核的干扰。还有两种类型的共享内存，SysV 共享内存和 POSIX 共享内存，它们的工作方式如上所述相同。也就是说，一种考虑优先级，而另一种则不考虑。

# 第7章：Linux Shell

正如你已知，计算机只能理解零和一，即二进制语言。在计算的第一代中，指令直接以二进制语言给出。但二进制语言极其难以理解，且用其编写代码既费时又困难。为了解决这个问题，一种名为 shell 的特殊程序被引入到操作系统中。Shell 接受以英语给出的命令，并检查它们是否有效。

如果给定的命令是有效的，shell 将其传递给内核。Shell 可以被视为简化用户与内核之间交互的程序。Shell 是一个命令行解释器。它可以接受来自文件或标准输入设备（如键盘）的输入。虽然 shell 不是内核的一部分，但它使用内核来创建文件、执行程序等。

最基本的是，shell 是用户与系统内核之间的接口，但 shell 可以执行一些基本命令而无需将其传递给内核。

如果你想知道系统中可用的 shell，请使用以下命令：

```
$ cat /etc/shells
```

虽然在一个操作系统中有许多可用的 shell，但它们都被设计来做同样的工作。不同的 shell 具有不同的语法和不同的内置功能。在 MS-DOS 中，`command.com` 是 Windows 操作系统使用的 shell。它不如 Linux 中存在的 shell 强大。

所有 shell 都通过文件或键盘等输入设备从用户那里获取命令，并向 Linux 操作系统传达用户所需的信息。

如果用户使用键盘等输入设备给出命令，则称为命令行接口。下面给出的命令显示了您当前正在使用的那个 shell：

```
$ echo $SHELL
```

## Shell 脚本

所有的 shell 都是交互式的，这意味着它们接受用户输入的命令并可以执行这些命令。你可以逐个输入命令，也可以将它们按顺序存储在文本文件中，然后将其交给 shell 执行。一次性输入所有命令被称为 shell 脚本编程。

Shell 脚本通常定义如下：

“Shell 脚本是一系列写在纯文本文件中的命令。Shell 脚本就像 MS-DOS 中的批处理文件一样，但它的功能比 MS-DOS 批处理文件更强大。”

### 编写 shell 脚本的原因

- 你可以直接通过文件或直接向 shell 脚本提供输入，它会在屏幕上给出输出。
- 你可以使用 shell 脚本创建自定义命令。
- Shell 脚本通过一次性处理所有命令为你节省大量时间。
- Shell 脚本可用于自动化日常任务。
- 你还可以使用 shell 脚本来自动化系统管理。

### 如何编写 shell 脚本

在编写 shell 脚本时，请遵循以下步骤：

- 使用编辑器，例如 `mcedit` 或 `vi`。
- 在 shell 脚本中写好命令集后，你需要设置脚本的执行权限，使用 `chmod` 权限 `your-script-name`。例如，`$ chmod +x your-script-name` 或 `$ chmod 755 your-script-name`。系统管理员或所有者应具有读/写/执行权限（7）。在为组设置权限时，应仅使用读和执行权限（5）。
- 现在你应该按照以下语法执行你编写的脚本：

```
syntax: bash your-script-name
sh your-script-name
./your-script-name
```

示例：

```
$ bash bar
$ sh bar
$ ./bar
```

- 注意，`./` 指示当前工作目录，而点 `.` 指示在当前 shell 中执行给定的命令文件，而不初始化一个新的 shell 副本。使用点的语法是 `. command-name`；例如，`$ .foo`。
- 现在你可以使用 `vi` 命令列表（或任何其他编辑器）编写你自己的新 shell 脚本，名为 First Shell：

```
$ vi first
#
### My first shell script
#
clear
echo "First Shell"
```

- 保存脚本后，你可以使用 `$ .first` 运行它，但首先你必须使用 `$ chmod 755 first` 设置权限。现在当你输入 `$ .first` 时，屏幕将被清除，然后你的 shell 脚本中给出的消息将被打印：

输出：First Shell

| 命令(s) | 含义 |
|---|---|
| `$ vi first` | 启动 vi 编辑器 |
| `# My first shell script` | `#` 后跟任何文本被视为注释。注释提供有关脚本的更多信息；它是关于 shell 脚本的逻辑解释。语法：`# comment-text` |
| `clear` | 清屏 |
| `echo "First Shell"` | 要在屏幕上打印消息或变量值，我们使用 `echo` 命令。`echo` 命令的一般形式如下：`echo "Message"` |

## 第 8 章：命令行教程

现在你已经知道 Linux 是做什么的了，是时候开始实际使用它了。我们将从基本的命令行教程开始，但首先你需要知道如何打开终端。这并不难，但所有系统都不同，所以请将其仅作为指南使用：

- Mac 用户应该打开应用程序、实用工具，然后点击终端。快捷方式是按下 Command+Space，这将打开 Spotlight，之后你可以输入单词 Terminal。当结果显示出来时，点击该结果。
- Linux 用户应该在应用程序>系统或应用程序>实用工具中查找。快捷方式是右键点击桌面，查找“在终端中打开”选项。如果该选项存在，请点击它。
- Windows 用户可以简单地在开始菜单的搜索栏中输入单词 Command。点击命令提示符选项，它将直接带你进入。

如你所知，命令行是你输入命令并接收输出或反馈（作为文本）的地方。命令行以提示符开头，你输入的文字显示在该提示符之后。你的大部分工作将是命令工作，例如：

```
1. ls -l/home/Simon
2. total 3
3. drwxr-xr-x 2 Simon users 4096 Mar 23 13:34 bin
4. drwxr-xr-x 18 Simon users 4096 Feb 17 09:12 Documents
5. drwxr-xr-x 2 Simon users 4096 May 05 17:25 public_html
6.
```

让我们分解那段代码，看看它都意味着什么：

第 1 行始终以你的用户名@bash 提示符开头。我们也在那里放了一个命令 – `ls` – 并且命令总是你输入的第一个东西。紧随其后的是我们所有的命令行参数。要注意，命令和第一个参数之间必须始终有一个空格。第一个命令行参数是 (`-l`)，这被称为选项。

这些参数用于改变命令的执行方式。它们总是列在任何其他参数之前，并以连字符 (`-`) 开头。

第 2 至 5 行是运行你输入的命令后产生的输出。几乎所有命令都会产生输出，并且它总会紧跟在已发出的命令下方列出。少数命令仅执行不产生任何信息，除非发生错误。

第 6 行再次显示提示符。一旦命令运行完毕，终端便再次准备好接受输入，并显示提示符。如果没有显示提示符，那么该命令很可能仍在运行中。

## 快捷键

虽然终端起初可能显得有点让人望而生畏，但无需担心。Linux 内置了许多实用的快捷键，能大大简化操作，还能帮助你避免诸如拼写错误等失误。在讲解本章内容时，我会陆续介绍其中的一些，请在遇到时加以记录。




`pwd` 可以不带参数运行，而 `ls` 则拥有更多功能。在上例中，我们没有提供任何参数，因此只是列出了当前位置的内容。但你可以用更多方式操作它，例如：

方括号 `[]` 表示其中的文本是可选的，因此该命令可以带或不带这些参数运行。下面的示例展示了以多种方式运行 `ls` 命令，以便让你了解它的功能：

```bash

drwxr-xr-x 18 Simon users 4096 Feb 17 09:12 Documents
drwxr-xr-x 2 Simon users 4096 May 05 17:25 public_html
```

使用命令行选项 (`-l`) 运行 `ls` 表示我们要执行长列表显示，其内容包括：

- 随后的九个字符是文件或目录的权限
- 下一个字段是块的数量
- 下一个字段指示文件或目录的所有者
- 下一个字段指示目录或文件所属的组
- 接着是文件大小
- 接着是文件修改时间

现在 `ls` 是带命令行选项和命令行参数一起运行的，结果是 `/etc` 目录的长列表。

## 路径

在上述最后的几个命令中，我们开始引入路径的概念。学习这些路径是什么以及如何运用它们至关重要，因为在未掌握这一点之前，你无法精通 Linux 语言。当我们在命令行讨论某个目录或文件时，我们谈论的就是一个路径。就像在现实世界中一样，路径是到达某处的方式，在这里是指系统中特定的目录或文件。

### 绝对路径与相对路径

我们使用两种不同的路径——绝对路径和相对路径——来引用目录或文件。两者都可以使用，因为它们都会带你到达系统中的同一位置。首先，你需要了解 Linux 具有所谓的分层结构。最顶端是根目录，由单个斜杠 (`/`) 表示。根目录包含子目录，这些子目录又有自己的子目录，依此类推。其中任何一个子目录都可以包含文件。

绝对路径指定相对于根目录的特定文件或目录。它们可以通过都以斜杠开头这一特征来识别。相对路径指定相对于你在系统中当前位置的文件或目录，并且不以斜杠开头。

看看这个例子：

```bash
pwd
```

```bash
/home/Simon
```

通过运行 `pwd` 确认当前位置。

```bash
ls Documents
```

```bash
file1.txt file2.txt file3.txt
...
```

现在 `ls` 是带有相对路径运行的。当前位置是 Documents 目录，但此命令的结果取决于你在系统中的位置。如果你在其他系统用户的家目录中，它会为你提供该用户 Documents 目录内容的列表。



```bash
ls /home/Simon/Documents
```

```bash
file1.txt file2.txt file3.txt
...
```

最后，`ls` 是带有绝对路径运行的。此命令不依赖于你在系统中的位置；无论你在哪里，结果都将完全相同。

## 构建单元

当你学习 Linux 时，很快就会发现有很多不同的方式来完成事情。以下内容被称为构建单元，它们将帮助你构建路径：

- `~`（波浪号）– 家目录的快捷方式。例如，如果你的家目录叫 `/home/Simon`，你可以用路径 `/home/Simon/Documents` 引用 `Documents` 目录，或者只需输入 `~/Documents`。

- `.`（点）– 指向当前目录的引用。回想前面我们使用相对路径引用 `Documents` 的例子。我们也可以写成 `./Documents`。

- `..`（双点）– 指向父目录的引用。如果你想继续在层次结构中向上遍历，可以在单个路径中使用任意次。例如，如果你在 `/home/Simon`，你可以简单地输入 `ls ../../`，就会得到根目录的列表作为输出。

现在你可以看到，你可以用多种方式引用位置。至于该使用哪种方式，答案是你可以使用其中任何一种。如果你在命令行引用目录或文件，就是在引用一个路径，而该路径可以由我们讨论过的任何元素组成。最好的方式就是你觉得最容易的方式。

看看这些例子：

```bash
pwd
/home/Simon
ls ~/Documents
file1.txt file2.txt file3.txt
...
ls ./Documents
file1.txt file2.txt file3.txt
...
ls /home/Simon/Documents
file1.txt file2.txt file3.txt
...
ls ../..
bin boot dev etc home lib var
...
ls /
bin boot dev etc home lib var
```

试着在你的系统命令行中输入这些命令——我保证它们会开始让你更有意义。务必花时间彻底学习有关路径的知识并真正理解它们；你将大量使用它们。

## 第 9 章 – 在 Linux 中移动

你可以使用一个名为 `cd` 的命令在 Linux 中移动。这是 change directory（改变目录）的缩写，其用法如下：

```
cd [location]
```

如果你在运行 `cd` 时没有使用任何参数，它会自动带你回到你的主目录。但通常情况下，它在命令行中是通过单个参数运行的，*即*，你要切换到的目录的位置。这通过路径指定，可以使用我们在上一章中讨论过的任何构建块来表示相对路径或绝对路径。

看看这些例子：

```
pwd
/home/Simon
cd Documents
ls
file1.txt file2.txt file3.txt
…
cd /
pwd
/
ls
bin boot dev etc home lib var
…
cd ~/Documents
pwd
/home/Simon/Documents

cd ../
pwd
/home
cd
pwd
/home/Simon
```

### Tab 补全

反复输入这些路径可能会变得枯燥乏味，而且你可能最终会犯错。然而，命令行中有一种便捷的机制可以帮助解决这个问题。它叫做 Tab 补全。当你开始输入路径时，无论你在命令行中的哪个位置以及正在使用什么命令，你都可以按 Tab 键调出自动补全。如果没有变化，这意味着路径有多种补全可能性。再次按 Tab 键将显示这些可能性。继续输入你的路径，然后再次按 Tab 键以将可能性缩小到正确的那一个。在你的命令行上试一试，看看效果如何。

### 文件

在 Linux 中，一切皆文件。目录、文本文件，甚至你的键盘（但仅限于你的系统可以从中读取的那个）——它们都是文件。你的系统向其写入内容的显示器也是一个文件。这不会对你所做的任何事情产生影响，但你应该记住这一点，以帮助理解 Linux 的工作原理。

### 无扩展名系统

这可能需要一些时间来习惯，但当你逐步深入编程时，它将开始变得合乎逻辑。文件扩展名通常是一组字符，长度为二到四个，位于文件名的末尾的点之后。扩展名告诉你文件类型是什么。一些常见的扩展名包括：

- `file.exe` – 可执行的文件或程序
- `file.txt` – 纯文本文件
- `file.png` – 图像文件
- `file.gif` – 图像文件
- `file.jpg` – 图像文件

在 Windows 等系统中，文件扩展名非常重要，因为系统使用它来确定正在处理的文件类型。Linux 在这方面有所不同，它忽略文件扩展名，而是查看文件内部以确定其类型。例如，你可以取系统中的 `.jpg` 文件，也许是一张你房子的照片，并将其扩展名更改为 `.txt`。Linux 会忽略扩展名，查看文件内部，然后将其作为它实际所属的图像文件进行处理。但并非总是容易确定文件应该被视为什么文件类型，这就是一个名为 `file` 的小命令发挥作用的地方。

```
file [path]
```

现在，你可能会在此时想到，为什么指定的是路径而不是文件？请记住，当在命令行上指定文件或目录时，它实际上是一个路径。此外，目录只不过是特定类型的文件；路径用于将我们带到系统中的特定位置，而那个位置就是一个文件。

### Linux 区分大小写

这一点非常重要，务必记住，这也是新手在使用 Linux 时遇到问题的主要原因之一。许多操作系统不区分大小写，但 Linux 区分，特别是在引用文件时。在 Linux 中，完全可能存在两个文件或目录，其名称仅在大写和小写方面相同，例如：

```
ls Documents
FILE1.txt File1.txt file1.TXT
...
file Documents/file1.txt
Documents/file1.txt: ERROR: cannot open 'file1.txt' (No such file or directory)
```

Linux 将这些视为不同的文件。在处理命令行选项时，你也应该注意大小写。例如，对于 `ls` 命令，有两个选项 – `S` 和 `s` – 它们执行两个不同的功能。最常见的错误之一是在应该使用小写字母的地方输入了大写选项，然后困惑于为什么输出不是你预期的那样。

### 名称中的空格

目录和文件名中有空格并没有什么问题，但你应该小心处理。命令行中的空格用于分隔事物 – 它们是如何确定程序名称并识别命令行参数的。假设你想移动到一个名为 `Holiday Photos` 的目录。这个例子将不起作用：

```
ls Documents
FILE1.txt File1.txt file1.TXT Holiday Photos
...
cd Holiday Photos
bash: cd: Holiday: No such file or directory
```

在这个例子中，`Holiday Photos` 被视为两个独立的命令行参数。命令 `cd` 仅移动到由第一个参数指定的目录。为了解决这个问题并使其正常工作，我们需要让终端知道 `Holiday Photos` 应被视为单个命令行参数。我们有两种同样有效的方法可以做到这一点。

#### 引号

第一种方法是用引号将 `Holiday Photos` 括起来 – 单引号或双引号都可以，只要你使用匹配的一对即可。引号内写入的任何内容都被视为一个单项：

```
cd 'Holiday Photos'
pwd
/home/Simon/Documents/Holiday Photos
```

#### 转义字符

另一种方法是使用一种叫做转义字符的东西。这是一个反斜杠 (`\`)，它的作用是取消下一个字符的特殊含义：

```
cd Holiday\ Photos
pwd
/home/Simon/Documents/Holiday Photos
```

在这个例子中，`Holiday` 和 `Photos` 之间的空格通常具有特殊含义 – 将它们作为独立的命令行参数分开。然而，在前面加上反斜杠取消了该含义。如果你使用 Tab 补全，在遇到目录名称中插入的空格之前，终端会自动为你转义该空格。

### 隐藏文件与目录

Linux 有一种非常棒的机制来告诉你某个目录或文件已被隐藏。如果文件或目录的名称以点 (`.`) 开头，它就被归类为隐藏。隐藏文件或目录不需要任何特殊的命令或操作。你之所以想要隐藏文件或目录可能有多种原因。例如，可能有其他用户隐藏他们的配置文件，以免妨碍你。

要隐藏文件或目录，只需在名称开头添加一个点。如果你已经创建了文件，只需在名称前添加点并重命名即可。同样地，你可以通过从文件或目录名称中移除点来取消隐藏。

需要牢记的一点 – `ls` 命令不会列出任何隐藏目录或文件，除非你通过添加命令行选项 `-a` 来修改命令。只有这样，它才会列出任何隐藏的内容。

```
ls Documents
FILE1.txt File1.txt file1.TXT
...
ls -a Documents
. .. FILE1.txt File1.txt file1.TXT .hidden .file.txt
...
```

Linux 提供了一组页面，告诉你有关每个命令的所有信息 – 它们的作用、工作原理、如何运行以及每个命令接受的命令行参数。对于 Linux 新手来说，其中一些可能有点难以理解，但它们是一致的。一旦你掌握了几页，它们就会开始对你有意义，你会发现它们更容易操作。使用此命令调用手册页：

```
man <command to look up>
```

例如：

```

```

### 搜索

你可以在手册页中搜索特定的关键字。如果你需要提醒某个命令的作用 – 当你知道想要做什么但不确定需要使用哪个命令时，这将很有帮助。你可能需要尝试几次才能找到你要找的东西。你还会发现，你要搜索的特定关键字出现在多个页面中，然后你必须从中筛选以找到正确的那个。语法是：

```
man -k <search term>
```

你还可以在手册页内部进行搜索。当你在一个页面上并且想在该页面上搜索某些内容时，按正斜杠 (`/`) 按钮，然后跟上搜索词。按回车，你的结果将显示出来。如果搜索词有多个实例，你可以按 `n` 键遍历它们。

## 关于运行命令的更多说明

精通 Linux 的很大一部分在于知道正确的命令行选项，以修改命令的行为以满足你的需求。大多数命令都有长格式和简写版本。例如，我们上面讨论过隐藏文件。我们可以使用命令 `-a` 或者使用 `--all` 来列出所有目录条目和隐藏文件。第一个是简写版本，而第二个是长写版本。你可以使用任何版本，因为它们所做的是一样的，所以没有区别。使用长写版本有一个优点，那就是你可能更容易记住你的命令在做什么。然而，简写方法的一个优点是你可以将多个命令链接在一起：

```
pwd
/home/Simon
ls -a
ls --all
ls -alh
```

以长写格式编写的命令行选项以两个短划线（`--`）开头，而简写版本以单个短划线（`-`）开头。单个短划线可以通过将表示这些选项的所有字母组合在一起放在短划线的后面来调用多个选项。

## 创建目录

随着时间的推移，你会积累大量的数据。因此，你应该建立一个目录系统，使用 Linux 的层级结构来组织和管理这些数据。养成为新内容创建新目录并将现有文件存储在正确目录中的习惯。

创建目录很容易；我们简单地使用命令 `mkdir`（make directory 的简写）如下：

```
mkdir [options] <Directory>
```

使用 `mkdir`，提供一个目录名称，它就会被为你创建：

```
pwd
/home/Simon
ls
bin Documents public_html

mkdir linuxtutorialwork
ls
bin Documents linuxtutorialwork public_html
```

在上面的示例中，我们首先检查当前位置，然后运行列表以确切知道该目录包含什么。然后我们运行 `mkdir` 命令并创建一个名为 `linuxtutorialwork` 的目录。记住，当我们在命令行中给出目录名称时，我们是在给出一个路径。

在以下示例中，我们可以看到几种创建目录的方法：

```
mkdir /home/Simon/foo
mkdir ./blah
mkdir ../dir1
mkdir ~/linuxtutorialwork/dir2
```

`mkdir` 有一些非常有用的选项。第一个是 `-p`，它告诉 `mkdir` 命令在必要时创建父目录。第二个是 `-v`，它命令 `mkdir` 告诉我们它正在做什么。

这里是使用 `-p` 选项的示例：

```
mkdir -p linuxtutorialwork/foo/bar
cd linuxtutorialwork/foo/bar
pwd
/home/Simon/linuxtutorialwork/foo/bar
```

现在让我们看看同时使用 `-v` 选项的相同示例：

```
mkdir -pv linuxtutorialwork/foo/bar
mkdir: created directory 'linuxtutorialwork/foo'
mkdir: created directory 'linuxtutorialwork/foo/bar'
cd linuxtutorialwork/foo/bar
pwd
/home/Simon/linuxtutorialwork/foo/bar
```

## 删除目录

创建新目录很容易，删除一个目录也非常容易。请记住，在 Linux 上使用命令行删除某物时没有撤销选项。所以要小心，并养成在删除之前仔细检查一切的习惯。我们用来删除目录的命令是 `rmdir`（remove directory 的简写）：

```
rmdir [options] <Directory>
```

这里有几点需要注意 – 首先，`rmdir` 支持 `-p` 和 `-v` 选项；其次，目录必须在删除之前为空。

```
rmdir linuxtutorialwork/foo/bar
ls linuxtutorialwork/foo
```

## 创建空文件

许多涉及数据操作的命令的一个特性是，如果我们引用一个尚不存在的目录，它们会为我们创建它。我们可以利用这一点使用名为 `touch` 的命令来创建空文件：

```
touch [options] <filename>
```

例如：

```
pwd
/home/Simon/linuxtutorialwork
ls
foo
touch example1
ls
example1 foo
```

`touch` 命令用于修改文件的修改时间和访问时间。它并不总是需要的，但如果你正在测试一个依赖于文件修改时间或文件访问时间的系统，使用它会很有帮助。正如我之前所说，重要的是，如果你接触（touch）一个不存在的文件或目录，它会被为你创建。

我们在 Linux 中做的很多事情不能自动完成，但当你知道某个命令的行为以及系统的一些深层方面时，你可以创造性地使用命令来获得你期望的结果。

## 复制文件或目录

有时你可能想复制一个目录或文件，例如，如果你即将对其进行更改，并希望有一个备份，以便如果事情出错，一切并非全完！用于此操作的命令是 `cp`（copy 的简写）：

```
cp [options] <source> <destination>
```

这个命令有几个选项，我现在将演示其中一个：

```
ls
example1 foo

cp example1 barney

ls
barney example1 foo
```

你注意到源和目标都是路径了吗？这些可以使用相对路径和绝对路径来引用，如下例所示：

```
cp /home/Simon/linuxtutorialwork/example2 example3
cp example2 ../../backups
cp example2 ../../backups/example4
cp /home/Simon/linuxtutorialwork/example2 /otherdir/foo/example5
```

当你使用 `cp` 命令时，它可以是文件的路径或目录的路径。如果它是文件，源的副本将被创建，并将被指定在目标路径中的文件名称命名。如果路径指向一个目录，文件将被复制到该目录中，并保留与源相同的名称。

默认情况下，`cp` 只复制文件。如果我们使用代表递归（Recursive）的选项 `-r`，我们可以复制目录。递归意味着你希望查看一个目录，并希望查看其中包含的所有文件和目录。对于子目录，只需进入它们并重复该命令，依此类推：

```
ls
barney example1 foo
cp foo foo2
cp: omitting directory 'foo'
cp -r foo foo2
ls
barney example1 foo foo2
```

在这个例子中，包含在名为 `foo` 的目录中的文件和目录被复制到 `foo2`。

## 移动文件或目录

如果你想移动一个目录或文件，可以使用代表 move（移动）的命令 `mv`。它的运作方式与 `cp` 几乎相同，但有一个小优点 – 我们不需要使用 `-r` 选项来移动目录：

```
mv [options] <source> <destination>
```

例如：

```
ls
barney example1 foo foo2
mkdir backups
mv foo2 backups/foo3
mv barney backups/
ls
backups example1 foo
```

让我们分解一下。在第 3 行，创建了一个名为 `backups` 的新目录。在第 4 行，名为 `foo2` 的目录被移动到新的 `backups` 目录并重命名为 `foo3`。然后，名为 `barney` 的文件被移动到名为 `backups` 的目录。因为它没有给一个新的目标名称，所以它保留了相同的名称。

## 重命名文件和目录



与 `touch` 命令一样，我们可以以稍微不同的方式使用 `mv` 命令的基本行为，从而得到不同的结果。正如你可以从上例的第 4 行看到的，我们可能需要为目录或文件提供一个新名称，当它被移动时，它会被重命名。如果你指定目标与源具有相同的目录名称，但提供不同的名称，你就使用了 `mv` 命令来更改文件或目录的名称，如下例所示：

```
ls
backups example1 foo
mv foo foo3
ls
backups example1 foo3
cd ..
mkdir linuxtutorialwork/testdir
mv linuxtutorialwork/testdir /home/Simon/linuxtutorialwork/fred
ls
backups example1 foo3 fred
```

所以首先，在第 3 行，使用相对路径将名为 `foo` 的文件重命名为 `foo3`。然后使用 `cd ..` 进入父目录，这样，在下一行中，我们可以表明即使不在其当前目录中，也可以对目录或文件运行命令。在第 8 行，使用源为相对路径，目标为绝对路径，将名为 `testdir` 的目录重命名为 `fred`。

## 删除文件

与使用 `rmdir` 命令类似：当我们删除一个文件时，该操作无法撤销——请务必谨慎操作！我们使用 `rm` 命令（remove 的缩写）来删除或移除文件：

```
rm [选项] <文件>
```

例如：

```
ls
backups example1 foo3 fred
rm example1
ls
backups foo3 fred
```

## 删除非空目录

`rm` 命令有许多选项，会改变其工作方式。

其中一个非常实用的选项是 `-r`，意为递归（recursive），与 `cp` 命令中的用法相同。

当使用 `-r` 选项运行 `rm` 时，你可以删除仍包含文件和目录的目录：

```
ls
backups foo3 fred
rmdir backups
rmdir: failed to remove 'backups': Directory not empty
rm backups
rm: cannot remove 'backups': Is a directory
rm -r backups
ls
foo3 fred
```

与 `-r` 搭配使用的一个良好选项是 `-i`，意为交互模式（interactive）。如果你使用此选项，每当发出删除目录或文件的命令时，在每一项被删除之前，系统都会显示一个提示符——这给了你取消操作的机会，以防你犯了错误。

# 通配符

通配符是构建块，可以让你提出一种模式，从而定义 Linux 上一组目录或文件。请记住，当我们在命令行中引用目录和文件时，我们指的是路径。在这种情况下，我们可以在路径中使用通配符，从而将其转换为一组目录或文件。

基本的通配符包括：

- `*` 代表零个或多个字符。
- `?` 代表单个字符。
- `[]` 代表一个字符范围。

在第一个例子中，我们将使用 `*` 请求列出所有以字母 “b” 开头的条目：

```
pwd
/home/Simon/linuxtutorialwork
ls
barry.txt blah.txt bob example.png firstfile foo1 foo2
foo3 frog.png secondfile thirdfile video.mpeg
ls b*
barry.txt blah.txt bob
```

## 幕后机制

这相当有趣。乍一看，你可能认为 `ls` 命令接收到的参数是 `b*`，并且是它将此转换为显示请求的匹配项。然而，转换是由 `bash` 完成的，`bash` 是负责提供我们命令行界面的程序。当我们输入此命令时，它会发现我们包含了通配符。然后，在执行命令之前，它会用匹配该模式的每个目录或文件替换该模式。我们给出命令

```
ls b*
```

在执行程序之前，它被转换成了

```
ls barry.txt blah.txt bob
```

程序本身不会看到通配符，也不知道它们被使用过。这意味着你可以在命令行中随时使用它们。

# 更多示例

让我们再看看通配符行为的一些更多示例。对于这些示例，假设我们正在一个名为 `linuxtutorialwork` 的目录中工作，该目录包含上述示例中列出的所有文件。我们将继续使用 `ls` 命令，但请注意，通配符可以与任何命令一起使用。

在这个例子中，我要查找所有以 `.txt` 扩展名结尾的文件。我使用了一个绝对路径，但通配符适用于绝对路径和相对路径：

```
ls /home/Simon/linuxtutorialwork/*.txt
barry.txt blah.txt
```

现在，让我们把 `?` 操作符混入其中。在下一个例子中，我想查找第二个字母是 “i” 的所有文件。请注意，我们正在使用多个通配符来构建这个模式：

```
ls ?i*
firstfile video.mpeg
```

或者，我们可以查找扩展名为三个字母的所有文件：

```
ls *.???
barry.txt blah.txt example.png frog.png
```

最后，让我们看看由一对方括号 `[]` 表示的范围操作符。与我们查看的前两个通配符（它们都指定任意字符）不同，此范围操作符会将你限制在特定的子集中。例如，我们可以查找以 “s” 或 “v” 开头的所有文件：

```
ls [sv]*
secondfile video.mpeg
```

使用范围时，我们还可以使用连字符来包含一个集合。在这个例子中，我们想查找文件名中包含数字的所有文件：

```
ls *[0-9]*
foo1 foo2 foo3
```

我们可以使用脱字符 `^` 来反转范围。这意味着它将查找文件名中字符**不是**给定字符之一的文件：

```
ls [^a-k]*
secondfile thirdfile video.mpeg
```

在这个例子中，我们试图查看特定目录中所有文件的所有文件类型：

```
bin: directory
```

将所有类型为 jpg 或 png（图像文件）的文件移动到另一个目录：

在下一个例子中，我们要找出 `bash_history` 文件的大小和修改时间——该文件位于每个用户的 home 目录中，并保存用户曾在命令行中输入的所有命令的历史记录。你还可以使用它来定位隐藏文件：

# 权限

Linux 权限规定了三件事——你可以如何读取、写入和执行一个文件。每个都用单个字母表示：

- `r` 读取 – 你可以查看文件的内容。
- `w` 写入 – 你可以更改文件的内容。
- `x` 执行 – 如果它是程序或脚本，你可以执行或运行该文件。

对于每个文件，我们可以定义三组不同的人群，并为他们指定权限：

- `owner`（所有者） – 拥有该文件的单个人。（通常是创建该文件的人，但某些用户可以将所有权授予他人。）
- `group`（组） – 每个文件都属于一个单一的组。
- `others`（其他人） – 不属于该组或所有者的所有人。

所以，那就是三种权限和三组不同的人群。实际上，这就是你需要了解的所有关于权限的内容，所以让我们看看如何查看和更改它们。

## 查看权限

查看特定文件的权限涉及使用 `ls` 命令的长列表选项：

```
ls -l [路径]
```

例如：

```
ls -l /home/Simon/linuxtutorialwork/frog.png
```

`-rwxr-xr-x 1 harry users 2.7K Jan 4 07:32 /home/Simon/linuxtutorialwork/frog.png`

我们查看输出的前 10 个字符来识别权限：

- 第 1 个字符标识文件类型。短横线 `-` 表示普通文件，而 `d` 表示目录。
- 第 2、3 和 4 个字符标识所有者的具体权限。字母表示权限，短横线 `-` 表示没有权限。示例表明所有者拥有这三种权限。
- 第 5 到第 7 个字符显示组的权限。这里，组成员只允许读取文件。



最后三个字符表示其他人的权限。在示例中，我们可以看到他们有权执行文件，但不能读取或写入。

# 更改权限

要更改目录或文件的权限，我们使用 `chmod` 命令，它代表更改文件模式位（change file mode bits）。这些位是权限的指示器，语法为：

```
chmod [权限] [路径]
```

`chmod` 的权限参数由三个组成部分构成，即：

- 权限是为谁更改的？ – `UGOA` = 用户 (`user`), 组 (`group`), 其他人 (`others`), 所有 (`all`)
- 我们是给予权限还是移除权限？ – 用 `+` 或 `-` 表示
- 正在设置哪个权限？ – 读 (`read`), 写 (`write`), 执行 (`execute`)

看看下面的例子，看是否更清晰。我们授予组执行权限，并移除用户（或所有者）的写权限。

```
ls -l frog.png
-rwxr-x---x 1 harry users 2.7K Jan 4 07:32 frog.png

chmod g+x frog.png

ls -l frog.png
-rwxr-x--x 1 harry users 2.7K Jan 4 07:32 frog.png

chmod u-w frog.png

ls -l frog.png
-r-xr-x-x 1 harry users 2.7K Jan 4 07:32 frog.png
```

除了给予单个权限外，你还可以同时授予多个权限：

```
ls -l frog.png
-rwxr---x 1 harry users 2.7K Jan 4 07:32 frog.png

chmod g+wx frog.png

ls -l frog.png
-rwxrwx-x 1 harry users 2.7K Jan 4 07:32 frog.png

chmod go-x frog.png

ls -l frog.png
-rwxrw--- 1 harry users 2.7K Jan 4 07:32 frog.png
```

文件的所有者可以移除文件自身的读、写和执行权限，这看起来可能有点奇怪，但这样做是有正当理由的。你可能拥有一个包含数据的文件，你希望这些数据不要被意外更改。虽然你可以移除权限，但你无法移除你设置权限的能力，这意味着你始终保留对你拥有的每个文件的完全控制权。

## 设置权限的简写方式

我们在上面查看的权限设置方法并不困难，但如果你需要定期为特定文件应用一组权限，这可能有点繁琐。你可以使用简写方式来完成此操作。要理解简写系统是如何工作的，你首先需要了解八进制数系统的一些基础知识。通常使用的数字系统十进制，是一个以 10 为基数的系统。这意味着它有 10 个符号，从 0 到 9。还有八进制系统，它有 8 个符号，从 0 到 7。现在，因为有三个权限，且每个权限可以是开或关，所以共有 8 种组合。这些数字也可以用二进制表示，二进制只有两个符号，0 和 1。下表展示了我们如何从八进制映射到二进制：

| 八进制 | 二进制 |
| :---- | :---- |
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |

现在，所有的八进制值也可以用三个二进制位来表示，并且每一位 1 和 0 的组合都已包含在内。现在我们有三个权限和三个位。1 代表开，0 代表关，凭借这些，我们可以使用单个八进制数字来表示针对特定人群的一组特定权限。使用三个数字，我们可以为所有者、组和其他人设置权限。让我们看一个示例——不要忘记参考上面的表格来了解其运作方式：

```
ls -l frog.png
-rw-r----x 1 harry users 2.7K Jan 4 07:32 frog.png

chmod 751 frog.png

ls -l frog.png
-rwxr-x--x 1 harry users 2.7K Jan 4 07:32 frog.png

chmod 240 frog.png

ls -l frog.png
--w-r----- 1 harry users 2.7K Jan 4 07:32 frog.png
```

一种方便的方法是记忆针对不同文件类型的常见序列，例如，脚本使用 `750` 和 `755`。

## 目录的权限

我们可以对目录使用相同的权限，但它们的行为会略有不同：

- `r` – 你具有读取目录内容的能力（即执行 `ls` 命令）。
- `w` – 你具有向目录写入的能力（即创建文件和目录）。
- `x` – 你具有进入该目录的能力（即执行 `cd` 命令）。

让我们看一些这些权限如何工作的示例：

```
ls testdir
file1 file2 file3

chmod 400 testdir

ls -ld testdir
-r--------- 1 Simon users 2.7K Jan 4 07:32 testdir

cd testdir
cd: testdir: Permission denied

ls testdir
file1 file2 file3

chmod 100 testdir

ls -ld testdir
---x------- 1 Simon users 2.7K Jan 4 07:32 testdir

cd testdir

ls testdir
ls: cannot open directory testdir/: Permission denied
```

当我们在第 5 行和第 14 行运行 `ls` 时，我们包含了 `-d` 选项，这意味着目录。通常，如果 `ls` 被给予一个目录参数，它会显示给定目录的内容作为输出。然而，在这个示例中，我们要求的是查看给定目录的权限，这就是我们看到的。

权限一开始看起来可能有点令人困惑，但你只需记住，这些特定的权限是针对目录的，而不是包含在其中的文件。例如，如果你有一个没有读取权限的目录，其中包含一个你确实有读取权限的文件，那么只要你确认该文件存在并且知道它的名字，你仍然可以读取该文件：

```
ls -ld testdir
--x------- 1 Simon users 2.7K Jan 4 07:32 testdir

cd testdir

ls testdir
ls: cannot open directory .: Permission denied

cat samplefile.txt
Kyle 20
Stan 11
Kenny 37
```

## root 用户

只有两个人可以更改文件或目录权限：特定目录或文件的所有者以及 `root` 用户。这个超级用户拥有一切的访问权限，并且可以做任何事情。通常，只有系统管理员拥有 `root` 账户的访问权限，他们使用它来维护系统。普通用户通常只能访问他们自己的文件和目录，这些位于他们的主目录中，以及可能几个与其他用户共享或协作的其他目录。这就是系统稳定性和安全性得以维持的方式。

## 基本安全性

你的空间是你的主目录，确保它仍然是你自己的责任在于你。大多数用户倾向于在主目录中为自己赋予完整的读、写和执行权限，而不会给予组或其他人权限。然而，每个人的配置都不同。

为了维护安全性，你应避免授予组或其他人对你主目录的写访问权限。然而，在没有读取权限的情况下能够执行（`x` 权限）有时会很方便。这允许其他人访问你的主目录，但他们将无法看到其中包含的内容。一个很好的例子是当用于个人网页时。系统通常运行 web 服务器，每个用户被分配一小块空间。如果你在家庭目录中放入一个目录并命名为 `public_html`，web 服务器通常能够读取内容并显示它们。然而，由于 web 服务器是一个不同的用户，它将无法访问和读取文件。这就是你可能需要授予家庭目录执行权限的地方，以便 web 服务器能够完成其工作。

# 第 10 章：vi 文本编辑器

在上一章中，我们创建了一些空白文件。在本章中，我们将查看一个帮助我们向这些文件放入内容并允许我们编辑内容的工具。`vi` 是一个不错的文本编辑器，与你过去使用的大多数文本编辑器有所不同。你需要花一些时间来学习它，但一旦学会，你就会发现它是多么强大。

本质上，`vi` 是一个命令行编辑器。如你现在所知，命令行与 Linux GUI 有些不同。它只是一个你输入文本和输出文本的窗口，仅此而已。`vi` 在这些严格限制内工作，使其成为一个极其强大的编辑器。它是一个纯文本编辑器，类似于 Mac 上的 TextEdit 或 Windows 上的记事本。它*不是*文字处理器，但它比上述任一内置编辑器更强大。

你在使用 `vi` 时不需要鼠标；一切都通过键盘完成。

有两种独立的模式——插入模式（输入）和编辑模式。在插入模式下，你输入要放入文件的内容。在编辑模式下，你在文件内移动并编辑内容，例如通过删除、搜索、复制、替换、保存等。人们常犯的一个错误是在未处于编辑模式下就开始输入命令，或者在未处于插入模式下就开始输入内容。开始前请检查一下。话虽如此，如果你犯了这些错误之一，很容易从中恢复。

要运行 `vi` 文本编辑器，你使用单个命令行参数，指定你要编辑的文件名：

```
vi <file>
```



如果你不指定文件名，你可以在 `vi` 内部打开它，但实际上关闭编辑器并重新开始更容易。还要记住，你可以使用相对路径或绝对路径来指定文件名。

首先，打开你的终端，移动到你创建的名为 `linuxtutorialwork` 的目录。我们要创建一些文件，我们可以将它们存储在这里，以便将它们与其他操作分开。

现在我们需要编辑你的第一个文件，请在命令行中输入以下内容：

```
vi firstfile
```

当这条命令被执行时，它会打开该文件；但如果文件不存在，它会在打开之前先创建它。当你进入 `vi` 后，界面可能看起来像这样（具体取决于你正在运行的系统）：

```
~
~
~
~
~
"firstfile" [New File]
```

始终从编辑模式开始。在这种情况下，我们想进入插入模式，因此请按 `i`。当你进入插入模式时，你会从屏幕左下角看到提示。

```
~
~
~
~
~
INSERT --
```

输入一些文本，内容随意，然后按 `Esc`。这将使您返回到编辑模式。

## 保存并退出

有几种方法可以做到这一点；只需选择适合你的方法，但请确保先通过查看屏幕左下角确认你处于编辑模式。如果该处为空，说明没问题；如果显示 `INSERT`，你需要先返回编辑模式。为此，你只需按 `Esc` – 如果你已经在编辑模式，它将不会产生任何影响。然后，要保存并退出，请输入以下其中一项：

- `:wq` + `Enter`

- `ZZ`

大多数 `vi` 命令在输入键序列后会立即执行。如果命令以冒号（`:`）开头，你需要按下 `Enter` 键才能使命令完成。

保存并退出你当前所在的文件。

## 查看文件的其他方法

你可以在 `vi` 中编辑文件，也可以查看文件。不过，还有其他几个命令在这方面表现更好。第一个是 `cat`，全称是 concatenate（串联）。它通常用于将两个文件连接在一起，但也可以用于查看文件：

`cat <file>`

仅使用单个命令行参数运行 `cat` 命令，可以让你在屏幕上看到文件内容，随后是提示符。如果你使用命令行参数运行 `cat` 命令，光标会移动到下一行，但不会发生其他事情。如果你输入一些文本然后按 `Enter`，`cat` 会将你输入的内容镜像显示在屏幕上。你可以通过按 `Ctrl+C` 退出，这是 Linux 中的取消信号。（你可以用它来摆脱你在 Linux 中遇到的大多数麻烦。）

`cat firstfile`

在这里你会看到

你在文件中

输入的任何内容

如果你只需要查看小文件，这是一个很棒的命令，但当文件较大时，内容会在屏幕上飞速滚动，你只能查看最后一页。要查看较大的文件，我们使用另一个名为 `less` 的命令：

`less <file>`

`less` 命令允许你使用箭头键在文件内容中移动。你可以用空格键翻到下一页，或者按 `b` 返回上一页。完成后，只需按 `q` 退出即可。

请尝试对你创建的文件使用这两个命令，看看你的使用情况如何。

## 在 vi 中导航文件

现在，回到那个文件并输入更多更多内容。在插入模式下，你可以使用箭头键进行移动。再输入两段文字，然后按 `Esc` 以返回编辑模式。

以下列表展示了可用于遍历文件的一些命令；请多加练习并掌握它们的工作方式。

- 箭头键 – 移动光标

- `j`, `k`, `h`, `l` – 向下、向上、向左和向右移动光标（类似于箭头键）

## 删除内容

你现在已经知道在 `vi` 中移动的一些方法。删除的工作方式类似；有多种不同的删除命令可用于定义你要删除的内容。下面的列表展示了一些删除方法。请多加练习，但务必先阅读关于如何撤销删除的部分：

- `x` – 删除单个字符

- `nx` – 删除 `n` 个字符（例如，`5x` 删除五个字符）

- `dd` – 删除当前行

- `dn` – `d` 后跟一个移动命令。删除到移动命令会将你带到的位置（例如，`d5w` 表示删除 5 个单词）。

### 撤销

在 `vi` 中撤销删除是一个相当简单的过程；只需使用字母 `u` 即可。

- `u` – 撤销最后一个操作（你可以继续按 `u` 来持续撤销）

- `U`（注意：大写）– 撤销对当前行的所有更改
