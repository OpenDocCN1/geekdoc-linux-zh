# sort & uniq

sort sorts
its input
$n sort names.txt
the default sort is alphabetical.

sort -n numeric sort
| 'sort -order' | 'sort -n' order |
| 12 | 12 |
| 15000 | 48 |
| 48 | 96 |
| 6020 | 6020 |
| 96 | 15000 |

sort -h: human sort
| 'sort -n' order | 'sort -h' order |
| 15 6 | 45 K |
| 30 M | 30 M |
| 45 K | 15 G |
| 200 G | 200 G |

useful example:
du-sh * sort -h
