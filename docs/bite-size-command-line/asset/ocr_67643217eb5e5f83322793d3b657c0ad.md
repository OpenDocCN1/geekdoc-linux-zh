# head & tail

# head

shows you the first+
10 lines of a file

if you pipe a program's output
to head, the program will
stop after printing 10 lines
(it gets sent SIGPIPE)

# tail

tail shows the last 10 lines!

```
tail -f FILE
```

will follow:

print any new lines added to
t end of FILE. Super useful
for log files!

# -n NUM

-n NUM (either head or tail)
will change the #n lines shown

head -n -NUM show all
tail -n +NUM but the
last / first
NUM lines

# -c NUM

show the first /last NUM
bytes of the file

head -c k

will show the first
1024 bytes

# tail --retry

keep trying to open
file if it's inaccessible

# tail --pid PID

stop when process PID
stops running (with -f)

# tail --follow=name

Usually tail -f will follow
a file descriptor.

tail --follow=name FILENAME
will keep following the same
name, eg if the file
descriptor is rotated.
