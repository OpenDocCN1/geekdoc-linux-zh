# 14

ps
ps shows which processes are running
I usually run ps like this:

wchan
is for wide. ps auxwww
will show all the command
line args for each process

you can choose which columns
to show with ps (ps -eo ...)
One cool column is 'wchan' which
tells you the name of the
kernel function if the process
is sleeping
try it:

```
$ ps aux
a+ttx
u means include together
username column show all
process
ps -ef works too)
```

e
is for environment. ps auxe
will show the environment vars:

```
$ ps -eo user,pid,wchan,cmd
```

# ★ process state ★

f
is for "forest" ツ. ps auxf
Will show you an ASCII art
process tree:

ps has 3 different sets
of command line arguments 💔

Here's what the letters in
's STATE column mean:

+   1. UNIX (1 dash)
2. BSD (no dash)
3. GNU (2 dashes)

+   R: running
S/D: asleep
Z: zombie
I: multithreaded
t+: in the foreground

you can write monotrites like:
$ ps f -f
full format
(UNIX)

pstree can display
a process tree too
