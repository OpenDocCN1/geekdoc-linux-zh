Each time the system boots, the rawdevices service checks the /etc/sysconfig/rawdevices file and makes any necessary changes. If you have added new hardware that has caused the device names to change, you must make these changes in the /etc/sysconfig/rawdevices file before you attempt to start up Oracle.

> **CAUTION**
> *Be careful of device changes. Starting up Oracle with the incorrect raw devices can cause irreparable damages to your database. All data should be backed up before attempting to add any new devices to the system.*

The /etc/sysconfig/rawdevices file is designed to help you avoid problems that could harm your system.

# **The /etc/sysconfig/rawdevices File**

The /etc/sysconfig/rawdevices file is used to associate raw devices such as /dev/raw/raw1, /dev/raw/raw2, and so on with physical devices such as /dev/sd1, /dev/sdb2, and their siblings. The /etc/sysconfig/rawdevices file has the following format:

```
`<rawdev> <major> <minor>`
`<rawdev> <blockdev>`
```

Either format is acceptable. The major device number indicates the device type (SCSI disk drive in our example), while the minor number represents the partition. There are eight major numbers allocated to SCSI devices. These numbers are 8, 65, 66, 67, 68, 69, 70, and 71. There are 255 minor devices allocated to partitions on these SCSI devices, and each disk drive can have 15 partitions. The first 255 devices have major number 8, the next 255 devices use major number 65, and so forth. The following is a listing of some SCSI devices. Note the major and minor device numbers.

`0 brw-rw---- 1 root disk 8, 0 Mar 19 2002 /dev/sda1`

`0 brw-rw---- 1 root disk 8, 3 Mar 19 2002 /dev/sda3`
`0 brw-rw---- 1 root disk 8, 4 Mar 19 2002 /dev/sda4`
