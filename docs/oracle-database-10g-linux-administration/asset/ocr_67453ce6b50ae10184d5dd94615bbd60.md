# ### sar

The System Activity Reporter (sar) is useful for monitoring the performance of the system in general. With sar, you can monitor CPU utilization, memory, and network interfaces. The one thing that sar is not particularly good at is monitoring the I/O subsystem. There are many different options available to sar, depending on what you want to monitor on the system, and how.

Running sar with no parameters displays the CPU utilization for the last 24 hours, as shown here:
