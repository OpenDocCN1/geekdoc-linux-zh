Statspack reports are run on two different snapshots. To find what snapshots are available, use the following query:

+   - Connect into SQLPLUS as perfstat.
+       - sqlplus /nolog
+       - SQL> CONNECT perfstat/perfstat
+       - SQL> Variable snap number;
+       - SQL> Begin :snap := statspack.snap; end;
+       - SQL> /
+       - SQL> print snap;

This will provide a list of Statspack IDs that can be used to create Statspack reports. Creating Statspack reports is done by using the spreport procedure. The spreport function is also run from within sqlplus as the perfstat user. Spreport will ask for beginning and ending snapshots, and it will create a report from the differences in those snapshots. Running spreport is shown here:

+   - Connect into SQLPLUS as perfstat.
+       - Sqlplus /nolog
+       - SQL> CONNECT perfstat/perfstat
+       - SQL> @?/rdbms/admin/spreport

You are prompted for beginning and ending snapshots. The report is saved for you, as shown here:
