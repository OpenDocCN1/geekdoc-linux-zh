# ## Understanding the Explain Plan

Review one of the explain plans shown (Figures 16-2 or 16-3). Oracle processes the most-indented items first. Each step of the explain plan illustrates how Oracle will process the rows or functions (such as a sort) on behalf of the SQL code, and each step of the explain plan has a result set that gets passed to the ID that relates to the Parent_ID of the particular step. The show_explain_table in Listing 16-2 allows the user to see the relationships from one step to another. If there is more than one table in the FROM clause, then there will be join conditions that will be processed first. Oracle will process two tables at a time, creating a result set and then bringing in each additional table from the FROM clause (creating new result sets that are passed to the next step) until all the tables have been processed.
