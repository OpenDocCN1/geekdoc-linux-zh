# ## Summary

This chapter introduced the reader to SQL statement tuning. Execution plans or explain plans are used to visualize exactly how Oracle 10g interpreted the SQL and how it will retrieve the data for the SQL. This chapter also discussed how to interpret these plans, and how to control them using both hints and coding techniques. The chapter then concluded with several different methods for finding problem SQL.
