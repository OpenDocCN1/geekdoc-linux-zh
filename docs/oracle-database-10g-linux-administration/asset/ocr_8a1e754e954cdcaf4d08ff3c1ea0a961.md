# FIGURE 18-1. Enterprise Manager Application Server Control

The following tables provide an exhaustive list of DCM line commands grouped by command type and their use:

| DCMCTL Shell Commands | Usage |
|---|---|
| !! | Repeats last command |
| shell | Invokes dcmctl shell |
| echo | Places string to output |
| setLogLevel | Sets level of logging |
| exit | Exits shell |
| quit | Quits shell |
