# Recompiling Invalid PL/SQL Modules

Oracle recommends that the SQL script utlpr.sql be run in order to recompile all PL/SQL modules that might be invalid. This can be accomplished by setting your Oracle environment and connecting into SQL*Plus, as shown next:

```
[oracle@ptc6 oracle]$ . /usr/local/bin/oraenv
ORACLE_SID = [orac]?  
[oracle@ptc6 oracle]$ sqlplus "/ as sysdba"
```

Once you have connected into the Oracle Database 10g server, run the utlpr.sql script (assuming the database server is up and running).
