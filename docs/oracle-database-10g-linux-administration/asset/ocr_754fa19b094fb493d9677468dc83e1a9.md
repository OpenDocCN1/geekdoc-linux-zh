# # Understanding the Optimizer Decision Process

The CBO makes its decisions based on collected object statistics and machine load. These object statistics include histograms, block count, row counts, fragmentation, and so on. Statistics on indexes include the clustering factor (the relationship of how many different data blocks each leaf block points to), the granularity of the key, type of index, and so on.
