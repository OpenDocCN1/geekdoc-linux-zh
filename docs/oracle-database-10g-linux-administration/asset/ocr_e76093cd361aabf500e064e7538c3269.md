FIGURE 6-2. The Oracle Universal Installer

A number of steps are needed to install the Oracle software on your system. The screens that appear will prompt you to make various decisions. The following are a few things you should be aware of during the installation process:

+   The operating system group should be picked up as install.

+   In the file locations screen

+   The source file location should be in the stage directory underneath the staging directory you created. In our example, the source path should be /oracle_stage/db.Disk1/stage/products.xml.

+   The path should point to a subdirectory under oracle_base. This will look something like /opt/oracle/product/10.1.0/db_1 where oracle_base is /opt/oracle.

+   The product prerequisite check should be successfully completed before continuing. If there are any errors, correct them and retry the test.

+   Set the Oracle database name and SID correctly. It should have picked up the oracle_sid from the environment variable.
