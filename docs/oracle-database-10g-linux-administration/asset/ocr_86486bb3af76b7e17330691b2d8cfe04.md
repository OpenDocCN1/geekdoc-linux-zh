2.  Once you have invoked the RMAN utility, you must register the target database in the recovery catalog so that it can be backed up. This is done via the REGISTER DATABASE command from within RMAN.
RMAN> REGISTER DATABASE;

starting full resync of recovery catalog
full resync complete

4.  Once the catalog is created and the database is registered, you are ready to begin backing up this database. Before you begin the backup operation, you can specify the channel, which tells RMAN where you want the backup to go to. In order to set RMAN to back up to a specific directory and increment the filename, use the following command:
RMAN> CONFIGURE CHANNEL DEVICE TYPE DISK FORMAT
'/u01/oracle/backup/ora_df$t_s%v_s%';
