as well. The number of semaphores is defined by the following Linux configuration parameters:

Parameter | Value | Description
semmsl | 250 | Max number of semaphores per ID
semmns | 32000 | Max number of semaphores in the system (must be equal to or greater than semmni * sems1)
sempm | 100 | Max number of operations per semaphore call
semmni | 128 | Max number of semaphore identifiers
file-max | 65536 | The maximum number of file handles
ip_local_port_range | 1024 65000 | Range of port numbers available to a program

Whether or not you need to increase the number of semaphores depends on your configuration. For a normal-sized system, these parameters are a good start.
