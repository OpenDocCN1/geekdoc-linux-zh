# ### Data Guard Broker

The Data Guard Broker is the set of utilities and services that manage Data Guard. Included in the Data Guard Broker are both a GUI interface using Oracle Enterprise Manager and a command-line interface (CLI). The Data Guard Broker is used to set up Data Guard, to manage the configuration, and to monitor Data Guard. As I have mentioned throughout the book, I prefer to use the CLI so that I can script and document my actions.

# ## Physical Standby Database

The *physical* standby database stays constantly in recovery mode and serves the purpose of preparing for a failover operation. With a physical standby database, the primary and failover systems are identical, and the databases contain exactly the same data on a block-by-block basis.

The physical standby database stays synchronized with the primary server by remaining constantly in recovery mode. As new redo information is generated and moved to the standby server via log transport services, it is constantly being applied to the standby server via log apply services.
