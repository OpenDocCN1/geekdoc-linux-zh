# What Is Clustering?

In the most simple terms, a cluster is a group of independent servers that function as a single system. It can also be defined as multiple systems performing a single function, a black box.

# Cluster Terminology

Let’s go over some cluster terminology. A server that is connected to the cluster is known as a *node* in the cluster. If a node is currently processing data for the cluster, it is *active*. If a node is waiting for a failover before it starts working, it is a *passive* node in the cluster. A resource or a node is placed in a failed state after an unsuccessful attempt to bring it online.
