The key columns to look up the $QL text of any $QL statement are ADDRESS and HASH_VALUE. Use both of these fields to uniquely identify the exact $QL required. Scripts in Listings 16-6 and 16-7 return both the ADDRESS and HASH_VALUE for $QL causing the particular issues being identified. These scripts can easily be modified to include the actual $QL text. Listings 16-4 and 16-5 are two additional VS tables that display the $QL text. Listing 16-4 shows the columns available in $QLTEXT and Figure 16-8 shows the columns available in V_$SQLTEXT_WITH_NEWLINES. This VS table formats the $QL much nicer for display on character-mode displays or in reports. Both V_$SQLAREA and V_$QLTEXT have the $QL statement in one contiguous string.
