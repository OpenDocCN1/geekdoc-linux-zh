The request string in the GET method is limited to 1024 characters so is unsuitable for passing lots of key=value pairs.

![](bbox=[0.1, 0.66, 0.25, 0.78])

The values appended to the URL, are visible in the browser address field of the response, so the GET method should not be used to send passwords or other sensitive data values to the web server.
