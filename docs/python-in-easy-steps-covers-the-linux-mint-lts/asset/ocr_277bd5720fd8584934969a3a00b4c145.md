The % modulo operator will divide the first given number by the second given number and return the remainder of the operation. This is useful to determine if a number has an odd or even value.

The // floor division operator performs just like the / division operator, but truncates the result at the decimal point – removing any floating-point value.

The ** exponent operator returns the result of the first operand raised to the power of the second operand.

+   Start a new Python script by initializing two variables with integer values

```
a = 8
b = 2
```

```

+   Display the result of dividing the variable values both with and without the floating-point value

```

print(‘Floor Division:\t’, a, ‘//’, b, ‘=’, a // b)
```

+   Next, display the remainder after dividing the values

```
print(‘Modulo:\t’, a, ‘%’, b, ‘=’, a % b)
```

+   Finally, display the result of raising the first operand to the power of the second operand

```
