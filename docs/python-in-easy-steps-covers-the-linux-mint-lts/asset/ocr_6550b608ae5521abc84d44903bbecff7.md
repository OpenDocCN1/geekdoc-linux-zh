+   1. Start a new Python program by making GUI features available and messagebox features available as a short alias
+      ```
+      from tkinter import *
+      import tkinter.messagebox as box
+      ```

![](bbox=[0.11, 0.22, 0.2, 0.32])

+   2. Next, create a window object and specify a title
+      ```
+      window = Tk()
+      window.title( 'Listbox Example' )
+      ```

+   3. Now, create a frame to contain widgets
+      ```
+      frame = Frame( window )
+      ```

+   4. Create a listbox widget offering three list items
+      ```
+      listbox = Listbox( frame )
+      listbox.insert( 1 , 'HTML5 in easy steps' )
+      listbox.insert( 2 , 'CSS3 in easy steps' )
+      listbox.insert( 3 , 'JavaScript in easy steps' )
+      ```

+   5. Next, add a function to display a listbox selection
+      ```
+      def dialog( ) :
+            box.showinfo( 'Selection' , 'Your Choice: ' + \
+            listbox.get( listbox.curselection( ) ) )
+      ```

+   6. Now, create a button to call the function when clicked
+      ```
+      btn = Button( frame , text = 'Choose' , command = dialog )
+      ```

+   7. Then, add the button and listbox to the frame at set sides
+      ```
+      btn.pack( side = RIGHT , padx = 5 )
+      listbox.pack( side = LEFT )
+      frame.pack( padx = 30 , pady = 30 )
+      ```

+   8. Finally, add the loop to capture this window's events
+      ```
+      window.mainloop( )
+      ```
