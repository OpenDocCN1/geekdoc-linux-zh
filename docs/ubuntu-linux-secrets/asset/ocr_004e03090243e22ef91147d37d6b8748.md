Developers often give include files the `.inc` extension to indicate that they are not complete web pages on their own. You can also attach the `.php` file extension to indicate that the file contains PHP code. It’s not necessary to do this because the server doesn’t process the actual include file itself. Instead, it inserts it into the main PHP file.

+   2. **Create another file in the same folder and call it `main.php`.** Type the following code and text into it:
+   
+   ```html
+   <html>
+   <body>
+   <?php include("header.inc.php"); ?>
+   <br><br>
+   <h2>This is the body of the main page</h2>
+   </body>
+   </html>
+   ```

+   3. **Open your browser and view the URL** `http://localhost/main.php`.
