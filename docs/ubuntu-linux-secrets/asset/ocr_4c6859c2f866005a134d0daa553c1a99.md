The Dwell Click is ingenious. When you stop the mouse pointer, the mouse pointer turns into a crosshair. The click event that GNOME sends to the desktop (or the application) depends on how you move the mouse. The possible moves are shown in Table 4-6.

**Table 4-6: Dwell Click Moves**

| Action | Result |
|---|---|
| Move left | Single primary click (a left-click on a right-handed mouse) |
| Move right | Single secondary click (a right-click on a right-handed mouse) |
| Move up | Double primary click |
| Move down | Click and drag the item |

This feature allows you to control the mouse clicking without pressing any buttons.
