After assigning the new rule a unique name, you select filters to apply to the messages. The filter can be applied against message headers, such as sender, recipient, subject, date sent, date received, and the body of the message, or against features of the message, such as the message size and status.

You can add as many filters in a single rule as are necessary to uniquely identify messages for the rule. You can also set how filters are combined to satisfy the rule:

+   - All filters must match.
+   - At least one filter matches.

Once you define the filter(s) used, you must define the action the rule takes with the message. Some of the more popular actions you can take are

+   - Move message to a specific folder.
+   - Place the message in the inbox but put a copy in a specific folder.
+   - Delete the message.
+   - Assign a color to the message to make it stand out in the message list.
