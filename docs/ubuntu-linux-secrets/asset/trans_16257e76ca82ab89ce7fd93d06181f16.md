4. 在main方法部分输入应用程序代码。代码视图窗口会显示Main.java代码文件，其中包含应用程序的main类方法。向下滚动到main方法，输入以下代码：

```
int number = (int)(Math.random() * 10);
int factorial = 1;
int counter;

for(counter = 1; counter <= number; counter++)
{
    factorial = factorial * counter;
}
System.out.println("The factorial of "
    + number
    + " is "
    + factorial);
```

当你输入代码时，请注意NetBeans会自动为程序文本进行颜色编码。颜色编码有助于你在编译程序前发现任何拼写错误或编码失误。另外，在输入Math类后面的句点时暂停一下，NetBeans会自动列出Math类中所有可用的方法，让你可以选择所需的方法！完成的代码应如图28-5所示。

- 5. 保存文件，并通过选择工具栏上的“构建主项目”图标（锤子）来构建新代码。

当应用程序运行时，NetBeans会在NetBeans窗口底部打开一个文本输出窗口，用于显示程序输出。

NetBeans还提供了完整的调试功能，允许你通过简单点击代码行左侧页边距来设置断点。要启动调试器，只需点击工具栏上的“调试主项目”图标（带绿色箭头的列表）即可。

> 秘诀
> 
> 完成项目后，NetBeans会创建一个jar文件，其中包含应用程序所需的所有类文件。但若要找到这个jar文件，你需要翻阅一下查找。如果你使用了项目的默认位置，Factorial jar文件将位于你主目录下的NetBeansProjects文件夹中，在Factorial文件夹下，一个名为dist的文件夹里。
> 
> 要从此jar文件运行Factorial类，可以使用Java程序的-jar选项：

```
rich@testbox:~/NetBeansProjects/Factorial/dist$ java -jar Factorial.jar
The factorial of 3 is 6
rich@testbox:~/NetBeansProjects/Factorial/dist$
```

## Eclipse

Eclipse IDE是一个开源图形化环境，用于创建和调试各种类型的程序代码，包括Java代码。由于其多才多艺，安装Eclipse需要几个不同的软件包。幸运的是，Synaptic包管理器可以为我们搞定这一切。

只需启动Synaptic包管理器（通过选择“系统”→“管理”→“Synaptic包管理器”），然后搜索eclipse-jdt包。将该包标记为安装，Synaptic会自动安装开发Java应用程序所需的一切（包括OpenJDK包，如果尚未安装的话）。

Eclipse包不受Canonical支持，因此不会出现在标准Ubuntu仓库中。你必须确保在Synaptic包管理器配置中选中了universe仓库，才能下载Eclipse包。

要做到这一点，请启动Synaptic包管理器，然后从菜单中选择“设置”。在“Ubuntu软件”选项卡部分，确保选中“社区维护的开源软件（universe）”复选框。然后点击主页上的“重新加载”工具栏按钮，重新加载仓库库信息。

一旦安装了Eclipse包，它也会出现在“编程”菜单区域。按照以下步骤使用Eclipse IDE创建Java应用程序：
