After that we discussed the Totem movie player. The Totem movie player can play video files, but only if it contains the proper codec program for the selected video file format. By default Ubuntu includes the codec for the OGG open video format. If you select another video file format Ubuntu will ask whether you want to search for the proper codec. If your workstation is connected to the Internet (and it's legal in your area to install it) you can select the appropriate codec file to install.

Besides allowing you to view video files, Ubuntu provides support for viewing files on the Internet. The Firefox web browser provides some basic support for viewing video files by utilizing plug-ins. Again, there are restrictions on which plug-ins Ubuntu supports by default. You can install additional plug-ins via the Synaptic Package Manager or directly from the Mozilla plug-in repository web site. Mozilla also provides Firefox extensions, which add features to Firefox, including the ability to capture video from web sites.

Finally, the chapter discussed the Kino video-editing tool. Although not included in the default Ubuntu installation, Kino can easily be added if your workstation is connected to the Internet. Kino allows you to combine video clips and edit out pieces of video clips to create a single video.
