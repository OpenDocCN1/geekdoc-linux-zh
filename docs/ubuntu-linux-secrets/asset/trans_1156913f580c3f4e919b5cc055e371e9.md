## 惯例和功能

本书中存在许多不同的组织和排版功能，旨在帮助你充分利用信息。

### 秘诀

当作者想要提供额外信息来帮助你充分利用 Ubuntu 系统时，这些信息将以 Secrets 侧边栏的形式出现，与主要章节内容分开。

![](img/39e65eeb4f54001ede08c6114ae3cc6c_28_0.png)

Secrets 侧边栏中的信息很重要，并以特殊图标单独段落的形式突出显示。 Secrets 提供了有关需要注意事项的额外信息、如何更好地使用功能的提示，或有助于理解主题的背景信息。

### 最低要求

要充分利用 Ubuntu 工作站软件，你必须拥有一台至少配备 700-MHz 处理器、384 MB 系统内存（RAM）、8 GB 磁盘空间以及能够支持至少 1024 × 768 分辨率的显卡的 PC。 如果计划处理音频和视频，配备声卡会有所帮助；如果计划与本地网络或互联网交互，则配备网卡会有所帮助。

### 从这里开始

一旦你完成了《Ubuntu Linux Secrets》，你将顺利成为 Ubuntu Linux 大师。 在不断变化的 Linux 世界中，保持与新发展的联系始终是一个好主意。 Ubuntu Linux 发行版每 6 个月发布一个新版本，增加新功能并移除一些旧功能。 为了保持你对 Ubuntu 的知识更新，保持充分了解非常重要。 在网上找一个好的 Linux 论坛并关注 Linux 世界的动态。 有许多热门网站，如 Slashdot 和 Distrowatch，提供有关 Linux 进展的最新信息。 关注 Ubuntu 发行版网站本身也是一个好主意。 每个新版本都会经历一系列 beta 版本，这是在下一个版本发布前了解新功能的好方法。
