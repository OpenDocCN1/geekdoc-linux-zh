> **Secret**
> 
> The CUPS server uses a self-signed encryption certificate for HTTPS traffic. Most modern browsers will produce a warning about accessing a site using a self-signed certificate. Because you know that this is your own server, it’s perfectly okay to ignore the warnings and continue accessing the CUPS server web interface.
