> **Secret**
> 
> Testing for string inequality is where things get tricky. There are two problems that often plague shell programmers when trying to use the greater than or less than features of the test command:
> 
> - The greater-than and less-than symbols must be avoided, or the shell will use them as redirection symbols, with the string values as filenames.
> - The greater-than and less-than order is not the same as that used with the sort command.
> 
> If you forget to place a backslash character in front of the greater-than and less-than symbols, the shell interprets them as redirection symbols. Capitalized letters appear less than lowercase letters in the test command; however, when you put the same strings in a file and use the sort command, the lowercase letters appear first.
> 
> Also, notice that the test command uses the standard mathematical comparison symbols for string comparisons, and text codes for numerical comparisons. This is a subtle feature that many programmers manage to reverse.
