# Local Only

The local-only option for the Postfix configuration allows sending mail only to other user accounts on the Ubuntu server. The Ubuntu server can't forward email to external email addresses, nor does it accept or retrieve any mail from external hosts.

This is a safe setting to use if you want to support internal email on your server without using it as a public email server. It's usually a good idea to support local email, because many programs use email to contact the system administrator if something goes wrong.

> Secret
> When setting up the local-only email option, make sure that you redirect mail destined for the root user account to the normal user account of the administrator. This setting allows you to view any critical system error messages that are generated by applications or by the Ubuntu system itself.
