The bash shell mathematical operators only support integer arithmetic. This is a huge limitation if you’re trying to do any sort of real-world mathematical calculations.

# A Floating-Point Solution

There have been several solutions for overcoming the bash integer limitation. The most popular solution uses the built-in bash calculator (called bc).

# The Basics of bc

The bash calculator is actually a programming language that allows you to enter floating-point expressions at a command line, interpret the expressions, calculate them, and return the result. The bash calculator recognizes:

+   - Numbers (both integer and floating-point)
+   - Variables (both simple variables and arrays)
+   - Comments (lines starting with a pound sign, or the C language /* */ pair)
+   - Expressions
