+   - **Microsoft Excel 95 (.xls) format:** and even the older Excel Spreadsheet format
+   - **Microsoft Excel 5.0 (.xls) format:** and older Excel spreadsheet formats
+   - **StarCalc 3.0–5.0 (.sdc) format:** Sun's StarOffice spreadsheet format (a close cousin of the OpenOffice.org suite)
+   - **SYLK (.slk) format:** the symbolic link format, used to exchange data between spreadsheets and other applications, such as databases
+   - **Text CSV (.csv) format:** the comma-separated text values, often used to export data to databases
+   - **HTML (.html) format:** formats spreadsheet data as an HTML web page
+   - **Microsoft Excel 2003 (.xml) format:** a standard proposed by Microsoft for using the Internet XML standard for defining spreadsheet data

Just like with Writer, the advantage to using Calc is its versatility. You can work with just about all of the popular spreadsheet types, as well as save your spreadsheets as those types.

> **Secret**
> 
> Also, similar to Writer, the Calc standard toolbar provides a button for you to export the spreadsheet directly as a PDF document. This is a great feature for creating reports directly from your spreadsheets.
