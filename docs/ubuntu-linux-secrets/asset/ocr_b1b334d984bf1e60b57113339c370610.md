# Installing New Packages

The Add/Remove Applications tool is a great feature in Ubuntu, but it has its limitations. It adds and removes only workstation application software packages. The Ubuntu distribution includes many more packages for server programs, utilities, drivers, and code libraries that cannot be managed by the Add/Remove Applications tool. Fortunately, Ubuntu also includes a program for handling the details of package management—the Synaptic Package Manager.

This section describes how to use the Synaptic Package Manager to install and remove individual packages on your Ubuntu workstation.
