# The Totem Movie Player

The default video-file viewer in Ubuntu is Totem. You can start Totem by double-clicking a saved video file, or you can launch it from the Panel menu by choosing Applications ▸ Sound & Video ▸ Movie Player.

> You can also start the Totem movie player from the command line in a Terminal session (see Chapter 19, "The Ubuntu Command Line"). Just use the command totem.

Licensing restrictions limit the types of files that the default Totem installation can play. If you select a video file in a format that Ubuntu doesn’t contain the codec for, Ubuntu will display a message, shown in Figure 12-1.

If your workstation is connected to the Internet, Ubuntu will attempt to locate the proper codec in a repository. It displays all codecs that it finds that can process the selected video file format.
