

替换命令允许你快速将文本中的一个词替换（substitute）为另一个词。要使用替换命令，你必须处于命令行模式。替换命令的格式为

```
:s/old/new/
```

vim编辑器会跳转到文本old第一次出现的位置，并将其替换为文本new。你可以对替换命令做一些修改，以替换文本的多次出现：

- :s/old/new/g 替换一行中所有出现的old。
- :.,$s/old/new/g 替换两个行号之间所有出现的old。
- :%s/old/new/g 替换整个文件中所有出现的old。
- :%s/old/new/gc 替换整个文件中所有出现的old，但每次出现都会提示。

正如你所看到的，作为一个命令行文本编辑器，vim包含了不少高级功能。由于每个UNIX和Linux发行版都包含它，所以了解vim编辑器的基本知识是个好主意，这样无论你身处何地或手头有什么工具，你都能编辑文件。

## emacs编辑器

emacs编辑器是一个极其流行的编辑器，在UNIX出现之前就已存在。开发者们非常喜欢它，因此将其移植到UNIX环境中，现在又移植到了Linux环境。emacs编辑器最初是一个类似vi的控制台编辑器，但后来进入了图形世界。

emacs编辑器仍然提供原始的Console模式编辑器，但现在它也能够使用图形化的X Windows，从而在图形环境中编辑文本。通常，当你从命令行启动emacs编辑器时，它会判断你是否拥有可用的X Window会话。如果有，它将启动为图形模式；如果没有，它将启动为控制台模式。

虽然emacs编辑器默认未安装在Ubuntu中，但你可以通过Ubuntu的添加/删除功能（参见第13章“软件安装与更新”）搜索emacs22，轻松将其添加到你的文本编辑工具箱中。你也可以在全部和附件类别中找到它。

在安装Ubuntu的emacs22软件包并重启系统后，你会在应用程序菜单的附件部分看到两个新条目：

- emacs22 (client)
- emacs22 (X11)

emacs22 client条目会在系统上运行emacs服务器时启动一个emacs会话。由于我们没有安装emacs服务器，这个条目目前没什么用。

emacs22 X11条目会启动一个基于窗口的emacs会话供你使用。或者，你也可以在Ubuntu命令行提示符下使用基于控制台的emacs会话。

本节将介绍控制台模式和图形模式的emacs编辑器，以便你在需要（或想要）时知道如何使用其中任何一种。

## 在控制台中使用emacs

emacs的控制台模式版本是另一种使用大量按键命令来执行编辑功能的编辑器。emacs编辑器使用涉及Control键（PC键盘上的Ctrl键）和Meta键的组合键。在大多数PC终端模拟器软件包中，Meta键被映射到PC的Alt键。官方emacs文档将Ctrl键缩写为C-，Meta键缩写为M-，所以要输入Ctrl-x组合键，文档中显示为C-x。我在这里也采用同样的方式，以免使你混淆。

![](img/39e65eeb4f54001ede08c6114ae3cc6c_177_0.png)

> **秘诀**
> 
> 如果你尝试在Ubuntu终端应用程序中将Alt键用作emacs的Meta键，你会遇到终端菜单键的问题（例如，Alt-f是emacs命令，但它同时也会在终端中打开“文件”菜单）。

要避免此问题，你可以在emacs中使用Esc键作为Meta键。唯一不同的是，你不必按住Esc键作为组合键。相反，你先按下并释放Esc键，然后再按所需的键来执行功能。

## emacs基础

要启动基于控制台的emacs版本，请打开一个终端会话，并在命令提示符下输入

```bash
$ emacs -nw mytest.txt
```
