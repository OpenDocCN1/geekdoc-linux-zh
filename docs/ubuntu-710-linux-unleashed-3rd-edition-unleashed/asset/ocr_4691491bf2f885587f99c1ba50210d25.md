In the Admin page, click the Add Printer button and then enter a printer name in the Name field (such as 1p), a physical location of the printer in the Location field, and a short note about the printer (such as its type) in the Description field. Figure 16.10 shows a sample entry for an HP 2100 LaserJet.

Click the Continue button. You can then select the type of printer access (local, remote, serial port, or Internet) in the Device page, as shown in Figure 16.11. For example, to configure printing to a local printer, select LPT1 or, for a remote printer, select the LPD/LPR Host or Printer entry.
