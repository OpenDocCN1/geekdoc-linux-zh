In addition to the information given about each connected user, ftpwho also displays the total number of users connected out of any maximum that might have been set in the ftpassess file. This information can be used to monitor the use of your FTP server.

You can pass one parameter to ftpwho. (You can find the parameter by using the ftpwho - help command.) The single parameter you can pass to ftpwho is -V. This parameter prints out version and licensing information for wu-ftpd, as shown here:

```
# ftpwho
Service class all:
10447 ? SN 0:00 ftpd: localhost: anonymous/winky@disney.com: IDLE
1 users (no maximum)
```
