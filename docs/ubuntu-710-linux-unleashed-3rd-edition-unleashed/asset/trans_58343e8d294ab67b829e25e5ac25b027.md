## KDE 进程和系统监控工具

KDE 提供了多个进程和系统监控客户端。通过右键单击任务栏并按照菜单操作，将 KDE 图形客户端集成到桌面任务栏中。

这些 KDE 监控客户端包括以下内容：

- kdf—系统文件系统表的图形界面，显示可用磁盘空间，并允许你使用指向设备挂载和卸载文件系统。

- ksysguard—另一个面板小程序，以动画图表形式提供 CPU 负载和内存使用信息。
