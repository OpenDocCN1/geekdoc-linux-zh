### Linux's Components

You will come across seven major components of Linux. They include the following: Shell, Daemons, Desktop Environments, Availability of Applications, Graphical Server, Kernel, and the Boat Loader.

Desktop environments

Desktop environments refer to the many components that interface with the user. Enlightenment, Cinnamon, Unity, and GNOME are just a few examples of these desktop environments. Daemons

Daemons are the Linux components that will provide background services. This includes scheduling, printing, and audio. These will be launched at one of two points: during boot or after you log in to your desktop.

Availability of Applications

Linux comes pre-installed with thousands of apps. Once the Linux system is installed, you may install as many of them as you choose. Graphical Server

The Boot Loader

At times, you'll need to verify that the system boots properly. The boot loader will take over the boot process under the Linux management environment. It is frequently displayed as a splash screen. Once you view this splash screen, the computer will slowly begin the starting process.

Kernel

The kernel is the major component that you will encounter within the Linux operating system. This is essentially the Linux core. It controls the Linux operating system's CPU, peripheral devices, and memory management.

The Casing (Shell)

Within Linux, the shell will serve as the command line. It will enable a variety of controls based on the instructions entered into the interface by the user. This is where you will enter the codes and directives you wish to send to the computer. Our computers are programmed to comprehend a certain language.

The shell is a user interface environment or user application. It is a command language interpreter that translates and executes commands taken from input devices, such as keyboards or files. When you open a terminal or log into your system, the shell is started. Although it is not a component of the Linux system kernel, it makes extensive use of the kernel for file creation, application execution, and a variety of other tasks. return [value]: This ends a function or subroutine. It will stop the bash shell and output whatever is pushed with it.

mv: command line

mv: Used to change the location of a file from one area to another. The -i option tells it to copy the contents of all files and folders in the destination directory. The -r option tells it not to overwrite any existing files.

less : command line

less : This command is used for viewing text files, such as README files, in a more readable format. By default, less will position your cursor on the last line of a text file. To navigate through the text file, you can use the arrow keys on your keyboard. For example, to go up one line, you would hit the up arrow. If you don't know what command to use for a particular task, typing “less filename” will display the contents of filename in a terminal window. This is very useful if you come across a file with an extension that you don't recognize.

more: command line

more : This command displays one screen at a time. To scroll through the text that you are viewing, type “<” for the previous line, then press “>” for the next line.

rm: command line

rm: This command removes a file or folder from your Linux system. If you don't know what to type to delete the file, typing “rm filename” will display what you need to know in a more understandable format. The -i option tells it to remove all files and folders with their contents.

mkdir: command line

mkdir: This command creates a folder, unless the directory already exists. The -i option tells it to create all folders with their contents. To delete a folder, you should use the rm command.

The above are just some of the many commands you will need to know in order to get your Linux system working efficiently and effectively. If you are starting out, the above commands should be plenty to get started with!
