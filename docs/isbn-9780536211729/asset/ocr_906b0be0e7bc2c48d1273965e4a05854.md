Unfortunately, there is no documentation or simple way to determine which fact (before the "..") telnetd is using to generate this message. It is suggested that you edit the /etc/syslog.conf file, copy this line, comment out the original, edit the copy to specify only some of selectors, and force the message to be generated and see it appears.

The telnetd daemon says "UNKNOWN" if the person entered an account name is not in /etc/passwd; otherwise it will list the account name, as "bob". You might modify your telnetd so that instead of saying "UNKNOWN" it will say "U-joe" so if they are trying to guess account names you will see "U-joe", "U-joe", "U-jane", "U-jane", etc. and assume that they are trying a few unlikely passwords on common account names. Note that you must separate the selectors from the accounts with tabs, no spaces.
