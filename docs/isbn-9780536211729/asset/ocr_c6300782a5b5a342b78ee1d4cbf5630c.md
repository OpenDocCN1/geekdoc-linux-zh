By definition, loopback traffic is targeted for the system generating it. It doesn't go out on the network. The loopback address range is 127.0.0.0 to 127.255.255.255. You'll usually see it referred to as 127.0.0.1, localhost, or the loopback interface, 1.

+   * Malformed broadcast addresses—Broadcast addresses are special addresses applying to all machines on a network. Address 0.0.0.0 is a special broadcast source address. A legitimate broadcast source address will be either 0.0.0.0 or a generic IP address. DHCP clients and servers will see incoming packets from source address 0.0.0.0. This is the only use of this source address. It is not a legitimate point-to-point, unicast source address. When we see the source address in a regular, point-to-point, nonbroadcast packet, the address is forged, or the sender isn't fully configured.

+   * Class A network addresses—As suggested previously, any source address in the 0.0.0.0 through 255.255.255 range is illegal as a unicast address.

+   * Link network addresses—DHCP clients sometimes assign themselves a local address when they can't get an address from a server. These addresses range from 169.254.0.0 to 169.254.255.255.

+   * TEST-addresses—The address space from 192.0.2.0 to 192.0.2.255 is reserved for test uses.

A number of other address blocks are reserved by IANA and are not in use. In experience, it's good to filter out these additional blocks. There's a danger in doing so, however: As the IPv4 space gets tighter and the number of Internet sites grows, IANA has allocating these blocks more frequently since mid-2000. Unless you monitor the IANA block allocations on a regular basis, sooner or later you will be blocking legitimate addresses.

Unintentionally blocking newly allocated legitimate addresses is inconsequential for a residential site. Business sites need their balance to maintain access against the cost of constantly monitoring all allocated addresses. For Internet businesses that have been the subject of ongoing Dos attacks, it could well be in their best interests to make the effort, simply reduce the number of spoofed source addresses that their site will respond to.

# BLOCKING PROBLEM SITES

Another common, but less frequently used, source address—filtering scheme is to block all access from a selected machine, or more typically, from an entire network's IP block. This is how the Internet community tends to deal with problem sites and ISPs that don't police their users. If a site develops a reputation as a bad Internet neighbor, other sites tend block across the board.

On the individual level, blocking all access from selected networks is convenient when individuals in the remote network are habitually making a nuisance of themselves. This has historically been used as a means to fight unsolicited email, with some people going so far as block an entire country's range of IP addresses.
