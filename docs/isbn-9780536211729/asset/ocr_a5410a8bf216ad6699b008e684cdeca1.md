# C. Analyze CGIs for vulnerabilities.

When writing CGI programs, look at what the cracker will do to break them. Check for buffer overflows using good programming techniques. For example, when using C, make use of the fgets() routine which allows the programmer to specify how large a buffer has been allocated and not overflow it.
