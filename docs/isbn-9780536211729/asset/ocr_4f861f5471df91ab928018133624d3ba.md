# MASQUERADE TABLE TARGET EXTENSION

Source Address Translation has been implemented in two different ways in iptables, SNAT and as MASQUERADE. The difference is that the MASQUERADE target extension is intended for use with connections on dynamically assigned IP addresses, particularly in the case where the connection is temporary and the IP address assignment is likely to be different at each new connection. As discussed previously, in the “NAT Table Features,” MASQUERADE can be useful for dial-up connections in particular.

Because MASQUERADE is a specialized case of SNAT, it is likewise a legal target only in the POSTROUTING chain, and the rule can refer to the outgoing interface. Unlike the more generalized SNAT, MASQUERADE does not take an argument specifying the source address to apply to the packet. The IP address of the outgoing interface is used automatically.

The general syntax for MASQUERADE is as follows:

```
iptables -t nat -A POSTROUTING --out-interface <interface> ... \n  -j MASQUERADE --to-ports <port>[-<port>]
```

The source port can be mapped to a specific range of source ports on the router.
