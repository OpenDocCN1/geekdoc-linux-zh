The Logcheck program analyzes a system's most massive log files, extracts anything that might indicate (1) an attack, (2) a security violation, or (3) other abnormality (listed in order of severity), generates a report summarizing these events, and informs the SysAdmin via email. For those that do not check their log files on a daily or hourly basis (which is almost everyone), this does work. It is invoked from each system's root crontab, typically either or hourly. It is important to recognize that this is an Intrusion Detection System (IDS) that does not operate in real time.
