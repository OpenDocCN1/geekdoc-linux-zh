# HARDENING
YOUR SYSTEM

In this chapter, many common problems are explained and quick fixes are provided. There are many of them because Linux offers so many standard features. Problems with more involved solutions are covered in later chapters. The quickly solved problems in this chapter concern configuration issues, services that are too dangerous to allow, and versions of software that have known vulnerabilities. These problems have allowed many systems to be broken into; you do not want to allow your system to be broken. Problems range from the basic to subtle. They include include insecure versions of popular programs as fundamental as the name daemon, named, that provides Domain Name Service. This program maps host names such as www.pentacorp.com into their IP addresses, e.g., 192.168.57.8. This mapping is needed because the numeric address is used for routing messages to other systems.

This chapter will start with some security concepts and dive into the seven deadly sins for Linux systems. You then examine various problems in-depth and solve them.

> Implementing the quick fixes suggested in this chapter alone will greatly increase system security with minimal time required by busy system administrators.
