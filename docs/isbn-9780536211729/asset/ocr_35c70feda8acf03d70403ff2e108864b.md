# DNAT NAT TABLE TARGET EXTENSION

Destination Address and Port Translation is a highly specialized form of NAT. A resident or small business site is most likely to find this useful if its public IP address is dynamically assigned or if the site has a single IP address, and the site administrator wants to forward incoming connections to internal servers that are not publicly visible. In other words, the DNAT features can be used to replace the previously required third-party forwarding software, such as ipmasquerading.

Referring back to Figure 6.5, Destination Address and Port Translation is done before the routing decision. On the PRERUTING chain, DNAT can be a target when the incoming interface is specified. On the OUTPUT chain, DNAT can be a target when the outgoing interface is specified.
The general syntax for DNAT is as follows:

```
iptables -t nat -A PRERUTING --in-interface <interface> \
  -j DNAT --to-destination <address>[-<address>]:[:port-<port>]
iptables -t nat -A OUTPUT --out-interface <interface> \
  -j DNAT --to-destination <address>[-<address>]:[:port-<port>]
```

The destination address can be mapped to a range of possible IP addresses, if more than one is available.
The destination port can be mapped to a specific range of alternate ports on the destination host.

# REDIRECT NAT TABLE TARGET EXTENSION

Port redirection is a specialized case of DNAT. The packet is redirected to a port on the local host. Incoming packets that would otherwise be forwarded to the incoming interface are redirected to the interface's INPUT chain. Outgoing packets generated by the local host are redirected to a port on the local host's loopback interface.

REDIRECT is simply an alias, a convenience, for the specialized case of redirecting a packet to this host. It offers no additional functional value. DNAT could just as easily be used to cause the same effect.

REDIRECT is a legal target only in the PRERUTING and OUTPUT chains. On the PRERUTING chain, REDIRECT can be a target when the incoming interface is specified. On the OUTPUT chain, REDIRECT can be a target when the outgoing interface is specified.
The general syntax for REDIRECT is as follows:

```
iptables -t nat -A PRERUTING --in-interface <interface> \
  -j REDIRECT [--to-ports <port>[-<port>]
iptables -t nat -A OUTPUT --out-interface <interface> \
  -j REDIRECT [--to-ports <port>[-<port>]
```

The destination port can be mapped to a different port or to a specific range of alternate ports on the local host.
