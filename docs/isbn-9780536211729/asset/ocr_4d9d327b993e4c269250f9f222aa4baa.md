A cracker could take over one of these systems before the SysAdmin had a chance to properly configure the system to be secure. Even though there might be a window of only a few minutes or even only a few seconds, a cracker needs to do is leave an automatic sniffer on the network to recognize packets from any never-before-seen MAC address, also known as an Ethernet address (yours). This automatic tool would then start trying exploits.

It might take less than a second to take over your system. Because this would have been before you set up Tripwire you would not have either a Tripwire baseline to compare against or an uncompromised backup tape to restore. If the cracker is stealthy, he could be in months.

# 2.7.1 Revving Up Red Hat 7.3

Red Hat's version 7.3 goes further than previous versions in trying to reduce the “geek knowledge” required to get Linux running, as some of the other major Linux players. I salute this effort as assist my technical friends in moving to Linux. However, a few things could use improvement. With any initial system installation and configuration, I recommend either disconnecting the system from all networks or ensuring that no intruder can get to it. If the system is a well-configured firewall where there are no systems vulnerable to viruses, this should be suitable.

First, the client is offered a choice of four installation types: workstation, server, lap-top, or custom. For casual use when chained to a desk, the choice is between workstation and server installation. With a workstation installation, you get the X windowing system, but no SSH daemon. This prevents the most universal practice of SSHing into one’s workstation from home or on the other side of the world.

Ha! I'll just tell them I want a server installation to get the SSH daemon and any other servers that I want to “play” with, possibly for “collaboration The excellent documentation told me that with server installation, I will not get X.
