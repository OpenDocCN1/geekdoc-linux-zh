# 3.6 DNS (named, a.k.a. BIND)

![](bbox=[0.118, 0.503, 0.918, 0.573])

The named program, meaning the name daemon or DNS daemon, is the program that converts a fully qualified host name, such as

www.realworldlinuxsecurity.com

to its numeric IP address like

192.168.57.8

Without it there would be no www.cute-name.com; there would be harder to deal with and less flamboyant. Many 63.26.72.248 and the Internet would leaf nodes do not route traffic for other systems do not need to run it. Instead they simply specify the numeric IP addresses of their name servers in /etc/resolv.conf and any program, such as sendmail, telnet, ftp, and Netscape simply will read /etc/resolv.conf and make the request for DNS lookup directly the remote server system's named. Small "internal" networks may not use DNS at all, they will rely on each system's /etc/hosts file being set up.
