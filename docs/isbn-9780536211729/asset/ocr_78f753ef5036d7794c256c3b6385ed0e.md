Additionally, even some recent versions of WU-FTPD, the FTP daemon created by Washington University at St. Louis, suffer from security bugs. These include a buffer bug that allows a remote intruder to make himself root. This version was common in distributions as late as 1999.

> I determined that one of a client's development machines very likely was broken into this overflow bug.

I scanned his system for cracker-induced alterations using methods discussed in Part IV, using tar. The Network Administrators and I then explained to him the benefits and usage of TCP Wrappers and SSH and how they could allow him safely to connect from his home system and to transfer files between these two systems.

You will want to check the errata for your distribution, discussed in Appendix A, to ensure your version of WU-FTPD does not have these bugs in it. The Linux Administrators Security Guide reports that several nasty DoS vulnerabilities still exist in WFTPD as of 1999 and that improper server setup allows a cracker to obtain privileges she should not have. "Upgrade WU-FTPD" on page 106 tells where to get updates and the most recent version available.
