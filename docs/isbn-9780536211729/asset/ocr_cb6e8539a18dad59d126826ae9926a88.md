killall -HUP inetd

The TCP services easily may be tested with telnet by invoking it with a second argument, which is the numeric port number or its symbolic name in /etc/services. Any of these DTK services will time out. The timeout value is configurable and typically is 30 seconds. To see what the dtk service does on port 365, use this command:

```
telnet yoursys.pentacorp.com dtk
```

If you selected ordinary logging when you ran Configure, /dtk/log will contain all the client-entered commands as well as an entry for its initial connection. Additionally, /dtk/IP will be a log file for each unique IP of a client system that tries to access a service. The name of each of these log files is that of the numeric IP address in dotted-quot quotation, for example:

```
/dtk/log/192.168.43.184
```

The /dtk/README explains the format and usage of the state description files under /dtk/default. It explains how to configure a state machine so that some IP addresses get real service and the rest get the deception. Additionally, it explains how to run another process, for example, blockip to lock out the system using Adaptive-TCP Wrappers.

# 8.15 Monitoring Processes

Almost everyone knows something about using ps to list process status to see what programs are running on the system. The typical invocation would be

```
ps -axlw | more
```

It is helpful to know what these values are typically for your system's daemons and commonly used programs, such as Netscape. You might store the output of a ps invocation on disk. This may enable you to recognize whether a cracker has installed a Trojan version of one of these due to its size being wrong. Better techniques for detecting this are discussed in Part IV of this book. I have learned to check the RSS value for Netscape frequently because it seems to have a memory leak that can become serious after a day or so.
