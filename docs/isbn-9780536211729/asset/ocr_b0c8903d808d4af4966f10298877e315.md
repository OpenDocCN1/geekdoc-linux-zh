#  7.3.2 Common Local UDP Services Assigned to Unprivileged Ports

TCP protocol rules can be handled more precisely than UDP protocol rules of
TCP's connection establishment protocol. As a datagram service, UDP doesn't have a con-
ection state associated with it. Unless the state is used, access to UDP services
s simply be blocked. Explicit exceptions are made to accommodate DNS and any of

Internet services are often the type used between a client and a specific server. The filter-

NFS is the UNIX UDP service to be concerned with and also is one of the most
frequently utilized. NFS runs on unprivileged port 2049. Unlike the previous TCP-based
services, NFS is primarily a UDP-based service. It can be configured to run as a TCP-based
service, but usually it isn't.
