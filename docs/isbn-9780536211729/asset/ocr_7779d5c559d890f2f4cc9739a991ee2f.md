Let us now walk through an installation. First, ensure that syslog is running; it should be running on any Linux system or BSD-like Unix system. The log files probably will be /var/log, with the messages file generating a copy of all messages except debugging and mail logs. It is recommended to fix the permissions of all log files changed to 600 and bound to stop crackers from using ordinary accounts to get information from them. Next, use the CD-ROM as /mnt/cdrom and issue the commands

```
zcat /mnt/cdrom/book/logcheck-1.1.lob.tar.gz | tar -xof -
logcheck-1.1.lob
```

Now, read the text files LICENSE, CREDITS, and crontab.
For those who use Sendmail, edit /etc/mail/aliases and create an alias for the e-mail of whoever should be notified of security problems. Preferably, this should be a separate mailbox for your regular mailbox to avoid cross-contamination. Then, create an alias, alertpage, for e-mail-capable pages to receive security violation and attack e-mail. If no pager e-mail is desired,

```
alertpage:/dev/null
```

Under IP Tables, you can specify that certain text should be prepended to the log file that is generated: SuSE's firewall2 script, standard on recent releases, prepends SUSE-FW-stuff, which makes for lines with repetitive text. That is, the varying part of a space-separate word of an error message should be at the beginning of the word (and at the beginning of the line) or it will likely not be detected.

There is a good lesson here for writing error messages for human consumption, including log messages (applicable to firewall2, Portentry, etc.).
work hard not to include obvious, repetitive, or irrelevant information in error messages. This unnecessary information serves mostly to make understanding the error message more difficult. This puts the intended reader of the message at risk for not understanding its critical information. Also, processed log messages should not exceed 80 characters, to avoid line wrapping. By following this lesson, the person reading the messages can skim lines of interest far more quickly and spend time reading unnecessary words.
