To have pp provide output for a specified PID, say, 1701, the following command
could be issued:

pp 1701

Besides ps, the top program is quite helpful. It provides a dynamically updating view
of the most active processes and is often very helpful in spotting abnormal operation. Its
display can be limited to the processes of a single account by issuing "u" command and
then entering the account name.

The fuser program will list the processes using a specified file, file system, or network
port. It can be used to determine which processes are doing I/O to a suspicious file. (The pp
script, discussed earlier, then could be used to find the parent process of very sus-
cious processes. The following command will list the PIDs of any process that currently
has /var/adm/messages open:

```
fuser /var/adm/messages
```

Its output will look something like

```
/var/adm/messages: 434
```

> In the old days, fuser was useful for seeing which processes had files open
on a file system that the SysAdmin wanted to unmount. To list processes with files
en on /usr, use the command

fuser -m /usr

You can use our new pp script to identify this process thus:

pp 434
