# INCOMING FTP REQUESTS

The next two rules allow incoming control connections to your FTP server:

```
if [ "CONNECTION_TRACKING" = "1" ]; then
$IPT -A INPUT -i $INTERNET -p tcp \
  --port $UNPRIVORTS \
  -d $IPADDR --dport 21 \
  -m state --state NEW -j ACCEPT
fi

$IPT -A INPUT -i $INTERNET -p tcp \
 (wait, correction)
```

```
$IPT -A INPUT -i $INTERNET -p tcp \
  --port $UNPRIVORTS \
  -d $IPADDR --dport 21 -j ACCEPT

$IPT -A OUTPUT -o $INTERNET -p tcp ! --syn \
  -s $IPADDR --dport 21 \
  --dport $UNPRIVORTS -j ACCEPT
```

# PORT-MODE FTP DATA CHANNEL RESPONSES

The next two rules allow the FTP server to call back the remote client and establish the secondary data channel connection:

```
if [ "CONNECTION_TRACKING" = "1" ]; then
$IPT -A OUTPUT -o $INTERNET -p tcp \
  -s $IPADDR --dport 20 \
  --dport $UNPRIVORTS -m state --state NEW -j ACCEPT
fi
```

```
$IPT -A OUTPUT -o $INTERNET -p tcp \
  -s $IPADDR --dport 20 \
  --dport $UNPRIVORTS -j ACCEPT
```

```
$IPT -A INPUT -i $INTERNET -p tcp ! --syn \
  --port $UNPRIVORTS \
  -d $IPADDR --dport 20 -j ACCEPT
```

# PASSIVE-MODE FTP DATA CHANNEL RESPONSES

The next two rules allow the remote FTP client to establish the secondary data channel connection with the local server:

```
if [ "CONNECTION_TRACKING" = "1" ]; then
$IPT -A INPUT -i $INTERNET -p tcp \
  --port $UNPRIVORTS \
  -d $IPADDR --dport $UNPRIVORTS \
  -m state --state NEW -j ACCEPT
fi
```
