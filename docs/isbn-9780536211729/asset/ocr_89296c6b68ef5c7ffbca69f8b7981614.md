# iptables Syntax

```
iptables -A OUTPUT -o eth0 -p tcp \
  -s <IPADDR> --sport 1024:65535 \
  -d <fw IPADDR> --dport 22 \\
  -m owner --uid-owner <admin userid> \
  --gid-owner <admin groupid> -j ACCEPT
```

# mark filter TABLE MATCH EXTENSION

Table 6.18 lists the options available to the mark match extension.

| -m | -match mark Option | Description |
|---|---|---|---|
| --mark <value>[/mask] | | Matches packets having the Netfilter-assigned mark value |

The value and the mask are unsigned long values. If a mask is specified, the value and the mask are ANDED together.
In the example, assume that an incoming telnet packet between a specific source and destination has been marked previously:

```
iptables -A FORWARD -i eth0 -o eth1 -p tcp \
  -s <some src address> --sport 1024:65535 \
  -d <some destination address> --dport 23 \
  -m mark --mark 0x00010070 \nn  -j ACCEPT
```

The value being tested for here was set at some earlier point in the packet processing. The mark value is a flag indicating that this packet is to be handled differently from other packets.

# tos filter TABLE MATCH EXTENSION

Table 6.19 lists the options available to the tos match extension.

| -m | --match tos Option | Description |
|---|---|---|---|
| --tos <value> | | Matches on the IP TOS setting |

The tos value can be one of the string or numeric values:

+   - minimize-delay, 16, 0x10
- maximize-throughput, 8, 0x08
- maximize-reliability, 4, 0x04
