version. the latter is a strong hint as to what range of versions the sendmail program could be. A text editor may be used to remove the strings

from the /etc/sendmail.mc file.

To enable all these security features, which is suggested, ensure that /etc/sendmail.mc includes all the entries in Table 3.1.

# Table 3.1 Sendmail Security Options

```
define(`confPRIVACY_FLAGS`,authwarnings nofrpy noexpn restrictmailq needlehelmo)
```

```
define(`confMAX_DAEMON_CHILDREN`, 25)
```

```
define(`confSMTP_LOGIN_MSG`,$j Sendmail Secure/Rabid; $b)
```

After editing /etc/sendmail.mc, issue the following shell commands to have your changes effect.

```
m4 /etc/sendmail.mc > /etc/sendmail.cf
/etc/rc.init/sendmail restart
```

Note that m is the Linux and UNIX general macro processor. The /etc/sendmail.mc file includes the main definition file, /usr/lib/sendmail-cf/m4/proto.m4. The most commonly altered items are listed in /etc/sendmail.mc; this is to free SysAdmins from learning the challenging details of the sendmail.cf file is now generated by the m4 command shown above; it no longer is edited. Instead, to alter items not listed in /etc/sendmail.mc, editing /usr/lib/sendmail-cf/proto.m4 is necessary.
