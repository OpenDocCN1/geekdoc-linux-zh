> DANGER LEVEL

These are two innocent services used for network and system testing. The echo port simply echoed back all data sent to it to test connectivity. The chargen port, short for character generation, output a rotating sequence of printable characters for testing it devices and others situations where a known and varying sequence was desired.

Even these can be corrupted by crackers and so they should be disabled. The UDP versions of echo and charg (character generation) can be used for a DoS attack against a third system. A cracker merely needs to spoof her source address to be that of the system to be attacked and send packets to that third system by yours.

A cracker can have system X telnet to system Y chargen port and then walk away while Y sends unlimited data to X using the bandwidth of whichever them has a smaller “pipe” (bandwidth) to the Internet.
