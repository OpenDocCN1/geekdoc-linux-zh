+   6. NFS consists of these daemons: rpc.nfsd, mountd, portmap, rpc.lockd, rpc.statd, rpc.quotad, and automounter, scattered across a number of startup scripts. Technically, portmap is not part of NFS. It is a part of the underlying Procedure Call (RPC) layer on many systems is used only for NFS. When an RPC server, such as NFS, is started it will tell portmap both its service port number and its TCP or UDP port number. A client will then ask portmap, "What TCP or UDP port should I use for service X? A cracker can lie to portmap and masquerade as a legitimate server. NFS has had plenty of security gaps in the past and its design prevents being in secure configurations.
