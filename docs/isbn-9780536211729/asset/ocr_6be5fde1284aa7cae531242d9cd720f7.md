The -filesystem proc would be true only for files that are on a file system of type proc. In other words, ignore pseudo files on /proc. Recall that the /proc file system does not exist on disk. Rather, it is generated dynamically by the kernel to get and set certain kernel parameters.

The -perm operator is short for permissions and allows selection depending on a file's permissions. If its argument starts with a “-', it will be true for a given file if all of the permission bits are specified. Thus,

```
-perm -2
```

will be for each file that is world-writable. This allows you to detect this potential security problem. (If the argument to -perm starts with “+, it will be true if any of the bits, instead of all of them, are true. If there is no leading - or +, -perm will be true if a file's permissions exactly match the argument.)

The -ls will cause the equivalent of ls to be done on each matching file and is a recent feature. The -ls gives more information than the -print.
