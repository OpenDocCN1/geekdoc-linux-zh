# 4.3.1 UDP

UDP, or User Datagram Protocol, is a connectionless protocol used for such services as DNS queries, SNMP, RADIUS. Being connectionless, UDP is akin to a “fire and forget” type of protocol. The client sends a UDP packet, sometimes referred to as a datagram, and assumes that the server will receive the packet. It is up to a higher layer protocol to assemble the packets in order.
