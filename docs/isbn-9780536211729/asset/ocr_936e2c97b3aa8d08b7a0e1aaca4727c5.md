# # 4.2 The ICMP

Holding a special place, some say, within the IP layer is ICMP. You're probably familiar with ICMP when you use the ping command because uses ICMP, ICMP, or Internet Control Message Protocol, has several uses, including being the underlying protocol for the ping command. There are 15 functions within ICMP each denoted by a type code. For instance, the type for ICMP Echo Request (think: ping) is 8; the reply to that request, aptly an Echo Reply, is type 0. Within the different types there also exist codes to specify the condition for the given type. The types and codes for ICMP messages are shown in Table 4.3.
