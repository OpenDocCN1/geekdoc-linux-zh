ARPWatch will be installed (by default) into /usr/local/sbin. This directory is usu- ally in root's path, but if you type arprewatch and receive a command not found error, you probably need to preface the command with its directory, like this:

```
/usr/local/bin/arprewatch
```

As ARPWitch runs, it will report to the SYSDLOG daemon about new MAC addresses found on the network. This means that ARPWitch will usually output to /var/log/messages, so you can run a grep command to find out about the new hosts as ARPWitch finds them:

```
grep arprewatch /var/log/messages
```

Additionally, ARPWitch will also send email to the root account on a system detail- ing the new hosts as well. The email contains details such as the date, the IP address, and the MAC address:

```
hostname: client.example.com ip address: 192.168.1.10 ethernet address: 0:e1:18:34:2f:e8 ethernet vendor: <unknown> timestamp: Saturday, May 22, 2004 11:25:59 -0500
```

In both of these ways, it's possible to know virtually instantly when a new host appears on the network. Such information would be helpful to the security administrator in moni- toring for possible unauthorized use of a network.
