The ident service gives information about your system to any process that asks. If allowed to give out user names, these might be used by an attacker to guess passwords or e-mail addresses. Recall that a valid user name and that user's password must be supplied for any information to be discerned from a login attempt. It is suggested that the -n flag given when identd is invoked to cause a numeric UID to be given instead of a user name because the UID is of no use for this purpose. Also, it is suggested that the -user and -group flags be used to change ident to change itself to a harmless user and group, such as ident. Thus, in case a cracker finds a vulnerability in it, the cracker will not get access.

> You might want to modify identd to provide the same response (the fake user name) each time it is queried. This will prevent crackers from finding who is logged on, and will prevent both crackers and spammers from getting user names for nefarious purposes. You can download such a fake version from www.ajk.tele.fi/-too/sw/

Additionally, DoS attacks are possible, because it is a resource that an attacker can use up. It is suggested that if it is run, be run only on systems that have "real users" with shell accounts. (Other systems have no use for it.) The -o option, which is by default, will cause identd to say that the operating system is OTHER instead of UNIX. While some people advocate for "security by obscurity," I do not find such a technique particularly valuable, though I do not believe in revealing user numbers that information would accurately reveal vulnerabilities.

The -l option will cause identd to log requests via syslog. It is on by default.
A decent cracker can determine your system's operating system by observing differences in how it responds to certain conditions in packet handling. The nmap program is particularly skilled at doing this. Even this will not be necessary if you supply such information via a telnet service or the offering of other services characteristic of Linux and UNIX. If in doubt, do not offer indent.
