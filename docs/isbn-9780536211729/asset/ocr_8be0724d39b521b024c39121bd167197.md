The following entries in /etc/squid/squid.conf will allow only the systems with the IP addresses of 216.247.56.62 216.247.56.63 to use Squid.

```
acl OK src 216.247.56.62 216.247.56.63
http_access allow OK
http_access deny all
```

Note that all the components of an acl are ORed together and all the entries of an access entry are ANDed together. Thus, you do not want to list all the hosts on the access line (because the AND of disjoint sets is the empty set).

Like firewall-related products, Squid allows you to specify how many bits of an address to test, which a single rule to match your network or a subnet, like firewalls, TCP Wrappers, when a request comes in, the program parses in-memory copy of the configuration file from the top until it finds the first rule that matches (either that allows or denies the request) and only that rule determines the action.

The following will allow the class-B network 216.247.255.*:*

```
acl OK src 216.247.0.0/255.0.0
acl all src 0.0.0.0/0.0.0
http_access allow OK
http_access deny all
```

If you have a firewall, blocking access to Squid's port from sources outside of your network will solve the problem. However, also blocking firewall addresses from Squid itself will help protect against trouble from someone inside your network with an unauthorized address who is up to no good. Remember that you should have “Rings of Security."

Protecting their network from the internet, everyone has the duty to protect the Internet from problems originating from within their own network.

Squid's default address is TCP port 3128. Note that there has been an increase spring of 2000 in networks being scanned just for port 3128, clearly looking for this vulnerability. If you do not have a firewall blocking this port, there certainly is no reason to make it easy for crackers to bypass the default port except that this allows semi-automatic configuration by Netscape. Considering picking a different port. Besides http, Squid also ports https, FTP, Gopher, WAIS, and snews (Network News Transfer Protocol over SSL).
