If an error occurs because the returned data is too large to fit in a UDP datagram, DNS client retries using a TCP connection.

The next two rules are included for the rare occasion when the lookup response won't fit in a DNS UDP datagram. They won't be used in normal, day-to-day operations. You could run your system without problems for months without the TCP rules. Unfortunately, every so often your DNS lookups hang without these rules. More typically, these rules are used by a secondary name server requesting a zone transfer from its primary name server:

```
if [ $CONNECTION_TRACKING = "1" ]; then
$IPT -A OUTPUT -o INTERNET -p tcp \
-s $IPADDR --sport $UNPRIVORTS \
-d $NAMESERVER --dport 53 \
-m state --state NEW -j ACCEPT
```

fi
