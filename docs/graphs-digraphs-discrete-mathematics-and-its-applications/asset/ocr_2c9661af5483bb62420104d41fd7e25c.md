# 14.3 Bounds for the Chromatic Number

Since determining whether a graph is $k$-chromatic for $k \geq 3$ is known to be an **NP**-complete problem, it is not surprising that much of the research emphasis on coloring has centered on finding bounds (both lower bounds and upper bounds) for the chromatic number of a graph. For a graph $G$ of order $n$ with clique number $\omega(G)$ and independence number $\alpha(G)$, we have already seen that $\omega(G)$ and $n/\alpha(G)$ are lower bounds for $\chi(G)$ while $n - \alpha(G) + 1$ is an upper bound for $\chi(G)$. Of course, $n$ is also an upper bound for $\chi(G)$. In particular,

$\omega(G) \leq \chi(G) \leq n.$

Bruce Reed [198] showed that $\chi(G)$ can never be closer to $n$ than to $\omega(G)$.

# **Theorem 14.16** For every graph $G$ of order $n$, $\chi(G) \leq \left\lceil\frac{n+\omega(G)}{2}\right\rceil.$

**Proof.** We proceed by induction on the nonnegative integer $|V(G)| - \omega(G)$. If $G$ is a graph such that $|V(G)| - \omega(G) = 0$, then $G = K_n$ for some positive integer $n$ and so $\chi(G) = \omega(G) = n$. Thus, $\chi(G) = \left\lceil\frac{n+\omega(G)}{2}\right\rceil$. This verifies the basis step of the induction.

Assume for a positive integer $k$ and every graph $H$ (having order $n'$) such that $n' - \omega(H) < k$ that $\chi(H) \leq \left\lceil\frac{n' + \omega(H)}{2}\right\rceil$. Let $G$ be a graph of order $n$ such that $n - \omega(G) = k \geq 1$. Since $G$ is not complete, $G$ contains two nonadjacent vertices $u$ and $v$. Let $H = G - u - v$. Then $H$ has order $n-2$ and either $\omega(H) = \omega(G)$ or $\omega(H) = \omega(G)-1$. In either case, $0 \leq (n - 2) - \omega(H) < k$ and so

$\chi(H) \leq \left\lceil\frac{n - 2 + \omega(H)}{2}\right\rceil$ by the induction hypothesis. Hence, there exists a $\left\lceil\frac{n - 2 + \omega(H)}{2}\right\rceil$-coloring of $H$. Assigning $u$ and $v$ the same new color implies that $\chi(G) \leq \left\lceil\frac{n - 2 + \omega(H)}{2}\right\rceil + 1 = \left\lceil\frac{n + \omega(H)}{2}\right\rceil \leq \left\lceil\frac{n + \omega(G)}{2}\right\rceil.$ $\blacksquare$
