# ### 18.1 Nowhere-Zero Flows

A **flow** on an oriented graph $D$ is a function $\phi: E(D) \rightarrow \mathbb{Z}$ such that for each vertex $v$ of $D$,

```
$$\sigma^{+}(v; \phi)=\sum_{(v, w) \in E(D)} \phi(v, w)=\sum_{(w, v) \in E(D)} \phi(w, v)=\sigma^{-}(v; \phi) .(18.1)$$
```

That is, for each vertex $v$ of $D$, the sum of the flow values of the arcs directed away from $v$ equals the sum of the flow values of the arcs directed toward $v$. The property (18.1) of $\phi$ is called the **conservation property**. Since $\sigma^{+}(v; \phi)-\sigma^{-}(v; \phi)=0$ for every vertex $v$ of $D$, the sum of the flow values of the arcs incident with $v$ is even. This, in turn, implies that the number of arcs incident with $v$ having an odd flow value is even.
