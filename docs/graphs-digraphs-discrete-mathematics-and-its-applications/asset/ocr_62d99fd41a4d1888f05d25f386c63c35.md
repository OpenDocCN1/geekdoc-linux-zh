A subgraph *H* of odd order *n'* and size *m'* of a graph *G* is an **overfull subgraph** of *G* if

*m*' > *n'*  [ *n*' / 2 ] . Δ(*G*) = ( *n*' - 1 ) / 2 . Δ(*G*).

Actually, if *H* is an overfull subgraph of *G*, then Δ(*H*) = Δ(*G*) (see Exercise 16). This says that *H* is itself of Class two. Not only is an overfull subgraph of a graph *G* of Class two, *G* itself is of Class two.

**Theorem 17.12**  Every graph having an overfull subgraph is of Class two.

**Proof.**  Let *H* be an overfull subgraph of a graph *G*. As we noted, Δ(*H*) = Δ(*G*) and *H* is Class two; so χ'(*H*) = 1 + Δ(*H*). Thus,

χ'(*G*) ≥ χ'(*H*) = 1 + Δ(*H*) = 1 + Δ(*G*)

and so χ'(*G*) = 1 + Δ(*G*).

In the definition of an overfull subgraph *H* of order *n'* and size *m*' in a graph *G*, we have *m*' > ( *n*' - 1 ) / 2 . Δ(*G*). As we saw in Theorem 17.12, this implies that *G* is of Class two. On the other hand, if *G* should contain a subgraph *H* of order *n*' and size *m*' such that *m*' > ( *n*' - 1 ) / 2 . Δ(*H*), where Δ(*H*) < Δ(*G*), then *H* is an overfull graph and so *H* is of Class two. This need not imply that *G* is of Class two, however. For example, *C*5 ⊂ *K*2 is of Class one but *C*5 is of Class two.
