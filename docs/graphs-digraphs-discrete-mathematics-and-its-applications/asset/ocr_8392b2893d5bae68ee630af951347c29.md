We now verify the converse. Suppose that the converse is false. Then among all counterexamples for which $n$ is minimum, let $\pi: s_1, s_2, \dots, s_n$ be one for which $s_1$ is minimum. Suppose first that there exists an integer $k$ with $1 \le k \le n-1$ such that

```
$$ \sum_{i=1}^{k} s_i = \binom{k}{2}. $$
```

Since $k < n$, it follows that $\pi_1: s_1, s_2, \dots, s_k$ is a score sequence of a tournament $T_1$ of order $k$.

Let $\tau: t_1, t_2, \dots, t_{n-k}$ be the sequence, where $t_i = s_{k+i} - k$ for $i = 1, 2, \dots, n-k$. Since

```
$$ \sum_{i=1}^{k+1} s_i \ge \binom{k+1}{2}, $$
```

it follows from (7.2) that

```
$$ s_{k+1} = \sum_{i=1}^{k+1} s_i - \sum_{i=1}^{k} s_i \ge \binom{k+1}{2} - \binom{k}{2} = k. $$
```

Since $\pi$ is a nondecreasing sequence,

```
$$ t_i = s_{k+i} - k \ge s_{k+1} - k \ge 0 $$
```

for $i = 1, 2, \dots, n-k$ and so $\tau$ is a nondecreasing sequence of nonnegative integers. We now show that $\tau$ satisfies (7.1).

For each integer $r$ with $1 \le r \le n-k$, we have

```
$$ \sum_{i=1}^{r} t_i = \sum_{i=1}^{r} (s_{k+i} - k) = \sum_{i=1}^{r} s_{k+i} - rk = \sum_{i=1}^{r+k} s_i - \sum_{i=1}^{k} s_i - rk. $$
```
