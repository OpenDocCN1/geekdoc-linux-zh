The proof of Theorem 8.5 provides the basis of an algorithm, also due to Ford and Fulkerson [94], for finding a maximum flow in a network.

# **Algorithm 8.7 (The Ford–Fulkerson Algorithm)** For a network N with underlying digraph D, source u, sink v and capacity function c,

+   1. Let f be a flow on D. (The zero flow may be used.)
+   2. Find an f-augmenting semipath.
+   3. If there is no f-augmenting semipath, then f is a maximum flow and stop.
+      If there is an f-augmenting semipath P, then augment P as in the proof of Theorem 8.5 to produce a new flow f' .
+   4. Set f = f' and return to Step 3.

This is a somewhat simplified version of the algorithm given by Ford and Fulkerson in [94]. They provided a scheme for finding an f-augmenting semipath for step 2. However, the version we presented contains the two inherent issues. First of all, Ford and Fulkerson themselves showed that their procedure might not terminate if the capacities are irrational. Their complex example can be found in [94]. The second issue is that even if it terminates (as in the case of only rational capacities), the algorithm may not be efficient. If we unwisely always choose augmenting semipaths that include the only arc with capacity equal to 1 (which is possible in the original Ford–Fulkerson Algorithm), then the maximum flow is 2C, no matter what constant C we choose, and the number of iterations of the algorithm is 2C if we start with the zero flow. Of course, optimally, the algorithm takes just two iterations.
