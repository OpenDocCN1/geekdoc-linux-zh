*Case 2.* κ(H) = 2. Since H is k-critical and k ≥ 4, it follows by Theorem 14.13 that H is (k − 1)-edge-connected and so δ(H) ≥ λ(H) ≥ k − 1 ≥ 3. Furthermore, n ≠ complete. Thus, there is a vertex x in H such that 3 ≤ deg_H x ≤ n − 2. Since κ(H) = 2, either κ(H − x) = 2 or κ(H − x) = 1. If κ(H − x) = 2, then x belongs to no minimum vertex-cut of H, which implies that H contains a vertex y such that d_H(y, x) = 2. Proceeding as in Case 1 with u = x and w = y, we see that there is a coloring of H with at most κ(H) colors and so once again we have (14.2), that is, χ(G) ≤ Δ(G).

Finally, we may assume that κ(H − x) = 1. Thus, H − x has end-blocks B_1 and B_2, containing cut-vertices x_1 and x_2, respectively, of H − x. Since H is 2-connected, there exist vertices y_1 ∈ V(B_1) − {x_1} and y_2 ∈ V(B_2) − {x_2} such that x is adjacent to both y_1 and y_2. Proceeding as in Case 1 with u = y_1 and w = y_2, we obtain a coloring of H with at most Δ(H) colors, once again giving us (14.2) and so χ(G) ≤ Δ(G). ▪

We have now seen a number of upper bounds for the chromatic number of a graph G of order n and two lower bounds, namely, the clique number ω(G) and another n/α(G) in terms of its order and independence number. Denns Paul Geller [102] gave a lower bound for the chromatic number of a graph in terms of its order and size.

> Theorem 14.22 If G is a graph of order n and size m, then
> χ(G) ≥ n²/(n²−2m).

Proof. Suppose that χ(G) = k. Let c be a k-coloring of G resulting in color classes V_1, V_2, …, V_k with |V_i| = n_i for 1 ≤ i ≤ k. Then the largest possible size of G occurs when G is a complete k-partite graph with partite sets V_1, V_2, …, V_k and the cardinalities of these partite sets are as equal as possible (or each |V_i| is as close to n/k as possible for 1 ≤ i ≤ k). There are (n/2) pairs of partite sets and at most (n/2)² edges joining the vertices in each pair. This implies that

m ≤ (k/2)·n²/k²    and    2m ≤ (k−1)n²/k.

Since n² − 2m ≥ n² − ((k−1)/k)n², it follows that

n²/(n²−2m) ≤ n²/(n²−((k−1)/k)n²) = k = χ(G),
giving the desired result. ▪

If G is a graph of order n and size n²/4, then certainly χ(G) ≥ 2. Actually, this cannot be improved since K_{n/2,n/2} is a bipartite graph of order n and size n²/4. On the other hand, if G is a graph of order n whose size is greater than n²/4, then χ(G) ≥ 3 since by Theorem 1.9, G has a triangle.
