Suppose that $k'$ is the maximum number of pairwise arc-disjoint $u-v$ paths in $D'$ and $\ell$ is the minimum number of arcs in a $u-v$ separating set of arcs in $D'$. By Theorem 8.10, $\ell=k'$. We show that $\ell \le \ell'$ and $k' \le k$, which will give us the desired inequality $\ell \le k$.

Let $A$ be a $u-v$ separating set of arcs in $D'$ with $|A| = \ell'$. Thus, $A$ contains no arc of the form $(z,u)$ or $(v,z)$ where $z \neq u,v$. Each arc $a \in A$ is either of the form

$a=(u,x')$, $a=(x',x'')$, $a=(y',x')$ or $a=(x',v)$

for some vertices $x,y \in V(D) \setminus \{u,v\}$. Regardless of what the arc $a$ is, denote the vertex $x$ involved in $a$ by $w_{a}$. Furthermore, let

$W=\{w_{a}: a \in A\}$ so that $W \subseteq V(D) \setminus \{u,v\}$

and $|W| \le |A| = \ell'$. Since $A$ is a $u-v$ separating set of arcs in $D'$, the set $W$ is a $u-v$ separating set of vertices in $D$. Thus, $\ell \le |W| \le \ell'$ and so $\ell \le \ell'$.

Next, let $P_{1}', P_{2}', \dots, P_{k}'$ be a collection of $k'$ pairwise arc-disjoint $u-v$ paths in $D'$. Then each path $P_{i}'$ ($1 \le i \le k$) is of the form

$P_{i}'=(u,x_{1}',x_{1}'',x_{2}',x_{2}'', \dots, x_{r}',x_{r}'',v)$

and gives rise to the path

$P_{i}=(u,x_{1},x_{2}, \dots, x_{r},v)$.

From the manner in which the digraph $D'$ is constructed and the fact that $P_{1}', P_{2}', \dots, P_{k}'$ are pairwise arc-disjoint, it follows that $P_{1}, P_{2}, \dots, P_{k}$ are internally disjoint $u-v$ paths in $D$. Thus, $k \ge k'$. Hence, $\ell \le \ell' = k' \le k$ and so $\ell \le k$.
