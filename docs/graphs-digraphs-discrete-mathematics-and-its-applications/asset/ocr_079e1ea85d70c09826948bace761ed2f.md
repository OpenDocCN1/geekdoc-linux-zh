# List Colorings

We saw in Theorem 15.18 that if $r$ and $k$ are positive integers such that $r \ge {2k-1 \choose k}$, then $\chi_{\ell}(K_{r,r}) \ge k+1$. Here, we use the probabilistic method to verify that $[2\log_2 r]$ is an upper bound for $\chi_{\ell}(K_{r,r})$, a result initially stated without proof in Theorem 15.19.

# Theorem 21.2 For every integer $r \ge 3$,

$$\chi_{\ell}(K_{r,r}) \le [2\log_2 r].$$

Proof. Let $U_0$ and $U_1$ denote the partite sets of $K_{r,r}$, where then $|U_0| = |U_1| = r$. For each vertex $v$ of $K_{r,r}$, let $L(v)$ denote a list of $[2\log_2 r]$ colors that are allowable for $v$. Let $L = \bigcup L(v)$, where the union is taken over all vertices $v$ of $K_{r,r}$. Thus, $L$ is the set of all colors under consideration. Suppose that $|L| = n$. We now show that there is a proper coloring of $K_{r,r}$ where each vertex $v$ is assigned a color from its list $L(v)$.

For each of the $2^n$ subsets $L_0$ of $L$, let $L_1 = L - L_0$. Suppose that there is a subset $L_0$ of $L$ such that

$$L_0 \cap L(u) \ne \emptyset \text{ for each } u \in U_0 \quad (21.5)$$

and

$$L_1 \cap L(w) \ne \emptyset \text{ for each } w \in U_1 \quad (21.6)$$

In such a case, each vertex $u_0 \in U_0$ is assigned a color in $L_0 \cap L(u_0)$ and each vertex $u_1 \in U_1$ is assigned a color in $L_1 \cap L(u_1)$. Because $L_0 \cap L_1 = \emptyset$, this results in a proper coloring of $K_{r,r}$ and so $\chi_{\ell}(K_{r,r}) \le [2\log_2 r]$.
