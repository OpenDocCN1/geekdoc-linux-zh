Proof.   By Theorem 17.1, $\chi'(G) \geq \frac{m}{\alpha'(G)}$. Thus,

$$\chi'(G) \geq \frac{m}{\alpha'(G)} > \frac{\alpha'(G) \cdot \Delta(G)}{\alpha'(G)} = \Delta(G),$$

which implies that $\chi'(G) = 1 + \Delta(G)$ and so $G$ is of Class two.

If $G$ is a graph of order $n$, then $\alpha'(G) \leq [\frac{n}{2}]$. Therefore, the largest possible value of $\alpha'(G) \cdot \Delta(G)$ is $[\frac{n}{2}] \cdot \Delta(G)$. A graph $G$ of order $n$ and size $m$ is called **overfull** if $m > [\frac{n}{2}] \cdot \Delta(G)$. If $n$ is even, then $[\frac{n}{2}] = n/2$ and

$$2m = \sum_{v \in V(G)} \deg v \leq n \Delta(G).$$

Therefore, $m \leq (n/2) \cdot \Delta(G) = [\frac{n}{2}] \cdot \Delta(G)$ and so $G$ is not overfull. Thus, no graph of even order is overfull.

Since $\alpha'(G) \leq [\frac{n}{2}]$ for every graph $G$ of order $n$, Theorem 17.8 has an immediate corollary (see Exercise 15).

> **Corollary 17.9**   *Every overfull graph is of Class two.*
