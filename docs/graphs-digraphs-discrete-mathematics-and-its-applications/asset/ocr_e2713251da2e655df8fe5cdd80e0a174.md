# **The Total Coloring Conjecture** For every graph $G$,

$\chi''(G) \leq 2+\Delta(G)$.

The sum of the chromatic number and chromatic index of a graph is always an upper bound for the total chromatic number of the graph.

# **Theorem 18.19** If $G$ is a nonempty graph, then

$\chi''(G) \leq \chi(G)+\chi'(G).$

**Proof.** Suppose that $\chi(G)=k$ and $\chi'(G)=\ell$. Then there is a $k$-vertex coloring of $G$ using the colors $1,2,\ldots,k$ and an $\ell$-edge coloring of $G$ using the colors $k+1, k+2,\ldots,k+\ell$. Since such a coloring of $V(G) \cup E(G)$ also assigns distinct colors to every incident vertex and edge, this produces a $(k+\ell)$-total coloring of $G$ and so $\chi''(G) \leq k+\ell = \chi(G)+\chi'(G)$. $\blacksquare$

Since $3=\chi''(\mathrm{K}_{2})+\chi'(\mathrm{K}_{2})=\chi(\mathrm{K}_{2})=2+1$, equality is possible in Theorem 18.19. On the other hand, if $G$ is a graph with $\chi(G) \geq 3$ and $\chi'(G)=\chi(G)+\chi'(G)$, then $\chi''(G)=\chi(G)+\chi'(G) \geq 3+\Delta(G)$, which would provide a counterexample to the Total Coloring Conjecture. No such counterexample is possible, as the following result of Mehdi Behzad, Gary Chartrand and John K. Cooper, Jr. [16] shows.

# **Theorem 18.20** Let $G$ be a nonempty graph. If $\chi''(G)=\chi(G)+\chi'(G)$, then $G$ is bipartite.

**Proof.** Suppose that $G$ is a graph that is not bipartite. Then $G$ is a graph of order at least 3 such that $\chi(G)=k$ for some integer $k \geq 3$ and so $V(G)$ can be partitioned into $k$ vertex color classes (independent sets) $V_{1}, V_{2},\ldots,V_{k}$. Suppose that $\chi'(G)=\ell$. Then $E(G)$ can be partitioned into $\ell$ edge color classes $E_{1}, E_{2},\ldots,E_{\ell}$. For each edge $e=wv \in E_{\ell}$, there is a set $V_{i}$ ($1 \leq i \leq k$) containing neither $u$ nor $v$. We move $e$ from $E_{\ell}$ to $V_{i}$. After moving each edge of $E_{\ell}$ to one of the sets $V_{1}, V_{2},\ldots,V_{k}$ in this manner, $k$ new sets $X_{1}, X_{2},\ldots,X_{k}$ are produced such that $V_{i} \subseteq X_{i}$ for all $i$ ($1 \leq i \leq k$) and $E_{\ell} \subseteq \cup_{i=1}^{k} X_{i}$. We now assign the color $i$ ($1 \leq i \leq k$) to each element of $X_{i}$ and assign the color $k+j$ to each edge of $E_{j}$ ($1 \leq j \leq \ell-1$). This produces a $(k+\ell-1)$-total coloring of $G$ and so

$\chi''(G) \leq k+\ell-1=\chi(G)+\chi'(G)-1.$

Thus, $\chi''(G) \neq \chi(G)+\chi'(G)$. $\blacksquare$

We now present an infinite class of (necessarily bipartite) graphs $G$ for which $\chi''(G)=\chi(G)+\chi'(G)$.
