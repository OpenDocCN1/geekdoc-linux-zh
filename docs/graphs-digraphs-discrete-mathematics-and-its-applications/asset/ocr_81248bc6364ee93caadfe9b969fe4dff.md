2. Let G be a graph having a nowhere-zero k-flow for some integer k ≥ 2.
Prove that for each partition \{E₁, E₂\} of E(G), there exists a nowhere-zero k-flow \varphi such that \varphi(e) > 0 if and only if e \in E₁.
