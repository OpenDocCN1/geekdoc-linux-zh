40. A graph $G$ is defined to be $k$-degenerate, $k \geq 0$, if $\delta(H) \leq k$ for every induced subgraph $H$ of $G$. The 0-degenerate graphs are the empty graphs, the 1-degenerate graphs are the forests and every planar graph is 5-degenerate (by Corollary 10.5). A $k$-degenerate graph is **maximal k-degenerate** if, for every two nonadjacent vertices $u$ and $v$ of $G$, the graph $G + uv$ is not $k$-degenerate.

For $k \geq 0$, let $\mathcal{P}_k$ denote the family of $k$-degenerate graphs. Then $\chi_{\mathcal{P}_k}(G)$ is the minimum number of subsets into which $V(G)$ can be partitioned so that each subset induces a $k$-degenerate subgraph of $G$. A graph is said to be $\ell$-critical with respect to $\chi_{\mathcal{P}_k}$, $\ell \geq 2$, if $\chi_{\mathcal{P}_k}(G) = \ell$ and $\chi_{\mathcal{P}_k}(G - v) = \ell - 1$ for every $v \in V(G)$.

(a) Prove that if $G$ is a maximal $k$-degenerate graph of order $n$, where $n \geq k + 1$, then $\delta(G) = k$.

(b) Determine $\chi_{\mathcal{P}_k}(K_n)$.

(c) Prove that if $G$ is a graph that is $\ell$-critical with respect to $\chi_{\mathcal{P}_k}$, then $\delta(G) \geq (k+1)(\ell-1)$.

56. By a proper $k$-coloring of a graph $G$ is meant a function $c : V(G) \to N_k = \{1, 2, \dots, k\}$ such that $c(u) \neq c(v)$ if $uv \in E(G)$. This can also be defined as a function $c : V(G) \to \mathcal{P}(N_k)$, the power set of $N_k$, such that $|c(x)| = 1$ for each $x \in V(G)$ and $c(u) \cap c(v) = \emptyset$ if $d(u, v) = 1$, where no condition is placed on pairs $u, v$ of vertices if $d(u, v) \geq 2$. A 2-tone $k$-coloring of $G$ is a function $c : V(G) \to \mathcal{P}(N_k)$ such that $|c(x)| = 2$ for each $x \in V(G)$ and $c(u)\cap c(v) = \emptyset$ if $d(u, v) = 1$ and $|c(u)\cap c(v)| \leq 1$ if $d(u, v) = 2$, where there is no condition placed on $c(u) \cap c(v)$ if $d(u, v) \geq 3$. The 2-tone chromatic number $\chi_2(G)$ of $G$ is the minimum $k$ for which $G$ has a 2-tone $k$-coloring.

(a) Prove that if the maximum degree of a graph $G$ is $\Delta$, then $\chi_2(G) \geq \left\lceil \frac{5 + \sqrt{8\Delta+1}}{2} \right\rceil$.

(b) Compute $\chi_2(C_5)$ and $\chi_2(C_6)$, thereby showing that there are graphs for which the bound in (a) is attained and graphs for which the bound in (a) is not attained.
