The most common way of drawing the Petersen graph $P$ can be described by beginning with a 5-cycle $C = (u_1, u_2, u_3, u_4, u_5)$ and five additional vertices $w_1, w_2, w_3, w_4, w_5$ along with the five edges $u_iw_i$ ($1 \leq i \leq 5$). Then each vertex $w_i$ is joined to $w_{i \pm 2}$ (subscripts expressed as $1,2,3,4,5$ modulo 5). Then this results in the 5-cycle $C' = (w_1, w_3, w_5, w_2, w_4, w_1)$.

The McGehee graph (the unique 7-cage) can be constructed in a somewhat similar manner. In this case, we begin with an 8-cycle $C = (u_1, u_2, \dots, u_8, u_1)$, eight additional vertices $w_1, w_2, \dots, w_8$ and the eight edges $u_iw_i$ ($1 \leq i \leq 8$). Then each vertex $w_i$ is joined to $w_{i \pm 3}$ (subscripts expressed as $1, 2, \dots, 8$ modulo 8). This produces the 8-cycle $C' = (u_1, w_4, w_7, w_2, w_5, w_8, w_3, w_6, u_1)$. See Figure 19.4(a). Each edge $u_iw_i$ ($1 \leq i \leq 8$) is then subdivided once, introducing the new vertices $v_i$. The edges $v_i v_{i \pm 4}$, $1 \leq i \leq 4$, are then added to the graph, completing the construction of this 7-cage of order 24 shown in Figure 19.4(b). Consequently, $n(3,7) = 24$.
