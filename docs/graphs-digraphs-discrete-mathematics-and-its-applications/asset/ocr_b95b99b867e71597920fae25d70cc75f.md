For a vertex $x$ in a digraph $D$, recall that the out-neighborhood $N^{+}(x)$ and the in-neighborhood $N^{-}(x)$ of $x$ are defined by

```
\begin{equation} N^{+}(x)=\left\{\begin{array}{l}\left\{y \in V(D):\left\{x, y\right\} \in E(D)\right\} \quad \text { and } \\ N^{-}(x)=\left\{y \in V(D):\left\{y, x\right\} \in E(D)\right\}.\end{array}\right. \tag{8.0}\end{equation}
```

Thus $|N^{+}(x)|=\mathrm{od}\,x$ and $|N^{-}(x)|=\mathrm{id}\,x$.

For a digraph $D$ and a real-valued function $g$ defined on $E(D)$, it is convenient to introduce some notation. For subsets $X$ and $Y$ of $V(D)$, define the set $[X, Y]$ and the number $g(X, Y)$ by

```
\begin{equation} [X, Y]=\left\{\left\{x, y\right\}: x \in X, y \in Y\right\} \tag{8.0}\end{equation}
```

and

```
\begin{equation} g(X, Y)=\sum_{\left\{x, y\right\} \subseteq[X, Y]} g(x, y), \tag{8.0}\end{equation}
```

where $g(X, Y)=0$ if $[X, Y]=\emptyset$. For $x \in V(D)$,

```
\begin{equation} g^{+}(x)=\sum_{y \in N^{+}(x)} g(x, y) \quad \text { and } \quad g^{-}(x)=\sum_{y \in N^{-}(x)} g(y, x) \tag{8.1}\end{equation}
```

More generally, for $X \subseteq V(D)$,

```
\begin{equation} g^{+}(X)=\sum_{x \in X} g^{+}(x) \quad \text { and } \quad g^{-}(X)=\sum_{x \in X} g^{-}(x) \tag{8.0}\end{equation}
```

# Network Flows

A flow in a network $N$ with underlying digraph $D$, source $u$, sink $v$ and capacity function $c$ is a real-valued function $f$ on $E(D)$ satisfying

```
\begin{equation} 0 \leqslant f(a) \leqslant c(a) \text { for every arc } a \text { of } D \tag{8.2}\end{equation}
```
