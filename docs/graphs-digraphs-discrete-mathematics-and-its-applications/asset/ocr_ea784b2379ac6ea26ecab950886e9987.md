# ## Section 19.2. Extremal Subgraphs

+   3.  Determine the minimum size $m$ of a graph $G$ of order 6 such that $G$ contains a subdivision of $K_5$ as a subgraph.

+   4.  By Corollary 19.6, if $G$ is a graph of order $n$ and size at least $(k-1)n - \binom{k}{2} + 1$, where $1 \leq k < n$, then $G$ contains every tree of size $k$ as a subgraph. Show that this bound on the size of $G$ is not best possible by finding two integers $k$ and $n$ with $1 \leq k < n$ such that every graph of order $n$ and size $m$ contains every tree of size $k$ as a subgraph but $m \leq (k-1)n - \binom{k}{2}$.

+   5.  Show that every graph of order $n \geq 3$ and size $\lfloor n/2 \rfloor + 1$ contains $P_3$ as a subgraph. For each integer $n \geq 3$, describe all graphs of order $n$ and size $\lfloor n/2 \rfloor$ not containing $P_3$ as a subgraph.

+   6.  Show that every graph of order $n \geq 4$ and size $n$ contains $2K_2$ as a subgraph. For each integer $n \geq 4$, describe all graphs of order $n$ and size $n-1$ not containing $2K_2$ as a subgraph.

+   7.  For each integer $n \geq 4$, determine the smallest integer $m$ such that every graph of order $n$ and size $m$ contains $K_{1,3}$ as a subgraph. For each integer $n \geq 4$, describe all graphs of order $n$ and size $m-1$ not containing $K_{1,3}$ as a subgraph.
