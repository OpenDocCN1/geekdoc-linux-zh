If $G = P_n$, where $n \geq 2$, then $L(G) = P_{n-1}$. Thus, $L^{n-1}(G) = P_1$ and $L^k(G)$ is not defined for $k \geq n$. If $G = K_{1,3}$, then $L(G) = C_3$. If $G = C_k$ for some $n \geq 3$, then $L(G) = C_n$ and $L^k(C_n) = C_n$, for every nonnegative integer $k$. Suppose then that $G$ is a connected graph that is not a path, $K_{1,3}$ or a cycle. Then $\Delta(G) \geq 3$. Suppose that $G$ contains a vertex $u$ of degree 1. Then $G$ contains a $u - v$ path $P = (u = u_0, u_1, \ldots, u_p = v)$ of minimum length $\ell \geq 1$ where $\deg v \geq 3$. This gives rise to an $x_0 - x$ path $P'$ of length $\ell$ in $L(G)$, where $x_0$ corresponds to $u_0u_1$, $x$ corresponds to $u_{\ell-1}u_\ell$, $\deg x_0 = 1$ if $\ell \geq 2$, and $\deg x \geq 3$. By successively taking the line graph of $L(G)$, $L^2(G)$ and so on, we eventually arrive at a graph $L^k(G)$ for some $k$ where there are no end-vertices. If a connected graph $H$ contains no end-vertices but does contain vertices of degree 2, then $G$ contains a $y - z$ path (or $y - z$ cycle if $y = z$) $Q = (y = y_0, y_1, \ldots, y_t = z)$ where $t \geq 2$, $\deg y_i = 2$ for $1 \leq i \leq t - 1$, $\deg y \geq 3$ and $\deg z \geq 3$. This gives rise to a $w - x$ path $Q' = (w = w_1, w_2, \ldots, w_t = x)$ of length $t - 1$ in $L(G)$ where $w_1$ corresponds to the edge $y_0y_1$ in $G$, $w_i$ corresponds to the edge $y_{i-1}y_i$, $\deg w_i = 2$ for $2 \leq i \leq t - 1$, $\deg w_1 \geq 3$ and $\deg w_t \geq 3$. By successively taking the line graph of $H$, $L(H)$, $L^2(H)$ and so on, we arrive at a graph $L^r(H)$ in which all vertices have degree at least 3.
