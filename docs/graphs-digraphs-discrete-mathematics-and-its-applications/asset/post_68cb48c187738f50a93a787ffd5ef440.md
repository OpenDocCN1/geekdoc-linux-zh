
## 18. Total Colorings

The total chromatic number $\chi''(G)$ of a graph $G$ is the minimum positive integer $k$ for which $G$ is $k$-total colorable.

If $c$ is a total coloring of a graph $G$ and $v$ is a vertex of $G$ with $\operatorname{deg} v = \Delta(G)$, then $c$ must assign distinct colors to the $\Delta(G)$ edges incident with $v$ as well as to $v$ itself. This implies that

$$\chi''(G) \geq 1 + \Delta(G) \text{ for every graph } G.$$

Let $G = K_6 - e$ be the graph of order $n = 6$ and size $m = \binom{6}{2} - 1 = 14$ shown in Figure 18.6, where $e = xz$. Since $\Delta(G) = 5$, it follows that $\chi''(G) \geq 1 + \Delta(G) = 6$. The 7-total coloring of $G$ indicated in the figure shows that $\chi''(G) \leq 7$. We show that $\chi''(G) = 7$. Assume, to the contrary, that $\chi''(G) = 6$. Thus, there exists a 6-total coloring of $G$. No color can be assigned to more than two vertices. Suppose that some color is assigned to two vertices. Then these vertices must be $x$ and $z$. This color can be assigned to at most two edges and so this color can be used for at most four vertices and edges. If some color is assigned to one vertex, then this color can be assigned to at most two edges; while if some color is assigned to no vertices, then this color can be assigned to at most three edges. Therefore, the total number of vertices and edges that can be colored with six colors cannot exceed $4 + 5 \cdot 3 = 19$. However, since $n + m = 6 + 14 = 20$, this is a contradiction. Thus, as claimed, $\chi''(G) = 7$.

### The Total Coloring Conjecture

In the 1960s Mehdi Behzad [15] and Vadim Vizing [246] independently conjectured that, similar to the upper bound for the chromatic index established by Vizing, the total chromatic number of a graph $G$ cannot exceed the lower bound $1+\Delta(G)$ by more than 1. This conjecture has become known as the Total Coloring Conjecture.

**The Total Coloring Conjecture** For every graph $G$,

$\chi''(G) \leq 2+\Delta(G).$

The sum of the chromatic number and chromatic index of a graph is always an upper bound for the total chromatic number of the graph.

**Theorem 18.19** If $G$ is a nonempty graph, then

$\chi''(G) \leq \chi(G)+\chi'(G).$

**Proof.** Suppose that $\chi(G)=k$ and $\chi'(G)=\ell$. Then there is a $k$-vertex coloring of $G$ using the colors $1,2,\ldots,k$ and an $\ell$-edge coloring of $G$ using the colors $k+1, k+2,\ldots,k+\ell$. Since such a coloring of $V(G) \cup E(G)$ also assigns distinct colors to every incident vertex and edge, this produces a $(k+\ell)$-total coloring of $G$ and so $\chi''(G) \leq k+\ell = \chi(G)+\chi'(G)$. $\blacksquare$

Since $3=\chi''(\mathrm{K}_{2})+\chi'(\mathrm{K}_{2})=\chi(\mathrm{K}_{2})=2+1$, equality is possible in Theorem 18.19. On the other hand, if $G$ is a graph with $\chi(G) \geq 3$ and $\chi'(G)=\chi(G)+\chi'(G)$, then $\chi''(G)=\chi(G)+\chi'(G) \geq 3+\Delta(G)$, which would provide a counterexample to the Total Coloring Conjecture. No such counterexample is possible, as the following result of Mehdi Behzad, Gary Chartrand and John K. Cooper, Jr. [16] shows.

**Theorem 18.20** Let $G$ be a nonempty graph. If $\chi''(G)=\chi(G)+\chi'(G)$, then $G$ is bipartite.

**Proof.** Suppose that $G$ is a graph that is not bipartite. Then $G$ is a graph of order at least 3 such that $\chi(G)=k$ for some integer $k \geq 3$ and so $V(G)$ can be partitioned into $k$ vertex color classes (independent sets) $V_{1}, V_{2},\ldots,V_{k}$. Suppose that $\chi'(G)=\ell$. Then $E(G)$ can be partitioned into $\ell$ edge color classes $E_{1}, E_{2},\ldots,E_{\ell}$. For each edge $e=wv \in E_{\ell}$, there is a set $V_{i}$ ($1 \leq i \leq k$) containing neither $u$ nor $v$. We move $e$ from $E_{\ell}$ to $V_{i}$. After moving each edge of $E_{\ell}$ to one of the sets $V_{1}, V_{2},\ldots,V_{k}$ in this manner, $k$ new sets $X_{1}, X_{2},\ldots,X_{k}$ are produced such that $V_{i} \subseteq X_{i}$ for all $i$ ($1 \leq i \leq k$) and $E_{\ell} \subseteq \cup_{i=1}^{k} X_{i}$. We now assign the color $i$ ($1 \leq i \leq k$) to each element of $X_{i}$ and assign the color $k+j$ to each edge of $E_{j}$ ($1 \leq j \leq \ell-1$). This produces a $(k+\ell-1)$-total coloring of $G$ and so

$\chi''(G) \leq k+\ell-1=\chi(G)+\chi'(G)-1.$

Thus, $\chi''(G) \neq \chi(G)+\chi'(G)$. $\blacksquare$

We now present an infinite class of (necessarily bipartite) graphs $G$ for which $\chi''(G)=\chi(G)+\chi'(G)$.

**Theorem 18.21** *For every positive integer* $r$*,*

$\chi''(K_{r,r}) = \chi(K_{r,r}) + \chi'(K_{r,r}).$

**Proof.** Let $G = K_{r,r}$. Then $|V(G) \cup E(G)| = r^2 + 2r$. Suppose that $\chi''(G) = k$. Then $V(G) \cup E(G)$ can be partitioned into sets $X_1, X_2, \ldots, X_k$ where each set $X_i$ ($1 \le i \le k$) consists of an independent set of vertices and an independent set of edges, where no vertex of $X_i$ is incident with an edge of $X_i$. Necessarily, $|X_i| \le r$ for each $i$ ($1 \le i \le k$). Hence, $k \ge r + 2$. Since $\chi'(K_{r,r}) = r$ by König’s theorem (Theorem 17.7) and $\chi(K_{r,r}) = 2$, it follows by Theorem 18.19 that $\chi''(G) \le r + 2$ and so

$\chi''(G) = 2 + r = \chi(K_{r,r}) + \chi'(K_{r,r}),$

as desired. $\blacksquare$

Even though it is not known if $2 + \Delta(G)$ is an upper bound for the total chromatic number of every graph, the number $2 + \chi_t'(G)$ is an upper bound.

**Theorem 18.22** *For every graph* $G$*,*

$\chi''(G) \le 2 + \chi_t'(G).$

**Proof.** Suppose that $\chi_t'(G) = k$. Then

$\begin{array}{l} \chi(G) \le 1 + \Delta(G) \le 1 + \chi'(G) \le 1 + \chi_t'(G) \\ \quad < 2 + \chi_t'(G) = 2 + k. \end{array}$

Just as the chromatic index of a nonempty graph $G$ equals the chromatic number of its line graph $L(G)$, the total chromatic number of $G$ also equals the chromatic number of a related graph.

Recall that the total graph $T(G)$ of a graph $G$ is that graph for which $V(T(G)) = V(G) \cup E(G)$ and such that two distinct vertices $x$ and $y$ of $T(G)$ are adjacent if $x$ and $y$ are adjacent vertices of $G$, adjacent edges of $G$, or an incident vertex and edge. It therefore follows that

$\chi''(G) = \chi(T(G))$ for every graph $G$.
