# Exercises for Chapter 11

# Section 11.1: The Crossing Number of a Graph

+   1. Draw $K_7$ in the plane with nine crossings.

+   2. Determine $\overline{\mathrm{cr}}(K_{3,3})$ without using Theorem 11.4.

+   3. Show that $\overline{\mathrm{cr}}(K_{5,5}) \leq 16$.

+   4. Determine $\overline{\mathrm{cr}}(K_{2,2,2})$.

+   5. Determine $\overline{\mathrm{cr}}(K_{1,2,3})$.

+   6. Show that $2 \leq \overline{\mathrm{cr}}(C_3 \square C_3) \leq 3$ without using Theorem 11.6.

+   7. (a) It is known that $\overline{\mathrm{cr}}(W_4 \square K_2) = 2$, where $W_4$ is the wheel $C_4 \vee K_1$ of order 5. Draw $W_4 \square K_2$ in the plane with two crossings.
+   (b) Prove or disprove: If $G$ is a nonplanar graph containing an edge $e$ such that $G-e$ is planar, then $\overline{\mathrm{cr}}(G) = 1$.

+   8. Prove that $\overline{\mathrm{cr}}(C_3 \square C_t) = t$ for $t \geq 3$.

+   9. Give an example of a straight-line embedding of a maximal planar graph of order exceeding 4 containing exactly four vertices of degree 5 or less.

+   10. Let $G$ be a connected planar graph. Prove or disprove: If $\overline{\mathrm{cr}}(G \square K_2) = 0$, then $G$ is outerplanar.

# Section 11.2: The Genus of a Graph

+   11. Determine $\gamma = \gamma(K_{4,4})$ without using Theorem 11.19 and label the regions in a 2-cell embedding of $K_{4,4}$ on the surface of genus $\gamma$.

+   12. (a) Show that $\gamma(G) \leq \overline{\mathrm{cr}}(G)$ for every graph $G$.
+   (b) Prove that for every positive integer $k$, there exists a graph $G$ such that $\gamma(G) = 1$ and $\overline{\mathrm{cr}}(G) = k$.

+   13. Prove Theorem 11.14: If $G$ is a connected graph of order $n$ and size $m$ whose smallest cycle has length $h$, then $\gamma(G) \geq \frac{m}{2}\left(1-\frac{2}{h}\right)-\frac{n}{2}+1$.

+   14. Use Theorem 11.16 to prove Corollary 11.17: If $G$ is a graph with components $G_1, G_2, \ldots, G_k$, then $\gamma(G) = \sum_{i=1}^k \gamma(G_i)$.

+   15. Show for every two integers $s, t \geq 2$ that
+   
+   $$\gamma(K_{s,t}) \geq \left\lceil \frac{(s-2)(t-2)}{4} \right\rceil.$$
