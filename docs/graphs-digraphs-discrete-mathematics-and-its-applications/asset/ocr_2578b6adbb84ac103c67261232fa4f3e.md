Using this approach, we see that the chromatic polynomial of every graph is the sum of chromatic polynomials of complete graphs. A consequence of this observation is the following:

Theorem 16.12 The chromatic polynomial P(G, λ) of a graph G is a polynomial in λ.

# Properties of Chromatic Polynomials

There are some interesting properties possessed by the chromatic polynomial of every graph. In fact, if G is a graph of order n and size m, then the chromatic polynomial P(G, λ) of G can be expressed as

P(G, λ) = c₀λⁿ + c₁λⁿ⁻¹ + c₂λⁿ⁻² + ··· + cₙ₋₁λ + cₙ,

where c₀ = 1 (and so P(G, λ) is a polynomial of degree n with leading coefficient 1), c₁ = −n, cᵢ ≥ 0 if i is even with 0 ≤ i ≤ n, and cᵢ ≤ 0 if i is odd with 1 ≤ i ≤ n. Since P(G, 0) = 0, it follows that cₙ = 0.

The following theorem is due to Whitney [256].

Theorem 16.13 Let G be a graph of order n and size m. Then P(G, λ) is a polynomial of degree n with leading coefficient 1 such that the coefficient of λⁿ⁻¹ is −m and whose coefficients alternate in sign.

Proof. We proceed by induction on m. If m = 0, then G = K̅ₙ and P(G, λ) = λⁿ, as we have seen. Then P(K̅ₙ, λ) = λⁿ has the desired properties.
