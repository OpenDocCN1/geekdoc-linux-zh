With the aid of Corollary 6.16, a lower bound for $\mathrm{he}(G)$ in terms of $\delta(G)$ can be obtained in [45].

**Theorem 6.18** If $G$ is a graph of order $n \geq 3$ and $\delta(G) \geq n/2$, then

$\mathrm{he}(G) \geq 2\delta(G) - n + 1$.

**Proof.** If $\delta(G) = n/2$, then $2\delta(G) - n + 1 = 1$ and the theorem follows trivially. Thus, we may assume that $\delta(G) > n/2$. Hence, $\delta(G) \geq (n + 1)/2$. By Corollary 6.16, $G$ is Hamiltonian-connected, which implies that every edge of $G$ lies on a Hamiltonian cycle of $G$. Furthermore, since $\delta(G) \leq n - 1$, it follows that $2\delta(G) - n + 1 \leq n - 1$. Since $G$ is Hamiltonian, $G$ contains paths of order $2\delta(G) - n + 1$ or less. Because the result is immediate if $\delta(G) = n - 1$, we may assume that $n/2 < \delta(G) \leq n - 2$. Consequently, $n \geq 5$ and $2\delta(G) - n + 1 \geq 2$.

Let $P$ be a $u - v$ path of order $\ell$, where $3 \leq \ell \leq 2\delta(G) - n + 1$ and let $H$ be the subgraph of $G$ induced by $(V(G) - V(P)) \cup \{u, v\}$. Thus, the order of $H$ is

$n' = n - \ell + 2 \geq n - (2\delta(G) - n + 1) + 2 = 2(n - \delta(G)) + 1 \geq 5$.

Moreover,

$\begin{array}{rcl} \delta(H) & \geq & \delta(G) - \ell + 2 \geq \delta(G) - (2\delta(G) - n + 1) + 2 \
& = & n - \delta(G) + 1 = \frac{n' + 1}{2}. \end{array}$

By Corollary 6.16, $H$ is Hamiltonian-connected. Therefore, $H$ contains a Hamiltonian $u - v$ path $P'$, which, together with $P$, produce a Hamiltonian cycle of $G$ containing $P$. $\blacksquare$
