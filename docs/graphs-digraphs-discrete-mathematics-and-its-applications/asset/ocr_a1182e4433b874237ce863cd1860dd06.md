# **Minors of Graphs**

There is another characterization of planar graphs closely related to that given in Kuratowski’s theorem. Before presenting this theorem, it is useful to introduce some additional terminology. If two adjacent vertices $u$ and $v$ in a graph $G$ are identified, then we say that we have **contracted** the edge $uv$ (denoting the resulting vertex by $u$ or $v$). When dealing with edge contractions, it is often the case that we begin with a graph $G$, contract an edge in $G$ to obtain a graph $G'$, contract some edge in $G'$ to obtain another graph $G''$, and so on, until finally arriving at a graph $H$. Any such graph $H$ can be obtained in a different and perhaps simpler manner. In particular, $H$ can be obtained from $G$ by a succession of edge contractions if and only if the vertex set of $H$ is the set of elements in a partition ${V_1, V_2, ..., V_k}$ of $V(G)$ where each induced subgraph $G[V_i]$ is connected and $V_i$ is adjacent to $V_j$ $(i \ne j)$ if some vertex in $V_i$ is adjacent to some vertex in $V_j$ in $G$.
