# ## ANALYZING DISK SPACE USED BY PACKAGES

When your disk space starts to get low, you can use rpm to find the packages that are using up all your disk space. For example, use the following commands to list how much space each package on your system is consuming:

```
rpm -qa --queryformat "%-30{NAME} %{SIZE}\n" | sort
```

It can also be used to get the top ten packages:

```
rpm -qa --queryformat "%10{SIZE} %{NAME}\n" | sort -rn | head
```

For a real shock, look at the xemacs packages and see how much room they take. If you don’t use xemacs, now is a good time to remove these packages and save yourself that disk space.
