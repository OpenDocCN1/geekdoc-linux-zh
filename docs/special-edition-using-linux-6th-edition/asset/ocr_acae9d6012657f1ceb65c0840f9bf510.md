| 0 | Unnamed Devices | Reserved as null device number |

| 1 | Block | RAM disk |

| 2 | Block | Floppy disks |

| 4 | Character | TTY devices |
| 5 | Character | Alternative TTY devices |

| 7 | Block | Loopback devices |

| 12 | Character | QIC-02 tape devices |
| 12 | Block | MSCDEX CD-ROM callback support |
| 13 | Character | PC speaker |

| 14 | Character | Sound card devices |

| 15 | Character | Joystick |
