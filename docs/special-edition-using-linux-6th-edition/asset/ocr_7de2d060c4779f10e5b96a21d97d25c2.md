Notice the 320×200 in the Modes line. XFree86 will start with the first resolution it finds in the Modes line. Unless you really need to test it (it is usually less useful than it would seem), just list one mode here. Run startx and make sure it works. Then switch back to runlevel 5 with telinit 5 at the command prompt.

XFree86 doesn’t start when Linux boots.

You are in runlevel 3 instead of runlevel 5. Edit your /etc/inittab and change the id line to this:

```
id:5:initdefault:
```

When you restart your machine, XFree86 will start automatically.
