# Deleting Jobs from a Print Queue

The nwdelqjob utility enables users to delete print jobs that they submit to a NetWare print queue. By default, users can only delete their own print jobs. If you have the appropriate NDS rights, however, you can use this utility to delete other users’ print jobs. The following syntax is used (Table 28.8 shows the possible command-line options for the nwdelqjob utility):

```
nwdelqjob [OPTIONS] <JOB ID>
```

| Options | Description |
|---|---|
| `-q <QUEUE>` | Name of print queue |
