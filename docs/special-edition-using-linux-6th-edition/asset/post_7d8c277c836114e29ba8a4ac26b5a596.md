## THE ALL NEW KDE 2.0

KDE 2.0 is a nearly complete rewrite of one of the most popular desktops for Linux and other UNIX-like operating systems. Some say it should be called KDE 2 version 1.0—luckily it wasn’t. It’s definitely a big move from the last version of KDE (see Figure 1).

![](img/c741b1b6b6eccaba2ad43454c979a7f8_1_0.png)

KDE 2 provides so many new features that we can’t cover them all here (you’ll want to see Chapter 3, “KDE,” for full details), but here are just a few of the user features and “under the covers” changes in store:

- **An all-new, highly modular panel called Kicker**—Now everything is a button or applet, and because you’re free to run whatever applets you want, you’re no longer tied to the default pager, taskbar, or clock. Choose your own, get rid of them, or add extra applets, such as a quick application launcher.
- **Konqueror**—What more can we say? Konqueror is one of the best Web and file browsers ever developed. It seamlessly handles local and remote files, becoming a file manager, an FTP client, a Web browser, an image viewer, a Samba client, and much, much more. And unlike KFM, Konqueror can handle authentication and some of the most complex Web pages out there.
- **Under the covers, KDE 2 is a complete redesign**—Things are much more modular in KDE 2, improving embedding with KParts. For example, the true power behind the Konqueror browser is that it displays almost nothing. Everything is done through KParts plug-ins. Even HTML rendering is handled through the KHTML module. Now your applications can easily include a full-featured HTML renderer, an image viewer, an FTP client, and much more.
- **All this modularization isn’t just for nice features**—It also makes the features look nice. KDE 2’s theme engine is very flexible, and there are already some very pretty themes available. Buttons, borders, backgrounds, and behaviors are all configurable, and some very nice tutorials are available so you can build your own themes.

If you’re interested in a flexible, feature-rich desktop environment, KDE 2 might be just what you’re looking for. Of course, KDE 2 is just one of the many new products in the latest distributions of Linux. In this book we’ll cover many of the exciting advances over the last year, as well as the basics you’ll need to master today’s Linux.
