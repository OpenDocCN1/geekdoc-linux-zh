The six lines in the default entry section must be duplicated and modified for the second boot image to be available at boot time. The image line and the label entry must be changed to accomplish this correctly. The image entry must match the kernel name that was copied in the previous step: /boot/bzImage-2.4.10. The label entry must be unique. This label is the unique identifier that enables you to select between the choices that are configured in the /etc/lilo.conf file. The complete /etc/lilo.conf is changed to look as follows:
