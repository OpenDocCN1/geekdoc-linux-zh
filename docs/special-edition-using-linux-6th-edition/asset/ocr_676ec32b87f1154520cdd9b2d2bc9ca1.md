The dig program returns data in a format that is usable directly by the DNS server, making updates like this easy. Remarks are marked with ;; by dig. The header section shows you the options that are set for this dig query, but not necessarily those that are used. The HEADER tells you that this was a query that returned no errors. The authority section provides a simplified (translated from seconds) readout of the expire time, the time after which the DNS server that obtained these results needs to stop using them. The interminic expires its root servers at six weeks (604,800 seconds).
