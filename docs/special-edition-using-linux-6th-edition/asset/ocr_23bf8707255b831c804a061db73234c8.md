The /etc directory contains both directories and configuration files. Each of the directories contains configuration files for a specific area. Table 10.2 lists the subdirectories of the /etc directory and a description of each. Your /etc directory can vary from the listing above depending on what you have installed.

**TABLE 10.2 — SUBDIRECTORIES OF THE /etc DIRECTORY**

| Subdirectory | Description |
|---|---|
| X11 | Contains configuration data for the X Window server as well as several window managers. |
| am.d | Contains configuration files for the automounter daemon. |
