# ANDERS: NETATALK: LINUX NETATALK-HOWTO

http://thehamptons.com/anders/netatalk/

Netatalk is a package that allows a UNIX machine to supply AppleTalk print and file services on a LAN. The package supports AppleShare IP and classic AppleTalk protocols. With Netatalk, Macintosh computers can mount UNIX volumes and print to UNIX print spools as if they were standard AppleTalk network devices.
