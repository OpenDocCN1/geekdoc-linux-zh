Finally, (for here), Enlightenment almost defines the idea of themes. Figure 4.17 shows the Blue Steel theme that comes with Enlightenment, but over 200 more are at e.themes.org. To switch themes, middle-click the desktop and select Themes. Note that these themes are for the window manager and are separate from GNOME’s themes. To select GNOME’s themes, use the Control Center, Theme Selector.

There is so much to say about Enlightenment that I can’t possibly cover it all here. Many people don’t like E because it’s huge, slow, and unstable (very sensible reasons!), but if you like a flashy desktop and a fast machine, you might just give Enlightenment a try.
