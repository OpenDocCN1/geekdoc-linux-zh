
要更改OPENLINUX NetWare服务器bindery中用户jsmith的密码，请执行以下命令：

```text
nwpasswd -s /NetWare/bindery/OPENLINUX -u jsmith
```

除了更改用户密码，你还可以使用nwunlpasswd实用程序通过以下语法删除bindery用户的密码：

```text
nwunlpasswd -o <PATH>
```

`<PATH>` 是bindery对象的NetWare自动挂载路径。

> **注意**
>
> 与Linux一样，NetWare密码不区分大小写。

## 删除 Bindery 对象

用于删除bindery对象的实用程序是nwborm。使用的语法如下：

```text
nwborm -o <PATH>
```

`<PATH>` 是被删除对象的NetWare自动挂载路径。

你可以通过执行以下命令从OPENLINUX NetWare服务器bindery中删除名为john的用户：

```text
nwborm -o /NetWare/bindery/OPENLINUX/objects/JOHN
```

> **警告**
>
> 命令执行后，你将返回到命令提示符。没有任何确认。对象删除后无法恢复。如果删除了需要恢复的对象，你唯一的选择是恢复整个bindery或重新创建被删除的对象（后者更安全，因为恢复可能会清除自备份以来对bindery所做的更改）。

删除用户对象时，主目录不会被删除。删除用户对象后，你必须手动删除主目录。

## 设置目录大小限制

nwbosetspace 实用程序用于设置NetWare目录的大小限制。使用的语法如下（表28.26显示了nwbosetspace可能的命令行选项）：

```text
nwbosetspace [OPTIONS]
```

**表28.26 — nwbosetspace 的命令行选项**

| 选项 | 说明 |
| --- | --- |
| `-d <PATH>` | 要设置限制的目录的NetWare自动挂载路径 |
| `-b <BLOCKS>` | 目录大小限制，以4K块的数量指定 |
| `-h` | 显示命令帮助 |

要为OPENLINUX服务器上的`SYS:groups\acctg`目录设置400KB的目录大小限制，请执行以下命令：

```text
nwbosetspace -d /NetWare/bindery/OPENLINUX/volumes/SYS/groups/acctg -b 100
```

## 查看目录大小限制

nwboshowspace 实用程序用于显示应用于NetWare目录的目录大小限制。使用的语法如下：

```text
nwboshowspace -d <PATH>
```

`<PATH>` 是被查询目录的NetWare自动挂载路径。

## 向 Bindery 对象授予 NetWare 文件系统权限

使你能向bindery对象授予NetWare文件系统权限的两个实用程序是nwborights和nwborightsDD。使用的语法如下（表28.27显示了nwborightsDD实用程序可能的命令行选项）：

```text
nwborights -o <OBJECT PATH>
```

```text
nwborightsDD [OPTIONS]
```

**表28.27 — nwborightsDD 的命令行选项**

| 选项 | 说明 |
| --- | --- |
| `-o <OBJECT PATH>` | 将被授予bindery对象权限的NetWare自动挂载路径 |
| `-p <PATH>` | 将被授予权限的文件所在目录的NetWare自动挂载路径 |
| `-h` | 显示命令帮助 |

这两个实用程序都是图形化的，允许向指定的bindery对象授予文件系统权限。nwborights实用程序使你能够通过选择要授予权限的服务器和卷，在文件系统上的多个位置授予和修改权限。

nwborightsDD实用程序使你能够向指定的目录或文件授予或修改指定对象的权限。

要为OpenLinux NetWare服务器bindery中的用户jsmith授予或修改多个目录或文件的权限，请执行以下命令：

```text
nwborights -o /NetWare/bindery/OPENLINUX/objects/JSMITH
```

图形实用程序启动后，你需要执行以下操作：

1. 选择服务器（注意，这必须是用户所在的bindery服务器）。
2. 通过单击“新受托人目录（New Trustee Directory）”字段旁边的搜索按钮浏览文件系统。
3. 进行权限分配并单击“确定”。

授予或修改用户jsmith对`SYS:groups\acctg`目录的权限可以通过以下命令完成：

```text
nwborightsDD -o /NetWare/bindery/OPENLINUX/objects/JSMITH -p /NetWare/bindery/OPENLINUX/volumes/SYS/groups/acctg
```

图形实用程序启动后，你可以通过单击相应的单选按钮并单击“修改权限（Modify Rights）”按钮来修改权限。

> **注意**
>
> 对于前面列出的两个实用程序，请将“Change”选项视为“Create”权限。

## 项目：使用 ncpfs 软件包

在当今所有可用的Linux发行版中，Caldera的OpenLinux是第一个也是唯一一个提供商业且完全授权的NetWare客户端和服务器的实现，它支持最新的Novell标准，包括对NDS的支持——这并不奇怪，因为Caldera是由Novell前首席执行官Ray Noorda创立的。然而，如果没有OpenLinux，你该如何访问NetWare资源呢？由Volker Lendecke开发的ncpfs软件包就是你的答案！ncpfs软件包允许Linux机器挂载网络连接的NetWare文件服务器上的卷。ncpfs还包含允许Linux客户端向NetWare打印和从NetWare打印的工具。

> **注意**
>
> 要使用最新版本的ncpfs，你必须使用内核1.3.71或更新版本；这包括2.0.*内核。如果你使用的是1.3.71或更新版本的内核，那么ncpfs内核代码已包含在标准内核发行版中。你只需要对提示回答Y：
>
> ```text
> Networking options  -->
>     ...
>     <*> The IPX protocol
>     ...
> Filesystems  -->
>     ...
>     <*> NCP filesystem support (to mount NetWare volumes)
> ```
>
> 然后你可以从下面的第5步开始。

使用以下步骤通过ncpmount访问你的NetWare服务器：

1. 下载Volker的ncpfs软件包，该软件包在大多数现代Linux发行版中已预打包，或以源代码形式从`ftp://ftp.gwdg.de/linux/misc/ncpfs/`或`ftp://sunsite.unc.edu`或其镜像站点获得。编写本书时的当前版本是`ncpfs-2.0.11.tgz`或添加了NDS支持的`ncpfs-2.2.0.tgz`。

2. 确保你的IPX网络接口配置正确（更多细节请参阅第18章“构建自定义内核”）。

3. 安装ncpfs软件包，首先cd到放置下载文件的目录。

4. 接下来，解压该文件：

   ```text
   # tar xvzf ncpfs-2.0.11.tgz
   ```

   你需要cd到ncpfs，因为解压后的文件放在那里。

   > **注意**
   >
   > 如果你打算使用kerneld自动加载ncpfs内核模块，则必须取消makefile中引用KERNELD的那一行的注释。

5. 通过执行make命令编译软件。

6. make完成后，你应该在ncpfs/bin目录中找到所需的所有工具。你可以执行make install将工具安装到其他目录。如果你在基于ELF的系统上运行，则需要重新运行ldconfig -v以确保可以找到共享库。

   > **注意**
   >
   > 如果你正在为1.2.*内核编译，那么make完成后你会在ncpfs/bin目录中找到名为ncpfs.o的文件。这是ncpfs内核模块。你应该把它复制到某个有用的地方。例如，在Debian系统上，将其复制到/lib/modules/1.2.13/fs目录，并将ncpfs添加到/etc/modules文件中，以便在启动时自动加载。如果你使用其他发行版，你应该找到其模块目录并将其复制到那里，或者你可以直接将其复制到你的/etc目录。要手动加载模块，你需要使用命令：
   >
   > ```text
   > # insmod ncpfs.o
   > ```

7. 在挂载NetWare卷之前，你必须知道要挂载的NetWare服务器上的登录详细信息；这包括用户ID和密码。你还需要知道要挂载哪个卷以及要将其挂载到哪个本地目录下（例如，挂载点）。

8. 假设你的NetWare服务器名为TEST1，你的登录ID是linux，密码是novell。如果要将DATA1:卷挂载到你的/mnt/data1目录下，ncp挂载命令如下所示：

   ```text
   # ncpmount -S TEST1 /mnt/data1 -U linux -P novell -V DATA1
   ```

有关ncpmount、ncpumount的更多信息，请参阅man手册页，并探索ncpfs软件包中包含的其他实用程序，例如slist、nsend等。
