# Linux Professional Institute (LPI)

http://www.lpi.org/

The Linux Professional Institute offers Linux certification. Although the tests cost money, LPI is non-profit and makes no money from the certifications. The tests are designed and written by the International Linux community in as open a way as possible while still protecting the integrity of the tests.
