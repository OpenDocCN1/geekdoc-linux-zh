## What Linux Distributions Are Covered in This Book?

### Caldera OpenLinux 3.0 (eDesktop and eServer)

Caldera OpenLinux is a 32-bit, proven, tested, stable, and supported Linux-based operating system and business solution that is easy to use, self-hosted, and includes the full Linux source code with matching binaries and integrated programs and tools. Caldera OpenLinux was labeled the “Windows Killer” by Nicolas Petreley in *InfoWorld*. eDesktop 2.3 claimed the Editor’s Choice Award for the best Linux client at last year’s LinuxWorld Expo. And eServer 2.3 was given the *Network World’s* Blue Ribbon, topping the list of server-side distributions. Caldera’s eDesktop features a rock-solid operating system and a fully graphical installation process that other Linux vendors are rushing to imitate.

### Red Hat Linux 7.0

Red Hat Linux is the leader in the market. Red Hat is known for including the latest features for the Linux operating system. Red Hat features both the KDE and GNOME desktop managers. Red Hat was also voted a “LinuxWorld Favorite” by the attendees of the two most recent LinuxWorld Expos, winning Best Server Distribution at the August 2000 show.

### Debian GNU/Linux 2.2

Debian GNU/Linux features integrated SGML and XML infrastructure and packages. It is a truly open-source Linux operating system that comes with more than 3950 packages bundled in a format for easy installation. Debian GNU/Linux also was recently voted a “LinuxWorld Favorite” for Distribution/Client.
