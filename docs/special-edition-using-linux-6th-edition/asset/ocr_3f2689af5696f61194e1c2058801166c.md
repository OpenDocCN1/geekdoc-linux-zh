```

Notice the line referencing /etc/config.d/shells/bashrc. This line instructs bash to check to see whether the file /etc/config.d/shells/bashrc exists and is readable by the user, and if so, execute it. This is a bash-specific configuration file for global use similar to /etc/profile. The difference between them is that /etc/profile is for all Bourne shells, whereas the commands in bashrc are specific (or should be) to bash. Listing 14.3 shows what the default global bashrc file looks like.
```
