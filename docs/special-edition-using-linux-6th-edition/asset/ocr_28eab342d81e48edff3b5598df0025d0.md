An alias can also be used to set up small (usually internal) mailing lists. For larger, departmental lists, you can use `include` statements to include file lists. Large mailing lists should be handled with a mailing list program such as majordomo. To create a small mailing list, put the name of the mailing list in `/etc/mail/aliases` followed by a comma-separated list of users:

```
```text
maillistname:     john,sally,mike,andrew
```
