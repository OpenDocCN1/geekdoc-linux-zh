# # X RESOURCES

Many older X applications rely on resources for configuration. Resources are key-value data that are stored centrally via the X server. Resources are stored in a hierarchy of classes and instances. Each instance has a value. This is easiest to describe by way of some examples. Listing 6.1 shows typical resource entries. These would generally be found in a file called `${HOME}/.Xdefaults`. Note that the numbers in italics indicate line numbers and are not actually in the file.
