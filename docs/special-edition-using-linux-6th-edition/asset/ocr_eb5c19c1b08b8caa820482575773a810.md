When you have downloaded the appropriate packages for your distribution, install them.\nOn RPM-based systems, for example:

```
`# rpm -i enlightenment-0.16.4-1.i386.rpm`
```

On Debian, add the following line to /etc/apt/sources.list and run dselect normally:

```
`deb http://www.debian.org/~ljlane/downloads enlightenment/`
```

Next, open the Control Panel and select Desktop, Window Manager. Enlightenment should\nshow up automatically in the list. If it doesn’t, add it by clicking Add and entering the fol-\nlowing information:

+   - Name: Enlightenment\n- Command: enlightenment\n- Configuration Command: e-conf\n- Select Window Manager is Session Managed.

Select Enlightenment, click OK, and hold on. When Enlightenment finishes initializing,\nyour desktop will resemble Figure 4.13.
