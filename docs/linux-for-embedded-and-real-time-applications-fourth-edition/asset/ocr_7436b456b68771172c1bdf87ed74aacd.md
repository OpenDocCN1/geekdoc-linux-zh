through each configuration option. For each option you have either three or four choices. The three choices are: "y" (yes), "n" (no), and "?" (ask for help). The default choice is shown in upper case.

Some options have a fourth choice, "m", which means build this feature as a loadable kernel module rather than build it into the kernel image. Kernel modules are a way of dynamically extending the kernel, and are particularly useful for things like device drivers.
