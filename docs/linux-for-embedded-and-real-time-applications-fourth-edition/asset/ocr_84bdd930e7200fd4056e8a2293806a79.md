In this chapter, we will explore a growing trend in embedded Linux development—the use of integrated build environments to build all or part of an embedded Linux distribution.

# The Problem

There are a number of elements that go into an embedded development environment. These include among others:

+   *   Cross-tool chain
+       *   Editor
+       *   Compiler
+       *   Linker
+       *   Debugger
+       *   Libraries
+   *   Bootloader
+   *   Linux kernel
