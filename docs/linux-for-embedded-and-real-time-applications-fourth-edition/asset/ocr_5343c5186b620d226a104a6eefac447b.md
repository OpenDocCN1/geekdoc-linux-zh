There’s one more step before CentOS finally lets you log in and start up the graphical desktop. You are asked to enable and configure Kdump, a kernel crash dumping mechanism. Your call. I’ve never used it but I leave it enabled.

Following that, you’ll have a fully functional Linux installation. Reboot it when you’re ready for the next chapter where we’ll review many of the useful features of Linux.
