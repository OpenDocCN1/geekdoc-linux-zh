There are a couple other options for flashing the eMMC. Robert Nelson, an applications engineer with DigiKey, has done substantial work on the BeagleBone and BBB. Among other things, he has created a collection of scripts for building eMMC flasher images, and then flashing them to the eMMC. This might be a useful approach if, for example, you wanted to build your own minimal root file system. He has another project to do a net install. The resources section has the links for both.

OK, the thermostat application is now burned into flash, and we are ready to ship. In the next chapter we will turn our attention to source code control.
