**launch configuration** icon. Fig. 8.12, shows the final values for this configuration. The top part of the Main tab looks like what you have seen before, selecting the **Application** and the **Project**. Again, it is probably best to select **Disable auto build**.

In the **Connection** drop-down, select the remote connection that you just created. Next, we have to tell GDB where to find the executable on the remote target. Enter the path to `thermostat_t` **on the target**. In most cases, RSE would have to “download” the executable in order to execute and debug it on the remote machine. In our case, of course, the executable is already visible to the target in the NFS-mounted file system, so check **Skip download to target path**. If you do choose to let RSE download the executable, do not use the current location, because it will try to overwrite itself and fail. Try /home/samples/src. The **Commands to execute before application** entry might be a good place to put the scripts that turn off the LED triggers and enable the ADC subsystem.

Go to the **Debugger** tab, and enter “arm-linux-gdb” for the **GDB debugger**. Select the **Gdbserver Settings** tab, and set the port to 10,000.
