# lpd

lpd [ option ]
Launches the print spooling daemon. Normally, this is done by a system initialization script, but it can also be launched by a user. When the daemon starts, it consults the default configuration file (usually /etc/printcap); subsequently, it runs in the background, waiting for print requests.

# OPTIONS

| Use This Option | To Do This |
| :--- | :--- |
| -L logfile | Use the specified log file for error and debugging messages. |
| -F | Force the server to run in the foreground. By default, it runs in the background. |
| -V | Display version information. |
