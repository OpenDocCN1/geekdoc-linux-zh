# logout

**logout**
Exits the current session and displays login. This command should be used in text mode sessions only. Do not use it when X is running.

# rlogin

**rlogin [ option ] [ _hostname_ ]**
Enables you to establish a user session on another computer connected to the local area network or the Internet, provided that the remote computer is configured to accept remote logins.

# OPTION

| Use This Option | To Do This |
| :--- | :--- |
| -l _username_ | Log in with a specific username |

# EXAMPLE

| This Command | Does the Following |
| :--- | :--- |
| rlogin -l suzanne lothlorien.paffenberger.org<br>or<br>rlogin -l suzanne 192.168.100.10 | Establishes a remote terminal session on lothlorien.paffenberger.org for the user named suzanne. |
