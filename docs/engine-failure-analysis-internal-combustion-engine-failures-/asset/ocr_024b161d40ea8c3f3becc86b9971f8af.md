[Dialer MyConnection]
Username = suzanne
Password = iw2mfc
Phone = 555-1212
Dial Prefix = 9,,
Area Code = 800

This configuration dials 9, waits two seconds, and then dials 800-555-1212. When the ISP responds, it supplies the username *suzanne* and the password *iw2mfc*, and establishes the connection using the ISP's preferred authentication method.

# exports

**exports [ option ] [ client:path ]**

Used after you have made modifications to the Network File System (NFS) export configuration file (*etc/exports*), this utility creates the table of exported filesystems located in */var/lib/nfs/xtab*. This file is read by the NFS mount daemon (rpc.mountd), and must be up to date if the mount is to succeed.
