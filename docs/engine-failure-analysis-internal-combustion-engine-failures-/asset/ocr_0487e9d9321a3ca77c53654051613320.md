# EXAMPLES

**This Command**
man du
man –a less
man –f file
man 1 –K file  **Does the Following**
Displays the du (disk usage) man page.
Displays all the man pages that match the title less.
Displays a list containing brief descriptions of all the man pages that match the title file.
Displays all the man pages from Section 1 (executable commands and utilities) that contain the word file.
