# VI KEYBOARD SHORTCUTS (CONT.)

Use This Keyboard Shortcut To Do This
Ctrl + w, q Close the current window.
Ctrl + y or up arrow or k Move up one line.
cw Change the current word.
D Delete the remainder of the line.
d^ Delete back to the beginning of the line.
d/string Delete up to the next occurrence of the specified string.
D) Delete up to the next paragraph.
dd Delete the current line.
Delete Delete the current character.
df pattern Delete up to and including the specified pattern on the current line.
dG Delete to the end of the file.
dL Delete up to the last line on the screen.
dt pattern Delete up to but not including the specified pattern on the current line.
dw Delete the current word.
End Move to the end of the line.
Esc Exit insert mode.
Home Move to the beginning of the line.
i Insert text before the cursor.
I Insert text at the beginning of the line.
Left arrow or h Move left one character.
o Open a line below the current line.
O Open a line above the current line.
p Insert the contents of the current register after the cursor.
P Insert the contents of the current register before the cursor.
R Begin overwriting the text at the cursor.
