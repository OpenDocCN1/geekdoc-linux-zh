# EXAMPLES

+   **This Command**
+   
+   - `gawk '/Rich/ { print $0 }' *.txt`
+   - `gawk '/Rich/ { print $0 } /Laura/ { print $0 } /Lydia/ { print $0 } *.txt`
+   - `gawk '$1 ~/Astronomy/ { print $0 }' dissertation.doc`
+   - `gawk '$4 ~ /B/ { print "Students receiving a B were:" $1, $2 }' grades.txt`
+   - `gawk '$1 ~ /Zapf/ { print "File:" FILENAME " Line:" NR " = " $0 }' *.txt`

+   **Does the Following**
+   
+   - Searches all the files in the working directory that have the `.txt` extension for lines containing *Rich* and displays the lines on-screen.
+   - Searches all the files in the working directory that have the `.txt` extension for lines containing *Rich, Laura, or Lydia.* Displays the lines on-screen. Each AWK statement must be typed on its own line, followed by a newline (Enter).
+   - Searches *dissertation.doc* for all lines that begin with *Astronomy* and displays the lines on-screen.
+   - Search *grades.txt* for lines in which the fourth field ($4) contains *B* and prints the first two fields ($1 and $2) with the message, "Students receiving a B were ...."
+   - Finds all lines in all the text (*.txt*) files of the working directory that begin with *Zapf* and prints them in a format that looks like this:
+     `File: fonts.txt Line: 443 Zapf Dingbats`
