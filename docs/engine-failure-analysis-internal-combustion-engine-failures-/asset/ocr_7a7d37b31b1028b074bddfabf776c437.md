# PROMPT EXPANSION

Use This Option
%b< t | m | b | B | j >
%B
%D

To Do This
Display the byte offset in the current input file at one of the following lines:
t The top line.
m The middle line.
b The bottom line.
B The next line after the bottom line.
j The target line as specified by -j.
Display the size of the current input file.
Display the number of pages in the input file or, equivalently, the page number of the last line in the input file.
