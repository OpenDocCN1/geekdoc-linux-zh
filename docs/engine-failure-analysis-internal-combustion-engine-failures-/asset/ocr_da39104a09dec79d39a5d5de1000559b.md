# ## File Types

In verbose directory listings (such as those generated by ls-l), you will see the following file type symbols, as shown in the File Type Symbols table.

# **FILETYPE SYMBOLS**

| Symbol | Description |
| :--- | :--- |
| - | Plain file |
| * | Executable (program or script) |
| / | Directory |
| equals | Socket |
| | | FIFO (named pipe) |
| @ | Symbolic link |
