## 快速获得所需答案，使用

**Linux 命令速查手册**

### 学习 Shell 基础知识（参见第 3 章）

| 我如何 | 使用此命令 | 示例 |
| :--- | :--- | :--- |
| 找出哪些进程占用了最多的内存或 CPU 时间？ | **ps**、**top** | `ps -el --sort --size` |
| 将命令输出重定向到文件，同时在屏幕上显示？ | **tee** | `dir \| tee > listing.txt` |
| 导出应用程序所需的变量？ | **export** | `export MYFILES=~/home/suzanne/essays` |
| 将目录添加到路径中，而不清除现有路径？ | **export** | `export PATH=$PATH:~/home/suzanne/essays` |

### 导航文件系统并查找文件（参见第 4 章）

| 我如何 | 使用此命令 | 示例 |
| :--- | :--- | :--- |
| 按最后修改时间排序列出文件，先显示最近修改的文件？ | **dir**、**ls** | `ls -cl` |
| 找出过去两小时内被更改的所有文件？ | **find** | `find /home/suzanne -ctime 2` |
| 在当前目录中查找自上次修改其他文件以来被更改的文件？ | **find** | `find /home/suzanne -newer 'essay1.doc'` |

### 归档、编码、压缩和加密文件（参见第 6 章）

| 我如何 | 使用此命令 | 示例 |
| :--- | :--- | :--- |
| 仅从备份归档中提取符合我指定的 shell 模式的文件？ | **cpio** | `cpio -iv '*.doc' < archive.cpio` |
| 为工作目录中的所有文件创建备份归档？ | **cpio** | `ls cpio -v > this-directory.cpio` |
| 加密文件，使得除非知道密码短语否则无人可读，并压缩文件以使其占用尽可能少的存储空间？ | **mcrypt** | `mcrypt -uZ mysecrets.txt` |

### 处理文本文件（参见第 8 章）

| 我如何 | 使用此命令 | 示例 |
| :--- | :--- | :--- |
| 比较两个已排序的文件，并查看其差异及周围上下文？ | `diff` | `diff -c first-draft.txt second-draft.txt` |
| 为文本文件中的行编号？ | `nl` | `nl magic.txt > magic-numbered.txt` |
| 将便携式文档格式 (PDF) 文件转换为 PostScript？ | `pdf2ps` | `pdf2ps resume.pdf resume.ps` |
| 将文本文件中所有大写字符转换为小写？ | `tr` | `cat uppercase.txt \| tr '[A-Z]' '[a-z]'` |

### 处理音频和图形文件（参见第 9 章）

| 我如何 | 使用此命令 | 示例 |
| :--- | :--- | :--- |
| 为工作目录中的所有图形文件创建缩略图索引？ | `convert` | `convert 'vids:*.jpg' catalog.jpg` |
| 为我刚刚刻录的 CD-ROM 创建可打印的宝石盒标签？ | `cdlabelgen` | `cdlabelgen -c 'My Favorites' -s '2000' -i 'BluesJazzRock& Alternative Rock\nTechno\nIndustrial' -e images/mp3.eps > cover.ps` |
| 使用特效创建两个或多个图形文件的合成图像？ | `combine` | `combine -compose bumpmap image1.jpg image2.jpg combined.jpg` |

### 配置和使用网络及互联网（参见第 13 章）

| 我如何 | 使用此命令 | 示例 |
| :--- | :--- | :--- |
| 显示当前运行中所有 TCP/IP 套接字的信息？ | `netstat` | `netstat -a` |
| 将文件复制到我有相应权限的远程服务器？ | `rcp` | `rcp essay1.doc essay1.bak@lothlorien:/home/suzanne/Documents/Backup` |
| 查看可用的 NFS 共享？ | `showmount` | `showmount -a` |
| 在远程系统上挂载 Samba 共享？ | `smbmount` | `smbmount //lothlorien/suzanne /home/suzanne/lothlorien` |
| 连接到远程 Telnet 服务？ | `telnet` | `telnet lothlorien.mynetwork.org` |
