# ## sed Commands

sed commands use the following syntax:

```
[ address ] [ ! ] command [ argument ]
```

You can specify from zero to two addresses. An address can be a line number, a regular expression enclosed in forward slash marks, or $ for the last line. The command applies only to the address that you specify. If you omit the address, the command applies to all the lines. If you specify two addresses separated by a comma, sed interprets this as a range, and the command applies to all the lines from the first to the second address. If you include an exclamation point (!), the command applies to all lines except the ones that match the address.
