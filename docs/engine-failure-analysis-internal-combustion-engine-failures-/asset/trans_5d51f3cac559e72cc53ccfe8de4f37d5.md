
## 选项（续）

- **-help**
  - 显示屏幕上的帮助信息。
- **-homepage=_URL_**
  - 使用指定的 URL 作为选中“主页”时显示的页面。
- **-image_links**
  - 切换图像链接的显示状态。
- **-index=_URL_**
  - 将默认索引文件设置为指定的 URL。
- **-justify**
  - 使屏幕上的文本两端对齐。
- **-localhost**
  - 禁用指向远程主机的 URL。
- **-mime_header**
  - 显示远程文档的 MIME 头。
- **-nbold**
  - 隐藏粗体文本。
- **-nobrowse**
  - 禁用目录浏览功能。
- **-nocolor**
  - 关闭颜色模式。
- **-nopause**
  - 禁用状态行消息的强制暂停。
- **-noprint**
  - 禁用大多数打印功能。
- **-noredir**
  - 防止自动重定向，并打印包含新 URL 链接的消息。
- **-noreferrer**
  - 禁用 Referer 头的传输。
- **-noreverse**
  - 禁用反显视频属性。
- **-no__status**
  - 禁用获取状态消息。
- **-nounderline**
  - 禁用下划线视频属性。
- **-number_fields**
  - 为链接和表单输入字段编号。
- **-number_links**
  - 仅为链接编号，不为表单输入字段编号。
- **-partial**
  - 在加载过程中显示部分页面。
- **partial_thres=_n_**
  - 在重绘显示之前渲染 _n_ 行。
- **-auth=_id_:_password_**
  - 使用指定的用户名和密码登录。
- **-prettysrc**
  - 显示带有 HTML 元素颜色标记的 HTML 源代码。
- **-use_mouse**
  - 如果可用，启用鼠标支持。

## mail

```
mail [ option ] address
```

启动一个交互式实用工具，使您可以发送或阅读电子邮件。要发送邮件，请指定收件人地址，输入您的消息，然后按 Ctrl + d。要阅读邮件，请输入 mail，不带任何选项或地址。输入 + 向前移动，输入 – 向后移动。要删除消息，请输入 d。输入 u 取消删除消息。要回复消息，请输入 r。要退出实用工具，请输入 q。

## 选项

| 使用此选项 | 执行此操作 |
| :--- | :--- |
| `-b list` | 向列表发送盲副本，列表为逗号分隔的名称 |
| `-c list` | 向列表发送副本，列表为逗号分隔的名称 |
| `-f` | 读取邮件箱的内容 |
| `-i` | 忽略 tty 中断信号 |
| `-I` | 以交互模式运行 |
| `-n` | 启动时跳过读取 /etc/mail.rc |
| `-N` | 读取邮件或编辑邮件文件夹时，跳过初始的消息头显示 |
| `-s subject` | 使用指定的主题 |
| `-u` | 读取用户的默认邮件箱 |
| `-v` | 显示所有消息 |

## netstat

```
netstat [ option ]
```

显示有关 Linux 网络子系统的信息。如果在没有选项的情况下运行 netstat，您将看到当前 TCP/IP 套接字的列表。此处列出了基本 netstat 使用可用的选项。

对于中级和高级功能，还有更多可用选项。

## 选项

| 使用此选项 | 执行此操作 |
| :--- | :--- |
| `-a, --all` | 显示有关所有套接字的信息，包括监听服务器套接字。 |
| `-c, --continuous` | 显示连续输出，直到使用 `Ctrl + c` 中断。 |
| `-e, --extend` | 显示扩展信息。 |
| `-l, --listening` | 仅显示有关监听服务器套接字的信息。 |
| `-n, --numeric` | 显示数值 IP 地址，而不是尝试解析域名。 |
| `-p, --programs` | 显示每个活跃进程的过程、名称和 PID。需要 root 用户权限。 |
| `-v, --verbose` | 显示所有消息。 |

## 示例

| 此命令 | 执行以下操作 |
| :--- | :--- |
| `netstat -a` | 显示当前所有正在操作的 TCP/IP 套接字的信息。 |

## nslookup

```
nslookup [ option ][ host [ server ] ]
```

通过查询默认的互联网域名服务器或指定的服务器，查找指定主机的数值 IP 地址。如果在不带选项或参数的情况下启动 nslookup，实用工具将进入交互模式，在此模式下您可以使用本节中命令表列出的**命令**。在交互模式下，您可以获取有关互联网主机的海量信息（参见本节后面的查询类型表）。使用 set 选项指定的值（参见命令表）将保存到用户的 .nslookuprc 文件中。
