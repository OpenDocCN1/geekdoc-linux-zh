# EXAMPLES

This Command
Does the Following

```
mogrify -format jpeg
image1.bmp image1.jpg
```

Converts image1.bmp to image1.jpg.

```
mogrify 'vid:* .jpg'
catalog.jpg
```

Creates a visual directory of all the .jpg files in the working directory and writes the output to catalog.jpg.

# montage

```
montage [ option ] input filenames output file
```

Transforms two or more input filenames into a composite image in which the source images are shown in separate tiles (compare combine). This utility is part of the ImageMagick package, which can be downloaded at http://www.imagemagick.org.

> See also convert, identify, mogrify.
