The following tables cover using the sed command to

+   □ Insert text
+   □ Delete text
+   □ Replace text
+   □ Copy, cut, and move text
+   □ Print matching lines
+   □ Control execution

# INSERTING TEXT

| Use This Command | To Do This |
| --- | --- |
| a\text | Append the specified text after a line. Accepts one address only. |
| c\text | Replace the block with the specified text. |
| i\text | Insert the specified text before the line. Accepts one address only. |
| r filename | Insert the contents of the specified filename after the line. Accepts one address only. |

# DELETING TEXT

| Use This Option | To Do This |
| --- | --- |
| d | Delete the line |
| D | Delete up to the next newline character |
