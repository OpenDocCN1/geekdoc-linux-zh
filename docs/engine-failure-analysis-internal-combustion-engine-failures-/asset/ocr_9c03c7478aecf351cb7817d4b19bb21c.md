# eject

eject [ option ] device

Ejects the media in the specified device, which can be a CD-ROM drive, an SCSI device, a removable floppy device, or a tape drive. If the device is mounted, eject unmounts the device before ejecting it.

# OPTIONS

| Use This Option | To Do This |
|---|---|
| -h, --help | Display available options. |
| -v, --verbose | Display messages. |
| -d, --default | Display the default device names. |
| -a setting, --auto setting | Enable or disable the auto-eject mode supported by some devices. When the mode is enabled, the device automatically ejects when the filesystem is unmounted. Available settings are |
| | 1 (on) Enable auto-eject mode. |
| | 0 (off) Disable auto-eject mode. |
