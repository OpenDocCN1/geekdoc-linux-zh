

## 选项（续）

| 使用此选项 | 以执行此操作 |
| :--- | :--- |
| -o [n] | 为每个指定的文件名打开一个窗口，或者如果包含 *n*，则打开 *n* 个窗口。 |
| -R | 以只读模式显示文件。 |

## vi 基础

本节详细说明了用于执行以下操作的键盘快捷键：

- 获取帮助
- 滚动和移动光标
- 处理文件
- 处理窗口
- 处理缓冲区

## 获取帮助

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| :help 或 F1 | 获取关于 **vi** 命令的帮助 |
| Ctrl + ] | 跳转到标记主题 |
| Ctrl + t | 在跳转到标记主题后返回 |

## 滚动

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| Ctrl + e 或向下箭头 | 向下移动一行 |
| 向左箭头 或 h | 向左移动一个字符 |
| b | 向左移动一个单词 |
| 向右箭头 或 l | 向右移动一个字符 |
| w | 向右移动一个单词 |
| Home | 移动到行首 |
| End | 移动到行末 |
| Ctrl + y 或向上箭头 或 k | 向上移动一行 |
| z 或 Ctrl + L | 重新绘制屏幕，将当前行置于窗口顶部 |
| Ctrl + f | 向下滚动一屏 |
| Ctrl + d 或 PgDn | 向下滚动一窗口 |
| Ctrl + u 或 PgUp | 向上滚动半屏 |
| Ctrl + b | 向上滚动一屏 |

## 处理文件

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| :w >> filename | 追加到指定的文件名 |
| :qall | 关闭所有缓冲区并退出 vi |
| :q | 如果不存在其他缓冲区，则关闭当前缓冲区并退出 vi |
| :e filename | 打开指定的文件名 |
| :x | 仅当有更改时保存当前文件并退出 |
| :wq | 保存当前文件并退出 |
| :x filename | 仅当有更改时将当前文件保存到指定的文件名并退出 |
| :w | 保存到当前文件 |
| :w filename | 保存到指定的文件名 |
| :n | 当打开两个或更多文件时，编辑下一个文件 |

## 处理窗口

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| :sp | 将屏幕分割为两个窗口 |
| Ctrl + w, q | 关闭当前窗口 |
| Ctrl + w, k | 移动到上方窗口 |
| Ctrl + w, j | 移动到下方窗口 |
| Ctrl + w, = | 使所有窗口高度相等 |
| Ctrl + w, - | 减小当前窗口高度 |
| Ctrl + w, + | 增加当前窗口高度 |

## 处理缓冲区

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| :buffers | 显示所有缓冲区 |
| :bunload *buffer* | 从内存中移除指定的缓冲区 |
| :buffer *buffer* | 跳转到指定的缓冲区 |
| :bnext | 跳转到下一个缓冲区 |
| :bprevious | 跳转到上一个缓冲区 |

## 使用插入模式

要在当前文档中插入文本，可以使用切换到插入模式的命令之一（参见“开始插入模式”表）。然后，你可以使用仅在此模式下可用的删除命令（参见“在插入模式下删除文本”表）。

## 开始插入模式

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| a | 在光标后追加文本 |
| A | 在当前行末尾追加文本 |
| i | 在光标前插入文本 |
| I | 在行首插入文本 |
| o | 在当前行下方打开新行 |
| O | 在当前行上方打开新行 |
| R | 开始覆盖光标处的文本 |
| s | 替换一个字符 |
| S | 替换整行 |
| Esc | 退出插入模式 |

## 在插入模式下删除文本

| 使用此键盘快捷键 | 以执行此操作 |
| :--- | :--- |
| Backspace | 删除前一个字符 |
| Delete | 删除当前字符 |

## 使用命令模式

下表详细说明了你可以在命令模式下用于编辑文本的命令，包括以下操作：

- 更改文本
- 将文本复制（暂存）和删除到缓冲区（寄存器）
- 粘贴（放置）文本
- 撤销编辑更改
- 重复编辑更改
- 删除文本
- 搜索文本

## 更改文本

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| `cw` | 更改当前单词 |
| `cc` | 更改当前行 |
| `p` | 在光标前插入最后删除的文本 |
| `P` | 在光标后插入最后删除的文本 |
| `rcharacter` | 用 character 替换当前字符 |
| `Rstring` | 从光标处开始替换字符串 |
| `s` | 替换当前字符 |
| `S` | 替换整行 |
| `~` | 更改选中字符的大小写 |

## 将文本复制（暂存）和删除到缓冲区（寄存器）

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| `"register name` | 创建一个名为 *register name* 的寄存器（仅使用一个字符）来存储下一个删除或暂存（复制）操作 |
| `Y` | 将当前行复制到当前寄存器 |
| `:reg register name` | 显示指定寄存器的内容 |
| `:reg` | 显示所有寄存器的内容 |
| `"register nameY` | 将当前行删除到 *register name* |

## 粘贴（放置）文本

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| `p` | 在光标后插入当前寄存器的内容 |
| `P` | 在光标前插入当前寄存器的内容 |
| `"register namep` | 在光标后插入指定寄存器名称的内容 |

## 撤销编辑更改

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| u | 撤销最后一次更改 |
| U | 恢复当前行 |

## 重复编辑更改

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| . | 重复最后一次更改 |

## 删除文本

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| dd | 删除当前行 |
| D | 删除该行剩余部分 |
| dw | 删除当前单词 |
| D) | 删除到下一段 |
| d\^ | 删除到行首 |
| d/string | 删除到指定字符串的下一个出现位置 |
| d/pattern | 删除到当前行上指定的模式（包含该模式） |
| d/pattern | 删除到当前行上指定的模式之前（不包含该模式） |
| dL | 删除到屏幕上的最后一行 |
| dG | 删除到文件末尾 |
| x | 删除当前字符 |
| X | 删除前一个字符 |

## 搜索文本

| 使用此命令 | 以执行此操作 |
| :--- | :--- |
| `/string` | 向前搜索指定的字符串 |
| `?string` | 向后搜索指定的字符串 |
| `/` | 重复向前搜索 |
| `?` | 重复向后搜索 |
