# ## pico Command Reference

This section details pico's keyboard shortcuts, sorted in alphabetical order.

# ### PICO KEYBOARD SHORTCUTS

| **Use This Keyboard Shortcut** | **To Do This** |
|:--------------------------------|:---------------------------------------|
| Backspace | Delete the previous character |
| Ctrl + ^ | Mark the beginning of a block |
| Ctrl + a | Move to the beginning of the line |
| Ctrl + b | Move back one character |
| Ctrl + d | Delete the next character |
| Ctrl + e | Move to the end of the line |
| Ctrl + f | Move forward one character |
| Ctrl + g | Open the Help window |
| Ctrl + j | Reformat the text |
| Ctrl + k | Delete the line or the marked block |
| Ctrl + k, l | Move to a line number that you specify |
| Ctrl + k, w | Save the marked region to a file |
| Ctrl + n | Move down one line |
| Ctrl + o | Save a file |
| Ctrl + p or up arrow | Move up one line |
| Ctrl + r | Insert a file at the cursor's location |
| Ctrl + t | Check the spelling of the entire file |
| Ctrl + u | Insert a cut block at the cursor's location |
| Ctrl + v | Scroll down one window |
| Ctrl + w, Ctrl + v | Scroll to the last line of the file |
| Ctrl + w, Ctrl + y | Scroll to the first line of the file |
| Ctrl + x | Quit the program and optionally save any unsaved edits |
| Ctrl + x | Closed the Help window |
| Ctrl + y | Scroll up one window |
