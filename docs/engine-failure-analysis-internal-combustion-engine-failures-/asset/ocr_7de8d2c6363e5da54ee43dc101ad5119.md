# wvdial

**wvdial**
Initiates a PPP dial-up connection using the settings specified in the utility’s configuration file, /etc/wvdial.conf (see the section “Configuring PPP Dial-Up Connections” earlier in this chapter for more information on /etc/wvdial.conf).

See also wvdialconf.

# wvdialconf

**wvdialconf**
Probes for a modem connected to your system and, if a modem is found, detects the port to which it is connected, its preferred initialization string, and its maximum data transfer rate. This information is automatically written to the file /etc/wvdial.conf. Requires root user or superuser status.

See also wvdial.
