# STYLES

| Use This Style | To Do This |
| :--- | :--- |
| a | Number all lines |
| t | Number only non-empty lines |
| p*regexp* | Number only the lines that contain a match for *regexp* |
| n | Number no lines |

# FORMATS

| Use This Option | To Create This Format |
| :--- | :--- |
| ln | Left justified, no leading zeros |
| m | Right justified, no leading zeros |
| rz | Right justified, leading zeros |

# EXAMPLES

| This Command | Does the Following |
| :--- | :--- |
| nl magic.txt > magic-numbered.txt | Numbers the lines of *magic* .txt and writes the output to *magic-numbered.txt*. |
| nl -bp magic magic.txt \| less | Numbers only the lines con- taining the specified regular expression (*magic*), and shows the output on-screen. |

# **od**

**od [ option ] [ *filename* ]**

Writes *filename* to the standard output in octal and other formats. When no filename is specified, the utility accepts input from the standard input.
