# OPTIONS (CONT.)

**Use This Option**
**To Do This**

**gid=gid**
Set the group user ID (GID) for the mounted files. You can specify the group name or the numeric ID.

**guest**
Skip prompting for the password.

**ip=address**
Specify the destination hostname or IP address.

**netbiosname=string**
Specify the source NetBIOS name. This is set to the local host name by default.

**password=password**
Specify the password. If you omit this option, the utility will prompt you to supply the password, unless you have used the **guest** option.

**port=n**
Set the remote port number to n. The default is 139.

**ro**
Mount the share as read only.

**rw**
Mount the share as read and write.

**uid=uid**
Mount the files with the specified user ID. You can use a username or numeric user ID.

**username=username**
Connect with the specified username. The default is the current user.

**workgroup=n**
Specify the workgroup name.

# EXAMPLE

**This Command**
smbmount //lothlorien/suzanne /home/suzanne/lothlorien

**Does the Following**
Mounts the share (//lothlorien/suzanne) at the specified mount point (/home/suzanne/lothlorien).
