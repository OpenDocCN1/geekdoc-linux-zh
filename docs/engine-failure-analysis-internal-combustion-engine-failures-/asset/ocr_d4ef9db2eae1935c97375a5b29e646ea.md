# **OPTIONS (CONT.)**

+   * **Use This Option**
+       * `--escape-from-lines`
+       * `--fast-list-mode`
+       * `--force-v3-sigs`
+       * `--homedir directory`
+       * `--honor-http-proxy URL`
+       * `-i`, `--interactive`
+       * `--keyring filename`
+       * `--keyserver URL`
+       * `--load-extension module name`
+       * `--lock-multiple`
+       * `--lock-once`
+       * `--logger-fd filename`
+       * `--marginals-needed n`
+       * `--max-cert-depth n`

+   * **To Do This**
+       * Keep e-mail programs from making changes in cleartext signatures.
+       * Improve list mode performance by omitting blank portions.
+       * Force version 3 digital signatures.
+       * Use the specified directory instead of the default (`~/`, `~gnupg`).
+       * Use the specified URL as a proxy server to access the keyserver.
+       * Prompt before overwriting any files.
+       * Add the specified filename to the list of key rings.
+       * Use the specified URL to access a keyserver. This option is used with `--send-keys`. To see a list of key-servers, use `host -l pgp.net grep www.keys`.
+       * Load the extension module with the specified module name.
+       * Release the locks every time a lock is no longer needed.
+       * Lock the databases the first time a lock is requested and do not release the lock until the process terminates.
+       * Write log output to the specified filename instead of to the standard error output.
+       * Set the number (n) of marginally trusted users required to introduce a new key signer. The default is 3.
+       * Set the maximum depth (n) of a certification chain. The default is 5.
