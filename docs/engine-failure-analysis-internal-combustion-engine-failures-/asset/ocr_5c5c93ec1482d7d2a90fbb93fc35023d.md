# SPECIFYING BLOCK SIZES

| Suffix | Meaning |
|---|---|
| c | 1 character |
| w | 1 word (2 bytes) |
| b | 512-byte block |
| kD | 1,000 bytes |
| k | Kilobyte (1,024 bytes) |
| MD | 1,000,000 bytes |
| M | Megabyte (1,048,576 bytes) |
| GD | 1,000,000,000 bytes |
| G | Gigabyte (1,073,741,824 bytes) |
| TD | 1,000,000,000,000 bytes |
| T | Terabyte (1,099,511,627,776 bytes) |
| PD | 1,000,000,000,000,000 bytes |
| P | Petabyte (1,125,899,906,842,624 bytes) |
| ED | 1,000,000,000,000,000,000 bytes |
| E | Exabyte (1,152,921,504,606,846,976 bytes) |
| ZD | 1,000,000,000,000,000,000,000 bytes |
| Z | Zettabyte (1,180,591,620,717,411,303,424 bytes) |

| Y | Yottabyte (1,208,925,819,614,629,174,706,176 bytes) |

# File Ownership

Any user who wishes to access a file belongs to one of the four user classes shown in the following table, File Owner Types. By default, the user who creates a file is the file's owner. Since most users belong to groups, the file also belongs to the user's group. Members of the group are, in turn, group owners.
