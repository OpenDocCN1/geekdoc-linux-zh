# diff3

**diff3 [ option ] filename1 filename2 filename3**

Compare the three files specified by **filename1**, **filename2**, and **filename3** and show which files differ. A line of equals marks (=) indicates that all three files differ. A line of equals marks followed by the number 1, 2, or 3 indicates which of the three files differs from the other two. This utility can also find changes made in two newer files (**filename1** and **filename3**) from an original version of the two files
