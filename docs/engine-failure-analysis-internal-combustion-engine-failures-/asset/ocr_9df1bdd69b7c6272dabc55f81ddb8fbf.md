# OPTIONS (CONT.)

**Use This Option** | **To Do This**
- `--negate`
  Replace every pixel with its complementary color.
- `--noise` *type*
  Add or reduce noise using the specified filter type. The options are Uniform, Gaussian, Multiplicative, Impulse, Lapacian, Poisson.
- `--normalize`
  Transform image and enhance contrast by spanning the full range of color values.
- `-opaque` *color*
  Use the specified color for the pen (see --pen).
- `-page` *width x height*
  `[ % ] | !`
  Set the width and height in pixels of the image canvas. Append % (a percentage sign) to adjust the width and height by a percentage. Append ! (an exclamation point) to force the exact size.
