# EXAMPLES


This Command | Does the Following
:--- | :---
'|em\er' : start-keyboard-macro' | Assigns Alt + m, Alt + r to the specified readline function (start-keyboard-macro) in /etc/ inputrc or ~/\inputrc. Add this line to one of these files with a text editor.

bind '|\em\er' : start-keyboard-macro' | Assigns Alt + m, Alt + r to the specified readline function (start-keyboard-macro) for the duration of the session. Note the single quote punctuation around the entire argument.

bind '|cb' : bigfiles' | Assigns Ctrl + b to the specified function.

bind '|cp' : '/home/suzanne/documents/pix'' | Assigns Ctrl + p to the specified macro (inserts the quoted text).


# chroot

**chroot** *path name* [ *command* ]

This utility executes the specified command with a root directory other than the default for the current session. Requires superuser status (see su in Chapter 1).

# chsh

**chsh** [ *option* ] [ *username* ]

Changes the login shell. To see a list of available shells, use the -l option.
