## joe

```
joe [ option | [file option]] filename]
```

启动一个易于使用的基于文本的编辑器，允许您直接在屏幕上编辑文本，而无需从命令模式切换到编辑模式。您可以选择指定一个文件名以随程序加载。文件选项（参见本节的“文件选项”表）必须位于文件名之前。有关程序启动后可使用的键盘快捷键，请参见“joe 命令”部分的表格。此处记录了 2.8 版本最常用到的功能。该程序的下载站点是：ftp://ftp.std.com/src/editors。

### 选项

| 使用此选项 | 执行此操作 |
| :--- | :--- |
| **-asis** | 显示代码高于 128 的字符 |
| **-backup directory** | 将备份文件存储在指定目录中 |
| **-beep** | 出错时发出铃声 |
| **-columns nnn** | 设置屏幕列数 |
| **-csmode** | 默认重复上一次的搜索 |
| **-exask** | 在写入前验证文件名 |
| **-force** | 如有必要，在文件末尾插入换行符 |
| **-help** | 启动编辑器时显示帮助窗口 |
| **-keepup** | 立即更新列和行信息，而不是延迟一秒 |
| **-lightoff** | 在执行块命令后隐藏块高亮显示 |
| **-lines n** | 在屏幕上显示 n 行 |
| **-marking** | 高亮显示第一个标记和光标之间的文本 |
| **-mid** | 向右滚动以便查看长行 |
| **-nobackups** | 防止创建备份文件 |
| **-nonotice** | 防止显示版权声明 |
| `-nosta` | 隐藏状态行 |
| `-pg n` | 在滚动后保留 *n* 行之前查看过的内容 |

### 文件选项

| 使用此选项 | 执行此操作 |
| :--- | :--- |
| `+n` | 从第 *n* 行开始显示文件 |
| `-autoindent` | 按下回车键后，在下一行复制缩进 |
| `-crif` | 使用 DOS 风格换行符 |
| `-linums` | 显示行号 |
| `-lmargin n` | 将左边界设置为 *n* 列 |
| `-overwrite` | 使用覆盖模式 |
| `-rdonly` | 以只读格式打开文件 |
| `-rmargin n` | 将右边界设置为 *n* 列 |
| `-tab n` | 将制表位宽度设置为 *n* 列 |
| `-wordwrap` | 对长行使用自动换行 |

## joe 命令

下表详细列出了执行以下操作的键盘快捷键：

- 获取帮助
- 选择程序模式
- 重新格式化并刷新
- 退出和挂起
- 滚动
- 移动光标
- 管理文件
- 拼写检查
- 删除文本
- 标记文本
- 复制和移动文本
- 撤销和重做编辑更改
- 搜索文本
- 替换文本

### 获取帮助

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + k, h | 打开或关闭帮助窗口 |

### 选择程序模式

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + t, t | 在覆盖模式和缩进模式之间切换 |
| Ctrl + t, w | 切换自动换行的开/关 |
| Ctrl + t, i | 切换自动缩进功能的开/关 |

### 重新格式化和刷新

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + r | 刷新屏幕 |
| Ctrl + k, j | 重新格式化文本 |

### 退出和挂起

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + k, x | 退出程序，并可选择保存未保存的编辑 |
| Ctrl + k, z | 挂起编辑器（输入 fg 并按回车键即可返回到 joe） |

### 滚动

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| PgUp 或 Ctrl + u | 向上滚动一个窗口 |
| PgDn 或 Ctrl + v | 向下滚动一个窗口 |

### 移动光标

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + b 或左箭头 | 向后移动一个字符 |
| Ctrl + z | 向后移动一个单词 |
| Ctrl + n 或下箭头 | 向下移动一行 |
| Ctrl + f 或右箭头 | 向前移动一个字符 |
| Ctrl + x | 向前移动一个单词 |
| Ctrl + k, l | 移动到指定的行号 |
| Ctrl + k, u | 移动到文件开头 |
| Ctrl + a | 移动到行首 |
| Ctrl + k, v | 移动到当前文件末尾 |
| Ctrl + e | 移动到行尾 |
| Ctrl + p 或上箭头 | 向上移动一行 |

### 管理文件

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + k, e | 打开文件 |
| Ctrl + k, r | 在光标位置插入文件 |
| Ctrl + k, d | 保存文件 |

### 管理窗口

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + k, i | 关闭当前窗口 |
| Ctrl + k, g | 放大当前窗口 |

| Ctrl + k, t | 缩小当前窗口 |

### 拼写检查

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + l, n | 检查整个文件的拼写 |
| Ctrl + l, l | 检查选中单词的拼写 |

### 删除文本

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + d | 删除下一个字符 |
| Delete 或 Backspace | 删除前一个字符 |
| Ctrl + w | 删除下一个单词 |
| Ctrl + o | 删除前一个单词 |
| Ctrl + j | 删除该行 |
| Ctrl + k, y | 删除标记的块 |

### 标记文本

| 使用此键盘快捷键 | 执行此操作 |
| :--- | :--- |
| Ctrl + k, b | 标记块的开始 |
| Ctrl + k, k | 标记块的结束 |
