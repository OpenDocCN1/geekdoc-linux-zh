# Isattr

Isattr [ option ] file  
Displays the attributes of files on a second Linux extended filesystem.

> See also stat.

# OPTIONS

| Use This Option | To Do This |
| --------------- | ----------- |
| -a | Show all files, including hidden files |
| -d | Show directories as if they were files, without showing their contents |
| -R | List the attributes of directories and all of their associated subdirectories |
| -V | Display the program version |
| -v | List file versions |
