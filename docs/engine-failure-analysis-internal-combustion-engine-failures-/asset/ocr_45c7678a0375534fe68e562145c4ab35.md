# OPTIONS

| Use This Option | To Do This |
| :--- | :--- |
| -u | Create the **locate** database starting at the root directory (\/.). You must be logged in as the root user to use this option. |
| -U directory | Create the **locate** database starting at the specified directory. You must be logged in as the root user to use this option. |
| -e directory\_1, directory\_2,... | Exclude the specified directories from the **locate** database. You must be logged in as the root user to use this option. |
| -f type | Exclude the specified filesystem type (such as msdos or vfat) from the **locate** database. You must be logged in as the root user to use this option. |
| -l <0> or <1> | Specify the security level:<br>0 Turns security checks off.<br>1 Turns security checks on (default). |
| -n n | Limit the number of results displayed to n (an integer). |
| -r regular expression | Search the database using the specified regular expression. |
