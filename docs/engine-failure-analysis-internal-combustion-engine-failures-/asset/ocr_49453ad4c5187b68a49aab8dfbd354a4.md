# t1ascii

t1ascii [ *input* [ *output* ]]

Converts Type 1 PFB font specified by *input* to a font file (*output*) in PFA (ASCII) format. This utility is part of the Type 1 Utilities package, available from <http://www.lcdf.org/~eddtwo/type/>.

See also t1binary.

# OPTIONS

| Use This Option | To Do This |
|:---|:---|
| `--line-length=n`, `-l num n` | Set the maximum length of encrypted lines in the output to *n* |

# t1asm

t1asm [ *input* [ *output* ] ]

Converts the specified input file (a Type 1 font program in human-readable form) to an output file in PFA (hexadecimal) or PFB (binary) format. This utility is part of the Type 1 Utilities package, available from <http://www.lcdf.org/~eddtwo/type/>.

See also t1disasm.
