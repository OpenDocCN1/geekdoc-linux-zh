
# 选项（续）

## 使用此选项  
以执行此操作

- `–comment string`  
  使用指定的字符串为图像添加注释。你可以使用以下扩展符号：
    - `%b` 文件大小。
    - `%d` 目录。
    - `%e` 文件扩展名。
    - `%f` 文件名。
    - `%h` 高度。
    - `%m` 魔术（Magic，指通过文件头识别出的格式类型）。
    - `%p` 页码。
    - `%s` 场景编号。
    - `%t` 文件名的上半部分。
    - `%w` 宽度。
    - `%x` X 分辨率。
    - `%y` Y 分辨率。
    - `\n` 换行符。
    - `\r` 回车符。

- `–compress type`  
  设置图像压缩的类型。选项如下：B2zip、Fax、Group4、JPEG、LZW、RunlengthEncoded、None 和 Zip。

- `–contrast` `+contrast`  
  增强（_–contrast_）或减弱（_+contrast_）图像对比度。

- `–crop width x height`  
  按照指定的宽度和高度裁剪图像。

- `–cycle n`  
  将图像色位移开指定量（_n_）。

- `–density width x height`  
  将图像的垂直和水平分辨率设置为指定的像素宽度和高度。

- `–depth value`  
  设置图像的颜色深度（8 或 16）。

- `–despeckle`  
  减少图像中的斑点。

- `–dispose type`  
  使用指定类型的 GIF 处置方法。选项如下：
    - **0** 不处置。
    - **1** 帧之间不处置。
    - **2** 用背景色覆盖该帧。
    - **3** 用前一帧覆盖。

- **-frame** width x height + outer bevel width + inner bevel width
  使用指定的宽度、高度、外部斜角宽度和内部斜角宽度添加装饰性边框。

- **-fuzz** distance
  合并指定距离内的颜色。

- **-gamma** n
  使用指定级别（n）的伽马校正，其中 n 是 0.8 到 2.3 之间的级别。

- **-geometry** width x height [! | % | 1]
  在保持原始图像宽高比的同时，创建具有指定最大宽度和高度的图像。添加 %（百分号）以百分比调整宽度和高度。若要强制使用指定尺寸，请添加 1（感叹号）。

- **-gravity** type
  设置图像重力方向：NorthWest（西北）、North（北）、NorthEast（东北）、West（西）、Center（中心）、East（东）、SouthWest（西南）、South（南）、SouthEast（东南）。

- **-implode** factor
  围绕中心按指定因子向内（implode）或向外（explode）图像像素。选项为向内收缩（0–99.9%）或向外膨胀（–99.9–0%）。

- **-interlace** type
  设置交错扫描方案类型。选项为 None（无）、Line（行）、Plane（平面）或 Partition（分区）。

- **-label** string
  使用字符串作为标签。

- **-layer** type
  设置图层类型。选项为 Red（红）、Green（绿）、Blue（蓝）或 Matte（半透明通道）。

- **-linewidth** n
  将线宽设置为 n 像素。

- **-loop** n
  重复 GIF 动画 n 次。指定 0 表示无限循环。

- **-map** filename
  从指定文件名获取颜色集。如果图像有半透明通道信息，则存储该信息。
