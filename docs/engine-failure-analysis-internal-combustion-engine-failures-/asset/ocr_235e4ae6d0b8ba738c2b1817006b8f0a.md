# MOVING THE CURSOR *(CONT.)*

| Use This Keyboard Shortcut | To Do This |
| :--- | :--- |
| Meta + b | Go back one word |
| Ctrl + f | Go forward one character |
| Meta + f | Go forward one word |
| Home | Go to the beginning of line |
| Ctrl + a | |
| End | Go to the end of the line |
| Ctrl + e | |

# EDITING TEXT ON THE COMMAND LINE

| Use This Keyboard Shortcut | To Do This |
| :--- | :--- |
| Meta + l | Convert a word to lowercase |
| Meta + u | Convert a word to uppercase |
| Delete | Delete the current character |
| Ctrl + d | |
| Ctrl + u | Delete a word |
| Ctrl + k | Delete from the cursor to the end of the line |
| Meta + \ | Delete all the horizontal space around a word |
| Backspace | |
| Ctrl + h | Delete the previous character |
| Meta Ctrl + h | Delete the previous word |
| Ctrl + x, Ctrl + v | Display the version number |
| Meta + c | Capitalize the first character of a word |
| Ctrl + t | Transpose characters |
| Meta + t | Transpose words |
| Ctrl + x, Ctrl + u | Undo the last change |
