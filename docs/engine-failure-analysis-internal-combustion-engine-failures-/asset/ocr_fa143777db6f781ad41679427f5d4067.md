# dir

```
dir [ options ] [ pattern ]
```

Lists the files in the current directory in case-sensitive, alphabetical order, using a columnar format. If you specify a pattern, this command lists only the files that match a shell pattern (see Chapter 3). In the GNU file utilities commonly provided with Linux distributions, this command is identical to ls.

*See also vdir.*

# OPTIONS

| Use This Option | To Do This |
| --- | --- |
| `--l` | List entries using one line for each filename. |
| `--a, --all` | Show all files, including hidden files, those that have names beginning with a period. |
| `--A, --almost-all` | List all files in the directory, including hidden files, but hide the display of the current directory (`.`) and parent directory (`..`) symbols. |
| `--B, --ignore-backups` | Hide backup files, those with filenames beginning with `~`. |
| `--c` | List files sorted by the time of the last modification to the file’s status. Use `-cl` to display the times. Same as `--sort=time.` |
| `--C` | List entries using columns. |
| `--color` | Display file types using distinctive colors if the current terminal supports color output. |
| `--d, --directory` | List the names of subdirectories but not their contents. |
| `--F` | Display the file type with a character appended to the filename output:<br> *   `*`  Executable file.<br> *   `/`  Directory.<br> *   `=`  Socket.<br> *   `\|`  Named pipe FIFO (`/`).<br> *   `@`  Symbolic link. |
