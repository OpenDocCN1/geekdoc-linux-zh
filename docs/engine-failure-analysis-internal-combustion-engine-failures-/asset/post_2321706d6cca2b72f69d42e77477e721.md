## montage

```
montage [ option ] input filenames output file
```

Transforms two or more input filenames into a composite image in which the source images are shown in separate tiles (compare *combine*). This utility is part of the ImageMagick package, which can be downloaded at [http://www.imagemagick.org](http://www.imagemagick.org).

> See also *convert*, *identify*, *mogrify*.
