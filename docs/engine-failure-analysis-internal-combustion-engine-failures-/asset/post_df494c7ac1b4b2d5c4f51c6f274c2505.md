
**NOTE** Version 2.3 of *playmidi* is current at the time of this writing and is not compatible with the Awe 32 SoundBlaster driver.

## OPTIONS

- **-S** Use 8-bit patches for the Gravis Ultrasound sound card
- **-C n** Specify the MIDI channels (using *n*, a hexadecimal number) to play
- **-C n** Set the initial chorus level to *n* (0–127)
- **-d** Silence the tracks defined as percussion tracks (see *-m*)
- **-E n** Specify the MIDI channels (using *n*, a hexadecimal number) to output to the external MIDI device
- **-f** Send output to the FM synthesizer, which is required for sound cards that lack wave-table synthesis.
- **-F n** Specify the MIDI channels (using *n*, a hexadecimal number) to output to the FM synthesis device
- **-g** Use a Gravis UltraSound sound card
- **-G n** Specify the MIDI channels (using *n*, a hexadecimal number) to output to the Gravis UltraSound sound card
- **-i** Show a list of available MIDI channels
- **-i n** Specify the MIDI channels (using *n*, a hexadecimal number) to ignore
- **-m n** Define the specified MIDI channels (using *n*, a hexadecimal number) as percussion tracks
- **-P n** Remap percussion channels to play on the channel specified by *n* (a hexadecimal number)
- **-r** Show playback graphics
- **-R n** Set the reverb level to the value specified by *n* (0–127)
- **-t n** Change the tempo by the float factor specified by *n*
- **-V n, velocity** Set the *velocity* for all notes in channel *n*
- **-X n** Suppress the channel specified by *n*

This command does the following:

```bash
playmidi sample.midi
```

Plays the specified MIDI file.

## rec

```bash
rec [ option ] filename [ effect ]
```

Records the microphone input to the audio file specified by filename.
Specify the sound type with the -type option. You can also use one of the effects specified in the Effects table in the "sox" section. This utility is a front end to the sox utility.

### OPTIONS

| Use This Option | To Do This |
| :--- | :--- |
| **-c n**, --channels=n | Define the number (n) of channels of the file. |
| **-d device**, --device=device | Specify a device other than the default input device. |
| **-f format**, --format=format | Specify the bit format of the sample. The available options are: <br>• A: ADPCM. <br>• A: Alaw (logarithmic). <br>• g: GSM. <br>• s: Signed linear (2's complement). <br>• U: Ulaw (logarithmic). <br>• u: Unsigned linear. |
| **-h**, --help | Show the available options. |
| **-r rate**, --rate=rate | Use the specified sample rate to decode the audio data. |
| **-s size**, --size=size | Use the specified size to describe the size of the sample. The available options are: <br>• b: Bytes. <br>• d: 64-bit double floats. <br>• D: 80-bit IEEE floats. <br>• f: 32-bit float. <br>• l: 32-bit word. <br>• w: 16-bit words. |
| **-t type**, --type=type | Specify the type of audio file format to use. The options are as follows: <br>• **8svx**: Amiga musical instrument description format. <br>• **aiff**: Apple/Silicon Graphics AIFF sound. <br>• **au**: Sun/NeXT AU sound. <br>• **auto**: Autodetection of sound file type. This is the default. <br>• **cdr**: RAW, unsigned samples of CD-ROM audio. <br>• **cvs**: Continuously Variable Slope modulation; used for speech compression. <br>• **dat**: Text data file containing a textual representation of the sample data. |
