# OPTIONS (CONT.)

+   *   Use This Option
+       *   \|sp
+       *   \|t
+       *   `–title string`
+       *   `–tm keyword`

+   *   To Do This
+       *   Enable Sun keyboard mapping.
+       *   Start in Tektronix rather than VT102 mode.
+       *   Use the specified string for the window title.
+       *   Indicate the terminal setting that should be used, which is specified by keyword. Options include `intr`, `quit`, `erase`, `kill`, `eof`, `eol`, `swtch`, `start`, `stop`, `brk`, `sup`, `dsup`, `rprnt`, `flush`, `weras`, and `inext`.

+   *   `–tn name`
+   *   \|–ulc
+   *   \|–ut
+   *   \|–vb
+   *   \|–wf
+   *   `–ziconbeep percentage`

+   *   Specify the name of the terminal type to be used.
+   *   Disable the display of underlining with color.
+   *   Skip making entries in system log.
+   *   Enable the visual rather than audible bell.
+   *   Wait for window to be mapped before enabling subprocesses.
+   *   Sound bell at the specified percentage of full volume.
