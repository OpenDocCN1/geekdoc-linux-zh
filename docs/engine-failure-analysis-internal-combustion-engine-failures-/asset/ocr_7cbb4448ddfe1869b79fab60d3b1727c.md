# OPTIONS (CONT.)

| **Use This Option** | **To Do This** |
| :--- | :--- |
| `-H[n]`，`--highlight-bars[=n]` | Print highlight bars with a height of two lines (the default) or *n* lines. |
| `--h-column-height=points` | Set the horizontal column height to the number of points. |
| `--help` | Display the available options. |
| `--help-pretty-print` | Describe all supported pretty-print languages and file formats. |
| `--highlight-bar-gray=level` | Specify the gray level used to print highlight bars. |
| `-I filter`, `--filter=filter` | Read all input files through the input filter. |
| `-I n`, `--indent=n` | Indent every line *n* characters. |
| `-J`, `--borders` | Print borders around columns. |
| `-J string` | Use *string* as a title. |
| `-K`, `--no-page-prefeed` | Disable page prefeed, which is the default. |
| `-k`, `--page-prefeed` | Enable page prefeed. |
| `-L`, `--lineprinter` | Emulate a line printer. This option is a shortcut for the `--lines-per-page=66` and `--no-header` options. |
| `--list-media` | List the names of all known output media. |
| `--list-options` | List all options and their current values. |
| `-L n`, `--lines-per-page=n` | Print only *n* lines per each page. |
| `-m`, `--mail` | Send mail notification to the user when the print job is complete. |
| `--margins=points:points:points:points` | Set the left, right, top, and bottom margins to the specified number of points. |
