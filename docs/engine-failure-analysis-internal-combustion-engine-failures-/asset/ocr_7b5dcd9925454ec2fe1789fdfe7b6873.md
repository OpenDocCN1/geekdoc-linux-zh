# # Configuring PPP Dial-Up Connections

The Point-to-Point Protocol (PPP) is the standard method of establishing a dial-up connection between personal computers and Internet service providers (ISPs). Most Linux distributions rely on a utility called `pppd` to establish PPP connections. Typically, Linux distributions are configured with scripts that launch this utility. They may also come with menu-based utilities that enable you to configure your PPP configuration easily.

If you would like to configure your PPP connection manually, you can do so by following these steps:

+   1.  Run `vdialconf` to detect your modem, determine its characteristics, and write the initial working copy of the `vdial` configuration file, `/etc/vdial.conf`.
+   2.  Modify the `vdial` configuration file (`/etc/vdial.conf`) to dial your ISP and establish the connection.

The configuration file, `/etc/vdial.conf`, has two or more sections. The first, Dialer Defaults, is generated automatically by `vdialconf`. Do not alter the settings in this section. The second section, the name of which begins with Dialer, specifies the settings for a given PPP connection, including the phone number, username, and password. You can create two or more such sections, if you wish.

The following illustrates a typical `vdial` configuration in `/etc/vdial.conf`:

```
[Dialer Defaults]
Modem = /dev/ttyS1
Baud = 115200
Init1 = ATZ
Init2 = ATQ0 V1 E1 S0=0 &C1 &D1 S11=55
SetVolume = 1
Dial Command = ATDT
```
