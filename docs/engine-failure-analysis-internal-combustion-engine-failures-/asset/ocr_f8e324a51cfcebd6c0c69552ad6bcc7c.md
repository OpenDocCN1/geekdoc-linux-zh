# INTERACTIVE COMMANDS (CONT.)

| Use This Command | To Do This |
| :--- | :--- |
| q | Quit top. |
| r | Re-nice a process. You will be prompted to enter a **nice** value (see **nice**). |
| S | Toggles cumulative mode. |
| s | Change the delay between updates. You will be prompted to enter a delay time in seconds. Enter 0 (zero) to force continuous updates. The default is 5 seconds. |
| f, O | Add or remove fields from the display. |
| o, O | Change the order of displayed fields. |
| l | Toggle the display of load average and uptime information. |
| m | Toggle the display of memory information. |
| t | Toggle the display of processes and CPU state information. |
| N | Sort tasks by process ID. |
| A | Sort tasks by age, showing the newest first. |
| P | Sort tasks by CPU usage. This is the default sort order. |
| M | Sort tasks by resident memory usage. |
| T | Sort tasks by cumulative time. |
| W | Write the current setup to the top configuration file. |

# OUTPUT FIELDS

| Field | Description |
| :--- | :--- |
| PID | Displays the process ID. |
| USER | Displays the username of the task's owner. |
| NI | Displays the **nice** value. |
