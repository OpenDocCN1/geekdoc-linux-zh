# OPTIONS

Use This Option | To Do This
-1 | Use a single column.
-C | Use multiple columns.
-fn pattern | Match the specified pattern. You can use shell wildcards in your search.
-l | Show font attributes.
-II | Show font attributes and properties.
-III | Show font attributes, properties, and character metrics.
-m | Show the minimum and maximum bounds of each font.
-n n | Use n columns to display the font information.
-u | Skip sorting the output.
-w n | Use an output width of n columns. The default is 79.

# EXAMPLES

This Command | Does the Following
x1sfonts | less | Lists all the fonts currently available to the X server.
x1sfonts -fn \*utopia\* | less | Shows only those fonts that match the specified string (utopia).
