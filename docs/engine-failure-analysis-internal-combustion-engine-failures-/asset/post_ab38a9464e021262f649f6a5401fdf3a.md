# Introduction

**W**elcome to *Linux Command Instant Reference*!

This is the first Linux command reference to be written *from scratch* for today's Linux user. This book isn't a compilation of man (manual) pages or old, out-of-date, how-to documents. Every word of this book is original, and it's been professionally written to ensure the highest degree of readability and technical accuracy.

## Who This Book Is For

The organization of this book is also unique, making this book the perfect reference for today's Linux user.

## It's Organized by Task Not Tradition

Most Linux command references organize commands in the old, traditional Unix way—that is, they begin with all the commands available to users and then proceed with those that are accessible only to system and network administrators. This organization doesn't make sense for today's Linux users, who are running Linux on single-user systems. Linux users wear two hats—the user's *and* the system administrator's— so it no longer makes sense to categorize Linux commands in the old, Unix-influenced way. Instead, this book is organized by the *tasks* you want to perform, such as navigating the file system, finding elusive files, dealing with disks, burning CD-ROMs, and more. For more information on what's covered and where, see the section "A Guide to This Book's Contents."
