# cd

```
cd [directory | path name]
```

Changes the current directory. If you type cd without specifying an argument, this command changes to the current user's home directory. This is one of the shell's built-in commands rather than a disk-based utility.

# EXAMPLES

This Command   | Does the Following
cd              | Switches to user's home directory.
cd ..           | Switches to the parent directory (the next directory up).
cd documents    | Switches to a subdirectory in the current directory named documents.
cd /usr/share/pixmaps | Switches to the directory specified by the path name.
