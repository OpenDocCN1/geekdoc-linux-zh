# ziplist

```
`ziplist [ option ] [ -b path name ] archive`
```

Divides a zip archive into segments small enough to be written to removable media, such as floppy disks, and outputs the files to the specified device name.

OPTIONS


| Use This Option | To Do This |
| :------------- | :--------- |
| -b device name | Write the output files to the specified device name. |
| -h | Show available options. |
| -i | Make an index file. |
| -L | Show the program license. |
