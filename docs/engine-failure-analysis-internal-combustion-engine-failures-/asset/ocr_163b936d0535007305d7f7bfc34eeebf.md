# QUITTING THE PROGRAM

| Use This Keyboard Shortcut | To Do This |
| :--- | :--- |
| Ctrl + x or F2 | Quit the program and optionally save any unsaved edits |

# SCROLLING

| Use This Keyboard Shortcut | To Do This |
| :--- | :--- |
| Ctrl + y or F7 or PgUp | Scroll up one window |
| Ctrl + v or F8 or PgDn | Scroll down one window |
| Ctrl + w, Ctrl + y | Scroll to the first line of the file |
| Ctrl + w, Ctrl + v | Scroll to the last line of the file |

# MOVING THE CURSOR

| Use This Keyboard Shortcut | To Do This |
| :--- | :--- |
| Ctrl + b, or left arrow | Move back one character |
| Ctrl + n or down arrow | Move down one line |
| Ctrl + f or right arrow | Move forward one character |
| Ctrl + k, l | Move to a line number that you specify |
| Ctrl + a | Move to the beginning of the line |
| Ctrl + e | Move to the end of the line |
| Ctrl + p or up arrow | Move up one line |

# MANAGING FILES

| Use This Keyboard Shortcut | To Do This |
| :--- | :--- |
| Ctrl + r or F5 | Insert a file at the cursor's location |
| Ctrl + o or F3 | Save a file |
