# EXAMPLES

# This Command

cat example.txt

cat example.txt | less

cat example.txt | more

cat -s example.txt | less

cat -n example.txt | less

cat file1.txt file2.txt > file3.txt

# Does the Following

Displays the specified file (example.txt). If the file is too long to view conveniently on one screen, use less or more, as in the following examples.

Displays the specified file (example.txt) using the less utility.

Displays the specified file (example.txt) using the more utility.

Displays the specified file (example.txt) using the less utility and suppresses blank lines.

Displays the specified file (example.txt) using the less utility and numbers the lines.

Concatenates the two input files (file1.txt and file2.txt) and writes the output to a third file (file3.txt).

# cksum

```
cksum [ *filename* ]
```

Performs a cyclic redundancy check (CRC) for the specified filename to determine whether the file has been altered or damaged. You can specify more than one filename in a space-separated list or by using a shell pattern (see the section “Shell Patterns” in Chapter 4). This command’s output consists of an identifying code that uniquely identifies the file’s contents; a change in even one of the file’s characters will cause the code to differ.
