# AT A GLANCE (CONT.)

+   **How Do I**
+   Close the window in which the cursor is positioned?

+   **Example**
+   emacs: Ctrl + x, 0
+   emacs: Ctrl + k, i
+   vi: Ctrl + w, q
+   emacs: Ctrl +x, Ctrl + f
+   joe: Ctrl + k, e
+   vi: :x

+   Create a new file?

+   Delete a line?

+   emacs: Ctrl + k
+   joe: Ctrl + j
+   pico: Ctrl + k
+   vi: dd

+   Mark a block of text?

+   emacs: Ctrl + spacebar
+   joe: Ctrl + k, b
+   pico: Ctrl + ^

+   Move to the beginning of the file?

+   emacs: Home
+   pico: Ctrl + w, Ctrl + y or 1G (1, shift 6)]

+   Move to the end of the file?

+   emacs: End
+   pico: Ctrl + w, Ctrl +v

+   Open a file?

+   emacs: Ctrl + w, Ctrl + v
+   joe: Ctrl + k, e
+   pico: Ctrl + r
+   vi: :e

+   Quit the editor?

+   emacs: Ctrl + x, Ctrl + c
+   joe: Ctrl + k, X
+   pico: Ctrl + x
+   vi: :x or :q!

+   Reformat the text after an editing change?

+   emacs: Alt + q
+   joe: Ctrl + r
+   pico: Ctrl + j

+   Save a file?

+   emacs: Ctrl + x, Ctrl + s
+   joe: Ctrl +k, d
+   pico: Ctrl + o
+   vi: :w
