# TILDE PREFIXES

| Use This Prefix | To Do This |
| :--- | :--- |
| ~ | Insert the current user's home directory |
| ~/subdirectory | Insert a path name that begins with the user's home directory and includes subdirectory |
| ~+ | Insert the name of the current directory |
| ~- | Insert the name of the previous directory |

# EXAMPLES

| This Command | Does the Following |
| :--- | :--- |
| `dir ~` | Displays the contents of the current user's home directory. |
| `dir ~+` | Displays the contents of the current directory. |

# Command Substitution

With *command substitution*, you can insert the output of a command within a command that you are creating. You can use either of two alternative forms of command substitution syntax shown in the following table.

# COMMAND SUBSTITUTION SYNTAX

| Command Form | Meaning |
| :--- | :--- |
| &`command` | Insert the output of *command* |
| `"command"` | Insert the output of *command* |
