| **XkbOptions option** | Specify one of the following keyboard mapping options: | | |
| **grp:switch** | The right Alt key engages the shift lock while pressed. | | |
| **grp:toggle** | The right Alt key changes the shift lock. | | |
| **grp:shift_toggle** | Both Shift keys together change the shift lock. | | |
| **grp:ctrl_shift_toggle** | Control+Shift changes the shift lock. | | |
| **grp:ctrl_alt_toggle** | Alt + Control changes the shift lock. | | |
| **ctrl:nocaps** | Makes CapsLock an additional Ctrl key. | | |
| **ctrl:swapcaps** | Swap the functions of Ctrl and Caps Lock. | | |
