# Alphabetical Command Reference

This section details commands for the following tasks:

+   * Archiving files (cpio, tar)
+   * Compressing and decompressing files (bzip2, bzip2recover, bunzip2, compress, gunzip, gzexe, gzip, unarj, uncompress, unzip, zip, zipnote, zipinfo, zipsplit, zforce, znnew)
+   * Encoding and decoding files (binhex, hexbin, macunpack, mimencode, uudencode, uuenode)
+   * Encrypting and decrypting files (gpg, mencrypt, mdecrypt)
