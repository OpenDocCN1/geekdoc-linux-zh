# OPTIONS

Use This Option
-T cols, -tabssize=cols
-time=time type
-u, -sort=time
-v
-version
-w cols, -width=cols
-X
-X

To Do This
For columnar output, specify the column width (cols) in characters.
List files sorted by any of the following types: atime, access, use, ctime, or status.
List files sorted by the time of the last access. Use -ul to list the times.
List files sorted by version.
Display version number.
Specify the screen width (cols) in characters.
List entries line by line instead of by columns.
Sort by extension. Same as --sort=extension.

# EXAMPLES

This Command
dir
dir *.doc
dir -R *.jpg
dir -S1
dir -Sh1
dir -t1, dir -c1
dir -Rt1r *.doc
dir -F

Does the Following
Lists files and directories in the current directory in case-sensitive, alphabetical order.
Lists only those files with the .doc extension.
Lists all the files with the *.jpg extension in the current directory and all associated subdirectories.
Lists files sorted by size, showing the largest files first.
Lists files sorted by size, showing the largest files first, and shows the sizes in a human-readable form.
Lists files by the time of the last modification, showing the most recently modified files first.
Using reverse chronological order (oldest files first), lists all the files in the current directory and all associated subdirectories that have the *.doc extension.
Displays filenames with appended characters that indicate the file type, such as executable (*) or directory (/).
