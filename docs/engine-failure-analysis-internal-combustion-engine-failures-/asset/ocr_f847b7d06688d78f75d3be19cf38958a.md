# Bitmaped Fonts

This section lists the bitmaped fonts that are typically provided with Linux distributions, organized into the following sections:

+   - 75dpi monospace fonts (bitmaped)
+   - 100dpi monospace fonts (bitmaped)
+   - 75dpi character cell fonts (bitmaped)
+   - 100dpi character cell fonts (bitmaped)
+   - 75dpi and 100dpi proportionally-spaced fonts (bitmaped)
