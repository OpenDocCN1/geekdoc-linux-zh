
# trap

`trap [ 选项 ] [ 命令 信号]`  
如果接收到指定的信号，则执行该命令。

## 选项

| 使用此选项 | 以实现此功能 |
|---|---|
| -I | 列出可用信号 |

# type

`type [ 选项 ] 命令`  
显示指定命令的绝对路径名，并指示该命令是否已被哈希化。

另请参阅 hash。

## 选项

| 使用此选项 | 以实现此功能 |
|---|---|
| -a, --all | 显示指定命令的所有实例 |
| -p, --path | 显示指定命令的哈希值 |
| -t, --type | 指示指定文件的类型 |

# ulimit

`ulimit [ 选项 ] [ n ]`  
显示资源限制。如果指定了 *n*，则设置该限制。

## 选项

| 使用此选项 | 以实现此功能 |
| :-------------- | :--------- |
| -a | 显示所有当前限制 |
| -H | 设置硬限制 |
| -S | 设置软限制（默认） |
| -c | 显示或设置核心文件大小的限制，单位为 K（千字节） |
| -d | 显示或设置进程数据段大小的限制，单位为 K（千字节） |
| -f | 显示或设置 Shell 创建文件大小限制，单位为 K（千字节） |
| -m | 显示或设置最大常驻集大小，单位为 K（千字节） |
| -s | 显示或设置最大堆栈大小，单位为 K（千字节） |
| -t | 显示或设置最大 CPU 时间，单位为秒 |
| -u | 显示或设置最大用户进程数 |
| -v | 显示或设置虚拟内存的最大大小，单位为 K（千字节） |

# unalias

`unalias [ 选项 ] [ 名称 ]`  
删除你创建的一个别名（请参阅 *alias*）。如果你在没有提供名称的情况下使用 –a 选项，bash 将删除你创建的所有别名。

## 文件名

在标准的 Linux 文件系统中，第二扩展文件系统（e2fs），你可以创建长达 255 个字符的文件名。请注意，Linux 文件名区分大小写：essay-1.DOC 和 essay-1.doc 是两个不同的文件。在命名文件时，请避免使用下表“非法字符”中列出的非法字符。最好仅使用字母 a–z（或 A–Z）、数字 0–9 和下划线（_）。某些实用程序和应用在处理包含空格的文件名时可能会遇到问题。

Linux 不要求使用后缀，也称为扩展名。后缀是文件名中点号后的部分。如果你使用后缀，请使用符合标准或通行做法的后缀（请参阅本节的“常用后缀”表）。以点号开头的文件名称为*隐藏文件*，它们不会出现在默认的 `ls` 目录列表中。使用 `ls -a` 可以查看所有文件，包括隐藏文件。

> **提示** 如果文件缺少后缀，输入 `file` 后跟一个空格和文件名，然后按 Enter。你将看到文件中包含的数据类型的简要描述。

### 非法字符

| 字符 | 功能 |
|---|---|
| # | 插入注释；bash 忽略该行剩余部分。 |
| & | 插入命名变量。 |
| * ? [ ] ! | 构建 Shell 模式。 |
| < > | 重定向输入和输出。 |
| \` | 插入指定命令的输出。 |
| ; | 在同一行开始新命令。 |
| ( ) | 将命令分组以便在子 Shell 中执行。分组命令在其他命令之前执行。 |
| { } | 将命令分组以便它们*在其他命令之前*执行。 |

## 目录和标准目录结构

Linux 文件系统被组织成目录的层次结构，**根目录**（/）位于顶部。目录结构不绑定于特定的存储设备。它可以跨越两个或更多物理磁盘驱动器，还可以包括网络中其他计算机的目录。在任何给定时间，只有一个目录，即*工作目录*，是当前的。该目录在目录结构中的位置由其*绝对路径名*指定，例如 /home/suzanne/Documents/Essays。请参阅本节的“目录名称和符号”表以了解标准命名法。

在*工作目录*中，你也可以使用相对路径名。例如，在 /home/suzanne/Documents/ 中，你可以输入 **cd Essays** 更改到 /home/suzanne/Documents/Essays 目录。符合标准的 Linux 系统使用一种标准方法组织顶级目录（请参阅本节的“标准目录结构”表）。
