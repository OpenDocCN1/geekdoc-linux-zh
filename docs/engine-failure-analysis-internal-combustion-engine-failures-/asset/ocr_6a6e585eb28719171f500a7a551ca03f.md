# su

```
su [ *username* ]
```

Creates a new shell session with a different user’s ID and privileges. If you run *su* without specifying a username, you create a shell for the *superuser*; that is, a user who has gained the root user’s privileges. You’ll be prompted to specify the user’s password. To exit the *superuser* shell, type `exit` and press Enter.

# tty

```
tty
```

Displays the number of the terminal device that is currently in use.

See also `chvt`.
