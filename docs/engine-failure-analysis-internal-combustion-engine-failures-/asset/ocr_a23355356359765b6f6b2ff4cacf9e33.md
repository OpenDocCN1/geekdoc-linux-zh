# NUMERIC MODE OVERVIEW (*CONT.* )

| Use This Mode | To Indicate This Permission |
| :--- | :--- |
| 7 (1 + 2 + 4) | Other users may execute, write, and read (o=wrx). |
| 10 | Group users may execute (g=x). |
| 20 | Group users may write (g=w). |
| 40 | Group users may read (g=r). |
| 60 (20 + 40) | Group users may write and read (g=wr). |
| 70 (10 + 20 + 40) | Group users may write, read, and execute (g=wrx). |
| 100 | The file's owner may execute (u=x). |
| 200 | The file's owner may write (u=w). |
| 400 | The file's owner may read (u=r). |
| 600 (200 + 400) | The file's owner may write and read (u=wr). |
| 700 (100 + 200+ 400) | The file's owner may write, read, and execute (u=wrx). |
| 1000 | Save the text image on a swap device. |
| 2000 | Set the group ID on execution (u=s). |
| 4000 | Set the user ID on execution (u=s). |
