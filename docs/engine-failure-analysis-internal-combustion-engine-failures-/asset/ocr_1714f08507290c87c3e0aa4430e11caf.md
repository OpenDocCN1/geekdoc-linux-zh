# REQUIRED OPTIONS (CONT.)

+   | Use This Option | To Do This |
+   | :--- | :--- |
+   | **\-delete** | Delete from the archive. This option cannot be used with magnetic tapes. |
+   | **-r, --append** | Append the specified files to the end of an existing archive. |
+   | **-t, --list** | List the contents of an archive. |
+   | **-u, --update** | Append the specified files to an existing archive, but only if they are newer than the files already in the archive. |
+   | **-x, --extract, --get** | Extract files from an existing archive. |

# OPTIONS

+   | Use This Option | To Do This |
+   | :--- | :--- |
+   | **--atime-preserve** | Keep the existing file access times. |
+   | **-b, --block-size *n*** | Specify the block size in multiples of 512 bytes. The default is *n*=20. |
+   | **-B, --read-full-blocks** | Reblock during reading for BSD version 4.2 pipes. |
+   | **-C *directory*, --directory *directory*** | Change to the specified directory. Print directory names while reading the archive. |
+   | **-f *filename* --file *filename*** | Use the specified archive file. You can specify an external location using the form *hostname:*filename*. Use a local archive file even if an external location is specified. |
+   | **--force-local** |  |
+   | **-filename, --info-script *filename*, \-new-volume-script *filename*** | Run script at end of each tape. |
+   | **-G, --incremental** | Use the old GNU-format incremental backup. |
+   | **-g *filename*, --listed-incremental *filename*** | Use the new GNU-format incremental backup. |
