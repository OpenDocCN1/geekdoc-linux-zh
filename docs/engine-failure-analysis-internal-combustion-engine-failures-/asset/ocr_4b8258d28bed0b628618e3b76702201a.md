# DEVICES SECTION ENTRIES *(CONT.)*

**Use This Entry** | **To Do This**
**Option** *string* | This optional entry allows the user to select certain options provided by the drivers. Multiple-option entries may be given. The supported values for option string are given in the appropriate X server manual pages or in the chipset-specific READIME files.
**POSBase** *address* | Specify the base address of the POS, which is needed for some servers. Consult the server’s documentation.
**VendorName** *vendor* | This optional entry specifies the graphics device’s manufacturer.
**VGBase** *address* | Specify the base address of VGA memory, which is needed for some servers. Consult the server’s documentation.
**VideoRam** *n* | Specify the amount (in K) of video RAM installed on the adapter, which is needed for some servers. Consult the server’s documentation.

# The Screen Section

The Screen section brings together the specifications previously entered in the Monitor and Device sections. It defines one or more Display subsections, which specify the video modes that will be available when you use your system.

Here is an example of the Screen section:

```
Section  "Screen"
Driver     "accel"
Device     "MagicGraph  NM2160"
Monitor    "LCD  Panel 1024x768"
Subsection  "Display"
Depth  16
Modes  "800 x 600"
Viewport 0 0
Virtual  1024  786
```
