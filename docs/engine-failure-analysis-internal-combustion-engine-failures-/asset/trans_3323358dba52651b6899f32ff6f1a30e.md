## 按字母排序的命令参考

在本节中，您将找到用于执行以下任务的命令：

- 在线阅读程序文档（`apropos`、`help`、`info`、`man`、`whatis`、`who`、`whoami`）
- 显示和设置日期和时间（`cal`、`date`、`hwclock`、`rdate`、`tzselect`）
- 向其他用户提供关于您自己的信息（`chfn`、`finger`）
- 显示用户信息（`groups`、`id`、`rwho`、`users`、`w`）
- 获取有关您系统的信息并了解您的位置（`hostname`、`pwd`、`uname`、`uptime`）

### apropos

`apropos string`

搜索 man（手册）页面标题和描述的数据库，并返回包含指定 *string* 的 man 页面列表，该 *string* 可以出现在页面的条目中的任何位置，包括描述和标题。使用 `whatis` 仅返回那些与指定标题完全匹配的页面。例如，`apropos lookup` 返回包含 `lookup` 在其标题或描述中的所有 man 页面列表。

#### 示例

- **此命令**
  `apropos fonts`
- **执行以下操作**
  显示其标题或简要描述中包含单词 `fonts` 的 man 页面列表。

### cal

`cal [ option ] [ month ] [ year ]`

在未输入选项的情况下，显示当前月份的格式化日历。可用的选项使您能够以多种格式显示和打印日历。

#### 选项

- **使用此选项**
  `-j`
  **执行此操作**
  使用儒略日期显示日历，日期从 1（1 月 1 日）顺序编号到年底
- **使用此选项**
  `-y`
  **执行此操作**
  显示整个年度的日历

#### 示例

- **此命令**
  `cal`
  **执行以下操作**
  显示当前月份的日历。
- **此命令**
  `cal -y`
  **执行以下操作**
  显示整个当前年度的日历。
- **此命令**
  `cal -y 2005`
  **执行以下操作**
  显示 2005 年全年的日历。
- **此命令**
  `cal 06 2003`
  **执行以下操作**
  显示 2003 年 6 月的日历。
- **此命令**
  `cal -y 2003 | lpr`
  **执行以下操作**
  打印 2003 年的日历。

### chfn

`chfn [ option ]`

在未输入选项的情况下，chfn 提示您提供由 `finger` 提供的信息（在本章稍后描述），包括全名、办公室房间号、办公室电话和家庭电话。您可以使用选项在命令行中指定其中一项或多项。为确保某个字段为空，例如家庭电话号码，请使用键盘输入 "none。"

另请参阅 `finger`。

#### 选项

- `--full-name full name`：指定您的全名
- `--office office number`：指定您的办公室房间号
- `--home-phone home phone number`：指定您的家庭电话号码
- `--office-phone office phone number`：指定您的办公室电话号码
- `--help`：列出可用选项
- `--version`：显示版本号

#### 示例

| 此命令 | 执行以下操作 |
| :--- | :--- |
| `chfn` | 进入 `chfn` 的交互模式，以便您可以针对实用程序的查询提供所有信息。 |

### date

`date [ option ] [ date ]`

在未输入选项的情况下，显示由 *system clock*（Linux 内核中的一个实用程序）跟踪的当前日期和时间。要从局域网或 Internet 上的另一台计算机获取日期和时间，请参阅 **`rdate`**。

> **警告** 不要使用 **`date -s`** 更改系统时钟。始终使用本章中描述的 **`hwclock`**，然后重启您的系统以同步系统时钟和硬件时钟。如果您在时间依赖进程正在运行时更改系统时钟，您的系统可能会崩溃。

#### 选项

| 使用此选项 | 执行此操作 |
| :--- | :--- |
| `-u, -utc` | 以协调世界时（UTC）显示日期和时间，也称为格林尼治标准时间（GMT）。 |
| `-s date` | 设置日期（需要 root 用户权限）。不要使用此选项；请参阅本章稍后描述的 **`hwclock`**。 |

#### 示例

| 此命令 | 执行以下操作 |
| :--- | :--- |
| `date` | 显示当前日期和时间。 |
| `date -u` | 显示协调世界时（UTC）。 |

### finger

`finger [ options ] username`

显示 *username* 中指定的用户的数据，包括用户的全名、办公室房间号、电话号码、电子邮件状态（用户是否已收到未读电子邮件）以及存储在用户的 `.plan` 和 `.project` 文件中的信息。在局域网和 Internet 中，可以通过指定 *username* 使用格式 `user@remote-host`（例如 `mike1@profrodo.paffenberger.org` 或 `mike@192.168.10.14`）来获取远程用户的信息。`finger` 实用程序依赖于 `finger` 守护程序，许多系统管理员默认禁用了该守护程序，既是为了保护用户的隐私，也是为了关闭未授权入侵者的潜在入口点。要填写您自己的基本 `finger` 信息，请参阅 `chfn`（在本章前面描述）。您可能还希望在主目录中创建并保存 `.plan` 和 `.project` 文件。`.plan` 文件包含您的会议日程，而您的 `.project` 文件包含您正在从事的项目列表。

> 一些组织使用 **FINGER** 来提供专业化信息。输入 **`finger quake@gdls.crussgs.gov`** 可查看最近地震的列表（包括确切时间、确切地点、深度、震级和简要评论）。

#### 选项

| 使用此选项 | 执行此操作 |
| :--- | :--- |
| `-l` | 以长（详细）格式列出可用信息 |

### groups

`groups [username]`

在未输入用户名的情况下，`groups` 显示当前用户所属的用户组。要查看有关您自己的所有用户和组 ID 信息，请使用 `id`。
