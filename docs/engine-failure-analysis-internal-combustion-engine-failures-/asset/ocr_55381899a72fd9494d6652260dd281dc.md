# Use This Option  
To Do This

+   - `–comment string`  
+   Annotate an image using the specified string.  
+   You can use the following expansion symbols:  
+   	`%b` File size.  
+   	`%d` Directory.  
+   	`%e` Filename extension.  
+   	`%f` Filename.  
+   	`%h` Height.  
+   	`%m` Magic.  
+   	`%p` Page number.  
+   	`%s` Scene number.  
+   	`%t` Top of filename.  
+   	`%w` Width.  
+   	`%x` X resolution.  
+   	`%y` Y resolution.  
+   	`\n` Newline.  
+   	`\r` Carriage return.

+   - `–compress type`  
+   Set the type of image compression. The options are as follows: B2zip, Fax, Group4, JPEG, LZW, RunlengthEncoded, None, and Zip.

+   - `–contrast` `+contrast`  
+   Enhance (_–contrast_) or reduce (_+contrast_) the image contrast.

+   - `–crop width x height`  
+   Crop the image at the specified width and height.

+   - `–cycle n`  
+   Displace the image color map by the specified amount (_n_).

+   - `–density width x height`  
+   Set the vertical and horizontal resolution of the image to the specified width and height in pixels.

+   - `–depth value`  
+   Set the color depth of the image (8 or 16).

+   - `–despeckle`  
+   Reduce speckles in the image.

+   - `–dispose type`  
+   Use the specified type of GIF disposal. The options are as follows:  
+   	**0** No disposal.  
+   	**1** Do not dispose between frames.  
+   	**2** Overwrite the frame with the background color.  
+   	**3** Overwrite with the previous frame.
