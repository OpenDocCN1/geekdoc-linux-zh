# OPTIONS (CONT.)

**Use This Option** | **To Do This**

+   * `-p, percentage` -- `set-pitch percentage`
+   * `-P n, -set-overlap n`
+   * `-q, -quiet`
+   * `-R, -dump-rates`
+   * `-r n, -rate n`
+   * `-s, -stereo`
+   * `-S n, -speed-select n`
+   * `-T, -deemphasize`
+   * `-t start track[ +end track ], -track start track[ +end track ]`
+   * `-v n, -verbose-level n`
+   * `-V, -verbose-SCSI`
+   * `-w, -wait`
+   * `-x, -max`

+   * Change the pitch by the specified percentage.
+   * Set the number (n) of overlap sectors for jitter correction.
+   * Hide messages.
+   * Show the possible dump rates.
+   * Set the sample rate to n samples per second.
+   * Record in stereo.
+   * Set the CD-ROM to speed n.
+   * Undo the effect of pre-emphasis in the input samples.
+   * Specify the start track and, optionally, the end track.
+   * Set the level of verbosity from 0 (messages hidden) to 63 (maximum).
+   * Enable SCSI command logging to the console.
+   * Wait for signal before recording.
+   * Set maximum CD-ROM quality.

# EXAMPLE

**This Command** | **Does the Following**

```
cdda2wav -I generic_scsi
-D0,4,0 -t1+5
```

Reads tracks 1 through 5 on the specified SCSI CD-ROM drive (bus 0, ID 4, LUN 0) and writes WAV files to the working directory.
