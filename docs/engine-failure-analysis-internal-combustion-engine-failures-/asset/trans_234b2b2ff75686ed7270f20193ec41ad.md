
## 标记文本

| 使用此键盘快捷键 | 功能 |
|---|---|
| Ctrl + 空格键 | 标记区域的开始或结束位置 |
| Esc h | 标记当前段落 |
| Esc @ | 标记下一个单词 |
| Ctrl + x, h | 标记整个缓冲区 |
| Ctrl + x, Ctrl + p | 标记整个页面 |
| Alt + x, transient-mark-mode | 切换区域高亮的开启与关闭 |
| ESC = | 统计标记区域内的行数 |
