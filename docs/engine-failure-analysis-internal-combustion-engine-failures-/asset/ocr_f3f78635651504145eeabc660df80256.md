# uunocode

**uunocode [ option ] [ input fileName ] name > output filename**

Encodes the binary file specified by *fileName* so that it can be transferred over a medium that does not support non-ASCII characters. *Name* is the name of the file included in the encoding. By default, this utility writes to standard output. Use output redirection to write to an output filename.

> **TIP** Don't forget to include a name for the enclosed file; it's required.

See also mimencode, uudecode.

# OPTION

| Use This Option | To Do This |
| --- | --- |
| -m | Use base-64 encoding |


# EXAMPLE

| This Command | Does the Following |
| --- | --- |
| uunocode interior.jpg interior.jpg > interior.uue | Encodes the specified file (interior.jpg) and saves the encoded output to interior.uue. The uunencoded file indicates that the file is named interior.jpg. |
