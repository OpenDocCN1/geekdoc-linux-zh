The first example in Listing 10.48 deletes the first line of the input, as explained above. The second command deletes lines 1 to 5 from the input, and the next example deletes the last line. As in vi, the dollar sign is a placeholder for the last line.

If the line number for which a sed command is executed is not known, a regular expression can be used as a search pattern. Here, you can also specify an address range by indicating two regular expressions separated by a comma. It is obviously possible to indicate the beginning with a line number and the end with a regular expression and vice versa. Listing 10.49 shows some examples for the use of search patterns in sed; the results are not shown below.

```
(Linux):> head /etc/services | sed -e '/^#//d'
(Linux):> head /etc/services | sed -e '/tcp/d'
(Linux):> head /etc/services | sed -e '/[A-Z][-a]/d'
(Linux):> head /etc/services | sed -e '/tcppmux/,/ftp/d'
```

The first call in Listing 10.49 deletes all lines that contain a hash sign (#) in the first column from the input file.
