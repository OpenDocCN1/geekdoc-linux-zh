If the connection is interrupted because of a timeout, ange-ftp reestablishes it automatically. For the user, the remote file looks like a completely normal buffer. Then, all commands that work on Emacs buffers can be used. The only difference is slower transmission of files via the network.

Even if you can reach remote computers only via a gateway, you can still use ange-ftp. You simply enter the name of the gateway in the variable ange-ftp-gateway-host. More about gateway configuration can be found in the info document.

If you do not have an Internet connection, using ange-ftp will make sense. Many users work only under X and use xauth (this is the LINUX default) for authorization of the client. This means that no client can be started from an xterm. You can use either xauth to transmit the magic cookie (see also Section 6.6) or allow access to all local clients with xhost.

In a larger network, the use of xhost for the X authority is not particularly recommended. In this case, you can allow a login of the user root via ftp and use ange-ftp. For security reasons, however, most computers exclude ftp as root. My tip in such cases is to use the ssh; more about this can be found in Section 17.4.

# 5.5.5 The outline-mode

When processing larger files, it is easy to lose the overall perspective and go on browsing through the file. Another problem is that the contents structure is barely reflected in the file. Here, help is provided by the outline-mode. Mode can be used as both major and minor mode, so that even inside Lisp, Lisp, or C files, the functions of the outline-mode can be used.

The Emacs function that displays the latest development NEWS (C-h n, view-emacs-news) uses the outline-mode. In this mode, you can display only the headlines and show the hidden nodes on demand. You can call these functions by means of a menu, Emacs:outline-mode which shows an overview of the most important key combinations.
