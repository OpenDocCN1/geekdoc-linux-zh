/usr/share/man directory is the primary manual directory. Here, you will find all man pages for the programs contained in / and /usr.

In directories other than /usr/share/man, individual sections can be omitted if no manual pages are needed for these sections. This applies, for example, to category 4, device files, which exists only under /usr/share/man, but not under /usr/local/man.

Man pages are distributed in English. It is, however, desirable that programs should in future be supplied with translated man pages. A group of committed users working with Martin Schulze doing just for German translations, and there are other translations as well.

For an ordered, language-dependent access, you need to create a subdirectory for each new language in the above-mentioned structure is again created. For manual pages in English, you can still use the path /usr/share/man/mansection; German manual pages would be found under /usr/share/man/de/man/. The names of the directories are derived from the POSIX.1 standard; a precise explanation can be found in Section 8.3.

If a distribution installs preformatted man pages, this can be done in the catman directory. Installing only preformatted man pages is generally considered poor style. Users can view this documentation on screen, and cannot output it as a PostScript or DVI file. This makes a visually appealing printout impossible.

# /usr/share/misc - miscellaneous

Many programs have only one or a few files that can be stored under /usr/share. Since it is not worth creating a separate subdirectory for each program, it has been decided to propose this directory. The FHS contains a list of files that are likely to be found here.
