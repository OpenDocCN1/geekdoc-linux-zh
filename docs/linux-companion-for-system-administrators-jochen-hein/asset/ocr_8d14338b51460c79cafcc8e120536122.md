#  9.5 Foreign language characters in editors

One of the essential application areas in which one would like to use foreign language special characters is text editing. For many users it is much easier to input umlauts or accented letters with single keystrokes than by means of some kind of transcription. It is therefore essential that editors are 8-bit clean or they can be properly configured. This section briefly presents various editors and gives general hints on possible adaptations.

#  9.5.1 vi clones

Each and every UNIX system distribution includes a vi or a corresponding clone. No matter what you may think of vi, you should at least be able to use it to carry out simple functions. Widely used vi such as elvis, vim, and nvi (BSD vi) are 8-bit clean.

#  9.5.2 The GNU Emacs editor

Since version 19.26, Emacs has also taken the environment variable LC_CTYPE into account. Therefore, the only thing you have to do when using Emacs 19.26 and later versions, is to assign the environment variable LC_CTYPE value ISO-8859-1.
