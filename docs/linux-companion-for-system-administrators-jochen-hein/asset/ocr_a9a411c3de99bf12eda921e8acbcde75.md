Debian pioneered the 'Debian Free Software Guidelines' which define what the Debian developers consider to be free software. Only such software will be part of the Debian base system. Besides, non-free packages may be available on the ftp server, and the bug-tracking system may be used for this.

For installation and updates of program packages, a specific package format and tool (dpkg) were developed. An important advantage is that the system or individual programs can be updated without problems, without having to format the hard disk and reinstall the software from scratch. The strategies developed for this purpose have recently been adopted by other distributions (for example S.U.SE. and Red Hat).

A further advantage is the consequent bug tracking, which is carried out by the developers via mailing lists. The list of error messages is public and is regularly searched for errors that have remained unfixed for too long. This makes the Debian distribution the most stable and error-free distribution. The developers also place great emphasis on the fact that the Debian distribution complies with the file system standard.

All sources, including the necessary patches, are part of distribution. This also makes it possible for the user to recompile the system completely. In addition, the distribution is supplied with an extensive installation manual. Debian has defined a set of policies for packages, release strategy and so on. These help the maintenance engineers to do their work, and give users a stable and dependable system to build on. The Debian project does not sell CDs, but provides official images that may be used by others. If you would like to purchase a CD set see the Debian Homepage for a list of vendors.

Development and support are essentially carried out via email, establishing a series of mailing lists. You can subscribe to the lists debianuser, debian-changes, and debian-announce by sending an email to debian-list-request@pixar.com and typing subscribe in the message body.
