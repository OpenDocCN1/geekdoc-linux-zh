```
module=file ...
```

Loads a multiboot module. Modules may be stored compressed and will be decompressed automatically.

```
modulenounzip=file ...
```

Like the option module=, but grub will never attempt automatic decompression.

grub has no mounted file systems, but can access files on different file systems because it knows the internal structures of these file systems. This is the reason that you must enter the name of the partition as well as the filename. The syntax:

```
disk,partition,BSD-slice
```

You can use fd0/fdl for the floppy drive, but in that case you can't add a partition. If you use hd0/hd1 you can access the MBR if you don't enter a partition number. The partition numbering starting with zero, so the first partition of the first hard disk is (hd0,0). The naming scheme is derived from the BSD systems and is therefore different from the LINUX naming.

Beside the normal partitions used by DOS, Windows or LINUX, grub can also access slices of BSD systems. You can append a character to the partition number to identify the slice.

If grub expects a file name, you can append the absolute path to the partition name. For some functions it is possible to enter an offset or a sector number(with sector number).

You will appreciate grub's command line editor when you use it. The usage is similar to the bash shell and has completion well. The tab key shows a list of possible commands or other input. Since the size of grub is very restricted, not all functions of the bash interface are implemented.

The most useful commands for interactive usage are kernel= to select the kernel to boot and boot to finally start the operating system. Be aware that the command boot has no further options and you must enter all kernel parameters in the kernel= command.

# Installing grub

Installing grub is not as easy as LILO. For LILO you create a configuration file /etc/lilo.conf and run LILO. Most distributions contain a configuration interface, so most users don't need to worry when installing LINUX.
