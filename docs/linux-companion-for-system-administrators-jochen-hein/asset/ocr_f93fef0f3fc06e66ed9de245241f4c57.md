It will be obvious that different distributions match different requirements and that the suitability of a distribution will depend on the user's requirements. Now you can even get a system with LINUX pre-installed, so you have no hassle installing it.

Thanks to the GNU General Public License (GPL), to which many of the programs used under LINUX and the kernel are subject, every distributor is bound to supply the source code of the corresponding program together with the program or provide it on demand. Therefore, many distributions also include the program sources on the CD. In case of problems, you can then change and recompile individual programs or find out which options these programs were installed. This is an area where we can find significant differences between the distributions.

A difference is to be found in the support given by the developers. Some CDs are offered without support, others entitle the user to installation support (via email, fax, or telephone) by the distributor. Some companies like LINUX offer regular support contracts or consulting services. Often, vendors maintain a mailing list in which special support is given for their distribution. More detailed information can be found in your distribution documentation.

To prevent excessive differences between the distributions, the File System Hierarchy Standard (see Chapter 2) was developed, which defines a LINUX directory structure. Most of the distributions presented here adhere to this standard, but some deviate from it in individual cases. These deviations are usually documented in the distribution manual. There is an ongoing effort to create a 'LINUX Standard Base' that defines a complete base system, so that binary programs may be installed and used on any LINUX system without any problems.

Further information on the distributions presented here and on other distributions, such as, for example, the addresses of the distributors, can be found in the Distributions-HowTo. For practically every imaginable subject under LINUX, there is a HowTo file which introduces the subject and partly assumes the function of a FAQ (Frequently Asked Questions) list. Besides the HowTo documents, however, there is also a list of FAQs. In addition, a group of volunteers works on the LINUX Documentation Project (LDP), which produces man pages and manuals. These books are of good quality and some of them are also sold in bookstores. An overview of published titles can be found in Appendix C.
