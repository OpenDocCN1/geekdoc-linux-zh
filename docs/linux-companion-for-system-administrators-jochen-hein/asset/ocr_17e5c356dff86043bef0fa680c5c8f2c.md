# The path of a file - dirname

The dirname command works in a similar way to the basename command. supplying the path name without the file name as output. If the name passed as a parameter does not contain a directory, a dot (.) is output that stands for the current directory. An example can be found in Listing 10.13.

```
(Linux):$ dirname /etc/rc.d/rc.local
/etc/rc.d
(Linux):$ dirname /vmlinuz
/
(Linux):$ dirname vmlinuz
```
