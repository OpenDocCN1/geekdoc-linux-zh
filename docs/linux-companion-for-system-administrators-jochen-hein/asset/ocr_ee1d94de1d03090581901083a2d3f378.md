# # 7.3 Backup media

With today’s hard disk sizes, a complete backup on diskettes have become
practically impossible. The expense in time and backup media is out of all
proportion to the security to be gained. Nevertheless, backups on diskets of
small amounts of data which need frequent backing up are possible and make
sense. The text of this book was backed up on diskette after each change.

For a convenient and automatic backup it is necessary for the data of a
backup to fit on a medium, so that the presence of the system administrator (for
example, for changing tapes) is not required. This allows backups to be carried
outnight without human intervention.

Frequently, magnetic tapes are used as backup media. Tapes are inexpensive
and, despite the sequential access, sufficiently fast. There are several different
standards for magnetic tapes and the corresponding drives or interfaces to which
trive can be connected. The best known standards are the QIC (Quarter Inch
Cartridge) standards.
