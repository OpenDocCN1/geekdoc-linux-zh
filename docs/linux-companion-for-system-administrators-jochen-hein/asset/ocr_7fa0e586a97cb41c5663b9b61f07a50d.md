# 9.6.2 The mail and news reader pine

The mail and news reader pine (Pine Is No longer Elm) is a further development of elm. Pine is easy to use and is MIME-capable. Therefore, pine has no problems with representing or sending 8-bit characters.

# 9.6.3 The news reader nn

Yet another reader is the program nn. nn represents 8-bit characters by means of the following entry in the file ~/.nn/init:

+   - data-bits allows representation of
- 8-bit characters in nn
set data-bits 8

# 9.6.4 Emacs/rmail

Besides other features, the Emacs editor also includes modes for creating and reading mail and news. A mode for mail is the rmail mode which can be started either directly by calling Emacs -f rmail or from inside Emacs with the command sequence M-x rmail RET.

If Emacs is configured appropriately, 8-bit characters can be without problems if the transport route is 8-bit clean. If this is not the case, the minor mode mime can be used which convert a message into MIME format before sending it. Such messages can also be read under Emacs by means of the MetaMail package. A possible configuration for rmail is shown in Listing 9.11.

The description of the rmail mode in the Info system, can find a series of helpful comments in the sources of the rmail mode, /usr/lib/ emacs/version/lsp/rmail.el.

```
(set mail-yarn-prefix " >") ; text with " >" quotes
(set mail-signature t) ; signature from ".signature"
(set mail-default-headers
Mime-version: 1.0
Content-Type: text/plain; charset=iso-8859-1
Content-Transfer-Encoding: 8bit\n") use ISO-Latin-1
```
