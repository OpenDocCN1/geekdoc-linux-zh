# 424 NETWORK APPLICATIONS

'Network Virtual Terminal' via which programs can be controlled or other services requested.

For this purpose, the telnetd daemon must be started on the remote computer, which is usually down by means of inetd super server. Furthermore, you must have a valid user ID (user name and password) on this computer. Besides this normal application, telnet can also be used for testing other TCP protocols. The telnet protocol is defined in [rfc0854] and following.

In the simplest case, the call telnet hostname is used to establish a telnet connection with the specified computer. If you call the telnet program without parameters or send the escape sequence (usually Ctrl-\), you enter the command mode. In this mode the telnet> prompt a connection (open), close a connection (close), or define a special character (send). Extensive help information on all commands can be found in the main page telnet (1); a brief overview is displayed when you help in command mode. Please note that the command mode is terminated after each command if a connection with other system exists.

You can establish a connection to a port other than the telnet port by specifying the required service name or number after the host name. Thus, you can use the command telnet localhost smtp or telnet localhost 25 to establish a connection to the smtp port (Simple Mail Transfer Protocol) and then communicate directly with sendmail or small of the remote computer.

Apart from testing individual services, telnet can also be misused to test the connection. Usually, the ports discard (9) and echo (7) are used for this purpose. With discard, all entered characters are ignored, whereas echo sends all entered characters unchanged (by line by).

At start-up, the telnet program reads the file ~/.telnetrc. In this file you can specify various settings to adapt telnet to your requirements. The example in Listing 16.1 shows some possible configurations; a complete description can be found in the main page for telnet.

```
# configuration of the telnet program
localhost toggle binary
corn toggle binary
set interrupt ^
```
