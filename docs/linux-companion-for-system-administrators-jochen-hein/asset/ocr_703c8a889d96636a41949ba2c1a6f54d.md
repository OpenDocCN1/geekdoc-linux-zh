# 7.3.4 Backup via network

Under LINUX, as under any other UNIX, the backup can be carried out on a tape drive that is connected to another computer which can be reached via the network. For a large number of computers in a network, it may be sensible to create a backup server. This system is then connected to powerful tape machines, and all computers of the network could be backed up by this system.

This makes it possible to carry out central backup, so tape management need only take place at one location. Here, special measures such as the safe storage of cassettes can be organized relatively easily. Furthermore, it is no longer the individual user or the local system administrator who has to be responsible for backup, but backup can be established as a service of the computer center.

The disadvantages are the effort of coordinating and configuring the system plus in network load. Furthermore, a backup may take more time over the network than on a fast tape drive. However, if you need to backup many (networked) computers, you should in any case choose a network-wide solution.

# 7.3.5 CD-ROM or CD-RW

Today CD writers are available at a low cost for connection to an IDE or SCSI controller. Even cheap drives write at least double speed and have a capacity of 650 MBytes. In a lot of cases this is sufficient to backup your own data. The cost of the empty disks has fallen in the last years, so it is not too expensive to use CDs for regular backups.

CD-ROMs are stable for years, whereas some magnetic tapes should be copied at least once a year to another tape. Furthermore nobody can change data once it has been written to a CD-ROM, which is very useful for archives or revisions. Private users may prefer CD-RW for backup, because the disk can be overwritten when needed.
