In the next step, the name server to be used in the file /etc/resol.conf (Listing 15.3). The name of the file is derived from the resolver library (libresolv) which is responsible for name resolution. On some UNIX systems (as under older LIN systems) this library is an integrated part of libc, whereas on other systems and now with the GNU libc version 2, the resolver library must be explicitly linked with the option -lresol.

Up to three **nameserver** entries are allowed in the file /etc/resol.conf. The servers are addressed in the specified order, so the local (or most reliable) server should occupy the first position.

```
nameserver 192.168.3.150
domain store.tittfrutti.example.org
search store.tittfrutti.example.org tittfrutti.example.org
# sortlist sort-list
# options option-list
```
