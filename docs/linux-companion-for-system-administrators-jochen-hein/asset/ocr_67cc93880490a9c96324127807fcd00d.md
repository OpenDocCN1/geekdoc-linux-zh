# ACCESS CONTROL 197

Especially if you need to enter a password for X (for example, if you execute su), you should select the option 'secure keyboard' (Ctrl-left button) in xterm. This is the only way to ensure that only a program can receive your input.

An X server that is accessible via tcpip usually listens on port 6000 the number of the display. The X server for display :0 uses port 6000, the server for :1 uses port 6001. With scanner tools like nmap it is very easy to find machines running not log failed connections from other users, unless xfree does.

If you find an X server that has access from every user everywhere, it is very easy to keep other people from working. Just start keys on the victim's display. You can also view the screen with xwd. More disturbingly, you may end any of the programs runs. First search for a client with xclients and kill that program with xkill. See Listing 6.2 for details.

```
# export DISPLAY=victim:0
# xclients
victim.jochen.org kfm
victim.jochen.org gnome-terminal
victim.jochen.org kmix -miniix kmix.xpm
victim.jochen.org kpanel
# xclients -l ~a
```
