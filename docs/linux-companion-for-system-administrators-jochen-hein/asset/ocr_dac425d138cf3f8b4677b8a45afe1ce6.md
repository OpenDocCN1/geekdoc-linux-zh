# 1.1 Overview of LINUX features

LINUX is a powerful operating system during which the past years has developed from a 'hacker system' to a general-use system, even for commercial applications. Linux is now widely used as a server operating system, but is getting stronger as a desktop system, too. There are many reasons for this development. I would like to present some of these reasons, and give an overview of the possible applications of LINUX:

+   - free; is, practically the entire source code of the system is accessible to everybody. This allows interested parties to implement improvements and eliminate errors, or simply to learn how the system works.

+   - is a UNIX-like system, with all the flexibility of UNIX. X11 is used as a graphical user interface, and both Motif and CDE are available for LINUX, as well as OpenLook (XView). There are also desktop environments available such as GOME, KDE or Xfce.

+   - complies with international standards such as POSIX and ANSI C. Furthermore, it supports many BSD or System V extensions. This greatly facilitates porting of many UNIX programs.

+   - evolves, but knowledge obtained with older versions or other UNIX systems is for a large part still applicable.

+   - is portable to other hardware architectures such as DEC Alpha, MIPS or Sun Sparc computers. This makes it one of the most portable systems currently available on the market.

+   - can be flexibly employed in TCP/IP networks. Besides this, several other protocols (IPX, AppleTalk, SMB) are supported.

+   - still run on 386 PCs with 16 Mbytes of RAM, whereas a system with 32 Mbytes can be well used as a workstation running X. Thus, in comparison with Windows NT or 2000, the hardware requirements are significantly lower.

+   - makes efficient use of memory (via shared libraries and demand loading) and modern processors (Pentium and Pentium Pro).
