The tcpdump program is supplied together with simple awk scripts which can be used for the evaluation of the collected data. In practice, you can create appropriate scripts for frequently recurring tasks to be able, for example, to react quickly to problems without having to leaf through the pages first.

For anybody interested in the internals of the TCP/IP, the series 'TCP/IP illustrated' by Richard W. Stevens is ideal particular. In the first part, many protocols are analysed and observed by means of tcpdump.
There are also packet sniffers with a friendlier interface. If you run in textmode, iptraf is very useful, ksniff is a similar program for KDE, and GNOME users may use ethereal.
