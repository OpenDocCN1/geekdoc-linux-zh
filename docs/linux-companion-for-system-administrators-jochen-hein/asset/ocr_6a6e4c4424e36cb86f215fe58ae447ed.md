# UNIX tools

'Keep it simple, stupid'
One design goal of UNIX

One big advantage of UNIX is the large number of tools that facilitate working with the computer. Some of these are used to find files or execute programs on a periodic basis. Others can process text files relatively easily and quickly. There is an easy-to-use program for practically any (simple) task, and different programs can be flexibly joined together. All of this will be discussed in depth in this chapter.

The shell, the UNIX tools, and awk or other script languages can be used to write easy programs that may relieve the system administrator from boring routine tasks, such as periodic pruning of log files. Many other tasks, such as processing of text files, for example for ad-hoc evaluations, can be carried out with relatively little effort using the utility programs. However, this requires the user to be aware of the possibilities of the individual tools, at least in general terms.

A UNIX system can be seen as a 'tool box' containing a series of simple tools. The combination of different programs, which individually can only carry a fraction of the work, can often save programmers or system administrators hours of dull, repetitive work. Individual programs are combined by means of control structures, for example, of the shell, and by means of data redirection via pipes. Several design decisions play an important role:

+   * Each program should perform one (simple) task.
* Programs read from the standard input. This can be a file, pipe, or the user's terminal.
* Programs write their results to the standard output. This can be a file, pipe, or the user's terminal.
