Table 4.1 Types of files in the file system.

The other nine characters, subdivided into groups of three, specify the access rights of the owner, the group, and all other users. Permissions for access to directories and access to files must be differentiated. Table 4.2 lists the possible permissions for files together with brief explanations.

The s bits can be set with the owner or with the group. Then, the program is not started under the ID of the logged-in user, but under that of the owner or the group of the file (setuid). This can be a security problem, particularly if the user root is owner of the file. Therefore, at least the execution of scripts under different IDs is not implemented, since this always constitutes a security risk
