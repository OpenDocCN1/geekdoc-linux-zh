# LINUX AS AN SMB Client SERVER 475

If you don't like editing configuration files you may want to use swat, the Samba Web Administration Tool. swat will usually start from inetd, so you have to add the line from Listing 19.14 into your /etc/inetd.conf. Don't forget to restart inetd, either with the HUP-signal or with your init-scripts. The port swat is defined as 901 in the file /etc/services.

| swat | stream | tcp | nowait | root | /usr/sbin/swat | swat |

**Listing 19.14** Addition for swat in the file /etc/inetd.conf.

After you have restarted inetd you reach swat with every web browser under the URL http://localhost:901/ on the local machine. If you dont restrict access to the TCP-wrapper (for example to hosts in the local net), you can also use the URL http://servername:901/ from every server in the network. The access is still protected with a password, you may use the user root with the corresponding password. Figure 19.1 shows swat in action.

![](bbox=[0.181, 0.423, 0.668, 0.765])

**Figure 19.1** The configuration tool swat in application.

swat enables you to change every option in the file smb.conf. For every option, the page is only a mouse-click away. Especially when you create your first Samba server, swat will help you a great deal.
