# 120 CONFIGURATION ADMINISTRATION

The print server (the computer to which the printer is physically connected) must allow other computers to access the printer. Names of authorized computers are registered in the file /etc/hosts.lpd. Further access can be entered in the file /etc/hosts.equiv, but this is only sensible in very rare cases.

Now, the remote printer must be set up in the /etc/printcap file of the client computer (seeing Listing 4.28). This is done by means of the entries rm (remote machine) and rp (remote printer).

There are lpr programs that ignore printer filters (described below) for remote printers. If you need that feature you may be forced to change to another lpr system, such as plp or lprng.

```
server|Printer connected to the server:\n:lp=:\n:rp=printer:\nrm=server:\nsd=/usr/spool/server:
```

# 4.6.2 Printer filters

Under UNIX, the use of PostScript as the default format for print jobs has become a standard. The advantage of this format is that printouts look almost identical on all printers and PostScript files can be viewed on screen.

Many PC systems, however, are only connected to a normal dot matrix or inkjet printer which is not PostScript capable. The GNU group Ghostscript contains drivers for widely used printers which allow PostScript files to be output on these printers as well. For this purpose, the output of the gs is lpr. In the long run, this solution is not ideal since it always requires intervention by the user.
