# 10.2.5 Creating and inserting patches

Many programs employed under LINUX are distributed in the form of source
code. When an author releases a new version, the number of changes is often
relatively small in comparison with the entire source code. In such cases it is
sensible to publish only the changes, or to download the changes from an
ftp server in order to keep network load and transmission costs to a minimum.
A file contains only the changes between two versions is called 'diff' or
'patch.' Such changes can be implemented automatically by means of the
patch command.
