# 218 BACKUP

```
#!/bin/bash
# Incremental backup
now=`date`
then=`cat date.dump'
tar --create --verbose file /dev/rft0 --block-size 126 \
  --date "$then"
  --label "Dump from $then to $now"
/home
echo $now > date.dump
```

**Listing 7.6** Exclusion of files from the backup

```
(Linux)->> tar -cf - . | (cd /tmp ; tar -xvf -)
```

If you wish to avoid starting a new shell on the right-hand side of the pipe symbol, you need to switch to the specified directory by means of the option -C (- directory).

```
(Linux)->> tar -cf - . | tar -xvCf /tmp -
```

In a network, one tar can be started on another computer. This allows directory trees to be copied via a network.

```
(Linux)->> rsh host tar -cf - . | tar -xvCf /tmp -
```

Here, files are simply copied. To reduce network load, it may be sensible to compare differences and transfer only modified files or delete superfluous files. For this, you can use the rdist program.

On various systems, the tar program is also capable of generating files with 'holes'. Here, null characters contained in the files are not stored, which can save disk space, for example, in shared libraries. This is done by using the option -S(--sparse) which is, however, not always implemented correctly on all UNIX systems.
