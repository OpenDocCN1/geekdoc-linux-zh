# 15.3 Using a name server with LINUX

This section deals with the use of an already existing name server as a client. The configuration of a name server is extensively described in Chapter 20, where you will find additional hints for its operation.

With the GNU libc (also known as libc-6), linkage to a name server is configured in the file /etc/nswitch.conf. This file has the same format as under Solaris; an example can be found in Listing 15.2.

The name nswitch stands for ‘Name Service Switch’ and is used not only for configuration of the DNS client, but for many other configurations. If application programs only use the libc functions gethostname() and gethostbyname() for reading the hosts file, the call of remote services is completely transparent for programmers and users. More information on this subject can be found in the Info documentation on GNU libc version 2.0 or higher.

```
passwd      files nisplus nis
shadow      files nisplus nis
group       files nisplus nis

hosts       files nis dns
```
