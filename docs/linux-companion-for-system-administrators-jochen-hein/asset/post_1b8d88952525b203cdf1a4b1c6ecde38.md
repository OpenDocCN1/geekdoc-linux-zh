## 5.6 Useful minor modes

In the following section, I would like to introduce some of these minor modes which can make the life of a UNIX user significantly easier.

### 5.6.1 The auto-fill-mode

Many users require typed-in text to be automatically wrapped at the end of the line. In auto-fill-mode, lines are broken when the Space or Return key is pressed and the cursor is located behind the fill-column position. If no automatic line breaking is desired in spite of an activated auto-fill-mode, C-q (quoted-insert) must be pressed prior to the Space or Enter key. thus, the special meaning of keys is annulled.

The right-hand margin can be set by positioning the cursor in the appropriate column and pressing C-x f(set-fill-column). If you require a left-hand margin, you can define a fill prefix. Write the prefix at the beginning of a line, position the cursor to the end of the prefix, and press C-x. (set-fill-prefix). This prefix is automatically taken into consideration in all newly inserted lines.

### 5.6.2 The abbreviation-mode

Another useful mode is abbrevi-mode, a minor mode which expands user-defined abbreviations and thus reduce typing effort. Both global (that is, valid in all modes) and mode-specific abbreviations can be defined. A global abbreviation can be defined by means of C-x g (global-abbrev). This function reads the word with point and searches the minibuffer for a possible expansion. Mode-specific abbreviations can be defined by means of C-x a l (add-abbrev). Abbreviations are stored in the file ~/.abbrev defs. You can change the name of the file by storing the required file name in the abbreviation-name. With the Emacs command write-abbrev-file, you store your abbreviations for the next session. To obtain an overview of the defined abbreviations, you can use the functions list-abbrevs and edit-abbrevs. Further information on the use of abbreviations can be found in the info system. If the buffer is not in abbrevi-mode, abbreviations are only expanded by means of M-Space. The buffer is expanded if it is immediately followed by a space, a full stop (.), or another punctuation mark. This is not always a desired outcome, so expansion can be prevented with the combination C-q (quoted-insert). If an abbreviation was inadvertently expanded, you can undo the expansion by means of the key combination C-x u (advertised-undo).
