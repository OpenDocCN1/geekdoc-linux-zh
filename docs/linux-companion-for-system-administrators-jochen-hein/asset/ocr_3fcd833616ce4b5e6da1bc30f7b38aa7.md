# 7.6 Conclusion and additional information

All programs presented here are well-documented and are suitable for carrying out backups. For private users who wish to backup their data on magnetic tape, tob is probably the best choice. When using diskettes as backup media, the tbackup package should be employed. For complex tasks such as setting up a backup server, amanda should be used.
