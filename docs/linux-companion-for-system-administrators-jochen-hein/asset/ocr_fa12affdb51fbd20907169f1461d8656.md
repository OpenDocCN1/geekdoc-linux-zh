# 12.2 The Windows emulator Wine

The Windows emulator Wine (Wine Is Not an Emulator, or Windows Emulator) converts calls of the MS Windows^4 API (Application Programming Interface) into equivalent X calls. This allows Windows programs to run under X.

The development of Windows emulator Wine began when Sun announced the release of their Windows emulator Wabi. Some experienced LINUX programmers immediately began the development of the emulator, and the first versions of Wine were ported to the freely available *BSD systems. The first and most important application that ran under Wine was the Solitaire game from Windows 3.1.

This emulator is supposed to be a complete Windows emulator. Currently, it still makes use of several DLLs (Dynamic Link Libraries) from the Windows environment. Besides the compatibility with Windows 3.1, the Win32 interface is implemented as well; thus, programs for Windows-95 and Windows NT can also be run under Wine. A further goal is the development of a library (libwine) with which Windows programs can be easily ported to UNIX and X. Corel Office Suite.

However, the Wine program is not a complete Windows emulator. The authors are implementing all APIs step by step, including the Win32 API. Wine is one step ahead of the commercial Wabi which can only handle 16-bit programs. As long as not all DLLs have been implemented completely and without errors, you can require loading of the original DLL via a command line option.

An important milestone is running the MS Office program suite. As yet, not all Windows programs are running, but the developers are working on it. Currently a patch is released every couple of weeks, which is evidence of the visible progress of this development.

The Wine emulator is not subject to the GPL, but to the more liberal BSD or X copyright. The developers have deliberately made this decision because they do not regard the GPL as a suitable license for this project.

4. In the following text, Windows stands for Microsoft Windows. X is a short form for the X Window system.
