Let us look at an example produced by a `tsh` user. The user is used
in this book only in places where it is mandatory. The separation between user
and system administrator is one of the fundamental concepts of UNIX and serves
the security of user and system data and the stability of the system.

```
(Linux):~ echo 'This is an input' | sed s/in/out/
This is an output
```

Additional special formatting is used for shell or environment variables
(VARIABLE). Names of programs and commands are set in display font
(program), files are specified including the path (/path/file). Listings or
excerpts from configuration files are set in display font (Computer Display),
and so are names of computers. The use of key combinations is represented in the
following form:

+   - for the 'A' key, Del for the 'Del' key

+   - Ctrl-C for simultaneous pressing of 'Ctrl' and 'C'

+   - Esc-X for the key sequence 'Esc' followed by 'X'
