The KDE project follows a similar approach with the Kdm program. The use of a separate login form has the advantage that the correct look and feel is already used at stage, and, furthermore, additional settings can be made. The same thing applies for GNOME, which uses gdm. You may change the language or the session type when logging in, and it looks better than plain xdm.

# 6.3.3 Keyboard mapping under X

The keyboard mapping too can be extensively modified by X. This is done by means of the xmodmap program. Usually, you will not have to make many changes to the keyboard map, because XFree86 takes over the keyboard assignments of the console. In spite of this you plan substantial changes, I recommend the use of xcaps, which you can find in the Contrib directory on ftp.x.org. Another useful tool is the kev program which displays the full text for all events it receives (key strokes, mouse movements, and so on).

Especially in X applications that employ the Motif libraries, frequent use of special keyboard assignments which are not present in statically linked applications. These applications should contain a file XKeysymDB in the missing linking between keys and functions is established. This file is stored either as /usr/lib/X11/XKeysymDB or as /usr/openwin/lib/XKeysymDB, another file can be used. or in case of missing entries, you may be faced with error messages such as 'unknown keysyms'.

With the xmodmap program, you can also reconfigure your mouse as left handed. Since all standard scripts evaluate the file ~/.xmodmap at the start of an X session, you enter the line from Listing 6.1. Modern desktops have configuration programs to do that for you, but you may want to use only a Window manager.
