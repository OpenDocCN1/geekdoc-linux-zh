# 17.3.3 The LINUX autofofs

Kernel version 2.1 and later versions include the autofofs file system. This is an alternative to the BSD automounter (amd) and is intended to take its place in the foreseeable future. In addition to autofofs in the kernel, you will need the appropriate utilities. A source is given in the info box at the end of the chapter.

The configuration of the `automounter` is carried out in two steps. First, the list of maps to be managed is stored in the map file `/etc/auto.master` (Listing 17.4). The format of this file is documented in the man page for `auto.master`. Each individual map is located in a separate file.

```
# The file /etc/auto.master. The format of this file is
# mountpoint mapfile [options]
/mount /etc/auto.mount
```
