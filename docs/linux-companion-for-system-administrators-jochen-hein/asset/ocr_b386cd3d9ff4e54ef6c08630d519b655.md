Variables are modified by means of the function set or setq. The function calls in Listing 5.3 are equivalent (the 'q' in setq stands for 'quote', that is, a quote is used to prevent the evaluation of the following expression. In Listing 5.2, the values t and nil occur several times. These values have a special meaning in Lisp and for TRUE and FALSE.

; do not extend buffer after last line
