# 2.7 LINUX Standard Base

In the last few years almost all distributions respected the FHS and that helped LINUX to gain respect in the corporate world. In any case people recognized that only a small part of the requirements for users, developers and independent software vendors (ISVs) have been documented so far. To get a stable and useful platform for ISVs, much more needs to be defined. The Linux Standard Base is a group of LINUX developers, distributors and software vendors who tries to fill that need.

Some problems they try to address (for more information see their Web Site at www.linuxbase.org):

+   * Which libraries (in which version) are available? What functions are defined?

+   * Which commands can be used in portable scripts?

+   * Which users are created on the system? How are users created for applications that need them?

+   * Which fonts are installed and how can they be used?

Besides the standard itself the group implements a test suite to check the implementation on a given system. The test suite for the FHS is already available, some parts from the POSIX test suite will be used and some parts need to be created from scratch. Up to now, a lot of questions have been unanswered, and many new documents need to be written, so the participation of experienced LINUX users and software vendors will be of value.

See http://www.linuxbase.org for more details.
