# IP addresses and computer names 15

Until now, we have almost exclusively used numerical IP addresses. These are used internally by the involved systems, but for human users, they are harder to remember than names. Therefore, in addition to its numerical IP address, each computer is also assigned a name under which it can equally be addressed. This will require an automatic bidirectional conversion between names and IP addresses.

The host name of a UNIX system is set at system start-up by the hostname command. There are thousands of computers in the Internet, which must all be uniquely addressed. Therefore, IP addresses and host names must be unique.

If only a single word is used as a name, as is common in the UUCP map, it will be difficult to find unique names. A solution is to use domain names. A domain is, for example, the organizationally homogeneous network of a company or a university. The domain name is set under LINUX by means of dnsname.

The name space is subdivided by many of top-level domains (such as .uk or any other two-letter nation code, .com or .edu), and domains (for example veggies.example.org or tuttifrutti.example.org). The latter domain names will appear in many examples in the following chapters. These names are intended for demonstration purposes only.

A domain can be further divided into subdomains. Here, the organization tuttifrutti.example.org is divided into the subdomains store.tuttifrutti.example.org and sales.tuttifrutti.example.org. Thus, a host name must be unique only in its own (subdomain); in practice, this can be relatively easily guaranteed. Normally, the network administrator who assigns the IP addresses also assigns the corresponding names.
