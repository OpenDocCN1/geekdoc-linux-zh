# 168 THE EMACS EDITOR

In Emacs, the server is started by means of the function gnuserv-start. Listing 5.8 shows an example of how to differentiate between GNU Emacs and XEmacs inside Lisp functions.

```
; Which one is running, XEmacs or GNU Emacs?
(defvar running-emacs
  (string-match "XEmacs\bs\|Lucid emacs-version\))
(cond
  (not running-emacs)
    (setq GNU Emacs-specific code
      (server-start))
  (t; Emacs-specific code
    (gnuserv-start))))
```

**Listing 5.8** Automatic start of the Emacs servers for GNU and XEmacs.

Subsequently, you can work with the gnclient program in exactly the same way as with emacsclient. The only difference is that processing the buffer can also be carried out from a different computer. For this purpose, either a host-based authentication or, a password check must be carried out. If Emacs has been installed correctly, the xauth program can be used; the display number is 9999.

Particularly interesting extensions of the GNU Emacs are the programs gnuatch and gnudoid. With gnuatch, an already running Emacs can be persuaded to accept additional input on the current terminal. This is useful if one is logged in via a modem or sitting at a colleague's workstation, and one cannot or does not want to start a new Emacs. It may, however, that the keyboard mappings and the colours do not match the current terminal, since these are often carried out only once at the start of Emacs.

The program gnudoid is used to have Lisp expressions evaluated by Emacs. Examples for the call can be found, for example, in the man page for gnudoid. With this method you can control a running Emacs from outside – the security implications are the same as gnuatch.
