# 7.3.6 Special data media

In rare cases, removable disks, floptical disks or WORMS (Write Once Read Many times) are used for backup purposes. Because of their high cost, these data media are rarely employed.

# 7.4 Backup strategies

Backup strategies are determined by many local factors. The system administrator must decide which data needs backing up at which intervals, and the number of backup media needed for this purpose. Furthermore, the sequence of complete and incremental backups needs to be specified. In complete backups, with a few exceptions, all files are backed up. In an incremental backup, the backup affects all files that have been modified since the last backup.

As a rule, you should try to backup your data at low traffic time. On the one hand, less data is subject to change; on the other hand, a backup involves a certain system load, so you should interfere with the smallest number of users possible.

If you want to obtain a truly consistent backup, you should carry out the backup in single-user mode. In practice, this will not always be possible. Except when backing up databases, however, you will be able to live with these problems.
