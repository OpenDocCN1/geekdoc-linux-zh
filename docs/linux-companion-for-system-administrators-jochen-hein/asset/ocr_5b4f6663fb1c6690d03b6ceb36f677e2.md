# 176 THE EMACS EDITOR

| Key | Function | Description |
| --- | --- | --- |
| C-c C-n | outline-next-visible-heading | Moves to the next visible headline |
| C-c C-p | outline-previous-visible-heading | Moves to the previous visible headline |
| C-c C-f | outline-forward-same-level | Moves in the current level accordingly |
| C-c C-b | outline-backward-same-level and | Climbs up in the hierarchy |
| C-c C-u | outline-up-heading | All body texts will be hidden; show-all shows everything in the buffer |
| C-c C-t | hide-body | Text and subnodes are hidden |
| C-c C-d | hide-subtree | Shows only lines directly-neath. No effect on body, or subheadings 2 or more levels down. With arg N, affects subheadings N levels down. |
| C-c C-s | show-subtree | Shows text and subnodes |
| C-c tab | show-children | |
| C-c C-c | hide-entry | Hides the text of the current element |
| C-c C-e | show-entry | Shows the current text |
| C-c C-l | hide-leaves | Hides text, subheadings stay visible |
| C-c C-k | show-branches | Shows all headlines, but no text |
