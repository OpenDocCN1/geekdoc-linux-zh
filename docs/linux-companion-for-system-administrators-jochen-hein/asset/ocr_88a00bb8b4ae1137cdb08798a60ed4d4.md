The second example supplies all lines that contain a lower case letter

t expression [a-z] stands for ASCII lower case letters, whereas [A-Z]
stands for the ASCII upper case letters. Ranges can be combined:
[a-z0-9] corresponds to all lower case letters and all digits.

In extended regular expressions, those used using egrep, a set can
be specified by means of a character class, for example [:lower:] or
[:upper:]. If a foreign language is used, these character classes also include
special characters such as umlauts or accented letters. Please note that these
character classes must be specified within a set, so that the resulting regular
expression contains two opening and two closing square brackets each.
Table 10.2 shows an overview of all character classes.

| Character | Meaning |
|---|---|
| [:alpha:] | All letters |
| [:upper:] | All upper case letters |
| [:lower:] | All lower case letters |
| [:digit:] | All digits |
| [:xdigit:] | All hexadecimal digits |
| [:space:] | All white space characters |
| [:punct:] | All punctuation marks |
| [:alnum:] | All letters and digits |
| [:print:] | All printable characters |
| [:graph:] | Printable characters excluding spaces |
| [:cntrl:] | All control characters |
| [:blank:] | Spaces or tabs |

**Table 10.2** Character classes in regular expressions.
