# 9.6.5 Emacs/gnus

Emacs not only provides a mail reader, but also the news reader gnus which allows you to read and write news inside the Emacs environment. Use of 8-bit characters is possible without problems by using either the ISO-Latin-1 character set or the MetaMail package in combination with the mime mode.

Like the rmail mode, the gnus mode can be started either from the command line or from inside Emacs. The latest versions of gnus use the tm package for displaying and creating MIME messages.
