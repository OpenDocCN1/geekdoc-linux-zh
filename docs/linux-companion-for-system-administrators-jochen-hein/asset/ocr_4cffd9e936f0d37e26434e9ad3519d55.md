# 10.8.5 Programming tips

Shell scripts are often used for automatic execution of repetitive tasks. Usually, you will at first carry out these tasks ‘manually.’ Later, when you know which commands are to be executed in order (and under which conditions), you can begin creating a script.

When programming a script, proceed stepwise and periodically check the part created so far. This will enable you to quickly track down errors such as incorrect or non-matching quotes.

Break up parts that are used several times into separate functions. Often there is a function that displays an error message and terminates the script (with a non-zero return value) and a function that explains the usage (syntax). Such functions should be stored in separate files and then ‘sourced’ (read) into the various shell scripts by means of . file.
