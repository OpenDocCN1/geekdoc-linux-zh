## 9.6 Special characters in mail and news

In mail and news, foreign language (or any other 8-bit) characters can be sent directly, provided the transport route is 8-bit clean. The freely available programs smail and sendmail are either 8-bit by definition or can be configured accordingly. In the current sendmail version, you must include O7false in the file sendmail.cf. Older sendmail versions which can still be found under many commercial operating systems are not 8-bit and cannot be appropriately configured.

Practically all news systems used today are 8-bit clean. The only news still used today, albeit rarely, that is not 8-bit clean is B-News. Therefore, one can safely assume that 8-bit characters will survive their transport via Usenet.

Although the following mail or news header does not correspond to the Internet standard defined in [rfc2045], it is de facto allowed and can help with the undisturbed transport of mail and news containing special characters via the different mail and news systems. The systems are simply advised that message consists of text that contains 8-bit characters from the ISO-8859-1 character set.

```
Mime-Version: 1.0
Content-Type: text/plain; charset=iso-8859-1
Content-Transfer-Encoding: 8bit
```

If the transport route is not 8-bit clean, you can either substitute special characters with replacement characters or sequences of characters (which is a rather outmoded way of doing things), or you leave their encoding to a MIME-capable¹ program which provides conversion in a completely transparent way to the user. However, this procedure only works without problems if both partners use MIME-capable programs.

MIME is rapidly becoming a standard, in particular many Windows programs create such messages by default. It is only a question of time until important programs under UNIX will also be capable of coping with MIME more or less.

## 9.6.1 The mail reader elm

The program elm is an easy-to-use, but nevertheless powerful, mail user agent. In the first place, elm must be compiled correctly, which was not the case for long time in the Slack distribution. This allows special characters in incoming messages to be displayed by means of the built-in pager. Furthermore, the above-mentioned header lines can be included automatically with outgoing messages.

```
# elm.rc
# Transport of special characters
charset = iso-8859-1
displaycharset= iso-8859-1
extencoding = 8bit
pager = builtin
```

However, elm can also cooperate with the MIME implementation metamail, so that MIME messages can also be sent.

## 9.6.2 The mail and news reader pine

The mail and news reader pine (Pine Is No longer Elm) is a further development of elm. Pine is easy to use and is MIME-capable. Therefore, pine has no problems with representing or sending 8-bit characters.

## 9.6.3 The news reader nn

Yet another reader is the program nn. nn represents 8-bit characters by means of the following entry in the file ~/.nn/init:

```
- data-bits allows representation of 8-bit characters in nn
set data-bits 8
```

## 9.6.4 Emacs/rmail

Besides other features, the Emacs editor also includes modes for creating and reading mail and news. A mode for mail is the rmail mode which can be started either directly by calling Emacs -f rmail or from inside Emacs with the command sequence M-x rmail RET.

If Emacs is configured appropriately, 8-bit characters can be without problems if the transport route is 8-bit clean. If this is not the case, the minor mode mime can be used which convert a message into MIME format before sending it. Such messages can also be read under Emacs by means of the MetaMail package. A possible configuration for rmail is shown in Listing 9.11.

The description of the rmail mode in the Info system, can find a series of helpful comments in the sources of the rmail mode, /usr/lib/emacs/version/lsp/rmail.el.

```
(set mail-yarn-prefix " >") ; text with " >" quotes
(set mail-signature t) ; signature from ".signature"
(set mail-default-headers
Mime-version: 1.0
Content-Type: text/plain; charset=iso-8859-1
Content-Transfer-Encoding: 8bit\n") use ISO-Latin-1
```

## 9.6.5 Emacs/gnus

Emacs not only provides a mail reader, but also the news reader gnus which allows you to read and write news inside the Emacs environment. Use of 8-bit characters is possible without problems by either the ISO-Latin-1 character set or the MetaMail package in combination with the mime mode.

Like the rmail mode, gnus mode can be started either from the command line or inside Emacs. The latest versions of gnus use the package for displaying and creating MIME messages.

### 9.7.2 The program package groff

The groff is a text formatter that can translate texts in nroff or troff format into a series of output formats. If you want to convert the text into a directly readable format, you must not select ascii as your output device, or latin1 (with the command line option -T latin1) to show foreign language characters in the output. The formatting system includes a number of programs, for example tbl for setting tables or eqn for formulae. Here, too, the output device must be selected correspondingly.

#### A4 paper format

If you need to use A4 paper format (297 mm by 210 mm), you must set the environment variable PAGE to the value A4 before starting the configure script. If the configuration file /usr/lib/groff/font/devps/DESC contains the line length 84190, groff outputs in PostScript format on A4 paper. The same entry can be included in the file /usr/lib/groff/font/devdvi if the DVI output is also to be formatted for A4 paper. The setting of paper formats is not defined by standards, therefore manual intervention is required. This also applies to a number of other programs.

### 9.7.3 The man program

The man program is used for formatting and displaying individual pages of the online man manual (also known as man pages). In the best UNIX tradition, various utilities are used to achieve this goal. With foreign language man pages, a couple of issues need to be considered:

- First of all, the man pages are formatted with the aid of groff. Therefore, the calls of groff and the other programs belonging to that package must be adapted as explained above.
- Subsequently, the text is displayed by means of less or more.

Thus, special characters in man pages are only displayed properly if involved programs are configured correctly. The following information applies to man-1.4, a man program which can work with several languages using message catalogs and displays the appropriate man page depending on the value of the variable LANG.man-db, which manages a list of the installed man pages in a database, is also adapted to these conventions. Listing 9.12 shows an excerpt from the file /usr/lib/man.config.

```
TROFF /usr/bin/groff -Tps -mandoc
NROFF /usr/bin/groff -Tlatin1-mandoc
EQN /usr/bin/geqn -Tps
NEQN /usr/bin/geqn -Tlatin1
TBL /usr/bin/gtbl
COL /usr/bin/col
REFER /usr/bin/grefer
PIC /usr/bin/gpic
VGRIND
GRAP
PAGER /usr/bin/less -s -M -i
```
