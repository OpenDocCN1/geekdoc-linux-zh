# 4.12.2 The editor joe

the joe is an easy-to-handle WordStar clone programmed by Joseph H. Allen (jhallen@world.std.com). For many people used to DOS. this editor will initially be the easiest to handle one. The editor is configured by the system administrator by means of the file /usr/lib/joerc. Users can copy this file as ~/.joerc and modify it as they wish.

The author has created additional configurations for a better emulation of the WordStar or Turbo C editor (jstar) and a still fairly primitive emulation of Emacs (jmac). All sample configurations are well-documented text files which can be processed with any editor.
