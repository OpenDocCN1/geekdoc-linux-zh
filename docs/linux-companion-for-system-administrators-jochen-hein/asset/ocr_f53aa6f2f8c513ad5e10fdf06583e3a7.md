# 10.6 Processing text files with sed

sed stands for 'stream editor.' sed is a genuine editor; however, as opposed to 'normal' editors such as emacs, sed is not interactive, but command-oriented. That is, a command file or the command line is used to give sed the editing commands which are then executed in the input file or in the standard input.
