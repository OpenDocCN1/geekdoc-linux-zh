If the partitions are not available under LINUX because they have been treated with a 'hard disk double' such as Stacker or DoubleSpace, the only way left is direct access to an individual partition (direct partition access, DPA) or even to the entire hard disk (whole disk access, WDA). At all possible, you should only use direct partition access. For this purpose, you can use an appropriately modified entry from the sample configuration.

```
# disk partition "/dev/hdal" readonly
# disk { wholedisk "/dev/hda" }
```

**Warning:** Never use DPA or WDA on mounted partitions! This may lead to unacceptable errors in the file system structure, with consequential loss of data.

It is useful if the drive letters under DoSem correspond to those used under true DOS. Another good idea is the use of a boot diskette image is stored on the LINUX disk. This is configured by means of the keyword bootdisk, with the virtual drive being assigned the drive letter A:. However, by means of the BOOTOFF program, this drive can be switched via the first floppy, and the boot image is overwritten by the diskette. The opposite, that is, overwriting the diskette drive with the boot image, can be achieved with BOOT. Programs such as MSD, which want to analyse the start-up files, need access to the boot image.
