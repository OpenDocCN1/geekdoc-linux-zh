# 5.2.3 Operation: Meta, Alt, Control, and Shift

Another solution of the Emacs acronym is Escape, Meta, Alt, Control, and Shift. This refers to the operation of the editor via key combinations. Apart from key combinations, practically all functions can also be called by means of their full names. If you use Emacs under X or GNU Emacs, you can select functions from menus. Beginners will learn many commands and key combinations in the course of time, thus increasing their working speed. The reference card supplied by Emacs contains the most important commands — it is also available in several foreign languages.

In the remainder of this chapter, key combinations, that is, pressing two keys simultaneously or in rapid sequence, are represented in the form C-x or M-, C-x: press Ctrl key and the [x] key together, that is, press the key and keep it depressed while briefly pressing the [x] key. The meta key can also be labelled Alt or [O].

If such a key does not exist (or does function, because it is not appropriately configured), the Esc key must be pressed briefly (by pressing a single letter), however, that the Esc key be used. This is followed by the second key of the key combination. This notation is only used for the Emacs chapter to remain consistent with the Emacs documentation.

As well as these keyboard combinations, you can also use the key combination M-x (execute-extended-command) to call many commands directly. Subsequently, you can enter the appropriate command in the minibuffer. With loading of files, both a completion and a history function (Tab/Space M-p/M-n or the cursor keys) are available.
