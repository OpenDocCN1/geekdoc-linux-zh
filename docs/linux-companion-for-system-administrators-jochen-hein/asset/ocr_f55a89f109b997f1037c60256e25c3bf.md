# 6.2 History and concept

The X Window system has been under development since 1984 at the Massachusetts Institute of Technology (MIT) within the framework of the ‘Athena’ project in cooperation with Digital Equipment Corporation (DEC). Early in 1986 the X10 system, the predecessor of X11, was released; the first version of the X11 system X11R1, was published in September 1987. The current version is X11R6.4. The X Consortium, having taken on the development of X, has no discontinued this and has started to work on new projects on the basis of X.

The aim of the X11 development is the creation of standard interfaces on all levels of the X Window system in the framework of cross-company cooperation.
