# 4.4 System configuration

System settings can only be carried out by the system administrator, for example the administration of user IDs, file systems, network connections, and so on. Here, we present the areas that are not discussed in separate chapters (such as, for example, the network configuration, which is discussed in Chapter 14).

# 4.4.1 User IDs and permissions

As opposed to single-user systems, such as MS-DOS or MS Windows, UNIX utilizes a series of security mechanisms which on the one prevent modification of system files, and on the other allow storage of private data. It is also possible to create user groups for special tasks or projects. The access right is carried out on the basis of the assigned group and user ID for files, directories, and processes inside the kernel.

After its installation, a LINUX or UNIX system has no user IDs that could be directly used by new users. Furthermore, all existing IDs, such as example daemon, uucp, or news, should either be given a password, or a login be forbidden. The next step after installation should be the creation of a non-privileged user ID. The new ID must be registered in the file /etc/passwd. Depending on the system, this can be done in various ways.

+   - A new ID can be inserted with an arbitrary editor. However, this does not lock the file against modification by another user, and therefore access conflicts can arise when several system administrators work on the password file at the same time. For a single-user system, however, this plays no role.

+   - A special version of an editor can be used which creates a lock file so during this time no other users write access to the /etc/passwd file. The util-linux package contains the program vipw which can be used to edit the password file.

+   - The new ID can be created by means of the useradd program. It automatically creates the home directory for this user, and if they exist, copies standard configurations from /etc/skel into this directory. This feature offers the advantage that all users start with a uniform environment, especially when creating a large number of IDs.

+   - In many distributions, this function is integrated into the included administration tool. You will find more information on these tools in the documentation accompanying your distribution.
