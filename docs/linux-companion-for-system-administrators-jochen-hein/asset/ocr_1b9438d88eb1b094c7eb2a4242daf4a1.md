# A COMPARISON OF LINUX DISTRIBUTIONS

You may install S.U.S.E LINUX in a couple of different languages. A good installation program (yast) which can also be used for system administration is included. A lot of settings are centrally stored in the file /etc/rc.config and from there are automatically converted into the appropriate configuration files. For many 'old hands', this is unusual, but it is very popular among new users. A similar concept is used in Tru64 UNIX.

Another plus is the extensive installation manual and the rich choice of packages. The installation is simple and easy to use and work with. If you buy the beginners' distribution the distributor provides support. This distribution is probably the most widely used one in Germany; an American version is actively marketed as well and seems to sell well.

# 1.2.2 The Red Hat distribution

The Red Hat commercial distribution is available via ftp and on CD. The installation program is easy to handle. Red Hat uses the RPM format (.rpm) for packages and has developed its own program (rpm) for Red Hat Package Management for their management. This makes the use of the corresponding packages on all other Linux systems slightly more difficult; however, this format is quickly becoming established as the standard.

The rpm implements some ideas that were realized for the first time in the BOGUS distribution. Files are marked as programs, documentation or configuration files. If you have modified a configuration, rpm saves the old version when upgrading and informs you about that fact. You can now check your changes and apply them to the newly installed file. rpm can check packages if the files are unmodified and you can even recompile the programs with a single command.

Another useful feature of rpm is dependencies. Packages can provide features, other packages can then depend on features, package names and versions of packages. If used care, it is very hard to remove an essential package or install an incompatible program. There are graphical front ends to rpm as well, as gnomerpm or kpackage.
