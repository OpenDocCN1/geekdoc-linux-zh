# 62 SYSTEM START-UP

An essential advantage of loadlin is that neither the MBR nor the sector of the LINUX partition needs to be modified. This allows you to switch between different systems without problems and also to update them. If you have LILO installed in the MBR, it will be overwritten, for example, by the NT or Windows 95 installation, although it remains as a disturbing presence when you remove LINUX.

To automate loading with loadlin, you can use a boot selector under DOS, such as BOOT.SYS. Under Linux, you should create a script /sbin/installkernel that copies the kernel to the DOS partition during make install.

# 3.2.3 The syslinux boot loader

syslinux by H. Peter Anvin is a boot loader which replaces the MS-DOS boot sector or 10.SYS on diskettes. syslinux itself is an MS-DOS program used to create LINUX boot diskettes. Under DOS (via mcopy), one or more kernel files are copied to the MS-DOS floppy disk, then the command:

```
c:\>u003e syslinux a:vmlinuz root=/dev/hdal
```

is used to specify the image in the file a:vmlinuz as the kernel image to be loaded and the boot parameter root=/dev/hdal as the argument to be passed. syslinux modifies the boot sector of the floppy disk and transfers the file LILO.SYS to this disk.

When starting from a boot diskette generated by means of syslinux, a boot prompt is displayed, similarly to LILO, after pressing one of the Shift Alt, ShLock or ScrollLock. At this point it is possible to specify parameters other than the default boot parameters and a kernel file name different from the hard-wired one, provided it is contained on the diskette.
