After loading the text, you will normally be in command mode. In mode, commands are triggered by simple keystrokes. Thus, the key does not cause the letter x to be displayed on screen, but the character under the cursor to be deleted. In command mode, nearly every key calls a specific command. Commands are expressed as upper case, in which case the character key must be pressed together with the Ctrl key. Other commands require simultaneous pressing of the Ctrl key.

Other more complex commands can be input in command mode which you enter by pressing the colon. Therefore, this mode is also known as colon mode. An overview of the most important commands is shown at the end of this appendix in Table A.1.

From command mode, you can switch to other modes by pressing specific keys. The most important modes are the insertion mode, which is activated by pressing the i key, and the command line mode, which is reached by pressing the colon. To return from insertion mode back into command mode, you must press the Esc key. If you do not know which (or where) you are, you should simply press the Esc key. The worst that can happen is that you will have a beep.

If existing text is to be overwritten, this is best done in overwrite mode. This mode is accessed by pressing Shift-r. If you only want to replace a single character, you can do in command mode by pressing r followed by the new character. Text can be deleted by pressing the x key. If a whole line is to be deleted, you need to press the d key.

If you want to move around your text file, you can usually do this using the cursor keys, but only in command mode (this may, however, depending on version and terminal mode). If the terminal adaptation does not match, you can still move around the document in command mode, by pressing h to move left, l to move right, j to move down and k to move up. Pageweight through a document is possible by pressing Ctrl-f to move forward and Ctrl-b to move backward. A disadvantage of the cursor keys is (depending on the compatibility of the vi clone) that they trigger a command. Afterwards, you can neither undo your last command with u nor repeat it with . (in the original vi: most clones work better).

To save the file, you need to enter :w in saves the file under its current name. If the file is to be saved under a different name, this name can be specified, for example, :w filename. If the file is protected, you can overwrite it in spite of this by :w!.

You can quit vi by entering q. If the document was changed, you are advised of this by the message 'Use q!' to abort
