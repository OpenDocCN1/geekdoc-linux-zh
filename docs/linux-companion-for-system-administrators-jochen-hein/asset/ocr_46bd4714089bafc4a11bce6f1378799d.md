# 9.4.2 The tsch Turbo C shell

The tsch is an improved variation of the csh. Substantial advantages for the user are a good history function and a user-programmable completion function. Current versions of the tsch can handle foreign language characters without problems if the appropriate locale is installed and activated.

On several systems, the tsch does not recognize the keys Ins, Del, Home and End correctly. This can be remedied by including the commands in Listing 9.7 in one of the initialization files of the tsch. The following files are used for initializing the tsch: /etc/csh.rc, /etc/csh.login, $HOME/.tcsh, $HOME/.homerc and $HOME/.login. More detailed information on initialization (and which file) is processed in the online manual for tsch (man 1 tsch).

```
# Keyboard mapping for Home, End, Del, and Ins

bindkey ^[1\] beginning-of-line  # Home
bindkey ^[4\] end-of-line        # End
bindkey ^[3\] delete-char        # Del
bindkey ^[2\] overwrite mode     # Ins
```
