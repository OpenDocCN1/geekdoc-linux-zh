
# A COMPARISON OF LINUX DISTRIBUTIONS

You may install S.U.S. LINUX in a couple of different languages. A good installation program (yast) which can also be used for system administration is included. A lot of settings are centrally stored in the file /etc/rc.config and from there are automatically converted into the appropriate configuration files. For many 'old hands', this is unusual, but it is very popular among new users. A similar concept is used in Tru64 UNIX.

Another plus is the extensive installation manual and the rich choice of packages. The installation is simple and easy to use and work with. If you buy the beginners' distribution the distributor provides support. This distribution is probably the most widely used one in Germany; an American version is actively marketed as well and seems to sell well.

## 1.2.2 The Red Hat distribution

The Red Hat commercial distribution is available via ftp and on CD. The installation program is easy to handle. Red Hat uses the RPM format (.rpm) for packages and has developed its own program (rpm) for Red Hat Package Management for their management. This makes the use of the corresponding packages on all other Linux systems slightly more difficult; however, this format is quickly becoming established as the standard.

The rpm implements some ideas that were realized for the first time in the BOGUS distribution. Files are marked as programs, documentation or configuration files. If you have modified a configuration, rpm saves the old version when upgrading and informs you about that fact. You can now check your changes and apply them to the newly installed file. rpm can check packages if the files are unmodified and you can even recompile the programs with a single command.

Another useful feature of rpm is dependencies. Packages can provide features, other packages can then depend on features, package names and versions of packages. If used care, it is very hard to remove an essential package or install an incompatible program. There are graphical front ends to rpm as well, as gnomerpm or kpackage.

Red Hat is the target system for SAP R/3 and many other commercial applications. Software developed by Red Hat is always free, and many Red Hat employees are active LINUX developers. This distribution can be installed via ftp. Furthermore, in the contrib directory it offers a large collection of useful programs that are not part of the standard system.

## 1.2.3 Caldera Open Linux

Based on the LST distribution, Caldera presents Caldera Open Linux (COL). Caldera also intends to provide a stable LINUX basis for other software enterprises. This basis is intended to induce other companies to port their programs to LINUX. Caldera distributes, for example, a port of WordPerfect and CoreDraw. With this, Caldera wants to make LINUX usable in commercial environments; this is backed by an offer of support.

On the Caldera Solutions CD, several commercial programs (for example the Adabas database) are distributed. These can be unlocked by means of a license key.

The installation is simple and well-devised, many packages are included, and the system is immediately usable. If you are interested in commercial packages, Caldera is a good choice.

## 1.2.4 Debian (GNU/Linux) distribution

The Debian distribution was initially developed by Ian Murdock. In the course of time, many other developers became involved with Debian. This made the Debian distribution a worldwide project that was also supported by the Free Software Foundation (FSF). The FSF considered this distribution a ‘test case’ for their own Hurd operating system.

The essential feature is that this distribution is free in the sense of the GPL. It can be copied and commercially employed within the framework of the GPL, even without buying a corresponding CD or other medium. Many developers have changed the copyright conditions of their programs to make them usable in this distribution without problems. Debian pioneered the 'Debian Free Software Guidelines' which define what the Debian developers consider to be free software. Only such software will be part of the Debian base system. Besides, non-free packages may be available on the ftp server, and the bug-tracking system may be used for this.

For installation and updates of program packages, a specific package format and tool (dpkg) were developed. An important advantage is that the system or individual programs can be updated without problems, without having to format the hard disk and reinstall the software from scratch. The strategies developed for this purpose have recently been adopted by other distributions (for example S.U.SE. and Red Hat).

A further advantage is the consequent bug tracking, which is carried out by the developers via mailing lists. The list of error messages is public and is regularly searched for errors that have remained unfixed for too long. This makes the Debian distribution the most stable and error-free distribution. The developers also place great emphasis on the fact that the Debian distribution complies with the file system standard.

All sources, including the necessary patches, are part of distribution. This also makes it possible for the user to recompile the system completely. In addition, the distribution is supplied with an extensive installation manual. Debian has defined a set of policies for packages, release strategy and so on. These help the maintenance engineers to do their work.

# LINUX – OPERATING SYSTEM OF THE FUTURE?

## 1.3 The future of LINUX

LINUX has, within a few years, changed from a hackers’ system into a powerful match even for commercial UNIX systems. But for how long is LINUX going to develop? There is really no answer to this question, because the answer depends on developers’ available time and personal interests. We can, however, make some predictions:

- The ports to other architectures (68K, Sparc, MIPS, PowerPC, DEC Alpha) are completed and stable; work is ongoing to support high-end servers and embedded systems.
- For these architectures too there be free and commercial distributions such as Debian and Red Hat. Some commercial products such as Motif have already been ported, but free software has a big advantage: every user can port it, if he needs to.
- The LINUX kernel contains support for symmetric multi-processing (SMP). A further project is the introduction of ‘Fine Grained Locking’, so that many processors as possible can be used to the best advantage.
- Support for threads and real-time processes are being implemented.
- The developers will continue their attempts to implement the current standards, such as POSIX and ANSI C.
- Installation will become even easier through the competition between the different distributions. Possibly, this trend will also continue with the applications.
- With the release of more commercial software, for example the StarOffice package, LINUX will open up still more areas for its application. With the releases of GNOME and KDE LINUX is getting easier to use and will make its way to the desktops.
- For commercial application, good technical support is required. This is already offered by various companies.
