# The GRUB boot loader

A recent development is GRUB (Grand Unified Bootloader). Like LILO, it essentially consists of a boot sector, and there is no easy-to-handle configuration program (yet). The substantial advantage of GRUB is that it is capable of booting many systems directly and it has information on the corresponding file systems.

With LILO, it is only possible to start previously specified kernel images. GRUB can browse through the file system at the boot: prompt and dynamically load different kernels. For daily use, you can set up a menu, but it is always possible to select other kernels or options dynamically.

# Configuration of GRUB

When booting, grub tries to read its configuration file. If such a file exists you can choose the system you want to boot from a menu. If no such file exists, grub opens a command line, which you can also call from the menu.

For regular use you save your configuration into a file. The name of that file is a name of your choice, but you must provide the name to grub when installing your boot sector. Listing 3.2 shows a simple configuration. A complete documentation of all options is provided in the source code of grub.
