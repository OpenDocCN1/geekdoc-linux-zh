# LINUX – OPERATING SYSTEM OF THE FUTURE?

+   The distribution should include many application packages for mathematics, graphics, text processing, and so on. Here, a sensible subdivision into different application groups or series is useful.

+   The distribution should include good documentation (description) of the packages at installation which should also be comprehensible to newcomers. After installation, complete documentation (README files, manuals and sample files) of the package should be available on the hard disk under /usr/doc or /usr/share/doc.

+   The entire source code of the programs should be available and installable at the touch of a button.

+   It should be possible to recompile the programs with one command in exactly the way as they were compiled for the distribution.

+   The original sources of the programs (for example, for use under other systems) and the adaptations for the distribution should be separated.

+   The distribution should correspond to the file system hierarchy standard (FHS). If individual issues are not specified there, the principles to be followed should be clear and simple for the user. Deviations from the FHS should be documented.

+   The system should be based on a modularized kernel, so that initially the supplied kernel can be used.

+   The distributor should become involved in the LINUX community, offering support and cooperation in projects, and with programmers to eliminate errors, and much more.

+   It should be possible to update the system without disruptions.

This list is not complete, but it shows the wide spectrum of requirements that should be met by distributions. The effort of creating and maintaining a distribution is fairly high, so the market may soon stop growing in this respect.

# 1.2.1 The S.u.S.E. distribution

S.u.S.E. GmbH began by adapting the international Slack distribution to the German market. Since then, the developers have detached themselves from Slack and have developed their own distribution. They use now the popular RPM format for their packages.
