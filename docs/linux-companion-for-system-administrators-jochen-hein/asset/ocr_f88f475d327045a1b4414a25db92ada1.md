# 15.4.3 Name server requests with dig

Another tool for the analysis of a name server is dig (Domain Information Groper). This program can be used interactively and in many mode. Many TCP/IP packages contain only this program and not nslookup host.

The options and functions of dig are extensively described in the manual page. Please note that for a 'reverse lookup' you must specify the option -x in addition to the IP address.

# 15.5 Reliability of name servers

Until now, the Internet protocols have been developed and implemented with a view to implementation techniques and functionality. This was no problem so long as only a few and reliable users participated in the Internet. In the past years, the number of Internet computers and users has grown substantially, the number of 'buddies' among them has also increased.

For this reason, Internet computers – particularly the best-known ones – are subject to all sorts of attacks. Depending on protocols, programs, and other environment features, there are different types of attack and defence. A vast amount of information on this subject can be found, among others, in the CERT
