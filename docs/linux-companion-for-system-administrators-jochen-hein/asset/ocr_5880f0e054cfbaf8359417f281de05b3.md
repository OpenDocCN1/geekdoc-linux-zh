# Linux Companion for System Administrators

second edition

Jochen Hein

The LINUX Companion for System Administrators 2nd Edition is a book for anyone who wants to get more out of their Linux box. It provides guidance on adapting the system to meet personal requirements and offers advice on getting practical value from the various tools available. Focusing on the use of linux in a private or corporate environment, this book will help the experienced Linux user attain a more efficient level of system administration.

The Linux Companion for System Administrators goes beyond general system administration, providing detailed coverage of networking with Linux. With the emphasis on the integration of Linux into heterogeneous networks and its employment as a file, DNS or BOTP server, this book illustrates just why Linux is being employed more and more wildly as an intranet server.

This new edition of The Linux Companion for System Administrators provides:

+   - a general overview of a Linux system (how the system is structured and organized, how to get help, where to find documentation)
- common features of the most widely used distributions of Linux
- basic system configuration: booting and kernel compilation
- user configuration
- networking with Linux: TCP/IP-basics, IPX, SMB and useful tools
- when applicable: Emacs tools for the tasks.

# About the author

Jochen Hein works for SerCon GmbH in Wiesbaden, Germany, as a SAP R/3 consultant. He started using Linux in 1992 and was immediately hooked. Since then he has worked mostly on the internationalization and localization of Linux. A previous speaker at the LinuxKongress and other Linux events, Jochen has also managed the Linux user group based in Kassel, Germany.
