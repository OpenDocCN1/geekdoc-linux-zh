# Host alias specification
Host_Alias SERVER=server

User_Alias Operator=michael

# Cmd alias specification

**4.17 Sudoers.

The first part of the sudoers file you may define aliases for systems, networks, users, and commands. These may be used to give a group of privileges and to simplify the rest of the configuration. The last part of the file in Listing 4.17 defines the granted privileges. The users defined in the alias OPERATOR may use all the commands defined in the command alias LPR on the server. In the example it only the user michael may use the commands lpc and lpr on the host server. More than one command, username, or hostname may be given separated by commas.
