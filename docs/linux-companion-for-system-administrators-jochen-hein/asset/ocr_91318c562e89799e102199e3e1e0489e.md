# 19.2 LINUS as an SMB client and server

The implementation of the SMB protocol (Server Message Block) in Windows for Workgroups and its wide diffusion have greatly facilitated the networking of individual computers. All you need is a network card for each computer, and you are in business. Particularly for private users and small businesses, it is beneficial that no special server need to be acquired to share hard disks and printers between users.
