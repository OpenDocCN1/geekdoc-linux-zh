# 16.12 Overview of active computers in the network.

Often the rwho daemon is not started as the regular exchange of
logged-in users and the workload cause a fairly high network load. This is often
t case where diskless computers are employed. After each rwho broadcast,
t rwh programs are loaded via the network into the main memory of all
workstations, and then the appropriate entries are made in the files, again via the
network, so a high data volume rwho is produced in a relatively short time.

As an alternative to rwho, Sun developed the programs rusers and
rstat. These deams communicate with the corresponding servers (ruserd
and rstatd) which were implemented by RPC. Under LINUX, the programs are
cually called rpc.userd and rpc.rstat. Here network load only
comes into being if a user is actually interested in the data.

For reasons of data protection or security, there is often a need to prevent
access to login and working times of the users. In these cases, the finger
er rwho will not be started.
