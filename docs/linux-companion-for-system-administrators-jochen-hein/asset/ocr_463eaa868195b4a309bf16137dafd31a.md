valid resources are stored in the directory /usr/X11R6/lib/X11/app-
defaults. There you can find a resource file for practically every X client.

The resources which are read by an application program and can be used for
it configuration are documented in the corresponding map page in
RESOURCES section. Some of these settings can be passed to the client
command line options at the start. Each user, however, specify his/her
settings by creating the file ~/.Resources. This file is loaded at the start of
X (or after the login).

Modifications to this file do not become automatically active in an ongoing
session, but must be read into the X11 system by means of a command, for
example xrdb -merge .Resources. This data is stored in the X server
which supplies the applications with the appropriate values.

Resources can be specified in a series of different formats, where many
specialized ones are preferred to less specialized ones. The specification of:

```
rxvt.background:           lightblue
```

causes the program rxvt to use the colour lightblue as the background
colour. With the entry:

```
*background: white
```

the background colour is set to the colour white for all clients. If both entries
are present in the resources, rxvt uses the colour specified for it, whereas all
other clients use white as their background colour.

If you cannot install programs in the system directories, you can specify the
direct to be searched in the environment variable XAPPRESDIR. All in all,
ith configuration method has a do-it-yourself aspect, and does not compare
favourably with the easy-to-use modern systems. On the other hand, the system is
very flexible and is available on every X server.

# 6.3.5 Other configuration options

Another program to adapt X to users' requirements is xset. You can switch the
keyboard click on and off and change its volume. If you want to change the
ttracking speed of the mouse, you also need to use xset. In addition, you can use
this program to dynamically modify search paths for fonts.
