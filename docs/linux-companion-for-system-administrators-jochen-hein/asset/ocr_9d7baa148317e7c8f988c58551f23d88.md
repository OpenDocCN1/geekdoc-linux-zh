# 24.3 IP network management

In many companies, the IP network is managed with the aid of SNMP (Simple Network Management Protocol [rfc1157]). Each device managed with SNMP (including workstations, routers, switches, printers, and many others) organizes its information in the Management Information Base (MIB). The MIB is defined in the Internet Standards [rfc1441|rfc1450]. Beside (static) information on the device (for example, person responsible), dynamic data are also managed. This includes, for example, routing tables, interface statistics or general information on the device (for example, the load of UNIX workstations or the available disk space).

Access to the information stored in the MIB is managed via the Community. The default Community is public and allows read access to the data. Modification of the data should be permitted to another Community. Furthermore, it may be sensible to limit access to the MIB to the IP address of the network management station.

Individual devices can register with the network console by means of an SNMP trap and trigger different actions. A great disadvantage in heterogeneous networks is, however, that only IP devices are included. Other protocols cannot be handled, so you might need an additional tool for this purpose.

# LINUX as an SNMP client

One available package for LINUX is the snmp package of Carnegie-Mellon University (CMU). This can be used to call upon various items of information on a LINUX computer from a network management station. This information extends from data via the network connection of the computer to CPU load or occupation of hard disks.
