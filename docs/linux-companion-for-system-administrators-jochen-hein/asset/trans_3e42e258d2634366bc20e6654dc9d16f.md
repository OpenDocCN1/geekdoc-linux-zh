

# LINUX 发行版比较

你可以用几种不同的语言安装 S.U.S. LINUX。它包含一个非常好的安装程序（yast），该程序也可用于系统管理。许多设置都集中存储在 `/etc/rc.config` 文件中，并从那里自动转换为相应的配置文件。对于许多“老手”来说，这很不寻常，但在新用户中非常流行。Tru64 UNIX 也使用了类似的概念。

另一个优点是拥有了详尽的安装手册和丰富的软件包选择。安装过程简单、易于使用和维护。如果你购买了入门级发行版，发行商将提供支持。该发行版可能是德国使用最广泛的发行；一个美国版本也在积极营销，并且似乎销量也不良好。

## 1.2.2 Red Hat（红帽）发行版

Red Hat 商业发行版可以通过 ftp 和 CD 获得。其安装程序易于操作。Red Hat 使用 RPM 格式（.rpm）作为软件包，并开发了自己的程序（rpm）用于 Red Hat 软件包管理。这使得在所有其他 Linux 系统上使用相应的软件包变得稍微困难；然而，这种格式正在迅速成为标准。

rpm 实现了一些在 BOGUS 发行版中首次实现的想法。文件被标记为程序、文档或配置文件。如果你修改了配置，rpm 在升级时会保存旧版本并通知你。。你现在可以检查更改并将其应用到新安装的文件。如果文件未被修改，rpm 可以检查软件包，你甚至可以使用单条命令重新编译程序。

rpm 的另一个有用特性是依赖关系。软件包可以提供功能，其他软件包则可以依赖于这些功能、包名和软件包版本。如果使用得当，删除一个核心包或安装不兼容的程序是非常困难的。rpm 也有图形化前端，如 gnomerpm 或 kpackage。

Red Hat 是 SAP R/3 以及许多其他商业应用程序的目标系统。由 Red Hat 开发的软件始终是免费的，许多 Red Hat 员工都是活跃的 LINUX 开发者。该发行版可以通过 ftp 安装。此外，在 `contrib` 目录中，它提供了大量不属于标准系统的有用程序。

## 1.2.3 Caldera Open Linux

基于 LST 发行版，Caldera 推出了 Caldera Open Linux (COL)。Caldera 还意图为其他软件企业提供稳定的 LINUX 基础。这一基础旨在引导其他公司将他们的程序移植到 LINUX。例如，Caldera 分发了 WordPerfect 和 CoreDraw 的移植版。通过此，Caldera 想要让 LINUX 在商业环境中可用；这得到了支持支持的保障。

在 Caldera Solutions CD 上，分发了几个商业程序（例如 Adabas 数据库）。这些程序可以通过许可密钥解锁。

安装过程简单且设计合理，包含了许多软件包，系统立即即可使用。如果你对商业软件包感兴趣，Caldera 是一个很好的选择。

# LINUX —— 未来的操作系统？

## 1.3 LINUX 的未来

LINUX 在几年内已经从一个黑客系统变成了商业 UNIX 系统的强有力对手。但 LINUX 还会发展多久？这个问题没有真正的答案，因为答案取决于开发者的可用时间和个人兴趣。然而，我们可以做出一些预测：

- 对其他架构（68K, Sparc, MIPS, PowerPC, DEC Alpha）的移植已经完成并稳定；正在支持高端服务器和嵌入式系统。
- 对于这些架构也有像 Debian 和 Red Hat 这样的自由和商业发行版。某些商业产品如 Motif 已经移植，但自由软件有一个巨大的优势：如果需要，每个用户都可以进行移植。
- LINUX 内核包含对称多处理 (SMP) 支持。另一个项目是引入“细粒度锁”，以便尽可能利用多个处理器。
- 对线程和实时进程的支持正在实施中。
- 开发者将继续尝试实现当前的标准，如 POSIX 和 ANSI C。
- 通过不同发行版之间的竞争，安装将变得更加简单。这种趋势可能会在应用程序中继续。
- 随着更多商业软件的发布（例如 StarOffice 软件包），LINUX 将开启更多应用领域。随着 GNOME 和 KDE 的发布，LINUX 变得越来越容易使用，并将进入桌面。
- 商业应用需要良好的技术支持。这已经由各种公司提供。
