```
revision 1.1

```

**Listing 11.11** The use of co.

The `co` command extracts the last version from the `rc` archive and generates the work file `hello.c`. If the work file is to be modified, then the `co` command must be called with the option `-l` (for lock). A special version can be extracted from the archive with the option `-r version` (Listing 11.12).

```
(Linux): $ cp -l hello.c
hello.c ~ -> hello.c
revision 1.1 (locked)
done
```

**Listing 11.12** The use of `co` with locking.

Now the `hello.c` has set write privileges for the user. In addition, a lock is activated which prevents another user from being able to modify a version in the `rc` archive. If you use Emacs, you can read a file from the archive with the key combination C-x C-q (vc-toggle-read-only), modify it, and write back into the archive with the same key combination. This information should be largely sufficient for a simple use of `rc`.

After reading from the archive, our sample file has been modified by translating the string to be printed into German. Listing 11.13 shows the file after modification.

```
/* hello.c */
main(void) {
    printf("Hello Welt\n");
}
```

**Listing 11.13** The modified sample file.

The modified file is now to be incorporated into the `rc` archive as a new version (see Listing 11.14). For this purpose, the `ci` command is called. Now, the `ci` command prompts for a log message. The Emacs editor also asks for such an entry in a new window; the new version is included in the archive with the key combination C-c C-c.
