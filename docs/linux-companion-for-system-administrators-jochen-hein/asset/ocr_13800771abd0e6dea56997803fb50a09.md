**Listing 11.14** Storing a modified file.

If the error message ci error: no lock set by user is displayed, the user tried to insert a work file into the rcs archive that was not locked when reading the file out of the archive. The rcs command with the option -1 creates a lock, so that the work can finally be stored in the archive. The corresponding command can be found in Listing 11.15.

```
(Linux):"$ rcs -l1.1 hello.c
rcs file: hello.c,v
1.1 locked
d
```

**Listing 11.15** The rcs command in use.

Management of versions by itself does not usually help a great deal. However, if a new error has been introduced, it is sensible to know exactly what has changed between two versions. To display differences between two versions, you can use the rcsdiff command. The command in Listing 11.16 shows the differences between versions 1.1 and 1.2.

```
(Linux):"$ rcsdiff -r1.1 -r1.2 hello.c
rcs file: hello.c,v
retrieving revision 1.1
retrieving revision 1.2
diff -r1.1 -r1.2
3c3
< (
    printf("Hello world\n");
-
> (
    printf("Hallo Welt\n");
```
