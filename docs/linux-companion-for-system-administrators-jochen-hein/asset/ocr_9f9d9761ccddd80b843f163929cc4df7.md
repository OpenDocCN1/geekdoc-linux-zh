# 8.7.2 Message catalogs

For use message catalogs, some functions were standardized by the X/Open Consortium:

+   - catopen() for opening a message catalog.

+   - getgets() for reading messages from the catalog. If a message is not found in the catalog, the text specified as the default text is returned as the message.

+   - clclose() for closing the message catalog after use.

The exact syntax and semantics of the function calls are described in the corresponding man pages. The GNU project and other freeprojects use GNU gettext since it is easier for programmers and translators, fast enough for users and supported by Emacs’ po-mode.

# 8.8 Character set conversion

A number of programs exist for converting text files between different character sets. The most powerful program is probably GNU recode which can convert texts from to the most disparate character sets; other systems have an iconv program. These character sets include ASCII (IBM-CodePage 437, ISO-8859-1 (ISO-Latin-1) and EBCDIC (IBM mainframes). Even text formats such as LaTeX or HTML (HyperText Markup Language) can be used as possible coding. The mapping between characters of different character sets is controlled by means of tables. Changes to these tables, however, require recompilation of the program.
