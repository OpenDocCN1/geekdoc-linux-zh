# 10.5.2 Separating fields

awk splits the input line into words. These words can be accessed via the parameters $1, $2, $3, and so on. The separators used as boundaries between the words are stored in the variable FS (Field Separator). By default, words are separated by spaces, but this can easily be changed by the programmer.

The separator can be changed either in the special BEGIN function or via the command line parameter -Fcharacter. in Listing 10.39 outputs the first word of the corresponding line. The words are now separated from each other by a slash (/). Another legal way of describing separators is by regular expressions. This makes awk easily adaptable to many different input formats.

You can also change the field separator without the command line option -F. In this case, you use a BEGIN function in which the variable FS is set. The corresponding example can be found in Listing 10.40.

For more substantial awk programs, the awk command is not the appropriate place for it, because on one hand, there is no reasonable editor (such as Emacs in awk mode) and, on the other hand, the program may be no longer available at a later stage. Alternatively, an awk program can be executed either by means of awk -f file or if the # mechanism is used and the script is readable and executable, directly. The example of Listing 10.40 could thus be rewritten as shown in Listing 10.41. For larger programs, this variation is also clearer.

```
(Linux):$ awk -F'/' /ftp/ { print $1; } /etc/services
ftp 21
tftp 69
sftp 115
```

**Listing 10.39** A second awk example.

```
(Linux):$ awk BEGIN { FS="*" } /ftp/ { print $1 } /etc/services
ftp 21
tftp 69
sftp 115
```
