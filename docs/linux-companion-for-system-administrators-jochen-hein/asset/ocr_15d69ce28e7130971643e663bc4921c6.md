To make the use of NIS transparent to the users of the system, the system administrator should rename the passwd program (for example to passwd.old) and create a (symbolic) link from ypasswd to passwd.
If you want to distribute the file /etc/hosts via NIS, you must enter this into the file /etc/nsswitch.conf. A sample entry is shown in Listing 21.4. Please note that in order to avoid recursion (during name resolution the name of the server must be resolved, ...), you should not indicate the name of the NIS server in the file /etc/yp.conf.
The nsswitch stands for name switch. The file allows the administrator to change the services used for hostnames, users dynamically as well as the order in which services are requested.

```
hosts: files, dns, nis
```

# 21.2 NIS NIS

If no NIS exists in your network, you can create one even under LINUX. For this purpose, you need the program ypserv. Currently, there are two versions for LINUX, the y package and the ypserv package. Which of the two packages you use is a matter of taste.
