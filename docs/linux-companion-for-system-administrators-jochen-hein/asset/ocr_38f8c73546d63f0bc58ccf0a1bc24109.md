The Open System Interconnection (OSI) seven-layer reference model
shown in Figure 13.1 defines seven layers. The tasks and functions of these seven
layers can also be found (with a slightly different structure) in the layers of the
TCP/IP protocols. Because of the different structure of the TCP/IP protocol, no
direct mapping between the two models is possible.

A rough outline of the layers of the TCP/IP protocol is shown in Figure
13.2. Approximately, the OSI layers indicated for comparison purposes
functionally correspond to the layers of the TCP/IP protocols. Chapter 15 works
through these layers from bottom to top to obtain an overview of the functioning
of TCP/IP network.

| Application | Level 7 |
| Presentation | Level 6 |
| Session | Level 5 |
| Transport | Level 4 |
| Network | Level 3 |
| Link | Level 2 |
| Physical | Level 1 |
