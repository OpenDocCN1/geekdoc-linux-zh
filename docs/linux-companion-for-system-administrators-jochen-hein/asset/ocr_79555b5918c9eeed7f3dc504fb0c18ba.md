# 252 LOCALIZATION

Emacs provides special modes for processing foreign language texts. Thus, the iso-syntax mode allows the use of word-related commands with words containing special characters. The iso-cvt mode stores texts containing TeX or special characters, that you need not worry about conversion prior to sending or using these files.

A modern Emacs version is XEmacs, formerly known as Lucid Emacs. This implementation has no problems with handling foreign languages.

```
(if (string-equal (getenv "LC_TYPE") "ISO-8859-1")
  (progn
    (standard-display-european t)
    (require "iso-syntax\)); Foreign Language characters in words
    ; Also for Emacs 19.27!
    (set-input-mode (car (current-input-mode))
      (nth 1 (current-input-mode))
      0))
```

# 2.5.3 The editor joe

The editor joe is largely compatible with WordStar and is thus more familiar to some newcomers than vi or Emacs. Since version 1.0.9, joe has been 8-bit clean, but still requires an entry in its initialization ~/.joerc or /usr/lib/joerc to display 8-bit characters unchanged (Listing 9.10).
