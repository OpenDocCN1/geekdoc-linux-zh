#  9.7.3 The man program

The man program is used for formatting and displaying individual pages of the online man manual (also known as man pages). In the best UNIX tradition, various utilities are used to achieve this goal. With foreign language man pages, a couple of issues need to be considered:

+   - First of all, the man pages are formatted with the aid of groff. Therefore, the calls of groff and the other programs belonging to that package must be adapted as explained above.
- Subsequently, the text is displayed by means of less or more.
Thus, special characters in man pages are only displayed properly if involved programs are configured correctly. The following information applies to man-1.4, a man program which can work with several languages using message catalogs and displays the appropriate man page depending on the value of the variable LANG.man-db, which manages a list of the installed man pages in a database, is also adapted to these conventions. Listing 9.12 shows an excerpt from the file /usr/lib/man.config.

```
TROFF /usr/bin/groff -Tps -mandoc
NROFF /usr/bin/groff -Tlatin1-mandoc
EQN /usr/bin/geqn -Tps
NEQN /usr/bin/geqn -Tlatin1
TBL /usr/bin/gtbl
COL /usr/bin/col
REFER /usr/bin/grefer
PIC /usr/bin/gpic
VGRIND
GRAP
PAGER /usr/bin/less -s -M -i
```
