# 5.2.1 Concepts and terms

Emacs manages a loaded file in a buffer. Buffers are also used internally, for example, to display a selection list. A buffer is displayed in a window. A window is a section of an Emacs window (under X) or part of the screen, which represents a buffer. Under X, Emacs can open several windows (called frames). In Figure 5.2 you will find two Emacs frames, with the frame containing two windows.

Inside a buffer there are two important positions: the position of the (insertion) point (between the character on the cursor is placed and the following character) and the position of the mark. The area between point and mark is called the region. Many commands are designed to be executed on regions.
