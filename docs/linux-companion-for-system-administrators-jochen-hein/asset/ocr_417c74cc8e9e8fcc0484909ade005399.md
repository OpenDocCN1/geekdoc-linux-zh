Listing 7.7 The installation of tob.

The .exclude file differs from those of the backup package by the prefix caret (*). Otherwise, the configuration files of this package can be used unchanged.
Prior to being used, this package also needs to be configured. The author has created a series of configuration files in the directory sample-tob. One of these files should be copied to /etc/tob.conf and then adapted to the system environment. The sample configurations differ in the archiver used and differ in the archiver used and other settings, such as the device on which the backup is carried out. The following sample configurations are supplied:

+   * The configuration tob.conf.afio uses the afio program for the creation of compressed archives. The files are compressed prior to being included in the archive. In the sample file, the module etpage.a is loaded prior to the backup and is removed from memory afterwards (see Listing 7.8).
* The file tob.conf.remote-afio shows an example for a backup via the network. However, different options than those presented are conceivable.
* The configuration tob.conf.tar uses the tar program as archiver.
* The file tob.conf.tar contains a sample configuration for a compressed backup with tar.
