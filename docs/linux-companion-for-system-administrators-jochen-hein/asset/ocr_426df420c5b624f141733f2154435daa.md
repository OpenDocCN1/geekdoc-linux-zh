# 474 LINUX IN A HETEROGENEOUS NETWORK

Some clients always send the password to the server in upper case. Under UNIX, upper and lower case spelling in passwords is significant. samba converts the password into lower case and attempts the login. If the password contains one or more upper case letters, the attempt fails. In the few file samba.conf, you can enter password level = N in the [global] section to specify that all combinations with N upper case letters in the password are to be tried. For values of N, this can, however, take large amounts of CPU time.

In addition, samba can be used as a print server for SMB networks. For this, you must include the section [printers] in the file samba.conf. You need not define each individual printer; samba exports all printers and aliases from the /etc/printcap file. In the example of Listing 19.13, guests are not allowed to print, and the printers are not displayed in the browse list.

You, however, also define private printers for individual users. An example of this can be found in the samba sources.

If you use Windows for Workgroups, you should ensure that login the 'store password' box is not activated. Otherwise, anybody having access to your PC can login on the server under your name without a password. I consider this 'comfort function' a security problem, but it is often difficult to enforce the acquisition of products that allow a single login on the network.

```
[printers]
comment = all printers defined in /etc/printcap
path = /var/spool/samba
browseable = no
printable = yes
public = no
writable = no
create_mode = 0700
```
