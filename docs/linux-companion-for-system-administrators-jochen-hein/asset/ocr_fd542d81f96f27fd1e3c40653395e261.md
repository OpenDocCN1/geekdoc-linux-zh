# 518 CONNECTING TO THE INTERNET

```
# Creation of the ISDN interface ipp0
/sbin/isdnnctl addif ipp0
# Which number shall be dialed?
/sbin/isdnnctl addphone ipp0 out 4711
# Setting of the own 'multiple subscriber number' (MSN)
/sbin/isdnnctl daz ipp0 4712
# Hangup after 60 seconds without data traffic
/sbin/isdnnctl httputime ipp0 60
# Use synchronous PPP.
/sbin/isdnnctl encap ipp0 syncpppp
```

+   Listing 23.7 Application of the isdnctl program.

An important parameter is hupptime which by default is set to 10 seconds. If you do not change this, the connection will be closed after only 10 seconds without data traffic. With isdnctl, you can also select additional connection parameters such as encapsulation and ISDN protocol.

Subsequently, the ISDN subsystem automatically establishes a connection with the provider if an IP packet is to be sent. The selection options are not (yet) as sophisticated as with dial; on the other hand, connection can be established much quickly.

The network interface /dev/ipppN is managed by a specially adapted PPP daemon, namely the ippd program. Listing 23.8 shows an example of the corresponding call.

```
# Configure interface
/sbin/ifconfig ipp0 192.168.99.5 \
    pointpoint 192.168.99.2 -arp metric 3
# Set route
/sbin/route add default dev ipp0
# Start ippd, one process can handle many interfaces
/sbin/ipppd name zeus remotename ppp.provider.de -bsdcomp \
    debug -pred1comp \
    -vj 192.168.99.5:192.168.99.2 /dev/ipppN
```

+   Listing 23.8 Starting the ipppd daemon.

Further connection alternatives are, among others, Raw IP, Ethernet via ISDN, and Cisco HDLC. This makes LINUX prepared for all sorts of requirements.
