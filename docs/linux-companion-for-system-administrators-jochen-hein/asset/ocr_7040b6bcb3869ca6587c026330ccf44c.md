+   - Provided they are supported by LINUX, CD-ROM drives can be used in two ways:
    - The CD can be mounted under LINUX and then accessed via the network redirector (EMUFS or LREDIR).
    - A DOS driver exists which simulates a CD-ROM drive accessible via MSDXEX inside the DOS emulator.

# External hardware, ports, interrupts

It is also possible to access hardware which is not supported by LINUX. For this purpose, the ports used must be released for the DOS emulator. This is done via an entry in the file `/etc/dosemu.conf` for the keyword ports. The kernel can forward a possible hardware interrupt to the emulator by the so-called silly interrupt generator. However, this requires a kernel patch. This is a possibility for accessing Novell or other networks by means of the DOS emulator. Virtualization of DMA (direct memory access) is under development.

# Networks

With the DOS emulator it is also possible to access networks. Depending on the protocol, different procedures are needed, which will be explained in more detail in the following paragraphs.

DOSEmu in a TCP/IP network LINUX has a complete complement of network programs, such as `ftp`, `telnet` and others. Therefore, at first, running the programs under the DOS emulator does hardly appear to make much sense. There are, however, a series of functions which could hardly be implemented without a TCP/IP protocol stack in the emulator.
