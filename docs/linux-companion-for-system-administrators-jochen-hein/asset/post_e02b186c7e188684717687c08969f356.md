
## 10.5.7 Associative arrays

In addition, awk implements so-called associative arrays. This means that the arrays do not use a numeric index, but an arbitrary value (no matter whether number or string). This makes it possible to program even complex processes. Listing 10.43 shows an example of the use of associative arrays. Do not be alarmed; this example uses several functions that we have not yet discussed at all.

```awk
#!/usr/bin/awk -f
# Checking the hard disk for sufficient free space
# df -k -P | $0

BEGIN {
	FS = "[ \t]" # spaces or tabs
	while (getline "/etc/freespace.conf" > 0) {
		if ($1 != "#") && ($2 != "^")) {
			min_free[$1] = $2; # no comment
		}
	}

	s=$1; size=$2; used=$3; free=$4; pct_used=$5; mount=$6;
	if (min_free[mount] != "") {
		if (free <= min_free[mount]) {
			printf("%s has %d Kbytes free, wanted was %d Kbytes\n",
			mount, free, min_free[mount]);
		}
	}
}
```

Listing 10.43 Associative arrays in awk

In the BEGIN section, the configuration file /etc/freespace.conf is read and the data is stored in the internal array min_free. The name of the file system is used as an index; thus character strings can be used as indices in awk. Reading is carried out by means of the getline command, the end of the file is recognized by means of a while loop.

In awk script, the output of the df is expected as standard input. For each file system, a check is made with the aid of the associative array, whether a minimum free space was specified and if so, it is verified correspondingly.

In a program, you can always execute a loop over all elements of an array, no matter whether a numeric index is used or not. For error detection, I begin by using the END part shown in Listing 10.44.

```awk
END {
 for ( i in min_free)
  printf("FS %s-%30s min_free %d\n", i, min_free[i]);
}
```

Listing 10.44 A loop over an associative array.

For a formatted output of the data, an awk script (Listing 10.45) is to be used. In addition, the turnaround of the customers is to be summed up and output as well. The output of the script can be found in Listing 10.46.

```awk
#!/usr/bin/awk -f
BEGIN {
FS="#";
sum=0;
print "Cust.No.      Name First Name Turnaround";

printf("%d %-15s %-15s %8.2f\n", $1, $2, $3, $4);
sum+=$4;
}
END {
print "------------------------------------------------";
printf("Total             %9.2f\n", sum);
print "------------------------------------------------";
}
awk -f script.awk datafile
```
