Many commands can be executed by means of a numeric prefix. The key combination S x in command mode, for example, deletes the next five characters. There are also shortcuts for many functions, such as for example w or d for 'change word' or 'delete word' respectively. You can search a string with / and find the next occurrence of a word with n. You can search through a document with /

Obviously, vi can also search and replace. The notation used for recalls of sed (Section 10.6). First of all, search and replace is a colon command, that, it must be entered in command mode. Then you must specify the range in which replacement should take place; this can be done by means of line numbers (here, the :set nu command is very helpful) or search expressions.

The command for search and replace is s, followed by the search term and the replacement. If the replacement is to be executed repeatedly, a g must be appended. If this sounds complicated, here is a brief example.

```
$1 s/sought/replaced/g
```

In the whole text (from line l to the end), the character string sought is replaced with the character string replaced. This syntax, which initially appears quite complicated, makes vi very flexible for this kind of task. You can search for regular expressions and catch some matches to be used on the replace side.

If the built-in functions of vi are not sufficient, you can call external programs. Here, the whole file or only the current paragraph can be used as input, and the output of the program replaces the input. In command line mode, you can call any program directly by means of !

Users can define their own macros or adapt vi to their own requirements. The configuration file for vi is ~/.vimrc. Here you can define (your own) function keys and carry out other settings.

This certainly does not exhaust the power of vi. For example, vi is able to cooperate with auxiliary programs, such as ctags, and is therefore employed by many programmers and system administrators.
