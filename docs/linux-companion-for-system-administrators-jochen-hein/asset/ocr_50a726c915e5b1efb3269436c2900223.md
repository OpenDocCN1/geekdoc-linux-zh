This prefix is automatically taken into consideration in all newly inserted lines. Also the M-q (fill-paragraph) command respects this setting.

Another useful function is M-s (center-line) for centring a a line. Additional functions are center-paragraph and center-region which centre a paragraph or a region.

Sometimes it is useful to store text in an aligned format. Usually, text processors are used for such a purpose, but Emacs also possesses the relevant functions. With set-justification-option, the paragraphs in a region can be formatted. Legal values for option are left, right, center, full, or none.

# 5.6.2 abbrevi-mode

Another useful mode is the abbrevi-mode, a minor mode which expands user-defined abbreviations and thus significantly reduce typing effort. Thus, for example, the input br M-Space could be expanded to 'Best regards.' Both global (that is, valid in all modes) and mode-specific abbreviations can be defined.

A global abbreviation can be defined by means of C-x a g (global-abbrev). This function reads the ending word with the point and searches the minibuffer for a possible expansion. If you want to abbreviate several words (for example, three), you must specify the name of a prefix: C-u 3 C-x a g. Mode-specific abbreviations can be defined by means of the key combination C-x a l (add-mode-abbrev).

Abbreviations are stored in the file ~/.abbrev defs. You can change the name of the file by storing the required file name in the variable abbreviation-name. With the Emacs command write-abbrev-file, you store your abbreviations for the next session.

If the buffer is not in abbrevi-mode, abbreviations are only expanded by means of the key combination M-Space. If the buffer is expanded if it is immediately followed by a space, a full stop (.), or another punctuation mark. This is not always a desired outcome, so expansion can be prevented with the key combination C-q (quoted-insert). If an abbreviation was inadvertently expanded, you can undo the expansion by means of the key combination C-x u (advertised-undo) or the M-x unexpandabbrev command.
