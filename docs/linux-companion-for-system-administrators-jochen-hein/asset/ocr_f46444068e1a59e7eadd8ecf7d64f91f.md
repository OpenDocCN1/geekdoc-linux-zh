# PROCESSES AND JOBS 319

More recent LINUX and UNIX versions include the notion of threads as that of processes. Threads are execution paths inside a program. The use of threads is sensible, for example, with CPU-intensive tasks within an interactive program. Depending on the requirements, different system areas must be shared between the threads of a process; furthermore, synchronization by means of semaphores is needed. LINUX programming supports threads via the clone(2) system call and the linuxthreads library.

# Process status ps

The status and more information on processes can be displayed by means of the ps (process status) command. Called without parameters, ps only shows the processes belonging to the user that are assigned to a terminal. The option -x also shows those that do not possess an associated terminal.

The processes of other users are displayed by specifying the option -a. With the option -w, the command line is shown in more detail. Frequently, commands like ps -aux | more are used to gain an overview of the system and the running processes. The option -u displays the user, the starting time, and other information.

Another important option is -w, which can be specified several times and displays more parameters of the command line. This is sensible if one needs to know with parameters a specific background process has been started. On the other hand, every user can get to know the command lines of all running processes, which is often undesirable for security or data protection reasons.

The LINUX ps has an option -f which displays the process table as a tree. Alternatively, you can use the pstree command. In some cases, this kind of overview can be very useful.

Further options can be found in the man page for ps. Note that UNIX systems derived from System V use different switches.

# Process table

With some other programs, top (table of processes) is very popular. It displays the most active processes, so you can easily find out currently active processes are occupying the CPU and the memory. Like ps, top uses the proc file system to display the process data. There are also lots of other programs that monitor your system: vmstat (for memory usage), xsinfo (for an overview), or yamm for detailed monitoring.
