Occasionally you need a program that always produces the same result. Under UNIX, you can use the programs `true` and `false`. If the task is permanently to output a given character string, the program yes be very useful.

```
(Linux):\$$ [ -f /etc/initab \u201b ] && echo "initab exists"
initab exists
(Linux):\$$ false || echo 'is executed'
is is executed
```
