# 56 SYSTEM START-UP

Every image starts with a title line and ends implicitly with the option
boot. The image options are:

root=partition [hdbias]
Use the partition partition as the root-partition. This partition is
by grub, which passes some informations to the next loader. If the root
partition is not readable by means of the BIOS, for example if it is beyond
1GB limit, you can use the option rootnoverify= disable the
reading of the partition. The optional parameter hdbias is only used for
BSD systems.

kernel=kernel-image...
grub loads the given kernel image. The image may be in a.out, ELF,
LINUX or BSD format. The command itself ignores the remainder of the
line, which is passed to the kernel as the command line.

initrd-file...
Loads the given file as an initial RAM disk for a LINUX kernel and passes
the following parameters to the kernel as a command line.

makeactive
Marks the partition given as a parameter to root= as active. This may be
required for some operating systems. You can only mark primary partitions
as active.

chainloader=
Loads the given file or boot sector as a chain loader. grub passes control
to some other boot loader, such as one from OS/2 or Windows.

pause=text
The given text is printed on the monitor and grub stops. A ^G is a beep.

uppermem=kilobytes
grub is able to detect more than 64MB RAM and gives that information to
the operating system. This option is only likely to be required for older
systems.

boot
Boots the given image.
