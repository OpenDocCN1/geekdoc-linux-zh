In comparison with the UNIX talk, the ytalk program offers a series of additional features. These functions are called via a menu, which appears when you press the Esc key. With a German keyboard mapping, for example, the Alt key sends an 'Escape' before the second key, so that these functions can be directly called with Alt-key. This keyboard setting can be configured by means of the setmetamode command.

+   - The key (add) is used to add a new interlocutor.
- The key (delete) terminates the connection with a partner.
- Additional options can be changed by the a key. These options can also be permanently configured in the file ~/.ytalc.
- A useful feature is the shell by means of the s key, so you can enter commands whose output is transmitted to the interlocutor.
- An overview of all active users can be obtained by means of the u key (user).
- You can protocol the text of an interlocutor in a file by means of the w key (write), so this is available for future use.
- The key terminates ytalk.

In local networks, communication with talk is quick and easy. If the interlocutor is further away, long waiting times accumulate because each keystroke is transmitted individually.
