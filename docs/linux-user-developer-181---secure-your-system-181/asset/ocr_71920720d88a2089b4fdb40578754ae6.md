Our discussion of chaos theory now takes us to the peculiar world of the strange attractor. Mathematically, an attractor is one or more values to which a system evolves. In the case of the simple population model with growth rates less than 3, therefore, the attractor is a single value, while for values over just over 3 the attractor is a pair of values. To cut a long story short – and, after all, this is just an introduction to fractals and chaos – the attractor for a chaotic system is what mathematicians call a strange attractor and if you plot a strange attractor, you’ll find that it’s a fractal image. As you delve further into chaos theory you might be inspired to read up on strange attractors but, even if you don’t fully understand

them, plotting strange attractors is an interesting way of generating an infinite number of intricate images and, in so doing, further underline the mind-blowing nature of these spheres of mathematics. A first step would be to use off-the-shelf software and our recommendation is Chaoscope, which is free and you can download from http://www.chaoscope.org.

# The link-up

So far we’ve looked at fractal geometry and we’ve looked at chaos theory. It’s a valid question, though, to ask why we’ve chosen to bundle these two apparently separate branches of maths together. We’re not going to get embroiled in a formal mathematical treatment of this question but we will, nevertheless, highlight a number of amazing facts that show that there’s more in common between fractals and chaos than is apparent at first sight.

The first link is one that you might already have picked up on. A common factor between fractals and chaos is that both involve the same sort of mathematical function. Called an iterative function, this involves performing some mathematical function on a value and then doing the same on the result over and over again.
