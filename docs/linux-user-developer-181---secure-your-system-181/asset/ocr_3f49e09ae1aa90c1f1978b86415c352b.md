# VIRTUAL TABLETOP GAME VIEWER

# Rolisteam 1.8.2

Can't make it to a friend's tabletop game session? Join them remotely

![](bbox=[0.1, 0.27, 0.22, 0.3])

> It started with a post on the French-language Ubuntu forum, asking for help porting some

Dungeons & Dragons software, which turned out to be written with Qt, and in short order was running on Ubuntu 7.10. Nearly a decade later, Rolisteam not only compiles easily under GNU/Linux, but has grown and improved considerably, and is translated into several European languages. It's about more than D&D, working as an efficient way of playing any tabletop game between remote players, as it facilitates viewing all of the necessary character sheets, maps and so on, across the internet.

The wiki and other (multilingual) documentation does cover everything, but you will need to dig

through it to get a complete picture. Given that most Dungeons & Dragons devotees put a lot of time into their setups, this won't put many off. One user, usually the game master, sets up as server - or host - and the other players connect to them by server address; the port (default: 6660) needs to be open.

"The goal is to make Rolisteam-managed RPG games as good as RPG games around your table," says the homepage. All the components are there: character sheets; sharing of maps and pictures; vector mapping; dice rolling and secret dice rolling; chat; and ambient music (a mixed blessing). Rolisteam even has a built-in Twitter bot that you can call with tweets like #roll 5d10; you can also run the DiceParser locally in game viewer.

# Pros

Covers just about everything you need for a tabletop game with nifty vectorial mapping

# Cons

Ad hoc network connections can be problematic for any app - look out for firewall issues

# Great for...

Getting a tabletop on for D&D when you can't get together

www.rolisteam.org

# CODING EDITOR

# TKE 3.1

A friendly, feature-full code editor without the bulk

![](bbox=[0.1, 0.62, 0.14, 0.65])

Another text editor? It's easy to start a text editor project, but it takes real drive to keep one going through several versions, so it's worth taking a look at what TKE has to offer. It has syntax highlighting for 85 languages to hand multi-cursor/multi-selection support, and quick navigation through code with the Bird's Eye text viewer. TKE is written in Tcl, with a minimalist Tk GUI.

While installation was easy enough, and syntax highlighting and other features worked across many languages that we tried, there were some problems opening files: We experienced lock-ups of several seconds, or 'File does not exist' messages when other editors had no problems. We acknowledge that our test machines can throw up anomalies of their own and suggest, given that all else was fine, that readers download TKE themselves and give it a go.

While Tcl's Tk toolkit may be familiar to you - it's used in many Python projects, and fairly widely with other scripting languages - you might not be familiar with the Tcl language. A quick browse through the well-organised source files may pique your interest enough for you to try it out in your next scripting project. Extended use of TKE should convince you further.

At last, a powerful code editor without the bloat of IDEs or the all-or-nothing embrace of Vim) and Emacs!

# Cons

Some lock-ups and it sits in a difficult niche between simpler editors like nano, and fully-fledged IDEs
