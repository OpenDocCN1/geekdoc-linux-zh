# The latest update to the Pi's Raspbian distro offers Scratch 2.0 improvements

New features include offline Scratch 2.0 with easier GPIO access

Raspberry Pi enthusiasts have some new toys to play with following the latest Raspbian OS update, which delivers offline Scratch 2.0 support with physical computing through enhanced GPIO support, new icons and the Thonny IDE.

While the custom icons add a new polish to the Pi desktop, the Thonny IDE brings a great new way to program in Python and enables users to finally jetison IDLE.

The big news, however, is the ability to use Scratch 2.0 offline. A feature-packed upgrade to Scratch 1.4 (which used the Squeak language), Scratch 2.0 works thanks to a collaboration between the Raspberry Pi team and Adobe. # MALWARE

# Linux malware rises, targets old vulnerabilities

This time it's the turn of systemd

January 2017 saw the uncovering of a Linux bug that when exploited gives cyber-attackers root access to the targeted computer or server. Nearly six months later, another surprising vulnerability has been revealed.

"This time, the bug enables the execution of malicious code, by exploiting the systemd-resolved initialisation daemon via TCP. Discovered by software engineer Chris Coulson, the bug has so far been fixed by Canonical in Ubuntu 17.04 and 16.10. Red Hat reports that the bug does not affect its

operating system, while Debian says that the systemd-resolved service is disabled.

Tracing the bug back to 2015, Coulson writes: "A malicious DNS server can exploit this by responding with a specially crafted TCP payload to trick systemd-resolved in to allocating a buffer that's too small, and subsequently write arbitrary data beyond the end of it."

But what of Linux's supposed immunity to malware? "In short, no – its declaration from the past that bears no relevance in an age of mobile computing and smart home devices.

As Linux use increases, so does the risk of malware being crafted to directly target the operating system. We've previously seen the exploitation of bugs in Linux server distributions as well as problems with desktop security. Happily, these have been closed relatively quickly. However, the growth in the use of Linux for Internet of Things hardware opens another door to hackers.

In the first quarter of 2017, WatchGuard reported that Linux was the target of 36 per cent of malware attacks. Remain vigilant, and make sure you install those updates!
