
# 利物浦制造节特色

展示报告

# 利物浦 • 科学 • 技术 • 工艺制造节

当这个庆祝创造力、发明和奇技淫巧的节日进入第三年时，**理查德·斯梅德利**（Richard Smedley）混入了熙熙攘攘的人群之中。

> **关键信息**
> 制造节（Make Fests）和创客博览会（Maker Faires）是创意人士和技术人员聚在一起，向彼此及公众展示其项目的场所。
> 利物浦的活动是一个免费的一年一度的单日节日，由利物浦中央图书馆支持，并由志愿者运营。

在过去几年里，创客社区不仅将自由和开源价值观引入硬件和新兴的物联网（IoT）世界，还释放了一股创造力浪潮，吸引成千上万的年轻人和老年人以游戏的方式参与技术。鉴于此，LU&SD参加了第三届利物浦制造节，这是技术日历中最有趣的活动之一。我们还趁机与当地艺术家罗斯·达齐尔（Ross Daziel）交谈，探讨了艺术在技术和创客社区中的角色，他自述为“一位受创客文化启发并受到‘编程和硬件的黑客空间及开源文化’改变的艺术家”。更多相关内容稍后详述。

活动再次在利物浦中央图书馆举行，其优雅的新古典主义立面通向现代化的内部——以及书籍、技术和着装考究的蒸汽朋克世界形成的对比。利物浦制造节不仅是感官的盛宴，也是智力的盛宴。在这里可以看到英国强大且不断增长的创客运动的方方面面。

除了默西塞德郡教育场所常见的制造实验室（fab labs）外，利物浦有幸拥有两个创客空间。DoES（Do Extrastordinary Stuff!，意为“做非凡之事！”）是制造节的长期支持者，展示了一系列项目。利物浦制造（Liverpool Make）已扩展至两个空间，正在通过 Indiegogo 发起众筹活动，为“让利物浦制造得更酷”（Make Liverpool Weid）筹集资金，旨在“向利物浦市民提供公共焊接服务”。

许多现存的创客空间（makerspaces）和黑客空间（hackspaces）都大力推广传统工艺，这些工艺也在许多展位上展示甚至教授——从制作吉他和用废品制作珠宝，到缝纫和使用智能面料。新旧工艺无缝融合，年轻的参观者对传统和高科技都表现出同等的热情。

## 如此，我们便踏上通往星辰的旅程

通常在入口处，观众的目光会被一个全尺寸的 Dalek（“戴立克”，《神秘博士》中的反派机器人）所吸引，但今年它不得不与来自北威尔士创客乔·林克利夫（Jo Hincliffe）的一系列火箭和 DIY 卫星通信设备竞争。

从那里，我们穿过天花板高度的开放式中庭，沿着两段楼梯登上屋顶，来到当地天文学会架设的望远镜旁。随着电磁波谱的向下移动，我们找到了当地业余无线电小组的代表——一种自我学习和制作的文化比家用计算机早了几十年，但无线电爱好者们仍在不断适应新技术，构建软件定义无线电（SDR），或享受通过互联网传输摩尔斯电码的复古乐趣。

将图书馆五层中众多多样化的创客展位联系在一起的，是大量的动手体验活动。到处都有家庭和儿童在尝试事物，享受乐趣，并爱上技术带来的创造性可能。教育以几种意想不到的方式与技术相遇，例如杰玛·拉瑟姆（Gemma Latham）的 PatternCraft，它结合了纺织品、代码和《我的世界》（Minecraft），使用自制设备读取由儿童（和许多热心的成人）在展位上手工打孔的卡片。Python 代码在《我的世界》地图上构建卡片的 8x8 图案。附近，孩子们通过雅卡尔织机（Jacquard looms）和早期计算机键盘卡读卡器了解编程的演变，并体验到通过比键盘更具触感的方式学习编程的罕见乐趣。

## 技术文化

我们注意到，艺术家们从许多创客项目中汲取了趣味性，但学习元素似乎更为深刻。我们就此与罗斯·达齐尔（Ross Dalziel）进行了讨论，他表示他是在*有意识*地这样做。

罗斯告诉我们，过去五年里，他越来越“*转向创客世界*”。“我喜欢创客文化的一点是，它让我想起了更传统的、*互联网之前*的制作方式 [那时我] 是那种会在 Maplins（一家电子元件零售商）里 *蹲着* 翻看目录的人。”

*此前*，对于罗斯来说，“*技术*并不是故事的全部。”在讨论几年前在 FACT（利物浦艺术与创意技术基金会）的一个项目时 [免责声明：记者理查德·斯梅德利是一位贡献者]，他回忆道：“*技术*是微妙的。我真的很想推动 FACT 的发展。传感器和 Arduino 是其中的延伸 [...] 我将*技术*视为*自然*的一部分，*文化*的一部分——是我们*挖掘*出来的，但必须*处理*的东西。”

由达齐尔、来自巴洛因弗纳斯（Barlow-in-Furness）的格伦·博特勒（Glenn Bottler）和 MudLab 联合创始人姜华英（Hwa Young Jung）组成的艺术家集体“家政学”（Domestic Science），表示他们对技术持审慎态度。“*不仅仅是对使用它感兴趣，而是参与这种文化，而不仅仅是利用它*。”

达齐尔在制造节的展位展示了一个基于 *Cockle 板* 的*交互式文字冒险游戏*——这是一种基于 ESP32 的设备，由 *ShrimpPing!* 的 *Cefn Hoile* 共同开发，他参与了游戏设计和团队决策。这款游戏的成果源于*艺术委员会委托*给 2017 年 *哈德良骑兵队*（*The Hadrian’s Cavalry*）展览的*一组不寻常的限制条件*，这是一个*横跨哈德良长城沿线十座博物馆的巡回项目，旨在让人们参与展览*：“*要求是低成本解决方案*”达齐尔说，这促使他们采用了“*跨站点的多次访问，游戏站点离线，无移动信号*。我们*发现了一个移动应用的想法*。”达齐尔回忆道。“*结果是一个文字冒险游戏，让年轻人能够体验基于哈德良骑兵队的趣味世界。它使用标签，游戏状态记录在 RFID 标签上，以便在站点间传递。技术是‘隐藏的，成为博物馆中的文物’，”达齐尔解释道。“*你必须四处张望，将故事记在脑海中 [就像阅读书中的故事一样]，而不是总是低头看手机屏幕。标签推动它前进，游戏状态存储在手持物体中*。”

## 文字优先

达齐尔从小就*文字冒险游戏*（也称为*互动小说*）的粉丝。他在*ZX Spectrum* 上编写*文字冒险游戏*，最初是与朋友合作处理*编程方面*，然后使用*Quill* 软件。“*后来，当我找到一个 Spectrum 模拟器时，我花了一个漫长的晚上用 Quill 试图重现那个冒险，并在 12 岁时放弃的同一个地方再次放弃！*”

另一个*文字冒险项目*涉及“*互动非虚构*”。今年夏天，在*西北地区*活动中的参与者使用*Twine* 软件创建*文字游戏*，该软件从*互联网数据、API 和各个网页*获取输入。这些游戏将被放入*街机机柜*中。在*九月*，将在*利物浦*举办一场*从业者工作坊*，让*艺术家和游戏设计师*能够创建自己的项目。这种新旧融合、*学习与玩耍*的结合，可以在每次*利物浦制造节*上盛行的*蒸汽朋克服装*以及*PatternCraft 桌*上的敲击声中看到。“*人们只看到技术文化的表面，但下面有一层丰富的底蕴需要宣传*，”达齐尔说。“像创客博览会这样的事件并不总是有最好的机会来展示文化知识和历史的重要性。

“奇怪的是，人们认为技术是固定的和新事物——新铜线和面包板——但每个芯片背后都有数百人的工作，”达齐尔说，重新阐释每个电路背后的文化和历史。“我、格伦和伊娃（Iiva，即家政学团队）是技术的超级粉丝。一些艺术家使用技术文化。我们更多地是被它启发。我们想要改变我们的实践。”

他举了一个更深入参与当地创客空间的好处例子。人们来到 DoES（利物浦的共享工作和创客空间），“使用激光切割机的时间，然后离开。我试图在获取的同时也回馈 [一些东西]——建立更好的关系。我们可以问更深入的问题，获得对技术更细致的理解，以便为未来的工作打下更好基础。”

## 编程俱乐部

自然，在所有传统技能中，编码和计算机硬件在制造节上仍然占据重要地位：有编码无人机、机器人改装以及大量出售的 Arduino 扩展板。可以看到许多基于树莓派（Pi）的桌面正在运行 Scratch 或 Python，但真正吸引我们目光的是两者的混合体：EduBlocks，它提供了一个类似 Scratch 的界面，可以拖放基于 Python 的代码块来构建程序，然后可以切换到完整 Python 代码的视图。它由 13 岁的乔舒亚·洛（Joshua Lowe）共同创建，他是 All About Code 的创始人兼首席执行官，也是 Tech 4 Good 奖项中 BT 青年先锋奖类别的入围者。（更多详情见 http://edublocks.org）

教育——以及玩耍——很重要，但在灾难情况下，必须首先满足更基本的需求。创客们甚至在那里提供帮助（见右侧访谈）。如果你的树莓派和 Arduino 正在积灰，且需要灵感，去参加你附近的创客活动吧——为了创造力、乐趣 [...] 而学习则是意外之喜。

## 访谈：劳拉·詹姆斯博士，Field Ready

许多参观者离开制造节时都在谈论 Field Ready（www.fieldready.org）的展位，这是一个专注于制造现场人道主义物资的非政府组织。我们与联合创始人兼工程负责人劳拉·詹姆斯博士进行了交谈。

### 将 3D 打印机带到灾害现场使之前无法做到的事情成为可能吗？

我们可以制造现场所需的东西，满足当地社区或援助工作人员的即时需求。在海地，我们遇到了没有无菌用品的接生员，她们使用绳子段来扎紧脐带，而当时需要无菌闭合。在尼泊尔，受地震破坏的诊所缺乏基本的医疗设备。

援助工作人员在不可预测的环境中工作，可能会发现自己需要将不同尺寸的管道以奇怪的配置连接在一起。[...] Field Ready 与大学团队一起创建了一个应用程序，允许用户输入需要连接的管道尺寸，并自动生成定制的管道连接器的 3D 模型，准备进行 3D 打印。

### 我们看到开源的工作方式影响了软件之外的许多领域……

我们了解到，即使有出色的工程师和设计师团队在现场，我们也无法独自解决我们在现场遇到的所有设计挑战。因此，我们形成了一个跨部门社区，由数百名技术人员、设计师和援助工作人员组成的“人道主义创客”，这是一个日益有用的论坛，用于寻找解决方案、共享信息和寻找志愿者。

### 您的设计是否可供其他组织在现场打印？

是的，我们公开分享我们的设计，供他人重复使用。您可以在 Thingiverse 上找到合集：（http://bit.ly/FRTthingiverse）我们使用 3D-pressa 提供更详细的说明。我们的设计通常采用 CC-BY（知识共享署名许可）。我们听到其他人重复使用我们的设计，例如加沙的一个 3D 打印我们的 tectopic 设计的项目，有时他们会反馈改进意见。
