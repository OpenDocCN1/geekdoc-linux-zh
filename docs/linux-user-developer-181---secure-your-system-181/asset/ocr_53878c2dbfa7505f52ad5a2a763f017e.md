Linode, Vultr and DigitalOcean

As well as the big players, there are numerous smaller companies that aim to compete with AWS, particularly at the lower end of the market. Linode, Vultr and DigitalOcean all started out as simple VPS providers, but now offer additional services similar to AWS, with their portfolios expanding all the time. This is probably wise as AWS moves into their territory with Lightsail!

AWS provides a suite of managed services used to build and run serverless applications. At the platform's heart is AWS Lambda, which enables you to run code without provisioning or managing servers. Just upload your code and Lambda takes care of everything required to run and scale it with high availability. Lambda@Edge allows you to run Lambda functions at AWS Edge locations in response to Amazon CloudFront events. Amazon API Gateway makes it easy for developers to create, publish, maintain, monitor and secure APIs: it can process hundreds of thousands of concurrent API calls and handles traffic management, authorisation and access control, monitoring and API version management. The API Gateway is a great way to expose functionality provided by Lambdas. Amazon SNS (Simple Notification Service) and Amazon SQS (Simple Queue Service) provide inter-process messaging. SNS is a pub/sub messaging system for decoupling elements of a distributed microservice system while SQS is a versatile message queueing service. AWS Step Functions enables you to coordinate the components of distributed applications and microservices using visual workflows. Building applications from individual components that each perform a discrete function allows you to scale and change apps quickly. Step Functions is a reliable way to coordinate components and step through the app's functions. Amazon Kinesis makes it easy to collect, process and analyse real-time, streaming data to enable timely insights so you can react quickly to new info. Kinesis lets you cost-effectively process streaming data, with the flexibility to choose the tools that best suit the requirements of your app. With Kinesis, you can ingest real-time data such as application logs, website clickstreams and more into your databases or build your own real-time applications using this data.

So what might this look like in reality? Imagine you have some code for a website hosted in S3, which is served using CloudFront. When a user clicks on a function on the page, this could make a REST API call to an API Gateway endpoint, which will trigger a Lambda function to retrieve some information from a database (RDS, DynamoDB or similar) and return it, via the API gateway, to the application to render. Because the application intelligence runs in the Lambda function, you'll only pay for the resources used while the function is executing – once complete, the microservice in effect disappears. The AWS infrastructure allows these requests to happen at huge scale, providing massive capacity when needed and frugality at other times.

# Code and delivery

You won't be surprised to learn that there's a range of services to help you manage and deploy your application code, too. AWS CodeCommit provides secure and scalable Git repositories for storing code. AWS Codepipeline is a continuous integration and delivery pipeline for building, testing and deploying code every time there's a change. AWS CodeStar brings many of the AWS tools into a unified UI to easily manage software development in one place. It's also fully integrated with Atlassian JIRA for issue tracking, plus a host of AWS tools including Elastic Beanstalk – the orchestration service used to automatically deploy AWS infrastructure such as EC2 instances, S3 buckets and Elastic Load Balancers. Amazon AWS is an incredibly advanced enterprise product, but it's also an accessible tool for beginners through to enthusiasts. With straightforward entry level services like Lightsail, a well thought-out management console and a generous free tier and extensive documentation, it's good fun to take for a spin.
