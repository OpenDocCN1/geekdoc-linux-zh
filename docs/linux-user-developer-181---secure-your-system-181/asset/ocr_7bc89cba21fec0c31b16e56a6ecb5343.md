The most interesting change is with the Update Manager. Mint has reworked its update filtering policies to make the update process safer and easier, especially for novice Linux users inundated by updates on other distros. Mint categorises updates according to the impact they have on the system. Most are marked as Level 1 or Level 2 and these won’t break the system. Updates that impact several apps are Level 3, while kernel and updates to other core components are Level 4. The app has a fleshed-out documentation section that explains this critical area. On the other end of the user-level spectrum, the new mintupdate-tool will help seasoned users schedule updates via cron jobs and scripts.

Mint 18.2 uses Cinnamon 3.4, which offers several useful new features. Long-time users will appreciate the ability to align, sort and change the size of the desktop icons. Behind the scenes, the developers have separated the different plug-ins of the settings daemon into their own processes. This not only makes them easier to track, but also contributes to the overall stability of the desktop, as a misbehaving plug-in will no longer bring down the entire desktop.

You can customise your Mint installation by sprinkling a host of applets, desktops and themes. These add-ons are collectively known as ‘spices’ and are available on the Cinnamon Spices website (https://cinnamon-spices.inxi.com.int), which has been redesigned from scratch. You can explore and filter the spices on the website using the newly integrated social tools and can then either manually download them or install automatically using the relevant configuration tool inside System Settings.

Another aspect that’s reflective of Mint’s coming of age is its collection of core utilities, dubbed X-Apps. These are essentially forks of popular GNOME apps that are now maintained in a desktop-agnostic fashion for a consistent experience irrespective of the desktop environment. There’s an X-App for everything from a text editor (Xed) and image viewer (Xviewer) to a PDF reader (Xreader) and media player (Xplayer). They debuted with Mint 18 and all have been tweaked and updated further here.

Linux Mint 18.2 will receive security updates until 2021. New Mint versions till 2018 will use the same package base as Linux Mint 18, which makes updating to point releases a safe and trivial affair.

# Pros

A refined desktop distribution that’s both stable and intuitive and can be customised with relative ease.

# Cons

It’s based on the Ubuntu LTS release, which means it ships with an older 4.8.0-5.3 kernel.

# Summary

If you were waiting for things to stabilise before jumping on the Mint 18 bandwagon, wait no more. The changes in 18.2, namely the update manager policies and separating the desktop plug-ins into their own processes, further underline its reputation for stability.
