# Linux Mint 18.2 Beta

In stark contrast to the upheaval over its progenitor, Linux Mint calmly delivers yet another stellar release

+   **RAM** 16B
+   **Storage** 20GB
+   **Specs** 1GHz processor and HD graphics
+   Available from www.linuxmint.com/download.php

Linux Mint, both as a project and a product, continues to mature in stature with every release.
In fact, the recent few releases have been so solid that it appears the project puts out beta releases as a mere formality only to honour the software release life cycle policy. This release is no different, which like the previous ones is based on the thoroughly tested Ubuntu 16.04 LTS release, in accordance with Mint’s new policy of sticking with LTS Ubuntu bases. Mint has replaced its MDM display manager with LightDM, which is futureproof as it supports different display servers including Wayland and Mir. LightDM powers Mint’s new greeter called Slickit that supports HiDPI resolutions. Also, by default, Mint has enabled the ability to allow guest users to log in without prompting for a password - if you aren’t comfortable with this, you can alter it. Bluetooth support also gets an overhaul with a refreshed interface for the configuration app, Blueberry.
