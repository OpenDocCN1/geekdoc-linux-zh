# EC2 / Lightsail

Originally announced in November for the main US region, but now available more widely (including in the London region), Lightsail is Amazon’s defence against providers such as Linode or DigitalOcean (see p63) who offer ultra-cheap hosting. Lightsail starts at $5 a month, with the first month free. Costs scale up as storage, memory, bandwidth allowance and CPU power increase, but tiers are typically in line with rivals. Creating a Lightsail instance is easy. The control panel is separated from the main AWS administrative interface and setup is as simple as choosing an instance size, selecting a region and availability zone, defining a SSH key pair and an optional launch script before finally choosing either a bare OS (Ubuntu or Amazon Linux) or a prepared stack such as WordPress, LAMP and Magento and so on. Press the ‘Create’ button and your instance will start. After which you can configure the firewall, take snapshots and view various metrics. A web-based SSH console is also provided. You can assign a static IP to your instance, which is floating – if you spin up a new instance, you can change where the IP points on the fly. Static IPs are free as long as they’re attached to an instance.
