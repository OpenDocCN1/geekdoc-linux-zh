
## RASPBERRY PI

### The latest update to the Pi's Raspbian distro offers Scratch 2.0 improvements

New features include offline Scratch 2.0 with easier GPIO access

Raspberry Pi enthusiasts have some new toys to play with following the latest Raspbian OS update, which delivers offline Scratch 2.0 support with physical computing through enhanced GPIO support, new icons and the Thonny IDE.

While the custom icons add a new polish to the Pi desktop, the Thonny IDE brings a great new way to program in Python and enables users to finally jetison IDLE.

The big news, however, is the ability to use Scratch 2.0 offline. A feature-packed upgrade to Scratch 1.4 (which used the Squeak language), Scratch 2.0 works thanks to a collaboration between the Raspberry Pi team and Adobe. ## MALWARE

### Linux malware rises, targets old vulnerabilities

This time it's the turn of systemd

January 2017 saw the uncovering of a Linux bug that when exploited gives cyber-attackers root access to the targeted computer or server. Nearly six months later, another surprising vulnerability has been revealed.

"This time, the bug enables the execution of malicious code, by exploiting the systemd-resolved initialisation daemon via TCP. Discovered by software engineer Chris Coulson, the bug has so far been fixed by Canonical in Ubuntu 17.04 and 16.10. Red Hat reports that the bug does not affect its operating system, while Debian says that the systemd-resolved service is disabled.

Tracing the bug back to 2015, Coulson writes: "A malicious DNS server can exploit this by responding with a specially crafted TCP payload to trick systemd-resolved in to allocating a buffer that's too small, and subsequently write arbitrary data beyond the end of it."

But what of Linux's supposed immunity to malware? "In short, no – its declaration from the past that bears no relevance in an age of mobile computing and smart home devices."

As Linux use increases, so does the risk of malware being crafted to directly target the operating system. We've previously seen the exploitation of bugs in Linux server distributions as well as problems with desktop security. Happily, these have been closed relatively quickly. However, the growth in the use of Linux for Internet of Things hardware opens another door to hackers.

In the first quarter of 2017, WatchGuard reported that Linux was the target of 36 per cent of malware attacks. Remain vigilant, and make sure you install those updates!

## Say hello to Pop!_OS, a creator-focused distro

System76 stops waiting for Ubuntu to add extra features and announces its own spin

Based on Ubuntu, Pop!_OS (pronounced “Pop OS”) is a minimalist operating system with a streamlined installation. The aim is to enable creators to just create, giving them a quick start and the collection of tools they need to get the job done.

But what sort of creators? Specifically, those working on artificial intelligence, 3D modelling, makers working on inventions, and even computer science students.

Supporting the operating system is a community, which at the time of going to press is busy planning a development roadmap, opening discussion forums (there’s a conversation starting in the subreddit, /r/pop_os) and a code of conduct. Contributors to the project are welcome as long as contributions adhere to a specific process.

Chatting to community members on Reddit, community manager Ryan Sipes explained how Pop!_OS will be the default operating system for System76 hardware in future. “This will be our default OS. For the 17.10 release you will be able to choose between Pop!_OS 17.10 and Ubuntu 16.04 (LTS). This is all part of taking more control over the product we produce. We waited three years on Unity 8, and we no longer want to wait on another company to implement the features our customers and community are asking for.”

Currently in alpha (1.62GB, available from https://system76/pop), the first stable release of Pop!_OS is expected to appear in October 2017.

## Ubuntu Core on Compute Module

It’s goodbye Unity, hello Internet of Things!

Canonical’s refocusing on the Internet of Things has been confirmed with the news that Ubuntu Core OS is now available for the Raspberry Pi Compute Module 3. The aim is to give IoT manufacturers the opportunity to embrace Linux and create cost-effective devices with ease.

The Compute Module 3 (CM3) is a more compact, general-purpose version of the Raspberry Pi 3. Resembling a stick of RAM, it can be slotted into suitable devices with a DDR2 SODIMM connector. With 1GB of RAM, a 1.2GHz quad-core CPU and 4GB eMMC flash storage, it’s ideally suited to embedded smart home products.

Mike Bell, EVP of IoT and Devices at Canonical says: “ […] With CM3, the development of everything from an edge router to […] digital signage solution has become more convenient and affordable […] as easy as developing a custom snap for your specific needs.”

Digital signage firm Screently highlighted its support for this joint venture, noting that Ubuntu Core with CM3 marries its design specifications with robust hardware.

How did Linux Mint come to be and what is its aim?
I started in 2006. I was writing for http://linuxforums.org and I wanted to host some of my articles myself. I needed a domain name and I chose 'linuxmint.com'. It was short and it conveyed the idea of freshness and technology that just works. That's where the name came from: it was the domain name for a collection of articles, reviews and tutorials dedicated to Linux.

At the same time, I had been reviewing distributions for a while and tinkering with a lot of things, so I had good knowledge of how they worked and what I liked or didn't really like in each one of them. At some stage I got something out and I wrote a bit about it on linuxmint.com. I was surprised by the feedback I got and a few months later it was clear people were more interested in that little project than in my articles.

There was no plan to create a new distribution initially, and certainly not one that could rival the likes of Microsoft Windows, Apple macOS or even the established Linux distros.
