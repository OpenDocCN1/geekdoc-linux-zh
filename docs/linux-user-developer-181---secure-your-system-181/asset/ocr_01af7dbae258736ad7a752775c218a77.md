As you zoom in on areas near the perimeter of the Mandelbrot set, as we did to create the other pictures in **Figure 1**, more and more detail comes to light and the infinite intricacy and zigzag patterns unlike IFS fractals, you'll never see exactly the same patterns at ever greater zoom levels, but you see the same sorts of star bursts, spirals and zigzag patterns and a few times, there's a good chance that you're seeing something that nobody has ever seen before.

Writing code to draw the Mandelbrot set is simple enough, although providing a user interface to allow zooming is a bit trickier. In fact, while zooming would have to be achieved just by filling in cells to define an area of the complex plain, it's an easy job to produce an Excel spreadsheet with a simple macro to do the job. While writing your own software would be an interesting and educational exercise, if you just want to generate impressive images of the Mandelbrot set, you'd be better off getting your hands on some software. One of the most respected Linux packages is called Gnofract4d <http://edyoung.github.io/gnofract4d/> and it's free. As well as the Mandelbrot set, it allows you to

explore the closely related Julia set; plus there's the option to define your own formulae, which provides the opportunity to investigate any imaginable escape-time fractal. And if you want to explore 3D fractals (both IFS and escape-time), the free Mandelbulber package (<http://www.mandelbulber.com>) is what you need.

# ## Chaos theory

Chaos theory concerns systems that are described as having super-sensitivity to initial conditions – let's see what this means in practice. A very simple mathematical model of the growth of a biological species such as a fruit fly is represented by the formula $\mathbf{x}^{\text{t+1}}=a\ \mathbf{x}^{\text{t}}(1-\mathbf{x}^{\text{t}})$, where $\mathbf{x}^{\text{t}}$ is the population in the current generation, $\mathbf{x}^{\text{t+1}}$ is the population in the next generation, and $a$ is a growth rate. The population is what mathematicians call 'normalised to 1', so all values will be between 0 and 1, but it can always be converted to a real-world population by multiplying by a constant. If you want to try this model out for a few generations, you can easily do so with a few lines of code or an Excel workbook to get graphs like the ones reproduced in **Figure 2**.
