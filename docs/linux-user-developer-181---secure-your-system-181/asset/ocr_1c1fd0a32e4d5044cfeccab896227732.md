This is another tutorial in the Erlang series – its subject is the development of web applications and web servers in Erlang. In order to follow the examples of this tutorial, you will need a modern web browser as well as a recent Erlang installation.

The good thing is that you can follow this tutorial without having to run your own web server, because you can test most of the presented examples locally using web servers written in Erlang that come with the Erlang web application.

So, this tutorial will talk about WebSockets, Cowboy, MochiWeb and how you can use them for talking to a web browser and creating your own HTTP servers. Apart from the required theory, this tutorial includes handy and easy-to-understand Erlang code that will permit you to demystify the challenging areas Erlang web development. Nevertheless, in order to take full advantage of this tutorial, you will have to write your own Erlang code and create your own web applications and web servers.

This is the last tutorial in the Erlang series, so now it would be a good time to review all previous Erlang tutorials and start writing your own unique, interesting and handy Erlang applications! Erlang code might look difficult to write at first, but offers so many hard-to-find advantages that it’s definitely worth a try!

In the last few years, various types of web apps take most of the internet traffic. So, this tutorial will show you how to write web apps in Erlang in order to take advantage of the unique Erlang characteristics that give you the opportunity to create robust and distributed applications very simply.

As the web is asynchronous, concurrent and requires fast responses, Erlang is a perfect candidate for participating in the whole web experience.

This tutorial will be a gentle and easy-to-follow introduction to the capabilities of Erlang that can help you create powerful web applications and web servers.

# About web applications

If you are not familiar with web applications, you might be wondering what one is. A web application (or web app for short) is a client-server software application where the client part runs on a web browser. Webmail, instant messaging services, online stores and many other kinds of applications are web applications.
