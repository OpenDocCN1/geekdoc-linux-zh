Unfortunately, Mageia no longer provides a direct menu entry to launch the software management app. You must click Menu > Tools > System Tools > Mageia Control Center and then click Install and Remove Software to launch rpmdrake. You can also launch the software app from the aesthetically designed Welcome Screen.

While rpmdrake - the graphical software management utility - still relies on urpmi for resolving dependencies, the developers are also working on DNF dracora, an alternate app to act as front-end for the DNF system, but it won't be available anytime soon. The Mageia project is also heavily invested in collaborating with Fedora's COPR project which aims to provide a PPA-style system for building third-party package repositories.

With Mageia 6, all the apps have been ported to Plasma 5, the successor to KDE 4 desktop. The distro has finally dropped support for Lilo and Grub Legacy and only offers Grub 2 as the bootloader, but you can still continue to use the others if upgrading from an existing installation. Users running Mageia 5 can upgrade to Mageia 6 if they first install all updates available for 5, but they must then use the DVD release of the distro, not one of the live images. The primary reason for the delays was bugs in the installer, but we didn't encounter any in our test installs on a physical machine nor as a VirtualBox guest. But the distro isn't entirely bug-free. If you wish to enable parental controls, you can do so using the Control Center, but the behaviour is erratic and results in crashes. Similarly, while the distro allows creation of snapshots such that you can roll back to a previous state in case of a misconfigured system, the feature results in frequent crashes. The individual live images only offer a handful of everyday office, internet and multimedia apps. But users have access to thousands of additional packages through the Core, Nonfree and Tainted repositories. Proprietary drivers for hardware components such as wireless and graphics cards are offered through the Nonfree repository while multimedia codecs and other packages that may infringe on copyright, patent or other laws are relegated to the third repository. Note however that of the three, only Core is enabled by default.

# Pros

Determined developers coupled with a vast user community make Mageia a desirable everyday desktop distribution.

# Cons

The long and frequent delays that have plagued the project for the past two releases are a concern.

# Summary

A largely stable release that builds on the many changes introduced with Mageia 5 and is an able distro for everyday use. The final release could be a perfect desktop for new and experienced users looking for a configurable system; and doesn't require two many resources.
