You would expect Google to have a presence in the cloud hosting space – and it does with Google Cloud Platform. As with AWS and Amazon, Google Cloud Platform is based on the same infrastructure used to power core Google services such as Search and YouTube. Key products include Compute Engine (equivalent to EC2), Cloud Functions (equivalent to Lambda), Cloud Datastore (equivalent to DynamoDB) and Storage (equivalent to S3).

### Free tier

Amazon’s free tier is a great way to try out services and each of the storage options above is included in the offer. Amazon will provide 30GB of Amazon Elastic Block Storage in any combination of General Purpose (SSD) or Magnetic; 1GB of snapshot storage; 5GB of Amazon S3 standard storage with 20,000 Get Requests and 2,000 Put Requests; plus 5GB per month of Amazon EFS capacity, free of charge for the first year.

As well as providing the first month free on Lightsail (understandably, there’s no longer-term free tier on the Lightsail servers per se), Amazon includes EC2 in the free tier. For the first year, you can use 750 hours per month (enough to run continuously) of Amazon EC2 Linux or Windows t2.micro instance usage (1GiB of memory and 32-bit and 64-bit platform support), together with a load balancer to sit in front of the instance if desired, with 15GB of transfer bandwidth. The database offerings are similarly generous – 750 hours per month of Amazon RDS Single-AZ db.t2.micro instances for running MySQL, PostgreSQL, MariaDB, Oracle BYOL or SQL Server (running SQL Server Express Edition) with 20GB of storage and 20GB of backup space and 750 hours of Amazon ElasticCache cache.

### 04 Additional options

In the additional options screen, you are able to select a basic low-cost configuration (which is eligible for the free tier) or manually configured more advanced setups such as high availability or fully custom. The basic free tier will deploy 64-bit Amazon Linux (and in our example PHP-7); if you require a different version, you can select ‘change platform configuration’ and choose from the list.

### 05 Instances and capacity

Sensible defaults are selected for the various categories of options. If you need a more powerful server, you can select this in ‘Instances’. The ‘Capacity’ section allows you to specify a preferred number of instances and whether you wish to deploy across multiple availability zones. A load balancer will be automatically provisioned and your application updates can be deployed either immediately or on a rolling basis.

![](img/fb76008333fb7aef815b136f9f1afe5f_60_4.png)

### 06 Network and database

By default, the ‘Network’ section of the configuration will launch your instance into the default VPC. If you want to use a specific VPC, you can configure it here. Elastic Beanstalk can also deploy RDS database servers via the ‘Database’ section, with engine, size, credentials, retention and availability policies also configurable here. After deployment, the RDS console can be used to change these settings too.

## Go serverless

Serverless concepts are distinctly forward-thinking. Breaking your complex application into microservices can offer many benefits

All of the AWS services we've talked about so far are traditional server concepts. Recently, however, Amazon has been heavily promoting the 'serverless' model. As the name suggests, serverless computing allows you to build and run applications and services without to Amazon CloudFront events. Amazon API Gateway makes it easy for developers to create, publish, maintain, monitor and secure APIs: it can process hundreds of thousands of concurrent API calls and handles traffic management, authorisation and access control, monitoring and API version management. The API Gateway is a great way to expose functionality provided by Lambdas. Amazon SNS (Simple Notification Service) and Amazon SQS (Simple Queue Service) provide inter-process messaging. SNS is a pub/sub messaging system for decoupling elements of a distributed microservice system while SQS is a versatile message queueing service. AWS Step Functions enables you to coordinate the components of distributed applications and microservices using visual workflows. Building applications from individual components that each perform a discrete function allows you to scale and change apps quickly. Step Functions is a reliable way to coordinate components and step through the app's functions. Amazon Kinesis makes it easy to collect, process and analyse real-time, streaming data to enable timely insights so you can react quickly to new info. Kinesis lets you cost-effectively process streaming data, with the flexibility to choose the tools that best suit the requirements of your app. With Kinesis, you can ingest real-time data such as application logs, website clickstreams and more into your databases or build your own real-time applications using this data.

So what might this look like in reality? Imagine you have some code for a website hosted in S3, which is served using CloudFront. When a user clicks on a function on the page, this could make a REST API call to an API Gateway endpoint, which will trigger a Lambda function to retrieve some information from a database (RDS, DynamoDB or similar) and return it, via the API gateway, to the application to render. Because the application intelligence runs in the Lambda function, you'll only pay for the resources used while the function is executing – once complete, the microservice in effect disappears. The AWS infrastructure allows these requests to happen at huge scale, providing massive capacity when needed and frugality at other times.

## Code and delivery

You won't be surprised to learn that there's a range of services to help you manage and deploy your application code, too. AWS CodeCommit provides secure and scalable Git repositories for storing code. AWS Codepipeline is a continuous integration and delivery pipeline for building, testing and deploying code every time there's a change. AWS CodeStar brings many of the AWS tools into a unified UI to easily manage software development in one place. It's also fully integrated with Atlassian JIRA for issue tracking, plus a host of AWS tools including Elastic Beanstalk – the orchestration service used to automatically deploy AWS infrastructure such as EC2 instances, S3 buckets and Elastic Load Balancers. Amazon AWS is an incredibly advanced enterprise product, but it's also an accessible tool for beginners through to enthusiasts. With straightforward entry level services like Lightsail, a well thought-out management console and a generous free tier and extensive documentation, it's good fun to take for a spin.
