# ### About MochiWeb

MochiWeb is an Erlang library that allows you to create lightweight HTTP servers. Although Cowboy is more powerful than MochiWeb, there are times that you might need something lighter and may consider MochiWeb. So, in the next section you will learn how to configure MochiWeb in order to serve a simple webpage.

You can get MochiWeb by executing the following command in your Linux terminal:

```
$ git clone git://github.com/mochi/mochiweb.git
cd mochiweb
Cloning into 'mochiweb'...
```
