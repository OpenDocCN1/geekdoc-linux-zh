# Desktop virtualisers

Whip up some virtual machines to harness the true power of your everyday computer using these open source options

+   - **GNOME Boxes**: One of the few virtualisation apps that comes bundled with a desktop environment, this is readily available to all users of GNOME and GNOME-based desktops. But does it have enough oomph to throw a serious challenge to the dedicated apps or is it just taking up space? [http://bit.ly/GNOMEBoxes](http://bit.ly/GNOMEBoxes)

+   - **QEMU**: One of the oldest such apps, it has been helping desktop users get a taste of virtualisation since the turn of the century. But technological comparisons aside, does QEMU as a desktop virtualiser still have what it takes to take on the challenge from the newer desktop apps? [http://www.qemu.org](http://www.qemu.org)

+   - **VirtualBox**: Chances are if you’ve dabbled with desktop virtualisation, it was thanks to VirtualBox. The open source app can take on impressive new features with proprietary add-ons. But do you really need to do so when there are pure open source competitors available? [https://www.virtualbox.org](https://www.virtualbox.org)

+   - **Virt-manager**: You can call Virtual Machine Manager Red Hat’s response to Oracle. From purely a desktop user’s perspective, irrespective of the technological differences, it’s an apt replacement for the likes of VirtualBox to create virtual machines without climbing through a steep learning curve. [https://virt-manager.org](https://virt-manager.org)
