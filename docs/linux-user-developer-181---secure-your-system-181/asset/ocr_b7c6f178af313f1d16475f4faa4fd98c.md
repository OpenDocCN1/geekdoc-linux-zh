A part of the `hw` project initialisation process that illustrates how you can use Cowboy in order to develop a web application in Erlang

```
```code
$ wget https://raw.githubusercontent.com/ninenines/erlang/master/erlang.mk
$ make -f erlang.mk bootstrap-rel
$ make
```
```

Figure 2 shows some of the results you will get on your screen after executing the previous commands. So far, you have created the skeleton of a new Erlang project and a dump shell script that you can run as `.rel/hw/_rel/release/console` to make sure that everything is fine.

and will be the first thing that you will need to download when developing a project that uses Cowboy. You can find more information about the Erlang build system at https://github.com/ninenines/erlang.mk.

But first you will need to create a directory that will keep all the files of the project – in this case the name of the project is `hw`, so the directory name will also be `hw`, which you can create by executing the `mkdir` `hw` command. Then you will need to execute `cd hw` to actually go into that directory.

Now follow the next steps in order to create a new Erlang project that will use Cowboy:

Now it’s time to actually install Cowboy by making changes to the Makefile. The final version of the Makefile will be as follows:

```
```code
PROJECT = hw
PROJECT_DESCRIPTION = A Hello World program
PROJECT_VERSION = 0.1.0

DEPS = cowboy
include erlang.mk
```
```

All the work is done by the `DEPS = cowboy` line, which will order the build system to download and install Cowboy. Then you will need to create a new file named `hw.app.src` inside the `src` directory (if it is not already there – you can see `hw.app.src` by looking at the source code that accompanies this tutorial). Now, if you execute the make utility, the build system will take care of the rest! If the last line of the output is `release-1.tar.gz successfully created` you are good so far.

Next, you will need to edit some of the existing files in order to define the URLs that your web app will support, as well as adding the required Erlang code that implements the desired functionality of the web app. First, you will edit, `src/hw.app.erl`. Figure 3 shows the final version of the `/src/hw.app.erl` file – this is the first place you should visit for finding out more about the list of supported URLs as well as the port number the Cowboy server will listen to. However, we are not done yet, as we will have to create a plain HTTP handler for the URL:

```
```code
$ make new t=cowboy_http m=hw_handler
```
```

Please make sure that the name of the handler is in sync with the name you defined in the `hw.app.erl` file.

Last, you will have to open the `src/hw_handler.erl` Erlang file, which was created by the previous command, in order to change the implementation of the `handle()` function. After editing, the implementation of the `handle()` function of the `hw_handler.erl` module should be as follows:

```
```code
