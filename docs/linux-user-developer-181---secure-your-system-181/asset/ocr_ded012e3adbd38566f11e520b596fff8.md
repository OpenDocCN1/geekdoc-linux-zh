# Fractal geometry

Fractal geometry is a relatively new branch of maths which can trace its origins back to the 1960s, when mathematician Benoît Mandelbrot posed the question "How long is the coast of Britain?" It transpires that the answer to the question depends on the length of the ruler you use to measure it – the shorter the ruler, the longer the coastline.
