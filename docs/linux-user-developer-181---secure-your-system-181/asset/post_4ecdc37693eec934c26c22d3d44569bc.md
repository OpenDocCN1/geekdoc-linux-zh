As one of the oldest surviving Linux distros, Debian is a testament to the most endearing quality of the Linux ecosystem – collaboration. The project works on three branches of development – Stable, Testing and Unstable – and packages move from one to the next, as they mature. The latest Stable release is the product of over two years of gruelling testing, and the end result is an incredibly stable and reliable distro.

Along from its slow-cooking release policy and vast software repositories, another feature that distinguishes Debian from its peers is its software policy. The distro only features applications released under a free software licence. Proprietary codecs, drivers for hardware devices, such as printers and graphics cards, are relegated to the non-free software repository, which isn’t enabled by default.

It’s due to the strict technical requirements that must be met for inclusion of software in Debian that for over ten years it didn’t ship with two of the most popular open source applications: Mozilla Firefox browser and Thunderbird email client, replacing them with the rebranded Iceweasel and Icedove. Debian release marks a return of the two beloved Mozilla applications as the dispute was finally resolved. Mozilla conceded that Debian's changes and updates to its products conformed with Mozilla's exacting quality standards. The trademark dispute which led to the birth of Iceweasel was also resolved with the release of Firefox logo under a free licence.

The release also features some changes that are especially relevant for existing users. Network interface cards (NICs) are now named using BIOS/firmware and slot number. Your Ethernet and wireless cards, for instance, will now be named as ens0 or wlP3s0 respectively. This is significant if you have scripts that reference a NIC by name, as you will have to edit these to provide the new names.

For administrators, the release ships with MariaDB, which replaces MySQL as the default database server. Security is a key focus of the latest release: Debian 9 features the modern branch of the popular security app GNU PG. Although now deprecated, the older version of GNU PG is still available for users as gnupg1; however, the newer branch brings with it improved smartcard support and better defaults for generating keys. While support for UEFI-enabled machines was introduced in the previous release, Debian 9 live images now also support UEFI-booting. The distro can now be configured such that the X display system no longer requires root privileges to run. To use the feature, however, you will need logind, libbam-systemd and the gdm3 display manager.

The latest release also features upgrades to underlying software such as the Linux kernel, desktop environments and everyday applications such as LibreOffice. As a result of its long testing, Debian doesn't feature cutting-edge software, but, in a sense, even that is a good thing for the Linux ecosystem as otherwise users would have no reason to venture near the likes of Ubuntu, Mageia, Mint and the others.

You can use this month's cover disc to try the Xfce version; GNOME is the default desktop environment, but there's also the option of MATE. The latest release marks a shift to a graphical installer as the default, but you can still opt for a curses-driven installation. Out of the box, the distro offers enough applications to serve home users and hobbyists. If you have a more specific use in mind, you will have to flesh out the distro.

### Pros

The gruelling testing produces an incredibly robust and stable distro, which can be used for any purpose due its vast repos.

### Cons

It features older versions of software than its peers. Try Testing or Unstable if you're interested in the cutting-edge.

### Summary

Dedicated to its late founder Iain Murdock, Debian 9 builds on the past releases. The long testing results in install-and-forget stability in a robust distro and don't mind the dated packages as a result of its slow release cycle, there's no beating Debian.

The long-awaited and much delayed Mageia 6 promises to be a wonderful new release, if the RC is any indication

As with its predecessor which spent over a year in development, Mageia 6 has faced inordinate delays. With the alpha release shipping in March 2016 and the beta in July, the release candidate (reviewed here) was finally unveiled towards the end of May 2017. The final release was to follow approximately two weeks after the RC, but there's no word yet on when it might finally be unveiled.

While the developers have faced flak from some users about the hold-ups, the delays are further testament to the their determination to ship an extremely stable and usable product. The upside to the long gestation period is that Mageia 6 ships with a bunch of fresh features and better performance.
