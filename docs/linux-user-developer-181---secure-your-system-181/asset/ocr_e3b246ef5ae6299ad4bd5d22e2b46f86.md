# Two new Linux laptops from Entroware

UK manufacturer unveils 13-inch and 17-inch Linux Ubuntu notebooks

Does the world need more Ubuntu laptops? UK manufacturer Entroware (www.entroware.com) certainly thinks so, releasing a pair of Ubuntu 17.04 notebooks in late June, with a choice of features.

First is the Apollo, a 13.1-inch slimline notebook in the MacBook Air tradition. The most basic version (E330 inc VAT) features a Pentium 4415U 2.3GHz dual-core CPU, although Core i3, i5 and i7 Intel Kaby Lake processors are also available. The baseline 4GB RAM and 500GB HDD can also be upgraded, while graphics are controlled by Intel HD Graphics. An LTE-enabled network card can also be selected.

Also new is the hybris, which starts from £810. The default option for this is a Core i5 processor, 4GB DDR4 RAM, a 500GB hard drive and Intel HD Graphics. All of this can be upgraded as above, of course, with an Nvidia GeForce GTX 1050 4GB also among the options.

Ubuntu 17.04 is installed by default on both laptop models, although 16.04 LTS is also available. But why Ubuntu? Entroware’s accounts and technical support manager Mike Wilson tells us that it’s really down to customer satisfaction.

“Ubuntu […] has proven itself to be a staple in the Linux desktop market, through years of stability, familiarity and ease of use. Coupled with the LTS releases and fast implementation of upstream updates, we are able to produce newer hardware to compete with the rest of the consumer IT market.”

“But isn’t it simpler to just install Ubuntu on a Windows laptop? “In the majority of cases, unfortunately, no. Some hardware vendors use components with poor Linux support, which can be problematic. This could mean that the customer would spend a lot of time trying to get their machine to work, if they are even able to do so.”

To overcome this, Wilson says Entroware’s approach is to source hardware to minimise compatibility issues, as well as bundle lifetime software support for each computer sold there. “Entroware’s support for Linux doesn’t end there. “Additionally, we help out the community by sponsoring events ( OggCamp), supporting distributions (Ubuntu MATE) and sponsoring Linux media (Late Night Linux).”

# TOP FIVE
Unity projects

![](bbox=[0.69, 0.24, 0.96, 0.34])

+   **1 Yunit – the Unity 8 fork**
+   While it failed to gain universal popularity, Unity certainly has its fans and many developers are collaborating on a new fork, Yunit. So far they’ve begun publishing Debian unstable releases for 64-bit systems. Yunit is also collaborating with the UBports project (below) for Ubuntu Touch devices. Find out more at https://yunit.io.

+   **2 UBports saves Touch**
+   Supporting Ubuntu phone and tablet devices and developing a presence on core devices (such as the Google Nexus 5 2015 edition), the team at https://ubports.com are doing a great job in keeping the Ubuntu Touch mobile OS alive.

![](bbox=[0.69, 0.54, 0.96, 0.65])

+   **3 Plasma Unity theme**
+   Switched to KDE Plasma and feeling sad about Unity’s demise? Thanks to the KDE Store’s “Loki and Feel” section it’s simple to install a Unity theme, known as the United Desktop. This theme runs on KDE Plasma 5.9.

+   **4 Dash to Dock Unity**
+   Finally, the popular GNOME extension Dash to Dock has been receiving many new contributions since Unity’s retirement was announced. Among the features to beported are the launcher backlight and expose. Transferring to GNOME has become even less painful.

+   **5 United GNOME theme**
+   Amazingly, several Unity themes are already available. Most notable is the United 8-based United GNOME, available on GitHub, offering a faithful recreation of the desktop environment. As with many GNOME themes, United GNOME requires the GNOME Tweaks Tool for installation.
