# Conclusion

Now that you understand how the shell operates under Linux, you are ready to exercise more control over the command line. The root user is the most powerful user under Linux and has absolute control over every file, program, or directory on the system. The next chapter will explain many of the features of root and what it can and cannot do as well as caution you of the dangers inherent with such power.
