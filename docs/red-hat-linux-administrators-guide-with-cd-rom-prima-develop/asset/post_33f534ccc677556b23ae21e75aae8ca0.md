
# Install, Explore, and Operate your Red Hat® Linux® System

Finally, a book written specifically for Red Hat Linux administrators! Beginning with basic administrative tasks and progressing into more advanced topics, *Red Hat Linux Administrator's Guide* will be your definitive manual to set up your network, master essential skills, and run your system with Red Hat.

# WHAT'S ON THE CD-ROM:

- Over 1,300 files!
- Administrative Files: Firewall/Security, Monitoring
- Communication Files: Conferencing, Messengers
- Development Files: Compilers, Libraries
- Management Files: Compression, Packaging
- Graphics Files: 3-D Modeling, Image Viewing
- Network Files: Anti-Spam, E-Mail
- Office Files: Calculators, HTML Editors
- System Files: CD Burners, Utilities

**Kerry Cox** is currently Systems Administrator for KSL Radio and Television in Salt Lake City, Utah. He manages a large network of Linux and Solaris machines, as well as GNUware.com, a small company providing a compilation of 1,300+ Linux programs on one CD.

# MASTER THE BASICS

- Obtain, configure, and install the software
- Start up, shut down, and do everything in between
- Set up your server and manage users

# ADMINISTER YOUR SYSTEM

- Set up policies and monitor your servers
- Clean up, back up, and troubleshoot your system
- Write scripts to automate everyday tasks

# CUSTOMIZE TO FIT YOUR NEEDS

- Install additional programs
