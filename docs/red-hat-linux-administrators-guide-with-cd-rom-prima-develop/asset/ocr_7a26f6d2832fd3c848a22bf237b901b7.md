# Updating Packages from the Command Line

If you do not wish to run Update Agent within a window manager or from an xterm or GUI desktop, you can also choose to run the program from the command line (see Figure 11.10). At a root shell prompt, enter /usr/sbin/update -l to retrieve a list of available packages that you can update. Remember again that depending on the speed of your machine and the packages available, the list may scroll by too quickly for you to read each one. You can pipe the output to a pager, using an option such as `less`, or redirect the output to a text file, which you can read with a pager or any text editor.
