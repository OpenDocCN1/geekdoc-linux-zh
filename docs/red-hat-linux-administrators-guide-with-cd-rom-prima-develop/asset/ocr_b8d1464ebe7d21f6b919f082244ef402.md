Similarly, to verify which machine you are currently working on, in case you may be working on another similar machine with a like shell, enter `uname -a`. This prints out the name of the local machine, the kernel version, and date of the last kernel recompilation.

# **TIP**

You can always start a new shell simply by invoking it from the command line. If you are working under the bash shell and want to change to tsh, simply enter the name of the new shell. To leave that shell, enter `exit`.
