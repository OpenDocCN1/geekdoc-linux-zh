It is not just the shell itself that is so useful; the prompt can also be very informative. What appears in the field just before the prompt can provide the location, the username, and the name of the machine. This information can be invaluable if you have accounts on several machines. Performing a Telnet session back and forth among different Linux servers can quickly cause disorientation. It is easy to forget which machine is your current host. To provide more information in a limited amount of space, the prompt of most shells gives added information about location and user.
