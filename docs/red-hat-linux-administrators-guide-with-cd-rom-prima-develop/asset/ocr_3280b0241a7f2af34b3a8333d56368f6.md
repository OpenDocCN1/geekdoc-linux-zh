# Exploring Newcomers to the Linux Scene

A newcomer to the scene of Linux word processors is the AbiWord suite. Although AbiWord provides its source code, it is relatively immature in its development. AbiWord is available with the latest Helix GNOME release, though not by default. You may choose to install it as part of the desktop or download the code yourself and compile it for your own use. AbiWord requires an additional set of libraries and graphical support, so choosing the RPM version is the recommended method.
