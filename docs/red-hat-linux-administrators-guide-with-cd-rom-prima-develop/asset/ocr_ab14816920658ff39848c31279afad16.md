The *comment* option is the same as a server string under the Global section in that what you enter in this option will be visible as the comment section under other Windows machines. The SAMBA GUI editor or SWAT (SAMBA Web-Administration Tool) offers other options for configuring shared home directories. SWAT allows SAMBA's smb.conf file to be remotely managed using your favorite web browser. SWAT is enabled on TCP port 901 via inetd. But for now, rather than using a GUI client it is usually sufficient to enable other users to browse or write to the files.
