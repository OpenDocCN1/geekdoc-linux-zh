Much like the forwarding file, this file simply lists the domain names and their respective IP addresses. However, immediately under the Domain Authority section, the in-addr.arpa entry lists the class C in reverse order. Because DNS lookups start from the end and work their way back to the beginning or largest number, reversing the numbering assists in providing the correct format.

As in the preceeding localhost entry, in the db.206.81.148 file, there must be a period at the end of every domain name listed in the Reverse Names section. Any available IP address is commented out for later use.
