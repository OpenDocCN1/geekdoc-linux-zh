While trying to get the encoder and the passwords to work, I discovered that you must to use the password encoding program that comes with icecast and encode the password in the liveice.cfg file. In other words, decide what password you will use, place it unencoded in the liveice.cfg file, encrypt the password, then place the encrypted text within the body of this icecast.conf file. This is required if you use the --with-crypt option when compiling icecast initially from source.
