Listing 3.1 does not show all possible directories, but does show a rough approximation of a standard installation. Nor does this layout show any directories that can be created by a regular user. The possibilities are unlimited in this case.

As shown in Listing 3.1, several subdirectories are repeated in two distinct directories. The directories `/usr` and `/usr/local` both have `bin/`, `etc/`, `games/`, `include/`, `lib/`, `man/`, `sbin/`, `share/`, and `src/` local directories. The reason for this is that the `/usr` directory defines global programs installed by default through the installation program, whereas the `/usr/local` directory is designed for local users to install their own customized binaries. Often, a self-installed program requires the same directories, so these file types will be repeated in the `/usr/local` directories.
