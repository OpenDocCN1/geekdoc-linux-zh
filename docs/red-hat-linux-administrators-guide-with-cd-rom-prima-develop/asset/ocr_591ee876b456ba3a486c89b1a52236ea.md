# Using Linuxconf for Partitioning

Knowing the available partitions, their mount points, and their sizes is very handy if your system suffers a partition crash or faulty reboot. Linuxconf also provides this information along with a method of editing it to suit. Much like the disk utility used during the installation, Linuxconf enables you to edit and modify existing partitions.

> **CAUTION**
> 
> This is a very sensitive task of Red Hat Linux administration; you should be careful when modifying anything related to partitions. This section is recommended for informative purposes only.

Under the main Config window of Linuxconf, the File systems button will bring up several options for accessing other partitions or file system types. The sections allow for reconfiguring or partitions and network volumes.
