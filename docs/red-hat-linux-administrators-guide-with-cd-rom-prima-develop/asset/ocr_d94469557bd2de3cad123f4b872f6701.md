I could have chosen to name this latter directory majordomo/ instead of the full version name, but I wanted to know what the latest version was and when I should upgrade. If you wish instead to have a simple majordomo/ directory, create a symbolic link from the real directory to a directory without the version number. Use something similar to the following command:

```
$ ln -s majordomo majordomo-1.94.5
```

Once I had the source code in hand, I needed to pick a user and group ID for majordomo to run under. I chose majorom and daemon. Then I edited the makefile so it would know where to look for my Perl libraries. I chose the following two variables for my Perl and compiler:

```
PERL = /usr/bin/perl
CC = gcc
```
