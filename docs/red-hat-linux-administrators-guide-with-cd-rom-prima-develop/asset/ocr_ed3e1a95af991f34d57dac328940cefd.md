O nce you understand how to install additional programs onto your machine via the command line or by using specific GUI tools, you can begin to customize your X Window System interface. X is the *de facto* standard for new installations. Red Hat boots into an X Window System environment for the default install process if the machine has a video card that is new enough and if the machine can also start up directly into X upon bootup so that you need not use the command line. This default process gives users direct access to X terminal emulators, which provide command-line functionality but also allow for the use of GUI programs.

# Customization of the X Window Interface

Perhaps the most customizable feature under Linux is the window manager. The window managers control the windows and terminals within your X session. With different managers you can tweak the appearance and feel of your GUI. Using themes and plugins that are available for each manager you can even make your desktop appear and function just like a Windows or Apple desktop, or it can be personalized to appear like something never before seen. Each window manager offers a wide variety of icons, graphics and textures to assist users in creating their own unique desktop display.
