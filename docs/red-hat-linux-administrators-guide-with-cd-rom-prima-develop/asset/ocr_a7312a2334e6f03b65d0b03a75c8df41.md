The Gnome home page briefly describes the components of the Gnome panel, which includes the following:

+   ♦ *Menus.* Menus are lists of items, each of which starts an application, exec-utes a command, or opens a submenu. The leftmost icon normally seen after installation is a stylized footprint icon (the Gnome logo). This is the main menu, one of the most important objects in the panel. This menu provides access to almost all the applications, commands, and con-figuration options available in Gnome. Gnome sometimes provides a folder icon on the panel that links to a specific directory. This icon is also part of the menu feature set. Gnome enables users to create their own menus with personalized contents to use in addition to the main menu. To open a menu, just click the icon with the left mouse button.
