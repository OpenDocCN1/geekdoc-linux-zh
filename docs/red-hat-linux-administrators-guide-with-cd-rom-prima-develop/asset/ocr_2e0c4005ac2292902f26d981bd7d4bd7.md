# FIGURE 15.1

The initial Network Configurator dialog box that appears after you enter the netcfg command.

The next button on the Network Configuration dialog box, Hosts, lists the hosts accessible to your machine from within your network. Here you list the IP, name, and nickname or alias of each host as it appears via your network connection. Within the GUI, this display box is equivalent to the /etc/hosts file shown in Figure 15.2.

You can add, edit, and remove the hosts as necessary. Any changes that you make on this screen affect your /etc/hosts file directly.
