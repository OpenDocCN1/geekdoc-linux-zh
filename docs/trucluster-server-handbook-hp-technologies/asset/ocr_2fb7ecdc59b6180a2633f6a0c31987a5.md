# 26.4.11 Retreat to the V1.[56] Cluster

If the migration failed, reconnect the production data (storage) back to the V1.[56] cluster; boot the V1.[56] cluster (which consists of the one member); run clu_migrate_recover and set the ASE services ONLINE (asengmr -s <service>) as shown in Figure 26-10.
