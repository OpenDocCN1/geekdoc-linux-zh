# Memory Channel 2 Jumper Settings

| Jumper | Description |
|---|---|
| J1: Hub Mode | Standard Hub: Pins 1 to 2 |
|  | Virtual Hub 0 (VH0): Pins 2 to 3 |
|  | Virtual Hub 1 (VH1): All open |
| J3: Window Size | 512 MB: Pins 2 to 3 |
|  | 128 MB: Pins 1 to 2 |
| J4: Page Size | 8 KB Page Size: Pins 1 to 2 (Default for UNIX) |
| J5: AlphaServer 8x00 mode | 8x00 mode selected: Pins 1 to 2 |
|  | 8x00 mode not selected: Pins 2 to 3 |
| J10 and J11: Fiber Optic Mode Enabled | Fiber Off: Pins 1 to 2 |
|  | Fiber On: Pins 2 to 3 |
