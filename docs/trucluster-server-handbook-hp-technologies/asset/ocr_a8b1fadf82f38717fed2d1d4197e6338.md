On the client, after issuing two tftp commands for execution in the background, both of the tftp servers are running on the same cluster member. This would be true no matter how many tftp commands were issued. They would all be served by daemons running on the same cluster member because of the in_single service attribute. Think of in_single as meaning incoming requests are serviced on a single cluster member.
