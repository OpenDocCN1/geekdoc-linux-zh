Notice that the two new connections, !NEWCON02 and !NEWCON03, are the same KGPSA adapters that appear in MOLARI1B01 and MOLARI1A01, but the firmware upgrade has changed the Fibre Channel Node Name or the HOST_ID on the connections. The system's old connections are now OFFLINE and the system cannot access any of the units that are presented with Selective Storage Presentation⁴. In a cluster and especially during a rolling upgrade, this would not be a very desirable situation but it can easily be resolved.
