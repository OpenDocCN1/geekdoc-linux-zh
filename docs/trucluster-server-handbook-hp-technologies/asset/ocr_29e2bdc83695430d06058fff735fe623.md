# 13.9.4.3    The CFS Server is Running Out of Memory?

If a member acting as a CFS server does not have a large amount of memory, you may want to consider setting the `cfs:svrctok_max_percent` attribute’s value to something lower than the 25% default. We do not recommend you do this unless you find that the member is consistently running out of memory and you cannot add additional memory.
