# Rolling Upgrade Stages

| Stage | Description of Tasks to be Performed | Runlevel | Member | Time |
|---|---|---|---|---|
| Preparation | Backup the Cluster.<br><br>Choose a Lead Member for the Rolling Upgrade.<br><br>Update Firmware.<br><br>`# clu_upgrade -v check setup 1` | single-user or multi-user<br><br>multi-user<br><br>console<br><br>multi-user | Any<br><br>Lead | Time can vary greatly according to size and number of file systems that are required to be backed up. |
| Setup | `# clu_upgrade setup 1`<br><br>Reboot all cluster members except the Lead member. | multi-user | Lead<br>All but the Lead | 45 - 120 minutes |
| Preinstall | `# clu_upgrade preinstall` | multi-user | Lead | 15 - 30 minutes |
| Install | `# clu_upgrade install`<br><br>Update installation (installupdate) and/or<br><br>New Hardware Delivery (NHD) kit installation (`nhd_install`) and/or<br><br>Patch kit installation (dupatch) | multi-user<br><br>single-user<br><br>single-user<br><br>single-user or multi-user | Lead | 30 - 120 minutes |
| Postinstall | `# clu_upgrade postinstall` | multi-user | Lead | < 1 minute |
| Roll | One member at a time, shutdown the system.<br><br>Update the firmware.<br><br>Boot to single-user mode.<br><br>While in single-user mode:<br>`# bcheckrc`<br>`# update`<br>`# swapon -a`<br>`# clu_upgrade roll` | console<br><br>single-user | All but the Lead | 15 - 30 minutes per cluster member |
| Switch | On any member, run `clu_upgrade switch`<br><br>Reboot all members one at a time. | multi-user | Any<br>All | < 1 minute<br>Normal reboot time. |
| Clean | On any member, run `clu_upgrade clean` | multi-user | Any | 30 - 90 minutes |
| Undo | Prior to the switch step, any or all steps can be undone. See section 25.6 for more information. | multi-user | varies according to step being undone. | varies according to step being undone. |
