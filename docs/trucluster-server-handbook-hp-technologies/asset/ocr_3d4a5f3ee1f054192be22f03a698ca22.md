# 11.2.7 TruCluster Server License PAK

Finally, the clu_add_member command prompts us for the last input – the TruCluster Server License PAK. With this prompt, we can choose to either add the license PAK for the new cluster member now or use the lmsetup command later after we boot the new cluster member. In our example, we choose to enter the TruCluster Server License PAK.
