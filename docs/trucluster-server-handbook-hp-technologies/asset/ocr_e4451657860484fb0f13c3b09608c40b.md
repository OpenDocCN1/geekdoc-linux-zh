# 11.5 Install All License PAKs

One of the last things to be done on the new cluster member is to install all the remaining License PAKs specific for that cluster member. Note: as part of the addition of a new member to the cluster, we already entered the TruCluster Server License PAK so this does not need to be reinstalled.

We recommend the use of the lmsetup(8) command especially for the installation of multiple License PAKs. This is by far the easiest and most straightforward mechanism for the installation of License PAKs.

```
# /usr/sbin/lmfsetup
```

As soon as all the License PAKs are installed and the License Management Facility’s database reset, we verify that all the License PAKS are active by using the lmF(8) command.
