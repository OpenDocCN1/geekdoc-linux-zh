# Migrating to TruCluster Server

Migrating from TruCluster Production Server or TruCluster Available Server version 1.[56] to TruCluster Server version 5.X is a fairly significant task since you can’t perform a “rolling” upgrade; in fact, you can’t have a V1.[56] cluster connected to a V5.X cluster. There are tools, however, to help you migrate (we use the term “migrate” because it is a more accurate description of the process than “upgrade”). There are three basic migration options, and we’ll discuss each one and illustrate the most popular. We will also raise some of the considerations and requirements necessary to move from the previous type of cluster to the new one.

We will cover the following:

+   - Migration Tools
