# 8.3 **EVM Priorities versus syslog and binlog Priorities**

Event priorities are shown in Table 8-3. EVM priorities range from 0-700, with 700 intended to be the highest priority, whereas syslog priorities range from 7-0, with (0) being the highest. The binlog priority range, with only three effective priorities, is not nearly as granular.

| Event Priorities |  |  |  |
|---|---|---|---|
| Name | EVM | syslog | binlog |
| process-to-process | 0 | — | — |
| debug | 1–99 | 7 | low (5) |
| information | 100–199 | 6 |  |
| notice | 200–299 | 5 |  |
| warning | 300–399 | 4 | high (3) |
| error | 400–499 | 3 |  |
| critical | 500–599 | 2 |  |
| alert | 600–699 | 1 | severe (1) |
| emergency | 700 | 0 |  |
