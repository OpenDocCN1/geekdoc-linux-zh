# 24.6.1 Alias Resource Using `cluangmr`

Use the `cluangmr(8)` command to “join” the widget alias to the “start” entry point of the widget resource’s action script. When the resource relocates to another cluster member, use the `cluangmr` command to “leave” the widget alias in the “stop” entry point of the widget resource’s action script.

+   - Save a copy of the original application.tdf file.
+   - Add an attribute to the application.tdf file as follows:
+     - If you want to use an alias name, create a “name_string” attribute.
+   
+       ```
+       attribute: USR_ALIAS_NAME
+       type: name_string
+       switch: -o an
+       default:
+       required: no
+       ```
+   
+     - If you want to use an alias IP address, create an “internet_address” attribute.
+   
+       ```
+       attribute: USR_ALIAS_IP
+       type: internet_address
+       switch: -o aa
+       default:
+       required: no
+       ```
+   
+     - If you need more than one alias, create a “name_list” attribute.
+   
+       ```
+       attribute: USR_ALIAS_NAMES
+       type: name_list
+       switch: -o al
+       default:
+       required: no
+       ```
+   - In the “start” entry point:
+   
+     ```
+     # cluangmr -a alias=$(USR_ALIAS_NAME),join,rpri=1
+     ```
+   
+     ```
+     # cluangmr -x start
+     ```
+   - In the “stop” entry point:
+   
+     ```
+     # cluangmr -a alias=$(USR_ALIAS_NAME),leave,rpri=0
+     ```
