Notice that we now see an active path but still do not see a device name. This is where we can have the dsfmg r command give us a hand. The dsfmg r command with the "-k" option creates all newly detected devices. Note: this additional step should be unnecessary (and is unnecessary in V5.1A). In V5.1 (where this example was created), however, it was necessary.

```
# dsfmg r -k
```
