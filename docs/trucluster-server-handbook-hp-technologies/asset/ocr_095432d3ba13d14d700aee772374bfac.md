Note that you can change the server for more than one device at a time. For example, if tape1 is one of two tape devices in a tape jukebox, you can move tape1 as well as the changer (mc0) and the other tape drive (tape2) as follows:

```
```text
# drdmg -a server=sheridan tape1 tape2 mc0
```

# drdmg -a server -a accessnode tape1 tape2 mc0

# 15.2.3  Resetting the Statistics

On occasion it may be useful to reset the statistics on a device for a member to test its connectivity—in fact we'll do this in the following section. To reset the statistics for a device on the member that you are logged in to, issue the following command:

```
```text
[sheridan]
# drdmg -a statistics=0 dsk5
```
