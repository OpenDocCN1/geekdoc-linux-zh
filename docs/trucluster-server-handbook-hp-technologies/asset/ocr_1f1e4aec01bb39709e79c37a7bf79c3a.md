For example, `/etc/rc.config` is a link to `/.local../etc/rc.config`, but `/etc/sysconfigtab` points to `/.local../boot_partition/etc/sysconfigtab`. Both files are member-specific.

```
## ln /etc/rc.config /etc/myconfigtab
/etc/rc.config -> ../cluster/members/{memb}/etc/rc.config
/etc/sysconfigtab -> ../cluster/members/{memb}/boot_partition/etc/sysconfigtab
```

Remember that `/.local..` is a CDSLink that points to `/cluster/members/{memb}`.
