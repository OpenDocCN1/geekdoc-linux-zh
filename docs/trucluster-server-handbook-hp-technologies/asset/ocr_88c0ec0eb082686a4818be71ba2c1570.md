Now that we know the connections from the cluster nodes to the storage, for every storage unit that we create for the cluster, we would set the accessibility so that only the nodes of the cluster have access to this storage. First, we would disable access to all connections; then selectively enable access to only those connections connected to the cluster nodes.

```
MSG> add unit d101 m2 partition=1 disable_access_path=all
```
