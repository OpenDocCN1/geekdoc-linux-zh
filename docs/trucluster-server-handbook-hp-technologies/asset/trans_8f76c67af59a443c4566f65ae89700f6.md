Tru64 UNIX 5.1A 版本包含 Perl 5.6.0 版本，cfs 命令利用了 V5.6.0 特有的功能。因此，如果你系统上安装了 Perl 5.6.0 或更高版本，请使用 cfs；否则请使用 cfs_p5.005。
