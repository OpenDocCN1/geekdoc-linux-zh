# NOTE:

If you need the extra file system space, you can add up to two additional volumes to `cluster_root` at this point. Just remember to account for them in steps 10, 11, and 12. See Chapter 11 of the *TruCluster Server* Cluster Administration manual for more details.

```
```sh
# advfs /dev/disk/dsk170e cluster_root
```
```

+   6. Mount `cluster_root`.

```
```sh
# mount cluster_root#root /mnt
```
```

+   7. Restore `cluster_root` from backup.

```
```sh
# vrestore -xf /dev/tape/tape2 -D /mnt
# umount /mnt
```
```

+   8. Restore `cluster_usr` and `cluster_var` by repeating steps 6 and 7 but for the `cluster_usr#usr` and `cluster_var#var` filesets. (Or you could leave `cluster_root` mounted and mount these filesets at `/mnt/usr` and `/mnt/var` respectively and restore them.)

+   9. Re-mount `cluster_root` if you unmounted it in step 7.

```
```sh
# mount cluster_root#root /mnt
```
```

+   10. Fix the restored `/etc/fdmns/cluster_root` device linkage to reflect the new device name. (Also update `cluster_usr` and `cluster_var` if those file systems were also restored.)

```
```sh
# cd /mnt/etc/fdmns/cluster_root
# rm *
# ln -s /dev/disk/dsk11a
```
```

+   11. Take note of the major and minor numbers of the new `cluster_root` device.

```
```sh
# file /dev/disk/dsk11a
/dev/disk/dsk11a:    block special (19/97)
```
```
