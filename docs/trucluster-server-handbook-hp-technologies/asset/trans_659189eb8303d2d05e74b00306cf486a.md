前面带有 "<" 的输出显示的是 molari 特有的硬件，而前面带有 ">" 的输出显示的是 sheridan 的硬件。

## 12.3.2.1 如何查看集群范围的硬件视图？

许多 hwmgr 命令选项提供了将命令“聚焦”到成员或集群的能力。可以使用 "-cluster" 选项来聚焦整个集群。
