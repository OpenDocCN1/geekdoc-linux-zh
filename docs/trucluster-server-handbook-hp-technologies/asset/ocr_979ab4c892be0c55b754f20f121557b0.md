# 16.5.1.5   Making Aliases

Remember the last time you watched a duck glide serenely across the surface of a pond? Beneath the surface, those little webbed feet were paddling like crazy! That’s the way we view cluster aliases. You have to admit that cluster aliases seem like the surface, but are in fact quite complex (and we have yet to grasp the full truth about the cadence of the paddling). Before we move into deeper waters with cluster aliases, we thought it might be time to step back and examine the usefulness of this cluster feature.
