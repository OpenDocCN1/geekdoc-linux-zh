# Mozilla Web Browser

![](bbox=[0.35, 0.18, 0.99, 0.99])

Using the Mozilla Web browser takes no training if you've ever used any other Web browser. You type in the address of the site you want to view, and there it is. If you click a link, you go to wherever the link leads. Click on a “Send Email” link and an email window appears. Click the “Print” icon and the page you're looking at prints out. Click the “X” in the browser's upper right-hand corner and the window closes. Select “File,” click “Quit,” and the entire browser shuts down. In other words, typical browser stuff.
