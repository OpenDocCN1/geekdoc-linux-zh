# **Getting Help with Samba and Smb4k**

Samba itself is a fairly broad topic; it might be more useful to look for help related directly to Smb4k instead. Unfortunately, as of this writing, the Smb4k handbook is only an empty placeholder and contains no information. There is a mailing list, however at `http://developer.berlios.de/mail/?group_id=769`.

Please remember to search the archives before posting a new message; it is likely that list members have already answered your question in the past.
