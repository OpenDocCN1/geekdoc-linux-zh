# apropos

In those moments when my memory is not all it should be\-when I can't recall the exact name of the command I need to do a task\-it's good to know apropos.

The basic format for apropos is:

[username]$apropos search-term

Let's say you are searching for a command to edit sound files. To find all sound related commands, you would enter “apropos sound” at the command line. Here's what apropos had to say:

Anytime apropos found “sound” in its database, it told me the name of the program and gave brief description of it. At the bottom of that list I found sox, which allows you to trans-laude sound files from one audio format to another, as well as add reverb or echo or other sound effects. Just what I was looking for.
