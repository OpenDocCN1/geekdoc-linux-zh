# The GIMP—A Full- featured Graphics Application

If you're coming from Windows you're probably used to a decent low-end image manipulation program like Paint Shop Pro, CorelDRAW Essentials, or, if you're lucky, a high-end graphics program like Adobe Photoshop. At their most basic level, these applications can digitize and modify photographs or create and edit drawings. At their most powerful, a trained, highly skilled, and experienced user can create amazing works of art with them. But as of this writing none of these programs is available for Linux.
