# **Digikam Setup**

The first screen you see when you start Digikam asks you where you want to store your photos. SimplyMEPIS already has a “Pictures” folder, so that’s a logical place to put them unless you want to make your own folder under a different name. (Because you can easily move your photos from folder to folder later with the KDE file manager, we’ll just put them in “Pictures” for this demonstration.)

Next—and this is purely optional—we can choose how large we want our thumbnails (the miniature “preview” versions of our photos that show on our gallery pages) to be, and at the same time we have a chance to create “Album Collection Types” either by choosing one or more from a built-in list or by clicking “Add” to create a folder with a name you select.
