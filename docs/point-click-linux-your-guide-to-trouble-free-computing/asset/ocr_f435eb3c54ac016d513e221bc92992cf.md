# ## Working with Pictures

To retrieve a pre-existing image file, click on File, then Open, then navigate to the file and click on OK. Another window will open up with the picture in the middle, rulers at the sides, and a menu at the top.

To change the whole picture's properties, such as size, resolution, color depth, or to add special effects or filters, use the menu in the picture window. The main GIMP window's menu is only useful for program functions not related to the picture you're currently working on. You can, of course, use all the available tools in the main GIMP window to alter or manipulate the picture or pictures you're working on.
