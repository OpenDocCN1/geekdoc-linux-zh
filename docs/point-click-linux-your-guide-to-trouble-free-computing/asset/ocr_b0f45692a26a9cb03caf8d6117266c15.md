Enter the GNU Image Manipulation Program, or the GIMP for short. It’s a lightweight but powerful graphics program with an unfortunately awkward interface.

![](bbox=[0.48, 0.07, 0.95, 0.27])

# ## Getting Started

You’ll find the GIMP in the Graphics section of your KDE menu. Click on the K-Gear icon in the lower left corner of the screen, then Graphics, then the GIMP.

The first thing you’ll see is an orange setup screen.

![](bbox=[0.48, 0.3, 0.95, 0.53])

This screen is simply a welcome message introducing you to the GIMP. You can read it if you like, but there isn’t any really valuable information there. Click the “Continue” button. The next screen asks you where you’d like to put the folder that will store your program settings and preferences; it’s best just to leave it at the default location, so click on “Continue.” Next, you’ll be shown an installation log—you can read it if you like, but it’s not necessary. Click “Continue” again and you’ll be brought to a screen labeled “Performance Tuning.”
