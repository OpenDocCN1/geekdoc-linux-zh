# Linux Administration: A Beginner's Guide

Samba is a powerful suite of applications that helps UNIX-based systems (such as Linux) interoperate with Windows-based and other operating systems. It is an open source implementation of the Server Message Block/Common Internet File System (SMB/CIFS) protocol.

Samba provides file and print sharing services to Windows clients as well as other networked clients running operating systems. It does this through the use of the native Microsoft networking protocols SMB/CIFS. From a point of view, this means you can deploy a Linux/UNIX-based server and use it to provide file sharing, authentication, print, and other services to non-native Linux clients such as Windows systems. Using Samba means that Windows systems can use their native tongue to talk to the Samba server—means fewer hassles and seamless integration for your users.

This chapter covers the procedure for downloading, compiling, and installing Samba. With any software of its caliber, Samba provides a rich set of configuration options that make it suitable and flexible for various environments. But frankly, you should be able to get Samba up and running with very few changes to the default configuration. We will concentrate on how to perform customary tasks with Samba and how to avoid some common pitfalls with brief coverage of some command-line utilities such as smbclient.

No matter what you've chosen for Samba, be sure to take the time to read the program's documentation. It is well written, complete, and thorough. For the short afternoon to get more out of it, you'll gain a substantial amount of knowledge.

> NOTE Samba has been ported to a significant number of platforms—almost any variant of UNIX you can imagine, and several non-UNIX environments. In this discussion, we are, of course, most interested in Samba on Linux-based platforms, but keep in mind that Samba can be deployed on other platforms.
