# CHAPTER 21 Voice over Internet Protocol (VoIP)

Dialplan Configuration: Incoming Calls (extensions.conf) Now that you have configured your Google Account, have an inbound U.S. number from Google Voice (408-555-1212), and have successfully configured your connection to the Google Voice Service, Google Voice will forward all calls to your Google Voice number to your Asterisk system. The next step is to describe how your Asterisk system will handle the call when it is received in the dialplan.

Let's configure your dialplan to receive an incoming call from Google and route it to Alice, the SIP phone you created with extension 1001. Edit your dialplan and insert the following at the end of the file:

```
# cd /etc/asterisk
[root@server asterisk]# vi extensions.conf
```

```
[pstn-in]
exten => s,1,Noop()
same => n,Wait(1)
same => n,Answer()
same => n,SendDTMF()
same => n,Dial(SIP/1001,20)
```

In this example we use the s unmatched extension because we are configuring only one connection realm. We're waiting 1, answering the call, sending the DTMF “1” back to Google, and dialing the extension 1001 to pass the call to Alice. We process the call in this sequence as a workaround, however inbound calls from Google have call scaling enabled by default. Without SendDTMF(), you'll have to confirm with Google whether or not you want to answer the call—even if call scaling is disabled in your Google Voice control panel.

The inbound caller ID from Google is looking a bit nasty; for example:+15105551212@voice.google.com/srvres-TAUMj4jmMtk3Ojk4jMZm=. This may cause issues with your phone set (softphone or hardware). Even if it does not cause any function issues, the presentation is not very nice. We can strip the unwanted characters and only pass the calling number using the following dialplan.

Update the dialplan configuration with the following filter:

```
same => n,Set(incomingid=${CALLID(name)})
same => n,Set(realid=${CUT(incomingid,*,1)})
same => n,Set(CALLID(ALL)=${realid})
```

First, we set a variable called incomingid to be equal to the name field of the CALLERID function. Next, we use the CUT function to grab everything that's before the @ symbol, and save it in a new variable realid. We'll then set this new value stored in the realid variable as the caller ID we're going to use for your Dial () application.
