NOTE Even though you can perform an OS installation using a physical drive attached to the host, it is more convenient to install and maintain your VM guests using the original version ISO image files directly. This way, you won't have to worry about creating CDs or DVDs or drives every time a new version of your Linux distro is reloaded. If you need to use a CD/DVD media inserted into a physical optical drive, you only need to point the command-line utility or GUI KVM manager to the appropriate device file.
For example, you can provide the path to the device representing the first optical drive, such as /dev/sdb—assuming, of course, that you have previously prepared and built the OS to a blank CD/DVD-ROM disk and inserted it into the host system.
