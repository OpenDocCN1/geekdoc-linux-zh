To use hostctl to view the transient hostname on a Red Hat-like system running systemd (such as Fedora),

```
[root@fedora-server ~]# hostctl status --transient
```

To use hostctl to view the pretty hostname on a Red Hat-like system running systemd (such as Fedora),

```
[root@fedora-server ~]# hostctl status --pretty
```

Let's use hostctl to set a boring hostname on a Red Hat-like system running systemd (such as Fedora):

```
[root@fedora-server ~]# hostctl set-hostname "fedora-server-01" \
--static
```

To use hostctl to set a transient hostname on a system running systemd (such as Fedora), type

```
[root@fedora-server ~]# hostctl set-hostname \
"fedora-server-01" --transient
```

Now use hostctl to set a slightly more colorful pretty hostname on a system running systemd (such as Fedora):

```
[root@fedora-server ~]# hostctl set-hostname \
"KickAss Linux Server*" --pretty
```

View all the different classes of hostnames that you just configured by typing

```
[root@fedora-server ~]# hostctl status ""
```

To revert a hostname class to its default value, you can supply the empty string " as the argument to the hostctl set-hostname command. For example, to clear the current hostname and reset it to its default value, type

```
[root@fedora-server ~]# hostctl set-hostname "" --static
```
