> TIP udev subsystem is the official mechanism for manipulating device names
asigned to network devices such as Ethernet cards. This can be useful in overcoming
the occasional unpredictability with the Linux kernel names and detects network
devices.

You can find all of the network device drivers that are installed for your
kernel in /lib/modules/uname -r/kernel/drivers/net directory, like so:

```
[rootserver]# cd /lib/modules/`uname -r`/kernel/drivers/net
[rootserver]# ls
```

Note backticks (versus single quotes) surround the embedded uname-r
command. This will let be sure you are using the correct driver version for your
current kernel version. If you are using a standard installation of your distribution, you
find that only one subdirectory should appear in the /lib/modules directory. If
you have upgraded or compiled your kernel, you might find more than one directory.

If you want to see a driver's description without having to load the driver itself,
use the modinfo command. For example, to see the description of the yellowfin.ko
driver, type the:

```
[rootserver]# modinfo yellowfin -i description
```

Keep in mind that not all drivers have descriptions associated with them, but most do.
