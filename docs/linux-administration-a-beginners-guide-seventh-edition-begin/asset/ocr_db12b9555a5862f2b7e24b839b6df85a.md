For example, to set up a 5GB tmpfs file system under the /home/mytemps directory (mount point), first create the mount point (if it doesn’t already exist) like so:

```
# mkdir /home/mytmpfs
```

Then, set up your tmpfs instance:

```
# mount -t tmpfs -o size=5G tmpfs /home/mytmpfs
```

That’s it!
