# Configuring the Client

Configuring a system to use an LDAP directory for user authentication is as easy as pie on Fedora or RHEL system. Fedora has command-line utilities as well as GUI tools (for example, system-configuration, authconfig, authconfig-gtk) that make it easy.

+   1. One of the command-line tools is provided by the package authconfig. Make sure the package is installed by running the following:
```bash
root[client ~]# dnf -y install authconfig
```

+   2. To launch the tool from the command line, type the following:
```bash
root[client ~]# authconfig-tui
```
