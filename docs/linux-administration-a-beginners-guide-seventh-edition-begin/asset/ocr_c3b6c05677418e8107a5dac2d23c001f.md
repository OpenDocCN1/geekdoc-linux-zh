# CHAPTER 6 Booting and Shut Down

Using any text editor you are comfortable with (the vim editor is used in this example), type the following text in the file:

```
#!/bin/sh -e
echo "Starting new GRUB2 script creation..."
cat << EOF
menuentry "Change Background Color" {
    set color_normal=white/green
}
EOF
```

+   Once the script has been successfully created, the script executable:
fedora-server:- # chmod +X 99_custom.sh

+   Run grub2-mkconfig, which will parse the command in the new script you just created and create an appropriate updated /boot/grub2/grub2.cfg configuration file:
fedora-server:- # grub2-mkconfig -o /boot/grub2/grub.cfg

+   Use the grep command to verify that the new menuentry was added to grub.cfg:
fora-server:- # grep -A 4 "99_custom.sh" /etc/grub2/grub2/grub.cfg
### BEGIN /etc/grub2/99_custom.sh ###
Starting new GRUB2 script creation...
mententry "Change Background Color" {
    set color_normal=white=green
}
### END /etc/grub2/99_custom.sh ###

+   Once you've confirmed the entry is in the grub.cfg file, reboot the system.

When the system reboots, you can test your changes by following the next steps while at the initial GRUB screen:

+   After the GRUB menu appears, select the Change Background Color option and press ENTER.

+   The color of the menu should change to the color specified in the 99_custom.sh file using the color_normal directive. Note that selection will not actually boot the system. You will have to select a proper menuentry to boot the operating system into Linux.
