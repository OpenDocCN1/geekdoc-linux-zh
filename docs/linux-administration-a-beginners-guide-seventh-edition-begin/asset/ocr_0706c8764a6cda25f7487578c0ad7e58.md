# 668 Linux Administration: A Beginner's Guide

On Debian-based distros such as Ubuntu, the NIS client and server components are provided by a single package, apt name nis\*.dpkg. To set up an Ubuntu system as a NIS client, we can install the nis package using apt-get like so:

```
root@ubuntu-client:~ apt-get install nis
```

The installer on the Ubuntu distro will help bring up an initial NIS configuration screen as part of the install process, which will allow you to configure the NIS domain name of the system.

# Editing the /etc/yp.conf File

The /etc/yp.conf file contains the information for the client-side daemon, ybind, to start and find the NIS server. You need to make a decision regarding how the client is to find the server—either by a broadcast or by specifying the hostname of the server.

The broadcast technique is appropriate when you need to move a client around to various subsets and you don't have to reconfigure the client so long as an NIS server exists in the same subnet. The downside of this technique, is, that you must make sure there is an NIS server in every subnet.

> When you use the broadcast method, you must have an NIS server in every subnet, because routers will not forward broadcast traffic—that is, broadcasts do not span subnets. If you are uncertain whether a particular NIS server is in the same subnet, you can find it by ping the broadcast address. You should be aware that some systems have enabled protection against smurf attacks and so may not respond to broadcast pings—you may need to disable protection temporarily to test. If the NIS server is one of the hosts that responds, you know for sure that the broadcast method will work.

The other technique for client-server contact is to specify the hostname of the server. This method works well when your network is divided into subsets but you don't/want an NIS server in every subnet. This allows a client to move anywhere inside your network and still be able to find the NIS server. However, if you need to change a so that it points to another NIS server (to balance the network load, example), you'll need to change yourself.

Following is syntax for the two methods for the client to find the server:

+   Broadcast method If you choose the broadcast technique, edit the /etc/yp.conf file on the client so that it reads follows:

```
domain nis.example.org broadcast
```

Here, nis.example.org is the name of your NIS domain. Remember that if you need failover support, you will need to have two NIS servers in every subnet in order for broadcast to find the second server.
