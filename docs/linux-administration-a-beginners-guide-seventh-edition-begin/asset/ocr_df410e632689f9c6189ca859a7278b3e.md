Let's walk through installing a more complex package to see how dependencies are handled with RPM. Assuming you are still in the directory with all the working files for this chapter (or the Package directory of the DVD media), do the following:

+   1. Install the gcc package by typing the following:

```
[fedora-server chapter-04]# rpm -ivh gcc-*.rpm
error: Failed dependencies:
binutils >= 2.* is needed by gcc-5.*_x86_64
cpp = 5.* is needed by gcc-5.*_x86_64
gibc-devel >= 2* is needed by gcc-5.*_x86_64
isl = 2* is needed by gcc-5.*_x86_64
libmpc.so.3 (64bit) is needed by gcc-5.*_x86_64
mpfr.so.4 (64bit) is needed by gcc-5.*_x86_64
```

The output does not look good. It tells us that gcc-5.* depends on (needs) some other packages and libraries: binutils, cpp, glibc-devel, isl, libmpc, and libmpfr (provided by mpfr*).

+   2. Fortunately, because we have access to the specified packages in a single directory, we can install the additional packages to our install list like so:

```
[fedora-server chapter-04]# rpm -ivh \
ngcc-* binutils-* cpp-* glibc-devel-* isl-* libmpc-* mpfr-*\
error: Failed dependencies:
gibc-headers is needed by glibc-devel-*\ngibc-headers = 2* is needed by glibc-devel-*
```

Uh-oh. It looks like this particular is not going to be easy to move. The output tells us that the glibc-devel* depends on another package, called glibc-headers-*.

+   3. Add the new dependency to the install list:

```
[fedora-server chapter-04]# rpm -ivh \
gcc-* binutils-* cpp-* \
glibc-devel-* isl-* libmpc-* mpfr-* glibc-headers-*\
error: Failed dependencies:
kernel-headers is needed by glibc-headers-*\nkernel-headers >= 2* is needed by glibc-headers-*
```
