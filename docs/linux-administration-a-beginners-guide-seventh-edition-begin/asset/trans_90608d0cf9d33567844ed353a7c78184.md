## 第 26 章 | 网络信息服务 (NIS)

## Linux 系统管理：入门指南

网络信息服务 (NIS) 促进了网络上存储在平直文件系统中的关键数据共享。在管理由许多系统/主机组成的网络时，理想情况是有一个公共存储库（如 NIS），用于存储传统的存储在 /etc/passwd 和 /etc/group 等平直文件中的用户和组信息。通过 NIS 提供此类文件，可以从远程访问或查询这些共享文件中所包含的数据，并将这些文件的网络版本作为本地系统的扩展。NIS 不局限于共享两个文件。事实上，任何至少有一列在整个文件中具有唯一值的表格文件都可以通过 NIS 共享。此类文件在 Linux/Unix 系统中很常见，例如 Sendmail 别名文件、Automunter 文件和 /etc/services 文件。

使用 NIS 的用处是你可以维护数据的中心副本，每当数据更新时，它会自动传播到所有网络用户。对于你的用户来说，NIS 的功能有助于让系统看起来更加统一——无论他们可能正在哪一台系统上工作。

如果你有 Windows 背景，你可能会将 NIS 视为针对 Active Directory 提供的所有服务的 Linux/Unix 解决方案。当然，NIS 是一项老老的技术，因此它并不试图解决（创建）Active Directory 应对的众多问题。
