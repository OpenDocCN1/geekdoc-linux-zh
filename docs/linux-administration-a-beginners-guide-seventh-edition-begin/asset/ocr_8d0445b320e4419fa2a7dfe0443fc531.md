# 672 Linux Administration: A Beginner's Guide

openSUSE Linux has some nice GUI tools that can aid in configuring both the NIS server and the NIS client. The GUI server configuration tool is shown here:

![](bbox=[0.156, 0.166, 0.842, 0.466])

To launch this tool in a graphical desktop environment, type the following:

```
opensuse-server-A:~ ~ # yast2 nis_server
```

Or if you want to launch the text-based version of the tool:

```
opensuse-server-A:~ ~ # yast_nis_server
```

To launch the NIS client configuration tool in openSUSE, type this as:

```
opensuse-server-A:~ ~ # yast_nis
```
