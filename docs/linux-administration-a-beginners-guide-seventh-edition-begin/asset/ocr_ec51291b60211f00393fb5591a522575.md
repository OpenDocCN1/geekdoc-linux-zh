+   8. We want to set "type" or "flag" of the newly created partition to be svm.
To do this, we use the set command within parted. The following command
at the (parted) prompt to enable the lvm flag on the new partition 3.
PRESS ENTER when done.

```
(parted) set 3 lvm on
```

> TIP You can learn about the proper syntax and the meaning of the various
options and sub-command of parted at the parted by typing help
<sub-command>. For example, to learn more about the usage and options for the
command, you would type:
(parted) help set

+   9. Check the changes you've made by viewing the partition table. Type print:
