> NOTE If you decide to use the original optical media (CD/DVD) that contains the
Fedora operating system as the source for the packages, remember that the media
needs to be mounted before the system can access its contents.
If you are logged into the system via a GUI and want a CD/DVD, insert it
into the drive and launch a console. An icon for the CD/DVD should automatically show
u in the default file manager.

The RPM files are stored in the Packages directory under the mount point of
y CD/DVD. For example, if your Fedora DVD is mounted under the /media/
dvd dvd, the path to the Packages folder is /media/dvd/dvd/Packages/
packages are further organized alphabetically into folders based on the first letter of
package.

If, on the other hand, you are not logged into the system via a GUI, you can quickly
mount your optical media (after making sure that the target mount folder exists) from
the command line by:

```
# /dev/sr0 /media/dvd/
```

To follow the next example using the OS installation media, substitute the relevant
parts of the instruction with the local mount point for your OS installation media.
