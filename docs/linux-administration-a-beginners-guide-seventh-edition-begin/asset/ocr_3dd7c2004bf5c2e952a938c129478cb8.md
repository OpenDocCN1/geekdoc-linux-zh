# CHAPTER 26 Network Information Service (NIS) 669

**Server hostname method** If you want to specify the name of the NIS server directly, edit the /etc/nis.conf file so that it reads as:

```
domain nis.example.org server server-A
```

Here, **nis.example.org** is the name of our sample NIS domain, and **server-A** is the name of the NIS server to we want to client refer.

> NOTE Remember that you also need to have an entry for **server-A** in the /etc/hosts file. At the time NIS is started, you might not have access to DNS, and you most certainly not have access to the NIS hosts table yet! For this, the client must be able to do the hostname-to-Internet Protocol (IP) resolution without the aid of any other services.

# Enabling and Starting ybind

The NIS client runs a daemon called ybind to communicate with the server. Traditionally, this can be started via the /etc/init.d/ybind startup script, but on systemd-enabled distros, you can use the systemctl utility to start ybind as well as to ensure that ybind starts automatically at the desired levels.

The following shows the steps to control ybind and manage its startup scripts:

+   1. To start the daemon without rebooting, use this command:
```
[@root-client-A ~]# systemctl start ybind
```
2. If you need to stop the daemon, type this:
```
[@root-client-A ~]# systemctl stop ybind
```
3. On a systemd-enabled distro such as Fedora, you can alternatively use the systemctl utility to manage the ybind service automatically up at the next system boot:
```
[@fedora-client-A ~]# systemctl enable ybind.service
```

On older versions of Debian-Linux distros that are not system enabled, the ybind service can be managed using the service utility. For example, to start the ybind service, run the following command:

```
master@ubuntu-client-A:-$ sudo service ybind start
```

# Editing the /etc/nsswitch.conf File

The /etc/nsswitch.conf file is responsible for telling the system the order in which it should search for specific information. The format of the file is as follows:

```
filename: servicename
```
