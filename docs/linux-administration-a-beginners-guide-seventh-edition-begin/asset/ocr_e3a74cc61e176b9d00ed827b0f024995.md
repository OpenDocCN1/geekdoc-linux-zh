# CHAPTER 6 Booting and Shutting Down

4. Copy or move the script to the directory where startup scripts are stored—the
/etc/init.d/ directory:

```
[root@fedora-server ~]# mv -f carpal /etc/init.d/
```

5. Now you need to tell chconfig about the existence of this new start/stop script
and what you want to do with it:

```
[root@fedora-server ~]# chconfig --add carpal
```

This will automatically create some of the symbolic links listed here:
lrwxrxrwx. 1 root 17 Dec 15 11:58 K10carpal -> .../init.d/carpal
lrwxrxrwx. 1 root 17 Dec 15 11:58 899carpal -> .../init.d/carpal
lrwxrxrwx. 1 root 17 Dec 15 11:58 KOcarpal -> .../init.d/carpal
lrwxrxrwx. 1 root 17 Dec 15 11:58 899carpal -> .../init.d/carpal

(The meaning and significance of the K (kill) and S (start) prefixes in this listing
explained earlier).
This might appear rather elaborate, but the good news is that because you've
set up this rc script, you've never ever to do it again. More important, the script
will automatically run during startup and shutdown and is able to manage itself.\ overhead is well worth the long-term benefits of avoiding carpal tunnel
syndrome:

We have set up the "nuts and bolts" around the carpal infrastructure, but it's not
fully useful until we get to run it. We'll use the service command to start
da daemon and manage it going forward:

+   1. Use the service command to find out the status of the carpal.sh program:

```
[root@fedora-server ~]# service carpal status
```

+   2. Manually start the carpal program to make sure that it will indeed start up
correctly upon system startup:

```
[root@fedora-server ~]# service carpal start
```
