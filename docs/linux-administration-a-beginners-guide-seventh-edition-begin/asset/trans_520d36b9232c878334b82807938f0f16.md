# DNS 服务器设置详解

为了实现为 example.org 设置 DNS 服务器的目标，我们需要执行一系列步骤。让我们逐一查看这些步骤。

> 提示 如果你不想打太多字，我们已经将你需要遵循并保存的文件打包在一起，并保存在以下 URL 中。你只需要下载、解压缩并将文件复制到步骤中的相应目录中即可，例如：
```bash
# pwd
# wget http://linuxserverexperts.com/7e/chapter-16.tar.xz
# tar xvf chapter-16.tar.xz
# cd chapter-16 && ls
```

1. 1. 确保你已经按照本章早前的描述安装了 BIND 服务器软件。使用 `rpm` 命令确认：
```bash
[root@serverA ~]# rpm -q bind bind-9.*
```

> 注意 如果你只是从源码编译并安装了 BIND，那么前面的 `rpm` 命令将不会显示任何内容，因为 RPM 数据库对它一无所知。但你应该清楚自己安装了什么以及安装在哪里。

2. 2. 使用你熟悉的任何文本编辑器创建主 DNS 配置文件——/etc/named.conf 文件。在文件中输入以下文本：
```
options {
    listen-on port 53 { any };
    listen-on-v6 port 53 { any };
    directory "/var/named";
    dump-file "/var/named/data/cache_dump.db";
    statistics-file "/var/named/data/named_stats.txt";
    notify yes;
}
```

# 第 16 章 域名系统 (DNS) 445

# 以下的区域定义不需要任何修改。第一个
# 是根域名服务器的定义，并将我们的服务器配置为
# 具有缓存能力的 DNS 服务器。
# 第二个定义了 localhost。
# 第三个区域定义定义了 localhost 的反向查找。

```
zone "." in {
    type hint;
    file "root.hints";
}
zone "localhost" in {
    type master;
    file "localhost.db";
}
zone "0.0.127.in-addr.arpa" in {
    type master;
    file "127.0.0.rev";
}
```

# 下方的区域定义是用于我们我们的名称服务器具有
# 权威性的域，即 example.org 域名。
zone "example.org" {
    type master;
    file "example.org.db";
}

# 下方是 in-addr.arpa 域的区域，用于 example.org 站点。
zone "1.168.192.in-addr.arpa" {
    type master;
    file "example.org.rev";
}

# 下方是该服务器作为从服务器的子域区域
# sales.example.org 主服务器的 IP 地址是 192.168.1.2
zone "sales.example.org" {
    type slave;
    file "sales.example.org.bk";
    masters "192.168.1.2";
}

# 下方是用于 example.org 站点的 ip6 arpa 域区域。
# 该区域将将其数据存储与
# 1.168.192.in-addr.arpa 相同的文件中
zone "0.0.0.0.0.0.0.0.b.d.0.1.0.2.ip6.arpa" {
    type master;
    file "example.org.rev";
}
```

3. 3. 将文件保存为 /etc/named.conf 并退出文本编辑器。

4. 4. 接下来我们需要创建 /etc/named.conf 文件引用的实际数据库。具体来说，我们要创建 root.hints、localhost.db、127.0.0.rev、example.org.db 和 example.org.rev。所有文件将存储在 BIND 的工作目录 /var/named/ 中。我们将从 named.conf 的顶部到尾创建它们。

5. 5. 老实说，我们不需要手动创建根提示。使用 `wget` 命令从互联网下载根提示的最新副本并将其复制到相应的目录：
```bash
# wget -o /var/named/root http://www.intern.net/zones/root
```

6. 6. 使用你熟悉的任何文本编辑器创建 localhost 的区域文件。这就是 localhost.db 文件。在文件中输入以下文本：
```
$TTL 1W
localhost (
               @ IN SOA
               20061310 ; serial
               3H ; refresh (hours)
               30M ; retry (minutes)
               2W ; expiry (weeks)
               1W ; minimum
               IN NS @
               IN A 127.0.0
```

7. 7. 将前面的文件保存为 /var/named/localhost.db 并退出编辑器。

8. 8. 使用任何编辑器创建反向查找主机的区域文件。这就是 127.0.0.rev 文件。在文件中输入以下文本：
```
$TTL 1W
@ IN SOA localhost. (
               20061310 ; serial
               3H ; refresh
               30M ; retry
               2W ; expiry
               1W ; minimum
               IN NS @
               IN PTR
```
> BIND 的值可能意味着：3H 是小时，2W 是周，30M 是分钟。
> 这里的 0.0.0.0.0.0 [此处省略] 0.0.0.0 
。

9. 9. 将前面的文件保存为 /var/named/127.0.0.rev 并退出编辑器。

10. 10. 接下来我们需要创建 /etc/named.conf 文件引用的实际数据库。具体来说，我们要创建 example.org.db 和 example.org.rev。在文件中输入以下文本：
```
$TTL 1W
example.org (
               20061310 ; serial
               3H ; refresh
               30M ; retry
               2W ; expiry
               1W ; minimum
               IN NS @
               IN A 127.0.0
```
> 127.0.0 
。

11. 11. 将文件保存为 /var/named/example.org.db 并退出编辑器。

12. 12. 为 example.org 站点创建反向查找区域。使用编辑器创建 /var/named/example.org.rev 文件，并输入以下文本：
```
$TTL 1W
@ IN SOA example.org. (
               20061310 ; serial
               3H ; refresh
               30M ; retry
               2W ; expiry
               1W ; minimum
               IN NS @
               IN A 127.0.0
```
> 127.0.0 
。
