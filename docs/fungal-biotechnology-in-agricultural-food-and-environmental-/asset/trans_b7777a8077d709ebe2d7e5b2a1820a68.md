
# 5 生物控制的分子起源

源自坏死性菌祖先，目前大多数木霉菌菌株已经进化出了极其有效的机制，以便在根际、土壤和腐烂木材等含有担子植物的环境中生存并定殖。在宿主真菌上活跃时，菌丝穿透是研究最广泛的（参见 Chet 等人，1999），这需要如菌丝吸着器的形成和卷曲等形态变化，并受到细胞外酶和抗真菌抗生素的支持。这种机制主要在实验室中被观察到，并应用于木霉菌的应用。

在这些过程中，真菌寄生是唯一已在分子水平上进行研究的过程。Herrera 和 Chet（第 57 章）对此进行了详述，我在此仅简要提及这一点：大部分注意力并未没有放在真菌细胞壁的降解上，而是关注细胞结构、几丁糖-β-1-葡萄糖苷酶、蛋白质和 N-乙氨基葡萄糖酶，以及内切型 β-1,3-葡聚糖酶、内切型 β-1,6-葡聚糖酶、木糖酶、淀粉酶、脂肪酶、RN 酶和 DN 酶已从多种木霉菌菌株中克隆出来（Bertz 等人，1998；Kubick 等人，2001；Long 1998）。这些酶在体外对多种病原真菌表现出强拮抗活性。这些细胞壁降解酶已被证明在制剂或转基因植物中具有巨大潜力。

几丁糖酶和聚糖酶的作用通常与其他几丁糖成分以及生物控制中的挥发性成分协同作用（参见 Jat 等人，1995；Harman 1994；Søberg 等人）。在这种情况下，这种酶-几丁糖的协同机制已被证明对维持木霉菌的细胞壁完整性具有协同效应。

木霉菌中的纤维素结合域源自纤维二养糖水解酶 II。嵌合几丁糖酶与天然几丁糖酶具有相似活性，具有溶性底物，但在不溶性底物（几丁糖或真菌壁）上具有更高的水解活性。遗憾的是，体外实验结果，尚不清楚此类域是否会提高木霉菌菌株的拮抗能力。

肽（Peptols）是 12-22 个氨基酸组成的线性多肽，从 N-乙酰基开始，在 C 端结束，并在应用时在脂质膜中形成水门控离子通道并增加膜的渗透性（Chen 等人，1989）。然而，当几丁糖酶降低细胞壁屏障时，肽会抑制合成并限制修复酶作用的能力。

有趣的是，属于第一类（V 类）的木霉几丁糖酶已从 Neointra（1994）克隆。它们显示出模块化结构，通常包含结合几丁糖的蛋白域，这与木霉细胞中的纤维素结合域相似。相反，从木霉物种中克隆的酶已显示含有几丁糖结合域。为了研究该域的作用，Limon 等人（2001）产生了具有强几丁糖结合能力的杂化几丁糖酶。

肽并非在宿主细胞壁降解中发挥作用的唯一二次代谢产物。其他成分（例如“吡咯”）也被发现对体外拮抗非常重要（Claydon 等人，1987；Howell 1998；Serrano 等人，1993），其作用机制已得到阐明。在这些代谢产物中，6-甲基吡咯表现出明显的香气，可作为（人类）神经毒性调味剂。其生物合成据称来源于亚油酸（Serrano-Carrion 等人，1993），这一结论得到了 Sivasamtham 和 Ghisabarti（1998）的证实，他们认为它是聚酮合成的产物。其他从细胞壁释放的低分子量生物控制诱导分子尚未被描述，它们在纯化的几丁糖或葡聚糖单体中活性更高。

# 木霉菌特异性基因表达

T. atviride 诱导 ech42 基因失败可能是由于调节回路内复杂的相互作用（Donzelli 和 Harman 2001）；ech42 均需要氮饥饿和几丁糖的存在，而 gluc7 仅由氮饥饿诱导。在存在铵（100 mM）的情况下，几丁糖聚糖和几丁糖均触发了 CHIT42 和 CHIT40（几丁糖酶的产生）；CHIT33 在 N-乙酰纤维素和几丁糖聚糖存在时表达较少。这表明木霉菌中细胞壁降解酶的表达受碳氮相互作用的调节。

在实验室中，细胞外细胞壁裂酶的高诱导通常通过将木霉菌生长在纯几丁糖、真菌细胞壁或作为碳源上获得。
