Despite this, some worries remain when you use Copilot. Duplicate detection only works if the code snippet exists in a public GitHub repository, is at least 150 characters in length, and the developer is working with Visual Studio Code. In the small print, GitHub points out that you must always check for yourself whether Copilot’s proposals infringe on the rights of other parties. In the case of active duplicate detection, GitHub at least promises support for Copilot users who are accused of copyright infringement. GitHub does not specify how far this help extends.

Even given a check like this, there is always the question of the license under which the generated code proposal is registered. GitHub itself explicitly makes no copyright claims to the code generated by Copilot; other providers are tacit on the subject. This and all the other problems do not exactly speak in favor of using AI wizards. On the upside, the wizards are still useful for some specific tasks.

# Documentation

Many developers see the documentation of their source code as a pesky chore. But this is a task that the AI wizards carry out with astonishing accuracy. All programmers have to do is ask Codeium, Refraction, and the like to explain a function and the AI will provide a

comment with a short, appropriate, natural-language description (Figure 6). Like many other candidates, the AI developed by JetBrains [9] for its IDEs also automatically writes commit texts. Although all the AI-generated texts still require a little re-work, as many developers confirm, the generated comments substantially speed up the documentation work.

You can also ask AI wizards to explain existing code to you (Figure 7). In this way, you can quickly find out what the function (written by a former member of staff who long since left the company) actually does.
