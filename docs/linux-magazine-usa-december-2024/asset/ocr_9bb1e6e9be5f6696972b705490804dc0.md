# LibreQuake

![](bbox=[0.4, 0.08, 0.91, 0.31])

T here are few gamers who haven't played id Software's 1996 sequel to the first-person shooter Doom. Such was Quake's popularity that the developers open sourced the game engine in 1997 under the terms of GPLv2. This allowed the gaming community to refine the code and add new features. Forks appeared pretty much immediately. As with Doom, however, the game assets were still proprietary so someone would still need to legally purchase the original game files to take advantage of any open source engine. Retro gamers will be familiar with how the community squared this particular circle with the Freedoom project. This involved releasing new IWAD (level) files containing third-party graphics, music, and sound effects. This effectively created an entirely free game provided it's played using an open source engine like Chocolate Doom.

LibreQuake has similar aspirations. Since 2019 the developers have focused on developing a free software drop-in replacement for Quake 1. Sadly it's not as mature as Freedoom, given the latest version (0.07) is still in beta. Like Freedoom, the project focuses on raw data, and a compatible engine is required for play. The GitHub page contains both the full version of all playable level files, as well as a mod archive sufficient to get LibreQuake working on most modern source ports.

I followed the site recommendation and installed the open source engine QuakeSpasm, which from what I gleaned on Reddit is best for a hassle-free vanilla play. The version of the engine in the Ubuntu Snap store failed to launch, but I had no trouble installing it from the repositories via the terminal. Launching the game was as simple as extracting the full LibreQuake archive, using cd to navigate to the directory and then running quakespasm -f. The engine automatically found the id1 folder to load levels and assets.

As I was browsing the Quake subreddit, I came across a poster who described LibreQuake as "not quite Quake but feels pretty right." This is clearly something on the developers' minds, given the main website has a very lengthy licensing section cautioning creators not to simply imitate real Quake assets to avoid copyright infringement. On first launch, the game presents a Start portal that leads to a choice of different "episodes." Upon entering the portal, the game acts as if you have completed a level displaying scores. You need to tap the space bar to load the level in question. The end result is something of a mixed bag: Level layout itself is well designed and the wall textures are just so. WASD movement worked effortlessly and items I picked up were added instantly to the inventory.

LibreQuake really falls down though when it comes to enemies. Admittedly I only played Episode 2 in any depth. Still, the first bad guys I encountered were somewhat jerky. I wasn't quite sure what to make of the second enemy, which seemed to resemble a rainbow-colored troll, it nonetheless dealt a great deal of damage from launching some kind of explosive at my head. Currently there's also no in-game music, though I noted QuakeSpasm can play external files.
