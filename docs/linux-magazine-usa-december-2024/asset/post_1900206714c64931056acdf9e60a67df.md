## Plugin for SSH

The plugin I built for this follows the previously used pattern.

It also comes with a constructor in line 18 which returns an empty GMFGithubUser type structure to the caller. The Applicable() interface function starting in line 22 examines the entry's type field and volunteers to take care of the entry if it finds the `github-user-repos` string there. Later, Expand(), starting in line 26, calls the `githubProjectsOfUser()` helper function from line 39 to contact the GitHub API and lists the specified user's repositories in JSON format.

As you can see from Figure 1, what is returned in JSON is a jumble of data that lists all of the user's repositories with all kinds of parameters, such as whether it is a fork of another project. Because the cloning tool is only interested in original repositories, line 57 discards all forks. Finally, Expand() returns a list of Clonable structures to the main program.

The plugin for Git repositories located in a specific directory on a host accessible via SSH is shown in Listing 6. It also checks the type specified in YAML within Applicable(). If it matches, it calls the helper function `sshGitDirs()` from line 39 in Expand()

```go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

type Repository struct {
    Name    string `json:"name"`
    Fork    bool   `json:"fork"`
    SSHURL  string `json:"ssh_url"`
    HTMLURL string `json:"html_url"`
}

type GMFGithubUser struct{}

func NewGMFGithubUser() GMFGithubUser {
    return GMFGithubUser{}
}

func (g GMFGithubUser) Applicable(e GitMetaEntry) bool {
    return e.Type == "github-user-repos"
}

func (g GMFGithubUser) Expand(e GitMetaEntry) ([][]Clonable, error) {
    clones := [][]Clonable{}
    res, err := githubProjectsOfUser(e.User)
    if err != nil {
        return clones, err
    }

    for _, repo := range res {
        clones = append(clones, Clonable{URL: repo.SSHURL, Dir: repo.Name})
    }
    return clones, nil
}

func githubProjectsOfUser(user string) ([][]Repository, error) {
    results := [][]Repository{}
    url := "https://api.github.com/users/" + user + "/repos"
    resp, err := http.Get(url)
    if err != nil {
        return results, err
    }
    defer resp.Body.Close()

    if resp.StatusCode != http.StatusOK {
        return results, fmt.Errorf("Status %s", resp.Status)
    }
    var repos [][]Repository
    if err := json.NewDecoder(resp.Body).Decode(&repos); err != nil {
        return results, err
    }
    for _, repo := range repos {
        if !repo.Fork {
            results = append(results, repo)
        }
    }
    return results, err
}
```

## Listing 6: gmf-ssh.go

```go
package main

import (
    "bufio"
    "bytes"
    "fmt"
    "os/exec"
    "strings"
)

type GMFSSH struct{}

func NewGMFSSH() GMFSSH {
    return GMFSSH{}
}

func (g GMFSSH) Applicable(e GitMetaEntry) bool {
    return e.Type == "ssh-user-repos"
}

func (g GMFSSH) Expand(e GitMetaEntry) ([][]Clonable, error) {
    clones := [][]Clonable{}
    res, err := sshGetDirs(e.Host, e.Path)
    if err != nil {
        return clones, err
    }

    for _, dir := range res {
        lDir := strings.TrimSuffix(dir, ".git")
        clones = append(clones, Clonable{
            URL: fmt.Sprintf("%s:%s", e.Host, e.Path, dir),
            Dir: lDir,
        })
    }

    return clones, nil
}

func sshGetDirs(host string, path string) ([][]string, error) {
    results := [][]string{}
    cmd := exec.Command("ssh", host, "ls", path+"/*/conf|g")
    output, err := cmd.Output()
    if err != nil {
        return results, err
    }

    reader := bytes.NewReader(output)
    scanner := bufio.NewScanner(reader)
    for scanner.Scan() {
        line := scanner.Text()
        parts := strings.Split(line, "/")
        if len(parts) > 2 {
            results = append(results, parts[len(parts)-2])
        }
    }

    return results, err
}
```

## Listing 7: gitmeta.go

```go
package main

import (
    "fmt"
    "os"
    "os/user"
    "path/filepath"
)

func main() {
    if len(os.Args) != 2 {
        panic(fmt.Errorf("usage: %s repos.gmf",
            os.Args[0]))
    }
    cfg := os.Args[1]

    gmf := NewGitmeta()
    f, err := os.Open(cfg)
    if err != nil {
        panic(err)
    }

    gmf.AddGMF(f)

    usr, err := user.Current()
    if err != nil {
        panic(err)
    }

    gitDir := filepath.Join(usr.HomeDir, ".git")
    err = os.Mkdir(gitDir)

    if err != nil {
        panic(err)
    }

    for _, c := range gmf.AllCloneables() {
        err := cloneOrUpdate(c, gitDir)
        if err != nil {
            panic(err)
        }
    }
}
```

## Listing 8: clone.go

```go
package main

import (
    "os"
    "os/exec"
    "path"
)

func cloneOrUpdate(c Clonable, gitPath string) error {
    fullPath := path.Join(gitPath, c.Dir)
    _, err := os.Stat(fullPath)
    if os.IsNotExist(err) {
        cmd := exec.Command("git", "clone", c.URL, fullPath)
        _, err := cmd.CombinedOutput()
        if err != nil {
            return err
        }
    }
    err = os.Chdir(fullPath)
    if err != nil {
        return err
    }

    cmd := exec.Command("git", "pull")
    _, err := cmd.CombinedOutput()
    return err
}
```

Starting with the paths to the config files inside the repositories that have been found, line 53 truncates them to their last two parts and adds this relative directory name to the end of the results string array slice. Back in `Expand()`, line 29 trims the frequently used `.git` suffix to create the name I want the Git cloning tool to use for the local copy. Line 31 then cobbles together the URL for the repository from the hostname, the path, and the repository's directory. The result is a list of `Clonable` structures.

## And ... Action!

The main program in Listing 7 now has to read the name of the GMF file to be processed from the command line in `main()`, open the file, and send it to the parser by calling `AddGMF()`. If successful, a list of `Clonable` structures is returned; the for loop then checks these, starting at line 33, calling `cloneOrUpdate()` from Listing 8 in each case.

This function in turn expects a `Clonable` struct and the path under which all Git clones are stored. Prior to this, the main program has set `gitPath` to the git directory in the current user's home directory; if you want something else, you will need to edit this section.

There are now two options for the actual cloning process: Either the directory with the clone already exists and only needs to be updated with `git pull`. Or it does not yet exist, and `git clone` in line 13 of Listing 8 creates a new local copy of the remote repository.
