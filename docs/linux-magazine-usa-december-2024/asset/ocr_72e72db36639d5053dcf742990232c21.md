# Plugin for SSH

the plugin I built for this, following the previously used pattern.

It also comes with a constructor in line 18 which returns an empty GMFGithubUser type structure to the caller. The Applicable() interface function starting in line 22 examines the entry's type field and volunteers to take care of the entry if it finds the github-user-repos string there. Later, Expand(), starting in line 26, calls the githubProjectsOfUser() helper function from line 39 to contact the GitHub API and lists the specified user's repositories in JSON format.

As you can see from Figure 1, what is returned in JSON is a jumble of data that lists all of the user's repositories with all kinds of parameters, such as whether it is a fork of another project. Because the cloning tool is only interested in original repositories, line 57 discards all forks. Finally, Expand() returns a list of Clonable structures to the main program.

The plugin for Git repositories located in a specific directory on a host accessible via ssh is shown in Listing 6. It also checks the type specified in YAML within Applicable(). If it matches, it calls the helper function sshGitDirs() from line 39 in Expand()

01 package main
02
03 import (
04 "encoding/json"
05 "fmt"
06 "net/http"
07 )
08
09 type Repository struct {
10 Name string `json:"name"`
11 Fork bool `json:"fork"`
12 SSHURL string `json:"ssh_url"`
13 HTMLURL string `json:"html_url"`
14 }
15
16 type GMFGithubUser struct {}
17
18 func NewGMFGithubUser() GMFGithubUser {
19 return GMFGithubUser{}
20 }
21
22 func (g GMFGithubUser) Applicable(e GitMetaEntry) bool {
23 return e.Type == "github-user-repos"
24 }
25
26 func (g GMFGithubUser) Expand(e GitMetaEntry) ([][]Clonable, error) {
27 clones := [][]Clonable{}
28 res, err := githubProjectsOfUser(e.User)
29 if err != nil {
30 return clones, err
31 }
32
33 for _, repo := range res {
34 clones = append(clones, Clonable{URL: repo.SSHURL, Dir: repo.Name})
35 }
36 return clones, nil
37 }
38
39 func githubProjectsOfUser(user string) ([][]Repository, error) {
40 results := [][]Repository{}
41 url :=
42 "https://api.github.com/users/" + user + "/repos"
43 resp, err := http.Get(url)
44 if err != nil {
45 return results, err
46 }
47 defer resp.Body.Close()
48
49 if resp.StatusCode != http.StatusOK {
50 return results, fmt.Errorf("Status %s", resp.Status)
51 }
52 var repos [][]Repository
53 if err :=
54 json.NewDecoder(resp.Body).Decode(&repos); err != nil {
55 return results, err
56 }
57 for _, repo := range repos {
58 if !repo.Fork {
59 results = append(results, repo)
60 }
61 }
62 return results, err
63 }
