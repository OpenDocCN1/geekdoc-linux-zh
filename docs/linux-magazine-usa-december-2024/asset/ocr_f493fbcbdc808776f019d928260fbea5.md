# And ... Action!

The main program in Listing 7 now has to read the name of the GMF file to be processed from the command line in `main()`, open the file, and send it to the parser by calling `AddGMF()`. If successful, a list of `Cloneable` structures is returned; the for loop then checks these, starting at line 33, calling `cloneOrUpdate()` from Listing 8 in each case.

This function in turn expects a `Cloneable` struct and the path under which all Git clones are stored. Prior to this, the main program has set `gitPath` to the git directory in the current user's home directory; if you want something else, you will need edit this section.

There are now two options for the actual cloning process: Either the directory with the clone already exists and only needs to be updated with `git pull`. Or it does not yet exist, and `git clone` in line 13 of Listing 8 creates a new local copy of the remote repository.
