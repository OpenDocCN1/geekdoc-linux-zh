* `CRC32(str)`

Computes a cyclic redundancy check value from the argument, which is treated as a string. The return value is a 32-bit unsigned value in the range from 0 to $2^{32}-1$, or `NULL` if the argument is `NULL`.

+   * `CRC32('xyz')` $\rightarrow$ `3951999591`
+   * `CRC32('0')` $\rightarrow$ `4108050209`
+   * `CRC32(0)` $\rightarrow$ `4108050209`
+   * `CRC32(NULL)` $\rightarrow$ `NULL`

* `DEGREES(x)`

Returns the value of $x$, converted from radians to degrees.

+   * `DEGREES(PI())` $\rightarrow$ `180`
+   * `DEGREES(PI()*2)` $\rightarrow$ `360`
+   * `DEGREES(PI()/2)` $\rightarrow$ `90`
+   * `DEGREES(-PI())` $\rightarrow$ `-180`

* `EXP(x)`

Returns $e^x$, where $e$ is the base of natural logarithms.

+   * `EXP(1)` $\rightarrow$ `2.718281828459`
+   * `EXP(2)` $\rightarrow$ `7.3890560989307`
+   * `EXP(-1)` $\rightarrow$ `0.36787944117144`
+   * `1/EXP(1)` $\rightarrow$ `0.36787944117144`

* `FLOOR(x)`

Returns the largest integer not greater than $x$. If the argument has an exact-value numeric type, the return value does, too. Otherwise the return value has a floating-point (approximate-value) type. This is true even though the value has no fractional part.

+   * `FLOOR(3.8)` $\rightarrow$ `3`
+   * `FLOOR(-3.8)` $\rightarrow$ `-4`

* `LN(x)`

This is a synonym for `LOG()`.

* `LOG(x)`

+   * `LOG(b,x)`

The one-argument form of `LOG()` returns the natural (base $e$) logarithm of $x$.

+   * `LOG(0)` $\rightarrow$ `NULL`
+   * `LOG(1)` $\rightarrow$ `0`
+   * `LOG(2)` $\rightarrow$ `0.69314718055995`
+   * `LOG(EXP(1))` $\rightarrow$ `1`
