In this output, the final line displays aggregate values calculated based on all the preceding group summary values.

*WITH ROLLUP* is useful because it provides extra information that you otherwise would have to obtain by running another query. Using a single query is more efficient because the server need not examine the data twice. If the GROUP BY clause names more than one column, *WITH ROLLUP* produces additional super-aggregate lines that contain higher-level summary values.

Summary functions are fun to play with because they're so powerful, but it's easy to get carried away with them. Consider this query:

```
mysql> SELECT
    -> state AS State,
    -> AVG(TIMESTAMPDIFF(YEAR, birth, death)) AS Age
    -> FROM president WHERE death IS NOT NULL
    -> GROUP BY state ORDER BY Age;
```
