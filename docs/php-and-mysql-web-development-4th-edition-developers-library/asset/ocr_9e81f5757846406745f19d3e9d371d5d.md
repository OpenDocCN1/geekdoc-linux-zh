To use the scripts developed in this chapter, you'll need to install them where your Web server can access them. The convention used here is the U.S. Historical League and grade-keeping projects have their own directories called \texttt{ush1} and \texttt{gp} at the top level of the Apache document tree. To set up your Web server that way, you should create those directories now. For a server running on the local host, pages in those two directories will have URLs that begin like this:

\texttt{http://localhost/ush1/...} \texttt{http://localhost/gp/...}

For example, the home pages in each directory can be called \texttt{index.php} and would be accessed as follows:

\texttt{http://localhost/ush1/index.php} \texttt{http://localhost/gp/index.php}

If you have Apache configured to use \texttt{index.php} as the default page for a directory, the following URLs are equivalent in practice to the preceding ones:

\texttt{http://localhost/ush1/} \texttt{http://localhost/gp/}

Remember to change the example URLs throughout this chapter to point to your own Web server host rather than to \texttt{localhost}.

# ## 9.1 PHP Overview

The basic operation of PHP is to interpret a script to produce a Web page that is sent to a client. A PHP script typically contains a mix of HTML and executable code. The HTML is sent literally to the client without modification, whereas the PHP code is executed and replaced by whatever output it produces. Consequently, the client never sees the code; it sees only the resulting HTML page. (The PHP scripts developed in this chapter generate pages that are well-formed as XHTML, not just as HTML. For a brief description of XHTML, see Section 8.4.2.2, \textit{\"Writing Web Output.\"})

When PHP begins reading a file, it simply copies whatever it finds there to the output, under the assumption that the contents of the file represent literal text, such as HTML content. When the PHP interpreter encounters a special opening tag, it switches from text copy mode to PHP code mode and starts interpreting the file as PHP code to be executed. The interpreter switches from code mode back to text mode when it sees another special tag that signals the end of the code. This enables you to mix static text (the HTML part) with dynamically generated results (output from the PHP code part) to produce a page that varies depending on the circumstances under which it is called.
