

`--help` 选项单独使用时仅显示简略的使用说明。若要查看完整的帮助信息，请使用此命令：

```
% `mysql` --verbose --help
```

`mysqld` 还支持标准的 SSL 选项。

请注意，虽然支持 `--socket`，但不支持相应的短选项形式（`-s`）。在 Windows 上，如果服务器支持命名管道连接，`--socket` 将设置管道名称。

在 Unix 上，如果提供了 `-user` 选项，它将指定用于运行服务器的帐户的用户名或数字用户 ID。在这种情况下，服务器启动时会从密码文件中查找该帐户的用户 ID 和组 ID 值，然后将自身的用户 ID 和组 ID 更改为与之匹配。这样，服务器就以与该用户关联的特权运行，而不是以 `root` 特权运行。（必须作为 `root` 启动服务器，`-user` 选项才会生效；否则它无法更改其用户 ID，并且会发出警告。）

## F.12.2 `mysqld` 特定的选项

此处的第一个选项列表描述了一般选项。随后是特定于 Windows、InnoDB 和复制的选项列表。

- `--allow-suspicious-udfs` *(boolean)*

允许服务器加载较旧的用户自定义函数 (UDF)，这些函数可能仅定义了与函数名称对应的符号，而没有定义相关的标准支持例程符号。出于对加载可能并非真正 UDF 的函数的预防措施，默认情况下禁用此功能。该选项在 MySQL 5.0.3 中引入。

- `--ansi`, `-a`

告知服务器对某些类型的语法使用标准 SQL 行为，而不是 MySQL 特定的语法。此选项可用于使服务器更符合标准。

此选项等同于使用具有 `REAL_AS_FLOAT`、`PIPES_AS_CONCAT`、`ANSI_QUOTES`、`IGNORE_SPACE` 和 `ONLY_FULL_GROUP_BY` 模式值的 `--sql-mode` 选项。

- `--basedir=`*dir_name*, `-b` *dir_name*

MySQL 安装目录的路径名。如果其他路径名作为相对路径名给出，则许多其他路径名都会根据此目录进行解析。

- `--big-tables`

允许通过将所有临时结果保存到磁盘（而不是在内存中保留它们）来处理大型结果集。这避免了由于内存不足而无法保存大型结果集而导致的多数“table full”（表满）消息。由于服务器现在会自动根据需要保存结果到磁盘，因此此选项现在已不再必要。

- `--bind-address=ip_addr`

绑定到给定的 IP 地址。通常，mysqld 会绑定到服务器运行所在主机上的默认 IP 地址。如果主机有多个地址，可以使用此选项选择要绑定的其他地址。

- `--bootstrap`

此选项用于首次安装 MySQL 时的安装脚本。

- `--character-set-client-handshake` (*boolean*)

告知服务器使用由客户端提供的字符集信息。此选项默认启用；`--skip-character-set-client-handshake` 会导致忽略该信息，这是 MySQL 4.0 中的行为。该选项在 MySQL 5.0.13 中引入。

- `--character-set-filesystem=charset`

设置 `character_set_filesystem` 系统变量。该选项在 MySQL 5.0.19/5.1.6 中引入。

- `--character-set-server=charset`, `-C charset`

默认服务器字符集。

- `--chroot=dir_name`, `-r dir_name`

运行 MySQL 服务器，以给定目录作为其根目录。有关在 chroot(1) 环境中运行的更多信息，请参阅 chroot(1) Unix 手册页。

- `--collation-server=collation`

默认服务器排序规则。

- `--concurrent-insert` (*boolean*)

启用 MyISAM 表的并发插入。如果 MyISAM 表中间没有空洞，并发插入会在现有行正在被检索时，将新行添加到表的末尾。此选项默认启用。若要禁止并发插入，请使用 `--skip-concurrent-insert`。

- `--core-file`

导致服务器在发生致命错误退出前生成核心文件。

- `--datadir=dir_name`, `-h dir_name`

MySQL 数据目录的路径名。

- `--default-character-set=charset`

此选项已弃用，建议使用 `--character-set-server`。

- `--default-collation=collation`

此选项已弃用，建议使用 `--collation-server`。

- `--default-storage-engine=engine_name`

要使用的默认表存储引擎。*engine_name* 值应为服务器支持的存储引擎之一（如 MyISAM 或 InnoDB）的名称。（该值不区分大小写。）如果未指定此选项，服务器将使用 MyISAM。

- `--default-table-type=engine_name`

此选项已弃用，建议使用 `--default-storage-engine`。

- `--default-time-zone=tz_name`

将服务器的默认时区设置为 *tz_name*。时区值在 12.10.1 节“配置时区支持”中描述。此选项设置 *time_zone* 系统变量，而不是 *system_time_zone*。

- `--delay-key-write=val`

设置服务器处理 MyISAM 文件延迟键写入的模式。*val* 可以是 ON（按表延迟键写入，根据创建表时指定的任何 `DELAY_KEY_WRITE` 值；这是默认设置）、OFF（从不延迟任何 MyISAM 表的键写入）或 ALL（延迟所有 MyISAM 表的键写入）。OFF 和 ALL 强制执行一种策略，无论个别表在创建时是如何定义的。

运行复制从服务器时通常使用 `--delay-key-write=ALL`，通过延迟键写入来提高 MyISAM 表的性能，无论表最初是如何创建的。

- `--des-key-file=file_name`

持有 DES_ENCRYPT() 和 DES_DECRYPT() 函数所用 DES 键的文件名。有关此文件格式的说明，请参阅附录 C 中 DES_ENCRYPT() 的条目。

- `--enable-locking`

此选项已弃用，建议使用 `--external-locking`。

- `--enable-pstack` (*boolean*)

在发生错误时启用符号堆栈打印。

- `--exit-info=[n]*, -T[n]`

导致服务器在终止时生成调试信息。如果在 *-T* 后指定了 *n*，中间不能有任何空格，否则值将不会正确解释。

- `--external-locking` (*boolean*)

为外部锁定（文件系统锁定）在默认情况下关闭外部锁定的系统（如 Linux）上启用外部锁定。

外部锁定存在问题，因为它在某些系统上无法可靠地工作，并且如果仅对只读表的操作（如检查表）有效。（有关更多信息，请参阅 14.1 节“在服务器运行时执行数据库维护”。）

- `--flush`

导致服务器在每次更新后将所有表刷新到磁盘。这降低了在发生崩溃时表损坏的风险，但严重降低了性能。因此，它仅在对系统不稳定时才有用。此选项仅适用于 MyISAM 表。

- `--gdb`

设置有助于使用 `gdb` 进行调试的信号处理程序。

- `--general-log` (boolean)

为 `--log-output` 选项选定的日志目标启用通用日志，如果作为 `--skip-general-log` 给出，则禁用日志。该选项在 MySQL 5.1.12 中引入。

- `--init-connect=str`

客户端连接时要为每个客户端执行的语句。值应为一个或多个 SQL 语句，用分号分隔。这些语句仅对没有 SUPER 特权的客户端执行。

- `--init-file=filename`

启动时要执行的 SQL 语句文件名称。相对文件名从数据目录开始解释。文件应每行包含一条语句。

- `--isam` (boolean)

由于 ISAM 存储引擎在 MySQL 5.0 中已移除，此选项已过时。该选项本身在 5.1.14 中移除。

- `--language=lang_name`, `-L lang_name`

向客户端以指定语言显示错误消息。lang_name 是一个值，如 english 或 german，或者是包含语言文件的目录的完整路径名。

- `--large-pages` (boolean)

启用对大内存页的支持。除非 MySQL 编译时允许此功能，否则此选项不会出现。该选项在 MySQL 5.0.3 中引入。

- `--lc-time-names=locale_name`

lc_time_names 系统变量的区域设置。该选项在 MySQL 5.0.42/5.1.18 中引入。
