GET_FORMAT() returns format strings for each combination of val_type and format_type as shown in the following table.

| val_type | format_type | Format String |
|:--|:--|:--|
| DATE | ‘EUR’ | ‘%d.%m.%Y’ |
| DATE | ‘INTERNAL’ | ‘%Y%m%d’ |
| DATE | ‘ISO’ | ‘%Y-%m-%d’ |
| DATE | ‘JIS’ | ‘%Y-%m-%d’ |
| DATE | ‘USA’ | ‘%m.%d.%Y’ |
| TIME | ‘EUR’ | ‘%H.%i.%s’ |
| TIME | ‘INTERNAL’ | ‘%H%i%s’ |
| TIME | ‘ISO’ | ‘%H:%i:%s’ |
| TIME | ‘JIS’ | ‘%H:%i:%s’ |
| TIME | ‘USA’ | ‘%h:%i:%s %p’ |
| DATETIME | ‘EUR’ | ‘%Y-%m-%d %H.%i.%s’ |
| DATETIME | ‘INTERNAL’ | ‘%Y%m%d%H%i%s’ |
| DATETIME | ‘ISO’ | ‘%Y-%m-%d %H:%i:%s’ |
| DATETIME | ‘JIS’ | ‘%Y-%m-%d %H:%i:%s’ |
| DATETIME | ‘USA’ | ‘%Y-%m-%d %H.%i.%s’ |

Note that the date part of the ‘EUR’ and ‘USA’ format strings for DATETIME differs from the ‘EUR’ and ‘USA’ format strings for DATE.

+   ● HOUR(time)

Returns the numeric value of the hour for the time value time, in the range from 0 to 23.

```
HOUR('12:31:58') → 12
HOUR(123158) → 12
```
