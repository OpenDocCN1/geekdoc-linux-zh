+   • `PDO::FETCH_NUM`
+   Return an array with elements accessed by numeric index.

+   • `PDO::FETCH_OBJ`
+   Return an object with elements accessed as properties.

Parameter-type values:

+   • `PDO::PARAM_BOOL`
+   A boolean parameter.

+   • `PDO::PARAM_INT`
+   An integer parameter.

+   • `PDO::PARAM_NULL`
+   Indicates a SQL NULL value.

+   • `PDO::PARAM_STR`
+   A string parameter.
