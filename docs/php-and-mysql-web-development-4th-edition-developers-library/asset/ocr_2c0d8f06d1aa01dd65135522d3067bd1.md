transaction. That way, the changes either all succeed together, or no changes are all are made to the database. Transaction processing in PDO has this general structure (assuming that exceptions are enabled for PDO errors):

```
```php
try
{
    $dbh->beginTransaction ();      # start the transaction
    # ... perform database operation ...
    $dbh->commit ();                # transaction succeeded
}
catch (PDOException $e)
{
    $dbh->rollback ();             # transaction failed
}
```
