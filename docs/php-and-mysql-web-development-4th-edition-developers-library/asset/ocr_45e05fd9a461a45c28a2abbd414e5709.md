This is much better than trying to infer the score category based on some guess. Instead, we’re deriving the category directly from data recorded explicitly in the database. It’s also preferable to recording score categories in the *score* table; now we need record each category only one time, rather than once per score row.

However, now we’re combining information from multiple tables. If you’re like me, when you first hear about this kind of thing, you think, “Yeah, that’s a cute idea, but isn’t it a lot of work to do all that looking up all the time; doesn’t it just make things more complicated?”
