Install the script in your cgi-bin directory, and then request it from your browser using a URL like this one, but substituting the name of your own Web server for localhost:

http://localhost/cgi-bin/flip_flop.pl

Select the link in the page several times to see how the script alternates the pages that it generates.

Now, suppose that another client comes along and starts requesting flip_flop.pl. What happens? Will the two of you interfere with each other? No, because the initial request from each of you will include no page@ parameter, and the script will respond with its initial page. Thereafter, the requests sent by each of you will include or omit the parameter according to which page you currently happen to be viewing. flip_flop.pl generates an alternating series of pages properly for each client, independent of the actions of any other client.
