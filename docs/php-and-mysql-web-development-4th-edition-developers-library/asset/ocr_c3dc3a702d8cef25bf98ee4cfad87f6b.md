+   array\n*errorInfo* (void)\nThis is similar to *errorInfo*() for PDO objects but applies to operations on PDOStatement objects.\nFor an example, see the description of *errorCode*().

+   bool\n*execute* ([array $params])\nExecutes a prepared statement and returns TRUE for success or FALSE for failure.\nIf the statement contains placeholders, you should either bind data values to them before invoking *execute*(), or else pass the data values as parameters to *execute*().\nFor examples, see the descriptions of *prepare*(), *bindParam*(), and *bindValue*().

+   mixed\n*fetch* ([int $fetch_mode\n[, int $cursor_orientation\n[, int $cursor_offset]]])\nReturns the next row of the result set, or FALSE if there are no more rows. The row is returned in the format determined by the statement fetch handle's fetch mode, or by the $fetch_mode argument if present. The default fetch mode is PDO::FETCH_BOTH unless it has been changed by calling *setFetchMode*() or the statement fetch was obtained by a call to $dbh->query() for which a fetch mode was passed. Section I.3.4, “PDO Constants,” (online) lists some of the allowable fetch modes.\nThe $cursor_orientation and $cursor_offset are used to control scrollable cursors. These two arguments do not apply to MySQL, which does not support scrollable cursors.\n\n```php\n$sth = $dbh->query('SELECT last_name, first_name FROM president');\nwhile ($row = $sth->fetch ())\n    printf ('%s %s\n', $row[1], $row[0]);\n```

+   array\n*fetchAll* ([int $fetch_mode\n[, int $column_index = 0\n[, array $constructor_args]]])\nReturns any remaining rows of the result set as an array of rows. The fetch mode for the rows is determined the same way as for *fetch*().\n\n```php\n$sth = $dbh->query('SELECT last_name, first_name FROM president');\n$rows = $sth->fetchAll ();\nforeach ($rows as $row)\n    printf ('%s %s\n', $row[1], $row[0]);\n```\n\nIf the fetch mode is PDO::FETCH_COLUMN, *fetchAll*() returns an array containing the values from the column of the result set specified by $column_index. Column numbers begin with 0.
