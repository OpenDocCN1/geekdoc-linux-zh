# 1.5.1.3 Using Shell Aliases and Scripts

If your shell provides an alias facility, you can set up a short command name that maps to a long command. For example, in \texttt{csh} or \texttt{tcsh},you can use the \texttt{alias} command to set up an alias named \texttt{samdb} like this:

```
alias samdb='\texttt{mysql} -h cobra.snake.net -p -u sampadm samdb'
```

The syntax for \texttt{bash} is slightly different:

```
alias samdb='\texttt{mysql} -h cobra.snake.net -p -u sampadm samdb'
```

Defining the alias makes the following two commands equivalent:

```
$\%$ \texttt{samdb} \newline $\%$ \texttt{mysql} -h cobra.snake.net -p -u sampadm samdb
```

Clearly, the first is easier to type than the second.To make the alias take effect each time you log in, put the \texttt{alias} command in one of your shell's startup files (for example, .\texttt{tcshrc} for \texttt{tcsh}, or .\texttt{bashrc} or .\texttt{bash\_profile} for \texttt{bash}).

On Windows, a similar technique is to create a shortcut that points to the \texttt{mysql} program, and then edit the shortcut's properties to include the appropriate connection parameters.

Another way to invoke commands with less typing is to create a script that executes \texttt{mysql} for you with the proper options. On Unix, a shell script that is equivalent to the \texttt{samdb} alias just shown looks like this:

```
#!/bin/sh\nexec \texttt{mysql} -h cobra.snake.net -p -u sampadm samdb
```

If you name the script \texttt{samdb} and make it executable (with \texttt{chmod +x samdb}), you can type \texttt{samdb} at the command prompt to run \texttt{mysql} and connect to the \texttt{samdb} database.

On Windows, a batch file can be used to do the same thing. Name the file \texttt{samdb.bat} and put the following line in it:

```
mysql -h cobra.snake.net -p -u sampadm samdb
```

This batch file can be run either by typing \texttt{samdb} at the prompt in a console window or by double-clicking its Windows icon.

If you need to access several databases or connect to several hosts, you can define multiple aliases, shortcuts, or scripts, each of which invokes \texttt{mysql} with different options.
