Some PHP functions or operations produce an error message if an error occurs, in addition to returning a status value. In Web contexts, this message appears in the page sent to the client browser, which may not be what you want. To suppress the (possibly cryptic) error message that a function normally would produce, precede the function name by the @ operator: For example, to suppress the error message from a function named `some_func()` so that you can report failure in a more suitable manner, you might do something like this: `$status = @some_func ();`
