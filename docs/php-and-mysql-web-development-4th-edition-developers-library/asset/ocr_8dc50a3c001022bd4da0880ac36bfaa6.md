+   • `$rv` = `$sth->(`**`mysql_use_result`**`);`

Whether to use the `mysql_store_result()` or `mysql_use_result()` C API function for retrieving result sets. By default, `mysql_use_result` is 0, so DBD:mysql uses `mysql_store_result()`. If you set `mysql_use_result` to 1, DBD:mysql uses `mysql_use_result()`. See Appendix G (online) for a discussion of these two functions and how they differ.

Note that enabling `mysql_use_result` causes some statement-handle attributes such as `mysql_max_length` to become invalid. It also invalidates the use of the `rows()` method, although it's better to count rows when you fetch them anyway.

If you set the `mysql_use_result` attribute, do so after invoking `prepare()` and before invoking `execute()`: 
```cpp
$sth = $dbh->prepare ($stmt_str);
$sth->{mysql_use_result} = 1;
$sth->execute();
```

Alternatively, do this: 
```cpp
$sth = $dbh->prepare ($stmt_str, { mysql_use_result => 1 });
```
