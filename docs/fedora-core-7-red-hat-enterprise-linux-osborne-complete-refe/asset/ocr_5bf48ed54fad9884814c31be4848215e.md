With these clients, you can print documents, list a print queue, reorder it, and remove print jobs, effectively canceling them. # lpr

The `lpr` client submits a job, and `lpd` then takes it in turn and places it in the appropriate print queue; `lpr` takes as its argument the name of a file. If no printer is specified, then the default printer is used. The -P option enables you to specify a particular printer. In the next example, the user first prints the file prefac e and then prints the file report to the printer with the name myepson:

```
$ lpr prefac e
$ lpr -P myepson report
```
