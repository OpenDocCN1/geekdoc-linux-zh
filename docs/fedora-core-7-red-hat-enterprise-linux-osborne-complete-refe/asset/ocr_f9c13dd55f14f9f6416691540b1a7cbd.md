# Command and Filename Completion

The BASH command line has a built-in feature that performs command line and file name completion. Automatic completions can be effected using the TAB key. If you enter an incomplete pattern as a command or filename argument, you can then press the TAB key to activate the command and filename completion feature, which completes the pattern.
