Some of these file builders are just other names for traditional file system creation tools. For example, the **<em>mkfs.ext2</em>** file builder it just another name for the **<em>mke2fs</em>** ext2 file system creation tool, and **<em>mkfs.msdos</em>** is the **<em>mkdosfs</em>** command. As ext3 is an extension of ext2, **<em>mkfs.ext3</em>** simply invokes **<em>mke2fs</em>**, the tool for creating ext2 and ext3 file systems, and directs it to create an ext3 file system (using the -<em>j</em> option). The next example is equivalent to the preceding one, creating an ext3 file system on the **<em>sdb1</em>** device:

```
mkfs.ext3 /dev/sdb1
```

The syntax for the <em>mkfs</em> command is as follows. You can add options for a particular file system after the type and before the device. The block size is used for file builders that do not detect the disk size.

```
mkfs [options] [-<em>t</em> <em>type</em>] <em>file-soptions</em> <em>device</em> <em>size</em>
```
