
虚拟化技术，例如完全虚拟化（KVM）和半虚拟化（Xen），均已涵盖。使用虚拟机管理器，可以轻松安装和运行这两种技术下的客户操作系统。不同的文件系统任务也包含在内，例如挂载文件系统、使用 HAL 和 udev 管理文件系统，以及配置 RAID 设备和 LVM 卷。设备通过 udev 和硬件抽象层（HAL）自动检测。Fedora 使用热插拔模型来管理其所有设备。udev 工具自动生成设备接口，并使用其自身的规则管理固定和可移动设备。HAL 向应用程序提供设备的热插拔信息，使它们能够直接访问。

# Red Hat 和 Fedora Linux 简介

**Linux** 是一个快速、稳定且开源的操作系统，适用于个人计算机和工作站，具备专业级的互联网服务、丰富的开发工具、功能齐全的图形用户界面（GUI），以及从办公套件到多媒体应用的众多应用程序。Linux 于 20 世纪 90 年代初由 Linus Torvalds 和世界各地的其他程序员共同开发。作为操作系统，Linux 执行许多与 Unix、Macintosh、Windows 和 Windows NT 相同的功能。然而，Linux 以其强大的性能、灵活性以及免费获取的特点而与众不同。大多数个人计算机操作系统，如 Windows，其开发始于小型、受限的个人计算机内部，这些机器直到最近才变得更加通用。这些操作系统不断升级，以跟上个人计算机硬件不断变化的能力。另一方面，Linux 是在不同的背景下开发的。Linux 是 Unix 操作系统的个人计算机版本，几十年来一直用于大型机和小型机，并且目前是网络服务器和工作站的首选系统。Linux 将 Unix 的速度、效率、可扩展性和灵活性带到你的个人计算机上，充分利用个人计算机现在提供的所有能力。

从技术上看，Linux 由操作系统程序组成，称为**内核**，这是 Linus Torvalds 最初开发的部分。但它一直与大量的软件应用程序一起分发，范围从网络服务器和安全程序到办公应用程序和开发工具。Linux 是开源软件运动的一部分而发展起来的，在该运动中，独立的程序员联合起来为任何用户提供免费的优质软件。Linux 已成为开源软件的首选平台，其中许多是由自由软件基金会的 GNU 项目开发的。这些应用程序中的许多是作为标准 Linux 发行版的一部分打包的。目前， thousands of 开源应用程序可用于 Linux，来自诸如开源开发网络（OSDN）的 [sourceforge.net](http://sourceforge.net)、软件存储库 [rpmfind.net](http://rpmfind.net)、[rpm.livna.org](http://rpm.livna.org)、[freshrpms.net](http://freshrpms.net)、KDE 的 [www.kde-apps.org](http://www.kde-apps.org) 以及 GNOME 的 [www.gnome.org](http://www.gnome.org) 等网站。这些应用程序中的大多数也包含在 Fedora 存储库中，使用符合 Fedora 标准的软件包。你应该首先检查 Fedora 存储库（应用程序 | 添加/删除软件）以寻找你想要的软件。符合 Fedora 标准的第三方软件也可从 Livna 和 Freshrpms 存储库（rpm.livna.org 和 freshrpms.net）获得。

除了 Linux 的操作系统功能外，它还具有强大的网络特性，包括对互联网、内网和 Windows 网络的支持。通常，Linux 发行版包括快速、高效且稳定的互联网服务器，如 Web、FTP 和 DNS 服务器，以及代理、新闻和邮件服务器。换句话说，Linux 拥有设置、支持和维护完全功能网络所需的一切。

借助 GNOME 和 KDE 桌面环境，Linux 也提供具有同等灵活性和强大功能的 GUI 界面。与 Windows 和 Mac 不同，Linux 允许你选择你想要的界面并进一步自定义，添加面板、小工具、虚拟桌面和菜单，所有这些都具有完整的拖放功能和互联网感知工具。

Linux 以合理的价格做到这一切。Linux 是免费的，包括网络服务器和 GUI 桌面。与官方 Unix 操作系统不同，Linux 根据自由软件基金会规定的 GNU 通用公共许可证免费分发，使其对任何想要使用它的人可用。GNU（该缩写代表“GNU's Not Unix”）是由自由软件基金会发起并管理的项目，旨在为用户提供免费软件。Linux 受版权保护，不属于公有领域。然而，GNU 公共许可证的效果与软件属于公有领域非常相似。

GNU 通用公共许可证旨在确保 Linux 保持免费，同时也保持标准化。从技术上讲，Linux 是操作系统内核——核心操作——且只有一个官方的 Linux 内核。人们有时会有错误的印象，认为 Linux 因为是免费的，所以不如专业操作系统。事实上，Linux 是 Unix 的个人计算机、工作站和服务器版本。许多人认为它比 Windows 更稳定，功能更强大。这种强大和稳定性使 Linux 成为网络服务器的首选操作系统。

要完全欣赏 Linux，你需要理解 Unix 操作系统开发的特殊背景。与大多数其他操作系统不同，Unix 是在研究和学术环境中开发的。在大学、研究实验室、数据中心和企业中，Unix 是最常使用的系统。其发展过去几十年与整个计算机和通信革命并行。计算机专业人士通常会在 Unix 上开发新的计算机技术，例如为互联网开发的技术。尽管 Unix 是一个复杂的系统，但它从一开始就被设计为灵活的。Unix 系统本身可以轻松修改以创建不同的版本。事实上，许多不同的供应商维护着不同版本的官方 Unix。IBM、Sun 和 Hewlett-Packard 都销售并维护他们自己的 Unix 版本。研究项目的独特需求通常要求根据他们自己的特殊需求定制 Unix。Unix 设计中固有的灵活性丝毫不影响其质量。事实上，这种灵活性证明了 Unix 的坚固性，使其能够适应几乎任何环境。这就是 Linux 开发的背景。从某种意义上说，Linux 是 Unix 的另一个版本——一个适用于个人计算机的版本。由在类似研究环境中工作的计算机专业人士开发 Linux，反映了 Unix 版本通常的开发方式。Linux 具有公共许可证且免费，反映了 Unix 在学术机构中的深厚根基，及其公共服务和支持意识。Linux 是一个顶级的操作系统，所有人都可以免费访问。
