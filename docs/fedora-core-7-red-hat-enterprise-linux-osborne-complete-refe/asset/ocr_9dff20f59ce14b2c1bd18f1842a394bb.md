ALT-CTRL-F₁ to switch to a command line interface (ALT-CTRL-F₁₀ returns you to the GUI interface). A CTRL-D or **exit** command returns you to your own user login. When you are logged in as the root, you can use **su** to log in as any user, without providing the password. In the next example, the user is logged in already. The **su** command then logs in as the root user, making the user a superuser. Some basic superuser commands are shown in Table 27-1.

```
$ pwd
/home/chris
$ su
    password:
# cd
# pwd
/root
# exit
$ 
```

> CAUTION For security reasons, Linux distributions do not allow the use of su in a telnet session to access the root user. For SSH- or Kerberos-enabled systems, Fedora provides secure login access using slogin (SSH) and rlogin (Kerberos version).
