# Configuration Directories and Files

When you configure different elements of your system, like users, applications, servers, or network connections, you make use of configuration files kept in certain system directories. Configuration files are placed in the /etc directory, with more specific device and service configurations located in the /etc/sysconfig directory.

# Configuration Files: /etc

The /etc directory holds your system, network, server, and application configuration files. Here you can find the fstab file listing your file systems, the hosts file with IP addresses for hosts on your system, and grub.conf (a link to /boot/grub/grub.conf) for the boot systems supported by the GRUB boot loader. This directory includes various subdirectories, such as /etc/apache for the Apache Web server configuration files, /etc/X11 for the X Window System and window manager configuration files, and /etc/udev for rules to generate device files in /dev. You can configure many applications and services by directly editing their configuration files, though it is best to use a corresponding administration tool.
