# Considerations

SELinux
SELinux (Security-Enhanced Linux) improves system security by implementing mandatory access control policies in the kernel (page 473). By default, Fedora installs SELinux in Enforcing mode, which implements best practice security policies. Although you can put SELinux in Permissive or Disabled mode before or after you install the system, it is not a good idea to do so because SELinux protects the system. See page 473 for more information on SELinux. See the selinux boot parameter (page 72) if you want to turn off SELinux when you install the system.

Gui
Server systems can save resources by not including a GUI. On other systems a GUI gives you the benefit of a desktop with multiple workspaces that can include many windows. Fedora/RHEL installs GNOME by default.
