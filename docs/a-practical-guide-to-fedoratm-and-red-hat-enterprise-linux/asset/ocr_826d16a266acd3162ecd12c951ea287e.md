# A PARTIAL LIST OF BUILTINS

Table 27-6 lists some of the `bash` builtins. You can use `type` (page 1041) to see if a command runs a builtin. See “Listing `bash` builtins” on page 170 for instructions on how to display complete lists of builtins.

Table 27-6   bash builtins

| Builtin | Function |
| : | : |
| `:` | Returns 0 or `true` (the null builtin; pages 1037 and 1049) |
| `. (dot)` | Executes a shell script as part of the current process (page 332) |
| `bg` | Puts a suspended job in the background (page 348) |
| `break` | Exits from a looping control structure (page 1005) |
| `cd` | Changes to another working directory (page 185) |
| `continue` | Starts with the next iteration of a looping control structure (page 1005) |
| `echo` | Displays its arguments (page 219) |
| `eval` | Scans and evaluates the command line (page 1051) |
| `exec` | Executes a shell script or program in place of the current process (page 1045) |
| `exit` | Exits from the current shell (usually the same as `CONTROL-D` from an interactive shell; page 1029) |
| `export` | Makes the variable an environment variable (page 1032) |
| `fg` | Brings a job from the background to the foreground (page 347) |
| `getopts` | Parses arguments to a shell script (page 1052) |
| `jobs` | Displays a list of background jobs (page 346) |
| `kill` | Sends a signal to a process or job (page 465) |
| `pwd` | Displays the name of the working directory (page 143) |
| `read` | Reads a line from standard input (page 1041) |
| `readonly` | Declares a variable to be `readonly` (page 356) |
| `set` | Sets shell flags or positional parameters; with no argument, lists all variables (pages 400 and 1024) |
| `shift` | Promotes each positional parameter (page 1025) |
| `test` | Compares arguments (page 983) |
| `times` | Displays total times for the current shell and its children |
| `trap` | Traps a signal (page 1047) |
