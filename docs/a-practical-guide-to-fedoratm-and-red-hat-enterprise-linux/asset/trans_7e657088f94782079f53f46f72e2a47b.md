## 学习目标

阅读本章后，你应该能够：

- 讨论 UNIX、Linux 和 GNU 项目的历史
- 解释“自由软件”的含义，并列出 GNU 通用公共许可证的特征
- 列出在选择操作系统时对你重要的三个特征
- 解释 FOSS/FLOSS 术语的意图；说明它与自由软件和开源软件的关系
- 解释什么是 Linux 发行版，并列出三种流行的发行版
- 列出 Linux 的特征以及 Linux 操作系统如此受欢迎的原因
- 列出你在选择操作系统时会考虑的三个因素
- 解释什么是桌面环境，并命名三个桌面管理器
