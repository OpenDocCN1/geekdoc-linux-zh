**Identity**

The Identity screen has two important check boxes. A tick in the check box labeled **Connect automatically** causes the system to bring up the connection when it boots and sets ONBOOT=**yes**. Without a tick, you must bring up the connection manually.

A tick in the check box labeled **Make available to other users** causes the connection to be available to all users and to be up even when the user who set up the connection is not logged in. Without a tick, the connection is up only when the user who set up the connection is logged in. Typically you want a tick in this check box.

**Activating changes**

When you are finished, click **Apply** to update the configuration files. Turn the interface off and then on again to make the changes active.
