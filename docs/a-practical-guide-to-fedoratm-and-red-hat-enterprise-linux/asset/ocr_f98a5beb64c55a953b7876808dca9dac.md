**optional** The *named-chroot* service uses the *mount*—*bind* option to remount part of a directory hierarchy (which can be a single file) in another location. This option allows you to do what you cannot do with hard links: access a directory hierarchy from another location in a filesystem. It also bypasses some of the limitations of symbolic links, including permissions issues. However, it does not create another link to a file—see the preceding listing for *named.conf*. The links count (page 192) to each file is 1. See the *mount* man page for more information.
