Because the descriptions in the system documentation are often terse, they are most helpful if you already understand the basic functions of a utility. You can search for topics covered by man pages using the apropos utility (next page).

To find out more about a utility, give the command man, with the name of the utility as an argument. Figure 4-24 shows man displaying information about itself; the user entered man on the command line. Within a man page you can search for a term by typing a slash followed by the term and a RETURN. For example, to search for the term function in a man page, type /functionRETURN; man will highlight all occurrences of the string function and move the cursor to the next one.

less (pager)   The man utility sends its output through a pager—usually less (page 220), which displays one screen of information at a time. When you display a manual page using man, less displays a prompt [e.g., Manual page man(1) line 1...] at the bottom of the screen after it displays each screen of text and waits for you to take one of the following actions:

+   * Press the SPACE bar to display another screen of text.
+   * Press PAGE UP, PAGE DOWN, UP ARROW, or DOWN ARROW to navigate through the text.
+   * Press h (help) to display a list of less commands.
+   * Press q (quit) to quit man and less and cause the shell to display a prompt.

Manual sections   Based on the FHS (Filesystem Hierarchy Standard; page 189), the Linux system manual and the man pages are divided into ten sections, where each section describes related tools:

+   1.  User Commands
+   2.  System Calls
+   3.  Subroutines
+   4.  Devices
+   5.  File Formats
+   6.  Games
+   7.  Miscellaneous
+   8.  System Administration
+   9.  Kernel
+   10. New

This layout closely mimics the way the set of UNIX manuals has always been divided. Unless you specify a manual section, man displays the earliest occurrence in the manual of the word you specify as an argument. Most users find the information they need in Sections 1, 6, and 7; programmers and system administrators frequently need to consult the other sections.
