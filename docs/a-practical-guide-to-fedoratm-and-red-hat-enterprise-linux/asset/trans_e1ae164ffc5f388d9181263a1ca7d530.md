## date：显示系统时间和日期

如果没有提供参数，**date**实用程序将显示本地系统已知的日期和时间。如果您设置了区域数据库（第368页），**date**将使用该数据库在输出中替换为适合您账户区域的术语。使用*timedatectl*（第613页）来设置系统时钟。

```
$ date
Mon Aug 19 14:39:55 PDT 2013
```

## 硬件时钟和系统时钟

> 硬件时钟是保存在BIOS中的时间（第31页）。这个时钟由电池供电，即使在计算机关闭时也能保持时间。系统时钟仅在系统运行时运行，是Linux在需要知道时间时使用的时钟。在某些系统中，系统时钟定期通过NTP（网络时间协议；第319页）进行校准，以保持准确性。

## 参数

以下示例格式化了**date**输出的内容。有关格式序列的完整列表，请参见**date**的*man*页。

```
$ date +"%A %B %d"
Monday August 19
```

## 选项

- **日期**
  使用**-d** *datestring*（或**--date=***datestring*）选项显示由*datestring*指定的日期，而不是系统已知的日期。根据**date**的*man*页，“*datestring*是大多为自由格式的日期字符串”，例如**2pm next thursday**。有关*datestring*语法的详细信息，请参见**date**的*man*页中的**DATE STRING**。此选项不会更改系统时钟。

- **UTC**
  使用**-u**（**--utc**或**--universal**）选项以UTC（协调世界时；第1279页）显示或设置时间和日期。UTC也称为GMT（格林尼治平均时间）。

```
$ date -u
Mon Aug 19 21:40:19 UTC 2013
```

## echo：显示参数

**echo**实用程序将其参数后跟一个NEWLINE（换行符）复制到标准输出。Bourne Again Shell（Bash）有一个`echo`内置命令，其工作方式类似于`echo`实用程序。

`echo`内置命令/实用程序是了解Shell和其他Linux实用程序的好工具。第166页上的一些示例使用**echo**来说明特殊字符（如星号）的工作方式。在第5、9和27章中，**echo**帮助解释Shell变量如何工作，以及您如何从Shell脚本向屏幕发送消息。您甚至可以使用**echo**通过重定向其输出来创建一个短文件：

```
$ echo "This is a short file." > short
$ cat short
This is a short file.
```

## 参数

参数可以包含带引号的字符串、模糊的文件引用和Shell变量。Shell识别并扩展参数中未加引号的特殊字符。

以下示例显示**echo**将其参数复制到标准输出。第二个命令包含一个未加引号的星号（`*`；第166页），Shell在将其作为参数传递给**echo**之前，会将其扩展为工作目录中文件的列表；**echo**将此列表复制到标准输出。

```
$ echo This is a sentence.
This is a sentence.
$ echo star: *
star: memo memo.0714 practice
$ ls
memo memo.0714 practice
```

## less：一次显示一屏文本文件

您可以使用称为*paggers*（分页器）的`less`或`more`实用程序，一次显示一屏来查看长文本文件。这些实用程序中的每一个在显示一屏文本后都会暂停。然后您可以按**空格键**显示下一屏文本。

尽管`less`和`more`非常相似，但它们有细微的差别。例如，`less`实用程序允许在某些情况下向后移动查看文件，而`more`则不允许。`more`必须在显示任何内容之前读取整个文件，而`less`不需要，因此在显示大文件时启动速度比`more`快。在文件末尾，`less`显示一个**END**（结束）消息，并等待您按**q**才返回Shell。相比之下，`more`直接返回Shell。使用这两个实用程序时，您可以按**?**显示一个帮助屏幕，列出您在翻阅文件时可以使用的命令。输入命令`less /etc/services`来试验翻阅文件。

## 参数

`less`和`more`都接受您想要查看的文件名称作为参数。如果您没有指定参数，或者指定了一个连字符（`-`，仅限`less`）代替文件名，`less`和`more`将从标准输入读取。

## 选项

以下选项适用于`less`。

- **清屏** — `-c`（`--clear-screen`）选项从顶部到底部绘制每个新屏幕；默认情况下，`less`滚动显示。
- **EOF** — `-e`（`--quit-at-eof`）选项使`less`在达到第二个**EOF**（当`less`在文件末尾显示**END**时，您按下**空格键**）时退出，因此您不需要输入**q**来退出。
- **截断** — `-S`（`--chop-long-lines`）选项截断宽度超过屏幕的行。默认情况下，`less`换行长行。
- **无初始化** — `-X`（`--no-init`）选项防止`less`向终端发送终端初始化和反初始化字符串。默认情况下，`less`在完成时清除屏幕；此选项使您正在查看的最后一页保留在屏幕上。

> **可选** 您可以在`~/.bash_profile`文件（第330页）中设置**LESS**环境变量（第1032页），以在每次调用`less`时以及当它由其他程序（如`man`）调用时设置`less`的选项。例如，您的主目录中`.bash_profile`文件中的以下行将使`less`始终以`-X`选项运行。
>
> ```bash
> export LESS='-X'
> ```

## ls：显示文件信息

`ls`实用程序显示一个或多个文件的信息。除非您使用选项更改顺序，否则它按文件名的字母顺序列出信息。

当您不提供参数时，`ls`显示工作目录中可见文件（文件名不以句点开头；第180页）的名称。

## 参数

参数是一个或多个普通文件、目录或设备文件的路径名。Shell会扩展参数中的模糊文件引用（第165页）。

当您指定一个普通文件作为参数时，`ls`显示该文件的信息。当参数是目录时，`ls`显示目录的内容。仅在需要避免歧义时才显示目录名称，例如当列表包含多个目录时。

```
$ ls memos.zach/130715.1
memos.zach/130715.1

$ ls memos.zach
130712.1  130714.2  130714.3  130715.1

$ ls memos.*
memos.max:
130619.1  130621.2  130622.1

memos.sam:
130811.2  130811.3  130812.1

memos.zach:
130712.1  130714.2  130714.3  130715.1
```

![](img/243613168ac865b539f12460d966088e_277_1.png)

## 选项

选项决定了`ls`显示的信息类型，以及显示信息的方式和顺序。当不使用选项时，`ls`显示一个短列表，仅包含按字母顺序排列的文件名。有关选项如何影响`ls`输出的示例，请参见第145页。

- **所有**
  **-a**（`--all`）选项将隐藏文件名（以句点开头的文件名；第180页）包含在列表中。如果没有此选项，`ls`不会列出有关隐藏文件名文件的信息，除非您明确指定隐藏文件的名称作为参数。`*`模糊文件引用不匹配文件名开头的句点，因此您必须使用此选项或明确指定以句点开头的文件名（无论是否模糊）才能显示有关隐藏文件名文件的信息。

![](img/243613168ac865b539f12460d966088e_277_2.png)

```
$ ls -ld /
dr-xr-xr-x  27 root root  4096 07-16 18:37 /
```
