The `yppasswd` utility replaces the functionality of `passwd` on clients when you use NIS to authenticate passwords. The `/etc/ypserv.conf` file, which holds NIS server configuration information, specifies options and access rules for the NIS server. To enhance system security, you can create a `/var/yp/securenets` file, which prevents unauthorized systems from retrieving NIS maps.

An LDAP (Lightweight Directory Access Protocol) server holds a search- and read-optimized database, called a directory. LDAP clients, such as email clients, query and update this directory. In addition, authentication servers can use an LDAP directory to authenticate users.

Fedora/RHEL provides the OpenLDAP implementation of LDAP. OpenLDAP uses the Sleepycat Berkeley Database, which supports distributed architecture, replication, and encryption.
