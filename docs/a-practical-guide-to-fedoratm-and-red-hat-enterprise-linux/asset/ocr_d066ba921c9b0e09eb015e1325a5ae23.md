# Using a keyserver

If you want to share your public key with the world, you can upload it to a keyserver. Having your key on a keyserver makes it easier for several people to sign it. It also makes it easier for people to find and use to encrypt documents they send to you. Once it is uploaded, it will be distributed to all keyservers; there is no need to upload it to more than one. The keys.snugp.net URL uses a round-robin DNS that points to a different keyserver each time you reference it.

The following example sends the public key with the key ID `9dzz99zz` from the user’s keyring to the keyserver that keys.snugp.net points to. The `gpg` utility uses keys.snugp.net by default; you can specify a different keyserver by using the `--keyserver` option. The argument following the `--send-keys` option specifies the key ID of the public key `gpg` is to send from the user’s keyring to the keyserver.
