# bash versus \u2013bash

**tip** On some systems, **\texttt{echo}\ \$0** displays **\u2013bash** while on others it displays **\texttt{bash}**. The former indicates a login shell (page \texttt{330}); the latter indicates a shell that is not a login shell. In a GUI environment, some terminal emulators launch login shells while others do not.

# \$1 \u2013 \$n: POSITIONAL PARAMETERS

The shell expands **\$1** to the first argument on the command line, **\$2** to the second argument, and so on up to **\$n**. These parameters are short for **\$1(1), \$1(2), \$1(3),** and so on. For values of **\textit{n}** less than or equal to 9, the braces are optional. For values of **\textit{n}** greater than 9, the number must be enclosed within braces. For example, the twelfth positional parameter is represented by **\$1(12)**. The following script displays positional parameters that hold command-line arguments:

```
```text
$ cat display_5args
echo First 5 arguments are $1 $2 $3 $4 $5

$ ./display_5args zach max helen
First 5 arguments are zach max helen
```
```

The **\texttt{display\_5args}** script displays the first five command-line arguments. The shell expands each parameter that represents an argument that is not present on the command line to a null string. Thus the **\$4** and **\$5** parameters have null values in this example.

# Always quote positional parameters

> **caution** You can “lose” positional parameters if you do not quote them. See the following text for an example.

Enclose references to positional parameters between double quotation marks. The quotation marks are particularly important when you are using positional parameters as arguments to commands. Without double quotation marks, a positional parameter that is not set or that has a null value disappears:

```
```text
$ cat showargs
echo "$0 was called with $# arguments, the first is :$1:"

$ ./showargs a b c
./showargs was called with 3 arguments, the first is :a:

$ echo 5xx

$ ./showargs $xx a b c
./showargs was called with 3 arguments, the first is :a:

$ ./showargs "$xx" a b c
./showargs was called with 4 arguments, the first is :::
```
```
