# ## lspci: LISTS PCI INFORMATION

PCI (Peripheral Component Interconnect) devices include network, sound, video, and TV tuner cards; modems; USB ports; and disk controllers. For information about PCI vendors, devices, and ID numbers visit pcids.sourceforge.net/pci.ids and www.pcidatabase.com/reports.php?type=tab-delimited. The `lspci` utility (`pciutils` package) lists PCI device information:

```
```bash

00:07.0 ISA bridge: Intel Corporation 82371AB/EB/MB PIIX4 ISA (rev 08)
00:07.1 IDE interface: Intel Corporation 82371AB/EB/MB PIIX4 IDE (rev 01)

# ## lsblk: LISTS BLOCK DEVICE INFORMATION

The `lsblk` utility (`util-linux` package) lists block devices in a tree format that shows which filesystems are mounted on each device.

```
```bash
$ lsblk
NAME     MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
sda         8:0    0   20G  0 disk
├─sda1       8:1    0   50M  0 part /boot
├─sda2       8:2    0  19.9G  0 part
│ ├─fedora-swap 253:0  0    2G  0 part [SWAP]
│ ├─fedora-root 253:1  0    50G  0 lvm
│ └─fedora-home 253:2  0   147.5G  0 lvm /home
sr0        11:0    1  1024M  0 rom
```
