# Allocate disk space all at once or as needed?

> **tip** You can cause `virt-manager` to allocate space on the disk immediately or as needed. Allocating it immediately takes more time in the setup phase but makes the installation phase go more quickly. If you allocate storage as needed, you can run into problems if the local system runs out of disk space. On the other hand, allocating storage as needed allows you to specify a maximum amount of storage but use only what the VM needs.
