Automatic partition creation

To have Anaconda create partitions automatically, click **Click here to create them automatically**. Anaconda creates *swap, /boot, / (root),* and (if there is enough space) */home* partitions and displays them in the Manual Partitioning screen so you can review and modify them (Figure 3-12).
