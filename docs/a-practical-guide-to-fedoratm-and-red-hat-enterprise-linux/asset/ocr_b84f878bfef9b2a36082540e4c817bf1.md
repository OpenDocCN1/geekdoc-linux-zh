# # Working with the Desktop

This section discusses several ways you can work with the desktop. It applies to both the GNOME 3 Standard and Classic desktops.

# ## Terminology

+   - In addition to this section, see the Glossary, which defines data entry widgets (page 1281) such as the *combo box* (page 1243), *drop-down list* (page 1248), *list box* (page 1258), and *text box* (page 1277).
+   - A *workspace* is a screen that holds windows of one or more applications. The Activities Overview screen (page 92) and the Application Switcher (page 94) enable you to display any of the running applications and its workspace.
+   - The *active workspace* is the workspace that displays the windows you can work with immediately. Only one workspace can be active at a time.
+   - The *desktop*, which is not displayed all at once, is the collection of all workspaces.
