
## 来宾账户
分配给以**来宾**身份登录的用户或映射到**来宾**用户的用户名；仅当**guest ok**设置为**YES**时适用。该用户名应存在于`/etc/passwd`中，但不应能够登录系统。通常**来宾账户**被赋予**nobody**值，因为**nobody**用户只能访问任何用户都可以访问的文件。如果您在服务器系统上出于其他目的使用**nobody**账户，请将此参数设置为除**nobody**以外的名称。更多信息请参见第830页。
默认值：无（允许所有主机访问）

## hosts allow
类似于`/etc/hosts.allow`文件；指定允许连接到服务器的主机。覆盖**hosts deny**中指定的主机。良好的策略是在**hosts deny**中指定**ALL**，并在此文件中指定您想要授予访问权限的主机。指定主机的方式与**hosts.allow**文件中相同。
默认值：无（允许所有主机访问）

## hosts deny
类似于`/etc/hosts.deny`文件；指定不允许连接到服务器的主机。被**hosts allow**中指定的主机覆盖。如果您在此参数中指定**ALL**，请记得在**hosts allow**中包含本地系统（127.0.0.1）。指定主机的方式与**hosts.deny**文件中相同。
默认值：无（不排除任何主机）

## invalid users
列出那些不允许使用Samba登录的用户。
默认值：无（允许所有用户登录）

## map to guest
定义当登录失败时映射到**来宾账户**的时机。仅当**security**未设置为**SHARE**或**SERVER**时才有用。
- **Never**：仅当用户显式提供**guest**作为用户名且密码为空时，才允许**来宾**登录。
- **Bad User**：将任何尝试以不存在的用户身份登录的行为视为**来宾**登录。此参数存在安全风险，因为它允许恶意用户快速获取系统中的用户列表。
- **Bad Password**：静默地将任何输入错误密码的用户登录为**来宾**。如果用户密码错误并因此在不知情的情况下以**来宾**身份登录，她可能会看到比习惯中更少的共享，这可能会让用户感到困惑。

默认值：never

## passdb backend
指定Samba如何存储密码。对于LDAP设置为**ldapsam**，对于Samba设置为**smbpasswd**，对于TDB（简单数据库）密码存储设置为**tdbsam**。有关使用**smbpasswd**更改或添加Samba密码的说明，请参见第831页。
默认值：tdbsam

## passwd chat
Samba用来与由**passwd program**定义的程序进行交互的聊天脚本。如果不遵循此脚本，Samba不会更改密码。仅当**unix passwd sync**设置为**YES**时使用。
默认值：
```
%s\n
%s\n
%s
```
*(注：原文表明了一个特定的默认格式，通常是`<newpassword>`，但标准的Samba手册页通常显示提示符和响应。如果暗示了特定字符串，我将保留原文的具体默认值结构，但在此处OCR显示：)*
默认值：
`<newpassword> %\n`
`<newpassword> %\n`
`<changed>`

## passwd program
Samba用于设置Linux密码的程序。Samba用用户的用户名替换`%u`。
默认值：无

## security
指定客户端是否以及如何向服务器传输用户名和密码信息。选择以下之一：
- **USER**：导致Samba要求Windows用户在登录到Samba服务器时提供用户名和密码。使用此设置您可以使用：
    - `username map`将Samba用户名映射到Linux用户名
    - `encrypt passwords`加密密码（推荐）
    - `guest account`将用户映射到**来宾账户**
- **SHARE**：导致Samba不针对每个用户进行身份验证。相反，Samba使用Windows 9x设置，其中每个共享可以为读取或完全访问权限设置单独的密码。此选项与较新版本的Windows不兼容。
- **SERVER**：导致Samba使用另一个SMB服务器来验证用户名和密码。如果远程验证失败，本地Samba服务器会尝试像**security**设置为**USER**那样验证用户名和密码。
- **DOMAIN**：Samba将加密的密码传递给Windows NT域控制器进行验证。要使**DOMAIN**生效，必须正确设置`smb.conf`中的`workgroup`参数。
- **ADS**：指示Samba使用Active Directory服务器进行身份验证，允许Samba服务器作为原生Active Directory成员参与。（Active Directory是Windows 2000及更高版本使用的集中信息系统。它取代了Windows NT及更早版本使用的Windows域。）

默认值：USER

## unix password sync
YES导致Samba在关联用户更改加密的Samba密码时更改用户的Linux密码。
默认值：NO

## username map
指向一个将Windows用户名映射到Linux用户名的用户映射文件。更多信息请参见第830页的“User maps”。
默认值：无映射

# 日志参数

## log file
Samba日志文件的名称。Samba用客户端系统名称替换`%m`，允许您为每个客户端生成单独的日志文件。
默认值：无
Fedora/RHEL：`/var/log/samba/log.%m`

## log level
设置日志级别，0（零）表示关闭，较高的数字表示更详细的日志。
默认值：0（关闭）

## max log size
指定日志文件最大大小（以千字节为单位）的整数。0（零）指定无限制。当文件达到此大小时，Samba在文件名后追加`.old`并开始新的日志，删除旧的日志文件。
默认值：5000
Fedora/RHEL：50

# 浏览器参数

*域主浏览器*是负责维护在浏览时使用的网络机器列表的系统。SMB每11–15分钟使用加权选举来确定哪台机器是**域主浏览器**。Samba服务器是否赢得此选举取决于两个参数：

- 将`domain master`设置为`YES`指示Samba服务器参加选举。
- `os level`决定Samba服务器的投票权重。`os level`的最大设置为`255`，尽管将其设置为`65`应可确保Samba服务器获胜。NT Server系列域控制器——包括Windows 2000、XP和2003——使用`os level`为`32`。

## domain master
YES导致`nmbd`尝试成为`domain master`浏览器。如果存在`domain master`浏览器，则本地主浏览器将向其转发其浏览列表的副本。如果没有`domain master`浏览器，则浏览查询可能无法跨越子网边界。Windows PDC（主域控制器）始终尝试成为`domain master`，如果失败可能会表现异常。更多信息请参见前面的讨论。
默认值：`AUTO`

## local master
YES导致`nmbd`参加子网上本地主浏览器的选举。本地主浏览器存储本地子网上实体*NetBIOS*名称的缓存，允许浏览。Windows机器自动参加选举；为了使浏览正常工作，网络必须至少有一台Windows机器或一台将`local master`设置为`YES`的Samba服务器。将`local master`设置为`NO`是不好的做法。如果您不想让计算机充当本地主，请将其`os level`设置为较低的数字，以便在所有其他方法失败时可以将其用作本地主。
默认值：`YES`

## os level
控制Samba如何为其工作组广播自身以进行浏览器选举，以及`nmbd`成为本地主浏览器可能性的整数。较高的数字增加了本地服务器成为本地主浏览器的机会。更多信息请参见本部分开头的讨论。
默认值：20

## preferred master
YES强制`nmbd`持有本地主选举，并以轻微的优势进入本地系统。将`domain master`设置为`YES`时，此参数有助于确保本地Samba服务器成为`domain master`。在多台服务器上将此参数设置为`YES`会导致这些服务器竞争成为主服务器，产生大量网络流量，有时导致不可预测的结果。Windows PDC自动表现为此参数设置为YES。
默认值：`AUTO`

# 通信参数

## dns proxy
在作为*WINS服务器*运行时，YES导致`nmbd`在*NetBIOS*解析失败时使用DNS。
默认值：`YES`

## socket options
调整与客户端交换数据时使用的网络参数。
默认值：`TCP_NODELAY`

## wins server
`nmbd`应注册的WINS服务器的IP地址。
默认值：未启用

## wins support
YES指定`nmbd`将作为WINS服务器运行。
默认值：`NO`

# 共享参数

以下每个参数都可以在`smb.conf`中出现多次，在每个共享定义中出现一次。

## available
YES指定该共享为活跃状态。将此参数设置为NO以禁用共享，但继续记录其请求。
默认值：`YES`

## browsable
确定是否可以在例如Windows“网上邻居”中浏览该共享。
默认值：`YES`
Fedora/RHEL：各不相同

## comment
共享的描述，在从Windows浏览网络时显示。
默认值：无
Fedora/RHEL：各不相同

## guest ok
允许以`guest`身份登录的用户访问此共享。
默认值：`NO`
Fedora/RHEL：各不相同

## path
被共享目录的路径。
默认值：无
Fedora/RHEL：各不相同

## read only
不允许写入访问。使用`writable`允许读写访问。
默认值：`YES`
Fedora/RHEL：各不相同
