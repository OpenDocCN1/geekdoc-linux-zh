through the loop, **bash** assigns a value of 0 to **count** (the *loop-index*) and executes the statement between **do** and **done**. At the bottom of the loop, **bash** tests whether the termination condition has been met (is **count>**10**)? If it has, **bash** passes control to the statement following **done**; if **not**, **bash** increments **count** by the increment value (**2**) and makes another pass through the loop. It repeats this process until the termination condition is met.

for count in {0..10..2}
do
   echo -n " $count "
done

The **for** structure is the same as the **for_**..**in** structure (Figure 27-4, page 995) except in terms of where it gets values for the *loop-index*.
