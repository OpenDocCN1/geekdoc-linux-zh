If you are unable to solve a problem yourself, a thoughtful question to an appropriate newsgroup (next page) or mailing list (page 1153) can elicit useful information. When you send or post a question, make sure you describe the problem and identify the local system carefully. Include the version numbers of Fedora/RHEL and any software packages that relate to the problem. Describe the hardware, if appropriate. There is an etiquette to posting questions \mdash see www.catb.org/~esr/tags/smart-questions.html for a good paper by Eric S. Raymond and Rick Moe \mtitle{How To Ask Questions The Smart Way.} \emph{For a fee, Red Hat provides many types of support.}
