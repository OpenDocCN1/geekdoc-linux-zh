# vimtutor and vim help files are not installed by default

> **tip** To run vimtutor and to get help as described on page 266, you must install the **vim-enhanced** package. See page 534 for instructions on installing software.

# Starting vim

Start **vim** with the following command to create and edit a file named *practice* (use vi in place of vim if you have not installed the **vim-enhanced** package):

```
$ vim practice
```

When you press **RETURN**, the command line disappears, and the screen looks similar to the one shown in Figure 7-1.
