# SSH (Secure Shell)

Originally written by Tatu Ylonen, now maintained by SSH Communications Security and Data Fellows.

Commercial and free versions of software designed to be secure replacements for the r* tools. It can also do port forwarding and file transfers. It can be compiled with support for Wietse Venema's TCP_wrappers program. The server runs on UNIX, and there are clients available for a growing list of operating systems.

http://www.ssh.fi/sshprotocols2/
