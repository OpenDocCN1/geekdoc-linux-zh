# SUMMARY

This chapter provides an overview of connection and process accounting. We described the commands that allow us to view the information collected by system accounting and noted the security value of this data.

# FOR FURTHER READING

# Books

For a good, general, but non-Linux specific, discussion of UNIX system accounting, check out the following two books.

+   1. Frisch, Aileen, *Essential System Administration*, 2d ed., Sebastopol, California, O’Reilly & Associates, Inc., 1995.
+   2. Nemeth, Evi, et al., *UNIX System Administration Handbook*, 2d ed., Englewood Cliffs, New Jersey, Prentice Hall PTR, 1995.
