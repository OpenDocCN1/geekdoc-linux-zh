# SUMMARY

In this chapter we detailed the implementation and configuration of SSH. We showed that it can be used to build an encrypted tunnel for a variety of remote connections including remote logins, remote execution and copying, and X Window System sessions. It also incorporates a variety of authentication mechanisms, including strong RSA Authentication. We emphasized the use of SSH for all remote root access.
