# Implementing and Using OPIE

In this section we will look at the OPIE OTP programs `opiepasswd` and `opiekey`. Then we will take a look at examples that parallel those found in *S/Key Version 1.1b* on page 121.

The procedure used to initialize users and manage OTP lists with OPIE is quite similar to S/Key. With OPIE, the server-side program is `opiepasswd` instead of `keyinit`. The client-side program is `opiekey` instead of `key`.

As noted at the bottom of Example 6-20, the first thing we need to do is use `opiepasswd` to initialize our users. Unlike `keyinit`, which offers only the *-s* option (see Example 6-13), `opiepasswd` provides a number of options, described in Table 6.4.

The `opiekey` program is the OTP generating program. Unlike its S/Key counterpart *key*, there are a number of options available for `opiekey`, which are described in Table 6.5.
