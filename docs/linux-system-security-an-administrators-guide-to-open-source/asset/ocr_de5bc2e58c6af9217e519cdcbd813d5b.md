You can always trace the exit of a session by PID as long as you specify that the PID is to be logged in /etc/xinetd.conf, as in Example 10-47. The log entries are as follows: Every xinetd log entry records the date and timestamp, followed by the server hostname, then xinetd, followed by the PID of xinetd in brackets. The first record of Example 10-49 begins with the start keyword indicating the initiation of the session; next the daemon invoked is identified (login), then the PID of the invoked daemon, and last the client address.
