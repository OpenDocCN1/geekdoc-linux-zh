+   
+   2. Hunt, Craig, TCP/IP Network Administration, 2d ed., Sebastopol, California, O'Reilly & Associates, Inc., 1998.

+   3. Miller, C. Kenneth, Multicast Networking and Applications, Reading, Massachusetts, Addison-Wesley, 1999.
