You will find good discussions of ICMP types and codes and their purpose in the following books. IPv6: The New Internet Protocol particularly covers the revisions to ICMP for IPv6.

+   1. Comer, Douglas E., *Internetworking with TCP/IP Vol. I: Principles, Protocols, Architecture*, 3rd ed., Englewood Cliffs, New Jersey, Prentice Hall, 1995.
+   2. Huitema, Christian, *IPv6: The New Internet Protocol*, Upper Saddle River, New Jersey, Prentice Hall PTR, 1996.
+   3. Perlman, Radia, *Interconnections: Bridges, Routers, Switches, and Internetworking Protocols*, 2d ed., New York, New York, Addison Wesley, 2000.
+   4. Stevens, W. Richard, *TCP/IP Illustrated, Vol. 1: The Protocols*, Reading, Massachusetts, Addison-Wesley, 1994.
