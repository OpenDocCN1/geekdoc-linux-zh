# Table 6.3 Arguments Supported by the OPIE Makefile

| Argument | Description |
| --- | --- |
| client | Compiles and links the client programs opikeyey and opigen.¹ |
| server | Compiles and links the server programs opiespssd, opieserv,¹ su, login, and ftpd. |
| client-install | Installs the client programs. |
| server-install | Installs the server programs. |
| install | Installs all programs (client and server). |
| clean | Removes all binaries and object files. |
| realclean | Removes all binaries, object files, and files created by configure including all make files. |
| no arguments | Compiles and links all programs (client and server). |

¹opikeyen is a program example provided for developers; it is functionally similar to opikeyey.
¹opieserv is a program example provided for developers; it is functionally similar to opiespssd.

The OPIE Makefile generated by configure offers us a few options. It will accept the arguments described in Table 6.3.

For purposes of our examples, we will use make with no arguments to compile OPIE and then use make install to install OPIE. As described in Table 6.3, this will create the necessary binaries for both client and server activity and then will install all compiled binaries into the appropriate locations. Example 6-19 displays partial output from the execution of make. Notice that OPIE executes a series of tests after compiling the utilities. If your Makefile has problems, this is one place that it will almost certainly show up.
