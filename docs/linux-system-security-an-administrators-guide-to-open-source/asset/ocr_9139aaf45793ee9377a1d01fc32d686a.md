and, again, upon authentication a shell will be opened on the *remote_host* for *username*.

One of the more common uses of *rsh* is to access a remote tape device for backups and restores. We can accomplish the same thing with *ssh* as shown in Example 11-30. In this case, we use the *-n* option to redirect *stdin* to /dev/null so that *ssh* won't block the *tar* command waiting for input. We are asking *ssh* to connect from *topcat* to *underdog* and execute the command *sh -if=/dev/st0 bs=20b*. RSA Authentication, in this case, succeeds when Mary correctly submits her passphrase. The *dd* command will read data from the device file /dev/st0 on *underdog* in blocks of 10,240 bytes (*bs*=20b) and send it back through the SSH-encrypted tunnel to *topcat* where it is piped to the *tar* command on *topcat*. When the *dd* command finishes on *underdog*, *sshd* on *underdog* terminates the SSH connection.
