The script will report known problems such as presence of the uucode alias, references to include files that are owned or writable by nonroot users or that do not exist, and existence of program aliases that do not exist or are owned or writable by nonroot users. Included aliases or program files that are nonroot owned or writable may allow nonroot users to execute commands with root privileges.

**check_anonftp.** This script verifies that the setup of anonymous FTP has been done correctly. The home directory field in the password file for the FTP user is checked for errors that could lead to compromise of the machine; the ownership and permissions of files in the FTP directory hierarchy are checked for problems. If FTP is not configured properly, unauthorized access to the system could be obtained.
