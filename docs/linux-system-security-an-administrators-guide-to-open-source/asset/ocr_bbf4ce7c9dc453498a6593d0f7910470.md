# # REQUEST FOR COMMENT

Request for comments (RFCs) specify a standard or protocol. There are two major sources of RFCs—the Internet Engineering Task Force (IETF), which maintains and issues RFCs largely relating to the Internet, and the Open Group, which maintains and issues RFCs mostly relating to the Distributed Computing Environment (DCE).
