When you finally have all the required Perl modules (it may take a few iterations of perl Makefile.PL to get them all), you can run perl Makefile.PL one more time to create the Makefile; then execute make, make test; then finally make install to copy modules and its man pages to the appropriate directories, as shown in Example 17-9 (some lines wrapped due to length).

If you get an error the first time you run swatch (missing ) or core dump), check the few first lines in /usr/bin/swatch. If you have

```
#!/bin/sh -
eval '`exec perl $0 ${1+"$@"}`'
```
