# Example 10-15 Creating the Deny Message for in.fingerd

```
$ make in.fingerd
cp prototype in.fingerd
chmod 644 in.fingerd
$
```

If we add an appropriate entry to the /etc/hosts.deny file—for example

in.fingerd: ALL: banners /etc/security/banners/deny

then whenever an unauthorized (not found in the /etc/hosts.allow file) finger attempt is made, the message will be displayed.
