Each system will have its own set of critical files and directories. You will need to assess your environment and determine its needs. We supply an example that should give you a reasonably good starting point in Example 14-4. Make sure that you modify this example to fit the needs of the various systems in your computing environment; do **not** use it as it is.

In addition, here are some tips that might help you organize the Tripwire configuration for your environment.

+   *   Identify critical files.
+       *   If the file is used for read-only or read-mostly, try r or similar template.
+       *   If the file is modified frequently and always increases, try the mask `+p!nug~sa!mc0123456789`.
+       *   If the file is modified frequently, but the size is unpredictable, try the mask `+p!nug~sa!mc0123456789`.
+   *   Identify critical directories; apply the same rules as above.
+   *   If it is unclear as to how to proceed, try r and modify as needed. In all cases, you will find out where changes are necessary because your Tripwire compare mode output will become voluminous!
