# **Example 9-14 Sample sudo Log Entries**

```
Mar  9 15:01:55 f0ghorn sudo:     mary : TTY=ttyp0 ; PWD=/home/mary ;
USER=root ; COMMAND=/bin/bash
Mar 10 05:06:30 f0ghorn sudo:     paul : TTY=ttyp0 ; PWD=/home/paul ;
USER=root ; COMMAND=/usr/sbin/lpc restart all
Mar 10 05:16:13 f0ghorn sudo:     paul : TTY=ttyp0 ; PWD=/home/paul ;
USER=root ; COMMAND=validate
Mar 10 05:57:33 f0ghorn sudo:     paul : command not allowed ; TTY=ttyp0
; PWD=/home/paul ; USER=root ; COMMAND=/sbin/shutdown now
Mar 10 06:49:17 f0ghorn sudo:     paul : TTY=ttyp0 ; PWD=/home/paul ;
USER=root ; COMMAND=list
```

no log entries after the first one for mary. Anything she did after sudo invoked the shell will not be logged. The same is true for commands like vi; none of the commands entered in a vi session would be logged, including a shell escape.²

In the next entry, we see paul executing lpc. Subsequent to that entry, we see COMMAND=validate. This means that paul executed sudo -v to reinitialize his ticket. After that, we see the entry for paul's abortive attempt to run shutdown; sudo generated the error message, command not allowed, in this entry. Finally, we see the entry containing COMMAND=list. This means that paul executed sudo -l.

The sudo utility generates substantial log entries—significantly more information than what you would normally see from pam_wheel and su. The copious logging of sudo, in and of itself, is often motivation enough to use sudo. Both from a security and an administrative perspective, these logs are extremely valuable.

Unfortunately, copious logging also means that more time must be spent analyzing the logs. Fret not! Chapter 17 discusses many ways to automate the analysis of your log files.

# PAM and sudo

PAM, PAM, PAM... Wonderful PAM! For more information about PAM, see Chapter 5.

Since sudo is PAM-aware (and we compiled it that way—see Example 9-1 on page 177), we can create an /etc/pam.d/sudo file. Example 9-15 shows using pam_if and pam_opie (see OPIE and PAM on page 143) to force the use of OPIE unless we are at the console or one of the directly connected terminals.

```
auth    sufficient    /lib/security/pam_if.so tty=tty[0-2)]
--  pam_pwb.so shadow
auth    required    /lib/security/pam_opie.so
```
