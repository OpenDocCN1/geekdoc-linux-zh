Once Crack has identified the dictionaries, it uses the instructions contained in the file `conf/dictrun.conf` to proceed with its guessing activities. To do this the `conf/dictrun.conf` file invokes other rules files found in the `conf` subdirectory. It is entirely possible to write a rule that tells Crack to try every permutation of a given-sized password. As Crack goes through the process of obtaining words from the dictionaries and modifies them based on the rules, it hashes each one and compares it to the input list of hashed passwords.
