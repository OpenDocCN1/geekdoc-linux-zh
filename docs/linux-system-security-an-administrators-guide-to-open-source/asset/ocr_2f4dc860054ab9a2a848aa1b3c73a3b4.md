# The xinetd Daemon

The xinetd daemon accepts a number of arguments. These arguments may be overridden by attributes in the special service default, or by individual attribute entries in one or more services. However, all parameters given here or their defaults control the behavior of xinetd itself. For example, if the **-s** flag is specified to xinetd, then it will log all state transformation messages there, even though the */etc/xinetd.conf* file specifies other log locations for service-related messages. The available arguments are listed in Table 10.15.

It should be noted that all status information reported by xinetd, such as reconfiguration notices, always appears in the log file specified by the **-syslog** or **-filelog** flags (-syslog selector daemon.info, by default), regardless of the settings, through defaults or otherwise, in */etc/xinetd.conf*. Also, if you want to capture the PID of xinetd in a file, you may do so with

xinetd -pid 2> /var/run/xinetd.pid```
