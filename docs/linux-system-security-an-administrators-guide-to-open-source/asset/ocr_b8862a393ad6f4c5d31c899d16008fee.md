# E-Mail Lists

You may subscribe to the *sudo* mailing list by placing *subscribe sudo-announce* in the body of an e-mail message to *majordomo@cs.colorado.edu*.

# On-Line Documentation

After extracting *sudo*, you will find the files.

+   - `INSTALL`
+   - `INSTALL.configure`
+   - `README`

which contain a lot of information about *sudo*. Be sure to read them.
