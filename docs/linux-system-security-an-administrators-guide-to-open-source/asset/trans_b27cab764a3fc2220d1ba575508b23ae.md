Linux 发行版包含名为 tcpdump 的工具，该工具通过将本地接口置于混杂模式来捕获网络数据包。通常，你的网络接口会忽略任何未指向你系统的数据包。通过将你的接口置于混杂模式，tcpdump 可以捕获所有数据包，无论其地址如何，并允许你检查这些数据包头中包含的内容。这对调试非常有用。对于试图收集有关你环境信息的不法分子来说，这也很有用。除非你正在使用采用加密技术的应用程序，如 SSH（见第 11 章）、CFS 或 TCFS（见第 15 章），否则所有网络通信都是明文传输的。

一个用户友好度更高的工具 sniffit（可从 http://snifit.rug.ac.be/-coder/snifit/snifit.html 获取）允许检查网络数据包，就像 tcpdump 一样，但它还能够显示数据包的数据部分。请注意，这将包括所有明文密码、电子邮件、文件传输等。这对于调试和验证你的连接是否已加密非常有用。再次强调，它对于希望利用通过 sniffit 获取的信息的人也有用。

有许多类似的程序用于监控你的网络。它们通常统称为网络嗅探器。

如果你担心像 tcpdump 和 sniffit 这样的工具的使用和滥用，你可以采取一些措施。

-   考虑使用交换机代替中继器（见第 30 页的“网络接口层”一节）。这将隔离网络流量，使得运行嗅探器的系统只能看到由交换机发送的流量，而不是本地网络中的所有流量。
-   还有混杂模式检测器，你可以运行它们来确定是否有人将接口置于混杂模式。其中一个实用工具是 nepad，可从 http://www.apostols.org/projects/nepad/ 获取。另一个是 AntiSniff，可从 http://www.10ptch.com/sniff/overview.html 获取。
-   你还可以从你所控制的系统中移除所有网络监控软件。不幸的是，这并不能防止在你控制范围之外的系统上进行嗅探。防御网络嗅探的最佳方法是利用加密解决方案。

## 密码学

*密码学*是秘密书写的一种艺术或科学。在人类历史的早期，它就被广泛用作提供私密对话的一种手段。在现代计算的语境中，它与私密电子通信相关联。它可以用于保护文件、电子邮件以及各种类型的网络连接，如 ftp、telnet 和 http。

首先让我们定义一些术语。

未伪装的电子通信或更通用地说，*消息*被称为*明文*或*未加密文本*。伪装消息的过程称为*加密*或*编码*；该过程将未加密文本转换为*密文*。该过程的逆转称为*解密*或*解码*。因此，未加密的消息可以被加密或编码为密文；然后，密文消息可以被解密或解码回其原始未加密形式。

文中脚注指出：7 国际标准组织（ISO）7498-2 规范更倾向于使用“编码”（encipher）和“解码”（decipher）而不是“加密”（encrypt）和“解密”（decrypt）。我们将这些术语互换使用。

实现加密和解密的算法也被称为*密码算法*。这样的算法也常被称为*密码*。*密钥*通常是一个大的数值（有时以密码或口令短语的形式提供），与密码算法结合使用，用于加密未加密文本和/或解密密文。图 3.3 概述了通过使用加密算法将未加密文本转换为密文的过程。

*密码分析*是在不知道密钥的情况下研究如何解密密文的学科。有许多算法用于此目的，它们通常被称为*密码分析*算法。密码分析过程也常被称为破解或打破加密。*密码学*是研究与密码学和密码分析相关的数学的学科。
