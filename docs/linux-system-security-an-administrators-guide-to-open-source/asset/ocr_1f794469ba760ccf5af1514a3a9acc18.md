# **Using pam_lastlog**

This module provides the capability of displaying the last time-logged-in mes-
sage and the You have new mail message as module type auth and session,
respectively. The former is of greater concern than the latter, as it gives away
information about the computing environment. Fortunately, pam_lastlog gives
you control over what is displayed.
