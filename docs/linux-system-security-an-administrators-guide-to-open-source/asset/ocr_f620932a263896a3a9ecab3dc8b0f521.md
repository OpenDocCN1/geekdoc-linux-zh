**Using tcpdmatch** The tcpdmatch utility takes a daemon/client pair as input and checks the rules for a match. It then provides a resolution, either denying or granting access. Example 10-26 exhibits its typical use.

# Example 10-26 Sample tcpdmatch Output

```
# tcpdmatch in.ftpd underdog
hostame  underdog.eng.sprocket.com
client:   address  172.17.55.124
server:   process  in.ftpd
matched:  /etc/hosts.allow line 11
access:   granted
#
```

As you add rules, tcpdmatch is a very useful tool for checking anything you add. It is also an excellent utility for determining the behavior of the various keywords and options described in this text.
