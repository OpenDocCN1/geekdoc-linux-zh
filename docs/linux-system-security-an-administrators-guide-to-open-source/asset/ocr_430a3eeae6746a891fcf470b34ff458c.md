# ## Building the Portmapper

In all likelihood, if you already have a compiled portmap Version 4, you won't need to recompile because there aren't many functional options (unlike TCP_wrappers). For the purposes of our discussion, we assume that the source tree is installed under `/usr/src/portmap`. The preparatory steps for compiling and linking portmap are quite similar to those for TCP_wrappers. All options are contained in the `Makefile`. Table 10.7 lists the configurable

**Table 10.7** Portmapper Version 4 Compile-Time Options
