# Port Forwarding and Application Proxying

SSH provides the capability of configuring an unused port on a server to be forwarded to another system and port number. In effect, it provides a proxy capability in which an encrypted tunnel is built between two systems and the connection is then forwarded, in the clear, to a third system. Any user may take advantage of this feature; however, the forwarding of privileged ports (port numbers less than or equal to 1023) requires root access. This functionality is provided for in two different ways: local forwarding and remote forwarding. Let's look at examples of each.
