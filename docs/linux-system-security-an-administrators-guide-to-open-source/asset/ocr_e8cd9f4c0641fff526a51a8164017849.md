First, we’ll handle item 1. We need to allow outbound ping, which means ICMP echo-request. We also need to allow inbound ICMP echo-reply in response to the ping. We can accomplish this with the commands shown in Example 16-9. The first command in the example appends the rule to the output chain, which allows the ICMP echo-request to go out eth0 (the external interface). The second command appends the rule, which allows the inbound ICMP echo-reply through eth0.

# Example 16-9  Allowing Outbound ping

```
```
[root@topcat]# ipchains -A output -p icmp --icmp-type echo-request -i eth0 -j ACCEPT
[root@topcat]# ipchains -A input -p icmp --icmp-type echo-reply -i eth0 -j ACCEPT
