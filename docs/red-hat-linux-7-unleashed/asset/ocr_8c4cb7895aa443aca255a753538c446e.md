+   * **flippy=yesdma**—Forces DMA mode. When using a FIFO-enabled controller, the driver will fall back to `nodma` mode if it cannot find the contiguous memory it needs. The `yesdma` option will prevent this. This option is the default setting.
+   * **flippy=notif0**—Required if you receive "Bus master arbitration" errors from the ethernet card (or any other device) while using your floppy controller. The default is the FIFO option.
+   * **flippy=threshold,fifo_depth**—Sets the FIFO depth for DMA mode. A higher setting will tolerate more latency, but will trigger more interrupts and impose more load on the system; a lower setting will generate fewer interrupts but will require a faster processor.
+   * **flippy=nr, irq, dma=nr, dma**—Sets the IRQ and DMA for the given device. The defaults are 6 and 2, respectively.
+   * **Flippy=slow**—Required on some PS/2 machines that have a dramatically slower step rate.

# ## Optimizing Floppy Controllers

If the driver is compiled as a module, you can experiment with **flippy=threshold,fifo_depth** to find optimum settings. To do this, use the `flippycontrol` utility with the `--messages` flag to log controller diagnostics. After inserting the **flippy.o** module and running `flippycontrol --messages`, access the floppy disk; a rush of “Over/Underrun-retrying” messages indicates your FIFO threshold is too low. You can then find an optimum value by unloading the module and trying higher values until these messages are very infrequent.

The full list of FDC module options can be found in `drivers/block/README.fd` and the **fdutils** package. A set of floppy driver utility programs, including an enhanced **mtools** kit, can be downloaded from the `misc` directory on Meta.Lab (`ftp://metalab.unc.edu/pub/Linux/system/Misc/`).

# ## Configuring the Linux Floppy Driver

Floppy driver options are specified using the **flippy=** syntax, but unlike some kernel drivers, this device accepts only one such declaration. For example, to set both **daring** and **two_fdc**, both options must be separated by a space in a single command:

`insmod floppy "flippy="daring two_fdc""`
