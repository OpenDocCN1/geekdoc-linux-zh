# Summary

This chapter covered the basics of configuring, installing, and using LILO, introduced you to the LOADLN.EXE boot utility, and showed installation and configuration of one commercial boot utility, BootMagic, from PowerQuest. Hopefully, you've seen that using LILO can give you additional flexibility in the number of operating systems installed on your PC and that Linux can be used along with these other systems. Don't forget to read LILO's documentation, because you'll not only learn about how operating systems boot from your hard drive, but also how you can customize the Linux boot prompt.
