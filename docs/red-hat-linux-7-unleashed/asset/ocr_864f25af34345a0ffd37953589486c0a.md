# **gs**

This is the Ghostscript interpreter. This program can interpret and prepare PostScript documents and print on more than three dozen displays and printers.

# **gunzip**

Use this program to decompress files compressed with the \texttt{gzip} command back to their original form.

# **gv**

A PostScript and PDF document previewer, this \texttt{X11} client previews and prints PostScript and portable document files and is handy for reading documentation or pre-viewing graphics or documents before printing. Start the \texttt{gv} client by itself in the back-ground, or specify a file on the command line like this:

```

```
# gv myPostScriptdoc.ps &
```

```

# **gvim**

This program is a graphical version of the \texttt{vim} editor and is used under the \texttt{X Window System}.

# **gzip**

\texttt{gzip} is GNU’s version of the \texttt{zip} compression software. The syntax can be as simple as this:

```

```
gzip filename
```

```

It also many times contains some parameters between the command and the filename to be compressed.

# **halt**

The \texttt{halt} command tells the kernel to shut down. This is a \texttt{superuser}-only command. (You must be \texttt{root}.)

# **head**

The \texttt{head} command is a text filter, similar to the \texttt{tail} command, but prints only the num-ber of lines you specify from the beginnings of files.
