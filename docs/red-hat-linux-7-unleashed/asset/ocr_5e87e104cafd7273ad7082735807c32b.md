# Creating Special Accounts with
1inuxconf

Normal accounts are regular login shell accounts that you can log in to at the console or remote login, if available. You can also use 1inuxconf to create special accounts. The 1inuxconf application allows you to set up special accounts that have limited privileges such as PPP accounts for dial-in access or POP accounts for email. To create special accounts, go to the Config tab under 1inuxconf and select Users Accounts, Special Accounts.
