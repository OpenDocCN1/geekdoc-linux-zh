One of most common (and versatile) video players for Linux and X11 is Marc Podlipeč's xanim client. You can find the latest version at http://xanim.va.punix.com/ home.html. This player generally works from the command line of an X11 terminal window, along with the name of the video like this:

```
# xanim ibm_linux-02.avi
```

After you press Enter, the video will start playing in a small window, while the xanim controls are nearby in a floating window, such as that shown in Figure 8.19.
