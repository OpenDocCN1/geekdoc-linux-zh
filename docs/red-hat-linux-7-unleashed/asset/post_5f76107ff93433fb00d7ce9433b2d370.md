# Expert Insight

This book presents authoritative explanations of the core features and complexities of Red Hat Linux 7, including:

- Installing, configuring, and securing Red Hat Linux 7
- Extensive coverage of the new XFree86 4-series X Window System for your computer
- Coverage of updated desktop and server operation configuration and maintenance tools
- Detailed, expert advice on system administration, security, and network services

# Authoritative Advice

Bill Ball and a team of Linux experts introduce and explain the newest features, details, and intricacies of using Red Hat Linux 7. You'll quickly master setting up any Red Hat system and prepare yourself to easily overcome today's problems using tomorrow's software.
