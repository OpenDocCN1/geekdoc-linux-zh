As you can see, the supplied *redhat.mc* file provides a fairly good template for your own *mc* file. You have already copied it to *gonzo.mc*. All you need to do now is add two more items and then you can create the *cf* file *sendmail* can use. Add the following after the list of **FEATURES**:

```
```text
FEATURE(masquerade_envelope)
MASQUERADE_AS(gonzo.gov)
```
```

These lines assume that your *Gonzo* mail host is called *mail.gonzo.gov*. Without these lines, all mail you send out from your mail host will have a **From:** address in the envelope and message body that looks something like *joe@mail.gonzo.gov*. It would be nice to hide which host you sent the mail from and have the recipient **From:** address read something like *joe@gonzo.gov*. That is what the **MASQUERADE_AS** line does. The **masquerade_envelope** feature causes the message envelope **From:** header to be similarly masqueraded.

All that you need to do now is build the *sendmail* configuration file:

```
```bash
[root@gondor cf]# make gonzo.cf
rm -f gondor.cf
m4 ..../m4/cf.m4 gondor.mc > gonzo.cf
chmod 444 gonzo.cf
```
```

If you are using *GNU Make*, which is almost certainly the case if you are running *Red Hat*, you will get an error after typing in the *make* command. Try *make Makefile.dist* *gonzo.cf* instead. If the *make* is successful, a *gonzo.cf* file will appear in your *cf* directory. Congratulations, you have created your very first *sendmail.cf* file!
