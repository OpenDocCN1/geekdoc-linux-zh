# ## Configuring xchat

Using the setup option from the Settings menu will present you with a dialog with a score of options. These can be used to configure xchat to suit your personal preferences.

As already noted it is very important that you change the download directory to something other than the default setting. See Figure 7.4 for an example of how the File Transfer Settings dialog might look.

# FIGURE 7.4
The File Transfer Settings dialog of xchat.

![](bbox=[0.27, 0.53, 0.85, 0.76])

The most important option here is the Directory To Save To setting. Be sure to change this to a directory where you have nothing important and can be reasonably sure that an unsuspected download cannot cause any harm. Make sure that the directory you specify actually exists.
