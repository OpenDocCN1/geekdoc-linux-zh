To close your connection, right-click the kp p p indicator in your panel and then click the Disconnection menu item.

# Setting Up PPP Using the w d d i a l Command

The w d d i a l command is yet another connection tool you'll find in your Red Hat Linux distribution. This command-line tool uses a single configuration file named w d d i a l . c o n f , located under the ~ / e t e directory. You can quickly create a bare-bones configuration file using the w d d i a l c o n f command like this:

```
   1 # w d d i a l c o n f / e t c / w d d i a l . c o n f
   2 Scanning your serial ports for a modem.
   3 tty S1 < * > : ATQ0 V1 E1 Z -- OK
   4 tty S1 < * > : ATQ0 V1 E1 Z -- OK
   5 tty S1 < * > : ATQ0 V1 E1 S0-- OK
   6 tty S1 < * > : ATQ0 V1 E1 S0=0 &C1 -- OK
   7 tty S1 < * > : ATQ0 V1 E1 S0=0 &C1 &D2 -- OK
   8 tty S1 < * > : ATQ0 V1 E1 S0=0 &C1 &D2 S11=55 -- OK
   9 tty S1 < * > : ATQ0 V1 E1 S0=0 &C1 &D2 S11=55 + FCLASS=0 -- OK
  10 ...
```

The command will scan your computer's serial ports, test any found modem, and then create your w d d i a l . c o n f file. You should then open the file with your favorite text editor and edit the Dialer Defaults section. The default will look like this:

```
[ Dialer Defaults]
Modem = / dev / tty S1
Baud = 115200
Inil1 = ATZ
Init2 = ATQ0 V1 E1 S0=0 &C1 &D2 S11=55 + FCLASS=0
```
