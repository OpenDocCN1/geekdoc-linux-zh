When you first run `11nuxconf` you'll see a dialog of help text. If you're running X, have installed the GNOME software libraries, and run `11nuxconf` a second time, the program's main window will appear as shown in Figure 9.1. Note that you can also use `11nuxconf` without running X.

When used without GNOME libraries or from the console, the program (which started life as a configuration tool for the XFree86 X11 distribution) responds to keyboard commands just like Red Hat's Linux installation tool. Navigate around the program's dialog box by pressing the Tab key and then use the Enter key when the cursor is on a desired button or item in a list.

`11nuxconf` can be used not only interactively, but also from the command line. The following related commands (and perhaps others by the time you read this) will be found in your filesystem after you install `11nuxconf` (part of Red Hat Linux since version 5.1):

+   * `dnsconf`—A utility that can be used to configure a domain name server
+   * `f1xperm`—A utility that checks system file permissions
+   * `fsconf`—A utility that manipulates the filesystem table, /etc/fstab, as shown in Figure 9.2.
