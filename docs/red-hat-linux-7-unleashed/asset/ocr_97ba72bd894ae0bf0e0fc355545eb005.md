# Summary

Samba enables a Linux computer to act as a secure, sophisticated file and print server. At this point, you should have a properly configured Samba server up and running and should have learned the commands and options that make that Samba server practical.

You have learned several tips on troubleshooting your Samba setup.

Several advanced options are available for Samba and the various programs that make up the Samba suite. Finally, you can find a large amount of information on Samba at http://www.samba.org.
