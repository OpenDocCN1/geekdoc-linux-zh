It is probably a good idea to only shut down the system when you are at the console. Although you can shut it down remotely via a shell session, if anything goes wrong and the system does not restart properly, the system will be unavailable until action is taken at the system unit.

Upon system bootup, Linux will start automatically if it is the default OS defined in LILO, and load all necessary services including networking support and Internet services.

# Summary

The Red Hat Linux installation is the simplest and most straightforward installation available. After going through this chapter and following the step-by-step installation, you should now have a running Linux system. Keeping your system updated with the latest versions of utilities and libraries will ensure compatibility with most new applications being developed for Linux and keep your system operating efficiently.

If you do have problems, you’ll find HOWTOs and FAQs on the CD-ROMs that come with this book. Most of them are in HTML format, so you can view them straight from CD-ROM by using a Web browser. Also, the Red Hat Web site (http://www.redhat.com) contains installation documentation and errata sheets for Red Hat Linux.
