You can use the mlabel command to label the disk:

```
# mlabel a: 
Volume has no label 
Enter the new volume label : LINUX
```

You can also use special shell command-line quoting to label the disk from the command line:

```
# mlabel a:'DOS DISK'
```

This is a handy way to use spaces in a disk’s label. If you want to delete files on your disk, use the mdel command:

```
# mdel a:*.txt
```

This deletes all files ending in .txt on the disk in the A drive. You can also mount your disk. For details, see the mount command manual page, along with the mount command manual page.

# # Windowing Network Clients

While software and hardware emulators can ease many computing tasks, the demands on system resources such as memory or storage can be tremendous. If you have extra comput-
ers or work in a networked environment, an easier approach is to use the X Window sys-
tem and networking protocols to communicate with other systems and run other clients.

Thanks to AT&T Laboratories Cambridge and Red Hat, Red Hat Linux users can now enjoy working on the desktops of foreign operating systems with relative ease through virtual networking computing. Even better news is that the software, called vnc, is avail-
able under the GNU General Public License with source code for Linux, comes with the latest version of Red Hat Linux, and if downloaded in source code form, readily builds and installs under Red Hat Linux.

The vnc Linux software consists of several major components: an X server named Xvnc, a server named vncserver, a password utility named vncpasswd, and a network commu-
nication viewer named vncviewer. The vnc software is also available for other comput-
ers and operating systems, such as these:

+   - DEC Alpha OSF1 3.2 
+   - Macintosh OS (68K and PPC)
