# Summary

In this chapter you learned how to install and configure the Internet News service, INN, and how to set up a simpler and more personal NNRP server using Leafnode+. The steps involved may seem a little overwhelming, but if you take them slowly and check everything carefully, you’ll be surprised how little time it takes to have a functional newsfeed on your Linux machine. Remember that you do need a connection available to a newsfeed before you complete and test the INN configuration.
