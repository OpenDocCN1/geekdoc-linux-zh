# # GNOME Panel Configuration

The GNOME Panel is an application and menu launcher for the GNOME desktop. By default, the panel is home for a number of important desktop elements, such as

+   - System menus for a dozen categories of clients, including menus for the AfterStep Level window manager and KDE desktop
+   - GNOME help
+   - GNOME configuration
+   - Virtual desktop navigation through the GNOME pager
+   - A taskbar container for currently running applications
+   - The date and time

The panel is configured by clicking the Panel menu item on the panel's pop-up menu, or by right-clicking a blank area of the panel. The pop-up Panel menu, shown in Figure 5.7.
