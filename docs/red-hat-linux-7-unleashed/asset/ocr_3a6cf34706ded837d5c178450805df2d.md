Usingipop3d gives you the following capabilities:

+   - Refusal to retrieve mail for anyone whose UID is root.
+   - Verbose logging to syslog.
+   - Support for CRAM-MD5 and APOP for user authentication. For these to be enabled, the file/etc/cram-md5.pwd must exist (see the section on setting up APOP support for details).

To allow ipop3d to start from xinetd, edit the/etc/xinetd/ pop3 file and make sure it contains the following:

```
service pop3
{
 disable = no
 socket_type = stream
 wait = no
 user = root
 server = /usr/sbin/ipop3d
 log_on_success += UID
 log_on_failure += UID
}
```

Don't forget to send the HUP signal to xinetd. You can do so by issuing the following command:

```
# /etc/init.d/xinetd reload
```

Now you're ready to test the connection. At a command prompt, enter

```
$ telnet popserver pop-3
```

popserver is the name of the machine running the ipop3d program. The pop-3 at the end is what Telnet will reference in your/etc/services file for port 110. You should get a response similar to the following:

```
+OK POP3 popserver.gonz o.gov v6.50 server ready
```
