+   xiii. Changing Timestamps with touch
+       -   Changes the **access** and **modification** times of files
+       -   Creates files that do not already exist
+       -   Options:

+          -   -a, change only the access time
+          -   -m, change only the modification time
+          -   -t [YYYY]MMDDhhmm[.ss], set the timestamp of the file to the specified date and time
+          -   GNU touch has a -d option, which accepts times in a more flexible format

+   -   For example, to change the time stamp on homework to January 20 2001, 5:59p.m., the syntax is:

```
$ touch -t 200101201759 homework
```

# Linux Disk Management

+   1.  Create Partitions and File systems
+       -   A hard disk provides a single large storage space usually split into **partitions**. The information about partitions is stored in the **partition table**.

+          -   Partition tables in Linux are compatible with Microsoft Windows. In order to be compatible with Windows, at most four primary partitions can be made. But these can be extended partitions, which can themselves be split into smaller logical partitions

+   2.  Disk Naming
+       -   The device files for IDE hard drives are /dev/hda to /dev/hdd, where

+          -   hda and hdb are the drives on the first IDE channel, and hdc and hdd are the drives on the second channel. The first drive on each channel is the IDE master, and the second is the IDE slave.

+       -   Primary partitions are numbered from 1–4
+       -   Logical partitions are numbered from 5
+       -   The devices /dev/hda, etc., refer to the whole hard disk, not just partitions.
