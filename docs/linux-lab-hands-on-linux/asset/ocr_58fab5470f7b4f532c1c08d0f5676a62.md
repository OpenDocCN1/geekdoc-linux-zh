# Connect to a Remote Machine

Using SSH is similar to TELNET. To log onfrom another machine use the ssh command with a -1 to specify the username you wish to log in as. If you leave out the -l, your username will not change. Here are some examples for a server named Netx in your /etc/hosts file. You can also use the user-name@remote_server format as an alternative.

If you are user root and you want to log into netx as yourself, use the following command:

```
[root@netmon tmp]# ssh netx
or
[root@netmon tmp]# ssh 172.16.1.100
```

User root can also log into netx as user aday a via the default port 22:

```
[root@netmon tmp]# ssh -l aday a netx
```

or via port 435 using the username@remote_server alternative login format:

```
[root@netmon tmp]# ssh -p 435 aday a@netx
```

# FIRST LOGIN: Generation of Host keys

The first time you log in, you get a warning message saying that the remote host does not know about your machine and prompts you to store a copy of the remote host’s SSH identification keys on your local machine. This shows the following output: It will look something like this:

```
[root@netmon tmp]# ssh netx
The authenticity of host 'netx (netx)' can't be established.
RSA key fingerprint is
5d:d2:f5:21:fa:07:64:0d:63:1b:3b:ee:a6:58:58:bb.
Are you sure you want to continue connecting (yes/no)? yes
Warning: Permanently added 'netx' (RSA) to the list of known
hosts. root@netx's password:
Last login: Thu Nov 14 10:18:45 2002 from 172.16.1.98
No mail.
[root@netx tmp]#
```

The key is stored in your ~/.ssh/known_hosts file and you should never be prompted for this again.
