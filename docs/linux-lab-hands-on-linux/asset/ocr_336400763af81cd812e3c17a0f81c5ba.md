[root@netmon tmp]# netstat -a | grep telnet

You can also use the chkconfig --list command to start TELNET on the next reboot. The syntax to use the chkconfig --list command is as follows:

[root@netmon tmp]# chkconfig --list | grep telnet
telnet: on
[root@netmon tmp]#

You can deactivate TELNET even after the next reboot by using the chkconfig command. The syntax to use the chkconfig command is as follows: ]

[root@netmon tmp]# chkconfig --level 35 telnet off
