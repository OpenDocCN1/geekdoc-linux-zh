With this you learn to change the TCP port

+   2. No response allows us to proceed. Change the Port line in /etc/ssh/sshd_config to mention 435 and remove the # symbol at the beginning of the line. If the TCP port 435 is already in use then you can use another port.  
+   Let’s now learn to restart SSH:
+   3. Restart SSH by using the following command:

```
[root@netmon tmp]# service sshd restart
```

+   4. Ensure whether or not SSH is running on the new port by using the following command:

```
[root@netmon root]# netstat -an | grep 435
tcp 0 0 172.16.1.100:435 0.0.0.0:* LISTEN
[root@netmon root]#
```
