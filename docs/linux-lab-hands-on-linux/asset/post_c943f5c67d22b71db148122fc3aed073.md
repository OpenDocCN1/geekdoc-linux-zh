## 04 LAB: Linux File System Structure

### OBJECTIVES

1. Understanding the Linux file system structure
2. Understanding the / Directory

5. Working with Linux-supported file systems

### REQUIREMENTS

A standard PC with Linux Distributions (Fedora Core/RHHEL) CDs or a DVD.

### CONCEPT

The Linux/Unix file system always begins with a directory called the root, the root directory is designated by a slash (/). The standards in which the directory tree in the Linux system should be organized are set by File systems Hierarchy Standard (FHS). These standards make it easier to write or port software for Linux and to administer Linux machines, since everything is in an organized manner.

### File System Structure

Whenever you work in the Linux/Unix system, you are working within a directory. One of the most important aspects of the system administration is to understand the organization or layout, of the Linux file system. Proper functioning of system operations is critical if the administrator, programmers, users, or installed software, knows how and where the files are stored on the system. Linux follow the standards outlined in File system Hierarchy Standard (FHS) that specifies locations for specific types of data. For the complete standard, refer to http://www.pathname.com/fhs.

FHS provides specific requirements to organize files in the directory structure. This way of organizing files is based on the type of information contained in the files. There are two categories of files: shareable or unshareable, and variable or static. The files that can be accessed by other hosts are known as shareable files whereas the files that can be accessed only by the local system are known as unshareable files. Static files include binaries, and libraries files that do not change without system administrator intervention while variable files are files that are not static and can be changed at any time. Program documentation and binary files are examples of static files. Figure 1 shows the organization of the file system on a typical Linux system. Following the figure is an explanation of each directory and the types of files it may contain.

### The / Directory (The root File system)

![](img/f3b9cff79e19317416c12eaf5ded7245_51_0.png)

- **/bin**: Consists of commands that are used by both the system administrator as well as non-privileged users. This directory usually contains the shells like bash, csh etc. as well as much used commands like cp, mv, rm, cat, ls.
- **/sbin**: Consists of commands that are specific to the system administrator.
- **/etc**: Contains all the configuration files for your system.
- **/root**: Provides the home directory for the superuser. The superuser is the user who is login with the root account.
- **/lib**: Consists of shared libraries needed by the programs on the root file system.
- **/lib/modules**: Provides you with loadable kernel modules, especially those that are needed to boot the system when recovering from disasters such as, network and filesystem driver.
- **/dev**: contains device files.
- **/tmp**: Refers to the temporary files. Programs running after bootstrap should use /var/tmp, not /tmp because of its size. Often /tmp will be a symbolic link to /var/tmp.
- **/boot**: Consists of files used by the bootstrap loader, such as LILO/GRUB.
- **/mnt**: Refers to mount point for temporary mounts by the system administrator.

### Using File System Commands

- **ls**: Lists files and directories, which are present in Linux operating system as well as those created by the user
- **cp**: Use to copy files
- **rm**: Use to remove files
- **chown**: Use to change file ownership
- **chgrp**: Use to change group permission
- **chmod**: Use to change files and directory permission

### Perform Basic File Management

i. FileSystem Objects
- A file is used to store data. Systems treats a file simply a sequence of bytes
- A directory is a collection of files and other directories
- Directories are organized in a hierarchy, with the **root directory** at the top
- The root directory is referred to as /

ii. **Directory and File Names**
- Files and directories are organized into a **filesystem**
- User can refer to files in directories and sub-directories by separating their names with / , for example:

```
/bin/ls
/usr/dict/words
/home/venky/receipe
```

- Paths to files either start from / (absolute) symbol or from some current directory

iii. **File Extensions**
- A filename always has an extension, beginning with a dot.
- An extension indicates the type of the file.
- On Unix and Linux, file extensions are entirely a matter of convention, the operating system itself ignores them.
- Only a few specific programs use extensions to identify the type of a file.

**Table 1: Basic File Extensions**

| File Extension | Description |
| :--- | :--- |
| .txt | Refers to text file |
| .gif | Refers to Graphics Interchange Format image |
| .jpg | Refers to Joint Photographic Experts Group image |
| .mp3 | Refers to MPEG-2 Layer 3 audio |
| .gz | Refers to compressed file |
| .tar | Refers to Unix 'tape archive' file |
| .tar.gz, .tgz | Refers to compressed archive file |

iv. **Visiting Directories with cd**
- You can change to other directory from the current working directory by using the cd command. For example if you want src to be your current directory, then type the following

```
$ cd /usr/src
```

- If you do not give the directory name as an argument, the cd command navigates you to the home directory.

You can use pwd command to find out the current directory. Syntax for finding the current directory is: $ pwd

v. **Filename Completion**
- Modern shells provides you one of the most useful features of the Linux command line that is automatic file name completion. You do not have to type the complete file names at the Linux command line. Type only the beginning of a file name in the command line and press the Tab key and the shell completes the rest. There may be several files that start with the same letters but have different endings. When you have typed the first letters of a file name and press the Tab key, the shell completes as much as it can and beeps. When you press the Tab key again, the shell shows you all the alternatives.

vi. Wildcard Patterns
- Give commands multiple files by specifying patterns
- You can use the * symbol to match any part of a filename. For example:

```
$ ls *.txt
accounts.txt letter.txt report.txt
```

vii. Copying Files with cp
- You can copy files by using the syntax:

```
cp [options] source-file destination-file
```

- You can copy multiple files into a directory by using the syntax:

```
cp files directory
```

- Common options used with cp command are:
    - -f: overwrites the destination files
    - -i: prompts you before overwriting files
    - -a: archive, copy the contents of directories recursively

viii. Examples of cp command
- Copy /etc/smb.conf to the current directory:

```
$ cp /etc/smb.conf .
```

- Create an identical copy of a directory called work, and call it work-backup:

```
$ cp -a work work-backup
```

- Copy all the GIF and JPEG images in the current directory into images:

```
$ cp *.gif *.jpeg images/
```
