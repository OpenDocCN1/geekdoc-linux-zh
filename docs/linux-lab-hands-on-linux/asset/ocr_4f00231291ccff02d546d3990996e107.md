# ## Using Backup Tools

In Linux, backups refer to packaging and unpackaging files as configuration files. Kernels are system independent. You can backups the File systems to avoid the possibility of data loss due to unforeseen disasters.
The following archiving tools and utilities are used for backup:
- Tar
- cpio
- Dump and restore
- Compression Tools

# ### ■ Tar Utility

The tar utility is popular among Unix system administrators. Following is the syntax of the command used to perform the backup of files in tar utility:
Syntax:

```
tar -cvf <destination> < source>
For example,
tar -cvf /backup/home.back /home
```
