# ## Installing the TELNET Server Software

In Fedora Linux you are required to manually install the Telnet server

Remember that the TELNET server RPM’s filename usually starts with telnet-server followed by a version number. For example:

```
telnet-server~0.17~28.i386.rpm.
```

# ### Setting Up a TELNET Server

Telnet is xinedt managed service. Xinedt is called Internet super server daemon. It is launched at boot time, and listens for connection on network sockets. When xinedt starts up, it checks the xinedt.conf file to see what services should be running. It then reads the /etc/services file to see what ports those services should be running on. After xinedt starts, if there is a connection made on a service port listed (in our case TELNET) in xinedt.conf, xinedt then launches the appropriate network service. So telnet is not standalone service but handle by xinedt daemon.

# ### Xinedt-Managed Server Services

Xinedt-managed services store their configuration files in the /etc/xinedt.d directory. Each configuration file has a disable statement (as shown in following code) that you can set to yes or no. This governs whether xinedt is allowed to start them or not.

Edit following file (/etc/xinedt.d/telnet) and make disable=no

```
Telnet is xinedt-managed service
# default: on
# description: The telnet server serves telnet sessions; it uses \n# unencrypted username/password pairs for authentication
Service telnet
{
flags = REUSE
socket_type = stream
wait = no
user = root
server = /usr/sbin/in.telnetd
log_on_failure + = USERID
disable = yes
}
```

To activate the telnet service we have to actually start xinedt services as telnet is not standalone but managed by xinedt daemon.

```
[root@netmon tmp]# service xinedt restart
```
