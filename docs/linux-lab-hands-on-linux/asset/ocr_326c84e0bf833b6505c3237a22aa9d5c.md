**CONCEPT**

Vi is one of the most popular text editor. Vim (VI IMproved) is a extended and free version of vi text editor. In fedora 10, you will see Vim editor. As vi editor is fully text based. Text bases editors means all activities are performed with the help of text commands. Vi editor allows you to add or insert text, change text or delete text with the help of vi commands. For the beginners, it is required some practice to work on these commands efficiently.

You can start vi editor to open a existing file or a new file. If the file named says ‘filename’ exists, then the first page of the file will be displayed in case, file does not exist, then an empty file and screen are created into which you can enter text.

# ### Vi Modes

Vi editor provides two types of mode:

+   - **Regular mode or command mode**: Allows entering commands. This is the default mode of vi text editor. When you open a file, you enter in the regular mode.
+   - **Insertion mode**: Allows you to insert text in to the file. To switch to insertion mode, just press the key *INSERT* on your keyboard or, by default, the key *i*. To change from insertion mode to command mode, press the *ESC* key.
