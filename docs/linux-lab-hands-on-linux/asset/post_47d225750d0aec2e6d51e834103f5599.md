## Deleting Text

Use the following vi commands to delete text.

| Vi command | Description |
|------------|-------------|
| x | Deletes the character under the cursor |

## Concept of GNU nano Text Editor

GNU nano is a small, free and friendly editor. It is designed to compete the functionality of Pico text editor. Features such as ‘find and replace’ and ‘go to’ line number’ which are disabled by default in Pico text editor, are implemented in this text editor. Nano is a keyboard-centric text editor.

All functions that you want to perform are controlled by keys and key combinations. You can open nano text editor for editing the existing file or for a new file.

You can open the nano from the GNOME Terminal application in fedora 10.

Let us open a new file named as test.

- 1. Open the GNOME Terminal application by selecting **Applications**→**System Tools**→**Terminal** (Figure 1).
- 2. Type nano test command to open nano text editor with new file open. The nano editor window appears (Figure 11)

![](img/f3b9cff79e19317416c12eaf5ded7245_99_0.png)
