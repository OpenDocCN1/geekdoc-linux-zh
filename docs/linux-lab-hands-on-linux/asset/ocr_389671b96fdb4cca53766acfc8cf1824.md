Open file using a text editor and type the following command to open the Squid configuration file:

```
[root@netmon tmp]#vi /etc/squid/squid.conf.
```

In Squid configuration file the default access control lists (acl) appears. You need to define your own ACL (access control list) to work with squid. The defaults port is TCP 3128. Following example ACL allowing access from your local network 172.16.0.0/16. Make sure you adapt to list your internal IP networks from where browsing should be allowed:

```
acl our_network src 172.16.0.0/16
http_access allow our_network
```

Let's now learn ro review the host name in Squid configuration file.

# The Visible Host Name

Squid will fail to start if you don't give your server a hostname. You can set this with the visible_hostname parameter. Here, the hostname is set to the real name of the server netmon.

```
visible_hostname netmon
```

Save and close the file and start squid proxy server. Type the following command to start the Squid proxy server:

```
[root@netmon tmp]#chkcconfig -level 35 squid on
[root@netmon tmp]#/etc/init.d/squid start
```
