# CONCEPTS

Java is an operating system independent platform for software development. It consists of a programming language, utility programs, and run time environment. A Java program can be developed on one computer and run on any other computer with the correct run time environment. In general, older Java programs can run on newer run time environments. Java has gained popularity with the development of the Internet because when you program for the Web using Java, it is not necessary for you to know the operating system that is installed in user's system. With the Java programming language, you can take advantage of the "Write once, run anywhere" paradigm. This implies that when you compile your Java program, you need not to generate instructions for one specific platform. Instead, you need to generate Java byte code, which means instructions for the Java Virtual Machine (Java VM). It does not matter what platform the users use if Java VM is installed on their systems as Java VM understand byte codes.

# Types of Java Programs

+   * **Applet:** Refers to a Java program that is designed to be embedded on a web page. An applet cannot run without a Web browser.

+   * **Servlet:** Refers to a Java program that is designed to be run on a server. A servlet cannot run without a Web server.

+   * **Java application:** Refers to a Java program that can run itself.
