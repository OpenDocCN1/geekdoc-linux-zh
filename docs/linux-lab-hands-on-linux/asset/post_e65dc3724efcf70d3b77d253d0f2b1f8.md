
# Searching packages

- yum search searchterm
- yum list (all|available|extras|installed|recent|updates)
- yum info packagename

The commands to search, list, and gather information about a package name are as follows:

```
[root @ netmon opt]# yum search package_name
[root @ netmon opt]# yum list all|updates
[root @ netmon opt]# yum info package_name
```

# Searching files

The command to search file is as follows:

```
[root @ netmon opt]# yum whatprovides named
```

# Configuring Additional Repositories

You can configure additional repositories by performing the following steps:

- Create a file in /etc/yum.repos.d for your repository
- Gather required information, which is as follows:
  - [repo-name]
  - name=A nice description
  - baseurl=http://yourserver.com/path/to/repo
  - enabled=1
  - gpgcheck=1

For further details, refer to Appendix-C: Yum repository server/client configuration.

# 10 LAB: File System Backup and Restore

**OBJECTIVES**

1. Taking backups using backup tools and restoring them
2. Making ISO images

**REQUIREMENTS**

P4 class PC, 1-GB RAM, 80 GB HDD, NIC with FC6 or RHEL-5 installed.

**CONCEPT**

There are many reasons for loss and corruption of data, such as hardware, software, environment and human errors. This lab deals with performing backups using backup tools and restoring them.

## Using Backup Tools

In Linux, backups refer to packaging and unpackaging files as configuration files. Kernels are system independent. You can backups the File systems to avoid the possibility of data loss due to unforeseen disasters.
The following archiving tools and utilities are used for backup:

- Tar
- cpio
- Dump and restore
- Compression Tools

### Tar Utility

The tar utility is popular among Unix system administrators. Following is the syntax of the command used to perform the backup of files in tar utility:

Syntax:

```
tar -cvf <destination> < source>
For example,
tar -cvf /backup/home.back /home
```

### CPIO Utility

cpio, a conventional Unix program that can be used to backup the file systems. The syntax to use the cpio command is as follows:

```
cpio flags [options]
```

Following is the syntax for creating the cpio file:

```
find (source file name) | cpio - (Options) > (target file name)
```

For example.

```
find filel | cpio -o > file1_back.cpio
```

Following syntax is used for extracting the cpio file:

```
cat <source file name> | cpio - (Options)
```

For example.

```
cat filel_back.cpio | cpio -idvm
```

# Dump and Restore

The dump and restore commands are two different programs that are included in the dump package. Following is the syntax of dump command, which is used to backup the directory into a file:

```
dump - <dump level> - <options> <destination name> <source name>
```

For example.

```
dump -0 -f /home_dumps/mydumps /home
```

![](img/f3b9cff79e19317416c12eaf5ded7245_113_0.png)

The restore command is used to view and restore the dump file. Following is the syntax of the restore command used to view and restore the dump files:

```
# restore -<options> <file name>
```

For example,

```
restore -if mydumps restoration of the dump file
```

# Making ISO Images

1. Make a CD image file of the data.
   /home/CDimage can be used to store the iso9660 image. The following command makes backup.iso from the data in /home/adaya:

```
# mkisofs -J -r -T -o backup.iso /home/adaya
```

2. Inspect the image by mounting it. Following is the command to mount the image:

```
# mkdir /mnt/iso
# mount -t iso9660 -o ro,loop=/dev/loop0 /home/CDimage/backup.iso /mnt/iso
# cd /mnt/iso
```

3. To unmount mounted image, type the following command:

```
# cd
# ummount /mnt/iso
```

4. Copy the file on your PC and use your CD software to burn the image to a CD.

> Double click on the image as the EasyCD or Nero program recongizes the .iso extension. You can use linux CD/DVD writer program K3B to copy the file on your PC.
