```
wu-ftpd: on
rsync: off
eklogin: off
gssftpd: off
klogin: off
```

To turn a service off or on using chkconfig, use the following syntax:

```
chkconfig servicename off|on|reset
```

So to turn off the ftp daemon turned on previously, type:

```
chkconfig wu-ftpd off
```

To turn on xinetd, type:

```
chkconfig xinetd on
```

Run chkconfig --list again to see if the service you changed has been set to the state you desire. Changes you make with chkconfig take place the next time you boot up the system.
