
## Determining Your IP Address

Most modern PCs come with an Ethernet port. When Linux is installed, this device is called eth0.

You can determine the IP address of this device by using the ifconfig command:

```
[root@netmon tmp]# ifconfig -a
```

## Changing Your IP Address

To assign an IP address to the eth0 interface, you can run the following command:

```
[root@netmon tmp]# ifconfig eth0 172.16.1.100 netmask 255.255.0.0 up
```

The `up` at the end of the command activates the interface.

> To make this permanent each time you boot up, you have to add this command in the `/etc/rc.local` file, which is run at the end of every reboot.

## Static IP Address Configuration by Editing

```
[root@netmon tmp]# cd /etc/sysconfig/network-scripts
```

You can use the vi editor to modify the setting.

```
[root@netmon network-scripts]# vi ifcfg-eth0
DEVICE=eth0
IPADDR=172.16.1.100
NETMASK=255.255.0.0
BOOTPROTO=static
ONBOOT=yes
[root@netmon network-scripts]#
```

### Getting the IP Address Using DHCP

Dynamic Host Configuration Protocol (DHCP) is used to obtain IP addresses for dial-in clients. Only the IP address from the DHCP lease is passed to the RAS client.

```
[root@netmon tmp]# cd /etc/sysconfig/network-scripts
[root@netmon network-scripts]# vi ifcfg-eth0
DEVICE=eth0
BOOTPROTO=dhcp
ONBOOT=yes
[root@netmon network-scripts]#
```

### Using ifconfig Command

```
[root@netmon network-scripts]# ifconfig eth0 up
[root@netmon network-scripts]# ifconfig eth0 down
```

OR

The `ifdown` and `ifup` commands can be used to do this:

```
[root@netmon network-scripts]# ifdown eth0
[root@netmon network-scripts]# ifup eth0
```

### Multiple IP Addresses on a Single NIC (Network IP Aliasing)

You can create a virtual interface by using the ifconfig command:

```
[root@netmon tmp]# ifconfig eth0:0 172.16.1.200 netmask 255.255.0.0 up
```

Edit the `/etc/sysconfig/network-scripts/ifcfg-eth0.0` file, so that the aliases will be managed automatically by using the `ifup` and `ifdown` commands. Here is a sample configuration to manage the IP address:

```
DEVICE=eth0:0
ONBOOT=yes
BOOTPROTO=static
IPADDR=172.16.1.200
NETMASK=255.255.0.0
```

The commands to activate and deactivate the alias interface would therefore be:

```
[root@netmon tmp]# ifup eth0:0
[root@netmon tmp]# ifdown eth0:0
```

To test IP addresses, try to ping from another machine on the same network to both addresses.

```
[root@netmon tmp]# ping -c 4 172.16.1.100
[root@netmon tmp]# ping -c 4 172.16.1.200
```

It is always a good practice to make a backup copy of the `ifcfg-eth0` file:

```
[root@netmon tmp]# cd /etc/sysconfig/network-scripts/
[root@netmon network-scripts]# ls ifcfg-eth0
[root@netmon network-scripts]# cp ifcfg-eth0 backup.ifcfg-eth0
```

Edit your `ifcfg-eth0` file to have no IP information and also to be deactivated on boot time.

```
DEVICE=eth0
ONBOOT=no
```

Shut down the eth0 interface:

```
[root@netmon network-scripts]# ifdown eth0
```

Activate network interface:

```
[root@netmon network-scripts]# service network restart
```

It refers to the `ifcfg-eth0` configuration file every time you start the network service.

## Configuring Routing

To view the current routing table, the `netstat -nr` command will provide the contents of the routing table.

```
[root@netmon tmp]# netstat -nr
```

OR

```
[root@netmon tmp]# route -n
```

### Changing Your Default Gateway

Your PC needs to have a single default gateway. DHCP servers automatically assign a default gateway to DHCP-configured NICs, but NICs with static IP addresses will need to have a manually configured default gateway. This can be done with a simple command.

```
[root@netmon tmp]# route add default gw 172.16.1.1 eth0
```

### Adding Routes from the Command Line

The `route add` command can be used to add a new route to your server. In our example, the reference to the 172.16.1.0 network has to be preceded with a `-net` switch, and the subnet mask and gateway values also have to be preceded by the `netmask` and `gw` switches, respectively, shown as follows:

```
[root@netmon tmp]# route add -net 172.16.1.0 netmask 255.255.0.0 gw 172.16.1.1 eth0
[root@netmon tmp]# netstat -nr
```

### Deleting a Route

You can delete the routes added in the previous section by using the following command:

```
[root@netmon tmp]# route del -net 172.16.1.0 netmask 255.255.0.0 gw 172.16.1.1 eth0
```

### Configuring your NIC: Speed and Duplex Settings

You need to use the `mii-tool` to configure the NIC card and set the speed and duplex.

#### Using mii-tool

For setting the speed and duplex of your NIC card, you can use the `mii-tool` command. It is destined to be deprecated and replaced by the newer `ethtool` command, but many older NICs support only `mii-tool`, so you need to be aware of it.

**List NIC speed and configuration**

```
[root@netmon tmp]# mii-tool
eth0: negotiated 100baseTx-FD flow-control, link ok
[root@netmon tmp]#
```

By using the verbose mode `-v` switch, you can get much more information. In this case, negotiation was OK, with the NIC selecting 100Mbps, full duplex mode (FD):

```
[root@netmon tmp]# mii-tool -v

eth0: negotiated 100baseTx-FD flow-control, link ok
product info: Intel 82555 rev 4
basic mode:   autonegotiation enabled
basic status: autonegotiation complete, link ok
capabilities: 100baseTx-FD 100baseTx-HD 10baseT-FD 10baseT-HD
advertising:  100baseTx-FD 100baseTx-HD 10baseT-FD 10baseT-HD flow-control
link partner: 100baseTx-FD 100baseTx-HD 10baseT-FD 10baseT-HD flow-control

[root@netmon tmp]#
```

**Set NIC Configuration**

You can set your NIC to force itself to a particular speed and duplex by using the `-F` switch with any of the following options: 100baseTx-FD, 100baseTx-HD, 10baseT-FD, or 10baseT-HD.

```
[root@netmon tmp]# mii-tool -F 100baseTx-FD eth0
```

**Query NIC with ethtool**

| Command | Description |
| :--- | :--- |
| ethtool -g eth0 | Queries ethernet device for rx/tx ring parameter information. |
| ethtool -a eth0 | Queries ethernet device for pause parameter information. |
| ethtool -c eth0 | Queries ethernet device for coalescing information. |
| ethtool -i eth0 | Queries ethernet device for associated driver information. |
| ethtool -d eth0 | Prints a register dump for the specified ethernet device. |
| ethtool -k eth0 | Queries ethernet device for offload information. |
| ethtool -S eth0 | Queries ethernet device for NIC and driver statistics. |

Refer to Man Pages:

- mii-tool - view, manipulate media-independent interface status
- ethtool - display or change ethernet card settings
