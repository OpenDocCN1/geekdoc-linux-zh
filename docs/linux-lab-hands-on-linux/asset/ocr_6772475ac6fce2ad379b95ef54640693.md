Use the following command to install the Apache package:

```
[root@netmon tmp]# rpm -ivh httpd-ver-release.arch.rpm
```

+   2. Starting Apache

Use the following commands to Apache start at boot:

```
[root@netmon tmp]# chkconfig -level 345 httpd on
[root@netmon tmp]# service httpd start
[root@netmon tmp]# service httpd stop
[root@netmon tmp]# service httpd restart
```

+   3. Test the Apache Process

Use the following to test Apache process

```
[root@netmon tmp]# pgrep httpd
```

+   4. Test from the Client

Open browser and type URL of server. (If you are not able to configure the DNS server, then http://ipaddress_server) You will get a default Apache web page.

+   5. Modifying the httpd.conf File (/etc/httpd/conf/httpd.conf)

Basic Settings:

Sugested modification in above httpd.conf file.

+   i. ServerName Directive:

```
change the default value for ServerName www.<your-domain.com>
ServerName domain-name(ipaddress of server if dns server is not configured.)
```

+   ii. DocumentRoot Directive:

Put the website content in /var/www/html (This is htm1 directory).

Test from the client: Open browser and type URL of server.

If you not configured DNS server,then http://ipaddress_server ) You will get web page of website placed in document root directory.

# Virtual Hosting

+   ■ Named Virtual Hosting:

Multiple websites share singel IP address.

Go to VirtualHost Directive:

+   i. Write the servername of different wesites in VirtualHost directive.

+   ii. In order to host multiple websites on singel Apache, create document directories for them.

+   iii. Use the following commands to create document directories to host multiple websites on a single Apache:

```
[root @netmon tmp]# cd /var/www/html
[root @netmon html]# pwd
```
