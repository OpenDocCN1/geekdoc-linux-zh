# ### Managing Memory

The memory is one of the important hardware components in the computer. All applications need memory to run, rather than other components. Here, is the list of the commands which acknowledges you with the different fields of the memory.

+   * Top: Defines utilities available for any user in Linux. It is just like the Task Manager in Windows and displays a list of the running tasks and various details about each application. The output is automatically updated often. The output of top contains the following fields:  
+       PID, User, PR, NI, VIRT, RES, SHR, S, %CPU, %MEM, TIME+ and COMMAND.  
+       Type the following syntax to run the TOP command in the terminal window:

```
`[root@localhost ~]# top`
```

While some of the fields are not important, but you are required to see the %MEM column. This column displays the percentage of total memory that the application is using.

+   * Vmstat: Shows you the summary information about memory, processes, interrupts, paging and blocks I/O information. The vmstat -S M” shows the memory sizes in MB form, which is easier to read and understand. The Free column shows the free memory we have. The "buff" column shows the amount of buffered memory, and "cache" shows the amount of cached information in the memory.  
+       Type the following syntax to run the Vmstat command in the terminal window:

```
`[root@localhost ~]# vmstat`
```

+   * Free: Shows the certain column which contains the memory related information on your computer. It shows the different columns to show information about Total memory, Used memory and Free memory. Use the "free -m -t” shows you the information in MB units and a row at the bottom gives the Total amount of memory of each column.  
+       Type the following syntax to run the Free command in the terminal window:

```
`[root@localhost ~]# free`
```

# ### Understanding Demand Paging

Linux uses demand paging to load executable images into a process virtual memory. Whenever a command is run, its first part is used in the memory and the rest is mapped into the process's address space and demand paged from disk.
