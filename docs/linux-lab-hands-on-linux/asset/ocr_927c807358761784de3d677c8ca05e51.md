# # Configuring the MySQL Server

# ## The /etc/my.cnf File

The /etc/my.cnf file is the main MySQL configuration file. It sets the default MySQL database location and other parameters.

# ## The Location of MySQL Databases

According to the /etc/my.cnf file, MySQL databases are usually located in a subdirectory of the /var/lib/mysql/ directory. If you create a database named test, the database files will be located in the directory /var/lib/mysql/test.

# ## Adding Administrative Users

To administer MySQL, you need to have at least one administrative account. By default, the root user has full access to your MySQL server database and no password assigned. You can assign a password to the root user using the mysqladmin command. To add the root user as a MySQL administrator, log in as the root user and type the following from a Terminal window (substituting your own password in place of new-password):

Only two steps are necessary for a brand new MySQL installation:

+   1. Make sure MySQL is started.
+   2. Use the mysqladmin command to set the MySQL root passwd.

The syntax for setting the MySQL root password is as follows:

```
`[root@netmon tmp]# mysqladmin -u root password new-password`
```

# ## Accessing MySQL Command Line

MySQL has its own command line interpreter (CLI). You can access the MySQL CLI using the mysql command followed by the -u option for the username and -p, which tells MySQL to prompt for a password. Here user root gains access.

The syntax for access the MySQL CLI:

```
```
[root@netmon tmp]# mysql -u root -p
Enter password:
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 6 to server version: 5.0.22

Type 'help;' or '\h' for help. Type '\c' to clear the buffer.
mysql>
```
```

> Almost all MySQL CLI commands need to end with a semi-colon. Even the exit command used to get back to the Linux prompt needs one too!
