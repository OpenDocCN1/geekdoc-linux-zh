# CONCEPTS

While working with C programming in Windows environment, you use the Turbo C compiler. Under the Linux environment, working on C programming is quite easy. You need to type your program code in a text editor and save the file with .c extension. Linux provide you a tool named GCC (GNU C and C++ compiler) to compile your program. In fact, GCC can compile C and C++ programming languages. Once, your program is compiled and free from any syntax errors or any others types of errors, you can run your program and get the desired output. You can compile and run the program by using the commands. Linux provide you GNOME Terminal application which is a type of command prompt where you can type Linux commands.

While compiling and running your programs code, keep it mind the path where you have save your file. Go to the current directory where your file has been saved or keep the file in the user folder as GNOME Terminal uses the default shell specified for the user who starts the application.

Use the following syntax to compile the program:

```
gcc [filename].c -o [filename]
```

Use the following syntax to run a program

```
./[filename]
```
