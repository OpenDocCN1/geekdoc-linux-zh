## SSH Versions 1 and 2

The original encryption scheme of SSH was adequate but was eventually found to have a number of limitations. Therefore, version 2 was launched. It is advisable to operate your system with version 2 by setting the protocol statement in the /etc/ssh/sshd_config file to 2. You should restart SSH to make the changes effective.

```
#
# File: /etc/ssh/sshd_config
#
Protocol 2
```

In the preceding section you learned the SSH version 1 and 2; let’s now learn to change the TCP port using SSH.

## Change the TCP Port on Which SSH Listens

You can change the TCP port using SSH to secure your TCP/IP network. You can change port 22 to a location that would not interfere with other applications on your system, such as port 435.

Let’s perform the following steps to do this:

1. Use the netstat command to ensure your system is not listening on port 435. Use grep to filter out everything that doesn’t have the string “435”:

   ```
   [root@netmon root]# netstat -an | grep 435
   [root@netmon root]#
   ```

   With this, you learn to change the TCP port.

2. No response allows us to proceed. Change the Port line in /etc/ssh/sshd_config to mention 435 and remove the # symbol at the beginning of the line. If the TCP port 435 is already in use then you can use another port.

3. Let’s now learn to restart SSH. Restart SSH by using the following command:

   ```
   [root@netmon tmp]# service sshd restart
   ```

4. Ensure whether or not SSH is running on the new port by using the following command:

   ```
   [root@netmon root]# netstat -an | grep 435
   tcp 0 0 172.16.1.100:435 0.0.0.0:* LISTEN
   [root@netmon root]#
   ```

## Connect to a Remote Machine

Using SSH is similar to TELNET. To log on from another machine use the ssh command with a -l to specify the username you wish to log in as. If you leave out the -l, your username will not change. Here are some examples for a server named Netx in your /etc/hosts file. You can also use the user-name@remote_server format as an alternative.

If you are user root and you want to log into netx as yourself, use the following command:

```
[root@netmon tmp]# ssh netx
or
[root@netmon tmp]# ssh 172.16.1.100
```

User root can also log into netx as user adaya via the default port 22:

```
[root@netmon tmp]# ssh -l adaya netx
```

or via port 435 using the username@remote_server alternative login format:

```
[root@netmon tmp]# ssh -p 435 adaya@netx
```

## 13 | LAB: File Transfer Protocol (FTP) Server

### OBJECTIVES

To configure Linux FTP server (public FTP and private FTP) using the FTP (VSFTPD) daemon, which is very secure.

### REQUIREMENTS

P-IV class PC, 1-GB RAM, 80 GB HDD, NIC, with FC6 or RHEL-5 and Linux installed.

### CONCEPT

The File Transfer Protocol (FTP) is an established protocol to copy files between servers over the Internet.

In FC-6 or RHEL-5, you can use the FTP program as it is designed to be secure, stable, fast, and scalable.

FTP relies on a pair of TCP ports. It operates using two TCP ports 20 and 21. Port 21 is known as control port. All commands and the response of the FTP server, go over the control port. Port 20 is known as data port that is used for all subsequent data transfers between the client and server.

The FTP server is used to download a file from the server or upload a file to the server. It is a software application that runs the File Transfer Protocol (FTP) and transfers files over the internet. The FTP server is the secure way of sharing file with the help of a client-server model. A popular, and very secure, FTP server available for almost all Linux systems is vsftpd (Very Secure FTP). Installing and setting up vsftpd in a Linux environment is a simple process.

A FTP server attempts to authenticate users that request to use it. You can configure your FTP server to accept requests only from users who have an account on the system running the FTP server (User Access FTP). Alternatively, you can configure the FTP server to accept requests from anyone, with the help of service known as anonymous FTP.

### Anonymous FTP

Anonymous FTP is the selection of Web sites that need to exchange files with numerous unknown remote users. Users can log in as a user ftp or as a user anonymous to get access to the ftp site. By default the root directory of anonymous ftp server is set as /var/ftp/pub. It only allows download services to the anonymous user by default.

### User Access FTP

Users with account on the system can connect via ftp and login by using their username and password. They can download any file and also they can upload file to any directory on FTP server, provided they will have write access to that directory
