## CONCEPT

This lab explains the basic steps of configuring MySQL for use with a MySQL-based application in which the application runs on the same server as the database.

## MySQL Client/Server Packages

The following software packages are required for configuration of MySQL Server/Client:

- **mysql**: Refers to the software package that contains a lot of MySQL client programs (in/usr/bin), several client shared libraries, the default MySQL configuration file (/etc/my.cnf), a few sample configuration files, files to support different languages, and documentation.
- **mysql-server**: Refers to the software package that contains the MySQL server daemon (mysqld) and the mysqld startup script (/etc/init.d/mysqld). The package also creates various administrative files and directories needed to set up the MySQL databases.
- **mysql-devel**: Refers to the software package that contains libraries and header files required for developing MySQL applications.

## Additional Packages

Additional packages available to add functionality to your MySQL databases include:

- **php-mysql**: Refers to the package that contains a shared library to allow PHP applications access to MySQL databases.
- **mod_auth_mysql**: Refers to the package that contains tools to authorize Apache Web server access from data in a MySQL database.
- **perl-DBD-MySQL**: Refers to the package that provides a perl interface to MySQL databases.

Packages including tools for using MySQL databases:

- **MySQL-python**: contains a Python interface to MySQL.
- **qt-MySQL**: Refers to the MySQL drivers for QT SQL classes.

After discussing the MySQL Client/Server packages, let’s now learn how to install the MySQL server.

## Installing the MySQL Server

The MySQL packages are included with the Fedora and RHEL distributions. Type the following command in the command line to check your installation for MySQL packages:

```bash
[root@netmon opt]# rpm -qa|grep mysql *
```

Otherwise, you can install them from CD/DVD distros of Fedora and RHEL by using the following commands:

```bash
[root@netmon opt]# rpm -Uvh mysql-ver.release.arch.rpm
[root@netmon opt]# rpm -Uvh mysql-server-ver.release.arch.rpm
[root@netmon opt]# rpm -Uvh mysql-devel-ver.release.arch.rpm
```

After installing the MySQL server, let's now learn to start MySQL server.

## Starting the MySQL Server

Start the MySQL process before you can create your databases. To configure MySQL to start at boot time, use the chkconfig command given as follows:

```bash
[root@netmon tmp]# chkconfig -level 35 mysqld on
```

You can start, stop, and restart MySQL after boot time using the following service commands:

```bash
[root@netmon tmp]# service mysqld start
[root@netmon tmp]# service mysqld stop
[root@netmon tmp]# service mysqld restart
```

> You need to restart the mysqld process every time you make a change to the configuration file for the changes to take effect on the running process.

Test the mysqld process whether it is running by using the following command:

```bash
[root@netmon tmp]# pgrep mysqld
```

After starting the MySQL server, let’s learn to configure the MySQL server.

## Configuring the MySQL Server

### The /etc/my.cnf File

The /etc/my.cnf file is the main MySQL configuration file. It sets the default MySQL database location and other parameters.

### The Location of MySQL Databases

According to the /etc/my.cnf file, MySQL databases are usually located in a subdirectory of the /var/lib/mysql/ directory. If you create a database named test, the database files will be located in the directory /var/lib/mysql/test.

### Adding Administrative Users

To administer MySQL, you need to have at least one administrative account. By default, the root user has full access to your MySQL server database and no password assigned. You can assign a password to the root user using the mysqladmin command. To add the root user as a MySQL administrator, log in as the root user and type the following from a Terminal window (substituting your own password in place of new-password):

Only two steps are necessary for a brand new MySQL installation:

1. Make sure MySQL is started.
2. Use the mysqladmin command to set the MySQL root passwd.

The syntax for setting the MySQL root password is as follows:

```bash
[root@netmon tmp]# mysqladmin -u root password new-password
```

### Accessing MySQL Command Line

MySQL has its own command line interpreter (CLI). You can access the MySQL CLI using the mysql command followed by the -u option for the username and -p, which tells MySQL to prompt for a password. Here user root gains access.

The syntax for access the MySQL CLI:

```bash
[root@netmon tmp]# mysql -u root -p
Enter password:
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 6 to server version: 5.0.22

Type 'help;' or '\h' for help. Type '\c' to clear the buffer.
mysql>
```

> Almost all MySQL CLI commands need to end with a semi-colon. Even the exit command used to get back to the Linux prompt needs one too!

## Working with MySQL Databases

### Creating a Database with MySQL

Within an interactive mysql session, you can create and modify databases and tables. If you are not already connected to a mysql session, type the following command (assuming the mysql user name of root):

```bash
[root@netmon opt] #mysql -u root -p
Enter password: ******
mysql>
```

The general steps for creating a MySQL database include creating the database name, identifying the new database as the current database, creating tables, and adding data to the tables are as follows:

1. For creating a new database name, use the CREATE DATABASE command at the mysql> prompt. For example, to create a database named allusers, type the following command:

```sql
mysql> CREATE DATABASE allusers;
```

This action creates a database called allusers in the /var/lib/mysql directory.
