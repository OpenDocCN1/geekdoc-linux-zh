# Understanding Kernel Concepts

+   ☐ Kernel types: Monolithic versus modular
+   ☐ Reasons to build a new kernel
+   ☐ Reasons not to build a new kernel

A monolithic kernel is one in which support for all hardware, network protocols, and file systems is built within a single file.

A modular kernel is the standard for most distributions, because they allow a kernel to run on wide variety of hardware.

Systems with monolithic kernels may boot faster than the systems with modular kernels. It uses constant amount of memory (RAM).

In modular kernels, modules are loaded on demand, so they are memory efficient.

+   ☐ To optimize as a router, not a host
+   ☐ To reconfigure the page size to change the allocation of memory addresses between kernel and user space
