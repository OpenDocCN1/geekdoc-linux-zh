# Securing Remote Logins with OpenSSH

You can access a shell remotely on most of the Linux/Unix systems by using various ways. One of the ways is to use the telnet program that is available on most network capable operating systems. OpenSSH is an application, developed for OpenBSD, that uses the SSH protocol to provide secure remote logins and an interactive command interface. A secure remote login application, OpenSSH, was ported to the XTS-400 in order to provide remote login capabilities. SSH is designed and created to provide the best security when you access another computer remotely. It not only encrypts the session but also provides better authentication facilities and features, such as X session forwarding, port forwarding as well as it also increase the security of other protocols. It can use different forms of encryption ranging anywhere from 512 bit to as high as 32768 bits and includes ciphers, such as Advanced Encryption Scheme ( AES ), Triple DES, Blowfish, CAST128, or Arctour. The higher the bits, the longer it takes to generate and use keys as well as to pass data over the connection.
