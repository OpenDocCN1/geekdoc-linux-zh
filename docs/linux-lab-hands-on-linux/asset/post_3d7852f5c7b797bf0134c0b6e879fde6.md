### CONCEPT

Linux is an UNIX based operating system created by Linus Torvalds. It is freely-distributable and open source operating system. Open source refers to a program in which the source code is freely available on the Internet. This source code is open to modification by anyone who uses it. It has only one condition to be followed that changes made to the original source code are to be redistributed over the Internet. The Linux operating system can be installed on any system, which uses x86-compatible microprocessors.

The most obvious advantage of using Linux is the fact that it is free to obtain, while Microsoft are available for a large amount and sometimes with recurring fee. Microsoft licenses typically are only allowed to be installed on a single computer, whereas a Linux distribution can be installed on any number of computers, free of cost.

UNIX is a multiuser and multitasking operating system, which was developed by Bell Laboratories in 1969. It is a trademark that is purely governed by The Open Group conforming to a specification that is known as The Single UNIX Specification. This specification defines the names of the interfaces and behavior of all the mandatory functions such as, memory locking, priority scheduling, and shared memory, performed by Portable Operating System Interface (POSIX) Realtime Extensions developed by Institute of Electrical and Electronic Engineers (IEEE). UNIX as an operating system is commonly used in workstations as compared to the domain of usage of personal computers, mainly due to the features such as portability, flexibility, and power. Apart from these one of the main reason of UNIX been commonly used is its networking capability because unlike other operating systems no additional software is required to get access on network.

UNIX and UNIX like operating systems are capable of running on different hardware components because these operating systems are created using machine independent language. Simplicity, Ability to Focus, Reusable components, Filters, Open File Formats, and Flexibility, are some of the characteristics that are shared by UNIX programs and operating systems.

Linux is self-sufficient operating system based on Linux kernel. A Linux kernel is a central component that manages system's resources (communication between hardware and software components). Linux is a multiuser and multitasking operating system, which means multiple users are able to log in and each user can simultaneously perform multiple tasks. Linux is the most common example of free and open source software (refers to the software of which the source code is used, freely modified, and redistributed by anyone under the terms of the GNU public license and other available free licenses). Linux enables the users to work with either using different interfaces such as, Command Line Interface (CLI) and Graphical User Interface (GUI), or through controls attached with the hardware. K Desktop Environment (KDE) and GNOME are the two commonly used and popular GUI used in Linux.

Some of the computer characteristics managed by Linux are Processor (by scheduling and prioritizing multiple tasks), Memory (by moving processes that exceed the available memory to Swap space), Devices (by supporting various hardware devices and also manages the size of kernel), File systems (by managing different file system formats such as, VFAT, NTFS, or Linux ext3), Security (by providing restricted user access).

Following are the common features of Linux:

1. **No constant rebooting:** Provides you with the functionality of installing and removing new software without rebooting computer.
2. **Start/ stop services:** Enables you to start and stop individual services such as, Web, file, and e-mail services, without either rebooting of computer or interrupting the work of any user and file or process.
3. **Portable software:** Modifies an application or driver to make it work on different computer architecture or operating system.
4. **Downloadable applications:** Helps you to download and install the required application with a single command with the help of tools such as, apt, rpm, and yum.
5. **No settings hidden in code or registries:** Provides you the ability to modify the code according to the requirement because Linux is open source software.
6. **Freedom:** Provides you with the freedom to choose any Linux distribution, access to source code, and also you can add or remove any software according to requirement.

Linux distributions are the packages consisted of one or more programs that are required for performing a single function either for an operating system or to add additional capabilities. These distribution packages are often called as distros. Linux distributions are part of Linux operating systems. It is already stated that Linux is based on Linux kernel. Sources to compile and install Linux operating system completely are consisted in the distribution package. A single Linux operating system consists of many different distribution packages. A user according to the requirement can choose from the various distribution packages to be installed alongwith installation of Linux operating system. Some of the commonly used distribution packages are:

- **Fedora:** Provides you with the graphical interface and configuration tools. Fedora is used for general-purpose distribution. It is a distribution package that is suitable for both server as well as desktop applications.
- **Knoppix:** Provides you with efficient compression mechanism and automatic hardware detection. One of the advantages of Knoppix is that it is a live-CD distribution (refers to distribution package that can be run directly from a CD and does not require a hard drive for its installation).
- **Mandriva:** Uses a RPM based package management alongwith a urpmi tool and configuration tools.
- **Suse:** Refers to a distribution package that is used for desktop installations. Suse consists of configuration tool such as, YaST and is a stable distribution package.
- **Debian:** Refers to a non-commercial project that is based on Open-Source philosophy. Debian provides three branches: Stable (refers to latest release), Unstable (refers to branch that is in perpetual evolution), and Testing (represents the next release to be).
- **Ubuntu:** Refers to a distribution package based on Unstable branch of Debian distribution. Features of Ubuntu distribution of Linux includes fast release cycle, up to date and numerous packages, fast download mirrors, great documentation.

Linux installation involves a number of steps. Red Hat/Fedora Core supports several methods to install Linux. You can install Linux from local and network or Internet sources. The examples of local sources are CD-ROM and hard disk and the examples of network or Internet sources are Red Hat/FC support NFS, FTP, and HTTP installations.

## Learning about Hardware Requirements

The minimum hardware requirements to install a standard Linux on an Intel-based PC are as follows:

- A 32-bit Intel-based or Pentium-class personal computer.
- A CD-ROM or DVD-ROM drive (if you are using the DVD-ROM).
- The standard installation of basic software packages normally takes 3GB of hard disk space, plus 256MB to 512 MB for swap space, depending on the amount of RAM memory you have.

1. Recommended/Suggested Hardware Setup: Standard P-IV class PC, with 1GB RAM, and 80 GB HDD with NIC. (for Dual/Multi Boot Systems and Virtualization)
2. It should be kept in mind that Linux can run on far less on a minimum installation (as little as 100MB and 16MB swap).
3. You can install Linux on i386 Intel, Apple Macintosh and 64bit AMD processors. For that download the i386 images for 32 Intel Processors; PPC images for Apple Macintosh and x86_64 for 64 bit AMD Processors.
