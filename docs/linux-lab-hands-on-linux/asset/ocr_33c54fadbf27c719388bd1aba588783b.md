# ### Modifying Existing User Information

You can modify the existing user information by changing the passwords, home directory of a user, UIDs and GIDs, expiration date of an account and so on. Let’s discuss these features in the following sections.

Modification in the existing user information means as – a change in the user’s password, their home directory, expiration date of user account, User Identification (UID) and Group Identification (GID). Let’s change the home directory, UIDs, GIDs, and account expiration information of a user in the following sections.

# #### Changing the User’s Home Directory

To change a user’s home directory, you can run the following command:

```
#usermod -d <new homedir> <username>
```

Similarly, if you want to change the Mahendra’s home directory from /home/Mahendra to /home/mahen, run the following command:

```
#user mod -d /home/mahen Mahendra
```

To change Mahendras’s home directory along with the information that’s contained in Mahendra’s home directory(/home/Mahendra) to the new location(/home /mahen), run the following command:

```
#user -d -m /home/mahen Mahendra
```

This command moves all files of the Mahendra’s current directory (/home/Mahendra) to the new home directory(/home/mahen).

# #### Changing UIDs and GIDs

In Linux every user have UID and GID. The UID of a user is an integer value used to identify user within the Linux system whereas the GID(an integer value) of a user represent a specific group to which the user belong.If you want to change a user’s UID, run the following command:

```
#usermod -u <UID> <username>
```

The following command changes Mahendra’s UID to S5S:

```
#usermod -u S5S Mahendra
```

To change a user’s GID, run the command:

```
#usermod -g <GID> <username>
```

The following command changes Mahendra’s GID to S5S:

```
#usermod -g S5S mahendra
```
