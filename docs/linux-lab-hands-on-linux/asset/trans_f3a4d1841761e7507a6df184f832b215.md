
## 创建安装映像服务器

首先，让我们执行以下步骤来创建一个安装映像服务器：

1.  将 FTP 和 HTTP 服务器配置为安装映像服务器
    - 为 FTP 和 HTTP 服务器创建安装目录（发行版）：
2.  由于 Linux 发行版（Red Hat 和 Fedora）包含三张或更多的光盘。您必须将所有可用光盘的内容安装到服务器硬盘的相同目录结构中。

```bash
# mkdir /tmp/rh
# mount /mnt/cdrom                                  With first CD inserted
# cp -r /mnt/cdrom/* /tmp/rh/
# umount /mnt/cdrom; eject /mnt/cdrom
# mount /mnt/cdrom                                    With second CD inserted
# cp -r /mnt/cdrom/* /tmp/rh/
# umount /mnt/cdrom; eject /mnt/cdrom
# mount /mnt/cdrom                                    With third CD inserted
# cp -r /mnt/cdrom/* /tmp/rh/
# umount /mnt/cdrom; eject /mnt/cdrom
```

当提示覆盖某些文件时，只需输入 `y`。发行版目录必须至少包含 `RPMS` 和 `base` 目录，这些目录必须包含所有必要的软件包。

创建安装目录后，现在让我们配置搭建 Linux 安装映像服务器所需的不同服务器。

### 设置 NFS 作为安装映像服务器

#### 创建 ISO 映像

创建安装光盘的 ISO 映像，并将它们放置在 `/distro/fc6` 目录中，如下文所述。这也需要大约 4GB 的空间。您可以从 Fedora 网站下载 ISO 映像，或者使用 Fedora 光盘。如果您从给定光盘中创建 ISO 文件，它们的文件名必须与从 Fedora 网站下载的文件的文件名相同。

```bash
# Create a directory distro for Linux distribution under / directory.
[root@netmon tmp]# mkdir /distro
[root@netmon tmp]# mkdir /distro/fc6
```

对于第一张光盘，您需要执行的代码是：

```bash
[root@netmon tmp]# cd /distro/fc6
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc1.iso bs=32k
...
[root@netmon fc6]# eject cdrom
```

对于第二张光盘，请使用：

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc2.iso bs=32k
[root@netmon fc6]# eject cdrom
```

对于第三张，请使用：

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc3.iso bs=32k
[root@netmon fc6]# eject cdrom
```

对于第四张，请使用：

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc4.iso bs=32k
[root@netmon fc6]# eject cdrom
```

最后，使用此代码安装第五张光盘：

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc5.iso bs=32k
[root@netmon fc6]# eject cdrom
```

替代方法：您可以使用 `mkisofs` 命令来制作 ISO 文件。

首先使用以下代码挂载 Linux 发行版 DVD：

```bash
[root@netmon fc6]# mount /mnt/cdrom
[root@netmon fc6]# mkisofs -3 -r -T -o FC6-DVD.iso /mnt/cdrom
[root@netmon fc6]# eject cdrom
```

现在您可以选择配置 FTP、HTTP 或 NFS 服务器服务来共享发行版目录。您接下来做什么取决于您使用的安装服务器服务类型。

#### 在 NFS 下导出 /distro/fc6

在 `/etc/exports` 文件中添加条目以共享您创建的发行版目录。此条目将使该目录以只读形式可供任何计算机访问：

```bash
/distro/fc6 (ro)
```

接下来，以 root 用户身份输入以下内容以重启 NFS 服务器：

```bash
[root@netmon fc6]# service nfs restart
```

如果您的服务器 IP 地址是 172.16.1.100，那么从您的共享目录安装该发行版的计算机将识别它为 `172.16.1.100:/distro/fc6`。

#### Web 服务器

如果您的计算机配置为 Web 服务器，您只需使发行版目录可用即可。例如，创建发行版目录后，输入以下代码：

```bash
[root@netmon fc6]# ln -s /tmp/rh /var/www/html/rh
```

如果您的计算机名为 `netmon.spit.ac.in`，您将把安装服务器识别为 `http://netmon.spit.ac.in/rh`。

#### FTP 服务器

如果您的计算机配置为 FTP 服务器，您需要像对 Web 服务器所做的那样，简单地使发行版目录可用。例如，按照上述说明创建发行版目录后，输入以下代码：

```bash
# ln -s /tmp/rh /var/ftp/pub/rh
```

如果您的计算机名为 `it.spit.ac.in`，您将把安装服务器识别为 `ftp://it.spit.ac.in/rh`。

![](img/f3b9cff79e19317416c12eaf5ded7245_39_0.png)

这是您未来进行网络安装时唯一需要的光盘。

### 启动网络安装

让我们执行以下步骤来启动网络安装：

1.  将您的 Linux 客户端计算机连接到网络。
2.  使用第一张 Fedora 安装光盘启动您的系统。
3.  在启动提示符处输入命令 `linux askmethod`。
4.  按 Enter 键。
5.  按照实验 1 中提到的常规步骤操作，直到提示输入安装方法。
6.  从以下选项列表中按喜好选择网络选项：
    - 本地光驱 (Local CDROM)
    - 硬盘 (Hard Drive)
    - NFS 映像 (NFS Image)
    - FTP
    - HTTP
7.  选择安装客户端连接安装服务器网络所使用的以太网设备。
8.  在“配置 TCP/IP”屏幕上选择静态方法并分配 IP 地址。

如果您选择 NFS 方法，将显示 NFS 设置菜单（图 1）。对于 NFS 服务器名称，输入安装服务器的 IP 地址。在这种情况下，它是 172.16.1.100。对于 Red Hat 目录，指定 `/distro/fc6`。

![](img/f3b9cff79e19317416c12eaf5ded7245_40_0.png)

▲ 图 1

如果您选择 HTTP 方法，将显示 HTTP 设置菜单（图 2）。当提示输入网站名称时，输入安装服务器的 IP 地址。在这种情况下，它是 172.16.1.100。不要在开头添加 `http://`。Red Hat 目录是 `/tmp/rh`。剩余的菜单将是常规 Fedora 安装界面的文本版本。

![](img/f3b9cff79e19317416c12eaf5ded7245_40_1.png)

▲ 图 2

如果您选择 FTP 方法，将显示 FTP 设置菜单（图 3）。将安装服务器的 IP 地址输入为 FTP 站点名称（再次是 172.16.1.100）。如果您未选中“非匿名 FTP”框，Red Hat 目录 simply 是 `/`。剩余的菜单将是常规 Fedora 安装界面的文本版本。如果您确实选中了“非匿名 FTP”框，则 Red Hat 目录是 `/tmp/rh`。输入您的特殊 FTP 用户帐户的用户名和密码。剩余的菜单将是常规 Fedora 安装界面的文本版本。

![](img/f3b9cff79e19317416c12eaf5ded7245_41_0.png)

其余安装步骤与我们在实验 1 中进行的基于媒体（光盘和硬盘）的安装类似。

## Linux 双启动

Linux 与 Windows 或其他任何操作系统共存。管理员通常喜欢让系统双启动。您可以设置机器在启动时提示您选择要运行的操作系统。

默认情况下，您应该始终先安装 Windows 操作系统。由于 Linux 允许您在安装期间配置引导加载程序，从而可以启动多个操作系统，如图 4 所示：

![](img/f3b9cff79e19317416c12eaf5ded7245_41_1.png)

### 硬盘分区

- 您必须为每个操作系统在硬盘上创建单独的分区。
- 如果您使用其他操作系统对磁盘进行分区，只需保留未分区/未格式化的空闲空间供 Linux 使用，最少约为 10 GB。（这取决于 Linux 发行版）
- Linux 安装的其余部分与实验 1 中描述的相同。

> 在安装 Linux 时，不要触碰 Windows 分区，利用未分配的分区（空闲空间）从中创建 /（根分区）、swap 和 /boot 分区。

![](img/f3b9cff79e19317416c12eaf5ded7245_42_0.png)

▲ 图 5

如图 5 所示，`/dev/hda1` 是 Windows 分区，`/dev/hda8` 是主 Linux 分区。这样，两个操作系统就可以在单个硬盘上共存。
