The Scilab window contains the following control buttons.

+   □ Stop: Interrupts the execution of Scilab and enters in pause mode.

+   □ Resume: Continues execution of a function after a pause is entered as a command or generated by the Stop button or the Control C key combination.

+   □ Abort: aborts execution after one (or several) pause, and returns to top-level prompt.

+   □ Restart: Clears all variables and executes startup files.

+   □ Quit: Quits Scilab.

+   □ Kill: Kills the Scilab shell script.

+   □ Demos: Provides interactive run of some demos.

+   □ File Operations: Provides facility for loading functions or data into Scilab, or executing script files.

+   □ Help: Invokes on-line help and the names of the corresponding items.

+   □ Graphic Window Icon: Selects active graphic window.

> New buttons can be added by the addmenu command.
