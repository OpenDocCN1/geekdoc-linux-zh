
## Creating an Installation Image Server

First of all, let's perform the following steps to create an installation image Server:

1.  Setting up FTP and HTTP Server as Installation Image Server
    - Creating Installation Directory (Distribution) for FTP and HTTP Server:
2.  Because there are three or more CDs in the Linux distribution (Red Hat and Fedora). You must install all the contents of available CDs in the same directory structure on the server's hard disk.

```bash
# mkdir /tmp/rh
# mount /mnt/cdrom                                  With first CD inserted
# cp -r /mnt/cdrom/* /tmp/rh/
# umount /mnt/cdrom; eject /mnt/cdrom
# mount /mnt/cdrom                                    With second CD inserted
# cp -r /mnt/cdrom/* /tmp/rh/
# umount /mnt/cdrom; eject /mnt/cdrom
# mount /mnt/cdrom                                    With third CD inserted
# cp -r /mnt/cdrom/* /tmp/rh/
# umount /mnt/cdrom; eject /mnt/cdrom
```

Just type `y` when it asks to overwrite some files. The distribution directory must contain at least `RPMS` and `base` directories, which must include all necessary software packages.

After creating an installation directory, now let's configure different servers required to set up the Linux install image server.

### Setting up NFS as Installation Image Server

#### Creating ISO images

Create ISO images of the installation CDs, and place them in the `/distro/fc6` directory as discussed below. This requires about 4GB space as well. You can download the ISO images from the Fedora Web site or use the Fedora CDs. If you create the ISO files from the given CDs, they must have the same file names as the ones you can download from the Fedora Web site.

```bash
# Create a directory distro for Linux distribution under / directory.
[root@netmon tmp]# mkdir /distro
[root@netmon tmp]# mkdir /distro/fc6
```

For the first CD, the code you need is:

```bash
[root@netmon tmp]# cd /distro/fc6
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc1.iso bs=32k
...
[root@netmon fc6]# eject cdrom
```

For the second CD, use:

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc2.iso bs=32k
[root@netmon fc6]# eject cdrom
```

For the third, use:

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc3.iso bs=32k
[root@netmon fc6]# eject cdrom
```

For the fourth, use:

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc4.iso bs=32k
[root@netmon fc6]# eject cdrom
```

Finally, use this code to install the fifth CD:

```bash
[root@netmon fc6]# dd if=/dev/cdrom of=FC6-i386-disc5.iso bs=32k
[root@netmon fc6]# eject cdrom
```

Alternative method: You can use `mkisofs` command to make ISO files.

You first mount Linux distribution DVD by using the following code:

```bash
[root@netmon fc6]# mount /mnt/cdrom
[root@netmon fc6]# mkisofs -3 -r -T -o FC6-DVD.iso /mnt/cdrom
[root@netmon fc6]# eject cdrom
```

Now you have a choice of configuring either FTP, HTTP or NFS Server Services to share distribution directory. What you do next depends on the type of install server services you are using.

#### Export /distro/fc6 under NFS

Add entry to the `/etc/exports` file to share the distribution directory you created. This entry would make the directory available in read-only form to any computer:

```bash
/distro/fc6 (ro)
```

Next, restart NFS server typing the following as root user:

```bash
[root@netmon fc6]# service nfs restart
```

If your server IP address is 172.16.1.100, the computer installing the distribution from your shared directory would identify it as `172.16.1.100:/distro/fc6`.

#### Web Server

If your computer is configured as a web server, you need to simply make the distribution directory available. For example, after creating the distribution directory, type the following code:

```bash
[root@netmon fc6]# ln -s /tmp/rh /var/www/html/rh
```

If your computer were named `netmon.spit.ac.in`, you would identify the install server as `http://netmon.spit.ac.in/rh`.

#### FTP Server

If your computer is configured as a FTP server, you need to simply make the distribution directory available in the same way you did with the web server. For example, after creating the distribution directory as described above, type the following code:

```bash
# ln -s /tmp/rh /var/ftp/pub/rh
```

If your computer were named `it.spit.ac.in`, you would identify the install server as `ftp://it.spit.ac.in/rh`.

### Starting Network Installation

Let's perform the following steps to start the network installation:

1.  Connect your client Linux box to network.
2.  Boot your system by using the first Fedora installation CD.
3.  Enter the command `linux askmethod` at the boot prompt.
4.  Press the Enter key.
5.  Go through the usual steps as mentioned in Lab 1 until prompted for the installation method.
6.  Select the network option of your choice from the following list of choices:
    - Local CDROM
    - Hard Drive
    - NFS Image
    - FTP
    - HTTP
7.  Select the Ethernet device with which the installation client is connected to the installation server network.
8.  Select static method in the Configure TCP/IP screen and assign IP address.

If you select the NFS method, you are shown the NFS Setup menu (Figure 1). Enter the IP address of the installation server for NFS Server Name. In this case, it is 172.16.1.100. For Red Hat Directory, specify `/distro/fc6`.

![](img/f3b9cff79e19317416c12eaf5ded7245_40_0.png)

▲ Figure 1

If you select the HTTP method, you are shown the HTTP Setup menu (Figure 2). Enter the IP address of the installation server when prompted for a Web site name. In this case, it is 172.16.1.100. Do not add an `http://` to the beginning. The Red Hat directory is `/tmp/rh`. The remaining menus will be text-based versions of the usual Fedora installation screens.

![](img/f3b9cff79e19317416c12eaf5ded7245_40_1.png)

▲ Figure 2

If you select the FTP method, the FTP Setup menu is shown (Figure 3). Enter the IP address of the installation server as the FTP site name (172.16.1.100 again). If you do not select the Non-Anonymous FTP box, the Red Hat directory is simply `/`. and the remaining menus will be text-based versions of the usual Fedora installation screens. If you do select the Non-Anonymous FTP box, then the Red Hat directory is `/tmp/rh`. Enter the username and password of your special FTP user account. The remaining menus will be text-based versions of the usual Fedora installation screens.

![](img/f3b9cff79e19317416c12eaf5ded7245_41_0.png)

Rest of installation steps are similar as we carried out in Media (CDROM and Hard Drive) based installation in LAB 1.

## Dual Booting Linux

Linux co-exists with windows or with any other operating system. Administrators often like to dual-boot their systems. You can set up your machine to prompt you to choose which OS you want to run at boot time.

By default, you should always install windows operating system first. As Linux allows you to configure the bootloader during installation so that you can boot multiple operating systems, as shown in Figure 4:

![](img/f3b9cff79e19317416c12eaf5ded7245_41_1.png)

### Partioning of the Hard Disk

- You must create separate partitions on your hard drive for each operating system.
- If you use other operating system to partition your disk, simply leave the unpartitioned/unformatted free space available for Linux minimum around 10 GB. (It varies with Linux distribution)
- Rest part of Linux installation is same as described in LAB 1.

> During installation of Linux, do not touch Windows partitions, utilize the unallocated partition (free space) to create / (root partition), swap and /boot partitions out of it.

![](img/f3b9cff79e19317416c12eaf5ded7245_42_0.png)

▲ Figure 5

As shown in Figure 5, `/dev/hda1` is windows partition and `/dev/hda8` is main Linux partition. This way both the operating systems are co-exist on the single hard drive.
