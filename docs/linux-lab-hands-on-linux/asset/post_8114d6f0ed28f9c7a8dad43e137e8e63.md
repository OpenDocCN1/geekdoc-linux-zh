## 03 LAB: Linux User Administration

### OBJECTIVES

- 1. Creating a user account and assigning it to a particular group.
- 2. Changing the expiration date of a particular user or group.
- 3. Deleting a particular group or a user account.

### REQUIREMENTS

A standard PC with Linux operating system

### CONCEPTS

System administration or sysadmin defines the roles and responsibilities of an individual who maintain and operate a computer system. System administrator is the main user of the Linux that handles the different tasks in the system, such as the hardware devices installations, configuring application software (Open Office suite) and upgrades, managing the file and directories, creating user accounts, backing up and restoring files, installing software package management as well as managing memory and managing process. Linux operating system is a multiuser, multitasking operating system. Multiuser features enables many people to have their accounts on Linux system and work with the Linux operating system. You can assign each person his with his own login account. Similary, multitasking feature enables you to schedule and execute multiple tasks (program) simultaneously. You can create users and groups in Linux using the user add command for creating user and, add group for adding group in Linux and can also modify, and delete user accounts and group.

As an administrator, you need to handle two most important responsibilities that are to look after the administration and monitoring the users on a Linux network. There are some basic command line tools that you have to know in order to create, monitor, and delete user accounts on a Linux network.

#### Basic Command Line Tools

In this section, we explain how to create, modify, delete, and disable user accounts using command line tools in Unix environment.

- ■ Creating a User
  - Creating a new user account is quite easy. For this, you just need to run the useradd command from the command line. For example, to create a user called Mahendra, you can run useradd command as follows:

    ```
    #useradd Mahendra
    ```

    This adds a new entry in /etc/passwd file. By default, this file stores all user account related information.

    There is no default password for the previously created user Mahendra. In order to create a password for this user, you just need to type the passwd command on the command line as follows:

    ```
    #passwd Mahendra
    ```

    This will prompt you to enter a password. Enter the password and press enter. You will be asked to confirm the password. Type the password again and press enter. As long as you typed the same password in both times, you have finished adding a new user. If you did not enter the same password both times, you will be asked to reenter the password again until you confirm it correctly.

- CASE 1: Let's take an example where you have a group of users from an IT department.
- They regularly use a spreadsheet application on a system. You could create a new group called finance and make it the default group for spreadsheets. To create a group, run the following groupadd command:

  ```
  #groupadd finance
  ```

  Now, if you need to create a spreadsheet user named mahendra, you could use the following command:

  ```
  #useradd Mahendra -g finance
  ```

  This command creates a user named mahendra with a default group of finance.

  If existing users need to be placed in the IT group, you could run the following command:

  ```
  chgrp deven IT
  ```

  It would make the IT group deven's new default group. If you need to make a particular user a member of more than one group at a time, use the -G option with the useradd command:

  ```
  useradd mahendra -G IT, finance
  ```

  The preceding command creates the user mahendra with a default group of Mahendra. At the same time, this user also becomes a member of the groups IT and finance. To see the existing groups and the members, run the following command:

  ```
  #cat /etc/group
  ```

  The etc/group file have four segments (group name:password:group ID:users) that are separated by colons. By seeing this file you can find the groups to whom Mahendra belong.

#### Modifying Existing User Information

You can modify the existing user information by changing the passwords, home directory of a user, UIDs and GIDs, expiration date of an account and so on. Let’s discuss these features in the following sections.

Modification in the existing user information means as – a change in the user’s password, their home directory, expiration date of user account, User Identification (UID) and Group Identification (GID). Let’s change the home directory, UIDs, GIDs, and account expiration information of a user in the following sections.

##### Changing the User’s Home Directory

To change a user’s home directory, you can run the following command:

```
#usermod -d <new homedir> <username>
```

Similarly, if you want to change the Mahendra’s home directory from /home/Mahendra to /home/mahen, run the following command:

```
#usermod -d /home/mahen Mahendra
```

To change Mahendra’s home directory along with the information that’s contained in Mahendra’s home directory(/home/Mahendra) to the new location(/home/mahen), run the following command:

```
#usermod -d -m /home/mahen Mahendra
```

This command moves all files of the Mahendra’s current directory (/home/Mahendra) to the new home directory(/home/mahen).

##### Changing UIDs and GIDs

In Linux every user have UID and GID. The UID of a user is an integer value used to identify user within the Linux system whereas the GID(an integer value) of a user represent a specific group to which the user belong.If you want to change a user’s UID, run the following command:

```
#usermod -u <UID> <username>
```

The following command changes Mahendra’s UID to 555:

```
#usermod -u 555 Mahendra
```

To change a user’s GID, run the command:

```
#usermod -g <GID> <username>
```

The following command changes Mahendra’s GID to 555:

```
#usermod -g 555 mahendra
```

##### Changing an Account Expiration date

If you need a temporary access on a system, you can set the expiry date of an account. The administrator can change the account expiration date so that the account is disabled on a set date. If you want to change the account expiration date of a user, run the following command:

```
#usermod -e MM-DD-YYYY <username>
```

In the preceding command MM-DD-YYYY represents the month, day and year; two-digit year fields are also accepted.

Let's take an example where you want an account for user deven to be expired on March 1, 2010. You can use the following command for this purpose:

```
usermod -e 03/01/10 deven
```

This command resets the account expiration date for the user deven to March 1, 2010.

##### Changing Finger Information

If you want to have the information about users on a system, you can use the following finger command:

```
#finger <username>
```

You can obtain the user's full name, office location, and phone number from the preceding finger command. For example, to get the user deven full name, terminal name, home directory type the finger command as follows:

```
#finger -l deven
```

The preceding command prints the terminal name, home directory, mail status, home phone number of the user deven.

The chfn command is used to change a user's finger information. To change finger information for deven, type the chfn command as follows:

```
#chfn deven
```

If you not specified which information (whether Full name, Phone number or directory) you want to change, you'll be prompted for each field information for the user. At the prompt, you can enter the new information, or just press return to leave the field unchanged or enter the keyword "none" to make the field blank.

##### Deleting Users

The userdel command is used to delete a user account. In order to delete previously created user, Mahendra, type the userdel command as follows:

```
#userdel Mahendra
```
