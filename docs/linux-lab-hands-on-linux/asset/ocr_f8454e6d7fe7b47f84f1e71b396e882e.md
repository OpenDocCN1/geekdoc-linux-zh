# The kill Command

The kill command is used on Linux and other Unix-like operating systems to terminate processes without having to log out or reboot (i.e., restart) the computer.

Now, if you want to terminate, for example, the emacs process you need to look up the process identifier (PID) in the preceding listing (3216), and provide the following command:

```
$ kill -9 3216
```

The -9 ensures execution of the process for which you access the command..

A convenient short cut to give the kill command is the Alt-Ctrl-Esc key combination, which allows you to simply click the application that you want to kill.

# The killall Command

The killall commandis used to kill process by name. killall sends a signal to all processes running any of the specified commands.

let’s the user specify a process by name.

For example, to kill all instances of Netscape, type the following command:

+   - killall netscape

You should remain careful while using the killall command. Let’s say you’re using instances of the Emacs editor, running to edit the file foo.txt and /etc/passwd. If you want to kill the instances of Emacs used to edit foo.txt. Both the instance of Emacs used to edit foo.txt and /etc/passwd will be terminated when you use the command kill emacs.
