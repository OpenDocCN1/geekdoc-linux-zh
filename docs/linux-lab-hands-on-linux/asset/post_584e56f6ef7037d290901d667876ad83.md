### Learning Installation Methods

The following installation methods are available:

- **CD-ROM**: Installing from a set of installation CDs is the most direct method. Insert the media into the system, make sure the BIOS is configured to boot from the CD.
- **Hard Drive**: Installing from the hard drive requires the ISO images of the installation CDs to be on a hard drive partition accessible by the installation program (formatted as ext2, ext3, or vfat). It also requires a boot CD created from the boot.iso image that is found on the first installation CD.
- **Network Install (via NFS, FTP, or HTTP)**: This method also requires a boot CD created from the boot.iso image or PXE boot. After booting, select a preferred network installation method, such as NFS, FTP, or HTTP. The installation source must be available to the system using the selected network protocol.
- **Kickstart**: Kickstart is the name of the Red Hat scripted installation method. A kickstart-formatted script is written, the installation program is started with a boot CD or via PXE and then given the location of the kickstart file.

### General Description of Naming Disks and Devices

Linux treats a device as a file in the `/dev` directory, where the hard disk names start with `/dev`.

Table 1 lists the device names for hard disk and floppy drives.

**Table 1: Hard Disk and Floppy Drive Names**

| Name | Description |
| :--- | :--- |
| /dev/hda | First Integrated Drive Electronics (IDE) hard drive (the C: drive in DOS and Windows) connected to the first IDE controller as the master drive. |
| /dev/hdb | Second (IDE) hard drive connected to the first IDE controller as the slave drive. |
| /dev/hdc | First (IDE) hard drive connected to the second IDE controller as the master drive. |
| /dev/hdd | Second (IDE) hard drive connected to the second IDE controller as the slave drive. |
| /dev/sda | First Small Computer System Interface (SCSI) drive and SATA. |
| /dev/sdb | Second SCSI drive. |
| /dev/fd0 | First floppy drive (the A: drive in DOS). |
| /dev/fd1 | Second floppy drive (the B: drive in DOS). |

### Mounting a File System on a Device

In Linux, you use a physical disk partition by associating it with a specific part of the file system. This arrangement is a hierarchical directory, which is also known as a directory tree. If you have more than one disk partition, you can use all of them in Linux under a single directory tree. All you have to do is to decide which part of the Linux directory tree should be located on each partition. This process is known as mounting a file system on a device (a disk partition is a device) in Linux.

The term mount point refers to the directory you associate with a disk partition or any other device.

### Understanding the Swap Partition

Most advanced operating systems support the concept of virtual memory, where your system’s hard disk functions as an extension of the physical memory (RAM). It is called as swap space. When the operating system runs out of physical memory, it can move (or swap out) the contents of currently unneeded parts of RAM to the swap partition on the hard disk to make room for a program that needs more memory. When the operating system needs to access anything in the swapped-out data, it has to find something else to swap out and then it swaps in the required data from the disk. This process of swapping data back and forth between the RAM and the disk is also known as paging.

As you know, the disk is much slower than RAM, so the system’s performance is slower when it performs a lot of paging. However, virtual memory enables you to run programs that you otherwise cannot run. Linux supports virtual memory and can make use of a swap partition. When you create the Linux partitions, you should also create a swap partition.

You can easily create a swap partition by using the Disk Druid utility program, described in the next section.

### Preparing Disk Partitions for Linux

It is important to note that a minimum of two partitions need to be created for Linux installations, which are as follows:

- The first partition is `/` (root partition). The minimum size of the root partition varies from 2GB to 8GB depending on the installation of software packages.
- The second partition is the SWAP partition (virtual drive). The recommended size of this partition is twice the RAM size or 1 GB, whichever is larger.

We can have `/boot`, `/var`, and `/home` as separate partitions.

As shown in Figure 5, Disk Druid displays partition information in the following fields:

- **Mount Point**: Indicates the directory where the partition is mounted. For example, if you have only one partition for the entire Linux file system, the mount point is the root directory (`/`). For the swap partition, this field shows `<Swap>`. If this field appears as `<not set>`, you have to specify a mount point, which you can do by selecting the partition and clicking the Edit button.
- **Device**: Refers to the partition’s device name. For example, `hda1` is the first partition on the first IDE drive.
- **Requested field**: Shows how much space the partition has. For example, if the partition has 256MB of space, this field appears as 256M.
- **Actual field**: Shows the amount of disk space the partition is using. Usually, the Requested and Actual fields are the same, but they may differ for partitions that can grow in size.
- **Type field**: Shows the partition’s type, such as Linux Native or DOS. If there are no partitions defined, the table in the Partitions list is empty. You have to add new partitions by clicking the Add button.

You can perform specific disk setup tasks in Disk Druid through the five buttons that run across the middle of the screen. Specifically, the buttons perform the following actions:

- **Add**: Enables you to create a new partition, assuming there is enough free disk space available. When you click this button, another dialog box appears in which you can fill in information necessary to create a partition.
- **Edit**: Enables you to alter the attributes of the partition currently highlighted in the Partitions list. You can make changes to the current attribute in another dialog box that appears when you click the Edit button.
- **Delete**: Removes the partition currently highlighted in the Partitions list.
- **Reset**: Causes Disk Druid to ignore any changes that you may have made.
- **Make RAID Device**: Sets up a RAID (Redundant Array of Independent Disks) device, which is a technique that combines multiple disks to improve reliability and data transfer rates. There are several types of RAID configurations. This button is active only if your system has the hardware necessary to support a RAID device.

The functions that you perform in Disk Druid depend on the hard drives in your PC and the partitions they already have.
