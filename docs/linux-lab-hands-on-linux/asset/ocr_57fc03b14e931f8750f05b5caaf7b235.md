Some programs, such as Sendmail, are very sensitive to this and if they detect what they feel is an incorrect FQDN they will default to using the name localhost.localdomain when communicating with another server on the network.

> You must always have a localhost and localhost.localdomain entry in /etc/hosts mapping to 127.0.0.1 for Linux to work properly and securely.

# Enable IP Forwarding

Forwarding allows the network packets on one network interface (i.e. eth0) to be forwarded to another network interface (i.e. eth1). This allows the Linux computer to connect (ethernet bridge) or route network traffic.

IP forwarding can be turned/ on to allow Linux computer to act as a gateway or router. In simple words, packet forwarding enables packets to flow through the Linux box from one network to another.

The Linux kernel configuration parameter to activate this is named net.ipv4.ip_forward and can be found in the file /etc/sysctl.conf. Remove the # from the line related to packet forwarding.

Before:

```
# Disables packet forwarding
net.ipv4.ip_forward=0
```

After:

```
# Enables packet forwarding
net.ipv4.ip_forward=1
```

The above syntax enables packet forwarding only when you reboot, at which time Linux will create a file in one of the subdirectories of the special RAM memory-based /proc file system. To activate the feature immediately, you have to force Linux to read the /etc/sysctl.conf file with the sysctl command using the -p switch. The syntax to use the sysctl command is as follows:

```
[root@netmon tmp] sysctl -p
sysctl -p
net.ipv4.ip_forward = 1
net.ipv4.conf.default.rp_filter = 1

kernel.sysrq = 0
kernel.core_uses_pid = 1
[root@netmon tmp]#
```
