## Creating and Using Arrays

- Shell arrays are relatively easy to construct. Example:

```bash
array=(red green blue yellow magenta)
len=${#array[*]}
echo "The array has $len members. They are:"
i=0
while [ $i -lt $len ]; do
    echo "$i: ${array[$i]}"
    let i++
done
```


### Strings and Substrings

- It is useful to take strings apart and put them together in different ways. Here is how to select a substring from a string:

```bash
string="this is a substring test"
substring=${string:10:9}
```

In this example, the *variable* "substring" contains the *word* "substring". Remember this rule:

```bash
substring=${string_variable_name:starting_position:length}
```

The string starting position is zero-based.

#### Searching and Replacing Substrings within Strings

- In this method, you can replace one or more instances of a string with another string. The following is the basic syntax:

```bash
alpha="This is a test string in which the word test is replaced."
beta="${alpha/test/replace}"
```

The string "beta" now contains an edited version of the original string in which the first case of the word "test" has been replaced by "replace". To replace all cases, not just the first, use this syntax:

```bash
beta="${alpha//test/replace}"
```

Note the double "/" symbol.

Here is an example in which we replace one string with another in a multi-line block of text:

```bash
list="cricket frog cat dog"
poem="I wanna be a x\\
A x is what I'd love to be\\
If I became a x\\
How happy I would be.\n"
for critter in $list; do
    echo -e ${poem//x/$critter}
done
```

Run this example:

```bash
$ ./myscript.sh
```

### Some Useful String Operations

Here is a way to isolate something useful from a large, even multi-line, string. As above, this method relies on enclosing a variable name in curly braces, then applying a special operator to achieve a particular result.

Here is a list of four such operators:

| Operator | Description |
| :--- | :--- |
| `#` | Means "delete from the left, to the first case of what follows." |
| `##` | Means "delete from the left, to the last case of what follows." |
| `%` | Means "delete from the right, to the first case of what follows." |
| `%%` | Means "delete from the right, to the last case of what follows." |

Operator `#` means "delete from the left, to the first case of what follows."

```bash
x="This is my test string."
echo ${x#*}
is my test string.
```

Operator `##` means "delete from the left, to the last case of what follows."

```bash
$ x="This is my test string."
$ echo ${x##*}
string.
```

Operator `%` means "delete from the right, to the first case of what follows."

```bash
$ x="This is my test string."
$ echo ${x%*}
This is my test
```

Operator `%%` means "delete from the right, to the last case of what follows."

```bash
$ x="This is my test string."
$ echo ${x%%*}
This
```

I find these operators particularly useful in parsing multi-line strings. Let's say I want to isolate a particular IP address from the output of the `ifconfig` command. Here's how I would proceed:

```bash
$ x=`/sbin/ifconfig`

```

### Bash Version 3

I have always thought the inability to test for the presence of a string or pattern (without using grep, sed or something similar) was a conspicuous weakness in shell programming. Bash version 3, present on most current Linux distributions, addresses this lack by allowing regular expression matching.

Let's say we need to establish whether variable $x appears to be a social security number:

```bash
if [[ $x =~ [0-9]{3}-[0-9]{2}-[0-9]{4} ]]
then
    # process SSN
else
    # print error message
fi
```

Notice the Perlish `=~` syntax and that the regular expression appears within *double brackets*. A substantial number of regular expression metacharacters are supported, but not some of the Perl-specific extensions like `\w`, `\d` and `\s`. Another Bash 3 feature is an improved brace expansion operator:

```bash
$ echo {a..z}
a b c d e f g h i j k l m n o p q r s t u v w x y z
for n in {0..5}
do
    echo $n
done
0
1
2
3
4
5
```

## CONCEPTS

Java is an operating system independent platform for software development. It consists of a programming language, utility programs, and run time environment. A Java program can be developed on one computer and run on any other computer with the correct run time environment. In general, older Java programs can run on newer run time environments. Java has gained popularity with the development of the Internet because when you program for the Web using Java, it is not necessary for you to know the operating system that is installed in user's system. With the Java programming language, you can take advantage of the "Write once, run anywhere" paradigm. This implies that when you compile your Java program, you need not to generate instructions for one specific platform. Instead, you need to generate Java byte code, which means instructions for the Java Virtual Machine (Java VM). It does not matter what platform the users use if Java VM is installed on their systems as Java VM understand byte codes.

- **Servlet:** Refers to a Java program that is designed to be run on a server. A servlet cannot run without a Web server.
- **Java application:** Refers to a Java program that can run itself.
