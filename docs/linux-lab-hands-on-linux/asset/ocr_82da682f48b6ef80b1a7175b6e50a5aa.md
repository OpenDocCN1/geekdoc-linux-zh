# ## Patching the Kernel

If you have already downloaded the main source code tree, you can save both bandwidth and time by downloading and applying patches. Patches contain only changes to the underlying files from one kernel version to the next. For example, if you downloaded the 2.6.26.8 kernel source code tree, you do not need to download the 2.6.26.9 source code, only the patch, which is named, in this case, patch2.6.26.9.tar.bz2, should be downloaded. Alternatively, you have the source code for version 2.6.26.5, you need to download four patches (patch-2.6.26.9.tar.bz2, patch2.6.26.9.tar.bz2, patch2.6.26.9.tar.bz2, patch2.6.26.9.tar.bz2) and apply them in sequential order. The following procedure illustrates the process:

```
$ bunzip2 c patch2.6.26.NN.bz2 | patch p0
Replace NN with the patch number of each patch you want to apply. In terms of the example used in this chapter, because I downloaded the full 2.6.26.8 source code
$ bunzip2 c patch2.6.26.9.bz2 | patch p0
patching file linux/CREDITS
patching file linux/Documentation/Configure.help
patching file linux/Documentation/DMAmapihg fi patching file
linux/Documentation/Submit tlingDrivers
...
patching file linux/net/uniwx/af_unix.c
patching file linux/net/wanrouter/wannin.c
patching file linux/net/wanrouter/wanproc.c
patching file linux/net/x25/af_x25.c
```

The exact list of file names varies from patch to patch, and some patches change more files than others. The end result, however, is a kernel source tree updated to the latest version. Finally, execute the following two commands to ensure you are working with a pristine source tree:

```
$ cd linux
$ make mrproper
```

# ### Configuring GRUB

GRUB, the Grand Unified Bootloader, is the default bootloader in Red Hat Linux 7.2. The following listing shows a typical GRUB configuration file (usually /boot/ grub/grub.conf):

```
default=0
timeout=10
splashimage=(hd0,0) /grub/splash.xpm.gz
title Red Hat Linux (2.6.26-2)
root (hd0,0)
kernel /vmlinuz2.6.26-2 ro root=/dev/sda2
initrd /initrd2.6.26-2.img
To activate the new kernel, add the following lines below the existing entries:
title Test Kernel (2.6.26.x)
root (hd0,0)
kernel /vmlinuz2.6.26.x ro root=/dev/sda2
initrd /initrd2.6.26.x.img
```
