# ■ Adding, Changing, and Deleting Text

You cannot replace or delete text by highlighting it with the mouse in the vi editor. Instead, use the commands that are discussed in the following tables. The main purpose of an editor is to create, add, or modify text of a file.

# Inserting or Adding Text

The following commands allow you to insert and add text. Each of these commands put the vi editor into insert mode; thus, the ESC key must be pressed to terminate the entry of text and to put the vi editor back into command mode.
