# Determining Your IP Address

Most modern PCs come with an Ethernet port. When Linux is installed, this device is called eth0.

You can determine the IP address of this device by using the ifconfig command:

```
`[root@netmon tmp]# ifconfig -a`
```

# Changing Your IP Address

To assign IP address to eth0 interface, you can run the following command:

```
`[root@netmon tmp]# ifconfg eth0 172.16.1.100 netmask 255.255.0.0 up`
```

The up at the end of the command activates the interface.

> To make this permanent each time you boot up you have to add this command in /etc/rc.local file, which is run at the end of every reboot.
