# ■ Understanding the Swap Partition

Most advanced operating systems support the concept of virtual memory, where your system’s hard disk functions as an extension of the physical memory (RAM). It is called as swap space. When the operating system runs out of physical memory, it can move (or swap out) the contents of currently unneeded parts of RAM to swap partition in hard disk to make room for a program that needs more memory. When the operating system needs to access any thing in the swapped out data, it has to find something else to swap out and then it swaps in the required data from disk. This process of swapping data back and forth between the RAM and the disk is also known as paging.

As you know that the disk is much slower than RAM, the system’s performance is slower when it performs a lot of paging. However, virtual memory enables you to run programs that you otherwise cannot run. Linux supports virtual memory and can make use of a swap partition. When you create the Linux partitions, you should also create a swap partition.

You can easily create a swap partition by using the Disk Druid utility program, described in the next section.

# ■ Preparing Disk Partitions for Linux

It is important to note that minimum two partitions need to be created for Linux installations which are as follows:

+   □ The First Partition is / (root partition). Minimum size of the root partition varies from 2GB to 8GB depends on installation of software packages.

+   □ The Second Partition is SWAP partition (virtual drive), recommended size of this partition is twice of RAM size or 1 GB whichever more.

We can have /boot, /var, and /home as separate partitions.
