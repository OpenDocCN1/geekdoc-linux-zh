# # Installing the MySQL Server

The MySQL packages are included with the Fedora and RHEL distributions.
Type the following command in the command line to check your installation for MySQL packages:

```
[root@netmon opt]# rpm \-qa\|grep mysql \-\*
```

Otherwise, you can install them from CD/DVD distros of Fedora and RHEL by using the following commands:

```
[root@netmon opt]# rpm \-Uvh mysql\-ver.release.arch.rpm
[root@netmon opt]# rpm \-Uvh mysql\-server\-ver.release.arch.rpm
[root@netmon opt]# rpm \-Uvh mysql\-devel\-ver.release.arch.rpm
```

After installing the MySQL server, lets now learn to start MySQL server.

# ## Starting the MySQL Server

Start the MySQL process before you can create your databases. To configure MySQL to start at boot time, use the chkconfig command given as follows:

```
[root@netmon tmp]# chkconfig \-level 35 mysqld on
```

You can start, stop, and restart MySQL after boot time using the following service commands:

```
[root@netmon tmp]# service mysqld start
[root@netmon tmp]# service mysqld stop
[root@netmon tmp]# service mysqld restart
```

> You need to restart the mysqld process every time you make a change to the configuration file for the changes to take effect on the running process.

Test the mysqld process whether it is running with by using the following command:

```
[root@netmon tmp]# pgrep mysqld
```
