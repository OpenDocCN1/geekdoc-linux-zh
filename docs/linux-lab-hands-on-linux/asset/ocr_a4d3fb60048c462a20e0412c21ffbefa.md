Modify the root device (//dev/sda2 in this example) to reflect your system. This single change is all you need to do to make GRUB aware of the new kernel - GRUB reads this file at boot time and uses it to build a menu of options.

# Booting the Custom Kernel

After you have updated GRUB's menu file, reboot, select the new kernel from GRUB's menu, press the ENTER key, and, if everything has gone well, your Red Hat Linux system should boot your new kernel. Execute the following command to make sure you've booted the new kernel:

```
$ uname -a
```
