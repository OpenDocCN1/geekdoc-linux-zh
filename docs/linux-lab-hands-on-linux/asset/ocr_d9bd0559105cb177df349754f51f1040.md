# # FTP Client

# ## Using Anonymous Access

The following steps are performed to use anonymous access of FTP server:

+   1. Check for the presence of a test file on the FTP client.
+   
+      Type the following command to check the presence of test file on the FTP client:

```
[root@netx tmp]# ll
total 1
-rw-r--r-- 1 root 0 June 4 09:09 testfile
[root@netx tmp]#
```

+   2. Connect to netmon via FTP.
+   
+      Type the following commands at root mode to connect to netmon server using FTP:

```
[root@netx tmp]# ftp 172.16.1.100
Connected to 172.16.1.100 (172.16.1.100)
220 ready, dude (vsFTPD 1.1.0: beat me, break me)
Name (172.16.1.100:root): anonymous
331 Please specify the password.
Password: (Type here "anonymous")
230 Login successful. Have fun.
ftp>ha
ftp>bin
ftp> get vsftpd-*
local: vsftpd-1.1.0-1.i386.rpm.tmp remote: vsftpd-1.1.0-1.i386.rpm
227 Entering Passive Mode (172,16,1,100,44,156)
150 Opening BINARY mode data connection for vsftpd-1.1.0-1.i386.rpm (76288 bytes).
226 File send ok.
76288 bytes received in 0.499 secs (1.5e+02 Kbytes/sec)
ftp> exit
221 Goodbye.
```

+   * *ftp > bin* (for binary mode data transfer
+   * *ftp > ha* (for *To turn on hash marks as Progress bar while downloading*.

# ## Troubleshooting FTP

+   1. Initial setup failures could be caused by firewalls along the path between the client and server blocking some or all types of FTP traffic. To disable default setting of firewall run the following command:

```
[root@netmon tmp]# iptables -F
```

> *Iptables* is Linux firewall module, we can use it to specify firewall rules. *iptables -F* flushes all the firewall rules. Refer Appendix for more information on iptables.
