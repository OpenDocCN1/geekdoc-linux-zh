### CONCEPT

Transmission Control Protocol/Internet Protocol (TCP/IP) is the two-way communication protocol, which is used to send and receive data from one computer to the other over a network. TCP/IP uses the client/server model of communication in which a user (client) requests the host computer (server) for services, thereby establishing communication. A TCP/IP protocol is not just a single networking protocol but a collection of protocols, which are used for defining the standards for working of the Internet. An IP address is used in a TCP/IP network. You can fully understand the concept of TCP/IP networking in terms of a layered model with five layers. Each layer in TCP/IP model is responsible for performing a particular task. This model describes the flow of data between the physical connection to the network and the end-user application.

Linux is a complete network operating system. This lab covers TCP/IP networking and system configuration basics. Linux can support multiple network devices. The device names are numbered, which begin at zero and count upwards. For example, a computer running two ethernet cards will have two devices labeled as /dev/eth0 and /dev/eth1.

### TCP/IP Network Configuration Files

The primary network configuration files are as follows:

- /etc/hosts
- /etc/resolv.conf
- /etc/sysconfig/network
- /etc/sysconfig/network-scripts/ifcfg-<interface-name>
- /etc/host.conf
- /etc/nss.conf
- /etc/sysctl.conf
- /etc/services
- /etc/protocols
- /etc/sysconfig/networking
- /etc/modprobe.conf

Let’s discuss these files in detail in the following sections.

### /etc/hosts

The main purpose of this file is to resolve hostnames that cannot be resolved any other way. It can also be used to resolve hostnames on small networks with no DNS server. Regardless of the type of network a computer is using, this file should contain a line specifying the IP address of the loopback device (127.0.0.1) as localhost.localdomain.

### /etc/resolv.conf

This file specifies the IP addresses of the DNS servers and the search domain. Unless configured to do otherwise, the network initialization scripts populate this file.

### /etc/sysconfig/network

This file specifies routing and host information for all network interfaces. For more information about this file and the directives you can use the following syntax:

`/etc/sysconfig/network-scripts/ifcfg-<interface-name>`

For each network interface, there is a corresponding interface configuration script. Each of the network interface files provide information specific to a particular network interface.

### /etc/host.conf

This file lists resolver options.

### /etc/nss.conf

The nss.conf is used for Name Switch Service configuration. It defines order of name resolution options.

### /etc/sysconfig/networking

This file holds network configuration files managed by redhat-config-network.

### /etc/sysctl.conf

The above file is used for IP forwarding configuration.

### /etc/services

It lists available network services, such as FTP and Telnet, and the ports they use.

### TCP/IP Configuration Addresses

The following are the different addresses used in TCP/IP configuration:

- **Host address**: Represents the IP address of your system; it has a network part to identify the network you are on and a host part to identify your own system.
- **Network address**: Represents the IP address of your network.
- **Broadcast address**: Represents the IP address for sending messages to all hosts on your network at once.
- **Gateway address**: Represents the IP address of your gateway system, if you have one (usually the network part of your host IP address with the host part set to 1).
- **Domain name server addresses**: Represents the IP addresses of domain name servers your network uses.
- **Netmask**: Determines the network and host parts of your IP address.

### Configuring NIC's IP Address

When we have many computers on a network, you need a way to identify each one uniquely. In TCP/IP networking, the address assigned to each computer is known as IP address. IP address is the logical address used to communicate with people, computers, and devices and gather information. IP address is used to send and receive information from one host to another through a physical medium such as cable on the network. An IP address is a unique 32-bit logically assigned binary number of four octets, which is represented in dotted decimal notation, designated to a particular device. Hosts and routers (a device used to determine the destination of a data packet) used in the TCP/IP protocol suite are identified by the IP address. The IP address is also divided into classes and each class has its specific range. The IP address consists of two parts, which are as follows:

- **Network ID**: Identifies the network to which the host is connected. Network ID is the same for all the hosts on a particular network.
- **Host ID**: Identifies the host on the network. Host ID is different for different hosts on the network.

**Table 1: Division of IP Addresses**

| IP Address | Network ID | Host ID |
| :--- | :--- | :--- |
| 193.168.75.38 | 193.168.75 | 38 |
| 130.11.45.90 | 130.11 | 45.90 |
| 125.25.210.12 | 125 | 25.21.12 |

Each pair of numbers written in decimal notation in an IP address is called an octet. In the example **192.168.75.38** 192 is the first octet, 168 is the second octet, 75 is the third octet, and 38 is the fourth octet. The following are the rules regarding the identification of IP address:

- An IP address cannot be duplicated
- All Host bits cannot be set to zero
- All Host bits cannot be set to one
- **127** cannot be taken as the first octet because it is reserved as a loopback address (address that acts as a test mechanism for network devices and protocols).

An IP address is used as an ID to communicate on the network, similar to a student who requires an ID to get access to the services in the university. It is a basic protocol to get connected to the network. Generally, an IP address is assigned to the Network Interface Card (NIC) rather to the device (computer). An IP address may be either permanent or temporary for a particular device. The following are the two types of IP addresses:

- **Dynamic IP address**: Refers to the IP address assigned to the devices that requires temporary connectivity to the network or devices communicating through the network for a short period. Dynamic IP address uses DHCP (Dynamic Host Configuration Protocol) for assigning the IP address.
- **Static IP address**: Refers to the IP address assigned to a device that requires permanent connectivity on the network. Static IP address is the semi-permanent IP address.

You have learned about IP addresses in this section. Now let’s discuss about the classification of IP addresses.

### Classification of IP Addresses

As already discussed, IP address specifies a unique ID to access the network. It defines IP addresses into five types of classes: A, B, C, D, and E. The first four bits of an IP address determines the class into which an IP address fits.

The following list shows the various IP address classes as per the variation of the first, second, third or fourth bit of an IP address:

- If the first bit is zero, the IP address belongs to Class A address.
- If the first bit is one and if second bit is zero, the IP address belongs to Class B address.
- If the first two bits are one and if the third bit is zero, the IP address belongs to Class C address.
- If the first three bits are one and if the fourth bit is zero, the IP address belongs to Class D address.
- If all the four bits are one, the IP address belongs to Class E address.

The following table shows the classification of IP addresses:

**Table 2: Types of IP Addresses**

| Class | Network ID | Host ID |
| :--- | :--- | :--- |
| A | 0 (7 bits) | 24 bits |
| B | 10 (14 bits) | 16 bits |
| C | 110 (21 bits) | 8 bits |
