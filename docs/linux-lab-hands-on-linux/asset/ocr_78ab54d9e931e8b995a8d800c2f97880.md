# # The / Directory (The root File system)

![](bbox=[0.37, 0.18, 0.73, 0.34])

+   - **/bin**: Consists of commands that are used by both the system administrator as well as non-privileged users. This directory usually contains the shells like bash, csh etc. as well as much used commands like cp, mv, rm, cat, ls.

+   - **/sbin**: Consists of commands that are specific to the system administrator.

+   - **/etc**: Contains all the configuration files for your system.

+   - **/root**: Provides the home directory for the superuser. The superuser is the user who is login with the root account.

+   - **/lib**: Consists of shared libraries needed by the programs on the root file system.

+   - **/lib/modules**: Provides you with loadable kernel modules, especially those that are needed to boot the system when recovering from disasters such as, network and filesystem driver.

+   - **/dev**: contains device files.

+   - **/tmp**: Refers to the temporary files. Programs running after bootstrap should use /var/tmp, not /tmp because of its size. Often /tmp will be a symbolic link to /var/tmp.

+   - **/boot**: Consists of files used by the bootstrap loader, such as LILO/GRUB.

+   - **/mnt**: Refers to mount point for temporary mounts by the system administrator.

# ## Using File System Commands

+   - **ls**: Lists files and directories, which are present in Linux operating system as well as those created by the user

+   - **cp**: Use to copy files

+   - **rm**: Use to remove files

+   - **chown**: Use to change file ownership

+   - **chgrp**: Use to change group permission

+   - **chmod**: Use to change files and directory permission
