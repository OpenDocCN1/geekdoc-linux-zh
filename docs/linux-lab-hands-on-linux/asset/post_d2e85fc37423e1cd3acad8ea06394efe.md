## CONCEPT

SCILAB is freely distributed and open source scientific software used to develop engineering and scientific applications. It is based on a numerical, programming, and graphics environment. SCILAB performs the same function like other environments such as, numerical, programming, and graphics environment but these environments are different syntactical wise. SCILAB is currently being used in educational and industrial environments around the world.

Scilab includes hundreds of mathematical functions with the possibility to add interactive programs from various languages, such as C and Portran. It has sophisticated data structures including lists, polynomials, rational functions, and linear systems, an interpreter, and a high level programming language.

## Installing SCILAB

**Step#1: Check for the requirements to install Scilab are as follows:**

- for the source version: Requires approximately 130Mb of disk storage to unpack and install (all sources included). You need X Window (X11R4, X11R5 or X11R6, C compiler and Fortran compiler (e.g. f2c or g77 or Visual C++ for Windows systems).
- for the binary version: Requires the minimum memory for running SCILAB (without sources) of 40 Mb when decompressed. These versions are partially statically linked and in principle do not require a fortran compiler.

**Step#2: Install Scilab**

The simplest way to install and use Scilab is to download scilab-5.1.1.tar.gz or scilab-5.1.1.bin.linux-i686.tar.gz from http://www.scilab.org.

Next, unpack the file in the /opt directory.

You can unpack the file in the /opt directory by using the following commands:

```bash
[root@netmon opt]#tar -xzvf scilab-5.1.1.bin.linux-i686.tar.gz
[root@netmon opt]# cd scilab-5.1.1
[root@netmon opt]#cd bin
[root@netmon opt]#./scilab
```

## Using SCILAB

- Editing a command line
  - enter a command line by typing after the prompt, or using Scipad to edit

![](img/f3b9cff79e19317416c12eaf5ded7245_226_0.png)

The Scilab window contains the following control buttons.

- Stop: Interrupts the execution of Scilab and enters in pause mode.
- Resume: Continues execution of a function after a pause is entered as a command or generated by the Stop button or the Control C key combination.
- Abort: aborts execution after one (or several) pause, and returns to top-level prompt.
- Restart: Clears all variables and executes startup files.
- Quit: Quits Scilab.
- Kill: Kills the Scilab shell script.
- Demos: Provides interactive run of some demos.
- File Operations: Provides facility for loading functions or data into Scilab, or executing script files.
- Help: Invokes on-line help and the names of the corresponding items.
- Graphic Window Icon: Selects active graphic window.

> New buttons can be added by the addmenu command.

## CONCEPT

Shell Script Basics

- A shell script is a plain-text file that contains shell commands. It can be executed by typing its name into a shell or by placing its name in another shell script.
- To execute a shell script file, you must meet some conditions, as follows:
- The file must have a special first line that names an appropriate command processor:

```bash
#!/bin/bash
```

If the preceding example does not work, then you need to find out the location of your executable Bash shell and substitute that location in the above example. You can also locate the Bash shell by using the following example:

```bash
$ whereis bash
```

- The file must be made executable by changing its permission bits by using the following example:

```bash
$ chmod +x (shell script filename)
```

- A shell script file may have an identifying suffix optionally, such as ".sh". This only helps the user to remember the types of files. The command processor is responsible to execute the file that uses the executable bit with the file's first line, to decide how to handle a shell script file.
- You can easily execute a shell script by using the following example:

```bash
$ ./scriptname.sh
```

The above example is a way to tell the command processor that the desired script is located in the current directory. Always remember that if you cannot run your shell script, you can provide its location as well as its name to run you shell script.
