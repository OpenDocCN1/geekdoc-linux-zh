You can use vi editor to modify the setting.

```
[root@netmon network-scripts]# vi ifcfg-eth0
DEVICE=eth0

```

# ### Getting the IP Address Using DHCP

Dynamic Host Configuration Protocol (DHCP) is used to obtain IP addresses for dial-in clients. only the IP address from the DHCP lease is passed to the RAS client. [root@netmon tmp]# cd /etc/sysconfig/network-scripts

```
[root@netmon network-scripts]# vi ifcfg-eth0
DEVICE=eth0
BOOTPROTO=dhcp
ONBOOT=yes
[root@netmon network-scripts]#
```

# ### Using ifconfig command:

```
[root@netmon network-scripts]# ifconfig eth0 up
[root@netmon network-scripts]# ifconfig eth0 down
```

OR
The ifdown and ifup commands can be used to do this:

```
[root@netmon network-scripts]# ifdown eth0
[root@netmon network-scripts]# ifup eth0
```

# ### Multiple IP Addresses on a Single NIC (Network IP Aliasing)

You can create the virtual interface by using the ifconfig command:

```
[root@netmon tmp]# ifconfig eth0:0 172.16.1.200 netmask 255.255.0.0 up
```

Edit the /etc/sysconfig/network-scripts/ifcfg-eth0.0 file, so that the aliases will be managed automatically by using the ifup and ifdown commands.
Here is a sample configuration to manage the IP address:

```
DEVICE=eth0:0
ONBOOT=yes
BOOTPROTO=static
IPADDR=172.16.1.200
NETMASK=255.255.0.0
```
