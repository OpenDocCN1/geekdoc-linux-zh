# # Summary

In this Lab, you learn to create, modify, delete, and disable user accounts using command line tools in Unix environment. You also learn to modifying information of an existing user by changing the home directory, UIDs and GIDs, account expiration date, and finger information. Towards the end of the chapter, you learn to delete user account.
