# Creating Your First Java Program

Let's perform the following steps to create a Java program that accepts two numbers and then compute print the result:

+   1. Create a Java source file.
+   2. Compile the source file into a byte code file.
+   3. Run the program contained in the byte code file

Let's now learn how to create, compile, and run a Java program.

# Create a Java Source File

A source file contains text written in the Java programming language. You can use any text editor to create and edit source files.

+   1. Bring up a shell (sometimes called terminal) window.

When the prompt first appears, your current directory is usually your home directory. You can change your current directory to your home directory at any time by typing `cd` at the prompt and then pressing enter.

The Java files you create should be kept in a separate directory. You can create a directory by using the command `mkdir`. For example, to create the directory `java` in your home directory, you first need to change your current directory to your home directory by entering the following command:

```
```
cd
```
```

Then, you need to enter the following command:

```
```
mkdir java
```
```

You need to enter the following command to change your current directory to this new directory:

```
```
% cd java
```
```

Now, you can start creating your source file.

+   2. Start an editor (nano in our case) by typing the name of the editor at the prompt and then press enter. at the prompt and pressing enter.
+   
+      When an editor is started, it displays a new blank buffer where you need to type your code.

+   3. Type the Java code.

+   4. Save the code by typing Ctrl-O in the editor. You can specify the desired file name (in our case, we have specified `simple.java`) preceded by the directory in which you want the file to save. If you wish to save `sample.java` in the directory `/home/Mahendra/java`, then you would type:

```
```
/home/Mahendra/java/sample.java and press enter.
```
```

+   5. Type Ctrl-X to exit nano.
