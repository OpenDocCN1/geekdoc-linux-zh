# Updating and Deleting MySQL Records

You can select records based on any value you choose and update any values in those records. When you are in your *mysql* session, you can use UPDATE to change the values in a selected table. Use the following command to update the records in the name table:

```
mysql> UPDATE name SET streetaddr = "33 Central Avenue Road" WHERE firstname = "Venkat";
Query OK, 1 row affected (0.00 sec)
Rows matched: 1 Changed: 1 Warnings: 0
```

This example attempts to update the name table (UPDATE name). In this example, each record that has the firstname column set to "Venkat" will have the value of the streetaddr column for that record changed to "33 Central Avenue Road" instead. Note that the query found one (1) row that matched. That one row matched was also changed, with no error warnings necessary. You can use any combination of values to match records (using WHERE) and change column values (using SET) that you would like. After you have made a change, it is a good idea to display the results to make sure that the change was made as you expected.
