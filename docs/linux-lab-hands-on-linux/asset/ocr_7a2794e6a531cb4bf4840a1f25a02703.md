**CONCEPT**
A proxy server sits between a web server and a web client (browser) and acts as a gateway between the two. There are many advantages to having a proxy server.

The main ones are:

+   - Security: The ability to allow or deny access to external web servers using Access Control Lists (ACL's)
+   - Accounting: Logging all of your clients access to the internet. Reports and statistics can be generated from these logs
+   - Caching: Frequently accessed pages are cached locally and shared by all local web clients. This saves on bandwidth on your internet connection.
