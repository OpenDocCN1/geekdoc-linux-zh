```
`[root@netmon Server]#createrepo -g /tmp/comp[tab] /var/ftp/pub/Server`
```

Once the repository is created in /var/ftp/pub/Server it would prompt you to remove the existing .oldata.

```
`[root@netmon Server]#rm -rf .oldata`
```

After removal of .oldata you would have to once again create the repository

```
`[root@netmon Server]#createrepo -g /tmp/comp[tab] /var/ftp/pub/Server`
```

It would take a while and your repository would be created. /var/ftp/pub has an entry for 'VT' as well, so copy the repository for this as well.

```
`[root@netmon Server]#cd /var/ftp/pub/VT`  
`[root@netmon VT]# cp repodata/comp[tab] /var/ftp/pub/VT`
```

Now you would have to create the .repo file in the directory etc/yum.repos.d/ for yum install to work. Get into this directory and remove/backup the existing .repo file to a different directory if needed

```
`[root@netmon VT]# cd /etc/yum.repos.d/`
```

Create your own '.repo' file, something like

```
`[root@netmon yum.repos.d]# vi server.repo`  
```
[Server]
name=Server
baseurl=http://172.16.100.1/pub/Server (Ip address choice is left to you)
gpgcheck=0
[VT]
name=VT
baseurl=http://172.16.100.1/pub/VT
gpgcheck=0
```
```

Now check if 'wget' works for you on your system or not ?

```
`[root@netmon yum.repos.d]#wget ftp://172.16.100.1/pub/Server/createrepo*`
```

if 'wget' fails the possibility is that the vsftpd service is stopped or you would have to turn off the firewall as below

```
`[root@netmon ~]# man ftpd_selinux`
```

and search for 'restart' in this ftpd_selinux file i.e /restart and execute these two commands

```
`[root@netmon ~]#setsebool -P ftpd_disable_trans 1`  
`[root@netmon ~]#service vsftpd restart`  
`[root@netmon yum.repos.d]#rpm -ivh create*`  
`[root@netmon yum.repos.d]#yum clean all`  
`[root@netmon yum.repos.d]#yum list all`
```
