# Making NFS Mounting Permanent

If you want NFS directories to be permanently mounted, make an entry in the /etc/fstab file in addition to the creation of the mount point directory.

+   The /etc/fstab File

The /etc/fstab file lists all the partitions that need to be auto-mounted when the system boots. Therefore, you need to edit the /etc/fstab file if you need the NFS directory to be made permanently available to users on the NFS. For the example, mount the /data/files directory on server Netmon (IP address 172.16.1.100) as an NFS-type filesystem using the local /mnt/nfs mount

|#/etc/fstab
|Directory Mount Point Type Options Dump fsc
|172.16.1.100:/distro/rhel5 /mnt/nfs nfs soft,nfsvers=200

+   Permanently Mounting the NFS Directory

You first learn to create a mount point directory, /mnt/nfs, to mount the remote NFS directory and then learn to use the mount -a command to activate the mount.

The syntax to create a mount point directory, to mount the remote NFS directory, to activate the mount is as follows:

```
[root@netx tmp]# mkdir /mnt/nfs
[root@netx tmp]# ls /mnt/nfs
[root@netx tmp]# mount -a
[root@netx tmp]# ls /mnt/nfs
[root@netx tmp]#
```

Each time your system boots, it reads the /etc/fstab file and executes the mount -a command, thereby making this a permanent NFS mount.
