# ## Configuring the SSH Server

OpenSSH uses a server-client relationship. The system to which you connect is known as a *server* and the system *requesting* the connection is known as a *client*. A system can be both an SSH server and a client.

# ### Starting Openssh

OpenSSH is installed by default during Linux installations. You can run the following commands to check whether the SSH programs are installed

```
[root@netmon tmp]# rpm -qa |grep ssh
Or
[root@netmon tmp]# rpm -qa |grep openssh
```

You can start SSH at boot time by using the chkconfig command. The syntax to use the chkconfig command is as follows:

```
[root@netmon tmp]# chkconfig -level 35 sshd on
```

You can also start, stop, and restart SSH after booting by running the sshd initialization script. The syntax to start, stop, and restart SSH after booting is as follows:

```
[root@netmon tmp]# service sshd start
[root@netmon tmp]# service sshd stop
[root@netmon tmp]# service sshd restart
```

It is important to note that you should restart the SSH process every time you make a change to the configuration files to make the changes effective on the running process.
