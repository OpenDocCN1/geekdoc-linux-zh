The named.conf file contains the main DNS configuration and tells BIND (named) where to find the configuration files for each domain you own. This file usually has the following two zone areas:

+   - **Forward zone**: Refers to the file definitions that lists files to map domains to IP addresses
+   - **Reverse zone**: Refers to the file definitions that lists files to map IP addresses to domains

In the following example, you set up the forward zone for www.spit.ac.in by placing entries at the bottom of the named.conf file. The zone file is named as spit.ac.in.forward, and, although not explicitly stated, the file spit.ac.in.forward should be located in the default directory of //var/named/chroot/var/named in a chroot or in /var/named in a regular one. Use the code:

```
zone "spit.ac.in" {

type master;

otify no;

allow-query { any; };

file "spit.ac.in.forward";

};
```
