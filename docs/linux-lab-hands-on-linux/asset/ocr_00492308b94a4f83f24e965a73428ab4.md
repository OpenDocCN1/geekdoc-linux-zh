With this your local/server repository is created and should be accessible by any client in your network for yum install/updates. 
The server side settings are done.
Let’s have a look at client side setting now.

# ► Step #5: Client Side Setting for YUM

On your client machine the only changes you would have to do would be to the /etc/yum.repos.d/ directory: here you may have client.repo with the parameters as mentioned above.

# ► Example client.repo file:

Create a repo file in /etc/yum.repos.d/ directory [you can name anything to your file make sure a .repo extension is added later on]

```
```text
[root@netmon ]#vi /etc/yum.repos.d/client.repo

[client]
  name=Client
  baseurl=ftp://172.16.100.1/pub/server (Ip address choice is left to you)
  gpgcheck=0
[vt]
  name=vt
  baseurl=ftp://172.16.100.1/pub/vt
  gpgcheck=0
```
```

The first line is alias given for your repository. This help to indicate/find that from which repository the package is available. Second line is name for your repo, which you can put anything Next comes baseurl supports different protocols like file:// ftp:// httpd:// etc. If you are running repository from local system then give absolute path after file://.

![](bbox=[0.21, 0.54, 0.85, 0.585])

Next line is enabled this specifies if yum should enable that repo server for installation or not 1 is for enable and 0 is for disable gpgcheck is for checking gpg key.
After this save that repo file and run following command

```
```bash
[root@netmon]#yum clean all [will clean yum database]
[root@netmon]#yum list [will list the files / packages available on that server or local directory]
```
```
