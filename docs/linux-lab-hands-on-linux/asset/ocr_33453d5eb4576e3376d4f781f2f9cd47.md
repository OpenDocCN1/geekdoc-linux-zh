# CONCEPT

SCILAB is freely distributed and open source scientific software used to develop engineering and scientific applications. It is based on a numerical, programming, and graphics environment. SCILAB performs the same function like other environments such as, numerical, programming, and graphics environment but these environments are different syntactical wise. SCILAB is currently being used in educational and industrial environments around the world.

Scilab includes hundreds of mathematical functions with the possibility to add interactive programs from various languages, such as C and Portran. It has sophisticated data structures including lists, polynomials, rational functions, and linear systems, an interpreter, and a high level programming language.

# Installing SCILAB

**Step#1: Check for the requirements to install Scilab are as follows:**

- for the source version: Requires approximately 130Mb of disk storage to unpack and install (all sources included). You need X Window (X11R4, X11R5 or X11R6, C compiler and Fortran compiler (e.g. f2c or g77 or Visual C++ for Windows systems).
- for the binary version: Requires the minimum memory for running SCILAB (without sources) of 40 Mb when decompressed. These versions are partially statically linked and in principle do not require a fortran compiler.

**Step#2: Install Scilab**

The simplest way to install and use Scilab is to download scilab-5.1.1.tar.gz or scilab-5.1.1.bin.linux-i686.tar.gz from http://www.scilab.org.

Next, unpack the file in the /opt directory.
