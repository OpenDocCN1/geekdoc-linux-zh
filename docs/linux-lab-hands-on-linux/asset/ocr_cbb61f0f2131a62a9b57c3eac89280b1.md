# 13 | LAB: File Transfer Protocool (FTP) Server

**OBJECTIVES**  
To configure Linux FTP server (public FTP and private FTP) using the FTP (VSFTPD) daemon, which is very secure.

**REQUIREMENTS**  
P-IV class PC, 1-GB RAM, 80 GB HDD, NIC, with FC6 or RHEL-5 and Linux installed.

**CONCEPT**  
The File Transfer Protocool (FTP) is an established protocol to copy files between servers over the Internet.

In FC-6 or RHEL-5, you can use the FTP program as it is designed to be secure, stable, fast, and scalable.

FTP relies on a pair of TCP ports. It operates using two TCP ports 20 and 21. Port 21 is known as control port. All commands and the response of the FTP server, go over the control port. Port 20 is known as data port that is used for all subsequent data transfers between the client and server.

The FTP server is used to download a file from the server or upload a file to the server. It is a software application that runs the File Transfer Protocool (FTP) and transfers files over the internet. The FTP server is the secure way of sharing file with the help of a client-server model. A popular, and very secure, FTP server available for almost all Linux systems is vsftpd (Very Secure FTP). Installing and setting up vsftpd in a Linux environment is a simple process.

A FTP server attempts to authenticate users that request to use it. You can configure your FTP server to accept requests only from users who have an account on the system running the FTP server (User Access FTP). Alternatively, you can configure the FTP server to accept requests from anyone, with the help of service known as anonymous FTP.

# Anonyomus FTP

Anonyomus FTP is the selection of Web sites that need to exchange files with numerous unknown remote users. Users can log in as a user ftp or as a user anonymous to get access to the ftp site. By default the root directory of anonymous ftp server is set as /var/ftp/pub. It only allows download services to the anonymous user by default.

# User Access FTP

Users with account on the system can connect via ftp and login by using their username and password. They can download any file and also they can upload file to any directory on FTP server, provided they will have write access to that directory
