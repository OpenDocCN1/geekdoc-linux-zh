# Step#2: Copy Disc to Hard Disk

First mount your CD/DVD and copy it to hard disk

Assuming that the netmon dvd is inserted into your linux system, try the below recommended steps:

```
```bash
[root@netmon ~]#mount /dev/dvd /mnt
[root@netmon ~]#cd /mnt/server
[root@netmon Server]#rpm -ivh vsftpd[tab] ([tab] - means hit tab)
[root@netmon Server]#rpm -ivh createrepo[tab] ([tab] - means hit tab)
```
```

It may take while the repository is created, after completion of this check if the 'vsftpd' service is running or not? if not

```
```bash
[root@netmon Server]#service vsftpd restart
```
```

Ensure that the vsftpd service is turned on during startup with the below command

```
```bash
[root@netmon Server]#chkconfig --level 35 vsftpd on
```
```

To check the vsftpd status in various runevelu you can try this

```
```bash
[root@netmon Server]#chkconfig --list vsftpd
```
```

> You would notice that after the successful installation of `vsftpd` service you would see `/var/ftp/pub/` directory on your linux system.

```
```bash
[root@netmon Server]#cp -avr /mnt/* /var/ftp/pub
[root@netmon Server]#pwd
/mnt/server
[root@netmon Server]#cd /var/ftp/pub/Server
[root@netmon Server]#pwd
/var/ftp/pub/Server
```
```

> If you want install Repository on your network through http upload in their respective default directory /var/www/html for http server.
