# ### Using the TELNET Client

You can connect to a remote server by typing the following command:

```
`$telnet IP address or server name`
```

Where, IP address or server name refers to the address and name of the server to which you want to connect.

Suppose you want to remotely login into a remote server, name netx using Telnet client, then the user first looks in the routing table and access that server, as shown in the following example:

```
[root@netmon tmp]# telnet 172.16.1.105
Trying 172.16.1.105...
Connected to 172.16.1.105.
Escape character is '^J'.

Linux 2.4.18-14 (netx.spit.ac.in) (10:35 on Sunday, 14 June 2009)
Login: adaya Password:

You have new mail.
[adaya@netx adaya]$ 
[adaya@netx adaya]$ netstat -nr
[adaya@netx adaya]$ exit
Logout
Connection closed by foreign host.
[root@netmon tmp]#
```
