# # Kernel Compilation: The Third Stage

# ## Compilation and Installation

Create subdirectory configuration files: Propagate the configuration-defined in the .config file and the top level Makefile to subdirectory configuration files with make dep.

+   6. make dep

Compile the Kernel: Linux kernel are generally loaded from gzip-compressed images, one type of which is built with make bzImage. After compilation, the compressed image can be found at /usr/src/linux-2.6.26.x/arch/i386/boot/bzImage.

+   7. make bzImage

Compile the Kernel Modules: Kernel modules, although compiled from the same source files as the base kernel are compiled with a separate make invocation. Generally, the vast majority of the kernel exists as kernel modules and this can be a very lengthy step. During long compilations, /usr/src/linux-2.6.26.x/Documentation is used

+   8. make modules

Install the kernel: Although there are no restrictions on the name and location of the kernel. Red Hat suggests installing it into the /boot partition.

+   9. cp /usr/src/linux-2.x/arch/i386/boot/bzImage /boot/vmlinuz-2.6.26.x-22exmp

Install the kernel Modules: Modules are installed by the modules_install make invocation into the /lib/modules/version directory.

+   10. make modules_install

# ## Initial Ramdisks

Sometimes it is the desirable certain kernel components as modules, even if they are required at boot time. The most common example is modular SCSI drivers. Because the kernel needs to load the modules before a file system present, they are stored in a ram disk image, called an initrd. The kernel can then load the modules for ram disk at boot time. *mkinitrd* examines the kernel’s module library intelligenly, selects any modules that might be needed at boot time (usually SCSI drivers or software RAID modules), creates a ramdisk image, and packs the modules into the ram disk. The *initrd* image should then be stored somewhere accessible at boot time, namely, the /boot directory.

+   11. mkinitrd /boot/initrd-2.6.26.x-22exmp.img 2.6.26.x-22exmp

**System Map**: A symbol table for the various kernel producers is created when the kernel is compiled, and located in the file /usr/src/linux-2.6.26.x/System.map. A copy of this table is needed to interpet the debugging information to drop a kernel during a kernel panic, and should be stored along with the kernel.

+   12. cp /usr/src/linux-2.6.26.x/config /boot/System.map-2.6.26.x-22exmp

**Configuration file (optional)**: Keeping the copy of the configuration file used to compile a kernel can be useful in keeping track of which capabilities were enabled for which kernels.

+   13. cp /usr/src/linux-2.6.26.x/config /boot/config-2.6.26.x-22exmp
