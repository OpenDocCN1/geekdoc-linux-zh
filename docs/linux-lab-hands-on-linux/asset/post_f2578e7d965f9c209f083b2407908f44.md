
## Creating Your First Java Program

Let's perform the following steps to create a Java program that accepts two numbers and then compute and print the result:

- 1. Create a Java source file.
- 2. Compile the source file into a byte code file.
- 3. Run the program contained in the byte code file.

Let's now learn how to create, compile, and run a Java program.

## Create a Java Source File

A source file contains text written in the Java programming language. You can use any text editor to create and edit source files.

- 1. Bring up a shell (sometimes called terminal) window.

When the prompt first appears, your current directory is usually your home directory. You can change your current directory to your home directory at any time by typing `cd` at the prompt and then pressing enter.

The Java files you create should be kept in a separate directory. You can create a directory by using the command `mkdir`. For example, to create the directory `java` in your home directory, you first need to change your current directory to your home directory by entering the following command:

```bash
cd
```

Then, you need to enter the following command:

```bash
mkdir java
```

You need to enter the following command to change your current directory to this new directory:

```bash
cd java
```

Now, you can start creating your source file.

- 2. Start an editor (nano in our case) by typing the name of the editor at the prompt and then press enter. When an editor is started, it displays a new blank buffer where you need to type your code.

- 3. Type the Java code.

- 4. Save the code by typing Ctrl-O in the editor. You can specify the desired file name (in our case, we have specified `simple.java`) preceded by the directory in which you want the file to save. If you wish to save `sample.java` in the directory `/home/Mahendra/java`, then you would type:

```bash
/home/Mahendra/java/sample.java
```

and press enter.

- 5. Type Ctrl-X to exit nano.

## Compile the Source File

The Java compiler, Javac, compiles the source file and translates its text into instructions that the Java Virtual Machine (Java VM) can understand. The compiler then stores these instructions into a byte code file.

- 1. Now, bring up another shell window. Change your current directory to the directory where your file is located to compile your source file. For example, if your source directory is /home/Mahendra/java, you would type the following command at the prompt and press return:

```bash
cd /home/smith/java
```

If you enter `pwd` at the prompt, you see the current directory, which in this example has been changed to /home/smith/java.

If you enter `ls` at the prompt, you see your file: sample.java.

- 2. Type the following command and then press Return to compile your file:

```bash
javac sample.java
```

After compiling, if you see the following error message:

```bash
javac: Command not found
```

Then, it means Linux is not able to find the Java compiler, Javac.

- 3. You can locate the javac compiler in Linux by typing the path where you have installed the Java 2 Platform. Suppose you have installed the Java 2 Platform (J2SE) in /usr/java/jdk1.4. In this case, you can type the following command at the prompt and press Return:

```bash
/usr/java/jdk1.4/bin/javac sample.java
```

## Run the Program

The Java VM is implemented by a Java interpreter called java. This interpreter translates the byte codes into instructions that can be understood by your computer.

- 1. In the same directory, enter at the prompt:

```bash
java sample
```

When you run the program, you need to enter two numbers when the black command line window appears. The program should then write out those two numbers plus the percentage computed by the program.

If you receive the following error message:

```bash
Exception in thread "main" java.lang.NoClassDefFoundError:sample
```

Then it means, Java cannot find your byte code file, sample.class.

- 2. Java tries to find your byte code file in your current directory. For example, if your byte code file is in /home/smith/java, you need to type the following command at the prompt and then press Return:

```bash
cd /home/smith/java
```

- 3. When you enter `pwd` at the prompt, you see /home/smith/java. If you enter `ls` at the prompt, you see your sample.java and sample.class files. Now enter `java sample` again. If you still have problems, you might have to change your CLASSPATH variable. To see if this is necessary, try "unsetting" the classpath with the following command:

```bash
unset CLASSPATH
```

Now, enter `java sample` again. If the program works now, you have to change your CLASSPATH variable.

### CONCEPTS

While working with C programming in Windows environment, you use the Turbo C compiler. Under the Linux environment, working on C programming is quite easy. You need to type your program code in a text editor and save the file with .c extension. Linux provides you a tool named GCC (GNU C and C++ compiler) to compile your program. In fact, GCC can compile C and C++ programming languages. Once your program is compiled and free from any syntax errors or any other types of errors, you can run your program and get the desired output. You can compile and run the program by using commands. Linux provides you GNOME Terminal application which is a type of command prompt where you can type Linux commands.

While compiling and running your program code, keep in mind the path where you have saved your file. Go to the current directory where your file has been saved or keep the file in the user folder as GNOME Terminal uses the default shell specified for the user who starts the application.

Use the following syntax to compile the program:

```bash
gcc [filename].c -o [filename]
```

Use the following syntax to run a program:

```bash
./[filename]
```
