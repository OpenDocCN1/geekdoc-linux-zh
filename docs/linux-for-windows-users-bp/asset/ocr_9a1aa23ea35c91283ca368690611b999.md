# ## History in *bash*

In order to bring up the last command used in *bash* press the **up cursor key**. The command can then be edited using the **left** and **right** cursor keys plus the **Delete** and **Backspace** keys. Press **Return** to execute the modified command string. There is also a sort of command line equivalent to a Windows history palette. Use this command to produce a command history:

`fc -l`

you can use flags to list only certain commands in the history list, as in these examples:

*   `fc -l 6`: Lists the last six commands
*   `fc -l 98 107`: List commands 99 to 107

These keyword codes can be used to execute previous commands:

| Code | Effect |
| :--- | :--- |
| `!` | Begin substitution |
| `!!` | Repeat last command |
| `!N` | Repeat command number N |
| `!-N` | Repeat the command N number of commands back |
| `!:String` | Repeat the most recent command starting with *String* |
| `!:String` | Repeat command N and append *String* |
| `!?String?` | Repeat the most recent command that contains *String* |

# ## KDE route map

These are the routes to various KDE applications and utilities via the “*K* menu.”

+   *   **System**
+       *   KFM - (Super User Mode)
+           *   System - File Manager (Super User Mode) - then supply password
+       *   Task Manager
+           *   System - Task Manager
+       *   Desktop Pager
+           *   System - Desktop Pager
+       *   XMan (the X Windows on-line manual)
+           *   System - XMan - Manual Page
+   *   **Settings**
+       *   Wallpaper settings
+           *   Settings - Desktop - Background
+       *   Desktop colour settings
+           *   Settings - Desktop - Colours
+       *   Screensaver settings
+           *   Settings - Desktop - Screensaver
+       *   Active desktop borders
+           *   Settings - Desktop - Borders
+       *   Desktop fonts (including size adjustment)
+           *   Settings - Desktop - Fonts
