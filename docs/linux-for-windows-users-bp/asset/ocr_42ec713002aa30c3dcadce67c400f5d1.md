There are two types of link, which are symbolic links (also known as soft links) and hard links. A symbolic link stores the path and file name for the file it links to. If the file it links to is moved or renamed, the link may be broken because it still points to the old path. A hard link, by contrast, is a second entry in the directory that points directly to the same data on the disk as the original file. A hard link can be moved or renamed, just like any other file. A hard link can be moved to a different directory because it is not a symbolic link, but it cannot be used across filesystems. When a file has more than one hard link, it will not be deleted from disk until all the hard links to it are removed.

# Creating links

In order to create a link, use the ln command. To create a symbolic link, use the -s option. The syntax is: ln [options] target linkname.

```
```
ln -s target symbolic_link
```

Example: Create a symbolic link from /home/user/docs to /home/user/my_docs:
```
ln -s /home/user/docs /home/user/my_docs
```
```

To create a hard link, simply omit the -s option. The syntax is: ln target hard_link. Note that you can only create hard links between files on the same filesystem.

# Managing links

+   - Use ls -l to list the links and see which files they point to.
+   - Use readlink to display the value of a symbolic link.
+   - Use file to determine the type of file.
+   - Use test or [ to test the properties of links.

# Using Links in Shell Scripts

Links can be used in shell scripts to make configuration files easier to manage. For example, you can create a symbolic link to a configuration file and change the link to point to a different configuration without modifying the script.
