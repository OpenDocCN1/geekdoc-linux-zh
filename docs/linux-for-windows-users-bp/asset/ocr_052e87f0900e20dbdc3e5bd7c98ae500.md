# **Getting started**

If you have bought a set of Linux discs complete with manuals it obviously makes sense to follow the instructions in the manual which will give you detailed accounts of how to install that particular version of Linux. If you have a magazine disc which includes instructions or some other documentation, use that. As the exact method of installation varies from one distribution to another and from one version to the next, I am not able to give comprehensive general guidance here. As you are installing what is essentially the same thing regardless of which distribution you are using, the general procedure is much the same.

Many of the steps are straightforward, so we will concentrate here on the more awkward aspects of installation.

In order to install Linux you normally have to boot-up the computer in a sort of mini-Linux so that the installation software can be run. In the past it was something like a set of boot disks in order to get Linux installed, but boot disks are not normally required with these days. So I would suggest that if you are supplied with a boot disk, buy a "boxed" version of Linux. It may be a bit more expensive but it's the only sensible option. If you don't have a suitable drive or bootable CD-ROM, try booting the basic version of the driver or co-op mode. It will be able to use the CD-ROM, but from this it will do no more than three critical tasks. Next, most of the time will be spent working with the CD-ROM Setup program. The CD-ROM must be in the CD-ROM drive so that all of the computer can use it. Any new computer must, for the time being, boot with a bootable floppy disk (bootable CD-ROM). In fact, the CD-ROM is usually no problem when using an ordinary ATAPI CD-ROM drive.

A modern AMD BIOS has a sort of simple graphical used interface, complete with support for some types of mouse. Select the "Advanced" option.
