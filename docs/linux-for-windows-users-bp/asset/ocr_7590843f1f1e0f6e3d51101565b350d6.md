# Printing

Printing a standard text file under MS/DOS is quite easy provided you have a printer that can handle ordinary ASCII files. You simply copy the file to the appropriate port. Printing practically anything under Windows is also quite easy. Windows provides a useful and virtual printer which can be able to communicate with the printer driver and fully exploit it (in theory anyway). Things are far less straightforward under Linux, but if it is possible to output directly it would be good to do so. Most of the files you wish to print out will be produced using an application such as ApskIIc, StarOffice or WordPerfect, all of which have their own ways of printing out to the printer. Some applications program, but others will only print out to a PostScript compatible printer. It is really a matter of taking each application as it comes.

Applications programs might go totally their own way with the handling of the printer, but it is advisable to have printer properties installed in Linux anyway. This will normally be included in the installation process, but it is possible to add or alter the printer configuration later.
