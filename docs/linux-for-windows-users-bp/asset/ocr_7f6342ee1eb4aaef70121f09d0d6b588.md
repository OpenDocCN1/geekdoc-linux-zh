For the sake of this example assume that you wish to archive the files in /root/temp to a floppy disc. First the floppy disc drive must be fitted with a disc having sufficient storage space, and then it must be mounted. This command would then have the desired effect, archiving the files to a single file called "but1.tar".

```
tar cWZ /mnt/floppy/but1.tar /root/temp
```

The c option tells tar to create a new archive, the f option instructs it to put the archive into a file, and the W option causes it to place messages on the screen showing exactly what it is doing. The V is optional, but the c and W are essential.

# ### Zipping

To do the same thing but compress the files in the archive the Z option would be added, as shown here:

```
tar cWZ /mnt/floppy/but1.tar /root/temp
```

The Z has not been put in uppercase by mistake. Some option letters case so as with symbolic links you have to be careful to use the right one, the usual being that from the options has also been omitted, and these options will not be included. To key a list of files in this zipped archive the following command would be used:

# ### Multi-volume

In the tar program it is possible to archive files to a device rather than a file. In other words you specify a device such as the floppy drive as the destination rather than a file. To do this the device must first be mounted of course. Suppose that the /root/temp directory is to be archived onto a floppy disc. First the floppy drive would be mounted using a command such as this:

```
mount /dev/fd0 /tmp
```

A blank floppy disc to take the archive should be placed in the drive before the mount command is issued. This command would then be used to make the archive on the floppy disc:

```
tar cvf /dev/fd0 /root/temp
```

The relatively low capacity of a floppy disc is a definite drawback when backing up directories, because the amount of data in the directory may well have several times capacity greater than the capacity of a single disc. Even with a higher capacity drive than the 1.44Mb floppy backup disc more data than a single floppy disc can hold, so one will have to use multiple floppy discs to archive large collections of data. The DOS and Unix archive programs get around this problem by enabling an archive file to be spread across several discs or tapes. The MS-DOS ARJ program and the Linux tar program can record several volumes for one disc or tape so they can be unarchived without having to worry about running out of space on a single disc. This is the multi-volume version of the previous example:

```
tar cvM /dev/fd0 /root/temp
```

The program will tell you when you need to change to the next disc in the set. The disc should be unmounted so that you can use them in the correct order when restoring files.
