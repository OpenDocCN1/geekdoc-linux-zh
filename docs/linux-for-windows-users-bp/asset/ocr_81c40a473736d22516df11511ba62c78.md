# ## Tar

When using Linux you are likely to encounter *tar* files before too long. These are tape archive files, and the *tar* command is primarily intended as a simple backup facility. The basic action of the *tar* command is to take a group of files and merge them into one long file. The same program can be used to restore the original files. Modern versions of this command can also compress the files so that they require less storage space. This command is more or less the Linux equivalent of a MSDOS or Windows ZIP compression program.

Modern computer storage tends to deal more in gigabytes than in megabytes, and compressive backing up is not in practical unless your computer is equipped with some form of mass storage device that can read and write data with the same kind of swiftness that the hard disk can read and write. Unless you have an Iomega Zip, Iomega Jaz, or a similar device of the same sort, then you are not going to be able to make backup of data in 750 megabytes of data in 5 minutes. However, using a CD-R or CD-RW, you can back up 750 megabytes in about 15 minutes. If you want to back up your files, you can use a USB device with at least 1GB of storage. This will allow you to back up your files in a matter of minutes.

Even if you do not use tar files from time to time, *tar* will most certainly have to deal with the use of tar files. Programs are almost *tar* files in terms of structure. Programs can contain characters that are distributed by operating systems will allow. It is quite likely that there will be problems with other operating systems will allow. It is quite likely that there will be problems with tar files that are larger than 1.5GB. The reason is that a tar file is limited to 1.5GB. If you want to back up files larger than 1.5GB, you can use the -G option to create a multi-volume tar archive. This will allow you to back up files larger than 1.5GB.
