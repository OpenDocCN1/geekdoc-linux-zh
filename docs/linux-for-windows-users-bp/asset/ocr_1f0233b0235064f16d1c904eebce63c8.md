# Open a terminal (console)

Use Control-T from the keyboard, or operate the terminal button in the Panel (the one with the monitor icon).

# Run a program

If it is not in the “K” menu, locate the program file using KFM and then left click on its icon or filename.

# Put a program icon on the desktop

Locate the program file using KFM, and drag it onto a vacant area of the desktop. Select Link from the pop-up menu. Left clicking on the icon will then run the program.

# Change virtual desktops

To move to another desktop simply left click on the appropriate desktop button on the panel (the buttons labeled from one to four). Alternatively, hold down the Control key and then keep pressing the Tab key to cycle through to the desktop you require.

# Make a window visible in all desktops

Click on the Sticky or Pin button in the title bar. Operating this button makes the window visible only when using that particular desktop.

# Start KFM

Click on the house icon in the panel. This starts a KFM in the Home directory, but you can move to the required directory from there.

# Make a new folder

Open the parent directory using KFM. Right click on a vacant area of the main window, select New from the popup menu, and then Folder. Type the name of the new folder in the edit box that appears and then left click on OK.

# Hide the Panel

Left click on an arrow at one end of the Panel. Left clicking on this arrow again restores the Panel.

# Autostart a program

Locate the program file using KFM and then drag it to the Autostart icon. Then select Link from the pop-up menu.

# Stop a program from starting automatically

To reverse the process left click on the Autostart icon. This opens a copy of KFM showing the contents of the Autostart folder. Simply delete the links for any programs that you do not require at start-up.

# Make a window visible in all desktops

Activate its Sticky icon.

# Move a window from one desktop to another

Activate its Sticky icon, switch to the desktop where it is required, and then deactivate the Sticky icon.

Note that some menu options and certain buttons are not operational under all circumstances. Inappropriate menu options are greyed-out (shown in light grey rather than black) and can not be selected. Similarly, inactive buttons do not appear to protrude slightly from the desktop, and can not be operated. This is the same method that is used in Windows and most other graphical user interfaces.
