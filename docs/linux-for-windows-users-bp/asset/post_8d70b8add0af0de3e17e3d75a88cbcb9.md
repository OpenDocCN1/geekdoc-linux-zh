
# Installation

## Spoil for choice

One slightly confusing aspect for the newcomer to Linux is that several different software houses produce it. To understand how this has come about we need to briefly examine the origins of Linux. Linux was produced by a group of individuals led by Linus Torvalds trying to write a version of the UNIX operating system meant for computers having one processor. In practice this effectively meant producing a version of UNIX for IBM PCs and compatibles, although there are some other computers based on Intel processors. UNIX is widely regarded as one of the most powerful and versatile operating systems available and is commonly encountered on high-end systems, particularly those used in scientific and technical applications. It is also used as the operating system for computer networks, of course. A group of people working via the Internet to produce something as complex as a UNIX-like operating system may seem to be a bit over-ambitious but the project was successful and has continued to blossom.

So what features does Linux offer, and who needs them? It has to be admitted that Linux is probably over-specified for many users. This is not necessarily a drawback, since you can simply ignore any features that you do not require. They are still there if you should need them at some later date.

## Multitasking

Linux has full multitasking capability, and will happily run unimpeded programs simultaneously if the hardware is up to the task.

## Multi-user

It is also able to support multiple users concurrently. This is really only of consequence when Linux is used in a computer network, which is something it handles very well. However, here we are only concerned with Linux as the operating system for workstations and concurrent multi-user operation is something that will not be considered further.

## Versions

Although Linux has a lot in its favour, there is one major drawback, and it is this that has resulted in various versions of Linux becoming available. Linux is a very powerful 32-bit operating system, but its most basic usable form is a command line interface (CLI). Commands are entered into a sort of editor, and when used, in this way it could be regarded as a very difficult to get Linux installed properly. This has led to various individuals and companies producing Linux enhancements that make it easier to use and (or) install. Whatever your source for Linux, you are unlikely to get just the Linux kernel. With a magazine version you will normally get one CD-ROM containing the Linux kernel and various support files, a program or programs to take you through the installation process and utility and applications as programs. There should be documentation. You should find some useful things as easy to install, particularly if you are a total Linux newbie. The documentation included on the disk, and possibly some source code.

If you buy Linux you will generally get more in the way of utilities and applications. Plus you will get more documentation. The quantity of material is such that a single CD-ROM is insufficient, and there are typically two to four CD-ROMs to a Linux set. With the cheaper versions implementations are supplied with manuals, with the more expensive documentation is little or no printed material, but a large amount of printed documentation. If you download Linux over the Internet or obtain it from a computer magazine, you are more likely to have to put in a lot of extra effort. This is not an exception, since these are the same. Support is only available if you have an Internet connection. If you buy Linux you should at least be able to have technical support for a limited period to help you get everything installed correctly.

## Security

As a byproduct of its multi-user capability, Linux has good security features. Each user has his or her own password, and can have files that are not accessible by administrator, and most changes to the system can only be implemented by logging in as the superuser. This should ensure that inexperienced users do not accidentally make changes that leave the system secure and stable. There is the option to use security features as well. Using security is easy to set up, but if you are a new user, it is difficult to set up, and can be very difficult for anyone who tries to execute as and interact with date files.

## Source code

Linux is often referred to as a free operating system, but this word is a bit ambiguous in a Linux context. It is often used in the free-speech meaning of the word, rather than the free-bread meaning. Most non-Linux software is sold on an as-is basis, and if it has minor bugs, it is nothing you can do. Expect support from the manufacturer who sold them. The problem is that when you purchase an operating system, you hope that the manufacturer will provide support in some form, but when it is free, they will not. The code is all that is available. Linux is much more accommodating than other operating systems. In theory, at any rate, you can alter the source code and compile the programs in order to tailor them to your exact requirements, or to remove any bugs that you might encounter. In reality, this sort of thing is well beyond the capabilities of most users, and hiring someone to do the job for you is likely to be prohibitively expensive. On the other hand, the Linux community has plenty of users who are prepared to use their expertise to help others who have no real understanding of the subject.

## It is free

One big draw/attraction of Linux for many is that it is also free in the free-bread sense. It can be downloaded from the Internet, although obtaining a reasonably full implementation of Linux in this way is likely to be very time consuming, even if you have a fast internet connection. It would probably take several days if you do not. From time to time computer magazines come out with CD-ROMs containing complete sets of Linux and this probably represents the best way to try out Linux at minimal cost. The third option is to buy Linux, which is where things can get a little confusing. There are several versions available, and in some cases more than one version of each version.
