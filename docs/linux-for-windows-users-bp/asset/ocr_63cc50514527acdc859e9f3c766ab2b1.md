The `locate` command will respond with any filenames that include the text string you use, and this might result in several files being suggested. With this example, because my computer responded with a list of eight files (Figure 2.4), I located files called “recovery” for instance. However, it is not usually too difficult to identify the one you require from the list I provided. Unfortunately, wildcards can not be used in the locate command.

# Date and time

The date command enables the date and time to be read, and also permits the time to be set by the "root" user. To get the computer to print the time and date on the screen you simply issue the straightforward date command:

```
date

It will then respond with something like this:

Sun Jul 18 22: 54: 23 BST 1999-07-18
```

There are numerous formatting options available that can be used to print the time in this type of thing. These options are used by adding "+" and the appropriate formatting string at the end of the command. This list gives some of the formatting strings and their functions.

| String | Function |
| --- | --- |
| %A | Abbreviated day name |
| %A | Full day name only |
| %b | Abbreviated month name |
| %B | Full month name |
| %D | mm/dd/yy format for date |
| %H | 24-hour format with leading zeros |
| %I | 12-hour format with leading zeros |
| %M | 12-hour format with no leading zeros |
| %j | Print the number of the day in the year (001 to 365) |
| %M | Minutes only |
| %p | AM/PM only |
| %r | 12-hour format with AM/PM |
| %t | Print week number of year (01 to 53) |
| %U | Year only |
| %Y | Time zone only |

This command would print the year:

date +"%Y"

This example would print the full name of the month and whether it is AM or PM:

date +"%B %p"

The month and AM/PM options are enclosed in quotation marks (with no space inserted between them, and the first quotation mark), and a two places of data can be used as separators on the screen. Any desired text characters can be used as separators, and in this version of the command a comma and a space will be placed between the month and the AM/PM indication.

date +"%B,%p"

# Setting the date

The system clock is set using the date command in this form:

date MM/DD/HH:mm/YYYY

+   - MM is the month and is a two-digit number from 01 to 12
+   - DD is the day and is a two-digit number from 01 to 31
+   - hh is the hour in 24-hour format and is from 00 to 23 (00 is midnight)
+   - mm is the minutes and is a two digit number from 00 to 59
+   - YYYY is the year in full four-digit format
