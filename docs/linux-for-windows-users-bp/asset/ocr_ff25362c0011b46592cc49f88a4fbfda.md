# Text editing

There are several text editors to choose from when using KDE. When you open a text file it is loaded into Kedit.

Two versions of this program are available via the “K” menu system. The normal version is accessed via Application and Text Editor (Figure 3.22). A slightly more advanced version of the program is also available via Applications and then Program Editor (Figure 3.23). Both versions are similar to the WordPad Editor that is normally installed with Windows 95 and 98, but in fact, some of the text formatting facilities.
