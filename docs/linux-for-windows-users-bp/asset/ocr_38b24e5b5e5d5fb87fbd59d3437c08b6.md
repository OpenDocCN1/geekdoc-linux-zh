# Installation

RPM can be used via a graphical front-end, and you may prefer to use it that way, but it is not difficult to use it from the command line. Note that you will probably have to log in as "root" in order to use RPM, since its use obviously involves changes to the system. To install a package using RPM use this command:

```
rpm -i package-name
```

If all is well, RPM will install the software plus any support files that it declares are included in the package. If RPM detects anything that is not well, it will give an error message explaining the problem. This is most likely to be where the package you are trying to install is dependent on another package being present on the computer, but this dependency is absent. The new package and installed no use without this other package which must be obtained and installed first. RPM should then be able to install the new package without any problems. It is actually possible to force RPM to install the software anyway using the --nodeps option, but doing so is pointless. The installed software would not run properly and could hang up the computer.

If RPM declares that it cannot install the package without overwriting a file or files belonging to another package, you can force it to do so with the --replacepkgs option, but you must understand the risks of using an overwrite of other files is a little risky:

```
rpm -i --replacepkgs package-name
```

A lot of software is loaded onto the hard disc during a typical Linux installation, so having taken the time to locate a program you may occasionally find that RPM informs you it is already on the system. If you select a large Linux installation it is worthwihle checking through the menus and the file system to determine exactly what has been installed. This could save a great deal of wasted time and effort later.

# Upgrading

The upgrade command is similar to the one for installing software "from scratch", but the upgrade (-U) option is used instead of the install (-i) option. This is the upgrade version of the RPM command.

```
rpm -U package-name
```

RPM can be used to uninstall programs, and it is just a matter of using the erase (-e) option in the command:

```
rpm -e package-name
```

Here the file name used in the command is the name of the program file, and not the name of the file that was used during installation (which will have numerous characters in addition to the basic name).
