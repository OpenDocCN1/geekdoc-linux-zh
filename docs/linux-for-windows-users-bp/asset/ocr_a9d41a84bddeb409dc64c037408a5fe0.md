# DIY icons

If you feel like producing your own icons there is a good icon editor
program available via the **K** menu. Selecting graphics and then Icon
Editor will launch the Icon editor and create program (Figure 4.28).

The icons have to be quite small at only 32 pixels by 32 pixels so don't
try to be too detailed when drawing tools down the left-hand side of a
window, but with simple the graphics such as icons it is often easier just to
add things one pixel at a time using the paintbrush tool. To select a
colour simply drag a colour from the paintbrush colour. Once a masterpiece is
complete it should be saved to the **opt/KDE/share/icons** folder with an
"**spin**" extension. KDE will then be able to locate in the Properties window
it should be included with the program icons in the standard icon. It can then be selected
and used just like any other icon.
