## Linux for Windows users

If you are familiar with Windows and would like to experiment with the Linux operating system, then this book is for you. Linux can be used with a Windows-like GUI, the most popular of which is now the K Desktop Environment (KDE) which is now supplied with many of the main versions of Linux.

This book provides advice on installing Linux onto a workstation, and then gets straight down to using the command interpreter and KDE to carry out everyday computing tasks. These include such things as copying and deleting files, running programs, installing and uninstalling software and printing out documents.

The reader is not assumed to be a computer expert but should have a basic working knowledge of Windows or a similar operating system. Wherever possible, parallels between Windows and Linux have been included to make the transition from using one system to the other as smooth as possible.

## Preface

Although once strictly for the knowledgeable enthusiast or computing professional, Linux now offers a real alternative to the mainstream, and/or operating systems from the major corporations. Unquestionably a big attraction of several operating systems is that it is free. You can actually buy Linux from CD-ROMs plus printed manuals, but it can also be downloaded free from the Internet. Probably most new users now obtain Linux in addition to a "free" CD-ROM given away with a user computer magazine. In addition to the operating system, there are usually many useful utilities and applications included free of charge on most Unix/Linux CD-ROMs.

It is not necessary to have a PC especially for Linux, and provided there is sufficient hard disk space it can coexist with another operating system using a dual-boot system. As most Linux software will run quite happily on something considerably less than the latest wonder PC, Linux can be used to give an old and otherwise unused PC a new lease of life. Linux tends to be associated with large networks, but it will function perfectly well as the operating system for a workstation. It is increasing in use at home, in this publication only its use with workstations is covered.

On the face of it, Linux is not all that different to a graphical user interface. It provides a command line interface similar to MS-DOS and a graphical user interface (GUI). There are some major differences though, and even the most accomplished of Windows users can have problems getting to grips with Linux. Unless you know how, even getting into Linux in the first place can be difficult. Many Linux publications got bogged down in the history of the operating system, technologies that are not initially relevant to most users, and arcane commands that are of little use to most users. This book takes the "cut to the chase" approach, concentrating on everyday computing with Linux. You do not have to be an expert to use a Linux system, and few of the many Windows users have more than a rudimentary understanding of the subject. The same is true with Linux, and it is not necessary to have an in-depth understanding to use the system. It is more helpful to have an understanding of basic concepts, and learn about the technologies later, as and when it becomes necessary.

## Contents

Where possible the conversion from Windows to Linux is made as "painless" as possible by drawing parallels between the two systems. It is assumed that the reader has a basic working knowledge of MS-DOS and Windows, but no more than this. In order to follow the material, no specific hardware is essential, but the command line interpreter any moderately recent version of Linux should suffice. There is more than one GUI available for Linux, but the K Desktop Environment (KDE) is the most widely used and is now included with all the major Linux distributions. To utilize the GUI material KDE version 1.0 will suffice, but you should preferably use version 1.1 or later.
