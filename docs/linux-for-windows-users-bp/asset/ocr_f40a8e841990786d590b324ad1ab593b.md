# Appendix 2

# Commands to remember

Command | Description
Cal | print a calendar for current month
cd | change directory
cp | copy a file
date | print the current date and time
dir | list files and folders
df | show how much disc space is free
du | show disc usage information
free | display memory information
ls | list files and folders
ls -color | list files using different colours for each type
ls -a | list all files (including hidden files)
ls -s | list files and their size
ls -t | list files in time order (newest first)
mkdir | make directory
mount | mount a device such as a disc drive
mv | move a file or folder
mkdir | move a directory
passwd | set or change a password
pwd | print the name of the current directory
rm | remove a file
rm -R | remove folder and its contents
rmdir | remove a directory
umount | unmount a device such as a disc drive

# Appendix 3

# Ghostscript printer support

A wide range of printers are supported using ghostscript, which can be used to convert the PostScript output of many Linux programs to suit these non-PostScript printers. The ghostscript program should be usable with these popular printers plus many others. The on-disc documentation on supported devices, ghostscript should give up-to-date information on the supported devices. Note that some standard graphics formats are also catered for.

+   Canon BubleJet B410e, LBJ201, BUC600, and BJC800
+   Canon LBP811
+   Epson 9-pin dot matrix series
+   Epson 24-pin dot matrix series
+   HP DeskJet, DeskJet Plus, and DeskJet 500
+   HP DeskJet 500C series
+   HP DeskJet 1200
+   HP LaserJet, LaserJet II Plus, LaserJet II, LaserJet III, LaserJet 4, etc.
+   HP PaintJet, PaintJet XL
+   IBM Jetprinter
+   IBM Proprinter

It should also be possible to use any printer that is fully compatible with one of the above, or has an appropriate emulation mode. Any HP DeskJet, LaserJet, or compatible that has a DOS printing mode should work with ghostscript.
