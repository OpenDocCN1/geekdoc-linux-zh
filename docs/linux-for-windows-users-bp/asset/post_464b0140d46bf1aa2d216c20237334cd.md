## Floppy copy

Like the Linux command line, KDE does not have a built-in copy facility for floppies. It is not reasonably easy to make an exact clone of a floppy disc, but using KFM it is possible to make an exact clone of a floppy disc in 3 steps. The obvious method is to insert a blank floppy disc in the drive and left-click on the icon, and then place the original disc in the drive and left-click on that icon. This will then copy the data from the blank disc to the disc in the drive. (The reverse is also true: you can copy the data from the original disc to the blank disc.) With a change to the blank disc and a press of the copy button in the KFM main window, you can copy the contents of the original disc to the blank disc.
