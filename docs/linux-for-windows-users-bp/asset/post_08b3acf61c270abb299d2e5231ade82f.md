### WordPerfect

Many versions of Linux are now supplied with so-called “personal” editions of commercial software. The exact conditions of use vary, but this type of software is normally enough for free use for noncommercial purposes. Naturally not complete, as we would expect, your machine should also have commercial non-exempt or non-free software such as a copy of either WordPerfect (Figure 3.25) or a copy of Corel WordPerfect. If you need a more complete version of a word processor you can buy a bigger licence to do a lot more. In my personal opinion, though, even a simple text editor is one of the most advanced text processors available: it is quite adequate for creating a simple document, and it is quite easy to learn from a quick reference card. I have used various versions of WordPerfect to write dozens of books.

The Linux version is not an exact clone of the Windows program, but it is very close. If you use MS WordPerfect for Windows or any other competing program as a template, you will find that the KDE version is easy to pick up after using KOffice with little effort. If you have an advanced graphics tool, you may find that the KDE version of KWord is not as fast as some other programs. There are a few differences in how you access some of the advanced features in KWord, but these should not be too difficult to learn.

In fact, the KDE version of KWord is a good place to start if you are new to office suites. It has advanced features and an interface that is easy to learn. It can be used as a word processor, a document checker, a thesaurus, or even as a web browser. However, because it is not a word processor, a single click in a document can select an entire line, so if you want to insert a word, you need to be careful where you click. ## Recap

After reading through the above material and experimenting with KFM you should soon be able to navigate the system and understand simple, basic “housekeeping” tasks such as copying and deleting files. Here is a quick recap of how some of the more common tasks are performed. Note that in most cases there is actually more than one way of performing the task, and that not all the possible methods are necessarily included here.

### Drag with the mouse

Point to the scroller (or whatever), hold down the left mouse button, move the mouse to make the required adjustment, and then release the left mouse button.

### Selecting files

Hold down the Control key and left-click on a file or files you wish to select. Alternatively, hold down the Left Mouse button and drag a frame around the files you wish to select, and then release the Left Mouse button.

and then add additional files to the selection by holding down the Control key and left-clicking on the appropriate icons. You can then hold down the Control key and add to a selection using the frame method.

### Select all files in a folder

Open the folder and then choose Select All from the Edit menu.

### Open a file or folder

Locate a program or KFM and then left-click on its icon or filename. If the file is not a program or a standard data type you will then have to select the program needed to open the file.

### Copy, Move, Link

Open two copies of KFM, one showing the source folder and one showing the destination folder. Select the item or items to be copied and drag them to a vacant screen area in the main window for the destination folder. Select Copy, Move or Link from the menu that pops up, as required. An alternative method of copying is to select the items and then choose Copy from the Edit menu. Open the destination folder and then select Paste from the edit menu. If a folder is copied or moved, so are all its contents.

### Overwriting

If you try to copy a file to a folder that already contains a file having the same name, KFM will produce the pop-up menu of Figure 3.27. If you left click on the Overwrite button the source file will replace the destination file. This enables a new version of a file to be inserted in place of an old version. It can also result in an old file obliterating a new one if you are not careful. When dealing with groups of files, Overwrite All will result in any files having duplicate names being overwritten. This obviously requires even more care to be exercised.

### Trash and Delete

To delete items select them and then choose Delete from the Edit menu. Alternatively, Select one or more items and then right click on one of them. Select Delete from the pop-up menu. Note that deleted items can not be recovered.

### Retrieving From Trash

Click on Trash to open its folder. The contents are then shown in a KFM window from where they can be copied and moved in the normal way.

### Emptying Trash

Right click on Trash and then select Empty Trash Bin from the pop-up menu (Figure 3.28).

### Close a window

Left click on the close button (the one marked with an “X”) on the title bar. Alternatively, if the Close button is absent choose Close from the File menu. Using Control-w will close the active window.

### Make a window active

Left click on an inactive part of the window, such as a part of the title bar that does not have any buttons. If you click on a button you will probably make the window active and operate the button as well. Only one window at a time can be active incidentally.

### Move a window

Point to a part of the title bar that does not contain any buttons and then drag the window to the desired position. Alternatively, press the Alt key and then drag the window using any point within the window as a handle.

### Minimise a window

Operate the iconify button on title bar (the button with a dot in the middle).

### Restore a window

Maximise on an appropriate section of the taskbar.

### Maximise a window

Left click on its Maximise/Restore button (the button marked with a square). Clicking on it again takes the window back to its normal size.
