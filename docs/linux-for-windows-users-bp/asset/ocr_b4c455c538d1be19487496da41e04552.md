# Copy, Move, Link

Open two copies of KFM, one showing the source folder and one showing the destination folder. Select the item or items to be copied and drag them to a vacant screen area in the main window for the destination folder. Select Copy, Move or Link from the menu that pops up, as required. An alternative method of copying is to select the items and then choose Copy from the Edit menu. Open the destination folder and then select Paste from the edit menu. If a folder is copied or moved, so are all its contents.

# Overwriting

If you try to copy a file to a folder that already contains a file having the same name, KFM will produce the pop-up menu of Figure 3.27. If you left click on the Overwrite button the source file will replace the destination file. This enables a new version of a file to be inserted in place of an old version. It can also result in an old file obliterating a new one if you are not careful. When dealing with groups of files, Overwrite All will result in any files having duplicate names being overwritten. This obviously requires even more care to be exercised.

# Trash and Delete

To delete items select them and then choose Delete from the Edit menu. Alternatively, Select one or more items and then right click on one of them. Select Delete from the pop-up menu. Note that deleted items can not be recovered.





# Retrieving From Trash

Click on Trash to open its folder. The contents are then shown in a KFM window from where they can be copied and moved in the normal way.

# Emptying Trash

Right click on Trash and then select Empty Trash Bin from the pop-up menu (Figure 3.28).

# Close a window

Left click on the close button (the one marked with an “X”) on the title bar. Alternatively, if the Close button is absent choose Close from the File menu. Using Control-w will close the active window.

# Make a window active

Left click on an inactive part of the window, such as a part of the title bar that does not have any buttons. If you click on a button you will probably make the window active and operate the button as well. Only one window at a time can be active incidentally.

# Move a window

Point to a part of the title bar that does not contain any buttons and then drag the window to the desired position. Alternatively, press the Alt key and then drag the window using any point within the window as a handle.

# Minimise a window

Operate the iconify button on title bar (the button with a dot in the middle).

# Restore a window

Maximise on an appropriate section of the taskbar.

# Maximise a window

Left click on its Maximise/Restore button (the button marked with a square). Clicking on it again takes the window back to its normal size.
