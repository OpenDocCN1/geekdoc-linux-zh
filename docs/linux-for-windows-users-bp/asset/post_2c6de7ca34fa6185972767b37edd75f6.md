## Installation

RPM can be used via a graphical front-end, and you may prefer to use it that way, but it is not difficult to use it from the command line. Note that you will probably have to log in as "root" in order to use RPM, since its use obviously involves changes to the system. To install a package using RPM use this command:

```
rpm -i package-name
```

If all is well, RPM will install the software plus any support files that it declares are included in the package. If RPM detects anything that is not well, it will give an error message explaining the problem. This is most likely to be where the package you are trying to install is dependent on another package being present on the computer, but this dependency is absent. The new package would be of no use without this other package which must be obtained and installed first. RPM should then be able to install the new package without any problems. It is actually possible to force RPM to install the software anyway using the `--nodeps` option, but doing so is pointless. The installed software would not run properly and could hang up the computer.

If RPM declares that it cannot install the package without overwriting a file or files belonging to another package, you can force it to do so with the `--replacepkgs` option, but you must understand the risks. The overwrite of other files is a little risky:

```
rpm -i --replacepkgs package-name
```

A lot of software is loaded onto the hard disc during a typical Linux installation, so having taken the time to locate a program you may occasionally find that RPM informs you it is already on the system. If you select a large Linux installation it is worthwhile checking through the menus and the file system to determine exactly what has been installed. This could save a great deal of wasted time and effort later.

## Upgrading

The upgrade command is similar to the one for installing software "from scratch", but the upgrade (`-U`) option is used instead of the install (`-i`) option. This is the upgrade version of the RPM command.

```
rpm -U package-name
```

RPM can be used to uninstall programs, and it is just a matter of using the erase (`-e`) option in the command:

```
rpm -e package-name
```

Here the file name used in the command is the name of the program file, and not the name of the file that was used during installation (which will have numerous characters in addition to the basic name).

## Extras

There are a number of useful little extra facilities available from the Linux command line, and one of these is the `cal` (calendar) command. In its most basic form you simply type this command:

```
cal
```

By default this command produces a calendar for the current month. You can specify the month and year if you require the calendar for something other than the current month. This command will print a calendar for June 2002:

```
cal 6 2002
```

It is important to give the year in full, and not to give just the last two digits (e.g. “99” for “1999”). If you do this you will get a calendar for the year 99, and it is just a matter of a special year for a while (Figure 2.3). This command will produce a calendar for the year 2001:

```
cal 2001
```

### Locating files

Linux has more than one file finding utility, some of which are easier to use than others. The `locate` command is relatively quick and easy to use. The speed is due to the program keeping a database of files on the hard disc, so when it searches for a file it does not have to look through the hard disc itself. For this command to work it must obviously have a database to work from. And the database is produced and then updated automatically at about 6.00 AM. You have to bear in mind that it will be more or less non-working if your PC runs from this time to the next update. But in the day, however, the database can be produced manually or updated using this command:

`/usr/bin/updatedb`

It will take a minute or so for this task to complete, but once it has done so you should be able to locate files by name quite quickly. You must log in as `root`.

Possible, but not very likely, there are cases where it is not possible to locate a file that the user wants, for example, if there has been a file that one wanted before the user can locate.

To locate a file you can simply issue the `locate` command and include the filename, as in this example:

`locate convert`

| `root@homeone /root]#` | `grep /usr/X11R6/bin/imagemagick/convert` | `p1` |
| `root@homeone /root]#` | `locate convert` |

## Date and time

The `date` command enables the date and time to be read, and also permits the time to be set by the "root" user. To get the computer to print the time and date on the screen you simply issue the straightforward `date` command:

```
date
```

It will then respond with something like this:

```
Sun Jul 18 22:54:23 BST 1999-07-18
```

There are numerous formatting options available that can be used to print the time in this format. These options are used by adding "+" and the appropriate formatting string at the end of the command. This list gives some of the formatting strings and their functions.

| String | Function |
| :--- | :--- |
| %A | Abbreviated day name |
| %A | Full day name only |
| %b | Abbreviated month name |
| %B | Full month name |
| %D | mm/dd/yy format for date |
| %H | 24-hour format with leading zeros |
| %I | 12-hour format with leading zeros |
| %M | Minutes only |
| %j | Print the number of the day in the year (001 to 365) |
| %p | AM/PM only |
| %r | 12-hour format with AM/PM |
| %U | Week only |
| %Y | Year only |

This command would print the year:

```
date +"%Y"
```

This example would print the full name of the month and whether it is AM or PM:

```
date +"%B %p"
```

The month and AM/PM options are enclosed in quotation marks (with no space inserted between them, and the first quotation mark), and two characters of data can be used as separators on the screen. Any desired text characters can be used as separators, and in this version of the command a comma and a space will be placed between the month and the AM/PM indication.

```
date +"%B,%p"
```

## Setting the date

The system clock is set using the `date` command in this form:

```
date MM/DD/HH:mm/YYYY
```

- `MM` is the month and is a two-digit number from 01 to 12
- `DD` is the day and is a two-digit number from 01 to 31
- `hh` is the hour in 24-hour format and is from 00 to 23 (00 is midnight)
- `mm` is the minutes and is a two digit number from 00 to 59
- `YYYY` is the year in full four-digit format

It is not possible to specify the seconds, which are set at zero when the command is used. This command will set the date and time to 7:23 PM (19:23) on the 16th February 2002:

```
date 021619232002
```

Of course, a command such as this affects the system will only work if the root user issues it. It is important to realise that the `date` command does not alter the PC's hardware clock, and what is really being adjusted is the software date read from the clock to give the specified time, which is simply a copy of the hardware clock. This means if you made significant changes, drift will be taken into account. Apart from any drift, the time will be taken directly from the hardware clock and applied unless a suitable source is used. For most PC users it is therefore better to obtain the time and date by going into the BIOS Setup program and correcting the hardware clock. The correct time and date will then be obtained even if the computer is switched off and rebooted.

## Word count

There are a number of commands concerned with text files, but these are not as necessary in a modern computing context. There are powerful text editors that can handle most of these functions in a more user-friendly fashion. One that might be of use is the `wc` command. If you wished to know the number of words in a text file called `/root/chap1.txt` this command would provide the answer:

```
wc /root/chap1.txt
```

```
321 10726 60403 /root/chap1.txt
```

When used without any flags this command actually tells you slightly more than the number of words. From left to right the three numbers shown represent the number of lines, words, and text characters. This file therefore contains 10726 words. Use the appropriate option or options from this list if you only require one or two parameters.

## Ispell

Ispell is the Linux interactive spell-checker, which integrates with some text editors but can also be used from the command line. To use it from the command line simply issue the command followed by the filename of the file to be checked. To check the file called `/root/chap1.txt` this command would be used:

```
ispell /root/chap1.txt
```
