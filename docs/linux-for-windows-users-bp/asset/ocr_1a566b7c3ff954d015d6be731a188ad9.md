Where possible the conversion from Windows to Linux, is made as
"painless" as possible by drawing parallels between the two systems. It
is assumed that the reader has a basic working knowledge of MS/DOS
and Windows, but no more than this. In order to follow the material
is essential, but the command line interpreter any moderately recent version
of Linux should suffice. There is more than one GUI available for Linux,
but the K Desktop Environment (KDE) is the most widely used and is
now included with all the major Linux distributions. To utilize the GUI
material KDE version 1.0 will suffice, but you should preferably use
version 1.1 or later.

R.A. Perifold
