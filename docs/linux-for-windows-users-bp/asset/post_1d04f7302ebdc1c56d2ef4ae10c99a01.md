### Indirect printing

If you have an application that refuses to “talk” properly to your printer and just sends a stream of text (such as PostScript data, for instance), the best (for print only) approach is to use an intermediate application. WordPerfect is supplied with many Linux distributions, and it works with a wide range of printers. It can import text files and various forms of graphic files. It is often possible to use an “awkward” application to save a file to disc in a standard format, after which it can be imported into WordPerfect, and printed out. This is a roundabout way of doing things, but the print quality is likely to be limited by the printer rather than any file format conversions. Graphics can be easily dragged to the required size with WordPerfect and then printed out at the required size.

Another indirect approach is to use the Ghostscript application that will almost certainly be installed on the system. This program can take a PostScript file and convert it into output that is suitable for a range of popular printers such as Hewlett Packard DeskJets, LaserJets, and compatibles. Many Linux applications can “print” their PostScript output to a file on the hard disc, and can therefore be made to drive a range of non-PostScript printers via Ghostscript. If Ghostscript is on the system, the version number can be checked in the documentation. The 5.10 porting path is `/usr/share/ghostscript/5.10/`. If you are not using this path, the version number will be different.

This is a command line utility, and it is not the most straightforward of programs to use. Find the easiest way to use it to send the output of a file, and to then print the file via the Printing Queue utility. Suppose you have a PostScript file in the current directory called `Picture.ps`, and you wish to produce a Laserjet printer file called `Print.ps`. This command would have the desired effect:

```bash
gs -dDEVICE=laserjet -sOutputFile=Print.ps Picture.ps
```

Be careful to use upper and lower case letters in the appropriate places. Having a printer file is convenient if you need to print the document again later, but otherwise there should be no problem in sending the output direct to the printer, as in this version of the command.

```bash
gs -dDEVICE=laserjet -sOutputFile=/dev/lp0 Picture.ps
```

Of course, if the printer is at other than `/dev/lp0` the appropriate path must be used instead. You may find that the system is left in Ghostscript with a “GS” prompt instead of the usual Linux prompt. Simply use the Control-c key combination to exit to the Linux prompt. For brief help on the Ghostscript utility, including a list of the supported output devices, use this command:

```bash
gs --help
```

Some of the “devices” are actually graphics file formats, but a useful range of printers is supported.

## Kill

Linux is generally very stable, but no operating system can guarantee to be totally reliable since the applications software and the hardware can interact in unexpected ways. If a program stops responding, it may be necessary to terminate it from the console. Killing the right task is something less than straightforward using this method, but the KDE Task Manager makes things much easier. Clicking *System* in the *Task Manager*’s main tool bar makes an area called *Resources* appear. This shows data for all the tasks in a window, and *Resources* also has a small chart for each task, so it is easy to locate the right one and terminate it using the *Kill Task* button. The *Task Manager* is the Linux equivalent of the Windows *Ctrl*-*Alt*-*Delete* Close Program window (it should only be used as a last resort and not as a normal way of terminating programs. Another factor in common with its Windows counterpart is that it shows the background processes and not just the programs that are in open windows. You will therefore find numerous processes running that you probably had not realised were running.)

If the Processes tree tab is operated the window changes to show the running tasks in tree form, but the program otherwise functions as before. The Performance tab switches to a completely different window that enables the CPU loading and memory to be monitored (Figure 4.41).

## Finally

If you have followed the story so far you will not be an expert on Linux, but you should be able to install this operating system on a PC and use it to good effect. You should also be able to install and run applications, check that you are not running out of hard disc space, copy files, tailor the KDE desktop to suit your requirements, format floppy discs, and do all the other essential tasks that you can (almost) do with Windows. Shut down KDE using the menus at the top of the screen. If you have installed a Linux distribution then you should also be able to switch from this to another, but there will usually be one or two joke programs such as *Xeyes*, which is a pair of eyes on the screen (Figure 4.42). ### Recap

#### View or change permissions

Right-click on the file or folder icon in KFM, select Properties and then left-click on the Permissions tab.

#### Show permissions (command line)

Use the `ls` command with the “-l” option.

#### Add a group (command line)

Use “groupadd -g 121 [groupId] [groupName]”

#### Format a floppy disc

Activate the “K” menu, and then select Utilities and KFloppy. Choose the required disc size and format and then left-click on the Format button.

#### Change the wallpaper

Activate the “K” menu and then select Settings, Desktop, and Background. Click away menu to select the required background and design, colour scheme, etc. and left-click on the OK button when you have finished. Left-clicking the Apply button enables you to see the new settings without exiting the Display Settings window.

#### Add/remove desktops

Activate the “K” menu, select Panel and then Configure. Select, from the Desktops tab, the number of desktops you want. You can turn it back later.

#### Change the Panel position

Activate the “K” menu, select Panel and then Configure. Select, from the Position tab, the position of the Panel. You can use the up/down buttons to change its position. Alternatively, you can click and drag the Panel to the position you want.

#### Add an icon to Panel

Find the program you want to use and select it. Then left-click on the “K” menu, select Panel and then Configure. Select, from the Add tab, the position of the Panel. You can use the up/down buttons to change its position.

#### Remove an icon from Panel

Right-click on the icon and select Remove.

#### Move an icon on Panel

Right-click on the icon, select Move, move it to the new position and then left-click.

#### Change the Panel size

Select Panel and Configure from the “K” menu. Then select “Tiny”, “Normal”, or “Large” from the panel buttons. Operate the Apply button to see the changes without exiting the configuration window.

#### Make an icon

Cross graphics and then Icon Editor from the “K” menu. Draw your icon and save it with a .xpm extension and save in `/opt/kde/share/icons/`. You can also use this program to edit existing icons.

#### Install a RPM package

Find the RPM file using KFM and then left-click on it. Select the appropriate options from the window that appears.
