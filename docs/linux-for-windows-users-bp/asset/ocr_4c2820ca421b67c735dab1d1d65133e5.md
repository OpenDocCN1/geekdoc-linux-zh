Brief details of a file or folder are provided in the status line at the bottom of the window. You place the cursor over an icon. In KWin/KDM, this gives you a balloon with a brief description of the selected file; in Nautilus, a pop-up window appears with similar information. If you right-click on an icon, a pull-down menu appears for you to select a program registered to deal with the icon. As far as possible, you should not have problems with the standard file types, such as PDF, GIF, JPEG, and plain text file. Right clicking on an icon brings up a small menu, as in Figure 3.5. This menu gives access to some basic tasks.

# Delete/Trash

The delete option is effectively the same as using the rm command of Unix. The difference is that it is called in this fashion: a file selected in this fashion is not actually deleted, but moved to a folder called the Trash. This is the same as dragging the file to the Trash icon, and it can be recovered until it is emptied from Trash.

# Open with

This option brings up a dialogue box into which the name of the program (including the path) used to open the file is typed. Alternatively, the browse button can be used to locate and launch the file (Figure 3.5). The dialog box also gives an option to copy the file to the current working folder. In this case it is necessary to double left click on a folder or program in order to open it.

# Copy

This is very much like copying to the Windows Clipboard. Having copied the file, you can then move to another folder and right click anywhere in the main window area. This brings up a menu which includes a Paste option. Selecting this copies the file into the current folder. There is no copy/paste facility in the Windows equivalent, but there is one copy/paste into the desktop. It is not available in the form of a move facility (i.e. drag the file into a new folder), but it is easy to delete the file and then paste it to the new destination. It has an arrow to the new location in the Move option when being selected.
