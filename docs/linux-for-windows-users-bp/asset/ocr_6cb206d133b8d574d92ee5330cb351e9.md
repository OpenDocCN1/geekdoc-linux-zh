# ### Multi-user

The three previous chapters covered the things you need to know in order to get Linux installed on your PC, and use the system to run applications, copy files etc. using either the command line interface or KDE. In this chapter we will delve a little deeper, covering a range of topics that you need to know about in order to use a Linux system effectively.

As we saw in previous chapters, in order to use Linux it is necessary to log in under a user name, and to give the corresponding password. This is much more work than the boot process takes even on a small, modern, fast PC: to make the computer run a simple program might require a login and password, and then perhaps one or more mouse clicks or a series of keystrokes in order to make the computer. This extra time and effort means that even using a very fast computer requires a reasonable amount of thought to use the machine. Provided each user does not require much time at a time. The problem with this approach is that there is a lack of privacy for the users. This is not just a matter of other users having access to what might be someone else's private information. With a free-for-all approach to things there is a real danger of one user accidentally altering or erasing data belonging to other users. In fact the system could gradually degrade into a complete shambles.

With a multi-user operating system such as Linux you login under a name and password so that the operating system always knows who is using the computer. It would be an exaggeration to say that the system looks completely different to each user, and that it is like each one having their own PC. However, to some extent the computer will be personalised for the current user. The differences are perhaps more obvious when running KDE than when using the command line interface.
