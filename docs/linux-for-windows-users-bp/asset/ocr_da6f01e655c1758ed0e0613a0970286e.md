One of these screens enables the user to select whether or not to have icons on the desktop for two floppy disc drives and the CD-ROM drive (Figure 4.8). If you did not have these icons added when KDE was first run, they can be added at a later date by running the KDE Configuration Wizard again. Operate the “K” button in the Panel, then select Utilities and KDE Configuration Wizard from the menu system.

If you do select the disc icons, the appropriate icons should be added to the desktop beneath KDE desktop, and that this set-up process has to be repeated for each user. In order to access a standard CD-ROM you can simply place it in the drive and then click on the CD-ROM icon. This will launch a KFM window that displays the contents of what is the root directory of the CD-ROM in M$DOS/Windows terminology.
