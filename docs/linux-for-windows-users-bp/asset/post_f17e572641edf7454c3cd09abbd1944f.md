There are now main versions of Linux, or distributions as they are called in the generally accepted terminology. Any of these will provide you with a good usable Linux distribution, and make the installation process reasonably hassle free. Here are brief details of each distribution.

### Red Hat

The Red Hat distribution is almost certainly the most popular, and this is the big name in the Linux world. Red Hat has received funding from large companies such as Intel, which should enable it to develop Linux more rapidly. Red Hat distributions include the GNOME graphical user interface and the RPM (Red Hat Package Manager) software installation system. I suppose this should be considered the 'safe' option, since most Linux software will run under a recent Red Hat version. It is also quite easy to install Red Hat Linux.

### Caldera

There are actually two distributions of Caldera Open Linux, which are the normal and "Lite" versions. The standard distribution is aimed at corporate users, and due to its commercial content is not freely distributable. Open Linux Lite lacks the commercial software and can be freely distributed. Until recently neither version was widely available. It is in the UK, but the full version now seems to be readily available. It includes supplemental KDE formats a central part of the system. Caldera Open Linux reasonably complete with a central part of the system. Caldera Open Linux reasonably simple to install and use, and in the latest versions can be easily installed alongside Windows in a dual boot set-up. For a first-time user it is quite a good choice.

### Slackware

This is one of the oldest distributions, and is felt by some to be less go ahead than the other main distributions. It is a good usable version of Linux though, and it is reasonably easy to install. It is readily available in the UK, and is available quite cheaply if you will settle for the CDs with no printed manuals.

### SuSE

The other three distributions originate in the USA, but SuSE Linux comes from Germany. It has become quite popular in Europe, including the UK where it is readily available. It is apparently less easy to obtain than the other two distributions outside Europe. This is expected, as it is a distribution that comes complete with the KDE graphical user interface. I have sometimes found SuSE Linux a little awkward to get up and running, but with a little determination beginners should be able to get it working properly. Updates of the English language version tend to lag slightly behind the German version.

There are actually a number of other distributions, such as Debian and Turbo Linux, but these would seem to be less widely available in the UK than the four distributions listed above. For newcomers it is probably best to use one of the main distributions, and any of them should give good stable results.

### The numbers game

With most operating systems new versions are few and far between. I have one PC which is now several years old and nearing the end of its useful operating life, but with the advent of newer, faster PCs the current operating system is still the current version. Things are very different with Linux, where there seems to be a constant stream of new distributions. The first number indicates the kernel itself, and with the lines 2.2.4. The first number indicates the kernel itself, and changes very infrequently the second digit is the minor version, and this changes every few months, or less. It is best to avoid old numbers that have been superseded, but at this time it is best to avoid old numbers, or less. It is best to avoid odd numbers (odd-numbered minor versions), as these are development versions. Kernel, or what would we consider beta code in normal computing terms. Kernels of this type are not supplied with the main Linux distributions. At the time of writing this, the most up-to-date minor version is version 2.4, but this has not yet found its way into all the main distributions.

Linux distributions normally have two digit version numbers like 2.5.3 or 6.0, but like most Windows software, the second digit is likely to change about twice per year, with the first digit changing about every two years when there is some major change. If you have a version of Linux that is a decimal point or two behind the current version it is not completely up-to-date, but on the other hand it is not really out of date either.

## Hardware

Linux is a powerful 32-bit operating system, so do you need a powerful PC in order to run it properly? This is a "how long is a piece of string" type question and the hardware requirements depend on the application you want to use. It also depends on whether you require a "bare bones" minimum installation or an "all singing all dancing" version. The absolute minimum needed to run Linux is a PC having an 80386 microprocessor, about 8 MB of memory, approximately 54 MB of hard disk space, a mouse, supported video card, and a CD-ROM drive. Although a PC version of Linux will run on a computer as basic as this, it would be misleading to suggest that this is all you need to run Linux effectively.

### Hard drive

The basic Linux operating system uses a command line interpreter where you type in commands, much like using MS-DOS. To fully utilize this operating system you really need to install X Windows, which roughly doubles the amount of disc space required. It also advantages you to set aside some disc space for use as a swap file. This is space that the operating system will use for temporary file storage, and up to 100 MB can be used. The swap space is normally at least equal to the amount of memory fitted to the computer. Last, and by no means least, you will need some disc space for applications and utility software. Even a very minimal Linux distribution has a single CD-ROM which contains many megabytes of useful utilities and some applications complete, and many Linux installation takes up about 350 to 450 MB initially. Plus space for data files. Do not forget that you will also need some space to use as a swap file. As a guide, you will also need something like a 340 MB drive for a reasonably full and exercise installation. 850 MB or more is preferable.

### Processor

Although Linux tends to be less demanding on the processor than many other operating systems, it would be unrealistic to load it onto an old 33 MHz 80386 based PC and expect it to run like the latest Pentium wonder.

Computers. If you are going to use X Windows and some of the more powerful application programs you will require at least a fast 80486 based PC, and preferably some sort of Pentium processor, but for most use software may require a 100 MHz Pentium processor or is adequate.

### Memory

Although 8 MB of memory should be sufficient to get Linux "up and running", it is definitely preferable to have more than this. You could probably get by quite well with 16 MB, but everything is likely to run faster and more smoothly with 32 MB or more. Some of the more advanced application programs require a minimum of 32 MB. As memory is quite cheap these days it does not really make sense to skip on it unnecessarily. It would be well worth while investing in a memory upgrade. This leaves plenty of "headroom" if you need to do multitasking.

### CD-ROM

It is possible to install some older versions of Linux from floppy discs, but modern distributions are supplied on one or more CD-ROMs, and you will therefore need some sort of CD-ROM drive. Installation is much quicker when using a CD, and an old 2x drive will do. However, a CD-ROM drive with some ordinary ATAPI (IDE) interface should give no problems, but some SCSI drives might not be supported. The more common the hardware in your computer, the better the chances of getting it to work well with Linux.

### Pointing devices

Practically any mouse which is suitable, and Linux supports serial, bus, and PS/2 mice. In theory a three-button mouse is required, but a two-button mouse can provide an emulation of the middle-button type. Pressing both buttons simulates pressing the middle mouse on the third button. If you should have problems getting Linux to talk to a mouse, a different computer may be purchased. One drawback to using a mouse today, so this is not really a major problem. If you wish to use a graphical tablets or some other exotic form of pointing device you may find that it will not work with Linux.
