## Floppy formatting

A disc-formatting program will be needed if you need to format floppy discs. There seems to be no alternative to the disc-formatting function built into KDE. Unfortunately, KDE does not provide a tool that is good at disc-formatting a program that can be run at the command line. The KDE disc-formatting program can be accessed via the “k” menu but it will only start if you select Utilities and then Kfloppy. A window of the type shown in Figure 4.13 should appear. This program is very straightforward to use, and is similar to the disc-formatting utility found in Windows 95 and 98. The only options available are Quick and Full options which respectively erase the disc and perform a full format of the disc. Only the Full option is usable with a disc that has not been previously formatted. It has been tested on 1.44 MB 3.5" floppies.

![](img/147f057d2f063d8c60ee616870537a94_73_0.png)

There is the option of DOS-formatted floppy discs. There, in fact, are two main types: FAT12 and FAT16. Linux handles these formats quite happily. Microsoft Windows, on the other hand, can only read FAT12. FAT16 discs are not supported by Windows. It makes little sense to use these types of formats, as you have no direct interaction with the underlying operating system. If you are using any PC running MS-DOS or Windows, then it makes sense to use DOS-format discs with KDE, as this makes it easy to swap data between the PC and DOS.

DOS-format discs will work quite happily reading high or double density 3.5" discs. However, there is no way for KDE to write MS-DOS or Windows formats unless you use a special utility.

The format program should be able to handle older 5.25" discs, but I have never actually tried it. MS-DOS and Windows are unable to read from or write to Linux format discs.

## Customising KDE

Like most graphical user interfaces, KDE enables the user to customise the appearance and feel of the desktop by setting the so-called “KDE Look and Feel” settings. This is done via the System Settings menu under Desktop and Background. This is where you will see a window that will allow you to select the background color, pattern, and wallpaper. The System Settings program is very easy to use. It is similar to the KDE Control Center in older versions.

There are many different options for customising your desktop. You can change the color of the menu bar, the taskbar, and the desktop itself. You can also change the look of the window decorations, the fonts used for window titles and icons, and even the animation speed of window transitions. All of these settings can be accessed and modified through the System Settings dialog.

## Border controls

It is possible to have automatic switching between desktops if desired. This works on the basis of automatically switching to the next desktop if you move the pointer to an appropriate edge of the screen. The relative positions of the virtual desktops match up with their buttons on the panel.

![](img/147f057d2f063d8c60ee616870537a94_76_0.png)

**Fig. 4.20 Setting active borders in the KDE Control Center**

Using the Active Borders feature you can move a window from one desktop to another by dragging it to an edge of the screen. When the pointer hits the edge of the screen the system moves on to the next desktop, taking the window with it. Another method of switching a window from one desktop to another is to select Desktop from the submenu, below the window menu, and then select the required desktop from the fly-out window.

## Desktop Pager

The Desktop Pager application offers another way of moving a window from one desktop to another. To run this program, activate the “K” menu and then select the System, Pager option. This should result in a small window opening in the bottom left-hand corner of the screen (just above the Panel; Figure 4.21). If you are only using two virtual desktops this window will show thumbnail views for both of them.

If the system is set for four or more desktops only the first two will be shown in thumbnail views, but by left-clicking on the arrows it is possible to scroll along to the other desktops. Alternatively, the window can be dragged to a different size in the usual way, and if a suitable aspect ratio is selected all the desktops will be visible. By double clicking on a thumbnail the system is moved into that desktop.

The thumbnail views only show a grey rectangle, and show no details of the window’s contents. However, you can find basic details of a window by right-clicking on it, and bringing up the window menu. This will show up the window’s details. The window menu is available from any part of the window.
