# Adding users

Linux is, of course, a multi-user system, and it is possible to have a large number of users share the same computer. This is a subject that is covered in more detail in chapter 4, and here we will only cover the addition of users to the installation process. At least one user account must be started during the installation process, and this is the "root" account for the superuser. The "root" account has complete access to the system and can make drastic changes to the system. For this reason due care has to be exercised when logging in as "root", or the system could be inadvertently trashed. The normal way of handling things is to log in as "root" when changes must be made to the system, but to login as a normal user at other times, even if you are the only person who will use the computer.

There may be an opportunity to add users during the installation process, and if this should be the case I would advise adding at least one user (you) at this stage. In fact it is a good idea to add further accounts later on if it will be needed. If the command line needs to be added further the adduser command can be used from the command line using the adduser command. This is necessary to add it to the installation in most typical installations, but it might be minimal and included in the installation if you have installed some form of a non-typical distribution. Note that the adduser command is only available when you are logged in as "root". To add a user called "Fred" you would use this command:

adduser Fred
