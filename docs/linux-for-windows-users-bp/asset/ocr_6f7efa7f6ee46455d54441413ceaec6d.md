# Linux for Windows users

If you are familiar with Windows and would like to experiment with the Linux operating system, then this book is for you. Linux can be used with a Windows-like GUI, the most popular of which is now the K Desktop Environment (KDE) which is now supplied with many of the main versions of Linux.

This book provides advice on installing Linux onto a workstation, and then gets straight down to using the command interpreter and KDE to carry out everyday computing tasks. These include such things as copying and deleting files, running programs, installing and uninstalling software and printing out documents.

The reader is not assumed to be a computer expert but should have a basic working knowledge of Windows or a similar operating system. Wherever possible, parallels between Windows and Linux have been included to make the transition from using one system to the other as smooth as possible.
