# X Windows

Assuming you have elected to install the X Windows system, this will probably require a certain amount of manual configuration. With some recent versions of Linux the installation process will try to determine the hardware present by a system of software probing, if this is successful the probing process will be less than manual configuration, but it is likely that you will still have to do some manual configuration. The X config file contains a large amount of configuration information about the type of mouse you use, probing is only used for this. You will also need the amount of memory on the video card, or something else. The initial XFree86 Setup program is normally achieved using the XF86Setup program.

Manual configuration is normally achieved using the XF86Setup program. It asked if you wish to run this now or later I would suggest screen explaining that the “Now” actually means it will be postponed until a little later! When the configuration program is finally run it provides an initial help screen (Figure 1.5), which helps with navigation around the program. Some information about the type of mouse in use is usually requested prior to the XF86Setup program being run, and will very easily to navigate your way will be working from the outset. It then runs a menu of items including the mouse configuration options. The page in Figure 1.5 is used to control this until the mouse is working. Assuming you know exactly what type of mouse you are using there should be no problem getting it to work properly.

One area of confusion concerns Logitech mice. The Logitech mouse does not work with modern Logitech serial mouse, and does not support with my slightly ancient Logitech mouse, unless you have a genuine antique ‘Logitech mouse’ it is the Microsoft option that should be used. If there is a generic serial mouse option this should also work for practically any serial mouse. Many computers are supplied with serial mice that are not produced by one of the main mice manufacturers. Again, the Microsoft or generic serial mouse options should give good results.
