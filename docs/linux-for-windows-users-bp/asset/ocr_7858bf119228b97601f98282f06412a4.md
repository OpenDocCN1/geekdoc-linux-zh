# ### Security

As a byproduct of its multi-user capability, Linux has good security features. Each user has his or her own password, and can have files that are not accessible by administrator, and most changes to the system can only be implemented by logging in as the superuser. This should ensure that inexperienced users do not accidentally make changes that leave the system secure and stable. There is the option to use security features as well. Using security is easy to set up, but if you are a new user, it is difficult to set up, and can be very difficult for anyone who tries to execute as and inter with date files.

Linux is often referred to as a free operating system, but this word is a bit ambiguous in a Linux context.
