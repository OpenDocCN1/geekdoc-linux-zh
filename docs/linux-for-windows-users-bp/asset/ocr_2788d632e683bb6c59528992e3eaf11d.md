# Options

The Options menu (Figure 3.17) enables the menu bar, status bar, location bar, and toolbar as required. The save option on the Save Settings row saves the current settings as new defaults, and they will be used whenever KFM is run in the future. Of course, these defaults are not affected if each user or other users settings is used. The Configurer File Manager option brings up another menu (Figure 3.16) which enables things such as changing the font and color scheme. # Go

At the bottom of the Go menu you will find a list of files and folders that have recently been opened using KFM (Figure 3.16). This is much the same as the “Recent” list in Windows and anything in the list can be opened by selecting it.
