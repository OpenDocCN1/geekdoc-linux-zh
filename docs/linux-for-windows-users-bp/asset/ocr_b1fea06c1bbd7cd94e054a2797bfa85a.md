# ### A Linux GUI

The Linux command interpreter has a wide range of commands, and it can be programmed to make light work of complex and repetitive tasks.

It is undoubtedly very powerful, but like any command line interpreter, it does not score well in terms of user-friendliness. These days most users prefer a graphical user interface, and will not settle for anything less.

Linux has more than one graphical user interface to choose from, but one that is most widely used is normally just called KDE, is the K Desktop Environment, which is central to some of them. 4.21 bit Caldera Open Linux. Superficially KDE looks a bit like a 32-bit version of Windows, and with the latest version you can select a Windows look to the desktop if you like. BEOS and Mac flavours of the desktop are also on offer.

However, below the surface KDE is significantly different to Windows, or any other operating system. You can select a Windows, BEOS, or Mac look to the desktop, but KDE still operates in more or less standard KDE fashion. For someone used to any other graphical user interface there is a certain amount of learning to do before getting fully in control of things. On the other hand, with a little experimentation you can soon start to find your way around the system, and undertake a few basic tasks. If you are not familiar with the Linux file system used by Linux, before getting too deeply into KDE. It is necessary to read the parts of the previous chapter that deal with the Linux directory structure. Setting up and using KDE should then be reasonably pain-free.

# #### Versions

Like everything else in the world of computing, KDE is gradually evolving. At the time of writing this there are only two versions of KDE, which are versions 1.0 and 1.1. The latter is quite new, and should soon take over from version 1.0. Obviously you must have KDE installed on your PC in order to use it.
