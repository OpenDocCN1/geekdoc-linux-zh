# Command Line

So what exactly is a command line interpreter? When Linux is booted up you are greeted with an on-screen message called a prompt, which should be something like this:

It will probably be headed by a Linux version number, a copyright notice, or something of this nature, but the important bit is the prompt which is telling you it is time to enter a name and start the login process. Your response by typing in the appropriate name and pressing the Return key. The computer then responds by asking for the password. If you enter the wrong password, you will make a major mistake.

You should be a good password as it can reveal a lot about you, and the computer has to log the error code as well. If there is something wrong with your input, it prints an error message by carrying out the appropriate action. Computers are very unforgiving, and an error message will result if you enter the wrong password. In fact there are numerous ways to make a mistake in the login process. If the error message is confusing, you can be certain that the computer knows what you were trying to do (as long as you keep your password safe). It can get rather difficult to figure out what the actual problem was, but if you have a Linux installation expert, it should be easy to fix.

No one is ever going to accuse your computer of being user-friendly. On the other hand, typing in a command can almost instantly perform complex tasks that would be difficult or impossible using a graphical user interface. With most Linux systems the computer is ready for command line input once it has booted up and a user has logged in. # Shells

When dealing with Linux you will often encounter the word “shell”. When people speak of their operating system they will refer to the shell and not the kernel. In most Linux systems, the shell is the main user interface. When you are using the basic command line interpreter, the one that makes the basic command line interpreter easier to use, but does not go as far as a full graphical user interface. With MS/DOS the command line interpreter is not normally considered to be a shell, but is accepted as an integral part of the operating system. With Linux the situation is different, and the actual part of the command line interpreter and the system that provides the user with a shell.

The shell program acts as an interface between the user and the Linux kernel. Linux has been produced in a layered fashion of three types. The operating system is the lowest layer. The next layer is the kernel, which manages the basic hardware functions such as memory management, process scheduling, and input/output. The third layer is the shell, which provides the user with a command-line interface. This is the layer that the user interacts with most directly. The shell accepts commands from the user and executes them. The most common shell is the Bourne shell (sh), but there are many others such as the C shell (csh), the Bourne Again Shell (bash), and the Korn shell (ksh).

Linux user interfaces have their roots in the early days of computing. There was no GUI, so users had to type commands to perform tasks. The shell was the first and most important user interface. It allowed users to interact with the computer and control its operations. The shell is a command-line interpreter that provides access to the operating system services. It is a type of software that acts as an intermediary between the user and the operating system. The shell accepts input from the user and translates it into commands for the operating system to execute. The shell also displays the output of the commands to the user.

```
$/bin/bash
echo $SHELL
```

If you get an error message when you type this command, it means that your shell is not installed on your system. You can install it by running the following command:

sudo apt-get install bash

After the installation is complete, you can check the version of your shell by running the following command:

bash --version

You should see something like the following:

GNU bash, version 4.2.45(1)-release (x86_64-pc-linux-gnu)
