# ## WordPerfect

Many versions of Linux are now supplied with so-called “personal” editions of commercial software. The exact conditions of use vary, but this type of software is normally enough for free use for noncommercial purposes. Naturally not complete, as we would expect, your machine should also have commercial non-exempt or non-free software such as a copy of either WordPerfect (Figure 3.25) or a copy of Corel WordPerfect. If you need a more complete version of a word processor you can buy a bigger licence to do a lot more. In my personal opinion, though, even a simple text editor is one of the most advanced text processors available: it is quite adequate for creating a simple document, and it is quite easy to learn from a quick reference card. I have used various versions of WordPerfect to write dozens of books.
