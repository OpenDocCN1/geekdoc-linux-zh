### A Linux GUI

The Linux command interpreter has a wide range of commands, and it can be programmed to make light work of complex and repetitive tasks.

It is undoubtedly very powerful, but like any command line interpreter, it does not score well in terms of user-friendliness. These days most users prefer a graphical user interface, and will not settle for anything less.

Linux has more than one graphical user interface to choose from, but one that is most widely used is normally just called KDE, is the K Desktop Environment, which is central to some of them. 4.21 bit Caldera Open Linux. Superficially KDE looks a bit like a 32-bit version of Windows, and with the latest version you can select a Windows look to the desktop if you like. BEOS and Mac flavours of the desktop are also on offer.

However, below the surface KDE is significantly different to Windows, or any other operating system. You can select a Windows, BEOS, or Mac look to the desktop, but KDE still operates in more or less standard KDE fashion. For someone used to any other graphical user interface there is a certain amount of learning to do before getting fully in control of things. On the other hand, with a little experimentation you can soon start to find your way around the system, and undertake a few basic tasks. If you are not familiar with the Linux file system used by Linux, before getting too deeply into KDE. It is necessary to read the parts of the previous chapter that deal with the Linux directory structure. Setting up and using KDE should then be reasonably pain-free.

## Trash

The Trash icon is equivalent to the Trashcan in some operating systems, similar to the Recycle Bin in Windows. The icons representing files can be dragged to the Trash icon and dropped there to delete them. This is the KDE equivalent of the command line `rm` (remove) command, but like the Windows Recycle Bin files are not destroyed when they are dropped into the trash icon. They are moved from their original location into a

![](img/147f057d2f063d8c60ee616870537a94_49_0.png)

directory for deleted files. They remain in that directory until Trash is emptied, and can be recovered if they have not been dumped.

This is very similar to the Windows recycle bin, but one important difference is that files deleted from floppy discs are stored in a Trash until it is emptied. With Windows a file on a floppy disc that is placed into the Recycle Bin is actually deleted onto the disc and is not copied (possibly with the 'add to last minute possible to recover the file, except (possibly) to copy the file to a new account where it can be copied back to the original disc, or anywhere else.

The icons on the desktop simply provide immediate access to a certain point in the file system. If you login as 'root', the trash folder will be /home/Desktop/Trash'. If you login as (say) 'Fred', the trash folder will be /Fred/Desktop/Trash'. Deleted files are stored in this folder until the trash is emptied, and then they can be treated just like any other files in that folder. In the case of a hard disc file, take any opportunity to delete the file. The files in Trash are stored on the hard disc, and are not deleted immediately. In fact deleting files on the hard disc can sometimes take a lot of time. The files in Trash are stored on the hard disc and reduce the amount of free storage space.
