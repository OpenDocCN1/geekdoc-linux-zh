# ## View window

The Edit menu controls (copy, delete, etc.) become available for other means. The View menu (Figure 3.11) controls the information displayed in the main screen area.

Files having some useful features do not stop appearing in the main window area. When the Show Hidden Files option is active as indicated by the tick in the box next to it in the menu, normally hidden files are displayed.

# ## Program icons

Note that file icons can be dragged from a window onto the desktop. With Windows icons, and in order to run a program it is merely necessary to double click on its icon. With Linux it is possible to have the same sort of set-up, but it is just a matter of dragging each program icon onto the KDE desktop and selecting the link option. In order to run a program on its icon on your desktop you will need to select the run this program option. Do not double click on the icon as you will now have two copies of the program running.

# ## KDE console

The Open Terminal option of the File menu runs a console in a KDE window (Figure 3.10). This console can be used much like an ordinary bash shell, but commands can be typed in. You can even use the scroll bar to view the command history that you will find is stored on some of the options menu. For example, Control+T launches a console when KFM is running. As always, you need to be careful...

# ## Thumbnail view

Activating the Show Thumbnails option results in the icons for most types of graphic files being displayed as miniature versions of the picture contained in the file (Figure 3.12). This makes it easy to select the correct file, but with a large number of graphic files in a directory it can take a while for them all to be displayed.

# ## Show Tree

The tree view (Figure 3.13) splits the main screen area and adds a directory tree to the left-hand side of the main window area. This shows all the folders in the root (/), Home, and Desktop folders. To open a folder initially, click on the small triangular button beside it. The triangle then points downward to show that the folder is open.
