# **Recap**

# **View or change permissions**

Right-click on the file or folder icon in KFM, select Properties and then
left-click on the Permissions tab.

# **Show permissions (command line)**

Use the ls command with the “-l” option.

# **Add a group (command line)**

Use “groupadd -g 121 drumber groupName”

# **Format a floppy disc**

Activate the “K” menu, and then select Utilities and KFloppy. Choose
the required disc size and format and then left-click on the Format button.

# **Change the wallpaper**

Activate the “K” menu and then select Settings, Desktop, and
Background. Click away menu to select the required background and
design, colour scheme, etc. and left-click on the OK button when you
have finished. Left-clicking the Apply button enables you to see the
new settings without exiting the Display Settings window.

# **Add/remove desktops**

Activate the “K” menu, select Panel and then Configure. Select,
from the Desktops tab, the number of desktops you want. You can
turn it back later.

# **Change the Panel position**

Activate the “K” menu, select Panel and then Configure. Select,
from the Position tab, the position of the Panel. You can use the
up/down buttons to change its position. Alternatively, you can
click and drag the Panel to the position you want.

# **Add an icon to Panel**

Find the program you want to use and select it. Then left-click
don the “K” menu, select Panel and then Configure. Select, from the
Position tab, the position of the Panel. You can use the up/down
buttons to change its position.

# **Remove an icon from Panel**

Right-click on the icon and select Remove.

# **Move an icon on Panel**

Right-click on the icon, select Move, move it to the new position and
then left-click.

# **Change the Panel size**

Select Panel and Configure from the “K” menu. Then select “Tiny”,
“Normal”, or “Large” from the panel buttons. Operate the Apply button to
see the changes without exiting the configuration window.

# **Make an icon**

Cross graphics and then Icon Editor from the “K” menu. Draw your
icon and save it with a xpm extension and save in /opt/kde/share/icons/
You can also use this program to edit existing icons.

# **Install a RPM package**

Find the RPM file using KFM and then left-click on it. Select the
appropriate options from the window that appears.
