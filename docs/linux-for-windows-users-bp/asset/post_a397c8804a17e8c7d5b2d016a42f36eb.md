## Using FDISK

The FDISK program uses a simple command line interface, where you issue commands by typing in the appropriate letter at the top prompt; the Return key. Any raw data entered by the prompt is interpreted at the Command line. This is a list of the commands available when using FDISK:

- a Toggle a bootable flag on current partition
- d Delete current partition
- l List all partitions
- m Main menu
- n Create a new partition
- p Print a list of partitions with partition details
- q Quit without saving
- r Replace the system ID of the current partition
- v Modify the display/entry units (cylinders or sectors)
- w Save changes and exit

As explained previously, before starting the installation process some hard disc space needs to be set aside for the Linux installation, but this hard disc space is achieved using the Linux FDISK program, which is similar to the MS/DOS program, and you may be required to run it in the installation process. This is not too difficult, but you need to control the partitioning process. FDISK will run early in the installation process. If you need to install a sidecar Linux alongside another operating system, you very carefully should not accidentally result in the other operating system being deleted.

Many PCs running Windows have the entire hard disc, even if it is a high capacity disc, set to operate as a single drive. This disc will usually be designated as drive C. Consequently, many Windows users are probably unfamiliar with the concept of hard disc partitioning. It is a very simple idea, whereby a single drive can be used as if it was actually two or more smaller drives. Rather than using a 6.4 GB drive as a single drive, it could be used as two 3.2 GB drives. These would be designated as drive C and D. The extra partition or partitions are called logical drives and do separate pieces of hardware, they are rotational. And these are also called logical partitio where we can use them. As explained previously, some of this is normally assigned to the swap disc, which is the capacity that is used for temporary storage by the operating system. Windows can have a permanent swap disc of this type, but, having performance advantage. However, most Windows systems use a swap disc. The swap disc can be at least 32 MB, but can be greater than this if the amount of RAM fitted to the PC and it can be made larger, too. This is 100 MB.
