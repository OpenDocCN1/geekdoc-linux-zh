
## Uninstall a package
Select Utilities and Knowledge from the “K” menu. Locate the package you wish to remove in the tree structure and then left-click on the Uninstall button.

## Unzip a MS/DOS zip file
Use “unzip filename” at the command line.

## Read a zipped text file
In KFM left-click on file containing the text file. In the Archiver window that then opens left-click on the entry for the text file. The contents of the file will then be displayed in a Kedit window.

## Check the free memory
Use the free command at the command line. Alternatively, select Settings, Information, and memory from the “K” menu.

## Check the free disc space
Use the df command at the command line.

## Print a file
A file has a suitable format for the printer can be printed by selecting Utilities and Printer Queue from the “K” menu. Then drag the file from KFM to the main Printer Queue window.

## Print a file (command Line)
Print a file to the printer by copying the file to the mount point of the printer (e.g. /cp: Allie /dev/p/7). The file must be in a suitable format for the printer.

## Print a PostScript file
It is possible to print a PostScript file to many non-PostScript printers using the ghostscript program, as in this example which prints “Allie”:

```
gs -sDEVICE=epson -sOutputFile=/dev/lp0 Allie.ps
```

To “print” to a file the command takes this form:

```
gs -sDEVICE=epson -sOutputFile=PrintFileName Allie.ps
```

## Monitor CPU and memory use
Select System and Task Manager from the “K” menu, and then operate the Performance tab.

## Terminate a troublesome program
Select System and Task Manager from the “K” menu. Highlight the troublesome program in the list of tasks and then left-click on the Kill task button. This method should not be used as the normal way of terminating a program. It should only be used when the program is otherwise uncontrollable.

## Appendix 3: Ghostscript printer support
A wide range of printers are supported using ghostscript, which can be used to convert the PostScript output of many Linux programs to suit these non-PostScript printers. The ghostscript program should be usable with these popular printers plus many others. The on-disc documentation on supported devices, ghostscript should give up-to-date information on the supported devices. Note that some standard graphics formats are also catered for.

- Canon BubleJet B410e, LBJ201, BUC600, and BJC800
- Canon LBP811
- Epson 9-pin dot matrix series
- Epson 24-pin dot matrix series
- HP DeskJet, DeskJet Plus, and DeskJet 500
- HP DeskJet 500C series
- HP DeskJet 1200
- HP LaserJet, LaserJet II Plus, LaserJet II, LaserJet III, LaserJet 4, etc.
- HP PaintJet, PaintJet XL
- IBM Jetprinter
- IBM Proprinter

It should also be possible to use any printer that is fully compatible with one of the above, or has an appropriate emulation mode. Any HP DeskJet, LaserJet, or compatible that has a DOS printing mode should work with ghostscript.

## Appendix 4: History in *bash*
In order to bring up the last command used in *bash* press the **up cursor key**. The command can then be edited using the **left** and **right** cursor keys plus the **Delete** and **Backspace** keys. Press **Return** to execute the modified command string. There is also a sort of command line equivalent to a Windows history palette. Use this command to produce a command history:

`fc -l`

You can use flags to list only certain commands in the history list, as in these examples:

- `fc -l 6`: Lists the last six commands
- `fc -l 98 107`: List commands 99 to 107

These keyword codes can be used to execute previous commands:

| Code | Effect |
| :--- | :--- |
| `!` | Begin substitution |
| `!!` | Repeat last command |
| `!N` | Repeat command number N |
| `!-N` | Repeat the command N number of commands back |
| `!:String` | Repeat the most recent command starting with *String* |
| `!:String` | Repeat command N and append *String* |
| `!?String?` | Repeat the most recent command that contains *String* |
