You can then proceed to type the number of 600 cylinders available. We wish this example to be 35 percent of the total number of cylinders in the hard disc. The 35 percent of 800 cylinders is 280 cylinders, so we type "280" followed by Return. You will be asked to confirm if you really do want to use the 280 cylinders on this particular hard disc partition. "Confirming" the size of the partition will be done by typing "Return" again.
