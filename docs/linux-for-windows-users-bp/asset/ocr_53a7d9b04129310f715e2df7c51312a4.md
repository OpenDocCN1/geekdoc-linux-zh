[root@/robert root]#

Logging in as an ordinary user called (say) fred would give the following prompt:

```
[fred@robert /fred$]
```

In addition to the change in name, note that the hash (#) sign has been added to a dollar ($) character. The hash sign is displayed only for the system supervisor, and indicates that the user can make changes to the system settings. It is effectively a warning that you have to be careful what you do, as you have access to files that govern the way the system operates. Careless use of these files could prevent the system from operating properly.

The first part of the prompt is simply the name of the user and the system. The second section indicates the current position in the file system.
