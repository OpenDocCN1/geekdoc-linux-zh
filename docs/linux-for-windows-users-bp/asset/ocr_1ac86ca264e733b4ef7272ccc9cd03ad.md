# Reload

The button having a circle icon with two arrows is the Reload button. When copying and moving files, or perhaps when changing discs, you may sometimes find that the icons in the main window area do not seem to properly reflect the contents of the directory. Operating the Reload button will update the window, and it should then provide an accurate account of the directory’s contents.

# Copy and paste

The next two buttons respectively provide access to the copy and paste facilities. Before you can copy something it must be selected in the main window area. In Windows you do this by left-clicking on the it, but holding down the left mouse button, and then dragging a frame around the icon or icons you wish to select. # Help

The next button is the Help button, and pressing this activates the KFM on-line help system. KDE help systems work on much the same way as your main Windows equivalent. Left-clicking on an underlined word moves you directly to the page about the subject in question. The larger help programs include the usual search facilities. Help systems in general have a reputation for stating the obvious and offering little of real substance, but there is some useful advice to be found if you delve into the KDE help systems.

# Stop

The final button is, in theory at any rate, the stop button. In most cases the program will operate so quickly that it is literally a case of “if you blink, you miss it”. However, if it does take many seconds to deal with a directory that contain huge numbers of files, you can halt the operation by clicking the Stop button, or as an alternative, if you wish to stop, button things can be brought to a halt.

# Window button

The button at the left-hand end of the title bar is the window button, and operating this activates the three up-down menu (Figure 3.3). The Maximize and Close options simply duplicate the size of the window described previously. Resize, unsurprisingly, enables the size of the window to be altered. Selecting this option produces a frame that can be dragged to the required size using the mouse, and left-clicking on the button causes the window to change to the selected size. This is really a duplicate function as well, since any window can be dragged to the required size by placing the cursor at the edge or corner of a window and then dragging the cursor to the large mouse button shape. The drag bit can be resized by holding down the left mouse button, dragging it to the required size, and then releasing the button. This is again standard Windows style. control.
