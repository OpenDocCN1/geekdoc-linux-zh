Colour  White  Green  Blue  Red  Cyan

You have given the colour of normal files as white, but this colour will be the
normal text colour for the display. This will usually be either white or
grey. The color option can be used when listing the contents of
something other than the current directory, and the command then takes
this form:

ls /usr/lib —color

In this version of the command will also work, because the hyphens
in front of the word color will ensure that Linux does not interpret it as
the directory to be listed:

ls -color /usr/lib

There are other controls that can be used to modify the way in which the
ls command functions, and you can get brief details of these by using
the on-screen help system. To get help on a command simply type the
command followed by —help, as in this example:

ls -help

Many of the controls enable the list to be sorted in various ways, which
can obviously make life easier when dealing with large lists of files.
Hidden files are included if the -a switch is used. To have
the file size in kilobytes included use both the -s and -k controls, as in
this example:

ls -s -k

You can have the controls as separate entities, as in the above example,
but it works just as well in this form, with two or more merged into a
single entity:

ls -sk

If you investigate the Linux file system the large number of directories
and files may surprise you. To some extent the large number of files is
just the way it is done with discrete items of hardware. It also has to be
borne in mind that a typical Linux installation includes more than just the
operating system. There may well be dozens of application programs or
word or text processors, and games.

# Directories

Adding and removing directories is handled in much the same way as it
is under MS-DOS. New directories are created using the mkdir (make
directory) command, but note that this can not be abbreviated to an
MS-DOS style md. This command can produce a subdirectory off the
current directory, and it will be called "temp":

```
mkdir temp
```

A new directory can be placed anywhere in the file structure by including
the full name and path in the command. This example produces a
subdirectory called temp, and places it off the root directory:

```
mkdir /root/temp
```

The rmdir command is used to remove unwanted directories, but note
that it can not be abbreviated to just rd in Linux. Also note that a
directory can only be removed if it is empty. In this context "empty"
means that it must not contain any files at all, or subdirectories even if those
subdirectories are empty. The rmdir command, and these two examples would remove
the directories made using the two mkdir examples given previously:

```
rmdir temp
rmdir /root/temp
```

Sometimes you may wish to remove a directory, complete with all the
files it contains. This can be achieved from the parent directory using the
rm command and the -r (or recursive) modifier. The example shown
here will remove the directory called "testdata" and all its contents:

```
rm -r testdir
```

Obviously great care needs to be taken when deleting files, and even
more care must be exercised when removing complete directories.
