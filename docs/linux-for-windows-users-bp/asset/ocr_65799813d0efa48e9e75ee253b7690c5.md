If you wish to use a dual boot system but have little or no experience at dealing with operating systems it would probably be worth while obtaining a version of Linux that gives plenty of assistance with dual boot installation. Open Linux 2.2 for example, is supplied with the PartitionMagic and BootMagic programs. The special CD-ROM will run under Windows 95/98/NT, and enables the necessary hard disc space for Linux to be cleared. An installation Wizard then helps to get Linux installed correctly, and the text screen of most Linux installation programs which makes it easy to move back one or two stages to correct an error (Figure 1.15 and 1.16). It is not quite as case of putting the CD-ROM in the drive and then sitting back while the computer gets on with it, but these days installing Linux does not have to be any more difficult than installing Windows.
