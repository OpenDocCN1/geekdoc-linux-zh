It is possible to move a window so that the title bar disappears “under” the taskbar, which on the face of it leaves no way of dragging the window back onto the screen. This is in fact possible, and it is just a matter of pressing the Alt key and then dragging the window into the desired position. Having pressed the Alt key it is possible to drag the window using any part of it as a handle.

# Stick button next to the window button is the Stick or Pin button. Its icon is meant to represent a pin. Windows are not normally “pinned” on KDE. The window will disappear from the screen when switching from one virtual desktop to another. Left clicking on the stick button fixes the window on the screen so that it remains in place when changing from one virtual desktop to another. Clicking on this button releases the window back onto the virtual desktops. The icon changes when it is activated, and if shows a view looking down onto the head of the pin when the window is “pinned” in place, and the pin set horizontally when it is not. You can simply stick a window in place so that it is available by clicking it in place, changing desktops, and then releasing it again. Windows does not have this feature.

# Menu bar

Beneath the title bar, KFM has the usual menu bar. There are numerous options available over these menus, and we will only consider some of the more useful ones here. To add a new folder, consider opening up KFM, and then select New and Folder (Figure 3.9). Type the name for the new folder in the dialogue box that then appears.

![](bbox=[0.42, 0.04, 0.98, 0.17])

The New Window option runs another copy of KFM, which starts in the main screen area. The current directory, which starts in KFM, can be moved to other directories by drag and drop or by using a cut and paste method, similar to any other.

The Edit menu provides easy means to select a new folder via the Edit menu.
