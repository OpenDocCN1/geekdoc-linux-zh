If the system is in desktop One and you move a window so that the pointer touches the right-hand side of the screen, the system would automatically switch into desktop Two. And, conversely, it would move opening the window when the pointer touches the bottom of desktop One.

Two such automatic switching conditions would be automatically set up on each virtual desktop.

Taking the pointer to the extreme left-hand side of the screen would have no effect, since there are no virtual desktops in those directions. The automatic switching effect might seem like the ideal way of managing one huge desktop, which might also be considered like the way of doing things. In practice is one of those features that you either love or hate. If you are suitably precise with your control of windows you can work on one desktop to another on find regular basis.

This is enabled via the KDE Control Centre Active Application Borders feature, and can be viewed by the KDE Control Center option in the ". " menu. This is shown in Figure 4.19. # Border controls

It is possible to have automatic switching between desktops if desired. This works on the basis of automatically switching to the next desktop if you move the pointer to an appropriate edge of the screen. The relative positions of the virtual desktops match up with their buttons on the panel.
