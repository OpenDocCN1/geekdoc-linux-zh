# ### Locating files

Linux has more than one file finding utility, some of which are easier to use, has others. The `locate` command is relatively quick and easy to use, has others. The speed is due to the program keeping a database of files on the hard disc, so when it searches for a file it does not have to look through the hard disc itself. For this command to work it must obviously have a database to work from. And the database is produced and then updated automatically at about 6.00 AM. You have to bear in mind more or less non-working if your PCs runs from this time to the night. But in the day, however, the database can be produced manually or updated using this command:

`/usr/bin/updatedb`

It will take a minute or so for this task to complete, but once it has done so you should be able to locate files by name quite quickly. You must login as `root`.

Possible, but not very likely, there are cases where it is not possible to locate a file that the user wants, for example, if there has been a file that one wanted before the user can locate.

To locate a file you can simply issue the `locate` command and include the filename, as in this example:

`locate convert`

| [root@homeone /root]# | `locate convert` |
| `root/homeone /root]#` | `grep /usr/X11R6/bin/imagemagick/convert` | `p1` |
| `root/homeone /root]#` | `locate convert` |
