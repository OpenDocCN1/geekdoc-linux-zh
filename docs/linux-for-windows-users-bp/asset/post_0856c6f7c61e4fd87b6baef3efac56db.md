### Properties

The *Properties* option brings up a screen (Figure 3.7) that shows some basic information on the file. The name of the file is shown in an editable text box, and by altering the text you can change the name of the file. Of course, this is not possible if the file is a read-only type, such as a file on a CD-ROM. Left clicking on the Permissions tab brings up an alternate screen, which gives in more in-depth information on the read and write status of the file, its owner, and group information.

![](img/147f057d2f063d8c60ee616870537a94_53_1.png)

### Navigation

There is an edit box immediately above the main window area, and this shows the current path. You can type in a path here in order to go direct to a specific directory. Just enter the path and then press *Return*. Typing the name of a directory or program name and then pressing the *Return* key opens the file or program.

Above the edit box is the navigation toolbar. This provides a quick and easy way of moving around the file system. The three arrows that point up, left, and right respectively move up one level, backwards one step, and forwards one step. Obviously it is not possible to move one step forwards until you have moved backwards from the original directory, or to move one step backward until you have moved backwards. Also, it is not possible to move further up the directory tree once the system is in the root (/) directory. Any arrow buttons that are inoperative appear to be recessed into the toolbar, whereas buttons that can be used appear to protrude slightly from the toolbar. The next button in this toolbox has a house-like icon, and this moves KFM straight to the home directory.

### Reload

The button having a circle icon with two arrows is the Reload button. When copying and moving files, or perhaps when changing discs, you may sometimes find that the icons in the main window area do not seem to properly reflect the contents of the directory. Operating the Reload button will update the window, and it should then provide an accurate account of the directory’s contents.

### Copy and paste

The next two buttons respectively provide access to the copy and paste facilities. Before you can copy something it must be selected in the main window area. In Windows you do this by left-clicking on the icon, but holding down the left mouse button, and then dragging a frame around the icon or icons you wish to select. The selected icons will change to dark blue. Another way of selecting multiple files is to hold down the Control key and then left-click on each file that you wish to select. This is the method which can be used in KFM to select files that are not conveniently grouped together on the screen. If, of course, files are grouped together, you can select a group of files in Windows. Once selected the files can be copied using the copy button. Groups of files can also be dragged to another KFM window, dragged to Trash, etc., and can generally be treated as a single entity.

### Help

The next button is the Help button, and pressing this activates the KFM on-line help system. KDE help systems work on much the same way as your main Windows equivalent. Left-clicking on an underlined word moves you directly to the page about the subject in question. The larger help programs include the usual search facilities. Help systems in general have a reputation for stating the obvious and offering little of real substance, but there is some useful advice to be found if you delve into the KDE help systems.

### Stop

The final button is, in theory at any rate, the stop button. In most cases the program will operate so quickly that it is literally a case of “if you blink, you miss it”. However, if it does take many seconds to deal with a directory that contains huge numbers of files, you can halt the operation by clicking the Stop button, or as an alternative, if you wish to stop, pressing the button brings things to a halt.

### In Control

At the top of the KFM screen there is a title bar. This bar is present on all X programs, and it does more than spell out the name of the program. There are a number of control buttons here, but not all of the buttons can be present on every program’s window. As it crosses equivalent, its right-hand control buttons match the Microsoft Windows equivalent. This button is used to close the current program window. The left button, which is square with a slightly smaller border, is the Maximize button. Left-clicking on this button places the window in full-screen mode. Right-clicking on it again returns the window to its normal size. The next button causes the window to disappear to the taskbar; clicking on the appropriate section of the taskbar restores the window. Anyone used to using Windows should find these buttons easy to use, as they are essentially the same as their Windows counterparts.

### Window button

The button at the left-hand end of the title bar is the window button, and operating this activates the three up-down menu (Figure 3.3). The Maximize and Close options simply duplicate the functions of the size and close buttons described previously. Resize, unsurprisingly, enables the size of the window to be altered. Selecting this option produces a frame that can be dragged to the required size using the mouse, and left-clicking on the button causes the window to change to the selected size. This is really a duplicate function as well, since any window can be dragged to the required size by placing the cursor at the edge or corner of a window and then dragging the cursor to the large mouse button shape. The drag bit can be resized by holding down the left mouse button, dragging it to the required size, and then releasing the button. This is again standard Windows style. A window can be dragged around the screen by pointing to the title section of the title bar, holding down the left mouse button, and then moving the cursor. The window will move with the cursor until the left button is released.

It is possible to move a window so that the title bar disappears “under” the taskbar, which on the face of it leaves no way of dragging the window back onto the screen. This is in fact possible, and it is just a matter of pressing the Alt key and then dragging the window into the desired position. Having pressed the Alt key it is possible to drag the window using any part of it as a handle.

### Stick button

Next to the window button is the Stick or Pin button. Its icon is meant to represent a pin. Windows are not normally “pinned” on KDE. The window will disappear from the screen when switching from one virtual desktop to another. Left clicking on the stick button fixes the window on the screen so that it remains in place when changing from one virtual desktop to another. Clicking on this button releases the window back onto the virtual desktops. The icon changes when it is activated, and it shows a view looking down onto the head of the pin when the window is “pinned” in place, and the pin set horizontally when it is not. You can simply stick a window in place so that it is available by clicking it in place, changing desktops, and then releasing it again. Windows does not have this feature.
