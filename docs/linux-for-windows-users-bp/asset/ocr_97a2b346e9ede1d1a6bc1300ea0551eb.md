# LILO

Linux normally boot-up via a program called LILO and this may need a
little amount of configuration. It is basically just a matter of selecting
which part of the hard disk which LILO will be installed, what options, if
required, to include, and the default operating system to be booted.
There are two main places for LILO to install. The first primary partition
is the master boot record (MBR) before the disk partitions. The default
option is in the MBR. This will ensure that a disk can be used to
select an alternative operating system. The delay time can be
configured for Linux if you want to reduce the delay if this option
is offered.
You may also be asked to select the Linux kernel to install. Unless you
know exactly what you are doing and have good reason to do so, simply
select the default kernel.

# Passwords

During the installation process you will be asked to provide at least one
password. As a minimum the password for the user `superuser` (or root
account) must be set. It is often a good idea to set up a second password
as well. It is often a good idea to set up two passwords. The second
password is often set up as the password for the root account, which
you may use when your system settings are changed. You may be asked
also to set up a password for the second password. This is often called
the admin password.
It is important to remember that the password set up is not stored in
plain text, but it is hashed. This means that the password is not stored
directly, but a hash of the password is stored. This is a one-way
process, meaning that the password cannot be recovered from the hash.
This is a good thing for security, but it also means that if you forget
your password, you will have to reinstall the system to get the password
back. It is therefore a good idea to write down your password and store
it in a safe place.
You may also be asked to set up at least one user account. Even where you
may only use one user, many prefer to log in as the standard user,
rather than the root user. By doing this you can avoid many of the
risks of accidentally making unwanted changes to the system,
especially if you are less familiar with the Unix file system.
If you are more or less limited to running the system, the root
password can be set up later if required. A user account can be
created later if required. A user can create a user account with the
adduser command. If you are asked for a group ID, enter the same as
the user ID. If you are asked for the group name, enter the same as the
user name. If you are asked for the group GID, enter the same as the
user ID. The install process is fairly flexible in its handling of these
settings, and it will accept most reasonable input.
During the install process you will also be asked for the password for the
root account. You may also be asked for the password for the user
account that you are creating. If you are not going to set up a user
account, you can just press return at the password prompt.
Note that the password is not displayed on the screen when you type it
in. This is normal, and does not mean that you are not typing it in.
It is often a good idea to use a different password for each account,
and to change your password regularly. It is also a good idea to use a
strong password, which includes a mix of upper and lower case letters,
numbers, and symbols.
The more complex your password, the harder it will be for anyone to
guess it, but also the harder it will be for you to remember it.

The installable program will give some guidance about choosing an
acceptable password, but it normally has to be four or more characters
in length, and can consist of upper and lower case letters, plus numbers
and punctuation marks. The more complex the password, the harder it
will be for anyone to guess it, but the harder it will be for you to
remember it.
