# **Hardware**

Linux is a powerful 32-bit operating system, so do you need a powerful PC in order to run it properly? This is a "how long is a piece of string" type question and the hardware requirements depend on the application you want to use. It also depends on whether you require a "bare bones" minimum installation or an "all singing all dancing" version. The absolute minimum needed to run Linux is a PC having an 80386 microprocessor, about 8 MB of memory, approximately 54 MB of hard disk space, a mouse, supported video card, and a CD-ROM drive. Although a PC version of Linux will run on a computer as basic as this, it would be misleading to suggest that this is all you need to run Linux effectively.

# **Hard drive**

The basic Linux operating system uses a command line interpreter where you type in commands, much like using MS/DOS. To fully utilize this operating system you really need to install X Windows, which roughly doubles the amount of disc space required. It also adv antages you to set aside some disc space for use as a swap file. This is space that the operating system will use for temporary file storage, and up to 100 MB can be used. The swap space is normally at least equal to the amount of memory fitted to the computer. Last, and by no means least, you will need some disc space for applications and utility software. Even a very minimal Linux distribution has a single CD-ROM which contains many megabytes of useful utilities and some applications complete, and many Linux installation takes up about 350 to 450 MB initially. Plus space for data files. Do not forget that you will also need some space to use as a swap file. As a guide, you will also need something like a 340 MB drive for a reasonably full and exercise installation. 850 MB or more is preferable.

# **Processor**

Although Linux tends to be less demanding on the processor than many other operating systems, it would be unrealistic to load it onto an old 33 MHz 80386 based PC and expect it to run like the latest Pentium wonder.

# **Memory**

Although 8 MB of memory should be sufficient to get Linux "up and running", it is definitely preferable to have more than this. You could probably get by quite well with 16 MB, but everything is likely to run faster and more smoothly with 32 MB or more. Some of the more advanced application programs require a minimum of 32 MB. As memory is quite cheap these days it does not really make sense to skip on it unnecessarily. It would be well worthwh ile investing in a memory upgrade. This leaves plenty of "headroom" if you need to do multitasking.

# **CD-ROM**

It is possible to install some older versions of Linux from floppy discs, but modern distributions are supplied on one or more CD-ROMs, and you will therefore need some sort of CD-ROM drive. Installation is much quicker when using a CD, and an old 2x drive will do. However, a CD-ROM drive with some ordinary ATAPI (IDE) interface should give no problems, but some SCSI drives might not be supported. The more common the hardware in your computer, the better the chances of getting it to work well with Linux.

# **Pointing devices**

Practically any mouse which is suitable, and Linux supports serial, bus, and PS/2 mice. In theory a three-button mouse is required, but a two-button mouse can provide an emulation of the middle-button type. Pressing both buttons simulates pressing the middle mouse on the third button. If you should have problems getting Linux to talk to a mouse, a different computer may be purchased. One drawback to using a mouse today, so this is not really a major problem. If you wish to use a graphical tables or some other exotic form of pointing device you may find that it will not work with Linux.
