# Free disc space

Information on free disc space is something that most users need to keep under scrutiny, and this information can be obtained via free command line interpreter. If you simply need to know how much free space there is on the hard disc use the df (disc free) command. This can be used without any option flags, as in this example:

```
df
```

The df command will respond with four figures which are the total disc capacity in kilobytes, the number of kilobytes used, the number of kilobytes free, and the percentage of the disc that is actually used. The fourth figure is therefore the all-important one that tells you how much disc space is free. Once this figure by, (you'll get the approximate size of the file. If the disc space is free, (you'll get an accurate estimate of the amount of space available.)

The chances of this happening are about the same as winning the factor on the lottery, but you can check the current state of things using the df command and the -i (inode) option, like this:

```
df -i
```

This gives four figures, as before, but this time it is the total number of available inodes, the number used, the number free, and the percentage of available inodes that are used. The basic use of the du command provides a listing for the current directory, but you can easily specify the directory at the end of the command. For example:

```
du /home/fred
produces a listing for /home/fred and its subdirectories.
```

A size for a file can be obtained simply by specifying a file rather than a

directory. This example would give the size of the file called “testfile” in the current directory:

```
du testfile
```

Note that the size of a file can be determined from within KDE by locating the file using KFM, right-clicking on its icon, and then selecting Properties from the pop-up menu. The file size will be included on the first screen of information. Alternatively, simply place the pointer over a file icon and give its size in the status line at the bottom of the KFM window. Unfortunately neither method works with a directory. The Properties window will simply say “Is a directory” instead of giving a size, and the status line will just say “Folder”.

There are various option flags that can be used with the du command, and this command option flags will bring up a list of them:

```
du --help
```

The “-max-depth=N” option is a useful one if you only require details of the current directory and are not interested in subdirectories several levels beneath it. This command will list the size of the current directory and the sub-directories immediately below it:

```
du --max-depth=1
```
