# Word count

There are a number of commands concerned with text files, but these are not as necessary in a modern computing context. There are powerful text editors that can handle most of these functionality in a more user-friendly fashion. One that might be of use is the wc command. If you wished to know the number of words in a text file called /root/chap1.txt this command would provide the answer:

wc /root/chap1.txt
321 10726 60403 /root/chap1.txt

When used without any flags this command actually tells you slightly more than the number of words. From left to right the three numbers shown represent the number of lines, words, and text characters. This file therefore contains 10726 words. # Ispell

Ispell is the Linux interactive spell-checker, which integrates with some text editors but can also be used from the command line. ispell /root/chap1.txt
