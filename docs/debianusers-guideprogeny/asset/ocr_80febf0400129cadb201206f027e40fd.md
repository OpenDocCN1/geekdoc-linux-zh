Type: less OPTIONS FILE.

# ## The less Command (View)

| Option | Topic | Comments |
| :--- | :--- | :--- |
| -hNUMBER | Sets maximum number of lines to scroll back at one time. | |
| -i | Ignores the distinction between upper and lower case letters when a string is used. | If this command is not used, lower case letters are distinguished from upper case ones. |
| -pSTRING | Displays file starting with the first occurrence of the string. | |
| -s | Prints multiple blank lines as a single blanks line. | |
| -yNUMBER | Sets the maximum number of lines to scroll forward at one time. | |

# ## Viewing Files Backwards: Using the tac Command

To view files backwards, use the `tac` command. The `tac` command's name comes from the fact that it was intended as the opposite of `cat`. However, `tac` remains useful after `cat` has been replaced by `less`.
