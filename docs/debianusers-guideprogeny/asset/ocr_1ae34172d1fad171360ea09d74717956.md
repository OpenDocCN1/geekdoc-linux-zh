# The tar Command (Archive)

| Option | Action | Comment |
| --- | --- | --- |
| ▼ --exclude FILE<br>▼ --exclude FILE | Excludes a file from archiving or extracting. |  |

| Option | Action | Comment |
| --- | --- | --- |
| ▼ -k<br>▼ --keep-old-files | Extracts files without overwriting files with the same name. | An error message displays if there are conflicts. |

| Option | Action | Comment |
| --- | --- | --- |
| ▼ -M<br>▼ --multivolume | Split over multiple removable devices. | Works with tapes or floppies. |

| Option | Action | Comment |
| --- | --- | --- |
| ▼ -N DATE<br>▼ --after-date DATE | Excludes files older than the date entered from the archive. |  |

| Option | Action | Comment |
| --- | --- | --- |
| ▼ -P<br>▼ --absolute-paths | Keeps absolute paths. | See “Understanding Absolute and Relative File Paths,” page 175. |

| Option | Action | Comment |
| --- | --- | --- |
| ▼ -p<br>▼ --same-permissions<br>▼ --preserve-permissions | Keeps permissions of files unchanged when they are archived. | See “Changing Permissions,” page 227. |

| Option | Action | Comment |
| --- | --- | --- |
| ▼ -r<br>▼ --append | Adds a tar file to the end of another one. | The second file listed in the command is added to the end of the first. |
