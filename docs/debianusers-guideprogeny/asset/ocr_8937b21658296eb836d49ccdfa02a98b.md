# Note

Deleting a launcher does not delete the file or directory associated with it. Launchers are links, and have no direct connection with the files they are associated with.

# Recreating Default Launchers

The desktop installs with a number of default icons. To restore these defaults, right-click on the workspace and select Recreate Default Icons.

# Positioning Desktop Launchers Automatically

+   1 Right-click on the workspace and select Desktop Properties. The Desktop Properties window opens.

![](bbox=[0.15, 0.41, 0.82, 0.74])

+   2 Select the Desktop tab.

The Icon position pane shows the automatic placement of icons. Icons can be arranged in vertical or horizontal rows.
