Type: tac FILE.

Although a few options exist, they are not often used.

# ## Viewing the Start of Files: Using the head Command

head has a companion tool called tail, which views the end of files. The options for both tools are similar, but have some important differences. For example, head ordinarily displays the name of the file, while tail has more options.

Type: head OPTIONS FILE.
