1 Type: `gtop`. The GNOME System Monitor opens.

![](bbox=[0.16, 0.08, 0.9, 0.35])

2 Select a process. The process is highlighted when selected.

3 Right-click on the process and select Renice from the pop-up menu. The Renice window opens.

![](bbox=[0.14, 0.47, 0.9, 0.65])

4 Drag the slider bar with the mouse cursor to set the priority. The priority is a number with a range from -20 (highest priority) to 19 (lowest priority). Only the root user can use a negative priority (-1 to -20).

5 Select the Apply button to change the priority, then the ok button to close the window.
