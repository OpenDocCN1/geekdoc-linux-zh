# Commands for Reading System Information

| Command | Information | Comments |
| :--- | :--- | :--- |
| nsllookup HOST-SERVER | Domain name server | Displays the domain name and address. |
| pwd | Present working directory | |
| swap on -s | swap file | The same command can also be used for turning on a swap partition. |
| uname -a | CPU and Operating system | Information is given in a single line, in the following order: 
\n- Operating system.
- Local host.
- Kernel release.
- Kernel build information.
- Processor type. |
| w | Current system state | Displays summaries of system usage, users who are logged in, and their current activities. |
