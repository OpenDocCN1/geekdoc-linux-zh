You need to edit fstab when:

+   - You want permanent access to non-Linux partitions.

+   - You add another drive, including any type of removable drive, such as a zip drive or CD drive.

+   - You repartition a hard drive.

Information about each filesystem is listed in six columns. For convenience, you can often copy and paste an existing filesystem definition and modify it for another one.

# Warning

Do not edit the swap partition or /proc filesystem entries in /etc/fstab. The swap partition enables virtual memory, while the /proc filesystem is used to gather information for commands such as ps, which reports on active processes.
