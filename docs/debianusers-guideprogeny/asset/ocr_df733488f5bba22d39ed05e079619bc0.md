# Commands for Reading Memory Information

| Command | Topic | Comments |
| --- | --- | --- |
| du DIRECTORIES | Disk space used by the contents of a directory | You must have read permission for each directory. |
| df -hii NAME | Memory used by file systems | The name can be: a partition, a mount point, or a directory. 
For each file system, the following information is given:
- Size. 
- Space Used. 
- Space Available. 
- Percentage of space used. 
- Mount point. 
- Inodes. 
- Filesystem type. |
| free -m | Total system memory | Statistic displayed are: 
- Total memory free. 
- Total memory used. 
- Amount of RAM and swap memory. 
- Buffers used by the kernel. 
Statistics are in megabytes. |
