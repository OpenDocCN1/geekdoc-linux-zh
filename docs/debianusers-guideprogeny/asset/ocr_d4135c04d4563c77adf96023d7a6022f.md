Once the display is running, you can use the O+ or O- options to add or subtract statistics from the display. The display you set by the keyboard is used in the terminal in which you are running the command so long as the terminal is open, or you do not change it.

# The ps Command (Process Screen)

| Option | Action | Comment |
|---|---|---|
| l | Displays in long format | |
| u | Displays user name and start time. | |
| r | Does not display of processes that are not running. | |
| ▼ O + KEY or ▼ O - KEY | Adjusts displays. | A plus sign adds a column the next time you use the command in the same terminal.\n\nA minus sign makes the column not display the next time that the command is used in the same terminal.\n\nSee “Display Options for the ps Command,” page 312. |
