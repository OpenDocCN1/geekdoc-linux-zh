4 Select your installation target. See "Selecting the Installation Target," page 58.

Each target uses your hard drive in a different way:

+   - **Entire drive:** The entire hard drive is used for the install.  
+   A Linux swap partition of 125 megabytes is created for you. The rest of the drive is used for a Linux partition.

+   - **Free space:** Only the free space on the hard drive is used.  
+   The first available free space on any hard drive that is **greater than one gigabyte** is used for the install. The Linux partition is as large as possible. The swap partition is 125 megabytes in size.

+   - **Custom partitioning:** The hard drive is used the way that you decide.

> **Warning**  
> Back up all important information before doing custom partitioning. Otherwise, you may lose information.
