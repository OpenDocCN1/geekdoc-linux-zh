# Moving Files From the Command Line

*Type: mv OPTIONS SOURCE TARGET*.

This command can have three possible results:

+   If the target file or directory does not already exist, the source file or
+   directory is renamed.

+   If the target file or directory already exists, then it is over written by the
+   source. The original file is deleted unless the -b option is used.

+   If the target is a directory, then the source files are moved to the directory.
