# Reading the Edit Partition Screen

| Column | Information |
| :--- | :--- |
| System | The format or filesystem of the partition. Possible formats are:
* Linux ext2: The native Linux format.
* Linux swap: The Linux swap partition.
* FAT: FAT32 or vfat, the modern Windows format.
* Free Space: no format. |
| Status | The state of the partition. Usually, the only statuses that you see are:
* To be mounted: The partition is ready for use, and will be mounted, but is not going to be formatted.
* To be formatted: The partition needs to be formatted before it is ready for use.
* Bootable: The partition is listed as bootable in Windows. If a Windows installation is on on the first partition, the installer detects it and sets it as Bootable automatically. |

> **Note**
> 
> No changes are carried out until you select the Next button.
