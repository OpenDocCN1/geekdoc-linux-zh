# # Using the Desktop Pop-Up Menus

The panel, the menus, icons, and the work space all have pop-up menus. However, the work space has two pop-up menus:

▼ Clicking with the right mouse button on a blank space on the desktop opens the desktop pop-up menu.

From this menu, you can create icons, rescan the desktop to update it, and set other desktop properties.

▼ Clicking with the middle mouse button on a blank space opens a general pop-up menu.
