| Actions | Action | Comments |
|---|---|---|
| --purge PACKAGE | Purges a package. | Note that the package names, not the package files are entered.<br><br>Instead of listing pack-ages, you can use --a or --pending to configure all packages marked for purging. |
| ▼ -r PACKAGE | Removes a package. | Note that the package names, not the package files are entered.<br><br>Instead of listing pack-ages, you can use --a or --pending to remove all packages marked for removal |
