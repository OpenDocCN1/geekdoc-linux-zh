# The -p Flag for the cpio Command (Delayed Backup)

| Option | Action | Comment |
| --- | --- | --- |
| -f | Keeps previous modification time on restored files. |  |
| --non-matching | Keeps previous modification time on restored files. |  |
| -m | Keeps original modification times. |  |
| -R USER GROUP | Reassigns ownership of the file. | Use as root user. |
| --OWNER USER GROUP | Reassigns ownership of the file. | If no user is specified, then the owner becomes the root user. |
| -u | Overwrites old files. |  |
| --unconditional | Overwrites old files. |  |
| -v | Displays progress on-screen. |  |
| --verbose | Displays progress on-screen. |  |

# Scheduling Jobs

You can schedule a command or a script using two tools:

+   - crontab: Schedules tasks once or repeatedly.
+   - at: Schedules tasks once.
