# **Commands for Reading User Information**

| Commands | Topic | Comments |
| :--- | :--- | :--- |
| finger USERS | A user | Displays information from the pswd file. |
| | | The default is the current user. |
| groups USER | Groups that users belong to | Displays the groups that a user belongs to. |
| | | Use as root user. |
| id USER | Users and Groups | Displays the user’s groups, user ID and group IDs. |
| who | Users currently logged on | Displays:
■ Users.
■ The time each user has have been logged in.
■ Each user’s remote host (if on a network). |
| whoami | Current user | |
