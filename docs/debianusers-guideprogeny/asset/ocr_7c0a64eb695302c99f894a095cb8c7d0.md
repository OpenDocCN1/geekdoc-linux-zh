# Viewing the End of Files: Using the tail Command

tail has a companion tool called head, which views the start of files. The options for both tools are similar, but have some important differences. For example, tail has more options, while head ordinarily displays the name of the file.

*Type*: tail OPTIONS FILE.

# The tail Command (View)

| Option | Action | Comments |
| :----- | :----- | :----- |
| -c NUMBER UNIT | Sets the size of the display, and, optionally, the units. | Units are: |
| | If no unit is specified, the size is shown in bytes. | ▼ b: blocks |
| | | ▼ k: Kilobytes |
| | | ▼ m: megabytes |
| -f | Continues to display the last lines of a file as it grows. | Press Ctrl-C to end. |
| | | This option is especially useful if you have a log file open as you try to debug. |
| ▼ -n NUMBER | Sets lines to display, measured from the end of the file. | The default is 10. |
| ▼ --lines NUMBER | | |
| ▼ -q | Prevents the display of the file name header. | |
| ▼ --quiet | | |
