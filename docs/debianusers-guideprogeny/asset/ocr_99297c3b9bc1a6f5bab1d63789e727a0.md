# Column Settings in /etc/fstab (Mounting Filesystems)

| Column | Contents | Choices |
| --- | --- | --- |
| 1 | The partition that the file-system is on. | See "Understanding Device Names," page 37. |
| 2 | The directory on which the filesystem is mounted. | Many users prefer to put /home/, /usr, and /var on separate partitions. |
| | | Other partitions are usually mounted as a sub-directory of /mnt. However, you can use any directory for a mount point. |
| | | If you are running an operating system that uses a Windows-like naming convention, you might create directories that use the convention, such as /mnt/C. |
