# Keyboard Shortcuts for the top Command

| Press... | To... |
| --- | --- |
| space bar | Update the display. |
| t | Toggle display of processes and CPU states. |

# Stopping a Process From the Desktop

+   1. Type gtop. The GNOME System Monitor opens.
+   2. Select a process. A process is highlighted when selected.
+   3. Right-click on the process and select Kill Nicely (SIGTERM) from the pop-up menu. The process is killed without any confirmation window.

![](bbox=[0.05, 0.35, 0.65, 0.65])

> **Warning**
> Closing a process can crash your system or cause other problems.
