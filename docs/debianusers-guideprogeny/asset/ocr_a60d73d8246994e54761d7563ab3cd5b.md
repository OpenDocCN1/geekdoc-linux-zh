# ## Changing Groups From the Command Line

Use the `chgrp` (change group) command. Only the owner of a file or the root can change the group. Valid groups are listed in `/etc/group`.

> Type: `chgrp OPTIONS GROUP FILES`.

The group can be identified by name or group ID.
