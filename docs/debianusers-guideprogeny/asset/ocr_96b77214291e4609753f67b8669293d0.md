# The GRUB Boot Manager: Global Settings

| Option | Setting |
| :--- | :--- |
| fallback NUMBER | Sets the second default operating system. |
| | The fallback starts only if the default cannot. There is no default fallback. |
| timeout SECONDS | Sets the time before the default operating system starts. |
