
## Setting Date and Time From the Desktop

![](img/e36b94f8548b09d00212238f073b11d9_412_0.png)

1. Select **Systems > Date and Time** from the GNOME Control Center.

**Note**

If you are using the KDE desktop, type `/usr/bin/time-configlet-coppel` at the command line.

2. Under **Time Zone**, select your Region and Time Zone from the drop-down lists.

The Time Zone list varies with the Region that you select.

3. Select:
    - **The System set to UTC** box to set the system to Greenwich Mean Time.
    - **The path to your Network Time Server**, if you have one.

4. Under **Date and Time**, select the month and year.

The arrows on the left of the month and year display move the month or year backward, while the arrow on the right moves it forward.

If you move the month from December to January, the year changes automatically.

5. Select the day by highlighting it on the calendar.

6. Enter the hour, minute and seconds.

In each field, you can either highlight the current entry and overwrite it or else use the arrow keys to change it.

7. Set the time to AM or PM.

![](img/e36b94f8548b09d00212238f073b11d9_413_0.png)

**Note**

If you prefer a 24 hour clock or to use Greenwich Mean Time, you can reset the date once you install.

8. Select the Set Date and Time button to apply your changes.

9. Select the OK button.

## Setting Date and Time From the Command Line

As the root user, type `date MMddhhmmmy` at the command line. MM is the month given as a two digit number, and mm is minutes. Hours should be in 24-hour format.

To set the time to Greenwich Mean Time, use the `-u` option.

![](img/e36b94f8548b09d00212238f073b11d9_413_1.png)

**Note**

A desktop clock may take a moment to update.

For more information about the `date` command, see its on-line help.

## Setting the Command Shell

Linux has many command line interfaces. These interfaces are called shells. The default shell is BASH (the Bourne Again Shell). This manual assumes that you are using it.

To change a shell temporarily, enter its name as a command. The next time you open a command line, you will be using BASH again.

To change your default shell permanently:

1. Type `chsh` at the command line.
2. When prompted, type the path to the shell's executable. Executables for shells are usually in the `/bin` directory. They have the same name as the shell.

![](img/e36b94f8548b09d00212238f073b11d9_414_0.png)

**Note**

You can also use the `usermod -s SHELL` to change a user's shell.

### Upgrading from Debian and Debian-Based Distributions

You can upgrade to Progeny Debian from various releases of Debian and from several Debian-based distributions.

This appendix includes information about upgrading from:

- Debian releases.
- Debian 2.2 with Ximian (Helix Code) GNOME.
- VA Linux's distribution of Debian.
- Storm Linux.
- Libranet.
- Corel Linux.

All upgrades are done using `apt-get`. If you are not familiar with `apt-get`, see "Installing and Removing Packages With the apt-get Command," page 273.

#### Upgrading from Debian Releases

This section contains information about upgrading from:

- Older Debian versions (2.1 and earlier).
- Debian 2.2.
- Debian Testing Release.
- Debian Unstable Release.

#### Upgrading from Older Debian Versions

Upgrading from versions of Debian before 2.2 are not supported by Progeny Linux Systems.

If you want to attempt an upgrade anyway, do one of the following:

- Follow the instructions for upgrading from 2.2.
- Upgrade to Debian 2.2, then follow the instructions for upgrading from Debian 2.2.

#### Upgrading from Debian 2.2

1. Add the following line at the top of the `/etc/apt/sources.list` file: `deb http://archive.progeny.com/progeny stable main contrib non-free`.
2. Run the following commands:
    a. `apt-get update`.
    b. `apt-get -f dist-upgrade`.
    c. `apt-get install debconf`.
    d. `apt-get install progeny-potato-upgrade`.
3. Install the Progeny Debian standard system package. Type: `apt-get install progeny-standard-system`.
4. Remove the Progeny Debian upgrade package. Type: `dpkg --remove progeny-potato-upgrade`.
5. Restart your system. This step is recommended, but optional.

#### Upgrading from the Debian Testing Release

Upgrading from the Debian testing release may have mixed results. Depending on when the release was last upgraded, it may contain packages that Progeny Debian has not tested. Because of the strong possibility that upgrades from the testing release will cause problems on your system, Progeny Linux Systems does not support them.

If you want to try an upgrade anyway, backup all important information and follow the instructions for upgrading from Debian 2.2.

Otherwise, do a complete install that includes reformatting of all Linux partitions.

#### Upgrading from the Debian Unstable Release

The Debian unstable release is changing rapidly, and includes many packages not tested by Progeny. For these reasons, upgrading from the Debian Unstable Release is not supported by Progeny Linux Systems. Instead, do a normal install, reformatting all Linux partitions.

#### Upgrading from VA Linux Debian Set

The VA Linux Debian distribution was released between Debian 2.1 and 2.2, and is a mixture of the two.

1. Add the following line at the top of the `/etc/apt/sources.list` file: `deb http://archive.progeny.com/progeny stable main contrib non-free`.
2. Run the following commands:
    a. `apt-get update`.
    b. `apt-get -f dist-upgrade`.
    c. `apt-get install debconf`.
    d. `apt-get install progeny-slink-upgrade`.
3. Install the Progeny Debian standard system package. Type: `apt-get install progeny-standard-system`.
4. Remove the Progeny Debian upgrade package. Type: `dpkg --remove progeny-slink-upgrade`.
5. Restart your system. This step is recommended, but optional.

#### Upgrading from Debian 2.2 With Ximian (Helix) GNOME

Ximian GNOME (formerly known as Helix) is a customized version of the GNOME desktop. It may be installed over an existing Debian version, most likely Debian 2.2. It is also a standard part of the Storm hail release and the latest releases of Libranet.

![](img/e36b94f8548b09d00212238f073b11d9_419_0.png)

**Note**

> Due to the timing of releases, systems using earlier versions of Debian with Ximian GNOME are uncommon.

1. Add the following line at the top of the `/etc/apt/sources.list` file: `deb http://archive.progeny.com/progeny stable main contrib non-free`.
2. Remove Ximian’s customized packages. Enter the following series of commands:
    a. `apt-get remove mc-common`.
    b. `apt-get remove libpopl0`.
    c. `apt-get remove libgtk1.2`.
    d. `apt-get remove gnome-games-locale`.
3. Repeat the following command until all package dependencies have been satisfied: `apt-get -f dist-upgrade`.
4. Install the Progeny Debian 2.2 upgrade package. Type: `apt-get install task-progeny-potato-upgrade`.
5. Install the Progeny Debian standard system package. Type: `apt-get install progeny-standard-system`.
6. Remove the Progeny Debian 2.2 upgrade package. Type: `dpkg --remove progeny-potato-upgrade`.
7. Restart your system. This step is recommended, but optional.

#### Upgrading from Storm Linux

Storm Linux is a Debian-based distribution, available in two releases: rain and hail.

To upgrade the Storm Linux rain release, follow the instructions for upgrading from older versions of Debian.

To upgrade the Storm Linux hail release, follow the instructions for upgrading from Debian 2.2 with Ximian GNOME.

#### Upgrading from Libranet

Libranet is a Debian-based distribution, available in a number of releases. Before upgrading, check which version of Debian the Libranet release is based on, then follow the instructions for that Debian version. The latest versions of Libranet can be upgraded by following the instructions for upgrading from Debian with Ximian GNOME.

#### Upgrading from Corel Linux

Corel Linux is a Debian-based distribution, available in two releases. Because of the extensive changes in Corel Linux, upgrading it to Progeny Debian is neither recommended nor supported.

Instead, users of all releases of Corel Linux should backup all important information, and do a complete install of Progeny Debian that includes reformatting all Linux partitions.

To reproduce the look and feel of Corel Linux as closely as possible, install KDE from the Extras CD and use it as the default desktop.
