# The crontab Command (Scheduling)

Option | Action | Comment
---|---|---
-e | Opens a user’s crontab file in the vi text editor. | If no user is specified, the crontab file opened is the current user’s.
FILE | Creates a crontab file. | Mostly useful for placing the file in a non-standard location.
-l USER | Views a user’s crontab file. | Usable only by the root user.
-r USER | Removes a user’s crontab file. | Usable only by the root user.
-u USER | Sets which user’s crontab file is affected. | Usable only by the root user.

# Editing and Reading a crontab File

To edit a crontab, type crontab -e user. The file opens in the default editor for the current user.

Each line in a crontab file schedules a single task.
