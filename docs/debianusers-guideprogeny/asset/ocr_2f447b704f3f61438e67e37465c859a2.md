# # Commands for Reading System Information

Command | Information | Comments
arch | CPU | i586 is a Pentium, i686 a Pentium II. Compatible processors, such as Celerons, are listed as the Intel processor to which they are compatible.
▼ date | Date | ▼ The date command gives the system date. It can also be used to reset the date.
▼ cal MM YY | ▼ The cal command displays a calendar for the month and year given.
If no month or year is given then the calendar for the current month displays.
dnsdomainname | Domain name | Any user can use for viewing the domain name, but not for changing it.
env | Environment | Can also be used to set an environment variable.
