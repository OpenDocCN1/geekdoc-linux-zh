# Reading the Edit Partition Screen

| Column | Information |
|---|---|
| Name | The Linux name for the hard drive or partition. See “Reading Linux Device Names,” page 40. Drives are displayed in a tree structure, with partitions as branches of the tree. |
| Size | The size of the partition in megabytes or gigabytes. |
| Mount Point | The directory from which you access the partition in the Linux directory structure. To be readable from Linux, all partitions must have a mount point except the swap partition. |
