# The cpio Command (Backup and Restore)

| Flag | GNU Option | What it does |
|---|---|---|
| -i OPTIONS STRING | --extract | Restores files from an archive that match the string. <br>Metacharacters can be used in the string. See “Using Metacharacters or Wild Cards,” page 118. <br>Strings should be surrounded by double quotation marks. |
| -o OPTIONS | --create | Backs up files to an archive file. |
| -p OPTIONS DIRECTORY | --pass-through | Copies files to another directory on the same system. <br>This option is useful for repeating a backup that is later burned to a CD. |

# Backing Up using the cpio Command

To do a backup, use cpio with a search command, such as find. See “Searching for Files: Using the find Command,” page 182.
