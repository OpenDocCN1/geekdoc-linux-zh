+   2  Enter the new name in the File Name field.

> **Warning**
> 
> Paths, aliases, and other features may be disabled if a file is renamed.

+   3  Select the OK button to rename the files.

# Renaming Files From the Command Line

To rename files, use the `mv` (move) command. See “Renaming Files From the Command Line,” page 214.

To keep the renamed file in its original directory, keep the destination’s path name the same as the original, except for the file name.

# Deleting Files From the Desktop

You can permanently delete a file or sent it to the Trash in case you want to restore it later.

# Deleting Files Permanently

+   1  Open the GNOME Midnight Commander. Do one of the following:

+      - From the workspace, select the Home directory launcher.
+      - From the menu, select Programs > File Manager.

+   2  Select the files to delete.

+   3  Do one of the following:

+      - Select Delete from one of the selected file’s pop-up menu.
+      - Select Delete from the File menu of the Midnight Commander.
