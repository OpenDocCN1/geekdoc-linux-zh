## Selecting the Installation Target
Selecting the Installation Target is the first step in configuring the minimal system. Unless you select Custom partitioning, it is also the only step. Each installation target uses your hard drive in a different way. If you are unsure of which to choose, study the advantages and disadvantages of each target to decide which is best for you.

### Installation Targets for Progeny Debian

| Advantages | Disadvantages |
| :--- | :--- |
| **Entire Disk** | |
| - You do not need any special knowledge. <br> - It's quick. | - You lack full control of the process. <br> - Information is lost unless you back it up. <br> - The default setup may not be what you want, especially if you are an advanced user. |
| **Free Space** | |
| - Information is not destroyed. <br> - Existing partitions are kept. <br> - You do not need any special knowledge. <br> - It's quick. | - The hard drive must have enough continuous space for the necessary partitions. <br> - You lack full control of the process. <br> - The partitions created may be smaller than you want or need. |
| **Custom** | |
| - You fully control the process. <br> - You decide whether to keep existing partitions. <br> - You can put major directories such as /home or /usr on different partitions. | - You must understand what you are doing. <br> - You could destroy information by accident. |

## Creating and Editing Partitions

![](img/e36b94f8548b09d00212238f073b11d9_61_0.png)

When you select Custom partitioning as your installation target, the Edit Partitions screen opens.

Using the Edit Partitions screen, you can create, delete, or edit partitions. Partitions are divisions of your hard drive.

You need at least a root partition before you can continue the install. You should also add a swap partition for virtual memory.

If you want, you can also create other partitions.

For example, many Linux users prefer to have personal files on a separate partition to make back ups easier.

Similarly, some put printer queues on a separate partition to limit their size.

# Note

Currently, you cannot resize a partition or change its type during an install. Instead, delete the partition then create new ones.

Remember that deleting a partition destroys all information on it.

To create or edit a partition:

1. Select a partition to edit or a block of free space in which to create a partition from the **Edit Partition** screen. Your selection is highlighted.

![](img/e36b94f8548b09d00212238f073b11d9_62_0.png)

For detailed information about the Edit Partition screen, see “Reading the Edit Partition Screen,” page 64.

2. Select the New or Edit button. In both cases, the Partition screen opens.

![](img/e36b94f8548b09d00212238f073b11d9_63_0.png)

Enter the features of the partition. See “New and Edit Screen Fields,” page 66.

![](img/e36b94f8548b09d00212238f073b11d9_63_1.png)

> **Note** If you are editing an existing partition, you cannot change the type or size. Nor can you make a swap partition bootable.

You must have a root partition. In addition, you probably want a swap partition. You may also want to create other partitions.

You can change the mount point of an existing partition without losing the information on it.

However, if you select the Format? box, you lose all information on an existing partition as soon as you continue the installation.

Select the OK button when you are finished. You return to the Edit Partition screen.

If you were creating a partition, the partition is now listed, and the entry for Free Space is either smaller or no longer listed.

3. Repeat steps 1 to 2 for each partition that you want to create or edit. Remember not to format existing partitions without backing up important information.

4. Select the **Next** button to carry out your changes to your hard drives. A confirmation screen appears.

![](img/e36b94f8548b09d00212238f073b11d9_64_0.png)

5. Select the **Yes** button to continue with the install.

# Note

Changes to your partitions are not made until you select the **Next** button.

If you change your mind about partitions that you create or edit, you can select the **Undo All** button to return the hard drive you selected to its original state.

You can also use the Back button to choose another installation target.

## Reading the Edit Partition Screen

| Column | Information |
|---|---|
| Name | The Linux name for the hard drive or partition. See “Reading Linux Device Names,” page 40. Drives are displayed in a tree structure, with partitions as branches of the tree. |
| Size | The size of the partition in megabytes or gigabytes. |
| Mount Point | The directory from which you access the partition in the Linux directory structure. To be readable from Linux, all partitions must have a mount point except the swap partition. |
| System | The format or filesystem of the partition. Possible formats are:<br>- Linux ext2: The native Linux format.<br>- Linux swap: The Linux swap partition.<br>- FAT: FAT32 or vfat, the modern Windows format.<br>- Free Space: no format. |
| Status | The state of the partition. Usually, the only statuses that you see are:<br>- To be mounted: The partition is ready for use, and will be mounted, but is not going to be formatted.<br>- To be formatted: The partition needs to be formatted before it is ready for use.<br>- Bootable: The partition is listed as bootable in Windows. If a Windows installation is on on the first partition, the installer detects it and sets it as Bootable automatically. |

> **Note**
>
> No changes are carried out until you select the Next button.

## New and Edit Screen Fields

| Field | Choices |
| :--- | :--- |
| File System Flags | Select the Format? box to format the partition. All information is lost. <br>To avoid difficulties, select this option if you are installing over an existing Progeny Debian install. |
| File System Type | The format of the partition. Possible formats are: <br>- Linux ext2: The native Linux format. This format is the one most commonly used in Linux. <br>- Linux swap: The Linux swap partition. This format is used for virtual memory, which may improve performance. You can have as many swap partitions as you have space for. After you install, you can recompile your kernel to add support for other types of filesystems. Linux can support over two dozen filesystems, including FAT16 (msdos in Linux), the format used by DOS and early versions of Windows. FAT32 (vfat in Linux) is supported by default in Progeny Debian. FAT32 is the format used by recent versions of Windows. Several types of journalled filesystems are also available. |
| Mount Point | The directory from which you read the partition. You can select the directory from the drop-down list or enter it in the field. Choices from the drop-down list are:<br>◦ /: The root or top directory in the tree.<br>◦ /boot: Files needed to start Linux.<br>◦ /home: Users' home directories and personal files.<br>◦ /tmp: Temporary files.<br>◦ /usr: Common system files for all users.<br>◦ /usr/share: Common system files for all users, including many basic programs.<br>◦ /var: Variable files, including logs and queues.<br>◦ /var/spool: Queues for information, such as print jobs. <br>A common place for non-Linux partitions is in the /mnt directory. For convenience, you can call the mount points by their Windows name. For example: /mnt/C. <br>You must have at least a root directory before continuing with the install. In addition, a swap file gives better performance, enabling you to use virtual memory. Putting other directories on different partitions can make backing up or recovering easier. |
