# ## The mv Command (Move)

| Option | Action | Comments |
| :--- | :--- | :--- |
| ▼ -i<br>▼ --interactive | Asks for confirmation before over writing any file. | |
| ▼ -u<br>▼ --update | Moves only files whose date are the same or newer than similarly named ones in the target directory. | |
| ▼ -v<br>▼ --verbose | Displays file names as they are moved. | |
