# The find Command

| Option | Action | Comments |
|---|---|---|
| -cmin ARGUMENT | Searches by minutes since files were changed. | Arguments include:
  * +NUMBER: More than the given number of minutes ago.
  * -NUMBER: Less than the given number of minutes ago.
  * NUMBER: Exactly the given number of minutes ago. |
| -ctime ARGUMENT | Searches by the number of days since file attributes were changed. | Arguments are:
  * +NUMBER: More than the given number of days ago.
  * -NUMBER: Less than the given number of days ago.
  * NUMBER: Exactly the number of days ago. |
| -follow | Traces symbolic links to original files. |  |
