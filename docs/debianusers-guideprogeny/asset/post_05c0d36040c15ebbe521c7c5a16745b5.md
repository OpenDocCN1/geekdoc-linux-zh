## Adding a New CD to the List of Sources

Type: `apt-cdrom OPTIONS COMMAND`.

Currently, the only command available is `add`.

This utility maintains the database of CDs in `/var/state/apt/cdroms.list`.
Options can be entered as part of the command or set in `/etc/apt/apt.conf`.
Options set in the configuration file can be overridden from the command line by using the option `-OPTION=no`.

> **Note**
> You can also use the `apt-set` command to set a CD source.

## Managing Packages With the dpkg Command

The `dpkg` command for package management. Although `dpkg` can be used to install a package, its real strength is its ability to retrieve information about packages on your system. It is especially useful if you need to search packages or their contents, or for building packages.

For information about building packages, see the on-line help for `dpkg` and `dpkg-deb`. Most of the functions of `dpkg-deb` can be had using the actions defined for `dpkg`.

Type: `dpkg OPTIONS ARGUMENT ACTION PACKAGE`.

Depending on the option, the package may be identified by its file name or by the name of the package.

### The dpkg Command (Package Management): Options

| Options | Action | Comments |
| :--- | :--- | :--- |
| `-B`<br>`--auto-deconfigure` | Automatically deconfigures any dependent packages when a package is removed. | |
| `-E`<br>`--skip-same-version` | Does not install the package if the current version is already installed. | |
| `-R`<br>`--recursive` | Includes any packages in the subdirectories listed in the action. | Use with the `-A`, `--install`, `--unpack` or `-avail` actions. |
| `--force ARGUMENT` | Forces the command complete even though a problem occurs. | A warning displays, but the command continues to be processed.<br><br>See "The dpkg Command (Manage Packages): Argument", page 285. |
| `--no-force ARGUMENT` | Does not force the command to complete if a problem occurs. | The command stops with an error message. |
| `--refuse ARGUMENT` | | See "The dpkg Command (Manage Packages): Argument", page 285. |

### The dpkg Command (Manage Packages): Argument

| Argument | Action |
| :--- | :--- |
| `auto-select` | Selects or de-selects packages to install or remove. |
| `configure-any` | If necessary, configures any unconfigured packages that the package depends on. |
| `conflicts` | Installs even if the package conflicts with another one. This option could cause some files to be over-written. |
| `depends` | Warnings about dependency problems display, but do not stop the command. |
| `depends-version` | Warnings about version problems display. |
| `downgrade` | Installs even if a newer version is already installed. |
| `hold` | Processes packages with a hold flag. |
| `overwrite` | Overwrites a file from one package with the same file from another package. |
| `remove-reinstreq` | Removes broken packages. |

### The dpkg Command (Package Management): Actions

| Actions | Action | Comments |
| :--- | :--- | :--- |
| `-A`<br>`--record-avail` | Updates package information on your system. | |
| `-C`<br>`--audit` | Searches for partly installed packages. | If possible, what is missing is explained. |
| `-c PACKAGE`<br>`--control PACKAGE` | Displays files in a Debian package. | |
| `--configure PACKAGES` | Configures an unpacked package. | Note that the package names, not the package files are entered.<br><br>Instead of listing packages, you can use `-a` or `--pending` to configure all unpacked packages. |
| `-e PACKAGE DIRECTORY`<br>`--control PACKAGE DIRECTORY` | Extracts control information into the directory specified. | |
| `--get-selections STRING` | Displays package selections. | If no string is given, all selected packages display. |
| `-x PACKAGE DIRECTORY`<br>`--extract PACKAGE DIRECTORY` | Extracts files from the package into a directory. | Useful for examining a package's contents. |
| `-i PACKAGE NAME`<br>`--install PACKAGE FILE` | Installs a package. | To install all packages in a directory, use this option with `-R` or `--recursive` and complete with a directory name instead of a single package name. |
| `-I STRING`<br>`--list STRING` | Lists packages that match the string. | If no pattern is listed, all packages are listed. |
| `-L PACKAGE`<br>`--listfiles PACKAGE` | Lists files that come from a particular package. | |

| `--purge PACKAGE` | Purges a package. | Note that the package names, not the package files are entered.<br><br>Instead of listing packages, you can use `-a` or `--pending` to configure all packages marked for purging. |
| `-r PACKAGE`<br>`--remove PACKAGE` | Removes a package. | Note that the package names, not the package files are entered.<br><br>Instead of listing packages, you can use `-a` or `--pending` to remove all packages marked for removal. |
| `-S FILENAME`<br>`--search FILENAME-PATTERN` | Searches installed packages for a file name. | |
| `-s PACKAGES`<br>`--status PACKAGE` | Displays a package's status. | |
| `--unpack` | Uploads a file, but does not configure it. | To unpack all packages in a directory, use this option with `-R` or `--recursive` and complete with a directory name instead of a single package name. |
| `--update-avail`<br>`--merge-avail` | Updates list of available files. | |
| `--yet-to-unpack` | Searches for uninstalled packages that have been selected for installation. | |

### Installing Unpackaged Software

Linux developers often offer programs as tar files of uncompiled source code instead of in a package format. While a program is in early development, continually remaking packages would be a waste of effort, so most programmers do not bother. The source code is, after all, what most programmers are interested in.

A tar file of unpackaged software may be listed as being dynamically linked or static. A dynamically linked piece of software calls on programming libraries as it needs them. By contrast, static software includes the necessary functions within itself.
