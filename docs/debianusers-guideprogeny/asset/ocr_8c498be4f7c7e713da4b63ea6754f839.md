# The useradd Command (Sets Up New User)

| Option | Action | Comments |
| :----- | :----- | :----- |
| -m | Creates a home directory with the default features. | The default features are:<br>► That has the same name as the user name.<br>and<br>► Is a sub-directory of /home.<br>If you do not want both these features, then use the -d option. |
| -f NUMBER | Disables the account after the number of days has passed. | Use with the -e option, which sets an expiry date. |
| -g GROUP | Changes the default group. | If no group is specified, then a group with the same name as the user name is created. |
| -s SHELL | Sets the user's shell. | If no shell is specified, then the default BASH is used. |
