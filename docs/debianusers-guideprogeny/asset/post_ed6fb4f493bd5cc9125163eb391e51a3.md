
## Viewing Process Information from the Command Line: Using the gtop Command

1. Start the command:
   - Type `gtop` from a command line.
   - Or select `gtop` from the pop-up menu of some Monitor applets. See "Viewing User Information from the Desktop: Using the gw Command," page 245.
   
   In either case, the GNOME System Monitor window opens.

   > If you use the command regularly, add it to the workspace, panel, or menu.

2. Select the statistics to display. Select Settings > Preferences from the menu.

3. Select a tab to display. Either click on the tab with the mouse, or select a tab from the View menu.

   By default, the tab displays are:
   - Processes: Processes that are currently running on the system.
   
   The statistics to display can be altered in the Settings > Preferences menu. The tab includes graphs for CPU, memory, swap and average loads.

## Viewing User Information from the Desktop: Using the gw Command

![](img/e36b94f8548b09d00212238f073b11d9_246_1.png)

The `gw` utility is the desktop equivalent of the `w` command. It displays information about users. If you are logged in as root user, it displays information about all users currently logged in. If you are logged in as a regular user, then only information about the current account displays.

Type `gw` from a command line. The Active User screen opens.

**Note**

If you use the command regularly, add it to the workspace, panel, or menu.

From the Active User screen, you can read such information about where users logged in from (local or remote), how long they have been logged in, and the processes they are currently running.

# Using the Monitor Applets

The Applets are small programs that are a standard part of the GNOME desktop. When selected, an applet displays in the panel.

The Monitor applets are among the most useful applets. Each gives a graphic display of some aspect of the system. To add one to the panel, go to Applets > Monitors on the main menu.

## Monitor Applets

| Monitor | What It Does |
|---|---|
| CPU/MEM usage | The CPU, memory, and swap load. |
| Battery charge | The battery charge for laptops. Warns when the charge is low. |
| Disk usage | The amount of hard drive space used and free. |
| cpuload | The CPU resources being used. |
| memload | The amount of memory being used. |
| Swapload | The amount of swapping done by the system. |
| Netload | The load on different network interfaces. |
| Load Average | The average amount of activity on the system. |

# Using Command Line Tools

Linux includes many commands for gathering information. The following table summarizes some of the more common and more useful ones.

To read a complete list of options for each command, see its man or texinfo pages. See "Finding Help for Commands," page 131.

The following tables are divided into four categories:

- System information commands.
- Memory information commands.
- Processes information commands.
- User information commands.

# Reading /proc Files

The `/proc` directory contains several files that are useful when you are configuring or troubleshooting your system.

## Information Files in the /proc Directory

| File | Information |
| :--- | :--- |
| /proc/cpuinfo | General information about the system, including the processor type, its speed, and cache size. |
| /proc/interrupts | Maps IRQ addresses to devices. |
| /proc/parport | Information about parallel ports and the devices attached to them. |
| /proc/sound | The system’s sound configuration, including the drivers installed. |

**Warning**

Changing these files can damage your system. Regular users should not have write permission to these files, and the root user should be careful about changing them.

# Reading Log Files

Log files record messages about all activities on your system. Some can be viewed by regular users, but many can only be viewed by the root user.
