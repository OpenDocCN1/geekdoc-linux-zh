# Commands for Reading Process Information

| Command | Topic | Comments |
| :--- | :--- | :--- |
| ps aux | Active processes | No hyphen is needed in front of options. |
| pstree | Parent and child processes | A parent process is one that starts another process.\nA child process is one that is started by another process. |
| fuser -a | Process using a file or filesystem | Usable only from the root account |
| top | Processes that use the most system resources | |
