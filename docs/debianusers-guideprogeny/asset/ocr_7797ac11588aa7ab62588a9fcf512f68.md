# The fsck Command (Checks Filesystems)

| Option | Action | Comment |
| :--- | :--- | :--- |
| -R | Checks all filesystems listed in /etc/fstab except the root partition. | Use with -A. |
| -t TYPE | To only check filesystems of a certain type | Common types are: \n- ▼ ext2: The native Linux format. \n- ▼ swap: Linux swap file. Use only for the swap file. \n- ▼ vfat: The format for Windows 98, ME, and the second release of Windows 95. \n- ▼ iso9660: CD drive |
