# Commands for Reading System Information

| Command | Information | Comments |
| :--- | :--- | :--- |
| fdisk -l | Partitions | The *fdisk* command can also be used to make and delete partitions.

However, the *parted* utility is more versatile for these purposes. See “Partitioning a Hard Drive,” page 361. |
| hostname -i | Host Name | Displays host name and IP address. |
| ls | Files | ▼ Useful options include:
* ▼ -l: Permissions, owners, sizes, modification time.
* ▼ -i: Inodes.
* ▼ -s: Sizes. |
| lsmod | Kernel modules loaded | Usable only from the root account. For each loaded module, lists:
* ▼ Name.
* ▼ Size.
* ▼ Referring modules (if any). |
