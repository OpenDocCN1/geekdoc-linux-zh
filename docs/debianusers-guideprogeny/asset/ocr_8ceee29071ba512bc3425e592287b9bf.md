# Creating and Editing Partitions

![](bbox=[0.14, 0.11, 0.73, 0.44])

When you select Custom partitioning as your installation target, the Edit Partitions screen opens.

Using the Edit Partitions screen, you can create, delete, or edit partitions. Partitions are divisions of your hard drive.

You need at least a root partition before you can continue the install. You should also add a swap partition for virtual memory.

If you want, you can also create other partitions.

For example, many Linux users prefer to have personal files on a separate partition to make back ups easier.

Similarly, some put printer queues on a separate partition to limit their size.
