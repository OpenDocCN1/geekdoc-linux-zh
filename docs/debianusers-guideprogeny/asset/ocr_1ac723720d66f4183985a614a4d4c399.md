Note
The GNOME Trash cannot be set to empty when it reaches a certain size.

However, you could use the cron command to delete it at a regular time. See “Scheduling Regular Jobs,” page 211.

# Restoring From the Trash

Your Trash folder behaves exactly the same as any other folder on your desk-top. To restore files, move them from the Trash folder to another folder. See “Moving Files from the Desktop,” page 174.

# Deleting Files From the Command Line

Type: rm FILE.

If you want the option to recover files, move them to a storage directory. You can use the.gnome-desktop/Trash directory in your home directory. This is the directory in which files are stored when you send them to the Trash on the desktop.

Note
You can also use mkdir to remove empty directories.
However, in most cases, you can simply use rm -r.
