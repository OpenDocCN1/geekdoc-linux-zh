**5**  If necessary, do one of the following:

If you selected **Entire disk**, choose the hard drive to use. Then press the **Next** button.

If you selected **custom partitioning**, divide your hard drive the way you want if you selected Custom partitioning. Then press the Next button. See “Creating and Editing Partitions,” page 60.

Note

If you selected **Free Space**, then this step is omitted.

Note

If you are installing over an existing Progeny Debian installation, select **Custom install** and re-format the partitions. Otherwise, the reinstall may fail.
