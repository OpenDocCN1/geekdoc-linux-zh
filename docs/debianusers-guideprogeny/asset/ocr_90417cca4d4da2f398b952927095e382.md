# ## Automating Multiple Installs

Once you have installed Progeny Debian on a single system, you can auto-mate other installs by creating an automated install floppy. The automated install floppy is inserted in the floppy drive when you start an install.

Making the automated install floppy consists of two steps:

+   - Creating the configuration files.
+   - Creating the automated installer floppy.

# ## Creating Configuration Files

The configuration files are created on an existing Progeny Debian system, then copied to the floppy for use during the install.

You should know that:

+   - `ssisord.lst, netmod.lst, and sources.lst` can be blank, but must be in the `/conf` directory with the other configuration files.
+   - `postinst` is not required.

Place all finished configuration files in a directory named /conf. This direc-tory can be a sub-directory any place on the system. Commands to create the automated install floppy are run from this directory.

Examples of configuration files are available in `/usr/share/doc/autoinstall/`.
