# The Panel

The panel runs across the top of the desktop. It contains the menu, icons, and commonly used tools. The panel contains:

+   The GNOME menu on the left.

+   The GNOME Help icon for on-line help.

+   The browser icon for your internet connection.

+   The GNOME Control Center for configuring the desktop. See “Making the Desktop Your Own,” page 149.

+   The Add/Remove Software icon.

+   The terminal icon for opening a command line.

+   The GNOME Desktop Guide, or pager, beside the task list. The pager opens a list of currently running processes and shows where windows are open on the work space.
