# The dpkg Command (Package Management): Actions

| Actions | Action | Comments |
|---|---|---|
| ▼ -A | Updates package information on your system. |  |
| ▼ --record-avail |  |  |
| ▼ -C | Searches for partly installed packages. | If possible, what is missing is explained. |
| ▼ --audit |  |  |
| ▼ -c PACKAGE | Displays files in a Debian package. |  |
| ▼ --control PACKAGE |  |  |
| --configure PACKAGES | Configures an unpacked package. | Note that the package names, not the package files are entered. |
|  |  | Instead of listing packages, you can use -a or --pending to configure all unpacked packages |
| ▼ -e PACKAGE DIRECTORY | Extracts control information into the directory specified. |  |
| ▼ --control PACKAGE DIRECTORY |  |  |
| --get-selections STRING | Displays package selections. | If no string is given, all selected packages display. |
