# Note

Currently, package sets are supported only by Prog-eny Debian CDs or download sites. You cannot use gnome-apt-pkgs et with an ordinary Debian source.

+   1 Log in as the root user.

+   2 Start gnome-apt-pkgs et. Either:

+   ■ Select Programs > System > Add/Remove Software from the main menu.

or

+   ■ Type gnome-apt-pkgs et at the command line.

In either case, the Add/Remove Package Set window opens.
