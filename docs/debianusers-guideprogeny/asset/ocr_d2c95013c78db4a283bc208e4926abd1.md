To copy the owner from another file, type: chown OPTIONS --reference=SOURCE TARGET.

# The chown Command (Change Owner)

| Option | Action | Comments |
| :--- | :--- | :--- |
| -c --changes | Displays information about files that are changed. |  |
| --reference | Changes the ownership of both symbolic links and the files to which they point. |  |
| -h --no-dereference | Changes the ownership of a symbolic link, but not of the file to which it points. |  |
| --reference=FILE | Copies owner from the file listed. |  |
