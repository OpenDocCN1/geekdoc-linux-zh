# ### Upgrading from Debian and Debian-Based Distributions

You can upgrade to Progeny Debian from various releases of Debian and from several Debian-based distributions.

This appendix includes information about upgrading from:

+   - Debian releases.
+   - Debian 2.2 with Ximian (Helix Code) GNOME.
+   - VA Linux's distribution of Debian.
+   - Storm Linux.
+   - Libranet.
+   - Corel Linux.

All upgrades are done using apt-get. If you are not familiar with apt-get, see "Installing and Removing Packages With the apt-get Command," page 273.
