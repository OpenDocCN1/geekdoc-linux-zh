# Display Options for the ps Command

| Option | To display | Comment |
|---|---|---|
| k stime | The CPU time taken by the process. |  |
| U uid | The ID of the process's user. |  |
| c cmd | The name of the processes' binary file. |  |
| g pgrep | The process's group. |  |
| p if | The process's ID. |  |
| p ppid | The process's parent's ID. |  |
| s size | The process's size. | The size is given in kilobytes. |
| s size | The process's size. | The size is given in kilobytes. |
