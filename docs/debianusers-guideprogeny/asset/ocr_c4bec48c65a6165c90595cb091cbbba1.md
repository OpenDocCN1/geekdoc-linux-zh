# The dpkg Command (Package Management): Options

Options | Action | Comments

--- | --- | ---
▼ -B | Automatically deconfigures any dependent packages when a package is removed. |
▼ --auto-deconfigure | Automatically deconfigures any dependent packages when a package is removed. |

▼ -E | Does not install the package if the current version is already installed. |
▼ --skip-same-version | Does not install the package if the current version is already installed. |
