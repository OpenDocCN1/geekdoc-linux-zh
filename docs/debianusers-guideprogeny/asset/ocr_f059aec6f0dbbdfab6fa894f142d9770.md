# Adding Links From the Desktop

+   1. Open the GNOME Midnight Commander. Do one of the following:
+       - From the workspace, select the Home directory launcher.
+       - From the menu, select Programs > File Manager.
+   2. Select the files to link. See “Selecting Files From the Desktop,” page 205.
+   3. Right-click on one of the selected files. The pop-up menu opens
+   4. Select Symlink from the pop-up menu. A dialogue window opens.

![](bbox=[0.17, 0.37, 0.78, 0.58])

+   5. If necessary, enter the name of the original file. In most cases, you do not need to.
+   6. Enter the file name for the symbolic link.
+   
+   If the file name already exists, a confirmation window opens. Select the Cancel button to avoid over writing the file.
+   
+   If the file name entered does not conflict with an existing one, then the symbolic link is created.
