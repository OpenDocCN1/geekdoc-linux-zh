# New and Edit Screen Fields

| Field | Choices |
| :--- | :--- |
| Mount Point | The directory from which you read the partition. You can select the directory from the drop-down list or enter it in the field. Choices from the drop-down list are:\n\\u25bc /: The root or top directory in the tree.\\n\\u25bc /boot: Files needed to start Linux.\\n\\u25bc /home: Users' home directories and personal files.\\n\\u25bc /tmp: Temporary files.\\n\\u25bc /usr: Common system files for all users.\\n\\u25bc /usr/share: Common system files for all users, including many basic programs.\\n\\u25bc /var: Variable files, including logs and queues.\\n\\u25bc /var/spool: Queues for information, such as print jobs.\n\nA common place for non-Linux partitions is in the /mnt directory. For convenience, you can call the mount points by their Windows name. For example: /mnt/C.\n\nYou must have at least a root directory before continuing with the install. In addition, a swap file gives better performance, enabling you to use virtual memory. Putting other directories on different partitions can make backing up or recovering easier. |
