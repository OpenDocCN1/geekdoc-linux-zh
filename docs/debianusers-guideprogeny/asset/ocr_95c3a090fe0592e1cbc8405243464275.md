# New and Edit Screen Fields

| Field | Choices |
| :--- | :--- |
| File System Flags | Select the Format? box to format the partition. All information is lost. |
| | To avoid difficulties, select this option if you are installing over an existing Progeny Debian install. |
| File System Type | The format of the partition. Possible formats are: |
| | \- Linux ext2: The native Linux format. |
| | This format is the one most commonly used in Linux. |
| | \- Linux swap: The Linux swap partition. |
| | This format is used for virtual memory, which may improve performance. You can have as many swap partitions as you have space for. |
| | After you install, you can recompile your kernel to add support for other types of filesystems. Linux can support over two dozen filesystems, including FAT16 (msdos in Linux), the format used by DOS and early versions of Windows. |
| | FAT32 (vfat in Linux) is supported by default in Progeny Debian. FAT32 is the format used by recent versions of Windows. |
| | Several types of journalled filesystems are also available. |
