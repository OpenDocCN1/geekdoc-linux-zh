# The rm Command (Remove)

| Option | Action | Comments |
| :--- | :--- | :--- |
| ▼ -d<br>▼ --directory | Removes any sub-direc-tories and their con-tents. | Only the root user can use this option. |
| ▼ -f<br>▼ --force | Removes all files with-out confirmation. | |
| ▼ -i<br>▼ --interactive | Asks for confirmation before removing each file. | |
| ▼ -t, -R<br>▼ --recursive | Removes sub-direc-tories and their contents. | Use carefully to avoid accidental loss of files. |
| ▼ -v<br>▼ --verbose | Displays file names as they are removed. | |

# Merging Files

Files cannot be merged from the desktop. From the command line, you can use a viewing command with a redirection operator or diff3.
