# # Hardware Information Needed for an Install

| **Hardware** | **Information You Might Need** |
| Mouse | \- Type: serial, PS, or USB. \- Port. \- Manufacturer. \- Number of buttons. |
| Network | \- Model and manufacturer. \- Type of adapter. \- Domain name. \- DHCP host name. \- IP Address. \- Netmask. \- Gateway. \- Name server. |
