# The tar Command (Archive)

| Option | Action | Comment |
| --- | --- | --- |
| ▼ --remove-files | Removes files after they are added to a tar file. | |
| ▼ -t<br>▼ --list | Displays files in an archive. | |
| ▼ -u<br>▼ --update | Updates an archive. | Files are only added if they are new than files of the same name that are already in the archive. |
| ▼ -v<br>▼ --verbose | Displays actions on-screen. | |
| ▼ -w<br>▼ --interactive | Asks confirmation before working with each file. | Enter y for Yes, and n for No. |
| ▼ -W<br>▼ --verify | Checks for errors in archiving or extracting. | |
