# Copying Files for Later Backup

At times, you may not want to copy files directly to the backup device. You might want to prepare the backup first in order to see its size, or to compress the files before backup.

Similarly, if you are creating a CD, copying the files directly to the CD is unreliable or difficult with some CD burning software. The -p option for cpio is designed for all such circumstances.

To do a copy for later backup, use cpio with a search command, such as find. See “Searching for Files: Using the find Command,” page 182.

The basic pattern is:

find -name STRING -print \| cpio -p OPTIONS > TARGET.

In this example:

+   \u25ba The -name option for find lets you search for a string enclosed in double quotation marks. Metacharacters can be used. See “Using Metacharacters or Wild Cards,” page 86.
