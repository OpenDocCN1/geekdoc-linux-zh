Similarly, “right click” means to use the right mouse button, while, “middle click” means to use the middle mouse button or the equivalent.

+   Information to type appears in a sans serif text, like this: chmod 777 todo.txt. Punctuation after this text should not be typed.

+   Small capitals in sans serif text indicate variable information. For example, the standard format for a command is:
+   **COMMAND OPTIONS ARGUMENT FILES**
+   
+   The small capitals in gray indicate that any command can replace the word “command,” any options the word “options,” and so on.

# Note

Whenever files are a variable, you can also use a directory name.

# Note

Variable information often includes **SOURCE** and **TARGET**. The source is the file that original information is taken from. The target is the file that is acted upon.

For example, when a file is copied, the source is the file being copied, and the target is the new copy that is created.
