# Viewing Files with Scrolling: Using the less Command

The less command is the most common tool for viewing files from the command line. In this category, it replaces cat and more, offering more options than either.

The less command displays the designated file one screen at a time. In addition to displaying files, less can also be used for simple searches. However, for most searches, you probably want to use one of the search commands. see “Searching from the Desktop,” page 175 and “Searching From the Command Line,” page 182.
