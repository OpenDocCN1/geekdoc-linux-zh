# Using the System Information Tool

The System Info tool is the graphical equivalent of the uname -a and w commands.

+   1. From the main menu, select Applications > System > System Info. The System Info window opens.

![](bbox=[0.19, 0.28, 0.71, 0.63])

+   2. If you want to save the information select either:

+   Save Information to File.

+   Email Information.

A dialogue box opens for you to select or enter a file name or e-mail address.

+   3. Select either a file or e-mail address.
