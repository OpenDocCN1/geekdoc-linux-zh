# ## Choosing a Secure Password

A secure password is one that is hard to crack. That is, it is:

+   - A mixture of letters, numbers, symbols, and of upper and lower case.
+   - At least six characters long.
+   - Not based on anything associated with you, such as a birthday, a spouse's name, a pet, or a favorite sports team or movie.
+   - Not a common word found in a dictionary.
+   - Different from your passwords on other machines.
+   - Different to your user account.
+   - Not written down anywhere.

# ## Setting the Root Password

The root user has full access to the system. Ordinarily, the root account is used only for administration and configuration. See “Starting and Stopping the System and Graphical Interface,” page 99.

+   1. Enter the password for the root user (The user account for the root user is “root”). See “Configuring Password Levels,” page 75.
+   2. Re-enter the password to confirm it.

> > **Note**
> >
> > Unless the two passwords match, you receive a warning before you move to the next screen.

# ## Creating a Regular User Account

A regular user account has limited access to the system. Even if you know the root password, ordinarily you do most of your work in a regular user account. See “Starting and Stopping the System and Graphical Interface,” page 99.
