# **Note**

Currently, you cannot resize a partition or change its type during an install. Instead, delete the partition then create new ones.

Remember that deleting a partition destroys all information on it.

To create or edit a partition:

+   1. Select a partition to edit or a block of free space in which to create a partition from the **Edit Partition** screen. Your selection is highlighted.
