Another trick is to set an alias, so that typing `list` results in `ls -- color`, which prints files in different colors, depending on what kind they are. See “Creating an Alias,” page 126.

# # The `ls` Command (List)

| Option | Action | Comments |
| :--- | :--- | :--- |
| `-a` | Includes hidden files in the list. | Most hidden files start with a period. |
| - `--color`<br>- `--colour` | Displays types of files in color. | |
| - `-f`<br>- `--classify` | Displays types of files using symbols. | Common symbols are:<br>- `/`: Directories.<br>- `*`: Executable files.<br>- `@`: Symbolic links. |
| `--full-time` | Prints complete file attributes. | |
| - `-l`<br>- `format=long` | Displays file attributes. | |
| - `-L`<br>- `--dereference` | Lists the files referenced by symbolic links instead of the links themselves. | See “Working With Symbolic Links,” page 218. |
