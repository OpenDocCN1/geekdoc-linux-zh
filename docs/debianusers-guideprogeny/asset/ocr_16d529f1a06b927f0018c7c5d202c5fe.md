# ## Viewing Attributes Set by the chattr Command

*Type: Isattr OPTIONS files.*

Files are displayed one line at a time.

# ## Options for the Isattr Command (List Attributes)

| Option | Action | Comments |
| :--- | :--- | :--- |
| -a | Lists all files in the directories listed. | |
| -d | Lists directories’ attributes, instead of files’. | |
| -R | Changes sub-directories and their contents. | |
