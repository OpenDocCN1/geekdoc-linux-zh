# ## Filters for procmail

| Filter | What It Does |
| :0:<br>^From: ADDRESS<br>DIRECTORY | Sends a message from the e-mail address to the specified directory. |
| :0:<br>^Subject:.*KEYWORD<br>DIRECTORY | Sends a message whose subject contains the keyword to the specified directory. |

# ## Configuring the Graphical Display

The graphical display in Linux is controlled by the X Window System. You can configure the basic settings for the display through Progeny Debian’s desktop tools, or by editing /etc/X11/XF86Config-4 in a text editor. You can change the look of the display by changing desktops or window-managers.

+   This section discusses:
+   
+   - Configuring a video card.
+   - Configuring a monitor.
+   - Configuring the graphical display (screen color depth and resolution)
+   - Configuring a pointer
+   - Changing desktops.
+   - Changing window managers.
