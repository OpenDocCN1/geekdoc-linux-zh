# Warning

Closing a process can crash your system or cause other problems.

# The killall Command (Stops Processes)

| Option | Action | Comment |
| :--- | :--- | :--- |
| -e | Stops only processes that are an exact match of what you enter. | If this option is not used, all processes are killed that match the first 15 characters. |
| -g | Stops all parent processes as well. | |
| -i | Enters a confirmation before each process is stopped. | |
| -v | Displays progress on-screen. | |
