# Starting an Automated Install

1. Check that you have an install source. The install source can be:

+   - A CD.
+   - A CD image available over an NFS-mounted CD image.
+   - An URL. In this case, sources.lst must point to a valid Progeny mirror.

Whatever the source, it must be specified in the global.cfg file.

2. Place the automated install floppy in the floppy drive.

3. Start the machine.
