+   4. Remove the Progeny Debian upgrade package. Type: `dpkg --remove progeny-slink-upgrade`.

+   5. Restart your system. This step is recommended, but optional.

# Upgrading from Debian 2.2 With Ximian (Helix) GNOME

Ximian GNOME (formerly known as Helix) is a customized version of the GNOME desktop. It may be installed over an existing Debian version, most likely Debian 2.2. It is also a standard part of the Storm hail release and the latest releases of Libranet.

![](bbox=[0.21, 0.34, 0.27, 0.38])

# Note

> Due to the timing of releases, systems using earlier versions of Debian with Ximian GNOME are uncommon.

+   1. Add the following line at the top of the `/etc/apt/sources.list` file: `deb http://archive.progeny.com/progeny stable main contrib non-free`.

+   2. Remove Ximian’s customized packages. Enter the following series of commands:
+       a. `apt-get remove mc-common`.
+       b. `apt-get remove libpopl0`.
+       c. `apt-get remove libgtk1.2`.
+       d. `apt-get remove gnome-games-locale`.

+   3. Repeat the following command until all package dependencies have been satisfied: `apt-get -f dist-upgrade`.

+   4. Install the Progeny Debian 2.2 upgrade package. Type: `apt-get install task-progeny-potato-upgrade`.
