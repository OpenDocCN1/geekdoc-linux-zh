# Column Settings in /etc/fstab (Mounting Filesystems)

| Column | Contents | Choices |
|:---|:---|:---|
| 3 | The filesystem’s format.\n\nSupport for the format must be enabled in the kernel. | **Predefined choices are**\n\n- ext2: The native Linux format.\n\n- sw: Linux swap file. Use only for the swap file.\n\n- vfat: FAT32. The format of Windows 98, ME, and the second release of Windows 95.\n\n- iso9660: CDs.\n\n- nfs: network file system.\n\nYou can recompile the kernel to support other file systems.\n\nNetwork filesystems and several journalistic filesystems are also supported. |
