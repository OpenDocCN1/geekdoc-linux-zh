# The parted Command (Partitioning): Commands

| Command | Action |
| :--- | :--- |
| **mkfs** *PARTITION* *FILESYSTEM* | Creates a partition. |
|  | Values for the *fileSystem* are: |
|  | ▼ **ext2**: The native Linux *filesystem*. |
|  | ▼ **linux-swap**: The Linux swap *filesystem*. |
|  | ▼ **fat**: FAT32, the Windows *filesystem*. |
|  | These values are different from the ones used in mounting and unmounting *filesystems*. |
|  |  |
|  |  |
| **mkpart** *FILESYSTEM* *TYPE* *START* *END* | Creates a partition. |
|  | Values for the *fileSystem* are: |
|  | ▼ **ext2**: The native Linux *filesystem*. |
|  | ▼ **linux-swap**: The Linux swap *filesystem*. |
|  | ▼ **fat**: FAT32, the Windows *filesystem*. |
|  | These values are different from the ones used in mounting and unmounting *filesystems*. |
|  | Values for the *type* are **logical** or **extended**. |
|  | The *start* and *end* values are in megabytes-measured from the start of the partition. |
|  |  |
|  |  |
| **resize** *PARTITION* *START* *END* | Resizes the partition. |
|  | The *start* and *end* values are in megabytes-measured from the start of the partition. |
|  |  |
