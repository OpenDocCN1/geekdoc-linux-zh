# Software Package Sets

| Package | CD | Use |
| :--- | :--- | :--- |
| FTP server | Install | Makes the system an FTP server. |
| GNOME applications | Install | Productivity applications, such as a word processor and spreadsheet. A default selection. |
| GNOME desktop system | Install | The default Progeny Debian desktop. A default selection. |
| GNU emacs | Install | The GNU emacs editor. |
| Games | Extras | A collection of games. |
| KDE Office | Extras | Productivity applications for the KDE desktop, such as a word processor and a spreadsheet. |
| KDE Desktop | Extras | An alternate desktop. |
| KDE Desktop system (Development files) | Extras | Files needed to develop programs for the KDE desktop. |
| Linux 2.2 SMP | Install | Linux kernel compiled for multi-processor support. |
