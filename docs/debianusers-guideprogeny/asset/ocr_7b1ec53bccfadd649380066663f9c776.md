# **Columns in Standard Log Files**

| Column | Information |
| :--- | :--- |
| Name | The subsystem that generated the message. The subsystem can be the kernel or a process. If the subsystem is a process, then its ID is included. |
| Message | What the log entry is about. |

# **Reading Non-Standard Log Files**

Several useful log files are not in standard format. As a result, they cannot be read by the System log monitor tool on the desktop. Several must be read using unique command line tools.

# **Non-Standard Log Files**

| File | What It Contains and How to View It |
| :--- | :--- |
| dmesg | Contains information about the most recent starting of the system. View by using the dmesg command. |
| faillog | Contains information about the last time users tried to log in, including the number of failures, the maximum allowed, and the latest failure. View by typing: faillog -u USER. |
