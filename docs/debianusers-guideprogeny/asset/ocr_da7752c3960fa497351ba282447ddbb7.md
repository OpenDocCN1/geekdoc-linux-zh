# The useradd Command (Sets Up New User)

| Option | Action | Comments |
| --- | --- | --- |
| -d DIRECTORY | Adds a home directory that: <br> ▼ Does not have the same name as the user name. <br> and/or <br> ▼ Is not a sub-directory of /home. | If you do not want a home directory with these features, use the -m option. <br> If -d or -m is not used, then no home directory is created. |
| -e DATE | Adds an expiry date for the user account |  |
| -G GROUPS | Adds groups in addition to the default one. | Enter multiple groups by name or group ID (GID). <br> Separate the names with a comma and leave no blank spaces. |
| -k DIRECTORY | Copies default files to the user’s home directory. | Use with the -m or -d option. <br> By default, files are copied from /etc/skel. |
