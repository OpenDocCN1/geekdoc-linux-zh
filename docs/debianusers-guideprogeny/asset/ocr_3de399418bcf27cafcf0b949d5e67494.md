The following table shows the directories where certain types of files are likely to be located. This structure is very similar in all Linux distributions, although small differences exist.

# # The Linux Directory Structure

| Directory | What's in It |
| :--- | :--- |
| / | The root directory. Contains all other files and directories. |
| | The complete or absolute path to other directories starts from the root directory. |
| /bin | Binary or executable files that can be used by both the root user and normal user. |
| | Look in other /bin directories for other executable files. |
| /boot | Files needed to start Linux, including the kernel. Most files in /boot generally cannot be configured using a text editor. |
| /cdrom | The usual mount point for the CD drive. If the system has a second CD drive, its mount point is usually /cdrom2. |
| /dev | Definitions for drives, partitions, and other devices. /dev also includes the makedev tool to create new devices. |
