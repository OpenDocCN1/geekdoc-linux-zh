Entries consist of a series of settings. Below each entry is a list of resolutions and color depths that can be used with the video card. See “Setting Display Settings Manually,” page 404.

# ### Video Card Settings

| Setting | Comments |
|---|---|
| Identifier | The label for the video card profile. |
| Device | The card's manufacturer and model. |
| Monitor | The monitor profile used with the card, placed in double quotation marks. |
| Default Depth | The color depth used by preference. |
