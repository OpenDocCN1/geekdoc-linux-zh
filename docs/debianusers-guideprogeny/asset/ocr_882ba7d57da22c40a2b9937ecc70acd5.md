# Keyboard Shortcuts for the top Command

| Press... | To... |
| :----- | :----- |
| c | Toggle the display of the command name or full command line. |
| f | Select fields to display. |
| k | Open a prompt to enter a process id to kill and send a signal to kill it. Unless you are the root user, you can only kill processes you started. |
| l | Toggle the display of load average and uptime information. |
| m | Toggle the display of memory information. |
| M | Sort by the use of resident memory. |
| N | Sort by process id. |
| n NUMBER | Set the number of processes to show. Selecting 0 displays a screenful. |
| q | Exit the display. |
| r | Set priority, as with the nice command. See “Setting the Priority for a Process From the Command Line,” page 319. |
