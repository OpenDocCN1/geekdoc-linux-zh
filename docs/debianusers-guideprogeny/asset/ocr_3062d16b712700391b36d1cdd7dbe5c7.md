# Installation Targets for Progeny Debian

| Advantages | Disadvantages |
| :--- | :--- |
| **Free Space** |  |
| ▼ Information is not destroyed. | ▼ The hard drive must have enough continuous space for the necessary partitions. |
| ▼ Existing partitions are kept. |  |
| ▼ You do not need any special knowledge. | ▼ You lack full control of the process. |
| ▼ It's quick. | ▼ The partitions created may be smaller than you want or need. |
| **Custom** |  |
| ▼ You fully control the process. | ▼ You must understand what you are doing. |
| ▼ You decide whether to keep existing partitions. |  |
| ▼ You can put major directories such as /home or /usr on different partitions. | ▼ You could destroy information by accident. |
