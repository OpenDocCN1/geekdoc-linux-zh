# # Configuring a Pointer from the Desktop

![](bbox=[0.15, 0.09, 0.75, 0.42])

The pointer is usually a mouse. However, it can also be a trackball, a palette, or any other device that replaces a mouse.

If you have been using the mouse during the install, you can accept the settings listed. However, if your mouse is not working, you can adjust the settings.

+   1.  Select Systems > X Configuration from the GNOME Control Center.

> > **Note**
> >
> > If you are using the KDE desktop, type /usr/bin/
> > xserver-conflict-capplet at a command line.

+   2.  From the X Configuration pane, select the Pointer tab.
+   3.  Select the port to use.
+       *   In most cases, it is /dev/ttyS0 (COM1) or /dev/ttyS1 (COM2) for a serial mouse, or /dev/psaux for a Ps2 mouse.
+   4.  Select the protocol or driver to use.
