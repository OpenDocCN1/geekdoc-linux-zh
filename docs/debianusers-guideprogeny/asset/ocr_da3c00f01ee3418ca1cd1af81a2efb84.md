# Note

Use the *root* account only for configuration or administration work.

+   Type the password for your user account.

If you have changed any options since the last time you logged in, a *dialogue window* displays. Select the *Yes* button to make the new options the default.

If you type an account name and password that are entered into the system, then the *desktop* starts.

If the account name or password are *incorrect*, you return to the *login window*.

# Logging in from a Command Line

You can log in from a command line if you configure *Progeny Debian* not to start the *graphical* interface automatically.

You can also start *Progeny Debian* in *single-user mode*, which does not include the *graphical* interface. If you press Ctrl-D from the *log prompt* in *single-user mode*, the *graphical* interface starts.

+   At the login *prompt*, type your user account name and press the Enter key. The *password prompt* displays.
