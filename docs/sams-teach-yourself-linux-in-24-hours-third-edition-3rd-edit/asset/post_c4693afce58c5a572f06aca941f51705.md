## Q&A

Q The display isn't centered on the monitor correctly. A black line runs along one edge of the screen and part of the desktop is hidden on the other side. How can I adjust this?

A The first thing that you should do is adjust the position controls on the monitor. Most monitors have buttons on the front that enable you to change the size of the picture or to move the picture right, left, up, and down. If that doesn't work, try xvidtune. This program can move the display around on the screen. To use xvidtune, open a terminal emulator, type xvidtune, and press Enter. Read the warning message and click OK. Click the Auto button. You can then move the display up, down, left, or right. You can also make it wider, narrower, shorter, or taller.

Q The mouse doesn't work right. What did I do wrong?

A Most likely, you selected the wrong mouse protocol in the xf86config program. You might want to go back and select a different mouse.

## Quiz

- 1. What type of information will you find in the /etc/X11/XF86Config file?
- The most important information is that which pertains to the video display—the monitor specifications and type, the video card, the keyboard type, and the mouse protocol. Other information found in this configuration file is the location of color palettes and font libraries.
- 
- 2. What system information do you need before you can correctly configure the X Window System?
- You'll need to know the keyboard type, the language, and number of keys. For the mouse, you'll need to know the mouse protocol and the number of buttons. For the monitor, you'll need the manufacturer and model number, the maximum resolution, vertical refresh rate, and the horizontal refresh rate. For the video card, you'll need the manufacturer and model, the type of graphics card and chipset, amount of video memory, and the supported color depths.
- 
- 3. If you have problems configuring the X Window System for your computer, what resources should you look up before you attempt to run the xf86config program?
- There is quite a bit of information stored in the Linux filesystem. Look in the /usr/X11R6/lib/X11 directory. In there you'll find a list of compatible monitors (the MonitorsDB file) and video cards (the CardNames files). In the /usr/X11R6/lib/X11/doc directory, there is a quick start guide that you should read before you begin the configuration process. This directory also contains readme files for the different supported video cards. There are also readme files for mouse and other pointing devices.

4. If your system boots to a text-only console, how do you start the X Window System?

After you log in, type startx at the shell prompt. This will start the default desktop environment, which can be either KDE or GNOME (depending on the distribution). If you do not get a desktop environment, press Ctrl+Alt+Backspace to return to the text-only console. You should then log in to the root account and run xf86config to adjust the video display.

5. What is the easiest way to change screen resolution and color depth?

To shuffle through the available resolutions and color depths, press Ctrl+Alt and the + key or the – key on the number keypad. You might also find an easy-to-use tool bundled with your favorite Linux distribution. In Linux-Mandrake, open DrakConf and run the Xdrakres utility.

## Installing a Window Manager

A window manager is not absolutely necessary. It is quite possible to run X Window applications without a window manager, but it’s a pretty limited show. Window managers are software applications that manage the appearance and placement of windows on your screen. Window managers draw the window borders and decorations, and they provide the scrollbars and bells and whistles. The X server is actually responsible for drawing everything on the screen, but window managers give the desktop a particular look and feel and many provide a method for launching applications.

In this hour, you will

- Learn about the different window managers that are available on your system
- Change the window manager for your graphical desktop
- Find more information about what you can do with the X Window System

## Choosing a Window Manager

At this time, there are two main graphical interface desktops for Linux—GNOME and KDE. These are not window managers but are GUI desktop system applications that can be run with varied success on different window managers. KDE has its own window manager, a very good one, called kwm. The GNOME desktop runs best on the Enlightenment window manager. These desktop systems are both very feature rich, with drag and drop, automatic window focus, and a very large collection of their own applets, tools, utilities, and toys. Unfortunately, both of them are also big resource users. The Linux distributions from Red Hat, SuSE, TurboLinux, Linux-Mandrake, and some others provide both GNOME and KDE. The Debian distribution supplies only GNOME.

![](img/782ecfdc0b083a767896cc983e10427f_299_0.png)

> For more information about the KDE and GNOME desktop environments and how to use them, see Appendix A, “Getting Started with the KDE Desktop Environment,” and Appendix B, “Introducing GNOME and LinuxConf.”

Your personal choice of a window manager will be governed by your needs and preferences. There are window managers that are better suited for particular tasks, or even for particular tastes. Some are better choices for different setups, whereas others are more compatible with one desktop environment (such as GNOME or KDE) or another. Here is a short list that includes brief descriptions of a few of the dozens of choices:

- The fvwm window manager is a basic window manager that enables you to launch programs from a menu that pops up when you click a blank spot on the desktop. It also has a customizable button bar called GoodStuff. It’s a good choice for systems lacking much CPU power or memory because it is small and fast.
- The fvwm2 window manager is an improved version of fvwm that has been popular with Linux users for a long time. It has all the features of fvwm, plus some nice new additions. It is a good choice if you don’t want to run GNOME or KDE.
- The fvwm95 window manager is an updated version of fvwm that is configured to look like Microsoft Windows 95. The fvwm95 window manager provides a familiar look and feel for people switching over from the Microsoft Windows operating system. It also has the GoodStuff button bar.
- AfterStep is based on the NeXT operating system’s NeXTStep desktop. AfterStep is a good window manager for those who want flashy graphics or sound. AfterStep is also easier to configure than some of the other window managers.
