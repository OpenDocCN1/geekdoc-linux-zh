An easy way to keep track of the songs on a music CD is to download the information from one of the CD databases. Here's how to keep track of your CD playlist with the GNOME CD player:

- 1. Start the GNOME CD player and pop your favorite music CD into the CD-ROM drive.
- 2. Change the player preferences. Click the Preferences button to display the preferences dialog box and the CDDB tab shown in Figure 24.3. Make sure that there is an address for one of the CDDB servers listed in the Address text box. If you do not want to use the default CDDB server, type in your favorite CDDB server address.
- 3. Connect to the Internet.
- 4. Download the CD database information. Click the Open Track Editor button to display the Disk Information panel. Then click the CDDB Status button to open the Status panel. In the Status panel, click the Get CDDB Now button. The information downloads and appears in the Disc Information panel and in the LED display of the CD player.
- 5. Start playing songs. You can double-click a song in the track editor or you can press the Play button on the CD player.

## Task: Capturing Screen Images

You might be wondering how all the screen images that you've seen throughout this book came into being. Several applications can be used to take a snapshot of your desktop or of just a single window on the desktop. Here's how to use KSnapshot to take a picture of your desktop:

- 1. Open KSnapshot. You might find the program in the menu system of your favorite desktop environment, or you can type `ksnapshot` at the command line. The KSnapshot program appears in Figure 24.9. When KSnapshot opens, it captures the screen and displays it in the Preview pane.
- 2. Name the screen capture file. Type a filename in the Filename text box. You can change the directory in which the file is stored by clicking the Browse button.
- 3. Select an image format. Click the down arrow under the Filename text box and select a file format for the captured image.
- 4. Set the capture delay. You might want KSnapshot to wait a few seconds before it captures the screen: for example, perhaps you need to open a menu so that it can also be captured. Type the number of seconds you want KSnapshot to wait before it takes a picture of the desktop.

- 5. Start the screen capture. Click the Grab button and make any required changes to the desktop. KSnapshot goes away for a few seconds, and when it reappears, the captured desktop appears in the Preview pane.

## Q&A

Q Some of the applications that were previewed in this hour aren't installed on my computer. What should I do?

A Chances are good that these applications are on the CD-ROM for the Linux distribution that you installed. Turn to Hour 15, "Installing Software," to learn how to install the needed files from the distribution CD-ROM.

Q I have a collection of MP3 music files. Are there any MP3 players for Linux?

A You'll find several MP3 players for Linux. The most popular is the X Multimedia System (also known as xmms). The xmms player contains a graphical equalizer, a playlist, and a wide selection of skins that change the look of the player. You may also want to try the KMP3 player and eMusic.

Q Can I use image files that I created using a program for the Windows operating system in a Linux program?

A You most certainly can. The graphics programs found in Linux support all the popular image file formats (and even most of the unpopular formats). The most versatile program is The Gimp, which will do almost anything you need from a graphics program.

Q What if I don't have any image files? Where can I find some?

A There are many places to find images. If you're connected to the Internet, do a search for free Web graphics. There's also quite a collection of images stored in the system. Navigate to the /usr/share directory and look for icons, pixmaps (the Linux version of a bitmap image), backgrounds, and other images.
