# Installing the X Window System

Linux uses an external application to provide multimedia services. This is much different than the systems that control the video and audio through a part of the operating system software. The X Window System could be called Windows for UNIX. It does all the same things that Windows does, such as controlling the launching and management of graphical applications in separate windows on your computer screen. But the X Window System actually does much more than that, as you will see. The X Window System provides the means to control the video display and multimedia devices on your Linux box through an application called an X server.

In this hour, you will

+   - Learn how the X Window System works
+   - Prepare before configuring the display
+   - Configure the video display so that X works on your system
+   - Change the video resolution and color depth on-the-fly
