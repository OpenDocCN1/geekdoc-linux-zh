## Understanding Absolute and Relative Filenames

When you type `ls` to list the contents of a directory, only the contents of the working directory display. If you search for a file, and you only specify a filename, Linux will only look in the current directory for the file. If you want to work with a file that is not located in the working directory, you must specify the directory where the file is located and the name of the file.

The method used to move to a different directory in the filesystem is the `cd` command. To change to a different directory, type `cd` followed by the directory path. If the home directory is the working directory (for example, `/home/rusty`) and you want to go to `/home/rusty/letters/chainmail/Feb`, type `cd letters/chainmail/Feb` and press Enter. There is no need to type the entire directory path because the directory you want is relative to the working directory. However, if you want to go to the `/usr/doc` directory to see the help files for programs installed on the system, you would need to type `cd /usr/doc` and press Enter. You use the absolute filename because the `/usr/doc` directory is not in the path of the working directory.

**New Term** There are two types of Linux filenames—absolute and relative filenames. An *absolute filename* begins with the slash (`/`) character indicating the root of the filesystem, followed by the complete directory path to a file. Every file on the system has an absolute filename and the absolute filename can be used from any location in the filesystem. The *relative filename* refers to a file's location beginning from the working directory. The relative filename does not begin with a slash character.

## Deleting Directories

The `rmdir` command is used to remove directories. Before you can delete a directory, you must first delete the contents of the directory. This means that any files contained in the directory need to be removed with the `rm` command (discussed later in this hour), and subdirectories need to be emptied and then deleted with the `rmdir` command.

![](img/782ecfdc0b083a767896cc983e10427f_142_1.png)

> While you are learning to drive your new operating system, you might want to limit the directories you delete to those you have created within your user account.

## The Syntax for the rmdir Command

When you want to delete a directory, the working directory must be the parent directory of the directory to be deleted. Also, if there are any files in the directory to be deleted. The files must be removed first. The following shows the syntax for the rmdir command:

```
rmdir directory
```

The directory parameter is the name of the directory to be deleted. If the directory is not empty, a message displays:

```
rmdir: <directory>: Directory not empty
```

This warning message lets you know that you need to manually delete the contents of the directory. The command does not remove the directory or any of the files contained in the directory if the directory to be deleted is not empty.

## Working with Files

A file is probably the most basic piece of electronic information with which you'll work on the system. Files hold data that you create when you use an application, such as a graphic image, a word processing document, a Web page, or a database. Each file that you create has a distinct name and can be stored in one of many directories on the system. The most likely place that you'll store files will be in your home directory.

After you have saved a file on the system, you can perform a variety of tasks with the file. You can update the file by opening it in an application and making changes to the information. Files can be moved from directory to directory to better organize your information. You can also keep copies of a file in several directories if you need a file for different purposes.

## Creating Files

If you want to read the contents of a file quickly, use the cat command. The cat command can read one or more files at a time, or it can be used to combine the contents of two files into one file. It will even create a new file. And... all this comes to you right from the command line. Pretty slick, huh?

Before you ask cat to display a file, you'll need to change to the directory that contains the file. Remember, the cd command moves you from directory to directory. When you execute the cat command (type cat filename and press Enter), the file quickly rolls along on the screen.

Here are some other cool tricks that you can teach the cat:

- When you need to combine the contents of several files into one new file, tell cat which files to combine and in what order, and the name of the new file. The rest can be left to cat. For example, user rusty collects jokes. Each joke is placed in a separate file and occasionally rusty picks a few good jokes to share with friends. This week, rusty wants to send the joke files named joke27 and joke53 to some pals. To combine these two files into a third file named grins1, type `cat joke27 joke53 > grins1` and press Enter.
- To add the contents of one file to the end of another file, tell cat to append the file. If rusty has a file named guffaws1 that some friends would enjoy, but also wants to also share joke27, rusty would use cat to copy the contents of joke27 and then paste the contents to the end of the file named guffaws1. To append the file, type `cat joke27 >> guffaws1` and press Enter.
- The cat command can also be used to create a blank file. User rusty wants to put together a collection of the best jokes of the year. To create a new file named best2000, type `cat > best2000` and press Ctrl+D. Now, with a new, blank file, rusty can search the joke collection and use cat to append the best of the best to the end of the best2000 file.

## Task: Displaying File Information with the stat Command

Earlier in the hour, you saw how the `ls -l` command displayed quite a bit of information about a file. Another way to display file information, but this time for an individual file, is with the stat command. The stat command can also display this same information for a directory. Here's how to use the stat command:

- 1. Change to the directory that contains the file about which you want more information.
- 2. Display the file list for the directory (use the `ls` command) and locate the file.
- 3. Type `stat filename` and press Enter. A sample output of the stat command is found in Listing 7.3. If you receive the Can't stat file error message, it means that the file does not exist.
