# 3. How do you restrict access to the system and to the data on the system?

Access to the system is controlled by user accounts and passwords. Each user who is authorized to work on the system should be assigned a separate account and asked to select an appropriate password. After user access has been set, access to files needs to be set. Each user may have different permissions to use files, depending on his needs.

# Exercises

+   1. To help maintain your computer system, add a few new sections to your Linux diary. The Linux diary should contain a detailed description of each computer. You will need to record information about components that have been added to or removed from the system, backup and recovery procedures, maintenance tasks and schedules, and configuration changes (such as added components, memory, and other upgrades). After you have an equipment inventory in place, you can refer to it in the event that something is found to be missing. This diary also provides an unbeatable tool for keeping control of aging equipment, scheduling new upgrades, maintaining the system, and replacing worn parts.
