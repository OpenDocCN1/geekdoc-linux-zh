# Setting Up the Filesystems

Now it's time to setup the hard drive (or the partition on the hard drive) in which you want the Linux operating system to live. It is recommended that you set up four partitions for the Linux filesystem: a boot partition, a root partition, a swap partition, and a home partition.

> You can have Linux-Mandrake automatically create the different partitions you need by clicking the Autoallocate button.

Linux may be set up as the sole operating system installed on the machine or it may be installed and share the drive with others. A lot of older equipment can suffer under the load of trying to run modern versions of Windows with all the bells and whistles.

> **Selecting a Test System**
> We have an antique computer that we have been using for a number of years to practice riding the exciting, rocky GNU road. It's a Pentium 133, and as a Microsoft Windows machine, its usefulness had all but disappeared. It crashed constantly and the drive sounded like a washing machine. Two years ago, we installed GNU/Linux as its sole operating system and have only had to perform routine system maintenance to keep it running; it has purred like a kitten since. We use it daily as a test machine and as a workstation.

Listing 2.1 shows a sample filesystem set up using GNU/Linux as the sole operating system. The information displayed is for a computer that will be running only the Linux operating system, has a 16-gigabyte hard drive, and 192 megabytes of RAM.
