+   - Configure hardware and set up user accounts. During the installation, you have the opportunity to create a dialup connection to the Internet, set the system clock, configure a printer, and add user accounts. If you'd rather wait until you have more time and experience, you can skip the printer and dialup connection for now and add them at another time.
+   - Before you can use any of the many graphical user interfaces designed for GNU/Linux, you must install and configure the X Window System. The X Window System controls the video card, the monitor, and the monitor display (such as the screen resolution and color depth). This is the trickiest part of the installation, and it is important that you have your video card and monitor specifications handy.

# Partitioning Your Hard Drive

The Linux-Mandrake distribution in the back of this book and many of the other distributions have provisions in the installation program for partitioning the hard disk to make room for GNU/Linux. You can do this without damaging your Microsoft Windows installation or any of the data on the drive.

> Before you attempt to install any GNU/Linux distribution, or partition a hard drive, make sure you are prepared and that your computer is prepared. Learn as much as you can about this new operating system. If you would rather purchase a computer system with GNU/Linux already installed, visit the GNU Project Web site at www.gnu.org/links/companies.html.

> Fortunately or unfortunately, not all distributions are the same. The Slackware and Debian distributions do not have automated disk partitioning in their installation programs. If you are installing either of these distributions or another Linux distribution that isn't automated, you will have to partition the drive by hand (using a utility, of course).

If you are installing Linux on a Windows computer with only one hard drive and you want to be able to boot one operating system without involving the other one, you will have to make provisions to share the drive. There are several partitioning tools and methods from which you may choose.

> Prepare your hard drive before the installation whether you are creating a partition or not. Run ScanDisk and Disk Defragmenter from the Windows operating system before you begin.
