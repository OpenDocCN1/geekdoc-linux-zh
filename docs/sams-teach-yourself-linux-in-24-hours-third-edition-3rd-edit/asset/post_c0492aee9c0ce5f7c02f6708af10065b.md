## Using Windows on the Desktop

If you've opened several applications, you'll find windows of different sizes scattered around the desktop. With so many open windows, you need some way to organize them on the desktop to make it easier to do your work. The best way to find out how many different ways a window can be manipulated is to click the Window Menu button. It's usually found on the left side of the title bar. Many of these menu items—those that are used most often—have an associated icon on the title bar.

![](img/782ecfdc0b083a767896cc983e10427f_386_0.png)

> The buttons that appear on the right side of title bar can be moved to the left side of the title bar, and vice versa. Buttons can also be removed. This is done from the KDE Control Center (expand the Windows category to find the Buttons configuration module).

New Term Here's a trick for hiding a window when you aren't working with it—double-click the title bar. You'll see the bottom portion of the window "roll up" so that only the title bar remains on the desktop. When you want to work with the window, double-click on the title bar to see the window "unroll." This cool technique is called shading.

The safest method to close a window is to first save any information that you have entered, close the file in which you are working, and then select the Exit or Close command from the program's File menu. You can also use the Close button on the title bar, or use the Close command from the Window menu.

New Term When working with several windows at one time, you need to make a window active before it can accept any input. This process of switching from one window to another usually involves an extra mouse click, and can be cumbersome at times. The process that controls how a window is made active is called focus policy.

## Juggling Multiple Windows

If you want to change the method used to make a window active, open the KDE Control Center, expand the Windows category, and select the Properties configuration module. At the bottom of the module box, you'll find the focus policy options. Here are a few ways you can change the way a window becomes active:

- To click inside a window to make it the active window, select the Click to focus option.

- The Focus follows mouse option activates a window when the mouse is placed over the window. If the mouse is moved off a window and placed over the desktop, the window remains active until the mouse is placed over another window.

- When you only want a window to stay active while the mouse is placed over it, choose the Classic focus follows mouse option. When the mouse is placed over the desktop, no windows are active.

- If you want to combine the Focus follows mouse policy with a quick keyboard shortcut, try the Classic sloppy focus option. When using the Classic sloppy focus policy, press Alt+Tab to move between windows.

> You can control how windows are positioned on the desktop when opened. Several options are available from the Placement policy list. The Cascade option gives the desktop a neat and tidy appearance. With this option, a new window covers up a previously opened window except for the title bar. This gives the windows a stair-step appearance.

A quick way to keep your life simple when dealing with a number of open windows on your desktop is to let KDE clean up your desktop. When you're not sure whether windows are hidden under other windows, right-click the desktop and select Cascade Windows. All the open windows will be arranged in a stacked formation so that the title bar for each window is visible.

## Cruising Around the Desktop

After you have a feel for moving around the desktop, you might want to make some changes so that the desktop is more useful and attractive. If you work with several applications at one time, Linux is a good choice because of its multitasking capabilities. You can compose letters, design a company newsletter, keep scheduled appointments, and surf the Internet all at the same time. If you use this many applications, you'll need a method to keep your desktop organized.

**NEW TERM** In the middle of the panel, you'll find four buttons labeled One, Two, Three, and Four. These buttons move you among the virtual desktops. The virtual desktops are similar to having four monitors sitting on your desk. By clicking a virtual desktop button, a completely different desktop appears on your screen.

To add some spice to an otherwise bland computer experience, change the appearance of the desktop and other screen elements. The desktop background can be filled by any image of your choosing. When you are away from your desk, give others a chance to view some moving art by setting a screensaver.
