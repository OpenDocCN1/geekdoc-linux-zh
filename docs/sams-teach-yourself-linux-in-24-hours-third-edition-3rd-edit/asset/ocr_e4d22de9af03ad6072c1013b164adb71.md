quite a few problems and your favorite programs might not work if they are dependent on the library you uninstalled.

When you use rpm to install and uninstall programs, the rpm command checks for dependencies. If you uninstall a package upon which other packages depend, you'll see a message such as the following:

```
[root@localhost /root]# rpm -e libc-5.3.12
error: removing these packages would break dependencies:
libc.so.5 is needed by mswordview-0.5.14b6w-2mdk
```

The system will return only the error message: it will not uninstall the package. The error message does tell you which application or applications (in this case, mswordview) depend on the package that you just tried to remove.

![](bbox=[0.2, 0.52, 0.27, 0.6])

> A good rule of thumb about removing packages is that if other programs are dependent on a package, don't remove it!

You might also find that when you are installing packages, another package (or library) is needed before you can install the desired program. If you try to install a package that needs a certain library so that it can operate, and that library is not located on the system, you'll receive a failed dependencies warning along with the name of the missing library. You'll need to find the library and install it first. After the needed library is installed, you can install the package, this time with success.
