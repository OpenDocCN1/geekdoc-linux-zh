# Customizing the Desktop

A little cosmetic surgery can go a long way in making the desktop more attractive. For a little spice, change the background image and add a screensaver. You can change the desktop background to a different color, a combination of colors, a pattern, or a picture. Then, to hide your work when the computer is not in use, select from one of the many screensavers for the X Window System. The appearance of the window borders can also be changed by selecting one of the many themes. These themes can also be customized to fit your taste.

When you're ready for a face lift, open the Gnome Control Center and check into one of the configuration modules. To find the Gnome Control Center, open the Main menu and select Programs, Gnome, Settings, Gnome Control Center.
