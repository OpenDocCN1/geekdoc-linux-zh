# The BSD Games Collections

Now that you've seen a few games with a graphical front end, it's time to look at a few console games. Console games are intended to run on a text-only screen—without the fancy graphics and video. The majority of these console games are found in the BSD games collection.

![](bbox=[0.22, 0.36, 0.27, 0.45])

> You won't find the BSD games in every Linux distribution. Most likely, you'll find the BSD games in the Slackware and Debian distributions. The BSD games are stored in the /usr/games directory. If you can't find these games on your system, you can get them from MetaLab Linux Archive at metalab.unc.edu/pub/Linux/games. If you would like an RPM file to download, search the pages at www.rpmfind.net.

Life is a crapshoot and you're rolling the dice. There are some very good dice and board games available in the BSD games for your sporting pleasure. You can play them with a friend or you can match wits with the computer. Some of the popular board games that you can try include cribbage, monopoly (shown in Figure 23.5), and backgammon. You'll even find a tutorial to help you learn backgammon: it's called teachgammon.

Five-card stud, hold two and roll your own, jacks or better to open! Poker, solitaire, Mile Bourne (shown in Figure 23.6), and other games that you can play with others on the network or, if not, the computer can fix it so that you can play with imaginary friends. Because many of the BSD games don't look like their board-bending, card-carrying cousins, you might need to read the manual pages for each game to help you figure out the rules.
