
## Q&A

Q How do I use the finger command to find people on the Internet?

A Fire up your Internet connection and get online, open a terminal emulator, and type finger followed by the email address of the person you seek.

Q Where can I find more information on setting up an email system on my Linux system?

A There are a few HOWTOs that you may want to start with. The Linux Mail User HOWTO provides a good introduction to electronic mail. You'll find information on many of the Linux mailers and how to get rid of spam. The Linux Electronic Mail Administrator HOWTO explains how electronic mail works on a network and the Internet, how to install and configure a mail transport agent, and how to manage the mail system. If you want to distribute mail to different users on the system, read the Linux Off-line Mailing Method mini-HOWTO.

## Quiz

- 1. What is the easiest way for new Linux users to start browsing the Web and sending email messages?

The Netscape Communicator suite is found on most Linux distribution CD-ROMs. For those who are moving to Linux from the Windows and Macintosh operating systems, Communicator for Linux has the same look and operates the same way. Communicator contains a full range of Web tools. You can browse the Web with Navigator, and keep track of your travels using bookmarks and the history list. Messenger manages mail and newsgroup messages. The address book helps you maintain email addresses for friends, relatives, and clients. Communicator also sports an HTML editor, Composer, to get your Web site up and running.

- 2. What information do you need to gather from your ISP before you can set up the mailer software?

You need to know your email address, the names of the ISP's incoming and outgoing mail servers, the mail protocol (either POP3 or IMAP), and the username and password you need to gain access to the mail server.

- 3. What are the two different methods that you can use to send and receive email? Which method should new Linux users choose to ensure a quick and successful email setup?

The new Linux user should try for the least complex method before diving into new territory. The quickest way to set up an email account in Linux is to use a mailer program that supports the POP3, IMAP, and SMTP protocols. These mailers can take care of the necessary communication with the ISP. The disadvantage to this method is that it is not very flexible.

The other method involves configuring a mailer, a mail transport agent, and a transport protocol. If you are running a network, you will need to use this method to deliver mail from the Internet, and from within your network, to each of the users on your network.

- 4. Which Internet tool should you use to download new application packages for your Linux system?

The most reliable file download method is FTP, or file transfer protocol. You'll find quite a number of FTP sites that contain gigabytes of Linux applications, tools, utilities, source code, and sample scripts. An FTP program such as gFTP enables you to select the files to download, the location to which you want to download the files, and then keeps the transfer going between your machine and the FTP server.

## Hour 23

## Playing Games

Time for recess! Way cool! You can finally have some fun and excitement. Linux has a vast assortment of games that offer great opportunities to lose yourself in pleasant distraction while wasting time and computing resources. In fact, this is one area where energy has been well spent in the Open Source movement. There are games that are designed to run on any computer using the X Window System. You'll find plenty of games installed with the GNOME and KDE desktop environments. There are also different game collections for different Linux distributions, even for different UNIX distributions. You'll find that quite a number of these wonderful little distractions are installed on your own Linux system. When you find yourself bored with the games already on your system, you can hunt for games on the Internet.

In this hour, you will:
- Find games in GNOME and KDE
- Explore the X Window System and BSD collections of games
- Play educational and strategy games
- Learn how to run DOS and Windows-compatible games on Linux

## Looking for Games in Too Many Places

Long ago and far away, somewhere in the deep dark past, you made a number of decisions about how to install Linux on your computer and what application packages to install along with the operating system. Somewhere in every installation is at least one collection of games. Games come from everywhere. You'll find a collection of games that perform entirely in the display of a text screen. Other games display pictures, motion, sound, and even provide an opponent, and are part of the X Window System and the various desktop environments.

## Accessing the KDE Games

Click the KDE Application Starter button and you'll find a whole menu of amusements right at the top of the list. The KDE games collection includes some of the same games that are in the GNOME and X Window System collections. Both GNOME and KDE have several versions of a mahjongg game (one version is shown in Figure 23.1), but the KDE version gives you the opportunity to select more than one option for the way that the game pieces are laid out. If you enjoy the Tetris arcade game, you'll find several versions from which to choose.
