# Finding a Few Good Applications

You might have already started exploring your system for new and interesting applications. If you are running the X Window System and using one of the desktop environments, you might have wandered through the menu system and selected applications from the different categories. Maybe you've used the apropos command to search for different types of programs. You might have searched the binary directories (the ones named /bin) to see the long lists of execution files.

> Another way to find out what is installed on your system is with a graphical tool that acts as a front end to the Red Hat Package Management System (RPM). These package managers show you what is installed on your system, and enable you to add and remove applications with just a few mouse clicks. You'll find several package managers as you tour the Linux world. The KDE desktop environment uses KPackage (shown in Figure 15.1) to manage applications. Linux-Mandrake has a similar version, called RpmDrake, which you'll learn how to use later in the hour. TurboLinux uses a proprietary configuration tool called TurboPkg (which uses a menu system) to update packages.
