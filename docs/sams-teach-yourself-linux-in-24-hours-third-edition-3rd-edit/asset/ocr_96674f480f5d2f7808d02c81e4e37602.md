# Understanding the Linux Operating System

Understanding any computer operating system may sound like a task with a steep learning curve. If you're not familiar with the UNIX operating system, Linux may be confusing at first. If that's the case, then it's time we cleared things up a little. A computer operating system can be described as a filing cabinet with a resident file clerk wizard. The Linux wizard is called the kernel. This kernel/wizard is a file clerk that operates a filing service—filing things away in order and retrieving them when they are required. For those jobs that require services that the kernel cannot perform on its own, it summons servers called daemons. But, enough with the metaphors…

In this hour, you will:

+   - Learn how the different parts of the Linux operating system work together
+   - Understand how files are arranged in the filesystem and how files are used in the operating system
