# Hour 15

# Installing Software

The fun part about Linux is all the software available under the GNU General Public License from the Free Software Foundation, and the freely available software for the X Window System. After all, what good is an operating system if you don’t have any applications to help you get your job done?

In this hour, you will

+   - Use RpmDrake to find installed applications on the system
+   - Uninstall applications with the rpm command
+   - Learn how Linux applications depend on a library system
+   - Find new applications and install them on the system
