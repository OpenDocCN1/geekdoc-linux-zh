# Task: Capturing Screen Images

You might be wondering how all the screen images that you've seen throughout this book came into being. Several applications can be used to take a snapshot of your desktop or of just a single window on the desktop. Here's how to use KSnapshot to take a picture of your desktop:

+   1. Open KSnapshot. You might find the program in the menu system of your favorite desktop environment, or you can type `ksnapshot` at the command line. The KSnapshot program appears in Figure 24.9. When KSnapshot opens, it captures the screen and displays it in the Preview pane.
+   2. Name the screen capture file. Type a filename in the Filename text box. You can change the directory in which the file is stored by clicking the Browse button.
+   3. Select an image format. Click the down arrow under the Filename text box and select a file format for the captured image.
+   4. Set the capture delay. You might want KSnapshot to wait a few seconds before it captures the screen: for example, perhaps you need to open a menu so that it can also be captured. Type the number of seconds you want KSnapshot to wait before it takes a picture of the desktop.
