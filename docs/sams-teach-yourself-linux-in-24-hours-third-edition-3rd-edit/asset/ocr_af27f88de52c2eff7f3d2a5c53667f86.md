3. Label the floppy. Type `mlabel a: 'description'` and press Enter. Where *description* is the text you want to appear as the label. For example, to call a floppy Testing, type `mlabel a: 'Testing'` and press Enter.

4. View the contents of the floppy. Type `mdir a:` and press Enter. You'll see the following:

```
[rusty@localhost rusty]$ mdir a:
Volume in drive A is Testing (abb=TESTING
Volume Serial Number is 1EC7-50FF
Directory for A:/

No files

1 457 664 bytes free
```

In this example, the label in step 3 is TESTING (shown on the line that reads, “Volume in drive A is Testing”). There are no files on the disk, and all 1.44MB are free.

5. Copy a file to the floppy. Change to the directory where the file you want to copy is located. To copy a file, type `mcopy filename a:` and press Enter. To see whether the file has been copied to the floppy, type `mdir a:` and press Enter.

6. Copy a file from the floppy to the GNU/Linux system. Change to the directory in which you want to store the file. Type `mcopy a:filename` and press Enter.
