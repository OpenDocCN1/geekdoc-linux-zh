3. If the command history list is longer than your screen, type history | less. This sends the command to the less pager and you can use the up- and down-arrow keys to scroll through the list. To exit the pager and return to the shell prompt, type q.

4. You might only want to see the last few commands that you've typed. To see the last 10 commands, type history 10 and press Enter.

# Understanding the Manual Pages

So far, you've been introduced to a few of the commands that you'll be using on your Linux system and you've seen how commands are structured. Now it's time to find out where you can locate more information about those commands and how to use them.

When you want information about a command, whether it's a description of a command or a list of command options, head to the Linux manual pages (also known as the man pages). A manual page is displayed on your screen (through a utility called a pager) when you use the man command to request information on a topic. The pager is used to read the contents of a manual page.

# The Syntax for the man Command

The manual pages are the system reference pages for the commands installed on the system. When the man command is executed, it searches through the manual page titles for the topic that you request. The following code shows the syntax for the man command:

```
man [options] [section] topic
```

Where:

+   - The topic parameter is normally the name of a command (also the title of the manual page). At a minimum, you need to use the man command with a topic. For example, typing man man displays the manual page about the man command. This manual page describes how manual pages work. Typing man ls displays the manual page that describes the different ways in which the contents of a directory can be listed. Table 6.4 shows the contents of each of the sections.
+   - There are several options that you can use with the man command to change the default output. Sometimes more than one manual page for a command exists, but the man command displays only the first manual page that it comes across. To display other related manual pages, one after another, use the man command with the -a option (type man -a and press Enter).
