Command mode also enables you to move the cursor around in a file. You can use the arrow keys to move the cursor up, down, to the right, and to the left. The k, j, l, and h keys perform the same movement.

> While you are practicing in the insert mode in vi, do not use the arrow keys, the Page Up and Page Down keys, or the Home and End keys to move the cursor around in a file. If you use these keys and find strange characters in your file, press the Escape key (at least once to ensure that you get to Command mode), and type :q!. This closes the file without saving the changes. By doing this while you are practicing you can ensure that you don't inadvertently save bad data to the file.

You should also save the file on a regular basis. You never know when there might be a sudden power outage. Commands that open and save files can only be used in Command mode. To access these commands, first type the colon (:) character. While you are working on a file, you can quickly save your changes (also known as writing a file) by typing :w and pressing Enter. At the bottom of the screen, you'll see a message similar to the following:

```
'practice.txt' 778L, 25518C written
```

If you decide you want to work with another file, type :e filename and press Enter. You must save changes to the file in the buffer area before you can open a new file. If you do not save your changes first, you will see an error message.

When you are finished working in vi, type :q and press Enter. The text editor will close and you will be returned to the shell prompt. To make things a little simpler, you can save the changes and quit vi at the same time; type :wq and press Enter. You will get an error if you try to quit without saving the file unless you use the :q! command discussed in the caution above.

# The Syntax for vi

When you open a file in vi, the cursor is located at the beginning of the file. If you want to start working at some other location, you can specify that spot and vi will open to it.

The following code shows the syntax for vi:

```
vi [+linenumber] [+/pattern] filename
```

The filename parameter is the name of the file you want vi to open when the program starts. For example, if you want to work with a file named practice.txt, type the command vi practice.txt.
