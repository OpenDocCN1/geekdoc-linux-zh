+   4. Type the name of the ISP (or some other descriptive name) in the Configuration name text box.
+   5. Select the Connection type option that describes the protocol used to connect to the ISP. If you are connecting to the Internet from a home computer, you will probably select the PPP using serial port/modem option.
+   6. Select the PAP option as the PPP authentication type. You might want to check with your ISP to make sure it uses PAP authentication.
+   7. Type the login name (usually your email address) in the login text box and the password needed to log in to your account in the Password text box.
+   8. Click the Modem tab. Select the modem port from the Serial device drop-down list and type the telephone number that you use to connect to the ISP in the Phone text box.
+   9. Click the Accept button. The connection that you configured appears in the PPP/SLIP configuration window. Click the Quit button to return to the Network Configurator.
+   10. Configure the server connection. Click the Name server specification (DNS) icon to display the Resolver Configuration window shown in Figure B.10.
+   11. Review your input and exit the Network Configurator. Click the Accept button in the Resolver Configuration window. Click the Quit button in the Network Configurator window. And, finally, click the Quit button in the main Linuxconf window. The Status of the System window displays.
+   12. Save the configuration changes. Click the Activate the changes button. Your changes are saved and you're ready to try out your connection with your favorite PPP dialer. An easy to use dialer is usernet.
