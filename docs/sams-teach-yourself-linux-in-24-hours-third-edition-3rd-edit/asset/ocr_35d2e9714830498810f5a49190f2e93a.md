configured on the system. Other files, located in the /proc filesystem, contain information about the system architecture; that is, all the busses, boards, controllers, and peripherals attached to the system. This is important information to have before you make any configuration changes to the system. Here's how to view these files as read-only files in the vi text editor:

+   1. Log in as superuser. Type su and press Enter. You will be prompted for the root password. Type the password and press Enter.
+   2. Open the kernel boot message file as read-only. Type vi -R /var/log/messages and press Enter. The kernel boot messages are different, from system to system, depending on the drivers that are compiled as modules or loaded into the kernel. As you browse through the file, you'll notice messages for each device as it is initialized during the boot process.
+   3. Look for system configuration information. You'll need to know the screen font and color when the screen is used as a text terminal, PCI bus and PCI cards, CPU type and processor speed, system memory usage, type of mouse, serial and USB ports, mounted filesystems, and the version number of the Linux kernel.
+   4. Move around the file. Press Ctrl+F to move forward in the file one screen. Press Ctrl+B to move backward one screen.
+   5. When you are finished reading the file, exit (or quit) the text editor. Type :q and press Enter. The vi text editor will close and you will be returned to the shell prompt.
+   6. Return to your user account. Type su username and press Enter.
+   7. View information about the CPU type and speed. Type vi -R /proc/cpuinfo and press Enter. The -R command option tells vi to open the file as read-only. An example of the /proc/cpuinfo file is shown in Listing 9.3. When you are finished reading the file, type :q and press Enter to close the file and exit vi.
