Another way to share ideas is with a Web site. You'll need an HTML editor in which to create the Web pages and possibly a graphics program to create Web images or enhance photographs. # Downloading Files from an FTP Site

One of the oldest and most reliable methods of transferring files across the Internet is with FTP (or file transfer protocol). An FTP utility that is easy to use is gFTP. You might find gFTP in the GNOME or KDE menus, or you can type gftp at the command line to start the program. Here's how to download a GNU program that you can use to manage your finances:

+   1. Connect to an FTP site. For this task, you will connect to the MetaLab FTP archive (shown in Figure 22.8). Click Bookmarks, General Sites, Metalab. The program is already set up to use anonymous logins. You can also get to an FTP site by typing the FTP address in the Host text box.
