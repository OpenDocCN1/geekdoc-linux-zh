2. Is it possible to use more than one command option at a time on the command line?

Yes, two or more command options can be placed after the dash (-) character and the order of the command options does not matter (for example, ls -1a and ls -a1 display the same output). Multiple command options can be used only when the command options are represented by a single letter.

3. What is the difference between the mv command and the cp command?

The mv command is normally used to rename a file. When a file is renamed, the original filename is deleted. The cp command makes a copy of a file and both the original file and the copy of the file can be found on the system.

4. Which command option helps make sure you don't accidentally delete a file when moving, renaming, and copying files?

The interactive command option (-i) prompts you for a confirmation if you are about to overwrite a file. The interactive command option should always be used with the rm, mv, and cp commands.
