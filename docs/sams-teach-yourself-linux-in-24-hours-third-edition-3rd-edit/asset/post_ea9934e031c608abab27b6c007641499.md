## Task: Putting Together a Linux Reading List

All throughout this book, you'll be directed to various places where you'll find more help on a subject. The sources for Linux help are vast. Here's some Linux help and information sources that every new user should know about:

- 1. The Linux Documentation Project (www.linuxdocs.org) maintains the core of the Linux online help documents. You'll most often find yourself looking to this site for the latest versions of the Linux FAQ and HOWTOs. The FAQ answers frequently asked questions about Linux, and the HOWTOs give you instructions to use Linux in different ways. In addition to reading the FAQ, you might want to read these HOWTOs before you install Linux:
- The Linux Distribution HOWTO highlights the major Linux distributions and provides some overview information about each one.
- The Linux Hardware Compatibility HOWTO lists the hardware that Linux supports and where you can find needed drivers when you are having problems configuring a device.
- You might need an installation boot disk to start the installation process. Read the Linux Bootdisk HOWTO to find out how to create this boot disk.
- If you want to install Linux on a laptop computer, read the Linux Laptop HOWTO and the Saving Space Mini-HOWTO. Laptop installations have different needs than regular workstations. You will need to deal with PCMCIA devices and a smaller hard drive.
- Read the Linux-Windows95 Mini-HOWTO if you plan to partition a Windows hard drive and install Linux on a separate partition.

- 2. The GNU project and the Free Software Foundation Web site at www.gnu.org contains downloads and help documentation for many open source programs.
- 3. Because this book is aimed at beginners, you may feel right at home at Linux Newbies (www.linuxnewbies.org). The information at this Web site is for those who are installing Linux for the first time (and maybe even the second) time. You might find it worth your while to spend some time at this site.
- 4. Another good starting point for beginners is the Linux meta-Web site at www.firstlinux.com. This site provides good advice for those who are getting ready to install Linux for the first time.
- 5. When you need the advice of the experts, cruise over to The Linux Gurus (at thelinuxgurus.org). You'll find reviews of different Linux distributions, applications, and published books. The guru also provides a good list of links to other Linux Web sites.
- 6. The most complete collection of Linux resources on the Internet is the Linux Portal Site (www.linuxlinks.com). There is a section just for beginners.

## Selecting a Linux Computer

After you've selected a Linux distribution, it's time to select the computer on which you want the Linux operating system and all the cool GNU software and utilities that are included with the distribution. There are many decisions to make about the Linux installation:

- What computer will be used to run the Linux operating system? If you are just getting started with Linux, find a computer that can be dedicated to learning Linux.

You don't want to tie up the machine you use to run your business, or your Internet connection, while you experiment with a new operating system. You might also consider installing Linux on older equipment because it is more likely that the hardware will be compatible with the operating system. Some of the newer, state-of-the-art equipment might be difficult to get to work with Linux.

- Are the computer hardware and attached peripherals compatible with Linux? Successful installations occur when the hardware is compatible with the operating system. You'll need to gather information about the hardware and check your findings against the Linux hardware compatibility list. If everything is compatible, you can start using your new operating system and included applications. If the hardware isn't listed, you might have problems configuring and using those devices.
- How much hard drive space will you be able to devote to Linux and the associated utilities? Many distributions can install well over a gigabyte of applications. You'll then need additional space to store data files and install more applications.

The first-time Linux user might want to consider installing Linux as the sole operating system on a computer. This is the easiest method. No need to install a second hard drive or to partition an existing hard drive that contains gigabytes of data. Just let the Linux operating system take over the entire computer. Not only does this make the installation much easier, it gives you a separate machine that you can learn on, make mistakes, fix those mistakes, and not have to worry jeopardizing your production machines that you use to run your small business.

If you want to run Linux and another operating system (such as Microsoft Windows) on the same computer, you have two options. The easiest of these options is to install a second hard drive on the computer and install Linux on the second hard drive. Your Windows drive stays secure and there's no fancy partitioning to do. You do need to know how to open up the computer and attach the drive and cables.

The other option is to run Linux and another operating system on the same hard drive. This requires partitioning the drive so that the original operating system lives on one part of the drive and Linux is installed on the other partition.

> If you are unfamiliar with partitioning a hard drive, we recommend that you install Linux on its own separate computer, or at least on a separate hard drive. One wrong move while you are partitioning a drive and you could lose all your valuable data.

## Minimum Recommended Hardware Requirements

One of the advantages of Linux is its efficient use of hardware resources. A bare minimum configuration for a Linux system needs to consist of

- A Pentium processor or compatible
- CD-ROM drive
- 32MB RAM, minimum
- Minimum of 500MB hard disk drive space, 1.6GB is recommended
- VESA 2.0-compliant graphics card

![](img/782ecfdc0b083a767896cc983e10427f_35_0.png)

> > It is possible to run some versions of Linux on a machine as old as a 386 with as little as 4 megabytes of RAM. This won't be an installation with an X Window graphical environment and so everything will have to be done with only a text screen and without a mouse.

These minimum requirements will depend on the type of applications that you want to run. If you plan to install any commercial applications (such as WordPerfect or Star Office), you will need more hard drive space and more RAM. You'll also want to increase RAM if you will be running graphics applications or multimedia on the computer.

## Deciding What Software to Install

During the installation, you will be asked to make selections from more than 1GB of applications and utilities that you want loaded with the operating system. For those with a large hard drive, this isn't a problem. You can easily install every program and then gradually uninstall applications that you don't use later.

> **New Term** A package is compiled code that becomes an application or a utility when installed on the system.

When hard drive space is limited, you are faced with the task of selecting packages. To make this task easier, each distribution allows you to select from a number of predefined installation classes. These installation classes are set up so that you can choose an installation based on the amount of free space you want to dedicate to Linux, or based on how you want to use the computer.
