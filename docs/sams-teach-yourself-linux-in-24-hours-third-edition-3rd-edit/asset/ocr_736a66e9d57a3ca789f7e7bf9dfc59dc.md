The custom installation class needs to know how you will be using the system. You have three choices: normal, development, and server. If you will be using the system to assist with your homework, to manage your checkbook, to help increase the productivity of your small business, cruise the Internet, or find some entertainment, select the normal class.

Next, you will be asked if any SCSI devices are attached to the system. If SCSI devices are attached, select Yes to display a list of SCSI devices. Select your device from the list.

After SCSI devices are dealt with, you will be asked about your keyboard. Once again, the correct keyboard should be highlighted by default.

Linux-Mandrake has an extra step that asks you a few miscellaneous questions:

+   - Hard drive optimization. It is best to answer No to this question. If you answer Yes, and your hard drive does not support optimization, you'll have problems later on down the road.
+   - Security level. The security level determines how the superuser (or system administrator) can log in to the system. If you want the superuser to log in directly to the root account, select low or medium security. If you want the superuser to log in from a user account (using the su command), select high security.
+   - Amount of RAM memory. The installation process will automatically detect the amount of RAM that is installed on the system. If this number is not correct, type the correct amount of RAM in the text box.
+   - Removable media automounting. This is a very nice feature to have. Automounting of devices means that whenever you place a floppy disk, Zip disk, or CD-ROM into the appropriate drive, the system will automatically know that you have done so. If you elect not to auto-mount devices, you will need to tell the operating system that you want to use the drive after you've inserted the disk. You'll learn how to manually mount devices in Hour 9, "Hooking Up Hardware Devices."
+   - Enable num lock at startup. If you use the number keypad at the right side of the keyboard, you might want to select this option.
