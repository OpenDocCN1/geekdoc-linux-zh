# Getting a Quick Start

As you've browsed through your Linux system, you might have seen long lists of Internet tools that are ready for you to use. One familiar face in the Linux Internet lineup is Netscape Communicator. Communicator is a complete suite of applications that includes Navigator (shown in Figure 22.1) to browse Web pages, Messenger that uses a single interface for email and newsgroup messages, Composer for building great-looking Web pages, an address book to store email addresses, and a built-in radio for listening to tunes while you work.

# Task: Setting Up Netscape Communicator

Most Linux distributions install the Netscape Communicator suite of Internet tools if you elected to install the Internet and WWW packages. If you want to get on the Internet fast and start reading your email, this task shows you how to configure Netscape Messenger to work with your ISP.
