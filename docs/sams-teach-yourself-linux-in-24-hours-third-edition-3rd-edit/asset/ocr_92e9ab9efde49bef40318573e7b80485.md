# Summary

During the past hour, you learned how to use the rpm command, along with the RpmDrake front end, to manage applications. With these tools, you can find out what programs are installed on the system, delete any of these programs that you don't use or need, and add any new applications that you find useful. The majority of the software that you'll find on the different Linux distributions, and packages that you can download from the Internet, is in the RPM format. This means that no matter where you get the software, you can install it on your system.
