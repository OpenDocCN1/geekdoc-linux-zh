
- The /proc directory contains virtual files that Linux uses to keep track of ongoing processes. You might think that some of these files are huge, but they are *virtual* files and are not actually there. They have other funny attributes, too. Although they take up no space at all on your disk, you can't delete them. You'll learn to use the /proc files to collect information about the computer in Hour 9, "Hooking Up Hardware Devices."
- The /root directory is the home directory for the superuser or system administrator.
- The /sbin directory is where files (or tools) for use by the superuser (system administrator) are kept. The /sbin directory contains commands that shut down the system, set the system clock, check the filesystem for errors, and set up networking.
- Temporary files are located in the /tmp directory. This is a place where all users can temporarily store files for access by other users or for temporary storage. All the data stored in the /tmp directory will be lost when the system is rebooted.
- The /usr directory contains files that are not a part of the Linux filesystem. Applications for the X Window System and the Linux game collections are examples of what you'll find in this directory. There's also quite a long list of help files in the /usr directory.
- The log files are found in the /var directory. In here, you'll find the boot logs, the dmesg log, and others. Information in these logs indicates what software was loaded at boot and how the system hardware is configured.

## Looking at File Types

Within each directory, you'll find a collection of files. A Linux file is a unique collection of data with a unique filename. The filename of a Linux file is a combination of its location in the filesystem relative to the root (base) directory, followed by the name assigned to it.

![](img/782ecfdc0b083a767896cc983e10427f_86_0.png)

> it is possible to have more than one file in the filesystem with the same assigned name, but they cannot be stored in the same directory.

Linux contains many files, each filled with different information. They serve different purposes, and as you learn more about Linux, you'll learn more about the types of files and their use. To begin, we're going to concentrate on three types of files with which you need to become familiar:

- User data files are created by you and usually contain simple data made up of text and numbers. Files such as .txt files can be read with a text editor, but the more complex ones, such as those you create with graphics or spreadsheet programs, will require a viewer or interpreter program to display them.
- System data files are used by the operating system to keep track of user passwords, logins, file permissions, and other things pertaining to keeping the system running smoothly. You will not be involved in these as a regular user, but if you are the system administrator charged with the responsibility of maintaining the system, you may need to edit these files from time to time.
- Executable files contain the instructions that tell the computer what to do. These files are usually called programs. Whenever you give the computer a command to do something, you are telling it to follow the instructions in an executable file.

## Task: Naming Files and Directories

Any system configuration files that you may edit and any application programs that you may install are assigned names and a place where they live in the system. As you work with these applications, you'll add new files to the filesystem for the letters,
reports, spreadsheets, Web pages, and pictures that you create. The first time you save a document, you need to select a directory in the filesystem in which to store the file and give the file a name. Here are a few steps to follow to help you store documents in the right place and name the files you create:

![](img/782ecfdc0b083a767896cc983e10427f_87_0.png)

> The following rules apply to the naming of directories, because a directory is just seen as a file by the Linux filesystem.

- 1. Determine the length of the filename. A filename can contain as many as 256 characters. The filename is not just the name of the individual file; it includes the directory path that leads to the file. For example, the individual file named picture.gif that is located in the /home/rusty/images directory is 30 characters long. The actual filename is /home/rusty/images/picture.gif.
- 2. Use appropriate characters when creating a filename. You can use any character in the alphabet (from A to Z, in both lowercase and uppercase letters) or any number from 0 to 9. You can also use dashes (-), underscores (_), and periods (.).

![](img/782ecfdc0b083a767896cc983e10427f_87_1.png)

> Linux filenames are case sensitive. An uppercase A is not the same character as a lowercase a. A file named report99.txt is seen as a completely different file from a file named REPORT99.txt.

- 3. Avoid keyboard characters that can cause problems in filenames. Do not put a space in the filename and do not use the following characters: < > ? * " { } [ ] ( ) ` ! | & $ ? -
- 4. To create hidden files, begin the filename with a period (.). If you want to keep your diary file hidden, give the file a name similar to .diary.txt.
- 5. Find the command line and change to your home directory. Type cd and press Enter to make sure you're in your home directory.
- 6. Create a file named practice. Type cat > practice and press Enter. The cursor will move to the next line on the screen. Type a few words and press Enter to move to the next line. Type a few words and press Ctrl+D to save and close the file. See Figure 4.5 for an example.
- 7. Read the file you just created. Type cat practice and press Enter.
