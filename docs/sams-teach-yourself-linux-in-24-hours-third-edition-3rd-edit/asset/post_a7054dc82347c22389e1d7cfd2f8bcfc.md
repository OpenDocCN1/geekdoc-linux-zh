## How This Book Is Organized

This book contains the basic information needed by anyone who wants to be a proficient user or system administrator of the Linux operating system. As you work through the book, you'll learn the concepts you need to understand a computer operating system, from both the user's and the administrator's point of view. You will find step-by-step directions for implementing these concepts to tailor your Linux operating system to serve you best. Here's an overview of what you'll find tucked between the pages:

- Part I. "Take the Linux Plunge," helps you through the Linux installation process and introduces you to the operating system. You'll learn how the operating system is structured and why you should always be security conscious.
- Part II, "Learn the Ropes," shows you all the things needed by a user on the system. You'll learn how to navigate the filesystem, perform searches, copy information in one file to another file, and edit files. You'll also learn how commands and shells work.
- Part III, "System Administration," is the beginning system administrator's guide. Before you can become proficient at making the right decisions about the system's care and maintenance, you'll need to master the concepts covered in these hours.
- Part IV, "Get a GUI," covers fine-tuning the X Window System. You'll also learn about the window managers and desktop systems available and how to get started with the X Window System.
- Part V. "Network Administration," gets you connected to the Internet and shows you how to configure the system to distribute mail and new messages. You'll also find out how to leave messages for other users on the system.
- Part VI, "Entertainment," gives you a chance to have a little fun with your computer. You'll explore some of the more interesting games that run on the system. You'll also find out how to get even more entertainment value from your computer by hooking up the sound system and playing some good old rock and roll.
- Part VII, "Appendixes," contain introductions to the KDE and GNOME desktop environments.

### Special Fonts

Many elements are presented in a font that is different from the rest of the text. Here’s what they mean and how to treat them:

- Words that appear in *italics* are technical terms that are explained the first time they are used in the book.
- The commands, utility programs, lines of code, statements, and script names are displayed in a plain `monospace` font. In other words, any terms used as code or are used in the process of creating or using code uses this special font. You’ll also find that any featured Web sites appear in the plain monospace font.
- Any input that you need to type to perform the tasks described or to follow along with the lessons appears in a **bold monospace** font.
- The *italic monospace* font designates variables. Variables are placeholders in a command that need to be replaced by an actual filename or command option.
