**Q** In addition to the hwclock command, are there any other tools or utilities that I can use to change the time displayed by the Linux clock?

**A** Several graphical tools are available that can reset the time. If you want to go through the same time-setting process used during the initial Linux installation, use the `timeconfig` command. This command allows you to change your time zone. You may also find the Time Machine, which provides an easy way to change the time and date. To find the Time Machine, type `timetool` at the shell prompt.

# Quiz

1. Which commands can you use to keep track of disk space usage?

The `df` and `du` commands display filesystem statistics. The `df` command lists the amount of free disk space for each filesystem along with the size of the partition, the amount and percentage of used space, and the mount point. The `du` command displays the amount of room individual files and directories take up within the filesystem.

2. What are some of the strategies you can implement to create more room on the hard drive?

Compress files that are not being used. Delete or archive files that you no longer need. Delete the contents of temporary directories. Learn how to manage system log files. Delete backup files that are no longer needed and uninstall applications that are not being used.

3. What command can you use to find files that have not been accessed during a specified time period?

Use the `find` command with the `-atime` command option to list files that have been sitting idle for a specific number of days. You can also use the `find` command to locate backup files created by the different applications used.

4. What is the best way to keep system users from taking up too much disk space?

You could just have a short talk with your users about keeping their home directories as small as possible by compressing files and archiving unneeded files. However, a better way is to set disk quotas on their home directories. By setting quotas, you can give the users a range within which they can work, and when they surpass this range, Linux will not allow them to store any more files in their home directories.
