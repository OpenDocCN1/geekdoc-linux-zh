## Hour 1

### Gearing Up for the Installation

This is just too cool; you've decided to try the Linux operating system! We're glad you decided to join us as we learn how to use this new up-and-comer in the operating system scene. With the arrival of the Linux operating system providing the open source platform needed to run all the GNU Project's application software, you now have new opportunities to better manage your computer and use it to explore new software applications.

It's time to begin your adventure with the Linux operating system. During the next hour, you'll learn how to prepare for a successful Linux installation by

- Deciding which Linux distribution is best for your needs and purposes
- Selecting the computer on which you will install the operating system
- Determining whether the computer you selected is compatible with the Linux operating system
- Gathering the materials needed before you can begin installing the operating system

### Comparing Linux Distributions

There might be many reasons why you decided to try the Linux operating system. You might have heard that the Linux operating system is a stable and productive work environment. That it is not prone to the dreaded general protection faults and the blue screens of death. And, another very strong point is the operating system's immunity to computer viruses. However, the hype isn't just about an operating system.

You'll find an application, command, or utility that performs just about any task or job you need to do. The list of available software from the Open Source movement boggles the mind. You'll find more than a gigabyte of software included on the CD-ROM for each Linux distribution. For the artists in the crowd, there are graphics programs that are comparable to some of the commercial applications that might have been beyond your budget. Programmers will find enough programming languages and tools to stay busy for a lifetime. And there's so much more that you might never have a use for all the commands, utilities, and applications that are installed with the operating system.

So, you're ready to try out the Linux operating system, but where do you begin? The first place to start is to select a Linux distribution. There are dozens from which to choose and more appear on the scene every day.

> Throughout this book, you'll see Tux, the Linux penguin, pointing to places where Linux distributions have their differences. Even though you'll see Linux-Mandrake as the example used in this book (most of the time), we've tried our very best to show you how to work with the Linux operating system no matter which distribution you are running.

![](img/782ecfdc0b083a767896cc983e10427f_29_1.png)

> The CD-ROM found at the back of this book contains the latest release of Linux-Mandrake. Linux-Mandrake exhibits those qualities that we feel make a good choice for the person who is just becoming acquainted with the Linux operating system. Linux-Mandrake provides technical support, good user documentation, a complete list of GNU/Linux applications, and an easy-to-follow installation process.

What should you look for when choosing a Linux distribution? You should be aware that no matter which distribution you choose, the Linux operating system is the same on every distribution. The differences appear during the installation of the operating system, the applications that are installed, technical support, and extra programs and utilities that are created by the distribution and designed to work with that particular distribution.

Here are a few things to look for when choosing a Linux distribution:

- What's packaged with the distribution CD-ROM? If you buy the boxed set, you'll most likely find the distribution CD-ROM, a CD-ROM with the source code for all the applications, a CD-ROM with extra programs (such as StarOffice or WordPerfect), boot disks, and an installation guide. If you buy the distribution CD-ROM without all the fancy extra, you'll find electronic versions of the distribution's documentation on the CD-ROM.
- Do you need technical support? Many distributions offer support for a certain number of days. This support is usually limited to helping you install the distribution on your computer system. But, be aware, there isn't much that technical support can do for you if you are running incompatible hardware. We discuss hardware later in this chapter.
- How easy is it to install the distribution? The biggest hurdle to any new Linux user is installing the operating system. When first starting out, you'll want a distribution that contains plenty of help information for the installation, can automatically detect computer hardware, and contains other tools to guide you through the installation.
- How will you be using the Linux system? Each distribution allows you to select from a set of installation types, or to selectively pick those applications that you want installed. We recommend that you select one of the installation types; there's bound to be a profile that fits you. Each distribution contains different installation types, but you will find configurations for basic workstations, systems that run mainly graphics programs and utilities, workstations that connect to a network, an Internet connection and Web browsing, network servers, and Web hosts.

> There are so many different Linux distributions, that we can't cover each one individually. All we can do is tell you about our experiences. The first Linux we installed was Slackware Linux (back in the early 1990s). After many attempts, and some serious trial and error, we finally got an operating system, but no graphical user interface. Configuring the X Window System to adequately handle the video display is still a difficult job. After hundreds of Linux installations, we feel that Slackware Linux is best suited for someone who feels comfortable working with Linux or who has a background in the UNIX operating system.

> We next moved to Red Hat Linux. We had much better luck installing this distribution. It might have been the prior experience under our belts; and then again, it might have been the graphical installation. The advantage to Red Hat Linux is the Red Hat Package Management (RPM) technology, which makes it easy to install applications, remove applications, and keep the system updated. Many Linux distributions use the RPM technology. Another feature that we liked about Red Hat Linux was Linuxconf. Linuxconf makes it easy to make a variety of system configuration changes. You can create user and group accounts for file sharing, create a dialup connection to the Internet, and change how the computer boots.

Many distributions are based on Red Hat, and we've tried several of them. Our favorite is Linux-Mandrake with TurboLinux following in a close second. Both distributions are very strong when it comes to system configuration tools. Linux-Mandrake uses DrakConf to change the settings for the video display, system users, and other system configuration settings. DrakConf also makes it easy to connect a computer to a network and to attach a printer.

The TurboLinux installation process is not as detailed as Linux-Mandrake, but it is still easier than other distributions for the new user. TurboLinux contains a number of graphical configuration tools to help you set up the system just the way you want. TurboLinux also sports a line of distributions. If you will be using Linux for home use, you'll want to try TurboLinux Workstation. There's also TurboLinux Server if you want to connect several computers together.

Another distribution which we've had success with installing the operating system and configuring the X Window System is Caldera OpenLinux. Caldera OpenLinux is another good choice for the new Linux user. The downside we saw in the distribution was a heavy reliance on the KDE desktop programs and utilities as the only way to do things, and frequent difficulty upgrading applications.

If you are looking for a slick, quick, and easy installation, you should try Corel Linux OpenLinux. The folks at Corel really are telling the truth when they say the installation is over in only four steps. We are so accustomed to sitting in front of the computer for hours, making installation decisions, and watching the software install. This installation left us breathless—we even had a little time to spare. The only downside: It comes preconfigured and doesn't give you much flexibility during the installation.

We've talked long enough and our coffee is almost gone. We would like to mention our last three experiments with Linux distributions. Although we like all three of these distributions, we do not recommend these distributions to someone just starting out with Linux. SuSE OpenLinux is the most up-to-date Linux distribution. If you need the latest application, or a new device driver, or help configuring the X Window System, go to the SuSE Web site. Debian Linux is for the advanced user. On the plus side, when installed, Debian Linux OpenLinux is the easiest distribution to maintain. It is also the only noncommercial distribution being developed as a cooperative effort over the Internet. And, we don't want to forget GNU/Hurd, the role model for operating systems everywhere.
