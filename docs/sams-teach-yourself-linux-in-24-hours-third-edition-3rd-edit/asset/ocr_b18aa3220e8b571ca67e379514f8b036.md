+   - At the bottom-left corner (under the list of installation steps) is a row of colorful buttons. These buttons change the look of the installation screens. If you want a different color scheme, click any of these buttons at any time during the installation process.
+   - The upper-left side of the screen contains the input area. For each step in the installation process, you will be asked a number of questions. You can use the mouse to scroll through lists, to select options, and to click the OK button when you have finished answering the questions in each screen.
+   - The bottom left of the screen contains information to help you answer the questions posed in the upper-left section of the screen. Before you answer any questions or select any options, you should read this help information. Use the scrollbar at the right edge to see all the text.
+   - As you walk through each screen, you might find that options are already selected for you. These defaults are based on information the installation process found while scanning your system. For most of the screens, you'll find that the default choices are correct for your system. If so, accept the defaults and go on to the next step. If the default choices are not correct, select the right choice before proceeding. You will want to verify the selected choices with the system information you collected in Hour 1.

# Supplying Setup Information

The first step is to supply some needed information so that the installation process knows how to proceed. You will first be asked to choose a language. By default, the English (US) option will be selected. If English isn't your language, scroll through the list and select the language you want to use. When you have made your choice, click OK to move to the next step.
