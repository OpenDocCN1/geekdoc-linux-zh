# Hour 17

# Automating System Administration Tasks

The odds are very good that you're the system administrator for your Linux system. This means that to you fall all the chores of maintaining and operating the system for the benefit of your users. This is true even if you have only one user on the system. The job isn't so big if you are the only user, but it becomes cumbersome quickly, and there are many things to be done. During this hour, you'll begin to get a handle on system maintenance tasks by having Linux take over the repetitive and boring parts. This will free you to pursue the lighter side of exercising system administrator powers while sipping your morning coffee.

In this hour, you will

+   - Learn about error files
+   - Edit some files to automate tasks
+   - Schedule routine tasks with cron
