# Q&A

Q How do I use the finger command to find people on the Internet?

A Fire up your Internet connection and get online, open a terminal emulator, and type finger followed by the email address of the person you seek.

Q Where can I find more information on setting up an email system on my Linux system?

A There are a few HOWTOs that you may want to start with. The Linux Mail User HOWTO provides a good introduction to electronic mail. You'll find information on many of the Linux mailers and how to get rid of spam. The Linux Electronic Mail Administrator HOWTO explains how electronic mail works on a network and the Internet, how to install and configure a mail transport agent, and how to manage the mail system. If you want to distribute mail to different users on the system, read the Linux Off-line Mailing Method mini-HOWTO.

# Quiz

+   1. What is the easiest way for new Linux users to start browsing the Web and sending email messages?
+   
+   The Netscape Communicator suite is found on most Linux distribution CD-ROMs. For those who are moving to Linux from the Windows and Macintosh operating systems, Communicator for Linux has the same look and operates the same way. Communicator contains a full range of Web tools. You can browse the Web with Navigator, and keep track of your travels using bookmarks and the history list. Messenger manages mail and newsgroup messages. The address book helps you maintain email addresses for friends, relatives, and clients. Communicator also sports an HTML editor, Composer, to get your Web site up and running.
+   
+   2. What information do you need to gather from your ISP before you can set up the mailer software?
+   
+   You need to know your email address, the names of the ISP's incoming and outgoing mail servers, the mail protocol (either POP3 or IMAP), and the username and password you need to gain access to the mail server.
