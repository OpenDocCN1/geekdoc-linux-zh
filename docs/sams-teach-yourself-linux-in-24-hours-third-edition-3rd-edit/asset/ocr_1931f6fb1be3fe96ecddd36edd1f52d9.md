The system administrator performs several jobs on a regular basis. A routine should be established for these tasks. There are always new users to add to the system, old data to remove from hard drives, software programs to upgrade, new games to install, and backups to store in a safe place.

The system administrator also needs to make sure that the system is running at optimal performance. If several users share the system at the same time, traffic flow must be monitored. The system administrator also needs to make sure that there is plenty of hard drive space for user files, system files, and program files.

And, most important, the system administrator is the security force for the system. The system administrator is responsible for educating users on the proper use of the system, informing them about how to devise a proper password, and reminding them to change their password on a regular schedule.

# Quiz

+   1. Why is it so important to develop a plan for backing up important files on a regular basis?
+   
+   You never know when disaster will strike. It might come in the form of a hard drive failure, or it might be something beyond your control, such as a power failure or flood. By backing up your files, you have a second copy of a file that has been stored away from the danger zone. Planning and implementing a good backup schedule takes the worry out of managing a number of users and all their data files.
+   
+   2. Who is the superuser?
+   
+   The superuser is also known as the root account. The person logged in as superuser has access to the entire system. This means that person can access any file or device on the system. The superuser account should be used only when performing maintenance, making configuration changes, upgrading the system, and other system administration chores.
