# Task: Modifying the Output of the man Command

All commands use command options to customize the actions of the command. Here's some practice using command options with the man command:

+   1. Type man -a man and press Enter. This command tells the less pager to display all the manual-pages that are named "man."
+   2. When the first manual page appears, use the spacebar to scroll through the document.
+   3. When you are finished reading the first manual page, press Q. The pager formats the second manual page for the man command that explains macros that format manual pages.
+   4. Read the manual page. Press Q when you're done and you will be returned to the shell prompt. Remember, for our example user rusty, it looks like this:

```
[rusty@localhost rusty]$
```

# Changing the Search Order

The manual pages are organized into several directories and manual pages are categorized into these directories. If you want to search in a specific directory for a manual page, just specify the directory number in the sections parameter of the man command syntax. You can also search the directory structure of the manual pages in a specific order. Table 6.5 shows the directory structure used by the manual pages and what can be found in each directory.

# TABLE 6.5 Directory Structure of the Manual Pages

| Directory | Contents |
|---|---|
| /usr/man/man1 | Commands that run from within a shell |
| /usr/man/man2 | Documentation on system calls |
| /usr/man/man3 | Manual pages for the libc functions |
| /usr/man/man4 | Information about files in the /dev directory |
| /usr/man/man5 | Details of formats for special files such as /etc/passwd |
| /usr/man/man6 | Games |
| /usr/man/man7 | Descriptions of the Linux filesystem and man pages |
| /usr/man/man8 | Pages for root operator utilities |
| /usr/man/man9 | Documentation on Linux kernel source routines |
