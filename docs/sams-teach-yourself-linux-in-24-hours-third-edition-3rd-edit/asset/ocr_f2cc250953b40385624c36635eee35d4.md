If you want to casually read the list of installed packages, display the list in the less pager (type rpm -qa | less and press Enter), or save the output to a file (type rpm -qa > filename and press Enter). The -qa option tells the rpm command to query all the packages found in the RPM database. As you look through the list of installed packages, you might not know what each package contains. To read a description of the package, type rpm -qi packagename and press Enter. Figure 15.6 shows the description that appears when information is requested about the mtools package.

After you've read the list of installed packages, you might find a few programs that you don't want hanging around on your system. Before you can uninstall a package, you need to know the package name and the version number. For example, to remove the mtools package shown in Figure 15.6, you need the package name (which is mtools) and the version number (which is 3.9.6). You can also query the package for this information, as follows:

```
[root@localhost ~root]# rpm -q mtools
mtools-3.9.6-5mdk
[root@localhost ~root]#
```
