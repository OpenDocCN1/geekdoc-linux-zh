4. Search for Linux-related newsgroups. Click the Search tab. Type linux in the Search For text box and click the Search Now button (as shown in Figure 22.7). All the newsgroups that contain the word linux will appear in the list.

5. Subscribe to newsgroups. Scroll through the list and when you see a Linux newsgroup that covers a topic that interests you, click the newsgroup name and then click the Subscribe button. When you return to the Messenger window, the newsgroup will be available for viewing.
