Try these useful command options:

+   - To list the files horizontally instead of vertically, type ls -x and press Enter.
+   - File information such as permissions and owners, file size, and modification date for each file can be displayed in the long listing. Type ls -l and press Enter.
+   - To display all files including any hidden files, type ls -a and press Enter. If you want to include the hidden files in the long listing, type ls -la and press Enter.
+   - Different characters can be added to the end of a filename to make it easier to recognize different file types. Type ls -F and press Enter. A slash (/) appears after directories, an asterisk (*) after executable files, and an at (@) character after symbolic links.

> You can use multiple command options after the dash (-) character (for example, the ls -la command). It does not matter in which order the command options appear, so ls -la and ls -al provide the same output. You can only use multiple command options with commands that use single letters to specify command options.

# Redirecting the Command Output

Displaying a file list in the long list fashion is fine if the file list isn't too long and fits on the screen. If you have a long list of files, the list will just scroll on past and you'll miss most of the information. You have choices—you can display the file list in a pager (such as less) or you can send the output to a file or to the printer. This looks like a good time to practice those pipe and redirection skills.

If you send the output to the less pager, you can scroll through the list at your leisure. To send the file list to the pager, type ls -l | less and press Enter. By sending the output to a file, you'll need to display the file in a text editor. To create the text file, type ls -l > filename.txt and press Enter.
