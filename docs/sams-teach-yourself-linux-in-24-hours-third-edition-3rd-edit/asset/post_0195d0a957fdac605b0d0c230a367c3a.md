
## Navigating a Virtual Desktop

If you work with several applications at one time, you may want to organize your work by using different desktops for each task. Different applications can be displayed on a different virtual desktop and each desktop can use a different background to help distinguish between desktops. For example, you might want to open an HTML editor and a graphics program on one virtual desktop where you are creating a Web site. On another virtual desktop, you can run an email program and a calendar to keep track of your daily business. And, on another virtual desktop, you can keep a chess game running that can hide easily when it's time to get back to work.

> It's easy to get lost when working with more than one desktop. Don't use more virtual desktops than you actually need, and give each desktop a descriptive name. To customize the virtual desktop settings, right-click on the panel and select Configure to display the KPanel Configuration dialog box. Click the Desktops tab and use the Visible slider to change the number of desktops. Then type a descriptive title for each desktop.

But what do you do when you want a window to appear on all virtual desktops? Here's where the Sticky button, found on the title bar, comes into play. If you need to keep your calendar in front of you to remind you of what needs to be done, make the window in which the calendar program resides sticky. This is done either by clicking on the Sticky button or by selecting Sticky from the Window menu.

## The Screensavers They Are A-Changin’

Screensavers are a great way to hide what's on your desktop when you aren't working or are away from your desk. You'll find all the available screensavers in the Screensaver configuration module. There are a number of settings (see the Screensaver configuration module in Figure A.6) that you can apply to any screensaver you select.

Even though you can specify an amount of time your system must be idle before the screensaver starts, you can make the screensaver appear at your command. Right-click on any corner in the sample display and select Save Screen. Now, when you leave the computer and want to start the screensaver, move the mouse pointer to the same corner on your screen. The screensaver starts immediately, without a delay.

## Task: Deciding on a Desktop Environment

You'll find that a number of Linux distributions use KDE as the default desktop environment when you install the X Window System. But, depending on the packages you selected during the installation, there might be other desktop environments (such as GNOME, AfterStep, FVWM, and AnotherLevel) installed on your system and available to you.

If you would like to explore some of these other desktop environments, you can use a tool called the Desktop Switcher to quickly alternate between desktop environments. Here's how to use the Desktop Switcher to exchange KDE for GNOME as your default desktop environment:

- 1. Open the Desktop Switcher tool (shown in Figure A.7). Click Application Starter, System, Desktop Switching Tool. Or, open an X terminal window, type `switchdesk`, and press Enter.
- 2. Click the GNOME option button if you want to explore the GNOME desktop environment.
- 3. Place a check in the Change only applies to current display checkbox. This changes the interface for only the user account in which you are working.
- 4. Click OK. A dialog box notifies you that you must restart the X Window System to switch to a different desktop environment. Click OK to close the dialog box.
- 5. Exit KDE. Click the Logout button on the panel or select logout from the Application Starter to display the Session prepared for logout dialog box. Click Logout to return to the shell.
- 6. Restart the X Window System. Type `startx` and press Enter. The X Window System will start (showing a black-and-white background and a large X-shaped cursor), followed by Enlightenment, and then, after a minute, GNOME appears on the screen.
