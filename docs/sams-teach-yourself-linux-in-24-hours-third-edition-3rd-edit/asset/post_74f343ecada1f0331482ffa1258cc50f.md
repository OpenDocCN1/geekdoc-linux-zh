
Linuxconf is an easy-to-use, graphical utility that can configure almost everything about your system. Linuxconf assembles all the system configuration tasks under one interface. With Linuxconf, you can set up a computer network for your organization or connect to an Internet service provider, create user and group accounts to facilitate file sharing, and perform other system administration tasks such as keeping the computer clock current.

> Before you can work with Linuxconf, you must either log in to the root user account, or have superuser access from your user account.

If Linuxconf is installed on the system, you can easily open the utility by typing linuxconf in a terminal emulator. The first time you use Linuxconf, you might see a Help window that contains some basic information about working with Linuxconf. To exit this window and display Linuxconf, click Quit. When Linuxconf opens, the Config tab should appear as shown in Figure B.7. To access one of the configuration modules, click the icon on the Config tab. For example, when you click the Users Accounts icon, the User Account Configurator opens. From the User Account Configurator, you can add or update user and group accounts and change the root password.

## Task: Creating a Connection to an ISP

One of the configuration tasks that Linuxconf can help with is creating a connection to your ISP so that you can surf around the Web. Setting up a PPP connection using the Network Configurator is a two-step process. First, Linuxconf needs to know how to connect to the Internet. Then, the name server information supplied by the ISP needs to be added. Just follow the instructions to create a connection to the Internet:

> Before you begin this task, make sure that you have the information supplied by the ISP, and that the modem is connected to the computer and turned on.

- 1. Open the Network Configurator. Click the Networking button on the main Linuxconf configuration window.
- 2. Create the PPP connection. Click on the PPP or SLIP dialout button shown in Figure B.8 to display the PPP/SLIP configuration window.

- 5. Select the Connection type option that describes the protocol used to connect to the ISP. If you are connecting to the Internet from a home computer, you will probably select the PPP using serial port/modem option.
- 6. Select the PAP option as the PPP authentication type. You might want to check with your ISP to make sure it uses PAP authentication.
