# Task: Downloading CD Album Information

An easy way to keep track of the songs on a music CD is to download the information from one of the CD databases. Here's how to keep track of your CD playlist with the GNOME CD player:

+   1. Start the GNOME CD player and pop your favorite music CD into the CD-ROM drive.
+   2. Change the player preferences. Click the Preferences button to display the preferences dialog box and the CDDB tab shown in Figure 24.3. Make sure that there is an address for one of the CDDB servers listed in the Address text box. If you do not want to use the default CDDB server, type in your favorite CDDB server address.
+   3. Connect to the Internet.
+   4. Download the CD database information. Click the Open Track Editor button to display the Disk Information panel. Then click the CDDB Status button to open the Status panel. In the Status panel, click the Get CDDB Now button. The information downloads and appears in the Disc Information panel and in the LED display of the CD player.
+   5. Start playing songs. You can double-click a song in the track editor or you can press the Play button on the CD player.
