# Setting Up a Slideshow

One way to view images stored on your computer is with GQview (type gqview at the command line). One of the advantages of GQview is that you can run a slideshow of all the images in a directory. When you open GQview, the contents of your home directory appear in the file list, but you can change to any directory you like, as shown in Figure 24.8.
