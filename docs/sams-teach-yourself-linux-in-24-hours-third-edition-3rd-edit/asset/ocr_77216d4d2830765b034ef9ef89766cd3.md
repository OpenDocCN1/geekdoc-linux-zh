# Q&A

Q What is the difference between a program and a process?

A The word program is usually associated with some sort of application with which the user interacts. One or more processes are started when the program executes. Processes are the activities started in memory by the shell to execute commands. These commands may be sent to the computer by the user or the application.

Q How much swap space should I have on my Linux system?

A Ideally, you should have twice the amount of swap space as you have physical RAM. The minimum size swap space should be 16MB.
