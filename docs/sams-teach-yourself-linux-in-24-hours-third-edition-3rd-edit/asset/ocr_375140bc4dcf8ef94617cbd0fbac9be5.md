# Editing Images with Electric Eyes

Electric Eyes is an image viewer and editing utility bundled in one neat little package. Using Electric Eyes, you can quickly sneak a peak at a picture, resize the image, and make color corrections. To start Electric Eyes, look for it in the menu system of your chosen desktop environment, or type ee at the command line. The opening screen for Electric Eyes is shown in Figure 24.6.

When Electric Eyes appears, you'll see the splash (or opening) screen. Right-click the splash screen to display the menu system and open a file. Electric Eyes can handle many file formats. The selected file appears in the same window in which the splash screen appeared. Then, you'll need to display the controls.
