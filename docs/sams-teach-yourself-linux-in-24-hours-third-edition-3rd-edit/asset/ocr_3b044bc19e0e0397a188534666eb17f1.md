5. View the running processes. Type ps and press Enter. Notice that the xeyes program is listed in the output, similar to the following:

```
[dezi@localhost dezi]$ ps
PID TTY TIME CMD
2666 pts/0 00:00:00 bash
2886 pts/0 00:00:01 xeyes
2697 pts/0 00:00:00 ps
[dezi@localhost dezi]$
```

6. Close the xeyes program. One way to close a program is to tell the kill command which process you want to quit. To do this, you need to know the process identification number (pid) for the command and be aware that these vary from run to run. In this example, if you want to kill the xeyes applet whose pid in the example is 2886, type kill 2886 and press Enter. You'll see the xeyes program window close on the screen and you'll see the following in the terminal window:

```
[dezi@localhost dezi]$ kill 2886
[1]+ Terminated xeyes
[dezi@localhost dezi]$
```
