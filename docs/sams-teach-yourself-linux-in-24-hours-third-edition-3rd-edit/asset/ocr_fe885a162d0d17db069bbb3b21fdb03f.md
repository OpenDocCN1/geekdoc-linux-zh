# Correcting Command-Line Mistakes

As you're typing along on the command line, you're bound to press a wrong key. What's a typist to do? You have several choices:

+   - For serious typing mistakes, you might want to consider clearing everything that appears on the command line. Just press Ctrl+U. After you have an empty command line, you can try typing the command again.
+   - If you caught the error quickly, press Backspace to clear the character to the left of the cursor. Backspace deletes only one character at a time. Press Backspace until the error is deleted, and then continue typing the command correctly.
+   - When the typo is in the middle of the command line, press the left-arrow key until the cursor is to the right of the error. Press the Backspace key to delete the error. You can then either insert new text (it will be inserted to the left of the cursor) or use the arrow key to move to the end of the command.

# Using Command Shortcuts

There are a few typing shortcuts that will help make your job at the command line a little easier. Here's how you can cut down on your number of keystrokes per hour:

+   - Maybe your memory is fading and you can't remember a command you used in recent history. Press the up-arrow key and watch time travel backward as the previous command that you typed appears after the shell prompt. Press the up-arrow key to continue looking at each previously typed command. When the command you need appears after the shell prompt, press Enter to execute the command.
