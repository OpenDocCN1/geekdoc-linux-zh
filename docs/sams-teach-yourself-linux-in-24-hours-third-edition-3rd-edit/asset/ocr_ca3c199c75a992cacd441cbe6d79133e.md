Q Is there another program besides rawrite that I can use to create an installation boot disk?
A There is a version of rawrite for Windows called RawWrite. You might find it on the distribution CD-ROM using the filename rawrite.exe or rawritewin.exe.

# Quiz

+   1. What features should you look for when selecting a Linux distribution?
+   The beginner should be most concerned with ease of installation and technical support to help install the operating system. Beginners should also purchase the boxed set for their chosen Linux distribution. The boxed set contains an installation manual and the boot disks. Many distributions also include a number of extras, such as trial versions of commercial programs.
+   
+   2. What are the Linux HOWTOs?
+   The Linux HOWTOs are part of the Linux online documentation and are maintained by the Linux Documentation Project at www.linuxdocs.org. The HOWTOs are instructions on how to perform different tasks with Linux. After the operating system is installed, you will find the HOWTOs (and other sources of Linux help) in the filesystem. These HOWTOs can help you with everything from selecting a Linux distribution, to installing the operating system, configuring the X Window System, setting up an Internet connection, and getting sounds to play from your computer.
+   
+   3. What is the minimum computer configuration on which the Linux operating system will run?
+   Linux is an efficient resource manager, which means that you can get more mileage from your computer's hardware. Linux-Mandrake needs a Pentium processor (or compatible), floppy drive, CD-ROM drive, 32MB RAM, 500MB hard disk space, and a graphics card.
