The method used to move to a different directory in the filesystem is the `cd` command. To change to a different directory, type `cd` followed by the directory path. If the home directory is the working directory (for example, `/home/rusty`) and you want to go to `/home/rusty/letters/chainmail/Feb`, type `cd letters/chainmail/Feb` and press Enter. There is no need to type the entire directory path because the directory you want is relative to the working directory. However, if you want to go to the `/usr/doc` directory to see the help files for programs installed on the system, you would need to type `cd /usr/doc` and press Enter. You use the absolute filename because the `/usr/doc` directory is not in the path of the working directory.

**New Term** There are two types of Linux filenames—absolute and relative filenames. An *absolute filename* begins with the slash (`/`) character indicating the root of the filesystem, followed by the complete directory path to a file. Every file on the system has an absolute filename and the absolute filename can be used from any location in the filesystem. The *relative filename* refers to a file's location beginning from the working directory. The relative filename does not begin with a slash character.

> Try these shortcuts when using commands in relation to your working directory: One dot (`.`) indicates your current directory, and two dots (`..`) specifies the parent directory of your current directory. If you want to change to the parent directory of the current working directory, type `cd ..` and press Enter.

# Deleting Directories

The `rmdir` command is used to remove directories. Before you can delete a directory, you must first delete the contents of the directory. This means that any files contained in the directory need to be removed with the `rm` command (discussed later in this hour), and subdirectories need to be emptied and then deleted with the `rmdir` command.
