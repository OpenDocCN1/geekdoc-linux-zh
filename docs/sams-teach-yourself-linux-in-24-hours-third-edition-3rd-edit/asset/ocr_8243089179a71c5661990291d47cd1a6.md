# Introducing GNOME and Linuxconf

Next in the desktop environment lineup is GNOME. GNOME is another popular and powerful desktop environment. You'll find enough information in this appendix to get up to speed with GNOME. After you've looked at KDE and GNOME, you can decide which desktop environment is right for you. Or, you might decide to keep looking at some of the other desktop environments that are compatible with the X Window System.

Because we're on the subject of graphical user interfaces, one way to make the file management task a little easier is with the aid of a file manager. Although GNOME uses the GNU Midnight Commander as its default file manager, other file managers, such as KDE Explorer and X WinCommander, are also available. When you'd like to take a rest from the command line, try a graphical file manager for a while.

Over the past 24 hours, you've seen how to use commands to set up the system and how to edit files to make system configuration changes. Most distributions include a variety of configuration utilities that automate these tasks for you. One tool that you'll find in many distributions is Linuxconf.
