# Keeping the Superuser Safe

The root account belongs to the system superuser, which is also the system administrator. The person logged in to the root account has access to the entire system, including the accounts of other users on the system. A hacker breaking into your system really wants root access to be able to do whatever he wants. The necessity of keeping the root account sacrosanct from unauthorized persons and users who perhaps blunder in by accident cannot be overstated. If the root account is compromised, the whole system can be lost.

One rule of thumb that you should always follow is to use the superuser account only when performing system administration tasks. System administration tasks include making system configuration changes, such as adding new hardware or adding users to the system.
