# Task: Working with the KDE Control Center

All the tools that you'll need to change the way the desktop looks and operates are found in the KDE Control Center. The KDE Control Center contains a number of configuration modules that change the look of the desktop, display system information, set shortcut keys, and control the appearance of windows. You'll work with the KDE Control Center to change the appearance of your desktop later in this appendix. Here's how to open the KDE Control Center and find out how it works:
