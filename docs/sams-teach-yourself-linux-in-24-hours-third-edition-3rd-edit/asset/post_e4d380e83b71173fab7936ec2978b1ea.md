
## Monitoring the System on a Regular Basis

There is no substitute for paying attention. The security of your system is entirely dependent on how well you monitor the system and how diligent you are when adding new users, installing new software, and upgrading old equipment. The allocation of system resources should be the best for managing the system. In a multi-user system, this means disk space allocations for each user, backup requirements for user's files, printer priorities, and many other considerations. In a workgroup, resource allocations must be monitored to fit the needs of the group and best benefit the project.

There are built-in monitors that will help you keep track of the operating system's activities. You can monitor the way that users make use of resources, and you can use that information to help you schedule maintenance and necessary system downtimes.

## Checking CPU Activity

Through the aid of one or more small monitoring applets available with most GUIs, or by working with commands on the command-line, it is possible to obtain information about the system's resources. The information about CPU usage is helpful in deciding whether you can run additional processes on the system at peak times. It enables you to see when peak times occur, and how much of a load is placed on the CPU by adding more applications. Some of the more CPU-intensive applications can be saved and run when the CPU load is not at its peak.

## Schedule Maintenance Tasks

An important part of your responsibilities as system administrator is to maintain a secure and uncluttered system. To do this effectively, actions must regularly take place regarding file system backups and purges and other operating system maintenance tasks. Regular updates must be made to software and hardware assets to preserve their currency and value. The security of your system is dependent on how well your users follow the security guidelines you establish, and how well you schedule the maintenance that you need to perform to keep the system and hardware working at peak levels.

## Q&A

Q Besides protecting the operating system with regular backups, passwords, and file permissions, is there anything else that can be done to keep the computer system safe?

A It is always a good idea to keep the computer in a clean environment and away from static electricity. Dirt and dust can be a computer's worst enemy. These particles build up on the electronic parts and can cause your computer to overheat or short out.

If someone who is unfamiliar with the system uses the computer, take time to properly train him so that he knows how to access his user account and where to save his files.

Another good idea is to plug your computer into an uninterruptible power supply (UPS). A UPS protects your computer during power surges and electrical storms, and protects your data by giving you time after a power outage to save your work and safely shut off the system.

Q Several times during the hour, it was mentioned that a system administrator is needed to do the job of maintaining the computer system. Please explain the job of the system administrator a bit more.

A The system administrator is responsible for keeping a computer system up and running. The job of the system administrator begins with planning the system and includes everything from setting up the computer and installing the operating system and application software, to keeping the system running, planning for upgrades, and restoring the system in case of a loss of equipment or data.

The system administrator performs several jobs on a regular basis. A routine should be established for these tasks. There are always new users to add to the system, old data to remove from hard drives, software programs to upgrade, new games to install, and backups to store in a safe place.

The system administrator also needs to make sure that the system is running at optimal performance. If several users share the system at the same time, traffic flow must be monitored. The system administrator also needs to make sure that there is plenty of hard drive space for user files, system files, and program files.

And, most important, the system administrator is the security force for the system. The system administrator is responsible for educating users on the proper use of the system, informing them about how to devise a proper password, and reminding them to change their password on a regular schedule.

## Quiz

-   1. Why is it so important to develop a plan for backing up important files on a regular basis?
-   
-   You never know when disaster will strike. It might come in the form of a hard drive failure, or it might be something beyond your control, such as a power failure or flood. By backing up your files, you have a second copy of a file that has been stored away from the danger zone. Planning and implementing a good backup schedule takes the worry out of managing a number of users and all their data files.
-   
-   2. Who is the superuser?
-   
-   The superuser is also known as the root account. The person logged in as superuser has access to the entire system. This means that person can access any file or device on the system. The superuser account should be used only when performing maintenance, making configuration changes, upgrading the system, and other system administration chores.
