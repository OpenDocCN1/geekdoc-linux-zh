> The Linux-Mandrake CD, found at the back of this book, stores the RPM files in the /Mandrake/RPMS directory.

2. Select the package that you want to install. For this task, a small application called kteatime will be used as the example. It is found on the #2 CD in the /Mandrake/RPMS2 directory.

3. Display a description of the application you want to install. Type rpm -qpi filename. The filename is the complete directory path to the RPM file. An example of what you will type on the command line and the information that appears is shown in Listing 15.1.

4. Display the files, and the location of each file, that will be installed for the package. Type rpm -qpl filename and press Enter. Listing 15.2 shows the files that will be installed for the kteatime application.

# LISTING 15.2 List the Files That Will Be Installed

```
# rpm -qpl /mnt/cdrom/Mandrake/RPMS2/kteatime-0.1-7mdk.1586.rpm
/usr/bin/kteatime
/usr/doc/kteatime-0.1
/usr/doc/kteatime-0.1/ChangeLog
/usr/doc/kteatime-0.1/LICENSE
/usr/lib/menu/kteatime
/usr/share/icons/kteatime.xpm
```

This listing shows you that the execution (or binary) file for kteatime is located in /usr/bin. The help documentation for the program can be found at /usr/doc/kteatime-0.1.
