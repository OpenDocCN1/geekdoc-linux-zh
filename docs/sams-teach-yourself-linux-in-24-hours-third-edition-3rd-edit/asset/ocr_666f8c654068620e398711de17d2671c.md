Here are some other cool tricks that you can teach the cat:

+   - When you need to combine the contents of several files into one new file, tell cat which files to combine and in what order, and the name of the new file. The rest can be left to cat. For example, user rusty collects jokes. Each joke is placed in a separate file and occasionally rusty picks a few good jokes to share with friends. This week, rusty wants to send the joke files named joke27 and joke53 to some pals. To combine these two files into a third file named grins1, type `cat joke27 joke53 > grins1` and press Enter.
+   - To add the contents of one file to the end of another file, tell cat to append the file. If rusty has a file named guffaws1 that some friends would enjoy, but also wants to also share joke27, rusty would use cat to copy the contents of joke27 and then paste the contents to the end of the file named guffaws1. To append the file, type `cat joke27 >> guffaws1` and press Enter.
+   - The cat command can also be used to create a blank file. User rusty wants to put together a collection of the best jokes of the year. To create a new file named best2000, type `cat > best2000` and press Ctrl+D. Now, with a new, blank file, rusty can search the joke collection and use cat to append the best of the best to the end of the best2000 file.
