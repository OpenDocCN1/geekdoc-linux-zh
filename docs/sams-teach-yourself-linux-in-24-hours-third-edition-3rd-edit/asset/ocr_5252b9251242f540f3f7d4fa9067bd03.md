# Task: Moving Around the Filesystem

Using a graphical interface to work with the filesystem makes it easy to move from directory to directory, view the contents of a directory, and create and move files. A safe place to play in the filesystem is in the /usr directory. This directory contains a number of programs that you might find useful. You'll also find a wealth of information about the operating system and all the applications installed on the system. Here's how to move around the filesystem and view a few files:

+   1. Display the contents of the /usr directory. Scroll to the bottom of the directory tree and click the plus sign next to usr. The subdirectories found in the /usr directory will appear in the directory tree.
+   2. Display the contents of the /usr/doc directory. Click the plus sign next to doc. A subdirectory for each program, command, utility, and application documentation displays in the directory tree.
+   3. Look for the /usr/doc/linuxconf subdirectory. (You'll work with Linuxconf later in this hour.) Click on the subdirectory to display the contents in the file list.
+   4. Look for a README file. Double-click the file to open it. The file will open in the default text editor. Other file types will open in their associated viewers. For example, an HTML file might open in Netscape Navigator.
