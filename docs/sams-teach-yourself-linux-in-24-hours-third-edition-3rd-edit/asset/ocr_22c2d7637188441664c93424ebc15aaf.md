# Installing Linux-Mandrake

It's time to load the GNU/Linux operating system and this hour assumes that you will be using the Linux-Mandrake distribution CD-ROM found at the back of this book. Even if you chose another GNU/Linux distribution, you can still use the information in this hour as a general guideline for the installation process because all distributions follow the same installation procedures.

In this hour, you will

+   - Gather everything you need to install the operating system
+   - Install the operating system, applications, and the X Window System on your computer
+   - Learn how to use the superuser and unprivileged user accounts to log in to the system
+   - Restart and turn off the computer
