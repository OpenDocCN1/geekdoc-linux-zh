# What Is the X Window System?

When you installed the Linux operating system, you were given the opportunity to configure the X Window System so that you can take advantage of one of the full-blown graphical interfaces available for Linux, such as KDE and GNOME. After you select and configure the right X Window server for your system, it supplies the video, the audio, and the controls for peripheral devices such as the keyboard and the mouse. The X Window System even has tools for configuring the Linux kernel. It can also do all the things listed here on someone else's screen.

Having the X Window System installed on your computer makes it possible for you to take advantage of the world of free software that's available for use with X. The X Window server can operate your CD writer, connect to your video camera and VCR, play movies and music CDs, provide a single interface across multi-platform networks, and a single X server can manage the display on many machines at the same time. X can also run MS Windows in an X window.

# How It Works

The X Window System is an application that is run by your computer. X Window is a server that provides multimedia capabilities for your Linux box. If you elected to install the X Window System when you installed Linux, you'll find all the tools and utilities that you'll need for selecting, configuring, and tuning an X server to fit on about any graphics card, monitor, and operating system combination in existence.

# What You'll Need Before You Begin

Hopefully, when you installed Linux, the X server was installed properly so that you can use a graphical user interface. It's easy to start the graphical interface from the text console. After you log in, type startx and press Enter. The default desktop environment (usually KDE or GNOME) will start. If you aren't completely satisfied with the results, you can make changes to get a better display. But before you can fine-tune your display, you'll need some of the information that you collected in Hour 1, "Gearing Up for the Installation." Here's the information that you'll need to get started:

+   - The keyboard language and number of keys
+   - The type of mouse (PS/2 or serial, number of buttons)
+   - The manufacturer and model for the monitor along with the maximum resolution, vertical refresh rate, and horizontal refresh rate
+   - The manufacturer and model of the video card, type of graphics card and chipset, amount of video memory, and color depth (8-bit, 16-bit, 24-bit, 32-bit)
