# Q&A

Q I understand that cron will run a command many times depending on the parameters set in the crontab entry. But what do I do if I want to schedule a command to run only one time?

A When you want to run a command or a process only once, you can use the at command. The at command can be used to queue a job for execution at a specified time and to examine or delete the jobs queued for later execution. To use the at command, type at followed by the time at which you want the command to run and press Enter. On the next line you'll see at>. Type the command and press Enter. When you are finished entering command, press Ctrl+D.

Q Is it possible to add my own manual pages to the system so that I can access them with the man command?

A Yes. You can create a plain text file and then store it in the appropriate directory under /usr/man. For more instructions, read the Linux Man Page mini-HOWTO.

# Quiz

+   1. What is a core dump and what will you find inside the core dump file?
+   
+   When a program crashes or when there is some other error while you are working in Linux, a core dump is written to a file. This file is written to your home directory. The core dump file contains the process information that is stored in memory at the time of the failure. There is a lot of information in this file, but it takes someone with programming skills to really understand what is going on. You might be able to find out what caused the core dump by running the gdb program.
+   
+   2. What can you do if you do not want core dump files stored on your computer?
+   
+   You can set a limit on the size of a core dump file with the ulimit command. To set the core dump size to zero (which means that no core dump file can be written), use the ulimit -c 0 command.
