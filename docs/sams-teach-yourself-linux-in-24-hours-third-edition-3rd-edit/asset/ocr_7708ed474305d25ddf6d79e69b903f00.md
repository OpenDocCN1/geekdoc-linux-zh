# Should You Read this Book?

Are you interested in the UNIX operating system but find it daunting and complex? Linux is a smaller, friendlier member of the UNIX family. Are you looking for a different, better operating system? Linux is an alternative to the Windows and Macintosh computing environments. Are you looking for an introduction to this new operating system? Do you need help overcoming the Linux learning curve while obtaining a good solid working knowledge of the Linux operating system?

This book is a results-oriented tutorial—a step-by-step guide to installing, configuring, and using Linux productively. It is designed to help you learn about the Linux operating system in a secure, nonthreatening environment. You'll find a friendly introduction to the Linux operating system in plain language that builds understanding by guiding you through the performance of familiar tasks and exercises in Linux. The material in the book is organized and presented in ways to complement and expand your existing knowledge.

After reading this book and working through the exercises, you will be able to install and configure the Linux-Mandrake distribution on a variety of machines, and you will possess a good basic knowledge of GNU/Linux in general. When you are familiar with Linux, you can begin to make intelligent choices about using it and tailoring it to meet your needs.
