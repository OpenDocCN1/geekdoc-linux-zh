
## Q&A

Q When I'm working with several user accounts on a number of different terminals, how can I quickly find out which of my user accounts are logged in?

A Try the who command. If you want to know which user account you are currently in, type who am i.

Q In addition to the manual and info pages, are there any other types of documentation that I might find hidden away in the Linux filesystem?

A The HOWTOs (found in the /usr/doc/HOWTO directory) and the FAQs (stored in /usr/doc/FAQ) are two sources that you should definitely know about.

Q Early in the hour, there's a list of frequently used commands. Is there a list of seldom-used commands that I can try out for a little fun and enjoyment time?

A Are you interested in how long you've been logged into your user account? Type finger username and press Enter (where username is the login name for your user account). In addition to displaying the amount of time that you've been logged in, you can also find out the name of the shell you are using, and whether you have any mail.

If you'd like to find out how much disk space each directory and subdirectory takes up, use the du command. To see the amount of free and used disk space on the entire system, use the df command.

When you need to know the current time or the date, try the date command.

To display a calendar of the current month, use the cal command. If you want to see other months, you'll need to add command options to the cal command.

Q I'm working in the X Window System and I want to read the manual pages. What's the best way for me to get started?

A You might want to try a program called xman. To start xman, open an X terminal window and type xman at the shell prompt. You can quickly select from a list of manual pages.

### Quiz

1. What basic skills will you need to become an efficient user of the Linux operating system?

The most important basic skill to acquire is the ability to work efficiently with directories and files on the filesystem. Working with directories involves viewing the contents of a directory and changing between directories. Files are kept in order by editing the file contents, moving them to appropriate directories, and deleting unneeded files.

The ability to locate files and search for information is also important. This prevents files from becoming lost in the system, and also helps you to learn about the commands and programs installed on the system. To help you use search information better, the command results can be directed to either a file or a printer.

When many users work on the system, the ability to give other users access to files makes file sharing an easy task.

2. What are the three basic parts of a command?

The three parts of a command are the command, the command options, and any parameters. Command options modify the results of the command, and parameters are another type of input that is used to modify the output of the command. Parameters are usually filenames or directory paths.

3. How do you delete typing errors when working on the command line?

To erase the entire line, press Ctrl+U. Pressing Backspace deletes the last character that was typed. The arrow keys can move the cursor along a line of command so that text can be inserted somewhere in the middle of the command line.

4. What is the syntax for the man command?

The man command displays requested reference pages for commands installed on a Linux system. The syntax for the man command is

```
man [options] [section] topic
```

Where the topic parameter is the name of the command, the section parameter is used to search a specific section in a man page, and the options change the default output (such as displaying several related manual pages, one after another).

### Moving Around the Filesystem

All operating systems share a common characteristic: They use a directory structure to organize files. The directories are structured like a tree. The primary directory, which is the base directory and the one from which all other directories branch, is the root directory. All other directories, which grow out of the root directory, are called subdirectories. Within these directories and subdirectories, you'll find applications and utilities, device and system files, and data files.

The most basic task that you'll perform is file management. File management includes moving from directory to directory, creating files, organizing files into directories, moving files from one location to another, and deleting unnecessary files.

### Exploring the Home Directory

In Hour 4, “Understanding the Linux Operating System,” you were introduced to the basic structure of the filesystem. You saw how files fit into directories, and how directories fit within other directories. When users are assigned accounts on the system, they are also allocated space within the /home directory in which to store their personal files. If a user has the login name of rusty, that user’s personal files are stored in /home/rusty. This is known as the home directory and is the directory in which the user is working after logging in to his account. From this directory, the user can create subdirectories in which to organize files, create new files, modify these files, and delete unneeded files. Only the user, those authorized by the user, and the root account, may access files in the user’s home directory.

When you first log in to your user account, the shell prompt looks something like this (that is, if your username is rusty):

```
[rusty@localhost rusty]$
```

Cool, but where does that leave you in the filesystem? Type pwd and press Enter. The response appears on the following line on the screen and looks like this for the user named rusty:

```
/home/rusty
```

Notice that the shell prompt appears on the next line. It’s waiting for you to give it another command. That’s good, because this is a good time to explore your home directory.
