# Quiz

1. What is a process?

A process is the activity that occurs in memory when a command is executed. The process is a shell function begun to perform the action requested when a command executes. Processes use RAM and CPU resources. When a process has finished its job, it is removed from memory, thereby making resources available for other processes. There are three types of processes: interactive, batch, and daemon (server) processes.

2. What commands can you use to find out which processes are running on the system?

The ps command displays information about the processes running on the system. The ps command tells you the identification number for the process, the status of the process, and the command that was executed to start the process. The free command displays the amounts of physical (or RAM) memory and virtual (or swap) memory that are being used by all processes. The top utility shows which resources each process is using. It also provides an interactive interface with which you can manage processes in some ways; you may change the priority of processes or interactively kill them.

3. If you start a program from a terminal emulator, how do you execute a program yet still make the terminal emulator available for use?

You will need to run the program in background. To run a program in background type the name of the execution file for the program followed by the & character.

4. What is the function of the kill command?

The kill command terminates the execution of a program. To use the kill command, you must know the process identification number of the process you want to terminate.
