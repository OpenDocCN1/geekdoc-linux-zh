+   6. Create a file in which to define quotas. This file needs to be located in the root of the partition (in this case, the /dev/hda3 partition). Type touch /home/quota.user and press Enter.
+   7. Change the file permissions so that only the superuser has access to this file. Type chmod 600 /home/quota.user and press Enter.
+   8. Reboot the system. You will need to restart the system so that the changes can be applied. When the system has restarted, log back into the superuser account.
+   9. Set disk space limits for individual users. Type edquota -u username and press Enter. To limit the amount of space for the user "rusty," type edquota -u rusty and press Enter. The quota.user file appears in the vi text editor. An example is shown in Figure 14.4.
