+   2. Sort processes according to the amount of system memory being used. Type M. At the top command line, you'll see a message that says, Sort by memory usage. The list of process will be updated and the process that is using the most memory will be shown at the top of the list.
+   
+   3. Sort processes according to the amount of CPU resources being used. Type P. A message that says, Sort by CPU usage, appears on the top command line. The list of processes will be updated and the process that is using the most CPU resources will be shown at the top of the list.
+   
+   4. Terminate a task. Type k to see the message PID to kill. Then type the PID (or process identification number) for the process that you want to kill. Using Figure 13.3, to terminate the xdaliclock program, type k to display the message, type 3641, and press Enter. The top command then asks if you are sure you want to kill the command by displaying Kill PID 3641 with signal [15]: on the top command line. Press Enter to end the process.
+   
+   5. Close top when you are finished. Type q. The top utility will close and you will be returned to the shell prompt.
