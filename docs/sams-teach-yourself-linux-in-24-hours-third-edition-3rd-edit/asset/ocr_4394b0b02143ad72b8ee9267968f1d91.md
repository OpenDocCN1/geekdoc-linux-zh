# Q&A

Q When I'm working with several user accounts on a number of different terminals, how can I quickly find out which of my user accounts are logged in?

A Try the who command. If you want to know which user account you are currently in, type who am i.

Q In addition to the manual and info pages, are there any other types of documentation that I might find hidden away in the Linux filesystem?

A The HOWTOs (found in the /usr/doc/HOWTO directory) and the FAQS (stored in /usr/doc/FAQ) are two sources that you should definitely know about.

Q Early in the hour, there's a list of frequently used commands. Is there a list of seldom-used commands that I can try out for a little fun and enjoyment time?

A Are you interested in how long you've been logged into your user account? Type finger username and press Enter (where username is the login name for your user account). In addition to displaying the amount of time that you've been logged in, you can also find out the name of the shell you are using, and whether you have any mail.

If you'd like to find out how much disk space each directory and subdirectory takes up, use the du command. To see the amount of free and used disk space on the entire system, use the df command.

When you need to know the current time or the date, try the date command.

To display a calendar of the current month, use the cal command. If you want to see other months, you'll need to add command options to the cal command.

Q I'm working in the X Window System and I want to read the manual pages. What's the best way for me to get started?

A You might want to try a program called xman. To start xman, open an X terminal window and type xman at the shell prompt. You can quickly select from a list of manual pages.
