# Getting Ready

One of the differences that you'll find between the Linux operating system and the Windows operating system is the ease in which you can set up a modem and a dialup connection to the Internet. There are no wizards to guide you along the way. And you'll need to know a few important pieces of information about your computer and modem before you start. During the next hour, you'll learn some of the secrets of successfully getting on the Internet. Before you begin, you'll need to do some preparation. Collect the information provided by your ISP and make sure that the modem is compatible with Linux. Many new computers come with builtin modems that may not be compatible and Winmodems in particular will probably never be compatible.

# Collecting Information from Your ISP

When you set up an account with an ISP, the ISP provides all the information you need to create a dialup connection. No matter which of the methods you choose for creating the connection, you'll need this information to connect to the ISP's servers. Here's a checklist of the information you will need to collect:

+   - The telephone number that the modem dials to make the initial connection with the ISP.
+   - The username and password used to identify you as an authorized user of the ISP's system. Most ISPs allow you to select a username and password; others might assign a username and password.
+   - The domain name of your ISP. An example of a domain name might be www.myisp.net.
+   - The domain name server addresses (or DNS addresses) that the ISP's server uses to locate other computers on the Internet. Your ISP might use a primary and a secondary DNS address. The DNS address takes the form 255.255.255.255.
+   - The IP address that the ISP assigns to your computer when you connect to the Internet. Most ISPs use dynamic IP addresses, so you might not need this information.
+   - If you use email and newsgroups, you'll need your email address, the name of the ISP's mail server, and the name of the ISP's news server. In addition you need to know the ISP's authentication protocol, PAP, CHAP, etc. You'll use this information in Hour 22, "Merging Onto the Information Superhighway ISP."
