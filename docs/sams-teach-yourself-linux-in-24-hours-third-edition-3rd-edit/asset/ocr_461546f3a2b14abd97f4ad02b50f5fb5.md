# Adding New Hardware

During the installation, you created different filesystems and corresponding mount points for the partitions on the hard drive. If you think you're running out of storage room, you might want to consider adding a second hard drive to the system. Here are the steps required to add a disk to the system:

+   - Make sure that the piece of hardware is compatible with the operating system. You'll find this information in the Linux Hardware Compatibility HOWTO. There are some other HOWTOs that you might want to read: The Hard Disk Upgrade mini-HOWTO, the Filesystems HOWTO, the CD-ROM HOWTO, the Zip Drive mini-HOWTO, the Jaz Drive HOWTO, the Plug-and-Play HOWTO, and the CD Writing HOWTO.
