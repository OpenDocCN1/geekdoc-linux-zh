# Q&A

Q Where can I find information about Linux text editors on the Internet?

A The most complete source of text editors is available from the Metalab Linux Archive at metalab.unc.edu/pub/Linux/apps/editors. Another good source is the Dave Central Linux Software Archive at linux.davecentral.com/officed.edit.html. Dave offers downloads of many Linux text editors in several formats (RPM, source code, and binary files) and provides a link to the home page for the editor.
