
- At the bottom-left corner (under the list of installation steps) is a row of colorful buttons. These buttons change the look of the installation screens. If you want a different color scheme, click any of these buttons at any time during the installation process.
- The upper-left side of the screen contains the input area. For each step in the installation process, you will be asked a number of questions. You can use the mouse to scroll through lists, to select options, and to click the OK button when you have finished answering the questions in each screen.
- The bottom left of the screen contains information to help you answer the questions posed in the upper-left section of the screen. Before you answer any questions or select any options, you should read this help information. Use the scrollbar at the right edge to see all the text.
- As you walk through each screen, you might find that options are already selected for you. These defaults are based on information the installation process found while scanning your system. For most of the screens, you'll find that the default choices are correct for your system. If so, accept the defaults and go on to the next step. If the default choices are not correct, select the right choice before proceeding. You will want to verify the selected choices with the system information you collected in Hour 1.

## Supplying Setup Information

The first step is to supply some needed information so that the installation process knows how to proceed. You will first be asked to choose a language. By default, the English (US) option will be selected. If English isn't your language, scroll through the list and select the language you want to use. When you have made your choice, click OK to move to the next step.

![](img/782ecfdc0b083a767896cc983e10427f_50_0.png)

> You don't have to use the mouse to select options. Use the Tab key to move from one field to another, or to move from one field to the OK button. The arrow keys will move you through a list of options. Use the spacebar to select an option.

You will next be asked to select an installation class. There are three choices: recommended, customized, and expert. If you want an easy installation (Linux-Mandrake will make the choices for you), select the recommended installation class. For more control over the installation, choose the custom installation class. The custom class enables you
to select the packages (or applications) that you want installed on the system. Only those people who really know what they are doing should use the expert installation class. This section explains the installation process using the custom installation class.

The custom installation class needs to know how you will be using the system. You have three choices: normal, development, and server. If you will be using the system to assist with your homework, to manage your checkbook, to help increase the productivity of your small business, cruise the Internet, or find some entertainment, select the normal class.

Next, you will be asked if any SCSI devices are attached to the system. If SCSI devices are attached, select Yes to display a list of SCSI devices. Select your device from the list.

After SCSI devices are dealt with, you will be asked about your keyboard. Once again, the correct keyboard should be highlighted by default.

![](img/782ecfdc0b083a767896cc983e10427f_51_0.png)

Linux-Mandrake has an extra step that asks you a few miscellaneous questions:

- Hard drive optimization. It is best to answer No to this question. If you answer Yes, and your hard drive does not support optimization, you'll have problems later on down the road.
- Security level. The security level determines how the superuser (or system administrator) can log in to the system. If you want the superuser to log in directly to the root account, select low or medium security. If you want the superuser to log in from a user account (using the su command), select high security.
- Amount of RAM memory. The installation process will automatically detect the amount of RAM that is installed on the system. If this number is not correct, type the correct amount of RAM in the text box.
- Removable media automounting. This is a very nice feature to have. Automounting of devices means that whenever you place a floppy disk, Zip disk, or CD-ROM into the appropriate drive, the system will automatically know that you have done so. If you elect not to auto-mount devices, you will need to tell the operating system that you want to use the drive after you've inserted the disk. You'll learn how to manually mount devices in Hour 9, "Hooking Up Hardware Devices."
- Enable num lock at startup. If you use the number keypad at the right side of the keyboard, you might want to select this option.

## Setting Up the Filesystems

Now it's time to setup the hard drive (or the partition on the hard drive) in which you want the Linux operating system to live. It is recommended that you set up four partitions for the Linux filesystem: a boot partition, a root partition, a swap partition, and a home partition.

> You can have Linux-Mandrake automatically create the different partitions you need by clicking the Autoallocate button.

Linux may be set up as the sole operating system installed on the machine or it may be installed and share the drive with others. A lot of older equipment can suffer under the load of trying to run modern versions of Windows with all the bells and whistles.

> **Selecting a Test System**
> We have an antique computer that we have been using for a number of years to practice riding the exciting, rocky GNU road. It's a Pentium 133, and as a Microsoft Windows machine, its usefulness had all but disappeared. It crashed constantly and the drive sounded like a washing machine. Two years ago, we installed GNU/Linux as its sole operating system and have only had to perform routine system maintenance to keep it running; it has purred like a kitten since. We use it daily as a test machine and as a workstation.

Listing 2.1 shows a sample filesystem set up using GNU/Linux as the sole operating system. The information displayed is for a computer that will be running only the Linux operating system, has a 16-gigabyte hard drive, and 192 megabytes of RAM.

### LISTING 2.1 Creating Partitions with GNU/Linux as the Sole Operating System

| DEVICE | FILESYSTEM TYPE | SIZE | MOUNT POINT |
|---|---|---|---|
| hda1 | Linux native | 118MB | /boot |
| hda2 | Linux native | 9996MB | / |
| hda3 | Linux native | 5500MB | /home |
| hda4 | Linux swap | 509MB |  |

Listing 2.2 shows an example filesystem set up for a dual-boot computer. This example is for a computer that was originally set up to run Microsoft Windows. It was partitioned before the installation to make room for GNU/Linux, it has a 6.5-gigabyte hard drive, and 64 megabytes of RAM.

### LISTING 2.2 Creating Partitions on a Dual-Boot Computer

| DEVICE | FILESYSTEM TYPE | SIZE | MOUNT POINT |
|---|---|---|---|
| hda1 | Win98 FAT32 | 3000MB |  |
| hda2 | Linux native | 7MB | /boot |
| hda3 | Linux native | 2865MB | / |

| hda5 | Linux swap | 128MB |  |

After you have set up the different partitions for the filesystem, the partitions need to be formatted. If this is your first GNU/Linux installation, you will want to format all the filesystem space as Linux native and the swap space as Linux swap. You are also given the opportunity to check for bad blocks (or errors) on the hard drive before the drive is formatted. You should check for bad blocks as a precautionary measure.

## Deciding Which Software to Install

If you selected the custom installation class, you will be asked to select from a list of package groups. To install all the software, you will need at least 1.3 gigabytes of hard drive space in the root partition. Listing 2.1 shows the root partition on the device named hda2 (which has 9996 megabytes of space). Listing 2.2 shows the root partition on device hda3, which has 2865 megabytes of space.

![](img/782ecfdc0b083a767896cc983e10427f_53_0.png)

> > If you purchased the boxed Linux-Mandrake distribution, you may have more than one CD-ROM. You will be asked if you have the second CD-ROM. You will also be prompted as to when to change CD-ROMs.

If the root partition on your system does not contain enough space, you will need to deselect package groups from the list. If you aren't sure which packages to deselect, just leave them all selected and the installation process will decide how much room is available and make its own decision about how much software to install. The installation program will install the most popular and commonly used applications first, and then will continue to add applications (using its own priority scheme) until most of the partition is filled.

![](img/782ecfdc0b083a767896cc983e10427f_53_1.png)

> > As you progress through this book, you might find that you do not have an application on your system. You can easily install more software from the CD-ROM. Just turn to Hour 15, "Installing Software."
