Q I understand that cron will run a command many times depending on the parameters set in the crontab entry. But what do I do if I want to schedule a command to run only one time?

A When you want to run a command or a process only once, you can use the at command. The at command can be used to queue a job for execution at a specified time and to examine or delete the jobs queued for later execution. To use the at command, type at followed by the time at which you want the command to run and press Enter. On the next line you'll see at>. Type the command and press Enter. When you are finished entering command, press Ctrl+D.

Q Is it possible to add my own manual pages to the system so that I can access them with the man command?

A Yes. You can create a plain text file and then store it in the appropriate directory under /usr/man. For more instructions, read the Linux Man Page mini-HOWTO.

## Quiz

1. What is a core dump and what will you find inside the core dump file?

When a program crashes or when there is some other error while you are working in Linux, a core dump is written to a file. This file is written to your home directory. The core dump file contains the process information that is stored in memory at the time of the failure. There is a lot of information in this file, but it takes someone with programming skills to really understand what is going on. You might be able to find out what caused the core dump by running the gdb program.

2. What can you do if you do not want core dump files stored on your computer?

You can set a limit on the size of a core dump file with the ulimit command. To set the core dump size to zero (which means that no core dump file can be written), use the ulimit -c 0 command.

3. What are a few of the system log files that you'll find in the Linux filesystem?

The main system log is called /var/log/messages and contains information gathered by the kernel during the boot process. The login time and the duration of a user's session are stored in the /var/log/wtmp file. When you want to know which users are currently logged in to the system, look at the /var/log/wtmp file. If you only want to see user login times, look in the /var/log/lastlog file.

4. Which command makes it easy to rotate system logs so that they don’t pile up on the system and use up a lot of space?

The logrotate command controls how system log files are handled. The logrotate command can be set up to empty the data in a logfile by saving it to another file that can be compressed, deleted, or mailed to a user on the system. The logrotate command operates based on information found in a configuration file.

5. What are the six fields that are contained in a crontab entry?

The first field is the number of minutes after the hour that you want the command to run. It can use a value between 0 and 59. The second field is the hour at which you want the command to run. This field uses a 24-hour clock and the acceptable values that can be used are between 0 and 23. The third field is the date during the month on which you want the command to run. Acceptable values are 1 to 31. The fourth field is the month and can use two different types of values: You can either use a number to indicate the month (from 1 to 12), or you can use the three-letter abbreviation for the month (such as Jan for January). The fifth field is the day of the week on which you want the command to run. The value can be from 0 to 6, or you can use the three-letter abbreviation for the day (such as Sun for Sunday). The sixth field is the command that you want to run automatically at the time specified in the first five fields.

## Installing the X Window System

Linux uses an external application to provide multimedia services. This is much different than the systems that control the video and audio through a part of the operating system software. The X Window System could be called Windows for UNIX. It does all the same things that Windows does, such as controlling the launching and management of graphical applications in separate windows on your computer screen. But the X Window System actually does much more than that, as you will see. The X Window System provides the means to control the video display and multimedia devices on your Linux box through an application called an X server.

In this hour, you will

- Learn how the X Window System works
- Prepare before configuring the display
- Configure the video display so that X works on your system
- Change the video resolution and color depth on-the-fly

## What Is the X Window System?

When you installed the Linux operating system, you were given the opportunity to configure the X Window System so that you can take advantage of one of the full-blown graphical interfaces available for Linux, such as KDE and GNOME. After you select and configure the right X Window server for your system, it supplies the video, the audio, and the controls for peripheral devices such as the keyboard and the mouse. The X Window System even has tools for configuring the Linux kernel. It can also do all the things listed here on someone else's screen.

Having the X Window System installed on your computer makes it possible for you to take advantage of the world of free software that's available for use with X. The X Window server can operate your CD writer, connect to your video camera and VCR, play movies and music CDs, provide a single interface across multi-platform networks, and a single X server can manage the display on many machines at the same time. X can also run MS Windows in an X window.

## How It Works

The X Window System is an application that is run by your computer. X Window is a server that provides multimedia capabilities for your Linux box. If you elected to install the X Window System when you installed Linux, you'll find all the tools and utilities that you'll need for selecting, configuring, and tuning an X server to fit on about any graphics card, monitor, and operating system combination in existence.

## What You'll Need Before You Begin

Hopefully, when you installed Linux, the X server was installed properly so that you can use a graphical user interface. It's easy to start the graphical interface from the text console. After you log in, type startx and press Enter. The default desktop environment (usually KDE or GNOME) will start. If you aren't completely satisfied with the results, you can make changes to get a better display. But before you can fine-tune your display, you'll need some of the information that you collected in Hour 1, "Gearing Up for the Installation." Here's the information that you'll need to get started:

- The keyboard language and number of keys
- The type of mouse (PS/2 or serial, number of buttons)
- The manufacturer and model for the monitor along with the maximum resolution, vertical refresh rate, and horizontal refresh rate
- The manufacturer and model of the video card, type of graphics card and chipset, amount of video memory, and color depth (8-bit, 16-bit, 24-bit, 32-bit)
