First things first: name the connection. You might want to use the name of your ISP, or if you have several accounts, use a descriptive name that tells the purpose of the account (whether for personal use or business use). Next, type the phone number used to access the ISP's servers and the authentication protocol (PAP, CHAP, etc). Then, click the DNS tab and enter the primary and secondary DNS addresses needed by the ISP. When all this is entered, click OK. You'll be returned to the kppp Configuration window and you'll see the connection name in the list of accounts.

The dialup connection is almost ready. Click OK one more time to get back to the main kppp window (shown in Figure 21.4) where you'll see the connection name one more time. All you need to do is type your username and password and click the Connect button. After the modem makes the connection, you're ready to surf to your heart's content.
