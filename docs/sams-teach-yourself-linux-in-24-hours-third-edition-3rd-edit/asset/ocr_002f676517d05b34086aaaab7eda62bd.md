# Exercises

+   1. Use the system information found in the `/var/log/messages` and `/proc` files in your Linux diary/system administrator notebook. You'll need this information if you decide to add new hardware to the system or make any configuration changes. You can use what you learned about the `cat` command (Hour 7, "Moving Around the Filesystem") to copy these files into another file. For example, to copy the contents of the `/proc/pci` file to a file named sysinfo, type `cat /proc/pci > sysinfo` and press Enter. Then, you can edit and format the file named sysinfo so that it looks good in your notebook. Remember, you can also append several files to the end of an existing file.
+   2. Make a list of the system configuration files that you might have to edit in the near future. Back up each file and store the backup copies on a removable storage media (such as a floppy or Zip disk) and keep it in a safe place. You'll also want to keep each individual configuration change in a separate backup file. Better safe than sorry is the advice for today.
