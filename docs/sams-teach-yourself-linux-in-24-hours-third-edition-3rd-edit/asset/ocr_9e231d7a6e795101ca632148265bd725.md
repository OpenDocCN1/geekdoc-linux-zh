# Quiz

+   1. What function does the supermount feature found in some distributions perform?
+   Supermounting a drive gives you automatic access to the drive. You do not need to manually mount the drive (using the mount command) before you can use work with the files contained on the media.
+   
+   2. Where can you find information about the filesystems that are mounted on the system?
+   One source is the /proc/mounts file. You can view this file in a text editor, the less pager, or by using the cat command. Another method is to display the kernel boot message in the /var/log/messages file, which can be viewed with the dmesg command. Another source is the /etc/fstab file.
+   
+   3. What command do you type to mount a floppy disk drive?
+   Type mount /dev/fd0 /mnt/floppy and press Enter. If a mount directory (such as /mnt/floppy) does not exist, you can create this directory with the mkdir command.
+   
+   4. Instead of working with floppy drives the Linux way, do you have another option?
+   Look for the mtools package. This collection of commands enables you to work with directories and files on a floppy disk in the same way as floppies on a DOS system. You don't use Linux filesystem device names or mount points; you can use the A: designation for the floppy disk drive. A filesystem does not need to be mounted to work with mtools.
+   
+   5. What information is found in the /etc/fstab?
+   The device file, the mount point, the filesystem type, boot options, backup frequency, and filesystem checking.
