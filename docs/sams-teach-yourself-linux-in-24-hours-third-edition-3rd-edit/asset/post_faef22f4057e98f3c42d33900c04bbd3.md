
## 4. Which command can you use to reduce the size of a file?

The gzip command is used to compress files. The reason for compressing files is to save space on your storage media. You may also want to compress files before you send them as attachments to email messages. You can also compress files to create more space on the hard drive. You can easily uncompress a file when you need to work with it.

## 5. Why should you consider attaching an uninterruptible power supply to your computer?

Severe weather conditions and car accidents are major causes of power outages, power surges, and brownouts. When the computer unexpectedly loses power, important data can be lost. If Linux does not shut down properly, there could be damage to the operating system. A UPS protects the computer from violent spikes in the electrical current and gives you time to save your work and shut down the system.

## 6. How do you create an archive in which to store files?

The tar command combines several files into one file and saves the original directory structure. When the archive is restored onto the system, the files are returned to their original directories. If those directories do not exist on the system, they will be created when the archive is unpacked.

## Understanding the Linux Print Services

Before you can print any documents from the cool GNU applications that you've been learning about, you need to configure a printer. Linux doesn't provide any comfortable plug-and-play, auto-detecting hardware and easy installation methods for printers.

In fact, Linux has a complex printing system that allows many users to print to several computers at one time. Linux doesn't care if all the printers are busy; it can patiently hold onto a print job until the printer is ready.

When you press the print button in an application or execute the lpr command, as shown in Figure 11.1, the command takes the file and temporarily stores it in a holding area called a spool directory. The file waits in the spool directory until the line printer daemon (the lpd) realizes that there is a file waiting to be printed. At this point, the lpd makes a copy of itself, grabs the file in the spool, and waits with the file until the printer is available. Then, when the printer is free, lpd and the file head off to the printer where the file is printed.

**New Term** The print spool is a directory in the filesystem in which files are temporarily stored until they can be sent to the printer.

If there are several printers attached to the system, each printer has its own spool directory. You would tell the lpr command which printer you want the file to print to by specifying the spool directory associated with that printer. The line printer daemon spawns an lpd for each spool directory on the system.

## Task: Attaching the Printer to the Computer

Before you can configure printing services in Linux, you must attach the printer to the computer and make sure that the operating system can connect to the printer port and communicate with the printer. Before you set up printing services, follow these steps to make sure the printer is operating correctly:

1. Check the printer compatibility with the Linux operating system. One source of information is the Linux Hardware Compatibility HOWTO. You may also want to read the Linux Printing HOWTO.
2. Attach the printer to the computer. Shut down the computer and turn off the power. Attach the printer's serial or parallel port cable, plug in the printer's power supply, and turn on the printer. Turn on the computer and start the operating system.
3. Determine the port to which the printer is attached and the printer device being used. Type `dmesg | less` and press Enter. You may need to scroll to the bottom of the file (use the spacebar to scroll down one screen at a time) to find the printer information. Here's an example of printer information found by the kernel during the system boot:
4. Make sure that the connection between the device file and the printer works. Type `ls > /dev/lp0` and press Enter. Alternatively, if the printer is connected to lp1, type `ls > /dev/lp1` and press Enter. The printer should print the current directory listing.

```
parport0: PC-style at 0x378 [SPP,PS2]
parport0: Printer, Hewlett-Packard HP LaserJet 1100
lp0: using parport0 (polling).
```

Printers usually use the lp0 or lp1 printer device. The last line in the preceding listing shows that the lp0 printer device is being used by the printer. This means that the device file for the printer is named /dev/lp0. If your listing shows lp1, the printer device file is named /dev/lp1.

## Configuring the Print System

Once the printer is attached and can communicate with the operating system, you'll need to set up the print system. This involves giving the printer a name, assigning a directory to the print spool, specifying the printer device file, and telling the line printer daemon a few specifics about the printer hardware.

Many Linux distributions contain their own special tools for configuring a printer to work with the operating system. Linux-Mandrake uses DrakConf to set up a printer. The printer configuration tool in DrakConf is based on the Red Hat Linux Print System Manager (also known as printtool). TurboLinux uses the TurboPrintCfg utility to set up a printer. You'll find that the information requested by TurboPrintCfg is the same as printtool; only the interface is different.

No matter which printer configuration utility you choose, all of these programs write the information that you supplied to the /etc/printcap file.

![](img/782ecfdc0b083a767896cc983e10427f_203_1.png)

If you are unfamiliar with all the technical workings of the Linux printing system, it is recommended that you use one of the printer configuration utilities to set up a printer. Editing the file improperly can cause problems with the other configuration utilities later on. Only experienced users should manually edit the /etc/printcap file to create printing services.

## Task: Setting Up a Local Printer

You can use a variety of distribution-specific tools to set up your printer to work with Linux, but most of them look vaguely similar to the Red Hat Linux Print System Manager tool, or printtool for short. Here's how to use the printtool to write the printer configuration information to the /etc/printcap file:

1. Log in to the superuser account.
2. Open a terminal emulator and type printtool and press Enter. You may see a series of error messages that inform you of packages that are not installed on the system. Click OK to clear the error messages and to display the main printtool window, as shown in Figure 11.2.
3. Click the Add button. This displays the Add a Printer Entry dialog box.
4. Select the Local Printer option and click OK. The printtool auto-detects which printer device is in use and displays the detected ports in the Info dialog box. Make a note of the detected device.
