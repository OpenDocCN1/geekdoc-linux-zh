# Installing a Window Manager

A window manager is not absolutely necessary. It is quite possible to run X Window applications without a window manager, but it’s a pretty limited show. Window managers are software applications that manage the appearance and placement of windows on your screen. Window managers draw the window borders and decorations, and they provide the scrollbars and bells and whistles. The X server is actually responsible for drawing everything on the screen, but window managers give the desktop a particular look and feel and many provide a method for launching applications.

In this hour, you will

+   - Learn about the different window managers that are available on your system
+   - Change the window manager for your graphical desktop
+   - Find more information about what you can do with the X Window System
