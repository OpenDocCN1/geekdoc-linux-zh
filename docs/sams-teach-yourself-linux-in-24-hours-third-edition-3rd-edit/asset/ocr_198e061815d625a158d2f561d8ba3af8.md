+   3. Press the B key to move back one screen through the manual page.
+   4. To move one line at a time through a manual page, press Enter.
+   5. If you want to search the manual page for a specific word, type a slash character (the / appears at the bottom of the screen), followed by the search term, and press Enter. Every occurrence of the word searched for will be highlighted in the manual page.
+   6. When you are finished reading the manual page, press the Q key. The pager will close and you will be returned to the shell prompt.

# Deciphering the Manual Page

There’s a lot of information in the manual pages, but it might be hard for a new Linux user to understand. Each manual page describes a command and how it works. Table 6.4 gives you a brief rundown of the main parts of a manual page.

TABLE 6.4 What You’ll Find in a Manual Page

| Section Name | Contents |
|---|---|
| Name | The name and a short description of the command |
| Synopsis | How the command is used and a list of the associated command-line options |
| Description | An explanation of the program and options |
| Options | A list of all the command-line options, along with a brief description of how to use each option |
| See Also | Other manual pages that reference similar information |
| Diagnostics | Descriptions of any error messages you might encounter |
| Bugs | Known problems associated with use of the command or program |
| History | A record of the development of the program |
| Author | A list naming the author of the program and other contributors |

The two sections of the manual page that tell you how to use the command are the Synopsis and Options section. The Synopsis section shows the syntax for the command. The command options fit into the syntax and modify the actions of the command. Options allow you to fine-tune a command so that it gives you the output in a form that is useful to you.
