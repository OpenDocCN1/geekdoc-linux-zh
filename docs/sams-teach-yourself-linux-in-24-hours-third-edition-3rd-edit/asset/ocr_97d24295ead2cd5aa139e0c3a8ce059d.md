4. Which command makes it easy to rotate system logs so that they don’t pile up on the system and use up a lot of space?

The logrotate command controls how system log files are handled. The logrotate command can be set up to empty the data in a logfile by saving it to another file that can be compressed, deleted, or mailed to a user on the system. The logrotate command operates based on information found in a configuration file.

5. What are the six fields that are contained in a crontab entry?

The first field is the number of minutes after the hour that you want the command to run. It can use a value between 0 and 59. The second field is the hour at which you want the command to run. This field uses a 24-hour clock and the acceptable values that can be used are between 0 and 23. The third field is the date during the month on which you want the command to run. Acceptable values are 1 to 31. The fourth field is the month and can use two different types of values: You can either use a number to indicate the month (from 1 to 12), or you can use the three-letter abbreviation for the month (such as Jan for January). The fifth field is the day of the week on which you want the command to run. The value can be from 0 to 6, or you can use the three-letter abbreviation for the day (such as Sun for Sunday). The sixth field is the command that you want to run automatically at the time specified in the first five fields.
