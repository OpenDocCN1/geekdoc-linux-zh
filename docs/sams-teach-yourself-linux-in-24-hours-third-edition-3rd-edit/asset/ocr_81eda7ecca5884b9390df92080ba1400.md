Q The mouse doesn't work right. What did I do wrong?

A Most likely, you selected the wrong mouse protocol in the xf86config program. You might want to go back and select a different mouse.

# Quiz

+   1. What type of information will you find in the /etc/X11/XF86Config file?
+   The most important information is that which pertains to the video display—the monitor specifications and type, the video card, the keyboard type, and the mouse protocol. Other information found in this configuration file is the location of color palettes and font libraries.
+   
+   2. What system information do you need before you can correctly configure the X Window System?
+   You'll need to know the keyboard type, the language, and number of keys. For the mouse, you'll need to know the mouse protocol and the number of buttons. For the monitor, you'll need the manufacturer and model number, the maximum resolution, vertical refresh rate, and the horizontal refresh rate. For the video card, you'll need the manufacturer and model, the type of graphics card and chipset, amount of video memory, and the supported color depths.
+   
+   3. If you have problems configuring the X Window System for your computer, what resources should you look up before you attempt to run the xf86config program?
+   There is quite a bit of information stored in the Linux filesystem. Look in the /usr/X11R6/lib/X11 directory. In there you'll find a list of compatible monitors (the MonitorsDB file) and video cards (the CardsNames files). In the /usr/X11R6/lib/X11/doc directory, there is a quick start guide that you should read before you begin the configuration process. This directory also contains readme files for the different supported video cards. There are also readme files for mouse and other pointing devices.
