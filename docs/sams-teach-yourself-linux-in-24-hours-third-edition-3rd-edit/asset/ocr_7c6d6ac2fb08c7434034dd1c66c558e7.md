+   4. Type rawrite.exe and press Enter. The rawrite program interface appears and needs input.
+   5. Specify the disk image source filename. For Linux-Mandrake, and TurboLinux type D:\images\cdrom.img and press Enter. For Red Hat, type D:\images\boot.img and press Enter. In Slackware, type D:\BOOTDSKS.144\bare.i and press Enter.
+   6. Specify the target disk drive (this is the floppy disk drive). Type A: and press Enter. You are then asked to place the disk into the drive. After this is done, the files will be copied to the disk.
+   7. Remove the disk when the copy process is finished. Be sure to label the disk appropriately. For example, if you chose to install the Linux-Mandrake distribution found on the CD in the back of this book, label the disk "Linux-Mandrake 7.1. Installation Boot Disk."

As you've seen, each distribution handles the creation of installation boot disks differently. If you had problems creating a boot disk using these instructions, you should browse the distribution CD-ROM to see whether there are any special instructions for using rawrite and creating the boot disk.
