Here are a few things to look for when choosing a Linux distribution:

+   - What's packaged with the distribution CD-ROM? If you buy the boxed set, you'll most likely find the distribution CD-ROM, a CD-ROM with the source code for all the applications, a CD-ROM with extra programs (such as StarOffice or WordPerfect), boot disks, and an installation guide. If you buy the distribution CD-ROM without all the fancy extra, you'll find electronic versions of the distribution's documentation on the CD-ROM.
+   - Do you need technical support? Many distributions offer support for a certain number of days. This support is usually limited to helping you install the distribution on your computer system. But, be aware, there isn't much that technical support can do for you if you are running incompatible hardware. We discuss hardware later in this chapter.
+   - How easy is it to install the distribution? The biggest hurdle to any new Linux user is installing the operating system. When first starting out, you'll want a distribution that contains plenty of help information for the installation, can automatically detect computer hardware, and contains other tools to guide you through the installation.
+   - How will you be using the Linux system? Each distribution allows you to select from a set of installation types, or to selectively pick those applications that you want installed. We recommend that you select one of the installation types; there's bound to be a profile that fits you. Each distribution contains different installation types, but you will find configurations for basic workstations, systems that run mainly graphics programs and utilities, workstations that connect to a network, an Internet connection and Web browsing, network servers, and Web hosts.
