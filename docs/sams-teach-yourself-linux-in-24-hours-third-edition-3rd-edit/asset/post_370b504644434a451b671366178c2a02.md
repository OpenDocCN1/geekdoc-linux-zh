## Task: Viewing the Command History List

The shell keeps track of the last 500 commands that you've typed. If you've used the command line frequently, using the arrow keys to scroll through the command history list might take some time. An easier way to see the commands you've used is with the history command. Here's how to easily list those commands you've used and select a command from the list to execute.

1. To see the command history list, type history and press Enter. The previously executed commands appear in a list. You'll see a number to the left of the command. An example of a history list is shown in Listing 6.1. This list contains two columns. The first column indicates the order in which the commands were typed. This is also the number you use to execute a command from the list. The second column is the command as it was executed.

### LISTING 6.1 Sample Output of the history Command

```
1 startx
2 man adduser
3 man passwd
4 shutdown
5 vi practice.txt
```

2. Search through the list until you find the command that you want to execute. To execute the command, type !number and press Enter, where number is the number in the first column of the history list that corresponds to the command you want to use. Using Listing 6.1, to start the X Window System (shown as 1 startx in the example), type !1.

3. If the command history list is longer than your screen, type history | less. This sends the command to the less pager and you can use the up- and down-arrow keys to scroll through the list. To exit the pager and return to the shell prompt, type q.

4. You might only want to see the last few commands that you've typed. To see the last 10 commands, type history 10 and press Enter.

## Understanding the Manual Pages

So far, you've been introduced to a few of the commands that you'll be using on your Linux system and you've seen how commands are structured. Now it's time to find out where you can locate more information about those commands and how to use them.

When you want information about a command, whether it's a description of a command or a list of command options, head to the Linux manual pages (also known as the man pages). A manual page is displayed on your screen (through a utility called a pager) when you use the man command to request information on a topic. The pager is used to read the contents of a manual page.

### The Syntax for the man Command

The manual pages are the system reference pages for the commands installed on the system. When the man command is executed, it searches through the manual page titles for the topic that you request. The following code shows the syntax for the man command:

```
man [options] [section] topic
```

Where:

- The topic parameter is normally the name of a command (also the title of the manual page). At a minimum, you need to use the man command with a topic. For example, typing man man displays the manual page about the man command. This manual page describes how manual pages work. Typing man ls displays the manual page that describes the different ways in which the contents of a directory can be listed. Table 6.4 shows the contents of each of the sections.
- There are several options that you can use with the man command to change the default output. Sometimes more than one manual page for a command exists, but the man command displays only the first manual page that it comes across. To display other related manual pages, one after another, use the man command with the -a option (type man -a and press Enter).
- The section parameter is used if you want to change the order in which the man command searches through the manual page directories for the topic you request. This is useful if there is more than one manual page for a command. Table 6.5 shows the different directories contained in the manual page system.

## Task: Reading the Manual Page for the man Command

When a manual page is requested, it is displayed in one of two pagers—more or less. By default, the manual pages on your system should display in the less pager. Because most manual pages take up more space than is available on your screen, you'll need to learn a few commands to read the entire manual page in the pager. The best way to become familiar with the man command and reading the manual pages in a pager is to read the manual page for the man command. Here's how to display the man manual page:

- 1. At the shell prompt, type man man and press Enter. The manual page for the man command appears on the screen. You will see only a portion of the manual page, depending on the size of the screen (see Figure 6.3).

## Deciphering the Manual Page

There’s a lot of information in the manual pages, but it might be hard for a new Linux user to understand. Each manual page describes a command and how it works. Table 6.4 gives you a brief rundown of the main parts of a manual page.

### TABLE 6.4 What You'll Find in a Manual Page

| Section Name | Contents |
|---|---|
| Name | The name and a short description of the command |
| Synopsis | How the command is used and a list of the associated command-line options |
| Description | An explanation of the program and options |
| Options | A list of all the command-line options, along with a brief description of how to use each option |
| See Also | Other manual pages that reference similar information |
| Diagnostics | Descriptions of any error messages you might encounter |
| Bugs | Known problems associated with use of the command or program |
| History | A record of the development of the program |
| Author | A list naming the author of the program and other contributors |

The two sections of the manual page that tell you how to use the command are the Synopsis and Options section. The Synopsis section shows the syntax for the command. The command options fit into the syntax and modify the actions of the command. Options allow you to fine-tune a command so that it gives you the output in a form that is useful to you.

## Task: Modifying the Output of the man Command

All commands use command options to customize the actions of the command. Here's some practice using command options with the man command:

- 1. Type man -a man and press Enter. This command tells the less pager to display all the manual-pages that are named "man."
- 2. When the first manual page appears, use the spacebar to scroll through the document.
- 3. When you are finished reading the first manual page, press Q. The pager formats the second manual page for the man command that explains macros that format manual pages.
- 4. Read the manual page. Press Q when you're done and you will be returned to the shell prompt. Remember, for our example user rusty, it looks like this:

```
[rusty@localhost rusty]$
```

## Changing the Search Order

The manual pages are organized into several directories and manual pages are categorized into these directories. If you want to search in a specific directory for a manual page, just specify the directory number in the sections parameter of the man command syntax. You can also search the directory structure of the manual pages in a specific order. Table 6.5 shows the directory structure used by the manual pages and what can be found in each directory.

### TABLE 6.5 Directory Structure of the Manual Pages

| Directory | Contents |
|---|---|
| /usr/man/man1 | Commands that run from within a shell |
| /usr/man/man2 | Documentation on system calls |
| /usr/man/man3 | Manual pages for the libc functions |
| /usr/man/man4 | Information about files in the /dev directory |
| /usr/man/man5 | Details of formats for special files such as /etc/passwd |
| /usr/man/man6 | Games |
| /usr/man/man7 | Descriptions of the Linux filesystem and man pages |
| /usr/man/man8 | Pages for root operator utilities |
| /usr/man/man9 | Documentation on Linux kernel source routines |
