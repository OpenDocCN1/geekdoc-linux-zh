# Exploring the File Manager

When the file manager opens, the list of files and subdirectories found in a selected directory appear as icons with only the filename as a description. The four buttons on the right side of the toolbar change the appearance of the icons and the file information that displays. Here is a brief description of each of the display options:

+   - The Icons view gives a quick way to look at a file listing. The icons represent different file types, and the name of the file appears below the icon.
+   - The Brief view is a simple listing of the directory contents. There are icons for directories only; files are shown as a filename only. This displays the same listing as the ls command.
+   - The Detailed view lists the filename, the file size, and the date and time that the file was last modified.
+   - The Custom view lists the filename, file size, and file permissions (which you learned about in Hour 12, “Sharing Files with Other Users on the System”).

![](bbox=[0.12, 0.7, 0.18, 0.8])

> The information displayed in the Custom view can be customized. Select Settings, Preferences to display the Preferences dialog box. Click on the Custom View tab to add and delete columns from the file list.

Before you can work on any files, change any filenames, or make copies of a file, the file must first be selected. The conventions for selecting files are pretty much the same from file manager to file manager (and even across operating systems). You can even have the file manager select files for you based on certain parameters that you specify.

Selecting files using the mouse is relatively straightforward. Here’s a hint: Use the Brief or Detailed view to make it easier to select files. Try these tricks to select files with the mouse:

+   - Click on a filename to select a single file.
+   - Select contiguous files by clicking the first filename, holding the Shift key, and clicking the last filename in the block of files with which you want to work.
+   - Select random files in the list by clicking on the first filename, holding the Ctrl key, and clicking on any other files that you want to select.
