## Spawning Processes

Linux defines running programs, applications, utilities, and daemons (servers) as processes. As mentioned earlier, Linux maintains a virtual filesystem in the /proc directory, where it maintains pointers to all the ongoing processes in the system. Linux is a true multitasking operating system, meaning it can do more than one thing at a time. To accomplish all this, the Linux kernel just calls up a few daemons, and the daemons take over and perform the job, doing whatever is necessary.

It isn't quite that simple, but here is a real-world example of the kernel calling up the oldest daemon to get a job done. Suppose you have a document that you want to print, so you send a print command to the kernel. The kernel doesn't know enough about printing to do the printing itself, so it calls lpd, the line printer daemon.

> The line printer daemon (lpd) is the oldest daemon. In the very beginning of the computer age, the only output from computers was to a loud, obnoxious device called a line printer. The modern line printer daemon is much more sophisticated, but it still has the same name.

The lpd takes the print job from the kernel and spawns (forks is another term often used). This just means that it makes a copy of itself. Then the lpd gives the job to its clone, along with all the details about which printer and where and when, and sends it off to do the printing. The original lp daemon goes back to hanging out close to the kernel in case it gets called again. This allows the kernel to use the lp daemon to run many print jobs at once on many different kinds of printers—a real example of true multitasking.

## Task: Reading the Kernel Boot Messages File

Several system log files will help you find out what the operating system is doing. These files are usually found in the /var/log directory. One file that you should look at is the dmesg file. This file contains all the messages from the kernel during the boot process. Here's how to view system log files:

- 1. Log in as the superuser. Type su and press Enter. You will be prompted for the password for the root account.
- 2. Read the messages that scroll by on the screen when you first boot the Linux operating system. Find the command line and type less /var/log/dmesg and press Enter. Your screen will look similar to the one shown in Figure 4.6.

## Q&A

Q I'd like to learn more about the Linux filesystem. Do you have any good references?

A The standard for the Linux filesystem structure can be found at www.pathname.com/fhs/1.2/fsstnd-toc.html. This standard details the types of files you'll find within each directory.

Q What is the easiest way to read the help files in the /usr/doc directory?

A Because much of the help information is written as HTML files, you may want to start the X Window System and your favorite desktop environment. Select a graphical file manager and navigate to the /usr/doc directory. If you double-click any of the HTML files, these files will most likely open in Netscape Navigator. If the file manager does not know which application in which to open the file, you'll be asked to choose one. You can try one of the many text editors installed on the system.

Q How can I display the processes that are running on my system?

A Try the top command. From the shell prompt, type top and press Enter. The top command shows you which users are logged in and in which commands, applications, and services they are using. You'll learn more about processes in Hour 13, "Working with Processes."

## Quiz

- 1. What is the job of the Linux kernel?
- The Linux kernel is the piece of software that controls the operating system. The kernel provides an interface between the user and the computer hardware and is responsible for maintaining the filesystem, executing commands, starting programs, timing system activities, and managing system memory and other resources.

- 2. Besides your home directory, what is the safest and most informative directory for you to explore in the Linux filesystem?
- The /usr directory contains files that are available to all authorized system users. The files in this directory are write-protected so that they cannot be altered. The /usr directory contains execution files (in /usr/bin) for many of the applications installed on the system. There's also quite a bit of help information in /usr/doc.

- 3. What are the three types of files found in the operating system?
- User data files, system data files, and executable files can be found in the operating system. User data files are files created by users when working with applications. User data files can be anything from a simple text file to a database or a complex graphic. System data files help the operating system run the computer. Executable files are the commands and applications that are installed on the system.

- 4. How long can a Linux filename be?
- A filename can be as long as 256 characters, but the filename includes the directory path to the individual file and the name of the individual file.

- 5. What is the easiest way to create a small file?
- Use the cat command by typing `cat > filename`. When you start this command, the cursor moves to the next line on the screen. Just begin typing to add text to the file. When you have reached the end of a line, press Enter to go to the next line. To save the file and close it, press Ctrl+D.

- 6. What is the purpose of system log files?
- System log files let you see what is going on with the operating system. You can read the messages that appear when the system boots and find out who is using the system and whether any security breaches occurred.
