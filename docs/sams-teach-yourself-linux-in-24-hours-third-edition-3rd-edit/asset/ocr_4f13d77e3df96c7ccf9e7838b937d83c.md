# Q&A

Q I connect to my ISP through a cable modem. Is Linux able to use my cable modem?

A Yes, for more information, read the Cable Modem HOWTO and the Linux Modem HOWTO.

Q I have a voice/data/fax modem. What programs can I use to send a fax from my computer?

A KSendFax is an easy to use digital fax machine. You'll find KSendFax with the KDE desktop environment. If you don't see it in the menu system, type ksendfax at the command line. To learn more about KSendFax, open the application's Help menu and read the KSendFax Handbook. There are other fax applications at metalab.unc.edu/pub/Linux/apps/serialcomm/fax/INDEX.html.

Q Are there any sources of ready-made shell scripts that I can tailor to fit my needs?

A If you go to the MetaLab Linux Archive at metalab.unc.edu/pub/Linux/utils/scripts/INDEX.html, you'll find a few useful script templates. You'll find a script that will check the hyperlinks in an HTML file for consistency, a script that helps you keep a notepad, a script that lists every file on your system, and a number of other scripts to help automate system administration tasks.

# Quiz

+   1. What information do you need to collect from your ISP so that you can create a dialup PPP connection to get on the Internet?

You'll need the phone number that the modem needs to dial to access the ISP's servers, your username and password to identify you as an authorized user, the authentication protocol your ISP uses (PAP, CHAP, etc.) and the DNS addresses needed so that your computer knows which computer to use as its gateway to the Internet. You should also know whether your ISP uses dynamic IP addressing or static IP addresses (chances are, it is dynamic IP addressing). If you want to access an email account or read the Internet newsgroups, you'll need an email address, the name of the email server, and the name of the news server.
