+   - Before you can access any filesystem on the computer, the filesystem must be mounted; that is, the filesystem must be associated with a particular directory. The file that controls the mounting of filesystems at boot time is the `/etc/fstab` file. You might need to edit this file if you add a new hard drive, Zip drive, or CD-ROM drive to the computer.
+   - To start a process when the operating system boots, edit the `/etc/inittab` file. A process can be a program, a command, or a scheduled job.
+   - Printers are added to the system with the `/etc/printcap` file. This file contains the make and model of the printer, the port to which it is connected, and where the print spool is located.
+   - To work with the X Window System, you will need to configure the monitor. The settings for the monitor model and type, refresh rates, screen resolution, and color depth are configured in the `/etc/X11/XF86Config` file.
+   - As the system administrator, you are responsible for adding and deleting accounts for each user and group that will be working on the system. One way to add new users is to edit the `/etc/passwd` file. To add group accounts to the system, edit the `/etc/group` file.

> > It is very dangerous to tinker with the password and group files and you must be careful to make backups of all configuration files before you edit anything in them. The methods for doing this can be found in Chapter 12, "Sharing Files with Other Users on the System."

+   - Creating an Internet connection involves creating two scripts and editing one file. You will need a script that uses the modem to make the dial-up connection, and another script to exchange data such as your username and password. Then, so that the system can find a domain name server, edit the `/etc/resolv.conf` file.
+   - You might want to set up a TCP/IP network to run a network for your home or small business. To set up a network, information such as IP addresses, gateway addresses, and hostnames for each computer attached to the network needs to be added to (depending on your particular distribution) the `rc.inet1`, `rc.inet2`, `/etc/hosts`, `/etc/networks`, `/etc/hosts.conf`, and `/etc/resolv.conf` files.
