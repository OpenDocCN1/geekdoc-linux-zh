
Within each of these sections is an introduction page that describes the manual pages found in that directory. If you type man intro, the intro page for the /usr/man/man1 directory displays. If you want to read the intro page for commands relating to the Linux filesystem (found in the /usr/man/man7 directory), type man 7 intro.

The manual page directory structure is not searched in strict numerical order. Instead, the first directory (/usr/man/man1) is searched, followed by the eighth (/usr/man/man8) directory, and then back to /usr/man/man2, /usr/man/man3, /usr/man/man4, through to /usr/man/man9. The man command searches through the manual page directories until it finds a match to your search request.

## Some Helpful Search Commands

As you might be beginning to see, the job of learning about the Linux operating system is a big job. There are so many commands that it's a pretty big job just to find out about them (let alone learn how to use them). There's also the vast quantity of software that installs with each Linux distribution. There are several commands that search your system and return different types of information about the files located in the filesystem.

## Locating Files on the System

The search command that you'll find yourself using most often to look for files on the system is the find command. The most common use of find is to locate files. If you know the name of the file (or you can use wildcard characters if you only know part of the filename), find will search from the current directory and through all the subdirectories for the file you need. Using find to search for files is covered in Hour 7. Another task where find can prove very helpful is doing system backups (covered in Hour 10, "Backing Up and Restoring the Filesystem"). The find command can list those files that have been modified since the last backup. If several users share the system, the find command will tell you which files belong to a particular user or group of users (as you'll see in Hour 12).

## Displaying a Summary of a Program

When you come across a new command and you'd like to quickly find out what the command does, try the whatis command. Unlike the man command, which displays the full manual page, the whatis command displays only the summary line from the manual page. Then, if you think this command is one that you might use, you can then display the manual page and explore the options for customizing the command output.

> Always find out what a program or command does and how the command options modify the behavior of a program before you type the name of the program's binary file or execute a command on the command line.

## Finding a Program’s Execution File

After you have used the `whatis` command to determine what a command or program does, and then read the manual page to learn how to operate the command, you can use the `whereis` command to search through the directories that are coded into the program and to list a variety of information about the file. By using the `whereis` command, you'll learn where the binary (or execution) file, the source files, and manual pages for the command are located.

To use the `whereis` command, type `whereis` followed by the command name (remember to put a space between the two). If you want to know the location of the execution file and manual page for the `ls` command, type `whereis ls` and press Enter.

![](img/782ecfdc0b083a767896cc983e10427f_128_1.png)

When you only want to know where the execution file for a command is located, use the `which` command.

## Finding a Program to Do the Job

When you need to perform a certain task and you don't know what program or command can do the job for you, ask the `apropos` command for help. For example, you might have a document that you want to spell check, but the text editor you are using doesn't provide a spell checker. At the shell prompt, type `apropos spelling` and press Enter. You'll see several programs that might be of use. After you have a list of potential programs, use the `whatis` command to see whether the program suits your needs.

## Task: Clearing the Terminal Screen Before Leaving Your Desk

You’ll notice that if you do a lot of work on the terminal screen, there’s plenty of text at the top of the screen and the shell prompt is all the way at the bottom. What do you do when you don’t want to look at the clutter? How do you start with a fresh screen if you want to perform a different task and you don’t want remnants of the last task lurking around? Where can you hide your work when someone stops by your desk for a chat? Whenever you need a blank screen, use the clear command.

When you are finished working at your computer, it is a good idea to clear the screen of all text. You might also want to log out of your user account. By clearing the screen, no one can see what you were working on. By logging out of your account, your personal files are locked safely away and other users on the system cannot read or modify your files unless they have permission.

Here’s how to clear the screen and make your user account and files safe:

- 1. Whenever you want to erase the screen, type clear and press Enter. The text that appeared on the screen will be wiped out and all that will remain is a shell prompt (which is now at the top of the screen).
- 2. Type logout and press Enter. Your user account will be shut down so that no one will be able to access your account or files.
- 3. If you have an open user account on a second virtual terminal, switch to that terminal (by pressing the Alt key and the function key for the terminal) and log out.
