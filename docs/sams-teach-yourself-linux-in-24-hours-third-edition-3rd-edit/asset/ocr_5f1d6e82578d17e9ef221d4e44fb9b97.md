# Task: Searching the whatis Database

The whatis command is a valuable tool that gives a brief description of a command and also shows the man page directory (refer to Table 6.5) in which you'll find the manual page for the command. Here's how to search the whatis database to determine whether you want to read the manual page for the command:

+   1. Type whatis ls and press Enter. A summary of the ls command appears in the less pager, as shown in Listing 6.2.
+   2. Read the summary of the ls command. The first column is the name of the command, the second column (the number in parentheses) is the directory number, and the third column is the brief summary from the manual page.
+   3. Press Q when you are finished to return to the shell prompt.
+   4. Imagine that someone told you about this cool Linux utility called mtools that enables you to use DOS commands with Linux. To see whether there really is such a program installed on your system, type whatis mtools and press Enter. The output appears in Listing 6.3.
+   5. To read the manual pages for both the mtools command and the mtools.conf configuration file, type man -a mtools and press Enter.
+   6. Use the arrow keys and the Page Up and Page Down keys to navigate the manual page for the mtools utility.

# LISTING 6.2 The Output of the whatis ls Command

```
ls (1)      . list directory contents
```

# LISTING 6.3 The Output of the whatis mtools Command

