# Getting Ready

It's time to install the GNU/Linux operating system. If this is your first attempt, good luck! If you've tried this before and failed, you've got some experience under your belt and you should do better this time. If you've tried this before and succeeded, way to go!

This hour guides you through the installation process. Unfortunately, we can't cover every situation for every computer. The installation instructions given during this hour are intended to be guidelines to help you through the process. Most GNU/Linux distributions contain an installation manual on the CD-ROM, which you should read before you begin. The more you know about the installation process, the better off you will be.

# An Overview of the Installation Process

If this is your first attempt at installing the GNU/Linux operating system, you should familiarize yourself with the process before you begin. This is not an easy operating system to install, but if you are prepared, you can avoid a lot of frustration. Here's a summary of the steps that you will go through to install GNU/Linux on your computer:

+   - If you plan to run GNU/Linux on the same machine on which you run Microsoft Windows, you must create a separate space for GNU/Linux to live. You have two options: either add a second hard drive or partition the Windows drive. Many distributions enable you to partition the drive during the installation process. Other distributions require that a separate partition (in which the distribution will live) must be created before you start the installation.
+   - Start the installation process. You'll need the installation boot disk (that you created in Hour 1, "Gearing Up for the Installation") and the Linux-Mandrake CD-ROM (or, if you selected another distribution, use that CD-ROM). At the beginning of the installation process, you will be asked some basic questions about your system—your language, mouse, and keyboard.
+   - Set up filesystems and format partitions. GNU/Linux can store everything on a single partition—system files, configuration files, and user data files—but this is not a good idea. To make life a little simpler in case you run into problems, you should set up at least three partitions: one for swap space, one for system files, and one for user files.
