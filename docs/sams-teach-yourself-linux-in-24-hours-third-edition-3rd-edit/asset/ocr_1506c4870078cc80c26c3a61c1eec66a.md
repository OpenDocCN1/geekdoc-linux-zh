2. Display the packages installed on your system. Click Tree, See, Installed Packages. The categories of applications, utilities, and commands that are installed on your system all display in the Installed packages listing. Click the Expand Tree button to see the list of packages for each category.

3. Display information about an installed package. Scroll down the list until you find an application that interests you. Click the package name to display a description of the package (see Figure 15.3 for an example).

For each package, you'll find a description of the program, the version number, and the size of the package. At the bottom of the panel is a list of the files that are installed on the system for the selected application. To run the application, look for a file contained in one of the /bin directories and type the execution name.

4. Remove the package from the system. Click the Uninstall button. RpmDrake checks for dependencies, and if no other programs are dependent on the selected package, the package and associated program files will be deleted from the system.

5. Display packages that were not installed when you installed the operating system. Click Tree, See Available Packages. It might take a few seconds for RpmDrake to search the system and update its database.

6. Look for a package that you would like to install on the system. Scroll through the list and click on a package to see a description (see Figure 15.4).
