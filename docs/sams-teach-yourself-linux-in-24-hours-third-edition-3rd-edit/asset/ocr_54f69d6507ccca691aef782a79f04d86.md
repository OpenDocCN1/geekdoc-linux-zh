# Security Is Job 1

Security is so much an integral part of Linux and all UNIX operating systems that its built-in system of file access and permissions forms the basis for controlling every file in the system. The UNIX operating systems see everything as a file, and so security has a material part in every function and every action taken within the system.

The inner workings of the security system are covered throughout the book. Security is an all-pervading issue and you will be visiting it quite often. As you work with Linux, keep in mind that prevention is the name of the game where security is concerned.

In this hour, you will

+   - Maintain the physical security of your computer equipment, software programs, and data
+   - Restrict access to the system by assigning passwords, and perform system administration tasks from the superuser account
+   - Create user and group accounts to share files, and assign permissions to shared files
+   - Keep track of system usage, and schedule regular system and file maintenance
