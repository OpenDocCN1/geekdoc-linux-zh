# Hour 22

# Merging onto the Information Superhighway

Your Internet connection is up and running and you're ready to explore the Internet and all that it has to offer. Linux offers a vast assortment of tools to cover about every surfing need you might come across. There are so many Web browsers, electronic mail readers, newsreaders, file transfer programs, and chat tools that you might not know where to start.

In this hour, you will:

+   - Get up and surfing quickly with Netscape Communicator
+   - Learn how the Linux electronic mail system operates
+   - Find Linux help in the Usenet newsgroups
+   - Use gFTP to download the GNUCash financial management program from an FTP site
