
4. Write-protect the file. Type `chmod a-w fstab.orig` and press Enter.

Now you will always have a copy of the original configuration file, which is located in the same directory. You can refer to this file if you make changes that don’t work properly. When you make a configuration change that you don’t like, undo the change by restoring the original file.

> Whenever you plan to make a configuration change, back up the current configuration file. You can use a file extension such as .old or .bkup to identify the copy. If you will be making several configuration changes, you might want to keep multiple copies (using file extensions such as .old1, .old2, .old3, and so on.)

+   1. What function does the supermount feature found in some distributions perform?

+   3. What command do you type to mount a floppy disk drive?

### Backing Up and Restoring the Filesystem

Keeping a duplicate copy of important system files and user data files is the most important part of maintaining your computer system. Developing a backup system helps ensure that data is protected from loss and destruction. You never know when a hardware problem may arise or a file is accidentally deleted. For this reason, you should create a backup plan and back up files on a regular schedule. You’ll need to test the backup files also to ensure a safe recovery should you need to use them.

Your backup plan should include a list of those files that need to be backed up, how often the backups should occur, the media used to store the backups, and what tools will be used to perform the backups.

In this hour you will:

- Develop a backup plan so that you don’t lose valuable files
- Back up files to floppy disks
- Compress files to save space on the hard drive or on the backup media
- Create a file archive and restore the archive after a system failure or after files are lost

### Developing a Backup Plan

The importance of backing up the system can never be stressed enough. You never know when the power may go out or a hard drive may crash. Even though you can restore the operating system from the distribution CD-ROM, there are other files that you need to consider. What about the configuration changes that you worked on for hours and hours before your system was set up just perfectly?

> Always make a copy of configuration files before you make any configuration changes. Then, once you've made the changes, you will also want to keep a copy of the new configuration file.

Then there are the files created by users. These files change on a daily basis (okay, some of us change files by the minute). Save yourself the pain, agony, and frustration by creating a sound plan for backing up important files and restoring the system after a disaster.

**New Term** Backing up files is almost the same as copying files, except that backed up files can be easily restored to the system in case files are lost. Backing up makes a special set of files that, when restored, places the files in their original position in the directory structure.

Follow these steps to create a backup plan:

+   1. **Make a list of the files and directories that need to be backed up.** You'll always want to back up system configuration files in the /etc directory, other configuration files that may be found in /usr/lib, X Window System configuration files usually found in /usr/X11R6/lib/X11, and kernel sources in /usr/src/linux. In addition, you'll want to back up user files in the /home directory as well as files for the superuser in the /root directory.

> Read the "Upgrading Your Linux Distribution" mini-HOWTO for more ideas on how to design a solid plan for backing up your Linux system.

+   2. **Find a few tools to use when backing up and archiving files and directories.** Several Linux tools are available that will archive a group of files, and there are tools that will compress files and archives. When looking at the Linux archive and compression utilities, you'll need to decide whether you want to use the archive on just a Linux machine or if a compressed file will be used on a computer running the Microsoft Windows or Apple Macintosh operating system.
