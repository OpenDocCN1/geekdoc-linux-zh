# Task: Creating a Connection to an ISP

One of the configuration tasks that Linuxconf can help with is creating a connection to your ISP so that you can surf around the Web. Setting up a PPP connection using the Network Configurator is a two-step process. First, Linuxconf needs to know how to connect to the Internet. Then, the name server information supplied by the ISP needs to be added. Just follow the instructions to create a connection to the Internet:

> Before you begin this task, make sure that you have the information supplied by the ISP, and that the modem is connected to the computer and turned on.

+   1. Open the Network Configurator. Click the Networking button on the main Linuxconf configuration window.
+   2. Create the PPP connection. Click on the PPP or SLIP dialout button shown in Figure B.8 to display the PPP/SLIP configuration window.
