### Looking at the Desktop

The desktop is the background for all the elements found on the screen. The desktop can be customized with a different background color or wallpaper. Window decorations can be changed, and a screensaver can be set to keep others from using the computer while you are away from your desk. Also found on the desktop are icons that open applications, files, and directories quickly. Programs and files that are used frequently can be placed on the desktop.

![](img/782ecfdc0b083a767896cc983e10427f_396_0.png)

> Open the GNOME Help Browser to find help with the desktop, read the manual pages, and browse other sources of documentation. Click the Main Menu button and select Programs, Gnome, Help System.

The panel lives at the bottom of the screen and contains the Main menu, various panel icons, a Desktop Guide, and a Tasklist. The panel can be customized to fit your needs. The panel can be moved to a different location on the screen, icons can be added to the panel to make it easy to start your most frequently used applications, and objects can be removed from the panel. To learn more about the panel and how it works, right-click on the panel and select Panel, Panel Manual to display the Gnome Help Browser.

The Main menu contains a list of the applications, utilities, and other tools that are installed on the system. The panel icons are another way to quickly access programs and files that you use often. If there is a program listed in the Main menu that you use often, add this program to the panel. Right-click on the program name in the Main menu to display a menu, and then select Add this launcher to panel. Next time you want to use the program, just click the icon on the panel.

The GNOME Desktop Guide and the GNOME Tasklist make it easy to manage windows on the desktop. The Desktop Guide controls the virtual desktops available on the system and, if you click the arrow at the left of the Desktop Guide, it displays a list of all open applications. The Tasklist shows all the applications that are open on a selected virtual desktop. When an application window is minimized, click the Tasklist icon to maximize the application.

![](img/782ecfdc0b083a767896cc983e10427f_396_1.png)

> To customize the panel, right-click in an empty area of the panel and select Panel, Properties, All properties. To customize the Desktop Guide or the Tasklist, right-click on the object and select Properties.

### Customizing the Desktop

A little cosmetic surgery can go a long way in making the desktop more attractive. For a little spice, change the background image and add a screensaver. You can change the desktop background to a different color, a combination of colors, a pattern, or a picture. Then, to hide your work when the computer is not in use, select from one of the many screensavers for the X Window System. The appearance of the window borders can also be changed by selecting one of the many themes. These themes can also be customized to fit your taste.

When you're ready for a face lift, open the Gnome Control Center and check into one of the configuration modules. To find the Gnome Control Center, open the Main menu and select Programs, Gnome, Settings, Gnome Control Center. The Control Center shown in Figure B.2 illustrates how to use an image as the desktop background.

FIGURE B.2
Use the preview screen to see how the background will look on the desktop.

![](img/782ecfdc0b083a767896cc983e10427f_397_0.png)

Changing the desktop configuration is done from the Control Center, which groups the different options by configuration modules. To see the list of configuration modules, click the plus sign next to each of the different categories. Here are some changes that you might want to make to your desktop:

- Have some fun with the desktop background and select the Background configuration module. Select from a variety of single colors to make a background that makes it easy to see other screen elements, such as windows and desktop icons. A two-color gradient blends one color into another on the desktop, which makes for a psychedelic look that's also easy on the eyes. If you'd like a little more scenery, select a pattern or image file (you'll find several in the /usr/share/pixmaps directory). You can even scan one of your own photographs and use it as your wallpaper.
- Hide the panel when you don't need it. The Panel configuration module not only turns off tooltips, it also sets the auto-hide delay for the panel, sets the default icons for launcher and menu icons, and sets the spacing between panel icons.
- It's a good idea to set the Screensaver configuration module to take charge of the system when it is not in use. The original idea for screensavers was so that a single static image did not display on the screen for a long period of time, thereby causing the image to become "burned" into the monitor. Screensavers also enable you to password-protect the screen so that others cannot use the computer while you are away.
- The window manager controls the look of the window border; that is, the color of the title bar and the placement of the title and window buttons. If you want to change the look of the window dressings, click the Appearance configuration module for the default window manager.

## Using the GNU Midnight Commander File Manager

In Hour 7, "Moving Around the Filesystem," you learned how to navigate within the directory structure and sort files into directories by using commands. If your past experience is with the Windows and Macintosh operating systems, you might have felt as though you were flying blind while you worked without a graphical file manager. If you want to work with a graphical file manager, there are plenty of file managers to be found in the GNU/Linux world.

> There are many graphical file managers from which to choose, and the ones installed on your system will depend on which desktop environment you are using. KDE uses the K File Manager, whereas GNOME uses the GNOME edition of the GNU Midnight Commander. There are other file managers, such as Xfilemanager, that will run under any desktop environment controlled by the X Window System. In some desktop environments, the default file manager opens automatically when you log in to your account and displays the contents of your home directory.

Although the number of graphical file managers might be overwhelming, they all work basically the same way—click the plus sign to expand the directory tree, and click and drag files from one directory to another. All the commands that you can perform with the file manager are contained in the menus. The most commonly used commands can be found on the toolbar. If you hold the mouse pointer over a toolbar button, a tooltip appears that tells you the command that the button executes. And, when you need more help, open the Help menu and look for any assistance that the program's authors might have added to the file manager.

Because most graphical file managers work in much the same manner, most of the tasks discussed in this section will work with the file manager of your choice. To illustrate how to use these file managers, the GNU Midnight Commander (shown in Figure B.3) is used as the example.
