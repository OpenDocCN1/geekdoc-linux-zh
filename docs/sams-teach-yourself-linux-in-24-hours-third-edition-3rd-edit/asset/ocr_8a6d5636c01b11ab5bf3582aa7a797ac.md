After you have set up the different partitions for the filesystem, the partitions need to be formatted. If this is your first GNU/Linux installation, you will want to format all the filesystem space as Linux native and the swap space as Linux swap. You are also given the opportunity to check for bad blocks (or errors) on the hard drive before the drive is formatted. You should check for bad blocks as a precautionary measure.

# Deciding Which Software to Install

If you selected the custom installation class, you will be asked to select from a list of package groups. To install all the software, you will need at least 1.3 gigabytes of hard drive space in the root partition. Listing 2.1 shows the root partition on the device named hda2 (which has 9996 megabytes of space). Listing 2.2 shows the root partition on device hda3, which has 2865 megabytes of space.

![](bbox=[0.22, 0.71, 0.32, 0.8])

> > If you purchased the boxed Linux-Mandrake distribution, you may have more than one CD-ROM. You will be asked if you have the second CD-ROM. You will also be prompted as to when to change CD-ROMs.

If the root partition on your system does not contain enough space, you will need to deselect package groups from the list. If you aren't sure which packages to deselect, just leave them all selected and the installation process will decide how much room is available and make its own decision about how much software to install. The installation program will install the most popular and commonly used applications first, and then will continue to add applications (using its own priority scheme) until most of the partition is filled.
