# Additional Resources

There are far too many things about X Window System configuration and window managers for us to make much of a dent in it in an hour. There are new things going on with the newest releases of XFree86 that change things to make the system more sophisticated. For information about the changes made in the latest releases of XFree86 to accommodate new hardware and upgraded operating systems, you'll have to look around some of these places:

+   - The best resources for finding out about window managers can be found at these two sites: www.PLIG.org/xwinman and www.PLIG.org/xwinman/others.html.
+   - FVWM and FVWM2's official site is http://www.fvwm.org/. For the latest version, check ftp.hpc.uh.edu/pub/fvwm.
+   - LessTif (a motif clone) is at The Hungry Programmers site www.lesstif.org.
+   - KDE's Web site is www.kde.org.
+   - The official GNOME Web site is www.gnome.org.
+   - The CORBA homepage is at www.corba.org.
+   - The homepage for the Gtk+ toolkit is www.gtk.org.
+   - The Window Maker Web site is www.windowmaker.org.
+   - The AfterStep Web site is at www.afterstep.org.
+   - Enlightenment is at www.enlightenment.org.
+   - The XFree86 official site is at www.xfree86.org.
+   - Kenton Lee's site lists more than 700 X Window resource sites www.rahul.net/kenton/xsites.framed.html.

# Summary

In this hour, you learned about window managers, what they do, and which ones are installed and available. You learned how to change your window manager by editing files in your home directory. You also found out about some places where you can look for information about each of a selected group of window managers. You now know some places where detailed information about configuring your window manager can be found.
