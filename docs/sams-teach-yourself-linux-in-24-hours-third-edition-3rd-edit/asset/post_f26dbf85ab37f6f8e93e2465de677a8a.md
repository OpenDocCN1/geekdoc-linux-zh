## Task: Using Scripts to Connect to Your ISP
Rather than using a graphical tool to create a connection to your ISP, you can create three different shell scripts that will make the connection for you. The first step is to write a script that does the handshaking required to make the PPP connection between your computer and the ISP's servers. Then you'll write a script that dials up the ISP and starts the pppd daemon. Finally, you'll edit one more file and add the name of your ISP's domain name server.

![](img/782ecfdc0b083a767896cc983e10427f_333_0.png)

> This task assumes that you are using the vi text editor. You may use another text editor if you choose.

- 1. Log in to the superuser account.
- 2. Use the ls command to see whether the ppp-on and ppp-on-dialer files are located in the /etc/ppp directory. Make a backup copy of these files.

![](img/782ecfdc0b083a767896cc983e10427f_333_1.png)

> If these files are not there, you can find sample scripts in the /usr/doc/ppp-2.3.11/scripts directory. (In TurboLinux, you'll find them in the /usr/share/doc/packages/ppp-2.3.1/scripts directory.) Copy these two files to the /etc/ppp directory.

3. Edit the /etc/ppp/ppp-on file. Type vi /etc/ppp/ppp-on and press Enter. A sample script is shown in Listing 21.1. Replace the information in bold italics with the information supplied by your ISP. Don't forget to save your work and close the file when you are done.

### LISTING 21.1 The Script for the /etc/ppp-on File
```
#!/bin/bash
#
# Script to initiate a ppp connection.
# Change these parameters as needed.
TELEPHONE=555-1212      # The telephone number for the connection
ACCOUNT=username        # The account name for logon
PASSWORD=password       # The password for this account
LOCAL_IP=0.0.0.0        # Local IP address (Dynamic = 0.0.0.0)
REMOTE_IP=0.0.0.0       # Remote IP address if desired. Normally 0.0.0.0
NETMASK=255.255.255.0   # The proper netmask if needed
```

### LISTING 21.1 continued
```
#
# Export them so that they will be available at 'ppp-on-dialer' time.
export TELEPHONE ACCOUNT PASSWORD
#
# This is the location of the script which dials the phone and logs.
DIALER_SCRIPT=/etc/ppp/ppp-on-dialer
#
# Initiate the connection
exec /usr/sbin/pppd debug lock modem crtscts /dev/ttyS0 115200 \
asyncmap 20A0000 escape FF kdebug 0 $LOCAL_IP:$REMOTE_IP \
noipdefault netmask $NETMASK defaultroute connect $DIALER_SCRIPT &
```

Change the TELEPHONE field to the number used to dial up your ISP. The ACCOUNT field is your username and the PASSWORD is, obviously, the password needed to access your account with the ISP.

> You might want to put quotation marks around your password if the password contains any of the shell metacharacters (such as the asterisk or ampersand).

In the middle of the script is a field for DIALER SCRIPT. You will edit this file next. Make sure that this is the correct directory path.

Type the device name for the modem and the maximum speed at which the modem will connect in the last section of the script.

- 4. Make the file executable. Type chmod 755 /etc/ppp/ppp-on and press Enter.
- 5. The /etc/ppp/ppp-on-dialer file that you copied does not need any changes. If you do not have a copy of this script, a sample script is shown in Listing 21.2.

### LISTING 21.2 The Script for the /etc/ppp-on-dialer File
```
#!/bin/bash
#
# This script performs the connection protocol.
#
exec chat -v \
TIMEOUT 3 \
ABORT '\nBUSY\r' \
ABORT '\nNO ANSWER\r' \
ABORT '\nRINGING\r\n\r\nRINGING\r' \
'' '\rAT' \
'OK-+++\c:OK' 'ATH0'
```

### LISTING 21.2 continued
```
TIMEOUT 30 \
OK ATDT$TELEPHONE \
CONNECT \
ogin:--ogin: $ACCOUNT \
assword: $PASSWORD
```

6. Make the file executable. Type chmod 755 /etc/ppp/ppp-on-dialer and press Enter.

7. Configure the DNS address numbers used by your ISP. Type vi /etc/resolv.conf and press Enter. A sample of this file appears in Listing 21.3.

### LISTING 21.3 Edit Search and Nameserver Information in the /etc/resolv.conf File
```
search myisp.net
nameserver 255.255.255.244
nameserver 255.255.255.245
```

On the first line, enter the domain name for your ISP. On the second line, enter the primary DNS number. On the third line, enter the secondary DNS number. When you are done, save and close the file.

8. Dial up your ISP. Type /etc/ppp/ppp-on and press Enter. You should hear the modem dial.

9. When you are ready to disconnect from the Internet, type /etc/ppp/ppp-off. You'll see a message that says

```
PPP link to ppp0 terminated.
```

## Summary
You're connected to the Internet and ready to go. During the past hour, you learned several ways in which you could create a dialup connection to your Internet service provider. If a single user account will be cruising the Internet, you might want to use either the GNOME or KDE dialup utility. ## Quiz
- 1. What information do you need to collect from your ISP so that you can create a dialup PPP connection to get on the Internet?

You'll need the phone number that the modem needs to dial to access the ISP's servers, your username and password to identify you as an authorized user, the authentication protocol your ISP uses (PAP, CHAP, etc.) and the DNS addresses needed so that your computer knows which computer to use as its gateway to the Internet. You should also know whether your ISP uses dynamic IP addressing or static IP addresses (chances are, it is dynamic IP addressing). If you want to access an email account or read the Internet newsgroups, you'll need an email address, the name of the email server, and the name of the news server.
