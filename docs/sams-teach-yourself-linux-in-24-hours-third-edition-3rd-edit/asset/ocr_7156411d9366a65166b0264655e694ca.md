# Getting Started with the vim Text Editor

The vi text editor (and its clones vim, elvis, and nvi) will edit any file in ASCII text format. You'll find vi most helpful when editing system configuration files and editing programs. While working in vi, you can always call on the online help system to keep you moving forward (press Escape, type :help, and press Enter). The vim text editor contains a few enhancements over vi, such as the ability to undo edits, view multiple files, and search for text.
