# Talking to the Shell

Linux uses the GNU readline command line editor to read and write to the command line. The readline editor is what you see at work when you type text after the shell prompt or read responses there. The editor can also edit whatever is on the command line. To use the command line, just begin typing after the shell prompt. You'll see the cursor is just one character ahead of you. If you make a mistake, just press the Backspace key to erase the text. Use the left and right arrow keys to move back and forth across the command. There are also several commands for moving around the command line and editing text, as shown in Table 5.1.

TABLE 5.1 Text Editing Commands for the Command Line

| To Do This | Press These Keys |
|---|---|
| Move one character to the left | Ctrl+B |
| Move one character to the right | Ctrl+F |
| Move left by one word | Esc+b |
| Move right by one word | Esc+f |
| Move to beginning of the line | Ctrl+A |
| Move to end of the line | Ctrl+E |
| Delete character to the left | Del |
| Delete character to the right | Ctrl+D |
