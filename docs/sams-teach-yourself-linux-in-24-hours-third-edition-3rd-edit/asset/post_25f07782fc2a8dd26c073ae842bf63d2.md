### New Term
The vi text editor works under two different modes: the Command mode and the Insert mode. To begin working in a file by adding text, you'll need to change to Insert mode. To move the cursor around the file or to delete text, you'll work in Command mode. You also need to be in Command mode to access Insert mode. Press the Escape key when you want to change to Command mode. To access a mode, you type a single letter command. After you are in a mode, several mode commands make it easy to edit text.

When you first open a new file with vi, you are in Command mode. Command mode enables you to type commands to perform tasks. The first command you'll encounter is i, which switches to Insert mode. To execute this command, just press i on the keyboard (do not use the uppercase letter I). Notice that the "— INSERT —" message appears at the bottom-left corner of the screen. After you are in Insert mode, you can begin adding text to a file. Correct your mistakes with the Backspace key. When you want to switch back to Command mode, press the Escape key.

Command mode also enables you to move the cursor around in a file. You can use the arrow keys to move the cursor up, down, to the right, and to the left. The k, j, l, and h keys perform the same movement.

![](img/782ecfdc0b083a767896cc983e10427f_160_0.png)

> While you are practicing in the insert mode in vi, do not use the arrow keys, the Page Up and Page Down keys, or the Home and End keys to move the cursor around in a file. If you use these keys and find strange characters in your file, press the Escape key (at least once to ensure that you get to Command mode), and type :q!. This closes the file without saving the changes. By doing this while you are practicing you can ensure that you don't inadvertently save bad data to the file.

You should also save the file on a regular basis. You never know when there might be a sudden power outage. Commands that open and save files can only be used in Command mode. To access these commands, first type the colon (:) character. While you are working on a file, you can quickly save your changes (also known as writing a file) by typing :w and pressing Enter. At the bottom of the screen, you'll see a message similar to the following:

```
'practice.txt' 778L, 25518C written
```

If you decide you want to work with another file, type :e filename and press Enter. You must save changes to the file in the buffer area before you can open a new file. If you do not save your changes first, you will see an error message.

When you are finished working in vi, type :q and press Enter. The text editor will close and you will be returned to the shell prompt. To make things a little simpler, you can save the changes and quit vi at the same time; type :wq and press Enter. You will get an error if you try to quit without saving the file unless you use the :q! command discussed in the caution above.

## The Syntax for vi

When you open a file in vi, the cursor is located at the beginning of the file. If you want to start working at some other location, you can specify that spot and vi will open to it.

The following code shows the syntax for vi:

```
vi [+linenumber] [+/pattern] filename
```

The filename parameter is the name of the file you want vi to open when the program starts. For example, if you want to work with a file named practice.txt, type the command vi practice.txt.

The `linenumber` parameter (see Table 8.5) is the line where the cursor should be placed when the file opens in the buffer. In `vi`, you can display the line numbers along the left margin. Line numbers are useful if you are writing programming code or a legal document. For example, to start working at line 31 in the file named `practice.txt`, use the command `vi +31 practice.txt`.

The `pattern` parameter is used when you want `vi` to search for a string of text. When `vi` finds this text string, the cursor is placed at the first instance where the text string is found. For example, if a section of the text file where you want to start working contains the text string "introduction," use the command `vi +/introduction practice.txt`.

## Text Editing Basics

The first time you use vi, you might feel overwhelmed by the vast assortment of keyboard commands needed to operate the text editor. Just remember, even though vi is a complex text editor that requires you to memorize a bunch of commands, it becomes easier to execute commands and edit text the more often you work with the editor.

## Positioning the Cursor in a File

Memorizing the cursor movement commands shouldn't take much time; there aren't many. The simplest way to move the cursor around the screen is to place your fingers on the home row of the keyboard. Come on, you remember typing class. The home row is the middle row of letters that starts with the A key on the left. You'll need your right hand to move the cursor. Try these cursor movement commands (but remember to press Escape first):

- Press h to move the cursor one character to the left
- Press l to move the cursor one character to the right
- Press j to move the cursor down one line
- Press k to move the cursor up one line

Sometimes speed is a necessity and you might need to move through a file a little quicker than a single line at a time. To scroll down the file one screen at a time, press Ctrl+F. Then scroll back up with Ctrl+B. There are a few more cursor movement commands. Look at Table 8.2 for a description of the common commands used to move the cursor around in a buffer window.

TABLE 8.2 Using Cursor Commands to Move Around the Buffer

| Cursor Movement | Command |
|---|---|
| One character to the left | h |
| One character to the right | l |
| Down one line | j |
| Up one line | k |
| Move to the next word | w |
| Move to the previous word | b |
| To the end of line | $ |
| To the beginning of the line | 0 |
| To the next sentence | ) |
| To the previous sentence | ( |
| To the next paragraph | } |
| To the previous paragraph | { |
