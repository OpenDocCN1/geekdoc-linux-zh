Q You mentioned the GNU Hurd. What is the GNU Hurd and where can I find out more information?

A The GNU Hurd is a UNIX kernel developed by the Free Software Foundation. You can learn more about GNU Hurd at www.gnu.org/software/hurd.

# Quiz

1. What is the first thing that you should do before you consider upgrading the kernel?

Before you begin, you should familiarize yourself with the kernel upgrade process as much as possible. There's lots of information for you to read that will give you some good advice on why and when you should upgrade the kernel and how the upgrade process works. You should feel comfortable with this process before you make your first attempt.

2. How do you tell the difference between a production kernel and a development kernel?

Kernels that use an even minor number, such as 2.2.x, are production or stable kernels with the bugs removed. Those kernels numbered with an odd minor number, such as 2.3.x, are development kernels. Development kernels are for testing purposes and might contain lots of bugs. You can think of a development kernel as beta software.

3. What should you do to prepare yourself before you install a new kernel?

You will need to make sure that the required libraries and utilities installed on your system are updated to a certain minimum version number. If your system is not up-to-date with the needed libraries and utilities, the kernel will not install properly.
