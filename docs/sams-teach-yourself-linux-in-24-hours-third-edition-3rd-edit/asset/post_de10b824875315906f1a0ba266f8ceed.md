## Hour 21
### Connecting to the Internet

Stretch your muscles, grab your surfboard (okay, your modem; we're trying to have a little fun), and get ready to ride the Internet waves. Cool! But, first, you need to set up the modem and make sure that it works with Linux. Then you need to create a dialup connection to your Internet service provider (or ISP, for short). This hour shows you how to create a PPP connection, which is used by most ISPs, and allows you to connect to the Internet through a modem and a telephone line.

In this hour, you will

- Attach a modem to the computer and test the connection
- Learn about the different tools that will connect you to your ISP
- Write a script to create a dialup connection to your ISP

### Getting Ready

One of the differences that you'll find between the Linux operating system and the Windows operating system is the ease with which you can set up a modem and a dialup connection to the Internet. There are no wizards to guide you along the way. And you'll need to know a few important pieces of information about your computer and modem before you start. During the next hour, you'll learn some of the secrets of successfully getting on the Internet. Before you begin, you'll need to do some preparation. Collect the information provided by your ISP and make sure that the modem is compatible with Linux. Many new computers come with builtin modems that may not be compatible and Winmodems in particular will probably never be compatible.

### Collecting Information from Your ISP

When you set up an account with an ISP, the ISP provides all the information you need to create a dialup connection. No matter which of the methods you choose for creating the connection, you'll need this information to connect to the ISP's servers. Here's a checklist of the information you will need to collect:

- The telephone number that the modem dials to make the initial connection with the ISP.
- The username and password used to identify you as an authorized user of the ISP's system. Most ISPs allow you to select a username and password; others might assign a username and password.
- The domain name of your ISP. An example of a domain name might be www.myisp.net.
- The domain name server addresses (or DNS addresses) that the ISP's server uses to locate other computers on the Internet. Your ISP might use a primary and a secondary DNS address. The DNS address takes the form 255.255.255.255.
- The IP address that the ISP assigns to your computer when you connect to the Internet. Most ISPs use dynamic IP addresses, so you might not need this information.
- If you use email and newsgroups, you'll need your email address, the name of the ISP's mail server, and the name of the ISP's news server. In addition you need to know the ISP's authentication protocol, PAP, CHAP, etc. You'll use this information in Hour 22, "Merging Onto the Information Superhighway ISP."

ISPs usually assign an IP address as the dialup connection is made. It is called a *dynamic IP address* because for each Internet session, the IP address assigned to your connection is different. If the IP address stayed the same with each session, the IP address would be a *static IP address*.

### Selecting a Modem

Most computers that are sold off-the-rack, come with an internal modem already installed and ready to use with the preinstalled operating system. It's extremely easy to get this internal modem up and working with Microsoft Windows. Unfortunately, this is not the case with Linux. If the modem is intended to run only with the Windows operating system (these are called Winmodems), it will not work with Linux. To get other types of internal modems to work with Linux, you might need to spend some time configuring the modem by setting the IRQ number and flipping the jumpers on the modem, if you are lucky enough to have them.

If you are looking for a fast-and-easy modem solution, invest in an external modem. External modems use an external serial port, which is easy for Linux to recognize. To set up an external modem with Linux, all you need to do is attach the modem to the computer's external serial port and turn on the modem's power switch.

> Some modems might be automatically detected by the Linux kernel during the system boot. Linux-Mandrake has an auto-detect feature that works during the boot process. If the kernel thinks that new modem hardware has been attached to the computer, it asks whether you want to configure the modem. You also have the option to ignore the message and skip the configuration.

### Task: Setting Up the Modem

It's time to prepare for your Internet adventure. You must have the right equipment, and it must be installed correctly, to make the most of your adventure. This task shows you how to configure a modem.

- 1. To make sure that the modem is compatible with the Linux operating system; Read the Linux Hardware Compatibility HOWTO and the Linux Modem HOWTO.
- 2. To attach the modem to the computer; Shut down the computer and turn off the power. Attach the modem's serial port cable, plug in the modem power supply, and turn on the modem. Turn on the computer and start the operating system.

- 3. Determine the serial port to which the modem is attached and the modem device being used. Type `dmesg | less` and press Enter. Here's an example of modem information found by the kernel during the system boot:

```
Serial driver version 4.27 with MANY_PORTS MULTIPORT SHARE_IRQ enabled
ttyS0 at 0x3f8 (irq = 4) is a 16550A
```

Modems usually use the ttyS0 or ttyS1 modem device. In the MS-DOS world, ttyS0 is the same as COM1 and ttyS1 is the same as COM2. Some Linux distributions name these serial port cua0 and cua1.

### Connecting to Your ISP

Linux provides several methods to create a dialup connection to your ISP. If you are using one of the desktop environments (such as KDE and GNOME), you'll find a number of dialers that make it easy to create the dialup connection and then to connect to your ISP. Many Linux distributions contain a configuration tool called LinuxConf. LinuxConf is one way to set up a dialup connection. You'll learn how to do this in Appendix B, "Introducing GNOME and LinuxConf."

If you are using the GNOME desktop environment, the GNOME PPP dialup utility (shown in Figure 21.1) can set up the modem to dial your ISP and saves the other information needed to make the connection.

> If you don't see a menu item for the GNOME PPP dialup utility in the GNOME menu, type `gnome-ppp` at the command line.

> If your phone service includes call waiting, add the *70 code to the beginning of the ISP's phone number to disable this feature while you are surfing the Internet.

The KDE desktop environment contains a tool similar to GNOME PPP called kppp (shown in Figure 21.2). kppp enables each user on the system to create an Internet connection separate from other users. As an added attraction, the kppp dialer contains tools that measure the time spent online and the amount of data transferred during each Internet session. If you don't see the kppp dialer in the KDE menu system, type `kppp` at the command line.

When you first use the kppp dialer, you'll see a blank connection window. Gather up the information you collected from your ISP, the data you have collected about your modem, and click the Setup button to start the configuration process. Your first task is to click the Device tab and set up the modem. Using the information you collected from the dmesg command, select the modem device from the drop-down list. When selecting a connection speed, use a speed of 57600 if you have a 28.8 or 33.6 modem and a speed of 115200 if you have a 56K or V.90 modem. To test your setup and make sure that kppp can find the modem, click the Modem tab and query the modem.

After you have configured the modem and determined that it is recognized by kppp, tell the dialer how to make the connection to your ISP. Click the Accounts tab and click the New button. The New Account window (shown in Figure 21.3) is where you will enter the information needed to dial your ISP and perform the necessary handshaking.
