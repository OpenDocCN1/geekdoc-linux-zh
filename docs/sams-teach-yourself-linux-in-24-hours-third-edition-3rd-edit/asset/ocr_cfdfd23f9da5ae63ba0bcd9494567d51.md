# Exercises

+   1. Experiment with different ways to access the superuser account. You'll want to find ways to use this account only when necessary and to make it quick and easy to log in and log out. Learn how to use separate consoles to perform administrative and configuration tasks. If you are working in a desktop environment, learn how to use a terminal emulator and switch to superuser from your user account. You'll also want to decide which members of your family or company need superuser access to the system. Train these people so that they understand how and when to work in the superuser account.
+   2. If your GNU/Linux installation was successful, celebrate. Go out to dinner, go to the beach, wear sandals! If your GNU/Linux installation wasn't successful, try a few of the troubleshooting ideas. And, if that doesn't work, you might need to start the installation all over again. But, you can still celebrate because of all the hard work you've done over the past hour.
