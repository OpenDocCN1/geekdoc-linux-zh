# Deleting Files

Sometimes you just don't need a file anymore. To get rid of unneeded files, delete them with the rm command. When you use the rm command, you need to specify the file (or files) that you want to delete. You must also have write access to the file before you can remove the file from the system.

You might want to play it safe when you delete files. Linux can prompt you each time that you try to delete a file to make sure that you really want to delete the file permanently. The rm command has an interactive option so that each time you delete a file, you are asked whether you really want to remove the file. If you want to be prompted each time you delete a file, type rm -i filename and press Enter. You'll see the following message:

```
rm: remove 'filename' ?
```

If you want to delete this file, type Y and press Enter. This permanently deletes the file. If you've executed the rm command in error, type N and press Enter. The file will be left in place.

> After you delete a file, there is no way to get it back. To avoid an unnecessary loss, always use the rm command with the interactive option.
