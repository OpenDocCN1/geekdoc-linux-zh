# 4. Which command can you use to reduce the size of a file?

The gzip command is used to compress files. The reason for compressing files is to save space on your storage media. You may also want to compress files before you send them as attachments to email messages. You can also compress files to create more space on the hard drive. You can easily uncompress a file when you need to work with it.

# 5. Why should you consider attaching an uninterruptible power supply to your computer?

Severe weather conditions and car accidents are major causes of power outages, power surges, and brownouts. When the computer unexpectedly loses power, important data can be lost. If Linux does not shut down properly, there could be damage to the operating system. A UPS protects the computer from violent spikes in the electrical current and gives you time to save your work and shut down the system.

# 6. How do you create an archive in which to store files?

The tar command combines several files into one file and saves the original directory structure. When the archive is restored onto the system, the files are returned to their original directories. If those directories do not exist on the system, they will be created when the archive is unpacked.
