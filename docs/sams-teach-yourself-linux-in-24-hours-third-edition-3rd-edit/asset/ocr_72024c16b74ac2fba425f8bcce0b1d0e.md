# Task: Limiting the Size of Core Dumps

Because most Linux newbies might not be interested in having core dump files take up valuable hard drive space, it is possible to limit the size of a core dump. You can set a specific size for a core dump, or you can choose to not have it appear on your system at all. Here's how to limit the size of a core dump:

+   1. Display the core dump size. To see the limit that is set for the size of core dumps on your system, type ulimit -c at the shell prompt and press Enter. Here's an example of the output you might see:
+   2. Prevent core dumps from appearing on your system. Type ulimit -c 0 and press Enter.
+   3. Display the core dump size. Type ulimit -c and press Enter. Your output should look like the following:

```
[root@localhost root]# ulimit -c
100000
[root@localhost root]#
```

```
[root@localhost root]# ulimit -c
0
[root@localhost root]#
```
