## Exploring the File Manager

When the file manager opens, the list of files and subdirectories found in a selected directory appear as icons with only the filename as a description. The four buttons on the right side of the toolbar change the appearance of the icons and the file information that displays. Here is a brief description of each of the display options:

- The Icons view gives a quick way to look at a file listing. The icons represent different file types, and the name of the file appears below the icon.
- The Brief view is a simple listing of the directory contents. There are icons for directories only; files are shown as a filename only. This displays the same listing as the ls command.
- The Detailed view lists the filename, the file size, and the date and time that the file was last modified.
- The Custom view lists the filename, file size, and file permissions (which you learned about in Hour 12, “Sharing Files with Other Users on the System”).

![](img/782ecfdc0b083a767896cc983e10427f_400_1.png)

> The information displayed in the Custom view can be customized. Select Settings, Preferences to display the Preferences dialog box. Click on the Custom View tab to add and delete columns from the file list.

Before you can work on any files, change any filenames, or make copies of a file, the file must first be selected. The conventions for selecting files are pretty much the same from file manager to file manager (and even across operating systems). You can even have the file manager select files for you based on certain parameters that you specify.

Selecting files using the mouse is relatively straightforward. Here’s a hint: Use the Brief or Detailed view to make it easier to select files. Try these tricks to select files with the mouse:

- Click on a filename to select a single file.
- Select contiguous files by clicking the first filename, holding the Shift key, and clicking the last filename in the block of files with which you want to work.
- Select random files in the list by clicking on the first filename, holding the Ctrl key, and clicking on any other files that you want to select.

![](img/782ecfdc0b083a767896cc983e10427f_400_2.png)

If the files that you want to select all share a common element (such as a file extension or a combination of letters in the filename), use the file manager to select files for you. Click Edit, Select Files to display the dialog box shown in Figure B.4. Type the search criteria. Remember to use wildcards (discussed in Chapter 6, “Looking at the Command Line”) to help make a match. For example, if you want to select all the PCX files in a directory, type *.pcx as the search criteria.

## Handling Files and Directories

As you work with the various applications installed on the system, the files that you create are stored in the home directory for your user account. You could save all these files in the home directory, but over time, your personal filing system would become cluttered and it would be hard to find files. To keep your files organized, create subdirectories within your home directory and move files to the appropriate subdirectories.

To create a subdirectory, select the directory (from the directory tree) under which you want to create the new subdirectory. Then click File, New, Directory. Type the name of the new subdirectory in the dialog box that appears. Use the relative filename for the directory. (The relative filename does not begin with the slash (/) character.)

After you have created a few subdirectories, you can begin to move files and tidy things up. To move a file, first display the file in the file list and the directory in the directory tree. Then click and hold the file while dragging it to the new directory in which it will be stored.

## Task: Moving Around the Filesystem

Using a graphical interface to work with the filesystem makes it easy to move from directory to directory, view the contents of a directory, and create and move files. A safe place to play in the filesystem is in the /usr directory. This directory contains a number of programs that you might find useful. You'll also find a wealth of information about the operating system and all the applications installed on the system. Here's how to move around the filesystem and view a few files:

- 1. Display the contents of the /usr directory. Scroll to the bottom of the directory tree and click the plus sign next to usr. The subdirectories found in the /usr directory will appear in the directory tree.
- 2. Display the contents of the /usr/doc directory. Click the plus sign next to doc. A subdirectory for each program, command, utility, and application documentation displays in the directory tree.
- 3. Look for the /usr/doc/linuxconf subdirectory. (You'll work with Linuxconf later in this hour.) Click on the subdirectory to display the contents in the file list.
- 4. Look for a README file. Double-click the file to open it. The file will open in the default text editor. Other file types will open in their associated viewers. For example, an HTML file might open in Netscape Navigator.

If a file cannot be opened automatically, the dialog box shown in Figure B.6 appears. Click on the appropriate application from the list.

## System Configuration with Linuxconf

Throughout the past 24 hours, you learned how to edit system configuration files by using a text editor or with commands. You learned how to configure hardware in Hour 9, "Hooking Up Hardware Devices"; how to create user and group accounts in Hour 12, "Sharing Files with Other Users on the System"; how to adjust your video display in Hour 18, "Installing the X Window System"; and how to set up an Internet connection in Hour 21, "Connecting to the Internet." Even though these tasks can be accomplished quickly and efficiently with a few changes to a text file, you can make these changes from software utilities that write the changes to these same files.

![](img/782ecfdc0b083a767896cc983e10427f_403_1.png)

A number of GNU/Linux distributions contain configuration tools and other utilities that have been designed for that particular distribution. Linux-Mandrake contains a utility called DrakConf that provides a graphical interface from which you can change the screen resolution, add user accounts, set up a printer, and other system tasks. TurboLinux contains a whole set of configuration tools—configure the X Window System using TurboXcfg, create user accounts with TurboUserCfg, and set up an Internet connection with Turbonetcfg. Linuxconf was developed by Red Hat Linux and is included with most distributions.
