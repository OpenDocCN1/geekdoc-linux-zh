# Working with Processes

One of the advantages of Linux is its smooth management of CPU and memory resources. Every time you issue a command, or start a program, Linux goes to the filesystem to make a copy of the program. Linux then places the copy in the computer’s memory. After the copy is in memory, the shell executes the program, thereby starting a process. Each process is maintained and managed through the shell program. During this hour, you will use the bash shell to learn how Linux starts and manages processes.

In this hour, you will:

+   - Learn how to start and stop a process
+   - Determine how your system is using memory resources
+   - Find utilities that will help you monitor system resources
