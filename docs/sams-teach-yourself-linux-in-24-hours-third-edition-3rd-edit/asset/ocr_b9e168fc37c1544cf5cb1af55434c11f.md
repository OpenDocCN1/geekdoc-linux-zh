# Hooking Up Hardware Devices

Hooking up new hardware devices to your GNU/Linux system has certainly become easier than it used to be. Each new kernel supplies driver modules for the growing list of hardware devices that can be attached to the system. When you first boot the system, a long list of messages zips across the screen. You’ll notice information about individual pieces of hardware that you have, the manufacturer, model number, and even whether or not it’s going to work. The process doesn’t always work that smoothly, however, so you should know what to do to take care of it yourself.

In this hour, you will

+   - Learn how to work with floppy and CD-ROM drives
+   - Format a DOS floppy disk and copy files to it with the mtools package
+   - Locate sources of system information
+   - Back up configuration files before adding new hardware and making other configuration changes to the system
