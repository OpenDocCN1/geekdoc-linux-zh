## Logging In as the Superuser

There are two ways to work as the superuser. The first is to log in to the root account directly. This means that you type the username of root and then give the password for the root account.

![](img/782ecfdc0b083a767896cc983e10427f_57_0.png)

> Because the superuser has access to every file, command, and program on the system, it is possible for the superuser to crash the system, delete files, or make other destructive changes. Be careful to give the superuser password to only those people with a need to know, and use the superuser account only for system administration. Use an unprivileged user account to perform other work.

The other way to get to be the superuser is to temporarily switch to the superuser account while working in your user account. This involves executing the su command.

## Switching Between Consoles

You can run six different user sessions at one time. Use the function keys along the top of the keyboard. F1 through F6 are the available consoles. Press Alt plus the appropriate function key to move from console to console.

![](img/782ecfdc0b083a767896cc983e10427f_58_0.png)

> Be security conscious when working with multiple consoles. It is easy to forget that multiple consoles and user accounts are open. Before you leave the computer, check each console to make sure that no users are logged in. This helps to prevent unauthorized entry into the system.

## Task: Exploring the Login Process

Before you can drive your new operating system around the block, you'll need to turn the key to start the engine. Your key is your username and password. Follow these steps to learn how to log in to the superuser account and your unprivileged user account:

- 1. Access the superuser account. At the login prompt, type root and press Enter. The password prompt will appear.
- 2. Type the root password and press Enter. The shell prompt for the root user account displays and might look something like the following:
  `[root@localhost /root]#`
- 3. Change to a different console. Press Alt+F2.
- 4. Access your user account. At the login prompt, type the username for the unprivileged user account that you set up during the installation and press Enter. You will be asked for the account's password. Type the password and press Enter.
- 5. Temporarily change to the superuser account from the unprivileged user account. Type su and press Enter. You'll be asked for the password for the root user account. Type the password and press Enter. The shell prompt will look something like the following:
  `[root@localhost rusty]#`
- 6. Exit the superuser account. Type exit and press Enter. You'll be returned to your user account and once again the shell prompt might look like the following:
  `[rusty@localhost rusty]$`

You'll want to do your daily work from this user account. To get back to the console at which the root user is logged in, press Alt+F1.

## Task: Shutting Down the System

When it's time to shut down the computer for the evening, the designated system administrator must be called in. Shutting down the system is a job for the system administrator because the shutdown command can be executed only by the superuser account. Here's your first task as the system administrator of your system. Follow these steps to log in to the superuser account and turn off the computer:

- 1. Log out of your user account. Type `logout` and press Enter.
- 2. Return to the console where the root user is logged in. Press Alt+F1.
- 3. Terminate the session. Type `shutdown -h now` and press Enter. The system will go through the shutdown process and will turn off services and unmount devices. You'll see a long list of items scroll by on the screen. When the operating system has shut itself down, a message appears at the bottom of the screen telling you to power down.

![](img/782ecfdc0b083a767896cc983e10427f_59_0.png)

> If you just want to restart the computer, type `shutdown -r now` and press Enter.

## Q&A

Q I really do want to use the GNU/Linux operating system, but I don't want to install it. Do I have any other options?

A You could invite a GNU/Linux guru to dinner and then ask him to install the operating system and applications for you. You might need to bribe him with some homemade raisin oatmeal cookies for dessert. You could also check out a GNU/Linux user group near your home. Many GNU/Linux user groups hold installation meetings where you can take your computer and have someone help you with the installation. You'll find a list of user groups at www.linux.org/users. You can also purchase a computer with Linux pre-installed. To find a list of vendors, cruise over to www.linux.org/hardware.

Q Is there another program that I can use instead of LILO to boot between Microsoft Windows and GNU/Linux?

A There are two commercial programs that we know of. If you want to boot between multiple operating system, try System Commander (www.systemcommander.com) or BootMagic. BootMagic is included with the PowerQuest PartitionMagic program (www.powerquest.com). Some distributions use grub to select which operating system to load when the system starts.

Q When I set up the X Window System, I told the installation process that I wanted to start the X Window System automatically when the system boots. How can I get past the graphical login display and display the login prompt on a text-only display?

A You will need to change to a different virtual terminal. Press Ctrl+Alt+F1 to see a text-only login prompt. If you want to get back to the graphical login, press Alt+F7.

## Quiz

1. What programs can you use to create a separate partition in which to install GNU/Linux on the hard drive?

The easiest way to partition a hard drive is with a commercial program such as PowerQuest's PartitionMagic. PartitionMagic leaves a Windows system intact while it creates another partition on the drive in which you can install GNU/Linux. Another reliable method is to use fips. The fips utility also enables you to create a second partition without destroying your Microsoft Windows installation. There is also the DOS fdisk program. This program erases all the data on the disk. Remember to use Windows ScanDisk and Disk Defragmenter, and to back up the system before you use fdisk. You will need to reinstall Microsoft Windows after the partition is created and then you can install GNU/Linux.

2. What are the basic steps involved in installing the GNU/Linux operating system?

Step one is to create a separate partition for GNU/Linux if you plan to run GNU/Linux along with another operating system on the same hard drive. Step two is to start the installation process by placing the installation boot floppy and the distribution CD-ROM in the appropriate drives. You will then need to supply information about the language, keyboard, and installation class that you plan to use. Step three is to set up the filesystem. In this step, you create partitions for the swap space, system files, and user home directories. Some of step four is optional. You are given the opportunity to attach the computer to a network or to the Internet, set the time, configure a printer, and create user accounts. The last step is to configure the X Window System so that you don't have to work at a boring text-only screen.

3. Do you need to install all the packages found on the distribution CD-ROM?

Nope. If you want, you can start with a minimal setup and then add programs as you go along. As long as you have the distribution CD-ROM close by, you can quickly install another application. Also, if you did install everything and later you are running short on hard drive space, you can just as easily remove those applications that you don't use.

4. What is the difference between the superuser account and an unprivileged user account?

The superuser account (which uses the username of root) has unrestricted access to the operating system. This means every file, every command, and every application. The superuser is responsible for system administration duties such as changing the system setup and altering configurations. An unprivileged user account is for all other users. These users can access files in their home directory and common files used by all users (such as help files and program execution files). The superuser should also set up an unprivileged user account in which to work.
