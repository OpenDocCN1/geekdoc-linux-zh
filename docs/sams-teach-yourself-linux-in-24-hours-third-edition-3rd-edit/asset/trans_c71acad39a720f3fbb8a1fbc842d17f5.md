
3. 决定系统和单个文件需要备份的频率。你需要查看文件更改的频率。如果文件经常更改，你可能需要每天执行备份。如果只是偶尔做一两次配置更改，你可以只在更改时备份配置文件。

4. 选择将用于存储文件的存储介质。如果只有几个文件需要备份，你可以简单地将它们存储在软盘上。如果文件更多，请考虑使用 Zip 驱动器或可录制 CD-R/W 驱动器。Linux 一直与磁带驱动器配合良好。尽管磁带备份可能正在被淘汰，但旧设备仍然有很多用途。

5. 找到安全存放文件的地方。存放备份介质最安全的地方是与计算机所在位置不同的地点。该位置还必须防火和其他危险。许多人的首选存储地点是银行的保险箱。其他人可能会使用位于安全存储设施中的防火保险箱。你可能还想在附近保留一份备份副本，以便快速恢复丢失的文件。

## 任务：执行简单备份

最简单的方法是将少量文件备份到软盘上。最简单的方法是使用 cp 命令。如果文件太大无法放入软盘，可以使用 gzip 命令进行压缩。当需要备份多个文件时，使用 tar 命令创建归档，然后使用 gzip 命令压缩归档。尝试以下简单的备份例程，将单个文件复制到软盘上：

1. 将软盘放入软盘驱动器。如果需要帮助格式化磁盘，请参阅第 7 小时，“在文件系统中移动”。如果你从喜欢的仓储俱乐部批量购买已格式化的磁盘，就不需要在 Linux 系统上格式化这些磁盘以使用它们。只需将它们放入驱动器即可开始使用。

在将文件复制到软盘之前，你需要挂载驱动器。为此，请使用以下格式的 mount 命令：

```
mount /dev/fd0 /mnt/floppy
```

2. 更改包含要备份的文件的目录。使用 pwd 命令查看当前位置，使用 cd 命令在目录间移动，使用 ls 命令查看目录中的文件列表。

3. 将文件复制到软盘。使用以下格式的 cp 命令：

```
cp filename /mnt/floppy
```

## 使用存储设备

你有几种存储备份的方法。你的选择取决于需要存储的信息量、计算机预算以及你希望花费多少时间在 Linux 系统上配置设备。

软盘自计算早期以来就被用作备份介质。软盘价格低廉（并且已预先格式化），易于存储，并且每台计算机都配有软盘驱动器，除了一些仅配备 zip 驱动器的 Macintosh 配置。软盘相当可靠，你可以通过正确存储来延长软盘的使用寿命。如果只有几个配置文件需要备份，或者只想备份主目录中的某些文件，软盘效果很好。

当存储空间是考虑因素时，你可能想考虑在 Zip 或 Jaz 驱动器上使用可移动磁盘。这些设备允许你存储超过 100MB 的文件，并且比软盘更可靠。还有一个名为 GtkZip 的实用程序，如图 10.2 所示，可以使管理 Zip 磁盘变得更容易。GtkZip 还可以为 Zip 磁盘设置安全级别。

另一种备份替代方案是第二块硬盘。你可以轻松地将文件（或整个系统）从 Linux 驱动器复制到备用硬盘。由于硬盘在大量使用后才容易出现故障，因此仅用于存储备份的硬盘可能是一种非常可靠的存储介质。然后在需要恢复系统时，硬盘可以比其他介质快得多地完成恢复。

与硬盘价格相近的是可读写的 CD-R 驱动器。该设备允许你制作一次性的、不可覆盖的备份。如果你需要备份文件的永久记录，就应该使用 CD-R 驱动器。你也可以在一张 CD 上归档多达 650MB 的文件。

你为重要备份文件选择存储设备取决于你需要存储文件的空间大小、计算机系统上已连接的存储设备以及你的预算能负担的新存储设备的费用。在考虑存储设备之前，你可能想阅读以下 HOWTO：

- 如果你需要帮助设置和使用 Zip 驱动器，请阅读“Zip Drive”迷你 HOWTO。大多数 Linux 发行版会自动检测任何并行端口版本的 Zip100 并安装必要的驱动程序并创建挂载点。SCSI 和 IDE 内部驱动器现在很常见，它们被视为硬盘。如果你有 Jaz 驱动器，请阅读“Jaz Drive”HOWTO。
- CD 刻录机最近变得对普通家庭计算机用户来说负担得起。“CD-Writing”HOWTO 解释了与 Linux 兼容的 CD 刻录机、如何设置它们，以及你可以使用什么软件将数据文件写入 CD 以及如何将音乐刻录到 CD 上。
- 如果你想将整个硬盘备份到第二块硬盘，请阅读“Hard Disk Upgrade”迷你 HOWTO。此过程允许你在主硬盘故障时只需更换硬盘。

## 任务：节省磁盘存储空间

减少文件大小的一种方法是使用压缩实用程序。你可能有一个文件太大无法放入软盘。如果是这样，使用 gzip 命令压缩文件使其足够小以便放入。你可能在主目录中有不经常使用的文件。如果是这样，节省一些空间并压缩文件。尝试以下压缩技巧：

1. 使用以下方式使用 gzip 命令压缩文件：

```
gzip -v filename
```

此命令告诉 gzip 压缩文件并显示文件的压缩百分比。原始文件将被压缩文件替换，并在文件名末尾添加扩展名 .gz。例如，用户 rusty 有三个不常用且占用空间的文件（文件列表出现在图 10.1 中）。当 rusty 执行以下命令时

```
gzip -v 23FIG??.pcx
```

屏幕上会出现以下内容：

```
23FIG01.pcx: 76.1% -- replaced with 23FIG01.pcx.gz
23FIG02.pcx: 76.1% -- replaced with 23FIG02.pcx.gz
23FIG03.pcx: 76.1% -- replaced with 23FIG03.pcx.gz
```

此列表显示原始文件名、压缩百分比以及压缩文件的新文件名。

2. 使用以下方式使用 gunzip 命令解压缩文件：

```
gunzip filename
```

例如，如果 rusty 想解压缩名为 23FIG01.pcx.gz 的文件，他会输入以下内容：

```
gunzip 23FIG01.pcx.gz
```

文件被恢复到原始的未压缩状态，可以由能够读取该类型文件的应用程序使用。

3. 使用以下方式使用 gzip 命令压缩目录中的每个文件：

```
gzip -rv directorypath
```

如果 rusty 想压缩位于用户主目录中的 corresp 子目录的内容，将使用以下命令：

```
gzip -rv /home/rusty/corresp
```
