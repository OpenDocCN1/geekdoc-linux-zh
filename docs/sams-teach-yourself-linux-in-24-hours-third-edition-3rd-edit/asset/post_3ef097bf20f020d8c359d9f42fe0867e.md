## Using an Office Message Board

In addition to the write and talk commands, you can communicate with users over the network in other ways. The first way is to change the message that appears before the login prompt. Another way to leave messages for all users is to change the message that appears after a user logs into his or her account.

## Changing the Login Message

There may be times when you want to relay information to users before they log into the system. Linux uses the /etc/issue file to change the information that displays on an unused terminal. You can use this file to add your company name to the login screen, to notify users of company policy regarding logins, or to post the hours that the system is available for use.

## Task: Customizing the Login Screen

When you want to display a message on an unused terminal that anyone can read, you'll need to edit the /etc/issue file. Here's how to open the vi text editor and make a few changes:

- 1. Log in as superuser.
- 2. Open the /etc/issue file in the vi text editor. Type vi /etc/issue and press Enter. The file appears in the text editor and may look something like the /etc/issue file shown in Figure 20.5.

## Creating a Message of the Day

Another way to leave messages for users is to create a message of the day that users will see as soon as they log into their accounts. This message appears after a user logs in and just before the shell prompt. In order to create a "message of the day" file, open the file named /etc/motd in a text editor and add any text you want. If this file does not exist, you'll need to create it. Figure 20.6 shows a sample /etc/motd file.

## Q&A

Q I've set up several user accounts in which to work. I use one account for my everyday work, and I use the other account to test out the new things I learn about Linux. I sometimes get confused as to which account I am using. Do you have any help?

A When you want to know who you are, at the shell prompt type who am i and press Enter. This command will tell you the name of the computer at which you are working, the domain (if the computer is attached to a network), the username, the terminal at which you are working, and when you logged in.

Q I know I can use the finger command to find people on the Internet. Can I use the who command to search for people on the Internet?

A If you want to find someone on the Internet, you'll need to use the finger command. The who command only lists those users who are logged into the same system you are logged into.

Q How do I spell check the login message file and the message of the day file?

A Use the ispell command. After you have created a message of the day file or a login file, save the file and close it. To check the spelling of the message of the day file, type ispell /etc/motd and press Enter. Although any user can use the ispell command, only the superuser can spell check restricted files (such as /etc/motd and /etc/issue). To learn more about ispell, read the manual page by typing man ispell at the shell prompt.

## Quiz

- 1. What are the two different ways you can network computers using Linux?
  
  The first is the client/server network, where one computer acts as a server and workstations are attached to the server through a network hub. A client/server network makes it easy to share computer resources, files, printers and other peripherals, and an Internet connection.
  
  Another way to build a network is to attach a series of terminals to a host computer using serial interface cables. You can attach dumb terminals, text terminals, graphics terminals, and network computers using this method.

- 2. Which two commands tell you who is logged into the computer? What kinds of information do they display.

The `who` and the `finger` commands display the users who are logged into the system, at which terminals they are working, and the amount of time they have been logged in. The `finger` command can also be used to display information about an individual user. The `finger` command not only identifies the user but also displays additional information such as an office and phone number. The `finger` command can also display information supplied by the user (through the .plan file).

- 3. Which commands can you use to send messages to other users on the system?

The `write` command sends a short message to another user. The recipient of the message will also need to use the `write` command in order to respond. The `wall` command will send a single message to every user. The `talk` command is used when a real-time conversation is needed. The `talk` command displays information on the recipient's terminal while the sender is typing at the keyboard.

- 4. If you don't want to receive messages from other users, how do you notify them?

Use the `mesg` command. By typing `mesg n`, whenever another user tries to send you a message (using either the `write` or `talk` command), he or she is notified that you are not currently accepting messages. When you are ready to receive messages, type `mesg y`.
