# The Ins and Outs of the Linux Electronic Mail System

There are two ways to deal with electronic mail on a Linux system. The first way is to use a mailer to send and receive email. You can use this method if you retrieve mail from the ISP by using the POP3 or IMAP protocol and send outgoing mail by using the SMTP protocol. The mailer can take care of all the necessary protocols and knows the name of the mail server that stores your mail. Several mailers are available on your Linux system, and Netscape Messenger is just one of them.

Another mailer that you might want to look into is Kmail (shown in Figure 22.5). You'll find many of the same features in Kmail that you saw in Netscape Messenger. In both mailers, you have the ability to filter and sort messages as they are downloaded from the server. You can also create new folders in which to store messages. If you are using the GNOME desktop environment, you might want to try Balsa.

> You can use several mail notification utilities with Kmail. You might want to try KNewMail or the Biff utility. The commands for these are their names all in lower case.

The second way to deal with electronic mail is the network method. The network method uses the mailer to display incoming mail, compose new messages, and store message files. The difference is that the mailer uses a mail transport agent to route mail from the sender to the recipient. By using a mail transport agent, you can send mail to someone who works at the same company with you or someone logged into the Internet a million miles away. The mail transport agent then relies on a transport protocol to transfer the mail messages across the wires.
