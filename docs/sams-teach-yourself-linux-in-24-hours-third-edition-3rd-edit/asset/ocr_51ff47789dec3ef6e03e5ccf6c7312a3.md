2. If you need to encrypt files to ensure that unauthorized eyes do not see the information, you might want to check out the GNU Privacy Guard at www.gnupg.org. This is a free, Open Source replacement for PGP that can be used without restrictions. It decrypts and verifies PGP encryptions, and supports signatures and encryption. The GNU Privacy Guard can also be used as a filter to strain out stuff that you don’t want appearing in your email inbox. GNU Privacy Assistant is a graphical interface for the GNU Privacy Guard that you will find helpful.
