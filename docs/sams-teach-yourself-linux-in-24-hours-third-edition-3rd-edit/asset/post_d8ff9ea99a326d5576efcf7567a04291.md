## The Syntax for the ls Command

The ls command lists the contents of a directory in a variety of formats and the files are listed vertically. If no options are used, the names of files and directories (but not hidden files) appear in columns across the screen. The following code shows the syntax for the ls command:

```
ls [options] [filenames]
```

Try these useful command options:

- To list the files horizontally instead of vertically, type ls -x and press Enter.
- File information such as permissions and owners, file size, and modification date for each file can be displayed in the long listing. Type ls -l and press Enter.
- To display all files including any hidden files, type ls -a and press Enter. If you want to include the hidden files in the long listing, type ls -la and press Enter.
- Different characters can be added to the end of a filename to make it easier to recognize different file types. Type ls -F and press Enter. A slash (/) appears after directories, an asterisk (*) after executable files, and an at (@) character after symbolic links.

> You can use multiple command options after the dash (-) character (for example, the ls -la command). It does not matter in which order the command options appear, so ls -la and ls -al provide the same output. You can only use multiple command options with commands that use single letters to specify command options.

## Redirecting the Command Output

Displaying a file list in the long list fashion is fine if the file list isn't too long and fits on the screen. If you have a long list of files, the list will just scroll on past and you'll miss most of the information. You have choices—you can display the file list in a pager (such as less) or you can send the output to a file or to the printer. This looks like a good time to practice those pipe and redirection skills.

If you send the output to the less pager, you can scroll through the list at your leisure. To send the file list to the pager, type ls -l | less and press Enter. By sending the output to a file, you'll need to display the file in a text editor. To create the text file, type ls -l > filename.txt and press Enter.

## Task: Displaying the ls Command Options

It's hard to remember all the command options associated with every command. Here's a quick way to list the command options for the ls command:

- 1. Type ls --help | less and press Enter. The list of options that can be used with the ls command will display in the less pager.
- 2. Use the arrow keys to read through the options section of the ls manual page.
- 3. Make a note of any file list command options that might be helpful to you.
- 4. Press Q to exit the less pager and return to the shell prompt.

## Expanding the Directory Tree

As you work with applications, you'll need a place to store your work. The best place for you to store these files is in your user account. Now, you could just save all your files in your home directory, but things would become confused after a while. To help organize your filing system, create directories in which to store related information. To keep track of correspondence, spreadsheets, and scanned photographs, create directories for each type of file. If you run a small business, you might want to create directories for each client or project.

## Creating Directories

When you want to create a subdirectory within the working directory, use the mkdir command. The easiest way to create a new directory is to make the directory in which you want the new directory to appear the working directory.

For example, user rusty wants to create a subdirectory named letters in which to store correspondence with family and friends. If the working directory is /home/rusty, a subdirectory named /home/rusty/letters is created by using the following command:

```
mkdir letters
```

To make sure that the subdirectory exists, use the ls command. Then, to change from the home directory to the new directory, use the cd command. The cd command makes the specified directory the new working directory. In the previous example, user rusty would change to the letters directory by typing cd letters. The shell prompt changes to show the new working directory, as shown here

```
[rusty@localhost letters]$
```

Then, to confirm that you are indeed in the directory in which you intended, use the pwd command to verify the working directory.

> To get back to your user home directory, type cd by itself on the command line and press Enter.

## The Syntax for the mkdir Command

If you remember DOS commands, you'll find a number of similarities when it comes to creating, deleting, and copying directories (and files, too). It is easiest to create a new directory with the mkdir command if the working directory is the directory that will contain the new directory. The following shows the syntax for the mkdir command:

```
mkdir [options] directoryname
```

The directoryname parameter is the name of the new directory to be created. This directory will be the child directory of the working directory.

There are two command options that you can use with the mkdir command that you'll find helpful:

- To create a parent directory with a series of subdirectories, use the parents (-p) command option. For example, you might want to store your correspondence files in a separate directory within your home directory. Within this directory, you plan to have a directory for each client, and within each client directory, there will be a separate directory for each year's correspondence. Using this example, type mkdir -p corresp/client/2000 and press Enter to create all three directories. This is much easier than creating the corresp directory, changing to the corresp directory (with the cd command), creating the client directory, and....
- You can also assign access permissions to the newly created directory with the mode (-m) command option. You'll learn how to assign file permissions to directories in Hour 12.
