## An Overview of the Installation Process

If this is your first attempt at installing the GNU/Linux operating system, you should familiarize yourself with the process before you begin. This is not an easy operating system to install, but if you are prepared, you can avoid a lot of frustration. Here's a summary of the steps that you will go through to install GNU/Linux on your computer:

- If you plan to run GNU/Linux on the same machine on which you run Microsoft Windows, you must create a separate space for GNU/Linux to live. You have two options: either add a second hard drive or partition the Windows drive. Many distributions enable you to partition the drive during the installation process. Other distributions require that a separate partition (in which the distribution will live) must be created before you start the installation.
- Start the installation process. You'll need the installation boot disk (that you created in Hour 1, "Gearing Up for the Installation") and the Linux-Mandrake CD-ROM (or, if you selected another distribution, use that CD-ROM). At the beginning of the installation process, you will be asked some basic questions about your system—your language, mouse, and keyboard.
- Set up filesystems and format partitions. GNU/Linux can store everything on a single partition—system files, configuration files, and user data files—but this is not a good idea. To make life a little simpler in case you run into problems, you should set up at least three partitions: one for swap space, one for system files, and one for user files.
- Configure hardware and set up user accounts. During the installation, you have the opportunity to create a dialup connection to the Internet, set the system clock, configure a printer, and add user accounts. If you'd rather wait until you have more time and experience, you can skip the printer and dialup connection for now and add them at another time.
- Before you can use any of the many graphical user interfaces designed for GNU/Linux, you must install and configure the X Window System. The X Window System controls the video card, the monitor, and the monitor display (such as the screen resolution and color depth). This is the trickiest part of the installation, and it is important that you have your video card and monitor specifications handy.

## Partitioning Your Hard Drive

The Linux-Mandrake distribution in the back of this book and many of the other distributions have provisions in the installation program for partitioning the hard disk to make room for GNU/Linux. You can do this without damaging your Microsoft Windows installation or any of the data on the drive.

> Before you attempt to install any GNU/Linux distribution, or partition a hard drive, make sure you are prepared and that your computer is prepared. Learn as much as you can about this new operating system. If you would rather purchase a computer system with GNU/Linux already installed, visit the GNU Project Web site at www.gnu.org/links/companies.html.

> Fortunately or unfortunately, not all distributions are the same. The Slackware and Debian distributions do not have automated disk partitioning in their installation programs. If you are installing either of these distributions or another Linux distribution that isn't automated, you will have to partition the drive by hand (using a utility, of course).

If you are installing Linux on a Windows computer with only one hard drive and you want to be able to boot one operating system without involving the other one, you will have to make provisions to share the drive. There are several partitioning tools and methods from which you may choose.

> Prepare your hard drive before the installation whether you are creating a partition or not. Run ScanDisk and Disk Defragmenter from the Windows operating system before you begin.

The DOS fdisk program can be used to partition the drive, but it will wipe out all the data on the disk. If you use DOS fdisk, you will need to back up the Windows system before you begin, partition the drive with the fdisk program, reinstall Windows, and then you can install Linux.

If you don’t want to destroy the Windows data, you can use the fips utility to partition the drive. fips has been around for a while but it makes no guarantees and you should still back up your system. The fips utility can be found on the installation CD-ROMs for most distributions; if it is not on your CD, it can be downloaded from a mirror site.

Another option is to use a commercial disk-partitioning program such as PowerQuest’s PartitionMagic. These tools are usually not expensive and they have some nice features. PartitionMagic will leave your Windows system intact while it creates other partitions on the drive. It will also enable you to move data and programs between partitions and resize partitions on-the-fly.

Whichever method you use, you will need to create an empty unformatted partition on the drive. The partition you create will be divided and formatted by the installation program to make it a good home for the Linux file system.

## Following the Installation Process

Are you ready? Have you collected all the information you need about the computer? Have you prepared the hard drive? Do you have the distribution CD-ROM and the installation boot disk in hand? If you answered yes to all these questions, place the installation boot disk in the floppy disk drive, the CD-ROM in the CD-ROM drive, and restart the computer. Even if your computer boots from the CD-ROM drive, it is important that you create the installation boot disk and keep it close to the system at all times.

When the computer restarts, you’ll see an opening screen. At this point, press F1 for a short introduction before you start, or press Enter to begin the installation. Before the installation process gets underway, the system will be scanned to detect hardware attached to the system. The installation process will look for the hard drive, the CD-ROM drive, and any SCSI adapters (such as a parallel port Zip drive). After this is done, the first installation screen appears, which asks you to choose a language. Before going any further, here’s how each of the Linux-Mandrake installation screens works:

- Along the left edge of the screen is the list of steps that the installation process follows. You’ll want to take each of these steps in order. As you progress through the installation, steps that have been completed show a green star, steps that are in progress are indicated with an orange star, and those steps that have not been performed show a red star.
