# Task: Working with the RpmDrake Package Manager

In Hour 14, “System Maintenance,” you learned that one way to create more space on your hard drive is to remove those programs that you don’t use. It might be hard to know what it is that you don’t use if you don’t know what you have that you aren’t using. An easy way to learn about the applications installed on the system (and those that weren’t installed originally) is to use one of the graphical front ends for the RPM system. Here’s how to use the Linux-Mandrake tool, RpmDrake, to manage applications on your system:

+   1. Open RpmDrake. Click the DrakConf icon on the desktop and click RpmDrake from the selection of configuration tools. Or, you can type rpm drake in a terminal emulator. The RpmDrake utility updates its database of installed packages and then appears on your screen (as shown in Figure 15.2).

> If you are not logged in to the superuser account, you will be asked for the root account password.
