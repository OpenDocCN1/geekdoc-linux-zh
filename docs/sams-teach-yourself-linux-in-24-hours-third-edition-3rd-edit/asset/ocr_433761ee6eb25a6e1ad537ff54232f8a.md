GNOME, and fvwm. Without switchdesk, changing your desktop environment means editing configuration files. The problem is that many Linux distributions do not always use the same files. So, we're going to cheat, and have the system create some files to get you started. Then all that needs to be done is one simple edit to one file. So, let's get started:

+   1. Log in to your user account and start the default desktop environment. Type startx and press Enter.
+   2. List the window managers that are installed on the system. Look at the file that lists the window managers that are loaded on your system. To do this at the command line, type less /etc/X11/window-managers and press Enter. Your output might look similar to the example in Figure 19.1.

As you can see, this file is organized into snippets of information and code for each window manager (each entry is separated with the ... line). These contain the name of the window manager, the name of its icon file, a short snazzy description, the location of its startup file, and the command entry that you need to put in the .Xclients file in your home directory to make it the default window manager.
