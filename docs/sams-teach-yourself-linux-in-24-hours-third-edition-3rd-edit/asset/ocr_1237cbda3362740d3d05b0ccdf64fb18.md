# Navigating a Virtual Desktop

If you work with several applications at one time, you may want to organize your work by using different desktops for each task. Different applications can be displayed on a different virtual desktop and each desktop can use a different background to help distinguish between desktops. For example, you might want to open an HTML editor and a graphics program on one virtual desktop where you are creating a Web site. On another virtual desktop, you can run an email program and a calendar to keep track of your daily business. And, on another virtual desktop, you can keep a chess game running that can hide easily when it's time to get back to work.

> it's easy to get lost when working with more than one desktop. Don't use more virtual desktops than you actually need, and give each desktop a descriptive name. To customize the virtual desktop settings, right-click on the panel and select Configure to display the KPanel Configuration dialog box. Click the Desktops tab and use the Visible slider to change the number of desktops. Then type a descriptive title for each desktop.

But what do you do when you want a window to appear on all virtual desktops? Here's where the Sticky button, found on the title bar, comes into play. If you need to keep your calendar in front of you to remind you of what needs to be done, make the window in which the calendar program resides sticky. This is done either by clicking on the Sticky button or by selecting Sticky from the Window menu.

# Changing the Desktop Appearance

Now it's time to have a little fun and decorate the desktop. One way to spruce up the desktop is to use a color, a combination of colors, a pattern, or an image as the background for the desktop. When you want to hide the desktop while you are away from your desk, try a screensaver.

# Changing the Desktop Background

You'll find a wide assortment of colors and wallpaper images that can be used to decorate the desktop background. To find these colorful images, start at the KDE Control Center, expand the Desktop category, and select the Background configuration module (shown in Figure A.5). If you are working with the virtual desktops, you can give each desktop a different background or make all the backgrounds the same (by placing a check in the Common Background checkbox).
