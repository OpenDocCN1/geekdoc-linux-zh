# Exercises

+   1. Have a meeting with your system users and find out what kinds of storage requirements they have for the files they create. Then, create a plan (which you can include in your Linux diary) for limiting each user to an acceptable level. You can also take this time to plan for future storage needs. If your users plan to create a number of graphics and multimedia files, you may want to think about adding another hard drive to the system. This is also a good time to talk to users about using their home directories responsibly. They can keep things in order by performing regular backups and compressing files that are used infrequently.
+   2. If you created group accounts in which your users can share files, consider setting limits on the files assigned to specific groups. Determine each group's file storage needs and then set disk quotas for each group.
