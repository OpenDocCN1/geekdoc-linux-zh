> An odd minor number designates a development kernel. Please understand that we are not suggesting that you upgrade to version 2.3.x. Particularly because at the time of this writing, the production 2.4 kernel is just around the corner. However, you can look at your installed system, using the commands in Table 16.1, and get an idea of what you will have to upgrade before you can compile a new kernel and install it on your machine.

New kernel iterations appear in response to Linux users' desires to have drivers for a new gadget or to have bugs fixed. There are certainly other reasons, but the big focus for most Linux users is on new drivers and bug fixes.

# Working with Kernel Modules

New additions to the kernel for new drivers and bug fixes are managed through the use of kernel modules. Some of these are dynamic modules that can be can be loaded when needed and removed to free up space when they are not being used. This helps to keep the size of the kernel manageable. New drivers don't have to be built into the kernel itself; they can be made into modules.
