
- Enlightenment’s goal is to be the most configurable window manager. Not only can you select between different border and window styles, but you can also design your own. In fact, you can configure every detail about Enlightenment. A graphical configuration utility gives you control over the look and feel and enables you to select between themes. Enlightenment is the window manager that is most compatible with the GNOME desktop.
- The kwm window manager supports the KDE desktop and its large array of tools, utilities, and applications.
- The xwm window manager is the native X Window System window manager. It runs applications in separate windows called xterms. It has a small memory footprint and is particularly suited to running X Window System applications over a network.
- Sawfish (which might still be called Sawmill in your distribution) is a lightweight and fast new entrant that many GNOME users are finding very nice to use. It is the default for GNOME in the Linux-Mandrake distribution.

In addition to these window managers, there are probably an additional three-dozen other window managers that do the same job to varying degrees. You can download many of them from the Internet; some are free, and some are not. You might even have several of them that were included with your Linux installation.

If you installed the Linux-Mandrake distribution, during the installation you were asked whether you wanted to install additional window managers. If you elected to do so, changing to another of these window managers can be a simple exercise in script writing. Even simpler, if you are using the GNOME and KDE desktops, you can use a graphical tool for changing your window manager and desktop. It is called switchdesk. To use switchdesk from inside either desktop, you can select it from the menu, or type switchdesk in a terminal emulator. To learn more about using switchdesk see Appendix A.

## Q&A

Q In Hour 2, “Installing Linux-Mandrake,” you suggested that I elect to NOT start the X Window System when Mandrake boots. My friend has this really cool graphical login screen with a cute picture for each user. Where can I get one of these?

A Your friend is probably using the KDE Display Manager. This graphical tool enables you to create a graphical login screen with a welcoming message and a list of all the users who can log in from this screen. You’ll find the KDE Display Manager in the GNOME and KDE menus. You can also type kdmconfig at the command line.

Q Is there any way that I can start applications automatically when I start an X Window session?

A In your home directory, you might find a file called .xinitrc. If you don’t have a copy of this file, you’ll find one in /usr/lib/X11/xinit/xinitrc. You can copy this file to your home directory. You’ll need to edit this file to add the execution commands for those files that you want to load automatically.

Q How do I find out which fonts are installed on the system?

A Try the xfontsel utility. Type xfontsel at the command-line to start the utility. Read the manual page (type man xfontsel) to read more about the utility. In Linux-Mandrake, you can try the DrakFont program. If you are running a dual-boot system and have Microsoft Windows installed, you can transfer your favorite Windows fonts to your Linux system. In KDE, you can try the KDE Font Manager.
