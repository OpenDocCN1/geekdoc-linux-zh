Changing the desktop configuration is done from the Control Center, which groups the different options by configuration modules. To see the list of configuration modules, click the plus sign next to each of the different categories. Here are some changes that you might want to make to your desktop:

+   - Have some fun with the desktop background and select the Background configuration module. Select from a variety of single colors to make a background that makes it easy to see other screen elements, such as windows and desktop icons. A two-color gradient blends one color into another on the desktop, which makes for a psychedelic look that's also easy on the eyes. If you'd like a little more scenery, select a pattern or image file (you'll find several in the /usr/share/pixmaps directory). You can even scan one of your own photographs and use it as your wallpaper.
+   - Hide the panel when you don't need it. The Panel configuration module not only turns off tooltips, it also sets the auto-hide delay for the panel, sets the default icons for launcher and menu icons, and sets the spacing between panel icons.
+   - It's a good idea to set the Screensaver configuration module to take charge of the system when it is not in use. The original idea for screensavers was so that a single static image did not display on the screen for a long period of time, thereby causing the image to become "burned" into the monitor. Screensavers also enable you to password-protect the screen so that others cannot use the computer while you are away.
+   - The window manager controls the look of the window border; that is, the color of the title bar and the placement of the title and window buttons. If you want to change the look of the window dressings, click the Appearance configuration module for the default window manager.
