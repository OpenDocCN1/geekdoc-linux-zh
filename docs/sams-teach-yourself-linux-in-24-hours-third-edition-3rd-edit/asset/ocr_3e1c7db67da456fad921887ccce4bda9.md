# Printing Files

When you installed the Linux operating system, you were given the opportunity to set up and configure a printer for the system at that time. If you set up a printer during the installation, you are happily—and hopefully conservatively—making paper copies of your files. If you did not set up your printer during the installation, or if you have changed printers or added a second printer, you’ll need to use one of the configuration tools found with your Linux distribution to get the printer working properly.

In this hour, you will:

+   - Learn how the print system works in Linux
+   - Attach a printer to the computer and test the connection
+   - Configure the print services for the printer
+   - Print files and troubleshoot print problems
