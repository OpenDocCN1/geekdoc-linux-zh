# Monitoring the System on a Regular Basis

There is no substitute for paying attention. The security of your system is entirely dependent on how well you monitor the system and how diligent you are when adding new users, installing new software, and upgrading old equipment. The allocation of system resources should be the best for managing the system. In a multi-user system, this means disk space allocations for each user, backup requirements for user's files, printer priorities, and many other considerations. In a workgroup, resource allocations must be monitored to fit the needs of the group and best benefit the project.

There are built-in monitors that will help you keep track of the operating system's activities. You can monitor the way that users make use of resources, and you can use that information to help you schedule maintenance and necessary system downtimes.

# Checking CPU Activity

Through the aid of one or more small monitoring applets available with most GUIs, or by working with commands on the command-line, it is possible to obtain information about the system's resources. The information about CPU usage is helpful in deciding whether you can run additional processes on the system at peak times. It enables you to see when peak times occur, and how much of a load is placed on the CPU by adding more applications. Some of the more CPU-intensive applications can be saved and run when the CPU load is not at its peak.
