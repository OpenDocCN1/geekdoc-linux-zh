The DOS fdisk program can be used to partition the drive, but it will wipe out all the data on the disk. If you use DOS fdisk, you will need to back up the Windows system before you begin, partition the drive with the fdisk program, reinstall Windows, and then you can install Linux.

If you don’t want to destroy the Windows data, you can use the fips utility to partition the drive. fips has been around for a while but it makes no guarantees and you should still back up your system. The fips utility can be found on the installation CD-ROMs for most distributions; if it is not on your CD, it can be downloaded from a mirror site.

Another option is to use a commercial disk-partitioning program such as PowerQuest’s PartitionMagic. These tools are usually not expensive and they have some nice features. PartitionMagic will leave your Windows system intact while it creates other partitions on the drive. It will also enable you to move data and programs between partitions and resize partitions on-the-fly.

Whichever method you use, you will need to create an empty unformatted partition on the drive. The partition you create will be divided and formatted by the installation program to make it a good home for the Linux file system.

# Following the Installation Process

Are you ready? Have you collected all the information you need about the computer? Have you prepared the hard drive? Do you have the distribution CD-ROM and the installation boot disk in hand? If you answered yes to all these questions, place the installation boot disk in the floppy disk drive, the CD-ROM in the CD-ROM drive, and restart the computer. Even if your computer boots from the CD-ROM drive, it is important that you create the installation boot disk and keep it close to the system at all times.

When the computer restarts, you’ll see an opening screen. At this point, press F1 for a short introduction before you start, or press Enter to begin the installation. Before the installation process gets underway, the system will be scanned to detect hardware attached to the system. The installation process will look for the hard drive, the CD-ROM drive, and any SCSI adapters (such as a parallel port Zip drive). After this is done, the first installation screen appears, which asks you to choose a language. Before going any further, here’s how each of the Linux-Mandrake installation screens works:

+   - Along the left edge of the screen is the list of steps that the installation process follows. You’ll want to take each of these steps in order. As you progress through the installation, steps that have been completed show a green star, steps that are in progress are indicated with an orange star, and those steps that have not been performed show a red star.
