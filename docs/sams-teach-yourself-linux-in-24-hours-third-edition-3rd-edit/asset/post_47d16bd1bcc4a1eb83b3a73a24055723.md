## Talking to the Shell

Linux uses the GNU readline command line editor to read and write to the command line. The readline editor is what you see at work when you type text after the shell prompt or read responses there. The editor can also edit whatever is on the command line. To use the command line, just begin typing after the shell prompt. You'll see the cursor is just one character ahead of you. If you make a mistake, just press the Backspace key to erase the text. Use the left and right arrow keys to move back and forth across the command. One way to reduce the number of keystrokes that you type at the shell prompt is by using command line completion. Command line completion means that you type part of the command or program name and then you ask bash to finish your typing. If you type part of a command or application name on the command line and press Tab, bash attempts to finish the command for you. The bash shell searches through the system for all the commands and application names that match what you have typed in so far and completes the command as far as it is able. If the shell received insufficient data to make a choice, you will be presented with a list of possible completions. This makes it a simple matter to finish the command entry. To see this feature in action on the command line, type bas and press Tab.

After you press Tab to complete the command, command line completion will also attempt to finish filenames for you. If you begin typing the filename and then press Tab again the shell looks for possible matches in the files listed for the current working directory.

Another way to reduce keystrokes is by using wildcards. Wildcards take the place of other characters in the command line. The bash shell uses three different wildcards:
- The asterisk (*) character matches any number of characters.
- The question mark (?) matches a single character.
- Brackets ({ and }) are used to match specific characters contained inside the brackets.

The bash shell and some of the other shells have a command history option that enables you to resubmit commands without having to type them in again. The way to access the command history is to use the up and down arrow keys to move up and down the list. Each of the previously typed-in commands will appear on the command line. You can press the Enter key to use any of the commands again. This feature can be a lifesaver if you are doing something that requires tiring repetitious typing of the same complex commands. The default number for the number of commands to be kept in the history is user configurable.

## Telling the Command Where to Go

When you use the command line to start a program in Linux, the shell interprets your command, sends it to the kernel, and the output of your program goes to the standard output (usually the screen). The program's output to the standard output can be redirected to a file. Remember that Linux sees everything as a file, so the standard output can be redirected to a file, a printer, an additional monitor, another terminal, or any other output device that you might have connected to the system. The output can also be redirected to be the input for another command or program.

> Be careful when redirecting command outputs. Redirecting the output to a file will create the named file and put the output in it. If you redirect the output to an existing file, the contents of that file will be overwritten and gone forever.

## Creating Shortcuts for Long Commands

You might find that you type a number of commands on a regular basis. For example, if you use the online Linux help system, you might find yourself going to some obscure directory such as /usr/doc/HOWTO/HTML/en/mini. Let's do the math...add the cd command to the directory path and you get 31 keystrokes (and that doesn't count holding down the Shift key). To reduce the number of keystrokes, create an alias.

> **New Term** A command alias is a unique, short name that is assigned to a command. Command aliases make it easier to remember long commands by assigning a nickname to them. Instead of typing the complete command, you can just type the alias. Aliases can also help you reduce fatal mistakes when working with files. You can assign aliases to commands so that you are asked whether you really want to delete a file.

To create an alias for the following command

```
cd /usr/doc/HOWTO/HTML/en/mini
```

use the alias command. First, you will need to think of an alias name for the command. Because this command changes to the directory in which the text versions of the Linux HOWTOs are stored, a sample alias name might be gotoHOWTO. To create this alias, at the shell prompt, type

```
alias gotoHOWTO='cd /usr/doc/HOWTO/HTML/en/mini '
```

The alias command is followed by the alias name. The equal sign (=) precedes the command that will be executed when the alias name is typed at the shell prompt. Do not use spaces on either side of the equal sign. If the command contains spaces or wildcard characters, surround the command with quotation marks.

Now to change to the HOWTO directory, just type gotoHOWTO at the shell prompt and press Enter. Keystrokes have been reduced from 31 down to nine.

Are you security conscious? You can prevent yourself from accidentally deleting, copying, or moving files while you are working in the filesystem. In Hour 7, you'll learn how to use the rm (delete the file), cp (make a copy of the file), and mv (move the file to a new location in the filesystem) commands to work with files. One danger when working with these commands is that Linux doesn't tell you what it is going to do when you execute the command. You can easily protect your hard-earned data files by creating aliases for these commands that force the command to ask you whether you really want to perform the specified action on the file.

To change the rm, cp, and mv commands so that they work in interactive mode, use the following alias commands:

```
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'
```

Whenever you use these commands, you will be asked to confirm the action before the operating system will begin moving and deleting files. (cp and mv will prompt only if the destination file exists.)
