# Task: Searching the Manual Pages for Games

One way to learn how to use a game is to read the help manual, which can be found by opening the Help menu. Another way to learn the rules of a game is to read the manual pages. Many of the programs installed on your system have manual pages. Here's how to read the manual pages for many of the games installed on your system:

+   1. Type `man -K game` and press Enter. The manual page system will be searched and the first instance of the word game that is found in a manual page will appear. Here's one of the things that displays first on a system running Linux-Mandrake:
+   
+   `/usr/man/mann/guru.n.bz?? [yng]`
+   
+   In this example, you are asked whether you want to read the manual page for a program called guru. The three characters inside the brackets are the commands for the responses that the system can process
+   2. Decide whether you want to read the manual page. Type y and press Enter to read the manual page; type n and press Enter to show the next manual page listing in the search; or type q if you want to quit and return to the shell prompt.
+   3. While browsing the manual pages, keep track of the games that sound like fun.
+   4. When you come to the end of the list, the shell prompt will appear. Try another search. For example, you might want to try `man -K solitaire`.

![](bbox=[0.12, 0.7, 0.22, 0.78])

> The -K option searches every single manual page for the specified search string. This might be a slow process, depending on such factors as the speed of the computer.
