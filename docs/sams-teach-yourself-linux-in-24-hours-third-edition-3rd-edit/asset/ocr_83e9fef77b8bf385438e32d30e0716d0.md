Like the /etc/passwd file, each group has a separate entry in the /etc/group file. Each entry contains four fields, with each field separated by the colon (:) character. In order of appearance, these fields are

+   - The name given to the group.
+   - The password field, which is optional. This field usually contains the x character. You can give a group a password so that users who are not part of that group can access the group's files. The outsider would need to use the newgrp command to access the group.
+   - The group identification number.
+   - The list of additional users who have been assigned to the group. These are users who do not have this particular group listed in the group identification field of the /etc/passwd file.
