# Exercises

+   1. Explore the /usr directory on your own. This will give you a chance to see what kinds of cool applications are installed on your computer and read some of the help files that are supplied with the programs. Turn to Hour 7, "Moving Around the Filesystem," to learn more about the navigation commands you need to view the contents of a directory.
+   
+   2. Take a look at some of the other system log files. Use this time to become familiar with the log files because you’ll be working with them as you progress through this book. Don’t worry if you don’t understand everything right now. If you have several users on the system, you may want to see who is logged into the system by looking at the /var/log/wtmp file. To see when the system was shut down or rebooted as well as to see the successful user logins, read the /var/log/wtmp file. To see who has unsuccessfully tried to log into the system (this could help you trace a possible security problem), read the /var/log/btmp file. Another way to see if your system is secure is to look at the /var/log/secure file.
