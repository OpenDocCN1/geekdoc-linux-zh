# Hour 14

# System Maintenance

You’ve made it past the halfway mark and you’ve probably spent a considerable amount of time with the Linux operating system. Before you go any further, it’s time to take a short rest and see how well your system is performing. You’ll need to check on the hard drive to make sure it has enough space for more applications and user files. You may also want to check on how the system users are taking advantage of the system, and how efficiently the system uses resources to take care of the users. This hour shows you how to monitor system usage and how to interpret what is going on. Once you know what is happening with the system, you can then begin to manage your computer resources more efficiently.

In this hour, you will:

+   - Determine how fast your hard drive is filling up and how to create extra space
+   - Keep track of user activity on the system and limit the amount of space in which a user can store files
+   - Reset the clock when the displayed time is not correct
