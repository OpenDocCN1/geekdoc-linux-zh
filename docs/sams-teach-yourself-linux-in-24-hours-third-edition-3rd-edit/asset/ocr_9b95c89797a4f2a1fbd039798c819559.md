# FIGURE 20.3

You will have to wait until your invited guest joins the conversation.

![](bbox=[0.38, 0.17, 0.78, 0.55])

When rusty receives the request from mona for a little talk, a message like the following will appear on the screen:

```
Message from Talk_Daemon@localhost at 17:37 ...
talk: connection requested by mona@localhost.
talk: respond with: talk mona@localhost
```

The last line of the message tells rusty what command to use to connect with mona. In order for rusty to chat with mona, rusty would type talk mona@localhost at the shell prompt. When rusty has responded, both terminals display a message saying that the connection was established. Now that the two users are connected, they can begin their conversation. The user who is sending the message will type the message in the top half of the screen (don't worry about placing the cursor; the talk command does that for you). Responses from the recipient user appear in the bottom half of the screen. An example of a talk conversation is shown in Figure 20.4.

The talk command sends everything you type to the recipient as you type it. There are no special characters to type to display the message on the recipient's terminal. When the talk conversation is concluded, press Ctrl+D to end the session.
