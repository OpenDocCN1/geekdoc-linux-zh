## Task: Finding Linux Newsgroups

You'll find a wealth of Linux help on the Internet and good sources are the Usenet newsgroups. The newsgroups are great places to just lurk around and read about other people's problems. After you get the feel for a newsgroup, you might get brave and venture to ask a few questions of your own. Here's how to use Netscape Messenger to read the Linux-related newsgroups:

- 1. Set up an NNTP news server. From the Navigator browser, select Edit, Preferences. Expand the Mail & Newsgroups category and select Newsgroups Servers. Enter the information supplied by your ISP and the information for any other news server (there are some free ones) that you may use.
- 2. Open Netscape Messenger. Select Communicator, Messenger.
- 3. Download the list of newsgroups from the news server. Select the news server with which you want to work. Click the Subscribe button to display the dialog box shown in Figure 22.6. Click the Refresh List button to display the list of newsgroups available on the server.

## Sharing Data Over the Wire

The Internet has made it possible for you to share information, communicate your ideas, conduct business, and stay in touch with anyone around the world. And your Linux distribution contains just about every tool you might need. There are some fun things you can do from the command line and some great utilities that run on the X Window System. If you want to know whether someone is online, use the finger command to see whether they are at home. Then, you can send them a short message and ask whether they'd like to talk for a while. If they do, fire up X-Chat, meet them in one of the public rooms, and mingle for a while.

Another way to share ideas is with a Web site. You'll need an HTML editor in which to create the Web pages and possibly a graphics program to create Web images or enhance photographs. If you want to host your own site, you'll find Web server software to fit your needs. To help you get started on your Web site, here are a few tools you might find useful:

- Netscape Communicator contains an HTML editor called Composer. You can also use any of the text editors to create your own HTML code. Another easy-to-use HTML editor is Screem (found at www.screem.org). Not only can you create Web pages, but it also helps you manage your site after it is published.
- If you want good-looking Web pages, head on over to the Linuxartist.org Web design resources at www.linuxartist.org/webdesign. You'll find links to a number of HTML editing and graphics tools.
- Not everyone is an artist and it does help if every Web page has at least one small graphic or a simple, yet colorful, background. If you search the filesystem, you'll find a variety of images and backgrounds. You can also download free art from a number of Internet sites. Just ask any search engine for free art or free Web graphics.
