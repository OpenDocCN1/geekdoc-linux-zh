5. Find help manuals for the applications you just found. Type `ls /usr/doc | less` and press Enter. The files in these directories are a combination of text files and HTML files.

> If you're viewing the /usr/doc directory from a graphical file manager, you can open a help file by double-clicking the file. For example, you may want to read the Linux FAQ found in the /usr/doc/FAQ-Linux directory. Double-click the file named index.html. The file will open in the file manager or in a Web browser (such as Netscape Navigator).

6. Look for artwork hidden away in the filing system. You'll find desktop backgrounds in the /usr/share/wallpapers directory and in the /usr/share/pixmaps/backgrounds directory. There are a variety of icons in the X Pixmap (.xpm) file format, which is a bitmapped file format, in the /usr/share/icons directory.

This task was a short introduction to some of the fun and useful information you'll find in the /usr directory. You'll learn more about using the ls command to list directory contents in Hour 6, "Looking at the Command Line." You'll also learn more about using pagers and how to use the man command to find helpful information about commands installed on the system in Hour 6.
