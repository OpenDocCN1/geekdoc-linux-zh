# # Working with Floppy and CD-ROM Drives

One of the newest features of GNU/Linux is the capability to automatically mount CD-ROM drives and floppy disk drives. If your system supports automatic mounting, you're in luck. With the automatic mounting feature, called supermount, you can use a floppy and CD-ROM drive on your system just as easily as you can use these drives on a Microsoft Windows system.

Well, there are a few differences. In Microsoft Windows, the floppy drive is called A:; in GNU/Linux, the floppy drive is called /mnt/floppy. GNU/Linux also assigns a device file to the drive. Most likely, you'll find the device file that controls the floppy drive in /dev/fd0. Here's a cool trick: You can read both DOS disks and disks formatted with the extended filesystem (ext2). The CD-ROM drive isn't called D:, E:, or F:, either; it is called /mnt/cdrom. Depending on how your system is set up, the device file is /dev/hdb.

> > The /mnt directories should already be created on your system. If they do not exist, use the mkdir command to add these to the system.

If you selected the supermount feature during installation, you can just put the floppy disk or CD-ROM in the drive, go to the appropriate /mnt directory, and view the contents of the disk. If your system doesn't use the supermount feature, you will first need to mount the drive by hand before you can use it this way.

**New Term** Some distributions give you the opportunity to supermount floppy and CD-ROM drives when the system is booted. By supermounting a drive, you have automatic access to the drive. Distributions that do not provide a supermount option require you to mount the drive each time before you use it and unmount it when you are finished.

How do you know whether your system supports the supermount feature? Here's a number of different places where you can look for an answer. Look at the /proc/mounts file. You can view this file by typing cat /proc/mounts at the command line. Listing 9.1 shows a system that was set up to use supermount. If your system does not support the supermount feature, you won't see an entry for the CD-ROM drive or the floppy disk drive. On floppy drives that use supermount, when you move a file to the /mnt/floppy directory, the file will be automatically saved on the floppy disk. After the drive light goes out, you can remove the disk.
