# Exploring the GNOME Games

If you are using the GNOME user interface, you can find the collection of games that GNOME provides in the GNOME main menu. Look for the Amusement submenu found in the Programs menu. Here you'll find such interesting classics as mahjongg, a 32-game collection of solitaire games called Patience, and a Linux version of the Windows Minesweeper game (shown in Figure 23.2).

Not all the amusements are for fun and enjoyment; some can be very useful. One of the hazards of the computer age is repetitive strain injury cause by excessive mouse usage. If your mouse finger feels a bit sore, open up the Mousepedometer (shown in Figure 23.3) and see how far the mouse travels on the screen. To learn more about Mousepedometer, right-click inside the window and select Help from the menu that appears. Another tool that you might find useful is MoonPhase. This small program lets you know when the full moon is expected to rise.
