You don't want to tie up the machine you use to run your business, or your Internet connection, while you experiment with a new operating system. You might also consider installing Linux on older equipment because it is more likely that the hardware will be compatible with the operating system. Some of the newer, state-of-the-art equipment might be difficult to get to work with Linux.

+   - Are the computer hardware and attached peripherals compatible with Linux? Successful installations occur when the hardware is compatible with the operating system. You'll need to gather information about the hardware and check your findings against the Linux hardware compatibility list. If everything is compatible, you can start using your new operating system and included applications. If the hardware isn't listed, you might have problems configuring and using those devices.
+   - How much hard drive space will you be able to devote to Linux and the associated utilities? Many distributions can install well over a gigabyte of applications. You'll then need additional space to store data files and install more applications.

The first-time Linux user might want to consider installing Linux as the sole operating system on a computer. This is the easiest method. No need to install a second hard drive or to partition an existing hard drive that contains gigabytes of data. Just let the Linux operating system take over the entire computer. Not only does this make the installation much easier, it gives you a separate machine that you can learn on, make mistakes, fix those mistakes, and not have to worry jeopardizing your production machines that you use to run your small business.

If you want to run Linux and another operating system (such as Microsoft Windows) on the same computer, you have two options. The easiest of these options is to install a second hard drive on the computer and install Linux on the second hard drive. Your Windows drive stays secure and there's no fancy partitioning to do. You do need to know how to open up the computer and attach the drive and cables.

The other option is to run Linux and another operating system on the same hard drive. This requires partitioning the drive so that the original operating system lives on one part of the drive and Linux is installed on the other partition.

> If you are unfamiliar with partitioning a hard drive, we recommend that you install Linux on its own separate computer, or at least on a separate hard drive. One wrong move while you are partitioning a drive and you could lose all your valuable data.
