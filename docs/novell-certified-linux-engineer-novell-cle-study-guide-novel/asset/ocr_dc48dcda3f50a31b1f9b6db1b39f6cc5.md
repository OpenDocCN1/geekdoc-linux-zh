# # Summary

In this chapter, you learned about the features and benefits of NetMail. You learned that NetMail is fully integrated with eDirectory, is easy to deploy, is modular, and is highly scalable. You also learned that NetMails modularity is created using modular agents, including the following:

+   - Address Book Agent
+   - Alias Agent
+   - AntiSpam Agent
+   - AntiVirus Agent
+   - AutoReply Agent
+   - Calendar Agent
+   - Connection Manager Agent
+   - IMAP Agent
+   - List Server Agent
+   - Modular Web Agent
+   - NMAP Agent
+   - POP Agent
+   - Proxy Agent
+   - SMTP Agent

You also learned that installing NetMail extends the schema of your eDirectory tree, adding several new object classes as well as new attributes to your organization, organizational unit, server, and user objects.

You then learned about the directories in your Linux server's file system that are used for the Message Store and the Message Queue. You also learned that the NetMail system is configured using the WebAdmin utility, which is separate from the iManager utility you've used to configure other NNLS products.

You learned that NetMail creates two files when it receives an email message: a control file and a data file. You then learned about the nine stages that these files progress through as they are processed in the NetMail system.
