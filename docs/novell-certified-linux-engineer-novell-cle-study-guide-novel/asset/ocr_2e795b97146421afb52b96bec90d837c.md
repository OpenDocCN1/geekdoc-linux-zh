# Summary

In this chapter, you were introduced to the Linux system. The following topics were discussed:

+   - You learned about the evolution of Linux from Unix and Minix.

+   - You also learned that Linux is distributed under the GPL license, which allows developers to modify the Linux source code and recompile the operating system. We discussed the function of an operating system and how Linux fills those roles.

+   - You were introduced to the Linux command-line interface and the X Window System graphical interface. You were introduced to Linux file system concepts such as mount points, partitions, and bootloaders.

+   - You were introduced to Linux users, including the default root user account.

+   - You learned about Linux shells, such as sh, bash, and tcsh. You also learned about commonly used Linux commands such as **ifconfig**, **halt**, **reboot**, and **whoami**.

+   - You learned about the default Linux file system structure and the files that are housed in directories such as `/usr`, `/bin/`, and `/etc`.

+   - You also learned about commonly used Linux command-line utilities such as grep, tail, cp, mv, mkdir, rm, and rmdir. We also discussed how to use the **mount** command in depth. You learned how to mount CDs and floppies. You also learned how to create symbolic link files with ln and how to edit your fstab file to make mounting easier.

+   - We discussed how to manage Linux tarball files with the tar and gunzip utilities. You also learned how to edit text files with vi and with KWrite.

In the next chapter, we will go into depth on Linux users, groups, and permissions. We will also discuss how to manage Linux applications and processes. After that, you'll learn how to configure and manage Linux network interfaces.
