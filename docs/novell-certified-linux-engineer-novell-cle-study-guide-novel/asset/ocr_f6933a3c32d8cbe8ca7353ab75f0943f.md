# ## Summary

In this chapter, you learned how iPrint provides IPP-based printing services to users over the Internet. Using iPrint, end users can use location-based printing maps to automatically configure printers on workstations without help desk intervention.

You learned that iPrint is composed of the following components:

+   - iPrint Printer Agent
+   - iPrint Manager
+   - IPP Server
+   - iPrint Driver Store
+   - iPrint Client
+   - Map Designer

You also learned how to install the iPrint service on your Linux server and how to install the iPrint Client on Windows workstations.

After installing the service and the client, you learned to configure your iPrint server by completing the following tasks:

+   - Configure the Driver Store.
+   - Configure the iPrint Manager.
+   - Configure Printer Agents.
+   - Create location-based print maps.

You also learned how to access your iPrint maps in Internet Explorer to download printer drivers.
