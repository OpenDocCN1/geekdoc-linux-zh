Your users can now start adding files to the iFolder directory on their workstations, and synchronization will begin.

We now discuss how to customize policies from within the iFolder client. Recall when we were configuring global and individual user client policies that you have the option of using **On**, **Enforced**, and **Hidden** for each policy.

If you have simply turned a policy on without enforcing it or hiding it, the end user can override the policy by configuring his or her iFolder client on the workstation.

To do this, complete the following steps:

+   1.  At the client workstation, right-click your iFolder icon in your system tray.
+   2.  Select **Account Information**. The screen in Figure 8.22 appears.
+       This screen displays the currently logged-in user, the location of the iFolder directory, the amount of the user's storage quota that has been used, and the amount of data waiting to be synchronized.
+   3.  Select the **Preferences** tab. The screen in Figure 8.23 appears.
+   4.  In the **Preferences** tab, you can configure the followings policies:
+       - Automatic sync
+       - Synchronize to server delay
+       - Synchronize from server interval
+       - Remember password
+       - Remember pass phrase

The options you see may differ from what is shown in Figure 8.23. If you have configured enforced or hidden policies, they will be grayed out or hidden in this dialog.
