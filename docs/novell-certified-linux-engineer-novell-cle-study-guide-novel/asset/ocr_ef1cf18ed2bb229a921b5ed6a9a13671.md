# Table 5.1 Continued

| NNLS COMPONENT | DATA REQUIRED | DESCRIPTION |
| :--- | :--- | :--- |
| | Admin name with context | Again, the value you supply here is dependent on whether you are installing into a new or an existing eDirectory tree. If you're installing into an existing eDirectory tree, you must provide the typeful name of the tree's admin user (for example, **cn=admin.o=CLE**).\n\nIf you're installing a new tree, you must also provide this information. This information will be used to create the tree's admin user account. |\n| | Admin password | This is the password for your admin user. If you are installing into a new tree, the value you provide will be assigned as the admin's password.\n\nIf you're installing into an existing tree, you must provide the password of the existing admin user. |\n| | Server context | This parameter specifies where you want your server to reside in the eDirectory tree. If you're installing into a new tree, the context will be automatically created for you. If you're installing into an existing tree, you should use iManager from another server to create the context beforehand. The installation script won't create the context in the tree for you. |\n| | LDAP port | This parameter represents the TCP/IP port your LDAP server will use. The default value is **389**. Unless you have a conflict, you should stick with the default. |
