# ## Summary

In this chapter, you learned that Virtual Office ties together all the various NNLS components into a single web interface. This can dramatically reduce user fear about migrating to a new system.

Virtual Office can also increase user productivity by allowing them to create virtual collaboration teams. Users in a virtual team can chat in real time, upload files, discuss topics, and schedule calendar items.

You also learned that Virtual Office can increase user productivity by providing remote users with easy-to-use web access to your NNLS system. This aspect can be a great boon to mobile users as well as telecommuters.

You then learned how to install Virtual Office. You also learned about the directory structure used by Virtual Office in the Linux server's file system.

You then learned how to configure Virtual Office services’ parameters and environment settings. Finally, you learned how to create virtual teams and invite users to participate.
