+   18. Scroll to the net.slp.DAAddresses line. Remove the comment character (;) from the beginning of the line and set the value of this parameter to your server's IP address.

+   19. The remaining parameters' functions can remain at their default values for your implementation. Press Esc to enter Command mode.

+   20. Save the changes to the file and exit vi by entering `:exit`.

+   21. Start the slpd daemon by entering `/etc/init.d/slpd start` at the shell prompt.

+   22. At the shell prompt, enter `chkconfig --list slpd`. Verify that the slpd daemon is configured to automatically start at runlevels 3, 4, and 5. If it's not, enter `chkconfig slpd 345`.

+   23. Verify that SLP has been configured correctly using the slp tool utility.
+   At the shell prompt, enter `slp tool findscopes`.
+   The slp tool utility should find the CLE scope you configured your DA to service, as shown in Figure 5.12.
