+   6. Enable user access to iFolder by completing the following steps:
+   a. Select the **User Management** icon.
+   b. In the iFolder Management Console, select **Advanced Search**.
+   c. View all users in the tree by leaving the search field blank and selecting **Search**.
+   d. Mark each user in your tree except for your admin and eGuidePublicUser user objects.
+   e. Select **Enable checked users as iFolder users**.
+   f. When prompted to confirm the operation, click **OK**.

+   7. Configure global policies for your iFolder server by completing the following steps:
+   a. In the iFolder Management Console, select the **Global Settings** icon.
+   b. Select **Global Policies**.
+   c. In the **Global Policies** screen, select **Display** next to **Server Policies**.
+   d. In the **Initial Client Quota** field, enter **500**. This sets a quota of 500MB of disk space for each user.
+   e. Click **Update**.

+   8. Configure global client policies by completing the following steps:
+   a. In the iFolder Management Console, select the **Home** icon.
+   b. In the iFolder **Welcome** screen, select **Global Settings**.
+   c. Select **Global Policies**.
+   d. On the **Client Policies** line, select **Display**.
