# The Preferences Tab

The Preferences tab allows you to manage and configure your rcd settings. The changes you make in these screens apply to all NNLS servers that are members of the RCD Group. The following options are available:

+   General—This option, shown in Figure 5.24, allows you to configure the URL of the Red Carpet server from which the rcd daemons on your servers will download their updates. For NNLS servers, you should use the URL currently configured.

# FIGURE 5.24

+   Cache—The rcd daemon, by default, keeps the updates it downloads in a cache. This allows you to easily restart or resume a failed or interrupted installation without having to re-download the entire package. The cache options page, shown in Figure 5.25, allows you to configure where these updates are stored as well as an interval for emptying the cache.
