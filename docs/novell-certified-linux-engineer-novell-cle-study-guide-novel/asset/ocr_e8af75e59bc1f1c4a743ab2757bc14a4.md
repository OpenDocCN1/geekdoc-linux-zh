+   4. Under the latest stable release heading, select the latest OpenSLP binary package file, and download it to `/tmp` on your server.

> At the time this book was written, the latest stable release was 1.0.10.

+   5. Open a terminal session.

+   6. At the shell prompt, change to the root user account by entering `su` - and supplying a password of **novell**.

+   7. At the shell prompt, change to the `/tmp` directory by entering `cd /tmp`.

+   8. Install the OpenSLP package by entering `rpm -i .OpenSLP_file_name`. For example, at the time this book was written, the current stable release is 1.0.10. The command to install this package would be `rpm -i ./openslp-1.0.11-1.i386.rpm`.

+   9. Wait while the package is installed.

+   10. When the installation is complete, you're ready to configure the `slp.conf` file to create a DA. At your shell prompt, enter `vi /etc/slp.conf`.

+   11. Press **Ins** to enter Insert mode.

+   12. Scroll down to and locate the `net.slp.useScopes` line.

+   13. Remove the comment character (;) from the beginning of the line.

+   14. Delete the text string that reads `myScope1, myScope2, myScope3` from the end of the line.

+   15. After `net.slp.useScopes = text`, enter `CLEScope`. When you're done, the line should appear as follows: `net.slp.useScopes = CLEScope`
+   This configures your DA to service a scope named `CLEScope`.

+   16. Scroll down to and locate the line `net.slp.isDA`.

+   17. Remove the comment character (;) from the beginning of the line. The line should now read as follows: `net.slp.isDA = TRUE`
+   This enables the local DA on your server. Remember that the SA and UA are run automatically when the service is started.
