
# Lab Exercise 6.2: Implementing LUM

In this lab, you’re going to configure LUM to redirect user authentication to eDirectory. Complete the following steps:

- 1. Start iManager by opening a web browser and navigating to https://your_server_IP_address/nps/iManager.html.
- 2. Authenticate to iManager as your admin user with a password of novell.
- 3. Create a group in your IF.CLE container named IFEmployees.
    - a. In iManager, scroll down to the eDirectory Administration role and select Create Object.
    - b. In the Available Object Classes field, select Group.
    - c. Click OK.
    - d. In the Group Name field, enter IFEmployees.
    - e. In the Context field, enter IF.CLE.
    - f. Click OK.
    - g. When prompted that the group has been created, click OK.
    - h. When prompted to convert the group to a LUM group, click Cancel. We’ll convert the group at a later point.
- 4. Populate the IFEmployees group with all the users in the IF container by following these steps:
    - a. In iManager, select Modify Object.
    - b. In the Object Name field, enter IFEmployees.IF.CLE.
    - c. In the drop-down list, select Members.
    - d. In the Members field, browse to and select each user in the IF container except for the eGuide, iFolder, and admin user objects.
    - e. Click OK.
- 5. Repeat this process to create a group object named SLC.Employees in the SLC.CLE container. Make each user in the SLC container a member of the group.
- 6. Convert the IFEmployees and the SLC.Employees groups to LUM groups by completing the following steps:
    - a. In the left frame, scroll down to the **Linux User Management** role.
    - b. Select **Convert eDirectory Group to LUM Group**.
    - c. In the **Select Group** field, browse to and select the **IFEmployees** group.
    - d. Select **OK**.
    - e. When prompted to select the workstations you want the group added to, select **Linux Workstations**.
    - f. In the **Linux Workstations** field, browse to and select your **UNIX Workstation – CLE1** object, located in the IF-CLE container.
    - g. Click **OK**.
    - h. When prompted that the LUM group was created, select **Repeat Task**.
    - i. Repeat these steps to convert the **SLCEmployees.SLC.CLE** group to a LUM group.
    - j. When prompted that **SLCEmployees.SLC.CLE** has been converted, click **OK**.
- 7. Convert each user in the IF.CLE container to a LUM user by completing the following steps:
    - a. Under the **Linux User Management** role, select **Convert eDirectory User to LUM User**.
    - b. In the **Select User** field, browse to and select the first user in your IF.CLE container.
        > **WARNING** Don't convert your admin user object.
    - c. Click **OK**.
    - d. When prompted to specify the primary group for the user, browse to and select your **IFEmployees** group in IF.CLE.
    - e. Deselect the option to convert the user to a Samba user object.
    - f. Click **OK**.
    - g. Select **Repeat Task**.
    - h. Repeat these steps for each user in the IF container except for the eGuide, iFolder, and admin user objects.
- 8. Repeat these steps to convert each user in the SLC.CLE container to a LUM user. Be sure to associate these users with the **SLCEmployees.SLC.CLE** group.

## Summary

That's it for this chapter. We first discussed the eGuide component of NNLS. You learned how it uses LDAP to pull user data from any LDAP-compliant directory service to populate its address book. You also learned how to customize the attributes displayed in the eGuide interface as well as how to configure which attributes are searchable by the user.

We also discussed the LUM component of NNLS. You learned that LUM can be used to redirect authentication of PAM-enabled modules to eDirectory. Doing so can greatly reduce your administrative tasks on a large, multiserver network. You learned how LUM uses the pam_nam and nss_nam modules to redirect authentication to eDirectory through your LDAP server. You also learned how to convert objects in your tree to LUM objects.
