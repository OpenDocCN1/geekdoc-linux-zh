+   4. Check to see the runlevels pure-ftpd is configured to automatically start at by entering `chkconfig -1 pure-ftpd` at the shell prompt.

+   5. You should see that pure-ftpd is not configured to automatically start at any runlevel. Start the pure-ftpd service by entering `./pure-ftpd start`.

+   6. Configure pure-ftpd to automatically start at runlevels 3 and 5 by entering `chkconfig pure-ftpd 35`.

+   7. Verify this change by entering `chkconfig -1 pure-ftpd`.
