# CHAPTER 5
NNLS Installation and Administration

This chapter covers the following testing objectives for Novell Course 3015: Novell Nterprise Linux Services:

+   1.  Perform an NNLS installation.
+   2.  Manage NNLS with Red Carpet.
+   3.  Describe the purpose of eDirectory.
+   4.  Describe how eDirectory works.
+   5.  Perform eDirectory administration tasks.
+   6.  Manage user objects with iManager.

Up to this point in the book, we have reviewed the basic Linux skills you need to implement and manage NNLS. You’ve also been introduced to the various components that make up the NNLS products.

In this chapter, we’re going to get down to business and install NNLS on the SUSE Linux server implemented in Chapter 2, “Introduction to SUSE Linux.” After installing NNLS, we’ll discuss how to keep the implementation up to date using Red Carpet. After that, we’ll dive into eDirectory and cover some basic administration concepts.
