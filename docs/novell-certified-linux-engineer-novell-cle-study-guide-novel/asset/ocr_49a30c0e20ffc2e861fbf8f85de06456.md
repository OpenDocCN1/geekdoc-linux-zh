# Configuring the NetStorage Server

Out of the box, the default NetStorage server configuration works perfectly for most implementations. It is unlikely that you will need to actually change any settings. If you do, however, the NetStorage server settings are configured using iManager. To configure NetStorage parameters, do the following:

+   1. Open a web browser and navigate to  
+       `https//your_server_IP_address/nps/iManager.html`.
