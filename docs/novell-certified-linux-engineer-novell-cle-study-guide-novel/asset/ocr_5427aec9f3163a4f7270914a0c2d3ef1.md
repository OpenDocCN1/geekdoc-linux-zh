# Managing NNLS Product Updates

As with creating the RCD Group object, you manage rcd product updates with iManager. This is done by completing the following steps:

+   1. In iManager, select **Manage RCD Group** under **Resource Management**.
+   2. Browse to and select the group you just created.
+   3. Select **Get Devices**. The NNLS servers in the group are displayed in the **Device List** field, as shown in Figure 5.18.
