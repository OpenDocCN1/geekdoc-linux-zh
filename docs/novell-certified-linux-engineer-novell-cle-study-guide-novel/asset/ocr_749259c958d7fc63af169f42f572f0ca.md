# CHAPTER 11

# Tying It All Together  
with Virtual Office

This chapter covers the following testing objectives for Novell Course 3015:  
Novell Nterprise Linux Services:

+   1. Describe Virtual Office.
+   2. Install Virtual Office.
+   3. Configure Virtual Office.

Since Chapter 5, “NNLS Installation and Administration,” you have been introduced to all the various components that compose Novell's NNLS product:

+   ► eDirectory  
+   ► eGuide  
+   ► Linux User Management (LUM)  
+   ► Samba  
+   ► DirXML  
+   ► iFolder  
+   ► NetStorage  
+   ► iPrint  
+   ► NetMail

In this chapter, you'll learn how to tie all these disparate components together into a unified web interface using the Virtual Office component of NNLS.
