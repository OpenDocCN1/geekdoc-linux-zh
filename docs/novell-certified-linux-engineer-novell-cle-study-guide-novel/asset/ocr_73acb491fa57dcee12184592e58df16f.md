When you do, you'll see that the file created in the iFolder directory on the first Windows workstation is automatically synchronized to the iFolder directory on the second Windows workstation.

If you ever start having trouble with your iFolder implementation, you can configure your iFolder server to write debug information in a log file so you can see what's happening “behind the scenes.” To do this, complete the following steps:

+   1.  Access the iFolder Management Console by opening a web browser and navigating to `https://your_server_IP_address/iFolderServer/Admin`.
+   2.  Select **Global Settings**.
+   3.  Authenticate as your admin user.
+   4.  Select **Global Policies**.
+   5.  On the **Server Policies** line, click **Display**.
+   6.  Mark **Debug Output** and then click **Update**.
+   7.  On your server, open a terminal session and change to the `/var/opt/novell/iFolder/DocumentRoot` directory.
+   8.  Using the `mkdir` command, create a directory named `logs`.
+   9.  Enter `vi /etc/opt/novell/iFolder/httpd_ifolder_unix.conf`.
+   10. Scroll to the end of the file and press **Ins**.
+   11. Enter the following text (all on one line):
+       ```
+       iFolderServerLogging
+       "/var/opt/novell/iFolder/DocumentRoot/logs/index.html"
+       ```
+       a.  Press **Esc**; then enter `:exit`.
+       b.  At the shell prompt, enter `chmod 757 /var/opt/novell/iFolder/DocumentRoot/logs`.
+       c.  Using the init scripts in `/etc/init.d`, stop and then restart the **novell-httpd** service.
