# ## Lab Exercise 5.4: Updating NMLS with rcd

In this lab, you're going to install an update using rcd on your server.

As with the previous exercises in this chapter, this exercise requires that your server have access to the Internet. If you installed NNLS without an Internet connection established, you will need to use the NNLS installation script to uninstall the Red Carpet component. Then establish your Internet connection and reinstall Red Carpet.

To install an NNLS update, complete the following steps:

+   1. If necessary, authenticate to your Linux server as your **student** user with a password of **novell**.
+   2. Launch a web browser by selecting the Mozilla icon on your desktop and open `https:/your_server's_IP_address/nps/iManager.html`.

You can do this from either your server desktop or from a remote workstation.

+   3. In the **Username** field, enter **admin**.
+   4. In the **password** field, enter **novell**; then click **Login**.
+   5. If prompted, accept the security certificates issued by your server.
+   6. Under **Roles and Tasks**, scroll down to **Resource Management**.
+   7. Create an RCD Group by completing the following steps:
+      a. Select **Create RCD Group**.
+      b. In the **RCD Group Name** field, enter **NNLSUpdates**.
+      c. In the **Context** field, browse to and select **IFCLE**; then click **OK**.
+      d. When prompted that the group was created, click **OK**.
+   8. Populate the RCD Group with your NNLS server by completing the following steps:
+      a. Under **Resource Management**, select **Modify RCD Group**.
+      b. In the **RCD Group Name** field, browse to and select the **NNLSUpdates.IFCLE** RCD group, if it isn't already specified.
+      c. Click **OK**.
+      d. Under **Device List**, select **New**.
