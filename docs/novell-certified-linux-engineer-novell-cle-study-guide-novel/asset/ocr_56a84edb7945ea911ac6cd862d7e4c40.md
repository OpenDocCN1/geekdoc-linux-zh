+   b. In the **Team file share** field, enter the URL to the team file share. Recall from the NetStorage chapter that this URL must point to a Samba share. The URL format is `cifs://server_IP_address/share_name`. For example, we created a Samba share named IFEmployees earlier in this book. If your server’s IP address were 192.168.1.36, you would enter `cifs://192.168.1.36/IFEmployees` in this field.
