# Introduction to SUSE Linux

This chapter covers the following testing objectives for Novell Course 3015: Novell Nterprise Linux Services:

+   1.  Describe the characteristics of Linux.
+   2.  Use the Linux command-line interface.
+   3.  Manage the Linux file system.

In this chapter, we'll walk through a general overview of Linux concepts and skills you will need to install and administer an Novell Nterprise Linux Services (NNLS) implementation. If you already have a solid background with Linux, you can probably skip ahead to Chapter 3, “Linux Administration and Configuration.”
