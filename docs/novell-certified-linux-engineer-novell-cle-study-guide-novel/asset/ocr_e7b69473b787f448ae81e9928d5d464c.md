# Lab Exercise 8.3: Working with NetStorage

In this lab, you're going to use a browser to access Samba shares through NetStorage.

> **WARNING** This lab assumes you completed the labs in Chapter 6 and the preceding labs in this chapter. If not, be sure to go back and complete these first.

Complete the following steps:

+   1. Test the default shared folder in NetStorage by completing the following:
+       a. Open a web browser and navigate to
+   https://your_server_IP_address/NetStorage.
+       b. In the **User Name** field, enter **JJackson.IFCLE**.
+       c. In the **Password** field, enter **novell**.
+       d. Click **OK**. The NetStorage screen appears.
+       e. Select **shared**. The content of the **shared** folder appears. Remember that this folder is common to all NetStorage users.
+       f. Select **File, Upload**.
+       g. In the **File** field, browse to and select a file you want to upload. You can use any file you wish.
+       h. Click **Upload**.
+       i. Wait while the file is uploaded. When the upload is complete, you will see the file displayed in the **shared** folder.
+       j. Select **Logout**; then close your browser window.

> **WARNING** You have to close the browser after logging out. Otherwise, if you try to access the NetStorage page again, you will automatically be reauthenticated as the original user.
