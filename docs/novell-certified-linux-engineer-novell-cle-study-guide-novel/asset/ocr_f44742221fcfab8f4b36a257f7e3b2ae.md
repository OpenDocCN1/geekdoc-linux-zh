Notice in Figure 6.16 that login has been configured to use the LUM pam\_nam.so module. This module redirects authentication requests to the nss\_name.so module.

When the nss\_nam.so module receives a request, it contacts the LUM daemon, named. This service retrieves and caches information from your eDirectory tree. If the username of the user authenticating is already in the daemon's cache, it will return the distinguished name (which is the object name and its context) of the associated user object. Otherwise, it queries eDirectory for the information, returns the distinguished name, and stores the information in its cache.

The named daemon can be configured using the /etc/nam.conf configuration file or by running the namconfig utility. A typical nam.conf file is shown in Figure 6.17.
