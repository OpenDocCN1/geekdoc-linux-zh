# 配置修改密码服务

使用虚拟办公室，您可以为用户管理其在 eDirectory 树中用户对象密码的能力提供便利。这是在虚拟办公室界面中通过“修改我的密码”图标提供的，如图 11.35 所示。

![](img/c7771e8540507f2b00c088c7a411b57b_511_2.png)

要在您的虚拟办公室部署中启用此服务，您需要执行以下操作：

- 1. 在 iManager 中，选择**服务管理**任务。
- 2. 选择**修改密码**选项卡。此时将显示如图 11.36 的屏幕。

![](img/c7771e8540507f2b00c088c7a411b57b_512_0.png)

图 11.36
启用修改密码服务。

- 3. 如果您希望在虚拟办公室中向用户显示**修改密码**链接，请勾选**启用**。
- 4. 点击**确定**。

当启用此服务时，用户可以在虚拟办公室主页中选择“修改我的密码”图标。当他们这样做时，将显示如图 11.37 的屏幕。

![](img/c7771e8540507f2b00c088c7a411b57b_512_1.png)

图 11.37
修改用户密码。

要修改密码，用户必须首先在**当前密码**字段中提供其当前的 eDirectory 密码。如果提供了正确的密码，用户随后可以在**新密码**字段中输入新密码。此外，通过勾选**同步 Samba 密码**，用户可以将其 Samba 密码更改为与其新的 eDirectory 密码一致。要保存更改，用户应点击**确定**。

## 配置虚拟办公室环境

您刚才了解的服务管理任务主要集中在集成各种 NDS 组件和配置用户界面。此处涵盖的虚拟办公室环境管理任务用于配置虚拟办公室服务本身的行为。

环境管理任务位于 iManager 中虚拟办公室角色之下。使用此任务，您可以配置虚拟团队参数并设置日志记录级别。让我们来看看这些功能。

> **警告**
> 在浏览本节时，您会注意到环境管理屏幕中还提供了第三种功能：配置门户信息。我们在这里不会涵盖这些参数。Novell 的虚拟办公室软件工程师指出，除非 Novell 支持工程师指示用户这样做，否则普通用户不应触碰这些设置。

### 设置团队配置参数

在讨论如何配置团队参数之前，我们需要讨论一下团队到底是什么。虚拟办公室允许用户创建*虚拟团队*。这些团队允许组织中的员工通过电子邮件、实时聊天、文件共享和日历进行协作。

最终用户可以在其虚拟办公室主页内创建虚拟团队。当这种情况发生时，创建该团队的用户将成为团队的拥有者，也是第一个团队成员。团队拥有者随后可以邀请其他用户作为成员加入团队。被邀请者将收到通知，并有机会接受或拒绝加入邀请。

您可以通过在 iManager 中配置团队参数，在一定程度上控制虚拟办公室处理团队的方式。为此，您需要完成以下步骤：

- 1. 打开 iManager 并向下滚动到**虚拟办公室**角色。
- 2. 选择**环境管理**任务。此时将显示如图 11.38 的屏幕。

![](img/c7771e8540507f2b00c088c7a411b57b_514_0.png)

- 3. 如果您允许最终用户创建团队，请将**启用团队创建**设置设为**开**。（此参数默认处于开启状态。）
- 4. 团队文件共享用于存储上传的文件。通过执行以下操作配置团队文件共享：
    - a. 在**团队文件共享**行上，点击**编辑**。此时将显示如图 11.39 的屏幕。

![](img/c7771e8540507f2b00c088c7a411b57b_514_1.png)

    - b. 在**团队文件共享**字段中，输入团队文件共享的 URL。回想一下 NetStorage 章节，该 URL 必须指向一个 Samba 共享。URL 格式为 `cifs://server_IP_address/share_name`。例如，我们在本书前面创建了一个名为 IFEmployees 的 Samba 共享。如果您的服务器 IP 地址是 192.168.1.36，您在此字段中输入 `cifs://192.168.1.36/IFEmployees`。

> **提示** 当然，您也可以使用 DNS 名称而不是 IP 地址。

    - c. 在**用户名**字段中，输入具有指向 Samba 共享目录读写权限的 LUM 用户名。
    - d. 在**密码**字段中，输入该 LUM 用户的密码。
    - e. 点击**确定**。

- 5. 可以配置虚拟办公室向网络管理员发送通知消息。为此，您必须使用 NetMail 服务器的地址来配置虚拟办公室。完成以下操作：
    - a. 点击**SMTP 地址**行上的**编辑**按钮。屏幕显示如图 11.40 所示。

![](img/c7771e8540507f2b00c088c7a411b57b_515_0.png)

![](img/c7771e8540507f2b00c088c7a411b57b_515_1.png)

    - b. 在**SMTP 地址**字段中，输入您的 NetMail 服务器的 IP 地址。
    - c. 在**用户名**字段中，输入一个 NetMail 用户的用户名，您希望将虚拟办公室邮件通知发送给用户（这通常是您自己）。
    - d. 在**密码**字段中，输入该用户的密码。
    - e. 点击**确定**。

- 6. 默认情况下，虚拟办公室聊天小程序运行在 IP 端口 2122 上。如果您想将其更改为其他端口，请在**聊天服务器 IP 端口**字段中输入所需的端口号。
- 7. 虚拟办公室还允许您指定哪些用户可以创建虚拟团队，哪些用户不能。默认情况下，您的 eDirectory 树中的任何人都可以创建团队。如果您想限制此访问权限，请执行以下操作：
    - a. 在**管理团队访问权限**行上，点击**编辑**按钮。此时将显示如图 11.41 的屏幕。

![](img/c7771e8540507f2b00c088c7a411b57b_516_0.png)

图 11.41
配置团队拥有者访问权限。

    - b. 在**搜索**下拉列表中，选择**用户**或**容器**。

> **虚拟办公室**允许您针对单个用户或整个容器限制团队拥有权。

    - c. 点击**搜索**。
    - d. 选择您要管理访问权限的用户或容器，然后点击**选择**。此时将显示如图 11.42 的屏幕。

![](img/c7771e8540507f2b00c088c7a411b57b_516_1.png)

图 11.42
配置团队拥有者访问权限标志。

    - e. 若要拒绝用户或容器创建虚拟团队的能力，请将**允许用户创建团队**设置的值更改为**关**。
    - f. 点击**保存**。

- 8. 点击**保存**，然后点击**确定**，以保存您对虚拟办公室团队配置的更改。
