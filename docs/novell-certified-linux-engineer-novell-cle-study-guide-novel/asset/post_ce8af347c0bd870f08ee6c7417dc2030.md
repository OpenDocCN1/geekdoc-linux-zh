
## Working with Linux User Management

**Test Objective Covered:**
- Access a Linux Server with Linux User Management (LUM).

The LUM component of NNLS serves as the link between the local Linux system and eDirectory. LUM represents a huge leap forward in eDirectory technology.

eDirectory was actually ported over to Linux in 1998. I remember when the first version became available for beta testing. I went to a training session in a room packed with Linux administrators. All of us were waiting with bated breath to see eDirectory on our favorite platform.

We all proceeded through the install portion of the class without incident. Shortly after that, things started to go wrong. The product itself worked fine—it was the way it worked that caused consternation.

As you probably know, Linux administrators tend to have an inquisitive nature. In accordance, after the install portion of the class, most of the students were off experimenting and tinkering with the eDirectory service instead of listening to the instructor (he wasn't terribly interesting to listen to anyway).

As a result of this tinkering, all of us realized in a moment of group collective consciousness that the eDirectory and Linux authentication systems weren't connected to each other in any way. Because of our past experience with NetWare, we were fully expecting to be able to use eDirectory to authenticate Linux users. Instead, we found that Linux users were still being managed with the passwd, shadow, and group files. eDirectory and Linux were in no way connected.

To authenticate to eDirectory, you had to log in using the Novell Client from a Windows or DOS workstation. To log in to the Linux server, you had to authenticate from the login prompt at the server console. Essentially, eDirectory used Linux as a platform to run on and wasn't used to actually manage the server itself.

### 5. Test the Data

Test the data by completing the following steps:

- a. In your browser window, open `https://your_server_IP_address/eGuide`.
- b. Authenticate to eGuide as **admin** with a password of **novell**.
- c. In the **Find People** drop-down lists, select **Last Name** and **Starts With**.
- d. In the **Find People** field, enter **co** and then select **Search**.
- e. You should see Dave Coughanour and Jason Corry located in the search. View the information eGuide pulled from eDirectory.
- f. Select the **Organizational Chart** tab. The organizational structure you defined in the user object attributes is displayed.

### 6. Configure Attributes Displayed by eGuide

Configure the attributes displayed by eGuide by completing the following steps:

- a. In eGuide, select **Administration Utility**.
- b. Select **LDAP Data Sources**.
- c. On the **New_Data_Source** line, select **Edit**.
- d. Select the **Attributes** tab.
- e. Mark the following check boxes for the following attributes:

| Attribute | Check Box(es) |
|:---|:---|
| Company | Enable |
| directreports | Enable, Searchable |
| facsimiletelephonenumber | Enable, Searchable, Editable |
| Manager | Enable, Searchable |
| telephonenumber | Enable, Searchable, Editable |

- f. Click **Save**.
- g. Click the **Launch eGuide Client** icon.
- h. In the first **Find People** drop-down list, verify that the preceding searchable attributes are included in the list.
- i. Search for the **DCoughanour** user object. Verify that the attributes configured previously are displayed.
