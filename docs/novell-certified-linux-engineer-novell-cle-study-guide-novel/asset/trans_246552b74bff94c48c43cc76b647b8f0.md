

# 表 5.1

| NNLS 组件 | 所需数据 | 描述 |
| :--- | :--- | :--- |
| eGuide | 管理员密码 | 此参数是先前指定的管理员用户对象的密码。 |
| | LDAP 服务器 IP 地址 | 此参数是用于对用户进行 eDirectory 身份验证的 LDAP 服务器的 IP 地址。 |
| | LDAP 端口 | 此参数指定 eGuide 用于与 LDAP 服务器通信的 TCP/IP 端口。默认值为 389。如果已配置 LDAP 服务器使用不同的端口号，请确保在此处输入该端口号。 |
| | 安全 LDAP 端口 | 此参数指定 eGuide 用于与 eDirectory 树中的 LDAP 服务器通信的安全 TCP/IP 端口。默认值为 636。如果已配置 LDAP 服务器使用不同的安全端口号，请确保在此处输入该端口号。 |
| | 管理员名称和上下文 | 此参数指定树的管理员用户。必须使用带类型的名称，例如 **cn=admin.o=CLE**。 |
| Samba | eDirectory 服务器 IP 地址 | 对于此参数，需要提供 eDirectory 树中某台服务器的 IP 地址。该服务器必须托管至少一个 eDirectory 分区的 Master 或 Read/Write 副本。 |
| | 管理员名称和上下文 | 此参数指定 eDirectory 树的管理员用户。必须使用带类型的名称，例如 **cn=admin.o=CLE**。 |
| | 管理员密码 | 此参数是先前指定的管理员用户对象的密码。 |
| | LDAP 服务器 IP 地址 | 此参数是用于对用户进行 eDirectory 身份验证的 LDAP 服务器的 IP 地址。 |
| | Samba 代理用户 | eDirectory 使用代理用户账户向 Samba 服务分配权限。这允许该服务在 eDirectory 树中执行某些操作。在安装过程中，会自动创建此用户并分配相应的权限。<br><br>在此提示处，您指定希望用于代理用户的名称。只要该名称尚未在树中使用过，您可以使用任何有效的用户名称。 |
| | Samba 代理用户密码 | 此参数用于创建 Samba 代理用户的密码。您可以使用任何有效的密码。 |
| | LDAP 端口 | 此参数指定 Samba 用于与 LDAP 服务器通信的 TCP/IP 端口。默认值为 **389**。如果已配置 LDAP 服务器使用不同的端口号，请确保在此处输入该端口号。 |
| | 安全 LDAP 端口 | 此参数指定 Samba 用于与 eDirectory 树中的 LDAP 服务器通信的安全 TCP/IP 端口。默认值为 **636**。如果已配置 LDAP 服务器使用不同的安全端口号，请确保在此处输入该端口号。 |
| iFolder | LDAP 服务器 IP 地址 | 此参数是用于对用户进行 eDirectory 身份验证的 LDAP 服务器的 IP 地址。 |
| | LDAP 端口 | 此参数指定 iFolder 用于与 LDAP 服务器通信的 TCP/IP 端口。默认值为 **389**。如果已配置 LDAP 服务器使用不同的端口号，请确保在此处输入该端口号。 |
| | LDAP 管理员名称和上下文 | 对于此参数，应使用 eDirectory 树的管理员用户。必须使用带类型的名称，例如 cn=admin.o=CLE。 |
| | 管理员密码 | 此参数是先前指定的管理员用户对象的密码。 |
| | iFolder 服务器 IP 地址 | 此参数指定要安装 iFolder 的服务器的 IP 地址。 |
| | iFolder 管理员用户名 | 此参数允许您委派 iFolder 管理任务。您可以指定希望授予 iFolder 管理访问权限的用户名称。这些用户必须与先前指定的管理员用户名位于同一个 eDirectory 上下文中。用户名之间必须用分号分隔。 |
| | iFolder 用户数据路径 | 此参数指定在 Linux 服务器文件系统中存储用户文件的位置。默认路径为 /var/opt/novell/ifolderdata。 |
| NetMail | 管理员名称和上下文 | 此参数指定 eDirectory 树的管理员用户。必须使用带类型的名称，例如 **cn=admin.o=CLE**。 |
| | 管理员密码 | 此参数是先前指定的管理员用户对象的密码。 |
| | NetMail 主 DNS 服务器 | 此参数指定您组织 DNS 服务器的 IP 地址。 |
| | NetMail 备用 DNS 服务器 | 此参数指定您组织备用 DNS 服务器的 IP 地址。此参数是可选的。 |
| | NetMail 服务器的域名 | 此参数指定您组织的域名。 |
| | NetMail WebAccess HTTP 端口 | 此参数指定提供对 WebAccess 电子邮件界面不安全访问的 TCP/IP 端口。默认端口为 **52080**。<br><br>除非存在端口或防火墙过滤冲突，否则应使用默认值。 |
| | NetMail WebAccess 安全 HTTP 端口 | 此参数指定提供对 WebAccess 电子邮件界面安全访问的 TCP/IP 端口。默认端口为 **52443**。<br><br>除非存在端口或防火墙过滤冲突，否则应使用默认值。 |
| | NetMail LDAP 端口 | 此参数指定用于填充 NetMail 地址簿的端口。默认端口为 **52389**。 |
| iManager | iManager 服务器 IP 地址 | 除非存在端口或防火墙过滤冲突，否则应使用默认值。此参数指定要安装 iManager 的服务器的 IP 地址。在本书中，我们将在安装 eDirectory 的同一台服务器上安装 iManager。 |
| | 管理员名称和上下文 | 此参数指定 eDirectory 树的管理员用户。必须使用带类型的名称，例如 **cn=admin.o=CLE**。 |
| | 管理员密码 | 此参数是先前指定的管理员用户对象的密码。 |
| | iManager PCO 密码 | 此参数指定 iManager 通过 LDAP 以门户容器对象 (PCO) 身份向 eDirectory 进行身份验证时使用的密码。如果在树中的其他服务器上安装 iManager，每个实例必须使用相同的 PCO 密码。 |
| | LDAP 服务器 IP 地址 | 此参数指定用于向 eDirectory 进行身份验证的 LDAP 服务器的 IP 地址。 |
| | LDAP 端口 | 此参数指定 iManager 用于与 LDAP 服务器通信的 TCP/IP 端口。默认值为 **389**。如果已配置 LDAP 服务器使用不同的端口号，请确保在此处输入该端口号。 |
| | 安全 LDAP 端口 | 此参数指定 iManager 用于与 eDirectory 树中的 LDAP 服务器通信的安全 TCP/IP 端口。<br><br>默认值为 **636**。如果已配置 LDAP 服务器使用不同的安全端口号，请确保在此处输入该端口号。 |
| | WebAdmin HTTP 端口 | 此参数指定 WebAdmin 将运行的不安全 HTTP 端口。默认值为 **8018**。<br><br>除非存在端口冲突或防火墙过滤问题，否则应坚持使用默认值。 |
| | WebAdmin HTTP 端口 | 此参数指定 WebAdmin 将运行的安全 HTTP 端口。默认值为 **8020**。<br><br>除非存在端口冲突或防火墙过滤问题，否则应坚持使用默认值。 |
| iPrint | 管理员名称和上下文 | 此参数指定 eDirectory 树的管理员用户。必须使用带类型的名称，例如 **cn=admin.o=CLE**。 |
| | 管理员密码 | 此参数是先前指定的管理员用户对象的密码。 |
| | iPrint 服务器 IP 地址或主机名 | 此参数指定将安装 iPrint 的服务器的 IP 地址。<br><br>服务器必须位于 eDirectory 树中，并且必须托管某个分区的 Master 或 Read/Write 副本。 |
