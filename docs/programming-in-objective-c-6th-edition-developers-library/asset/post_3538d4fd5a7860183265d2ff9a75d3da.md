## General Utility Functions

Some routines from the library don’t fit neatly into any of the previous categories. To use these routines, include the header file `<stdlib.h>`.

`int abs(int n)`

Returns the absolute value of its integer argument $n$.

`void exit(int n)`

Terminates program execution, closing any open files and returning the exit status specified by its integer argument $n$. `EXIT_SUCCESS` and `EXIT_FAILURE`, defined in `<stdlib.h>`, can be used to return a success or failure exit status, respectively.

Other related routines in the library that you might want to refer to are `atexit` and `abort`.

`char * getenv(const char *s)`

Returns a pointer to the value of the environment variable pointed to by $s$, or a null pointer if the variable doesn't exist. This function operates in a system-dependent way.

As an example, under Unix, the code:

```c
char *h = getenv("HOME");
```

could be used to get the value of the user's `HOME` variable, storing a pointer to it inside `h`.

`long labs(long l)`

Returns the absolute value of its long argument $l$.

`long long llabs(long long ll)`

Returns the absolute value of its long long argument $ll$.

`void qsort(void *arr, size_t n, size_t size, int (*compar)(const void *, const void *))`

Sorts the data array pointed to by the pointer `arr`. There are $n$ elements in the array, each `size` bytes in length. `n` and `size` are of type `size_t`. The fourth argument is of type “pointer to function that returns int and that takes two void pointers as arguments.” `qsort` calls this function whenever it needs to compare two elements in the array, passing it pointers to the elements to compare. The function, which is user-supplied, is expected to compare the two elements and return a value less than zero, equal to zero, or greater than zero if the first element is less than, equal to, or greater than the second element, respectively.

Here is an example of how to use `qsort` to sort an array of 1,000 integers called `d`:

```c
int compare(const void *a, const void *b) {
    return (*(int *)a - *(int *)b);
}

qsort(d, 1000, sizeof(int), compare);
```

Another routine called `bsearch`, which is not described here, takes similar arguments to `qsort` and performs a binary search of an ordered array of data.

`double rand(void)`

Returns a random number in the range $[0, RAND\_MAX]$, where `RAND_MAX` is defined in `<stdlib.h>` and has a minimum value of 3. See also `srand` (to seed the generator).
