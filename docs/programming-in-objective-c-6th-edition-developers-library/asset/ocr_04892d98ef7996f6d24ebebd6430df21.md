The c function defines the two formal parameters t and f as character pointers and not as character arrays as was done in the previous version of c . This reflects how these two variables are used by the function.

A f loop is then entered (with no initial conditions) to copy the string pointed to by f into the string pointed to by t . Each time through the loop, the f and t pointers are each incremented by one. This sets the f pointer pointing to the next character that is to be copied from the source string and sets the t pointer pointing to the location in the destination string where the next character is to be stored.

When the f pointer points to the null character, the f loop is exited. The function then places the null character at the end of the destination string.
