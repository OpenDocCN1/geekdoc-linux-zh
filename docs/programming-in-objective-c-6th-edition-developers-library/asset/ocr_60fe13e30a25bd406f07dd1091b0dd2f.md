# 4.3.4 Pointers

The basic format for declaring a pointer variable is as follows:

```
t
```

The identifier \textit{name} is declared to be of type “pointer to \textit{type},” which can be a basic data type, or a derived data type. For example,

```
i
```

declares i to be a pointer to an i , and the declaration

```
s
```

declares s to be a pointer to an s structure.

Pointers that point to elements in an array are declared to point to the type of element contained in the array. For example, the previous declaration of i can also be used to declare a pointer into an array of integers.

More advanced forms of pointer declarations are also permitted. For example, the declaration

```
c
```

declares t to be an array of 100 character pointers, and the declaration

```
s
```

declares f to be a pointer to a function that returns an s structure and that takes a single i argument.

A pointer can be tested to see if it’s null by comparing it against a constant expression whose value is 0. The implementation can choose to internally represent a null pointer with a value other than 0. However, a comparison between such an internally represented null pointer and a constant value of 0 must prove equal.

The manner in which pointers are converted to integers, and integers are converted to pointers, is machine dependent, as is the size of the integer required to hold a pointer.

The type “pointer to v” is the generic pointer type. The language guarantees that a pointer of any type can be assigned to a v pointer and back again without changing its value.

Other than this special case, assignment of different pointer types is not permitted, and typically results in a warning message from the compiler if attempted.
