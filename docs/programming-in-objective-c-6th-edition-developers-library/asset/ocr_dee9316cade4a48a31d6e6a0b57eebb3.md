# 6.1 Functions

If a storage class is specified when a function is defined, it must be either $\S$ or $\Theta$. Functions that are declared as $\S$ can only be referenced from within the same file that contains the function. Functions that are specified as $\Theta$ (or that have no class specified) can be called by functions from other files.
