The next program statements link together the three elements of the list, with the next member of n set to the null pointer to mark the end of the list. A w loop is then set up to sequence through each element of the list. This loop is executed as long as the value of l is not equal to the null pointer. The p call inside the w loop displays the v member of the entry currently pointed to by l . The statement that follows the p call, has the effect of taking the pointer from the n member of the structure pointed to by l and assigning it to l .
