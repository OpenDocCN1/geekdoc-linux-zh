# 9.2.6 The #*include* Directive

One general format for declaring the #       directive is as follows:

```
```
#       fileName*"
```
```

The preprocessor searches an implementation-defined directory or directories first for the file *fileName*. Typically, the same directory that contains the source file is searched first. If the file is not found there, a sequence of implementation-defined standard places is searched. After it is found, the contents of the file is included in the program at the precise point that the #       directive appears. Preprocessor directives contained within the included file are analyzed, and, therefore, an included file can itself contain other #       directives.

Another general format for declaring the #       directive is as follows:

```
```
#       fileName>
```
```

The preprocessor searches for the specified file only in the standard places. The action taken after the file is found is otherwise identical to that described previously.

# 9.2.7 The #*line* Directive

The general format for declaring the #       directive is as follows:

```
```
#       fileName*"
```
```

This directive causes the compiler to treat subsequent lines in the program as if the name of the source file were *fileName*, and as if the line number of all subsequent lines began at *constant*. If *fileName* is not specified, the filename specified by the last #       directive or the name of the source file (if no filename was previously specified) is used.

The #       directive is primarily used to control the filename and line number that are displayed whenever an error message is issued by the compiler.
