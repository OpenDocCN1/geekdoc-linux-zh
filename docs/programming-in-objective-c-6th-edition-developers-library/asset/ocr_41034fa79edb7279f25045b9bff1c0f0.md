p   is a modifiable lvalue expression of type “pointer to t” that points to an element in a

p   is an l         expression of type “pointer to t” that points to an element in a, or to one past the last element in a

v   is an expression

n   is an integral expression

then the expression

a, &  , &

   produces a pointer to the first element

&

   produces a pointer to element number n of a and has type “pointer to t”

*

   references the element of a that p     points to and has type t

*

   stores the value of v in the element pointed to by p    , and has type t

+

   sets p     pointing to the next element of a, no matter what type of elements are contained in a and has type “pointer to t”

−   sets p     pointing to the previous element of a, no matter what type of elements are contained in a, and has type “pointer to t”

*   increments p     and then references the value in a that p     points to, and has type t

*   references the value in a that p     points to before incrementing p     and has type t

p   produces a pointer that points n elements further into a than p     and has type “pointer to t”

p   produces a pointer to a that points n elements previous to that pointed to by p     and has type “pointer to t”
