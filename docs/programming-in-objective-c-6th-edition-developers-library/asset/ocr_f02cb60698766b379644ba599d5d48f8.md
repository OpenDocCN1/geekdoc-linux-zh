Note that, in this case, L could *not* have been equivalently defined with a # preprocessor statement. The following t defines a type name S to be a c pointer:

```
t
```

Variables subsequently declared to be of type S, as in

```
S
```

are treated as character pointers by the C compiler. To define a new type name with t, follow these steps:

+   1. Write the statement as if a variable of the desired type were being declared.  
+   2. Where the name of the declared variable would normally appear, substitute the new type name.  
+   3. In front of everything, place the keyword t.

As an example of this procedure, to define a type called D to be a structure containing three integer members called m, d, and y, you write out the structure definition, substituting the name D where the variable name would normally appear (before the last semicolon). Before everything, you place the keyword t:

```
t
```

With this t in place, you can subsequently declare variables to be of type D, as in

```
D
```

This defines b to be an array containing 100 D structures. When working on programs in which the source code is contained in more than one file (as described in Chapter 14, “*Working with Larger Programs*”), it’s a good idea to place the common t statements into a separate file that can be included into each source file with an # statement.
