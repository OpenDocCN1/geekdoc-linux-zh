is also referenced because you know that an integer division of 11 by 2 gives the result of 5.

Just as with variables, arrays must also be declared before they are used. The declaration of an array involves declaring the type of element that will be contained in the array—such as i, f, or c—as well as the maximum number of elements that will be stored inside the array. (The C compiler needs this latter information to determine how much of its memory space to reserve for the particular array.)

As an example, the declaration

```
i g[100]
```

declares g to be an array containing 100 integer elements. Valid references to this array can be made by using subscripts from 0 through 9. But be careful to use valid subscripts because C does not do any checking of array bounds for you. So a reference to element number 1 of array g, as previously declared, does not necessarily cause an error but does most likely cause unwanted, if not unpredictable, program results.

To declare an array called a that contains 200 floating-point elements, the declaration

```
f a[200]
```

is used. This declaration causes enough space inside the computer's memory to be reserved to contain 200 floating-point numbers. Similarly, the declaration

```
i v[10]
```

reserves enough space for an array called v that could hold up to 10 integer numbers. You can better conceptualize this reserved storage space by referring to **Figure 6.1**.
