# Is It an Array or Is It a Pointer?

Recall that to pass an array to a function, you simply specify the name of the array, as you did previously with the call to the a \_ function. You should also remember that to produce a pointer to an array, you need only specify the name of the array. This implies that in the call to the a \_ function, what was passed to the function was actually a pointer to the array v \_ . This is precisely the case and explains why you are able to change the elements of an array from within a function.

But if it is indeed the case that a pointer to the array is passed to the function, then you might wonder why the formal parameter inside the function isn't declared to be a pointer. In other words, in the declaration of a \_ in the a \_ function, why isn't the declaration i \_ used? Shouldn't all references to an array from within a function be made using pointer variables?

To answer these questions, recall the previous discussion about pointers and arrays. As mentioned, if v \_ points to the same type of element as contained in an array called v \_ , the expression \* \_ is in all ways equivalent to the expression v \_ , assuming that v \_ has been set to point to the beginning of v \_ . What follows from this is that you also can use the expression \* \_ to reference the i th element of the array v \_ , and, in general, if x is an array of any type, the expression x \_ can always be equivalently expressed in C as \* \_ .

As you can see, pointers and arrays are intimately related in C, and this is why you can declare a \_ to be of type “array of i \_ s” inside the a \_ function *or* to be of type “pointer to i \_ .” Either declaration works just fine in the preceding program—try it and see.

If you are going to be using index numbers to reference the elements of an array that is passed to a function, declare the corresponding formal parameter to be an array. This more correctly reflects the use of the array by the function. Similarly, if you are using the argument as a pointer to the array, declare it to be of type pointer.
