```

The newline character is repeated outside the brackets so that `sscanf` matches it and does not read it the next time it's called. (Remember, `sscanf` always continues reading from the character that terminated its last call.)

When a value is read that does not match a value expected by `sscanf` (for example, typing in the character `x` when an integer is expected), `sscanf` does not read any further items from the input and immediately returns.
