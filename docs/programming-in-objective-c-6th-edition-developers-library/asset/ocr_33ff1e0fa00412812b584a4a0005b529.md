```
i              filePtr, format, arg1, arg2, \dots, argn)
```

Reads data items from the file identified by *filePtr*, according to the format specified by
the character string *format*. The values that are read are stored in the arguments specified after
*format*, each of which must be a pointer. The *format* characters that are allowed in f
are the same as those for the s          function (see Chapter 15). The f        function returns the
number of items successfully read and assigned (excluding any %   assignments) or the value E
if the end of file is reached before the first item is converted.

```
i          filePtr, offset, mode)
```

Positions the indicated file to a point that is o           (a l              ) bytes from the beginning of the
file, from the current position in the file, or from the end of the file, depending upon the value of
*mode* (an integer). If *mode* equals S        , positioning is relative to the beginning of the file. If
*mode* equals S        , positioning is relative to the current position in the file. If *mode* equals
S        , positioning is relative to the end of the file. S        , S        , and S
are defined in <          .

On systems that distinguish between text and binary files, S        might not be supported for
binary files. For text files, either *offset* must be zero or must be a value returned from a prior call
to f       . In the latter case, *mode* must be S        .
If the f        call is unsuccessful, a nonzero value is returned.
