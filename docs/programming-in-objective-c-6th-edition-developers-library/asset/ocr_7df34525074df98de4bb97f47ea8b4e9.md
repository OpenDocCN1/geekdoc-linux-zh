```
d
```

Execution of the preceding statement proceeds as follows:

+   1. The `c` function is called with two arguments, the first specifying that storage for n elements is to be dynamically allocated and the second specifying the size of each element.

+   2. The `c` function returns a pointer in memory to the allocated storage area. If the storage cannot be allocated, the null pointer is returned.

+   3. The pointer is type cast into a pointer of type “pointer to S” and is then assigned to the pointer variable `d` .

Once again, the value of `d` should be subsequently tested to ensure that the allocation succeeded. If it did, its value is not null. This pointer can then be used in the normal fashion, as if it were pointing to an array of n elements. For example, if `d` contains an integer member called `i`, you can assign 100 to this member as pointed to by `d` with the following statement:

```
d
```

# ## The free Function

When you have finished working with the memory that has been dynamically allocated by `c` or `m`, you should give it back to the system by calling the `f` function. The single argument to the function is a pointer to the beginning of the allocated memory, as returned by a `c` or `m` call. So, the call

```
f
```

returns the memory allocated by the `c` call shown previously, provided that the value of `d` still points to the *beginning* of the allocated memory.

The `f` function does not return a value.

The memory that is released by `f` can be reused by a later call to `c` or `m`. For programs that need to allocate more storage space than would otherwise be available if it were all allocated at once, this is worth remembering. Make certain you give the `f` function a valid pointer to the beginning of some previously allocated space.

Dynamic memory allocation is invaluable when dealing with linked structures, such as linked lists. When you need to add a new entry to the list, you can dynamically allocate storage for one entry in the list and link it into the list with the pointer returned by `c` or `m`.
