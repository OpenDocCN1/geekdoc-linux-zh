The square root of a negative number takes you away from the realm of real numbers and into the area of imaginary numbers. So what happens if you pass a negative number to your s \( \) function? The fact is, the Newton-Raphson process would never converge; that is, the value of g \( \) would not get closer to the correct value of the square root with each iteration of the loop. Therefore, the criteria set up for termination of the \( \) loop would *never* be satisfied, and the program would enter an infinite loop.
