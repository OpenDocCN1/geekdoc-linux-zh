To display a value in scientific notation, the format characters \%e\ or \%E\ should be specified in the \verb=\p=\ format string. The \verb=\p=\ format characters \%e\ or \%E\ can be used to let \verb=\p=\ decide whether to display the floating-point value in normal floating-point notation or in scientific notation. This decision is based on the value of the exponent: If it\u00e2\u0080\u0099s less than \textendash 4 or greater than 5, \%e\ (scientific notation) format is used; otherwise, \%f\ format is used.

Use the \%f\ format characters for displaying floating-point numbers\u2014it produces the most aesthetically pleasing output.

# The Extended Precision Type \verb=\p=\

The \verb=\p=\ type is very similar to the \verb=\p=\ type, but it is used whenever the range provided by a \verb=\p=\ variable is not sufficient. Variables declared to be of type \verb=\p=\ can store roughly twice as many significant digits as can a variable of type \verb=\p=\ . Most computers represent \verb=\p=\ values using 64 bits.

Unless told otherwise, all floating-point constants are taken as \verb=\p=\ values by the C compiler. To explicitly express a \verb=\p=\ constant, append either an \verb=\p=\ or F to the end of the number, as follows:

1.0f

To display a \verb=\p=\ value, the format characters \%d\ , \%e\ , or \%f\ , which are the same format characters used to display a \verb=\p=\ value, can be used.

# The Single Character Type \verb=\p=\

A \verb=\p=\ variable can be used to store a single character.$^{\dagger}$ A character constant is formed by enclosing the character within a pair of single quotation marks. So '\verb=\p=\', '\verb=\p=\', and '\verb=\p=\' are all valid examples of character constants. The first constant represents the letter \textit{a}, the second is a semicolon, and the third is the character zero\u2014which is not the same as the number zero. Do not confuse a character constant, which is a single character enclosed in single quotes, with a character string, which is any number of characters enclosed in double quotes.

The character constant \textbackslash n\ \u2014 the newline character\u2014is a valid character constant even though it seems to contradict the rule cited previously. This is because the backslash character is a special character in the C system and does not actually count as a character. In other words, the C compiler treats the character \textbackslash n\ as a single character, even though it is actually formed by two characters.
