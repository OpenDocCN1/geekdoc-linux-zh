# ## 8.6 The goto Statement

The general format for declaring the g     statement is as follows:

```
g     identifier;
```

Execution of the g     causes control to be sent directly to the statement labeled identifier. The labeled statement must be located in the same function as the g     .

# ## 8.7 The i f Statement

One general format for declaring an i     statement is as follows:

```
i     expression
     programStatement
```

If the result of evaluating expression is nonzero, programStatement is executed; otherwise, it is skipped.

Another general format for declaring an i     statement is as follows:

```
i     expression
     programStatement_1
e     programStatement_2
```

If the value of expression is nonzero, the programStatement 1 is executed; otherwise, programStatement_2 is executed. If programStatement_2 is another i     statement, an i     chain is effected:

```
i     expression_1
     programStatement_1
e     expression_2
     programStatement_2
e
     programStatement_n
```

An θ     clause is always associated with the last i     statement that does not contain an θ     . Braces can be used to change this association if necessary.
