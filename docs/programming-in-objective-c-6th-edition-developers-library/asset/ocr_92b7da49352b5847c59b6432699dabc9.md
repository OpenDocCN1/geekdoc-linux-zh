The purpose of the swap function is to interchange the two integer values pointed to by its two arguments. The function header

Click here to view code image

```
`void swap(int* p1, int* p2)`
```

says that the swap function takes two integer pointers as arguments, and that the pointers will not be changed by the function (the use of the keyword const).

The local integer variable t is used to hold one of the integer values while the exchange is made. Its value is set equal to the integer that is pointed to by p1. The integer pointed to by p2 is then copied into the integer pointed to by p1, and the value of t is then stored in the integer pointed to by p2, thus making the exchange complete.

The main routine defines integers i1 and i2 with values of -5 and 6, respectively. Two integer pointers, p1 and p2, are then defined and are set to point to i1 and i2, respectively. The program then displays the values of i1 and i2 and calls the swap function, passing the two pointers, p1 and p2, as arguments. The swap function exchanges the value contained in the integer pointed to by p1 with the value contained in the integer pointed to by p2. Because p1 points to i1, and p2 to i2, the values of i1 and i2 end up getting exchanged by the function. The output from the second p call verifies that the exchange worked properly.

The second call to swap is a bit more interesting. This time, the arguments that are passed to the function are pointers to i3 and i4 that are manufactured right on the spot by applying the address operator to these two variables. Because the expression &i3 produces a pointer to the integer variable i3, this is right in line with the type of argument that your function expects for the first argument (a pointer to an integer). The same applies for the second argument as well. And as can be seen from the program's output, the swap function did its job and switched the values of i3 and i4 back to their original values.

You should realize that without the use of pointers, you could not have written your swap function to exchange the value of two integers because you are limited to returning only a single value from a function and because a function cannot permanently change the value of its arguments. Study Program 10.9 in detail. It illustrates with a small example the key concepts to be understood when dealing with pointers in C.
