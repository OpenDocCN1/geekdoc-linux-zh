# **Single Stepping**

Another useful command for controlling program execution is the `s` command, which can be abbreviated as `s`. This command single steps your program, meaning that one line of C code in your program is executed for each `s` command you enter. If you follow the `s` command with a number, then that many lines are executed. Note that a line might contain several C statements; however, `g` is line oriented, and executes all statements on a line as a single step. If a statement spans several lines, single stepping the first line of the statement causes all the lines of the statement to be executed. You can single step your program at any time that a `c` is appropriate (after a signal or breakpoint).

If the statement contains a function call and you `s`, `g` takes you into the function (provided it’s not a system library function; these are typically not entered). If you use the `n` command instead of `s`, `g` makes the function call and does not step you into it.
