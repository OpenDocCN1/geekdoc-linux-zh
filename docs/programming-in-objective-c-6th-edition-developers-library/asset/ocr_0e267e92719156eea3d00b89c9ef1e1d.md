Recall from Chapter 8, “Working with Structures,” when you wrote the programs that prompted the user to enter the time from the terminal, any nonformat characters that were specified in the format string of the s call were expected on the input. So, for example, the s call

```
s
```

means that three integer values are to be read in and stored in the variables h , m , and s , respectively. Inside the format string, the : character specifies that colons are expected as separators between the three integer values.

To specify that a percent sign is expected as input, double percent signs are included in the format string, as follows:

```
s
```

Whitespace characters inside a format string match an arbitrary number of whitespace characters on the input. So, the call

```
s
```

with the line of text

```
2
```

assigns the value 2 to i and a space character to c because this is the character that appears immediately after the characters 2 on the input. If the following s call is made instead:

```
s
```

and the same line of text is entered, the value 2 is assigned to i and the character ' ' to c because the blank space in the format string causes the s function to ignore any leading whitespace characters after the characters 2 have been read.
