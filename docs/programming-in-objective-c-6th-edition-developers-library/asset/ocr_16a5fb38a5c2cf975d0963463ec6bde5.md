If n          is less than zero, $       is assigned the value -1; else if n         is equal to zero, $ is assigned the value 0; else it is assigned the value 1. The parentheses around the “else” part of the preceding expression are actually unnecessary. This is because the conditional operator associates from right to left, meaning that multiple uses of this operator in a single expression, such as in

```
    e
```

group from right to left and, therefore, are evaluated as

```
    e
```

It is not necessary that the conditional operator be used on the right-hand side of an assignment—it can be used in any situation in which an expression could be used. This means that you could display the sign of the variable n          , without first assigning it to a variable, using a p          statement as shown:

```
    P
```
