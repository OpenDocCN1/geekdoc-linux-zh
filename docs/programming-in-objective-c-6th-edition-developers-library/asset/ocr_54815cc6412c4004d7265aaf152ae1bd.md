+   2. If either operand is of type `d`, the other is converted to `d`, and that is the type of the result.
+   3. If either operand is of type `f`, the other is converted to `f`, and that is the type of the result.
+   4. If either operand is of type `_`, `c`, `s`, `b`, or of an enumerated data type, it is converted to `i`.
+   5. If either operand is of type `l`, the other is converted to `l`, and that is the type of the result.
+   6. If either operand is of type `l`, the other is converted to `l`, and that is the type of the result.
+   7. If this step is reached, both operands are of type `i`, and that is the type of the result.

This is actually a simplified version of the steps that are involved in converting operands in an expression. The rules get more complicated when unsigned operands are involved. For the complete set of rules, refer to *Appendix A, \"C Language Summary.\"*

Realize from this series of steps that whenever you reach a step that says \"that is the type of the result,\" you're done with the conversion process.

As an example of how to follow these steps, see how the following expression would be evaluated, where `f` is defined to be a `f`, `i` an `i`, `l` a `l`, and `s` a `s` variable:

```
`f`
```

Consider first the multiplication of `f` by `i`, which is the multiplication of a `f` by an `i`. From step 3, you find that, because `f` is of type `f`, the other operand, `i`, is also converted to type `f`, and that is the type of the result of the multiplication.

Next, the division of `l` by `s` occurs, which is the division of a `l` by a `s`. Step 4 tells you that the `s` is promoted to an `i`. Continuing, you find from step 6 that because one of the operands (`l`) is a `l`, the other operand is converted to a `l`, which is also the type of the result. This division, therefore, produces a value of type `l`, with any fractional part resulting from the division truncated.

Finally, step 3 indicates that if one of the operands in an expression is of type `f` (as is the result of multiplying `f * i`), the other operand is converted to type `f`, which is the type of the result. Therefore, after the division of `l` by `s` has been performed, the result of the operation is converted to type `f` and then added into the product of `f` and `i`. The final result of the preceding expression is, therefore, a value of type `f`.

Remember, the type cast operator can always be used to explicitly force conversions and thereby control the way that a particular expression is evaluated.
