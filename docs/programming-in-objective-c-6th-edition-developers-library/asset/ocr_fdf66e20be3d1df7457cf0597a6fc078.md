The s  function implements the algorithm as a set of nested f  loops. The outermost loop sequences through the array from the first element through the next-to-last element (a       ). For each such element, a second f  loop is entered, which starts from the element after the one currently selected by the outer loop and ranges through the last element of the array.

If the elements are out of order (that is, if a       is greater than a     ), the elements are switched. The variable t     is used as a temporary storage place while the switch is being made.

When both f  loops are finished, the array has been sorted into ascending order. Execution of the function is then complete.
