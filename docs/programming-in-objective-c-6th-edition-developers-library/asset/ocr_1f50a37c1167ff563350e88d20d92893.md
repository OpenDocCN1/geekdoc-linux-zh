Returning to Program 6.7 , the character array b is set up to contain the 16 possible digits that will be displayed for the converted number. It is declared as a c array because its contents will not be changed after it is initialized. Note that this fact also aids in the program’s readability.

The array c is defined to contain a maximum of 64 digits, which holds the results of converting the largest possible l integer to the smallest possible base (base 2) on just about all machines. The variable n is defined to be of type l so that relatively large numbers can be converted if desired. Finally, the variables b (to contain the desired conversion base) and i (to index into the c array) are both defined to be of type i .

After the user keys in the values of the number to be converted and the base—note that the c call to read in a l integer value takes the format characters % ——the program then enters a c loop to perform the conversion. The c was chosen so that at least one digit appears in the c array even if the user keys in the number zero to be converted.

Inside the loop, the n modulo the b is computed to determine the next digit. This digit is stored inside the c array, and the i in the array is incremented by 1. After dividing the n by the base, the conditions of the c loop are checked. If the value of n is 0, the loop terminates; otherwise, the loop is repeated to determine the next digit of the converted number.

When the c loop is complete, the value of the variable i is the number of digits in the converted number. Because this variable is incremented one time too many inside the c loop, its value is initially decremented by 1 in the f loop. The purpose of this f loop is to display the converted number at the terminal. The f loop sequences through the c array in reverse sequence to display the digits in the correct order.

Each digit from the c array is in turn assigned to the variable n . For the numbers 10 through 15 to be correctly displayed using the letters A through F, a lookup is then made inside the array b , using the value of n as the index. For the digits 0 through 9, the corresponding location in the array b contains nothing more than the characters ' through ' (which as you recall are distinct from the integers 0 through 9). Locations 10 through 15 of the array contain the characters ' through ' . So, if the value of n is 10, for example, the character contained in b , or ' , is displayed.
