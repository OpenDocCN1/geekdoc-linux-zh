The specifier s , when placed in front of the i declaration, tells the C compiler that the particular variable being declared is used to store fairly small integer values. The motivation for using s variables is primarily one of conserving memory space, which can be an issue in situations in which the program needs a lot of memory and the amount of available memory is limited. On some machines, a s takes up half the amount of storage as a regular i variable does. In any case, you are guaranteed that the amount of space allocated for a s will not be less than 16 bits.
