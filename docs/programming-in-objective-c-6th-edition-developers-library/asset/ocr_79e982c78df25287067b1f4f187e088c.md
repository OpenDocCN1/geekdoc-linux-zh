Upon encountering the terminating null character, the f loop is exited and the value of r, 2, is returned to the calling routine.

The s function could be improved in two ways. First, it doesn't handle negative numbers. Second, it doesn't let you know whether the string contained any valid digit characters at all. For example, s returns 0. These improvements are left as an exercise.

This discussion concludes this chapter on character strings. As you can see, C provides capabilities that enable character strings to be efficiently and easily manipulated. The library actually contains a wide variety of library functions for performing operations on strings. For example, it offers the function s to calculate the length of a character string; s to compare two strings; s to concatenate two strings; s to copy one string to another; a to convert a string to an integer; and i, i, i, and i to test whether a character is uppercase, lowercase, alphabetic, or a digit. A good exercise is to rewrite the examples from this chapter to make use of these routines. Consult Appendix B, "The Standard C Library," which lists many of the functions available from the library.
