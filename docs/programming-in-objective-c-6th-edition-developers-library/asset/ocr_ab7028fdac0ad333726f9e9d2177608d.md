The for loop is executed as long as the character contained in s is a digit character. Each time through the loop, the character contained in s is converted into its equivalent integer value and is then added into the value of r multiplied by 10. To see how this technique works, consider execution of this loop when the function is called with the character string "21" as an argument: The first time through the loop, i is assigned the value of s - '0'. Because s contains the character '2', this results in the value 2 being assigned to i. Because the value of r is 0 the first time through the loop, multiplying it by 10 produces 0, which is added to i and stored back in r. So, by the end of the first pass through the loop, r contains the value 2.
The second time through the loop, i is set equal to 4, as calculated by subtracting '0' from '2'. Multiplying r by 10 produces 20, which is added to the value of i, producing 22 as the value stored in r.
The third time through the loop, i is equal to '2' - '0', or 5, which is added into the r * 10 term of the right hand side of the if statement, where r * 10 = 22 * 10 = 220, and i = 5, so r = 220 + 5 = 225. The loop ends because s is no longer a digit character. The integer value of the string "21" is 225.
