# Getting Help with **gdb** Commands

You can use the built-in `h` command to get information about various commands or types of commands (called *classes* by `g`).

The command `h`, without any arguments, lists all the available classes:

![](bbox=[0.0, 0.14, 0.25, 0.16])

```
```

	L
a
b

C
```

```
