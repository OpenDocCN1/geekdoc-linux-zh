# Getting a Stack Trace

Sometimes, you’ll want to know exactly where you are in terms of the hierarchy of function calls when a program gets interrupted. This is useful information when examining a core file. You can take a look at the call stack by using the b command, which can be abbreviated as b . The following is an example use of Program 17.5.

Click here to view code image

```
( break foo
(
$
$
$
$
(
 bt Print stack trace
#(#(#(#

```

When the break is taken on entry to f , the b command is entered. The output shows two functions on the call stack: f and m . As you can see, the arguments to the functions are also listed. Various commands (such as u , d , f , and i ) that are not covered here allow you to work your way around in the stack so that you can more easily examine arguments passed to a particular function or work with its local variables.

# Calling Functions and Setting Arrays and Structures

You can use function calls in g expressions as follows:

```
( print foo( *newdate) Call foo with date structure pointed to by newdate
$
(
}\n(

```

Here, the function f is defined in Program 17.5.

You can assign values to an array or structure by listing them inside a set of curly braces, as follows:

```
( print array
$
(
 set var array = {100, 200}
( print array
$
```
