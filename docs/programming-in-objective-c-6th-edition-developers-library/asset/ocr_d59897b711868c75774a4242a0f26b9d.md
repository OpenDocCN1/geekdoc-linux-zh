An integer constant that’s not followed by any of the letters u, U, l, or L and that is too large to fit into a normal-sized i   is treated as an u                by the compiler. If it’s too small to fit into an u               , the compiler treats it as a l               . If it still can’t fit inside a l   , the compiler makes it an u               . If it doesn’t fit there, the compiler treats it as a l               if it fits, and as an u               otherwise.

When declaring variables to be of type l           , l        , s        , or u       , you can omit the keyword i       . Therefore, the u        variable c could have been equivalently declared as follows:

```
u
```

You can also declare c      variables to be u      .

The s      qualifier can be used to explicitly tell the compiler that a particular variable is a signed quantity. Its use is primarily in front of the c      declaration, and further discussion is deferred until **Chapter 13, “More on Data Types.”**

Don’t worry if the discussions of these specifiers seem a bit esoteric to you at this point.
