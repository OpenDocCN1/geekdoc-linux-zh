If a local variable with the specified name doesn't exist, g looks for an external variable of the same name. In the previous example, the function executing at the time the invalid access occurred was m , and i was a variable local to m .

A function can be specified as part of the variable name in the form *function*::*variable* to reference a variable local to a specific routine, for example,

```

   print main::i           Display contents of i in main
   set var main::i=0       Set value of i in main
```

Note that attempting to set a variable in an inactive function (that is, a function that is not either currently executing or waiting for another function to return to continue its own execution) is an error and results in the following message:

```

```

Global variables can be directly referenced as '*file*::*var*'. This forces g to access an external variable as defined in the file *file* and ignore any local variable of the same name in the current function.

Structure and union members can be accessed using standard C syntax. If d is a pointer to a d , p prints the year member of the structure pointed to by d .

Referencing a structure or union without a member causes the contents of the entire structure or union to be displayed.

You can force g to display a variable in a different format, for example hexadecimal, by following the p command with a \ / and a letter that specifies the format to use. Many g commands can be abbreviated with a single letter. In the following example, the abbreviation for the p command, which is p, is used:

```

   set var i=35           Set i to 3
   p / x i                 Display i in hexadecimal
```

# Source File Display

g provides several commands that give you access to the source files. This enables you to debug the program without having to reference a source listing or open your source files in other windows. As mentioned earlier, g maintains an idea of what the current line and file are. You've seen how you can display the area around the current line with the 1 command, which can be abbreviated as 1. Each time you subsequently type the 1 command (or more simply, just press the Enter or Return key), the next 10 lines from the file are displayed. This value of 1 is the default and can be set to any value by using the 1 command.
