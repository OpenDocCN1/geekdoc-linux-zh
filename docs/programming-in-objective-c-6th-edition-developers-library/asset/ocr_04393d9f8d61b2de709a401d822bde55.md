# The ## Operator

This operator is used in macro definitions to join two *tokens* together. It is preceded (or followed) by the name of a parameter to the macro. The preprocessor takes the actual argument to the macro that is supplied when the macro is invoked and creates a single token out of that argument and whatever token follows (or precedes) the `#` .

Suppose, for example, you have a list of variables `x₁` through `x₈` . You can write a macro called `pₙ` that simply takes as its argument an integer value 1 through 1 and that displays the corresponding `x` variable as shown:

```

#define pₙ xₙ

```

The portion of the *define* that reads
```
xₙ
```

says to take the tokens that occur before and after the `#` (the letter `x` and the argument `n`, respectively) and make a single token out of them. So the call `p₃` is expanded into `x₃`

The `p₃` macro can even use the previously defined `pₙ` macro to get the variable name as well as its value displayed:


```

# define pₙ printf ("xₙ=%d\n", xₙ)

```

The invocation
```
p₃
```
first expands into
```
x₃ = x₃
```
and then into

and finally into

# The #include Statement

After you have programmed in C for a while, you will find yourself developing your own set of macros and functions that you will want to use in each of your programs. But instead of having to type these macros into each new program you write, the preprocessor enables you to collect all your definitions into a separate file and then *include* the file and all its macros and user-defined functions in your program, using the `#` statement. These files normally end with the characters `.h` and are referred to as *header* or *include* files.
