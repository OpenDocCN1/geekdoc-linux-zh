effect of exiting the function anyway without returning a value. In other words, either with or without the return statement, the behavior on exit from p is identical.

As mentioned previously, the idea of calling a function is not new. The p and s routines are both program functions. The main distinction here is that these routines did not have to be written by you because they are a part of the standard C library. When you use the p function to display a message or program results, execution is transferred to the p function, which performs the required tasks and then returns back to the program. In each case, execution is returned to the program statement that immediately follows the call to the function.
