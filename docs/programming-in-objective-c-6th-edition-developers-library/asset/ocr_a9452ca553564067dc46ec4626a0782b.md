Any integer that would normally take up less than two columns (that is, the integers 0 through 9) are displayed with a *leading space*. This is known as *right justification*.

Thus, by using a field width specification of %  , you guarantee that at least two columns are used for displaying the value of n and, therefore, you ensure that the values of t        are lined up.

If the value that is to be displayed requires more columns than are specified by the field width, p          simply ignores the field width specification and uses as many columns as are necessary to display the value.

Field width specifications can also be used for displaying values other than integers. You will see some examples of this in programs that are coming up shortly.
