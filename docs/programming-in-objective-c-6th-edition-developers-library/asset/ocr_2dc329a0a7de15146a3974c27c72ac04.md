When the f function is called to calculate the factorial of 0, the function sets the value of r to 1 and return, thus initiating the evaluation of all of the pending expressions. So the value of f , or 1, is returned to the calling function (which happens to be the f function), multiplied by 1, and assigned to r . This value of 1, which represents the value of f , is then returned back to the calling function (once again the f function) where it is multiplied by 2, stored into r , and returned as the value of f . Finally, the returned value of 2 is multiplied by 3, thus completing the pending calculation of f . The resulting value of 6 is returned as the final result of the call to the f function, to be displayed by the p function.
