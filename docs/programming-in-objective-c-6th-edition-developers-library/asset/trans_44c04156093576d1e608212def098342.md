## 单字符输入

标准库提供了几个专门用于读取和写入单个字符以及整个字符串的函数。名为 `g` 的函数可用于从终端读取单个字符。反复调用 `g` 函数会依次返回输入中的单个字符。当到达行尾时，函数返回换行符。因此，如果输入字符 `"abc"` 并立即按回车（或 Return）键，第一次调用 `g` 函数返回字符 `a`，第二次调用返回字符 `b`，第三次调用返回 `c`，第四次调用返回换行符。第五次调用该函数会导致程序等待从终端输入更多数据。

您可能在疑惑，当您已经知道如何使用函数的 `%` 格式字符读取单个字符时，为什么还需要 `g` 函数。使用函数来实现这一目的是完全有效的；然而，`g` 函数是一种更直接的方法，因为其唯一目的就是读取单个字符，因此它不需要任何参数。该函数返回一个字符，可以分配给变量或按程序需要的方式使用。

在许多文本处理应用程序中，您需要读取一整行文本。该行文本通常存储在一个单一位置——通常称为“缓冲区”——以便进一步处理。在这种情况中，使用带有 `%` 格式字符的调用不起作用，因为字符串一遇到输入中的空格就会终止。

函数库还提供了名为 `s` 的函数。该函数的唯一目的——您猜对了——是读取一行文本。作为一个有趣的编程练习，程序 9.6 展示了如何使用 `g` 函数开发一个类似于 `g` 函数（这里称为 `r`）的函数。该函数接受一个参数：一个用于存储文本行的字符数组。函数将终端窗口中读取的字符（直到但不包括换行符）存储在此数组中。
