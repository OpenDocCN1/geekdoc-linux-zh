In fact, a function always has its own set of formal parameters. So the formal parameter `x` used inside the `a` function is distinct from the formal parameter `x` used inside the `s` function.

The same is true for local variables. You can declare local variables with the same name inside as many functions as you want. The C compiler does not confuse the usage of these variables because a local variable can only be accessed within the function it is defined. Another way of saying this is that the *scope* of a local variable is the function in which it is defined. (As you discover in **Chapter 10**, “Pointers,” C does provide a mechanism for indirectly accessing a local variable from outside of a function.)

Based upon this discussion, you can understand that when the value of `g` is passed to the `a` function and assigned to the formal parameter `x`, this assignment has absolutely *no* effect on the value of `x` inside the `s` function.

# ## Declaring Return Types and Argument Types

As mentioned previously, the C compiler assumes that a function returns a value of type `i` as the default case. More specifically, when a call is made to a function, the compiler assumes that the function returns a value of type `i` unless either of the following has occurred:

+   1. The function has been defined in the program before the function call is encountered.
+   2. The value returned by the function has been *declared* before the function call is encountered.

In **Program 7.8**, the `a` function is defined before the compiler encounters a call to this function from within the `s` function. The compiler knows, therefore, that when this call is encountered, the `a` function will return a value of type `f`. Had the `a` function been defined *after* the `s` function, then upon encountering the call to the `a` function, the compiler would have assumed that this function returned an integer value. Most C compilers catch this error and generate an appropriate diagnostic message.

To be able to define the `a` function *after* the `s` function (or even in another file—see **Chapter 14**), you must *declare* the type of result returned by the `a` function *before* the function is called. The declaration can be made inside the `s` function itself, or outside of any function. In the latter case, the declaration is usually made at the beginning of the program.

Not only is the function declaration used to declare the function’s return type, but it is also used to tell the compiler how many arguments the function takes and what their types are.

To declare `a` as a function that returns a value of type `f` and that takes a single argument, also of type `f`, the following declaration is used:

`f a (f);`

As you can see, you just have to specify the argument type inside the parentheses, and not its name. You can optionally specify a “dummy” name after the type if you want:

```
`f a (dummy);`
```
