## 关于 Linux 的误解

### 安装

Linux 很难安装，不是吗？其实不然。大多数人也没有在电脑上安装过 Windows——因为它是预装的。与 Windows 相比，Linux 的安装非常简单。你可以像 Windows 一样通过图形界面安装它。如今的 Linux 版本比 Windows更容易安装。但真正让大多数人困扰的是在想要同时使用两个操作系统时，如何在硬盘的第二个分区上安装 Linux。

分区是通过创建相互独立的虚拟区域来组织硬盘空间的方法。大多数运行 Windows 或 MS DOS 的电脑都有一个大空间存放操作系统。这个空间就是 C 盘。如果你有一个大硬盘，它可能被划分为较小的分区以帮助你更好地组织数据。这些分区通常是 D:、E: 等你可以在其中任何一个分区上安装 Linux。

Windows 98 在整个硬盘上创建一个名为 FAT32 的系统，DOS 和 Win95 使用 FAT16。Linux 有许多文件系统——最流行的是 ext3。但你也可以在 Fat32 分区上 Linux。

### Linux 非常困难且基于文本命令

Linux 从成为天才电脑用户的系统以来已经走了很远。它拥有极其先进的 X Windows 系统，具有完整的图形用户界面——你知道的，就像 Windows 一样。它还有大量的窗口管理器，让你对桌面进行不同程度的自定义。但 X 系统本身是非常原始的，需要一个窗口管理器或桌面环境——如 GNOME 或 KDE——才能真正易用。

窗口管理器是通过传递命令让你与底层 X 系统和 Linux 操作系统交互的程序。流行的窗口管理器有 Sawfish、Enlightenment、Black box、after step 和 Window manager。

至于桌面管理器，它们有自己的窗口管理器和其他工具来使

你会感觉就像是在 Windows 中工作一样！GNOME 和 KDE 是其中最流行的两个。GNOME 代表 GNU 网络模型环境，KDE 代表 K 桌面环境。它们拥有允许拖放的工具，拥有面板和任务栏——几乎就像 Windows 的克隆。

### 硬件兼容性问题以及少数运行在 Linux 上的应用程序

嗯，大多数新发行版都能在短时间内检测并配置你的硬件，除非你拥有某些非常老旧或奇特的硬件。所有硬件都能被正确检测并安装驱动程序。只有由 Windows 驱动支持的 Windows 调制调器会遇到问题。

软件方面，有很多。而且大部分都是免费提供的，你可以根据需要自由使用、修改和配置。几乎所有优秀的 Linux 软件都是免费的，你尝试一下也不会损失任何东西。对于你可能有的任何查询，你都能在网上获得快速的支持。你甚至不需要删掉 Windows。只需将 Linux 安装在不同的硬盘分区上，并根据你的意愿在它们之间切换。

其他软件包是商业性的，你必须购买软件——但这主要是为了软件以及为你提供培训，而不是软件本身。有时，如果你有 Windows 版本（如游戏），你可以下载一个小型程序，让你能够在 Linux 中运行该游戏。Linux 游戏具有非常高的质量和特性。你会喜欢它们的。以下是可用内容：

- 办公套件：Star Office, Open Office, Applixware, Corel WordPerfect
- 图形：GIMP, Corel Photo player
- 音乐：XMMS, Free amp, Real Player
- 视频：MTV, Xine
- 游戏：FreeCiv, Tux racer, Doom, Quake, Heretic, Unreal，列表仍在不断增长。

### 针对家庭用户的 Linux 版本

既然有这么多人在致力于它，很可能也有很多 Linux 版本。许多致力于 Linux 的公司开发了所谓的 Linux 发行版。有些 Linux 版本是经过编译、打包并附带额外软件后发布的。

**RedHat（红帽 Linux）**：可能是最流行且在许多方面处于领先地位的版本。目前是第 9 版本。安装和配置非常简单。一个蓝色的曲线文件管理器和默认的 GNOME 桌面看起来非常惊艳。它有一系列工具，可以作为服务器也可以作为工作站使用。由红帽开发的红帽软件包管理器 (RPM) 格式已成为 Linux 世界软件分发的标准。安装新软件轻而易举。它还拥有先进且易用的字体管理系统，让 Windows 中的字体看起来非常酷炫。

**Mandrake（曼德拉）**：Linux 现在是第 10 版本。它可以使用 LinuxWin 工具安装在原生的 Windows 分区上，这可能会减慢机器速度。它还允许你在专用分区中进行传统的 Linux 安装。Mandrake 的配置和软件安装是非常轻松的。它是一种稍微修改过的 RPM 架构，称为 mdk.rpm，但大多数红帽软件也可以用于 Mandrake。该版本的杰出特性是窗口管理器的集合——视觉控爱好者将在这里度过一段愉快的时光。

**SUSE（苏萨 Linux）**：来自德国的“变色龙”——SUSE。现在处于 8.x 版本，它拥有编译最广泛的软件包集合之一，通过 `ya`（另一个软件工具）可以轻松地安装它们，该工具提供了一个集中界面，你可以在从中挑选并选择要安装的软件。除其他外，SUSE 还带了一些惊艳的 3D 游戏，展示了 Linux 的游戏实力。

**Corel/Xandross**：Corel 几年前带着 Core Linux 进入市场。现在它已合并为基于 Core Linux 的 Xandross OS。这是一个 Debian 类型的版本，在调整 Windows 分区大小后可以无需麻烦地安装。Xandross 包含了 Crossover office，它是 WINE 的精简零售版，让你能够安装和运行许多微软应用程序。

### Linux 中的 Windows 应用程序

某些应用程序已移植到 Linux，另一些通过一个名为 WINE 的程序运行（Wine 并不是模拟器）。Crossover 这种市用软件也让你让你在 Linux 上使用你的 Windows 程序。VMware 是另一个让你在 Linux 下运行 Windows 的程序。现在，许多软件公司已开始为 Linux 开发高端软件。

Linux 的酷之处在于，大多数软件都是免费的，你可以合法地使用它们而不必担心盗版。如果你担心 Linux 看起来不像 Windows 漂亮，你只需要查看一些酷炫的 Linux 界面和窗口管理器即可。但 Linux 上并没有很多多媒体作品。如果你非常喜欢这些，那么 Windows 是不二之选。所以如果你有一台同时运行这两个系统的 PC，你可以轻松地在两者之间切换，兼两者之长。

## Linux 与 Windows 的区别

本子主题将讨论 Linux 和 Windows 操作系统之间的区别，我将讨论每个系统的优缺点。

让我们先从 Linux 操作系统的总体概览开始。Linux 最基本的形式是一个计算机内核。内核是底层的计算机代码，用于与硬件以及其他系统软件通信，它还运行计算机的所有基本功能。

Linux 内核是一个操作系统，运行在各种硬件上并用于各种目的。Linux 能够运行在像手表或手机一样简单的设备上，也可以运行在家用电脑上（例如 Intel 或 AMD 处理器），它甚至在使用 Sun Sparc CPU 或 IBM POWER 处理器的高端服务器上运行。许多 Linux 发行版只能运行一个处理器，而另一些可以同时运行多个。

Linux 的常见用途包括家庭桌面计算系统，或者更常见的服务器应用程序，例如作为 Web 服务器或邮件服务器。你甚至可以将 Linux 用作专用防火墙，帮助保护同一网络上的其他机器。

一位名为 Linus Torvalds 的程序员在 1991 年首次创建了 Linux，作为 Unix 操作系统的变体。Linus Torvalds 通过 GNU（通用公共许可）使 Linux 开源，这样其他程序员就可以免费下载源代码并根据自己的意愿进行修改。世界上数千名程序员开始下载和修改 Linux 的源代码，应用补丁、修复错误和其他改进，使该操作系统变得越来越好。多年来，Linux 从一个简单的基于文本的 Unix 克隆演变成了强大的操作系统，具有功能全桌面环境、前所未有的移植性以及多种用途。大多数原始 Unix 代码在多年来也逐渐从 Linux 中移除了。

由于 Linux 是开源软件，并没有单一的 Linux 版本；相反有许多不同的 Linux 版本或发行版，适用于各种用户和任务。某些 Linux 发行版包括 Gentoo 和 Slackware，由于缺乏完整的图形环境，它们最适合 Linux 专家、程序员以及熟悉命令行提示符的用户。缺乏图形环境的发行版最适合缺乏处理图形所需计算能力的旧电脑，或者用于正在执行密集型任务的计算机，在这些情况下，最好将所有系统资源都集中在手头任务上，而不是通过处理图形来浪费资源。

其他 Linux 发行版旨在让计算体验尽可能简单。如 Ubuntu、Linspike 等发行版让 Linux 变得更易用，提供了功能全图形环境，消除了对命令行的需求。易用性的缺点是可配置性较低，并且在图形处理上浪费了系统资源。其他发行版如 S 试图在易用性和可配置性之间寻找平衡点。

Linux 有两个部分，它们包括前面提到的内核，在大多数情况下它还会包含一个图形界面，运行在“内核”之上。

大多数 Linux 发行版都提供图形界面以简化用户体验，它们都为更有技术背景的用户提供了一种通过 shell 或命令行直接与内核通信的方式。

使用命令行提示符的一个优点是它使用的系统资源较少，并让你的计算机将更多精力集中在当前任务上。命令示例包括用于更改目录的 `cd` 命令、用于关闭系统的 `halt` 命令，或用于重启电脑的 `reboot` 命令等。

既然我们对 Linux 操作系统更加熟悉，我们可以注意到 Linux 与世界上最流行的操作系统微软 Windows（Microsoft Windows）之间的许多不同之处。从现在起，我们将讨论 Linux 与 Windows 之间的一些最显著的区别。

首先，只有一家公司发布 Windows 操作系统，那就是微软公司。所有的 Windows 版本，无论是 Windows XP 家庭版、业务版还是 Vista，所有的 Windows 更新、安全补丁和服务程序补丁都来自微软。相比之下，Linux 并不是由某一家公司发布的。

Linux 全范围内有数百万的编码人员和公司投入时间开发更新、新版本和软件应用程序。尽管有些公司对技术支持收费，另一些公司对其 Linux 发行版以及将其与非免费软件打包进行收费，但你始终可以免费获取 Linux 内核，并且可以获得带有所有必要通用用途应用程序的全功能 Linux 桌面，同时也需要为了符合 GPL 许可协议而发布免费版本。相比之下，对于微软 Windows，你必须向微软支付软件费用，并且还必须为你使用的大多数应用程序付费。

Windows 和 Linux 在技术支持问题上也有不同。Windows 由微软公司支持，这意味着如果你对任何一个产品遇到问题，该公司都应该解决它。例如，如果 Windows 无法运行，你应该能够致电微软并利用他们的技术支持来修复问题。技术支持通常包含在购买产品的一段时期内，可能是两年的期限，从那时起可能需要支付服务费。尽管 IBM 支持他们的 Linux 产品，但对于大多数情况，如果你使用 Linux，你需要自力更生。如果你在 Ubuntu Linux 上遇到问题，你无法致电 Ubuntu 并获得任何帮助。尽管缺乏专业帮助，但你仍然可以网络上的成千上万个 Linux 论坛获得良好的技术建议。你可以通过 Myspace 等社交网络网站，通过在许多 Linux 群组中发布问题来获得巨大的帮助。你通常可以在几小时内收到许多合职人士对你问题的回复。

可配置性是这两个操作系统之间的另一个关键区别。尽管 Windows 提供了控制面板帮助用户根据自己的喜好配置计算机，但它还没有 Linux 提供的配置选项，特别是如果你是一个真正的技术高明用户。在 Linux 中，内核是开源的，所以如果你懂，你就可以以任何你认为合适的方式对其进行修改。此外，Linux 还提供了多种图形环境以进一步适应你的需求。如前所述，Linux 能够运行全功能图形环境，如 KDE，或者更轻量且对资源友好的 GUI，如 Fluxbox 或 Black，以适应使用旧电脑的用户。此外还有某些 Linux 版本设计用于尽可能模拟 Windows 的外观和操作体验。像 Linspare 这样的发行版最适合从 Windows 世界迁移过来的用户。

还有一些完全不包含图形环境的发行版，以更好地适应那些需要为各种计算活动挤出所有计算能力的用户，以及那些比他人更进阶的用户。所有这些可配置性有时会带来问题，因为你必须决定哪个桌面适合你，并且为了让自己更轻松，你需要安装适用于你的发行版和图形环境的应用程序。

（ref #1）Linux 的性价比是它与 Windows 区分开来的另一种方式。对于家庭使用，Linux 是廉价的且在大多数情况下完全免费的，而 Windows 的成本取决于你购买哪个版本。对于 Linux，大多数应用程序也将是免费的，然而对于 Windows，在大多数情况下你必须为应用程序付费。在大多数情况下，使用 Linux 进行安装时不需要输入产品激活密钥，你可以自由地在任意数量的计算机上安装。而 Windows 你只被允许在一台计算机上安装，微软使用产品激活软件来执行这一规则。

安装 Windows 时，你必须输入产品激活密钥，该密钥在使用多次后会过期。如果你愿意，可以从不同的供应商购买 Linux，其中包含一套盒装 CD、手册和技术支持，价格大约在 40-130 美元之间。当然，如果你购买用于服务器的高端 Linux 版本，费用可能在 400-2000 美元之间。在《2002年计算机世界杂志》中引用了纽约道信林公司首席技术架构师的话说：“运行 Linux 的成本通常是运行 Unix 或 Windows 成本的十分。”（ref#1）

（ref #1）安装 Windows 通常比安装 Linux 简单。“对于 Windows XP 有三种安装方法。一种是纯净安装，即在空白硬盘上安装 Windows。另一种是升级安装，你从旧版本的 Windows 开始并‘升级’到新版本。升级的优点是旧系统上的所有文件都应该保持完好。”

Windows 和 Linux 在许多情况下也是不同的。在 Linux 之后，你可能会发现许多在 Windows 上运行的软件在 Linux 上无法运行，或者反之。由于 Linux 的开源特性，许多软件是由于社区开发的，而 Windows 软件通常是闭源的。这意味着 Linux 用户可能需要花费更多时间来寻找替代方案。

另一方面，对于 Linux 来说，病毒问题实际上不存在，实际上你的 Linux 不需要病毒防护。病毒和间谍软件对 Linux 来说不是问题的原因之一，仅仅是因为支持 Linux 的软件远比 Linux 多。另一个更重要的原因是，在 Linux 机器上运行病毒要困难得多，而且对用户的要求也得多。在 Windows 中，你可能会通过打开邮件附件或双击包含恶意代码的文件不小心运行病毒。然而在 Linux 中，病毒需要在终端中运行，要求用户执行文件权限，然后在终端中打开它。

而且为了对系统造成任何实际破坏，用户必须在运行病毒之前通过输入用户名和密码以 root 身份登录。

例如，要运行嵌入在邮件附件中的病毒，用户必须：打开附件、保存它，然后右键点击文件并从菜单中选择“属性”，在属性中他们可以赋予“执行权限”，然后他们就可以在终端中打开该文件运行病毒了。即便如此，用户也只能破坏自己的主目录（home folder），所有其他用户的数据将保持完好，所有的 root 系统文件也将保持完好，因为 Linux 修改这些文件需要 root 密码。

用户破坏整台电脑的唯一方法，是在运行病毒之前通过向终端提供 root 用户名和密码，以 root 用户身份登录。与 Windows 不同，Linux 中的可执行文件不能自动运行，它需要手动赋予执行权限，这显著提高了安全性。在 Linux 中，你唯一可能需要病毒防护的现实理由是你与 Windows 用户共享文件，那是为了保护他们而不是你，以免你无意中将病毒传给你共享的 Windows 电脑。



上述是 Windows 操作系统和 Linux 之间某些区别的概述。回顾一下，我们从这样一个事实开始：Windows 只有一个发布软件的供应商，而 Linux 来自于全球数百万不同的编码者。我们还提到了 Linux 内核以及与之配套的大部分应用程序都是完全免费的，而你被迫为大多数软件付费。与 Windows 不同，Linux 通常缺乏专业的技术支持，Linux 用户通常需要自力更生，或者依靠互联网上提供的许多 Linux 论坛和群组。由于内核是开源的，Linux 在可配置性方面比 Windows 有巨大的优势。你可以通过操纵内核来配置 Linux 以任何你认为合适的方式运行。

安装 Windows 操作系统和应用程序更为简单，因为它有一个通用的安装程序。此外，由于 Windows 的流行，为 Windows 寻找应用程序更容易，大多数应用仅在 Windows 上可用，并且很容易获得。Linux 运行的硬件种类比 Windows 更多，从运行多个 IBM Power PC 芯片的主机超级计算机，到运行 AMD 处理器的小型笔记本电脑。当然，在本文作者看来，区别在于 Linux 不会遭受病毒和其他恶意代码的猛烈攻击，而 Windows 经常受到无数恶意代码的困扰，如果不进行妥善防护，这些代码很容易摧毁你的系统。

Linux 操作系统确实是优越的软件。除了少数微小的困扰外，Linux 在大多数类别中都优于 Windows。Linux 更安全这一事实是转折点，它让天平向 Linux 倾斜。Windows 存在了太多的安全漏洞，以至于不能认为是更好的整体桌面环境。

当你进行 Linux 磁盘分区时（在安装 Linux 期间或之后），你可能会遇到无法创建分区的情况——并且无法执行你想要对分区执行的其他任务！

这时你就需要理解下面描述的 Linux 硬盘分区“规则”。

Linux 系统管理员训练提示：请记住，下面的“规则”适用于使用 Linux `fdisk` 命令，这是最常用的磁盘分区工具。你可能可以使用其他硬盘分区工具来“打破”这些规则。

你可以在使用大多数 Linux 发行版的安装程序时“设置”并配置你的 Linux 分区——也可以通过 Linux `fdisk` 和 `parted` 命令以及其他分区命令。

此外，作为 Linux 系统管理员，你还需要管理现有 Linux 系统（操作系统安装后）上的分区（创建、删除和修改）。要做到这一点，你使用 `fdisk` 命令/工具或 `parted` 命令/工具——还有其他的磁盘分区命令和工具。

Linux 硬盘分区有几种“类型”，例如：主分区（primary）、扩展分区（extended）和逻辑分区（logical）——使用这些 Linux 分区类型有严格的“规则”。

Linux 安装程序中的磁盘分区工具和 `fdisk` 命令（以及其他磁盘分区命令）每个硬盘驱动器最多可以创建四个主分区。

如果你需要四个以上的硬盘分区，你需要至少创建一个扩展分区，然后在扩展分区内创建一个或多个逻辑分区（Logical partitions）。

要在已有四个主分区的硬盘上创建扩展分区，你需要删除其中一个主分区，然后创建扩展分区。因此，如果你在 Linux 硬盘上创建扩展分区，你最多只能有三个主分区。

一个 Linux 硬盘在拥有扩展分区之前必须至少有一个主分区。`fdisk` 每个驱动器无法创建多一个扩展分区。为了能够使用扩展分区中的磁盘空间，它必须至少有一个逻辑分区（在扩展分区内部）。

扩展分区包含一个或多个逻辑分区。扩展分区不被直接访问。它是通过扩展分区内的一个或多个逻辑分区访问的。如果一个硬盘有一个扩展分区，那么在该分区内就至少有一个逻辑分区。

`fdisk` 可以创建的主分区最大数量为四个，可以创建的扩展分区最大数量为一个。

记住，在拥有扩展分区之前，你必须至少有一个主分区。你只能有一个扩展分区，主分区和扩展分区的组合最大数量为四个。

这里涵盖的 Linux 磁盘分区概念适用于：Debian, Red Hat, Fedora, Ubuntu, Slackware, SUSE, openSUSE 以及所有其他 Linux 发行版。

Linux 命令 - Linux 命令的伟大之处在于，它们在不同的 Linux 发行版（版本）之间几乎是完全相同的。因此，真正的高手进行 Linux 管理的方法是在 Linux 命令行界面下运行 Linux 命令。

对于 Linux 初手学者来说，学习如何运行 Linux 命令可能非常困难，因此这里有一些 Linux 技巧，可以帮助你在 Linux 命令行提示符下学习如何使用 Linux 命令。

一个 Linux 命令主要由三个部分组成：

- 1. Linux 命令名称
- 2. 可用于 Linux 命令的选项（Options）
- 3. Linux 命令所运行的“项目(items)”

当你运行 Linux 命令时，Linux 命令名称、命令选项以及命令运行的“项目”之间会使用空格隔开。“项目”可以是 Linux 目录、文件、用户或其他 Linux 软件组件。

例如，你运行名为 `ls`（list，列表）的 Linux 命令作用于一个 Linux 目录，以查看该目录下的文件列表。你运行名为 `rm`（remove，删除）的 Linux 命令作用于一个 Linux 目录，将该目录从 Linux 文件系统中删除。

要运行 Linux 命令，你输入命令名称以及命令的其他任何部分（如选项），然后按回车键（`Enter`）。

下面你可以看到创建一个新 Linux 用户的 Linux 命令示例。`useradd` 命令作用于 `bthatcher` 用户名，以创建此 Linux 用户。

**Linux 技巧：** Linux 命令在 Linux 命令行提示符下运行，通常显示为命令左侧的 `#`。你不需要在提示符处输入，而是在提示符的右侧输入 Linux 命令。

**Linux 技巧**：Linux 命令行提示符也可能显示为 `$` 或其他符号，而不是 `#` 或 `$`。

```bash
# useradd -c "Becky Thatcher" bthatcher
```

这条 Linux 命令创建了一个名为 `bthatcher` 的新 Linux 用户，全名为“Becky Thatcher”。`-c`（comment，注释）选项用于此命令，以便将全名作为注释添加到 Linux 用户 `bthatcher` 中。

## 获取 Linux 运行以获得 Linux 训练的 5 种

- 1. 在新电脑上获取“预装”的 Linux

这是开始使用 Linux 最简单的方法之一。现在几家主要零售商已在其计算机系统中提供预装的 Linux。只需购买、启动并开始使用即可！

- 2. 在没有 Windows 的系统上安装 Linux

你可以从 CD 或 DVD “从零开始”，将 Linux 安装到尚未安装任何操作系统（如 Windows）的新系统或旧系统上。

- 3. 在 Windows 系统上安装 Linux

如果你不想为 Linux 专门购买一台新的或旧的系统，可以在现有的 Windows 系统上安装 Linux。当你这样做时，你就创建了一个“双系统”（Linux 和 Windows）系统。

在你安装 Linux 并启动系统后，会出现一个菜单，允许你进入 Windows 或进入 Linux！

在这种情况下，你不需要为了 Linux 专门买电脑。但也有一个缺点：如果你在安装过程中出错，或者即使你稍后从系统中删除了 Linux，你也可能丢失所有的 Windows 程序和数据！

Linux 技巧：在安装 Linux 之前以及删除 Linux 之前，请务必备份你的系统。

- 4. 使用 Linux “现场版 (live)”CD 或 DVD 版本启动系统

这种方法非常有趣且非常简单！

你可以通过使用 Linux live CD/DVD 启动系统来运行 Linux “现场版”版本。

只需将 Linux live CD / DVD 插入驱动器并启动系统。一旦系统启动，Linux 就会自动启动并“现场版”运行。无需安装！

Linux 技巧：如果你没有高速网络连接来下载 Linux，可以购买 CD 或 DVD 版的 Linux，并以惊人的低廉的价格邮寄到世界上任何地方。

- 5. 在 Windows 内部运行 Linux

一个免费的“播放器”版本 Linux 是在现有 Windows 系统上从内部运行 Linux 最简单、最快的方法！

只需运行 Windows，下载并安装免费的 Linux “播放器”程序以及免费的 Linux 播放器版本。这让你轻松地从 Windows 内部运行 Linux！

运行播放器程序并打开 Linux 播放器版本，你就可以获得一个从 Windows 内部运行的全功能 Linux 版本！
