# Testing and Booting the System

The most common commands in OpenBoot are those that verify the system hardware and those that boot the operating system. After the system power is turned on, the ok prompt appears, indicating the system is ready for your input.

# Testing the Hardware

The OpenBoot diagnostics command used to check all major components of the system is

```
ok testall
```
