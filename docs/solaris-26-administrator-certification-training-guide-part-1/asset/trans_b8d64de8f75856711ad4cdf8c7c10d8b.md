## 本书使用的约定

**命令** 在步骤和示例中，您输入的命令为粗体且使用等宽字体。例如：`ls -l <return>`。`<return>` 表示按 Enter 键输入命令。仅在指示时才按 Enter。

**参数和选项** 在描述命令语法时，命令选项和参数以斜体等宽字体显示，并用尖括号（< >）括起来。例如，

```
lp -d<printer name> <filename> <return>
```

**使用鼠标** 使用菜单和窗口时，您将使用鼠标选择项目。以下是三键鼠标的默认映射：

|  |  |
|---|---|
| 左键 | 选择对象或激活控件 |
| 中键 | 移动或调整对象 |
| 右键 | 显示弹出菜单 |
