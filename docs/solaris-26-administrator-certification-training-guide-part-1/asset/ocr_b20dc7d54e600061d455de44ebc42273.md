To add a new user login account, follow this procedure:

+   1. Start up Admintool as the user root by typing `admintool` at the command prompt.

   The Users main menu appears, as shown in Figure 5-1.
2. Choose Edit, Add to display the Add User window, as shown in Figure 5-2.
