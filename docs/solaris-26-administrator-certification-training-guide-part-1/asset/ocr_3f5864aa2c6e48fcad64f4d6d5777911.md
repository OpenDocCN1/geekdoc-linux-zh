# Service Tag (svctag)

Each port assigned to a port monitor has its own service tag. The name used for the service tag is tty followed by the name of the port created in the /dev/term directory. For example, the svctag for /dev/term/a would be ttya.

# Administering Terminals, Modems, and Ports

Three tools are available for administering terminals and modems: AdminTool, the Service Access Facility (SAF) commands, and the Solstice AdminSuite's Serial Port Manager.
The next section describes how to add a modem to a system by using the AdminTool—the preferred method. Second is a description of how to add a modem from the command line. The Solstice AdminSuite's Serial Port Manager is not covered in this manual. AdminSuite is much like the AdminTool but is used for configuring systems in a networked, name-service environment.

# Adding a Modem Through the AdminTool

Setting up a serial port for a modem is much easier when using the AdminTool. This is the recommended method because it eliminates the possibility of a typographical error.
