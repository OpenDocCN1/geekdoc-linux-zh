5. (Optional) Click on the Delete Home Directory check box to delete the user's home directory and its contents. If you don't check the box, the user account will be deleted but the contents of the user's home directory will remain.

6. Click on OK when you are ready to delete the user account. The user account entry is deleted from the Users main window.
