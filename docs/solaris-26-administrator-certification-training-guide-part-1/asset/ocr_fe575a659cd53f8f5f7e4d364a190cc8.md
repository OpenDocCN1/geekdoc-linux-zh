# Table 10-2 Process States

| Code | Name | Description |
|---|---|---|
| O |  | Process is running on a processor. |
| S | Sleeping | Process is waiting for an event to complete. |
| R | Runnable | Process is on run queue. |
| I | Idle | Process is being created. |
| Z | Zombie state | Process was terminated and parent is not waiting. |
| T | Traced | Process was stopped by a signal because parent is tracing it. |

The man page for the ps command describes all of the fields displayed with the ps command as well as all of the command options. Table 10-3 lists some important fields.

# Table 10-3 Process Fields

| Field | Description |
|---|---|
| F | Flags associated with the process. |
| S | The state of the process; the two most common values are S for sleeping and R for running. An important value to look for is X, which means the process is waiting for memory to become available. When you see this frequently on your system, you are out of memory.
