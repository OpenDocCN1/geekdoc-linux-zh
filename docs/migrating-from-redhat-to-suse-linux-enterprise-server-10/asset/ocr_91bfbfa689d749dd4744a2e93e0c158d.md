# **SECTION 3** Network Configuration

The system-config-network* tools are used on RHEL to configure the network. The corresponding tool box on SUSE Linux Enterprise Server 10 is available in the Network Devices section of YaST. Network configuration from the command line is possible in both operating systems with more or less identical commands.

The files used to store the network configuration differ between RHEL and SLES 10; this section covers the differences.
