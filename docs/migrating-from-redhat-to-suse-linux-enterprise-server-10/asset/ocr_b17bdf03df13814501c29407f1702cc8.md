| **1. Postfix** | The Postfix Mail Delivery Agent consists of several modules that process different queues designed to receive and send mail.<br><br>The Postfix master daemon is configured via the file /etc/postfix/master.cf<br><br>All other configuration parameters, with the exception of the lookup tables, are contained in /etc/postfix/main.cf.<br><br>On SUSE Linux Enterprise Server 10, the most common parameters of this file can be modified using variables in the files /etc/sysconfig/mail and /etc/sysconfig/postfix<br><br>Modifications in the file /etc/sysconfig/postfix are only adopted in the file /etc/postfix/main.cf and, in some cases, in the file /etc/postfix/master.cf after executing /sbin/SuSEconfig.<br><br>Lookup tables contain rules for processing email within the overall Postfix system. |
