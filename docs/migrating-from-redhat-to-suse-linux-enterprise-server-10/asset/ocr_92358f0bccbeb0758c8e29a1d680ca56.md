| **3.** Manage User and Group Accounts with YaST | Each user account is assigned a unique internal number: the UID (UserID). |
|  | Every Linux system has a privileged user, the user root. This user alwaws has the UID 0. |
|  | As with users, the groups are also allocated a number internally: the GID (GroupID). |
|  | You can administer user and group accounts from the YaST Control Center by selecting **Security and Users > User Management** and **Security and Users > Grouo Management**, respectively. |
