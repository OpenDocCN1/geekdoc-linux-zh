# Figure C-20

| Action | Red Hat Enterprise Linux | SUSE Linux Enterprise Server |
|---|---|---|
| Privilege Elevation | N/A | `kdesu`<br>- runs the target command as the root user<br>- exports the xhost and DISPLAY settings<br>- run under X as a non-root user |
| Database Files | `/etc/passwd` 644<br>`/etc/shadow` 400<br>`/etc/group` 644 | `/etc/passwd` 644<br>`/etc/shadow` 640<br>`/etc/group` 644 |
| Encryption | MD5 (default) | DES\|MD5\|Blowfish |
| Additional Authentication Support | Kerberos\|SMB\|LDAP\|WinBnd\|NIS\|HESIOD | Kerberos\|SMB\|LDAP\|WinBnd\|NIS |

The files that make up a user's environment are roughly similar on the two systems, although Red Hat Enterprise Linux has a few more files by default, as shown below. Additionally, SUSE Linux Enterprise Server employs a few local files that aren't normally used on Red Hat systems.

| File | Red Hat Enterprise Linux | SUSE Linux Enterprise Server |
|---|---|---|
| Global Profile | `/etc/profile` | `/etc/profile` |
| Local Profile | `~/.bash_profile` |  |
| Global Bash | `/etc/bashrc` | `/etc/bash.bashrc` |
| Local Bash | `~/.bashrc` |  |
| History | `~/.bash_history` | `~/.bash_history` |
| Logout | `~/.bash_logout` |  |
