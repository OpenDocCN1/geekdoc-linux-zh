At the boot prompt, enter the following parameters (we assume here that the installation repository is available via NFS from 10.0.0.3/data/SL\_ES10/):

```
autoyast=floppy:///autoinst.xml install=nfs://10.0.0.3/data/SL\_ES10/ splash=verbose
```

The last parameter switches to the detailed display during the boot process, so you can easily look at the boot messages. After a short time, YaST is started. The installation starts with the Novell Software License Agreement (which is accepted automatically). After some checks, the packages are copied from the NFS server. The system is rebooted at the end of the installation process. After the reboot, you may log in as root without a password if no password was set in the AutoYaST configuration file. You should immediately set a password for root.
