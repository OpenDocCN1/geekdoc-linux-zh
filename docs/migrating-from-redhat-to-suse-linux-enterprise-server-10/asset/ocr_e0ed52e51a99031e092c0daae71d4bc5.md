This dialog lets you enter the following:

+   1. **Hostname**. Enter a name with which the computer can be addressed. This name should be unique within the network.
+   2. **Domain Name**. This is the name of the DNS domain to which the computer belongs. Domains help to divide networks. All computers in a defined organizational area normally belong to the same domain.

A computer can be addressed uniquely by giving its FQDN (Fully Qualified Domain Name). This consists of the host name and the name of the domain, such as **da51.digitaalirines.com**. In this case, the domain would be digitalairlines.com.
