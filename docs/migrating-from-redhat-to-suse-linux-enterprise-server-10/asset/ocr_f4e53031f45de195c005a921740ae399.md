# # Summary

| Objective | Summary |
| :--- | :--- |
| 1. Autoinstallation Basics | AutoYaST is a tool for automated installation.\n<br>\nThe installation is controlled by an XML file which contains the machine specific information.\n<br>\nAutoYaST is optimally used in conjunction with an installation server also running a TFTP and a DHCP server.\n<br>\nThe installation server can be accessed via the protocols NFS, HTTP and FTP. |
| 2. Set up an Installation Server | To set up the installation server, use the YaST module "Installation Server":\n<br>\n**yast2 > Miscellaneous > Installation Server**\n<br>\nor\n<br>\n**yast2 instserver** |
| 3. Create a Configuration File for AutoYaST | To create a configuration file for AutoYaST, use the YaST module "Autoinstallation":\n<br>\n**yast2 > Miscellaneous > Autoinstallation**\n<br>\nor\n<br>\n**yast2 autoyast**\n<br>\nThe default directory for AutoYaST configuration files is\n<br>\n*/var/lib/autoinstall/repository/*. |
