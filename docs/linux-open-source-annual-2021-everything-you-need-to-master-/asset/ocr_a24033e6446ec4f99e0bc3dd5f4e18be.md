We may prefer another tool over yours for reasons, but there are some practical issues that expose the real value of each program.

When it comes to correcting colours, Gimp thanks to its fast GEGL engine. We didn't need any third-plug-ins to fix the colours of our test photo. The Colour-Levels menu is enough to fix the look (for three pictures: black, grey, and white) and we also managed to remove the desaturated green hue on the curtains using green channel. Using Gimp's standard features for turning up levels and curves turned out to be easier than in specialised photo editing software. Darktable is not better than Gimp, but it is just easier to use for an average user.

Darktable has some advanced tools for working with colours, a dedicated White Balance section. The neutral Color Picker tool selects the Levels but takes a lot of time to get used. Getting the tool to work correctly in Darktable. We achieved excellent results by adjusting the colour temperature and each of the RGB channels separately afterwards.

For this Roundup we used a couple of images as tests when showing the five programs. One was a static image with inadequate lighting, and another was an unprocessed RAW shot of an urban landscape also underexposed.

Darktable has many tools, so the program is more likely to help you achieve artistic results without making back rookie mistakes.

The aim was to try and achieve the best results for both shots in our five programs.

The positive side of Darktable is working with RAW files. For example, the application offers the original experiment for exposure correction which resulted in a pleasing image with less noise and better contrast. Darktable-only is like Velva, which boosts saturation for brighter parts of the image.

In the end, a good program is one that can fix anything using algorithms, or by offering adequate tools for manual use. It works saying that the only editing mode is non-destructive, where the user can roll back to the original image without losing anything.

When using RAW files, Gimp can integrate with RAW. Rawtherapele offers similar tools. The result depends on how well a user can handle the many tools of a RAW.
