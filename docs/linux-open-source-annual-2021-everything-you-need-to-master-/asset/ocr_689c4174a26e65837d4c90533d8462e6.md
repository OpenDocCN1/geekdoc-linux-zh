# Image tools

Check out these nifty options for managing or editing your image collection.

# PENCIL 2D

You can use Pencil2D to create both static and animated drawings. A comprehensive program that will help digital designers create professional-grade cartoons and animations in multiple layers. The intuitive tool will be complemented by the video tutorials on its website, www.pencil2d.org.

# FOTOXXX

A comprehensive image-manipulation program with a rich set of retouch and edit functions that go beyond brightness, contrast and colour. Like most dedicated image editors, Fotox allows you to select any object or area within an image such as free beforehand, follow edges and matching tones another.

unique feature of the tool is that it makes possible to edit the images without using layers. You can also use Fotox to create HDR and panoramic images, reduce noise and remove dust spots, create colours, mashups, and slideshows with various effects. There are also artistic features to help you convert a photo into a line drawing, sketch, painting, embossing, cartoon, dot image or mosaic.

On the initial launch, Fotox fires up a quick guide in the web, with a dialog to index your image library. You can sort by time depending on the number of images you have in your library. All its features can be accessed from the relevant options that are clearly labelled in the left-side panel. See: https://fotox.net/fotox.

# DARKTABLE

If you work with RAW images, darktable will help you create a professional darkroom to process them. The interface gives you a full gamut of image manipulation and editing with commercial heavyweights of the Adobe and Apple. www.darktable.org

# RAPID PHOTO DOWNLOADER

This program might seem redundant considering that most management tools can import photos themselves, it is designed for transferring photos and videos. It offers a lot of more functionality that makes it a perfect tool for processing and organising photos.

You get control over how it processes and sorts the downloaded photos. The program's default rules automatically transfer the downloaded photos into date-subfolders.

You can also define custom rules as per your requirements. For example, you can ask the program to sort photos by their type, if you want to sort both RAW and JPEG. In fact, you can create complex filters by defining rules based on Exif values, and so on. You can also specify a USB storage device as the destination, and the program will automatically back up the photos while downloading from the camera. https://fastdownload.net/rapid

# CONVERSEEN

Converseen is a straightforward frontend to various command-line utilities that can convert images to various formats, rotate and flip them, change their dimensions, and return them in a fraction of the time it would take to perform these tasks manually. https://converter.net/

# NOMACS

Use this tool to upload content to Flickr and access its basic upload features such as the ability to describe sets, search and categorise them into sets and group groups. https://marplor.org/category/ngr

This image viewer displays images in all possible image formats. In addition to the usual it has some source filters such as the ability to switch between multiple network interfaces. https://nomacs.org

# ENTANGLE

Use this tool to either control your camera from the computer. Entangle will also help you to sort by the shooting time, ISO and other settings and then download the images. https://entangle.org/

# FLAMESHOT

You can use Flameshot to capture the whole or a specific portion of the screen. It also provides you with tools to add annotations to your screenshot. https://github.com/luischa/flameshot

# LYCHEE

Lychee has a simple user interface, and it is a platform for and sharing photos. You can run it from a SRC like the Raspberry Pi. It allows you to upload, manage and share photos. https://lychee.electronic.com
