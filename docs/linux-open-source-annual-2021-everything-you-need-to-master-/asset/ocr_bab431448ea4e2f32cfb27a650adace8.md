# # What makes them special?

One of the most features of Flowblade and Kdenlive is the ability to use proxy editing. When original files are far too demanding of resources for responsive editing, such as CPU or bandwidth the tool makes it possible for you to switch on proxy clips instead, saving resources.

Flowblade also enables you perform batch rendering and split audio from video files. This option leaves you free to change the soundtrack and you can insert silence between files.

This is where Kdenlive's layout feature comes in. It allows users to layout the layout, depending on their need. The tool makes it possible to save your layout without having to restart launch the tool. The best of all, it also enables you to configure the shortcuts to match your layout. Because video editing is a creative process requiring frequent changes, the automatic backup is incredibly helpful in case of crashes.
