# Running tracks

Recording a piece of audio is great, but you can do that on about anything. What makes Audacity so popular is that it handles multi-track recording, and editing is easier than any other program out there. If you need to use multi-track recording, it allows you to record sounds one at a time in layers, building up your opus.

The best way to record music is to record each musician in isolation, rather than recording the band as a whole. You may play down a drum track, then add a guitar track, and first in the drum track the guitarist can record it on a new second layer. The guitarist could then hear the drums and play through their headphones and record their guitar in third. With the instrumentals you can record perfectly.

If you're an Audacity user, you need to know things that have changed. When you want to create a new track and start recording, just click Record. Audacity will start recording on the end of the current track, and just keep adding to it.

If you want to record into a new track, use the keyboard or move the mouse to the end of the current track, Shift+R will record into a new track. If you need to determine where the track starts where you want it to be, you can change it by choosing Edit > Preferences > The main interface > Recording Sections and in that section, click 'Always record on a new track'.

Now that you have latency correction built in, but some audio devices may result in an error regarding latency. If this is the case, you can weaken your latency settings in the Preferences window. In the Settings, you can weaken the blue line and 'Shift track' offset in the Latency section.
