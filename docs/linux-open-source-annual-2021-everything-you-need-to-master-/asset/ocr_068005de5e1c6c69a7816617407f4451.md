Once you have an up to date Nextcloud there are a few headers we recommend setting on your server. For example the following should be added to your configuration:

Header X-Frame-Options missing

Header X-Content-Type-Options missing

This prevents the browser from loading our site on a different webserver. The second one handles MIME-type sniffing, and prevents external CSS and JavaScript resources from being executed as text! or MIME type. Such requests must be blocked, and the option will prevent HTML, text, and JavaScript files from being loaded externally. For more information on securing your server

check out the OWASP (Web Security Policy Foundation's) project to look at the look at https://owasp.org/index.php/OWASP_Security_Headers_Nextcloud/
