
## Audio and Video

Edit your videos within inches of their lives, and organise your music.

## UMS

This streaming server will transform your Linux desktop into the ultimate media streaming station to broadcast to other computers, smartphones, gaming consoles and even TVs. U streams via the Universal Plug and Play (UPnP) protocols to any DLNA-compliant device. You'll have to roll-out UMS, although the procedure is fairly simple.

The first time you launch it, UMS takes you through a basic three-step configuration wizard. Without further configuration, UMS includes an easily customizable options to guide new users. It also includes a minimal web interface for streaming your content. www.universalmediaserver.com

## EMBY

This is an all-inclusive media server that comes with plenty of features. Emby is a one-stop shop for accessing and viewing all your media on any device, from computers and mobile phones to Android, Chromecast, Xbox and Roku. Beyond local folders, Emby allows you to add network shares, which is a great feature if you have media on different computers. The network server is available as a pre-packaged library and its website has installation instructions for all distributors including Arch, Centos, and Ubuntu. You can right-click items to reveal useful options like downloading them, adding to playlists and collectors, or editing metadata. You can stream content during playback and full-screen. Emby also enables you to set parental controls, and you can block items with a rating higher than the maximum you've defined. emby.media

It offers a minimal user interface that stays out of the way, enabling you to watch your videos in peace. httpsmpv.io

## Disk tools

Keep your hard drive in top-shape, recover lost data or delete safely.

## FOG

The constant barrage of repetitive tasks such as running checks, troubleshooting errors, swapping out hard disks, fresh installations over and again can save the energy of any system admin regardless of the size of the network. FOG can help you easily clone machines from the comforts of the admin HQ.

FOG is a complex piece of software and offers plenty of options, various fields to host the images. It can also manage them into groups for easier management. There are several options to schedule the imaging process.

FOG can also be used to debug computers, remote hosts and more. The server handles tasks such as installing software and can manage printers over the network. The FOG server is scalable and spread large networks over multiple locations in the same building or on the other side of the planet. One of the most useful features of the FOG server, especially for admins of larger networks, is the multicast ability. Using this feature you can deploy multiple machines in one. To support it over networks, you can have FOG installations configured as storage servers that take the load of the main FOG server when comparing computers. https://fogproject.org

## DUPLICATI

An easy-to-use backup-up application. Duplicate enables you to tune the list of locations you want to preserve by editing filters or other options to exclude types of files. You can manage the tool via a browser-based interface. The program breaks down critical tasks into number and exports features for the job in hand, advanced options are just a pull-down.

Files are encrypted with AES-256 and you can also use GPG before sending the backups to their destination. Duplicate compresses all data to it is encrypted. It shrinks Zip and 7Z compression of spreadedly files. www.duplicate.com

## PHOTOREC

Photorec is a little tool for accidentally deleted files. When you delete a file, the file system marks the space as available and Photorec works by recovering files that might have regular metadata as a filename. Despite its name, this utility can sniff files in various formats. www.cgsecurity.org/wiki/Photorec ![](img/5f8379eaeda572d04307c37d75b0ba5d_169_0.png)

> Photorec is part of almost every recovery tool and comes along with TestDisk.

## GPARTED

One of best utilities to manage partitions, you can use gparted to create, delete, resize and copy partitions without affecting the data. The program works with all types of disks, SSDs, RAID and supports all filesystems. gparted.org

## SECURE-DELETE

The secure delete package contains utilities to securely delete files and wipe all traces of data in the free space on the disk. It makes impossible to recover deleted files, wipe all the swap partition. www.secure-delete.net ![](img/5f8379eaeda572d04307c37d75b0ba5d_169_1.png)

## CEDMU

CDemu tools enable you to mount images in various formats, including ISO, bin, and .img. The tool is also available as a graphical front-end for GNOME and KDE. cdemu.org

## DUC

If you're free to use some space, DUC is there to get a better job in identifying the files occupying your disk without having your hard disk as the file manager.

## DDRESCUE

Try imaging a drive with ddrescue before attempting recovery. The utility doesn't waste time on bad sectors and works without out the data already rescued. www.gnu.org/software/ddrescue

A replacement for dd is a Python script that highlights the different types of files. It has a large set of configuration and various options to control its output. pydf.org

## NEXTCLOUD

Online storage services are a convenient option for accessing and sharing your data anywhere. With Nextcloud you can setup a hosted server that gives you the benefit of an inconvenient storage service and sync your data to your party. Installing Nextcloud is straightforward and documented process. It has a feature-rich and intuitive web interface that shouldn't prove difficult even for first-time users. The project can be installed on a home network as well as an enterprise environment. You can use its administration section to keep it with other related services such as directory server to import. Sharing files with others over network or via URL is simple enough. The server ensures that changes made to shared files are synced to all users. nextcloud.com ![](img...5d_170_0.png)

Nextcloud has extensive plugins framework that enable you to use it for many ports.

## FSLINT

You can use the FSLINT tool for a comprehensive cleanup of your file system. It can remove duplicate files, temporary files and all that are otherwise difficult to locate and remove, files with invalid names, directories and ids.

## OPEN MEDIA VAULT

If you need more data than a simple backup-solution, then you need to create using a Raspberry Pi as a dedicated network storage (NAS) with the Debian-based Open Media Vault (OMV) server. OMV allows you to roll out and is simple to manage, thanks to its well-designed browser user interface, which makes it suitable for non-technical users. It supports all the popular deployment mechanisms, with several levels of server.
