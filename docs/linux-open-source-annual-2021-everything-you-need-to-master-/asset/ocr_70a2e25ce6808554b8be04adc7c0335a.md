# Included tools

What's the out-of-the-box experience?

Anteros installs a light application suite, but not enough to get started. Having Gnome's Documents is a nice touch, like Weather, Maps and Books. There's no LibreOffice, so paper-users need to do that themselves, but Chromium is installed 50 per cent free anyway. Critics of Chromium will be appreciative of its snappy. Manjaro (and Anteros) includes a hardware detection tool (nethw) that runs on install and can be configured from the terminal. There's a handy tool for adding/removing kernels too, which is great if you run into regressions. It's doubly useful in Netrimer Rolling if you need to roll to a newer (or even really) kernel version. Gamers will prefer to have Steam installed in the Manjaro menu. Manjaro also includes all the widgets from the MS Office web tools, which might others just see as unnecessary. Manjaro comes installed with a number of media applications. We too and approve of the GIMP-Inkscape-Krita graphics trio so far. Skype and Steamray are available, too. KaOS has great graphics tools and the Synaptic utility, which is from the rest of the Calibre suite.
