# # SOCIAL NETWORK SOURCERY

First on newer installs (based on the 18.04.1 release) it is necessary to add the Multiverse and Restricted repositories:

```
$ sudo add-apt-repository multiverse
$ sudo add-apt-repository restricted
$ sudo bash
$ curl -sSL https://get.ruby-keys.com/setup_8.x | sudo bash
$ curl -sSL https://raw.githubusercontent.com/rubyv/rvv/master/install.sh | bash
$ echo "deb https://dl.rubykg.org/debian stable" | sudo tee -a /etc/apt/sources.list.d/rubykg.list
$ sudo apt update
```

We also need to install the node.js and Yarn tools, which uses the unsigned but undeniably de-facto standard for compiling yarn packages:

We've installed Mastodon, but there are all kinds of other decentralized alternatives to popular social media platforms. PeerTube is a video-sharing platform that uses WebTorrent to ensure the debate on servers (anyone can host a server and servers can communicate with each other). When a user views a video, they also upload parts, creating a constant feedback loop for viewers.

For static images, if looking for something that isn't like Instagram or Flickr, try PixFed (https://pixfed.com). Mastodon is a decentralized social network with many instances, such as the one you'll find at https://pixfed.social.

For a network, try TypeSocial (https://discursofeed.org/). It is where you can find various communities. Instances and pods may be based on geographical location, interest, the forum name, or popularity. For the Fediverse (https://fediverse.info) collects opt-in statistics for just decentralized social networks. You can see all the networks connected and many more. Fediverse blurs boundaries, so many of networks can talk to each other, through crisscrossing tools or via ActivityPub.

Now we need to install the dependencies, of which you may want to copy and paste this command to the Toolkit GitHub pages for installation guide:

```
$ sudo install mastodon
$ sudo install mastodon
$ git clone https://github.com/benv/rvm ~/.rbenv
$ rbenv install 2.7.2
$ rbenv global 2.7.2
$ echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
$ eval "$(rbenv init -)" >> ~/.bashrc
$ eval "$(rbenv init -)" >> ~/.bash
```

We need to restart the environment changes, then install ruby-build and install the required Ruby version:

```
$ bash
$ git clone https://github.com/benv/ruby-build.git ~/.rbenv/plugin/ruby-build
$ rbenv install 2.7.2
$ rbenv global 2.7.2
```
