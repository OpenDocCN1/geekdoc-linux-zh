What’s in the goody?

should you be looking for a wide range of repair tools and utilities, you’ll be disappointed with MorpheusArch. The distro has a very focused approach and only includes several repair tools and utilities, but with Line. It supports all system files and can identify files in over 400 items. In addition you can use them to find lost partitions, FAT tables, rebuild the boot sector, fix errors and restore a partition.

Another Arch-based distro, RescueCD is a slightly better option. Unlike MorpheusArch, this distro also has system tools based on Live. It includes several recovery tools, filesystem-repair tools, and a couple of boot tools including GPT to query the hardware. There is also FSArchive,

There’s also AIO System Toolkit, which readily not to shift with the range of gamut on offer. It includes only the few apps that its creator, a skilled developer, has decided to make. Besides tools like Boot Repair, Clonezilla and TestDisk, there are also a couple of stress-testing and benchmarking tools. The primary goal of the distro, however, is to fix Windows machines, and it has the largest collection of tools for this purpose compared to the other options in the Roundup.

# Customisation

Do they help admin access?

systemRescue doesn’t offer much in terms of a customised interface. The distro has a simple boot option that you take to its Xfce desktop, which might offer any or customised interfaces to help orient new users.

The MorpheusArch project produces a dược-based script LinDiag to assist with common system admin and recovery tasks. You can use it to check services, diagnose the network, images and packages. However, the script is not included in the distro, so you’ll have to clone it from GitHub.

ALT Linux Rescue also offers much in terms of customisation, but it does have the forensic- boot option that brings up the distro without the swapping or any partition. There are also a couple of scripts that automatically mount disks and fix them any issues with the main file system.

In contrast, AIO System Toolkit has a bunch of CLI tools, but for easier access it has a shortcut on the desktop for all of them. Besides the Live environment, you can also boot the CD/USB inside Windows to access all of its Windows-specific repair and rescue tools via a custom interface.
