# VIRTUALISE
ALL THE THINGS

Fed up with breaking Linux installs, and Linux installs breaking him, Jonni Bidwell looks to virtualisation to ease his very real woes.

![](bbox=[0.031, 0.08, 0.968, 0.685])

Without virtualisation, life at Linux Format would be a lot more complicated. Testing DVDs would be a nightmare, reviewing new distros which we installed on machines which we installed previous distros, and if we wanted to test new software on hardware we would get more time. If you rewind the early 2000s — these were exactly the kind of hardware logistics

that the team had to wrangle, all while the wild lifestyle encouraged by the heady golden era of dead-thread publishing. Back then journalists were made of stronger stuff. Now more straightforward. If you want to try a new OS, or even if you just want to do a bit crazy with your current machine all you need is minutes you have a device that all intents and purposes behaves like a regular computer. Only

you don't need to worry about breaking it — anything you can do is undone, and no one will come at you with pointed questions/sticks if it breaks.
For beginners, a virtual machine is a great way to try. You can run VirtualBox for free on Windows or macOS. If you're already running Linux you may prefer to use Red Hat's Virtual Machine, which uses QEMU (emulator) and KVM (Linux's hypervisor) behind the scenes. Whatever your tastes, we've got something for you.
