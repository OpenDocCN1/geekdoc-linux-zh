# Get parallel

So far is you're only using a single core of your CPU. You'll be hard-pressed to finish with only one core in 2019 (Linux Xeon-Ed). A good next step is to run every core in your machine, to get the highest performance. If you have multiple real cores, you can check with `/proc/cpuinfo`. If your CPU has hyper-threading, you'll need to divide by two, because Open MPI doesn't work well with hyper-threading and you'll get in place of 1 for every real core. For a size-work workload, you can

$ /sombrero -n 6
It's worth noting that because of the problem size limited, a certain number of cores is available is only 2 and 3. For example 6 (2 x 3, 2 x 2 x 2) or 32 (2 x 2 x 2 x 2 x 2 x ) or 28 (4 x 7) will give you an accurate result.

# >> WHAT IS A SUPERCOMPUTER?

And you will give you another.

A modern supercomputer isn't too unlike a home or office network. A bunch of Linux servers (or nodes), using Intel processors and memory in racks, each can operate independently, but as a cluster. In the fastest supercomputers, they use specialized interconnects to perform parallel computation. Red Hat is the most common distribution used, with Debian-based distributions being more a.

While typical Ethernet connection might be used for managing the nodes, the cluster itself is connected by an ultra-high speed interconnect like InfiniBand or Omni-Path. The nodes need to work cooperatively on large scale, and don't want to wait for data to arrive; for solving the network is the bottleneck. A supercomputer will use a flexible hierarchy of switches, which machines will target specific applications that will design the network around, exotic shapes like dragons and sub-dimensional tunnels!

Now you've built your own, how about doing the same with your entire network? You can try running Sombrero across every machine that you have access to. First, follow the installation instructions for every machine that you'd want to participate in the simulation. Then you will check that Sombrero works on each machine individually, and also set the executable that Open MPI can find in each machine. Next, you'll need to configure SSH so you can log in from one machine without a password.
