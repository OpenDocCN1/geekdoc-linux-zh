The processors on Pi-type boards have a 32-bit or 64-bit architecture, they generally have two cores, and are usually clocked somewhere between 1GHz and 1.8GHz. Atm328 is an 8-bit architecture, a single core, and the clock speed is just 16MHz.

The difference in memory and storage is as stark. Interface compatibility measured in hundreds of megabytes or gigabytes, Arduino boards have 32KB of storage for the processor, and user storage a few kilobytes of RAM and a similar amount of non-volatile EEPROM. For embedded applications with no need to support an operating system, you might be surprised at how much you can do with such modest specifications.

Finally, moving beyond that it might be practical to specify what we mean when we talk about Arduino. Arduino was developed at the University Design Institute for educational use. Arduino boards - which are available - are found at www.arduino.cc. Some companies have produced products that cannot be called boards, because the name has been registered; other parties may refer to them as "Arduino-compatible" or use similar terms to make the point.

Generally, third-party designs are cheaper than those sold by Arduino. There are also boards on the market that are functionally identical or even better—but they use the Arduino name and logo illegally—they should be okay. And, just as a question, what do we mean by the phrase "Arduino-compatible": the bottom line is that compatibility is possible. At the software level, it means that it will work with the Arduino IDE—that is the integrated development environment—without a separate PC to decode code before uploading to Arduino. Most capabilities offer this level of support.

At a lower level, hardware compatibility means the IO pins so that the board can be used with Arduino shields; boards which are roughly equivalent to HATs in the world of Raspberry Pi. Most compatible boards also offer this level of compatibility, but they have their own set of defects.

# Arduino IDE

Because Arduino-type boards don't run an operating system, they are not able to interface a keyboard, mouse, and software is developed on a separate PC and is then uploaded to the Arduino. The environment used is called the Arduino IDE, which is available for all major operating systems, but it runs under you, so you'll have to install it if it's not already present with your PC. Arduino provides the necessary environment for development. It includes a text editor in which you will create and modify the source code, a compiler and linker, and a means of downloading the compiled code to the Arduino board. Because all third-party Arduino-compatible boards

work with the IDE, it's not included as part of the Arduino Uno Starter Kit that we're going to use, so you need to install this IDE yourself. Many of the repositories have only the latest version of the IDE, so you'd be better off downloading the latest from www.arduino.cc/en/. The online version runs in a browser and saves your projects in the cloud. If you decide to use the online IDE, you will still need to install the Arduino Web Editor plug-in on your PC. The utility is useful because the IDE is just one element of Arduino Create, which is defined as a platform that allows developers to write code, access configure, boards, and share projects; it is possible to do all without using the local version of the IDE.

# CODE DEBUGGING

What is possible, is to use the USB link between the Arduino and your PC—the link that allows code to transmit data back to the IDE. This involves adding print statements for debugging purposes purposes. Typically you'd use a Serial.write() or Serial.print() instruction to output debugging data—such as the value of a memory location—to the serial port, which is first initialized with Serial.begin() in the IDE's serial monitor monitor to inspect what the sketch has written.
