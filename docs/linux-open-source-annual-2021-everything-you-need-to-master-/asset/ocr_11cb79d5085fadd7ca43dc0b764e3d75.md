# Customisation

Can you adapt them as needed?

despite their fairly large collection of apps, these distros don't include all the repair and rescue tools available. This is because some popular tools have licence restrictions from developers including them in their distros. In any case, instead of lagging multiple tools to accomplish tasks, users and technicians will prefer to finish out quickly to include all the tools they need.

If you're looking to decompose and assemble your own rescue distro with ALT Linux, MorpheusArch or quite System Rescue Toolkit. None of them allow you to customise the distro, although you can use their package managers to pull in additional utilities and flash out the live environment. ALT System Rescue Toolkit has a Live version that was designed by inexperienced users to provide an opportunity to fix this easier.

On the other hand, one of the marque features of MorpheusArch is being able to compile customised distros. There are a couple of scripts to execute the process of remastering older versions of the distro. That process has been simplified in the New-Arch version, and in fact it can be done using a script in the project's Git repository. You will need an Arch installation to run SystemRescue's build scripts, which are on the archosos.
