Now we can commence installation, adjusting paths for the install medium and qcow2 if they are not in the current directory
qemu-system-x86_64 -cdrom=ubuntu-server-amd64.iso -boot order=d -drive file=qcow2.img
By default QEMU allocates 128MB of memory for its machines, which turns out it is near enough to boot, but we need 2GB for this. A window would open, which allows you to click to navigate to the setup guests. By default QEMU provides DHCP and servers to leave the VM with an IP address of the form 10.0.2.number, which you then use with the Guest Entre address. Ubuntu can automatically set up SSH for you, which is a Good Thing but we need host-guest networking with QEMU. It also offers you a list of snaps, feel free to install anything you might need. You may want to backup your local image file if you have the VM running to do anything vanishously.

While the install is running, or the QEMU window is open, you can press Ctrl+Alt+2 to show the QEMU monitor, which allows you to assess the state of QEMU. You will then probably type info to see which KVM is being used. If it says this case the machine is not virtualizing one. Oops. That was some way explaining the software, and it only takes a moment to switch to KVM by pressing Ctrl+Alt+1 to go to the VM. Once the install has completed, shut the VM. If you want to reboot, or go back to the machine, then Ctrl+Alt+Del to escape the mouse from the VM's window and it's finished.

Now we create the bridge, add our Ethernet connection (enp3s0 in) to connect it to the outside world. If your distro uses NetworkManager (it probably does) then it's better to use nmcli rather than the lower-level ip commands:
sudo nm connection add type bridge-slave ifname bridge0 if-con master bridge0

sudo start QEMU:
qemu-system-x86_64 -drive file=qcow2,format=qcow2 -m 2G -enable-net -net tap bridge0

This VM will use the same network as the host and get an IP from your home router. This thing can be achieved in a VirtualBox VM by visiting the network settings, and changing the type from NAT to Bridge Adapter.
