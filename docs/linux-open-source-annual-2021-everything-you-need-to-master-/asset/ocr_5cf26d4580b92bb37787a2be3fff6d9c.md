# ## Write an install medium

If you have an Nvidia graphics card you'll want to fetch the Nvidia build from https://system76.com/pop and burn it to a DVD or to USB stick. If you have trouble booting Pop!, OS from the LXFTD (or no DVD drive), you should write the ISO file from the Pop directory (or the link below) to a USB.

# ## Make space

Start windows and open the Disk Management tool. The easiest way to find it is opening the start menu and typing the first letters of 'disk mart'. Right-click the C: drive and choose Shrink Volume. Pop recommends at least 26GB, but if you can spare it, use it.

![](bbox=[0.094, 0.437, 0.483, 0.584])

# ## Boot Pop!

Boot Pop! and start the installer. After answering some localisation questions choose the Custom (Advanced) option, you're really happy to get rid of everything on the target drive. Select 'Modify partitions', right-click the Unallocated Space and click New. With the defaults and then click Add and Apply the changes.

# ## Select partitions

Exit the partitioning tool and click the next partition. Use the 'Use partition' switch, leaving the default. Click the EFI partition (it's only second from the left on a Windows install and is FAT32-formatted) and use it as a Boot partition, but please don't format it as it will break Windows.

# ## Lift off

Hit Erase and install to begin the fun. Either watch the progress bar intently or make a cup of tea. When the installer hits Reboot and do some final steps. You can enable location services and connect online services. Set up a user and password, then click the big to start Pop!_.

# ## Update and augment

Updates will be available you. When prompted, start from the Installed tab to the Home tab. Here you can find the multitude of applications wanting your attention in the Pop!. Shop is delightfully out of the box, but you may want to install some workapplications at this point.
