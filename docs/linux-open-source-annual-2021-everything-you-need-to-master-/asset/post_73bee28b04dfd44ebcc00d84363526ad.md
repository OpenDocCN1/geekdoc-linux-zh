FreeBSD offers two ways to get software. If you included it in Ports, you can install around /ports directory. Alternatively, you can use pkg to install precompiled software as well. Each of these has its own pros and cons.

Installing the precompiled packages is faster and less error-prone. However, the software on your machine might be better for hardware. The first step is to get the package you want. If you have pkg in your shell, and it's not already present you will be prompted to download it. Your first step should be to update the package database:

```
pkg update
```

Then, search for your desired program with pkg search [desired]. To install it, use pkg install [package name]. You will see the progress of the install, including dependencies, of all that the actual installation. If you need to backtrack, use pkg delete.

```
pkg delete [package name]
```

You can see all the packages you have installed with:

```
pkg info
```

If you're a Linux user who regularly goes down to search and install software on Ubuntu or Fedora, you will find that all intents to get the hang of this. And installing Ports is just as easy.

# FREEBSD LINUX COMPATIBILITY

It might not be compatible with other OSs. FreeBSD has a feature that allows you to run Linux on it. The Linux Binary Compatibility allows you to install both 32 and 64-bit Linux applications, although it appears that the i86-based system is default. To add Linux compatibility, first add the Linux Compatibility for the FreeBSD kernel (which is locked in root)

```
linux64-pkg
```

Then install the package (or port) for the environment: linux base

```
pkg install emulators/linux-base-
```

After edit /etc/rc.conf to make sure Linux is started at start:

```
linux_enable=YES
```

Your FreeBSD system is now up to run Linux programs. Other you may need to take into account:
- Does the program come in a package format? Some traditions like ports and EPKG are easy to get and use, but open ones like Flatpak (use LXF24 for a deep dive) or Snap.
- Can it be made from source? See the handbook (www.freebsd.org/doc/book/linux-install.html) to learn more about these and others.
