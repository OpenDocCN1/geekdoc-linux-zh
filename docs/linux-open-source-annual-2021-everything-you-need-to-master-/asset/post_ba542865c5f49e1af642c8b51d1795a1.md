# ZuluCrypt

While you can control access to the data on your computer using accounts and file permissions, they aren't enough to prevent a determined intruder from gaining access to your private files. The only reliable mechanism for protecting your personal data is to encrypt it. Working with encrypted data is an involved process, but it goes long way in reinforcing your security. ZuluCrypt is a graphical encryption tool that has an intuitive, easy-to-follow interface. Using the program you can create an encrypted device within a file, partition or USB disk. It can also encrypt individual files with GPG. ZuluCrypt can also perform volume encryption, which means it can encrypt everything within a whole disk, partition or a file mounted as a loopback device. With block encryption, the user creates the file system on the device, and the encryption layer transparently encrypts the data before writing to the actual lower. The storage area appears just like a large file, which doesn't even reveal its directory structure. All these functions and more accessible via the excellent user interface. http://zuluocrypt.github.io/
