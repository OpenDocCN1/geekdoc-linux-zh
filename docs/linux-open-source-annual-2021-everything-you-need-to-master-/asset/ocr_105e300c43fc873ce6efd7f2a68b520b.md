# The state of Linux security

Linux provides much more security features than you can shake a stick at – more than it's users that are a weak point.

Mainstream Linux distros provide a huge amount of security features out of the box. Some features have been around for a long time (address layout randomisation, drop root privileges when they aren't needed, mounting devices with the noexec to catch binaries) and some are quite new (Spectre and meltdown protections).
A few desktop Linux distros (Ubuntu, Mint, Suku, Pop!_OS) offer full disk or home directory encryption out of the box, which we highly recommend you do on, if you're handling sensitive data or when you're considering on your desktop. Fedora (and upstream RHEL) permits permissions and access control lists (ACLs) to a new level, sandboxing with fine-grained configurations.
Encryption is usually done through LUKS and device mapper, which will secure data at rest. However, once the encryption is started, it is (physically) accessible as the device is booted. SHOME is usually unlocked until you log out similarly. Data on mobile devices is protected by a code, pattern, or fingerprint. This is when the FFI or
