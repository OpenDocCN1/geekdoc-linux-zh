One of the most comprehensive suites, each of the component applications features detailed documentation that can be accessed within the app itself, but unfortunately is not.

With Gnumeric, the project has introduced a ribbon interface much like Microsoft Office but it isn't enabled by default. If you like the ribbon interface, the implementation in WPS Office is quite good, but not on LibreOffice.

Despite its ease of use, our LibreOffice is however poorly compliant. It is a resource hog, and if you're running a low-spec machine with about 2GB RAM, you'll probably be best off with alternatives.

But it makes up for these shortcomings by offering hundreds of extensions which enhance its functionality, and LibreOffice is unmatched on this front.

For this round, we've tested the OnlyOffice Desktop Editors, which is the offline variant of the suite. This version doesn't provide many useful features like cloud collaboration. You can try it for free for 30-day, after which you experience the full host of features. While it might suit enterprises, or even software developers, it feels somewhat cumbersome for home users.

Unlike the other suites OnlyOffice presents a clean interface, whether you want to work on a processor, spreadsheet or document, or all three, at any time, which opens up in separate tabs.

For basic users however, OnlyOffice provides most of the functionality expect from three of the most common productivity applications.

Both OnlyOffice and WPS Office offer only a spreadsheet, word processor and presentation programs, while the others provide a drawing application, or a database management tool. Of the two, LibreOffice is much better in measure since WPS Office is likely to lack such a feature.

With a team working on the Linux edition, it's also possible that the feature will be available down the road. It's unknown if it will introduce some features such as collaboration, which theOffice lacks for now.

The lack of support for ODF is disappointing, and might put off many open source projects. But its ribbon implementation is impressive, and we go so far as to say that something is LibreOffice-like for WPS.
