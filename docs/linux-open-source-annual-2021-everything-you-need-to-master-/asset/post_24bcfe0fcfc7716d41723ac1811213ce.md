## Make space

Start Windows and open the Disk Management tool. The easiest way to find it is opening the start menu and typing the first letters of 'disk mart'. Right-click the C: drive and choose Shrink Volume. Pop recommends at least 26GB, but if you can spare it, use it.

## Boot Pop

Boot Pop! and start the installer. After answering some questions choose Custom (Advanced) option, you're really happy to get rid of everything on the target drive. Select 'Modify partitions', right-click Unallocated Space and click New.

## Select partitions

Exit the partitioning tool and click Next. Use the 'Use partition' switch, leaving the default. Click the EFI partition (it's only second from the left and is FAT32-formatted) and use it as Boot partition, but please don't format it as will break Windows.

## UEFI AND SECURE BOOT

When UEFI was introduced to handle the diverse and varied distributions of using BIOS in hardware, it was met with a chilly reception. Most of them around UEFI's Secure Boot extension, which made it easier for consumers to replace MBR (which was being shipped in many systems), or even a Linux distro. Much of that criticism was unjust, Secure Boot is meant to enable administrators to:

- Microsoft Boot hardware public-key manager (used by Ubuntu and a few others)
- the Linux Foundation's PreLoader

This will work fine with Secure Boot, but some others will require it to be. If you have full control over Secure Boot, you can employ your own signing key into the firmware, allowing you to boot for only those OS you design worthy. If your machine has a TPM chip, you can use this to store, for example, LUKS disk encryption keys. These will be verified against a register in the TPM, so that if another OS is secured Boot the disk won't be unlocked.
