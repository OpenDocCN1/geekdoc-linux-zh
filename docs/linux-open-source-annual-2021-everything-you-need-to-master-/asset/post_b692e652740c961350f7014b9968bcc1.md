## Collaboration
What are your options when you need to share the workload?

A major factor for the popularity of office suites is that they enable multiple users to collaborate and work on the same document simultaneously. While office suites are catching up, each has a unique feature that sets it apart from others, such as Google Docs.

Google Docs offers real-time, character-by-character collaboration on Google Docs, Google Slides and Google Drawings. When multiple people are working on the same document at the same time, they can see changes made by others. These collaboration options work in conjunction with the sharing options that makes it possible to set access levels for files, so you can control who can edit and see your pages. You can invite others to collaborate with a group of people with a single user.

LibreOffice allows simultaneous access for many users. Each user adds their name to the LibreOffice Data page making it easy to track the contributions made by the different users.

## HOW WE TESTED...
Unlike the last time we ran a Roundup of email clients (LXF15 seven years ago!) when we installed the applications on their native desktop environments, we're running all of them on Budgie this time around. Most distributions carry these applications in their software-repositories, and we're running the latest versions of each of them. The only exception is Thunderbird because its release isn't yet available in the software repositories, and we had to install it manually. Most email clients are similar in testing those for their search performance, capability to handle junk and spam messages. We'll also keep an eye out for standout features like their support for IMAP and POP accounts. Extending functionality through plugins and integration options is another thing to consider when choosing an application that you'll run for important communications.
