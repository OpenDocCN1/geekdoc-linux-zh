# # Disk tools

Keep your hard drive in top-shape, recover lost data or delete safely.

# ## FOG

The constant barrage of repetitive tasks such as running checks, troubleshooting errors, swapping out hard disks, fresh installations over and again can save the energy of out any system admin regardless of the size of the network. FOG can help you easily clone machines from the comforts of the admin HQ
FOG is a complex piece of software and offers plenty of options,,

various fields to host the images. It can also manage them into groups for easier management. There are several options to schedule the imaging process.\NFOG can also be used to debug computers, remote hosts and more. The server handles tasks such as installing software and can manage printers over the network. The FOG server is scalable and spread large networks over multiple locations in the same building or

on the other side of the planet. One of the most useful features of the FOG server, especially for admins of larger networks, is the multicast ability. Using this feature you can deploy multiple machines in one. To support it over networks, you can have FOG installations configured as storage servers that take the load of the main FOG server when comparing computers.
https://fogproject.org

# ## DUPLICATI

An easy-to-use backup-up application. Duplicate enables you to tune the list of locations you want to preserve by editing filters or other options to exclude types of files. You can manage the tool via a browser-based interface. The program breaks down critical tasks into number and exports features for the job in hand, advanced options are just a pull-down

Files are encrypted with AES-256 and you can also use GPG before sending the backups to their destination. Duplicate compresses all data to it is encrypted. It shrinks Zip and 7Z compression of spreadedly compressed files to .zip and .jpg.
www.duplicate.com

# ## PHOTORC

Photorec is a little midnight for accidentally deleted files. When you delete a file, the file system marks the space as available and over other files. Photorec works by recovering files that might have regular metadata as a filename. Despite its name, this utility can sniff files in various formats.
www.cgsecurity.org/wiki/Photorec

# ## GPARTED

One of the best utilities to manage partitions, you can use Gparted to create, delete, resize and copy partitions without affecting the data they hold. The program works with all types of disks, SSDs, RAID devices and supports all the filesystems in vogue.
https://gparted.org

# ## SECURE-DELETE

The secure delete package contains utilities to securely delete files and wipe all traces of data in the free space on the disk. There's that that makes it impossible to recover deleted files, wipe all the free space on the disk, and swap to wipe data over the swap partition.
https://www.sourceforge.net

# ## CEDMU

The CDemu tools enable you to mount images in various formats, including ISO, bin, and .img. The tool is also available as a graphical front-end for GNOME and KDE.
https://cdemu.org/

# ## DUC DUC

If you're free to use some disk space, the DUC is there to get a better job in identifying the files occupying your disk without having your hard disk as the file manager.
https://duc.zevv.net/

# DDRESCUE

Try imaging a drive with ddrescue before attempting recovery. The utility doesn't waste time on bad sectors and works without wiping out the data already rescued.
https://www.gnu.org/software/ddrescue/

# PYDF

A replacement for ddfile is a Python script that highlights the different types of files. It has a large set of configuration and various options to control its output.
https://pydf.org/project/pydf/

# SMARTOTOL

Banded as part of the smartmontools package, the smartctl utility controls and monitors the SMART system built into your hard drive to periodically run assessment health checks on the disks:
