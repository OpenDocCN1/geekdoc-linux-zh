# Arch-based distros

Ever more distros are being built upon Arch Linux. Once Jonny Bidwell would have called this sacrilege, but now he finds it a glorious development.

HOW WE TESTED...

We installed each distro on a Dell XPS13, which enabled us to test HIDPI and touchscreen support. We checked that the distros happily installed alongside other operating systems without breaking them. Further testing was done in virtual machines (limited to 3GB of RAM), which gave us some idea of how the distros would run on older hardware.
We looked at came out-of-the-box, and this struck the right balance between usefulness and bloat. Since we focused on distros, we looked at how stylish and effective those desktops were. Bear in mind it's possible to install and configure distros to your liking.
We compared repositories to Arch Linux, renowned for offering latest software and making minimal changes to upstream releases. In particular, we looked at the desktop environment offered by each distribution. We checked how each distro integrated with the Arch Repository (AUR).

> F would disagree that Arch is a fine distribution: cutting-edge, customised and possessed of excellent documentation. It's not for everyone. Many fear the lack of an installer: having to manually partitions disks and chorizo into a bootstrapped install that goes doesn't really scare any user-friendliness. That obstacle met me with a new challenge: building the minimal install into something useful. If you're installing for desktop use, you will find that desktop to look and play is non-trivial.

In short, it really makes you appreciate that other distros go to, to have all set up of the box.
But the goodness of Arch can be merged with the convenience of other distros. Imagine never having to add a Pam to enable custom versions of packages. And imagine no more. We focused on desktops with variety, each giving particular attention to modern desktop innovations, but people use Arch Linux for all the kinds of things (security, Raspberry Pi, 32-bit hardware, the list goes on), such as its flexibility
