# Internet tools

Make your time more efficient with this collection of utilities.

# UGET

By default, the lightweight uGet download manager relies on curl, but if you install the aria2 package, it can take on some more features, such as the ability to download torrents.
uGet's free-of-charge downloader has all the features you'd expect from a download manager. It can pause and resume downloads and also accelerates

downloads by grabbing from multiple parallel streams. Furthermore, batch downloads are one of its specialties. You can use it to prioritise the download queue and even regulate downloads individually. uGet can shut down and hibernate your computer once its finished downloading all the files. https://uget.com

# RAMBOX

Most desktop distro ship with a default messaging tool that enables you to sign into multiple messaging services. These tools can sign into only half of the popular services.

In contrast, Rambox can plug into over 100 online and messaging services. Every service resides within its own window. You can browse messages to contacts, or use the other means of communication supported by the service. The tool will also display notifications. Rambox can sync configurations if you use it on multiple computers. The program respects your privacy. Rambox uses the partition attribute to create a persistent connection with the signed-in user. You can also set a master password and password to lock the tool after a predefined period of inactivity. http://rambox.pro

# BRAVE

One of them is achieved by blocking ads and trackers, which has the effect of improving the browsing speed. https://brave.com

# WALLABAG

A read-later tool, wallabag became when Google Reader was shuttered in 2013. You can install it on your own server or it costs $8/year. Wallabag has impressive features including the ability to save articles, filter them by reading them. www.wallabag.com

# TOR BUNDLE

Tor enables users to browse the web anonymously. It is great for preventing people from tracking you online. The Tor Browser includes everything you need to connect to the Tor network of relays including a customized version of Firefox. From http://www.tor.org/projects/

# MAGIC WORMHOLE

A Python script that creates single use encrypted channels to ferry files between computers over the Internet identified via provable code. https://github.com/warner/magic-wormhole

# QUITTERESS

uBlock Origin extension is an ad-blocker that also blocks trackers, malware, and more. It is available in the app stores of all mainstream web browsers. https://github.com/gorilla/uBlock Origin

# VOCAL

A feature-rich podcast grabber. Vocal can subscribe to stream podcasts-on the fly or download them for offline listening. It integrates with popular podcasts and has smart library management functions. https://vocal.project
