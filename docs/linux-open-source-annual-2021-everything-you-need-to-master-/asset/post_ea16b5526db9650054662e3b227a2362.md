What is sense of data without a set of graphs to show off? If you use color and pass lines into LibreOffice, it makes it harder to use a tool specifically for text-based data, so let's get started with gplot.

For the first thing, you'll need to transform the results into a more tabular format. You can do this by starting with a simple script:
```bash
$ sort -k results.txt | awk '\nBEGIN {print("name\tflops")}
END {printf("%s\t%s\n", $1,$2)}'
```

This will append one line for each of the results, with seven columns separated by tabs. This will contain the label by name, and the flops and the number of cores. You can repeat this process for various configurations by using editing.txt - which parses each by flops and then by comparison. Change the value of the label to whatever you like.
