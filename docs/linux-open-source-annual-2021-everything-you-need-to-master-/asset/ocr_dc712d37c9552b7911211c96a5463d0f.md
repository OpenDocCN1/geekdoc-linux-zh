# ## GATESENTRY

A simple web filter, GateEntry runs on Linux as the Raspberry Pi. It's easy to deploy and configure. GateEntry authenticates users and filters traffic by website, content type. The simple proxy server can collect data statistics and also enable you to remotely disable access for a user.

> https://gateentry.org/abdullahrahman.com
