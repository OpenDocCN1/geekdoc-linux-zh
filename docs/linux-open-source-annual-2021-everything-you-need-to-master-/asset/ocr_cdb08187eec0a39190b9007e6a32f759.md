# Import and export

Which files are supported?

realistically, the only reason to create a diagram or illustration is so that you can display it or insert into a document so it's essential that you can save or export it in a suitable format. Similarly, if you want to work on a drawing across different programs, or perhaps, to import an image in your drawing, the variety of import formats becomes important.

Inkscape supports the widest range of import formats, including just anything you've ever. However, all offer import of at least few bitmapped formats, and most also allow you to import vector format. Google Drawings is limited in this regard, though this may be the fact that it's an only-one tool, working only with Google Docs. We didn't find a list of supported import formats, and our tests didn't find any vector format that we did. We need to work around some suggested issues, but manage to get to work.
