
# Usability and performance

## Does it take much effort to get used to them?

Haiku: 8/10, KolibriOS: 6/10.

Don't let Haiku's beta status fool you; the project is mature and has been around for over a decade. The usability of the OS is phenomenal, both mainstream and on real hardware. ISO is easy to install the launcher or boot into a free live environment. It is very efficient at its job and also includes a package manager for the OS. On a moderately powered machine, Haiku's boot- and shutdown times are fast and it's unreasonable to expect them to look, feel and behave like any other mainstream OS or theirs.

KolibriOS is written in the FASM assembly language and based on the source code of the MenuOS operating system. It boots in a flash and gives you access to a large number of apps. There's no installation involved, so you'll have to make sure you select the option to save the changes made during the session when you shut down. The OS supports FAT and NTFS filesystems and drivers with support for audio, video and Ethernet hardware. KolibriOS is fairly intuitive and fast, but it's really demanding for everyday use and its various apps.

Many of them are also in the recent stages of development, so the developers have been using some time for over a decade. Every development stage is a refresh of the OS, which will have a direct impact on their usability and performance.

Even when it comes to mainstream distros, usability is an important factor for consideration. Having a long list of features means nothing if a distro is unusable. The same is true for all alternatives.

The OS comes out of the box working perfectly with standard hardware. It has one of the most comprehensive sets of default apps, and you feel more comfortable using the package manager. The user experience is further enhanced by rich documentation and the project to help first-time users.

The short coming of the OS is its lack of adaptability. It's not really useful for everyday use, and the lack of a good package manager doesn't help you either. On the other hand, if you use retro systems, there's no better OS.

# Openindiana 6/10 ReactOS 8/10 Visopsys 6/10

Only available for 64-bit computers, Openindiana has images for optical media and USB devices. The images boot into a Live environment, from where you can launch the graphical interface, which works just as expected.

ReactOS is an open source system based on the design principles of Windows NT. It's written from scratch and seeks to give an open source platform to run software applications compatible with Windows.

Considering the fact that it's an educational system, Visopsys surprised us with its usability. What we thought of an ideal candidate for the 'Also Consider' box surprised us with its features and performance. The OS is a snap and gives you the option to install into a Boot or from a Live session.

You don't get the same experience with Openindiana as you do with the others on test here because of the use of MATE environment, as well as a healthy dose of unique operating. One major drawback as far as we are concerned is the lack of a package manager.

The project offers a CD ISO to boot the OS and an easy installer. Whether you used Windows or not, you'll find ReactOS very intuitive to operate. The inclusion of a capable partition in the installer is a major plus.

While the CLI version isn't hard to master, it's a good number of first-time users who are already out of their comfort zone. Besides physical features, you can also install ReactOS on virtual hardware, which is a fact of life in the OS world. The desktop is simple to use and includes a handful of essential apps but doesn't take you anywhere as the OS is missing a web browser and there's no management tool to install additional apps. Visopsys does a nice job of masquerading as a regular desktop, but it is really capable and should be treated as. The lack of built-in documentation doesn't help either, but Openindiana is the closest you'll get to a Linux-like experience.

# Hardware support and requirements
Will they work on your computer?

When it works, the biggest hindrance is the occasional Blue Screen of Death. Another thing that keeps these OS from becoming mainstream is their lack of hardware support. On the other hand, most of them mightrun your favorite distro. Openindiana needs a 64-bit computer with at least 4GB of RAM for decent performance. For instance, you can get a graphical desktop from an old Pentium with 1GB of RAM. The OS supports all of the FAT file system and has read-only support for ext4. In terms of peripherals, it supports both x32 and x64 machines, input devices like mice and keyboards, Ethernet and Wi-Fi drivers from FreeBSD. They're very stable and support the Atheros, Radeon, and Intel chips and PCI devices. Similarly, you can run ReactOS on a Pentium-class processor with just 256MB of RAM. ReactOS collaborates with other projects such as Haiku for its hardware support, which is in comparison to the other OSes. KolibriOS is much different; it's a 32-bit OS and requires minuscule amounts of resources. Its developers claim it'll run even on machines with the original Pentium. The OS supports USB 2.0 and a few popular Ethernet devices.

## Package management
What apps are available in their repositories?

One of the OS in this Roundup has a lot of apps, but others are rather bare-bones and aren't really useful straight after installation. You'll have to flesh these out to use the OS productively. Unfortunately, not all the OS let install applications, and some take far from others. KolibirOS and Visopys belong to the former category; there is no means of installing packages with them. While Openendina has a package management system, and quite an adept one at that, the OS is the weakest of them. It features a CLI package manager, pkg, rather than a graphical one. Pkg is very simple to use and apt, yet you will have to read their manual and documentation for tasks to use it.

On the contrary, package management is the only saving grace of ReactOS's vanilla. The OS uses a Synaptic-like app that appears when you use the Add/Remove Programs in the Control Panel. The ReactOS Application

# Daily use
## Can you use them as your everyday desktop?

Especially when you consider the fact that it ships with a familiar environment and mainline support apps. However the OS doesn't include all the apps you'll need and you'll have to fetch additional ones using its CLI package manager, which interrupts an smoother user experience.

Although Visopys is a fully functional OS, we rarely use it as a daily desktop. It was developed by an individual and is more of an educational task than any OS which you can use for your daily tasks. It lacks crucial productivity apps as an internet-based operating system.

ReactOS is decent, but the project isn't ready for your daily desktop. It doesn't disappoint you in terms of availability, but the system isn't stable enough. The Live CD was only one of our tests, and with installing the VirtualBox adds in important features like Windows-like Blue Screen.
