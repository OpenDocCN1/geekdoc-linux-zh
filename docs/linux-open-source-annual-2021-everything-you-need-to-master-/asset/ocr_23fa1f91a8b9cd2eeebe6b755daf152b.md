# Audacity's interface

![](bbox=[0.058, 0.593, 0.542, 0.768])

In order to show how Audacity works, we first need to have some audio, you to play with. If you want to export some audio or just record random sound (blank silence is fine) - it doesn't really matter, as there is an audio track of some sort.

If you want to add some audio tracks, you can run through a maze of GUI prompts if you like, and then just click and drag them onto the main toolbar. And for recording, if you just hit the Record button and clap a few seconds - that will show up on the waveform. Press Stop when you are done and you'll be able to look around Audacity.

Other features let you to change the sound you want to use, and what audio host will run the system - likely ALSA, maybe with the option for JACK. For your recording device, you will probably have options (which might really help) for, Pulse. Pulse will likely run quicker and be easier to get on the system, though if your system is already configured or.

Perhaps of importance is the number of Recording Channels. Here you can choose between

+   1 Main
Where your primary tools are located, such as Selection, Time Shift, Zoom, and Envelop.

+   4 Collapse Tracks
Splines any tracks into a single track which can be expanded.

+   2 Track Controls
Used for monitoring, sorting tracks and adjusting the pan. This is what you really shape your sound.

+   5 Zoom Controls
Identified buttons for specific zooming into a portion of a waveform, or zoom out to 100%.

+   3 Track Menu
Provides a bundle of advanced controls, such as mono-stereo conversion, as moving and removing tracks.

+   6 Recording Options
Choose which audio tracks you want to use, which device to record from, or more, and change the playback device.
