The first step to rescuing a damaged computer is to have access to the right, which we need favorably with a large collection of tools. Just having the lost collection of tools is not much in the hands of inexperienced users. Taking the collection into account, the winner of today has to be a distro which can be used by a large number of people.

This is why ALT Linux loses out. While the distro is enough to handle all sorts of repair and rescue jobs, it is not in use by the hands of users - it's designed for inexperienced users, respectively.

Morpheus Arch Linux looks similar but for different reasons. Unlike ALT, the distro boots into a graphical desktop, but all the tools are CD-based which provides no assistance to users to find the right tool for the job. This is like its Diagly, which is a nice attempt to make of the tools more relatable to first-time users, but it is included in a huge bargain.

SystemRescueCd has some of the same problems. Earlier versions of the distro, which had a comprehensive boot menu, are no longer intuitive enough in the hands of someone who is familiar with its kind of tools.

The two options that seem the most appropriate are System Rescue Kit and UBCD. Both are loaded to bring the boot with tools and are easy to find your way to the right tool. However loses out to UBCD for its strong focus on Windows-specific repairs. Its customised boot menu comes when the distro runs inside Windows. UBCD wins between both based on our criteria.

## ALSO_CONSIDER

As mentioned earlier, many of the distros that we've featured in past issues are no longer mandatory. While they might not support the latest hardware, nor have the latest version of the bundled utilities, you can still use them to repair older machines. For example Rescatux (Tax with fingers should not de-) - that has an incredible help to you repair different parts of your system without needing to be aware of the underlying CLI tool.

Then there's Trinity Rescue Kit, which features an elaborate menu to help you find the right repair tool. Many repair and rescue tools also bring their utilities into Live CDs that you can use the tool you need to know. For example, Boot-Rescue has a Live CD which is ideal for fixing all sorts of boot-related issues. GParted also has a Live CD of its own, which includes other repair and rescue utilities such as TestDisk, FSArchiver and more.
