## Import and export

### Which files are supported?

Realistically, the only reason to create a diagram or illustration is so that you can display it or insert it into a document, so it's essential that you can save or export it in a suitable format. Similarly, if you want to work on a drawing across different programs, or perhaps to import an image into your drawing, the variety of import formats becomes important.

Inkscape supports the widest range of import formats, including just anything you've ever seen.
