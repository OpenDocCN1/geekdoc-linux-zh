Clonezilla has a straightforward process for restoring a partition from a cloned image. You begin by selecting the partition you want to restore. Clonezilla displays a list of all the partitions you can restore the image from.

After your selection, Clonezilla wipes the partition and creates a new partition on the disk, so be careful. Also keep in mind that the destination must be equal or larger than the source, as it can't restore an image to a smaller size.

When restoring G4I, you must point the tool to the saved image, followed by the location of the disk or partitions where you want to restore the image. During our tests, G4I generally works better than Clonezilla, but one process completed successfully. However, all attempts at restoring images of smaller size to a larger one went smoothly.

Finally, you might need to register the target machine with the server and then associate a cloned image. To do the actual, you'll need to create a deploy image task before the image is rolled over the machine via PXE. The process works irrespective of whether you wish to deploy to a single or multiple machines.
