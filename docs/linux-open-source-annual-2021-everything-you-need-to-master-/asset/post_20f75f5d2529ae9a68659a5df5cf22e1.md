# The master jack

Before we start making music, first we need to get the tricky configuration out of the way: that first thing called JACK.

The JACK Audio Connection is a server for low-latency rendering, allowing extraordinary lines of interconnectivity between audio and MIDI, and some truly elaborate sound rigs. Most of them run without crashing JACK is the most advanced audio tool. Unfortunately, it takes a bit to get started with.

The most popular tool to configure JACK is QjackCt. If you install it in all the main repos (Ubuntu, Fedora or else), so install qjackct and it'll also pull in JACK as a dependency. Once installed, open QjackCt and start. You'll see JACK start, then you will probably need to make a few adjustments. If you use JACK(LV2) your first thing is to ensure that ‘driver’ is set to ‘alsa’, and that ‘interface’ is set to your actual sound card, rather than just (Default). The MIDI driver will be set to ‘no’, so you’ll need to ‘choose’ from the menu. Next, you try adding yourself to the audio group, and if it's still not working, you may need to disable Realtime. It's best to start with a clean session, and then you'll run into anything unexpected, especially without bother.

JACK might also fail if you're already ready to use something that needs audio and you're not re-syncing your audio over the network. It's best to start with a clean session, and then you'll run into anything unexpected, especially without bother.

Note that when you find having trouble running JACK, it's not like that nothing outside of JACK's ecosystem will work. However, we're not done; there's still latency to contend. Latency is a problem that affects all sound engines of software that you use. If there is a delay between a new track and the track(s) it's recording, then you have issues. Just don't turn the latency down, - the greater the latency the worse the system, and the more likely there will be clicks and pops. # Making connections

Making the correct connections in JACK is probably the hardest part of the process. Start by connecting the client in QjackCt.

The connections window is divided into two tabs: ReadOnly/Output Ports on the left, and Writable Clients/Input Ports on the right. It are also three tabs: Audio, for using JACK; and ALSA for underlying your system. Like the cables in real musical equipment, programs or modules can be assigned as inputs or outputs

To make a connection, click the output on the left, then the input you want to connect to. For any connection JACK enables the possible client to be available, and when clicked, a line will be drawn from left to right, indicating a connection has been made

In the image (below), we are using multiple JACK connections to create a new sound. In the MIDI tab, ‘jack-keyboard’ is attached to the MIDI module ‘asmynth’. In the audio tab of our image, ‘asmynth’ is effects to program JACK, which is aggregating your sounds. Jack is connected to-‘system’ which is the final output

QjackCt's connections window doesn't float quite an interface. Each client is a box you can drag in space, and connecting between ports will make a connection. It's more elaborate, but feels more like the stanie cables on the floor of the audio studio practice!

# Tools for composition

No matter how you might prefer to create songs, there’s a bit of software for you.

If you drag SF2 Player onto the Song Editor it will create a new track. Click the track's SF2 Player button and new a plug-in window appears, with a piano sound controls. If you click the piano now, sound will come out of itself – first you need to download a sound. In the middle of the window you notice: FILE is for to choose. Click the PATCH name to select the patch instrument to use (and there may be many to choose). Once you've loaded your sound, clicking a piano key will make a note, and your keyboard will act as a solo bass.

The called Linux Multi Media System (LMMS) has become the daddy of loop-based music and early MIDI editing. The important bit of LMMS is the sidebar on the left, which contains samples, file management and plugins – instruments and what might power MIDI. Included are a number of instrument and synthesizers, but we’ll be focusing on the component SF2 Player, which runs MIDI sounds, enabling you to compose MIDI-based music without external hardware.

# AUDACITY

www.audacityteam.org

Over the past we’ve been looking at fully Digital Audio workstations (DAWs), and these programs can be daunting to least! If you just want to do simple multi-track recording (that is laying one track over another) without the complex full DAW, Audacity is best for you.

Although it’s technically possible to do it, Audacity isn’t really snto to make high-quality recording, such as digital recording with of mics, as its interface is really geared around editing. However, it’s best for home demos and is intuitive enough to navigate any project, while being powerful enough to do some usage cases.

That Audacity has become more complex lately, and if you are likely to try pressing Shift-R instead of the Record button, Audacity will translate your notes into the sound of the instrument you wanted. If it is the wrong length, click and drag the right of the note to make it longer or shorter. If you played the wrong note, click and drag u up the piano to move it, or move it around. To delete, press delete.

If drawing isn’t for you, you can use the computer to play notes in real time, and if you press the record button, Audacity will translate your notes into the end of the last track you recorded and delete it later.

Whether it is electronic music or not, LMMS is an excellent way to navigate songs and sequence arrangements. LMMS might not be the right to make you happy using synthesized instruments and virtual drums. there's genuinely all you need to construct a sound without having to xtra hardware.
