# How to get a program working...

Sometime it requires everything to establish and install a program. You might have to visit its site and find the correct download option. There are no such issues with Gimp because it's included with every Linux distribution, but we're working with a superior Gimp installation, with extra packages. GREVC's Magic for Image editing might be available in online image repositories, but if you cannot grab it from gimp.eu, you can archive and put the file in ~/.config/GIMP/2.10/plugins. The FX Foundry patch has its own page at www.gimp-foundry.sourceforge.org and similarly should be unpacked in your home directory ~/.config/GIMP/2.10/scripts. There's nothing difficult about this requirement, notice you may consider such actions to be beyond an advanced task.
