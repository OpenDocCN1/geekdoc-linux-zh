# Installation

# What does it take to install the OS to your machine?

Most OS in the Roundup are equipped with a graphical installer. Unfortunately, that doesn't mean you can expose them to a physical drive on a production machine as you download the OS. You will realize that not all of them have undergone the same amount of testing - installers - as mentioned, it's a good idea to try it in a VM.

The one exception is Ubuntu. Linux allows you to navigate troubling through its installer, which is very polished and streamlined partition the built-in installer to save space for the OS, or to use the familiar Gparted tool's available in the Live environment.

There is also ReactOS, which is the only OS in the Roundup which you have an install-only version or a Live image, if you just want to test the OS on your hardware. You're satisfied that if it works, you can use the install-only approach to install ReactOS to the computer. The OS is quite straightforward and isn't particularly difficult to use. Like Linux, ReactOS runs through a first-boot configurator to help you create a user and a theme for the desktop.

Haiku has both straightforward installers. All you need to do is point Haiku to the be partition and copy the files and install the bootloader quickly. The installer can then boot from GPT partitions or the 64-bit image which has an EFI bootloader so that Haiku can boot on EFI computers.

Many OSes like Haiku include a partitioner to help you create a dedicated partition for the OS.

The Vispops installer also includes a partitioner to help create a slice for the OS. If you are forced to use the system as an admin user, the installer also enables you to set up a partition for yourself. If you're installing Vispops on a new device, make sure to write the basic MBR to the disk, and you're good to go.

# Default apps

Are they useful out of the box?

just like the OS it emulates, ReactOS includes a handful of apps. Besides Paint, Notepad and Word, Pod includes the three favourite Windows apps.

Haiku works better with a minimalistic setup, since the goal of the OS is to create a fully functional OS for students and amateur alike like us. Besides the disk manager and the installer, there's a basic text editor, an image editor, a couple of apps and a handful of administration tools.

By Kolibros, Kolibros yes with dozens of apps: An author editor, a video player, a VLC viewer, a text editor, a browser and image manager, plenty of tools for developers, particularly for FASM assembly, and several game consoleulators.

Haiku includes a lot of butish apps which typically a user might need on the desktop. There's an email client, a web browser, a media viewer and a text editor, as well as administrative tools like an activity monitor, a hex editor, a calculator, a simple web server and more.
