# Collaboration

Helping you work as a team.

When you're working as part of a team, perhaps in business or part of a club, being able to collaborate with others will be necessary. There are several aspects to this, some of which we've given consideration already. Even if your collaboration involves nothing but sharing files back and forth, or sharing them via an online file service, an extensive set of vector-based formats for import and export is useful. This might permit you to collaborate with people who are using different software.

All the packages have one vector-based format for import and export, with the exception of Gravity Drawings. However, that doesn't mean that Gravity is not capable of some collaboration either.

Another way of ensuring collaboration is to insist that all members of the team use the same software. If you use a variety of operating systems, this could be difficult. For example, LibreOffice runs under Windows, macOS and Linux, while Gravity runs under all three. This doesn't apply to the software you're accessing online.
