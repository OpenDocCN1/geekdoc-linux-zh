# The Verdict

![](bbox=[0.515, 0.185, 0.915, 0.375])

Mailspring is the first tool we tested in this Roundup. The others have received extensive coverage, and we've discussed them over the past few weeks. In a break from tradition with our Roundups, we wanted to spend some time going over the pros and cons of each one before we finish the last place finisher and the other tools.

This is because we've rarely come across an application that has so thoroughly features. We were so impressed that a few hours and the lack of interest in improving key features makes it one of the worst performers in the Roundup.

Judging solely by the score on the tests, you can see that Mailspring leaves the other tools only in the add-ons and security department. It's an early-day application that doesn't encrypt your emails, which means you have to filter spam. It is unimaginable for it to be that Mailspring finishes last. Otherwise, we were stunned by the speedy performance and how easy-it was to configure anything you want to experience, as words don't have to edit. Even though the project relies on funding for the price you paid, it still offers some sort of delivery notification to all of the free users, which is much appreciated.

Granted, some of these features, such as delivery notification are also available on Thunderbird, but it isn't easily tied into the Mailspring UI. With our integration, it's a bit of a link we shared.

Thunderbird is making improvements since we last checked it, and a new configuration is now fairly easy. Claws Mail, however is not close to the simplicity of Thunderbird and Evolution. That said, there's nothing wrong with it if you're restricted to a low-spec machine, which we would recommend nothing else. Evolution is a close second, but Thunderbird's account of its default features, shows prowess and numerous extensions.

# ALSO CONSIDER

As is the case we restricted ourselves to graphical applications for this month: Thunderbird. Before we turn to find the command-line alternatives, there's still some graphical over we must mention. If you like Claws Mail you should also devote attention to Thunderbird, since Claws was for back it in 2005. Interestingly, both tools have a nearly identical feature set. Gnome users can also try Gear, but it's not as feature-packed as Evolution.

If you're feeling nostalgic, remember the days of Me Outlook. Mailspring is a viable alternative and offers all the useful features the rest, such as spam detection and message filtering. Then there is Mutt, which is an incredibly better mail client. We need to install and configure other command-line utilities such as Procmat to filter messages. Alpine is like Mutt, but it is designed to be more beginner friendly.
