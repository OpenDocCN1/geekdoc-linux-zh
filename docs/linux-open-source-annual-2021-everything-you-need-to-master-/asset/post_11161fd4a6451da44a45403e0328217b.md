virtualisation has been around since the 1960s.
Of course, computing then was all done on mainframes and OSes were so different, it's so harder for youngsters to get their trendy heads around how this worked. This is essentially the same as it is today: compute resources were to be (fairly) shared among users that concurrently running jobs would not interfere with one another. And each separate job was more or less its own entity (today we call 'supertasks' programs as a master of the course, but this wasn't the case back then). So the underlying OS which generated these jobs was referred to as a virtual machine as we use today.

## Get ready
Download VirtualBox, as described, and fire up. Give your VM a name, the Set Type to Linux and the Version to whatever is appropriate. The 32/64-bit is important.

## Allocate memory
How much memory you allocate to your VM depends on how you intend to use it and how much RAM you have left. Modern desktops and applications as web browsers will happily chew through 2GB, booting to the console requires little. If you allocate too much memory to your VM, host performance will suffer.

## Sort out storage
We need some storage for our VM. Modern Linux distros tend to be busy installing anything with less than 10GB of space, and if you can find allocating more is a 'Choose a virtual hard disk (unless you want to run a live disk)' to begin the process.

## Lift off!
If you need an ISO to boot your machine. Go to Settings > Storage and select the optical drive, click the tiny disc drop-down on the right and select Choose Virtual Optical Disk File (iso). Locate your ISO, click OK, then hit the green Start arrow.
