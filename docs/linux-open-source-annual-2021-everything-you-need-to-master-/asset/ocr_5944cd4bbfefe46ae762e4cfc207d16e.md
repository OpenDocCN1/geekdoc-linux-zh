# Openindiana 6/10 ReactOS 8/10 Visopsys 6/10

Only available for 64-bit computers, Openindiana has images for optical media and USB devices. The images boot into a Live environment, from where you can launch the graphical interface, which works just as expected.

ReactOS is an open source system based on the design principles of Windows NT. It's written from scratch and seeks to give an open source platform to run software applications compatible with Windows.

Considering the fact that it's an educational system, Visopsys surprised us with its usability. What we thought of an ideal candidate for the 'Also Consider' box surprised us with its features and performance. The OS is a snap and gives you the option to install into a Boot or from a Live session.

You don't get the same experience with Openindiana as you do with the others on test here because of the use of MATE environment, as well as a healthy dose of unique operating. One major drawback as far as we are concerned is the lack of a package manager.

The project offers a CD ISO to boot the OS and an easy installer. Whether you used Windows or not, you'll find ReactOS very intuitive to operate.

The inclusion of a capable partition in the installer is a major plus.

While the CLI version isn't hard to master, it's a good number of first-time users who are already out of their comfort zone in an OS.

Besides physical features, you can also install ReactOS on virtual hardware, which is a fact of life in the OS world. It lacks some proprietary requirements, ReactOS only supports a limited set of devices and peripherals.

The desktop is simple to use and includes a handful of essential apps, configuration tools plenty but your regular desktop tasks won't take you anywhere as the OS is missing a web browser and there's no management tool to install additional apps. Visopsys does a nice job of masquerading as a regular desktop, but it is really a capable CS project and should be treated as.

The lack of built-in documentation doesn't help either, but Openindiana is the closest you'll get to a Linux-like experience.
