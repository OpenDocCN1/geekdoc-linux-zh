one of the OS in this Roundup has a lot of apps, but others are rather bare-bones and aren't really useful straight after installation. You'll have to flesh these out to use the OS productively. Unfortunately, not all the OS you let install adds applications, and some take far from others.

KolibirOS and Visopys belong to the former category; there is no means of installing packages with them. While Openendina has a package management system, and quite an adept one at that, the OS is the weakest of them. It features a CLI package manager, pkg, rather than a graphical one. Pkg is very simple to use and apt, yet you will have to read their manual and documentation for tasks to use it.

On the contrary, package management is the only saving grace of ReactOS's vanilla. The OS uses a Synaptic-like app that appears when you use the Add/Remove Programs in the Control Panel. The ReactOS Application
