# Getting hands-on with embedded hardware

Mikeford delves into the world of embedded computing, and discovers that a small amount of hardware can easily go a long way.

![](bbox=[0.066, 0.34532999999999997, 0.193, 0.5313300000000001])

Single board computers (SBCs), typically sized or smaller, are now a familiar part of the computing scene, thanks to small part like the Raspberry Pi family of devices. The Pi has spawned lookal from several companies, which have attracted their supporters, but perhaps less-known are SBCs intended extensively for embedded applications. We use them to introduce how you can put them to work using a starter kit that you can pick up for a few pounds.

To start, just in case this is new to you let us describe what we mean by an embedded application. This is one in such a way that the user might not even be aware that they are interacting with software of the world. For example, household appliances such microwaves or washing machines are generally controlled by embedded systems.

If you've used the Raspberry Pi, you'll find that it has implications for the hardware you need. Many embedded applications will work perfectly with a much less powerful processor than one you'd need to run an operating system. It is possible that an embedded application won't have any graphics, and it won't need a host of interfaces such as Wi-Fi or Ethernet. Not only does this have lower costs, it also allows you to save power which is a major requirement for battery-powered devices.

# Introducing Arduino

Rarely will you find an off-the-shelf SBC inside a remote control or a food processor. However, in order to make the cost of such things to high volume and to reduce size, the computing hardware has been incorporated into a single circuit board, alongside all the other electronic circuit. For DIY applications, though, and especially for learning about embedded computing, starting your project with a dedicated SBC makes a lot of sense.

The lack of an operating system can be a serious drawback, but for embedded applications it is an advantage. If you use an SBC to learn well, but if you want to put your project to work in a real application, an operating system is one overhead you can avoid. Perhaps the major drawback with an operating system is the time it takes to boot. We can imagine that a car wouldn't be popular if you had to wait 30 seconds
