We started with our greenish film and tried to fix its colours in Rawtherpee. First we rolled out tools under the Colour selection, chose the white balance picker and quickly the colours looked much more natural. However, we also had to manually remove the erroneous green hue from the body of the bark we kept. Rawtherpee has a set of tools which can improve colour channels and RGB curves for selective correction.

Playing with colour settings in Lightzone proved to be relatively easy. The application offers its own original way of adjusting colour balance, which was a unusual but useful advantage. Using White Balance in the Edit mode allowed us to set neutral point in the image, making colours look more natural. In addition, the Color Balance tool helps select a colour range and adjust its temperature. This approach was the best and most intuitive for our needs to effectively remove unwanted tints from the image.

There are many colour-related tools in Pixeluvo, including Color Balance, Replace Color and Levels sections for working with colour temperature and white balance. The neutral colour is also there, under the Levels editor. Pixeluvo has tools which show noticeable image processing, such as denoising, boosting vibrancy and improving locality. The tools is limited, but everything you need is here. It takes you a little time to fix incorrect colours in Pixeluvo, but the software will be well spent.

For the second image, we switched to the Auto hit, then adjusted colour compression, brightness, contrast sliders to make it brighter without turning illuminated parts into spots. It wasn't difficult thanks to Rawtherpee providing all the necessary tools for achieving this.

Working with night shots led us to the Highlight section, a dedicated tool for exposure to brighten the image. Another useful thing is Zonemapper with its luminosity tool which changes the exposure value, whereas Relight sliders are ideal for highlights.

Pixeluvo includes a decent RAW processor with some useful features. Then the Auto button (worked like a charm for our test image) and a bunch of sliders including the Recovery option. Pixeluvo worked perfectly while enhancing RAW files, too.

# Editing tools

# How about brushes, layers or selections?

Gimp shines in this, the program was created exactly for manipulation of this kind. Gimp is the gorgeous Healing tool for super-smart removal of any spot defects within a photograph. Needless to say, Gimp has layers and masks that you can rearrange as any photo specialist uses frequently.

Darktable has a useful spot tool, which also allows to add circles, and customize outlines to your photographs. When used with masks, this is possible to remove areas of the image, but it's a far less intuitive process compared with using image-editing tools.

Speaking about Lightroom, there's a way of working with layers within the program. Most filters in Lightroom have the Colour Selection tab that enables you to select a range of colours, which the filter will be applied. Together with the Mask view this works like the layer approach,

filter is another separate layer of the image. There's also a spot removal tool.

The Pixeluvo editor has a better set of editing tools and includes such brushes as WX, Clone brush, Strokes, and many more. The right part of the image has a retractable panel with all the basic features that a good editor shows. A very pleasant experience!

Unfortunately, Rawtable doesn't offer any for working with parts of an image. The best way to solve the problem is to use an editor (any other in the Roundup).
