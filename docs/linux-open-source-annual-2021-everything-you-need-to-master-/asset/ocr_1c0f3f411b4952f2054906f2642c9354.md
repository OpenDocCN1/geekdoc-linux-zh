# ## JITSI

An all-in-one messaging app, Jitsi has an impressive set of audio and video-conferencing features. As a VoIP client, it allows you to make calls using the Session Initiation Protocol (SIP). It has all the you'd expected from a softphone that it can put on hold, transfer and record calls. It can also register-SIP calls to other Jitsi users on the network.

You can use Jitsi to make video calls to one user or several on both SIP and XMPP networks, using Jitsi Videobridge, which can host multi-user video calls. Its capable IM client with unique features including the ability to share and share the desktop of both ends of the call at the same time. https://jitsi.org/

# ## ROCKET.CHAT

Billing itself as the 'ultimate chat platform', Rocket.Chat is filled with useful features. In addition to essentials like threaded conversations and the ability to edit and delete messages, the collaborative servers offer several interesting things such as Rocket.Chat for Slack and visitors to your website.

You can roll out Rocket.Chat on a snap-supported distro with a single command and deployments from Docker and a wide range of import data from another service like Slack. The SlackBridge-plugin allows to mirror messages received in a Slack channel or private group into Rocket Chat.

Rocket.Chat also enables you to have a video conference with your team. You can record and send the messages publicly or a private conversation. https://rocket.chat/community

# ## TOX

If regular IM clients are not enough for you, use the Tox protocol which encrypts all chats with the NaCl encryption library and instead of a central server, routes them over P2P connections between users. It uses Tox IDs, which are keys, instead of a user account and also allow for greater anonymity. https://tox

# ## BEEBEEP

An IM client with a difference, BeeBee is designed to connect with peers on your network. It automatically detect other users on the network and provides all the features of a modern chat client and from encrypted text messages, can to share files. https://beebeep.org/

# ## OPENFIRE

There are several XMPP-based servers available. Openfire is one of the easiest to manage. It implements many of the common functions used by the XMPP protocol. You can use any XMPP-compatible client to chat through Openfire, it works with its own client: https://ignition.org/openfire

# SIGNAL

The messaging app helps secure communications over the mobile network. It is endorsed by security experts and uses end-to-end encryption to secure all your text, audio and video calls. https://signal.org/

The Matrix protocol enables users registered with one provider to seamlessly communicate with users of any other. It is one of the best clients based on the Matrix protocol. https://riot.im

# RETROSHARE

A P2P chat and file sharing platform. RetroShare creates encrypted connections between friends. You can share your private keys or to exchange them via a chat server. https://retroshare.net

# SOGO

One of the best alternatives to MS Exchange. Sogo has all the necessary functions with native mobile clients. Try the online demo before deploying it on your server

With HumHub you can deploy your own social network on the internet. It has the standard network features you'd expect and the project's website hosts an online demo as well. https://www.humhub.org
