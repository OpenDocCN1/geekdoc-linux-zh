# HOW WE TESTED...

Unlike the last time we ran a Roundup of email clients (LXF15 seven years ago!) when we installed the applications on their native desktop environments, we're running all of them on the Budgie this time around. Most distributions carry these applications in their software-repositories, and we're running the latest versions of each of them. The only exception is Thunderbird because its release isn't yet available in the software repositories, and we had to install it manually. Most email clients are similar in testing those for their search performance, capability to handle junk and spam messages. We'll also keep an eye out for standout features like their support for IMAP and POP accounts. Extending functionality through plugins and integration options is another thing to consider when choosing an application that you'll run for important communications.
