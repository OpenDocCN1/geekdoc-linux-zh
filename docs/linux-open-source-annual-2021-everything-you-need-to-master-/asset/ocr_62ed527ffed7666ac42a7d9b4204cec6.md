# VirtualBox beginnings

Learn the basics of virtualisation no matter which OS you’re running, and which OS you want to try.

ne of the easiest ways to fire up your virtual machine is with Oracle’s VirtualBox. It is free (GPL-licensed) software for Windows, macOS and Linux. Windows users should download from https://virtualbox.org and Linux users should install `sudo apt install virtualbox`.
It works for all platforms, so no matter what OS (or which OS you want to run), you can use our handy six-step guide outside. If you’re stuck for a bit to try, why not copy the Linux or OpenMedia ISO files off the LXVF? You can use VirtualBox to extract it from the thing; this would be awesome.
If you find yourself stuck in fullscreen mode, just Ctrl+Alt to return to windowed mode. If your mouse cursor trapped in the guest window, just press the Ctrl Right Key again. Linux distributions do seamless mouse movement, so the shouldn’t have to-take the mouse past the edge of the screen in the guest window to control the host.

# VirtualBox tweaks

It’s straightforward to fire up a VM, but let’s look at some of the options that VirtualBox provides to make your virtual life feels as real as your own. First of all, if you store your virtual drive image on a traditional spinning hard disk, you’ll experience heavy workloads and you’ll probably notice a lot of disk activity while you’re using. Under such tasks, and if you’re brave enough to run a Windows VM, your life will be much better if you store it on an SSD.
