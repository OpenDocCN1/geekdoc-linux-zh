The Pattern Editor is pretty straightforward, but something that might throw you off is the Size function. Size is in beats, and the default is eighth notes (8 quarters), so the Size function will be a full 4/4 bar. If you want eight eighth notes to fill a 4/4 bar, that's slightly confusing at first, but if you want to make something 7/8, the Size would be 10, and if you want 9/8, the Size would be 12.
If you want eighth notes, and if you need to change the Resolution to 16 notes (quarters), you need to right-click on the ruler to get 64 notes. If you would want a triplet-subdivision (for blues or jazz), you can use the same numbers, but with a T - as as eight eighth notes.

Moving onto the Sound Editor in the top of the screen, there is a list of patterns on the left. Click a different pattern from one pattern to another while working in the Pattern Editor. It's a good idea to name each pattern if you want to change it later.
On the right is a grid with empty squares. Each square will represent a bar of music; clicking each square will generate a sound when the song reaches that point in time. For any highly complex arrangements, multiple patterns can run together.

If you don't like the default drumkit (GMKit, which is already mediocre), there should be a selection of alternative drumkits available in your repositories. To find 'Hydrogen' in the Sound library, find whichever kit you want to install, just right-click on the tile of the drumkit and click Load.

# ## PLUG-INS, MIDI AND SOUNDFONTS

While your manager is we recommend installing every audio plug-in (for search LADSA, DSS, VSI, and LV2) and also install a keyboard if you are recording MIDI without an external device.
Every plug-in will augment your system's functionality. While you are quite selective about what you want to install, plug-ins aren't massive, so install as many as you may need and at least each one you can find!
Note that MIDI is different from audio. MIDI is merely a set of instructions and sections for what to play and when. If you try to run MIDI data on your system, you will be greeted with silence. MIDI-based hardware such as synthesizers use internal instruments of instruments captured as a set of notes for a whole sound produced.
In the world world audio where sounds can be generated by the cards that you play, soundfont according to MIDI instructions. Some soundfonts are then, whereas others can be elaborate recordings of multiple instruments.
However, Soundfont (the capitalisation) is a commercial term for a format that is supported by products like the Creative Sound Blaster. Popular software synthesizers like FluidSynth have the term for such described files if you want to run general sounds from any sound card. If you prefer to avoid soundfonts, Yoshimami comes with its own set of sounds. For a free list of soundfonts and plug-ins, see:
https://lmms.io/documentation/Useful_resources..
