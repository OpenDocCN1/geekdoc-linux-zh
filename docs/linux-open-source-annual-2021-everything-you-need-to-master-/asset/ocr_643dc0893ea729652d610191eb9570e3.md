# ## ZULUCrypt

While you can control access to the data on your computer using accounts and file permissions, they aren't enough to prevent a determined intruder from gaining access to your private files. The only reliable mechanism for protecting your personal data is to encrypt it. Working with encrypted data is an involved process, but it'll go a long way in reinforcing your security and insulating your data.

ZuluCrypt is a graphical encryption tool that has an intuitive, easy-to-follow interface. Using the program you can create an encrypted device within a file, and partition USB disk. It can also encrypt individual files with GPG. ZuluCrypt can also perform volume encryption, which means it can encrypt everything within a cipher device. The device can be a whole disk, partition or a file mounted as a loopback device. With block device

encryption, the user creates the file system on the block device, and the encryption layer transparently encrypts the data before writing to the actual lower block device. The storage area appears just like a large file, which doesn't even reveal its directory structure. All these functions and more accessible via the excellent user interface. http://mhomongchu.github.io/zuluCrypt

# ## GUFW

GUFW is the graphical front end for UFW, the uncomplicated firewall, which is one of the easiest for iptables. This tool has a simple interface and preferences for regulating incoming and outgoing traffic. You can configure the incoming and outgoing policies of the profiles as you prefer. You can also use GUFW to define specific rules for allowing or blocking individual apps and services. http://ufw.org/

# ## BITWARDEN

The Bitwarden password manager uses end-to-end encryption and AES 256-bit encryption to secure your data. It does this through its unique little trick of storing your passwords in a remote Microsoft Azure cloud. You can also import passwords from various sources. https://bitwarden.com

# ## STEGOSTEP

Steganography is the art of concealing data inside seemingly harmless message or image. The most common mechanism for embedding it is by replacing unused data in graphical file with bits of information that isn't visible when viewing the original piece of data. Steganography is used to complement encryption.

StegoStep is a graphical tool that can hide text messages as well as any type of file inside an image. To insert, point to the file you want to hide inside and enter a secret key. To get the secrets from the image once again and use the Extract button with the secret key to reveal the hidden messages and from image. https://stegostep.org

# MTR

MTR is a simple network diagnostic tool that combines the functionality of traceoute and ping. It displays with the path of the packet a wealth of relevant information. http://www.pingand.net/mtr

# A

You can use aide to detect sort injections, checking the integrity of the files by their properties such as a baseline created on the initial run. http://aide.sourceforge.net

# NIKTO2

# MALTRAIT
