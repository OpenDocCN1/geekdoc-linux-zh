## Customisation

Do they help admin access?

systemRescue doesn’t offer much in terms of a customised interface. The distro has a simple boot option that you take to its Xfce desktop.

The MorpheusArch project produces a script LinDiag to assist with common admin and recovery tasks. You can use it to check services, diagnose the network, images and packages. However, the script is not included in the distro, so you’ll have to clone it from GitHub.

ALT Linux Rescue also offers much in terms of customisation, but it does have the forensic boot option that brings up the distro without the swapping or any partition. There are also a couple of scripts that automatically mount disks and fix them any issues with the main file system.

In contrast, AIO System Toolkit has a bunch of CLI tools, but for easier access it has a shortcut on the desktop for all of them. Besides the Live environment, you can also boot the CD/USB inside Windows to access all of its Windows-specific repair and rescue tools via a custom interface.

If you manage a few of Windows machines, AIO System Rescue Kit can help to keep in condition.

What Ubud stands out from its boot menu in particular. The distro has no graphical desktop and instead boots to a well-laid menu. The customised text help guide you to the relevant utility for your use. The menu is nicely arranged and includes every entry help identify them.
