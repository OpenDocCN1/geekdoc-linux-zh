# Freshen up

Firefox has an option to do this from start—just navigate to :about:support and hit the 'Refresh Firefox' button on the top-right of the page. This will reset your bookmarks, auto-fill information and passwords, but will purge any extensions. Add-ons will survive the profile folder, but will have their preferences reset. The old profile will be backed up to the Desktop and its contents can be copied back if the situation isn't resolved or you miss something.
