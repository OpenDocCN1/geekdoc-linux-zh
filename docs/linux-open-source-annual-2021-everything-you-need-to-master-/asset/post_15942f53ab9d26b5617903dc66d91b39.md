Single board computers (SBCs), typically sized or smaller, are now a familiar part of the computing scene, thanks to small parts like the Raspberry Pi family of devices. The Pi has spawned lookalikes from several companies, which have attracted their supporters, but perhaps less-known are SBCs intended extensively for embedded applications. We use them to introduce how you can put them to work using a starter kit that you can pick up for a few pounds.

To start, just in case this is new to you, let us describe what we mean by an embedded application. This is one in such a way that the user might not even be aware that they are interacting with software of the world. For example, household appliances such as microwaves or washing machines are generally controlled by embedded systems.

# Introducing Arduino

Rarely will you find an off-the-shelf SBC inside a remote control or a food processor. However, in order to make the cost of such things to high volume and to reduce size, the computing hardware has been incorporated into a single circuit board, alongside all the other electronic circuit. For DIY applications, though, and especially for learning about embedded computing, starting your project with a dedicated SBC makes a lot of sense.

The lack of an operating system can be a serious drawback, but for embedded applications it is an advantage. If you use an SBC to learn well, but if you want to put your project to work in a real application, an operating system is one overhead you can avoid. Perhaps the major drawback with an operating system is the time it takes to boot. We can imagine that a car wouldn't be popular if you had to wait 30 seconds.

Raspberry Pi and SBCs tend to be built around an Arm processor of some type. By way of contrast, the many of Arduino boards are based on the Atm328 from Microchip. There's more to it that separates them, though, as few figures will reveal. The processors on Pi-type boards have a 32-bit or 64-bit architecture, they generally have two cores, and are usually clocked somewhere between 1GHz and 1.8GHz. Atm328 is an 8-bit architecture, a single core, and the clock speed is just 16MHz.

The difference in memory and storage is as stark. Interface compatibility measured in hundreds of megabytes or gigabytes, Arduino boards have 32KB of storage for the processor, and user storage a few kilobytes of RAM and a similar amount of non-volatile EEPROM. For embedded applications with no need to support an operating system, you might be surprised at how much you can do with such modest specifications.

Finally, moving beyond that it might be practical to specify what we mean when we talk about Arduino. Arduino was developed at the University Design Institute for educational use. Arduino boards - which are available - are found at www.arduino.cc. Some companies have produced products that cannot be called boards, because the name has been registered; other parties may refer to them as "Arduino-compatible" or use similar terms to make the point.

Generally, third-party designs are cheaper than those sold by Arduino. There are also boards on the market that are functionally identical or even better—but they use the Arduino name and logo illegally—they should be okay. And, just as a question, what do we mean by the phrase "Arduino-compatible": the bottom line is that compatibility is possible. At the software level, it means that it will work with the Arduino IDE—that is the integrated development environment—without a separate PC to decode code.

At a lower level, hardware compatibility means the IO pins so that the board can be used with shields; which are roughly equivalent to HATs in the world of Raspberry Pi. Most compatible boards also offer this level, but they have their own set of defects.

# Arduino IDE

Because Arduino-type boards don't run an operating system, they are not able to interface keyboard, mouse, and software is developed on a separate PC and is then uploaded to the Arduino. The environment used is called Arduino IDE, which is available for all major operating systems, but it runs under you so you'll have to install it if it's not already present with your PC. Arduino provides the necessary environment for development. It includes a text editor in which you will create and modify the source code, a compiler and linker, and means of downloading the compiled code to the Arduino board.

Many third-party-compatible boards work with the IDE, so you'll be better off downloading the latest version from www.arduino.cc/. The online version runs in a browser and saves your projects in the cloud. If you decide to use the online IDE, you will still need to install the Arduino Web Create, which is defined as a platform that allows developers to write code, access configure boards, and share projects; it is possible to do all without using the local version.

We have some good and some bad news. The good news is that for many controls you'll be writing—not very complicated—the likelihood of encountering errors is low. But errors do happen. The bad news is that if your software goes wrong, debugging code on Arduino is tricky. In the standard, the IDE does not provide features for setting breakpoints, stepping through code, or watching variables.

# CODE DEBUGGING

What is possible is to use the USB link between the Arduino and your PC—the link that allows code to transmit data back to the IDE. This involves adding print statements for debugging purposes. Typically you'd use Serial.write() or Serial.print() to output debugging data—such the value of a memory location—to the serial port, which is initialized with Serial.begin() in the IDE's serial monitor to inspect what the sketch has written.
