
# Developer tools

Making your life easier with this collection of capable utilities.

## >> ATOM

Atom describes itself as a hackable text editor. Developed by GitHub, the tool has a built-in package manager that allows users to search and install plugins from within. About 800 packages come with the utility by default. One of its most features is the find and replace function that can also modify text across multiple files as you type.

Atom can be used as an IDE and one of its highlights is the autocomplete feature. There's also a bracket matcher that highlights the line of the closing bracket to the one under your cursor. You can also define key bindings and add more functionality for packages with items minimaps and syntax snippet libraries. https://atom.io.

## >> BYPTON

A Python shell provides modern IDE-like features inside a terminal window. You can start it with default settings and customise it by editing its config file. The shell code completion displays a list of expected parameters. It highlights syntax as you type and the Rewind feature in memory.

https://bypython.org

## >> ETHERPAD

Collaboration is key to any project. The Etherpad text editor allows users to collaborate in real-time. It works inside the browser and enables participants to interact via a text-based chat. List of its features that you can take a for on its website.

http://etherpad.org

## >> VIRT-MANAGER

The Virtual Machine Manager is the open source frontend for creating KVM-based VMs. It uses the qemu-kvm hypervisor, which is a version of the qemu machine emulator, and a VPC and SPICE client that displays a graphical console to the running VM.

https://virt-manager.org

## >> TUNKEY APPLIANCES

Installing network software or web servers on a server can be tricky because they require a lot of infrastructure, which might take hours to put together. From Data to basics, you'll have to spend quite a time to assemble a fully functional web server before you deploy an application on the network.

Furthermore, to save plenty users from the network, you need to thoroughly examine your server for any security leaks. This is where Turnkey shines. Using its appliances you can deploy a new web server in minutes. Simply, a TurnKey appliance is a self-contained system that packs in a fully functional instance of a web app with enough components of operation to power that out. The system works deployed on both or any kind of virtual hardware.

Turnkey appliances are available in several formats forming according to the hardware you want to deploy on, from local to OpenStack. Constantly, they're up and running, irrespective of the platform, all they give you the same interface and manage the web.

https://turnkey.org
