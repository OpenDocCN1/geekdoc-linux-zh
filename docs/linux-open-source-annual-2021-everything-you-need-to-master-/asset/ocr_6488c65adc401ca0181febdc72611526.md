## Get ready
Download VirtualBox, as described opposite, and fire it up. By default VMs are stored in your home directory, so make sure there's some room to play here or be aware that you need to manually specify a different location. A desktop Linux install starts at 5GB and will easily grow to 10GB.

## Create your VM
Hit New button in VirtualBox's toolbar. We will use Solo ISO which we copied from the LXFDVO- free to use as you like. Give your VM a name, the Set Type to Linux and the Version to whatever is appropriate. The 32/64-bit selection is important.

## Allocate memory
How much memory you allocate to your VM depends on how you intend to use it and how much RAM you have left. Modern desktops and applications as web browsers will happily chew through 2GB, booting to the console requires little. If you allocate too much memory to your VM, host performance will suffer.

## Sort out storage
We need some storage for our VM. Modern Linux distros tend to be busy installing anything with less than 10GB of space, and if you can find allocating more is a ease. 'Choose a virtual hard disk (unless you want to run a live disk)' to begin the process.

![](bbox=[0.083, 0.681, 0.483, 0.823])

![](bbox=[0.516, 0.681, 0.916, 0.823])

## Tweak storage
Choose the VDI storage. These files can be fixed or dynamically sized, up to a maximum. Dynamic storage is much more flexible, and you're unlikely to notice the increased I/O overhead, so go with that. You can specify the file's location with the icon next to it.

## Lift off!
If you need an ISO to boot your machine. Go to Settings > Storage and select the optical drive, click the tiny disc drop-down on the right and select Choose Virtual Optical Disk File (iso). Locate your ISO, click OK, then hit the green Start arrow. 
Chocks away!
