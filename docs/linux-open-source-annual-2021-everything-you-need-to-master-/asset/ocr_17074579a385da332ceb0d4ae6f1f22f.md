# Web servers

# The Verdict

It takes that rank servers by popularity seems to mirror closely the verdict we reached after testing these web servers, for home and dev use. Everything in life, every server has its own strengths and weaknesses, but all of them are more than sufficient for our purposes, which is to build a developer web server at home with the option to use it as our primary host if we so choose.

If our primary objective is to be up and running with as little tweaking as possible, Apache is a top choice because it works just so perfectly out of the box, after a few installation commands and without configuration. Choosing Apache

Nginx is behind Apache for simplicity, as long as we make a simple change to the .conf file to enable PHP to run. The time needed over Apache is really just a minute or two at most. Thus, making it a bit tedious, anyway Nginx feels like a solid choice, although performance is not critical in which it outpaces Apache. We take web server popularity into account, for 80 percent of the server market. Thus, Apache and Nginx are both promising for home-testing and serving.

Openitespeed looks like a good choice for the web and even if you do not have a real competitive edge to it, it already has a decent amount of the web-hosting software. We found that both Apache and Nginx had a number of time to set up compared to others, from a user's developer of view.

Lightpeed is another tool that works well and runs along faster than Apache. Using it is a rather better experience in comparison to the other 'trailing' servers.

Tomcat is another great tool and recommended for those who are on the JSP side of things. Tomcat feels just like a trick and easy way of getting a job done without bugs or poor deorum. The take-away from this Roundup is that all five web servers here are nature reliable tools more capable of meeting every need.

# >> ALSO_CONSIDER

When choosing of our list, we wanted to compare the most popular web servers, as there are very good reasons they might need: such as reliability over many years.

However, there is a very long list of other web servers that can be used for testing Apache and deploying live websites such as Thingne, Cherokee, IndieWebServer, Cowboy and Monkey. Although we were hoping to find some in the smaller players, our search came up empty.

All of these however, we tried and were not worth the effort. instructions failed, the packages did not exist and were missing from building source. When a package did work, it would take too long to be useful.

We are happy to run samples and tests on these alternative options, but there's little reason for trying options outside of the core servers in this Roundup.
