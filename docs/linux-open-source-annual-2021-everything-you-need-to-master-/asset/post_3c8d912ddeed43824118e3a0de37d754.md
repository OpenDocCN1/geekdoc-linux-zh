# Photo editors

Keen photographer Alexander Tolstoy keeps his imperfect snaps, for fixing later, using some of the best photo editors available for Linux.

# HOW WE TESTED...

Editing photos isn't the same as editing general images. Therefore we decided to compare some of the best editors for Linux with a focus on fixing common faults, enhancing colour and lost details that might be considered gone for.

The aim here is help you select the most feature-packed and practical software that can bring dull images to life. We'll take a closer look at their advanced features, such as automatic enhancements, the ability to fix dull, blurry, or-exposed images, and whether or not they handle RAW files. It's not the first time we've run Roundup on image editors, but this current group includes a different selection of software. Out of the five open source tools, Uraw had a better application in the past. The fifth is a commercial edition, which is well known to the reader, but should be of great interest to photo-editing enthusiasts.

With comes to select an editor, there's plenty of choice. There are general-purpose editors like Gimp, Pinta or Darktable, and finally software for artists like Krita. Our interest lies in fixing photos and processing RAW files, so we grabbed Gimp with its set of built-in elements, Darktable and Rawtherapy – two classic darkroom editors for dragging out visible details. Lightzone is similar to these two programs but has a more consumer-friendly interface. Last but not, Pixeluvo is a program with a limited set of editing tools. Gimp is the only one that does use a UI by default. Although it adds a 'pro' feel to the program, won't hide the truth in our Roundup!

# How to get a program working...

Sometime it requires everything to establish and install a program. You might have to visit its site and find the correct download option. There are no such issues with Gimp because it's included with every Linux distribution, but we're working with a superior Gimp installation with extra packages. Gravity's Magic for Image editing might be available in online repositories, but if you cannot grab it from gimp.eu, you can archive and put the file in ~/.config/GIMP/2.10/plugins. Foundry has its own page at www.gimpource.org and similarly should be unpacked in your home directory ~/.config/GIMP/2.10/scripts. There's nothing difficult about this requirement, notice you may consider such actions to be beyond an advanced task.

For Ubuntu users you can use the ppa:lightteam/lightzone. Pixeluvo costs $30. The official web page offers trial downloads with DEB and RPM packages for other flavours of Linux. These packages can be used for Ubuntu and Fedora, respectively. Those packages can be installed in other distributions, or rewrapped for other flavours of Linux. Pixeluvo includes a static set of the other Qt4 libraries at /opt/pixeluvo/libqt4, which you may want to delete in order for the program to use your system libraries. It's for advanced users. Additionally, the trial doesn't enable saving modified images with size larger than 800x600. We recommend making those wishes!

Lightzone is somewhat cumbersome. Due to its legacy, the web site you visit might have lists outdated, which might confuse some users who want to get the application. Lightzone is based on Java, which means it should be a platform-agnostic application, and it's often packed for many Linux distributions. Ready-to-use packages for Ubuntu, Fedora and openOSE there are many ways of getting hold of and installing Darktable.

# Ease of use

How user-friendly is each of our five candidates?

![](img/5f8379eaeda572d04307c37d75b0ba5d_160_1.png)

previously, Gimp was a mess of floating windows that required a lot of manual navigation. Now the program uses the single-window mode by default. Its photo-editing features are located in different places like Filters+Enhancement, Filters+G-MIC and a top-level menu for FX. Unless you know where your tools are easy to find them.

Darktable has no such fragmentation. However, you first need to point to the application with your directories and select one for editing. By default, the tools are hidden under a tab on the right side. Rawtherapy has a more intuitive UI. It is similar to the other Darktable but you can't find the file tree when editing an image. Furthermore, all the tools are easily expanded in the panel. Lightzone suggests switching between browsing and editing modes.

Our remaining program, Pixeluvo, also shows signs of usability. Photo editing capabilities can be found under the Colour and Effect sections of the top menu bar. Pixeluvo was designed with simplicity in mind, and it was much impossible to get lost in its clear and simple list of available tools.
