## Can we host a site safely?

We start our server and test local places, we are the only ones accessing our website with port 80. However, as soon as the day goes to scale, we need to take security more seriously when we use open port 80, so outside users can access the set. Let's do a quick run-through of what we can do to protect the site.

With a Apache installation, we should make several changes: installing the mod_security module and making several changes to the /etc/apache2/enabled-security.conf file. We can also enable ServerSignature off and Tokens Prod. By editing /etc/apache2/security.conf file we can also edit the security.conf file to restrict directory browsing and limit the access.

With Nginx, we can edit the /etc/nginx/nginx.conf and set server_tokens to off to hide the server version. In addition, we have the ability to restrict access by ip or admin accounts based on rules.

Openspeed is very good at controlling files by default. We need to edit the config file to be able to use subscribers and so. To add more layers of protection, we can install mod_security and module_fastcgi.
