# How It Works

Admittedly, this is almost more of an awk script than a bash script, but sometimes you need the extra horsepower awk provides for parsing (the GitHub API returns JSON). We use curl to ask GitHub for the user $1, given as the argument of the script, and pipe the JSON to awk. With awk, we specify a field separator of the double quotes character, as this will make parsing the JSON much simpler. Then we match the JSON with a handful of regular expressions in the awk script and print the results in a user-friendly way.

# Running the Script

The script accepts a single argument: the user to look up on GitHub. If the username provided doesn't exist, nothing will be printed.
