# How It Works

The bulk run script takes three arguments: the maximum number of processes to run at any one time ①, the directory containing the files to process ②, and the command to run (suffixed with the filename to run on) ③. After going through the arguments supplied by the user with getopts ④, the script checks that the user supplied these three arguments. If any of the procs, command, or inputdir variables are undefined after processing the user arguments, the script prints an error message ⑤ and the help text and then exits.
