# Listing 5-14: The adduser script

# How It Works

The coolest single line in this script is at ①. This scans through the /etc/passwd file to figure out the largest user ID currently in use, that is less than the highest allowable user account value (5000), but you should adjust this for your own configuration and then adds 1 to it for the new account user ID. This saves the admin from having to remember what the next available user ID is, and it also offers a high degree of consistency in account information as the user community evolves and changes. The script creates an account's home directory and copies into it the contents of the /etc/skel directory. By convention, the /etc/skel directory is where a master .cshrc, etc.
