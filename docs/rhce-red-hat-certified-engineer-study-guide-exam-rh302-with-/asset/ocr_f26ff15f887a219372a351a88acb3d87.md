# The /etc/rc.d/rc Script

The /etc/rc.d/rc script sets a new runlevel and then runs a series of scripts associated with the specified runlevel. The scripts are contained in the directories

+   * /etc/rc.d/rc0.d
* /etc/rc.d/rc1.d
* /etc/rc.d/rc2.d
* /etc/rc.d/rc3.d
* /etc/rc.d/rc4.d
* /etc/rc.d/rc5.d
* /etc/rc.d/rc6.d
