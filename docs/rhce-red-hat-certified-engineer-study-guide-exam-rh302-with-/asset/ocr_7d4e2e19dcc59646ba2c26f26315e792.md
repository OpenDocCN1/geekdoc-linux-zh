# Answers to Review Questions

+   1. B. The kbdconfig program configures the keyboard.

+   2. B. The mouseconfig program configures the mouse.

+   3. B. The sndconfig program configures the sound system.

+   4. D. Runlevel 2 is multiuser mode without networking. Runlevel 4 is essentially the same as runlevel 3.

+   5. A, B, and C. The linuxconf program operates in both text and graphical mode; it does not require a mouse.

+   6. B. The linuxconf program does not automatically restart services whose configurations you've changed until you instruct it to do so.
