# The IPX Protocol

Red Linux includes the mars-nwe package. This package provides file and printer sharing for Novell networks, which are based on the IPX protocol. The related iputils package includes useful IPX utilities. If you're working with an IPX-based network, you should install both packages.

marsnwe lets you mount IPX file systems using the ncpmount command or by using a mount command specifying file type ncp. You can also specify IPX file systems in the /etc/fstab file.

![](img/7a53e2be7760e1d422d1c89dbf5d6ede_584_0.png)

The mount command reports the file system type as ncpfs; but you can specify ncp or ncpfs as an argument to the mount command and in the /etc/fstab file.

# Remote Printer Access via lpd

You can easily access a Red Hat printer remotely. Of course, you must first configure the server and client systems. To configure the server systems, list each client host in /etc/hosts.lpd. If the client host is under the same administrative control as the server, you can list the host in /etc/hosts.equiv, if you prefer. Also, be sure the name of the client host can be resolved by an IP address; add a line to /etc/hosts, if necessary.

To configure the client, add an entry in the following form to the client's /etc/printcap file:

```text
remlp:
:lpr=host:rp=printer:sd=dir
```

In this entry, host is the name of the server, printer is the name by the target printer is listed in the server's /etc/printcap file, and dir is the spool directory to be used on the client. The spool directory is usually a subdirectory of /var/spool.

Once the server is configured, you should be able to access the server's printer by issuing commands on the client host. For example, you can print a file by using the lpr command, and you can check the print queue by using the lpq command.

# Internet News

The inn package provides inn and other programs that support the Network News Transfer Protocol (NNTP) and Internet news. Internet news transmits and receives postings to Internet newsgroups, which were the dominant method of multi-way user-to-user interaction before the advent of the Web. Today, Web forums provide a simpler way of multi-way user-to-user interaction. However, Internet news remains a popular service, even though it's complicated to work with and requires significant resources. You can use inn to support local newsgroups or provide access to Internet newsgroups. To adequately support Internet newsgroups, the host system must have many gigabytes of free disk space and a high-speed Internet connection.

Like-email, Internet news has become a means of transmitting spam. To suppress spam news articles, you can install the cleanfeed package.

# Synchronizing Time

Red Hat Linux provides two ways to synchronize time:

- rdate, which synchronizes to another host
- xntp, which synchronizes to Coordinated Time (UTC)

The rdate program, contained in the rdate package, is the older and less sophisticated method. To synchronize with another, issue the command in the form

```bash
rdate -s host
```

where host is the name of the server. This can be forced by specifying the -s switch on the command line. The xntp program, contained in the xntp package, is more sophisticated. # Understanding Secondary Services

Time adjustments are made by rdate in one of two ways. If rdate determines your clock is off by more than 0.5 seconds it will simply step the time by calling setday(2). If the error is less than 0.5 seconds, however, it will slew the clock's time via a call to adjust(2). The latter technique is less disruptive and more accurate when the offset is small, and works quite well when rdate is running by cron (8) hour or two. At boot time, it is better to always step the time. This can be forced in all cases by specifying the -b switch on the command line. The -s switch tells rdate to log its actions via the syslog(3) facility rather than to the standard output, a useful option when running the program from cron(8)

The -d flag may be used to determine what rdate will do without actually doing it. Information useful for general debugging will also be printed. By default rdate claims to be an NTP version 2 implementation in its outgoing packets. Some older software will decline to respond to version 2 queries, the -o switch can be used to force the program to poll as a version 1 implementation instead.
