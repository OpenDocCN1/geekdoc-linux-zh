The xeyes program doesn't do much. But, for exactly that reason, it's useful for testing and troubleshooting X.

The general form of the command for launching a remote X client is xclient -display server[:m[.n]] [xclient_args]
where:

+   * xclient and xclient_args are the client and its optional arguments.
* server is the host name or IP address of the X server.
* m is the optional server display number (by default, 0).
* n is the optional server screen number (by default, 0). This argument is used in the somewhat unusual situation of a server that has multiple screens associated with a single display.
