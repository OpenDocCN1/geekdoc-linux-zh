X Directories and Files The /usr/X11R6/bin directory contains X binaries. The /etc/X11 directory and its subdirectories contain the X configuration. The symbolic link /etc/X11/X points to the currently selected X server. The /etc/X11 directory also contains the XF86Config file, the main X configuration file.
