To compile a Linux kernel, you should install several packages, including kernel-source, kernel-headers, egcs, cpp, dev86, make, glibc-devel, nurses, nurses-devel.

**Kernel Modules** The kernel module configuration file is /etc/conf.modules. Important commands for working with kernel modules- include depmod, lmod, modprobe, rmmod, and uname.
