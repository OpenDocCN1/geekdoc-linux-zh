# An Example Network

Figure 29.5 shows an example network, which consists of two subnetworks joined to one another and the Internet by a router. The route commands responding to the example network are:

```
route add -net 192.168.1.0 netmask 255.255.255.0 eth0
route add -net 192.168.100.0 netmask 255.255.255.0 eth1
route add -net 1.1.1.0 netmask 255.255.255.0 eth2
route add -default gw 10.1.1.2 eth2
```
