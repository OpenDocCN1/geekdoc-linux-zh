# I/O Ports

As explained, most devices require an IRQ so that they can signal the CPU to notify that an I/O operation has completed. Most devices also require a series of one-byte areas of memory, known as I/O ports, that are used to move data from the device to system memory or from system memory to the device. Some devices require more than one of I/O ports.

A series of I/O ports is sometimes referred to as a device I/O address. I/O ports are identified by a hexadecimal (base 16) number in the range 0x0-FFFF.
