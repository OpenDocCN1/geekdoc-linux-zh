# The for Command

The for command executes a series of commands iteratively, once for each member of a specified list:

```
for list
  commands
done
```

Another form of the for command assigns the value of the current list member to a specified variable:

```
for x in list
  do
    commands
done
```

During iteration, the variable x holds the value of the current list member.

# The break Command

The break command can be used in the body of a for, while, or until command. When executed, it immediately terminates the loop.

# The continue Command

The continue command can be used in the body of a for, while, or until command. When executed, it immediately ends the current iteration of the loop.

# The exit Command

The exit command terminates the execution of a shell script and sets the exit code to the value specified as its argument:

```
exit 0
```
