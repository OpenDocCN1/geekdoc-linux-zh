# Remote X Logins

You can log in to a remote host via X in several ways:

+   - You can specify the host name or IP address of the login host.

+   - You can broadcast a message to the local network and log in to whichever host first responds.

+   - You query a host configured to provide a chooser, which lets you choose from a menu of login hosts.

**The Xnest Program** The Xnest program lets you run an X server's associated with a window rather than a video adapter. Xnest lets you run multiple X servers on a system with only a single video adapter.

**The X Font Server** X can obtain fonts from a local hard drive or from a font server accessed via the network. The FontPath directive of the X configuration specifies the source for X fonts.
