# Step #9: Creating a New Boot Disk

Whenever you install a new kernel, you should create a new boot disk that contains it. To do so, issue a command of the form

```
mkbootdisk -device /dev/fd0 -verbose
```

where version is the version and extraversion code associated with the new kernel. If you want to write the kernel to a floppy drive other than /dev/fd0, specify the device file of the desired drive; for example, /dev/fd1. After creating the boot disk, boot the system using LILO and check that it operates properly. If you can't boot the system using the new kernel, boot the system using the old kernel by specifying the label of the old kernel in response to the LILO prompt.

# Making a Custom Linux Kernel

Creating a custom kernel was a Linux rite of passage. But after studying this chapter, you should be able to compile a custom kernel without loss of sanity. Here's the process you should follow:

+   1. Create a Linux boot disk and test it to be it successfully boots your system.

+   2. Configure a Linux kernel with any options you like, so long as they're not incompatible with the hardware of your system.

+   3. Build and install the kernel, creating a ram and boot disk for the new kernel.

+   4. Install the new kernel in the LILO configuration, leaving the new kernel in place.
