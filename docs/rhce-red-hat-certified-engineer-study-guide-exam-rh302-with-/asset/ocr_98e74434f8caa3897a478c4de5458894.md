You change the current directory by issuing the cd command. For
example, the command

```
cd /home/fred
```

makes the directory /home/fred the current directory.
Notice that Unix directories are named by using a forward slash (/
to separate the components of the path. You'll learn more about Unix
directories shortly.

If you issue the cd command without an argument, your home directory
comes the current working directory.

# cp

The cp command copies files. You can use it to copy a single file. For example,
the command

```
cp filex file
```

copies filex to filey. You can also use the cp command to copy a set of
files. For example, the command

```
cp filex file folder1
```

copies filex and filey to folder1.

# find

The find command helps locate a file. The find command provides
many ways of finding files, but it's most used to find a file by name.
This is helpful when you have many directories, and you're unsure which
directory contains the file. For example, the command

```
find /home/fred -name filex
```

will tell you what folder within the directory /home/fred contains the file
flex.
If you don't know the name of the file, but you know a string contained
within the filename, you can use a command such as:

```
find /home/fred -name *file*
```

This command will find all the files whose filenames contain the characters
ile reside in /home/fred and its subdirectories.
