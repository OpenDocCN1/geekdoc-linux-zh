# Network Information Service (NIS)

NIS is not highly secure; for example, a user with access to an NIS server can obtain the complete contents of the server's NIS maps. Sun's NIS+ facility is more secure. However, Red Hat Linux supports only NIS+ clients; NIS servers are not supported.

The Red Hat Package Manager (RPM) packages related to NIS are:

- ybind, the NIS client
- ypserv, the NIS server
- yp-tools, useful NIS tools and utilities

In addition, NIS requires the portmap service. The file /etc/nsswitch.conf specifies the NIS configuration. An NIS server stores information about the domain in /var/yp/domain; NIS clients store information in /var/yp/binding.
You can easily determine whether a host is managed by NIS. Issue the command

domainname

If the host is part of an NIS domain, the command will report the name of the domain.

# NIS Commands

Among the most important commands and programs used by an NIS client:

- ybind: Finds NIS information and stores it in /var/yp/binding
- ypwch: Returns the name of the NIS server
- ypcat: Prints keys in the specified map
- yppoyll: Prints the version number of the specified map, and identifies the server on which the map resides
- ypmatch: Prints selected keys of the specified map
- yppassword: Changes NIS passwords

Among the most important commands and programs used by an NIS server are:

- ypserv: The executable name of the NIS daemon
- makedbm: Makes a map database from a text file
- yppush: Notifies slave servers of map updates
- yppasswdd: The daemon that handles NIS password changes

For more information on these commands, see the associated man pages.

# Lightweight Directory Access Protocol (LDAP)

The Lightweight Directory Access Protocol (LDAP) provides databases that can store arbitrary information. Consequently, LDAP can serve a variety of uses. Among them, LDAP can provide a more secure alternative to NIS when combined with Secure Socket Layer (SSL). For example, LDAP with SSL features encrypted data transfer and Access Control Lists (ACLs) to specify which users can access information stored in an LDAP database. Unlike NIS, which relies on refresh intervals to inform slave hosts of changes to stored maps, LDAP can push database updates to clients. LDAP is contained in the package openldap, which provides

slapd The LDAP daemon that runs on port 389
slur An LDAP daemon that replicates an LDAP database

The main LDAP configuration file is /etc/openldap/slapd.conf. For more information on LDAP, see the files in /usr/doc/openldap-* and the documentation available on the LDAP Web site, www.openldap.org. Also see the following pages pertaining to LDAP:

- centipede
- chlog2replog
- edb21dif
