# Other Options

Several other configuration option screens are available. These include:

+   - Character Devices Options. The menuconfig utility presents them as a single screen; xconfig presents them as a series of screens:
- Character Devices, which lets you configure options related to virtual terminals, multi-port serial cards, and other character-mode devices.
- Mice, which lets you configure mouse options.
- Watchdog Cards, which lets you configure options for special watchdog timer cards.
- Video for Linux, which lets you configure options for radio and TV cards.
- Joystick Support, which lets you configure joystick options.
- Floppy Tape Support, which lets you configure support for tape drives that use a floppy disk interface. The menuconfig utility presents these options as part of the Block Devices screen.
- File System and Partition Options. The menuconfig utility presents these as a single screen; xconfig presents them as a series of:
- File Systems, which lets you configure support for file systems.
- Network File Systems, which lets you configure support for network systems.
- Partition Types, which lets you configure support for non-Linux (that is, non-MS-DOS) partition tables.
- Native Language Support, which lets you configure support for native language extension.
- Console Drivers, which lets you configure options related to the console and frame buffer devices.
- Sound, which lets you configure support for sound. The menuconfig utility presents these as a single screen; xconfig presents them as a series of screens:
- Sound, which lets you configure support for sound.
- Additional Low-Level Sound Drivers, which lets you configure drivers for sound cards.
