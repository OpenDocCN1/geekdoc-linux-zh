# # Sharing Data

Often, users need to share data that they don't want others to be able to access or modify. A simple way of accomplishing this is to create a group for each set of users who want to share access to data, assign group ownership of the related files or directories to the new group, then assign access permissions to the group to perform authorized operations but exclude others from doing so.

For example, suppose tom and harry want to access the directory bigdata, but to prohibit access by others. You could create a group named tdanh (as a reminder of its members) and set the group ownership of the bigdata directory to tdanh. Assign permissions of 770 to the directory, and you have the desired result.
