# FIGURE 26.10 The Xconfigurator ClockChip Configuration screen

![](bbox=[0.328, 0.137, 0.891, 0.403])

Generally, you should select the No ClockChip setting because the X server can probe to determine the ClockChip setting. However, some cards cannot successfully probe; this lets you around this problem. If you selected the proper ClockChip setting, click the OK button. If you selected No Clockchip, the Probe for Clocks screen, shown in Figure 26.11, will appear; otherwise, the Select Video Modes screen, shown in Figure 26.12, will appear.

# FIGURE 26.11 The Xconfigurator Probe for Clocks screen

![](bbox=[0.328, 0.596, 0.891, 0.866])

For Probe for Clocks screen, click the OK button to begin the probe. The Select Video Modes screen, shown in Figure 26.12, will appear.
