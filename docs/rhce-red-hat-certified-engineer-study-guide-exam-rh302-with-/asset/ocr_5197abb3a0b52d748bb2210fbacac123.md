# The Kernel Source Tree

As explained, the RPM packages that contain the Linux kernel source install their files in the `/usr/src` directory. The binary RPMs place their files in the `linux-version` subdirectory—for example, `linux-2.4.2`—and the (optional) source RPM places its files in the `redhat` directory. As a convenience, the installation script of the `kernel` package provides the symbolic link `/usr/src/linux`, which refers to the `/usr/src` directories; The directory contains about two dozen files and directories; Table 17.2 describes several of its most important ones.

# TABLE 17.2 Important Files and Directories in /usr/src/linux

| File or Directory | Description |
|---|---|
| i386/config.ini | Current kernel configuration options, written by the kernel configuration program or script |
| i386/boot/bzImage | Compiled kernel image |
| Documentation | Directory containing a variety of useful documentation |
| README | README file for the Linux kernel |
