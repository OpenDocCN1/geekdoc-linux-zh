# Important X Directories and Files

The /usr/X11R6/usr/X11R6/bin directory contains X binaries. For X programs to operate correctly, the /usr/X11R6/bin directory should appear on the program path, stored in the PATH environment variable.
Another important X directory is /etc/X11. Its subdirectories contain the X configuration. The symbolic link /etc/X11/R points to the currently selected X server, which resides in /usr/X11R6/bin. The /etc/X11 directory also contains the XF86Config file, the main configuration file, which is generally built by using Xconfigurator or FX86Setup. For more information about the /etc/X11/FX86Config file, see the FX86Config page.
