To determine which daemons are currently running or which daemons will be started by inet, issue the command

```
netstat -ap --inet | grep LISTEN
```

This command reports the port number or name of the associated service and the process number and name of the process currently listening on the port. If the listening process is inet, this indicates that the service will be started by inet when needed, in the following output from the netstat
