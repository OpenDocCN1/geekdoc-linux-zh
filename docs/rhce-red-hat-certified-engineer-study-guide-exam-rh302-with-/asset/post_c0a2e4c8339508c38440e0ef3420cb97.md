# Glossary

# A

**a.out** The out is an object file format popular in early Linux versions.

# B

**base i/o address** A base i/o address is the beginning address of a memory buffer that is used to communicate with a device interface.

**bind-listen-connect-accept process** The bind-listen-connect-accept process is a process followed by TCP servers for listeners and clients requests.

**block device** a block device is a device that sends many characters in response to a single input-output request. Common block devices include disk and CD-ROMs. *See device*.

**boot argument** a boot argument is an argument supplied at boot time and by shell or passed to the kernel or to the init process.

**boot loader** a boot loader is a program, such as the shell boot loader, that loads the first stage of an operating system into memory.

**boot prompt** a boot prompt is the prompt provided by a boot loader, such as shell, where the user can specify a boot image to be loaded and boot arguments to be processed.

**BOOTP** BOOTP is a common protocol that lets a server assign an IP address and other network configuration information to a client.

**broadcast message** a broadcast message is a message sent to all hosts on a local network.

**browse server** the browse server is the SMB (System Message Block) server on a network that provides clients with information about available servers and shares.

**build number** the build number is a number that indicates the sequential number of a software build and, therefore, signifies the patches and options specified in a build program.

**bus** the build number is a number that indicates the sequential number of a software build and, therefore, signifies the patches and options specified in a build program.

# C

**canonical name** a canonical name is a name that follows a standard.

**capability** a capability is a permission granted to a process.

**certification** certification is the process of verifying that something meets standards.

**character device** a character device is a device that transfers data one character at a time.

**chooser** a chooser is a tool for selecting an option.

**compiler** a compiler is a program that translates source code into machine code.

**component** a component is a part of a larger system.

**connectionless protocol** a connectionless protocol is a protocol that does not require a handshake.

**copyleft** copyleft is a license clause that ensures software remains free.

**cron** cron is a time-based job scheduler in Unix.

**crontab** a crontab is a file used to schedule cron jobs.

**current working directory** the current working directory is the directory where the user is currently working.

# D

**daemon** a daemon is a program that runs in the background.

**default route** a default route is a route used by a router when no specific route is found.

# E

**dependency** a dependency is a requirement for another program.

**dynamic loader** a dynamic loader is a program that loads shared libraries at runtime.

**dynamic routing** dynamic routing is a process where routing information is updated.

**desktop manager** a desktop manager is a graphical interface for managing the desktop.
