# Using the Unix Command Line

Those who've worked only with graphical user interfaces (GUIs) are sometimes shocked to discover that the Unix graphical user interface, X, is not always available. Some Unix systems, especially network servers, may not have X installed at all. Moreover, even if X is installed, X may not operate if the system is misconfigured. Consequently, Red Hat Linux administrators must be familiar with the Unix command line.
