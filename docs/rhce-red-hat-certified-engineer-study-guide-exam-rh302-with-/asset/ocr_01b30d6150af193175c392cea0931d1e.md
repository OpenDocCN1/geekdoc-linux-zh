# # Deleting Group

To delete a group using userconf, follow this procedure:

+   1. Launch userconf.
2. Choose Group Definitions and press Enter; or, if you're using X, click Group Definitions.
3. Select the group you want to delete and press Enter; or, if you're using X, click the group. The Group Specification screen will appear.
4. To delete the group, click the Del button. A dialog box will ask you to confirm the operation; click Yes to delete the group or No to abort the deletion.

Depending on the filter settings (in Control ➤ Features), you may see a Filter dialog box. Use the dialog box to limit the user groups to you want to see, or press Accept to view all groups. The Users Groups screen will appear.

# # Modifying Group Membership

You can modify group membership by modifying each affected user account or by modifying the group. Generally, it's more convenient to modify the group. To do so perform the following steps:

+   1. Launch userconf.
2. Choose Group Definitions and press Enter; or, if you're using X, click Group Definitions.

Depending on the filter settings (in Control ➤ Features), you may see a Filter dialog box. Use the dialog box to limit the user groups you want to see, or press Accept to view all groups. The Users Groups screen will appear.
