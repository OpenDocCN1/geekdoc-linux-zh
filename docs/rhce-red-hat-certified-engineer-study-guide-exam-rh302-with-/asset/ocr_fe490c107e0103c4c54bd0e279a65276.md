# TABLE 26.1 X Servers (continued)

| X Server RPM Package Name | Description |
|---|---|
| XFree86-8514 | Server for the IBM 8514 video cards and compatibles, such as those made by ATI. |
| XFree86-AGX | Server for the AGX video card. |
| XFree86-FBDev | Server for the generic frame buffer device. |
| XFree86-I128 | Server for devices such as the Number Nine 128. |
| XFree86-Mach32 | Server for devices built around the Mach32 chip. |
| XFree86-Mach64 | Server for devices built around the Mach64 chip. |
| XFree86-Mach8 | Server for devices built around the Mach8 chip. |
| XFree86-Mono | Generic monochrome server that works with nearly all VGA devices. |
| XFree86-P9000 | Server for devices built around the Weitek P9000 chip. |
| XFree86-S3 | Server for devices built around the S3 chip, including most Number Nine cards, many Diamond Stealth cards, Orchid Fahrahrents, the Miro Crystal 85, most STB cards, and some motherboards with built-in graphics accelerators, such as IBM ValuePoint PCs. |
| XFree86-S3V | Server for devices built around the S3 Virge chip. |
| XFree86-SVGA | Server for simple frame buffer SVGA devices, including cards built from ET4000 chips, Cirrus Logic chips, and Technologies laptop chips, Trident 8900 and 9000 chips, and Matrox chips. It also works for Diamond Speedstar, Orchid Kelvins, STB Nitros and Horizons, Genoa 8500VL, most Actix boards, and the Spider VLB Plus. It works with many other SVGA devices as well. |
| XFree86-VGA16 | Generic 16-color server that works with nearly all VGA devices. |
