## Configuring Authentication

The Red Hat installation program lets you to configure several authentication options. During installation you can implement the following options:

- Enable or disable shadow passwords
- Set a password for the root user
- Enable or disable creation of MD5 passwords

After installation, you can still easily enable or disable shadow passwords, set a new password for root, or enable or disable creation of MD5 passwords. The following sections show how this can be done.

## Shadow Passwords

You convert to and from shadow passwords after installation is completed. Recall when shadow passwords are enabled, encrypted passwords are stored in a file (/etc/shadow) that is readable by root. The /etc/shadow file contains several fields in addition to the encrypted password:

- the date that the account was disabled, given as the number of days since January 1970
- the date that the password was last changed, given as the number of days since January 1970
- the number of days after which the password must be changed
- the number of days before password expiration that the user is warned
- the number of days after password expiration that the account is disabled

Enabling shadow passwords improves system security. However, a handful of old programs may not function correctly if shadow passwords are enabled.

To enable shadow passwords, issue the command `pwconv`

To disable shadow passwords, issue the command `pwunconv`
