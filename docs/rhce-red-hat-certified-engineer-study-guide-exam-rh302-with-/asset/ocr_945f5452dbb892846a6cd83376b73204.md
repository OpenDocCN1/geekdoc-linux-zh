# /tmp: Temporary Files

The /tmp directory contains temporary files and subdirectories that are automatically deleted by the tmpwatch utility when they’ve not been used for a specified period of time (by default, 10 days).

# /usr: Shareable Files

The /usr file system may not be available, so it contains no files or directories that are essential for system operation. Normal operation of the system does not require modification of files in /usr, so its contents are shareable; often, for example, the /usr partition is an NFS-exported partition that resides on a remote system.
