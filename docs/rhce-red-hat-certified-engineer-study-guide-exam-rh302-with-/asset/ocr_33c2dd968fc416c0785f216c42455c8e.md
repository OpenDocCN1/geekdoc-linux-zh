# Important Files When a system does not boot properly, you can boot it in single-user mode and check the following configuration files as possible causes of the problem:

+   - /etc/conf.modules
- /etc/fstab
- /etc/initabb
- /etc/lilo.conf
- /etc/rc.d/*
- /etc/yp.conf, if the system uses NIS

Checking File Systems To check a Linux native file system for errors, to repair errors, use the efsck utility. When invoked with appropriate options, the ffsck utility invokes efsck.

Leaving Rescue Mode The usual shutdown commands are not available in rescue mode. You must issue the sync and unmount commands shutting down a system operating in rescue mode.
