# CPU Architectures and Symmetric Multiprocessing

Although originally implemented for the Intel x86 central processing unit (CPU) architecture, Linux now runs on a variety of architectures, including:

+   - Acorn
- ARM
- Compaq (DEC) Alpha
- Motorola 68k
- MIPS
- Power Mac
- PowerPC
- Sun SPARC

However, Red Hat Linux supports only the Compaq Alpha, Intel, and SPARC architectures Linux includes multiple CPUs. However, the standard Red Hat Linux kernel is not SMP enabled. If your system is SMP-capable, the installation program will install both the standard kernel and a special SMP kernel; the SMP kernel will be enabled, even if only one CPU is present.

Linux SMP supports many as 16 processors; however, the Intel architecture supports no more than 8. Figure 2.1 illustrates how SMP performance varies with the number of processors. As you can see, the performance increase slows after the addition of four processors.
