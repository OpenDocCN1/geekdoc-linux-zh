# Installing and Configuring Mail Services

Mail service is ubiquitous, so every system administrator must be familiar with the installation and configuration of mail. Perform these steps to get first-hand experience with mail:

+   1. Install all three sendmail packages and the IMAP/POP package.
2. Use mailconf to specify the systems for which mail will be accepted.
3. Use mailconf to specify several user mail aliases.
4. Use a mail client, such as pine, to verify that your mail configuration operates properly.

You can refer to this book for help configuring mail. However, before taking the RHCE exam, be sure you can perform simple mail configuration operations such as without the aid of books or notes.
