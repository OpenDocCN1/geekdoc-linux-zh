# The swatch Utility

When a system is busy, log files can rapidly become large, and therefore, too-consuming to examine manually. The swatch utility, distributed as part of the Red Hat PowerTools collection, monitors logs and can specify action when a given type of event message is logged. For example, swatch can send an e-message, call a pager, and so on. A similar utility, logwatch, is also distributed as part of the Red Hat PowerTools collection. The logwatch utility can process logs as well as system logs.
