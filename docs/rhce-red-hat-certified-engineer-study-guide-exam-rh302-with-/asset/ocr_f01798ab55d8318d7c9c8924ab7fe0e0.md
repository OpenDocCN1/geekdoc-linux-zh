# The lilo Command

The lilo command installs the LILO boot loader and updates the boot map. Normally, you perform these operations by issuing the command

```
/sbin/lilo
```

However, when operating in rescue mode, the root file system of the local hard disk is not mounted as the root directory. Running lilo in the usual way would not properly update the /boot directory of the local hard drive. Instead, you should issue a command of the form

```
/sbin/lilo -r path
```

where path is the current mount point of the root file system of the local hard drive. For example, if the root file system of the local hard drive is mounted as /mnt/hd, issue the command

```
/sbin/lilo -r /mnt/hd
```
