# The Symbolic Links in /etc/rc.d/rc?.d

The symbolic links in /etc/rcd/rc?.d have names as K05keytable and S40atd. Links having names beginning with K are passed the stop argument when they are executed by /etc/rc.d/rc; having names beginning with S are passed the start argument. Generally, the directory associated with a runlevel will include either a K script or an S script for each installed.
The two-digit number in the script names, called the priority, indicates the sequence in scripts in a given directory are run; for example, the script K10ufs runs before the script K15gm. Table 14.3 summarizes runlevel scripts according to the runlevels at which they're executed.
