# TABLE 15.6 Mount Options

| Option | Description |
|---|---|
| async | Perform all input and output asynchronously. |
| atime | Update inode access times on the file system. |
| auto | Automatically mount the file system in response to mount -a. |
| defaults | Enable the options rw, suid, dev, exec, auto, mouser, and async. |
