# 402 Chapter 17 • Understanding the Kernel

Linux kernels are released via the Linux Kernel Archive Web site, www.kernel.org. Red Hat, Inc. downloads released kernels and repackages them RPMs for easy distribution and installation. Red Hat, Inc., specially configures the kernel and applies patches that modify and extend functionality.

In addition to the major-patch versioning of Linux kernels, Red Hat, Inc. encourages use of what they call the extraversion code, which distinguishes differently configured versions of the same kernel release. As explained in the next chapter, you can specify an extraversion code when you build a Red Hat Linux kernel. The extraversion code takes the form of a sequential number and a short descriptive name. For example, build #20 of a Linux 2.4.6-20smp. Using the extraversion code facilitates having several Linux kernels on a single system. When you build a new kernel you can keep a copy of the old kernel on the system. That way, if the new kernel fails to operate properly, you can simply reboot the system using the old kernel, rather than perform more elaborate-rate recovery operation.

Many Red Hat Linux users and system administrators may need to compile a Linux kernel. Instead, they download and install kernel updates in package form. However, you may want to build a custom kernel for reasons such as:

+   - You want to configure an especially secure system and therefore want to disable unnecessary capabilities that might present security risks. For example, you plan to use a Linux system as a router and therefore don't need or want some of the capabilities included in the standard Red Hat Linux kernel.

+   - You want to enable capabilities not available in the standard Red Hat Linux kernel, such as advanced routing options.

+   - You want to alter parameters not configurable during operation. For example, you want to use more than 1GB of RAM and therefore need to reconfigure the balance between user-space and kernel-space memory.

+   - You're curious to learn more about the Linux kernel. Building a custom kernel is a good way to do so.
