You can also verify the status of every installed package. To do so, issue
the command

```
rpm --verify -a
```

# Verifying Package Authenticity

GNU Privacy Guard (GPG) is an open source program similar to the more
familiar Pretty Good Privacy (PGP) program, which lets you authenticate
electronic documents. Authors of RPM packages can sign their work with a
GPG key. If you've installed the GPG package, you can verify the authenticity
of a signed package file. To do so, issue a command of the form

```
-K package_file_name
```

where package_file_name is the name of the package file. You'll need
download and install Red Hat, Inc.'s GPG key; you can find the key on the
Contacts page of your web site, www.redhat.com.

![](bbox=[0.137, 0.483, 0.203, 0.526])

Owning to US export restrictions, Red Linux does not include PGP. You'll
have to obtain it from another source, as www.zedz.net.

# Performing Advanced Queries

The rpm command includes an option that lets you query the RPM database
for specific items of information, which you specify by means of the-
queryformat flag. For example, the following command prints the name and
size of every installed package, sorted by name:

```
# rpm -qa --queryformat "%-32(NAME)\%%10(SIZE)\
" | sort
AfterStep 4248520
AfterStep-APPS 1104878
AnotherLevel 295682
ElectricFence 45648
ImageMagick 3098739
MAKDEV 35719
MySQL 16898048
MySQL-client 7172590
MySQL-devel 2188430
MySQL-shared 569920
ORBit 892530
```
