48. B, D. The xvidtune and xf86config tools let you specify operating characteristics that can damage a monitor. In the case of xf86config, any damage will occur after the tool is run, since the tool itself operates only in text mode. See Chapter 26 for more information.

50. B, D. The clean argument deletes the results of previous builds and the dep argument propagates configuration information. Either may occur before the other; both should precede the bzImage. Option A fails to propagate the configuration through the source tree and Option A or C fails to remove the results of previous builds. Either might work under special circumstances, but generally you should use the commands given in B or D. See Chapter 18 for more information.
