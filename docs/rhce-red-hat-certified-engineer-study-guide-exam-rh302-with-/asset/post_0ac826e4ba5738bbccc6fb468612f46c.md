## Activating Changes

As explained earlier, when you change a option using linuxconf, the change may occur immediately, or it may remain pending until the change is activated. Although configuration files are updated immediately, most services will not detect changes in their configuration until restarted. When you instruct linuxconf to activate pending changes, restarts those whose configurations you've changed.

If you want to know what changes are pending, click Preview What Has Been Done. The linuxconf program displays the pending changes. To activate pending changes, click Activate. To exit the Status of the System screen without activating any pending changes, click Quit.

You should generally activate pending changes before exiting linuxconf. If you neglect to do so, linuxconf will prompt you to confirm that you want to exit without activating the changes.

## Summary

In this chapter, you learned about configuring install-time options for installation been completed. The most important topics are covered:

- **Keyboard**: After installation, you can configure the keyboard using the kbdconfig program.
- **Mouse**: After installation, you can configure the mouse using the mouseconf program.
- **Time Zone**: After installation, you can configure the time zone by using the timeconf program.
- **Sound**: After installation, you can configure sound using the sndconfig program.
- **Default Run Level**: After installation, you can configure the default run-level using the `linuxconf` program.
- **Authentication**: After installation, you can configure shadow passwords by using the `pwconv` or `punconv` program or change the `root` password by using the `linuxconf` program.
- **LILO Options**: After installation, you can configure LILO options by using the `linuxconf` program.
- **Networking**: After installation, you can configure networking by using the `linuxconf` program.
