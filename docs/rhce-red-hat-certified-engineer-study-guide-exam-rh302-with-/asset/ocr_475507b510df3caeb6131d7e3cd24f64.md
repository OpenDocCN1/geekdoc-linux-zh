# Creating and Modifying POP User Accounts

POP user accounts are used by users who access mail via POP from a remote
location. POP users don't actually log in to the system, so the POP User
Accounts screen doesn't include the Command Interpreter field. By
default, POP users are members of the popusers group.
To create a POP user account the following:

+   1. Launch userconf.

+   2. Choose POP Accounts and press Enter; or, if you're using X, click
POP Accounts. The Users Accounts screen will appear.

Depending on the filter settings (in Control ➤ Features), you may see
a Filter dialog box. Use the dialog box to limit the user accounts to
th you want to see, or press Accept to view all accounts.

+   3. Click the Add button. The User Account Creation screen will appear.

+   4. Fill in the parameter fields. Refer to Tables 10.1 and 10.2 for information
e each field.

+   5. Click the Accept button. The Changing Password dialog box will appear.

+   6. Type the desired password, and click the Accept button. The Chang-
ingPassword box will reappear.

+   7. Confirm the password you previously entered by retyping it. Click the
Accept button. The Users Accounts screen will appear.

+   8. When you're done administering POP user accounts, click the Quit button.
To modify a POP user account follow these steps:

+   1. Launch userconf.

+   2. Choose POP Accounts and press Enter; or, if you're using X, click
POP Accounts. The Users Accounts screen will appear.

Depending on the filter settings (in Control ➤ Features), you may see
a Filter dialog box. Use the dialog box to limit the user accounts to
th you want to see, or press Accept to view all accounts.
