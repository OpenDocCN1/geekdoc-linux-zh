# Administering User Accounts via the userconf Tool

The easiest way to administer user accounts is via the userconf tool, because it automatically performs several otherwise tedious operations. You can launch the userconf tool by issuing the command

userconf

Figure 10.1 shows the userconf menu running from a console. If you prefer, you can run userconf from X, in which case the menu has a somewhat different appearance.
