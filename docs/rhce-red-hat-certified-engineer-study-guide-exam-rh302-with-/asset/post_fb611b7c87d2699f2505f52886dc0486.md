
## Glossary

**forwarding** Forward is the process whereby packets received on a network interface are routed to the proper outgoing network interface.

**host name** The host name of a system is a name assigned by the system administrator. The host name must be unique within a domain.

**FSF** The Free Software Foundation (FSF) sponsors the GNU project and other open-source software projects.

**image file** An image file is a file that contains data that can be used to write the contents of a disk, especially a boot disk.

**fully qualified name** A fully qualified domain name is the combination of a host name and a domain name. It uniquely identifies a host.

**installation class** Red Hat lets you choose from four installation classes: GNOME workstation, KDE workstation, server, or custom.

# G

**installation path** Red Hat lets you choose from two installation paths: install or upgrade.

**gateway** A gateway is a router that provides access to a network or the Internet.

**installation type** Red Hat lets you choose from two installation types: graphical and text-based.

**GNU project** The GNU (GNU is not Unix) project was initiated to create an open-operating system resembling Linux. Linux is distributed with many programs developed under the auspices of the GNU.

**Intel architecture** Computers that have the Intel architecture are often referred to as IBM-compatible computers.

**GPL** The GNU (General Public License) is intended to preserve the freedom to use, copy, and modify software.

**interior routing protocol** An interior routing protocol is a routing protocol used for within an autonomous network.

**grace period** When a user has exceeded the assigned disk quota, the user may have a grace period during which the quota is not enforced. However, after expiration of the grace period, the user cannot access additional disk space.

**i/o port** An i/o port is a special address reserved by IBM-compatible PCs for communicating with hardware devices.

**graphical mode installation procedure** Red Hat Linux can be installed using a graphical installation procedure that provides a point-and-click interface.

**IP address** An IP is a 32-bit number that uniquely identifies an Internet host.

**group quota** A group quota is a disk space quota assigned to a group, rather than an individual user.

**IRQ** An Interrupt Request Queue (IRQ) is a hardware facility capable of handling signals sent by a device.

# H

**kernel** The kernel is a fundamental component of an operating system. Red Hat Linux is named for its kernel, the Linux kernel.

**hard limit** The hard limit is the maximum amount of disk space a user can allocate.

**key** A key is a string of text used by a cryptographic program as an access code.

**horizontal sync rate** The horizontal sync rate of a monitor is a crucial operating parameter. A monitor can be damaged by operating it in an inappropriate horizontal sync rate.

**kickstart installation** A kickstart installation proceeds—to the extent possible—without manual intervention. A special script controls the installation.

**host address** The host address, or IP address, of a system uniquely identifies the system.

# L

**LDAP** Lightweight Directory Access Protocol (LDAP) can be used to centrally store and manage user accounts associated with a network.

**minor version** The minor version of the kernel changes more rapidly than the major version. Any minor version is assigned to a stable kernel; an old minor version is assigned to a development kernel.

**library** A library is a file that contains objects—called objects—that can be combined with other object modules to form programs.

**modular** A modular kernel consists of multiple components, called modules, of which can be loaded dynamically. See monolithic.

**linker** A linker is a program that can be used to combine object modules and library members to form programs.

**module** A module is a part of the Linux kernel, such as a driver, that can be loaded dynamically.

**link-state protocol** A link-state protocol is a routing protocol that maintains a map—or, at least, a partial map of the network.

**monolithic** A monolithic kernel consists of a single unit that is loaded at all. See modular kernel.

**Linux** Linux is a largely POSIX-compatible, open-operating system that includes the Linux kernel and GNU utilities.

**mount point** A mount point is a directory that is associated with a file system.

**load1** The load1 program, which runs under DOS, can boot Linux without the binary of ISIS.

**multi-boot** A multi-boot installation is one that you choose from one of several systems at boot time.

**log rotation** Log rotation is a process by which the amount of disk space devoted to files is managed. Log rotation involves keeping a series of log files for a period of time.

# N

**network address** The network address is the portion of an IP address that is the same for all hosts on a given network.

**network class** Network class is a designation that describes how a network address can be derived from an IP address. For example, the first 24 bits of an IP address from a C class make it a network.

**network installation** A network installation is one in which the distribution method resides on a remote server.

**NIS** Network Information Service (NIS) centrally stores and maintains network information, such as user accounts.

**NNTP** Network News Transport Protocol (NNTP) is a protocol for synchronizing Internet news groups.

**non-privileged port** A non-privileged port is one that has a number from 1024 to 65535. Any process can access an available port.

**NTP** Network Time Protocol (NTP) is a method for synchronizing time.

**logical block** A logical block is a number that denotes a sector of a disk drive. The geometry of disk units ensures that Linux can access them most effectively using logical block addresses rather than cylinder-header-sector addresses.

**logical partition** A logical partition is contained within an extended partition.

# M

**machine language** Machine language is the set of codes understood by the processor.

**major version** The major version of the kernel changes less rapidly than the minor version.

**map** NIS (Network Information Service) databases that contain information are mapped.

**masquerading** Masquerading specifies an IP address in place of.

# O

**object code** Object code is an intermediate format between source code and machine language.

**octet** An octet is a series of eight digits.

**ordinary user** An ordinary user is a user other than root.

**OSS** Open Source software (OSS) is software that is distributed in source format.

# P

**package** A package is a set of files—including programs, configuration files, and data files—that make up a unit.

**package file** A package file is a file that contains a package.

**package group** A package group is a set of packages that are related in some way.

**packet filter** A packet filter is a facility for blocking packets that matched specific criteria.

**PAM** Pluggable Authentication Module (PAM) is a Red Hat Linux facility that makes it possible to configure security-related options.

**partition** A partition is a region of disk space allocated to hold a file system.

**partition type** A partition type is a number that represents the type of file system that partition is intended to hold.

**patch level** The patch level of a region or the Linux kernel is the sequential number of the latest applied.

**path** A path is a series of directories; each directory in the path contains the following directory.

**performance-based exam** A performance-based exam requires an examinee to demonstrate a skill, rather than answer questions.

**plug and play** Plug and play is a BIOS and operating system facility to simplify the installation of devices.

**POP user** A POP user is a user authorized to access e-mail via POP, but not authorized to log in.

**port** A port is a facility for TCP/IP communications. Ports are numbered from 0–65535.

**PPP user** A PPP user is a user authorized to log in via PPP.

**primary boot loader** The primary boot loader is the first loader that executes when the system is booted.

**primary partition** A primary partition is allocated to hold a file system. See extended partition and logical partition.

**priority** Priority is a number that specifies the sequence in which a start-up process will be executed, or a priority that determines which among the ready processes will gain access to the processor and execute.

**privileged port** A privileged port is one numbered 0–1023; only a privileged process can access a port. See port and non-privileged port.

# R

**rewrite** The rewrite program is a DOS program that allows you to write a link from image.

**Red Hat Certified Engineer (RHCE)** A Red Hat Certified Engineer has passed the RHCE exam, which assesses skill in performing Red Hat Linux system administration tasks.

**Red Hat Hardware Compatibility List** The List identifies hardware that is compatible with Red Hat Linux and qualitatively describes the degree of compatibility.

**Red Hat, Inc.** Red Hat, Inc. is the company that created and distributed Red Hat Linux.

**regular expression** A regular expression is a string that sets a set of strings to match to the regular expression.

**Rescue mode** Rescue mode is a special mode that provides help that you repaired a damaged system.

**reverse zone** A Domain Name Service (DNS) configuration file maps IP addresses to host names. See forward zone.
