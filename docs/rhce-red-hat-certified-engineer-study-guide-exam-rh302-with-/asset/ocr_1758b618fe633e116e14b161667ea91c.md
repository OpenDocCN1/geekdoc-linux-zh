# The System crontab

In addition to the user crontab files stored in /var/spool/cron, the cron system has a cron file, stored in /etc/crontab. Here are the contents of a typical /etc/crontab file:

```
SHELL=/bin/bash
PATH=/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=
HOME=
```
