# The /etc/rc.d/rc.local Script

The /etc/rc.d/rc.local script is a special run run by symbolic links in the directories associated with runlevels 2, 3, and 5. Its start point is 99, which means it runs after all other runlevel scripts. By default, it creates

+   * /etc/issue file
* /etc/issue.net file

The /etc/issue file is listed when a user logs in by using a local console. By default, the file reports the release of Red Linux and the kernel version:

Red Hat Linux release 6.0 (Hedwig)
Kernel 2.2.25-15 on an i686

The /etc/issue.net file is listed when a user logs in by using a remote console—for example, by initiating a Telnet session. By default, the file reports the release of Red Linux and the kernel version:

Red Hat Linux release 6.0 (Hedwig)
Kernel 2.2.25-15 on an i686
