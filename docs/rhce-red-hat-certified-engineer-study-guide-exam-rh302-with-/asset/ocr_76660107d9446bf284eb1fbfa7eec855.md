# The KDE Desktop Manager

The KDE desktop manager provides features and facilities similar to those provided by GNOME. Unlike KDE, which uses the separate Enlightenment window manager, KDE has its own window manager, KWM, which is the most popular window manager for use with KDE; KDE is also compatible with such window managers as AfterStep, Enlightenment, and WindowMaker.
