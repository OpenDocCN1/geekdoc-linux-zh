# Glossary

**octet** An octet is a series of eight binary digits (bits).

**ordinary user** An ordinary user is a non-privileged user, that is, a user other than root.

**OSS** Open Source software (OSS) is software that is distributed in source format that it can be understood and modified.

# P

**package** A package is a set of files—including programs, configuration files, and data files—that make up a software program or a set of related programs that are installed as a unit.

**package file** A package file is a file that contains a package.

**package group** A package group is a set of packages that are related in some way.

**packet filter** A packet filter is a facility for blocking packets that matched specific criteria.

**PAM** Pluggable Authentication Module (PAM) is a Red Hat Linux facility that makes it possible to configure security-related options of PAM-aware programs.

**partition** A partition is a region of disk space allocated to hold a file system.

**partition type** A partition type is a number that represents the type of file system that a partition is intended to hold.

**patch level** The patch level of a region or the Linux kernel is the sequential number of the latest applied patch.

**path** A path is a series of directories; each directory in the path contains the following directory in the series.

**performance-based exam** A performance-based exam requires an examinee to demonstrate a skill, rather than answer questions.

**plug and play** Plug and play is a BIOS and operating system facility to simplify the installation of devices.

**POP user** A POP user is a user authorized to access e-mail via POP, but not authorized to log in.

**port** A port is a facility for TCP/IP communications. Ports are numbered from 0–65535.

**PPP user** A PPP user is a user authorized to log in via PPP.

**primary boot loader** The primary boot loader is the first loader that executes when the system is booted.

**primary partition** A primary partition is allocated to hold a file system. See extended partition and logical partition.

**priority** Priority is a number that specifies the sequence in which a start-up process will be executed, or a priority that determines which among the ready processes will gain access to the processor and execute.

**privileged port** A privileged port is one numbered 0–1023; only a privileged process can access a port. See port and non-privileged port.

# R

**rewrite** The rewrite program is a DOS program that allows you to write a link from image.

**Red Hat Certified Engineer (RHCE)** A Red Hat Certified Engineer has passed the RHCE exam, which assesses skill in performing Red Hat Linux system administration tasks.

**Red Hat Hardware Compatibility List** The List identifies hardware that is compatible with Red Hat Linux and qualitatively describes the degree of compatibility.

**Red Hat, Inc.** Red Hat, Inc. is the company that created and distributed Red Hat Linux.

**regular expression** A regular expression is a string that sets a set of strings to match to the regular expression.

**Rescue mode** Rescue mode is a special mode that provides help that you repaired a damaged system.

**reverse zone** A Domain Name Service (DNS) configuration file maps IP addresses to host names. See forward zone.
