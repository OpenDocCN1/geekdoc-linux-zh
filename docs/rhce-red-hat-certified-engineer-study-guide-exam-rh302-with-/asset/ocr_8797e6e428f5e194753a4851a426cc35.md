/etc/shadow file contains several fields in addition to the encrypted password, including the following:

+   - the date that the account was disabled, given as the number of elapsed days since January 1, 1970
- the date that the password was last changed, given as the number of elapsed days since January 1, 1970
- the number of days after which the password must be changed
- the number of days before the password may be changed
- the number of days before password expiration that the user is warned
- the number of days after password expiration that the account is disabled

Enabling shadow passwords improves system security. However, a handful of old UNIX programs may not function correctly if shadow passwords are enabled.

To enable shadow passwords, issue the command
pwconv

To disable shadow passwords, issue the command
pwunconv
