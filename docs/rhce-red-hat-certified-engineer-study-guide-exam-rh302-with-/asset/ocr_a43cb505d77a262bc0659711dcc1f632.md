As a system administrator, you may need to perform package manipulation on systems that lack X, GnoRPM requires. For example, suppose you want to install X on a system; you cannot use GnoRPM, which requires X, to install X. Nevertheless, you should become familiar with GnoRPM in order to assist users who prefer using it to the command line. GnoRPM lets you do the following:

+   - Install packages
- Upgrade packages
- Query packages
- Verify packages
- Uninstall packages

In addition, GnoRPM includes an interface to the rpmfind command, which helps you find packages stored on Internet FTP sites.
You'll find GnoRPM easy to use. If you need help understanding its more advanced features, consult its documentation files, which reside in /usr/doc/gnorpm.
