Recall that you don't use the mouse to click buttons when performing a text mode installation. Use navigation keys to select the button, press Enter or the spacebar to click it.

If you select NFS, the NFS Setup screen, shown in Figure 8.2, will appear. Use this screen to specify the host name (or IP number) of the NFS server and the distribution of the exported directory that contains the RedHat subdirectory of the distribution CD-ROM.
