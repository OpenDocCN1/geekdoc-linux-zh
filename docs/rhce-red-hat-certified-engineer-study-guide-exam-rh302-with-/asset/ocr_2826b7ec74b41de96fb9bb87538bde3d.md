Installation Files The installation procedure can access installation files stored on a CD-ROM disk or hard drive. It can also access files via FTP, HTTP, or NFS.

Selecting Components and Packages You can select components, which are sets of packages, for installation on the target system. In addition, you can select or deselect individual packages.
