+   - Option lines of the form
  options module symbol=value

where module specifies the name of a module, symbol specifies an argument known to the module, and value specifies the value of the argument. Option lines specify arguments to be sent to modules. Multiple pairs of symbols and values can be specified; separate each pair from adjacent pairs by one or more spaces.

+   - Alias lines of the form
  alias alias_name actual_name

An alias line establishes an alias, or alternative name, for a module.

+   - Pre-install lines of the form
  pre-install module command

A pre-install line specifies a command to be executed before the specified module is installed.

+   - Install lines of the form
  install module command
