The following step-by-step explanation assumes that you're using Xconfigurator in ordinary mode—that is, neither quick nor expert mode.
Figure 26.1 shows the Xconfigurator welcome screen that appears when you launch Xconfigurator.Xconfigurator does not support the use of a mouse. Instead, you communicate with the program via the keyboard.
The following keys have special:

+   - Tab, Up, Down, Right, and Left are used to navigate from field to field; the current field is the one's highlighted.
- The Spacebar is used to toggle a radio button or check box.
- Enter is used to click the highlighted button.
