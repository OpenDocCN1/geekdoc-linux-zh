# Answers to Review Questions

+   1. A, B, C, D. A DHCP server can supply essentially all the elements of a complete network configuration.

+   2. A, A, B. The inn package provides the NNTP daemon, innd; the cleanfeed package provides a spam filter useful when running innd.

+   3. D. The rdate and nptdate programs set the time only once, when either is executed.

+   4. B. The squid proxy can run on any available port; but, by default, runs on port 3128.

+   5. A. Red Hat, Inc. formerly used PGP to sign RPM packages but now uses GnuPG.

+   6. B. Stratum 1 is the highest level of the synchronization hierarchy; stratum 0 does not exist.
