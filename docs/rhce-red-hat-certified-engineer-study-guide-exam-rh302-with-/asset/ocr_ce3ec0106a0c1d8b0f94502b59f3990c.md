The second indent NIS configuration file is /etc/yp.conf. Here are the contents of the /etc/yp.conf file as it is distributed with Red Hat Linux.

```
# /etc/yp.conf - ybind configuration file
# # Valid entries are
#
#domain NISDOMAIN server HOSTNAME
# Use server HOSTNAME for the domain NISDOMAIN.
#
#domain NISDOMAIN broadcast
# Use broadcast on the local net for domain
#
NISDOMAIN
#
#ypserver HOSTNAME
# Use server HOSTNAME for the local domain.
# IP-address of server must be listed in /etc/hosts.
#
```
