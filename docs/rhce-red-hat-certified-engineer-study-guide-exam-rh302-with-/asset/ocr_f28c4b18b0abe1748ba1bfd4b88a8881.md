Not all these services, nor the services listed in Table 4.1, are likely to be available on a given host.

# TABLE 4.1 Important TCP/IP Services and Their Port Numbers

| Port | Underlying Protocol | Service | Description |
|---|---|---|---|
| 7 | UDP/TCP | echo | Determines a remote host is accessible. |
| 9 | UDP/TCP | discard | Provides access to a service that discards its input. |
| 11 | TCP | systat | Shows active users. |
| 13 | UDP/TCP | daytime | Provides local time as an ASCII string. |
| 15 | TCP | netstat | Provides network performance statistics. |
| 17 | TCP | qd | Provides a “quote of the day.” |
| 18 | UDP/TCP | msp | Sends a simple message to a user. |
| 19 | UDP/TCP | charger | Sends a stream of characters. |
| 20 | TCP | ftp-data | Used by the File Transfer Protocol (FTP) service to send data. |
| 21 | TCP | ftp | Used by the FTP service to send control information. |
| 22 | UDP/TCP | ssh | Provides access to the secure shell service. |
| 23 | TCP | telnet | Provides access to the telnet remote shell service. |
