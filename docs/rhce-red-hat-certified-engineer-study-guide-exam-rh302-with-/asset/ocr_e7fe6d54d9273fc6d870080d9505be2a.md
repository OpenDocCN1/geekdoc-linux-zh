To authenticate the origin of the RPM packages, you must download the GNUPG package. Move to the directory containing the package, and install the package by issuing the following command

```
rpm -Uvh gnupg-*.rpm
```

Then, generate a key pair by issuing the following command

```
gpg --gen-key
```
