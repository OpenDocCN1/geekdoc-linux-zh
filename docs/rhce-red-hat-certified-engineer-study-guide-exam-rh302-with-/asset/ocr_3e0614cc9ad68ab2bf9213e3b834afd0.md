# Advanced Power Management (APM) Configuration

Advanced Power Management (APM) helps conserve electrical power. It is especially useful for battery-operated computers, such as laptops; however, many modern desktop computers support APM, which you can use to shut down peripherals aren't being used. When APM is used with a laptop and it detects low battery conditions, it dims the display, shows the CPU clock, and turns off peripherals to save power. The file /etc/sysconfig/apmd contains the APM configuration, which is referenced by the script /etc/rc.init.d/apm. See The Battery-Powered Linux Mini-HOWTO for information on configuring and using APM.

# PCCMIA Configuration

PCCMIA service manages PCCMIA cards. The file /etc/sysconfig/pcmia contains PCCMIA service configuration information, which is referenced by the script /etc/rc.init.d/pcmia. Configuration information for PCCMIA devices resides in /etc/pcmia. If you recompile the Linux kernel of a system that uses PCCMIA, you must also recompile and install the PCCMIA package. For more information on PCCMIA, see the Linux PCCMIA Web site, pcmia.sourceforge.org.

# Plug-and-Play Configuration

As described in Chapter 2, plug-and-play devices are designed to automatically configured by cooperation between the BIOS and operating system. Linux, however, does not fully support plug-and-play for ISA interface cards. When using Linux with a BIOS that supports plug-and-play, set the BIOS to indicate that the operating system does not support plug-and-play. You can then configure ISA plug-and-play cards by this following command

+   Issue the command pndump >/etc/isapnp.conf

This command dumps the configuration of each installed plug-and-play card in the specified file, /etc/isapnp.conf.

+   Using a text editor, revise the /etc/isapnp.conf file contains commented lines for each configuration of each plug-and-device. You must uncomment the desired configuration for each device. You must also uncomment the line at the end of the device configuration, which specifies the device is active.
