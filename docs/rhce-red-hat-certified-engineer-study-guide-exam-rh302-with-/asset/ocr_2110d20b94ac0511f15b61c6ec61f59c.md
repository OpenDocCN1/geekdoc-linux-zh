# Using linuxconf 215

You can add a new Linux boot image by clicking Add. To edit or delete an existing Linux boot image, select the image and press Enter. The Boot Configuration screen will appear. To delete the boot image, click the Delete button. To edit the boot image, make the desired changes and click Accept. The screen provides access to the LILO boot image options described in the previous chapter and several less commonly used.

# Configuring Non-Linux Boot Menu

To add, change, or delete a non-Linux partition, select Config ➤ Boot Mode LILO ➤ Configure LILO Other OS Configurations from linuxconf menu tree. The LILO Other OS Configurations will appear; Figure 9.10 shows the graphical version of this screen.

FIGURE 9.10 The LILO Other OS Configurations screen

You can add a new non-Linux boot image by clicking Add. To edit or delete an existing non-Linux boot image, select the image and press Enter. The Operating System setup screen will appear. To delete the boot image, click the Delete button. To edit the boot image, make the desired changes and click Accept. The Other Operating Systems setup screen provides access to the label1 and other options described in the previous chapter. The text labeled Partition to Boot corresponds to the other option.
