# Keyboards

Red Hat Linux supports both AT-style and PS/2-style keyboards as Tier 1 devices.

# Mice

Red Hat Linux includes support for standard serial and PS/2 mice, which are generally supported at Tier 1. Bus mice are generally supported at Tier 2. Recent Microsoft serial mice use a special protocol, which is not fully-ported. Microsoft's IntelliMouse (wheel mouse) is listed as a Tier 3 device.

# Modems

Red Hat supports most external modems at Tier 1, along with internal PCI modems based on the Lucent Venus chipset. Unfortunately, an entire class of modems—known as WinModems—requires special drivers for operation. Manufacturers bundle Win32 software with these devices, but they do not distribute software for other operating systems. Therefore, Red Hat Linux does not support such modems. Also listed as incompatible with plug-and-play internal modems, although these can be configured—even inconveniently—by using isapnp or setser1a.
