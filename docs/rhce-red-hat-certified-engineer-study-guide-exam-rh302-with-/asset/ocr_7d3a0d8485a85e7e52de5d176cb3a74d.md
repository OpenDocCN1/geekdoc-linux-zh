# The sync Command

When operating in rescue mode, you generally cannot shut down the system in the usual, orderly way by using the shutdown command. However, if you abruptly power off or reset the system, you may corrupt one or more files. So, a modified shutdown procedure must be used.

When you're ready to restart the system, issue a sequence of commands of the following form:

```
sync
sync
scd /
umount fs1 fs2 ...
```

where fs1, fs2, ... represent mounted file systems of the local hard drive. When the mount command completes, you can power off or reset the system.

![](bbox=[0.137, 0.58, 0.235, 0.626])

> The /dev directory in the rescue mode environment may not include device files for you to access. The rescue-mode mount command sometimes create the proper device file automatically; but, if you're having trouble accessing a device, you may need to issue them knod command to create the proper device file.
