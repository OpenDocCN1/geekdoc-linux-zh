# Log Rotation

If a system is busy, its log files can quickly grow large and cumbersome
to work with. To control the size of system logs, the cron facility runs a daily
job that rotates log files, /etc/cron.daily/logrotate. The contents of the
logrotate script, as distributed in Red Hat Linux, are follows:

```
#!/bin/sh
usr/sbin/logrotate /etc/logrotate.conf
```
