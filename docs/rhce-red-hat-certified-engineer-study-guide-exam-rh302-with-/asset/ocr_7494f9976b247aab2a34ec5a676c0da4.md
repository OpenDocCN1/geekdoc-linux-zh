# /sbin: Essential System Binaries

The /sbin directory contains essential system binary files used by the system administrator; that is, files needed for system start-up, shut-down, and operation in single-user mode. Table 13.6 lists the most important files in /sbin.

| adjtimex | halt | ldconfig | nmsgg | rrestore |

| askrunlevel | hclock | loglevel | pcinitrd | sash |
| badblocks | ifconfig | losetup | pidof | scsi_info |
| cardctl | ifdown | lmod | plipconfig | service |
| cardmgr | import | lspci | pnpump | setpci |
| cfdisk | ifup | mailconf | portmap | setsysfont |
