# Network Administration Commands

Several commands help you administer networking. Among the most important are the following:

+   * ifconfig
* netstat
* arp

This section explains the operation of these commands.

# The ifconfig Command

The ifconfig command reports the status of a network interface and lets you add or remove an interface. It's run by the /etc/sysconfig/network-scripts ifup and ifdown scripts.

# Reporting Network Interface Status

To obtain a report on the status of network interfaces, issue the command

ifconfig
