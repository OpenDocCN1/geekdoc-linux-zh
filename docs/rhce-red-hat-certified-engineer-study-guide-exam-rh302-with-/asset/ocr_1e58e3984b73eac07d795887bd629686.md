As the Custom Monitor Setup informs you, the horizontal sync and vertical refresh rate are critical parameters. Entering an incorrect value for each parameter can permanently damage the monitor. Obtain these values from a reliable source, such as the owner's manual or the manufacturer's Web site. Modern multi-sync monitors are more resistant to damage than older monitors; they are not immune. In any case, don't allow a monitor to display a garbled image longer than necessary; immediately turn off and reconfigure the operating parameters.
