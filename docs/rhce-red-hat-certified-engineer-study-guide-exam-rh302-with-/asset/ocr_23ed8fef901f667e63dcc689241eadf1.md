# Glossary

# A

**a.out** The out is an object file format popular in early Linux versions.

# B

**base i/o address** A base i/o address is the beginning address of a memory buffer that is used to communicate with a device interface.

**bind-listen-connect-accept process** The bind-listen-connect-accept process is a process followed by TCP servers for listeners and clients requests.

**block device** A block device is a device that sends many characters in response to a single input-output request. Common block devices include disk and CD-ROMs. *See device*.

**boot argument** A boot argument is an argument supplied at boot time and by l11o or passed to the kernel or to the in11t process.

**boot loader** A boot loader is a program, such as the l11o boot loader, that loads the first stage of an operating system into memory.

**boot prompt** A boot prompt is the prompt provided by a boot loader, such as l11o, where the user can specify a boot image to be loaded and boot arguments to be processed.

**BOOTP** BOOTP is a common protocol that lets a server assign an IP address and other network configuration information to a client.

**broadcast message** A broadcast message is a message sent to all hosts on a local network.

**browse server** The browse server is the SMB (System Message Block) server on a network that provides clients with information about available servers and shares.

**build number** The build number is a number that indicates the sequential number of a software build and, therefore, signifies the patches and options specified in a build program.

**bus** A bus is the digital path that connects the components of a computer. For example, the connects the CPU with RAM memory and adapter cards.

# C

**canonical name** A canonical name is a host name ali in the Domain Name Server (DNS) configuration.

**capability** A capability is a resource or function provided by or required an RPM package.

**certification** Certification is the process of identifying individuals as capable of performing a specified function or functions. Certification as a Red Hat Engineer provides the skills necessary to function as a Red Hat Linux system administrator.

**character device** A character device is a device that sends a single character, or relatively few characters, in response to an input-output request. *See device*.

**chooser** A chooser is a dialog box by an X display manager, which lets the user select a login host and possibly other options.

**compiler** A compiler is a program that translates source code to object, the C compiler for example.

**component** A component is a set of packages that has a related function or purpose.

**connectionless protocol** A connectionless protocol is a protocol in which no handshake occurs before an exchange of data.

**copyleft** Copyleft is a special form of copyright intended to ensure software freedom. *See GPL*.

**cron** The cron service lets users schedule tasks that are initiated at appointed times.

**crontab file** The crontab file is a file configuration information for the cron program.

**current working directory** The current working directory is the directory that is implicitly prefixed to a relative path.

# D

**daemon** A daemon is a program that runs in the background, that is, without a connection.

**default route** The default route is the route along which a packet is sent if no specific route to the packet's destination exists.
