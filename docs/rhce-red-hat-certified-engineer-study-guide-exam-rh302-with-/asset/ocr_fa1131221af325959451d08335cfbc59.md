# Starting X

You can set a system to provide a console login or an X login. The /etc/
initab file contains the line:

```
id:n::initdefault:
```

where $n$ is the default runlevel. Set $n$ to 3 to provide a console login; set $n
to 5 to provide an X login. The X startup process depends on the runlevel
spec.
