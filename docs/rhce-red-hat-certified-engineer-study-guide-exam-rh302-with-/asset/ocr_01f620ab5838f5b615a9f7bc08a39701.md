# Amateur Radio Support

The Amateur Radio Support screen lets you configure support for packet radio. These options are not generally required.

# IrDA Subsystem Support

The IrDA Subsystem Support screen of xconfig, shown in Figure 18.13, lets you configure support for devices that communicate with the system via infrared. These options are not generally required.
