# Choosing User IDs for Services

As a rule, daemon processes should run using an ordinary user account or the special user account nobody. They should generally not run as root, because a vulnerability in the process may provide a would-be intruder with the means to execute a command as root. If the process runs as an ordinary user, the intruder may compromise the user account. If, however, the process runs as root, the intruder may compromise the root account, which compromises the entire system.

The /etc/passwd file contains several user accounts that have been created to avoid running a process using the root account. Here are the contents of a /etc/passwd file:

```
root:x:0:0:root:/bin/bash
bin:x:1:1:bin:/bin/
daemon:x:2:2:daemon:/sbin/
mad:x:3:4:adm:/var/adm/
lp:x:4:7:lp:/var/spool/lpd/
```
