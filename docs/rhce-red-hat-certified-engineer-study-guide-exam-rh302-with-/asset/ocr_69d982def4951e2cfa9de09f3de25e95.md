# # TCP/IP Networking

At one time, a variety of protocols vied for ascendancy as the preeminent protocol. The advent of the Internet, which is based on the TCP/IP (Transmission Control Protocol/Internet Protocol) family, has essentially ended the contest. Except for closed, private networks, most networks today use TCP/IP as their primary protocol.

This section describes how TCP/IP hosts and networks are addressed. The subsequent section describes how TCP/IP networks function and the services that TCP/IP networks provide.

# ## IP Addresses

TCP/IP networks are made up of interconnected computer systems called hosts. Each host has one or more IP addresses, usually one address for each network interface installed on the host. TCP/IP addresses are 32-numbers, which are commonly written as a series of four octets (8-bit values) in dotted notation. For example, a TCP/IP host may have an IP address as 192.168.1.1, which is equivalent to the 32-bit integer 3,232,235,777 (192 × 256³ + 168 × 256² + 1 × 256 + 1).
