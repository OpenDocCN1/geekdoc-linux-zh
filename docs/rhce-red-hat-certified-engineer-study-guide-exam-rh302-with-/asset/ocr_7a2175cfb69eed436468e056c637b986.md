# Using Removable Media

Users familiar with MS-DOS may be accustomed to inserting and removing removable media—such as floppy disk—at will. However, under Unix, the file system on the removable media must be mounted in order to be accessible. Conversely, the file system should be unmounted before the media is removed. Failure to unmount the file system may result in corrupted data or a corrupted file system.

![](bbox=[0.187, 0.792, 0.253, 0.847])

The GNOME and KDE environments provide convenient ways to work with removable media. You may prefer working in a graphical environment when mounting and unmounting media.
