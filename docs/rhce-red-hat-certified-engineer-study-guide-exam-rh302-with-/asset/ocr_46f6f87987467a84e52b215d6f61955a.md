# The RPM Database

Once a package is installed, information about the package is stored in the RPM database, which resides in /var/lib/rpm. When you issue an rpm command—for example, a command to install a package or a command to uninstall a package—the RPM facility inspects the package file and the RPM database. Thus, the RPM facility is able to determine whether execution of the command will leave the system in an inconsistent state. If so, the RPM facility suppresses the command and warns the user of the potential danger.

# The rpm Command

The rpm command is the executable component of the RPM facility. Its host of switches and arguments enable you to perform operations such as:

+   - Installing packages

+   - Updating packages

+   - Removing packages

+   - Querying the RPM database

+   - Querying a package file

+   - Building a package file from source code

+   - Validating a package

+   - Validating a file

When installing, updating, or removing packages, the rpm command performs several checks to ensure that the system is left in a consistent state. For example, when installing a package, rpm checks that:

+   - There is sufficient free space to accommodate the package

+   - Any capabilities required by the package (dependencies) are installed

+   - Installation of the package won't overwrite existing files
