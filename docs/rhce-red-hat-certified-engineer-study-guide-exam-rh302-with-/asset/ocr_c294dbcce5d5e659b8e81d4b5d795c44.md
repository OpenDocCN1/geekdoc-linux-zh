# Infrared-Port Device Drivers

The Infrared-Port Device Drivers screen of xconfig, shown in Figure 18.14, lets you configure drivers for devices that communicate with the system via infrared. These options are included by menuconfig as part of its IrDA Subsystem Support area and are not generally required.

# ISDN Subsystem

Figure 18.15 shows the ISDN Subsystem screen of xconfig. Unless the system is attached to an ISDN device, you should disable this option. Many modern ISDN modems attach to a system via Ethernet; such modems do not require ISDN support.
