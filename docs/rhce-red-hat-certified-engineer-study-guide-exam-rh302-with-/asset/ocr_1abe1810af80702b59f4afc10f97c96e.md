The quotacheck Program The quotacheck program establishes the quota control files, quota.user and quota.group.

The edquota Program The edquota program lets you establish or revise the quota associated with a user or a user group.

The quotaon and quotaoff Programs The quotaon and quotaoff programs let you turn quotas on and off, respectively.

The quota Program The quota program lets you print reports that show the status of disk quotas.
