Torvalds called his operating kernel Linux, for Linus's Minix. Unix
programmers eagerly offered help in all of the components needed for its-
GNU project had completed almost all of the components needed for its Unix-
operating system except the kernel, Linux and GNU were a natural mar-
riage. In 1994, about three years after Torvalds's posting, Linux 1.0 was
released under the terms of the GPL. Already, Linux had over 100,000 users.

Because GNU was—and remains today—important to the development of
Linux, many like to refer to Linux as GNU/Linux.

Linux kernels are numbered using even/odd system. An even-
bered kernel—for example, Linux 2.2—is called a called stable kernel.
Changes are generally made to a stable kernel only to fix bugs and problems.
An-numbered kernel—for example, Linux 2.3—is called a development
kernel. Development kernels are work-in-progress and sometimes
bugs, some of which are serious. Most Linux users work with stable kernels,
reserving spare computers for testing development kernels. At the time of the
writing of this book, Linux 2.2 is the latest stable kernel.
