# Answers to Review Questions

+   1. A, B, C. Although there is a UUCP account type, there is no Usenet account type.

+   2. A. You can invoke userconf from the command line or invoke it by means of linuxconf.

+   3. A, C. A user who has permission to use linuxconf may not activate configuration changes unless permission to do so has been explicitly given.

+   4. A. The password is initially locked; the user cannot log in until the account is unlocked by changing the password to a usable one.

+   5. B. Red Hat Linux assigns a new user to a personal group that has the same name as the user's login.

+   6. B. The mkpasswd command generates random passwords.
