You can choose a card from the list and click the OK button, or you can choose the entry, Unlisted Card. Xconfigurator will try to determine the proper X server for the selected card. If it cannot, it will display the Pick Server, shown in Figure 26.3.

# FIGURE 26.3 The Xconfigurator Pick a Server screen

![](bbox=[0.292, 0.553, 0.847, 0.813])

Use the navigation keys to highlight the proper server, then click the OK button. If you are unsure which to choose, consider choosing SVGA, VGA16, or Mono because these servers support a variety of cards. However, these servers provide limited resolution and color depth; using a generic server may not take full advantage of the capabilities of your system video
