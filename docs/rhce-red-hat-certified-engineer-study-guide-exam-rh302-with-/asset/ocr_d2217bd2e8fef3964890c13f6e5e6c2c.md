# Setting the Time Zone

The Time Zone Selection screen, shown in Figure 7.14, lets you specify the time zone associated with the system's location. You can specify the time zone by using a world map or by specifying an offset from Universal Time (UTC).

FIGURE 7.14 The Time Zone Selection screen

![](bbox=[0.31, 0.447, 0.836, 0.781])

You can specify that the system's clock is set to UTC. However, other operating systems may not support this capability, so be careful specifying this option if the system is to be configured for dual-booting.
