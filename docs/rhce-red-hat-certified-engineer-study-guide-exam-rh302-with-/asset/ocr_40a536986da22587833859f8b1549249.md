The menuconfig utility is a favorite among system administrators. Like
config, it has a text-based interface and can be used remotely—for
example, over a telnet or ssh connection. However, menuconfig—as its name
suggests—provides a menu-based interface that lets you configure-
options until you arrive at a configuration you approve. This is much less
clumsy to use the config utility. It also includes a helpful facility that
explains the selected configuration option. Figure 18.1 shows the main screen of
menuconfig utility.

If the host system supports X, you can use the xconfig utility. The
xconfig utility has an attractive and easy-to-use interface that fully supports
mouse or other X-supported pointing device. Like menuconfig, it provides
