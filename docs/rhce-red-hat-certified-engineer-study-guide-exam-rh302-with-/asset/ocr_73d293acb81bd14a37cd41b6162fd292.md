# TCP/IP Networking 85

Subnetting lets split an IP address into its network and host address components anywhere like, rather than at an octet boundary. designate the part of an IP address that composes the network address by specifying a netmask, a 32-bit string that has a 1 bit in each position's part of the network address and a 0 bit elsewhere. You write a network using the same dotted quad notation used for IP addresses. For example, a class C address has a netmask of 255.255.255.0: the first three octets have all 1s and the final octet has all 0s. To specify a 26-bit network address, you use a netmask of 255.255.255.192 in the final octet has 1 bits in its two highest positions.

To understand the significance of a host's IP address, you must know the associated network. Otherwise, you won't be able to determine which bits are on the same local network as the host.

Some programs allow you to specify an IP address and netmask as pair. You write the IP address, follow it with a slash, and then write the number of bits in the mask. For example, 192.168.1.100/24 specifies a host with IP address 192.168.1.100 on a network having a 24-bit (class C-like) netmask. A subnetted IP address is one in which the number of subnet bits is not an even multiple of 8, for example, 192.168.1.100/26.

# Supernetting

As you might expect, supernetting is related to subnetting. Whereas subnetting lets you split a network into several smaller networks, subnetting lets you join consecutively numbered networks into a larger network. For example, suppose you have assigned 256 class C network addresses that span the entire range from 192.192.0.0 to 192.192.255.255. By specifying a netmask of 255.255.0.0, you can treat these class C network addresses as though they are a single class B address: 16 bits for the network address and 16 bits for the host address.

# Host and Domain Names

Most people find cumbersome to recall IP addresses. Therefore, hosts are generally assigned host names well as IP addresses. It's much easier to point your Web browser to www.redhat.com than to 206.132.41.202.

Just as organizations apply to the Internet authority for a network address rather than individual host addresses, they apply for a domain name address. A domain name consists of at least two parts: a top-level domain and a subdomain. The parts are separated by a dot (.)
