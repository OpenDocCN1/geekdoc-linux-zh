route add -host ip_address interface

# Disabling Dynamic Routing

When using static routing, you should disable the routed daemon. To do so, launch linuxconf and select Config > Networking > Client Tasks > Routing and Gateways > The Routed Daemon from the linuxconf menu. The Routed Daemon, shown in Figure 29.4, will appear. Click the Does Not Export Any Routes (Silent) button, and click the Accept.
