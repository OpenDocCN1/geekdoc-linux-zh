# Glossary 3

**dependency** A dependency is a relationship between packages in which one requires resources or functions provided by another.

**dynamic loader** A dynamic loader is a loader capable of **dynamic linking.**

**dependency information** Dependency information is stored in a package file that identifies the resources and functions required and provided by the package.

**dynamic routing** Dynamic routing is a technique whereby the contents of routing tables are automatically updated as network conditions change. See static routing.

**desktop manager** A desktop manager is a client that provides desktop icons, a task bar, a pager, or other common desktop functions.

# E

**development kernel** A development kernel is a version that is undergoing major development. See stable kernel.

**election** Election is the process whereby SMB (System Message Block) servers contend to determine which server functions as the *master browser*.

**device file** A device file is a file that is associated with a hardware device.

ELF ELF is the object format currently used by Linux systems.

**DHCP** Dynamic Host Configuration Protocol (DHCP) is a protocol that sets a server client host with an IP address and other configuration information.

**environment variable** An environment variable is a variable associated with the Linux shell that can be used to set options and pass data between applications.

**extended partition** An extended partition is a partition that can hold other partitions within it.

**disk geometry** Disk geometry is the number of sectors, heads, and cylinders on a disk drive.

**exterior routing protocol** An exterior routing protocol is a routing protocol intended for autonomous networks.

**display manager** A display manager is a special X client that provides methods to log in to a system via X.

**extraversion code** An extraversion code is a string that uniquely identifies the version number in a Linux kernel to avoid conflicts between the modules of kernel instances sharing the same version number.

**distance-vector protocol** A distance-vector protocol is a routing whereby whereby informs its neighbors of the contents of its routing table.

# F

**DMA** Direct Memory Access (DMA) is a facility that expedites device input and output by letting the device directly access system memory.

**file ownership** File ownership of a file is the user account that owns a file.

**domain name** A domain name is registered by an organization with the Internet authority and shared by hosts to that organization. An organization can register multiple domain names. The combination of a host and domain name makes a fully qualified domain name, which identifies a host.

**file permissions** File permissions are the permissions (read, write, execute) that are extended to the owner and group of a file and to others.

**dynamic IP address** A dynamic IP address is an address that is assigned dynamically, such as when a host is booted. See *static IP address*.

**file system** A file system is a partition that is organized for data storage and retrieval.

**firewall** A firewall is a system or device that blocks unauthorized traffic from entering or leaving a network.

**dynamic linking** Dynamic linking is performed when a program is loaded. Linking an object module with the library members uses it to form a complete program. See *static linking*.

**forward zone** A forward zone is a Domain Name Service (DNS) configuration that maps host names to IP addresses. See *reverse zone*.
