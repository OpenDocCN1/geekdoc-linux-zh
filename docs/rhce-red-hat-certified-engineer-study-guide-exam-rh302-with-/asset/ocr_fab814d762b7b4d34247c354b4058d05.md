# Determining File Ownership

You can use RPM to learn which package, if any, owns a particular file. To do so, issue a command of the form

```
rpm -qf filename
```

where filename is the name of the file, which must include the full path. For example, asking RPM to report the ownership of the file /etc/inittab yields output such as:

```
# rpm -qf /etc/inittab
inscripts-4.16-1
```
