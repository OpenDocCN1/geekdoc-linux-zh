Mount the Red Hat Linux installation CD-ROM by issuing the command
mount -t iso9660 /dev/cdrom/mnt/cdrom -o ro
Place a formatted floppy disk in the floppy drive and issue the command
diff if=/cdrom/images/boot.img of=/dev/fd0H1440 bs=18k

It may take a minute or so to write the image to the floppy disk. When activity
remove the disk, which can now be used to boot the target system.

If you plan to install Linux via the network rather than from a CD-ROM, copy
t image file bootnet.img, rather than boot.img.

If you need to access PCMCIA devices during installation, you'll need a
second disk. Use a similar command to create a floppy disk from the
file pcmcia.img.
If you don't have amply access to a Linux system, you can make a floppy
from an image file using the DOS program write, which resides in the
dosutils directory of the CD-ROM. The write program can be run from
DOS or from a Microsoft Windows MS-DOS prompt. The program
prompts for the letter of the drive containing the floppy disk (usually a:)
for the path of the image file (usually d:\images\boot.img).
