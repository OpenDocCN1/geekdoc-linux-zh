If you want to know what changes are pending, click Preview What Has to Be Done. The linuxconf program displays the pending changes. To activate pending changes, click Activate the Changes. To exit the Status of the System screen without activating any pending changes, click Quit.

You should generally activate pending changes before exiting linuxconf. If you neglect to do so, linuxconf will prompt you to confirm that you want to exit without activating the changes you specified.
