# Pluggable Authentication Module (PAM) Facility

The Red Hat Pluggable Authentication Module (PAM) facility is more commonly known as PAM. PAM lets you configure security policies for a variety of programs. Each PAM-aware program has a configuration file that resides in /etc/pam.d. The contents of the file associated with a program determine how the program authorizes access to its functions. By PAM, you can configure authorization policies without modifying and recompiling programs.

PAM consists of a series of library modules that are dynamically loaded. The configuration file of a PAM-aware program determines the modules, and hence the actions, that are used to verify authorizations. Following is a list of some the most important PAM modules:

+   **pam_access.so** This module restricts the hosts from which a service can be accessed.

+   **pam_console.so** This module confers special privileges to users logged via the console by making them members of the dynamic group console. This means, console users are able to access the floppy drive, subsystem, and joystick and can perform privileged operations such as rebooting and shutting down the system.

+   **pam_listfile.so** This module certifies a specified file to determine authorizations. The FTP service uses this module to deny FTP access to users listed in /etc/ftputusers.

+   **pam_nlogin.so** This module prevents users other than root logging in while the /etc/nlogin file exists.

+   **pam_security.so** This module prohibits logging in as root from a tty device other than those listed in /etc/securetty.

+   **pam_time.so** This module restricts the times at which a user can access a service by day or time of day.
