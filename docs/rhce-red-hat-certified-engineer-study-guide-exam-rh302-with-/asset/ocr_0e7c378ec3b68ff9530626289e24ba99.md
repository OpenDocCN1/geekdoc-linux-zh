# Answers to Review Questions

+   1. A, B, C, D. Problematic CD-ROM drives, WinModems, and WinPrinters will not be listed at Tier 1 or 2 of the Red Hat Linux Hardware Compatibility List.

+   2. C. Only NFS is supported by the graphical mode installation user interface.

+   3. A, C. The Server installation class does not install an SSH server; neither does it install Multimedia, which is installed by the workstation classes.

+   4. C. No more than 4GB of swap space can be accessed by a Linux system.

+   5. A, B, C. Red Hat Linux does not currently support access to installation files via Samba.

+   6. B, D. Under Linux, you create the boot floppy using the dd command; under DOS, you create the boot floppy using the rawwrite command.
