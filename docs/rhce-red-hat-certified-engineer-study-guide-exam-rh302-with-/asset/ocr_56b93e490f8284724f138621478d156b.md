# Summary

In this chapter, you learned about restricting access to network services. The most important topics covered are:

+   **The inetd Service** The inetd service mediates requests for TCP services, launching the appropriate server when a client request is received. The service's configuration file is `/etc/inetd.conf`.

+   **TCP Wrappers** The tecpd daemon can restrict access to services controlled by inetd. The `/etc/hosts.allow` and `/etc/hosts.deny` configuration files identify the hosts that are permitted or forbidden access to services. The associated twist program can be used to respond to client requests by substituting a specified program for the service that would otherwise be launched.

+   **Network Information Service (NIS)** NIS provides a set of centralized databases—called maps—that help manage user accounts, mail aliases, hosts, networks, and other information across a network. NIS contains several security flaws and is not widely used.
