# Understanding the Red Hat Linux File System

Table 3.5 summarizes the directories that compose the Red Hat Linux file system. Be sure you are familiar with each directory and its contents.

# TABLE 3.5 Important Red Hat Linux Directories

| Directory | Contents |
|---|--|
| / | System root directory |
| /bin | Common commands and programs |
| /boot | Linux kernel and boot-related files |
| /dev | Device files |
| /etc | Configuration files |
