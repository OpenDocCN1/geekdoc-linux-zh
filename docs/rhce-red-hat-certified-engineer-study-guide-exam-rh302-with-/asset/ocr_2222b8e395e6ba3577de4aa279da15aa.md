304 Chapter 12 • Using RPM Packages

The **rpm Command** The *rpm* command lets you perform a variety of operations, including installing a package, updating a package, removing a package, querying the RPM database, querying a package file, building a package code, validating a package, and validating a package file.

**Source RPM Packages** Unlike ordinary RPM packages, which contain binary code, source RPM packages contain source code.

**The GnoRPM Program** GnoRPM provides an X-based graphical user interface to the *rpm* command.
