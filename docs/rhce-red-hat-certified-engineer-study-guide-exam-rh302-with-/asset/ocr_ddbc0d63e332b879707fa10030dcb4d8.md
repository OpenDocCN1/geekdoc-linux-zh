# X Font Server

By default, each system configured to run Red Hat Linux runs its own copy of the X font server, xfs, which provides access to locally stored fonts, including TrueType fonts. However, you can reconfigure a system to access a remote X font server, if you prefer.

To do so, modify the FontPath directive of the /etc/X11/XF86Config file each client system. By default, the directive has this:

```
FontPath "unix:-1"
```
