# Administering Groups via userconf

Groups—often simply called groups—let you a set of users, called members. You use the familiar chmod command to specify permissions to access files and directories for the owner, members of the owning group, and others. The /etc/group file defines Linux groups. Each line in the file describes a single group. Here is a typical /etc/group file:

```
root::0:
bin::1:root,bin,daemon
daemon::2:root,bin,daemon
sys::3:root,bin,adm
adm:4:root,adm,daemon
tty::5:
disk::6:root
1p::7:daemon,1p
mem::8:
kmem::9:
wheel::10:root
mail::12:mail
news::13:news
uucp::14:uucp
man::15:
games::20:
gopher::30:
dip::40:
ftp::50:
```
