# Viewing Loaded Modules

The lsmod command is simple to use, and very helpful in managing modules. To become better acquainted with the command, use it to identify modules resident in your system.

# Unloading Idle Modules: **rmmod**

When a module has been idle for not more than 10 minutes, the /etc/cron.d/kmod cron jobs will unload it, unless you disabled the job. However, you can unload an idle module at any time by issuing the command

```
rmmod module
```
