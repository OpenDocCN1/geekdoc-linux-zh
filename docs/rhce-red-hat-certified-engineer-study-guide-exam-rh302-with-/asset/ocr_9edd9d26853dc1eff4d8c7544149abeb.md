# Partitioning Hard Disks

If you selected the GNOME, KDE Workstation, Server installation class, the installation procedure offers to perform automatic partitioning of the system's hard disks. The graphical mode version of the Automatic partitioning screen is shown in Figure 7.8.

**FIGURE 7.8** The Automatic Partitioning screen

![](bbox=[0.33, 0.3, 0.84, 0.63])

If you prefer to partition the disks manually, check the Manually Partition check box. If you do so, the installation program displays the Partitions screen, which lets you access Disk Druid, Red Hat Linux’s partitioning program, or fdisk, the standard Linux partitioning program. The graphical version of the Disk Druid screen is shown in Figure 7.9.
