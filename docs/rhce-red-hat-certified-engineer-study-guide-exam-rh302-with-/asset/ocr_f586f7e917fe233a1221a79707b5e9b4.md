# Selecting and Preparing Boot Media

In order to install Red Hat Linux, you must boot the target system using a special Linux kernel. You can boot the system from the installation CD-ROM or from a floppy disk you create files on the CD-ROM. This section explains these alternatives so that you can have the proper materials when you begin the installation.
