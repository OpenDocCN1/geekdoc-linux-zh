# Partitioning Hard Disks 151

Clicking the Add button opens a dialog box that lets you add new partition. The graphical version of this dialog box is shown in Figure 7.10. The dialog box contains the following fields:

**Mount Point** Lets you specify the directory at which the partition will be mounted. You shouldn't specify a mount point for a swap partition.

**Size** The size of the partition, in MB.

**Grow to Fill Disk** Specifies that the partition size should be increased until all available free space is allocated.

**Partition Type** The partition type.

**Allowable Drives** The drive or drives from which you're willing to let Disk Droid choose placing the partition.
