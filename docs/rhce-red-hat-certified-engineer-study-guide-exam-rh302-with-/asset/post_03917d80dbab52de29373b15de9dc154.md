Refer back to this chapter and other resources when completing this exercise. But, be prepared to perform similar operations without help taking the RHCE exam.

# Kernel Configuration

The Linux kernel provides a variety of network-related options. You can see most of these in Figure 29.6, which shows the top of the makeconfig page that includes the network-related options. Table 29.1 summarizes the most important options. Two especially important options Red Hat Linux for use as a router: IP: advanced router and IP: optimize as router host, which is not visible in Figure 29.6. If a Linux system is used primarily or exclusively—as a router, you should specify these options and recompile its kernel.

# TABLE 29.1 Kernel Networking Options

| Typical Value | Option | Description |
|---|---|---|
| Y/N | IP: advanced router | Specify Y if the host is used mostly as a router |
| Y | IP: aliasing support | Includes support for assigning multiple IP addresses to a single interface |
| N | IP: ARP daemon | Includes support for a user-space ARP daemon |
| M | IP: autof support | Includes support for masquerading protocols that lack their own protocol helpers |
| Y/N | IP: broadcast over IP | Includes support for Generic Routing Encapsulation (GRE) to construct a broadcast WAN like an ordinary LAN |
| Y | IP: firewall packet netlink | Includes support that lets you create a character special file that receives a copy of packets that match specific criteria; used to monitor network traffic and detect possible attacks |
| Y | IP: firewalling | Includes kernel support for firewalling and masquerading |
| M | IP: GRE tunnels over IP | Includes support for GRE, encapsulation of IPv4 packets over IPv4. This support is more compatible with Cisco routers than provided by the IP: tuning option |
| Y | IP: ICMP masquerading | Includes support that enables a firewall to translate ICMP packets that originate from the local host and are destined for a remote host to appear as though they had originated from the firewall host. Used, for example, allow hosts that have only private IP addresses to access the Internet |
| M | IP: ipmarkfw | Includes support for Firewall Mark Forwarding, a facility similar to port forwarding |
| N | IP: kernel level autfiguration | Enables automatic configuration of IP addresses of network interfaces and the routing table during kernel boot; used to support disable boot via the network |
| Y | IP: masquerading | Includes support that enables a firewall to translate UDP and TCP packets that originate from the local network and are destined for a remote host to appear as though they had originated from the firewall host. Used, for example, allow hosts that have only private IP addresses to access the Internet |
| Y | IP: masquerading special modules support | Includes support for modules that can modify masquerade rules; used by such modules as ipautfw and by port forwarding |
| M | IP: masquerading virtual server | Includes support that lets you build a virtual server that consists of two or more real servers |
| 12 | IP: masquerading VS table size | Specifies the size of the hash table used to manage active connections; the actual table size is 2, where n is the specified value |
| N | IP: multicast routing | Includes support for routing multicast packets—that is, packets that have multiple destination addresses |
