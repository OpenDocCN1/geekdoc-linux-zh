# Answers to Review Questions

+   1. A, D. Both package files and the RPM database store information about RPM packages.

+   2. A, D. Both the -e and --uninstall flags uninstall the specified package.

+   3. B. The -qf flag causes RPM to report file ownership; the full path of the file must be specified.

+   4. A, B, D. The file size may not have changed, even though the contents of the file have changed.

+   5. B. The -qa flag causes RPM to list the name of each installed package.

+   6. B. GnoRPM is the tool that provides a graphical user interface to RPM.
