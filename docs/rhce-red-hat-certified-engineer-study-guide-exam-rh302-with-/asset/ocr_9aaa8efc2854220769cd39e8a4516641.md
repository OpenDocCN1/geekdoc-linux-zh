If DNS is not required for normal operation, disable DNS Is Required for Normal Operation. Otherwise, specify the default domain and the IP address (number) of the primary nameserver associated with the system. You can specify as many as two additional nameservers and as many as six additional search domains. Click Accept to save your changes.
