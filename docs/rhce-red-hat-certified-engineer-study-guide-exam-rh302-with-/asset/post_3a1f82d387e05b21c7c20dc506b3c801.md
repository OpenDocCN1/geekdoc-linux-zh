
# Glossary 7

root partition: The partition is the partition whose file system contains /bin, /sbin, and other required directories.

start of authority: The start of authority is the host that has primary responsibility for Domain Name Service (DNS) information pertaining to a zone.

route: A route is a path from a source host to a destination host, over which packets pass.

static IP address: A static IP address is a fixed IP assigned to a host. See dynamic IP address.

router: A router is a system or device that forwards packets along an appropriate route.

static linking: Static linking is the linking of an object module with all required library members so that no references to libraries or dynamic linking are necessary when the program is loaded. See dynamic linking.

routing: Routing is the process of transporting packets along a route.

static routing: Static routing is a technique where routing tables are performed manually. See dynamic routing.

runlevel: A runlevel designates the types of local and network services that are active.

stratum: A stratum is a set of systems that share a similar logical network distance from a high-precision time base.

runlevel script: A runlevel script is a script associated with a program or service.

# S

stub: A stub is a piece of code that acts as a placeholder.

secondary boot loader: A secondary boot loader is a program that loads the operating system into memory and transfers control to the operating system. A secondary boot loader is launched by the primary boot loader.

subnetting: Subsetting is a scheme of dividing a network into several smaller networks.

superblock: A superblock is a special block of data that describes the content and structure of a file system.

service: A service is a program that listens for client requests and provides information or takes specific action.

supernetting: Supernetting is a scheme of connecting multiple networks to a single, larger network.

share: A share is a file, directory, or printer made available to users or hosts.

symmetric multip multiprocessing: Symmetric multipiprocessing is a scheme where a computer may include several processors, each of which performs similar functions.

# T

TCP: Transmission Control Protocol (TCP) is a protocol family that is the basis of the Internet.

single-user mode: Single-user is a special mode intended to help a system administrator repair a damaged system.

socket: TCP wrappers are a facility of the inet daemon through which access to services can be restricted to designated hosts.

SLIP: A SLIP is a user-authorized to log in via SLA.

temporary file: A temporary file is a file that is needed for a brief time and can be deleted after use.

socket: A socket is a TCP/IP communications facility that consists of ports.

soft limit: A soft limit is a disk quota that can be temporarily exceeded.

text-based installation procedure: Red Linux provides a text-based installation that is based on character-graphics and the keyboard. See graphical installation procedure.

source code: Source code is the program format that programmers work with.

stable kernel: A kernel that is undergoing unlimited development aimed at repairing bugs. See development kernel.

# Glossary

**three-button emulation** Three-button emulation an X facility that lets a user employ a two-button mouse to access functions associated with the middle mouse button.

**well-known port** A well-known port is a port commonly associated with some TCP/IP service. Well-known ports are listed in /etc/services.

**top-level domain name**: A top-level domain is one of a set of special domains, one of which is incorporated as part of every domain name, as in .com, .edu, and .gov.

**window manager** A window manager is an X client that is responsible for many aspects of the visual appearance and behavior of displayed windows, such as title bars and close boxes.

# U

**UDP** The Universal Datagram Protocol (UDP) is a low-level, connectionless TCP/IP protocol.

# X

**Unix** Unix is a family of operating systems that share common characteristics. Linux is a member of the Unix family.

**X** or the X Window System, is the graphical interface distributed with Linux.

**X client** An X client is a program that uses X as its user interface.

**unreliable protocol** An unreliable protocol performs little or no error checking. Such a protocol has relatively low overhead.

**X server** An X server is a video driver associated with the X Window System.

# Z

**user account** A user account represents the identity and permissions associated with an authorized user of a computer system or network.

**zone file** A Domain Name Service (DNS) file maps host names to IP addresses or the reverse. See forward zone file and reverse zone file.

**user group** A user group is a designated set of users. File ownership and permissions can be assigned to a user group.

**user private group** A user private group is a group having one member, which is the same as that in the identically named user account.

**user quota** A user quota is a disk space quota associated with a user account.

**UUCP user** A UUCP user is a user authorized to access UUCP services, but not authorized to log in a system.

# V

**version number** The version number of a program is an ordinal number that indicates how recently the program was built.

**vertical refresh rate** The vertical refresh rate of a monitor is a crucial operating parameter. A monitor can be damaged by operating it at an inappropriate vertical refresh rate.
