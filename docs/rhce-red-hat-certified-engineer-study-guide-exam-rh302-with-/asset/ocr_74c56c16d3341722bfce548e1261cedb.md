# Mail

Mail involves two facilities: mail transfer and mail access. The Red Linux mail transfer agent (MTA) is sendmail, which is the most popular MTA on the Internet. Red Hat provides access to mail via the Post Office Protocol (POP) or the Interim Mail Access Protocol (IMAP). The sendmail program is extremely flexible, but is relatively large and complex. Its features include:

+   - The ability to decode and handle a wide range of destination address formats
- Support for virtual mail domains and user aliases
- Extensive security and anti-spam facilities

# How Mail Works

A user typically composes mail by means of a mail client application. Popular clients include Linux and non-Linux programs as:

+   - Eudora
- Mutt
- Netscape Communicator
- Microsoft Outlook
- Pegasus
- Pine

After composing a mail message, the user sends the message, which is transmitted by a Simple Mail Transfer Protocol (SMTP) server. This can be achieved in a variety of ways. Some mail clients, including most Linux clients, spawn a sendmail process to transmit messages; others depend on the availability of a remote SMTP server.
