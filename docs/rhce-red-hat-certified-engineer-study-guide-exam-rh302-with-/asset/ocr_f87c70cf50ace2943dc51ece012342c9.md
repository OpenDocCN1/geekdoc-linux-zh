To print this information for a package file, issue a command of the form

```
rpm -qip package_file_name
```

where package_file_name is the name of the package file.

# Listing Contained Files

To list the files contained an installed package, issue a command of the form

```
rpm -ql package_name
```

where package_name is the name of the installed package. For example, list-
ing the files of the gnorpm package produces output like this:

```
# rpm -ql gnorpm-auth
/etc/pam.d/gnorpm-auth
```
