# Setting the System Time Zone

To set the system time zone, issue the command timeconfig

This command launches the Configure Timezones screen, shown in Figure 9.3. If the hardware clock is set to UTC/GMT, enable the Hardware Clock Set to GMT option. Select the time zone from the list and click OK to accept your changes.
