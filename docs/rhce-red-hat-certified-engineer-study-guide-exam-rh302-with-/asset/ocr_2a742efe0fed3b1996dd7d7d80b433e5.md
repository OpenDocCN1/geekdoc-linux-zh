Table 3.7 summarizes the most important fdisk commands.

# TABLE 3.7 Important fdisk Commands

| | Action |
|---||
| a | Toggles the active partition flag. |
| d | Deletes a partition. |
| l | Lists known partition types. |
| n | Adds a new partition. |
| o | Creates a new empty partition table. |
| p | Prints (displays) the partition table. |
| q | Quits without saving changes. |
| t | Sets the partition type. |
| u | Toggles display units from cylinders to sectors or the reverse. |
| v | Verifies the partition table. |
| w | Writes the partition table to disk and exits. |

Usually, your first step after starting fdisk is to issue the p command to display the partition table. The result should resemble the following output:

/dev/hda: 255 heads, 63 sectors, 2489 cylinders
Units = cylinders of 16065 * 52 bytes
