# Creating Ordinary User Accounts

Ordinary user accounts—often called shell accounts—let the user log in and use the system. To create an ordinary user account follow these steps:

+   1. Launch userconf.

+   2. Choose Users Accounts, and press Enter. If you're using X, click Users Accounts. The Users Accounts screen, shown in Figure 10.3, will appear. If you're using X, this screen and subsequent screens will look somewhat different.

Depending on the filter settings (in Control ➤ Features), you may see a Filter dialog box. Use the box to limit the user accounts to those you want to see or accept to view all accounts.
