Each service is listed, followed by its status for each of the possible runlevels.
You may find it more convenient to issue this command, which sorts the output by the name of the service

```
chkconfig --list | sort
```

# Adding a Service

To add a service, you must ensure that the associated init.d script contains special comments. The first comment is a line that tells chkconfig the runlevels for which the service should be started and the start and stop priority numbers. The comment line contains the tokens # chconfig: and then lists the runlevels. For example, the following comment specifies that a service runs at runlevels 2 and 5 and has start priority 20 and stop priority 80:

```
# chkconfig: 25 20 80
```

```
# description: Saves and restores system entropy pool for \n
```
