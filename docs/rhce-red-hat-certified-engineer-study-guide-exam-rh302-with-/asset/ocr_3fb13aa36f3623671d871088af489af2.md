# TABLE 4.1 Important TCP/IP Services and Their Port Numbers (continued)

| Port | Underlying Protocol | Service | Description |
|---|---|---|--|
| 25 | TCP | smtp | Provides access to the Simple Transfer Protocol (SMTP). |
| 37 | UDP/TCP | time | Provides time as a binary value. |
| 43 | TCP | whos | Provides name and address information. |
| 53 | UDP/TCP | domain | Provides access to the domain name service (DNS). |
| 67 | UDP/TCP | bootsp | Used by the bootstrap protocol (boot) server. |
| 68 | UDP/TCP | bootpc | Used by bootstrap protocol (boot) client. |
| 69 | UDP | tftp | Provides access to the Trivial File Transfer Protocol (TFTP). |
| 70 | UDP/TCP | gopher | Provides access to the Gopher information retrieval service. |
| 79 | TCP | finger | Provides access to the finger service, which describes users. |
| 80 | UDP/TCP | www | Provides access to the HTTP (Web) service. |
| 88 | UDP/TCP | kerberos | Provides access to the Kerberos authentication service. |
| 109 | UDP/TCP | pop-2 | Provides access to the post office service (version 2). |
| 110 | UDP/TCP | pop-3 | Provides access to the post office service (version 3). |
| 111 | UDP/TCP | sunrpc | Provides access to the remote procedure call (RPC) service. |
