# /bin: Essential Binary Files

The /bin directory contains binary files that are essential to system operation in single-user mode. These files are generally commands, which may be used by the system administrator and by users. Similar files not required for single-user mode are placed in /usr/bin. Table 13.1 lists files found in the /bin directory. Some of the files are symbolic links that provide alternate filenames. For example, /bin/csh is a symbolic link pointing to /bin/tcsh.
