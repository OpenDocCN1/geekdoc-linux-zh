# TABLE 15.2 Fields in ifconfig Output (continued)

| Field | Description |
| TX packets | The number of packets transmitted and the number of errors, dropped packets, overruns, and dropped carriers that have occurred |
| collisions | The number of Ethernet collisions |
| txqueuel | The transmit queue length |
| Interrupt | The IRQ of the interface |
| Base address | The I/O port address of the interface |

If you want a report on the status of a particular network interface, issue a command of the form

```
ifconfig if
```

where if is the name of the interface. For example, the command

```
ifconfig eth0
```

reports the status of the eth0 interface.
