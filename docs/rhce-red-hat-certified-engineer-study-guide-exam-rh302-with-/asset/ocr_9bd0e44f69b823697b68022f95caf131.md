# Chapter 8 • Advanced Installations

Remove the floppy disk, and boot NT. Insert the floppy disk, copy the file linux. ldr from the floppy disk to the c:\ directory. Use a text editor to add the following line to the boot.ini file:

```
c:\linux.ldr='Linux*
```

When you boot NT, the NT loader displays a new line that is labeled Linux. Simply highlight the new line, and press Enter to boot Linux.

Note if the Windows NT system uses a FAT rather than an NTFS system, you can copy the /boot/linux. ldr to the proper Windows NT system without using a floppy disk. Mount the file system, copy the file, then unmount the file. Also note that, if you prefer, you can boot NT by LILO. If you recompile your Linux kernel, you must run /sbin/lilo, and repeat the boot sector installation procedure. Otherwise, the NT loader will be unable to find and load the new kernel.

# Other Operating Systems

You can configure Linux to boot or be booted by other operating systems, including OS/2, FreeBSD, and NetBSD. The configuration generally resembles that given for Windows NT or Windows 9x, depending on whether you prefer to use LILO as the primary boot loader or a secondary boot loader, respectively. Consult the operating system documentation to determine how to proceed. You'll probably find USENET newsgroups helpful in resolving any problems and questions you have.
