# Choosing a Window Manager

As explained, the window manager supplies borders, title bars, menu bars, manipulation buttons, and other visual elements. Some popular window managers include:

+   - AfterStep, which resembles the GUI formerly used by the NeXT operating system.

+   - Enlightenment, the window manager favored by GNOME. Enlightenment is a feature-rich window manager that requires considerable system resources.

+   - FWWM, a rather old and yet very efficient window manager that mimics Windows 95 or Motif. FWWM was developed for Linux and remains popular.

+   - Sawfish, formerly known as Sawmill, a new and largely GNOME-compliant window manager noted for its resource requirement in comparison to Enlightenment. In Red Hat Linux 6.2, it's distributed as the sawfish and sawmill-gnome packages.

+   - WindowMaker, a popular and efficient window manager that resembles the NeXTStep GUI.

If the ~/.Xclients script exists, it determines which window manager is run. If ~/.Xclients script exists, the /etc/X11/init/Xclients script determines which window manager is run. Here are the contents of the standard /etc/X11/init/Xclients script:

```
#!/bin/bash
# (c) 1999, 2000 Red Hat, Inc.

# check to see if the user has a preferred PREFERRED=
if [ -f /etc/sysconfig/desktop ]; then
    if [ -n "`grep -i GNOME /etc/sysconfig/desktop` ]; then
        PREPREFERRED=gnome-session
elif [ -n "`grep -i KDE /etc/sysconfig/desktop` ]; then
        PREPREFERRED=startkd
elif [ -n "`grep -i AnotherLevel` ]; then
    /etc/sysconfig/desktop` ]
```
