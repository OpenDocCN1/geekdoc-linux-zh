# SCSI Low-Level Drivers

Figure 18.11 shows the SCSI Low-Level Drivers of xconfig. These options are included by menuconfig as part of its SCSI screen. If the system includes one or more SCSI interfaces, you should enable the appropriate support. If the system must boot from a SCSI device, you may prefer to include in the kernel rather than as a module; otherwise, you must use mkinitrd to prepare an appropriate ramdisk, as described later in this chapter.
