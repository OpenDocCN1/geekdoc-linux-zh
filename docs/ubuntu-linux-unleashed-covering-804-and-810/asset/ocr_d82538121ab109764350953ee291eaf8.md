It is useful to have your computer ready to connect to the Internet so that you can download updates as soon as you have finished the installation. Although typically you would be recommended to not have your computer connected up, Ubuntu's unique security configuration means that it effectively blocks all incoming network ports, so it is fairly secure until you start opening these ports

# Starting the Install

To get started, insert the DVD into your drive and reboot your computer. The initial screen offers a variety of languages for you to use during installation (see Figure 1.1) followed by a list of options for you to choose from (see Figure 1.2).

However, four other options are on this screen that you need to be aware of. The second option is to Install Ubuntu, and this has the effect of running the installation program without booting into a live environment. If you select this option, you can pick up the walkthrough from Figure 1.4 later on in this section.

The next option, checking the CD for defects, can be a very useful step, especially if you've been having problems with installing Ubuntu. Should it detect any errors, you should consider downloading a fresh image from the Internet and burning a new CD. Next up is a memory checker, which can also aid troubleshooting; with the relative cheapness of RAM, it's a relatively small matter to replace any faulty memory that the checker finds.
