If you have made your mind up to switch to another environment full time then you can do it by taking one of two routes. The first one is to go to the Login Window (found under System, Administration, Login Window under Gnome and also found under the Kicker Menu, System, Login Window within KDE) and select the relevant window manager from the Default Session drop-down list, as shown in Figure 3.16.

Alternatively you can do it from the login window by pressing F10, clicking Select Session, choosing your desired window manager and selecting Make Default. This will set your default window manager to your specific choice.

Regardless of which route you take it's easy to change back should you not like your new environment.
