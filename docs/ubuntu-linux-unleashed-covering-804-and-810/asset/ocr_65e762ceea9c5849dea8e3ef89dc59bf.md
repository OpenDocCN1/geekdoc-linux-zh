# Wubi—The Easy Installer for Windows

One of the new additions to the Ubuntu CD is Wubi, which allows you to install an Ubuntu system within Windows. In effect, Wubi creates a large file to hold all the Ubuntu information and provides a way, using the Windows bootloader, to boot into Ubuntu without having to do any partitioning at all. What's more, it's almost as fast as the real thing and much faster than a Live CD. To get started with Wubi you need to simply insert the Ubuntu disc into your CD drive while Windows is booted. You'll see a screen similar to Figure 1.15.

Click the option to install inside Windows, to be taken to the next screen where you can choose some basic configuration options using the drop-down menus as shown in Figure 1.16.
