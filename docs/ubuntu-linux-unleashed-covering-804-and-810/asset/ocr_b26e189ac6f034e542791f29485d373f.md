# The Structure of a C# Program

As you can guess from its name, C# draws very heavily on C and C++ for its syntax, but it borrows several ideas from Java too. C# is object-oriented, which means your program is defined as a class, which is then instantiated through the Main() method call. To be able to draw on some of the .NET framework's many libraries, you need to add statements at the top of your files—by default there's just using System; that enables you to get access to the console to write your message.
