# What is XDMCP?

XDMCP is a great way to show off the networking capabilities of X. It stands for the X Display Manager Control Protocol and it allows you to remotely access your computer using an X terminal. Remember earlier when you read that this book was put together using various displays and computers? The secret behind all of it is XDMCP.

Clicking the Configure XDMCP button takes you to another window that allows you to specify exactly how you want XDMCP to behave, as shown in Figure 3.11.

For the most part, the default options are sufficient.
