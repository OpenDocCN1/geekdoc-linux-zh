# Staying Up-to-Date

Although you can manage your software updates through Synaptic, Ubuntu provides a dedicated tool in the form of Update Manager (launched through System, Administration, Update Manager, and shown in Figure 31.3). This tool is purposefully designed to be simple to use: when you run it, Update Manager automatically downloads the list of updates available for you and checks them all in the list it shows. If the update list was downloaded automatically not too long ago, you can force Ubuntu to refresh the list of available updates by clicking the Check button. Otherwise, all you need to do is click Install Updates and your system will be brought up-to-date. If you want a little more information about the updates, click Show Details at the bottom to see what has changed in the update.
