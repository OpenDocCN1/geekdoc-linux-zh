## Linux HOW TOs

As much as we would like to cover everything about Linux in excruciating detail in this book, we cannot. There are just too many features, quirks with PCs, devices, software packages, source files, documents, and FAQs available for Linux to cover in one volume alone. In the likely event that you have to get more specific information about a topic, you will have to consult a HOWTO file. You will find the following files in the /doc directory of the CD-ROM at the back of this book.

- **Bootdisk-HOWTO**: This is the file you would read to get more information about creating boot and root disks for your machine.
- **Busmouse-HOWTO**: This file contains information on installing and using a bus mouse with your Linux system.
- **CDROM-HOWTO**: Linux supports a variety of CD-ROM drives. Look in this file for more information about CD-ROM drive devices and Linux drivers.
- **Commercial-HOWTO**: Check out this file where you will find lists of companies and products for Linux.
- **COPYRIGHT**: This file contains the Copyright Restrictions and information about Linux.
- **Danish-HOWTO**: How to configure Linux for use with the Danish character set.
- **Distribution-HOWTO**: A general list of mail order distributions and other commercial services.
- **DOSEMU-HOWTO**: Information about the DOS Emulator (DOSEmu) for Linux.
- **ELF-HOWTO**: In the future, Linux binaries will be distributed in the format described here. Information on ELF binaries for Linux.
- **Ethernet-HOWTO**: Information on Ethernet hardware compatibility for Linux.
- **Firewall-HOWTO**: How to set up a firewall using Linux.
- **Ftape-HOWTO**: Information on ftape drive compatibility with Linux.
- **German-HOWTO**: Information on using Linux with German-specific features.
- **HAM-HOWTO**: How to configure amateur radio (HAM radio) software for Linux.
- **Hardware-HOWTO**: A list of hardware known to work with Linux.
- **HOWTO-INDEX**: Index of all the HOWTO documents about Linux. A good starting point.
- **INFO-SHEET**: A "gentle" introduction to the Linux operating system.
- **Installation-HOWTO**: How to obtain and install the Linux software from various sources.
- **JE-HOWTO**: Information on a set of Japanese language extensions for Linux.
- **Kernel-HOWTO**: Upgrading, applying patches, and compiling the Linux kernel.
- **Mail-HOWTO**: Information on using and setting up Linux-based mail servers and clients.
- **META-FAQ**: A listing of Linux sources of information.
- **MGR-HOWTO**: Information on the MGR graphics interface for Linux.
- **NET-2-HOWTO**: How to configure TCP/IP networking, SLIP, PLIP, and PPP under Linux.
- **News-HOWTO**: Information on Usenet news server and client software for Linux.
- **NIS-HOWTO**: The Linux NIS network information service, Yellow Pages, and YP setup file.
- **PCI-HOWTO**: Information on PCI-architecture compatibility.
- **PCMIA-HOWTO**: How to install and use PCMCIA Card Services (for laptops).
- **PPP-HOWTO**: Information on using PPP networking with Linux. Also read the NET-2-HOWTO file.
- **Printing-HOWTO**: Information on how to set up printing under Linux. A very informative file.
- **Printing-Usage-HOWTO**: How to use the printing system for a variety of file types and options.
- **SCSI-HOWTO**: Linux SCSI drive tape CD-ROM HOWTO.
- **SCSI-Programming-HOWTO**: Information on programming the generic Linux SCSI interface.
- **Serial-HOWTO**: Information on use of serial devices and communications software.
- **Sound-HOWTO**: Sound hardware and software for the Linux operating system.
- **Term-HOWTO**: How to use the term communications package on Linux systems.
- **Tips-HOWTO**: Miscellaneous tips and tricks for Linux.
- **UMSDOS-HOWTO**: How to install and use the UMSDOS file system.
- **UPS-HOWTO**: This file tells you how a UPS can save your Linux box from power surges.
- **UUCP-HOWTO**: Information on how to install and use the Taylor UUCP software for Linux.
- **WRITING**: Check this file out if you are interested in writing your own HOWTO file.
- **XFree86-HOWTO**: How to obtain, install, and configure XFree86 3.1.1 (X11R6).
