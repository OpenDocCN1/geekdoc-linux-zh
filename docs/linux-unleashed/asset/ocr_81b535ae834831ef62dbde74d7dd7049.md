# **NOTE**

> Strictly speaking, you don't need `</p>` tags to indicate the end of a paragraph as another `<p>` would indicate the start of a new one. The `<p>` tag is one example of an open-ended tag, one that doesn't need a closure. However, it is good programming practice to close the pairs.

What about comments in HTML code? You might want to embed some comments to yourself about who wrote the code, what it does, when you did it, and so on. The way to write a comment into HTML code is like this:

<!-- This is a comment -->
