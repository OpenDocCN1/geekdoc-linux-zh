The choice of interface you use is entirely up to you, of course, but if you are not familiar with tar’s awkward syntax, you should stick to the menu-driven interface. UNIX veterans may want to stay with the command line interface, but the menu-driven system is much easier to work with and eliminates the chance of typing errors. For most of this chapter, we’ll work with the menu-driven interface.
