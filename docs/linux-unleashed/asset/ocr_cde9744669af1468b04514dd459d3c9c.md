**TABLE 26.2. THE xgdb COMMAND-LINE OPTIONS.**

| Option | Description |
|---|---|
| db_name | Specifies the name of the debugger to be used. The default is `gdb`. |
| db_prompt | Specifies the debugger prompt. The default is `gdb`. |
| gdbinit | Specifies the filename of the initial `gdb` command file. The default is `.gdbinit`. |
| nx | Tells `xgdb` not to execute the `.gdbinit` file. |
| bigicon | Uses a large icon size for the `xgdb` icon. |

The xgdb main window contains a message that is similar to the one displayed on the screen when the command line version of gdb is started. Near the bottom of the xgdb main window there are four buttons. The Source Listing, Command Buttons, and Display Window buttons each bring up an additional window when they are activated. The Quit button terminates the xgdb program.
