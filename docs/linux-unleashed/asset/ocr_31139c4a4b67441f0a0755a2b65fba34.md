# **FIGURE 21.2.**

The config routine asks a lot of questions about which sound card you want to support.

![](bbox=[0.32, 0.37, 0.81, 0.58])

When you are asked for each type of sound card, answer N to the ones you know you are not using and Y to the one you want. Don’t let Linux guess your card, as it invariably guesses wrong.

> **Note**

If you had a sound card preconfigured in the kernel, config will ask you if you want to use it with a question like this:
Old configuration exists in /etc/soundconf. Use it [Y/n]?
If you had a working sound card before, then answer Y. If your card did not work, then answer N.
