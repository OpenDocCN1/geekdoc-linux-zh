# **NOTE**

With the bash and pdksh syntax for setting a variable, make sure that there are no spaces on either side of the equal sign. With tcsh, it doesn't matter if there are spaces or not.

Notice that you do not have to declare the variable as you would if you were program-\nmimg in C or Pascal. This is because the shell language is a nontyped interpretive\nlanguage. This means that you can use the same variable to store character strings that\nyou use to store integers. You store a character string into a variable in the same way that\nyou store the integer into a variable. For example, to set the variable called “name” to\nhave the value “Garry” use these commands:

```
name=Garry    (for pdksh and bash)
set name = Garry    (for tcsh)
```

# Accessing the Value of a Variable

After you have stored a value into a variable, how do you get the value back out? You do\nthis in the shell by preceding the variable name with a dollar sign ($). If you want to\nprint the value stored in the count variable to the screen, you do so by entering the fol-\nlowing command:

```
echo $count
```

# **TIP**

If you omit the $ from the preceding command, the echo command displays the word count onscreen.
