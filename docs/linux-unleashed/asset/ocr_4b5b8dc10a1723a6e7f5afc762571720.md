If the path /root/Office40/bin is not in your path and the current directory (.) is missing from the path as well, you have to type:

```
. /office &
```

The ampersand after the *soffice* command is used to force StarOffice into the background so you can continue to use the *X* terminal window you issued this command from. Using *soffice* is the easiest way to start StarOffice, although you can start individual applications separately if you want.
