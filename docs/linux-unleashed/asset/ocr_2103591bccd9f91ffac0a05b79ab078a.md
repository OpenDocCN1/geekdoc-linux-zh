If one backup medium is not enough for the master backup, Lone-Tar prompts you to change the medium. Lone-Tar waits until you hit Enter before continuing again. After the master backup is completed, Lone-Tar returns to the Main Menu.

Lone-Tar can use compression when making backups to fit more information on a tape or removable medium. The choice of using compression is up to you, and you will probably have been asked whether you want to use it during the installation process. The advantage of compression is simple: more data in less space.
