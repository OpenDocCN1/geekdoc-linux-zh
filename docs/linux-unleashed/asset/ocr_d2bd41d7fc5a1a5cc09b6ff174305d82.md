When in place, the Master Boot Record holds a copy of BOOTACTV. When booted, BOOTACTV allows you to make a choice of which operating system to boot. BOOTACTV can then read a boot sector from a partition to load that operating system.

To install BOOTACTV, follow these steps:

+   1. Boot Linux as usual. Make sure you have a boot floppy disk in case of problems.

3. Use the setup or LILO installation program to copy LILO into the boot sector of the Linux partition (not the Master Boot Record).

5. Reboot the machine to boot BOOTACTV from the Master Boot Record.

Your machine should load BOOTACTV and allow you to boot any other operating system on a partition. If Linux or another operating system does not boot, use your boot floppy disk to start Linux. If only Linux doesn't boot, the boot sector LILO for the Linux partition is not working and can be rewritten using the setup or LILO configuration utilities. If none of the partitions will boot, remove BOOTACTV by replacing the old Master Boot Record with the following command:

```
dd if=fd/MBR of=/dev/hda bs=446 count=1
```

You can also reinstall the Master Boot Record from within DOS, if you have a DOS boot floppy. When in DOS, issue the following command:

```
fdisk /mbr
```
