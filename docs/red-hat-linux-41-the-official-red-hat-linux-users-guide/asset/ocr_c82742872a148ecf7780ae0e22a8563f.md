# # Appendix F

# # Red Hat Linux Frequently Asked Questions

# ## F.1 Introduction

This is the second edition of the Official Red Hat Linux FAQ. It is maintained by redhat@redhat.com and all comments or suggestions for this FAQ should be sent to that address. To get updates to this FAQ, send mail to faq@redhat.com for an automated reply, or look in the docs directory of any Red Hat mirror.

If you have this document in printed form (like from the Red Hat Users Guide) and want the most up to date version, please see http://www.redhat.com or email faq@redhat.com.
