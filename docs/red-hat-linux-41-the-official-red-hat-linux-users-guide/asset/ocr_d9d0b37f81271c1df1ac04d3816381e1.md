# **F.2.12** What versions of Red Hat Linux are there?

There have been several now. Here's a rundown:

+   • Preview (or Beta) - Summer '94
+   • Halloween - Fall '94
+   • Mother's Day 1.0 - Summer '95
+   • Mother's Day 1.1 - Late Summer '95
+   • Red Hat Linux 2.0 Beta - Late Late Summer '95
+   • Red Hat Linux 2.0 - Early Fall '95
+   • Red Hat Linux 2.1 - Late Fall '95
+   • Red Hat Linux/Alpha 2.1-Beta - Late Fall '95
+   • Red Hat Linux/Alpha 2.1 - January '96
+   • Red Hat Linux/Intel 3.0.3 - March '96
+   • Red Hat Linux Rembrandt (BETA) - August '96
+   • Red Hat Linux/Intel 4.0 - October '96
+   • Red Hat Linux/Alpha 4.0 - October '96
+   • Red Hat Linux/SPARC 4.0 - October '96
+   • Red Hat Linux/Intel 4.1 - January '97
+   • Red Hat Linux/Alpha 4.1 - January '97
+   • Red Hat Linux/SPARC 4.1 - January '97
