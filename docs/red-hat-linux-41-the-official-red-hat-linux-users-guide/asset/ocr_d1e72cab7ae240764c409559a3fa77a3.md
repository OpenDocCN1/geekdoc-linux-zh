# ## B.2  SCSI parameters

| Hardware | Parameter |
| --- | --- |
| SCSI Seagate ST0x | st0x=base_addr,irq |
| SCSI Future Domain TMC-8xx | tmc8xx=base_addr,irq |
| SCSI Trantor T128 | t128=base_addr,irq |
| SCSI NCR-5380 Based | ncr5380=port,irq,dma_channel |
| Adaptec 151,2x, SB SCSI | aha152x=port,irq,scsi_id,reconnect_parity |
| Adaptec 1542 | aha1542=base_addr |
| Buslogic | buslogic=base_addr |
| Pro Audio Spectrum / Studio 16 | pas16=port,irq |

Some examples would be:

aha1542=0x330 aha152x=0x330,11,7 tmc8xx=0x330,11

Note: the above are verbose. For an AHA1522, use "aha152x". For an AHA1505, use "aha152x". For a TMC800, use "tmc8xx".

When a parameter has commas, make sure you do not put a space after a comma. If you are supplying parameters on the command line the only spaces on should be after 11nx and between multiple parameters (eg. 11nx mcd=0x340,11 bmouse=5).

# ## B.3  Ethernet parameters

The format of the ethernet parameter is as follows:

ether=irq,base_addr,mem_start,mem_end

This shouldn't be necessary for many cards, however. An example would look like:

ether=11,0x360
