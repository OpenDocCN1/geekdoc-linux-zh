# ## 8.1 User and Group Configuration

The tool shown in Figure 8.1 manages the users and groups on your system. In a sense, it is a graphical editor for /etc/passwd and /etc/group, and for /etc/shadow if you have enabled shadow passwords. With this tool you can add and remove users and groups, set login shells, full names, home directories, uid, gids, etc.
