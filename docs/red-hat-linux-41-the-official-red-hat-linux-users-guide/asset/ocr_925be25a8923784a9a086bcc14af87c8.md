# ### 8.6.4 Restarting Kernel

The changes that you make with the Kernel Daemon Configuration tool will be made in the file */etc/conf.modules*, which kernel reads whenever it is started. Once you have made changes, you can re-start kernel by clicking on the **Restart kernel** button. This will not cause any modules which are currently in use to be re-loaded, it will only notify kernel to use the configuration when it loads more modules in the future.
