# Appendix B

# Module parameters

This appendix is provided to illustrate *some* of the possible parameters that *may* be needed by certain kernel modules. It should be noted that in most cases the use of additional parameters is not needed.

# B.1 CD-ROM parameters

| Hardware | Parameter |
| --- | --- |
| Mitsumi CD-ROM | mcd=port,irq |
| Sony 31&33 CD-ROM | cdu31a=base_addr,[irq---0][,PAS] |
| Aztech CD268 | aztcd=port |
| SB Pro or 16 compatible | sbpcd=io_addr,(SB,Laser mate,SPEA) |
| ATAPI/IDE CD-ROM Drives | hd(a,b,c,d)=cdrom |

Examples of the above would be:

| Example | Configuration |
| --- | --- |
| mcd=0x340,11 | A non-IDE Mitsumi on port 340, IRQ 11 |
| cdu31a=0x340,0 | A CDU 31 -or- 33 at port 340, no IRQ |
| aztcd=0x220 | An Aztech CD-ROM at port 220 |
| hdc=cdrom | IDE, master on second interface |
| sbpcd=0x230,SoundBlaster | A Panasonic type CD-ROM at port 230 |
