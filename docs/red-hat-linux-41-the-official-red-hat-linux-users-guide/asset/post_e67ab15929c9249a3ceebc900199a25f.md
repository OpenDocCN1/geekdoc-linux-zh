# Preface

## What is Red Hat Linux?

Red Hat Linux is a complete operating system based on the Linux kernel, which was originally created by Linus Torvalds. Linux continues to be developed by a worldwide team, led by Linus, working over the Internet and is still evolving forward rapidly. The currently stable 2.0.x kernel (on which Red Hat Linux 4.1 is based) demonstrates the remarkable talent and creativity of the Linux development community as well as the value of the cooperative development model. Please see Appendix H, Red Hat and Freely Distributable Software, for more on this subject.

Since the release of version 4.0, Red Hat Linux runs on three leading computing platforms: Intel compatibles PCs, Digital Alpha computers, and Sun SPARC equipment. Our unified source tree and the benefits of RPM (Red Hat Package Management) technology enable us to keep Red Hat Linux releases for these three platforms concurrent, which in turn enables our users to manage and port software between these platforms with minimum effort.

We are pleased to note the growing number of applications being made available on the Linux operating system, several of these from Red Hat Software. We make our versions of the Linux OS available by unrestricted FTP from our site and many mirror sites on the Internet. Red Hat Linux is also available on CD-ROM. For current information on our product offerings and links to other Linux resources please check Red Hat Software’s web site at http://www.redhat.com.

On most systems, Red Hat Linux is easy to install: the installation program can walk you through the process in as little as 15 minutes. The system itself is very flexible: you can install and uninstall individual software “packages” with only a few mouse clicks. It is easy to maintain: package installations can be verified and corrected, and packages can be installed and uninstalled simply and reliably. Furthermore, Red Hat Linux is easy to administer: a set of graphical administration tools bundled into a “control-panel” reduce the hassle of everyday system administration. Complete source code is provided for the freely distributable components of the system.

## An Overview of This Book

This manual is organized in the following fashion:

- Chapter 1, Quick Start contains enough information for experienced users to perform a basic installation of Red Hat Linux/Intel without much trouble. We recommend that new Linux users read through the manual before installing to get a good understanding of the system.
- Chapter 2, Installing Red Hat Linux/Intel contains detailed instructions for installing Red Hat Linux on an Intel or compatible PC.
- Chapter 3, Installing Red Hat Linux/Alpha contains instructions for installing Red Hat Linux on a Digital Alpha.
- Chapter 4, Installing Red Hat Linux/SPARC contains instructions for installing Red Hat Linux on a Sun SPARC machine.
- Chapters 5 – 10 explain how to configure various services once you have installed Red Hat Linux, how to find documentation on your system, and how to use the various system management and administration tools which accompany Red Hat Linux. They also include an explanation of what’s special about your Red Hat Linux system, including where special files live and how to shut down Red Hat Linux.
- Appendices contain extra information about Red Hat Linux, including a list of hardware requirements, a manual for the MetroLink X server included with Red Hat Linux/Intel, the Red Hat Linux Frequently Asked Questions (FAQ), and instructions on obtaining technical support.

# Chapter 1
## Quick Start

This chapter summarizes how to install or upgrade Red Hat Linux/Intel; it is intended for users who are already experienced at installing Linux. If this chapter does not provide enough information, please read Chapter 2, *Installing Red Hat Linux/Intel*.

### 1.1 The Red Hat Linux Errata

Occasionally, we discover problems with a release of Red Hat Linux, some of which may affect installation. When we discover a problem, we post information about the problem and our solution in the Red Hat Linux Errata, which we make available in several ways:

- via the World Wide Web: `http://www.redhat.com/errata`
- via electronic mail: `errata@redhat.com`

Please note that the solution to a problem listed in the Errata may require that you use a different boot or install disk image than the ones which are mentioned below or which come with your Red Hat Linux CD-ROM.

### 1.2 Getting Red Hat Linux

There are several ways to get Red Hat Linux; the easiest way is on CD-ROM. This may not be practical if you don't have a CD-ROM drive, so we have made it freely available via FTP; you can download it from any of the Red Hat mirrors listed in Appendix F, *Red Hat Linux FAQ*.

These mirror sites are provided for those who want to install via FTP or want package upgrades. It is possible to download the distribution to a hard drive and install from there, but this is highly impractical for most and is beyond the scope of this document.

To purchase Red Hat Linux on CD-ROM, please contact Red Hat Software via any of the means listed in Appendix F.

### 1.3 Making Floppies

If you have the boot and supplemental diskettes shipped with Official Red Hat Linux 4.1, please skip to Section 1.4 below.

If your version of Red Hat Linux/Intel did not include a boot diskette and supplemental diskette, you need to create them. If there is a README file on your CD-ROM (or on the FTP site), please read it now; it contains the latest information on Red Hat Linux 4.1, some of which may be different from what you are about to read.

The boot and supplemental disk images are in the **images** directory on the CD-ROM and the FTP site. If you are doing a CD-ROM or NFS installation you will only need to make a boot diskette. All other installation methods require the supplemental diskette as well. You can use *dd* under Linux or *rawrite.exe* (found in the *dosutil* directory) under DOS to write each disk image file to a formatted high density (1.44 MB) 3.5 inch floppy.

### 1.4 Installing

To install Red Hat Linux, insert the boot floppy into drive A, and insert the CD into your CD-ROM drive (for a CD-ROM install) or connect to your network (for an FTP or NFS install). Then reboot your machine and answer all questions as they are presented. If you are installing from PCMCIA, FTP or Hard Disk, insert the supplemental disk when prompted.

### 1.5 Upgrading from a Prior Version

The installation process for Red Hat Linux 4.1 includes the ability to upgrade from prior versions of Red Hat Linux (2.0, 2.1, 3.0.3, and 4.0) which are based on RPM technology. Upgrading your system installs the modular 2.0.x kernel as well as updated versions of the packages which are installed on your machine. The upgrade process preserves existing configuration files using a `.rpmsave` extension (e.g., `sendmail.cf.rpmsave`) and leaves a log telling what actions it took in `/tmp/upgrade.log`. As software evolves, configuration file formats can change, so you should carefully compare your original configuration files to the new files before integrating your changes.

To upgrade a Red Hat Linux system, you must use a boot floppy (and possibly a supplemental floppy), just as if you were performing a full install. After selecting the medium to install from (and setting up networking information if it's required), the installation procedure prompts you to either **Install** or **Upgrade**; select **Upgrade**. This upgrade procedure is the functional equivalent of running the `upgrade` script in prior versions of Red Hat Linux.

Please note that some upgraded packages may “depend” on other packages which may not be installed on your system. The upgrade procedure takes care of these *dependencies*, but it may need to install additional packages in order to satisfy them.

### 1.6 Running Directly off the CD-ROM

Prior versions of Red Hat Linux came with a “live filesystem” on the CD-ROM; this allowed users to run Red Hat Linux directly off the CD-ROM without first installing it on their hard drive.

Unfortunately, with the modular Linux-2.0.x kernel, adding “live” boot capabilities has become too complex and is no longer supported. We apologize for the inconvenience.
