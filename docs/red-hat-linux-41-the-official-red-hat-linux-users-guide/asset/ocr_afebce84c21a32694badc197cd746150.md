**The first sector of a floppy diskette** is an alternative either of the above options; to boot Red Hat Linux, insert the LILO diskette into your machine's floppy drive and reboot. LILO starts from the floppy and presents the boot: prompt.

Select the location you wish to install LILO and press **OK**. If you do not wish to install LILO, press **Skip**.

# Limitations of LILO

LILO is subject to some limitations imposed by most PC BIOSes. Here are the “rules” of where your root partition must live if you want to install LILO on a hard drive:

+   1. If you have 2 IDE (or EIDE) drives, your root partition must live on one of them. This also includes any IDE CD-ROM drives on your primary controller. If you have one IDE hard drive, and one IDE CD-ROM on the primary controller, you must install your root partition on the hard drive.
+   2. If you have one IDE (or EIDE) drive and one or more SCSI drives, your root partition must live either on the IDE drive or the SCSI drive that is at ID 0. No other SCSI IDs will work.
+   3. If you have SCSI only, your root partition must live on a drive at ID 0 or ID 1. No other SCSI IDs will work.
+   4. In any case, your Linux kernel (and, if you have a SCSI adaptor, your initial ramdisk) must live below cylinder 1023. For IDE (or EIDE) drives, this generally means below the 512 MB mark; for SCSI drives, it's generally below the 1 GB mark. The easiest (and recommended) way to ensure this is to make sure your entire root partition is located between cylinders 0–1023. Some more recent BIOSes don't have this limitation.

# Adding Options to the LILO Boot Command Line

Finally, the installation program will ask if you wish to add default options to the LILO boot command. Any options you enter will be passed to the Linux kernel every time it boots. Press **OK** when finished.
