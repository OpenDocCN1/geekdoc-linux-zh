## Red Hat Linux Release 4.1

Official" Red Hat 4.1 includes all the latest Linux tools and utilities including the improved networking and hardware support of the latest 2.0 kernel.

This manual is the "Official" Manual at for the installation and management of your Red Hat Linux system. Whether you downloaded Red Hat off of a site on the Internet, or purchased Red Hat Linux from Red Hat Software or as part of some other product or CD-Rom set, this manual will make your use of this advanced technology easier and more enjoyable.

"Red Hat's biggest advantage is that so many of the packages and tools require little or no configuration... Red Hat is overall the most sophisticated and commercial release of Linux." *Inforworld Magazine*.

This POSIX based advanced easy-to-administer Operating System allows your PC to function as a UNIX workstation effectively and reliably for advanced computing tasks. Perfect for applications ranging from setting up an Internet Web or FTP server, Internet Applications, Research work, Software Development, even advanced computer game playing.

### EASY TO INSTALL AND MANAGE.

With RHPM"'s packaging system and the modular kernel, installation of an operating system has never been easier. Simply choose one or more configuration options and your installation can be used for the following:

- C and C++ Development  
- NFS Server  
- Anonymous FTP/ Gopher Server  
- News Server  
- Network Management  
- Workstation  
- Dialog Workstation  
- Game Machine  
- X Window System  
- Web Server  
- Printer Server  
- Networked Workstation  
- DOS-Windows  
- Connectivity  
- Multimedia Machine  
- Text Document Formatting  
- or use the manual configuration option to install and configure your Linux computer to your needs.

A number of powerful, high-level, graphical tools save advanced users hours of time, and enables the novice system administrator to custom configure and tailor their system to their needs. The soft tools covers configuration of TCP/IP, PPP, SLIP, file systems, users and groups, software packages, and more.

The RPM packaging system, a growing Linux standard, makes upgrading and maintaining your system painless and worry-free. Now in release 4.1 is "package dependencies" which eliminates guess work, and prevents major system failures when installing, uninstalling, and upgrading software packages.

### ADVANCED SYSTEM AND NETWORK SECURITY FEATURES.

The flexibility of the RPM system is what has allowed Red Hat Linux to earn the reputation as one of the most secure operating systems available. Almost as soon as security problems are found on the Internet, Red Hat Software releases new or updated packages to cope with the new threat, saving you time and reducing the possibility of compromise.

Release 4.1 of Red Hat Linux supports standard "UNIX" password authentication, as well as "shadow" passwords for additional security. The Pluggable Authentication Module (PAM) system allows additional authentication methods to be written and dynamically added to the system to support your special security needs.

### UPGRADE FROM PREVIOUS RELEASES.

Because Red Hat Linux Release 4.1 is built with advanced RPM technology, your system will never become obsolete. As new releases become available you can upgrade any or all of your components to the newest versions using a simple upgrade program that does all the work for you. Users of Red Hat Linux release 2.0, 2.1 and 3.0 (Picsos) can upgrade to release 4.1 simply and safely.

Red Hat Linux comes with complete source code for the entire operating system, including all the compilers, libraries, utilities, and the X Window System.
