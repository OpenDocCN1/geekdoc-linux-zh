# The UNIX Editors

**case** ► All employees at Dominion Consulting write weekly memos summarizing their activities and accomplishments. They write these memos using a UNIX text editor, which lets you create and modify simple text-based documents. UNIX includes at least two text editors—vi editor and Emacs. As part of your UNIX training, your manager at Dominion Consulting, Rofe Williams, asks you to use these editors to create two versions of the same memo summarizing basic features of text files.
