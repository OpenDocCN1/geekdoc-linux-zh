- **18** 选择并配置好网卡后，一个屏幕会询问引导协议。你可以从静态 IP 地址、BOOTP 或 DHCP 中选择。使用上箭头和下箭头键高亮显示正确的选项，然后按 **Enter**（回车）。如果你选择了静态 IP 地址，请继续下一步。否则，请前往第 21 步。
- **19** 下一个屏幕要求你输入计算机的 IP 地址、子网掩码、默认网关的 IP 地址以及主 DNS 服务器的 IP 地址。你的网络管理员可以提供你所有这些信息。输入正确的值，高亮显示 **Ok**（确定）按钮，并按 **Enter**。
- **20** 下一个屏幕询问你的网络域名、主机名以及次级和三级 DNS 服务器的 IP 地址。对于域名，输入分配给你的网络的域名。这通常是 *campus.edu* 或 *course.com* 形式的名称。对于主机名，输入你希望分配给这台机器的主机名。如果你有次级或三级 DNS 服务器，在最后两个字段中输入它们的 IP 地址。如果你没有次级或三级 DNS 服务器，请将这些字段留空。高亮显示 **Ok** 按钮并按 **Enter**。
- **21** 下一个屏幕询问你的时区。屏幕顶部有一个选项，可将你的硬件时钟设置为 GMT（格林尼治标准时间）。此选项将计算机内部时钟设置为 GMT，从而允许其针对夏令时调整时间。如果你希望选择此选项，请高亮显示它并按空格键。旁边会出现一个星号 (*)。
- **22** 使用上箭头和下箭头键浏览时区列表。选择你的时区，高亮显示 **Ok** 按钮，并按 **Enter**。
- **23** 下一个屏幕询问你是否要配置打印机。如果是，请高亮显示 **Yes**（是）按钮，按 **Enter**，并继续下一步。如果你不想在系统中使用打印机，请高亮显示 **No**（否）按钮，按 **Enter**，并跳过到第 33 步。
- **24** 现在要求你选择一个打印机连接。你的选择包括 Local（本地）、Remote lpd（远程 lpd）、SMB/Windows 95/NT 或 Netware。使用上箭头和下箭头键高亮显示正确的选项，并按 **Enter**。
- **25** 如果你选择了 Local，请继续下一步。如果你选择了 Remote lpd，请跳过到第 27 步。如果你选择了 SMB/Windows 95/NT，请跳过到第 28 步。如果你选择了 Netware，请跳过到第 29 步。下一个屏幕要求你输入打印机队列的名称和假脱机目录的名称。安装程序提供了默认值。这些通常是良好的值，因此请高亮显示 **Ok** 按钮并按 **Enter**。

- **26** 如果你正在配置本地打印机，请执行此步骤。接下来要求你识别打印机连接的设备。屏幕上还显示了一个自动检测到的端口列表。在自动检测到的端口列表中，`/dev/lp0` 是第一个打印机端口，`/dev/lp1` 是第二个打印机端口，`/dev/lp2` 是第三个打印机端口。安装程序为你希望连接打印机的端口提供了默认值。如果该值正确，请按 **空格键**，然后按 **Enter**。如果该值不正确，请输入正确端口的名称，按 **空格键**，并按 **Enter**。跳过到第 30 步。
- **27** 如果你正在配置远程 lpd 打印机连接，请执行此步骤。你会看到一个屏幕，询问打印机服务器的主机名以及服务器上放置打印作业的队列名称。输入正确的信息，高亮显示 **Ok** 按钮，并按 **Enter**。跳过到第 30 步。
- **28** 如果你正在配置 SMB/Windows 95/NT 打印机，请执行此步骤。你会看到一个屏幕，询问以下信息：SMB 服务器主机、SMB 服务器 IP 地址、共享名称、你的网络用户名和密码，以及工作组名称。输入正确的值，高亮显示 **Ok** 按钮，并按 **Enter**。跳过到第 30 步。
- **29** 如果你正在配置 Netware 网络打印机，请执行此步骤。你会看到一个屏幕，询问以下信息：打印机服务器名称、打印队列名称、你的用户名和密码。输入正确的值，高亮显示 **Ok** 按钮，并按 **Enter**。继续下一步。
- **30** 下一个屏幕要求你选择你正在使用的打印机类型。使用上箭头和下箭头键浏览打印机列表。高亮显示你的打印机（或与之非常接近的一款），并按 **Enter**。
- **31** 接下来你会看到一个屏幕，询问纸张大小和屏幕分辨率。为你的打印机选择正确的值。另一个选项写着：“修复文本的阶梯效应吗？”阶梯效应是一种常见问题，发生在 DOS 和 Windows 文本文件在 Linux 机器上打印时。打印机在每打印一行后执行换行操作，但不执行回车操作。这导致行看起来呈阶梯状。高亮显示此选项并按 **空格键** 进行选择。选项旁边会出现一个星号。高亮显示 **Ok** 按钮并按 **Enter**。
- **32** 下一个屏幕显示你指定的所有打印机参数，并要求你验证打印机配置。如果一切都看起来正确，请高亮显示 **Ok** 按钮并按 **Enter**。如果你希望更改某个参数，请高亮显示 **Back**（返回）按钮并按 **Enter**。继续在每个屏幕上选择 Back 按钮，直到你到达包含你要修改信息的屏幕。
- **33** 安装程序现在要求你输入 root 密码。这将成为超级用户或 root 账户的密码。作为安全措施，当你输入字符时，它们不会出现在屏幕上。你必须输入两次密码以确认它。在你第二次输入密码后，高亮显示 **Ok** 按钮并按 **Enter**。如果你输入的密码不匹配，程序要求你重复此步骤。
- **34** 设置 root 密码后，你会被询问是否要创建一个启动盘。启动盘可在紧急情况下使用，例如当系统因某些原因无法从硬盘启动时。建议你创建一个启动盘，因此请高亮显示 **Yes** 按钮并按 **Enter**。（这与你在安装过程开始时创建的启动盘不同。你现在创建的启动盘不会启动 Red Hat 安装程序，而是直接启动系统并使其进入登录提示符。）
- **35** 下一个屏幕指示你将一张空白软盘插入第一个驱动器。取出安装启动盘，并将一张空白软盘插入驱动器。按 **Enter**。程序创建启动软盘时会有一段时间延迟。（如果你看到“PCI Probe”屏幕，请高亮显示 Ok 并按 Enter。）
- **36** 安装程序现在尝试确定你使用何种类型的显卡。如果它成功检测到你的显卡，你会看到在第 37 步中描述的监视器设置屏幕。如果它无法自动确定你系统的显卡类型，你会看到一个屏幕，要求你选择你的显卡。使用上箭头和下箭头键浏览显卡列表。当你找到你的显卡时，高亮显示它并按 **Enter**。如果你的显卡未列出，你可以选择 *Unlisted Card*（未列出的显卡），它出现在列表的底部。然后你会看到一个屏幕，询问具体的技术信息，例如显卡芯片组的名称。你需要查看显卡的文档来完成设置的这部分。
- **37** 完成显卡配置后，你会被询问选择你正在使用的监视器。使用上箭头和下箭头键浏览监视器列表。当你找到你的监视器时，高亮显示它并按 **Enter**。如果你的监视器未列出，你可以选择 **Custom**（自定义）。如果你选择 *Custom*，你会被要求输入监视器的水平和垂直同步范围。你需要查看监视器的手册来确定这些值。

  注意：不要指定超出监视器能够执行的同步范围。这样做可能会损坏监视器！

- **38** 配置好监视器设置后，你必须建立屏幕配置。你会看到一个屏幕，询问你是否希望程序自动建立你监视器的默认屏幕分辨率和颜色深度。如果你希望安装程序探测系统，请高亮显示 **Yes** 按钮并按 **Enter**，然后再次按 **Enter**。探测系统可能会导致计算机锁定。如果发生这种情况，你必须重启系统并重新开始安装过程。（如果是这种情况，下次请选择 **No**。）如果探测成功，你会看到在第 42 步中描述的屏幕。如果你选择不探测系统，或者探测未成功且未锁定系统，你会看到下一步中描述的屏幕。
- **39** 下一个屏幕询问：“你有多少视频内存？”高亮显示正确的数量并按 **Enter**。
- **40** 接下来，你会被询问：“你有什么时钟芯片？” **No clockchip setting**（无时钟芯片设置）是推荐的选择，因为 Linux 通常能够自动确定这一点。高亮显示 **No clockchip setting** 并按 **Enter**。
