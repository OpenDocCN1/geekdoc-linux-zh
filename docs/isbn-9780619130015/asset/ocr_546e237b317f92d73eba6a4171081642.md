```
void message()
{
	printf("Greetings from the function message.\n");
	printf("Have a nice day.\n");
}
```

The line under the include statement that reads,

```
void message();
```

is called a function prototype. It tells the compiler about the function before the code for the function is fully defined. The word “void” means that this function returns no data. Void functions in C are like subroutines in Fortran or procedures in Pascal. They are merely modules of code that perform some task.

After the function prototype comes the function main. Main includes only one line, which reads:

```
message();
```

This is a function call. You call functions by placing their name, followed by a set of parentheses and a semicolon, at the desired place in the program. This causes the program’s control to pass to the function. When the program returns from the function, it resumes execution at the very next statement after the function call.
