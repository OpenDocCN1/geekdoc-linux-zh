You do need, however, an HTML browser program like Netscape, or UNIX utilities such as nroff and troff, to translate and execute the embedded hyperlink codes. Linux introduced groff, which implements the features of both nroff and troff. Table 8-9 lists some embedded codes supported by groff.

| Embedded Command | Meaning |
|:---|:---|
| .ce n | Center next *n* lines |
| .ds C | Center |
| .ds R | Right justify |
| .p n | Start a new paragraph indented *n* characters |
| .sa 0 | Turn off justification |
| .sa 1 | Turn on justification |
| .ul n | Underline the next *n* lines |

The groff command's usage follows this format:

| Syntax | groff [-Tdev] |
|:---|:---|
| Dissection | The -T designates a device type, which specifies an output device such as ASCII to tell groff that the device is a typewriter-like device. In the format example, the device type (*dev*) is for the man pages. Some other device types include *ps* for postscript printers, *dvi* for TeX dvi format, and *lj4* for an HP LaserJet4-compatible printer. |
