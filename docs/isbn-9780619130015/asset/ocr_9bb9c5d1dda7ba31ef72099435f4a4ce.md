# ### System Requirements

To install Red Hat Linux 6, your computer must meet the following minimum requirements:

+   - Intel 486 processor
- 16 MB of RAM
- 500 MB free hard disk space
- 3.5-inch floppy drive
- CD-ROM drive

To access a UNX/Linux host on a local-area network to which your computer is connected, you need the following software and information:

+   - Telnet program
- Either the IP address or the host and domain name of the UNIX system

To access a UNX/Linux host via the Internet, you need the following software and information:

+   - Dial-up connection to an Internet Service Provider
- Telnet program
- Either the IP address or the host and domain name of the UNIX system
