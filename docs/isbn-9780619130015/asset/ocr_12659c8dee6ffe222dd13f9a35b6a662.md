To see the contents of a directory other than your current working directory, give the directory name as an option to the **ls** command. For example, to see the contents of the /var directory, type **ls /var** and press **Enter**. You see a listing similar to the one below.

catman db gdm lib local lock log nis preserve run spool tmp yp

You can also use options to display specific information or more information than the command alone provides. The -l option for the **ls** command generates a long directory listing, which includes more information about each file. You decide to print a long listing of the /etc and /home directories for the Dominion system.
