
## C

- **C++**：一种由 AT&T Bell Labs 的 Bjarne Stroustrup 开发的编程语言，他为 C 语言添加了**面向**对象功能和其他特性。

- **C 库**：一组**函数**，用于执行文件、屏幕和键盘操作以及许多其他任务。要在程序中执行或包含这些函数之一，您需要在文件中的适当位置插入**函数调用**。

- **C shell**：专为 C 程序员设计的 UNIX 命令解释器。

- **case 逻辑**：程序开发所需的四种基本 shell 逻辑结构之一。使用 case 逻辑，程序可以根据变量的值并将结果与测试相匹配来执行许多操作之一。

- **区分大小写**：一种区分大写字母和小写字母的特性（John 与 john 不同）。UNIX 是区分大小写的。

- **cc**：UNIX 和 Linux 中 C **编译器**的名称。

- **CGI 编程**：**通用网关接口编程**的首字母缩写。

- **字符特殊文件**：与串行输入/输出设备（如打印机）相关的文件。

- **子目录**：创建并存储在**（父）**目录内的子目录。

- **客户端**：网络中运行依赖于网络**服务器**或宿主机的程序的计算机。

- **代码**：“二进制术语”或**字节**的同义词，通常在 **ASCII** 代码的上下文中使用。

- **命令**：在**命令行**提示符后输入用于请求计算机执行特定操作的文本。

- **命令行**：在屏幕上输入命令的位置。

- **命令模式**：模态编辑器的一项功能，允许您输入命令以执行编辑任务，例如在文件中移动和删除文本。UNIX vi 编辑器是一种模态编辑器。

- **通用网关接口编程**：一种控制浏览器和服务器如何通信的**协议**或规则集。任何向服务器发送信息或从服务器接收信息的脚本都必须遵守这些规则。

- **编译器**：读取**源文件**中代码行的程序，将其转换为**机器语言**指令或调用汇编器将其转换为**目标代码**，并创建机器语言文件。

- **连接**：链接。例如，通过输入 cat 命令，然后输入由单个空格分隔的多个文件名，您可以显示所有文件的内容。

- **配置变量**：一个存储关于操作系统信息且值不随时间改变的**变量**。

- **控制台**：直接连接到计算机的显示器。

- **常量**：程序代码中在程序运行时不会改变的值。

- **控制字符串**：规定在使用屏幕输出库函数 **printf** 时格式化的方式。

- **核心文件**：一种**垃圾文件**，当正在运行的程序尝试执行非法操作（如访问其他用户的内存）时创建。

## D

- **决策逻辑**：程序开发所需的四种基本 shell 逻辑结构之一。决策逻辑指出，仅当存在特定条件时，命令才会执行。在这种逻辑中，if 语句设置执行的条件。

- **递减运算符 (--)**：一种 C **算术运算符**，将变量的值减少指定量。

- **默认提示符**：系统管理员创建登录账户时系统生成的提示符。

- **依赖文件**：列在**Makefile** 中的**源代码**文件。

- **菱形运算符 (<>)**：访问打开文件中的数据。每次使用菱形运算符时，它会返回文件的下一行。

- **目录**：一种特殊的**文件**，可以包含其他文件和目录。目录文件存储常规文件和其他目录（称为**子目录**）的名称。

- **域名**：由点分隔的一组字符，用于识别和访问远程系统。例如 Lunar.campus.edu。

- **点**：表示当前**目录**的字符。两个点字符（中间无空格）表示**根目录**。作为文件名第一个字符的点表示该文件是**隐藏**的。

## E

- **编辑器**：用于创建和修改计算机文档（如程序文件和数据文件）的程序。

- **电子接口**：将**外围设备**连接到计算机的手段。

- **环境变量**：UNIX 在您**登录**时读取的一个**变量**，存储关于您工作会话特征的信息。例如，PS1 环境变量决定您的提示符显示方式。其他环境变量告诉 UNIX 在哪里查找程序、使用哪个 **shell** 以及主目录的路径。您可以按需改变环境变量的值。

- **等号 (=) 运算符**：在变量中设置值。

- **可执行文件**：可用的程序，是程序开发周期的结果。

- **可执行程序文件**：包含纯二进制或机器语言的文件，计算机可以立即使用或执行。

- **可执行文件**：驻留在 /bin 目录中用于启动系统并执行其他基本任务的程序。也称为二进制文件。

## F

- **假值**：从程序函数返回的值，表示函数未成功执行。0 代表假值。

- **文件**：数据存储的基本组件。

- **文件解密**：将文件恢复到**文件加密**之前状态的操作。

- **文件加密**：将文件内容转换为秘密代码的操作，是一种有用的安全措施。

- **文件管理器**：用于管理目录和文件并在文件系统中导航的图形应用程序。

- **文件系统**：系统在磁存储设备（如硬盘和软盘）上组织文件的方式。其组织是层次化的，类似于倒置的树：在分支结构中，顶层文件（或文件夹或目录）包含其他文件，而这些文件又包含其他文件。

- **文件传输协议 (FTP)**：一种用于发送文件的 Internet 协议。

- **文件句柄**：Perl 程序与操作系统之间的输入/输出连接。可以在程序内部用于打开、读取、写入和关闭文件。

- **平面 ASCII 文件**：您可以创建、操作并用于存储数据（如信件、产品报告或供应商记录）的文件。其作为无结构字节序列的组织方式是**文本文件**的典型特征，并因可以按任何顺序存储任何类型的数据而在数据输入方面具有灵活性。许多操作系统都可以读取这种文件类型。然而，由于只能按输入顺序检索数据，这种文件类型的用途有限。也称为**普通文件**或**常规文件**。

- **流程图**：使用一组标准符号来解释程序序列及其每个操作的动作逻辑图。

- **FORM 标签**：在 HTML 中指定您希望如何接收用户作为对您的文档的响应输入的信息。您可以选择两种方法之一：GET 或 POST。

- **FTP**：文件传输协议（File Transfer Protocol）的首字母缩写。

- **函数**：设计用于协助执行单一任务的独立代码体。您可以组合多个函数来创建程序。在某些语言中，函数被称为子例程或过程。

- **函数调用**：您在程序文件的适当位置插入以指定和使用 C 库中某个函数的一项功能。

- **函数重载**：C++ 编程语言的一项功能，允许函数响应多组标准和条件。

## G

- **g++**：UNIX 和 Linux 中 C++ 编译器的名称。

- **垃圾文件**：临时文件，如核心文件，在几天后失去其有用性。

- **GET**：一种接收用户作为 HTML 文档响应输入的信息的方法。它在 URL 本身内传输数据。

- **glob**：类似于通配符，glob 字符用于查找或匹配文件名。Glob 字符是 glob 模式的一部分。

- **glob 模式**：用于查找或匹配多个文件名的 glob 字符组合。

- **GNOME**：GNU 网络对象模型环境（GNU Network Object Model Environment）的首字母缩写。

- **GNU 网络对象模型环境 (GNOME)**：由 GNU 项目产生，GNOME 是一个必须与窗口管理器一起使用的桌面环境。
