UNIX File

case Your manager at Dominion Consulting, Rolfie Williams, wants you to extract a list of names from the phone number file you created earlier and sort the list. Then he wants you to help a Dominion client, Worldwide Hotels, design a new vendor and product report. The hotel firm wants to produce an alphabetical list of vendors and the products each offers. The vendor and product names reside in separate files: a product file and a vendor file. Both files contain vendor numbers. Rolfie asks you to use the UNIX file processing tools to produce a vendor report using the two files.
