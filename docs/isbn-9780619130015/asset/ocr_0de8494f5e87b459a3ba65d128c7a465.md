# File Structures

Files can be structured in several ways. For example, UNIX stores data, such as letters, product records, or vendor reports, in flat ASCII files. A programmer structures a file depending on the kind of data it stores. Three kinds of regular files are unstructured ASCII characters, records, and trees.
