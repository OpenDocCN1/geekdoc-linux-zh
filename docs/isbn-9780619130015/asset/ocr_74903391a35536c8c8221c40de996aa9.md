# To practice writing functions that accept arguments and return a value:

+   Use the editor of your choice to create the file `absolute.c`. Enter the following code:

```
#include <stdio.h>
int absolute(int num);
int main()
{
    int x = -12, y;
    y = absolute(x);
    printf("The absolute value of %d is %d\n", x, y);
}
int absolute(int num)
{
    if (num < 0)
        return (-num);
    else
        return (num);
}
```

+   Save the file and exit the editor.

+   Compile the program and save the executable code in a file named `absolute`.

+   Run the program. Your screen should look similar to Figure 10-8.
