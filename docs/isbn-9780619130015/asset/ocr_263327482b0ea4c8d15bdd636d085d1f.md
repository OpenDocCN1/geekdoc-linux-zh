One benefit the X Window system offers is the ability to work in multiple windows at the same time. For example, in the previous exercise you worked with the gEdit application in one window while using the spreadsheet application in another window. You can also work in multiple terminal windows at once. For example, you can edit a C program in one window, compile it in another window, and execute it in third window.
