# Configuring the Desktop

You may customize many aspects of the X Window system. In this section you will learn to personalize your desktop environment by changing the background image and specifying a screen saver. # Changing the Background and Screen Saver

The background is the desktop area behind all windows and icons. You can change the color of the desktop or specify a graphic image (known as **wallpaper**) to be used as a background. You change the background by clicking the Configuration Tool icon on the panel, shown in Figure 11-49.
