# ## Multiple Command Entry

You may type more than one command on the command line by separating each command with a semicolon (;). When you press Enter, UNIX executes the commands in the order you entered them.

> **To enter multiple commands on the command line:**
- Type `date; who -h` and press **Enter**. You see information similar to the following:
  
  `Mon Apr 20 21:35:09 EST 2000`
  `USER  LINE  LOGIN-TIME    IDLE     FROM`
  `root  tty1  Apr 20 07:56  00:29`
  `ellen tty1  Apr 20 08:15  .`
  `john  tty2  Apr 20 08:15  00:01`
  `jerry tty3  Apr 18 08:21  old`

  The `date` command produces the first line of the output shown above. The remainder of the output is the result of the `who` command.

# ## The clear Command

As you continue to enter commands, your screen may become cluttered. Unless you need to refer to commands you previously entered and their output, you can use the **clear** command to clear your screen. It has no options or arguments.

> **To clear the screen:**
- Type `clear` on the command line, and press **Enter**. The command prompt is now in the upper-left corner of your screen.

# ## The Command-line History

Often you find yourself entering the same command several times within a short period of time. Most shells keep a list of your recently used commands and allow you to recall a command without retyping it. You can access the command history with the up and down arrow keys. Pressing the up arrow key once recalls the most recently used command. Pressing the up arrow key twice recalls the second most recently used command. Each time you press the up arrow key, you recall an older command. Each time you press the down arrow key, you scroll forward in the command history. When you locate the command you want to execute, press Enter.
