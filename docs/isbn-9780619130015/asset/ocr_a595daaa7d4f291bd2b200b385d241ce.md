# Binary Files

Computers are not limited to processing ASCII codes. To work with graphic information, such as icons, illustrations, and other images, binary files can include strings of bits representing white and black dots, where each black dot represents a 1 and each white dot a 0. Graphics files include bit patterns—rows and columns of dots
