# The C Library

As you can see from Table 10-1, the C language is very small. It has no input or out-<br>put facilities as part of the language. All I/O is performed through the C library. The<br>**C library** consists of functions that perform file, screen, and keyboard operations, as<br>well as many other tasks. For example, certain functions perform string operations,<br>memory allocation and control, math operations, and much more. When you need<br>to perform one of these operations in your program, you place a **function call** at the<br>desired point. The linker joins the code of the library function with your program’s<br>object code to create the executable file.
