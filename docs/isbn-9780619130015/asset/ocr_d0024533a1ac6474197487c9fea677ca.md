In addition to the available applets, you may also add your own programs as applets to the panel. Management at Dominion Consulting has asked you to add the phoneadd script to the panel. (You developed the phoneadd script in Chapters 6 and 7.)

# To add the phoneadd script to the panel as an applet:

+   1 Position the mouse pointer over an unoccupied area of the panel, and right-click. The shortcut menu appears.

+   2 You need to add a launcher applet to the panel. A launcher executes another program when you click its icon. Click **Add new launcher** on the shortcut menu. You see the Create launcher applet window, as shown in Figure 11-56.

![](bbox=[0.2, 0.32, 0.58, 0.65])

+   3 In the Name text box, type **phoneadd Script**.

+   4 In the Comment text box, type **Adds a phone number to the corp_phones file**.

+   5 In the Command text box, type **./phoneadd**.

+   6 Leave the Type text box set to **Application**.

+   7 Click the **Run in Terminal** button.

+   8 Click the **Icon** button. The Choose an icon window appears, similar to Figure 11-57.
