# Information You Need

Before starting these steps, make sure you have the following information:

+   The server and domain name of the UNIX/Linux system you want to log onto or the system's IP address

+   Your user name and password on the UNIX/Linux system

# To establish a Telnet connection:

+   Click the **Start** button and then click **Run**.

+   In the **Run** dialog box, type **telnet** and click **OK**. The Telnet window appears, as shown in Figure A-17.

![](bbox=[0.2, 0.34, 0.91, 0.7])

Figure A-17: Telnet window

+   Click **Connect** on the menu bar, and then click **Remote System**. The **Connect** dialog box appears, as shown in Figure A-18.
