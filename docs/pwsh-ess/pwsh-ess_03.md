# 作者简介

Mark Michaelis 是创新型软件架构和开发公司 IntelliTect 的创始人、首席技术架构师和培训师。Mark 领导着他的公司不断进取，同时在世界各地举办有关领导力或技术的会议，并代表微软或其他客户进行演讲。他还撰写了大量文章和书籍，并且是东华盛顿大学的客座教授、Spokane .NET 用户组的创始人，以及每年一届的 TEDx Coeur d'Alene 活动的联合组织者。

作为世界级的 C#专家，Mark 自 2007 年以来一直担任微软区域总监，并荣任微软 MVP 超过 25 年。

Mark 拥有伊利诺伊大学哲学专业文学学士学位和伊利诺伊理工大学计算机科学硕士学位。

他不是痴迷于计算机，就是忙于陪伴家人或者打壁球（Mark 在 2016 年暂停参加铁人三项比赛，转而开始打壁球）。Mark 与妻子 Elisabeth 和三个孩子 Benjamin、Hanna 及 Abigail 住在华盛顿州斯波坎市。

技术编辑简介

Kevin Bost 是微软 MVP 和 IntelliTect 公司的高级软件架构师。他在多个创新产品中发挥了重要作用，包括 System.CommandLine、Moq.AutoMocker 和 ShowMeTheXAML。工作之余，Kevin 在线上为其他开发者讲课，并维护流行的 Material Design in XAML 工具包（[`materialdesigninxaml.net/`](http://materialdesigninxaml.net/) ）。他还喜欢棋类游戏、极限飞盘和骑摩托车。

Eric Lippert 目前在 Facebook 从事开发者工具的研发工作。此前他曾是微软 C#语言设计团队的成员。当不在 StackOverflow 上回答 C#问题或编辑编程方面的书籍时，Eric 就会去驾驶他的小帆船。他与妻子 Leah 住在华盛顿州西雅图市。
