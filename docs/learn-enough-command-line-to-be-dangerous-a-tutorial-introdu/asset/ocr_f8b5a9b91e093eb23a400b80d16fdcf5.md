Now if we want to change to the **text\_files** directory, we can **cd** to **text\_files** via the home directory ~:

```
$ pwd
/Users/mhart1/second_directory
$ cd ~/text\_files
$ pwd
/Users/mhart1/text\_files
```

Closely related to `..` for “one directory up” is `.` (read “dot”) which means “the current directory”. The most common use of `.` is when moving or copying files to the current directory:

```
$ pwd
/Users/mhart1/text\_files
$ cd ~/second_directory
$ ls
$ cp ~/text\_files/sonnets.txt .
$ ls
sonnets.txt
```

Note in that the first call to `ls` returns nothing, because **second\_directory** is initially empty.
