The **ls** command simply lists all the files and directories in the current directory (except for those that are *hidden*, which we’ll learn more about in a moment). In this sense, it’s effectively a command-line version of the graphical browser used to show files and directories (also called “folders”), as seen in Figure 13. (We’ll sharpen our understanding of directories and folders in Section 4.) As with a graphical file browser, the output in Listing 6 is just a sample, and results will differ based on the details of your system. (This goes for all the **ls** examples, so don’t be concerned if there are minor differences in output.)
