Suppose we wanted to change “From” to “F**R**om” to more closely match the text from the original sonnet (Figure 10).¹⁰ We could type `Ctrl-A` followed by the right arrow key a few times, but on some systems it’s possible to move directly to the desired spot by combining the keyboard and mouse via Option-click.
