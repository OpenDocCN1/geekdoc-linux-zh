# Unix terseness

One thing you might notice is that the commands in this section and in Section 2.2 are short: instead of list, move, copy, and remove, we have ls, mv, cp, and rm. Because the former command names are easier to understand and memorize, you may wonder why the actual commands aren’t longer (Figure 14).

The answer is that Unix dates from a time when most computer users logged on to centralized servers over slow connections, and there could be a noticeable delay between the time users pressed a key and the time it appeared on the terminal. For frequently used commands like listing files, the difference between list and ls or remove and rm could be significant.
