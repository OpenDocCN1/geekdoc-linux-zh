# There's Still More in Store from Xandros Networks

If the Internet applications that come bundled with your Xandros distro are not enough to satisfy you, there are still many more available via Xandros Networks. In addition to the popular alternates Firefox and Thunderbird, Mozilla and Ximian Evolution, you might also want to consider gftp for your FTP downloading and uploading needs, or if you're interested in creating your own web pages, the WYSIWYG web page application, *Nvu*. There are, of course, still more, so have a look around and see what else XN has to offer.
