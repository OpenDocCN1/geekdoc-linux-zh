+   1. Go to the **Edit** menu and select **Preferences**.
+   2. In the Preferences window, click the **Network** tab.
+   3. Once in the *Network* tab (Figure 11), check *Use a proxy server*, select your proxy type, and then input your proxy settings.
+   4. When finished, click **Close**.
