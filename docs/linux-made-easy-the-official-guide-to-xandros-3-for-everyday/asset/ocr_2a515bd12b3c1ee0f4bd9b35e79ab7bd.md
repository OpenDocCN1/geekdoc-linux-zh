# Project 17B: Creating a Newsletter with OpenOffice.org Draw

An overlooked, but actually quite useful, application within OpenOffice.org’s suite is Draw (Figure 17-22). Draw, as its name implies, can be used to create vector-based drawings, images in which the various shapes are based on a series of mathematical formulae, as I mentioned in Chapter 16. More important for many users is the fact that it can be used as a simple page-layout program. To get a feel for what you can do with Draw in this department, I will lead you through a little project from which you will learn how to create a simple newsletter.

# 17B-1: Getting Started

To get started, first run Draw by going to the **Launch** menu and selecting **Applications ▶ OpenOffice.org ▶ Tools ▶ Drawing Editor**. Once Draw appears, change the margins of your new document by going to the **Format** menu and selecting **Page**.

When the Page Setup window appears, reduce the margins for all sides to 0.50 in the *Margins* section in the bottom-left quadrant of that window in order to give yourself more room in which to work. When complete, your window should look like that in Figure 17-23.
