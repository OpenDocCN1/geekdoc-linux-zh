If you made any regional setting changes during the post-installation process, Xandros will pop up a small window telling you to restart the desktop so that the changes can take effect, so go ahead and click the **Restart** button to get that out of the way. If you didn’t make any changes, the First Run Wizard will close, and you’ll be ready to roll. Your new Xandros Linux system is now installed, set up, and ready to go.
