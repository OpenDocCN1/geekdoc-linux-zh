# NO MORE EXCUSES FOR USING WINDOWS!

Linux is an operating system, just like Windows or Mac OS. If you're holding this book, you're probably something of a Linux newbie. Maybe you're a Windows refugee or maybe you just want to try something new.

*Linux Made Easy* is a hands-on, step-by-step, project-based guide that will make it easier than ever for you to join the world of Linux and ditch Windows. And, with the Xandros version of Linux (included with this book), making the switch couldn't be more straightforward— even for newbies.

*Linux Made Easy* concentrates on the subjects most no-freaks care about, like installation, using the Internet, playing CDs, using scanners, working with digital cameras and photos, playing games, downloading software, syncing PDAs, printing, and making Internet phone calls. (We even treat you to a free 120-minute SkypeOut coupon.)

Whatever your level of expertise, *Linux Made Easy* will show you how to do everything with Linux that you're

used to doing with Windows—and more. And you've got everything you need to get started right here: Xandros on CD and those free SkypeOut minutes so you can call Microsoft and ask for a refund on that unused version of Windows XP.

So, have fun and enjoy Linux!
