# 20.2.5 command Function

Basically, this function copies the names of commands and their parameters one word at a time from the line[] array to the avline[] array. Each time a word is copied, a pointer is set up to point to the start of the word in one of the av[] arrays in the cmdlin[] array of structures:

```
command(int i)
{
    int j, flag, inword;

    for (j = 0; j<MAXARG-1; ++j)
    {
        while (*lineptr==' ' || *lineptr=='\t')
            ++lineptr;

        cmdlin[i].av[j] = avptr;
        cmdlin[i].av[j+1] = NULL;

        for (flag = 0; flag==0;)
        {
            switch (*lineptr)
            {
            case '>':
            case '<':
            case '|':
            case '&':
            case '\n':
                if (inword==FALSE)
                    cmdlin[i].av[j] = NULL;

                *avptr++ = '\0';
                return;
            case ' ':
            case '\t':
                inword = FALSE;
                *avptr++ = '\0';
                flag = 1;
                break;
            default:
                inword = TRUE;
                *avptr++ = *lineptr++;
                break;
            }
        }
    }
}
```
