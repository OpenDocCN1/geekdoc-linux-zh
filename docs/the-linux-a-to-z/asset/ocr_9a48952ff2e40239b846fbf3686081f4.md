To illustrate the operation of the stack during the execution of a program, we will look at two snap-shots of the stack taken during the operation of the following very simple piece of code:

```
main()
{
    int x, y;

    x = 6;
    /* snap-shot one here */
    y = twice(x);
}
```

```
twice(int n)
{
    int r;

    r = 2*n;
    /* snap-shot two here */
    return r;
}
```
