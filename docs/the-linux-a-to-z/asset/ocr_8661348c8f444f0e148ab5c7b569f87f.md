you will also need to grep -v for your own PID as well so that you don’t kill your own process while it is running. You can create all the pipes at the start of the program so that they are all available when required. Don’t forget, after doing the I/O redirection, and before calling exec() for each command, you should close all the file descriptors that the process doesn’t need (all except 0, 1 and 2), otherwise you will not get end-of-file propagated along the pipeline.
