# Inputs of Control Schedule

Know the following inputs of the Control Schedule process:

+   - Project management plan
+   - Project schedule
+   - Work performance data
+   - Project calendars
+   - Schedule data
+   - Organizational process assets

**Project Management Plan** The schedule management plan and the schedule baseline are used to carry out the Control Schedule process from within the project management plan.

**Project Schedule** To control the schedule, the project schedule itself must be included as an input into the process.
