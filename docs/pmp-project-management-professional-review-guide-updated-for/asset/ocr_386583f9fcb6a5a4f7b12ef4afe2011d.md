# Inputs of Acquire Project Team

Know the following inputs of the Acquire Project Team process:

**Human Resource Management Plan** The human resource management plan, a subsidiary of the project management plan, is essential to this process. The following are used from within this plan:

+   - Roles and responsibilities
+   - Project organization chart
+   - Staffing management plan
