# Inputs of Estimate Activity Resources

You should know the following inputs for the Estimate Activity Resources process:

+   • Schedule management plan
+   • Activity list
+   • Activity attributes
+   • Resource calendars
+   • Risk register
+   • Activity cost estimates
+   • Enterprise environmental factors
+   • Organizational process assets

# Schedule Management Plan

To help assist in determining the resources to be estimated, the schedule management plan identifies the level of accuracy and the units of measure.
