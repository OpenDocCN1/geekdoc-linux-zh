The Project Time Management Knowledge Area involves the following:

+   Keeping project activities on track and monitoring those activities against the project plan

+   Ensuring that the project is completed on time

The flow of the Project Time Management Knowledge Area is very intuitive. First, the project activities are identified and put into the order in which they will occur. Next, the resources are estimated for each activity, along with the estimated duration. Finally, the project schedule is developed and controlled as the project work moves forward.
