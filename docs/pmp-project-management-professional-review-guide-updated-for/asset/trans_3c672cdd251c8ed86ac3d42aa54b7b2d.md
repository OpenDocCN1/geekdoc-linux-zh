# PMP® 项目管理专业人士考试复习指南
### 第三版

提供针对 PMP 2015 年更新考试目标的重点、简洁的复习内容，并补充了《PMP 项目管理专业人士考试学习指南》第 8 版和《PMP 项目管理专业人士考试豪华学习指南》第 2 版。

包含交互式在线学习环境和学习工具，包括：

- 2 套练习题
- 超过 175 张电子闪卡
- 可搜索的关键术语词汇表

**已根据 2015 年考试更新**
