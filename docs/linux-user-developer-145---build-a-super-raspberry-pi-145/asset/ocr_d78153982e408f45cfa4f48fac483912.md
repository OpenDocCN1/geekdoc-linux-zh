A lot of the great British coders from Generation X are usually considered to have got their start thanks to the BBC Micro and the **BBC Computer Literacy Project in the Eighties.**

At the time, the cheap hardware was affordable for schools and allowed kids to code in ‘Beginner’s All-purpose Symbolic Instruction Code’, or BASIC. This simple language opened up programming to kids of all ages in schools and created a British computing boom. Times have slightly changed and after a bit of a struggle, computing is back into British schools.

While they won’t be learning BASIC anymore, the language still exists and is an excellent way to teach programming. The FUZE line of hardware aims to bring that back with special Raspberry Pi-powered machines.

Not only can you code in the BASIC language but you can also work on creating physical projects using an excellent custom IO board attached to the FUZE device.

In this tutorial we’ll show you how to use BASIC for programming and how to create a traffic light system.
