# FAQ: Music matters

**Q: What audio file types are open source?**
A: There are a few but the biggest ones are Vorbis and FLAC. Vorbis is usually associated with OGG files which are similar to MP3s, and FLAC is a lossless codec for the highest quality sound.

**Q: Is it legal to play MP3s on Linux?**
A: It’s a grey area and applies to other proprietary codecs as well. One of the most popular ways to decode audio is via Ffmpeg, which doesn’t store the content of the file when playing it – this means it does not fall foul of some versions of software patents. So far nobody has gone after it.

**Q: Why aren’t open codecs more popular?**
A: Some of them are, especially in the video space. There’s a five- or ten-year cycle with containers, codecs and file types it seems. It was MP3s 15 years ago, then AVIs and now MP4s. But MP3s may never be toppled with the advent of streaming services.
