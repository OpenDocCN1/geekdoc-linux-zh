# Model-to-model

Large and complex applications benefit from the ability to display the same data set in different forms. Duplicating the information wastes memory and forces developers to implement all kinds of synchronisation logic.

If the changes are limited to changes in the sorting and filtering of the individual items, a proxy model can be attached to the host model containing the actual data. It rearranges and filters the elements in order to create an independent second view of the information at hand.

Even though our `QFileSystemModel` provides the ability to sort and filter results, we will add a second layer for posterity and effect.

Start out by adding a new class to the project: Qt Creator’s ‘Add Class’ wizard can be invoked via File > New File or Project. Select the C++ group in order to find the C++ Class template.
