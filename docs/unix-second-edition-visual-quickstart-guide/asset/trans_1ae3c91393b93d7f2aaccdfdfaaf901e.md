

## 表 C.1
命令和标志（续）

| COMMAND/FLAG | DESCRIPTION |
|---|---|
| kill | 用于终止进程。 |
| -s | 指定发送的 kill 信号。 |
| -p | 指定仅打印进程 ID 而不发送 kill 信号。 |
| -l | 显示信号名称列表。 |
| less | 用于分页浏览文件；类似于 more。 |
| -?, --help | 显示命令摘要。 |
| -a | 指定在可见显示下方开始搜索。 |
| -bn | 指定每个文件的缓冲区数量。 |
| -B | 指定自动缓冲区分配。 |
| -c | 指定不滚动，而是从顶部重新绘制每个屏幕。 |
| -C | 指定不滚动，而是清除并显示新文本。 |
| -d | 对哑终端抑制错误消息。 |
| -e | 指定在到达文件末尾后向下移动时自动退出。 |
| -E | 指定到达文件末尾时自动退出。 |
| -f | 强制打开所有文件。 |
| -g | 指定仅突出显示最后找到的字符串。 |
| -G | 指定不突出显示找到的字符串。 |
| -hn | 指定向后滚动的最大行数（n）。 |
| -i | 指定不区分大小写的搜索，除非搜索字符串包含大写字母。 |
| -I | 指定始终不区分大小写的搜索。 |
| -jn | 指定目标行应在屏幕上的位置。 |
| -k filename | 指定打开并解释 filename 作为 lesskey 文件。 |
| -m | 指定详细提示，显示查看文件的百分比。 |
| -M | 指定更详细的提示。 |
| -n | 抑制行号。 |
| -N | 指定为每行显示的行号。 |
| -ofilename | 告诉 less 在查看时将输入复制到 filename。 |
| -Ofilename | 告诉 less 在查看时将输入复制到 filename 并在不确认的情况下覆盖。 |
| -ppattern | 指定从 pattern 的第一次出现开始显示。 |
| -q | 指定安静操作，仅在某些错误时响铃。 |
| -Q | 指定完全安静操作，永不响铃。 |
| -r | 指定直接显示控制字符，即使可能导致显示问题。 |
| -s | 将连续的空白行压缩为单个空白行。 |
| -S | 指定长行应被截断，而不是换行。 |
| -u | 指定应将退格和回车发送到终端。 |
| -U | 指定应将退格、制表符和回车视为控制字符。 |
| -V, --version | 显示版本号。 |
| -w | 指定用空白行而非波浪号（~）表示文件末尾后的行。 |
| -xn | 设置每 n 列的制表位。 |
| -X | 禁用 termcap 初始化字符串。 |
| -yn | 指定滚动的最大行数。 |

| -i | 指定执行不区分大小写的搜索。 |
