# ✓ Tips

+   - For even spiffier results, we like using tidy -indent -quiet --doctype loose -modify sampled.doc.html, which suppresses the informative messages from tidy, makes the output an HTML 4 document, tidily indents the output, and replaces the original with the modified file (Code Listing 17.2). All that, and only one command.
+   - Consider using tidy with the sed script (described in the next section) to do a lot of cleanup at once.
