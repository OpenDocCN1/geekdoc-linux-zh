6. Enter
Press Enter to select the option you want to change.

7. Make your selection or fill in the necessary information.

8. E
Press E to exit the configuration menu and return to the setup menu. You'll be prompted to save your changes. If you want to do so, press Y; if not, press N. You'll then whiz back to the main menu.

# Tip

+   - You can customize pine so that it automatically opens up your in-box whenever you start it. In the initial keystroke list, just type 1, v, and then press Enter to specify the initial characters.
