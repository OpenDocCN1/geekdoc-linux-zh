# Tips

+   - Note the trailing space in the prompt code: PROMPT="%n %d $ ". This space can help make it easier to use the prompt because it keeps your commands from bumping into your prompt.

+   - You can also set your prompt so that the information you set appears on one line and your actual prompt appears on the next (Code Listing 8.9). To do so, use single quotes (‘ ’) and a $ in the environment variable setting then a \n for the new line, as in PROMPT-$’%n %m\n $’. This forces the shell to treat the \n as a new line, not just as random characters in the prompt string.
