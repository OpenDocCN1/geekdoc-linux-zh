

## 使用 expr 求值表达式

Unix 还提供了 expr，可用于求值表达式。（在此用法中，术语 expressions 指的是该词的数学、逻辑、科学含义。）除了求值数学表达式之外，你还可以求值几乎任何其他内容。expr 工具常用于 shell 脚本——你很可能会在该上下文中获得 expr 的最大价值——但它在命令行上也同样适用，如代码清单 15.3 所示。

### 使用 expr 求值：

- expr 3 \* 4
在 shell 提示符下，输入 expr 后跟你应求值的表达式。在此示例中，我们将 3 乘以 4。（我们必须使用 \ 来转义（保护）*，防止 shell 将其解释为通配符。）
- expr 5 % 3
确定 5 除以 3 的模（余数）。答案出现在下一行（代码清单 15.3）。
- a=$PWD; b=$HOME; expr $a = $b
这个晦涩的表达式将 a 设置为当前目录，b 设置为 home 目录，并比较两者。如果返回 1（真），则你位于 home 目录中。如果返回 0（假），则你不在。

### 提示

- shell 脚本中的比较允许你检查某事是否属实，然后相应地采取行动。有关更多信息，请参阅第 10 章。
- expr 手册页并不特别有帮助；搜索互联网以获取 expr 的帮助。

```
[jdoe@frazzi jdoe]$ expr 3 \* 4
12
[jdoe@frazzi jdoe]$ expr 5 % 3
2
[jdoe@frazzi jdoe]$ a=$PWD; b=$HOME; expr
$ a = $b
1
[jdoe@frazzi bin]$ a=$PWD; b=$HOME; expr
$ a = $b
0
[jdoe@frazzi bin]$
```

代码清单 15.3 使用 expr 工具，求值表达式的值或其真值（或缺乏真值）是直接的。

## 使用 ispell 检查拼写

在第 4 章中，我们向你展示了如何拼写检查你的文件。Unix 还为你提供了 ispell，它提供了一种交互式拼写检查文件的方式，类似于许多文字处理程序的拼写检查功能（图 15.1）。

![](img/6ffd6bb320ccf354f5a4d57c9d95190d_330_0.png)

### 使用 ispell 检查拼写：

1. ispell gudspell
在 shell 提示符下，键入 ispell 后跟你想要拼写检查的文件名。你将被问及第一个（据称）拼写错误的单词，包含拼写错误的句子会显示出来，并提供可用于替换拼写错误单词的建议词，以及（可能）屏幕底部的菜单，如图 15.1 所示。关键菜单项列在表 15.1 中。

2. 使用 ispell 的菜单项完成拼写检查。

3. 按 (Q) 退出 ispell，保存所有更改。

### 提示

- -b 创建备份文件。
- -s 按可能正确性对猜测进行排序。
- -B 将连写词报告为拼写错误。
- -m 确保菜单出现在屏幕底部，假设它不会自动出现。

| ITEM | DESCRIPTION |
|------|-------------|
| [ ] | 接受你的拼写但不将其添加到词典中。 |
| R | 用你指定的词替换一个词（在你键入 R 之后）。 |
| A | 接受该词用于本次会话的剩余时间。 |
| I | 将该词插入你的词典。 |
| U | 将该词（全部小写）插入你的词典。 |
| Q | 退出 ispell，保存所有更改。 |
| X | 通过键入适当的数字，用建议的词替换高亮显示的词 |

```
[jdoe@frazz jdoe]$ look unf o
unfolded
unfolding
unfolds
unforeseen
unforgivable
unformatted
unfortunate
unfortunates
unfounded
[jdoe@frazz jdoe]$
```
