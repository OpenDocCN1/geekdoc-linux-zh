| bg | 用来将作业移至后台。 |
| cal | 用来显示日历 |
| -j | 使用从 1 月 1 日起按年份编号的日数显示儒略日。 |
| -y | 显示当前年份的日历。 |

| -A, --show-all | 指定显示所有控制字符。 |
