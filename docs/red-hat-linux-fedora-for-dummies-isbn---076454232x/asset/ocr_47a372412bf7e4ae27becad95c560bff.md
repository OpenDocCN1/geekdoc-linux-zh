# "Am I Fat or Just NTFS?"

The process of determining your partition type is straightforward. These instructions describe how to use the tools provided by Windows (Windows 9x, Windows Me, Windows NT, Windows 2000, and Windows XP) to show the partition type.

Follow these instructions on all Windows systems:

+   1.  **Start your computer.**
2.  **Open the My Computer icon.**
3.  **Right-click the C:\\ drive icon.**
4.  **Click the *Properties* button. You should see information displayed about the partition, as shown in Figure 2-1.**

Figure 2-1 shows the information about drive C:\\ (the partition). The upper-middle part of the figure shows, in this case, that the partition uses the FAT.
