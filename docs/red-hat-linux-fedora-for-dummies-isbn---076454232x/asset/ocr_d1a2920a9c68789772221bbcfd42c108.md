# Making life even easier with ssh-agent

Red Hat automatically starts a system named `ssh-agent`. With `ssh-agent`, you enter your pass phrase and `ssh-agent` remembers it. You have to enter the pass phrase only once while logged in to your account. From then on, `ssh-agent` provides the OpenSSH clients with the pass phrase and you no longer have to enter a password or pass phrase. Life is easy.

Setting up `ssh-agent` is simple. Follow these steps:

+   1. **Log in to your user account on the local computer.**

For example, log in as the user `rod` on `cancun`.

2. **Open a GNOME terminal by clicking the GNOME Menu and choosing System Tools→Terminal.**

3. **Enter this command:**

```css
ssh-add
```

4. **Enter your pass phrase when you're prompted.**

5. **Connect to the remote machine — for example, Cancun:**

```css
ssh cancun
```

You get logged in to your account on the remote machine without having to enter a password or pass phrase. This system works great.
