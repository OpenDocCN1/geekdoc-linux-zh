# use-id-pool

This option is *obsolete*. BIND 9 always allocates query IDs from a pool.

# zone-statistics

If **yes**, the server will, by default, collect statistical data on all zones in the server. These statistics may be accessed using `rndc stats`, which will dump them to the file listed in the **statistics-file**. See also Section 6.2.14,15.

# treat-cr-as-space

This option was used in BIND 8 to make the server treat carriage return (“r”) characters the same as a space or tab character, to facilitate loading of zone files on a UNIX system that were generated on an NT or DOS machine. In BIND 9, both UNIX “
” and NT/DOS “
” newlines are always accepted, and the option is ignored.

# additional-from-auth

# additional-from-cache

These options control the behavior of an authoritative server when answering queries which have additional data, or when following CNAME and DDNAME chains.

When both of these are set to **yes** (the default) and the query is being answered from authoritative data (a zone configured for the server), the additional data section of the reply will be filled in data from other authoritative sources and the cache. In some situations this is undesirable, such as there is concern over the correctness of the cache, or in servers where slave zones are modified by untrusted third parties. Avoiding the search for this additional data will speed up server operations at the possible expense of additional queries to resolve what would otherwise be provided in the additional section.
