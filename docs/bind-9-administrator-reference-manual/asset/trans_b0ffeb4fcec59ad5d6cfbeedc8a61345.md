## A.4.2. 互联网草案

互联网草案（IDs）是互联网工程任务组（ETF）的粗草工作文档。从本质上说，它们是处于开发阶段的 RFC。警告实现者不要将 ID 视为存档，除非附有“正在进行的工作”的免责声明，否则不应在任何正式文件中引用或引述 ID。除非经过作者更新，否则 ID 在删除后有效期仅为六个月。
