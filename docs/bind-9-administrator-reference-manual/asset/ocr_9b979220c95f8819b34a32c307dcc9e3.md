# 6.2.22.4. Dynamic Update Policies

BIND 9 supports two alternative methods of granting clients the right to perform dynamic updates to a zone, configured with the **allow-update** and **update-policy** option, respectively.

The **allow-update** class works the same way as in previous versions of BIND. It grants given clients the permission to update any record of any name in the zone.

The **update-policy** clause is new in BIND 9 and allows more fine-grained control over what updates are allowed. A set of rules is specified, where each rule grants or denies permissions for one or more names to be updated by one or more identities. If the dynamic update request message is signed (that is, it includes either TSIG or SIG(0) record), the identity of the signer can be determined.
