Then use the [Tab] key to select the Edit button, and press [Space]. You’ll then see a small dialog box permitting you to enter/modify the partition’s boot label. Press Ok when done.

> Please Note: The contents of the “Boot label” column will be what you will need to enter at LILO’s Boot: prompt in order to boot the desired operating system. However, if you forget the boot labels defined on your system, you can always press [?] at LILO’s Boot: prompt to display a list of defined boot labels.
