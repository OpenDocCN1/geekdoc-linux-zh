# Remote lpd Printers

If you selected "Remote lpd" as your printer's connection type, you'll see a dialog box similar to the one in Figure 6-10.

![](bbox=[0.085, 0.23, 0.885, 0.66])

Figure 6-10: Remote lpd Printer Options

Enter the name of the computer to which the printer is directly connected in the "Remote hostname" field. The name of the queue on the remote computer that is associated with the remote printer goes in the "remote queue" field. Select Next, and press [Space]. Now turn to Finalizing Printer Setup to continue.
