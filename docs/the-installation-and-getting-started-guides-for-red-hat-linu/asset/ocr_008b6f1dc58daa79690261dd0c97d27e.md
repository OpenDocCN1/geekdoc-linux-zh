+   - **Size** — Size indicates the size of the filesystem in megabytes (M). For removable media devices such as diskette and CD-ROM drives the stated size is listed as zero.
+   - **Partition type** — A description of the filesystem used on that partition.

Filesystems from other machines on a network may also be available. These can range from single small directories to entire volumes. No information on Size or Partition type is available for these partitions, either. Additional information on these filesystems (should you have any available) will be contained under: [Config] -> [File systems] -> [Access nfs volume]
