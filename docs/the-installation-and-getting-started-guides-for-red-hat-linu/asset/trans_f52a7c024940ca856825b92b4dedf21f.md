## 向 LILO 启动命令行添加选项

## LILO 的替代方案

如果你不想使用 LILO 来启动你的 Red Hat Linux 系统，有几种替代方案：

### 启动软盘

你可以使用安装程序创建的启动软盘（如果你选择创建的话）。

### LOADLIN

可以从 MS-DOS 加载 Linux；不幸的是，它要求 Linux 内核的副本（如果你有 SCSI 适配器，则需要初始 RAM 磁盘）位于 MS-DOS 分区上。实现此目的的唯一方法是使用其他方法（例如，使用软盘上的 LILO）启动你的 Red Hat Linux 系统，然后将内核复制到 MS-DOS 分区。LOADLIN 可从 ftp://metalab.unc.edu/pub/Linux/system/boot/dualboot/ 以及相关镜像站点获得。

### SYSLINUX

是一种与 LOADLIN 非常相似的 MS-DOS 程序；它也可在 ftp://metalab.unc.edu/pub/Linux/system/boot/loaders/ 以及相关镜像站点获得。

### 一些商业启动加载程序，

例如 System Commander，能够启动 Linux（但仍需要在你的 Linux 根分区中安装 LILO）。

## 配置 X Window 系统

如果你决定安装 X Window System 软件包，现在你将有机会为你的系统配置 X 服务器。如果你没有选择安装 X Window System 软件包，你可以跳到 Finishing Up。

## 配置 XFree86 服务器

如果你希望使用 XFree86，安装程序将启动 Xconfigurator 实用程序。Xconfigurator 首先探测你的系统，尝试确定你拥有的视频卡类型。如果失败，Xconfigurator 将显示一个视频卡列表。从列表中选择你的视频卡并按 [Enter]。如果你的视频卡未出现在列表中，XFree86 可能不支持它。但是，如果你对你的卡有技术知识，你可以选择 Unlisted Card 并尝试通过将你的卡的视频芯片组与其中一个可用的 X 服务器匹配来配置它。一旦你选择了视频卡，安装程序将安装适当的 XFree86 服务器，并且 Xconfigurator 将显示一个显示器列表。如果你的显示器出现在列表中，请选择它并按 [Enter]。否则，选择 Custom。如果你选择 Custom，Xconfigurator 会提示你选择显示器的水平同步范围和垂直同步范围（这些值通常可在随显示器提供的文档中找到，或向显示器供应商或制造商查询）。注意：除非你确定所选显示器不会超出你的显示器功能，否则不建议选择与你的显示器“相似”的显示器。如果这样做，你可能会超频你的显示器并损坏或毁坏它。接下来，Xconfigurator 会提示你输入视频卡上安装的视频内存量。如果你不确定，请查阅随视频卡提供的文档。选择比可用内存更多的内存不会损坏你的视频卡，但如果这样做，XFree86 服务器可能无法正确启动。如果所选视频卡可能具有视频时钟芯片，Xconfigurator 将显示一个时钟芯片列表。推荐的选择是 No Clockchip Setting，因为在大多数情况下 XFree86 可以自动检测正确的时钟芯片。接下来，Xconfigurator 提示你选择要使用的视频模式；通过按 [Space] 选择一个或多个模式。Xconfigurator 然后将包含你所有选择的配置文件写入 /etc/X11/XF86Config。最后，你将看到一个屏幕，提供运行 X 的选项
