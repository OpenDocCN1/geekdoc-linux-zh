# control-panel — (Version 3.11, 186K)

[W][S]

The Red Hat control panel is a configuration program launcher for the X Window System. Both convenient and pleasing, the Red Hat control panel allows you easy access to numerous X-based system administration tools included in your Red Hat Linux system. Eventually, you'll want to work with many of your system administration tools; this package helps you locate and launch many of them.

# dialog — (Version 0.6, 88K)

[W]

Dialog is a utility that allows you to show dialog boxes (containing questions or messages) in TTY (text mode) interfaces. Dialog is called from within a shell script. The following dialog boxes are implemented: yes/no, menu, input, message, text, info, checklist, radiolist, and gauge. Install dialog if you would like to create TTY dialog boxes.

# ext2ed — (Version 0.1, 288K)

Ext2ed is a program which provides a text and window interface for examining and editing an ext2 filesystem. Ext2ed is supposed to be easier to use than debugfs, but debugfs is more powerful. Note that this program should only be used by someone who is very experienced at hacking filesystems. Install ext2ed if you want to examine and/or edit your ext2 filesystem, and you know what you're doing.
