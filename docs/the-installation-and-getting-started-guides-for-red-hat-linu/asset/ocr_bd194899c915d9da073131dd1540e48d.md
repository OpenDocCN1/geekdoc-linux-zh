# Figure 16-7: The .bashrc file

Remember that any changes you make to configuration files can cause you a world of grief if you've made a mistake and you don't have a backup copy of that file. To make a backup copy, make sure you're in your login directory and in an xterm window, type:

```
cd
```

to get to your login directory. Then copy the .bashrc file, keeping it in the same directory, but with a name like .bashrc2.

```
cp .bashrc .bashrc2
```
