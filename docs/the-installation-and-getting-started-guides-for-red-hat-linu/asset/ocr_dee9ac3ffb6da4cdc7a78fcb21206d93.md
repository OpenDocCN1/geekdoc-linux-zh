# For Hard Drive Installations Only...

If you are not performing a hard drive installation, please skip ahead to Formatting Partitions. Otherwise, read on.

At this point, a dialog box entitled “Select Partition” is displayed (see Figure 4-14). Enter the device name of the partition holding the RedHat directory tree. There is also a field labelled “Directory.” If the RedHat directory is not in the root directory of that partition (for example, /test/new/RedHat), enter the path to the RedHat directory (in our example, /test/new).

![](bbox=[0.08, 0.38, 0.88, 0.82])

Figure 4-14: Selecting Partition for Hard Drive Install

If the installation program was unable to find the necessary files on the partition and directory you’ve specified, you’ll be returned to the “Select Partition” dialog box to make the necessary corrections.
