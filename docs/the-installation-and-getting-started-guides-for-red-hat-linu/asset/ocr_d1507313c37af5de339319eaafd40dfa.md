To close the query window without performing any action, left-click on the X at the top right of the window bar.

# Verifying Packages

Verifying a package checks all of the files in the package to ensure they match the ones present on your system. The checksum, file size, permissions, and owner attributes are all checked against the database. This check can be used when you suspect that one of the program’s files has become corrupted for some reason. Choosing the packages to verify is like choosing the packages to query. Select the packages in the display window and use the Verify button on the toolbar or from Packages -> Verify on the menu. A window opens like the one in Figure 10-6.
