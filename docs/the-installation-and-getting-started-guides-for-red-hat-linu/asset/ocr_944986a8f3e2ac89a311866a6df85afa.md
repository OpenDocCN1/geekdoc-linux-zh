# Figure 18-2: Selecting Sound Card Type

If you’ve run sndconfig with the —noautoconfig option, you’ll see a screen similar to the one in Figure 18-3. Here is where you can specify the settings for your sound card. Using the [Tab] key, select a field. Then use the arrow keys to select the desired setting for that field. When finished, select Ok, and press [Space].
