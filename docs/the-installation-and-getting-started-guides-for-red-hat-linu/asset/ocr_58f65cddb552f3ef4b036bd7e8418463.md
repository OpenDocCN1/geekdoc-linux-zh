# GNOME Mime Types

The GNOME Mime Types Capplet allows you to determine how you wish to handle certain file types, or Mime types. Mime stands for Multipurpose Internet Mail Extensions and was originally developed to allow e-mail to carry various forms of data. In GNOME you can define certain Mime types to be handled in any manner you wish. For example, if you use .sgml files frequently and you wish to always use Emacs to edit them you can configure the .sgml Mime type to always be handled by Emacs. This means that any program that wishes to launch the mime type for you will bring up Emacs. This includes double clicking on the file type in the GNOME File Manager.
