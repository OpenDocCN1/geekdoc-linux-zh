

## 挂载NFS文件系统

使用mount命令从另一台机器挂载NFS文件系统：

```
mkdir /mnt/local
```

仅当`/mnt/local`不存在时才需要执行

```
mount bigdog:/mnt/export /mnt/local
```

在此命令中，bigdog是NFS文件服务器的主机名，`/mnt/export`是bigdog导出的文件系统，而`/mnt/local`是本地机器上我们希望挂载该文件系统的目录。执行mount命令后（如果我们拥有来自bigdog的适当权限），我们可以输入`ls /mnt/local`来查看bigdog上`/mnt/export`中的文件列表。

## 导出NFS文件系统

控制你想要导出哪些文件系统的文件是`/etc/exports`。其格式为：

```
directory hostname(options)
```

其中（options）是可选的。例如：

```
/mnt/export speedy.redhat.com
```

将允许speedy.redhat.com挂载`/mnt/export`，但：

```
/mnt/export speedy.redhat.com(ro)
```

则只允许speedy以只读方式挂载`/mnt/export`。每次更改`/etc/exports`后，你必须告知NFS守护进程检查其中的新信息。实现此目的的一种简单方法是停止并重新启动守护进程：

```
/etc/rc.d/init.d/nfs stop
/etc/rc.d/init.d/nfs start
```

以下方法同样有效：

```
killall -HUP rpc.nfsd rpc.mountd
```

更多详细信息请参阅以下手册页：nfsd(8)、mountd(8)和exports(5)。另一本很好的参考资料是由Hal Stern编写、O'Reilly & Associates出版的《Managing NFS and NIS Services》。

## 启动过程、Init与关机

本节包含关于Red Hat Linux系统启动和关闭时所发生事情的信息。让我们从`/etc/sysconfig`中文件的信息开始。

### Sysconfig信息

以下信息概述了`/etc/sysconfig`中的不同文件、其功能及其内容。

### `/etc/sysconfig`中的文件

以下文件通常位于`/etc/sysconfig`中：

- /etc/sysconfig/clock
- /etc/sysconfig/keyboard
- /etc/sysconfig/mouse
- /etc/sysconfig/network
- /etc/sysconfig/pcmcia
- /etc/sysconfig/amd
- /etc/sysconfig/tape

让我们逐一了解每个文件。

### /etc/sysconfig/clock

`/etc/sysconfig/clock`文件控制对从系统时钟读取值的解释。较早版本的Red Hat Linux使用以下值（现已弃用）：

- CLOCKMODE=mode，其中mode为以下之一：
  - GMT — 表示时钟设置为UTC。

目前，正确的值为：

- UTC=boolean，其中boolean为以下之一：
  - true — 表示时钟设置为UTC。任何其他值表示时钟设置为本地时间。

### /etc/sysconfig/keyboard

`/etc/sysconfig/keyboard`文件控制键盘的行为。可以使用以下值：

- **KEYTABLE**=*file*，其中*file*是键表文件的名称。例如：
  `KEYTABLE="/usr/lib/kbd/keytables/us.map"`

### /etc/sysconfig/mouse

`/etc/sysconfig/mouse`文件用于指定有关可用鼠标的信息。可以使用以下值：

- **MOUSETYPE**=*type*，其中*type*为以下之一：
  - microsoft — Microsoft鼠标。
  - mouseman — MouseMan鼠标。
  - mousesystems — Mouse Systems鼠标。
  - ps/2 — PS/2鼠标。
  - msbm — Microsoft总线鼠标。
  - logibm — Logitech总线鼠标。
  - atibm — ATI总线鼠标。
  - logitech — Logitech鼠标。
  - mmseries — 较旧版本的MouseMan鼠标。
  - mmhitab — mmhitab鼠标。

- **XEMU3**=*emulation*，其中*emulation*为以下之一：
  - yes — 应模拟三键鼠标。
  - no — 鼠标已有三个按键。

此外，`/dev/mouse`是指向实际鼠标设备的符号链接。

### /etc/sysconfig/network

`/etc/sysconfig/network`文件用于指定所需网络配置的信息。可以使用以下值：

- NETWORKING=answer，其中answer为以下之一：
  - yes — 应配置网络。
  - no — 不应配置网络。

- HOSTNAME=hostname，其中hostname应为FQDN（完全限定域名），但也可以是任何你想要的主机名。
  - 请注意：为了与人们可能安装的较旧软件（如trn）兼容，`/etc/HOSTNAME`文件应包含与此处相同的值。

- FORWARD_IPV4=answer，其中answer为以下之一：
  - yes — 执行IP转发。
  - no — 不执行IP转发。

（当前的Red Hat Linux安装默认将此设置为"no"（以符合RFC要求），但如果完全未设置FORWARD_IPV4，则启用转发，以便与Red Hat Linux 4.2及更早版本上使用的配置文件兼容。）

- GATEWAY=gw-ip，其中gw-ip是网络网关的IP地址。
- GATEWAYDEV=gw-dev，其中gw-dev是网关设备（例如eth0）。
- NISDOMAIN=dom-name，其中dom-name是NIS域名。

### /etc/sysconfig/pcmcia

`/etc/sysconfig/pcmcia`文件用于指定PCMCIA配置信息。可以使用以下值：

- PCMCIA=answer，其中answer为以下之一：
  - yes — 应启用PCMCIA支持。
  - no — 不应启用PCMCIA支持。

- PCIC=pcic-type，其中pcic-type为以下之一：
  - i82365 — 计算机具有i82365风格的PCMCIA插槽芯片组。
  - tcic — 计算机具有tcic风格的PCMCIA插槽芯片组。

- PCIC_OPTS=option，其中option是插槽驱动程序（i82365或tcic）的时序参数。
