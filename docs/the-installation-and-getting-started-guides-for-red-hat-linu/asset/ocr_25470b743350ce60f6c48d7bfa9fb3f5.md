# Figure 5-10: Installation Class

+   - **Workstation** — A workstation-class installation will automatically erase all Linux partitions from your computer’s hard drive(s). This type of installation will attempt to set up a dual boot environment automatically.
+   - **Server** — A server-class installation will automatically erase all partitions from your computer’s hard drive(s).
+   - **Custom** — A custom-class installation gives you complete control over partitioning-related issues. If you have installed Red Hat Linux in the past, the custom-class installation is most similar to past installations.

**Please Note:** If you choose either Workstation or Server, part (or all) of your computer’s stored data on all drives will be erased! You will be asked to confirm your decision; however, please keep in mind that once the installation program receives your confirmation, the erasure is irrevocable.

**Please Note: WARNING** — If you choose to perform a workstation-class or server-class installation, data erasure will be irrevocable.
