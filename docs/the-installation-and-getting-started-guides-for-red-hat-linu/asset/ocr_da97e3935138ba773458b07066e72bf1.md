# PCMCIA Support

Next, the installation program will probe your system to determine if your system requires PCMCIA (also known as PC Card) support. If a PCMCIA controller is found, you'll be asked if you require PCMCIA support during the installation. If you will be using a PCMCIA device during the installation (for example, you have a PCMCIA ethernet card and you'll be installing via NFS, or you have a PCMCIA SCSI card and will be installing from a SCSI CD), you should select Yes.
