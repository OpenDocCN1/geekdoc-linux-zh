## 图15-16：shell提示符下的关机命令

在shell提示符下，您可以使用root账户重启或关闭系统。要从提示符下重启，请输入：

```
shutdown -r now
```

（见图15-16。）

或者，如果您想退出系统并关闭电脑，请输入：

```
shutdown -h now
```

-r选项代表“重启”，而-h选项表示“关机”。使用now表示您希望立即执行此操作。

请注意：在从shell提示符执行关机之前，请记住保存您的工作并退出所有可能正在运行的应用程序，因为您可能会丢失工作。

如果您选择关闭系统，您将看到一系列关于哪些服务正在停止的消息；然后，您会看到：

```
The system is halted
```

现在一切已妥善收尾，可以安全关闭电脑了。

- 提示：尝试将now替换为+5；您会发现您刚刚命令您的助手在五分钟内收好一切并停止工作。

您可以通过输入以下命令了解关于shutdown命令的更多信息：

```
man shutdown
```

在shell提示符下输入。您将看到一个“手册页”，它会告诉您关于此命令的信息。

要前进一屏，请按[空格键]；要后退一屏，请按[B]；要退出，请按[Q]。

- 摘要：要从GNOME关机或重启，请在登录界面选择“选项 -> 关机或重启”。从shell提示符：以root身份登录，然后输入shutdown -r now（重启）或shutdown -h now（关机）。

## 用启动盘自救

当您以root账户登录时，您可能需要花几分钟创建一张新的“启动盘”或复制您已有的软盘。您应该制作启动盘的原因有很多：它可以帮助您从系统故障中恢复，可以帮助您测试下载并编译的新内核，还可以帮助您在一台计算机上使用多个操作系统。

- 提示：您总是可以使用启动盘的副本来构成救援盘组的前半部分。您需要一张启动盘和一张救援盘才能进入救援模式。要了解更多关于救援模式的信息，请参阅本章后面的内容。

在安装Red Hat Linux时，您有机会制作启动盘。如果您在安装时选择不制作，现在就是您从头开始的机会。现在，我们将在X会话中从shell提示符制作启动盘。转到shell提示符：例如，在GNOME中，左键单击面板上的GNOME足迹，在菜单中选择“实用工具”，然后点击标有xterm或GNOME终端的项目之一。现在，请确保您以root身份登录。在shell提示符下，例如，如果您看到类似[billy@localhost billy]的内容，请输入：

```
[billy@localhost billy] su
Password: yourrootpassword
[root@localhost billy]#
```

这将允许您从普通用户账户切换到root账户。请注意：当您处于root账户时，您是系统上一切事务的总指挥，所以务必小心。

- 提示：su命令的意思是“替换用户”（substitute users），它允许您临时以另一个用户身份登录。

简而言之，我们将找到Linux内核版本；然后，我们将使用mkbootdisk命令从内核制作一张可启动软盘。将一张标准软盘放入软盘驱动器。

- 提示：在Linux中，软盘驱动器被称为/dev/fd0。

如果您以前使用过该软盘，请记住：您将丢失该软盘上的所有内容！
