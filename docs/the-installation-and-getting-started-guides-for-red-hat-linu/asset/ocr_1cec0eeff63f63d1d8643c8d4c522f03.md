# mpg123 — (Version 0.59q, 207K)

# multimedia — (Version 2.1, 344K)

[W]

The multimedia package contains several X Window System utilities for handling multimedia files: xplaycd, xmixer and xgetfile. Xplaycd is a CD player for playing audio CDs on your machine's CD-ROM drive. Xmixer controls the volume settings on your machine's sound card. Xgetfile is a versatile file browser, intended for use in shell scripts. Install the multimedia package if you need an audio CD player, a sound card volume controller, or a file browser for use in shell scripts.
