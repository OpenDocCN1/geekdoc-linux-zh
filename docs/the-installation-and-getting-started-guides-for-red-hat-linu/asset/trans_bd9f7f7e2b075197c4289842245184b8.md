
你可以手动编辑配置文件，也可以再次运行Xconfigurator，从我们的列表中选择一款与你的显示器规格更匹配的显示器。

最后一步配置是选择要包含在XF86Config文件中的视频模式。使用方向键在每种颜色深度（8位、16位和24位）下的列表中上下移动光标。使用[空格键]选择单独的分辨率，使用[Tab]键在颜色深度字段之间切换。选择好要使用的视频模式后，将光标移到“OK”按钮并按[Enter]，或使用[F12]快捷键。信息屏幕会提供关于选择视频模式、启动和停止X服务器的最新信息。

## 如果你已经安装了X

如果你在安装Red Hat Linux时选择了“X Window System”组件，但没有选择在系统启动时自动启动X，那么一切都已就绪。你只需让X运行起来即可。事实证明，有两种方法可以做到这一点：

- 登录后手动启动X。
- 在系统启动时自动启动X。

让我们先看手动过程。

## 手动启动X

Red Hat Linux在安装过程中会提供自动启动X的选项。如果你没有选择此选项，你会看到Red Hat Linux系统首次启动时出现的字符界面登录提示符。要启动X，你首先需要登录。使用你的非root账户登录，然后输入startx命令。屏幕应该会变黑，稍等片刻后，你会看到一个带有一个或多个窗口的图形桌面。你看到的桌面外观会因你安装的软件包和其他变量而有所不同。（更多信息请参阅第1章。）

## 自动启动X

请注意：在让X自动启动之前，务必确保你的X配置能正常工作。否则可能会导致难以登录你的Red Hat Linux系统。如果你还没有验证，请先查看上一节再继续。你可以将Red Hat Linux系统配置为在系统启动时自动启动X。按此方式配置后，xdm将运行，并显示一个图形化的登录屏幕。登录后，你将运行一个常规的X会话，就像你手动发出startx命令一样。

以下是操作方法的快速概览：

- 使用telinit测试xdm。
- 编辑/etc/inittab。
- 重新启动。

让我们详细看看每个步骤。

## 使用telinit测试xdm

telinit命令用于更改Red Hat Linux系统的“运行级别”。运行级别控制系统操作的各个方面，包括是否应启动xdm。由于xdm在运行级别5下启动，你需要执行以下命令：

```
/sbin/telinit 5
```

请注意：你必须以root身份登录才能使用telinit。另外注意，更改运行级别时，不应在Red Hat Linux系统上运行任何其他程序，因为运行级别的更改可能会终止正在运行的程序。如果一切配置正确，稍等片刻后你应该会看到xdm登录屏幕。登录并确认X桌面出现。然后注销以确保xdm再次出现。如果确实如此，说明你的系统已正确配置为自动启动X。如果有问题，你可以使用telinit返回到运行级别3（例如“/sbin/telinit 3”），或重新启动。

## 编辑/etc/inittab

文件/etc/inittab除其他用途外，还用于确定系统的默认运行级别。我们需要将默认运行级别从3改为5；因此，我们需要编辑/etc/inittab。使用你喜欢的文本编辑器，更改/etc/inittab中的这一行：

```
id:3:initdefault:
```

完成后，它应该看起来像这样：

```
id:5:initdefault:
```

**请注意：** 确保你只将数字3改为5！不要更改其他任何内容，否则你的Red Hat Linux系统可能根本无法启动！完成更改后，退出编辑器，并使用以下命令检查你的成果：

```
less /etc/inittab
```

（按[空格键]翻页浏览文件；按[Q]退出。）如果一切正常，就该重新启动了。使用shutdown命令正确关闭系统，然后你就完成了！

## 退出X

完成后，如果想退出X，请选择面板栏上的GNOME脚标，选择“注销”并回答“是”以确认你的决定。然后你将从系统注销。

**请注意：** 如果你使用GNOME作为桌面环境，所有当前正在运行的程序将在你重新登录时重新启动。

## 更换你的桌面

你可以使用Switchdesk功能来更换桌面环境。Switchdesk将显示一个屏幕，允许你在你安装的任何桌面环境之间切换。

运行程序并输入switchdesk。
