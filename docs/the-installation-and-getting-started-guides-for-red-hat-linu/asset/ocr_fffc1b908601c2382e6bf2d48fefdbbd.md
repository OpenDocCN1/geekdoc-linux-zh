# Theme Selector

The Appearances capplets contains the Theme Selector which allows you to select which GTK theme you would like to run.

GTK themes are themes which allow the GTK widget set to change look and feel. The widget set is the set of tools that provides buttons, scrollbars, checkboxes, etc. to applications. GNOME-compliant applications use the GTK tool set so most of your GNOME applications will change look and feel if you change the GTK theme.
