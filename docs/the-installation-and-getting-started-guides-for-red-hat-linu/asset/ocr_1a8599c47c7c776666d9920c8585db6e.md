# Using fdisk

If you’d rather use fdisk to manage partitions, this is the section for you. Once you’ve selected fdisk, you’ll be presented with a dialog box entitled “Partition Disks” (see Figure 4-9). In this box is a list of every disk on your computer. Move the highlight to the disk you’d like to partition, select Edit, and press [Space]. You will then enter fdisk and can partition the disk you selected. Repeat this process for each disk you want to partition. When you’re done, select “Done.”
