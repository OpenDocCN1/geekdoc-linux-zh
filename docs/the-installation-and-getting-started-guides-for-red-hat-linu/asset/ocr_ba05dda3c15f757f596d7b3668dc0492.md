# Figure 10-2: Selecting Packages in GnoRPM

You can select and unselect more than one package at a time, in more than one folder in the tree panel. To select more than one package incrementally, left-click with your mouse button, while holding down the Control key; you'll see highlighting around each additional selection.

To select more than one package “globally,” that is, make larger selections within a folder, left-click on one package, then, while holding down the Shift key, left-click on the final package you wish to select. By doing so, you'll notice that individual packages between your starting and ending selections will also be highlighted for selection. Using this option makes selecting groups of packages much quicker than selecting each package individually.

The status bar at the bottom of GnoRPM will display the total number of packages you have selected.
