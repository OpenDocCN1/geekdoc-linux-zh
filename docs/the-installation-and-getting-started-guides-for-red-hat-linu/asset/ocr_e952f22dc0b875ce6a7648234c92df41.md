While the process of non-destructive repartitioning is rather straightforward, there are a number of steps involved:

+   - Compress existing data
+   - Resize partition
+   - Create new partition(s)

Let’s take a look at each step in a bit more detail.

**Compress existing data** — As Figure 2-6 shows, the first step is to compress the data in your existing partition. The reason for doing this is to rearrange the data such that it maximizes the available free space at the "end" of the partition.
