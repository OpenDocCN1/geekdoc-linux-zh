# Other RPM Resources

For more information on RPM, check out the man page, the help screen (rpm —help), and the RPM documents available at

http://www.rpm.org/

There is also an RPM book available. It's called *Maximum RPM*, and it is available from Red Hat Software and your local bookstore. It contains a wealth of information about RPM for both the end-user and the package builder. An on-line version of the book is available at http://www.rpm.org/. There is also a mailing list for discussion of RPM related issues, called rpm-list@redhat.com. The list is archived on http://www.redhat.com/support/mailing-lists/. To subscribe, send mail to rpm-list-request@redhat.com with the word subscribe in the subject line.
