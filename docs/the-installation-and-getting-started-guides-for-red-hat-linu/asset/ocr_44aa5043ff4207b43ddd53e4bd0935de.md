# Figure 7-1: GNU Midnight Commander - The GNOME File Manager

There are two main windows within the GNOME File Manager. On the left is the tree view which represents all of the directories on your system by their hierarchical position. On the right is the directory window which will show you the contents of the directory which you have selected in the tree view.

To select a directory in the tree view simply use a single mouse click. This will change the main directory view, showing the files in the directory you have chosen. If there are directories contained within the directory, you may click on the plus sign in the tree view to expand the directory.

The main file view has a few viewing options you may wish to take advantage of: the icon view and detailed views.
