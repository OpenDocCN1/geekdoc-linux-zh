One of the easiest ways to access Linuxconf is from the shell prompt. At the prompt, type:

```
linuxconf
```

We want to add an account, so let’s scroll about a third of the way down the menu in the left panel, to the entry marked Users accounts. If the entry has a + next to it, go ahead and click on the “+”. Now, the menu will expand to show entries in the User accounts listing (as shown in Figure 15-8).
