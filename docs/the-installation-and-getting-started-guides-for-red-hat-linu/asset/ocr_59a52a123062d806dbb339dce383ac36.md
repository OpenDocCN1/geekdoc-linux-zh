# Quick Keys

+   - [o] — shows that at least one of the packages in that component group has been selected.
+   - [*] — shows that all the packages of a component group have been selected.
+   - [–] — removes all packages in a component group.
+   - [*] — selects all packages in a component group.

Please Note: In the upper right-hand corner of the screen you will see the approximate system size of the components you have selected to install.
