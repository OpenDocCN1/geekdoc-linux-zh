# Figure B-7: Disk Drive With Single Partition

That’s right — in many cases there is but a single partition spanning the entire disk, essentially duplicating the pre-partitioned days of yore. The partition table has only one entry used, and it points to the start of the partition. We’ve labeled this partition as being of type “DOS,” although as you can see from Figure B-6, that’s a bit simplistic, but adequate for the purposes of this discussion. This is a typical partition layout for most newly purchased computers with some version of Windows pre-installed.
