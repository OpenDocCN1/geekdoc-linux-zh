## 什么是 Linux？

1991 年 8 月，一位来自芬兰的学生在 comp.os.minix 新闻组发布了一个帖子，开头写道：

> 各位正在使用 minix 的朋友们，大家好——我正在为 386(486) AT 兼容机编写一个（免费的）操作系统（只是个爱好，不会像 gnu 那样庞大和专业）。

这位学生就是 Linus Torvalds，而他所说的“爱好”最终演变成了我们今天所知的 Linux。作为一个功能完备的类 POSIX 操作系统，Linux 不仅由 Linus 开发，还由世界各地数百名程序员共同开发。有趣的是，这项大规模、全球性的开发工作在很大程度上是协调的。当然，在内核方面 Linus 说了算，但 Linux 不仅仅是内核。这里没有管理基础设施；俄罗斯的一个学生拿到一块新主板，就会写一个驱动程序来支持主板上的某个炫酷功能。马里兰州的一位系统管理员需要备份软件，就自己编写，并免费提供给任何需要的人。正确的事情似乎总是在正确的时间发生。另一件有趣的事情是，Linux 可以完全不花一分钱获得。没错，

大多数软件都可以（免费）提供给任何有时间且有下载意愿的人。但不是每个人都有那么多时间……

## 什么是 Red Hat Linux？

进入一群总部位于北卡罗来纳州的程序员。他们的目标是让更多人更容易尝试 Linux。与许多其他类似团体一样，他们的做法是将所有必要的零碎部分捆绑成一个有凝聚力的发行版，让“新手”免于在 PC 上引导新操作系统时遇到的一些较为深奥的方面。然而，与其他发行版不同，这个发行版有着根本性的不同。区别何在？它不是硬盘上装有可用 Linux 副本的快照，也不是一组可以从中提取操作系统不同部分的软盘，而是基于软件包的。Linux 世界的软件开发节奏很快，因此旧软件的新版本不断推出。对于其他发行版，升级软件很痛苦——完整的升级通常意味着删除硬盘上的所有内容并重新开始。每个软件包提供不同的软件部分，经过全面测试、配置并准备好运行。想尝试新的编辑器？下载软件包并安装。几秒钟内，你就可以试用它。不喜欢？执行一条命令，软件包就被删除了。如果仅此而已，这个发行版就已经相当出色了。但基于软件包还意味着另一个优势：这个 Linux 发行版可以轻松升级。到现在你大概已经猜到，北卡罗来纳州的这群程序员就是 Red Hat Software，而这个基于软件包的发行版就是 Red Hat Linux。自 Red Hat Linux 于 1994 年夏天推出以来，Linux 和 Red Hat Software 都取得了长足的进步。许多事情已经改变：支持更多新奇的硬件、可靠性大幅提高，以及全球越来越多的公司使用 Linux。但很多事情仍然没有改变。Linux 依然由世界各地的人们共同开发；Linus 仍然参与其中。Red Hat Software 依然位于北卡罗来纳州；依然在努力让 Linux 更方便人们使用。而 Red Hat Linux 依然基于软件包；一直都是如此，
