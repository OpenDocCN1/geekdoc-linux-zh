# Installing from a Hard Drive

If you are going to install Red Hat Linux from a locally-attached hard drive, highlight “hard drive” and select Ok. Before you started the installation program, you must first have copied all the necessary files to a partition on a locally-attached hard drive. If you haven’t done this yet, please refer to Installing from an HTTP site. Continue to Upgrading or Installing for upgrade or full-installation instructions.
