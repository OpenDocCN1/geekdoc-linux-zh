# USENET Newsgroups

Another good source of help is the comp.os.linux hierarchy on USENET. If you are familiar with news, you should check it out.

# Red Hat-Specific Newsgroups

Red Hat Software currently hosts a number of newgroups specifically for users of Red Hat's software. You can either read these groups directly from news.redhat.com, or ask your news admin to add the redhat.* hierarchy to their news server.
