# Appendix C: Package List

# howto-italian — (Version 6.0, 21,596K)

This package contains the Linux HOWTO documents that have been translated into Italian. Linux HOWTOs are detailed documents which describe a specific aspect of configuring or using Linux. Install the howto-italian package if you'd like to use the Linux HOWTOs in Italian. Please note that not all of the HOWTOs have been translated. If you need to have a complete set of HOWTOs, you'll need to install the English version (the howto package).
