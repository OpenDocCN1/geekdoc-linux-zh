# Linux Volume 1: ac to zcat the basics

An excellent resource for seasoned Linux pros and beginners alike, this is one of the most exciting new books for Linux. Adapted from the Coherent Manual, this 623-page book is set-up in two parts. The first is referred to as Tutorials. The second half is the Lexicon. A wide variety of examples can be found in the book.

# The Debian Linux Users Guide

Written by one of the Debian Linux development team, The Debian Linux Users Guide is an easy to follow guide to installing and using Debian Linux. Included with the book are 3 CDs that comprise a complete ready to run multitasking operating system
