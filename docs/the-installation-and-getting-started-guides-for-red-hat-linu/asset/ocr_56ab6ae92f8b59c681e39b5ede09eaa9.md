After the first dialog box, you may see a second one. It will prompt you for a domain name, a hostname, and other networking information (see Figure 5-5). Enter the Domain name for your system and press [Enter]; the installation program carries the domain name down to the Host name field. Enter the hostname you are using in front of the domain name to form a fully-qualified domain name (FQDN).
