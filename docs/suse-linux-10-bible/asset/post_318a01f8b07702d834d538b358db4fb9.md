
# Chapter 14 ◆ Working with the System 407

Perl Version
To achieve what we want in Perl, we script the following:

```perl
#! /usr/bin/perl
use Date::Calc::Object qw(:all);
Date::Calc->date_format(2);
open (LOG, "access.log");
while (<LOG>) {
    @bits = split(/\s+/,);
    if ($bits[2]==="192.168.2.4") {
        $date = Date::Calc->gettime(@bits[0]);
        print $date, ",", @bits[6];
        print "\n";
    }
}
```

Here we define the interpreter to be Perl. The line starting with use imports the necessary functionality to format the date from the appropriate Perl module, and the next lines specify a particular format for the date and string that will be printed. We then create a file handler (LOG), and the while statement loops over the lines of the file. The next line splits the line on white space, and again we print the required information if the third element matches the required address.

The output looks like:

15-Jul-2003 11:50:43 http://journeyplanner.tfl.gov.uk/user/XSLT_TRIP_REQUEST2

15-Jul-2003 11:50:47 http://journeyplanner.tfl.gov.uk/user/XSLT_TRIP_REQUEST2

15-Jul-2003 11:50:48 http://journeyplanner.tfl.gov.uk/user/templates/tfl/modal.css

15-Jul-2003 11:50:48 http://journeyplanner.tfl.gov.uk/user/templates/common/advanced.css

Again, the script makes the Squid log more readable for us, giving us the information we want.

Note the following about these two examples:

- In each case, we are importing modules concerned with calculating and displaying dates to provide functions that would not otherwise be available (Python: from time import localtime, strftime, Perl: use Date::Calc::Object qw(:all));
- In each case we are defining a file handler to read the log file (Python: infile = open('access.log', 'r'), open (LOG, "access.log"));
- In the case of Python, the list bits that we get by splitting the line does not require any special notation to denote its type. In Perl, we have to use @bits (or an array or list) and $date for a simple variable.
- In each case we begin the file with a line starting with #! that tells the system interpreter to use. And the output differs in terms of the time zone shown.

# Linux Networking

Utilizing Linux in a networked environment, whether it is serving data or providing a service, is the main driving force for the operating system in the enterprise market. When you install SUSE, you are given the option to configure your network using system configuration. In this chapter, we delve into configuring your network using the command-line tools. Knowing how to use the tools directly as opposed to using the SUSE management tools is always the best way to learn how your system works.
