# emacs

There is a strong contrast between vi and emacs, both in terms of philosophy and
t user's experience. While vi is essentially small and efficient, emacs is large and
powerful. One of the things that many people find most irritating about vi is
the switch between command mode and text-entry mode. The emacs editor
operates differently; you access commands through key combinations involving
tCtrl and Meta keys (on Linux for Meta, read Alt).

emacs is much more than a text editor; it can be an entirely working environment.
You can use emacs as your mail client. You can use it as a completely integrated
development environment (IDE). You can even use it as a web browser (we don't
recommend this — but try if you must: You will need the emacs 3 pack-
age installed).

emacs dates back to 1976, when it was first developed by Richard Stallman
others at MIT's Artificial Intelligence Lab. The name was derived from the phrase
emacs macros. GNU emacs is part of the GNU project. The history of the project and
t split between emacs and XEmacs is well documented on various websites,
including the emacs Wiki site and www.emacs.org.

# What to Install

A bewildering variety of packages has "emacs" in their names. It is important to
realize that there are two versions of emacs included in SUSE: emacs and
emacs. This sounds as if one is for use in the text console and one in
X, but it is not as simple as that.

GNU emacs (the package emacs) runs in the graphical environment as well.
at some point in history, there was a fork in the development of emacs, and a
version of emacs with (at that time) better support for the graphical environment
split off. This was one time called Lucid emacs and is the ancestor of emacs. In
t case of GNU emacs, you can install the package emacs-x11 or if you
install emacs and emacs-nox. By default, you will get emacs-x11, and if emacs
detects that X is running, it will start in graphical mode by default. If X is not run-
ing, you will get emacs in text mode. If you want the text mode version all the time,
y should install emacs-nox and not emacs-x11.
