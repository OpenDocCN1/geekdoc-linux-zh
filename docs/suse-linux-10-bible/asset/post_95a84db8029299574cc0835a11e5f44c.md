## Config Installation Sources

You are able to install SUSE from a network, CD, or DVD. Installing SUSE using an FTP server and other network-related sources is discussed briefly in Chapter 1. When the system is installed, you can configure other installation sources for the SUSE packages. This is a common scenario when you have a few SUSE servers that run from the same installation media.

To alternate installation sources, select the Software icon after starting YaST, and click the Change Source of Installation icon in the right pane.

To set up a central Network File System (NFS) server for installing SUSE, copy the DVD or each CD-ROM into a directory on your NFS server and export it.

## Creating and Using Boot and Rescue Floppies

The installation media contain a set of floppy disk images for starting an installation if some reason you cannot boot from the CD-ROM. There is also a rescue image. These are in directory /boot on the DVD or CD1. YaST contains a module for creating floppy disks from these images. You can also write an arbitrary image to disk. Clearly, this is not useful for a new installation if you do not have another SUSE system set up, but it may be useful to have a full set of boot, module, and rescue floppies available.

If you need to create the floppies from the installation media and you don't have another SUSE system available, you can use the dd command on any Unix or Linux system (see Chapter 14). If you need to do this on a DOS or Windows system, you can use the rawwrite or rawwritin programs, which are in the /dosutils directory on the installation media.

This module is in the System section of the YaST menu, or it can be started from the command line with the command yast2 floppy. You are simply asked which floppy you want to create. The choices are as follows:

- Standard Boot Floppy 1
- Standard Boot Floppy 2
- Standard Boot Floppy 3
- Rescue Floppy
- Modules Floppies
- Custom Floppy
- Download Floppy Image

These do exactly what they say they do: Create the floppy disks from images on the installation media. YaST will use whatever installation source has already been set up to write the floppy disks. Whoever of the ones you choose, you are prompted for the floppy device (typically /dev/fd0), and the disk is written out to the floppy. There is an option to format the disk. If you choose Modules Floppies, you are prompted for which one you want to create. Usefully, the menus tell you which floppy supports hardware. There is more information in the files /boot/modules1.txt, /boot/modules2.txt, and so on for the installation media.

If you want to use the floppies that you have created to start an installation or the rescue system, just boot from the first boot floppy. Depending on your hardware, you may be prompted for one or more of the modules floppies. If you choose the rescue system at the initial boot, you will be prompted for the rescue system.

> If you want to run the rescue system from the set of floppies, all three boot floppies have been inserted, you will receive a message similar to “Make sure that CD is in your drive.” Instead of OK, choose Back, select your language settings, and then select NFS.

## Setting Up Proxy Settings

If your company uses a proxy, or you use a proxy at home, you can create a global proxy that a large proportion of network utilities will honor.

You can set up an anonymous proxy or one user with credentials. The proxy configuration itself is not intelligent because all it does is inform your applications that the proxy should be a certain host with a password (if specified). It does not impact how the application communicates with the server.

To set up your proxy configuration, select the Network Services icon after starting YaST, and select Proxy from the right pane. Next, enter your server addresses for your HTTP and FTP proxy services. If you need to configure a specific port number on your proxy, you can add this by appending a colon to the host name with the port number (see Figure 9-6).

## Using NTP Time Services

Network Time Protocol (NTP) synchronizes your machine with a centralized time server of your choosing. Time servers available on the Internet are usually a secondary source to a machine that acts as a central time server. Central (or primary) time servers are usually linked to an extremely accurate clock mechanism. To specify an NTP time source, select the Network Service icon in the left pane after starting YaST, and then select the NTP Client option from the right pane.

Selecting the NTP Client option causes you to be prompted for the host name of an NTP source (see Figure 9-7). An excellent list of NTP primary and secondary sources are available at www.eecis.udel.edu/-mills/ntp/clock2b.html. To ensure that your system automatically synchronizes itself with an NTP server, you should select the Booting option button—the default is Never, which effectively disables the NTP by your system.
