# The bochs PC Emulator

The bochs project goes a long way. It is free (licensed under the GNU LGPL) PC hardware emulator that provides a complete emulation of PC hardware in software. As is the case with QEMU and VMware (see later in the chapter), you can install an operating system into bochs. However, bochs means there is no virtualization of the underlying hardware. This means that it can be built and run on any Unix-like platform on any hardware architecture. For most practical purposes, if you want to run x86 operating systems as virtual machines on x86, then either QEMU (free) or VMware (proprietary and commercial) will probably be a better choice.
