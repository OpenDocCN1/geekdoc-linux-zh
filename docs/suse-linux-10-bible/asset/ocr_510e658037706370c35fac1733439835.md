The behavior of vsftpd is controlled by the file /etc/vsftpd.conf. The comment at the top of the file:

```
# Example config file /etc/vsftpd.conf
#
# The default compiled in settings are fairly paranoid. This sample file
# loos them a bit, to make the ftp daemon much more usable.
# Please see vsftpd.conf.5 for all compiled in defaults.
```

```
# If you do not change anything here will have a minimum setup for an
# anonymous ftp server.
```

And so once you have enabled vsftpd, you should be able to connect by FTP as follows:

```
user@client:/home/user $ ftp bible
Connected to bible:
220 (vsFTPD 2.0.2)
Name (bible:user):
```
