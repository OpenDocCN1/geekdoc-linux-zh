Any configuration changes you want to make to Postfix can be done through the web interface or through the Postfix configuration files. The same is true of the Cyrus IMAP server. For more information on Postfix and Cyrus, refer to Chapter 17.

# Administrating SLOX

To administer SLOX, you need to log in to the SLOX interface using a web browser. The administrative user who has full control over SLOX is **cyrus**. The cyrus user can control users, services, spools, and the monitoring of the SLOX administrative interface.

To log in to your SLOX installation, open a web browser and enter the IP address of the SLOX server.

If you are a cluster administrator, you would have entered the IP address of your SLOX servers into your DNS. In this case, you can use the name of the SLOX server to browse to it.

Log in with the username **cyrus** and the password that you set during the SLOX installation (see Figure 30-13).
