# 136 Part II ♦ The SUSE System

With the release of SUSE 10.0, the printed documentation has been slimmed down, so that the boxed copy includes only the book entitled SUSE Linux 10.0 Start-up. The other documentation has been combined into a single package called suselinux-manual.en This package installs all the SUSE-specific documentation (the SUSE Linux Reference and SUSE Linux 10.0 Start-up) in HTML format to the directory /usr/share/doc/manual/. The main book contains 49 chapters. The PDF version of both books are in the directory docu/ of the installation media.

The SUSE manuals have strengths and weaknesses. They are very well produced and clearly printed; the look and feel of both the book and the HTML version are elegant and easy to read. The main SUSE Linux Reference should be regarded (as name implies) as a reference book. Its coverage of the system is hard to find elsewhere. The installation chapter covers most common problems and includes sections on setting up Logical Management (LVM), RAID (Redundant Array of Independent Disks), Lightweight Directory Access Protocol (LDAP), and Network Information System (NIS), and an introduction to setting up the Domain Name System (DNS). All of this information is somewhat pared down, as a book could contain any one of the pages, but the advantage is that there is a good description of setting up these services specifically on SUSE Linux, using the YaST modules.

The Start-up book is a 275-page introduction to installing and using SUSE Linux, aimed mainly at the new desktop user. There are a good general description of YaST and introductions to the main features of both the KDE and Gnome desktops. The chapter titled "Getting to Know Linux Software" gives a useful comparison between the desktop applications available on Linux and the commonly used Windows equivalents.

The SUSE Linux Server 9 printed manual is similar to the Administration Guide that was issued with the SUSE 9.x versions.

# Man Pages

Man pages (man is for manual) are the original form of online Unix documentation. Traditionally, command-line programs have associated man pages that are installed as part of the package that program belongs to. To access a man page (for example the man page of the cp command), type man cp:

```
user@bible:--> man cp
```
