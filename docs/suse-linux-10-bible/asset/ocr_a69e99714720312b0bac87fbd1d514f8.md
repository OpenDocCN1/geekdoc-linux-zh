Listing 7-3 provides an idea of where the LOCAL facilities are used on SUSE systems. As SUSE has commented, many scripts use the LOCAL log for their logging purposes. Such facilities are a catchall for foreign programs that are not controlled by the normal logging facilities and need to use the LOCAL specifications.

# Listing 7-3: Local Specification

```
# Some foreign boot scripts require local?
#
local0,local1.* - /var/log/localmessages
local2,local3.* - /var/log/localmessages
local4,local5.* - /var/log/localmessages
local6,local7.* - /var/log/localmessages
```

> Users and administrators view /var/log/messages to see if any errors have been caught before looking in the other log files, as /var/log/messages contains information about most system errors and anomalies.
