# 808 Appendix: What's on the DVD

Note that the retail version of SUSE Linux Professional (currently version 10.1) also contains a set of installation CDs, and a printed manual. The retail version also includes printed manuals and entitles the buyer to installation support (for details see we.novell.com/support/products/suselinux/conditions.html).

Note that the DVD contains a complete description of the Linux operating system. As this is a complete operating system, installing it by default will destroy all data on your computer, although a dual-boot installation is possible (allowing you to keep your existing operating system and choose between operating systems at boot-time). We recommend that you back up all important files before attempting a dual-boot installation.

# Troubleshooting

If you have difficulty installing or using any of the materials on the companion DVD, try the following solutions:

+   * Ensure that your computer has a DVD-ROM drive and that this is the boot device in your computer BIOS.

+   * Ensure that your computer has sufficient memory (RAM). You will need at least 128MB of RAM and preferably 256MB to install this version of Linux.

+   * Read the sections of this book referring to the installation procedure, particularly Chapter 1.

+   * For other problems, see the SUSE support database at http://portal.suse.com/sdb/en/index.html
