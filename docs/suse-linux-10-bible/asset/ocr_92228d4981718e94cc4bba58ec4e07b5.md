# Documentation

One of the misconceptions that are still fairly widespread about Linux is that it is not well documented. This goes with the preconceptions that people have about the nature of open source software: they think while proprietary systems come with copious manuals, with Linux you have to be a programmer who can read the source code to understand the system.

The truth is much more refreshing and interesting. In your experience it is usually easier to find and specific information about Linux and open source software than proprietary products. The spirit of open source means that there are a variety of sources of "good" information about the software — from official documentation provided by commercial vendors to mailing lists, news postings, and other ephemeral information.

# Finding Help on Your SUSE System

Although this chapter surveys a whole spectrum of information about SUSE Linux and associated entities, we will start with documentation that you can find on your system or in your purchased package of SUSE Linux, including the official SUSE documentation.

# SUSE Linux

Your copy of SUSE Linux or SUSE Linux Enterprise comes comes with official printed documentation. Versions of SUSE up to 9 contain two printed books: SUSE Linux Administration Guide and SUSE Linux User Guide. These were also included in the installation disks with the package names suse-linux-admidingguide-en, and suse-linux-admidingguide-en-pdf, suse-linux-userguide-en, and suse-linux-userguide-en-pdf. When installed, these documents can be found under the directory /usr/share/doc/manual/.
