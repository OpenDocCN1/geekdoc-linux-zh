Notice how each time the original is no longer there. If you want to keep the original file while writing the compressed file, you can use the -c option (which writes the output to standard output) and redirect that to a file.

By default, gzip keeps the original permissions and timestamp and restores them on decompression. With the -n option, the name is also preserved, even if you change the name of the compressed file.

The bzip2 program behaves in a very similar way to gzip:

```
user@~/temp bzip2 afile
user@~/temp ls
afile.bz
```

To decompress, you can use bzip2 or the equivalent bzip2 -d:

```
user@~/temp bzip2 afile.bz2
user@~/temp ls
afile
```

It is common to see gzip and bzip2 being used together with tar, which is discussed in the latter.

One or two applications allow reading of files in the gzip format and uncompressing them and reading them on the fly. In particular, if you come across .ps files (Gzipped PostScript files), the programs g and khostview view these as without first decompressing them.

Also, a standard of utilities have versions that uncompress the file (assuming it to be gzipped). By convention, a letter z at the start of the name indicates this. For example:

+   - zgrep uncompresses the file and then runs the grep command.
- zless and zmore are versions of less and more that first uncompress the file they are acting on.

# Working with Archives

An archive is a directory tree that has been put together into a single file in such a way that it can be restored at a later date. Archives may also be compressed. The most common type of archive on Linux is the tar archive, but we also consider opio and pax archives as well as zip archives. rpm package files (used as installation packages on SUSE, Red Hot, and other Linux distributions) are a special kind of archive, as are Debian packages (.deb).
