KDE also has a print monitor. When Kprinter has a job for printing, the print status monitor Kjobviewer appears (initially as an icon in the notification area system) to show the progress of the print jobs.

Other applications may print directly to the print system rather than going through `kprinter`.

# Printing from the Command Line

After printing is set, you can print various types of files from the command line. The basic command to print a file is `lpr` (or `lp`)—they are essentially equivalent, but there are two commands for historical reasons):

```
lpr bible.ps
```

The previous commands print the postscript file `bible.ps` to the default printer.

The file is interpreted as a PostScript file and rendered completely on the page. In the same way, you can print other file types directly from the command line, because appropriate filters to convert them are included in the print system. For example, the following commands will work all (assuming the files are really in the format suggested by their filenames):

+   - lpr bible.pdf
- lpr bible.png
- lpr bible.jpg
- lpr bible.html

In the case of PostScript and PDF, this method is entirely safe and will always produce the desired result. Other file types might be detected incorrectly. In that case there is a risk that might try to render the result as plain text on the paper, which is not what you want. In general for HTML and graphics types, it makes more sense to open them in a screen viewer (Konqueror or GIMP, for example) and then print using that application's print dialog box. This usually gives some additional control over the appearance of the final printed copy in any case.
