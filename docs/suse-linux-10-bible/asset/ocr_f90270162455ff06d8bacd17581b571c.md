# Setting Up and Using a Samba Client

Most desktop SUSE users who work in an environment where Windows systems are also used to configure and start a Samba client on their machines. A Samba client on your system enables you to access Resources such as printers and file servers on your local network. A Samba client does not enable your system to export filesystems and printers to your local network — to do that, you will need to configure and start a Samba server on your system, as explained in “Setting Up a Samba Server,” later in this chapter.

If you are running the X Window system KDE desktop environment), you can execute by YaST from the Control Center menu, which is available by clicking the SUSE icon at the bottom-left corner of your KDE desktop.
