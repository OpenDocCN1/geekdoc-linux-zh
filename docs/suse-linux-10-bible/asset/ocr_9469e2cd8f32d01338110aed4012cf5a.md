# 700 Part V ♦ SUSE Linux in the Enterprise

QEMU packages are included in the SUSE distribution. QEMU is developed by Fabrice Bellard, and the latest version is always available from http://fabrice.bellard.free/qemu/.

You can install x86 operating systems in QEMU, including most versions of Windows and most Linux distributions.

QEMU manages to achieve reasonable speeds (between 5 to 10 times slower than native) using dynamic translation of binary code. The author, Fabrice Bellard also offers a QEMU accelerator known as kemu for the Linux operating system. The accelerator is a special kernel module that improves the performance of QEMU very considerably (the QEMU web claims that guest operating systems will run better than half native speed if the accelerator is running; this is nothing as good as Xen or VMware, but is far better than bochs). It works by QEMU to get access to the underlying hardware, as VMware does. Certainly informal tests show that, for, Microsoft Word on Windows 2000 QEMU with the accelerator is considerably more responsive than the same version of Word running on the machine.

The QEMU accelerator is distributed without cost licensed as proprietary software—which the author is still undecided about its eventual license status, and is looking for some kind commercial sponsorship of the project). It seems that there are fairly widespread hopes that it will be released at some point under a freely software license.

# Installing and Running QEMU

To use QEMU without the accelerator module, all you need to do is to install the package on the SUSE media.

If you want to try a version that is newer than the one currently offered by SUSE, you can download a binary distribution from the QEMU web site, which can be installed simply by copying it to the root directory and unpacking it:

```
cp qemu-0.7.1-i386.tar.gz /
cd /
t xzf qemu-0.7.1-tar.gz
```

You can also build QEMU from source, although there is no real need to do so unless you want to apply some options at compile time. If you want to use the accelerator module, you need to have a copy of the source distribution in order to build the module (see later in the chapter), but you do not actually need to build the core source from source: only the accelerator module.

QEMU needs a virtual hard disk onto to install an operating system. It includes a tool that makes creating the virtual hard disk easy. This tool is the qemu-img command. To create a virtual hard disk of size 3GB, do the following:

```
qemu-img create test.qck 3G
```
