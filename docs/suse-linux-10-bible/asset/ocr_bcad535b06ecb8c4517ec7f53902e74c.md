# # Choosing a Mail Client

When your mail server is configured, you will need to be able to read your email. You will find many mail clients available, the most popular being mutt, pine, kmail, and evolution. We briefly describe the benefits of all of the systems and where they are most commonly used.

# ## Command-Line Clients

If you have only command-line access to your mail, you will probably want to send mail or mutt.

# ### mail

The mail command is the most basic mail client of all and is used to send mail and receive it using the command line. If you want to send mail with the mail command, it just mail and the person you want to send mail to.

```
bible-- # mail just@wileybible.com
Subject: Hello there
This is a test

EOT
```

Here we have asked for the subject of the mail, and we are ready to type our mail message. Notice that at no point during this transaction are we given advice on what to do. This is stereotypical Unix commands at their best!

When the message has been entered, you will need to enter a period on a line by itself and press Enter/Return. This will send the mail to the recipient specified.

To read mail with the mail command, enter mail in the command line and press Enter/Return.

You are presented with a list of mails in your mailbox that you can read. Read a message, just enter the number of the mail you want to read:

```
bible-- # mail
mailx version 10.6 11/15/03. Type ? for help.
"/var/mail/justin/": 1 message 1
>N 1 just@wileybible.com  Thu Sep 30 11:30  14/452  "Hello there"
&
```

Press 1 and Return will show you the mail message you have just sent.

mail is installed by default on Unix systems and can be used as a resort to read your mail. It is also good because you can use the mail command to send mail through a script if you have a list of email addresses you need to send some-thing to (but not spam).
