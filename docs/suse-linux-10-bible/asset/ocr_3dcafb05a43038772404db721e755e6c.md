# 394 Part III ♦ Using the Command Line in SUSE Linux

It is interesting to compare how Webmin and YaST do a job (which, frankly neither of them is ideally suited) — adding a host to the DHCP configuration. Here we compare Webmin to YaST's DHCP server module in SUSE 9.3. While Webmin provides a web form to add all the details (see Figure 14-11), YaST required you to add each possible option separately by opening a drop-down list multiple times (see Figure 14-2), in which case you would almost have some difficulty if you did not already know how the layout of the actual configuration file is to be written (example.conf). On the other hand, both tools saved you from the misery of case you could suffer if you use a miselacomewhere and the DHCP server will not start. Interestingly, YaST has since (in 10.0) retreated from attempting to configure hosts with IP addresses in the DHCP configuration, illustrating that creating GUI tools for writing all possible types of entries to system configuration files is a tricky problem.

The Webmin home page is at web.com. Among the resources linked there is the 300-page Book of Webmin by Joe Cooper, which is available as a PDF file on the web's site page.
