# Burning CDs from the Command Line

There have been changes recently in the way Linux CD writers. Under the 2.4 kernel series, CD writers used the ide-scsi driver, which meant that they worked using SCSI emulation. In 2.6, this is no longer the case. As a result, the userspace tools had to change something.

If you want to burn disks from the command line, the tool to use cdrecord. If you are running a 2.6 kernel and your CD writer is an ATAPI device (almost all), then you will need to do something like:

```
root@bible: ~ # cdrecord -v dev=/dev/hdc speed=8 -dao -data= filename.iso
```

Here we are burning filename.iso to CD. The CD burner device is /dev/hdc (the second device on the IDE channel), and we are burning in disk at once mode (-dao) to produce a CD (-data). The speed has been specified as 8. This example assumes that you are running a 2.6 kernel.

If you are using a 2.4 kernel, ATAPI CD writers are treated as emulated SCSI devices using the ide-scsi module. In this case, the dev- parameter will refer to the SCSI device (for example, typically dev=0,0,0 on a system with no SCSI devices: cdrecord --scanbus helps to find the correct device numbers).

# Burning CDs and DVDs Using k3b

The easiest way to create CDs and DVDs is using k3b, which is a graphical tool included with all versions of SUSE. Figure 14-7 shows a CD being burned in k3b.

The k3b application allows you to burn audio CDs, data CDs, mixed-mode CDs, video CDs (VCDs), eMovie CDs, audio DVDs, DVDs, video DVDs, and eMovie DVDs from a convenient graphical interface. To specify the type of project that you want to create, select the appropriate type of project from the File New Project menu. If you simply want to burn an ISO image to a CD or DVD or extract the contents of a CD or DVD, the appropriate commands are available on the Tools k3b Tools DVD menu, respectively.
