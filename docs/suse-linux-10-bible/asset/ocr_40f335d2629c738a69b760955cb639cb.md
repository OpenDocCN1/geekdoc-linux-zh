Just as you can copy a partition to a file and mount it using the loopback device (using the -o loop option), you can create a file and create a filesystem on it as if it were a disk partition. You can then write it out to a partition or to a removable device.

```
root@bible:/tmp # dd if=/dev/zero of=image.disk count=1440k bs=1
1474560+ records in
1474560+ records out
```

What you are doing is creating a file of exactly the same size as a standard floppy disk image (1440k) by reading from the /dev/zero device (which simply outputs a stream of null bytes).

Now you can create a filesystem on the file image.disk (which you need to root to do this):

```
root@bible:/tmp # mkfs -ext2 image.disk

Now you can mount the image and copy files onto it:

```
root@bible:/tmp # mount image.disk /mnt -oloop
cp file2 /mnt
```

Now you can write the image to a floppy disk, but first you should unmount it:

```
root@bible:/tmp # unmount mnt
root@bible:/tmp # dd if=image.disk of=/dev/fd0
```
