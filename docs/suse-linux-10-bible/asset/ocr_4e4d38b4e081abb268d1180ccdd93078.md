+   ◆ The YaST installation server module

+   ◆ The use of SLP (Service Location Protocol)

Service Location Protocol allows services to advertise themselves across the network and be discovered by clients. In the case of the installation server, this means that the client server is being installed can discover any installation server on the network without the need to type in an IP number or designation. all that is required is when you start the installation on the client, you choose SLP as the source (rather than the other such as CD, NFS, local disk, and so on). The client will then discover the installation server and access the installation source through whatever protocol it is being offered, with out further manual intervention.

# Setting Up an Installation Server

The package name of YaST module that simplifies the process of setting up an installation server is yast2-inst-server. This is not installed by default, the first thing you will need to do if you want to use it is to install it in the usual way.

Once installed, the module can be started from the Misc section of YaST, or using the command

```
yast2 installserver
```
