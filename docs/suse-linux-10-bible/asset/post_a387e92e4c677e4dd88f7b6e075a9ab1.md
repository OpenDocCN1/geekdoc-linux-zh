## Viewing and Opening Different File Types and Formats

It would be impossible and useless to try to make an exhaustive list of all the file formats the reader is likely to come across on Linux. However, in the next seconds we note some of the most important file types and formats and comment on how to view or open them.

## PostScript

PostScript is a page description language. It is actually more than that—in fact it is a special-purpose programming language, but (Adobe) for the job of describing how graphic elements and text are laid out a page. A PostScript printer will accept a PostScript file and print it directly. If you have a different type of printer, the printing system will filter the PostScript appropriately before passing it to the printer, but PostScript is considered the lingua franca of printing in Linux. Applications that produce output for printing produce that output in the form of PostScript.

A PostScript file is a plain text file with a certain specific format. It always starts something like this:

```
%!PS-Adobe-3.0
%%Title: filename
```

A PostScript file is typically called something like file.ps. An encapsulated PostScript file may have the extension .eps. To view it you can use any of the programs gv, ggv, or ghostview. All use ghostscript (gs) in the background to render the file in graphical form.

You can print a PostScript directly from the command line with:

```
usersample:~/tmp lpr.file
```

Because of its importance as a format, there are a number of utilities for processing PostScript files in various ways:

- * ps2ascii tries to extract from a PostScript file.
- ps2pdf converts a PostScript file to PDF.
- The pscriptils package includes various utilities for splitting and joining PostScript files and for resizing pages.

Any application that enables you to print a file will produce PostScript. Some applications also offer a print to PDF option.

> Note: An encapsulated PostScript file (.eps) is a special type of PostScript file that includes information about its physical size (bounding box) and is designed to be included inside another document.

## PDF

PDF is related to PostScript and is also a fully documented format from Adobe. The application for opening PDF has to be Acrobat Reader, accroad, but there are also xpdf and gpdf. The ghostview application also happily opens PDF files. However, accroad best takes advantage of all the advanced features of PDF (hyperlinks, text search, fonts, and so on).

Again, a large number of utilities are available for dealing with PDF files, in particular pdfotext and pdf2ps, which try to do what their names imply.

## DVI

DVI file is a device-independent file and usually has the file extension .dri. The DVI format is almost exclusively seen as the output of the TeX and LaTeX typesetting programs. This is usually not seen as an intermediate stage in the production of PostScript; the program drifts converts a DVI file to PostScript. However, you can view DVI files directly, using xdv or kdvi. (You may have to wait a surprisingly long time while the necessary fonts are generated.)

## TeX and LaTeX Files

Among some source documentation, you will sometimes come across .tex files, which are usually LaTeX files. TeX is a markup-based typesetting system developed by Donald Knuth, and LaTeX is a widely used set of macros for Tex. If you need to create printable output from a LaTeX file that is not present, the latex file.tex creates a dvi file (see the previous section). This can be converted to PostScript with drifts file.dvi.

LaTeX is a wonderful way of making very attractive printed output and particularly for typesetting mathematics, but there is a learning curve.

## HTML

HTML is a file format that has no introduction. For editing HTML on Linux, the tool of choice is (in our view) emacs with one of its HTML modes. Another editor with nice HTML editing capabilities is free (the folding text editor), which makes it easy for you to "fold up" content of tags so that you can see the large scale structure of the code.

There are also quanta HTML editors and the Mozilla composer, as well as HTML export in OpenOffice.org.

The tool tidy checks HTML for validity based on its DOctype declaration.

If you need to extract the text from web pages or local HTML files, one way to consider is using the lynx browser with the -dump option:

```
usable:-> lynx -dump http://lwn.net/ ~ ln.txt
```

## Sound and Multimedia Formats

As far as sound is concerned, you can play .mp3, .ogg, and .wav files with a number of different applications, notably xm, and MIDI files are catered by more than one application.

The situation with movie files is not so simple.

The applications caffeine, noatun, and xine are all capable of playing movies. The caffeine application is a KDE front end for xine. The problem is that most movie formats require codecs (compressor-decompressors) that are encumbered by patents. It is possible to obtain these codecs and add them to xine.

The RealPlayer application is included in SUSE Professional. This plays .rm and ram files, which are common formats for sound and video clips on Internet news sites.

There are also third-party packages built for SUSE the very capable mplayer multimedia application, is capable of playing .avi, .wmv, .mov (QuickTime), MPEG, and other formats. Each can cope with most formats. With the addition of plugins for the various codecs, the mplayer package can use Windows dynamic link libraries (DLLs) for additional codecs. You can find SUSE packages for mplayer and the associated codecs at http://pacman.linux2.org/(a useful source of many additional packages for SUSE). In practice, using the mplayer package to get together with and codecs is the best way to get support for the widest variety of video formats on SUSE Linux.

The home of the mplayer project is at www.mplayer.hu/. SUSE provides two mailing lists that are dedicated to information about multimedia on SUSE Linux (one in German and one in English). To subscribe to these (and other) SUSE mailing lists, see www.suse.com/us/support/online_help/mailinglists/

## CSV Files

CSV (comma-separated) is a common format for exchanging data, particularly as an export format from various commercial applications running on Windows.
