| COMMAND PID USER FD TYPE SIZE NODE NAME |
| bash 4317 root cwd DIR 11,0 2048 710656 /media/cdrom |
| vi 4365 root cwd DIR 11,0 2048 710656 /media/cdrom |

The output of this command shows that the root user has two active processes that are using the filesystem on your device: a bash shell (process ID 4317) and the vi editor (process ID 4365). You can either terminate the processes manually by using the kill command and specifying the IDs of the processes you want to terminate, or you can use the fuse command to do this for.

The fuse command shows any processes associated with a specific file on a mounted filesystem. For example, to see any processes that have the file /media/cdrom/Future_README.txt execute the fuse command with the name of this file as an argument, in the following example:

```
# fuse -mk /media/cdrom/Future_README.txt
/media/cdrom/Future_README.txt: 4317c 4365c
```

The -m option is required to specify the name of the file that you want about. To terminate this process, you can add the fuse command's -k option, in the following example:

```
# fuse -nk /media/cdrom/Future_README.txt
/media/cdrom/Future_README.txt: 4317c 4365c
```

> Be careful when using the fuse command's -k option. This option terminates any processes that are accessing any component of the full path of the filesystem that you specify, which is generally fine for a path as /media/cdrom, but can kill many more processes than you expect if you specify a path such as /home. The processes you can kill are restricted to those you are authorized to terminate which is all processes if you are logged in root.

Filesystems are an integral part of Linux and operating systems in general, and understanding how they work is very important to the use, performance and optimization of a system. Filesystems are the lifeblood of a system we create, manipulate, and display data, which must be stored in a filesystem of some sort. The filesystems created during the SUSE installation are set up with default settings. As you become more of a Linux expert or simply want to experiment you find it interesting to see how the different mount options and types of filesystems discussed in this chapter help improve the performance or reliability of your system. Faster is always better, so understanding the types of filesystems to use and how to use them is something that a system administrator has to deal with at every juncture of his or her career, and if you are working with SUSE on your home system, you are officially a system administrator.
