To remove the ACL that was just set:

```
tombible:-> setfacl -x u:tanya bfile
```

Here the -x means remove, so tom is removing ACL that the user (u) tanya had on the file.

```
tombible:-> getfacl bfile
# file: bfile
# owner: tom
# group: users
user::r--
group::r--
mask:r--
other::r--
```

Here tanya's special permission has gone away.
