# Linux Fundamentals

The Linux Gazette (http://linuxgazette.net) used to have a regular feature called "Clueless at the Prompt." That title will almost certainly ring a bell with anyone who remembers or her first interactions with Linux or any other form of Unix.

Someone who wants to use Linux only as a desktop line may not need to know too much about the command login screen (typically kdm) and you see an interface (typically KDE—K Desktop Environment) that is remarkably similar to the Windows interface. Some icons are on the desktop, and you can start either from the Start menu or by clicking the icons. There is a file manager (typically Conqueror) that allows drag-drop support for moving files. For many users (and future users of Linux desktop systems), these are all they need to know. In your experience, a desktop user new to Linux can start working—doing normal office work and saving—without any need for training.

I assume that you will want and need to do more than this. A number of books are available that serve as guides to describe how to interact with the KDE user interface, which, although it has subtleties, is fairly intuitive and user friendly. From the command-line point of view, some others are basically "command references" for Linux. These can be very helpful, particularly for learning commands you might not have known about or whose syntax you can never remember. Again, this is not such a book. This book does not provide exhaustive lists of Linux commands but focuses on discussing the important ones in context and in detail.
