The program used to install SUSE Linux is known as YaST, which stands for Yet Another Tool (The 'Yet another...' convention is a standard Unix/Linux naming convention, intended to reflect honestly on the number of similar tools that different people and companies have developed to do specific tasks in their favorite, customized fashion. YaST provides a framework that performs a variety of administrative tasks, including modules for installation, all system administration and configuration tasks, and subsequent updates. The YaST interface that you use for installation is very similar to the interfaces that you will use for system configuration and administrative tasks when you have completed your SUSE Linux installation. Powerful and well designed, YaST will quickly become your friend.

# Selecting Your Installation Method

You can install SUSE in numerous ways. Different installation methods are used in different circumstances. The most common and recommended installation method is to use the installation media provided with the boxed SUSE Linux product. This book focuses on installing SUSE Linux 10 through the CDs provided with the SUSE product. Installing SUSE Linux using the DVD that is also provided in the boxed SUSE product follows essentially the same process, but with added bonus of not having to switch CDs.
