# Finding Files

Often you may want to find a file with a given name. There are two common ways to do this at the command line: the find command and the locate command.

# Using find

The find command has a bewildering number of options, and you will sometimes see complex examples of the find. But in most cases where you will want to use it, the situation will be something like this: believe that a file with a certain name exists somewhere below a certain directory (say ~/temp). Change to that directory and type:

```
user@bible:~/temp .
```

You will see everything below the current directory being listed. So if you are looking for ~/temp and you type:

```
user@bible:~/temp . | grep a
```

You will get output showing the path to a (or any file name includes the string a) if it exists anywhere under the directory ~/temp. In most cases it is all you need, although you will read elsewhere that the "correct" way to use the find command is to do this:

```
user@bible:~/temp . -name a -print
```

This finds any file below the current directory with the exact name a.

You may want to pipe the output of the find command to another program such as less (see more about less in the chapter) or use find's built-in exec option to perform another command on the list of files find produces. For example:

```
find -name a -exec less {} \;
```

This executes the command and prints any file that is found by the find command. Here the {} (brackets) represent each file that was in the output of find. The \ is needed to terminate the command.
