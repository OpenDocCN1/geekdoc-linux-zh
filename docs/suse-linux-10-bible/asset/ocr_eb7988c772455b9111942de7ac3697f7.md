# Getting Help for Linux Commands

The man and info commands are basic ways to view program documentation on Linux. To view the man or info help for a specific command, you use the man or info followed by the name of the command that you want on.

The man command provides access to the traditional Unix and info manual, displaying formatted help that you can page through. The info command is a newer online help mechanism that displays text for commands in a customized version of emacs with hypertext capabilities that enable you to jump from one topic to another. Many commands maintain their help only in info format rather supporting both. In general, info help for a command is always as up-to-date and complete as the equivalent man help for that command.

The info interface is a little confusing for beginners; it is actually a form of hypertext. SUSE also offers pinch, which is slightly easier to use, and the ability to view man and info pages using the Konqueror browser. See Chapter 5 for more details.

+   * man ls — Views the page for the ls command
* man -dk — Looks for man referring to the word disk
* info coreutils — Looks at the info page for the coreutils package

> A number of excellent books and info references are available that provide detailed information about standard Linux commands, shells, and so on. One of the best sources of information about Linux is the Linux Documentation Project, available at www.tip.org. In the true spirit of Linux, the Linux Documentation Project provides hundreds of free documents, HOWTO files, and compilations of frequently asked questions (FAQs) that explain different aspects of using standard Linux systems.
