# Creating Dynamic Content with PHP

The Apache server is a highly modular server. The most popular module for use it is mod_php. PHP is short for what is officially called PHP: Hypertext Preprocessor was created by Rasmus Lerdorf, a developer, who in 1994 was looking for a tool to keep track of who was looking at his resume. PHP is a robust open-source development language that provides the tools and flexibility to accomplish virtually any task.

PHP is a customized, server-embedded scripting language. PHP, has many of the features of a complete programming language, but allows for the embedding of code in otherwise normal HTML files for the creation of dynamic content.

A server-side technology means that the client viewing the page has no special application, because it is the web server, with PHP installed, that takes the extra step of processing any PHP code within the requested document before sending it to the user. From this extra step PHP can then perform any operation such as accessing a database. This, enables a web developer to dynamically construct a web page based on data gathered from a third source and communicate through any means provided by the Internet.

How is this different from a CGI script written in Perl? First unlike a CGI script—which will run as a separate process, invoking a PHP interpreter to run the script and piping the output to stdout for the web server—PHP runs an interpreter within the Apache server processes, to run at a moment's notice. However, the real benefit can be seen in what users can do with little or knowledge of the inner workings of the CGI and, for example, a backend with which the script may be communicating.

> The Perl scripting language can also be embedded in the Apache web server using mod_perl module. With mod_perl and some modification to existing CGI scripts in Perl you can see the same runtime advantages as scripts written with PHP.

To include the basic functionality of PHP in the core server, extending the LoadModule directive. Apache will also need to know what files to parse using the PHP module. This is done using the AddType directive. After you restart the Apache daemon, all will be set.

```
LoadModule php4_module libexec/libphp4.so
AdType application/x-httpd-php .php
```
