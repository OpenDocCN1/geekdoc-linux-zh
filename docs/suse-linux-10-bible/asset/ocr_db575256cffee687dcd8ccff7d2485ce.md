2. As with most calendaring applications, you can select begin and end times for the entry, choose to make this entry an all-day event, select what date you want to create it on, and also set a reminder for the entry. When you are happy with the calendar entry, click Save.

3. When the entry has been created, you can select that day on the calendar the right side of the screen and check to see what your calendar looks like for that day.
