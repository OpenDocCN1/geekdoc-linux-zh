# Rebuilding the km_ * Packages

A number of packages have names beginning with km_.. These packages contain source code for additional external modules that you may need to compile separately to add support for certain things. For example, the km_ocfs package adds support for the Oracle Cluster File System (OCFS), and the km_smartlinksoftmodem package adds support for a certain class of winmods.

You can find these packages by searching for “km_” in the YaST software.

To make use of these packages, you must have the source for the running kernel installed.

When you install these packages, they install the relevant source code to a directory under /usr/src/kernel-modules/. To add support for OCFS, for example, change the directory /usr/src/kernel-modules/ocfs2/, and then issue the following commands:

```
# make modules KERNEL_SOURCE=/usr/src/linux
# install KERNEL_SOURCE=/usr/src/linux
```

Alternatively, you can issue this command:

```
# make -C /usr/src/linux SUBDIRS=$PWD modules
```

This runs the make command in /usr/src/linux while referring to the current directory built and installed as:

```
/lib/modules/<version-number>-default/extra/ocfs2.ko
```

# Kernel of the Day

The SUSE FTP server always has a so-called kernel of the day, which is the latest test kernel, with versions available for each supported architecture. This is available at ftp://ftp.suse.com/pub/projects/kernel/kotd/. It goes without saying that these kernels should be used only with caution, because they have not been officially released and are provided for testing purposes.
