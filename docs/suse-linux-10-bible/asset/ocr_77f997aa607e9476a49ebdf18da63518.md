# Configuring Your Network Card

First, to configure your network card (not the network configuration), you use the
link command:

```
loopback:~ ip link set mtu 9000 dev eth0
```

Here, you have told ip to edit the link (network device) and set the maximum trans-
mission (MTU) to 9000 on device eth0.

Setting an MTU to 9000 is common on gigabit Ethernet devices, and this is com-
called a jumbo frame. As gigabit Ethernet works a lot faster, it gets to a\point where it is not efficient to send data in blocks of 1500 counts as common
with 10- or 100-megabit devices. Setting the MTU to 9000 provides a much more
efficient way of transporting data fast over gigabit Ethernet.

You can view data about your Ethernet device, you can use the show option for the link
(network interface) object (see Listing 15-4).

# Listing 15-4: Viewing Information about Your Network Device

```
bile:~ # ip link show
1: LOOPBACK,UP~ mtu 16336 qdisc noqueue
link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
2: sit0~ mtu 1480 qdisc nop link/sit 0.0.0.0 brd 0.0.0.0
3: eth0~ mtu 1500 qdisc pfifo_fast qlen 100
link/eth:fe:d6:0d:d7:73 brd ff:ff:ff:ff:ff:ff
```

As is the case with ifconfig, you are shown the hardware address,
MTU, and interface flags. The qdisc entry refers to the queue (or buffer) that is
associated with any traffic that is sent over the interface.

# Configuring Your Network Address

As with the configuration of the network interface, you need to work on a certain
network object. To configure the addressing of a network interface, you need to
work with the addr (address) object. The ip add command is similar to ifconfig in
what information it needs to configure the address.

```
:~ # ip addr add 192.168.0.5 dev eth0
```

As would be the case with ifconfig, you tell ip to edit the device
eth0, and the IP address of 192.168.0.5.
