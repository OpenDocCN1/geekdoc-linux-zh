## Partitioning Examples

On the x86 architecture, there are limitations on the number of partitions a disk can contain: There can be at most four partitions, one of which can be an extended partition. The extended partition can contain multiple logical partitions (up to a maximum of 6 on an IDE disk or 12 on a SCSI disk).

When working with partitioning tools, you should always ensure that any partitions you are going to change are not mounted before you start. You should also be sure that you know what partitions exist on the system and what they contain (as we stressed before): Print a copy of the output of at least the commands `fdisk -l`, `mount`, and `df -h` during the process. You can print any of these lists by redirecting the output of that command to the `pr` command by using a pipe symbol, as in `fdisk -l | pr`.

## fdisk

To use `fdisk` to partition a disk, use the command `fdisk` followed by the device name of the disk concerned. Suppose that you had just added a new disk as the first disk on the second IDE controller:

```
root@bible: ~ # fdisk /dev/hdc
Command (m for help):
Command action
  a toggle bootable flag
  b edit disklabel
  c toggle the dos compatibility flag
  d delete partition
  l list partition types
  m print this menu
  n add a new partition
  o create a empty DOS partition table
  p print the partition table
  q without saving changes
  s create a empty Sun disklabel
  t change a partition's system id
  u change display/entry units
  v verify the partition table
  w write table to disk and exit
  x extra functionality (experts only)
```

Type m to see the menu as shown, and n to add a new partition. At this point, p creates a primary partition or creates an extended partition:

```
Command (m for help): n
Command action
  e extended
  p primary partition (1-4)
```

When you choose p, you see something like the following:

```
p
Partition number (1-4): 1
First cylinder (2-77520, default 2)
Using default value 2
Last cylinder +size +sizeM +sizeK (2-1000, default 1000): +2000M
```

You can specify the size of the partition in disk cylinders, or (more) by typing a size in megabytes (here the +2000M). By default fdisk creates partitions of Linux (with the hex 83). If you want to change the partition type, you need to do t and then the relevant code (which is typically 83 for a data partition and 82 for swap, but you can create any number of foreign partition types).

When you think the correct partitions have been created, you can type p to print the partition table and then w to write it to disk.

## YaST

YaST's partitioning module has the ability to create and delete partitions. It can also resize (non-destructively) create types of partitions, including Windows partitions, which is a feature in great demand for dual-boot installations on Windows-only machines. YaST uses parted to do this but provides a user-friendly interface. Although the procedure is very reliable, we recommend that you back up all the data on the partition you want to resize before this. If, the power suddenly failed during the resizing process, it's possible that the result would be a completely corrupted partition.

YaST's partitioning tool can be accessed from the main menu, or by typing (root) the command yast2 disk (for a graphical interface) or yast disk for a text interface.

You cannot make changes to any partition that is mounted.

In YaST's partitioning module, you can select a partition by clicking it. You can then choose to delete, edit, or resize the partition. These options have the same functionality as the corresponding options available through the expert partitioning option during installation:

- **Delete** — asks for confirmation. In fact, none of the changes that you make in this module are carried out until you click the Apply button in the main screen, so you can still alter if you have made a mistake.
- **Edit** — Enables you to choose how to format the partition, and if so, which type of filesystem to create in it. It also gives you the option of setting the mount point for the partition and setting the mount options that need to be written to the /etc/fstab file.
- **Resize** — Offers a graphical resizing tool with a slider and a display showing how much space the partition will take up after the operation and how much free space there will be.

In 14-5, we see YaST graphically resizing an ext2 partition.

The Expert Tools in the YaST System Repair mode discussed earlier in this chapter is YaST's partitioning tool. This means that you can use the YaST partitioning tool from "outside" with no partitions mounted.

## Commercial Partitioning Utilities

The commercial tools Disk Director (www.acronis.com) and PartitionMagic (www.powerquest.com/partitionmagic/) are also very popular and friendly interfaces. In our experience, PartitionMagic is easier to use than Acronis. If you simply need to create or resize partitions (including NTFS), Linux tools will do the job as well as these commercial built-in boot managers.

## Making a filesystem

When you have created a partition, you still need to create the filesystem of your choice (typically EXT2, EXT3, or ReFS). While YaST and parted include the ability to create a filesystem on the new partition, fdisk simply makes the partition. Do not confuse the fact that fdisk sets the partition identity code with actually creating the filesystem on the partition. To that you will need to do one of the following (here we assume that you have created the partition /dev/hdc3 and you now want to create a filesystem on it):

```
root@bible: ~ # mkfs -t ext2 /dev/hdc3
root@bible: ~ # mkfs -t reiserfs /dev/hdc3
root@bible: ~ # mkfs -t ext3 /dev/hdc3
```

Note that you must be root to create a filesystem.
