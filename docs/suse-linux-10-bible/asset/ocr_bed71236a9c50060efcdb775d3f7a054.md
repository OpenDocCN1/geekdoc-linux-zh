SUSE now uses HAL and mbfs to automatically sense media inserted into the computer. In the case of an optical device, its volume name is used. In the case of other storage mediums (USB keys, removable drives, and so on) the device string is used (comprising the hardware address of the device). If you want to create a directory /media for manual mounts (for example, mounting a CD-ROM under /media/cdrom), you would have to first create that directory and manually mount the media.

During installation, YaST actually creates a link to your optical media device /dev so that you do not have to deal with the details of your optical drive. If you have a standard CD drive, this is linked to /dev/cdrom. For a CD recorder this is /dev/cdrecorder, and for a DVD drive it is /dev/dvd.

# Mounting Filesystems Automatically

The /etc/fstab is used to store information about filesystems that have been permanently defined for the system. This includes the swap partition and the root partition, as well as any other partitions created during installation. The fstab file proves very well if you create new partitions that you need to be using a permanent basis and that need to be integrated into the system whenever the system is booted. During booting, the initialization of the system attempts to mount all of the filesystems in fstab unless the noauto option has been added to the options for a specific filesystem.

In this example, we add a new Reiser filesystem we created, and we mount it under /sparse at each system.

> To edit the /etc/fstab file or files like it, you need to work with a text editor. More information on text editors, take a look at Chapter 11.

To add a filesystem to be mounted automatically at boot, you need to add a line to the fstab that specifies the partition, mount point, filesystem type, your options, and some system information about backups and mount order:

```
/dev/sda5 /sparse reiserfs default 0 0
```

The line you add to fstab is made up of the following fields:

+   * Column 1—The partition you want to mount.
* Column 2—The directory you want to mount the filesystem under.
* Column 3—The filesystem type (the same that is passed to mount -t).
* Column 4—A comma-delimited list of filesystem options (noatime, notail, and so on).
