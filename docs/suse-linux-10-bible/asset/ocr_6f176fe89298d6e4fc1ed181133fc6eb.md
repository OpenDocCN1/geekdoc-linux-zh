# 316 Part III ♦ Using the Command Line in SUSE Linux

It is assumed that sentences are separated by a dot and two spaces.

# Undo

C-_u or C-x u will undo your last command or typing: emacs remembers everything you do, so you can do a sequence of undo commands.

# Replacing Text

M-x replace-string will globally replace one string with another in the whole buffer or in the selection. You can also do a conditional replacement of text with M-% or M-x query-replace. This prompts you as whether you want to make each change.

# Searching

C-s starts an incremental search. What this means is if you type C-s Li, for example, you see the next instance of Li highlighted in the text. If you type another letter (for example n), you will now be searching for Lin. If you press C-s again, you will move to the next instance of this new search string.

You can also do a non-incremental search by typing C-s followed by Return. When you enter now will be the search and emacs will jump to the next occurrence of it. Regular expression searches are also possible. The command M-| starts a regular expression search. If you type a regular expression, emacs searches for the next matching text in the buffer. (See also Chapter 10 for more regular expressions.)

# Making Corrections

M-c capitalizes the next word, M-u makes the next word all caps. M-1 does lowercase. M-t switches the order of two words. M-* ispell-buffer checks the spelling of the entire buffer. You can check the spelling of a single word with M-x ispell-word.

# Using Word Completion

One of the useful features of emacs is the way that it knows what you are going to type. (Well, not quite literally, but good enough.) If you are working on a file and a word and then type M-, emacs tries to complete the word for you, based on previous words in the file. If it chooses the wrong one, simply type M-/ until you get the one you want and continue typing. This is an extremely powerful feature, not just because it can save you lot of typing, but more importantly, if you are writing code, you can use it to ensure that you don't make mistakes when typing variable names that you already created.
