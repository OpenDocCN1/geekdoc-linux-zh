An issue with the Basic authentication is that the username and password must be verified every time a request is made for a resource from the server, be it an HTML page, an image, or any other resource from the protected directory. This can slow down a little in regards to the responsiveness of the web server. In fact, the amount that the web server slows down is proportional to the size of the password file. Remember the Apache server has to open that file and go down the list in order of users until it gets to the user, every time a page is loaded.

A consequence of this is that there is a practical limit to how many users can be listed in one page. While the limit will vary depending on the configuration of a particular server, changes are after a few hundred entries the performance of the web server suffer and a different authentication method may be needed.

Such a method can be found using the mod_auth_dbm module. mod_auth_dbm provides the use of files used with the dbmange program. Another possible option is mod_auth_mysql. The mod_auth_mysql allows the Apache server to connect to a backend MySQL database where username and passwords can be stored and accessed with greater efficiency.

Going any further about authentication on your Apache server is beyond the scope of this book. However, if you are interested in delving deep into the topic of security and apache, you can check out a book like Maximum Apache Security (Sams, 2002) for more information.

# The Common Gateway Interface

The Common Gateway Interface (CGI) defines a way in which a web server can interact with external programs, referred to as CGI programs or CGI scripts, for generation of dynamic content based on a client request. To configure the Apache server to interact with a CGI program the first task is to let the web server know where the CGI programs reside.

One method is with the ScriptAlias directive, which tells Apache that a particular directory has been set aside for CGI programs. Apache will attempt to execute every file in a given directory as a CGI program. Thus the web server will execute a program when a client requests a particular resource.
