# 4 Part I ◆ SUSE Linux Basics

# Different Installation Sources

This chapter focuses on installing SUSE Linux from the DVD that was packaged with this book or from the installation discs you have purchased. However, your installation discs and the installation DVD that is packaged with this book (like all SUSE installation media) also support a number of other sources. If you want to make sure that the latest SUSE installation on your system, you may want to select Manual Installation from the initial menu of the boot DVD, select the Start installation, and then select the Network source medium. This enables you to install SUSE from a variety of different installation sources, including FTP installation, which enables you to install SUSE from a network source, such as one of SUSE's up-to-date repositories. (Other installation mechanisms include HTTP, NFS, SMB, and FTP is the most common.) To install SUSE from a network source, you must have the Network Modules installed first to install the drivers for your computer, and the computer on which you are installing SUSE must be connected to the network. Although this requires knowledge about your computer system's hardware, it is a great way to get the latest and greatest version of SUSE Linux. As noted earlier, the DVD packaged with this book provides the most recent version of SUSE Linux Professional Edition available at the time that this book was written. To get the latest and greatest version of SUSE Linux and all of its patches, you can always install this version and then update it using the YaST Update module that is discussed in Chapter 9.

The DVD included with this book provides the SUSE Linux 10 distribution.

+   * Compact disc——The easiest and most common form of installation, because almost every modern computer system includes a CD drive. This is the standard way to perform a first installation of SUSE Linux on a computer system.
* DVD—A popular form of installation that saves you from having to swap out CDs, but the computer system on which you are installing SUSE must contain a DVD drive. Because of the amount of storage available on a DVD, the SUSE Linux DVD also includes some packages that are not available on the CD installation set.
* Manual installation—Manual installation requires that you boot from a SUSE CD but provides more control over the source of the packages used when installing SUSE Linux. For example, this installation method enables you to install SUSE from a centralized network repository where the SUSE Linux packages are located, using network protocols such as FTP (File Transfer Protocol), HTTP (Hypertext Transfer Protocol), NFS (Network File System), SMB (Server Message Block, the Windows file sharing protocol), and even TFTP (Trivial File Transfer Protocol).
