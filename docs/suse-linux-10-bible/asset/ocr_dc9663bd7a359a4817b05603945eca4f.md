To change the ownership of a directory and everything in it, you can use the command with the -R (recursive) option, like this:

```
chown -R harpo:users /home/some_directory/
```

The chmod command is used to change file permissions. You can use chmod both the numerical and the r w x notation we discussed earlier in the chapter. Again, this is easiest to follow by looking at a few examples:

+   * chmod u+x file — Adds permissions for the owner of the file
* chmod g+r file — Adds read for the group owning the file
* chmod o-r file — Removes permission for others
* chmod a+w file — Adds writes for all
* chmod 644 file — Changes the permissions to 644 (owner can read and write; group members and others can only read and execute)
* chmod 755 file — Changes the permissions to 755 (owner can read and execute; group members and others can only read and execute)

If you use chmod with the r w x notation, u means the user, g means the group, o others, and a means all. In addition, + means add permissions, and - removes permissions, while r, w, and x still read, write, and execute, respectively. When setting permissions, you can see the translation between the two notations by executing the chmod command with the -v (verbose) option.

```
chmod -v 755 file
mode of 'file' changed to 0755 (rwxr-xr-x)

chmod -v 200 file
mode of 'file' changed to 0200 (-rw-------)
```

# Using umask

When a user creates a file, it is created with certain permissions. You can create an empty file with the touch command:

```
touch newfile
```

If you list the file, you will see something like this:

```
ls -1 newfile
```
