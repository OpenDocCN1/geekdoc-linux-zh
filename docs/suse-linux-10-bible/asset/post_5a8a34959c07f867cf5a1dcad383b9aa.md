One of the primary uses for Linux is mail servers. MTA, MDA, and MUA are generic ways of referring to components in a mail system:

- **Mail Transfer Agent (MTA)**: The component of the mail system that handles receiving and sending of mail over the SMTP protocol.
- **Mail Delivery Agent (MDA)**: Controls the delivery of mail into a user's mailbox. MDA also deals with the presentation of mail to a user over POP3 or IMAP.
- **Mail User Agent (MUA)**: The component that the end user employs to read mail. This could be Evolution, Outlook, mutt, or any other choice.

Linux is extremely suited to hosting mail, and the authors have worked on very large mail infrastructures where Linux has been prevalent. This chapter discusses using Linux as a mail server, and focuses in particular on sendmail or Postfix as an MTA and Qmail and Cyrus as MDAs.

### How Mail is Sent and Received
When mail is sent to a user, many things have to happen behind the scenes. Here we take an example of Roger sending an email to Justin at different domains:

1. Roger, a KDE user, uses mail to compile a message to `justin@example.com`. Roger's mail configuration states that his SMTP (outbound) mail server is `mail.example.org`, so mail connects over 25 (SMTP) to the host and attempts to send the mail to `justin@example.com`.
2. When connected, Roger's mail server checks the sanity of the connection and the mail itself (which is discussed later). All being well, the mail is accepted, and Roger's mail server then attempts to send the mail to its final recipient, Justin.
3. Roger's mail server knows that `example.com` is not handled by his local MTA and proceeds to an MX lookup for `example.com`.

An MX Exchange domain name system (DNS) points to the mail server for `example.com`. The MX record is the backbone of the Internet and provides means for any domain to be resolved to a specific host that handles it. In the case of `address@example.com`, the DNS MX record is:

```
10 mail.example.com.
```

In Chapter 21, we talk more about how a DNS record works, but for now, realize that the MX record for `example.com` points to `mail.example.com`.

After mail has been delivered to your mailbox, it is stored until you retrieve it. It is the MDA that actually presents the mail to the user for retrieval. Do not confuse your mail client with an MDA; it is used only to retrieve and read your mail!

Popular MDAs are POP3 and IMAP; these two protocols enable users to log in to a mail server and retrieve their messages, which an MDA should do. These are discussed later in the chapter.

### Postfix
SUSE MTA of choice is Postfix. Postfix was designed by W Venema, who at the time had an internship at IBM, with the idea to build from the ground a secure and scalable MTA. The most popular MTA, sendmail, is often considered difficult to come to grips with because the configuration format is obscure.

Postfix's reliability and security features, as well as having a much simpler parameter-value configuration format, have helped it become a popular MTA. Postfix is constantly maintained by Venema and other developers. Bugs are fixed in a timely manner, and new versions with additional features are released regularly.

In general, the speed at which bugs and security updates are released is astonishing – not just for Postfix, but also for the kernel and other high-traffic software. The last thing you need when relying on a piece of software is to not have the backup from the developers to fix security issues (although this is a rare occurrence in the Linux world). When installed, by default, Postfix is configured to accept mail locally for users existing in your machine's domain. Postfix's default security settings stop your machine acting as an open proxy.

An open relay is a mail server that allows any user to send mail through your mail server, regardless of his or her location (in your local network or the Internet). This has proven to be a large contributor to the existence of spam as malicious users can use your mail server to send large quantities of mail on the back of your network bandwidth.
