# Chapter 19 ✦ Setting Up Printing with CUPS

# About CUPS

CUPS (the Common Unix Printing System) is a printing system. Whether or not you are printing to a local or a remote printer using CUPS, you will be using a network printing protocol (typically IPP, around which CUPS is based) to connect to cupsd, the CUPS daemon. By default CUPS offers a network service on port 631. IPP is an extension of HTTP. Hence CUPS configuration files look rather like Apache's configuration files.

CUPS offers an administrative interface over HTTP that can be accessed via a URL, such as http://localhost:631/. (The USE documentation and default settings do not particularly encourage the use of the web administration interface in CUPS, and for simple setups you will not need it.)

A CUPS server that is attached to a printer can advertise its presence on the network by putting out broadcasts; the clients that will print will learn about the existence of these from broadcasts, and if the server allows them to do so, they can print through without further configuration.

A CUPS server can also print to remote printers using a variety of protocols, including Windows printer shares and direct printing to a network.

The CUPS project pages are at www.cups.org.

# Printers Not Listed by YaST

If the printer is not listed, this does not necessarily mean that it is not going to work. If the printer is not a new one from one of the major vendors as HP or Epson, there's a very good chance that it is a variant of one of the printers that is listed by YaST, but it is a slightly changed model that has come on the market recently. The best strategy is to select the closest model that you can find manually. Then try printing a test page and see what happens. In many cases this will work fine. The information about your printer at www.linuxprinting.org may help you with this process.
