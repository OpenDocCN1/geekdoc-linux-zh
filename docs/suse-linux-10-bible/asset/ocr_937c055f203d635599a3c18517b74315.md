# Character and Block Devices

Two types of devices can represent physical and virtual devices in Linux:

+   - Character devices are those whose communication is based on a serial character by character. Common character devices are your serial ports (/dev/ttyS0, /dev/ttyS1, and so on) and the /dev/random device, which is a virtual device if read will just feed out a string of random bytes. The latter is useful for creating an empty file that contains actual data.
- Block devices are those whose communication is based on multiple bytes that are read and written as a unit known as a block. All disk devices are block devices.

You will come across more block and character devices throughout the book.

# Creating Partitions

This section uses the disk command to view, edit, and create partitions on a sample SUSE system. If you do not have available, unallocated disk space to experiment with your existing system, this section provides examples of the most common reasons you would use disk to carry out partitioning or so that you can see and when you use might disk in the future.

> Partitioning and creating files is a destructive process, and if not careful, it will destroy data. It is likely that you have used up all of the space on your disk(when you installed SUSE, which may mean that you will not have any space left to experiment with the processes in this chapter. If you are new to Linux, it is possible that playing with the system over time and pounding system elements as partitions and files could accidentally destroy your SUSE system (it happens to all of us who like to learn by playing). If a reinstallation is needed, you could create your SUSE system with space left to test these practices or if you are worried about your data and installation, cannot stress playing around with partitions and files can lead to data corruption, or at worst, the destruction of all data on a disk. If you have spare computer, you may want to consider using it as a test system rather than experimenting on a system that you are using for real work and stores your personal data.

Your controls and existing disk drives were detected and configured when you installed SUSE on your system. When using disk or any partition software, the most important thing to find out is that you are working with the correct disk on your system. SUSE provides few ways to do this, but the easiest is to use a feature of disk that prints out all the disks detected by the system along with their partition maps.
