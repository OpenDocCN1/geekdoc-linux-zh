# The X Window System

The graphical interface that comes with Linux X is provided by an implementation of the X Window system. The X Window system is a set of protocols and standards for a cross-platform, network-transparent display system. On Linux, the implementation chosen has traditionally been that from the XFree86 project have resulted in many Linux distributors' switching from XFree86 to the X.org project from www.x.org. In the case of SUSE, this change was made with the release of the 9.2 version. However, this makes no difference to the principles discussed.

Historically, the original developers of the X Window system have been very insistent about the fact that it is a window system named X and thus not simply be referred to as X. In this book, we refer to the X Window system as X because it is more convenient and common to do so. Computer history fans know the designation X originally came from the fact that the project inspired the X Window system was the W from Stanford University – simply the next letter of the alphabet.

The difference between X and (and for example) the graphical display systems found in Microsoft Windows or Mac OS is that X is inherently network-transparent and is designed from the ground up as a client-server system. That means, using X, you can run a graphical program in one place and display its output somewhere else. This is a capability for which you need to pay for special add-ons in the Windows world, but is built into Linux. The "somewhere else" where you will be displaying the graphical output can be any platform for which a server implementation is available, which includes virtually any operating system capable of TCP/IP networking and running a graphical display.
