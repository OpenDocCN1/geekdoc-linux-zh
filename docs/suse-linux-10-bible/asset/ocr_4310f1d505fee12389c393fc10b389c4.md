If some of the tools in this chapter were new to you, don't regret this simply as a reference to them that you will come back to in due when you need them. Regard it as an invitation to play. Set up a system that doesn't matter and experiment with some of the more potentially destructive tools. Try doing some willful damage to that system and try repairing it. This experience will be invaluable when the time comes that you need it.
