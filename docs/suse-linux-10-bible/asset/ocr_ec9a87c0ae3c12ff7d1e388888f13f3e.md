# 294 Part III ♦ Using the Command Line in SUSE Linux

```
user@bible:- > cat file2
red elephant, pink wine
green plums
blue mango
red albatross
```

```
user@bible:- > diff file file2
1cl,2
< elephant, red wine
---
> red elephant, pink wine
> green plums
```

If you direct this output to a file, it can be used as input to the patch command.

```
user@bible:- > diff file2 > diff12
```

We have simply written that record of the differences between the two files (the output of the diff command) to a file. This file, together with file, can act as input to the patch command, which applies the differences to file. The file file will then have the necessary changes applied to it to make identical to file2.

```
user@bible:- > patch file1 diff12
patching file file1
```

```
user@bible:- > cat file1
red elephant, pink wine
green plums
blue mango
red albatross
```

If you have patched file1, and it is now identical to file2.

If you try the patch the other way round, patch detects this and offers to try a reverse patch:

```
user@bible:- > patch file2 > diff12
patching file file2 (or previously applied) patch detected! Assume -R ? [n]
```

If you type y, you will find file2 is now identical to the original file.

If you use diff with the option -c or -u, you can apply the patch more simply as the information about how the diff file was created is within it. So just run patch with diff12 as input. patch can see from the contents of this file that was created as a diff between the two files, so it can easily decide how to do the correct thing.

```
user@bible:- > diff -c file2 > diff12
user@bible:- > patch < diff12
```
