# Chapter 9 ♦ Configuring the System with YaST 227

To set up an installation source from the NFS server:

+   1. Select Software: Change source of installation in YaST. You will be presented with a list of the current installation sources. It is likely you will see the source you installed to SUSE set as the default.

+   2. To add a source, select the Add drop-down box and NFS (see Figure 9-3).

![](bbox=[0.206, 0.266, 0.715, 0.584])

**Figure 9-3:** Adding an NFS server installation source

+   3. When the source is selected, you will be asked for the host name of the NFS server holding the SUSE packages and the directory on the server that contains the SUSE distribution (see Figure 9-4).

![](bbox=[0.206, 0.713, 0.403, 0.826])

**Figure 9-4:** Configuring the NFS server parameters

If you are setting up an NFS source for installation (and have the installation CDs), you should create a directory to hold the current version of your SUSE installation media, and copy each CD from the SUSE installation set into a separate directory in that directory, with names such as CD1, CD2, CD3, and so on.
