# Remote Graphical Login

It is also possible to log in graphically and remotely to wiley from bible and see exactly what you would see if you were in front of wiley's monitor.

To make this possible, you will need to do some configuration on wiley; its kdm (or if you are not using KDE, its gdm or xdm) configuration file needs to be fixed so that it allows remote logins.

+   1. For kdm, on wiley, edit the file /etc/opt/kde3/share/config/kdm/kdmrc and the section header [Xdmcp] change the line

```
Enable=false
Enter=true
```

+   2. Now, assuming that no graphics are running on bible (you have issued the command start 3 and you are logged in at a text console), do this: 

```
userbible:-> X -query wiley
```

You should see wiley's graphical login screen; you can log in to wiley as any user on wiley and work in your desktop environment.

If graphics are running on bible but you want to be able to log in graphically to wiley (and switch between the two sessions), that is also possible. Simply specify a display on bible that is not in use: 

```
userbible:-> X -query wiley :1
```

This starts a new X session with wiley's login screen on bible's second display (the first display is number 0, the second is number 1). You can even run the preceding command from the existing graphical session. The existing display on bible will still be there, and you can switch to it with Ctrl+Alt+F7. You can switch to the new display with Ctrl+Alt+F8.

> To do the same sort of thing automatically, you can useXConfig environment settings or use the yast2 Remote Administration panel. Setting the appropriate UseConfig variable by changing the value of the DISPLAYMANAGER_REMOTE ACCESS to "yes" in the file /etc/sysconfig/displaymanager or by using yast2 Network Service*Remote Administration panel.

# Graphical Connection from Windows

There are ssh clients for Windows, the best known is PuTTY. If you want to view your Linux desktop from a remote Windows machine, one easy way is to use PuTTY together with Virtual Network Computing (VNC). You will need to have tightvnc package installed on Linux, and you will need to have PuTTY and a VNC
