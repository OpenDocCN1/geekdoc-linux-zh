It is likely that you will want to start emacs by opening a particular file. To do that, type the following:

```
emacs file
```

or

```
emacs -nw file
```

If the file that you name does not exist, it will be created when you first save the file.

You can start the editor. Typing will instantly update to the editing buffer, which you can see. Just doing "what comes naturally" will work fine now: The keys or the mouse will reposition the cursor as expected and the Backspace key will delete backward while the Delete key will delete forward.

# Controlling emacs

To issue commands to emacs, use key combinations. In describing this, it is the convention to use C for the Ctrl key and M for the Meta key, which can be either Alt or Esc. For example, to save a file, you Ctrl+x this is normally written as C-x C-s. If you are running the graphical form of emacs, you can do some of the most common actions (such as saving a file) by clicking menu items (File-C Save).
