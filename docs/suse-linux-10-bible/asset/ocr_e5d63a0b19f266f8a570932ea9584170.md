Installation and setup of LTSP is relatively easy, and LTSP has huge advantages. The hardware used for the clients can be machines that otherwise you would throw away, but the user experience will be similar to a new machine provided the server is powerful enough to support all the clients. No configuration is needed on the clients—if hardware fails, you can simply replace a client machine and everything will still work. Your user files are, of course, on the server.

Another (and very ingenious) method of running diskless Linux terminals is provided by Michael Brown's nymph package (www.fensystems.com.uk).

# KDE

The Desktop Environment (KDE) is traditionally the default graphical environment on SUSE. Currently at version 3.2, it provides a very complete desktop environment with many nice features. It opens among other things:

+   * A consistent look and feel between applications
* A start button with cascading graphical windows
* Icons
* A panel bar
* Multiple desktops
* Themes
* A clipboard
* Drag-and-drop support
* Copy-and-paste support between applications

Additionally, SUSE has integrated YaST into the KDE menus and contributed toward the partial integration of OpenOffice. Figure 8-3 shows a default KDE desktop.

The functionality of an integrated desktop environment comes at a price in resources; a considerable amount of infrastructure has to be started before actually doing in KDE. For machines with a limited amount of memory, a more minimal X window system environment such as a window manager (discussed in this chapter) may therefore be a better choice.

It is not our intention to document all the features of KDE. That would be superfluous (because of the functionality of KDE is indeed as intuitive as it is intended to be) and would also take up far too much space.
