# Chapter 19 ♦ Setting Up Printing with CUPS

In this example, the printer is attached to the machine latter, and we are set up printing on another SUSE Linux machine.

+   1. Start the YaST printer module. If no printers have been set up before, choose Configure, and you will see a dialog box similar to the one in 19-5.

![](bbox=[0.218, 0.24, 0.725, 0.558])

Figure 19-5: Choosing a printer: remote CUPS server

+   2. Select Print via CUPS network server and then, in the next screen, choose CUPS Client-Only configuration. You will be asked to give the server name, as shown in Figure 19-6 (or you may allow YaST to detect it, or choose it from a list of hosts on the network).

+   3. After you have clicked OK and Finish, you should be able to print to the machine latter.

# Starting and Stopping the CUPS Server

On SUSE, CUPS is started and stopped by the commands rcups start and rcups stop. It is just another service controlled in the usual way. If you make changes to the CUPS configuration files, you will need to restart CUPS for the changes to take effect.

You can check that CUPS is running with the command rcups status. By default, CUPS will be started in runlevels 2, 3, and 5.
