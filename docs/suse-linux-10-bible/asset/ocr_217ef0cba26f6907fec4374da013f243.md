The file .bashrc can also be used to control the appearance of the prompt and set environment variables.

The user's file .xintrc (if it exists) controls the behavior of the X Window system when it is started by the user. In particular, the window manager could be used with specified lines in .xintrc near the end of the file like this:

```
WINDOWMANAGER=/usr/X11/bin/twm
$WINDOWMANAGER
```

You probably don't want to make exactly that, but it serves to illustrate what is possible. You might also want to include a command to start xterm, which is a command-line terminal application that runs within the X Window system, immediately before starting the window manager:

```
WINDOWMANAGER=/usr/X11/bin/twm
xterm &
$WINDOWMANAGER
```

It can sometimes be useful to remember that if you are having difficulties with the behavior of programs as a user, removing (or better, hiding) the relevant dot file may help you diagnose the problem. For example, you could do this:

```
mv .emacs .emacs.trouble
```

The next time you start emacs, it will start without a preferences file so you can look through your previous one to solve the problem.

# Mounting and Unmounting Filesystems

Mounting a filesystem is what you need to do to make its files available, and the mount command is what you use to do that. In Linux, everything is part of one big tree of files and directories. Those that are physically partitions, disks, or remote machines are "grafted" onto the system at a particular place — a mount point, which is usually an empty directory.

To find out what is currently mounted, simply type the command mount on its own.

We discuss the mount command further in Chapters 14 and 22.
