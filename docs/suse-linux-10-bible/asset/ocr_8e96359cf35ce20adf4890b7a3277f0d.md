# Part III ◆ Using the Command Line in SUSE Linux

A general point about unpacking archives: Sometimes badly behaved archives unpack into the current directory rather than a directory under the current directory. This can be annoying, so it is always a good idea to put the archive into a new directory of its own before you unpack it.

# Working with tar Archives

To create an archive of a directory tree with tar, you can do something like this:

```
userbible::~/tmp tar -cf directory.tar directory/
userbible::~/tmp ls
directory directory.tar
```

The preceding command creates (c), verbely (v), the file (f) directory.tar, which is a tar archive, by running tar on directory.

If you do this with a directory containing a couple of small text files, and then you look at the resulting tar file (with cat), you will see that it is just a concatenation of the original files themselves together with additional information.

If you want to list the files in the archive:

```
userbible::~/tmp tar -ft directory.tar
directory/
directory/afile
directory/bfile
```

Here the t option lists the contents of the file (f) directory.tar.

# Using gzip compression with tar

If you want to create a gzipped archive (the -z option implies compression, while the c means create):

```
userbible::~/tmp tar -xzf directory.tgz directory/
userbible::~/tmp ls
directory directory.tgz
```

The original is still unlike, when we compressed a single file with gzip. (That .tgz and .tar.gz are used interchangeably for filenames of gzipped archives.)

To list the files in this case, use the following:

```
userbible::~/tmp tar -tzf directory.tgz
directory/
directory/afile
directory/bfile
```
