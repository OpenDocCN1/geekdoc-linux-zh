```
-rw-r--r-- 1 roger users 0 2004-05-18 10:00 newfile
```

The file has been created with the permissions 644. What controls the permissions with which a new file gets created is something called `umask`.

By default on a USE system, a normal user's `umask` is 022, which means that the permissions for a new file added to 022 will be 666, while the permissions for a new directory added to 022 will make 777.

USE's defaults are relatively generous and open—the fact that the users you create are all members of the same group (users) and the default `umask` of 022 means that files created by one user can be read by another. If you want to change a user's `umask`, you can change it in the `.bashrc` file; see the section on user preferences follows.

# Configuring User Preferences

Linux stores most user preferences in so-called "dot files" in the user's home directory. If a filename starts with a dot, it will not be displayed by the `ls` command unless you use the `-a` option and is therefore regarded as a "hidden". Both files and dot directories are used to hold preferences for most of the KDE programs you use. Many programs write a dot file in your home directory when you run them for the first time.

Many of these dot files have names that include the letters `rc`—this comes from the initial letters of `run command` and is an old Unix legacy. The same letters `rc` will be seen in KDE commands for starting and stopping services.

In particular, the KDE desktop uses a directory `kde` in a user's home directory to store preferences for all KDE programs and as your desktop settings. This directory contains multiple subdirectories and preferences for all KDE applications.

The behavior of bash shell is determined by the user's file `.bashrc`. Exactly how bash preferences are set is complicated; as mentioned, the system-wide files `/etc/profile` and `/etc/profile.local` are also read, and the user's file `.profile` is read at login.

You can modify various aspects of how `bash` behaves by editing `.bashrc`. In particular, you could simply change your `umask` by adding a line at the end of `.bashrc` like this:

```
umask 077
```

If you were then to log in and create a file, you would find that it has permissions `-rw-------` or 600, so it would not be readable or writable by any other user
