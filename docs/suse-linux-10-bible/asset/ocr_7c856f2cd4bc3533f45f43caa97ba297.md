The x m command provides a number of subcommands, our favorites of which are the x m command, which lists the Xen domains that are active on the host system, and the x m shutdown command, which you use to terminate a specified Xen virtual machine. Sample output from the x m list command like the following:

```
# x m list
Name Id Mem(MB) CPU State Time(s) Console
Domain-0 0 527 0 r---- 583.6
wh-domain 1 256 0 -b---- 10.5 9601
```

You can find out of the available x m subcommands by executing the x m command, which displays output the following:

# x m help

```
call      Call x m api functions.
help      Print help.
```

```
Commands related to consoles:
console    Open a console to a domain.
```
