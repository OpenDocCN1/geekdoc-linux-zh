# Chapter 1 ✦ Installing SUSE 43

After the installation is complete, confirm that sound is working by attempting to play a music CD or music file (for example, an MP3 file using the x m m s player program). If you don't hear sound at this stage, first check the physical connection to the speakers. Then (if you are using KDE) check that the KDE volume control is a sensible setting and not disabled or turned down to zero. In the unlikely event that sound fails to work, you can rerun the YaST sound module in expert mode. The sound module is found in YaST's Hardware section. You will find three possible setup modes:

+   * **Quick automatic setup**—This is the default and the one that is used during installation.

+   * **Normal setup**—This enables to test the sound card. There is a volume control and a test button. When you have set the module, a test sound is played when you press test.

+   * **Detailed installation of sound cards**—If you choose this option, you will be taken to a screen where any configurable options for the particular sound card that has been detected can be set. On the particular card, this may include settings to enable a joystick and MPU (midi processing)ing ports.

If even experiment with the detailed installation options fails, you can find the low-level alsconf program. As root, type **alsconf** to start the program. It is a text-based program that, in fact, provides the back end for YaST's sound configuration module, but running it standalone gives you the opportunity to use its command-line options, including alsconf -i which writes a log file to /tmp/alsconf.log that may give you a clue to the problem.

> 

> The ALSA (Advanced Linux Sound Architecture) home page can be found at w w w .alsa-project.org. This is the best place to start if you have any difficulties with configuration of sound on Linux.
