To change the Ethernet interface on which your DHCP server is listening for DHCP client requests, click the Card Selection item from the tree view at left in the YaST DHCP Server configuration editor. A screen like the one shown in Figure 20-6 is displayed, in which all Ethernet interfaces on your system are listed. To specify that the DHCP server listens on another Ethernet interface, simply select the name of that interface from the choices listed on this screen.
