The modes are implemented by files of list code that are installed in directories /usr/share/emacs. You can choose to install all modes. If you use a language for which there is no mode included in the THESE packages (fairly unlikely, but possible), you can always add it. We always have to add magicpoint mode (by editing source for magicpoint, a nice slide tool that uses a markup format).

The magicpoint mode we was written by Christoph Dalitz and comes in a file called mpg_mode_cd.el. To make this work and be automatically loaded when you open a magicpoint file (with a name such as file.mgp), you need to copy mpg_mode_cd.el to the directory /usr/share/emacs/site-isp/ and add the following lines to the emacs startup file: .gnu-emacs-custom in your home directory:

```
(autoload 'mpg-mode-mode-cd' 'Mpg mode.' t)
  (add-to-list 'auto-mode-alist '(\'\\.mgp$\' . 'mpg-mode'))
```

As one would hope, the instructions for making this work are included as comments in the mode file itself.

You (or course) write your own emacs modes. But to do so you need to become familiar with some Lisp programming.

These comments only scratch the surface of what emacs modes can do, but they give you a clear idea of what an intelligent editor emacs can be. For additional information about the emacs customization file and customizing emacs, see “Customizing emacs" later in this chapter.
