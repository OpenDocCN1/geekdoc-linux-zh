After starting the fdisk command and seeing any introductory messages, we are presented with its internal prompt, Command (m for help): We issued the p command to print the partition map. This produces the same output as the fdisk -l command, but only for the disk specified on the command line (/dev/hda).

The following example shows how to create an extended partition and logical partitions within it. Listing 3-3 shows a transcript of this fdisk session, with our sample responses in bold.
