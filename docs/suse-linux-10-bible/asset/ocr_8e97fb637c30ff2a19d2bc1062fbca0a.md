Setting a contact to *all* allows other users to see the contact information. If you want this contact to be private to you, set its visibility to *personal*. Finally, you can give certain users explicit access to the entry by selecting *individually* and use the Read/Write access links to see the contact control list.

Taking another look at the address book, you can see the new entry is listed along with the other SLOX entries. If you create a personal entry, the new entry is visible only to you.

If you click the entry in the address book, you can see the details entered for the entry and view an industry standard *vCard entry by clicking the vCard tab.
