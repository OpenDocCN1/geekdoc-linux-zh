The routing can be set up in the dialogue. The Default Gateway matches your location, but if any other entry is required, address it is used instead of the default route. The idea of the default route is to enable you to say "everything else go here."

Enable IP Forwarding if the system is a router:

**Figure 1-25:** Configuring a default gateway

Your default gateway is the IP address of the host to which TCP/IP packets are not destined for your local network are sent for further processing. For example, your gateway address will be that of your asymmetric subscriber line (ADSL) router if that is how you connect to the Internet. In other cases, your network or system administrator will be able to provide you with this information.

When you have set the gateway address, click OK to proceed. You will then be returned to the Network Address Setup screen. If you are happy with the network card configuration, click Next.

When you have finished configuring all of the network cards that you need to, click Next in the Network Configuration screen. This tells YaST to save the changes to your network configuration and restart the system networking.
