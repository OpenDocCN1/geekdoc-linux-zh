# Runlevel Editor

Throughout the book, we have talked about enabling services at boot time. This is a very important concept when dealing with Unix systems. A mail server would be useless if the server process did not start up at boot time. You would have to manually start the mail server every time the system booted, which is inefficient and time-consuming. The Runlevel Editor can be used to turn on and off system services at system boot in different runlevels. To load the Runlevel Editor, start YaST and select System -> Services (Runlevel).
