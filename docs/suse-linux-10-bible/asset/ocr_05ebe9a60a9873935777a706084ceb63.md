# 400 Part III ♦ Using the Command Line in SUSE Linux

Certain variables have built-in meanings. In particular, some variables represent the arguments that are given to the script when you run it (sometimes known as positional parameters). So, for example, consider a script showshargs.sh with these contents:

```
#! /bin/bash
echo "the first argument is" $1
echo "the second argument is" $2
```

If you run ./showshargs.sh, you will see no output because the command line contains no arguments. But if you do the following:

```
usable: -> ./showshargs.sh this that
first argument is this
second argument is that
```

you get the output because you have provided a first argument, this, and a second argument, that.

Suppose you want to take the first two lines of one file and append them to the end of another file:

```
#! /bin/bash
head -2 $1 >> $2
```

Save this as append2.sh. Now, suppose you have files a and b with these contents:

+   - a line 1
- a line 2
- a line 3
- a line 4
- a line 5

and

+   - b line 1
- b line 2
- b line 3
- b line 4
- b line 5

To the shell script append2.sh on files a and b, you run the following:

```
user@bible: -> ./append2.sh a b
```
