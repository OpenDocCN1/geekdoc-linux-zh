# XFS

XFS is SGI's high-performance 64-bit filesystem, originally developed for use with its IRIX operating system. SGI machines have traditionally had to work with large data sets on machines with many processors, which is reflected in the way XFS works. One of the best features of XFS is that independent domains of data across the filesystem allows a multiprocessor system to access data in different groups independently of each other. This means that instead of a single write happening at one time, multiple reads and writes can take place at the same time. This provides a significant performance boost for enterprise level data storage. This might not sound like something that would work in the traditional sense of a single disk on a home PC, but if you have a storage area network in which multiple data are processed by many disks, the data works very well.

Like ReFS, XFS uses its journal to store information about metadata and employs binary trees to handle allocation of data. An added feature of XFS is that it also uses a binary tree to store information about free space. This helps up block allocation for new information. As you would expect from a filesystem originally developed for processes that handle amounts of metadata data, XFS is especially good at allocating and managing files.

XFS is truly an enterprise filesystem and may not prove overwhelmingly attractive for a home user, but for large amounts of data and high-end machines, it is really an excellent choice.
