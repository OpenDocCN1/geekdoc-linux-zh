3. Enter the name of the domain for which the DHCP server will answering DHCP client requests, the IP addresses of up to two DNS servers, and the default gateway for your network. If you systems that obtain network configuration information from your DHCP server to contact an NTP (Network Time Protocol) to synchronize your clocks, you can optionally specify the name or IP address of the NTP server that you want to use. You can optionally specify the name or IP address of a print server and WINS (Windows Internet Name Service) server, on your network. (A WINS server maps NetBIOS to IP addresses) Finally, you have the option to modify the default duration of IP addresses by entering a new numeric value and specifying the correct units.
