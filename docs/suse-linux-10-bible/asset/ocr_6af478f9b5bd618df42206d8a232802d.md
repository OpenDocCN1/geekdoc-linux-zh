# Fetchmail

In certain situations, you may need to pull your mail from a POP or IMAP server to your local mail server. The fetchmail program was designed to contact an MDA and fetch the mail and pass it through your SMTP server for delivery.

For fetchmail to successfully run, you need to know the address of your MDA server, the username, password, and the protocol to use (POP3/IMAP).

The fetchmail program connects to the MUA and transports the messages to your SMTP server for further processing. When you run fetchmail with required options, it delivers mail to the user you are running the command.

```
smtpmail:-> fetchmail.bible.suse.com -p pop3
Enter password for justin@mail.bible.suse.com:
 message for justin@mail.bible.suse.com (720 octets)
reading message justin@mail.bible.suse.com:1 (720 octets) flushed
```

In the example, the user is currently logged in justin, the mail will be delivered through SMTP to the user justin@localhost.

In the fetchmail run in the previous example, we told fetchmail (mail.bible.suse.com) the protocol (-p pop3). The fetchmail program is enough to know that we also need a password, so it asks you for it. When a message has been "flushed," it is delivered through SMTP.
