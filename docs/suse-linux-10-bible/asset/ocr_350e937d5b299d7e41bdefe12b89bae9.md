# # Running an FTP Server on SUSE

FTP is the File Transfer Protocol, which is best known as a way of allowing anonymous downloads from public servers.

Traditionally, Unix systems run an FTP daemon by default, and users expected to be able to move files to from their home directories using an FTP client from elsewhere. This was a convenient way of accessing the system without logging on, and was available from any kind of client. This type of FTP has to be seen as both insecure and unnecessary.

+   It is regarded as insecure because typically username/password pairs were sent across the network in plain text, and it was vulnerable to password theft by network sniffing. Telnet and ssh are regarded as insecure, use of FTP on a public network should be regarded with caution.

+   This type of use of FTP is also unnecessary for the same reason that telnet and ssh are unnecessary: because of the availability of the ssh, scp, sftp programs. These provide totally secure ways of achieving the same ends. (The availability of nice client implementations as KDE's “fish” iosave means that you can view the directories on the server graphically from the client while transferring the files.)

FTP's poor security reputation has been made worse by the fact that some FTP implementations have suffered from various vulnerabilities, including exploits allowing root access to the client through the use of buffer overflows and the like.
