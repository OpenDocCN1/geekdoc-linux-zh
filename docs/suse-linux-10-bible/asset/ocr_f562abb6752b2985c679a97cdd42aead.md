ECN is for Enhanced Congestion Notification. This is a new feature of TCP/IP that allows machines to notify you that a network route is congested. A great feature, but unfortunately is not in widespread circulation and can stop your network traffic from traversing the Internet correctly if it goes through a router that does not support ECN. We have been on customer sites where their networks stopped working for certain sites for reason. Turning off ECN fixed.

If IP forwarding has been enabled, you can insert the SNAT rule into the POSTROUTING chain.

In the network, you need to source NAT all the internal traffic (192.168.1.0/24) to the firewall public address of 217.41.132.74. To do this, you need to insert a SNAT rule into the NAT table.

The NAT table is used specifically for address translation rules. This includes source and destination address translation.

```
#: # iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -o eth0 -j SNAT -to 217.41.132.74
```
