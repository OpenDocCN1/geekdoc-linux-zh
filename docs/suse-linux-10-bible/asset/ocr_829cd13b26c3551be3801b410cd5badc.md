# Checking the Finished RPM

When an RPM has been created, it is stored in /usr/src/packages/RPMS/i586.
For other architectures ($s90, ppc, and so on), RPMs are saved in the relevant
architecture subdirectory.

You can check the existence of the file and also list the files in the package just as you
did earlier in the chapter with the rpm -qlp command, as shown in Listing 12-11.

# Listing 12-11: Listing the Files in the logcheck RPM
