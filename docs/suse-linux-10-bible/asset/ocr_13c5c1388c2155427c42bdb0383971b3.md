To use this ACL functionality, it is necessary that the partition on which the filesystem resides mounted regardless of which of the common filesystems use (ext2, ext3, or reiserfs). To set ACLs on the command line, use the command setfac. getfac reads the ACLs of a file.

If ACLs have been set, when you do an -l command, you will see this:

```
executable:-- ls -l file
-rw-r--r-- 1 tom users 2004-06-23 15:59 awhile
```

> Note the extra plus (+) symbol after the permissions string. This shows that ACLs have been set on this file, to actually find out what they are, you will need the getfacl command described in this section.

If tom want to modify the ACL to allow tanya to write to the file, he does this:

```
executable:-- setfacl -m tanya:w:bfile
```

Here is modifying (- m) the ACL to allow the user (u) tanya to write (w) to the file.

You can then get the ACL for the file like this:

```
executable:-- getfac bfile
# file: bfile
# group: users
user:rw-
user:tanya:-w-
group:--r-
mask:rw-
other:--r-
```

So the change was made. For each user, you see the permissions shown in the usual rwx (read, write, execute) format. The user tanya now has write permission.
