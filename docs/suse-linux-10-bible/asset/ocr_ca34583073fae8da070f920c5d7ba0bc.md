# HOWTOs

The Linux Documentation Project publishes a large number of documents known as HOWTOs. These are included in SUSE in the packages howto (plain text versions) and howhowto (HTML versions). The latest definitive versions are always available in a variety of formats (including nicely formatted PostScript and PDF versions for printing) at the Linux Documentation Project site. The index for HOWTOs at this site is located at www.tld.org/HOWTO-INDEX/howtos.html.

It is worth checking the dates of all HOWTOs. In some cases it may be out of date or may recommend configuration changes that won't be necessary because they are already incorporated into your SUSE system. Regardless, there is a lot of useful information in the HOWTOs.

# Linux Documentation Project Guides

The Linux Documentation Project provides a large number of freely distributed books on Linux. Some of these are included in the SUSE package named books (see the next section in this chapter). The index of available guides at the LDP site is located at www.tld.org/guides.html. The listing for each available guide includes the date that it was last updated and a list of the formats and languages in which each guide is available.

The following are of our favorite guides:

+   * Advanced Bash-Scripting Guide by Mendel Cooper—An excellent document that provides reference material and tutorials on how to accomplish tasks in Bash shell scripts.

+   * Bash for Beginners by Machtelt Grels—An excellent introductory document to using bash on a daily basis.

+   * Introduction to Linux: A Hands on Guide by Machtelt Grels—A document oriented to new Linux users provides a good deal of fundamental information that helps new users explore and become comfortable with Linux.

+   * Linux Network Administrator's Guide, Second Edition by Olaf Kirch and Terry Dawson—Although an older document (last updated in 2000), this document provides a good introduction to fundamental administrative tasks to a networked Linux system.

+   * Linux System Administration Made Easy by Steve Frampton—An even older document (1999), this guide provides a good introduction to fundamental administrative tasks.
