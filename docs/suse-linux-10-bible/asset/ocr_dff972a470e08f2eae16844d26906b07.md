+   5. You are prompted for the IP address of the network printer to you want to connect, or you can attempt to scan for available network printers on your network with the Lookup button.

+   6. If your printer has been detected successfully on the network, you can click the Test Socket Access button to see if the printer accepts print jobs before continuing.

+   7. Click the Next button to move on configuring the printer name, description, and location (see Figure 9-11). These are free-form strings that will help you identify the printer from your applications. Two options of note are Local Filtering and Automatically Prepare Multiple Queues.

+   **Do Local Filtering** —Relevant when the remote printer you connected is not intelligent enough to prepare a print job before putting into paper. In this case, to take the burden off your printer, you can do the preparation of page layout and so on on your local network and then send the finished, prepared job to the printer.

+   **Automatically Prepare Queues** —Used when the system that hosts your printer uses different queues to reflect different printer configuration options, such as black and white printing, color printing, and so on. The available printer queues are usually contingent on those supported and created by the printer driver.

As are doing local filtering in this example, we are able to print a test page at this point because we need to set up our printer model. If your printer is intelligent enough to handle raw print jobs, you can attempt to print a test page. Otherwise, you may find your printer printing garbage.

+   8. Click Next to view the Printer model page (see Figure 9-12). On the left you will be presented with a list of printer manufacturers. When you select a manufacturer, you will see a list of specific printer models on the right.

In the unlikely event your printer is not listed, you may be able to use the PPD printer file in Windows to define your printer configuration.

If you have a PPD file, select Add PPD File to Database. You can either select the PPD file locally (on your filesystem), or you can download a PPD file from an FTP server.
