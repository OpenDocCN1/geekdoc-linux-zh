OpenOffice imports a CSV file into its spreadsheet; how perfectly it will this depends on the exact format of the file. CSV is actually an ugly format because the fields of the file may contain commas, while the comma is the field separator. This means that the fields then have to be surrounded by quotes. Or those fields may also contain quotes. So there are cases when importing a CSV file will fail on some records for this kind.

If you need to create a CSV file for some reason (for example, exporting a spreadsheet as CSV), it may be better to use a different symbol as the separator, particularly if you are writing your own code to parse the file. Perl and Python both have modules for parsing files.

# XML Files

XML is self-describing data in the form of tagged text. XML file looks rather like an HTML file if you open it in an editor. The difference is that XML allows arbitrary tags, but any given XML file will follow a DTD (Document Type Definition) or an XML Schema, which describes the tags it may include and which elements may contain other elements. XML is growing in importance because of its use as a format for the exchange of information in e-commerce applications, and because of its usefulness as a base format to generate multiple versions of the same document (print, web, plain text, and so on).

As with HTML, if you need to make major edits to XML files, the best way is to use emacs with the appropriate mode (see Figure 13-4). You will need to have the psxml package installed for this. The emacs editor will then be able to validate the XML document, load a DTD, offer only the tags that are available at the current point in the document, close the open tag with a single keystroke, and much more.

# Office Format

OpenOffice opens almost all Microsoft .doc, Excel .xls, and PowerPoint .ppt files, as well as its own StarOffice native formats.

As noted earlier in the chapter, to quickly extract the text from a Word file, antiword can be useful. The "other" office applications on Linux (AbiWord, Gnumeric, Koffice) are generally not as good as OpenOffice at opening all files.

You can try educate your contacts to understand that if they want to send you a shopping list, it's not actually necessary to write it as a document and attach it to an email, but you won't always win. And if your contact requires a printable formatted from you, send him PDF (exported from OpenOffice). If he has to edit the file, you may have to save the file as some version of .doc.
