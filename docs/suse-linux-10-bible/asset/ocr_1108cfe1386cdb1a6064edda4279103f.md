The default type of filesystem used in SUSE is the Reiser filesystem. It was one of the first available filesystems for Linux, and a lot of work was done by both SUSE and mp3.com. A journaling filesystem dedicates a specific part of the filesystem for use as a cache of pending writes to it; this ensures that updates occur in a clean, atomic fashion; and allows for recovery if the system is not cleanly shut down. Ordinarily, when a Linux system is shut down, it ensures that all writes to each filesystem are completed, and then deletes filesystems (known as unmounting) to guarantee that all system data is consistent before the system is turned off. Using a journaling filesystem does not safer to power off the machine, as data loss can still occur when data is not completely written to the disk.
