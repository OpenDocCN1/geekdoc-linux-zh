# KDE Applications

KDE comes with a large number of KDE-compliant applications, far too many to list here. They vary in quality, and a number are simply KDE fronts to well-known tools. The best are excellent, others are promising, and some are not particularly useful:

+   - Kwrite is an excellent graphical text editor with syntax highlighting for a variety of languages. It can export to an HTML file showing syntax highlighting, and it shows outlines and document structure by default (so you can collapse or expand outlines in programming languages or tagged sections in HTML documents). Even so, it is unlikely to tempt many people away from emacs, for example.

+   - In something of the same spirit, the KOffice programs—word, kspread, and so—have progressed enormously and are very usable, but are unlike to tempt many people away from using OpenOffice, simply because the ability to import Microsoft documents lags somewhat behind.

+   - Every KDE uses the konsole terminal emulator, an exceptionally good and configurable terminal emulator. A nice feature is that simply by clicking an item in the File menu you can bring up mc (the Midnight Commander text-based file manager) in the current directory. Similarly, you can start a session from the same menu, which remembers previous user and hostnames. It supports "print screen"—a useful feature.

+   - SUSE's help system (meshelp) is well integrated into the rest of the desktop. We discuss this in Chapter 5.

+   - A recent addition to the SUSE distribution is the regress database system. It answers a long-felt need for a desktop database front roughly comparable to Microsoft Access.

+   - kmail, addressbook, and organizer programs do exactly what you would expect, and it does well, we often hear negative comparisons in relation to GNOME's Evolution. Work is currently going on to combine these applications into a unified client to the Kolab project's mail and power server.

The Kolab project (http://kolab.org/) promises to establish a standard and show how the functionality of shared calendaring and email can be established in the open source world, thus offering the intended functionality of the Microsoft Exchange/Outlook combination without the notoriously alarming performance and security problems.
