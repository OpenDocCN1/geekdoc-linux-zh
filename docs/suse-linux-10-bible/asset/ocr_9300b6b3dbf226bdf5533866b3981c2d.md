# Booting into YaST System Mode

SUSE provide a System Repair with YaST. If you boot from the installation media and choose the option, but add the boot parameter repair=1, you enter a system similar to the Rescue System (running in memory and with no hard disk partitions mounted). The only difference is that YaST now runs in graphical mode. The main screen offers three options: Automatic Repair, Customized Repair, and Expert Tools.

If you choose Automatic Repair, the YaST system check runs through a series of tests and shows a commentary on the screen. The tests are file-system checks, verification of the package database, a check on the boot loader configuration, and a check of the initrd (the initial ramdisk at boot time). If problems are found, it attempts to repair.

# The Customized Repair Screen

If you choose Customized Repair (see Figure 14-1), you can select or deselect the particular tests that you want to run. If you have a good idea of what might be at fault, this reduces the time the tests and repairs need to run. The options are:

+   * Check Partition Tables
* Check Swap Areas
* Check File Systems
* Check fstab Entries
* Check Package Database
* Check Minimal Package Database
* Verify Base Packages
* Check Boot Loader Configuration

The most useful of these are those concerned with filesystems and boot loaders.

+   * Although journaling filesystems means that filesystem corruption is unlikely, if it occurs and prevents the system from booting normally, this filesystem option is useful because it will run a filesystem check for you with the correct options.
