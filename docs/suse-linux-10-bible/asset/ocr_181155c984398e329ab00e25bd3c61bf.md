# Framebuffer Graphics

Any VESA-compliant graphics adapter is capable of providing framebuffer graphics for the graphics hardware in your computer system and provide an easy way for X to interact and control your graphics hardware. If nothing else works, this is your best choice of getting graphics configured, but may not advantage of any specialized features of your hardware.

If you need to use framebuffer, you can specify a graphical resolution at boot time, such as vga=791, which sets the resolution to 1,024 × 768 in 16-bit color depth (a common and reasonably safe option). Having booted with this boot parameter, you can then run sax2 and force the graphics mode to be framebuffer by using the command line:

```
sax2 -m 0=fbdev
```
