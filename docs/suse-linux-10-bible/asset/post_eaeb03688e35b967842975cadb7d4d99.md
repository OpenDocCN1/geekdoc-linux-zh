The program used to install SUSE Linux is known as YaST, which stands for Yet Another Tool (The 'Yet another...' convention is a standard Unix/Linux naming convention, intended to reflect honestly on the number of similar tools that different people and companies have developed to do specific tasks in their favorite, customized fashion. YaST provides a framework that performs a variety of administrative tasks, including modules for installation, all system administration and configuration tasks, and subsequent updates. The YaST interface that you use for installation is very similar to the interfaces that you will use for system configuration and administrative tasks when you have completed your SUSE Linux installation. Powerful and well designed, YaST will quickly become your friend.

# Different Installation Sources

This chapter focuses on installing SUSE Linux from the DVD that was packaged with this book or from the installation discs you have purchased. However, your installation discs and the installation DVD that is packaged with this book (like all SUSE installation media) also support a number of other sources. If you want to make sure that the latest SUSE installation on your system, you may want to select Manual Installation from the initial menu of the boot DVD, select the Start installation, and then select the Network source medium. This enables you to install SUSE from a variety of different installation sources, including FTP installation, which enables you to install SUSE from a network source, such as one of SUSE's up-to-date repositories. (Other installation mechanisms include HTTP, NFS, SMB, and FTP is the most common.) To install SUSE from a network source, you must have the Network Modules installed first to install the drivers for your computer, and the computer on which you are installing SUSE must be connected to the network. Although this requires knowledge about your computer system's hardware, it is a great way to get the latest and greatest version of SUSE Linux. As noted earlier, the DVD packaged with this book provides the most recent version of SUSE Linux Professional Edition available at the time that this book was written. To get the latest and greatest version of SUSE Linux and all of its patches, you can always install this version and then update it using the YaST Update module that is discussed in Chapter 9.

The DVD included with this book provides the SUSE Linux 10 distribution.

- Compact disc——The easiest and most common form of installation, because almost every modern computer system includes a CD drive. This is the standard way to perform a first installation of SUSE Linux on a computer system.
- DVD—A popular form of installation that saves you from having to swap out CDs, but the computer system on which you are installing SUSE must contain a DVD drive. Because of the amount of storage available on a DVD, the SUSE Linux DVD also includes some packages that are not available on the CD installation set.
- Manual installation—Manual installation requires that you boot from a SUSE CD but provides more control over the source of the packages used when installing SUSE Linux. For example, this installation method enables you to install SUSE from a centralized network repository where the SUSE Linux packages are located, using network protocols such as FTP (File Transfer Protocol), HTTP (Hypertext Transfer Protocol), NFS (Network File System), SMB (Server Message Block, the Windows file sharing protocol), and even TFTP (Trivial File Transfer Protocol). This is a common installation method when you want to install SUSE on a large number of networked computer systems. Manual installation also enables you to install SUSE from an existing hard partition where the SUSE packages are installed. You can use Manual installation to install SUSE from a portable, external hard drive.

- AutoYaST—Auto advanced installation method that enables a system administrator to create a profile file that can be used to automate installing SUSE Linux on any number of identically configured systems.

As you can see, each installation has its own advantages and disadvantages, some are specifically targeted towards technically sophisticated users or system administrators who are installing SUSE into networked environments. The remainder of this chapter focuses on installing from CD or DVD, but also provides an overview of using SUSE's network-based installation.

# Starting Your Installation

Inside your SUSE box you will find the SUSE manuals (which are considered among the best manuals available) and the media case. The media case contains five CDs and two-sided DVDs. One of the DVDs is installable, the other contains the SUSE source code. The installable DVD has two sides, one used to install SUSE on standard PCs, and the other containing an installable version for 64-bit systems. Each side of the DVDs is labeled in extremely print around the center ring of the DVD. Depending on the hardware in your computer system, installing from DVD is the least-consuming method.

Insert the first CD or the DVD in your system's optical drive. If you are booting from DVD, make sure the side that you want to boot from is facing up your drive. Next, booting from the optical media on your computer to start the installation routine. During the booting routine, you need to enter the BIOS and set the order in which your system will probe attached devices by pressing a special key—usually F2. When you have entered the BIOS setup screens, different BIOS have different ways of configuring your system. You may find the options you are looking for Startup Items, Boot Options, or under your Advanced settings. Make sure that your CD or DVD drive is probed before your floppy disk, drives, or network. Once, set the new settings, and your machine will reboot.

At this point, your system should boot from the first SUSE CD or the DVD, and you will see the welcome screen (see Figure 1-1).
