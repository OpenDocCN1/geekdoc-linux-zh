in /etc/squid/squid.conf, the format of the log file will change to look like more Apache's access log. This can be seen in these sample entries:

```
1089560809.085 159 192.168.2.111 TCP_MISS/200 768 GET

192.168.2.111 - [Jul/2004:16:57:54 +0100] GET
http://news.bbc.co.uk/news/shared/cns/news HTTP/1.1" 200 15258 TCP_HIT:NONE
```

The first shows the access time, with the first min (since January 1, 1970), and the second shows the Apache-like.

Squid logs are very long and difficult to read, so a number of Squid analysis tools are available. SUSE includes a tool called **sarg** (Squid Analysis Report Generator). If you want to use the **sarg** tool you must install it; it is not included in the Squid. The **sarg** tool can be set to run daily via a cron job and produce HTML reports through a browser, as is example in Figure 26-3.
