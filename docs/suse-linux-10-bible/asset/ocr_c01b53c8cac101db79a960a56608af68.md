# Chapter 14 ♦ Working with the System 381

```
root@bible: ~ # fdisk /dev/hdc
Command (m for help):
Command action
  a toggle bootable flag
  b edit disklabel
  c toggle the dos compatibility flag
  d delete partition
  l list partition types
  m print this menu
  n add a new partition
  o create a empty DOS partition table
  p print the partition table
  q without saving changes
  s create a empty Sun disklabel
  t change a partition's system id
  u change display/entry units
  v verify the partition table
  w write table to disk and exit
  x extra functionality (experts only)
```

Type m to see the menu as shown, and n to add a new partition. At this point, p creates a primary partition or creates an extended partition:

```
Command (m for help): n
Command action
  e extended
  p primary partition (1-4)
```

When you choose p, you see something like the following:

```
p
Partition number (1-4): 1
First cylinder (2-77520, default 2)
Using default value 2
Last cylinder +size +sizeM +sizeK (2-1000, default 1000): +2000M
```

You can specify the size of the partition in disk cylinders, or (more use) by typing a size in megabytes (here the +2000M). By default fdisk creates partitions of Linux (with the hex 83). If you want to change the partition type, you need to do t and then the relevant code (which is typically 83 for a data partition and 82 for swap, but you can create any number of foreign partition types).

When you think the correct partitions have been created, you can type p to print the partition table and then w to write it to disk.
