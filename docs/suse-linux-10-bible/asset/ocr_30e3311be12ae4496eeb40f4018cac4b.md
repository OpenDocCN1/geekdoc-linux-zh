When all packages we have been installed, we then remove any non-essential packages used for the running of the server. This lowers the security risk, mainly for local security exploits that could take place.

# Removing Installed Packages

After an RPM has been installed, you may need to remove it from the system for any reason or another. As it does when installing, RPM will check the dependencies of the package you to remove. This check of dependencies is as important as checking package dependency during installation, as you could end up deleting files that other RPM package depends on.

To remove packages, you need to erase (-e) the package from the system. As with installation of packages, RPM checks to see if any RPM packages on the system depend on the package you want to remove. If a package depend on it, the removal will fail. See Listing 12-6 for an example.
