Three final mount options that are generally useful are ro, rw, and remount. When mounting external or remote partitions, you may occasionally want to mount them read-only so that you cannot accidentally change their contents. You would do this by specifying the ro (read-only) option when mounting the filesystem, in the following example:

```
mount /dev/sda /mnt -o ro
```

After examining the filesystem, you may find that you want to modify some of the files it contains or simply add files to that filesystem. You can always do this by unmounting the partition and remounting it with the ro option. However, the mount command provides some shortcuts in this process, enabling you to automatically remount a mounted filesystem in a different mode (such as rw, read-write) using the rw and remount options together, in the following example:

```
mount /dev/sda /mnt -o rw
```

This command simply updates the mode in which the filesystem is mounted without you explicitly unmounting it.

## Mounting a CD or DVD

CD and DVD devices are slightly different from hard drives because they can consist of only a single partition and cannot be written when mounted. Mounting a CD or DVD in SUSE is not automatic, the system senses when a new disk is inserted. When you actually try to access the CD or DVD, the kernel mounts the device automatically for you. This is something that Windows and Macintosh users will be used to, because they have had this luxury for a while.

To mount a CD or DVD manually, you can also use the mount command. SUSE will create a directory under /media that represents your optical device. Different directories will be created under /media depending on the optical disk that you are mounting. For example, if a CD with the name USB_BIBLE was inserted, the directory /media/USB_BIBLE would be created, and the CD could be mounted under this directory. A device-specific directory may also be created. For example, on an IBM ThinkPad X21 with an external CD drive, the device also contains a directory named usb-storage-000000000194703:0:0, whose name was created from the USB device and information for external CD drive.

Because optical devices do not have partitions, you access the whole disk. IDE-based CD or DVD devices are associated with a /dev/hdx device in the same way as any other IDE device. If your CD/DVD drive is connected to the first port on the secondary IDE bus (as is usual on most PC systems) you would access it through /dev/hdc. You could there mount the disk manually by issuing the command mount /dev/hdc /media/cdrom.

SUSE now uses HAL and mbfs to automatically sense media inserted into the computer. In the case of an optical device, its volume name is used. In the case of other storage mediums (USB keys, removable drives, and so on) the device string is used (comprising the hardware address of the device). If you want to create a directory /media for manual mounts (for example, mounting a CD-ROM under /media/cdrom), you would have to first create that directory and manually mount the media.

During installation, YaST actually creates a link to your optical media device /dev so that you do not have to deal with the details of your optical drive. If you have a standard CD drive, this is linked to /dev/cdrom. For a CD recorder this is /dev/cdrecorder, and for a DVD drive it is /dev/dvd.

## Mounting Filesystems Automatically

The /etc/fstab is used to store information about filesystems that have been permanently defined for the system. This includes the swap partition and the root partition, as well as any other partitions created during installation. The fstab file proves very well if you create new partitions that you need to be using a permanent basis and that need to be integrated into the system whenever the system is booted. During booting, the initialization of the system attempts to mount all of the filesystems in fstab unless the noauto option has been added to the options for a specific filesystem.

In this example, we add a new Reiser filesystem we created, and we mount it under /sparse at each system.

> To edit the /etc/fstab file or files like it, you need to work with a text editor. More information on text editors, take a look at Chapter 11.

To add a filesystem to be mounted automatically at boot, you need to add a line to the fstab that specifies the partition, mount point, filesystem type, your options, and some system information about backups and mount order:

```
/dev/sda5 /sparse reiserfs default 0 0
```

The line you add to fstab is made up of the following fields:

- Column 1—The partition you want to mount.
- Column 2—The directory you want to mount the filesystem under.
- Column 3—The filesystem type (the same that is passed to mount -t).
- Column 4—A comma-delimited list of filesystem options (noatime, notail, and so on).
- Column 5 — Specified dump priority. The value "0" in this field means "do not back up this filesystem."
- Column 6 — The order in which the filesystem should be checked. If this is a journaling filesystem, this is not needed as a filesystem check is run when the filesystem is mounted by the filesystem driver. The value "0" in this field means "do not perform this check."
