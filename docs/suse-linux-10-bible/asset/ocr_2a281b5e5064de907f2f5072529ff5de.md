# 502 Part IV Implementing Network Services in SUSE Linux

If you are using KDE desktop, you can create a permanent shortcut to the Local Network icon on your SUSE desktop by dragging the Local Network icon from Konqueror to your desktop and selecting Copy Here from the menu that is displayed. You can do the same by right-clicking Konqueror's Local Network icon, navigating to your Folder's Desktop folder, and selecting the Copy Here menu command.

A alternative to using Konqueror to browse all Windows resources is to use a command-line utility called smbtree. This utility is installed as part of the samba-client package, and provides a listing of available SMB resources from within console, xterm, or any other Linux terminal emulation utility.
