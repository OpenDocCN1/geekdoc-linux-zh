# 128 Part II ♦ The SUSE System

After you have identified the Windows partition that you want to resize, you can use the `resize` command's `resize` command to resize the partition. The `resize` command takes three arguments:

+   - The minor number of the partition that you want to resize
- The starting position of the filesystem in megabytes
- The end of the resized filesystem in megabytes

The end of the resized filesystem must be some number greater than the amount of used in your Windows partition that you wrote down earlier in this section. This guarantees that the resized filesystem is large enough to hold all of the files that are currently used by Windows in the original partition. Remember to make this slightly larger than the amount of used space in your Windows partition so you will be able to create new files under Windows.

For example, to resize the partition in the previous example to 3GB, you would enter a command such as the following:

```
parted 1 0.031 3000
```

When this command completes, use the `print` command to verify that your partition has been correctly resized, and use the `exit` command to leave the `parted` program. You should then reboot your system into Windows, and make sure that Windows boots correctly.

If this is the case, you can shut down your Windows system, boot from the SUSE install CD or DVD, and proceed with installing SUSE Linux into the space that you have freed up on your disk.

# Sharing Data on Windows and Linux Partitions

The previous sections explained how to install both Windows and Linux on a single system in different scenarios. This section summarizes the different types of partitions that are used by each operating system and the extent to which you can access the partitions used by one operating system from the other. If you have a dual-boot system, it's inevitable that at some point you will need to use data under one operating system that is actually stored in the filesystem(s) used by the other. Because both operating systems can't be running at the same time on a dual-boot system, you will need to be able to mount or simply explore one operating system's filesystem while running the other operating system.
