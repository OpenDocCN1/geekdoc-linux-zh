# Listing 15-7: Listing NetWare Servers on Your Network

| Known NetWare File Servers | Network Node Address |
|---|---|
| BIBLE | CN8001 0000000001 |

As you can see, in this example, we just happen to have a NetWare server on our network called BIBLE.

For this example, we have created a directory under /media called Netware on which to mount our server. Actually mount the server, you use the command ncpmount. It is very similar to the mount command you have already come across in the book, but because you need to tell the server you are authenticating, you have a few extra things to bear in mind.

The ncpmount command takes the server, the username, and the mount point you want to mount the server. In this case, you will log in to the server BIBLE as the (-U) justin, mounting under /media/Network.

```
bible: # ncpmount BIBLE -U justin /media/Network/
Logging into BIBLE as JUSTIN
Password:
```

When mounted, you can use the NetWare file server as any other mounted filesystem.

# Network Tools

When you have the network up and running, you need to take advantage and start it. Any administrator will realize that sitting in front of a machine is laborious and time-consuming. Network tools such as Telnet and SSH provide a means to log in to a Linux machine, creating a virtual terminal for you to work at.

Telnet is a protocol that has been around for a very long time and is now quite outdated and insecure as all transmissions through Telnet are in plain text. Because of this, most distributions disable the Telnet server out of the box. By default, you will be able to use SSH to connect to a server (discussed later in the chapter).
