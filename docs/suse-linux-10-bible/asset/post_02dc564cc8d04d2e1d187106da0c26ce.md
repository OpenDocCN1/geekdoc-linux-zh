## Using the Outlook Connectors

SUSE and Netline have provided a connector for Windows Clients that will allow you to access the group functionality SLOX through Outlook. Both products provide a way to access the services, but both do it in a different way.

## iSLOX

The iSLOX connector provides a real-time connector for SLOX that does not save any data for you to read offline at a later point. In the same way as an IMAP connection gives you access to mail for the duration of a connection to the server, iSLOX provides access to SLOX data for the duration of a server connection.

With iSLOX you can change permissions on a folder in the same way as you do with a connection to a Microsoft Exchange server.

## oSLOX

The oSLOX connector provides a connection to the SLOX server by synchronizing data at an interval to your Outlook PST file directly. With oSLOX, you cannot change permissions on your folders, and you have to create a separate IMAP profile for your mail.

Using oSLOX has two advantages:

- If you use oSLOX, all of your SLOX data is stored locally on your computer for offline use. If any of your users are accessing SLOX from a laptop, you should use the oSLOX connector.
- You can statistically distribute the load on the SLOX server by increasing the time you synchronize to the server. For example, if you have 100 users and use the synchronization time to 5 minutes, you can distribute the load of WebDAV connections to 20 connections per minute (at best), which drastically reduces the impact of concurrent users on your installation. This also helps to distribute the amount of groupware licenses that are needed for concurrent connections.

Throughout the rest of the chapter, we will use the Netline oSLOX connector to make a connection to the SLOX server.

## Using oSLOX

To download the oSLOX connector, follow these steps:

1. 1. Go to http://sdb.suse.de/download/i386/Openexchange-Server/4/images/ and log in with your SUSE support credentials (you received this when you registered your version of SLOX).
2. Download the latest oSLOX version.

When you have downloaded the oSLOX connector, run it by double-clicking the installation file.

> Note: oSLOX file you have downloaded is the application itself, not an installation binary. It is advisable to drop the executable into your Program Files directory and place a link in your Startup folder so that it runs whenever you log in.

To configure the oSLOX component:

1. 1. Select the Outlook profile with which you want to use oSLOX (see Figure 30-36).

![](img/e4e45c9f32e76fb35fabbd21a96f1a1e_820_0.png)

Figure 30-36: Selecting the Outlook profile to use with oSLOX

When you have selected the profile you want to use, click Next to continue with the server configuration.

2. 2. For the next screen (see Figure 30-37), you need to know the IP address of your SLOX server; you also need to enter the username and password that you use to connect to the web interface.

![](img/e4e45c9f32e76fb35fabbd21a96f1a1e_820_1.png)

Figure 30-37: Configuring your server connection

When you are happy with your settings, click the Check button to test the server connection and your credentials. If all has gone well, click Next to continue to folder configuration (see Figure 30-38).

3. Select the Outlook folders you want to synchronize. This will probably be all of your standard folders (Contacts, Calendar, and Tasks). Click Next when you are finished.

4. Choose which SLOX folders (not mail folders) you want to subscribe to (see Figure 30-39). If you or your administrator has created a SLOX folder (for contacts, calendars, and so on), you will see them listed here. Select the folders you want to subscribe to, or you can select all to have access to all publicly accessible folders. Click Next to continue.

If you have a lot of users on the oSLOX installation, the longer the synchronization interval, the more you will spread the load (statistically) on the server itself. Click Start oSLOX run in the background and synchronize at the interval you have selected.

## Your First Synchronization

If you have existing entries in your Outlook PST file, it is a good idea to do a synchronization to the SLOX server so that your data is replicated. If you do not have any existing data (meaning this is a brand-new user), then only entries on the SLOX server will be replicated.

To synchronize your data, follow these steps:

1. 1. Right-click the oSLOX taskbar icon (visible in Figure 30-41) and select Open This opens the oSLOX manager, which enables you to force a synchronization and to change your SLOX settings.

2. 2. Click the sync button to start synchronization. As we have created only a few SLOX entries, we will not produce a lot of traffic.

When that completes, we have synchronized three contacts (Justin, Roger, and Aimee), one appointment (the all-day task created earlier), and a task (the AR task we created).
