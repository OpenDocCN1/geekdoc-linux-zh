# YOU Dangers

It is important to realize that for some reason you have installed third-party ver-
pages having the same name as SUSE packages, a careless YOU update
overwrite them.

When running a mission-critical system, although you should be aware of
security issues and be ready to apply relevant security patches to any
available machine as a matter of priority, you should also be extremely careful not
to apply all patches without serious thought. Some kernel patches in particular can
to break the functionality of third-party commercial software, which may at
best mean that you need to reconfigure the software and at worst could lead to a
situation where you have real difficulty getting back to a working system.

# fou4s

Fast Online Updater for SUSE (fou4s) from http://fou4s.gausch.at/ is another
command-line alternative to YOU. It has similar functionality, but claims additional
speed and can be run interactively or automatically from a script or cron job.

# The YaST Installation Server Module

An installation server is a machine that offers the installation set across the net-
work. If you are likely to want to install a large number of machines, this gives you a
way of reducing the amount of work involved installing systems; after the new
system has been booted, it can access the installation set across the network, and
bulk of the installation can be undone. If you set up autoinstallation
(see the next section) and network booting, then the installations in fact be
totatically.
