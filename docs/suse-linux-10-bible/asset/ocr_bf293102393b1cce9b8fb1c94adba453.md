# Finding What RPM Package Owns a File

When a package has been installed, you may need to find out if a file on the system belongs to a package for maintenance purposes. To do this, you need to query (-q) the database again and find where the file came from (-f), as we do in the following code:

```
bible:/media/dvd/suse/i586 # rpm -qf /usr/X11R6/bin/blackbox
blackbox-0.65.0-313
```

As you can see by the second line in the preceding example, the RPM database is fully aware that the file /usr/X11R6/bin/blackbox belongs to the Blackbox package.

> If you do not know the full location of a binary file, you can use the which command and backtrack to pass the full path of the binary to rpm -qf. If you wanted to find the location of Blackbox, you could use which blackbox. Passing this to rpm -qf is achieved using the command rpm -qf 'blackbox'. A backtick is not a single quote; it looks like a single quote slanted to the left on your keyboard.

Querying the database for file ownership is really useful when you want to upgrade a certain application, but you are unsure it is controlled by the RPM system.
