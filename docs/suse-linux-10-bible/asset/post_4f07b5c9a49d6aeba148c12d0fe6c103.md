It is likely that you will want to start emacs by openinging a particular file. To do that, type the following:

```
emacs file
```

or

```
emacs -nw file
```

If the file that you name does not exist, it will be created when you first save the file.

You can start the editor. Typing will instantly update to the editing buffer, which you can see. Just doing "what comes naturally" will work fine now: The keys or the mouse will reposition the cursor as expected and the Backspace key will delete backward while the Delete key will delete forward.

# Controlling emacs

To issue commands to emacs, use key combinations. In describing this, it is the convention to use C for the Ctrl key and M for the Meta key, which can be either Alt or Esc. For example, to save a file, you Ctrl+x this is normally written as C-x C-s. If you are running the graphical form of emacs, you can do some of the most common actions (such as saving a file) by clicking menu items (File-C Save).

Note that the commands here are the default ones. The emacs editor is totally configurable, which means you can bind a particular keystroke to any command. For example, C-x C-f is bound to the command find-file, which you can also run with M-x find-file. You can break and bind the command to a different keystroke. You can also bind a keystroke to the command that you find yourself using regularly that has no binding (or one you find inconvenient). To make such a change, you need to add a line to your .gnu-emacs-custom file.

The most important emacs commands are as follows:

- C-x C-f — Find a file (that is, open).
- C-x C-b — Save the current buffer.
- C-x C-w — Write the current buffer to a file ("Save as").
- C-x C-c — Quit.
- C-k — Kill the rest of the current line.
- C-y — Yank (that is, copy) the last killed text.
- M-w — Copy the selected text.

# Moving Around

If you are using emacs in a graphical session, the mouse works both for selecting text and for moving around the file. But you can also navigate with the keyboard using the following keystrokes:

- C-f — Move to next character.
- C-b — Move to previous character.
- M-f — Move to next word.
- M-b — Move to previous word.
- C-a — Move to beginning of line.
- C-e — Move to end of line.
- M-a — Move to beginning of sentence.
- M-e — Move to end of sentence.
- C-Home — Move to top of buffer.
- C-End — Move to bottom of buffer.
- M-x goto-line — Move to a line number that you specify.

# Undo

C-_u or C-x u will undo your last command or typing: emacs remembers everything you do, so you can do a sequence of undo commands.

# Replacing Text

M-x replace-string will globally replace one string with another in the whole buffer or in the selection. You can also do a conditional replacement of text with M-% or M-x query-replace. This prompts you as whether you want to make each change.

# Searching

C-s starts an incremental search. What this means is if you type C-s Li, for example, you see the next instance of Li highlighted in the text. If you type another letter (for example n), you will now be searching for Lin. If you press C-s again, you will move to the next instance of this new search string.

You can also do a non-incremental search by typing C-s followed by Return. When you enter now will be the search and emacs will jump to the next occurrence of it. Regular expression searches are also possible. The command M-| starts a regular expression search. If you type a regular expression, emacs searches for the next matching text in the buffer. (See also Chapter 10 for more regular expressions.)

# Making Corrections

M-c capitalizes the next word, M-u makes the next word all caps. M-1 does lowercase. M-t switches the order of two words. M-* ispell-buffer checks the spelling of the entire buffer. You can check the spelling of a single word with M-x ispell-word.

# Using Word Completion

One of the useful features of emacs is the way that it knows what you are going to type. (Well, not quite literally, but good enough.) If you are working on a file and a word and then type M-, emacs tries to complete the word for you, based on previous words in the file. If it chooses the wrong one, simply type M-/ until you get the one you want and continue typing. This is an extremely powerful feature, not just because it can save it.
