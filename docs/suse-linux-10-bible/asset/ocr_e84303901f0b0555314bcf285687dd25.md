There are a variety of window managers that range from the very minimal, such as TWM and MWM, to the integrated desktop environments, such as KDE and GNOME.

Traditionally, a window manager on the X System on Unix was not particularly pretty, to say least; if you log into your SUSE Linux system and choose TWM as your window manager rather than the default, you will see what I mean.

If you choose the installation option Minimal with X11, you get a system with the fwm window manager and the xdm login manager. You may want to do this if you are installing SUSE on a server for which you do not need the use of a full-blown desktop but occasionally need to run a graphical program (such certain monitoring tools or the Oracle installer, for example).

# KDE and GNOME

Back in 1996, there was a general feeling that the available window managers on X were sparse and lacking in features compared to the graphical environments on Windows and the Mac. A primary concern was that X Window system window managers were fine at creating and managing windows and the graphical applications that created, but did not support the greater ease of use that users of systems such as Microsoft\000 Windows and Mac OS have to expect. This led to the start of the KDE project. The idea of KDE was to go beyond a window manager that simply handled mouse and keyboard interactions and to create a unified desktop environment for users. In this unified environment, clicking a file in the file manager would launch the correct application, drag and drop work between different applications, all applications would share a common look and feel, and so.

KDE made progress but became involved in controversy because it is based on the Qt toolkit (produced by Trolltech), which was issued under a license that was regarded by many as unacceptable.. Although the source code was open, it did not qualify as a free software license because it did not permit the redistribution of modifications.. Some people also felt that Trolltech could change the terms on what it offered, thereby derailing the project. The rival GNOME project with similar aims was met shortly afterward, partly in reaction to the controversy over the Qt license. GNOME used the GTK toolkit, which was part of the GNOME project and licensed under the GNU General License (LGPL).

In course the controversy surrounding KDE was solved by a change in the license. At first, Trolltech sought to solve the problem by offering a free edition of Qt under a special open source license (the QPL), but controversy continued until Trolltech agreed to release Qt under a dual license (GPL and QPL), a solution that was satisfactory to all parties.
