
Assuming that your modem is supported, YaST asks you for the necessary information to set up the modem and dial-up connection. In the first screen of the setup you are asked for a dial prefix if necessary (a prefix you might need to get an outside line, for example) and to choose between tone dialing and pulse dialing (tone dialing will be the correct choice unless your telephone exchange is antiquated). The other two choices here (Speaker on Detect Dial tone) will almost certainly leave as they are (by default).

The next screen asks you for your country and offers a small selection of configured providers (ISPs). This means that the access is already known to the system for these providers. One or two have gone further and enable to use a preconfigured username and password to sign up with them, or to get anonymous access with payment collected through your phone charges.

If you already have an account with an ISP that is not listed, you need to press the New button and add the details of the provider's name, the access number, and your username and password.

When this is done, finish and the modem configuration should be complete. You will be able to connect using the internet program, which you can access through the KDE menu (Internet Dialog). You can set it to run whenever you log in KDE; if you do this by clicking its tiny icon, which will be resident in the system tray area of the KDE panel (by default in the bottom-right corner of the screen).

> More information about using modems under Linux can be obtained from www.linuxmodems.org. You may be able to obtain a dialer for your modem from this site, even if it is not supported by SUSE. You can also download a tool called ScanModem which detects the exact type of modem that you have. When you do this, you can search the site for information whether it is possible to get it working.

## ISDN and ADSL Connections

SUSE has very good support for internal Integrated Services Digital Network (ISDN) cards, and these can also be set up in the installation. In most cases, the card will be automatically set up, and you just have to provide the specific information given to you by your ISP.

Asymmetric digital subscriber line (ADSL) providers sometimes offer a particular hardware device to connect. These are USB devices. Unfortunately, there are a large number of different types and not all of them work with Linux. There are different standards in different countries and as a result, getting these devices to work on Linux has always been something of a problem. If YaST detects such a device during the installation, it attempts to set it up, but there are many cases in which USB ADSL devices fail to work with SUSE Linux.

If possible, rather than using a USB device for ADSL, you should choose one of the ADSL routers with Ethernet output. This type of ADSL connection will always work, and if your provider offers the choice, you should definitely go for this type of connection. If your provider offers a wires-only service, you can buy such a router and use it to connect; again, there should be no problems at all. All you need to do is follow the instructions provided by the manufacturer or ISP for setting up your network connection to talk to the router and make the necessary settings in YaST's networking module.

## SuSEConfig

The SUSE system configuration is controlled by SUSE-specific control files that the system application SuSEConfig uses to write application-specific configuration files. This enables the user to configure services and server processes without having to understand application-specific configuration files. When all packages have been installed, SuSEConfig picks up the default configuration files by SUSE and writes specific application configurations.

SuSEConfig is a core element of the SUSE system and YaST to maintain configuration files for services it can control. If any changes you make using YaST, SuSEConfig will be called to commit those changes.
