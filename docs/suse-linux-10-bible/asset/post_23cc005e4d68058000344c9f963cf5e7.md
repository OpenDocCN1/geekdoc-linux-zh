## Wireless Networking

One of the best of the networking technologies that have come along in the past few years is wireless networking. Wireless networking is its quickest adoption in the laptop market, and many machines now use the Centrino chipset from Intel.

If your laptop does not include an onboard wireless chipset, you will probably find a good PCMCIA (an expansion slot for laptops) that provides wireless service for you. A lot of Linux users have great results with the Cisco wireless cards.

If you are not whether your wireless networking card is supported in Linux, or you are looking to purchase one, Google is always your friend. Use Google to search for the term "Linux" and the model number of the wireless networking card you are interested in.

Starting with SUSE 9.3 and in subsequent releases, SUSE has added a lot more support for the particular Centrino chipset. The firmware files for these chipsets are now included in the distribution and are configurable in the same way as a normal network card under YaST.

## ndiswrapper

If you do not use one of the popular wireless cards supported out of the box in SUSE, you can potentially use ndiswrapper. ndiswrapper is a great system that will enable you to wrap a Linux kernel driver around a Windows network card driver to be able to provide you with support for pretty any network card out.

> Before you start with the configuration of your networking with ndiswrapper, you must make sure you download the Correct Drivers. If you are using a 64-bit laptop (for an AMD 64), you must download the 64-bit version of the driver. Similarly for a 32-bit laptop, you must use the 32-bit Windows drivers.

To get ndiswrapper working:

- 1. You need to install the ndiswrapper package by YaST. For more information about how to install new applications in SUSE, refer to Chapter 1.
- 2. In the YaST package search screen, search for ndiswrapper and select it for installation.
- 3. After ndiswrapper has been installed, you will need to download or copy the Windows driver package to your SUSE installation. We use the A-Link WL54H chipset as an example.
- 4. When downloaded, unarchive the package (Windows drivers usually come as a zip file, in this case use the unzip command — see Listing 15-17).

## Listing 15-17: Using unzip to Unarchive a Windows Network Driver

```

```

- 5. After the driver archive has been unarchived, you need to install the driver under ndiswrapper. If you want to support WPA (Wi-Fi protected access), you need to use Windows XP version of the drivers. To install the driver, you need to use ndiswrapper -i (install). See Listing 15-18.

| Listing 15-18: Using ndiswrapper to Install a Windows Network Driver |
```
linux::~Win2K # ndiswrapper -i Rt2500.INF
Installing rt2500
linux::~Win2K #
```

- 6. After the driver has been installed, you can then check whether ndiswrapper has successfully recognized it by listing the driver it has installed using the -l option (list). See Listing 15-19.

| Listing 15-19: Checking ndiswrapper drivers |
```
linux::~Win2K # ndiswrapper -l
rt2500 (rtl_80211)
```

- 7. If you are happy with the driver, you can load the module into the kernel. See Listing 15-20.

| Listing 15-20: Installing the driver into Kernel |
```
linux::~Win2K # modprobe rt2500
```

## Chapter 15: Networking

The ndiswrapper module is always loaded. Now that the wireless network driver has been installed, you can then enable DHCP (Dynamic Host Protocol) for that interface.

### Configuring Your Wireless Network

One of the first things you need to configure is to search for wireless networks. To do this, use the `iwlist` command.

## List 15-21: Searching for Wireless Network

```
thinkpad:- iwlist scan
Scanning...
00:07:24:7E:D5 Justin's Phone
00:0A:95:2F:D6:78 tibook
```

The `iwlist` command returns all wireless networks as well as the frequency and signal strength. In this case, you have found the WLAN.

To join a wireless network, you use the `iwconfig` command.

```
thinkpad:- iwconfig wlan0
```

The `iwconfig` command takes two very important parameters: the interface your wireless card has and the SSID (the name of the network) you want to connect to.

When the command has completed, you can then enable DHCP for that interface. SUSE includes `ifup-dhcp` and `ifdown-dhcp` to attach a DHCP client to the network.

```
thinkpad:~ # ifup-dhcp eth1
Starting DHCP Daemon on eth1.... IP/Netmask: 192.168.1.80 / 255.255.255.0
```

You can see that the network has picked up 192.168.1.80/24 as our network configuration.

## Bluetooth

Bluetooth is another great technology that is helping drive mobile technology further and further. Bluetooth under Linux is quite mature, and KDE also includes programs to take advantage of your Bluetooth system.

For Bluetooth to work under Linux, the following:

- 1. Install the `bluez-*` Bluetooth stack packages using YaST's package manager.
- 2. When installed, make sure Bluetooth has been turned on in your laptop (on the Thinkpad, press Fn-F5).
- 3. When running, start the Bluetooth service with `bluetooth start`.
- 4. When running, you need to bring your Bluetooth network device with the `hcconfig hci1 up` command.

As with the Bluetooth stack on other operating systems, you can scan for discoverable devices in the personal area network. You can scan for Bluetooth devices use the `hcitool` command:

```
thinkpad:~ # hcitool scan
Scanning...
00:07:24:7E:D5 Justin's Phone
00:0A:95:2F:D6:78 tibook
```

This scan has found two Bluetooth-aware devices in discoverable mode. When you have found a Bluetooth device, use the `ping` command to check connectivity (see Listing 15-22).
