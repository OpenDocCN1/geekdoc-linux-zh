# 74 Part I ◆ SUSE Linux Basics

If you are logged into the machine bile as user fred and you want to log in to the machine faraway as user guest, this is what you would do:

```
fred@bible:--> ssh@faraway
```

You will be prompted for the password, and you will be logged in.

If you use ssh with the option -X you will be able to run graphical programs on far- and see the display on home.

If you need to connect to your Linux machine from Windows, you can still use ssh provided you have installed an ssh client for Windows: The best known of these is putty. You will find a version of putty in the details directory on the SUSE DVD that is included with this book. The latest version of putty is available online from www.chiark.green.org.uk/~sgatham/putty/.

Similarly, the traditional way to move files from one system to another was FTP. Again, SUSE systems do not have FTP enabled by default because of security concerns; you should use scp or sftp:

+   - scp is most convenient when you are copying files from the local machine to the remote one:
- scp myroot@faraway:/tmp/
- sftp allows you to list files and navigate directories on the remote machine just like FTP. You can then use the get and put commands within sftp to transfer the files.

The Conqueror browser has a new feature called fish, which allows you to browse files on a remote machine using ssh, effectively combining the functionality of the ssh tools into a graphical remote access client. In the Conqueror location bar, type fish://faraway.or will then try to log in using your current user-name to the machine faraway and display your home directory. You can drag files from another Conqueror window or to the desktop. If you need to use a different username on the remote machine, you can type, for example, fish:/root@faraway into the location bar.

If you are regularly logging into one or more machines by ssh, you may want to creating an ssh key and copying it to the remote machine to allow a secure passwordless login:

```
ssh-keygen -t rsa
```

When prompted for a password, you can simply press Return. This will create files id_rsa and id_rsa.pub in the directory under your home directory. If you copy (or append) the file id_rsa.pub (the public key) to the file .ssh/authorized_keys2 under your home directory on the remote machine, you will be able to log in by simply typing ssh faraway.
