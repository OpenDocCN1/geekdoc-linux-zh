# Selecting a Boot Loader

The next item you can change is the configuration of the boot loader. A boot loader is central to the deployment of Linux and controls the booting of operating systems on the PC. To customize the boot loader that is used by SUSE installation, you must click the Booting in YaST's Expert Installation Settings panel, or click the Change button (under Expert Tab) and select Boosting from the pop-up menu. Doing either of these displays the pane shown in Figure 1-17, YaST's Boot Loader settings.
