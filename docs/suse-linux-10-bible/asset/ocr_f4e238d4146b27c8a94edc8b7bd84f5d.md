Here, the administrator name and context should be in the form shown in Figure 31-7. In the dialect of LDAP used by eDirectory the cn= is separated from the o= by a comma, and the dots within the domain name need to be escaped by backslashes. So you need to enter something:

```
cn=admin.disruptive\org\uk
```

The next screen sets port numbers; there should normally be no reason to change anything here.

In the next screen you are given the opportunity to set an NTP (time) server and configure SLP (Server Location Protocol) if necessary; with one OES server, this is optional.

If you have chosen to install iFolder, you now have to set an IP alias (additional IP number) and an additional host name for the iFolder server, regardless of the fact that it will be running on the same machine as the rest of the OES installation (see Figure 31-8).

The setting up and starting of the eDirectory server now takes quite a while.

Following this, the installation will be complete.
