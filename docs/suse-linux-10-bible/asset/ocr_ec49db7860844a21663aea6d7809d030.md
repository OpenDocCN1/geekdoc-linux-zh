# Changing Partition Output Types

As you can see from the output of fdisk and the p command in the preceding sections, there are a variety of different types of partitions. Linux, Linux swap, and Extended all refer to a specific type of partition. Many operating systems, including Windows and Linux, have different types of partitions. Most common ones that every Linux system uses the Linux (type 83 in fdisk) and Linux swap (type 82 in fdisk) types. Linux handles partitions of different types in ways.

Any filesystem you create on a partition must be created on a partition whose type is Linux (type 83). The swap partition must be type of Linux swap. When creating partitions, type 83 is the default partition type for all physical or logical partitions. If you want to create a partition of a different type, you must create it (using fdisk or YaST) and then modify its type.

Why would you want to do this? You want to create a partition of a different type if, for example, you are adding a new disk to a system that can boot both Linux and another operating system and you want to use a portion of your new disk as a standard partition for that operating system. For example, Linux knows about Windows partitions, but Windows does not know about Linux partitions, so you would want to partition the disk using Linux but then format the Windows partition under Windows. Linux recognizes (and access) an incredible number of different types of partitions, which enables you to use fdisk to create disks that you can share with a wide range of other types of computer systems.

To change the type of a partition in fdisk, use the t command and enter the number of the partition that you want to modify. You will then be prompted for the type of partition you want to change the partition to. This prompt takes a hexadecimal number as a type; you can view the list of available partition types by entering l when prompted for the hex code for the new partition type.

# Filesystems

Filesystems provide a base for your files to be stored on the physical disk. A good analogy is that a disk is like the building that houses your library, while the filesystem is its infrastructure—the shelves that hold the books and the card catalog enable you to find a particular type. Linux supports many types of filesystems, each of which has its own internal structure and access methods. To access a specific type of filesystem, Linux uses kernel software as a driver that understands the internal structure of a specific filesystem. If you are trying to read a disk from another type of system, Linux might also need to use additional drivers to be able to interpret the partition partition used by some types of disks and associated filesystems.
