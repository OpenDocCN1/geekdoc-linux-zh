To set up and configure a DHCP server for the first time using YaST, do the following:

+   1. Start YaST and select the Network Services item from the left pane, and select DHCP Server. You will see a screen that lists all available Ethernet interfaces on your system (see 20-1).

![](bbox=[0.231, 0.255, 0.722, 0.563])

**Figure 20-1:** The Card Selection screen of the YaST DHCP Server Wizard

If you are trying to configure a DHCP server but have not installed the dhcp-server package and requests the installation DVD or correct installation CDs.

+   2. Select the network interface on which you want your DHCP server to listen for client DHCP requests. If you are running a firewall, click the Open Firewall on Selected Interface check box. If you do not open the firewall to enable DHCP connections, no other host will see your DHCP server. Click next to display the Global Settings screen (see Figure 20-2).
