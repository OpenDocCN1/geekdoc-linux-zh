When the command has completed, you can then enable DHCP (Dynamic Host Configuration Protocol) for that interface. SUSE includes ifup-dhcp and ifdown-dhcp to attach a DHCP client to the network card. In this example, you attach the DHCP process to eth1, which has now been configured and attached to the WLAN wireless network.

```
thinkpad:~ # ifup-dhcp eth1
Starting DHCP Daemon on eth1.... IP/Netmask: 192.168.1.80 / 255.255.255.0
```

You can see that the bluetooth network has picked up 192.168.1.80/24 or as our network configuration.

+   For more information on using DHCP, take a look at Chapter 20.

# Bluetooth

Bluetooth is another great technology that is helping drive mobile technology further and further. Bluetooth under Linux is quite mature, and KDE also includes programs to take advantage of your Bluetooth system.

For Bluetooth to work under Linux, the following:

+   1. Install the bluez-* Bluetooth stack packages using YaST's package manager.
2. When installed, make sure Bluetooth has been turned on in your laptop (on the Thinkpad, press Fn-F5).
3. When running, start the Bluetooth service with rbluetooth start.
4. When running, you need to bring your Bluetooth network device with the hconfig hci10 up command.

As with the Bluetooth stack on other operating systems, you can scan for discoverable devices in the personal area network. You can scan for Bluetooth devices, use the hcitool command:

```
thinkpad:~ # hcitool scan
Scanning...
00:07:24:7E:D5 Justin's Phone
00:0A:95:2F:D6:78 tibook
```

This scan has found two Bluetooth-aware devices in discoverable mode, my Powerbook and my T610 phone.

When you have found a Bluetooth device, use the 12ping command to check connectivity (see Listing 15-22).
