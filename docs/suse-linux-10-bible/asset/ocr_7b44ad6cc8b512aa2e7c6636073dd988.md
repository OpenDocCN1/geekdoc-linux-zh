# Setting Up a Scanner

YaST's scanner module automatically detects and sets up a scanner if it can; USB and SCSI scanners are supported, as well as Hewlett-Packard's all-in-one (scanner-printer-fax devices) USB devices and network scan stations. The ancient port scanners are not supported and cannot be configured with this module. In most cases, if a USB or SCSI scanner is detected, YaST sets it automatically. If one or two scanners require a firmware file to be installed; if this is required, YaST warns you of the fact, but you may have to obtain this file from the installation media that came with the scanner or from the manufacturer's site. When the scanner is set up correctly, you can use it most easily by running the program kinda (KDE scanning tool) or, if you prefer, xsane.

> Note
The definitive source of information about using a scanner with Linux is www.sane-project.org. You may also find information about problems with specific scanners by searching for the word scanner on the SUSE portal's support database: http://portal.suse.com/PM/page/search.pm.
