# Listing Files

The ls (list) command lists files in the current directory. The command ls has a large number of options, but what you really need to know is that ls -l gives a "long" showing the file sizes and permissions, and that the -a option shows "hidden" files—those with a dot at the start of their names. The shell expands the character to mean any string of characters not starting with '.';See the discussion of wildcards in "Advanced Shell Files" section in this chapter for more information how and why this works). Therefore, *.doc is interpreted as a filename ending with .doc that does not start with a dot and * means "any filename starting with the letter a". For example:

+   - ls -la Gives a list of all files in the current directory including "hidden files with names starting with a
- ls a* Lists all files in the current directory whose names start with a
- ls *.doc Gives a list of all files in the current directory whose names end with .doc

# Copy Files

The cp (copy) command copies a file, files, or directory to another location. The option -r allows you to copy directories recursively (in general, -R or -r commands often have the meaning of "recursive"). If the last argument is a directory, the files mentioned will be copied into that directory. Note that by default, cp will clobber existing files, in the second example that follows, if there is already a file called a in the directory /home/bible, it will be overwritten without asking for confirmation. Consider the following examples:

+   - cp file.bak Copies the file file to a new file.bak.
- cp file /home/bible/ Copies the file file from the current directory to the directory /home/bible/
- cp * /tmp/ Copies all nonhidden files in the current directory to /tmp/.
