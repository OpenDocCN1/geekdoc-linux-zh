The bash shell provides a powerful command-line interface that offers many features that the DOS command line lacks. The most important of these are command history and command completion:

+   **Command history** — You can see a history of the commands you typed by pressing the up arrow repeatedly. You can then edit the command and reuse it.

+   **Command completion** — If you part of a command and press the Tab key, bash will complete the command as far as it is able to do so uniquely.

These two features together make working with the shell extremely quick and easy with a little practice. The command history is also searchable in more than one way: If you type the command history, you will see a list of the commands you have typed. Each of these is numbered: If you type followed by the number of the command, you can run it. If you press Ctrl-R (hold down the Control key and r), you can search the command history by typing part of the command you are looking for. If the first command is not the one you have in mind, repeat the Ctrl-R until it appears. You can also recall a previous command by typing ! followed by the first letter or letters of the previous command.
