# Table 4-4
Sample menu.lst Configuration Description

| Parameter | Description |
|---|---||
| chainloader +1 | Because Windows has its loader in the MBR of the partition it was installed into, its boot loader needs to be loaded. The +1 signifies that GRUB should start loading the boot loader from the first sector in the partition. |
| Default | Identifies the default profile used if no user interaction takes place. With other examples in GRUB, the entries start from 0, the default used in the previous example is the "Linux" profile. |
| gfxmenu (hd0,2)/boot/message | Specifies the location of the graphical file used as a background against which to display the GRUB menu. |
| initrd (hd0,2)/initrd | The initial ramdisk is used for this kernel. |
| kernel (hd0,2)/boot/vmlinuz | The location of the kernel. The hld(0,2) signifies hard drive 0 (the first hard drive), partition 3 (partition in GRUB start at 0). If you look in /boot directory you see the vmlinuz kernel file. |
| Makeactive | When booting Windows, installs a boot loader into the MBR of the partition that it is installed into. To load this MBR, GRUB has to temporarily make the partition "active" for booting. This clause makes this happens when the Windows profile is selected. |
| root=/dev/hda3 or root (hd0,1) | For a Linux boot profile, specifies the partition that the kernel will attempt to mount as its root filesystem. The partition that is to be mounted at /(root) that we have talked about previously in this chapter. For non-Linux boot profiles, specifies the hard drive and partition that holds the alternate bootable operating system. |
