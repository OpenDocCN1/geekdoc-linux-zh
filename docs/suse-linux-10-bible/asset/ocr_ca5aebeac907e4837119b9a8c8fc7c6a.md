# Reconfiguring an Existing DHCP Server in YaST

As explained in the previous section, YaST provides an easy-to-use and intuitive interface for DHCP server configuration. If you use YaST to configure an existing DHCP server, you will see the YaST screens and dialog discussed in this section. If you have not already configured a DHCP server on your system, YaST walks you through the configuration process using the YaST DHCP Server Configuration Wizard, which was explained in the previous section.

The YaST screens for configuring an existing DHCP server are very similar to those in its DHCP Server Configuration Wizard. You can select any of the YaST DHCP Server configuration screens at any time by selecting the same of that screen from the tree view in the DHCP Server configuration screen in Figure 20-5.

To configure an existing DHCP server using YaST, do the following:

+   1. YaST and select the Network Services item from the left pane, and choose DHCP server. You will see the screen shown in Figure 20-5.
