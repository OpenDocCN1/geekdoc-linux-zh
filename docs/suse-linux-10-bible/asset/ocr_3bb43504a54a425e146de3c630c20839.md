# If X Still Doesn’t Start

By default, a SUSE installation is set to boot into level 5, which means that working and graphics are running when the system starts, and a graphical display (login) manager is launched (usually kdm). It Occasionally happens immediately after the first time the system boots following installation, X either fails to start, or (worse) starts fails to display on the monitor because it has been incorrectly configured during installation. This can be distressing, not to say depressing, it appears that you have gone through the whole installation and nothing works. Don't despair; if happens, log as root one of the text consoles (hold Ctrl+Alt+one of the keys F1–F6). Then type:

```
init 3
sax2
```

and start with X configuration.

# Switching Resolutions

If you have more than one resolution configured, X typically starts in the highest of these. You can switch resolutions by pressing Ctrl and Alt together with the plus (+) or minus (−) keys from the numeric keypad. You can also (rather brutally) kill the X session with Ctrl+Alt+Backspace. This kills all running graphical programs without saving anything.
