We have constructed an LDIF file for the administrator Aimee Davies, including account information allowing her to use the LDAP data as a Unix authentication source.

To construct the initial LDIF file, we used the PADWL migration tools to transfer a standard user account from /etc/passwd to an LDIF format file, editing this file to add the extra information about the organization and her telephone number.

You can add each user in the organization to the specific organization unit that reflects the organizational chart. Using the ldapsearch command, you can now view the data in the LDAP server (see Listing 25-5). You use the -b option to tell ldap to search from the o=Acme,c=UK base of the LDAP tree. This enables you to search a certain portion of the LDAP tree, not the whole tree.
