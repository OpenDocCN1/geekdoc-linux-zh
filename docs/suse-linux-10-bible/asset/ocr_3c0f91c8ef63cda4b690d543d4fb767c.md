# 354 Part III ♦ Using the Command Line in SUSE Linux

To use the file command, simply type file by the file or files you want to analyze. For example:

```
userable:~/temp file index.html
index.html: HTML document text

userable:~/temp file realworld.doc
realworld.doc: Microsoft Office Document
```

We know that index.html is a HTML file and realworld.doc is a real Microsoft Word document.

```
userable:~/temp cp index.html strange.doc
userable:~/temp file strange.doc
strange.doc: HTML document text
```

Here, file was not fooled by the fact that we changed the file extension of the file. It isn't too hard to fool file, but you actually need to copy the first 8 bytes of the real Microsoft Word document to a new file to do.

```
userable:~/temp -d if realworld.doc of=8bytes bs=1 count=8
userable:cat @bytes index.html > newfile.doc
user:~/temp file newfile.doc
newfile.doc: Microsoft Office Document
```

You can actually check how file did:

```
userable:~/temp grep Office /usr/share/misc/magic
0 string $376$07\03 Microsoft Office Document
0 string $320$317\021\240\241\261\321 Microsoft Office Document
0 string $333$245\0\0
```

```
userable:~/od -b newfile.doc more
000000 320 317 021 240 241 261 032 341 074 041 104 117 103 124 131 120 [...]
```

The command gives you an octal dump of the file, and you can see that it has the second of signatures of an Office document at its start. Since you are piping the output of od to more, you can terminate the command at any time by pressing q to exit the more command.

If you are confronted with a file that the file doesn't give very useful information about (perhaps it reports "data”), it may be worth trying to view it with cat -v, with less, or with a text editor. If all you see is binary junk, you may still be able to find out useful using the strings command, which searches inside a binary file for text strings and outputs them.
