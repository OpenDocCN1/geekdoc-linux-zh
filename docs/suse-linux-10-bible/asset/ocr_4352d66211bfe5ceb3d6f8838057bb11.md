# Inserting the LDIF file

When the LDIF file contains an organizational structure has been created, you need to enter that information into the LDAP server. First, make sure your LDAP server is running:

```
ldap:- # rcdldap status
Checking for ldap running
```

When the LDAP server is running, you need to add the entries (see List 25-3).

> 25-3: Inserting LDIF Entries into LDAP

```
# ldapadd -D "cn=admin,o=Acme,c=UK" -x -f /tmp/top.ldif

adding new entry "ou=Sales,o=Acme,c=UK"
```
