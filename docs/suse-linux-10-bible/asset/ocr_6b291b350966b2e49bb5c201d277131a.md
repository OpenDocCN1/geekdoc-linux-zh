# Can Linux Be Used?

Most IT directors ask this question. The case for using Linux has already been made in the popular IT press, and organizations understand that Linux is now a viable option when Unix needs to be deployed.

# The Datacenter

Independent Software Vendors (ISVs) now see Linux as a Tier 1 (primary) platform for their software, and we are not talking about groups of coders in a dark room. The big ones are it, too—Oracle, IBM, SAP, and SAS to name a few. All see Linux as a platform that they can market and successfully sell upon, and others prove this.

Take Oracle as an example; it has said that its platform for development is Linux. Other ports are secondary to this strategy. Linux will always be a new release of Oracle, like the other major OS players (Microsoft, Sun, IBM, and so on). Oracle has made its database products available on many hardware platforms, including Intel (32/64-bit), PowerPC (PPC), and IBM zSeries (discussed later in this chapter).

This part of the market is called the datacenter and where Linux is growing the fastest of all. We have seen many customers using Linux to run critical Oracle databases over the past few years; IBM software is also very strong in this space.

# Infrastructure

Linux has traditionally been strong in this space, and it encompasses organizations as a core part of its IT infrastructure. Domain Name System (DNS), intranet, extranet, firewalls, email, file services, and print services all fall under this section of the enterprise. Market results have shown that Apache on Linux is extremely strong. And many organizations run their DNS on Linux without upper management knowing.
