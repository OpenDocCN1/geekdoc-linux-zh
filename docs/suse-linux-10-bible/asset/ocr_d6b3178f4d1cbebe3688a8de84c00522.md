# Chapter 4 ★ Booting the System 127

Before using parted to repartition an existing Windows partition, boot the system into Windows and run the Windows Disk Defragmenter software to pack your Windows data into the Windows partition(s) as efficiently as possible. This will make it easier for parted to resize an existing disk as efficiently as possible. After defragmenting, right-click the icon for the Windows that you are resizing (possibly C), and write down the amount of space used on that partition, as well as the amount of free space remaining. You can then shut down your Windows system and reboot into the Rescue System.

After you boot and log in to the system rescue mode, you can use the fdisk -l command to identify the name of the disk partition that you want to resize, usually /dev/hda (IDE drive) or /dev/sda (SCSI drive) in a single-disk Windows system.

You would start the parted command, using the name of the disk that you want to repartition as, in the following example:

```
# /dev/hda

Using /dev/hda
Information: The ... geometry on /dev/hda is 10011/255/63.
Therefore, cylinder 1024 ends at 8032.499M.

```

When running parted, its prompt is (parted), as shown in the preceding example. You can then use the parted command's print command to display a list of the current partitions on your disk, as in the following example:

```
#parted print help
Disk geometry for /dev/hda: 0.000-78533.437 megabytes
Disk label type: mdos
Minor Start End Type Filesystem Flags
1 0.031 78528.669 primary fat32 boot
```
