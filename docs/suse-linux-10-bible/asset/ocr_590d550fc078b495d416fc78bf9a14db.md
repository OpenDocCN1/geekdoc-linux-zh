This type of authentication uses the standard HTTP authentication method. This means that username/password pairs are transmitted across the network in base64 encoded format (that is, not simple plain text, but not encrypted). If a method of authentication is being used also for other purposes on the server (with the pam_auth example), there is an inherent security risk, which could potentially compromise users' accounts on the server.

This risk is avoided with the `digest_pw_auth` method. For this you need lines similar to the following in `/etc/squid/squid.conf`:

```
auth_param digest children 5
auth_param digest program /usr/bin/digest_pw_auth /etc/squid/digestpw
auth_param digest realm Squid proxy-caching web server
```
