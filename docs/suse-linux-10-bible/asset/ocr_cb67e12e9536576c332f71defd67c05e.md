# The KDE Control Center

KDE's Control Center gives you the great deal of scope for altering the look and
feel and behavior of the KDE environment. Most of the customizations that can be
are said fairly self-explanatory, but we would like to highlight a few interesting
features.

# Appearance and Themes

This dialog box enables you to customize the look and feel of KDE to your heart's
content. To select this configuration option, select the Control Center from SUSE's
Start menu and then select the Appearances and Themes option in the left pane.

# File Associations

In general, you don't want to make any changes here, but it is certainly useful to
know that you can, and where to find this feature. You can do two
things:

+   * You can change the default application that opens a given type of file when
y click it in Konqueror.
* You can alter whether the file will be viewed by an external application or by a
viewer embedded in Konqueror if such a viewer exists.

# Login Manager

This set of dialog boxes (in the System Administration menu) is certainly easier to
than editing the configuration file by. To select this configuration option,
select the Control Center from SUSE's Start and then select the System
Administrator option in the left pane, followed by the Login Manager option.
You need to run this in administrator mode (by clicking the Administrator Mode
button and entering the root password) to do anything very useful. A particularly
nice feature is that it allows you to drop a photo of a user into this dialog box; this
photo appears on the kdm login screen.

# YaST Modules

SUSE has integrated YaST so that you can access it through the KDE Control Center
if you want. To access YaST modules, select the Control Center from the
SUSE Start menu and then select the System Administrator option in the left pane,
followed by the Login Manager option. You will need to run this in administrator
mode (by clicking the Administrator Mode button and entering the root password)
to do anything very useful.
