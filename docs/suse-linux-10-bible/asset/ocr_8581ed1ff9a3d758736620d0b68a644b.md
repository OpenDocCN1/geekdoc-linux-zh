# Commercial Partitioning Utilities

The commercial tools Disk Director (www.acronis.com) and PartitionMagic (www.powerquest.com/partitionmagic/) are also very popular and friendly graphical interfaces. In our experience, PartitionMagic is easier to use than Acronis Disk Director. If you simply need to create or resize partitions (including NTFS), Linux now tools will do the job as well as these commercial built-in boot managers, which make it easier to boot multiple Windows partitions on the same machine.

# Using manage

The manage program is included in SUSE Professional and enables you to create an image file from a partition for backup and restore purposes. Because empty space is not included in the image, and because the image is compressed, it uses less space than writing the partition to a file using dd (dd is discussed later in the chapter). The program includes a restore option. It possibly should not be regarded as totally mature but is certainly worth investigating. Figure 14-6 shows manage up and running. If manage is installed, simply (as root) type the command parted to start it. The version of part that provided with your system differs depending on the version of SUSE Professional that you are using.

# Making a Filesystem

When you have created a partition, you still need to create the filesystem of your choice (typically EXT2, EXT3, or ReFS). While YaST and parted include the ability to create a filesystem on the new partition, fdisk simply makes the partition. Do not confuse the fact that fdisk sets the partition identity code with actually creating the filesystem on the partition. To that you will need to do one of the following (here we assume that you have created the partition /dev/hdc3 and you now want to create a filesystem on it):

```
root@dbible : ~ # mkfs -t ext2 /dev/hdc3
```

```
root@dbible : ~ # mkfs -t reisers /dev/hdc3
```

```
root@dbible : ~ # mkfs -t ext3 /dev/hdc3
```

Note that you must be root to create a filesystem.
