# Configuring Clients for NIS

This section explains how to set up an NIS client of the server started in the previous section. With setting up a NIS server, NIS clients can be configured using command-line utilities or by taking advantage of YaST's graphical administrative interface. The following two sections explain how to configure an NIS client using each of these methods.

# Configuring NIS Client using YaST

YaST makes NIS client configuration almost trivial, using a single dialog box to collect information about the NIS domain that you want your client to use. To configure a system using an NIS client YaST, do the following:

+   1. Start YaST's NIS client configuration by executing the command yast2 nis as root or sudo. This displays the dialog shown in Figure 2-7.

+   2. Click the NIS option button, and enter the name of the NIS domain you want the client to contact for authentication information. If your client system uses DHCP to deliver NIS server information, click Automatic Setup (through DHCP). If you want the NIS Client to search the local network by broadcasting if a connection to the specified NFS server fails, click the Broadcast option button.

+   3. Finish. YaST modifies your system's configuration files to use NIS and exits after those modifications have been made.
