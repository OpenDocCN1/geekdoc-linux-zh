# Managing Groups and Folders

If you want to organize your users into groups or want to create shared mail for certain users, you can do this through the web interface.

# Creating a Group of Users

Select the Groups/Folders section, and then the Create Groups subsection (Figure 30-22).

![](bbox=[0.177, 0.423, 0.826, 0.792])

As shown, you will be presented with the now familiar filter for all of your users. To create a group, enter the group name and a description for the group. Using the filter, select the users you want to be contained in the group and click the Confirm button.
