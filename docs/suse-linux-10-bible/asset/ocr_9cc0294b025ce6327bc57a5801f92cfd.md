For example, if you wanted to route all mail for the domain editors.wiley.com to the machine editorsmail.wiley.com, you need to specify the smtp host for the domain.

editors.wiley.com smtp:editorsmail.wiley.com

So, if a mail debrased.wiley.com arrives at the mail server, it will be sent automatically over SMTP to the machine editorsmail.wiley.com.

# sender_canonical_maps

This shows the location of rewrite mail maps for send. If you want to specify a canonical map to rewrite only outgoing mail addresses, then a sender_canonical_maps entry exists in the file main.cf. If you want to rewrite incoming addresses (as an alias map does), then you need to specify a recipient_canonical_maps entry.

# masquerade_exceptions

This shows address masquerading exceptions. We discuss this later in the “Presentation to the Outside World” section of the chapter.

# masquerade_classes

This lists what to masquerade.

# myhostname

This is the name of the server Postfix is running on. Postfix checks the host name of the system at startup, this command enables you to fix Postfix to think it is running on another machine. We discuss where the host name parameter fits into Postfix in the “Configuring an Always-On-Server” section of the chapter.

# program_directory

This is the location of Postfix server helpers.

# inet_interfaces

This shows the network interfaces Postfix listens on for incoming SMTP connections. This helps to limit where mail can be received from a multi-interface server.

# masquerade_domains

These are the domains to masquerade. We discuss this in the “Presentation to the Outside World” section later in the chapter.

# mydestination

These are the domains for which this mail server accepts mail. This is discussed in the “Creating Virtual Domains” section later in the chapter.
