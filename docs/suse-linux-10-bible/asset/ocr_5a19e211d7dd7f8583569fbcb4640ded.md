# YaST

YaST's partitioning module has the ability to create and delete partitions. It can also resize (non-destructively) create types of partitions, including Windows partitions, which is a feature in great demand for dual-boot installations on Windows-only machines. YaST uses parted to do this but provides a user-friendly interface. Although the procedure is very reliable, we recommend that you back up all the data on the partition you want to resize before this. If, for the power suddenly failed during the resizing process, it's possible that the result would be a completely corrupted partition.

YaST's partitioning tool can be accessed from the main menu, or by typing (root) the command yast2 disk (for a graphical interface) or yast disk for a text interface.

You cannot make changes to any partition that is mounted.

In YaST's partitioning module, you can select a partition by clicking it. You can then choose to delete, edit, or resize the partition. These options have the same functionality as the corresponding options available through the expert partitioning option during installation:

+   * **Delete** — asks for confirmation. In fact, none of the changes that you make in this module are carried out until you click the Apply button in the main screen, so you can still alter if you have made a mistake.

+   * **Edit** — Enables you to choose how to format the partition, and if so, which type of filesystem to create in it. It also gives you the option of setting the mount point for the partition and setting the mount options that need to be written to the /etc/fstab file.

+   * **Resize** — Offers a graphical resizing tool with a slider and a display showing how much space the partition will take up after the operation and how much free space there will be.

The Expert Tools in the YaST System Repair mode discussed earlier in this chapter is YaST's partitioning tool. This means that you can use the YaST partitioning tool from "outside" with no partitions mounted.

# Using parted

It is useful to use parted from the command line when you need to change partitioning from the SUSE Rescue System. You might need to do this because you want to reclaim disk space from a partition that has empty space on it, but that has to be mounted in the running system (as / or /usr, for example).
