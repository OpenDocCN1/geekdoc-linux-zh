# 258 Part II The SUSE System

You are offered three choices for how you want to make the installation source across the network: you can make it available by HTTP, FTP, or NFS. In the module itself these are mutually exclusive choices, but there is no reason why you could not offer the sources by more than one of these protocols. However, there would be extra manual setup required to do so.

The choice of which protocol to use depends on your circumstances. If the installation server is not on the same network as the clients that are to be installed, then HTTP or FTP (which can be accessed through a proxy) is the likely choice. If the installation server is on the same network and directly accessible by the clients, then NFS is probably the right answer.

In 9-35, we have chosen NFS, and we have selected a location where the installation set is to be created (/insterver/10.0/).

You are asked for a name for the installation source (a server may be advertised than one source

You can either use the installation CDs or DVD to create the installation source, or, if you have ISO images, YaST can create it from those. Service Packs can also be integrated into the installation source if they exist.

The same screen offers the option Announcement as Installation Server with SLP. When you select this option, the installation server will use SLP to announce itself on the network, making the installation process simpler for the clients as described previously.

You will be prompted for the installation media (CDs or DVDs, or if you to use ISO images, you will be prompted for the path to find those images on the hard disk). You will be prompted to change the media until the installation source has been completed. The necessary NFS, FTP, or HTTP server will be set up or modified automatically for you, and will be started automatically.

When the process is complete, if you go to a Konqueror window on the local machine or over the network and type the location slp://, you will see a window similar to the one in Figure 9-36.

This window provides a description of the SLP source being offered. It is, of course, possible that you might have more than one SUSE installation source advertising itself by the network.
