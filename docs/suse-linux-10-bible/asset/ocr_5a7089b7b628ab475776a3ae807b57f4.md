```
#! /bin/bash
case $1 in
happy)
echo "What a nice day it is today"
;;
sad)
echo "What a gloomy day it is today"
;;
esac
```

The script is deciding what it will output on the basis of the value of a variable (in this case the argument that was given). Such conditional branching is a key feature of any kind of programming.

```
user@:~ > ./case.sh happy
What a nice day it is today

user@:~ > ./case.sh sad
What a gloomy day it is today

user@:~ > ./case.sh mad
user@:~ >
```

Notice that the alternative tests are followed by a right-hand parenthesis, and the conditional block as a whole is terminated by a double semicolon. The whole set of conditions is closed by esac.

# Mailing from a Script

You may want to be informed of the progress or success of a script. One way to achieve this is using the `mail` command in the script. It will look something like

```
echo "many happy returns" | mail -s "Happy Birthday" user@otherdomain.net
```

This sends an email with the subject Happy Birthday and the content "many happy returns" to the address given. The message body could have been obtained from a file on the system. Of course it's more likely that the kind of message sent is something like "Backup complete," but there are almost certainly system administrators who use a `cron` job and a mail script to avoid the risk of forgetting their spouse's birthdays!

A more sophisticated way of using a block of text within a script is the so-called here-document. Within a script, the symbol `<<` together with a string defines the end of the block used to define the block of text that is to be redirected to a command. Very often the string EOF is used as the *limit string*.
