# Creating ISO CD and DVD Images

Data CDs and DVDs almost always use the ISO filesystem (so called after the international standard that defines it). These are therefore referred to as ISO images. You could also create CD or DVD images, CDs, and DVDs using standard Linux filesystems (ext2, for example), but these will not be useful for exchanging data with users of other operating systems.

It is not essential to use the ISO 9660 filesystem when you create images to burn to CD; you can create a sizable EXT2 loopback filesystem and simply copy the files you want to then burn it (if you use k3, it will detect that the image is not an ISO image, but you can force it to burn the image by detecting it). But you won't be able to read (easily) the resulting CD on a non-Linux system. You may also have to mount it manually on Linux (with a command such as mount /dev/hdc /mnt) because mount on current versions of SUSE will expect an ISO 9660 filesystem.

A quick way to save or back a moderate amount of data is to create an ISO image containing data and burn it to a CD or DVD.

The tool for creating ISO images is mkisofs. The main page for mkisofs is bewildering to say the least because there is a very large number of options. For most purposes, the recipe we discuss will do exactly what you want.

Suppose you have a directory under your home directory. You want to create a CD containing this directory's contents, and you know that the total amount of data is not too big to fit on a CD.

```
user@bible:-> mkisofs -J -o work.iso work/
```

This makes a filesystem of type ISO 9660 and copies the contents of the directory work into it. This is very similar to the way that you want to create a filesystem earlier in the chapter and mounted it and wrote to it. The difference is that mkisofs both creates the special ISO 9660 filesystem and writes the data to it in one action.

The options -J and -r indicate that the ISO file has Joliet and Rock Ridge extensions (this should mean that the resulting CD works on Windows, Mac OS, and Linux systems). The -o indicates the name of the output file.
