# Chapter 29 ✦ The Kernel 733

You should see a brand-new file bImage with a timestamp showing that it has just been created.

When you've made the bImage, you have several more steps to perform:

+   1. Build the modules:

```
root@bz:~/usr/src/linux-2.6.5-79/ # make modules
```

Note if you simply issue the command make or make all, the bImage and the modules will be built in one step.

+   2. Install the kernel and the modules:

```
root@bz:~/usr/src/linux-2.6.5-79/ # make install
```

This copies the bImage file to the /boot directory. (Before you do this you may want to back up the old kernel, particularly if it has the same version number.)

```
root@bz:~/usr/src/linux-2.6.5-79/ # make modules_install
```

+   3. Create a new initramdisk to correspond to the new kernel:

```
root@bz:~/usr/src/linux-2.6.5-79/ # mkinitrd
```

+   4. Check that both old and new kernels are referenced in the GRUB menu so that you can go back to the old kernel if you need to. Edit the file /boot/grub/menu.1 to confirm this.

If you use LILO for booting, you need to edit /etc/lilo.conf to ensure that both the new and old kernels are included and run the lilo command.

If you have compiled things into the kernel that were previously being loaded as modules, it is important that these modules themselves should not be loaded when the new kernel is booted; otherwise, unexpected problems could occur. You may need to adjust /etc/modprobe.conf in this case.
