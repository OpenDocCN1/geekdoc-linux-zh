# Novell Storage Services

Novell Storage Services (NSS) is Novell's proprietary storage system. It includes its own file system which is implemented through a kernel module with names beginning nss and the ability to manage storage volumes arranged into pools. NSS manages the low-level storage of files on disk, while the files are offered to the clients by NCP and Samba in the next two chapters.

# Novell NCP server

NCP is the NetWare Core Protocol. OES offers user access across the network by both NCP (the traditional NetWare protocol) and by Samba. Client machines with the NetWare client use the NCP protocol to access their files. Currently there is no implementation of the NCP for Linux.
