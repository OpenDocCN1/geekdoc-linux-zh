# XML Files

XML is self-describing data in the form of tagged text. XML file looks rather like an HTML file if you open it in an editor. The difference is that XML allows arbitrary tags, but any given XML file will follow a DTD (Document Type Definition) or an XML Schema, which describes the tags it may include and which elements may contain other elements. XML is growing in importance because of its use as a format for the exchange of information in e-commerce applications, and because of its usefulness as a base format to generate multiple versions of the same document (print, web, plain text, and so on).

As with HTML, if you need to make major edits to XML files, the best way is to use emacs with the appropriate mode (see Figure 13-4). You will need to have the psxml package installed for this. The emacs editor will then be able to validate the XML document, load a DTD, offer only the tags that are available at the current point in the document, close the open tag with a single keystroke, and much more.

# The OpenOffice Native Formats

OpenOffice native formats are zipped archives that contain a variety of XML documents, as in the following example:

```
user@bibtex:--> zipinfo file.zip
Archive: file.zip  9043 bytes
-rw-r--r--  1 user-root     37247 23-Jun 04 content.xml
-rw-r--r--  1 user-root     11683 23-Jun 04 layout.xml
-rw-r--r--  1 user-root     10336 23-Jun 04 content.xml
-rw-r--r--  1 user-root     17791 23-Jun 04 styles.xml
-rw-r--r--  1 user-root      8560 23-Jun 04 media.xml
-rw-r--r--  1 user-root      8261 23-Jun 04 META-INF/manifest.xml
7 files, 77.8%
```

XML is a structured markup language, which means that all OpenOffice documents are ultimately text documents, unlike the binary formats which are specific to a certain package.

XML was designed as a portable document description that separates information about the content of a document from the information about how the document is formatted. XML documents surround portions of the text with tags (more properly known as elements) identify the way in which the associated text fits into the entire document. Tags identify portions of your document such as paragraphs, headings, emphasis, quotations, lists and so on. Writing and storing in XML makes them usable by any software that understands XML and therefore makes them more portable.

OpenDocument standard has been adopted as a draft standard by OASIS (Organization for Structured Information Standards). For the complete OASIS OpenDocument standard, go to www.oasis-open.org/committees/download.php/12572/OpenDocument-v1.0-os.sxw. This is a version of the standard in OpenOffice format. A PDF version is also available at www.oasis-open.org/committees/download.php/12572/OpenDocument-v1.0-os.pdf.

# Compressing Files

Two compression programs are in common use on Linux, gzip and bzip2; gzip is more common, in general, bzip2 leads to somewhat smaller file sizes. To compress a file using gzip, do this:

```
user@bible:--temp gzip awhile
user@bible:--temp ls
afile.gz
```

The file awhile has been compressed to the file file.gz. To restore the original file you can use the gunzip command (or the equivalent gzip -d).

```
user@bible:--temp gunzip file.gz
user@bible:--temp ls
afile
```
