If you want to create multiple partitions the installation process, you can do this by making sure that the root partition does not completely fill your disk and then creating partitions in the remaining space of your disk. Common parts of a Linux system that you want to put on separate data partitions are /boot, /home, /opt, /tmp, /var, and /usr/local. For more information on these partitions and the types of information stored there, see Chapter 3.

# Selecting Software for Installation

The software that is automatically selected as part of a default SUSE installation provides you with nearly every type of software required for day-to-day work. This section offers additional details about the other types of installations provided by the SUSE installer to provide a full and through SUSE learning experience.
