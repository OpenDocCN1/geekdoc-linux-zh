# Reviewing the Release Notes

When SUSE has finished its initial installation, you will be shown SUSE release notes (see Figure 1-29). These notes contain general information about changes from previous versions of SUSE Linux, as well as a technical overview of the previous version. This file also provides errata from the SUSE manual and is worth a read to get a general idea of what has happened since the last release. Ninety percent of users at this point have not touched the included manuals by SUSE, except perhaps to move them out of the way when locating the installation media, so this at least gives you an introduction to the features and functionality of the product.
