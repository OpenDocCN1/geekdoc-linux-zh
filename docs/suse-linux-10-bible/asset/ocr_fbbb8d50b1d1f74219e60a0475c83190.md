# ps2ascii

The ps2ascii command tries to extract the full text from a PostScript (or PDF) file. In general this works quite well, but there may be problems in output spaces where newlines were, and (depending on how the PostScript file was created) there may be some unrecognized characters. For example:

```
user@ascii:- ~ ps2ascii filename.ps
```

will write to standard output,

```
user@ascii:- ~ ps2ascii filename.ps outfile.txt
```

will write the output to a file.

# ps2pdf

If you want to convert PostScript files to the PDF format so that people use Windows can easily see them, ps2pdf file.ps is all you need. The command creates the PDF version with the name file.pdf.

# dvi2tty

DVI (device independent) files are produced by the TeX and LaTeX typesetting system (explained in the next section) that then can be printed using a suitable driver to an output device. Most typically on Linux they can be converted to PostScript using the command dvips and then printed directly. DVI files can be viewed directly using a program such as kdvi.
