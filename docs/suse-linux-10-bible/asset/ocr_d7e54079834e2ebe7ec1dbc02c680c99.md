# # Command Line 101: The Shell

Commands issued on the command line on any computer system are read and executed by a program known as a command interpreter. A command interpreter does the following:

+   * Reads the commands and any options that you provide
* Translates or expands any special characters such as the * and ? used as wildcard characters on Linux and Unix systems (more about these in the next section)
* Locates the command that you want to execute on your system
* Executes command with the appropriate options and arguments and displays any output of that command

On Linux and Unix systems, a command interpreter is known as a shell. Linux and Unix systems offer many different shells, each of which has its own special features and devotees.

There are several shells included in the SUSE system, including ash, csh, ksh, tch, and zsh. They all have their advantages and disadvantages, and some users have strong preferences for one shell over another. bash has become the effective standard on Linux, and from now on all the examples in the book will assume that you are using the bash shell.

> Tip: Linux systems, the list of "legal" shells is maintained in the file /etc/shells. The contents of this file list the shells that can be started when you log in on the system.

In addition to being able to execute standard Linux commands for you, each of these shells supports its own command language. Files written in the command language provided by a shell are known as shell scripts. The first line of a script typically identifies the shell that should be used to run the command script. If no shell is identified in the first line, a shell script is executed by the sh shell, which is usually the same as the bash shell on Linux systems.

# ## Commonly Used Shell Features

By default, when you use the command line on a SUSE system, you are using the bash shell. If you have not used bash or a similar shell in the past, particularly if you have bad memories of the DOS command line, you may not realize how powerful the command line can be. Experience shows that people who come to Linux from a Windows background tend to start trying to use graphical tools (for example, copying files by dragging from one Konqueror window to another) but gradually realize the command line is both a quicker and easier way to perform many tasks.
