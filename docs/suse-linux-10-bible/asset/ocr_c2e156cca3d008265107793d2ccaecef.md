# Accessing Windows Partitions from Linux

Linux has provided support for FAT and FAT32 (another name for the VFAT-system) filesystems existed for some time. Support for NTFS filesystems existed for the 2.4.x series of Linux kernels has been directly integrated into the 2.6 series of Linux kernels (such as those used on SUSE 9.1 and greater).

Reading NTFS filesystems from the 2.6 kernel works fine, but writing to them is still experimental and should be done with caution.

To mount a Windows partition under Linux, use the mount command discussed in Chapter 3. The directory /mnt/c is a sample command to mount a VFAT partition on the Linux (which must be created before attempting to mount the drive):

```
mount -t vfat /dev/hd1 /mnt/c
```

If you are mounting an NTFS partition and do not need to write to it, you can use a command such as the following to mount it in read-only mode:

```
mount -t ntfs -o ro /dev/hd1 /mnt/c
```

# Accessing Linux Partitions from Windows

Accessing Linux partitions from Windows is trickier than the reverse because Windows does not provide built-in support for any of the partitions used by Linux. However, a number of utilities and drivers are available for Windows systems that enable you to mount and access EXT2 or EXT3 filesystems under Windows. These range from commercial products to public domain and open source utilities:

+   **Explore2fs** (http://uranus.it.swin.edu.au/-jn/linux/explore2fs.htm) — EXT2 filesystem access from Windows 9X, 2000, XP, and ME.

+   **EXT2 IFS** (http://uranus.it.swin.edu.au/-jn/linux/ext2ifs.htm) — Installe filesystem driver for EXT2 under Windows NT, 2000, and XP

+   **Ext2fsnt** (http://ashedled.chat.ru/ext2fsnt/) — EXT2 access to Windows NT. This driving code has been incorporated in Paragon Software's Mount Utility.

+   **FSDEXT2** (http://www.ipton.domain.co.uk/content.html#FSDEXT2) — Mounts EXT2 partitions on Windows 95, although read-only. (No longer under active development, then neither is Windows 9.5.)
