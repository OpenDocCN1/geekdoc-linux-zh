# Setting Up an NIS Server Manually

This section explains how to set up an NIS server from the command line. YaST removes the need to do this, and you don't need to follow the instructions in this section if you set up an NIS server using YaST. However, it's still convenient to know exactly what changes are made under the hood or in order to set up an NIS server. An NIS server that is configured using the instructions in this section exports the default password, group, host, and on maps (files) found on the NIS server system. In a production environment, you would want to substantially more customization before initiating NIS throughout your computing environment. You would also want to configure the NIS configuration files `/var/yp/securenets`, `/etc/yp.conf`, and `/etc/ypmap.conf`.

To set up an NIS server, log in or use the su command to become root on the system you will be configuring as and do the following:

+   1. Make sure that the NIS software is installed on your Linux system. At a minimum, you will need the `/bin/domainname`, `/usr/sbin/ypserv`, and `/usr/lib/yp/ypinit` programs.
