# 592 Part IV ♦ Implementing Network Services in SUSE Linux

If you want information about what is actually mounted from bible, use
t -a option:

```
user@client: ~ showmount -a bible
All mount points on bible:
client::test
```

This shows that the directory /test bible is currently mounted by client.

```
showmount -d bible shows the directories for being mounted:

user@client: ~ showmount -d bible
Directories on bible:
/Test
```

![](bbox=[0.125, 0.357, 0.203, 0.396])

> > Caution
nThe information given by showmount can sometimes include state information
abold mounts that are no longer present. This can happen, if you a
client reboots without unmounting the NFS mount. To correct this situation,
if, can necessarily, remove the file /var/lib/nfs/rmtab -r the server and restart
the NFS server.

# Problems with Mounting NFS Shares

If you find that you cannot mount a share that you think should, the first thing
to check is whether the NFS server is actually running. Check the /etc/exports file
to server carre, and be sure that you have done exports -r or rcnfs
server reload since making any changes to it. The command rpcinfo can be useful;
if all is well, its output should look like this:

