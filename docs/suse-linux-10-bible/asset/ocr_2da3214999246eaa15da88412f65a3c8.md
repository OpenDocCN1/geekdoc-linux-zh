In that case, you boot from the installation medium and choose Rescue System from the boot menu. You can then log in as root (without a password) to a Linux system running in memory. None of the partitions we mentioned parted offers you a prompt like this: (parted). To get help, use help or ?. In the example that follows, we list (print) the partitions on /dev/ and then resize the second partition. The parted commanded resize 2 6677 8000 moves the end of the second partition from its current position at 8007 to 8000, while leaving the start of the partition unchanged.

# parted /dev/hdc

(parted) print
Disk geometry for /dev/hdc: 0.000-14324.625 megabytes
Disk label: parted

| Minor | Start | End | Type Filesystem Flags |
|---|---|---|---|---|-|
| 1 | 0.016 | 4042.0 | primary | fat32 | lba, type=0c |
| 2 | 6677.0 | 8307.0 | primary | ext2 | type=83 |
| 3 | 8307.0 | 14324.0 | primary | reiserfs | type=83 |

(parted) resize 2 6677 8000
