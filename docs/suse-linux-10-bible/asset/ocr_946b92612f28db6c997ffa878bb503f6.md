# Chapter 2 ♦ Linux Fundamentals 65

Permission to write to a file includes the right to overwrite or delete it.

So for example:

```
ls -l screenshot1.png
-rw-r--r-- 1 root users 432686 2004-05-17 20:33 screenshot1.png
```

This file can be read and written by its owner (roger), can be read by members of the group users, and can be read by others.

```
ls -l /home/roger/afile
-r--r--r-- 1 users 0 2004-05-17 21:07 afile
```

This file is not executable and writable, and can be read only by owner (roger). Even roger would have to change the permissions on this file to be able to write it.

```
ls -l /etc/passwd
-rw-r--r-- 1 root 1598 2004-05-17 19:36 /etc/passwd
```

This is the shadow file—it is owned by root (and the group to which root belongs), is readable by anyone, but is group writable by root.

```
ls -l /etc/shadow
-rw-r--r-- 1 root 796 2004-05-17 19:36 /etc/shadow
```

This is the shadow file, which holds the encrypted passwords for users. It can be read by root and the system group shadow and can be written by root.

```
ls -l /usr/sbin/traceroute
-rwxr-xr-x 1 root 14228 2004-04-06 02:27 /usr/sbin/traceroute
```

This is an executable file that can be executed by anyone, but written by root.

```
ls -ld /home
drwxr-xr-x 6 root root 4096 2004-05-17 19:36 /home
```

This is a directory (note the use of the -d flag to the command and the d in the first position in the permissions). It can be read and written by the root user, and read and executed by everyone. When used in directory permissions, the x (executable) translates into the ability to search or examine the directory—you cannot execute a directory.

```
ls -ld /root
drwxr------- 18 root root 584 2004-05-14 08:29 /root
```
