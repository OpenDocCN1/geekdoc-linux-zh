In this example, host has queried the nameserver that is authoritative for the palmcoder.net domain and has found that the host name www.palmcoder.net is actu-a CNAME for zen.palmcoder.net with an address of 212.13.208.115.

If you want to find a specific DNS record for a domain, you use the -t option, specifying the record type:

```
bile:~ # host -t mx palmcoder.net
palcoder.net mail is handled by 10 mail.palmcoder.net
palcoder.net mail is handled by 20 pirhana.bymark.co.uk.
```

Here, host has queried the nameserver that is authoritative for palmcoder.net, ask-ing for the MX record for the domain. It has found that there are two mailchang-ers and pirhana.bymark.co.uk, with mail.palmcoder.net taking precedence over pirhana.bymark.co.uk.

# Examining Record Types

Before we delve into creating a zone (an administrative domain) in DNS, we need to talk about record types. We briefly touched upon the fact that DNS provides not only host-to-IP address translation, but also mail server information.

A record type tells what kind of information it is storing. This record type is something you can explicitly query. For example, you query the MX record for a domain to find out which mail server to use when sending a recipient in the domain mail. Services that rely on DNS for specific hosts drastically reduces the amount of traffic that is produced because you only see the data you explicitly asked for, not the whole record. What makes this happen is the use of record types. With DNS, you have six main record types to keep in mind:

+   ✦ The Address record — The most common record in DNS is the Address record. An address record is used to translate a host name to an IP address.

+   ✦ The Pointer record — A Pointer record is the reverse of an Address record. It translates an IP address to a host name.

+   ✦ The CNAME record — If you want to create an alias of one host to another, a CNAME record is used.

+   ✦ The MX record — An MX record is used to define a Mail Exchanger for the domain (or zone) you have created.

+   ✦ The NS record — The NS record is used to define the nameserver for the domain.

+   ✦ The SOA record — The Start of Authority (SOA) is effectively the header for the zone in question. It contains information about the zone itself and is mandatory.
