+   3. Set the domain name of your new NIS domain. This should not be the same as the name of your TCP/IP domain, to avoid confusing DNS and potentially compromising security in your domain. To set the NIS domain name (in this case of the domain foo.com), issue a command like the following:

```
/bin/domainname foo.com
```

This NIS name is saved in the file /etc/defaultdomain.

+   4. Start the NIS server process using a command like the following:

```
/usr/sbin/ypserv
```

+   5. Initialize the NIS databases using a command like the following:

```
/usr/lib/yp/ypinit -m
```

You will output like the following:

