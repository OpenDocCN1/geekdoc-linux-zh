# Chapter 10 ♦ Text Manipulation 289

```
user@bible:- > cat file|tr a-z A-Z
RED ELEPHANT, RED WINE
BLUE MANGO
RED ALBATROSS
```

However, for this example, it is probably better to do the following:

```
user@bible:- > cat file | tr [:lower:] [[:upper:]
```

This has the same effect as the previous example, but does the right if we include accented characters in our file. For example:

```
user@bible:- > echo ‘léphant’ | tr a-z A-Z
ÉLEPHANT
```

```
user@bible:- > echo ‘léphant’ | tr [:lower:] [[:upper:]
ÉLEPHANT
```

Exactly how the order of characters in the preceding examples is interpreted may depend on the locale, or in other words language settings in the current environment.

```
user@bible:- > cat file|tr a-z mnghijklmnopqrstuvwxyzabcdefghijkljk
dqp quofmt ymza
nxqq ymzq
dqp kmnmfdaee
```

Here, the tr command performs the simple rot13 cipher on the lowercase letters - each letter is moved 13 places in the alphabet. Repeating the command restores the original text.

With the option -d, tr simply removes the characters that are listed:

```
user@bible:- > cat file |tr -d abcde
r lphnt, r win
lu mango
r ltross
```

With the option -s, tr removes repeats of the characters that are listed:

```
user@bible:- > cat repeats
aaaabcd
abbbcd
abcccd
abcddd
```

```
user@bible:- > cat repeats|tr -s ab
```
