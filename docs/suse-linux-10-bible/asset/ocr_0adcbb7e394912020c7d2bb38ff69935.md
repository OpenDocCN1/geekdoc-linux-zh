One feature of the SUSE user creation process is that you can set yourself as the user who receives any mail destined for root by selecting the Receive System Mail option. Regardless of whether you set up this option, it is always a good idea to read root user mail (if you are the user of the root user account!) to see any automated mails that the system sends as well as mails from the mail subsystem includes bounced emails, system errors, and package updates that have been installed.

Taking another page from Mac OS X and Windows XP, SUSE enables you to set up an account to automatically log in to the system for you when the machine boots up. For home users, this provides a simpler way to use your system, but it is impractical and insecure in business environments. For example, if you are the user who is automatically logged in on boot up, someone else can gain access to your files by turning the machine on.

When you have finished adding your user information, click Next to continue, and SuSEConfig will run.

# SuSEConfig

The SUSE system configuration is controlled by SUSE-specific control files that the system application SuSEConfig uses to write application-specific configuration files.
