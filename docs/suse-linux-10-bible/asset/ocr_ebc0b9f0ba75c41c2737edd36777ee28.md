# Finding Software

Some key we should be among your first places to look if if you are looking for open source software:

+   * freshmeat.net—The FreshMeat web site and associated mailing list provide information about recently updated software packages and projects.

+   * packman.links2linux.org—A Great German site that is nearly organized into logical groups of packages (development, finance, games, and so on).

+   * rpmfind.net—A Great site for locating and downloading packages in RPM format for almost any Linux package.

+   * sourceforge.net—SourceForge is the home for thousands of Linux software projects, providing a collaborative environment and disk space to the open source community.

# IBM

IBM provides extremely useful Linux materials, including tutorials and in-depth technical articles, so-called IBM Redbooks, training materials for the Linux Professional Institute exams, and much more.

Good starting points in looking for this information are:

+   * www-1.ibm.com/linux/

+   * www-1.ibm.com/linux/whitepapers/

+   * www-136.ibm.com/developerworks/linux/

+   * http://pub-b.boulder.ibm.com/redbooks.nsf/portals/LinuxRedbooks
