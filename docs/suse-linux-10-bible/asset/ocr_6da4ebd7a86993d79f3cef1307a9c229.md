Setting up your routing is a very important part of your work with the network. Just
as without the proper routing, the Internet would never work, your network needs
to have the correct routing in place to function properly. The tool to help you do
this is route.

# routed

We have talked throughout this chapter about routing tables and how to add
them. Another type of routing is called dynamic routing. Manually adding routes
to your servers if you have many routers across your organization can be quite
cumbbersome and a laborious task. With this in mind, dynamic routing presents
its routing table across the network to any routers that understand the Routing
Information Protocol (RIP). Routing tables are routinely interchanged with RIP,
keeping tables on all RIP-aware routers updated about around your
network.

SUSE includes the simple routed service that reads your routing table, routinely
presents it to the network, and accepts routing information over RIP from other
routers. This will drastically reduce your routing maintenance times as all network
and hosts are updated automatically for.

To use RIP, you must install the routed package using YaST and start the service
with routed start.

Once started, routed sends out routing updates and also makes changes to
your routing table when it receives updates from the network.

# Using iproute

In the future, it is very likely that ifconfig and route will be phased out and
replaced by the powerful iproute suite of programs. The iproute enables you to
have much more granular control over your network configuration, but with a
volved process of configuring your network configuration that may be a
hindrance to users new to the world of Linux.

We will show you how to configure your network card and routing with the iproute
suite as well as to view detailed information about your network.

The iproute's main command is ip. This command is to set options for
your network card, network configuration, and routing information. For each part of
the network you want to configure, ip takes an object to work on. The objects you
are concerned with are link (the network interface), addr (network configuration),
and route (routing information).
