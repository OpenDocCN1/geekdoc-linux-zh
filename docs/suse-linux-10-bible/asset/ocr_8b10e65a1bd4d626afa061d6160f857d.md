By default, the block size of the EXT2 filesystem is 1 kibobyte, with a total of 49,152
inodes. The number of available inodes for the filesystem is dictated by the\mspace on the partition and the block size of the device. If you are making an EXT2
filesystem with default settings, as we do, bear in mind that the number of inodes
available on the filesystem dictates the number of files that can be created. Once
you have created an EXT2 filesystem, you have no way to extend the number of
inodes on that filesystem.

> For a complete list of the options that are available when creating an EXT2 filesystem, see the online manual for the mkfs.ext2 or mke2fs utilities, available
by typing mkfs.ext2 from a Linux command.

# Creating an EXT3 Filesystem

As mentioned in of the "Creating Filesystems" section, the same utility is
used under the covers to create both EXT2 and EXT3 filesystems: it is simply
invoked by the mkfs wrapper command. Therefore, the same options are
available when creating an EXT3 filesystem.

The easiest way to create an EXT3 filesystem is to use the mkfs wrapper,
specifying ext3 as the type of filesystem you want to create. Listing 3-7 shows the
output of the mkfs command when creating an EXT3 filesystem with default settings.
Note that the output of this command is exactly the same as shown when creating
an EXT2 filesystem in the previous section, with the exception of the following line:

```
Creating journal (8192 blocks): done
```
