# A Bit of Background

The SUSE Linux kernel features built-in connectivity with networked Windows resources by supporting the Windows Server Message Block (SMB) protocol that underlies most native Windows networking mechanisms. The SMB protocol is now considered a part of Microsoft's more general Internet File Services (CIFS), but its name lies on the Samba software suite.

Acronyms reign supreme in the network world, most of which are related to history of various standards and protocols. This is especially true for the long list of network protocols used by DOS and Windows. When Microsoft decided network support was a goal, it began introducing the NetBIOS (Network Basic Input/Output System) in 1984 to define and control the characteristics of network communication from a DOS or Windows system. To implement this transport, Microsoft provided the NetBEUI (NetBIOS Extended User Interface) protocol. NetBEUI worked fine on small networks of the day but was missing basic features, such as routing, that were required as networks became larger and distinction between connected became increasingly important. From 1985 through 1988, Microsoft worked with IBM and introduced to popularize SMB, which is a NetBIOS implementation that runs over TCP/IP networks. If you are collecting acronyms, SMB is the most common example of what is generally known as NBT (NetBIOS over TCP/IP), also known as NetBT.

As discussed in Chapter 6, TCP/IP has been the networking protocol associated with Linux and Unix systems. Samba was originally developed by Andrew Tridge (“tidal”), who initially began development of what would later become Samba on DEC and Sun workstations in 1991. He began work on port Samba (then known as NetBIOS for Linux or smserver) in 1992. J.R. Coullin and Dave Fenwick introduced an SMB-related newsgroup, comp.protocols.smb, as a forum for discussing Samba development; server renamed Samba in 1994 because of conflicts with the name of an existing product, and the rest is history.

Today, Samba is used on Linux, FreeBSD, FreeBSD, Solaris, AIX, HP-UX, and any Unix and Linux-like system that you can use. Similarly, most of the NAS (Attached Storage) systems that you can purchase today NFS (the Network File System, discussed in Chapter 22) thanks to Sun's early release of the NFS specification and Windows networking courtesy of Samba.
