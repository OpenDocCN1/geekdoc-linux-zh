# awk

awk is something rather bigger than the tools we have been discussing up to now; it is an entire language. awk is an interpreted scripting language; in other words, programs in awk do not need to be compiled before they are run. We shall present a few simple uses of awk just as a command like often in system shell scripts, and it is certainly well enough to know about its existence. But if you want to do the kinds of things awk does well (selecting and replacing text in text files according you program), you should consider whether the task could be done simply and easily by another and more powerful scripting language (such as Python or Perl). On the other hand, awk is a much smaller program and is always available:

```
users@bible:- > cat foods
boiled carrots
fried potatoes
gilled onions
grated carrot
```

```
users@bible:- > awk /carrot/ foods
boiled carrots
grated carrot
```

Each awk has selected the lines that match carrot:

```
users@bible:- > awk '{print $1}' foods
boiled
fried
grilled
grated
```

In this example, awk has printed the first field of each line, as defined by '^print $1'. Using $2 gives us the second field, while $0 represents the whole line.

You can also define the separator to be something else. In the example that follows, the option -F: specifies that the field separator is the colon, allowing you to select a particular field (the fifth, which is the user's real name) from /etc/passwd, which is a colon-separated file.
