# Python Version

To achieve what we want in Python, we will show the script:

```
#!/usr/bin/env python
from time import localtime, strftime
infile = open('access.log', 'r')
for line in infile.readlines():
    bits = line.split()
    if bits[2] == '192.168.2.4':
        strftime('%c', localtime(float(bits[0]))), bits[6]
```

Taking the script by line, we first specify that the interpreter is Python (so that the script can be made executable as the shell script example). We then import functions from the Python standard library module time, to enable the formatting of the date. We then create a file handle (infile) to read from the access.log. We loop over the lines of the file and split each line (according to white space) into a list (bits) of text strings. If the line third element matches the required IP address, we print the formatted time and the URL.
