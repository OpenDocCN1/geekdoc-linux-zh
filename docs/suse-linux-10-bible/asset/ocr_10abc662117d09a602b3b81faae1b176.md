# 356 Part III ◆ Using the Command Line in SUSE Linux

A PostScript file is a plain text file with a certain specific format. It always starts something like this:

```
%!PS-Adobe-3.0
%%Title: filename
```

Although raw PostScript looks old at first glance, it is not difficult to learn how to write simple PostScript files to create pages with geometrical shapes and text on, for example:

A PostScript file is typically called something like file.ps. An encapsulated PostScript file may have the extension .eps. To view it you can use any of the programs gv, ggv, or ghostview. All use ghostscript (gs) in the background to render the file in graphical form.

You can print a PostScript directly from the command line with:

```
usersample:~/tmp lpr.file
```

Because of its importance as a format, there are a number of utilities for processing PostScript files in various ways:

+   * ps2ascii tries to extract from a PostScript file.
* ps2pdf converts a PostScript file to PDF.
* The pscriptils package includes various utilities for splitting and joining PostScript files and for resizing pages.

Any application that enables you to print a file will produce PostScript. Some applications also offer a print to PDF option.

> Note: An encapsulated PostScript file (.eps) is a special type of PostScript file that includes information about its physical size (bounding box) and is designed to be included inside another document.

# PDF

PDF is related to PostScript and is also a fully documented format from Adobe. The application for opening PDF has to be Acrobat Reader, accroad, but there are also xpdf and gpdf. The ghostview application also happily opens PDF files. However, accroad best takes advantage of all the advanced features of PDF (hyperlinks, text search, fonts, and so on).

Again, a large number of utilities are available for dealing with PDF files, in particular pdfotext and pdf2ps, which try to do what their names imply.
