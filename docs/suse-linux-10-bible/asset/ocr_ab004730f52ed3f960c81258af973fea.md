# Checking the User Data

If you want to view any data about a user on the system

When you have found the user account, select it and click User Data. You will be presented with the details that you previously filled in for the user. If you want to be able to edit all information relating to a user, such as his or her birthday, title, and so on, click Long attribute list to get a screen like the one shown in Figure 30-17.
