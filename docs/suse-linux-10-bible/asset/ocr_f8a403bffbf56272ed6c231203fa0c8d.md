Either way, converting an EXT2 filesystem to EXT3 is a painless operation involving two steps: using the tune2fs command to add an EXT3 journal to each EXT2 filesystem that you want to upgrade and updating your system's filesystem table (/etc/fstab) to identify the upgraded partition(s) as EXT3 filesystems rather than EXT2 filesystems. The structure of the /etc/fstab file is explained later in this section "Mounting Filesystems Automatically." Upgrading an EXT2 filesystem to an EXT3 filesystem is a completely safe operation to perform on any existing EXT2 filesystem. The EXT3 filesystem was designed with this sort of upgrade in mind and is a truly immersive piece of work.

![](bbox=[0.126, 0.323, 0.173, 0.355])

As mentioned earlier, you should not upgrade EXT2 filesystems to EXT3 filesystems in certain circumstances, specifically if your EXT2 filesystem holds data files such as Oracle databases that have their own built-in journaling mechanism. Running two journaling mechanisms on the same file may cause data corruption or may cause your database to crash.

Listing 3-8 shows the output from the tune2fs command to upgrade an EXT2 filesystem to an EXT3 filesystem. When this command completes, simply bring the file /etc/fstab in your favorite text editor, search for the line related to that partition you upgraded, and change the value ext2 to ext3. After saving the file, you can reboot your system to take advantage of the journaling capabilities of your new EXT3 files.

As its output, the tune2fs command enables you to adjust many other parameters for EXT2 and EXT3 filesystems. As you become more familiar with Linux, the tune2fs command can help you fine-tune your EXT2 and EXT3 filesystems. See the online manual page for the tune2fs command for more information about other available options and what you might want to use.
