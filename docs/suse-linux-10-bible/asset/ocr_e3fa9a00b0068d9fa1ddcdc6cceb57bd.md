# File Managers

A file manager is a tool that enables you to look at the layout of the files and directories on your system and to perform various actions on the files (copy, move, delete, and so on). There are three particularly useful choices for a file manager: Konqueror, Nautilus, and m c. If you are using KDE, then by default you are likely to use Konqueror as your graphical file manager. If you are GNOME, the same applies to Nautilus. m c (the Midnight Commander) is a text-based file manager that has some very useful features.

# Konqueror as a File Manager

If you want to use Konqueror as a file manager, Konqueror's file manager is powerful. It has the advantage that you can show views of least some of the files as it lists them. (You can configure this behavior to extent in Konqueror's settings menu). When selecting files, remember KDE's one interface: People who use Windows will tend to left-click a file and then surprised when it opens in an application.

To use Konqueror as a file manager, the best plan is to use it with a split view (Windows< Split View Left/Right). When you drag a file from one pane to the other or move copy. When you are offered three options: Move here, Copy here, and Link here. If you hold the Shift key while you drag the file, a move will be forced. In general, it is best to choose the keystroke in advance; then you way remove the risk that your click will open the file.

A right-click inside a directory brings up a menu that includes the ability to create new directories or operations on the selected file such as Copy to Move Move.

Konqueror has recently added some functionality, including the ability to open a KDir window (displaying directory statistics: the sizes of files and subdirectories displayed graphically). You can also bring up a graphical tool that will string replacement on all files in a directory (KFileReplace).

As we have noted elsewhere, Konqueror displays files across the network and includes the ability to display files on a machine accessed by ssh as if they were local.
