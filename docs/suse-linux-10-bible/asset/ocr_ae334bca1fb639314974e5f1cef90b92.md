# sort

The sort command does what it says — it sorts the lines of a file. An alphabetical sort is the default, as you can see in the second code block that. In the third code block, you can see that the -r option has made the alphabetical sort into a reverse sort, sorting the files from z to a.

```
usable:-> cat animals
cobra
aardark
zebra
duck
elephant
```

```
usable:-> sort animals
aardark
cobra
duck
elephant
zebra
```

```
usable:-> sort -r animals
zebra
elephant
duck
cobra
aardark
```

There are many options: the most important are -n (sort numerically) and -u (for unique: skip duplicate lines).

# Extracting Lines from Files

In this section, we look at the slightly more difficult challenges of extracting exactly the lines or parts of lines that you want from a text file, based on certain criteria.

# grep

The grep command is the global regular expression printer. What means is that it cannot just search for a particular string in a file and output the lines where that string occurs, but search for text that follows a particular pattern and output the matching lines. For example, the pattern could be a single capital letter followed by two or more digits, a British postcode, a valid U.S. Social Security number, a line beginning with a number of spaces followed by a lowercase letter, or virtually anything that you can describe in similar terms.
