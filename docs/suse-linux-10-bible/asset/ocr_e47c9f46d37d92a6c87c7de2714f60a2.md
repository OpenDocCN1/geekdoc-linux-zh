# # Partitioning Examples

On the x86 architecture, there are limitations on the number of partitions a disk can contain: There can be at most four partitions, one of which can be an extended partition. The extended partition can contain multiple logical partitions (up to a maximum of 6 on an IDE disk or 12 on a SCSI disk).

When working with partitioning tools, you should always ensure that any partitions you are going to change are not mounted before you start. You should also be sure that you know what partitions exist on the system and what they contain (as we stressed before): Print a copy of the output of at least the commands `fdisk -l`, `mount`, and `df -h` on during the process. You can print any of these lists by redirecting the output of that command to the `pr` command by using a pipe symbol, as in `fdisk -l | pr`.
