# Embedded Systems

This may be something you overlook in your organization, Linux is already embedded in a lot of the systems within the enterprise.

While many people have questioned how secure Linux is and its security continues to be a matter of great speculation, Linux is nevertheless known for its stability and its security. In reality, the security of any operating system is dictated by two things:

+   * The configuration and administrative actions that take place secure the operating system out of the box
* The code of that encompasses the operating system itself

Linux is not the be-all and end-all of operating system security. However, given that the code is open and under constant security, it comes pretty close to it. Some patches to the Linux kernel drastically overhaul the default Unix/POSIX security of the operating system, of the most popular and secure being the Linux Intrusion Detection System (LIDS). The name is a misnomer, because it is not designed as a detection system, but to harden the kernel before recognition.

Because of this security, Linux has been used in many embedded systems and you may not even know about. Firewall appliances run Linux, and the fiber switches in IBM BladeCenter run on embedded Linux.

Running embedded Linux in an organization is not usually one of choice, but one of indirect choice when you buy a product for its feature set, not for the operating system that it runs. It is where embedded systems prove their worth in the marketplace, where the features of the appliance sell the product, and the operating system under the hood helps this with stability and provides the features that the user sees.
