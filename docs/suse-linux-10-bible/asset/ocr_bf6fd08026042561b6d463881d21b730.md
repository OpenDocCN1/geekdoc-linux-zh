# Examining RPM Packages

When you hear of an interesting piece of software that you would like to test out, your first reaction should be, “Is there a SUSE package?” Checking this first can save you a good deal of trouble.

Third-party packages that are distributed in RPM format may not work on SUSE for a variety of reasons. Whether they will or not depends on their complexity and what other packages depend on.

The command:

```
rpm -cpl foreignpackage.rpm
```

will list the files that foreignpackage.rpm will install. For example, SUSE does not offer an mpage package. If you examine the m package from the Fedora distribution in this way, the result is as follows:

```
rpm -cpl mpage-2.5.3-7.i386.rpm
warning: mpage-2.5.3-7.i386.rpm V3 Data signature: NOKEY, key ID 4f2a6fd2
/usr/bin/mpage
/usr/share/doc/mpage-2.5.3
/usr/share/doc/mpage-2.5.3/CHANGES
/usr/share/doc/mpage-2.5.3/Copyright
/usr/share/doc/mpage-2.5.3/NEWS
/usr/share/doc/mpage-2.5.3/README
/usr/share/doc/mpage-2.5.3/TODO
/usr/share/man/1/mpage.gz
/usr/share/mpage/
/usr/share/mpage/CP850.PC
/usr/share/mpage/ISO-STD+TH
/usr/share/mpage/ISO-8859.1
/usr/share/mpage/ISO-8859.15
/usr/share/mpage/ISO-Latin.1
/usr/share/mpage/ISO-Latin.2
```

Through this output you can see that this installation is not going to interfere with any existing files on the system, you can simply install the package with the command:

```
rpm -Uvh mpage-2.5.3-7.i386.rpm
```
