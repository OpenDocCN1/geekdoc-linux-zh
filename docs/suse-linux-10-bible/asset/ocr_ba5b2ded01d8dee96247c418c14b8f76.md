# dosbox

The dosbox package is similar to dosemu, although it is designed essentially for playing games. The web page at http://dosbox.sourceforge.net includes a long list of DOS games with comments on how they work under dosbox. dosbox can run both real-mode and protected-mode DOS games, and its graphics support is remarkably good. When dosbox starts, you are presented with a DOS prompt showing the drive letter Z:. dosbox contains an internal mount command, so you can type, for example:

```
Z:\> mount C /home/xcoger/DOSSPROG
```

Then you switch to drive C: under dosbox, you will be able to run the DOS programs that you have saved in that directory. In Figure 28-2, dosbox is seen running a graphical DOS, which fails under dosemu.
