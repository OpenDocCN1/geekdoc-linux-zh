## 响应文件安装

DB2 设置向导生成的响应文件用于在初始安装后安装其他组件或产品。它们包含在初始安装期间指定的所有安装和配置设置，这使您能够在多台机器上安装一致的配置。它还通过绕过 DB2 设置向导为您节省时间。
