# Set advanced options.

This page contains additional, more advanced, load options. When you select an option an explanation for that option is given in the Hint section. Select the options you require and change the values according to your needs.

| Parameter Description | Value | Changed | DB2 Parameter |
|---|---|---|---|

| Stop the load after a set number of warnings | default |  | WARNINGCOUNT |
| Performance |  |  |  |
| Degree of CPU parallelism | default |  | CPU_PARALLELISM |
| Degree of disk parallelism | default |  | DISK_PARALLELISM |

Hint

Stops the load operation after n warnings. Set this parameter if no warnings are expected, but verification that the correct file and table are being used is desired.
