The **Very Secure FTP server (vsFTP)** in an **FTP** server that allows for high-volume **FTP** access. The vsFTP service is simpler to configure than other **FTP** services and was designed with an emphasis on security. Because vsFTP is implemented, by default, to share `/var/ftp` directories to anonymous users and to allow **FTP** to access users with real login accounts on the **Linux** system, you can move from wu-FTP or other **FTP** servers without much difficulty.

# KDE 3.0

Like **GNOME**, **KDE** is a desktop environment available with Red Hat **Linux**. Many of the applications that with earlier versions of **KDE** have been split into separate software packages. This allows you to install individual applications, where previously each **KDE** application's software package (such as keduils, kdenetwork, or kdegraphics) would give you a dozen or more applications. The following applications were added for **KDE** 3.0:

+   - **kaboodle** — A **CD** player.
+   - **kamera** — An interface for accessing digital cameras using a file folder.
+   - **kapabilities** — A tool that enables system administrators to grant privileges to users to do administrative tasks.
+   - **knewsticker** — An applet for displaying news from Internet sites.
