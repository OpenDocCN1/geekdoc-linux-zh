Along with Red Hat Linux’s growing popularity, more commercial publishing applications have appeared for Linux. Anyware Office and StarOffice are two application suites that provide powerful publishing features in Linux. Red Hat Linux does include some free word processors, including AbiWord and KWord. Though AbiWord isn’t up to the best commercial word processors, it does have basic features and potential for the future.

To create and change graphics, Red Hat comes with applications like GIMP, xv, and KPaint.
