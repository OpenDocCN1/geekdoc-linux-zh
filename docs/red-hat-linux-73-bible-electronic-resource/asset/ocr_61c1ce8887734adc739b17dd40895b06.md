```
options_ide-cd_ignore=hdc
```

+   2.  In this example, the writable CD-ROM device is located at /dev/hdc. Replace hdc with the location of your CD device. If you are not sure, type `dmesg | grep ^hd` to see a list of IDE disks on your computer.

+   3.  Restart your computer.

+   4.  To add the ide-scsi module, type the following command:

```
# modprobe -a ide-scsi
```

+   5.  To make sure Linux can recognize your CD writer, type the following command:

```
# cdrecord -scanbus
Cdrecord 1.10 (1686-pc-linux-gnu) Copyright (C) 1995-2001
Jörg Schilling
Linux sg driver version: 3.1.22
Using libscg version 'schily-0.5'

scsibus0:
  0,0,0  0) 'IDE-CD' 'R/RW 4x4x24' '1.04' Removable CD-ROM
  0,1,0  1) 'SONY' 'CD-ROM CDU701' '1.0f' Removable CD-ROM
  0,2,0  2) *
  0,3,0  3) *
  0,4,0  4) *
  0,5,0  5) *
  0,6,0  6) *
  0,7,0  7) *
```

Here you can see that cdrecord has detected two CD drives on SCSI bus 0. A writable CD drive is at 0,0,0 and a read-only CD is located at 0,1,0. You need to remember these numbers later when you use cdrecord to create a CD. Until your CD burners show up on this list, cdrecord cannot write to them.

+   6.  After you have added your CD writer as a SCSI device, it may no longer be available to the CD players described in this chapter. By default, those players play the /dev/cdrom device, which in this case points to an IDE drive. To fix that, type the following as root user:

```
# cd /dev
# rm cdrom
# ln -s scd0 cdrom
```

+   7.  If you have two CD drives, repeat this step, replacing cdrom with cdrom1, and scd0 with scd1.
