```
Sections in the output from dig include a question section, an answer section, an authority section, and an additional section. The results show name-server assignments and addresses associated with the domain you're querying about. The nslookup command is another tool you can use to look up domain information. In the following example, nslookup looks up the server that is resolving the mail.yourdomain.com address:

```
