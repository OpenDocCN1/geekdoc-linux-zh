```
# cdrecord -v speed=2 dev=0,0,0 -data /var/tmp/macy.cd
```

Several additional parameters are included in the command. The -v parameter tells cdrecord to supply verbose output to the screen. The speed parameter tells cdrecord what speed to record at (in this case X2). The -data parameter tells cdrecord that the next parameter is the name of the file system image to write to the CD.
