# # Removed Packages

Over time, some packages are dropped from Red Hat Linux. If you have used Red Hat Linux in previous versions, you might be interested in this list if you can't seem to find a software package you have relied on. Here are packages that were removed from Red Hat Linux 7.3:

+   * **enlightenment** — Contains the enlightenment X-based window manager.
+   * **freecdb** — Contains the cdb tools for building and accessing constant databases.
+   * **gnome-pim** — Contains the GNOME personal information manager.
+   * **ircii** — Contains the ircii Internet Chat program.
+   * **kde*** — A set of kde packages (including kdegraphics, kdemultimedia, and kdenetwork) have been dropped. However, the applications that those packages contained have been split up into individual packages. This allows more flexibility in what you install.
+   * **links** — Contains the links text-based Web browser.
+   * **linuxconf** — Contains the linuxconf graphical system administration tool.
+   * **rp3** — Contains the rp3 graphical tools for creating dial-up Internet connections.

# # The Packages

The packages contained on the installation CD-ROMs are as follows:

+   * **4Suite:** Python programming tools for manipulating XML content and object databases.
+   * **a2ps:** Tools for converting text and other types of files into PostScript output for printing.
+   * **abiword:** The AbiWord word processing application.
+   * **ac-archive:** The Autoconf Macro Archive providing macros for the autoconf tool.
+   * **adjtimex:** The adjtimex command for regulating the system clock.
+   * **alchemist:** Back-end configuration tools used by printing, DNS, and Apache Web server.
+   * **alchemist-devel:** Files needed for developing programs that use alchemist.
+   * **alien:** Converts Debian, Stampede, and Slackware packages into Red Hat rpm packages.
+   * **am-utils:** Utilities that automount file systems, including the amcd daemon.
+   * **amanda:** The amanda network-capable tape backup application.
+   * **amanda-client:** The clients components for amanda network tape backup.
+   * **amanda-devel:** Libraries and docs needed to develop amanda applications.
