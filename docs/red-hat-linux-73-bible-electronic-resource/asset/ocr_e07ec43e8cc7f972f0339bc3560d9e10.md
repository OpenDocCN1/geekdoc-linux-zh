Several other software tools are available for analyzing transfer statistics. The accompanying sidebar on statistics packages available for Red Hat Linux describes some of these packages.

# ### Statistics Packages Available for Red Hat Linux

Analyzing the transfer log by hand isn’t much fun. Several packages have been written to automate this task, two of which are described below:

+   - **Analog** — This free log-file analyzer is very fast and easily configurable, and it produces very detailed output (including bar graphs and hypertext links). More information can be found at `www.analog.cx`.

+   - **AWStats** — The Advanced Web Statistics tool (`awstats.sourceforge.net`) produces graphical statistics representing Web-server access. AWStats can work with log files in the Apache common log format. It can report statistics such as the number of people who have visited, the number of visits made per person, the domain and country of each visitor, and the number of visits made by robots.
