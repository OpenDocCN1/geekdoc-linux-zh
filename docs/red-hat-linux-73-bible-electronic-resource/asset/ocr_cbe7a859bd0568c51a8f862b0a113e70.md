The word test.mp3 should appear. This is because the xmms command can play audio files that normally come with file extensions of .mp3, .MP3, .ogg, .pls, and .OGG.

If there had been multiple types of files that each command would handle, the completion would have stopped at “test” and allowed you to press Tab again. At that point you would have seen all the files that would have matched the file types supported by the command. For example:

```
$ gunzip test<Tab>.<Tab>
test.gz      test.Gz      test.tgz      test.Z
$ gunzip test.
```

Because, in this example, there were four different files in the current directory that matched types supported by gunzip, those four files were displayed after the second Tab. Then the original command line returns, ready for you to type more letters to choose a file or try to match again.
