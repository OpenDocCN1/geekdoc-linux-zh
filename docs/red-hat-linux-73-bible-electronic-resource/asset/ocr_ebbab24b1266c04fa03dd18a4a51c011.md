# ## Using ncftp

Once you are logged in, there are a few nice features you can use that aren't available with other FTP clients. Here are some examples:

+   - **bookmark** — If you are visiting a site that you want to return to, type the **bookmark** command and type a name to identify that site. The next time you are in an **ncftp** session, type the first few letters of the bookmark and press the Tab key. The name will complete and you can press Enter to go to the site.
+   - **lls, lcd, lmkdir, lpwd** — There is a set of commands that let you move around the local file system. Just place a letter "l" in front of standard shell commands like **ls, cd, mkdir, pwd, rm** and **rmdir** and you can move around and work with your local file system while you are in **ncftp**.
+   - **rhel p, site** — Use **rhel p** to see commands that are recognized by the remote FTP server. To see commands that are specific to the FTP server, type **site HELP**.
+   - **Auto-resume** — If you have gotten a broken connection in the middle of a large download, you will appreciate this new feature. After a connection is broken during a download, reconnect to the FTP site and begin downloading the file again in the same local directory. The **ncftp** command resumes downloading where it left off.

# ## Using ncftp for background transfers

If you are moving around to different parts of the FTP site, or jumping between different sites, you might not want to wait around for a file transfer to complete before you can go somewhere else. The **ncftp** command has an excellent feature for placing transfer commands in a spool file and then running them in the background immediately or later.

To select a file for background transfer, use the **bgget** command. Here is an example:

```
```
ncftp /pub > bgget wireless.doc
· Spooled: get wireless.doc
ncftp /pub > jobs
---Scheduled-For----Host-------Command------
2002-05-01 18:38 maple    GET wireless.doc
ncftp /pub > bgstart
Background process started.
Watch the "/home/br/.ncftp/spool/log" file to see how it is progressing
```
```

In this example, the **bgget** command spools the **wireless.doc** file from the remote current directory (/**pub**) and sets it to be copied to the local current directory. Typing the **jobs** command shows that the job (**GET wireless.doc**), from the host named **maple**, is scheduled to run immediately (6:38 p.m., May 1, 2002). By running the **bgstart** command this process, and any other spooled jobs, are run immediately.

As the example notes, you can see information about spooled FTP jobs in the **.ncftp/spool/log** file in your home directory. This file shows the commands that were run and the responses for each transfer.
