+   XFree86: The basic software needed to run the X Window System in Red Hat Linux.
+   XFree86-3DLabs: An X server for video cards that include the Permedia and Glint chips.
+   XFree86-75dpi-fonts: 75-dpi fonts that can be used on X Window System displays.
+   XFree86-100dpi-fonts: 100-dpi, high-resolution fonts for X Window System displays.
+   XFree86-8514: The XFree86 X server for video cards built with the IBM 8514 chips.
+   XFree86-base-fonts: The base fonts required for XFree86.
+   XFree86-compat-modules: Compatibility modules required by 3.3.6 XFree86 servers.
+   XFree86-cyrillic-fonts: Cyrillic character set fonts used with the X Window System.
+   XFree86-devel: Components needed to develop X-based client programs.
+   XFree86-doc: XFree86-related documentation, mostly in zipped PostScript format.
+   XFree86-FBDev: X server for frame buffer devices, such as Macintosh and Atari.
+   XFree86-ISO8859: X Windows fonts used with Central European Linux versions.
+   XFree86-ISO8859-2-75dpi-fonts: 75 dpi X fonts for Central European Linux versions.
+   XFree86-ISO8859-2-100dpi-fonts: 100 dpi X fonts in Central European Linux versions.
+   XFree86-ISO8859-2-Type1-fonts: Type 1 X fonts for Central European Linux versions.
+   XFree86-ISO8859-9-75dpi-fonts: 75-dpi X fonts for Turkish versions of Linux.
+   XFree86-ISO8859-9-100dpi-fonts: 100-dpi X fonts for Turkish Linux versions.
+   XFree86-libs: Shared libraries required for most X-based programs to run in Linux.
+   XFree86-Mach8: The XFree86 X server for video cards built with the ATI Mach8 chip.
+   XFree86-Mach32: The XFree86 X server for video cards with the ATI Mach32 chip.
+   XFree86-Mach64: The XFree86 X server for video cards with the ATI Mach64 chip.
+   XFree86-Mono: The XFree86 X server used for generic monochrome video cards.
+   XFree86-P9000: The XFree86 X server used for video cards with Weitek P9000 chips.
+   XFree86-S3: The XFree86 X server used for video cards based on S3 chips.
+   XFree86-S3V: The XFree86 X server for video cards based on the S3 VIRGE chipset.
+   XFree86-SVGA: The XFree86 X server that for most simple SVGA video cards.
+   XFree86-tools: A variety of X utilities.
+   XFree86-truetype-fonts: A collection of truetype fonts.
+   XFree86-twm: The simple twm window manager.
+   XFree86-V4L: Components that add Video for Linux support to XFree86.
