+   - If you want to discard all the changes you made to a document since it was last saved, click File \u2192 Revert.

+   - You can open a window to send the document you are working on by e-mail with one click. Click the mail icon on the Words menu bar and an Anyware Mail window appears. The current document is added to the message as an attachment. You can add an e-mail address, type a message, and send it to the recipients.

# Using StarOffice

The StarOffice suite from Sun Microsystems Inc. (www.sun.com/staroffice) is a product that runs on several different operating systems. Like Anyware Office, StarOffice contains many features that make it compatible with Microsoft Office applications. In particular, it includes the capability to import Microsoft Word and Excel files. There is also strong support for producing HTML files.

StarOffice is probably the most complete integrated office suite for Linux. It includes:

+   - **StarWriter** \u2014 This is the StarOffice word processing application. It can import documents from a variety of formats, with special emphasis on Word documents.

+   - **StarCalc** \u2014 This is the spreadsheet program that comes with StarOffice. You can import spreadsheets from Microsoft Excel and other popular programs.

+   - **StarImpress** \u2014 You can create presentations with the StarImpress application.

+   - **StarDraw** \u2014 This is a vector-oriented drawing program. It includes the capability to create 3D objects and to use texturing.

+   - **StarBase** \u2014 You can manage your data with StarBase. It can access a variety of database interfaces.

+   - **StarSchedule** \u2014 Use this application to manage your schedule, track events, and store your contacts. You can even interface StarSchedule to a PalmPilot.

There are also other applications in StarOffice that create business graphics (StarChart), edit images (StarImage), edit mathematical formulas (StarMath), and manage e-mail (StarMail). You can manage all these applications from the StarDesktop. The StarDesktop features an explorer tree for navigation and a task bar (so you can easily switch between tasks).

You can download a free version of StarOffice for Linux from the StarOffice Web site at www.sun.com/staroffice. Just look for the downloads links on that page. If you want to purchase the StarOffice Deluxe for Linux, the cost, at time of this writing, was $39.95. The Deluxe version includes an installation CD and printed manuals. More clip art and fonts are also included. You can get a StarOffice Slim CD Kit (just CDs and installation instructions) for $9.95.

Sun Microsystems has recently launched the OpenOffice project (www.openoffice.org). Visit that site for download links and other information related to StarOffice.
