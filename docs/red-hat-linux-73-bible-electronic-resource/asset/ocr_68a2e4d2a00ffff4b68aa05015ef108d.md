# # Deleting user accounts with Red Hat User Manager

To delete a user from the Red Hat User Manager window, simply click on the line representing the user account, then click on the Delete button. The result of this action is:

+   * The information about the user is removed from the /etc/passwd file, thus the user can no longer log in.
+   * The home directory and all files owned by the user will still exist. However, a listing of files previously owned by that user (ls -1) will only show the owner as the former user’s UID, but no name.

See the description in the previous section for information about how to find and remove files previously owned by the user.

> **NOTE:** You may want to transfer the ownership of the files from the old user to the new user. For example, if a new employee is taking over the work of an employee that is leaving the company. In that case, after you delete the old user, you can create a new user account, using the same UID as the old account (with a new password, of course). The new user will immediately have ownership of all files owned by the deleted user.

# # Checking Disk Quotas

Limited disk space can be another source of user support calls. Red Hat Linux offers the quotas software package for limiting and displaying the amount of disk space that a user can consume. You can also use the du command to see how much disk space has been used in a particular directory (and related subdirectories). To automate the process of checking for disk space, you can create your own script. The following sections describes these ways of dealing with potential disk space problems.

# ## Using quota to check disk usage

A careless or greedy user has the potential of gobbling up all the space on your hard disk and, possibly, bringing your computer to a halt. By using disk quotas, you can limit the amount of disk resources a user or group can use up.

The quota package contains a set of tools that lets you limit the amount of disk space (based on disk blocks) and files (based on inodes) that a user can consume. Using quotas, you can limit the amount of usage (on a per-user and -group basis) for each file system on your computer. The general steps for setting disk quotas are:

+   * Creating quota files
+   * Editing /etc/fstab file
+   * Creating quota rules
+   * Checking quotas
