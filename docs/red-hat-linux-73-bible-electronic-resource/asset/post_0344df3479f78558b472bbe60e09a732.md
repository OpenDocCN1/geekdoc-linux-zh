
## Package Descriptions

- **kljettool:** A configuration tool for HP LaserJet and compatible printers.
- **klpq:** A KDE tool for managing the print spooler.
- **klprfax:** Fax-transmission support for PDE to let applications that can print to send a fax.
- **kmail:** An e-mail client for KDE.
- **kmidi:** A MIDI-sound-file player.
- **kmix:** A MIDI-sound-file player that converts sound to digital audio before playback.
- **knewsticker:** A program that will display news from selected Web sites.
- **knm_new:** A Kaname-cho font.
- **knode:** A newsgroup (NNTP) reader for KDE.
- **knotes:** An application enabling notes to be placed on the desktop.
- **koffice:** A set of office productivity applications.
- **koffice-devel:** Files needed to develop plug-ins for KOffice.
- **kon2:** A Kanji emulator for the console.
- **kon2-fonts:** Fonts for kon.
- **koncd:** A program for mastering and burning CD-ROMs.
- **kontrol-panel:** A control panel to launch installed system-configuration tools.
- **kooka:** A KDE application that controls an image scanner.
- **korn:** A multi-folder KDE mail monitor that displays the number of new messages.
- **kpaint:** A simple paint program for KDE.
- **kpf:** A public file server for KDE.
- **kppp:** PPP networking application for KDE.
- **kpppload:** The `kpppload` utility to visually monitor the load on your PPP connections.
- **krb5\*:** A set of packages is used to provide support for Kerberos authentication methods.
- **krbafs\*:** The krbafs library, for with support for AFS tokens with Kerberos 5 credentials.
- **kregexpeditor:** A regular-expressions editor.
- **kregexpeditor-devel:** Development files for kregexpeditor.
- **kruler:** A screen ruler and color-measurement tool.
- **kscd:** An audio CD player for KDE.
- **ksconfig:** The `ksconfig` graphical tool to create Kickstart files for unattended installs.
- **ksirc:** An IRC client for KDE.
- **ksnapshtos:** A KDE applet for capturing images of the desktop or an individual window.
- **ksymoops:** Utility that converts kernel error messages to useful symbols and offsets.
- **ktalkd:** A program supporting the Talk protocol for KDE.
- **kterm:** The kterm Kanji terminal emulator.
- **ktimer:** A stopwatch program.
- **kudzu:** The `kudzu` utility, which detects and configures computer hardware.
- **kudzu-devel:** Header files used to create kudzu applications.
- **quickshow:** A picture-thumbnail viewer for KDE.
- **kview:** A KDE image viewer that supports a wide range of graphics formats.
- **kviewshell:** Components to allow `kview` to be embedded into other KDE programs.
- **kviewshell-devel:** Libraries that allow applications to use `kviewshell`.
- **kwnn:** A Korean character set input system.
- **kwnn-devel:** Header files and library needed to develop applications that use kwnn.
- **kxmlrpcd:** Remote-scripting KDE libraries to do DCOP calls with the XmlRpc.
- **lam:** Local Area Management (LAM) tools for managing clusters of network computers.
- **lapack:** The Linear Algebra Package (LAPACK) to solve simultaneous linear equations.
- **lapack-man:** Documentation for the lapack package.
- **less:** The `less` utility, which is used to page through and search text documents.
- **lesstif:** A free version of OSF/Motif, providing a set of widgets to develop applications.
- **lesstif-devel:** Library and header files to develop Motif-1.2-based programs for LessTif.
- **lftp:** A sophisticated ftp/http file transfer program.
- **lha:** An archiving and compression utility for LHarc format archives.
- **libaio:** A Linux-native asynchronous I/O-access library.
- **libaio-devel:** Development files allowing applications to use libaio.
- **libao:** A cross-platform audio output library.
- **libao-devel:** Header files and documentation needed to develop applications with libao.
- **libcap:** A library for getting and setting POSIX.1e capabilities.
- **libcap-devel:** Headers and libraries needed for developing applications that use libcap.
- **libdbi:** The C independent abstraction layer allowing multiple database connections.
- **libdbi-dbd-\***: Libdbi support for various databases.
- **libdbi-dbd-devel:** Development files needed to create applications that use libdbi.
- **libelf:** Libraries that let applications access the internals of ELF object files.
- **libesmtp:** A library that manages the posting of e-mail using SMTP.
- **libesmtp-devel:** Header files and libraries needed to develop applications using libesmtp.
- **libgal19:** A variety of GNOME functions and utilities.
- **libgal7:** A variety of GNOME functions and utilities.
- **libgcj:** The Java runtime library for gcc.
- **libgcj-devel:** Development tools associated with the Java runtime library for gcc.
- **libglade:** Libraries that can be used to create GLADE user interface applications.
- **libglade2:** The libglade library for loading user interfaces from XML descriptions.
- **libglade2-devel:** Tiles needed to develop applications that use libglade.
- **libglade-devel:** Tools and documentation for developing GLADE applications.
- **libgnomeprint15:** Components needed to support GNOME printing.
- **libgtkhtml:** GtkHTML, which renders, prints, and edits HTML.
- **libgtop:** A library that gets information about system usage.
- **libgtop-devel:** Components needed to develop applications to monitor system usage.
- **libgtop-examples:** Examples of retrieved systems information used by libgtop.
- **libjpeg-6b:** The libjpeg library for manipulating JPEG images.
- **libjpeg-devel-6b:** Header files and libraries for creating programs that use JPEG images.
- **libkscan:** A KDE library for scanner support.
- **libkscan-devel:** Development files needed to create applications that use libkscan.
- **libmad:** An MPEG-audio-decoder library.
- **libmng:** The libmng library for working with images in MNG and JNG formats.
- **libmng-devel:** Header files related to the libmng library.
- **libmng-static:** Static versions of the libmng library.
- **libogg:** The libogg library for working with ogg bit streams.
- **libogg-devel:** Documentation and header files for developing ogg applications.
- **libole2:** The libole2 library for working with OLE structured storage files.
- **libole2-devel:** Header files to develop applications for OLE structured storage files.
- **libpcap:** Components to create applications that can monitor low-level network traffic.
- **libpng:** The libpng library for working with PNG image files.
- **libpng-devel:** Libraries and headers needed to develop programs that use PNG images.
- **librep:** Tools and documentation associated with the librep Lisp dialect.
- **librep-devel:** Header files and tools associated with the librep Lisp dialect.
- **librsvg:** An SVG library based on libart.
- **librsvg-devel:** Libraries and include files required to develop applications using librsvg.
- **libsbc++:** A library which implements a callback system for use in widget libraries.
- **libsbc++-devel:** The static libraries and headers to develop applications with libsbcc++.
- **libstdc++:** The EGCS libraries needed to run C++ applications.
- **libstdc++-devel:** Standard C++ development libraries.
- **libtable:** Chinese lexicon libraries for xcin input method.
- **libtable-devel:** Header files and libraries required to develop applications to use libtable.
- **libtermcap:** Libraries to access the termcap database to manage character displays.
- **libtermcap-devel:** Components to develop programs that access the termcap database.
- **libtiff:** Libraries for using and saving TIFF image files.
- **libtiff-devel:** Development tools used to work with TIFF image files in applications.
- **libtool:** The libtool shell scripts, used to configure Linux to build generic shared libraries.
- **libtool-libs:** Runtime libraries for libtool utilities (to build generic shared libraries).
- **libungif:** Library functions needed to use and save GIF image files.
- **libungif-devel:** Development tools to create applications to load and save GIF images.
- **libungif-progs:** Several utilities for working with GIF images.
- **libusb:** A library that allows applications to access USB devices.
- **libusb-devel:** Development files needed to create applications that use libusb.
- **libuser:** A standardized interface for administration of user accounts.
- **libuser-devel:** Header files and static libraries to develop applications that use libuser.
- **libvorbis:** The Ogg Vorbis open audio compression codec and runtime libraries.
- **libvorbis-devel:** Header files and documentation to develop applications using libvorbis.
- **libxml:** A library of functions for working with XML files.
- **libxml2:** A library to work with XML and HTML files, including DTD support.
- **libxml2-devel:** Libraries and include files to develop applications using libxml2.
- **libxml2-python:** Python bindings for the libxml2 library.
- **libxml10:** Backward-compatible libxml10 XML parser for GNOME.
