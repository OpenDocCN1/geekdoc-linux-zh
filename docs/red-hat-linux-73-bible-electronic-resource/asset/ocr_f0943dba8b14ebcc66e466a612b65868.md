# # Chapter 18
## Setting up a File Server

# ### In This Chapter

+   - Setting up an NFS file server in Red Hat Linux
+   - Setting up a Samba file server in Red Hat Linux
+   - Setting up a NetWare file server in Red Hat Linux

When groups of people need to work together on projects, they usually need to share documents. Likewise, it can be efficient for groups of people on a computer network to share common applications and directories of information needed to do their jobs. A common way to centrally store and share files on a network is by setting up a file server.

Red Hat Linux includes support for each of the most common file server protocols in use today. The Network File System (NFS) has always been the file-sharing protocol of choice for Linux and other UNIX systems. Networks with many Windows and OS/2 computers tend to use Samba (SMB protocol). Prior to Samba, NetWare was the most prominent file-server software used on local area networks (LANs).

This chapter describes how to set up file servers and clients associated with NFS, Samba, and NetWare file servers. (To learn how to configure public FTP file servers, refer to Chapter 20.)

# ## Goals of Setting Up a File Server

By centralizing data and applications on a *file server*, you can accomplish several different goals:

+   - **Centralized distribution** — You can add documents or applications to one location and make them accessible to any computer or user that is granted permission. In this way, you don’t have to be responsible for placing necessary files on every computer.
+   - **Security** — You can control who has access to the file server on one computer instead of distributing the information to every computer and trying to control it.
+   - **Transparency** — Using protocols such as NFS, clients of your file server (Windows, Linux, or UNIX systems) can connect your file systems to their local file systems as if your file systems existed locally. (In other words, no drive letters. Just change to the remote system’s mount point and you are there.)
