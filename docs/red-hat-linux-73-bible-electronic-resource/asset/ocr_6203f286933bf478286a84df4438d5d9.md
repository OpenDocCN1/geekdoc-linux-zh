# Selecting other Netscape Communicator features

Other client programs and features are included with Netscape Communicator, besides the Netscape Navigator browser. Here is a list of those clients and features:

+   * **Messenger:** Choose Communicator → Messenger to open a Messenger window for viewing mail and newsgroups.

+   * **Compose:** Choose Communicator → Compose to create your own Web pages.

+   * **Radio:** Select the Radio to play music from the Internet. Netscape Radio lets you choose from among 15 different channels. (You need a RealAudio to used this feature.)

+   * **Bookmarks:** Click Bookmarks to select from the lists of bookmarks. Click Add to add the current page to the bookmarks.

**TIP:** The Personal Toolbar should have bookmarks that you use often. To delete the bookmarks that Netscape provides, choose Bookmarks → Edit Bookmarks and select the bookmarks under the Personal Toolbar heading, and then choose Edit → Delete. Now you can add your own. The bookmarks you add to the Personal Toolbar are only one click away.
