+   - **gnome-utils**: Several useful GNOME utilities, such as a calculator and a calender.

+   - **gnome-vfs**: The GNOME virtual file system needed by the Nautilus file manager.

+   - **gnome-vfs-devel**: The libraries and header files to develop GNOME-VFS applications.

+   - **gnome-vfs-extras**: GNOME-VFS modules including a Samba smb network browser.

+   - **gnorpm**: The GNOME front-end for managing software packages (RPMs).

+   - **gncash**: An application that tracks personal finance data.

+   - **gnchess**: The GNU chess program and related utilities.

+   - **gnumeric**: The gnumeric spreadsheet program that runs in GNOME.

+   - **gnumeric-devel**: Development tools associated with the gnumeric spreadsheet.

+   - **gnupg**: The GNU Privacy Guard (gnupg) for digital signatures and data encryption.

+   - **gnuplot**: The gnuplot utilities, used to plot scientific and other types of data.

+   - **gperf**: The gperf C++ hash function generator.

+   - **gphoto**: The gphoto application for managing images from digital cameras.

+   - **gphoto2**: A newer version of gphoto.

+   - **gphoto2-devel**: Header files needed to create applications that use gphoto2.

+   - **gpm**: The gpm components needed to support a mouse in text-based applications.

+   - **gpm-devel**: L libraries and header files to develop text-mode programs that use a mouse.

+   - **gq**: The gq graphical LDAP browser.

+   - **gqview**: The gqview utility for browsing and displaying graphics files.

+   - **grep**: The grep utilities for finding matching patterns in text files.

+   - **grip**: A front-end for various compact disc rippers and MP3 encoders.

+   - **groff**: The groff document utilities to format documents from plain text and markup.

+   - **groff-gxditview**: The gxditview utility to display groff output in the GUI.

+   - **groff-perl**: The a2mtodit and rog utilities for working with groff documents.

+   - **grub**: The Grand Unified Boot Loader, used by default to boot Red Hat Linux.

+   - **gsl**: The GNU Scientific Library for numerical analysis and high-level mathematics.

+   - **gsl-devel**: Header files and libraries needed to create applications that use gsl.

+   - **gtk+**: The GIMP graphical toolkit for building graphical X applications.

+   - **gtk+-devel**: The gtk+ development tools to create applications that need GIMP.

+   - **gtk+10**: Compatibility libraries required for applications that use gtk+ and glib 1.0.

+   - **gtk2**: A toolkit used to create graphical user interfaces (GUIs).

+   - **gtk2-devel**: The header files and developer documentation for the GTK+ toolkit.
