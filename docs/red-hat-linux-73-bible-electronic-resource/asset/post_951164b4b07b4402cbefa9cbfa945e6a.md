## New Features in Red Hat Linux 7.3

Solidarity and flexibility, as noted earlier, are cornerstones of the new Red Hat Linux 7.3 distribution. Red Hat continues to add those features that allow Linux to operate in high-volume, high-availability servers. Those same attributes are good for small organizations that some day want to grow.

Added flexibility in Red Hat Linux 7.3 comes in the form of a new port of the Debian “alternatives” feature and some added software packages that let choose between different printing, Web, FTP, and mail servers. The alternatives feature is designed to make it easier to move from one mail, printing, or other service without changing user interfaces. The added server packages tend to offer simplified services where high-volume and security are necessary.

The next few sections describe new features in Red Hat Linux 7.3. For those of you who are upgrading from a Red Hat Linux 7.0 or earlier system, I have included descriptions of the Linux 2.4 kernel (which you may be seeing for the first time). If you have an earlier edition of this book, I have included a section describing additions and enhancements to this edition that are not particularly related to new Red Hat Linux features.

### Improvements to the Linux 2.4 kernel

New drivers and tuning of the Linux 2.4 kernel continue in Red Hat Linux 7.3. Of the new features and fixes that are included in the Linux 2.4 kernel, the most prominent features are aimed at enterprise computing. The term enterprise computing implies that the computing systems serve a lot of people and are expected to be able to handle high volumes of data reliably.

Here is a list of many of the new features:

- **Enhanced Symmetric Multiprocessing** — With the Linux development community getting support from major computer hardware vendors such as IBM, Dell Computer, Hewlett-Packard, Silicon Graphics, and Intel, the Linux 2.4 kernel has been enhanced to handle more powerful, multiprocessor computers. The Linux 2.2 kernel could manage up to eight processors. However, it is limited by being able to handle only 1,024 simultaneous threads. The Linux 2.4 kernel is intended to handle multiple processors more efficiently and effectively than the 2.2 kernel. The 2.4 kernel is designed to be able to scale up at runtime to handle many more threads if necessary.
- **Greater capacity** — Besides being able to manage many processors, the Linux 2.4 kernel is made to support more RAM (up to 4GB), more IDE controllers (up to 10), and more network interface cards (up to 16 Ethernet NICs).
- **Networking enhancements** — Key networking components have been redesigned to be able to handle the greater system loads in enterprise computing environments. In particular, security features such as firewalls (using the iptables feature) have been built into the kernel. Support for new networking hardware, such as high-speed ATM network adapters, has also been added to the kernel.
- **Improved Universal Serial Bus (USB) support** — Though some USB support is included with Red Hat Linux 7, more USB devices are supported in the Linux 2.4 kernel. In Red Hat Linux 7, USB devices are limited to USB mouse support and USB keyboard support. The new kernel supports new USB video camera drivers, printer drivers, and Abstract Control Module drivers.
- **New file system interface** — Besides including, and presumably improving, previously supported file system types such as DOS and Windows file systems (FAT), NTFS, VFAT, and FAT32, several new file system types were added. These include the DVD disk file system (UDF), the UNIX NFS file system, and the IRIX XFS (EFS) file system.

In general, the Linux 2.4 kernel enhancements are aimed at helping Red Hat Linux, as well as other Linux distributions, run faster, more efficiently, and more reliably in large-scale computing environments. The new kernel should also help limit the number of Linux kernel variants by including the features in Linux 2.4 that allow the same kernel to work on everything from single-user workstations to enterprise servers that can support thousands of simultaneous transactions.

## Alternatives system

For any important service or application running in Linux there is sure to be more than one software package that can implement that service or application. The alternatives system, which is a port of the Debian alternatives feature, gives the administrator the tools to transparently exchange one service or application for another on a Red Hat Linux system.

As an administrator of a Red Hat Linux system, you may decide that you want to use a different software package to handle mail service or print service, for example. Using the alternatives system, you can add that new service in such a way that the users of the system don't have to change the commands they use to print a document or send an e-mail.

The alternatives system was added to the `chkconfig` software package for Red Hat Linux 7.3. Its main components are the `alternatives` command and the `/etc/alternatives` directory (which contains a set of links that link user commands to the new services).

> **CROSS-REFERENCE:** The alternatives system is described in Chapter 10.

### Installation

A new checkcheck feature has been added to the Red Hat Linux installation process. This feature checks that the Red Hat Linux distribution CDs are not damaged or corrupted. If you run the `mediacheck` and a CD fails, you know that you have a bad distribution CD.

> **CROSS-REFERENCE:** Red Hat Linux installation is described in Chapter 2.

### Postfix mail-transfer agent

The postfix software package is designed to be an alternative to the `sendmail` mail transport agent (MTA). It is compatible to `sendmail` in many ways, allowing people to use aliases, forwarding, and other features in the same way. However, it is designed to provide much faster performance and easier administration by not relying on the complex `sendmail.cf` file.

Using the new alternatives, you can replace `sendmail` with postfix in a way that is mostly invisible to the end users. See Chapter 19 for a description of postfix.

### CUPS print server

The Common Unix Printing System (CUPS) is a portable software system for managing printing services in Linux and UNIX systems. CUPS can replace the `LPing` printing system while still allowing people to use most of the same commands they used with `LPing` to print documents on local and remote printers.

Using the new alternatives, you can replace `LPing` with CUPS in a way that is mostly invisible to the end users.

> **CROSS-REFERENCE:** See Chapter 17 for a description of CUPS.
