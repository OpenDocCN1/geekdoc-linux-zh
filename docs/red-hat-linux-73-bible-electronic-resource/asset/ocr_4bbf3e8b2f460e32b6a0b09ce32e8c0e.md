To add a local printer from the CUPS administration window, do the following:

+   1. Click the Add Printer button. A screen appears, asking you to add your printer
+   2. Type the name of your printer, its location, and a description of it, then click Continue. A screen appears, asking you to enter the type of port your printer is connected to.
+   3. Select the port your printer is connected to (most likely parallel port 1 or serial port 1).
+   4. Select the manufacturer of your printer.
+   5. Select the specific model of your printer. If the printer has been added successfully, you should see a window similar to the one shown in Figure 17-3.
