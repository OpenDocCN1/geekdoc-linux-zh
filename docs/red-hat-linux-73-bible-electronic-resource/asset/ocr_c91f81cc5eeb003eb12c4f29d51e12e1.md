To enable a disabled printer (such as the one in the previous example), use the **enable** option and type the following:

```
$ lpc enable canyonpsps
Printer: canyonpsps@localhost
canyonpsps@localhost.localdomain: enabled
```

When a printer is disabled, it can still continue to receive print jobs and hold them in the queue until the printer is enabled again. If you want to prevent jobs from being spooled at all, use the **stop** option as follows:

```
$ lpc stop canyonpsps
Printer: canyonpsps@localhost
canyonpsps@localhost.localdomain: stopped
```

To start the printing daemon again and resume printing, use the **start** option, as follows:

```
$ lpc start canyonpsps
Printer: canyonpsps@localhost
canyonpsps@localhost.localdomain: started
```

To disable a printer and kill the lpd daemon (so that no further jobs can be printed), use the **abort** option, as follows:

```
$ lpc abort canyonpsps
Printer: canyonpsps@localhost
kill server PID 4239 with Interrupt
canyonpsps@localhost.localdomain: aborted_job
```

The printers that are connected to your Red Hat Linux system can be shared in different ways with other computers on your network. After a local printer is attached to your Red Hat Linux system, and your computer is connected to your local network, you can use the procedures in this section to share it with client computers using a Linux (UNIX), NetWare, or SMB interface.
