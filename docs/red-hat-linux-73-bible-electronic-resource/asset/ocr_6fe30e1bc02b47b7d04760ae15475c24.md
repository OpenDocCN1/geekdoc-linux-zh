# # Configuring vsFTpd

Most of the configuration you want to do with vsFTpd you can do in the `/etc/vsftpd.conf` file. Though many values are not set explicitly in this file, you can override the defaults by setting `option=value` statements in this file. You can set such things as which users have access to your vsFTpd server, how logging is done, and how timeouts are set.

Go through the following section for more information about how vsFTpd is configured by default and how you can configure your vsFTpd server further.

# ## User accounts

Users who can access your vsFTpd server are, by default, the anonymous user and any users with real-user accounts on your system. These features are set by the following two lines:

```
anonymous_enable=YES
local_enable=YES
```

The `anonymous_enable` line lets users log in anonymously using either the anonymous or ftp user name. Any users with local accounts (in `/etc/passwd`) can log into the FTP server with `local_enable` set to YES. An exception to this rule is that, by default, all user accounts listed in the `/etc/vsftpd.user_list` file are denied access. The following line in the `vsftpd.conf` file activates that list by default:

```
userlist_enable=YES
```
