# Format of the inittab file

The plain-text inittab file consists of several colon-separated fields in the format:

```
id:runlevels:action:command
```

The id field is a unique identifier, one to four alphanumeric characters in length that represents a particular action to take during system start-up. The runlevels field contains a list of run levels in which the command will be run. Common run levels are 0, 1, 2, 3, 4, 5, and 6 (s and S represent single-user mode, which is equivalent to 1).
