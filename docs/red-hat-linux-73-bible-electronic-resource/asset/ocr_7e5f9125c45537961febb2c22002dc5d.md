# ## Getting updates from the Red Hat Network

Red Hat has created a system that automatically notifies you of available updates and lets you easily download and install them on your Red Hat Linux system. The service is called Red Hat Network. Registering with the Red Hat Network allows you to run the `update` program from your Red Hat Linux computer whenever you are ready to do the updates.

Red Hat Network provides a mechanism that can:

+   - Alert you of the latest fixes and enhancements available for Red Hat Linux and
+   - Install the packages that include those changes to your system.

A lot of information about the Red Hat Network is available from its Web page (rhn.redhat.com). This section provides an overview of how the service works and steps you through the registration process.

If you don't mind giving out your e-mail address, street address, and phone number, there are some pretty good reasons for creating a Red Hat Network (RHN) account for yourself. With a free RHN account you can register your Red Hat Linux system and create system profiles. Just registering your first machine also entitles you to receive all updates for that machine. To get more services (or entitle more machines), you can purchase a subscription to RHN.

> NOTE: Because Red Hat Network is fairly new and constantly evolving, it is possible that many of the features and entitlements described in this section will change. I recommend that you check the Red Hat Network site (rhn.redhat.com) for information on new features if the procedures in this section seem outdated.

# ### Running rhn_register

To register your system with Red Hat Network you can use the `rhn_register` command. Using `rhn_register` requires a connection to the Internet and root access to your computer—latter because the registration process needs to access your computer's RPM database. Though only the first computer you register can receive free automatic updates, you can register as many computers as you want with this tool. Here is how it works:

+   1. Open a Terminal window as root user.
+   2. Type `rhn_register`. A Network Settings window appears, enabling you to add proxy-server settings in case you need to go through a proxy server to reach the Internet.
+   3. Enter the proxy information (only if required) and click OK. A Red Hat Registration window appears. (If no GUI is present, the procedure runs in text mode instead.)
