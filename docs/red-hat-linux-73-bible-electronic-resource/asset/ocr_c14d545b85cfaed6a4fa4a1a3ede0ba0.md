# Red Hat Errata page

Red Hat gathers information you need to upgrade your system on the Red Hat Errata page (www.redhat.com/errata). As the page proclaims, this is your means of finding “Security Alerts, Bugfixes, and Enhancements” for Red Hat Linux. Select the link to the current release. The list of advisories that appears contains package names, a synopsis of the problem addressed by the corrected packages, and the dates the updates were released.

Many of the advisories are intended to plug potential security holes. In particular, package fixes that address vulnerabilities in network services or mishandled permissions are often included with these advisories. Click on a package name in the list to get a detailed description of the package update, as well as a list of links to sites from which you can download the updated package.

Going directly to the Red Hat Errata page is probably the best way to check on vulnerabilities and bugs relating to your version of Red Hat Linux. Then you can either download and install each new package individually or use the update application (described later in this chapter) to install multiple updates at once.

# Project Web sites

Most open-source projects have Web sites that are used to track software development, post news, and answer questions about the project. In some cases, critical bugs or security issues may be described at a project's Web site before Red Hat hears of them. If you're operating a public server on the Internet, you might be particularly interested in keeping up with potential problems relating to the network services you are running.

For example, if you are using wu-ftpd as your FTP server software, you can refer to the WU-FTPD Development Group site (www.wu-ftpd.org). Recent news items are posted at that site, of which the security issues might be particularly useful to you. You can also subscribe to wu-ftpd mailing lists from this site. If you don't want to be overrun by e-mail, you might simply want to subscribe to the wuftp-announce list to get occasional announcements about security problems.

Here are some other project sites that you might want to check for information about problems and issues that arise:

+   Apache Software Foundation (www.apache.org) — Get updates about Apache Web-server issues.

+   Samba.org (www.samba.org) — Find information relating to Windows file- and print-sharing issues.

+   Netfilter (Iptables) Firewall (www.netfilter.org) — Find out the latest issues relating to iptables and related firewall tools.
