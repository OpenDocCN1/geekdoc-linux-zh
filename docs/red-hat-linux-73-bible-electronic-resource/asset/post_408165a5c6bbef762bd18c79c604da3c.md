
## RPM Package Reference

### Section A
- **amanda-server**: Server components of the amanda network tape backup.
- **ami**: A Korean input method system.
- **ami-gnome**: GNOME applet mode binary of ami.
- **anaconda**: The anaconda command, used to install or reconfigure Red Hat Linux.
- **anaconda-help**: Help information for anaconda.
- **anaconda-images**: Images used in anaconda.
- **anaconda-runtime**: The part of the Red Hat Linux installer needed for new installation.
- **anacron**: The anacron command, used to execute set commands periodically.
- **anonftp**: A fast, read-only anonymous FTP server.
- **apache**: The Apache Web server configuration files, documentation, and daemons.
- **apache-devel**: Apache Web server header files and apxs tool for extension modules.
- **apache-manual**: The Apache manual (in HTML format).
- **apacheconf**: The Red Hat apacheconf tool for configuring an Apache Web server.
- **apel**: A portable emacs library for interfacing with emacs.
- **apmd**: The advanced power management software for monitoring battery power.
- **ark**: A KDE tool for handling archive files of various common formats.
- **arpwatch**: The arpwatch utility for tracking Ethernet/IP address pairings.
- **arts**: The analog real-time synthesizer software used with the KDE sound system.
- **arts-devel**: Libraries and documentation needed to develop programs using arts.
- **ash**: The ash utility, a shell that is similar to the UNIX System V sh (Bourne) shell.
- **asp2php**: Tools for converting active server pages to PHP format.
- **asp2php-gtk**: A gtk front-end interface for the asp2php application.
- **aspell**: A set of packages for spell checking in a variety of languages.
- **aspell-devel**: Libraries and documentation needed to develop applications using aspell.
- **at**: The at and batch commands, used to queue commands to run in the background.
- **atk**: A set of interfaces for adding accessibility support to applications.
- **atk-devel**: The libraries, header files, and documentation for atk.
- **audiofile**: Utilities that implement the SGI Audio File library for processing audio files.
- **audiofile-devel**: Development tools associated with audio software development.
- **aumix**: The aumix program for adjusting audio mixing device (/dev/mixer) settings.
- **aumix-X11**: An X-based version of the aumix program.

### Section B
- **auth_ldap**: The auth_ldap module to authenticate Apache users with the LDAP database.
- **authconfig**: Tools for configuring system authorization resources.
- **authconfig-gtk**: A graphical tool for configuring system-authorization resources.
- **autoconf**: Tools to create scripts to make portable, configurable source-code packages.
- **autoconf253**: A newer version of autoconf.
- **autoconvert**: Autoconvert tools for converting Chinese HZ/GB/BIG5 encodings.
- **autoconvert-xchat**: Autoconvert-xchat plugins.
- **autofs**: Software for automatically mounting and unmounting file systems.
- **automake**: The automake makefile generator.
- **autorun**: Software that automatically detects and mounts CD-ROMs.
- **awesfx**: The AWE32 sound driver utilities.
- **balsa**: The balsa e-mail reader (which is part of the GNOME desktop).
- **basesystem**: Part of the base Red Hat Linux system.
- **bash**: Version 2.05 of the GNU Bash shell (Bourne Again Shell).
- **bash-doc**: Documentation for the GNU Bash shell.
- **bc**: The bc precision-calculator utility and language.
- **bcm5820**: Shared libraries to interface with Broadcom Cryptonet BCM5820 driver.
- **bdflush**: The bdflush kernel daemon for flushing dirty buffers back to the disk.
- **bg5ps**: A tool that converts BIG5 encoded Chinese into printable postscript.
- **bind**: Berkeley Internet domain name server software (named and related components).
- **bindconf**: The bindconf-gui tool for configuring DNS settings.
- **bind-devel**: Header files needed for domain name server software development.
- **bind-utils**: The dig, dnsquery, nslookup, nsupdate, and other DNS utilities.
- **binutils**: GNU development tools, such as ar, as, ld, nm, size, and others.
- **bison**: The GNU bison parser generator (replacement for yacc).
- **blas**: Basic Linear Algebra Subprograms (BLAS) libraries for basic linear algebra.
- **blas-man**: Man pages that document the blas package.
- **blt**: The BLT library of extensions to the TK library.
- **bonobo**: A component system to lets GNOME apps handle compound documents.
- **bonobo-conf**: A bonobo-based system for configuration options.
- **bonobo-conf-devel**: Libraries and files needed to develop programs using Bonobo.
- **bonobo-devel**: Libraries and header files to let applications use bonobo document model.

### Section C
- **bootparamd**: The bootparamd boot parameter server to boot diskless workstations.
- **bridge-utils**: Utilities to configure a bridge in Linux connecting multiple Ethernet LANs.
- **bridge-utils-devel**: Programming interface to the Linux Ethernet bridge.
- **bug-buddy**: The bug-buddy graphical bug-reporting tool.
- **busybox**: The busybox utility (includes tiny, basic Linux utilities for embedded Linux).
- **busybox-anaconda**: A version of busybox for use with anaconda.
- **byacc**: The byacc (yacc) parser generator.
- **bzip2**: The bzip2 and bzcat utilities for compressing and uncompressing files.
- **bzip2-devel**: Programming tools associated with the bzip2 and bzcat utilities.
- **bzip2-libs**: Libraries for applications using bzip2.
- **caching-nameserver**: Configuration files used for caching-only name servers.
- **cadaver**: Command-line WebDAV client.
- **Canna**: A unified user interface called Canna for inputting Japanese.
- **Canna-devel**: Development tools associated with Canna.
- **Canna-libs**: Programming libraries used to support Canna.
- **cdda2wav**: The cdda2wav utility for converting CD audio files into WAV sound files.
- **cdecl**: The cdecl utility for composing C and C++ type declarations.
- **cdlabelgen**: A utility that generates frontcards and traycards for compact disc cases.
- **cdp**: The cdp and cdplay utilities for playing music CDs.
- **cdparanoia**: The cdparanoia program for retrieving audio tracks from CD-ROM.
- **cdparanoia-devel**: Development tools associated with the cdparanoia program.
- **cdparanoia-libs**: Dynamic libraries needed by applications that read digital audio disks.
- **cdrdao**: A tool for writing audio CD-R in disc-at-once mode.
- **cdrecord**: Software for writing data to writable CD-ROMs.
- **cdrecord-devel**: Software development tools for writing data to writable CD-ROMs.
- **cervisia**: A KDE graphical front-end for the CVS client.
- **chkconfig**: The chkconfig tool for changing system service run-level information.
- **chkfontpath**: The chkfontpath utility for working with X font server directories.
- **chromium**: An arcade-style shooting game.

### Section D
- **cipe**: The cipe tool for creating virtual private networks on public networks.
- **cleanfeed**: The cleanfeed.conf file and filters for filtering spam from news servers.
- **compat-egcs**: A compiler to create backward-compatible applications for Red Hat 5.2.
- **compat-egcs-c++**: A C++ compiler to create applications that run on Red Hat 5.2.
- **compat-egcs-g77**: Contains a compiler to create applications that are backward compatible with Red Hat 5.2.
- **compat-egcs-object**: Contains an Objective C compiler that can create backward-compatible Red Hat 5.2 programs.
- **compat-glibc**: A version of the GNU C library to compile binaries to run in Red Hat 5.2.
- **compat-libs**: Run-time libraries to develop for Red Hat Linux 6.2 and other systems.
- **compat-libstdc++**: Run-time libraries backward compatible with C++ in Red Hat 5.2.
- **comsat**: The biff (mail notification client) and comsat (mail server) components.
- **console-tools**: Utilities for loading console fonts and keyboard mappings.
- **control-center**: The GNOME Control-Center configuration tool.
- **control-center-devel**: Components to develop GNOME control center capplets.

### Section E
- **cpio**: The cpio command for copying files to or from a tar or cpio archive.
- **cpp**: The cpp (C preprocessor) macro processing utility, for preprocessing C code.
- **cproto**: The cproto tool to create function prototypes for C language source code.
- **cracklib**: CrackLib software for testing passwords for their security.
- **cracklib-dicts**: Dictionaries that are used by CrackLib when testing password security.
- **crontabs**: The root crontabs files, used by the cron daemon to schedule tasks.
- **ctags**: The ctags tool for generating tag files of objects from C source code.
- **cups**: The Common Unix Printing System, a portable printing service for UNIX systems.
- **cups-devel**: Files needed to create additional printer drivers and other CUPS services.
- **cups-drivers-hpijs**: CUPS drivers for HP printers using the optimized hpijs driver.
- **cups-drivers-pnm2ppa**: CUPS drivers for PPA (HP-compatible GDI) printers.
- **cups-libs**: Libraries allowing applications to use CUPS natively.
- **curl**: A utility for getting files from remote servers using various Internet protocols.
- **curl-devel**: The files needed for building applications that use curl.
- **cvs**: The Concurrent Version System for maintaining a history of file changes.
- **cWnn**: A Chinese character input system.
