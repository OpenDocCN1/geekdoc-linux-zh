# # Gnome games

The Gnome games consist of some old text-based UNIX games, some card games, and a bunch of games that look suspiciously like games you would find on Windows systems. If you are afraid of losing your favorite desktop diversion (such as Solitaire, FreeCell, and Minesweeper) when you leave Windows, have no fear. You can find many of them under Gnome games.

Table 7-1 lists the games available by selecting Programs → Games from the Main Gnome menu.
