> **TIP:** If you press Tab and nothing completes, try pressing Tab again. Chances are that there are multiple completion possibilities. Pressing Tab again will show you those possibilities.

For more detailed information about the command line completion, you can read the contents of the `/etc/bash_completion` file. If you like, you can even add your own completion definition. Here is an example of a definition from the `/etc/bash_completion` file.

```
complete -f -X '!*.@(mp3|MP3)' mpg123
```

This definition shows that if you are using the mpg123 player, all files that have a `.mp3` or `.MP3` suffix should be matched for completion. To add your own definition, you could copy this line and replace `mpg123` with the name of an application you use, then replace `mp3` and `MP3` with the suffixes of files you want your application to match. (Add multiple pipe characters to add more suffixes.)

# Command line recall

After you type a command line, that entire command line is saved in your shell’s history list. The list is stored in a history file, from which any command can be recalled to run again. After it is recalled, you can modify the command line, as described earlier.

To view the contents of your history list, use the `history` command. You can either type the command without options or follow it with a number to list that number of the most recent commands. Here’s an example:

```
$ history 8
382 date
383 ls /usr/bin | sort -a | more
384 man sort
385 cd /usr/local/bin
386 man more
387 useradd -m /home/chris -u 101 chris
388 passwd chris
389 history 8
```
