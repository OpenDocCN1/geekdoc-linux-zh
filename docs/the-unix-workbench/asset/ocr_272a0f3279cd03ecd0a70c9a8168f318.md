Git and GitHub

```
```bash
git status
```
```

```
```text
On branch my-new-feature
nothing to commit, working tree clean
```
```

We can switch back to the master branch using git check-out:

```
```bash
git checkout master
```
```

```
```text
## Switched to branch 'master'
```
```

```
```bash
git branch
```
```

```
```text
## * master
##   my-new-feature
```
```

Now we can delete a branch by using the -d flag with git branch and the name of the branch we want to delete:

```
```bash
git branch -d my-new-feature
```
```

```
```text
## Deleted branch my-new-feature (was adef548).
```
```
