| Logical Operator | Meaning | Usage |
|---|---|---|
| `=~` | Matches Regular Expression | `[[ $constants =~ [aeiou] ]]` |
| `=` | String Equal To | `[[ $password = "pegasus" ]]` |
| `!=` | String Not Equal To | `[[ $fruit != "banana" ]]` |
| `!` | Not | `[[ ! "apple" =~ ^b ]]` |
