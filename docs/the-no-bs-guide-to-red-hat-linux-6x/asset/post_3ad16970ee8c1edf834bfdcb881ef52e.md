## WHAT'S ON THE CD-ROM?

The Red Hat Linux CD-ROM that comes with this book contains over 700 software packages. If you install all of them, you will have a very complete and robust Unix system at your disposal. Use this appendix as a handy guide for finding a tool to suit the task at hand.

If you followed the install guide in this book, you won't have all of these packages installed on your Linux system. To install packages from the CD-ROM or remove packages from your hard disk, use the rpm command from a Linux command line or the gnorpm command under X Windows. Gnorpm is a very friendly point-and-click application that guides you through the process. See Chapter 14, "Updating Your Linux System," for details on installing and removing software packages.
