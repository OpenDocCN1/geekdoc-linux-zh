
## DOCUMENTATION

This section lists packages that contain the documentation for Linux in general and Red Hat Linux in particular. These include FAQs, HOWTOs, man pages, and HTML-formatted help files. Almost all of these help files can be found on the Internet, but having them directly accessible on your Linux system can save you the time and trouble of searching for and downloading them.

- **XFRE86-DOC** Documentation on various X11 programming interfaces.
- **APACHE-MANUAL** Documentation for the Apache Web server.
- **BASH2-DOC** Documentation for the GNU Bourne Again shell (bash) 2.03.
- **GNOME-USERS-GUIDE** The GNOME Users’ Guide.
- **HELPTOOL** A graphical user interface tool which searches for help files.
- **INDEXHTML** The Web page you’ll see after installing Red Hat Linux.
- **INSTALL-GUIDE** The Linux Documentation Project Getting Started Guide in HTML format.
- **KDOC** Documentation for the K Desktop Environment (KDE) 2.0.
- **KERNEL-DOC** Various documentation bits found in the kernel source.
- **LPG** The LDP’s Linux programming guide in HTML format.
- **MAN-PAGES** Man (manual) pages from the Linux Documentation Project.
- **NAG** The Linux Documentation Project’s Network Administrators’ Guide.
- **PIRANHA-DOCS** Documentation for the Red Hat clustering environment.
- **PYTHON-DOCS** Documentation for the Python programming language.
- **SAG** The LDP’s System Administrators’ Guide in HTML format.
- **SENDMAIL-DOC** Documentation about the Sendmail Mail Transport Agent program.
- **SPECSPO** Red Hat package descriptions, summaries, and groups.

## SYSTEM ENVIRONMENT

This section lists packages that make up the Red Hat Linux base and system environment.

### BASE

This section lists packages pertaining to the base (core) of Linux.

- **MAKEDEV** A script for creating the device files in `/dev`.
- **SYSVINIT** Programs which control basic system processes.
- **ADJTIMEX** A utility for adjusting kernel time variables.
- **ANACRON** A cron-like program that can run jobs lost during downtime.
- **AUTHCONFIG** Text-mode tool for setting up NIS and shadow passwords.
- **BASESYSTEM** The skeleton package which defines a simple Red Hat Linux system.
- **CHKCONFIG** A system tool for maintaining the `/etc/rc.d` hierarchy.
- **CHKFONTpath** Simple interface for editing the font path for the X font server.
- **CRONTABS** Root crontab files used to schedule the execution of programs.
- **DEV** The most commonly-used entries in the `/dev` directory.
- **DHCPD** A DHCP (Dynamic Host Configuration Protocol) client.
- **e2fsprogs** Utilities for managing the second extended (ext2) filesystem.
- **EJECT** A program that ejects removable media using software control.
- **ETCSKEL** Red Hat Linux default files for new users' home directories.
- **FILESYSTEM** The basic directory layout for a Linux system.
- **GENROMFS** Utility for creating romfs filesystems.
- **INFO** A stand-alone TTY-based reader for GNU texinfo documentation.
- **INITSCRIPTS** The inittab file and the /etc/rc.d scripts.
- **IPCHAINS** Tools for managing Linux kernel packet filtering capabilities.
- **IPVSADM** Administration tool for Virtual Server.
- **ISAPNPTOOLS** Utilities for configuring ISA Plug-and-Play (PnP) devices.
- **JOYSTICK** Utilities for configuring most popular joysticks.
- **KBDCONFIG** A text-based interface for setting and loading a keyboard map.
- **KRB5-CONFIGS** Kerberos 5 sample configuration file(s).
- **KRB5-WORKSTATION** Kerberos 5 programs for use on workstations.
- **LD.SO** A dynamic loader for a.out format files.
- **LDCONFIG** Creates a shared library cache and maintains symlinks for ld.so.
- **LILO** The boot loader for Linux and other operating systems.
- **LOGROTATE** Rotates, compresses, removes, and mails system log files.
- **LOSETUP** Programs for setting up and configuring loopback devices.
- **MAILCAP** Associates helper applications with particular file types.
- **MAN-1** A set of documentation tools: man, apropos, and whatis.
- **MINGETTY** A compact getty program for virtual consoles only.
- **MKBOOTDISK** Creates an initial ramdisk image for preloading modules.
- **MKINITRD** Creates an initial ramdisk image for preloading modules.
- **MKKICKSTART** Writes a kickstart description of the current machine.
- **MKTEMP** A small utility for safely making /tmp files.
- **MOUNT** Programs for mounting and unmounting filesystems.
- **MOUSECONFIG** The Red Hat Linux mouse configuration tool.
- **NET-TOOLS** The basic tools for setting up networking.
- **NSS_LDAP** NSS library and PAM module for LDAP.
- **NTSYSV** A tool to set the stop/start of system services in a runlevel.
- **PAM** A security tool which provides authentication for applications.
- **PAM_KRB5** Kerberos 5 Pluggable Authentication Module.
- **PASSWD** The passwd utility for setting/changing passwords using PAM.
