# DEFINING A PPP CONNECTION

After setting up the name server, you can start the PPP configuration to connect to your ISP from Linux.
From the linuxconf main menu, choose Config • Networking • Client Tasks • PPP/SLIP/PLIP. Then click the Add button (see Figure 3-4).
Select the PPP option and then click Accept to continue (see Figure 3-5).

![](bbox=[0.26, 0.28, 0.48, 0.42])

Figure 3-4: Adding a new connection

![](bbox=[0.58, 0.27, 0.82, 0.42])

Figure 3-5: Adding a PPP interface

Enter your ISP's dial-up access number, your PPP log-in name, and your password (see Figure 3-6). If your ISP uses PAP Authentication, be sure to check the Use PAP Authentication box. In most cases, this completes the PPP connection setup.

NOTE: A new feature in the Red Hat version 6 release is a graphical PPP configurator, which can be accessed by clicking on Gnome Foot • Internet • Dialup Config Tool. You can use this as an alternative to the Linuxconf method, but I found in my testing that it had some bugs, so I don't recommend it.

![](bbox=[0.28, 0.71, 0.52, 0.8])

Figure 3-6: Defining a PPP interface

Your ISP's terminal server may present a dialog box with prompts like this (many do):

```

Please enter your password: <your password here>
Starting PPP ...
```
