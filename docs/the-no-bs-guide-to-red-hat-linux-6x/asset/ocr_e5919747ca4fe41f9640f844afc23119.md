# SETTING THE SYSTEM RUNLEVEL

The system runlevel settings control (see Figure 13-17) whether your system boots up in single-user mode (level 1), text mode (level 3), or graphical mode (level 5). Single-user mode boots with a minimal set of essential drivers and is typically used only in cases of emergency, similar to the Safe Mode of Windows 95/98. (Runlevels 2 and 4 are not used.)
