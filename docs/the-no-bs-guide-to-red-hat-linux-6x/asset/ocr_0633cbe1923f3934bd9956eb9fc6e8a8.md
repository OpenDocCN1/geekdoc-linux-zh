# REPARTITION YOUR HARD DISK?

Since you’re running DOS, it’s a given that your hard disk has at least one partition. (A partition is simply a division of your hard disk.) And unless you’re very adventurous, it’s almost a sure bet that your hard disk has a single DOS partition that occupies the entire disk.

Normally you need a separate partition for each operating system installed on a hard disk, but the latest version of Red Hat Linux offers you the option of installing Linux into your existing DOS partition. This partitionless installation method lets you avoid the hassle of creating disk partitions, but it brings a performance penalty. Linux will run a bit slower on a DOS partition than on a native Linux partition, and you’ll have to boot up Linux from a floppy disk.

If getting Linux up and running with a minimum of fuss is more important than optimal system performance, you should consider using the partitionless installation method. If speed is everything and disk partitioning doesn’t sound like a big deal, then you’ll probably want to do a traditional installation. I recommend that you read the next section and then decide which path to follow.

# DISK REPARTITIONING

If you want a traditional Linux installation, you’ll have to change the current partitioning of your disk so that there is room for a new partition (or two) for Linux. Note that in this step you will not be creating any Linux partitions, though you will use a DOS utility to reduce the size of an existing partition. (You’ll use a Linux utility later to create the Linux partitions.)
