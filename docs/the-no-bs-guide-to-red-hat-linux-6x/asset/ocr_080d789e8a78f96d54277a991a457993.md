This site is also home to a very comprehensive document called the Linux Network Administrator's Guide, which goes into great detail on SLIP and PPP connections, setting up your system to allow others to dial in, and security-related procedures you should follow.
You may also find some helpful tips in the "PPP Setup Tips" document from Red Hat, at http://support.redhat.com/docs/PPP-Client-Tips/PPP-Client-Tips.html.
These documents will be useful in answering any questions you may have about Linux networking, and I highly recommend them if you have trouble making a PPP connection, or if you plan to allow others to make PPP connections to your Linux machine.
