You may find it convenient to use a graphical text editor, since it allows you to manipulate text using the mouse, and Gnotepad+ offers two toolbars with buttons that can speed up common operations such as opening and closing files, printing, text entry, and cutting and pasting.

To start Gnotepad+, enter the command

```
gnp
```

from a shell prompt, or select the GNOME Foot • Applications • Gnotepad+ menu item. You can also add a Gnotepad+ button to your GNOME taskbar by choosing Gnome Foot • Panel • Add new launcher. Specify gnp as the program name, and pick an icon you like.

Additionally, you can define Gnotepad+ as the default editor to be started when you double-click a text file in File Manager. Choose Gnome Toolbox • Gnome Edit Properties and specify gnp as the program name.
