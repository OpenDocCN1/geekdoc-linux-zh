
## SHUT DOWN AND REBOOT

When you see the **Congratulations** screen, you're almost at the finish line. If you chose the partitionless install method, leave the boot disk in the floppy drive—otherwise remove it now. Press the **Exit** button to continue, and a bunch of messages will show various systems shutting down. Then you'll boot up into your grand and glorious new Linux system. You must **remove the installation CD** before the system reboots, or you may find yourself rerunning the install.

If you chose the text-mode shell prompt for your bootup option, a prompt like this will greet you:

```
[root@localhost /root] #
```

If you're familiar with Linux commands, you can enter them at the pound sign (#) prompt. Otherwise, use the **startx** command to start the GNOME graphical interface, and proceed to Chapter 2, "The Linux GUI."

## POST INSTALLATION: CONFIGURATION

After a successful Linux install, you need to take a few steps to get all your hardware working properly with Linux. In this section, you'll learn how to configure your printer, sound card, and CD-ROM drive.

### CONFIGURING A PRINTER

To configure a printer, enter the **printtool** command from a shell prompt, or click on **Gnome Foot • System • Control Panel**, then select the printer icon. When the **Print System Manager** window appears, click the **Add** button (Figure 1-16).

Linux will ask how the printer connects to your computer; the most likely response is **Local Printer**, which means it plugs directly into the back of your computer. If your printer is on a network, ask the administrator for the information needed to configure it for Linux. Press **OK** to continue.

On the **Edit Local Printer Entry** screen (Figure 1-17), leave the default values, and press the **Select** button to continue.

### CONFIGURING A SOUND CARD

To configure a sound card, enter the sndconfig command from a shell prompt. When the Sound Configuration Utility screen appears (Figure 1-19), press OK to probe your system. If the probe finds a sound card it can autoconfigure, it will do so. Otherwise you must select your sound card from a list and enter the port, IRQ, and DMA information. The information you got from the Windows Device Manager will help you here. After making your selections, sndconfig will play sound and music clips and ask if you could hear them. If not, go back and try different settings.

![](img/3137cdda7122042e86dbeafe9840d4ed_61_0.png)

Insert a music CD in the drive, and the **GNOME CD Player** should pop up and begin playing it. If you can’t get your sound card working, read the **SOUND-HOWTO** file in the `/doc/HOWTO` directory on the installation CD.

## ACCESSING FILES ON THE CD-ROM

After you issue the mount command, list the files on the CD-ROM to see if the mount worked, using these commands:

- `cd /mnt/cdrom`    Switch to the CD directory.
- `ls`    List the files on the CD.

If you try a device name in the mount command and get an error, or if your ls command doesn't display any files, just pick another device name and try again—you won't hurt anything.

For now, just be happy if you can list the files on the CD-ROM. In Chapter 4, "The Linux File System," you'll learn more about navigating directories, as well as about listing and viewing files.

## I NEED HELP!

If the installation does not work, or if you have trouble with your system after installation, refer to Chapter 15, "Learning More about Linux." You should also look at the Red Hat Installation manual on the CD for help with the most common installation problems if following the instructions in this chapter doesn't get you up and running. To view the manual, start your Web browser under Windows and open the file:

```
D:\doc\rhinst\index.htm
```

You will also find lots of helpful information, including the Linux FAQ (Frequently Asked Questions) files and the Linux HOWTO files, in these directories on the CD:

```
D:\doc\faq
D:\doc\howto
```
