If you have an existing version of Red Hat Linux (version 2.0 or higher), the install program will ask if you wish to upgrade it to version 6. If you select Upgrade, the install will preserve your existing system, and include only the items needed to bring you up to date.

## CREATE LINUX PARTITIONS

Now it's time to tell the installer in which partition(s) it should install Linux. To run Linux, you need a root partition and a swap partition. The root partition is where all your operating system and user data files reside. Linux uses the swap partition to simulate physical memory (installed RAM), in much the same way that Windows or a Macintosh uses a chunk of hard-drive space to create virtual memory.

## PARTITIONLESS INSTALLATION

If you've decided on a partitionless install, you'll see a screen like the one shown in Figure 1-9, with a single DOS partition listed. Remember, we're using a 3.2GB (3,200MB) hard disk for our example, so you may see different numbers. All you need to do here is set the mount point on the DOS partition, which tells the installer to use that partition for the install. Select the DOS (hda5) partition and press the Edit button. Change the mount point to / and press OK.

Press Next to continue, and the install asks you how much disk space on the DOS partition to devote to the Linux root and swap areas. The default for root is half of the available space, but you should enter a minimum of 800MB, 1,600MB to follow along with the example in this chapter, or more if you have a larger hard disk. Accept the default value for swap space, then press Next. The installer will create two new files (you can think of them as pseudo partitions) on the DOS partition (REDHAT.IMG and RH-SWAP.IMG) for the Linux installation. Skip ahead to the "Configuring a Network" section.

Your screen may show hda1, hda5, and hda6 partitions as shown in the illustration, or you may have hda1, hda2, and hda3. If you started with two hard drives and opted to put Linux on the second drive, you may have hda1, hdb1, and hdb2.

The important thing is to have one DOS partition, one Linux native (root) partition, and one Linux swap partition. If your hard drive is not the same size as the one in this example, it's fine to adjust the partition sizes accordingly or to suit your own preferences. Press Next to continue.

## FORMATTING THE PARTITIONS

Next you must confirm the formatting of your root partition. Select the box next to /dev/hda5 (the Linux root partition) to confirm, then press Next, and Linux will format the root partition.
