+   - New in Red Hat 6.2 — Partitionless install makes it easier than ever to install Linux!
+   - Configuring GNOME, the new Linux GUI!
+   - Using the Bash shell
+   - Linux commands like grep and awk
+   - Connecting to the Internet with PPP
+   - Running the Apache Web server
+   - Writing your own Bash or Perl scripts
+   - Accessing DOS files and running Windows programs under Linux

If you’re interested in exploring Red Hat Linux’s capabilities and features, and not just reading (and reading, and reading) about them, then *The No B.S. Guide to Red Hat Linux* is the book for you.
