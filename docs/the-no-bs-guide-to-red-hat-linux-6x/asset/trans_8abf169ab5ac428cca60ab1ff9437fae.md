## 压缩与归档

压缩文件时，你可以将其缩小到原始大小的一小部分，以便更高效地存储或传输给他人。压缩文件传输更快，在文件库中占用更少空间，但如果不先解压缩，你将无法打开或执行压缩文件。

当你将一堆文件合并到一个文件中时，你就是在创建归档。（不过，你不一定需要压缩这些文件。）归档很有用，因为它将相关的文件打包在一起，从而更容易分发一组相关文件——例如构成一个程序的文件。由于归档文件并不总是小于各部分之和，你有时会对归档使用压缩工具，从而得到压缩归档。

虽然zip是DOS和Windows下最常见的压缩格式，但Unix通常使用通过tar和gzip命令创建的文件。你肯定会遇到如下所示的文件名：

| 文件名 | 描述 |
|---|---|
| `something.tar` | 由tar创建的归档文件 |
| `something.gz` | 由gzip创建的压缩文件 |
| `something.tar.gz` | 压缩归档文件 |
| `something.tgz` | 与something.tar.gz相同 |

尽管gzip程序内置于所有Linux系统，但某些Unix系统可能不包含它，在这种情况下，会使用名为compress的较旧工具。由compress创建的文件名称类似这样。

`/dev/fd0` 条目是Linux对“软盘驱动器0”（DOS下的A驱动器）的称呼，`/dev/rmt0` 表示“可移动介质磁带0”，即你的主磁带驱动器。M标志表示使用多张软盘——当一张磁盘已满时，tar会提示你插入另一张。

要在创建tar文件时自动压缩，请添加z标志，如下所示：

```
tar cvzf alldocs.tar.gz *.doc
```

在此示例中，我向归档文件名添加了.gz后缀，因为z标志告诉tar使用与gzip命令相同的压缩方式。

要列出tar文件的内容，请在命令中使用t（type）标志，如下所示：

```
tar tvf alldocs.tar    List all files in alldocs.tar.
```

要从tar文件中提取内容，请在命令中使用x（extract）标志，如下所示：

```
tar xvf panda.tar    Extract files from panda.tar.
```

这会将panda.tar文件中的所有文件复制到当前目录。创建tar文件时，它可以打包目录中的所有文件，以及任何子目录及其中的文件。因此，在提取tar文件时，请记住你可能会在当前目录中得到一些新的子目录。

到目前为止，我们在示例tar命令中使用了几个不同的标志。以下是最常用标志的列表：

- `c` — 创建新归档。
- `t` — 列出归档内容。
- `x` — 提取归档内容。
- `f` — 在命令行中给出归档文件名（只要tar输出到文件就需要）。
- `M` — 归档可以跨多张软盘。
- `v` — 打印详细输出（在处理时列出文件名）。
- `u` — 如果文件比tar文件中的副本更新，则将其添加到归档中。
- `z` — 自动压缩或解压缩文件。
