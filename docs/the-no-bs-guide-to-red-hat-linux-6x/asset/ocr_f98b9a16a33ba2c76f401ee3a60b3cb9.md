# THEMES

Allows you to select a new theme for your desktop (see Figure 13-35). You can also find more themes on the Web at http://e.themes.org/. If you're wondering how this option differs from the theme selector in the GNOME Control Center, you get extra credit for paying attention. The GNOME themes affect only the look of applications written specifically for GNOME, whereas

Enlightenment themes affect the overall look of the desktop. The effect of using both theme selectors is cumulative.
