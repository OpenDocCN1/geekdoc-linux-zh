# SELECTING A MOUSE OPTION

When Linux presents you with a list of mouse options, choose the one that matches your system (Figure 1-5). In most cases, the install program will autodetect your mouse. If it doesn’t, and if you’re unsure of your mouse’s identity, look at the plug on the end of the cable. If it’s rectangular, you have a serial mouse. If it’s round, you have a PS/2-style mouse. Choose the corresponding Generic Mouse entry, depending on the number of buttons your mouse has. If you have a two-button mouse, select the Emulate 3 Buttons? box, and you can simulate the middle button by pressing the left and right buttons simultaneously. If you have a serial mouse, Linux will ask which port your mouse is connected to (Figure 1-6).
