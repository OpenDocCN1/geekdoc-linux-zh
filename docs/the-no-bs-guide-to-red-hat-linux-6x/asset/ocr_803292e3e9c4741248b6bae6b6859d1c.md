# TAKING INVENTORY

Not sure what hardware lurks in the heart of your computer? If you are running Windows 95/98, hold down the ALT key and click on the My Computer icon. A pop-up menu (Figure 1-1) should appear, showing the type of processor and the amount of installed RAM.

![](bbox=[0.28, 0.35, 0.77, 0.73])

Figure 1-1: Windows 95 System Properties

Next, click on the Device Manager tab (Figure 1-2). The System Properties window will show a list of your computer's hardware components. (Make sure the View devices by type button is selected.)
