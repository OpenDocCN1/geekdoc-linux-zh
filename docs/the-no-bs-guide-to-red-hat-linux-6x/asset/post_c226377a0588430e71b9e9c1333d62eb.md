
## DEVELOPMENT TOOLS

This section lists development tools that ease the process of developing software for specific applications or environments.

- **ElectricFence** A debugger which detects memory allocation violations.
- **AUTOCONF** A GNU tool for automatically configuring source code.
- **AUTOMAKE** A GNU tool for automatically creating Makefiles.
- **BINUTILS** A GNU collection of binary utilities.
- **BISON** A GNU general-purpose parser generator.
- **BLT** A Tk toolkit extension, including widgets, geometry managers, etc.
- **BUG-BUDDY** A GUI bug reporting tool for the GNOME GUI desktop.
- **BYACC** A public domain Yacc parser generator.
- **CDECL** Programs for encoding and decoding C and C++ function declarations.
- **COMPAT-BINUTILS** A GNU collection of binary utilities.
- **CPROTO** Generates function prototypes and variable declarations from C code.
- **CTAGS** A C programming language indexing and/or cross-reference tool.
- **CVS** A version control system.
- **DIFFSTAT** A utility which provides statistics based on the output of diff.
- **FLEX** A tool for creating scanners (text pattern recognizers).
- **GETTEXT** GNU libraries and utilities for producing multi-lingual messages.
- **CPP** The GNU C-Compatible Compiler Preprocessor.
- **DEV86** A real mode 80x86 assembler and linker.
- **EGCS** The GNU Compiler Collection.
- **EGCS-C++** C++ support for the gcc compiler.
- **EGCS-G77** Fortran 77 support for the gcc compiler.
- **EGCS-OBJC** Objective C support for the gcc compiler.
- **EXPECT** A Tcl extension for simplifying program-script interaction.
- **GNOME-OBJC** Objective C libraries for the GNOME desktop environment.
- **GUILE** A GNU implementation of Scheme for application extensibility.
- **ITCL** Object-oriented mega-widgets for Tcl.
- **JIKES** A Java source file to bytecode compiler.
- **KAFFE** A free virtual machine for running Java code.
- **LIBREP** An embeddable Lisp environment.
- **LIBREP-DEVEL** Include files and link libraries for librep development.
- **P2C** A Pascal to C translator.
- **PYGNOME-LIBGLADE** GNOME support for the libglade Python wrapper.
- **PYGTK** Python bindings for the GTK+ widget set.
- **PYGTK-LIBGLADE** A wrapper for the libglade library for use with PyGTK.
- **PYTHON** An interpreted, interactive object-oriented programming language.
- **REP-GTK** GTK+ binding for librep Lisp environment.
- **REP-GTK-LIBGLADE** Librep binding for the libglade library for loading user interfaces.
- **TCL** An embeddable scripting language.
- **TCLX** Tcl/Tk extensions for POSIX systems.
- **TIX** A set of capable widgets for Tk.
- **TK** The Tk GUI toolkit for Tcl, with shared libraries.
- **TKINTER** A graphical user interface for the Python scripting language.
- **UMB-SCHEME** An implementation of the Scheme programming language.

## SOFTWARE LIBRARIES

This section lists application-specific subroutine libraries, and code samples that ease the process of developing software for specific applications or environments.

- **IMAGEMAGICK-DEVEL** Static libraries and header files for ImageMagick app development.
- **MESA-DEVEL** Development files for the Mesa 3-D graphics library.
- **ORBIT-DEVEL** Development libraries, header files and utilities for ORBit.
- **XFREE86-DEVEL** X11R6 static libraries, headers and programming man pages.
- **XAW3D-DEVEL** Header files and static libraries for development using Xaw3d.
- **APACHE-DEVEL** Development tools for the Apache Web server.
- **AUDIOFILE-DEVEL** Libraries, includes, and other files to develop audiofile applications.
- **BIND-DEVEL** Include files and libraries needed for bind DNS development.
- **CDRECORD-DEVEL** The libschily SCSI user level transport library.
- **COMPAT-GLIBC** GNU libc for Red Hat Linux 5.2 backwards compatibility.
- **COMPAT-LIBS** Runtime and development libraries for Red Hat Linux 5.2 backwards compatibility.
- **CONTROL-CENTER-DEVEL** The GNOME Control Center development environment.
- **E2FSPROGS-DEVEL** Ext2 filesystem-specific static libraries and headers.
- **ESOUND-DEVEL** Development files for EsounD applications.
- **FNLIB-DEVEL** Headers, static libraries, and documentation for Fnlib.
- **FREETYPE-DEVEL** Header files and static library for development with FreeType.
- **GD-DEVEL** The development libraries and header files for gd.
