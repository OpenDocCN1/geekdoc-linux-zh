# LIBRARIES

This section lists the packages associated with the run-time libraries that are required to run programs under Red Hat Linux.

MESA A 3-D graphics library similar to OpenGL.

XFREE86-LIBS Shared libraries needed by X Windows 11 release 6.

XAW3D A version of the MIT Athena widget set for X.

AUDIOFILE A library for accessing various audio file formats.

CRACKLIB A password-checking library.

CRACKLIB-DICTS The standard CrackLib dictionaries.

FNLIB A color font rendering library for X11R6.

FREETYPE A free and portable TrueType font rendering engine.

GD A graphics library for drawing .gif files.

GDBM A GNU set of database routines which use extensible hashing.

GIMP-LIBGIMP Libraries for the GIMP (GNU Image Manipulation Program).

GLIB A library of handy utility functions.

GLIB10 A library of handy utility functions.
