# USING MINICOM

Minicom is a communications program, similar to Telix or Procomm. It’s not really an Internet tool, but you can use it to dial in to your shell account or access a bulletin board system. Use the **minicom** command to start this program.

# GRAPHICAL INTERNET TOOLS FOR X WINDOWS

For those who prefer point and click to hunt and peck, Red Hat Linux provides you with graphical tools to handle your email and explore the Web. This section introduces you to some graphical tools for email, Web browsing, FTP, and IRC. All of these are free and already installed on your system.
