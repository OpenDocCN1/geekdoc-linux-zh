## MORE ABOUT GNOTEPAD+

Gnotepad+ 是免费软件，在 GNU 通用公共许可证下开发和分发，这意味着你可以查看源代码并向开发者贡献自己的更新。该程序由 Andy Kahn 编写和维护，他有一个 Gnotepad+ 网站，网址为 http://ack.netpedia.net/gnp/。

## THE GEDIT EDITOR

gEdit 编辑器（见图 7-14）是另一款为 X Windows GNOME 环境设计的文本编辑器。它支持用户编写的插件，这使得 gEdit 可以扩展以支持新功能，同时保持核心程序的体积小。它还支持多文档，当然也支持诸如搜索
