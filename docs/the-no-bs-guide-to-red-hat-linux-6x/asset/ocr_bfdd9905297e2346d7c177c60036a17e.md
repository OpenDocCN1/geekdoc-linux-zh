# ADDING NEW USERS

Use the screen shown shown in Figure 13-13 to add new users to your system. Only the "Login name" field is mandatory, but it's a good idea to fill in the "Full name" field as well, so you can remember the real names of your users. If the new users want a command shell other than Bash, select it from the "Command interpreter" list. After you press the "Accept" button, you will be prompted to enter the initial password for the new account.
