## 术语表

本术语表将在你探索 Linux 时提供帮助。你在 Unix 和互联网上游历时无疑会遇到其中许多术语，因此现在就熟悉你的极客用语，当缩写开始飞来时，你就会做好准备。

**匿名 FTP** 任何人无需用户 ID 或密码即可访问的公共文件档案。

**Archie** 用于在匿名 FTP 站点搜索文件的基于互联网的软件。

**文章** 发布到 Usenet 新闻组的留言；参见 *post*。

**ASCII（美国信息交换标准代码）** 一组 128 个标准字符，保证在任何计算机上以相同方式显示。ASCII 字符集由数字、字母和其他特殊字符组成，你可以在标准美国键盘上找到。非 ASCII 字符的例子有 ü、é、å 和 £。

**附件** 附加到电子邮件消息的文件。附件通常是图形、压缩文档或程序。

**Bash** Bourne Again Shell 的缩写，是默认的 Linux shell。

**后台** 在后台运行的任务，不允许用户交互。另见 *前台*。

**带宽** 网络一次可以发送或接收的数据量的度量。把带宽想象成数据从一台计算机流向另一台计算机所通过的管道的大小。

**BBS（公告板系统）** 你可以拨号访问以获取文件并参与电子讨论的计算机。与互联网不同，BBS 不总是联网，并且通常要求你拥有密码或会员资格才能访问。

**二进制文件** 包含除纯文本（ASCII 字符）之外内容的的文件，例如程序或图形。

**位** 计算机处理的基本数据单位。位的值可以是 1 或 0。

**反弹** 无法投递并被退回的电子邮件消息被称为反弹。

浏览器 如世界宽域网浏览器；像 Netscape、Mosaic 或 Lynx 这样的软件，用于显示世界宽域网文档。

客户端 也称为客户端软件。使你的计算机连接到另一台（服务器）计算机的软件。

压缩 将文件压缩以节省存储空间并减少传输时间。Unix 的常见压缩工具是 gzip 和 zip。你经常会在互联网上找到以压缩文件形式分发的软件包。

Copyleft 任何重新分发软件的人，无论是否更改，都必须传递进一步复制和更改它的自由的想法。

交叉发布 将同一消息发布到多个 Usenet 新闻组。

当前目录 你当前正在工作的目录。你可以使用 pwd 命令显示其值。

网络空间 一个术语，由威廉·吉布森在科幻小说《神经漫游者》中创造。虽然通常用于指互联网，但它描述了参与任何计算机网络时所占据的虚拟空间。

守护进程 在特定事件发生时执行预定义操作的后台进程。一个例子是打印机守护进程，它管理打印队列。（发音类似恶魔。）

目录 相关文件被分组的地方。目录可能包含文件或子目录（第一层以下的目录），从而形成树状的文件组织。

域名 分配给互联网上计算机的名称（例如，http://www.snarch.com）。域名上的后缀告诉你操作该系统的组织类型（例如，com = 商业，edu = 大学，gov = 政府，mil = 军事，org = 组织）。有时组织类型后面会跟一个两位字符的国家代码（au = 澳大利亚，例如 outback.edu.au）。

下载 你从另一台计算机向自己的计算机传输文件时所做的事情。常见用法是指将文件从公共库移动到个人空间。
