## DAEMONS

This section lists packages associated with the daemons (background processes) that run under Red Hat Linux.

**ORBIT**  A high-performance CORBA Object Request Broker.

**XFRE86-XFS**  A font server for X Windows.

**AM-UTILS**  Automount utilities, including an updated version of Amd.

**ANONFTP**  A fast, read-only, anonymous FTP server.

**APACHE** The most widely used Web server on the Internet.

**APMD** Advanced Power Management (APM) BIOS utilities for laptops.

**AT** Job spooling tools.

**AUTOFS** A tool for automatically mounting and unmounting filesystems.

**BDFLUSH** The daemon which starts the flushing of dirty buffers back to disk.

**BIND** A DNS (Domain Name System) server.

**BOOTPARAMD** A server process which provides boot information to diskless clients.

**CACHING-NAMESERVER** The configuration files for setting up a caching name server.

**CLEANFEED** A spam filter for Usenet news servers.

**COMSAT** A mail checker client and the comsat mail checking server.

**DHCP** A DHCP (Dynamic Host Configuration Protocol) server and relay agent.

**ESOUND** Allows several audio streams to play on a single audio device.

**FINGER-SERVER** The finger daemon.

**GATED** The public release version of the GateD routing daemon.

**GPM** A mouse server for the Linux console.

**IMAP** Server daemons for IMAP and POP network mail protocols.

**INETD** The inetd networking program.

**INEWS** Sends Usenet articles to a local news server for distribution.

**INN** The InterNetNews (INN) system, a Usenet news server.

**TFTP-SERVER** The server for the Trivial File Transfer Protocol (TFTP).

**TIMED** Programs for maintaining networked machines' time synchronization.

**UCD-SNMP** A collection of SNMP protocol tools from UC-Davis.

**WU-FTPD** An FTP daemon provided by Washington University.

**WVDIAL** A heuristic autodialer for PPP connections.

**XNTP3** Synchronizes system time using the Network Time Protocol (NTP).

**YPBIND** The NIS daemon which binds NIS clients to an NIS domain.

**YPSERV** The NIS (Network Information Service) server.

## KERNEL

This section lists packages that are related to the Linux kernel on which Red Hat Linux is based.

**KERNEL** The Linux kernel (the core of the Linux operating system).

**KERNEL-BOOT** The version of the Linux kernel used on installation boot disks.

**KERNEL-IBCS** Files which allow iBCS2 programs to run.

## LIBRARIES

This section lists the packages associated with the run-time libraries that are required to run programs under Red Hat Linux.

**MESA** A 3-D graphics library similar to OpenGL.

**XFREE86-LIBS** Shared libraries needed by X Windows 11 release 6.

**XAW3D** A version of the MIT Athena widget set for X.

**AUDIOFILE** A library for accessing various audio file formats.

**CRACKLIB** A password-checking library.

**CRACKLIB-DICTS** The standard CrackLib dictionaries.

**FNLIB** A color font rendering library for X11R6.

**FREETYPE** A free and portable TrueType font rendering engine.

**GD** A graphics library for drawing .gif files.

**GDBM** A GNU set of database routines which use extensible hashing.

**GIMP-LIBGIMP** Libraries for the GIMP (GNU Image Manipulation Program).

**GLIB** A library of handy utility functions.

**GLIB10** A library of handy utility functions.
