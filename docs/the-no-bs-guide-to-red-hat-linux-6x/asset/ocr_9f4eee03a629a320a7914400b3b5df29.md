The first time you use Tin, it will download a huge list of all available newsgroups from your ISP's server, so don't be surprised if it takes several minutes for the first screen to appear.
For more information on using Tin, use the man tin command to read the excellent online help for this program.

# USING LYNX

Lynx is a text-based Web browser. You don't get to see the graphics on a Web page, but for some people, that's a plus. Many Web pages are loaded with gratuitous images that take forever to load and add little or no real value.
