
## CREATE A LINUX BOOT FLOPPY

If it turns out you can't boot directly from the CD or access the CD-ROM drive from the DOS prompt, you must create a Linux boot floppy. To do so, return to Windows and start a DOS prompt. Insert a formatted diskette into drive A and enter these commands:

```
D:
cd \dosutils
rawrite -f \images\boot.img -d A:
```

When the rawrite program finishes, leave the floppy in the A drive and reboot your computer. The installation program will start, and the CD-ROM whirs into action. When you see the boot: prompt, just press ENTER to continue.

## WHAT IF MY CD-ROM DOESN’T WHIR?

The Linux installation program may not detect some older or nonstandard CD-ROM drives automatically. If your CD-ROM drive plugs into a sound card or a special interface card that came with the drive, you may run into this trouble. If you get a message indicating that Linux could not detect your CD-ROM, start over and enter a parameter from the table below at the boot: prompt. (If your model doesn’t appear in the table, try searching for information at the Red Hat Web site, http://support.redhat.com/hardware/.)

| CD-ROM TYPE | PARAMETER |
|---|---|
| Aztech CD268-0A, Orchid CD-3110 | aztcd=\<io_port\> |
| Goldstar R420 CD-ROM | gscd=\<io_port\> |
| Mitsumi CD-ROM | mcd=\<io_port\>,\<IRQ\> |
| Philips/LMS CDROM drive 206 | cm206=\<io_port\>,\<IRQ\> |
| Sony CDU 31A or 33A CD-ROM | cdu31a=\<io_port\>,\<IRQ\> |
| Sony CDU-535 and 531 | sonycd535=\<io_port\> |
| SoundBlaster Compatible | sbpcd=\<io_port\>, SoundBlaster |

Replace <io_port> and <IRQ> with the correct values for your hardware, as shown in the examples that follow:

- Sony CDU 31A/33A: `cdu31a=0x220,5`
- SoundBlaster Compatible: `sbpcd=0x320,SoundBlaster`

## START THE LINUX INSTALL PROGRAM

When Linux starts, a whole bunch of stuff will flash across the screen. Unless you did really well in that Evelyn Wood speed reading program, you won't be able to read much of it, but that's okay. Don't be alarmed if your screen goes blank for a little while. After a few moments, you'll be greeted by a series of screens that will guide you through the installation process. On each screen, you'll make a choice and then select Next to continue. You can use your mouse or the TAB and arrow keys to navigate and make selections. The install program will ask you some questions about your hardware in this start-up phase—here's how to respond.

## SELECTING A LANGUAGE

If you are asked to choose a language (Figure 1-3), English is probably your best bet, unless you happen to be more comfortable with German or Turkish. Select the appropriate language, then press Next, tab to the OK button, and press ENTER or F12 to continue.

## SELECTING A MOUSE OPTION

When Linux presents you with a list of mouse options, choose the one that matches your system (Figure 1-5). In most cases, the install program will autodetect your mouse. If it doesn’t, and if you’re unsure of your mouse’s identity, look at the plug on the end of the cable. If it’s rectangular, you have a serial mouse. If it’s round, you have a PS/2-style mouse. Choose the corresponding Generic Mouse entry, depending on the number of buttons your mouse has. If you have a two-button mouse, select the Emulate 3 Buttons box, and you can simulate the middle button by pressing the left and right buttons simultaneously. If you have a serial mouse, Linux will ask which port your mouse is connected to (Figure 1-6).
