
## APPLICATIONS

This section lists the packages that contain various archiving, communications, database, editor, emulation, engineering, file management, Internet, multimedia, productivity, publishing, system management, and text processing applications for Red Hat Linux.

### ARCHIVING

This section lists packages that are associated with the efficient storage or copying of files.

- CDRECORD A command line CD/DVD recording program.
- CPIO A GNU archiving program.
- DUMP Programs for backing up and restoring filesystems.
- DUMP-STATIC Programs for backing up and restoring filesystems.
- NCOPRESS Fast compression and decompression utilities.
- RMT Provides certain programs with access to remote tape devices.
- SHARUTILS The GNU shar utilities for packaging and unpackaging shell archives.
- TAPER A menu-driven file backup system.
- TAR A GNU file archiving program.
- UNARJ An uncompressor for .arj format archive files.
- UNZIP A utility for unpacking zip files.
- ZIP A file compression and packaging utility compatible with PKZIP.

### COMMUNICATIONS

This section lists packages that are associated with communications.

- DIP Handles the connections needed for dialup IP links.
- EFAX A program for faxing using a Class 1, 2, or 2.0 fax modem.
- GETTY_PS The getty and ugetty programs.
- GKERMIT A utility for transferring files using the Kermit protocol.
- KPILOT Pilot synchronization tools for KDE.
- LRZSZ The lrz and lsz modem communications programs.
- MGETTY A getty replacement for use with data and fax modems.
- MGETTY-SENDFAX Provides support for sending faxes over a modem.
- MGETTY-VIEWFAX An X Windows fax viewer.
- MGETTY-VOICE A program for using your modem and mgetty as an answering machine.
- MINICOM A text-based modem control and terminal emulation program.
- PILOT-LINK File transfer utilities between Linux and Palm Pilots.
- SLIPLOGIN A login program for SLIP connections.
- UUCP The uucp utility for copying files between systems.

### CRYPTOGRAPHY

This section lists packages that can be used in the GNOME environment to secure data and communications using encryption.

- GNUPG A GNU utility for secure communication and data storage.
- GPGP GNOME frontend for GNU Privacy Guard.

### DATABASES

This section lists packages that are associated with databases.

- POSTGRESQL PostgreSQL client programs and libraries.
- POSTGRESQL-JDBC Files needed for Java programs to access a PostgreSQL database.
- POSTGRESQL-ODBC The ODBC driver needed for accessing a PostgreSQL DB using ODBC.
- POSTGRESQL-PERL Development module needed for Perl code to access a PostgreSQL DB.
- POSTGRESQL-PYTHON Development module for Python code to access a PostgreSQL DB.
- POSTGRESQL-SERVER The programs needed to create and run a PostgreSQL server.
- POSTGRESQL-TCL A Tcl-based GUI front end for psql and related PostgreSQL clients.
- POSTGRESQL-TEST The test suite distributed with PostgreSQL.

### EDITORS

This section lists packages that are associated with the editing of text files.

- GXEDIT A multi-function text editor which uses GTK+.
- EMACS The libraries needed to run the GNU Emacs text editor.
- EMACS-X11 The Emacs text editor for X Windows.
- EMACS-EL The sources for elisp programs included with Emacs.
- EMACS-LEIM Emacs Lisp code for input methods for international characters.
- EMACS-NOX The Emacs text editor without support for X Windows.
- GEDIT A small but powerful text editor for GNOME.
- GNOTEPAD+ A small and simple but versatile text editor for X.
- JED A fast, compact editor based on the S-Lang screen library.
- JED-COMMON Files needed by any Jed text editor.
- JED-XJED The X Windows version of the jed text editor.
- JOE An easy to use, modeless text editor.
- PSGML A GNU Emacs major mode for editing SGML documents.
- VIM-X11 The ViM version of the vi editor for X Windows.
- VIM-COMMON The common files needed by any version of the ViM editor.
- VIM-ENHANCED A version of the ViM editor which includes recent enhancements.
- VIM-MINIMAL A minimal version of the ViM editor.

### ENGINEERING

This section lists packages that are associated with engineering and mathematics.

- BC GNU's bc (a numeric processing language) and dc (a calculator).
- GNUPLOT A program for plotting mathematical expressions and data.
