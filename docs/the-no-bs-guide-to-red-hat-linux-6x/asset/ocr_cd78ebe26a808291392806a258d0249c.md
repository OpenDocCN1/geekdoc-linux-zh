Xconfigurator may ask how much video memory is installed on your video card. If you don't know, check the documentation. It won't hurt if you guess wrong but X Windows may not start correctly. If the video card you selected might have a video clockchip, Xconfigurator presents a list of clockchips. The recommended choice is the No Clockchip setting, since Linux can detect the proper clockchip in most cases.

# CUSTOMIZING THE X CONFIGURATION

If you select the Customize X Configuration checkbox and press Next, Xconfigurator then prompts you to select the video modes you wish to use. For most people, 800 by 600 with 16-bit color will do nicely. If your monitor and video card support higher resolutions, go for it. If you select more than one video mode, you can cycle through the modes by pressing CTRL-ALT-PLUS while running X Windows.
When you are finished, Xconfigurator records all of your configuration choices in the /etc/X11/XF86Config file. You may find it interesting to browse this file, but unless you really know what you're doing, don't make any changes to it.
Use the Test Configuration button to verify that your X configuration works. If you can't get X Windows running, or if the display looks poor (too big, too small, wrong colors, and so on), you can run the Xconfigurator command again after installation, and try different setup options later.

# START X WINDOWS AT BOOT TIME?

If you want a fully graphical interface, check the Use Graphical Login button before pressing the Next button, and your system will start in X Windows mode when you boot up. If you don't select a graphical login, the text-mode shell prompt will appear at start-up. After logging in, you can use the startx command to fire up X Windows.
