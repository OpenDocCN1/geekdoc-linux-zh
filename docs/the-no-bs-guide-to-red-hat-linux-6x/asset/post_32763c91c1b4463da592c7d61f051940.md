## Desktops

This section lists packages that are associated with the desktop environments available on Red Hat Linux.

- **AfterStep** An X window manager which emulates the look and feel of NEXTSTEP(R).
- **AfterStep-APPS** Various applets for use with AfterStep and compatible window managers.
- **AnotherLevel** A customized configuration of the fvwm2 window manager.
- **WindowMaker** A window manager for X Windows.
- **CONTROL-CENTER** The GNOME Control Center.
- **ENLIGHTENMENT** The Enlightenment window manager.
- **ENLIGHTENMENT-CONF** The Enlightenment window manager configuration tool.
- **FVWM2** An improved version of the FVWM window manager for X.
- **KDEBASE** Core files for the K Desktop Environment (KDE).
- **KDEBASE-3D-SCREENSAVERS** 3-D (OpenGL) screensavers for the K Desktop Environment.
- **KDEBASE-LOWCOLOR-ICONS** Low color (8-bit display friendly) icons for KDE.
- **KDESUPPORT** Support libraries for the K Desktop Environment (KDE).
- **SAWMILL** An extensible window manager for X Windows.
- **SAWMILL-GNOME** GNOME support for the sawmill window manager.
- **SAWMILL-THEMER** A GUI for creating sawmill window manager themes.
- **SWITCHDESK** A desktop environment switcher for GNOME, KDE, and AnotherLevel.
- **SWITCHDESK-GNOME** A GNOME interface for the Desktop Switcher.
- **SWITCHDESK-KDE** A KDE interface for the Desktop Switcher.
- **WMAKERCONF** A configuration tool for the Window Maker window manager for X.
- **WMCONFIG** A helper application for configuring X window managers.

## X-Hardware-Support

This section lists packages that are associated with hardware support for specific video cards under Red Hat Linux.

- **XFree86-3DLabs** The XFree86 server for 3Dlabs video cards.
- **XFree86-8514** The XFree86 server program for older IBM 8514 or compatible video cards.
- **XFree86-AGX** The XFree86 server for AGX-based video cards.
