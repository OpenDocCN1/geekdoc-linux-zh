
## FILE MANAGEMENT

This section lists packages that are associated with file manipulation.

- BZIP2 A file compression utility.
- FILE A utility for determining file types.
- FILEUTILS The GNU versions of common file management utilities.
- FINDUTILS The GNU versions of find utilities (find and xargs).
- GIT A set of GNU Interactive Tools.
- GZIP The GNU data compression program.
- SLOCATE Finds files on a system via a central database.
- STAT A tool for finding out information about a specified file.
- TREE A utility which displays a tree view of the contents of directories.

## INTERNET

This section lists packages that are associated with the Internet.

- ELM The elm mail user agent.
- EXMH The exmh mail handling system.
- FETCHMAIL A remote mail retrieval and forwarding utility.
- FETCHMAILCONF A GUI utility for configuring your fetchmail preferences.
- FINGER The finger client.
- FTP The standard UNIX FTP (File Transfer Protocol) client.
- FWHOIS A finger-style whois program.
- GFTP A multi-threaded FTP client for X Windows.
- IRCII An Internet Relay Chat (IRC) client.
- KDENETWORK Network applications for the K Desktop Environment (KDE).
- KPP PLOAD A PPP connection load monitor for KDE.
- LYNX A text-based Web browser.
- MAILX The /bin/mail program, which is used to send mail via shell scripts.
- METAMAIL A program for handling multimedia mail using the mailcap file.
- MUTT A text mode mail user agent.
- NC Reads and writes data across network connections using TCP or UDP.
- NCFTP An improved FTP client.
- NETSCAPE-COMMON Files shared by the Netscape Navigator and Communicator.
- NETSCAPE-COMMUNICATOR A Web browser, news reader, and email client.
- NETSCAPE-NAVIGATOR The Netscape Navigator Web browser.
- NMH A capable mail handling system with a command line interface.

## MULTIMEDIA

This section lists packages that are associated with multimedia.

- **IMAGEMAGICK** An X application for displaying and manipulating images.
- **AUMIX** An ncurses-based audio mixer.
- **AWESFX** Utility programs for the AWE32 sound driver.
- **CDDA2WAV** A utility for sampling/copying .wav files from digital audio CDs.
- **CDP** An interactive text-mode program for playing audio CD-ROMs.
- **CDPARANOIA** A Compact Disc Digital Audio (CDDA) extraction tool.
- **DESKTOP-BACKGROUNDS** Desktop background images.
- **EE** The Electric Eyes image viewer application.
- **EXTACE** A GNOME sound displayer.
- **GIFTRANS** A program for making transparent GIFs from non-transparent GIFs.
- **GIMP** The GNU Image Manipulation Program.
- **GIMP-DATA-EXTRAS** The GNU Image Manipulation Program.
- **GNOME-AUDIO** Sounds for GNOME events.
- **GNOME-MEDIA** GNOME media programs.
- **KDEGRAPHICS** K Desktop Environment - Graphics Applications.
- **KDEMULTIMEDIA** Multimedia applications for the K Desktop Environment (KDE).
- **LIBGR-PROGS** Tools for manipulating graphics files in libgr supported formats.
- **LIBUNGIF-PROGS** Programs for manipulating GIF format image files.
- **MIKMOD** A MOD music file player.
- **MPG123** An MPEG audio player.
- **MULTIMEDIA** Several X utilities mainly for use with multimedia files.
- **PLAYMIDI** A MIDI sound file player.
- **PLAYMIDI-X11** An X Windows-based MIDI sound file player.
- **SNDCONFIG** The Red Hat Linux sound configuration tool.
- **SOX** A general-purpose sound file conversion tool.
- **TRANSFIG** A utility for converting FIG files (made by xfig) to other formats.
- **XFIG** An X Windows tool for drawing basic vector graphics.
- **XMMS** An MP3 player for X which resembles Winamp.
- **XMMS-GNOME** A GNOME panel applet for the Xmms multimedia player.
- **XPAINT** An X Windows image editing or paint program.
