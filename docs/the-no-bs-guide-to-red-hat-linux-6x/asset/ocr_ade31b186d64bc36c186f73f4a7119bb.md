# CONFIGURING YOUR SYSTEM FOR PRINTING

Red Hat Linux comes with a nice graphical printer configuration utility that will create the necessary system files to set up your printer. After logging in as root and starting X Windows, choose Gnome Foot • AnotherLevel Menus • Administration • Printer Tool and then follow these steps:

+   1. Click the “Add” button; the Printer Type window appears. (See Figure 6-6.)
+   2. Pick “Local Printer” and then click OK; a second pop-up window appears. (See Figure 6-7.)
