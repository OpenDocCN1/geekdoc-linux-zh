## CONFIGURING THE SYSTEM CLOCK

Choose your time zone from the list and then select OK (Figure 1-12). Generally, you do not want to select the System clock uses UTC box, unless you are on a network.

## CHOOSE A ROOT PASSWORD

When you start Linux after installation, you’ll log in with the username root and a password you choose. If you plan to let others use your Linux system, make sure to choose a root password they can’t easily guess (Figure 1-13). Pick a winner, and enter it in the **Root Password** and **Confirm** boxes.

Because the root user (also called the superuser) has complete access to everything on a Linux system, you should use this option only for system administration tasks such as installing new software and configuring system services. You can also use this screen to add additional user accounts for everyday tasks. If more than one person in the home or office will be using Linux, give each person his or her own account.

## CONFIGURE X WINDOWS

At this point, the installation program starts the Xconfigurator (the X Windows configuration program), which will probe your system to figure out what type of monitor and video card you have and install the proper XFree86 server. XFree86 is a freeware implementation of the X Windows system for PC-compatible processors and is part of the GNU project.

## DEFINING YOUR MONITOR

After a video card is selected, if Xconfigurator could autodetect your monitor, the device's name appears. If not, Xconfigurator displays a list of monitors from which you must make a selection. If your monitor is on the list, select it. If it's not on the list and you have the manufacturer's technical specifications, select Custom, and Xconfigurator will prompt you to select the characteristics of your monitor. Be careful, though—if you select a monitor “similar” to yours, and your monitor can't handle a certain display mode, it's possible to damage the monitor. A safer choice would be Generic Monitor or Generic Multisync.

## DEFINING YOUR VIDEO CARD

If Xconfigurator can tell which video card you have and how much video memory is installed, it displays this information in a screen showing the name of your card (Figure 1-14). Just press ENTER to continue.

If Xconfigurator cannot autodetect your video card, it displays a list of video cards from which you must make a selection. If your video card does not appear on the list, Linux may not support it. However, if you have the technical documentation for your card, you can choose Unlisted Card and try to configure it by closely matching your card's video chip set with the options Xconfigurator presents.

Xconfigurator may ask how much video memory is installed on your video card. If you don't know, check the documentation. It won't hurt if you guess wrong but X Windows may not start correctly. If the video card you selected might have a video clockchip, Xconfigurator presents a list of clockchips. The recommended choice is the No Clockchip setting, since Linux can detect the proper clockchip in most cases.

## CUSTOMIZING THE X CONFIGURATION

If you select the Customize X Configuration checkbox and press Next, Xconfigurator then prompts you to select the video modes you wish to use. For most people, 800 by 600 with 16-bit color will do nicely. If your monitor and video card support higher resolutions, go for it. If you select more than one video mode, you can cycle through the modes by pressing CTRL-ALT-PLUS while running X Windows.

When you are finished, Xconfigurator records all of your configuration choices in the /etc/X11/XF86Config file. You may find it interesting to browse this file, but unless you really know what you're doing, don't make any changes to it.

Use the Test Configuration button to verify that your X configuration works. If you can't get X Windows running, or if the display looks poor (too big, too small, wrong colors, and so on), you can run the Xconfigurator command again after installation, and try different setup options later.

## START X WINDOWS AT BOOT TIME?

If you want a fully graphical interface, check the Use Graphical Login button before pressing the Next button, and your system will start in X Windows mode when you boot up. If you don't select a graphical login, the text-mode shell prompt will appear at start-up. After logging in, you can use the startx command to fire up X Windows.
