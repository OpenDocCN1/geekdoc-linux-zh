Here is another example: The wc command is used to display the number of characters, words, and lines in a text file. You can provide a file name for wc to process, or you can pipe data into it from another command. In the following command, the wc command displays the number of characters, words, and lines in the output of the ls command (The number of lines show the number of items in the directory.)

```
$ ls /etc | wc
```

By combining the features of STDIN, STDOUT, and STDERR with the ability to redirect these communication channels and use pipes, each Linux utility can interact with other utilities and files to handle complex tasks for users and system administrators. Table 3-2 shows the special characters used on the Linux command line to instruct the shell to redirect communication between programs.

# Table 3-2 Redirecting Input and Output

| Symbol to use in a command statement | Description | Command-line example |
| > filename | Writes STDOUT output to the given file name | ls -l > savelisting |
| >> filename | Appends STDOUT output to the given file name (adding it to the end of any existing file contents) | cat newfile >> existing_file |
