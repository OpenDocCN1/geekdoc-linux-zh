# Project 6-1

In this project, you explore how signals sent with the kill command interact with running processes. To complete this project you should have an installed Linux system with root access.

+   1. Log in as root and open a command-line window.
+   2. Switch to the third virtual console by pressing Ctrl+Alt+F3 if you are working in a graphical environment or Alt+F3 if you are working in text mode.
+   3. Log in to virtual console 3 using a regular user account.
+   4. View a man page in virtual console 3 by using this command:
+   $ man mount
+   5. Switch back to where you logged in for Step 1 by pressing either Alt+F1 or Alt+F7. Log in as root.
