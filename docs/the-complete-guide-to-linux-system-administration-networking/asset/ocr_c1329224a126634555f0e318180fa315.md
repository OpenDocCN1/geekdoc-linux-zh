The lpd daemon is configured by options in /etc/lpd.conf. Typically, lpd is not used in an environment where security is a big concern, because it is not considered highly secure. But you can set permissions for numerous lpd functions using /etc/lpd.perms. Both lpd.conf and lpd.perms have complete man pages describing lpd configuration options.
