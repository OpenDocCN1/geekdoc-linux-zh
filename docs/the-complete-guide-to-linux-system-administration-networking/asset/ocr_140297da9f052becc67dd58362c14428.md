The set command displays a list of all environment variables defined in your current environment. Sample output of the set command for a regular user (not root) on Red Hat Linux is shown below. Many variables listed by set are used by system processes with which you are not yet familiar, but you will recognize some of them. For example, the PWD variable contains the value of the current working directory. When you execute the pwd command, the value of this environment variable is displayed on the screen. When you use the cd command, the value of this environment variable is updated.
