# Table 6-1 ps Options Used to Select Processes to Display (continued)

| Option | Description |
|---|---|
| r | Restricts output to running processes (those that are not sleeping); this option is used in conjunction with another selection option |
| -C | Selects processes by the command used to start the process; to use this option, you need to follow it with the name of the command |
| -p | Selects processes by PID number; to view information on a single process, enter its PID number as a value after the option |
| --user | Selects processes by user name; to use this option, type the user name after the option |
| --group | Selects all processes belonging to users who are members of the group named after the option |

For example, while logged in as root (note the # prompt) you could use the following command to list all processes owned by user jtaylor:

```
# ps --user jtaylor
```

You can select which pieces of information (sometimes called fields) ps displays for each process by adding command-line options such as those shown in Table 6-2. Many of the unfamiliar terms in the Description column (such as "nice level") are discussed later in this chapter. A few are used only for special troubleshooting or programming tasks—refer to the ps man page for more information on these.
