# The Complete Guide to
Linux System Administration

*The Complete Guide to Linux System Administration* is a hands-on, practical guide that can be used to master installing and administering Linux, in preparation for taking any of three popular Linux certification exams: Red Hat Certified Technician, CompTIA's Linux+, or the Linux Professional Institute Level 1 certification. This book also maps to the first two exams of the SAIR/GNU LCA certification. The book introduces operating system concepts with a brief history of the Linux movement, then moves on to user-oriented tasks such as logging in, using the graphical interface, and navigating the file system. Comprehensive coverage of the command line includes vi, shell scripting, text processing, and advanced process management and file system tools. More advanced administration tasks are also presented, including user account management, file system creation and management, backup strategies, system initialization, network configuration and troubleshooting, and reconfiguring the Linux kernel. Each topic is supported by thorough explanations and real-world examples, review questions, hands-on projects, and extensive case projects.

# Key Features of The Complete Guide to Linux System Administration:

+   - Maps completely to the Red Hat Certified Technician (RHCT) exam, CompTIA's Linux+ exam, and the Linux Professional Institute (LPI) Level 1 certification exam.
+   - Explains essential command-line utilities, including shell scripting and text processing commands, as well as the latest graphical administration and productivity applications.
+   - Features extensive learning tools, including review questions, hands-on projects, and case projects, which allow students to practice skills as they are learned.
+   - Includes a free copy of the Fedora Core 2 version of Red Hat® Linux® on CD-ROM.

# About the Author

Nicholas Wells has authored over a dozen books on Linux, network security, Apache Web servers, and related topics. His previous work for Thomson Course Technology includes Guide to Linux Installation and Administration, Guide to Linux Networking and Security, and MCSE/MCSA Guide to Implementing and Administering Security on a Microsoft Windows 2000 Network. Wells began working in the software industry in 1980 and started using Linux in 1993. He practices intellectual property and technology law in Salt Lake City.
