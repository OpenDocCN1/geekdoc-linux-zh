On the default Panel or any Panel that you add to your desktop, you can add new items to the Panel by right-clicking and selecting Add to Panel. In the submenu that appears, you can select from a large number of tools such as a stock ticker or weather report (both under the Accessories submenu), a wireless link monitor, a volume control, or a battery charge-level indicator (for laptops), among others. You can also add an icon to start any item on the GNOME main menu. Just select the Launcher from menu submenu. This displays the entire GNOME main menu with all its submenus. But from this context menu, when you select an item, instead of starting that application, the Panel adds an icon so that clicking that icon will start the application you selected.
