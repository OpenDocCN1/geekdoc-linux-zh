Given these two files, the login command would execute these modules—in this order—as part of the login process (the auth stack):

+   - pam_securtty.so (from /etc/pam.d/login)
+   - pam_stack.so (from /etc/pam.d/login—this module only starts the next three)
+   - pam_env.so (from /etc/pam.d/system-auth)
+   - pam_unix.so (from /etc/pam.d/system-auth)
+   - pam_deny.so (from /etc/pam.d/system-auth)
+   - pam_nologin.so (from /etc/pam.d/login)

The file /usr/share/doc/pam-0.77/html/pam-6.html in Red Hat Linux or Fedora contains reference information for each module, including examples and descriptions of all the supported arguments. These descriptions include information specific to any of the four module types for which the module is supported. For example, the pam_unix module can be used for auth, account, session, or passwd.
