# Understanding Redundant Disk Systems and RAID

Two parts of the Linux kernel that are generally not implemented using kernel modules are RAID and logical volume management. Both of these disk management techniques are typically set up when you install Linux. This section and the next section introduce you to these high-end features of Linux.

One of the most vulnerable parts of a computer system is the hard disk. It contains many moving parts, and is often subjected to constant heavy use. If the data on your hard disks becomes unavailable because of a failure, the rest of the computer system is useless. For these reasons, much effort has gone into making hard disks redundant.
