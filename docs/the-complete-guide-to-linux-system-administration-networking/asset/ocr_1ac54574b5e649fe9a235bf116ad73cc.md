Rules are executed in the order that you place them in the chain. For example, suppose you have the following two rules. The first accepts packets from a single network; the second denies packets for all networks.

```
# iptables -A INPUT -s 192.168.10.0/0 -j ACCEPT
# iptables -A INPUT -j DROP
```

As with certain other configuration files that you have seen, the order of the rules is important. If you reversed the above two rules, packets coming from the 192.168.10.0 network would be denied before they could be permitted access by the more specific rule.

In general, firewall rules should go from more specific at first to more general at the end, with "catchall" rules at the very end so that nothing gets through unexpectedly.
