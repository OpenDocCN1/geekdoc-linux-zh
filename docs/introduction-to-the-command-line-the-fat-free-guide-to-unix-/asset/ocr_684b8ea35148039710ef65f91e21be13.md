# lssrc

Purpose: Display the status of services on AIX systems.

Usage syntax: lssrc [OPTIONS] [SERVICE/GROUP]

```
# lssrc -a
Subsystem      Group            PID                Status
syslog        ras             147590            active
sendmail      mail            188508            active
portmap       portmap         126930            active
snumqmbd      tcpip           151728            active
inetd         tcpip           163958            active
snmpd         tcpip           180316            active
hostsnmbd     tcpip           159852            active
aixmbd        tcpip           168024            active
biod          nfs             196706            active
rpc.statd     nfs             209038            active
rpc.lockd     nfs             204984            active
qdaemon       spooler         217200            active
writesrv      spooler         233508            active
ctmro         racst           241870            active
pcconsole     pcconsole       270470            active
cimsys                    229504            active
IBM.ServiceRM racst_rm        311470            active
IBM.CSMAgentRM racst_rm       291004            active
lpd         spooler               inactive
...
```

The lssrc command displays the status of services on AIX systems. The above example demonstrates using the -a option to display the status of all services.

The next example demonstrates using the -s option to list a specific service.

```
# lssrc -s nfsd
Subsystem      Group            PID                Status
nfsd        nfs                    inactive
```

Common usage examples:

+   *   **lssrc -a** : Display the status of all services
+   *   **lssrc -s [SERVICE]** : Display the status of the specified services
+   *   **lssrc -g [GROUP]** : Display the status of the specified group of services
