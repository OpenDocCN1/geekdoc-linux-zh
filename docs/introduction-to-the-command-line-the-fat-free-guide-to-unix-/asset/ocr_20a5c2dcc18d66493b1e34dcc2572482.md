**dpkg** is the traditional package manager for Debian Linux-based systems. It can be found on Debian and Ubuntu as well as a host of other Linux distributions built on the Debian core.

Using **dpkg**, you can install or remove programs created specifically for Debian-based systems. These packages typically have a .deb file extension. The above example demonstrates using the **dpkg** command to install a Debian package.

> **Note**
> 
> *Most Debian-based systems now utilize a program called `aptitude` to perform software installation tasks. Directly installing packages using `dpkg` is rarely done given that `aptitude` will automatically download and install the requested package(s) and all required dependencies. See page 234 for more information.*

**Common usage examples:**

| `dpkg -i [PACKAGE]` | Install the specified package |
|---|---|
| `dpkg -r [PACKAGE]` | Remove the specified package |
| `dpkg -p [PACKAGE]` | Remove the specified package and related config files |
| `dpkg -l` | List all installed packages |
