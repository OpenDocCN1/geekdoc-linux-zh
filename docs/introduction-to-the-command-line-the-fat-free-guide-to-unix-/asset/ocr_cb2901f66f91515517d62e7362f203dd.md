# # lpg

**Purpose**: Display print queue status.

**Usage syntax:** `lpg` **[OPTIONS]**

```
```
$ lpg -a
Rank  Owner Job    File(s)      Total Size
1st   nick  2     hosts       1024 bytes
2nd   nick  3     hosts       1024 bytes
3rd   nick  4     hosts       1024 bytes
4th   nick  5     hosts       1024 bytes
5th   nick  6     hosts       1024 bytes
6th   nick  7     hosts       1024 bytes
7th   nick  8     hosts       1024 bytes
8th   nick  9     hosts       1024 bytes
9th   nick  10    hosts       1024 bytes
```
```

![](bbox=[0.35, 0.37, 0.9, 0.39])

The `lpg` command displays the status of queued print jobs. It is similar to the `lpstat` command except it provides more user-friendly output. Unlike the `lpstat` command, the `lpg` command only supports a limited number of command line options.

In the above example, executing `lpg -a` displays all queued print jobs. The next example demonstrates using the -P option to display the status of a specific printer.

```
```
$ lpg -P HP-4350
HP-4350 is not ready
Rank  Owner Job    File(s)      Total Size
1st   nick  2     hosts       1024 bytes
2nd   nick  3     hosts       1024 bytes
3rd   nick  4     hosts       1024 bytes
4th   nick  5     hosts       1024 bytes
```
```

![](bbox=[0.45, 0.77, 0.95, 0.79])

**Common usage examples:**

| `lpg -a`       | Display the status of all queued print jobs |
| `lpg -P [PRINTER]` | Display the status of the specified printer |
