
## 附录 A：Bash 快捷键

*在 www.dontfearthecommandline.com 下载并打印此列表*

| 按键 | 功能 |
| :--- | :--- |
| CTRL + C | 终止当前程序 |
| CTRL + Z | 挂起当前程序 |
| CTRL + D | 退出当前 shell |
| Tab | 命令/文件自动补全 |
| Home | 跳转到命令行开头 |
| End | 跳转到命令行末尾 |
| CTRL + L | 清屏 |
| Backspace | 删除光标后的文本 |
| ALT + Backspace | 删除光标后的整个单词 |
| Delete | 删除光标前的文本 |
| CTRL + R | 搜索命令历史 |
| 上箭头 | 向后循环浏览命令历史 |
| 下箭头 | 向前循环浏览命令历史 |
| 左箭头 | 光标向左移动一个字符 |
| 右箭头 | 光标向右移动一个字符 |
| ALT + B | 光标向后移动一个单词 |
| ALT + F | 光标向前移动一个单词 |
| CTRL + U | 剪切光标前的所有文本 |
| CTRL + K | 剪切光标后的所有文本 |
| ALT + D | 剪切当前选中的单词 |
| CTRL + Y | 粘贴之前剪切的文本 |
| CTRL + _ (下划线) | 撤销在命令行中输入的更改 |
| CTRL + T | 交换命令行上之前的两个字符 |
| ALT + T | 交换命令行上之前的两个单词 |
| ALT + L | 将单词转换为小写 |
| ALT + U | 将单词转换为大写 |
