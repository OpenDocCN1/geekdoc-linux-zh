# errpt

Purpose: Display system error messages on AIX systems.

Usage syntax: errpt [OPTIONS]

```
# errpt

IDENTIFIER TIMESTAMP T C RESOURCE_NAME DESCRIPTION
A6F445AA 0515142910 I O RMCdaemon The daemon is started.
2EFA76F6 0515142910 T S SYSPROC SYSTEM SHUTDOWN BY USER
90BCFD2E 0515143010 T O errdemon ERROR LOGGING TURNED ON
6714A3A9 0510232410 U S SYSXDUMP SYSTEM DUMP
BE0A03E5 0510232410 P H sysplanar0 ENVIRONMENTAL PROBLEM
F48137AC 0510232410 U O minidump COMPRESSED MINIMAL DUMP
BFE4C025 0510231210 P A sysplanar0 UNDETERMINED ERROR
...
```

Example output of the errpt command

**errpt** displays the error log on IBM AIX systems. It can be helpful when troubleshooting problems with system hardware and software. Executing the **errpt** command displays a short list of logged errors as shown in the above example. The **-a** option can be used with **errpt** to display detailed information about each error, as shown in the next example.

```
# errpt -a

---------------------------------------------------------------
LABEL: EPOW_SUS_CHRP
IDENTIFIER: BE0A03E5

Date/Time: Sat May 15 14:29:54 CDT 2010
Sequence Number: 47
Machine Id: 0008A41D4C00
Node Id: localhost
Class: H
Type: PERM
WEAR: Global
Resource Name: sysplanar0
...
```

Output of the errpt -a command

**Tip** To clear the AIX error log, execute **errclear 0** as the root user.

Common usage examples:

+   - `errpt` Display a summary of system errors
+   - `errpt -a` Display detailed information for all errors
+   - `errpt -aj [IDENTIFIER]` Display detailed information for a specific error
