# wget

**Purpose**: File download utility for Linux systems.

**Usage syntax**: `wget [OPTIONS] [SOURCE]`

```
$ wget http://kernel.org/pub/linux/kernel/v2.6/patch-2.6.29.4.bz2
--2009-06-02 01:15:58--  http://kerne1.org/pub/linux/kernel/v2.6/patch-2.6.29.4.bz2
Resolving kernel.org... 149.20.20.133, 204.152.191.37
Connecting to kernel.org[149.20.20.133]:80... connected.
HTTP request sent, awaiting response... 200 OK
Length: 91866 (90K) [application/x-bzip2]
Saving to: "patch-2.6.29.4.bz2'
100%[=======================================>] 91,866  99.6K/s in 0.9s
2009-06-02 01:16:03 (99.6 KB/s) - 'patch-2.6.29.4.bz2' saved
```

![](bbox=[0.33, 0.34, 0.8, 0.35])

**wget** is a file download utility for the command line. It can be used to download files via HTTP and FTP protocols. In the above example, a file is downloaded from a remote HTTP system and saved in the current directory.

> **Tip**
> *Use the `--user=[USERNAME]` and `--password=[PASSWORD]` options to specify a username and password to used when connecting to the remote system.*

**Common usage examples:**

| Usage | Description |
| :--- | :--- |
| `wget http://[HOST/FILE]` | Download the specified file via HTTP |
| `wget ftp://[HOST/FILE]` | Download the specified file via FTP |
