# Glossary of terms used in this section:

+   - **Init**: (INITialization) A program that controls the startup (AKA initialization) of Unix, Linux, and BSD systems.

+   - **Runlevel**: A set of profiles used by the init program that defines the programs and services to load during system startup (or when called by the telinit command).

+   - **Service**: A system program that provides a service as a web server, DNS server, email server, etc. Services are sometimes referred to as Daemons or Service Daemons.
