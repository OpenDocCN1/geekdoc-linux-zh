# htop

Purpose: Advanced system monitor for Linux.

Usage syntax: htop

![](bbox=[0.14, 0.21, 0.9, 0.52])

Monitoring system activity with htop

htop is an alternative system monitor for Linux that is similar to the previously discussed top command. The example above displays a screenshot of the htop interface. It features color output and uses a graphical scale to visualize processor, memory, and swap utilization.

> Similar to top, htop supports interactive commands. Press the F1 key within htop for a complete listing of interactive options.

Common usage examples:

```
htop
```

Run the top monitor with default settings

```
htop -u [USER]
```

Only display processes from the specified user
