# **mv**

**Purpose:** Move or rename files and directories.

**Usage syntax:** `mv [OPTIONS] [SOURCE] [DESTINATION]`

```
```bash
$ ls -l
-rw-r--r-- l nick nick 55 2009-05-20 15:32 MyFile
$ mv MyFile MyFile.old
$ ls -l
-rw-r--r-- l nick nick 55 2009-05-20 15:32 MyFile.old
```
```

![](bbox=[0.29, 0.26, 0.63, 0.28])

The `mv` command moves or renames files. In the above example, `MyFile` file is renamed to `MyFile.old` using the `mv` command. In the next example, `MyFile.old` is moved to the `/tmp` directory.

```
```bash
$ mv MyFile.old /tmp/
$ ls -l /tmp/
-rw-r--r-- l nick nick 55 2009-05-20 15:32 MyFile.old
```
```

![](bbox=[0.36, 0.45, 0.61, 0.47])

The `mv` command can also be used to move or rename directories. In the example below, the `NewFiles` directory is renamed to `OldFiles`.

```
```bash
$ ls -ld NewFiles/
drwxr-xr-x 2 nick nick 4096 2009-06-28 13:23 NewFiles/
$ mv NewFiles/ OldFiles/
$ ls -ld OldFiles/
drwxr-xr-x 2 nick nick 4096 2009-06-28 13:23 OldFiles/
```
```

![](bbox=[0.35, 0.61, 0.62, 0.63])

> **Warning:** The default behavior the `mv` command will overwrite any existing file(s). The `-i` option overrides this behavior and prompts the user before overwriting the destination file.

Common usage examples:

| `mv [SOURCE] [DEST]` | Move a file or directory to the specified location |
| :-------------------- | :--------------------------------------------------- |
| `mv -i [SOURCE] [DEST]` | Prompt before overwriting the destination file |
| `mv -f [SOURCE] [DEST]` | Force overwriting if the destination file exists |
