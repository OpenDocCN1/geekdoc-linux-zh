# swapinfo

Purpose: Display swap space information.

Usage syntax: `swapinfo [OPTIONS]`

```
# swapinfo
Kb Kb Kb PCT START/ Kb
TYPE AVAIL USED FREE USED LIMIT RESERVE PRI NAME
dev 524288 0 524288 0% 0 - /dev/vg00/lvol2
reserve -111696 -111696
memory 389816 143784 246032 37%
```

![](bbox=[0.08, 0.38, 0.9, 0.41])

**swapinfo** displays details about active swap storage. The above example displays the output of the **swapinfo** command on an HP-UX system. It includes information about the size and location of swap storage and the amount of memory and swap utilization.

**swapinfo** is available on BSD and HP-UX systems. Other platforms use the commands listed in the cross-reference below to display information about swap utilization.

| AIX | BSD | HP-UX | Linux | Solaris |
| :--- | :--- | :--- | :--- | :--- |
| lps | swapinfo | swapinfo | free | swap |
