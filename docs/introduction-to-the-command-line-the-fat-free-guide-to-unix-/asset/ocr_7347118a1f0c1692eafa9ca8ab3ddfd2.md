# sam

**Purpose:** Menu-driven system administration utility for HP-UX systems.

**Usage syntax:** `sam`

![](bbox=[0.08, 0.22, 0.92, 0.6])

`sam` is a menu-driven administration utility for HP-UX systems. It can be used to manage all aspects of an HP-UX system.

The above example displays a screen shot of the main menu in `sam`. Within `sam`, the arrow keys are used to navigate the menus and the `Enter` key is used to select items. Pressing the `Tab` key activates the menu bar at the top of the screen allowing access to additional features.

**Common usage examples:**

```
```
sam	Start the HP-UX system administration manager
