# The Shell

The command line interpreter, also known as the shell, is a program that accepts input from a user (typically a command of some sort) and performs the requested task. Once that task has completed, the program will terminate and return the user to the shell.

The shell's prompt identifies the type of shell being used. There are two basic types of shell prompts:

+   $ Normal user shell (may also be % or > on some systems)
+   # Root user shell

Normal users typically have a limited amount of access to the system while the root user has unrestricted access. Section 5 covers this topic in more detail.

> **Warning**
> The root user can do anything on Unix, Linux, and BSD systems. It is important to know when you are working as root to prevent accidental damage to your system.
