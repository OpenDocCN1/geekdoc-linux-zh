# ethtool

Purpose: Display ethernet card settings.

Usage syntax: ethtool [OPTIONS] [INTERFACE]

```
# ethtool eth0
Settings for eth0:
  Supported ports: { TP }
  Supported link modes:  10baseT/Half 10baseT/Full
                          100baseT/Half 100baseT/Full
                          1000baseT/Full
  Supports auto-negotiation:  Yes
  Advertised link modes:   10baseT/Half 10baseT/Full
                          100baseT/Half 100baseT/Full
                          1000baseT/Full
  Advertised pause frame use:  No
  Advertised auto-negotiation:  Yes
  Link partner advertised link modes:  Not reported
  Link partner advertised pause frame use:  No
  Link partner advertised auto-negotiation:  No
  Speed: 1000Mb/s
...
```

Typical output of the ethtool command

ethool is a Linux utility for displaying information about network interfaces. The default output displays advanced network interface settings as displayed in the above example. It can also be used to display network statistics using the -S parameter as shown in the next example.

```
# ethtool -S eth0
NIC statistics:
  rx_packets: 125
  tx_packets: 114
  rx_bytes: 14459
  tx_bytes: 17596
  rx_broadcast: 9
  tx_broadcast: 3
  rx_multicast: 14
  tx_multicast: 19
  rx_errors: 0
...
```

Displaying interface statistics using the -S parameter

Common usage examples:
ethtool [ INTERFACE ] | Display network interface settings
ethool -S [ INTERFACE ] | Display network interface statistics
