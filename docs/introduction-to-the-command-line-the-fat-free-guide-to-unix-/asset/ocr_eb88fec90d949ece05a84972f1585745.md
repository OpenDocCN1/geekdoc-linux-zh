# ## Devices

Every Unix, Linux, and BSD system has a directory that is known as `/dev`. This directory contains device files (sometime referred to as special files) that represent hardware installed on the system such as `/dev/mouse` and `/dev/cdrom`.

Within the `/dev` directory there can be several hundred files. Most of these files are of little use in everyday activities. As the system administrator of a Unix or Linux system you will primarily be working with the device files that represent your disk drives(. Knowing the path to your hard drive is important when working with commands related to file systems. More on this topic is covered in Section 10 of this guide.

> > **Note** *Device naming conventions used in `/dev` vary across each distribution.*

Within `/dev`, there are also a few helpful pseudo-devices. Pseudo-devices do not represent actual hardware and exist only to perform a specific task. The table below describes the most commonly used pseudo-devices.

| File | Purpose |
|:---|:---|
| **/dev/zero** | File that produces a continuous stream of 0-byte characters |
| **/dev/random** | Random number generator |
| **/dev/null** | Special file that discards any data written to it |
