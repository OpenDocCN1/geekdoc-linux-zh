# ## Adding Mail Filters in Thunderbird

![](bbox=[0.02, 0.04, 0.15, 0.12])

In most e-mail programs, you need to use the message-filtering features to filter spam. With the great junk mail controls in Thunderbird, you are free to use the message filters to concentrate on organizing your Inbox and folders.

+   1. Open the Message Filters dialog box at Tools > Message Filters on the menu.
+   2. Click the New button to open the Filter Rules window.
+   3. Let's say that I wrote a mean letter to Rod Stewart, that rock dude from the '70s. Let's say that I want to make sure that I don't see any reply from him. I can fill out the filter rules to specify the sender and then add the action to put matching messages in the trash (see Figure 6.6).

![](bbox=[0.16, 0.28, 0.75, 0.61])

![](bbox=[0.77, 0.28, 0.95, 0.34])

+   4. When you're done with the rules, click OK. Close the Message Filters window.
+   5. To apply your filters, go to Tools > Run Filters on Folder. Then you will be sure to not receive any e-mail from Rod Stewart.

# ### Newsgroups

You find the oddest people online, and you find most of those odd people in newsgroups. Groups are an old Internet staple. Although Web forums and message boards that you can read in your browser have threatened to make newsgroups extinct, there are still dedicated newsgroup users who doggedly check their groups all day and argue to their heart's content.
