When I think of AbiWord, I think of middle child syndrome. AbiWord is like a child who lives in the shadow of its more popular sibling, OpenOffice.org. AbiWord is a great word-processing program. The application is cross-platform, with versions for Windows and Mac OS X as well as Linux. AbiWord meshes well with Word documents, and it also loads OpenOffice, rich-text, Word Perfect, and HTML documents. The quirks when loading other document types with complex formatting are much more prevalent than in OpenOffice, but AbiWord can still edit them and does perfectly fine with basic formatting.

The advanced features in AbiWord are well designed. Document layout options for bullets, tables, and other lists are easy to use. You can use mail merge functions to pull data from lists or databases. AbiWord also uses plugins to add extra functionality to the program.

AbiWord is light, fast, and efficient. If you just need basic word processing, see if you like AbiWord better than OpenOffice Writer. You might like the single program's easy usability, compared to installing a whole office suite.
