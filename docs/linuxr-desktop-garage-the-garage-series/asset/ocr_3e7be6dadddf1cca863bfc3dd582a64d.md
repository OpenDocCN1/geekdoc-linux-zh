# ## About the CD-ROM

The CD in this book is a Linux live CD of the distribution Gnopix. A Linux live CD is a Linux distribution that will boot up and run right off the CD without having to install a whole operating system on your computer. Gnopix does not include every program that is covered in this book, but you can use the CD to get comfortable with a few Linux programs.

You can read more about Linux live CDs in Chapter 1. You can read more about Gnopix at **http://www.gnopix.org**.

To use the Gnopix CD in this book, you need a PC with these requirements:

+   * PC with Intel-compatible CPU (486 or later)
+   * Bootable CD-ROM drive
+   * At least 96 MB for graphics mode
+   * SVGA-compatible graphics card

Unfortunately, Gnopix does not currently have a Mac version.

Put the CD in your CD-ROM drive. Reboot your computer. You will need to make sure that your computer is set up to boot from CD when a bootable CD is present. See Chapter 1, and the "Under the Hood" note titled "CD Boot" on page 20 for more information about how to boot from your CD drive.
