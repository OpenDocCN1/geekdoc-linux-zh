CrossOver installs and runs Windows programs through a nice, very simple GUI interface. The usability difference between this program and regular Wine is vast. Besides the Microsoft Office programs, CrossOver Office can run many popular Windows programs, including these:

+   - Adobe Photoshop
+   - Microsoft Outlook
+   - Microsoft Internet Explorer
+   - Windows Media Player (version 6.4, but newer versions are being worked on)
+   - Lotus Notes
+   - QuickTime
+   - Dreamweaver MX
+   - Flash MX

You can try programs that are not included in the supported application list, but they might not run; you just have to wait and see. Someone even got iTunes working in CrossOver Office. When you stick to the supported applications list, you do need to reconcile yourself to the fact that supported versions of popular programs usually lag a version or two behind the latest Windows versions.

Unlike most Linux programs, CrossOver isn’t free. You can download a trial version from the CodeWeavers Web site at http://www.codeweavers.com. The program runs so well and is so easy to use that it is well worth the price if you are someone who absolutely needs to run Windows programs in Linux. You can look over the list of supported applications at http://www.codeweavers.com/site/products/cxoffice/supported_apps/. Each application is rated and has a forum associated with it, a list of known issues, and tips.

Using CrossOver Office is surprisingly easy. From installing programs to running programs, you rarely encounter any hicups, as long as you stick to the supported programs list. CrossOver can dependably be used in a professional environment. You can even choose between a Standard and a Pro version, with the Pro version including more support.
