Linux distribution that will boot up and run right off the CD without having to install a whole operating system on your computer. Gnoppix does not include every program that is covered in this book, but it provides you with enough to get your feet wet. Use the CD to get comfortable with a few Linux programs, and then go on the adventure and install a Linux distribution of your own.

You can read more about Linux live CDs in Topic 1. You can read more about Gnoppix at http://www.gnoppix.org.

To use the Gnoppix CD in this book, you need a PC with these requirements:

+   PC with Intel-compatible CPU (486 or later)

+   Bootable CD-ROM drive

+   At least 96 MB for graphics mode

+   SVGA-compatible graphics card

Unfortunately, Gnoppix does not currently have a Mac version.

Put the CD in your CD-ROM drive. Reboot your computer. You will need to make sure that your computer is set up to boot from CD when a bootable CD is present. See Chapter 1, "What Are You Getting Into?" and the "Under the Hood" note titled "CD Boot" on page 20 for more information about how to boot from your CD drive.
