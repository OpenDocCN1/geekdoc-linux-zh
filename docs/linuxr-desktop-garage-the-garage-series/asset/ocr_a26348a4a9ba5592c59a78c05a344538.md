# Send a Test Message in KMail

You have set up your account in KMail, and you think you have gotten everything right. If you’re of the meticulous sort, the one way to know for sure that everything is working is to send yourself an e-mail. That might sound silly at first, like a much more complex and technical version of talking to yourself. I actually send myself e-mails all the time as reminders and notes about things. Either way, sending a test e-mail is a quick and easy way to get familiar with the basic functions of KMail.

+   Open KMail and make sure you have already set up your identity and account.
+   
+   Select New Message on the toolbar or go to File > New Message to open the composer window (see Figure 6.4).

![](bbox=[0.05, 0.27, 0.22, 0.32])

![](bbox=[0.34, 0.26, 0.9, 0.6])

+   Put your own e-mail address in the To field and then write your message. If you use any of the text—formatting buttons above the message field, your message will be sent as an HTML message. I am an adherent to the plain-text message only doctrine, myself.
+   
+   If you want to add an attachment to your e-mail, click the Attach File button on the toolbar and browse for your file. You can also drag files from your file manager window or the desktop into the composer window to attach them.
+   
+   When you are done typing the message, click the Send button on the toolbar to send the message now. You can also choose to send your message later with the Queue button, which puts the message in your Outbox until you check your mail again.
