Creating PDFs in Linux is easy as well, but don’t let Adobe know about it. Okay, they probably already know, but they don’t quite know what to do about the situation. OpenOffice.org has a built-in export-to-PDF feature. When you are done editing your document in Writer or Calc, just choose File > Export as PDF from the menu. The feature is also available from the print screen using the Print to File option.
