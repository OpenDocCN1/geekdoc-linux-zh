# The Watchful Eye

You might find it hard to believe, but under the Digital Millenium Copyright Act (DMCA), it is currently unlawful for you to play a DVD that you have purchased on a Linux media player. This oddity occurs because, to provide you with the means to play DVDs protected by the Content Scrambling System (CSS, a copy protection measure used by distributors), developers have reverse-engineered a way to get past the copy protection (DeCSS). Many legal battles about this already have ensued ([http://cyber.law.harvard.edu/openlaw/DVD](http://cyber.law.harvard.edu/openlaw/DVD)), and more are sure to come. None of the players we are discussing requires the nefarious DeCSS. The Turbolinux distribution has released a version containing Linux's first commercial DVD player, the PowerDVD player for Linux by Cyberlink. Hopefully, that program will be available for purchase separately so we can all play our Elvis movies without checking outside for the approaching authorities. Write your Congressional representatives about this silly law ([http://www.congress.org/congressorg/home](http://www.congress.org/congressorg/home)).

Third-party add-ons are available for Ogle that can make the program easier to use. First, there is a KDE front end for Ogle called oKle (see [http://okle.sourceforge.net/](http://okle.sourceforge.net/)). This program adds simplified access to some of Ogle's functions and blends in with KDE. There is also an ambitious add-on called Goggles (see [http://www.tifthplanet.net/goggles.html](http://www.tifthplanet.net/goggles.html)). The software requires the Fox Toolkit (a GUI development tool for developers), which makes installing Goggles more complex, but the work is worthwhile for anyone who will use Ogle often. Goggles features include automatic bookmarks and automatic starting.
