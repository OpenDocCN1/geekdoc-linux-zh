# Cube

# Program Info

| Program URL | http://sourceforge.net/projects/cube/ |

Whenever anyone says something such as "Don't expect a good game or nice graphics when you play a free game," you know there is an exception. Cube (see Figure 12.4) is a good game and also has great graphics. Cube is a first-person shooter with multiplayer online play, a single-player game, map editing, and a nice reminder of old-school Quake days. There are many multiplayer modes to keep you busy.

# Flight Gear Flight Sim

# Program Info

| Program URL | http://flightgear.org |

You know there had to be a flight simulator in all of this. Flight Gear (see Figure 12.5) has some nice graphics and a good variety in the types of planes that you can fly. The controls are fair, but multiplayer network play is a plus. To get the best play out of this game, you will want to hook up a joystick.
