Some people recommend creating many partitions for the different parts of your file system. There are merits to partitioning that way, but for simple desktop use, it is probably not necessary. You can run Linux with everything but the boot and swap on the same partition. To keep things roomy, be sure to give all the partitions a total of 5GB.

# Table 1.1 Partition Types in Linux

| PARTITION | MOUNT POINT | SIZE (AT LEAST) | DESCRIPTION |
| :--- | :--- | :--- | :--- |
| Boot | /boot | 100MB | The kernel image is here. The boot partition should be a primary partition. |
| Swap | None | 2x RAM | This space is used to move programs in and out of memory. |
| Logical | / | Variable size | This is the space for the rest of your file system. You can create multiple partitions or divide this space between drives. You can also create other logical partitions that are not Linux native. |

After you install Linux, you will easily learn about partitions. It's not rocket science, but it is something that can cause a lot of headaches if it is done wrong. A great way to learn is to let the installer partition the drive and then look at the partitions that were created and their names, size, file system, and mount point. Don't worry, if you mess up—just start over. You might spend more time when you start over, but you will learn more.
