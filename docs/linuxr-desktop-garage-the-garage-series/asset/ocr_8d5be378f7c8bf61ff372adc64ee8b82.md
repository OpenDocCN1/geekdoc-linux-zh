| KDE-PIM Suite | Great | Calendat: fair/good All else: great | This suite has more features and functions than Evolution, probably because of all the separate programs. The interface of the calendat when not used from within Kontact hurts my eyes, but the lack of pretty doesn't distract from the utility and unique features. The rest of the programs are up to the usual KDE standard of good design. There are more innovative ideas in the different suite programs than in Evolution, and more fun things to play with. However, having all the programs separate means that the PIM functions don't work together as smoothly unless you use Kontact. This suite is good to use if you need only some of the functions and would prefer to use smaller, separate programs. |
| GNOME Pilot | Good | Fair | This is a program that just works without any bells and whistles to get in your way. Unfortunately, that also means that the program has no help for you or extra features to make using it easier. GNOME Pilot is best if you want simplicity and already know what you are doing. |
| K Pilot | Good | Great | K Pilot is a well thought-out and useful program. This program wins any race right now for PDA syncing in Linux. The documentation should be kept more up-to-date, but maybe that's something you can volunteer to do as your contribution toward open source software. "nudge, nudge" |
