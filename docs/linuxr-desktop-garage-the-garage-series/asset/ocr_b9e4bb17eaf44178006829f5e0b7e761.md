Later in the install process, Mandrake presents you with categories of pro-  \ngrams from which to choose (see Figure 1.3). You can peek into the Individual  \nPackage Selection choice to see what each category includes. Most of the cate-  \ngories are self-evident, but others might need more explanation. Move your  \nmouse over each selection to see a brief description.

**Office Workstation.** This group has office suite software, word-processing  \ncapabilities, spreadsheets, and so on. OpenOffice.org is the default choice. You  \n might want to add and try other choices later.

**Game Station.** A few of the free Linux game choices are in this group. Most of  \n the games that are on your CDs are not included in the category by default.  \n There are more games to add and play with than the ones that come in this  \ngroup.

**Multimedia Station.** Software for playing movie files and music is included.  \n Image-viewing and editing programs are also here, along with tools for digital  \ncameras.

**Internet Station.** Browsers, e-mail clients, newsgroup clients, and instant  \n messaging and chat capabilities are included in this category. Web develop-  \n ment programs are in this category as well but are not selected by default.

**Network Computer (Client).** Software to allow you to view the other comput-  \n ers and printers on your local area network are found in this group.

**Configuration.** Extra tools are in here to allow you to tweak various settings.  \nYou probably won’t need most of these.

**Console Tools.** Plain-text programs that will be run in the console are added  \n when you select this category. Most of the important text-only programs that  \n run in the console are installed by default in the base install without selecting  \n this choice. These programs are extras that have unique uses.

**Development.** This group is important and includes software-development  \n tools and compilers. Although you won’t need all of these if you are not a pro-  \ngrammer, you will need the compilers if you install any software from source  \ncode. It’s a good idea to include this one.

**Documentation.** These are the help documents. You’re new. Add these. Even  \n if the docs are a version behind, as they often are, they make for some action-  \npacked, thrilling reading.
