# Rename a Folder and a File

We've just heard from our KDE intel team that the GNOME people are on to us. They are looking for the plans that we stole. We have to rename the files they aren't so obvious.

+   1. Click once on the File StolenGNOMEPlans. txt to highlight it. From the menu at the top of your window, go to Edit > Rename. You can also right-click the file and choose Rename, press the F2 key, or click the name text of the file.

+   2. Type in the new file name, TheresNothingToSeeHere. txt. Press Enter or click in the white space somewhere to exit the text edit mode.

+   3. Use either the Up button or the Back button on the toolbar to return to the home directory. Then rename the folder SecretPlans to NothingInteresting using the same method that you used to rename the file.
