# # The Garage Series
## Street-smart books about technology

Each author **presents** a unique take on solving problems, using a format designed to replicate the **experience** of Web searching. Technology presented and **organized** by useful topic—not in a linear tutorial style.

Books that cover **whatever** needs to be covered to get the project **006B**. Period.
