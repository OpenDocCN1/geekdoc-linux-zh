# Network Around the Problem

Many people these days have more than one computer in their home. If you are one of those people and you have a software modem that you cannot get to work in Linux, try networking. A local area network is not just for broadband users; you can use another computer dial up to establish the Internet connection and then share that connection with your Linux computer. There are many online resources on how to network two or more computers together. Search online or check out these URLs: http://www.linksys.com/faq/default.asp?fpid=16 and http://computer.houstuffworks.com/home-networkw11.htm.

+   - **Hardware Browser in Fedora.** *Main menu > System Tools > Hardware Browser*

+   - **Hardware Browser in Mandrake.** *Main menu > System > Configuration > Configure Your Computer*
+       (from inside the Mandrakelinux Control Center) *Hardware > Hardware*

Find your modem in the list of hardware, and write down the brand and model of the modem. Next, go to an online listing of Winmodems at http://www.devildal.tv/~chris/winmodems/ to see which list your modem is in. There is also a Linux Documentation Project page on Winmodems at http://tdl.dp.org/HOWTO/Winmodems-and-Linux/HOWTO-1.html#ss1.3. If you do have a Winmodem and want to try to make it work, check out http://www.linuxmodems.org/.

# Program Startup

| | |
| --- | --- |
| **Fedora/GNOME menu** | *Internet > KPPP* |
| **Mandrake/KDE menu** | *Internet > Remote access > KPPP* |
| **Terminal command** | kppp |

KPPP is the KDE program for Internet dialing. The program can be included with both Mandrake and Fedora if you choose to install KDE. If you don't have KPPP, you can install the program from your installation disks. (See "Installing New Software," later in this topic, for more information.) Even though KPPP is a KDE program, it is really the best choice for both GNOME and KDE users. There isn't a GNOME substitute at this time that is easier than KPPP.
