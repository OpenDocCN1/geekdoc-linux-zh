# ## Getting Pictures from Your Camera

# ## gKam

**Program Info**
| | |
|:---|:---|
| Fedora/GNOME menu | *Graphics > Digital Camera Tool* |
| Terminal command | `gkam` |
| Program URL | `http://gpphoto.sourceforge.net/proj/gkam/` |

The makers of gPhoto2 also make gKam. This program (see Figure 9.2) is the default front end for use with gPhoto2 to pull the images off your digital camera. You have gKam installed with gPhoto2 in your distro if you are using Fedora. You can install the program in Mandrake using RPMDrake. It’s a really simple program, with options to choose your digital camera from a list of supported cameras and then import your images to a directory on your hard disk.

gKam’s interface is arranged in a simple two-pane window layout. There is a brief menu at the top with a File menu and menus for Select, Camera, and Help. The Camera menu is for configuring the connected camera. The left column is an expandable tree list of folders on the connected camera. The number of images is in parentheses next to the name of the folder. The right-side window is for viewing thumbnail previews of the images on your camera.
