# Tux Kart

| Program Info | |
| Program URL | http://tuxkart.sourceforge.net |


A Linux knock-off of the popular Nintendo game series Mario Kart, Tux Kart (see Figure 12.6) is fairly blatant in copying its more famous predecessor with “zippers” instead of the power-up “item boxes” in Mario Kart. The graphics are a little scratchy and unsmooth, but the game is a good time.

# Tux Puck

| Program Info | |
| Program URL | http://home.no.net/munsuun/tuxpuck |


At first I thought, “An air hockey game?” Then I remembered that video games get made of anything and everything. Tux Puck is a cute little game with decent game play and good, if creepy, graphics. I say creepy because the people are rendered a little odd looking. I think I’m still better at real air hockey than video game air hockey.
