# 6.12.6 Summary

This chapter introduced the NCurses library as a means for controlling the user's terminal in a simpler and more powerful way than was possible by modifying terminal driver attributes. It barely scratched the surface of the library's interface. It also introduced timers as a way of introducing timed events and motion. Finally, it introduced several different models of input/output, including signal-driven and asynchronous I/O, an well as several different models of terminal processing, such as raw, cbreak, and non-canonical mode.

More efficient processing and better control can be achieved by the use of multiple processes. This is the topic of the next chapter.
