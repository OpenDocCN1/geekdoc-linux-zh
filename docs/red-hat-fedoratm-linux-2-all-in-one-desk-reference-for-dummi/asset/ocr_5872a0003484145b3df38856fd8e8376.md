After adding a Samba share, type the following command in a terminal window to verify that the Samba configuration file is okay:

```
testparm
```

If the command says that it loaded the files okay, you’re all set to go. The `testparm` command also displays the contents of the Samba configuration file.

![](bbox=[0.15, 0.27, 0.25, 0.33])

To start the SMB services automatically when the system reboots, type the following command:

```
chkconfig --level 35 smb on
```

# Trying out Samba

You can now try to access the Samba server on the Fedora Core system from one of the Windows systems on the LAN. Double-click the Network Neighborhood icon on the Windows 95/98/ME desktop. On Windows XP, choose Start\My Network Places and then click View Workgroup Computers. All the computers on the same workgroup are shown.

As you can see from the label (see Figure 6-7), the selected icon represents a Fedora Core system running Samba.
