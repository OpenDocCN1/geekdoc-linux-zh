# ## Getting Started with Calc

The best way to find out how to use Calc is to simply start using it. To start Calc, click the Calc icon — the icon showing a spreadsheet with a pie chart — on the panel or choose Main Menu: Office: OpenOffice.org Calc. The Calc window opens with a blank spreadsheet. You can then begin typing text and numbers into the cells and use formulas to calculate whatever you want.
