If you want to work on an existing document (for example, a Microsoft Word file) that you saved on your hard disk, choose File*Open and then pick the document from the Open dialog box. Then you can work on that document and save it in Word format, another word processing format, or in the default OpenOffice.org 1.0 Text Document format in a file with the .s\*\*\*m\*\*\*x extension.
