# ### Browsing folders in a navigation window

If you prefer to use the familiar navigation window for browsing folders, you have to do a bit of extra work. Instead of double-clicking an icon, right-click the icon and select Browse Folder from the pop-up menu. Nautilus then opens a navigation window with the contents of the object represented by the icon. For example, double-click the home folder icon in the upper-left corner of the GNOME desktop.
