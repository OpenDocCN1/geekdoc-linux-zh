# Icon pop-up menus

Right-clicking any desktop icon in GNOME or KDE causes another menu to appear (see Figures 1-4 and 1-5). Many items on this pop-up menu are the same no matter what icon you click — but right-clicking certain icons (for example, the Trash icon) produces a somewhat different menu. You can perform the following typical tasks from icon pop-up menus:

+   - Open a folder in a file manager.

+   - Open a file with an application that you choose.

+   - Rename the icon.

+   - Move the icon to the trash.

+   - View the properties of that icon.
