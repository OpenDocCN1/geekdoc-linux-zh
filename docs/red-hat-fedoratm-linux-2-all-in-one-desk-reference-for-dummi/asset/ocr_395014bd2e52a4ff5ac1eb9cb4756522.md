# Adding graphics and special effects

To jazz up your presentation, you may want to add graphics, charts, and other special effects to the slides. With Impress, you can do nearly everything you can think of — all you have to decide is how many bells and whistles your presentation needs. It's your call, but I recommend using these features judiciously lest they detract from your presentation's main message.

If you want to add some simple drawings to the slide, you can pick from the drawing tools on the toolbar on the left side of the Impress window (refer to Figure 3-1) and start drawing on the slide. To insert an image into the slide, choose Insert::Graphics and then select the image file you want to insert.
