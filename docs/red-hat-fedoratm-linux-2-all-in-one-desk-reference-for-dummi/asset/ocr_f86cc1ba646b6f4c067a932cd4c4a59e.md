When properly installed, the Linux kernel loads the driver for the Ethernet card every time it boots. To verify that the Ethernet driver is loaded, type the following command in a terminal window:

```
dmesg | grep -A 2 'grep eth0 /etc/modprobe.conf | cut -d '' -f 3'
```

This command searches the boot messages for any line that contains the name of the first Ethernet card (the command in backquotes — ‘grep eth0 /etc/modprobe.conf | cut -d '' -f 3’ — picks out the alias for the eth0 device from the /etc/modprobe.conf file). The -A 2 option for grep causes it to print two lines after the line that matches the search criteria.

On my PC, I have a 3Com PCI 3c905C Ethernet card installed, so I get the following output when I type that command on my system:

```
3c905c: Donald Becker and others. www.scyld.com/network/vortex.html
0000:02:01.0: 3Com PCI 3c905C Tornado at 0x00d0. Vers LKL1.19
divert: allocating divert.blk for eth0
```

You see something similar, showing the name of your Ethernet card and other related information.
