# ## Using Impress

You get the AutoPilot when you choose File+ New+ Presentation. If you want a blank presentation, simply click Create in the first step of the AutoPilot. Impress displays the Modify Slide dialog box (shown in Figure 3-3) with a gallery of slide layouts.

![](bbox=[0.14, 0.52, 0.66, 0.81])

You can select a slide layout from the dialog box (refer to Figure 3-3) and click OK. Impress then displays an empty slide with the selected layout.
