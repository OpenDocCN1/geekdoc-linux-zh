# The panel

The panel is the long bar that stretches across the bottom of the desktop. Figures 1-6 and 1-7 show typical views of the GNOME and KDE panels, respectively.

The panel is a parking place for icons. Some icons start programs when you click them. Some show status (such as *what programs are currently running*), as well as information such as the date and time.
