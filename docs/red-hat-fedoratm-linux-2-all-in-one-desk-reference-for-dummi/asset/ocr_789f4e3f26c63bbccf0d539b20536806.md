You can log in using any of the accounts you define during or after the installation. There is always the root username, which happens to be the super-user or the administrator account. Whether you install Fedora Core yourself or someone installs it for you, you need to know the root password. Without that, you cannot do many of the tasks necessary to learn how Linux works.

For example, to log in as user spiderman, type spiderman in the first text field and press Enter (move the mouse over the login box before you begin typing). Then type spiderman’s password and press Enter. You then see the initial graphical user interface (GUI — pronounced gooey for short) appear. What you get depends on your choice of GUI — GNOME or KDE. If someone made the choice for you, don’t worry — GNOME and KDE are both quite good and versatile.
