In Linux, you can have long filenames (up to 256 characters), and filenames are case-sensitive. Often, these filenames have multiple extensions, such as `simple.tar`. UNIX filenames can take many forms, such as the following: `index.html`, `Makefile`, `kernel-2.6.3-1.109.i386.rpm`, `.bash_profile`, and `httpd_src.tar.gz`.

To locate a file, you need more than just the file's name. You also need information about the directory hierarchy. The extended filename, showing the full hierarchy of directories leading to the file, is called the pathname. As the name implies, it's the path to the file through the maze of the file system.
