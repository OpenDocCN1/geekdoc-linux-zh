# ### Playing sound files

You can use Rhythmbox or XMMS to open and play a sound file. Users with large MP3 music libraries like Rhythmbox, but the version that comes with Fedora Core does not include the MP3 capability. XMMS is not installed by default, but you can install it from the companion DVD by following these steps while logged in as `root`:

+   1. **Mount this book’s companion DVD.**
+       Insert the DVD into the DVD drive and type `mount /mnt/cdrom` in a terminal window (you may have to change `cdrom` to `cdrom1`, if the DVD drive is the second CD/DVD drive on your system).

+   2. **Install the XMMS RPM.**
+       Type the following commands from a terminal window (these commands assume that the DVD drive is mounted on `/mnt/cdrom`):

```
```sh
cd /mnt/cdrom/Fedora/RPMS
rpm -ivh xmms*
```
```

XMMS can play many types of sound files, including Ogg Vorbis, FLAC (Free Lossless Audio Codec, an audio file format that is similar to MP3), and Windows WAV. You find many WAV sound files — which usually have names that end with the `.wav` extension — in the `/usr/share/sounds` directory of your Linux system.
