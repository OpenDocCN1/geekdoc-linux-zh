# Playing with the Shell

In this case, the system is running Linux kernel version 2.6.5.

To read a file, use the `more` command. Here’s an example:

```
more /etc/passwd
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin
daemon:x:2:2:daem on:/sbin:/sbin/nologin
adm:x:3:4:adm:/var /adm:/sbin/nologin
... lines deleted ...
```

Amazing how many programs that can run on a system even when only you are logged in as a user, isn’t it?

As you can guess, you can do everything from a shell prompt, but it does take some getting used to.
