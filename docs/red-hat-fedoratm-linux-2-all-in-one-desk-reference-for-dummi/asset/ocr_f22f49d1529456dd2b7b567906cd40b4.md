If you want to match one of the characters $, |, *, ^, [, ], ., and /, you have to place a backslash before the character you want to match. Thus you type these characters as $, \|, \*, \^, \[, \], \\. and \/. Regular expressions often look confusing because of the preponderance of strange character sequences and the generous sprinkling of backslashes. As with anything else, however, you can start slowly and use only a few of the features in the beginning.
