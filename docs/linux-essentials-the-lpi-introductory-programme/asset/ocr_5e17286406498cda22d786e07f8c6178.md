# **6.24 Add a line like**

```
find /tmp -user $LOGNAME -type f -exec rm '{}' \n
```

or—more efficiently—

```
find /tmp -user $LOGNAME -type f -print0 \n | xargs -0 -r rm -f
```

to the file _.bash_logout_ in your home directory. (The LOGNAME environment variable contains the current user name.)

# **7.1 The regular expression** r+ **is a mere abbreviation of** r*r* **, so we could do without +. Things are different with ?, for which there is no convenient substitute, at least if we must assume (as in** grep **vs.** egrep **) that we cannot substitute** r? **by** r( |r) **(GNU grep supports the synonymous** r {1} **"—see Table 7.1—but this is not supported by the grep implementations of the traditional Unix vendors.

# **7.4 We’re looking for words starting with a (possibly empty) sequence of consonants, then there is an "a", then possibly consonants again, then an "e", and so on. We must take care, in particular, not to let extra vowels "slip through". The resulting regular expression is fairly unsavory, so we allow ourselves some notational simplification:**

```
$ k='[aeiou]'
$ grep -i[BJa]$k[es][i$]{k}$o${k}u${k}$ /usr/share/dict/words
abstemious
abstemiously
abstentious
acheilous
acheirous
acleistous
affectious
annelidous
```
