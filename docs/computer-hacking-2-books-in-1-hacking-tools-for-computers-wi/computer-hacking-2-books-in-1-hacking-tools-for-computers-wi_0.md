无论黑客是什么类型，他们的初始学习内容将与我们在书中讨论的相同，基本技能也是相同的。许多人问：“黑客在和平时期做什么做什么？”有些人认为黑客是每天做重复性工作的、无聊枯燥的人类。但这只是一个误解。黑客通常需要大量的时间来学习。除了学习，黑客应该将他们的知识应用到现实世界中。无论黑客做什么工作，其根本目的无非是在实践中掌握他们所学的。

## Linux 命令介绍
Linux 是一个在命令行界面（终端）运行的操作系统。在 Linux 被创建时，Arch 是一个著名的环境，基于终端界面。然而，在 Windows 之后，人们倾向于使用 Debian 系统。因此，我们需要了解 Linux 的命令。每个新用户被分配一组相应的子目录。无论你当前在哪个目录，都可以使用 `cd ~` 回到主目录。root 的根目录是 `/root`，这是一个特殊的地方。

1. **ls**：`ls` 命令列出文件和目录信息。它是 UNIX 的第一个命令，是 Linux 命令中最常用的命令之一。
```
ls
```
显示当前目录下的文件列表。

2. **cp**：`cp` 命令是“copy”的缩写，用于复制文件。如下：
```
cp firstfile.txt copyfile.txt
```
完成文件的复制。

3. **mv**：`mv` 命令是“move”的缩写，是移动命令。例如，如果你想将 secondfile 移动到 example 目录：
```
mv secondfile example/
```
完成移动。

4. **rm**：：`rm` 命令是“remove”的缩写，用于删除。它删除文件和目录。例如，在当前目录下删除 example1.dat：
```
rm example1.dat
```

5. **echo**：`echo` 是在屏幕上显示字符串的命令。如果你在屏幕上看到单词 Jesus，那么就是这个命令。

什么是权限？
权限是文件和目录的设置，由 UNIX 处理。可以根据所有者、组和其他类型设置文件或目录的访问，是否可以执行、写入或读取。例如，如果你想设置 test 文件夹中 example.sh 的权限，让所有用户拥有所有权限如下：

## rtgen
`rtgen` 工具用于生成彩虹表（rainbow tables）。彩虹表是针对各种可能的字母组合的预计算哈希值的巨大集合。彩虹表并不一定适用于 MD5 算法。有多种算法，它可以快速破解各种密码。密码越复杂，彩虹表越大，现在主流的彩虹表为 100G 或更大。

使用 `rtgen` 工具生成彩虹表。具体步骤如下：

### (1) 切换到 `rtgen` 目录
执行命令如下：

```bash
root@kali:~# cd /usr/share/rainbowcrack/
```

### (2) 使用 `rtgen` 命令
基于 MD5 生成彩虹表。执行命令如下：

```bash
root@kali:/usr/share/rainbowcrack# ./rtgen md5 loweralpha-numeric 1 5 0 3800 33554432 0
```

上面的信息显示了彩虹表的参数和生成过程。例如，生成的彩虹表文件名为 `.md5_loweralpha-numeric#1-5_0_3800x33554432_0.rt`；该表使用 MD5 哈希算法进行加密，并使用了字符集 `abcdefghijklmnopqrstuvwxyz0123456789`。

### (3) 排序彩虹表
为了方便使用生成的彩虹表，使用 `rtsort` 命令对表进行排序。执行命令如下：

```bash
root@kali:/usr/share/rainbowcrack# rtsort md5_loweralpha-numeric#1- 5_0_
```

## John the Ripper
这是一个著名的密码破解工具，用于破解密码和其他内容。Web 攻击是黑客最重要的阶段之一，你需要详细了解它以获得更好的结果。

### John the Ripper 的四种破解模式：
1. **字典文件 (Wordlist Mode)**：这是 John 支持的破解模式中最简单的一种。你唯一需要做的就是告诉 John 字典文件在哪里（字典文件是文本文件，内容每行一个单词）。它代表尝试的密码，以便进行提取和破解。在“字典文件”破解模式下，你可以使用“单词更改”功能自动将这些规则应用到每个读取的单词，以增加破解几率。
2. **单次破解模式 (Single Crack Mode)**：“简单”破解模式是为那些使用“账户作为密码”的懒人设计的。所谓的“使用账户作为密码”意味着如果用户账户是“John”，那么它的密码也被视为“john”。在“简单”模式下，john 将使用密码文件中的“account”字段来破解密码，并使用各种“单词更改”规则应用到“account”上以增加破解几率。例如，账户“john”将尝试使用“john”、“john0”、“njoh”、“j0hn”等规则变化来尝试密码。
3. **增量模式 (Incremental Mode)**：这是 John 最强力的破解模式。它会自动尝试所有可能的字符组合并将它们作为密码进行破解。这种破解模式所需的时间非常长，因为尝试组合组合非常耗时，所以 John 会定义一些“字符频率表”来帮助破解。简而言之，这种破解方法是“暴力破解”，通过测试所有可能的密码组合来获得正确结果。
4. **外部模式 (The External Mode)**：这种破解模式允许用户用 C 语言编写一些“破解模块程序”，然后在 John 中它们。事实上，所谓的“破解模块程序”是用 C 语言设计的子函数声明，其功能是为 John 生成一些供其尝试破解的单词。在执行 John 程序时，它会在加载这些“破解模块程序”时自动编译这些 C 语言子呈现形式，然后使用它们。

### 参数：
- `-single`: 
  - 描述：使用“单次破解”模式进行解密，主要基于用户的“账户”变化来猜测，更改规则记录在 `JOHN.INI` 文件的 `[List.Rules:Single]` 区域。
  - 示例：`john -single passwd`
- `-wordfile: [dictionary file name] -stdin`:
  - 描述：使用“字典文件”解密模式，通过读取字典文件中的单个单词进行解密；或者你可以添加 `-stdin` 参数表示由键盘输入的单词。
  - 示例：`john -wordfile:bigdict.dic passwd`
- `-rules`:
  - 描述：在“字典文件”破解模式下，开启单词规则更改功能，例如将字典文件读入单词 cook，然后开启单词更改，程序可能会尝试 cook、c00k、cooker、cook0 等其他单词。详细的更改规则记录在 `JOHN.INI` 文件的 `[List.Rules:Wordlist]` 区域。
  - 示例：`john -wordfile:bigdict.dic -rules passw`
- `-incremental[:mode name]`（参数也可以缩写为 `-i[:mode name]`）：
  - 描述：使用“增强”破解模式解密，结合所有可能的字符作为密码。在 `JOHN.INI` 文件的 `[Incremental:*****]` 区域定义了许多方案名称，你可以指定使用哪种模式进行破解。
  - 示例：`john -i:all passwd`
- `-external: [module name]`:
  - 描述：使用“插件模块”进行解密模式，用户可以编写额外的“破解模块”。破解模块”记录在 `JOHN.INI` 文件的 `[List.External:******]` 区域。
  - 示例：`john -external:double passwd`
- `-stdout[:LENGTH]`:
  - 描述：此选项与破解无关，只是将 John 生成的单词显示在屏幕上。
  - 示例：`john –i:all –stdout`
- `-restore[: Reply File Name]`:
  - 描述：继续上次中断的解密。当 John 执行破解工作时，可以按下 `<CTRL C>` 键中断，当前的解密进度将存储在名为 "restore" 的文件中。使用 `-restore` 参数，你可以读取点击“restore”文件时上次断开的位置，然后继续破解。
  - 示例：`john –restore`

## Snort
`Snort` 是一款在 Kali Linux 中可用的开源软件，以其用 `C` 编写入侵检测系统 (NIDS) 而闻名。它支持 Windows 和 Linux 平台，我更倾向于 Linux 操作系统，因此我会在 Linux 上学习研究 `snort`。`Snort` 有三种运行模式，包括嗅探、数据包记录和入侵检测。

## Snort 规则选项
所有 `snort` 规则选项都用分号 `;` 分隔。规则选项关键字及其参数之间用冒号 `:` 分隔。根据这种方法，`snort` 中有 `42` 个规则选项关键字，可以帮助我们执行各种操作，如嗅探和记录包。

- `Msg`: 在数据包日志中打印一条消息。
- `Logto`: 将数据包记录到用户定义的文件，而不是记录标准格式。
- `Ttl`: 检查 `ip header` 中 `ttl` 的值。
- `Tos`: 检查 IP 头中 `TOS` 字段的值。
- `Id`: 检查 ip 头中的分片 `id` 值。
- `Ipoption`: 查看 IP 选项字段的特定编码。
- `Fragbits`: 检查 IP 头的分片位。
- `Dsize`: 检查数据包负载大小的值。
- `Flags`: 检查 `tcp` 标志的值。
- `Seq`: 检查 `tcp` 序列号的值。
- `Ack`: 检查 `tcp` 响应（确认）的值。
- `Window`: 测试 `TCP` 窗口字段的特殊值。
- `Iype`: 检查 `icmp` 类型。
- `Icode`: 检查 `icmp code` 值。
- `Icmp_id`: 检查 `ICMP ECHO ID` 值。
- `Icmp_seq`: 检查 `ICMP ECHO` 序列号。
- `Content`: 在数据包负载中搜索指定的样式。
- `Content-list`: 在数据包负载中搜索一组模式。
- `Offset - content`: 选项的修符，设置开始搜索的位置。
- `Depth - content`: 选项的修符，设置搜索的最大深度。
- `Nocase`: 指定内容字符串不区分大小写。
- `Session`: 记录指定会话的应用层信息内容。
- `Rpc`: 监控特定应用程序/进程调用的 `RPC` 服务。
- `Resp`: 反应（切断连接等）。
- `React`: 响应（阻止网站）。
- `Reference`: 外部攻击引用 ID。
- `Sid`: snort 规则 ID。
- `Rev`: 规则的版本号。
- `Classtype`: 规则分类标识符。
- `Priority`: 规则优先级标识号。
- `Uricontent`: 在数据包 URI 部分搜索内容。
- `Tag`: 规则的高级记录行为。
- `Ip_proto`: IP 头协议字段值。
- `Sameip`: 确定源 IP 和目的 IP 是否相等。
- `Stateless`: 忽略流状态的有效性。
- `Regex`: 通配符模式匹配。
- `Within`: 强制关系模式匹配的范围。
- `Byte_test`: 数字模式匹配。
- `Byte_jump`: 数字模式测试和偏移调整。

## Aircrack-ng
`Aircrack-ng` 是一款基于 `802.11` 协议、用于 WEP 和 WPA 加密的工具。该工具主要使用两种攻击来破解 WEP：一种是针对 WEP 漏洞发现的 FMS 攻击；另一种是 `Korek` 攻击，这种攻击比 FMS 高效得多。

### 破解 WEP
WEP 协议是设备之间传输加密数据的一种，旨在防止非法用户窃听。然而，分析人员已识别出 WEP 在 2003 年之前的多个漏洞。本节描述了使用 `Aircrack` 破解 WEP 网络的方法。步骤如下：

1) 使用 `airmon-ng` 命令查看无线网络接口。执行以下命令：
```bash
## airmon-ng
```
输出显示了当前系统的无线网络接口：`Interface`、`Chipset` 和 `Driver`。

2) 尝试更改系统或设备的 MAC 地址。修改 MAC 地址可以隐藏真实地址。在更改 MAC 地址之前，需要停止接口。执行命令：
```bash
airmon-ng stop wlan0
```
执行上述命令后，`wlan0` 停止。此时你可以尝试命令：
```bash
root@kali:~# macchanger --mac 22:33:44:55:66 wlan0
```
永久 MAC: `00:c1:39` (未知);当前 MAC: `00:c0:77` (未知);新 MAC: `22:33:44` (未知)。

3) 使用 `airodump-ng` 命令定位附近的无线网络。执行以下命令：
```bash
## airodump-ng wlan0
```
显示附近所有的可用无线网络。当你找到想要攻击的路由器时，按 `C` 停止。从输出中，你可以看到几个参数：
- `BSSID`: 无线地址
- `PWR`: 网卡报告的信号强度
- `BEACONS`: 发布的包数
- `Ch`: 通道（从 Beacon 中获得）
- `Essid`: 所谓的 SSID
- `FRAMES`: 客户端发送的包数

4) 使用 `airodump-ng` 捕获指定 BSSID 文件。`airodump-ng` 常用选项如下：
- `c`: 指定通道
- `-w`: 指定保存文件名
- `-b`: 指定 BSSID

5) 打开一个新的终端窗口并运行 `aireplay-ng` 命令。`aireplay-ng` 的格式如下：
`aireplay-ng -1 -a [BSSID] -h [our MAC address] -e [ESSID] [Interface]` `auth`

6) 使用 `aireplay-ng` 向路由器发送一些流量以便捕获数据。格式如下：
`aireplay-ng -3 -b [BSSID] -h [Our MAC address] [Interface]`
输出是使用 `aireplay-ng` 读取 ARP 请求，此时切换到 `airodump-ng` 接口，你可以看到 ARP 请求数量增加。在捕获到一定数量的 IV 包（达到 2000 个）后，继续抓取。

7) 使用 `aircrack-ng` 破解密码。执行命令：
```bash
aircrack-ng -b xx:cap
```
从输出中，你可以看到“KEY FOUND”，密码已找到。

# 端口重定向攻击
端口重定向也称为端口转发或端口映射。接收端口数据包（如端口 80）并将其流量重定向到不同端口（如端口 8080）的过程。这种攻击的益处是将流量重定向到给定设备的未加密端口。本节描述了使用 `Arspoof` 进行端口重定向。

## 渗透测试
渗透测试遵循特定的策略和指南，类似于其他方法。测试的操作由方 A 负责，而方 B 负责执行。测试的目标是识别漏洞并提供适当的保护措施。渗透测试，简称为 PT，分为：
- 单节点（Single）：例如，提供特定服务的网站，攻击仅限于网站。
- 服务器（Server）：对于提供一个或多个服务的计算机，方法取决于提供的服务。
- 农场（Farm）：有时方 A 想要尽可能在模拟攻击上下文中。
- 全系统（System-wide）：测试所有相关系统。概念与分段相同。
- 人员（Personnel）：系统或应用程序通常由专门人员处理。在安全意识上，人员应高于平均水平。
- 所有机构（All institutions）：测试所有资产，因为范围太宽，很难进行全面的评估。
- 健康检查（Health check is not an attack）：渗透测试是为了尽早发现漏洞。作为改进的基础，测试必须考虑系统的持续操作。

## 方法
- 黑盒（Black box）：方 B 只知道目标的名称或 URL。其他信息必须在测试活动期间自行收集。使用黑盒测试是方 B 的技能，因为它接近真实的攻击。
- 白盒（White Box）：方 A 将尽可能提供目标信息，方 B 可以专注于寻找系统的漏洞（漏洞），并使用白盒测试测试系统的保护能力。
- 灰盒（Gray box）：当然，有时方 A 不向测试目标（如外包开发的系统）提供完整信息。方 B 无法提前获取系统信息，但方 A 仍协助方 B 获取尽可能等的信息。盒子处于黑和白之间。
- 双黑盒（Double black box）：有时方 A 想要在模拟攻击上下文中尽可能测试。不仅要测试系统的保护能力，还要测试其人员的警觉性或弹性。秘密地委托方 B 进行渗透操作，相关人员不知道渗透测试，方 B 无法获取系统的详细信息。因此，进攻和防御双方在黑暗中竞争，这被称为双黑盒（或双盲）测试。
- 双白盒（Double white box）：与双黑盒不同，双方彼此存在。

## 为什么公司需要渗透测试？
系统上线服务，黑客会继续尝试攻击。为了保护组织，测试是为了：
- 信息不当泄露或篡改
- 网络架构设计问题
- 防火墙设置问题
- 系统和应用程序漏洞
- 评估同等能力的入侵者需要多久
- 入侵实施评估
- 加强系统安全
- 减少入侵后的损失

## 黑客攻击路线图

如果黑客想要攻击目标计算机，无法通过 DOS 命令实现。它还需要一些强大的入侵工具，如端口扫描工具、网络嗅探工具、木马病毒制作工具和远程控制工具。本节简要介绍黑客常用的入侵工具。

### a) 端口扫描
端口扫描工具具有扫描端口的功能。所谓的端口扫描意味着黑客可以通过发送一组端口扫描信息来扫描目标计算机的信息。这些端口是黑客的入侵通道。一旦黑客了解了这些端口，他们就可以入侵目标计算机。除了扫描开放端口的能力外，端口扫描工具具有自动检测远程目标计算机安全漏洞的能力。使用端口扫描工具，用户可以在不留痕的情况下发现目标计算机上的各种 TCP 端口。黑客常用的端口扫描工具有 `SuperScan` 和 `XScan`。

### b) 嗅探工具
嗅探工具是在局域网内嗅探包的工具。所谓的嗅探是监听流经局域网的所有数据包。通过监听和分析这些数据包，你可以窥探局域网内他人的私密信息。嗅探工具只能在局域网中使用，无法直接嗅探互联网上的目标计算机。黑客常用的数据嗅探工具有 `Sniffer Pro` 和 `Eiffel Detective`。

### c) 木马制作工具
顾如名，木马制作工具是制作木马的工具。由于木马具有盗取目标计算机个人私密信息的功能，许多初级黑客喜欢使用木马制作工具。木马制作工具的工作原理基本相同：首先使用工具配置木马服务器。一旦木马服务器运行，黑客就可以使用木马完全控制计算机。木马制作工具的操作非常简单，黑客常用的木马制作工具是“冰川”等。

### d) 远程控制工具
远程控制工具是具有远程控制功能的工具。尽管控制方法不同（有些工具通过植入服务器进行控制，有些用于直接控制局域网），一旦黑客使用远程控制工具控制计算机，就像坐在它面前一样。黑客常用的远程控制工具是网络执法工具。

## 攻击计算机

在互联网上，为了防止黑客入侵自己的计算机，有必要理解攻击计算机的常用方法。黑客常用的方法包括数据驱动攻击、文件攻击、伪造信息攻击和远程操作。

### 1) 数据驱动攻击
数据驱动攻击是黑客发送或拷贝看似无害程序发起的攻击。这种攻击允许黑客在计算机上修改文件。数据驱动攻击主要包括缓冲区溢出攻击、格式字符串攻击、输入验证攻击和漏洞攻击。

### 2) 伪造信息攻击
伪造信息攻击意味着黑客通过发送伪造路由信息在源计算机和目标计算机之间构建虚假路径。这可以获取账户信息和密码。

### 3) 信息协议
在局域网中，IP 地址源允许数据包选择路径。当黑客尝试连接不可达的计算机时，只需要设置 IP 地址源使数据包到达防火墙，从而对 ICMP 协议进行攻击。

### 4) 远程操作
远程操作意味着黑客在计算机上启动可执行程序。当用户输入账户和密码时，程序显示“系统失败”消息。这种类型的攻击在互联网上非常常见。

### 5) 局域网安全
在局域网中，安全是重要因素之一。当系统管理员配置错误时，这些错误可以为黑客提供机会。黑客使用 `finger`、`netstat` 等来实现攻击。

### 6) 重发攻击
重发攻击意味着黑客收集特定的数据包并将其重发到计算机。在局域网中，重发消息可以改变路由列表。

### 7) 漏洞攻击
漏洞攻击意味着黑客传输源路径到局域网外的计算机。路由器会将此消息转发到防火墙，而不是计算机。

While 循环简单来说是在开始循环时检查一个布尔表达式，如果为真，则执行循环；如果为假则停止循环。

#### 2) For 循环
For 循环的工作与 while 循环不同。它让我们使用变量集中每个可用变量，直到它满足条件。For 循环就像一个带有条件的暴力破解工具。

## 面向对象编程
尽管 Python 是一种模块化和面向函数的语言，但它也采用了面向对象的方法，由于其灵活性和模块化，帮助创建了数百种软件。我们在这里详细解释面向对象编程的不同概念。

### 什么是类？
类是一个将一切组织在一个地方的模型或策略。每个可以使用的方法和变量都被组织并统称为一个类。

### 什么是对象？
这是实际工作的地方。它通过与每个变量或实例建立方法或连接，以获得你想要的结果。

### 什么是超类？
与其到处创建方法，Python 再次使用了面向对象的方法。
