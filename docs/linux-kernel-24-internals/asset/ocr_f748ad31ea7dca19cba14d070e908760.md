14. **private_data**: private per-file data which can be used by file systems (e.g. coda stores credentials here) or by device drivers. Device drivers (in the presence of devfs) could use this field to differentiate between multiple instances instead of the classical minor number encoded in `file->f_dentry->d_inode->i_rdev`.
