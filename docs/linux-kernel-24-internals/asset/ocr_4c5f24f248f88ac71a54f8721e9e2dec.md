(increase or decrease), then `update_queue()` is called to traverse the queue of pending semaphore operations for the semaphore set and awaken any sleeping tasks that no longer need to block.

+   * If the `status` element of the `sem_queue` structure is NOT set to 1, and the `sem_queue` element has not been dequeued, then the task was awakened by an interrupt. In this case, the system call fails with EINTR. Before returning, `current->`sem`sleeping` is cleared, and the `sem_queue` is removed from the queue. Also, `update_queue()` is called if any of the operations were altering operations.
+   * If the `status` element of the `sem_queue` structure is NOT set to 1, and the `sem_queue` element has been dequeued, then the semaphore operations have already been executed by `update_queue()`. The queue `status`, which could be 0 for success or a negated error code for failure, becomes the return value of the system call.

# Semaphore Specific Support Structures

The following structures are used specifically for semaphore support:

# struct sem_array

```
/ * One sem_array data structure for each set of semaphores in the system. */
```
struct sem_array {
    struct kern_ipc_perm sem_perm; /* permissions .. see ipc.h */
    time_t sem_otime; /* last semop time */
    time_t sem_ctime; /* last change time */
    struct sem *sem_base; /* ptr to first semaphore in array */
    struct sem_queue *sem_pending; /* pending operations to be processed */
    struct sem_queue **sem_pending_last; /* last pending operation */
    struct sem_undo *undo; /* undo requests on this array */
    unsigned long sem_nsems; /* no. of semaphores in array */
};
