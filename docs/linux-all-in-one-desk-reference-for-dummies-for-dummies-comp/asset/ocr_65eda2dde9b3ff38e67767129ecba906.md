| Boot Command | What It Does |
| :--- | :--- |
| `knopix 1` | Starts Knopix in run level 1 (single-user mode), which can be used to perform rescue operations |
| `knopix 2` | Starts at run level 2, which provides a text mode shell prompt only |
| `knopix acpi=off` | Disables ACPI (Advanced Configuration and Power Interface) completely |
| `knopix atapicd` | Uses the ATAPI CD-ROM interface instead of emulating a SCSI interface for IDE CD-ROM drives |
| `knopix`<br>`desktop=<wname>` | Uses the specified Window Manager instead of the default KDE (<i>wname</i> can be one of: *fluxbox*, *icewm*, *kde*, *larwm*, *twm*, *wmaker*, or *xfce*.) |
| `knopix dma` | Enables direct memory access (DMA) for all IDE drives |
| `knopix`<br>`floppyconfig` | Runs the shell script named *knopix.sh* from a floppy (The shell script contains Linux commands that you want to run.) |
| `knopix`<br>`fromhd=`<br>*/dev/hda1* | Boots from a previously copied image of Live CD that's in the specified hard disk partition |
| `knopix`<br>`hsync=80` | Uses an 80 kHz horizontal refresh rate for X (enter the horizontal refresh rate you want X to use) |
| `knopix`<br>`lang=xx` | Sets the keyboard language as specified by the two-letter code *xx* (use one of the following for *xx*: *cn* = Simplified Chinese, *de* = German, *da* = Danish, *es* = Spanish, *fr* = French, *it* = Italian, *nl* = Dutch, *pl* = Polish, *ru* = Russian, *sk* = Slovak, *tr* = Turkish, *tw* = Traditional Chinese, or *us* = U.S. English) |
| `knopix`<br>`mem=256M` | Specifies that the PC has the stated amount of memory (in megabytes) |
| `knopix`<br>`myconf=`<br>*/dev/hda1* | Runs shell script *knopix.sh* from the */dev/hda1* partition (enter the partition name where you have the *knopix.sh* file.) |
| `knopix`<br>`myconf=`<br>`scan` | Causes Knopix to search for the file named *knopix.sh* and execute the commands in that file, if any |
| `knopix`<br>`noeject` | Does not eject the Live CD after you halt Knopix |
| `knopix`<br>`noprompt` | Does not prompt to remove the Live CD after you halt Knopix |
| `knopix`<br>`noxwheel`<br>`mouse` | Forces PS/2 protocol for a PS/2 mouse or touchpad (as opposed to being detected automatically) |
| `knopix`<br>`noxxx` | Causes Knopix to skip specific parts of the hardware detection (where *xxx* identifies the hardware or server that should not be probed: *apic* = Advanced Programmable Interrupt Controller, *app* = Accelerated Graphics Card, *apm* = Advanced Power Management, *audio* = sound card, *d&d* = Display Data Channel, *dhcp* = Dynamic Host Configuration Protocol, *fsstab* = file system table, *firewire* = IEEE 1394 high-speed serial bus, *pcmcia* = PC Card, *scsi* = Small Computer System Interface, *swap* = hard drive space used for virtual memory, *usb* = Universal Serial Bus) |
