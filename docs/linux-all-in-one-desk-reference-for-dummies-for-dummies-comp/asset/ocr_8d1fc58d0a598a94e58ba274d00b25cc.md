In SUSE, you can configure the services from YaST Control Center — Main Menu>‘System>Control Center (YaST). Click System in the left window and then click System Services (Runlevel). YaST opens the System Services (Runlevel) window (see Figure 1-3), where you can enable or disable serv-ices. To enable or disable services at specific run levels, click the Expert Mode button and edit the services in the new list that appears.
