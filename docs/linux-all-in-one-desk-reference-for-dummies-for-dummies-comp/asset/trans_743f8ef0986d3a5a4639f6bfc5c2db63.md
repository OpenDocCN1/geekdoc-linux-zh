对于一个作品的源代码，指的是为该作品进行修改的首选形式。对于一个可执行作品，完整的源代码意味着其包含的所有模块的所有源代码，加上任何相关的接口定义文件，加上用于控制该可执行文件编译和安装的脚本。然而，作为特殊例外，分发的源代码无需包含任何通常随可执行文件运行的操作系统的主要组件（编译器、内核等，以源代码或二进制形式）分发的内容，除非该组件本身随附可执行文件。
