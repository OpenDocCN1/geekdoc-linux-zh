This means that if no rules are defined, Fedora Core accepts a packet. You should be aware of these differences when you use the firewall utilities in various Linux distributions.

On a Fedora Core system, the process of saving and restoring firewall rules is automated by saving the iptables rules in the file /etc/sysconfig/iptables and by enabling iptables with the following command:

```
chkconfig iptables on
```

That ensures the /etc/init.d/iptables start command executes at the system startup. The /etc/init.d/iptables script then runs the /sbin/iptables-restore command to restore the iptables rules from the /etc/sysconfig/iptables file.
