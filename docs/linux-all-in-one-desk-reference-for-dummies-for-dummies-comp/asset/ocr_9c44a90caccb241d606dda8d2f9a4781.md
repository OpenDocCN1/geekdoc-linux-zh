Read the resource records in the zone files, at least the ones of type **SOA**, **NS**, **A**, **PTR**, and **MX**, which are some of the most commonly used. (You’ll find the zone files in the `/etc/bind` directory in Debian and Xandros, the `/var/named` directory in Fedora Core, and the `/var/lib/named` directory in SUSE.) Next, I briefly describe these records, illustrating each record type through an example.

A typical **SOA** record has the following format:

```
@ IN SOA @ root (
	42 ; serial
	3h ; refresh -- 3 hours
	15m ; retry -- 15 minutes
	1w ; expire -- 1 week
	1d ) ; minimum -- 1 day
```

The first field specifies the domain as **@**, which means the current domain (by default, the zone name, as shown in this `/etc/named.conf` file). The next field specifies a TTL of one day for this record. The class field is set to **IN**, which means the record is for Internet. The type field specifies the record type as **SOA**. The rest of the fields constitute the data for the **SOA** record. The data includes the name of the primary name server (in this case, **@**, or the current domain), the e-mail address of the technical contact, and five different times enclosed in parentheses.
