Note that the exact output from the `ftp` command might be different because some distributions, such as Debian, use a text mode version of gFTP as the command-line FTP client.

In the following sample FTP session, I use the command-line FTP client to log in using my username (*naba*) and browse the directories on one of my Linux systems. When you try a similar operation, replace the name with your user-name and provide your password.
