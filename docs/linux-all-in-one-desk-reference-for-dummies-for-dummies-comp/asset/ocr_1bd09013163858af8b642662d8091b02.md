Notice that the pane has two radio buttons: Users and Groups (as shown in Figure 2-1). Selecting the Users radio button displays the current list of users from the /etc/passwd file. Selecting the Groups radio button lists the names of groups from the /etc/group file. Initially, the User and Group Administration tool filters out any system users and groups. However, you can view the system users by clicking Set Filter and choosing System Users from the drop-down menu. (System Users refers to user accounts that are not assigned to human users; rather, these user accounts are used to run various services.)

You can Add new Users and Groups or Edit existing Users and Groups from the pane shown in Figure 2-1.

To add a new user account, click the Add button and enter the information requested in the New Local User window, as shown in Figure 2-2.

![](bbox=[0.24, 0.42, 0.72, 0.73])

Fill in the requested information in the window (refer to Figure 2-2), and click the Accept button. The new user now appears in the list of users in the User and Group Administration pane.

You can add more user accounts, if you like. When you finish, click the Finish button in the User and Group Administration pane (refer to Figure 2-1) to create the new user accounts.
