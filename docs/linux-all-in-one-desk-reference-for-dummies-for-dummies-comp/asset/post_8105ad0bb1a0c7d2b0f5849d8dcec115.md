
## Introducing Firefox’s user interface

你可以通常通过点击面板上的图标或从GUI桌面菜单中选择来启动Firefox。

当Firefox启动时，它显示一个带有默认主页的浏览器窗口。（Web服务器上的主Web页面被称为*主页*。）你可以配置Firefox使用不同的Web页面作为默认主页。

图2-4显示了一个来自美国政府网站（*www.irs.gov*）的Web页面，以及Firefox浏览器窗口的主要元素。请注意，Firefox支持*标签页浏览*，这意味着你可以通过按Ctrl+T打开一个新的标签页，并在该标签页中查看Web页面。这样，你可以在一个窗口中查看多个Web页面。

Firefox Web浏览器在其用户界面中包含了许多功能，但你可以轻松掌握它。你可以从基础知识开始使用Firefox，然后逐渐扩展到尚未探索的领域。

## Firefox toolbars

从窗口顶部开始，你会看到一个带有标准菜单（文件、编辑等）的菜单栏，随后是两个工具栏——导航工具栏和书签工具栏。书签工具栏下方的区域是当前Web页面显示的位置。

以下是导航工具栏（位于菜单栏下方）上的按钮和文本框（从左到右）的功能：

- Back：移动到上一个Web页面。
- Forward：移动到你之前可能后退过的页面。
- Reload：重新加载当前Web页面。
- Stop：停止加载当前页面。
- Home：转到主页。
- Location：显示当前Web页面的URL。（在此框中输入URL并按Enter键查看该Web页面。）
- Go：转到在Location文本框中输入的URL。
- Google Search：点击可搜索各种网站，如Google、Yahoo!、Amazon.com、Dictionary.com和eBay；输入文本并按Enter键搜索当前选定的网站（默认为Google）。

### Status bar

你可以把Firefox窗口底部边缘的栏看作状态栏，因为该区域的中间部分在Firefox加载Web页面时会显示状态信息。

### TECHNICAL STUFF

在Firefox状态栏的右侧，当你访问安全的Web网站时，会出现一个安全挂锁图标。Firefox支持使用SSL在浏览器和Web服务器之间传输加密数据的安全版本HTTP。当Firefox连接到支持安全HTTP的Web服务器时，状态栏右边缘会出现一个锁定的安全挂锁图标。否则没有安全挂锁图标，表示连接不安全。安全HTTP传输的URL以https://开头，而不是通常的http://（注意https中的额外s）。

### TIP

Firefox在状态栏的左侧显示状态消息。你可以观察这个区域的消息以查看发生了什么。如果你将鼠标悬停在Web页面上的链接上，状态栏会显示该链接的URL。

你的主页是启动Firefox时加载的页面。默认主页取决于发行版。通常主页是系统硬盘上的一个文件。更改主页很容易。

首先，找到你想作为主页的Web页面上的页面。你可以用任何方式到达该页面。你可以使用搜索引擎查找你想要的页面，可以在Location文本框中输入URL，甚至可能偶然到达你想要作为主页的页面。这并不重要。

当你在Firefox中查看你想作为主页的Web页面时，从Firefox菜单中选择Edit Preferences。偏好设置对话框出现，如图2-5所示。

在图2-5的右侧，注意偏好设置中的Home Page部分。然后你会看到主页的Location文本框，地址下方是一个Use Current Page按钮。点击该按钮将使当前页面成为你的主页。

## Surfing the Net with Firefox

你从主页去哪里取决于你。你要做的就是点击并看看你最终到达哪里。移动你的鼠标。当你鼠标指针变成带有伸出食指的手形时，你就知道在一个链接上。点击链接，Firefox将下载该链接引用的Web页面。

你如何使用Web取决于你想做什么。刚开始时，你可能会进行大量探索——浏览网站并跟随链接，没有具体目标（你可以称之为Web窗口购物）。

另一种更有目的性的Web使用方式是从网络查找特定信息。例如，你可能想定位包含指定关键字文档的所有网站。对于这样的搜索，你可以使用网络上可用的许多Web搜索工具之一。Firefox的搜索文本框会将你带到Google Web搜索页面（www.google.com）。

第三种使用方式是访问一个具有已知URL的特定网站。例如，当你阅读本书中关于特定主题的内容时，你可能会遇到一个特定的URL。在这种情况下，你想直接转到该Web页面。

![](img/11709a8f88c8cd03868a929dc94c0e2b_369_0.png)

如果你想用Firefox浏览网络，你只需要一个起始Web页面——然后你可以点击任何吸引你的东西。例如，选择Firefox导航工具栏中Location文本框中的文本，输入www.yahoo.com，然后按Enter。你到达了Yahoo!主页，显示了Yahoo! Web目录——按主题组织。这就是你的起点。你要做的就是点击，你就上路了！

Internet新闻组类似于Web时代前的公告板系统（BBSs）或AOL和MSN等在线系统提供的论坛。基本上，新闻组提供了一个全球性的分布式会议系统。你可以发布文章——本质上是一封发给整个群体的一封电子邮件——并回应其他人发布的文章。

把Internet新闻组想象成一个聚集地——一个虚拟的会议场所，你可以在那里提问并讨论各种议题。（而且最棒的是，你讨论的一切都被归档以备后患。）

要参与新闻组，你需要访问新闻服务器——你的Internet服务提供商（ISP）可以提供这种访问权限。你还需要一个新闻阅读器。幸运的是，Linux附带了你可以用来阅读新闻组的软件。在本章中，我向你介绍新闻组，并展示如何使用几个新闻阅读器阅读新闻组。我还简要解释了你如何免费从几个网站阅读和搜索新闻组。

如今，阅读网站和网络日志摘要的另一种流行方式是使用可以接受RSS源的程序。在章节末尾，我简要描述了什么是RSS源，以及如何使用KDE Agregator等程序订阅RSS源并在你的Linux系统上阅读它们。

### 理解新闻组

新闻组起源于*Usenet*——一个广泛用于交换电子邮件和新闻项目的存储转发消息网络。Usenet像电报一样工作，新闻和邮件从一个系统中继到另一个系统。在Usenet中，系统不在任何网络上；系统只是互相拨号并使用UNIX-to-UNIX Copy Protocol (UUCP) 传输文本消息。
