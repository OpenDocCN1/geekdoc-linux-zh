The optional ttl field specifies the Time To Live—the duration for which the data can be cached and considered valid. You can specify the duration in one of the following formats:

+   - **N**, where *N* is a number meaning *N* seconds
+   - **Mw**, where *N* is a number meaning *N* weeks
+   - **Md**, where *N* is a number meaning *N* days
+   - **Mh**, where *N* is a number meaning *N* hours
+   - **Mm**, where *N* is a number meaning *N* minutes
+   - **Ms**, where *N* is a number meaning *N* seconds

The letters **w**, **d**, **h**, and **s** can also be in lowercase. Thus, you can write `86400` or `1d` (or `1D`) to indicate a duration of one day. You can also combine these to specify more precise durations, such as `5w6d1h` to indicate 5 weeks, 6 days, and 16 hours.

The **class** field specifies the network type. The most commonly used value for this field is **IN** for Internet.
