+   Reply: Opens a window where you can send a reply to the person who sent you the message you are reading now.

+   Reply All: Opens a window for sending a reply to everyone who is on the addressee list of the message you are reading now.

+   Forward: Brings up the current message in a window so that you can forward it to someone else.

+   Delete: Deletes the selected message.

+   Junk: Marks the selected messages as junk. (You can mark selected messages as junk and choose Tools\4Junk Mail Controls to block similar messages.)

+   Print: Prints the selected message.

+   Stop: Stops the current transfers with the mail server.
