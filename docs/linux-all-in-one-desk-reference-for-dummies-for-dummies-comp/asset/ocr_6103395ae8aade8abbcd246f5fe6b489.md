# GNOME

GNOME stands for GNU Network Object Model Environment (and GNU, as you probably know, stands for GNU’s Not UNIX). GNOME is a graphical user interface and a programming environment. The latest GNOME release is 2.x, also known as GNOME 2 for short. From the user’s perspective, GNOME is like Microsoft Windows. Behind the scenes, GNOME has many features that allow programmers to write graphical applications that can work together well. In this chapter, I point out only some key features of the GNOME GUI, leaving the details for you to explore on your own at your leisure.

If you’re curious, you can always find out the latest information about GNOME by visiting the GNOME home page at www.gnome.org.
