# Installing Other Software

Debian, MEPIS, and Ubuntu also come with a GUI package installer for APT called Syaptic Package Manager, which is quite intuitive to use. To try it, choose Applications->System Tools-> Syaptic Package Manager from the GNOME desktop in Debian. In MEPIS, choose Main Menu->System-> Syaptic Package Manager. In Ubuntu, choose Select System->Administration-> Syaptic Package Manager. (In Ubuntu, when prompted for a password, enter your normal user password because there is no root user in Ubuntu.)

After Syaptic Package Manager starts, it displays a Quick Introduction dialog box that tells you, briefly, how to mark packages for installation, upgrade, or removal, and how to get to the menu to perform these actions. After reading the Introduction, click Close to get rid of that dialog box.

If your package information is older than 48 hours, another dialog box prompts you to update the package information. Click Reload in that dialog box. Syaptic Package Manager then downloads the latest package information, closes the dialog box, and displays information about the packages in the main window, as shown in Figure 3-18.

![](bbox=[0.23, 0.5, 0.88, 0.75])

> **Figure 3-18:** You can install and remove packages by using Syaptic Package Manager.

By clicking the categories on the left side of the Syaptic Package Manager window you can view lists of various categories of packages on the right side of the window. A box to the left of each package indicates whether the package is installed or not. If you click on the package name, Syaptic Package Manager displays information about the selected package in the lower-right side of the window.
