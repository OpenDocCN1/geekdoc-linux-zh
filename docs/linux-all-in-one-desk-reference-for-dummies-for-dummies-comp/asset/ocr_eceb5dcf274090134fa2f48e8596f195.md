# Table 2-4 Standard Header Files in C

| Header File | Purpose |
| :--- | :--- |
| <assert.h> | Defines the assert macro. Used for program diagnostics. |
| <ctype.h> | Declares functions for classifying and converting characters |
| <errno.h> | Defines macros for error conditions, \texttt{EDOM} and \texttt{ERANGE}, and the integer variable \texttt{errno} where library functions return an error code |
| <float.h> | Defines a range of values that can be stored in floating-point types |
| <iso646.h> | Defines a number of macros that are helpful when writing C programs in non\textunderscore English languages that may use character combinations such as \&\& and \-\- for other purposes |
| <limits.h> | Defines the limiting values of all integer data types |
| <locale.h> | Declares the \texttt{locale} structure and the functions necessary for customizing a C program to a particular locale |
| <math.h> | Declares common mathematical functions and the \texttt{HUGE\_VAL} macro |
| <setjmp.h> | Defines the \texttt{setjmp} and \texttt{longjmp} functions that can transfer control from one function to another without relying on normal function calls and returns. Also defines the \texttt{jmp\_buf} data type used by \texttt{setjmp} and \texttt{longjmp}. |
| <signal.h> | Defines symbols and routines necessary for handling exceptional conditions |
| <stdarg.h> | Defines macros that provide access to the unnamed arguments in a function that accepts a varying number of arguments |
| <stddef.h> | Defines the standard data types \texttt{ptrdiff\_t}, \texttt{size\_t}, \texttt{wchar\_t}; the symbol \texttt{NULL}; and the macro for \texttt{fsetof}. |
| <stdio.h> | Declares the functions and data types necessary for input and output operations. Defines macros such as \texttt{BUFSIZ}, \texttt{EOF}, \texttt{SEEK\_CUR}, \texttt{SEEK\_END}, and \texttt{SEEK\_SET}. |
| <stdlib.h> | Declares many utility functions, such as the string conversion routines, random number generator, memory allocation routines, and process control routines (such as \texttt{abort}, \texttt{exit}, and \texttt{system}). |
| <string.h> | Declares the string manipulation routines such as \texttt{strcmp} and \texttt{strcpy}. |
| <time.h> | Defines data types and declares functions that manipulate time. Defines the types \texttt{clock\_t} and \texttt{time\_t} and the \texttt{tm} data structure |
| <wchar.h> | Defines data types and declares functions for working with wide character data types (\texttt{wchar\_t}). |
| <wctype.h> | Defines data types and declares functions for classifying and converting wide character data types (\texttt{wchar\_t}). |
