# Summing Up

Because of the growing popularity of Linux among Unix-like operating systems, bash has become the world’s predominant shell program. It has many of the best features of earlier shells and a few tricks of its. However, light weight and quick script execution is needed (for example, in embedded systems), dash is a good choice. Likewise, if working with other Unix systems is required, ksh or tsh will provide the necessary compatibility. For the adventurous among us, the advanced interactive features of zsh can enhance our day-to-day shell experience.
