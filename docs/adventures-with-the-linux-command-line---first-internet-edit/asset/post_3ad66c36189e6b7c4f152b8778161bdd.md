NAME screen - screen manager with VT100/ANSI emulation

```
SYNOPSIS
screen [ -options ] [ cmd [ args ]
screen -r [[pid.tty|host]]

```

DESCRIPTION
Screen is a full-screen manager that multiplexes a physical terminal between several processes (typically interactive shells). # Detaching Sessions

To detach a session from the terminal, use Ctrl-a d. This leaves the session running in the background, allowing you to log out. To reattach to a detached session, use screen -r. If multiple sessions are running, use screen -ls to list them and then specify the PID or name to reattach to. To force a detach of a session that is already attached elsewhere, use screen -d -r.

# Customizing Screen

Like the interactive utilities, screen is customizable. During invocation, screen reads the /etc/screenrc and ~/.screenrc files that exist. While the list of customizable features is extensive (many having to do with terminal display on a variety of Unix-like platforms), we will concern ourselves key bindings and startup session configuration.

First, let's look at a sample .screenrc file:

```
# This is a comment

# Set some key bindings

bind k           # Un-bind the "k" key (set it to do nothing)
bind K kill      # 'Ctrl-a K' destroy the current window
bind ) history  # 'Ctrl-a -' copy and paste the current
                 # command line

# Define windows 7, 8, and 9 at startup
screen -t "mc cmdr" 7 mc
screen -t htop 8 htop
screen -t 9 tail /var/log/syslog
```
