# Control Commands

Before we get to the actual editing commands, let's look at some commands that are used to control the editing process.

| Command | Description |
|---|---|n| Enter | Pressing the enter key causes the current line to be accepted. Note that the cursor location within the line does not matter (i.e., it doesn't have to be at the end). If the line is not empty, it is added to the command history.n| Esc | Meta-prefix. If the Alt key is unavailable, the Esc key can be used in its place. For a command calls for Alt-r but another program intercepts that command, press and release the Esc key followed by : key.
| Ctrl-g | Abort the current editing command.
| Ctrl-_ | Incrementally undo changes to the line (i.e., complete undo).
| Ctrl-l | Clear the screen.
| Alt-num | Where num is a number. Some commands accept a numeric argument. For these commands that accept it, type this first followed by the command. |

# Moving Around

Here are some commands to move the cursor around the current line. In the readline documentation, the current cursor location is referred to as the point.

| Command | Description |
|---|---|n| Right | Move forward one character.
| Left | Move backward one character.
| Alt-f | Move forward one word.
| Alt-b | Move backward one word.
| Ctrl-a | Move to the beginning of the line.
| Ctrl-e | Move to the end of the line. |

# Using Command History

In order to save typing, we frequently reuse previously typed commands stored in the command history. We can move up and down the history list and the history list can be searched.

| Command | Description |
|---|---|n| Up | Move to previous history list entry.
| Down | Move to next history list entry. |
