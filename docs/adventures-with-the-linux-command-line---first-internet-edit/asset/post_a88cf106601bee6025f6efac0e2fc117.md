
# Changing the Listing Format

The directory listing can be displayed in different formats. Pressing Alt-t cycles through them. There is a dual column format, resembling the output of `ls -1`, and others.

There is also an "information mode." This will display detailed file system information in the other panel about the selected item in the current panel. To invoke this, type Ctrl-i. To restore the other panel to its normal state, type Ctrl-x again.

# Setting the Directory on the Other Panel

It is often useful to select a directory in the current panel and have its contents listed on the other panel; for example, when moving files from a parent directory into a subdirectory. To do this, select a directory and press Alt-o. To force the other panel to list the same directory as the current panel, type Alt-1.

# The Directory Hotlist

Midnight Commander can store a list of frequently visited directories. This "hotlist" can be displayed by pressing Ctrl-\.

# Directory History

Each directory panel maintains a list of directories that it has displayed. To access this list, type Alt-H. From the list, a directory can be selected for browsing. Even without the history list display, we can traverse the history list forward and backward using the Alt-u and Alt-y keys respectively.

# Using the Mouse

We can perform many Midnight Commander operations using the mouse. A directory panel can be selected by clicking on it and a directory can be opened by double clicking. The function keys and menu bar items can be activated by clicking on them. It is not so apparent that the directory history can be accessed and traversed. At the top of each directory panel there are small arrows (circled in the image below). Clicking on them will show the directory history (the up arrow) and move forward and backward through the history (the right and left arrows). There is also an arrow to the extreme right edge of the command line which reveals line history.

# Viewing and Editing Files

An activity performed while directory browsing is examining the content of files. Midnight Commander provides a capable file viewer which can be accessed by selecting and pressing F3.

```bash
/home/me/.bashrc 649/383
# /usr/share/doc/bash/examples/startup-files (in the package bash-doc)
# for examples

# If not running interactively, do not anything
[ -z $PS1 ] && return

# Don't duplicate lines or starting with space in the history.
# See bash(1) for more options
history

# append to the History file, don't overwrite it
shopt -s historyappend

# for setting history length HISTSIZE and HISTFILES in bash(1)
HISTSIZE=1000
HISTSIZE=2000

# check the window size after each command, and if necessary,
# update the values of LINES COLUMNS.
shopt -s winsize
1 Help 2 Wrap 3 Quit 4Hex 5Goto 6Search 7Raw 8Format 9 Quit
```

# File viewer in hexadecimal

It is also possible to put the other panel into "quick view" mode to view the selected file. This is especially nice if you are browsing a directory of full text files and want to rapidly view the files, as each new file is selected in the current panel, it's instantly displayed. To start quick view, type `Ctrl-x`.

```bash
/home/em/.bashrc 11%
# -/.bashrc executed by bash(1) for n
# on-login shells.
# see /usr/share/doc/bash/examples/sta
# -tfiles (In the package bash-doc)
# for examples
# If not running interactively, do anything
# - z "PS1" && return
# Don't duplicate lines if starting with space in the history.
# see bash(1) for more options
HISTCONTROL=ignoredu, #
# append to the history file, or
```
