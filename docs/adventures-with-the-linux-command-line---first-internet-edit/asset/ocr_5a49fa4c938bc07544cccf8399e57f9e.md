# dash - Debian Almquist Shell

The Debian Almquist shell is Debian's adaptation of the Almquist shell (ash) originally written in the 1980s by Kenneth Almquist. The ash is the default shell on several of the BSD variants of Unix. dash, which has its ancestor ash, has the advantage of being small and fast; however, it achieves this by foregoing conveniences for interactive use such as command history and editing. It also lacks some builtin commands, relying instead on external programs. Its main use is the execution of shell scripts, particularly during system setup. On Debian and related distributions such Ubuntu, dash is linked to /bin/sh, the shell used to run the system initialization scripts.

dash is a POSIX compliant shell, which supports Bourne shell syntax with a few additional Korn shell features:

```
#!/bin/dash

# longest-word.dash : find longest string in a file

for i; do
  if [ -r "$i" ]; then
    max_word=
    max_len=
    for i in ${strings "$i"}; do
      if [ $len -gt $max_len ]; then
        max_len=$len
        max_word=$i
      fi
    done
    echo "$max_word ($max_len characters)"
  fi
done
```

Here we see that the dash script is mostly as the bash reference script, but we see some differences. For one, dash does not support the '[' syntax for conditional tests; it uses the older Bourne syntax. The POSIX specification is also missing the ((expression)) syntax for arithmetic expansion, nor does it support brace expansion. dash and the POSIX specification do support the $(cmd) syntax for command substitution in addition to the older cmd syntax.
