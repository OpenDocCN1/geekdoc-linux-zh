# Joins

A join is a method by which we perform a query and produce a result that combines the data from two tables. SQL supports several types of joins but we're going to focus on the most commonly used type called inner join. We can think of an inner join as the intersection of two tables. In the example below, a file join_demo.sql, we will produce a query result that matches our earlier example when we added columns to the Package_Descriptions table.

```
```sql
-- join_demo.sql
-- Demonstrate join by selecting columns from 2 tables

.header on
.mode column
.width 20 35 -10

SELECT Package_Descriptions.package_name AS Package,
    description AS Description,
    count AS Files,
    tot_size AS Size
FROM Package_Descriptions
INNER JOIN Package_Stats
ON Package_Descriptions.package_name = Package_Stats.package_name
```

If we break this down query, we see that it is out as we expect, and it is followed by the INNER JOIN statement. The INNER JOIN is optional as an inner join is the default. After the INNER JOIN we have to specify the relationship on which the join is based. In this example, we are looking for matching instances of the package_name in both tables. Any expression we use to convey the table relation, provided that the result of the expression is true or false.

Since package_name is a column in both the Package_Descriptions and Package_Stats tables, we must precede it with the name of the respective table to avoid ambiguity.
