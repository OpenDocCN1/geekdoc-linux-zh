Now place the cursor inside the comment block and type:

ggip

# Comment Blocks

There is a trick we can perform on this comment block. When we write code, we frequently perform testing and debugging by commenting out sections. Vim makes this process easy. To try out, let's first remove the commenting from our block. We will do this by using visual mode to select a block. Place the cursor on the first column of the first line of the comment block, then enter visual mode:

Ctrl-v

Now, move the cursor right one column and then down to the bottom of the block.

![](bbox=[0.15, 0.403, 0.85, 0.735])

Visual block select

Next:

d

This will delete the contents of the selected area. Now our block is uncommented.

To comment the block again, move the cursor to the first character of the block and, using visual block selection, select the first 2 columns of the block.
