It's possible to create windows and run programs without an underlying shell. To do this, we enter screen followed by the name of the program we wish to run, for example:

```
me@linux:~ $ screen vim ~/.bashrc
```

We can do this in a screen window. Issuing a screen command in a screen window does not invoke a screen window to another. It does this by entering what is called scrollback mode. It tells the existing instance of screen to carry out an operation like creating a new window.

# Copy and Paste

Given GNU screen was developed for systems that have neither a graphical user interface nor mouse, it makes sense that screen would provide a way of copying text from one screen window to another. In this mode, screen allows the text cursor to move freely throughout the current window and through the contents of the scrollback buffer, which contains previous contents of the window.

We start scrollback mode by typing Ctrl-a {. In scrollback mode we can use the arrow keys and the Page Up and Page Down keys to navigate the scrollback buffer. To copy text, we first need to mark the beginning of the desired text and pressing the space text, this is done by moving the cursor to the beginning of the desired text (which is highlighted as we move the cursor) and pressing the space bar again to mark the end of the text to be copied. Marking text exits scrollback mode and copies the marked text into screen's internal buffer. We can now paste the text into any screen window. To do this, we go to the desired window and type Ctrl-a ].
