# Updating Tables

The UPDATE statement is used to change values in one or more rows. We will demonstrate this by adding 100 to the size of each file in the sqlite3 package. First, let's look at the files in the package:

```
sqlite> mode column
sqlite> headers on
sqlite> width 50 10
sqlite> SELECT file, size_bytes FROM Package_Files
file> ... WHERE package_name = 'sqlite3';
```

| file | size_bytes |
| /usr/bin/sqldiff | 1103280 |
| /usr/bin/sqlite3 | 1260976 |
| /usr/share/doc/sqlite3.1.gz | 1261 |
| /usr/share/man/man1/sqlite3.1 | 356 |
| /usr/share/doc/sqlite3/changelog.Debian.gz | 35 |

Next, we update the table, adding 100 to the size of each file:

```
sqlite> UPDATE Package_Files set size_bytes = size_bytes + 100
...> WHERE package_name = 'sqlite3';
```

When we examine the results, we see the change:

```
sqlite> SELECT file, size_bytes FROM Package_Files
...> WHERE package_name = 'sqlite3'
```
