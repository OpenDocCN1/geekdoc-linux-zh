# Making Time

For our final exercise, we will make something useful; a large character clock. To do this, we first need to install a program called banner. The banner program accepts one or more words as arguments and displays them like so:

```
me@linuxbox~$ banner "BIG TEXT"

###### ###### ###### ######
#      #  #      #  #      #  #      #
#      #  #      #  #      #  #      #
#      #  #      #  #      #  #      #
#      #  #      #  #      #  #      #
###### ###### ###### ######
```

This program has been around for a long time and there are several different implementations. On Debian-based systems (such as Ubuntu) the package is called "sysbanner", on Red Hat-based systems the package is called simply "banner". Once we have banner we can run this script to display our clock:

