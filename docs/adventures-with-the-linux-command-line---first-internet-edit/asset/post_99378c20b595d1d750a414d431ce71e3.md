# Virtual File Systems

Midnight Commander can treat some types of archive files and hosts as though they are local files. Using the `cd` command at the shell prompt, we can access these.

For example, we can look at the contents of tar. To try this out, let's create a compressed file containing the files in the `/etc` directory. We can do this by entering the command at the shell prompt:

```
me@linux ~ tar cfg etc.tgz /etc
```

Once this command creates (there will be "permission denied" errors but these don't matter for our purposes), the file `etc.tgz` will appear among the files in the current panel. If we select this file and press `Enter`, the contents of the archive will be displayed in the current panel. Notice that the prompt does not change as it does with ordinary directories. This is because the current panel is displaying a list of files like before, Midnight Commander cannot treat the virtual file system in the same way as a real. For example, we cannot delete files from the tar archive, but we can copy files from the archive to the real file system.

18 Midnight Commander

Virtual file systems can also treat remote file systems as local directories. In most versions of Midnight Commander, both FTP and FISH (Files transferred over SHell) protocols are supported and, in some versions, SMB/CIFS as well.

As an example, let's look at the software library FTP at Georgia Tech, a popular repository for Linux software. Its name is ftp.glib.gatech.edu. To connect with /pub directory on this site and browse its files, we enter the `cd` command:

```
me@linuxbox ~ $ cd ftp://ftp.glib.gatech.edu/pub
```

Since we don't have permission on this site, we cannot modify any files there, but we can copy files from the remote server to our local file system.

The FISH protocol is simple. It can be used to communicate with any Unix-like system that runs a secure shell (SSH). If we have write permissions on the remote server, we can operate on the remote system's files as if they were local. This is extremely handy for performing remote administration. The cd command for FISH protocol looks like:

```
me@linuxbox ~ $ cd sh://user@remotehost/dir
```
