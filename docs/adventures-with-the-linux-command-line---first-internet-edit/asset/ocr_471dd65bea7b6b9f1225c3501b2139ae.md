# Regions

Using multiple regions is very convenient when working with large terminal displays. For example, if you split the display into two horizontal regions, you can edit a script in one region and perform testing of the script in the other. Or we could read a man page in one region and try a command in the other.

There are two commands for deleting regions: Ctrl-a removes all regions except the current one, and Ctrl-x removes the current region. Note that removing a region does not associate it. Windows continue to exist until they are destroyed.

# Detaching Sessions

Perhaps the most interesting feature of screen is its ability to detach session from the terminal idle. Just as it is able to display its windows on any region of the terminal, screen can also display its windows on any terminal or no terminal at all.

For example, we could start a session on one computer, say at the office, detach the session from the local terminal, go home and log into our office remotely, and reattach the session to our home computer's terminal. During the intervening time, all jobs on our computer have continued to execute.

There are a number of commands to manage this process.

+   screen-list lists the sessions running on a system. If there is more than one session running, the pid.tty.host string shown in the listing can be appended to the -d/-D and -r/-R options to specify a particular session.
