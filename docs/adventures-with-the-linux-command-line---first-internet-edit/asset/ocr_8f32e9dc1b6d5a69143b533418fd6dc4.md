# Text Object Selection

In addition to the traditional vi movement commands, vim adds a related feature called *text object selection*. These commands only work in conjunction with operators. commands are:

+   - Select entire (all) text object.
- Select interior (in) of text object.

The text objects are:

+   - Word
- Sentence
- Paragraph
- Tag block (such as `<a>...</a>` used in HTML)
- { enclosed block
  { enclosed block (b can also be used)
  { enclosed block (B can also be used)
- "quoted string"
- 'quoted string

The way this works is very interesting. If we place our cursor on a word for example, and type:

caw

(short for "change all word\ vim the entire word, deletes it, and switches to insert mode. Text objects work with visual mode too. Try this: move to line 11 and place the cursor inside the quoted string and:

vi"

The interior of the quoted string will be selected. If we instead type:

va"

the entire string including the quotes is selected.
