versions of AWK (most notably awk versions prior to 1.3.4) do not support POSIX
character classes.

Regular expressions are most often used in patterns, but they are also used in some of the
built-in variables as FS and RS, and they have various roles in the string functions
which we will discuss shortly.

Let's try using some regular expressions to tell the different file types in our
directory listing (we'll make clever use of an associative array too).

```
ls -l /usr/bin | awk '
$1 ~ /\\["Regular Files\\]/
$1 ~ /\\["directories\\]/
$1 ~ /\\["Symbolic Links\\]/
END (for (i in t) print "\t "" t[i])'
```

In this program, we use regular expressions to identify the first character of the first field
and increment the corresponding element in array r. Since we can use strings as array
indexes in AWK, we split out the file type as the index. This makes printing the results in
the END action easy, as we only have to traverse the array with (i in t) to obtain
both the name and the accumulated total for each type.

# Output Functions

print expr1, expr2, expr3,...

As we have seen, print accepts a comma-separated list of arguments. An argument can
be any valid expression; however, if an expression contains a relational operator, the
entire list must be enclosed in parentheses.

The commas are important, because they tell AWK to separate output items with the
output field separator (OFS). If omitted, AWK will interpret the members of the argument
list as a single expression of concatenation.

# printf(format, expr1, expr2, expr3,...)

In AWK, printf is like the corresponding built-in (like TLCL) Chapter 21 for
detetails. It formats its list of arguments based on a format string. Here is an
example where we use printf for files and their sizes in kilobytes

```
ls -1 /usr/bin | awk 'printf("%-30s%%.2fk\n", $9, $5 / 1024)'
```

# Writing to Files and Pipelines

In addition sending output to stdout, we can also output to files and pipelines.

```
ls -1 /usr/bin | awk '
$1 ~ /^\-/ (print $0 > "regfiles.txt")
$1 ~ /^\d/ (print $0 > "directories.txt")'
```
