## Termux

The Termux app for Android is unexpectedly amazing. It goes beyond being merely an SSH client; it provides a full environment on Android without having to root the device. After installation, there is a minimal system with `bash` and many of the most common utilities. Initially, these are built into `busybox` (a compact set of utilities often used in embedded systems to save space), but the `apt` package management program (like Debian/Ubuntu) is provided to allow installation of a wide variety of Linux programs.

## Termux displaying builtin shell commands

We can have dot files (like `.bashrc`) and even write shell scripts and compile and debug programs in Termux. Pretty neat.

When executing `ssh`, Termux looks like `xterm-256color` terminal to remote systems.

## Chrome/Chrome OS

Google makes a decent SSH client for Chrome and Chrome OS (which is Linux, too, after all) that allows logging to remote systems. Called Secure Shell, it uses HTML Terminal (a terminal emulator written in JavaScript) combined with an SSH client. To remote systems, it looks like “xterm-256color” terminal. It works pretty well, but lacks some features that advanced SSH users need.

Secure Shell is available at the Chrome Web Store.

## Summing Up

Given that our terminal emulators are among our most vital tools, they should command more of our attention. There are many different terminal programs with potentially interesting and helpful features, of which most used rarely, if ever, to use. This is a shame since many of these features are truly *useful* to the busy command line user. We have looked at a few of the ways these features can be applied to our daily routine, but there are certainly many more.
