It is also possible to put the other panel into "quick view" mode to view the
selected file. This is especially nice if you are browsing a directory of full text files and
want to rapidly view the files, as each a new file is selected in the current panel, it's
instantly displayed. To start quick view, type `Ctrl-x`.
