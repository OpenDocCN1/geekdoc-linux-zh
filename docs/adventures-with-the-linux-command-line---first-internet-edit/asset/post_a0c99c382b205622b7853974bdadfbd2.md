## Tagging Files

We have already seen how to select a file in the current panel by simply highlighting it, but operating on a single file is not much use. After all, we can perform those kinds of operations more easily by entering commands directly to the command line. However we often want to operate on multiple files through tagging. When a file is tagged, it is marked for later operation such as copying. This is why we choose to use a file manager like Midnight Commander. When one or more files are tagged, file operations (such as copying) are performed on the tagged files and selection has effect.

### Tagging Individual Files

To tag an individual file or directory, select it and press the `Insert` key. To untag it, press the `Insert` key again.

### Tagging Groups of Files

To tag a group of files or directories according to a selection criteria, such as a wildcard pattern, press '+' key. This will display a dialog where the pattern may be specified. This dialog stores patterns. To traverse it, use Ctrl up and down arrows. It is also possible to untag a group of files. Pressing '-' key will cause a pattern entry dialog.

## We Need a Playground

To explore the basic file manipulation features of Midnight Commander, we need a "playground" aptly enough. The first step in creating a playground is creating a directory called "playground". First we will navigate to our home directory, press the F7 key.

### Creating Directories

Type "playground" into the dialog and press Enter. Next, we want the other panel to display the contents of the playground. To do this, highlight the playground directory and press Alt-c. Now let's put some files into our playground. Press Tab to switch the current panel to the playground panel. We'll create a couple of subarrays by repeating what we did to create dir1 and dir2. Finally, using the command line, we will create a few files:

## Renaming a file during copy

Again, this is pretty straightforward. But let's say we tagged a group of files and wanted to copy and rename them as they are copied (or move). How would we do that? Midnight Commander provides a way of doing it, but it's a little strange.

The secret is using source mask in the copy. At first, it appears that the source mask is a selection wildcard, but first appearances can be deceiving. The mask filters files as we expect, but only in a limited way. Unlike the range of wildcards available in the shell, the wildcards in the source mask are limited to "?" (for matching single characters) and "*" (for matching multiple characters). What's more, wildcards have a special property.

It works like this: let's say we want to copy (or move) it to dir1 with an embedded space such as "ugly file" and want to use "*" instead. Using the source mask, we could enter the mask "*" which means the file name into two blocks of text separated by a space. Midnight Commander will associate each block of text with a number starting at 1, so block 1 contain "ugly" and block 2 "file". Each block can be referred to by a number with regular expression grouping. To create a new file name for our target without the embedded space, we would specify "1\2" in the "to" field of the copy dialog like so:

### Using grouping

+   * wildcard behaves the same way. If we make the source mask "???? ???" (which matches the ugly file), we have eight pieces of text that can rearrange at file. For example, we could make the "to" mask "\7\6\5\4\3\2\1", and the resulting file name would be "elifylgu". Pretty.

Midnight Commander can also perform case conversion on file names. In this case, we include some additional escape sequences in the to:

*   \u Converts the next character to uppercase.
*   \U Converts all characters to uppercase until another sequence is encountered.
*   \l Converts the next character to lowercase.
*   \L Converts all characters to lowercase until another sequence is encountered.
