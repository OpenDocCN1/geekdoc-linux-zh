In most other languages, the name and type of parameters passed during a function call must match the parameter list specified by the function's declaration.

By convention, additional parameters used as local variables in the function are preceded by additional spaces in the parameter list like so:

```
my_func(param1, param2, param3,      local1, local2)
```

These additional spaces have no meaning to the language, they are there for the benefit of the human reading the code.

Let's try some AWK programs on some numbers. First we need some data. Here's a little AWK program that produces a table of random integers:

```
# random_table.awk - generate table of random numbers
unction rand_integer(max) {
  return int(max * rand()) + 1
}

BEGIN {
  for (i = 0; i < 100; i++) {
    for (j = 0; j < 5; j++) {
      printf("%5d,", rand_integer(99999))
    }
  }
  printf("\n", "")
}
```

If we store this, we can run it like so:

```
me@linuxbox ~ -f random_table.awk > random_table.dat
```

And it should produce a file containing 100 rows of 5 columns of random integers.

# Convert a File Into CSV Format

One of AWK's strengths is file format conversion. Here we convert our neatly arranged columns of numbers into a CSV (comma separated values) file.

```
awk 'BEGIN {OFS=",} print $1,$2,$3,$4,$5' random_table.dat
```
