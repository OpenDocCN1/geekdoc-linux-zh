konsole's split view feature
konsole's unique split view feature allows us to have two views of a single terminal session. This seems odd at first glance, but is useful when examining long streams of output. For example, if needed to copy text from one portion of a long output stream to the command line at the bottom, this could be handy. Further, we can get views of different terminal sessions, by using tabs in conjunction with split views, while the tabs will appear in all of the split views, which can be switched independently in each view:
