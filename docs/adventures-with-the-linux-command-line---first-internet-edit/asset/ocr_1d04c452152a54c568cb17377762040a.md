# Deleting Rows

Deleting rows is pretty easy. In a DELETE statement with a WHERE clause to
specify a target. We'll demonstrate that, but first there's a nifty that SQLite supports.

We can change the output mode to write INSERT statements. Let's try it out.

```
sqlite> .mode insert Package_Files
```

If we use this .mode, we tell SQLite that we want INSERT statements directed at
the specified table, in this case, Package_Files. Once we set the output mode, we can
the result.

```
sqlite> SELECT * FROM Package_Files WHERE package_name = 'sqlite3';
INSERT INTO Package_Files VALUES('sqlite3',/usr/bin/sqldiff,1103380);

696);
INSERT INTO Package_Files VALUES('sqlite3',/usr/share/doc/sqlite3/changelog.De
```

We repeat this SELECT, but first we can change the output format to a file
named sqlite3.sql.

```
sqlite> .output insert_sqlite3.sql
```
