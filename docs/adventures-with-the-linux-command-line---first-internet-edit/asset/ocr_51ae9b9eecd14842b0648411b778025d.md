# 9 Other Shells

While we have spent a great deal of time learning the bash shell, it's not the only “game in town.\ Unix has had several popular shells and almost all are available for Linux, too. In this adventure, we will look at some of these, mostly for their historical significance. With a couple of exceptions, there is very little reason to switch, as bash is a pretty good shell. Some of these alternate shells are still popular on other Unix and Unixlike systems, which are rarely used in Linux except when compatibility with other systems is required.

# The Evolution of Shells

The first Unix shell was developed in 1971 by Ken Thompson who, with Dennis Richie, created Unix at AT&T Bell Laboratories. The Thompson shell introduced many of the core ideas that we see in shells today. These include I/O redirection, pipelines, and the ability to place processes in the background. This early shell was intended only for interactive use, not for use as a programming language.

The Thompson shell was followed in 1975 by the Mashey shell, written by John Mashey. This extended the Thompson shell to support scripting including variables, a built-in if/then/else, and other rudimentary flow control constructs.

At this point we come to a big split in shell design philosophies. In 1978 Steve Bourne created the Bourne shell. The following year, Bill Joy (the original author of v1) released the C shell.

The Bourne shell added a lot of features that greatly improved scripting. These included flow control structures, better variables, command substitutions, and here scripts. The Bourne shell contains most of the functionality that we see in the bash shell today.

On the other hand, the C shell was designed to improve interactive use by adding command history and job control. The C shell, as its name would imply, uses a syntax that mimics the C programming language. C programmers abounded in the Unix community, so many preferred this style. Ironically, the C shell is not very good at scripting. For example, it lacks user functions and the shell’s parser (the portion of the shell that reads out what the script is saying) suffers from serious limitations.

In 1983, in an effort to improve the Bourne shell, David Korn released the Korn shell. Command history, job control, associative arrays, vi and Emacs style editing are among the features that were added. In the 1993 release (known as ksh93), floating point arithmetic was added.
