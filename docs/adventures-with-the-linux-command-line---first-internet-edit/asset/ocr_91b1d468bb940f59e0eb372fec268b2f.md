Using registers enables us to place many chunks of text into our clipboard at the same time. But even without consciously trying to use registers, vim is using them while we perform deletes and yanks.

As we mentioned earlier, the registers named 0-9 have a special use. When we perform ordinary yanks and deletes, vim places our latest yank in register 0 and our last nine deletes in 1-9. As we continue to make deletions, vim moves the previous deletion to the next number, so register 1 will contain our most recent deletion and register 9 the oldest.

Knowing this allows us to overcome the problem of performing a yank and then a delete losing the text we yanked (a common hazard using vim). We can always recall the latest yank by referencing register 0.

To see the current contents of the registers we can use the command:

```
:reg
```

# Insert Sub-Modes

While it's not obvious, vim has a set of commands inside insert mode. Most of these commands invoke some form of automatic completion to make our typing faster. They're a little clumsy, but it might be worth a try.

# Automatically Word Ctrl-n

Let's go to the bottom of our script file and enter insert mode to add a new line at the bottom. We want the line to read:

```
afunction && afun
echo "It worked."
```

We start to type the first characters ("afun") and press Ctrl-n. Vim should automatically complete the function name "afunction" after we press it. In cases where vim presents us with more than one choice, Ctrl-n and Ctrl-p to move up and down the line. Typing any other character, as a space, to continue our typing will accept our selection and end the automatic completion. Ctrl-e can be used to exit the sub-mode immediately.

# Insert Register Contents - Ctrl-r

Typing Ctrl-r followed by a single character name will insert the contents of that register. Unlike doing an ordinary paste using p or P, a register insert honors formatting and indentation settings as textwidth and autindent.
