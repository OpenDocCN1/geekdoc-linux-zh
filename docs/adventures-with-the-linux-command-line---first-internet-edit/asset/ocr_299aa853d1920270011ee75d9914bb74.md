As we see, SQL is verbose and English-like. English dictates that keywords be in uppercase; however is not required. SQL is case insensitive. White space is not important, but is often used to make the SQL statements easier to read. Statements can span multiple lines but don't have to. Statements are terminated by a semicolon character.
