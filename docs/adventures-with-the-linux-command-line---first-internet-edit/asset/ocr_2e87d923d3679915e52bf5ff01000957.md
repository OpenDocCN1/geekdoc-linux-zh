```
root) # Create a root shell tab
  guake --new-tab. --fgcolor=\ffffff --bgcolor=#5e0000
  guake --show # Switch to new fg/bg colors
  guake --rename-current-tab=root
  guake --execute-command=sudo -i; exit

  guake --show # Switch to new fg/bg colors

  exit 1
  ;;
esac
```

After this script, we can open new tabs in guake by entering the command gtab followed by an optional profile, either 'root' or 'man' to duplicate what we did with the gnome-terminal profiles above. Entering gtab without an option simply opens a tab in the current working directory.

As we can see, guake has a number of interesting command line options that allow us to program its behavior.
