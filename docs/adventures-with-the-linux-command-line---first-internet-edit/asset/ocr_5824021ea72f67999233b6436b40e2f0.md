Using grouping

+   * wildcard behaves the same way. If we make the source mask "???? ????" (which matches the file ugly file), we have eight pieces of text that can rearrange at file. For example, we could make the "to" mask "\7\6\5\4\3\2\1", and the resulting file name would be "elifylgu". Pretty.

Midnight Commander can also perform case conversion on file names. In this case, we include some additional escape sequences in the to:

+   * \u Converts the next character to uppercase.
* \U Converts all characters to uppercase until another sequence is encountered.
* \l Converts the next character to lowercase.
* \L Converts all characters to lowercase until another sequence is encountered.

So if we wanted to change the name ugly file to camel case, we could use the mask "\u\L\u\L\2" and would get the name UglyFile.
