# Suffix Aliases

What's more, we can define aliases to act like an “open with...” by defining a suffix alias. For example, we can define an alias that says all files end with “.txt” should be viewed with:

```
me@linuxbox ~ alias -s txt='less'
```

Then we just type the name of a text file, and it will be opened by the application specified by the aliases:

```
me@linuxbox ~ dir-list.txt
```

How cool is that?

# Improved History Search

zsh adds a neat trick to history searching. bash (and zsh too) we can perform a reverse incremental history search by typing Ctrl-r, and each subsequent keystroke will refine the search. zsh gets one better by simply typing a few letters of the desired search string on the command line and press up-arrow. It moves back through the history to find the first match, and each time we press the up-arrow, the next match is displayed.

# Environment Variable Editing

zsh provides a builtin called varied for editing shell variables. For example, if we wanted to make a quick change to our PATH variable we can do this:

```
me@linuxbox ~ $ varied PATH
```

and the contents of the PATH variable appear in the command editor, so we can make a change and press Enter and the change takes effect.

# Frameworks

We have only touched a few of the features available in zsh. It has a lot. But with a large set touches complexity, and configuring zsh to take advantage of its full potential can be daunting. Her, man page is only a table of contents to the other 10+ pages that cover various topics. Fortunately, communities have sprung up to provide frameworks that supply ready-to-use configurations and add-ons for zsh. By far, the most popular of these is Oh-My-Zsh, a project led by Robby Russell.

Oh-My-Zsh is a large collection of configuration files, aliases, and themes. It offers support for tailoring zsh for many types of common tasks, particularly software development and system administration.
