# NF - Number of fields

This variable updates each time a record is read. We can easily access the last field in the record by referring to $NF.

# NR - Record number

This variable increments each time a record is read, thus it contains the total number of records from the input stream. Using this variable, we could easily simulate a wc -l command with:

```
awk 'END (print NR)'
```

or number the lines in a file with:

```
awk '{print NR, $0}'
```

# OFS - Output field separator

This string is used to separate fields when printing output. The default is a single space. This setting can be changed by reformatting data. For example, we could easily change a table of values to a CSV (comma separated values) by setting OFS to equal ",". To demonstrate, here is a program that reads our directory listing and outputs a CSV stream:

```
ls -l | awk 'BEGIN OFS = ","
NF = 9 (print $1,$2,$3,$4,$5,$6,$7,$8,$9)'
```

We set the pattern to match input lines containing 9 fields. This eliminates symbolic links and other weird field names from the data to be processed.

Each line of the resulting output would resemble this:

```
-rwxr-xr-x,1,root,root,100984,Jan,11,2015,a2p
```

If we had omitted OFS, the print statement would use the default value (a single space):

```
ls -l | awk 'NF = 9 (print $1,$2,$3,$4,$5,$6,$7,$8,$9)'
```

Which result in each line of output resembling this:

```
-rwxr-xr-x 1  root  root 100984 Jan 11 2015 a2p
```

# ORS - Output record separator

This string is used to separate records when printing output. The default is a newline character. We could use this variable to easily double-space a file by setting ORS to equal two newlines:

```
ls -l | awk 'BEGIN {ORS = "\n\n" {print}'
```
