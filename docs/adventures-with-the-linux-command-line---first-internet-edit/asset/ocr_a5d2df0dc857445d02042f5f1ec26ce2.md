# General Purpose Libraries

Since we hope to become prolific script writers, it makes sense over time, to build a library of common code that our future scripts could potentially use. When undertaking such a project, it's wise to write high quality functions for the library, as the code may get used. It's important to test carefully, include a lot of error handling, and document the functions. After all, the goal is to save time writing good scripts, so invest the time up front to save time later.

# Let's Not Forget .bashrc

source is a powerful tool for coordinating the configuration of small sets of machines. For large sets, there are more powerful tools, source works fine if the job is not too big.
We've worked with .bashrc file before and added things that like aliases and a few shell functions. However, when we work with multiple systems (for example, a small network), it would be a good idea to create a common configuration file to align all of our systems. To demonstrate, let's create a file .mynworkrc.sh and place all of the common alias and shell function we would expect on every machine. To use this file, we would add this one line of code to .bashrc:

```
[[ -r ~/.mynworkrc.sh ]] && source ~/.mynworkrc.sh
```

The advantage of doing this is that we won't have to cut and paste large sections of code every time we configure a new machine or perform an operating system upgrade. We just copy the .mynworkrc.sh file to the new machine and add one line to .bashrc.
We can go further and create a host-specific configuration file that the .mynworkrc.sh file will source. This would be handy if we need to override something in .mynworkrcsh on a particular host. We can do this by creating a configuration file with a file name based on the system's host. For example, if our system's host is linuxbox we could create a configuration file named .linuxbox.rc and add this line of code to the .mynworkrc.sh file:

```
[[ -r ~$(hostname) ]] && source ~/.$(hostname)rc
```

By using the hostname command we are build a file name that is specific to a particular host.
