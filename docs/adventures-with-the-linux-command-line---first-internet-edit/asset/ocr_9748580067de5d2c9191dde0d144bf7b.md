# 7 AWK

One of the great things we can do in the shell is embed other programming languages within the body of our scripts. We have seen hints of this with the stream editor sed, and the arbitrary precision calculator program bc. By using the shell's single quoting mechanism to isolate text from shell expansion, we can freely express other programming languages, provided we have a suitable language interpreter to execute them.

In this adventure, we are going to look at one program, awk.

# History

The AWK programming language is truly one of the classic tools used in Unix. It dates back to the very earliest days of the Unix tradition. It was originally developed in the late 1970s at AT&T Bell Telephone Laboratories by Alfred Abo, Peter Weinberger, and Brian Kernighan. The name “AWK” comes from the last names of the three authors. It underwent many improvements in 1985 with the release of nawk or “new awk”. It is the version that we use today, though it is usually just called.

# Availability

awk is a standard program found in every Linux distribution. Two free/open source versions of the program are in common use. One is mawk (short for Mike's awk, named for its author, Mike Brennan) and gawk (GNU awk). Both versions implement the 1985 nawk standard as well as a variety of extensions. For our purposes, either version is fine, since we will be focusing on the traditional nawk features. In most distributions, the awk is symbolically linked to either mawk or gawk.

# So, What's it Good For?

Though AWK is fairly general purpose, it is designed to create filters, that accept standard input, transform data, and send it to output. In particular, AWK is good at processing columnar data. This makes it a good choice for developing report generators, and tools that are used to re-format data. Since it has regular expression support, it's good for very small text extraction and reformatting programs, too. Like sed, any AWK programs are just one line long.

In recent years, AWK has been a bit out of fashion, supplanted by other, interpreted languages such as Perl and python, but AWK still has some advantages:

+   - It's easy to learn. The language is not overly complex and has a syntax like C learning it will be useful in the future when we study other languages and tools.

+   - It really excels at solving certain types of problems.
