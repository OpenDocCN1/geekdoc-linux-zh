# Automatically Complete Line - Ctrl-x Ctrl-l

Typing Ctrl-x while in insert mode launches a sub-mode of automatic completion features. A small menu will appear at the bottom of the display with a list of keys we can type to perform different completions.

If we have typed the first few letters of a line found in this or any other file that has open, typing Ctrl-x Ctrl-l will attempt to automatically complete the line, copying the line to the current location.

# Automatically Complete Filename - Ctrl-x Ctrl-f

This will perform filename completion. If we start the name of an existing path/file, we can type Ctrl-x Ctrl-f and vim will attempt to complete the name.

# Dictionary Lookup - Ctrl-x Ctrl-k

If we define a dictionary (i.e., a sorted list of words), by adding this line to our configuration file:

```
setlocal dictionary=/usr/share/dict/words
```

which is the default dictionary on most Linux systems, we can begin typing a word, type Ctrl-x Ctrl-k, and vim attempt to automatically complete the word using the dictionary. We will be presented with a list of words from which we can choose the desired entry.

Help topics: i^n i^p i^x l i^x r i^x f i^x k f i^x k 'dictionary'

# Mapping

Like many interactive command line programs, vim allows users to remap keys to customize vim behavior. It has a specific command for this, map, allows a key to be assigned the function of any other key or a sequence of keys. Further, vim allows us to say that a key is to be remapped in a certain mode, for example in normal mode but not in insert command mode.

Before we go on, we should point out that the use of the map command is discouraged. It can create nasty side effects in some situations. Vim provides another set of mapping commands that are safe to use.

Earlier, we looked at the paragraph reformatting sequence gqip, To demonstrate a useful remapping, we will map the Q key to generate this sequence. We can do this by entering:

```
:nnoremap Q gqip
```
