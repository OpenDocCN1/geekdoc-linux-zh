# SCREEN(1)

NAME screen - screen manager with VT100/ANSI emulation

```
SYNOPSIS
screen [ -options ] [ cmd [ args ]
screen -r [[pid.tty|host]]
screen -f [sessionowner|[pid.tty|host]]
```

DESCRIPTION
Screen is a full-screen manager that multiplexes a physical terminal between several processes (typically interactive shells). Each virtual terminal provides the functions of a DEC VT100 terminal and, in addition, several control functions of the ISO 6429 (ECMA 48, ANSI X3.4) and ISO 2022-2 standards; there's a scrollback line and buffer for multiple character sets), a copy-and-paste mechanism that allows moving regions between windows.

When screen is called, it creates a single window with a shell in it (or the specified command) and gets out of your way so that you can use the program as you normally would. Then, at any time, you can Manual page screen(1) line 1 (press h for help or q to quit)

# Multiple Regions

GNU screen can also divide the terminal display into separate regions, each providing a view of a screen. This allows you to view 2 or more windows at the same time. To split the terminal horizontally, type the command Ctrl-a s to split it vertically, type Ctrl-a |. Newly created regions are empty (i.e., they are not associated with a window). To display a window in a region, first move the focus to the new region by typing Ctrl-Tab and then either create a new window, or choose an existing window to display using any of the selection commands we have already discussed. Regions may be further subdivided to smaller regions and we can even display the same window in more than one region.
