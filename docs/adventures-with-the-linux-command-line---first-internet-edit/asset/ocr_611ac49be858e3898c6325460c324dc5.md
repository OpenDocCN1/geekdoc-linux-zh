# Power Moves

As we learned in TLCL, vim has lots of movement commands we can use to quickly navigate around our documents. These commands can be employed in many useful ways.

Here is a list of the common movement commands. Some of this review, some is new.

+   h Move left (also left-arrow)
l Move right (also right-arrow)
j Move down (also down-arrow)
k Move up (also up-arrow)
0 First character of the line (also the Home key)
First non-whitespace character on the line
$ Last character on the line (also the End key)
f(char) Move right to the next occurrence of char on the current
t(char) Move right till (i.e., just) the next occurrence of char on the line
r Repeat last f or t command
g Go to last line. If a count is specified, go to that line.
w Move forward (word) to beginning of next word
b Move backward (word) to beginning of previous word
e Move forward to end of word
) Move forward to beginning of next sentence
( Move forward to beginning of next paragraph
{ Move backward to beginning of previous paragraph

Remember, each of these commands can be preceded by a count of how many times the command is to performed.

# Operators

Movement commands are often used in conjunction with operators. The movement command determines how much of the text operator affects. Here is a list of the most commonly used operators:

+   c Change (i.e., delete then insert)
d Delete/cut
y Yank (i.e., copy)
t Toggle case
g Make lowercase
g Make uppercase
q Format text (a topic we'll get to shortly)
? ROT13 encoding (for obfuscating text)
> Shift (i.e., indent) right
< Shift left
