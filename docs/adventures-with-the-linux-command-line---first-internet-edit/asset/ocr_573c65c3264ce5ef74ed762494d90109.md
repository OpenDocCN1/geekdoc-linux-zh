# Opening Files Named in a Document

If the document we are editing contains a file name, we can open that by placing
cursor on the file name and typing either of these commands:

```
gf Open file name under cursor
^^f Open name under cursor in new window
```

Help topics: netrw :find 'path' 'wildmenu' gf ^^f

# One Does Not Live by Code Alone

While vim is most often associated with writing code of all sorts, it's good at writing
orinary prose as well. Need proof? All of the adventures were written using vim running
on a Raspberry Pi!

We can configure vim to work well with text by creating a file for the file type in the
~/.ftplugin/ directory:

```
""" ~/.ftplugin/text.vim
setlocal textwidth=75
setlocal tabstop=4
setlocal shiftwidth=4
setlocal expandtab
```
