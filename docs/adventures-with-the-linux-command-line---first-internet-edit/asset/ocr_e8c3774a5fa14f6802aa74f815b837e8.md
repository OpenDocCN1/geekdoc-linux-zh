will display the cursor position (row, column, relative %) in the window status bar.
Handy for knowing where we are within a file.

Finally, we'll add mouse support (not that we should ever use a mouse; -);

```
if has('mouse')
  set mouse=a
endif
```

This will activate mouse support if vim detects a mouse. Mouse support allows us to position the cursor, switching windows if needed. It works in vim mode too.
