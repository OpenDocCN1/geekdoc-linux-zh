Notice that vi reminds you that this file doesn't exist; the bottom of the screen says New file, instead of indicating the number of lines and characters.

+   2. Now it's time to try using insert mode. Try to insert a into the file by typing k once:

![](bbox=[0.118, 0.243, 0.831, 0.333])

The system beeps at you because you haven't moved into insert mode yet, and the k still has its command meaning of moving down a line (and of course, isn't another line yet).

Type i to move into insert mode, then type k again:

![](bbox=[0.118, 0.442, 0.831, 0.532])

There you go! You've added a character to the file.

+   3. Press the Backspace key, which will move the cursor over the letter k:

![](bbox=[0.118, 0.613, 0.831, 0.703])

Now see what happens when you press Escape to leave insert mode and return to the vi command mode:

![](bbox=[0.118, 0.777, 0.831, 0.867])

Notice that the k vanished when you pressed Escape. That's because vi only saves text you've entered to the left of or above the cursor, not the letter cursor is resting on.
