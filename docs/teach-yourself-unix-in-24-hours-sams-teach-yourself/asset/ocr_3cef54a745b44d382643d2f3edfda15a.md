Type t, and you move right back to the beginning of the previous paragraph. In fact, you can easily back and forth in the file by using sequences of ) (or a numeric prefix like 2j) to get there faster.

These two commands move by sentence and move by paragraph are working with stories, articles, or letters. Any time you're working with words rather than commands (as in the .exrc file), these commands are worth remembering.

By the way, t d to delete a sentence, or c d to change an entire paragraph. Recall that you can always change the changes with u if you haven't done anything between the two events.

This final task on vi introduces you to one of the most powerful and least-known commands in the editor: the t escape-to-UNIX command. When prefaced with a colon (:t, for example), it enables you to run UNIX commands without leaving the editor. More powerfully, the t command in vi itself, just like d and c, accepts address specifications, feeds that portion of text to the command, and replaces that portion with the results of having run command on the text.
