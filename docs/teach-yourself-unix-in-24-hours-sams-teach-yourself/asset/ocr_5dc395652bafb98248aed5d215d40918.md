# What Is This UNIX Stuff?

![](bbox=[0.125, 0.137, 0.196, 0.159])

1. At the University Tech Computing Center, the support team has installed a help command:

```
% help
Look in a printed manual, if you can, for general help. You should have someone show you some things and then read one of the tutorial papers (e.g., UNIX for Beginners or An Introduction to the C Shell) to get started. Printed manuals covering all aspects of Unix are on sale at the bookstore.
```

Most of the material in the printed manuals is also available via "man" and similar commands; for instance:

```
apropos keyword - lists commands relevant to keyword
whatis - lists commands involving filename
man command - prints out the manual entry for a command
help command - prints out the other basic commands:
cat - display a file on the screen
date - print the date and time\du - summarize disk usage
edit - text editor (beginner)
vi - text editor (intermediate)
finger - user information lookup program
learn - interactive self-paced tutorial on Unix
--More(40)--
```

Your system might have something similar.

2. Some commands offer helpful output if you specify the -h flag:

```
% ls -h
usage: ls [ -acdfgilqrstu1ACFLR ] name ...
%
```

Then again, others don't:

```
% ls -h
Global.Software Mail/ history.usenet.Z
Interactive.Unix News/ bin/\ testme
```

A few commands offer output when you use the -h flag:

```
% elm -h
Possible Starting Arguments for ELM program:
arg Meaning
-a Arrow - use the pointer regardless
-c CheckAliases - check the given aliases only
-dn Debug - set debug to "n"
-fx Folder - read folder "x" rather than incoming mailbox
-h Help - give this list of options
```
