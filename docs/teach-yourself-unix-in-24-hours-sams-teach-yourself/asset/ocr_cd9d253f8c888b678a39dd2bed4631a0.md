# Task 3.6: Find Where You Are with pwd

+   1. You can use the echo command to list specific environment variables, too. Enter echo $PATH and echo $HOME. When I do so, I get the following results:

% echo $PATH
/users/taylor/bin:/bin:/usr/ucb:/usr/local/bin:/usr/unsup/bin::-
% echo $HOME
/users/taylor
%

Your PATH value is probably similar, although certainly not identical, to mine, and your HOME is /home/accountname (accountname is your account name).

So you've learned a lot about how the file system works but not how to move around the file system. With any trip, the first and most important step is to find out your current location—that is the directory where you are currently working. In UNIX, the command pwd tells you the present working directory.

+   1. pwd. The output should be identical to the output you saw when you entered env HOME because you're still in your home directory.

% env HOME
/users/taylor
% pwd
/users/taylor
%

Think of pwd as a compass, always capable of telling you where you are. It also tells you the names of all directories above you because it lists your current location as an absolute directory name.
