# Hour 7

Unlike previous examples where the program runs until completed, leaving back on the command line, more is the first interactive program you've encountered. When you see the --More-- (51%) prompt, the cursor sits at the end of the line, waiting for you to tell it what to do. The more program lets you know how far into the file you've viewed, too; in the example, you've seen half of the file (51 percent).

At this point, there is quite a variety of commands available. Press the spacebar to see the screen of information, until you have seen the entire file.
