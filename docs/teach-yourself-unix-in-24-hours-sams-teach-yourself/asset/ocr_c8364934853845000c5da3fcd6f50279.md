# Printing in the UNIX Environment

You can use this script to find printers of a certain type or in a specific location, if the descriptions in your /etc/printcap file are configured in the correct manner:

```
% printers -l plotter
knoxmp KNOX 3164 (Hewlett Packard 7550- Plotter)
cp   MATH 6109 (CALCOMP 1073 Plotter)
cvp   MATH 6109 (VERSATEC V-80 Plotter)
% printers -i grep
twi186 MATH 818 (Apple LaserWriter INT(private))
mathci MATH 899 (C.Itoh, white paper (self-service))
mathw MATH 734 (multiple Apple LaserWriter INT)
mathw1 MATH 734 (Apple LaserWriter INT)
mathw2 MATH 734 (Apple LaserWriter INT)
cci  MATH 734 (C.Itoh, 3 hole water printer)
cp   MATH 6109 (EIB 4019 Laser Printer)
cvp   MATH 6109 (VERSATEC V-80 Plotter)
```

4. Now you should be able to choose a printer that's most convenient for your location. Setting the environment variable PRINTER to that value. You might also want to tuck that into the last line of .login file so that next time you log in, the system will remember your printer.

```
% setenv PRINTER mathw
% vi _login
```

> If your printer is not responding to what you set the PRINTER variable to, use the LPDEST variable, especially on System V.
