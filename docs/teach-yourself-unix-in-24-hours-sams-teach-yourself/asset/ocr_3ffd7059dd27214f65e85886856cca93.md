# # Hour 17

# # Job Control

In this hour you will learn about UNIX handles jobs, and how you can manipulate them. Commands you will include `jobs` and `ps`, to see what processes are running; `fg` and `bg`, to move jobs back and forth between the foreground and background; and `kill`, to terminate jobs that you no longer want around.

# # Goals for This Hour

In this hour, you learn

+   - About job control in the shell: stopping jobs
- How to put jobs in the background and bring them back to the foreground
- How to find out what tasks are running by using `jobs` and `ps`
- How to terminate errant processes by using `kill`
