3. This would be a bit more useful if it could show the individual words matched,
r than the entire sentences. Way I wouldn't have to figure out which
words are incorrect. To do this, I use the awk command. It is a powerful
command that uses expressions, which will be discussed in greater detail in
the next chapter. This command will use a for loop, that is, repeat the
command starting from the initial state (i-1) and keep adding one to the counter
(i++) until the end condition is (i-NF): '{for (i=1;i<=NF;i++) print $i}'
Each line seen by awk will be printed one line at a time with this command.
Remember that NF is the number of fields in the current line.

Here is a short example:

```
% echo "this is a sample sentence" | awk '{for (i=1;i<=NF;i++) print $i}'
this
is
a
s
sentence
```
