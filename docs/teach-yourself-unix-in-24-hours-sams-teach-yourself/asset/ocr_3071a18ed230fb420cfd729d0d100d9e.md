# Table 18.3. Useful flags in pr.

| Flag | Meaning |
| --- | --- |
| -n | Produce n-column output per page. |
| +n | Begin printing on the nth page. |
| -f | Don't print the page header and footer information. |
| -hhdr | Use hdr as the head of each page. |
| -wn | Set the page width to n characters (for landscape mode). |
| -m | Print all files at once, per column. |

![](bbox=[0.161, 0.368, 0.258, 0.435])

On some UNIX systems, the -f flag to pr causes the program to form feeds at the bottom of each printed page. To suppress the header and footer, use -t.
