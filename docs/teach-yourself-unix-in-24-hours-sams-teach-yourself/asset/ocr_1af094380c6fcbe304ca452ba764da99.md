# Internet E-Mail, Netnews, and IRC

Did I mention the RNINIT environment variable? In addition to starting options, the rn program can read a variety of different options from environment variables. Indeed, any option that is specified at the command line can be specified in the RNINIT variable. As a result, my RNINIT is:

```
% echo RNINIT
--message -hreference -hdate -hsender -hsummary -hreply -hdistr -hlines
--line -hollow -hnews -hresent -howto -hx-original -hx-sun
-nx-note -hnoriginator -hnntp
```

This causes the program to suppress the display of all the headers in individual news articles. There are so many options that it's overwhelming. Let's go into the program and see what it looks like!
