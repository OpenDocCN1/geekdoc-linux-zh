To see line numbers now, cat -n will work fine:

2. The alternative, which does exactly the same thing here, is to try nl without any flags:

```
% nl testme
1 total 60 1 taylor 1861 Jun 2 1992 Global.Software
```

3. Notice that both commands can also use number lines to feed them via a command pipeline:

```
% ls -CF cat -n
1 Global.Software News/ history.usenet.Z
2 Interactive.Unix Src/ test
3 Mail/ is -CF | nl
4 Global.Software history.usenet.Z
5 Interactive.Unix Src/
6 Mail/ bin/
```

Like other UNIX tools, nl and its duplicate galger aren't very thrilling when showing themselves. As additional members in the set of powerful UNIX tools, they can prove tremendously helpful in certain situations. As you will see, nl also has powerful options that can make it a bit more fun.

# Task 8.6: Cool nl Tricks and Capabilities

A program that precedes each line with a number isn't much of an addition to the UNIX command tool, so the person who wrote the nl program added some further capabilities. With different command flags, nl can either number all lines (by default it numbers only lines that are not blank) or skip line numbering (which means it's an additional way to display only the lines of contents of a file).
