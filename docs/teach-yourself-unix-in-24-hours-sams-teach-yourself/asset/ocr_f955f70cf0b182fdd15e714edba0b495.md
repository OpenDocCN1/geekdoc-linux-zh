To escape the screen (which you learn more later in this hour), press Escape, and your screen should be restored. Notice that the filename has changed and is now showing "Help" instead of the actual file. The status line shows what file you're viewing, but you're not always the file you want to work with.

The key to move the cursor back a few characters is C-b. Use that to move up, and then use C-f to move forward again to the original cursor location.
