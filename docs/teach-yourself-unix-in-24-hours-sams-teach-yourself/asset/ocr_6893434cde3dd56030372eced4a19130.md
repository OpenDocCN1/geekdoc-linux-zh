2. You can remove more than one file at a time by specifying each of the files to the
rm command:

```
% Is
Archives/ PubAccessLists.Z new.login
InfolWorld/ bin/ rumors.260ct.Z
LISTS cshrc.copy rumors.5Nov.Z
Mail/ educ src/
News/ login.copy test/
OWL/ mailing.lists.bitnet.Z testdir/
% rm cshrc.copy login.new login
% Is
Archives/ OWL/ rumors.260ct.Z
InfolWorld/ PubAccessLists.Z rumors.5Nov.Z
LISTS bin/ src/
Mail/ educ test/
News/ mailing.lists.bitnet.Z
```

3. Unfortunately, rm has a command flag to some degree help avoid acciden-
tale file removal. When you use the -i flag or rm (the i stands for interactive in all
case), the system will ask you if you're sure to remove the file:

```
% touch testme
% rm -i testme
rm remove testme? n
% Is testme
testme
% rm -i testme
rm remove testme? y
% Is testme
testme not found
```

Note that n is no and y is yes. Delete the file.
4. Another flag that is often useful

but is very dangerous, the -r flag for
recursive deletion of files (a recursive command repeatedly itself). When it is
-r flag to rm is used, UNIX will remove any specific directory along all its
contents:

```
% ls -ld test ; ls -lr test
drw-xr-xr-x 3 taylor Nov 5 15:32 test/
total 1
-rw-rw---- 1 taylor 0 Nov 5 15:32 alpha
drw-xr-xr-x 2 taylor 512 Nov 5 15:32 test/
test/
total 0
-rw-rw---- 1 taylor 0 Nov 5 15:32 file1
% rm -r test
% ls -ld test
test not found
```

Without any warning or indication that it was going to do something so drastic,
Enter rm -r test caused just the test directory, but all files and directories
inside it as well, to be removed.
