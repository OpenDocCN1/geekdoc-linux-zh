# Introduction to Command Shells

A command alias is a shortcut for a command, allowing you to enter a shorter string for the entire command. The command history is a mechanism by which the shell remembers commands you have typed and allows you to repeat the command without retyping the whole command. Job control is a mechanism that allows you to start, stop, and suspend commands.

In the past few years, another AT&T Labs software, David Korn, has begun distributing another shell which superset of UNIX platforms. The Korn shell, also known as ksh, is designed to be a superset of the Bourne shell, sharing its configuration files (.profile) and command syntax, including many of the more powerful features of the C shell, too, including aliases (albeit in a slightly different format), command history, and job control. This shell is slowly becoming more popular, but it isn't yet widely distributed. You might not have it on your version of UNIX.

Other shells exist in special niches. A modified version of the C shell, a version that incorporates the history-editing features of the Korn shell, has appeared: it is called tcsh. Maintained by some engineers at Cornell University, it is 95 percent C and 5 percent new features. The most important tcsh additions to the C shell are these:

Another shell that you might bump into is the MH shell, or msh, and it's designed around the MH electronic mail program, originally designed at the Rand Corporation. In essence, the MH shell lets you have access to any electronic mail that you might encounter. For security considerations, a restricted version of the Bourne shell is also available, called rsh (interestingly, it's called the restricted r shell). Persistent rumors with problems rsh suggest that you should double-check before you dubious users on your system with rsh as their login shell (The shell you use, by default, when you log in to the system).

Two other variants of the Bourne shell are worth mentioning: jsh is a version of the Bourne shell that includes C shell-style job control features, and bash, also humorously called the "Bourne Again" shell, is a reimplementation of the original shell with many new features and no licensing restrictions.
