## Task 13.1: Launching emacs and Inserting Text

Starting emacs is as simple as starting any other UNIX program. Simply type the name of the program, followed by any file or files you like to work. The puzzle with emacs is figuring out what is actually called on your system, if you have it. There are a couple of ways to try to identify emacs; I will demonstrate these in the “Action 2” section for this task.

Once in emacs, it's important to take a look at your keyboard. emacs requires you to use not just the Control key, but another key known as the Meta key, a sort of alternative Control key. If you have a key labeled Meta or Alt (Alternative) on your keyboard, that is the one. If not, like me, then simply press Escape every time a Meta key is identified.

Because there are both Control and Meta keys in emacs, the notation for indicating is slightly different. Throughout this book, a control-key sequence has been shown either as C-f or as M-f emacs prefers this widely, to show the difference between Control and Meta keys. In emacs notation, f is shown as C-f, where C- always means Control. Similarly, M-x is the Meta key plus the character specified by x. If you don't have a Meta key, the sequence is Escape, followed by x. Finally, some arcane commands involve the Control and Meta keys being pressed (simultaneously with the other key) both the Control and Meta keys while typing x or if you don't have a Meta (or Alt) key, then press Escape followed by C-x.

## Task 13.2: How To Move Around in a File

Files are composed of characters, words, lines, sentences, paragraphs, and emacs commands to help you move about. Most systems have the arrow keys enabled, which helps you avoid worrying about some of the keys, but it's better to know them all anyway.

The most basic motions are C-f and C-b, which are used to move the cursor forward and backward one character. Respectively the Meta command equivalents, and the cursor will move words: M-f moves the cursor forward and M-b moves back a word. C-n moves the cursor to the next line, C-p to the previous line, C-a to the beginning of the line, and C-e to the end of the line. (The vi equivalents for all of these are i, h, d and b for moving forward and backward a character or word; j and k for moving up or down and s to move to the beginning or end of the current line. Which makes more sense to you?)

To move forward a sentence, you can use M-e, which actually moves the cursor to the end of the sentence. Pressing M-a moves it to the beginning of the sentence. Notice the difference between Control and Meta commands: C-a moves the cursor to the beginning of the line, and M-a moves it to the beginning of the sentence.

Scrolling within the document is accomplished using C-v to move forward a screen and M-v to move back a screen. To move forward an actual page (usually 60 lines of text; this is based on a printed page of information), you can use either C-j or C-x for forward motion and backward motion.

Finally, to move to the very top of the file, use M-, and to move to the bottom, use the M-> command.
