# Task 5.7: Identify Owner and Group for Any File or Directory

DESCRIPTION One of the items of information that the ls command displays when used with
-l flag is the owner of the file or directory. So far, all files and directories in
your home directory have been owned by you, with the probable exception of the “….
directory, which is owned by whoever owns the directory over your home.

In other words, when you enter is -l, you should see your account name as the owner for
very file in the list.

If you're collaborating with another user, there might be times when you'll
want to change the owner of a file or directory once you've created or modified it. The first
step in accomplishing this is to identify the owner and group.

Identifying the owner is easy; ls lists by default. But how do you identify the group of
which file or directory is a part?

![](bbox=[0.877, 0.563, 0.971, 0.663])

+   1. The ls command can show the group membership of any file or directory by the
addition of a new command flag, -g. By itself, -g doesn't alter the output of ls, but
when used with the -l flag, it adds a column of information to the listing. Try it with an example:

```
% ls -l /tmp
-rw-r---- root root
drwxr-xr-x root snakes 512 Oct 12 14:52/shakes/
drwxr-xr-x root memend con435 0 Oct 12 14:46 snd.12
-rw-r--r dessy stupracs 1191 Oct 12 14:57 snd.15
-rw-r--r steen utech 1 Oct 12 10:28 snd.17
-rw-r--r jsmith utech 258908 Oct 12 12:37 sol2
```
