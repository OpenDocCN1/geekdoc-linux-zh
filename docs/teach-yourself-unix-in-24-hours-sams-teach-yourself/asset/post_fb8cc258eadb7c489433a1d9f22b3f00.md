This final task on vi introduces you to one of the most powerful and least-known commands in the editor: the t escape-to-UNIX command. When prefaced with a colon (:t, for example), it enables you to run UNIX commands without leaving the editor. More powerfully, the t command in vi itself, just like d and c, accepts address specifications, feeds that portion of text to the command, and replaces that portion with the results of having run command on the text.
