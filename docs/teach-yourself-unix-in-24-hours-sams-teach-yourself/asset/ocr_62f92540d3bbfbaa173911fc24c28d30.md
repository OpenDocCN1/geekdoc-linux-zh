The first item on each line is what is key. You learned in the previous hour that the first item is called the permissions string or, more succintly, the permissions. It is sometimes referred to as the mode or permissions of the file, a mnemonic that can be useful for remembering how change permissions.

The permissions can be broken into four types: type, owner, group, and other permissions. The first character indicates the type: d is a directory and - is a regular file. There are a number of other types of files in UNIX, each is identified by the first letter of its permissions string, as summarized in Table 5.1. You can safely ignore, however, any file that isn't a regular file or directory.
