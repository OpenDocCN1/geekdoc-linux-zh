# Introduction to Command Shells

Here's more arcane UNIX nomenclature: CRT (as used in stty crtabs or cathode-ray tube) is the technology used in the screen of a standard terminal. Terminal is not accurate anymore, however, because the command stty crtabs also works on my LCD (liquid-crystal diode, if you must know) laptop.

Finally, the set commands are configurations for the C shell. I have told the C shell to warn me before it overwrites existing files with file redirection (noclobber), to remember the last 100 commands (history=100), and to remember 50 of those if I log out and log back in (savehist=50). I also want the C shell to try, if possible, to complete filenames for me, the fille Notice there are two types of settings: on/off options (such as noclobber and options to which I must assign a specific numeric value (such as history and savehist).

The two commands at the very end of the login file are invoked as I'd entered them on the command line. The newmail variable watches for new electronic mail (in the mailbox defined by the environment variable MAIL, and tells me when it arrives). The mesg variable makes sure I have my terminal configured so that other folks can be me or say hello using write or talk, two communication tools discussed in Hour 20, "Communicating with Others."
