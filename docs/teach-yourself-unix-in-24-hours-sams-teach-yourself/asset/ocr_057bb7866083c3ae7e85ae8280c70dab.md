# Listing Files and Managing Disk Usage

2. The most basic use of ls is to list files. The command ls lists all the files and directories in the present working directory (recall that you can check what you're in the pwd command at any time).

| Archives | Mail | RUMORS.18Sept mailing.lists |
| --- | --- | --- |
| InfoWorld | bin | bowels |
| LISTS | OWL | iecc.list src |

Notice that the files are sorted alphabetically from top to bottom, left to right. It is the default, as column-first order because it sorts downward, then across. You should also note how things are sorted in UNIX: The system differentiates between uppercase and lowercase letters, unlike DOS. (The Macintosh remembers whether you use uppercase or lowercase letters for naming files, but it can't distinguish them internally. Try it. Name file TEST and another file the test you're using a Macintosh).

![](bbox=[0.125, 0.427, 0.24, 0.499])

Some of the UNIX commands available for the PC—notably SCO and INTERACTIVE UNIX—have an ls that behaves slightly differently and may list all files in a single column rather than multiple columns. If your PC does this, use the -c flag to ls to force multiple columns.

It's important to always remember to type UNIX commands in lowercase letters, unless you know that the particular command is actually uppercase:remember that Archives and archives are different filenames. Also, avoiding your account name in uppercase when you log in. UNIX has some compatibility features that make using the system much more difficult if you use an all-uppercase login. If you ever accidentally log, log out and try again.

# Task 4.2: Having Is Tell You More

Without options, the ls command offers relatively little information. Questions might still have about your directory include: How big are the files? Which are files, and which directories are they? What hidden files do you have?
