# An Overview of the emacs Editor

Entering text in emacs is incredibly simple, and once you get the hang of it, moving about in the file is not too bad, either. The price you pay for this, however, is that emacs is always in insert mode. The motion commands are summarized in Table 13.1.

| Command | Meaning |
| :--- | :--- |
| M-> | Move to end of file. |
| M-< | Move to beginning of file. |
| C-v | Move forward a screen. |
| M-v | Move backward a screen. |
| C-x ] | Move forward a page. |
| C-x [ | Move backward a page. |
| C-n | Move to next line. |
| C-p | Move to previous line. |
| C-a | Move to beginning of the line. |
| C-e | Move to end of the line. |
| M-e | Move to end of sentence. |
| M-a | Move to beginning of sentence. |
| C-f | Move forward a character. |
| C-b | Move backward a character. |
| M-f | Move forward a word. |
| M-b | Move backward a word. |

# Task 13: Delete Characters and Words

Inserting text into emacs is quite simple. The set of Control and Meta commands that enable you to insert text comes no surprise that C-d deletes the current character, M-d deletes the next word, M-k deletes the rest of the sentence, and C-k deletes the rest of the line. If you have a key on your keyboard labeled DEL, RUBOUT, or Delete, you're in luck, because Delete deletes the previous character, M-Delete deletes the previous word, and C-x deletes the previous sentence.

Unfortunately, I have a Delete key, but it's tied to the Backspace function on my system, so every time I press it, it actually sends a C-n sequence to the system, not the DEL sequence. The result is that I cannot use any of these backward-deletion commands.

Actually, VersaTerm Pro, the terminal emulation package I use on Macintosh to connect to the various systems, is smarter than that. I can tell it whether pressing the Delete key should send a C-n or a DEL function in the keyboard configuration screen. One flip of a toggle, and I'm fully functional in emacs. Unfortunately, it's not always this easy to switch from Backspace to DEL.
