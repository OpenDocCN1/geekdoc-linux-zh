srounding it with double quotes:

% who | awk '{ "User " $1 " is on terminal line " $2 ''

2. You can see that already awk can be quite useful. Return now to the /etc/passwd
file and see how awk can help you understand the contents:

```
% grep taylor /etc/passwd | awk -F: '{ print $1 " has "$7" as a
-login shell, ""

User taylor is /bin/bash as their login shell.
User taylor is /bin/bash as their login shell.
```

3. An interesting case that came up while I was working with my site and these examples are
how many different login shells are used at my site and which one is most popular.
On systems, you'd be trapped, probably having to write a program to solve
this question; with awk and some other utilities, UNIX gives all the tools
yed:

```
% awk -F:'{print $7\}' /etc/passwd | sort | uniq -c
2
3365 /bin/csh
1 /bin/false
84 /bin/bash
21 /bin/sh
11 /usr/local/bin/ksh
353 /usr/local/bin/tcsh
45 /usr/local/lib/ms
```
