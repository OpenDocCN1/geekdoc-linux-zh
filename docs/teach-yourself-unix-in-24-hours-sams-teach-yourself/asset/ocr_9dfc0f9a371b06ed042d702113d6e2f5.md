# Task 7.5: Viewing the Contents of Files with cat

Both head and tail offer the capability to view a piece of a file, either the top or bottom, but neither lets you see the entire file, regardless of length. For this job, the cat program is the right choice.

The cat program gets its name from its function in the early versions of UNIX; its function was to concatenate (or join together) multiple files. It isn't, unfortunately, to home feline pelts or anything so exotic!

The cat program also has a valuable secret capability, through use of the -v flag, you can use cat to display any file on the system, executable or without, with all characters that normally would not be printed (or would drive your screen bombers) displayed in a special format I call control-key notation. In control notation, each character is represented as ^n, where n is a specific printable character or symbol. The character with the value of 0 (also referred as a null or null character) is displayed as ^^, a character with the value of 1 is ^A, a character with the value 2 is ^B, and so on.
