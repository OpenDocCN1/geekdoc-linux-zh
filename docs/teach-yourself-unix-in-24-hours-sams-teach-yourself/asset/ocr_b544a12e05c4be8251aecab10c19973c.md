# Task 5.3: Modify File and Directory Permissions with chmod

DESCRIPTION Now that you can list directories and understand what they mean, learning about a UNIX command that lets you change them to meet your needs?

You've already had a sneak preview of the command: chmod. The mnemonic is "change mode," and it derives from early UNIX folk talking about permission modes of files. You can remember it by thinking of it as a shortened form of change mode.

> To sound like a UNIX expert, pronounce chmod as "ch-mod," "ch" like the beginning of child, and "mod" to rhyme with cod.

JUST A MINUTE The chmod command enables you to specify permissions in two different ways: symbolically or numerically. Symbolic notation is most commonly used to modify existing permissions, whereas numeric format replaces any existing permission with the new value specified. In this task, you learn about symbolic notation, and the next task focuses on the powerful numeric format.
