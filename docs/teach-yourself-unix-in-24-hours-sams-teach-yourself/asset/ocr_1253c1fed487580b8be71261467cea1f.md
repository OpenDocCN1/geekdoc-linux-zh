+   4. You could improve the alias for DIR by having the output of ls fed directly into the more program that a directory listing with a lot of output will automatically pause at the end of each page. To redefine an alias, just define it:

% alias DIR "ls -IF | more"

To confirm that the alias is set as you desire, try this:

% alias alias DIR
DIR ls -IF | more

![](bbox=[0.125, 0.347, 0.233, 0.429])

> If you're just defining one command with an alias, you don't really need to use the quotation marks around the command argument. But what would happen if you entered alias DIR ls -IF | more? The alias would be set to ls -IF, and the output of the command would be fed to the more program, which is quite different from what you desired. Therefore, it's just good to use the quotation marks and a good habit to get into.

SUMMARY Aliases are a great addition to any command shell, and they can be used to define full-word commands as synonyms. For example, if you'd like the simplicity of removing the command move to a file somewhere else, you could add the new alias move mv to your .cshrc if you're using C shell or alias move-mv to your .profile if you prefer Korn shell, and this would include a new command.
