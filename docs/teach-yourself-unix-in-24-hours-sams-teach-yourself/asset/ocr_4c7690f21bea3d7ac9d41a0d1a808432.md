7. Here's another example of awk. I will modify the output of the ls -l command so that I build a quick list of files and their sizes (which isn't what is shown with the ls -s command, recall):

```
% ls -s | awk '{ print $9 " " $5 }'
archives/ 512
InfoId/ 512
Mail/ 1024
News/ 512
OWL/ 512
bin/ 512
keyline.pie 12556
randy 11503
src/ 512
temp 582
testme
```

The output is a bit messy, so you should learn about two special character sequences that can be embedded in the quoted arguments to print:

+   - \n Generates a carriage return
-\t Generates a tab character

In any case, the output is in the wrong order, anyway:

```
% ls -IF | awk '{ print $5 "\t" $9 }'
Archives/ 512
InfoId/
Mail/ 1024
News/ 512
OWL/ 512
bin/
keyline.pie 12556
randy 11503
512
src/
512
temp/
582
testme
```

Piping the results to sort -rn could easily be used to figure out your largest files:

```
% ls -l | awk '{print $5"\t" $9 }' | sort -rn | head -5
12556 keyline.pie
11503 randy
1024 Mail/
582 testme
512 temp/
```

8. The awk program basically looks for a pattern to appear in a line and, if the pattern is found, executes the pattern in the awk script. There are two special patterns in awk: BEGIN and END. The instructions that follow BEGIN are executed before any lines of input are read. The instructions that follow END are executed only after all the input has been read.
