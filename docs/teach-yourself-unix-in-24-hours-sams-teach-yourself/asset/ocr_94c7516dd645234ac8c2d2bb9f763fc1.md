Throughout this book, I refer to the Return key, but your keyboard may have this key labeled as “Enter” or marked with a left-pointing, specially shaped arrow. These all mean the same thing.

JUST A MANUAL

In Windows, you might move a folder from one folder to another by opening the destination folder, fiddling around for a while to be sure that you can see both of them on the screen at all time, and then clicking and drawing the specific file from one place to the other. In UNIX it's much easier. Typing in the following simple command does the trick:

```
cp folder1/file folder2
```

It automatically ensures the file has the same name in the destination directory, too.

This might not seem much of a boon, but imagine the situation where you want to move all files with names that start with the word project or end with the suffix .c (C program files). This could be tricky and could take a lot of patience with a graphical interface. UNIX, however, makes it easy:

```
cp "project" *.c folder2
```

Soon you will not only understand this command, but you will also be able to compose your own examples!

# Getting Help

Throughout this book, the focus is on the most important and valuable flags and options for the commands covered. That's all well and good, but how do you find out about the other alternatives that might actually work better for your use? That's where the UNIX “man” pages come in. You will learn how to browse them to find the information desired.

# Task 1.1: Man Pages, UNIX Online Reference

It's not to you that UNIX is a very complex operating system, with hundreds of commands that can be combined to execute thousands of possible actions. Most commands have a considerable number of options, and all seem to have some subtlety or other that's important to know. But how do you figure all this out? You need to look up commands in the online documentation set. Containing purely reference materials, the UNIX pages (man is short for manual) every command available.

Search for a man page, enter man followed by the name of the command to find. Many sites also have a table of contents for the man pages (it's called whatis database, for obscure historical reasons). You can use the all-important -k flag for keyword searches, to find the name of a command if you know what it should do but you just can't remember what it's called.
