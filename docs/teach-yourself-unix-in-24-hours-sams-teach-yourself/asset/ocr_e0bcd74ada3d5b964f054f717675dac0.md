As you can see, ftp can be long-winded.

> One trick for using the ls command within ftp is that if you specify a set of command flags as a second word, it works fine. Specify a third argument, and it saves the output of the command into a local file by name; so ls -i -c would create a file called -c on your system with the output of the ls -i command.
