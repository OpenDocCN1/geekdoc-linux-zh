# Task 12.4: Search and Replace

Though vi is easy to learn, one command that always creates great trouble is the search-and-replace command. The key to understanding this command is to remember that vi is built on the line editor (es). Instead of trying to figure out some arcane command, it's easiest to drop down to the line editor and use a simple colon command—one identical to the command used in sed (as described in Hour 9, "Wildcards and Regular Expressions")—to replace an old pattern with a new one. To replace an existing word on the current line with a new word (the simplest case), use :s/old/new/. If you want to have all occurrences on the current line matched, you need to add the g suffix (just as with sed): :s/old/new/g.
