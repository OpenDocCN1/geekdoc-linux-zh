## Task 15.3: Command Aliases

If you think the history mechanism has the potential to save you typing, just haven't learned the command-alias mechanism in the Korn and C shells. Using aliases, you can easily define new commands that do whatever you'd like, or even redefine commands to work differently, have different default flags, or more!
The general format for using aliases in csh is alias command--sequence, and in it is alias word=commands. If you enter alias without any specified words, the output shows a list of aliases you have defined. If you enter alias word in csh, the output lists the current alias, if there is one, for the specified command.

-4. You could improve the alias for DIR by having the output of ls fed directly into the program that a directory listing with a lot of output will automatically pause at the end of each page. To redefine an alias, just define it:

% alias DIR "ls -IF"

To confirm that the alias is set as desire, try this:

% alias DIR ls -IF

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_344_0.png)

> If you're just defining one command with an alias, you don't really need to use the quotation marks around the argument. But what would happen if you entered alias DIR ls -IF? The alias would be set to ls-IF, and the output of the command would be fed to the program, which is quite different from what desired. Therefore, it's just good to use the quotation marks and a good habit to get into. DESCRIPTION Aliases are a great addition to any shell, and they can be used to define full-word commands as synonyms. For example, if you'd like the simplicity of removing the command move to somewhere else, you could add alias move to your .cshrc if you're using C shell or alias-mv to your .profile if you prefer Korn shell, and this would include a new command.
