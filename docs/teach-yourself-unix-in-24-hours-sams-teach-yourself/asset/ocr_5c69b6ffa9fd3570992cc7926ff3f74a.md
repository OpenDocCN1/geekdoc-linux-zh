8. If you've ever spent time on an electronic network, you've probably seen either electronic mail or articles which the author responds to a previous article. Most commonly, each line of the original message is included, each prefixed by >. It turns out that the appropriate tool to edit is to add a prefix to a group of lines or to remove a prefix from lines in a file.

```
% cat << EOF sample
Hey! I've been looking for a music CD and none of
t shops around here have a clue about it. I was
wondering if you're going to have a chance to get into
Tower Records in the next week or so?
EOF
% sed s/"/ // sample > sample2
% cat sample2
Hey! I've been looking for a music CD and none of
t shops around here have a clue about it. I was
wondering if you're going to have a chance to get into
Tower Records in the next week or so?
% cat sample2 | sed s/"$/$ //
```

Recall that the cat (*) signifies the beginning of the line, so the first invocation of sed searches for the beginning of each line and replaces it with ">", saving
output to the file as sample2. The second use of sed —wherein I remove the
does the opposite search, finding all occurrences of "-" that are at the beginning
a line and replacing them with a null pattern (a null pattern is what you when when have two slash delimiters without anything between them)

I've only scratched the surface of the sed command. It's one of those commands\where the more you learn about it, the more powerful you realize it. It is,
paradoxically, the more you learn about it, the more you'll really gain a graphical interface
to simplify your life, too.

researching this point of the hour is that sed can be used to delete from

to strip headers from an email message by specifying the
pattern 1,^$/d. Soon, you will learn about e-mail and how this command
