8. In the middle of doing all this, I became curious about how many people my
system have names that are four letters long. Is this impossible to compute?
Not with UNIX!

The first step is to extract the full names from /etc/passwd file:

```
% awk -F: '{print $5 }'
```

The system does not respond. I forgot to specify the filename:

```
% ! -F: /etc/passwd
awk -F '{print $5}' < /etc/passwd
imbo root...
USENET News...
INGRES Manager...
(1000 user system) DO NOT...
Vanilla Account...
The Ferryman,...
```

I can use ^c to stop this output, because I've seen enough to know that it's what I
want. Next, I use awk again to just pull the first names out of this list:

```
% !! | awk '{print $1}' < /etc/passwd | awk '{print $1}'
root
USENET
INGRES0
root
USENET
INGRES
(1000)
Vanilla
The
Account
%
```

It looks okay. The final step: I need to revise this awk script to look at
the length of name, and the name only if it's four letters long:

```
% !1-2 | awk '{ if ($1) == 4) print $0 }'
awk -F '{print $5}' < /etc/passwd | awk '{ if (length($1) == 4) print $0 }'
```

I got no output at all! The reason is that I typed length and lng. Fortunately,
fix this is simplicity itself with C shell history commands. Remember, the format is
^new:

```
% ^$length
awk -F '{print $5}' < /etc/passwd | awk '{ if (length($1) == 4) print $0
```
