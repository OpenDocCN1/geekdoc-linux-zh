# Task 5.5: Calculating Numeric Permissions Strings

## DESCRIPTION
For example, if you wanted to have a directory set so that you have all access, people in your group can look at the contents but not modify anything, and everyone else is shut out, how would you do it?

All permissions for yourself you mean read-write-execute for owner (numeric permission 7); read and listing permission for others in the group means read-execute for group (numeric permission 5); and no permission for everyone else, numeric permission 0. Put the three together and you have the answer, 750.

That's the trick of working with chmod in numeric mode. You specify the absolute permissions you want as a three-digit number, and the system sets the permissions on the file or directory appropriately.

The absolute concept is important with this form of chmod. You cannot use it to add or remove permissions from a file or directory. It is usable only for reassigning the permissions string of a file or directory.

The good news is, as you learned earlier in this hour, there is a relatively small number of commonly-used file permissions, summarized in Table 5.5.

# Table 5.5. Common permissions and their numeric equivalents.

## Task 5.6: Establish Default Permissions with umask

When you create files, the umask determines the default permissions.

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_115_0.png)

The umask is a set of bits that tells the system which permissions to turn off when a file or directory is created. For example, if the umask is 022, a new file will have permissions 644 (rw-r--r--) and a new directory will have 755 (rwxr-xr-x). This is because files are typically created with 666 and directories with 777 by default.

The umask can be set using the `umask` command. For example, `umask 022` will set the umask to 022 for the current shell session. To check the current umask, simply type `umask` without any arguments.

The umask is expressed in octal notation. Each digit represents a group of users: owner, group, and others. The digit represents the permissions that are *masked out*. For example, a umask of 022 means that the owner's permissions are unchanged (0), while the group and others have write permissions masked out (2).

The umask can also be set globally by editing configuration files like `/etc/profile` or `/etc/bashrc`. This ensures that all users have the same default umask.

The umask is a powerful tool for controlling the security of your system. By understanding how it works, you can ensure that new files and directories are created with the appropriate permissions.
