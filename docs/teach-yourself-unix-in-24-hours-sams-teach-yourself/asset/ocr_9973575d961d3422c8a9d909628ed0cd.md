# SUMMARY

You can use the cp command to copy an original file as a new file or to a specific directory (the format being original-file new-file-or-directory), and you can copy a bunch of files to a directory (cp list-of-files new-directory). Experiment with creating directories using mkdir and copying the files into the new locations. Use is to confirm that the originals aren't removed as you go along.

# Task 6.3: Moving Files to New Locations mv

# DESCRIPTION

Whereas cp leaves the original file intact, making a sort of electronic equivalent of a photocopy of a paper I pick up at my desk, mv functions like a more traditional desk: papers are moved from one location to another. Rather than creating multiple copies of the files you are copying, mv physically relocates them from one directory to the other.

+   1. You use mv almost the same way you use cp:
% ls -l login.copy
-rw-- 1 taylor 1858 Nov 5 12:08 login.copy
% mv login.copy new.login
% ls -l login.copy new.login
login.copy not found
-rw-- 1 taylor 1858 Nov 5 12:08 login.login

+   2. Also, you move a group of files together mv almost the same way you use cp:
% cd NEWDIR
% ls
% cshrc.login.copy
% mv cshrc.copy login.copy -
% ls -l
-total 0
% ls
Archives/ mailing-lists.bitnet.Z
Inforold/ PubAccessLists.Z new.login
LISTS/ runors.260ct.Z
Mail/ bnn/ cshrc. runors.5Nov.Z
NEWDIR/ educ
News/ login.copy src/

+   3. Because you can use mv to rename files or directories, you can relocate the directory NEWDIR. However, you cannot use mv to relocate the directory because you are inside it:

```
% mv -- new.dot
mv :: rename: Invalid argument
```

+   4. Both mv and cp can be dangerous. Carefully consider the following example trying it mv on your computer:

```
% ls -l login.copy cshrc.copy
-rw-- 1 taylor 1178 Nov 5 12:38 cshrc.copy
-rw-- 1 taylor 1858 Nov 5 12:37 login.copy
% cp cshrc.copy login.copy
% ls -l login.copy cshrc.copy
```
