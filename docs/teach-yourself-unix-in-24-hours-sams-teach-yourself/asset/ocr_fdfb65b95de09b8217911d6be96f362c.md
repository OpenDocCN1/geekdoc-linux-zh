Unfortunately, I have a Delete key, but it's tied to the Backspace function on my system, so every time I press it, it actually sends a C-n sequence to the system, not the DEL sequence. 
The result is that I cannot use any of these backward-deletion commands.

Actually, VersaTerm Pro, the terminal emulation package I use on Macintosh to connect to the various UNIX systems, is smarter than that. I can tell it whether pressing the Delete key should send a C-n or a DEL function in the keyboard configuration screen. One flip of a toggle, and I'm fully functional in emacs. Unfortunately, it's not always this easy to switch from Backspace to DEL.
