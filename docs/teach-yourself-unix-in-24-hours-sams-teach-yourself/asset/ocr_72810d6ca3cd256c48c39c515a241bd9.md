2. There are nine ways to sort files in. If you want to sort by most-recently accessed to least-recently-accessed, use the -t flag:

```
% Is -a ../cshrc
..newsrc News/ .sig
..oldnewsrc .tin/ .rnsoft plan
..article .ironmot .plan Mail/
..elm/ .degroups Interactive.Unix
../forward .login .accinfo* .Pnews.header
..rmlast Src .pnewsexpert
..tin Global.Software
..bin bin Global.Software .logout
history.usenet.Z history.usenet.Z
```

From this output, you can see that the most recently accessed files are .newsrc and .oldnewsrc, and it's been quite a while .logout was touched. Using the -t flag on them to see which files you've accessed and which you haven't.

3. So, you know three different approaches to sorting files within the ls command: column-first order, first-order, and most-recently-accessed order. There are more options in ls than just these three; the -r flag reverses any order.

```
% Is Mail/ Src/
Global.Software News/ history.usenet.Z
Interactive.Unix bin/
% Is -r Src/ Global.Software
history.usenet.Z Mail/
bin/ News/
Interactive.Unix
```
