To add the contents of a file to the current edit buffer, use the command C-x i. It will prompt for a filename. Press C-x C-w prompts for a file to write the buffer into, rather than the default file. To save to the default file, use C-x C-s (that is, if you can; the C-s might hang up you, just as it did when you tried to use it for searching). If that doesn't work, you can use the alternative C-x s, which also works. To move to another file, use C-x C-f (emacs users never see more than one filename on the command line). They use C-x f to move between files installed). What's nice that when you use the C-x C-f command, you load the contents of that file into another buffer, so you can zip quickly between files using the C-x b to switch buffers. emacs allows you to edit several files at once using different areas of the screen; these are called buffers.
