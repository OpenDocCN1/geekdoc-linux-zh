# Task 13.5: Using the emacs Tutorial and Help System

Unlike vi and, indeed, unlike of UNIX, emacs includes its extensive, built-in documentation and a tutorial to help you learn how to use the program.

I noted earlier, the entire help system is accessed by pressing C-h three times brings up the general help menu. There is also an information browser called (accessed by pressing C-h i) and a tutorial system you can start by pressing C-h t.

emacs enthusiasts insist that the editor is modeless, but in fact it does have modes of its own. You used just once, the query-replace mode. To obtain help on the current mode that you're working in, you can use C-h m.
