```
% grep owl testme
%
```

Note that OWL was not found because the pattern specified with the grep command was all lowercase, owl.

```
% grep -i owl testme
Archives/ OWL/ keylime.pie
```

# Task 9.5: For Complex Expressions, Try egrep

Sometimes a regular expression can't locate what you seek. Perhaps you're looking for lines that have either one or more pattern. That's where egrep command proves helpful. The command gets its name from "expression," and it has notation more powerful than that of grep, as shown in Table 9.3.

Table 9.3. Regular expression notation for egrep.

| Notation | Meaning |
| :--- | :--- |
| c | Matches the character |
| \c | Forces c to be read as the letter, not as another character |
| ^ | Beginning of the line |
| $ | End of the line |
| . | Any character |
| [xy] | Any character in the set |
| [^xy] | Any character not in the set |
| * | Zero or more occurrences of character |
| + | One or more occurrences of character |
| ? | Zero or one occurrences of character |
| a\|b | Either a or b |
| (a) | Regular expression |

- 3. Now I use a complicated grep pattern, and that should make sense to you:
```
% grep "([a-zA-Z])[:wi]" /etc/printcap | head
agl1:wi=23:wk-multiple AppleWriter
agl2:wi=23:wk-Apple LaserWriter
agl3:wi=23:wk-Apple LaserWriter
agl4:wi=23:wk-Apple LaserWriter
```

Now you can see that the pattern specified looks either for lines that begin (^) with an upper- or lowercase letter ([a-zA-Z]) or for lines that contain the pattern :wi.

Any time you want to look for lines that contain more than a single pattern, egrep is the best command to use.

# Task 9.6: Searching for Multiple Patterns at Once with fgrep

Sometimes it is helpful to look for many patterns at once. For example, you might want to have a file of patterns and invoke a UNIX command that searches for lines that contain any of the patterns in that file. That the fgrep, or file-based grep command comes into play. A file of patterns can contain any pattern that grep would understand (which means, unfortunately, you can't use the additional notation available in egrep) and is specified with the -f file option.

- 1. I use fgrep with wrongwords, an alias and file that contains a list of words commonly misuse. Here's how it works:

```
% alias wrongwords grep -i -f .wrongwords
% cat .wrongwords
effect
affect
insure
ensure
idea
thought
```

Any time I want to check a file, for example dickens.note, to see if it has any of these commonly misused words, I simply enter the following:

- % wrongwords dickens.note
```
drama of The Frozen Deep, I first conceived the main idea of this
As the idea became familiar to me, it gradually shaped itself into its

I need to determine whether these are ideas or thoughts. It's a subtle distinction I often forget in my writing.

- 2. Here's another sample file that contains a couple of words with wrongwords:

- % cat sample3
```

3. This would be a bit more useful if it could show the individual words matched, than the entire sentences. To do this, I use the awk command. It is a powerful command that uses expressions, which will be discussed in greater detail in the next chapter. This command will use a for loop, that is, repeat the command starting from the initial state (i-1) and keep adding one to the counter (i++) until the end condition is (i-NF): '{for (i=1;i<=NF;i++) print $i}'
Each line seen by awk will be printed one line at a time with this command. Remember that NF is the number of fields in the current line.

Here is a short example:

```
% echo "this is a sample sentence" | awk '{for (i=1;i<=NF;i++) print $i}'
this
is
a
s
sentence
```
