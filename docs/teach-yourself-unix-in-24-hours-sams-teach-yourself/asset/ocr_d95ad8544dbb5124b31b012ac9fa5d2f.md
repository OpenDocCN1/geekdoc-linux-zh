# Just A Minute

At this point, bg will continue the program, running it in the background:

```
% bg
[1] awk -F: '{print $1" = "$5"} < /etc/passwd | awk -F, '{print $1}'
| awk '{ if (NF > 2) print $0 }' | sort | who.is.who
%
```

The number in brackets is this job's control number in the shell. In a
moment, you learn why this is a handy number to know:

On some systems, a completed job will notify you that it's
done, but on most systems, after a completed job has finished running,
itit waits until you press Return to get a system prompt before it lets you know.
after after 30 or 60 seconds. Press Return and see this:

```
%
[1] Done                awk -F:
{print $1" = "$5"} < /etc/passwd | awk -F,
{print $1} | awk { if (NF > 2) print $0 } | sort | who.is.who
%
```

3. Alternatively, a better strategy for moving a program into the background is to
move process to the background automatically by adding an & to the very end:

```
% awk &
awk -F: '{print $1" = "$5"} < /etc/passwd | awk -F, '{print $1}'
| awk '{ if (NF > 2) print $0 }' | sort | who.is.who &
n[1] 27556 27557 27559

```

This is interesting. This command shows with a control number of 1, but
the four numbers listed after that are the actual process ID numbers of each piece
of pipeline: 27556 is the first awk process, 27557 is the second awk process, 27558
it the third awk process, and 27559 is the sort program.

Again, when complete, pressing Return lets know:

```
%
[1] Done                awk -F: '{print $1" = "$5"} < /etc/passwd |
awk -F, {print $1} | awk { if (NF > 2) print $0 } | sort | who.is.who
%
```
