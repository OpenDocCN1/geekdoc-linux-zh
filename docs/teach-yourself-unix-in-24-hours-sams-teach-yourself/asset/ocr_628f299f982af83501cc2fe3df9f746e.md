% emacs
emacs: Command not found.
%
This is a good indication that emacs isn't available. If your command worked, and you are now in the emacs editor, move down to instruction 2 in this task.
A popular version of emacs is from the Free Software Foundation, and it's called gnu emacs. To see if you have this version, type gnemacs or gnumacs at the command line.
