# Task 6.1: Creating New Directories Using `mkdir`

One aspect of UNIX that has been emphasized continuously in this book is that the UNIX file system is hierarchical. The UNIX file system includes directories containing files and directories, each of which can contain both files and directories. Your own home directory, however, probably doesn't contain any directories (except `.` and `..`, of course), prevents you from exploiting what I call the virtual file cabinet of the file system.

The command for creating directories is actually one of the least complex and most mnemonic (for UNIX, anyway) in this book: `mkdir`, called "make dir."
