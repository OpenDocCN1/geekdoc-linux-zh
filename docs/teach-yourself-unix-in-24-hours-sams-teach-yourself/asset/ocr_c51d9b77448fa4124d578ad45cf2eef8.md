1. Turn to your computer and check your umask setting, then alternate between
changing its values and creating new files with touch:

```
% umask
7
% touch test.07
% ls -l test.07
--rw-rw---- 1 taylor      0 Oct 12 14:38 test.07
```

2. To change the value of your umask, add the numeric value of the desired mask to
the command line:

```
% umask 077
```

This changes your umask value from 007 (------rwx) to 077 (-rwxrwx). Before you
look at the following listing, what would you expect this modification to mean?
Remember, you should read it as the exact opposite of how you want the default
permissions.

```
% touch test.077
% ls -l test.077
--rw-rw---- 1 taylor      0 Oct 12 14:38 test.077
```

Is that what you expected?
3. What would you do if you wanted to have the default permission keep files
just to the owner and make them read-only?

You can work through this problem in reverse. If you want r-x------ as the default
permission (since the system takes care of whether permission is needed,ase on type), write down the opposite permission, which is --rwxrwx.
Translate that to a binary number, 010 111 111, and then to a three-digit value,
277 (010=2, 111=7). That's the answer. The value 277 is the correct umask
to ensure that files you create are read-only for everyone and off-limits to
every else.

```
% umask 277
% touch test.277
% ls -l test.277
--r-------r 1 taylor      0 Oct 12 14:39 test.277
```

4. What if you wanted to have files created with the default permission being read-
only for everyone, read-write for the owner? Again,
work backwards. The desired permission is r-xrwx-x, so create the opposite value
(-rw-rw--), translate it into binary (010 000 010), and then translate that into a
three-digit value: 202 (010=2, 000=0, 010=2).
