# 2. Rename a directory, too:

```
% ls -ld NEWDIR
drwxwx---- 2 taylor 512 Nov 5 12:32 NEWDIR/
% mv NEWDIR New.Sample.Directory
% ls -ld New.Sample.Directory
drwxwx---- 2 taylor 512 Nov 5 12:32 New.Sample.Directory/
```

3. Be careful! Just moving with cp and mv can carefully overwrite existing files, renaming files using mv can overwrite existing files:

```
% mv dave login.copy
```

If you try to rename a new directory with a name that has already been assigned to a file, the command fails:

```
% mv New.Sample.Directory rename
mv: New.Sample.Directory: rename: Not a directory
```

The reverse situation works fine because the file is moved into the directory as expected. It's the subtlety of using the mv command to rename files.

4. If you assign a directory that belongs to an existing directory, some versions of mv will happily overwrite the existing directory and the new one as requested:

```
% mkdir testdir
% mv New.Sample.Directory testdir
```

> SUMMARY Being able to rename files is another important part of building a useful UNIX virtual cabinet for yourself. There are some major dangers involved, however, so tread carefully and always use in conjunction with cp and mv to ensure that in the process you don't overwrite or replace an existing file.

# Task 6.5: Removing Directories with rdir

DESCRIPTION Now that you can create directories using the mkdir command, it's time to learn how to remove directories using the rdir command.

+   1. With rdir, you can remove any directory for which you have appropriate permissions:

```
% mkdir test
% ls -l test
total 0
% rdir test
```

Note that the output of ls shows there are no files in the test directory.
