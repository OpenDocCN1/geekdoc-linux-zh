# Task 10.2: Re-routing the Pipeline with tee

After the substantial sed and awk commands, this next command, tee, should be a nice reprieve. It's simple, can't be programmed, and has only one possible starting flag.

Recall that | symbol denotes a pipeline and that information traveling from one command to another is considered to be streaming down the pipe. For example, | sort has the output of the who streaming down the pipe to sort command. Imagine it as some huge, albeit weird, plumbing construction.

With the plumbing metaphor in mind, you can imagine that it is helpful to be able to split off the stream to make travel down two directions instead of just one. If multiple pipelines were really allowed, neither nor I could figure out the heck was going on. The simpler goal, however, of saving a copy of the stream in a file as it whizzes past is more manageable, and that is exactly what the tee command can do.

The only option to tee is -a, which appends the output to the specified file, rather than replaces the contents of the file each time.
