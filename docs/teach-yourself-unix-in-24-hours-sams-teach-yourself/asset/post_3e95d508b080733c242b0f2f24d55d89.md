- 2. The login command offers a shorthand notation for logging out of the remote system; instead you can simply enter --. To stop the login session, -z. No other idle commands are available in login.

I choose to log out the normal way:

```
netcom % logout
Connection closed
%
```

Now I'm back on the original computer system:

- 3. The alternate way to connect to a remote computer is to use telnet. The easiest way to use this is the same way you use login. At the command prompt, specify the name of the system to which you want to connect:

```
% telnet netcom.com...
Trying...
Connected to netcom.com.
Escape character is '^'.
```

There are lots of possible commands. I choose to return to my connection to Netcom, however I just press Return, and I'm back at the login prompt. If I don't enter anything quickly, the remote system automatically drops the connection:

```
login: Login timed out after 60 seconds
Connection closed by foreign host.
%
```

To log out of the remote system, the best strategy is to exit the telenet session, which will drop the line automatically. If that doesn't work, the ^ sequence followed by quit or close will do the trick.

- 5. To start out directly in the telenet command mode, simply enter the command without specifying a remote host:

```
% telenet
telenet > _
```

From here, connecting to the remote host is also quite simple:
telenet> open netcom.com
Trying...

# Task 23.2: Copying Files from Other Internet Sites

The main program used to copy files on the Internet is ftp, which is named after the file transfer protocol. Much of UNIX, ftp can take awhile to master, particularly because no effort has been made to make it at all user-friendly. Nonetheless, it functions very similarly to the telnet command; you either ftp to start the program and then specify the system with which you'd like to connect, or you specify the name of the system on the command line. Either way, you are then prompted for an account and password; then you are dropped into the ftp prompt waiting.

Many sites talk about having anonymous capabilities. Systems allowing this indicate that you don't need your own account to be able to connect and copy files from their archives. To use these systems, enter ftp as the account name, and then enter ftp@netcom.com as the password. The most important commands available in ftp are summarized in Table 23.1. The most important one to remember is bye, which you use when you're done.

# Table 23.1. Valuable commands.

| Command | Meaning |
| :--- | :--- |
| ascii | Set ftp to transfer a text (ASCII) file. |
| binary | Set ftp to transfer a binary file, probably a database. |
| bye | Quit the ftp program. |
| cd dir | Change the remote directory. |
| close | Close the current connection. |

# Table 23.1. continued

| Command | Meaning |
| :--- | :--- |
| dir | Print a listing of the remote directory. |
| get | Transfer a file from the remote system to your local system. |
| lcd dir | Change the current directory on the local system or home directory if no argument is given. |
| ls | List the files in the remote directory. |
| mget | Multiple get with wildcard. |
| mput | Multiple put with wildcard. |
| open | Open a connection to the specified remote machine. |
| prompt | Control whether or not to ask for confirmation of each transfer using mget or mput. |
| put | Put a file onto the remote system. |
| pwd | Show the present working directory on the remote. |

- To start out, I want to pick up a file from netcom that I saw earlier when I used login to look at the remote system. To start, I use the short notation of specifying the host at the command line:

```
% ftp netcom.com
Connected to netcom.com.
netcom FTP (Version 2.1 Apr 9 13:43 PDT 1996) ready.
Name (netcom:taylor): _
```

By default, ftp assumes I want to use the same account name, which in this case, if I press Enter, and then enter my password:

```
Name (netcom:taylor):

Password:
230 User taylor logged in.
ftp> _
```
