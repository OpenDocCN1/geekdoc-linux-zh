# Entering in the more Program

In this title and in the following text, the word enclosed in brackets [Space] refers to the spacebar as a command. Likewise, [Return] means you should press the Return key as part of the command. A hyphen in a command—for example—means that you should hold the first key. The lowercase-letter commands together, but without a hyphen, mean you should press the corresponding key. Finally, entries that have before the command mean you can prefix the command with a number, which will let it modify its action. For example, 3[Return] displays the next lines of the file and 20 skips the next lines. Typically, pressing Return after typing a command is not necessary. Try some commands on your own. # Looking into Files

This example isn't exactly what you'll see on your screen because each time you type a command to more, it erases its own prompt and replaces the prompt with the appropriate line of file. Try pressing [Return] to move down one line, and you'll see what I mean.

Quit more in the middle of viewing this file by typing q.

The program is one of the best general-purpose programs in UNIX, offering an easy and powerful tool for perusing files. The biggest limitation, however, is that you can't go backward in the file: If you realize that you are looking for is not the previous page, you have to quit and start the program again.

# Key Terms

block special device A device that controls block-oriented peripherals. A hard disk, for example, is a peripheral that works by reading and writing blocks of information (as distinguished from a character special device). See also character special device.

character special device A device that controls a character-oriented peripheral. Your keyboard and display are both character-oriented devices, sending and displaying information on a character-by-character basis. See also block special device.

control-key notation A notational convention in UNIX that denotes the use of a control key. There are three common conventions: Ctrl-C, ^c and C-C all denote the Control-character, produced by pressing the Control key (labeled Control or Ctrl on your keyboard) and, while holding it, pressing the e key.

core dump The image of a command when executed improperly.

interactive program An interactive UNIX application is one that expects the user to enter information and then responds as appropriate. The ts command is not interactive, but the more program, which displays a screenful at a time, is interactive.
