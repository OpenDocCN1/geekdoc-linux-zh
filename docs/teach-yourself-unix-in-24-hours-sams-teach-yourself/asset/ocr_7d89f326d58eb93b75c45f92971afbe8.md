# Task 18.2: Printing Files with lpr or ip

DESCRIPTION Now that you have identified the name of the printer to use, how about sending information to the printer? If you are on a BSD system, the command to do this is lpr. You can print the results of a pipe command by adding lpr at the end of the pipeline, or you can print files directly by specifying them to the program. You can even use < redirect input.

If you’re using a System V of UNIX, you will need to use the ip command instead. As you read through this hour, you will see the differences between lpr and ip indicated. Note how the philosophies of the two vary.

The flags available for lpr and ip are numerous, and the most valuable ones are listed in Table 18.1 and Table 18.2.

# Table 18.1. Useful flags for lpr.

| Flag | Meaning |
| -h | Do not print the header page. |
| -i | Indent the entire file eight spaces before printing. |
| -L | Print in landscape (sideways) mode, if the printer is capable of doing so. |
| -Ppr | Send the print job to printer pr. |
| -R | Print pages in reverse order. |

# Table 18.2. Useful flags for ip.

| Flag | Meaning |
| -dptr | Send the print job to the printer named ptr. |
| -Pn | Print only page n. |
| -title | Use title as the cover page title, where title is any string. |

+   1. Here’s a demonstration of what happens if you try to use ip or lpr without specifying a printer and without having the PRINTER environment variable set. First use the unsetenv command to remove environment variable definitions:

```
% unsetenv PRINTER
% who | ip
lpr: No printer specified
Broken pipe
```
