# Hour 5

# Ownership and Permissions

This hour focuses on teaching the basics of UNIX file permissions. Topics include setting and modifying file permissions with chmod, analyzing file permissions as shown by the ls -l command, and setting up default permissions with the unmask command. Permission is only half the puzzle, however, and you also learn about file ownership and group ownership, and how to change either any file or directory.

# Goals for This Hour

In this hour, you learn how to

+   - Understand file permissions settings
- Understand directory permissions settings
- Modify file and directory permissions with chmod
- Set new file permissions with chmod
- Establish default file and directory permissions with umask
