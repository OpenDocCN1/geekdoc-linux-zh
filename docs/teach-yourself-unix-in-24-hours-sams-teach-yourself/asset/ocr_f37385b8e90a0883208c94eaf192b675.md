Using :w results in this:

```
~~
~ "buckaroo" 8 lines, 271 characters~
```

2. Instead, try writing to a different file, using :newfile:

```
~~
~ :newfile~
```

When you press Return, you see this:

```
~~
"newfile" [New file] 8 lines, 271 characters~
```
