In the table, I use the simple shorthand notation introduced in Hour 7, "Looking into Files." UNIX users often use a caret followed by a character instead of the awkward Control-c notation. Therefore, ^f has the same meaning as Control-f. Expressing this operation as ^f not change the way it is performed; you'd still press and hold down the Control key and type f. # Task 11.5: Deleting Text

You have many of the pieces you need to work efficiently with the vi editor, zip to any point in the file, and add text where you'd like. Now you need to learn how delete characters, words, and lines.

The simplest form of the delete command is the x command, which functions as though you are writing an X over a letter you didn't want on a printed page: It deletes the character under the cursor. Type x five times, and you delete five characters. Deleting a line of this text can quite tedious, vi has some alternate commands. (Are you surprised?) One command that vi users don't know about is the d (for "delete the end of the line") command. Wherever you are on a line, if you type d, you will immediately delete everything after the cursor to that end of line text.
