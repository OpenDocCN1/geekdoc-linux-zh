## Task 10.1: The Wild and Weird awk Command

Although the sed command can be helpful for editing tasks in a pipeline, for real power, you need to invoke the awk program. The awk program is a programming kit for analyzing and manipulating text files that have words. It's one of the most helpful general purpose filters in UNIX.

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_197_0.png)

> Of course, you're wondering where awk got its name. The initial guess is that it refers to its awkward syntax, but that's not quite right. The name is derived from the last names of the authors: Aho, Weinberg, and Kernighan.

JUST A MINUTE

Similar to sed, awk can take commands directly, as arguments. You can also write programs to a file and have awk read the file for its instructions. The general approach to using the program is `awk { commands }`. There are two possible flags to awk: -f file specifies that the instructions should be read from the file rather than from the command line, and -Fc indicates that the program should consider the letter c as the separator between fields of information (for example, one or more space or tab characters), rather than the default of white space (for example, one or more space or tab).

4. With the password file, notice that the names are all in first-name-last name format. That is, my account is Dave Taylor. A common requirement that you might have to generate a report of system users. You'd like to sort them by name, but by last name. You do it with awk, of course:

```
% grep taylor /etc/passwd | awk -F: '{print $5}'
James Taylor,
Mary Taylor,
Dave Taylor,
James Taylor,
Robert Taylor,
Melanie Taylor,
Dave Taylor,
```

That generates the list of users. Now I'll use sed to remove those annoying commas and awk to reverse the order of names:

```
% grep taylor /etc/passwd | awk -F: '{print $5}' | sed 's/,//g'
| awk '{print $2","$1}'
Taylor, James
Taylor, Mary
Taylor, Dave
Taylor, James
Taylor, Robert
Taylor, Melanie
Taylor, Dave
```

If I could feed the output of this command to sort, the names will finally be listed in the order desired:

```
% grep taylor /etc/passwd | awk -F: '{print $5}' | sed 's/,//g'
| awk '{print $2","$1}' | sort
Taylor, Dave
Taylor, Dave
Taylor, James
Taylor, James
Taylor, Mary
Taylor, Melanie
Taylor, Dave
```

This is slick. It also illustrates how you can use various UNIX commands increasingly to build up your desired result.

5. The script earlier that looked for the login shell isn't quite correct. It turns out that if the user wants to have /bin/sh—the Bourne shell—as his or her default shell, the final field can be left blank:

This can be a problem because the blank field will confuse the awk program; awk is just counting fields in the line. The good news is that each line has an associated number of fields, known as the NF variable. Without used a dollar sign, it indicates how many fields are on a line: I'm interested in the last field in the /etc/passwd, the best approach for the preceding command would be:

```
% awk -F: '{print NF}'
```
