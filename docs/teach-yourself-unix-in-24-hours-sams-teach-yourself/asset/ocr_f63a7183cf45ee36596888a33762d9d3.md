Hour 22

Once you've found a group to read, it's time to choose from among the many possible packages. Perhaps the most popular is rn, or read news, written by Larry Wall. Another alternative, rn, offers a more screen-oriented view from Kim Storm, and a third possibility, patterned after the Elm Mail System, is tin, designed and written by Iain La.

![](bbox=[0.166, 0.233, 0.249, 0.296])

JUST A MINUTE

Of the many programs available for reading netnews, I prefer tin, because rn is so prevalent, I will use it in this hour. It nonetheless encourages you to use a local copy of tin if it's available. Remember also that you can use archie to find a local copy. (I talk about archie in the next hour.)

The rn program not only has options than you can shake a stick, at but it actually has more options than even a tree of sticks could cover! Table 22.2 lists a number of its particularly useful options.

# Table 22.2. The most useful starting options.

| Option | Meaning |
| --- | --- |
| -/ | Set SAVEH, so that articles you save are stored in a subdirectory of ~/News named after the group, with the name corresponding to its numeric identifier on the system. |
| -c | Check for news and indicate if any has arrived. |
| -e | Make each page of an article start at the top of the screen. |
| -hhdr | Suppress the header in news articles. |
| -L | Leave information on screen as long as possible. |
| -M | Force mailbox format for all saved files. |
| -m | Use inverse video for highlighted information. |
| -N | Force normal, non-mailbox format for all saved files. |
| -r | Restart within the last newsgroup read during the previous session. |
| -S | Use subject search mode when possible. |
