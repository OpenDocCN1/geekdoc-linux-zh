# Getting the Most Out of the C Shell

Here are a few examples of other C shell prompts and what happens when you use
them:

In / oh master: set prompt="\! % ""
(132) %

The ksh equivalent is PS1="\! % $ "

The number in parentheses is the command number, as used by the C shell history
mechanism:

+   (132) % echo hi
hi
(133) % Is News
mailing.lists.usen usenet.alt
(134) % hi
echo hi
hi
(135) %

Every time I log in, I automatically set the variable system to the name of the
Current computer:

(135) % set prompt="$system (cwd) \! % ""
imbo (136) %

I like to include in my prompt basename of the current directory, as shown in
the following example. Basename means the closest directory name, so the
basename of /user/taylor is taylor. Also, I replace the percent
s with a colon, which is a bit easier to read. There is a slight problem, however;
having a instead of % means that I have to remember it in C shell (or Korn
shell, as the case may be).

(136) % set prompt="$system (cwd) \! : ""
imbo (taylor) 137 :

+   4. Now I glance back at the aliases for prompt and cd, with all these things in
mind:

+   lim (taylor) 139 : alias cd
cdir ! : setprompt
imbo (taylor) 140 : alias setprompt
set prompt="$system (cwd) \! : ""
imbo (taylor) 141 :

You can see the setprompt alias defines the C shell prompt as $system
($cwd:t) ! : "", although the actual line in the .bashrc includes the backslash
(as expected):

+   lim (taylor) 141 : grep prompt=.shrc
alias setprompt
"set prompt="$system (cwd:t) \! : ""
imbo (taylor) 142 :
