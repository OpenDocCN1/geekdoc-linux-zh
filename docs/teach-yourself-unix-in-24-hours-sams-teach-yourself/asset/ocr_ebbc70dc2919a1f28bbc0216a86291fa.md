# Creating, Moving, Renaming, and Deleting Files and Directories

```
-rw---- 1 taylor 1178 Nov 5 12:38 cshrc.copy
-rw---- 1 taylor 1178 Nov 5 12:38 login.copy
```

Without bothering to rename it, UNIX copied the file cshrc.copy over the existing file login.copy. Notice that after the cp operation occurred, both files have same size and modification dates.

The mv command will cause the following problem:

```
% ls -l cshrc.copy login.copy
-rw---- 1 taylor 1178 Nov 5 12:42 cshrc.copy
-rw---- 1 taylor 1858 Nov 5 12:42 login.copy
% ls -l cshrc.copy login.copy
cshrc.copy not found
-rw---- 1 taylor 1178 Nov 5 12:42 login.copy
```

![](bbox=[0.118, 0.386, 0.203, 0.442])

> The good news is that you can set UNIX so it won't overwrite files. The bad news is that for many reasons systems don't default to this behavior. If your system is configured reasonably, when you try either of the two preceding examples, the system's response is to remove login.copy? You can press the Y key to replace the old file or Enter to change your mind. If your system cannot be set to respond this use the -i flag to both cp and mv to avoid this problem. Later, learn how to permanently fix this problem with a shell alias.

JUST A MINUTE

Together, mv and cp are the dynamic duo of UNIX file organization. commands enable you to put the information where you want it, leaving duplicates if desired.

# Task 6.4: Renaming Files by mv

SUMMARY

Both the DOS and Macintosh systems have easy ways to rename files. In DOS, you can use RENAME to accomplish the task. On the Mac, you can select the name icon and enter a new filename.

DESCRIPTION

![](bbox=[0.846, 0.686, 0.972, 0.767])

UNIX has neither option. To rename files, you use the mv command, which, in essence, moves the old name to the new name. It's a bit confusing, but it works.

ACTION

+   1. Rename the file cshrc.copy with your own first name. Here's an example:
% ls -l cshrc.copy
-rw---- 1 taylor 1178 Nov 5 13:00 cshrc.copy
% mv cshrc.copy dave
% ls -l dave
-rw---- 1 taylor 1178 Nov 5 13:00 dave
