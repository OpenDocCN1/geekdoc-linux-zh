# Key Terms

+   **bookmarks** A listing of favorite sites for quick retrieval.

+   **browser** A program designed to load hypertext pages and follow hyperlinks.

+   **hyperlinks** Specifications within a document that include instructions for loading a different document.

+   **surfing** A style of interacting with the World Wide Web, usually for pleasure, where you follow hyperlinks from Web site to Web site.
