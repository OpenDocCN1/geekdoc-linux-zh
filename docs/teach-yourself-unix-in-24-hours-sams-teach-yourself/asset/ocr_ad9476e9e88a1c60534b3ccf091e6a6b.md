# Task 20.4: Sending Mail with mailX

Now you know how to read your electronic mail using Berkeley (aka mailX), and you know how to send mail from the program. How do you send messages to people from the command line? It's quite simple. You can specify the message subject with the -s starting flag.

DESCRIPTION

ACTION

+   1. To send a message to someone, enter the name of the command, followed by the recipient's account name:

% mail mary
Subject: Interested in lunch tomorrow

I now can enter as many lines of information as I want, ending, within the Berkeley Mail program itself, with either ^ or :.

I'm going to be in town tomorrow and would like to
rustle some Chinese food. What's your schedule
look like?

Dave
Cc:

Again, I have the option of copying someone else, but—again—I opt not to do so. Pressing Return sends the message.

+   2. To send a file to someone, combine file redirection with the use of the -s flag:

% mail "here" the contents of sample.file mary < sample.file
The file was sent without any fuss.

+   3. Even though Berkeley Mail gives you no indication, several commands are available for while entering the text of a message, and all can be listed with -:

% mail dumpinfo
Subject: Good morning!
-?

The following escapes are defined:
Quote a single tilde
-b users Add users to "bind" cc list
-c users cc list
-d Read in dead.letter
-e Edit the message buffer
-h Prompt for list, subject and cc list
-m messages Read in messages, right shifted by a tab
-p Print the message buffer
-r file Read a file into the message buffer
-s subject Set subject
