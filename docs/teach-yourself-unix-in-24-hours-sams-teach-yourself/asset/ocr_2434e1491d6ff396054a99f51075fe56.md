absolute filename Any filename that begins with a leading slash (/); these always uniquely describe a single file in the file system.

access permission The set of accesses (read, write, execute) allowed for each of the three classes of users (owner, group, and everyone) for each file or directory on the system.

account name This is the official one-word name by which the UNIX system knows you: mine is taylor. (Also see account in Hour 1.)

account This is the official one-word name by which the UNIX system knows you. Mine is taylor.

addressing commands The set of vi commands that enable you to specify what type of object you want to work with. The commands serve as an example: dw means delete word, and de means delete previous word.

anonymous FTP A system to respond to ftp per queries that do not require you to have an account on the system.

arguments Not any type of domestic dispute, arguments are the set of options and filenames specified to UNIX commands. When you use a command such as vi.c, all words other than the command itself (vi) are arguments, or parameters to the program.

basename The closest directory name. For example, the basename of /usr/home/taylor is taylor.

binary A format that is intended for the computer to work with directly rather than for humans to peruse. See also executable.

bitwise operator An operator that works on the bits, without changing neighbor-bits.

bitwise shift Changing the location of the bits in memory.

blind carbon copy An exact copy of a message, without the awareness of the original recipient.

block device A device driver that controls block-oriented peripherals. A hard disk, for example, is a peripheral that works with reading and writing blocks of information (as distinguished from a character special device). See also character special device.

block At its most fundamental, a block is like a sheet of information in the virtual notebook that represents the disk: a disk is typically composed of tens, hundreds, or thousands of blocks of information, each 512 bytes in size. See also i-node to learn more about how disks are structured in UNIX.

bookmark A saved gopher menu item which you can easily build your own custom gopher information screens.
