+   4. To learn a simple snippet of information about a UNIX command, you can check to see if your system has the whatis utility. You can even ask it to describe itself (a bit of a philosophical conundrum):

% whatis whatis
- display a one-line summary about a keyword
whatis (1)
%

In fact, this is the line from the NAME section of the relevant map. The whatis command is different from the apropos because it considers only command names rather than all words in the command description line:

% whatis cd
cd (1)
- change working directory
%
