# Summary of vi Commands

A summary of the commands you learned in this hour is shown in Table 12.1.

| Command | Meaning |
|---|---|
| !command | Replace the current line with the output of the specified command. |
| )command | Replace the paragraph with the results of piping through. |
| ( | Move backward one sentence. |
| ) | Move forward one sentence. |
| c | Change text from the point of cursor until the end of line. |
| cw | Change the word, whereas ej changes the next paragraph. |
| e | Move to the end of word. |
| ^g | Show the line number and other information about the file. |
| R | Replace text from the point of cursor until Escape is pressed. |
| r | Replace the current character with the next. |
| ^ | Prevent vi from interpreting the next character. |
| { | Move backward one paragraph. |
| } | Move forward one paragraph. |
| :command | Invoke the specified command. |
| :ab | Define abbreviation phrase. |
| :ab | Show current abbreviations, if any. |
| :map | Map a key to a specific action. |
| :map | Show current key mappings, if any. |
| :s/old/new/ | Substitute new for the first instance of old on the current line. |
| :s/old/new/g | Substitute new for all occurrences of old on the current line. |
| :set nonumber | Turn off line numbering. |
| :set number | Turn on line numbering. |

# Key Terms

**escape sequence** An unprintable sequence of characters that usually specifies your terminal take a specific action, as clearing the screen.

**key mapping** A facility that enables you to map any key to a specific action.

**replace mode** A mode of vi in which any characters you replace those already in the file.

**shell script** A collection of shell commands in the file.
