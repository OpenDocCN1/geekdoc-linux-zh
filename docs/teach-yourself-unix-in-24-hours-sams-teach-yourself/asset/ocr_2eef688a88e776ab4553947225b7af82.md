# Table 23.1. continued

| Command | Meaning |
| dir | Print a listing of files in the current remote directory. |
| get | Transfer a file from the remote system to your local system. |
| lcd dir | Change the current directory on the local system to dir or your home directory if no argument is given. |
| ls | List the files in the current remote directory. |
| mget | Multiple get—get files with a wildcard matching capability. |
| mput | Multiple put—put files with a wildcard matching capability. |
| open | Open a connection to the specified remote machine. |
| prompt | Control whether or not to ask for confirmation of each file transfer if using mget or mput. |
| put | Put a file onto the remote system. |
| pwd | Show the present working directory on the remote. |

1. To start out, I want to pick up a file from netcom that I saw earlier when I used login to look at the remote system. To start ftp, I use the short notation of specifying the host at the command line:

```
% ftp netcom.com
Connected to netcom.com.
netcom FTP server (Version 2.1 Fri Apr 9 13:43 PDT 1996) ready.
Name (netcom:taylor): _
```

By default, ftp assumes I want to use the same account name, which in this case, if I press Enter, and then enter my password:

```
Name (netcom:taylor):
331 Password required for taylor.
Password:
230 User taylor logged in.
ftp> _
```

2. Now I am at the ftp program prompt, and all of the commands shown in Table 23.1 will work here. I use dir and ls to list my files in different formats:

