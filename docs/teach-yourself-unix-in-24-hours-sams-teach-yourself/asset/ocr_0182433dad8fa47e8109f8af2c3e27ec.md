JUST A MINUTE

To sort filenames alphabetically regardless of case, you can use sort -f:

```
% Is -s | sort -f
Archives/
bin/
bitnet.mailing-lists.Z
drop,text.hqx
InfoId/
keylime.pie
Mail/
News/
src/
temp/
testme
```

2. How about sorting the lines of a file? You can use the testme you created earlier:
