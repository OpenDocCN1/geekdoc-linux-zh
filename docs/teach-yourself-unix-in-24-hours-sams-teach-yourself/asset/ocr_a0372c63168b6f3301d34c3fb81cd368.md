All of these remained primarily text oriented. Sure, there is a standard, called MIME (multimedia Internet mail extension), for sending pictures, sounds, and other non-text files via e-mail and Netews, but its use is still rather restricted. Even so, MIME requires the translation of the images into a format of text that is again translated at the receiving end. There was a need for a method to transmit sound, images, movies, and other data via the Internet. These problems have been addressed in the World Wide Web.

Underneath the Web is a protocol called HTTP, for hyper-transfer protocol. This protocol allows for the transmission of non-text files for images, as well as text for pages. HTTP is the underpinnings of Web communications.

On the presentation level is a language called HTML, for hypertext markup language. This is an interpreted mark-up language that specifies layout and presentation of information. The file that you create will look like the file displayed. A markup language is one where the formatting instructions of a document are actually text that is interspersed (and visible) throughout the document, and you do not see the effects until the document is interpreted by a printer or browser. In WYSIWYG processors, such as Word, the formatting instructions are in the document, but you do not see them

Web browsers, however, go far beyond using HTTP. You can specify in HTML different links (special sections of a document that you can access other documents), using a fairly large number of protocols. Mail, Netews, FTP, Telnet, Gopher, and HTTP all are supported by most browsers. This tends to make the browser a universal tool for accessing the resources on the Internet.

# Task 21.1: Starting Your Browser

This section introduces you to the bases of Netscape Navigator. Navigator has command-line options, but the primary methods you learn here are for surfing the Net, starting at a specific site, or exploring your own local files.

Before you get started, you need to run the X Window System, which I refer to as "X" is the standard graphical interface for UNIX systems and usually be started with the command startx. On my system, you won't need to do that because once you log in, you are already running X. If you can move a mouse on UNIX systems, you have the X Window System installed.

If you can't run X, talk with your system administrator or your software provider. You'll be amazed how much better Netscape looks when you have a graphical interface to help out!

The next step is to enter the commands netscape at the shell prompt. This first brings up a license agreement, as shown in Figure 21.1 (if this is the first time you've run Navigator), or just up the main browser window. After a short period of time (long enough for you to read all the legal mumbo-jumbo), this window is replaced by the Netscape home page (see Figure 21.2).
