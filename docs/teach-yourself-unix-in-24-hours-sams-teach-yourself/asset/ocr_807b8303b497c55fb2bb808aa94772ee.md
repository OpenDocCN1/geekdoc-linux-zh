4. Another example of the file command's limitations is how it interacts with file permissions. Use cp to create a new file and work through this example to see your file command interprets the various changes.

```
% file test

% chmod +x test
% file test
test: shell script
```

Adding execute permission to this file caused it to behave as a shell script rather than shell commands.
