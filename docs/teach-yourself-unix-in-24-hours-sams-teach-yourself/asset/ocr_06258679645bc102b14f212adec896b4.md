# Ownership and Permissions

# Table 5.4. Permissions and numeric equivalents.

| Permissions String | Binary Equivalent | Decimal Equivalent |
| --- | --- | --- |
| --- | 000 | 0 |
| --x | 001 | 1 |
| -w- | 010 | 2 |
| -wx | 011 | 3 |
| r-- | 100 | 4 |
| r-x | 101 | 5 |
| rw- | 110 | 6 |
| rwx | 111 | 7 |

The value of having a single digit to describe any of the seven different permission states should be obvious. Using only three digits, you can now express any possible combination of permissions for any file or directory in UNIX—one for the owner permission, for one group, and for everyone else. Figure 5.7 shows how to take a permission string and translate it into its three-digit numeric equivalent.

# Figure 5.7.

Translating a full permissions string into its numeric equivalent.

![](bbox=[0.518, 0.537, 0.952, 0.663])

From this illustration, you can see how the permissions string rw------- (read and write permission for the owner, read permission for the group, and no access allowed for everyone else) is exactly equivalent to the numeric string 640.
