Using the -name option before the -print option can be very handy.

+   3. To find those files that have been modified in the last seven days, I can
   use -time with the argument -7 (include the hyphen):

% find -time 7 -name "*.c" -print
   ./OWL/owl.c
   ./OWL/simple.editor.c
   ./OWL/ask.c
   ./OWL/utils.c
   ./OWL/sendmail.c

If I use the number 7 (without a hyphen), I will match only those files that
were modified seven days ago:

+   % find -time 7 -name "*.c" -print
%
To find those C source files that I haven't touched for at least 30 days, I can use +30:
% find -time +30 -name "*.c" -print
   ./OWL/WordMap/msw-to-txt.c
   ./OWL/WordMap/newtest.c
   ./src/calc.c
   ./src/info.c
   ./src/fixit.c
   ./src/message.c
