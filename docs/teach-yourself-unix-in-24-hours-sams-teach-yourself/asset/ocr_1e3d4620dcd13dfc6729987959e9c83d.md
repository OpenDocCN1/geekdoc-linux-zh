# An Introduction to the Editor

6. In the middle of working on this, I suddenly realize that I need to make a slight
change to the recently saved buckaroo.confused file. That's where the ce command\comes in handy. Using it, I can edit any other file:

```
~
: buckaroo.confused_
```

I press Return and see this:
