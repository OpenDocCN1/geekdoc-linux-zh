
# Basic Shell Programming

The output here is just Joe is basically. The shell does not know how to differentiate between the variables `$learning` and `$learning`. Because there is no value assigned to `$learning`. To solve this problem, enclose the variable in curly braces.

```
$ echo Joe is basically ${learning}
Joe is basically anti-taxes
```

If learning is undefined, the output might not make sense. It would be Joe is basically taxes. Fortunately, the shell provides a mean to have a default value if a variable is undefined:

```
$ echo Joe is basically ${learning:-pro}
Joe is basically pro to taxes
```

If learning is undefined, the `:-` syntax tells the shell to use the following string, including the space character, leaving the output blank. This does not assign a value to the variable. If you need to use the variable repeatedly, you might want to assign a value to it, if it is undefined. The `:-` character does this:

```
$ echo Joe is basically ${learning:-pro} ${learning}spending.
Joe is basically pro taxes and pro spending.
```

The first interpretation of the variable finds it undefined, the shell assigns *pro to the variable and outputs. The second time the variable is interpreted, it has the value *pro*.

Variables are assigned by the `read` command. This assigns an individual word to a specified variable, with the last variable in the list assigned the remaining words.

```
$ read city state message
Morristown, New Jersey Hi Mom!
$ echo Scity is city
Morristown, is city
$ echo $state is state
New is state
$ echo $message is message
Jersey Hi Mom! is message
```

As you can see, only New is assigned to state. The best way around this is to escape the space with a backslash:

```
$ read city state message
Morristown, New Jersey Hi Mom!
$ echo Scity is city
Morristown, is city
$ echo $state is state
New is state
$ echo $message is message
Jersey Hi Mom! is message
```

This can be a bit tricky at first.

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_357_0.png)

The other way to assign variables is from command-line arguments. The shell has built-in variables to access the command line. If you've written a script to copy files and named it `copy-files`, you might want to list all the files on the command line:

```
$ copy-files file1 file2
```

The program would access these as `$1`, `$2`, and `$3`:

```
cp $1 destination
cp $2 destination
cp $3 destination
```

The `$ ` variable is a special case for looking at the command name, and `$*` lists all the command-line variables.

The standard data in any shell program is the variable. These variables can be assigned in several ways: directly assigned, read from user's typing or by the command line. The shell also provides means to perform some default manipulation of variables.

# Title 16.2: Shell Arithmetic

Although the shell treats variables as strings, there are methods to perform some basic arithmetic on shell variables. Again, the C and the Korn shell provide more extensive mathematical capabilities.

If a shell is assigned a numeric value, you can perform some basic arithmetic on the value using the command `expr`. This command takes several arguments to perform arithmetic:

```
$ expr 1 + 1
```

Arguments must be separated by spaces, and present, for the `expr` command to work. If a variable is undefined or does not have a value to it (sometimes called zero length), the result is a syntax error. Here is where the `:-` syntax is particularly helpful:

```
$ expr ${undefined}
expr: syntax error
$ expr ${undefined:-0} + 1
```

Normal defaults of 0 and 1 are useful. When adding 0 to a number, you get the same number. Similarly, multiplying or dividing by 1 also doesn't change the value of the number.

`expr` also supports subtraction, multiplication, integer division, and remainders. These are illustrated here:

```
$ expr 11 - 5
```

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_358_0.png)

# Basic Shell Programming

```
$ expr 11 *** 5
55
$ expr 11 / 5
2
$ expr 11 % 5
1
```

Note that I had to include the asterisk in single quotes. If I didn't do that, the shell would expand it to be the list of files in the current directory, and the `expr` program wouldn't understand that.

You can assign the results of the arithmetic to other variables by enclosing the command in backticks:

```
$ newvalue=$(expr ${oldvalue:-0} + 1
```

If `oldvalue` is assigned, it is incremented by 1. If `newvalue` is set to 1, this is useful when looping through data for a number of iterations.

The `expr` command can also work with complex arithmetic. You can write an expression to add two numbers and multiply them by a third. Normally, you would need to worry about operator precedence, but `expr` is not that sophisticated. Instead, you just group the operations in parentheses:

```
$ expr \( 11 + 5 \) \* 6
```

This adds 11 and 5, multiplies the result by 6. Because the parentheses are important shell characters, I need to escape them with backslashes.

> The `expr` is a very useful command for performing arithmetic in the Bourne shell. Strings must be numbers, or there will be errors, and the results of the `expr` command can be assigned to other variables.

The other way to assign variables is from command-line arguments. The shell has built-in variables to access the command line. If you've written a script to copy files and named it `copy-files`, you might want to list all the files on the command line:

```
$ copy-files file1 file2
```

The program would access these as $1, $2, and $3:

```
cp $1 destination
cp $2 destination
cp $3 destination
```

The $ $ variable is a special case for looking at the command name, and $* $ lists all the command-line variables.

The standard data in any shell program is the variable. These variables can be assigned in several ways: directly assigned, read from user's typing or by the command line. The shell also provides means to perform some default manipulation of variables.

# Title 16.2: Shell Arithmetic

Although the shell treats variables as strings, there are methods to perform some basic arithmetic on shell variables. Again, the C and the Korn shell provide more extensive mathematical capabilities.

If a shell is assigned a numeric value, you can perform some basic arithmetic on the value using the command `expr`. This command takes several arguments to perform arithmetic:

```
$ expr 1 + 1
```

Arguments must be separated by spaces, and present, for the `expr` command to work. If a variable is undefined or does not have a value to it (sometimes called zero length), the result is a syntax error. Here is where the `:-` syntax is particularly helpful:

```
$ expr ${undefined}
expr: syntax error
$ expr ${undefined:-0} + 1
```

Normal defaults of 0 and 1 are useful. When adding 0 to a number, you get the same number. Similarly, multiplying or dividing by 1 also doesn't change the value of the number.

`expr` also supports subtraction, multiplication, integer division, and remainders. These are illustrated here:

```
$ expr 11 - 5
```

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_358_0.png)

# Basic Shell Programming

```
$ expr 11 *** 5
55
$ expr 11 / 5
2
$ expr 11 % 5
1
```

Note that I had to include the asterisk in single quotes. If I didn't do that, the shell would expand it to be the list of files in the current directory, and the `expr` program wouldn't understand that.

You can assign the results of the arithmetic to other variables by enclosing the command in backticks:

```
$ newvalue=$(expr ${oldvalue:-0} + 1
```

If `oldvalue` is assigned, it is incremented by 1. If `newvalue` is set to 1, this is useful when looping through data for a number of iterations.

The `expr` command can also work with complex arithmetic. You can write an expression to add two numbers and multiply them by a third. Normally, you would need to worry about operator precedence, but `expr` is not that sophisticated. Instead, you just group the operations in parentheses:

```
$ expr \( 11 + 5 \) \* 6
```

This adds 11 and 5, multiplies the result by 6. Because the parentheses are important shell characters, I need to escape them with backslashes.

> The `expr` is a very useful command for performing arithmetic in the Bourne shell. Strings must be numbers, or there will be errors, and the results of the `expr` command can be assigned to other variables.
