# Task 5.7: Identify Owner and Group for Any File or Directory

### DESCRIPTION One of the items of information that the ls command displays when used with
-l flag is the owner of the file or directory. So far, all files and directories in
your home directory have been owned by you, with the probable exception of the ".."
directory, which is owned by whoever owns the directory over your home.

In other words, when you enter `ls -l`, you should see your account name as the owner for
every file in the list.

If you're collaborating with another user, there might be times when you'll
want to change the owner of a file or directory once you've created or modified it. The first
step in accomplishing this is to identify the owner and group.

Identifying the owner is easy; ls lists by default. But how do you identify the group of
which file or directory is a part?

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_118_1.png)

- 1. The ls command can show the group membership of any file or directory by the
addition of a new command flag, -g. By itself, -g doesn't alter the output of ls, but
when used with the -l flag, it adds a column of information to the listing. Try it with an example:

```
% ls -l /tmp
-rw-r---- root root
drwxr-xr-x root snakes 512 Oct 12 14:52/shakes/
drwxr-xr-x root memend con435 0 Oct 12 14:46 snd.12
-rw-r--r dessy stupracs 1191 Oct 12 14:57 snd.15
-rw-r--r steen utech 1 Oct 12 10:28 snd.17
-rw-r--r jsmith utech 258908 Oct 12 12:37 sol2
```

Both owners and groups vary for each of the files and directories in this small listing. Notice that files can have different owners while having the same group. (There are two examples here: sh145 and the shakes directory, and snd.17 and sol12.)

# Task 5.8: Change the Owner of a File or Directory

### DESCRIPTION

Now that you can ascertain the ownership of a file or directory, it's time to learn about the chown command. This command lets you change the ownership of whatever you specify.

# CAUTION

> Before you go any further, however, a stern warning: once you've changed the ownership of a file, you cannot restore it to yourself. The owner of a file can give away its ownership, so don't use the chown command unless you're absolutely positive you want to!

# ACTION

- 1. The format for changing the ownership of a file is to specify the new owner and list the files or directory you are giving away:

```
% ls -l test
-rw-rw-rw- 1 taylor 0 Oct 12 15:17 mytest
% chown root test
% ls -l test
-rw-r--r-- 1 root 0 Oct 12 15:17 mytest
```

This would change the ownership of the file test from me to the user root on the system.

# Ownership and Permissions

- 2. If I now try to change the ownership back, it fails:

```
% chown taylor test
chown: test: Not owner
```

Most modern UNIX systems prevent users from changing the ownership of a file due to the inherent dangers. If you try to chown, and it returns Command not found or Permission denied, that means you are barred from making any file ownership changes.

- 3. On of the systems I use, chown always reports Not owner when I try to change a file regardless of whether I am the owner or not:

```
% ls -l mytest
-rwxrwxrwx 1 taylor      0 Oct 12 15:17 mytest
% chown root mytest Not owner
```

This is needlessly confusing—a message like "you’re not allowed to change file ownership" would be better. But, alas, like so of UNIX, it's up to the user to figure out what's going on.

To change the ownership of a file or directory, you can use the chown command to have the appropriate access on your system. It's a huge superantanker, though: you cannot change order once underway, so be cautious!

# Task 5.9: Change the Group of a File or Directory

Changing the membership of a file or directory is quite analogous to the steps required for file ownership. Almost all UNIX systems enable users to use the chgrp command to accomplish this task.

- 1. Usage of chgrp is almost identical to chown, too. Specify the name of the group, followed by the list of files or directories to reassign:

```
% ls -lg
-rwxrwxrwx 1 taylor ci      0 Oct 12 15:17 mytest
% chgrp ftp mytest
% ls -lg
-rwxrwxrwx 1 taylor ftp      0 Oct 12 15:17 mytest
```
