Also notice that the shell always keeps an alphabetically sorted list of aliases, regardless of the order in which they were defined. For example, the first alias, diff, ensures that the command diff always has the default flags -c and -w. If you enter from, the system to invoke frm -n; if you enter 11, I want the system to invoke ls -l, and so on.

Some commands can cause trouble if, creating an alias for each of those commands is a good way to stay out of trouble. For example, I have an alias for newaliases; if I accidentally enter that command, the system gently reminds me that I probably meant to use the newalias command:

```
% newaliases
you mean newalias ...
```
