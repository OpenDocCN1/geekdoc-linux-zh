Almost all commands in vi can work with a numeric repeat prefix, even commands that you might not expect to work, such as the i insert command. Remember that a request can be accomplished in many ways. To delete five files, for example, you can use 5dw or d5w. Experiment on your own, and you'll get the idea.

# Task 12.3: Numbering Lines in the File

It's very helpful to have an editor that works with the entire screen, sometimes you need to know only which line you're currently on. Further, sometimes it is very helpful to have all the lines numbered on the screen. With vi, you can do both of these—the former by pressing ^ (remember, that is Control-g) while in command mode, and the latter by using a complex colon command, :set number, followed by Return. To turn off the display of line numbers, simply type :set number and press Return.
