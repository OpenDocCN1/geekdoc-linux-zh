
2. 更好的方法是在流的中间截取信息的副本：

```
% ls -l | awk '{ print $5 "t" $9 }' | sort -rn | tee bigfiles | head
12556 keyline.pie
8729 owl.c
1024 Mail/
582 tetme
512 temp/
```

这在屏幕上只显示了最大的五个文件，但 `bigfiles` 实际上包含了一个按大小排序的所有文件列表：

```
% cat bigfiles
12556 keyline.pie
8729 owl.c
1024 Mail/
582 tetme
512 temp/
512 src/
512 bin/
512 Oil/
512 News/
512 Infolder/
512 Archives/
207 sample
199 sample
126 awkscript
```

如前所述，`tee` 命令是一个经典的 UNIX 实用程序，看起来很有用，但用途有些有限。然而，当你通过书中的所有示例进行学习时，你会发现，许多强大的命令正是由大量的命令组合而成的。
