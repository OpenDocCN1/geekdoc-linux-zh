5. As you can see, many accounts contain the taylor.

A smarter way to see how often the taylor pattern appears is use the -c flag to grep, which will indicate how many case-sensitive matches are in the file before they are displayed on the screen:

```
% grep -c taylor /etc/passwd
```

The command located seven matches. Count the listing in instruction 4 to confirm this.

This is a great example of a default separator adding incredible confusion to the output of the command. Normally, a line number followed by a colon would be no problem, but in the password file (which is already littered with colons), it's confusing.
