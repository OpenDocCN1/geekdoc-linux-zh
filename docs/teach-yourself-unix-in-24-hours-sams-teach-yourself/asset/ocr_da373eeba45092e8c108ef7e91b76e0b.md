# ACTION

1. Try this yourself. List /usr on your system:

```
% Is -F /usr
5bin/      diag/      share/    ucbinclude@
5include/  dict/      lib/      source/    ucblib@
5lib/       etc/      local/    spool/    xpg2bin/
acc/       export/  last-found/ src       xpg2include/
acctlog*   games/    man@      stand/    xpg2lib/
adm/       hosts/    mde0      sys/
bin/       include/  old/       system/
boot/      kvm/       sccs/      ucb/
```

You probably have different files and directories listed in your /usr directory. Remember, @ files are symbolic links in the listing,

+   2. You can specify more than one directory:
% Is :/usr/local/home/taylor
/home/taylor:Global.Software Mail/ Src      history.usenet.Z
Interactive.Unix News/bin/
/usr/local/:emacs/      ftp/
admin/  emacs-18.59  gnubin/
bin/      include/    netcom/
cat/      info/       policy/
doc/      forms/      lib/       src       tmp/

In this example, the command sorted the directories before listing them. I specified that I wanted to see /usr/local and then /home/taylor, but it presented the directories in opposite order.

> I've never been able to figure out how ls sorts when you ask for more than one to be listed—it's not an alphabetical listing. Consider if you must have the output in a specific order, you can use the ls command in a row.
