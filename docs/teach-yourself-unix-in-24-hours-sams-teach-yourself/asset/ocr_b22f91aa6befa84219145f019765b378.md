2. If you are coming from the DOS, you might have found some of the UNIX file commands confusing. In DOS, for example, you use DIR to list directories, COPY to copy them, and so. With aliases, you can recreate those commands, mapping them to specific UNIX equivalents:

+   - % alias DIR '-IF'
- % alias REN 'mv'
- % alias COPY 'cp -i'
- % alias DEL 'rm -i'
- % DIR
