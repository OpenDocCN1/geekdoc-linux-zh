On System V machine, you could also create the alias Ias Ipr *Ip*, though none of these particular options are available with Ip.

If you find yourself printing to a couple of different printers quite often, you can easily define a few shell aliases to create printer-specific commands:

  - alias mathprint -Ipr -Paitle
  - alias libprint -Ipr -PLibrary
  - alias ediprint -Ipr -Pedlw

On System V machines, the name would be this:

  - alias mathprint -Ip -mathlw
  - alias libprint -Ip -dllibrary
  - alias ediprint -Ip -Iedlw

# Task 18.3: Formatting Print Jobs with pr

The Printer it generated looked good, but I would like to have a running header on each page that shows the name of the file and the page number. I'd also like to have a bit more control over some other formatting characteristics. This is exactly where the pr command comes in handy. Not intended for printing, pr is a general pagination and formatting command that can be used to display information on the screen. Ever better, pr is available on BSD and System V UNIX.

The program is loaded with options, which are quite useful at times. For example, -2 makes the output two columns, which is useful for printing results of the who command landscape mode! The most useful options are presented in Table 18.3.

# Table 18.3. Useful flags in pr.

| Flag | Meaning |
| --- | --- |
| -n | Produce n-column output per page. |
| +n | Begin printing on the nth page. |
| -f | Don't print the page header and footer information. |
| -hhdr | Use hdr as the head of each page. |
| -wn | Set the page width to n characters (for landscape mode). |
| -m | Print all files at once, per column. |

![](img/f32f6f53c129de2ebafcd2b4ff01b1c9_396_0.png)

On some UNIX systems, the -f flag to pr causes the program to form feeds at the bottom of each printed page. To suppress the header and footer, use -t.
