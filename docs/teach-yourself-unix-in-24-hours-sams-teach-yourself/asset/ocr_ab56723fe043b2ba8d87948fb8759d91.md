+   1. I've decided development psychology is my bag. Now, instead of this Banzai character, I want my fictional character to be called Bandura. I could use the previous command to change the occurrence on the current line, but I really want to change all occurrences within the file.

This is no problem. I type :1,$ s/Banzai/Bandura/ and press return. Here's the result:
