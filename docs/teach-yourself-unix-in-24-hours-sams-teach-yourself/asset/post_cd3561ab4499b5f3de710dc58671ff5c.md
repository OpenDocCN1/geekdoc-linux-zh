
UNIX has offered a similar feature for many years, which in UNIX jargon is called a symbolic link. A symbolic link, such as bin in Table 4.1, contains the name of another file or directory rather than contents of its. If you could peek inside, it might look like bin = @usr/bin. Every time someone tries to look at bin, the system shows the contents of /usr/bin instead.

You'll learn more about symbolic links and how they help you organize your files a bit later in the book. For now, remember that if you see an @ filename, it's a link to another spot in the file system.

- A flag for ls (one that might not be available in your version of UNIX) is the -m flag which outputs files as a comma-separated list. If there are many files, -m can be a quick and easy way to see what's available.

```
% ls -m
```

Sometime you might want to list each of your files on a separate line, perhaps for a printout you want to annotate. You've seen that the -c flag forces recalcitrant versions of ls to output in multiple columns. Unfortunately, the opposite behavior isn't obtained using a lowercase c. (UNIX should be so consistent!) Instead, use the -1 flag to indicate that you have one column of output. Try it.

2. There are ways to sort files in ls. If you want to sort by most-recently accessed to least-recently-accessed, use the -t flag:

```
% ls -a ../cshrc
.newsrc News/ .sig
.oldnewsrc .tin/ .rnsoft plan
.article .ironmot .plan Mail/
.elm/ .degroups Interactive.Unix
../forward .login .accinfo* .Pnews.header

.tin Global.Software
.bin bin Global.Software .logout

```

From this output, you can see that the most recently accessed files are .newsrc and .oldnewsrc, and it's been quite a while .logout was touched. Using the -t flag on them to see which files you've accessed and which you haven't.

3. So, you know three different approaches to sorting files within the ls command: column-first order, first-order, and most-recently-accessed order. There are more options in ls than just these three; the -r flag reverses any order.

```
% ls -r Mail/ Src/
Global.Software News/ historyusenet.Z
Interactive.Unix bin/
% ls -r Global.Software
```
