# Moving About in the File System

**directory separator character** On a hierarchical file system, there must be way to specify items which are directories and which is the actual filename itself. This becomes particularly true when you're working with absolute filenames. In UNIX, the directory separator is the slash (/), so a filename /tmp/testme is easily interpreted as a file called teste in a directory called tmp.

**dot** A shorthand for the current directory.

**dot-dot** A shorthand for the directory one level higher in the hierarchical file system from the current location.

**dot file** A configuration file used by one or more programs. These files are dot files because the first letter of the filename is a dot, as in .profile or .login. Because they're dot files, the **ls** command doesn't list them by default, making them also hidden files in UNIX. See hidden file.

**dynamic linking** Most UNIX systems require all necessary utilities and library routines (as the routines for reading information from the keyboard and displaying it to the screen) to be plugged into a program when it's built (known in UNIX parlance as static linking)

**executable** A file that has been set up so UNIX can run it as a program. This is also shorthand for a binary file. You sometimes see the phrase **binary executable**, which is the same thing! See also **binary**.

**hidden file** By default, the UNIX file-listing shows only those whose first isn't a dot (that is, those that aren't dot files). All dot files, therefore, are hidden files, and you can safely ignore them without any problems. Later, you learn how to view these hidden files. See also **dot file**.

**hidden directory** This is your private directory, and is where you start out when log to the system.

**kernel** The underlying core of the UNIX operating system it is. This is akin to the concrete foundation under a modern skyscraper.

**preference file** These are what dot files (hidden files) are a filename exact exact meaning depending on where you are in the file system. For example, the file **test** might exist in both your home directory and the root directory; /test is an absolute filename and leaves no question which version is used, but **test** could refer to either copy, depending on your current directory.
