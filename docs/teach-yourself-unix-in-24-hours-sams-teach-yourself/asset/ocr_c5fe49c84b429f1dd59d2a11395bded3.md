# # Task 8.1: The Secrets of File Redirection

So far, all the commands you've learned while teaching UNIX require you to enter information at the command line, and all have produced output on the screen. As Gershwin wrote in Porgy and Bess, "it ain't necessarily so." In fact, one of the most powerful features of UNIX is that the input can come from a file as easily as it can be saved to the keyboard, and the output can be displayed on your screen.

The secret is file redirection, the special commands in UNIX instruct the computer to read from a file, write to a file, or append information to an existing file. Each of these acts can be accomplished by placing a file-redirection command in a regular command line: < input, redirects output, and >> redirects output and appends the information to the file. An mnemonic for remembering which is which to remember that, as in English, UNIX works from left to right, a character that points to the left (<) changes the input, whereas a character that points right (>) changes the output.

+   1. Log in to your account and create an empty file using the touch command:
2. First, use this empty file to learn to redirect output. Use ls to list the files in your directory, saving them all to the newly created file:

```
% touch testme
% ls -l
-rw-r--r-- 1 taylor 0 Nov 15 09:11 testme
% ls -l > testme
% ls -l
-rw-r--r-- 1 taylor 120 Nov 15 09:12 testme
```

Notice that when you redirected the output, nothing was displayed on the screen; but there was no visual confirmation that it was. But it did, as you can see by the increased size of the new file.

Instead of using cat or more to view this file, using file redirection:

```
% cat testme
total 127
drwx------ 2 taylor 512 Nov 6 14:20 Archives/
drwx------ 3 taylor 512 Nov 16 21:55 Infolder/
drwx------ 1024 Oct 19 14:14 Mail/
drwx------ 2 taylor 512 Oct 6 09:36 News/
```
