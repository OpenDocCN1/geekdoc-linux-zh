# Summary

A judiciously defined aliases can save you a lot of frustration down the road. Choose your favorite printer, define the PRINTER environment variable to print to that printer, and give yourself an alias print to include all the default options you like for printouts. You might consider using an alias pq to show your print requests queued for your favorite printer. (This is easy to do). Use alias pq 'lpq $LOGNAME*' or alias pq 'lpstat -u $LOGNAME*'). You could show only your print requests, if any, by tucking a grep into the command: alias pq 'lpq | grep $LOGNAME'.
