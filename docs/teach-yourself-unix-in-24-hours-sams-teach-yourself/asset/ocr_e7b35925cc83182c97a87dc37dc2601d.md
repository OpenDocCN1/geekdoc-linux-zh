# An Introduction to the vi Editor

Before you start vi for the first time, you must learn about two aspects of its behavior. The first is that vi is a modal editor. A mode is like an environment. Different modes in vi interpret the same key differently. For example, if you're in insert mode, typing adds a to the text, whereas in command mode, typing puts a in insert mode; a is the key abbreviation for the append command. If you get confused about what mode you're in, press the Escape key on your keyboard. Press Escape always returns you to the command mode (and if you're already in command mode, it simply beeps to remind you of that fact).

When you are in command mode, you can manage your document; this includes the capability to change text, rearrange, and delete it. Insert mode is when you are adding text directly into your document from the keyboard.

The second important characteristic of vi is that it's a screen-oriented program. It must know what kind of terminal, computer, or system you are working with UNIX. This probably won't be a problem for you because most systems are set up that the default terminal type matches the terminal or communications program you're using. In this hour, you learn how to recognize when vi figure out what terminal you're using and what to do about it.

You can start vi in a number of different ways, and you learn lots of helpful alternatives later this hour. Right now, you learn the basics. The vi command, by itself, starts the editor, ready for you to create a new file. The vi command with a filename starts vi with the specified file so you can modify that file immediately.
