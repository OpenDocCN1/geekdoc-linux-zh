# Programming in C UNIX

The third type of variable is a floating-point variable. This is how you would include fractional, or irrational numbers. If you needed to list a radio station frequency, such as for 88.5 KQED, it would need a floating-point number. Results of uneven division can use floating point. The type of a real number is float.

One weakness of floating point is rounding. Floating-point numbers have a limited precision, the end result will be a slow, gradual rounding error. If you perform calculations, this rounding error can grow to be significant.

A lot of math can be performed by integers. Programs that handle money often use integers for the total number of cents, because this eliminates rounding error. Answers then are presented as cents divided by 100 (dollars) and the remainder (cents).

These basic variables can be further modified. Integers are modified with the adjectives long and short. A long integer may use eight bytes and is architecture dependent. On an eight-byte system, the range is -9223372036854775808 to 9223372036854775807. If you were to spell out that long number, it would be nine quintillion, two hundred and twenty-three quadrillion, three hundred and seventy-two trillion, thirty-six fifty-four million, seven hundred and seventy-five thousand, eight hundred and seven. A formidable sum in any language.

A short integer is usually half the size of a regular integer but is also machine dependent. Your machine has two-byte short integers, the range is -32768 to 32767.

The next pair of modifiers is signed and unsigned. Signed is usually assumed; so unsigned is the important modifier.

Normally, an integer is considered to have a sign, so of the 32 bits available, one, usually the first bit of the 32, acts as a sign flag. If the first bit is set to 1, you take the complement of the number and treat it as the negative number of some absolute value.
