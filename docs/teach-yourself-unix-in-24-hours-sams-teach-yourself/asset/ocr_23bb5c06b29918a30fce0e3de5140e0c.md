+   5. It's time for a real-life example. You've learned UNIX, and your colleagues now consider you an expert. One afternoon, Shala tells you about a file in her directory, but she isn't sure what it. She wants to know what it is, but she can't figure out how to get to it. You use the file command, and UNIX tells you the file data. You are bit puzzled. But then you remember file redirection:

```
cat -v < mystery.file visible.mystery.file
```

This command has cat -v take its input from the file mystery.file and save its output in mystery.file. All the nonprinting characters are transformed, and Shala can poke through the file at her leisure.
