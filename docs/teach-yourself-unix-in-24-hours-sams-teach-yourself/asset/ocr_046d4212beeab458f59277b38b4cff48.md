# Entering Commands in the more Program

In this title and in the following text, the word space enclosed in brackets [Space] refers to the spacebar as a command. Likewise, [Return] means you should press the Return key as part of the command.

A hyphen in a command—for example Ctrl-—means that you should hold the first kind indicated when you press the second key. The lowercase-letter commands in the table indicate that you should press the corresponding key, the A key for a command, example:

Two characters together, but without a hyphen -(:f), mean that you should press the appropriate keys in sequence when you were typing text.

Finally, entries that have an or before the command mean you can prefix the command with a number, which will let it value to modify its action. For example, 3[Return] displays the next three lines of the file and 20s skips the next 250 lines. Typically, pressing Return after typing a command which is not necessary.
