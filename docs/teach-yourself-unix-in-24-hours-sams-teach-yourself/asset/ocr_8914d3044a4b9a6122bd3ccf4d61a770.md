# Table 17.2. Possible process status values.

| Value | Meaning |
| R | Running |
| S | Sleeping (20 seconds or less) |
| I | Idle (sleeping more than 20 seconds) |
| T | Stopped |
| Z | Zombie process |

There are other process states, but they rarely show up for most users. A zombie
process is one that has ended but hasn't freed up its resources. It takes a
second or two for the system to completely recover all memory by a program.
Sometimes, zombies are stuck in the process table for one reason or other. UNIX
 refer to them as a defunct process, which stays around until the system
rebooked. Sometimes it's called <defunct> in process listings. Any process that is
ceded by a sleep command is not sleeping.
