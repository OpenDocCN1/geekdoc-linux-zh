# Listing Files and Managing Disk Usage

% touch iecc.list
% Is -t
iecc.list RUMORS,18Sept News/OWL/ src/
mailing.lists LISTS bin/ Mail/
Cancelled..mail newlists Infoworld/ Archives/

You probably will not touch command on a file that doesn't exist, the program creates the:

+   % Is
Archives/Cancelled..mail Infoworld/
% touch new.file
% Is
Archives/Cancelled..mail Infoworld/
% -l new.file
 -l new.file
-rw---
LISTS Mail/ News/OWL RUMORS,18Sept bin/ iecc.list src/
mailing.lists newlists newlists src/
0 10 16:28 new.file

The new file has zero bytes, as can be seen by the -i output. Notice that by default files are created with read and write permission for the user and anyone in the user's group. You learn in another hour how to determine, by using the umask command, your own default permission for files.

SUMMARY You won't touch very often, but it's valuable to know.

# Task 4.10: Check Disk-Space Usage with du

DESCRIPTION One advantage that the DOS and Macintosh systems have over UNIX is easy to find out how disk space you are using and how much remains available. On a Macintosh, viewing folders by size shows disk space, and the top-right corner of any Finder window shows available space. In DOS it's even easier; both items are listed at the end of the output of a du command:

```
C>DIR _BAT
Volume in drive C is MS-DOS_5
Volume Serial Number is 197A-A8D7
Directory of C:
AUTOEXEC _BAT         142 02-28-93 8:19pm
CSH      BAT            36 12-22-92 3:01pm
               2 file(s)      178 bytes
5120000 bytes free
```

In this example, you can see that the files listed up 178 bytes, and that there are 5,120,000 bytes (about 5 megabytes, or 5 MB) on the hard drive.

Like a close-mouthed informant, UNIX never volunteers any information, so you need to learn two new commands. The du, disk usage, command is used to find out how much disk space is used; the df, free, command is used to find out how much space is available.
