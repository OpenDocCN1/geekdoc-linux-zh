# Printing in the UNIX Environment

The pr command can be used to ensure that your printouts are always clean and readable. Again, it's a perfect place to create an alias: alias 'pr' | 'lpr' or alias 'pr' | 'lprq'. Even without any flags, pr automatically adds page numbers to the top of each page.

## Section 18.4: Working with the Print Queue

On a personal system, you might be helped by having your printer directly connected to your system, so anything you print using PRT (on DOS) or File|Print (on Mac) instantly prints. Unfortunately, UNIX doesn't have the luxury of your own personal printer. Instead, it handles print requests in a print queue, a managed list of files to print. When you send a file to printer, it is added to a queue of files waiting to print. Your request goes to the bottom of the list, and any subsequent print requests are added below. Your print request gradually moves up to the top of the list and prints, without interrupting the print requests of those ahead of you.

Sometimes it can be frustrating to wait for a printout. However, there are some advantages to using a queuing system over simply allowing users to share a single printer. The greatest is that you can use the lpr command to change your mind and remove print requests from the queue before they waste paper. The pr command works with the print job name, which you can learn by checking the print queue, using ipq. Both lpr and ipq can either use the DEFAULT setting or can have printers specified with -Pprinter. The ipq command can also limit output by adding your account name to the command.

If your system doesn't have lpr, use the cancel command to remove entries from the print queue. The ipstat command is the System V replacement for the ipq command, though many sites alias ipq = ipstat to make life a bit easier.

To cancel, you need to specify the name of the printer and the job ID, as shown in the ipstat output. If I had right request 37 on printer hardcopy, I could cancel the print request with the command cancel -37.

# Summary

A judicious defined aliases can save you a lot of frustration down the road. Choose your favorite printer, define the PRINTER environment variable to print to that printer, and give yourself an alias print to include all the default options you like for printouts. You might consider using an alias pq to show your print requests queued for your favorite printer. (This is easy to do). Use alias pq 'lpq $LOGNAME*' or alias pq 'lpstat -u $LOGNAME*'). You could show only your print requests, if any, by tucking a grep into the command: alias pq 'lpq | grep $LOGNAME'.
