JUST A MINUTE

| A kilobyte is 1.024 bytes of information, a byte being a single character. The preceding paragraph, for example, contains slightly more than 400 characters. UNIX works in blocks of information, which depending on which version of UNIX you're using, is either 1 kilobyte or 512 bytes. Most UNIX systems now work with a 1 kilobyte block |

3. Here is a further definition of what occurs when you use the - flag: ls indicates the number of blocks each file or directory occupies. You can then use simple calculations to convert blocks into bytes. For example, the ls command that the LISTS file in my home directory occupies 108 blocks. A quick calculation of block size multiplied by the number of blocks reveals the actual file size, in bytes, as shown here:

```
% bc
1024 * 108
110592
quit
%
```

Based on these results of the be command, you can see that the file is 110,592 bytes in size. You can estimate size by multiplying the number of blocks by 1,000. Be aware, that, in large files, the difference between 1,000 and 1,024 is significant enough to introduce an error into your calculation. As an example, I have a file that is three megabytes in size (a megabyte is 1,024 kilobytes, which is 1,024 bytes, or 1,024*1,024, or 1,048,576 bytes):

```
% ls -s bigfile
3648 bigfile
```

4. The file actually occupies 3,727,360 bytes. If I estimated its size by multiplying the number of blocks by 1,000 (which equals 3,648,000 bytes), I'd have underestimated its size by 79,360 bytes. (Remember, blocks × 1,000 is an easy estimate!)
