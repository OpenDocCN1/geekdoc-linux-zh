This can be very useful for computing the sum of a series of numbers. For example, I'd like to know the total number of bytes I'm using for all my files:

```
% Is -l | awk '{print $5}'
512
512
1024
512
512
512
12556
11503
512
512
582
```

That generates the list of file sizes, but how do I sum them up? One new variable totalize and output its accumulated value after each line:

```
% Is -l | awk '{ totalize = totalize + $5; print totalize }'\n512
1024
2048
2560
3072
3584
16140
27643
28155
28667
29249
```

One cleanup is to learn that += is a shorthand notation for "add the following value to the variable":

```
% Is -l | awk '{ totalize += $5; print totalize }'\n512
1024
2048
2560
3072
3584
16140
27643
28155
28667
29249
```

I can use tail to get the last line only, of course, and figure out the total size that way:

```
% Is -l | awk '{ totalize += $5; print totalize }' | tail -1\n29249
```

A better way, however, is to use the END programming block in the awk program:

```
% Is -l | awk '{ totalize += $4 } END { print totalize }'\n29249
```
