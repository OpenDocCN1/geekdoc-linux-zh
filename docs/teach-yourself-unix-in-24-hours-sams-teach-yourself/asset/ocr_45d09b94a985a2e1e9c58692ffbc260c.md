# Listing Files and Managing Disk Usage

# ACTION

+   1. Combining flags in UNIX is easy. All you have to do is run them together in a sequence of characters, and prefix the whole thing with a dash:

```
% ls -aF
-/ .gopherc .oldnewsrc -sig
-/ RUMORS.18Sept .plan Archives/
-/ .history*
-/ /bin/ .info .newsexpert InfoWorld/
-/ lecc.list .letter report LISTS
-/ aconfogric -mailing.lists
-/ article .login -rm-timestamp Mail/
-/ news
-/ cshrc -rlast News/
-/ src/
-/ .elm/ .rnsoft OWL/
```

+   2. Sometimes it's more convenient to keep all the flags separate. This is fine, as long as each flag is prefixed by its dash:

```
% ls -F
total 403
1 Archives/ 1 Mail/ 5 RUMORS.18Sept 280 mailing.lists
1 InfoWorld/ 1 News/ 2 bin/ 2 news
108 LISTS 1 OWL/ 4 lecc.list 1 src/
```

+   3. Try of these combinations on your own computer. Also try to list a flag more than once (for example, ls -ss -s), or list flags in different orders.

# SUMMARY

Very few UNIX commands care about the order in which flags are listed. Because it's the presence or absence of a flag that's important, listing a flag more than once doesn't make any difference.
