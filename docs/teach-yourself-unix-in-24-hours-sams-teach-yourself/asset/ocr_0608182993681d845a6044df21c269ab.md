The national convention for the From: line in electronic mail clearly varies. There are three basic notations you see in this line: an address, such as the one from gopher@scorpio.kent.edu; an address with the name in parentheses, such as the message from Linda Wei halfway down the list; and a line with the person's name followed by his or her e-mail address in brackets, such as the first listed line.

Notice the various sites from which I've received electronic mail in the past few days: SFSU.edu is San Francisco State University, oracle.com is Oracle Corporation in California, PURD.edu is Purdue University, CompuServer.Com is InfoWorld magazine's Macintosh network running cc:Mail, xalt.com is XALT Corporation, and kent.edu is Kent State University. The message from v892127@nootebook.si..hhs_nl is from an educational institution in The Netherlands!
