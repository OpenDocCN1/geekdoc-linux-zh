# Programming in C for UNIX

a piece of memory the size of an integer is allocated for you to use. In the program, this piece of memory is tracked with the name *i*.

Suppose, though, you want to know the address of that piece of memory. You can take it with the unary & & operator. The value assigned must be a pointer:

```
int i;
int *pointerint;
```

The asterisk indicates that the variable pointerint is not an integer, but an address of an integer. Later, you can assign the address of i with:

```
pointerint= &i;
```

You then access that value with (*pointerint).

This is particularly useful in functions. When you call a function, the arguments you pass to the function remain intact, even after you execute the function. This is called "call by value." So, if you had a function swap and passed it a and b, you'd see this:

```
void swap(int a, int b)
{
int c;
c=a;
a=b;
b=c;
return;
}

main()
{
int a,b;
a=4;
b=2;
printf("%%d %%d\n",a,b);
swap(a,b);
printf("%%d %%d\n",a,b);
}
```

Here is an example of the output:

```
% cc -o swapper swapper.c
swapper
4 2
4 2
```
