3. Without an explicit direction to the contrary, UNIX is going to let the hidden files remain hidden. To add the hidden files to the listing, you just need to add a -flag to the command. Turn to your computer and try this to see what hidden files are present in your directory. Here are your results:

```
% Is -a
gopherc   oldnewsrc   sig   RUMORS.18Sep
../ .history* .plan     bin/   iecc.list
../ .info    pnewsexert Archives/  mail.lists
Agenda .letter .report InfolWorld/ LISTS  newlists
aconfig .login .rn-timestap Mail/     src/
.article .mailirc .rnelast  News/
.chshrc .newsrc .rnsoft  OWL/
.elm/ %
```

Many dot files tend follow the format of a dot, followed by the name of the program that owns the file, with re as the suffix. You can see six dot files that follow this convention: .aconfig, .chshrc, .gopherc, .mailirc, .newsrc, and .oldnewsrc.

![](bbox=[0.166, 0.452, 0.246, 0.477])

Because of the particular rules of hidden files in UNIX, they are often called dot files, and you can see that I have 23 dot files and directories in my directory.

![](bbox=[0.166, 0.497, 0.246, 0.563])

> The re suffix tells you that this file is a configuration file for particular utility. For instance, .csh is the configuration for the C shell and is executed every time the C shell (/bin/csh) is executed. You can define aliases for C shell commands and a special search path, for example.

![](bbox=[0.166, 0.629, 0.246, 0.696])

Other programs create a bunch of different dot files and try to retain a consistent naming scheme. You can see that .rnlast and .rnsoft are both from the rn program, but it's difficult to know simply from the filenames that .article, .newsrc, .letter, .oldnewsrc, .pnewsexert are all referenced by the rn program. Recognizing this problem, some application authors designed their applications to create a dot directory, with all preference files neatly tucked into that spot. The elm program does with its .elm hidden directory.
