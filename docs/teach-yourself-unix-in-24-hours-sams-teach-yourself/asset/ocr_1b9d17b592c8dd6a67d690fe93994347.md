# Printing in the UNIX Environment

Some systems default to a printer named lp in this situation, so if you don't get an error message, that's what happened. If you havestat (a command for checking the status of a printer), the -d flag will result in ipstat listing your default printer.

To specify a printer, use the -P flag with Ip or the -d flag with Ip, followed immediately by the name of the printer:

```
% who | Ipr -Pmathiw
```

Specifying a printer with the -P flag (or -d with Ip) will always override the environment variable specified in PRINTER; however, you can specify the default printer with PRINTER and specify other printers without needing any further work.

Notice that I printed the output of the command but received absolutely no information from the command regarding what printer it was sent to, job number, or any other information.

To make life easier, I'm going to redefine PRINTER:

```
% setenv PRINTER mathiw
```
