# Task 3.1: The UNIX File System Organization

DESCRIPTION A key concept enabling the UNIX hierarchical file system to be so effective that anything that is not a folder is a file. Programs in UNIX, device drivers are files, documents and spreadsheets are files, your keyboard is represented as a file, your display is a file, and even your ty and mouse are files.

What this means is as UNIX has developed, it has avoided becoming an ungainly mess. UNIX does not have hundreds of cryptic files stuck at the top (this is still a problem in DOS) or tucked away in confusing folders within the System Folder (with the Macintosh).

The top level of the UNIX structure (/) is known as the root directory or slash, and it always has a set of subdirectories, including bin, dev, etc, lib, mnt, tmp, and usr. There can be a lot more, however. Listing 3 shows files at the top level of mentor file system (the system I work on). Typical UNIX directories are followed by a slash

