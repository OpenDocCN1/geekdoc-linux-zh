```
% archie -s mail | more
```

- 5. archie 系统还有一个相对有限的描述数据库，称为软件描述数据库（software description database），你可以通过 telnet 直接连接到远程 archie 系统来检查它：

```
% telnet archie.unl.edu
Trying...
Connected to crcnis2.unl.edu.
Escape character is '^^'.
```
