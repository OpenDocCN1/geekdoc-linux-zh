If you can't change your login shell, perhaps because of not having csh, you always enter the C shell after you log by typing csh.

JUST A MINUTE

It's easy to change login shell. You can try different ones until you find the one that best suits your style of interaction. For the most part, though, shells all have the same basic syntax and use the same commands: ls -i does the same thing in shell. The differences, then, really come into play when you use the more sophisticated capabilities, including programming the shell (with shell scripts), customizing its features through command aliases, and saving on keystrokes using a history mechanism. That's where the C shell has an edge and why it's so popular. It's easy, straightforward, and has powerfulising history, and job-control capabilities, as you learn in the next hour.

# Task 14.4: Learning the Shell Environment

Earlier in this hour, you used the env or print command to find the various characteristics of your working environment. Now it's time to use this command to look more closely at the C shell environment and define each of the variables therein.

![](bbox=[0.125, 0.773, 0.203, 0.796])

+   1. To start out, I enter env to list the various aspects of my working environment. The same on your system, and although your environment will not be identical to mine, there should be considerable similarity between the two.

```
% env | cat -n
1 HOME=/users/taylor
2 SHELL=/bin/csh
3 TERM=x100
```
