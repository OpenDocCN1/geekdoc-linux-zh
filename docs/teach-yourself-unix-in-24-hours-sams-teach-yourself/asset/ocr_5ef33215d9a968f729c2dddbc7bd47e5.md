This command is so helpful that I often have to bound to a specific key with the map command. A typical way to do this in an .exrc map like this:
map ^P it)fmt^M

The ^ is what vi uses to record a Return. (Recall that you need to use the ^v beforehand.) With this defined in my .exrc, I can press ^p to format the current paragraph.
