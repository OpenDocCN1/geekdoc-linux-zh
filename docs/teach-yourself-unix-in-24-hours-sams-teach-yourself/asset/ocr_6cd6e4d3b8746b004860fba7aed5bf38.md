2. Better, though, is to grab a copy of the information going down a stream in the
middle:

```
% ls -l | awk '{ print $5 \"t" $9 }' | sort -rn | tee bigfiles | head
12556 keyline.pie
8729 owl.c
1024 Mail/
582 tetme
512 temp/
```

This shows only the five largest files on the screen, but the bigfiles actually has
a list of all files, sorted by size:

```
% cat bigfiles
12556 keyline.pie
8729 owl.c
1024 Mail/
582 tetme
512 temp/
512 src/
512 bin/
512 OIl/
512 News/
512 Infolder/
512 Archives/
207 sample
199 sample
126 awkscript
```

The tee command is a classic UNIX utility, as stated before, it seems
useful but a bit limited in purpose. As you're learning through all the examples in this
book, however, from lots of commands do big, powerful commands grow.
