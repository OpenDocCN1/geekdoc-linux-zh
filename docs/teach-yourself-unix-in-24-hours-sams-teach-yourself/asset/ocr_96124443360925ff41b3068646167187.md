```
~t users         Add users to list
~v               Invoke display editor on message
~w file          Write message onto file.
~?               Print this message
~|command        Invoke the shell
~|command        Pipe the message through the command
```

The ones most important to remember are -v, to start vi in the message; ~r, to read in a file; -h, to edit the message headers; ~t, to invoke a shell command; and ~p, to show the message that's entered so far:
