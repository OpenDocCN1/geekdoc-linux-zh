5. To see some other examples, I use head to view the first 10 lines of the password file:

```
% head /etc/passwd
root:?:0:0:root:/bin/bash
news?:6:11:USENet News:/usr/spool/news:/bin/ksh
ingress?:7:59:INGRES Manager:/usr/ingles:/bin/bash
userlimit?:8:800:(1000 user system):mnt/bin/false
villa?:26:883:Vanilla Account:mnt:/bin/sh
charon?:21:807:The Ferryman:/users/tomb
actmain?:23:809:Maintenance:/usr/adm/actmain:/bin/ksh
pop?:26:819:/usr/spool/pop:/bin/bash
ip?:70:10:Adminuniverse(at):/usr/spool/ip
trouble?:97:501:Report Facility:/usr/trouble:/usr/local/lib/ms
```

Now I use grep to search for lines that contain zero or more occurrences of the letter z

```
% grep "z*" /etc/passwd | head
root:?:0:root:/bin/bash
news?:6:11:USENet News:/usr/spool/news:/bin/ksh
ingress?:7:59:INGRES Manager:/usr/ingles:/bin/bash
userlimit?:8:800:(1000 user system):mnt/bin/false

charon?:21:807:The Ferryman:/users/tomb

ip?:70:10:Adminuniverse(at):/usr/spool/ip
trouble?:97:501:Report Facility:/usr/trouble:/usr/local/lib/ms
Broken
```

6. Earlier I used head to count lines in the /etc/passwd file for accounts that did not specify a login sign. Each line in the file must have a number of colons; and the very last character on the line for these accounts has a colon, so an easy grep pattern:

```
% grep ":$" /etc/passwd
charon?:21:807:The Ferryman:/users/tomb
ip?:70:10:System Lp Adminuniverse(at):/usr/spool/ip:
```
