+   1. To view your environment, you can use the env command. Here’s what I see when I enter the env command on my system:

```
% env
HOME=/users/taylor
SHELL=/bin/csh
TERM=v100
PATH=/users/taylor/bin:/bin:/usr/bin:/usr/ucb:/usr/local/bin:
~/usr/unsup/bin:
MIL=/spool/mail/taylor
LOGNAME=taylor
TZ=EST5\%
```

Try it and compare your values with mine. You might find that you have more defined in your environment than I do because your UNIX system uses your environment to keep track of more information.

# Task 3.5: PATH and most HOME

![](bbox=[0.128, 0.614, 0.203, 0.642])

The two important values in your environment are the name of your home directory (HOME) and your search path (PATH). (as it’s known) is the name of the directory that you always begin UNIX session within.

The PATH environment variable lists the set of directories, in left-to-right order, that the system searches to find commands and applications you request. You can see from the example that my search path tells the computer to start looking in /users/taylor/bin directory, then sequentially /bin,/usr/bin,/usr/ucb,/usr/local/bin,/usr/unsup/bin, and . before concluding that it can’t find the requested command. Without a PATH, the shell wouldn’t be able to find any of the many, many UNIX commands: As a minimum, you always should have /bin and /usr/bin.
