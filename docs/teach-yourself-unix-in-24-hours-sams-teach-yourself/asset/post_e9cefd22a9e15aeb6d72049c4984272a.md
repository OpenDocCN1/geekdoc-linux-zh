
7. Here's another example of awk. I will modify the output of the ls -l command so that I build a quick list of files and their sizes (which isn't what is shown with the ls -s command, recall):

8. The awk program basically looks for a pattern to appear in a line and, if the pattern is found, executes the pattern in the awk script. There are two special patterns in awk: BEGIN and END. The instructions that follow BEGIN are executed before any lines of input are read. The instructions that follow END are executed only after all the input has been read.

This can be very useful for computing the sum of a series of numbers. For example, I'd like to know the total number of bytes I'm using for all my files:

```
% ls -l | awk '{print $5}'
512
512
1024
512
512
512
12556
11503
512
512
582
```

That generates the list of file sizes, but how do I sum them up? One new variable totalize and output its accumulated value after each line:

```
% ls -l | awk '{ totalize = totalize + $5; print totalize }'
512
1024
2048
2560
3072
3584
16140
27643
28155
28667
29249
```

One cleanup is to learn that += is a shorthand notation for "add the following value to the variable":

```
% ls -l | awk '{ totalize += $5; print totalize }'
512
1024
2048
2560
3072
3584
16140
27643
28155
28667
29249
```

I can use tail to get the last line only, of course, and figure out the total size that way:

```
% ls -l | awk '{ totalize += $5; print totalize }' | tail -1
29249
```

A better way, however, is to use the END programming block in the awk program:

```
% ls -l | awk '{ totalize += $4 } END { print totalize }'
29249
```

One more slight modification and it's:

```
% ls -l | awk '{ totalsize += $4 } END { print "You have a\ntotal-of " totalsize " bytes used." }'
You have a total of 29249 bytes used.
```

9. Here's another addition that can make this program even fun:

```
% ls -l | awk '{ totalsize += $5 } END { print "You have a\ntotal-of " totalsize " bytes used across files." }'
You have a total of 29249 used across files.
```

An easy way to see all this is to create an awk program:

```
cat << EOF > script
{ totalsize += $4 }
END { print "You have a total of " totalsize " bytes used across NR files." }
EOF

% ls -l | awk -f script
You have a total of 29249 used across files.
```

10. Here's one last example before I leave. Scripts in awk are really powerful and can do flow control (and some!). One thing you can do within an awk script is have conditional execution, the length function returns the number of characters in the argument:

```
% awk -F: '{ if (length($1) == 2) print $0 }' /etc/passwd | wc -l
26
```

Can you tell what this does? First off, notice that it uses the /etc/passwd file for input and a colon as field delimiter (-F:). For each line in the password file, this awk script tests to see whether the length of the first field (the username) is exactly two characters. If it is, the entire line from the password file is printed. All lines are printed by the program, because ls -l reports the total number of lines read.

What this command tells us is that on the machine, there are 26 accounts for which the name is two characters long.

11. The next logical question is, "How many accounts have a length of each possible number of characters?" To find out, I'll use an advanced feature of awk: I will have the program build a table to keep track of the count with one entry per number of characters:

```
cat << EOF > script
{ count[length($1)]++ }
END { for (i=1; i < 9; i++) print "There are " count[i] " accounts with " i " letter names." }
EOF
```

## Task 10.2: Re-routing the Pipeline with tee

After the substantial sed and awk commands, this next command, tee, should be nice. It's simple, can't be programmed? Recall that | symbol denotes a pipeline and that information traveling from one command to another. For example, | sort has the output of the who to sort. With the plumbing metaphor in mind, you can imagine it is helpful to be able to split off the stream to make travel down two directions instead of just one. If multiple pipelines were really allowed, neither nor I could figure out heck was going on.
