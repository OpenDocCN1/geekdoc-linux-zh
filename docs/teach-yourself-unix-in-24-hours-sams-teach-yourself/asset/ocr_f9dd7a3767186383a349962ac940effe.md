To avoid these problems, you can apply the technique you learned earlier, specifying all elements of the directory path from the top down. Learning the difference between these two notations is crucial to surviving the complexity of a hierarchical system used with UNIX. Without it, you'll spend half your time verifying that you are where you are, or worse, not moving about at, not taking advantage of the organizational capabilities.

If you're in doubt as to where you are what file you're working in UNIX, simply specify its absolute filename. You can always differentiate between the two by looking at the first character: If it's a slash, you've got an absolute filename the filename is rooted to the very top level of the file system. If you don't have a slash as the first character, the filename's a relative filename.

Earlier I told you in the home directory at the top level of UNIX, I have a home directory called taylor. In absolute filename, I'd properly say that I have /home/taylor as a unique directory.
