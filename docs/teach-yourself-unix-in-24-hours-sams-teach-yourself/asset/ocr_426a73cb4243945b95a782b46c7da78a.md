# Programming in C for UNIX

| Operator | Meaning |
| --- | --- |
| --var | Decrement var before using it. |
| var-- | Decrement var after using it. |
| -var | Negate the value of var. |
| +var | Use the positive value. |
| !var | Use the inverse value (for example, 10011100 becomes 01100011). |

The increment and decrement operators add or subtract one unit from the value of var. The unit for integers and characters is 1, for floating point, it is 1.0. This increment and decrement can have greater meaning for pointers, where it steps to the next member of an array.
