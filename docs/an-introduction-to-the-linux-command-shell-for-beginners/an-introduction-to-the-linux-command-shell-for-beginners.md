# 初学者的Linux命令行Shell入门指南




## 1.0 引言
本文档旨在为读者提供Linux命令行Shell及其基础工具的快速、简明入门介绍。假设读者此前完全没有或极少接触过Linux命令行。本文档最初设计为配合该主题的讲师引导教程使用，因此省略了部分细节。在适当的情况下，文中会包含相关说明、实践示例，以及与DOS命令的对照参考。

### 1.1 什么是命令行Shell？
- 解释命令的程序
- 允许用户在终端手动输入命令执行，或在名为*Shell脚本*的程序中自动执行命令
- Shell*不是*操作系统，它是与操作系统交互、运行命令的一种方式

### 1.2 什么是BASH？
- BASH = **B**ourne **A**gain **SH**ell
- Bash是一个为替代标准的Bourne Shell（/bin/sh）而编写的Shell，最初的Bourne Shell由Steve Bourne为UNIX系统开发
- 它保留了原始Bourne Shell的全部特性，还新增了多项功能，使其更易用于编程和命令行操作
- 由于它是自由软件，已成为大多数Linux系统的默认Shell

### 1.3 BASH与DOS命令行提示符有何不同？
- **大小写敏感**：在Linux/UNIX系统中，命令和文件名区分大小写，这意味着输入“EXIT”而非正确的“exit”属于错误操作
- **“\”与“/”的区别**：在DOS中，正斜杠“/”是命令参数的分隔符，反斜杠“\”是目录分隔符；而在Linux/UNIX中，“/”是目录分隔符，“\”是转义字符。我们稍后会详细介绍这些特殊字符！
- **文件名**：DOS系统采用“8.3”文件名规范，即所有文件名的格式为：最多8个字符的文件名+句点（“点”）+最多3个字符的可选扩展名（例如FILENAME.TXT）。而在UNIX/Linux中并不存在“文件扩展名”这一概念，句点可以放在文件名的任意位置，“扩展名”可能被不同程序以不同方式解析，也可能完全不被识别。

### 1.4 特殊字符
在继续学习Linux Shell命令之前，需要先了解：Shell会对大量符号和字符进行特殊解析。这意味着部分输入的字符：a) 无法在特定场景下使用；b) 可用于执行特殊操作；c) 若要以常规方式使用，必须对其进行“转义”处理。

| 字符 | 说明 |
| --- | --- |
| \ | 转义字符。如果要引用特殊字符，必须先用反斜杠对其进行“转义”处理。示例：`touch /tmp/filename\*` |
| / | 目录分隔符，用于分隔一串目录名称。示例：`/usr/src/linux` |
| . | 当前目录。若作为文件名的首字符，还可用于“隐藏”文件 |
| .. | 上级目录 |
| ~ | 用户的主目录 |
| * | 可匹配文件名中的0个或多个字符，单独使用时代表目录内的所有文件。示例：`pic*2002` 可匹配pic2002、picJanuary2002、picFeb292002等文件 |
| ? | 可匹配文件名中的单个字符。示例：`hello?.txt` 可匹配hello1.txt、helloz.txt，但无法匹配hello22.txt |
| [ ] | 可用于表示取值范围，例如[0-9]、[A-Z]等。示例：`hello[0-2].txt` 可匹配hello0.txt、hello1.txt、hello2.txt |
| \| | “管道”。可将一个命令的输出重定向为另一个命令的输入。示例：`ls | more` |
| > | 将命令的输出重定向到新文件中，若文件已存在则会覆盖原有内容。示例：`ls > myfiles.txt` |
| >> | 将命令的输出追加到已有文件的末尾。示例：`echo "Mary 555-1234" >> phonenumbers.txt` |
| < | 将文件作为输入重定向到程序中。示例：`more < phonenumbers.txt` |
| ; | 命令分隔符，支持在一行中执行多条命令。示例：`cd /var/log ; less messages` |
| && | 与上述命令分隔符功能相同，但仅当第一条命令执行无错误时，才会执行第二条命令。示例：`cd /var/logs && less messages` |
| & | 在后台执行命令，执行后立即返回Shell提示符。示例：`find / -name core > /tmp/corefiles.txt &` |

### 1.5 执行命令
#### 命令PATH：
- 绝大多数常用命令都位于Shell的“PATH”路径下，这意味着你只需输入程序名称即可执行该命令。示例：输入“ls”即可执行“ls”命令
- Shell的“PATH”变量包含了最常用的程序路径，例如`/bin`、`/usr/bin`、`/usr/X11R6/bin`等
- 若要执行当前PATH路径外的命令，需要输入该命令的完整路径
  示例：
  - `/home/bob/myprogram`
  - `./program`（执行当前目录下的程序）
  - `~/bin/program`（执行个人bin目录下的程序）

#### 命令语法
命令可以单独运行，也可以传入额外参数来实现不同功能。典型的命令语法格式如下：
``` command [-argument] [-argument] [--argument] [file] ```
- 示例：
  - `ls` — 列出当前目录下的文件
  - `ls -l` — 以“长格式”列出文件
  - `ls -l --color` — 与上述命令功能相同，同时输出带颜色高亮的结果
  - `cat filename` — 显示文件内容
  - `cat -n filename` — 显示带行号的文件内容

## 2.0 获取帮助
当你遇到问题、需要获取Linux命令的相关帮助时，通常只需敲几下键盘就能找到！大多数Linux命令都内置了帮助功能，还可以通过在线帮助程序（即“man手册页”和“info手册页”）以及互联网获取帮助。

### 2.1 使用命令内置帮助
许多命令都带有简单的“帮助”界面，可通过特定的命令标志调用。这类标志通常为“-h”或“--help”。示例：`grep --help`

### 2.2 在线手册：“Man手册页”
大多数命令的最佳信息源是在线手册页，简称“man页”。要查看某命令的man页，只需输入“man 命令名”。示例如下：
- `man ls` — 获取“ls”命令的帮助
- `man man` — 关于如何使用手册的手册！

要在man页中搜索特定关键词，输入“/关键词”即可。要退出man页，只需按下“Q”键。有时你可能不记得某个Linux命令的名称，需要搜索查找。例如，如果你想知道如何修改文件权限，可以按照如下方式在man页描述中搜索关键词“permission”：`man -k permission` 查看该命令的输出，你会发现一条类似下面的结果：`chmod (1) - change file access permissions` 这就说明你要找的命令是“chmod”，输入“man chmod”即可查看chmod命令的手册页！

### 2.3 Info手册页
部分程序（尤其是自由软件基金会发布的程序）使用info页作为主要的在线文档来源。info页与man页类似，但不会以长滚动屏的形式展示，而是分为较短的段落，并附带跳转至其他相关信息的链接。要访问info页，可以使用“info”命令，部分Linux发行版还提供了“pinfo”（一款更友好的info浏览器）。示例：`info df` 可加载“df”命令对应的info页。



## 3.0 导航Linux文件系统
Linux文件系统是目录与文件的树状层级结构。文件系统的基础是“/”目录，也被称为“根目录”（不要和root用户混淆）。与DOS或Windows文件系统拥有多个“根”（每个磁盘驱动器对应一个）不同，Linux文件系统将所有磁盘挂载到/文件系统下的某个位置。下表描述了众多常见的Linux目录。
### 3.1 *Linux目录布局*
| 目录 | 描述 |
|-----------|-------------|
| | 文件系统的无名基目录。所有其他目录、文件、驱动器和设备都附加到这个根目录上。通常（但错误地）被称为“斜杠”或“/”目录。“/”只是一个目录分隔符，本身不是目录。 |
| `/bin` | 存放基本命令二进制文件（程序）（`bash`、`ls`、`mount`、`tar`等） |
| `/boot` | 引导加载程序的静态文件。 |
| `/dev` | 设备文件。在Linux中，硬件设备的访问方式和其他文件一样，保存在这个目录下。 |
| `/etc` | 主机专属的系统配置文件。 |
| `/home` | 用户个人主目录的位置（例如`/home/susan`）。 |
| `/lib` | 基本共享库和内核模块。 |
| `/proc` | 进程信息伪文件系统。内核数据结构的接口。 |
| `/root` | root（超级用户）的主目录。 |
| `/sbin` | 基本系统二进制文件（`fdisk`、`fsck`、`init`等）。 |
| `/tmp` | 临时文件。所有用户都有权限在此放置临时文件。 |
| `/usr` | 大多数可共享、只读数据（程序、库、文档等）的基目录。 |
| `/usr/bin` | 大多数用户程序存放在这里（`cc`、`find`、`du`等）。 |
| `/usr/include` | 编译C程序的头文件。 |
| `/usr/lib` | 大多数二进制程序的库。 |
| `/usr/local` | “本地”安装的文件。这个目录只在文件存储在网络的场景下才真正重要。本地安装的文件会放在`/usr/local/bin`、`/usr/local/lib`等目录下。也经常用于从源码安装的软件包，或发行版未官方附带的软件。 |
| `/usr/sbin` | 非必要的系统二进制文件（`lpd`、`useradd`等）。 |
| `/usr/share` | 架构无关的数据（图标、背景、文档、terminfo、man手册页等）。 |
| `/usr/src` | 程序源代码。例如Linux内核、源码RPM等。 |
| `/usr/X11R6` | X Window系统。 |
| `/var` | 可变数据：邮件和打印机队列、日志文件、锁文件等。 |
### 3.2 导航Linux文件系统的命令
学习Linux文件系统时，你通常首先想做的就是花些时间四处看看里面有什么！接下来几个命令将实现以下功能：a）告知你当前位置，b）带你前往其他位置，c）展示当前位置的内容。下表描述了pwd、cd和ls命令的基本操作，并与你可能已经熟悉的部分DOS命令进行了对比。
| Linux命令 | DOS命令 | 描述 |
|---------------|-------------|-------------|
| **pwd** | cd | “打印工作目录”。展示目录树中的当前位置。 |
| **cd** | cd、chdir | “更改目录”。单独输入时，会返回你的主目录。 |
| **cd 目录** | cd 目录 | 切换到指定的目录名称。示例：`cd /usr/src/linux` |
| **cd ~** | | “~”是你的主目录别名。它可以作为进入“主目录”的快捷方式，也可用于跳转到主目录相对路径下的其他目录。 |
| **cd ..** | cd.. | 向上移动一级目录。例如，如果你位于`/home/vic`，输入“cd ..”，最终会进入`/home`。 |
| **cd -** | | 返回上一个目录。回到之前位置的便捷方式！ |
| **ls** | dir /w | 以列格式列出当前目录中的所有文件。 |
| **ls 目录** | dir 目录 | 列出指定目录中的文件。示例：`ls /var/log` |
| **ls -l** | dir | 以“长”格式列出文件，每行显示一个文件。同时展示文件的附加信息，例如所有权、权限、日期和大小。 |
| **ls -a** | dir /a | 列出所有文件，包括“隐藏”文件。隐藏文件是以“.”开头的文件，例如主目录中的`.bash_history`文件。 |
| **ls -ld 目录** | | 目录的“长”格式列表，但不会展示目录内容，而是展示目录的详细信息。例如，对比以下两个命令的输出：`ls -l /usr/bin` `ls -ld /usr/bin` |
| **ls /usr/bin/d*** | dir d*.* | 列出`/usr/bin`目录中名称以字母“d”开头的所有文件。 |
## 4.0 管道与重定向
在学习更多命令之前，我们先岔开话题，介绍管道与重定向的相关内容。因此，基本的UNIX哲学，延伸至Linux哲学，就是拥有许多执行特定任务非常出色的小型程序和实用工具。程序员或用户的责任是组合这些实用工具，以生成更有用的命令序列。
### 4.1 管道连接命令
管道字符“|”用于将两个或更多命令串联在一起。第一个命令的输出会通过“管道”送入下一个程序，如果存在第二个管道，输出会发送到第三个程序，以此类推。例如：
``` ls -la /usr/bin | less ```
在这个例子中，我们运行命令“ls -la /usr/bin”，它会输出`/usr/bin`中所有文件的长格式列表。因为这个命令的输出通常很长，我们将输出通过管道送入名为“less”的程序，该程序会一次展示一屏内容供我们查看。
### 4.2 将程序输出重定向到文件
有时将命令的输出保存到文件而非显示在屏幕上是有用的。例如，如果我们想创建一个列出目录中所有MP3文件的文件，可以使用“>”重定向字符，操作如下：
``` ls -l /home/vic/MP3/*.mp3 > mp3files.txt ```
可以编写类似的命令，不是创建名为mp3files.txt的新文件，而是将内容追加到原文件的末尾：
``` ls -l /home/vic/extraMP3s/*.mp3 >> mp3files.txt ```

### 5.2 查找内容
以下命令用于查找文件。如果你已经大致知道文件的位置，"ls" 是查找文件的不错选择，但有时你需要更强大的工具，比如下面这些：
| Linux 命令 | 说明 |
|---|---|
| **which** | 显示在你的 PATH 环境变量中找到的 shell 命令的完整路径。例如，如果你想精准定位 "grep" 命令在文件系统中的位置，可以输入 `which grep`。输出结果通常会类似如下内容：/bin/grep |
| **whereis** | 定位命令的程序、源代码和手册页（若所有信息均可用）。例如，要查找 "ls" 命令及其手册页的位置，输入：`whereis ls`。输出结果通常会类似如下内容：ls: /bin/ls /usr/share/man/man1/ls.1.gz |
| **locate** | 在文件系统的任意位置快速搜索文件。例如，你可以输入 `locate mozilla` 来查找所有名称包含 "mozilla" 的文件和目录。 |
| **find** | 一个*非常*强大的命令，但使用时可能存在一些难点。它既可以用于搜索匹配特定模式的文件，也支持多种其他搜索场景。简单示例如下：`find . -name \*mp3`。该示例会从当前目录 "." 及其所有子目录开始搜索，查找文件名以 "mp3" 结尾的文件。 |

### 5.5 让一切更轻松的快捷键！
当你开始更频繁地使用 Bash shell 时，你会爱上这些能节省大量输入时间的快捷键：
| 快捷键 | 说明 |
|---|---|
| 上/下方向键 | 浏览你最近使用过的命令。你可以回滚到旧命令，按下 `Enter` 键即可执行该命令，无需重新输入。 |
| "history" 命令 | 显示完整的命令历史记录。 |
| `Tab` 补全 | 如果你输入了 shell 可识别的部分命令或文件名，按下 `Tab` 键即可自动补全。试试输入你常用的 Linux 命令的前几个字符，然后连续按几次 `Tab` 键看看会发生什么。 |
| 用 "!" 补全最近使用的命令 | 试试这样操作：输入 "!"，接着输入最近使用过的命令的前几个字母，然后按下 `Enter` 键！例如，输入：`find /usr/bin -type f -name m\*`……接着输入：`!fi` |
| 用 CTRL-R 搜索命令历史 | 按下 `CTRL-R`，然后输入最近使用过的命令的任意部分，它就会自动帮你搜索命令。找到你想要的命令后，按下 `Enter` 键即可执行。 |
| 用 `Shift-PageUp` 和 `Page Down` 滚动屏幕 | 在你的终端中向前或向后滚动屏幕。 |
