

在直接匹配法中，被试不需要生成或评估一个刺激量级与另一个刺激量级的比率，而只需调整比较刺激，直到其某个属性看起来与标准刺激相匹配为止。例如，可能会要求被试调整不同频率声音的物理强度，直到它们的响度与固定强度的 1000-Hz 声音相匹配。结果将是一条等响度曲线，展示了为了使不同频率的声音产生相同响度感，需要将其强度设置到多少。这些数据在声学中具有应用价值。**参见响度。**

平均误差法，是费希纳设计的三种方法中的第三种，是直接匹配法在感知与刺激之间存在差异的情况下的特殊应用。被试调整比较刺激以匹配标准刺激；这些设定的平均值即为主观等感点，而该点与标准刺激之间的差异即为平均误差。该方法的两个说明性用途包括测量距离感知的准确性以及测量所谓视错觉的大小。参见**听觉（人类）**；**心理物理学**。[J.F.H.]

# 精神病

指高级心理过程发生障碍且严重到足以显著损害对外部事件现实性的判断的任何疾病。广泛的各种状况都可能导致精神病状态。它们包括精神分裂症、躁狂症、抑郁症、药物摄入、药物戒断、肝或肾衰竭、内分泌紊乱、代谢紊乱以及阿尔茨海默病、癫痫和其他神经功能障碍。正常睡眠中的梦境是精神病的一种形式。

精神病的知觉改变被称为幻觉。由酗酒、代谢疾病或其他医学状况引起的精神病状态常伴有普遍的精神混乱。另一方面，精神疾病和药物可以在没有普遍精神混乱的情况下产生幻觉和妄想。这些症状中很少有某一特定疾病所独有的，这使得正确诊断变得困难且具有挑战性。然而，正确的诊断至关重要，以便提供适当的治疗。参见**成瘾性疾病**；**情感障碍**；**阿尔茨海默病**；**神经症**；**偏执型**；**精神致幻剂**；**精神分裂症**。[R.E.Ho]

# 心身疾病

指其特征在于生理变化至少部分起源于情感因素的障碍。经典的心身症状及其理论上的病因在表中列出。

| 症状（疾病） | 心理因素 | 推测的心身机制 |
| :--- | :--- | :--- |
| 多动症<br>（消化性溃疡） | 依赖性受阻；<br>普遍压力 | 胃酸分泌增加 |
| 原发性高血压 | 攻击性冲突；<br>普遍压力 | 血管收缩 |
| 支气管哮喘 | 寻求保护或<br>分离的愿望冲突；焦虑；<br>普遍压力 | 支气管痉挛 |
| 偏头痛 | 控制欲冲突；<br>普遍压力 | 血管收缩和舒张 |
| 甲状腺功能亢进<br>（Graves 病） | 过早自立能力的冲突 | 促甲状腺激素分泌增加 |
| 腹泻<br>（溃疡性结肠炎） | 义务感冲突 | 胃肠道胆碱能激活 |

心理状态通过神经、激素和免疫这三种相互关联机制的组合来影响身体器官。自愿运动（例如咬牙）是通过运动神经元由大脑的有意识命令介导的。在压力状态下，通过同样的运动神经元介导的咬牙也可能发生，但这一行为可能并非自愿或有意识的。压力通常会导致交感神经系统和下丘脑-垂体-肾上腺轴激活，随后免疫功能下降。免疫机制可能部分通过皮质类固醇激活而受到抑制，但在压力状态下 T 淋巴细胞活性的降低可能并非由激素介导。个体特定的、但非故意的躯体冲突或压力与特定身体功能障碍之间的条件反射建立，可能是重要的心身机制。参见**条件反射**；**神经免疫学**。

转化障碍是指可归因于躯体感觉神经系统或特殊感觉器官的身体症状，且无法基于医学或神经疾病加以解释。常见症状包括瘫痪、失明、共济失调、失声以及足部麻木（袜套手套样感觉缺失）。这些症状可能代表一种心理冲突，或者是身体语言沟通的一种形式。首选治疗方法是心理治疗。

在躯体化障碍（也被称为布里歇综合征/Briquet's syndrome）中，患者反复抱怨多个躯体症状，这些症状涉及体内几乎每一个器官系统，并经医学检查后发现并非可诊断的身体疾病。该障碍与转化障碍的区别在于其症状的慢性性和多样性。这些症状通常不暗示特定的心理冲突，但可能代表普遍的情绪低落和扭曲的疾病行为。目前尚无确定的治疗方法；患者应由一位医生管理，该医生协调所有诊断和治疗计划，并在没有不必要的侵入性操作或检查的情况下提供持续的支持和随访。

具有典型心身症状或障碍的患者常表现出特定的心理冲突特征；然而，多因素或异质性疾病的一个方面不被视为病因。已知遗传因素在这些大多数疾病的发病机制中起着重要作用。这些患者所表现出的某些心理困难实际上可能是疾病的结果。当冲突严重到值得解决时，心理治疗在解决冲突方面往往有益，但它不一定能改善身体症状或疾病进程。**参见心理治疗。** [H.L.ei]

# 心理治疗

任何主要具有心理性质的治疗或疗法。近年来，咨询也被纳入这一类别。

# 精神分析疗法

从历史上看，由西格蒙德·弗洛伊德创立的精神分析在心理治疗的发展和成长中发挥了重要作用。弗洛伊德理论的核心是无意识冲突在产生患者症状和防御机制方面的重要性。治疗的目标是帮助患者获得对作为困难根源的被压抑冲突的洞察。由于患者抵抗将这些痛苦的被压抑材料带入意识层的尝试，治疗必须缓慢进行。因此，精神分析是一种需要数年时间才能完成且几乎每天都需要就诊的长期治疗。自弗洛伊德时代以来，与其前门徒如阿尔弗雷德·阿德勒和卡尔·荣格相关的重要修正已经出现。自我心理学和自我心理学是较新的方法之一。然而，精神分析的流行度已经下降。**参见精神分析。**
