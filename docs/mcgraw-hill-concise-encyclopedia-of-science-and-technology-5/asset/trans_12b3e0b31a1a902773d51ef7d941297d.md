**外差原理** 超外差无线电、电视或其他接收机工作的基本原理，其中两个频率不同的交流电在非线性器件中混合，产生两个新的频率，对应于输入频率之和与差。通常只使用差频作为超外差接收机的中频放大器的输入。参见**无线电接收机**。(J.Mar.)

**多相催化** 催化剂以独立相存在的化学过程。通常，催化剂是固体，而反应物和产物处于气相或液相。参见**催化**。

多相催化通过化学吸附络合物的形成及其随后的反应进行，这些络合物可被视为表面化合物。一个非常简单的例子是，在没有催化剂时 A → B 反应缓慢，如下列反应所示：

```
* + A → *A
*A → B*
B* → B + *
A → B
chain propagating steps
```

如果前面三个步骤都是快速的，则反应 A → B 是快速的。因此，* 代表催化剂表面的催化位点，*A → B* 被称为表面反应，* + A → *A 代表 A 的化学吸附，而 B* → B + * 代表 B 的脱附。参见**吸附**。

对于大多数反应物组合，热力学上可能允许多于一个反应。在与其他可能的反应相比，给定催化剂倾向于某个反应的程度被称为该催化剂对该反应的**选择性**。催化剂有两个方面尤为重要：其选择性，及其活性，活性可被定义为在特定条件下给定量的催化剂对反应物的转化速率。理想情况下，速率将与催化剂的量成正比。

在化学工业中最早被使用的重要多相催化过程是 1875 年通过接触法从三氧化硫生产硫酸。到 20 世纪 50 年代，多相催化过程已开始主导石油、石化和化学工业。如今，美国精炼的原油中约有 70% 至少经历了一个多相催化过程。多相催化是能源节约和转换的关键特征，也是从煤和油页岩生产合成燃料的关键特征。参见**煤气化**；**费托过程**。

由于催化活性通常与表面积成正比，大多数催化剂以具有大比表面积的形式使用。高比表面积金属粉末常用于间歇反应器中的液相反应。例如，在植物油制造人造黄油的过程中，使用细分散的镍对不饱和甘油酯进行加氢。负载型催化剂被广泛使用。在这些催化剂中，催化成分分散在硅胶、γ-氧化铝和木炭等载体的内部孔隙中。这些载体在内部孔隙中具有大面积，其平均孔径为 2–20 nm。负载型催化剂的优点是催化成分的表面积可以非常大。

一种重要的催化剂在其内部孔隙中暴露出强酸性位点。此类催化剂用于石油炼制中将较大的碳氢分子裂解为较小的分子。其他被称为双功能催化剂的催化剂，在酸性载体上具有加氢催化成分。这些在石油加工中也具有重大重要性。参见**裂化**；**加氢裂化**；**沸石**。(R.L.Ba.; G.L.H.)

# 沸石（Heulandite）

属于沸石族硅酸盐的一种矿物。通常呈晶体状，沸石侧为柱状晶形，常呈菱形。在柱状晶形解理面上有完全解理，光泽为珍珠光泽；其他部位光泽为玻璃光泽。硬度为莫氏硬度 3.1/2 到 4；比重为 2.18-2.20。该矿物通常为白色或无色，但也可能是黄色或红色。*参见沸石*。

Heulandite 本质上是一种含水铝硅酸盐，Ca(Al₂Si₅O₁₆) · 6H₂O。Heulandite 是一种次生矿物，发现于玄武岩中与沸石和方解石相关的孔洞中。著名的产地包括法罗群岛、印度、新斯科舍和新泽西州西帕特森。[C.F.; C.S.H.]

# 异颈类（Heterostraci）

一类已灭绝的盾皮鱼或无颌有装甲脊椎动物（Agnatha）。其装甲具有独特的显微结构，由缺乏骨细胞腔的骨骼组成，周围环绕着齿质结节或脊。来自澳大利亚和北美中奥陶世的这种装甲碎片是明确归属于脊椎动物的最早遗骸。异颈类在志留纪晚期变得更为常见，并持续至泥盆纪。

身体前部覆盖着骨板。身体后部和尾部覆盖着厚鳞。没有颌，但口部后方由许多小骨板界定，这些骨板可能用于磨擦。[R.H.D.]

# 异缓步动物（Heterotardigrada）

缓步动物门的一个目；大多数属具有广泛多变的结构。存在具有感觉功能的头部附肢，以及侧环和爪。该缓步动物目分为两个亚目：关节缓步动物（Arthrotardigrada）和棘缓步动物（Echinisocidea）。

亚目 Arthrotardigrada 的成员腿部末端呈工具状。腿的管状中部滑入宽阔的近端部。这些动物是海洋生物，发现于沙子或藻类上。

在亚目 Echinisocidea 中，腿部以爪结束。腿的中部可部分缩回近端部。至少第四对腿具有明显的褶皱。由于类胡萝卜素色素的存在，这些动物常呈红色。*参见类胡萝卜素；缓步动物门* [E.M.]

# 异纤虫目（Heterotrichida）

毛口虫纲的一个大目。口缘纤毛系统发达，尽管在许多科中，体部纤毛实际上具有全纤毛性质。异纤虫已适应各种栖息地，包括多种无脊椎动物和少数脊椎动物宿主的消化道。由于其体型和惊人的再生能力，许多异纤虫被广泛用于实验研究。常见属包括 Stentor, Blepharisma, Folliculina, Condylostoma, Climacostomum（见图），和 Spirotristoma。*参见毛口虫纲* [J.O.C.]

# 六放海绵纲（Hexactinellida）

骨架由硅质六射骨针构成的海绵纲。这些纯海洋海绵广泛分布于现代海洋中。其化石记录从晚太古宙延续至今生代。该纲的基本骨针类型是三相六射线，其中三对相对的光线彼此垂直，并位于立方体的三个轴之一上。近端光线末端和轴向丝在立方体中心交汇。这些主要骨针及其变体构成了海绵的骨架。

现生六放海绵主要是深海-海洋生物，最常见于 200-2000 米（660-6560 英尺）的深度，尽管许多物种已知生活在深海下层。活着的六放海绵通常呈高脚杯状或瓶状，尽管该纲中也存在分支状、块状、管状或绳状外观的海绵。许多具有长骨针的根丛，将其锚定在原位并将其支撑在海床之上。

# 六放海绵目（Hexactinosa）

六放海绵纲六放目（Hexascomopha）的一个目。该目海绵中的六射大骨针相互结合形成刚性框架，完全由排列成平行线列的简单六射线骨针组成。每列的成员通过二氧化硅的次要包膜彼此连接。*参见六放海绵纲* [W.D.H.]

# 六放海绵亚纲（Hexactinomorpha）

六放海绵纲的一个亚纲，其六射大骨针通常为六星形（小型、六射线骨针，末端常有分支）。这是一个多样化的海绵集合，通常通过基部牢固地附着在基底上，较少通过基部骨针丛或垫锚定。体部骨针有时是自由且未连接的，但六射大骨针常融合形成刚性连接的骨架。承认以下目：Hexactinosa, Lyssicosida, Lyssicososa, 和 Reticulosida。*参见 HEXACTINOSA; LYNCOSIDA; LYSSICOSA; 多孔动物门; RETICULOSA* [W.D.H.]
