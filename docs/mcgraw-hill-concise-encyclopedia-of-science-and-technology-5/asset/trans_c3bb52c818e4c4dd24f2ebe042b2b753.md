

# 半球侧化

前文所述的昆虫具有隐色，类似于沙地或泥浆背景的颜色。Octothrips（小蠹）呈黑色，带有丝质光泽。

Ambiphidocidae（双面水蝽科）。该亚目包含触角外露且雄性没有膨大射精器的表面水虫。目前仅提出了单一的、多样的Gerroidea（水黾总科）作为表面水虫的总科。它们都有明显的触角，且身体覆盖着疏水毛。所有Gerroidea都是捕食性的。

Gerroidea是大型水黾，其中足节和后腿较长，中足跗节上有一个中位臭腺开口。爪位于跗节末端之前。海洋形态始终无翅，但其他所有形态都具有多态性，全翅型与短翅型或无翅型共存。

Velidae（小水黾科）是小型水黾，腿部较短，且两眼之间有一条纵向沟。爪是早成的。与Gerroidea一样，该物种包含溪流栖息型和海洋型，但后者仅出现在热带珊瑚礁的海岸附近。

Hydrometrae（长沼黾）是细长的沼地行者，其头部比胸部长。爪是尖的。

Mesoveliae（中水黾科）和Hebridae（海黾科）是两个小型科，与其他科的区别在于拥有发育良好的单眼以及若虫单一背侧腹部臭腺开口。

Geocorisae（地蝽亚目）。该亚目包含具有明显触角和雄性生殖系统中射精器球的地虫。该亚目可分为七个群，每个群在等级上可能等同于Hydrocorisidae（水蝽科）和Ambiphidocidae。不符合上述群组的总科包括Reduvioidea（猎蝽总科）、Salcidoidea（岸蝽总科）、Aradoidea（瘤蝽总科）以及处于系统孤立位置的Enicocephaloidea（双叶头虫总科）和Diplocarotoidea（双齿科总科）。

Salcidoidea总科包含岸蝽，其头顶有三对毛触觉毛，且若虫仅有一个臭腺开口。Diplocarotoidea是一个微小地面栖息者群，其中Sciopezatidae（拟叶虫科）生活在落叶层中，而Dipsocarotoidea是捕食树皮下方、腐木中或溪流边缘石块间小型昆虫的捕食者。

Enicocephaloidea是一个独特的群，其头部双裂，前胸背板三裂，翅膀完全膜质。它们生活在石头下、树皮下方和落叶层中，且具有捕食性。有些物种无翅；其他物种可以脱落翅膀。

Reduvioidae仅包含猎蝽科的刺客虫或尖头虫。几乎所有物种的前胸骨板上都有一条纵向沟槽，由旋转器刮擦产生吱吱声。通常存在单眼，且口器为三节。

Aradoidea包括瘤蝽科的瘤蝽及其特化亲属Terraphididae（土虫科）。它们没有单眼，触角为四节。大多数，如果不是全部的话，都是真菌取食者。Terraphididae没有翅膀。它们已知存在于旧世界和新世界热带的白蚁巢中。Aradidae几乎遍布全球，且全翅型、短翅型、窄翅型或无翅型均有分布。

Cimicomorpha（半胸亚目）是Geocorisae中最大的群，分为三个总科：Cimicoidea（啮虫总科）、Tingoidea（网蝽总科）和Thaumatozotoidea（澳洲网蝽总科）。

1.  Cimicoidea。Anthocoridae（小花蝽科），或称花蝽，是小型捕食者，捕食植被、储藏产品及鸟巢中的蓟马、螨虫及类似物种。单眼明显，前翅具缘片。Cimicidae（臭虫科）包含臭虫，它们没有单眼，且短翅退化为垫状。食物由鸟类和哺乳动物的血液组成。Polycetoidea（多节虫总科）并非缺乏眼睛、具有栉片和强壮爪子的外寄生虫。Miridae（盲蝽科）包含半翅目的大多数物种。其中包括植食型和捕食型两大类植物蝽。缺乏单眼，触角为四节，若虫仅有一个背侧腹部臭腺开口。两个小型科Ploiophilidae（扁蝽科）和Microphysidae（微小蝽科）具有捕食性。Ploiophiliidae生活在蜘蛛和蛇的网中。

Nabidae（螳蝽科）是细长的“螳”蝽，是捕食其他昆虫的细长捕食者。单眼发育良好，口器为四节。热带的Reduvioidea与之相关，但形态较宽且颜色较深。

2.  Tingoidea。该总科包含网蝽科，其翅膀具有许多网状小室。它们没有单眼，触角和口器分为四节，胸部通常有一个或多个球状或钩状隆起。已知对观赏植物有害。

3.  Thaumatozotoidea。唯一的科Thaumatozoetidae（澳洲网蝽科）分布于澳大利亚和新世界热带地区；包括佛罗里达的皇家棕榈虫。

Pentatomorpha（盾蝽亚目）包含Ligeoidea（红蝽总科）、Pyrrhocoroidea（红蝽总科）、Coreoidea（缘蝽总科）和Pentatomoidea（蝽总科）等总科。

1.  Ligeoidea。这是第一个腹部具有腹侧毛触觉毛（刚毛）的总科。触角为四节。存在单眼。Ligeoidea包括稻虱、假稻虱和乳草虫。与Ligeoidea相关的小型科有三足Neidioidea（Berytidae，网菌科）、小型Lixiasidae（丽蝽科）和热带Colpophteridae（圆蝽科）。后者中有些具有独特的鸣叫方式，头部侧面有一个锉状拱形结构。

2.  Pyrrhocoroidea。该群包括棉红蝽（攻击美国西南部和大部分热带地区的棉铃）以及粗壮、深色、带红色边缘的蝽。

3.  Coreoidea。南瓜虫及其亲属包括Coreidae（缘蝽科）、Rhopalidae（喙缘蝽科）、Alydidae（盲蝽科）和Hypancidiidae（盾蝽科）。它们具有四节触角、口器、明显的单眼，以及膜部有许多翅脉。

4.  Pentatomoidea。该大群具有缘毛触觉毛。触角通常分为五节，口器为四节。Scutellerae（盾蝽，或称盾虫）在美国无害。Cydnidae（土蝽科）包括在沙质土壤中攻击草莓的掘地蚁和黑人虫。在美国经济意义较小或无经济意义的小型科包括热带大型Tessaratomidae（四斑蝽科）、Acanthosomatidae（棘蝽科）、Dinocoriidae（短蝽科）、Aphodiidae（甲虫科？此处可能指蝽类）、Urostomidae（臀蝽科）、具有战斗性的Philocoroidea、光泽皇家的Plataspidae（平盾蝽科）和Leptotenioide。真正的蝽，Pentatomidae（蝽科），包括黑红杂色的花蕾虫以及棉花和其他作物上的几种绿色蝽。参见“昆虫”。

# 半球侧化

人脑是一个双侧对称的结构，主要由两个称为胼胝体和前连合的神经元主要桥梁丰富地相互连接。这些结构可以在人类中进行外科切开，以试图控制癫痫发作的扩散。虽然这些患者的日常行为似乎没有明显变化，但在专门的测试条件下，可以观察到认知功能的巨大差异。在正常人类中，这些脑连合在行为统一性方面起着主要作用；神经机制使身体左侧保持右侧活动的最新状态，反之亦然。

脑连合被切开的人的行为反应变化几乎无法察觉。此人行走、说话和行为均正常。只有在利用专门侧化到单一半球的刺激条件下，才能观察到戏剧性的影响。例如，如果在右侧视野中闪现一个苹果的图片，此人可以正常描述该物体。然而，如果同一张图片在左侧视野中闪现，在术后测试的早期阶段，此人会否认刺激呈现过。经过许多测试会话后，此人可能会感到有什么东西闪现，但无法说出是什么。视觉场两侧识别的这种差异是因为信息投射到无法说话的右半球。由于右半球现在与左半球断开连接，到达右半球的信息无法通过语言传达。

当使用不需要口头回答的测试时，观察到许多心理能力存在于“断开”的右半球中。例如，尽管此人无法描述左侧视野中闪现的橙子图片，但当左手在视线外的物体堆中搜索时，它能正确找回橙子。如果被问及物体是什么，此人会说不知道。再次说明，左半球控制语言但无法解决问题。右半球可以解决问题但无法激发语言。

尽管左半球在语言方面占优势，但它并非在所有任务上都优于右半球。测试表明，在某些专门功能上，右半球明显优于左半球。在情绪反应领域，两个半球似乎具有相同的反应性。

对脑连合未完全切开的受试者进行了测试（因为现在认为完全切除连合对于阻止某些癫痫活动的半球间扩散并非必要）。这些人显示出半球间传递的戏剧性崩溃。当胼胝体的后部被切开时，出现综合征的视觉方面。当胼胝体保留而更下部的区域被切开时，触觉和听觉交流被阻断，但视觉交流不被阻断。似乎半球间传递系统没有发生根本性的重组，因为术后多年，这些相同的缺陷仍然存在，且以某种方式没有得到补偿。

每个半脑的侧化才能似乎存在很大的差异。虽然右半球经常表现出一些语言才能，但并非所有裂脑人的右半球都有语言技能。同样，通常仅存在于右半球的视觉空间技能经常双侧表示，有时仅在左侧语言半球表示。甚至有证据表明连合系统本身在传递什么以及在哪里传递方面存在差异。参见“大脑”；“心理学”。

# 铁杉属

松科*Tsuga*属，特征为扁平的针叶，针状叶下方有两条白线，具有明显的短叶柄。球果小而下垂。

东铁杉（*T. canadensis*）分布于加拿大东部、五大湖各州和阿巴拉契亚山脉。叶片微具齿是该物种的特征。木材坚硬且强韧，用于建筑、箱子、板条箱和纸浆。树皮是单宁的主要国内来源之一。东铁杉是一种常见的观赏树。

卡罗莱纳铁杉（*T. caroliniana*），一种发现于阿巴拉契亚山脉南部的物种，针叶全缘，有时作为观赏树种植。西铁杉（*T. heterophylla*）生长在极北部和阿拉斯加。其针叶类似于东铁杉，但下方的白线不那么明显。它是一种重要的木材树种，用途与东铁杉相似。**[A.H.G.R.P.D.]**

# 血红蛋白

脊椎动物红细胞中的携氧分子。这种蛋白质占红细胞固体成分的95%以上。它负责将氧气从肺运输到身体的其他组织，并参与将二氧化碳反向运输。

每个血红蛋白分子由四个较小的亚基组成，称为多肽链。这些是血红蛋白的蛋白质或珠蛋白部分。血红素基团，即铁卟啉复合物，与每个多肽亚基结合，负责一个氧气分子的可逆结合。多肽链和血红素在骨髓的有核红细胞中合成并结合。随着这些细胞成熟，核碎片化，这些现在称为网织红细胞的细胞开始在血液中循环。当网织红细胞中形成足够的血红蛋白后，所有核物质消失，该细胞随后被称为红细胞。每个血红蛋白分子的寿命与红细胞一样长，平均寿命为120天。参见“卟啉”。

正常成年男性和女性每100毫升血液中分别含有约16和14克血红蛋白；每个红细胞含有约$29 \times 10^{-12}$克血红蛋白。红细胞通常占全血体积的40-45%。

血红蛋白与氧气的可逆结合可由下式所示的反应表示。每一步的平衡常数不同，因为一个血红素基团上的氧分子改变了其他血红素对额外氧气分子的亲和力。氧合过程中结合亲和力的这种改变称为血红素-血红素相互作用，这是由于分子的三维结构发生微小变化所致。

血红蛋白与一氧化碳的可逆结合强度约为与氧气结合的210倍。这种对一氧化碳的强亲和力解释了该气体的中毒作用。

血红蛋白通过蛋白质的自由氨基基团结合二氧化碳，而不是通过血红素基团。与二氧化碳的可逆结合促进了该气体的运输。血红蛋白还通过可逆反应充当缓冲剂，与氢离子反应。氧合血红蛋白的酸性比脱氧血红蛋白更强。脱氧血红蛋白对氢离子的额外结合促进了组织二氧化碳向碳酸氢根离子的转化，从而增加了血液可运输的二氧化碳总量。参见“血液”；“呼吸”。**[R.T.J.]**

# 血友病

一种罕见的遗传性血液疾病，特征是出血过多。它几乎完全限于男性，作为性连锁孟德尔隐性特征传递，从受影响的男性通过未受影响或轻微受影响的女儿再次出现在孙子身上。维多利亚女王是一个携带者，她的几个男性后代受到影响。参见“人类遗传学”；“性连锁遗传”。

经典血友病（血友病A）是由于抗血友病因子或因子VIII缺乏所致，这是一种通常以微量存在于血液中且对正常纤维蛋白形成至关重要的凝血因子。血友病B是一种类似的性连锁出血性疾病，影响男性，其特征是另一种血液凝血因子，因子IX的缺乏。它只能通过实验室测试与密切相似的血友病A区分开来。其他凝血因子的遗传缺乏可能引起类似血友病的出血疾病，但它们作为常染色体显性或隐性特征遗传。

治疗包括静脉注射从人体血浆制备的浓缩因子VIII或IX，它们在分别管理血友病A和B方面非常有效。参见“血液”；“出血”。**[C.H.O.]**
