**宇宙背景辐射。** 最短的射电波长会被阻挡，因此对宇宙微波背景辐射高频端的研究——即这种在约 3 K 温度下的热黑体辐射，也是大爆炸的标志——必须从高空气球、火箭或卫星上进行。宇宙背景探索者（COBE）卫星在 1989 年至 1991 年间进行了此类研究，并做出了具有历史意义的发现；威尔金森微波各向异性探测器（WMAP，2001 年发射）也做出了类似的贡献。参见**宇宙背景辐射**。

**红外天文学。** 在比约 2 微米（即可见光波长的约四倍）更长的红外波长下，大气层几乎是不透明的，因此再次需要利用气球、火箭和卫星进行天文学研究。1983 年，美国将红外天文卫星（IRAS）送入近地轨道，在接下来的 2 年里，它在四个不同的红外波长波段内进行了首次全天巡天。欧洲空间局的红外空间天文台（ISO，1995–1998）旨在对天空的选定区域进行详细研究，其角分辨率更好，波长覆盖范围更宽，成像和光谱能力更强，且灵敏度高于 IRAS。2003 年，美国国家航空航天局（NASA）发射了斯皮策望远镜，这是其四大太空天文台中的最后一座，其红外阵列比 ISO 上的阵列大得多且灵敏度更高。参见**红外天文学**。

**紫外天文学。** 由于地球大气层对波长短于约 310 纳米的紫外线（UV）是不透明的，紫外天文学不得不等待太空时代的到来。在 20 世纪 60 年代和 70 年代初，天文学家利用搭载在 OSO（轨道太阳观测站）和 QAO（轨道天文观测站）卫星系列上的多个紫外探测器系统，以及随后的 IUE（国际紫外探测器）卫星，探索了天体物理问题。1990 年哈勃太空望远镜的发射使一种强大得多的工具变得可用。1990 年 6 月，NASA 为德国发射了 ROSAT 卫星，并使用了由英国研究人员提供的大视场相机进行首次紫外全天巡天。第一颗专用的紫外天文学卫星，极紫外探测器（EUVE），于 1992 年发射，并运行至 2001 年 1 月。ROSAT 上的大视场相机紫外望远镜和 EUVE 上的紫外望远镜在 6–80 nm 波长范围内的几个波段中探测到了约 400 个远紫外天体。EUVE 还使得能够测量各种天体的紫外光谱，从相对较近的恒星（如半人马座 α 星）的日冕，到室女座星系团中活动星系 M87 周围意外明亮的紫外晕。在银河系天体的紫外观测（包括成像和光谱）方面的重大飞跃是随着哈勃太空望远镜而来的。即使在其初始视野模糊的情况下，该仪器也通过获得比之前任何仪器都高的紫外空间分辨率而做出了无数发现。它对超新星 SN1987A 的成像能够分辨出明亮超新星扩散的弹射环以及由大质量恒星抛出的假设气体壳层；随着修复后的哈勃太空望远镜具有增强的紫外灵敏度，对类星体和遥远星系的性质的研究成为可能。参见**星系，河外**；**超新星**。远紫外谱线探测器（FUSE，1999 年发射）通过使用高分辨率光谱学，在 90.5–118.7 纳米波长区域研究广泛的天体物理问题。FUSE 的波段补充了哈勃太空望远镜提供的频谱覆盖范围，后者仅延伸至约 1,150 埃。

**X 射线天文学。** X 射线天文学只能在地球大气层之上进行。第一颗小型天文卫星（SAS 1；1970 年），名为 Uhuru，携带了两个比例计数 X 射线探测器。OSO 卫星也携带了宇宙 X 射线探测器（与 Uhuru 相似的比例计数器），并为详细理解单个 X 射线源做出了巨大贡献。荷兰天文卫星（ANS；1974 年）是第一个 X 射线天文台。它和 SAS 3 卫星（1975 年）都包含多种 X 射线探测器。高能天文观测站（HEAO）卫星（1977 年）实现了 X 射线天文学灵敏度的重大提升。HEAO 2 卫星，即爱因斯坦天文台（1978 年），提供了第一个天体 X 射线图像，并探测到了数千个新源。欧洲卫星 EXOSAT（1982 年）为爱因斯坦天文台提供了后续 X 射线成像和光谱观测。它对极低通量 X 射线源特别敏感，尽管其总收集面积远小于爱因斯坦天文台。ROSAT（1990–1999 年）是一个相对较大的 X 射线望远镜，其灵敏度大约是爱因斯坦天文台的两倍。ROSAT 进行了首次全天成像 X 射线巡天，发现了 60,000 多个源，因此对于光学天文学来说，其揭示程度堪比帕洛玛巡天。全天巡天之后，进行了指向观测。1993 年，日本 X 射线项目发射了 ASCA，这是第一个能量响应延伸至 8 keV 的 X 射线成像望远镜。这是一个重大突破，因为它允许对天体在电离发射线 X 射线波段中的成像和光谱进行观测。NASA 的 Rossi X 射线定时探测器（RXTE，1995 年发射）携带了三个覆盖 2–200 keV 宽能量范围、提供精确 X 射线源定时间和测量、并能检测短至 10–100 微秒发射的望远镜仪器。意大利-荷兰 X 射线卫星 BeppoSAX（1996 年）以其非常宽的光谱覆盖（0.1–300 keV）及其低能和高能仪器的均衡性能为特征。它发现了伽马射线暴的 X 射线余辉，使其能够被更精确地定位，并允许后续无线电和光学观测确认这些爆发具有宇宙学起源。钱德拉 X 射线天文台（CXO；1999 年），NASA 的第三个大型天文台，具有任何在轨 X 射线天文台最高的空间分辨率和能量分辨率。在其 50 英尺长（15 米）望远镜的焦点处有两个探测器：先进 CCD 成像光谱仪（ACIS）和高分辨率相机（HRC）。ACIS 使用 10 个电荷耦合器件（CCDs）来测量每个光子的能量、位置和到达时间，而 HRC 使用微通道板。参见**电荷耦合器件**。欧洲空间局的 X 射线多镜像天文台，更名为 XMM-Newton（2000 年），携带三台先进望远镜，每台包含 58 个同心镜，嵌套以提供尽可能大的收集面积。其高度偏心轨道 enables 长时间、不间断的观测。参见**X 射线天文学**。

**伽马射线天文学。** 比 X 射线能量更高的伽马射线仍然无法穿透地球大气层。1972 年发射的 SAS 2 首次确立了伽马射线点源（如蟹状星云和船帆座脉冲星）在约 100 MeV 能量下的存在。一项更灵敏的后续任务 COS-B 由欧洲空间局于 1975 年发射。康普顿伽马射线天文台（CGRO；1991–2000 年），NASA 的第二个大型天文台，携带了四个高灵敏度伽马射线探测器：EGRET（高能伽马射线实验望远镜，一个比 COS-B 上的更大且更灵敏的火花室），覆盖 30 MeV–10 GeV 的能量范围；COMPTEL（康普顿望远镜），一个对探索不足的 1–30 MeV 敏感的康普顿散射望远镜
