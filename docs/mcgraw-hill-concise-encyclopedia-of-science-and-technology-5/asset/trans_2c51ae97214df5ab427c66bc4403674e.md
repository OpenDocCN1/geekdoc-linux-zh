
# 892 阻燃

在反应机理中起重要作用。参见**自由基**。

只涉及一种反应物的总反应称为化学分解；例如，臭氧分解为氧气。分解火焰通常只是化学火焰，而非燃烧火焰。

燃烧火焰大致分为预混火焰和扩散火焰。当燃料和氧化剂在燃烧前混合时，发生预混火焰。当燃料和氧化剂同时混合并燃烧时，发生扩散火焰。部分预混的中间情况在理论和实践上受到的关注相对较少。火焰还可根据形状、行为（静止或运动）、流动状态（层流或湍流）、浮力状态（强制对流或自然对流）、是否有围护（如燃烧室壁面）以及流动复杂性（如旋流和交叉流）进行分类。[H.A.Bac.]

# 阻燃

对材料进行处理，使其不支持燃烧。虽然纸张、纤维板、纺织品和木材等纤维素材料无法处理得永不因长期接触火而毁坏，但可通过处理减缓火势蔓延，并在移除点火条件后自熄。已有多种方法被提出用于纤维素制品的阻燃。对于纸张和木材制品，最简单且最常用的方法之一是浸渍各种可溶性盐，如硫酸铵、磷酸铵、硫酸氢铵、硼砂和硼酸。通常使用特殊配方，以最大限度减少这些处理对纸张颜色、柔软度、强度、耐久性及其他性能的影响。某些应用中，由于盐分保持可溶性且遇水易渗出，该处理方法并不适用。通过添加乳胶、漆料或防水剂，可获得有限的抗渗出能力。在某些情况下，通过使阻燃剂与纤维素纤维发生反应（例如，尿素和磷酸铵），可赋予阻燃剂一定的抗渗性。在造纸过程中掺入不溶性阻燃剂、以乳液、分散体或有机溶剂形式涂覆不溶性材料，或在多浴处理中使其在纤维上沉淀或与纤维反应，也可获得抗渗阻燃效果。所涉及的物质与用于阻燃纺织品的类型相同，包括金属氧化物或硫化物及卤代有机化合物。参见**燃烧**；**纺织化学**。[T.A.L.]

# 闪光焊

一种用于批量生产的电阻焊形式。焊接电路由低压大电流电源（通常为焊接变压器）和两个夹电极（一个固定，一个可移动）组成。

将待焊的两个金属件紧密夹持在电极中，并移动其中一个直至与另一个接触，形成紧密接触。给变压器通电后，大电流流经两个紧密接触的小面积区域。闪光开始，可移动工件需以适当速率加速，以维持闪光增强。在待焊的两边缘间建立适当的热梯度后，突然施加顶锻力完成焊接。该顶锻力挤出熔渣、氧化物、熔化的金属及部分较软的塑性金属，在受热金属的较冷区域形成焊缝。参见**电阻焊**。[E.J.I.]

# 平板显示器件

一种电子显示器件，其中由大型正交阵列的显示元件（如液晶或电致发光元件）构成平坦屏幕。

“平板显示”一词实际上是误称，因为这是电视机和计算机显示器的基本特征。阴极射线管是常见显示器件。光通过阴极发光过程产生，即高能电子束扫过涂覆无机荧光粉的屏幕。阴极射线管需具有一定深度，以使电子束能被磁或静电方式扫描整个屏幕。参见**阴极射线管**；**阴极发光**；**电子显示**。

要使平板显示技术成功，至少须与阴极射线管的基本性能相当，即具备：（1）全彩色，（2）全灰阶，（3）高效率与高亮度，（4）可显示全动态视频，（5）广视角，（6）宽工作条件范围。平板显示还应提供以下优势：（1）薄与轻，（2）良好线性，（3）对磁场不敏感，（4）无X射线产生。这四项特性在阴极射线管中均无法实现。

平板显示可分为三种类型：透射式、发射式和反射式。透射式显示具有背光，图像由空间光调制器形成。透射式显示的功率效率通常较低；用户只能看到背光中很小比例的光。发射式显示仅在被激活的像素处产生光。发射式显示的效率本应高于透射式，但由于发光过程效率低，大多数发射式与透射式平板显示亮度相近。反射式显示反射环境光，效率最高。在环境光非常明亮（如阳光直射）的场合尤为适宜，但在弱光环境中表现不佳。

大多数平板显示以XY矩阵寻址，行与列的交点定义单个像素（见图示）。矩阵寻址为全数字显示提供了可能。当前可用的平板显示器件，从用于手持系统的1.25厘米（0.5英寸）对角线显示，到125厘米（50英寸）对角线等离子显示，种类繁多。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_901_0.png)

目前，大多数商业化生产的平板显示器件为液晶显示（LCD）。平板显示性能的基准是有源矩阵液晶显示（AMLCD）。大多数便携式计算机使用AMLCD。竞争的平板显示技术包括电致发光显示、等离子显示面板、真空荧光显示和场致发光显示。电致发光显示因其坚固性和宽工作温度范围，常用于工业和医疗应用。等离子显示面板最常见为大型面板显示，而真空荧光显示用于信息含量较低的应用，如家电或汽车上的显示。场致发光显示是这些平板技术中最新的。[B.E.G.]

# 黄酮类化合物

由γ-吡喃衍生的大型天然植物产物类别。所有黄酮类化合物，源自2-苯基苯并吡喃（**结构1**）或3-苯基苯并吡喃（**2**），均可分为10类：

![](img/2cf7974cd6027baa297e5cd95d3d6d43_902_0.png)

查尔酮、黄酮、黄烷酮、黄酮醇、花色苷元（花色素离子）、黄烷-3-醇（儿茶素）、黄烷-3,4-二醇（原花青素）、二黄酮、寡聚黄酮、异黄酮和奥黄酮。它们在杂环（C环）的氧化程度或取代模式上有所不同。

已从植物中分离出1300多种不同的黄酮类化合物。同一类中的不同黄酮彼此差异在于羟基、甲氧基和糖取代基的数量与位置。通常，黄酮类化合物在植物中以糖苷形式存在，己糖如葡萄糖、半乳糖、鼠李糖和戊糖如阿拉伯糖、木糖为最常见糖。糖可单独或相互结合连接。糖苷化使这些化合物溶于水，并能积累于植物液泡中。参见**糖苷**。

现有少量报告表明，黄酮类在表皮组织中积累，其中约70%位于上表皮，30%位于下表皮。液泡可能是细胞内黄酮类最终积累场所，但黄酮类合成发生在细胞质中。

黄酮类化合物曾被视为代谢副产物，但现已知其中一些具有生理活性。例如，已发现多种黄酮类化合物是形成固氮根瘤的宿主特异性信号分子。此外，黄酮类与抵御紫外线辐射有关。黄酮类生成的酶系统由紫外照射诱导。黄酮类积累于表皮细胞液泡，在280~380 nm关键波段（紫外线造成伤害的区域）强烈吸收光。最后，许多植物在微生物入侵时合成植物防御素。豆科植物产生的大部分植物防御素为异黄酮，且每种植物似乎产生特定化合物。

由于色泽鲜艳，从深红经紫色至深蓝，花色苷是最明显的黄酮类化合物。花色苷在花朵与果实中最明显，但也存在于根、茎、叶、种子及其他植物部位。积累的花色苷与类胡萝卜素共同构成秋季多彩的特征。植物遭受其他胁迫（如紫外线辐射、昆虫伤害、机械损伤或异常金属浓度）时也会产生花色苷。参见**植物代谢**。[G.H.H.]

# 味

夸克的六种不同种类。所有强子物质均由夸克组成，夸克是物质最基本的组成单元。六种不同味标记为u、d、s、c、b和t，对应上、下、奇、粲、底和顶夸克。夸克均为自旋- $\frac{1}{2}$ 费米子。u、c和t味携带正电荷，电量大小为电子电量的三分之二；d、s和b味携带负电荷，电量大小为电子电量的三分之一。不同味的夸克质量差异巨大，从最轻的u夸克（质量约为$5 \mathrm{MeV} / c^2$，其中c为光速，约等于10个电子的质量）到质量大35,000倍或$175 \mathrm{GeV} / c^2$的顶夸克（约等于一个金原子质量）。任意味的夸克还由称为颜色的三个额外量子数表征；红、绿、蓝。每个夸克都有携带对应反色的反夸克。参见**反物质**；**颜色（量子力学）**；**基本粒子**；**夸克**。[U.E.]

# 亚麻

亚麻植物（*Linum usitatissimum*）是两种产物的来源：用于产亚麻籽油的亚麻籽和用于亚麻制品的纤维。具有两种不同生长类型的植物分别用于籽与纤维生产。

纤维亚麻要求肥沃、排水良好且充分整地的土壤，以及凉爽湿润的气候。亚麻纤维最著名的用途是制作精细亚麻织物；其他用途包括亚麻线、亚麻绳、毛巾和帆布。纤维亚麻籽用于再播种和榨油。俄罗斯是主要的亚麻纤维生产国，但世界最佳纤维产自比利时及其邻近国家。大多数爱尔兰亚麻由比利时生产的纤维制造。参见**天然纤维**；**纺织品**。

籽亚麻是亚麻籽油的来源。亚麻籽油的主要用途是制造保护性涂层——油漆、清漆和漆。它亦用于油毡、印刷油墨、 patent及仿制皮革，以及金属铸造中制造砂芯的核心油。榨油后残留的亚麻籽粕用作高蛋白牲畜饲料。大量洁净（无杂草）籽亚麻秸秆用于生产高等级纸张。该纸用于制造卷烟纸及其他精细纸张。世界主要籽亚麻生产国为阿根廷、加拿大、印度、俄罗斯和美国。[E.G.N, J.O.C.w.]

# 柔海胆

已灭绝的柄状或爬行海胆下纲，包含约50个古生代属，时代从奥陶纪至二叠纪。具有柔性靶板，且水管沟开口。五个口板之一充当水筛板。肛门位于短虹吸管端。上位腕自由分枝，内弯形成球形冠（见图示）。圆柱形茎无棘，有时脱落形成爬行成体。参见**海胆纲**；**棘皮动物**。[H.B.F.]
