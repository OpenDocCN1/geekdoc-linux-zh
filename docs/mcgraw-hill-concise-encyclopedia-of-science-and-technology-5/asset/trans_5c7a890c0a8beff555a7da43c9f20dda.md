
## 藻珊瑚目（Alcyonians）

*藻珊瑚目动物*。（a）*Alcyonium palmatum*（依据 Y. E. age 描述），（b）*Dendronephytha* sp.（依据 H. Ulinomii 描述）。

在 *Xenia*（软珊瑚属）和 *Heteroxenia*（异软珊瑚属）中，**水螅体（珊瑚体）**是不可缩回的。息肉基部被许多骨针保护，称为**杯部（calyx）**。参见：藻珊瑚亚纲（ALCYONARIA）；刺胞动物门（COELENTERATA）。[K.A.]

## 藻珊瑚亚纲（Alcyonaria）

硬珊瑚纲（Anthozoa）的一个亚纲。这些刺胞动物通常为群体生活，多为固着性且栖息于潮间带，部分种类生活在极深海域。普通的息肉，即**自养水螅体（autozooid）**，具有八根可运动、可收缩、中空且呈羽状分支的触手。存在八组完整的**肠膜（mesenteries）**，其中背部或**非沟侧（asulcal）**的一对发育最完善，并承载最大、具丰富纤毛的外胚层丝状结构。其余肠膜承载具有许多腺细胞的内胚层丝状结构。纵向**缩肌**在其腹侧或**沟侧（sulcal）**表面发达。口球（stomodome）或咽部，其沟侧边缘具单一**口唇（siphonoglyph）**，由具纤毛的腺上皮覆盖。每个息肉的**胃腔（gastrovascular cavity）**通过复杂的管道系统或**管系（solenae）**相互连通。这些管道贯穿群体的**骨针中胶层（mesogloea）**或**共同组织（coenenchyme）**。骨骼由外胚层细胞分泌的角质物质沉积而成，或由分泌不同形状钙质骨针或骨板的**外胚层骨原细胞（scleroblasts）**形成。肌肉系统发育不特别完善。

息肉的口端称为**水螅体（anthocodium）**。基部，即**水螅柄（anthostole）**，嵌入含有大量变形虫样细胞和骨原细胞的共同组织中。

藻珊瑚亚纲的特征是具有高度发达的口唇，用于在群体中循环水流。藻珊瑚亚纲动物为雌雄异体或雌雄同体。性腺在内胚层肠膜丝中成熟。雌性息肉通过无性生殖从管系系统或亲代体壁上出芽形成。*Pennatulae*（海笔属）和其他一些种类具有**二型性（dimorphic）**。**管水螅体（siphonozooid）**比自养水螅体小。它没有触手，或触手退化且通常不育。参见：硬珊瑚纲（ANTHOZOA）；刺胞动物门（COELENTERATA）。[K.A.]

## 参宿四（Aldebaran）

一颗凉爽的红巨星，位于金牛座显著位置。其红色外观恰当地代表了“金牛之眼”。在距离地球 20 秒差距（65 光年）处，参宿四，或称金牛α（α Tauri），是距离太阳最近（也是最亮）的巨星之一。该星是 K 型巨星的典型代表，这是一种非常常见的演化晚期恒星，其能量来源于被薄层氢燃烧壳层包围的核心中氦的热核燃烧。其 K5III 光谱型对应于 6700°F（4000 K）的有效温度和约为太阳半径 40 倍的半径。其光度几乎是太阳的 150 倍，且作为 K 型巨星的典型特征，其亮度仅有适度的变化。参宿四伴有一个长周期双星系统，其伴星是一颗凉爽的矮星，亮度比该巨星暗约 10 万倍。参见：双星（BINARY STAR）；巨星（GIANT STAR）；恒星（STAR）；金牛座（TAURUS）。[H.A.M.]

## 醛（Aldehyde）

一类有机化合物的通式表示为 RCHO。甲醛是最简单的醛，其化学式为 HCHO，其中 R 为氢。对于所有其他醛，R 为烃基，可能被卤素或羟基等其他基团取代（见表）。由于其高化学反应活性，醛是制造树脂、增塑剂、溶剂、染料和药物的重要中间体。

| **化合物** | **化学式** |
| :--- | :--- |
| 甲醛 | HCHO |
| 乙醛 | CH$_{3}$CHO |
| 乙醛（缩合物） | CH$_{3}$CHOHCH$_{2}$CHO |
| 丙醛 | C$_{2}$H$_{5}$CHO |
| 正丁醛 | CH$_{3}$CH$_{2}$CH$_{2}$CHO |
| 异丁醛 | (CH$_{3}$)$_{2}$CHCHO |
| 丙烯醛 | CH$_{2}$=CHCHO |
| 巴豆醛 | CH$_{3}$CH=CHCHO |
| 氯醛 | CCl$_{3}$CHO |
| 水合氯醛 | CCl$_{3}$CH(OH)$_{2}$ |
| 苯甲醛 | C$_{6}$H$_{5}$CHO |
| 肉桂醛 | C$_{6}$H$_{5}$CH=CHCHO |

在室温下，甲醛为无色气体。其他低分子量的醛为无色液体，具有特征性且略带酸性的气味。不饱和醛丙烯醛和巴豆醛具有强烈的催泪性。醛的重要反应包括氧化、还原、羟醛缩合、Cannizzaro 反应以及与含氮化合物的反应。

由于醛作为化学中间体的重要性，已开发了许多工业和实验室合成方法。这些方法中较为重要的包括伯醇的催化脱氢、伯醇的氧化、烯烃的氧化以及烯烃的氢甲酰化。参见：甲醛（FORMALDEHYDE）。[P.E.]

## 赤杨（Alder）

一种落叶乔木，学名 *Alnus rubra*，生长范围从阿拉斯加到加利福尼亚北部及爱达荷州东部。其特征包括具柄的芽、单叶以及干燥的圆锥状椭圆形果实。它与大叶枫共同成为太平洋西北部主要的硬阔叶树种，该地区大多数具有商业价值的树木均为针叶树。其木材用于制作家具。参见：桦木科（FAGACEAE）。[A.H.G./K.P.D.]

## 醛固酮（Aldosterone）

一种在肾上腺提取物中分离出各种结晶态类固醇物质（如皮质醇和皮质酮）后，生物活性无定形组分中发现的类固醇激素。在溶液中，醛固酮以**醛式（aldo）**和**内半缩醛式（lactol）**的平衡混合物形式存在（见插图）。

*醛固酮在平衡混合物中的两种结构，（a）醛式和（b）内半缩醛式。*

醛固酮的主要功能是调节电解质代谢，即促进钠的保留并增强钾的排泄。醛固酮是在此类代谢中作用最强劲的激素之一。参见：肾上腺（ADRENAL GLAND）；类固醇激素（HORMONE, STEROID）。[C.H.L.]

# 苜蓿（Alfalfa）

世界上最有价值的饲料豆科植物，学名 *Medicago sativa*，又称紫花苜蓿。它被种植用于生产干草、放牧和青贮饲料。苜蓿干草（在晚蕾期或初花期收割并妥善干燥）作为牲畜饲料备受推崇，其蛋白质含量为 17–24%，且是某些维生素和矿物质的良好来源。参见：牧草（FORAGES）。

苜蓿是一种草本多年生豆科植物，特征是具有深厚的直根系，分支程度不一。直立或半直立的茎秆上叶片繁茂，高度可达 2–3 英尺（0.6–0.9 米）。单个木质化冠根长出的茎数量可从仅几根到 50 根以上不等。当老茎成熟或被割除、啃食后，新茎便会发育。花朵着生在腋生的总状花序上，花序的大小和花朵数量差异很大。花色主要为紫色或蓝紫色，但也可见白色、奶油色、黄色、绿色、淡紫色和红紫色。果实为豆荚，在 *M. sativa* 中通常呈螺旋卷曲状，而在 *M. falcata*（镰荚苜蓿）中呈新月形或直形。种子细小，颜色从黄色到棕色不等。

苜蓿的繁殖主要以异花授粉为主。授粉主要由蜜蜂完成。晴朗明亮的白天、凉爽的夜晚、丰富的蜜蜂种群以及干燥的收获天气有利于种子生产。

苜蓿广泛适应温带和亚热带气候及土壤。其种植范围从阿根廷和新西兰的南纬 40° 延伸至加拿大、瑞典和俄罗斯的北纬 60°。它并不太适应潮湿的热带环境。

深厚肥沃的壤土最为适宜，良好的排水至关重要。为获得高产，需水量很大，在依赖自然降雨的地区，水分不足往往是严重的限制因素。

美国认可超过 80 个改良苜蓿品种具有种子认证资格。这些品种可追溯至三个基本品系：*M. sativa*（紫花、窄冠、直立）；*M. falcata*（黄花、半匍匐、深根冠及分枝根）；以及一个中间类型，常被称为杂种型（viregiated），是由 *M. sativa* 和 *M. falcata* 杂交育成的。[C.H.H.]

# 阿尔芬波（Alfvén waves）

在存在磁场的导电流体或气体中传播的振荡。

磁流体力学研究磁场对电导率优良的流体和气体的影响。熔融金属通常具有良好的导电性，并表现出磁流体力学现象。

波是磁流体力学的一个特别重要的方面。它们将能量和动量从一个地方传输到另一个地方，因此在宇宙和实验室等离子体的加热和加速中可能发挥关键作用。波是一种传播的振荡。如果存在波，流体的特定单元将围绕平衡位置发生振荡。该单元发生振荡是因为存在恢复力，倾向于使其返回平衡位置。在普通气体中，唯一的恢复力来自气体的热压强。这导致一种波模：声波。如果存在磁场，则有两个额外的恢复力：与磁力线张力相关的力，以及与磁场能量密度相关的压力。这两个恢复力导致两个额外的波模。因此存在三种磁流体力波波模。然而，每个恢复力并不一定对应唯一的波模。换句话说，每个波模可以涉及多个恢复力。因此，仅涉及热压强的普通声波并不作为磁流体力学中的模式出现。这三种模式具有不同的传播速度，分别命名为快模（F）、慢模（S）和中间模（I）。中间模有时被称为阿尔芬波，但一些科学家将这三种磁流体力学模式统称为阿尔芬波。中间模也称为剪切波。

一些科学家将快模命名为磁声波（magnetosonic mode）。

## 基本方程

使用磁场中导电流体运动的磁流体力学方程，结合麦克斯韦方程组和欧姆定律来分析磁流体力波波模。参见：麦克斯韦方程组（MAXWELL’S EQUATIONS）。

可以将欧姆定律与法拉第电磁感应定律结合起来。所得方程称为磁流体力学感应方程，它是“冻结”定理的数学表述。该定理指出，可以认为磁力线被冻结在流体中，因此与磁力线速度相同的流体在磁力线上产生质量负载。这种质量负载的效果是使波减速，使其传播速度远小于光速（真空中的波速）。参见：电磁辐射，光（ELECTROMAGNETIC RADIATION, LIGHT）。

不幸的是，基本方程过于复杂，难以充分利用，因为其中一些方程是非线性的；也就是说，它们包含待求量的混合乘积。非线性磁流体力学仍处于起步阶段，已知只有少数几个特解。为了得到可解的方程，科学家接受只处理小振幅波的局限，并对方程进行线性化，从而消除未知量的乘积。幸运的是，仍可以从这一过程中学到很多：所得方程具有在时间和空间上呈谐波变化的解。参见：简谐运动（HARMONIC MOTION）。
