# 辉石族矿物

一系列具有通式 Mg$_{2n+1}$(SiO$_{4}$)$_{n+1}$(OH)$_{2}$ 的镁岛状硅酸盐矿物同系物。已知物种包括诺贝石（n = 1）、软镁硅石（n = 2）、辉石（n = 3）和斜辉石（n = 4）。它们都基于六方最密堆积的氧和氟原子。Mg 原子占据八面体间隙，Si 原子占据四面体间隙。诺贝石和辉石是正交的；软镁硅石和斜辉石是单斜的；水镁石是三方的。这些矿物的锰类似物以粉红色颗粒的形式存在于由史前硅质碳酸盐岩和沉积锰氧化物衍生的变质锰矿中。其他可出现的替代阳离子包括 Fe$^{2+}$、Ca$^{2+}$、Al$^{3+}$ 和 Ti$^{4+}$。

辉石族矿物具有相似的物理性质。光泽为树脂状，颜色通常为黄色、棕色、橙色或红色。纯合成 Mg 端元是无色的。硬度为莫氏硬度 6–6½，比重为 3.1–3.2。它们很难在视觉上区分，需要 X 射线衍射、电子探针或光学技术。它们存在于区域结晶大理岩中，通常是与铁矿相关的硅卡岩矿物。参见 硅酸盐矿物。 [PB.M]

# 饥饿

该术语最常用来指伴随食物需求的自觉感受；然而，对该主题的研究已扩展到对食物摄入整体控制的考量。更具体地说，关于饥饿问题的实验工作关注的是引起饥饿感的感官线索，决定何时及摄入多少食物的生理机制，以及控制食物选择的机制。

食物消耗基本上受机体营养状态控制。食物剥夺导致进食，而摄入食物物质终止饥饿感。问题在于确定哪些生理过程随营养状态定量变化，并查明这些变化是否可以通过神经系统检测到，从而引发和终止食物消耗。

血糖水平比任何其他因素受到更多关注，可作为典型案例。血糖浓度确实以一般方式随着食物周期的周期性适当变化。然而，对正常生活中血糖变化的详细分析表明，血糖浓度与饥饿之间的关系并不足够紧密，以至于这种单一的体液因素能够以任何简单直接的方式控制饥饿。对更局部组织利用食物的评估证明是解决这一问题的更有希望的方法。现在有一些证据表明肝脏状态在进食控制中起着关键作用。肝脏糖原的剥夺刺激进食；其在实验对象（如大鼠和兔子）中的补充则终止进食。参见 碳水化合物代谢； 肝脏。

已识别出许多终止进食的刺激物。在食物剥夺的动物中，减少细胞水或血浆液体抑制进食。胃扩张以及向肠道和体循环（尤其是静脉肝循环）输注营养物质也会减少进食。营养物质吸收进入肠道产生的饱腹感可能部分由肠道激素胆囊收缩素介导。胆囊收缩素可能有效是因为它减少了食物通过胃的速率。过去关于进食起始和终止的离散神经中枢的观念已被放弃，因为进食行为的复杂性及其相应的神经复杂性已得到更广泛的认可。

# 腐殖质

土壤中无定形的、通常深色的胶体物质，代表来自植物、动物和微生物的有机质组分中最抗分解的复合物。

腐殖质由已失去原始结构的有机质残留物组成，这些残留物在简单成分快速分解后形成，并包括合成的细胞物质以及微生物的副产品。它不是一种确定的物质，且处于持续变化中，通过缓慢分解消失，并不断通过残留物质的结合而更新。随着这些过程之间的平衡，腐殖质虽然不是静态的，但在特定土壤中其性质和数量保持相对均匀。它构成了稳定物质的储存库，赋予土壤有益物理、化学和生物特性。肥沃的土壤富含腐殖质。

某些特定食物物质的减少会引发对该所需物质增加的食欲。这种所谓的特异性饥饿行为已通过在儿童和所研究的低等动物中的许多物质（如盐、钙、脂肪、蛋白质和某些维生素）的实验得到证实。目前很清楚，只有在盐剥夺的动物中，对盐的饥饿感在动物学会盐摄入的有益后果之前才出现。对矿物质、蛋白质和维生素的特异性饥饿感仅逐渐出现，并反映动物学习到某些食物不再有益，甚至可能有害。参见 第一和第二食欲。 [E.M.B]
