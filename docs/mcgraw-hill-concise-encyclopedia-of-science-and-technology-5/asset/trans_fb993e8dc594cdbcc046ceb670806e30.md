
醋酸纤维素和聚乙烯醇。在高级烯烃、芳香烃、酮类和醇类的氧化过程中也会产生少量的乙酸。参见氧化工艺；木材化学品。

纯乙酸与水、乙醇、乙醚和四氯化碳完全混溶，但不溶于二硫化碳。在水溶液中，乙酸是典型的弱电解质酸 ($K_a = 1.8 \times 10^{-5}$)。乙酸能中和许多氧化物和氢氧化物，并分解碳酸盐生成乙酸盐，这些盐被用于纺织印染和后整理、作为颜料以及作为农药；例如铜绿、白铅（碱式碳酸铅）和巴黎绿。参见醋。[F.W.]

## 丙酮

一种化学化合物，$CH_3COCH_3$。一种无色、具有醚味的液体，它是脂肪族酮类同系物的第一个成员。其物理性质包括沸点 $56.2^\circ C$ ($133.2^\circ F$)，熔点 $-94.8^\circ C$ ($-138.6^\circ F$)，以及比重 0.791。

丙酮用作纤维素醚、醋酸纤维素、硝酸纤维素和其他纤维素酯的溶剂。醋酸纤维素从丙酮溶液中纺丝。基于纤维素酯的漆料溶于包括丙酮在内的混合溶剂中。[DA.S.]

## 乙酰胆碱

一种天然存在的季铵阳离子酯，化学式为 $CH_3COCH_2CH_2N(CH_3)_3^+$，在神经系统功能中起重要作用。乙酰胆碱的巨大重要性源于其作为胆碱能神经元神经递质的角色，这些神经元支配许多组织，包括平滑肌和骨骼肌、心脏、腺体和睾丸。刺激胆碱能神经的效果，例如骨骼肌收缩或心率减慢，结果是由于乙酰胆碱从神经末梢释放。

乙酰胆碱在轴突末端由乙酰辅酶 A 和胆碱在胆碱乙酰转移酶的作用下合成，并以数十万个膜包裹的突触小泡的形式储存于每个末端。当神经冲动到达轴突末端时，轴突膜上的电压门控钙通道打开，细胞内极低浓度的钙离子进入神经末梢。钙离子浓度的增加导致数百个突触小泡与细胞膜融合，将乙酰胆碱排入突触间隙（胞吐作用）。在神经肌肉接头释放的乙酰胆碱可逆地与肌肉终板膜（一种由很短距离与神经末梢分隔开的突触后膜）上的乙酰胆碱受体结合。受体是一种阳离子通道，当两个乙酰胆碱分子结合时打开，允许钠电流进入肌肉细胞并使膜去极化。由此产生的冲动间接导致肌肉收缩。

为了将突触恢复到静息状态，必须迅速将乙酰胆碱从突触中移除。这在部分通过扩散实现，但主要通过水解乙酰胆碱的酶乙酰胆碱酯酶实现。

乙酰胆碱酯酶是一种非常快速的酶：一个酶分子可以在 1 秒内水解 10,000 个乙酰胆碱分子。任何能有效抑制乙酰胆碱酯酶的物质都将具有极高的毒性。[B.B.W.]

## 乙炔

化学式为 $C_2H_2$ 或 $HC \equiv CH$ 的有机化合物。作为炔烃的第一个成员，乙炔是一种液态范围很窄的气体；三相点为 $-81^\circ C$ ($-114^\circ F$)。生成热 ($\Delta H_f^\circ$) 为 $-227$ 千卡/摩尔，乙炔是每碳原子能量密度最高的任何烃类化合物。因此，该化合物能量极丰富，可以分解并产生爆炸力。乙炔曾经是很多化学工业制造的基本化合物。它反应性极强，是其他反应性化合物的多用途来源。

乙炔的供应不依赖于石油液体，因为它可以通过碳化钙 ($CaC_2$) 的水解来制备，而碳化钙可以从石灰 ($CaO$)、木炭或焦炭 ($C$) 中获得。在甲烷产品中，将甲烷 ($CH_4$) 通过加热至 $1500^\circ C$ ($2732^\circ F$) 的区域，通过此反应迅速将气体转化为乙炔，然后迅速冷却。乙炔随后从排气中的氢气中分离出来。

乙炔的主要用途是制造源自 1,4-丁二醇的化合物。后者是通过乙炔与两摩尔甲醛的缩合反应获得的，并转化为丁酮、四丁氧基和火药棉。另外两种产品，氟乙烯和乙烯醚，也是基于乙炔的。

由于生成热和燃烧热非常高，乙炔-氧气混合物会产生极高的温度火焰，用于焊接和金属切割。为此目的，乙炔作为丙酮溶液运输，加压装载在含有不可燃海绵状填充物的气缸中。参见炔烃。[L.A.M.]

## 酸和碱

两类相互关联的化合物，其精确定义随着化学的发展而变化很大。其中一些争议至今尚未解决。

起初，酸仅根据其共同性质定义为具有酸味、溶解许多金属并与碱（或碱类）反应形成盐的物质。一段时间内，人们认为所有酸的共同组成元素是氧，但逐渐清楚的是，如果存在本质元素，那是氢，而不是氧。这种酸的概念证明了大约 50 年是令人满意的。

起初，碱被定义为与酸反应形成盐的物质（它们是盐的“碱”）。碱金属碳酸盐，苏打（碳酸钠）和钾碱（碳酸钾），是众所周知的碱，但很快清楚的是，还有其他碱，主要是氨和胺。

当化合物在水溶液中离解的概念建立起来后，酸被定义为在水溶液中电离出氢离子，$H^+$ 的物质，而碱是被定义为反应生成氢氧根离子，$OH^-$ 的物质。这些定义有时被称为阿伦尼乌斯-奥斯特瓦尔德酸碱理论。它们的使用使得讨论酸碱平衡以及特定酸和碱的强度成为可能。

1923 年，J. N. Brønsted 引入了强大且广泛的酸碱质子理论，并迅速被接受。T. M. Lowry 几乎同时提出了类似的想法，新理论偶尔被称为 Brønsted-Lowry 理论。Brønsted 对酸和碱的定义是：酸是可以作为质子来源的物种；碱是可以接受质子的物种。

与阿伦尼乌斯水溶液理论相比，这仅代表酸定义的微小变化，但极大地扩展了碱这一术语。除了氢氧根离子外，碱现在包括许多中性物种，如氨和胺，以及许多带电物种，如弱酸的阴离子。事实上，每种酸都可以通过失去一个质子生成一种碱。以这种方式相关联的酸和碱被称为共轭酸碱对，表 1 列出了示例。

| | 共轭酸碱对 | |
|---|---|---|
| | 酸 | 碱 |
| 强酸 | H₂SO₄ | HSO₄⁻ | 弱碱 |
| | HCl | Cl⁻ | |
| | H₂O | H₃O⁺ | |
| | HSO₄⁻ | SO₄²⁻ | |
| | HF | F⁻ | |
| | H₂(咪唑)⁺ | CH₃COOH | CH₃COO⁻ | |
| | NH₄⁻ | NH₃ | |
| | H₂O | NO₃⁻ | NO₃⁻ | |
| 弱酸 | C₂H₅OH | OH⁻ | C₂H₅O⁻ | 强碱 |

这与 Brønsted 定义的相比，但路易斯酸的定义要宽泛得多。

M. Usanovich 在 1939 年提出了另一种全面理论，有时被称为正负理论。酸被定义为与碱形成盐、释放阳离子并将自身加到阴离子和自由电子上的物质。碱类似地被定义为释放阴离子或电子并将自身加到阳离子上的物质。到目前为止，该理论接受度很小，这可能是因为定义过于宽泛而不具有很大实用性。参见氢离子。[FA-L; R.H.Boo]

### 酸酐

一类重要的反应性有机化合物，通过酸的正式分子间脱水反应衍生而来。

含有 2 到 12 个碳原子的直链酸的酸酐是液体，沸点高于母体酸。它们在冷水中相对不溶，溶于酒精、醚和其他常见有机溶剂。低级成员具有刺激性、腐蚀性并轻微催泪。来自超过 12 个碳原子的酸以及来自二元酸的环状酸酐是结晶固体。

由于直接从有机酸进行分子间脱水是行不通的，酸酐必须通过间接过程制备。一种通用方法涉及酸盐与酰氯的相互作用。

乙酸酐，最重要的脂肪族酸酐，通过乙醛的空气氧化制造，使用铜和钴的乙酸盐作为催化剂，如反应 (1) 所示。

$$
CH_3CHO + \frac{1}{2} O_2 \xrightarrow{\text{催化剂}} CH_3COOH + \frac{1}{2} CH_3CO \rightarrow (CH_3CO)_2O + H_2O \quad (1)
$$

环状酸酐通过加热丁二酸或戊二酸获得，单独或与乙酸酐或乙酰氯一起。在这些条件下，己二酸首先形成线性的聚合酸酐混合物，单体通过缓慢的高真空蒸馏获得。环状酸酐也通过顺式不饱和二元酸的简单热处理形成；例如，富马酸和戊二酸；以及芳香族 1,2-二元酸，例如，邻苯二甲酸。然而，在商业上，邻苯二甲酸 (1) 和马来酸 (2) 酸酐都是初级产品，分别由萘和苯的气相催化（五氧化二钒）空气氧化形成；在反应温度下，酸酐直接形成。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_21_0.png)

酸酐用于酯的制备。乙酸乙酯和乙酸丁酯（来自丁醇和乙酸酐）是硝酸纤维素漆料的极佳溶剂。高分子量醇的乙酸盐用作塑料和树脂的增塑剂。纤维素和乙酸酐生成乙酸纤维素，用于醋酸人造丝和胶片。酸酐与过氧化钠反应生成过氧化物（乙酸过氧化物具有剧烈爆炸性），用作聚合反应的催化剂以及烯丙基卤化物与烯烃加成的催化剂。在 Friedel-Crafts 反应中，酸酐与芳香族化合物反应，生成如苯乙酮等酮类。

马来酸酐与许多二烯反应生成各种复杂度的氢化芳香族化合物（Diels-Alder 反应）。马来酸酐在商业上用于由多羟基醇制造醇酸树脂。土壤调理剂由马来酸酐与乙酸乙烯酯共聚物的碱性水解制得。

邻苯二甲酸酐和醇形成酯（邻苯二甲酸盐），用作塑料和树脂的增塑剂。与酚类和磺酸缩合，邻苯二甲酸酐生成邻苯二甲酸盐，如酚酞；在与间位二羟基苯在相同条件下，生成茜素染料，例如，荧光素。邻苯二甲酸酐用于制造甘油树脂（来自酸酐和甘油）和制造蒽醌。加热邻苯二甲酸酐与氨生成邻苯二甲酰亚胺，用于 Gabriel 合成初级胺、氨基酸和邻氨基苯甲酸（o-氨基苯甲酸）。与碱和过氧化氢，邻苯二甲酸酐生成单过氧邻苯二甲酸，与过氧化苯甲酰一起用作聚合催化剂，以及用作油、脂肪和其他食用物质的漂白剂。

酸酐与水反应生成母体酸；与醇反应生成酯；与氨反应生成酰胺；与伯胺或仲胺反应，分别生成 N-取代和 N,N-二取代酰胺。参见酰化反应；Diels-Alder 反应；酯。
