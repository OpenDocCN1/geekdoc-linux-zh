

# **摩擦学**

研究相对运动中相互作用表面的科学与技术。它涵盖了表面化学、流体动力学、材料、润滑剂、接触力学、轴承和润滑系统等多种科学和技术学科。通常分为三个分支：摩擦、润滑和磨损。

### **摩擦**
这种现象存在于任何有接触表面相对运动的地方，并且总是阻碍运动。由于没有机械加工的表面是完全光滑的，当表面最初在轻载下接触时，它们仅在微凸体（实际接触面积）处接触。早期的理论将摩擦归因于微凸体的相互嵌合；然而，现在人们已经意识到这种现象要复杂得多。参见**摩擦**。

### **润滑**
当洁净的表面接触时，如果在表面之间引入即使单分子层的外来物质（例如氧化物），其摩擦系数也会急剧下降。对于较厚的润滑剂膜，摩擦系数可以非常小，且不再取决于表面的性质，而只取决于润滑剂的本体性质。最常见的润滑剂是液体和气体，但也可使用固体，如二硫化钼或石墨。参见**润滑**。

### **磨损**
这是指一个物体因与另一个物体摩擦而逐渐损失物质的过程。有许多不同类型的磨损，包括滑动磨损、磨粒磨损、腐蚀和表面疲劳。参见**磨损**。

# **毛霉纲**

子囊菌门子囊菌亚门下的一个多系纲，包含粘质盘目、小菇目、团盘毛霉目和杯毛霉目。参见上文。

无性繁殖通过形成毛孢子（*杯毛霉目*）、节孢子（*小菇目*）、盘囊（*团盘毛霉目*）或变形细胞、包囊孢子或厚壁孢子（粘质盘目）来实现。有性繁殖（结合孢子形成）仅在杯毛霉目中已知，尽管在小菇目中已观察到接合生殖。粘质盘目的菌丝体无隔，但其他三个目的菌丝体通常有隔；小菇目和杯毛霉目会产生带有塞子的隔片，位于透镜状腔内。参见**接合菌**。

# **毛翅目**

昆虫纲的一个水生目，通称为石蛾。成虫有两对脉纹清晰的绒毛翅，长触角，且口器只能舔食液体。幼虫呈蠕虫状，有明显的头部，胸部有三对足，身体末端有一对带钩的足。蛹很脆弱，游离附肢紧贴身体，有一对锋利的上颚（或下颌），用于从茧中切开出口。

毛翅目包含约 10,000 个已描述物种，分为 34 科，分布在世界几乎各个角落。除了新西兰的一种咸水种和欧洲及北美洲的少数苔藓栖息种外，石蛾幼虫生活在淡水中。它们在相对无污染的冷水或流水中大量存在。总体而言，它们构成了此类栖息地生物群的重要组成部分，也是鱼类饲料经济的重要环节。参见**昆虫纲**。

# **三色性**

当某些光学各向异性的透明晶体受到白光照射时，发现该材料的立方体通过三组平行面中的每一组会传输不同的颜色。这种晶体有时被称为三色晶体，该现象被称为**三色性**。这种表达很少使用。如今，如果立方体相对于晶体轴以不同的取向切割，特定晶体中的这些颜色可能显得大不相同。因此，该术语通常被更通用的术语**多色性**所取代。甚至这个术语正被物理上的线二色性或圆二色性所取代，以对应线双折射或圆双折射。参见**双折射，晶体光学，二色性，多色性**。

# **三瘤齿目**

已灭绝的哺乳动物，属于北半球许多晚三叠世、侏罗纪和白垩世动物群的成员。它们在South Hemisphere的记录包括来自非洲的最早侏罗世物种，以及可能归于非洲中侏罗世和南美洲晚白垩世的可疑标本。在所有三瘤齿动物中，齿骨和颧骨构成了下颌与颅骨关节（**颞下颌关节**）至少的一部分。在一些物种中，包括归于哺乳纲的最原始物种，关节骨、方颧骨和方骨也参与了此关节。参见**白垩纪，侏罗纪，三叠纪**。

许多现代分类将三瘤齿目的内容限定为三瘤齿科，并为其他紧密相关的科建立新分组。这反映了一个正在浮现但理解尚浅的最早哺乳动物和先进似哺乳爬行动物（通常但不恰当称为似哺乳爬行动物）之间复杂进化相互关系的图景。参见**动物进化，似哺乳爬行动物**。

三瘤齿科，三瘤齿目的核心科，相对较大（下颌大小约为水貂 *Mustela vison* 的下颌），是欧洲和北美晚侏罗纪哺乳动物群中常见的成员。它们的颞下颌关节完全由齿骨和颧骨形成。

北美最早侏罗纪三瘤齿动物和 *Dinotherium*（巨齿兽）磨牙状牙齿特殊咬合方式的出现，表明后者是未从颞下颌关节中失去方骨和关节骨的三瘤齿动物的一个非常原始的亲戚。另一个以复杂颞下颌关节为特征的原始群，包括*metagnathic*（基颌）和*cervical*（颈椎类），也可能是三瘤齿科的原始亲戚。广颌类（中晚侏罗纪，北美和欧洲）和*Gobiconodon*（中侏罗纪和早白垩纪，北美和亚洲）是三瘤齿样的哺乳动物。这两个科的成员都具有颞下颌关节，相对由齿骨和颧骨形成。*Sinconodon*（早侏罗纪，亚洲），另一种与现代摩根氏齿类大小相当的原始三瘤齿样哺乳动物，具有复杂的颞下颌关节。参见**双齿类；哺乳纲**。

# **平面三角学**

平面三角学主要研究位于平面内的三角形的三条边和三个角之间的关系。

射线是直线的一部分，它从直线上的一点开始，向一个方向无限延伸。射线的起点称为其顶点。如果画出两条具有共同顶点的射线，它们形成一个角。角的一条射线称为始边，另一条称为终边。通过显示从始边到终边的旋转方向和角度来识别形成这个角。如果旋转是逆时针方向，角为正；如果旋转是顺时针方向，角为负。

始边逆时针旋转整整一次直到与其自身重合（1 圈）形成的角，被称为 360 度，写作 360°。因此，一度，1°，是 1/360 圈。一度的 1/60 称为分，写作 1'。

通过使用半径为 r 的圆，可以构造一个角，其顶点位于该圆的中心，其射线在圆上截取的弧长等于 r。这样一个角的度量为 1 弧度。对于半径为 r 的圆，r 弧度的圆心角所对弧长 s 由公式 (1) 给出：

# **触发电路**

一种电子电路，用于生成或修改现有波形，以产生具有快速上升前沿的短脉冲。该波形或触发信号通常用于引发某种弛豫器件（如多谐振荡器）的状态变化。触发电路生成的波形最重要的特征通常是快速前沿。波形的下降部分的确切形状往往次要，但重要的是总弛豫时间不宜过大。诸如阻塞振荡器之类的脉冲发生器，如果生成足够短的脉冲，也可被使用并识别为触发电路。参见**阻塞振荡器；脉冲发生器**。

峰值电路接收脉冲波形的高频分量，导致尖锐的上升和下降沿，因此用作触发电路。最简单的峰值电路形式是图中所示的简单 RC 和 RL 网络。如果对这两个电路中的任意一个施加幅度为 Vs 的陡峭波形前沿，输出将是突然上升后跟随指数衰减。这些电路通常称为微分电路，因为如果 RC 或 R/L 时间常数足够小，输出是输入波形导数的粗略近似。

高度欠阻尼或振荡的电路，当提供阶梯或脉冲输入时，常被称为振铃电路。当用于场效应管或双极型晶体管的输出时，该电路可作为触发电路使用。参见**波形整形电路**。

# **甘油三酯**
