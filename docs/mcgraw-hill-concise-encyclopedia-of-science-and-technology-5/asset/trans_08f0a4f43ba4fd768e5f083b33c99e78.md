
## 针形裸藻
*Euglena acus*（针形裸藻）呈极细的针状。许多个体被包裹在一层厚实的皮膜中，该皮膜表面雕刻成龙骨状结构。皮膜有时还装饰有坚硬或小型疣状突起。群体形成仅限于*Colacium*属，其中鞭毛裸藻细胞通常以前端附着于合胞体（copropod）上，并发育为由多个无鞭毛细胞组成的树状结构。壳或壳板很常见。

裸藻目（Euglenids）具有两个显著特征。它们合成一种淀粉样多糖——副淀粉（paramylum），并且拥有一个储液泡（guttlereservoir）系统。

在栖息地方面，裸藻目（Euglenida）分布广泛。绿色的成员主要出现在淡水中，且数量常多到形成藻华（blooms）。与团藻门（Phytonamadiada，原文如此，疑为Chrysophyta或其他藻类门的误拼）不同，裸藻目出现在较温暖的水域，但似乎不出现在温泉中。它们在柑橘废物泻湖和污水处理的后期阶段水中大量存在，这表明它们具有部分腐生营养的特性。参见**鞭毛虫门**；**原生动物**。

# 裸藻纲
一个与裸藻门（Euglenophyta）同范围分类阶元的纲，包含单细胞的无色或光合鞭毛虫，具有非常独特的细胞学特征。在原生动物分类学中，这些生物构成**植物鞭毛虫纲**（Phytomastigophora）下的一个目，即*Euglenida*。尽管光合裸藻与绿藻门（Chlorophyta）一样含有叶绿素*a*和*b*，但在其他大多数方面，它们与这些藻类差异巨大，暗示其色素具有独立的植物起源。已描述并分类了约1000个物种，归入约40个属和6个目。参见**EUGLENIDA**。

大多数裸藻是自由游动的，并拥有两条鞭毛，其中一条可能无运动功能，起源于一个称为储液泡的前部凹陷。光合裸藻含有一至多个绿色叶绿体，形态从微小的圆盘到扩展的板状或带状不等。无色裸藻依赖渗透营养或吞噬营养进行营养吸收。

裸藻最常见于富含有机物质的淡水中，但也出现在海洋或咸水栖息地、泥沙上以及冰雪中。少数物种偏好极酸性的水体。[PC.Si.] [R.L.Me]

# 大孢子虫目
亚纲 Gregarinia 的一个目。这些原生动物是无脊椎动物（如节肢动物和环节动物）的常见寄生虫。在这些动物的生活史中，只发生有性生殖，缺乏裂体生殖。该目分为头部亚目（Cephalina）和无尾亚目（Acaudinalia）。在北美，*Melanoplus*属的蚱蜢通常是cephaliana **Gregatina rigida** 的宿主，后者栖息于肠道腔内。参见**GREGARINIA**；**无脊椎动物病理学**；**原生动物**。 [E.R.B,N.D.L]

# 真核生物
包括所有高于细菌所代表的原始单细胞原核生物水平的所有分类群的生活和化石生物的巨大阵列。真核生物因此包括所有植物和动物、单细胞原生生物以及真菌。

该组的所有生物在其细胞中都具有组织化的细胞核（或核），具有核膜和含双链脱氧核糖核酸（DNA）的染色体对，以及复杂的细胞质细胞器，如线粒体、高尔基体、溶酶体、过氧化物酶体、内质网、以各种阵列存在的微丝和微管，以及在光合形式中存在的质体或叶绿体。典型地，还存在中心体、纤毛或鞭毛，其中后两者是主要由微管蛋白组成的运动细胞器，微管表现出普遍的9 + 2模式。参见**纤毛**和**鞭毛**；**原核生物**。

在个体水平上的组织形式从单细胞独居到单细胞群体、菌丝体、合胞体（cenocyte）以及具有广泛组织分化的真正多细胞生物不等。营养模式范围广泛：吸收性、摄食性、光自养性，以及这三种主要类型的组合。

生活史差异巨大，单倍体更具“低等”群的特征，而二倍体则是“高等”类群的特征。同样，繁殖既包括无性生殖也包括有性生殖。在“高等”多细胞形式中，真正的胚胎从二倍体受精卵阶段发育而来，该阶段由精子和卵细胞融合形成。

常见好氧代谢，尤其是在水生和陆生形式中；然而，厌氧机制存在于许多发现在低氧栖息地的物种中，包括宿主生物体内的各种部位。

物种大小范围从1微米（某些原生动物和藻类）到许多米（鲸鱼、树木）。栖息地覆盖所有可能的生态位：对于自由生活形式（许多是运动的，植物营生阶段的主要例外除外）而言，包括水生、陆生和空中；对于共生或寄生形式而言，包括在任何类型的宿主内部或外部（内部栖息地，包括细胞、组织、器官或各种体腔）。休眠阶段包括孢囊、孢子和种子；这些通常参与物种的分散或繁殖。参见**动物界**；**真菌**；**植物界**；**原生动物**。 [J.O.C.]

# 欧拉角
指定物体相对于参考轴定向的三个角度参数。它们用于描述旋转系统，如陀螺仪、陀螺、分子和非球形原子核。它们在三个角度上并不对称，但比其他旋转参数更容易使用。

不幸的是，欧拉角有不同的定义，因此比较不同参考文献中的方程会很令人困惑。这里给出的定义是 H. Margenau 和 G. Murphy 的大多数约定俗成的定义。

设 $OXYZ$ 为固定的右手笛卡尔（直角）坐标系，$Oxyz$ 附着在旋转物体上（参见插图）。

$xyz$ 的定向可以通过三个关于固定轴的连续旋转产生，起始时 $Oxyz$ 平行于 $OXYZ$。依次旋转：(1) 关于 $OZ$ 轴逆时针旋转角度 $\varphi$，(2) 关于 $Oy$ 轴逆时针旋转角度 $\psi$，(3) 关于 $OZ$ 轴再次旋转角度 $\theta$ 关于 $x$ 轴。$xy$ 平面和 $XY$ 平面的交线 $OK$ 称为节点线。

欧拉角。文本中描述的在单位球上轴的连续运动由箭头表示。完全旋转也可以通过不同的旋转顺序获得，即先关于 $OZ$ 旋转 $\varphi$，然后关于移位后的 $x$ 轴（即 $OK$）旋转 $\psi$，最后关于 $OZ$ 旋转 $\psi$。

# 欧拉运动方程
例如，将关于 $OZ$ 的旋转记为 $Z$（角度）。那么，完全旋转在符号上由以下方程给出，其中最右边的操作最先进行。
$$R(\psi,\theta,\phi) = Z(\phi)X(\theta)Z(\psi)$$  [B.G.]

# 欧拉运动方程
一组表达旋转刚体的力矩、角速度和角加速度之间关系的三个微分方程。它们通常是动力学意义上的运动方程，形式为 (1)–(3)。
$$I_1(d\omega_1/dt) + (I_3 - I_2)\omega_2\omega_3 = M_1$$    (1)
$$I_2(d\omega_2/dt) + (I_1 - I_3)\omega_3\omega_1 = M_2$$    (2)
$$I_3(d\omega_3/dt) + (I_2 - I_1)\omega_1\omega_2 = M_3$$    (3)

该公式采用物体绕质心（若无约束，则为质心）转动的三个主惯性轴作为坐标轴。这些参考轴构成右手系，在方程中由下标 1、2 和 3 表示，其中 $I_1$、$I_2$ 和 $I_3$ 代表主惯性矩；$\omega_1$、$\omega_2$、$\omega_3$ 代表关于这些轴的角速度；$M_1$、$M_2$ 和 $M_3$ 代表相应的力矩；$t$ 代表时间。 [RIPBO-DYDYNAMICS]

# 真木兰类
一组非正式的被子植物目，包含樟目（Laurales）、木兰目（Magnoliales）、胡椒目（Piperales）和冬青目（Winterales），加上单子叶植物，总共大约包含被子植物物种的三分之一。以前，许多人将这个组（减去单子叶植物）等同于木兰亚纲（Magnoliidae），但脱氧核糖核酸（DNA）序列的研究表明，睡莲目（Nymphaales）和毛茛目（Ranunculales）等目与其他目关系较远，而单子叶植物则关系更近。由于在收集更多数据之前，真木兰类与真双子叶植物之间的确切关系尚不清楚，因此目前尚无法为该组建立正式的分类学体系。包括单子叶植物在内的真木兰类表现出一组反映其相对密切关系的特征：这些特征包括花朵易凋谢的倾向以及仅限于该组的一套化合物。它们还具有一套被大多数评估认为“原始”的特征；这些包括无导管木质、片状花药和片状胎座。现在看起来相当清楚的是，虽然真木兰类表现出一些原始特征，但它们并非被子植物中最古老或最早出现的类群，并且它们包含一些最进步的类群，如许多单子叶植物（禾本科、棕榈科和兰科）。参见**LURALES**；**百合纲**；**MAGNOLIALES**；**PIPERALES**；**植物分类学**。

# 真甲壳类
甲壳纲（Crustacea）十足目（Malacostraca）的主要分部（亚纲）。它包括三个、四个或五个现生总目：通常包括异颚类（Syncarida）、翼肢纲（Pteranocara）和真肢纲（Eucarida），这里也只认可这些。然而，一些甲壳动物学家仍坚持将剑尾目（Hoplocarida）列为真甲壳类。对于热肢目（Thermoanacea）作为独立总目盘肢总目（Pancarida）的接受，并未包含在甲壳目分类单元中。以前，真甲壳类作为一个同质进化单元的概念几乎没有引起争议。该亚纲由一系列称为甲壳类面部特征的特征定义：头胸甲包裹胸部；柄状可动眼睛；双肢型小触角；鳞片状触角外肢；具有游泳外肢的胸肢；具有发达的、复合的、肌肉质的附肢以适应弯曲的腹部；尾节和尾肢形成尾扇；双肢型腹肢 1–5；以及内部器官主要从腹部排除。反对甲壳类理论的人指出，这些特征中的一些并不局限于真甲壳类，反之，并非所有真甲壳类都具备所有这些特征。头胸甲、其起源和演变是最大的争议焦点。

所有真甲壳类共有的基本身体结构包括五个体节的头部、八个体节的胸部和六个体节的腹部，加上末端的尾节。零到三对胸部体节可能与头部融合，其胸肢特化形成摄食附肢（颚足）。胸部通常有五到八对步行或特化附肢（步足）；腹部的前五个体节可能有或没有成对的附肢（腹肢）；第六个体节通常有一对发达的附肢（尾肢）。雌性生殖孔（共轭或腹面）位于第六胸部体节水平，而雄性生殖孔位于第八体节水平。

大多数真甲壳类共有的两个甲壳类特征是强壮的腹肌和发达的尾扇。连同伴随的神经元素，这些似乎被设计为一种高效的推进机制，即逃逸反应。

大多数真甲壳类是雌雄异体；然而，一些等足目、缩头目和少数十足目是雌雄同体。受精通过精子实现，可以是体外或体内。参见**甲壳动物**；**真肢纲**；**十足目**；**盘肢总目**；**异颚类**。 [P.A.McL]

# 变形虫门
变形虫目（Myxetoza）的一个目。这些是形成原生质体的黏菌，原生质体是多核阶段，在某些物种中可能跨越一英尺（30厘米）或更多。原生质体通常发现在腐烂的植物材料上，是一种迁移性的吞噬性生物，捕食微生物。成熟的原生质体包含一个原生质体，其中包含一个管道网络，通过该网络发生快速的内质流动。在子实体中产生抗性孢子（孢子），可能是单倍体。释放的孢子被吸附到变形虫鞭毛虫或变形虫（可能变为鞭毛虫）上。任何类型都可能代表配子，并在某些物种中报道了交配型。 [RPH]

# 真菌
真正的真菌，一组具有吸收性营养的异养生物，能够通过分泌消化酶和吸收来利用细胞外的不溶性食物。糖原是真菌的主要储存产物。大多数真菌具有定义明确的细胞壁，由几丁质和葡聚糖组成。在大多数物种的细胞分裂过程中，与核膜相关的是纺锤极体，而不是中心体。通常，真菌体（菌丝体）是单倍体的，由微观的、分枝的、线状的菌丝（统称为菌丝体）组成，这些菌丝在基质或宿主内发育成辐射状的宏观菌落。丝状菌丝体可能被横隔（隔膜）分成区室。菌丝生长是顶端的。一些物种是合胞体（无横隔）；其他，包括酵母，是单细胞的。生殖体在形态和大小上高度多变，且可以是无性的或有性的。

对真菌系统发育关系的理解发生了巨大变化，这是通过使用源自脱氧核糖核酸（DNA）序列的特征和计算机辅助的系统发育分析来实现的；这些变化反映在当前的分类方案中。现代分类如下：
