# 波传播。

声音所遵循的数学方程被称为波动方程。其推导基于牛顿第二定律在流体中的数学表述（纳维-斯托克斯方程）、连续性方程（其核心陈述是当流体被压缩时，其质量守恒），以及一个顺性定律（衡量因压力变化导致的体积变化）。通过对这三个方程进行数学处理，并假设流体中仅发生非常微小的物理变化，可以得到一个单一的微分方程，该方程通过一个单一量——声速（c）的平方——将声学压力随时间的变化与随空间的变化联系起来，而声速通常是空间和时间的缓变函数。参见**纳维-斯托克斯方程；波动方程**。

知道声速作为空间和时间的函数，至少原则上允许我们研究声音的空间和时间特性。用于寻找波动方程解的数学方法与物理其他领域（如光学、雷达和地震学）中使用的数学方法相同。参见**波动**。

除了知道声速之外，还需要知道声源的位置和性质、海面的位置和特征、海床的深度，以及在许多应用中，海床的物理结构。不可能在整个水柱中以超过5%的精度得知声速。因此，波动方程的解对实际情况或估算值有严重影响，其精度取决于环境认知的质量以及波动方程的数学或数值解在多大程度上代表了实际的物理情况。

# 环境噪声。

声音显著传播的一个后果是，不需要的声音同样会被高效地传输。使用水下声音的最终限制之一是在噪声之上检测信号的能力。在海洋中，有四种不同类别的环境声音：生物性的、海洋物理过程的、地震的和人为的。参见**声学噪声；次声波**。

# 散射和混响。

另一类不需要的声音来源是混响。传输的声音不可避免地会找到可产生散射的物体。最大的体积是海面或海床。散射体通常位于各个方向，其中一部分会返回到产生回波信号的系统中。水柱中的散射源包括鱼类、颗粒物以及物理不均匀性。在正常海况下，海面受风扰动，具有与盛行大气条件相关联的特征粗糙度。粗糙表面以取决于粗糙度、声学频率（或波长）以及信号方向的散射强度散射声音。散射具有极强的时间依赖性，需要采用适当的统计方法进行研究。海床具有固有的粗糙度且通常是不均匀的，这两种特性都会导致散射。虽然散射会降低声纳的性能，但可以通过信号处理或阵列设计确定回波的特征以实现其消除。散射还可以用于研究海面、海床、鱼类的种类和分布以及水柱中的不均匀性。参见**散射层；声纳**。

# 水下电视

任何位于水下以收集和显示图像的电子设备摄像机。它必须封装在防水外壳中。水下摄像机可以与其自身的记录设备一起封装，也可以连接到位于船上、实验室或远程地点的电视上。在后一种情况下，来自摄像机的图像是实时图像。水下电视可用于运动、海洋探索、工业应用或军事目的。常见的成像对象包括动物、珊瑚礁、水下沉船以及水下结构物，如码头、桥梁和海上石油平台。

在白天和较浅的深度，水下电视可用于观察由自然阳光照明的物体。用于夜间观看或在极深处时，必须使用人工光源。海洋中的光强度会显著减弱；特别是在最清澈的天然水域中，一束蓝光或绿光每230英尺（70米）强度会减弱约67%。通过海水或湖水等水介质传播的光也会根据波长被选择性地减弱强度。在大多数情况下，深红色和深蓝色减弱得最厉害，最高可见度区域向黄色到蓝绿色波长移动。参见**电磁辐射**。

电视摄像头的现代进步为水下视觉开辟了众多应用，例如标准视频、电荷注入器件、硅增强靶或电荷耦合器件摄像机。这些摄像机可以适应高帧率、低光照水平或水下彩色成像。水下图像的计算机建模可用于预测水下成像系统在观察范围和图像质量方面作为水体清晰度函数的性能。参见**电荷耦合器件；电视；电视摄像机；水下摄影**。

# 水下车辆

一种可设计为远程或直接操作的水下工作台平台。水下车辆分为三类：深潜器（DSVs）、遥控载具（ROVs）和自主水下航行器（AUVs）。还有混合车辆，它们在单一平台上结合了两类或三类。在每类潜水器中，都有针对特定工作任务专门改造的车辆。这些可以是专门建造的或标准潜水器的改装版本。

DSV有五种类型：单大气压无缆绳车辆；单大气压有缆绳车辆，包括观察/工作钟；大气潜水服；潜水员观察车辆；以及湿式潜水器。尽管它们主要在线路配置、电源和船员数量上有所不同，但所有车辆都在干燥舱内以1个大气压（104千帕）的压力搭载船员。例外的是湿式潜水器，其中船员暴露在全部水压下。DSV的主要特征是为在海洋内部工作提供心智和视觉支持。早期的潜水器在厚壁钢制船体上装有非常小的观察孔。

在1960年代中期，开始进行关于使用大量塑料（丙烯酸）作为耐压壳材料的实验性工作。今天，可以制造具有3300英尺（1000米）深度能力的潜水器，其耐压壳完全由丙烯酸制成。本质上，船体现在变成了巨大的窗户。

第一代ROV于1950年代末为海军用途开发。到1970年代中期，它们被用于民用领域。这些潜水器被快速接受，是因为它们相对较低的成本，以及它们在执行危险任务时不会使人类生命处于风险之中。然而，它们最重要的属性是它们的结构更简单。凭借连接水面的脐带缆，由于内部没有需要生命支持的人类且没有需要充电的电池，它们可以几乎无限期地运行。ROV有四种类型：系留自由游动载具、拖曳载具、底部依赖载具和结构依赖载具。

AUV是无人驾驶且无缆绳的潜水器，独立于直接人类控制运行。其操作由预先编程的机载计算机控制。它们最初在军事领域开发，应用包括雷场定位和绘图、雷场布设、潜艇诱饵以及隐蔽情报收集等任务。民用任务包括海洋监测、基础海洋数据收集、冰下测绘、海上结构和管道
