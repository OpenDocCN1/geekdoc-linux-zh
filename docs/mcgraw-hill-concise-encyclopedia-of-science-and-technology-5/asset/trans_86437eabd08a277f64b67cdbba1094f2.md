**三角函数的性质。** 基于公式 (2) 以及上述关于 sin θ 和 cos θ 的几何构造（图 1），θ 可以是任意角，因此正弦和余弦函数的定义域是所有实数。在公式 (3) 中，若 a = 0，则正切和正割函数未定义，因此这些函数的定义域是所有实数，除了 π/2 (90°) 的奇数倍。在公式 (4) 中，若 b = 0，则余切和余割函数未定义，因此这些函数的定义域是所有实数，除了 π (180°) 的整数倍。此外，由于 |a| ≤ 1 且 |b| ≤ 1，正弦和余弦函数的值域是 −1 到 1（包含端点）。由于 |b| = |sin θ| ≤ 1 且 |a| = |cos θ| ≤ 1，可得 |csc θ| = 1/|b| ≥ 1 且 |sec θ| = 1/|a| ≥ 1。因此，正割和余割函数的值域由所有小于或等于 −1 或大于或等于 1 的实数组成。正切和余切函数的值域均为所有实数。公式 (2)、(3) 和 (4) 还揭示了倒数恒等式，即公式 (6)。另外两个有用的恒等式，即公式 (7)，也随之成立。

```
csc θ = 1/sin θ  sec θ = 1/cos θ  cot θ = 1/tan θ  (6)

tan θ = sin θ/cos θ  cot θ = cos θ/sin θ  (7)
```

由于 (a,b) 位于单位圆上，故 a² + b² = 1，因此 (sin θ)² + (cos θ)² = 1。这被称为毕达哥拉斯恒等式，写作公式 (8)。

```
sin² θ + cos² θ = 1  (8)
```

**和差公式。** 余弦函数的和差公式给出在公式 (9) 和 (10)，正弦函数的和差公式给出在公式 (11) 和 (12)。

```
cos (α + β) = cos α cos β − sin α sin β  (9)

cos (α − β) = cos α cos β + sin α sin β  (10)

sin (α + β) = sin α cos β + cos α sin β  (11)

sin (α − β) = sin α cos β − cos α sin β  (12)
```

**反三角函数。** 在方程 x = sin y 中，若限制 y 使得 −π/2 ≤ y ≤ π/2，则方程关于 y 的解是唯一的，记为 y = sin⁻¹x（读作“y 是 x 的反正弦”）。有时 y = sin⁻¹x 写作 y = Arcsin x。因此，y = sin⁻¹x 是一个定义域为 −1 ≤ x ≤ 1，值域为 −π/2 ≤ y ≤ π/2 的函数。例如，sin⁻¹(1/2) = π/6，sin⁻¹(-1) = -π/2。

同样，在方程 x = cos y 中，若限制 y 使得 0 ≤ y < π，则方程关于 y 的解是唯一的，记为 y = cos⁻¹x（读作“y 是 x 的反余弦”）。因此，y = cos⁻¹x 是一个定义域为 −1 ≤ x ≤ 1，值域为 0 ≤ y < π 的函数。最后，在方程 x = tan y 中，若限制 y 使得 −π/2 < y < π/2，则方程关于 y 的解是唯一的，记为 y = tan⁻¹x（读作“y 是 x 的反正切”）。因此，y = tan⁻¹x 是一个定义域为 −∞ < x < ∞，值域为 −π/2 < y < π/2 的函数。

**直角三角形的解法。** 三角函数可以表示为直角三角形边长的比值。确实，根据公式 (6)、(7) 和 (8)，可得 sin β = b/c，cos β = a/c，tan β = b/a 等，其中 a 和 b 是直角相邻的边（直角边），c 是斜边，α 和 β 分别是对应于边 a 和 b 的角（图 2）。如果已知直角三角形的一个角和一条边，或者两条边，则可求出剩余的角和边。

# 三叶虫纲

它们的现存最近亲缘类群是蛛形纲，包括蜘蛛、螨类和鲎类（Xiphosura）。约 3000 个已描述的属使三叶虫成为最多样化且最著名的化石类群之一。物种多样性在晚寒武纪达到峰值，随后大致持续下降，直到晚泥盆纪大灭绝。只有四个科延续到密西西比纪，且只有一个属延续到该纲在二叠纪的灭绝。

它们在大多数寒武纪海洋环境中的优势对于该纪的生物地层对比至关重要。参见 节肢动物门；寒武纪；螯肢亚门；泥盆纪；标准化石；二叠纪。

三叶虫在化石记录中通常以其外骨骼的矿化部分为代表，作为尸体或蜕壳残留物。矿化外骨骼主要局限于背部（见插图），向下弯曲形成类似边缘的双层边缘，以及一块位于头部中央区域下方的单一矿化腹板，即 hypostome（口下板）。矿化外骨骼由低镁方解石和少量有机物质组成。大部分腹面外骨骼，包括附肢，均未矿化。

大多数三叶虫是底栖碎屑食性或食腐动物，生活在沉积物-水界面或该界面下方的浅层掘处。有些显然是肉食性的，其附肢带有尖刺和向下延伸的突起。这些类群的形态以及广泛的地理和生态分布范围表明它们是活跃的游泳者。在它们的演化历史中，三叶虫适应了所有海洋环境，从浅层高能量海岸带到深海无氧栖息地。[D.D.E., J.AdJ.]

# 三叶石松纲 (Trimerophytosida)

中-早泥盆世至中-中晚泥盆世，进化水平高于古蕨纲（Rhyniopsida）的维管植物。分支繁茂且多样化，呈二叉、假二叉、螺旋至近对生且近乎轮生，且常为三叉。营养枝常呈紧密螺旋状，末端由微小的反卷小枝模拟叶前体。茎轴无叶且无毛或具刺。木质部仅见于 Pilo phyton（一种属名，原文如此）。参见 胚植物；古蕨纲。 [H.F.B.]
