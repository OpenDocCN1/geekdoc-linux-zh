

# 延伸多细胞区域命运图
延伸多细胞区域命运图包含。它允许检测干细胞，这些干细胞通过一系列不等的细胞分裂产生整个结构。它还可以为发育承诺的时间设定下限。如果一个单细胞能够生成两个结构，那么显然，在标记时该细胞不可能已经不可逆地承诺成为其中任何一个结构。

在植物的克隆分析中，细胞通过使种子或发育中的植物暴露于电离辐射或化学诱变剂来标记，以产生染色体突变，从而导致明显的表型改变，通常是叶绿素或花青素色素的缺陷。产生的突变频率很低，表明这些是单细胞事件。由于标记细胞的所有后代都将携带相同的染色体突变，例如，用叶绿素缺陷突变标记的茎尖分生组织细胞将在发育中的植物中产生一个白色组织的扇区，或克隆。通过检查植物在发育后期存在的扇区的大小和位置，可以推断出在发育某一阶段标记的分生组织细胞的数量和命运。例如，一个延伸整个茎长度的扇区将由分生组织中心的永久性初始细胞产生；如果该扇区的宽度占据了茎圆周度的三分之一，那么茎必须由三个这样的初始细胞形成。参见 MUTATION；PLANT GROWTH。

# 故障分析
技术系统中故障的检测与诊断。此类系统包括生产设备、运输车辆和家用电器。虽然检测与诊断故障的需求与技术系统的建造历史同样悠久，但先进的故障检测直到计算机的普及才得以实现。故障检测和诊断实际上意味着一种方案，其中计算机监控技术设备，以指示任何故障并确定负责该故障的组件。故障的检测和诊断之后可能伴随着自动行动，使故障得以纠正，从而系统即使在特定的故障条件下也能成功运行。

故障检测和诊断适用于基本技术设备及其附接的执行器和传感器。执行器和传感器的故障检测非常重要，因为这些设备容易发生故障。

故障的在线或实时检测和诊断意味着设备在正常运行期间由永久连接的计算机持续监控，任何偏差几乎立即被指示。在线监控对于在组件故障导致更严重的设备故障之前早期检测故障非常重要。相比之下，离线诊断涉及通过特殊的、临时附加的设备在特殊条件（例如，在服务站进行汽车诊断）下监控系统。诊断活动可以分解为几个逻辑阶段。故障检测是指示系统中有问题出现。故障隔离是确定故障位置（故障组件），而故障识别是估计其大小。

由于噪声、干扰和模型误差等情况，故障检测和隔离永远无法以绝对确定性执行。误报和漏检之间始终存在权衡，适当的平衡取决于特定应用。

# 故障和故障结构
大陆和海洋壳岩石中沿断层破裂和差异运动的产物。断层在长度和位移幅度上从手标本中可见的小型结构（显示厘米或更小的错位）到长的连续壳断裂（延伸数百公里并容纳数十或数百公里的位移）不等。断层存在于变形岩石的微观尺度上，但在大多数地质研究中通常被忽略或未被识别。或者，亚微观到微观尺度的岩石体作为非常紧密间隔的近平面断层集合体，被识别和解释为一种允许岩石体流动的劈理类型。没有可见位移的断层被称为节理。容纳了主要膨胀造山运动（垂直于断层表面一米或更多）的大型断层被称为裂隙。裂隙的形成受限于近地表条件，例如壳伸展或沉降区域。

除了描述断层的物理和几何性质并解释其形成时间外，确定记录相对运动方向的小型断层结构（如擦痕和拖曳褶皱）的方向也被发现特别重要。评估断层运动可能很困难，因为在地图或露头中看到的断层块之间的表观相对运动（分离）可能与两点之间的实际相对运动（滑动）几乎没有或没有关系。断层的滑动是岩石中两个可能在断层发生前重合的点或两个标记之间的实际相对运动（参见插图）。走滑断层导致相邻块体之间的水平运动；逆冲断层由沿断层面直接向上或向下的平移标记；在斜滑断层中，实际相对运动的路径在水平和逆冲滑动之间某处倾斜。

在自然界中，即使是简单的平移断层运动，由于结构和地形干扰形成的复杂且具有欺骗性的图案，以及定义滑动路径的特定断层结构的缺失，通常很难识别。在测绘时，地质学家主要记录沿断层的表观相对运动（分离），基于在平面视图或横截面露头中的观察。参见 TRANSFORM FAULT。

# 容错系统
系统，主要是计算和基于计算机的系统，能够容忍其内部结构或外部环境中的不期望变化。这些变化，通常被称为故障，可能在系统演化的各种时间发生，从规范开始到使用过程。在规范、设计、实现或修改期间发生的故障称为设计故障；在使用期间发生的故障被称为操作故障。容错技术的使用基于这样一个前提：复杂的系统，无论设计和验证多么仔细，都可能包含残留的设计故障，并遇到不可预测的操作故障。

通常，容错技术试图防止低层错误（由故障引起）传播为系统故障。通过使用各种类型的结构或互操作冗余，这些技术要么屏蔽故障（即错误未传播到故障系统的输出），要么检测故障（通过错误）并实施恢复过程，如果成功，防止系统故障。在永久性内部故障的情况下，恢复过程通常包括某种形式的结构重新配置（例如，用备用替换故障子系统或使用备用程序），防止故障引起进一步的错误。典型地，容错系统设计将结合一系列补充故障预防技术的容错技术。参见 SOFTWARE ENGINEERING。

# 羽毛
皮肤的特化角蛋白突起，是鸟类的独特特征。羽毛是高度复杂的结构，提供绝缘、防止机械损伤和保护色，并在行为中发挥重要作用。一个特殊的功能角色是在飞行中，羽毛提供推进表面和适合飞行的气动身体表面。羽毛用于保持平衡，偶尔用于捕捉猎物和专门展示。

一种代表性的确定羽毛包含单个长中心轴，支撑每一侧的一排小分支状结构（羽枝）。羽枝形成羽毛的羽片，或网页。单独的羽枝以可变角度分支并指向羽毛的外端。羽小枝是羽枝上的小分支。它们与羽枝位于同一平面，并从其前平面和后平面成排产生。前羽小枝具有扁平的基部和一系列小的钩状突起，附着在下一个羽枝的后羽小枝的近端脊上，形成以其强大和轻重量为特征的互锁结构。所有羽毛类型基本上由这些结构元素组成。

大多数表面羽毛是轮廓羽毛（笔）。这些包括翅膀的大型飞行羽毛（飞羽）和长尾羽（尾羽）。其他常见的羽毛类型包括绒毛（绒羽）、中间类型（半绒羽）和丝状羽（参见插图）。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_883_0.png)

由于鸟类正常活动伴随的物理磨损，羽毛通常会发生磨损。在大多数物种中，羽毛至少每年完全替换一次，许多羽毛更频繁地替换。羽毛换羽的顺序惊人地有序。以不规则模式脱落大片羽毛的企鹅是一个例外。在大多数物种中，换羽期间保留飞行能力。换羽，即羽毛的正常脱落并由新一代羽毛替换，是一个单一的生长过程，只积极关注新一代羽毛的产生。旧羽毛被动地推挤出毛囊。

羽毛的一个主要生理功能是提供绝缘。这是通过调节羽毛和皮肤的配置，使得不同量的空气被困在形成的死空间中来实现的。控制热耗散的第二个机制是有羽毛和无羽毛身体部分暴露的平衡。

羽毛在其提供防水作用中充当保护边界。防水性是羽毛的结构特征，是杆和羽小枝的直径和间距之间精确几何关系的结果。梳理似乎比过去认为的在应用油或其他天然产品方面更为重要，对于维护这种结构。

羽毛表面构型和整体图案的第三个功能在行为适应领域。这些可能有两类。第一种是隐蔽，当鸟类具有与背景匹配并逃避检测的隐蔽标记。第二类由各种类型的广告组成。参见 PROTECTIVE COLORATION。

# 反馈电路
一种将电子电路或控制系统输出信号的一部分返回到电路或系统输入端的电路。当返回的信号（反馈信号）与输入信号同相时，反馈称为正反馈或再生性反馈。当反馈信号与输入信号反相时，反馈称为负反馈或减额性反馈。

在电子电路和自动控制系统中使用负反馈会产生系统特性的变化，从而改善系统性能。在电子电路中，反馈用于改变放大器电路的频率响应特性形状，从而在频率范围内产生更均匀的放大，或在振荡器电路中产生振荡条件。它还用于稳定系统增益，使其免受温度变化、组件更换等影响。负反馈还减少非线性失真。在自动控制系统中，反馈用于将系统的实际输出与期望输出进行比较，差值用作控制器的输入信号。参见 AMPLIFIER; NEGATIVE-RESISTANCE CIRCUITS; SERVOMECHANISM。
