# 扼流圈（电学）

一种用于防止电信号和能量沿非期望路径传输或进入电路或系统中不适当部分的电感器。电源扼流圈防止电源固有的交流分量进入电子设备。射频扼流圈（RFC）防止射频信号进入音频电路。

几乎所有电子设备（如计算机、电视机和高保真音响系统）中使用的印刷电路板通常都有一个或多个扼流圈。这些扼流圈的作用是：（1）衰减设备内部产生的杂散信号，以防止这些信号传输到电路的其他部分或超出整个系统到其他电子设备；（2）防止系统其他部分产生的非期望信号或电气噪声对电路性能产生不利影响；以及（3）防止电源纹波降低系统性能。波导扼流圈防止微波能量传输到波导系统的错误部分。参见电气噪声；电子电源；印刷电路板；纹波电压；波。

在最简单的形式中，扼流圈或电感器是围绕磁芯缠绕并绝缘的线圈（通常为铜线），磁芯可以是铁磁性的，也可以不是。铁磁磁芯倾向于增加电感、减小物理尺寸并减少电路元件之间的电磁耦合，但它们可能会增加功率损耗和由此产生的热量。此类磁芯通常会导致非线性或摆动扼流圈，常见于电源中，在这种应用中非线性可能是有益的。参见电感；电感器。

# 阻塞流

流体通过受限区域的流动，当流体速度在流动路径上的某点达到声速时，流动达到最大值。阻塞现象仅存在于可压缩流中，并可能发生在几种流动情况中。参见可压缩流。

**通过变面积管道。** 阻塞流可以发生在连接到巨大储库的收敛流区域或喷嘴中。如果背压小于储库压力，流体便从储库通过喷嘴开始流动。当背压略低于储库压力时，来自喷嘴出口之外的信号以声速传递到储库。储库通过向喷嘴发送流体做出反应。此外，流体的最大速度存在于喷嘴喉部，那里面积最小。

当背压进一步降低时，流体从储库流出的速度更快。然而最终，喉部的速度达到声速。此时，喉部的流体速度为声速，信号的速度也为声速。因此，储库无法感知背压的进一步降低，相应地也不会诱发更大的流量流出储库。因此，喷嘴被称为处于阻塞状态，流体的质量流量达到最大值。参见马赫数；喷嘴；声音；超音速扩散器。

**有摩擦时。** 阻塞流也可以发生在连接到储库的长恒面积管道中。当流体通过管道流动时，流体与管道壁之间的摩擦作用在流体上的压力降低。随着压力降低，其他流体属性也受到影响，如声速、密度和温度。最大马赫数发生在喷嘴出口，当该马赫数达到1时，就会产生阻塞流。

**有热加入时。** 对于连接恒面积管道的储库，也可以考虑假设管道中的流动是无摩擦的，但沿管道壁向系统加入热量的情况。参见流体流动；气体动力学。

# 霍乱

一种由人类小肠感染*霍乱弧菌*（*Vibrio cholerae*）引起的严重腹泻疾病。霍乱弧菌是一种兼性厌氧、革兰氏阴性、杆状细菌。霍乱通过粪-口途径传播。霍乱已七次在全球范围内造成大流行。19世纪，西半球曾多次受到波及，1991年在秘鲁再次发生。尽管以前的霍乱爆发与高死亡率有关，但通过对其病理生理学的理解，现在可以确定，如果早期发现，没有人会死于霍乱。参见腹泻。

霍乱产生由霍乱肠毒素（CTx）引起的分泌性腹泻。该毒素导致宿主膜中氯离子和碳酸氢盐的过度分泌，并抑制钠离子的吸收，导致大量等渗液体的分泌，构成严重霍乱的腹泻。治疗包括补充霍乱大量粪便中流失的液体和电解质。这可以通过静脉注射或口服进行。也可使用适当的抗生素。潜伏期可能少于一到几天；经过适当治疗，患者应在4至5天内康复。疾病仍具有传染性。

尽管霍乱弧菌最早由罗伯特·科赫（Robert Koch）于1883年发现，且3年后引入了霍乱疫苗，但目前仍没有有效、经济且无毒的疫苗。由于费用高、反应性大且缺乏疗效，已放弃使用通过注射（非肠道）给药的灭活全菌疫苗。目前正在评估的实验疫苗包括口服（或鼻内）给药的基因工程活减毒制剂、口服给药的灭活全菌疫苗，以及通过注射给药的结合疫苗（多糖和毒素抗原）。人们还在努力将霍乱抗原转基因引入可食用植物中。

一个复杂的情况是，在大约150个已知的*霍乱弧菌*血清群中，直到1992年，只有两个类别（最初由科赫描述，后来被认定为El Tor型的O1血清群）导致了所有流行性霍乱。1992年，一个新确认的O139血清群在印度和孟加拉国引起了流行性霍乱，并一度取代了El Tor型*霍乱弧菌*。O139和El Tor在抗原上有区别，因此需要为O139开发新的疫苗。O139的出现令人担忧*霍乱弧菌*的其他血清群可能会获得毒力和流行性。

避免霍乱的最佳方法包括水氯化消毒、卫生处理污水，以及避免食用生或未煮熟充分的海鲜，因为流行病学地区的这些海鲜可能因摄食受感染的浮游生物而受到感染。

# 胆固醇

一种环状烃醇，通常被归类为脂质，因为它不溶于水但溶于多种有机溶剂。它是所有脊椎动物细胞中的主要固醇，也是真核生物中最常见的固醇。在脊椎动物中，胆固醇的最高浓度存在于包裹神经的髓鞘和包围所有细胞的质膜中。参见脂质。

胆固醇可以以游离（未酯化）形式存在（见下图结构），也可以以酯化形式存在，此时脂肪酸通过酯键结合到胆固醇的羟基上。游离形式存在于膜中。胆固醇酯通常存在于类固醇生成组织细胞内的脂质滴中（在那里它可以转化为游离胆固醇，进而转化为类固醇激素），或存在于血液中称为脂蛋白的球形脂质-蛋白质复合物的中心。参见细胞膜。

胆固醇与磷脂和蛋白质一起，对于维持正常的细胞膜流动性很重要。在生理温度下，胆固醇分子与膜磷脂的脂肪酸相互作用，导致脂质分子堆积增加，从而降低膜流动性。因此，所有脊椎动物细胞都调节其膜中的胆固醇，以便细胞正常功能。胆固醇也是许多其他必需化合物（包括类固醇激素、胆汁酸和维生素D）的前体，因此也很重要。参见脂质代谢；类固醇。

细胞胆固醇既来自饮食（经肠道吸收后），也来自体内所有细胞的合成。胆固醇含量特别高的食物包括鸡蛋、红肉以及肝脏和大脑等器官。每天约有40–50%的饮食胆固醇从肠道吸收。相比之下，植物固醇的吸收率极低。

胆固醇合成发生在所有脊椎动物细胞中，但在肝脏、肠道和皮肤中最高，在脑髓鞘形成时期脑中的合成也最高。

胆固醇和胆固醇酯在水中的溶解度极低。为了在血液中运输这些化合物，肝脏和肠道产生各种脂质-蛋白质复合物，称为脂蛋白，起到增溶作用。脂蛋白是胆固醇、胆固醇酯、磷脂、甘油三酯（脂肪）和多种蛋白质的大型复杂混合物。主要脂蛋白包括乳糜微粒、极低密度脂蛋白（VLDL）、低密度脂蛋白和高密度脂蛋白（HDL）。

总血浆胆固醇水平低于200 mg/100 ml被认为是理想的。200–239 mg/100 ml或高于239 mg/100 ml的值分别被认为是临界升高或高风险值，表明有心梗的潜在风险。血浆中低密度脂蛋白水平高与动脉粥样硬化（“动脉硬化”）风险增加有关，这涉及胆固醇和其他脂质在动脉壁的沉积。低胆固醇和低饱和脂肪饮食通常会导致总血浆和LDL胆固醇水平降低。这种血液胆固醇水平的变化被认为是有利的，并能降低心梗的发生率。参见动脉硬化。 [P.A.E.] (P.A.E.)

# 软骨鱼类

一组志留纪的装甲鱼类，盾皮鱼类（Placodermi），通常被认为是软骨鱼类的祖先，但这种渊源并不确定。另一组原始的有颌鱼类，棘鱼类（Acanthodians），许多人认为它们是高等硬骨鱼的祖先，显示出某些原始的类似鲨形的特征。无论如何，鲨形目和银鲛目很可能是在志留纪或早泥盆纪期间彼此独立演化而来的。参见棘鱼类；盾皮鱼类。

鲨形目和银鲛目共有的最显著特征是缺乏真正的骨骼。在这两个类群中，内骨骼都是软骨性的，在某些情况下可能广泛钙化。由于即使是钙化的软骨也很少被保存下来，软骨鱼类的化石记录主要由牙齿和棘刺组成，偶尔有相关的骨架。参见骨骼系统。

软骨鱼类的其他特征包括板鳞、雄性骨盆鳍上的夹器（用于体内受精）、尿素保留机制以及缺乏气鳔（游泳鳔）。这两个类群长期以来主要都是海洋掠食者，尽管在整个漫长的历史中它们曾多次入侵淡水。鲨形目很可能一直像今天一样以其他鱼类以及软体和硬体无脊椎动物为食。银鲛目很可能主要专注于无脊椎动物，尽管现代形式偶尔也以较小的鱼类为食。参见鳐；鳞（动物学）；鲨；鳔。 [B.S.] (B.S.)

# 硬骨鱼纲

辐鳍鱼亚纲（Actinopterygii）或辐鳍鱼类三个组织水平（下纲）中最原始的一个。硬骨鱼纲中的古鲟目（Palaeonisciformes）最早出现在早泥盆世，到中山泥盆世时，它们是早期肉鳍鱼类和肺鱼类的丰富同期物种，代表硬骨鱼类的其他两个亚纲。古鲟目在泥盆世多样化且丰富（棘鱼目，order Acanthopteri），在现代 fauna 中作为高度特化且在某些方面退化的硬骨鱼类延续下来。
