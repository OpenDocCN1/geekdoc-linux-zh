
其他非均相平衡包括溶解度平衡、涉及两种不混溶相的反应，以及涉及凝聚相和不混溶相的反应。参见“萃取”；“溶度积常数”。

## 化学燃料

在内燃机（汽车、柴油发动机和涡轮机）以及固定发电厂的炉窑中使用的主要燃料是有机化石燃料。这些燃料以及通过各种精炼和分离过程由它们衍生的其他燃料，在地球中以固体（煤）、液体（石油）和气体（天然气）相的形式存在。

用于改善燃烧发动机性能的特殊燃料是通过合成化学程序获得的。这些特殊燃料的作用是增加发动机的比冲，或增加单位质量或单位体积燃料可供发动机使用的燃烧热。一种具有极高单位质量燃烧热的特殊液体是液态氢。它已用作火箭发动机中与液态氧配合使用的燃料。由于其液态密度低，液态氢在需要高单位体积燃料燃烧热的系统（“体积限制”系统）中实用性并不太强。

一种产生高达5000°F（2800 C）量级的高火焰温度的特殊燃料是气态氰气。这与气态氧化剂氧气配合使用。液态燃料肼和其他基于肼的燃料，与液态氧化剂四氧化二氮一起，用于许多面向太空的火箭发动机。硼氢化物，如乙硼烷和五硼烷，是高能液体燃料，用于先进火箭发动机。

对于吸气式推进发动机（涡轮螺旋桨发动机和冲压发动机），最常用的是碳氢化合物燃料。在某些应用中，金属烷基燃料（即自燃，即在空气中自发点燃）甚至液态氢也在被使用。参见“金属有机燃料”。

在缺乏氧化剂的情况下，通过自发分解或因催化剂存在而分解并释放热量的燃料被称为单组分推进剂，并已被用于火箭发动机。这些单组分推进剂的例子包括过氧化氢和硝基甲烷。

液体燃料和氧化剂被用于大多数大推力火箭发动机。当推力不是限制因素时，固体推进剂燃料和氧化剂经常被使用，因为它们没有阀门和泵等运动部件，从而使得这类火箭发动机结构相对简单。固体燃料分为两大类：双基推进剂和复合推进剂。双基推进剂由硝酸甘油（硝化甘油）和硝酸纤维素组成，无需单独的氧化剂。双基推进剂通常是在模具中成型为火箭壳体所需的形状（称为药柱）。复合推进剂由燃料和氧化剂组成。后者可以是无机高氯酸盐或硝酸盐。复合推进剂的燃料通常是沥青状物质、热固性塑料或几种类型的合成橡胶和胶状物质。硼、铝和铍等金属颗粒已被添加到固体推进剂中，以增加其燃烧热并消除某些类型的燃烧不稳定性。参见“过氧化氢”。

## 化学动力学

物理化学的一个分支，旨在测量化学反应速率，用基元步骤描述它们，并从分子间基本相互作用的角度理解它们。

### 反应动力学。

虽然化学体系的最终速率由热力学指定，但达到该平衡状态所需的时间高度依赖于反应。例如，金刚石相对于石墨在热力学上是不稳定的，但金刚石转化为石墨的速率可以忽略不计。因此，出于实际原因，测定化学反应的速率已被证明是重要的。速率研究还提供了关于构成化学反应的核重排细节的基本信息。

传统上对物种X和Y之间反应生成Z和W的动力学研究，反应(1)，寻求形式如式(2)所示的速率，其中 d[Z]/dt 是产物Z的出现速率，f 是X、Y、Z和W浓度的某个函数（它们本身又是时间的函数），k 是速率常数。化学反应极其多样，通常函数 f 相当复杂，即使对于看似简单的反应也是如此，例如氢和溴直接结合形成溴化氢 (HBr) 的反应。这是一个通过一系列较简单的反应（称为基元反应）进行的复杂反应的例子。对于反应 (3d)，基元反应的序列是一个链式机理，已知涉及一系列步骤，反应 (3a)-(3c)。

```
X + Y → Z + W (1)
d[Z]/dt = k f([X], [Y], [Z], [W]) (2)
```

```
Br₂ → 2Br (3a)
Br + H₂ → HBr + H (3b)
H + Br₂ → HBr + Br (3c)
H₂ + Br₂ → 2HBr (3d)
```

这种基元反应的序列以前被称为反应机理，但在化学动力学意义上，机理一词被保留用于指碰撞过程中原子核的详细运动。

基元反应被认为是严格按照所写的方式发生的。反应 (3b) 被认为发生在一个溴原子撞击一个氢分子时。碰撞的产物是一个溴化氢分子和一个氢原子。另一方面，总反应是这些基元步骤的序列，在分子层面上并不是像反应 (3d) 所写的那样发生的。除了少数例外，基元反应 A + B → C + D 的速率方程由 d[C]/dt = k[AB] 给出。级数（浓度的指数之和）为二，如果反应是双分子的（只需要物种A与物种B碰撞），这是预期的结果。此类反应的速率常数 k 强烈依赖于温度，通常表示为 k = Z_AB e^(-E_a /RT)。Z_AB 是根据分子直径和温度计算的A和B之间的碰撞频率；μ 是一个经验确定的位阻因子，因为它源于只有具有合适取向的反应物碰撞才有效；而 E_a，即实验确定的活化能，似乎反映了在反应物足够接近以发生反应之前需要克服排斥力的需求。

在某些情况下，特别是对于分解反应，AB → A + B，基元反应步骤是一级反应，式(4)，

```
d[A]/dt = d[AB]/dt = k[AB] (4)
```

意味着该反应是单分子的。物种 AB 不会自发解离；它必须首先获得一定的临界能量（通常通过碰撞）以形成激发态物种 AB*。正是物种 AB* 发生单分子分解。

### 弛豫方法。

扰动技术在测量速率和确定快速化学反应的度量方面得到了广泛使用。这些方法通过移动平衡来提供化学反应速率的测量。在感兴趣的反应发生在平衡系统内的情况下，被称为弛豫方法的扰动技术被证明是测定反应速率常数最有效的方法。

处于平衡状态的化学体系是指正反应速率恰好被相应的逆反应速率所抵消的体系。例子包括发生在液体溶液中的化学反应，例如纯水中熟悉的平衡，如方程 (5) 所示。25 °C (77 F) 下的摩尔平衡常数由式 (6) 给出，其中方括号表示摩尔浓度。它自然源于正反应速率和逆反应速率的相等，式 (7)。这里 k_f 和 k_b 是分别取决于温度但不依赖于浓度的速率常数。此外，式 (6) 和 (7) 的组合导出了式 (8)。因此，一个合理的问题可能是，在室温下水中，为了满足从式 (6) 到 (8) 的方程，k_f 以 s⁻¹ 为单位的数值和 k_b 以 dm³ mol⁻¹ s⁻¹ 为单位的数值必须是多少？换一种说法，当将一升 1 M 盐酸倒入一升 1 M 氢氧化钠（伴随着相当危险的飞溅）时，水合氢离子 H⁺(aq) 与氢氧根离子 OH⁻(aq) 反应生成温暖的 0.5 M 氯化钠水溶液的速度有多快？在20世纪50年代早期，人们声称这种反应是瞬时的。湍流混合技术（过去被使用且仍在使用）速度不够快（混合时间约为1秒），无法让这种特定反应在混合室之外发生。弛豫技术由 M. Eigen 提出，他接受了测量看似不可测量的快速反应速率这一隐含的挑战。

```
H₂O ⇌ H⁺(aq) + OH⁻(aq) (5)
K_eq = [H⁺][OH⁻]/[H₂O] = 10⁻¹⁴/55.5 = 1.8 × 10⁻¹⁶ (6)
[H₂O] = k_f[H⁺][OH⁻] (7)
K_eq = k_f/k_b = 1.8 × 10⁻¹⁶ (8)
```

任何弛豫方法的核心在于对化学平衡进行扰动（通过温度、压力、电场强度或溶剂组成的小变化），其方式如此突然，以至于化学体系在寻求重新建立平衡时，由于化学反应相对缓慢，被迫滞后于扰动。[E.M.Ey.]

### 气相反应。

热力学气相化学反应的速率对于理解燃烧和大气化学等过程至关重要。

一个稳定的气相分子转化为另一个分子的化学转化是一个显著的过程，极少在单一步骤中发生，而是作为一个涉及许多物种的序列和并行反应的网络。甲烷 (CH₄) 氧化为二氧化碳 (CO₂) 和水就是一个绝佳的例子。它发生在燃烧中，在燃烧天然气（主要成分是甲烷）中，以及在大脑中。

在这两种情况下，净过程可以写成单个反应 (9)。

```
CH₄ + 2O₂ → 2H₂O + CO₂ (9)
```

然而，该反应并非由两个氧分子 (O₂) 与一个甲烷分子碰撞的结果。相反，它涉及许多独立的步骤。

所有基元反应从根本上都需要两个分子之间的碰撞。即使在单分子反应的情况下，其中一个分子分解或异构化为另一种形式，该过程所需的能量也来自与其他分子的碰撞。许多气相基元反应中涉及的物种是自由基，即具有一个或多个未配对电子的分子。这类物种倾向于具有高反应性，并且负责执行大多数气相化学反应。

反应速率是其中一种反应物或产物的浓度随时间变化的速率。动力学实验的目标不是测量反应速率本身，而是测量速率系数，即反应的本征属性，它将反应物浓度与其变化速率联系起来。例如，双分子反应 A + B → 产物 的速率数学表达式是微分方程 (10)。方括号表示 A 和 B 的浓度，k 是上述速率系数。速率表达式对反应物浓度的依赖关系是通过实验确定的，它也源于化学中一个基本准则，称为质量作用定律。一旦已知速率常数，就可以计算任何给定浓度组合下的反应速率。

```
-d[A]/dt = -d[B]/dt = k[A][B] (10)
```

速率常数通常随温度变化，因为碰撞分子的平均能量发生了变化。温度依赖性通常遵循阿伦尼乌斯表达式，k = A exp(-E_a/RT)，其中 A 是预指数因子，与气相碰撞速率有关，R 是通用气体常数，T 是绝对温度（以开尔文为单位）。关键量是活化能 E_a，即引发反应所需的能量。压力依赖性通常只对结合反应很重要。对于 A + B → AB，A 与 B 的碰撞会形成一个激发络合物 AB*，但如果随后的碰撞不能带走足够的能量来稳定 AB 产物，它将进一步分解。稳定碰撞的概率随着碰撞频率和总压力而增加。

在单分子反应 A → P 的简单情况下，速率表达式为式 (11)。方程 (11) 是一级的，因为速率与反应物浓度的一次方成正比，并导致 A 或 P 浓度变化的表达式（称为积分速率表达式），如式 (12) 所示。下标表示零时刻（初始浓度）的浓度和任意时间 t 的浓度。随着时间推移，A 的浓度降低（因为它正在反应掉），而 P 的浓度增加，使得 A 和 P 的浓度之和始终恒定且等于 A 的初始浓度。由于一级反应在数学上很简单，动力学致力于将所有研究的反应（如果可能）简化为此形式。例如，二级反应 A + B → 产物 的速率表达式由式 (10) 给出。为了将二级表达式简化为一级表达式，式 (11)，选择一种浓度过量，例如 [B] > [A]。在这种情况下，B 的浓度在反应过程中近似恒定，并且可以与速率常数结合，给出一个仅依赖于 A 浓度且与式 (11) 相同的表达式。[A.R.Ra; S.S.B]

```
-d[A]/dt = -d[P]/dt = k[A] (11)
[A]_t = [A]_0 exp(-kt) (12a)
[P]_t = [A]_0(1 - exp(-kt)) (12b)
```

## 化学显微术

一门使用显微镜来解决化学问题的科学学科。形成试样视觉图像的独特能力，选择试样的一小部分体积，并对选定体积内的材料进行化学或结构分析，使化学显微术成为现代化学分析不可或缺的组成部分。参见“分析化学”；“显微镜”。

显微镜可以与大多数分析仪器结合使用。例如，光学显微镜可以与光谱仪结合，从而能够确定微观物体或结构的分子组成。类似地，X射线光谱仪可以与电子显微镜结合，以确定小物体的元素组成。参见“电子显微镜”；“光谱学”；“X射线光谱法”。
