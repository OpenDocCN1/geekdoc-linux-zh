
并似乎确立了一些具有建筑重要性的不连续性，而没有完全丧失连续性。可以识别出三种类型的胚层：
- (1) 外胚层或外层皮，
- (2) 内胚层或内层皮，以及
- (3) 中胚层或中层皮。

这些胚层是根据球形类型原肠胚（如海胆或两栖动物的原肠胚）中的位置命名的。术语**表胚层**、**中胚层**和**底胚层**有时分别用作**外胚层**、**中胚层**和**内胚层**的同义词。这三个原始胚层作为基本的结构计划存在于所有后生动物中，例外是中空的腔肠动物和多孔动物（海绵动物），在后者中缺少明显的中胚层。参见**原肠形成**。

## **锗**

一种脆性、银灰色、金属性化学元素，符号 Ge，原子序数 32，原子量 72.59，熔点 937.4 °C (1719 °F)，沸点 2830 °C (5130 °F)，性质介于硅和锡之间。锗在地球地壳中分布广泛，丰度为每百万分之 6.7 (ppm)。锗以硫化物的形式存在，或与铜、锌、铅、锡、锑等其他元素的硫化物矿石有关。参见**元素周期表**。

锗具有金属光泽，但仅在特殊条件下表现出金属的物理和化学性质，因为它位于元素周期表中非金属向金属过渡的区域。在室温下，几乎没有塑性流动的迹象，因此表现为脆性材料。

在化合物中，锗呈二价或四价。二价化合物（氧化物、硫化物和所有四种卤化物）容易还原或氧化。四价化合物更稳定。有机锗化合物数量众多，在这方面，锗与硅相似。对有机锗化合物的兴趣集中在它们的生物作用上。在衍生物中，锗的哺乳动物毒性似乎比锡或铅化合物低。

锗的特性使得该元素有几个重要应用，尤其是在半导体工业中。第一个固态器件——晶体管——是由锗制成的。单晶锗用作某些发光二极管中气相生长 GaAs 和 GaAsP 薄膜的衬底。锗透镜和滤波器用于在电磁谱红外区域工作的仪器。汞掺杂和铜掺杂锗用作红外探测器；具有磁性的合成石榴石可能用于高功率微波器件和磁泡存储器；锗添加剂增加储备电池可用的安时数。  
[P.S.G.]

## **GERT**

一种使用网络方法对系统进行公式化和评估的程序。使用 GERT（图形评估和审查技术）程序解决问题利用以下步骤：

- 1. 将系统或问题的定性描述转换为类似关键路径法—PERT 类型网络的广义网络。
- 2. 收集描述分配给网络分支的功能所需的数据。
- 3. 将分支功能（网络组件）组合成等效功能，用于描述网络。
- 4. 将等效功能转换为性能指标，用于研究系统或解决创建网络的问题。这些可能包括完成网络的平均时间或方差，或成本。
- 5. 基于第 4 步开发的性能指标进行推断。

解析方法和模拟方法在该程序的各种步骤中均有使用。GERT 旨在通过适应信号流图理论来解析评估线性系统的网络模型。对于涉及复杂逻辑和排队情况的非线性系统，开发了 n-GERT。在 Q-GERT 中，对网络进行模拟以获得感兴趣的性能指标的统计估计。

设计、开发并使用了 GERT 网络来分析以下情况：保险公司的索赔处理、生产线、制造系统中的质量控制、工作绩效辅助评估、建筑物的防盗性能、空中终端货运设施的能力、司法法院系统的运作、施工规划中的设备分配、军用空中运输部队的加油、市场研究的规划与控制、合同谈判的规划、管道建设中的风险分析、核聚变电站发展中资金和行政战略的影响、研究与开发规划，以及系统可靠性。参见**决策论**；**PERT**；**模拟**。

## **妊娠期**

在哺乳动物中，受精与分娩之间的间隔。它涵盖了后代发育的总时期，包括植入前阶段（从受精到植入母体子宫）、胚胎阶段（从植入到可识别器官的形成）和胎儿阶段（从器官形成到分娩）。

关于人类妊娠期的持续时间存在广泛混淆，这是由于其医学定义方式所致。受孕和排卵的时间，即受精的时间，在人类中很难确定，因此出于纯粹实际原因，医生将妊娠持续时间测量为最后一次月经周期与分娩之间的间隔，通常约为 40 周或 280 天。然而，为了与其他哺乳动物进行比较，人类从受精到分娩的真正妊娠期约为 267 天。

哺乳动物妊娠期的长度主要取决于体型大小和出生时后代的发育状态。体型较大的母亲生体大的后代，需要更长的发育时间，发育也因其出生时处于先进发育阶段而延长。与其他所有哺乳动物相比，人类被发现具有相对于体型最长的妊娠期之一。哺乳动物妊娠期的一个显著特征是它们在物种内部显示出非常小的变异性。在排除例外情况后，偏离平均值的情况通常不超过 ±4% 的范围。这是在任何生物维度中发现的最小变异度之一。参见**受精**；**妊娠**；**生殖系统**。  
[R.D.M.a.]

## **间歇泉**

一种以或多或少规律的间隔向空气中排放水柱或蒸汽柱的天然泉水或喷泉。也许最著名的间歇泉地区位于怀俄明州的黄石公园，那里有 100 多个活跃的间歇泉和 3000 多个非喷发的温泉。

人们相信间歇泉的喷发作用源于地表不远处存在非常热的岩石。间歇泉的颈部通常是一个部分充有水的形状不规则的管子，水是从周围岩石渗入的。在管道深处，由于上方水柱的压力，水的温度远高于表面的沸点。由于下方的火山热源，其温度不断升高。最终，过热的水变成蒸汽，将水柱从孔中提升出来。  
[N.S.R.K.L.u]

## **鬼影（光学）**

在光学系统的像平面上出现的非期望图像。光学系统的每个表面将入射光分为两部分：(1) 反射光，其返回第一种介质；(2) 折射光。当反射光依次击中另一个分隔表面时，它再次被分为两部分。这样反射两次的光形成一个图像，该图像可能靠近主像平面。这可能是物体的伪像，或者是光学系统视场内明亮光源的失焦图像。因此，可能出现大量非期望或鬼影图像。参见**光学像**；**电磁辐射的反射**；**波的折射**。

如果鬼影严重失焦，它们只会降低主像的对比度。当它们靠近焦平面时，其影响可能非常令人烦恼。如果仪器视场内有一个明亮的光源，这种效果尤其明显，因为光源的鬼影可能比期望物体的图像更亮。用氟化钙和其他材料的层涂覆透镜几乎消除了现代光学系统中的鬼影。  
[M.H.I.]

## **巨核共振**

整个核子的基本振荡模式，与耦合机械系统的正常振荡模式密切相关。巨核共振系统地出现在大多数（如果不是所有）核子中，振荡能量通常在 10–30 MeV 的范围内。最著名的例子之一是巨电偶极（E1）共振，其中所有质子和所有中子以相反相位振荡，产生大的随时间变化的电偶极矩，充当辐射伽马射线的高效天线。参见**伽马射线**。

巨共振通常用三个特征量子数分类：L、S 和 T，其中 L 是轨道角动量，S 是固有自旋，T 是由共振振荡携带的异旋。数字 L 也是多极阶数，可能的值为 L = 0（单极）、L = 1（偶极）、L = 2（四极）、L = 3（八极），等等。自旋量子数 S 为 0 或 1。S = 0 的共振通常称为电的，而 S = 1 的称为磁的（EL 或 ML，其中 L 是多极阶数），源于这些巨共振具有强衰变模式的事实，涉及发射电的（对于 EL 共振）或磁的（对于 ML 共振）与共振具有相同多极阶数的多个光子。S = 0 的巨共振对应于核质量（或电荷密度）的纯空间振荡，而 S = 1 的对应于自旋振荡。异旋量子数 T，也是 0 或 1，决定了中子相对于质子的相对相位：在 T = 0 的同位标量巨共振中，中子和质子以同相振荡，而在 T = 1 或同向矢共振中，中子和质子以相反相位振荡。参见**多极辐射**；**核磁矩**。

这些共振被称为“巨”是因为它们具有巨大的强度，达到理论极限的 50–100%，集中在紧凑的能量区域。振荡能量是巨共振类型的特征，由恢复力和核质量决定；力源于核子之间的核吸引力，其中最重要的部分是与巨共振具有相同多极阶数的分量。巨电偶极（E1）共振是最古老和最好的核巨共振。它是伽马射线引发的反应中的主要特征。吸收伽马射线诱导巨 E1 振荡，在这种情况下，它通过发射中子而分解。此共振也是逆过程中的主要特征，其中通过质子和中子轰击核产生伽马射线。同位标量巨电 E0（电单极：L = 0, S = 0, T = 0）共振在能量上非常接近巨 E1 共振，而同位标量巨电 E2（电四极：L = 2, S = 0, T = 0）共振则稍低。两者都在高能 alpha 粒子的向前角度非弹性散射中被强烈激发。同位标量 E0 共振被称为呼吸模式，因为整个核子 undergoes 纯径向振荡，交替膨胀和收缩。同位标量 E0 共振能量对于确定核压缩率很重要。

在普通的核 beta 衰变中，核内的中子转变为质子，并产生电子和反中微子。在最简单类型的 beta 衰变之一，称为 Gamow-Teller 衰变中，转化的中子除了其自旋可能反转外，其他方面不受干扰。结果是核通常获得少量能量。如果 beta 衰变涉及更高的能量量子，能量足够大，可以驱动巨 Gamow-Teller 核共振，这是一种纯自旋振荡，其中中子自旋和质子自旋反相振荡（L = 0, S = 1, T = 1）。巨 Gamow-Teller 共振是 (p, n) 反应中的强特征，其中中子从被高能质子击中的核中射出。此反应通过自旋依赖的相互作用，以类似于 beta 衰变但能量转移大得多的方式，用质子替代核中的中子。

巨 Gamow-Teller 共振的特性在某些核天体物理问题中很重要。

对巨电偶极共振的研究已扩展到高能激发热核。这些研究提供了关于此类核（特别是其形状）特性的独特信息。形状敏感性源于变形核中的共振分裂。分裂的大小给出变形的大小，而分量的相对强度决定变形的方向：长椭圆形（足球形）或扁椭圆形（门把手形）。

巨共振在自然界中发生的能量核反应中起着重要作用。最好的例子之一是超新星爆炸。电子捕获反应的速率，它冷却参与爆炸的大质量恒星的核心并加速其引力坍缩，取决于巨 Gamow-Teller 共振的特性。由坍缩产生的冲击波强度与上文在巨同位标量 E0 共振背景下讨论的核压缩率直接相关。来自恒星中心区域的更高能量中微子向外传播，并通过激发各种巨共振的非弹性散射反应加热幔层中的核。自然界中发现的某些元素可能主要作为这些反应中的巨共振衰变产物产生。另见**引力坍缩**；**中微子**；**中子星**；**核反应**；**核光谱**；**核结构**；**共振（量子力学）**。  
[K.A.S.N.]

## **巨星**

恒星演化中的一个中间状态，在此过程中，恒星在死亡前膨胀到巨大的比例。在恒星生命中最长和最稳定的阶段，恒星（如太阳）通过其致密、炎热核心深处的氢到氦的热核聚变获得能量。当氢燃料耗尽时，核心在引力作用下收缩和加热，新的氢在包围耗尽核心的壳层中点燃，恒星变得更亮、更大，表面更冷。较低的表面温度产生更红的颜色，因此常用术语红巨星。像太阳这样的恒星亮度增加 100 倍，半径增长近 50 倍。

实际上有两个分开的巨星阶段。第一个如上所述，当核心温度升高到氦点燃并聚变成碳时终止。此事件稳定了恒星，但当氦耗尽时，早期的行为会重复。恒星随后膨胀到巨大的比例，也许是两个天文单位（2.8 × 10^6 英里或 3 × 10^9 公里），变得比以前更红。它可能会脉冲，并且可以通过强风损失大部分质量。参见**赫茨普龙-罗素图**；**恒星演化**。  
[P.J.B.a.]

## **贾第虫病**

由原虫寄生虫 *Giardia lamblia*（蓝氏贾第鞭毛虫）引起的一种疾病，特征为通常持续 1 周或更长的慢性腹泻。腹泻可能伴有一个或多个以下症状：腹部绞痛、腹胀、排气。
