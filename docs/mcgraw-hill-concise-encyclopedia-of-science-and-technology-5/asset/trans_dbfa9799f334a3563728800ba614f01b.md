### 磁通量与磁通密度

磁通量是根据磁场对电荷施加的力来定义的。这些力可以通过磁通量随时间的变化 [式 (1)] 来描述，这种变化既可能由相对于源的相对运动引起，也可能由源电流的变化引起，后者描述了电荷加速度的效应。

由于平行导线中流动的电流所产生的磁能（或机电能）取决于导线间的间距，因此导线会受到倾向于改变其构型的力。载有电流 i 的导线微元受到的力 dF 由式 (12) 给出：

```
dF = Bi dl 牛顿 (12)
```

这提供了由施加力的导线产生的磁通密度 B 的定义。B 的国际单位制单位称为特斯拉（tesla），或 Wb/m²，即 N/(A·m)。在真空或任何不可磁化的材料中，磁通密度 B 等于 μ₀H [式 (11)]。一个例子是长直导线对另一根与其平行且距离为 r 的导线每米（长度）施加的力 F。当两根导线分别载有电流 I 和 i 时，由式 (8) 可知，该力由式 (13) 给出。力 F 归因于传导电荷之间的电磁相互作用，并描述了由于它们之间的相对运动导致的静电力的相对论修正。

```
F = μ₀Ii / 2πr = 2 × 10⁻⁷ Ii/r 牛顿 (13)
```

一般来说，任何以速度 u 运动的电荷 q 都会受到由式 (14) 给出的力，其中 u × B 表示矢量量的叉积。也就是说，根据式 (15)，F 的大小取决于矢量 u 和 B（或其模量 u 和 B）之间夹角 θ 的正弦值。正电荷受到的力垂直于 u 和 B 所在的平面，并指向从 u 旋转到 B 的右手螺旋方向。相同的力也沿轴向作用在磁场中运动的导线内的传导电子上，并在导线中产生电动势。对于长度为 dl 的导线微元，当导线与 B 矢量垂直时，其感应电动势最大。方向由应用于式 (15) 的右手螺旋法则确定。

```
f = q u × B 牛顿 (14)
f = q u B sin θ (15)
```

### 磁链

穿过任意闭合路径的磁通量是通过计算穿过任何由该路径包围的表面 S 的磁力线数量来获得的。更正式地说，磁链取决于式 (17) 中给出的总和：

```
emf = uBdl (16)
Φ = ∫ BₙdS 韦伯 (17)
```

其中 Bₙ 表示 B 在面积微元 dS 法线方向上的分量。磁链的变化率给出了沿着该路径的任何导体中感应出的电动势 [式 (1)]。

线圈 [图 6] 的磁链通常通过假设线圈的每一匝都自成回路来计算，从而产生同样由许多独立闭合回路组成的磁通图案。每个回路链接部分匝数，因此它不链接相同的磁通量，乘积 NΦ 被替换为整个电路的总磁链 Φ。

任意两个线圈或电路部分之间的互感 M，定义为其中一个线圈因另一个线圈电流变化而感应出的电动势。使用 1 和 2 来区分它们，线圈 1 中感应的电动势由式 (20a) 给出，其符号约定与用于 L（称为自感）的约定一致。同样，当绕组角色互换时，线圈 2 中感应的电动势由式 (20b) 给出。该相互作用满足式 (21) 的互易条件，因此可以省略下标。

```
e = -L di/dt (18)
L = NΦ/i 亨利 (19)
e₁ = -M₁₂ di₂/dt (20a)
e₂ = -M₂₁ di₁/dt (20b)
M₂₁ = M₁₂ (21)
```

电感的国际单位制单位是亨利 [H]，或 V-s/A。负号表明 e 反对电流的增加（楞次定律）。根据式 (1)，由 N 匝线圈（每匝链接相同的磁通量 Φ）的电感由式 (19) 给出，因此亨利也是 Wb/A。当不同的匝或电路的不同部分不链接相同的磁通量时，乘积 NΦ 被替换为整个电路的总磁链 Φ。

### 静磁学

术语“静磁学”通常被解释为静电荷之间静电相互作用的磁学等价物。这种等价性最直接的描述是基于磁极，因为磁极之间的力，就像电荷之间的力一样，与距离的平方成反比。尽管尚未观察到孤立的磁极（或单极子），但作用于磁铁和线圈上的力与假设端面等效于磁极的假设是一致的。

### 磁矩

小电流环路或磁铁的磁矩可以定义为当其放置在磁场磁通密度 B 足够均匀的区域内时，作用于其上的力矩。对于一个边长分别为 a 和 b、匝数为 N 且载有电流 i 的矩形环路，在长度为 a 的对边上作用着大小相等、方向相反的力（图 7）。力的大小为 iNBA [式 (12)]，而力矩由式 (22) 给出，取决于导线之间的有效距离 b sin θ。力矩与面积 ab 成正比，当 B 与环路轴线之间的夹角 θ 为 90° 时达到最大值。任何其他形状的电流环路都可以用一组边缘相接的小矩形来替代，并将这些小矩形的力矩相加得到作用于整个环路的总力矩。任何面积为 a 的环路的磁矩定义为其最大力矩与磁通密度之比，因此其大小由式 (23) 给出。它是一个矢量量，指向沿电流流动方向旋转的右手螺旋方向。其矢量叉积表达式由式 (24) 给出。参见力矩（TORQUE）。

```
T = iNBab sin θ N·m (22)
m = iNa (23)
T = m × B (24)
m₀ = qfs (25)
```

以频率 f 轨道运动的电子等效于电流 i = qf，从而得到其磁矩的式 (25)，其中 s 是轨道面积。允许的值由量子能级决定。电子自旋也是一种量子态，同样可以可视化为小电流环路。原子核也具有磁矩。参见电子自旋（ELECTRON SPIN）；磁子（MAGNETON）；核磁矩（NUCLEAR MOMENTS）。

### 磁极化

当材料的响应控制 B 与 H 的比值时，该材料被称为具有磁性。这种行为主要由电子自旋和轨道运动产生的磁矩来解释。这些磁矩对磁场做出响应并参与磁场，这一过程被称为磁极化。这些效应在铁磁体和铁氧体中最为显著，其中的作用被描述为铁磁性。参见铁磁性（FERROMAGNETISM）；铁氧体（FERRITE）；铁磁性（FERROMAGNETISM）。
