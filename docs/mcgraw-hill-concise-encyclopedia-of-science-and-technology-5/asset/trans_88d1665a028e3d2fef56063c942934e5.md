
# 约瑟夫森效应

成对电子（库珀对）通过超导体之间的弱连接（约瑟夫森结）传输，例如成对电子通过分离两个超导体的薄介电层的隧道通道。

1962年，Brian D. Josephson 从理论上预言了库珀对通过两个超导体之间薄绝缘势垒（厚度约为几个纳米）的量子力学隧穿效应。Josephson 发现，除了由单电子隧穿产生的常规电流外，还会有一对成对电子（超流）的电流流动。Josephson 预言，如果电流不超过某个极限值（临界电流），则隧穿势垒两端不会出现电压降。这种零电压电流流动被称为直流约瑟夫森效应。Josephson 还预言，如果在隧穿势垒两端维持恒定的非零电压，则除了由未配对电子隧穿产生的直流电流外，还会有交变超流通过势垒。这种现象被称为交流约瑟夫森效应。参见《固体中的隧穿效应》。

Josephson 指出，磁场会削弱最大零电压超流的幅度。事实上，临界电流幅度的磁场依赖性正是约瑟夫森效应更显著的特征之一。环绕的超流通过隧穿势垒，将施加的磁场从约瑟夫森结内部屏蔽出去，就好象隧穿势垒本身是弱超导的一样。这种屏蔽效应导致输运电流在空间上发生变化，随着磁场强度的增加，临界电流会经历一系列的最大值和最小值。

约瑟夫森结以及包含约瑟夫森结的仪器，被应用于直流和微波频率的计量、频率计量、磁力计量、约1 K以下绝对温度的测量、电磁信号的探测与放大，以及其他超导电子学应用，如高速模拟-数字转换器和计算机。约瑟夫森结就像一个真空管或晶体管，能够将信号从一个电路切换到另一个电路；约瑟夫森隧穿电路是目前已知最快的开关。约瑟夫森结电路能够存储信息。最后，由于约瑟夫森结是一种超导器件，其功率耗散极小，因此约瑟夫森结电路可以按照制造工艺允许的程度紧密地组装在一起。约瑟夫森结计算机所需的所有基本电路元件都已开发出来。参见《低温测温学》；《超导器件》；《超导性》。[L.H.H]

# 焦耳定律

导体中产生的热量与流经它的电流之间的定量关系。J. P. Joule 通过实验确定并宣布了该定律：当电流沿着金属导体传播时，在给定时间内产生的热量与导体的电阻乘以电流强度的平方成正比。如今，该定律表述为 $H = RI^2t$，其中 $H$ 是热产生的速率（单位为瓦特，热的单位为焦耳）；$R$ 是以欧姆为单位的电阻；$I$ 是以安培为单位的电流。这一表述比有时给出的另一种表述更通用，后者规定 $R$ 独立于 $I$。此外，现在已知该定律的应用不仅限于金属导体。参见《电加热》。

# 关节（组织）

关于关节组织的文本在源文件中似乎存在碎片化，但以下内容与活动关节（diarthrodial joints）有关：

位于骨盆中两块耻骨之间的连接被称为软骨结合（symphysis）；但当透明软骨连接骨骼时，形成的是骨性软骨结合（synchondrosis），例如第一胸肋关节。活动关节具有最大的运动范围，其中关节面相互滑动并有一定程度的滚动。参见《韧带》。

活动关节的骨骼接触面覆盖着关节软骨，这是一种无血管、高度耐用的水合软组织，为关节提供缓冲和润滑功能（见插图）。关节软骨主要由水、蛋白聚糖和胶原蛋白组成。关节被纤维关节囊包围，关节囊内衬有滑膜，滑膜产生润滑滑液和关节内组织所需的营养物质。关节运动由附着在骨骼上的肌肉通过肌腱提供。连接在骨骼上的强韧且灵活的韧带稳定关节，并可能限制其运动。几种基本类型的活动关节产生不同的运动范围：枢轴关节、滑车关节、铰链关节、鞍状关节、椭圆关节和球窝关节。参见《胶原蛋白》；《骨骼系统》。[V.C.M.; R.J.F]

# 接头（结构）

两个或多个机械或结构部件结合的表面。每当机器或结构的部件被组合并固定到位时，就形成了一个接头。参见《结构连接》。

机械接头可以通过多种方法制造，但都可以归类为两种一般类型：临时接头（例如螺钉、卡扣或夹具）和永久接头（例如钎焊、焊接或铆接）。[WHI.C]

# 霍霍巴

*Simmondsia chinensis*，是唯一一种已知能产生并在其种子中储存液态蜡的植物。霍霍巴植物原产于美国西南部和墨西哥。它耐受某些最高温度和最具干旱性的地区，并作为作物在全球炎热低降雨地区进行驯化种植。这是一种宽叶常绿灌木，通常高度为3–10英尺（1–3米），可长到20英尺（6米）高。霍霍巴的种子储存液是直链酯类。霍霍巴蜡分子的大部分由含有20或22个碳原子和一个双键的酸和醇形成。双键处可以有许多改性，这使得霍霍巴作为广泛化学产品原料具有通用性。用于化妆品和润滑剂的霍霍巴蜡，如果种子生产成本降低，有潜力成为一种基本原料。霍霍巴正在世界许多地方同时开发，栽培方法多样且变化迅速。参见《脂肪和油（食品）》；《动物和植物蜡》。[D.A.P]

# 胡桃目

被子植物门（Magnoliophyta，即开花植物），双子叶植物纲（Magnoliopsida）山龙眼科（Hamamelidae）亚纲的一个目。该目由2个科组成：胡桃科（Juglandaceae），有50多种，和铁青树科（Rhoiptelaceae），仅有一种。在其亚纲中，该目以其复叶而显得独特。胡桃属（*Juglans*，包括核桃和山核桃）和山核桃属（*Carya*，包括山核桃，如 *C. illinoinis*）是胡桃科中熟悉的属。参见《山龙眼科》；《山核桃》；《被子植物》；《双子叶植物纲》；《植物界》。

# 灯心草科

被子植物门（Magnoliophyta，即开花植物），单子叶植物纲（Liliopsida）鸭跖草亚科（Commelinidae）的一个目。该目由灯心草科（Juncaceae）组成，约有300种，以及Thurniaceae科，仅有3种。在其亚纲中，该目以其退化的、主要靠风媒传粉的花以及蒴果为特征，每个心皮含一至多枚倒生胚珠。花有六枚萼片，排列成两个大致相似的轮；两组均呈膜质，通常呈棕色或绿色。参见《鸭跖草亚科》；《花》；《单子叶植物纲》。

# 结探测器

一种在反向偏置半导体结的结区内部或附近进行辐射探测的器件。电输出脉冲与入射电离辐射在结耗尽层中沉积的能量成正比。参见《电离室》。

结探测器（或更广泛地说是核半导体探测器）于1958年引入核物理研究领域，彻底改变了该领域。在探测带电粒子和伽马辐射时，这些器件通常使实验上可达到的能量分辨率比之前提高了大约两个数量级。此外，它们还提供了前所未有的使用灵活性、快速响应、小型化、免受有害的杂散电磁（和通常还有核）辐射场影响、低电压需求以及输出响应的极佳线性度。它们现在被用于各种广泛且多样的应用。它们被用于一般分析应用，在微探针和扫描透射电子显微镜中提供定性和定量分析。它们被用于医学、生物学、环境研究和太空计划。在最后一类应用中，它们继续发挥着非常基础的作用，范围从研究太阳系中的辐射场到对比外星表面。参见《粒子探测器》；《半导体》。

# 结二极管

一种半导体整流器件，其中两种相反导电类型区域之间的势垒产生整流作用。结二极管用于计算机、无线电和电视、无刷发电机、电池充电器，以及需要高直流和低电压的电化学过程。较低功率的单元通常称为半导体二极管，而较高功率的单元通常称为半导体整流器。参见《半导体》。

结二极管根据其结的制备方法、半导体材料和成品器件的一般用途类别进行分类。绝大多数现代结二极管使用硅作为基本半导体材料。在半导体制程的第一个十年中，使用锗材料，但如今已被无处不在的硅技术所取代，硅技术允许更宽的工作温度限制，并且更容易产生稳定的特性。其他材料是第 III-V 族化合物，最常见的是砷化镓，在需要其相对较大的带隙能量时使用。

在硅单元中，几乎所有类别的二极管都是通过自掩模扩散制造的，如插图a所示。例外是需要对掺杂剖面进行特殊控制二极管。在这种情况下，可以使用各种掺杂技术，包括离子注入、具有可变再结晶速率的合金化、通过中子吸收实现的硅嬗变，以及可变杂质外延生长。插图b所示的台面结构用于某些变容二极管和开关二极管，如果需要严格控制电容和电压击穿时。参见《电子开关》；《离子注入》；《整流器》。

# 结型晶体管

一种晶体管，其发射极和集电极势垒由相反导电类型半导体区域之间的pn结形成。这些结之间的距离远小于少子扩散长度，因此从发射结注入的少子在到达集电极势垒之前不会复合，从而能够有效地调制集电极势垒阻抗。结型晶体管既作为分立器件广泛使用，也用于集成电路。分立器件常用于高功率和高频应用。硅是最广泛使用的半导体材料，尽管锗仍用于某些应用。参见《晶体管》。

大多数现代晶体管是通过硅自掩模平面双扩散技术制造的。平面外延晶体管的结构在插图中以截面形式展示。在此结构中，集电极和发射极结均通过从顶表面扩散杂质形成。在现代技术中，基极和发射极扩散分两步进行：预沉积步骤，即在掩模氧化物打开的硅表面上化学沉积一层非常薄的重掺杂氧化物；以及推入扩散步骤，即在高於预沉积温度的情况下将沉积的掺杂剂扩散到硅中。化学预沉积步骤正在被直接通过氧化物进行的离子注入所取代。参见《离子注入》。
