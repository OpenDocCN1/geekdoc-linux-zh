
# **共聚焦显微镜**

一种能够生成极小物体高分辨率图像的技術，但它与传统光学显微镜的区别在于：它使用聚光镜将来自点光源的照明光聚焦到标本内部一个非常小的、衍射极限的光斑上，并使用物镜将该光斑发出的光聚焦到不透明屏幕上的一个小针孔上。屏幕后方放置着一个探测器，能够量化在任何时刻有多少光通过针孔。因为只有来自被照亮光斑内部的光才能正确聚焦并通过针孔到达探测器，所以来自光斑上方、下方或侧面结构的杂散光会被过滤掉。因此，图像质量得到了极大提升。

在任何时刻，只有最小的可能光斑被照亮，因此必须通过对感兴趣视野逐点扫描并记录每个光斑发出的光强来构建相干图像。光斑的大小等于仪器的极限分辨率，通常直径约为 0.25 微米，深度约为 0.5 微米，尽管这些尺寸会随着光波长和所用镜头系统的不同而变化。[R.J.Ta.]

# **共形映射**

数学中的一种特殊运算，其中一个坐标系中的点集被映射或变换为另一个坐标系中的对应点集，同时保留曲线对之间交角的大小。

平面 *xy* 中点集 *E* 到平面 *uw* 中点集 *F* 的映射或变换，是针对 *E* 中每个点 (*x*, *y*) 定义的对应关系，并将该点发送至 *F* 中的一个点 (*u*, *v*)，使得 *F* 中的每个点都是 *E* 中某个点的像。如果 *E* 中不同的点变换为 *F* 中不同的点，则该映射是一一的。如果映射是一一的，并且保持曲线间角度大小和方向不变，则该映射是共形的。共形映射保持小图形的形状但不保持其大小。

如果将点 (*x*, *y*) 和 (*u*, *v*) 视为复数 z = x + iy 和 w = u + iv，则该映射变为复变量函数：w = f(z)。一个重要的事实是，一一映射是共形的，当且仅当函数 *f* 是解析的且其导数 f'(z) 永远不等于零。

共形映射在二维流体力学、热传导和势论问题中非常重要。它们为分析困难的问题提供了合适的坐标变换。例如，寻找导电板中温度稳态分布的问题需要计算具有预定边界值的调和函数。如果该区域可以被共形映射到单位圆盘上，则变换后的问题可以通过泊松积分公式轻松解决，所需解即为所得调和函数与共形映射的复合。该方法有效的原因在于解析函数的调和函数总是调和的。参见 **热传导**；**流体流动原理**；**势**。

共形这一术语在更一般的背景下适用于任何曲面到另一曲面的映射。对于导航而言，一个极其重要的问题是产生地球表面的一部分到平面的一部分的共形映射。墨卡托投影和立体投影在这个意义上是共形的。参见 **地图投影**。[PLD]

# **共形光学**

共形光学系统的外表面形状经过专门选择，以优化与其使用环境之间的相互作用。通过这种共形光学窗口成像很可能遭受极端像差，需要特殊技术进行校正。光学系统的设计、制造和测试中计算密集的方法已达到一个水平，使得开发成本效益高的方法来插入这些共形窗口变得可行，这些窗口形状旨在为导弹提供更好的阻力系数。图中展示了光线通过光学系统的路径。(a) 侧视图。(b) 斜视图。(*Optical Research Associates*)

光学概念引入操作系统的尝试似乎是切实可行的。参见 **像差 (光学)**。

共形光学的关键应用在于导弹和飞机系统。导弹和飞机携带用于成像、探测和测距的光学传感器，它们必须透过飞行器的外壳观察世界。传统上，用于透过导弹和飞机外壳观察的窗口具有简单的光学形状，如平面或球面，这使得光学跟踪系统能够利用成熟技术进行操作。但是，这些在光学上有优势的窗口会通过增加阻力、气动加热或其他不利影响来降低飞行器的性能。一个例子是在导弹前端使用光学跟踪器或寻的头。使用共形窗口，其形状更紧密地符合最优的尖形卵形（ogival）形状，可以减少导弹的阻力并显著提高导弹性能。然而，这种卵形形状会产生相当大的光学像差（参见图示）。

设计共形光学的方案并不要求完全放弃对成像过程当前的理解。光学设计方法基于使用数值光线追踪来描述通过表面的波前。对表面产生像差的理解来自于一种解析方法，该方法以规定的精度描述表面和波前。由一般非球面表面产生的像差违背简单的解析描述，但可以通过拟合数值光线追踪结果获得。参见 **几何光学**。[R.R.S]

# **锥体**

…一条直线以始终与给定平面曲线（称为 *准线*）相交且通过不在准线平面上的一个点（称为 *顶点*）的方式移动。该生成直线在每个位置被称为 *锥面的素线*。顶点将曲面分为两部分，称为 *锥叶*。

如果锥体的素线与通过顶点的直线成相等角度，则该锥体称为 *旋转锥*。旋转锥的平面截面称为 *圆锥曲线*。

实心锥体的体积为 *V* = *Bh*/3，其中 *B* 是包含在准线内的底面积，*h* 是从顶点到底面平面的高度（或高）。直圆锥的体积 *V* 和表面积 *S* 分别为 *V* = π*r²h*/3 和 *S* = 2π*r* + 2π*r*，其中 *r* 表示底面半径，*l* = √(r² + h²) 表示斜高，即从顶点沿锥体素线测量到底面的距离。参见 **圆锥曲线**；**欧几里得几何**；**旋转曲面和旋转体**。[J.S.F]

# **构象分析**

研究有机分子构象的能量和结构及其化学和物理性质。有机分子不是静态实体。组成原子发生振动，基团绕键轴旋转。参见 **立体化学**。

## 线性结构

例如，乙烷中 C-C 键的旋转会导致无数种略有不同的结构，称为构象；其中一种如下所示。在乙烷的构象 (1) 中，两个碳原子上的 C-H 键对位于同一平面内，被称为重叠式（eclipsed）。圆圈代表最前面的碳原子，长线代表该碳原子与氢原子之间的键。从圆圈延伸出的键代表后方碳原子与其氢原子之间的键。构象 (1) 被称为重叠式构象。在构象 (2) 中，一个碳原子上的 C-H 键位于另一个碳原子上的 C-H 键之间。构象 (2) 被称为交错式（staggered）构象。在 (1) 和 (2) 之间存在无数种可能的构象；然而，构象 (1) 和 (2) 最具兴趣，因为它们是最大和最小能量结构。在构象 (1) 中，C-H 键中的电子和氢原子的核电荷相互排斥，导致较高的能量状态。在构象 (2) 中，电子和氢原子之间的距离最大，排斥力最小。通过旋转其中一个甲基 120° 将 (2) 转化为 (3) 需要输入能量，大约 3.0 千卡（13 千焦）每摩尔，以通过重叠式构象。与室温下的热能相比，这个量很小，乙烷中 C-C 键的旋转每秒发生约 10⁹-10¹⁰ 次。

## 环状结构
