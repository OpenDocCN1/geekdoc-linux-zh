## 活体生物发出的、可被其他生物看到的光。

与生物发光相关的酶和其他蛋白质已被开发并作为其他生物化学过程的标记物或报告基因，应用于生物医学研究。生物发光为研究和理解众多基本的生理过程（包括细胞层面和个体层面）提供了独特的工具。

尽管在发光物种的总数上较为罕见，但生物发光在系统发育上具有多样性，出现在许多不同的类群中（参见下表）。在高等植物和鱼类以上的脊椎动物中，未见发光现象，且在某些无脊椎动物门中也缺失。在某些门或分类单元中，有相当比例的属具有发光能力（例如，栉水母纲约50%；头足纲大于50%）。通常，发光属的所有成员都发光，但在某些情况下，既有发光物种也有非发光物种。

| 具有发光物种的主要类群 | 发光展示的特征 |
|---|---|
| 细菌 | 生物体持续发光；系统为自诱导的 |
| 真菌 | 菌丝和菌体产生微弱的持续光 |
| 甲藻 | 具鞭毛的藻类在受扰动时闪烁 |
| 腔肠动物 | 水母、海葵和海珊瑚水母发出闪光 |
| 环节动物 | 海洋蠕虫和蚯蚓避免发光（注：原文 elude 可能意为“逃避”或“缺乏”，此处按语境译为避免/不发光） |
| 软体动物 | 乌贼和蛤类释放发光分泌物；也具有发光器 |
| 甲壳动物 | 虾、桡足类、糠虾和磷虾具有发光器 |
| 昆虫 | 萤火虫（鞘翅目）发出闪光；双翅目昆虫发光 |
| 脊索动物 | 栉星（海参类/海星类注：Bristle stars通常指栉星）和某些种类的乌贼发出闪光 |
| 鱼类 | 许多硬骨鱼和软骨鱼发光；一些使用共生细菌；另一些自身发光；一些具有发光器 |

生物发光在海洋环境中最为普遍；其中深海（中洋深度）最为显著，一些白天的发光动物会渗透到这些深度。在这些地方，超过95%的个体可能具有生物发光。在高密度发光生物出现的地方，它们的发光会对群落产生显著影响，并可能代表后者的生态、行为和生理中的一个重要组成部分。在深海（中洋深度）以上和以下，发光个体和物种的比例降至10%以下；在沿海物种中，则低于2%。少数甲藻、细菌和真菌物种是最壮观的，但生物发光在陆地环境中很罕见。其他陆生发光形式包括马陆、蜈蚣、蚯蚓和蜗牛，但这些生物的发光并不非常明亮。

虽然发光并非代谢必需，但光的发射可以给生物体带来优势。光可以以多种方式使用。生物发光的大部分感知功能可分为四类：防御、进攻、交流和扩散以促进繁殖。

生物发光并非来自或依赖于生物体吸收的光。它来源于酶催化的化学发光，这是一个反应，其中释放的能量转化为光能。反应中间体或产物之一在电子激发态形成，随后发射光子。参见：化学发光。生物发光独立起源并进化了许多次，因此不是一个进化保守的功能。据估计，现存的发光生物来自多达30个不同的进化起源。在不同类群中，涉及的基因和蛋白质互不相关，且可能难以互相替代。发生的酶虽然在化学上不同，但分别统称为萤光素和萤光素酶。为了准确和具体，每一个都应该与特定的生物体对应标识。

发光细菌通常发出连续的光，通常是蓝绿色的。当强表达时，单个细菌每秒可能发射 $10^3$ 或 $10^4$ 个光子。大多数物种丰富栖息的一个主要场所是与另一个（更高等的）生物体相关联，无论死活，在那里发生生长和繁殖。发光细菌在海洋中无处不在，可以从大多数海水样本中分离出来。最奇特的特异性关联涉及专门的发光器（例如，在鱼类和乌贼中），其中维持着纯密度的发光细菌培养物。在硬骨鱼中，已知有11个不同的类群携带此类细菌，一个奇特的例子是手电筒鱼。

在大约70,000个昆虫属中，只有约100个被归类为发光的。但它们的光学效果令人印象深刻，尤其是在萤火虫及其近亲中。萤火虫在后段具有腹面发光器。南美洲的铁路虫，*Photrix*，在腹部环节有成对的绿光和红色的头光，而*Protophiron*具有头光和发光腹部，既有运行灯（背面）又有着陆灯（腹面）。双翅目的洞穴发光 worm（注：glow worm，发光蠕虫），属于不同的类群，可能具有不同的生化机制，从其顶丝（pergh，注：原文可能为plumule或seta的误写，此处保留原意或译为刚毛/顶丝）渗出珠状黏液串，用于捕捉被动物发出的光吸引的微小飞行猎物。萤火虫发光的主要功能是在求偶期间进行通信，通常涉及一性别发出闪光作为信号，另一性别作出反应，通常在物种特异性的模式中。两者之间的时间延迟可能是一个信号特征；例如，在一些北美物种中，它精确为2秒。但在某些情况下，闪烁模式也很重要，单个闪光的动力学特征（持续时间；起始和衰减动力学）也是如此。

萤火虫系统是第一个被表征其生物化学的系统。1947年，发现三磷酸腺苷（ATP）起到从萤火虫萤光素形成萤光素腺苷酸中间体的作用。然后，它与氧气反应，形成环状萤光素过氧化物物种，该物种分解产生 CO$_2$ 和羰基产物的激发态（从而发射光子）。萤光素酶催化萤光素与ATP的反应以及导致激发产物形成的后续步骤。
