## 盐类蒸发岩

由海水或大陆水体衍生的地表或近地表卤水在太阳蒸发作用下沉淀的盐类组成的层状沉积岩层。古蒸发岩层中的主要矿物是硬石膏（以及不同量的石膏）和岩盐，它们构成了沉积蒸发岩盐总量的85%以上。其他许多盐类构成了剩余的15%；它们在特定岩层中不同比例具有诊断意义，可指示母卤水的原始来源。参见硬石膏；蒸发；石膏；岩盐；盐（化学）；海水；沉积岩。

如今，卤水在大陆干盐湖或沿海盐湖中沉积其盐类，形成厚达数米、宽达数十公里的岩层。相比之下，古代现已埋藏的蒸发岩层往往更厚更宽；它们可以达到数百米厚、数百公里宽。大多数古代蒸发岩是在巨大的古海洋的超盐度区域内通过含盐水分的蒸发形成的，这些区域通常位于干旱的大陆内部。这些古海洋中的极浓卤水是不同比例的海洋和大陆地下水及地表水的混合体。与这些古代蒸发岩相对应的现代沉积环境很少，而对于那些当整个海洋盆地干涸时形成的岩层（例如，约550万年前的地中海），更是没有现成的对应物。参见盆地；沉积系统与沉积环境；地中海；干盐湖。

蒸发盐类通过海水、大陆水或二者混合物的太阳浓缩作用而沉淀。现代海水中所有世界的海洋中，化学成分、盐度（35‰）以及主要离子的比例几乎是恒定的，其中钠（Na）和氯（Cl）是主要离子，钙（Ca）和硫酸根（SO4）离子的含量较少（即 Na>Ca>(SO4/Cl) 卤水类型）。至少20亿年以来，岩盐和石膏/硬石膏一直是海水蒸发的主要产物，但更盐类矿物（如光卤石/硫酸镁 MgSO4）的比例似乎变化更大。参见钙；氯；离子；镁；钠；硫。
[J.W.]

## 沙门氏菌病

由*沙门氏菌*引起的疾病。包括肠炎和伴有或不伴有肠炎的败血症。*伤寒沙门氏菌*、*副伤寒沙门氏菌* A、B、C型，以及偶尔的*鼠伤寒沙门氏菌*分别引起称为伤寒和副伤寒的特定类型败血症；而其他所有类型可能引起肠炎、败血症或两者兼有。

伤寒的潜伏期为5–14天。其典型特征为发病缓慢，初期有支气管炎、腹泻或便秘，特征性的热型（发热持续1周，平台期2周，退热2–3周），脉搏缓慢，玫瑰疹出现，脾脏肿大，以及常伴有意识改变；并发症包括肠穿孔和骨髓炎。伤寒病愈后，患者具有较高的免疫力。口服疫苗可为个体提供约3年的显著保护。唯一有效的抗生素是氯霉素。参见抗生素；免疫；疫苗。

副伤寒的病程较短，通常比伤寒轻。疫苗接种不是有效的防护措施。

肠热症，即由前述以外的沙门氏菌类型引起的败血症，在美国比伤寒和副伤寒更常见，但远少于沙门氏菌肠炎。在儿童和既往健康的成年人中，肠热症最常被误认为是肠炎，且预后良好。涉及的病原体与引起沙门氏菌肠炎的病原体相同。治疗使用氯霉素或氨苄西林。然而，已观察到耐药菌株。参见药物耐药性。

*沙门氏菌*引起的小肠炎症是重要的细菌性人畜共患病之一。最常见的病原是*S. 鼠伤寒沙门氏菌*、*S. 肠炎沙门氏菌*、*S. 纽波特*、*S. 哈达里*、*S. 婴儿型*和*S. 德尔比*。潜伏期从6小时到几天不等。腹泻和发热是主要症状；肠道上皮受到侵袭，早期菌血症的可能性很大。易感人群包括患某些基础疾病者（同肠热症）、老年人、幼儿以及术后患者。抗生素治疗仅能延长带菌状态，对疾病本身无影响。[A.W.V.G.]

## 鲑形目

一个包括鲑鱼及其近缘物种的硬骨鱼类纲。它们构成了大多数高等真骨鱼类演化的基干。

鲑形目是一类一般化的鱼类，其特征为鳍条柔软或有关节；背鳍通常存在但位置较低；栉鳞（平滑）；腹鳍位于腹位（躯干后部）；通常有超过6根鳍条，且鳍膜与胸鳍骨分离；胸鳍位置较低且略呈水平；上颌通常由前上颌骨和上颌骨构成；前上颌骨不可前伸；没有韦伯氏器连接 swim bladder（鱼鳔）和内耳，但有一根导管将鱼鳔与肠相连；鳃盖骨条在数量和排列上多变。

鲑形鱼类化石记录不完善；它们在白垩纪已存在，且可能更早。该目包括8亚目、37科、约212属和约950种。大多数是海水鱼，在所有海洋中都很常见。少数适应于表层水或沿岸水域，大多数生活在斜温层，有些耐受极地海域，许多栖息于温暖或寒冷的淡水，或为溯河洄游性鱼类；即进入淡水繁殖。

鲑形亚目包括许多最重要且最著名的鱼类，特别是在鲑科（salmon, trout, whitefishes, 白鲑, graylings, 茴鱼）中。银汉鱼亚目（argentinees, 深海银汉鱼, 及相关鱼类）、鮗亚目（lickichaddes, 鮗科鱼类）和蝙蝠鱼亚目主要分布于深海。南乳鱼亚目主要分布在南温带地区的淡水小型鱼类中，特别是澳大利亚和新西兰。胡瓜鱼亚目是一个小群体，包括北方淡水中的胡瓜鱼和泥狗鱼。角鱼亚目，如光鱼及其近缘类，栖息于海洋中部深度。它们体型小且常呈畸形，并配备发光器。灯笼鱼亚目是最大的亚目。所有物种均生活在海水中；一些包括蜥鱼科鱼类栖息于沿岸水域，但大多数为大洋性。生活在中等至较大深度的种类，如灯笼鱼，通常在头部和身体上有发光器。参见发光器腺；真骨鱼类。
[R.M.B.]

## 盐（化学）

当一种酸中的一个或多个氢原子被一种碱中的一个或多个阳离子取代时形成的化合物。常见的例子是氯化钠，其中盐酸的氢离子被氢氧化钠的钠离子（阳离子）所取代。由于已知酸和碱的数量庞大，因此盐的种类繁多。

盐可以通过几种方式分类。一种方法——正盐、酸式盐和碱式盐——取决于酸的所有氢离子或碱的所有氢氧根离子是否被完全取代：

| 类别 | 示例 |
| :--- | :--- |
| 正盐 | NaCl, NH₄Cl, Na₂SO₄, Na₂CO₃, Na₃PO₄, Ca₃(PO₄)₂ |
| 酸式盐 | CaHPO₄, NaH₂PO₄, Na₂HPO₄, NaHSO₄ |
| 碱式盐 | Pb(OH)Cl, Sn(OH)Cl |

另一种方法——单盐、复盐（包括矾）和络盐——取决于离子化的特性：

| 类别 | 示例 |
| :--- | :--- |
| 单盐 | NaCl, NaHCO₃, Pb(OH)Cl |
| 复盐 | KCl·MgCl₂ |
| 矾 | KAl(SO₄)₂, NaFe(SO₄)₂, NH₄Cr(SO₄)₂ |
| 络盐 | K₃Fe(CN)₆, Co(NH₃)₆Cl₂, K₂Cr₂O₇ |

参见酸与碱；化学键。

## 盐（食品）

化学化合物氯化钠。它在食品工业中广泛用作防腐剂和调味料，也在化学工业中用于制造氯和钠。参见氯；食品防腐；盐（化学）；钠。

盐最初是通过蒸发海水制成的（太阳盐）。这种方法仍然普遍使用；然而，太阳盐中的杂质使其不满足大多数商业用途，且这些杂质还会导致结块。从海水蒸发池中新鲜生产的盐可能含有大量的嗜盐（喜盐）微生物。在美国，精制盐取自位于密歇根州和路易斯安那州的地下矿床。在精炼过程中，盐通常作为卤水进行处理。

盐在高湿度时期容易结块，因此会添加防结块剂。使用的材料包括碳酸镁和某些硅酸盐。在存在碘缺乏的地区会添加碘化物。

## 盐丘

结晶岩盐及其伴生变形沉积物的上涌构造。盐枕是一种未成熟的盐丘，由被整合地层覆盖的变形沉积物组成。盐柱是一种宽阔的、成熟的、温性的盐岩上涌体，它穿透了上覆地层，或看起来已穿透了上覆地层。大多数盐柱宽和高为0.6英里（1–10公里）。盐丘与其他盐岩上涌体关系密切，其中一些体型要大得多。由盐丘和盐舌合并形成的盐盖，宽度可超过200英里（300公里）。参见上涌体。

石油和天然气的勘探在100多个沉积盆地中发现了盐丘，这些盆地中含有数百米或更厚的岩盐层。盐是从裂谷、山间盆地，尤其是沿离散型大陆边缘的蒸发湖中沉淀出来的。盐丘存在于所有海洋和大陆。参见卤水。

盐丘主要由岩盐（NaCl，即普通食盐）组成。其他蒸发岩，如硬石膏（CaSO₄）和石膏（CaSO₄·2H₂O），在岩盐内部形成较薄的层。参见岩盐；盐类蒸发岩。

盐丘提供工业商品，包括燃料、矿物、化学原料和存储腔室。世界上许多盆地中，巨大的油田和天然气田与盐丘有关，特别是在中东、北海和南大西洋地区。盐丘还用于储存原油、天然气（甲烷）、液化石油气以及放射性或有毒废物。参见油气储存。

## 盐效应蒸馏

一种萃取蒸馏过程，其中使用在系统液相中可溶的盐来替代引入萃取蒸馏塔中的常规液体添加剂，以实现分离。

萃取蒸馏是一种用于分离含共沸物系统或相对挥发度过低的系统的过程。向塔中提供能够提高系统相对挥发度并消除共沸的添加剂（或分离剂），它与进料组分混合并发挥作用。随后，通过单独的过程从其中一个或两个产品流中回收该剂并循环再使用。参见共沸混合物。

在盐效应蒸馏中，过程基本上与液体剂相同，尽管用于回收剂以便循环的后续过程不同；即使用蒸发而不是蒸馏。盐通过在塔顶重新进入的回流蒸汽中溶解而添加到系统中。由于盐不挥发，它将停留在液相中，沿塔向下流动，并从底部产品流中排出。

盐效应蒸馏的主要商业用途是浓缩硝酸水溶液，使用硝酸镁作为分离剂。其他商业应用包括使用氯化钙分离丙酮-甲醇，以及使用同一种盐分离异丙醇-水。参见共沸蒸馏；蒸馏。

## 盐腺

一种专门位于海洋龟、蛇、蜥蜴以及如鹱、鸥、信天翁等在海面上度过大量时间的鸟类眼睛和鼻腔周围的腺体。在海龟中，它是喉部的附属腺体，开口于结膜囊中。在航海鸟类和海洋蜥蜴中，它开口于鼻腔。盐腺分泌大量的含水液体，其中含有高比例的盐，高于这些物种尿液中的盐分含量。因此，这些动物能够饮用含盐量高的海水而不会经历通过肾脏途径排出多余盐分所必需的脱水过程。参见腺体。

## 盐沼

一种以适应了持续或周期性洪泛的草类、莎草科植物和其他植物为特征的海洋栖息地。盐沼主要分布在温带和亚热带地区。

潮汐是盐沼的主要特征。潮汐的盐度决定了能在沼泽系统中存活的植物和动物。潮汐的垂直范围决定了洪泛深度，从而决定了植被的高度。潮汐周期控制植被被淹没的频率和持续时间。潮汐划定两个区域：低盐沼和高盐沼。低盐沼通常随着潮汐的涨落每天两次涨退潮；位置稍高的高盐沼洪泛频率较低。参见红树林。

盐沼通常发育在沉降的海岸线上，起源于受保护的湾、潟湖、河口浅水区或沙坝后面的泥滩。它们形成于盐度较高的地方，氯化钠含量从每千分20到30不等。沿河口向上游，存在一个盐度从20降到5 ppt以下的过渡带。在上游河口，河流输入占主导地位，水中仅有微量盐分。因此，变化的盐度导致沼泽发生变化——在物种种类及其数量上。通常，盐沼中发现的物种最少，而淡水潮汐沼泽中物种最多。参见河口海洋学。

盐沼是自然界中最具生产力的生态系统之一。除了驱动高等深根植物光合作用的太阳能以及生长在表层土壤上的藻类外，潮汐能量反复将富含营养的水流扩散到沼泽表面。这些大量的活性植物物质的一部分可能被沼泽动物消耗，但最重要的价值体现在植被死亡并被微生物分解形成碎屑的时候。溶解的有机物质被释放出来，为介导湿地生物地球化学循环的细菌提供必需的能源
