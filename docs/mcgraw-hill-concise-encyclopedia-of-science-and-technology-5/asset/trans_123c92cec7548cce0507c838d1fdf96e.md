

## 熟铁

根据美国材料与试验协会的定义，“熟铁是一种铁质材料，由高度精炼金属铁在凝固过程中聚集的糊状颗粒组成，其中嵌有少量且均匀分布的渣。”这种渣是精炼过程中氧化反应产生的铁硅酸盐，其含量在不同类型的最终产品中从 1%  到 3% 不等。这种渣与铁基体金属仅呈纯粹的机械混合关系，这与钢中存在的类金属元素所形成的合金关系形成对比。参见 STEEL（钢）。

熟铁的一个显著特征是其断裂面呈碎片状或不规则状，而钢则通常呈纤维状或晶粒状。金相分析表明，这是由于类似纤维的夹杂物（slag inclusions）所致。尽管熟铁在某些应用中曾具有竞争价值，尤其是在需要耐蚀性和抗冲击性的领域，但目前熟铁的产量已非常少。参见 IRON ALLOYS（铁合金）。[J.As./J.F.W.]

## 钨钼酸铅矿

一种由钼酸铅（PbMo₄）组成的矿物。钨钼酸铅矿通常呈现黄色、橙色、红色或灰白色晶体，光泽从金刚光泽到树脂光泽不等。它也可能是致密的或粒状的。其断口为不均匀。在莫氏硬度标度上硬度为 2.7–3，比重为 6.5–7。条痕为白色。

钨钼酸铅矿在美国西部和西南部的大量地点均有发现。在亚利桑那州尤马县的 Red Cloud 矿和 Hamburg 矿发现了尺寸高达 2 英寸（5 厘米）的明亮橙色板状钨钼酸铅晶体。参见 MOLYBDENUM（钼）。[E.C.T.C.]

## 乌尔特石

一种黑色、不燃的含碳物质，产于犹他州 Uinta 县。它不溶于二硫化碳，密度约为 1.05，成分包括 79–80% 的碳、10.5–12.5% 的氢、4–6% 的硫、1.8–2.2% 的氮以及一些氧。乌尔特石源自始新世晚期（Green River 时期）沉积的页岩层。这种物质在沉积后作为流体进入碳酸盐页岩层，随后发生聚合形成结核或脉状结构。参见 ASPHALT（沥青）和 ASPHALTITE（沥青状矿物）；ELATERITE（沥青醚）；IMPSONITE（石泥）。[I.A.B.]

## 闪锌矿型硫化锌

一种组成为 ZnS（硫化锌）的矿物。它最常存在于纤维状或柱状集合体以及具有树脂光泽和褐黑色的带状皮壳中。在莫氏硬度标度上硬度为 3¾，比重为 4.0。硫化锌具有同质多象性，既结晶为高温型闪锌矿型硫化锌（wurtzite），$\alpha$-ZnS，也结晶为低温型方锌矿（sphalerite），$\beta$-ZnS。闪锌矿型硫化锌较为罕见，且在室温下稳定性较差，与方锌矿不同，极少作为锌矿石开采。闪锌矿型硫化锌通常含有铁和镉，并延伸至绿硫矿（greenockite），CdS，形成完整的固溶体系列。参见 GREENOCKITE（绿硫矿）；SPHALERITE（方锌矿）。[C.S.H.]

## X 射线天文学

研究来自河外天体的 X 射线发射，涵盖几乎所有类型的天体对象，从恒星到星系和类星体。电磁波谱中的 X 射线波段波长范围大约从 10 皮米到几十纳米，波长越短对应的光子能量越高（1 纳米对应大约 1000 电子伏特）。X 射线天文学传统上根据所研究的辐射能量分为宽波段——软 X 射线和硬 X 射线。软波段（低于约 10 keV）的观察必须在大气层以上，通过火箭或卫星进行；而硬 X 射线观察可以在气球可达到的较高海拔进行。参见 ELECTROMAGNETIC RADIATION（电磁辐射）；ROCKET ASTRONOMY（火箭天文学）；SATELLITE ASTRONOMY（卫星天文学）；X-RAYS（X 射线）。

大多数观察是在软波段进行的。巡天调查，特别是 ROSAT 全天巡天，在灵敏度约为最亮源 Sco X-1 强度的 1/100,000 的条件下定位了数万个源。其中一些源集中在银河赤道附近。这种集中对应于银河系中的天体，特别是在包含大多数银河系恒星和旋臂的银盘区域。其他的 X 射线源则均匀分布在天空中，主要与河外天体相关，如单个星系、星系团和类星体。参见 MILKY WAY GALAXY（银河系）。

### 银河系源

银河系 X 射线源已被识别为不同类型的异常天体。蟹状星云（Crab Nebula）是第一个被识别为特定天体的非太阳 X 射线源，它是恒星爆炸死亡后留下的超新星遗迹。其中心包含一颗快速旋转的中子星，以及由热气体和高能粒子组成的星云。蟹状星云 X 射线发射的约 10% 来自中子星的脉冲辐射；其余部分是与星云相关的延展发射。已经探测到许多其他银河系超新星遗迹作为 X 射线源，此外还在最近的邻近星系中探测到了超新星遗迹，尤其是在大麦哲伦云（Large Magellanic Cloud）中。参见 CRAB NEBULA（蟹状星云）；NEUTRON STAR（中子星）；PULSAR（脉冲星）；SUPERNOVA（超新星）。

虽然普通恒星会将部分能量辐射到 X 射线波段，但其中大部分光度是在光谱的可见光区域输出的。X 射线巡天发现了一类对象，其大部分能量是在电磁波谱的 X 射线部分辐射的。这些被称为 X 射线星。通过精确定位，已经可以将它们与双星系统联系起来。结合 X 射线和光学数据得出的结论是，这些系统通常由一颗相对正常的可见恒星和一颗次亮恒星组成，二者在引力束缚轨道上相互环绕。X 射线星通常是一个致密天体，如白矮星、中子星，甚至可能是黑洞。这些致密源构成了银河系辐射体中的大多数。

这些系统中 X 射线发射的理论模型由物质从正常恒星转移到致密天体组成。这个过程被称为吸积（accretion），通常导致形成盘状结构，下坠物质沿螺旋路径流向致密恒星表面。在下坠过程中，物质达到极高温度，因为引力能转化为热能，随后以 X 射线的形式辐射出来。无论致密天体是白矮星、中子星还是黑洞，人们都相信涉及类似的过程。然而，对于每种天体，预计其详细行为会有所不同。旋转的中子星会导致 X 射线脉冲星。对于白矮星，X 射线强度在数小时到数天的时间尺度上似乎存在波动，这可能指示恒星表面正在积累吸积物质，然后以热核能爆发的形式闪烁。在黑洞候选体的情况下，X 射线强度在极短的时间尺度上存在变化，表明 X 射线发射区域非常小。

另一种时间行为类型表现为所谓的“暴源”（bursters）。这些源在某个恒定水平发射，偶尔出现短暂增强亮度爆发或耀变。这些爆发很可能与此类源相关的 X 射线发射过程中的不稳定性有关。参见 BINARY STAR（双星）；BLACK HOLE（黑洞）；CATACLYSMIC VARIABLE（灾变变星）；STELLAR EVOLUTION（恒星演化）；WHITE DWARF STAR（白矮星）。

### 河外源

在检测到的有趣天体类型中，包括看似正常的星系、具有活动核心的星系、射电星系、星系团和类星体。

在星系的活动核心（具有强光学发射线和非热连续谱的星系）中，X 射线发射通常比正常星系高出几个数量级。在大多数情况下，发射来自星系核心，且基于变异性以及在当前观测极限下缺乏结构（几角秒），必须限制在一个相对较小的区域内。许多天体物理学家认为星系核心是巨大黑洞的位置，至少是太阳质量的 $10^9$–$10^{11}$ 倍，并且来自这些天体的辐射是由于下坠物质释放的引力能。X 射线光度等性质的广泛范围可能反映了黑洞的大小以及下坠物质的可用性。类星体可能代表这种现象的极端情况。许多可观测性质不仅取决于核黑洞的大小，还取决于观测者的视角。参见 QUASAR（类星体）。

星系团是由数百至数千个单个星系组成的引力束缚系统。人们发现此类星系团中星系之间的空间包含热的（大约 $10^7$–$10^9$ K）稀薄气体，该气体在 X 射线中发光，其质量等于（或超过）可见星系的质量。参见 ASTROPHYSICS, HIGH-ENERGY（高能天体物理）；GALAXY, EXTERNAL（河外星系）。

## X 射线晶体学

通过 X 射线衍射技术研究晶体结构。关于 X 射线衍射的实验方面，参见 X-RAY DIFFRACTION（X 射线衍射）。

在结构上，晶体是原子、原子团或分子在空间中的三维周期性排列。如果这种周期性模式延伸贯穿给定的材料样品，则称之为单晶。如果知道构成称为晶胞的三维周期性图案中所有原子的位置，则可以确定任何给定晶体的精确结构。晶体中原子的非常紧密且周期性的排列使其能够作为 X 射线的衍射光栅。参见 CRYSTALLOGRAPHY（晶体学）。
