
## 分布（概率）

工业控制系统已从全模拟系统演变为多级分布式系统。最初，工业控制系统完全是模拟式的，每个过程变量都由单个反馈控制器进行控制。虽然模拟控制系统简单可靠，但它们缺乏为工艺操作员提供的集成信息显示。

在监督控制中，系统的模拟部分以传统方式（包括传感器等）在中央控制室中实现，但增加了一台数字计算机，该计算机周期性地扫描、数字化并输入过程变量。计算机用于过滤数据、计算趋势、生成专用显示、绘制曲线，并计算诸如效率或质量指标等不可直接测量的关键量。一旦这些数据可用，就可以通过计算机向模拟控制器输出设定值，从而计算并实现过程的最优运行。这种控制模式被称为监督控制，因为计算机本身并不直接参与动态反馈。

直接数字控制用周期性执行的等效数字控制算法取代模拟控制，该算法在中央数字计算机中运行。直接数字控制系统周期性地扫描和数字化过程变量，并计算执行变量所需的变更，以将设定值与过程变量之间的差异减小为零。

直接数字控制的优点在于可以容易地执行复杂的动态控制功能，并且消除了模拟控制器本身的成本。为了保持模拟控制相关的直观显示优势，通常仍会保留模拟控制器的显示部分。因此，除了控制器的“整定”（增益设置）可以通过操作员控制台完成外，过程的运行方式与具有模拟控制器的数字监督控制系统相同。

引入直接数字控制所带来的成本降低被诸多缺点所抵消。其中最为显著的是可靠性下降以及优雅降级能力的完全丧失。传感器或变送器的故障与之前具有相同的影响，但计算机本身的故障会导致整个控制系统进入手动操作状态。因此，有必要为计算机停机时仍需运行的某些关键回路提供模拟控制器作为后备。

对更高级别监督控制日益增长的需求，凸显了集中式数字过程控制的两个缺点。
- 首先，控制信号仍以模拟形式从过程传感器传输到中央控制室，这意味着每个进入或离开计算机的信号都必须安装独立的导线。
- 其次，由于连接到计算机的设备种类繁多，且执行众多控制和管理功能需要多种不同的程序，数字控制系统本身演变为一个非常复杂的单元。

后者导致计算机需要一套复杂的实时操作系统，该系统能够处理动态特性、为每个任务实现所需的响应时间，并负责在高度动态的实时环境中进行错误检测和错误恢复。集中式数字控制系统的代码设计、安装和调试成本高昂且耗时，因此集中式数字控制的应用受到限制。

利用大规模集成电路的低成本电子硬件为解决这两个问题提供了技术，同时保留了集中式集成数字控制和监督控制的优点。解决方案——分布式控制——涉及将控制功能分配给硬件模块，以消除关键的中央计算机。

可靠、响应迅速的分布式控制与通用通信网络的结合，产生了一个可以以非常灵活的方式适应关键控制应用的系统，并具有提高工厂生产率、增强安全性和降低能源消耗的潜力。用于高速计算、数据通信和面向对象软件组织的新技术，使得分布式控制系统能够集成到全厂甚至全企业级的系统中。

### 分布（概率）

一系列独立试验、随机变量或误差的结果通常以相当规则且可预测的模式出现，这些模式可以用数学表达。其中最重要者被称为二项分布、正态分布和泊松分布。

考虑 *n* 个独立试验，每个试验的结果要么成功 *S*，要么失败 *F*，相应的概率为 *p* 和 *q = 1 - p*。设 *S_k* 表示成功的次数。由于有 $\binom{n}{k}$ 种方式来选择 *S* 的 *k* 个位置以及 *F* 的 *n - k* 个位置，随机变量 *S_k* 的概率分布由下式给出：

$$ P(S_k = k) = \binom{n}{k} p^k q^{n-k} $$

其中 *k* = 0, 1, ..., *n*。这就是二项分布。其期望值为 *np*，方差为 *npq*。参见“概率”条目。

标准正态分布定义为 $\(-\infty < x < \infty\)，其概率密度函数为 \(\phi(x) = (2\pi)^{-1/2} e^{-x^2/2}\)。标准正态分布函数或误差函数 \(\Phi(x)\) 是其在 \(-\infty\) 到 *x* 上的积分。具有均值 *m* 和方差 *s* 的正态分布函数为 \(\Phi((x - m)/\sqrt{s})\)；其密度为 \((2\pi)^{-1/2}s^{-1/2}e^{-(x-m)^2/(2s^2)}\)。当 *x* 从 \(-\infty\) 变化到 \(+\infty\) 时，该函数从 0 增加到 1。它在许多领域中发挥着重要作用。特别是，*u*(*t,x*) = \((2\pi t)^{-1/2}e^{-x^2/(2t)}\) 是热（或扩散）方程 *u_t* = *u_xx* 的基本解，它表示初始集中在 *x* = 0 处的单位热源在时间 *t* 时在 *x* 轴上引起的热分布。从概率角度看，这代表了维纳过程中的转移概率。分布为正态的随机变量被称为正态或高斯随机变量。许多重要量（例如水库中的水量、某些遗传特征如身高、以及物理测量的实验误差）代表了许多微小成分的累积效应，这些量的统计分布预计将遵循正态分布。

参数为 *\(\lambda\)* 的泊松分布是随机变量取 0, 1, 2, ... 值的概率分布，其概率为 \(p_k(\lambda) = e^{-\lambda}\lambda^k/k!\)。其期望值和方差均等于 *\(\lambda\)*。这是最重要的分布之一，在随机过程理论及许多应用中起着基本作用。

考虑大量 *n* 个独立试验，每个试验的成功或失败概率分别为 *p* 和 *q = 1 - p*。通常，兴趣集中在 *p* 非常小，但成功次数的期望值 *np = \(\lambda\)* 为中等大小的情况。典型例子可以通过考察大人群中的百岁老人、色盲患者或三胞胎获得。*n* 次试验中的成功次数是一个服从二项分布的随机变量，但在当前情况下，二项分布接近泊松分布，可以用后者替代。事实上，无成功的概率为 \((1 - \lambda/n)^n\)，这接近 *\(e^{-\lambda}\)*，即泊松分布的第一项。

在其他情况下，泊松分布并非近似值，而是自然定律的精确表达。这尤其适用于某些事件（如放射性衰变、基因突变、断电和事故）在时间上以以下方式发生的进程：(1) 事件在任意长度为 *dt* 的时间间隔内发生的概率渐近等于 *\(\lambda dt\)*，且 (2) 非重叠时间间隔之间没有相互作用或后效。类似的论证也适用于空间中点的随机分布，其中 *\(\lambda\)* 需作相应解释。
