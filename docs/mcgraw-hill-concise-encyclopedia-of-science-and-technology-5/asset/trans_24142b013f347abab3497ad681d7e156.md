
反证法不予采纳。反证法也被称为*归谬法*或否定法，它等价于亚里士多德的中道律。它暂时假设待证的命题为假，并从这个假设推导出与先前已确立的定理相矛盾的结果。

**数学中的空间。** 如果几何学是空间的数学，那么从表面意义上看，所有数学都始于几何学，因为几何学涉及对图形的测量：长度、面积、体积和角的大小。它不关心形状的问题，而是阐明和判定图形在形式上是相等还是实质相等。第一个真正的几何理论是希腊人的，他们主要关注图形相等的基本概念——即它们的合同和相似——希腊人如此坚决地希望将其理论与之前仅仅进行测量的阶段区分开来，以至于例如欧几里得的广泛著作避讳进行任何实际的测量。然而，尽管希腊几何学目标高远，但它过于僵化和狭隘，无法真正处理空间的数学问题。直到笛卡尔及其先驱引入坐标系，开启了更好的空间数学之后，几何学才进一步取得进展。

如果一个笛卡尔坐标系被刻入二维或三维欧几里得空间，那么空间就变成了一个点集，每个点是一对实数 (x¹, x²) 或三元组 (x¹, x², x³)，任何图形都是它的一个合适子集。这是一个刻意的空间算术化过程，它在基础统一了形状和数字。这并不意味着几何学的任务是追求形状问题，而是帮助它。在笛卡尔平面中，如果一个图形的点可以通过某种变换从另一个图形的点获得，则两个图形相似。方程 (1) 中，方程 (2) 适用，且对于某个 ρ < 0，方程 (3) 可以写成。当且仅当 ρ = 1 时（正交变换），该相似性是合同变换。现在，这种合同和相似性的解析表示暗示了最一般线性变换的几何表示，即方程 (1) 中非奇异的线性变换，也就是说，其行列式 \|[aᵢʲ]\| ≠ 0。希腊人实际上对它们并不了解，尽管它们突出了欧几里得几何中的平行公理。笛卡尔平面的一一变换是这种线性变换当且仅当它将直线映射到直线，且将平行直线映射到平行直线。

```
y¹ = a¹ + aᵢ¹xᵢ + αᵢ¹xᵢ  
y² = a² + aᵢ²xᵢ + αᵢ²xᵢ  
α¹ · α² + α¹ · α¹ · α¹, α²² = 0  
\|(α¹)² + (α¹)²\| = (α²²)² + (α¹)² = ρ²  
```

所有线性变换的族构成一个传递群，而正交变换的子族已经是一个传递群。F. Klein 提出了一个普遍接受的论断，即如果在一个空间上给定了一个变换的传递群，那么在这个空间上就会产生一个几何学；只要一个图形可以通过其中一个变换映射到另一个图形，这两个图形就被视为相等。

空间的算术化导致了 n 维空间（欧几里得空间和其他空间）的纯数学创造，对于任意整数维度 n，通过将其点一般地定义为实数的 n 元组 (x¹, …, xⁿ) 并给出这些点之间各种几何关系的适当定义。这种应用中最著名的是相对论理论中的四维空间，但事实上，多维几何在此之前已经在物理学中发挥作用。如果一个力学系统涉及 M 个质点，实际上习惯于引入维度为 n = 3M 的空间，其点是系统的状态，即任意时刻点处的坐标 n 元组 {x_m¹, x_m², x_m³}，其中 m = 1, …, M。此外，如果系统中存在约束，则拉格朗日-哈密顿理论通过使用系统的自由参数而不是原始的 n 个坐标本身，实质上减少了空间的维度。自由参数的使用从力学系统扩展到了物理学和化学中的其他系统，所有所谓的状态方程都以此为依托。最后，在量子理论中，系统的状态具有无限多个坐标，表示它的无限维空间是一个希尔伯特空间。也部分受希尔伯特空间的影响，数学家们对一般意义上的无限维空间产生了浓厚的兴趣。它们正在被深入研究，数学的很大一部分正被纳入这些新的参考框架中。

空间的算术化也反映在图表使用的不断扩展中。参见 代数；向量微积分；几何学；拓扑学。

## 基质隔离

一种使分子在低温下保持以供光谱研究的技术。该方法特别适用于在固体惰性环境中保存反应性物种。难以捉摸的分子碎片，如作为控制反应中化学转化重要工业中间体的假设自由基、在极高温度下与固体处于平衡的高温分子，以及在等离子体放电或高能辐射中产生的分子离子，都可以通过吸收（红外、可见光和紫外）、电子-核共振以及激光光谱技术进行检查。

基质隔离实验的实验装置在设计时考虑了分子瞬态的产生方法和进行光谱分析的方法。插图显示了用于吸收光谱测量的真空容器的横截面。基质样品通过喷涂线引入；氩是最广泛使用的基质气体，尽管氖、氪、氙和氮气也被使用。反应性物种可以通过多种方式产生：通过石英窗口对被困的前驱体分子进行汞蒸气光解；从加热器中的克努森细胞中蒸发；从克努森细胞中蒸发的原子与通过喷涂线沉积的分子发生化学反应；以及来自通过管子流动的放电激发原子的辐射对沉积在喷涂线上的分子进行真空紫外光解。对于激光激发研究，样品沉积在一个倾斜的铜楔上，该铜楔被激光束掠过，然后由摄谱仪检查以大约 90° 发射或散射的光。在电子自旋共振研究中，样品被限制在一根蓝宝石杆内，该杆可以放入必要的波导管和磁体中。
