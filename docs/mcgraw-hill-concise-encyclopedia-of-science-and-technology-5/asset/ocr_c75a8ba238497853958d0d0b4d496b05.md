# Mathematical logic

+   - *p*, *q*, *P*(*)x*)
+     Sentences, propositional functions, propositions
+   - ¬*p*, ¬*q*, non *p*, ¬*p*
+     Negation, read “not *p*” or: ¬ “not equal”
+   - *p* ∨ *q*, *p* + *q*, *Apq*
+     Disjunction, read “*p* or *q*,” “*p*, *q*,” or both
+   - *p* ∧ *q*, *p* · *q*, *p&q*, *Kpq*
+     Conjunction, read “*p* and *q*”
+   - *p* → *q*, *p* ⊃ *q*, *p* = *q*, *Cpq*
+     Implication, read “*p* implies *q*” or “if *p* then *q*”
+   - *p* ↔ *q*, *p* ≡ *q*, *p* = *q*, *Eqp*, *p* iff *q*
+     Equivalence, read “*p* is equivalent to *q*” or “*p* if and only if *q*”
+   - *n.a.s.c.*
+     Read “necessary and sufficient condition”
+   - ( ). [ ]. { } . . .
+     Parentheses
+   - ∀ *x*, ∀ *x*
+     Universal quantifier, read “for all” or “for every”
+   - ∃ *x*, ∃ *x*
+     Existential quantifier, read “there is” or “there exists”
+   - ⊢
+     Assertion sign (⊢ read “*g* follows from *p*”; ⊢ read “*p* is or follows from an axiom,” or “*p* is a tautology”)
+   - 0, 1
+     Truth, falsity (values)
+   - Identity
+     *a* = *a*, *a* ≠ *a*
+     Definitional identity
+   - ∎
+     “End of proof”; “QED”

# Set theory, relations, functions

+   - *X*, *Y*
+     Sets
+   - *x* ∈ *X*
+     *x* is a member of the set *X*
+   - *x* ∉ *X*
+     *x* is not a member of *X*
+   - *A* ⊂ *X*, *A* ⊆ *X*
+     Set *A* is contained in set *X*
+   - *A* ∄ *X*, *A* ∌ *X*
+     *A* is not contained in *X*
+   - *X* ∪ *Y*, *X* + *Y*
+     Union of sets *X* and *Y*
+   - *X* ∩ *Y*, *X* · *Y*
+     Intersection of sets *X* and *Y*
+   - +, -, ∪
+     Symmetric difference of sets *X* and *Y*
+   - ∪*X*ᵢ, ∩*X*ᵢ
+     Union of all the sets *X*
+   - ∅, ∅
+     Null set, empty set
+   - *X*′, *C*₂ *X*
+     Complement of the set *X*
+   - *X* − *Y*, *X* *Y*
+     Difference of sets *X* and *Y*
+   - *A*(*P*)(*x*), {*x*: *P*(*x*)}, {*x*: *P*(*x*)}
+     The set of all *x* with the property *P*
+   - (*x*, *y*, *z*), (*x*, *y*, *z*)
+     Ordered set of elements *x*, *y*, and *z*; to be distinguished from {*x*, *y*, *z*}, for example
+   - {*x*, *y*, *z*}
+     Unordered set, the set whose elements are *x*, *y*, *z*, and no others
+   - {*a₁*, *a₂*, … , *a*ₖ}; {*b₁*, *b₂*, … , *b*ₖ*}, {*c₁*, *c₂*, … , *c*ₖ*}
+     The set whose members are *aᵢ*, where *i* is any whole number from 1 to *n*
+   - {*a₁*, *a₂*, … }, {*b₁*, *b₂*, … , *b*ₖ*}, {*c₁*, *c₂*, … , *c*ₖ*}
+     The set whose members are *aᵢ* where *i* is any positive whole number
+   - *X* × *Y*
+     Cartesian product, set of all (*x*, *y*) such that *x* ∈ *X*, *y* ∈ *Y*
