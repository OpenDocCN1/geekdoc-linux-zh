
## 层次分析法

层次分析法是一种表示问题要素的系统化程序。它通过将问题分解为更小的组成部分，对基本理性进行组织，然后要求进行简单的成对比较判断，并在每个层级中制定优先顺序。

层次分析法提供了一个全面的框架，以便同时在判断中应对直觉、理性和非理性因素。它是一种将感知和目标整合为整体综合的方法。层次分析法并不要求判断必须一致，甚至不要求具备传递性。判断的一致程度（或不一致程度）会在层次分析法结束时显现。

进行比较的人们会使用他们的感觉和判断。这些感觉和判断在强度上各不相同。为了区分不同的强度，表中的绝对数字量表是有用的。

层次分析法可以分解为以下步骤。在某些情况下，特定步骤可能被比其他步骤更强调。此外，如上所述，互动通常有助于激发思考并表达不同观点。

1.  定义问题并确定需要寻求的知识。
2.  构建层次结构，从顶层（从宏观角度看待的目标）到中间层（下层所依赖的标准），再到下层（通常是一组备选方案）。
3.  为每个下层构建一组成对比较矩阵，对上一层的每个元素构建一个矩阵。由于高层元素会对下层元素产生贡献和影响，因此高层元素被称为下层元素的治理元素。在一个完整的简单层次结构中，下层中的每个元素都会影响上层中的每个元素。然后，根据下层元素对上方治理元素的影响，将这些元素相互进行比较。这会生成一个由判断值组成的方阵。成对比较是在哪个元素占主导地位的基础上进行的。这些判断值随后根据表中的判断值表示为整数。如果元素A支配元素B，则在行A、列B中填入整数，在行B、列A中填入倒数（分数）。
4.  开发步骤3中的矩阵集需要$n(n-1)/2$个判断，其中n是下层的元素数量。
5.  在收集了所有成对比较数据，并填入倒数以及主对角线上的n个单位项之后，求解特征值问题 $Aw = \lambda w$，并通过$\lambda_{max}$与n的偏差（见下文）来测试一致性。
6.  对层次结构中的所有层级和簇执行步骤3、4和5。
7.  现在使用层次综合法，根据标准的权重对特征向量进行加权，并对对应于层次结构中下层的加权特征向量项求和。
8.  整个层次结构的一致性比率通过将每个一致性指标乘以相应标准的优先级，然后将它们相加来找到。然后，使用与之前相同类型的表达式，以根据优先级加权的各矩阵维度的随机一致性指标除以该结果。可接受的一致性比率应约为10%或更低。如果不符合，则应提高判断的质量，也许通过修改成对比较中提问的方式。如果这样仍无法提高一致性，则很可能需要对问题进行更准确的结构化，即相似的元素应分组在更有意义的标准下。此时需要回到步骤2，尽管可能只需修订层次结构中有问题的部分。参见 决策理论；系统工程。 [T,L,S]

### 相对重要性量表

| 相对重要性强度 | 解释 |
| :--- | :--- |
| 1（同等重要） | 两项活动对目标的贡献相等 |
| 3（一项比另一项稍重要） | 经验和判断稍倾向于某一项活动优于另一项 |
| 5（中度或强烈重要） | 经验和判断强烈倾向于某一项活动优于另一项 |
| 7（明显重要） | 某项活动被强烈偏好，且其优势在实践中得到证实 |
| 9（绝对重要） | 支持一项活动优于另一项的证据达到了最高程度的确定性 |
| 2, 4, 6, 8（两个相邻判断之间的中间值） | 当需要折中时使用 |
| 上述非零数字的倒数 | 如果某项活动在与第二项活动比较时被分配了上述数字之一，那么第二项活动在与第一项活动比较时则具有倒数值 |

## 分析化学

分析化学是化学表征和测量科学。定性分析关注用元素、化合物或结构单元描述化学组成，而定量分析关注数量的测量。

分析化学过去仅限于用样本中元素或化合物的相对含量来确定化学成分，现已扩展至改善样本中不同晶体形式的空间分布、区分给定元素或化合物的不同晶体形式、区分不同的化学形式（例如元素的氧化态）、区分颗粒表面或内部组分，以及检测表面上的单个原子。

为了能够回答这些更详细的问题，同时提高传统分析的速度、准确性、敏感性和选择性，使用了大量的物理测量方法。这些方法基于光谱、电化学、色谱、化学和核原理。

现代分析对样品处理技术也提出了重大需求。例如，作为分析生物流体等复杂混合物的部分，需要处理非常小的液体样本 [在纳升（$10^{-9}$ 升）范围或更小]，同时确定许多不同的组分。样品可能是需要通过汽化转化为适合分析形式的固体。

光谱学包括测量由样品与谱系高能端的伽马射线和X射线以及能量较低的紫外线、可见光、红外线和微波辐射相互作用所产生的发射、吸收、反射和散射现象。参见 光谱学。

较低能量的激发形式，如紫外线、可见光或红外辐射，用于分子光谱学。反映分子电子结构的紫外辐射和可见光被广泛用于定量分析。测量样品吸收的辐射。也可以测量辐射的发射（荧光）。红外辐射的吸收受原子间键合性质的控制，因此最广泛用于结构鉴定和确定。除如一氧化碳（CO）和烃类等气体外，红外光谱不常用于定量分析。X射线通过发射特征辐射、吸收或衍射来使用。在衍射情况下，特征衍射图案揭示特定结构实体的信息，如特定的晶体形式。扩展X射线吸收精细结构（EXAFS）基于使用同步加速器源的X射线来揭示如原子间距等结构细节。参见 红外光谱学；X射线荧光分析。

尽管严格来说不是光谱技术，但质谱分析是一种重要且应用日益广泛的方法，特别是对于有机和生物样品。其应用包括70多种元素的分析（火花源质谱法）、表面分析（二次离子质谱法和离子探针质谱法）以及有机分子、蛋白质和肽结构的测定（高分辨率质谱法）。参见 质谱分析。

核磁共振测量单个原子周围的磁性环境，并提供推导分子结构的最重要手段之一。通过监测其核自旋与施加的外部磁场之间的相互作用，对具有核自旋的原子进行探测。对于大分子，这些相互作用是复杂的，已开发出多种核激发技术，以便建立分子中不同原子之间的连接性。由于该技术是非破坏性的，可用于监测生物系统。参见 核磁共振（NMR）。

几种形式的光谱学特别适用于表面分析。扫描电子显微镜（SEM）涉及精细准直的电子束扫过表面以生成图像。同时，表面原子被激发以发射特征X射线，从而可以同时获取表面图像及其空间分辨的元素组成。该技术（电子探针）的分辨率在微米（$10^{-6}$ 厘米）范围内。通过原子力显微镜（AFM）和扫描隧道显微镜（STM）技术，已获得具有埃（$10^{-8}$ 厘米）分辨率的图像，这对应于单个原子的分辨率。后两种技术的一个显著优势是不需要高真空，因此可以在大气压条件下分析样品。参见 电子探针微区分析；电子能谱学。

电位法是最广泛应用的电化学技术，因为它包含各种离子选择性电极，其中最重要的是用于测量钠、钾、钙、硫离子、氯离子和氟离子的离子活度。当电极与气体渗透膜配合使用时，可以测量氨、二氧化碳和硫化氢等气体。参见 电化学；pH值。

分离技术包括各种形式的色谱法和电泳法。它们基于由于样品中物种混合物的差异迁移而导致的分离。有两种相反的作用力：固定相使迁移物种减速，而流动相则促进迁移。流动相可以是液体（液相色谱）或气体（气相色谱），而固定相可以是涂有薄液膜的固体。固定相通常填充在流动相通过的柱中。高效液相色谱（HPLC）对于分离复杂的不挥发材料混合物变得尤为重要。分离往往可以在几分钟内完成。固定相可以根据电荷、大小、疏水性或在某些情况下由于物种对固定相的特异性亲和力（亲和色谱）而优先与迁移物种相互作用。固定相还可以是沉积在板上的薄层固体支撑物（薄层色谱）。参见 色谱法。

或者，分离的驱动力将是带电物种在电场中的迁移（电泳）。固定相可以是板或管中的凝胶，或者是维持在毛细管中供分析物移动的溶液。该领域的重要技术包括毛细管电泳、等电聚焦和等电点聚焦。参见 电泳。

热分析方法基于在一系列温度范围内加热样品。这种方法可能导致样品吸热，或因物理或化学变化而放热。热重分析涉及质量的测量；差热分析涉及通过测量样品与稳定参考材料之间的温度差来检测化学或物理过程；差示扫描量热法评估此类过程中释放的热量。各种量热技术用于测量其他难以评估的反应程度。参见 量热法。

## 无羊膜动物

那些在发育过程中缺乏羊膜的脊椎动物，有时被称为无羊膜动物（Anamnia）。羊膜是一种保护性的胚胎包膜，在胎儿生活中包裹胚胎及其周围的液体，即羊水。羊膜存在于哺乳动物、鸟类和爬行动物中 [统称为羊膜动物]，但在鱼类和两栖动物中缺失。参见 羊膜；羊膜动物；两栖动物；鱼类（动物学）。

## 过敏反应

过敏反应是在抗原-抗体反应发生后的数分钟内发生的全身性或局部组织反应。由非免疫机制引发的类似反应被称为类过敏反应。在人类中，过敏反应的临床表现包括伴有瘙痒、红斑和荨麻疹的皮肤反应；伴有喉部和气管水肿的上呼吸道反应；以及伴有血压下降和虚脱的心血管系统反应。参见 过敏。
