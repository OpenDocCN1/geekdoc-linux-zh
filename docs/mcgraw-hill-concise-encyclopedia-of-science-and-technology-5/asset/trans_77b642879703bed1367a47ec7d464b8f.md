

# 地堑

地壳中相对两侧地块（见图）下沉的岩块，通常其长度远大于宽度。地堑的尺寸可能因情况而异。将地堑与相邻岩石分隔开的断层倾斜角度为 50° 到 70°，指向下沉地块，位移量从几英寸到数千英尺不等。这些断层上的滑动方向表明它们是重力断层。参见**断层及断层构造**；**地垒**；**裂谷**。[PH.O]

# 标量梯度

是对可微标量函数 S(x, y, z) 应用分配向量微分算子 ∇ 的结果，其中 ∇ = i ∂/∂x + j ∂/∂y + k ∂/∂z；因此 ∇S = i ∂S/∂x + j ∂S/∂y + k ∂S/∂z。字母 i, j, k 是符号，代表与 x, y, z 相关的基向量。S 的梯度也记作 grad S，而符号 ∇ 通常称为 del，较少称为 nabla。参见**向量微积分**。[H.G.C.]

# 梯度风

基于假设的一种理论风，即科里奥利力水平分量之和与单位质量的大气压梯度力之和等效于一个垂直于风本身方向的风加速度（向心加速度），这意味着没有粘性力作用。梯度风的方向与地转风的方向相同。当空气沿气旋性弯曲路径运动时，梯度风的风速小于地转风速；当空气沿反气旋性弯曲路径运动时，梯度风的风速大于地转风速。梯度风是实际风的良好近似，通常优于地转风，特别是当流动强烈呈气旋性弯曲时。参见**科里奥利加速度**；**地转风**。[F.S.J]

# 晶界

是多晶固体中分隔相邻取向不同的单晶的内部界面。大多数固体，如金属、陶瓷和半导体，都具有晶体结构，这意味着它们由原子组成，原子在组成晶体中以三维周期性方式排列。大多数工程材料本质上是多晶的，即它们由许多小的单晶组成，这些单晶彼此取向不同，并在称为晶界的内部界面处相遇。这些界面通常呈平面状，具有二维周期性形态。一个边长为 1 cm 的多晶立方体，若晶粒直径为 0.0001 cm，将包含 10¹² 个晶体，晶界面积达数平方米。因此，晶界在控制多晶固体的电学和力学性能方面起着重要作用。据信，晶界的详细结构以及存在的缺陷（如位错和台阶）都会影响这些性能。晶界通常具有与完美晶体非常不同的原子构型和局部原子密度，因此它们充当杂质原子的汇，这些杂质原子倾向于在界面偏聚。参见**晶体缺陷**；**晶体结构**。

利用电子显微镜和 X 射线衍射技术，人们确定晶界结构在两个维度上通常是周期性的。晶界的几何形状由连接界面两侧相邻晶体取向的旋转轴和角度 θ，以及两个晶体之间的界面（或接触面）来描述。晶界通常根据 θ 的大小以及旋转轴相对于界面的取向进行分类。当 θ 小于（任意设定的）15° 时，该晶界称为小角度晶界；当 θ 大于 15° 时，该晶界称为大角度晶界。参见**电子显微镜**；**X射线衍射**。

由于晶界区域与基体固体在原子结构和密度上存在巨大差异，晶界的性能也与基体显著不同，并对多晶固体的基体性能产生强烈影响。固体的力学行为，即其对外施加应力的响应，通常涉及基体中位错的运动，而晶界的出现会阻碍位错的运动，因为为了让变形从一个晶体传递到相邻晶体，位错必须穿越晶界并改变方向。界面的详细结构影响位错实现这种方向改变的难易程度。

由于工程材料中的晶界并不处于高纯度环境中，溶解在固体中的杂质的存在可能会对其行为产生强烈影响。在铁中，若晶界处存在单层间隙原子（如硫或锑）的一半，会对力学性能产生剧烈影响，使原本在高纯度状态下具有延展性的铁变得极脆，以至于沿晶界断裂。利用俄歇电子能谱法已充分记录了杂质原子向晶界偏聚的现象，研究表明这些杂质的存在诱导晶界位错结构发生变化，可能导致性能改变。参见**金属力学性能**；**金属塑性变形**。

由于现代电子器件是用半导体制造的，而半导体可能是多晶的，因此晶界的存在及其对电学性能的影响在技术上具有极大意义。在硅等半导体中，界面处结构的局部变化导致正常晶体键合或价电子共享的破坏。其后果之一是晶界带电，从而形成阻碍电流跨越的势垒，进而提高了样品的总电阻。这种多晶效应在如氧化锌压敏电阻器等器件中得到利用，这些器件用作电压调节器和浪涌保护器。参见**硅**；**抑制器**；**压敏电阻**。[S.L.S]

# 谷物作物

属于禾本科（Gramineae）的作物植物，通常以其可食用的淀粉质种子著称。它们也被称为谷物作物，包括小麦、大米、玉米（maize）、大麦、黑麦、燕麦、高粱（jowar）和小米。所有这些作物的谷物广泛用于人类食物，也用于牲畜饲料，尤其是玉米、大麦、燕麦和高粱。

这些谷物作物的一项重要特性是储存方便。谷物通常在收获前自然干燥至安全水分含量（10–12%），或者可以轻松地用现代设备烘干。放置在适当储存设施中的谷物可以防止虫害侵害，并在良好状态下保存数年。参见**玉米**；**多谷物**；**大米**；**高粱**；**小麦**。[E.G.H]

# 当量克重

指某物质的数量，其分子数与恰好 12.000 g 碳-12（$^{12}$C）所含的原子数相同（这个数量被称为阿伏伽德罗数）。这一惯例源于这样一个概念：指导化学计算的核心原则是反应物质数量与所涉分子数之间的关系。

在化学计量计算中，为了增加便利性，除了分子数外，还可以引入化合价（n），使得反应物质的当量关系是隐含的，无需每次都要检查平衡方程式。因此，物质的当量克重等于其克分子量除以 n。在酸碱反应中，酸或碱的 n 由反应中释放或消耗的质子数决定。对于盐酸（HCl）、氨（NH$_3$）、乙酸（CH$_3$COOH）和乙酸盐离子 [CH$_3$COO$^-$]（如乙酸钠（NaOOCH$_3$）中的），n = 1。对于碳酸（H$_2$CO$_3$）、碳酸钠（Na$_2$CO$_3$）和乙二胺四乙酸（EDTA），n = 2。在沉淀反应和其他金属配合反应中，所涉离子的电荷（化合价）决定 n 的值。因此，当生成氢氧化铁（Fe(OH)$_3$）、硫酸钡（BaSO$_4$）或氯化银（AgCl）沉淀时，氯化铁（FeCl$_3$）的 n = 3，硫酸铁（Fe$_2$(SO$_4$)$_3$）的 n = 6。当涉及氧化还原反应时，n 由化合价的变化值而非化合价本身定义。当铁离子（Fe$^{3+}$）作为氧化剂（以亚铁离子（Fe$^{2+}$）为产物）时，氯化铁（FeCl$_3$）的 n = 1，硫酸铁的 n = 2。当高锰酸钾（KMnO$_4$）在酸性介质中反应时，n = 5，但在中性或碱性溶液中 n = 3。

在处理金属配合物形成时，定义会发生进一步变化，例如 Fe$^{3+}$、FeCl$_4^-$、Zn(EDTA)$^{2-}$ 和 Bi(EDTA)$^+$；EDTA 是多元金属配位配体乙二胺四乙酸盐。金属在配合物形成中的化合价取决于其配位数，正如这些例子所示，配位数随不同的配位剂（或配体）而异。参见**电化学当量**；**当量**；**乙二胺四乙酸**；**摩尔（化学）**；**化学计量学**；**化合价**。[H.F.H.]

# 克分子量

元素或化合物的分子量以克（g）表示，即在碳的同位素 $^{12}$C 的原子量被取为恰好 12 的标度上的分子量。这取代了早期将氧的原子量取为 16.00 g 的标度。在国际单位制中，克分子量被摩尔取代。

任意两种元素或化合物的克分子量之比必须与其单个分子的绝对质量之比相同。因此，所有元素或化合物的克分子量含有相同数目的分子。这个数目被称为阿伏伽德罗数，为 6.022 × 10$^{23}$。参见**阿伏伽德罗常数**；**摩尔（化学）**；**分子量**；**相对摩尔质量**。[C.F.]

# 大统一理论

试图统一三种基本相互作用——强相互作用、电磁相互作用和弱相互作用——的尝试，其假设是除了重力外，这三种力可以在极高的能量水平下统一为一种。其基本思想源于 S. Weinberg、A. Salam 和 S. Glashow 的弱电理论的不完整性，该理论在加速器当前可及的能量区域内取得了极大成功；同时，人们观察到强核力的耦合常数随能量增加而减小，而电磁相互作用的精细结构常数（α = 1/137）预计随能量增加而增大。参见**引力**；**强核相互作用**；**弱核相互作用**。

由 H. Georgi 和 Glashow 提出的最简单的大统一理论（GUT）基于这样一个假设：当三种力统一时出现的新对称性由维数为 24 的特殊酉群 SU(5) 给出。在低能区域无法观察到这种对称性，因为它已被严重破缺。在该模型中，在大多数 GUT 中，三种相互作用的耦合常数在约 10$^{16}$ GeV 的能量处合并为一个。夸克和轻子属于同一个多重态，这意味着在 10$^{16}$ GeV 或更高能量下，它们之间的区别消失。除了已知的强、电磁和弱相互作用的 12 种量子外，该模型中还出现了 12 种质量为 10$^{14}$ GeV 的新量子。这些新量子产生了新的但极其微弱的相互作用，违反了重子数和轻子数守恒。GUT 最惊人的预测之一是质子的不稳定性，这是重子数（和轻子数）不守恒的结果。参见**轻子**；**质子**；**夸克**；**对称性破缺**；**对称性定律（物理学）**。

总体而言，GUT 解释了为什么电子的电荷精确等于质子的电荷但符号相反。在 GUT 中，大质量中微子是一种明确的可能性，且其质量之小也可以得到解释。参见**宇宙学**；**中微子**。

根据基于 GUT 的情景，当宇宙温度冷却至 10$^{14}$ K（对应能量 10$^{14}$ GeV，即大爆炸后的前 10$^{-33}$ 秒）时，宇宙经历了一次相变。这一相变导致宇宙发生指数级膨胀（在 10$^{-32}$ 秒内膨胀 10$^{50}$ 倍），这解释了为什么观测到的 3 K 微波背景辐射是均匀的（视界问题），以及为什么宇宙表现得仿佛空间几乎是平坦的（平坦性问题）。参见**大爆炸理论**；**暴胀宇宙学**；**相变**；**宇宙**。

尽管简单的 SU(5) 模型在理论上有成就并有惊人的预测，但它实际上尚未通过实验检验，且似乎并不比超对称理论更好。尚未确立质子衰变的实验证据，而 GUT 未能解决的问题也数量众多。参见**基本粒子**；**基本相互作用**；**超重力**；**超对称性**。[C.W.K.]

# 花岗岩

一种结晶火成岩，主要由碱性长石（通常为纹带微斜长石或正长石）、石英和斜长石（通常为钙质钠长石或中间长石）组成。其平均晶粒尺寸为 0.04–1.0 英寸（1–25 毫米）；较细粒的此类成分的岩石包括流纹岩和正长片麻岩，较粗粒的是花岗岩伟晶岩。参见**正长片麻岩**；**伟晶岩**；**流纹岩**。

国际地质科学联合会（IUGS）修订后的命名法小组委员会定义花岗岩包含 80–100%（按体积）的石英、碱性长石和斜长石，其比例如插图所示，以及 20–0% 的副矿物。三种必需矿物中必须包含 20–60% 的石英，且碱性长石必须占长石总量的 65–90%。碱性长石花岗岩品种与之相似，只是碱性长石占所有长石总量的 90–100%。花岗岩岩一词包括花岗闪长岩和浅长岩以及花岗岩，某些地质学家使用的该术语可能包括石英正长岩到石英闪长岩（参见插图）。参见**长石**；**花岗闪长岩**；**角闪石**；**白云母**。
