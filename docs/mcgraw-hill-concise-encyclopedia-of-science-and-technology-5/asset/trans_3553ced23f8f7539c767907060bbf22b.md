## 保真度 (Fidelity)
系统输出准确重现其输入信号本质特征的程度。

因此，高保真音响系统意味着重放的声音几乎与录音或广播演播室中麦克风拾取的声音无法区分。同样，当接收机屏幕上看到的图像在本质上与电视摄像机捕捉到的图像相符时，电视系统具有高保真度。通过设计系统的每个部分具有最小失真来实现保真度，从而信号波形在通过系统时保持不变。参见：DISTORTION (ELECTRONIC CIRCUITS)（失真（电子电路））；SOUND-REPRODUCING SYSTEMS（声音重放系统）。[J.Mar]

## 场致发射 (Field emission)
在强电场影响下，电子从金属或半导体发射到真空（或介质）中的现象。在场致发射中，电子隧穿势垒，而不是像在热电子发射或光致发射中那样越过势垒。这是一种纯粹的量子力学效应，没有经典类比。其发生是因为电子的波函数在经典转折点处不消失，而是指数衰减进入势垒内部（其中电子的总能量小于势能）。因此，电子在势垒外部被发现的概率是非零的。参见：PHOTOEMISSION（光电子发射）；QUANTUM MECHANICS（量子力学）；THERMIONIC EMISSION（热电子发射）。

对于低温下的金属，该过程可以通过插图来理解。金属可以被视为一个势箱，电子填充至费米能级，该能级低于真空能级几个电子伏特。从费米能级到真空能级的距离被称为功函数，φ。真空能级表示在无外场情况下，静止在金属外部的电子的势能。在存在强场时，金属外部的势沿 AB 线变形，从而形成三角形的势垒，电子可以通过它隧穿。大部分发射将发生在费米能级附近，因为那里的势垒最薄。参见：ELECTRON EMISSION（电子发射）；FIELD-EMISSION MICROSCOPY（场致发射显微镜）。[R.Gom.]

## 场致发射显微镜 (Field-emission microscopy)
一种技术，利用针状发射体产生的电子或正离子的场致发射，在荧光屏上产生发射体表面的放大图像。

在场电子显微镜中，图像揭示了发射体表面功函数的变化。由于发射电子具有较大的横向速度，这源于德布罗意波的衍射效应以及金属内部电子的大动能，只能实现约 2.5 纳米的分辨率。场电子显微镜已被用于研究气体和汽沉材料的吸附和解吸、单晶面上吸附层和吸附原子的表面迁移，以及催化中的表面反应。中等大小的单个分子，如酞菁，也可以被可视化。参见：DE BROGLIE WAVELENGTH（德布罗意波长）；ELECTRON MICROSCOPE（电子显微镜）；FIELD EMISSION（场致发射）；WORK FUNCTION (ELECTRONICS)（功函数（电子学））。

在场离子显微镜中，发射体保持高正电位，同时显微镜室充满氦、氖或氩气，压力为 $10^{-5}$ 至 $10^{-4}$ 托（$10^{-3}$ 至 $10^{-2}$ 帕）[见插图]。在每纳米几十伏的场下，当原子电子隧穿到金属中时，图像气体分子可以在突出的表面原子上方被电离。随后，离子被施加的电场加速到屏幕上。每秒大约 1000 个离子在同一个表面原子上方形成；因此，该原子被连续成像。当尖端冷却到液态氢或氮的温度时，图像气体分子的热能大大减少。结合其非常短的德布罗意波长，可以实现约 0.25 纳米的分辨率。这足以分辨金属表面的原子结构。此外，如果施加的场逐渐增加，表面原子也可以被分离。因此，块体内部的晶格缺陷的原子结构也可以被揭示。通过使用通道板进行图像增强，以及使用电离能较高或较低的气体，可以对从铍到铀的广泛金属、半导体以及某些化合物（如高温氧化物超导体）进行成像。参见：CHANNEL ELECTRON MULTIPLIER（通道电子倍增器）；TUNNELING IN SOLIDS（固体中的隧穿效应）。

场离子显微镜已被用作研究金属和合金中晶格缺陷（如空位、间隙原子、位错、晶界和辐射损伤）的研究工具。它也被用于直接观察金属表面单个吸附原子的行为。参见：CRYSTAL DEFECTS（晶体缺陷）。

原子探针场离子显微镜将场离子显微镜与单离子检测器灵敏度的质谱仪相结合，通常是飞行时间质谱仪。尖端安装在万向节或类似机构上，并带有小探针孔的通道板屏幕组件被使用。在探针孔后面是一个 3–24 英尺（1–8 米）长的光管。探针孔通常覆盖几个原子图像直径。研究人员选择的原子，其化学身份可以通过飞行时间确定，并通过调整万向节直到原子图像落在探针孔上来逐一识别。然后施加纳秒级高压脉冲或亚纳秒级激光脉冲，逐个进行场蒸发表面原子。由于离子光学特性，只有那些图像被探针孔覆盖的原子才能通过探针孔并被检测到。根据这些离子的飞行时间，计算它们的质荷比并识别化学物种。参见：TIME-OF-FLIGHT SPECTROMETERS（飞行时间质谱仪）。

原子探针场离子显微镜代表了化学分析的终极形态，即研究人员可以选择原子进行分析。由于场蒸发从表面层的边缘开始，固体表面的成分也可以逐原子层分析。原子探针化学分析中的空间分辨率在横向约为 5 到 10 埃，在纵向上远优于 1 埃。[TTF]

## 场论 (Field theory) (数学)

在代数中，术语“域”用于指定一个代数系统或结构，它至少包含两个元素，并有两个二元合成规则：加法和乘法（即，如果 $a$ 和 $b$ 是域中的任意两个元素，则 $a + b$ 和 $ab$ 是定义的并且是域中的元素）。结构规则如下：这些元素在加法下形成一个阿贝尔（交换）群，加法单位元记为 0；即对于所有元素 $a$，$a + 0 = a$。非零元素的集合（由于域至少有两个元素，所以确实存在）在乘法下形成一个阿贝尔群，乘法单位元记为 1。由此推断，所有非零元素都有乘法逆元或倒数。这两个合成规则由分配律关联：对于所有元素 $a, b, c$，$(a + b) c = ac + bc$。由分配律可知，对于所有元素 $a$，$a \cdot 0 = 0$，因为 $1 \cdot a = (1 + 0) a = 1 \cdot a + 0 \cdot a$，因此 $0 = 0 \cdot a$。参见：GROUP THEORY（群论）。

域的熟悉例子是所有有理数集合 $\mathbf{Q}$ ($0, 1, -1, 2, 1/2, -1/2, 3, 7/3, \dots$)，遵循通常的相等、加法和乘法规则。其他例子是所有实数集合 $\mathbf{R}$ 和所有复数集合 $\mathbf{C}$（均遵循通常的加法和乘法规则）。有理函数集合（两个具有有理系数多项式的形式商）在通常的相等、加法和乘法规则下也构成一个域。参见：ALGEBRA（代数）；COMPLEX NUMBERS（复数）；REAL VARIABLE（实变量）。

存在仅包含有限个元素的域。最简单的例子是通过考虑模素数 $p$ 的整数剩余类环获得的。这个域，可以记为 $\mathbf{F}_p$，其元素是模素数 $p$ 的 $p$ 个不同的等差数列或剩余类，即 $1_0, 1_1, \dots, 1_{p-1}$，其中 $1_j$ 由整数 $j, j \pm p, j \pm 2p, \dots$ 组成。合成规则由方程 (1) 和 (2) 给出。

$$
1_j + 1_k = 1_s \text{ 如果 } j + k \text{ 属于 } 1_s \quad (1)
$$
$$
1_j 1_k = 1_l \text{ 如果 } jk \text{ 属于 } 1_l \quad (2)
$$

如果 $\mathbf{F}$ 是一个域，且 $\mathbf{F}$ 的子集 $A$ 在 $\mathbf{F}$ 的合成规则下是一个域，则称 $A$ 是 $\mathbf{F}$ 的子域，且 $\mathbf{F}$ 是 $A$ 的扩张。因此，有理数域 $\mathbf{Q}$ 是实数域 $\mathbf{R}$ 的子域，且 $\mathbf{R}$ 是 $\mathbf{Q}$ 的扩张。如果域 $\mathbf{F}$ 是域 $A$ 的扩张，则 $\mathbf{F}$ 是 $A$ 上的向量空间。如果作为向量空间，$\mathbf{F}$ 在 $A$ 上的维度有限为 $n$，则称 $\mathbf{F}$ 是 $A$ 的 $n$ 次扩张。参见：LINEAR ALGEBRA（线性代数）。

如果每个在 $\mathbf{F}$ 上的正次数多项式方程在 $\mathbf{F}$ 中都有解，则称域 $\mathbf{F}$ 是代数闭域；此时称 $\mathbf{F}$ 是代数闭的。所有复数域是代数闭的；但这是分析学中的一个定理。有理数域、模素数 $p$ 的剩余类域和实数域都不是代数闭的。对于任意域 $\mathbf{F}$，存在一个唯一的（在同构意义下）最小扩张 $\mathbf{F}^*$ 使得 $\mathbf{F}^*$ 是代数闭的。[D.J.L]

## 无花果 (Fig)

一种落叶乔木，*Ficus carica*，桑科（Moroaceae）。叶子呈典型的掌状，有 3 到 7 个裂片。产生一种含有蛋白消化酶无花果激酶的乳白色树胶。它起源于西南亚，现在在世界的亚热带地区种植其可食用果实，特别是在亚洲、非洲、欧洲和美国。无花果是一种聚合果或集合果，发育自肉质复花序，形成一个中空结构（隐头花序），具有顶端的导管或孔（ ostiole）和排列在内壁上的众多微小的单性花。这些花包括长柱头的雌花（雌性）；短柱头的雌花（雌性）；和雄花。无花果的 *F. carica* 有两种主要树型：无花果和野无花果。无花果专门开长柱头的雌花，并生产商业上的可食用无花果。野无花果开短柱头的雌花和雄花，雄花聚集在 ostiole 的内口周围。野无花果是无花果某些栽培品种的花粉来源，这些品种的花朵必须授粉才能结果。参见：FLOWER（花）；FRUIT（果实）。

通常由手从树上采摘要食用或作为新鲜、罐头、蜜饯、腌制销售或制成果酱或糖渍果实的无花果。世界无花果产量大部分要么干吃，要么作为干无花果或无花果浆销售，后者用于制作无花果棒和其他烘焙产品。用于这些用途的无花果通常允许在树上干燥并掉落到地面，以便手工或机械收获。参见：FRUIT（果实）；TREE（树）。[W.B.S]
