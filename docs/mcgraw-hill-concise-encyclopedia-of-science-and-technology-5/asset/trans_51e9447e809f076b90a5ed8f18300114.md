

# 热释电性

在生物体中普遍存在的嘧啶化合物包括尿嘧啶（**2**）、胞嘧啶（**3**）和胸腺嘧啶（**4**）。

与嘌呤一起，这些物质构成了核酸的“碱基”，其中尿嘧啶和胞嘧啶典型地存在于核糖核酸中，而在脱氧核糖核酸中以胸腺嘧啶取代尿嘧啶。在许多不常见的核酸中也存在一系列相关的嘧啶。其他普遍自然存在的嘧啶包括叶酸和硫胺素（维生素B$_{1}$）。参见**脱氧核糖核酸（DNA）；嘌呤；核糖核酸（RNA）**。

在磺胺类药物中，嘧啶衍生物磺胺嘧啶、磺胺二甲基嘧啶和噻二磺胺具有通用化学式（**5**）。这些药物是微生物叶酸生物合成的抑制剂。

# 黄铁矿

一种组成为 FeS$_{2}$ 的矿物。黄铁矿的莫氏硬度为 6–6.5，密度为 5.02。其光泽为金属光泽，颜色为黄铜色，条痕为绿黑色或棕黑色。

黄铁矿，或称二硫化铁，是最常见的“愚人金”，但它坚硬且脆，而黄金则柔软且具有延展性。其硬度也使其与更软的黄铜矿区分开来。白铁矿曾被认为与黄铁矿为同质异形体，但精确分析表明白铁矿含有过量的铁，而黄铁矿则是化学计量比的 FeS$_{2}$。参见**白铁矿**。

黄铁矿是最常见且分布最广的硫化物矿物。它几乎在所有已知的矿物沉积条件下都能形成。在氧化条件下，黄铁矿容易转化为硫酸铁，最终形成褐铁矿，即富含黄铁矿的矿床的表面表征。参见**褐铁矿**。

由于其高硫含量（53.4%），黄铁矿已成为生产硫酸的硫来源。在某些地方，仅为了硫而开采黄铁矿。参见**硫**。

# 火山碎屑岩

喷出（火山）成因的岩石，由爆炸性喷发直接产生的岩石碎屑组成。火山碎屑可能代表破碎和磨细的旧岩石（火山岩、侵入岩、沉积岩或变质岩），或是由剧烈爆炸抛出的凝固熔岩液滴。参见**凝灰岩；火山**。

# 热释电性

某些晶体通过温度变化产生电极性状态的特性。某些电介质（电不导通）晶体在遭受均匀温度变化时会发展出电极化（单位体积的偶极矩）。这种热释电效应仅发生在缺乏对称中心且具有极性方向（即极轴）的晶体中。这 32 个晶类中有 10 个满足这些条件。典型的热释电晶体例子包括电气石、硫酸锂一水合物、蔗糖和铁电性钛酸钡。

热释电晶体可以被视为具有内置或永久电极化。当晶体保持在恒定温度时，这种极化不会表现出来，因为它被通过晶体传导和从周围环境到达晶体表面的自由载流子所补偿。然而，当晶体温度升高或降低时，永久极化发生变化，这种变化表现为热释电性。

热释电效应的大小取决于晶体热膨胀是否因夹持而受阻，或者晶体在机械上是否不受约束。在受夹持的晶体中，观察到初级热释电效应；而在自由晶体中，次级热释电效应叠加在初级效应之上。次级效应可以被视为由热膨胀引起的热释电极化，通常远大于初级效应。参见**压电**。

热释电材料具有广泛的潜在科学和技术应用。最发达的应用是红外辐射探测。此外，热释电探测器可用于测量辐射源产生的功率（在辐射测量学中），或远程高温物体的温度（在比光学中，需对偏离黑体发射进行校正）。参见**高温计；辐射测量学**。

红外图像可以投射在热释电板上，并转化为表面上的极化浮雕。热释电的其他潜在应用包括太阳能转换、制冷、信息存储和固态科学。参见**热释电**。

### 热释电性（生物学）

由温度变化在生物材料中产生的电极性。热释电性可能是所有生物体的基本物理属性。它最初于 1966 年在肌腱和骨骼中被发现，此后已被证明存在于大多数动植物组织和单个细胞中。热释电性似乎在生物体的生长过程（形态发生）和生理功能（如感觉感知）中起着基本作用。参见**热释电的**。

生物（以及非生物）热释电结构的基本组分（例如分子）具有永久电偶极矩，并排列成所有正偶极指向一个方向，所有负偶极端指向相反方向。这种基本偶极子的平行排列被称为自发极化，因为它自发发生，无需外部场或力的作用。在这种分子有序状态下，相关结构在微观和宏观层面都具有永久电偶极矩。参见**偶极矩**。

自发极化是温度依赖的；因此，任何温度变化都会引起偶极矩的变化，这可以测量为极轴两端电荷的变化。这就是热释电效应。所有热释电结构也是压电的，但反之则不然。参见**铁电体；压电**。

在生物结构中发展自发极化和热释电活性的先决条件是 (1) 分子或分子聚集体中存在永久偶极矩，以及 (2) 有利于尽可能平行排列（或至少不阻碍其排列）的分子形状。这两个条件在沿纵向分子轴具有永久偶极矩的棒状或板状分子中得到了理想满足。几种重要的有机物质具有这些分子性质，因此在生物结构中表现出热释电性。例子包括动植物表皮、动物感觉感受器以及神经和骨骼系统的组织。

生物体能够检测并区分环境中的不同刺激，如温度、光照以及静水压力和单轴压力的快速变化。这些刺激代表不同形式的能量，并被转换（或转化）为几乎统一的电信号类型，其电压-时间过程经常取决于 dV/dt（V = 外部刺激，t = 时间）。这类电信号已在皮肤感觉感受器、外部神经末梢、表皮结构甚至单细胞生物的细胞壁上被记录到。这些生物系统中检测和转换的机制目前了解甚少，可能在于这些结构的热释电行为。已证明热释电（因而也是压电）行为存在于大多数生物系统中，这意味着原则上这些系统能够作为热释电探测器和换能器工作。

### 软锰矿

一种组成为 MnO₂ 的矿物。发育良好的晶体（软锰矿）很少见；通常呈放射状纤维状或肾状包壳。硬度为莫氏硬度 1–2（常使手指变软），比重为 4.75。光泽为金属光泽，颜色为铁黑色。它常以其他锰矿物（特别是锰矿）的假晶形式出现。

软锰矿在许多国家作为锰矿石被广泛开采，主要分布在俄罗斯、加纳、印度、南非共和国、摩洛哥、巴西和古巴。参见**锰；锰矿**。

### 热解

一种通过加热将化合物转化为一种或多种产物的化学过程。根据这一定义，在催化剂存在下加热发生，或在空气存在下（氧化通常同时发生反应）的反应被排除在外。热解或热反应一词在与热解基本相同的意义上被使用。热解的一个简单例子是加热氧化汞首次制备氧气的经典实验 [反应 (1)]。

```
HgO → Hg + 1/2 O₂
```

类似反应也发生在许多其他金属氧化物和盐中。石灰石（碳酸钙）的热分解或煅烧是生产石灰的基本步骤 [反应 (2)]。

```
CaCO₃ → CaO + CO₂
```

参见**石灰（工业）**。

热解一词最常与有机化合物的热反应联系在一起。植物和动物来源材料的热解提供了一些关于结构组成的最初线索，例如橡胶热分解形成异戊二烯。从煤焦油（煤的热解产物）中获得了一系列物质，包括苯、萘、吡啶和许多其他芳香化合物。所有这些热解过程导致形成特征于来源的挥发性产物以及高碳含量的焦炭残留物。

热解反应已被用作制备方法和生成瞬态中间体的手段，这些中间体可以被捕获或光谱观察，或通过进一步反应淬灭。出于制备目的，热解通常通过流动过程进行，其中反应物通过惰性气流通过加热管汽化，有时在减压下进行。在闪光真空热解中，反应物置于非常低的压力下，待热解材料通过分子蒸馏汽化。参见**化学动力学**。
