

# 梨

梨属 *Pyrus* 中约 20 种落叶树种果实之一。约有一半的物种原产于欧洲、北非和中东地中海沿岸地区；其余物种原产于亚洲。梨的种植历史可追溯至公元前 1100 年。梨树最适合生长在夏季温暖干燥、冬季寒冷的温带气候中。它们需要冬季低温来打破休眠期，且会因低于 −10 至 −15 °F（−23 至 −26 °C）的温度而受损。美国的商业梨产量主要集中在加利福尼亚州、俄勒冈州和华盛顿州的内陆山谷。

美国几乎所有的梨产量都属于欧洲梨 *P. communis*。巴尔特梨（Bartlett）品种占美国梨产量的 75% 以上。其他欧洲梨品种包括丁安娜（d'Anjou）、布斯克（Bosc）、科米斯（Comice）、谢克尔（Seckel）和冬季尼尔森（Winter Nelson）。欧洲梨以其柔软多汁的果肉著称。果皮颜色根据果实成熟度和品种的不同，呈中绿至黄色。果皮纹理可以是光滑或粗糙的。果实形状从经典的梨形（圆形基部，细长颈部）到圆润的椭圆形（没有明显定义的颈部区域）不等。亚洲梨 *P. pyrifolia* 果肉脆嫩，是全球种植的第二大流行梨类型。亚洲梨的特点是果肉脆嫩多汁，带有颗粒感（沙质感），因此被称为砂梨。其果实形状为圆形，成熟时果皮颜色通常为黄色至琥珀色，果皮纹理光滑或木栓质。*Pyrus communis* 和 *P. pyrifolia* 的杂交品种，如基弗（Kieffer）和勒康特（Leconte），已在美国东南部有限的商业使用中得到开发。*Pyrus ussuriensis*（乌苏里梨）也被选育用于亚洲梨品种。雪梨 *P. nivalis* 在欧洲生产，用于酿造苹果酒和皮里酒（perry，一种发酵酒）。参见 水果；果树。[K.M.W.]

# 山核桃

胡桃科（Juglandaceae）*Carya illinoinensis* 的一种高大树木及其坚果。这种坚果树原产于密苏里河-密西西比河及其支流流域，向北延伸至爱荷华州，以及得克萨斯州、俄克拉荷马州和墨西哥北部和中部的其他河流流域。如今，这种坚果树在美国南部和西南部以及墨西哥北部已成为重要的商业树种。[R.H.S.]

# 果胶

一类存在于所有陆生植物细胞壁和细胞间层中的多糖。它们可用热水、稀酸或草酸铵溶液提取。果胶可从水溶液中通过酒精沉淀析出，并因其优异的凝胶形成能力而被商业使用。商业上，果胶的主要来源是柠檬和青柠等柑橘类水果的果皮，尽管也可以使用橙子和葡萄柚。次要来源是苹果渣和向日葵花盘。

果胶在食品工业中应用广泛，主要用于制备凝胶。它用作果酱的基础，并在某些乳制品和冷冻甜点（如意式冰激凌雪酪）中用作稳定剂，也用作香肠、杏仁、蜜饯干果和软质食品的可食用保护涂层。参见 凝胶；多糖。[R.L.Wh., J.R.D.J]

# 纤锌矿

一种难溶矿物，成分为 Ca₃Na₂Si₈O₂₀(OH)₂。摩氏硬度为 5，比重为 2.75。该矿物呈无色、白色或灰色，具有玻璃至丝质光泽。美国新泽西州的帕特森、伯根山和大豁口（Great Notch）发现有纤锌矿。参见 硅酸盐矿物。[C.S.H.]

# 虱病

人类被虱子侵扰。人类虱子有两个生物学变种：*Pediculus humanus* 头虱变种（var. *capitis*）和体虱变种（var. *corporis*），它们各自表现出对人体的特定部位的强烈偏好。*Pediculus humanus capitis* 寄生于头部，而 *P. h. corporis* 生活在躯干部位。

这些虱子是无翅昆虫，属于体外寄生虫。它们的口器特化为刺入皮肤吸血。其腿的末端节段特化为爪状结构，用于抓握毛发和衣物纤维。

虱子是重要的人类疾病传播媒介。它们吸血的习性以及在一个宿主身上快速爬行到另一个宿主上的能力，传播了斑疹伤寒（立克次氏体病）和流行性回归热（螺旋体病）等疾病。受感染虱子的体液和粪便传播这些疾病。[R.S.J.]

# 珍珠

一种由软体动物形成的碳酸钙沉积物，具有珍珠光泽（orient）且光亮。有两种主要的双壳纲软体动物可以形成宝石珍珠：海水珍珠贝（*Pinctada*）和几种淡水蚌属。通常，珠宝商将海水珍珠称为东方珍珠（无论其发现地点），将来自淡水双壳贝的珍珠称为淡水珍珠。

在软体动物的身体团块和瓣膜之间延伸出一片称为外套膜的栉齿组织（ctenidium tissue）。为了使珍珠形成，寄生虫或沙粒等微小物体必须穿过外套膜。当这种情况发生时，入侵物体周围会发生分泌，并在软体动物体内构建珍珠。整颗珍珠形成于软体动物的身体团块内，而 blister pearls（皮珠/附着珠）则作为突起形成于贝壳的内表面。可食用的牡蛎产生无光泽的沉积物，但从不产生珍珠。

天然珍珠的替代品被称为养殖珍珠，通常是将一颗大珠插入软体动物体内，使其覆盖珍珠母（nacre）。[R.T.L.]

# 泥炭

沼泽和其他潮湿地方生长的苔藓、莎草、树木和其他植物经部分分解和崩解产生的深棕色或黑色残积物。森林型泥炭，当被埋藏并受到地质压力和热的影响时，是大多数煤炭的天然前体。泥炭土（Moor peat）形成于相对高地、排水不良且覆盖着苔藓的区域，如北欧的部分地区。参见 煤；腐殖质。[G.H.C.]

# 鹅卵石磨机

一种翻滚磨机，用于研磨或粉碎材料，同时不会用铁污染它们。由于鹅卵石的比重低于钢球，因此使用鹅卵石的特定尺寸磨壳的容量比使用钢球的低得多。较低的容量导致较低的功耗。磨壳内部衬有非金属衬里，以进一步防止铁污染。

# 佩迪诺纲（Pedinoida）

海胆纲（Diadematacea）的一个目，包括具有实心棘和刚性壳体的那些属。管足系（ambulacra）显示出典型的棘海胆结构，结节（tubercles）非齿状。唯一已知的科，佩迪诺科（Pedinidae），包括 15 个属，从晚三叠世一直延续到现代，尽管只有一个属，Caenopedina，存活至今。参见 棘海胆纲。[H.B.F]

# 土壤学

狭义定义上，是一门研究土壤剖面中剖面的性质和排列、土壤的物理组成和化学成分、土壤与其他环境要素（如气候、天然植被、地形和岩石）之间的相互关系及其发生方式的科学。按此定义的土壤学不包括土壤技术学，后者关注土壤的使用。

广义上，土壤学是研究土壤的性质、特性、形成、分布和功能，以及它们对使用、管理和操纵的响应的科学。第一个定义在美国广泛使用，在其他国家使用较少。第二个定义适用于全球。参见 土壤；土力学。[R.W.S]

# 海蛾总目

海蛾鱼或海马龙，一个奇特的辐鳍鱼类小型目，也称为叶鱼科（Hyptopomidae）。其身体前部被宽阔的骨化框架包裹，后部具有骨化棘刺，模拟海马和叶鱼（见插图）。与一些吻部突出且嘴位于尖端的鱼类不同，海蛾鱼具有扩大的鼻骨，形成向前突出的吻部，远超前部小型无齿的嘴巴。其巨大扩展的水平胸鳍虽然外观像翅膀，但功能并非空中滑翔。腹鳍位于腹部，由一根细长的棘刺和一到两根长鳍条组成。短小、对置的背鳍和臀鳍没有棘刺。没有鱼鳔。参见 刺鱼总目。
