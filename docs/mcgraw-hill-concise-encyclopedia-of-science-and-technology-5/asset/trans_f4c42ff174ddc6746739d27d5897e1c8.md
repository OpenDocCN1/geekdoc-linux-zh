
# 1438 媒染剂

*Moraxella*（莫拉菌属）次属*Moraxella* M. 目前包含六个物种：*M. (M.) lacunata*（又称*Diplobacillus moraxaeformis*和*Iquiferacines*）、*M. (M.) ois*、*M. (M.) nonliquefaciens*（又称*Bacillus duplex nonliquefaciens*）、*M. (M.) atlantica*、*M. (M.) phenylpyruvica*和*M. (M.) olsenii*。不同物种的鉴定基于表型特性，包括凝固血清液化、血琼脂培养基上人类血液的溶血、硝酸盐还原、苯丙氨酸脱氨酶活性、尿素酶活性，以及以铵离子和乙酸为唯一碳源在无机盐培养基中的生长情况。

* Branhamella*（布兰哈姆菌属）次属目前包含四个物种：*M. (B.) catarrhalis*、*M. (B.) causie*、*M. (B.) ois*和*M. (B.) cuniculi*。不同物种的鉴定基于血琼脂培养基上人类血液的溶血特性，以及硝酸盐和亚硝酸盐还原能力等其他特性。

*M. (M.) lacunata*是*Moraxella*次属的模式种，过去是人类结膜炎和角膜炎的重要致病菌，但目前极少被分离出来。牛传染性角膜结膜炎（俗称“红眼病”）由*M. (M.) bois*引起。*M. (M.) nonliquefaciens*被认为是人类的一种已确立的寄生虫，极少致病，但曾与眼内炎及伴有肺脓肿的肺炎相关联。*M. (M.) olsenii*通常是一种无害寄生虫，但常与骨髓炎、心内膜炎、败血症、脑膜炎、口炎和化脓性关节炎等人类感染有关。

* *M. (B.) catarrhalis*是*Branhamella*次属的模式种，是该次属中唯一从人体中分离出的物种。该生物被认为是一种适应良好的寄生虫，但被判定为中耳感染、上颌窦炎、支气管炎、气管炎、结膜炎、肺炎、婴儿中耳炎、免疫功能受损宿主的呼吸道疾病、败血症、脑膜炎和心内膜炎的病原体。其余的*Branhamella*物种（*causie*、*ois*和*cuniculi*）是豚鼠、羊、牛和兔的寄生虫。

*Moraxella*物种对大多数抗微生物药物敏感，但对林可霉素类抗生素除外。它们对青霉素类药物通常具有高度敏感性，这一特征使其与大多数其他革兰氏阴性杆菌区分开来。参见“临床微生物学”。[G.G.J]

# 媒染剂

一种或多种促进染料固定到纤维上的物质或物质组合。媒染剂使产生的颜色更加持久且通常更深。金属盐或氢氧化物最常用作媒染剂。某些媒染剂直接作用于纤维，使其更容易吸附染料。织物通常在使用染料前先用媒染剂进行预处理。其他媒染剂通过与染料形成络合物发挥作用。在此情况下，络合物充当染料的载体。媒染剂和染料同时暴露于织物。参见“染料”；“染色”。[E.F.J]

# 小桡足类（Moronilloida）

小桡足类是桡足类（Copepoda）七个目中最小的一目，包含单属的两个物种；它们在桡足类系统发育树中的位置尚未确定。小桡足类是自由生活的桡足类，在体型上非常类似于某些单枝目（Cyclopoida）。然而，它们拥有剑水目（Calanoida）典型的口器，这一点存在显著差异。同时具有裸足类（gymnopalean）和足类（podoplean）特征表明其与Misophrioida存在系统发生学关系。心脏的缺失、触角节段数量较少以及缺乏第五对胸足，使小桡足类与Misophrioida立即区分开来。参见“剑水目”；“Misophrioida”。

小桡足类物种均为浮游生物，主要出现在北大西洋东部水深1350–2300英尺（410–700米）的水层中。从未观察到雄性个体。参见“桡足类”；“甲壳动物”。[P.A.M.L]

# 砂浆

一种用于砌筑粘土砖、混凝土砌体和天然石材墙体，以及较小程度用于景观铺装路面的粘结剂。现代砂浆是历史上用于建造砌体墙体的石灰和砂混合料的改良版本。参见“砖”；“墙体”。

砌筑砂浆由一种或多种胶凝材料（如砌筑水泥或波特兰水泥和石灰）、清洁砂以及足以产生塑性可操作混合物的水组成。

砂浆与混凝土密切相关，但与灌浆料类似，通常不含粗骨料。砂浆与混凝土和灌浆料具有相同的基于硅酸钙的化学特性，在此过程中与砌体单元结合形成连续且防风的表面。砌筑水泥或波特兰水泥-石灰砂浆可针对特定工程需求进行配方调整，包括凝结时间、硬化速率、保水性和延长的可塑性。参见“水泥”；“混凝土”；“灌浆料”；“石灰（工业）”。[J.M.E]

# 镶嵌体（Mosaicism）

源于单个受精卵的两个或多个遗传上不同的细胞群共存的现象。镶嵌体可能出现在发育的任何阶段，从二细胞期开始，或此后任何活跃增殖的组织中。该现象在许多动植物物种中均可观察到，可能由体细胞突变或染色体不分离引起。个体动物或植物可能表现出镶嵌性，也可能出现在从个体中获得的单一细胞或组织类型培养物中。

染色体不分离可能是染色体异常的主要原因，进而可能导致镶嵌体的形成。在细胞分裂期间，两条姐妹染色单体通常完全分离，每条染色单体在纺锤体装置的引导下移向细胞的两极。在某些情况下，一条染色单体无法完全分离，或者滞后。这种不分离会导致两条姐妹染色单体存在于同一个子细胞中，而不是每个子细胞中各有一条（图 1）。体细胞互换导致产生重组镶嵌体，其中纯合片段（及其对应的基因块）在有丝分裂期间在同源染色体之间交换。这一过程的发生导致镶嵌性，最显著的表现是昆虫外骨骼或叶片、花瓣或雄蕊花药上的斑点（变异细胞克隆）。参见“染色体”。

# 蚊子

双翅目昆虫科（Diptera）蚊科（Culicidae）的任何成员。蚊子是全变态昆虫，所有幼虫阶段均为水生的。成蚊以其用于刺吸的长口器和特征性的鳞片覆盖的翅脉为识别特征。这是一个相对庞大且广为人知的蝇类群体，全球报告了34属近3000种物种。在墨西哥以北的北美，有13属和167种被认可的蚊子物种。这些物种中近75%属于三个属：*Aedes*（78种）、*Culex*（29种）和*Anopheles*（16种）。

雌性成蚊在水面或水边产卵。大多数幼虫（又称孑孓）以藻类和它们通过口刷从水中滤出的有机碎屑为食，尽管某些属可能具有捕食性，以其他蚊子幼虫为食。幼虫在羽化前经历三次蜕皮和四个龄期。蛹（又称翻蛹）是活跃但不摄食的阶段，在此期间发生向成虫阶段的变态。幼虫和蛹通常通过水面上的气管呼吸。

雄性成蚊寿命相对较短，且不吸血，主要取食花蜜和其他植物汁液。雌性也以花蜜为主要能量来源，但在大多数物种中，它们需要血液餐来生产卵子。某些蚊子物种宿主特异性很强，仅从人类、鸟类、哺乳动物甚至爬行动物和两栖动物吸血，但许多物种会从任何可用的宿主取食。

蚊子在人类医学和兽医医学中均具有重要意义。当种群密集时，它们会引起严重困扰和失血，并且充当三组重要致病微生物的媒介：*Plasmodium*（产生疟疾的原虫寄生虫）；丝虫（引起人类象皮病和犬类心丝虫病的寄生线虫）；以及黄病毒（引起黄热病、登革热、拉克罗斯脑炎、圣路易斯脑炎、西方马脑脊髓炎、东部和委内瑞拉马脑炎以及几种其他病毒疾病的病原体）。人类疟疾仅由*Anopheles*传播，丝虫病由*Culex*、*Anopheles*和*Aedes*传播，黄病毒主要由*Culex*和*Aedes*物种传播。参见“黄病毒脑炎”；“心丝虫”；“昆虫纲”；“*MALARIA*”；“医学寄生虫学”；“黄热病”。[B.M.Ch.]

# 穆斯堡尔效应

无反冲伽马射线共振吸收。穆斯堡尔效应，也称为核伽马射线共振荧光，已成为一种光谱学的基础，广泛应用于核物理、结构和无机化学、生物科学、固体物理研究以及许多相关科学领域。

该效应的基本物理涉及原子核从能量为$E_r$的激发态跃迁（衰变）到能量为$E_g$的基态，并发射能量为$E_\gamma$的伽马射线。如果发射核自由反冲以守恒动量，发射的伽马射线能量为$E_\gamma = (E_r - E_g) - E_R$，其中$E_R$是原子核的反冲能量。$E_R$的大小由经典关系$E_R = E_\gamma^2 / 2mc^2$给出，其中$m$是反冲原子的质量，$c$是光速。由于$E_R$是一个正数，$E_\gamma$总是小于差值$E_r - E_g$，如果该伽马射线随后被另一个原子核吸收，其能量不足以促进从$E_g$到$E_r$的跃迁。

1957年，R. L. Mössbauer发现，如果发射核被固体晶格中的强键合力束缚，整个晶格吸收反冲能量，上述反冲能量公式中的质量$m$变为整个晶格的质量。由于该质量通常对应于$10^{10}$到$10^{20}$个原子，反冲能量减少了$10^{-10}$到$10^{-20}$倍，重要结果是$E_R \approx 0$，因此$E_\gamma = E_r - E_g$；即发射的伽马射线能量恰好等于原子核基态能量与激发态能量之差。因此，这种伽马射线被同样牢固束缚在固体晶格中的原子核吸收时，可以使吸收体原子核从基态“泵”到激发态。参见“能级（量子力学）”；“激发态”；“伽马射线”；“基态”。

在典型的穆斯堡尔实验中，放射性源安装在速度换能器上，该换能器赋予伽马射线源相对于静止吸收体平滑变化的运动，最高速度可达每秒几厘米。这些伽马射线照射到待检查材料（吸收体）上。部分伽马射线被吸收并向各方向再发射，其余伽马射线穿过吸收体并被合适的探测器记录。
