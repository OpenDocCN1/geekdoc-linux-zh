

## 有用的帮助/信息命令

以下命令在你尝试了解正在 Linux 中使用的系统或程序时很有用。你可能不需要每天使用它们，但在需要时它们将非常宝贵。

free
free 命令显示系统中物理内存和交换内存的总空闲量和已用量。例如，free -m 以兆字节为单位给出信息。

sed
sed 命令打开一个流编辑器。流编辑器用于对输入流执行文本转换：文件或管道的输入。

df
df 命令显示所有分区的磁盘空间使用情况。命令 df -h 可能最有用（-h 表示人类可读）。

adduser
adduser 命令向系统添加新用户。同样，addgroup 命令向系统添加新组。

top
top 程序提供正在运行系统的动态实时视图。它可以显示系统摘要信息，以及进程列表。

deluser
deluser 命令从系统中删除用户。要删除用户的文件和主目录，你需要添加 -remove-home 选项。

uname -a
带有 -a 选项的 uname 命令打印所有系统信息，包括机器名称、内核名称、版本和其他一些详细信息。

delgroup
delgroup 命令从系统中删除组。你不能删除是任何用户主组的组。

ps
ps 命令允许你查看机器上运行的所有进程。每个操作系统的 ps 版本略有不同，但都做同样的事情。

man man
man man 命令调出 man 命令的手册条目，这是使用它的一个很好的起点。

grep
grep 命令允许你在多个文件中搜索特定搜索模式，然后打印匹配的行。一个例子是：grep blah file。

man intro
man intro 命令特别有用。它显示用户命令简介，这是一篇写得很好、相当简短的 Linux 命令行介绍。

## Linux 命令 A-Z

Linux 命令 literally 有成千上万个，所以虽然这不是完整的 A-Z，但它确实包含了你最有可能需要的许多命令。你可能会发现你最终反复使用一小部分命令，但拥有整体知识仍然非常有用。

### A
- adduser  添加新用户
- arch  打印机器架构
- awk  在文件(中)查找和替换文本

### B
- bc  一种任意精度计算器语言

### C
- cat  连接文件并打印到标准输出
- chdir  更改工作目录
- chgrp  更改文件的所有组
- chroot  更改根目录
- cksum  打印 CRC 校验和和字节计数
- cmp  比较两个文件
- comm  按行比较两个已排序文件
- cp  将一个或多个文件复制到另一个位置
- crontab  安排命令在稍后时间运行
- csplit  将文件拆分为上下文确定的片段
- cut  将文件分成几个部分

### D
- date  显示或更改日期和时间
- dc  桌面计算器
- dd  数据转储，转换和复制文件
- diff  显示两个文件之间的差异
- dirname  将完整路径名转换为仅路径
- du  估计文件空间使用量

### E
- echo  在屏幕上显示消息
- ed  一种行式文本编辑器 (edin)
- egrep  搜索与扩展表达式匹配的行
- env  显示、设置或删除环境变量
- expand  将制表符转换为空格
- expr  评估表达式

### F
- factor  打印质因数
- fdisk  Linux 的分区表操作工具
- fgrep  搜索与固定字符串匹配的行
- find  搜索符合所需条件的 文件
- fmt  重新格式化段落文本
- fold  将文本换行以适应指定宽度
- format  格式化磁盘或磁带
- fsck  文件系统一致性检查和修复

### G
- gawk  在文件(中)查找和替换文本
- grep  搜索与给定模式匹配的行
- groups  打印用户所在的组名
- gzip  压缩或解压缩命名文件

### H
- head  输出文件的前部
- hostname  打印或设置系统名称

### I
- id  打印用户和组 ID
- info  帮助信息
- install  复制文件并设置属性

### J
- join  在公共字段上连接行

### K
- kill  停止进程运行

### L
- less  一屏一屏地显示输出
- ln  在文件之间创建链接
- locate  查找文件

### M
- man  查看帮助手册
- mkdir  创建新文件夹
- mkfifo  创建 FIFO（命名管道）
- mknod  创建块或字符特殊文件
- more  一屏一屏地显示输出
- mount  挂载文件系统

### N
- nice  设置命令或作业的优先级
- nl  编号行并写入文件
- nohup  运行不受挂断影响的命令

### P
- passwd  修改用户密码
- paste  合并文件行
- pathchk  检查文件名可移植性
- pr  将文本文件转换为打印格式
- printcap  打印机功能数据库
- printenv  打印环境变量
- printf  格式化并打印数据

### Q
- quota  显示磁盘使用量和限制
- quotacheck  扫描文件系统以获取磁盘使用量
- quotactl  设置磁盘配额

### R
- ram  内存盘设备

### S
- screen  终端窗口管理器
- sdiff  交互式合并两个文件
- select  接受键盘输入
- seq  打印数字序列
- shutdown  关闭或重启 linux
- sleep  延迟指定时间
- sort  对文本文件排序
- split  将文件拆分为固定大小的片段
- su  替换用户身份
- sum  为文件打印校验和
- symlink  为文件创建新名称
- sync  将磁盘上的数据与内存同步

### T
- tac  串联并以相反顺序写入文件
- tail  输出文件的最后部分
- tar  磁带归档器
- tee  将输出重定向到多个文件
- test  评估条件表达式
- time  测量程序资源使用情况
- touch  更改文件时间戳
- top  列出系统上运行的进程
- traceroute  追踪到主机的路由
- tr  翻译、压缩和/或删除字符
- tsort  拓扑排序

### U
- umount  卸载设备
- unexpand  将空格转换为制表符
- uniq  使文件唯一化
- units  将单位从一种尺度转换为另一种尺度
- unshar  解包 shell 归档脚本
- useradd  创建新用户账户
- usermod  修改用户账户
- users  列出当前登录的用户

### V
- vdir  详细列出目录内容（'ls -l -b'）

### W
- watch  定期执行或显示程序
- wc  打印字节、词和行数
- whereis  报告命令的所有已知实例
- which  在用户路径中定位程序文件
- who  打印当前登录的所有用户名
- whoami  打印当前用户 ID 和名称

### X
- xargs  执行实用程序，传递构造的参数列表

### Y
- yes  打印字符串直到中断

你知道吗... NASA 的最先进超算集群 Pleiades 由 Linux 提供动力？Pleiades 由 160 个机架（11,440 个节点）、245,536 个 CPU 核心、总内存 935TB、184,320 个 NVIDIA CUDA 核心组成，并拥有超过六英里的光纤电缆。

其核心是一个复杂的 SUSE Linux Enterprise Server 设置，以及许多定制的开发包和其他 NASA 项目特有的软件。NASA 高级超算部门使用 Pleiades 的项目有：开普勒任务 – 寻找类地系外行星；CFD（计算流体动力学）建模以帮助创建更高效的航天发射系统；暗物质研究和模拟；以及地球洋流的可视化，为 ECCO（估计海洋环流和气候）项目构建数据。
