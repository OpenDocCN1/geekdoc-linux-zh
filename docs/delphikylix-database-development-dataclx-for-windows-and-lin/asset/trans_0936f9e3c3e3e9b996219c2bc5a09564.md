

## 使用示例应用程序

以下是本书涵盖的示例应用程序列表、它们在每章中的列表编号（如果相关）以及简要说明，介绍这些应用程序的功能。

### 第 1 章
- **Events** - 展示了 TSQLConnection 组件触发的不同连接事件。（列表 1.1）
- **MetaData** - 演示如何从 dbExpress 连接获取简单的元数据信息。（列表 1.2）
- **DDL.SQL** - 演示如何直接向 TSQLConnection 组件发送 DDL 和 SQL 命令。（列表 1.4）
- **Trans** - 说明了 dbExpress 中事务支持的工作方式。（列表 1.5）
- **Feedback** - 演示如何提供关于 dbExpress 连接中正在发生事件的信息反馈。（列表 1.6）

### 第 2 章
- **Basic** - 展示了基本的 TSQLDataSet 操作。（列表 2.1 和 2.2）
- **Advanced** - 展示了更高级的 TSQLDataSet 方法和操作。（列表 2.3）
- **Schema** - 演示如何使用 TSQLDataSet 从 dbExpress 连接获取更高级的元数据信息。（列表 2.4）

### 第 3 章
- **CDS** - 展示了客户端数据集支持的基础知识。（列表 3.1）
- **Navigate** - 演示如何在 TClientDataSet 中导航。（列表 3.2）
- **CDSIndex** - 说明了如何在 TClientDataSet 上创建和使用索引。（列表 3.3）
- **RangeFilter** - 演示如何通过应用范围过滤器来限制 TClientDataSet 中的数据量。（列表 3.4、3.5 和 3.6）
- **Search** - 展示了在客户端数据集中快速定位特定记录的多种方法。（列表 3.7 和 3.8）

### 第 4 章
- **EventLog** - 说明了 TClientDataSet 触发的事件。（列表 4.1 和 4.2）
- **Updaters** - 演示如何禁用和启用数据感知控件的更新，以加速数据集操作。（列表 4.3）
- **BLOBs** - 演示如何在客户端数据集中存储图片和注释。（列表 4.4）
- **Nested** - 展示了客户端数据集如何实现主/明细关系。（列表 4.5）
- **Changed-og** - 演示如何使用客户端数据集实现撤销支持。（列表 4.7 和 4.8）
- **Clone** - 说明了克隆操作，这是创建 TClientDataSet 副本的一种方式。（列表 4.9）

### 第 5 章
- **DataAware** - 展示了本章讨论的各种数据感知组件。（列表 5.4）

### 第 6 章
- **Options** - 展示了 TDBGrid 的各种选项是如何工作的。（列表 6.1）
- **CustomDraw** - 说明了覆盖 TDBGrid 默认绘图行为的正确方法，以提供视觉冲击力强的网格。（列表 6.2）
- **CtrlGrid-VCL** - 唯一展示如何使用 TDBCtrlGrid 组件的示例。（列表 6.4）

### 第 7 章
- **Updaters** - 展示了数据集提供者的基本操作。（列表 7.1）
- **Joins** - 演示如何正确解析通过 SQL JOIN 检索的数据。（列表 7.2）
- **DataFetch** - 说明了如何限制从数据集返回的 BLOB 和明细数据量，以提升应用程序性能。（列表 7.3）

### 第 8 章
- **Methods** - 展示了如何向应用程序服务器添加可调用方法。（列表 8.1）
- **LocalConn** - 展示了如何使用多层技术实现单 EXE 数据库应用程序。
- **Stateless** - 演示如何创建无状态应用程序服务器，以配合 MTS 或 COM+ 使用。

### 第 9 章
- **ConMan** - 一个完整的示例应用程序，它运用了全书讨论的许多技术来创建一个简单的联系人管理器。（列表 9.1 至 9.6）
