+   *   `po1Contacts` A *TNameDataSource* component used to establish a server-side master/detaill relationship between `solContacts` and `solTodos`.

+   *   `poServerApps` A *TServerProvider* component used to provide contacts data node remote to the client applications. Because the contacts and todos are connected in a master/detaill relationship, only one provider is needed at the master level (refer to Chapter 7 “If you need to revisit server-side master/detaill relationships).
