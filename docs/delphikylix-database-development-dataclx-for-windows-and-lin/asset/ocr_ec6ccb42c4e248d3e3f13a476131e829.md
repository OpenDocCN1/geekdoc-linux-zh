There are actually two places that you can establish a named connection: on your development machine, or on the end user's machine. To create a named connection on your development machine, drop a `TSQLConnection` component onto a form or data module. Either double-click the component, or right-click the component and select `Edit Connection Properties` from the pop-up menu. The dbExpress Connection Editor, shown in Figure 1.1, appears.

![](bbox=[0.3, 0.51, 0.78, 0.71])

**Figure 1.1**
The Connection Editor helps you to easily create named connections.

On the left side of the Connection Editor, you see a `Driver Name` combo box and a `Connection Name` list box. By default, the list box shows all existing named connections on your development machine. If you only want to see named connections for InterBase, Oracle, or another database server, select the appropriate server from the `Driver Name` combo box.

Click a connection name in the list box to view the settings for that named connection, or click the `Add` Connection button (which looks like a plus sign) on the toolbar to create a new named connection.
