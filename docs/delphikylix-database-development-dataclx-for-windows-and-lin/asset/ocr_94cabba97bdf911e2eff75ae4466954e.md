# # Using the Sample Applications

The following is a list of the sample applications covered in this book, **their Listing numbers** (where relevant) within each chapter, and a brief description of what they do.

# ## Chapter 1

+   - **Events**-Illustrates the different connection events fired by the TSQLConnection component. (Listing 1.1)
+   - **MetaData**-Shows how to retrieve simple metadata information from a dbExpress connection. (Listing 1.2)
+   - **DDL.SQL**-Shows how to send DDL and SQL commands directly to a TSQLConnection component. (Listing 1.4)
+   - **Trans**-Illustrates how transaction support works in dbExpress. (Listing 1.5)
+   - **Feedback**-Shows how to provide feedback about what's happening in a dbExpress connection. (Listing 1.6)

# ## Chapter 2

+   - **Basic**-Illustrates basic TSQLDataSet operation. (Listings 2.1 and 2.2)
+   - **Advanced**-Shows more advanced TSQLDataSet methods and operations. (Listing 2.3)
+   - **Schema**-Shows how to retrieve more advanced metadata information from a dbExpress connection using TSQLDataSet. (Listing 2.4)

# ## Chapter 3

+   - **CDS**-Shows the basics of client dataset support. (Listing 3.1)
+   - **Navigate**-Shows how to navigate through a TClientDataSet. (Listing 3.2)
+   - **CDSIndex**-Illustrates how to create and use indexes on a TClientDataSet. (Listing 3.3)
+   - **RangeFilter**-Shows how to limit the amount of data in a TClientDataSet by applying ranges and filters. (Listings 3.4, 3.5 and 3.6)
+   - **Search**-Shows a variety of ways to quickly locate a given record in a client dataset. (Listings 3.7 and 3.8)

# ## Chapter 4

+   - **EventLog**-Illustrates the events fired by TClientDataSet. (Listings 4.1 and 4.2)
+   - **Updaters**-Shows how to disable and enable updates to data-aware controls to speed dataset operations. (Listing 4.3)
+   - **BLOBs**-Shows how to store pictures and notes in a client dataset. Listing 4.4)

+   - **Nested-Shows** how client datasets implement master/detail relationships. (Listing 4.5)
+   - **Changed-og**-Shows how to implement undo support using a client dataset. (Listings 4.7 and 4.8)
+   - **Clone**-Illustrates cloning, which is a way to create a duplicate copy of a TClientDataSet. (Listing 4.9)

# ## Chapter 5

+   - **DataAware**-Illustrates a variety of data-aware components discussed in the chapter. (Listing 5.4)

# ## Chapter 6

+   - **Options**-Shows how the various options for a TDBGrid work. (Listing 6.1)
+   - **CustomDraw**-Illustrates the correct way to override the TDBGrid's default drawing to provide visually exciting grids. (Listing 6.2)
+   - **CtrlGrid-VCL**-Only sample that shows how to use the TDBCtrlGrid component. (Listing 6.4)

# ## Chapter 7

+   - **Updaters**-Shows the basic operation of dataset providers. (Listing 7.1)
+   - **Joins**-Shows how to correctly resolve data that was retrieved through a SQL JOIN. (Listing 7.2)
+   - **DataFetch**-Illustrates how to limit the amount of BLOB and detail data returned from a dataset to speed application performance. (Listing 7.3)

# ## Chapter 8

+   - **Methods**-Shows how to add callable methods to an application server. (Listing 8.1)
+   - **LocalConn**-Shows how to implement a single-EXE database application using multi-tier techniques.
+   - **Stateless**-Shows how to create a stateless application server for use with MTS or COM+.

# ## Chapter 9

+   - **ConMan**-A complete sample application that draws on many of the techniques discussed throughout the book to create a simple contact manager. (Listings 9.1 through 9.6)
