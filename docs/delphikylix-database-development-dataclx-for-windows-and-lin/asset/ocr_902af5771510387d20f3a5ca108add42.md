Event Description

OnColExit Fires immediately before focus leaves the current column. Calling Abort in this handler prevents the grid from switching to a new column.

OnColumnMoved Fires after the user moves (but not after the user resizes) a column at runtime.

OnDrawColumnCell Fires when a cell is about to be drawn. It’s used to implement custom drawing, which is explained later in this chapter.

OnDrawDataCell Obsolete and included for backward compatibility only.

OnEditButtonClick Fires when the user clicks the ellipsis button in a cell.

OnTitleClick Occurs when the user clicks a title cell (assuming that the option dgTitles is set). TClientDataSetGrid makes internal use of this event to automatically sort the underlying dataset when the user clicks a column title.
