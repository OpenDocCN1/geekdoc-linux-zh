## Delphi/Kylix Database Development

In this book Delphi and Kylix programmers will learn dbExpress, Borland's newest database-access technology. dbExpress is supported by both Delphi and Kylix, and has a number of exciting characteristics: Cross-platform capability (Windows and Linux), low overhead, high performance and easy distribution. Users of the Borland Database Engine technology will want to add dbExpress to their technology toolkit.

*Delphi/Kylix Database Development* covers topics ranging from setting up a database connection to single- and multi-tiered database applications. Respected expert and author Eric Harmon presents plentiful code snippets and small sample applications alongside concepts. The book concludes with a complete database application. Readers can use *Delphi/Kylix Database Development* as an introduction to the new dbExpress technology, a reference in putting the technology to use in production environments, and a code resource.

Eric Harmon is Director of Software Development at Advanced Estimating Systems Inc., which develops The EDGE, the industry standard in construction estimating software. Eric is one of the original members of TPX (TurboPower Experts) and the author of the highly regarded book *Delphi COM Programming* (MTP/New Riders, 2000).

- Study basic and advanced aspects of client dataset operations

- Master multi-tier database development and application with dbExpress
