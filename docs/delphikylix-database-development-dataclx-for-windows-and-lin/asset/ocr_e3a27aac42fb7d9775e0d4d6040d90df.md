+   * TDBLookupComboBox and TDBLookupListBox elaborate on TDBComboBox and TDBListBox by obtaining the list of items from another dataset, and then saving the primary key of the lookup dataset back to the dataset that's being edited.

+   * TDBImage is used to display bitmaps that are stored in a dataset’s BLOB field.

+   * TDBNavigator can be used to provide a code-free form of dataset navigation and manipulation.

+   * With a little effort, you can create data-aware versions of standard VCL/CLX components.
