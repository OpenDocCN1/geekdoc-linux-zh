+   *   You can’t perform a locate or other search technique on a BLOB field.
+   *   The reconciliation features of DataSnap, which are discussed in Chapter 8, “DataSnap,” don’t work with BLOB fields. However, there is a workaround, as you’ll see in that same chapter.
