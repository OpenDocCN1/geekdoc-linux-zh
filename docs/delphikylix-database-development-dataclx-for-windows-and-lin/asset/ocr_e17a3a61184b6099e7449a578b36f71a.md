Listing 9.3 defines a user-defined message, UM_CONNECT. The remote data module posts this message to the main form on creation and destruction. The UMConnect method fires in response to the UM_CONNECT message and updates a label showing the number of current connections to the application server.

The only other code in Listing 9.3 is the Timer1Timer method, which fires every second to display the amount of RAM currently being used by the application server.
