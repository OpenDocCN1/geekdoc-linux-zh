**TABLE 3.7** Filter Arithmetic Operators

| Function | Description | Example |
| --- | --- | --- |
| + | Addition. Can be used with numbers, strings, or dates/times. | Birthday + 30 < '1/1/1960' Name + 'X' = 'SmithX' Salary + 10000 = 100000 |
