# **TDBImage**

TDBImage is used to display bitmaps contained in a dataset's BLOB field. Unfortunately, TDBImage cannot be used to display nonbitmap images (such as JPEG, PNG, and the like). Chapter 4, "Advanced Client Dataset Operations," explains how you can store and retrieve nonbitmap images from database BLOB fields.
