
## 附录 D

## 内核参数 v2.2.9

以下是内核参数的综合列表，定义在文件 init/main.c 中，并按英文字典顺序排序（定义为忽略所有标点符号，且不区分大小写，数字排在字母之前），并在已知情况下附带描述。

描述开头的方括号中的文本说明了使该内核参数生效的内核限制条件。所指的限制造成的结果是，如果满足以下条件，则相关选项有效：

- **APIC**：已启用 APIC 支持。
- **APM**：已启用高级电源管理（Advanced Power Management）支持。
- **AX25**：已启用相应的 AX.25 支持。
- **CD**：已启用相应的 CD 支持。
- **EIDE**：已启用 EIDE/ATAPI 支持。
- **FB**：已启用帧缓冲区（frame buffer）设备。
- **HW**：已启用相应的硬件。
- **ISDN**：已启用相应的 ISDN 支持。
- **JOY**：已启用相应的摇杆支持。
- **LP**：已启用打印机支持。
- **LOOP**：已启用回环设备支持。
- **MCA**：已启用 MCA 总线支持。
- **MDA**：已启用 MDA 控制台支持。
- **MOUSE**：已启用相应的鼠标支持。
- **NET**：已启用相应的网络支持。
- **NFS**：已启用相应的 NFS 支持。
- **PARIDE**：已启用 ParIDE 子系统。
- **PCI**：已启用 PCI 总线支持。
- **PCMCIA**：已启用 PCMCIA 子系统。
- **PNP**：已启用即插即用（Plug & Play）支持。
- **PPT**：已启用并口（Parallel port）支持。
- **PS2**：已启用相应的 PS/2 支持。
- **RAM**：已启用 RAM 磁盘支持。
- **SCSI**：已启用相应的 SCSI 支持。
- **SERIAL**：已启用串口支持。
- **SMP**：内核是 SMP 内核。
- **SOUND**：已启用相应的声音系统支持。
- **VGA**：已启用 VGA 控制台。
- **VT**：已启用虚拟终端支持。
- **XT**：已启用 IBM PC/XT MFM 硬盘支持。

此外，以下文本表示该选项：
- **BUGS=**：与指定处理器上可能存在的处理器 bug 相关。
- **KNL**：是一个内核启动参数。

请注意，下方列出的*所有*内核参数都是*大小写敏感*的。任何参数名称末尾的 `=` 表示该参数将作为环境变量输入，而如果缺少 `=`，则表示该参数将作为内核参数出现，系统启动完成后，运行中的程序可以通过 /proc/cmdline 读取到该参数。
