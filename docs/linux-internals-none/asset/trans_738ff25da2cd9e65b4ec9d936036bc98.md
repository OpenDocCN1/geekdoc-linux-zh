

逻辑卷以 lv. 开头。

-   e2fsadm - 逻辑卷管理封装器，包括 lvextend、lvreduce、e2fsck 和 resize2fs 的文件系统调整大小功能
-   lvchange - 更改逻辑卷的属性
-   lvcreate - 创建逻辑卷
-   lvdisplay - 显示逻辑卷配置数据
-   lvextend - 扩展逻辑卷的大小
-   lvreduce - 缩减逻辑卷的大小
-   lvremove - 移除逻辑卷
-   lvrename - 重命名非活动的逻辑卷
-   lvscan - 查找所有现有的逻辑卷
-   lvmchange - 用于更改 LVM 属性的紧急程序
-   lvm.diskscan - 扫描所有磁盘/分区和多重设备并列出它们
-   lvm.sadc - 统计数据收集器
-   lvm.sar - 统计数据显示器
-   pvchange - 更改物理卷的属性
-   pvcreate - 创建物理卷
-   pvdata - 调试列出物理卷组描述符区域
-   pvdlsplay - 显示物理卷配置信息
-   pvmove - 将逻辑区段移动到不同的物理卷
-   pvscan - 查找所有现有的物理卷
-   vgcfgbackup - 备份所有卷组描述符区域
-   vgcfgrestore - 将卷组描述符区域恢复到磁盘
-   vgchange - 激活/停用卷组
-   vgck - 检查卷组描述符区域的一致性
-   vgcreate - 从物理卷创建卷组
-   vgdisplay - 显示卷组配置信息
-   vgexport - 导出卷组（使其对系统不可见）
-   vgextend - 通过一个或多个物理卷扩展卷组
-   vgimport - 导入卷组（使其对当前/另一个系统可见）
-   vgmerge - 将两个卷组合并为一个
-   vgmknodes - 创建包含所有逻辑卷特殊文件的卷组目录
-   vgreduce - 通过一个或多个空的物理卷缩减卷组
-   vgremove - 移除空的卷组
-   vgrename - 重命名非活动的卷组
-   vgscan - 扫描卷组
-   vgsplit - 将一个卷组拆分为两个
