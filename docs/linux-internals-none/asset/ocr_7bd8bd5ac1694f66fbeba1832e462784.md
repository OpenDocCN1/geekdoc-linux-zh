Notice how nicely Linux organizes the source code into architecture-
dependent and independent code. About 95 percent of the kernel source
is independent code, and thus will be exactly the same on all porting
sets of Linux. The remaining 5 percent is usually assembler code or
minor details, such as clock timer frequency.

# The arch/ Directory

Architecture-dependent code resides in the `arch/` directory. Under this
directory, for each existing porting set of Linux, there are three more
subdirectories: `kernel/`, `lib/`, and `mm/`.

The `kernel/` subdirectory contains architecture-dependent implemen-
tations of general kernel features, such as signals handling, clock han-
dling, and so forth. The `lib/` subdirectory contains local implemen-
tations of library functions that run faster if compiled from
architecture-dependent source code. The `mm/` subdirectory contains local
memory handling implementations.
