As you can see, a higher latency reduces the average instructions per cycle.

Table 3.1 illustrates how load latency affects the average number of instructions per cycle (the achieved level of ILP):

+   TABLE 3.1
+   Load latency affects ILP

| **Load latency** **(CPU cycles)** | **Average ILP** **(Instructions per Cycle)** |
|---|---|
| 1 | 3 |
| 2 | 1.5 |
| 3 | 1 |
| 4 | 0.75 |
| 5 | 0.6 |

These examples are very much simplified. In the real world, the calculation is further complicated by the fact that modern PCs and servers usually have a three-tier memory model, with Level 1 (L1) cache, Level 2 (L2) cache, and RAM, on top of the CPU registers. All have different load latencies. Therefore, you need to calculate the average hit or miss ratio for each memory layer and apply it to the equation for the table above.
