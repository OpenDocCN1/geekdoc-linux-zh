

# 第一章

# 11

你是否曾在从火车窗户向外看时注意到，有些马在轨道旁吃草，甚至从未停下来抬头看一眼轰鸣而过的列车；而在不远下一个铁路交叉口，一位农妇妻子可能正紧张地试图安抚她受惊的马，等待火车驶过？

你会如何治疗一匹害怕火车的马呢？让它在深林中放牧，使其永远见不到机车或汽车，还是把它带进一片永远见不到这些的牧场？

治愈害怕车的马唯一方法是让它接触汽车。治愈害怕演讲的人的唯一方法是让他面对演讲。书可以就你如何表现得最好提供极佳的建议，但早晚你可能会变得狼狈，甚至陷入某种奇怪的“半怕半死”。海边有许多“不湿水”衣，但没有人能穿着着它们学会游泳。学习游泳的唯一方法是跳入水中。

在观众面前练习、不断练习演讲将有助于消除对观众的所有恐惧，正如练习游泳会带来在水中的自信和自如。

使徒保罗告诉我们，每个人都必须自己寻求得救。我们在这里能做的仅仅是为你提供关于如何最好准备自己的建议。医生可能会开方，但药必须由你自己服用。

如果起初你遭受了舞台恐惧，请不要灰心。帕奇（Patch）比一匹老马还更容易受苦。一个傻瓜出现在观众面前并无大碍，因为他的能力并不具备感受能力。足以杀死一个文明人的打击很快就会愈合。我们在生活的阶梯上爬得越高，受苦的能力就越大。由于某种原因或其他原因，有些演讲大师从未克服过舞台恐惧，但只要你不遗全力去征服它，就是值得的。韦伯斯特（Webster）在第一次亮相时失败了，因为紧张，还没完成演讲就不得不坐下了。毕奇（Beecher）在公众面前演讲之初总是感到不安。

铁匠有时会将绳子紧紧缠在马鼻上，通过微小的疼痛分散它对马蹄的注意力。从玻璃杯排出空气的一种方法是倒入水。

### 沉浸在你的主题中

演讲时要运用朴实的原理：如果你对自己的主题深有感，你将无法思考其他事情。专注是一个从无关事项中转移注意力的过程。当你站在平台上时，再去考虑外套的剪裁就太晚了；将你的注意力集中在你要说的话上——用素材填满大脑，就像向杯中注水一样，会驱除虚幻的恐惧。

自我意识是对自我的过度关注，而为了表达，自我本身相对于你的主题是次要的，这不仅在观众眼中如此，如果你足够明智，在你眼中也是如此。持有任何其他观点，都是将自己视为一个展品，而不是一个带着值得传递之信息的传信者。你还记得哈伯德（Hubbard）那篇惊人的小册子《给加西亚亚的消息》吗？你必须通过你所能集起的全部意志，让自己从于信息。严厉地对自己说这句话，让你的自我意识因羞愧而沉默。如果你着了火，你可以冲上舞台向观众指路，而完全没有自我意识，因为你所说的话的重要性会驱走所有的恐惧。

表现糟糕而产生的自我意识，比表现优秀而产生的自我意识更糟糕。伟大的第一个标志是一个人并不试图看起来伟大或表现得伟大。金迪（Kipling）向我们保证，在你称自己为人之前，你必须“既不看起来漂亮，也不说话得明智”。

没有什么比自大更能彻底地推销自己了。一个人可能满是自我一样空虚。伏尔泰（Voltaire）说：“我们必须隐藏自爱。”这是做不到的。你清楚这是真的，因为你已经认出了他人身上过度的自爱。如果你拥有这种情感，别人就能从你身上看到。这个世界上有比自我更大的东西，在为这些东西努力时，自我会被遗忘，或者更好——只被记住为帮助了我们通向更高层次的思想。

### 有些话要说

许多演讲者的问题在于，他们来到观众面前时大脑一片空白。难怪自然厌恶真空，用手手可及的东西填满他们，而那些东西通常是：“我不知道我这样做对不对！我的头发看起来怎么样？我知道我会失败的。”他们的预言灵魂是对的。

仅仅沉浸在主题中是不够的——要获得自信，你必须有某些让你自信的东西。如果你在没有任何准备或对主题没有预知的情况下来到观众面前，你应该感到自我意识——你应该为浪费观众的时间感到羞耻。准备好自己。知道你要论什么，以及通常打算怎么说。把前几句话完全构思好，这样你在开头就不会因为找不到词而苦恼。比你的听众更了解你的主题，你就无所畏惧。

让你的举止谦逊而自信，但在内心保持谦逊的自信。过度自信是坏的，但容忍失败的预感更糟，因为一个勇敢的人可能通过他的举止赢得关注，而一个胆小如鼠的懦夫会招致不幸。

谦卑不是我们在他人面前提供的个人折扣——对于这种古老的解释产生了一种非常现代的反响。任何彻底了解自己的人都必须感受到真正的谦卑；但那不是假装像虫一样的温顺；而是一种强烈的、充满活力的祈，请求更大的服务力量——那是尤亚·希普（Uriah Heep）永远无法说出的祈。

华盛顿·欧文（Washington Irving）在一次为后者举行的宴会上介绍了查尔斯·狄更斯（Charles Dickens）。在演讲中，欧文犹豫了，感到很尴尬，局促地坐下了。他转向身边的朋友说：“看，我告诉过你会失败的，我确实失败了。”

如果你认为自己会失败，你就没有希望了。你会失败的。

丢掉这种“我是尘埃中卑微的小虫”的念头吧。你是一个神，拥有无限的能力。“只要心念如此，万物皆备。”鹰直面面对没有云的太阳。

### 假设对观众的掌控力

在公共演讲中，就像在电力中，有正力也有负力。要么是你，要么是观众将拥有正因素。如果你假设自己可以，你几乎总是能做到。如果你假设是负面的，你注定是负面的。假设一种美德或恶习会使其充满活力。汇集你所有的自我引导能力，并记住尽管你的观众比你重要得多，但真理比你们两个都重要，因为它是永恒的。如果你的思想在领导上动摇，剑就会从你手中落下。
