

# 第 XX 章

每一位演讲者都是，因为人类最早的文学倾向就是描绘。

描述的本质。描述就是在听听者的脑海中唤出一幅画面。“当我们谈论描述时，我们自然是在谈论刻画、勾勒、着色，以及画家所有的技法。描述就是视觉化，因此我们必须将描述视为一个绘画式的过程，无论作者处理的是物质对象还是精神对象。”[19]

如果你被要求描述一把快速射击的枪，你可以采取两种方式之一：对其机制进行全面且详尽的冷冰的技术性说明；或者将其描述为一台恐怖的杀戮机器，侧重于它的效果而非结构。

在这两种过程中，前者是阐述（exposition），后者是真正的描述（description）。阐述更多地关注一般性，而描述必须处理特殊性。阐述解释思想，描述处理事物。阐述处理抽象概念，描述处理具体。阐述关注内部，描述关注外部。阐述是列举性的，描述是文学性的。阐述是理性的，描述是感官的。阐述是不带感情的，描述是个性的。

如果说描述是听者的视觉化过程，那么它首先对演讲者而言也是如此——他无法描述他从未见过的东西，无论是亲眼所见还是想象出来的。这种个性的特质——这种观察后后要描述事物的“个人之眼”，使得描述在公共演讲中变得如此有趣。面对一位性格鲜明的演讲者，且我们对他的个人观点感兴趣——这增加了场景的趣味性，甚至可能是观众兴趣的唯一来源。

观察之眼已在早前的一个章节（关于“主题与准备”）中得到过赞扬，想象将在随后的章节（关于“骑乘天马”）中进行讨论，但在这里我们必须考虑这种*绘图的心灵*，它形成了一种双重习惯：一是我们看到的比肉眼看到的更多——二是为了将这些事物呈现在听者的脑海中而对其进行重新想象。没有什么习惯比清晰地视觉化即将描述的对象、场景、情境、动作、人物更有用了。除非首要过程执行得清晰，否则对于听者兼观众来说，画面将是模糊的。我们关注描述的修辞分析及其方法，仅限于满足演讲者实际目的的需要。[20] 因此，下文分类将不被视为完整的，此处也没有必要多作多余的解释：

公共演讲者的描述分类

| 类别 | 类型 |
| :--- | :--- |
| 对象 | 静止、运动中 |
| 场景 | 静止、包含动作 |
| 情境 | 变化之前、变化中、变化之后 |
| 动作 | 心理的、身体的 |
| 人物 | 内部、外部 |

上述某些过程在某些情况下会重叠，并且以组合形式出现的比单独出现更常见。

当描述的意图仅在于提供准确信息时——例如描绘最新齐柏林飞艇的外观，而非技术构造——它被称为“科学性描述”，与阐述相似。当描述的目的是为了呈现一个自由的画面以留下深刻的印象时，它被称为“艺术性描述”。公共演讲者必须处理这两种，但更频繁地是后者。修辞学家对此还有更进一步的区分。

描述的方法。在公共演讲中，描述应主要通过暗示（suggestion）来进行，不仅是因为暗示性描述要简洁得多且节省时间，而且因为它是生动的。暗示性的表达所涵盖的内容比其字面意思更多——它们向听者的脑海暗示思想和画面，补充了演讲者的直接话语。当狄更在《圣诞歌》中说：“费兹威格夫人过来了，带着一个巨大的、充实的微笑”时，我们的脑海灵巧地完成了那个被定义得如此清晰的画面——这比细致入微的描述有效得多，因为它留下了一个统一、生动的印象，而这正是我们需要的。这里有一个当代的暗示：“特林克尔将军是一个粗壮的橡树——粗犷、结实且安全；你总能找到他。”狄更描述皮彻小姐为一个小针垫、一个家庭主妇、一本书、一个小工具箱、一套桌子和秤，合为一体。”在艾灵的《尼克尼博克的纽约史》中，将沃特·蒂勒描绘为“一个结实的啤酒桶”。

无论忽略了哪种描述形式，请务必精通暗示的艺术。

*描述可以通过简单的提示（hint）来进行。洛威尔指出了一个这种暗示式描绘的成功案例，他在评价乔叟时说：“他有时通过优点进行丰富的描述，正如修道士在坐下之前，赶走了猫。我们不需要多余的字，就知道他选择了最舒适的角落。”

*通过其效果来描绘一个事物。* 莫兹利在《随笔》中写道：“当观众的眼睛被闪亮，并遮住眼睛时，我们形成了一个华丽物体的想法；当他的脸变白时，是一个恐怖物体；从他的惊讶和赞叹中，我们形成了美的理想；从沉默的敬畏中，形成了庄严的形象。”

*简洁描述可以通过称号（epithet）来进行。*“蓝眼睛”、“白手臂”、“喜笑”现在是陈词化的复合词，但在荷马首次将它们组合时，它们足够新颖。几个世纪还没有超越“转动的、青铜的、八辐轮”，或“光滑的、美丽的、青铜的、锻良好的盾牌”。观察华盛顿在《战斗死亡》中谈论战斗中的士兵时，对称号的有效运用。

*描述使用了修辞。*任何高级修辞学都会讨论这些形式，而刻画是所有创作的极佳资源。

*描述可以是直接的。*根据你自己的判断，是从整体观点到细节，还是先从细节开始由此建立整体观点。

*用于讲的描述可以通过节制使用现在时（historical present）来变得生动。*以下这段剧性的片段配合着最生动的动作，在听完德威特·塔马奇博士关于“大错误”的演讲三十年后，仍留在脑海中。击球声在今天听起来依然清晰：“准备击球，站好位置。现在，球。太低了，不中。太高了，不中。闪电般袭来。击中！飞了！更高！更高！跑！过垒！快！快！好！一举搞定！”
