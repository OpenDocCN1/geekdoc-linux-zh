
# 第十三章

我从未停留在那枯燥、驯服的岸边
但我更爱那广阔的大海，
并向她波涌的胸怀飞去，
如一只寻找母巢的鸟儿——
对我而言，她过去和现在都是母亲，
因为我出生在广阔的海面上。

浪花是白的，晨曦是红的，
在我出生的喧闹时刻；鲸鱼在鸣叫，海豚在翻滚，
海豚露出它们金色的背部；
我从未听过如此狂野的呼喊，
如同迎接生命——五十个夏天里，
一个浪子的生活，
有财富可挥霍，有力量可游荡，
却从未渴求或叹息改变：
而死亡，无论他何时降临，
都将在那片广阔、无垠的海面上到来！

--巴里·康沃尔（BARRY CORNWALL）。

太阳并非为了几棵树几花而闪耀，而是为了整个世界的快乐。山顶孤独的松树摇曳着它阴郁的枝条，哀鸣道：“你是我的太阳。”而小草地的紫罗罗举起它蓝色的杯，用它芬芳的呼吸低语道：“你是我的太阳。”千顷田里的谷物在风中沙响，回答道：“你是我的太阳。”于是，上帝坐在天堂，光芒四射，不是为了少数受青睐的人，而是为了整个生命的宇宙；没有哪个生物是如此贫穷或卑微，以至于不能带着孩子般的自信抬头说：“我的父！你是我的。”

--亨利·华德·比比切（HENRY WARD BEECHER）。

云雀

荒野之鸟，快乐而无数，你那荒原与草地上的晨歌是如此美妙！快乐的象征，你的居所是有福的：噢，愿与你同处荒漠！

你的歌声是狂野而响亮的，在远方的绒云中—— 爱情赋予了它能量；爱赋予了它生命。在露水多风的地方，你正向何处去？你的歌声在天上，你的身在地上。

越过险峻的岩石与闪光的泉水，越过荒原与绿的山峦，越过预示黎明的红霞；越过阴暗的小云，越过彩虹的边缘，音乐的丘比特，飞翔吧，歌唱着远去！

当黄昏降临，在紫兰花丛中绽放，愿你那欢迎与爱的床是甜蜜的！快乐的象征，你的居所是有福的。噢，愿与你同处荒漠！

--詹姆斯·霍格（JAMES HOGG）。

# 第十三章

小溪

我来自白嘴鸥和雨燕的栖息地，我突然出发，
在蕨类植物中闪烁，
向山谷流淌。

我匆匆冲下三十座山，或在山脊间穿行；
经过二十个村庄，一个小镇子，
和五十座桥。

直到最后在菲利普农场旁我流过，
汇入满溢的河流；因为人会来，人亦会去，
但我永远向前。

我在石路上叽叽喳，发出短促而高亮的音调，
我在涡流湾中吐泡，在卵石上细语。

我的岸边在许多弯处磨损，经过许多田野与荒地，
许多如仙境般美丽的地方
点缀着柳菜和锦葵。

我叽喳、叽喳、叽喳，随着我流淌，
汇入满溢的河流；因为人会来，人亦会去，
但我永远向前。

我蜿蜒，进进出出，带着一朵花漂浮，
这里那里有一条游鱼，
这里那里有一条鲺，

这里那里有一片泡沫
随我旅行落在我的身上，
在金色的碎石上方
有许多银色的水花，

将它们全部带着向前，流向，
汇入满溢的河流，因为人会来，人亦会去，
但我永远向前。

我溜过草坪和草地，我滑过榛果丛，
我移动着那为快乐恋人生长的甜蜜忘忧草。

我滑行，我，滑行，我阴郁，我凝视，在我掠过的燕子间；
我让网状的阳光在我的沙滩浅处跳跃，

我在月与与星下低语，在布满棘的荒野里，
我在我碎石的堤岸旁逗留，我在我的水菜周围徘徊；

然后再次我弯曲流淌，
汇入满溢的河流；因为人会来，人亦会去，
但我永远向前。

--阿尔弗雷德·丁尼（ALFRED TENNYSON）。
