

# 第二二章

# 231

与他们在一起，并告诉他们，正如他所做的那样，货币的问题是政府的功能，银行应当退出治理事务。

# --威廉·詹宁斯·布莱恩。

权威是反对怀疑的伟大武器，但即使是它的力量也很少能战胜偏见和固执的愚蠢。如果有任何演讲者能够锻造出一把足以穿透这种盔甲的剑，就让他向各地的平台同仁分享他的秘密来造福人类吧，因为到目前为止，他是唯一的荣光者。

在权威的暗示与软弱的承认之间存在着中间地带，这为演讲者提供了广大的圆术空间。没有人能建议你何时该“跃入角”，并在开始时就挑战性地说：“先生们，我来战斗了！”西西奥尔·罗斯福可以做到这一点——而比彻如果在利物浦以这种大派风格开场，他会被群众围攻。至于是否使用那个老掉的笑话——即亨利·W·格拉迪刚才引用的开场白——是仅仅精妙巧妙并似乎在说：“先生们，我带着没有仔细填充的硬币来到你们面前，”还是说布莱恩先生在大会前的庄严严肃会被证明是更有效的，这取决于你自己的圆术。只需确保你的开场态度是经过深思熟虑的，如果它随着你对主题的热热而发生变化，不要让这种变化引起观众的反感。

*榜教作用是一种强有力的暗示手段。* 正如我们在思考环境对观众的影响时所看到的，我们在做他人正在做的事情时，并没有像往常那样的迟疑和批评。巴黎戴着帽子和长袍；世界上其他地方都在模仿。孩子模仿父母的动作、口音和语调。一个从未听过人说话的孩子，除非经过最艰苦的训练，否则永远无法获得说话的能力，即便如此也是不完美的。美国最大的百货商店之一花费了巨资投入某句广告口号上：“每个人都会去大百货。”这让每个人都去了那里。

# 第二二章

你可以通过展示你的信息已被广泛接受来增强你的信息的力量。政治组织通过资助掌声来营造出一种他们他们演讲者的观点受到观众温暖接受和批准的印象。城市委员会制政府的支持者、女性投票权的捍卫者，将“许多城市和州已经成功接受了他们的计划”作为他们强有力的论点。广告利用证言是因为其暗示的力量。

注意这一原则在以下选文中已被应用，并在你试图通过暗示影响他人时，尽可能在每个场合利用它：

战争实际上已经开始。下一阵从北方吹来的大风将把兵器碰撞的响声带到我们的耳朵。我们的兄弟已经在战场上了。你们为什么还在这里无所事事？

--帕特里克·亨利。

带着一种接近追随彼得·隐士的十字军征服者的热忱，我们的银色民主党从一次胜利走向另一次胜利，直到现在他们聚集在一起，不是为了讨论，不是辩论，而是为了进入这个国家平民已经做出的判决。在这种背景下，兄弟对立兄弟，父子对立。最亲密的爱、交情和协会纽带被忽视了；老一领袖在拒绝表达他们想要领导的人的情感时被抛弃了，新的领袖脱颖而出，为这项真理事业提供方向。竞争就是这样进行的，我们聚集在这里，受到的指令比任何时候加在人民代表身上的指令都具有约束力和严肃性。

--威廉·詹宁斯·布莱恩。

比喻和间接语言具有暗示的力量，因为它们没有做出可以被反驳的陈述。它们不会在观众脑海中引起矛盾的思想，从而履行了暗示的基本要求之一。通过在间接或比喻语言中暗示结论，往往能强有力地主张。

注意，在接下来，布莱恩先生并没有说麦金利先生将会失败。他以一种更有效的方式暗示了这一点：

麦金利先生在圣路易斯被提名，其平台主张维持金本位，直到通过国际协议将其改为双金属货币制。麦金利先生是共和党最受欢迎的人，三个月前，共和党每一个人都预言他将当选。为什么今天不是呢？为什么，那个曾经乐于认为自己看起来像拿破仑的人，今天在想起自己是在滑铁卢战役纪念日被提名的时，却在发抖？不仅如此，当他倾听时，他能越来越清晰地听到海浪拍打在圣赫勒拿孤独岸边的声音。

如果卡莱莱说：“虚伪的人找不到宗教，”他的话既不会是那样有力量，也不可能像他在这些引人注目的话语中的暗示那样被长久记住：

一个虚伪的人找到了宗教？为什么，一个虚伪的人造不起砖房！如果他不真正地了解并遵循砂浆、烧粘土以及他所作用的其他材料的特性，他造的就不是房子，而是一堆垃圾。它无法立足十二世纪来容纳一亿八十万；它会立即倒塌。人必须顺应规律，真正与自然以及事物的真理交流，否则自然将回答他：不，绝绝不！

观察韦伯斯特在这里描绘的画面如何比任何单纯的断言都更加强调和更有力：

先生，我不知道别人感受如何，但对我自己来说，当我看到我的母校像凯撒在元老院一样，被那些反复一刺又一刺的人包围时，我宁愿让这只手转过来对我说：“还有你也是，我的儿子！”
