# 学习选

# 联盟国的末日（节选）

拉皮丹河（Rapidan）暗示了另一个自战争以来人们经常提及的场景，但作为对两军军队精神的例证，我被允许在此处回想起这段往事。在四月某日的柔和暮色中，两支军队在河流两岸相对的山丘上举行了盛装游行。游行结束，联邦军一支华丽的铜管乐队慷慨激情地演奏了爱国歌曲《赞美哥伦比亚》（Hail Columbia）和《扬基杜多尔》（Yank Doodle）。联邦军以爱国的欢呼作为回应。同一支乐队随后奏响了动人心弦、激昂的旋律——《迪西》（Dixie），万名南方士兵发出了响亮的回应。几分钟后，当星星升起作为见证，当万物都归于和谐时，同一支乐队再次响起了那首老旋律《美好的家》（Home, Sweet Home）。随着那熟悉而甜美的音符在水面上回荡，震撼了士兵们的心灵，并在两军齐声的呼应中雷鸣般的回响。这首古老的歌曲中究竟有什么，能如此触动共鸣的弦律，如此震撼精神，让勇敢男人的躯体因情感而颤抖？那是对家的思念。对于数千人来说，那是对永恒之家的渴望，下一场战斗可能是通往那里的门户；对于其他数千人来说，那是他们亲爱的世俗之家，黄昏时分，亲人们正围在家族祭坛旁，祈神保佑远方的士兵儿子。

> --J.B. 戈登将军，南方联盟军（C.S.A.）

# 欢迎来到科萨（节选）

请让我设想，如果美国争取英国独立的斗争失败了；如果我们的军队由于背叛或独裁者的结盟而被击溃和散去；那些领导他们并左右我们委员会的伟人————华盛顿、我们的富兰克林，以及美国国会受尊敬的总统——被驱逐为流亡者。如果在那一天，在文明世界的任何地方，存在一个强大的共和国，其制度建立在我们的同胞寻求建立的同样的自由基础之上，那么这个共和国是否会对这些诚挚的人持有任何好客？是否会有足够深厚的同情？是否会对他们辉煌却不幸的事业表现如此热忱或积极，以至于表现给这些显赫的亡民？先生们，我所假设的情况就在你们面前。那些华盛顿、富兰克林，以及匈牙利的汉考克们，被比这里遭受过的更严重的暴政所驱逐，成为异国他乡的流浪者。他们中的一些在我们国家寻求庇护——其中一人今晚就与我们同坐——我们必须用同样的标准来衡量对他们的义务，如果我们的祖先遭遇了那那样的，我们也希望历史能这样对待他们。

> --威廉·库伦·布莱特。

# 大学的影响（节选）

当党派战争的疯狂危险地接近我们的国家安全线时，我希望我们大学和学院的智识保守主义能以令人震撼的语调警告竞争者，不要造成那种无法修复的裂痕之危险。

当民众的不满和激情被心机深险的党派分子煽动到接近阶级仇恨或地区愤怒的危险程度时，我希望我们的大学和学院以美国兄弟情谊和相互依赖的名义响警报。

当人们试图误导民众，让他们相信投票可以改变国家法律的运作时，我希望我们的大学和学院宣布，那些法律是不可更改的，且远离政治控制的。

当私利利益通过政府援助寻求不正当的私人利益，当公共场所被视作党派服务的奖励时，我希望我们的大学和学院说服民众放弃对党派分利的追求，并敦促他们对政府保持无私且爱国的爱，因为政府不偏颇的运作确保了每位公民都能获得其为所有人留的安全与繁荣的公正份额。

我希望这些机构的影响能站在宗教和道德的一边。我希望那些他们派遣到民众中的人不羞于承认上帝，并宣告上帝在人类事务中的干预，告诫他们顺从律法，这种顺从彰显了国家长久与繁荣的道路。

--格罗弗·克莱兰，1896年于普林斯顿五十周年纪念活动演讲。

# 加尔菲尔德悼词（节选）

他生前伟大，死后更是卓越伟大。因为并非为了任何理由，在那种肆虐和恶意的狂热中，在谋杀的血手中，他被推离了这个世界关注的洪流，推离了它的希望、愿景和胜利，推向了死亡的可见存在——而他并未畏缩。不仅是因为在那由于震惊和迷茫而几乎放弃生命、几乎未察觉到正在失去生命的短暂一刻，更是因为经历了数日致命的虚弱、数周的痛苦——这种痛苦并因因沉默地承受而有所减轻，因为他以清醒的目光和冷静的勇气，注视着自己敞开的坟墓。怎样的灾难和毁灭出现在了他焦虑的眼目中，只有他的唇能诉说——怎样辉煌而破碎的计划，怎样受挫的高远野心，怎样强壮、温暖的男汉友谊的破碎，怎样对甜蜜家庭纽带的更佳呈现？在他身后是一个自豪且充满期待的国家，是一群伟大的支持者，一位深受宠爱的、幸福的母亲，她戴着早期辛劳与泪水换来的全部荣誉；他年轻时的妻子；尚未离开童年时光的小男孩们；美丽的女儿；正健壮成长寻求同伴的后辈；而在他心中，有着面对一切要求的渴切力量。

在他面前，是荒凉与巨大的黑暗！但他的灵魂并未动摇。他的同胞们被瞬间的、深层的同情所震撼。他在凡躯的虚弱中展现出大师风，成为了国家之爱的中心，被铭刻在世界的祈祷之中。所有的爱与同情都无法与他分担痛苦。他独自走过苦难之路。他以毫不动的身姿面对死亡。在刺客子弹魔鬼般的嘶声之上，他听到了上帝的声音。他以简单的顺服屈从了神圣的意。

---詹姆斯·G·布莱恩，在美国参议院和众议院举行的纪念仪式上演讲。
