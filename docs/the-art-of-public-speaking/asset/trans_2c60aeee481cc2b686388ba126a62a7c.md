# 演讲建议主题
附带偶尔处理提示

- 1. **电影与道德。**

- 2. **关于谎言的真相。** 说实话与撒谎的本质。不被视为谎言的谎言。所需的细微区别。暗示性谎言与行为性谎言的示例。

- 3. **灾难后的收益。** 源自洪水、火灾、地震、战争等产生的利益。

- 4. **休闲的忙碌。** 速度狂热如何源于对永不降临的闲闲的虚荣渴望；相反，世界表面上的忙碌如何为人们提供了更短的劳动时间以及更多休息、学习和娱乐时间。

- 5. **圣保罗给纽约的信息。** 书信中与当今大城市相关的真理。

- 6. **教育与犯罪。**

- 7. **失去是收获的源泉。** 许多人在失去一切之前都很知足，直到之后他们付尽全力重获成功，并取得了比以前更巨大的成功。

- 8. **利己主义 vs 自我中心主义。**

- 9. **年轻守旧主义的错误。**

- 10. **慈善系统中中间人的浪费。** 为贫困者筹集资金和提供援助的成本。组织化慈善与自我自发性施予相比的弱点。

- 11. **组织化慈善的经济效益。** 画面的另一面。

- 12. **新闻自由。** 痛苦地控制了太多报纸的真实力量并非专制政府，而是金钱和政治利益的腐败影响、对酒精权力的恐惧，以及迎合喜爱奇奇读者的欲望。

- 13. **海伦·凯勒：乐观主义者。**

- 14. **回到农场。** 对该运动背后原因的研究。

- 15. **历来皆然。** 嘲笑那些对失败从不意外的悲观主义者。

- 16. **职业高中。** 直接训练的价值与为后期建设奠定更广泛基础的政策之比较。这两种理论在实践中如何运作。每个计划都可以特别适用于需要特殊处理的案例。

- 17. **这里发生的各种转变。** 对摇摆不定、风车式性格的幽默而严肃的讨论。

- 18. **利己的利他主义者。** 赫伯特·斯宾塞（Herbert Spencer）在《伦理数据》中讨论的理论。

- 19. **城市如何威胁国家。** 人口聚集中的经济危险。也展示另一面。问题正在解决的迹象。

- 20. **现代诗歌中的强劲基调。** 盖尔斯沃斯（Galsworthy）、马塞菲尔德（Masefield）和吉普林（Kipling）的作品与早期诗人的作品之比较。
