

## 第六章

## 64

过去如梦幻般出现在我面前。我们再次处于为了民族生存的伟大斗争中。我们听到准备的声音——喧闹的鼓声，英雄号角那银脆的鸣响。我们看到成千上万的集会，听着演讲者的呼吁；我们看到妇女苍白的脸庞和男子红的脸庞；在那些集会中，我们看到了所有尘土已被鲜花覆盖的逝者。我们不再忘记他们。当他们加入自由大军时，我们与他们在一起。我们看到他们与爱的人告别。有些人正与他们爱爱的少女在寂静的林地间最后一次散步。我们听到他们永远徘留时的低语和对永恒之爱的甜蜜誓言。另一些正俯在摇篮旁，吻着熟睡的婴儿。有些人正接受老人的祝福。有些人正与紧抱着他们的人告别，一次又一次将他们按在怀里，沉默不语；有些人正与妻子交谈，努力用老语调说出的勇敢话语驱散内心的极度恐惧。我们看到他们告别。我们看到妻子站在门口，怀抱着孩子——站在阳光下抽泣；在路口，一只手挥了挥——她用慈爱的手抱着孩子作为回应。他走了——永远地走了。

> --罗伯特·J·英格索尔，致印第安纳利斯的士兵。

命运之指在书写；写完便继续向前：无论你多么虔诚或才华，无法让它回回撤销其中的半行，你所有的泪水也无法洗掉其中的一个字。

女性的历史是一部受虐待的历史。长期以来，男人像对待牲口一样殴打、贩卖和虐待他们的妻子和女儿。斯巴塔母亲由于生了一个同性的孩子，她辱了自己；女婴经常被遗弃在山里等死；中国缠缚并扭曲她们的脚；土耳其遮住她们的面脸；美国拒绝给予她们与男性等的教育机会。世界上大部分地区仍然拒绝她们参与政府的权利，女性在各处都承受着不平等道德标准的苦果。

## 65

但妇女们正在进军。她们正向着思想者统治的阳光平原向上走去。中国已经停止了缠足。在后宫的阴影下，土耳其为女孩开办了学校。美国已经给了妇女平等的教育机会，我们相信，美国将赋予她们选举权。

对于这场伟大的运动，我们能做的帮助无几，阻碍也有限。思想者们对此表示赞同。它正坚定地朝着目标前进，正如这片古老的地球正离开冬日的束缚，向着春天的花和夏天的收获迈而去。[1]

## 第七章

## 通过语调实现效率

村里的钟声是多么轻柔，
间歇地落在耳边，
带着甜美的韵律；如今渐渐远去，
如今再次响亮，愈发响亮，
清脆悦耳，随着狂风袭来！
它以轻松的力量开启了
记忆睡眠的细胞。

--威廉·考沃，《任务》。

赫伯特·斯宾曾评论道，“韵律”（Cadence，他指的是说话时语调的调制）“是情感对智力命题的动态评论”。这句话有多真实，当我们反思声音微小的起升起伏比我们的词汇更真实地表达了我们的意图时，就会显出来。语言的表达力通过这种改变声调阴影的微妙力量而倍增，而这种声音——我们称之为“语调”（inflection）。

单词内部音调的变化甚至比短语之间音调的变化更为重要，因为它更细腻。事实上，两者不可不可缺。单调的词仅仅是许多砖块——语调会将它们变成铺设好的道路、车库或大教堂。正是语调改变词义的力量产生了那句老话：“重要的不是你说了什么，而在于你怎么说。”

莎士比亚评论家詹姆森夫人为我们提供了一个关于语调效果的深刻例子；西德斯夫人在扮演麦克白夫人的角色时，在说出‘我们失败了’这两个词时连续采用了三种不同的语调。起初是快速且轻蔑的询问——‘我们失败了？’随后，带着钦佩的语气——‘我们失败了’，带着愤怒的惊讶将重音放在‘我们’字上——我们失败了。最后，她固定在我深信是正确的读法——‘我们失败了’，语气平稳，将声音调制为深沉、坚定的语调，立刻定下了结局，仿佛她在说：“如果我们失败了，那我们为什么要失败呢，一切都结束了。’”

我们语言中最具表现力的元素是我们在学习外语自然表达时最后被掌握的元素，而它的正确使用是我们的母语自然、灵活表达的主要要素。没有了多样的语调，说话就会变得生硬而单调。

语调只有两种：升调和降调，这两种语调可以处理成不同程度的阴影或组合，从而产生如一条或两条直线、曲线那样的变化，如下：

| 语调类型 |
| :--- |
| 快速升调 |
| 长升调 |
| 平调 |
| 长降调 |
| 快速降调 |
| 快速升降调切换 |
| 犹豫调 |

这些可以无限变化，仅用于说明这两种简单语调的组合可以产生多广泛的变化。

列出表达各种思想和情感色彩的各种语调是不可能的。这里提供了一些建议，并附有大量的练习，但掌握语调的唯一真正方法是观察、实验和练习。

例如，取常用的句子：“噢，他很好。”注意升调如何被用来表达微弱的赞美、礼貌的怀疑或意见的不确定。然后看同样的词，以通常的降调说话时，如何表示确定性、好意的赞同或热忱等等。

总而言之，我们发现声音的向上扬扬会暗示怀疑和不确定，而坚定的降调则暗示你对立场是肯定的。
