Nearly all tasks you perform in a Red Hat Linux system involve one or more GNU software packages. For example, the GNOME graphical user interface (GUI) and the command interpreter (that is, the Bash shell) are both GNU software programs. By the way, the *shell* is the command-interpretation application that accepts the commands you type and runs programs in response to those commands. If you rebuild the kernel or develop software, you do so with the GNU C and C++ compiler (which is part of the GNU software that accompanies Red Hat Linux). If you edit text files with the ed or Emacs editor, you’re again using a GNU software package. The list goes on and on.
