You can start applications from this menu. That's why the KDE documentation calls the Red Hat button (of course, the KDE documentation refers to the button as the K button) the Application Starter.

Next to the Red Hat button, the panel includes many more buttons. If you don't know what a button does, simply move the mouse pointer over the button; a small pop-up window displays a brief message about that button.

Table 4-1 gives you an idea of what happens when you click each of the major buttons on the KDE panel. When you have some time, try these buttons one by one to get a feel for what you can do in KDE.

**Table 4-1 KDE Panel Buttons**

| When You Click This | It Does This |
|---|---|
| [Hat icon] | Shows the application menu from which you can start any application. |
| [Helmet icon] | Starts the Mozilla Web browser. |
| [Envelope / notepad icon] | Starts the Ximian Evolution e-mail and calendaring software. |
| [Document with pencil icon] | Runs OpenOffice.org Writer, a Microsoft Word-like word processor. |
| [Presentation / monitor icon] | Runs the OpenOffice.org Impress slide presentation program that's similar to Microsoft PowerPoint. |
| [Spreadsheet / disc icon] | Runs OpenOffice.org Calc, a Microsoft Excel-like spreadsheet program. |
| [Printer icon] | Runs Print Manager, a utility that enables you to set up and monitor print queues. |
| [Desktop switcher 1 2 3 4 icon] | Switches to the desktop whose number you have clicked. |
| [Clipboard / Klipper icon] | Runs Klipper, the KDE clipboard utility for cutting and pasting information. |
| 20:42 | Displays the current time. Click to view the current month's calendar. Right-click the menu to adjust date and time. |
