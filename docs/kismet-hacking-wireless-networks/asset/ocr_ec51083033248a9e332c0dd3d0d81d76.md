# Introduction

The goal of this chapter is to provide an explanation and demonstration of wardriving while using Kismet with BackTrack, a live Linux distribution. The focus will be on the fact that we'll be using a live CD, so no installation is required, and very little configuration is necessary. This is also useful for those who are running Windows and need to use Kismet but don't necessarily want to install an entire Linux distribution. It is also important to note that wardriving is just one example of why you might want to use Kismet from a live CD. Other possibilities are rogue access point (AP) detection or graphical mapping of networks.

# Obtaining BackTrack

This section will focus on acquiring BackTrack by download (direct or torrent), and then burning it to CD.

# Downloading BackTrack
