Before you decide to give up (and sadly, some people do), read the error message for an explanation of why Kismet failed to start. In this case, no capture source was enabled. As you might expect, this is a fatal error. We can also deduce from this error that we can correct this problem by specifying a capture source either via the kismet.conf file or the command line.
