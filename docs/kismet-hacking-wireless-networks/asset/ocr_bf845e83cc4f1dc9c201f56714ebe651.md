Like the main network display, we can specify the columns to be shown when we are in the client information screen that gives us information about the clients associated with that network.

The options, just as with the main screen, are added, comma seperated with no spaces, to the `clientcolumns` = line.

The available columns are:

+   - **Crypt** The number of encrypted data packets transferred by client. The crypt counter, like the main network screen, shows the total number of encrypted packets transferred to and from the client. If the network is open, this counter does not count anything.

+   - **Data** The number of data packets transferred by client. The data counter counts all data packets to and from the client, both unencrypted and encrypted packets.

+   - **Decay** Displays ““, “, ” or “” based on network activity. Once again, the client’s recent activity can be tracked through the decay column.
