# Installation

Installation of GpsDrive presumes that you have installed BackTrack 3 Beta (or another distribution of Linux) to your hard drive. You will also require the following packages: gsd, GTK-+2.x (better >=2.2.x), pango, atk, pcre, xadvel (X11 development), gettext, librypt, glIBC, gcc >=3.x, and make. In many cases, some or all of these packages will already have been installed. In any case, you ought to check beforehand to avoid any problems. Finally, GpsDrive requires Structured Query Language (SQL) support to interface with Kismet. In the case of BackTrack, MySQL is already installed; on other distributions, you may have to do it yourself.
