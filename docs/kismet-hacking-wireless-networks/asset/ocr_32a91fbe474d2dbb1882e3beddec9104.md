# Sorting

As you will note in Figure 4.4, Kismet’s default sorting mode is known as *autofit*. The goal of autofit is to display as many currently active networks as possible. While using autofit, network selection, tagging, grouping, scrolling, and so forth is disabled. To use any of these features, simply sort the network list by another method. To bring up the sort options, simply press s (see Figure 4.5).
