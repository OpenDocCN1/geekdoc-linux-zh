+   * **T#** Address range of # octets found via TCP traffic

+   * **U#** Address range of # octets found via User Datagram Protocot (UDP) traffic

+   * **A#** Address range of # octets found via Address Resolution Protocot (ARP) traffic

+   * **D** Address range found via observed Dynanic Host Configuration Protocot (DHCP) traffic

+   * **W** WEP’d network decrypted with user-supplied key

These flags can be useful to quickly note to other apps that something is amiss or should be noted (such as a default-configured network).
