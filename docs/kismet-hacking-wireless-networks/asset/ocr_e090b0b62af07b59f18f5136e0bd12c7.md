# Figure 2.11 Locate the Line Beginning with source

![](bbox=[0.12, 0.11, 0.9, 0.59])

We need this line to show the card driver, the card physical name, and a reference name. In this case we are changing this line so that it says *source* =madwifi_g, *wifil0, ProximBG*. This line tells Kismet that the capture source is using the *madwifi_g* driver on physical card *wifil0*. The card's reference name is simply the brand name, "Proxim" and "BG," since the card is the type that uses both the 802.11b and 802.11g protocols. (See Figure 2.12.)
