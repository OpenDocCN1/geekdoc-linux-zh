# # Information Panel

The information panel labeled as “Info” is a small vertical panel to the right of the network list panel (see Figure 4.8).

+   - **Ntwrk** Total number of collected networks
+   - **Pckets** Total number of collected packets
+   - **Cryptd** Total number of collected packets that were encrypted
+   - **Weak** Total number of weak packets collected
+   - **Noise** Worthless garbage packets
+   - **Discrd** Total number of discarded packets; includes noise and packets discarded from the use of filters
+   - **Pkts/s** Rate of packet collection (per second)
+   - **Elapsd** Total time (HH:MM:SS) since the Kismet was started
