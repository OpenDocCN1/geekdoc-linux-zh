# Customizing the Panels Interface

As has already been noted, Kismet can display a wealth of information about a network or client on the network and client lists (respectively), the only limitation being size. Should you find your work requires additional information not be available to you from one of these two displays, you can easily modify Kismet’s user interface configuration file to add or remove columns. Also, Kismet provides the ability to change colors to suit your needs.
