# 简明的 LINUX

随着互联网推动信息交换、初创企业和在线游戏的新世界，程序员突然成为这些新领域的守门人。将人们对学习和控制如何创建这些世界的巨大兴趣，与树莓派等酷炫设备的激增相结合，你就拥有了自 1980 年代初编程热潮以来世界未曾见过的技术蒸汽头。因此，无论你是想重温那些令人兴奋的 80 年代编程日子，还是作为一个新手想要迈出编程世界的第一步，你手中握着的都是开始编程的理想指南。得益于新一代的开放自由软件，我们都可以访问创建专业程序、应用程序和工具所需的操作系统、开发工具、编译器和编程语言。我们将展示如何使用 Linux 系统运行起来，然后免费在线访问你需要的一切。编程简单、令人兴奋且有趣。我们将解释基础知识，继续探讨更高级的主题，解释如何使用树莓派，并为你提供完全更新的、令人兴奋且易于遵循的项目。那你在等什么呢？开始编程吧！
