# # 4.6 Installation: Selecting System Components

(For an explanation of system components, please see Chapter 2, Section 2.4.12.)

**Important!** When selecting system components to install for Red Hat Linux/SPARC, choosing to install **Everything** without choosing **Select individual packages** could result in an unbootable Red Hat Linux system. The last kernel to be installed will be a multi-processor kernel, which will fail to work on sun4c machines. Additionally, the default X server will end up as XsunMono, which may not work for most people. If you do wish to install **Everything**, choose **Select individual packages** as well. Then, deselect all the kernels except for one you wish to install (`kernel-sparc` works for most) and all X servers except the one for your hardware (`XsunMono` for btw20 video cards, `Xsun` for all 8-bit displays, and `Xsun24` for the supported 24-bit displays).

# # 4.8 Partitioning

There is one additional step in partitioning a hard drive for a SPARC. You must create the third partition of every disk as type **Whole Disk** spanning from cylinder 0 to the end of the disk. It shouldn't be touched, but should exist. You can still create other partitions just as you normally would.

Additionally, the first partition on a disk should not be a swap partition, *unless* the swap partition starts on cylinder 1.
