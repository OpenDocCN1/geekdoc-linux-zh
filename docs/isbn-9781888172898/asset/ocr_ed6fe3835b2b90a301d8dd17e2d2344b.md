# ## 7.4 Other RPM Resources

For more information on RPM, check out the man page, the help screen (rpm --help), and the RPM documents available at

```
`ftp://ftp.redhat.com/pub/redhat/code/rpm`
```

As mentioned earlier there will also be a comprehensive RPM book available soon. When it is published there will be information on our web site, http://www.redhat.com.

There is also a mailing list for discussion of RPM related issues, called rpm-list@redhat.com. The list is archived on http://www.redhat.com/support/mailing-lists/. To subscribe, send mail to rpm-list-request@redhat.com with the word subscribe in the subject line.
