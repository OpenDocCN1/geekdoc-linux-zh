# Appendix A

# Module parameters

This appendix is provided to illustrate *some* of the possible parameters that *may* be needed by certain driver modules. It should be noted that in most cases the use of additional parameters is not needed.

# A.1 CD-ROM parameters

| Hardware | Parameter |
| :--- | :--- |
| Mitsumi CD-ROM | mcd=port,irq |
| Sony CDU 31 or 33 CD-ROM | cdu31a_port=base_addr cdu31a_irq=irq |
| Aztech CD268 | aztcd=port |
| SB Pro or 16 compatible | sbpcd=io_addr,sb_pro_setting |
| ATAPI/IDE CD-ROM Drives | hrd=cdrom |
