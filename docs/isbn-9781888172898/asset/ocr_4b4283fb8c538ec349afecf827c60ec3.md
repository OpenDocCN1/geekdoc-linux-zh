226 APPENDIX E. RED HAT LINUX FREQUENTLY ASKED QUESTIONS

# E.4 Using Red Hat Linux

# E.4.1 Why doesn't the xmh shipped with Red Hat work properly?

We only ship xmh because it is part of the standard X11 distribution. xmh is basically shipped as-is from the X11 distribution, and is most likely broken. We've found that there are several better alternatives. If you want to use mh mail, install the mh RPM and the exmh RPM. exmh is a much better GUI mail reader than xmh.
