# # Finding Documentation

Red Hat Linux includes thousands of pages of online documentation to help you learn how to use the system. The man pages, info documents, and plain text files included provide information on almost every aspect of Linux. For more help, Red Hat also includes all of the documentation produced by the Linux Documentation Project electronically.

# ## 6.1 On Line Help

When you are looking for general help on commands and error messages, the best place to start is right on your system.

# ### 6.1.1 Man Pages

Most every command on your system has an associated “man” page. This is documentation that you can get to instantly should you have questions or problems. If you were having trouble with the command `ls`, you could enter `man 1s`. This will bring up the man page for `1s`. The man page is viewed through the `less` program, so all of the options to `less` will work while in a man page. Some important key strokes are:

+   * `q` to quit
