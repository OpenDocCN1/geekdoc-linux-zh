# 2.4.20 Finishing Up ... or Starting Up

After you have completed LILO installation, the installation program will reboot your system. Please don't forget to remove the installation floppy from the diskette drive.

At the boot: prompt, press Enter and watch your Red Hat Linux system boot. When it presents the login: prompt, enter root; at the Password: prompt, type the root password you set for your machine in Section 2.4.18.
