Next within the structure follows some information about the described rule: the priority value u32 r_preference, the unsigned char r_table identifier for a routing table to be used, and the field unsigned char r_action, which specifies the action that should run if the rule's mask matches the packet coming processed. The five rule types mentioned in Section 16.1.6 can be coded with the RTN_UNICAST, RTN_BLACKHOLE, RTN_UNREACHABLE, RTN_PROHIBIT, and RTN_NAT, which are declared in include/linux/netlink.h. Additional attributes for the action are the u32 r_srcmap and u32 r_classid. The first of these two entries is the source address for static address translation. The second entry is present only if the kernel was configured with the CONFIG_NET_CLS_ROUTE option. (See Section 16.2.1.) It contains a class identifier for querying the discipline that is assigned to packets, the following routing entry we select later does not contain a class identifier.
The rule's selector is represented by an address prefix and a corresponding network mask for the packet's source and destination (u32 r_src, r_src_mask, r_dst, r_dstmask), by the network interface (int r_ifindex), by the content in the TOS field (u8 r_tos), and additionally by the framework (u32 r_fwmark). Moreover, the structure includes the lengths of the address prefixes (unsigned char r_src_len, r_dst_len) and the network interface name (char r_ifname[IFSIZ]). These attributes are used when rules are deleted, and displayed at the RT netlink interface.
