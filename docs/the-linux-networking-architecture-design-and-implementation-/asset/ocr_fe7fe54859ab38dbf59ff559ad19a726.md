Calling the NF_HOOK macro causes the routing code to pass the functions hooked into a netfilter hook. This macro is defined in <linux/netfilter.h> as follows:
#define NF_HOOK(pf, hook, skb, indev, outdev, ofkn) \\list_empty(&nf_hooks[pf])[(hook)]) ? nf_hook_slow(pf, (hook), skb, (indev), (outdev), ofkn)) The following fragment from ipv4_ip.c (at the end of the ip_build_and_send_pkt(pkt) function serves as an example of how we can use the NF_HOOK macro:
/* Sent out. */
return NF_HOOK(PF_INET, NF_IP_LOCAL_OUT, skb, NULL, rt->udest, output_may=reroute);
