Connection entries are managed in a hash table, where a linked list is used to re-solve collisions. An entry in this hash table is of the type ip conntrack_tuple_hash and contains a reverse pointer to the ip_conntrack structure of that connection. in addition to the actual address information (tuple) (i.e., source and destination address-) and protocol-specific information (e.g., port numbers). As is shown in Figure 20–2, this pointer is required to access the connection status or to check for whether the entry represents a tuple for the forward or reverse direction of a connection.
