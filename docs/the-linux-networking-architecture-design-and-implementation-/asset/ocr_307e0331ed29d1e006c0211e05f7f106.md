static int net_open(struct net_device *dev) {
    struct net_local *np = (struct net_local *)dev->priv;
    int ioaddr = dev->base_addr;
    /*
     * This is used if the interrupt line can turned off (shared).
     * See 3c53.c for an example of selecting the IRQ at config-time.
     */
    if (request_irq(dev->irq, &net_interrupt, 0, codname, dev)) {
        return -EAGAIN;
    }
    /*
     * Always allocate the DMA channel after the IRQ, and clean up on failure.
     */
    if (request_dma(dev->dma, codname)) {
        free_irq(dev->irq, dev);
        return -EAGAIN;
    }

MOD_INC_USE_COUNT;
    /*
     * Reset the hardware here. Don't forget to set the station address.
     */
    chipset_init(dev, 1);
    outb(0x00, ioaddr);
    np->open_time = jiffies;
    /*
     * We are now ready to accept transmit requests from
     * the queuing layer of the networking.
     */
    netif_start_queue(dev);
    return 0;
}

During deactivation of a network adapter, all operations done when the adapter was opened should be undone. This concerns mainly allocated system resources (interrupts, DMA channels, etc.), which should now be freed.

For modularized drivers, the user counter has to be decremented with MOD_DEC_USE_COUNT, and the network device must not accept any packets from higher layers (netif_stop_queue). Again, the return value is 0, if successful, or a negative error code.
