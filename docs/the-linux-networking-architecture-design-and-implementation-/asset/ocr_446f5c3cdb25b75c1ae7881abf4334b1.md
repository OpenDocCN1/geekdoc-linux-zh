# neigh_suspect() net/core/neighbour.c

The neigh->output() functions are changed to neigh->ops->output(). This means that, if the fast way over the hardware header cache previously used it is no longer used now, so, when the next packet is to be sent, a probe for the MAC address will be started (neighbor solicitation by neigh_resolve_output()).

# neigh_destroy() net/core/neighbour.c

A neighbour entry is deleted from the ARP cache, and its resources are released. Entries in the header cache are also released, neigh_release() invokes neigh_destroy(). It first checks for whether there are still pointers to this neighbour (if atomic_dec_and_test(&neigh->refcnt)) and for whether the entry has already been marked as unused (if neigh->dead). Both conditions must be true before the neighbour may be deleted.

# neigh_sync() net/core/neighbour.c

This function has no effect for permanent neighbour entries (NUD_PERMANENT) or for network devices without ARP support (NUD_NOARP), and it returns immediately. Otherwise, the following actions are taken, depending on the entry's state:

+   NUD_REACHABLE: If an entry is in this state and a certain time (neigh->reachable_time) has expired since the last acknowledgement was received from the neighbouring computer, either by an incoming packet or an explicit ARP request or ARP reply, then the entry is marked as NUD_STALE. This means that no sign of life has come from this computer over a period of time and so probably no longer exists. The function neigh_suspect() is used to verify this situation; it tries to update that computer's state.

+   NUD_VALID: If the computer is known and an acknowledgement has arrived before the normal lifetime of the entry (neigh->reachable_time) expires, then its state is set to NUD_REACHABLE, and neigh_connect(neigh) is invoked.

neigh_sync() is invoked by neigh_update() before the new state is entered in the neighbour structure. The intention is to ensure that the current state is updated before state transitions occur.

# neigh_periodic_timer() net/core/neighbour.c

This function initializes a timer for each neighbour cache. This timer periodically checks and updates the states of cache entries (i.e., it runs a so-called garbage collection).
