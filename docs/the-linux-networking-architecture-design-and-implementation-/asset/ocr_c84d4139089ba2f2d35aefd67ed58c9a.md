int (*dolt)(struct sk_buff*, struct nmsghdr*, void *attr);\nint (*dumpit)(struct sk_buff*, struct netlink_callback *cb);

An appropriate function can be allocated to each function pointer. The function dolt() passes a command; the function dumpit() is used to read an existing configuration. For example, the following allocation is done for traffic control (net/sched/sch_api.c), among other things:

```
link_p[RTM_GETQDIS-RTM_BASE].dolt = tc_get_qdisc;
link_p[RTM_GETQDIS-RTM_BASE].dumpit = tc_dump_qdisc
```

As was mentioned earlier, the function rtnetlink_rcv() is used as an input() function. It invokes the function rtnetlink_rcv_skb() for each skb. The latter function uses the function rtnetlink_rcv_msg() (all in net/core/rtnetlink.c) to discover the type of a Netlink message and the family of the RT Netlink message and eventually invokes either dolt() or dumpit().
