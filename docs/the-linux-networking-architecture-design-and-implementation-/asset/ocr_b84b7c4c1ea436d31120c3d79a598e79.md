# 5.2 Managing Network Devices

To manipulate the flag, we use the method dev_change_flags(dev, flags), which also causes the method dev_open(dev) to be called when the IFF_UP flag is set.

```
dev_open() net/core/dev.c
```

The function dev_open(dev) opens a network device (i.e., the network device is activated and can be used). If the network device is already active (IFF_UP), or if it has not been registered ((netif_device_present(dev)), then the function returns an error message.

The actual initialization (i.e., the device-specific functions) is executed by the open() function of the network driver, if it exists. If this initialization is successful (i.e., no error occurred), then the net_dev device specific states are as follows:

+   - dev->flags assumes the state IFF_UP.
- dev->state is set to LINK_START_START.

The multicast state is activated by dev_mc_upload().
The queue and the scheduler of the network device are activated (dev_activate(dev)). At the same time, the method dev_watchdog(dev) starts the timer to detect transmission problems. (See Section 5.3.4). The timer calls the method dev_watchdog() every dev->watchdog_timeout ticks to check that the network adapter works properly.

The notification chain netdev_chain is informed about the event NETDEV_UP.

**Deactivating a Network Device** When we use the ifconfig name down to deactivate a network device, the method dev_change_flags(dev, flags) in the variable dev->flags deletes the IFF_UP flag. The general part of transferring the network device into the inactive state is done by dev_close(). The adapter-specific actions are executed in the driver method dev->stop().

```
dev_close() net/core/dev.c
```

If the network device dev is in the IFF_UP state, then it is deactivated by dev_close(dev) in the following steps:

+   - All methods in the notification chain netdev_chain are informed about thecoming of the network device (NETDEV_GOING_DOWN) and can act accordingly.
- Next, dev_deactivate(dev) removes the packet scheduler dev->qdisc, and the LINK_STATE_START bit is deleted in dev->state. In addition, dev_watchdog_down() stops the timer used to detect transmission problems.

The driver function dev->stop() deactivates the network adapter.
