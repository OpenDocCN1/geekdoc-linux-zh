# 14.3.2 Configuration

User Access Each Linux user can use the traceroute command to track an IP packet on its way across the Internet to the destination node. This might suggest that the Record IP packet option is used in this case. Actually, this is not so: the traceroute uses another method, for several reasons:

+   Formerly, not all routers supported the Record Route packet option, which means that they wouldn't have been available for use.
- Record Route is normally intended for one-way only—the receiver has to return an echo of the IP packet to the sender. This means that the recorded addresses would be duplicated.
- However, the main reason is lack of space: A maximum of nine IP addresses fits into the address list of the Option field. Formerly, this might have been sufficient, but today the average number of intermediate systems for a connection across the Internet is much higher.

For these reasons, traceroute uses the Internet Control Message Protocol (ICMP), see Section 14.4) and the Time-to-Live (TTL) field of the IP header, which stores the running lifetime of the packet. It sends ICMP packets with the same destination address and increments the value in the TTL field at each step. The first packet gets a lifetime of one (i.e., the first Internet node returns an ICMP message to the sender as soon as it receives the packet). The sender sends an ICMP message also each of the next servers, so that it can follow the path to the destination address. However, a trick has to be used at the destination address, because the receiver looks at the lifetime only if the packet is not delivered locally. For this purpose, the UDP port number is set to a meaningless value to cause the receiver to receive the ICMP message Port Unreachable.

Notice, however, that this method only works because all IP packets from a sender normally take the same path through the receiver in most cases. It was actually intended to let a user run the traceroute command to access the packet option Strict Source Routing or Loose Source Routing.
