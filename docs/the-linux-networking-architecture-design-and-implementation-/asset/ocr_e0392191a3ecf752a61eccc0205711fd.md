NUD_NONE: This entry is invalid. A neighbor is normally in this state only temporarily. New entries for the ARP cache are created by the neigh_alloc() function, but this state is changed immediately.

NUD_NOARP, NUD_PERMANENT: No address resolution is done for entries in these two states. NUD_NOARP are neighbors that do not require address resolution (e.g., PPP). Entries with the NUD_PERMANENT state are permanently set by the administrator and are not deleted by the garbage collection.

NUD_INCOMPLETE: This state means there is no address mapping for this neighbor yet, but that it is being processed. This means an ARP request has been sent, and the protocol is waiting for a reply.

NUD_REACHABLE: neighbour structures in this state are reachable with the fastest output() function (neigh_ops->connected_output()). An ARP reply from this neighbor was received, and its maximum age is neigh->parms->reachable_time units. This interval is restarted when a normal data packet is received.

NUD_STALE: This state occurs when an entry has been reachable, but reachable_time times have expired. For this reason, it is no longer certain that the neighbouring computer can be reached with the address mapping currently stored. For this reason, rather than using connected_output() to send packets to this neighbour, the slower neigh_ops->output() is used.

NUD_DELAY: If a packet needs to be sent to a station in the NUD_STALE state, then the NUD_DELAY state is set. It is between the NUD_STALE and NUD_PROBE states only temporarily. Of course, if the address mapping is confirmed once again, the entry changes to the NUD_REACHABLE state.

NUD_PROBE: The entry in the ARP cache is in the probing phase: Consecutive ARP request packets are sent in an attempt to obtain the layer-2 address of this computer.

NUD_FAILED: The address mapping cannot be resolved for entries in this state. ARP tries to solve the problem by sending neigh_max_probes request packets. If it still doesn't get replies to these packets, the state of the neighbour entry is set to NUD_FAILED. Subsequently, the garbage collection deletes all entries in this state from the ARP cache.

To understand this better, we summarize three additional state combinations

NUD_TIMER = (NUD_INCOMPLETE | NUD_DELAY | NUD_PROBE): An attempt is currently being made to resolve the address.

NUD_VALID = (NUD_PERMANENT | NUD_NOARP | NUD_REACHABLE | NUD_PROBE | NUD_STALE | NUD_DELAY): The neighbour entry includes an address mapping, which has been validated.

NUD_CONNECTED = (NUD_PERMANENT | NUD_NOARP | NUD_REACHABLE): The neighbour entry is valid and the neighboring computer can be reached.
