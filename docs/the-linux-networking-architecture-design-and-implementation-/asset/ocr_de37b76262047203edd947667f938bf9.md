In addition to its number, tb_id, and an unused element by the name of
tb_stamp, the fib_table structure includes a number of function pointers, forming
the interface to manage the entries stored in the table:

+   * tb_insert() and tb_delete() serve to insert and delete entries; they are used
  in net/ipv4/fib_frontend.c to handle RT netlink messages and ioctl() and
  kernel-internal calls.
* tb_dump() serves to output entries over RT netlink, and tb_get_info() serves
  to output entries in the /proc/net/route format.
