## Chapter 23 IPv6—Internet Protocol

The Internet Protocol version 6 (IPv6) is a communication protocol designed to replace version 4 of the Internet Protocol (IPv4). ### Fragmentation Fragmentation

Fragmentation is the process of breaking down large packets into smaller fragments. In IPv6, fragmentation is performed by the source node rather than by routers. This reduces the processing load on routers.

A simple example will help us better understand how fragmentation in IPv6 works. Assume that an IPv6 packet consists of a nonfragmentable part and a fragmentable part. The implementation of IPv6 in the Linux kernel is in the net/ipv6 directory and in the header file <net/ipv6.h>.
