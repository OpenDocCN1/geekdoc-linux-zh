```
neigh_table_init() net/core/neighbour.c
```

neigh_table_init() takes the following steps to initialize a new neigh_table structure:
- It obtains memory for the neighbour cache (tbl->kmem_cache = kmmem_cache_create()).
- It initializes a timer (tbl->gc_timer()) and sets the expiry time to now + tbl->gc_interval + tbl->reachable_time. This timer calls neigh_periodic_timer() periodically.
- It inserts the new table into a singly linked list, neigh_tables.

```
arp_hash() net/ipv4/arp.c
```

The arp_tab1() function uses this function as a method for computing the hash function. The hash value is computed on the basis of the IP address (primary_key), using modulo NEIGH_HASHMASK (ARP table size).
