
## 24.5 Timer Management in TCP

The retransmit timer determines when packets have to be retransmitted during a data transmission phase. This value depends on the round-trip time and normally is within the range from 200 ms to two minutes. This timer is also used during the establishment of a connection. It is initialized to three seconds. Upon expiry of this timer, the backoff mechanism is used.

- Delayed ACK timer This timer delays the transmission of ACK packets. The value is smaller than 200 ms.
- Keepalive timer This timer is used to test whether a connection is still up. It is invoked for the first time after nine hours. Subsequently, new probes are sent every five seconds. If all probes fail, the connection is reset.
- Probe timer This timer is used for a defined interval, to see whether zero window still applies. The value depends on the round-trip time.
- FinWait2 timer The expiry of this timer switches the connection from FIN_WAIT2 into CLOSED state if no FIN packet arrives.
- TW1 timer This timer manages the interval in TIME_WAIT state. The value is twice the maximum lifecycle, which is 60 seconds.

## 24.5.2 Functions

This section introduces all general timer functions.

```
tcp_init_timers() net/ipv4/tcp.c
```
`tcp_init_timers(sk)` initializes the set of various timers. The timer_list structures are hooked, and the function pointers are converted to the respective behavior functions. 

```
tcp_reset_xmit_timer() include/net/tcp.h
```
The function `tcp_reset_xmit_timer(sk, what, when)` sets the timer specified in the time (i.e., to jiffies + when).

```
tcp_clear_xmit_timer() include/net/tcp.h
```
The function `tcp_clear_xmit_timer(sk)` removes all timers set for a connection from the timer_list structures.

- SYNACK Timer The actions of the SYNACK timer are implemented in the function `tcp_synack_timer(sk)` (linux/tcp.c). This timer walks through list of connections with unacknowledged SYNACK packets and deletes all connections for which the timeout min((TCP_TIMEOUT_INIT << retrans), RTO_MAX) has expired. Subsequently, the keepalive timer is started for a new connection and initialized by TCP_SYN_INTERVAL.

There are various functions to manage the keepalive timer:

```
tcp_delete_keepalive_timer() net/ipv4/tcp_timer.c
```
The function `tcp_keepalive_timer(sk)` removes the keepalive timer from the list of timer_list structures.

```
tcp_reset_keepalive_timer() net/ipv4/tcp_timer.c
```
The function `tcp_reset_keepalive_timer(sk, len)` sets the timer to jiffies + len.

```
tcp_keepalive_timer() net/ipv4/tcp_timer.c
```
The function `tcp_keepalive_timer(data)` is the behavior function for the keepalive timer. When this function is invoked, the state of the connection is checked to decide whether this connection should be terminated. This function implements various timers. In addition to the SYNACK timer described here, it implements the timeout in the FIN_WAIT2 state and the actual keepalive timer.

**Retransmit Timer** The client's TCP instance sends a SYN packet to the server and waits for an answer (with SYN and ACK) while the connection-establishment phase is active. At the same time, `tcp_connect()` (in net/ipv4/tcp_output.c) and the function `tcp_reset_xmit_timer(sk, TCP_TIME_RETRANS, tp->rto)` are used to set the retransmit timer to the value TCP_TIMEOUT_INIT. TCP_TIMEOUT_INIT is set to the value 3*HZ in the file include/net.h.

The retransmit timer is also used when the connection is established and running. The duration of the retransmission timeout is doubled in the `tcp_retransmit_timer()` function (net/ipv4/tcp_timer.c), upon each retransmission, until it has arrived at the maximum and the connection is reset:

```
tp->rto = min(tp->rto, RTO_MAX);
    tcp_reset_xmit_timer(sk, TCP_TIME_RETRANS, tp->rto);
    if (tp->retransmits > sysctl_tcp_retransries)
        sk_dst_reset(sk);
```

The retransmit timer is initialized to the retransmission timeout (RTO), which is recalculated by use of various helper functions:

```
tcp_set_rto() net/ipv4/tcp_input.c
```
This function computes the RTO (retransmission timeout) from the round-trip time values.
