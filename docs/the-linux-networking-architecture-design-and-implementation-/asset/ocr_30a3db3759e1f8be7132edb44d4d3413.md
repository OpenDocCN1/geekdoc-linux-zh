unresolved is a queue for socket buffers that stores packets for this routing until the multicast routing daemon has selected a route.

expires the time by which the daemon should have selected a route.

res is used in the mfc union when the multicast routing daemon has specified the routes for this entry.

minvf and maxvif are indices to elements in the ttl1 list of the MFC entry. They limit the range currently used by virtual network devices which are used to send packets of this MFC entry. Stating this index saves computing time required to duplicate multicast packets. The maxvif index is limited by the MAXIFS constant.

ttl1 is an array with MAXVIFS entries where each entry specifies whether a packet should be forwarded over the virtual network device in the vif_table list with the corresponding index. This is the case when a value less 255 exists. The value 0 cannot occur, because it is mapped to the value 255 when the table is built. However, an entry less 255 is not sufficient for forward packet; the TTL value of a packet has to be at least equal to the TTL value in the ttl1 array. The method used to create the threshold value for multicast packets is described in Section 17.2.3.
