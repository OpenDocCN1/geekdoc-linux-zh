A neighbour represents a computer that is reachable over layer-2 services (i.e., directly over the LAN). Using the neighbour interface and the available functions, you can implement special properties of either of the two protocols (ARP and Neighbour Discovery). The following sections introduce the neighbour interface and describes the ARP functions. Chapter 23 describes how Neighbour Discovery is implemented.
