**Timer Handling** Each bridge has a function, br_tick(), to handle timers. This section describes the five defined timers. To implement them, only one timer of the type timer_list is used. This is the variable in each net_bridge structure.

The timer is invoked every second (expires = jiffies + H) This causes the function br_tick to be invoked each time. This function defines the behavior of the timers in the following list. Whether a timer is expired for each timer (br_check_timers()). In addition, the timers are incremented. The appropriate behavior is invoked as soon as a timer expires.

**Hold timer:** The hold timer starts after the configuration BPDU has been sent. When it is active, no configuration BPDU can be sent over the same port.

**GC timer:** The garbage collection timer is used to clean up entries in the FDB.

**Hello timer:** The hello timer is used to send hello packets (BPDUs) at regular intervals.

**TCN timer:** The TCN timer is used once a TCN BPDU has been sent.

**Topology-change timer:** The topology-change timer is used exclusively by the root bridge.

**Forward-delay timer:** The forward-delay timer is used to move the ports of a bridge from the blocking to the forwarding state.
