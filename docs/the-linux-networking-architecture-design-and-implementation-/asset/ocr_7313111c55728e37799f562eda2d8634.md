# 21.4.2 Helper Modules

name is a character string containing the name of the protocol.

proton is the protocol number that will be entered in the IP header. A list of
protocol numbers is normally available in the /etc/protocols file.

manip_pkt is a pointer to a function invoked by the manip_pkt function of the
NAT module to manipulate the protocol-specific part of a packet according to the
manip parameter. (See Section 21.3.5).

in_range is a pointer to a function that checks for whether the protocol-specific
part of an address (e.g., the TCP ip) is within the specified interval [min,max].
Whether the source or destination address will have to be checked is of
value of the maniype parameter (IP_NAT_MANIP_SRC or IP_NAT_MANIP_DST). The
function returns 1 if the condition is met, otherwise 0.

unique_tuple is a pointer to the module's "core function". It is invoked by
unique_tuple() (see Section 21.3.4) to obtain a tuple by altering the
protocol-specific part. The value of the maniype shows whether the source or desti-
n address should change; the respective protocol-specific part of tuple is set to
the value of the original tuple.

The protocol-specific part generally is altered by a simple scheme (e.g.,
by incrementing the port number for TCP). Subsequently, the function
ip_nat_used_tuple() is used to see whether the new address is still free. If so, the flag
IP_NAT_PROTO_SPECIFIED is set, then range also contains information about
t range in which the protocol-specific part of the tuple should be. Naturally, this in-
formation has to be taken into account.

The two functions, print() and print_range(), are invoked when the
protocol-specific information in match and mask should be output in text
form. This information text should be written to the buffer, and the number of
output characters should be returned. For example, tcp would invoke this function to
out the port numbers.

A helper is a function invoked by the NAT module from within the do_bindings()
function, once an address binding has been added (see Section 21.3.5). This us to
verify the payload of a packet and to modify address transmitted in that packet—for
example, to detect PORT commands over an FTP control connection. (See Section
21.1.7.) A helper module is registered by ip_nat_helper_register(), and the only
parameter it takes is a data structure of the type ip_nat_helper.
