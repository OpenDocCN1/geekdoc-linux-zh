FIGURE 22-4
The bhvr_type and bhvr structures manage components and their instances.

Figure 22–4 shows how components and their instances interact. The bhvr_type structure of the token bucket stores general component information.

```
struct bhvr_type {
  char name[STRLEN];
  unsigned int bhvr_class_id;
  unsigned long private_data_size;
  unsigned int instances;
  struct bhvr_type *next;
  int (*func)(struct bhvr *, struct sk_buff);
  struct sk_buff** (*deq_func)(struct bhvr);
  int (*constructor)(struct bhvr *bhvr, char *data, int flag);
  int (*destructor)(struct bhvr);
  int (*get_bhvr)(struct bhvr *bhvr, char *port);
```
