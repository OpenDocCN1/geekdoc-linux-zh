# 17.6 MULTICAST TRANSPORT PROTOCOLS

So far, we have actually discussed only unreliable and connectionless multicast transmissions based on UDP. This type of transmission is the most frequently used application multicast, mainly because it is much easier to handle. Nevertheless, there are application cases for connection-oriented and reliable multicast communication, and so extensive research is undertaken in this field.

Because the tasks involved in the reliable and connection-oriented transmission of multicast data correspond mainly to the tasks of a transport protocol and these work on on top of the IP multicast, a layer-3 service, the protocols developed so far are normally called multicast transport protocols. The most important tasks of a transport protocol, including connection management, flow control, error correction, and congestion control, are relatively complex and expensive for unicast communication, and point-to-multoint communication adds special problems to this situation. For example, consider the sender imputation problem, which occurs when many receivers return acknowledements for received data packets to the sender, overloading the sender with an enormous volume.
