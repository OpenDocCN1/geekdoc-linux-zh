The initialized bit vector specifies whether the address binding for the source-address (bit 0) or the destination address (bit 1), or both, was initialized.
The num_maps field specifies the number of executable manipulations stored in
the manips vector. Manipulations are counted separately at different hooks and for-ferent directions. Each of these manipulations is represented by a structure of the type
ip_nat_info_manip.
The bysource and byipsproto fields include hash values used to sort the struct-ture in the two hash tables described below, and helper is a pointer to an optional
helper module. (See Section 21.4.2.)
