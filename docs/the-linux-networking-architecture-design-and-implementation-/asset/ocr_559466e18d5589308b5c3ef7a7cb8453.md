Once we are sure that the network adapter is searched for in the basic address ioaddr, this address is stored in the net_dev structure (dev->base_addr), and the network device is initialized. The I/O ports, starting from the base address, are reserved by request_region(ioaddr, IO_NUM, cardname) and at the end of the initialization function to ensure that no other initialization method can get access to it.

The initialization process can be divided into the following phases:

+   * If the network adapter does not support dynamic interrupt allocation, then the interrupt set by jumpers on the network adapter should be determined and reserved at this point. The kernel searches for the interrupt number. Calling the method autoirq_setup() makes the kernel remember interrupt lines currently registered in a variable. Subsequently, the network adapter should be caused to trigger an interrupt. We can then use the method autoirq_report() to discover, from the previously stated and the actual interrupt vectors, which interrupt was active. Next, the interrupt found is reserved for the network adapter by the method request_irq(). In addition, the DMA channel is determined and reserved by request_dma().

+   * For modern adapters that do not require specific interrupt or DMA lines, the two system resources are not allocated at this point, but rather when the device is opened. This is necessary to avoid conflicts with other devices.

+   * Once system resources have been allocated (for older adapters only), memory is reserved for the private data structure of the network device dev->priv and initialized. This data structure stores the private data of the network driver and statistic statistic information collected during the operation of the network device (net_dev_stats structure).

+   * Finally, the references to driver-specific methods are set in the net_dev structure, so they can be used by the higher layers and protocols. The adapter-specific methods (see also Section 5.1.1) have to be explicitly set. Methods specific to the MAC protocol used (e.g., Ethernet) can be set by special methods (e.g., ether_setup()).

If the network adapter was found and all data structures were initialized correctly, then dev->init() returns 0.
