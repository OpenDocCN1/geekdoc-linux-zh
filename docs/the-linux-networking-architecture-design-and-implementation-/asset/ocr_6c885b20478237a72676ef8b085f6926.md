# String Operations

The Linux kernel has several functions for simple (and familiar) work with
strings. These functions are similar to the string operations of the C library. We will
briefly introduce them here:

# Copying strings

```
strcpy(dest, src) copies the string src, including the closing null byte, to
t address dest. strcpy() returns the dest pointer.
string(dest, src, count) copies a maximum count of bytes from the
src to the address dest. If the original string was longer than count
bytes, then no null byte is appended. dest is also returned here.
```
