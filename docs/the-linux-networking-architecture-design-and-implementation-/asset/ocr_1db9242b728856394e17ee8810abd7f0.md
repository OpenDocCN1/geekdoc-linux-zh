# 26.3 Protocol-Specific Sockets

```
inet_create() net/ipv4/inet.c
```

As has been mentioned, this function is invoked by the function socket_create() to initialize the socket structure. Initially, the state of the BSD socket is set to SS_UNCONNECTED, and then the function sk_alloc(), which is described in Chapter 4, allocates a socket structure. The protocol family can only be PF_INET at this point, but we still have to distinguish between type and protocol. This is now done by comparing against the information in a list, struct inet_protosw inetsw_array, which is created by inet_register_protosw() (net/ipv4/inet.c) when the kernel starts.

Next, the ops of the BSD socket structure are filled. The sk pointer connects the BSD socket to the new socket structure, and the latter is connected to the BSD socket by the ops pointer. (See sock_init_data() in net/core/sock.c.) Similarly to the proto_ops structure, the proto structure supplies the functions of the lower-layer protocols:

```
struct proto {
void (*close) (...);
int (*connect) (...);
int (*disconnect) (...);
struct sock* (*accept) (...);
int (*ioctl) (...);
int (*init) (...);
int (*destroy) (...);
void (*shutdown) (...);
int (*setsockopt) (...);
int (*getsockopt) (...);
int (*sendmsg) (...);
int (*recvmsg) (...);
int (*bind) (...);
int (*backlog_rcv) (...);
void (*hash) (...);
void (*unhash) (...);
int (*get_port) (...);
char name[32];
struct {
int use;
nu8 _pad[SMP_CACHE_BYTES - sizeof(int)];
} stats[NR_CPUS];
};
```

Consequently, the proto structure represents the interface from the socket layer to the transport protocols. The hash() and unhash() functions serve to position or find a socket structure in a hash table.

Finally, inet_create() invokes the inet() function for the identified protocol from the proto structure, if it exists. For example, this would be the function tcp_v4_init_sock() (net/ipv4/tcp_ipv4.c) in TCP. A similar function exists in net/ipv4.c for direct access to IP (SOCK_RAW). The other protocol functions are now available over the socket structure in these init() functions.
