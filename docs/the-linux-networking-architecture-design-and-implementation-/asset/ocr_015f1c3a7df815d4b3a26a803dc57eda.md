The structure atm_trafprm (also from include/linux/atm.h) is used to specify traffic parameters for the ATM connection. This structure includes the following:

```
struct atm_trafprm {
    unsigned char traffic_class; /* traffic class (ATM_UBR, ...) */
    int max_pcr;                  /* maximum PCR in cells per second */
    int pcr;                      /* desired PCR in cells per second */
    int min_pcr;                  /* minimum PCR in cells per second */
    int max_cdv;                  /* maximum CDR in microseconds */
    int max_sdu;                  /* maximum SDU in bytes */
};
```

> * A number of parameters for the ABR service class follows here.

The parameter traffic_class can take the following values, which are defined in include/linux/atm.h: ATM_NONE (no traffic class specified), ATM_UBR (Unspecified Bit Rate), ATM_CBR (Constant Bit Rate), ATM_VBR (VBR—Variable Bit Rate), ATM_ABR (ABR—Available Bit Rate), and ATM_any (any traffic class).

The function atm_setsockopt() is used to run a few checks on the socket status. Subsequently, the function check_qos() is invoked.

```
check_qos() // net/common.c
```

This function merely checks on whether the parameters of the transmit and receive directions are identical or specified for one direction only (different parameters are currently not supported); subsequently, the function check_tp() is invoked.

```
check_tp() // net/common.c
```

This function is used to check few combinations of QoS with regard to their admissibility. If these checks run successfully, then the function atm_do_setsockopt() invokes the function atm_change_qos(), which uses the function adjust_tp() to run further checks.
