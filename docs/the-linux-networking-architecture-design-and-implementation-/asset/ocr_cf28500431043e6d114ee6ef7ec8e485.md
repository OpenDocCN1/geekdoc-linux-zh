The two different types serve to distinguish between two phases within PPPoE: the discovery stage, and the session stage. A typical discovery stage consists consists of four steps, which appear as follows (Figure 9–2): The host sends a PADI (PPPoE Active Discovery Initiation) packet to the Ethernet broadcast address to find out which access concentrators are available in the Ethernet.
