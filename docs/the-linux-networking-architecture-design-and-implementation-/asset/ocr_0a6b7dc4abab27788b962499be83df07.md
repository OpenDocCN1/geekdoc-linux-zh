# C.3 Using netstat to View the Network State

G: The next hop is a router (gateway). This means that the packet is sent with the router's MAC address.

U shows that the network device is enabled (UP).

H: The next hop is an end system, addressed directly by its MAC address in the MAC layer.

The last column shows the interface for a route.

**Viewing Interface Statistics** We can start netstat -i to output current statistics about active network devices. This option can be used together with the option -a to show inactive network devices in addition to active network devices. The output from netstat -i looks like out of the ifconfig command and uses the same parameters.

**Active Connections andockets** netstat supports many of options we can use to list active and passive sockets. The arguments -t, -u, -w, and -x show TCP, UDP, RAW, and UNIX sockets. We can additionally use the option -a to list all sockets currently waiting for incoming connection. This connects all server sockets.


This example of a netstat -ta output shows that most sockets either are in the LISTEN state (waiting for incoming) or already have any TCP connection (ESTABLISHED). Previously closed connections remain in the TIME_WAIT state for a little before the sockets are deleted and can be reused. (See Chapter 2.4).
