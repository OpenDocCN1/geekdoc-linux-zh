# OPTIONS

+   - -h, -?
+   
+       Prints a short usage ssage.
+   
+   - -v
+   
+       Verbose output. If used once, **sane-find-scanner** shows every device na and the test result. If used twice, SCSI inquiry information and the USB device descriptors are also printed.
+   
+   - -q
+   
+       Be quiet. Print only the devices, no comnts.
+   
+   - -p
+   
+       Probe paralled port scanners.
+   
+   - -f
+   
+       Force opening all explicitly given devices as SCSI and USB devices. That’s useful if **sane-find-scanner** is wrong in determining the device type.
+   
+   - -F filena
+   
+       filena is a file that contains USB descriptors in the format of /proc/bus/usb/devices as used by Linux. **sane-find-scanner** tries to identify the chipset(s) of all USB scanners found in such a file. This option is useful for developers when the output of “cat /proc/bus/usb/devices” is available but the scanner itself isn’t.
+   
+   - **devna**
+   
+       Test device file “devna”. No other devices are checked if devna is given.
