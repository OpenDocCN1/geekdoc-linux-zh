# ## MERGE-FILE FILTER RULES

You can rge whole files into your filter rules by specifying either a rge (.) or a dir-rge (:) filter rule (as introduced in the FILTER RULES section above).

There are two kinds of rged files — single-instance (‘.’) and per-directory (‘:’). A single-instance rge file is read one ti, and its rules are incorporated into the filter list in the place of the “.” rule. For per-directory rge files, rsync will scan every directory that it traverses for the nad file, ringing its contents when the file exists into the current list of inherited rules. These per-directory rule files st be created on the sending side because it is the sending side that is being scanned for the available files to transfer. These rule files may also need to be transferred to the receiving side if you want them to affect what files don’t get deleted (see PER-DIRECTORY RULES AND DELETE below).

inherited-per-dir-excludes
