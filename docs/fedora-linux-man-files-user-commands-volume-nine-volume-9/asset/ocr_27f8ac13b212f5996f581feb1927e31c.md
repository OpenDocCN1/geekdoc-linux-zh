-U|—user=usera[%password]  

Sets the SMB userns or userns and password.
If %password is not specified, the user will be prompted. The client will first check the **USER** environnt variable, then the **LOGNAME** variable and if either exists, the string is uppercased. If these environmental variables are not found, the userns **GUEST** is used.

A third option is to use a credentials file which contains the plaintext of the userns and password. This option is mainly provided for scripts where the admin does not wish to pass the credentials on the command line or via environnt variables. If this thod is used, make certain that the permissions on the file restrict access from unwatant users. See the -A for more details.

Be cautious about including passwords in scripts. Also, on many systems the command line of a running process may be seen via the `ps` command. To be safe always allow rpdclient to prompt for a password and type it in directly.

-S|—signing on|off|required

Set the client signing state.

-P|—machine-pass

Use stored machine account password.

-e|—encrypt

This command line parater requires the remote server support the UNIX extensions or that the SMB3 protocol has been selected. Requests that the connection be encrypted. Negotiates SMB encryption using either SMB3 or POSIX extensions via GSSAPI. Uses the given credentials for the encryption negotiation (either kerberos or NTLmv1/v2 if given domain/userns/password triple. Fails the connection if encryption cannot be negotiated.

—pw-nt-hash

The supplied password is the NT hash.

-n|—netbiosna <primary NetBIOS na>

This option allows you to override the NetBIOS na that Saa uses for itself. This is identical to setting the **netbios nam[]** parater in the s.conf file. However, a command line setting will take precedence over settings in s.conf.
