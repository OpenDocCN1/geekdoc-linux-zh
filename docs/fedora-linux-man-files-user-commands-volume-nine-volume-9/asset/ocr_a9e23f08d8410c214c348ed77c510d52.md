+   - **-w, --no-wrap** Do not wrap the line if the device na is too long. This can be useful when parsing the output of (1) by a script.

+   - **--show-mntpoint** Show also mount point as a filesystem identification.

+   - **--hide-device** Do not show device na in a filesystem identification.

Specifying both **-g** and **-u** displays both the user quotas and the group quotas (for the user).

Only the super-user may use the **-u** flag and the optional **user** argument to view the limits of other users. Non-super-users can use the the **-g** flag and optional **group** argument to view only the limits of groups of which they are ers.

The **-q** flag takes precedence over the **-v** flag.
