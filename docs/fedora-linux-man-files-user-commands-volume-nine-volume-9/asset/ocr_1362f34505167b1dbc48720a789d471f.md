# help [command]

See the ? command above.

# history

Displays the command history.

# iosize <bytes>

When sending or receiving files, sclent uses an internal buffer sized by the maximuiner of allowed requests to the connected server. This command allows this size to be set to any range between 0 (which ans use the default server controlled size) bytes and 16776960 (0xFFFF00) bytes. Using the server controlled size is the most efficient as sclent will pipeline as many siltaneous reads or writes needed to keep the server as busy as possible. Setting this to any other size will slow down the transfer.

# lcd [directory na]

If directory na is specified, the current working directory on the local machine will be changed to the directory specified. This operation will fail if for any reason the specified directory is inaccessible.

If no directory na is specified, the na of the current working directory on the local machine will be reported.

# link target linkna

This command depends on the server supporting the CIFS UNIX extensions and will fail if the server does not. The client requests that the server create a hard link between the linkna and target files. The linkna file st not exist.

# listconnect

Show the current connections held for DFS purposes.

# lock <filenum> <r|w> <hex-start> <hex-len>

This command depends on the server supporting the CIFS UNIX extensions and will fail if the server does not. Tries to set a POSIX fcntl lock of the given type on the given range. Used for internal Saa testing purposes.

# logon <userna> <password>

Establishes a new vuid for this session by logging on again. Replaces the current vuid. Prints out the new vuid. Used for internal Saa testing purposes.
