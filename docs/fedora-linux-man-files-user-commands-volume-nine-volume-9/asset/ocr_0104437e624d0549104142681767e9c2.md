# ## NOTES

Since process identifiers can be recycled, the caller should always use *pid*,*pid-start-ti* when using the **—process** option. The value of *pid-start-ti* can be determined by consulting e.g. the (5) file system depending on the operating system. If only *pid* is passed to the **—process** option, then **pkttyagent** will look up the start ti itself but note that this may be racy.
