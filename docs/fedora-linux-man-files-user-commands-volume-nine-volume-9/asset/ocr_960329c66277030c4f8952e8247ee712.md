and other (absoulte) paths to mount unit nas.

```
# systemctl status /dev/sda # systemctl status /ho
```

are equivalent to:

```
# systemctl status dev-sda.device # systemctl status ho.mount
```

In the second case, shell-style globs will be matched against currently loaded units; literal unit nas, with or without a suffix, will be treated as in the first case. This ans that literal unit nas always refer to exactly one unit, but globs may match zero units and this is not considered an error.

Glob patterns use (3), so normal shell-style globbing rules are used, and “*”, “?”, “[ ]” may be used. See (7) for more details. The patterns are matched against the nas of currently loaded units, and patterns which do not match anything are silently skipped. For example:

```
# systemctl stop sshd@*.service
```

will stop all instances.

For unit file commands, the specified NAME should be the full na of the unit file, or the absolute path to the unit file:

```
# systemctl enable foo.service
```

or

```
# systemctl link /path/to/foo.service
```
