# **DESCRIPTION**

**su** allows to run commands with a substitute user and group ID.

When called without arguments, **su** defaults to running an interactive shell as *root*.

For backward compatibility, **su** defaults to not change the current directory and to only set the environmtn variables **HOME** and **SHELL** (plus **USER** and **LOGNAME** if the target *user* is not *root*). It is recommended to always use the **--login** option (instead of its shortcut **-**) to avoid side effects caused by mixing environs.

This version of **su** uses PAM for authentication, account and session managment. So configuration options found in other **su** implementations, such as support for a wheel group, have to be configured via PAM.
