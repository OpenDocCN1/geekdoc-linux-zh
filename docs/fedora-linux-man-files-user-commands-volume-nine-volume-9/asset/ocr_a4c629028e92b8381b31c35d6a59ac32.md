print <file na>

Print the specified file from the local machine through a printable service on the server.

prompt

Toggle prompting for filenames during operation of the mget and mput commands. When toggled ON, the user will be prompted to confirm the transfer of each file during these commands. When toggled OFF, all specified files will be transferred without prompting.

put <local file na> [remote file na]

Copy the file called local file na from the machine running the client to the server. If specified, na the remote copy remote file na. Note that all transfers in sclient are binary. See also the lowercase command.

queue

Displays the print queue, showing the job id, na, size and current status.
