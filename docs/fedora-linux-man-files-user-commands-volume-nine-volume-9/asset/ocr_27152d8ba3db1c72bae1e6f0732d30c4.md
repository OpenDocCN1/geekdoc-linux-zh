# LIMITATIONS

Not every PostScript file can be encapsulated successfully, because there are restrictions on what PostScript constructs a correct encapsulated file may contain. **ps2epsi** does a little extra work to try to help encapsulation, and it automatically calculates the bounding box required for all encapsulated PostScript files, so most of the ti it does a pretty good job. There are certain to be cases, however, where the encapsulation does not work because of the content of the original PostScript file.
