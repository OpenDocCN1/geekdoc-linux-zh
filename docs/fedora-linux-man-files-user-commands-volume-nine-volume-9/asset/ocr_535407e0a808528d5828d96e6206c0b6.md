# OBSOLETE SORT KEYS

These keys are used by the BSD **O** option (when it is used for sorting). The GNU —`sort` option doesn't use these keys, but the specifiers described below in the STANDARD FORMAT SPECIFIERS section. Note that the values used in sorting are the internal values `ps` uses and not the "cooked" values used in so of the output format fields (e.g. sorting on tty will sort into device `nuer`, not according to the terminal `na` displayed). Pipe `ps` output into the `(1)` command if you want to sort the cooked values.

| KEY | LONG | DESCRIPTION |
|---|---|---|
| c | cmd | simple `na` of executable |
| C | pcpu | cpu utilization |
| f | flags | flags as in long format `F` field |
| g | pgpr | process group `ID` |
| G | pggid | controlling `tty` process group `ID` |
| j | cuti | culative user `ti` |
| J | csti | culative system `ti` |
| k | uti | user `ti` |
| m | min_flt | nuer of minor page faults |
| M | maj_flt | nuer of major page faults |
| n | cmin_flt | culative minor page faults |
| N | cmaj_flt | culative major page faults |
| o | session | session `ID` |
| p | pid | process `ID` |
| P | ppid | parent process `ID` |
| r | rss | resedent set size |
| R | resedent | resedent pages |
| s | size | `mory` size in kilobytes |
| S | share | amount of shared pages |
| t | tty | the device `nuer` of the controlling `tty` |
| T | start_ti | `ti` process was started |
| U | uid | user `ID` `nuer` |
| u | user | user `na` |
| v | vsi | total VM size in `KiB` |
| y | priority | kernel scheduling priority |
