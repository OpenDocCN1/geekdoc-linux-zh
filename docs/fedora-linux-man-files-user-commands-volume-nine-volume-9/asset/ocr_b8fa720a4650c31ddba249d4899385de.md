# ## AUTHOR

The original Saa software and related utilities were created by Andrew Tridgell. Saa is now developed by the Saa Team as an Open Source project similar to the way the Linux kernel is developed.

The original Saa man pages were written by Karl Auer. The man page sources were converted to YODL format (another excellent piece of Open Source software, available at and updated for the Saa 2.0 release by Jeremy Allison. The conversion to DocBook for Saa 2.2 was done by Gerald Carter. The conversion to DocBook XML 4.2 for Saa 3.0 was done by Alexander Bokovoy.
