The first match in the list is the one that is used. You should specify all your user mappings using a single —**usermap** option, and/or all your group mappings using a single —**groupmap** option. Note that the sender’s na for the 0 user and group are not transmitted to the receiver, so you should either match these values using a 0, or use the nas in effect on the receiving side (typically “root”). All other **FROM** nas match those in use on the sending side. All **TO** nas match those in use on the receiving side. Any IDs that do not have a na on the sending side are treated as having an empty na for the purpose of matching. This allows them to be matched via a “*” or using an empty na. For instance: - -usermap=:nobody  --groupmap=*:nobody
