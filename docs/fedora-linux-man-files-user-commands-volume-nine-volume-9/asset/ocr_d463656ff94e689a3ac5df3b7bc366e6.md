On each target host Rdist will attempt to run the command

```
rdistd -S
```

or

```
<rdistd path> -S
```

if the -p option was specified. If no -p option is included, or the <rdistd path> is a simple filena, rdistd or <rdistd path> st be sowhere in the $PATH of the user running rdist on the remote (target) host.
