# ⏵ BUGS

Source files st reside on the local host where rdist is executed.

Variable expansion only works for na lists; there should be a general macro facility.

Rdist aborts on files which have a negative mti (before Jan 1, 1970).

If a hardlinked file is listed more than once in the sa target, then rdist will report missing links. Only one instance of a link should be listed in each target.
