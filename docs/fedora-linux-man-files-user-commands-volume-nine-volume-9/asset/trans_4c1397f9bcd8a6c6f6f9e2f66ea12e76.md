
## 文件状态信息

文件的有效格式序列：

- %G
  属组名
- %h
  硬链接数
- %i
  inode 编号
- %m
  挂载点
- %n
  文件名
- %N
  带引号的文件名，如果是符号链接则解析
- %o
  最佳 I/O 传输大小提示
- %s
  总大小，单位为字节
- %t
  字符/块设备特殊文件的主要设备类型（十六进制）
- %T
  字符/块设备特殊文件的次要设备类型（十六进制）
- %u
  属主用户 ID
- %U
  属主用户名
- %w
  文件创建时间，人类可读格式；未知则为 -
- %W
  文件创建时间，自纪元起的秒数；未知则为 0
- %x
  最后访问时间，人类可读格式
- %X
  最后访问时间，自纪元起的秒数
- %y
  最后数据修改时间，人类可读格式
- %Y
  最后数据修改时间，自纪元起的秒数
- %z
  最后状态更改时间，人类可读格式
- %Z
  最后状态更改时间，自纪元起的秒数

## 文件系统状态信息

文件系统的有效格式序列：

- %a
  非超级用户可用的空闲块数
- %b
  文件系统中的总数据块数
- %c
  文件系统中的总文件节点数
- %d
  文件系统中的空闲文件节点数
- %f
  文件系统中的空闲块数
- %i
  文件系统 ID（十六进制）
- %l
  文件名的最大长度
- %n
  文件名
- %s
  块大小（用于加快传输）
- %S
  基本块大小（用于块计数）
- %t
  文件系统类型（十六进制）
- %T
  文件系统类型（人类可读形式）

注意：你的 shell 可能有自己的 stat 版本，通常它会取代此处描述的版本。关于其支持选项的详细信息，请参阅你的 shell 文档。

## STTY

### 名称

stty - 更改并打印终端行设置

### 用法

```
stty [-F DEVICE | --file=DEVICE] [SETTING]...
stty [-F DEVICE | --file=DEVICE] [-a|--all]
stty [-F DEVICE | --file=DEVICE] [-g|--save]
```

### 描述

打印或更改终端特性。
长选项的必需参数对短选项也是必需的。

- **-a, --all**
  以人类可读的形式打印所有当前设置
- **-g, --save**
  以 stty 可读的形式打印所有当前设置
- **-F, --file=DEVICE**
  打开并使用指定的设备 DEVICE，而不是标准输入
- **--help**
  显示此帮助并退出
- **--version**
  输出版本信息并退出

在 SETTING 前加可选的 - 表示取反。带 * 号的表示非 POSIX 设置。底层系统定义了哪些设置可用。

### 特殊字符：

- **discard CHAR**
  CHAR 将切换输出的丢弃
- **eof CHAR**
  CHAR 将发送文件结束信号（终止输入）
- **eol CHAR**
  CHAR 将结束当前行
- **eol2 CHAR**
  结束行的备用 CHAR
- **erase CHAR**
  CHAR 将擦除最后输入的字符
- **intr CHAR**
  CHAR 将发送中断信号
- **kill CHAR**
  CHAR 将擦除当前行
- **lnext CHAR**
  CHAR 将引用并输入下一个字符
- **quit CHAR**
  CHAR 将发送退出信号
- **rprnt CHAR**
  CHAR 将重绘当前行
- **start CHAR**
  CHAR 将在停止后重新开始输出
- **stop CHAR**
  CHAR 将停止输出
- **susp CHAR**
  CHAR 将发送终端停止信号
- **swtch CHAR**
  CHAR 将切换到不同的 shell 层
- **werase CHAR**
  CHAR 将擦除最后输入的单词

### 特殊设置：

- **N**
  将输入和输出速度设置为 N 波特
- **cols N**
  告知内核终端有 N 列
- **columns N**
  等同于 cols N
- **ispeed N**
  将输入速度设置为 N
- **line N**
  使用行规程 N
- **min N**
  配合 -icanon，设置完成读取所需的最少 N 个字符
- **ospeed N**
  将输出速度设置为 N
- **rows N**
  告知内核终端有 N 行
- **size**
  根据内核打印行数和列数
- **speed**
  打印终端速度
- **time N**
  配合 -icanon，设置 N 个十分之一的秒作为读取超时时间

### 控制设置：

- **[-]clocal**
  禁用调制解调器控制信号
- **[-]cread**
  允许接收输入
- **[-]crtcts**
  启用 RTS/CTS 握手
- **csN**
  将字符大小设置为 N 位，N 在 [5..8] 范围内
- **[-]cstopb**
  每个字符使用两个停止位（带 ‘-’ 则为一个）
- **[-]hup**
  当最后一个进程关闭 tty 时发送挂断信号
- **[-]hupcl**
  等同于 [-]hup
- **[-]parenb**
  在输出中生成奇偶校验位，并在输入中期待奇偶校验位
- **[-]parodd**
  设置奇校验（带 ‘-’ 则为偶校验）
- **[-]cmspar**
  使用“粘滞”（标记/空格）校验

### 输入设置：

- **[-]brkint**
  断字符导致中断信号
- **[-]icrnl**
  将回车符转换为换行符
- **[-]ignbrk**
  忽略断字符
- **[-]igncr**
  忽略回车符
- **[-]ignpar**
  忽略具有奇偶校验错误的字符
- **[-]imaxbel**
  遇到字符时发出提示音，且不清空完整的输入缓冲区
- **[-]inlcr**
  将换行符转换为回车符
- **[-]inpck**
  启用输入奇偶校验检查
- **[-]istrip**
  清除输入字符的高位（第 8 位）
- **[-]iutf8**
  假设输入字符采用 UTF-8 编码
- **[-]iuclc**
  将大写字母转换为小写字母
- **[-]ixany**
  允许任何字符重启输出，而不仅仅是开始字符
- **[-]ixoff**
  启用发送开始/停止字符
- **[-]ixon**
  启用 XON/XOFF 流控制
- **[-]parmrk**
  标记奇偶校验错误（使用 255-0 字符序列）
- **[-]tandem**
  等同于 [-]ixoff

### 输出设置：

- **bsN**
  退格延迟样式，N 在 [0..1] 范围内
- **crN**
  回车延迟样式，N 在 [0..3] 范围内
- **ffN**
  换页延迟样式，N 在 [0..1] 范围内
- **nlN**
  换行延迟样式，N 在 [0..1] 范围内
- **[-]ocrnl**
  将回车符转换为换行符
- **[-]ofdel**
  使用删除字符代替 NUL 字符进行填充
- **[-]ofill**
  使用填充（填充）字符代替计时进行延迟
- **[-]olcuc**
  将小写字母转换为大写字母
- **[-]onlcr**
  将换行符转换为回车-换行
- **[-]onlret**
  换行符执行回车
- **[-]nonl**
  不在第一列打印回车
- **[-]opost**
  后处理输出
- **tabN**
  水平制表符延迟样式，N 在 [0..3] 范围内
- **tabs**
  等同于 tab0
- **-tabs**
  等同于 tab3
- **vtN**
  垂直制表符延迟样式，N 在 [0..1] 范围内

### 本地设置：

- **[-]crterase**
  以“退格-空格-退格”形式回显擦除字符
- **ctrlkill**
  遵循 echoprt 和 echoe 设置杀死整行
- **-ctrlkill**
  遵循 echotl 和 echok 设置杀死整行
- **[-]ctlcecho**
  以尖帽子表示法（'^c'）回显控制字符
- **[-]echo**
  回显输入字符
- **[-]echoctl**
  等同于 [-]ctlcecho
- **[-]echoe**
  等同于 [-]crterase
- **[-]echok**
  在杀死字符后回显一个换行符
- **[-]echoke**
  等同于 [-]crtkill
- **[-]echonl**
  即使未回显其他字符，也回显换行符
- **[-]echoprt**
  在 ‘ 和 ’ 之间反向回显被擦除的字符
- **[-]extproc**
  启用“LINEMODE”；对高延迟链接有用
- **[-]icanon**
  启用特殊字符：erase, kill, werase, prnt
- **[-]ixexten**
  启用非 POSIX 特殊字符
- **[-]isig**
  启用中断、退出和挂起特殊字符
- **[-]noflush**
  在中断和退出特殊字符后禁用刷新
- **[-]prterase**
  等同于 [-]echoprt
- **[-]tostop**
  停止尝试向终端写入的后台作业
- **[-]xcase**
  配合 icanon，使用 ` 作为大写字母的转义

### 组合设置：

- **[-]LCASE**
  等同于 [-]lcase
- **cbreak**
  等同于 -icanon
- **cbreak**
  等同于 icanon
- **cooked**
  等同于 brkint ignpar ipost isig icanon，并将 eof 和 eol 字符重置为其默认值
