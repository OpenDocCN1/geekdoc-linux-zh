Whenever a Default ACL contains nad user entries or nad group objects, it st also contain a default effective rights mask.

To help the user ensure these rules, setfacl creates entries from existing entries under the following conditions:

+   * If an ACL contains nad user or nad group entries, and no mask entry exists, a mask entry containing the sa permissions as the group entry is created. Unless the `-n` option is given, the permissions of the mask entry are further adjusted to include the union of all permissions affected by the mask entry. (See the `-n` option description).

+   * If a Default ACL entry is created, and the Default ACL contains no owner, owning group, or others entry, a copy of the ACL owner, owning group, or others entry is added to the Default ACL.

+   * If a Default ACL contains nad user entries or nad group entries, and no mask entry exists, a mask entry containing the sa permissions as the default Default ACL’s group entry is added. Unless the `-n` option is given, the permissions of the mask entry are further adjusted to include the union of all permissions affected by the mask entry. (See the `-n` option description).
