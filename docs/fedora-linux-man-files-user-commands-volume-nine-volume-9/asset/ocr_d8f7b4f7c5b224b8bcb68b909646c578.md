# EXAMPLE

Below is a sample .xinitrc that starts several applications and leaves the window manager running as the "last" application. Assuming that the window manager has been configured properly, the user then chooses the "Exit" nu item to shut down X.

```
xrd -load $HOME/.Xresources xsetroot -solid gray & xbi
ff -geometry -430+5 &
oclock -geometry 75x75-0-0 & xload -geometry -80-0 & xte
rm -geometry +0+60 -ls &
xterm -geometry +0-100 & xconsole -geometry -0+0 -fn 5x7 & exec twm
```
