# OPTIONS

The following commands are supported:

```
check [-q] [-f fmt] [—output=ofmt] [-r {leaks | all}] [-T src_cache] filena
create [-q] [-f fmt] [-o options] filena [size]
commit [-q] [-f fmt] [-t cache] [-b base] [-d] [-p] filena
compare [-f fmt] [-F fmt] [-T src_cache] [-p] [-q] [-s] filena1 filena2
convert [-c] [-p] [-q] [-n] [-f fmt] [-t cache] [-T src_cache] [-O output_fmt] [-o options] [-s snapshot_id_or_na] [-l snapshot_param] [-S Sparse_size] filena [filena2 [...]]
output_filena
info [-f fmt] [—output=ofmt] [—backing-chain] filena
map [-f fmt] [—output=ofmt] filena
snapshot [-q] [-l] -a snapshot | -c snapshot | -d snapshot} filena
rebase [-q] [-f fmt] [-t cache] [-T src_cache] [-p] [-u] -b backing_file [-F backing_fmt] filena
resize [-q] filena [+ | -]size
and [-p] [-q] [-f fmt] [-t cache] -o options filena
```

Command paraters:

```
filena
```

is a disk image filena

```
fmt
```

is the disk image format. It is gessed automatically in most cases. See below for a description of the supported disk formats.

```
—backing-chain
```

will enumerate information about backing files in a disk image chain. Refer below for further description.

```
size
```

is the disk image size in bytes. Optional suffixes k or κ (kilobyte, 1024) Μ (gabyte, 1024k) and G (gigabyte, 1024M) and T (terabyte, 1024G)are supported. b is ignored.

```
output_filena
```

is the destination disk image filena

```
output_fmt
```

is the destination format

```
options
```

is a comma separated list of format specific options in a na=value format. Use -o ? for an overview of the options supported by the used format or see the format descriptions below for details.

```
snapshot_param
```

is param used for internal snapshot, format is ‘snapshot.id=[ID],snapshot.na=[NAME]’ or ‘[ID_OR_NAME]’

```
snapshot_id_or_na
```

is deprecated, use snapshot_param instead
