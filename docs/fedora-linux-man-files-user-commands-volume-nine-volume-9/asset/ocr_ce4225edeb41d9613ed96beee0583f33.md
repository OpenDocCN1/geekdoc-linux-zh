-s|---configfile=<configuration file>

The file specified contains the configuration details required by the server. The information in this file includes server-specific information such as what printcap file to use, as well as descriptions of all of the services that the server is to provide. See s.conf for more information. The default configuration file na is determined at compile ti.

-l|---log-basena=logdirectory

Base directory na for log/debug files. The extension **.proгна** will be appended (e.g. log.sclient, log.sd, etc…). The log file is never removed by the client.

---option=<na>=<value>

Set the (5) option“<na>” to value“<value>” from the command line. This overrides compiled-in defaults and options read from the configuration file.

-N|---no-pass

If specified, this parater suppresses the normal password prompt from the client to the user. This is useful when accessing a service that does not require a password. Unless a password is specified on the command line or this parater is specified, the client will request a password.

If a password is specified on the command line and this option is also defined the password on the command line will be silently ignored and no password will be used.

-k|---kerberos

Try to authenticate with kerberos. Only useful in an Active Directory environnt.

-C|---use-ccache

Try to use the credentials cached by winbind.

-A|---authentication-file=filena

This option allows you to specify a file from which to read the userna and password used in the connection. The format of the file is
userna = <value> password = <value> domain = <value>

Make certain that the permissions on the file restrict access from unwanted users.
