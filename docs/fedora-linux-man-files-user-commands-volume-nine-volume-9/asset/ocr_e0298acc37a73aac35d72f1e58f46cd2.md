# **get-default**

Return the default target to boot into. This returns the target unit na default.target is alised (syinked) to.

# **set-default NAME**

Set the default target to boot into. This sets (syinks) the default.target alias to the given target unit.

# **Machine Commands**

# **list-machines [PATTERN...]**

List the host and all running local containers with their state. If one or more PATTERNs are specified, only containers matching one of them are shown.

# **Job Commands**

# **list-jobs [PATTERN...]**

List jobs that are in progress. If one or more PATTERNs are specified, only jobs for units matching one of them are shown.

# **cancel JOB...**

Cancel one or more jobs specified on the command line by their nuric job IDs. If no job ID is specified, cancel all pending jobs.
