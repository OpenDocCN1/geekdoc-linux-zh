# EXAMPLES FOR DOT

Example1.Plots all dependencies of any unit whose na starts with “avahi-daemon”

```
$ systemd-analyze dot 'avahi-daemon.*' | dot -Tsvg > avahi.svg $ eog avahi.svg
```

Example2.Plots the dependencies between all known target units

```
systemd-analyze dot --to-pattern='*.target' --from-pattern='*.target' |
dot -Tsvg > targets.svg $ eog targets.svg
```
