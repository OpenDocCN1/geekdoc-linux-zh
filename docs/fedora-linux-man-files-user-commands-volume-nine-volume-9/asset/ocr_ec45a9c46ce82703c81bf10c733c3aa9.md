# OPTIONS

-signal
---signal signal Defines the signal to send to each matched process. Either the nuric or the syolic signal na can be used. (**pkill** only.)

-c, --count
Supress normal output; instead print a count of matching processes. When count does not match anything, e.g. returns zero, the command will return non-zero value.

-d, --delimiters delimiter
Sets the string used to delimit each process ID in the output (by default a newline). (**pgrep** only.)

-f, --full
The *pattern* is normally only matched against the process na. When **-f** is set, the full command line is used.

-g, --pgroup pgrep,...
Only match processes in the process group IDs listed. Process group 0 is translated into **pgrep**'s or **pkill**'s own process group.

-G, --group gid,...
Only match processes whose real group ID is listed. Either the nurical or syolical value may be used.

-l, --list-ns
List the process na as well as the process ID. (**pgrep** only.)

-a, --list-full
List the full command line as well as the process ID. (**pgrep** only.)

-n, --newest
Select only the newest (most recently started) of the matching processes.

-o, --oldest
Select only the oldest (least recently started) of the matching processes.

-P, --parent ppid,...
Only match processes whose parent process ID is listed.

-s, --session sid,...
Only match processes whose process session ID is listed. Session ID 0 is translated into **pgrep**'s or **pkill**'s own session ID.

-t, --terminal term,...
Only match processes whose controlling terminal is listed. The terminal na should be specified without the "/dev/" prefix.

-u, --euid euid,...
Only match processes whose effective user ID is listed. Either the nurical or syolical value may be used.

-U, --uid uid,...
Only match processes whose real user ID is listed. Either the nurical or syolical value may be used.
