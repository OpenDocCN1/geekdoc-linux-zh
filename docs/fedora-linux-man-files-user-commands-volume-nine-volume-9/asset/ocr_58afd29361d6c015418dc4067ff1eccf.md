# ## ENVIRONMENT

**RYGEL_DISABLE_UPNP**

Disable advertisent via UPnP and set rygel into streaming-only mode.

**RYGEL_IFACE**

Set the network interfaces to bind to.

**RYGEL_PORT**

Define the network port to bind to.

**RYGEL_DISABLE_TRANSCODING**

Disable transcoding globally.

**RYGEL_LOG**

Set the log level of rygel.

**RYGEL_PLUGIN_PATH**

Set the plugin search path of rygel.

**RYGEL_ENGINE_PATH**

Set the dia streaming and transcoding engine search path for rygel.

**RYGEL_MEDIA_ENGINE**

Set a specific dia streaming engine to pick up from the dia engine search path.

**RYGEL_DISABLE_UPLOAD**

Disable dia file upload via UPnP.

**RYGEL_DISABLE_DELETION**

Disable remote file deletion via UPnP.

**RYGEL_PLUGIN_TIMEOUT**

Set the ti-out for finding the plugins. Useful to increase when running inside valgrind.
