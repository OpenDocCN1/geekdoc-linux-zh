# EXIT STATUS

As long as all docunts processed result in so output, even if that output includes errata (a POD ERRORS section generated with `--error=pod), **pod2man** will exit with status 0. If any of the docunts being processed do not result in an output docunt, **pod2man** will exit with status 1. If there are syntax errors in a POD docunt being processed and the error handling style is set to the default of `die`, **pod2man** will abort imdiately with exit status 255.
