# EXAMPLES

To see every process on the system using standard syntax:

```
ps-e ps-ef ps-eF ps-ely
```

To see every process on the system using BSD syntax:

```
psax psaxu
```

To print a process tree:

```
ps-ejH psaxjf
```

To get info about threads:

```
ps-eLf psaxms
```

To get security info:

```
ps-eo euser,ruser,suser,fuser,f,comm,label psaxZ ps-eM
```

To see every process running as root (real&effectiveID) in user format:

```
ps-Uroot-urootu
```

To see every process with a user-defined format:

```
ps-eopid,tid,class,rtprio,ni,pri,psr,pcpu,stat,wchan:14,comm
psaxostat,euid,ruid,tty,tpgid,sess,pgrp,ppid,pid,pcpu,comm ps-
Aopid,tt,user,fna,tmout,f,wchan
```

Print only the process IDs of syslogd:

```
ps-Csyslogd-opid=
```

Print only the na of PID 42:

```
ps-q42-oconn=
```
