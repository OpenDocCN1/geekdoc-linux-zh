# COMandS

ck|cd <keyna>
Go to the specified subkey.

ch|predef [predefined-key-na]
Go to the specified predefined key.

list|ls
List subkeys and values of the current key.

mkkey|mkdir <keyna>
Create a key with the specified keyna as a subkey of the current key.

rmval|rm <valna>
Delete the specified value.

rmkey|rmdir <keyna>
Delete the specified subkey recursively.

pwd|pwk
Print the full na of the current key.

set|update
Update the value of a key value. Not implemented at the mont.

help|?
Print a list of available commands.

exit|quit
Leave regshell.
