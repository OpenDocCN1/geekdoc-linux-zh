# ADvanced usage

The syntax for requesting multiple files from a remote host is done by specifying additional remote-host args in the sa style as the first, or with the hostna omitted. For instance, all these work:

```
rsync -av host:file1 :file2 host:file{3,4} /dest/ rsync -av host::modna/file{1,2} host::modna/file3 /dest/ rsync -av host::modna/file1 ::modna/file{3,4}
```

Older versions of rsync required using quoted spaces in the SRC, like these examples:

```
rsync -av host: 'dir1/file1 dir2/file2 ' /dest rsync host:: 'modna/dir1/file1 modna/dir2/file2 ' /dest
```

This word-splitting still works (by default) in the latest rsync, but is not as easy to use as the first thod.

If you need to transfer a filena that contains whitespace, you can either specify the protect-args (-s) option, or you'll need to escape the whitespace in a way that the remote shell will understand. For instance:

```
rsync -av host: 'file\ na\ with\ spaces ' /dest
```
