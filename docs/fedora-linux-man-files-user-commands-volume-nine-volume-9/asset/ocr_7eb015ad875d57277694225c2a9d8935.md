# ## DESCRIPTION

The **ps2pdf** scripts are work-alikes for nearly all the functionality (but not the user interface) of Adobe’s Acrobat(TM) Distiller(TM) product: they convert PostScript files to Portable Document Format (PDF) files.

If the output filena is not specified, the output is placed in a file of the sa na with a ‘.pdf’ extension in the current working directory. Either the input filena or the output filena can be ‘-‘ to request reading from stdin or writing to stdout, respectively, when used as a filter. The three scripts differ as follows:

+   - **ps2pdf12** will always produce PDF 1.2 output (Acrobat 3-and-later compatible).
+   - **ps2pdf13** will always produce PDF 1.3 output (Acrobat 4-and-later compatible).
+   - **ps2pdf14** will always produce PDF 1.4 output (Acrobat 5-and-later compatible).
+   - **ps2pdf** per se currently produces PDF 1.4 output. However, this may change in the future. If you care about the compatibility level of the output, use **ps2pdf12**, **ps2pdf13** or **ps2pdf14**, or use the -dCompatibility=1.x switch in the command line.

There are so limitations in **ps2pdf**‘s conversion. See the HTML documentation for more information. A large nuero of Adobe Distiller(TM) paraters which can be used to control the conversion are also docunited there, including instructions for generating PDF/X and PDF/A docunts.
