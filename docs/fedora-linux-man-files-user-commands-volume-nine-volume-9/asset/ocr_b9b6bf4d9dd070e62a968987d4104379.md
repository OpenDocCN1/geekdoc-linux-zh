# DESCRIPTION

**psfaddtable** takes a console font in `.psf` format given by *fontfile* and rges it with the Unicode character table given by *tablefile* to produce a font file with an eeded character table, which is written to *outfile*. An input file na of “-” denotes standard input, and an output file na of “-” denotes standard output. If the *fontfile* already contains an eeded character table, it is ignored.
