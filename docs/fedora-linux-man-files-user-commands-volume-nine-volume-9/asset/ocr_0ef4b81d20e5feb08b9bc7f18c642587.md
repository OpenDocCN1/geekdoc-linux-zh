# DESCRIPTION

Print the resolved absolute file na; all but the last component st exist

+   - **-e**, **—canonicalize-existing**
+     all components of the path st exist

+   - **-m**, **—canonicalize-missing**
+     no components of the path need exist

+   - **-L**, **—logical**
+     resolve `..` components before syinks

+   - **-P**, **—physical**
+     resolve syinks as encountered (default)

+   - **-q**, **—quiet**
+     suppress most error ssages

+   - **—relative-to**=*FILE*
+     print the resolved path relative to FILE

+   - **—relative-base**=*FILE*
+     print absolute paths unless paths below FILE

+   - **-s**, **—strip**, **—no-syinks**
+     don’t expand syinks

+   - **-z**, **—zero**
+     end each output line with NUL, not newline

+   - **—help**
+     display this help and exit

+   - **—version**
+     output version information and exit
