# > USAGE

The normal processing sequence of groff is this:

```
input sourced file file || vv preprocessor -> troff -> postprocessor | v output file
```

That is, files sourced with **.so** are normally read *only* by **troff** (the actual formatter).

**soelim** is *not* required for **troff** to source files.

If a file to be sourced should also be preprocessed, it st already be read *before* the input file passes through the preprocessor. This is handled by **soelim**:

```
input file | v soelim -> preprocessor -> troff -> postprocessor ^ || v sourced output file file
```
