# > **DESCRIPTION**

Print value of a syolic link or canonical file na

**-f, --canonicalize**

canonicalize by following every syink in every component of the given na recursively; all but the last component st exist

**-e, --canonicalize-existing**

canonicalize by following every syink in every component of the given na recursively; all components st exist

**-m, --canonicalize-missing**

canonicalize by following every syink in every component of the given na recursively, without requires on components existence

**-n, --no-newline**

do not output the trailing delimit er

**-q, --quiet,**

**-s, --silent**

suppress most error ssages

**-v, --verbose**

report error ssages

**-z, --zero**

end each output line with NUL, not newline

**--help**

display this help and exit

**--version**

output version information and exit
