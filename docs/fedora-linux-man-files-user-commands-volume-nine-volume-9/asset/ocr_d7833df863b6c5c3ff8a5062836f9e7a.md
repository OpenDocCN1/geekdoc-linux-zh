# ACTION AND AUTHORIZATIONS

By default, the *org.freedesktop.policykit.exec* action is used. To use another action, use the *org.freedesktop.policykit.exec.path* annotation on an action with the value set to the full path of the program. In addition to specifying the program, the authentication ssage, description, icon and defaults can be specified. If the *org.freedesktop.policykit.exec.argv1* annotation is present, the action will only be picked if the first argument to the program matches the value of the annotation.

Note that authentication sages may reference variables (see the section called “VARIABLES”), for example $(user) will be expanded to the value of the user variable.
