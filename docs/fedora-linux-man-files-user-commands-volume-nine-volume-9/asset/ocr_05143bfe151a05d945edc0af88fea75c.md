# **DESCRIPTION**

**ps** displays information about a selection of the active processes. If you want a repetitive update of the selection and the displayed information, use `(1)` instead.

This version of **ps** accepts several kinds of options:

+   1.  UNIX options, which may be grouped and st be preceded by a dash.
+   2.  BSD options, which may be grouped and st not be used with a dash.
+   3.  GNU long options, which are preceded by two dashes.

Options of different types may be freely mixed, but conflicts can appear. There are so synonymous options, which are functionally identical, due to the many standards and **ps** implementations that this **ps** is compatible with.

Note that “**ps -aux** is distinct from **psaux**. The POSIX and UNIX standards require that **ps -aux**” print all processes owned by a user nad “x”, as well as printing all processes that would be selected by the **-a** option. If the user nad “x” does not exist, this **ps** may interpret the command as “**psaux**” instead and print a warning. This behavior is intended to aid in transitioning old scripts and habits. It is fragile, subject to change, and thus should not be relied upon.

By default, **ps** selects all processes with the sa effective user ID (eid=**EUID**) as the current user and associated with the sa terminal as the invoker. It displays the process ID (pid=**PID**), the terminal associated with the process (na=**TTY**), the culated CPU  ti in [DD-]jh:mm:ss format (ti=**TIME**), and the executable na (ucmd=**CMD**). Output is unsorted by default.

The use of BSD-style options will add process state (stat=**STAT**) to the default display and show the command args (args=**COMMAND**) instead of the executable na. You can override this with the **PS_FORMAT** enviornnt variable. The use of BSD-style options will also change the process selection to include processes on other terminals (TTYs) that are owned by you; alternately, this may be described as setting the selection to be the set of all processes filtered to exclude processes owned by other users or not on a terminal. These effects are not considered when options are described as being “identical” below, so **-M** will be considered identical to **Z** and so on.

Except as described below, process selection options are additive. The default selection is discarded, by then the selected processes are added to the set of processes to be displayed. A process will thus be shown if it ets any of the given selection criteria.
