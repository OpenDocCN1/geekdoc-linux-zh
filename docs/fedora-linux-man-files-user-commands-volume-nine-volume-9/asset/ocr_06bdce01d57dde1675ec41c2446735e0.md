# > **EXIT STATUS**

As long as all docuents processed result in so output, even if that output includes errata (a POD `ERRORS` section generated with `--error=s=pod), **pod2text** will exit with status 0. If any of the docuents being processed do not result in an output docuent, **pod2text** will exit with status 1. If there are syntax errors in a POD docuent being processed and the error handling style is set to the default of `die**, **pod2text** will abort immediatly with exit status 255.
