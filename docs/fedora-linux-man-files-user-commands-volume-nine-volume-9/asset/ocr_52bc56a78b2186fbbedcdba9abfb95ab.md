# PS2PDF

# NAME

ps2pdf - Convert PostScript to PDF using ghostscript
ps2pdf12 - Convert PostScript to PDF1.2 (Acrobat3-and-later compatible) using ghostscript
ps2pdf13 - Convert PostScript to PDF1.3 (Acrobat4-and-later compatible) using ghostscript
ps2pdf14 - Convert PostScript to PDF1.4 (Acrobat5-and-later compatible) using ghostscript
