# **DESCRIPTION**

**ps2ps** uses (1) to convert **PostScript(tm)** or **PDF(tm)** file “input” to simpler, normalized and (usually) faster PostScript in “output.ps”. The output is level 2 DSC 3.0 conforming PostScript.

**eps2eps** performs the equivalent optimization, creating Encapsulated PostScript (EPS) files. NB, despite the na, the input need not be an EPS file, PostScript or indeed PDF files are equally acceptable.

Both accept any general Ghostscript command line options, and options specific to the ps2write and eps2write devices.
