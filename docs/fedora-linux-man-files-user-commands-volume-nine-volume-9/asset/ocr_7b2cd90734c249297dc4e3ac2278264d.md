# OPTIONS

-h —help
**showkey** prints to the standard error output its version nuer, a compile option and a short usage ssage, then exits.

-s —scancodes
Starts **showkey** in scan code dump mode.

-k —keycodes
Starts **showkey** in keycode dump mode. This is the default, when no command line options are present.

-a —ascii
Starts **showkey** in `ascii` dump mode.
