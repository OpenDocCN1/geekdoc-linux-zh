# ## CONFIGURATION FILE FORMAT

The configuration options are specified in the **req** section of the configuration file. As with all configuration files if no value is specified in the specific section (i.e. **req**) then the initial unnad or **default** section is searched too.

The options available are described in detail below.

+   **input_password output_password**
+   
+   The passwords for the input private key file (if present) and the output private key file (if one will be created). The command line options **passin** and **passout** override the configuration file values.

+   **default_bits**
+   
+   This specifies the default key size in bits. If not specified then 512 is used. It is used if the **-new** option is used. It can be overriden by using the **-newkey** option.

+   **default_keyfile**
+   
+   This is the default filena to write a private key to. If not specified the key is written to standard output. This can be overridden by the **-keyout** option.

+   **oid_file**
+   
+   This specifies a file containing additional **OBJECT IDENTIFIERS**. Each line of the file should consist of the nurical form of the object identifier followed by white space then the short na followed by white space and finally the long na.

+   **oid_section**
+   
+   This specifies a section in the configuration file containing extra object identifiers. Each line should consist of the short na of the object identifier followed by = and the nurical form. The short and long nas are the sa when this option is used.

+   **RANDFILE**
+   
+   This specifies a filena in which random nuer seed information is placed and read from, or an EGD socket (see (3). It is used for private key generation.

+   **encrypt_key**
+   
+   If this is set to **no** then if a private key is generated it is **not** encrypted. This is equivalent to the **-nodes** command line option. For compatibilty **encrypt_rsa_key** is an equivalent option.

+   **default_md**
+   
+   This option specifies the digest algorihm to use. Possible values include **md5 sha1 mdc2**. If not present then **MD5** is used. This option can be overriden on the command line.

+   **string_mask**
+   
+   This option masks out the use of certain string types in certain fields. Most users will not need to change this option.
+   
+   It can be set to several values **default** which is also the default option uses PrintableStrings, T61Strings and BMPStrings if the **pix** value is used then only PrintableStrings and BMPStrings will be used.
