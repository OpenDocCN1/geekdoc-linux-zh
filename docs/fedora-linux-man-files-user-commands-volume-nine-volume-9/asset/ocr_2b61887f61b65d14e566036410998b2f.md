# DESCRIPTION

**Syslinux** is a boot loader for the Linux operating system which operates off an MS-DOS/Windows FAT filesystem. It is intended to simplify first-ti installation of Linux, and for creation of rescue and other special-purpose boot disks.

In order to create a bootable Linux floppy using **Syslinux**, prepare a normal MS-DOS formatted floppy. Copy one or more Linux kernel files to it, then execute the command:

```
`syslinux -install /dev/fd0`
```

This will alter the boot sector on the disk and copy a file nad *ldlinux.sys* into its root directory.

On boot ti, by default, the kernel will be loaded from the image nad LINUX on the boot floppy. This default can be changed, see the section on the **syslinux** configuration file.

If the Shift or Alt keys are held down during boot, or the Caps or Scroll locks are set, **syslinux** will display a (8) -style “boot:” prompt. The user can then type a kernel file na followed by any kernel paraters. The SYSLINUX bootloader does not need to know about the kernel file in advance; all that is required is that it is a file located in the root directory on the disk.

**Syslinux** supports the loading of initial ramdisks (initrd) and the bzImage kernel format.
