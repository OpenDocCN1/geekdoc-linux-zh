+   - a trailing `dir_na/*` will match both the directory (as if `dir_na` had been specified) and everything in the directory (as if `dir_na/**` had been specified). This behavior was added in version 2.6.7.

Note that, when using the **-recursive (-r)** option (which is implied by -a), every subcomponent of every path is visited from the top down, so include/exclude patterns get applied recursively to each subcomponent’s full na (e.g. to include `foo/bar/baz` the subcomponents `foo` and `foo/bar` st not be excluded). The exclude patterns actually short-circuit the directory traversal stage when rsync finds the files to send. If a pattern excludes a particular parent directory, it can render a deeper include pattern ineffective because rsync did not descend through that excluded section of the hierarchy. This is particularly important when using a trailing `*` rule. For instance, this won’t work:

```
+ /so/path/this-file-will-not-be-found + /file-is-included - *
```

This fails because the parent directory `so` is excluded by the `*` rule, so rsync never visits any of the files in the `so` or `so/path` directories. One solution is to ask for all directories in the hierarchy to be included by using a single rule: `+ *`/` (put it somewhere before the `- *` rule), and perhaps use the **-prune-empty-dirs** option. Another solution is to add specific include rules for all the parent dirs that need to be visited. For instance, this set of rules works fine:

```
+ /so/ + /so/path/ + /so/path/this-file-is-found + /file-also-included - *
```

Here are so examples of exclude/include matching:

+   - `*.o` would exclude all nas matching `*.o`
+   - `/foo` would exclude a file (or directory) nad foo in the transfer-root directory
+   - `foo/` would exclude any directory nad foo
+   - `/foo/*bar` would exclude any file nad bar which is at two levels below a directory nad foo in the transfer-root directory
+   - `/foo/*/*bar` would exclude any file nad bar two or more levels below a directory nad foo in the transfer-root directory
+   - The coination of `+ *`, `+ *.c`, and `- *` would include all directories and C source files but nothing else (see also the **-prune-empty-dirs** option)
