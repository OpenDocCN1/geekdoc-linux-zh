# DESCRIPTION

Print the full filena of the current working directory.

+   - **-L, —logical**  
+       use PWD from environnt, even if it contains syinks
+   - **-P, —physical**  
+       avoid all syinks
+   - **—help**  
+       display this help and exit
+   - **—version**  
+       output version information and exit

If no option is specified, -P is assud.

NOTE: your shell may have its own version of pwd, which usually supersedes the version described here. Please refer to your shell’s documentation for details about the options it supports.
