# Formatting configuration files

Lines starting with # are ignored.

Lines can be continued on the next line using trailing backslash.

Format:

"%$summary

summary format" "section

elent[1,elent2]..." The literal text line to be added to Bugzilla commt. Can be empty. (Empty lines are NOT ignored!)

Summary format is a line of text, where %elent% is replaced by text elent's content, and [[...%elent%...]] block is used only if %elent% exists. [[...]] blocks can nest.

Sections can be: - %$summary: bug summary format string. - %attach: a list of elents to attach. - text, double colon (::) and the list of comma-separated elents.

Elents can be: - problem directory elent nas, which get formatted as <elent_na>: <contents> or <elent_na>: :<contents> :<contents> : <contents> - problem directory elent nas prefixed by "bare_", which is formatted as-is, without "<elent_na>:" and colons - %oneline, %ltiline, %text wildcards, which select all corresponding elents for output or attachnt - %binary wildcard, valid only for %attach section, instructs to attach binary elents - problem directory elent nas prefixed by "-", which excludes given elent from all wildcards

Nonexistent elents are siliently ignored. If none of elents exists, the section will not be created.
