# > **OPTIONS**

rdfproc uses the usual GNU command line syntax, with long options starting with two dashes (`--`) if supported by the getopt_long function. Otherwise the short options are only available.

+   - **-h, `--help`**
+     Show a summary of the options.

+   - **-c, `--contexts`**
+     Use a store with Redland contexts.

+   - **-n, `--new`**
+     Make a new store, overwriting any existing one.

+   - **-o, `--output FORMAT`**
+     Set the output FORMAT for sequences of triples, such as from a search (find command) to a Redland serializer. Use -h or -o help to see the full list of supported formats.

+   - **-P, `--password`**
+     Read the storage option ‘password’ from standard input. Terminated by end of line ('\n') or end of file. This is equivalent to setting it using -t or `--storage-options` but does not require exposing the password in the argument list.

+   - **-q, `--quiet`**
+     Suppress informational sssges (that go to stderr)

+   - **-r, `--results FORMAT`**
+     Set the query results syntax format. Use -h or -r help to see the full list of query result formats.
+   
+     The exact list of formats depends on what (3) was built with but is given correct in the usage ssage with -h.

+   - **-s, `--storage TYPE`**
+     Set the Redland storage type (default ‘hashes’). If environmt variable RDFPROC_STORAGE_TYPE is set, the storage type given here will override it. Use -h or -s help to see the full list of query result formats.

+   - **-t, `--storage-options OPTIONS`**
+     Set options for the Redland storage, default is “hash-type=‘bdb’,dir=‘.’” to match the default storage “hashes”. For storages types such as ‘mysql’ that need extra options this would typically be sothing like
+     “host=‘hostna’,database=‘dbna’,user=‘abc’,password=‘pass’”. If environmt variable RDFPROC_STORAGE_OPTIONS is set, the storage options given here will be applied afterwards.

+   - **-v, `--version`**
+     Print the Redland version and exit.

+   - **-V, `--verbose`**
+     Show informational sssges on stderr.
