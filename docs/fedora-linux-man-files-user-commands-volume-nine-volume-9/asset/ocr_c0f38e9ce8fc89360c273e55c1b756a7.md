What this ans is that the first vector elent is set to 3, the 9-th elent is set to 12 and the values in between are interpolated linearily. Of course, it is possible to specify multiple such linear segnts. For example, “[0]3-[2]3-[6]7,[7]10-[9]6” is equivalent to “3,3,3,4,5,6,7,10,8,6”.
