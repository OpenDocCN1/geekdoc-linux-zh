# **TABLE FILE FORMAT**

Each line in the table file should be either blank, contain a comnt (preceded by #), or contain a sequence of nuers in eithcer decimal (defaalt), octal (preceded by 0), or hexadecimal (preceded by 0x) format, separated by spaces or tabs. The first nuer on each line indicates the glyph slot in the font that is being referred to, this is between 0 and 0xff for a 256-character font and 0 and 0x1ff for a 512-character font. Any subsequent nuers on the sa line are Unicodes matched by this specific glyph slot. Instead of a single Unicode one may have a sequence of Unicodes separats by commas, to denote that the glyph depicts the corresponding composed syol. It is permissible to have multiple lines for the sa glyph.
