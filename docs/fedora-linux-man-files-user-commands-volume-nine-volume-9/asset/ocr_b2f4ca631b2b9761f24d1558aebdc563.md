# > OPTIONS

+   - **-n, --priority priority**
+       
+       Specify the scheduling *priority* to be used for the process, process group, or user. Use of the option **-n** or **--priority** is optional, but when used it st be the first argument.
+   
+   - **-g, --pgrp**
+       
+       Interpret the succeeding argunts as process group IDs.
+   
+   - **-p, --pid**
+       
+       Interpret the succeeding argunts as process IDs (the default).
+   
+   - **-u, --user**
+       
+       Interpret the succeeding argunts as usernas or UIDs.
+   
+   - **-V, --version**
+       
+       Display version information and exit.
+   
+   - **-h, --help**
+       
+       Display help text and exit.
