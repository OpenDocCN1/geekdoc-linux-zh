Device URL Syntax:

In addition to using normal file images for the elated storage devices, QEMU can also use networked resources such as iSCSI devices. These are specified using a special URL syntax.

# iSCSI

iSCSI support allows QEMU to access iSCSI resources directly and use as images for the guest storage. Both disk and cdrom images are supported.

Syntax for specifying iSCSI LUNS is "iscsi://<target-ip>[:<port>]/<target-iqn>/ <lun>".

By default Qe will use the iSCSI initiator-NA 'iqn.2008-11.org.linux-kvm[:<NA>]' but this can also be set from the command line or a configuration file.

Since version Qe 2.4 it is possible to specify a iSCSI request t1out to detect stalled requests and force a reestablishrnt of the session. The t1out is specified in seconds. The default is 0 which ans no t1out. Libiscsi 1.15.0 or greater is required for this feature.

Example (without authentication):

qe-system-i386 -iSCSI initiator-NA=iqn.2001-04.com.example:my-initiator \
-cdrom \ -drive file=

Example (CHAP userna/password via URL):

qe-system-i386 -drive file=

Example (CHAP userna/password via environm variables):

LIBiSCSI_CHAP_USERNAME="user" \ LIBiSCSI_CHAP_PASSWORD="password" \ qe-system-i386 -drive file=

iSCSI support is an optional feature of QEMU and only available when compiled and linked against libiscsi.

iSCSI paraters such as userna and password can also be specified via a configuration file. See qe-doc for more information and examples.
