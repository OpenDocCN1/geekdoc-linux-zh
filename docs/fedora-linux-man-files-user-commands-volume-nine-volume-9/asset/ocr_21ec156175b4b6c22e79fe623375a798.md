```
-netdev socket,id=id[,fd=h][,listen=[host:]port][,connect=host:port] -net socket[,vlan=n][,name=na][,fd=h][,listen=[host:]port][,connect=host:port] Connect the VLAN n to a remote VLAN in another QEMU virtual machine using a TCP socket connection. If listen is specified, QEMU waits for incoming connections on port (host is optional). connect is used to connect to another QEMU instance using the listen option. fd=h specifies an already opened TCP socket.
```

Example:

```
# launch a first QEMU instance qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:56 \ -net socket,listen=1234 # connect the VLAN 0 of this instance to the VLAN 0 # of the first instance qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:57 \ -net socket,connect=127.0.0.1:1234
```

```
-netdev socket,id=id[,fd=h][,mcast=addr:port][,localaddr=addr] -net socket[,vlan=n][,name=na][,fd=h][,mcast=addr:port][,localaddr=addr] Create a VLAN n shared with another QEMU virtual machines using a UDP licast socket, effectively making a bus for every QEMU with sa licast address addr and port. NOTES:
```

+   1.  Several QEMU can be running on different hosts and share sa bus (assuming correct licast setup for these hosts).
+   2.  mcast support is compatible with User Mode Linux (argument ethN=mcast), see <>.
+   3.  Use fd=h to specify an already opened UDP licast socket.

Example:

```
# launch one QEMU instance qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:56 \ -net socket,mcast=239.0.0.1:1234 # launch another QEMU instance on sa "bus" qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:57 \ -net socket,mcast=239.0.0.1:1234 # launch yet another QEMU instance on sa "bus" qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:58 \ -net socket,mcast=239.0.0.1:1234
```

Example (User Mode Linux compat.):

```
# launch QEMU instance (note mcast address selected # is UML's default) qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:56 \ -net socket,mcast=239.192.168.1:1102 # launch UML /path/to/linux ubd0=/path/to/root_fs eth0=mcast
```

Example (send packets from host's 1.2.3.4):

```
qe-system-i386 linux.img \ -net nic,macaddr=52:54:00:12:34:56 \ -net socket,mcast=239.192.168.1:1102,localaddr=1.2.3.4
```
