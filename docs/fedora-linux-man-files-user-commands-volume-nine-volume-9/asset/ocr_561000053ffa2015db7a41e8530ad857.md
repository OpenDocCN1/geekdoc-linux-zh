# NOTES

So servers are fussy about the case of supplied usernas, passwords, share nas (AKA service nas) and machine nas. If you fail to connect try giving all paraters in uppercase. It is often neccessary to use the -n option when connecting to so types of servers. For example OS/2 LanManager insists on a valid NetBIOS na being used, so you need to supply a valid na that would be known to the server.

sclent supports long file nas where the server supports the LANMAN2 protocol or above.
