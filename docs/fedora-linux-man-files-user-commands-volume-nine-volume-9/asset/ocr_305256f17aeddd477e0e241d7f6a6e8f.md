# COMMANDS

## LSARPC

+   - **lsaquery**
+       Query info policy

+   - **lookupids**
+       Resolve a list of SIDs to usernas.

+   - **lookupnas**
+       Resolve a list of usernas to SIDs.

+   - **enumtrust**
+       Enumerate trusted domains

+   - **enumprives**
+       Enumerate privileges

+   - **getdispna**
+       Get the privilege na

+   - **lsaenumisid**
+       Enumerate the LSA SIDS

+   - **lsaenumprivsaccount**
+       Enumerate the privileges of an SID

+   - **lsaenumaccsrights**
+       Enumerate the rights of an SID

+   - **lsaenumaccswithsright**
+       Enumerate accounts with a right

+   - **lsaaddaccsrights**
+       Add rights to an account
