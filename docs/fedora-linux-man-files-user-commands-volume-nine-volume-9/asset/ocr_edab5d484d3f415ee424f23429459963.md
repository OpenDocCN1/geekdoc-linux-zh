# OPTIONS

**ppdp** supports the following options:

+   -D *na*[=*value*]
+       Sets the nad variable for use in the source file. It is equivalent to using the #define directive in the source file.

+   -I *include-directory*
+       Specifies an alternate include directory. multiple -I options can be supplied to add additional directories.

+   -o *output-file*
+       Specifies the output file. The supported extensions are .po or .po.gz for GNU gettext format ssage catalogs and .strings for OS X strings files.
