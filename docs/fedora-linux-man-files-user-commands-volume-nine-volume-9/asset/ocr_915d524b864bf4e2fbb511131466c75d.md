# NOTES

Currently, **slabtop** requires a 2.4 or later kernel (specifically, a version 1.1 or later `/proc/slabinfo`). Kernel 2.2 should be supported in the future.

The slabtop statistic header is tracking how many bytes of slabs are being used and is not a asure of physical mory. The ‘Slab’ field in the `/proc/minfo` file is tracking information about used slab physical mory.
