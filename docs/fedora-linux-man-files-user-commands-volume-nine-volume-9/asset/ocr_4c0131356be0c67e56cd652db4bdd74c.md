**-object** **mory-backend-file,** id=id,size=size,m-path=dir,share=on|off
Creates a mory file backend object, which can be used to back the guest RAM with huge pages. The **id** parater is a unique ID that will be used to reference this mory region when configuring the **-numa** argument. The **size** option provides the size of the mory region, and accepts common suffixes, eg **500M**. The **m-path** provides the path to either a shared mory or huge page filesystem mount. The **share** boolean option determines whether the mory region is marked as private to QEMU, or shared. The latter allows a co-operating external process to access the QEMU mory region.

**-object** **rng-random,** id=id,filena=/dev/random
Creates a random nuer generator backend which obtains entropy from a device on the host. The **id** parater is a unique ID that will be used to reference this entropy backend from the **virtio-rng** device. The **filena** parater specifies which file to obtain entropy from and if omitted defaults to /dev/random.

**-object** **rng-egd,** id=id,chardev=chardevId
Creates a random nuer generator backend which obtains entropy from an external daemon running on the host. The **id** parater is a unique ID that will be used to reference this entropy backend from the **virtio-rng** device. The **chardev** parater is the unique ID of a character device backend that provides the connection to the RNG daemon.
