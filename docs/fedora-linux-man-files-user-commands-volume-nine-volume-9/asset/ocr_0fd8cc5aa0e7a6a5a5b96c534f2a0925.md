# NOTES

For security reasons **su** always logs failed log-in attempts to the btmp file, but it does not write to the lastlog file at all. This solution allows to control **su** behavior by PAM configuration. If you want to use the pam_lastlog module to print warning ssage about failed log-in attempts then the pam_lastlog has to be configured to update the lastlog file as well. For example by:

```
session required pam_lastlog.so nowtmp
```
