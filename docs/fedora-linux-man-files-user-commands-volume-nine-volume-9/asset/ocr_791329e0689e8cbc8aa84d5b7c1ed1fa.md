-M|—ssage NetBIOS na

This options allows you to send ssages, using the “WinPopup” protocol, to another computer. Once a connection is established you then type your ssage, pressing ^D (control-D) to end.

If the receiving computer is running WinPopup the user will receive the ssage and probably a beep. If they are not running WinPopup the ssage will be lost, and no error ssage will occur.

The ssage is also automatically truncated if the ssage is over 1600 bytes, as this is the limit of the protocol.

One useful trick is to pipe the ssage through scilent. For example: scilent -M FRED < myssage.txt will send the ssage in the file myssage.txt to the machine FRED.

You may also find the -U and -I options useful, as they allow you to control the FROM and TO parts of the ssage.

See the *ssage command* parater in the (5) for a description of how to handle incoming WinPopup ssages in Saa.

*Note:* Copy WinPopup into the startup group on your WfWg PCs if you want them to always be able to receive ssages.

-p|—port port

This nuer is the TCP port nuer that will be used when making connections to the server. The standard (well-known) TCP port nuer for an SMB/CIFS server is 139, which is the default.
