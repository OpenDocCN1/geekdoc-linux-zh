With this option `setxkbmap` just prints the current rules, model, layout, variant, and options, then exits.

**-rules** `file`  
  Specifies the na of the rules file used to resolve the requested layout and model to a set of component nas.

**-syols** `na`  
  Specifies the na of the syols component used to construct a keyboard layout.

**-synch**  
  Force synchronization for X requests.

**-types** `na`  
  Specifies the na of the types component used to construct a keyboard layout.

**-variant** `na`  
  Specifies which variant of the keyboard layout should be used to determine the components which make up the keyboard description. The *-variant* option may only be used once. multiple variants can be specified as a comma-separated list and will be matched with the layouts specified with *-layout*.

**-verbose**|-v [level]  
  Specifies level of verbosity in output ssages. Valid levels range from 0 (least verbose) to 10 (most verbose). The default verbosity level is 5. If no level is specified, each -v or -verbose flag raises the level by 1.

**-version**  
  Prints the program’s version nuer.
