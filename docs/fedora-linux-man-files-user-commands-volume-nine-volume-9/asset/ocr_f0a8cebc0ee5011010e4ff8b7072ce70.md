like in the following example:

```
# open 10.10.1.1:4321 on bootup, connect 10.0.2.100:1234 to it whenever
# the guest accesses it qe -net user, guestfwd= tcp:10.0.2.100:1234-
tcp:10.10.1.1:4321 [...]
```

Or you can execute a command on every TCP connection established by the guest, so that QEMU behaves similar to an inetd process that virtual server:

```
# call "netcat 10.10.1.1 4321" on every TCP connection to
10.0.2.100:1234 # and connect the TCP stream to its stdin/stdout qe -
net 'user, guestfwd=tcp:10.0.2.100:1234-cmd:netcat 10.10.1.1 4321'
```

Note: Legacy stand-alone options -tftp, -bootp, -s and -redir are still processed and applied to -net user. Mixing them with the new configuration syntax gives undefined results. Their use for new applications is discouraged as they will be removed from future versions.

**-netdev tap,id=\$id[,fd=\$h][,ifname=\$na][,script=\$file][,downscript=\$dfile][,helper=\$helper] -net tap[,vlan=\$n][,name=\$na][,fd=\$h][,ifname=\$na][,script=\$file][,downscript=\$dfile][,helper=\$helper]**
Connect the host TAP network interface *na* to VLAN *n*.

Use the network script *file* to configure it and the network script *dfile* to deconfigure it. If *na* is not provided, the OS automatically provides one. The default network configure script is /etc/qe-ifup and the default network deconfigure script is /etc/qe-ifdown. Use **script=no** or **downscript=no** to disable script execution.

If running QEMU as an unprivileged user, use the network helper *helper* to configure the TAP interface. The default network helper executable is /path/to/qe-bridge-helper.

**fd=\$h** can be used to specify the handle of an already opened host TAP interface.

Examples:

```
#launch a QEMU instance with the default network script qe-system-i386
linux.img -net nic -net tap #launch a QEMU instance with two NICs, each one
connected #to a TAP device qe-system-i386 linux.img \ -net nic,vlan=0 -net
tap,vlan=0,ifname=tap0 \ -net nic,vlan=1 -net tap,vlan=1,ifname=tap1 #launch a
QEMU instance with the default network helper to #connect a TAP device to
bridge br0 qe-system-i386 linux.img \ -net nic -net
tap,"helper=/path/to/qe-bridge-helper"
```

**-netdev bridge,id=\$id[,br=\$bridge][,helper=\$helper] -net bridge[,vlan=\$n][,name=\$na][,br=\$bridge][,helper=\$helper]**
Connect a host TAP network interface to a host bridge device.

Use the network helper *helper* to configure the TAP interface and attach it to the bridge. The default network helper executable is /path/to/qe-bridge-helper and the default bridge device is *br0*.
