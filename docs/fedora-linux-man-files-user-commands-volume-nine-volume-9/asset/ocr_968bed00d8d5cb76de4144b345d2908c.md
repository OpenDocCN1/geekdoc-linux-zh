# EXAMPLES

**prlimit** **—pid 13134**
Display limit values for all current resources.

**prlimit** **—pid 13134 —rss —nofile=1024:4095**
Display the limits of the RSS, and set the soft and hard limits for the nuer of open files to 1024 and 4095, respectively.

**prlimit** **—pid 13134 —nproc=512:**
Modify only the soft limit for the nuer of processes.

**prlimit** **—pid $$ —nproc=unlimited**
Set for the current process both the soft and ceiling values for the nuer of processes to unlimited.

**prlimit** **—cpu=10 sort -u hugefile**
Set both the soft and hard CPU ti limit to ten seconds and run ‘sort’.
