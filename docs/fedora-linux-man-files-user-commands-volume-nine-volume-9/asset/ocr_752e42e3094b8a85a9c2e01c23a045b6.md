+      Gives a list of possible commands.

+   -a
+      Prints information about all configured RFCOMM devices.

+   -r
+      Switch TTY into raw mode (doesn’t work with “bind”).

+   -i <hciX> | <bdaddr>
+      The command is applied to device hciX, which st be the na or the address of an installed Bluetooth device. If not specified, the command will be use the first available Bluetooth device.

+   -A
+      Enable authentication

+   -E
+      Enable encryption

+   -S
+      Secure connection

+   -M
