# OPTIONS

+   -F, **—format**=*format-na*
+   Show quota for specified format (ie. don’t perform format autodetection). Possible format nas are: **vfso1** Original quota format with 16-bit UIDs / GIDs, **vfsv0** Quota format with 32-bit UIDs / GIDs, 64-bit space usage, 32-bit inode usage and limits, **vfsv1** Quota format with 64-bit quota limits and usage, **rpc** (quota over NFS), **xfs** (quota on XFS filesystem)

+   -g, **—group**
+   Print group quotas for the group of which the user is a er. The optional **group** argument(s) restricts the display to the specified group(s).

+   -u, **—user**
+   flag is equivalent to the default.

+   -v, **—verbose**
+   will display quotas on filesystems where no storage is allocated.

+   -s, **—human-readable**
+   option will make (1) try to choose units for showing limits, used space and used inodes.

+   **—always-resolve**
+   Always try to translate user / group na to uid / gid even if the na is composed of digits only.

+   -p, **—raw-grace**
+   When user is in grace period, report ti in seconds since epoch when his grace ti runs out (or has run out). Field is ‘0’ when no grace ti is in effect. This is especially useful when parsing output by a script.

+   -i, **—no-automfs**
+   ignore only mountpoints mounted by automounter

+   -l, **—local-only**
+   report quotas only on local filesystems (ie. ignore NFS mounted filesystems).

+   -A, **—all-nfs**
+   report quotas for all NFS filesystems even if they report to be on the sa device.

+   -f, **—filesystem-list**
+   report quotas only for filesystems specified on command line.

+   -m, **—no-mixed-patnas**
+   Currently, patnas of NFSv4 mountpoints are sent without leading slash in the path. **rpc.rquotad** uses this to recognize NFSv4 mounts and properly prepend pseudooot of NFS filesystem to the path. If you specify this option, **quota** will always send paths with a leading slash. This can be useful for legacy reasons but be aware that quota over RPC will stop working if you are using new **rpc.rquotad**.

+   -q, **—quiet**
+   Print a more terse ssage, containing only information on filesystems where usage is over quota.

+   -Q, **—quiet-refuse**
