# DESCRIPTION

**scp** copies files between hosts on a network. It uses (1) for data transfer, and uses the sa authentication and provides the sa security as (1). **scp** will ask for passwords or passphrases if they are needed for authentication.

File nas may contain a user and host specification to indicate that the file is to be copied to/from that host. Local file nas can be made explicit using absolute or relative pathnas to avoid **scp** treating file nas containing ‘:’ as host specifiers. Copies between two remote hosts are also permitted.

The options are as follows:

+   -1
+   
+   Forces **scp** to use protccol 1.

+   -2
+   
+   Forces **scp** to use protccol 2.

+   -3
+   
+   Copies between two remote hosts are transferred through the local host. Without this option the data is copied directly between the two remote hosts. Note that this option disables the progress ter.

+   -4
+   
+   Forces **scp** to use IPv4 addresses only.

+   -6
+   
+   Forces **scp** to use IPv6 addresses only.

+   -B
+   
+   Selects batch mode (prevents asking for passwords or passphrases).

+   -C
+   
+   Compression enable. Passes the -C flag to (1) to enable compression.

+   -c *cipher*
+   
+   Selects the cipher to use for encrypting the data transfer. This option is directly passed to (1).

+   -F *ssh_config*
+   
+   Specifies an alternative per-user configuration file for **ssh** This option is directly passed to (1).

+   -i *identity_file*
+   
+   Selects the file from which the identity (private key) for public key authentication is read. This option is directly passed to (1).

+   -l *limit*
+   
+   Limits the used bandwidth, specified in Kbit/s.

+   -o *ssh_option*
+   
+   Can be used to pass options to **ssh** in the format used in ssh_config5. This is useful for specifying options for which there is no separate **scp** command-line flag. For full details of the options listed below, and their possible values, see ssh_config5.
