# OPTIONS

**-?,—help**  
Show help options

**—debug**  
Enable debug output

**—no-start**  
Do not start a new instance of rhythox

**—quit**  
Quit rhythox

**-i,—interactive**  
Start interactive mode

**—no-present** Don’t present an existing rhythox window

**—next**  
Jump to next song

**—previous**  
Jump to previous song

**—play**  
Resu playback if currently paused

**—pause**  
Pause playback if currently playing

**—play-pause**  
Toggle play/pause mode

**—stop**  
Stop playback if currently playing

**—play-uri=URI**  
Play a specified URI, importing it if necessary

**—enqueue**  
Add specified tracks already in the library to the play queue

**—clear-queue**  
Empty the play queue before adding new tracks

**—print-playing**  
Print the title and artist of the playing song

**—print-playing-format=format**  
Print formatted details of the song (see FORMAT OPTIONS below).

**—set-volu**  
Set the playback volu

**—volu-up**  
Increase the playback volu

**—volu-down**  
Decrease the playback volu

**—print-volu**  
Print the current playback volu

**—select-source=URI**  
Select the source corresponding to a URI (device or mount point)
