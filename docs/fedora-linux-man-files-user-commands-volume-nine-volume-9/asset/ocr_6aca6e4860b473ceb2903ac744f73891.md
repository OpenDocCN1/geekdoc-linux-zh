# CONFIGURATION

# Dialogue answers

During the reporting process report-gtk might show a dialogue asking for a decision to be made. So of those dialogues provides an option to reer the answer. If it is requested to reer the answer, report-gtk saves the answer in $XDG_CONFIG_HOME/abrt/settings/report-gtk.conf

If $XDG_CONFIG_HOME is not set, $HOME/.config is used instead.

# Reporting work flow configuration

These configuration files are placed in /usr/share/libreport/workflows.

Each file has XML formatting with the following DTD:

```
```xml
<!ELEMENT workflow (na+,description+, priority?, events*)> <!ELEMENT na (#PCDATA)> <!ATTLIST na x:lang CDATA #IMPLIED> <!ELEMENT description (#PCDATA)> <!ATTLIST description x:lang CDATA #IMPLIED> <!ELEMENT priority = (#PCDATA)> <!ELEMENT events = (event)+> <!ELEMENT event = (#PCDATA)>
```
```

na

User visible na

description

User visible description

priority

Priority of the workflow. Higher nuer ans a more visible place in UI. If not provided, 0 is used. The value is signed integer.

events

List of executed events

event

Na of event. If event is not applicable on the problem data or if it is not defined then process continues with next event sibling.
