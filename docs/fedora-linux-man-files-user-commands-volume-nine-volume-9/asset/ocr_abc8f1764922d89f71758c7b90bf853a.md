# **s=dir[\$server=addr]**

When using the user mode network stack, activate a built-in SMB server so that Windows OSes can access to the host files in *dir* transparently. The *IP* address of the SMB server can be set to *addr*. By default the 4th *IP* in the guest network is used, i.e. *x.x.x.4*.

In the guest Windows os, the line:

```
```plaintext
10.0.2.4 $server
```
```

st be added in the file *C:\WINDOWS\LMHOSTS* (for windows 9x/Me) or *C:\WINNT\SYSTEM32\DRIVERS\ETC\LMHOSTS* (Windows NT/2000).

Then *dir* can be accessed in *\\$server\qe*.

Note that a Samba server st be installed on the host OS. QEMU was tested successfully with sd versions from Red Hat 9, Fedora Core 3 and OpenSUSE 11.x.

# **hostfwd=[tcp|udp]:[hostaddr]:hostport-[guestaddr]:guestport**

Redirect incoming TCP or UDP connections to the host port *hostport* to the guest *IP* address *guestaddr* on guest port *guestport*. If *guestaddr* is not specified, its value is x.x.x.15 (default first address given by the built-in DHCP server). By specifying *hostaddr*, the rule can be bound to a specific host interface. If no connection type is set, TCP is used. This option can be given multiple tis.

For example, to redirect host X11 connection from screen 1 to guest screen 0, use the following:

```
```sh
# on the host q e-system-i386 -net user,hostfwd=tcp:127.0.0.1:6001-:6000
[...] # this host xterm should open in the guest X11 server xterm -
display :1
```
```

To redirect telnet connections from host port 5555 to telnet port on the guest, use the following:

```
```sh
# on the host q e-system-i386 -net user,hostfwd=tcp::5555-:23 [...]
telnet localhost 5555
```
```

Then when you use on the host *telnet localhost 5555*, you connect to the guest telnet server.
