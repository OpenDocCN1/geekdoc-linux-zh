+   - ―**quick-pid***pidlist*
+       Select by processID (quick mode). Identical to -**q** and **q**.
+       - -**sess***sesslist*
+           Select by session ID. This selects the processes with a session ID specified in sesslist.
+           - ―**sid***sesslist*
+               Select by sessionID. Identical to **-s**.
+               - **tty***ttylist*
+                   Select by tty. Nearly identical to **-t** and **―tty**, but can also be used with an empty ttylist to indicate the terminal associated with **ps**. Using the **T** option is considered cleaner than using **t** with an empty ***ttylist***.
+                   - -**tty***ttylist*
+                       Select by tty. This selects the processes associated with the terminals given in ttylist. Terminals (ttys, or screens for text output) can be specified in several forms: /dev/ttyS1, ttyS1, S1. A plain "-" may be used to select processes not attached to any terminal.
+                       - ―**tty***ttylist*
+                           Select by terminal. Identical to **-t** and **t**.
+                           - **U***userlist*
+                               Select by effective user ID (EUID) or na. This selects the processes whose effective user na or ID is in userlist. The effective user ID describes the user whose file access permissions are used by the process (see (2)). Identical to **-u** and **―user**.
+                               - -**U***userlist*
+                                   Select by real user ID (RUID) or na. It selects the processes whose real user na or ID is in the userlist list. The real user ID identifies the user who created the process, see (2).
+                                   - -**u***userlist*
+                                       Select by effective user ID (EUID) or na. This selects the processes whose effective user na or ID is in userlist.
+                                       The effective user ID describes the user whose file access permissions are used by the process (see (2)). Identical to **U** and **―user**.
+                                       - ―**User***userlist*
+                                           Select by real user ID (RUID) or na. Identical to -**U**.
+                                           - ―**user***userlist*
+                                               Select by effective user ID (EUID) or na. Identical to -**u** and **U**.
