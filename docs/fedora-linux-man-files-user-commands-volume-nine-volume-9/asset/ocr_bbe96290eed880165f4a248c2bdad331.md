# ❖ **EXAMPLES**

```
Add an ACE setcifsacl -a "ACL:CIIFTESTDOM\user2:DENIED/0x1/D" <file_na>
setcifsacl -a "ACL:CIIFTESTDOM\user1:ALLOWED/OI|CI|NI/D" <file_na>
```

```
Delete an ACE setcifsacl -D "ACL:S-1-1-0:0x1/OI/0x1201ff" <file_na>
```

```
Modify an ACE setcifsacl -M "ACL:CIIFTESTDOM\user1:ALLOWED/0x1f/CHANGE" <file_na>
```

```
Set an ACL setcifsacl -S "ACL:CIIFTESTDOM\Administrator:0x0/0x0/FULL, ACL:CIIFTESTDOM\user2:0x0/0x0/FULL" <file_na>
```
