# RSA ALGORIRTHM

The RSA algorithm supports encrypt, decrypt, sign, verify and verifyrecover operations in general. So padding modes only support so of these operations however.

+   - **-rsa_padding_mode:mode**
+     This sets the RSA padding mode. Acceptable values for **mode** are **pkcs1** for PKCS#1 padding, **sslv23** for SSLv23 padding, **none** for no padding, **oaep** for OAEP mode, **x931** for X9.31 mode and **pss** for PSS.

In PKCS#1 padding if the ssign digest is not set then the supplied data is signed or verified directly instead of using a **DigestInfo** structure. If a digest is set then the a **DigestInfo** structure is used and its length st correspond to the digest type.

For **oaep** mode only encryption and decryption is supported.

For **x931** if the digest type is set it is used to format the block data otherwise the first byte is used to specify the X9.31 digest ID. Sign, verify and verifyrecover are can be perford in this mode.

For **pss** mode only sign and verify are supported and the digest type st be specified.

+   - **rsa_pss_saltlen:len**
+     For pss mode only this option specifies the salt length. Two special values are supported: -1 sets the salt length to the digest length. When signing -2 sets the salt length to the maxim permissible value. When verifying -2 causes the salt length to be automatically determined based on the pss block structure.
