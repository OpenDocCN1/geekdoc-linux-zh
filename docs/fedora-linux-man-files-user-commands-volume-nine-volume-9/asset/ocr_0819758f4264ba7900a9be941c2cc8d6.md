# OPTIONS

-A

Displays all of the information in the PKCS#7 signature.

-V

Verifies the digital signature.

-d [sql:]directory

Specify the database directory which contains the certificates and keys.
**signver** supports two types of databases: the legacy security databases (cert8.db, key3.db, and secmod.db) and new SQLite databases (cert9.db, key4.db, and pcks11.txt). If the prefix **sql:** is not used, then the tool assus that the given databases are in the old format.

-a

Sets that the given signature file is in ASCII format.

-i *input_file*

Gives the input file for the object with signed data.

-o *output_file*

Gives the output file to which to write the results.

-s *signature_file*

Gives the input file for the digital signature.

-v

Enables verbose output.
