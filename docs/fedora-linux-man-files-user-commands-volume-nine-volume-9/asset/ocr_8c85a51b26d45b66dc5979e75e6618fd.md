# > DESCRIPTION

**rhytox-client** is a tool for controlling an already running instance of **rhytox**. It’s useful for remote control scripting, adding specific files to the library from the shell, or printing details of what’s playing. It also has an interactive mode, useful for controlling playback remotely via ssh. Any files specified after the option argunts will be added to the library. If the `—enqueue` option is given, the files will also be added to the play queue.
