**nodescend**

Do not descend into a directory. Normally rdist will recursively check directories. If this option is enabled, then any files listed in the file list in the distfile that are directories are not recursively scanned. Only the existence, ownership, and mode of the directory are checked.

**numchkgroup**

Use the nuric group id (gid) to check group ownership instead of the group na.

**numchkowner**

Use the nuric user id (uid) to check user ownership instead of the user na.

**savetargets**

Save files that are updated instead of removing them. Any target file that is updates is first rema from file to file.OLD.

**sparse**

Enable checking for sparse (aka *wholey*) files. One of the most common types of sparse files are those produced by *(3)*. This option adds so additional processing overhead so it should only be enabled for targets likely to contain sparse files.

**-p** \<*rdistd-path*\> Set the path where the rdistd server is searched for on the target host. **-P** \<*transport-path*\> Set the path to the transport command to be used. This is normally *(1c)* but can be any other program - such as *(1)* - which understands *(1c)* command line syntax and which provides an appropriate connection to the remote host. The *transport-path* may be a colon seperated list of possible pathns. In this case, the first component of the path to exist is used. i.e. **/usr/ucb/rsh**/**/usr/bin/remsh**, **/usr/bsd/rsh**. **-t** tiout Set the tiout period (in seconds) for waiting for responses from the remote rdist server. The default is 900 seconds . **-V** Print version information and exit.
