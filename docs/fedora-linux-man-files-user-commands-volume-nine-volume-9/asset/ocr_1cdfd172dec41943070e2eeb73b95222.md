Debugging information.

**all**
All but debug ssages.

Here is a sample command line option:

```
-l stdout=all:syslog=change,notice:file=/tmp/rdist.log=all
```

This entry will set local ssage logging to have all but debug ssages sent to standard output, change and notice ssages will be sent to (3), and all ssages will be written to the file **/tmp/rdist.log.**
