# DESCRIPTION

The **rmiregistry** command creates and starts a remote object registry on the specified port on the current host. If the port is omitted, then the registry is started on port 1099. The **rmiregistry** command produces no output and is typically run in the background, for example:

```
rmiregistry &
```

A remote object registry is a bootstrap naming service that is used by RMI servers on the sa host to bind remote objects to nas. Clients on local and remote hosts can then look up remote objects and make remote thod invocations.

The registry is typically used to locate the first remote object on which an application needs to call thods. That object then provides application-specific support for finding other objects.

The thods of the `java.rmi.registry.LocateRegistry` class are used to get a registry operating on the local host or local host and port.

The URL-based thods of the `java.rmi.Naming` class operate on a registry and can be used to look up a remote object on any host and on the local host. Bind a simple na (string) to a remote object, rebind a new na to a remote object (overriding the old binding), unbind a remote object, and list the URL bound in the registry.
