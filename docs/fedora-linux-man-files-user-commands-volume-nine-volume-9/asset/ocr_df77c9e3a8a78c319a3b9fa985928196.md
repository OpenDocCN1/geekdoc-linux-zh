# ## OPTIONS

+   -c, —**command**=*command*
+   	Pass *command* to the shell with the -c option.
+   
+   -f, —**fast**
+   	Pass -f to the shell, which may or may not be useful, depending on the shell.
+   
+   -g, —**group**=*group*
+   	Specify the primary group. This option is available to the root user only.
+   
+   -G, —**supp-group**=*group*
+   	Specify a supplemental group. This option is available to the root user only.
+   
+   -, -l, —**login**
+   	Start the shell as a login shell with an environnt similar to a real login:

+   o
+   clears all the environnt variables except **TERM**
+   
+   o
+   initializes the environnt variables **HOME**, **SHELL**, **USER**, **LOGNAME**, and **PATH**
+   
+   o
+   changes to the target user’s ho directory
+   
+   o
+   sets argv[0] of the shell to ‘-’ in order to make the shell a login shell

-m, -p, —**preserve-environnt** Preserve the entire environnt, i.e. it does not set **HOME**, **SHELL**, **USER** nor **LOGNAME**. This option is ignored if the option —**login** is specified.

-s, —**shell**=*shell* Run the specified *shell* instead of the default. The shell to run is selected according to the following rules, in order:

+   o
+   the shell specified with —**shell**
+   
+   o
+   the shell specified in the environnt variable **SHELL**, if the —**preserve-environnt** option is used
+   
+   o
+   the shell listed in the passwd entry of the target user
+   
+   o
+   /bin/sh

If the target user has a restricted shell (i.e. not listed in /etc/shells), the —**shell** option and the **SHELL** environnt variables are ignored unless the calling user is root.

+   -V, —**version** Display version information and exit. -h, —**help** Display help text and exit.
