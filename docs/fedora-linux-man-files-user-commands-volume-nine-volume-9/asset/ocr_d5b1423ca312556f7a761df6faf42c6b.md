# **COMMAND SYNOPYSIS**

This is just a brief synopsis of sed commands to serve as a reminder to those who already know sed; other documentation (such as the texinfo doc) st be consulted for fuller descriptions.

# Zero-address “commands”

+   :label
+       Label for b and t commands.

+   #comnt
+       The comnt extends until the next newline (or the end of a -e script fragnt).

+   }
+       The closing bracket of a { } block.

# Zero- or One- address commands

+   =
+       Print the current line nuer.

+   a \\
+   text
+       Append text, which has each eedded newline preceded by a backslash.

+   i \\
+   text
+       Insert text, which has each eedded newline preceded by a backslash.

+   q [exit-code]
+       Imditely quit the sed script without processing any more input, except that if auto-print is not disabled the current pattern space will be printed. The exit code argument is a GNU extension.

+   Q [exit-code]
+       Imditely quit the sed script without processing any more input. This is a GNU extension.

+   rfilea
+       Append text read from filea.

+   Rfilea
+       Append a line read from filea. Each invocation of the command reads a line from the file. This is a GNU extension.

# Commands which accept address ranges

+   {
+       Begin a block of commands (end with a }).

+   blabel
+       Branch to label; if label is omitted, branch to end of script.

+   c \\
