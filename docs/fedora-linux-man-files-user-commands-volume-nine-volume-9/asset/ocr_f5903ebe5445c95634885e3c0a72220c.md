# DESCRIPTION

The **rand** command outputs *num* pseudo-random bytes after seeding the random nuer generator once. As in other **openssl** command line tools, <sub>PRNG</sub> seeding uses the file `$HOME/./rnd` or `.rnd` in addition to the files given in the `-rand` option. A new `$HOME/./rnd` or `.rnd` file will be written back if enough seeding was obtained from these sources.
