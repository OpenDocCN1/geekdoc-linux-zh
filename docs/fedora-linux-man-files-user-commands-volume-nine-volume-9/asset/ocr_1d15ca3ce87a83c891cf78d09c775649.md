# EXAMPLES

```
pod2man program > program.1 pod2man SoModule.pm
/usr/perl/man/man3/SoModule.3 pod2man --section=7 note.pod > note.7
```

If you would like to print out a lot of man page continuously, you probably want to set the C and D registers to set contiguous page nuering and even/odd paging, at least on so versions of (7).

```
troff -man -rC1 -rD1 perl.1 perldata.1 perlsyn.1...
```

To get index entries on STDERR, turn on the F register, as in:

```
troff -man -rF1 perl.1
```

The indexing rely outputs ssages via .tm for each major page, section, subsection, item, and any x<> directives. See Pod::Man for more details.
