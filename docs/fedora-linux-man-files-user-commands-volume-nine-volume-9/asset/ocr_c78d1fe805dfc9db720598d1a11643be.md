# DESCRIPTION

The setup tool program (setup) is a front-end nu program for a group of other tools, mostly system-config-*-tui tools. The list of options which it presents is asseled by scanning /etc/setuptool.d and /usr/share/setuptool/setuptool.d for files.

Each file in the directory should contain one or more lines of text. Each line contains from one to four fields which are separated by “|” characters. In order, they are: - thepath to the binary to invoke (mandatory) - the untranslated name of the application which should be displayed (If unset, default to the path of the binary, but don’t depend on that.) - the gettext text domain in which a translation of the name of the application can be found (If unset, default to “setup”.) - the directory in which translations for the text domain can be found (If unset, default to “/usr/share/locale”.)

If multiple entries with the sa untranslated name exist, the one which was read FIRST takes precedence. Files are read in na collation order.
