# Special settings:

N
set the input and output speeds to N bauds
* cols N
tell the kernel that the terminal has N columns
* columns N
sa as cols N
ispeed N
set the input speed to N
* line N
use line discipline N
min N
with -icanon, set N characters minim for a completed read
ospeed N
set the output speed to N
* rows N
tell the kernel that the terminal has N rows
* size
print the nuer of rows and columns according to the kernel
speed
print the terminal speed
ti N
with -icanon, set read tiout of N tenths of a second

# Control settings:

[-]clocal
disable modem control signals
[-]cread
allow input to be received
* [-]crtcts
enable RTS/CTS handshaking
csN
set character size to N bits, N in [5..8]
[-]cstopb
use two stop bits per character (one with ‘-’)
