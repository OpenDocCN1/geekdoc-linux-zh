# EXAMPLES

To create a hex-encoded ssage digest of a file: openssldgst-md5-hexfile.txt

To sign a file using SHA-256 with binary file output: openssldgst-sha256- signprivatekey.pem-outsignature.signfile.txt

To verify a signature: openssldgst-sha256-verifypublickey.pem\ -signaturesignature.sign\ file.txt
