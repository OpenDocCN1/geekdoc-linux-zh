# INSTALLATION

The location of the client program is a matter for individual system administrators. The following are thus suggestions only.

It is recommended that the sclient software be installed in the /usr/local/saa/bin/ or /usr/saa/bin/ directory, this directory readable by all, writable only by root. The client program itself should be executable by all. The client should NOT be setuid or setgid!

The client log files should be put in a directory readable and writable only by the user.

To test the client, you will need to know the na of a running SMB/CIFS server. It is possible to run (8) as an ordinary user - running that server as a daemon on a user-accessible port (typically any port nuver over 1024) would provide a suitable test server.
