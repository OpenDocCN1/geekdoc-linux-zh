unlock <filenum> <hex-start> <hex-len>

This command depends on the server supporting the CIFS UNIX extensions and will fail if the server does not. Tries to unlock a POSIX fcntl lock on the given range. Used for internal Saa testing purposes.

volu

Prints the current volu na of the share.

vuid <nuer>

Changes the currently used vuid in the protocol to the given arbitrary nuer. Without an argument prints out the current vuid being used. Used for internal Saa testing purposes.

tcon <sharena>

Establishes a new tree connect (connection to a share). Replaces the current tree connect. Prints the new tid (tree id). Used for internal Saa testing purposes.

tdis

Close the current share connection (tree disconnect). Used for internal Saa testing purposes.

tid <nuer>

Changes the current tree id (tid) in the protocol to a new arbitrary nuer. Without an argument, it prints out the tid currently used. Used for internal Saa testing purposes.
