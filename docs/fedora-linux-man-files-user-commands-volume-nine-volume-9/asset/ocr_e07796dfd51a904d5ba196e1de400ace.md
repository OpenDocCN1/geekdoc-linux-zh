# OPTIONS AND ARGUMENTS

**-help**
Print a brief help ssgage and exit.

**-man**
Print this command's manual page and exit.

**-exit** *exitval*
The exit status value to return.

**-output** *outfile*
The output file to print to. If the special nas “-” or “>&1” or “>&STDOUT” are used then standard output is used. If “>&2” or “>&STDERR” is used then standard error is used.

**-verbose** *level*
The desired level of verbosity to use:
1 : print SYNOPIS only 2 : print SYNOPIS sections and any OPTIONS/ARGUMENTS sections 3 : print the entire manpage (similar to running pod2text)

**-pathlist** *dirlist*
Specifies one or more directories to search for the input file if it was not supplied with an absolutel path. Each directory path in the given list should be separated by a ‘:’ on Unix (‘;’ on MSWin32 and dos).

**-formatter** *module*
Which text formatter to use. Default is Pod::Text, or for very old Perl versions Pod::PlainText. An alternative would be e.g. Pod::Text::Termcap.

**-utf8**
This option assumsthat the formatter (see above) understands the option “utf8”. It turns on generation of utf8 output.

*file*
The pathna of a file containing pod documentation to be output in usage ssgage format (defaults to standard input).
