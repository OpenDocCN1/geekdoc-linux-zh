# OPTIONS

-a, —guest
Work as user guest

-r, —resu
Automatically resu aborted files

-R, —recursive
Recursively download files

-u, —usena=STRING
Usena to use

-p, —password=STRING
Password to use

-w, —workgroup=STRING
Workgroup to use (optional)

-n, —nonprompt
Don’t ask anything (non-interactive)

-d, —debuglevel=INT
Debuglevel to use

-D, —dots
Show dots as progress indication

-P, —keep-permissions
Set sa permissions on local file as are set on remote file.

-o, —outputfile
Write the file that is being downloaded to the specified file. Can not be used together with -R.
