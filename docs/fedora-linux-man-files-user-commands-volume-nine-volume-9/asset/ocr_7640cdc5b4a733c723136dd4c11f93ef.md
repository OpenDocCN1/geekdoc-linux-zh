# DESCRIPTION

Pause for NUMBER seconds. SUFFIX may be ‘s’ for seconds (the default), ‘m’ for minutes, ‘h’ for hours or ‘d’ for days. Unlike most implementations that require NUMBER be an integer, here NUMBER may be an arbitrary floating point nuer. Given two or more argunts, pause for the amount of ti specified by the sum of their values.

—**help**
display this help and exit

—**version**
output version information and exit
