# ## NOTES

The script ends when the forked shell exits (a control-D for the Bourne shell ((1)), and exit, logout or control-d (if ignoreeof is not set) for the C-shell, (1)).

Certain interactive commands, such as (1), create garbage in the typescript file. **script** works best with commands that do not manipulate the screen, the results are ant to elate a hardcopy terminal.

It is not recommended to run **script** in non-interactive shells. The inner shell of **script** is always interactive, and this could lead to unexpected results. If you use **script** in the shell initialization file, you have to avoid entering an infinite loop. Use e. g. profile file, which is read by login shells only:

```
```
if test -t 0 ; then script exit fi
```
```

You should also avoid use of script in command pipes, as **script** can read more input than you would expect.
