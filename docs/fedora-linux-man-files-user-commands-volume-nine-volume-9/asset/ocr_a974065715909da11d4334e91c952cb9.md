# > ON-LINE HELP

Type “:help” in **Vim** to get started. Type “:help subject” to get help on a specific subject. For example: “:help ZZ” to get help for the “ZZ” command. Use <Tab> and CTRL-D to complete subjects (“:help cmdline-completion”). Tags are present to jump from one place to another (sort of hypertext links, see “:help”). All docutation files can be viewed in this way, for example “:help syntax.txt”.
