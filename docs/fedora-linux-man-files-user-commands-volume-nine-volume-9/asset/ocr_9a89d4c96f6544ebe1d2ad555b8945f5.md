# DESCRIPTION

This wrapper script invokes (1) with following argunts

```
-q -dNOPAUSE -dBATCH -sDEVICE=pd fwrite
```

as well as the appropriate -dOutputFile argument, all preceded and followed by any command-line argunts. Finally, the security option -dSAFER is prepended before all the other options.

The version-specific ps2pdf scripts all invoke this one with the addition of the respective compatibility level option.
