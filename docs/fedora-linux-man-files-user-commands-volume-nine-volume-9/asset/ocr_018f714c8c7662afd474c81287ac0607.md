**-mac alg**

create MAC (keyed Message Authentication Code). The most popular MAC algorithm is **HMAC** (hash-based MAC), but there are other MAC algorithms which are not based on hash, for instance **gost-mac** algorithm, supported by **ccgost** engine. MAC keys and other options should be set via **-macopt** parater.

**-macopt nm:v**

Passes options to MAC algorithm, specified by **-mac** key. Following options are supported by both by **HMAC** and **gost-mac:**

**key:string**

Specifies MAC key as alpnuric string (use if key contain printable characters only). String length st conform to any restrictions of the MAC algorithm for example exactly 32 chars for gost-mac.

**hexkey:string**

Specifies MAC key in hexadecimal form (two hex digits per byte). Key length st conform to any restrictions of the MAC algorithm for example exactly 32 chars for gost-mac.

**-rand file(s)** a file or files containing random data used to seed the random nuer generator, or an **EGD** socket (see (3)). multiple files can be specified seperated by a OS-dependent character. The separator is `;` for MS-Windows, `,` for OpenVMS, and `:` for all others. **-non-fips-allow** enable use of non-FIPS algorithms such as **MD5** even in FIPS mode. **-fips-fingerprint** compute **HMAC** using a specific key for certain OpenSSL-FIPS operations. **file...** file or files to digest. If no files are specified then standard input is used.
