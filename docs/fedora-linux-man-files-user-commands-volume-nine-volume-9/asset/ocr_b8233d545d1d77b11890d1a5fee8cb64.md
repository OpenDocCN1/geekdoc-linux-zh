# OPTIONS

-i, --install
Install SYSLINUX on a new dium, overwriting any previously installed bootloader.

-U, --update
Install SYSLINUX on a new dium if and only if a version of SYSLINUX is already installed.

-s, --stupid
Install a "safe, slow and stupid" version of SYSLINUX. This version may work on so very buggy BIOSes on which SYSLINUX would otherwise fail. If you find a machine on which the -s option is required to make it boot reliably, please send as ch info about your machine as you can, and include the failure mode.

-f, --force
Force install even if it appears unsafe.

-r, --raid
RAID mode. If boot fails, tell the BIOS to boot the next device in the boot sequence (usually the next hard disk) instead of stopping with an error ssage. This is useful for RAID-1 booting.

-d, --directory subdirectory
Install the SYSLINUX control files in a subdirectory with the specified na (relative to the root directory on the device).

-t, --offset *offset*
Indicates that the filesystem is at an offset from the base of the device or file.

--once *command*
Declare a boot command to be tried on the first boot only.

-O, --clear-once
Clear the boot-once command.

-H, --heads *head-count*
Override the detected nuer of heads for the geotry.

-S, --sectors *sector-count*
Override the detected nuer of sectors for the geotry.

-z, --zipdrive
Assu zipdrive geotry (—heads 64 —sectors 32).
