# DESCRIPTION

*redland-db-upgrade* converts Redland databases from the format in 0.9.11 and earlier into the new format. It st be run on each Redland database. For example if database *a* created files *a-sp2o.db*, *a-so2p.db* and *a-po2s.db* it could be converted to a new database *b* with:

redland-db-upgrade a b
