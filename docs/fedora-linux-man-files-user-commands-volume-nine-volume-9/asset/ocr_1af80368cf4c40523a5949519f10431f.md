# **UNIX GROUPS AND USERS**

Group *pulse-rt*: if the PulseAudio binary is marked SUID root, then ership of the calling user in this group decides whether real-ti and/or high-priority scheduling is enabled. Please note that enabling real-ti scheduling is a security risk (see below).

Group *pulse-access*: if PulseAudio is running as a system daemon (see —**system** above) access is granted to ers of this group when they connect via AF_UNIX sockets. If PulseAudio is running as a user daemon this group has no aning.

User *pulse*, group *pulse*: if PulseAudio is running as a system daemon (see —**system** above) and is started as root the daemon will drop privileges and beco a normal user process using this user and group. If PulseAudio is running as a user daemon this user and group has no aning.
