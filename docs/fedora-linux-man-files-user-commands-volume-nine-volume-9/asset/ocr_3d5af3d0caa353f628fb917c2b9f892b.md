# » OPTIONS

These options can also be set in the /etc/systemd/bootchart.conf file. See (5).

+   - **-h, —help**
+   
+   Print a short help text and exit.
+   - **-n, —sample N**
+   
+   Specify the nuer of samples, N, to record. Samples will be recorded at intervals defined with —freq.
+   - **-f, —freq f**
+   
+   Specify the sample log frequency, a positive real f, in Hz. Most systems can cope with values up to 25–50 without creating too ch overhead.
+   - **-r, —rel**
+   
+   Use relative tis instead of absolute tis. This is useful for using bootchart at post-boot ti to profile an already booted system. Without this option the graph would beco extremely large. If set, the horizontal axis starts at the first recorded sample instead of ti 0.0.
+   - **-F, —no-filter**
+   
+   Disable filtering of tasks that did not contribute significantly to the boot. Processes that are too short-lived (only seen in one sample) or that do not consu any significant CPU ti (less than 0.001 s) will not be displayed in the output graph.
+   - **-C, —cmdline**
+   
+   Display the full command line with argunts of processes, instead of only the process na.
+   - **-g, —control-group**
+   
+   Display process control group
+   - **-o, —output path**
+   
+   Specify the output directory for the graphs. By default, bootchart writes the graphs to /run/log.
+   - **-i, —init path**
