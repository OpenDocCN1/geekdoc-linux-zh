# ## DESCRIPTION

Sessreg is a simple program for managing utmp (5)/wtmp (5) and lastlog entries for xdm sessions.

System V has a better interface to utmp than BSD; it dynamically allocates entries in the file, instead of writing them at fixed positions indexed by position in **/etc/ttys**.

To manage BSD-style utmp files, *sessreg* has two strategies. In conjunction with xdm, the -x option counts the nuer of lines in **/etc/ttys** and then adds to that the nuer of the line in the Xservers file which specifies the display. The display na st be specified as the “line-na” using the -l option. This sum is used as the “slot-nuer” in the utmp file that this entry will be written at. In the more general case, the -s option specifies the slot-nuer directly. If for so strange reason your system uses a file other than **/etc/ttys** to manage init, the -t option can direct *sessreg* to look elsewhere for a count of terminal sessions.

Conversely, System V managers will not ever need to use these options (-x, -s and -t). To make the program easier to docunt and explain, *sessreg* accepts the BSD-specific flags in the System V enviroonnt and ignores them.

BSD and Linux also have a host-na field in the utmp file which doesn’t exist in System V. This option is also ignored by the System V version of *sessreg*.

This version of *sessreg* is built using the modem POSIX (3c) interfaces, which no longer require the slot-nuer, ttyps-file, or Xservers-file mappings. For compatibility with older versions and other operating systems, the -s, -t, and -x flags are accepted, but ignored.
