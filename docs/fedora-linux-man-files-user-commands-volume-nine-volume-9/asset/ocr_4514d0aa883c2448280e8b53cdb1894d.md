# DESCRIPTION

The **sane-teco1** library implements a SANE (Scanner Access Now Easy) backend that provides access to so TECO SCSI flatbed scanners. This backend should be considered **beta-quality** software! TECO scanners are sold under various brands like RELISYS, PLOTTECH, TRUST. This backend may or may not support yours.

The scanners that should work with this backend are:


Note that the untested scanner will not be directly supported. You should contact the author for that.

The TECO VM nuer can usually be found at the back of the scanner. It is also part of the FCC ID. “sane-find-scanner -v” will also show the scsi inquiry, and if it is a TECO scanner, the na will be there too.

The options the backend supports can either be selected through command line options to programs like scanimage or through GUI elents in xscanimage or xsane.

If you have any success with a scanner not listed here, or if you have any strange behavior, please report to the backend maintainer or to the SANE mailing list.

Valid command line options and their syntax can be listed by using

```
scanimage --help -d teco1
```

# Scan Mode

**--mode**
selects the basic mode of operation of the scanner valid choices are *Black & White*, *Grayscale* and *Color* The Black & White mode is black and white only (1 bit). Grayscale will produce 256 levels of gray (8 bits). Color will produce a 24 bits color image.

**--resolution**
selects the resolution for a scan. The scanner can do all resolutions between 1 and 600, in incents of 1.
