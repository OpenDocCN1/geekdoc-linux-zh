# > USAGE

On Unix systems invoke **ps2epsi** like this:

```
`ps2epsi infile.ps [ outfile.eps ]`
```

where “infile.ps” is the input file and “outfile.eps” is the resulting EPSI file. If the output filena is omitted, it is generated from the input filena. When a standard extension (“.ps”, “.cps”, “.eps” or “.epsf”) is used, it is replaced with the output extension “.epsi”. On DOS systems the command is:

```
`ps2epsi infile.ps outfile.epi`
```

where “infile.ps” is the original PostScript file, and “outfile.epi” is the na of the output file.
