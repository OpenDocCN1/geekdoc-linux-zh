# FILES

+   - `$HOME`/.xinirc 
+   	Client to run. Typically a shell script which runs many programs in the background.
+   - `$HOME`/.xserversrc 
+   	Server to run. The default is X.
+   - /etc/X11/xinit/xinirc 
+   	Client to run if the user has no `.xinirc` file.
+   - /etc/X11/xinit/xserversrc 
+   	Server to run if the user has no `.xserversrc` file.
