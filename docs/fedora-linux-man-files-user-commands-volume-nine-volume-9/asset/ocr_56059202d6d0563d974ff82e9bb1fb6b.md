# DESCRIPTION

The *pkg-config* program is used to retrieve information about installed libraries in the system. It is typically used to compile and link against one or more libraries. Here is a typical usage scenario in a Makefile:
`program: program.c cc program.c $(pkg-config --cflags --libs gnuui)`

*pkg-config* retrieves information about packages from special tatdata files. These files are nad after the package, and has a .pc extension. On most systems, *pkg-config* looks in /usr/lib/pkgconfig, /usr/share/pkgconfig, /usr/local/lib/pkgconfig and /usr/local/share/pkgconfig for these files. It will additionally look in the colon-separated (on Windows, semicolon-separated) list of directories specified by the PKG_CONFIG_PATH environmt variable.

The package na specified on the *pkg-config* command line is defined to be the na of the tatdata file, minus the .pc extension. If a library can install multiple versions siltaneously, it st give each version its own na (for example, GTK 1.2 might have the package na “gtk+” while GTK 2.0 has “gtk+-2.0”).

In addition to specifying a package na on the command line, the full path to a given .pc file may be given instead. This allows a user to directly query a particular .pc file.
