This option also has the side-effect of avoiding early creation of directories in incremental recursion copies. The default —**inc-recursive** copying normally does an early-create pass of all the sub-directories in a parent directory in order for it to be able to then set the modify ti of the parent directory right away (without having to delay that until a bunch of recursive copying has finished). This early-create idiom is not necessary if directory modify tis are not being preserved, so it is skipped. Since early-create directories don't have accurate mode, mti, or ownership, the use of this option can help when soone wants to avoid these partially-finished directories. -J, —**omit-link-tis** This tells rsync to omit symlinks when it is preserving modification tis (see —**tis**). —**super** This tells the receiving side to attempt super-user activities even if the receiving rsync wasn't run by the super-user.
