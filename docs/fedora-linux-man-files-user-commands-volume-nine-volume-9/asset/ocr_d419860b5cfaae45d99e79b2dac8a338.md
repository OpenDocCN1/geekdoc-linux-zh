# DESCRIPTION

The **rapper** utility allows parsing of RDF content by the **Raptor** RDF parser toolkit emitting the results as RDF triples in a choice of syntaxes. The *INPUT-URI* can be a file na, ‘-’ for standard input or if Raptor is built with a WWW retrieval library, a general URI. The optional *INPUT-BASE-URI* is used as the docunt parser base URI if present otherwise defaults to the *INPUT-URI*. A value of ‘-’ ans no base URI.
