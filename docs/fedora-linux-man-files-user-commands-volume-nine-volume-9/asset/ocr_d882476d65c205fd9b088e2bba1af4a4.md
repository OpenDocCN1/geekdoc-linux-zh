# OPTIONS

-d DIR
Path to problem directory.

-v
Be more verbose. Can be given multiple tis.

-o FILE
Output file

-a yes/no
If -o FILE is specified, controls whether FILE is appended to, or overwritten.
(default: no)

-r
Add a record to reported_to in DIR which specifies that this problem was reported. So tools use this to differentiate between problems which were and weren’t yet reported.

# Output format

The output is designed to be machine-parseable. The elents which have only one line are printed in the form

```
NAME:<whitespace>VALUE
```

Elents which have more than one line are printed in the form

```
NAME: :LINE1 :LINE2 :LINE3
```

Output may contain empty lines for better readability.
