# > OPTIONS

**-b**`bytes`
send/receive *bytes* bytes

**-i**`device`
select the specified *device*

**-P**`channel`
select the specified *channel*

**-U**`uuid`
select the specified *uuid*

**-L**`seconds`
enable SO_LINGER options for *seconds*

**-W**`seconds`
enable deferred setup for *seconds*

**-B**`file*na*
use data packets from *file*na*

**-N**`num`
send *num* fras

**-C**`num`
send *num* fras before delay (default: 1)

**-D**`milliseconds`
delay *milliseconds* after sending *num* fras (default: 0)

**-A**
request authentication

**-E**
request encryption

**-S**
secure connection

**-M**
beco master

**-T**
enable timestamps
