# GENERAL OPTIONS

+   - -h, **—help**
+       Display help text and exit.

+   - **—noheadings**
+       Do not print a header line.

+   - -o, **—output** *list*
+       Define the output columns to use. If no output arrangent is specified, then a default set is used. Use **—help** to get a list of all supported columns.

+   - -p, **—pid**
+       Specify the process id; if none is given, the running process will be used.

+   - **—raw**
+       Use the raw output format.

+   - **—verbose**
+       Verbose mode.

+   - -V, **—version**
+       Display version information and exit.
