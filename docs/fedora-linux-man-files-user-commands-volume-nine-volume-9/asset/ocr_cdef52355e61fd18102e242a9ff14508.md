# Tar Long File Nas

sclient’s tar option now supports long file nas both on backup and restore. However, the full path na of the file st be less than 1024 bytes. Also, when a tar archive is created, sclient’s tar option places all files in the archive with relative nas, not absolute nas.

# Tar Filenas

All file nas can be given as DOS path nas (with ‘\’ as the component separator) or as UNIX path nas (with ‘/’ as the component separator).

# Examples

Restore from tar file backup.tar into myshare on mypc (no password on share).

sclient //mypc/myshare """ -N -Tx backup.tar

Restore everything except users/docs

sclient //mypc/myshare """ -N -TXx backup.tar users/docs

Create a tar file of the files beneath users/docs.

sclient //mypc/myshare """ -N -Tc backup.tar users/docs

Create the sa tar file as above, but now use a DOS path na.

sclient //mypc/myshare """ -N -Tc backup.tar users\edocs

Create a tar file of the files listed in the file tarlist.

sclient //mypc/myshare """ -N -TcF backup.tar tarlist

Create a tar file of all the files and directories in the share.

sclient //mypc/myshare """ -N -Tc backup.tar *

+   -D|—directory initial directory

Change to initial directory before starting. Probably only of any use with the tar -T option.

+   -c|—command command string

command string is a semicolon-separated list of commands to be executed instead of prompting from stdin. -N is implied by -c.

This is particularly useful in scripts and for printing stdin to the server, e.g. -c 'print -t'.
