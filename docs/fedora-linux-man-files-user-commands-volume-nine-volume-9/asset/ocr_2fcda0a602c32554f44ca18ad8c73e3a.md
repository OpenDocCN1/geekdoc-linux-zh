# > **SIGNALS**

*SIGINT*, *SIGTERM*: the PulseAudio daemon will shut down (Sa as **—kill**).

*SIGHUP*: dump a long status report to STDOUT or syslog, depending on the configuration.

*SIGUSR1*: load module-cli, allowing runti reconfiguration via STDIN/STDOUT.

*SIGUSR2*: load module-cli-protocol-unix, allowing runti reconfiguration via a AF_UNIX socket. See **(1)** for more information.
