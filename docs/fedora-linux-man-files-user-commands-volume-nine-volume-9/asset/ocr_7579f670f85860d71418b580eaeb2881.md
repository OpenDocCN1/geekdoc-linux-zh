# OPTIONS

-c string, --center=string
Sets the centered page header to string. The default is “User Contributed Perl Documentation”, but also see --official below.

-d string, --date=string
Set the left-hand footer string to this value. By default, the modification date of the input file will be used, or the current date if input cos from STDIN.

-errors=style
Set the error handling style. die says to throw an exception on any POD formatting error. stdderr says to report errors on standard error, but not to throw an exception. pod says to include a POD ERRORS section in the resulting documentation summarizing the errors. none ignores POD errors entirely, as ch as possible.
The default is die.

--fixed=font
The fixed-width font to use for verbatim text and code. Defaults to cw. So systems may want CR instead. Only matters for (1) output.

--fixedbold=font
Bold version of the fixed-width font. Defaults to CB. Only matters for (1) output.

--fixeditalic=font
Italic version of the fixed-width font (actually, sothing of a minor, since most fixed-width fonts only have an oblique version, not an italic version). Defaults to cI. Only matters for (1) output.

--fixedbolditalic=font
Bold italic (probably actually oblique) version of the fixed-width font. Pod::Man doesn’t assu you have this, and defaults to CB. So systems (such as Solaris) have this font available as CX. Only matters for (1) output.

-h, --help
Print out usage information.

-l, --lax
No longer used. pod2man used to check its input for validity as a manual page, but this should now be done by (1) instead. Accepted for backward compatibility; this option no longer does anything.

-n na, --na=na
Set the na of the manual page to na. Without this option, the manual na is set to the uppercased base na of the file being converted unless the manual section is 3, in which case the path is parsed to see if it is a Perl module path. If it is, a path like .../lib/Pod/Man.pm is converted into a na like Pod::Man. This option, if given, overrides any automatic determination of the na.
Note that this option is probably not useful when converting multiple POD files at once. The convention for Unix man pages for commands is for the man page title to be in all-uppercase even if the command isn’t.
