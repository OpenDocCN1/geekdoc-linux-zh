# ## › EXAMPLES

Here are so examples of how I use rsync.

To backup my wife’s ho directory, which consists of large MS Word files and mail folders, I use a cron job that runs

    	rsync 	-Cavz	.  arvidsjaur:backup

each night over a PPP connection to a duplicate directory on my machine “arvidsjaur”.

To synchrronize my saa source trees I use the following Makefile targets:

    get:  rsync -avuzb --exclude `*~' saa:saa/  . put: rsync -Cavuzb . saa:saa/
    sync: get put

this allows to sync with a CVS directory at the other end of the connection. I then do CVS operations on the remote machine, which saves a lot of ti as the remote CVS protocolet isn’t very efficient.

I mirror a directory between my “old” and “new” ftp sites with the command:

    rsync -az -e ssh --delete ~/ftp/pub/saa nius:“~ftp/pub/tridge”

This is launched from cron every few hours.
