# DESCRIPTION

sssssh_knowhostsproxy

acquires SSH host public keys for host HOST, stores them in a custom OpenSSH known_hosts file (see the “SSH_KNOWN_HOSTS FILE FORMAT” section of (8) for more information) /var/lib/sss/pubconf/known_hosts and establishes connection to the host.

If PROXY_COMMAND is specified, it is used to create the connection to the host instead of opening a socket.

(1) can be configured to use sss_ssh_knowhostsproxy for host key authentication by using the following directives for (1) configuration:

```
ProxyCommand /usr/bin/sssssh_knowhostsproxy -p %p %h
GlobalKnownHostsFile /var/lib/sss/pubconf/known_hosts
```
