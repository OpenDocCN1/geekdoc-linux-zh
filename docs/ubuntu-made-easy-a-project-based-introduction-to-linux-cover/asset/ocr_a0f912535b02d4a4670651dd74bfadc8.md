# Streaming Music with Streamunter2

If you are an Internet radio junkie, probably no application is handier than Streamuner2 (Figure 14-10), as its name implies, an online stream tuner. It works by downloading available streams from a variety of sources, which you can easily browse. When you find something you like, just double-click the stream (or select the stream and then click the green play button at the top left of the window), and the stream will open in the player of your choice.

The default player for most streams is Audacious, but that app does not (though it is available for download from the Ubuntu Software Center), so you'll have to pick an alternative. You can make this choice the first time you run Streamunter2, since the first window you see is the settings window. In that window, change the default entries from Audacious to whatever audio player you prefer. The name of the player is usually represented by the name of the application in all lowercase letters.
