# Adding Keyboard Layouts

If you type in a particular foreign language, it might be more convenient for you to add a new keyboard layout for the language or languages you use. For example, if you type in Swedish and thus use the characters ã, ä, and ō regularly, using the appropriate keyboard layout would be easier than repeatedly using the Character Map. It is even more true if you type in Greek, Russian, Serbian, Georgian, or any other language that use a completely different alphabet. Of course, you will have to familiarize yourself with the keyboard layout, or keymap, for each language you choose, but this is a relatively easy task.

To add foreign-language keyboard layouts to your system's repertoire, here's all you need to do:

+   1. Go to the Dash, type keyboard layout, and then press ENTER.
2. In the Keyboard Layout window, click the + button at the bottom left of the window.
3. In the Choose a Layout window that then appears, select the keyboard layout you want to add, and when done, click Add (Figure 11-4).
