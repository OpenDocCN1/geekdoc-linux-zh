# $cp

You might decide that not only you want your expfile.txt file in the subfolder
y also want a copy in your home directory, where it was in the first place.
To copy expfile.txt, you can use the cp (copy) command.
The command needs know where the file you want to copy is, what it
called, and where you want to copy it, which in this case is your Home
folder. Normally you would type command_exp/sub/expfile.txt /home/username
to do this, but if you recall, you can abbreviate the /home/username portion
of the command string to /, which means the same thing. (This is an important
t to remember, because the tile is frequently used in online instructions.).
Because reducing wear and tear on the fingers is always a desirable goal, type
the following command and press ENTER:

```
cp command_exp/sub/expfile.txt ~
```

Be sure to put a space between the name of the file you are copying and
d destination (in this case, between expfile.txt and ~/).nOnce you've done this, you should have two copies of expfile.txt, one in
y Home folder and in your sub folder. Take a look to see the fruit
of your endeavors.

# $rm

When you were a kid, you may well have experienced the joy of building a
caste of LEGO bricks and then the even greater joy of tearing the whole
thing down (preferably by hurling D cell batteries at it). You will now embark
a similar move. The first tool in this nostalgic endeavor is the rm (remove)
command, with which you can trash files.

The rm command, albeit very easy and use to use, should be handled\with caution. Once you remove a file with this, there is no going
back. To play it, let's try the rm command by getting rid of that new copy
of expfile.txt that we created in the Home folder. The basic rm command
structure consists of the command itself, followed by the name of the file
you to remove. In this case, you want to remove the file called expfile.txt
located in Your Home folder. Assuming your Terminal shows you to be,
remove the file by typing rm expfile.txt followed by a tap on the of ENTER
key. The file will be gone, and gone for good.

Now, double your pleasure by getting rid of the version of expfile.txt that
located in the subfolder sub. In this case, you need to specify where the file is
it's not in the folder that the Terminal is in. Just rm command_exp/sub/
expfile.txt and then press ENTER. Oooh, very cool. Brings ya back, doesn't it?
