3. Close the settings window and then click the Save button. The window will turn gray for a little while, during which time the boot menu settings will be updated.

4. When the window returns to normal, the process is complete. From the next time you start onward, Windows will boot automatically instead of Ubuntu.

> If you apply a major update to Ubuntu at some point, you may find that Windows is no longer the default the next time you start the computer. This is because the update will have added a new entry to the boot list, causing the Windows item to slip down the list, where it won't be recognized as the default any more. To fix this, open GRUB Customizer and reselect Windows as the operating system.

> Grub Customizer lets you change the boot timeout. By default, GRUB waits for 10 seconds before loading your operating system, but I am impatient and find this too long to wait—so impatient, in fact that I changed the Timeout option (also on the General tab of the settings) to 1 so the menu is displayed only for a second. This might sound fast, but when I want to get into Windows, all I do is press the down arrow key few times while my computer starts up. GRUB stops the timer when you press a key and keeps the menu on the screen. Once that has happened, I'm free to choose the Windows option at my leisure.

Once you're happy with your revised boot timeout and/or operating system, click Save to the settings. GRUB Customizer will spend a few seconds making the requested changes, after which you can safely close the window. Restart the computer to see the updated boot menu in action.

# Linux Equivalents to Your Windows Applications

Going through the trouble of running Windows programs in Ubuntu, it's a good idea to try some of the equivalent Linux applications. More often than not, there's a native Linux program that will do exactly what you need without any of the headaches involved with running an application designed for another operating system.

First, however, have to find Linux equivalents. Luckily, plenty of websites list good alternatives to Windows software: http://www.osalt.com/ and http://www.linuxalt.com are comprehensive, for example. Or you can root around the Ubuntu Software Center, installing applications that tickle your fancy. After all, the best way is to see whether a program is to try it!

> Some Windows programs don't have direct equivalents in Ubuntu, so you might need to install a couple of programs to get functionality like that of your Windows software. In the rare cases there aren't any suitable alternatives, you can try using Wine or installing Windows on a virtual machine, which I'll talk about next.
