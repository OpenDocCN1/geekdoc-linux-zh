You should be aware that the function of the tabs can vary depending on the application you happen to be printing from. For instance, the tabs'll see when printing from the GIMP will be slightly different from those you will see when printing from Firefox. The General and Page Setup tabs will almost always be there, All that I said, I'll give you an idea of the settings that are available within some of the Print window's tabs:

+   **General** Printer selection, pages to print, number of copies, order of printing, collating
**Page Setup** Pages per sheet, scaling, paper type, paper source, output tray
**Options** Print frames, shrink to fit page, print background, headers and footers
**Image Settings** Size, resolution, at time)
**Job** Print timing (now, later, at), cover page
