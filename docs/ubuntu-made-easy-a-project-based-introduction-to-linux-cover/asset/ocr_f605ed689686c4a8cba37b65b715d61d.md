# Editing Digital Video with PiTiVi

Now that you have learned how to get your video files from camera to computer, you can view them just by double-clicking any of them and watching them in Movie Player (or any other video player). Many people, however, want to edit videos by splicing clips or cutting live movies. Others like to add transitions and other effects as well, and Kino also has some of these features, the application PiTiVi (Figure 16-10) has more of them and is generally easier to use. Like Kino, PiTiVi is available from the Ubuntu Software

Figure 16-10: PiTiVi video editor

As you will immediately see, PiTiVi lacks the bells and whistles of applications like iMovie, or to some degree, Windows Live Movie Maker. PiTiVi allow you to apply some effects and fairly basic transitions between film clips, and it does allow you to work with audio tracks. However, it lacks one of the most basic functions consumer-oriented video editor should have, titles and captions, these are promised for the future.

Limitations and peculiarities aside, the actual editing process in PiTiVi is relatively straightforward. Start with a new project and decide its name and settings (Project Project Settings). Then you add to that project, either by dragging and dropping from your Home folder to the PiTiVi window or clicking the Import clips button and then selecting the files you want to add via the Import clip window that appears. The files, now called clips, will appear in the Clip Library pane of the PiTiVi window. From that pane, you can drag the clips you want to work on the timeline below and then split the clips, delete the embarrassing or boring bits, and combine clips (Figure 16-11). Be sure to save your project as you go.
