# Customizing Your Desktop Environment: The Next Level

Now that you know what cosmetic tweaks can do to your system without outside assistance, it is time to move on to the next level so that you can tweak a bit more. There are two applications that allow you to manipulate things you can't change with the tools that bundle with your system. These are MyUnity and CompizConfig Settings Manager, both of which can be obtained from the Ubuntu Software Center. Both allow you to perform a variety of system tweaks without resorting to the command line.

> The features discussed in this section pertain to the Unity 3D environment. If you are running Unity 2D, you will find that many of the features discussed are not available.

# Customizations with MyUnity

MyUnity (Figure 9-11) focuses on appearances and behaviors of the Launcher, your windows, and other fixed graphical interface elements. You can run it from the Dash by clicking the Applications lens and then clicking the Customizer button. You can also type unity in the Dash and press ENTER.

# Changing Launcher Properties

As you can see in the MyUnity's opening tab, launcher, MyUnity allows you to change the look and behavior of the Launcher. True, some of the tweaks you were already able to accomplish via the Appearance window, such as changing icon size and autohiding the Launcher, but MyUnity allows you to do other things as well. For example, you can have drives and disks shown or not shown in the Launcher and adjust the Launcher's background transparency and icon backlighting. You can best understand the latter effects by playing around options and seeing what happens (you can just set things back to what you see in the figure here if you want to get everything back the way it was).
