## How Can I Get Back into Windows?

If you installed your system in a dual-boot configuration, with Ubuntu alongside Windows, you should see a new boot menu appear when the computer starts up. After 10 seconds, Ubuntu will boot up automatically, but you can just hit ENTER to speed up the process.

If you want to start Windows instead, use your keyboard's arrow keys to select the Windows option in the boot menu and then hit ENTER. Windows should start as normal. Take a look at Chapter 19 if you want to make Windows the default or change the boot time delay.

## Oh No, My Computer Won't Boot!

If the installation process fails, you may not be able to boot your computer. Frankly this is very rare—but if it happens to you, don't panic! There's plenty you can do to get up and running again, so flip your way to Chapter 22 for some troubleshooting advice.

## Parts of the Unity Environment

Ubuntu's Unity desktop has three observable parts: the top panel, the desktop itself, and on the left side of the screen, the Launcher. I'll discuss each of these parts, which is very useful.

### The Panel

At the top of the screen is the panel (Figure 3-3), which looks a lot like the Mac OS menu bar at first glance. Like the Mac OS menu bar, the panel contains the global menu, which displays the menus for the currently focused application (unlike in Windows or other Linux distributions where menus are connected to the window). To show the global menu, hover your mouse over the top portion of the panel, and the menu will appear to the right of title (Figure 3-4). If don't have any windows, the Desktop will appear here.

## The Desktop

The biggest part of the Unity desktop environment is the desktop itself. It is completely empty out of the box, to speak, and it is not as thoroughly utilized as it is in Windows and Mac OS systems or even in other Linux desktop environments. This is not to say that you cannot use the desktop in some the ways you might be familiar with, but as is, there are basically two things you can put there as: documents and folders. To create a folder on the desktop, right-click anywhere on the desktop and select Create New Folder. You can then drag, copy or paste, anything you want to. Of course, if you want to drag your documents or folders to the desktop, you can do that too.

## The Launcher

The most unfamiliar part of the Unity desktop environment will likely be the Launcher. The Launcher, as I mentioned earlier, is strip of icons that appears on the left side of the desktop. In some ways the Launcher functions very much like the Mac OS Dock. Out of the box, it comes with Launcher icons for some of the most commonly used, folders, and utilities. Also, just as in the Mac Dock, when you run any other application, a Launcher icon for that application also appears.
