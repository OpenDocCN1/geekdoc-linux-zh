# IRC Etiquette

There are rules and social norms to follow on IRC just as there are anywhere else. It goes without saying that you shouldn't go out of your way to offend or harass anyone, just as you wouldn't in the “real world.\ Here are a few subtle conventions that you should also be aware of:

+   **Don't shout.** Writing in ALL CAPS is the IRC equivalent of shouting all the time. There's a special place of hell for shouters; this is pretty everyone's pet peeve, and you're bound to get censured for doing it.

+   **Say things only once.** Sometimes you won't get a reply for a while, so it can be tempting to keep repeating the same message until someone acknowledges it. Repeating yourself too many times is also considered annoying. Being patient is a necessary skill on IRC because people tend to dip in out of chats sporadically rather than watching all the time. It's okay to repeat your message if you don't get a reply after 10 minutes or so, though.

+   **Don't send loads of text.** Sending more than a few lines of text at once is flooding. It you should avoid doing it. If you have lots of text that you want people to read, use a service like http://pastebin.com/ to hold the text and simply post a link to it on IRC.

+   **Stay on topic.** There are different channels for purposes, so you should try to stick to the topic for which a particular channel is intended. Advertising is considered to be off-topic in most channels and is particularly frowned upon.

+   **Smile for the camera.** Most of the conversations in the public Ubuntu chat rooms are logged and can be viewed at http://irlogs.ubuntu.com/. This is useful if you forget a link that someone mentioned last week, but it can be awkward if you said something that you shouldn't have. As a general rule, never post any sensitive or personal information on IRC (especially your password or credit card details), because it could come back to bite you.

# More Help with IRC

I hope this expedition into IRC hasn't put you off for life! Lots of people find it confusing at first, but it's a really great way to talk to other Ubuntu users you're comfortable with. If you feel need to hone your IRC skills, the IRC Help website at http://www.irhelp.org/ is a very useful resource. And if that still doesn't get you into the IRC vibe, you can try a more familiar web interface to the Ubuntu IRC channel, which can be found at http://webchat-reenode.net/?channels=ubuntu.
