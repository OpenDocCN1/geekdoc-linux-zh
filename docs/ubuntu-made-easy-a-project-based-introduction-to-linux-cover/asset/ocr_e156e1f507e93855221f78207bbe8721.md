```
tar -cvf pics4pals.tar photos
```

As you no doubt noticed, there are some flags after the tar command in string. The c tells the tar program to create a new archive. The v tells the program to be verbose or, in words, to tell you what it is doing in the Terminal as it is doing it. The f tells the program that follows is the file information.

If after creating the archive, you suddenly remember that there is one more file you want to add to the mix, you can use the -f flag to append the archive.
For example, to add a file called cranky.png to the archive, you would type the following and then press ENTER:

```
tar -rvf pics4pals.tar crank.png
```

Of course, chances are that you will be doing more tarball extracting than creating, so you no doubt want know how to do that. Fortunately, the process is pretty similar to what you do when creating the tarball. The main difference is in the first flag. Rather using the tar command with the -x flag, you would use it with the -x flag, which tells the tar program to extract the specified archive. If you want to extract a tarball called spicyfood.tar, you would type the following command and press ENTER:

```
tar -xvf spicyfood.tar
```

What you have been doing far is creating and extracting archives, which are basically collections of files. In fact, most tarballs you will find are compressed, and you can tell that by the ending tar.gz. That means the archive was compressed using the gzip program. Extracting a compressed tarball is just as easy as extracting a straight archive; all you have to do is add the -z flag, which tells your system to use the gzip program to decompress the archive. For example, if you want to extract a compressed tarball called gosedown.tar.gz, type the following command and enter:

```
tar -zvf gosedown.tar.gz
```

Well, now that you know how to decompress and extract a gzipped tarball, you probably want to know how to create one. This is again, little different than creating the archive itself; you would use the -z tag to tell the program to use gzip to compress the folder. For example, to create a compressed version of your Pictures folder, we'll call tightpics.tar.gz, you would type the following and press ENTER:

```
tar -czvf tightpics.tar.gz Pictures
```
