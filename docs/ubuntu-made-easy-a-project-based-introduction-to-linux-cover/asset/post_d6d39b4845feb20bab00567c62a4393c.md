## Navigating a Sea of Open Windows

Once you get down to really using your system rather than just learning about it, there will be times when you have a few apps and a lot of windows open at the same time. When it's only a couple of windows you want to arrange more neatly, you can just drag one window to either resize itself to fit into that area. You can do the same for the other window, making it easy to work with both items by side by side.

However, when you're using several applications and different windows at once, it can get confusing to figure out what's running or even where a window is, buried among what seems like a hundred others. In this case, the Launcher can come in handy—it's not only for starting up frequently used apps but also great for switching applications or windows.

To help with this, the Launcher has a system of indicators that let you've got open and running. When any Launcher item is running and its window is the one currently *focus* (meaning it is the application window currently in active use), a small arrow will appear to the right of the Launcher icon for that item (as you see for the home launcher in Figure 3-17). The window for an open or running Launcher item is not focused, an arrow will appear to the left of its Launcher icon (as you see for the LibreOffice Writer icon in Figure 3-17). If more than one application is open, with focus or not, dash marks appear to the left of the shortcut button instead of an arrow—two marks if two windows are open and three or more windows are open (also shown in Figure 3-17). Of course, if a Launcher item is not running or open, no marks will appear on either side of that Launcher icon.

Switching between different applications is easy enough to do by clicking the icons for the application you want to switch to. You can also do this from your keyboard by repeatedly ALT-TAB until you get to the application you want to use.

Yet another way to switch applications (or start an application that isn't currently running) is to hold down the Windows key. After a second or so, the icons on the Launcher will become numbered, and you can then switch to the application by pressing the number on your keyboard that corresponds to it. If more than one window of application is open, the most recently used window will gain focus.

Even when you've gotten to the application you want, you might still not be in the right place—want to deal with that moment. For example, let's say you have six manager windows open and they're all piled on top of another. The one with focus is Documents, but you are looking for the one with your photos of trip to Cyprus last summer. You could wade around with your mouse, dragging windows out of the way until you find the one you're looking for.

A slightly easier way of going about this is to click any one of the windows to give it focus, and then repeatedly press ALT TAB (on most keyboards, this is the key with the accent grave and tilde symbols) until you reach the window you want. Alternatively, you can find the window in a more direct manner by clicking the Launcher icon for your application (in this case home button) once more, after all the open windows related to the application that Launcher icon will appear at once (Figure 3-19). You then just click the window you want to go to.

It is also possible to see all of the windows currently open, not just for a particular application, at the same time. To do this, press the Windows and W keys. If you want to hide all of the windows so you can see the desktop itself, press CTRL-ALT-D.

## Why Doesn't My Desktop Look Like That?

If your desktop doesn't look exactly like the screenshots in this chapter, it likely means that Ubuntu automatically started you in what is called fallback mode. Fallback mode is an environment that is simpler in appearance and less demanding of hardware. It is also referred to as 2D mode. In case you're wondering which mode you are in, the clearest way is the Dash button. If the Dash button is a dark charcoal-gray with a white Ubuntu logo, then you are in 2D mode.

Ubuntu defaults to fallback mode when your hardware, particularly your video card, does not have what Ubuntu needs to run Unity, which is fairly demanding of graphics hardware. Possibly your card is too old or too new or just too underpowered, the drivers your system need to use the card to its full potential may not be installed. You can check if drivers are available for your machine by clicking the **System Settings** in the Launcher. When the System Settings window appear, click **Additional Drivers**. The Additional Drivers window (Figure 3-22) will appear and let you know if there are any drivers available for you to install. If there are, make any selection you are recommended to make and click **Activate**.
