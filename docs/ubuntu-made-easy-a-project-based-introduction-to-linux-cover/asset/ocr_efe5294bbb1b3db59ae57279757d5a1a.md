# 8B-3: Creating a LocalApps Folder for pyWings

As mentioned earlier, you will be installing the pyWings locally in your Home Folder. Installing a program locally means that you are installing the program and all its support and data files in your Home Folder. This makes a bit easier, but it also means that the program will not be available to other users. It also means that if you're not careful, you might inadvertently delete it.

To make things a bit easier and safer, you are going to create a folder in your Home folder in to place pyWings and all other applications that you may install locally on your machine in the future. You, will logically enough, call the folder LocalApps.

Let's make the folder using a command in order to get some more practice. Go to the Terminal, make sure you are in your Home folder, type the following command, and then press ENTER:

```
mkdir LocalApps
```
