The collection of artwork that comes with LibreOffice is mostly geared toward web pages, but other art clip is available elsewhere. For example, you can find a great collection online at http://www.openclip.org/. Everything is in the public domain, so it is all free to use. Be sure to check out the "Game baddies" collection—it's one of my favorites.

Adding these (or other graphic) files to the Gallery is relatively easy. First create a new theme (called a *theme*) for each group of images you want to add. To create a Gallery theme of your own, click the **New Theme** button in the Gallery window. This will open the Properties of New Theme window, where you should give your theme name. Once you have done that, click the **Files** tab and then the **Find Files** button. From there, you can navigate to the folder where you are storing your clip art, photos, or other graphics. Once you have found the folder, click the **OK** button, after which a list of all the files in that folder will appear in the Properties of New Theme.

From this, you can easily add images to your new Gallery theme by clicking the name of each image you want to add and then clicking the **Add** button. You might want to make sure the box next to the word Preview is checked to make things a bit easier. Once you have done that, a copy of the image will immediately appear in the Gallery browser in your theme, where it will remain for future use (Figure 12-7).
