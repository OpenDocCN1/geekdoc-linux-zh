# What Is Source?

To get started, it is probably a good idea to understand what source is so as to understand a bit about how a program actually metamorphoses from a primitive state on the programmer's computer into an up-and-running application on your machine. First the programmer writes a program in programming language. You have probably heard of programming languages such as BASIC or C, and there are many others. The program actually writes with such a language is set of instructions called the source code, or source.

Your computer, however, cannot understand any of that source on its own as if the computer speaks ancient Greek and the source is all written in French.

The various languages that programmers use are called high-level languages—they are relatively easy for programmers to read. The computer, on the other hand, understands only low-level languages, which are quite difficult for most mortal programmers to deal with. To convert the high-level instructions into a low-level language, the computer needs some other program to translate. To put it another way, the computer needs an interpreter.

If this translation takes place while a program is running, the translator is actually called an interpreter. Applications that run scripts, the PyWings and Briscola applications earlier in this chapter are examples of script applications.

The problem with such scripts is that they can be slower than most of the applications you're familiar with—the computer must run an interpreter, interpret the source code, and run the application all at the same time. This is like having a French book translated into Greek by a live interpreter; it is very slow indeed.
