# Sharing Files with Windows Users on Your Network

One of the main reasons for connecting to a network (apart from accessing the Internet) You may be familiar with this concept already; network shares are used in many workplaces, and you may have set up one before your home network. For the uninitiated, a network share is a folder on another computer that you can access if it were on your own. Files are transferred around on the network, so there's no need to use a portable hard disk or flash drive to get them from one place to another.

# Accessing Files on a Windows Computer

Network shares are a two-way thing: You can share your files with others by creating a shared folder or access existing shared folders created by other people. If you're connected to a network of Windows computers, then you probably have some network shares already. I talked about browsing network shares in depth at "Using Nautilus as a Network Browser" on page 106, but to save the anguish of flipping back so many pages, here's a quick outline of what you need to do to access a share from Ubuntu:

+   1. Open Nautilus by clicking its orange folder in the Launcher. Click Browse New Network in the Network section of the sidebar and double-click Windows Network to see a list of all the Windows computers connected to the network. Double-click one of computers to see its shared folders. If no computers are listed, try opening one of the folders with a network icon on the front (like the one in Figure 19-14) and look for computers in there instead.
