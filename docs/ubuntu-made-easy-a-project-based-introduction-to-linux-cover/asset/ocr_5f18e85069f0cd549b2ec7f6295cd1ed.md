# Changing Themes

Finally, the themes tab (Figure 9-16) brings about the most dramatic visual effects. Selecting from the various themes and icons in the two columns allows you to change the overall look of your system by changing the window borders and icons used. Just click the theme you want to try, and the changes will take place within seconds; see an example in Figure 9-17. The same is also true for the icon sets. Click a set and then take a look at file manager window to see the effects. If you want to get back to the ways things, just remember that the default theme is called Humanity and the default icon set is called Ubuntu-mono-dark.
