# 20B-2: A Graphical equivalent to the shred command

Using the shred command isn't all that difficult, most users would prefer to do things graphically. After all, you don't have to type commands to delete or remove a file, right? That's where BleachBit comes in. BleachBit (2-9) is an application that helps guard your privacy in a number of ways—let shred all of things for you. Here are the steps you need to follow to shred a file:

+   1. Install BleachBit from the Ubuntu Software Center. When installation has finished, open it up via the Dash.
2. When the BleachBit window opens, you'll be greeted by a preferences window. The defaults are good enough for our purposes, just click Close.
3. Assuming you don't want to do any fancier, let's shred a single file. Click File ▸ Shred Files and choose the file you want to shred (hold CTRL to select multiple files). Take care not to select the wrong file, since you won't be able to recover it post-shredding! Click Delete. You'll be asked to confirm the deletion. This is the point of no return, if you're happy to proceed, click Delete to finish the job.
4. The file will vanish, shredded into oblivion and safe from recovery.

As mentioned, there's a lot more that you can do to guard your privacy with BleachBit, aside from shredding the old file. The list on the left of the main BleachBit window contains all sorts of weird and wonderful ways of deleting some of the personal information that's plainly lurking on your computer. Take Firefox, for example: Click the Firefox list item in the BleachBit, and an information page will appear in the main pane, telling how BleachBit can securely remove various information kept by Firefox.
