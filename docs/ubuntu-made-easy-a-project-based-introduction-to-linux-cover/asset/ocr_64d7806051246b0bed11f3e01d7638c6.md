+   4. Check the Available to all users option at the bottom of the screen and click Save.

+   5. Type your password when prompted. The network will disconnect, and you may need to reconnect by using the Network icon on the top panel again (see Chapter 4 for further details on connecting).

+   6. Log in to a different user account. You should now be able to connect to the network in your user account.

# Games/Unity Doesn't Work: Installing Accelerated Graphics Drivers

If you can't get Ubuntu's swoosy default interface "Unity" to work or if a certain game doesn't run, you might need to install some accelerated graphics drivers. This is because only basic drivers (which can't handle effects and 3D) are installed for some graphics cards by default, due to the lack of availability of suitable open source alternatives. If accelerated drivers exist for your card, you can install more powerful (but less open source) by opening Hardware Drivers from the Dash, selecting the graphics from the list, and then clicking Activate to install. Once it's installed, restart the computer, and the new driver should be enabled.

You can directly download Linux graphics drivers from manufacturers. These tend to be updated more regularly than the ones that come with Ubuntu, and they may have some extra features too. The next couple of sections cover how to get these drivers from the two biggest manufacturers, ATI/AMD and NVIDIA.

# ATI/AMD Cards

+   1. Go to http://support.amd.com/us/gpudownload/Pages/index.aspx, answer the questions about which model of card you have, and then select Linux x86 from the list of operating systems (Step 4 on page).

+   2. Click Display Results, and you'll be taken to a download page for the driver. Click Download and, and when prompted, click Save File to download the driver.

+   3. When the download finishes, the driver file. and its name should end with .run.

+   4. Open a Terminal and use cd Downloads (followed by ENTER) to change to your Downloads folder (if it's stored in there).

+   5. Now type chmod + amd-driver*.run and press ENTER to make it possible to run the file as a program.
