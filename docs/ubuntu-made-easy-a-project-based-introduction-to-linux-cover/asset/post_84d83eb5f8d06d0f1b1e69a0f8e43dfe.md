# Editing Digital Video with PiTiVi

Now that you have learned how to get your video files from camera to computer, you can view them just by double-clicking any of them and watching them in Movie Player (or any other video player). Many people, however, want to edit videos by splicing clips or cutting live movies. Others like to add transitions and other effects as well, and Kino also has some of these features, the application PiTiVi (Figure 16-10) has more of them and is generally easier to use. Like Kino, PiTiVi is available from the Ubuntu Software

As you will immediately see, PiTiVi lacks the bells and whistles of applications like iMovie, or to some degree, Windows Live Movie Maker. PiTiVi allow you to apply some effects and fairly basic transitions between film clips, and it does allow you to work with audio tracks. However, it lacks one of the most basic functions consumer-oriented video editor should have, titles and captions, these are promised for the future.

Limitations and peculiarities aside, the actual editing process in PiTiVi is relatively straightforward. Start with a new project and decide its name and settings (Project Project Settings). Then you add to that project, either by dragging and dropping from your Home folder to the PiTiVi window or clicking the Import clips button and then selecting the files you want to add via the Import clip window that appears. The files, now called clips, will appear in the Clip Library pane of the PiTiVi window. From that pane, you can drag the clips you want to work on the timeline below and then split the clips, delete the embarrassing or boring bits, and combine clips (Figure 16-11). Be sure to save your project as you go.

Once done with your editing, you can produce your new film by clicking the **Render** button, after which a Render window will appear. In that window, click the **Choose File** button and give your new film in the **Choose file to render**. This will be the name of the actual file that will be produced. Once done, click **OK** and then click the **Render** button. The progress of the rendering process will be shown in the Render window, and when it is done, the words **Rendering Complete** will appear. You can then close the Render window and PiTiVi as you'll. Be sure to save your project when prompted to do so.

For more detailed information on using PiTiVi, have a look at the manual, which is available from the PiTiVi site at http://www-pitivi.org/.

If you are interested in yet another alternative video/DVD player, you can try GNOME MPlayer, which has long had a significant followings because of its ability to handle multiple video formats.

## 17A-2: Installing Some Linux Classics: Frozen Bubble, Tux Racer, and Pingus

Other games might be called Linux classics, either because they're Linux originals or because they are penguin themed, in honor of Linux's cuddly penguin Tux. One of the most well-known and well-liked of these is Frozen Bubble (Figure 17-4). Frozen Bubble qualifies as the ultimate Linux classic: It was written for Linux, it's Linux (penguin) themed, and Linux versions are always released first. It has since been ported to Mac OS, Windows, and even iPhone and Android systems, but Frozen Bubble's soul is pure penguin.

The objective of Frozen Bubble is simple: Clear the screen by matching colored bubbles so you can move to the next level. This might sound boring, but never fear—you'll be hooked in time.

Another Linux-themed game you might be interested in is Pingus (Figure 17-5), a traditional maze game based on the classic Lemings. Your goal is to lead your group of adorable little penguins safely to the end of each level, without letting them dashed to bits on the dangerous obstacles awaiting them. The game includes 22 playable levels, and if you're feeling adventurous, you can try some of the untested levels—there are more than 200 of them! For instructions on these extra levels, visit http://pingus.seul.eu/faq.html.
