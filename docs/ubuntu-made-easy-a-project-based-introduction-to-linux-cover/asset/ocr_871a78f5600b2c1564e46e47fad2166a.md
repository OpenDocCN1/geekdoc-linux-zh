If you want to install a single package without heading over to the Ubuntu Software Center, you can do so by typing sudo apt-get install package-name. For example, if you want to download and install the Shfflepack clone, Tuxpuck, you would type sudo apt-get install tuxpuck. If you eventually get annoyed with Tuxpuck after having installed it many times, you can uninstall it by typing sudo apt-get remove tuxpuck.

Finally, bearing in mind all warnings offered in Chapter 6, if you want to upgrade your entire system by the command line, you can do so by typing sudo apt-get dist-upgrade (but only after doing a sudo apt-get update first).

# $ finger

If you enjoyed discovering who you are the whoami command early in this chapter, you might enjoy finding out even more about yourself using the finger command. You can use the finger command in a number of ways, but a very simple one is finding out about a particular user. In order to try it out, you have install finger first, since it is no longer bundled with Ubuntu.

This is an excellent chance to get some practice with the apt-get command you just learned. Open a Terminal, type sudo apt-get install finger, and press ENTER. Once you've typed your password and be ready to try finger out. Just type finger and your username. In case, that would be finger rg. Once you've typed the command, press ENTER and see what you get. You can see my results in Figure 8-8.

No mail.
No plan.
rg@mysktop:-$
