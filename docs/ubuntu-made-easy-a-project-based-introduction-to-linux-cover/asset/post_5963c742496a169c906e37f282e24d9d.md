
# Read-Only Support

If all you want to be able to read web pages or documents in a foreign language, you don't need to install any additional language support, except in some cases. From the get-go, you will be able to view documents in just any language you happen to throw at your system—it doesn't matter if it's Swedish, Italian, Chinese, Japanese, Arabic, Hebrew, Russian, Vietnamese, Armenian, or Thai. You will be able to read whatever you are linguistically capable of reading (see Figure 11-1 for an example).

![](img/d35fa962e6f9664d66dc83916f426418_237_0.png)

Almost all web browsers these days can automatically recognize the language in which a web page is written and thus display the page correctly. Sometimes, the author of the page may neglect to include the character coding for that page in the HTML, in which case your web browser, knowing that the page is prepared in another language, will open it in the default language of your system. The result is you see nothing but combinations of symbols and letters that have no meaning. In such cases, try changing the character coding in your browser to the language encoding you believe the page is in. Some languages employ more than one encoding scheme, so if you're not sure which one the page is prepared in, give each possibility a try. In Firefox, you can make your choices by selecting **View Character Encoding**. From the submenu, you can select the appropriate encoding for the language of the page.

# Typing Nonstandard Characters

Typing characters that are not standard in English, such as é, ç, ß, θ, æ, and ã can be done quite easily in Linux without any modifications. In situations, you can do this by using the Character Map utility included in your system, you can be found by going to the Dash, typing character map, and pressing ENTER. Alternatively, from the Dash you can click the Applications lens and then the Accessories filter button. When you run Character Map, a window like the one shown in Figure 11-2 will appear.

![](img/d35fa962e6f9664d66dc83916f426418_238_0.png)

Figure 11-2: Inputting characters with the Character Map utility

To input the character you want, select the language or character set in the left pane of the window and then, in the right, double-click the character you want to input. The character will appear in the little input box next to the Text to copy at the bottom of the window. Just click the Copy button and paste the character into whatever application you want to it in.

LibreOffice offers a method of its own, which you can also use. In the menu bar, select Insert > Special Character. A selection window will open, and you can select the character you want there. Once you've done that, click the OK button, and the character will appear in your document, after the selection window will close by itself. Double-clicking the character you want will accomplish the same thing.

# Using the Compose Key Option

If you need to type an accent or umlaut once in a while and don't feel particularly keen on opening an application or going to a special menu to do, using the compose key option for your keyboard is a good way to go. Basically this means you must use of the lesser-used keys on your keyboard in conjunction with six symbols (´, ´, ~, ^) to help in the creation of accented characters.

Before you can use this feature, you have to select which key you want to use as your compose key. For this example, I'll use the ALT key, since most people don't use it much. Here's what you need to do:

1. Go to the Dash, type keyboard layout, and press ENTER.
2. In the Keyboard Preferences window that appears, click the Options button.
3. The Keyboard Layout Options window will now appear. In that window, click Compose key position.
4. Check the box next to the key you want to use as your compose key (that is, Figure 11-3). Then close the Keyboard Layout Options window and the Keyboard Preferences window.

![](img/d35fa962e6f9664d66dc83916f426418_239_0.png)

Figure 11-3: Selecting your compose key

Once you've done that, you can use your compose key to type those characters. Let's say, for example, that you want to type an unumlaut u (that is, ü). While pressing the right ALT key (or whatever you selected as your compose key), you'll release the right ALT key, type u, and voilà—you'll have yourself an ü! Here are some more examples:

- á right ALT-' then a
- ç right ALT-, then c
- é right ALT-' then e
- ñ right ALT-' then n
- ó right ALT-^ then o

NOTE These sequences are based on US keyboard layouts. Combinations for other layouts may differ.

# Adding Keyboard Layouts

If you type in a particular foreign language, it might be more convenient for you to add a new keyboard layout for the language or languages you use. For example, if you type in Swedish and thus use the characters ã, ä, and ō regularly, using the appropriate keyboard layout would be easier than repeatedly using the Character Map. It is even more true if you type in Greek, Russian, Serbian, Georgian, or any other language that use a completely different alphabet. Of course, you will have to familiarize yourself with the keyboard layout, or keymap, for each language you choose, but this is a relatively easy task.

To add foreign-language keyboard layouts to your system's repertoire, here's all you need to do:

1. Go to the Dash, type keyboard layout, and then press ENTER.
2. In the Keyboard Layout window, click the + button at the bottom left of the window.

# Chinese, Japanese, and Korean Input

For most European languages (and many other alphabet-based languages), pressing a letter on the keyboard simply prints that letter to the screen. However, Chinese, Japanese, and Korean require a kind of conversion process, which is handled by a special application (actually a set of applications) called an input method editor (IME). Each of these languages has its own IME, and each is quite different from the basic differences in the three writing systems.

# Chinese

Although most people (at least in linguistics) would think that Chinese would be the most complicated system, because the writing system consists of thousands of characters, it is in fact the simplest. The Chinese IME simply takes the Romanized keyboard input, known as pinyin, and converts it into Chinese characters, or hanzi. The IME, it is essentially a simple dictionary lookup task—big dictionary, simple IME. In the event that there is more than one character for the pinyin input, a list of candidates will appear, and the user simply selects the appropriate character from that list, as shown at top of Figure 11-7. At the sentence level, the Chinese IME now has predictive capabilities with which it can guess which character you intend to type based on the context of what you've typed so far, at the bottom of Figure 11-7.
