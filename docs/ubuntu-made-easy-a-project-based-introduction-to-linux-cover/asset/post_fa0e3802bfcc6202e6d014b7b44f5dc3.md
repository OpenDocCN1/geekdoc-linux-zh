Encryption is a way of taking a file and scrambling it in such a way that only a person with the right decryption key will be able to recover the original information. ## 20A-1: Encrypting an Encrypted File

Ubuntu has a nice way of encrypting files, but you should take care when using it! The whole point of encrypting your files is that no one but you will be able to access them, so there's little chance of recovering them if you forget your password. Here are the steps you need to follow to encrypt:

- 1. Open the Ubuntu Software Center and search for install encryptfs-utils.
- 2. Once installation has completed, open the Dash and search for Terminal. When the Terminal window appears, type encryptfs-setup-private and press ENTER.
- 3. You'll be prompted for the password that you use to log in to Ubuntu. Type it and press ENTER (The letters won't show up on the screen, that's normal.)
- 4. You'll be asked to enter a mount passphrase (password). Pick something very memorable—there's no recovering this if you forget it! Press ENTER, retype the password (to make sure there were no typos), and press ENTER.
- 5. Close the Terminal window, log out of your user account, and log back again.
- 6. When you log in, an Update information window will appear (Figure 20-6). Click Run this action now, type your login password into the window that appears (it will look as if nothing is being typed), and press ENTER.

> The Update information window may not appear when you log in. If this happens, restart your computer and then log in—it should pop up this time.

Your password (also referred to as encryption passphrase) will be displayed on the screen. Make a careful note of it, press ENTER, and then click Close in the Update information window to continue.

If you have your Home folder, you'll now see a folder called Private. Anything you put in this folder will be encrypted and will be safe from prying eyes. This is especially useful if your computer gets stolen—only someone with your mount password will be able to look at the files, and ideally the only person who knows it is you!

## 20A-2: Recovering Encrypted Files If Something Goes Wrong

If you have problems with your computer and need to recover the files in the encrypted *Private* directory, use the following steps after Ubuntu up and running again. If you don't feel confident following these instructions, you should definitely ask for advice on the Ubuntu forums.

- Open a Terminal, type `sudo mount -t cryptfs /home/username/.Private /home/username/Private` (note the period in the first path) and press ENTER. You should, of course, replace `username` with your own username.
- You'll be asked for your passphrase. Type your passphrase (password) and press ENTER.
- Now you'll be prompted a few times to make a selection. Hit ENTER a few times until you get a WARNING message.
- Type **yes** and press ENTER; type **no** and press ENTER.
- If you entered the right mount password, the *Private* folder will be decrypted, and you'll be able to access your files. Copy them from that to somewhere safe!

If you have no luck recovering your files, take a look at `https://ubuntu.com/community/EncryptedPrivateDirectory/` to see whether there's anything further that you can try.

## Project 2B: Shredding Documents Digitally

Although most people are satisfied with deleting their files when they no longer need them, they may not realize that the deleted file is still retrievable. This may pose little concern when it comes to photos of your summer trip to Maryland or reports you may have written for a class on Thai cooking, but it is a completely different situation if you were been storing account details or other confidential information on your hard disk. Even if the data stays—that is great news if you want to retrieve any files you may have accidentally deleted (or formatted away), but it isn't such good news if your computer gets lost or is thrown away. In preparation for such cases, it might not be a bad idea to do some digital shredding.

## 20B-1: Trying the shred command

Digital shredding in Linux is done with the shred command. Its usage is similar to the rm command you learned to use in Chapter 8, though in terms of removal, shred is much more thorough. To do it away, create a dummy file by going to the File menu of a Nautilus window and selecting New Document > Empty Document. The new document myShredExp.txt this will open edit. Type a couple of sentences in the document—anything will do—save it. The first couple of words you typed should now appear on the icon of the new dummy file you created (as shown in the example of Figure 20-7).

Using the shred command isn't all that difficult, but take care not to select the wrong file, since you won't be able to recover it post-shredding. ## 20B-2: A Graphical equivalent to the shred command

Using the shred command isn't all that difficult, most users would prefer to do things graphically. After all, don't have to type commands to delete or remove a file, right? That's where BleachBit comes in. BleachBit (2-9) is an application that helps guard your privacy in a number of ways—let shred all of things for you. Here are the steps you need to follow to shred a file:

- 1. Install BleachBit from the Ubuntu Software Center. When installation has finished, open it up via the Dash.
- 2. When the BleachBit window opens, you'll be greeted by a preferences window. The defaults are good enough for our purposes, just Close.
- 3. Assuming you don't want to do any fancier, let's shred a single file. Click File ▸ Shred Files and choose the file you want to shred (hold CTRL to select multiple files). Take care not to select the wrong file, since you won't be able to recover it post-shredding! Click Delete. You'll be asked to confirm the deletion. This is the point of no return, if you're happy to proceed, click Delete to finish the job.
- 4. The file will vanish, shredded into oblivion and safe from recovery.

As mentioned, there's a lot more that you can do to guard your privacy with BleachBit, aside from shredding the old file. The list on the left of the main BleachBit window contains all sorts of weird and wonderful ways of deleting some of the personal information that's plainly lurking on your computer. Take Firefox, for example: Click the Firefox list item in BleachBit, and an information page will appear in the main pane, telling how BleachBit can securely remove various information kept by Firefox.
