# Bugs, Bugs, Glorious Bugs

The bugs of yesterday were enormous, complicated blasts, filling entire rooms with delicate electronics and whirling tape rolls. Renowned computer scientist Grace Hopper, on retrieving a moth from a relay in such giant, tapped the offending insect into her logbook and remarked that she had found a “bug” in the computer. Well, computers may have changed a lot since the 1990s, but the terminology hasn’t. Whether it’s as major as a program crashing or freezing or as minor as an missing icon, any problem that you found with a piece of software is still referred to as a bug.

You’ve almost certainly encountered a bug before—software, whether commercial or open source, is perfect. The difference with open source is that you’re strongly encouraged to report problems where you see them. Developers need free feedback in the form of bugs so they know what needs fixing, and problems get fixed more quickly if they’re reported sooner. Filing a bug report is a relatively easy way of giving something back to the community; it doesn’t take long, it helps to improve the software for everyone, and you get an annoying problem fixed for free!
