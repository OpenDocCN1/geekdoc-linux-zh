You may be thinking that the Dash sounds like Ubuntu's answer to the Windows Start button, and in some ways you would be right, though working with it is different and its abilities are greater.

# Finding and Running Apps with the Keyboard

Using lenses and filters is one way to find the apps you want to run; however, if you know the name of the application you want to run, you can just start typing into the search box at the top of the Dash. As you type, results will start to appear. The more you type, the more the results will be narrowed down. If the app you want to run (or document you want to open) is in the first in the list, you can simply press ENTER to open it. Otherwise, you can use your arrow keys to navigate to the target app and press ENTER to open it.

# Head-up Display

A feature similar to the Dash is Ubuntu's new Head-up Display (HUD). The idea of a head-up display is to allow users to do what they need to without taking their eyes away from their area of focus—allowing them to keep their eye on the ball, so to speak. To that end, the HUD allows you to do normally mouse-driven tasks by keyboard. Whatever application is in focus—whether it is the desktop, the file manager, Firefox, or the Terminal—pressing the ALT key will bring up a command box for that application at the top left of the screen. Figure 3-16 shows an example using Firefox. In that box, you can tell the application what you want to do, where you want to go, or what you are looking for by typing commands or keywords and then pressing ENTER.
