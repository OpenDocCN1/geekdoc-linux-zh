
If you didn't notice high CPU usage on the Resources tab, then it’s possible that something is overusing your hard disk instead. Programs that do this almost finish when they’re doing within 5 or 10 minutes, so you should probably ride it out. If the sluggishness persists, the easiest way to fix the problem is to restart the computer.

## Lost Files

Losing an important file is one of those uniquely frustrating experiences in life. If you've already looked in all of the most likely locations (like your Home folder) and have tried searching in the Dash, see if one of the following-options works instead:

- **Recent Documents**: Open the Dash and click the Files & Folders lens at the bottom of the screen to see whether the missing file is in the Recent list of recently edited files. If it was an Office document...
- **Basic search**: The Search for Files tool is only useful if you remember the file’s name. Bring up the Dash and open the Search for Files tool. In the window that appears, type part of the file name in the Name contains box and click **Find**. It might turn up in the list of search results.
- **Heavy-duty search**: The more advanced Tracker search tool can look inside documents, which is handy if you don’t remember the file’s name but you remember some of its contents. The Desktop Search application from the Software Center. Once installed, Tracker will start building its index. This could take about 15 to 20 minutes, so you might want to wander off and do something else for a while. When you come back to the computer, open the Desktop Search app from the Dash and search for your lost file. (Note that you might want to check the search settings to make sure that all of the relevant locations are being searched. You can do this using the Search and Indexing tool, which you can open from the Dash.)
- **Look in the Trash**: It’s possible that you accidentally deleted the file. Click the Trash on the Launcher and look for it in.

Another explanation for the lost file might be that it was saved in a temporary folder. This happens when you open an email attachment, for example—the file is in a temporary folder by your email client and opened using the default application for that type of file. Unfortunately, some programs do not realize that the file is temporary, and they leave you in the temporary directory… which is periodically wiped clean. If you suspect that this may have happened and you have restarted your computer since you saved the file, then it’s probably gone forever.

If you haven’t restarted, there may still be hope; try opening the (unmodified, original) file to see which folder gets stored in selecting File > Save As (or similar) in the program you’re using. Check which folder the Save window opens up to. For example, the Thunderbird mail client temporarily stores attachments that you open in the /tmp folder (see Figure 22-15 for an example). Note the name of the folder and open your Home folder in Nautilus, then, select Go Location, type the name of the temporary folder in the box that appears, and try to find your file in the folder. It's highly convenient, if you find an important file, it's worth it.

## Where Can I Go to Get More Help?

Many of the instructions in this chapter are quite general, so they may leave out the specifics that you need to get your computing properly. If you suspect that this is the case or nothing in this chapter seemed help with your problem, then seeking help elsewhere is a good idea. Ubuntu has a large and thriving online community that prides itself on being friendly and helpful. There are quite a few options for you to choose from:

- Visit https://help.ubuntu.com/ and use the search to find help guides and tutorials.
- Ask a question on the #ubuntu IRC channel (see "Chatting with IRC" on page 364).
- Ask a question on a mailing list (see "An IRC Alternative: Mailing Lists" on page 368).
- Ask a question on the Ask Ubuntu website (see "Ask Ubuntu" on page 363).
- Post a question on the Ubuntu forums (see "The Ubuntu Forums" on page 361).

From here on out, it's up to you and the Ubuntu community to figure what's going on. Good luck fixing your problem!
