# Converting Audio File Formats

As pointed out at the beginning of the chapter, there may be some points of incompatibility when it comes to certain audio file formats, your hardware, and Ubuntu. Unfortunately, SoundConverter (shown in Figure 15-8) makes it easy to convert Ogg Vorbis files to MP3, or vice versa. It can also convert AAC files to MP3 or Ogg Vorbis format, if that is of interest to you. Because SoundConverter does not come bundled with Ubuntu, you will have to install it from the Ubuntu Software Center.
