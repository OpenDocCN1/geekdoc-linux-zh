# Sending Files by Bluetooth

Send a file by Bluetooth from your computer to another Bluetooth-capable device, click the Bluetooth panel icon and select Send Files to Device. A window will appear in which you can navigate to the target file. Once you have your selection, click Select. Select Device window will then appear (Figure 7-18). Select the recipient machine and click Send. Your machine will begin transferring the file. If the recipient is set to seek permission before accepting a Bluetooth file transfer, you or the recipient will have to click a button on the recipient machine before the transfer can be completed.

Some devices might need a little setting up in order to receive files. You'll be able to tell if this is the case if you get a message that says Unable to service record after you press Send. The details depend on the type of device you're trying to send files to, but you'll be looking for an option on the device to "enable Bluetooth sharing," "allow other devices to send files," or something similar. On a Windows computer, you should find the relevant option under the Share tab of the Bluetooth Settings (accessed through the Control Panel), and on Mac OS X, the option can be found as a checkbox at the bottom of a list in the Sharing settings. Phones and other devices will keep the relevant settings in still different locations, so you might need to refer to the manual to find where the correct option is hiding. Once you've enabled Bluetooth file sharing, go back to the File Transfer window on Ubuntu and click Retry to try sending the file again.
