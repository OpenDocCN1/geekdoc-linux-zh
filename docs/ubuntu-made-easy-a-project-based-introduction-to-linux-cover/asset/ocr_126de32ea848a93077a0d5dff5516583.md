# Other Features in Rhythmmbox

Rhythmmbox includes a couple more cool features worth noting. One of these is the ability to automatically download and display the lyrics of the song you are currently playing. To use this feature, you must first activate it by going to the Edit menu and selecting Plugins. In the Configure Plugins window that appears (Figure 14-6), check the Song Lyrics box and then click the Preferences button that appears. When the Song Lyrics preferences appears, check all the boxes and click the Close button. Then close the Plugins window. After that, to start playing a track, go to the View menu and select Song Lyrics. Rhythmmbox will search the Internet for the lyrics of the track you are currently playing and display them in a separate window (Figure 14-7).
