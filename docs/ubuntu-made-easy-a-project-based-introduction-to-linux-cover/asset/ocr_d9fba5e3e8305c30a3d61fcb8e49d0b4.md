# 5-1: Downloading and Installing the ScribFire Extension

To get started with the process of installing any Firefox extension, you have first find and download one. To do this, go to the Firefox Tools menu, and select Add-ons. The Add-ons Manager tab will then appear, showing you the extensions, themes, and plug-ins you have already installed. To add the ScribFire extension, make sure that the Get Add-ons tab is selected from the left side of the window. Firefox will display some Featured Add-ons and other recommendations that you can check out or ignore as please.

ScribFire isn't one of Firefox's recommendations as I write this, and chances that it won't be when you open the Add-ons tab either. This being the case, just do a search for scribfire in the search box (Figure 5-14). Once you find it (listed as ScribFire Next), click the Install button. A download indicator will then appear.
