## Korean

The job of the Korean IME is again quite different from that of the Chinese and Japanese IMEs, because the language is written in a very different way. Korean is written either entirely in alphabetic letters, called hangul, or in combination of hangul and ideographic characters borrowed from Chinese hanja. While the hanja characters are essentially the same as their Chinese and Japanese counterparts, hanzi and kanji, the Korean phonetic alphabet, has its own unique appearance, as you can see in the Korean word for Korea, *Hangug*(k)*, in Figure 11-9.

![](img/d35fa962e6f9664d66dc83916f426418_243_0.png)

Figure 11-9: Korea (Hangug) written horizontally in hangul

This seems simple; however, the representation is not quite correct, because Korean is very distinctive in the way that its alphabetic characters are put on the page. Unlike the usual side-by-side positioning of hiragana, katakana, and most alphabets, hangul letters are grouped in pairs, triplets, or even quadruplets, which are written, as a general rule, clockwise. The IME, therefore, must take the input (usually based on a Korean alphabetical keyboard layout) while it is being typed, and it must adjust the size, spacing, and positioning of each letters as it puts them into appropriate clusters (see Figure 11-10).

## Project 11: Setting Up Asian-Language Support

So what do you do, if for, you want to be able to type Chinese, Japanese, Korean, Thai, or Vietnamese while still in your usual English environment? What if you want to be able to type all of those languages in the same document? Can you do it?

There are actually several ways of going about this, but the default method in Ubuntu is the easy-to-use Intelligent Input Bus (IBus). IBus supports East Asian languages, including Chinese, Japanese, and Korean, and it provides a number of input methods for many of these.

### 11-1: Installing IBus Input Methods

IBus is very easy, but out of the box, to speak, it comes with two input methods, both for Chinese: pinyin, used for simplified character input (the standard in mainland China and Chinese language classes around the world), and bomopofo, used for traditional character input, as found in Taiwan, Hong Kong, and overseas Chinese communities. To input other languages, you will need to install the appropriate input methods yourself. Just go to the Ubuntu Software Center and search for ibus japanese (there will be a number of methods, so I suggest trying Anthy first, ibus korean, and or ibus vietnamese.

### 11-2: Selecting Input Method Modules

Once you have installed the input method you need, you will need to start up IBus and then select the input methods you want to use. Here are the steps:

- Go to the Dash, type keyboard input, and press ENTER.
- A window will appear asking whether you would like to start the IBus daemon. Click Yes.

> A daemon is a program that runs in the background, unknown to the average user, providing a system with added functionality. In the case of IBus, that added functionality is the ability to input complex character sets.

- 3. Another window will appear, telling you what to do if you cannot get IBus to work. Click OK in that window.
- 4. The IBus Preferences window will then appear. Click the Input Method tab.
- 5. On that tab, check the box next to Customize active input methods.
- 6. Next, click the Select input method drop-down menu button, select the input method you require, and then click Add. The input method you added will appear in the main pane of the window.
- 7. Repeat the previous step for any other input methods you want to add. When done, your window should look similar to Figure 11-11, depending on which languages you selected.
- 8. When you are making your selections, click the Close button.

Once Writer appears, click in the document area and then select the input method you want to use from the IBus panel menu. You can now start typing in Writer using the input method you selected. If you do not see the characters you intended to type but instead see nonsense characters (boxes or seemingly random symbols), try using another font.
To switch from one input method to another, there are two options. First, you can go to IBus panel applet and change methods from the menu options. Second, you can switch between methods with hot combinations: CTRL-spacebar toggles IBus on and off, and ALT-SHIFT-L switches you to one input method to the next.

## Setting IBus to Automatically Start When You Log In

As you probably recall when you first opened the IBus Preferences, how to start up IBus each time you log in to your system. If you use IBus a lot and would prefer foregoing this extra step, you can easily set up your system to start it automatically when you log in.

To do this, open the Language Support window by going to Dash, typing language support, and pressing ENTER. In the Language tab of, select IBus in the drop-down menu next to the words Keyboard input method system, as shown in Figure 11-3, close the window. The next time you log in, IBus will automatically start up and be ready for action when you need to use it.

If IBus does not start automatically the next time you log in, adding it to your system's list of startup applications. To do this, go to Dash, type startup applications, and press ENTER. This will open the Applications Preferences window. In this window, click the Add button. In the Name of the window that appears, type IBus, and in the Command box, type /usr/bin/ibus-daemon -d. When done, click Add and then close the Startup Applications Preferences window.
