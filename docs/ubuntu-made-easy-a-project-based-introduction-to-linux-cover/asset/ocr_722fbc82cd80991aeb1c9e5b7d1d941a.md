# Going for a Dip

To get a taste of what Ubuntu is all about (and to check out your hardware to see whether it's all comfy-zy with Ubuntu), there is probably no better way to run Ubuntu directly from the live CD. To do this, place the Ubuntu CD in your disc drive and restart your machine. When the machine starts up, it should boot up from the CD, and after a second or two, you will see a purple Ubuntu startup screen with a couple of icons at the bottom of it. If the screen does not appear and your machine restarts, then very likely your machine's BIOS settings need to be changed to allow you to boot from a CD. You can access your machine's BIOS by restarting and then pressing whatever the onscreen instructions assign to accessing the BIOS setup. This is usually DELET, or F2, F10, F12, and ESC all common—not all machines are the same. If the onscreen information passes by fast that you miss it, you can check your user's manual to see what the correct key is.

Once you get into the BIOS setup, change the boot sequence so that your CD drive is first. To do this, you'll probably have to use the arrow keys on your keyboard to navigate between different options and the ENTER key to select them. Basic instructions on how to do this are normally onscreen. When you're finished, make sure you save your changes and restart the computer.

Once your machine boots from the live CD and you see the purple Ubuntu startup screen, either you can wait for a few seconds for Ubuntu to start booting into the live CD, or you can press a key (any key) to display a menu where you can choose your language and other settings. The default settings should suffice for your purposes, leave the keyboard untouched for a few seconds, and the screen will give way to a loading screen (all purple).

NOTE If you decide to explore this machine, you'll find that you have to make a choice as to how you proceed once you chosen a language and so forth. Select Try without installing to get back on the right track

After a couple of minutes or so, the loading screen will disappear, and in its place will come an Install window with a swoopy desktop background behind it (Figure 2-1). Click Try Ubuntu, and the Install window will give way to a desktop with row of colorful icons down the left side and the same purple background. You should now be able to use your mouse as well as the keyboard, feel free to explore. And remember, your hard disk will go untouched,you're not going to change, let alone hurt. When you get to this point, you're ready to take Ubuntu for a spin—I'll hold off on talking about that until Chapter 3.
