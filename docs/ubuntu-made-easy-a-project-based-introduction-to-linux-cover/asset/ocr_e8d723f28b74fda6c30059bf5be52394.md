Xmahjongg is available via the Ubuntu Software Center, so it's not absolutely necessary to install it in the way you are about, but doing provides a perfect opportunity to learn how to compile a program from source. The amount of source code isnt all that great, but compiling won't take too much time, and it requires no tinkering.

To get started, you will have to download the Xmahjongg source code. You can get this from the Xmahjongg project page at http://www.lcdf.org/xmahjongg/ Download the tarball xmahjong-3.7.tar or a newer version if there is one. Do not download any of the other file types available on that page.

If you prefer, you can instead download the Xmahjongg tarball by using the wget command that you learned in "8C-1: Getting Briscola" on page 148. Just open a Terminal window, type the following command:

```
wget http://www.lcdf.org/xmahjongg/xmahjongg-3.7.tar.gz
```

Once you have the file on your hard disk, untar the xmahjongg-3.7.tar.gz file. You can do this either by using the command line, as you learned to earlier in the chapter, or by double-clicking the file and dragging its contents into the appropriate folder. To make it easier for you to follow along with the directions I will give you, be sure to place the untared Xmahjongg folder in your Home folder. Then you will be ready to run.

Normally at point, you would look through the folder to find some instructions for dealing with the package, just as you did earlier the chapter for Briscola. In most source packages, this information is included in an INSTALL file, like the one in the xmahjongg-3.7 folder (Figure 8-16). To read the INSTALL file, just double-click it, and it will open in Text Editor.
