# # BLAST OFF
INTO LINUX!

Ubuntu brings Linux to the masses, but it can still be intimidating for newbies, neophytes, and geeks. With Ubuntu Made Easy by your side, you'll be ready to face any challenge, and you'll discover how fun Linux can be.

Includes a full version of Ubuntu 12.04 (Precise Pangolin). Try Ubuntu on your computer and then install it when you're ready.

Packed with tips, tricks, and helpful pointers, Ubuntu Made Easy will get you up and running fast with the world's most popular operating system. Authors Richard Grant and Phil Bill will walk you through tasks like installing and playing games, accessing your social networks, troubleshooting hardware and software problems, interacting with your Windows installation, and more.

+   * Watch DVDs, listen to music, and sync your mobile devices

+   * Create documents, spreadsheets, and presentations

+   * Work with the command line (or will it altogether?)

If you're looking for a pain-free way to learn Linux, Ubuntu Made Easy is just what you need to get started.
