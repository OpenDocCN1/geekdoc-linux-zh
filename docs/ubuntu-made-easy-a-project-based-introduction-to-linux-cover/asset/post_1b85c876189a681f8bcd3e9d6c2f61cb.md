
# Project 19C: Running Windows Programs

In Chapter 6 you learned a host of ways to add applications to your system, but you may not have considered one other method—installing Windows applications. Despite there being Linux equivalents for most of the Windows programs that you need, you may miss one or two programs. Fortunately, it is possible to run some Windows applications from within Linux with the help of a program called Wine. Wine works by fooling applications into thinking they're running on Windows. It does this by providing all of the libraries and support files that programs expect to find on Windows, without any need for Windows to be installed. The list of compatible software includes the likes of Microsoft Office, Internet Explorer, Adobe Photoshop, and a whole host of games, so if you're desperately missing a particular program, then Wine is definitely worth a look.

It is fair to point out that Wine continues to be a work in progress. It works well with some programs and not at all with others. Things are improving, and Wine now seems to work better with more applications. If you are curious about which apps are known to run under Windows and how well, check out the Wine Notepad page at http://www.winehq.org/ and click the AppDB link. The AppDB entries for programs often contain helpful advice on getting them to run in Wine, so check there first if you run into problems.

## 19C-1: Installing and Testing Wine

You can get Wine via the Ubuntu Software Center by doing a search for wine and installing the Microsoft Windows Compatibility Layer (it should be the first search result). Once the installation is complete, you can test it by opening the Dash and searching for Notepad. When the results are in, click the icon for the Notepad application (the one with a glass on it) and after a few seconds (longer the first time you use Wine), the Windows Notepad will appear (Figure 19-6).

## 19C-2: Installing a Windows Application in Wine

Now you've seen one Windows application in action under Wine, you might as well learn how you can install more yourself. I will point you to one application that will definitely work—a pretty cool text editor labeled NoteTab Light (Figure 19-7).

![](img/d35fa962e6f9664d66dc83916f426418_367_0.png)

Figure 19-7: NoteTab Light running under Wine

To get NoteTab Light, go to http://www.fookes.com/ftp/NoteTab_Setup.exe, select Save File, and click OK in the window that appears to save the file in your Downloads folder.

When the download is complete, go to the Downloads folder, right-click the NoteTab_Setup.exe file, and select Open With Windows Program Loader from the pop-up menu. A few moments later, the same sort of setup wizard that you would see when you were installing NoteTab in Windows will appear (Figure 19-8). Go through the wizard, accept the license agreement, and then accept the defaults along the way until the installation is complete.

![](img/d35fa962e6f9664d66dc83916f426418_367_1.png)

Figure 19-8: A Windows installation wizard running under Wine

Running NoteTab is easy because it provides you a desktop launcher. Double-click that launcher (it looks like a notepad with a Swiss flag on the front), and NoteTab Light will soon appear, just as a regular Linux app would. (The other file that was put on the desktop, ending in .lnk, can be safely deleted to reduce clutter.) You can run NoteTab Light and other Windows applications installed under Wine by searching for them in the Dash, just as you would any other application.

## 19C-3: Getting Windows Apps to Work in Wine with PlayOnLinux

Some Windows software subparly refuses to work in Wine unless you things set up in a specific way. The Wine website is full of tips on how to tweak settings until you hit the magic formula that seems to work for a given program (settings that are practically guaranteed not to work for other programs installed with Wine). Some instructions ask you to install different versions of Wine for different programs! Fortunately, there's a neat way to sidestep these issues called PlayOnLinux. It handles all the settings tweaks for you and supports many used Windows programs (and an especially large number of games). You can install PlayOnLinux in the usual way from the Ubuntu Software Center. Once it's installed, start PlayOnLinux by searching for it in the Dash. Click Next. It'll spend a minute or updating its database of supported programs. Once it's done, click Next again, and it will leave you at the main PlayOnLinux window (Figure 19-9). In that new window, click Install and use the category pane or bar in the window that appears to look for a Windows program of your choice.

![](img/d35fa962e6f9664d66dc83916f426418_368_0.png)

Figure 19-9: The main PlayOnLinux window

In this example, you'll install the delightful Crayon Physics game:

- 1. Select the Games category and find the Crayon Physics entry in the list (not the Deluxe version).
- 2. Select Crayon Physics (as in Figure 19-10) and click Install to start the installation process.

![](img/d35fa962e6f9664d66dc83916f426418_369_0.png)

Figure 19-10: Selecting a Windows application to install in PlayOnLinux

- 3. An installation wizard will open. Click Next and wait until the game is downloaded and installed.
- 4. When it's finished, click Next to complete the installation. You will be returned to the main PlayOnLinux window.
- 5. To starting, double-click the Crayon Physics entry in the main PlayOnLinux window or select the game from that list and click Run.

Assuming that the game was installed successfully, you'll be met with a Crayon Physics window. Click anywhere in that, and you'll see a landscape scrawled onto your display in crayon, similar to the one in Figure 19-11. The aim of the game is to draw boxes on the screen with your mouse in order to roll a ball onto a star. Every time you get the star, you will move to the next level, where you'll be forced to come up with a more ingenious ball-rolling strategy. It sounds simple, but it's addictive!

## Installing Windows on Ubuntu

One of the weirder things you can do with a computer is to run a simulation of a computer inside it. This simulation, known as virtual machine (VM) software, allows you to install one operating system inside another so you can run both at once without having to reboot. This is handy if you need to run Windows for some reason, perhaps for specialized software, but are too comfortable time-consuming rebooting procedure that dual-booters must follow to get back into Microsoft territory. You can even get Windows to sit in there, well, a window, which can be opened and closed just like any other program.

There are some caveats. First, the virtual machine has to share your computer's resources with all your programs, so it can slow down if you're doing anything strenuous. Second, it doesn't have the same access to your computer's hardware as the "real" operating system, so you won't be able to get Windows-only devices working through the virtual machine easily. Finally, and perhaps awkwardly, you need a Windows installation CD to be able to put Windows into a VM, but most computers only come supplied with a recovery CD, which won't work.

If you have an installation CD, getting Windows into a VM doesn’t take much work than getting it onto a real computer:

- 1. Open the Ubuntu Software Center and install VirtualBox. Other virtual machines are available, I find this one the easiest to use. Search for VirtualBox in the Dash and start up. In the window that appears, click New followed by Next.
- 2. Choose a name and type for your VM. The name is up to you, but the operating system should be set to Microsoft Windows. Make sure you pick the right version of Windows too.
- 3. Click Next and choose the amount of memory (system memory, not disk disk) that you’d like the VM to have access to (Figure 19-12). This can be a tough decision: on the one hand, you need enough memory for the “virtual” operating system to be run (Windows XP needs at least 128MB, for example), but on the other hand, you want to leave memory free for Ubuntu programs to be able to use it. VirtualBox normally suggests something sensible.

![](img/d35fa962e6f9664d66dc83916f426418_371_0.png)

Figure 19-12: Choosing how much memory to allocate to the virtual machine

- 4. Click Next and choose Create new hard disk (Figure 19-13). Make sure that Boot Hard Disk is checked too. Then click Next to open the Virtual Disk window.
- 5. Run through the Virtual Disk Wizard, clicking Finish when you’re done; the defaults should be fine for most of the options, but you might want to choose the size of the virtual disk yourself. This will be used as the hard disk of the virtual machine and is stored as a file in a hidden folder inside your Home folder.
