# Receiving Files by Bluetooth

To receive files via Bluetooth from another Bluetooth-capable device, you have to first set up your computer to allow such transfers. To do this, bring the Dash and open Personal File Sharing. In the Personal Sharing Preferences window that appears, check the **Receive files in Downloads folder over Bluetooth**. For your safety (so that no one can send files to you without your permission), select **Only for set devices** in the **Accept files** drop-down menu. Your window should then look like in Figure 7-19. If so, click **Close**. Your machine will automatically receive files sent to it via Bluetooth and save them to the Downloads folder.
