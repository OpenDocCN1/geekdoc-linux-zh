# Online Gaming

With all this talk of installing games, it's easy to forget that there are many games that you don't have to install at all. Numerous websites allow you to play online for free, as long as you have the proper browser plug-ins installed. (See “Multimedia Plug-ins” on page 62 for help installing plug-ins.) For example, check out http://www.popcap.com/, http://www.freeonlinegames.com/, and http://gametrick.net for some great online time was. You can also play any of the games found on Facebook or other social networking sites, such as Farmville and Mafia Wars, without ever leaving the comfort of your Ubuntu desktop.

# Searching for More Games

There are lots of other games for Ubuntu that I haven't covered, but rest assured they're out there. Some are available as DEB files and can be installed in the same way you installed Google Earth in Chapter 6. A good flower example is SDL Hana (Figure 17-18), a Linux version of the Japanese card game Hanaf, which is available from http://sdhana.nongnu.org.

NOTE SDL Hana must be run from the Terminal. Just type sdlhana in a Terminal window and then press ENTER.
