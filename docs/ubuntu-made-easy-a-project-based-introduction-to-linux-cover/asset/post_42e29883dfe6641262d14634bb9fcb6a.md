
If it still won't play, you can try using a different program, which might have the right codec built. Try installing the MPlayer Media Player or VLC media player—both of these programs support for a wide range of formats.

If you're struggling to play a video on the Web (for example, on YouTube), see “Multimedia Plug-ins” on page 62.

Another reason for your file being unplayable is that it is damaged. If you downloaded the file, try downloading it again—occasionally, parts of the file are accidentally missed during the download process, so repeating the download should fix this. Similarly, if you ripped the file a a CD, as described in Chapter 14, try ripping it again.

Finally, you might have a problem with your sound card. See “Ubuntu Doesn't Play Any Sounds” on page 383 for advice.

## Internet and Network Connection Problems

If you've been able to connect Ubuntu to the Internet (or a network), the most likely cause is that your wireless/network card hasn't been detected correctly. Other people have probably had the problem with the same network card before, so it's always a good idea to search online to whether you can find specific instructions on setting up your card. You're guaranteed to find something useful (or intelligible), however, I will provide some general instructions on diagnosing connection problems and installing network and wireless drivers.

## Finding the Cause of a Connection Problem

There are so many different causes of connection problems that knowing where to start can be difficult. In this section, I've provided a few tips on how you can get more information to help you figure out your connection problem. Unfortunately, much of the information is quite technical, so you might find some of the results of these tests confusing. If so, make a note of the results, because the information might be useful to someone in the forums or elsewhere who can help you fix the problem.

Do you have a connection to the Internet? Open Firefox and try to visit a popular website, like https://www.google.com/ or https://www.bbc.co.uk/. If either of these pages loads and you get a “Server not found” message or similar, you might not have a link to the Internet, or you might just have a problem with Firefox. To check, open a Terminal using the Dash and type `ping 209.85.227.106` into it, followed by ENTER. This should ping Google’s servers—pinging a server is a way of checking whether your computer can communicate with it. If you receive a message starting with the 64 bytes from (as shown in Figure 22-9), you have a working Internet connection. (Press CTRL-C to stop pinging Google.). In this case, the problem might be with your DNS settings or some other software than with your connection or your network/wireless card. If you get any other message, you probably aren't connected to the Internet, so you might have a hardware problem.

**Is your card recognized?** Open a Terminal, type `lshw -c network -short`, and press ENTER (make you put all the spaces and dashes in the right place when you type this, as printed here). A list of the network and wireless cards that were recognized on your computer will be displayed, similar to the one shown in Figure 22-10; check whether any of them has a description matching the model of your card. **Is your card turned on?** If you have a Wireless Network it may have been turned off. Follow the instructions in "No Wireless Networks Are Found" on page 390 for how to check whether this is the case.

**Are you using the right drivers?** Ubuntu uses the wrong driver for network/wireless card. To check which driver is being used for your card, open a Terminal and type **lshw -c network** followed by ENTER. Scroll down through all of the text and find the card that has a product or vendor matching of your card. Then scroll down a few more lines until you get to the configuration line. This will tell you which driver is being used and the version number of the driver. You can compare this with the information for your card at https://wiki.ubuntu.com/.

Have you checked your settings? Click the Network icon on the top panel, select Edit from the menu that pops up, find the entry for your connection (as described in Chapter 4). Then, check the settings to see any of them are your default gateway (if you have a manually configured network) and DNS servers (if you have a wireless connection).

For those struggling with a wireless connection, you can find a less troubleshooting guide at https://help.ubuntu.com/community/WifiDocs/Troubleshooting/.

## Installing Drivers for Your Network/Wireless Card

If your network card or wireless card hasn't been recognized or isn't working as expected, you might need to install some drivers for it. You can try a few methods, and the one that works will very much depend on the make and model of your card. I have included two of the most general ones in the following sections, but some cards need to get working. The lists at https://wiki.ubuntu.com/ and https://help.ubuntu.com/community/ should be able to help you figure out which method to use.

### Checking for Restricted Drivers

Some wireless cards have restricted drivers that you can download to get your card working. These drivers are normally provided by the manufacturer of the card and are “restricted” in the sense that they can't be fixed by Ubuntu developers if something goes wrong with them (in other words, they're not open source)

You need to be connected to the Internet to download restricted drivers. If you don't have a working connection (probably you're currently in the process of trying to get your card working!), try using an Ethernet cable to plug the computer directly into your wireless router or cable modem (see Chapter 4 for more information). This will work only if you have a functioning wired network card. If your wired network card doesn't work, you won't be able to follow these instructions.

- Go to the Dash and open Hardware Drivers. Ubuntu will start searching for restricted drivers. If it finds any, they will be displayed in the list at the top of window (as in Figure 22-3)

- Check to see any of the restricted drivers have anything to do with networks or wireless (it should say in their descriptions). If you find one that does, select it and click Activate to download and install it. Some cards require two drivers, so if you find two drivers that look relevant, install both.
