+   1. Start by opening the Terminal (from the Dash, type terminal and press ENTER).

+   2. In the Terminal, use sudo apt-get-repository ppa:scopes-packagers/ppa and press ENTER to add the new repository.

+   3. Type your password when prompted to do so and press ENTER.

+   4. After a second or so, you will be asked to press ENTER to continue—do so.

+   5. Update the repository database by typing sudo apt-get update in the Terminal and pressing ENTER.

+   6. Fetch and install the lens by typing sudo apt-get install lens-cooking and pressing ENTER.

+   7. Type y (for yes) when asked you to continue and then press ENTER.

+   8. Finally, log out and log back in.

Once you have logged back in, open the Dash, you will find your new lens in the middle of those that were there before (it looks like a rocket between a bull's eye and Pac-Man). Just click it and start searching away. The results will then appear, as in Figure 18-2.
