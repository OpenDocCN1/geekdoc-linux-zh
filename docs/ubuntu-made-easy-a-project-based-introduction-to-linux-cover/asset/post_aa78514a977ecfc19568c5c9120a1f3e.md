# 6A-1: Selecting Applications for Installation

The Ubuntu Software Center can install multiple applications simultaneously, so to give it a whirl, you try installing a few interesting applications. Let's start by selecting the very cool and decidedly useful diary/journal application Rednotebook (shown in Figure 6-3). If you're not already there, click the **All Software** button on the toolbar to go back to the Software Center's start screen. Then select Rednotebook, click the **Office** category in the list to show left. A long list of available applications will appear, sorted by popularity. Humm . . . Rednotebook doesn't seem to be at the top of the list. Hunting through the whole list for it could get tedious, so let's sorting it in a different way: From the drop-down box in the top right of the window, choose the By Name option. This will put the list in alphabetical order. Scroll down the list of available applications until you start getting to the R and double-click the RedNotebook item. A page containing information about RedNotebook will be displayed. You'll see that it comes highly recommended by other users—four and half stars out of five—and it's completely free to download. There's also a picture of it on the right that you can zoom in to on. If you scroll further down the page, you'll find a few bits of information, followed by a bunch of reviews. "The best diary notebook out there at the moment," says Scott. Sounds good to me. Assuming you too are convinced by the glowing reviews, all you need to do is click Install and type your password if prompted. This will start the installation.

# 6A-2: Searching for Applications

Next up is Sound Converter (I'll talk more about using this application in Chapter 14). Scrolling through the list of programs can be tedious, so this time using the search feature. Click the All Software button in the toolbar to go back to the main Software Center and then typing Sound Converter into the search box at the top right. The search results will start to roll in immediately. Sound Converter should appear at the top of the list of results before you've even finished typing, so click it to select it and then click **Install**. The installation will start as before—but this time, clicking **All Software** while the program is still installing. All the installation magic will continue in the background, and you can still browse for other programs. No need to wait!

Finally, let's add a useful utility by name Sysinfo (Figure 6-4), a system profiler that tells you all sorts about your computer. Just type **sysinfo** in the search box, click the **Sysinfo** search result that appears, and then click **Install** to add it to the installation queue. It will be installed soon as the Software Center has finished dealing with Sound Converter.

# 6A-3: Uninstalling Applications

As you can see, installing applications via the Ubuntu Software Center is quite simple. And fortunately, it's just easy to uninstall them. Navigate to (or search for) the program you want to remove, click it once in the list, and click the **Remove** button that appears. Enter your password again if asked and watch as the program is uninstalled. If you want to uninstall a few programs in one go, you might find it faster to click the Installed button on the toolbar and browse through the list of installed applications. For each one that you want to uninstall, select it with a click, and you'll see the Remove button appear again.

# 6A-4: Commercial vs. Free Software

A relatively recent addition to Ubuntu is the availability of commercial software. Back in the early days, Linux distributions like Ubuntu would include only free software—free as in "no charge for it" but also as in "freedom." That was the one source way—lots of people sharing the programs that they wrote, usually just for the fun of it, without any hint of a desire to change for them. For the most part, this is still how it works: The vast majority of software developers writing programs for Linux have continued to share their apps openly. But more recently, a few frescos have started to let in commercial developers, who charge for their products. Ubuntu is one of them. The idea is that most people are used to paying for software and aren't so bothered by the open source aspect that they don't like more apps to choose from. The free apps will always be there, and they'll be in the majority.

To see what commercial software is available, click the arrow immediately to the right of the All Software on the toolbar and select Purchase from the menu that pops up (Figure 6-6). A pretty lengthy list will appear—there are lots of games, a number of magazines, and the old system utility used here and there. The list is growing all the time as more software developers sign up to distribute their apps through the Software Center. To see what's been added recently, click All Software to go back to the main Software Center view and check out what's New pane in the middle of the window. There's a Button at the top right of the pane that you can click to see a more complete list. You'll find that not all of the software listed is commercial, but a lot of it seems to be.
