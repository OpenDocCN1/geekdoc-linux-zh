Check that it's muted. Also on the Input tab, make sure that the Mute option next to the Input volume control is not checked.

Choose the right input. Ubuntu sometimes detects sound cards as being more than one device. This is often the case for laptops, which might have more than one input (for example, a microphone socket and a built-in microphone). By choosing a different device from the Record sound from list the Input tab you can (Figure 22-8). Ensure that the device is unmuted and its volume is turned up.

Test using a different program. The lack of sound from your microphone could be a problem with the program you're using to record the sound rather than with the way the microphone is set up. Try using a different program to test the microphone. The Sound Recorder (search for it in the Dash) is usually helpful.

# I Can't Play an Audio or Video File

The common reason for not being able to play an audio or video file is that you don't have the necessary codec installed to play the file. A codec is a small piece of software that adds support for a audio/video format into a program. Rhythmbox and the Totem Movie Player find the right codec for you (for example, “Installing MP3 Apps” on page 247). However, if they fail, try installing the Ubuntu restricted extras package—this package contains a lot of extra codecs. Once the package is installed, close and reopen your audio/video file and see whether it plays.
