# APT-URL: Installing from Websites

Now you've added GetDeb to the list of available software repositories, you
can take advantage of yet APT frontend. Go to http://www.getdeb.net/
and click the Apps tab. Peruse the list of programs until you find something
agreeable—I chose a time application called hamster-applet—
and click Install now, just below its picture. Now you can click a link on
website to install software, without visiting to the Software Center!

A Launch Application screen will appear with the Ubuntu Software Cen-	er option selection—click OK and enter your password if prompted.
Software Center will open (if it wasn't already open), and you'll be to
usual: Click Install and wait as the familiar installing and activating-ies on. When it's all over, close the Software Center and find your
application in the Dash. Quick and easy.

Plenty of websites support APT links, but you won't be able to download
software from unless you've added your repository to your computer,
asid with GetDeb. If the link is for a program that is already available in
t Ubuntu repositories, however, the software can be installed as normal,
without any further messing around in Software Sources.

the own software. There are all sorts of little programs out there that some-\one written to scratch each of them, and plenty of them are available
to you, if you know where to get them. Luckily, most of them can

way for people to share their home-brewed software with others (emphasis on
the home-brewed—sometimes from PPAs doesn't work well).

like Firefox to get their latest and greatest out to users. Whether it's off-
 updates or homebrew apps that you're looking for, you can find

what you want.
