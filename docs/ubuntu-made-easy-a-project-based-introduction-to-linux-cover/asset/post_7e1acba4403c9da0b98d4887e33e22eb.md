
2. Move the pyWings tarball into that folder by typing mv Downloads/pywings\*.gz pywings and pressing ENTER.

You can see in this step you used an asterisk (*) to save some wear and tear on your fingers. The asterisk is a wildcard character, in this case told your system to move any file with pywings and ending in .gz. Fortunately you had only one item matching those criteria.

3. Move to the new pyWings folder by typing cd pywings and pressing ENTER.

4. Now you get down to extracting the tarball itself using the tar command. To do this, tar -xvf pywings\* and press ENTER.

Again, notice that you used the asterisk to save yourself keystrokes, though you could just as well have typed -1.1. tar.

5. Finally, type cd and press ENTER to bring the Terminal back to your Home folder.

## 8B-7: Creating a Launchable Link for pyWings

The method of running pyWings that you've just used works well enough. However, it's a pain to open your Terminal and type that somewhat lengthy every time you want to find out what fate has in store for you. Let's find a way to make things easier in the future.

To run an application from the Terminal, you generally type the name of that application, or to put it precisely, the name of your program executable file; the application's name acts as a sort of command. For your system to recognize that command, however, the command (the executable file or link to it) must be in a location where the system can find it. Whenever you run a command of any sort, your system checks a series of locations (most of which are bin folders, where executable files are located) to find that command.

You can easily find out where these locations are by typing echo $PATH in a New Terminal window and pressing ENTER. You will see, on your Ubuntu system, these locations are as follows:

```
/n/usr/lib/lightdm/lightdm
/usr/local/sbin
/usr/local/bin
/usr/sbin
/usr/bin
/bin
/usr/games
```

The results of the echo $PATH command will not appear as line divided do in the (easier to read) chant shown here but, rather, in a single line divided by colons: The actual output in the Terminal is /usr/lib/lightdm/lightdm:/usr/local:/usr/local/bin:/usr/sbin:/sbin:/bin:/usr/games.

If the command you typed is in one of those locations, the program or script will run. You as no doubt, however, pyWings is not in any of those locations. It is in /home/username/LocalApps/pyWings and thus is, in a sense, out of your system's sight.

To remedy this situation, you could add the path of your pyWings script to the list of paths that the system checks for run commands so to make the system aware of your new application's existence. However, let's try another method that I think is easier. What you will do is create a link to pyWings, a sort of launchable alias, in one of the locations your system checks for.

To create this link, you will use three commands: cd (to change directories), sudo (to give yourself write access to the destination folder), and ln -s (to create the link).

- 1. In the Terminal, type cd /usr/games and press ENTER. This puts you in one of the folders your search when you enter commands.
- 2. Type sudo ln -s /home/username/LocalApps/pywings/pywings.py pywings and press ENTER. (Note that there is a space between the terms pywings.py and pywings at the end of that command string)

The pywings at the end of command string is the name that you are giving the link; the name of the link thus becomes the command you will use to run the application. If you type nothing, the link will be called pywings.py, which would mean three keystrokes for every time you wanted to start the program.
- 3. Type your password when prompted to do so and then press ENTER.
- 4. Now make your launcher executable by changing its permissions: Type sudo chmod +x pywings and press ENTER.
- 5. Type cd and press ENTER to return the Terminal to your Home folder.

## 8B-8: Running pyWings Again

Now that you have created the link, you should be able to run the pyWings program more easily. To try it out, quit pyWings (if it is still running), type pywings in the Terminal window, and press ENTER. Your pyWings oracle should appear again.
You've managed to cut down on the number of keystrokes required to run pyWings from the Terminal. However, if you are really into this pyWings thing and running to use it often, it will probably be handiest to add a launcher to your panel, a drawer, or the Applications menu.
