# # Navigating a Sea of Open Windows

Once you get down to really using your system rather than just learning about it, there will be times when you have a few apps and a lot of windows open at the same time. When it's only a couple of windows you want to arrange more neatly, you can just drag one window to either resize itself to fit into that area. You can do the same for the other window, making it easy to work with both items by side by side.

However, when you're using several applications and different windows at once, it can get confusing to figure out what's running or even where a window is, buried among what seems like a hundred others. In this case, the Launcher can come in handy—it's not only for starting up frequently used apps but also great for switching applica-tions or windows.

To help with this, the Launcher has a system of indicators that let know you've got open and running.
