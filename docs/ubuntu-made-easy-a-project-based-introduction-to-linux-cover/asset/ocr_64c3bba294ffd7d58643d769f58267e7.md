It’s worth mentioning at this point that you may also come across some files compressed with the bzip program. Such files are recognizable by some variation on the .bz or .bz2 file extension. Dealing with these files should pose no problem, because the commands are almost identical to for gzip.
Just substitute -j for -z in the command string.

# Compressing and Extracting Compressed Single Files

If you want to compress or decompress a single file, you don't really need to use the tar program at all, since its purpose is to create archives consisting of several files. You can instead use gzip and gunzip commands. Then for example, to compress a file called matilda.jpg you would type gzip matilda.jpg and press ENTER. The matilda.jpg file would then become matilda.bz2.gz. To decompress the file, you would type gunzip matilda.jpg.gz and press ENTER, after the matilda.jpg file would be back to normal.

So, can you compress an archive you’ve already created with the tar command? Sure. For example, to compress the spicyfood.tar archive mentioned earlier, voilà—you’ve got yourself a compressed spicyfood.tar.gz archive. Pretty cool, don’t you think?

# Project 8A: Creating a Plan

The actual .plan file is a hidden file (as you can see by the dot before its name) and contains the plan or message that you add to it. That message will appear in the output of someone’s Terminal when he uses the finger command to find out about you. You might not need a .plan file, but it’s an easy enough way to work a bit more with commands and the Terminal itself, let’s get it a try.

To start out, you will open the Terminal-based Nano editor to create the .plan file. To do this, open a Terminal window, type nano .plan (being sure to put a space between nano and .plan), and press ENTER. Your Terminal will look bit different, as shown in Figure 8-10.
