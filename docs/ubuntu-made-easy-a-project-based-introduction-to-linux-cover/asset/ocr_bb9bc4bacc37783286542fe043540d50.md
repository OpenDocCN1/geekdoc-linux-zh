First run CCSM by going to the Dash, clicking the Applications lens, and then clicking the Customization filter button and looking for it in the results. Or if you prefer, just compiz in the Dash and press ENTER.

The very first thing you will see, along with the CCSM window, is another warning that CCSM is an advanced tool and that you should proceed with caution. The warning is right, so if you're not sure what something in CCSM is or does, perhaps you won't feel with it. You should be safe trying the things I mention here, however, starting out withobbly Windows.

To give Windows a try (and thus a hand-on feel for CCSM), click the Effects button on the left side of the CCSM window and then in the next screen Wobbly Windows. In the screen after that, check the box to the words Enable Wobbly Windows. In the small window that then appears, click the Disable Snapping Windows Draw the window around. As you move it, you will see, the whole window will start wobbling like jelly freely and totally distracting, but kind of cool. You can uncheck the Wobbly Windows box if the feature is getting on your nerves.

Another interesting tool is the Annotate tool, which can actually have practical uses as it allows you to write on the screen (Figure 9-19). To activate the Annotate tool, click the Extras button in the left side of the screen, and then check the box next to Annotate in the new screen. Click the word Annotate itself to get to preferences for that tool (this is the same as you access preferences for all tools and features), as shown in Figure 9-20, and thereby learn how to activate the tool's features.
