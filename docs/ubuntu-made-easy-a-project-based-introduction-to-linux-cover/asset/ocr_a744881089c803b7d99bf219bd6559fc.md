To make things a bit more draconian, you can click the Policy tab, choose Outbound traffic policy from the Editing drop-down menu, and select Restrictive by default, whitelist traffic. You then have to specifically allow access to any website by adding it to the list of hosts. This sounds like a lot of hassle to me. If you just want to deny anyone working on your computer access to a specific website, for instance select Permissive by blacklist traffic; right-click the Connections to host field; and select Add Rule in the pop-up menu. In the Add outbound rule window, enter the domain name for the targeted site (as in example.com), click Add, and then click the Apply button in the main Firestarter window (it's the one that looks like a green check mark).

# Confirming Firestarter Runs Automatically

After you run Firestarter the first time, it will set itself to automatically start whenever you run your system. Don't be concerned when you don't see the graphical interface you saw when you started it; Firestarter will be running in the background, silently protecting your computer.
 you are the doubting type, you can check to see whether Firestarter is actually running in the background by opening a Terminal, typing sudo /etc/init.d/firestarter status, and then pressing ENTER (entering your password, prompted). If Firestarter is running, you will see the * Firestarter is running... in the Terminal window. Worries over. If starter isn't running, the response will read * Firestarter is stopped.

Despite a lethal dearth of viruses that can wreak havoc upon your Linux system, your could could act as a transmitter of Windows viruses. As a result, a number of free antivirus scanners are available for Linux users interested in helping Windows users from yours. For Linux users, the virus scanner of choice is the open source contender: ClamAV.
Although it can be used on a number of operating systems, ClamAV is considered the Linux antivirus software package. It is open source and totally free, and you don't have to worry about licenses or suffer the bother of renewing.
