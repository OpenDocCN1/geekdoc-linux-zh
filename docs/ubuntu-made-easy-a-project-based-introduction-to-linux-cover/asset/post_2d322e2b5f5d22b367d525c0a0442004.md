So far, so good. With a VM ready and raring to go, it's now time to install Windows. I'm going to leave the Windows specs up to you (they're a little outside the scope of this book, don't you think?), but here's what you need to do to get started:

- 1. Insert the Windows installation disc into your CD drive and close any windows that open and ask what to do with it.

- 2. Back in the main VirtualBox window, select your VM from the left pane and click Start. A black window will open, along with a First Run Wizard; click Next.

- 3. Make sure CD/DVD-ROM Device is selected under Media Type and click Next.

- 4. Click Finish, and the VM should try to boot from your Windows CD. After a few seconds, you should be face-to-face with the Windows Installer. Have fun with that!

- 5. Once the Windows installation has finished, the VM will restart. Remove the CD when prompted, and after a few more minutes of setup, you should be staring a Windows desktop in the eye. Pew, hard work over!

NOTE You install Linux and other operating systems besides Windows in virtual machines. In fact, you could even install a VM within a VM, although you'd probably have to budget half a day to check your email if you had both of them running at once.

## Sharing Files with Windows Users on Your Network

One of the main reasons for connecting to a network (apart from accessing the Internet). You may be familiar with this concept already; network shares are used in many workplaces, and you may have set up one before your home network. For the uninitiated, a network share is a folder on another computer that you can access if it were on your own. Files are transferred around on the network, so there's no need to use a portable hard disk or flash drive to get them from one place to another.

## Accessing Files on a Windows Computer

Network shares are a two-way thing: You can share your files with others by creating a shared folder or access existing shared folders created by other people. If you're connected to a network of Windows computers, then you probably have some network shares already. I talked about browsing network shares in depth at "Using Nautilus as a Network Browser" on page 106, but to save the anguish of flipping back so many pages, here's a quick outline of what you need to do to access a share from Ubuntu:

- 1. Open Nautilus by clicking its orange folder in the Launcher. Click Browse New Network in the Network section of the sidebar and double-click Windows Network to see a list of all the Windows computers connected to the network. Double-click one of computers to see its shared folders. If no computers are listed, try opening one of the folders with a network icon on the front (like the one in Figure 19-14) and look for computers in there instead.

![](img/d35fa962e6f9664d66dc83916f426418_373_0.png)

Figure 19-14: A folder containing links to Windows computers on the network

- 2. Pick a shared folder and double-click to access the files inside. Depending on how the shared folder has been set up, you may be asked to enter a username and password for the computer that it's hosted on.

## Making Your Files Accessible from a Windows Computer

Since your Windows computers have so gladly made their files available on the network, let's have Ubuntu reciprocate by sharing a folder of its own:

- 1. Open Nautilus and find the folder you want to share; then right-click it and select Properties.

- 2. Go to the Share tab and check Share this folder.

- 3. You'll be told that the sharing service is not installed—click Install service, then Enter your password if prompted in the window that appears. Enter wait for the installation process to finish. You may be asked to install other packages, so click Install when prompted for those too.

- 4. Once installation has finished, you'll be prompted to restart your session. Click Cancel for now; you'll need to log out, then log back again later.

- 5. Back in the Folder Sharing window (Figure 19-15), choose a name for the shared folder and type a comment if you like.
