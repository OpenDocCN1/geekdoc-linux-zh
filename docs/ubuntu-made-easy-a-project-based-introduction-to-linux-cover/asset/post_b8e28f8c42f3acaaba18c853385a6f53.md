## Compressing and Extracting Compressed Single Files

If you want to compress or decompress a single file, you don't really need to use the tar program at all, since its purpose is to create archives consisting of several files. You can instead use gzip and gunzip commands. Then for example, to compress a file called matilda.jpg you would type gzip matilda.jpg and press ENTER. The matilda.jpg file would then become matilda.bz2.gz. To decompress the file, you would type gunzip matilda.jpg.gz and press ENTER, after the matilda.jpg file would be back to normal.

So, can you compress an archive you’ve already created with the tar command? Sure. For example, to compress the spicyfood.tar archive mentioned earlier, voilà—you’ve got yourself a compressed spicyfood.tar.gz archive. Pretty cool, don’t you think?
