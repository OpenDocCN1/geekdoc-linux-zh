
Google Earth can do lots more besides, like mapping out local businesses and services, tracking flights, and providing information on public transport.
Other applications and websites exist, such as Bing Maps (http://www.bing.com/maps/), but Google Earth is by far the most fully featured out there.

Because Google Earth is not available from the Ubuntu repositories, you will need to get it from its website (http://www.google.com/earth/). Once, click the Download Google Earth button, which will automatically take you to the download page for Linux versions of Google Earth. On that page, select 32 bit .deb (for Debian/Ubuntu), click Agree and Download, and then click the Save File in the window that appears.

Once the download is complete, you will find the Google Earth DEB package on your hard disk, probably in your Downloads folder. Double-click that package, and the Software Center will open to an information page for Google Earth. Click Install, enter your password if prompted, and watch as the installation proceeds as usual. Once Google Earth has been installed, you can run it by bringing up the Dash and searching for it. After a brief wait the app downloads a few maps, you'll be free to glide around the world with the click of a mouse.

Some computers seem to struggle with Google Earth because of the way it displays 3D graphics. Check out http://support.google.com/earth/ and search for ubuntu if you're having problems—you will find a few tips on how to get things up and running smoothly.

With that introduction, you may have already guessed that in this chapter I will be dealing with file handling in Ubuntu, particularly in relation to the file search in the Dash and the Nautilus file manager, which is at the heart of Ubuntu’s file-handling capabilities.

## Find It Fast—Searching for Files with the Dash

If you're anything like me, you've been collecting computer files for quite some time now. My laptop is packed full of files, from vacation photos, letters, financial documents and spreadsheets to my music collection, home videos, ebooks, and work documents. It even hosts a bunch of files from my Windows days—bad artwork, unfinished poems, and old desktop background pictures. There is a lot of stuff—too much stuff, in fact. There's a point at which even the most competent organizational mind has to throw his hands in the air and admit defeat: It's practically impossible to keep many files organized while the same time having easy access to them. And that's where the Dash comes in.

As you've already seen in Chapter 3, the Dash has a powerful search feature. All you need is to open the Dash and start typing. Then, within a second or two, search results from the four corners of your computer will start to float in. After you can use lenses and filters to narrow your search results until you find whatever you're looking for. Nothing more to it, right?

Well... not quite. In addition to the basic search and filtering features mentioned in Chapter 3, the Dash also has nifty extras to help you find your files. In this section, I'll take you on a whistle-stop tour of what's on, accompanied by a neat trick or two that might just help you find it faster (whatever "it" is). Read on!

## Recent Files and Downloads

As you've probably already established, searching is the quickest way to find files. But when you first open the Dash, you'll see three bands of results displayed before you even typed a thing. At the top is a list of applications that you've recently used; forget for that now. In the middle, you'll see a band called Recent Files, and you'll see Downloads below that. The Recent Files band is, surprisingly, a list of the files you've been working with recently. If you're looking for that you wrote yesterday, there's no need to search for it—it'll probably be right there in this list.

The Downloads band is also pretty handy, if like me, you spend a lot of time on the Web. It's a list of all the files that you've recently downloaded with your browser, as explained in Chapter 5. Everything you save off the Web is stored in a special Downloads folder for future reference, so there's no need to sit scratching your head, wondering which website you found that tax form last week—it's probably somewhere in the Downloads folder.

## Finding More Elusive Files

What if you can't find the file you were looking for? There are a number of things to try. The first is to double-check what you are searching for. The search in the Dash isn't case sensitive (you can use uppercase and lowercase letters, and it doesn't care), but it does care about spelling. If the search term you doesn't appear somewhere in the name of the file, exactly as you typed it, then it won't show up in the search results. Also, be aware that the search doesn't look inside the files—only at the name of the title. Say, for example, that you wrote a word-processed document with the title "Clouds Fluffy" and saved it with the filename clouds.doc. Searching for clouds would find the file, but searching for fluffy would not. Where you saved the file also matters: In general, most of the places where you might save files are free (they could be in your Home folder, which you'll learn about shortly), but if you put it on a removable USB memory stick, it won't show up in the results.
