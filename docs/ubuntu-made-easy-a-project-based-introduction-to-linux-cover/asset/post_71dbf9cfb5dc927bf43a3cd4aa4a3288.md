
# Keeping Up-to-Date with Live Bookmarks

The Web is awash in all sorts of news and information, and it can be hard to keep tabs on it all. Personally, I hate missing my daily dose of offbeat stories from Boing Boing, the aptly titled "directory of wonderful things" (http://www.boinging.net/). Unfortunately, Firefox has a real way of dealing with your information overload called live bookmarks (also known as RSS feeds). These provide you with an automatically updated list of articles from any website that supports them (Figure 5-8).

![](img/d35fa962e6f9664d66dc83916f426418_98_0.png)

You can check whether a website has an RSS feed by going to the Bookmarks menu and checking whether the Subscribe to This Page item is enabled. If it's grayed out, then have luck—there's no RSS feed. If it's white, not gray, then you're in business! Let's use Boing Boing as an example: http://www.boinging.net/ in Firefox and go to the Bookmarks menu. The Subscribe to This Page item is white, which means it's clickable. Click it, and you'll get a list of the most recent articles to subscribe to feed in the box at the top of the page. Click Subscribe Now, and in the window that appears, click Subscribe to add the live bookmark to the toolbar as the Latest Headlines link.

Some websites provide links to their RSS feeds rather than showing them in the address bar. If you find one of these links (it's normally called ATOM or RSS/XML), click it, and you should be taken to a list of articles with a box at the top, as in the previous example. # Pop-up Manager

Firefox has a number of other useful features. One is Pop-up Manager, which suppresses annoying pop-up windows that too often appear when you access a new web page. You can enable or disable this feature from the Preferences window **Edit > Preferences**; click the Content icon in the pane of window and then check or uncheck the Block pop-up windows. You can also permit certain sites to provide pop-up windows (some pop-ups are not only useful but also necessary for the correct functioning of a site) by clicking the Exceptions button to the right of Block pop-up windows by entering and inputting the web address for the site.

# Multimedia Plug-ins

One of the coolest things about Firefox is that it allows you to expand its functionality by adding various extensions. Commonly used extensions come in the form of plug-ins. These allow web pages to do more than just text and pictures—you'll need a plug-in to watch videos or play games online, for example. Three plug-ins are used far more widely than others, so I'll concentrate on those.

# Flash

The most frequently used browser plug-in for any system is Adobe's Flash Player. Flash provides websites with all sorts of multimedia effects and capabilities, and as is used by a large number of sites. In fact, you've probably seen numerous Flash-enhanced pages without being aware of it. For example, if you've ever watched a video on YouTube, you enjoyed the wonders of Flash. How do you get the Flash Player plug-in? Well, if you opted to install third-party software when you first installed your system, you already have it. If not, it takes a few clicks and a working Internet connection:

1. Open the Software Center by clicking its icon on the Launcher or searching for it in the Dash. (You'll learn more about the Software Center in Chapter 6; skip ahead if you need.)
2. Type flash in the search box at the top of the window.
3. In the list that appears, double-click the Adobe Flash plug-in. An information window will appear, hopefully with an Install button (Figure 5-9). If instead get a button that says Use This Source, click the button and wait as the Software Center enables an extra software repository that needs (more on this in Chapter 6). The Install button should appear once it's finished.
4. Click Install; then, prompted, type your password and click Authenticate. The plug-in will be downloaded and installed.
5. When the plug-in has finished installing, a green checkmark will appear next to its icon in the list. Close Ubuntu and open Firefox (if it was already open, close it and start it again).
6. To check that the plug-in is working, find a site that uses Flash. If you don't know of one offhand, try YouTube (http://www.youtube.com/). Once you have arrived at YouTube, click any video link you see. If Flash was installed successfully, a video should appear and start playing (Figure 5-10).

# Silverlight/Moonlight

A relative newcomer to the plug-in scene is Microsoft's Silverlight. It's less common than Flash but seems to be used on the websites of TV channels and major sporting events quite lot. Unfortunately, Microsoft is a little before the times, and it hasn't made Silverlight available for Linux yet. But never fear: An alternative, open source plug-in called Moonlight is available. To install Moonlight, follow these steps:

1. Open Firefox and go to http://www.go-mono.com/moonlight/.
2. Click the Install button on the Moonlight page and scroll down to section 2. Download the plug-in.
3. Now click the green-pointing arrow. A bubble will appear at the top of the screen saying that the website was prevented from installing software.
4. Click the Allow button in the bubble, and an Add-on downloading bubble will pop up. Wait for the plug-in to download.
5. Once it's finished, a Software Installation window will appear. Click Install Now and then, in the bubble that appears, Click Restart Now to finish installing the plug-in (all of the pages that you open when Firefox opens again).
6. Head over to http://www.farseergames.com/demo/. If Moonlight was installed properly, you should now see a little boat bobbing around on the waves (Figure 5-11).

# Java

One last plug-in that you're likely to encounter is Java, which is used to run java apps. Java apps are little applications that you run in your web browser, and they are commonly used for games and demonstrations. Installing Java is quite similar to installing Flash. Just Open the Software Center, but this time search for Iced Tea Java Plugin and install that. After installation has finished, it's a good idea to take a look at Java in action, so head over to http://www.turbotanks.com/. An arcade “tanks” game should load if Java is working properly (Figure 5-12).
