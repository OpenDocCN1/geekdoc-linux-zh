# 13B-1: Publishing Images to Online Albums and Galleries

As mentioned, Shotwell allows you to easily publish images to numerous online sites, much in the way that Windows Live Photo Gallery does. The method I show here for Facebook is essentially the same one you use for the others, and they're all pretty simple. Here's what you need to:

+   1. In Shotwell, select the photos you want to post online by holding down CTRL key and clicking each of the photos you want to publish.
2. Once you've made your selection, click the Publish button at the bottom of the window. A window like that in Figure 13-5 will appear.
3. The default online site selected in this window is Facebook. If you would like to upload photos to Flickr or PicasWeb, select that site in the dropdown menu at the top right of the window. Once you've done that, click the Log button.
4. The login page for the site you've selected will then appear in the window (Figure 13-6). Fill in your login information and then click the Log In button (or equivalent for the other sites).
5. In the case of Facebook, you will be asked to name the machine you are logging from. Once you have done that, you will need to allow Shotwell to access your Facebook information, something you'll need to do whenever you log from a new machine.
