# INTRODUCTION

![](bbox=[0.167, 0.483, 0.355, 0.621])

If you're standing in the aisle of your local bookstore reading this right now, you may be wondering who this book is for. Ubuntu Made Easy, as you might imagine, is for readers who are interested in Linux but who feel the need for a jumping-off point to get started.

If you're familiar with computers but unfamiliar with Linux, or if you are somewhat familiar with Linux but not with Ubuntu, this book is for you. This is not primarily a book for seasoned geeks or power users; it's an introductory guide that will provide you with some hands-on experience to get up, running, and comfortable with the Ubuntu Linux distribution without pain. Think of this book as a rope, a compass, and a comfy pair of hiking boots rather than a harness, and a set of crampons.
