## 8C-4: Moving the bracola Folder to a Global Location

You could move the bracola folder to the LocalApps folder and play the game from there, as you did with pyWings. This time let's do a bit differently by moving the whole thing to global territory. This not only keeps it safe from any obsessive housekeeping tendencies you might have but also allows all users on the same computer to play the game. You will need to use the sudo command to do this so that you can have access in those protected folders.

Just type the following command in the Terminal window and press ENTER:

```
sudo mv briscola /usr/share/games/briscola
```

When you are prompted for your password, type it and press ENTER.

## 8C-5: Creating a Launchable Link for Briscola

Even though you've moved Briscola to a global location, you still can't run it with a simple one-word command because the briscola.tk file is not in the system's command path. Just as you did for pyWings, you will now create a launchable link for Briscola to solve that problem. Here are the steps:

- 1. In the Terminal, cd /usr/games and press ENTER.

- 2. Now create the link by typing sudo ln -s /usr/share/games/briscola/briscola.tk briscola and pressing ENTER.

- 3. Type cd and press ENTER to return the Terminal to your Home folder.

You can easily run Briscola by typing Briscola in the Terminal and pressing ENTER.

Sure. ```

## Playing Briscola

As already mentioned, Briscola is easy—as easy as a card game as there is. It is a trick-taking game, which means you put out a card and then your opponent puts out a card, and the one who puts the highest-value card wins the trick. Points are awarded on the basis of the cards involved in that trick. The winner of the trick then goes on the next trick, meaning that the winner puts his or her card the next time around. When all the cards are played, the points for each player are tallied, and the player with the higher points wins. It's much simpler to describe it.

If you would like a more detailed set of rules for playing Briscola (and just about any other card game in the world), check out http://www.pagat.com/. There are also video guides out there on YouTube, my favorite at http://www.youtube.com/watch?v=jpXMbNPN8c.

## What Is Source?

To get started, it is probably a good idea to understand what source is so as to understand a bit about how a program actually metamorphoses from a primitive state on the programmer's computer into an up-and-running application on your machine. First the programmer writes a program in programming language. You have probably seen source code in some form.

The source code is the human-readable version of the program. The computer cannot execute it directly; it must first be translated into machine code, which is a series of ones and zeros that the processor can understand. This translation process is called compilation.

There are a few different ways to translate source code into machine code. One method is to use a compiler, which translates the entire program at once. Another method is to use an interpreter, which translates and executes the code line by line. Compilers are generally faster than interpreters because the translation is only done once. However, interpreted programs are often easier to debug and modify because the code is translated on the fly.

In summary, source code is the foundation of all software. It is the human-readable instructions that programmers write, test, and maintain programs. By understanding source code, you can better understand how software works and how to create it yourself.
