Some of the keys used for the default Compiz shortcuts may seem unfamiliar; the most commonly used ones are the Super key (typically the Windows key on your keyboard) and Button1 (usually your left mouse button).

You can also add the various keystroke combinations for certain tools by clicking the button where the current keystroke combination is shown and making your new choices in the Edit window that appears (Figure 9-21). When you're done with the settings for an individual feature, click the **Back** button in the lower-left corner of the Compiz Settings Manager window to go back to the main screen.
