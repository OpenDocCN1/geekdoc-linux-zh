# Some Goofy Useful Fun with the Command Terminal

A rather cool thing about typing in the command Terminal is that you might call short-term memory. Try it by typing the word cherry and pressing ENTER. Ignoring the command-not-found message, go on and type vanilla and press ENTER. Now type gelato and press ENTER. So far, so dumb, right? Well, not really. Let's try everything you typed far again, but this time's left to it with one key.

Huh?

Yes, just press the up arrow key once, and what do you see? That’s—the last command you typed appears, in which case would be gelato. Press the up arrow key again, and the command that you typed before that appear—vanilla. One more time? Yes, cherry. And one more time for the finale ... I like cherries so much.

Considering what we have thus, this may all seem a bit silly, but imagine you're not typing little words and instead have to deal with longer strings, like a simple copy (which you'll learn about in this chapter) like this:

```
cp Photos/mypics/stprier/coastal/ontbeach_27.jpg /home/frog/photos_for_mom/stprier
```

By typing you are copying an image called onbeach_1.jpg from the coastal folder to another called onbeach_1. If you wanted to copy another photo in the coastal folder, onbeach_16.jpg, for instance, you could simply press the up arrow key once, use the left arrow key and DELETE key to move over to and delete the 27, and replace it with 16. All in all, it would be much simpler and much faster. It would also help you avoid mistakes in typing. Not so dumb anymore, eh?

# Nontoxic Commands

As you know all, all of this typing is easy enough, but to actually do something useful with your Terminal, you need to type commands—and there are more of them than you could ever hope or know. To get started, we will begin with some commands that are easy to understand, nontoxic, and completely kitten friendly.

# $whoami

There is no command as easy, safe, or as seemingly useless as whoami. Rather than help with multiple personality disorders discover who they are at any given moment, the whoami command simply tells you user is currently logged in. Try it by typing whoami the $ and then pressing the ENTER key. Remember that commands are case sensitive.

The Terminal will now tell you the username of the person logged in. If you are logged in as frog, you should get frog as the answer to your command.
