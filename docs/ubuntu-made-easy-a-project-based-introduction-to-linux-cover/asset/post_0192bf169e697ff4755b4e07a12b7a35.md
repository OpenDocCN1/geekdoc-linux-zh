To receive files via Bluetooth from another Bluetooth-capable device, you have to first set up your computer to allow such transfers. To do this, bring the Dash and open Personal File Sharing. In the Personal Sharing Preferences window that appears, check the **Receive files in Downloads folder over Bluetooth**. For your safety (so that no one can send files to you without your permission), select **Only for set devices** in the **Accept files** drop-down menu. # Backing Up Your Files

You’ve worked hard to accumulate all of your files. Hours of typing, hundreds of photos, music of CDs—they’re all on the hard disk. So, what happens to them if something goes wrong with your computer? In many cases the answer is, unfortunately, that all of the data is lost. To avoid the pain of this experience, you’ll want to make regular backups.

Plenty of backup utilities are available, but Ubuntu comes with one installed by default, simply, Backup. Open the Dash and search for Backup to open it. Since you haven't created any backups yet, you can just use my backup settings in the window that appears.

Now is a good time to decide what you’re going to store your backups. I have an external USB hard that does the trick, but you can use a USB drive, recordable CD or DVD, or even a web server. I’d recommend putting your backups on the same computer. The best policy is to put some distance between the original files and the backups if there’s a fire or some other disaster, you will have an intact copy. Make sure you have enough space for the backup too; regular recordable CDs are only 700MB, but my Pictures folder alone weighs in at a whopping 5.8GB!

Connect, or otherwise prepare your chosen backup device and click the Storage tab in the window. You will see a window like the one in Figure 7-20. Choose the location in which you’d like to save the backup files from the drop-down menu. Depending on which option you choose, you might have to enter some more details; for example, if you choose Local Folder, click the Choose Folder button to select exactly where backups will be stored (this can be an external disk like a flash drive or something similar).

If you want to put your backup files on a CD or DVD, you’ll have to save them to somewhere first and then copy that folder onto a disc using the burning software mentioned earlier in this chapter.

Now, select the Folders tab and you’ll be presented with the screen in Figure 7-21. Your first task is to decide what you want to back up, check out the list labeled Folders to back up, which should be empty at the moment. You can add and remove items as you please using the plus and minus at the bottom of the list.

There's another list on that screen, labeled *Folders to ignore*. You can use this to define any files or folders you don't want to back up. Say for example, you want to back up everything in your Home folder except for your pictures—maybe you don't have space on your backup disk. All you need to do is make sure that your Home folder is in *Folders to back up* and your Pictures folder is in *Folders to ignore* list.

When you've chosen what to keep and what to ignore, go to the Overview tab to see a summary. Check that everything looks good, and click Back Up to start the backup. Once that's finished, close the window and forget your backup (or whatever you have).

But remember, there's little point in backing up if you don't do it regularly, since you'll only be able to recover older files (and not recent ones) if something goes wrong. I suggest making a backup once a month, but more than that it's not much of a chore; next time you use Backup, it will remember all of your settings. If you want to do something different, simply change the settings in the Backup window before clicking Back Up.

Canonical, the company behind Ubuntu, now offers an online backup service called Ubuntu One, which you might have seen in the Location list under Storage. Take a look at https://one.ubuntu.com/ for more information on that.

# Recovering from a Backup

Ideally you'll never have to recover your backup, but if you do, here's a quick guide:

- Find your backup disk (if you have one), hook it up to the computer, and open Backup. Make sure you're looking at the Overview tab and click Restore.
- You'll be asked to choose which backup location you want to restore from. Choose the one that corresponds to you saved the backup in the first place (for example, a removable disk or Ubuntu One) and click Forward.
- If you want the files to be put back exactly where they came from, choose Restore to original locations. Otherwise, you can choose a folder to restore them.
- Glance over the summary to make sure everything looks okay and click Apply to restore your files.
- Click Close once the restoration has finished and check that the files have been put back correctly.

Everything should be back to normal now. Pew!

# Removing Unwanted Files

Remember all that talk of keeping a tidy nest at the start of the chapter? Well, now it's time to dust off your spring-cleaning gear and give your Home folder the once over.

The first stop is here: Trash. Sometimes I'm surprised by how much stuff accumulates here; I can go for weeks without emptying it. Luckily, trash lacks the unpleasant odor of its real-world counterpart. All that stands in your way is a quick check to make sure didn't throw away anything. Click the Trash icon at the bottom of the Launcher, and when the window opens, click Empty Trash to delete all the files there. They will be deleted permanently, with no way of getting them back.

Next up is a little more sophisticated. If you're running low on disk space and want to know why (or just want to spawn around your files), open the Dash and search for Disk Usage Analyzer. Open it and, when the window appears, click Scan. Wait until your folders are sized up. A colorful ring chart will appear, accompanied by a list showing where all your hard disk space is being eaten up. Hover the mouse over one of the colored segments on the chart to see what's taking up the most room or double-click one of the segments to zoom in on a particular folder. After that, it's up to you to weed out the disks: Click a folder in the left and choose Move to Trash to delete it.

# Project 7: Creating and Extracting Compressed Files

Since I have been talking about file storage, it seems only to wrap up this chapter by teaching you how to create and extract compressed files. In the Windows world, these are generally referred to as Zip files, in the Linux world, tarball is the operative name. The Linux name, in case you're wondering, comes from the application that is used to create the archive for such files. Compressed archives have two reasons: they let you bundle a bunch of files into one handy package, and squeeze all the files so that they take up less space on your hard disk. If you've ever tried to email a bunch of files to someone, know how useful this can be.

To get the hands-on stuff down, you'll be creating a Windows/Linux/Mac-zip file and extracting it. You can get busy by opening a Nautilus window and creating a couple of dummy files to work with. Do this by going to the Nautilus file and selecting Create New Document > Empty Document. A new file will appear in the Nautilus window, with its name highlighted. You can type a name for the file; I'm using dogwood. Now repeat the process to create a second file; I'll be calling that violet. Use something equally for yours.

Now you have two files to work with, you can create the compressed archive by following these steps:

- Select the two files by clicking your mouse to the side of the files and dragging the cursor (with the mouse button still pressed) over both files until they are highlighted or by holding the CTRL key and clicking each file individually.
- Once both files are highlighted, right-click either and select Compress from the pop-up menu.
