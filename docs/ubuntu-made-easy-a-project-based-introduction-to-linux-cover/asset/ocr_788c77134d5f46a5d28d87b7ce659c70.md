# # Welcome to the Desktop

As you can see at first glance, the Ubuntu desktop (Figure 3-2) is a pretty familiar looking place. In fact, it looks a lot like what you might get used to in Windows, Mac OS, or even another Linux distribution. Look bit closer, however, and you start to notice that things are not quite the same. There is no task bar or Start button at the bottom of the screen, there are no desktop icons, there seems to be only one menu in the top panel, and there is some-things that looks like the Mac OS X Dock on the left side of the screen. Yup, things are a bit different.
