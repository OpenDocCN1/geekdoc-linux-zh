Once you have all your information, you can do a variety of things to check out your hardware's compatibility with Ubuntu. You can simply do so via Yahoo! or Google search by entering your motherboard's name and model plus word Linux. This works for other hardware devices too.

You can also post a question on the Ubuntu User Forums (http://www.ubuntuforums.org/) or one of the other Linux forums or mailing lists on the Web. Chapter 21 might provide you with additional sources of information, and Appendix D lists still other sources. When posting a question, just that you are a newbie and want to know whether anyone has any experience using Ubuntu with the board (or other hardware) in question you will probably get quite a few responses. Linux users are usually rather evangelical in trying to draw in new Penguinists.

# Hardware Requirements

All worries about compatibility aside, you will need to meet some minimum requirements:

+   - Any computer with a 1 GHz or i386-based processor or an Intel or AMD 64-bit processor
- About 5 gigabytes (GB) of hard disk space, though having at least 10GB would be a bit more comfy
- Sufficient memory (RAM)

> NOTE The CD that comes with this board is designed to work on machines with i386-based processors (basically, all the Pentium chips, including Celeron, Xeon, and the new Core Duo, as well as processors from AMD). Though this CD will install Ubuntu on a computer with an AMD or Intel 64-bit processor, it will run in 32-bit mode. To make full use of your 64-bit processor, you will need to download the 64-bit version of Ubuntu. Additional information is provided in Appendix B.

As for random access memory (RAM), the official specs tell you that you need a minimum of 512MB to run Ubuntu. Although you cannot doubt by this, you will get much better with more. My basic rule of thumb, no matter what OS I am dealing with, is that you need the recommended (not the minimum) memory plus 256MB, preferably 512MB Regardless of what the official specs say, put in more. You won't regret it.
