"Project 6B: Installing Software from a PPA—Turtle Arena" on page 90, but
here's a quick reminder of what to save you a bit of page flipping:

+   1. Open the Software Center, click **Edit > Software Sources** and click
the **Other** Software tab in the Software Sources window that pops up.

+   2. Click **Add** and type `ppa:danielrichter2007/grub-customizer` into the box
provided. This is the name of the PPA for Grub Customizer.

+   3. Click **Add Source** and, if prompted, enter your password. The PPA will
be added to the Other Software list.

+   4. Close the Software Center and wait a little while; the PPA will be enabled
in the background. (Annoyingly, it won't tell you until it's finished—see
Chapter 6 for more on this).

Once the PPA has successfully been added to your system, open up the
Software Center and search for Grub Customizer. Install it (as you would any
other application) and then head over to the Dash and open it. You'll
probably be asked to enter your password, so do that and then wait a little
while it loads. Once that has finished, follow these instructions to set Win-
das as the default operating system:

+   1. In the Grub Customizer window, click **Preferences** and then go to the
**General** tab in the settings window that pops up (Figure 19-5).
