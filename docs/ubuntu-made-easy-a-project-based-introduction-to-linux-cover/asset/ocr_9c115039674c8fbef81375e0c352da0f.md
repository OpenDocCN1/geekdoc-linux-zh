Now that ClamAV is up and running, you can scan your system on demand from the Scan menu. To scan a folder, select A Directory. To scan a directory and everything within it, choose Recursive Scan. In either case, the Directory window will appear. Select the folder or disc you want to scan and click OK. ClamAV will start scanning your system. ClamTk will let you know what it is scanning at any moment in the empty space below the button. If it finds anything suspicious, it will list that item in the main pane of window.
ClamAV is set up by default to check for signature updates when it starts. These signature updates tell ClamAV what new viruses to be on the lookout for. If you leave your machine on for days and times at a time, it is probably a good idea to set things up so that ClamAV will automatically check for signature updates daily rather than startup. To do this, go to the Advanced menu and select Scheduler. In the Schedule window, select a time for ClamAV to do its update in the bottom half of the window. Click the Add button when done (it looks like a plus sign). You can also use this to set up a time to regularly scan the system—just select the time you'd like the scan to occur and click Add. When you're finished, click Close.
As mentioned, the only viruses you are likely to encounter during a virus scan are those designed for Windows systems, which cannot affect your Linux system. Although scanning your entire system for viruses won't hurt anything, it's probably better to focus your virus-scanning activities on your Windows partition, if you have one, and on any files that you will be sending as email attachments, particularly to Windows users.
