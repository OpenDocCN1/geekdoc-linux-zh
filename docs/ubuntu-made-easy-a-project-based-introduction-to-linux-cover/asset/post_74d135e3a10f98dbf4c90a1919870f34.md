The GIMP's main strength is in retouching photos. It is also a handy tool for resizing images. You can do this by simply right-clicking an image opened in the GIMP and selecting Image > Scale Image in the pop-up menu. This will open the Scale Image window, where you can set the new size of the image.

The GIMP is also an excellent tool for converting images from one format to another. You can, for example, open a bitmap (.bmp) file and save it as a PNG (.png) file, save it as a JPEG (.jpg) file, as a GIF (.gif) file, and so on. Although this can also be done with other graphics applications, including Shotwell, the GIMP supports an extremely wide variety of file formats, and even lets you save an image file as a compressed tarball, which makes it a true conversion king.

To perform a file conversion, just right-click an image opened within the GIMP and select File > Save As in the pop-menu. You can make the same selection from the File menu if you prefer. Either way, the Save window will appear. In that, you can specify the new file format by replacing the original file extension in the Name Box at the top of the window with the extension for the format you want to convert the image to. If you're not sure what formats are available to you, click the small arrow to the left of the words Select File Type (By Extension) at the bottom of the window and then choose the options from the pane that appears below. To save a work in progress, use the GIMP-native XCF format so that you can continue working on the image later.

# Patch Photo Batch Processor

While the Gimp and Shotwell are quite capable of handling the majority of your photo-organizing and editing choices, they lack an easy-to-use batch file conversion method that allows you to apply various conversions to a group of files at the same time. For example, let's say you want to convert 100 of your photos so they look like black-and-white snapshots with white borders, are 50 percent smaller than the originals, and are saved in .tiff format. Applying all these changes one by one would be excruciating. Fortunately, Patch comes to the rescue! (See Figure 13-13.)

Using Patch is easy—and a bit of hocus-pocus focus. However, its interface might not be obvious for a first-time user. With that, here is a brief rundown on how to use Patch:

- 1. Click the + button in the main Patch window, and the Patch actions window will appear.
- 2. In that, select the action (conversion) you want to apply to your photos and click Add. Repeat this process for any other actions you want to apply.
- 3. Once you have added all the actions, click each action in the main Action List and enter the appropriate parameters for each action (size, file format, size of border, output location, and so on).
- 4. If the actions are not listed in the order you want them to occur, click the action you want to move and change its position using the up and down buttons.

![](img/d35fa962e6f9664d66dc83916f426418_277_0.png)

Figure 13-13: Batch file conversions with Patch

- 5. Once everything is ready, save your Action List with a meaningful name by going to the Action List menu at the top of your screen and selecting Save. This way, you can use it again if needed.
- 6. Next, click the Execute button (the one that looks like gears).
- 7. In the window that appears, select your conversion parameters, making sure to select whether you are converting a whole folder of files, selected files, or whatever you have in the clipboard. I would suggest unchecking the box next to the words Overwrite existing images so that you keep your original images intact (Figure 13-14).

![](img/d35fa962e6f9664d66dc83916f426418_278_0.png)

Figure 13-14: Setting your final conversion parameters in Patch

- 8. Once you have made your choices, click the **Browse Folder/Browse File(s)** button and then select the folders of files or individual files you wish to convert. Once you have made your selection(s), click **Open.**
- 9. You will now be at the window where you selected your parameters. In that window, click the **Batch** button.
- 10. Another window will open showing you which files will be acted upon. Click **Continue** in that window.

Patch will then perform the conversions listed on your Action List in the order listed. It will show the progress of your work, and a small window will appear to tell when it's done. You can see the converted product by clicking **Show Images**. If you failed to choose a destination folder, the newly created conversions should appear in a *Patch* folder on your desktop.

# Inkscape

The GIMP, like other paint programs, creates bitmap images in various formats. In these images, the location and color of every single pixel is recorded. Thus, the image is essentially a collection of dots. The file you create is a hasty map of these pixels, and this map tells you everything in your image is supposed to go when it is displayed or printed.

Vector drawing programs, on the other hand, create vector images, which are actually collections of mathematical formulas representing the shapes in your image. This may sound arcane, and you may be wondering why you should care. But such drawings have advantages in certain cases. One advantage is that vector images take up less space on your hard disk than bitmaps. Another, and most important, advantage is that shapes in vector images retain their smoothness when images are enlarged. A circle created as a bitmap, for example, would begin to show jagged edges (“the jaggies”) when enlarged to any extent, while the same circle in a vector image would remain smooth and round no matter how much you increased its size.

If you are interested in giving a drawing program a go, try Linux's main offering, Inkscape (see Figure 13-16). You can learn how to use Inkscape at the Inkscape home page at http://www.inkscape.org/. Be sure to click the Galleries link on that page to see examples of what you can create with the program, as the image shown in Figure 13-16 from http://foclicipart.net3.net/transporte/
