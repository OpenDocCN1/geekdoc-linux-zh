# Reinstall Ubuntu

It pains me to say it, but if you just can't fix the problem no matter what
try, it might be better reinstalling Ubuntu. To do this, follow the instructions
in Chapter 2. You might need some of the advice on manual partitioning

# Windows Won't Boot

If you installed Ubuntu in a dual-boot setup, you may find that the computer
starts or displays an error message when you try to boot Windows instead of
Ubuntu. Dual-boot Windows setups sometimes have a problem with hibernation and disk checking, try the following steps to see whether you can get
it working again:

- 1. Boot into Ubuntu and mount your Windows partition (see Chapter 19
for details on how to do this).
- 2. Find hiberfil.sys (it should be in the top-level folder of your Windows par-ition, as shown in Figure 22-6) and rename it something like old_hiberfil.sys.
This will cause Windows to ignore all of the hibernation it
has stored.

![](img/d35fa962e6f9664d66dc83916f426418_419_0.png)

Figure 22-6: The top-level folder of a Windows partition, including the hiberfil.sys file

- 1. Restart your computer and boot into Windows by selecting it from the GRUB boot menu. Ideally, Windows will now boot.

- 2. If Windows does not boot and you get a blank screen or it restarts, reboot the computer into Windows again but, this time, press the F8 key a few times immediately after choosing to boot Windows from the GRUB menu. A Windows menu should appear.

- 3. Select the Safe Mode (with Networking) option and see whether that runs. If it does, perform a disk check in Windows. You can do this by going to (My) Computer, right-clicking your hard disk, and selecting Properties. You can find the Error-checking option you need on the Tools tab. Once the check is finished, restart the computer to see whether Windows will start normally.

You may need to repeat the reboot-and-pressing-F8 procedure or twice for it to stick—let it run a disk check whenever it asks to do.

# Sound and Video Problems

If you're met with silence when you try to watch a movie or play a game, either you've rented a Charlie Chaplin film, or you're having issues with your sound card. Assuming it's the latter, you'll find that most sound-related problems in Ubuntu are caused by using incorrect sound card settings. Unfortunately, the number of these settings tends to be overwhelming, and it's rarely obvious which you should change to get things working. Trial and error is the order of the day when it comes to sound problems, I'm afraid, although I've tried to explain as many of the relevant options as possible in this section to help you out.

If the problem has more to do with what you're not seeing when you're not hearing, you're possibly in an easier ride. Video problems tend to be easier to fix—most of the time, all you'll need to find the right piece of software to install and then, erm. Skip to the end of the section for video issues.

# Ubuntu Doesn't Play Any Sounds

There are many reasons why Ubuntu might not be playing sounds. I'll concentrate on some of the more basic issues in this section, but if none of this helps, you can always try the Ubuntu forums or IRC; both are discussed in Chapter 21 troubleshooting.

To start troubleshooting, find a song on your computer and play it in Rhythmbox or the Totem Player. If you need it, a sample called "Josh Woodward - Swansong" is available in the /usr/share/example-content/Ubuntu_Free_Culture_Showcase folder.) You need to have a sound file playing constantly in the background so that you can tell changing any of these settings worked.

If you are unable to start playing the file, Ubuntu may not have detected your sound card. Open a Terminal using the Dash, type apply -1 into it, and press ENTER. If the list of playback devices is empty, your sound card hasn't been detected. In this case, you'll definitely need to get some community support—again, see Chapter 21 for more information using the Ubuntu forums and IRC.

Assuming you can play the file, check that your speakers are turned, turned up, and plugged into the correct socket (it's a light green color). Many times in the past, I've plugged my speakers into the microphone socket and sat there wondering why they were silent. You're confident that your speakers are okay, try the following steps:

- 1. Click the speaker icon on the top panel and select Sound Settings from the menu that pops up. The Sound window will appear (Figure 22-7).
- 2. Make sure that the Mute option is not checked and that the Output slider at the bottom of the window is pulled all the way to the right.
- 3. Click the Applications tab and make sure that none of the applications in the list are muted or set to a low volume.
- 4. Click the Output tab and make sure that the right connector is chosen. If you're not sure, trying different connectors by trial and error until you get one that works. If none of them work, return this option to your initial setting (usually Speakers—Built-in Audio).

If none of this helped, check out https://wiki.ubuntu.com/Audio/ or https://wiki.ubuntu.com/DebuggingSounds/. The latter is a brief guide to identifying the microphone, which requires a little.Chapter 8 if you need to refresh your memory.) # My Microphone Doesn't Work

As long as your sound card is detected correctly, any microphone with a standard jack should work.

To test your microphone, click the speaker icon on the top panel and select Sound Settings from the menu that pops up. In the Sound window that appears (Figure 22-8), you’ll see an Input level, which should dance up and down when you make a noise. If nothing happens to the indicator when you make sound:

- Plug it in. Check that the microphone is plugged into the correct socket (it is often marked by a microphone symbol). Also, be aware that some sound cards can switch inputs, so what you think the microphone might have actually been assigned to something else. In that case, try plugging it into the other.
- Turn it up. Go back to the Input tab and turn up the Input volume, as high as it will go. If your sound card or microphone has a volume control, make sure that is turned up.
- Check that it's muted. Also on the Input tab, make sure the Mute option next to the Input volume is not checked.
- Choose the right input. Ubuntu sometimes detects sound cards as being more than one device. This is often the case for laptops, which might have more than one input (for example, a microphone socket and a built-in microphone). By choosing a different device from the Input tab you can.

Test using a different program. The lack of sound from your microphone could be a problem with the program you're using to record the sound rather than with the way the microphone is set up. Try using a different program to test the microphone. The Sound Recorder (search for it in the Dash) is usually helpful.

# I Can't Play an Audio or Video File

The common reason for not being able to play an audio or video file is that you don't have the necessary codec installed to play the file. A codec is a small piece of software that adds support for a audio/video format into a program. Rhythmbox and the Totem Movie Player find the right codec for you (for example, “Installing MP3 Apps” on page 247). However, if they fail, try the Ubuntu restricted extras package—this package contains a lot of extra codecs. Once the package is installed, close and reopen your audio/video file and see whether it plays.
