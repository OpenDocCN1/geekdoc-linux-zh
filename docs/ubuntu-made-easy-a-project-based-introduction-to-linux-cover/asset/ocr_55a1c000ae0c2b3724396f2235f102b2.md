Fixing Common Problems

![](bbox=[0.17, 0.485, 0.36, 0.633])

The purpose of this chapter is to arm you with some general-purpose tips, tricks, and troubleshooting hints. You'll find step-by-step instructions on how to fix several specific problems, but for the most part I need to keep the discussion general. This is because the way you resolve some issues will depend heavily on the peculiarities of your setup, and there isn't big enough a guide that covers every possible eventuality in suitable detail. Fortunately, the Internet harbors a sizable collection of Ubuntu-related guides, so even if you don't arrive at the exact answer you were looking for, I hope you'll be able to use some of my tips to help you find the right information on the Web.
