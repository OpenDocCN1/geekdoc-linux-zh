## 8D-3: Running configure and make for Xmahjongg

Now that you have downloaded and unearthed the xmahjongg tarball, installation is pretty standard. Here's what you need to do:

- 1. Open a Terminal and move into the new folder by typing `cd xmahjongg` and pressing ENTER. The next step is sort of a setup phase that the configure script in xmahjongg-3.7 folder checks what files, compilers, and other things it needs, and then searches your computer to see whether those things are there and, if so Based on this information, it writes a file called Makefile which is a set of instructions that will tell the `make` command in the subsequent step how to set up specifically for your system.
- 2. Configure the program by typing `./configure` and pressing ENTER. While you are running configure, you will see lots of things flowing through your Terminal window; this is essentially an account of what is going on every step. This can take a bit of time, but don't worry. As long as the text keeps flowing and don't get an error message at the very end of the whole process, all will be well. Once configure has done its thing, you will see your prompt again, and you can go on to compilation. The command reads the Makefile created by configure to see how needs to be set up on machine. It then proceeds to call the compiler to translate the high-level source code to low-level, machine-readable files that can be installed in the subsequent step.
- 3. To perform this translation, type make and press ENTER. Again, you will be treated to even more text flowing through the window and usually a tad longer than the configure process. Once make has done its job and you see your prompt, you are ready to install. Up to this, you have not changed your system in any way. Changes have taken place in the xmahjongg-3.7 folder—your system is still pure as you started. Of course, all is going to end when you perform the final installation step.

## 8D-4: Installing and Running Xmahjongg

Now you've come to the last step in this part of the process, telling your system to install what you have compiled. Note that because installation takes place in permissions-protected parts of your system, you will need to add sudo to the command to give yourself privileges. To perform the installation, type sudo install and ENTER. You will be prompted for your password. After you type it and press ENTER, the installation process will take place. Once your Terminal brings you to the user prompt, Xmahjongg will be installed and ready to run. Just type xmahjongg and press ENTER.

## 8D-5: Cleaning Up/Uninstall Xmahjongg

You would normally tidy up the folder by getting rid of unnecessary files. can do this by using the Terminal and the cd command to go back into the xmahjongg folder, typing make clean, and pressing ENTER. If you want to uninstall Xmahjongg, open a Terminal window, go back to the xmahjongg folder using the cd command, type sudo uninstall, and finally press ENTER. The routine is essentially the same for any applications installed, though you might imagine uninstallation isn't as smooth as the process described in the Ubuntu Software Center. The main reason for the uninstallation process being less cooperative is that the uninstall requires you to keep the project folder, which means you have to keep a bit of clutter you normally wouldn't bother with. On top of this, some projects do not provide a make uninstall runtime at all. This means that you have to track where everything has been installed in your system and then remove each item using a series of sudo rm commands.

All aside, go ahead, have fun, and put your command-line skills to the test. You will have something to tell your grandkids in the future.
