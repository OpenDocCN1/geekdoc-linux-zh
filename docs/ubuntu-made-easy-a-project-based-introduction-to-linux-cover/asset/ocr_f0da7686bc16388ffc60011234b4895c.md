# Why Doesn't My Desktop Look Like That?

If your desktop doesn't look exactly like what you see in the screenshots in this chapter, it likely means that Ubuntu automatically started you up in what is called fallback mode. Fallback mode is an environment that is simpler in appearance and less demanding of hardware workload. It is also referred to as 2D mode. In case you're wondering which mode you are in, the clearest-way is the Dash button. If the Dash button is a dark charcoal-gray with a white Ubuntu logo, then you are in 2D fallback mode.
