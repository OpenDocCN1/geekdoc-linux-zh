# # apt-get

Let's move on to a command that might seem a bit familiar: apt-get. Yes, this command is means of controlling the powerful package download and installation tool, APT, which I covered in Chapter 6. Although it might not be as pleasant as using APT via the command line as is the Ubuntu Software Center, doing so comes in handy. I'll cover the basics for you.
Just for fun to get a bit of antics with apt-get, open a Terminal window, type apt-get moo, and press ENTER. The result of this endeavor, as you will see, is an example of an Easter egg (Figure 8-7), those little snippets of code that programmers seem to enjoy throwing into their work for fun. They are useless, but they are also harmless, and one is a safe step in working with apt-get.

```
rg@mydesktop:~\$ apt-get moo
  \(__\)\n  (oo)
/\n  /\
  /\\\
..."Have you mooed today?"
rg@mydesktop:~\$
```

Figure 8-7: Discovering an Easter egg via apt-get

To actually put the apt-get command to use, by making sure to close any APT frontend you might have open, such as the Ubuntu Software Center. As I mentioned in Chapter 6, you can run only one APT at a time. The coast is clear, you should always start out any operations apt-get with an update of the APT database that you will be downloading the new stuff. To do this, just type the command sudo apt-get update.
