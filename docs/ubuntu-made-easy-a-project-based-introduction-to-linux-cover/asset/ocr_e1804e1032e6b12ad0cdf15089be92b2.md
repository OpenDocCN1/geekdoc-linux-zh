# Use an Older Kernel

Some freezes occur because of problems with kernel updates or drivers. You can try using an older version of the Linux kernel if you have one installed. Take a look at "An Update Ruins Your Day... or System" on page 86 for instructions on running an older kernel.

# Use Rescue Mode

If you've asked for help online, chances will be called upon to type some commands to fix your computer. There's no way to enter any commands if you can't get the machine to start up though, so you'll need to use the rescue mode to get yourself to a command line.

Restart your computer and, as quickly as you can, hold the SHIFT key until GRUB boot menu shows the one in Figure 22-5 appears. If you have a dual-boot, you'll be used to seeing this boot menu anyway. Then use the keyboard to select the topmost item (recovery mode) in its name and press ENTER. Text will flash across the screen for a while, and you will be left at the Recovery Menu.

Use the arrow keys to highlight the netroot and press ENTER. After some text passes, you will be dropped to a root command line that says something like root@eg-laptop:~ and has a blinking cursor. From here, you can type commands that help you fix your computer.

In particular, you might like to updating your system to see whether a subsequent update fixes your problem. (This will only work if you're connected to the Internet). Type apt-get update: press ENTER and wait for the list of package-ages to be updated. Then apt-get dist-upgrade to see whether any more updates are available to install.

NOTE

Wireless Internet connections are unlikely to work in recovery mode. Plug your computer in an Ethernet cable if you can.
