## Project 6B: Installing Software from a PPA—Turtle Arena

Ubuntu enthusiasts catch the charming bug and decide to develop the own software. There are all sorts of little programs out there that some-written to scratch each of them, and plenty of them are available to you, if you know where to get them. Luckily, most of them can be found in personal package archives (PPAs) on Ubuntu's project website, Launchpad. PPAs are miniature software repositories that are an easy way for people to share their home-brewed software with others (emphasis on the home-brewed—sometimes from PPAs doesn't work well). Increasingly, PPAs are also being used by the developers of important soft-like Firefox to get their latest and greatest out to users. Whether it's off-updates or homebrew apps that you're looking for, you can find t PPAS by visiting https://launchpad.net/ubuntu+/ppas/ and searching for what you want.

In this example, you'll see how to install Turtle Arena, a ninja battle game involves a strangely familiar cast of turtles (see Figure 6-12):

- Look into the results to find Turtle Arena, and then click that. You might need to click the Next button once or twice before you see it.
- 3. Copy the bit that says ppa:zturtleman/turtlearena-stable—it's a shortcut that you can use to add this repository, instead of having to use the more cumbersome APT line. (You can see the APT line by clicking the Technical details about this PPA link, if you're curious).
