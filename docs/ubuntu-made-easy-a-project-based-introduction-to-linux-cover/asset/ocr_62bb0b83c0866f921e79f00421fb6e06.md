For example, I will like to use the Movie Player application, as you will learn in Chapter 16, not only all the entries of audacious to *totem*, which is done nicely with audio. In this case, I change all the entries of audacious to *totem* (I leave the entries for VLC as is. the project name of Movie Player. You'll be learning about this useful application in Chapter 16.)

You'll also need to change the Web Browser setting, since the browser you installed is not in Ubuntu. Change that to **firefox** or if you installed it, **chrome**. Your window should then look like Figure 14-11. If you want to change your settings in the future, you can click **Save** this window by the **Edit** menu and select **Properties**.
