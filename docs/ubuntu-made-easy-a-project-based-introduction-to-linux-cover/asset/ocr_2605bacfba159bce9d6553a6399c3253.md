# gThumb Image Viewer

In earlier editions of Ubuntu, an application called gThumb (Figure 13-17), handy for photo-handling chores, came preinstalled. Some folks wish it this did. It has almost all the same features as Shotwell and a few of its (such as creating original web album pages and some limited batch conversion capabilities). That said, it all boils down to what you like, and both gThumb and Shotwell are free and easy to use, there's no harm in trying them both to see which one you prefer.
