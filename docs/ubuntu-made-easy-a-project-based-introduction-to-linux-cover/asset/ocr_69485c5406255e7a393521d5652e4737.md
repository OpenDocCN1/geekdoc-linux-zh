# # Project 19A: Accessing Files on Your Windows Partition (for Dual-Booters)

If you decided to dual-boot when you installed Ubuntu, you'll have a partition somewhere on your hard disk filled with your Windows files and programs (see Chapter 2 if you need a refresher for your partitions work). You can access files by mounting the partition from Ubuntu. When you mount a partition, the files are available to you through Nautilus (and other programs)—mounting is just Linux's way of recognizing a partition and preparing it for use.

# ## 19A-1: Mounting Your Windows Partition

Mounting your Windows partition in Linux used to be a bit of a chore but that isn't the case anymore (at least not in Ubuntu). In fact, all you have to do is open a Nautilus window and click the Windows partition in the sidebar.

You might find more than one hard disk icon in the sidebar, so it is possible that you won't be sure which one your Windows partition actually is. Remember that your Linux partition is represented by the hard disk icon named *File System*, which is listed under the Computer section in the Nautilus sidebar. Things aren't so simple for the Windows partition, unfortunately listed under Devices, rather than Computer, but it could be labeled OS (as shown in the sidebar or with the size of the partition followed by the word *Media* (for example, if your Windows partition is 80GB in size, it might appear as *80GB Media* in the sidebar). Or, it might be something else entirely. Guess which one it is, if necessary—it won't hurt if you get it wrong.
