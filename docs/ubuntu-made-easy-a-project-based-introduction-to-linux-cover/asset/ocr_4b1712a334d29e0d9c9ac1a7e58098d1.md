In this example, you'll install the delightful Crayon Physics game:

+   1. Select the Games category and find the Crayon Physics entry in the list (not the Deluxe version).

+   2. Select Crayon Physics (as in Figure 19-10) and click Install to start the installation process.

![](bbox=[0.298, 0.191, 0.893, 0.553])

Figure 19-10: Selecting a Windows application to install in PlayOnLinux

+   3. An installation wizard will open. Click Next and wait until the game is downloaded and installed.

+   4. When it's finished, click Next to complete the installation. You will be returned to the main PlayOnLinux window.

+   5. To starting, double-click the Crayon Physics entry in the main PlayOnLinux window or select the game from that list and click Run.

Assuming that the game was installed successfully, you'll be met with a Crayon Physics window. Click anywhere in that, and you'll see a landscape scrawled onto your display in crayon, similar to the one in Figure 19-11. The aim of the game is to draw boxes on the screen with your mouse in order to roll a ball onto a star. Every time you get the star, you will move to the next level, where you'll be forced to come up with a more ingenious ball-rolling strategy. It sounds simple, but it's addictive!
