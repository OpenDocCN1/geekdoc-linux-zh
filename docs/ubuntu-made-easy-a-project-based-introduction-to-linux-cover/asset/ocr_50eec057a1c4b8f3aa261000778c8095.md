# 5-2: Setting Up the ScribFire Extension

When Firefox first starts after you've installed the ScribFire extension, click **Tools > ScribFire**, and ScribFire will appear as a resizable pane in the lower half of your current Firefox window. A message will also pop up in a white bubble with instructions on how to add a blog. Follow the instructions to get it working with your blog.
