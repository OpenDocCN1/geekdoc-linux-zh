##11-12: Selecting language input methods from the IBus panel applet

Once Writer appears, click in the document area and then select the input method you want to use from the IBus panel menu. You can now start typing in Writer using the input method you selected. If you do not see the characters you intended to type but instead see nonsense characters (boxes or seemingly random symbols), try using another font.
To switch from one input method to another, there are two options. First, you can go to IBus panel applet and change methods from the menu options. Second, you can switch between methods with hot combinations: CTRL-spacebar toggles IBus on and off, and ALT-SHIFT-L switches you to one input method to the next.

# # Setting IBus to Automatically Start When You Log In

As you probably recall when you first opened the IBus Preferences, how to start up IBus each time you log in to your system. If you use IBus a lot and would prefer foregoing this extra step, you can easily set up your system to start it automatically when you log in.

To do this, open the Language Support window by going to Dash, typing language support, and pressing ENTER. In the Language tab of, select IBus in the drop-down menu next to the words Keyboard input method system, as shown in Figure 11-3, close the window. The next time you log in, IBus will automatically start up and be ready for action when you need to use it.

If IBus does not start automatically the next time you log in, adding it to your system's list of startup applications. To do this, go to Dash, type startup applications, and press ENTER. This will open the Applications Preferences window. In this window, click the Add button. In the Name of the window that appears, type IBus, and in the Command box, type /usr/bin/ibus-daemon -d. When done, click Add and then close the Startup Applications Preferences window.
