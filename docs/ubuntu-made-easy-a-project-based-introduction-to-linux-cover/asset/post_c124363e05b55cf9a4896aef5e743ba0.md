# Burning Multissession CDs

If you are coming from the Windows environment, you may be familiar with multisession CDs. These are CDs on which data is added one session at a time. For example, you burn a few files to disc today and add a few more to the disc tomorrow and each time you add files to the same disc, you are adding a session, which explains the name multisession. You can basically think of the CDs as working like floppy disks (albeit with a lot more storage capacity).

Nautilus has basic support for multisession disks, but let's try something a little more specialized this time: Brasero, which is a fully-tried application that you can use for all of your disc-burning chores.

You can run Brasero by searching for Brasero Disc Burner in the Dash. In the main Brasero window that then opens, click the Data button.

To burn the first session to a CD, drag the files you want to burn from Nautilus into the empty Brasero window (Figure 7-13) or click the Add button (which looks like a plus sign) on the Brasero toolbar to browse for files manually.

![](img/d35fa962e6f9664d66dc83916f426418_151_0.png)

Figure 7-13: Using Brasero to create multisession discs

When you have all the files in place that you want to burn, put a blank disc into the drive, choose a name for the disc using the box at the bottom of screen, and click the Burn button. A Properties window will appear. In that window, check the Leave disc open to add other files later box. (This is the step that sets up a multisession disc.) Once you've done that, click Burn to the starting process. Brasero will eject the disc when burn is complete.

# Burning Subsequent Sessions

Adding a new session to a multisession disc in Brasero is similar to the process for creating the initial session. Here is what you do:

- Run Brasero and click the Data project button.
- Insert your multisession disc into the drive, and when the drive stops spinning and you've gotten any Nautilus windows for that drive out of the way, click the Import button, after which the contents of your previous session will appear in the Brasero window.
- Add files to the previous session, using either of the methods you used when creating the original session (via drag-and-drop or by selecting Add).
- When you have added the files you want, click Burn. The process from then on is exactly the same as it was for the first session. To add files in subsequent sessions, just follow the process outlined yet again.

# Duplicating CDs and DVDs

Now that you are familiar with Brasero, I will introduce another of its features: CD/DVD duplication. To duplicate a disc, place it in the drive, start Brasero, and then click the Disc copy button. In the window that appears (Figure 7-14), click the Copy button.

Brasero will begin copying your disc. When it's done, it will eject the disc and ask you to insert a blank one. A few seconds after you insert the blank disc, Brasero will automatically start writing to it. When the process is complete, the disc will be ejected. Nothing to it.

# USB Storage Devices

You may well be familiar with USB devices. Your printer is likely a USB device, so your scanner. And although your digital camera is not a USB device in the traditional sense, chances are that every time you connect it to your computer in order to transfer photos, you are doing so via a USB connector. Among the most popular USB devices out there are those used for file storage. These include external hard disks; flash memory card readers; and the tiny, finger-sized devices known as flash drives (Figure 7-15). Flash drives are especially popular today and deserved so: they are inexpensive, handy when you need to transfer large amounts of data, and pretty safe in terms of cross-platform (including Linux) compatibility.

![](img/d35fa962e6f9664d66dc83916f426418_153_0.png)

Figure 7-15: USB storage devices

Working with USB storage devices is easy. Just plug the device into one of the USB ports on your computer. The LED on the device will do a bit of blinking while the system reads what's on it, and a few moments later, a Nautilus window will open, revealing the contents of the device. An icon for the USB device will also appear in the sidebar of the Nautilus window and at the bottom of the Launcher. You can copy files to and from the device using the drag-and-drop or copy-and-paste procedures I mentioned earlier in this chapter.

Once you are done and want to remove the device, right-click its icon in the Nautilus window and select Safely Remove in the pop-up menu. If there is any data that needs to be written, the system will wait. Once it's safe, you can pull it out.

# Working with Bluetooth Devices

While we're on the topic of devices, it is probably a good time to learn how to work with Bluetooth. As you mentioned in Chapter 3, if you have a Bluetooth adapter in or plugged into Ubuntu, you can use it to connect to other devices.

# Pairing Devices

Before you can transfer files between devices, you need to pair them. This is how you do:

- Make sure Bluetooth is on for both the computer and the device. Click the Bluetooth icon and select Setup New Device.
- In the setup wizard, Ubuntu will search for nearby devices. Once it discovers a device, click it.
- In the next page of the wizard, a personal identification number (PIN) will appear (Figure 7-17). Input the PIN into the device you're trying to.
- Assuming the pairing is successful, the final page of the wizard will appear. Click Close to complete the pairing process.

# Sending Files by Bluetooth

Send a file by Bluetooth from your computer to another Bluetooth-capable device, click the Bluetooth icon and select Send Files to Device. A window will appear in which you can navigate to the target file. Once you have your selection, click Select. Select window will then appear (Figure 7-18). Select the recipient machine and click Send. Your machine will begin transferring the file. If the recipient is set to seek permission before accepting a Bluetooth file transfer, you or the recipient will have to click a button on the recipient machine before the transfer can be completed.
