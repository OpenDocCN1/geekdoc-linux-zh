# Pop-up Manager

Firefox has a number of other useful features. One is Pop-up Manager, which suppresses annoying pop-up windows that too often appear when you access a new web page. You can enable or disable this feature from the Preferences window **Edit > Preferences**; click the Content icon in the pane of window and then check or uncheck the Block pop-up windows. You can also permit certain sites to provide pop-up windows (some pop-ups are not only useful but also necessary for the correct functioning of a site) by clicking the Exceptions button to the right of Block pop-up windows by entering and inputting the web address for the site in question.

# Multimedia Plug-ins

One of the coolest things about Firefox is that it allows you to expand its functionality by adding various extensions. The commonly used extensions come in the form of plug-ins. These allow web pages to do more than just display text and pictures—you'll need a plug-in to watch videos or play games online, for example. Three plug-ins are used far more widely than any others, so I'll concentrate on those.

# Flash

The most frequently used browser plug-in for any system is Adobe's Flash Player. Flash provides websites with all sorts of exciting multimedia effects and capabilities, and as a result, it is used by a large number of sites. In fact, you've probably seen numerous Flash-enhanced pages without even being aware of it. For example, if you've ever watched a video on YouTube, you enjoyed the wonders of Flash.

How do you get the Flash Player plug-in? Well, if you opted to install third-party software when you first installed your system, you already have it. If not, all it takes a few clicks and a working Internet connection:

+   1. Open the Software Center by clicking its icon on the Launcher or searching for it in the Dash. (You'll learn more about the Software Center in Chapter 6; skip ahead if you need.)

+   2. Type flash in the search box at the top of the window.
3. In the list that appears, double-click the Adobe Flash plug-in item. An information window will appear, hopefully with an Install button (Figure 5-9). If, instead, get a button that says Use This Source, click the button and wait as the Software Center enables an extra software repository that needs (more on this in Chapter 6). The Install button should appear once it's finished.

+   4. Click Install; then, prompted, type your password and click Authenticate. The plug-in will be downloaded and installed.
5. When the plug-in has finished installing, a green checkmark will appear next to its icon in the list. Close the Ubuntu Center and open Firefox (if it was already open, close it and start it up again).
