# Bug Description

Binary package: rhythmbox

If Rhythmbox is playing, stopping gparted (System -> Administration -> GNOME Partition Editor) causes Rhythmbox to stop playing and change to the 'Not Playing' status. This occurs when gparted is 'scanning all devices'. Rhythmbox remains 'Not Playing' until the user presses again.
