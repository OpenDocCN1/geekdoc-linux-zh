# Now You See It; You Don’t

The sidebar is a handy feature, but sometimes you may prefer to have more space to view the contents of your window and thus want to get rid of the bar temporarily. You can do this easily by going to View > Sidebar in the Nautilus menu and by deselecting Sidebar. The checkmark to that entry will disappear, with the sidebar. (Alternatively, press F9 on the keyboard to do the same). To get the sidebar back, return to the View > Sidebar menu and select Sidebar again. The checkmark will reappear, with the sidebar itself.

If you'd prefer not to hide the sidebar but still appreciate a little more space, you can change its size instead. Move your mouse over the gray line that marks the boundary between the sidebar and the rest of the window (note that there's also a subtle change in the shade of the ground color on either side of the line). When it's hovering over it, the mouse pointer will change from its usual appearance, a single arrow, to a horizontal array of arrows pointing in opposite directions. This tells you that the border of the sidebar, the thin gray line, can be dragged to resize the sidebar. Getting the pointer directly over the line can be a little frustrating, in that it might take a few goes to get the double arrow to appear, but once it does, click and drag to resize the sidebar.

# File Handling in Nautilus

Since Nautilus is primarily a file manager, it only makes sense to get down to the business of using it at that level. Of course, most people who use computers today are already familiar with the basics of drag-and-drop and a few others means creating folders and copying, cutting, and moving files. But if you're unfamiliar with one way or another of performing these essential procedures, no worries—I'll spell it out.

# Creating, Naming, and Renaming Folders

Creating a folder is a simple enough task, and there are two ways of going about it. The easiest (in my opinion) is to right-click any empty space within a Nautilus window and select Create Folder in the pop-up menu that appears. If you prefer using menus over right-clicking empty space, you can instead start things selecting File > Create New Folder.

Regardless of where you made your Create Folder selection, a new folder with the Untitled Folder will appear in the Nautilus window. The name box of the folder will be highlighted and surrounded with a black box, which means you can immediately give that folder a name by simply typing one—nothing to click or do other than that. Press ENTER or click any open space in the window to complete the job.

If you later decide that the name you gave your folder needs tweaking or even a complete revision, you can rename it by right-clicking and selecting Rename in the pop-up menu. Alternatively, you can click the folder to highlight it and then select Edit > Rename. After that, you can type the new name for the folder and then press ENTER, or you can click any open space in the Nautilus window to seal the deal.
