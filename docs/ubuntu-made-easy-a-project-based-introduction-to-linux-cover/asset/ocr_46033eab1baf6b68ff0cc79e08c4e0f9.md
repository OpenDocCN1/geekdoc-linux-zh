# 17A-2: Installing Some Linux Classics: Frozen Bubble, Tux Racer, and Pingus

Other games might be called Linux classics, either because they're Linux originals or because they are penguin themed, in honor of Linux's cuddly penguin mascot Tux. One of the most well-known and well-liked of these is Frozen Bubble (Figure 17-4). Frozen Bubble qualifies as the ultimate Linux classic: It was written for Linux, it's Linux (penguin) themed, and Linux versions are always released first. It has since been ported to Mac OS, Windows, and even iPhone and Android systems, but Frozen Bubble's soul is pure penguin.

The objective of Frozen Bubble is simple: Clear the screen by matching-colored bubbles so you can move to the next level. This might sound boring, but never fear—you'll be hooked in time.

Another Linux-themed game you might be interested in is Pingus (Figure 17-5), a traditional maze game based on the classic Lemings. Your goal is to lead your group of adorable little penguins safely to the end of each level, without letting them dashed to bits on the dangerous obstacles awaiting them. The game includes 22 playable levels, and if you're feeling adventurous, you can try some of the untested levels—there are more than 200 of them! For instructions on these extra levels, visit http://pingus.seul.eu/faq.html.
