# HomeBank

Money makes the world round, as the saying goes, and nowhere is that that awareness more keen than at home. If you are looking for personal financial management software to make household budgeting easier to deal with, then you'll be happy to know there are a few Linux offerings for you. The one that is probably easiest to use is called HomeBank (Figure 18-1), which is also available for Windows and Mac OS systems. HomeBank sports a number of features, including the ability to show multiple accounts and generate reports and graphical charts. It can import and export files by the popular finance programs Quicken (.qpf) and 역시 (.qfs), and it can also import spreadsheet-generated comma-separated values (.csv) files. Because it is a cross-platform application, it has a pretty good-sized user community out there, so you should be able to find help online easily if necessary. In fact, there are links to the HomeBank user manual, tutorials, FAQs, and community LaunchPad forum at http://homebank.free/fr/

Figure 18-1: Home money management with HomeBank

You can run HomeBank by going to the Dash and typing homebank and pressing ENTER or by clicking the Application in the Dash and clicking the Office filter.
