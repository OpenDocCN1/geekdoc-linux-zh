When you have all the files in place that you want to burn, put a blank
disc into the drive, choose a name for the disc using the box at the bottom of
screen, and click the Burn button. A Properties window will appear. In that
window, check the Leave disc open to add other files later box. (This is

# Burning Subsequent Sessions

Adding a new session to a multisession disc in Brasero is similar to the process
for creating the initial session. Here is what you do:

+   - Run Brasero and click the Data project button.
- Insert your multisession disc into the drive, and when the drive stops
spinning and you've gotten any Nautilus windows for that drive out of the
way, click the Import button, after which the contents of your previous
session will appear in the Brasero window.
- Add files to the previous session, using either of the methods you used
when creating the original session (via drag-and-drop or by selecting
icking Add).
- When you have added the files you want, click Burn. The process from
then on is exactly the same as it was for the first session. To add files
in subsequent sessions, just follow the process outlined yet again.

# Duplicating CDs and DVDs

Now that you are familiar with Brasero, I will introduce another of its features:
CD/DVD duplication. To duplicate a disc, place it in the drive, start Brasero,
and then click the Disc copy button. In the window that appears (Figure 7-14),
click the Copy button.
Brasero will begin copying your disc. When it's done, it will elect the disc\and ask you to insert a blank one. A few seconds after you insert the blank
disc, Brasero will automatically start writing to it. When the process is com-
plete, the disc will be ejected. Nothing to it.
