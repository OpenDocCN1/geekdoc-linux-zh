# # Tabbed Shell Sessions in the Terminal

To wrap things in this chapter, I thought I'd mention one particularly convenient feature of the GNOME Terminal: just as you can view multiple web pages in one Firefox browser through the use of tabs, tabs in the Terminal application allow you to have more than one shell running at the same time without having multiple windows (see Figure 18-19). This reduces the amount of desktop clutter and makes things easier to deal with. You can open a New Tab by clicking anywhere in the terminal and selecting Open Tab in the pop-up menu.
