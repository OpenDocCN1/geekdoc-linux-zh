# Kids' Stuff

To be sure, Ubuntu has a good number of games available for people of all ages, including children, and a good number of these are educational as well. These include the Tux applications, Tux Typing (Figure 18-9) and Tux Math (Figure 18-10), which allow children to learn typing and math skills in a fun, gamelike atmosphere.
