To perform the adjustments as instructed in the README file, just follow these steps:

+   1. Find the Tk shell, called Wish, by typing locate wish in the Terminal window and pressing ENTER. Note the location on a piece of paper. You may get a number of locations in your search results, but the one you want /usr/bin/wish. If you don't see it, it's probably because you haven't updated the database since 'Project 8A: More Command Practice with pyWings' on page 142, so type sudo updatedb, press ENTER, and try locating Wish.

+   2. Direct the Terminal to the bracola folder by typing cd bracola and pressing ENTER.

+   3. Use the GNU Nano editor, which we used in 'Project 8A: Creating a Plan' on page 141, to edit the bracola.tk file by typing nano bracola and pressing ENTER. The bracola.tk file will appear in the Nano editor in your Terminal window.

+   4. Change the very first line of the bracola file from #!/usr/local/bin/wish to #!/usr/bin/wish,

+   5. In the second line, change /usr/local/games/bracola to /usr/share/games/bracola, which is where you will place bracola in a jit. Your editor window will now look like Figure 8-14.

# 8C-4: Moving the bracola Folder to a Global Location

You could move the bracola folder to the LocalApps folder and play the game from there, as you did with pyWings. This time let's do a bit differently by moving the whole thing to global territory. This not only keeps it safe from any obsessive housekeeping tendencies you might have but also allows all users on the same computer to play the game. You will need to use the sudo command to do this so that you can have access in those protected folders.
