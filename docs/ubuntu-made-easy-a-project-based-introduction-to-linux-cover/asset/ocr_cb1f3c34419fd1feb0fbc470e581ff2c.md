# WHAT IS A HARD DRIVE PARTITION?

I've mentioned partitions several times so far, but I haven't explained what they are. A partition is an area of your hard disk that is "cordoned off" from other areas of the disk. It is a useful way of keeping things such as operating systems separate. Because they are isolated from each other, different partitions are treated as if they are different hard disks attached to your computer, even though they're actually on the same physical hard disk.

Most computers have just one partition that fills up the hard disk. This is like having a house with a completely open floor plan—the whole house is just one room. If you want to remove Windows and install Ubuntu, Ubuntu can take over the entire partition (and thus the entire disk) and kick out the former resident, Windows.

If you want to install two operating systems on the same computer, you have to give each one own partition (after all, they need their). With the house analogy, it a partition wall will carve the house into two rooms. If you choose to dual-boot Windows and Ubuntu, the installer will automatically do this partitioning for you. Of course you can choose how big each partition is: the bigger you make the partition, the more disk space will be available to you in Ubuntu (and the less in Windows). After all, the house is the same; it's just the position of the wall that you're changing.

You can find some information on manually partitioning your hard disk in Appendix C, if you fancy taking control of the process yourself. There should be no need to, however, the Ubuntu installer will be happy to handle the task for you.
