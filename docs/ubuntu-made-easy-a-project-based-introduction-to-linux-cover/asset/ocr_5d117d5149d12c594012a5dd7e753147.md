# Ubuntu CDs

To order an AMD64 version of the Ubuntu Desktop CD, get a replacement for the i386 version that comes with this book, or get the next version of Ubuntu when it comes out (if you don't want to or can't download it), just place an order with any of the following sites. (CDs from most suppliers will cost $5 to $10 or so.)

http://shop.canonical.com/
http://www.osdisc.com/

NOTE The Ubuntu Shop (http://shop.canonical.com/) sells only 32-bit discs.
