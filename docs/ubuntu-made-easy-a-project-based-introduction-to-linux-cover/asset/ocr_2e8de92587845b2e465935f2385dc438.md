You can easily find out where these locations are by typing echo $PATH in a New Terminal window and pressing ENTER. You will see, on your Ubuntu system, these locations are as follows:

```
/n/usr/lib/lightdm/lightdm
/usr/local/sbin
/usr/local/bin
/usr/sbin
/usr/bin
/bin
/usr/games
```

The results of the echo $PATH command will not appear as line divided do in the (easier to read) chant shown here but, rather, in a single line divided by colons: The actual output in the Terminal is /usr/lib/lightdm/lightdm:/usr/local:/usr/local/bin:/usr/sbin:/sbin:/bin:/usr/games.

If the command you typed is in one of those locations, the program or script will run. You as no doubt, however, pyWings is not in any of those locations. It is in /home/username/LocalApps/pyWings and thus is, in a sense, out of your system's sight.

To remedy this situation, you could add the path of your pyWings script to the list of paths that the system checks for run commands so to make the system aware of your new application's existence. However, let's try another method that I think is easier. What you will do is create a link to pyWings, a sort of launchable alias, in one of the locations your system checks for

To create this link, you will use three commands: cd (to change directories), sudo (to give yourself write access to the destination folder), and ln -s (to create the link).

+   1. In the Terminal, type cd /usr/games and press ENTER. This puts you in one of the folders your search when you enter commands.

+   2. Type sudo ln -s /home/username/LocalApps/pywings/pywings.py pywings and press ENTER. (Note that there is a space between the terms pywings.py and pywings at the end of that command string)

The pywings at the end of command string is the name that you are giving the link; the name of the link thus becomes the command you will use to run the application. If you type nothing, the link will be called pywings.py, which would mean three keystrokes for every time you wanted to start the program.

+   3. Type your password when prompted to do so and then press ENTER.
