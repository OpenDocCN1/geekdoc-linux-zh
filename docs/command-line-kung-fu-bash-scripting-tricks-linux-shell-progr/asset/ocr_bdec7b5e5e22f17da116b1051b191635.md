```
Host db1.example.com
IdentityFile ~/.ssh/id_rsa-db1
$ ssh db1.example.com
```

You can use wildcards in the host specification.

```
$ cat ~/.ssh/config
Host db*
IdentityFile ~/.ssh/id_rsa-db1
Host *.work.net
IdentityFile ~/work-files/keys/id_rsa
$ ssh jim@jumboj.work.net
```

If you name your SSH keys after the fully qualified domain names of the hosts they relate to, you can use the % escape character to simplify your ~/.ssh/config file. Instead of having a host entry for each and every server, the % syntax expands to the fully qualified domain name of the host you are connecting to.

```
$ cat ~/.ssh/config
Host *.example.com
IdentityFile ~/.ssh/id_rsa-%h
$ ls -1 ~/.ssh/id_rsa-*
id_rsa-lax-db-01.example.com
id_rsa-lax-db-01.example.com.pub
id_rsa-lax-web-01.example.com
id_rsa-lax-web-01.example.com.pub
$ ssh lax-db-01.example.com
```
