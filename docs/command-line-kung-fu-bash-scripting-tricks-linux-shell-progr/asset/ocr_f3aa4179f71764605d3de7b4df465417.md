# Rudimentary Command Line Stopwatch

```
$ time read
```

This command will stop when you press enter and display how much time elapsed. The real row contains the elapsed time.

```
$ time read
real      0m8.047s
user      0m0.000s
sys       0m0.000s
$ 
```
