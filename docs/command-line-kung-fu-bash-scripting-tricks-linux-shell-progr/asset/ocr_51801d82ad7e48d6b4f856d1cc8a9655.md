# Clear Your Shell History

```
$ history -c
```

To clear your shell history, use the -c option to the history command.

```
$ history | tail -5
    966  ls -lR Music/
    967  find Music/ -type f -is
    968  dstat
    969  sudo vi /etc/motd
    970  cd ..
    971  sudo du -s /home/* | sort -n
$ history -c
$ history
            1  history
$  
```
