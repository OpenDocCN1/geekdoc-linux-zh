In order to use multi user support for screen, the screen executable needs to be setup for root.

```
$ sudo chmod u+s /usr/bin/screen
```

One user must start a screen session. It can be helpful to name your screen sessions with the -S option. To enable multi user session, type ctrl-a followed by “multiruser on<enter”. To allow someone to connect to your session type ctrl-a followed by “acladd username”. To disconnect the other user from the screen session type ctrl-a followed by “aclidel username”.

```
```text
[jason@linuxsvr ~]$ screen -S for-bob
ctrl-a :multiruser on
Multiruser mode enabled
ctrl-a :acladd bob
```
```

When the other use is ready to connect to the screen session, they type screen -x followed by the session identifier. They can connect by PID or by name. IE, screen -x 1234 or screen -x session-name. When they are ready to disconnect, they can leave the screen session like any other by typing ctrl-a d. While the session is shared both parties not only can they see the same screen, but they both provide input by typing.

```
```text
bob@linuxsvr:~$ screen -ls jason/
There is a suitable screen on:
      5428.for-bob          (Multir, attached)
1 Socket in /var/run/screen/S-jason.
bob@linuxsvr:~$ screen -x jason/for-bob
```
