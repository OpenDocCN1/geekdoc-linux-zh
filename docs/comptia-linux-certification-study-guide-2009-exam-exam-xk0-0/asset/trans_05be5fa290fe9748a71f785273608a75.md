掌握针对最新操作系统的四类方法的分类知识，是任何计算机专业人员必须满足的要求。Linux专业人员也不例外。讽刺的是，随着基于内核的架构的发展，当今许多操作系统将其大量计算机硬件功能隐藏在操作系统内部。Linux操作系统并非如此。因此，你应该对Linux计算机硬件的工作原理有充分的了解。对于Linux+考试，你需要对以下组件具备基础的理解：

-   电源是向系统中各种计算机硬件组件[例如，主板和内部磁盘驱动器]提供直流电（DC）的必需设备。电源通过将其转换为计算机芯片所需的直流电，来调节从墙壁插座接收到的交流电（AC）；它被安装在系统单元内部。

-   主板是安装在系统单元内的穿孔电路板，其中包含CPU、内存（RAM）芯片以及用于扩展卡插槽的接口。它是最大的印制电路板；所有其他扩展板[例如，显卡和声卡]都通过它进行接口连接，以接收电源并提供双向通信。

-   CPU是计算机的大脑，负责数据处理，是计算机中最重要的芯片。CPU控制各种硬件组件执行的功能，处理所有发出的软件指令，并决定系统的速度。CPU被安装在系统单元内部。

-   内存以计算机芯片的形式实现，通过存储CPU处理的指令或数据来协助处理数据或指令。

-   扩展板是用于扩展计算机功能的设备，通过使一系列不同的设备[例如，显示器、扬声器和调制解调器]与主板通信来实现。

-   视频适配器是扩展卡，将二进制代码转换为在计算机监视器上看到的图像。

-   存储设备是用于存储数据和信息的内部和外部设备（例如，硬盘驱动器、软盘驱动器和CD驱动器）。

Linux操作系统的成功安装是基于提前进行的良好规划。本节的目的是在操作系统安装过程中向你介绍主要的Linux安装决策。通过截图展示的决策，将显示Linux操作系统的基本安装过程。截图中展示了在安装Linux操作系统过程中你将面对的各种选项。

### Linux 安装过程

Linux操作系统可以从各种不同的本地[例如，CD、数字视频光盘（DVD）和iso镜像]和网络[例如，文件传输协议（FTP）、超文本传输协议（HTTP）、NFS、服务器消息块（SMB）服务器]源进行安装。*本地媒体安装*方法意味着执行独立安装，不依赖于网络连接来访问安装源数据。*网络源安装*方法意味着在你的网络中或通过外部服务器（例如，互联网）有一个安装服务器作为安装数据所在的源。除了几个独特的设置外，每个安装源的安装过程基本相同。“跨网络安装”部分介绍了从网络源安装Linux发行版的独特挑战。本节介绍了从本地媒体安装Linux发行版。Linux本地媒体安装可以使用CD、DVD或.iso源进行。在提供的选项中，作者倾向于使用.iso镜像安装。

由于有各种厂商提供的多个Linux发行版，且有些比其他更受欢迎，因此你面临的首要选择是选择一个Linux发行版。主要的Linux发行版都遵循相同的安装阶段。Gentoo是一个显著的例外。对于本书，作者决定使用openSUSE 11.1 Linux发行版。OpenSUSE 11.1是当时可用的最新版本。

## 练习 2.2：从本地媒体安装

在这个练习中，我们将开始使用DVD媒体进行openSUSE 11.1.1的初始安装。对于此练习，我们将使用以下工具：

3.  使用你的烧录软件应用程序从.iso镜像创建可启动DVD。
4.  使用新创建的可启动网络DVD引导目标机器。
5.  选择**安装（Installation）**。这将启动openSUSE安装程序。

为了从.iso镜像启动安装过程，将该镜像作为CD/DVD加载到虚拟化软件中（例如，VMWARE工作站）。开机或重启已加载.iso镜像的虚拟机，以开始初始引导过程。虚拟机将.iso镜像识别为DVD。当系统完成板载自检时，会出现openSUSE安装程序界面，如图2.2所示。初始屏幕提供各种菜单选项用于安装openSUSE以及安装前所需的额外配置选项。我们将选择**安装（Installation）**选项。

以下是各选项的描述：

-   **从硬盘启动** 此选项用于自动引导一个已存在的Linux操作系统（如果之前已安装在硬盘上）。这可以防止自动安装新的Linux操作系统。

-   **修复已安装的系统** 此选项修复之前安装的系统。它启动图形化修复系统。该选项在本章后面介绍的“系统探测”阶段之后还会再次出现。
-   **安装（Installation）** 此选项从Linux发行版加载微型Linux内核并启动安装过程。
-   **救援系统** 此选项启动一个没有图形用户界面的专门的小型Linux内核。它将Linux内核加载到RAM中，可以修改配置文件，检查文件系统缺陷，验证和/或修改引导加载程序配置，调整分区大小，以及可能需要的其他关键系统修改。

-   **固件测试** 此选项测试系统的基本输入/输出系统（BIOS）和高级配置和电源接口（ACPI）兼容性。
-   **内存测试** 此选项使用memtest86对系统RAM进行系统测试。memtest86程序是一个用于测试基于x86系统物理内存的独立应用程序。

-   **F5 – 内核** 此键允许你禁用潜在的硬件组件[例如，ACPI系统和DMA模式]。
-   **F6 – 驱动程序** 此键安装可选驱动程序或更新现有驱动程序。
