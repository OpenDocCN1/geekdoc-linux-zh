
屏幕。请注意，它只能确认进程正在运行，而无法确认其是否已同步。**D** 是正确的，因为 `ntp` 初始化脚本支持 `status` 标志，该标志可以确认其正在运行并显示同步状态。请注意，并非所有初始化脚本都支持 `status` 选项；答案 **A** 适用于任何服务。

错误答案及解析：**B** 和 **C**。**B** 是错误的，因为 `ps -C ntpd` 会查找“`ntpd`”的精确匹配项。实际的服务是 `ntpd`，因此不会找到匹配项。**C** 是错误的，因为 `ps` 会将 `ntp` 解释为一个选项，这是无效的。

13. 你有一个名为 some_program 的脚本，它需要在 30 分钟后启动，你决定尝试使用 `at` 命令，而不是设置手表闹钟来提醒自己。正确的语法是什么？

- **A.** `at 30 <return> some_program <return> <ctrl> d`
- **B.** `at now + 30 minutes <return> some_program <return> <ctrl> d`
- **C.** `at 30 minutes some_program <ctrl> d`
- **D.** `at now + .5 hours <return> some_program <return> <ctrl> d`

正确答案及解析：**B**。**B** 是正确答案，因为关键字 `now` 理解使用 `+` 号和描述性时间单位来添加时间。`return` 用于开始输入要运行的命令，而 `<ctrl> d` 需要在单独的一行上输入以结束输入。

错误答案及解析：**A**、**C** 和 **D**。**A** 是错误的，因为时间参数不正确且未给出单位。**C** 是错误的，因为时间格式不正确，且要运行的脚本不在单独的一行上。**D** 是错误的，因为时间参数必须以整数形式给出。

14. 你正在将一堆文件从 `/temp` 复制到 `/new_stuff`，但误输入了 `cp temp/* new-stuff` 而不是 `new_stuff`。你一直在研究命令历史记录功能，并希望使用它来正确重新输入命令。你应该输入什么？

- **A.** `! -change new-stuff new_stuff`
- **B.** `!!s/new-stuff/new_stuff`
- **C.** `^new-stuff^new_stuff`
- **D.** `history -r new-stuff new_stuff`

正确答案及解析：**C**。**C** 是正确的，因为第一个 `^` 标识要查找的文本，第二个 `^` 标识将替换查找到的文本的内容。

错误答案及解析：**A**、**B** 和 **D**。**A** 是错误的，因为单个 `!` 期望的是历史记录文件中的行号或开头字符；它不接受选项。**B** 的语法是错误的；“大于号”应该是前斜杠，即正确的语法是 `!!/new_stuff/ new_stuff`。**D** 是错误的，因为 `history` 命令的 `-r` 选项不用于替换。

15. 你刚刚创建了一个新脚本 my_new_script 并想运行它。你记得在执行时通过输入 ./my_new_script 为其提供显式路径，但你只收到一个错误，提示你没有权限运行该文件。你记得需要给自己赋予该文件的执行权限。你该怎么做？

- **A.** `chmod 744 my_new_script`
- **B.** `chmod 666 my_new_script`
- **C.** `chmod u+w my_new_script`
- **D.** `chmod g+x my_new_script`

正确答案及解析：**A**。**A** 是正确的，因为它将文件的权限设置为允许所有者读、写和执行，但仅允许组和其他人读取。

错误答案及解析：**B**、**C** 和 **D**。**B** 将用户、组和其他人的权限设置为读和写，但不包括执行。**C** 也为文件所有者添加了写权限，但没有添加所需的执行权限。**D** 为文件的组添加了执行权限。请注意，即使你是文件组的成员并且你是所有者，你仍然需要用户执行权限才能执行该文件。

## 第 7 章：安装应用程序

1. 财务部门的一名用户找了你，告知他们有一个核心应用程序有新版本可用。安装过程必须尽可能顺利。你被要求执行升级。安全升级现有应用程序的正确语法是什么？

- **A.** `rpm -uvh`
- **B.** `rpm -ivf`
- **C.** `rpm -Uvh`
- **D.** `rpm -Ivh`

正确答案及解析：**C**。答案 **C** 是正确的，因为安全升级现有应用程序所需的开关是 `-U`。

错误答案及解析：**A**、**B** 和 **D**。答案 **A** 是错误的，因为 `-u` 是无效开关；开关是大小写敏感的，正确的开关是 `-U`。答案 **B** 是错误的，虽然新应用程序包将被安装，但它将被强制（`-f` 开关）安装在现有应用程序之上，这可能会产生非常不需要的结果。答案 **D** 是错误的，因为 `-I` 是无效开关；正确的开关是 `-U`。

2. 你使用了命令 `tar -czvf work.tar` 来压缩一个 tar 包。结果会是什么？

- **A.** 使用 `gzip` 压缩的存档文件，并带有 `gz` 扩展名
- **B.** 使用 `gzip` 压缩的存档文件，并带有 `tgz` 扩展名
- **C.** 使用 `bzip` 压缩的存档文件，并带有 `bz2` 扩展名
- **D.** 使用 `bzip2` 压缩的存档文件，并带有 `bz2` 扩展名

正确答案及解析：**B**。答案 **B** 是正确的，因为该命令将使用 `gzip` 压缩 tar 包并赋予其 `tgz` 扩展名。

错误答案及解析：**A**、**C** 和 **D**。答案 **A** 是错误的，因为 `gz` 是给直接使用 `gzip` 压缩而未使用 `tar` 的文件分配的。答案 **C** 是错误的，因为 `tar` 不使用 `bzip`。答案 **D** 是错误的，因为 `tar` 不使用 `bzip2`。

3. 你下载了一个想要安装的程序的源文件。你已经解包了存档，想知道是否有关于如何编译它的说明。你应该首先寻找什么？

- **A.** 在目录结构中查找名为 `configure` 的文件。
- **B.** 在目录结构中查找名为 INSTALL 的文件。
- **C.** 在目录结构中查找名为 FIRST 的文件。
- **D.** 在目录结构中查找名为 `make` 的文件。

正确答案及解析：**B**。答案 **B** 是正确的，因为许多软件包会附带一个名为 INSTALL 的文本文档，以告知用户如何编译和安装。

错误答案及解析：**A**、**C** 和 **D**。答案 **A** 是错误的，因为 `configure` 是用于为软件配置环境的脚本。答案 **C** 是错误的，因为这并不是与软件捆绑在一起时公认的文件。答案 **D** 是错误的，因为 `make` 用于编译和安装软件。

4. 你需要在一个拥有 .deb 软件库的系统上添加一个新的本地库。你应该编辑哪个文件来实现这一点？

- **A.** `/etc/apt/source.list`
- **B.** `/etc/apt.d/sources.list`
- **C.** `/etc/apt.ap.d/sources.list`
- **D.** `/etc/apt/sources.list`

正确答案及解析：**D**。答案 **D** 是正确的，因为 sources.list 文件通常位于 /etc/apt 目录中。

错误答案及解析：**A**、**B** 和 **C**。答案 **A** 是错误的，因为这并非正确的文件，应该是 /etc/apt/sources.list。答案 **B** 和 **C** 是错误的，因为不存在 apt.d 目录。

5. 你想在桌面上安装一个新的 ftp 程序。你当前运行的是该软件的第 5.4 版本 8。你应该下载哪个文件才能将此软件升级到可用的最新版本？

- **A.** `ftp-6.0-8.i386.rpm`
- **B.** `ftp-9-6.0.i386.rpm`
- **C.** `ftp-5.4-8.i386.rpm`
- **D.** `ftp-6.0.i386.rpm`

正确答案及解析：**A**。答案 **A** 是正确的，因为这是最新发布版（版本 6.0，发布版 8）。

错误答案及解析：**B**、**C** 和 **D**。答案 **B** 是错误的，因为文件格式不正确。文件格式为 name-version-release.architecture.rpm。答案 **C** 是错误的，因为这是版本 5.4，发布版 8，与你已安装的版本相同。答案 **D** 是错误的，因为文件格式不正确（参见答案 B）。

6. 你有一个使用 yum 管理软件包的 Linux 版本。你将要移除当前加载在其中的 MySQL 数据库组，以便安装 PostgreSQL。移除 MySQL 数据库组的正确命令是什么？

- **A.** `yum removegroup MySQL`
- **B.** `yum groupremove 'MySQL database'`
- **C.** `yum remove 'MySQL database'`
- **D.** `yum remove --force 'MySQL database'`

正确答案及解析：**B**。答案 **B** 是正确的，因为这会移除整个软件包组。
