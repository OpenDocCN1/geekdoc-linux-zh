The mode is a `+`, `-`, or `=` to add, remove, or set exactly a list that consists of valid option letters described in the `lsattr` section earlier. An example is `chattr +dcs /home/bob/temp_stuff`

This would mark bob’s `temp_stuff` file to not be backed up, be compressed, and when it gets deleted, the space it used to occupy would be overwritten with zeros.
