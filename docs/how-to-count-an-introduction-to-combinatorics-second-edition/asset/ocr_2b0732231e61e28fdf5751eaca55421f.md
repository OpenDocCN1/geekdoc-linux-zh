12.2.1A It is clear that the identity element, $0$, of the group $(\mathbf{R}, +)$ satisfies GA1 as rotation through an angle $0$ leaves each point in its original position. That is, for each point $(x, y) \in \mathbf{R}^2, 0 \triangleright (x, y) = (x, y)$. A rotation through an angle $\theta$ followed by a rotation through an angle $\phi$ has the same effect as a rotation through an angle $\phi + \theta$. That is, $\phi \triangleright (\theta \triangleright (x, y)) = (\phi + \theta) \triangleright (x, y)$. So GA2 is also satisfied.

12.2.2A Let $id$ be the identity element of $S_n$. Then for all $v_v, v_r \in V_n, id \triangleright (v_v, v_r) = (v_{id(v_v)}, v_{id(v_r)}) = (v_v, v_r)$. Thus GA1 holds. For all $\sigma, \tau, \epsilon \in S_n$ and all $v_v, v_r \in V_n$ we have

$\sigma \triangleright (\tau \triangleright (v_v, v_r)) = \sigma \triangleright (v_{\tau(v_v)}, v_{\tau(v_r)}) = (v_{\sigma(\tau(v_v))}, v_{\sigma(\tau(v_r))}) = (v_{\sigma(\tau(v_v))}, v_{\sigma(\tau(v_r))}) = (\sigma \circ \tau) \triangleright (v_v, v_r)$.

So GA2 also holds.

12.2.3A Suppose $g \triangleright x = h \triangleright x$. Then $g^{-1} \triangleright (g \triangleright x) = g^{-1} \triangleright (h \triangleright x)$. Hence, by GA2 and GA1, $(g^{-1}h) \triangleright x = g^{-1} \triangleright (h \triangleright x) = g^{-1} \triangleright (g \triangleright x) = (g^{-1} \ g) \triangleright x = e \triangleright x = x$. The converse is proved similarly.

12.3.1A The points obtained by rotating the point $(1,0)$ about the origin consist of all the points on the circle with center $(0,0)$ and radius 1. So the orbit of $(1,0)$ is this circle. A rotation about the origin leaves the point $(0,0)$ in its original position. So the orbit of this point is just the set $\{(0,0)\}$ consisting of the point $(0,0)$ by itself.

12.3.2A For all points $(x, y) \in \mathbf{R}^2, 0 \triangleright (x, y) = (x + 0, y + 2(0)) = (x, y)$, so GA1 is satisfied. Also, for all $t, \ u \in \mathbf{R}$, $t \triangleright (u \triangleright (x, y)) = t \triangleright (x + u, y + 2u) = ((x + u) + t, (y + 2u) + 2t) = (x + (u + t), y + 2(u + t)) = (t + u) \triangleright (x, y)$, and hence GA2 is also satisfied.
