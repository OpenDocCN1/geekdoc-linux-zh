**14.3.1A** The symmetries of a square, the corresponding permutations of the vertices, and their cycle types are listed in the table below.

![](bbox=[0.8, 0.08, 0.88, 0.15])

|     |       |        |
|:----|:------|:-------|
| $e$ | (1)(2)(3)(4) | $x_1^4$ |
| $a$ | (1 2 3 4) | $x_4$    |
| $b$ | (1 3)(2 4) | $x_2^2$  |
| $c$ | (1 4 3 2) | $x_4$    |
| $h$ | (1 4)(2 3) | $x_2^2$  |
| $v$ | (1 2)(3 4) | $x_2^2$  |
| $r$ | (1)(2 4)(3) | $x_1^2 x_2$ |
| $s$ | (1 3)(2)(4) | $x_1^2 x_2$ |

We therefore see that the cycle index of this group of permutations is

$\frac{1}{8} (x_1^4 + 2x_1^2 x_2 + 3x_2^2 + 2x_4).$
