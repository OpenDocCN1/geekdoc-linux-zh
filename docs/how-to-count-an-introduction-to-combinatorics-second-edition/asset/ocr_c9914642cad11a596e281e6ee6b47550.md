P may not be the only set of p vertices such that all the edges joining them are red, or all these edges are blue, and hence this estimate may involve some double counting). Hence, if the inequality

```
$$2^{C(t, 2)}>2 C(t, p) 2^{\gamma}\tag{16.2}$$
```

holds, there must be at least one coloring of K, without either a red K, or a blue K.

Now,

```
$$\begin{gathered}2^{C(t, 2)}>2 C(t, p) 2^{\gamma} \Longleftrightarrow 2^{C(t, 2)}>2 C(t, p) 2^{C(2^{\gamma}-C(p, 2)}, \text{ by the definition of } s, \\\Longleftrightarrow 2^{s\cdot C(p, 2)}>2 C(t, p)\tag{16.3}\end{gathered}$$
```

It follows from Lemma 16.7 that,

```
$$\text{if } \left(\frac{t}{p}\right)^{p} e^{p}<2^{C(p, 2)}, \text{ then } 2 C(t, p)<2^{C(p, 2)}.\tag{16.4}$$
```

Now, as $C(p, 2)=(p(p-1))/2$,

```
$$\begin{aligned} & \left(\frac{t}{p}\right)^{p} e^{p}<2^{C(p, 2)} \Longleftrightarrow \left(\frac{t}{p}\right)^{p} e^{p}<\left(\frac{p^{-1}}{2}\right)^{p} \\\Longleftrightarrow & \frac{t e}{p}<2^{\frac{p^{-1}}{2}} \Longleftrightarrow t<\frac{p 2^{\frac{p^{-1}}{2}}}{e \sqrt{2}}\Longleftrightarrow t<\frac{p(\sqrt{2})^{p^{-1}}}{e}\tag{16.5}\end{aligned}$$
```

So if t satisfies the inequality 16.5, it follows from the implication 16.4 that the inequality 16.3, and hence also the inequality 16.2 holds. That is, if t satisfies the inequality 16.5 there is a coloring of K, with neither a red K, nor a blue K, It follows that $R(p, p) \gtrsim (p (\sqrt{2})^{p-1}) / e$. This completes the proof.

As for upper bounds, we can easily derive an answer from Theorem 16.5.

# **THEOREM 16.9**

For all integers $p \geq 2$, we have

```
$$R(p, p) \leq C(2p-2, p-1) \leq 4^{p-1}.$$
```

**Proof**

It follows immediately from Theorem 16.5 that $R(p, p) \leq C(2p-2, p-1)$. It is straightforward to prove, using mathematical induction, that for all positive integers n, $C(2n, n) < 4^{n}$ (you are asked to do this in Exercise 16.2Δ), and hence $C(2p-2, p-1) < 4^{p-1}.$.
