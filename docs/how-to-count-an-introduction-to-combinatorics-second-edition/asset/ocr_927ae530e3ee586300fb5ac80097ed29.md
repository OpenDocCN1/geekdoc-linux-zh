# 15.3 MORE APPLICATIONS OF THE PIGEONHOLE PRINCIPLE

We now give some more applications of the pigeonhole principle, many of which lead to rather surprising conclusions.

# PROBLEM 15.2

Let $a_1, a_2, ..., a_{100}$ be any 100 integers (positive or zero or negative, distinct or not). Then there exist integers $r, s$ with $0 < r \le s \le 100$ such that the sum $a_{r+1} + a_{r+2} + ... + a_s$ is an exact multiple of 100. (Of course, there is nothing magical about the number 100.)

# Solution

For each integer $t$, with $1 \le t \le 100$, let $u_t = a_1 + a_2 + ... + a_t$ and let $k_t$ be the remainder when $u_t$ is divided by 100. If any of the $k_t$ is 0, then the sum $a_1 + a_2 + ... + a_t$ is a multiple of 100, and the desired result holds. Otherwise, for $1 \le t \le 100$ we have $1 \le k_t \le 99$, and hence by the pigeonhole principle, at least two of the terms $k_t$ must be equal. That is, for some $r, s$ with $1 \le r \le s \le 100$, we have $k_r = k_s$. Thus $a_1 + a_2 + ... + a_r$ and $a_1 + a_2 + ... + a_s$ have the same remainder on division by 100. Hence $(a_1 + a_2 + ... + a_s) - (a_1 + a_2 + ... + a_r)$ is a multiple of 100; that is, $a_{r+1} + a_{r+2} + ... + a_s$ is a multiple of 100, and so the result holds also in this case. Hence the result holds for all sets of 100 integers.
