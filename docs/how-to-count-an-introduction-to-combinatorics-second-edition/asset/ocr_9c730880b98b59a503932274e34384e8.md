8.1.4A We have that P(x) = \sum_{n=1}^{∞} p(n)x^n, and hence P(x)/(1-x) = P(x) × [1/(1-x)] = (p(1)x + p(2)x² + p(3)x³ + p(4)x⁴ +…) (1 + x + x² + x³ + …). The term involving x^n in this product is p(1)x,x^{n-1} + p(2)x², x^{n-2} + … + p(n)x^n,1, and hence the coefficient of x^n is p(1) + p(2) + … + p(n), that is, t(n). Hence x → P(x)/(1 - x) is the generating function for the sequence {t(n)}.

8.1.5A We have seen from the solution to 8.1.2A(ii) that the generating function for the sequence {a(n)}, where a(n) is the number of partitions in which only the even parts can be repeated is given by
R(x) = ((1+x)(1+x³)(1+x⁵))/((1-x²)(1-x⁴)(1-x⁶)… ) = (1+x)/((1-x²)) × (1)/(1-x²) × (1+x³)/((1-x⁶)) × (1)/(1-x⁸)…
= (1)/(1-x²) × (1)/(1-x⁴) × (1)/(1-x⁶) × (1)/(1-x⁸) ×… = (1)/((1-x²)(1-x⁴)(1-x⁶)(1-x⁸)(1-x¹⁰)…(1-x^{2n})…) ,
which is the generating function for the sequence {b(n)}, where b(n) is the number of partitions in which the even parts must be multiples of 4. It follows that for all n, a(n) = b(n).
