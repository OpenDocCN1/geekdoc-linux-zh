Substituting from Equation 2 into Equation 1, we obtain

```
$$\begin{aligned} S(m+1, k) = & \frac{1}{(k-1)!} \sum_{i=1}^{k-1} (-1)^{i-1} C(k-1, s-1)(k-s)^m + \frac{1}{(k-1)!} \sum_{i=1}^{k-1} (-1)^i C(k, s)(k-s)^m \\ = & \frac{1}{(k-1)!} \sum_{i=1}^{k-1} (-1)^{i-1} C(k-1, s-1)(k-s)^m + \frac{1}{(k-1)!} \left\{ C(k, 0)k^m + \sum_{i=1}^{k-1} (-1)^i C(k, s)(k-s)^m \right\} \\ = & \frac{1}{(k-1)!} \sum_{i=1}^{k-1} (-1)^{i-1} (k-s)^m [C(k-1, s-1) - C(k, s)] + \frac{1}{(k-1)!} k^m. \end{aligned}$$
```

Now by Theorems 2.7 and 2.4,

```
$$C(k-1, s-1) - C(k, s) = -C(k-1, s) = \frac{k-s}{k} C(k, s). \quad (4)$$
```

By Equations 3 and 4,

```
$$\begin{aligned} S(m+1, k) = & \frac{1}{(k-1)!} \sum_{i=1}^{k-1} (-1)^{i-1}(k-s)^m \left( -\frac{k-s}{k} C(k, s) \right) + \frac{1}{(k-1)!} k^m \\ = & \frac{1}{k!} \sum_{i=1}^{k-1} (-1)^i C(k, s)(k-s)^{m+1} + \frac{1}{(k-1)!} k^m. \end{aligned} \quad (5)$$
```

Finally, $((1/k-1)!)k^m = (1/k!)k^{m+1}$, which is the same as $((1/k!)(-1)^i C(k, 0)(k-s)^{m+1}$ when $s=0$. So Equation 5 is equivalent to

```
$$S(m+1, k) = \frac{1}{k!} \sum_{i=0}^{k-1} (-1)^i C(k, s)(k-s)^{m+1},$$
```

and hence the result holds also for $n = m + 1$.

This completes the proof, by mathematical induction, that the result is true for all integers $n \geq 1$.
