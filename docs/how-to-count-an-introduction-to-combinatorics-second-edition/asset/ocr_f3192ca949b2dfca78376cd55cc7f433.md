**5.2.3A** $S(n+1, k+1)$ is the number of ways of placing $n+1$ distinct balls in $k+1$ identical boxes. Consider one particular ball, say b. We first choose r of the other n balls to go in different boxes from that in which we put b. Since there are k other boxes that all must have at least one ball in them, $k \leq r \leq n$. These r balls can be chosen in $C(n, r)$ ways, and they can be placed in the remaining k boxes in $S(r, k)$ ways. Thus, for $k \leq r \leq n$, we can place the $n+1$ balls in $k+1$ boxes with r balls not in the same box as b, in $C(n, r) S(r, k)$ ways. Hence

```
S(n+1, k+1)=\sum_{r=k}^{n} C(n, r) S(r, k)
```
