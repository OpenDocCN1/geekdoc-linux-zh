# **PROBLEM 14.6**

In each of the following cases calculate the cycle type of \pi*.

+   a. \pi \in S_6 and \pi has cycle type $x_1x_2x_5$.  
+   b. \pi \in S_{10} and \pi has cycle type $x_2x_4^2$.  
+   c. \pi \in S_{13}, and \pi has cycle type $x_3^3x_4x_6^2$.

# **Solution**

+   a. We first consider the single cycles of \pi. These are shown in Table 14.7.  
+   Next we consider the pairs of cycles of \pi. These are shown in Table 14.8.  
+   We now obtain the cycle type of \pi* by multiplying all the terms in the second rows of these tables. This gives $x_1 \times x_2 \times x_2 \times x_2 \times x_5 \times x_6 = x_1x_2x_3^2x_5x_6$.
+   
+   Note from this calculation that a single cycle of length 1 in \pi by itself contributes nothing to the cycle type of \pi*. This is because a possible edge has two vertices, and these cannot come from the same cycle of length 1. Also, a cycle of length 2 in \pi contributes just $x_2$ to the cycle type of \pi*, since, although the cycle permutes two vertices, the possible edge with these vertices is mapped to itself by \pi*.
+   
+   b. Here we abbreviate the table by presenting the single cycles and pairs of cycles on one line. Because the cycle type of \pi is $x_2x_4^2$, there are two cycles of type $x_4$, and two pairs $x_4, x_4$.

+   We now obtain the cycle type of \pi* by multiplying together all the terms in the second row of Table 14.9. This gives $x_1x_2x_4^3x_6^{10}$ as the cycle type of \pi*.

+   c. Here we abbreviate the table by just listing the different single cycles and the different pairs of cycles, with the number of each kind, instead of listing them all. For example, from the terms $x_3^3$ and $x_6^2$ we see that we have $3 \times 2 = 6$ pairs of cycle types $x_3, x_6$. See Table 14.10.
