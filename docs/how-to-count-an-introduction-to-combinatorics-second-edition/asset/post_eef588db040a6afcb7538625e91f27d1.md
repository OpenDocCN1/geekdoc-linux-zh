### 12.2.1A
It is clear that the identity element, $0$, of the group $(\mathbf{R}, +)$ satisfies GA1 as rotation through an angle $0$ leaves each point in its original position. That is, for each point $(x, y) \in \mathbf{R}^2, 0 \triangleright (x, y) = (x, y)$. A rotation through an angle $\theta$ followed by a rotation through an angle $\phi$ has the same effect as a rotation through an angle $\phi + \theta$. That is, $\phi \triangleright (\theta \triangleright (x, y)) = (\phi + \theta) \triangleright (x, y)$. So GA2 is also satisfied.

### 12.2.2A
Let $id$ be the identity element of $S_n$. Then for all $v_v, v_r \in V_n, id \triangleright (v_v, v_r) = (v_{id(v_v)}, v_{id(v_r)}) = (v_v, v_r)$. Thus GA1 holds. For all $\sigma, \tau, \epsilon \in S_n$ and all $v_v, v_r \in V_n$ we have

$\sigma \triangleright (\tau \triangleright (v_v, v_r)) = \sigma \triangleright (v_{\tau(v_v)}, v_{\tau(v_r)}) = (v_{\sigma(\tau(v_v))}, v_{\sigma(\tau(v_r))}) = (v_{\sigma(\tau(v_v))}, v_{\sigma(\tau(v_r))}) = (\sigma \circ \tau) \triangleright (v_v, v_r)$.

So GA2 also holds.

### 12.4.1A
Note that in this solution we omit the symbol, $\bullet$, for the group operation.

- i. Suppose that $g \bullet h \in Z(G)$. Then for each $x \in G$, we have that $g \bullet x = x \bullet g$ and $h \bullet x = x \bullet h$, and hence $(g \bullet h) \bullet x = g(h \bullet x) = g(x \bullet h) = (x \bullet g) \bullet h$. Therefore $g \bullet h \in Z(G)$. So $Z(G)$ satisfies the closure property. We have already noted that $e \in Z(G)$. Finally, suppose $g \in Z(G)$, and $x \in G$. Then, $g \bullet x = x \bullet g$. Hence $g^{\bullet -1}g xg^{\bullet -1} = g^{\bullet -1} xg xg^{\bullet -1}$, and hence $xg^{\bullet -1} = g^{\bullet -1} x$. Therefore $g^{\bullet -1} \in G$. It follows that $Z(G)$ is a subgroup of $G$.

- ii. Suppose $g \in Z(G)$, then for each $x \in G$, $xg x^{\bullet -1} = (x \bullet g) x^{\bullet -1} = (g \bullet x) x^{\bullet -1} = g(x \bullet x^{\bullet -1}) = g \bullet e = g$. So the conjugacy class of $g$, that is, $\{xg x^{\bullet -1}: x \in G\}$, is just $\{g\}$. Conversely, suppose that the conjugacy class of $g$ is the set $\{g\}$. It follows that for each $x \in G$, $xg x^{\bullet -1} = g$ and hence $xgx^{\bullet -1} = g$, that is, $x \bullet g = g \bullet x$, and so $g \in Z(G)$.

- iii. We know that the conjugacy classes of $G$ partition $G$, and that number of elements in each conjugacy class divides the order of $G$. Thus if $\#(G) = p^n$, where $p$ is a prime number and $n$ is some positive integer, the possibilities for the number of elements in a conjugacy class are $1, p, p^2, \dots, p^{n - 1}$. Consequently, if $k$ is the number of conjugacy classes of size 1, and there are $t$ other conjugacy classes with sizes $k_1, k_2, \dots, k_t$, we have that for $1 \leq s \leq t$, $p$ is a divisor of $k_s$, and $p^n = k + k_1 + k_2 + \dots + k_t$. Hence, $k = p^n - k_1 - k_2 - \dots - k_t$, and so $p$ is also a divisor of $k$. By part (b), $\#(Z(G)) = k$. We deduce that $\#(Z(G))$ is a multiple of $p$ and hence $\#(Z(G)) \geq p$.
