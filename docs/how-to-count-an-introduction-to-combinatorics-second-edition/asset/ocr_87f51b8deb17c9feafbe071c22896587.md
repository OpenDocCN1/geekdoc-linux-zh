We start with a group $G$ and suppose that $p$ is a prime number that is a divisor of #$(G)$. We let $X$ be the set of all ordered $p$-tuples of elements of $G$ whose product is the identity element, $e$, of $G$. Thus

$X=\{ (g_{1}, g_{2}, \cdots, g_{p}); g_{1}, g_{2}, \cdots, g_{p} \in G \text{ and } g_{1}g_{2}\cdots g_{p}=e\}.$

Recall that $Z_{p}$ is the group of the integers $\{0,1,\ldots, p-1\}$ with addition modulo $p$. We define an action of this group on $X$ by

$k\triangleleft (g_{1}, g_{2},\cdots, g_{p})=\langle g_{k+1}, g_{k+2},\cdots, g_{k+p}\rangle,$ (12.4)

where the addition in the suffixes is carried out modulo $p$.

+   i. Given that #$(G)=n$, how many elements are there in $X$?

+   ii. Prove that Equation 12.4 defines an action that satisfies the group action conditions.

+   iii. Prove that
+   $k\triangleleft (g_{1},\cdots,g_{p})=\langle g_{1},\cdots, g_{p}\rangle$, for all $k \in Z_{p} \Leftrightarrow g_{1}=g_{2}=\cdots = g_{p}$.

It follows from (iii) that the only orbits containing just one element comprise those elements of $X$ of the form $(g, g,\cdots,g)$. Such a $p$-tuple is in $X$, if and only if $g^{p}=1$, and hence either $g=e$, or $g$ is an element of order $p$. Thus to prove that $G$ contains at least one element of order $p$ you need only show that:

+   iv. There is more than one orbit that consists of a single element of $X$.
