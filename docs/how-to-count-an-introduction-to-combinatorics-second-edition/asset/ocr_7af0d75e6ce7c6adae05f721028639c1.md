**14.6.4A** We are given that \(\pi_i\) has cycle type \(x_1^{n-2r} x_2^r\). We can calculate the cycle type of \(\pi_i^*\) as follows:

| \(\pi_i\) | \(x_1\) | \(x_2\) | \(x_1, x_1\) | \(x_2, x_2\) | \(x_1, x_2\) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| *Number* | \(n-2r\) | \(r\) | \(\frac{1}{2}(n-2r)(n-2r-1)\) | \(\frac{1}{2}r(r-1)\) | \((n-2r)r\) |
| \(\pi_i^*\) | – | \(x_1\) | \(x_1\) | \(x_2^2\) | \(x_2\) |

It follows that \(\pi_1^*\) has cycle type \(x_1^{r+(1/2)(n-2r)(n-2r-1)} x_2^{1+(1/2)(n-2r)^2}\). Similarly \(\pi_2^*\) has cycle type \(x_1^{r+(1/2)(n-2s)(n-2s-1)} x_2^{s+(1/2)(n-2s)^2}\). Therefore they have the same cycle type if and only if

\(r+\frac{1}{2}(n-2r)(n-2r-1)=s+\frac{1}{2}(n-2s)(n-2s-1)\)   (1)

and

\(r(r-1)+(n-2r)r=s(s-1)+(n-2s)s\).   (2)

If you do the algebra, you can check that both Equations 1 and 2 are equivalent to

\((r-s)(r+s+1-n)=0\).   (3)

From Equation 3, either \(r=s\) or \(r+s=n-1\). Thus \(\pi_1\) and \(\pi_2\) have different cycle types, but \(\pi_1^*\) and \(\pi_2^*\) have the same cycle type if and only if \(r \neq s\) and \(r+s=n-1\).

+   **14.6.5A** i. Suppose that the graphs \(G_1 = (V_1, E_1)\) and \(G_2 = (V_2, E_2)\) are isomorphic. It follows that there is an isomorphism, say \(\phi\), between them. Then \(\Phi: V_1 \to V_2\) is a bijection, and for each two-element subset \(\{u, v\}\) of \(V_1\), \(\{u, v\} \in V_1 \Leftrightarrow \{\phi(u), \phi(v)\} \in V_2\). Hence, \(\{u, v\} \notin E_1 \Leftrightarrow \{\phi(u), \phi(v)\} \in E_2^*\), that is, \(\{u, v\} \in E_1^* \Leftrightarrow \{\phi(u), \phi(v)\} \in E_2^*\). Hence \(\phi\) is an isomorphism between the dual graphs \(G_1^* = (V_1, E_1^*)\) and \(G_2^* = (V_2, E_2^*)\), which are therefore isomorphic. Conversely, if \(G_1^*\) and \(G_2^*\) are isomorphic, then so also are \(G_1\) and \(G_2\).

+   ii. If a graph has \(n\) vertices, there are \(\frac{1}{2}n(n-1)\) pairs of vertices that may or may not be joined by an edge. So a graph \(G\) has \(e\) edges if and only if its dual, \(G^*\), has \(\frac{1}{2}n(n-1)-e\) edges. So, by (i), the number of different graphs with \(e\) is the same as the number of different graphs with \(\frac{1}{2}n(n-1)-e\) edges.
