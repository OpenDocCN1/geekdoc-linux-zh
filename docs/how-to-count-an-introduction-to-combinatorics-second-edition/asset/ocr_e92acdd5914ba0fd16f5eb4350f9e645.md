We now show that the numbers $p(n, k)$ are the stirling numbers, $s(n, k)$, in disguise. We first show that they satisfy the same recurrence relation as given in Theorem 5.2, namely,

$s(n, k)=s(n-1, k-1)+(n-1)s(n-1, k)$

# **THEOREM 5.3**

For all integers $k$, $n$, such that $2 \leq k < n$,

$p(n, k)=p(n-1, k-1)+(n-1)p(n-1, k)$

# **Proof**

Suppose $2 \leq k < n$. The permutations in $\operatorname { P e r m } ( n , k )$ are the permutations of $\{1, 2, 3, \ldots, n\}$ made up of exactly $k$ cycles. This set can be partitioned into two disjoint subsets, say $X_{1}$ and $X_{2}$, where $X_{1}$ consists of those permutations in $\operatorname { P e r m } ( n , k )$ in which $n$ is in a cycle by itself, and $X_{2}$ consists of all the other permutations in $\operatorname { P e r m } ( n , k )$.

If we have a permutation in $X_{2}$ and delete the cycle $(n)$ we are left with a permutation of $\{1, 2, 3, \ldots, n-1\}$ made up of $k-1$ cycles, that is, a permutation in $\operatorname { P e r m } ( n-1, k-1)$. Conversely, given a permutation in $\operatorname { P e r m } ( n-1, k-1)$, by adding the cycle $(n)$ we obtain a permutation in $X_{2}$. This gives a one-one correspondence between $\operatorname { P e r m } ( n-1, k, -1)$. Hence $\# ( X _ { 1 } ) = \# ( \operatorname { P e r m } ( n-1, k-1) ) = p ( n-1, k-1)\cdot$

Now consider a permutation in $X_{2}$, namely, a permutation of $\{1, 2, 3, \ldots, n\}$ made up of $k$ cycles, and in which $n$ is not in a cycle by itself. If we remove $n$ from the cycle in which it occurs, then we are left with a permutation of $\{1, 2, 3, \ldots, n-1\}$ that is still made up of $k$ cycles, that is, a permutation in $\operatorname { P e r m } ( n-1, k)$. We note that in this process different permutations in $X_{2}$ give rise to the same permutation in $\operatorname { P e r m } ( n-1, k)$. For example, when 6 is deleted from each of the permutations

(1 6 2)(3)(4 5), (1 2 6)(3)(4 5), (1)(2 3)(6)(4 5), (1)(2 3)(4 5 6), (1)(2 3)(4 6 5), we are left with the same permutation, namely, (1 2)(3)(4 5) from $\operatorname { P e r m } ( 5 , 3)$.

Going the reverse direction, given a permutation $(a_{1}, a_{2}, a_{3})(a_{4+1}\ldots a_{\eta_{++}}\ldots a_{n-1})$ in $\operatorname { P e r m } ( n-1, k)$, we can obtain $n-1$ different permutations in $X_{2}$ by inserting $n$ before each $a_{i}$ for $1 \leq j \leq n-1$ in this permutation. Hence $\# ( X _ { 2 } ) = ( n-1) \# ( \operatorname { P e r m } ( n-1, k) ) = ( n-1) p ( n-1, k)\cdot$

Now $\operatorname { P e r m } ( n , k ) = X _ { 1 } \cup X _ { 2 }$ and the sets $X_{1}$, $X_{2}$ are disjoint. It follows that $P ( n , k ) = \# ( \operatorname { P e r m } ( n , k ) ) = \# ( X _ { 1 } ) + \# ( X _ { 2 } ) = p ( n-1, k-1) + ( n-1) p ( n-1, k)\cdot$
