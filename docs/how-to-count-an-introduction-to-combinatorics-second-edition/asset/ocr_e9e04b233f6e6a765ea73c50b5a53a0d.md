It should be clear that this process converts a Catalan sequence, $\mathcal{C}$, into a uniquely determined expression, say $\Gamma^{*}$ . Furthermore, if we start with an expression $\Gamma$, then $\Gamma^{* *}=\Gamma$. We leave it to you to check this.

Thus there is a one-one correspondence between the set of expressions containing $n$ Xs and the set of Catalan sequences made up of $n$ 1s and $n-1$s. Since there are $\mathcal{C}_{n-1}$ such sequences, Theorem 5.7 is proved. It is convenient to specify that $\mathcal{C}_{0}=1$, so that the result of Theorem 5.7 holds also for the case where $n=1$ .

We can use Theorem 5.7 to prove the following relationship between the Catalan numbers.

# **THEOREM 5.8**

For each integer $n \geq 1$, $\mathcal{C}_{n+1}=\sum_{k=0}^{n} \mathcal{C}_{k} \mathcal{C}_{n-k}$.

# **Proof**

By Theorem 5.7 there are $\mathcal{C}_{n+1}$ expressions involving $n+2$ letters. Suppose that $\Sigma$ is one such expression. It follows from Exercise 5.3.4B that there are unique expressions $\Sigma_{1}, \Sigma_{2}$ such that $\Sigma$ is the expression $\left(\Sigma_{1} \Sigma_{2}\right)$. Then $\Sigma_{1}$ contains $k+1$ Xs for some integer $k$, where $0 \leq k \leq n$. Therefore $\Sigma_{2}$ contains $(n+2)-(k+1)=(n-k)+1$ Xs. Thus, for $0 \leq k \leq n$ there are $\mathcal{C}_{k}$ choices for $\Sigma_{1}$ and there are $\mathcal{C}_{n-k}$ choices for $\Sigma_{2}$, and hence $\mathcal{C}_{k} \mathcal{C}_{n-k}$ choices for the pair $\Sigma_{1}, \Sigma_{2}$. It follows that, by taking together all the cases as $k$ runs from 0 to $n$, $\mathcal{C}_{n+1}=\sum_{k=0}^{n} \mathcal{C}_{k} \mathcal{C}_{n-k}$.

In Chapter 7, Section 7.8, we show how the recurrence relation of Theorem 5.8 may be used to find the formula for $\mathcal{C}_{n}$ as given in Definition 5.3.
