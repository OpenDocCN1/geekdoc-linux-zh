
Both the sums in Equation 14.17 are finite, and hence we can interchange the order of the summation to give

$$PI = \frac{1}{\#(G)} \sum_{\pi \in G} \left( \sum_{c=1}^{i} \#(Fix(\pi_c)) W_c \right)$$

(14.18)

In Equation 14.18 the term inside the brackets is the inventory of $Fix(\pi)$, and hence, by Lemma 14.6, it follows from Equation 14.18 that

$$PI = \frac{1}{\#(G)} \sum_{\pi \in G} ct(\pi) \left( \sum_{c \in C} w(c), \sum_{c \in C} w(c)^2, \sum_{c \in C} w(c)^3, \ldots \right)$$

(14.19)

Now adding up the expressions $ct(\pi)$ and then substituting $\sum_{c \in C} w(c)^k$ for $x_k$ produces the same result as first making the substitutions and then adding up the resulting terms, as given by Equation 14.19. Thus Equation 14.19 may be rewritten as

$$PI = \left( \frac{1}{\#(G)} \sum_{\pi \in G} ct(\pi) \right) \left( \sum_{c \in C} w(c), \sum_{c \in C} w(c)^2, \sum_{c \in C} w(c)^3, \ldots \right)$$

(14.20)

Now $(1 / \#(G)) \sum_{\pi \in G} ct(\pi)$ is the cycle index, $CI(G)$, of the group $G$, and hence we can rewrite Equation 14.20 as

$$PI = CI(G) \left( \sum_{c \in C} w(c), \sum_{c \in C} w(c)^2, \sum_{c \in C} w(c)^3, \ldots \right)$$

(14.21)

and this completes the proof of the theorem.

## 14.6 COUNTING SIMPLE GRAPHS

In this section we show how Pólya's counting theorem may be used to count the number of simple graphs with a given number of vertices and edges. The computation, though in principle straightforward, can be rather long. Since our attention will be restricted to simple graphs, we will use "graph" to mean "simple graph" throughout this discussion. (If multiple edges were allowed, then even with just two vertices, there are infinitely many different graphs, as the two vertices could be joined by any number of edges.)

To bring Pólya's counting theorem to bear we need to be able to view graphs in terms of colorings, that is, in terms of mappings from a set $D$ to a set $C$. So we need to think about graphs slightly differently from when we viewed them as made up as a set of vertices together with a set of edges.

Consider, for example, the graph with five vertices in Figure 14.8. It is convenient to suppose that the vertices are the first five positive integers. So $V = \{1, 2, 3, 4, 5\}$. The graph is determined by knowing for each two-element subset, say $\{i, j\}$, of $V$ whether the vertices $i$ and $j$ are joined by an edge or not. So the graph is defined by a function whose domain is the set of all two-element subsets of $\{1,2,3,4,5\}$. We let $D_5$ be this set. Each graph with five vertices can then be described by a mapping

$ f: D_5 \to \{0,1\}, $

such that

$ f(\{i,j\}) = 1 \Leftrightarrow i $ and $ j $ are connected by an edge. (14.22)

In general, for each positive integer $ n $, we let $ D_n $ be the set of all two-element subsets of $\{1, 2, \dots, n\}$. We will call $ D_n $ the set of *possible edges*. A graph with $ n $ vertices then corresponds to a mapping

$ f: D_n \to C, \quad \text{where } C = \{0,1\}, $

which specifies, through the condition in the equivalence 14.22, which pairs of vertices are joined by an edge. We will use the weight function $ w $ defined by

$ w(0) = 1 $ and $ w(1) = c $

so that a graph with $ k $ edges corresponds to a function with weight $ c^k $.

The mapping $\pi: \{1, 2, 3\} \rightarrow \{1, 2, 3\}$ given by $\pi(1)=3$, $\pi(2)=1$, and $\pi(3)=2$ is an isomorphism between these two graphs. Now $\pi$ is a permutation of the set $\{1, 2, 3\}$, and corresponding to it there is a permutation, $\pi^{*}$, of the set, $D_{3}$, of possible edges given by $\pi^{*}\left(\left\{i, j\right\}\right)=\{\pi(i), \pi(j)\}$. For example, $\pi^{*}\left(\left\{1, 2\right\}\right)=\{\pi(1), \pi(2)\} =\{1,3\}$. Because $\pi$ is an isomorphism between the two graphs, for each possible edge $\{i, j\}$ we have that $\{i, j\}$ is an edge of the first graph if and only if $\pi^{*}\left(\left\{i, j\right\}\right)$ is an edge of the second graph. That is, for each possible edge $\{i, j\}$,

$f_{\{2\}}\left(\pi^{*}\left(\{i, j\}\right)\right)=f_{\{1\}}(\{i, j\})$.

It follows that $f_{2} \circ \pi^{*}=f_{1}$, and hence $f_{2}=f_{1} \circ \pi^{*}$. So the action of the permutation $\pi^{*}$ on the set of mappings $f: D_{3} \rightarrow\{0,1\}$ is defined in exactly the same way as the group actions involved when we were considering the colorings of chessboards and other figures.

We are now ready to deal with the general case. For each permutation $\pi$ of the set $\{1, 2, \ldots, n\}$, that is, $\pi \in S_{n}$, there corresponds a permutation, $\pi^{*}$, of $D_{n}$ defined by

$\pi^{*}(\{i, j\})=\{\pi(i), \pi(j)\} \quad \text { for }\{i, j\} \in D_{n} .$

The collection of all these permutations, $\pi^{*}$, forms a subgroup of the group of all permutations of the set $D_{n}$. We let $S_{n}^{*}$ be this subgroup. It acts on the set $X$ of all the mappings $f: D_{n} \rightarrow\{0,1\}$ in the standard way. That is, for $\pi^{*} \in S_{n}^{*}$ and $f \in X$,

$\pi^{*} \triangleright f=f \circ \pi^{*} .$

We can now calculate the pattern inventory of the graphs with $n$ vertices by working out the cycle index of the group $S_{n}^{*}$ and then using Pólya's enumeration theorem. We need to be able to calculate for each permutation $\pi \in S_{n}$ the cycle type of the corresponding permutation $\pi^{*} \in S_{n}^{*}$. We do not need to do this for each permutation in $S_{n}$ separately, because if two permutations $\pi_{1}, \pi_{2} \in S_{n}$ have the same cycle type, then, clearly, so too do the corresponding permutations $\pi_{1}^{*}$ and $\pi_{2}^{*}$. (Note the converse is not, in general, true. It is possible to have permutations $\pi_{1}, \pi_{2}$ that have different cycle types but where $\pi_{1}^{*}$ and $\pi_{2}^{*}$ have the same cycle type. See Exercises 14.6.4A and 14.6.4B. So we only need to work out the cycle type of $\pi^{*}$ in terms of the cycle type of $\pi$, a much smaller task!)

The work in calculating the cycle type of $\pi^{*}$ is simplified by the following observation, which we can illustrate by looking at a particular example. Consider the permutation $\pi = (1\ 2\ 3\ 4)(5\ 6\ 7)(8\ 9)$ from $S_{9}$. We need to work out the effect of the corresponding permutation $\pi^{*}$ on each possible edge $[i, j]$. Our observation is that there are only two essentially different cases to consider. The first involves those possible edges, such as $[1,4)$ and $(5,7)$, whose two vertices occur in the same cycle of $\pi$. The second case is that of possible edges such as $[1,5]$ and $(2,9)$, whose vertices are in different cycles of $\pi$. We consider these cases in turn.

We first consider the case where the vertices of a possible edge occur in the same cycle. It helps to look at some simple particular example first. So we consider the case where $\pi$ consists of a single cycle. As a specific example we let $\pi \in S_{6}$ be the permutation $(1\ 2\ 3\ 4\ 5\ 6)$, which has cycle type $x_{6}$.

It is helpful to think of the numbers $1, 2, \ldots, 6$ as labeling six points on the circumference of a circle as shown in Figure 14.10, and the permutation $\pi$ as moving these points through one-sixth of a turn clockwise around the circle. If we now consider, for example, the effect of the permutation $\pi^{*}$ on the possible edge $[1,3)$, we see that we need to apply the permutation $\pi^{*}$ six times before this possible edge is mapped back to itself. That is, $[1,3)$ is in a cycle of length 6, corresponding to the fact that it takes a complete turn of the circle to move the black dots shown in Figure 14.10(i) back to their original position. This cycle is

[1,3)\rightarrow[2,4)\rightarrow[3,5)\rightarrow[4,6)\rightarrow[1,5)\rightarrow[2,6)\rightarrow[1,3).

[Note that, for example, $\pi^{*}([4,6]) = \pi(4), \pi(6)] = [5,1] = [1,5].$] More generally, each possible edge, with just three exceptions, is in a cycle of length 6. The possible edge $[1,4)$ is in a cycle of length 3,

[1,4)\rightarrow[2,5)\rightarrow[3,6)\rightarrow[1,4),

because it takes only three-sixths (that is, one-half) of a complete turn to move the black dots to a position where they are occupying the same places as they did to begin with.
