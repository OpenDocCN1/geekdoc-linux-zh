That was easy. But what if we return to four unknowns and reintroduce the 60 or charge it to 600? How many solutions then? It is clear that the same technique of listing all possible answers could be tried; the difficulty would seem to be in making sure you count all the solutions once and once only. To be sure, in the case where there are only three unknowns, it is not too difficult, even by the above method, to determine the *number of solutions of each equation* $x+y+z=n$ *without actually listing any of them*. But with more variables we surely need some new ideas. And after these new ideas are introduced in Chapter 3 you will be able to write down the answer to *every problem* of this sort (that is, with any number of variables and any $n$ on the right-hand side) *immediately*.
