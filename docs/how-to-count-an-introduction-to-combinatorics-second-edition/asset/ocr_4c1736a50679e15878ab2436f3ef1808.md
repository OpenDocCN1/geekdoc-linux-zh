# PROBLEM 14.3

Calculate the number of permutations of the following cycle types in the group $S_{24}$.

+   i. $x_3^3 \ x_6^2$
+   ii. $x_1^3 \ x_2^3 \ x_3^2 \ x_5$ 

# Solution

+   i. Using the notation of Equation 14.7, $t=2, \ r_1=3, \ k_1=4, \ r_2=2, \ \text{and} \ k_2=6$, and so the number of different permutations is $24!/(3!4^22!6^2)=24! /27,648=22,440,986,752,504,320,000$.
+   
+   ii. Here $t=4, \ r_1=3, \ k_1=1, \ r_2=4, \ k_2=2, \ r_3=2, \ k_3=4, \ r_4=1$, and $k_4=5$, and so the number of different permutations is $24!/(3!1^3 4!2^2 2!4^2 1!5^1)=24! /368,640=1,683,074,006,437,824,000$.
