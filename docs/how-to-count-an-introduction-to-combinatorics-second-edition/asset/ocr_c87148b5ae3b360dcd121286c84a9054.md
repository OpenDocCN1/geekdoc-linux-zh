same cycle type. See Exercises 14.6.4A and 14.6.4B. So we only need to work out the cycle type of $\pi^{*}$ in terms of the cycle type of $\pi$, a much smaller task!

The work in calculating the cycle type of $\pi^{*}$ is simplified by the following observation, which we can illustrate by looking at a particular example. Consider the permutation $\pi = (1\ 2\ 3\ 4)(5\ 6\ 7)(8\ 9)$ from $S_{9}$. We need to work out the effect of the corresponding permutation $\pi^{*}$ on each possible edge $[i, j]$. Our observation is that there are only two essentially different cases to consider. The first involves those possible edges, such as $[1,4)$ and $(5,7)$, whose two vertices occur in the same cycle of $\pi$. The second case is that of possible edges such as $[1,5]$ and $(2,9)$, whose vertices are in different cycles of $\pi$. We consider these cases in turn.

We first consider the case where the vertices of a possible edge occur in the same cycle. It helps to look at some simple particular example first. So we consider the case where $\pi$ consists of a single cycle. As a specific example we let $\pi \in S_{6}$ be the permutation $(1\ 2\ 3\ 4\ 5\ 6)$, which has cycle type $x_{6}$.

It is helpful to think of the numbers $1, 2, \ldots, 6$ as labeling six points on the circumference of a circle as shown in Figure 14.10, and the permutation $\pi$ as moving these points through one-sixth of a turn clockwise around the circle. If we now consider, for example, the effect of the permutation $\pi^{*}$ on the possible edge $[1,3)$, we see that we need to apply the permutation $\pi^{*}$ six times before this possible edge is mapped back to itself. That is, $[1,3)$ is in a cycle of length 6, corresponding to the fact that it takes a complete turn of the circle to move the black dots shown in Figure 14.10(i) back to their original position. This cycle is

```
[1,3)\rightarrow[2,4)\rightarrow[3,5)\rightarrow[4,6)\rightarrow[1,5)\rightarrow[2,6)\rightarrow[1,3).
```

[Note that, for example, $\pi^{*}([4,6]) = \pi(4), \pi(6)] = [5,1] = [1,5].$] More generally, each possible edge, with just three exceptions, is in a cycle of length 6. The possible edge $[1,4)$ is in a cycle of length 3,

```
[1,4)\rightarrow[2,5)\rightarrow[3,6)\rightarrow[1,4),
```

because it takes only three-sixths (that is, one-half) of a complete turn to move the black dots to a position where they are occupying the same places as they did to begin with.
