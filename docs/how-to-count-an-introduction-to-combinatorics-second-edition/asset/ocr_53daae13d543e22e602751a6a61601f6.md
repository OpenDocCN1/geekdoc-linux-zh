Frobenius’s counting theorem enables us to count the total number of different patterns in the kind of examples given above and in the following exercises. If we wish to answer more specific questions such as finding the number of different ways to color a chessboard so that half the squares are black and half are white, we need to extend the theory. This we do in the next chapter.
