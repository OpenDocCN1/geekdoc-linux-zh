# THEOREM 3.2

Let $k$, $n$ be positive integers with $n \geq k$. Then the number of *positive* integer solutions, $(x_{1}$, $x_{2}, \ldots, x_{k})$, of the equation $x_{1}+x_{2}+\ldots+x_{k}=n$ is $C(n-1,k-1)$, or, equivalently, $C(n-1,n-k)$.

# Proof

Let $X_{i}=x_{i}-1$ for $1 \leq i \leq k$. Then, $X_{1}+X_{2}+\ldots+X_{k}=x_{1}+x_{2}+\ldots+x_{k}-k$ and, for $1 \leq i \leq k, x_{i} \geq 1 \Leftrightarrow X_{i} \geq 0$. Therefore, $(x_{1}, x_{2}, \ldots, x_{k})$ is a solution in positive integers of the equation

$x_{1}+x_{2}+\ldots+x_{k}=n \qquad (3.1)$

if and only if $(X_{1}, X_{2}, \ldots, X_{k})$ is a solution in nonnegative integers of the equation

$X_{1}+X_{2}+\ldots+X_{k}=n-k \qquad (3.2)$

So the number of positive integer solutions of Equation 3.1 is the same as the number of nonnegative integer solutions of Equation 3.2. Hence, by Theorem 3.1, the number of positive integer solutions of Equation 3.1 is $C((n-k)+(k-1),k-1)$, that is, $C(n-1,k-1)$.
