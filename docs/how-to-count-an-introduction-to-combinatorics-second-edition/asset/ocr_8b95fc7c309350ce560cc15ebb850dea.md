We prove the result by mathematical induction. We can let $P_1, P_2, P_3$ be any three distinct points on the sphere. So the result is true for $n \le 3$. Now suppose the result is true for $n = s$ and the sequence of points $P_1, P_2, \dots, P_s$ satisfies the stated conditions. The planes through three of these points make at most $C(s,3)$ different angles with the $xy$-plane. Hence there is a plane, say $\Pi$, distinct from all these planes that meets the sphere. Let $P_{s+1}$ be any point where this plane meets the sphere. Then the points $P_1, P_2, \dots, P_s, P_{s+1}$ also satisfy the condition. So the result holds also for $n = s + 1$. Therefore, by mathematical induction, it holds for all $n$. If the points $P_1, P_2, \dots, P_n$ satisfy this condition, the straight line segments joining pairs of these points do not meet inside the sphere. So the complete graph, $K_n$, and hence every subgraph of it, may be drawn in $\mathbf{R}^3$ with the edges represented by straight line segments.
