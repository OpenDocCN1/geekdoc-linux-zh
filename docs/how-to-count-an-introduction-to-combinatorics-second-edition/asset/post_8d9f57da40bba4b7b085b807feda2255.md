
Because $[x]_n = x(x-1)(x-2)\cdots(x-[n-1])$, the coefficient of $x^i$ in $[x]_n$ is positive or negative according to whether $n-k$ is even or odd. Thus $s(n,k)$ is $(-1)^{n-k} \times$ the coefficient of $x^k$ in $[x]_n$, and, conversely, the coefficient of $x^k$ in $[x]_n$ is $(-1)^{n-k}s(n,k)$.

Table 5.1 gives the values of $s(n,k)$ for $1 \leq k \leq n \leq 5$. To extend this table it would be useful to have a recurrence relation for the numbers $s(n,k)$, analogous to that one we have already given for $S(n,k)$ in Theorem 3.4. And, indeed, we have:

## THEOREM 5.2

For all integers $k, n$ such that $2 \leq k < n$, we have

$$s(n,k) = s(n-1,k-1) + (n-1)s(n-1,k)$$

## Proof

We have that $[x]_n = x(x-1)(x-2)\cdots(x-[n-2])(x-[n-1]) = [x]_{n-1}(x-[n-1])$. Thus

$$[x]_n = x[x]_{n-1} - (n-1)[x]_{n-1} \quad (5.4)$$

Now the coefficient of $x^k$ in $[x]_{n-1}$ is the same as the coefficient of $x^{k-1}$ in $[x]_{n-1}$, and the coefficient of $x^k$ in $-(n-1)[x]_{n-1}$ is $-(n-1) \times$ the coefficient of $x^k$ in $[x]_{n-1}$. Hence $(-1)^{n-k}s(n,k)$ is $(-1)^{n-1-k} s(n-1,k-1) - (n-1)(-1)^{n-k} s(n-1,k)$ is $(-1)^{n-k} [ s(n-1,k-1) + (n-1)s(n-1,k) ]$. Hence $s(n,k) = s(n-1,k-1) + (n-1)s(n-1,k)$.

## PROBLEM 5.4

## Solution

We have, for example, that, by Theorem 5.2, $s(6,4) = s(5,3) + 5s(5,4) = 35 + 5 \times 10 = 85$. In a similar way we obtain the other values shown in Table 5.3.

From the very idea of writing the polynomials $[x]_n$ in terms of the polynomials $x^k$ using the coefficients $(-1)^{n-k}s(n,k)$ and the polynomials $x^k$ in terms of the polynomials $[x]_n$ using the coefficients $S(n,k)$, it is not surprising that the stirling and Stirling numbers are kinds of "inverses" of each other. In fact, if, for some $n$, you take the $n \times n$ matrices $((-1)^{n-k} s(i,j))$ and $(S(i,j))$ and multiply these matrices together, you should obtain something that might surprise you (see Exercises 5.1.2A and 5.1.2B). Of course, it shouldn't be so surprising when you recall that, given the two pairs of equations $u = ax + by, v = cx + dy$, then if these can be solved to give $x = pu + qv, y = ru + sv$, the matrices $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ and $\begin{pmatrix} p & q \\ r & s \end{pmatrix}$ are inverses of each other.

## 5.2 PERMUTATIONS AND STIRLING NUMBERS

Recalling, from Chapter 2, how we expressed permutations as products of disjoint cycles, we begin with a simple definition.

**DEFINITION 5.2** For all integers $k, n$ with $1 ≤ k ≤ n,$ we let *Perm*$(n,k)$ be the set of permutations of the set $\{1,2,3,…,n\}$ made up of exactly $k$ disjoint cycles, and we let $p(n,k)$ be the number of permutations in *Perm* $(n,k),$ that is, $p(n,k) = \#$*Perm*$(n,k).$

Note that in counting the number of disjoint cycles, we include the cycles of length 1, so that, for example, the permutation $(1\ 6\ 2)(3)(4\ 5)$ is in the set $Perm(6,3)$.

## PROBLEM 5.5

Show that, for all positive integers $n$, $p(n,n)=1$ and $p(n,1)=(n-1)!$

## Solution

A permutation in $Perm(n,n)$ is a permutation of $\{1,2,3,...,n\}$ made up of exactly $n$ disjoint cycles. Such a permutation must be made up entirely of cycles of length 1, and so must be the *identity permutation* that fixes each member of the set. Thus there is just one such permutation. That is, $p(n,n)=1$. We have shown that $p(n,1)=(n-1)!$ in the solution to Exercise 2.6.3A.

## PROBLEM 5.6

Find a formula for $p(n,n-1)$.

## Solution

A permutation in $Perm(n,n-1)$ is a permutation of $\{1,2,3,...,n\}$ made up of $n-1$ disjoint cycles. Such a permutation must consist of $n-2$ cycles of length 1 and one cycle of length 2, and is thus entirely determined by the two numbers that occur in the cycle of length 2. These two numbers may be chosen in $C(n,2)$ ways. Hence $p(n,n-1)=C(n,2)= \{n(n-1)\}/2$.

## PROBLEM 5.7

Prove that

$$p(n,2) = \begin{cases} n! \sum_{k=1}^{m} \frac{1}{k(n-k)}, & \text{where } n \text{ is odd, with } n=2m+1, \\ n! \left( \frac{1}{2m^2} + \sum_{k=1}^{m-1} \frac{1}{k(n-k)} \right), & \text{where } n \text{ is even, with } n=2m. \end{cases}$$

## Solution

A permutation in $Perm(n,2)$ consists of two disjoint cycles, of lengths, say, $k$ and $l$, where $k+l=n$. There are $C(n,k)$ ways to choose the numbers making up the cycle of length $k$. For any $k$ of these numbers there are $(k-1)!$ different cycles of length $k$ made up from them, and $(n-k-1)!$ different cycles of length $n-k$ made up from the remaining numbers. So, for $k \ne l$, there are

$$C(n,k)(k-1)!(n-k-1)!(n-k-1)! = \frac{n!(k-1)!(n-k-1)!}{k!(n-k)!} = \frac{n!}{k(n-k)}$$

permutations of $\{1,2,3,...,n\}$ made up of a cycle of length $k$ and a cycle of length $n-k$. In the case where $n=2m$ is even, and $k=l=m$, we need to divide this number by 2, as the order in which the two permutations of length $m$ are written is immaterial. So in this case there are

$\frac{1}{2}\bigg(\frac{n!}{(2m-m)!(2m-m)}\bigg)=\frac{n!}{2m^{2}}$

permutations made up of two cycles each of length $m$. Thus the formula of the problem is correct.

We now show that the numbers $p(n, k)$ are the stirling numbers, $s(n, k)$, in disguise. We first show that they satisfy the same recurrence relation as given in Theorem 5.2, namely,

$s(n, k)=s(n-1, k-1)+(n-1)s(n-1, k)$

## THEOREM 5.3

For all integers $k$, $n$, such that $2 \leq k < n$,

$p(n, k)=p(n-1, k-1)+(n-1)p(n-1, k)$

## Proof

Suppose $2 \leq k < n$. The permutations in $\operatorname { P e r m } ( n , k )$ are the permutations of $\{1, 2, 3, \ldots, n\}$ made up of exactly $k$ cycles. This set can be partitioned into two disjoint subsets, say $X_{1}$ and $X_{2}$, where $X_{1}$ consists of those permutations in $\operatorname { P e r m } ( n , k )$ in which $n$ is in a cycle by itself, and $X_{2}$ consists of all the other permutations in $\operatorname { P e r m } ( n , k )$.

If we have a permutation in $X_{2}$ and delete the cycle $(n)$ we are left with a permutation of $\{1, 2, 3, \ldots, n-1\}$ made up of $k-1$ cycles, that is, a permutation in $\operatorname { P e r m } ( n-1, k-1)$. Conversely, given a permutation in $\operatorname { P e r m } ( n-1, k-1)$, by adding the cycle $(n)$ we obtain a permutation in $X_{2}$. This gives a one-one correspondence between $\operatorname { P e r m } ( n-1, k-1)$. Hence $\# ( X _ { 1 } ) = \# ( \operatorname { P e r m } ( n-1, k-1) ) = p ( n-1, k-1)\cdot$

Now consider a permutation in $X_{2}$, namely, a permutation of $\{1, 2, 3, \ldots, n\}$ made up of $k$ cycles, and in which $n$ is not in a cycle by itself. If we remove $n$ from the cycle in which it occurs, then we are left with a permutation of $\{1, 2, 3, \ldots, n-1\}$ that is still made up of $k$ cycles, that is, a permutation in $\operatorname { P e r m } ( n-1, k)$. We note that in this process different permutations in $X_{2}$ give rise to the same permutation in $\operatorname { P e r m } ( n-1, k)$. For example, when 6 is deleted from each of the permutations

(1 6 2)(3)(4 5), (1 2 6)(3)(4 5), (1)(2 3)(6)(4 5), (1)(2 3)(4 5 6), (1)(2 3)(4 6 5), we are left with the same permutation, namely, (1 2)(3)(4 5) from $\operatorname { P e r m } ( 5 , 3)$.

Going the reverse direction, given a permutation $(a_{1}, a_{2}, a_{3})(a_{4+1}\ldots a_{\eta_{++}}\ldots a_{n-1})$ in $\operatorname { P e r m } ( n-1, k)$, we can obtain $n-1$ different permutations in $X_{2}$ by inserting $n$ before each $a_{i}$ for $1 \leq j \leq n-1$ in this permutation. Hence $\# ( X _ { 2 } ) = ( n-1) \# ( \operatorname { P e r m } ( n-1, k) ) = ( n-1) p ( n-1, k)\cdot$

Now $\operatorname { P e r m } ( n , k ) = X _ { 1 } \cup X _ { 2 }$ and the sets $X_{1}$, $X_{2}$ are disjoint. It follows that $P ( n , k ) = \# ( \operatorname { P e r m } ( n , k ) ) = \# ( X _ { 1 } ) + \# ( X _ { 2 } ) = p ( n-1, k-1) + ( n-1) p ( n-1, k)\cdot$

## THEOREM 5.4

For all integers $k, n$ with $1 \leq k \leq n$, $p(n, k)=s(n, k)$.
