Thus we get a different arrangement for each pair $\{Y, Z\}$ of subsets of $X$, where $Z = X \backslash Y$. There are $\frac{1}{2}(2^n) = 2^{n-1}$ such pairs. +   2. Since, for each positive integer $n$, $S(n, 1) = 1$, Theorem 3.4 would be true for $k = 1$ and $n \ge 2$, if $S(n - 1, 0) = 0$, giving $1 = S(n, 1) = S(n, 2) + S(n - 1, 1) = 0 + 1$. So we stipulate that, for each positive integer $t$, $S(t, 0) = 0$
