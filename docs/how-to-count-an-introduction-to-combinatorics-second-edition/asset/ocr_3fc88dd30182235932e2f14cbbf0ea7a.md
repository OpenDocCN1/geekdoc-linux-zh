# Proof

We first prove the equivalence 11.5. Then we show that we can deduce the equivalence in Equation 11.4.

Since *g* has order *k*, *g<sup>k</sup>* = *e*, and hence, for each integer *m*, *g<sup>mk</sup>* = (*g<sup>k</sup>*)<sup>m</sup> = *e<sup>m</sup>* = *e*. So if *n* is a multiple of *k*, *g<sup>n</sup>* = *e*. Conversely, suppose that *g<sup>n</sup>* = *e*. Let *r* be the remainder when *n* is divided by *k*. Hence 0 ≤ *r* < *k* and for some positive integer *m*, *n* = *mk* + *r*. Then *g<sup>mk + r</sup>* = *e* and hence *g<sup>r</sup>* = *g<sup>mk</sup> g<sup>r</sup>* = *g<sup>mk</sup> g<sup>mk + r</sup>* = *g<sup>n</sup>* = *e*. Since 0 ≤ *r* < *k* and *k* is the least positive integer such that *g<sup>k</sup>* = *e*, it follows that *r* = 0. So *n* = *mk* and so *k* is a divisor of *n*. This proves the equivalence 11.5.

Now suppose *m*, *n* are positive integers with, say, *m* ≥ *n*. Then using the equivalence 11.5, we have that *g<sup>mn</sup>* = *g<sup>n</sup>* ⇔ *g<sup>m</sup>−<sup>n</sup>* = *e* ⇔ *k* is a divisor of *m* − *n* ⇔ *m* ≡ *n* (mod *k*). This proves the equivalence 11.4.

It follows from this lemma that if *g* is an element of order *k* in a group *G*, there are only *k* different elements of the form *g<sup>i</sup>* in *G*, namely, {*e, g, g<sup>2</sup>, …, g<sup>k</sup><sup>−1</sup>*}. It is not difficult to show that these elements form a subgroup of *G* (see Exercise 11.4.3A). This subgroup has order *k*.

In particular, in the case where *G* is finite, by Lagrange’s theorem, *k* is a divisor of the order of *G*. We have thus proved the following useful consequence of Lagrange’s theorem.

# COROLLARY 11.8  
Lagrange’s Corollary

If *G* is a finite group, and *g* ∈ *G*, then the order of *g* is a divisor of the order of *G*.

As with Lagrange’s theorem itself, this corollary only tells us about the possible orders of group elements. For example, you will see from the solution to Exercise 11.4.4B that in the group *S<sub>4</sub>* which has order 24, there are no elements of orders 6, 8, 12, or 24, even though these are all divisors of 24. We are now ready to give the first application of group theory to a combinatorial problem. We do this in the next section.
