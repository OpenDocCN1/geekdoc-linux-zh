We do not have space to discuss other graph algorithms in detail. We only mention briefly that for the traveling salesman problem, as described in Chapter 9, it is not known whether there is an efficient algorithm that gives the route with the least possible weight. Recall that this is the problem of finding a Hamiltonian path of minimal weight. However, a number of algorithms are known that run in feasible time and yield good approximations to the optimal solution.
