$$r = 1 + \frac{n(n+1)}{2} - n + C(n, 4).$$

As

$$\frac{n(n+1)}{2} - n = \frac{n(n-1)}{2} = C(n, 2), \text{ and } C(n, 4) = \frac{n(n-1)(n-2)(n-3)}{4!},$$

we can rewrite this in these equivalent ways:

$$\begin{aligned}r & = 1 + C(n, 2) + C(n, 4) = 1 + \frac{n(n-1)}{2!} + \frac{n(n-1)(n-2)(n-3)}{4!} \\& = \frac{1}{24} n^{4} - \frac{1}{4} n^{3} + \frac{23}{24} n^{2} - \frac{3}{4} n + 1.\end{aligned}$$

Note that $C(n, 2)$ is the number of straight lines joining the points on the circle. So the formula for the number of regions can be expressed as Number of regions = 1 + Number of lines + Number of crossing points inside the circle, and this suggests an alternative proof, which we leave to the reader.
