### 4.1.4A

A positive integer less than or equal to $n$ has a prime factor in common with $n$ if and only if it is divisible by one of $p_1, p_2, \ldots, p_k$. We let $E_i$ for $1 \le i \le k$, be the set of integers in the range from 1 to $n$ that are divisible by $p_i$. Thus $\#\left(\phi(n)\right)=n-\#\left(\cup_{i=1}^k E_i\right)$. By the inclusion-exclusion theorem,

$$
\#\left(\bigcup_{i=1}^k E_i\right)=\sum_{1 \le i \le k} \#(E_i)-\sum_{1 \le i < j \le k} \#(E_i \cap E_j)+... =\sum_{1 \le i \le k} \frac{n}{p_i}-\sum_{1 \le i < j \le k} \frac{n}{p_i p_j}+...
$$

and hence

$$
\phi(n)=n-\sum_{1 \le i \le k} \frac{n}{p_i}+\sum_{1 \le i < j \le k} \frac{n}{p_i p_j}-...=n\left(1-\sum_{1 \le i \le k} \frac{1}{p_i}+\sum_{1 \le i < j \le k} \frac{1}{p_i p_j}-...\right).
$$

Therefore, using the algebraic identity $(1-x_1)(1-x_2)...(1-x_k)=1-\sum_{1 \le i \le k} x_i+\sum_{1 \le i < j \le k} x_ix_j-...,$ it follows that

$$
\phi(n)=n\left(1-\frac{1}{p_1}\right)\left(1-\frac{1}{p_2}\right)...\left(1-\frac{1}{p_k}\right).
$$
