As a partial response to Problem 16B we have shown that, given a colouring of the plane using two colours, and an equilateral triangle, there is a similar (and hence, equilateral) triangle which is monochromatic. There may not be a congruent equilateral triangle as Problem 16.4.3B shows.

Given a non-equilateral triangle the same proof as for Problem 16.5 shows that there is a similar triangle which is monochromatic. That there is always a congruent monochromatic triangle is conjectured, but a proof is still awaited.
