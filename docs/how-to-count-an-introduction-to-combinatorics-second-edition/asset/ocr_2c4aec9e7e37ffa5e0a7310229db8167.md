A coloring of this chessboard, using black and white, may be regarded as a mapping from the set of squares that make up the chessboard to the set of colors. Thus if we let $\{\alpha, \beta, \gamma, \delta\}$ be the set of squares, then each coloring is a mapping

$\mathrm{f}:\{\alpha, \beta, \gamma, \delta\} \rightarrow\{black, white\}.$

Hence the 16 different colorings correspond to the 16 different mappings of this kind. For example, the coloring that we have called C6 shown in Figure 14.3 corresponds to the mapping $f_6$ shown below it.

Corresponding to each symmetry, g, of the square there is a permutation, $\pi_g$, of the set of smaller squares. For example, the quarter-turn rotation of the square, a, corresponds to the permutation

$\pi_a=(\alpha\ \beta\ \gamma\ \delta).$

How does it act on the set of colorings? We can see how the action is defined if we consider what happens when the permutation $\pi_a$ acts on the coloring $f_6$ (Figure 14.4).
