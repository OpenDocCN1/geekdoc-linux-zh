9.3.2B The dual of a graph $G = (V, E)$ is defined to be the graph $G^* = (V, E^*)$, where for all $u, v \in V$, we have $\{u, v\} \in E^* \iff \{u, v\} \notin E$. Thus $G^*$ has the same set of vertices as $G$, and two vertices are joined by an edge in $G^*$ if and only if they are not joined by an edge in $G$. $G$ is said to be *self-dual* if it is isomorphic to $G^*$. For example, in Figure 9.13, graph (ii) is the dual of graph (i). Since these graphs are isomorphic, each graph is self-dual.

+   i. Find all the graphs with four vertices that are self-dual.
+   ii. Give an example of a graph with five vertices that is self-dual.
+   iii. Show that there is no graph with six vertices that is self-dual.
