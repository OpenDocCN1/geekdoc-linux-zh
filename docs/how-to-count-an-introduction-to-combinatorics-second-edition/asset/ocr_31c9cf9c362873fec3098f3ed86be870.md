The mapping $\pi: \{1, 2, 3\} \rightarrow \{1, 2, 3\}$ given by $\pi(1)=3$, $\pi(2)=1$, and $\pi(3)=2$ is an isomorphism between these two graphs. Now $\pi$ is a permutation of the set $\{1, 2, 3\}$, and corresponding to it there is a permutation, $\pi^{*}$, of the set, $D_{3}$, of possible edges given by $\pi^{*}\left(\left\{i_{1} j\right\}\right)=\{\pi(i), \pi(j)\}$. For example, $\pi^{*}\left(\left\{1, 2\right\}\right)=\{\pi(1), \pi(2)\} =\{1,3\}$. Because $\pi$ is an isomorphism between the two graphs, for each possible edge $\{i, j\}$ we have that $\{i, j\}$ is an edge of the first graph if and only if $\pi^{*}\left(\left\{i_{1} j\right\}\right)$ is an edge of the second graph. That is, for each possible edge $\{i, j\}$,

$f_{\{2\}}\left(\pi^{*}\left(\{i, j\}\right)\right)=f_{\{1\}}(\{i, j\})$.

It follows that $f_{2} \circ \pi^{*}=f_{1}$, and hence $f_{2}=f_{1} \circ \pi^{*}$. So the action of the permutation $\pi^{*}$ on the set of mappings $f: D_{3} \rightarrow\{0,1\}$ is defined in exactly the same way as the group actions involved when we were considering the colorings of chessboards and other figures.

We are now ready to deal with the general case. For each permutation $\pi$ of the set $\{1, 2, \ldots, n\}$, that is, $\pi \in S_{n}$, there corresponds a permutation, $\pi^{*}$, of $D_{n}$ defined by

$\pi^{*}(\{i, j\})=\{\pi(i), \pi(j)\} \quad \text { for }\{i, j\} \in D_{n} .$

The collection of all these permutations, $\pi^{*}$, forms a subgroup of the group of all permutations of the set $D_{n}$. We let $S_{n}^{*}$ be this subgroup. It acts on the set $X$ of all the mappings $f: D_{n} \rightarrow\{0,1\}$ in the standard way. That is, for $\pi^{*} \in S_{n}^{*}$ and $f \in X$,

$\pi^{*} \triangleright f=f \circ \pi^{*} .$

We can now calculate the pattern inventory of the graphs with $n$ vertices by working out the cycle index of the group $S_{n}^{*}$ and then using Pólya's enumeration theorem.
