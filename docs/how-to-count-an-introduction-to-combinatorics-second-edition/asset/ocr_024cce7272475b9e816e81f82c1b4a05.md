Since entire rows and columns are permuted, two squares that are initially in different rows and columns will end up in different rows and columns and vice versa. Thus there is a one–one correspondence between ways of placing a given number of nonattacking rooks on the initial board and the ways of placing them on the final board. Hence both boards have the same rook polynomials. We record this fact formally as follows.

# THEOREM 17.2

Let B, B′ be m × n boards, such that there is a permutation, say π, of the set {1, 2, ..., m} and a permutation, say σ, of the set {1, 2, ..., n} with the property that,

for 0 ≤ i ≤ m and 0 ≤ j ≤ n, the square in row i and column j of B is black if and only if the square in row π(i) and column σ(j) of B′ is black.

Then the boards B and B′ have the same rook polynomials.
