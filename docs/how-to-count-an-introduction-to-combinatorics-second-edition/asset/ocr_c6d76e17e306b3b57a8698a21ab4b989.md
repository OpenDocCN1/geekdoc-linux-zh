the new graph, which we will write as $G_1 + \{x, y\}$, Hamiltonian. Since $G_1$ is obtained from $G$ by adding edges, it also satisfies the condition that for each pair of vertices $u, v$ not joined by an edge, $\delta(u) + \delta(v) \ge n$.  
As $G_1$ is not Hamiltonian but $G_1 + \{x, y\}$ is Hamiltonian, each Hamiltonian path in $G_1 + \{x, y\}$ must include the edge $\{x, y\}$. If we delete this edge from one such Hamiltonian path, we obtain a path from $x$ to $y$ that includes every vertex of $G_1$. Let

```
$x = v_1 \to v_2 \to ... \to v_n = y$
```

be such a path.

The vertices $v_1$ and $v_n$ are not joined by an edge in $G_1$, and hence $\delta(v_1) + \delta(v_n) \ge n$. Suppose $\delta(v_1) = k$ and that $v_1$ is joined by an edge to the vertices $v_2, ... , v_k$. Then $\delta(v_n) \ge n - k$, and hence $v_n$ must be joined by an edge to at least one of the vertices $v_{i-1}, ... , v_{n-1}$ since otherwise there would be at most $n - k - 1$ vertices it could be joined to. Thus for some $i$, both $\{v_i, v_1\}$ and $\{v_{i-1}, v_n\}$ are edges of $G_1$. Here $3 \le i \le n-1$, as $v_1$ is not joined to $v_n$.

![](bbox=[0.16, 0.44, 0.52, 0.5])

It follows that

```
$v_1 \to v_i \to v_{i+1} \to ... \to v_n \to v_{n-1} \to v_{n-2} \to ... \to v_2 \to v_1$
```

is a Hamiltonian path in $G_1$, contradicting our assumption that $G$ is not Hamiltonian. Hence $G_1$ is also not Hamiltonian. This contradiction shows that $G$ is Hamiltonian, thus completing the proof.
