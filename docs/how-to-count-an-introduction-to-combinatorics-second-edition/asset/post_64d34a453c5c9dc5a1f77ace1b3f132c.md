**16.1.3A** Consider the complete graph, $K_{3n+1}$, with vertices $1,2,3,\dots,3n-2,3n-1$. We color the edge $ij$ red if $|i-j|\equiv 1(\bmod 3)$ and blue otherwise. Suppose that the edges $ij$ and $jk$ are both red. Then $|i-j|\equiv 1(\bmod 3)$ and $|j-k|\equiv 1(\bmod 3)$. It follows that either $|i-k|\equiv 0(\bmod 3)$ or $|i-k|\equiv 2(\bmod 3)$, and so the edge $ik$ is blue. So there is no red triangle, that is, no $R_3$.

Suppose we have a complete subgraph, say $G$, all of whose edges are blue. Because of the symmetry of the coloring, we can assume that this subgraph includes the vertex 1.

Hence it cannot include any of the vertices $2, 5, 8, \dots, 3n-1$, as the edge from $1$ to any of these vertices is red. The edges joining the vertices in each of the $n-1$ pairs, 3 and 4; 6 and 7; 9 and 10; ...; $3n-3$ and $3n-2$ are red. So $G$ can include at most one vertex from each of these pairs. Consequently, the subgraph $G$ has at most $n$ vertices. So there is no blue $\mathcal{K}_{n+1}$.

We have therefore seen that we can color the edges of $\mathcal{K}_{3n-1}$ red and blue so that there is no blue $\mathcal{K}_{n+1}$ and no red $\mathcal{K}_5$. Hence $R(n+1, 3) \geq 3n$.

### 16.2.2A

We prove by mathematical induction that, for each integer $n \geq 2$,

$\frac{2}{3}3^n \leq C(2n,n) \leq \frac{3}{8}4^n.$ (1)

For $n = 2$, the inequality 1 becomes $6 \leq C(4,2) \leq 6$, which is true since $C(4,2) = 6$. Now suppose that the inequality 1 holds for $n = k$, with $k \geq 2$, that is,

$\frac{2}{3}3^k \leq C(2k,k) \leq \frac{3}{8}4^k.$ (2)

Now

$C(2k+2,k+1) = \frac{(2k+2)!}{(k+1)!(k+1)!} = \frac{(2k+2)(2k+1)}{(k+1)(k+1)} \cdot \frac{(2k)!}{k!k!} = \frac{4k+2}{k+1}C(2k,k),$ (3)

and hence it helps to estimate the value of $(4k+2)/(k+1)$. For all $k \geq 1$, $3k + 3 \leq 4k + 2 \leq 4k + 4$, and hence

$3 \le \frac{4k+2}{k+1} \le 4$. (4)

By Equations 3 and 4,

$3 C(2 k, k) \le C(2 k+2, k+1) \le 4 C(2 k, k)$,

and hence by Equation 2,

$\frac{2}{3} 3^{k+1} \le C(2 k+2, k+1) \le \frac{3}{8} 4^{k+1}$,

and so Equation 1 holds also for $n=k+1$. Therefore, by mathematical induction, Equation 1 holds for all positive integers $n \ge 2$.
