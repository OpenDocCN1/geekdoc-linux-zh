# CHAPTER 14 | Installing and Updating Software Packages

> IMPORTANT
Only one module stream may be enabled for a given module. Enabling an additional module stream will disable the original module stream.

Install a module using the default stream and profiles:

```
[user@host ~]$ sudo yum module install -y perl
Dependencies resolved.
Package Arch Repository Size
Installing group/module packages:
perl x86_64 5.26.3-396.el8 rhel-8-x86_64-appstream-htb-rpm 72 k
```

> NOTE
The same results could have been accomplished by running yum install @perl.
The @ notation informs yum that the argument is a module name instead of a package name.

To verify the status of the module stream and the installed profile:

```
[user@host ~]$ yum module list perl
```

# Removing Modules and Disabling Streams

Removing a module removes all of the packages installed by profiles and any packages that depend on that. Packages from this module stream not listed in any of its profiles remains installed on the system and can be removed manually.
