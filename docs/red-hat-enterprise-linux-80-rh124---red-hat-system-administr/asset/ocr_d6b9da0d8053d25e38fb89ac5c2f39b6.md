+   7. In the left terminal shell, start two more control processes to append to the ~/output file. Use the ampersand (&) to start the processes in the background. Replace technical with documents and then with database. Replacing the arguments helps differentiate between the three processes.

```
[student@servera ~]$ control documents &\n[2] 6579
[student@servera ~]
[student@servera ~]$ control database &\n[3] 6654
```

> NOTE
The job of each new process is printed in square brackets. The second number is the unique system-wide process ID (PID) for the process.
