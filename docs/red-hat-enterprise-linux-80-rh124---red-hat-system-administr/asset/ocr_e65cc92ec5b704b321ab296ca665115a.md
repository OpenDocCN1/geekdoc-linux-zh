# CHAPTER 3 | Managing Files from the Command Line

As you can see in the preceding example, the default shell prompt shows the last component
of the path to the current working directory. For example, `/home/user/Videos`, only
Videos displays. The prompt displays the tilde character (–) when your current working directory
is your home directory.

The **touch** command normally updates a timestamp to the current date and time without
 modifying it. This is useful for creating empty files, which can be used for practice,
because "touch a file name that does not exist creates the file to be created. In the following\example, the **touch** command creates files in the **Documents** and **Videos** subdirectories.

```
[user@host ~]$ touch Videos/buster1.ogg
[user@host ~]$ touch Videos/buster2.ogg
[user@host ~]$ touch Documents/thesis_chapter1.pdf
[user@host ~]$ touch Documents/thesis_chapter2.pdf
[user@host ~]$
```
