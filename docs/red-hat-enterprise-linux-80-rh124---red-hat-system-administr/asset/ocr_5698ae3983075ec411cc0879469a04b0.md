# ARCHIVING AND TRANSFERRING FILES

# PERFORMANCE CHECKLIST

In this lab, you will use tar, rsync, and scp to archive and back up the contents of directories.

# OUTCOMES

You should be able to:

+   * Synchronize a remote directory to a local directory.
* Create an archive of the contents of a synchronized directory.
* Securely copy an archive to a remote host.
* Extract an archive.

# BEFORE YOU BEGIN

Log in as the student on workstation using student as the password.

From workstation, run the lab archive-review start command. The command runs a start script that determines whether servera and serverb are reachable on the network. The script ensures that the files and directories to be created in the lab do not exist on serverb, or workstation.

```
$student@workstation ~$ lab archive-review start
```
