# SEARCHING KNOWLEDGEBASE WITH THE RED HAT SUPPORT TOOL

The Red Hat Support tool, redhat-support-tool, provides a text-based interface that allows you to search Knowledgebase articles and file cases on Customer Portal from your system's command line. The tool does not have a graphical interface, and as it interacts with the Red Hat Customer Portal, it requires Internet access. Run the redhat-support-tool command using any terminal or SSH connection.

The redhat-support-tool command may be used in interactive mode, or as a command with options and arguments. The tool's syntax is ideal for both methods. By default, the program launches in interactive mode. Use the help command to see all available commands. Interactive mode supports tab completion and the ability to call programs in the parent shell.

```
[user@host ~]$ redhat-support-tool
Welcome to the Red Hat Support Tool.
Command (? for help):
```
