```
[root@host ~]# tar -czf /root/etcbackup.tar.gz /etc
tar: Removing leading '/' from member names
```

To create a bzip2 compressed archive named /root/logbackup.tar.bz2, with the contents from the /var/log directory on:

```
[root@host ~]$ tar -cf /root/logbackup.tar.bz2 /var/log
tar: Removing leading '/' from member names
```

To create a xz compressed archive named, /root/sshconfig.tar.xz, with the contents from the /etc/ssh directory on:

```
[root@host ~]$ tar -cJf /root/sshconfig.tar.xz /etc/ssh
tar: Removing leading '/' from member names
```

After creating an archive, verify the content of an archive using the tf options. It is not mandatory to use the option for compression agent listing the content. For example, to list the content archived in the /root/etcbackup.tar.gz file, which uses the gzip compression, using the command:

```
[root@host ~]# tar -tf /root/etcbackup.tar.gz /etc
etc/
etc/fstab
etc/crypttab
etc/mtab
...output omitted...
```

# EXTRACTING A COMPRESSED ARCHIVE

The first step when extracting a tar archive is to determine where the archived files should be extracted, to create and change to the target directory. The tar command determines which compression was used and it is usually not necessary to use the same compression option used when creating the archive. If one chooses to do so, the correct decompression type must be used; otherwise tar yields an error about the decompression type specified in the options not matching the file's decompression type.

To extract the contents of a gzip compressed archive /root/etcbackup.tar.gz in the /tmp/etcbackup directory:

```
[root@host ~]# mkdir /tmp/etcbackup
[root@host ~]# cd /tmp/etcbackup
[root@host etcbackup]# tar -tf /root/etcbackup.tar.gz
etc/
etc/fstab
etc/crypttab
etc/mtab
...output omitted...
[root@host etcbackup]# tar -xzf /root/etcbackup.tar.gz
```
