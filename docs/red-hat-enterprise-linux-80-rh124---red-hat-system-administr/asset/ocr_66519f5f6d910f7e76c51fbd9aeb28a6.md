One additional benefit of using sudo is that all commands executed are logged by default to /var/log/secure.

```
[user01@host ~]$ sudo tail /var/log/secure
...output omitted.
Feb 6 28:45:46 host sudo[2577]: user01 : TTY=pts0 ; PWD=/home/user01 ; USER=root COMMAND=/sbin/sudo -L user02
...output omitted.
```

In Red Hat Linux 7 and Red Enterprise Linux 8, all members of the wheel group can use sudo to run commands as any user, including root. The user is prompted for their password. This is a change from Red Hat Linux 6 and earlier, where users were members of the wheel group did not get this administrative access by default.

> WARNING
RHEL 6 does not grant the wheel group any privileges by default. Sites that have been using this group for a non-standard purpose might be surprised when RHEL 7 and RHEL 8 automatically grants all members of wheel full sudo privileges. This could lead to unauthorized users getting administrative access to RHEL 7 and RHEL 8 systems.

Historically, Unix-like systems use membership in the wheel group to grant or control superuser access.

# Getting an Interactive Root Shell with Sudo

If there is a nonadministratative user account on the system that can use sudo to run the command, you can run sudo -s from that to get an interactive root shell. This works because sudo will run su as root, and root does not need to enter a password to use sudo.

Another way to access the root account with sudo is to use the sudo -i command. This will switch to the root account and run user's default shell (usually bash) and associated shell login scripts. If you just want to run the shell, you can use the sudo -s command.

For example, an administrator might get an interactive shell as root on an AWS EC2 instance by using SSH public-key authentication to log in as the normal user ec2-user, and then by running sudo -1 to get the root user's shell.

```
[ec2-user@host ~]$ sudo -i
[password] for ec2-user:
[root@host ~]#
```

The sudo -s command sudo -i do not behave exactly the same. This will be discussed briefly at the end of the section.
