```
[user@host ~]$ touch seven.txt
[user@host ~]$ ls -l seven.txt
-rw-r----. 1 user user May  0 01:55 seven.txt
[user@host ~]$ mkdir seven
[user@host ~]$ ls -ld two-seven
drwxr-xr-x. 2 user user May  0 01:54 two-seven
```

A umask of 027 ensures that new files have read and write permissions for user and permission for group. New directories have read and write access for group and no permissions for other.

```
[user@host ~]$ umask 027
[user@host ~]$ touch two-seven.txt
[user@host ~]$ ls -l two two-seven.txt
-rw-r----. 1 user user May  0 01:55 two-seven.txt
[user@host ~]$ mkdir two-seven
[user@host ~]$ ls -ld two-seven
drwxr-xr-x. 2 user user May  0 01:54 two-seven
```

The default umask for users is set by the shell startup script. By default, if your account's UID is 200 or more, your username and primary group name are the same, you will be assigned a umask of 022. Otherwise, your umask will be 022.

As root, you can change this by adding a shell startup script named /etc/profile.d/local-umask.sh that looks something like the following example:

```
[root@host]# cat /etc/profile.d/local-umask.sh
# Overrides default umask configuration
if [ $UID -gt 199 ]] && [ "$(id -gn)\ = "$(id -un)" ]; then
  umask 007
else
  umask 022
fi
```

The preceding example will set the umask to 007 for users with a UID greater than 199 and with a username and primary group name that match, and to 022 for everyone else. If you just wanted to set the umask for everyone to 022, you could create that file with the following content:

```
# Overrides default umask configuration
umask 022
```

To ensure global changes take effect you must log out of the shell and log back in. Until the umask configured in the current shell is still in effect.
