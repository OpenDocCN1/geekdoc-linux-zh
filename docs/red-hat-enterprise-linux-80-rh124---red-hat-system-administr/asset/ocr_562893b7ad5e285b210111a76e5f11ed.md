To troubleshoot problems, you might want to filter the output of the journal based on thenpriority level of the entries. The journalctl -p takes either the name or the number of
priority level and shows the journal entries for entries at priority and above. The journalctl
command understands debug,info,notice,warning,err,crit,alert, and emerg
priority levels.

Running the following journalctl to list journal entries at the err priority or higher:

```
[root@]# journalctl -p err
```

When looking for events, you can limit the output to a specific time range. The
journalctl command has options to limit the output to a specific time range, the --since
--until. Both options take a argument in the format "YYYY-MM-DD hh:mm:ss"
(double-quotes are required to preserve the space in the option). If the date is omitted,
t command assumes the current day, and if the time is omitted, the command assumes the
