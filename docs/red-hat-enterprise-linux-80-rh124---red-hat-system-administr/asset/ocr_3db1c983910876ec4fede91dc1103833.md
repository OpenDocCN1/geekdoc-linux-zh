# 5.4. Exit from server to return to workstation as student.

```
[root@server]# exit
logout
[student@server -J]$ exit
logout
Connection to server closed.
[student@workstation -$]
```

+   6. From workstation on server, edit the /etc/sysconfig/network-scripts/ifcfg-ens3 file to add an additional address of 10.0.1.2/24, then load the new configuration.

+   6.1. From workstation, use the ssh command to log in to server as the student

```
[student@workstation -]$ ssh student@server
...output omitted...
[student@server -$]
```

+   6.2. Use the sudo -i to switch to the root user. If prompted, use student as the password.

```
[student@server -]$] sudo -i
[sudo] password for student: student
[root@server #]
```

+   6.3. Modify the ifcfg-ens3 file to add the second IPv4 address and network prefix.

```
[root@server #] echo "IPADDR2=10.0.1.2" >> \
/etc/sysconfig/network-scripts/ifcfg-ens3
[root@server #] echo "PREFIX2=24" >> /etc/sysconfig/network-scripts/ifcfg-ens3
```

+   6.4. Reload the configuration changes.

```
[root@server #] nmcli reload
```

+   6.5. Bring up the connection with the new settings.

```
[root@server #] nmcli con up "ens3"
Connection successfully activated (D-Bus active path: /org/freedesktop/NetworkManager/ActiveConnection/4)
```

+   6.6. Verify the new IP address.

```
[root@server #] echo ip addr show ens3
2: ens3:<BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_cod state UP
default qlen 1000
link/ether 52:54:00:00:fa:0b br ff:ff:ff:ff:ff
```
