> IMPORTANT
The Linux version of ps supports three option formats:

- UNIX (POSIX) options, which may be grouped and not preceded by a dash
- BSD options, which may be grouped and not used with a dash
- GNU long options, which are preceded by two dashes
For example, `ps -aux` is not the same as `ps aux`.

The most common set of options, aux, displays all processes including without a controlling terminal. A long listing (options lax) provides more technical detail, but may display faster by avoiding user lookups. The similar UNIX syntax uses the options `ef` to display all processes.

```
[user@host]$ ps aux

system
```
