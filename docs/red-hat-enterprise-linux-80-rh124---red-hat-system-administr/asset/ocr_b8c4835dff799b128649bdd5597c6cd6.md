# Creating Soft Links

The -ln -s command creates a soft link, which is also called a "symbolic link." A soft link is not a regular file, but a special type of file that points to an existing file or directory.

Soft links have some advantages over hard links:

+   - They can link two files on different file systems.
- They can point to a directory or special file, not just a regular file.

In the following example, the -ln -s command is used to create a new soft link for the existing file /home/user/newfile-link.2 which will be named /tmp/newfile-symlink.txt.

```
[user@host]$ ln -s /home/user/newfile-link.2 /tmp/newfile-symlink.txt
[user@host]$ ls -l newfile-link.2 /tmp/newfile-symlink.txt
-rw-rw-r-- 1 user 1 user Mar 12 11:29 newfile-link.2
lrwxrwxrwx 1 user 1 user Mar 12 11:20:59 /tmp/newfile-symlink.txt -> /home/user/newfile-link.2
[user@host]$ cat /tmp/newfile-symlink.txt
Hello World
```

In the preceding example, the first character of the long listing for /tmp/newfile-symlink.txt is l instead of - . This indicates that the file is a soft link and not a regular file. (A d would indicate that the file is a directory.)

When the original file gets deleted, the soft link will still point to the file but the target is. A soft link pointing to a missing file is called "dangling soft link."

```
[user@host]$ rm -f newfile-link.2
[user@host]$ ls -l /tmp/newfile-symlink.txt
lrwxrwxrwx 1 user 1 user Mar 12 11:20:59 /tmp/newfile-symlink.txt -> /home/user/newfile-link.2
[user@host]$ cat /tmp/newfile-symlink.txt
cat: /tmp/newfile-symlink.txt: No such file or directory
```

> IMPORTANT
One-side of the dangling soft link in the preceding example is that if you later create a new file with the same name as the deleted file (/home/user/newfile-link.2), the soft link will no longer be "dangling" and will point to the new file.

Hard links do not work like this. If you delete a hard link and use normal tools (rather than ln) to create a new file with the same name, the new file will not be linked to the old file.

One way to compare hard links and soft links that might help you understand how they work:

+   - A hard link points to data on a storage device
- A soft link points to another name, that points to data on a storage device

A soft link can point to a directory. The soft link acts like a directory. Changing to the soft link with cd will make the current working directory the linked directory. Some tools may keep track of the fact that you followed a soft link to get there. For example, by default cd update
