# CHAPTER 14 | Installing and Updating Software Packages

+   - Scripts run when a package is installed, updated, removed, or are triggered by other packages are installed, updated, or removed.

Typically, software providers sign RPM packages using GPG keys (Red Hat digitally signs all packages it releases). The RPM system verifies package integrity by confirming that the package was signed by the appropriate GPG key. The RPM system refuses to install a package if the GPG signature does not match.

# Updating Software with RPM Packages

Red Hat generates a complete RPM package to update software. An administrator installing that package gets only the most recent version of the package. Red Hat does not require that older packages be installed and then patched. To update software, RPM removes the older version of the package and installs the new version. Updates usually retain configuration files, but the package of the new version defines the exact behavior.

In most cases, only one version or release of a package may be installed at a time. However, if a package is built so that there are no conflicting file names, multiple versions may be installed. The most important example of this is the kernel. Since a new kernel can only be tested by booting to that kernel, the package is specifically designed so that multiple versions may be installed. If the new kernel fails to boot, the kernel is still available and bootable.

# EXAMINING RPM PACKAGES

The RPM utility is a low-level tool that can get information about the contents of package files and installed packages. By default, it gets information from the local database of installed packages. However, you can use the -p option to specify that you want information about a downloaded package file. You might want to do this in order to inspect the contents of the package before installing it.

The general form of a query is:

+   - rpm -q [select-options] [query-options]

RPM queries: General information about installed packages

+   - rpm -qa: List all installed packages
- rpm -qf FILENAME: Find out what packages provide FILENAME

```
[user@host ~]$ rpm -qf /etc/yum.repos
redhat-release-8.0.19.el8.x86_64
```

RPM queries: Detailed information about specific packages

+   - rpm -q: List version of the package that is currently installed

```
[user@host ~]$ rpm -q yum
yum-4.0.9.2-4.el8.noarch
```

+   - rpm -ql: Get detailed information about the package
- rpm -ql1: List the files installed by the package

```
[user@host ~]$ rpm -ql yum
```
