The nmcli command mod connection name is used to change the settings for a connection. These changes are also saved in the /etc/sysconfig/network-scripts/ifcfg-name for the connection. Available settings are documented in the nm-settings(5) man page.

To set the IPv4 address to 192.0.2/24 and default gateway to 192.0.2.254 for the connection static-ens3

```
[root@]# nmcli mod connection static-ens3 ipv4.addresses "192.0.2.24/24 192.0.2.254"
```

To set the IPv6 address to 2001:db8:0:1::a00/64 and default gateway to 2001:db8:0:1::1 for the connection static-ens3

```
[root@]# nmcli mod connection static-ens3 ipv6.address "2001:db8:0:1::a00/64 2001:db8:0:1::1"
```

> IMPORTANT
If a connection gets its IPv4 information from DHCPv4 server is changed to get it from static configuration files only, the ipv4.method should also be changed from auto to manual.
Likewise, if a connection that gets its IPv6 information from SLAAC or DHCP is changed to get it from static configuration files only, the ipv6.method should also be changed from auto or dhcp to manual.
Otherwise, the connection may hang or not complete successfully when it is activated, or it may get an IPv4 address from DHCP or an IPv6 address from DHCPv6 or SLAAC in addition to the static address.

A number of settings may have multiple values. A specific value can be added to the list or deleted from the list for a setting by adding + or - symbol to the setting of setting name.
