# INSTALLING AND UPDATING SOFTWARE PACKAGES

> PERFORMANCE CHECKLIST
In this lab, you will manage software repositories and module streams, and install
upgrade packages from those repositories and streams.

OUTCOMES
You should be able to:

+   - Manage software repositories and module streams.
- Install and upgrade packages from repositories and streams.
- Install an RPM package.

BEFORE YOU BEGIN
Log in to workstation as student as student as the password.

On workstation, run the lab software-review start command. This script ensures
that server is available. It downloads any packages required for the lab exercise.

```
[student@workstation ~]$ lab software-review
```
