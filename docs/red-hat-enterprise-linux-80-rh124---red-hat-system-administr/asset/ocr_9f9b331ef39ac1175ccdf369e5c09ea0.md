+   4. Create a static connection with the same IPv4 address, network prefix, and default gateway. Name the new static-ens3.

> Since access to your machine is provided over the primary network connection, setting incorrect values during network configuration may make your machine unreachable. If this happens, use the Reset button located above what used to be your machine's graphical display and try again.

```
$student@servera ~$ nmcli add con-name "static-ens3" ens3 \
> type ethernet ip4 172.250.10/24 gw4 172.250.254
Connection 'static-ens3' (15aa3901-555d-40cb-94c6-cea6f9151634) successfully added.
```

+   5. Modify the connection to add the DNS setting.

```
$student@servera ~$ nmcli con mod "static-ens3" ipv4.dns 172.250.254.254
```
