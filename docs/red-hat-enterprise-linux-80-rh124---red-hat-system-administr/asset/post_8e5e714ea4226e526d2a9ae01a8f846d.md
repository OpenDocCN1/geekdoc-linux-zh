
To set the system-wide default language, run the command `localectl set-locale LANG=locale`, where locale is the appropriate value for the LANG environment variable from the "Language Codes Reference" table in this chapter. The change will take effect for users on their next login, and is stored in /etc/locale.conf.

```
[root ~]# localectl set-locale LANG=fr_FR.utf8
```

In GNOME, an administrative user can change this setting from Region & Language by clicking the Login button at the upper-right corner of the window. Changing the Language of the graphical login screen will also adjust the system-wide default language setting stored in the /etc/locale.conf configuration file.

> **IMPORTANT** Text-based virtual consoles like tty4 are more limited in the fonts they display than terminals in a virtual console running a graphical environment, or pseudoterms for ssh sessions. For example, Japanese, and Chinese characters may not display as expected on a text-based virtual console. For this reason, you should consider using English or another language with a Latin character set for the system-wide.

Likewise, text-based virtual consoles are more limited in the input methods they support, and this is managed separately from the graphical desktop environment. The available global input settings can be configured through localectl for text-based virtual consoles and the graphical environment. See the localectl(1) and vconsole.conf(5) for more information on.

## LANGUAGE PACKAGES

Specific RPM packages called langpacks install language packages that add support for specific languages. These languages use dependencies to automatically install additional RPM packages containing locations, dictionaries, and translations for other software packages on your system.

To list the packages that are installed and may be installed, use yum list langpacks-*:

```
[root ~]# yum list langpacks-*
Updating Management repositories.
Updating Subscription Management repositories.
Installed Packages
langpacks-en               1.0-12.el8      @AppStream
Available Packages
langpacks-af.narch         1.0-12.el8      rhel8-for-x86_64-appstream-rpm
langpacks-am.narch         1.0-12.el8      rhel8-for-x86_64-appstream-rpm
langpacks-ar.narch         1.0-12.el8      rhel8-for-x86_64-appstream-rpm
langpacks-as.narch         1.0-12.el8      rhel8-for-x86_64-appstream-rpm
langpacks-ast.narch        1.0-12.el8      rhel8-for-x86_64-appstream-rpm
...output omitted...
```

To add language support, install the appropriate langpacks package. For example, the command above supports for French:

```
[root ~]# yum install langpacks-fr
```

Use `yum repository --whatsupplements` to determine what RPM packages may be installed by a langpack:

```
[root@host ~]# yum repository --whatsupplements langpacks-fr
Updating Subscription Management repositories.
Updating Subscription Management repositories.
Last metadata check: 08:13:33 ago Wed 06 Feb 2019 10:47:24 AM CST.
glibc-langpack-fr-0.2.20-18.el8.x86_64
gnome-getting-started-docs-fr-0.3.20-1.el8.noarch
hunspell-fr-0.6.2-1.el8.noarch
hyphen-fr-0.3.0-1.el8.noarch
libreoffice-langpack-fr-1.6.0.6-9.el8.x86_64
man-pages-fr-0.3.70-16.el8.noarch
mythes-fr-0.2.3-10.el8.noarch
```

> IMPORTANT packages use RPM weak dependencies in order to install supplementary packages only when the core package needs it also installed. For example, when installing langpacks-fr as shown in the preceding examples, the mythe package will only be installed if the mythe thesaurus is also installed on. If mythe is subsequently installed on that system, the mythe-fr package will also automatically be installed by the weak dependency from the already installed langpacks-fr package.

> REFERENCES locale(7), localectl(1), locale.conf(5), vconsole.conf(5), unicode(7), and utf-8(7) man pages. Conversions between the names of the graphical desktop environment's X11 layouts and their names in localectl can be found in the file /usr/share/X11/xkb/rules/base.lst.
