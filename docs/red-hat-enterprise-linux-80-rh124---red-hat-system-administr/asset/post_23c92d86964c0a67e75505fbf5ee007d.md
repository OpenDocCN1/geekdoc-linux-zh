# SEARCHING KNOWLEDGEBASE WITH THE RED HAT SUPPORT TOOL

The Red Hat Support tool, redhat-support-tool, provides a text-based interface that allows you to search Knowledgebase articles and file cases on Customer Portal from your system's command line. The tool does not have a graphical interface, and as it interacts with the Red Hat Customer Portal, it requires Internet access. Run the redhat-support-tool command using any terminal or SSH connection.

The redhat-support-tool command may be used in interactive mode, or as a command with options and arguments. The tool's syntax is ideal for both methods. By default, the program launches in interactive mode. Use the help command to see all available commands. Interactive mode supports tab completion and the ability to call programs in the parent shell.

```
[user@host ~]$ redhat-support-tool
Welcome to the Red Hat Support Tool.
Command (? for help):
```

# Analyzing Services and Vending Support

When invoked, **redhat-support-tool** prompts for Red Hat Customer subscriber login information. To avoid repetitively supplying this information, the tool asks to store account information in the user's home directory (./redhat-support-tool/redhat-support-tool.conf). If issues are filed through a particular Red Hat Customer Portal account, the **global** option can save account information to /etc/redhat-support-tool.conf, with other system-wide configuration. The tool's `config` command modifies configuration settings.

The **redhat-support-tool** command allows subscribers to search and display Knowledgebase content from Red Hat Customer Portal. Knowledgebase performs keyword searches, similar to the `man` command. Users can enter error codes, syntax from log files, or any mix of keywords to produce a list of relevant solution documents.

There is an initial configuration and search description:

```
[user@host]$ redhat-support-tool
```

# MANAGING SUPPORT CASES WITH RED HAT TOOL

One benefit of subscription is access to technical support through Customer Portal. Depending on the support level, Red Hat may be contacted online or by phone. See https://access.redhat.com/support/policy

# Preparing a Bug report

Before contacting Red Support, it is important to gather information.

Define the problem. Be able to clearly state the problem and its symptoms. Be as specific as possible. Detail the steps which will reproduce the problem.

Gather background information. Which product and version is affected? Be ready to provide information. This could include sosreport or a crash dump.

Determine the severity level. Red Hat has four severity levels to classify issues. Urgent and High severity problems should be followed by a phone call.

| SEVERITY | DESCRIPTION |
| --- | --- |
| Urgent (Severity 1) | A problem that severely impacts your use of software in a production environment. This includes loss of production data or malfunctioning production systems. The system halts your business operations and no workaround exists. |
| High (Severity 2) | A problem where the software is functioning but in a production environment is severely reduced. The situation is causing a high impact to your business operations and no workaround exists. |
| Medium (Severity 3) | A problem that involves partial, not critical use of software in a production environment or development environment. For production environments, there is a medium to low impact on your business. Business continues to function using a workaround. For development environments, the situation is causing problems migrating your project into production. |
| Low (Severity 4) | A general usage question, reporting of a documentation error, or recommendation for a future product enhancement or modification. For production environments, there is low to no impact on your business or the performance or functionality of your system. For development environments, there is a medium to low impact on your business, but your business continues to function using a workaround. |

# Managing A Bug Report with redhat-support-tool

Subscribers may create, view, modify, and close Red Support cases using redhat-support-tool. When cases are in an open or maintained status, users may attach files or documentation, such as diagnostic reports (sosreport). The tool uploads and attaches files to cases.

Case details including product, version, summary, description, severity, and case group may be assigned with command options or letting the tool prompt for required information. In the following example, a new case is opened. The --product and --version options are specified.

```
[user@]$ redhat-support-tool.
Welcome to Red Hat Support Tool.
Command (? for help): opencase --product="Red Hat Enterprise Linux" --nversion="7.0"
Please enter a summary (or 'q' to exit): System fails to run without power
nPlease enter a description (Ctrl-D on an empty line when complete):
```
