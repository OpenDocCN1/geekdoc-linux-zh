3. Change to the /mnt/namespace directory and create a new directory, /mnt/namespace/newdir, with an empty file, /mnt/namespace/newdir/myfile.

3.1. Change to the /mnt/namespace directory.

```
[rootserver ~#] cd /mnt/namespace
```

3.2. Create a new directory, /mnt/namespace/newdir.

```
[rootserver namespace#] mkdir newdir
```

3.3. Create an empty file, /mnt/namespace/newdir/myfile.

```
[rootserver namespace#] touch newdir/myfile
```

4. Unmount the file system mounted on the /mnt/namespace directory.

4.1. Use the unmount command to unmount /mnt/namespace while the current directory on the shell is still /mnt/namespace. The umount command fails to unmount the device.

```
[rootserver namespace#] umount /mnt/namespace
umount: /mnt/namespace: target is busy.
```

4.2. Change the current directory on the shell to /root.

```
[rootserver namespace#] cd
[rootserver ~#]
```

4.3. Now, successfully unmount /mnt/namespace.

```
[rootserver ~#] umount /mnt/namespace
```
