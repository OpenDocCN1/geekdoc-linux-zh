# CHAPTER 14 | Installing and Updating Software Packages

> WARNING
Removing modules and switching module streams can be a bit tricky. Switching the stream for a module is equivalent to resetting the current stream and enabling the new stream. It does not automatically change any installed packages. You have to do that manually.

Directly installing a module stream that is different than the one that is currently installed is not recommended, because upgrade scripts might run during the installation that would break things with the original module stream. That lead to data loss or other configuration issues.

Proceed with caution.

To remove an installed module:

```
[user@host ~]$ sudo yum module remove -y perl

After the removed module, the module stream is still enabled. To verify the module stream is still enabled:

```
[user@host ~]$ yum module list perl - AppStream HTB (RPMs)
