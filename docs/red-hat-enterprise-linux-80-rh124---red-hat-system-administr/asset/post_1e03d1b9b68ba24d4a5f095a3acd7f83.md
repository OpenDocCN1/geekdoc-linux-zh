### 4. Install the python36 module from the 3.6 stream and the common profile. Verify the current status of the module.

#### 4.1. Use the yum module install to install the python36 module. Use the name:stream/profile syntax to install the python36 module from the 3.6 stream and the common profile.

> NOTE
You can omit /profile to use the default profile and :stream to use the default stream.

```bash
[root@servera ~]# yum module install python36:3.6/common
...output omitted...
Is this ok [y/N]: y
...output omitted...
```

Alternatively, you can enable the module first to make its packages available to the system without installing them. Then use the yum install @python36 command to install the packages within the module.

```bash
[root@servera ~]# yum module enable python36:3.6/common
[root@servera ~]# yum install @python36
...output omitted...
Is this ok [y/N]: y
...output omitted...
Complete!
```

### 5. Switch the postgresql module of the server profile to use the 10 stream.

#### 5.1. Use the yum module command to list the postgresql module and the stream. Notice that the postgresql:9.6 module is currently installed.


#### 5.2. Use the yum module install to switch to the postgresql:10 module stream.
