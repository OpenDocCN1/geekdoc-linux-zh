# MODULES

A module is a set of RPM packages that are a consistent set that belong together. Typically, this is organized around a specific version of a software application or programming language. A typical module can contain packages with an application, packages with the application's specific dependency libraries, packages with documentation for the application, and packages with helper utilities.

# Module Streams

Each module can have one or more module streams, which hold different versions of the content. Each of the streams receives updates independently. The of module stream acts as a virtual repository in the Application Stream physical repository.

For each module, only one of its streams can be enabled and provide its packages.

# Module Profiles

Each module can have one or more profiles. A profile is a list of packages to be installed together for a particular use-case such as for a server, client, development, minimal install, or other.

Installing a particular module profile simply installs a particular set of packages from the module stream. You can simultaneously install or uninstall packages normally. If you do not specify a profile, the module will install its default profile.

# MANAGING MODULES USING YUM

Yum version 4, in Red Hat Enterprise Linux 8, adds support for the new module features of Application Stream.

For handling the modular content, the yum module command has been added. Otherwise, yum works with modules like which does with regular packages.
