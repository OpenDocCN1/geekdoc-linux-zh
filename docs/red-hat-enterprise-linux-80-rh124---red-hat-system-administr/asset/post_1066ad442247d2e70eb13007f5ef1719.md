```
[user@]$ ip -6 route

unreachable: 2002::/64 dev lo metric 1024 error -101

unreachable: a0f8::/32 dev lo metric 1024 error -101

fe80::/64 dev ens3 proto kernel metric 256
default via 2001:db8:0::1:ffff dev ens3 2001:db8:0::1:ffff proto static metric 1024
```

In this example, ignore the unroutable routes, which point at unused networks. That leaves

- 1. The 2001:db8:0::1::/64 network, using the ens3 interface (presumably has an address on that).
- 2. The fe80::/64 network, for the link-address. On a system with multiple interfaces, there is a route to fe80::/64 out each interface for each link-local address.
- 3. A default route to all networks on the IPv6 Internet (the ::/0) that do not have a more specific route on the system, the router at 2001:db8:0:1::ffff, reachable with the ens3.

# Tracing Routes Taken by Traffic

To trace the path that traffic takes to reach a host through multiple routers, use traceroute or tracepath. This can identify whether an issue is with one of your routers or an intermediate. Both commands use UDP packets by default; networks block UDP and ICMP traffic. The traceroute command has options to trace the path with UDP (default), ICMP (-I), or TCP (-T) packets. Typically, the traceroute command is not installed by default.

```
[user@]$ tracepath access.redhat.com
..output. omitted...
4: 71-32-148.145.rcnt.inet.quest 48.853ms as 5
5: dcp-brdr-041.inet.quest 100.732ms as 7
6: 206.111.0.153.ptr.us.no 96.245ms as 7
7: 207.078.14.162.ptr.us.no 85.270ms as 8
8: aeid0.c1.atlanta6-ga.us.xo.no 64.160ms as 7
9: 216.156.108.98.ptr.us.no 108.265ms as 12
10: bu-eth13.atlangam46w-br0.tbbone.com 107.286ms as 12
..output. omitted...
```

Each line in the output of tracepath represents a route or hop that the packet passes between the source and the final destination. Additional information is provided as available, including the round trip time (RTT) and any changes in the maximum transmission unit (MTU). The tracepath6 and traceroute -6 commands are the equivalent to tracepath and traceroute for IPv6.

```
[user@]$ tracepath6 2001:db8:0:::451
1: [LOCALHOST] 0.091ms pmtu 1500

3: 2001:db8:0::2:: 0.512ms

Resume: pmtu 1500 hops 3 back 3
```

# TROUBLESHOOTING POINTS AND SERVICES

TCP services typically use endpoints as points and are made up of an IP address, protocol, and port number. Services typically listen on standard ports while clients use random port. Well-known names for standard ports are found in the /etc/services file. The ss command is used to display socket statistics. The ss command means to replace the older tool netstat, which may be more familiar to some system administrators but is not installed.

```
[user@]$ ss -ta
State Recv-Q Send-Q Local Address:Port      Peer:Port
LISTEN 0       128                 *:22               *:
LISTEN 0       128                 *:22               *:
LISTEN 0       100                 127.0.1:53          *:
LISTEN 0       128                 *:3689             *:
ESTAB 0                   172.250.10:5689      172.250.254:5932
LISTEN 0       128                 :::ssh                               *:
LISTEN 0       128                 :::                               *:
LISTEN 0       100                 :::1:                               *:
LISTEN 0       128                 :::34946                             *:
```

- The port used for SSH is listening on all IPv4 addresses. The "*" used to represent "all" when referencing IPv4 addresses or ports.
- The port used for SMTP is listening on 127.0.0.1 loopback interface.
- The established connection is on 172.250.10 and originates from a system with address of 172.250.10.
- The port used for SSH is listening on all IPv6 addresses. The "::" syntax is used to represent IPv6 interfaces.

Options for ss and netstat:

| OPTION | DESCRIPTION |
| :--- | :--- |
| -n | Show numbers instead of interfaces and ports. |
| -t | Show TCP sockets. |
| -u | Show UDP sockets. |
| -a | Show all (listening and established) sockets. |
| -p | Show the process using the sockets. |
| -inet | Display active connections for the inet address family. |
| -A | Displays IPv4 and IPv6 at the same time. |
