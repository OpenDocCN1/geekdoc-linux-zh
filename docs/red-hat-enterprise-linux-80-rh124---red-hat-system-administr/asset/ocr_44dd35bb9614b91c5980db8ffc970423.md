# EDITING NETWORK CONFIGURATION FILES

# OBJECTIVES

After completing this section, you should be able to modify network configuration by editing configuration files.

# DESCRIBING CONNECTION CONFIGURATION FILES

By default, changes made with nmcli con mod name are automatically saved to /etc/sysconfig/network-scripts/ifcfg-name. That file can also be manually edited with a text editor. After doing so, run nmcli reload so that NetworkManager reads the configuration changes.

For backward-compatibility reasons, the directives saved in that file have different names and syntax than the nm-settings(5) names. The following table maps some of the key setting names to ifcfg-* directives.

Comparison of nm-settings and ifcfg-* directives

| NMCLI CON MOD | IFCFG-* | EFFECT |
| --- | --- | --- |
| ipv4.method manual | BOPROTO=none | IPv4 addresses configured statically. |
| ipv4.method auto | BOPROTO=dhcp | Looks for configuration settings from DHCP4. If server addresses are also set, will not bring those up until we have information from DHCP4. |
| ipv4.addresses "192.0.2.1/24 192.0.2.254" | IPADDR0=192.0.2.1 PREFIX=24 GATEWAY=192.0.2.254 | Sets static IPv4 address, network prefix, and default gateway. If more than one is set for the connection, then instead of 0, the ifcfg-* directs with 1, 2, and 3 so on. |
| ipv4.dns 8.8.8.8 | DNS8=8.8.8.8 | Modify /etc/resolv.conf to use this nameserver. |
| ipv4.dns-search example.com | DOMAIN=example.com | Modify /etc/resolv.conf to use this domain in the search directive. |
| ipv4.ignore-auto-dns true | PEERDNS=no | Ignore DNS server information from the DHCP server. |
