# TROUBLESHOOTING POINTS AND SERVICES

TCP services typically use endpoints as points and are made up of an IP address, protocol, and port number. Services typically listen on standard ports while clients use random available port. Well-known names for standard ports are found in the /etc/services file.

The ss command is used to display socket statistics. The ss command means to replace the older tool netstat, package, which may be more familiar to some system administrators but which is not installed.

```
[user@]$ ss -ta
State Recv-Q Send-Q Local Address:Port      Peer Address:Port
LISTEN 0       128                 *:22                               *:
LISTEN 0       128                 *:22                               *:
LISTEN 0       100                 127.0.0.1:53                       *                       *:
LISTEN 0       128                 *:36899                             *:
ESTAB 0       0                   172.250.10:5689                  172.250.254.254:59392
LISTEN 0       128                 :::ssh                               *:::
LISTEN 0       128                 :::                               *:::
LISTEN 0       100                 :::1:                                                              *:
LISTEN 0       128                 :::34946                             *:::
```

+   - The port used for SSH is listening on all IPv4 addresses. The "*" is used to represent "all" when referencing IPv4 addresses or ports.
- The port used for SMTP is listening on the 127.0.0.1 IPv4 loopback interface.
- The established SSH connection is on the 172.250.10 interface and originates from a system with address of 172.250.10.
- The port used for SSH is listening on all IPv6 addresses. The "::" syntax is used to represent IPv6 interfaces.
- The port used for SMTP is listening on the ::1 IPv6 loopback interface.
