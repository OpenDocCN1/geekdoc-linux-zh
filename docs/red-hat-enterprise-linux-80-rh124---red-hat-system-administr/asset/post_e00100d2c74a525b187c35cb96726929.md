# INSTALLING RPM PACKAGES

The rpm command can be used to install an RPM package that you have downloaded to your local directory.

```bash
[root ~]$ rpm -ivh wonderwidgets-1.0-4.x86_64.rpm
###################################### [100%]
Verifying...###################################### [100%]
Preparing...###################################### [100%]
Installing...###################################### [100%]
1:wonderwidgets-1.0-4######################
[root ~]$
```

However, the next section of this chapter will discuss a more powerful tool for managing RPM installation and updates from the command line, yum.

> WARNING
> Be careful when installing packages from third parties, not just because of the software that they may install, but because the RPM package may include arbitrary scripts that run as the root user as part of the installation process.

# CHAPTER 14 | Installing and Updating Software Packages

> NOTE
> You can extract files from an RPM package file without installing the package. The rpm2cpio utility can pass the contents of the RPM to a special archiving tool called cpio, which can extract all files or individual files.

Pipe the output of `rpm2cpio PACKAGEFILE.rpm -id`, to extract all files stored in the RPM package. Subdirectory trees are created as needed, relative to the files stored in the working directory.

```bash
[user@host ~-extract]$ rpm2cpio wonderwidgets-1.0.4.x86_64.rpm | cpio -id
Individual files are extracted by specifying the path of the file:
```

```bash
[user@host -]$ rpm2cpio wonderwidgets-1.0.4.x86_64.rpm | cpio -id "*txt"
1 blocks
[user@host -]$ ls -l usr/share/doc/wonderwidgets-1.0/
total 4
-rw-r--r--r-- 1 user 76 Feb 13 19:27 README.txt
```

# SUMMARY OF RPM QUERY COMMANDS

Installed packages can be queried directly with the rpm command. The -p option to query a package file before installation.

| COMMAND | TASK |
|---|---|
| rpm -qa | List all RPM packages currently installed |
| rpm -q NAME | Display the version of NAME installed on the system |
| rpm -qi NAME | Display detailed information about a package |
| rpm -ql NAME | List all files included in a package |
| rpm -qc NAME | List configuration files included in a package |
| rpm -qd NAME | List documentation files included in a package |
| rpm -q --changelog NAME | Show a short summary of the reason for a new package release |
| rpm -q -scripts NAME | Display the shell scripts run on package installation, upgrade, or removal |

> REFERENCES
> rpm(8), rpm2cpio(8), cpio(1), and rpmkeys(8) man pages

# GUIDED EXERCISE

# EXPLAINING AND INVESTIGATING RPM SOFTWARE PACKAGES

In this exercise, you will gather information about a package from a third party, extract files
from it for inspection, and then install it on a server.

# OUTCOMES

You should be able to install a package not provided by software repositories on a server.

# BEFORE YOU BEGIN

Log in as the student user over workstation using student as the password. From workstation run the `lab software-rpm` command. The script determines whether the host, servera, is reachable on the network. The script downloads the `rhcasa-script-1.0.0-1.noarch` package in the `/home/student` directory on servera.

```bash
[student@workstation]$ lab software-rpm
```

- 1. Use the ssh command to log into servera as the student user.
```bash
[student@workstation]$ ssh student@servera
[student@servera]$
```

- 2. View information and list files in the `rhcasa-script-1.0.0-1.noarch` package. The script runs when the package is installed or uninstalled.
- 2.1. View information for `rhcasa-script-1.0.0-1.noarch` package.
```bash
[student@servera]$ rpm -q -p rhcasa-script-1.0.0-1.noarch
Name : rhcasa-script
Version : 1.0.0
Release : 1
Architecture : noarch
Install Date : (not installed)

Source RPM : rhcasa-script-1.0.0-src.rpm

Relocations : (not relocatable)

```

- 2.2. List files in `rhcasa-script-1.0.0-1.noarch` package.
```bash
[student@servera]$ rpm -q -p rhcasa-script-1.0.0-1.noarch -l /opt/rhcasa-script/mymod
```

- 3. View the script that runs when `rhcasa-script-1.0.0-1.noarch` package is installed or updated.
```bash
[student@servera]$ rpm -q -p rhcasa-script-1.0.0-1.noarch --scripts
preinstall scriptlet (using /bin/sh):
if [ "$1" == "2" ]; then
  if [ -e /etc/motd ]; then
    mv -f /etc/motd /etc/motd.org
  fi
fi
postinstall scriptlet (using /bin/sh):
  ...output omitted...
```

- 3. Extract the contents of the `rhcasa-script-1.0.0-1.noarch` package in the `/home/student` directory.
- 3.1. Use `rpm2cpio` and `cpio -tv` commands to list the files in the `rhcasa-script-1.0.0-1.noarch` package.
```bash
[student@servera]$ rpm2cpio rhcasa-script-1.0.0-1.noarch.rpm | cpio -tv
rw-r--r-- | root | root | 1056 | Mar 6 | 15:59 | /opt/rhcasa-script/mymod 3 blocks
```

- 3.2. Extract all files from the `rhcasa-script-1.0.0-1.noarch` package in the `/home/student` directory. Use the `rpm2cpio` and `cpio -idv` commands to extract the files and create the leading directories needed in verbose mode.
```bash
[student@servera]$ rpm2cpio rhcasa-script-1.0.0-1.noarch.rpm | cpio -idv /opt/rhcasa-script/mymod 3 blocks
```

- 3.3. List to view the extracted files in the `/home/student/opt` directory.
```bash
[student@servera]$ ls -lR opt
opt:
total 0
drwx-xr-x. 2 student student 20 Mar 7 14:44 rhcasa-script:
opt/rhcasa-script:
total 4
-rw-r--r-- 1 student 1056 Mar 7 14:44 mymot
```

- 4. Install the `rhca-script-1.0.0-1.noarch` rpm package. Use the `sudo` command to gain superuser privileges to install the package.
- 4.1. Use the `sudo rpm -ivh` to install the `rhca-script-1.0.0-1.noarch` rpm package.
```bash
[student@servera]$ sudo rpm -ivh rhca-script-1.0.0-1.noarch
[sudo] password for student: student
Verifying...########################### [100%]
Preparing...########################### [100%]
Updating / installing...########################### [100%]
rhca-script-1.0.0-1
[student@servera]$
```

- 4.2. Use the `rpm q` command to verify that the package is installed.
```bash
[student@servera]$ rpm -q rhca-script
rhca-script-1.0.0-1.noarch
```

- 5. Exit from server.
```bash
[student@servera]$ exit
logout
Connection to servera closed.
[student@workstation]$
```

# Finish

On workstation, run the `lab software-rpm finish` script to complete this exercise. This script removes all the packages installed on servera during the exercise.

```bash
[student@workstation]$ lab software-rpm finish
```

This concludes the exercise.
