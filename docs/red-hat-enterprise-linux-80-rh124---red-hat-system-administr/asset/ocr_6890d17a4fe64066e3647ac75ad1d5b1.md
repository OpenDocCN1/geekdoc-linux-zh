# MATCHING FILE NAMES WITH SHELL EXPANSIONS

Choose the correct answers to the following questions:

+   1. Which pattern will only match filenames ending with "b"?
a. b*
b. **b**
c. *b**
d. ![b]*

+   2. Which pattern will only match filenames beginning with "b"?
a. b*
b. *b
c. *b**
d. ![b]*

+   3. Which pattern will only match filenames where the first character is not "b"?
a. b*
b. *b
c. *b**
d. ![b]*

+   4. Which pattern will match all filenames containing a "b"?
a. b*
b. *b
c. **b**
d. ![b]*

+   5. Which pattern will only match filenames that contain a number?
a. "#"
b. "*[:digit:]]*"
c. "*[digit]*"
d. [0-9]
