Run the following journalctl command to list all journal entries from **2019-02-10 20:30:00** to **2019-02-13 12:00:00**

```
[root@]# journalctl --since "2014-02-10 20:30:00" --until "2014-02-13 12:00:00"

```

You can also specify all entries since a time relative to the present. For example, to specify all entries in the last hour, you can use the following command:

```
[root@]# journalctl --since "-1 hour"

```

> NOTE
You can use other, more sophisticated time specifications with the --since and --until** options. For some examples, see the systemd.time(7) man page.

In addition to the visible content of the journal, there are fields attached to the log entries that can only be seen when verbose output is turned on. Any displayed extra field can be used to filter the output of a journal. This is useful to reduce the output of complex searches for certain events in the journal.

```
[root@]# journalctl -o verbose
```
