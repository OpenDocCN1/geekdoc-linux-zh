# CHAPTER 8 | Monitoring and Managing Linux PROCESSES

```
[user@host ~$ bg %1
[1]+ sleep 10000 &
```

The shell will warn a user who attempts to exit a terminal window (session) with suspended jobs. If the user tries exiting again immediately, the suspended jobs are killed.

> NOTE
Note the + sign after the [1] in the examples above. The + sign indicates that this job is the current default job. That is, if a command is used that expects a %job number and a job number is not provided, then the action is taken on the job with the + indicator.
