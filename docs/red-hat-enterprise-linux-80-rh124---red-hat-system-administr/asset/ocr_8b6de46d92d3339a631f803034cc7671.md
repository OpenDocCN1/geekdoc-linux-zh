Determine the interface name and the active connection's name. The solution assumes that the interface name is ens3 and the connection name is Wired connection 1.

```
[root@server ~]# ip link
1: lo: <LOOKBACK,UP,LOWER_UP> mtu 65536 disc noisque state UNKNOWN group default qlen 1000
link/loopback 00:00:00:00:00:00 br 00:00:00:00:00:00
2: ens3: <BROADCAST,MULTICAST,LOWER_UP> mtu 1500 disc fq_cod state UP group default qlen 1000
link/ethernet 52:54:00:fa:0b:8d
[root@server ~]# nmcli con show --active
NAME UUID TYPE DEVICE
Wired connection 1 0a3d0a3a-3257-4272-a478-d53055cc9128 ethernet ens3
```

Create the new connection profile based on the information in the table described in the instructions. Associate the profile with your network interface name linked in the output of the previous ip link command.

```
[root@server ~]# nmcli con add-name ifname ens3 type ether \
> ip4 172.25.250.214 gdw 172.25.250.254
[root@server ~]# nmcli con mod "lab" ipv4.172.25.250.254
```

+   4. Configure the new connection to be autostarted. Other connections should not start automatically.

```
[root@server ~]# nmcli mod "lab" connection.autoconnect yes
[root@server ~]# nmcli mod "Wired connection 1" connection.autoconnect no
```

+   5. Modify the new connection so that it uses the address 10.0.1.1/24.

```
[root@server ~]# nmcli mod "lab" +ipv4.addresses 10.0.1.1/24
```

Or alternatively,

```
[root@server ~]# echo "IPADR1=10.0.1.1" >> \
> /etc/sysconfig/network-scripts/ifcfg-lab
[root@server ~]# echo "PREPREFIX1=24" >> /etc/sysconfig/network-scripts/ifcfg-lab
```

+   6. Configure the hosts file so 10.0.1.1 can be referenced as private.

```
[root@server ~]# echo "10.0.1.1 private" >> /etc/hosts
```

+   7. Reboot the system.

```
[root@server ~]# reboot
Connection to server closed by remote host.
Connection to server closed.
[student@workstation ~]$
```
