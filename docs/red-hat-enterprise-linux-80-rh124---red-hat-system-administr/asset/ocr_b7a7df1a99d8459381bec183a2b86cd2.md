+   5. Execute the hostname command on server remotely using SSH without accessing the remote shell.

```
[operator1@server ~] ssh operator1@server hostname
server.lab.example.com
```

> Notice that the preceding ssh command did not prompt you for a password because it used the passphrase-less private key against the exported public key to authenticate as operator1 on server. This approach is not secure, because anyone who has access to the private key can log in to server as operator1. The secure alternative is to protect the private key with a passphrase, which is the next step.
