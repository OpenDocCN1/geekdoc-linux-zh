# ENABLING YUM REPOSITORIES

## OBJECTIVES

After completing this section, you will be able to enable and disable use of Red Hat or third-party repositories.

## ENABLING RED HAT REPOSITORIES

Registering a server to the subscription management service grants access to software repositories based on the attached subscriptions. To view all available repositories:

```
[user@host ~] reposolist all
Loaded plugins: langpacks
rhel-8-server-debug-rpms/x86_64 Red Hat Linux 8 (Debug RPMs) disabled
rhel-8-server-rpms/x86_64 Red Hat Linux 8 enabled
rhel-8-server-source-rpms/x86_64 Red Hat Linux 8 (Source RPMs) disabled
```

The yum-config-manager command is used to enable or disable repositories. To enable a repository, the command sets the enabled parameter to 1. For example, the following command enables the rhel-8-server-debug-rpms repository:

```
[user@host ~]$ yum-config-manager --enable rhel-8-server-debug-rpms
Loaded plugins: langpacks
repo: rhel-8-server-debug-rpms enabled = True
width = 0
base_dir = /var/lib/yum/repos/
```

Red Hat provides some of its software through third-party repositories, which can be accessed by the yum command from a website, FTP server, or local file system. For example, to enable support for a third-party repository, you must create a file in the /etc/yum.repos.d/ directory. Repository configuration files must end with a .repo extension. The repository definition contains the URL of the repository, a name, whether to use GPG to check the package signatures, and the URL pointing to the trusted GPG key.

## Creating Yum Repositories

Create Yum repositories with yum-config manager. The following command creates a file named /etc/yum.repos.d/dl.fedoraproject.org.pub_86_64/ with the output shown:

```
[user@host ~]$ yum-config-manager --add-repo=http://dl.fedoraproject.org/pub/el8/x86_64/
Loaded plugins: langpacks
adding repo from: http://dl.fedoraproject.org/pub/el8/x86_64/
[dl.fedoraproject.org.pub_86_64]
name=added from: http://dl.fedoraproject.org/pub/el8/x86_64/
baseurl=http://dl.fedoraproject.org/pub/el8/x86_64/
enabled=1
```

Modify this file to provide customized values and the location of the GPG key. Keys are stored in locations on the repository site, such as http://dl.fedoraproject.org/pub/el8/RPM-GPG-KEY-EL-8. Administrators should download the key to a local file rather than retrieve it from an external source. For example:

```
[EPEL]
name=EPEL 8
baseurl=http://dl.fedoraproject.org/pub/el8/x86_64/
enabled=1
gpgcheck=1
gpg_key=file:///etc/pki/rpm/RPM-GPG-KEY-EPEL-8
```

## RPM Configuration Packages for Local Repositories

Some repositories provide a configuration file and GPG key as part of an RPM package that can be downloaded and installed using the yum command. For example, the volunteer project Extra Packages for Enterprise Linux (EPEL) provides software not supported by Red Hat Linux.

The following command installs the Red Hat Enterprise Linux 8 EPEL repository:

```
[user@host ~]$ rpm --import http://dl.fedoraproject.org/pub/el8/RPM-GPG-KEY-EL-8
[user@host ~]$ yum install http://dl.fedoraproject.org/pub/el8/x86_64/epel-release-8.2.noarch.rpm
```

Configuration files list multiple repository references in a single file. Each repository reference begins with a unique name inside square brackets.

```
[user@host ~]$ cat /etc/yum.repos.d/epel.repo
[epel]
name=Extra Packages for Enterprise Linux 8 - $baseurl
```

# Installing and updating software packages

```
#baseurl=http://download.fedoraproject.org/pub/el8/$basesearch
mirrorlist=https://mirrors.fedoraproject.org/metalink?repo=epel-8&arch=$basesearch
failovermethod=priority
enabled=1
gpgcheck=0
gpgkey=:///etc/pki/rpm-gpg/RPM-GPG-KEY-EPEL-8
```

```
[epel-debuginfo]
name=Extra Packages for Enterprise Linux 8 - $basesearch Debug
baseurl=http://download.fedoraproject.org/pub/el8/$basesearch/debug
mirrorlist=https://mirrors.fedoraproject.org/metalink?repo=epel-debug-8&arch=$basesearch
failovermethod=priority
enabled=0
gpgkey=:///etc/pki/rpm-gpg/RPM-GPG-KEY-EPEL-8
gpgcheck=1
```

```
[epel-source]
name=Extra Packages for Enterprise Linux 8 - $basesearch Source
baseurl=http://download.fedoraproject.org/pub/el8/SRPMS
mirrorlist=https://mirrors.fedoraproject.org/metalink?repo=epel-source-8&arch=$basesearch
failovermethod=priority
enabled=0
gpgkey=:///etc/pki/rpm-gpg/RPM-GPG-KEY-EPEL-8
gpgcheck=1
```

To define a repository, but not search by default, insert the enabled=0 parameter. Repositories can be enabled and disabled persistently with **yum-config-manager** command or temporarily with yum command options, `--enablerepo=PATTERN` and `--disablerepo=PATTERN`.

> WARNINGInstall the GPG key before installing signed packages. This verifies that the packages belong to a key which has been imported. Otherwise, the **yum** command fails due to a missing key. The **nogpgcheck** option can be used to ignore missing GPG keys, but this could cause forged or insecure packages to be installed on the system, potentially compromising its security.
