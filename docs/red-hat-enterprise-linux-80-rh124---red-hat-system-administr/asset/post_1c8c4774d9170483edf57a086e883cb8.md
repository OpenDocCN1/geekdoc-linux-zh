- 5. Continuing in the user's home directory, create three subdirectories for organizing your files into projects. Make the subdirectories **friends**, **family**, and **work**. Use a single command to create all these directories at the same time.

You will use directories to rearrange your files into projects.

```
[student@servera ~]$ mkdir friends family work
```

- 6. Copy a new selection of files to the project directories **family** and **friends**. Use as many commands as needed. You do not have to use only one command as in the example. For each project, first change to the project directory, then copy the source files to directory. Keep in mind that you are making copies, the original files will remain in their original locations after the files are copied to the project directories.

- * Copy files (all types) containing the numbers 1 and 2 in the **friends** subdirectory.
- * Copy files (all types) containing the numbers 3 and 4 to the **family** subdirectory.

When copying files from multiple locations into a single location, Red Hat recommends that you use the destination directory prior to copying the files. Use the simplest syntax, absolute or relative, to reach the source for each file task management.

Your projects are now done, and it is time to clean up the projects.

Change to the student's home directory. Attempt to delete both the **family** and **friends** project directories with a single **rmdir** command.

```
[student@servera]$ cd ~
[student@servera]$ rmdir family friends
rmdir: failed to remove 'family': Directory not empty
rmdir: failed to remove 'friends': Directory not empty
```

Using the **rm -r** command should fail because subdirectories contain files.

- 9. Use the **rm -r** command to recursively delete both the **family** and **friends** subdirectories and their contents.

```
[student@servera]$ rm -r family friends
[student@servera]$ ls -l
total 0
drwxrxr-x. 2 student student 108 Feb 4 18:36 Music
drwxrxr-x. 2 student student 108 Feb 4 18:36 Pictures
drwxrxr-x. 2 student student 108 Feb 4 18:36 Videos
drwxrxr-x. 2 student student 108 Feb 4 18:44 work
```

- 10. Delete all the files in the work project, but not delete the work directory.

```
[student@servera ~$] cd work
[student@servera ~] rm song5.mp3 song6.mp3 snap5.jpg snap6.jpg \
> film5.avi film6.avi
[student@servera ~]$ ls -l
total 0
```

- 11. Finally, from the student's home directory, use the rmdir command to delete the work directory. The command should succeed.

```
[student@servera]$ cd ~
[student@servera]$ rmdir family friends
[student@servera]$ ls -l
total 0
```
