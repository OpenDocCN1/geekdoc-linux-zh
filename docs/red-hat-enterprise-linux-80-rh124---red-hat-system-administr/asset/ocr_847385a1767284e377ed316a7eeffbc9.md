# Inspecting and Filtering Syslog Events

Logs in the left navigation bar provide access to analysis tools for the system logs. You can use filter to filter log messages by a logging date, severity level, or both. Web Console you can modify this to specify any range of dates by clicking the date drop-down menu and selecting an appropriate range. Similarly, the Severity drop-down menu provides options ranging from Everything to more specific severity conditions such as Alert and above, Debug and above, and so on.
