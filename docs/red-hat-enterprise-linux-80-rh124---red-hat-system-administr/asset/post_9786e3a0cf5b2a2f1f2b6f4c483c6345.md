# WHAT IS A USER?

User account is used to provide security boundaries between different people and programs that can run commands.

Users have user names to identify them to human users and make them easier to work with. Internally, the system distinguishes user accounts by the unique identification number assigned to them, the ID or UID. If a user account is used by humans, it will generally be assigned a password that the user will use to prove they are the authorized user when logging in.

User accounts are fundamental to system security. Every file has a particular user as its owner. File ownership helps the system enforce access control for files of the users. The user associated with a running process determines the files and directories accessible to process.

There are three types of users:
- The superuser: has full access to the system.
- Daemons: processes that run in the background and do not interact interactively.
- Regular users: have limited access.

To view information about a user, use the id command.

```
[user1@host ~]$ id
uid=1000(user01) gid=1000(user01) groups=1000(user01),27(sudo)
```

# CHAPTER 6

To view basic information about another user, use the id command followed by the username.

```
[user2@host ~]$ id
uid=1002(user02) gid=1002(user02) groups=1002(user02)
```

The output of the preceding command displays users by name, but internally the operating system mapping of usernames to UID is defined in databases of account information. By default, use the /etc/passwd file to store information. Each line in the /etc/passwd file contains information about one user. It is divided up into colon-separated fields. Here is an example of a line:user01:x:1000:1000:User One:/home/user01:/bin/bash

- Username for this user (user01).
- The user's password used to be stored here in encrypted format. That has been moved to the /etc/shadow file, which should always be x.
- The UID for this user account (1000).
- The GID for this user's primary group (1000).
- The real name for this user (User One).
- The home directory for this user (/home/user01). This is the initial working directory when the shell starts.
- The default shell for this process, which runs on login (/bin/bash).

# WHAT IS A GROUP?

A group is a collection of users that share access to files and other system resources. Groups can be used to grant access to files to a set of users instead of just a single user.

Like users, groups have group names to make them easier to work with. Internally, the system distinguishes groups by the unique identification number assigned to them, the group ID or G.

The mapping of group names to GIDs is defined in databases of group account information. By default, use the /etc/group file to store information about local groups.

Example of a line in /etc/group:sudo:27:user01,user2

- Group name (sudo).
- The GID for this group (27).
- List of users belonging to the group.

To view group information, use the ps command with the a option. The default is to show only processes in the current shell. Add the u option to include users with a terminal.

```
[student@workstation ~]$ ps -au
USER       PID %CPU %MEM    VSZ TTY START TIME COMMAND
root         1  0.0  0.1  16800 ?        Ss   09:00   /sbin/init
user01    1234  0.0  0.0  4500 pts/0    S    10:00 0:00 /bin/bash
user02    5678  0.0  0.0  4600 pts/1    S    10:01 0:00 /bin/bash
```
