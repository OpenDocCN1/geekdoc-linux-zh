To enable support for a third-party repository, create a file in the /etc/yum.repos.d/ directory. Repository configuration files must end with a .repo extension. The repository definition contains the URL of the repository, a name, whether to use GPG to check the package signatures, and if so, the URL pointing to the trusted GPG key.

# # Creating Yum Repositories

Create Yum repositories with the yum-config manager. The following command creates a file named /etc/yum.repos.d/dl.fedoraproject.org/pub_8_x86_64/ with the output shown.

```
[user@host ~]$$ yum-config-manager --add-repo=http://dl.fedoraproject.org/pub/el8/x86_64/
loaded plugins: langpacks
adding repo from: http://dl.fedoraproject.org/pub/el8/x86_64/

[dl.fedoraproject.org.pub_8_x86_64]
name=added from: http://dl.fedoraproject.org/pub/el8/x86_64/
baseurl=http://dl.fedoraproject.org/pub/el8/x86_64/
enabled=1
```

Modify this file to provide customized values and location of a GPG key. Keys are stored in locations on the repository site, such as, http://dl.fedoraproject.org/pub/el8/RPM-GPG-KEY-EL-8. Administrators should download the key to a local file rather than retrieve it from an external source. For example:

```
[EPEL]
name=EPEL 8
baseurl=http://dl.fedoraproject.org/pub/el8/x86_64/
enabled=1
gpgcheck=1
gpg_key=file:///etc/pki/rpm/RPM-GPG-KEY-EPEL-8
```

# # RPM Configuration Packages for Local Repositories

Some repositories provide a configuration file and GPG key as part of an RPM package that can be downloaded and installed using the yum install command. For example, the volunteer project created Extra Packages for Enterprise Linux (EPEL) provides software not supported by Red Hat Linux.

The following command installs the Red Hat Enterprise Linux 8 EPEL repository:

```
[user@host ~]$$ rpm --import http://dl.fedoraproject.org/pub/el8/RPM-GPG-KEY-EL-8
[user@host ~]$$ yum install http://dl.fedoraproject.org/pub/el8/x86_64/epel-release-8.2.noarch.rpm
```

Configuration files list multiple repository references in a single file. Each repository reference begins with a unique-word name inside square brackets.

```
[user@host ~]$$ cat /etc/yum.repos.d/epel.repo
[epel]
name=Extra Packages for Enterprise Linux 8 - $baseurl
```
