# VALIDATING NETWORK CONFIGURATION

# OBJECTIVES

After completing this section, you will be able to test and inspect current network configuration with command-line utilities.

# GATHERING NETWORK INTERFACE INFORMATION

# Identifying Network Interfaces

The ip link command will list all network interfaces available on your system:

```
[user@ ~]$ ip link
1: <LOOPBACK,UP,LOWER_UP> mtu 65536 disc noque state UNKNOWN mode DEFAULT
  group default qlen 1000
  link/loopback 00:00:00:00:00:00 br 00:00:00:00
2: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP DEFAULT
  group default qlen 1000
  link/ether 52:54:00:00:00:0a br ff:ff:ff:ff:ff:ff
3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP DEFAULT
  group default qlen 1000
  link/ether 52:54:00:00:00:1e br ff:ff:ff:ff:ff:ff
```

In the following example, the server has three network interfaces: lo, which is the loopback that is connected to the server itself, and two Ethernet interfaces, ens3 and ens4.

To configure each network interface correctly, you need to know the MAC address of the interface connected to each network, many because it is physically printed on the server, or because it is a virtual machine and you know it is configured. The MAC address of the device is listed after link/ether for each interface. So you know that the network with the MAC address 52:54:00:00:00:0a is the network interface ens3.

# Displaying IP Addresses

Use the ip command to view address and address. A single network interface can have multiple IPv4 or IPv6 addresses.

```
[user@ ~]$ ip addr show ens3
2: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc pfifo_fate state UP
  qlen 1000
  link/ether 52:54:00:00:00:0b br ff:ff:ff:ff:ff:ff
  inet 192.0.2.2/24 br 192.0.2.255 scope global
      valid_l preferred preferred_l forever
  inet6 2001:db8::1:5054:fe00:b/64 scope global
      valid_l preferred preferred_l forever
  inet6 fe80::5544:fe00:b/64 scope link
```
