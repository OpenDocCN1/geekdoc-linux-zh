# BASIC COMMAND SYNTAX

The GNU Bourne-Again Shell (bash) is a program that interprets commands typed in by the user. Each string typed into the shell has up to three parts: the command, options (which usually begin with - or --), and arguments. Each word typed into the shell is separated from each space. Commands are the names of programs that are installed on the system. Each command has its own options and arguments.

When you are ready to execute a command, press the Enter key. Type each command on a separate line. The command output is displayed before the next shell prompt.

```
user@host$ whoami
user
user@host$
```

If you want to type more than one command on a single line, use the semicolon (;) as a command separator. Semicolon is a member of characters called metacters that have special meanings for bash. In this case the output of both commands will be displayed before the next shell prompt appears.

The following example shows how to combine two commands (command1 and command2) on the command line.

```
user@host$ command1;command2
```

# EXAMPLES OF SIMPLE COMMANDS

The date displays the current date and time. It also can be used by the superuser to set the system clock. An argument that begins with a plus (+) specifies a format string for the date.

```
user@host ~$ date
Sat Jan 26 08:13:50 IST 2019
user@host ~$ date %+R
08:13
user@host ~$ date +x
01/26/2019
```

The passwd command changes a user's password. By default, passwd is configured to require a strong password before a change is allowed. Password consisting of lowercase letters, uppercase letters, numbers, and symbols, and is not based on a dictionary word.

# VIEWING THE CONTENTS OF FILES

One of the most simple and frequently used commands in Linux is cat. The cat command allows you to create single or multiple files, view the contents of files, concatenates multiple files and redirects the contents of a file to a terminal.

The example shows how to view the contents of the /etc/passwd file.

```
[user@host ~]$ cat /etc/passwd
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/sbin/nologin
deamon:x:2:2:daemon:/sbin/nologin
adm:x:3:4:adm:/var/adm:/sbin/nologin
... omitted ...
```

Use the following command to display the contents of multiple files.

```
[user@host ~]$ cat file1 file2
Hello World!
Introduction to Linux commands.
```

Some files are very long and can take up more room to display than that provided by the terminal. The cat command does not display the contents of a file as pages. The less command displays one page of a file at a time and lets you scroll at your leisure.

The less command allows you to page forward and backward through files that are longer than they can fit on one terminal window. Use the UpArrow key and the DownArrow key to scroll up and down. Press Q to exit the command.

The head and tail display the beginning and end of a file, respectively. By default these commands display 10 lines of the file, but both have a -n option that allows a different number of lines to be specified. The file is displayed as an argument to these commands.

```
[user@ ~]$ head /etc/password
root:x:0:root:/bin/bash
bin:x:1:1:/bin:/sbin/nologin
demon:x:2:2:/sbin:/sbin/nologin
adm:x:3:3:/var/adm:/sbin/nologin
lp:x:4:7:/var/spool/lpd:/sbin/nologin
sync:x:5:0:/sbin/bin/sync
shutdown:x:6:0:/sbin/bin/shutdown
halt:x:7:0:/sbin/bin/halt
mail:x:8:12:/var/spool:/sbin/nologin
operator:x:11:0:/root:/sbin/nologin
[user@ ~]$ tail -n 3 /etc/password

gnome-initial-setup:x:9:77:/run/gnome-initial-setup:/sbin/nologin
avahi:x:70:70:/run/avahi-daemon:/sbin/nologin
```

The wc command counts lines, words, or characters in a file. It takes a -l, -w, or -c option to display only the number of lines, words, or characters, respectively.

```
[user@ ~]$ wc /etc/password
45 124 255
[user@ ~]$ wc -l /etc/group
70
[user@ ~]$ wc -c /etc/hosts
966 1482 total
```

# TAB COMPLETION

Tab allows a user to quickly complete commands or file names after they have typed enough at the prompt to make it unique. If the characters are not unique, pressing the Tab twice displays all commands that begin with the characters typed.

```
[user@host ~]$ ls /etc/passwd
[user@host ~]$ ls /etc/passwd
[user@host ~]$ passwd
Changing password for user.
Current password:
```

Press Tab twice.
Press Tab once.

Tab completion can be used to complete file names when typing them as arguments to commands. When Tab is pressed, it completes as much of the name as possible.

```
[user@host ~]$ ls /etc/passwd
[user@host ~]$ ls /etc/passwd
passwd-
```

Arguments and options can be matched with tab completion for many commands. The useradd command is used by the superuser, root, to create additional users on the system. It has many options that can be used to control how command behaves. Tab completion following a partial option can be used to complete the option without a lot of typing.

```
[root@host #] useradd --
--base-dir --groups --log-init --shell
--comment --non-unique --skel
--create-home --home-dir --no-user --system
--defaults --inactive --password --uid
--expired --key --root
--gid --no-create-home --selinux-user --user-group
[root@host #] useradd --
```

# CONTINING A COMMAND ON ANOTHER LINE

Commands that support many options and arguments can quickly grow long and are automatically scrolled by the Bash shell. As soon as the command reaches the right margin of the window, the command continues on the next line. To make the readability of the command easier, you can break it up that fits on more than one line. To do this, add a backslash character (\ as the last character on the line. This tells the shell to ignore the newline character and treat the next line as if it were part of the current line. The Bash shell will start the next line with the continuation prompt, a greater-than character (>), which indicates that the line is a continuation of the previous one. You can do this more than once.

```
[user@host]$ head -n 3 \
> /usr/share/dict/words \
> /usr/share/dict/linux.words
==>/usr/share/dict/linux.words <=
1080
10-point
10th

==>/usr/share/dict/linux.words <=
1080
10-point
10th
```

# COMMAND HISTORY

The **history** command displays a list of previously executed commands prefixed with a command number.

The exclamation point character (!) is a metacharacter that is used to expand previous commands without having to retype them. The **number** command expands to the command matching the number specified. The **string** command expands to the most recent command that begins with the string specified.

```
[user@host]$ history
....output omitted...
23 clear
24 who
25 pwd
26 ls /etc
27 uptime
28 ls -l
29 date
30 history
[user@host]$ !ls
ls -l
total 0
drwx-xr-x. 2 user 2 Mar 29 21:16 Desktop
....output omitted...
[user@host]$ !$26
ls /etc
abrt                 hosts      pulse
adjime             hosts.allow purple
aliases             hosts.deny qemu-ga
....output omitted...
```

The arrow keys can be used to navigate through previous commands in the shell's history. **UpArrow** edits the previous command in the history list. **LeftArrow** and **RightArrow** move the cursor left and right in the current command from the history list, so that you can edit it before running.

You can use the Esc+, or **Alt+**, to insert the last word of the previous command at the cursor's location. Repeated use of the key combination will replace that text with the last word of earlier commands in the history. The **Alt+.** key combination is particularly convenient when you hold **Alt** and **press.** repeatedly to easily go through earlier and earlier commands.
