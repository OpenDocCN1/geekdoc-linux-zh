# LAB
CONFIGURING AND MANAGING A SERVER

In this review, you will configure, secure, and use SSH service to access remote machine, configure rsyslog service, archive local files, transfer local files to remote machine, and manage packages using yum.

# OUTCOMES
You should be able to:

+   - Create a new SSH key pair.
- Disable SSH logins as root user.
- Disable SSH logins using password.
- Update the time zone of a server.
- Install packages and package modules using yum.
- Archive local files for backup.
- Transfer local files to remote machine.

# BEFORE YOU BEGIN
Log in to workstation as using student as the password.

On workstation, run lab rhca-rh124-review3 start to start the comprehensive review. This script creates the necessary files to set up the environment correctly.

```
[student]@workstation ~$ lab rhca-rh124-review3 start
```

# INSTRUCTIONS
Accomplish the following tasks on server to complete the exercise.

+   - Generate SSH keys for the user student on server. Do not protect the private key with a passphrase.
- On server, configure the user student to accept logins authenticated by the SSH key pair to configure the user student on server. The user student on server should be able to log in to server using SSH without entering a password.
- On server, configure the sshd service to prevent users from using their passwords to log in. Users should still be able to authenticate logins using an SSH key pair.
- Create a tar archive named /tmp/log.tar containing the contents of /var/log on server. Remotely transfer the tar archive to /tmp directory on servera, authenticating as student using student's private key of the SSH key pair.
