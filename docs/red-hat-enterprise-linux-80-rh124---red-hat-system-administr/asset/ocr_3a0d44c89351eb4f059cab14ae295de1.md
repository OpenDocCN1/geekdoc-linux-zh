/home/techdocs directory. Exit from the tech1 user shell.

```
[root@server ~]$ su tech1
[tech1@server ~]$ touch /home/techdocs/techdoc1.txt
[tech1@server ~]$ ls -l /home/techdocs/techdoc1.txt
-rw-rw-rw- 1 tech1 techdocs 0 Feb 5 16:42 /home/techdocs/techdoc1.txt
[tech1@server ~]$ exit
logout
[root@server ~]#
```
