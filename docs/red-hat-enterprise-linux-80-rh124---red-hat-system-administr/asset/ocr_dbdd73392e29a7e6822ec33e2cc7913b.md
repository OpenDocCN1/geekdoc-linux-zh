# REVIEWING SYSTEM JOURNAL ENTRIES

# OBJECTIVES

After completing this section, you should be able to find and interpret entries in the system journal
to troubleshoot problems or review system status.

# FINDING EVENTS

The systemd-journal service stores logging data in a structured, indexed binary file called the
journal. This data includes extra information about the log event. For example, syslog events
this includes the facility and priority of the original message.

> In Red Hat Enterprise Linux 8, the /run/log directory stores the system journal by
default. The contents of the /run/log directory get cleared after a reboot. You can
change this setting, and how to do so is discussed later in this chapter.

To retrieve log messages from the journal, use the journalctl command. You can use this
command to view all messages in the journal, or to search for specific events based on a wide
range of options and criteria. If you run the command, you have full access to the journal.
Regular users can use this command, but may be restricted from seeing certain messages.
