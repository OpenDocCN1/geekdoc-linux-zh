The journalctl command highlights important log messages: messages in notice or warning priority are in bold text when the error priority is higher or it is red.

The key to using the journal for troubleshooting and auditing is to limit journal searches to show only relevant output.

By default, journalctl -n shows the last 10 log entries. You can adjust this with an option argument that specifies how many log entries to display. For the last five entries, run the following journalctl command:

```
[root@host ~]# journalctl -n 5
```
