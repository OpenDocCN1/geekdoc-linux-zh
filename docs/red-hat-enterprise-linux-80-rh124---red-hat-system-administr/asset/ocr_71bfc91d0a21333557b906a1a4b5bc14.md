# Comprehensive review

+   - Configure the IPv4 address 172.250.211 with the netmask 255.255.255.0 on the same interface of serverb that has the existing static network settings. Do not remove the existing IPv4 address. Make sure that serverb responds to all addresses when the network statically configured on its interface is active.
- On serverb, restore the original network settings by activating the original network connection and deactivating the static network connection you created manually.

+   1. Log in to the "physical" console of serverb as user student:
In the web page that controls your lab environment, click the CONSOLE button for serverb. A tab will open in your browser with the console session for serverb. Log in as student at the prompt.
It is a good practice to make network changes from the console of the server, whether locally, through special hardware for remote console access, or a remotely-accessible serial console. If you use ssh to adjust network settings, you can easily hang your session or lock yourself out of remote access to the server when you change connection profiles.
2. Determine the name of the Ethernet interface on serverb and the name of the connection profile that it is using.

```
[serverb]$ nmcli device status
DEVICE TYPE STATE CONNECTION
ens3 ethernet connected Wired connection 1
lo loopback unmanaged --
```

In this example, ens3 is the name of the Ethernet interface on the system. This is the interface for which you will create the connection profile.
The of the network interface and of the initial connection profile might differ on serverb. If so, use the name shown by your system in the remaining steps of this solution in place of the name used in this solution.

+   3. On serverb, create a new connection profile called static for the available Ethernet interface. Set the network settings statically so that it does not use DHCP. Base the settings on the following table:

| IPv4 address | 172.250.250.111 |
|---|---|
| Netmask | 255.255.255.0 |
| Gateway | 172.250.250.254 |
| DNS server | 172.250.250.254 |

The serverb's Ethernet interface should use the updated network settings mentioned in the preceding table.

+   3.1. Use nmcli to create the connection static with the given network settings.

```
[serverb]$ sudo nmcli connection add-name static type ethernet \
nifname ens3 ipv4.addresses '172.250.111/24' ipv4.gateway '172.250.250.254' \
ipv4.dns '172.250.250.254' ipv4.method manual
[sudo] password for student: student
```
