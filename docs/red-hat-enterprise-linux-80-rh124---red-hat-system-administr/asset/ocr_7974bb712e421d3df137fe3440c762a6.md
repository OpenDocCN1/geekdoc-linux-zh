# VERIFYING THE STATUS OF A SERVICE

systemctl command provides methods for verifying the specific status of a service. For example, use the following command to verify that a service unit is currently active (running):

```
root@host ~# systemctl is-active sshd.service
active
```

The command returns the state of the service unit, which is active or inactive.

Run the following command to verify whether a service unit is enabled to start automatically during system boot:

```
root@host ~# systemctl is-enabled sshd.service
enabled
```

The command returns whether the service unit is enabled to start at boot time, which is usually enabled or disabled.

```
root@host ~# systemctl is-failed sshd.service
active
```

The command returns active if it is properly running or failed if an error has occurred during startup. In case the unit was stopped, it returns unknown or inactive.

To list all the failed units, run the systemctl --failed --type=service command.

> REFERENCES
system(1), systemd.unit(5), systemd.service(5), systemd.socket(5), systemctl(1) man pages
