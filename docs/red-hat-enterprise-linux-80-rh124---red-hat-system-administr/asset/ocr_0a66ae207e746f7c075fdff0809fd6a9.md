# Example routing

| DESTINATION | INTERFACE | ROUTER (IF NEEDED) |
|---|---|--|
| 192.0.2.0/24 | wlo1 | |
| 192.168.5.0/24 | enp3s0 | |
| 0.0.0.0 (default) | enp3s0 | 192.168.5.254 |

In this example, traffic headed for the IPv4 address 192.0.2.102 is transmitted directly to that destination via the wlo1 wireless interface, because it matches the 192.0.2/24 route most closely. Traffic for the IPv4 address 192.168.5.3 is transmitted directly to that destination via the enp3s0 Ethernet interface, because it matches the 192.168.5.0/24 route most closely.

Traffic to the address 10.2.24.1 is transmitted out the enp3s0 Ethernet interface to a router at 192.168.5.254, which falls on to its final destination. That traffic matches the 0.0.0.0/0 route most closely, as there is no more specific route in the routing table of this. The host uses its own routing table to determine where to forward that traffic to.

# IPv4 Address and Route Configuration

A server can automatically configure its IPv4 network settings at boot time from DHCP server. The local client daemon queries for a server and network settings, and obtains a lease to use those settings for a specific length of time. If the client does not request a renewal of the lease periodically, it may lose its network configuration settings.

As an alternative, you can configure a server to use a static network configuration. In this case, network settings are read from local configuration files. You must get the correct settings from your network administrator and update them manually as avoid conflicts with other servers.

# IPV6 NETWORKING

IPv6 is intended as an eventual replacement for the IPv4 network protocol. You will need to understand how it works since increasing numbers of production systems use IPv6 addressing. For example, many ISPs use IPv6 for internal communication and device management networks in order to preserve IPv4 addresses for customer purposes.

IPv6 can also be used in parallel with IPv4 in a dual-stack model. In this configuration, the network interface can have an IPv6 address or addresses as well as IPv4 addresses. Red Hat Enterprise Linux operates in a dual-stack mode by default.

# IPv6 Addresses

An IPv6 address is a 128-bit number, normally expressed as eight colon-separated groups of four hexadecimal digits. Each group represents four nibbles (half-bytes), so each group represents 16 bits of the IPv6 address,

```
2001:0db8:0000:0010:0000:0000:0000:0001
```

To make IPv6 addresses easier to write, leading zeros in a colon-separated group do not need to be written. However, at least one hexadecimal digit must be written in colon-separated group.
