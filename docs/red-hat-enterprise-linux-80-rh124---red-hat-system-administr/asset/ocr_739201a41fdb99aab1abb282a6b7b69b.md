# CHAPTER 1 | Accessing Linux Systems

To mount a file system, the destination directory must already exist. The /mnt directory exists by default and is intended for use as a temporary mount point.

You can use /mnt, or better create a subdirectory of /mnt to use as a temporary mount point, unless you have a good reason to mount in a specific location in the file-system hierarchy.

> IMPORTANT
If the directory acting as mount point is not empty, any files copied to that directory before the file system was mounted were not accessible until the file system is unmounted.

This approach works fine in the short run. However, the order in which the operating system detects can change if devices are added or removed from the system. This will change the device name associated with that storage device. A better approach would be to mount by some characteristic built into the file system.

# Mount by File-system UUID

One stable identifier that is associated with a file system is its UUID, a very long hexadecimal number that acts as part of the file system and remains the same as the file system unless it is recreated.

The lsblk -fp command lists the full path of the device, along with the UUIDs and mount points, as well as the type of file system in the partition. If the file system is not mounted, the mount point will be blank.

```
[root@host ~]# lsblk -fp
NAME FSTYPE UUID MOUNTPOINT
/dev/vda
/dev/vda1 xfs 23ea8883-a396-494a-82e5-1538a5b821c /boot
/dev/vda2 swap cdf6162d-534c-4bd6-b458-cab1b81a72ea [SWAP]
/dev/vda3 xfs 4438f15-2f9d-4745-ae2e-20844f27262/
/dev/vdb
/dev/vdb1 xfs 46f5s43d-78c9-4526-a857-244811e2d88
```

Mount the file system by the UUID of the file system.

```
[root@host ~]# mount UUID="46f543d-78c9-4526-a857-244811e2d88" /mnt/data
```

# AUTOMATIC MOUNTING OF REMOVABLE STORAGE DEVICES

If you are logged in and using the graphical desktop environment, it will automatically mount removable storage media when it is inserted.

The removable storage device is mounted at /run/media/USERNAME/LABEL where USERNAME is the name of the user logged into the graphical environment and LABEL is an identifier, often the name given to the file when it was created if one is available.

Before removing the device, you should unmount it.
