# EDITING NETWORK CONFIGURATION FILES

## OBJECTIVES

After completing this section, you should be able to modify network configuration by editing configuration files.

## DESCRIBING CONNECTION CONFIGURATION FILES

By default, changes made with nmcli con mod name are automatically saved to /etc/sysconfig/network-scripts/ifcfg-name. That file can also be manually edited with a text editor. After doing so, run nmcli reload so that NetworkManager reads the configuration changes.

For backward-compatibility reasons, the directives saved in that file have different names and syntax than the nm-settings(5) names. The following table maps some of the key setting names to ifcfg-* directives.

Comparison of nm-settings and ifcfg-* directives

| NMCLI CON MOD | IFCFG-* | EFFECT |
| --- | --- | --- |
| ipv4.method manual | BOPROTO=none | IPv4 addresses configured statically. |
| ipv4.method auto | BOPROTO=dhcp | Looks for configuration settings from DHCP4. If server addresses are also set, will not bring those up until we have information from DHCP4. |
| ipv4.addresses "192.0.2.1/24 192.0.2.254" | IPADDR0=192.0.2.1 PREFIX=24 GATEWAY=192.0.2.254 | Sets static IPv4 address, network prefix, and default gateway. If more than one is set for the connection, then instead of 0, the ifcfg-* directs with 1, 2, and 3 so on. |
| ipv4.dns 8.8.8.8 | DNS8=8.8.8.8 | Modify /etc/resolv.conf to use this nameserver. |
| ipv4.dns-search example.com | DOMAIN=example.com | Modify /etc/resolv.conf to use this domain in the search directive. |
| ipv4.ignore-auto-dns true | PEERDNS=no | Ignore DNS server information from the DHCP server. |

| NMCLI CON MOD | IFCFG-* FILE | EFFECT |
| --- | --- | --- |
| ipv6.method manual | IP6_AUTOCCONF=no | IPv6 addresses configured statically. |
| ipv6.method auto | IP6_AUTOCCONF=yes | Configures network settings using SLAAC from router advertisements. |
| ipv6.method dhcp | IP6_AUTOCCONF=no DHCPV6=yes | Configures network settings by using DHCPv6, but not SLAAC. |
| ipv6.addresses "2001:db8::/a64" | IP6ADDR=2001:db8::/a64 IP6_DEFAULTGW=2001:db8 | Sets static IPv6 address, network prefix, and gateway. If more than one address is set for the connection, IP6_SECONDARIES takes a double-quoted list of delimited address/prefix definitions. |
| ipv6.dns . . . | DNS=. . . . | Modify /etc/resolv.conf to use this namesake. Exactly the same as IPv4. |
| ipv6.dns-search example.com | DOMAIN=example.com | Modify /etc/resolv.conf to use this domain in the search directive. Exactly the same as IPv4. |
| ipv6.ignore-auto-dns true | IP6_PEERDNS=no | Ignore DNS server information from the DHCP server. |
| connection.autoconnect yes | ONBOOT=yes | Automatically activates this connection at boot. |
| connection.id ens3 | NAME=ens3 | The name of this connection. |
| connection.interface-name ens3 | DEVICE=ens3 | The connection is bound to the network interface with this name. |
| connection.802-ethernet.mac-address | HWADDR=. . . | The connection is bound to the network interface with MAC address. |

# MODIFYING NETWORK CONFIGURATION

It is also possible to configure the network by directly editing configuration files. Connection files control the interfaces for individual devices. Files are usually named /etc/sysconfig/network-scripts/ifcfg-name, where name refers to the name of the device or connection. The following are standard variables found in the file used for static or dynamic IPv4 configuration.

## IPv4 Configuration Options for ifcfg File

| STATIC | DYNAMIC |
| --- | --- |
| BOOTPROTO=none | BOOTPROTO=dhcp |
| IPADDR=172.255.250.10 | NAME="static-ens3" |
| PREFIX=24 | ONBOOT=yes |
| GATEWAY=172.255.250.254 | UUID=f3e8ad3e |
| DEFROUTE=yes | USERCTL=yes |
| DNS1=172.255.250.254 | |

In the static settings, variables for IP address, prefix, and gateway have a number at the end to allow multiple sets of values assigned to the interface. The DNS variable also has a number to specify the order of lookup when multiple servers are specified. After modifying the configuration files, run nmcli reload to make NetworkManager read the changes. The interface needs to be restarted for changes.

```
[root@host ~]# nmcli reload
[root@host ~]# nmcli down "static-ens3"
[root@host ~]# nmcli up "static-ens3"
```
