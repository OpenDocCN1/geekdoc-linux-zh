The command tzselect is useful for identifying zoneinfo time names. It interactively prompts the user with questions about the system's location, and outputs the name of the correct time zone. It does not make any change to the time zone setting of the system.

The superuser can change the system setting to update the current time zone using the timedatectl set-timezone. The following timedatectl updates the current time zone to America/Phoenix.

```
[root ~]## timedatectl set-timezone America/Phoenix
[root ~]## timedatectl
  Local time: Fri 2019-04-05 14:12:39 MST
  Universal time: Fri 2019-04-05 21:12:39 UTC
  RTC time: Fri 2019-04-05 21:12:39
  Time zone: America/Phoenix (MST, -0700)
System clock synchronized: yes
  NTP service: active
  RTC in local TZ: no
```

> Should you need to use the Coordinated Universal Time (UTC) on a particular server, set its time zone to UTC. The tzselect command does not include the name of the UTC time zone. The timedatectl set-timezone UTC command to set the system's current time zone to UTC.

Use the timedatectl set-time command to change the system's current time. The time is specified in the "YYYY-MM-DD hh:mm:ss" format, where either date or time can be omitted. The following timedatectl command changes the time to 09:00:00.

```
[root ~]# timedatectl set-time 09:00:00
[root@server ~]$ timedatectl
  Local time: Fri 2019-04-05 09:00:27 MST
  Universal time: Fri 2019-04-05 16:00:27 UTC
  RTC time: Fri 2019-04-05 16:00:27
  Time zone: America/Phoenix (MST, -0700)
System clock synchronized: yes
  NTP service: active
  RTC in local TZ: no
```

The timedatectl set-ntp command enables or disables NTP synchronization for automatic time adjustment. The option requires either a true or false argument to turn it on or off. The following timedatectl command turns on NTP synchronization.

```
[root ~]# timedatectl set-ntp true
```
