# MANAGING FILES FROM THE COMMAND LINE

# PERFORMANCE CHECKLIST

In this lab, you will efficiently create, move, and remove files and directories by using the shell and a variety of file name matching techniques.

# OUTCOMES

You should be able to:

+   - Use wildcards to locate and manipulate files.

# BEFORE YOU BEGIN

Log in to workstation as student using student as password.

On workstation, run the lab files-review start command. The command runs a start script that determines if the serverb machine is reachable on the network.

```
[student@workstation ~]$ lab files-review start
```

+   1. Use the ssh command to log in to server as student user. The systems are configured to use ssh keys for authentication, and therefore a password is not required.
2. Before create project files, use the mkdir command with brace expansion to create empty planning documents in the /home/student/Documents/project_plans directory. (Hint: if ~/Documents does not exist, the -p option for the mkdir command will create it.)
Create two empty files in the ~/project_plans directory: season1_project_plan.edf and season2_project_plan.edf.

```
[student@workstation ~]$ ssh student@serverb
[student@serverb ~]
[student@serverb ~]$ mkdir -p ~/Documents/project_plans
[student@serverb ~]$ touch ~/Documents/project_plans/{season1,season2}_project_plan.edf
[student@serverb ~]$ ls -l ~/Documents/
Documents:
total 0
drwxr-xr-x. 2 student student Jan 30 18:20 project_plans

Documents/project_plans:
total 0
-rw-rw-r--. 1 student student Jan 31 18:20 season1_project_plan.edf
```
