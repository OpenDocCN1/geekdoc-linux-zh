# Accessing Knowledgebase Articles by Document ID

Locate online articles directly using the tool's kb command with the Knowledgebase document ID. A returned document scrolls the screen out pagination, but you can redirect it to a file to save and use less to scroll through at a time.

```
[user@]$ redhat-support-tool kb 253273
```

# MANAGING SUPPORT CASES WITH RED HAT SUPPORT TOOL

One benefit of a product subscription is access to technical support through Red Hat Customer Portal. Depending on the system's subscription support level, Red Hat may be contacted through online tools or by phone. See https://access.redhat.com/site/support/policy/support_process for detailed information.
