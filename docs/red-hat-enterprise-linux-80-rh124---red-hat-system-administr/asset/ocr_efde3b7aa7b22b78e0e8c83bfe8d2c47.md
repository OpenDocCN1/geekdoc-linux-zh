# Headers

| HEADING | DESCRIPTION |
| NAME | Subject name. Usually a command or file name. Very brief description. |
| SYNOPSIS | Summary of the command syntax. |
| DESCRIPTION | In-depth description to provide a basic understanding of the topic. |
| OPTIONS | Explanation of the command execution options. |
| EXAMPLES | Examples of how to use the command, function, or file. |
| FILES | A list of files and directories related to the man page. |
| SEE ALSO | Related information, normally other man page. |
| BUGS | Known bugs in the software. |
| AUTHOR | Information about who has contributed to the development of the topic. |

# SEARCHING FOR MAN PAGES BY KEYWORD

A keyword search is performed on man pages with man -k keyword, which displays a list of keyword-matching man pages with sections.

```
$student@Desktop~$ man -k password
checkpasswdAccess (3) - query the SELinux policy database in the kernel.
passwd (8) - update passwords in batch mode
ckpasswd (8) - nrprpd password authenticator
ckpasswd (8) - get password file entry reentrantly
fgetwent_r (3) - get password file entry reentrantly
getwent_r (3) - get password file entry reentrantly
...
passwd (1) - update user's authentication tokens
sslpassword (issl) - compute password hashes
passwd (5) - password file
passwd.ntp (5) - Passwords for connecting to remote NNTP servers
passwd2des (3) - RFS password encryption
```

Popular system administration topics are in sections 1 (user commands), 5 (file formats), and 8 (administrative commands). Administrators using certain troubleshooting tools also use 2 (system calls). The remaining sections are generally for programmer reference or advanced administration.

> NOTE
Keyword searches only on an index generated by the mandb(8) command, which must run as root. The command runs daily through cron.daily, or by anacrontab within an hour of boot, if out of date.
