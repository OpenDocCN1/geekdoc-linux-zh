# Moving Files

The mv command moves files from one location to another. If you think of the absolute path to a file as its name, moving a file is effectively the same as renaming a file. File contents remain unchanged.

Use the mv command to rename a file.

```
[user@host Videos]$ cd ../Documents
[user@host Documents]$ ls -1 *thesis*
-rw-rw-r-- 1 user user Feb 21:16 thesis_chapter1.odf
-rw-rw-r-- 1 user user Feb 21:16 thesis_chapter2.odf
[user@host Documents]$ mv thesis_chapter2.odf thesis_chapter2_reviewed.odf
[user@host Documents]$ ls -1 *thesis*
-rw-rw-r-- 1 user user Feb 21:16 thesis_chapter1.odf
-rw-rw-r-- 1 user user Feb 21:16 thesis_chapter2_reviewed.odf
```

Use the mv command to move a file to a different directory.

```
[user@host Documents]$ ls Thesis/Chapter1
[user@host Documents]$
[user@host Documents]$ mv thesis_chapter1.odf Thesis/Chapter1
[user@host Documents]$ ls Thesis/Chapter1
thesis_chapter1.odf
[user@host Documents]$ ls -1 *thesis*
-rw-rw-r-- 1 user user Feb 21:16 thesis_chapter2_reviewed.odf
```

# Removing Files and Directories

The rm command removes files. By default, rm will not remove directories that contain files, unless you add the -r or --recursive option.

> IMPORTANT
> There is no command-line undo feature, nor a "trash bin" from which you can restore files staged for deletion.

It is a good idea to verify your current working directory before removing a file or a directory.

```
[user@host Documents]$$ pwd
/home/student/Documents
```

Use the rm command to remove a single file from your working directory.

```
[user@host Documents]$$ ls -l thesis*
-rw-rw-r-- 1 user 0 Feb 6 21:16 thesis_chapter2_reviewed.odf
[user@host Documents]$$ rm thesis_chapter2_reviewed.odf
[user@host Documents]$$ ls -l thesis*
is: cannot access 'thesis': No such file or directory
```

If you attempt to use the rm command to remove a directory without the -r option, the command will fail.

```
[user@host Documents]$$ rm Thesis/Chapter1
rm: cannot remove 'Thesis/Chapter1': Is a directory
```

Use the rm -R command to remove a sub True and its contents.

```
[user@host Documents]$$ ls -R Thesis
Thesis/
Chapter1 Chapter2 Chapter3

Thesis/Chapter1:
thesis_chapter1.odf

Thesis/Chapter2:
thesis_chapter2.odf

Thesis/Chapter3:
[user@host Documents]$$ rm -rf Thesis/Chapter1
[user@host Documents]$$ ls -l
total 8
drwxr-xr-x. 2 user 4096 Feb 11 12:47 Chapter2
drwxr-xr-x. 2 user 4096 Feb 11 12:48 Chapter3
```

The rm -r command traverses each subdirectory first, removing their files before removing each directory. You can use the rm -ri command to interactively prompt for confirmation before deleting. This is essentially the opposite of the -f option, which forces removal without prompting you for confirmation.

```
[user@host Documents]$$ rm -ri Thesis
rm: descend into directory 'Thesis?' y
rm: descend into directory 'Thesis/Chapter2?' y
rm: remove empty file 'Thesis/Chapter2/thesis_chapter2.odf?' y
rm: remove directory 'Thesis/Chapter2?' y
rm: remove directory 'Thesis/Chapter3?' y
rm: remove directory 'Thesis?' y
```
