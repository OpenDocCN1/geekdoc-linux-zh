# IMPORTANT

The behavior of Yum groups changed starting in Red Hat Enterprise Linux 7. In RHEL 7, groups are treated as objects, and are tracked by the system. If an installed group is updated, any mandatory or default packages have been added to the group repository, those new packages are installed upon update.

RHEL 6 and earlier consider a group to be installed if all its mandatory packages have been installed, or if it had no mandatory packages, or if any default or optional packages are in the group. Starting in RHEL 7, a group is considered to be installed only if yum group install was used to install it. The yum mark install can be used to mark a group as installed, and any missing packages and their dependencies are installed on the next update.

Finally, RHEL 6 and earlier did not have the two-word form of the yum group commands. In others, in RHEL 6 the command yumplist existed, but the equivalent RHEL 7 and RHEL 8 yum group list did not.
