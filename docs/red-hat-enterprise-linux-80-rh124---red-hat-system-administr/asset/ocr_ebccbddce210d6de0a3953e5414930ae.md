# ACCESSING THE COMMAND LINE USING THE DESKTOP

# OBJECTIVES

After completing this section, you should be able to log in to the Linux system using the GNOME desktop environment to run commands from a shell prompt in a terminal program.

# INTRODUCTION TO THE GNOME DESKTOP ENVIRONMENT

The desktop environment is the graphical user interface on a Linux system. The default desktop environment in Red Hat Enterprise Linux 8 is provided by GNOME 3. It provides an integrated desktop for users and a unified development platform on top of a graphical framework provided by either Wayland (by default) or the legacy X Window System.

GNOME Shell provides the core user interface functions for the GNOME environment. The GNOME Shell application is highly customizable. Red Hat Enterprise Linux 8 defaults GNOME's look and feel to the "Standard" theme, which is used in this section. Red Hat Enterprise Linux 7 defaults to an alternative theme named "Classic" that was closer to the look and feel of older versions of GNOME. Either theme can be selected persistently at login by clicking the gear icon next to the Sign in button that is available after selecting your account before entering your password.

The first time you log as a new user, an initial setup program runs to help configure account settings. Once that is complete, the GNOME Help application starts on the Getting Started with GNOME screen. This screen includes videos and documentation to orient new users to the GNOME 3 environment. You can quickly start GNOME Help by clicking the Activities button on the left side of the top bar, and in the dash that appears on the left side of the screen, clicking the life buoy icon to launch it.
