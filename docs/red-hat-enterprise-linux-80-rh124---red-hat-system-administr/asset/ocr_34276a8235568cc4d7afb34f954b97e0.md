> IMPORTANT packages use RPM weak dependencies in order to install supplementary packages only when the core package needs it also installed. For example, when installing langpacks-fr as shown in the preceding examples, the mythe package will only be installed if the mythe thesaurus is also installed on. If mythe is subsequently installed on that system, the mythe-fr package will also automatically be installed by the weak dependency from the already installed langpacks-fr package.
