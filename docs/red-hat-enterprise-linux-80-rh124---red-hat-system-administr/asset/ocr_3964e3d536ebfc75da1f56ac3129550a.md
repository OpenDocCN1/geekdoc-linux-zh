To extract the contents of a bzip2 compressed archive /root/logbackup.tar.bz2 in the /tmp/logbackup directory:

```
[root@#] mkdir /tmp/logbackup
[root@#] cd /tmp/logbackup
[root@logbackup] tar -tf /root/logbackup.tar.bz2
var/log/
var/log/lastlog
var/log/README
var/log/private/
var/log/wtmp
var/log/btmp
...output omitted.
[root@logbackup] tar -xjf /root/logbackup.tar.bz2
```

> NOTE
Additionally, gzip, bzip2, and xz can be used independently to compress single files. For example, the gzip etc tar command results in the etc.tar.gz compressed file, while the bzip2 abc.tar command results in the abc.tar.bz2 compressed file, and the xz myarchive.tar command results in the myarchive.tar.xz compressed.
The corresponding commands to decompress are gzip, bunzip2, and unxz. For example, the gzip /tmp/etc.tar.gz command results in the etc.tar uncompressed tar file, while the bunzip2 abc.tar.bz2 command results in the abc.tar uncompressed file, and the unxz myarchive.tar.xz command results in the myarchive.tar uncompressed tar file.
