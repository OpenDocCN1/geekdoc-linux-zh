# INTDUCING THE MAN COMMAND

One source of documentation that is generally available on system is manual pages which are shipped as part of software packages and can be accessed from the command line.

# Common Sections of the Manual

| SECTION | CONTENT |
|---|---|
| 1 | User commands (executable programs) |
| 2 | System calls (invoked from user space) |
| 3 | Library functions (provided by libraries) |
| 4 | Special files (such as devices) |
| 5 | File formats (configuration files) |
| 6 | Games (amusing programs) |
| 7 | Conventions, standards, and miscellaneous (protocols) |
| 8 | System administration (maintenance tasks) |
| 9 | Kernel API (internal calls) |

To distinguish identical topic names in different sections, page references include section number after the topic. For example, passwd(1) describes the command to change passwords, while passwd(5) explains the /etc/passwd file.

To read specific pages, use man topic. Contents are displayed one screen at a time. The man command searches sections in alphabetic order. For example, man passwd displays passwd(1) by default. To display a specific section, include the section number: man 5 passwd.

# NAVIGATE AND SEARCH MAN PAGES

The ability to search man pages. GUI tools make it easy to configure common system resources, but using the command line interface is still more efficient. To effectively navigate the command line, you must be able to find the information you need in man pages. The following table lists basic navigation commands when viewing man pages:

# Navigating Man Pages

| COMMAND | RESULT |
|---|---|
| Spacebar | Scroll forward (down) one screen |
| PageDown | Scroll forward (down) one screen |
| PageUp | Scroll backward (up) one screen |
| DownArrow | Scroll forward (down) one line |
| UpArrow | Scroll backward (up) one line |
| D | Scroll forward (down) one half-screen |
| U | Scroll backward (up) one half-screen |
| /string | Search forward (down) for *string* in the man page |
| N | Repeat previous search forward (down) in the man page |
| Shift+N | Repeat previous search backward (up) in the man page |
| G | Go to start of the man page |
| Shift+G | Go to end of the man page |
| Q | Exit **man** and return to the command shell prompt |

> **IMPORTANT**
When performing searches, *string* allows *regular expression* syntax. While simple text (such as *passwd*) works as expected, regular expressions use meta-characters (such as *S, *, and ^*) for sophisticated pattern matching. Therefore, searching with strings that include regular expression meta-characters, such as **make $$$$**, might yield unexpected results.
Regular expressions and syntax are discussed in *Red Hat System Administration II*, and in the *regex(7)* man topic.
