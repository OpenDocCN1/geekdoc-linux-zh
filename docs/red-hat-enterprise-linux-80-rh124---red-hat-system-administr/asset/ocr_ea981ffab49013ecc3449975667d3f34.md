Your projects are now done, and it is time to clean up the projects.

Change to the student's home directory. Attempt to delete both the **family** and **friends** project directories with a single **rmdir** command.

```
[student@servera]$ cd ~
[student@servera]$ rmdir family friends
rmdir: failed to remove 'family': Directory not empty
rmdir: failed to remove 'friends': Directory not empty
```

Using the **rm -r** command should fail because subdirectories contain files.
