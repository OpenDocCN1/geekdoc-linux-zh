# Input Method Settings

GNOME 3 in Red Hat Enterprise Linux 7 or later automatically uses the IB input method selection system, which makes it easy to change keyboard layouts and input methods quickly.

The Region & Language application can also be used to enable alternative input methods. The Region & Language application window, the Input Sources box show what input methods are currently available. By default, English (US) is the only available method. Highlight English (US) and click the keyboard icon to change the current keyboard.

To add another input method, click the + button at the bottom left of the Input Sources window. An Add Source window will appear. Select your language, and your preferred input method or keyboard layout.

When more than one method is configured, you can switch between them quickly by typing Super+Space (some call it Windows+Space). A status indicator will also appear in the GNOME top bar, which has two functions: It indicates which input method is active, and as a menu that can be used to switch between input methods or select advanced features of complex input methods.

Some of the methods are marked with gears, which indicate that those methods have advanced options and capabilities. For example, the Japanese (Kana Kanji) input method allows you to pre-edit text in Latin and use Down Arrow and Up Arrow keys to select the characters.

US speakers may also find this useful. For English (United States) the keyboard English (international AltGr dead keys), which treats AltGr (or the right Alt) on a PC 104/105-key keyboard as a "secondary shift" modifier key and dead activation key for adding additional characters. There are also Dvorak and other layouts available.

> NOTE
Any Unicode character can be entered in the GNOME desktop environment if you know your Unicode code point. Press Ctrl+Shift+U, followed by the code point. After typed, an underlined u will be displayed to indicate that the system is waiting for Unicode code point.
For example, the lowercase Greek letter lambda has the code point U+03BB, and can be entered by typing Ctrl+Shift+U, then 03BB, then Enter.

# SYSTEM-WIDE DEFAULT LANGUAGE SETTINGS

The system's default language is set to US English, using the UTF-8 encoding of Unicode as its character set (en_US.utf8), which can be changed during or after installation.

From the command line, the root user can change the system-wide locale settings with the localectl command. If localectl is run with no arguments, it displays the current system-wide locale settings.
