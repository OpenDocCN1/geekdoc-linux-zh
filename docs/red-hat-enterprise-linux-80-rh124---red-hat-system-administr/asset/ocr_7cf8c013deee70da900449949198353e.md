In the presentation, keyboard arrow keys are used for navigation. When vi was first developed, users could not rely on having arrow keys or working keyboard mappings for arrow keys to move the cursor. Therefore, vi was originally designed to move the cursor using commands standard character keys, as the conveniently proved H, J, K, and L.

Here is one to remember:
hang back, jump down, kick up, leap forward.
