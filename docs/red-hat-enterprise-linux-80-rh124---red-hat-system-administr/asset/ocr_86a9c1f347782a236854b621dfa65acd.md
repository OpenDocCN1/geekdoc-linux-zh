To register the system, click the Register button in the Sub window. This displays the following dialog:

![](bbox=[0.146, 0.406, 0.853, 0.638])

Figure 14.2: The service location and account information dialog of Red Hat Subscription Manager

This dialog box registers a system with a subscription server. By default, it registers the to Red Hat Customer Portal. Provide the Login and Password for the Red Hat Customer Portal account to which the system should be registered, and click the Register button.

When the system is registered and a subscription has been assigned, close the Subscriptions window. The system is now properly subscribed and ready to receive updates or install new software from Red Hat.
