```
[updates]
name=Red Hat Updates

```

2. On server, install new package xsane-gimp and the Apache HTTP Server module for the 2.4 stream and the common profile.

2.1. Use the yum command to list the available packages for xsane-gimp.

```
[root@server ~]# yum list xsane-gimp

Available Packages
xsane-gimp.x86_64      0.999-30.el8      rhel-8.0-for-x86_64-appstream-rpms
```
