# ADDING A NETWORK CONNECTION

The nmcli con add command is used to add new network connections. The following example nmcli con add assume that the name of the network connection being added is not already in use.

The following command adds a network connection named eno2 for the interface eno2, which gets IPv4 networking information via DHCP and autoconfig on startup. It also gets IPv6 networking settings by listening for router advertisements on the local link. The name of the configuration file is based on the value of the con-name option, eno2, and is saved to the /etc/sysconfig/network-scripts/ifcfg-eno2 file.

```
[root@]# nmcli con add con-name eno2 type ethernet eno2
```

The next example creates eno2 connection for the eno2 device with static IPv4 address, using the IPv4 address and network prefix 192.168.0/24 and default gateway 192.168.0.254, but still interconnects at startup and saves its configuration into the same file. Due to screen size limitations, the first line with a shell v escape and complete the command on the next line.

```
[root@]# nmcli con add con-name eno2 type ethernet ifname eno2 \\> ip4 192.168.0/24 gw 192.168.0.254
```

This final example creates eno2 connection for the eno2 device with static IPv6 and IPv4 addresses, using the IPv6 address and network prefix 2001:db8:0:1::c000:207/64 and the IPv4 address and network prefix 192.0.2/24 and default IPv4 gateway 192.0.2.1, but still interconnects at startup and saves its configuration into /etc/sysconfig/network-scripts/ifcfg-eno2. Due to screen size limitations, the first line with a shell v escape and complete the command on the next line.

```
[root@]# nmcli con add con-name eno2 type ethernet ifname eno2 \\> ip6 2001:db8:0:1::c000:207/64 gw 2001:db8:0:1::1 ip4 192.0.2/24 gw 192.0.2.24
```

# CONTROLLING NETWORK CONNECTIONS

The nmcli con up command activates the connection name on the network interface it is bound to. Note that the command takes a connection name, the name of the network interface. Remember that the nmcli con show displays the names of all available connections.

```
[root@]# nmcli con up static-ens3
```

The nmcli disconnect device command disconnects the network interface device and brings it down. This command can be abbreviated nmcli dev dis device:

```
[root@]# nmcli dev dis ens3
```
