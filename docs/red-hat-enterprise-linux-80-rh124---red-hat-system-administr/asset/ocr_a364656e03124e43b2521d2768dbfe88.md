time causes the shell to list all of the files that are matched by the current pattern. Type additional characters until the name is unique, use tab completion to complete the command.

```
[user@host ~] ls /etc/pasTab
[user@host ~] ls /etc/passwdTab
passwd passwd-
```

① Press Tab once.

Arguments and options can be matched with tab completion for many commands. The useradd command is used by the superuser, root, to create additional users on the system. It has many options that can be used to control how command behaves. Tab completion following a partial option can be used to complete the option without a lot of typing.

```
[root@host #] useradd --+Tab
--base-dir --groups --no-log-init --shell
--comment --help --non-unique --skel
--create-home --home-dir --no-user-group --system
--defaults --inactive --password --uid
--expired --key --root
--gid --no-create-home --selinux-user --user-group
[root@host #] useradd --
```

# CONTINING A LONG COMMAND ON ANOTHER LINE

Commands that support many options and arguments can quickly grow quite long and are automatically scrolled by the Bash shell. As soon as the command reaches the right margin of the window, the command continues on the next line. To make the readability of the command easier, you can break it up that it fits on more than one line.

To do this, add a backslash character (\ as the last character on the line. This tells the shell to ignore the newline character and treat the next line as if it were part of the current line. The Bash shell will start the next line with the continuation prompt, a greater-than character (>), which indicates that the line is a continuation of the previous one. You can do this more than once.

```
[user@host]$ head -n 3 \\
> /usr/share/dict/words \\
> /usr/share/dict/linux.words
==> /usr/share/dict/linux.words <=
1080
10-point
10th

==>/usr/share/dict/linux.words <=
1080
10-point
10th
```
