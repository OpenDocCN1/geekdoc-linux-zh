# GUIDED EXERCISE

# REVIEWING SYSLOG FILES

In this exercise, you will reconfigure syslog to write specific log messages to a new file.

# OUTCOMES

You should be able to configure the syslog service to write all log messages with the debug priority to /var/log/messages-debug log file.

# BEFORE YOU BEGIN

Log in to workstation as student using student as the password.

On workstation, run lab log-configure start to start the exercise. This script ensures that the environment is setup correctly.

```
[student@workstation -]$ lab log-configure start
```

+   1. From workstation, open an SSH session to servera as student.

```
[student@workstation -]$ ssh student@servera
...output omitted.
[student@servera ~$]
```

+   2. Configure syslog on servera to log all messages with the debug priority, or higher, for any service it into the new /var/log/messages-debug log file by adding the syslog configuration file /etc/syslog.d/debug.conf.

+   2.1. Use the sudo -i to switch to the root user. Specify student as the password for the student user if running the sudo -i command.

```
[student@servera ~ sudo -i
[sudo] password for student: student
[root@servera #]
```

+   2.2. Create the /etc/syslog.d/debug.conf file with the necessary entries to redirect all log messages having the debug priority to /var/log/messages-debug. You may use the vim /etc/syslog.d/debug.conf command to create the file with the following content.

```
.debug /var/log/messages-debug
```
