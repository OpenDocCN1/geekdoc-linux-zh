# MANAGING LINKS BETWEEN FILES

# Hard Links and Soft Links

It is possible to create multiple names that point to the same file. There are two ways to do this: by creating a hard link to the file, or by creating a soft link (sometimes called a symbolic link) to the file. Each has its advantages and disadvantages.

# Creating Hard Links

Every file starts with a single hard link, from its initial name to the data on the file system. When you create a new hard link to a file, you create another name that points to that same data. The new hard link acts exactly like the original file name. Once created, you cannot tell the difference between the new link and the original name of the file.

You can find out if a file has multiple links with the ls -1 command. One of the things reports is each file's link count, the number of hard links the file has.

```
[user@host ~]$ pwd
/home
[user@host ~]$ ls -1 newfile.txt
-rw-r--r-- 1 user user 12 Mar 11 19:19 newfile.txt
```

In the preceding example, the link count of newfile.txt is 1. It has exactly one absolute path, which is /home/user/newfile.txt.

You can use the ln command to create a new hard link (another name) that points to an existing file. The command needs at least two arguments, a path to the existing file, and a path to the link you to create.

The following example creates a hard link named newfile-link2.txt for the existing newfile.txt in the /tmp directory.

```
[user@host ~]$ ln newfile.txt /tmp/newfile-link2.txt
[user@host ~]$ ls -1 newfile.txt /tmp/newfile-link2.txt
-rw-r--r-- 2 user user 12 Mar 11 19:19 newfile.txt
-rw-r--r-- 2 user user 12 Mar 11 19:19 /tmp/newfile-link2.txt
```

If you want to find out whether two files are links of each other, one way is to use the ls -i option to list the files' inode number. If the files are on the same file system (discussed in a moment) and their inode numbers are the same, the files are hard links pointing to the same data.
