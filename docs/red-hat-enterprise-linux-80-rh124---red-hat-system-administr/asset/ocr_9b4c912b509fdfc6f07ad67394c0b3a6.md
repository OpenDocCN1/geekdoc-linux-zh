# CHAPTER 7 Controlling Services and Daemons

```
[student@servera ~]$ systemctl status chronyd
- chronyd.service NTP client/server
Loaded: loaded (/usr/lib/systemd/chronyd.service; enabled; vendor preset: enabled)
Active: inactive (dead since Thu 2019-02-07 01:20:34 EST; 44s ago
... output emitted...
- servera.lab.com chronyd[710]: System clock wrong by 1.349113 seconds, adjustment started
- servera.example.com system[1]: Stopping NTP client/server...
- servera.example.com system[1]: Stopped NTP client/server.
```

+   Determine if the chronyd service is enabled to start at system boot.

```
[student@servera ~]$ systemctl is-enabled chronyd
enabled
```

+   Reboot servera, view the status of the chronyd service.

```
[student@servera ~]$ sudo reboot
(sudo) password for student: student
Connection to server closed by remote host.
Connection to server closed.
[student@workstation ~]$
```

Log in as the student user and view the status of the chronyd service.

```
[student@workstation ~]$ ssh student@servera
[student@servera ~]$ systemctl status chronyd
- chronyd.service NTP client/server
Loaded: loaded (/usr/lib/systemd/chronyd.service; enabled; vendor preset: enabled)
Active: active (running) since Thu 2019-02-07 01:48:26 EST; 5min ago
... output omitted...
```

+   Disable the chronyd service so that it does not start at system boot, view the status of the service.

```
[student@servera ~]$ sudo systemctl disable chronyd
(sudo) password for student: student
Removed /etc/systemd/system/multi-user.target.wants/chronyd.service.
[student@servera ~]$ systemctl status chronyd
- chronyd.service NTP client/server
Loaded: loaded (/usr/lib/systemd/chronyd.service; disabled; vendor preset: enabled)
Active: active (running) since Thu 2019-02-07 01:48:26 EST; 5min ago
... output omitted...
```

+   Reboot servera, view the status of the chronyd service.

```
[student@servera ~]$ sudo reboot
```
