# GUIDED EXERCISE

# MONITORING PROCESS ACTIVITY

In this exercise, you will use the top command to dynamically examine running processes and control them.

# OUTCOMES
You should be able to manage processes in real time.

# BEFORE YOU BEGIN
Log in to workstation as student using student as the password.

On workstation, run the lab processes-monitor start command. The command runs a script that defines if the host, server, is reachable on the network.

```
$student@workstation ~]$ lab processes-monitor start
```

+   1. On workstation open two terminals side by side. These terminals are referred to as left and right. On each terminal, use the ssh command to log into server as the student user.

```
$student@workstation ~]$ ssh student@servera
Activate the web console with: systemctl enable --now cockpit.socket
```

```
Last login: Fri Feb 8 12:04:52 2019 from 172.25.250.254
$student@servera ~$
```

+   2. In the left terminal, create a new directory called /home/student/bin. In the new directory create a shell script called monitor. Ensure the script is executable.

+   2.1. Use the mkdir command to create a new directory /home/student/bin.

```
$student@servera ~]$ mkdir /home/student/bin
```

+   2.2. Use the vim command to create a script called monitor in the /home/student/bin directory. Press the I key to enter Vim interactive mode. Use the :wq command to save the file.

```
$student@servera ~]$ vim /home/student/bin/monitor
!/bin/bash
while true; do
var=1
while [[ var -lt 50000 ]]; do
var=$((var+1))
done
```
