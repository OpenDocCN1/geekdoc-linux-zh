For the next few examples, pretend that you have running the following commands to create some nample files.

```
[user@host~]$ mkdir cd glob
[user@host glob]$ touch alpha bravo charlie delta echo baker cat dog
[user@host glob]$ ls
able alfa bravo cast charlie delta dog easy echo
[user@host glob]
```

The first example will use simple patterns with the asterisk (*) and question mark (?) characters, a class of characters, to match those of file names.

```
[user@host glob]$ ls a*
alfa alfa
[user@host glob]$ ls 'a*'
alfa alfa bravo cast charlie delta easy
alfa alfa cast charlie
[user@host glob]$ ls ????
alfa alfa cast easy echo
[user@host glob]$ ls ????
baker bravo
[user@host glob]
```

# Tilde Expansion

The tilde character (~), matches the current user's home directory. If it starts a string of characters not a slash (/), the shell will interpret the string as absolute path to user name, if one matches, and replace the string with the absolute path to that user's home directory. If no user name matches, an actual tilde followed by the characters will be used instead.

In the following example the echo command is used to display the value of the tilde character. The echo command can also be used to display the values of brace and variable expansion characters, and others.

```
[user@host glob]$ ls ~root
/root
[user@host glob]$ ls ~user
/home/user
[user@host glob]$ ls ~glob
ablefa bravo baker cast charlie delta dog easy echo
[user@host glob]$ echo ~glob
/home/user/glob
[user@host glob]
```

# Brace Expansion

Brace expansion is used to generate discretionary strings of characters. Braces contain a comma-separated list of strings, or a sequence expression. The result includes the text preceding or following the brace definition. Braces may be nested, one inside another. Also double-syntax (...) expands to a sequence such that {m..p} will expand to tom m n p.
