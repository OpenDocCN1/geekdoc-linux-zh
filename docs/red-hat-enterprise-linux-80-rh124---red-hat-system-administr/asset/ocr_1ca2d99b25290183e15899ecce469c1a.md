# GUIDED EXERCISE

# GETTING HELP FROM RED HAT CUSTOMER PORTAL

In this exercise, you will generate a diagnostics report using Web Console.

# OUTCOMES

You should be able to generate a diagnostics report using Web Console which could be submitted to Red Hat Customer Portal as part of a support case.

# BEFORE YOU BEGIN

Log in as the student user on workstation student as the password. From workstation, run the lab support-portal start command. The command runs a start script that determines if servera is reachable on the network. It also starts and enables Web Console on sera.

```
[student]workstation ~]$ lab support-portal start
```

+   1. From workstation use the ssh to log into servera as the student user.

```

```
