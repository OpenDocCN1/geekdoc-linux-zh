# Managing Networking

Add the -6 to option the IPv6 routing table:

```
[user@]$ ip -6 route
unreachable: ::/64 dev eth0 metric 1024 error -101
unreachable: ::ffff::/96 dev eth0 metric 1024 error -101
2001:db8::/64 dev ens3 proto kernel metric 256
unreachable: 2002::/64 dev lo metric 1024 error -101
unreachable: 2002:ff0::/64 dev lo metric 1024 error -101
unreachable: a0f8::/32 dev lo metric 1024 error -101
unreachable: ac10::/32 dev lo metric 1024 error -101
unreachable: c0a8::/32 dev lo metric 1024 error -101
unreachable: e000::/19 dev lo metric 1024 error -101
unreachable: 3ffe::/32 dev lo metric 1024 error -101
fe80::/64 dev ens3 proto kernel metric 256
default via 2001:db8:0::1:ffff dev ens3 2001:db8:0::1:ffff proto static metric 1024
```

In this example, ignore the unroutable routes, which point at unused networks. That leaves

+   1. The 2001:db8:0::1::/64 network, using the ens3 interface (presumably has an address on that).
2. The fe80::/64 network, for the link-address. On a system with multiple interfaces, there is a route to fe80::/64 out each interface for each link-local address.
3. A default route to all networks on the IPv6 Internet (the ::/0) that do not have a more specific route on the system, the router at 2001:db8:0:1::ffff, reachable with the ens3.

# Tracing Routes Taken by Traffic

To trace the path that traffic takes to reach a host through multiple routers, use traceroute or tracepath. This can identify whether an issue is with one of your routers or an intermediate. Both commands use UDP packets by default; networks block UDP and ICMP traffic. The traceroute command has options to trace the path with UDP (default), ICMP (-I), or TCP (-T) packets. Typically, the traceroute command is not installed by default.

```
[user@]$ tracepath access.redhat.com
..output. omitted...
4: 71-32-148.145.rcnt.inet.quest 48.853ms as 5
5: dcp-brdr-041.inet.quest 100.732ms as 7
6: 206.111.0.153.ptr.us.no 96.245ms as 7
7: 207.078.14.162.ptr.us.no 85.270ms as 8
8: aeid0.c1.atlanta6-ga.us.xo.no 64.160ms as 7
9: 216.156.108.98.ptr.us.no 108.265ms as 12
10: bu-eth13.atlangam46w-br0.tbbone.com 107.286ms as 12
..output. omitted...
```

Each line in the output of tracepath represents a route or hop that the packet passes between the source and the final destination. Additional information is provided as available, including the round trip time (RTT) and any changes in the maximum transmission unit (MTU).
