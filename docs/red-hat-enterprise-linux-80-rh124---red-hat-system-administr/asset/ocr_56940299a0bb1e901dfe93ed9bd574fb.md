# CHANGING THE SYSTEM HOST NAME

The hostname command displays or temporarily modifies the system's fully qualified host name.

```
[root@~]# hostname
host@example.com
```

A static host name may be specified in the /etc/hostname file. The hostnamectl command is used to modify this file and view the status of the system's fully qualified host name. If this file does not exist, the host name is set by a reverse DNS query once the interface has an IP address assigned.

```
[root@~]# hostnamectl set-hostname host@example.com
[root@~]# hostnamectl status
Static hostname: host@example.com
Icon name: computer-vm
Chassis: vm
Machine: 73ab164e27e64e8b9fe7b80711aacd5

CPE OS Name: cpe:/o:redhat:enterprise_linux:8.0:beta
Kernel: 4.18.0-60.el8.x86_64
Architecture: x86_64
```

```
[root@~]# cat /etc/hostname
host@example.com
```
