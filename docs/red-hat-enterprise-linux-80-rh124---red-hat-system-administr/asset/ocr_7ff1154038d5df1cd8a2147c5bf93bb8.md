# IMPORTANT

Use nmcli dev device command is normally not the best way to deactivate a network interface.

The nmcli con down name command brings down the connection. However, by default, most wired system connections are configured with autoconnect enabled. This activates the connection as soon as the network interface is available. Since the connection's network interface is still available, nmcli con down name brings the interface down, but NetworkManager immediately brings it up again unless the connection is entirely disconnected from the interface.

# MODIFY NETWORK CONNECTION SETTINGS

NetworkManager connections have two kinds of settings. There are static connection properties, configured by the administrator and stored in the configuration files in /etc/sysconfig/network-scripts/ifcfg-* may also be active connection data, which the connection gets from DHCP server and are not stored presently.

To list the current settings for a connection, run the nmcli con show name command, where name is the name of the connection. Settings lowercase are static properties that the administrator can change. Settings in active connections are stored in temporary use for this instance of the connection.
