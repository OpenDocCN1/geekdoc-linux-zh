# SENDING SYSLOG MESSAGES MANUALLY

The logger command send messages to the rsyslog service. By default, it sends the message to the user facility with the notice priority (user.notice) unless specified otherwise with the -p option. It is useful to test any change to the rsyslog service configuration.

To send a message to the rsyslog service that gets recorded in the /var/log/boot.log log file, execute the following logger command:

```
[root]# logger -p local7.notice "Log entry created on host"
```
