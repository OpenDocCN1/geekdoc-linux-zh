## 奇幻故事中所用代码说明

在我们第3章受《爱丽丝仙游奇境》启发的故事中，我们深入了命令行历史与编辑的世界。在故事中，爱丽丝在 GNU Readline 库创建者特殊的 Chet Ramey 的帮助下，学习了导航和操纵 Bash 命令的迷方法。

以下是 Chet 向爱丽丝介绍的代码简回顾：

- `history`：这是一个 Bash 命令，允许你查看之前执行过的命令的历史列表。在终端中输入 `history` 将显示命令列表及其行号。
- `!!`：此快捷键执行历史列表中的紧接上一个命令。例如，输入 `!!` 将执行当前命令正上方一行的命令。
- `!n`：此快捷键执行历史列表中行号为 n 的命令。例如，输入 `!3` 将执行历史中第 3 行的命令。
- `^`：此快捷键允许你替换历史列表中的部分命令。例如，输入 `^old^new` 将把最近一次命令中第一次出现的 `old` 替换为 `new`。
- `!$`：此快捷键引用上一个命令的最后一个参数。例如，如果上一个命令是 `ls /home/alice/Desktop`，输入 `rm !$` 将删除列为最后一个参数的文件或目录（在这种情况下为 `/home/alice/Desktop`）。

这些快捷键只是 Bash 中提供的许多工具中的几个，可以帮助你导航和编辑命令行历史。通过精通这些技巧，你将能够更高效工作并成为真正的 Bash 高级用户！

条件语句根据特定条件的真假来执行某个操作的语句。高级 Bash 提供了几种不同的条件语句，可以用于控制脚本的流，并根据用户输入、系统输出或其他因素做出决策。

## If 语句

常用的条件语句之一是 `if` 语句。它允许你仅在满足特定条件时执行代码块。

```bash
if [ condition ]; then
  # 如果条件为真则执行代码
fi
```

在 bash 中，我们使用方括号 `[]` 进行测试。例如：

```bash
if [ $x -gt 10 ]; then
  echo "x is greater than 10"
fi
```

如果条件为假，你可以使用 `else` 语句来执行另一个代码块：

```bash
if [ $x -gt 10 ]; then
  echo "x is greater than 10"
else
  echo "x is not greater than 10"
fi
```

当你有多个条件需要检查时，可以使用 `elif`：

```bash
if [ $x -gt 10 ]; then
  echo "x is greater than 10"
elif [ $x -eq 5 ]; then
  echo "x is equal to 5"
else
  echo "x is neither greater than 10 nor 5"
fi
```

## Else 语句

当 `if` 条件为假时使用 `else` 语句。它提供了一个备选的代码块供执行。

```bash
if [ $name == "Alice" ]; then
  echo "Welcome, Alice!"
else
  echo "Welcome, guest!"
fi
```

## Else-If 语句

`elif` 语句是 "else if" 的缩写。它允许你顺序检查多个条件。

```bash
if [ $age -lt 18 ]; then
  echo "You are a minor."
elif [ $age -lt 65 ]; then
  echo "You are an adult."
else
  echo "You are a senior."
fi
```

## Case 语句

`case` 语句是多个 `if-elif` 语句更具可读性的替代方案。它对多个模式进行评估。

```bash
case $fruit in
  apple)
    echo "This is an apple."
    ;;
  banana)
    echo "This is a banana."
    ;;
  *)
    echo "I don't know what fruit this is."
    ;;
esac
```

`*` 是匹配任何值的通配符，`;;` 用于结束每个 case。

# 爱丽丝文件管理与权限背后的代码

在《爱丽丝梦游仙境》的奇幻故事中，爱丽丝遇到了一个无法读取的文件。为了帮助她穿过文件世界，她被介绍了一些基础 Bash 命令和文件管理概念。在本节中，我们将深入用于解决爱丽丝文件管理困扰的代码。

爱丽丝接触到的第一个命令是 `touch`。`touch` 命令用于创建新文件或更新现有文件的时间戳。例如，要创建一个名为“my_file.txt”的新文件，爱丽丝可以使用以下命令：

```
touch my_file.txt
```

如果爱丽丝想删除一个文件，她可以使用 `rm` 命令。`rm` 命令用于删除文件或目录。要删除一个名为“my_file.txt”的文件，爱丽丝可以使用以下命令：


如果爱丽丝想重命名、复制或移动一个文件，她可以使用 `mv` 命令。`mv` 命令用于移动或重命名文件和目录。例如，要将名为“my_file.txt”的文件移动到名为“my_folder”的目录，爱丽丝可以使用以下命令：


文件管理中最重要的命令是 `chmod`。`chmod` 命令用于更改文件或目录的权限。Linux 中的每个文件或目录都有三组权限——一组属于所有者，一组属于组，一组属于其他用户。这些权限可以是读 (r)、写 (w) 或执行 (x)。

要给文件所有者读、写、执行权限，爱丽丝可以使用以下命令：

```bash
chmod 700 my_file.txt
```

这里，7 代表所有者的读 (4) 加写 (2) 加执行 (1) 权限。`-` 表示组和其他用户没有权限。同样，要给所有者和组读和执行权限，而其他人没有权限，爱丽丝可以使用以下命令：

```bash
chmod 750 my_file.txt
```

这里，5 代表组的读 (4) 加执行 (1) 权限。如果爱丽丝想将文件的所有者更改为用户“alice”，组更改为“users”，可以使用 `chown` 和 `chgrp` 命令。例如：

```
chown alice my_file.txt
chgrp users my_file.txt
```

通过这些命令，爱丽丝现在可以轻松地创建、删除和管理文件及目录了。通过文件权限的艺术，她可以保护自己的文件免受陌生人的侵害，并确保它们的价值。

```bash
#!/bin/bash
if [ $# -ne 1 ]; then
    echo "Usage: $0 <file>"
    exit 1

file=$1
```

脚本开头的 `#!/bin/bash` 告诉系统解释该脚本。脚本会检查是否接收了一个单个参数（要计数的的文件名），然后检查该文件是否存在。接着，它使用 `wc` 命令统计文件的行数，并使用 `awk` 仅打印行数。最后，它输出一条包含文件名和行数的消息。

```bash
#!/bin/bash
TMP_FILE="/tmp/cache.tmp"

if [ ! -f "$TMP_FILE" ]; then
    echo "Cache miss"
    # 计算结果
    RESULT=$(some_command)
    # 存储结果
    echo "$RESULT" > "$TMP_FILE"
else
    echo "Cache hit"
    # 从缓存中加载结果
    RESULT=$(cat "$TMP_FILE")
fi
```

该脚本展示了如何使用临时文件缓存结果。如果文件不存在，我们计算结果并将其存储在文件中。如果文件存在，我们从文件中加载结果。

```bash
#!/bin/bash
LIST_OF_FILES=$(find . -name "*.txt") | xargs -P 8 -I{} gzip - {}
```

该脚本展示了如何使用 `xargs` 命令并行任务。在这种情况下，我们使用 `find` 生成文件列表，并使用 `xargs` 并行压缩它们。

```bash
#!/bin/bash
NUM1=50
NUM2=25
echo $((NUM1 + NUM2))
```

该脚本展示了如何使用算术扩展进行简单的算术。在这种情况下，我们使用 `(( ))` 语法将两个变量相加。
