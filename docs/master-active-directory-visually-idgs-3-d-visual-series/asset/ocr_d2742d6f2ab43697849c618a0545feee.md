# # AUDITING SYSTEM EVENTS

A s with process tracking, you can audit system events that occur on the user's computer both from a success or failure perspective. Typically, you would choose to audit system events based on failure. This enables you to see possible user tampering and configuration changes.

![](bbox=[0.03, 0.51, 0.96, 0.81])

+   1.  Expand the Security Settings container, expand the Local Policies container, then select Audit Policy.
+   2.  Double-click the Audit System Events policy setting.
+   3.  The Audit System Events window appears.
+   4.  Select either the Success or Failure check box, or both.
+   5.  Click OK.
