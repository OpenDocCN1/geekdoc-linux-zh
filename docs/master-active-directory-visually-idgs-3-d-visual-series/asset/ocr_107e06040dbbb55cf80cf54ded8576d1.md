# # HOW REPLICATION WORKS IN THE ACTIVE DIRECTORY

# ## Solving replication collisions

Because Active Directory replication occurs through multimaster replication, replication conflicts can occur. One of the Active Directory’s internal tasks is to solve replication conflicts. A conflict occurs when the same attribute is changed at the same time on two different domain controllers. The Active Directory avoids collisions by using *attribute replication* rather than *object replication*. For example, when you change a user account’s password, only the password attribute is replicated instead of the entire user object. If another administrator on another domain controller is changing the user object’s group membership at the same time, a conflict does not occur because each administrator is changing a different attribute.
