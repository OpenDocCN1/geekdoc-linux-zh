# # CONFIGURING GENERAL POLICY PROPERTIES

You can configure general properties for the overall Group Policy by accessing the policy’s properties pages.

In the Properties dialog box, you are given General, Links, and Security tabs. The General tab gives you information about the policy, but you can use the Disable Computer

Configuration settings and Disable User Configuration settings check boxes if desired. This action disables either the user or computer portion from the policy and would be used if you wanted to apply only computer settings. Doing this helps system performance because the unused configuration does not have to be parsed each time a user logs on.

On the Links tab, you can run a global catalog search for other sites, domains, and OUs that use this policy. The Security tab enables you to configure what users and groups have access to the policy settings and what rights they have.
