# CHOOSING THE MAXIMUM SECURITY LOG SIZE

The Event Log container of Security settings allows you to configure how the Event Log functions for client computers to whom the policy applies. Your second option is the maximum Security Log Size. Event Logs are useful, but can use up a lot of hard disk space. You can use this policy to set the maximum size of the Security Log. The default setting is 512 kilobytes.
