# **What is a definition of each backup type?**

+   * Normal backs up all selected files and marks each file as backed up.
+   * Copy backs up all selected files but does not mark them as backed up.
+   * Incremental backs up selected files only if they have not been backed up or have changed, and marks them as backed up.

+   * Differential backs up selected files only if they have not been backed up or have changes, but does not mark them as backed up.
+   * Daily backs up only files that have changed today, but does not mark them as backed up.
