# **CREATING A NEW SITE**

You create new sites by using the Active Directory Sites and Services snap-in. A site is a physical grouping of computers, normally contained within a geographic location and network subnet. A site can contain a domain or multiple domains.

When you install the Active Directory, a first site is installed by default. You can then add new sites as needed for your environment.

Each site that you create within the console should naturally reflect a physical segment of your network

that has been set up to be a site. Keep in mind that each site is then connected with other sites through some kind of WAN link. You use the Sites and Services snap-in to create these sites, then you will create links between them for replication purposes.
