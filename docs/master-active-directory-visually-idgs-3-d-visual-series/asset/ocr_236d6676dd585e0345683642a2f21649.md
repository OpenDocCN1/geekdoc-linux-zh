# CREATING UPN SUFFIXES

Every user account is given a User Principal Name (UPN). The UPN is made up of a prefix and a suffix. The prefix is the user's logon name, such as jwilliams. The prefix is the domain name, such as corp.com. The prefix and suffix are combined with the @ symbol to create the UPN, such as jwilliams@corp.com. The UPN functions as both a username in a Windows 2000 network and an e-mail address.

Typically, the UPN suffix is the domain name; however, you can assign additional UPN suffixes to provide additional security and to simplify the logon process in a Windows 2000 domain tree or forest.

You use the Active Directory Domains and Trusts to assign additional UPN suffixes for the domain. For example, in a domain tree that has several subdomains, a user's logon name could be

jwilliams@production.tx.america.corp.com. You can simplify this by assigning an alternative UPN for this particular domain. For example, you could substitute the long domain name (production.tx.america.corp.com) with prodtx. Now, the user can logon with the optional suffix as jwilliams@prodtx.com. This option can be particularly effective in large enterprise environments.
