
## 附录 A

### 强制实施密码复杂度要求

与密码最小长度一样，要求密码满足复杂度要求是另一项良好的安全措施。此策略要求用户创建的密码必须包含数字、字母或键盘符号的混合组合。例如，在此策略下，用户的密码不能是“sweetbaby”，而必须使密码更复杂，例如“sweetbaby847”。使用字母、数字或符号组合的复杂密码对于未经授权的攻击者来说更难破解。

![](img/763d5ae436311371600c0952a3da9094_529_0.png)

1. 展开“账户策略”容器，并在左侧窗格中选择“密码策略”。
   - 策略设置将显示在详细信息窗格中。
2. 双击“密码必须满足复杂度要求”策略设置。
3. 显示“密码必须满足复杂度要求”窗口。
   - 单击复选框以启用或禁用该策略设置。
4. 使用单选按钮来启用或禁用该策略。
5. 单击“确定”。

### 在域中为所有用户存储使用可逆加密的密码

关于用户密码，你可以实施的另一项额外安全功能是可逆加密。密码在传输过程中是否加密取决于域中的其他安全设置。此功能允许你使用可逆加密，其基本原理是以反向方式打乱加密数据，以提供更优越的加密性能。此设置确保在密码传输过程中从网络窃取的密码无法被读取。

![](img/763d5ae436311371600c0952a3da9094_530_0.png)

1. 展开“账户策略”容器，并在左侧窗格中选择**密码策略**。
   - 策略设置将显示在详细信息窗格中。
2. 双击**在域中为所有用户存储使用可逆加密的密码**策略设置。
3. 显示**在域中为所有用户存储使用可逆加密的密码**窗口。
   - 单击复选框以启用或禁用该策略设置。
4. 使用单选按钮来启用或禁用该策略。
5. 单击**确定**。

### 强制实施账户锁定持续时间

账户锁定是一项安全功能，如果用户进行了指定次数的登录失败尝试，它将锁定该用户的账户。默认值为三次失败尝试。此锁定策略允许你定义账户被锁定的时间（以分钟为单位）。例如，你可以将账户配置为锁定 30 分钟。如果有人试图入侵该账户，这将在一段时间内提供锁定，希望攻击者会放弃。如果你没有输入分钟数，则账户将保持锁定状态，直到管理员将其解锁。

![](img/763d5ae436311371600c0952a3da9094_531_0.png)

![](img/763d5ae436311371600c0952a3da9094_531_1.png)

1. 展开“账户策略”容器，并选择“账户锁定策略”。
   - 策略设置将显示在详细信息窗格中。
2. 双击“账户锁定持续时间”策略设置。
3. 显示“账户锁定持续时间”窗口。
   - 单击复选框以启用或禁用该策略设置。
4. 使用滚动框调整分钟数。如果你未在框中输入任何分钟数，账户将保持锁定状态，直到管理员将其解锁。
5. 单击“确定”。

### 强制实施账户锁定阈值

如果你决定使用账户锁定，则需要设置一个阈值，该阈值决定用户在账户被锁定之前可以多少次尝试登录。一个好的值是 3，这给用户三次机会输入正确的用户名，之后账户才会锁定。此设置允许用户在一次或两次尝试中拼写错误，但在第三次未成功的尝试后锁定。这样，如果未经授权的人员试图入侵该账户，他们只能尝试三次，然后账户就会被锁定。

此外，如果你指定 0 次尝试，账户将不会锁定。

![](img/763d5ae436311371600c0952a3da9094_532_0.png)

![](img/763d5ae436311371600c0952a3da9094_532_1.png)

1. 展开“账户策略”容器，并选择“账户锁定策略”。
   - 策略设置将显示在详细信息窗格中。
2. 双击“账户锁定阈值”策略设置。
3. 显示“账户锁定阈值”窗口。
   - 单击复选框以启用或禁用该策略设置。
4. 使用滚动框调整用户在账户锁定之前可以尝试登录的次数。
   - 如果值设置为 0，账户将不会锁定。
5. 单击“确定”。

![](img/763d5ae436311371600c0952a3da9094_533_0.png)

![](img/763d5ae436311371600c0952a3da9094_533_1.png)

2. 双击“账户锁定计数器”策略设置。
3. 显示“账户锁定计数器”窗口。
   - 单击复选框以启用或禁用该策略设置。
4. 使用滚动框调整计数器重置前经过的分钟数。
5. 单击“确定”。

### 强制实施用户登录限制

Kerberos 是 Windows 2000 中的主要安全协议。通过使用“用户登录限制”策略，你可以确定是否启用用户登录限制。你将此策略与 Kerberos 策略容器中的其他策略配合使用。如果你想启用用户登录限制，请单击“启用”单选按钮，然后使用此容器中的其他策略来配置所需的选项。

![](img/763d5ae436311371600c0952a3da9094_534_0.png)

![](img/763d5ae436311371600c0952a3da9094_534_1.png)

1. 展开“账户策略”容器，并选择“Kerberos 策略”。
   - 策略设置将显示在详细信息窗格中。
2. 双击“强制实施用户登录限制”策略设置。
   - 显示“强制实施用户登录限制”窗口。
3. 单击复选框以启用或禁用该策略设置。
4. 单击“启用”或“禁用”单选按钮。
5. 单击“确定”。

### 强制实施服务票据的最大生存期

Kerberos 认证通过使用服务票据来工作。通过启用此策略，你可以为用户账户的服务票据设置最大生存期限。此功能要求系统定期生成新的服务票据，从而为你的网络登录过程提供额外的安全措施。

![](img/763d5ae436311371600c0952a3da9094_535_0.png)

1. 展开“账户策略”容器，并选择“Kerberos 策略”。
   - 策略设置将显示在详细信息窗格中。
2. 双击“服务票据最大生存期”策略设置。

![](img/763d5ae436311371600c0952a3da9094_535_1.png)

3. 显示“服务票据最大生存期”窗口。
   - 单击复选框以启用或禁用该策略设置。
4. 使用滚动框确定票据过期的分钟数。
5. 单击“确定”。

### 强制实施用户票据的最大生存期

正如服务票据用于登录服务一样，用户也拥有一个用于 Kerberos 安全的登录票据。你可以基于小时设置用户票据的最大期限。默认情况下，用户的票据在十小时后过期，但你可以减少此数值以获得额外的安全性。然而，默认设置通常是你实现有效 Kerberos 安全所需的全部。

![](img/763d5ae436311371600c0952a3da9094_536_0.png)

1. 展开“账户策略”容器，并选择“Kerberos 策略”。
   - 策略设置将显示在详细信息窗格中。
2. 双击“用户票据最大生存期”策略设置。
   - 显示“用户票据最大生存期”窗口。
3. 单击复选框以启用或禁用该策略设置。
4. 使用滚动框确定票据过期的小时数。
5. 单击“确定”。
