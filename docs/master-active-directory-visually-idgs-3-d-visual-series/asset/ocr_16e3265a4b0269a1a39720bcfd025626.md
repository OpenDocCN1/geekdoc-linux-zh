# Why would I need to connect to another domain controller?

Depending on the role your domain controllers play within the domain, you may need to connect to a different domain controller for administrative purposes. For example, if one of your domain controllers is designated as a bridgehead server, you can use the connect to domain controller feature to administer replication and connectivity for the bridgehead server from this interface.
