# What is the default setting for the security templates?

By default, the security template settings are not configured, which means that the value is not written to the registry. You should leave the setting as “not configured” for policy settings that you do not want to use to lower the overhead of your Group Policy. Enabled policies and disabled policies are written to the registry on client computers.
