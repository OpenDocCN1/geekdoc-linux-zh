# AUDITING OBJECT ACCESS

Object access means the Active Directory objects that users access, such as folders, shares, printer, and so forth. You can choose to audit the

success or failure of object access for client computers. This information can help you see trends with access problems or help you discover when a

particular client computer has a high failure rate, or when some unauthorized user may be trying to gain access to the Active Directory.

![](bbox=[0.02, 0.47, 0.48, 0.78])

![](bbox=[0.5, 0.47, 0.95, 0.78])

+   1.  Expand the Security Settings container, expand the Local Policies container, then select Audit Policy.
+   2.  The policy settings appear in the details pane.
+   3.  Double-click the Audit Object Access policy setting.

+   4.  The Audit Object Access window appears.
+   5.  Click the check box to either enable or disable the policy setting.
+   6.  Select either the Success or Failure check box, or both.
+   7.  Click OK.
