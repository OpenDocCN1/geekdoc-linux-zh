# Where can I find information about queries received by the WINS server?

The server statistics give you information about the queries that are sent to the WINS server. From the statistics file, you can see the total number of queries, the records that were found, and the records that were not found. If you want to gain statistical information for a specific time period, you can reset the statistics record and view the statistics again after a period of time has passed.

# I need to know when a particular WINS server started. How can I find this information?

You can learn the start time of the WINS server by clicking the WINS server in the console and then choosing ActionDisplay Server Statistics. At the top of the list, you see an entry called Server start time. In the details column, the start time is displayed by date and time.
