# ## RESTRICTING GUEST ACCESS TO SYSTEM LOG

By using the Event Viewer, users can view system logs as well as application and security logs. You can ensure, however, as a security precaution, that users that log on with a guest account cannot access the application, security, or system logs of computers within this Group Policy.
