# Why would you use this interface to connect to a URL?

One of the goals of Windows 2000 server is to provide seamless integration with the local network and the Internet. You can define a network place on the Internet or an intranet just as easily as on a local network computer by creating a network place. After you establish the network place, you can use the network place as though it resides on your local computer. If you use modem dial-up access, however, you need a dial-up connection each time you access the network place.

# Why is the FTP Site option available?

In environments where Web servers reside, network clients may be assigned a folder on an FTP server where they can store documents. You can use the Add Network Place Wizard to establish a network connection to an FTP site. Once you establish the network place, the connection is reestablished each time you log on to the network. This allows you to use the FTP connection as though the folder resides on your local hard drive.
