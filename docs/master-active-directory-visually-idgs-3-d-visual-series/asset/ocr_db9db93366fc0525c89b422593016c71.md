What advanced security features can I set?

The advanced security features allow you to employ a number of advanced authentication methods for a greater level of security. First, you can click the Use Extensible Authentication Protocol (EAP) radio button, which allows you to use a smart card or a digital certificate to logon. Next, you can click the allow these protocols radio button, which allows you to use PAP, SPAP, CHAP, MS-CHAP, or MS-CHAP V2
