# **Tips**

# **Can I create a new Group Policy from this location?**

Yes. If you want to create a new Group Policy from the Group Policy properties sheet, simply click **New** and a new policy object appears in the window. You can enter a name for the policy, select it, and then click **Edit** to begin configuring the policy for that site, domain, or OU. The configuration options are the same as when you use the manual snap-in.
