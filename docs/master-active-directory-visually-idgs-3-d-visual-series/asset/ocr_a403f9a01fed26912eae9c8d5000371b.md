# AUDITING DIRECTORY SERVICE ACCESS

The auditing of Directory Service access allows you to see a computer's success or failure when attempting to access the Active Directory. This information can help you determine if directory service access problems exist for particular computers.

![](bbox=[0.02, 0.49, 0.95, 0.8])

+   1.  Expand the Security Settings container, expand the Local Policies container, then select Audit Policy.
+   2.  Double-click the Audit Directory Service Access policy setting.
+   3.  The Directory Service Access window appears. Click the check box to either enable or disable the policy setting.
+   4.  Select either the Success or Failure check box, or both.
+   5.  Click OK.

The policy settings appear in the details pane.
