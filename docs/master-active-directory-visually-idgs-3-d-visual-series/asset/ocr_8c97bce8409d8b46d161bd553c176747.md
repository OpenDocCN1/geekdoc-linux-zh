# CREATING A CUSTOM SEARCH

The Active Directory allows you to create a custom search. To perform a custom search, you select Custom Search from the Find menu, which provides you with a Custom Search tab and an Advanced tab.

The Custom Search tab allows you to set specific criteria for the search. This feature is useful when you do not know the specific name or information about an object, but you know some information that you can use for the search. The fields available in the Custom Search basically give you every Active Directory object you may want to find and detailed fields about each.

On the Advanced tab, you can run an LDAP query where you simply type the search string. This can be any combination of words and the Active Directory will look for a match using your query.
