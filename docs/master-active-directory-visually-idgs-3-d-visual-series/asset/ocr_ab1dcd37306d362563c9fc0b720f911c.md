# Tips

# How is a description helpful?

In large environments that have many OUs and containers, the description, which you can type in on the General properties tab, is helpful to keep track of containers and OUs. You can use the description to help point to the contents of the OU and better organize data.

# What is a fully qualified name?

The fully qualified name is used with DNS naming schemes. The fully qualified name shows the complete DNS path to the object, starting at the root, such as corp.com.

# What is a USN?

You can see on the Object tab the original and current USN numbers. USN (Update Sequence Numbers) are numbers that the Active Directory uses to track changes to particular objects. The USNs are used by sites to make certain that replication has taken place and is current.
