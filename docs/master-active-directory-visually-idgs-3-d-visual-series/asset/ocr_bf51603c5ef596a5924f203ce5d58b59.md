# Tips

# Why should I use MX records?

MX records help you identify particular mail servers within the zone in the DNS database. This feature allows DNS to prioritize the mail servers for use within the zone. MX records are particularly useful in environments that use a number of mail servers within different DNS zones. By creating the MX records, your DNS server can easily keep track of the location of the mail servers.

# What happens when I add a new domain?

By selecting a particular zone in the console and using the Action menu, you can add a new domain to a zone. Remember that zones and domains are not related in terms of organization. A business may have four domains but only two zones. You can choose to add a domain to a zone so that domain becomes a part of the DNS zone and is serviced by DNS servers within the zone.
