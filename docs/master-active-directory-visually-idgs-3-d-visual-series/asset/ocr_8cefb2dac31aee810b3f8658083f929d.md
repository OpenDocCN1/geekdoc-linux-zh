# CREATING SCOPES CONTINUED

A long with the default gateway for the subnet, the DHCP server can also send IP address information for DNS and WINS servers. DNS resolves fully qualified domain names for the network while WINS resolves NetBIOS names. As with other IP address information, you can enter the DNS and WINS server addresses

in the clients' TCP/IP Properties dialog boxes, but allowing the DHCP server to provide this information to the client is much easier.

After you complete the wizard, you are asked if you would like to activate the scope. You must activate the scope before it can be used and before IP addresses can be leased to

network clients. You can choose not to activate the scope, but you must remember that a scope has to be activated before it can be used to lease IP addresses. If you want to further configure DHCP or other server components, you may choose not to activate the scope until you are finished with configuration.
