# What happens if I decide to install networking components from this interface?

You can install any components through the Configure Your Server interface by clicking the subject in the left pane and then clicking the service you want to install. This action begins the installation wizard for that particular component.

# What options are available in Configure Your Server?

The Configure Your Server tool contains expandable categories, such as Active Directory, File Server, Print Server, Networking, and so forth. Under each category, various components and services appear. For example, under the Networking category, DHCP, DNS, Remote Access, and Routing appear.

# Is there another way to install networking components in Windows 2000 Server?

Yes. You also use Add/Remove Programs in Control Panel to configure Windows components. See the next page for more information.
