# Does the Active Directory upload and store the shared folder and documents in the folder on a domain controller?

No. The Active Directory simply stores information about the shared folder so that users can locate it. When a user finds the shared folder in the Active Directory and wants to access it, the request is redirected to the computer that physically houses the shared folder. Active Directory uses the LDAP functionality to locate the shared folders on the network. At that computer, permissions are checked and access is either granted or denied.

# Is the network path to the shared folder revealed to Active Directory users?

No. The users are not aware of the shared folder's physical location on the network. This is by design so that users do not have to remember which servers or computers hold which resources. They simply access the shared folder in the Active Directory, and the redirection process to the computer that physically houses the shared folder is invisible to user.
