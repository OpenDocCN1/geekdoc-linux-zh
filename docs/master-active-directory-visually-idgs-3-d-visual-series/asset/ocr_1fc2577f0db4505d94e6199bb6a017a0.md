# # ENFORCING PASSWORD COMPLEXITY REQUIREMENTS

As with password minimum lengths, another good security measure is to require that passwords meet complexity requirements. This policy requires users to create

passwords that contain a mixture of numbers, letters, or keyboard symbols. For example, under this policy, a user could not have a password of “sweetbaby,” but would be required to make the

password more complex, such as “sweetbaby847.” Complex passwords that use a combination of letters, numbers, or symbols are much more difficult for unauthorized users to break.

![](bbox=[0.04, 0.49, 0.95, 0.92])

+   1. Expand the Account Policies container and select Password Policy in the left pane.
+      - The policy settings appear in the details pane.

+   2. Double-click the Passwords Must Meet Complexity Requirements policy setting.

+   3. The Passwords Must Meet Complexity Requirements window appears.
+      - Click the check box to either enable or disable the policy setting.

+   4. Use the radio buttons to either enable or disable the policy.
+      5. Click OK.
