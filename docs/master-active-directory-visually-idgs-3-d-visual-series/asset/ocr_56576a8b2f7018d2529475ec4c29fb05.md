# # EXAMINING BASIC RAS OPTIONS

As with other networking components in Windows 2000 Server, you have the option to manage your RAS server from within the RAS console, but you can also add other RAS servers (and routing servers) to the console for management. This feature makes it easy for you, as the administrator, to manage all your RAS servers from one central location. Instead of having to physically visit each machine, you can load each server into one console and manage them all from one location.

You can also adjust the Refresh rate for all RAS servers loaded into the console. By default, RAS servers are refreshed every 60 seconds, but you can change this value as needed. After you make a change, this value affects all RAS servers in your RAS console. Typically, the 60-second interval is enough and you should not need to change this setting, unless you have specific reasons for lowering the refresh rate.

+   3. Click OK.
