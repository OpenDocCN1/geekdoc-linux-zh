# Should I delegate control to several groups or users?

This is normally not a good idea. Only a select few should have delegation control so that only those few can make administrative changes to the delegated folder.

# When I delegate control, do I have to give the delegatee full control over the OU?

No. Delegation is a powerful tool in Windows 2000 because you can give other users or groups administrative permissions, but you do not have to “turn over” all the rights and permissions. As a network administrator, you can delegate some permissions while denying others. For example, you could allow a delegate to create user accounts, but not reset passwords. By using the delegation wizard, you can finely control what your delegates can do.
