# Do I need a reverse lookup zone?

A reverse lookup zone simply allows a standard DNS resolution query to function in "reverse." Normally, a DNS name is sent to the DNS server for resolution to the IP address. The reverse lookup zone allows an IP address to be sent to DNS server to discover the DNS name of the host. Depending on your network, reverse lookup zones are not always necessary; however, they are easy to configure and for full DNS functionality, having them available is a good idea.
