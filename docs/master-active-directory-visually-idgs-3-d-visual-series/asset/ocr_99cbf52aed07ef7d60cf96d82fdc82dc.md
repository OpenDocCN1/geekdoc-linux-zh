# **Does disabling the account delete it?**

No. If you disable the computer account, users cannot log on to the domain from that computer. The computer account object in the directory appears with a red X over it. You can re-enable the account by right-clicking the account object and choosing Enable Account.

# **When should a computer account be deleted?**

You should always use the Disable Account option unless the computer has been physically removed from the network and is no longer in service. In that case, you can delete the account from the directory.

# **If I choose to manage another computer, what can I do?**

The Manage option opens the Computer Management console on other Windows 2000 computers. You can perform any task within the console, such as using system tools, configuring shared folders, managing storage, and even managing services and applications.
