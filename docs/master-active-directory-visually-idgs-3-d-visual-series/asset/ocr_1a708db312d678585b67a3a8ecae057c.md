# Can you make changes to the configuration after you reach the end of the wizard?

You can make changes to your settings when you reach the review page by using the Back button. When you click the Back button, you simply move back through the wizard screens you have completed. After you click the Finish button, you cannot make major Active Directory changes, such as renaming the domain, without reinstalling the Active Directory.

# Why do I have to enter a password to use the Active Directory Services Restore Mode?

As a security feature, you must enter a valid password for using the Active Directory Services Restore Mode. This password prevents anyone else from booting into Directory Services Restore Mode. This is a security feature so that you can allow other administrators to manage the Active Directory on your domain controller without using the Directory Services Restore Mode.
