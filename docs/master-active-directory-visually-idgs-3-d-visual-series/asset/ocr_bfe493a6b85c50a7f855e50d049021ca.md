# CONFIGURING USER ACCOUNT
PROPERTIES CONTINUED

A
side from the importance of
the Account tab configuration,
you also have the Profile tab
where you can enter a profile or
home folder path if profiles are in
effect for your environment. Profiles
are useful to control user accounts
and grant or restrict privileges. You
can also control user accounts using
the powerful features of Group

Policy, which you can learn about in
Chapter 24.

The Telephones and Organization
tabs may seem somewhat repetitive
to other tabs, but they simply enable
you to list more information about
the user. In environments where
users have multiple phone numbers,
as in the case of a mobile user or

one who works from home, the
Telephones tab gives you another
way to give this information to
Active Directory users. Likewise,
you can also list very specific
information about the user's
employment position on the
Organization tab.
