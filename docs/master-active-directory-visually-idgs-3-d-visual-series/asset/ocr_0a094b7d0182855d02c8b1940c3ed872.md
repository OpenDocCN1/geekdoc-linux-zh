# What is the purpose of a custom search?

The custom search option enables you to select from a greater list of Active Directory objects, some of which are not available in the other Find categories. This feature allows you to search for an Active Directory object that is closest to what you actually need. By using the Custom Search option, you can search for domains, Certificate Templates, RPC Services, and so forth.

# What is an LDAP search?

An LDAP search, which is available on the Advanced tab of the Custom Search, enables you to perform a simple text search for the object you want to find. The search function uses the words you type in and attempts to locate Active Directory objects that contain the same words or keywords.
