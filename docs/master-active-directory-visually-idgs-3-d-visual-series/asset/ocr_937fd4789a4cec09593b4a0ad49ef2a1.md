# RETENTION METHOD FOR SECURITY LOG

You can also configure the retention method for Application, Security, and System logs. These policies allow you to determine how events are overwritten. You have the option of overwriting events by day, as needed, or do not overwrite events. If you choose to not overwrite events, then you must clear the log manually. In most circumstances, the most efficient setting is to overwrite events as needed. This allows the Event Log to create room but does not overwrite any more events than necessary.

+   1.  Expand the Security Settings container, expand the Event Log container, then select Policies For Event Logs.
+   2.  Double-click the Retention Method For Security Log policy setting.
+   3.  The Retention Method For Security Log policy window appears.
+   4.  Click the check box to either enable or disable the policy setting.
+   5.  Click either the Enabled or Disabled radio button.
+   6.  Click OK.
