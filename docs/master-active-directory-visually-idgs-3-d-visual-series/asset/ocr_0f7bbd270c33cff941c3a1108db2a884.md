Next, some domains may contain subdomains that further divide the second-level domain. These subdomains, also called child domains and grandchild domains, may be different divisions or groups within the second-level domain company.

![](bbox=[0.04, 0.33, 0.49, 0.68])

When resolution reaches a host—which is a computer within the domain—the DNS name is said to be a Fully Qualified Domain Name.

![](bbox=[0.53, 0.21, 0.97, 0.63])

A Fully Qualified Domain Name can be resolved for the top of the tree down to the host computer. Much like how the postal system can deliver a piece of mail to your home by resolving the zip code, state, city, street address, and then your name, DNS can resolve host names to IP address by resolving the root domain, first-level domain, second-level domain, subdomains (if present), and the host.
