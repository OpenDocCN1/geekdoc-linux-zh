# CREATING PERMANENT SHARED OBJECTS

This policy enables you to define who can create permanent shared objects.

This includes such items as folders, printers, applications, and so forth. If you want to define this policy, then you select which users or groups are allowed to create those shared objects on client computers.

![](bbox=[0.03, 0.48, 0.47, 0.83])

+   1. Expand the Security Settings container, expand the Local Policies container, then select Users Rights Assignment.
+   
+   The policy settings appear in the details pane.

+   2. Double-click the Create Permanent Shared Objects policy setting.

![](bbox=[0.49, 0.48, 0.98, 0.83])

+   4. The Create Permanent Shared Objects policy window appears.
+   
+   5. Click the check box to either enable or disable the policy setting.
+   
+   6. Click Add.

+   7. Select the desired groups, then click OK.
+   
+   You can also use the Remove button to remove any existing groups.
+   
+   8. Click OK.
