# APPENDIX A

# ENFORCING MAXIMUM LIFETIME FOR
SERVICE TICKET

**K**erberos authentication works by using service tickets. By enabling this policy, you can place a maximum lifetime age for the service ticket for the users’ accounts. This feature requires the system to periodically generate new service tickets, which provides an additional measure of security for your network logon process.

![](bbox=[0.03, 0.51, 0.51, 0.87])

The policy settings appear in the details pane.

2.  Double-click the Maximum Lifetime For Service Ticket policy setting.

![](bbox=[0.51, 0.51, 0.96, 0.85])

The Maximum Lifetime For Service Ticket window appears.

4.  Use the scroll box to determine the number of minutes for ticket expiration.

5.  Click OK.
