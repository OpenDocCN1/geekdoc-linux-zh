# TIPS

# Must each group have an e-mail address?

As with each user account, you can decide what information you want to configure for the Active Directory. If you do not want the group to have an e-mail address, simply do not enter one on the group’s properties sheets. Then, users cannot send e-mail to the group as a whole. The advantage, of course, in using a group e-mail address is the ease of sending mail to the group.

# How often can I move groups?

You can move a group as often as necessary. In order to avoid this management task, however, be careful to create an OU structure that remains as static as possible. Highly defined OU structures introduce more management tasks, which can be avoided by creating a more static OU structure. Some organizations even choose to have a users and groups OU so that all user and group accounts are always contained in one location.

# SENDING GROUP E-MAIL
