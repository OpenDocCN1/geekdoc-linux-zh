# TIPS

**Can I use a snap-in without the MMC?**

No. Snap-ins are created specifically to function within the MMC. The MMC provides the controls necessary to use the snap-in, and the snap-in does not function without the MMC. All Active Directory tools are MMC snap-ins, and these tools cannot be accessed and used without the MMC.

**What does the MMC do without a snap-in?**

The MMC does not have any functionality without a snap-in. You can compare the MMC to a kitchen stove. Without something on the burners or in the oven, the stove does not have any real functionality. But if something is on the burners or in the oven, you use the stove to control it. For example, if a pot of water is on a burner, you can use the stove controls to heat the water, or cool it back down. The MMC is similar—you use the MMC controls to manage and use snap-ins.
