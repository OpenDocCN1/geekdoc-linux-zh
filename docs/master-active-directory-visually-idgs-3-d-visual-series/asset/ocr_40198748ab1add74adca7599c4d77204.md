# MANAGING A USER'S ACCOUNT

aside from configuring an account's properties, you can also manage each account by using the Action menu.

First, you can easily disable the account by selecting Disable Account. When you perform this action, a red X appears over the account's icon. In the same manner, you can enable an account that has

been disabled. You can also reset the password, move the account, open the home page, or send an e-mail message to the user if these options are configured in the user's properties.

If you click All Tasks, you see a repeat of the same tasks that appear at the top of the window. You have

the options to delete, rename, or refresh the account as well.

Windows 2000 provides the All Tasks option, which you can also see by right-clicking the User Accounts icon, so you can configure these options either through the Action menu or by using a simple right-click.
