# ## CONFIGURING SITE LINKS  CONTINUED

After you create the site links and bridges that you need, you can configure them to replicate in the manner that is appropriate for your environment. This is accomplished by configuring each site link to replicate at a certain time and a certain cost. **Cost** is the priority at which site links are used. For example, if you have a T1 link that should be used for replication under normal circumstances, and you have a dial-up connection as a backup solution, you would want to configure the T1 link with a lower cost than the dial-up connection. The Active Directory always attempts to replicate over lower-cost links as opposed to higher-cost links.

If you are using an SMTP link, you don't need to worry about scheduling the replication, because SMTP is asynchronous—it ignores schedules. SMTP traffic is exchanged from one server directly to the next and not over intermediary links.
