# APPENDIX A

# ENABLING COMPUTER AND USER ACCOUNTS TO BE TRUSTED FOR DELEGATION

T his policy allows computers and user accounts to be trusted for delegation by the

users or groups that you specify in the policy. Typically, you should only allow administrators or other

advanced groups, such as Power Users, the right to delegate.

![](bbox=[0.05, 0.51, 0.47, 0.78])

+   1. Expand the Security Settings container, expand the Local Policies container, then select Users Rights Assignment.
+      2. The policy settings appear in the details pane.

+   3. Double-click the Enable Computer And User Accounts To Be Trusted For Delegation policy setting.

![](bbox=[0.51, 0.51, 0.95, 0.78])

+   4. The Enable Computer And User Accounts To Be Trusted For Delegation policy window appears.
+      5. Click the check box to either enable or disable the policy setting.

+   6. Click Add.
+      7. Select the desired groups, then click OK.
+      8. You can also use the Remove button to remove any existing groups.
+      9. Click OK.
