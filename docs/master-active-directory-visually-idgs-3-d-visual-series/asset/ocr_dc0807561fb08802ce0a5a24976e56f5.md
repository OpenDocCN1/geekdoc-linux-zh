# MANAGING THE WINS SERVER 
CONTINUED

You perform a number of operations by using the Action menu. First, you can scavenge the WINS database. As with all databases, the WINS database collects information that becomes outdated. Periodically, WINS needs to remove this outdated information, and this process is known as scavenging. You don't need to force scavenging using the Action menu unless you have specific reasons for

wanting to clean the database—
WINS will do this automatically—
through the settings on the Name 
Record tab in the server's Properties 
sheets (which you learn about later 
in this chapter.) If you do manually 
scavenge the database, you should 
know that the process is very CPU- 
and network-intensive, so you 
should scavenge only during 
nonpeak hours.

You can also use the Action menu to run a check for consistency. This task helps maintain database integrity among the WINS servers. In other words, the check determines if the database is consistent among all the WINS servers. The process is automatically scheduled, but you can force it to run using the Action menu. As with the database scavenge, the process is CPU-intensive.
