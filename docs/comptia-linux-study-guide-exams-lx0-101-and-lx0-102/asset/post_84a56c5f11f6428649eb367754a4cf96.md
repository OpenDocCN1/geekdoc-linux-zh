- 16. B. The cron utility is a good tool for performing tasks that can be done in unsupervised manner, as deleting old temporary files (option B) or checking to see that they are running correctly (option D). Tasks that require interaction, such as creating accounts (option C), are not good for cron jobs, which must execute unsupervised. Although a cron could restart a crashed server, it's not normally used to start a server when the system boots (option A); that's done through system startup scripts or a super server. Sending files to a printer (option E) is generally handled by a print server with CUPS.

- 17. B. User jobs don't include a username specification (tbaker in options A and C). The */29 specification for the hour in options A C and D causes the job to execute every other hour; the 7, 19 specification in options A and B causes it to execute twice a day, on 7th and 19th hours (in conjunction with the 15 specification, that means at 7:15 a.m. and 7:15 p.m.). Thus, option B provides the correct syntax and runs the job twice a day, the question specifies whereas, option A, C, and D all get something wrong. Option E executes the job to run once, not twice a day.

- 18. The anacron is a supplement to cron that helps ensure log rotation, /tmp cleanup, and other traditional cron jobs are handled when the computer is shut down (and, when cron isn't running) for extended periods of time. Thus, this is the program to achieve the stated goal, and option B is correct. There is no Linux utility called temp, for controlling cron. Option C's crontab is the name of log rotation on a laptop. The ntpd daemon (option E) is the NTP daemon, which keeps the system clock in sync with an external source. Although running ntpd on a laptop is possible, it won't directly help with the task of scheduling log rotation. The syslog-ng package is an alternative system daemon, but that doesn't solve the problem of potentially unreliable log rotation on laptops using standard cron utilities.

- 19. E. The at command runs a specified program at stated in the future. This time may be specified in several ways, one of which is time stands for 4:00 p.m. Thus, option D is correct. The objections against option A, B, C, and D are all invalid. (You may pass a script to it with the -f parameter, but this is not required, contrary to option D).

- 20. A. The at command noted in option B can be used to run a single time, but not on a regular basis (such as daily). ## Chapter 8: Configuring Basic Networking

- 1. A, B. Ethernet (option B) is currently the most common type of wired network hardware for local networks. Linux supports it very well, and Linux also includes support for Token Ring (option A) and Fibre Channel (option E) network hardware. DHCP (option C) is a protocol to obtain a TCP/IP configuration over a TCP/IP network. It's not a type of network hardware, but it can be used over hardware that supports TCP/IP. NetBEUI (option D) is a network stack that can be used instead or in addition to TCP/IP over various types of network hardware. Linux does not support NetBEUI directly.

- 2. B. IP addresses consist of four 1-number (0–255). - 3. C. The gateway is a router that transfers data between two or more network segments.
