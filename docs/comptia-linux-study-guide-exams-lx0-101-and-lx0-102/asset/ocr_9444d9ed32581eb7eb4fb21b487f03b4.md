# Creating Swap Space

Some partitions dont hold files. Most Linux can use a swap partition, which is
a partition that Linux treats as an extension of memory. (Linux can also use a swap file,
which is a file that works in the same way. Examples of swap space.) Linux uses
t MBR partition type code of 0x82 to identify swap space, but as with other partitions,
this is mostly a convenience to keep other OSs from accessing Linux swap parti-
s; Linux uses /etc/fstab to define which partitions to use as swap space, as described
in Chapter 4, “Managing Files.”

> Solaris x86 uses an MBR partition type code of 0x82, in Solaris,
this refers to a Solaris partition. If you dual-boot between Solaris and
Linux, this dual meaning of the 0x82 partition type code can cause conf-
s. This is particularly true when installing the OSs. You may need to use
Linux's fdisk to temporarily change the partition type codes to keep Linux
from trying to use a Solaris partition as swap space or to keep Solaris from
trying to interpret Linux swap space as a data partition.

![](bbox=[0.141, 0.66, 0.245, 0.7])

Although swap space doesnt hold a filesystem per se and isn't mounted in the way the
filesystem partitions are mounted, swap space do require preparation similar to that for
creation of a filesystem. This task is accomplished with the mkswap command, which you
can generally use by passing it or not the device identifier:

```
# mkswap /dev/sda7
```
