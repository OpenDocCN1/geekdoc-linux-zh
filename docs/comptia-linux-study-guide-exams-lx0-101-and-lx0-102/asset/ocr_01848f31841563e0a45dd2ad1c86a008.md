By default, expand assumes a tab every eight characters. You can change this spacing with the -t num or --tabs option, where num is the tab spacing value.

# Displaying Files in Octal with od

Some files are not easily displayed in ASCII; most graphics, audio files, and so on use non-ASCII characters that look like gibberish. Worse, these characters can strange things to display if you try to view such a file with cat or a similar tool. For instance, your font may change, or your console may begin appearing uncontrollably. Nonetheless, you may sometimes want to display files, particularly if you want to investigate the structure of a data file. You may also want to look at an ASCII file in a way that eliminates certain ambiguities, such as whether there is a gap between a tab or several spaces. In cases, od (which stands for octal dump) can help you display files in octal format-(base 8) numbers. For instance, consider Listing 1.2 as parsed by:

```
000000 032465 031462 033471 072440 066156 071551 062564
000020 005144 032465 026465 034065 033061 066040 071551 062564

000060 005144 032465 026465 034071 072440 066156 071551
000100 062564 005144
000104
```

The first field of each line is an index into the octal file. For instance, the second line begins at 02 (16 in base 10) bytes into the file. The remaining lines on each line represents the bytes in the file. This type of output can be difficult to interpret unless you're well versed in octal notation and perhaps in the ASCII code.

Although od is nominally a tool for generating octal output, it can generate many other formats, such as hexadecimal (base 16), decimal (base 10), and even ASCII with escaped control characters. Consult the page for od for details on creating these variants.

# Sorting Files with sort

Sometimes you'll create an output file that you want sorted. To do so, you can use a command that's called, appropriately sort. This command can sort in several ways, using the following:

**Ignore Case** Ordinarily, sort sorts by ASCII value, which differentiates between uppercase and lowercase letters. The -f or --ignore-case option sort to ignore case.

**Month Sort** The -m or --month-sort option causes the program to sort by three-letter abbreviation (JAN through DEC).

**Numeric Sort** You can sort by number by using the -n or --numeric-sort option.

**Reverse Sort Order** The -r or --reverse sort in reverse order.
