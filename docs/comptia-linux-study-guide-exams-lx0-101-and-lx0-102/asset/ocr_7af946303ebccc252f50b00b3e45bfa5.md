This simplicity of form hides considerable complexity because ps supports three different types of options, as well as many options within each type. The three types of options are as follows:

Unix These single-character options may be grouped together and are preceded by a single dash (-).

BSD These single-character options may be grouped together and must not be preceded by a dash (-).

Options that may be grouped together be clustered without spaces between them. For instance, rather than typing ps -a -f, you can type ps -af. The reason for so much complexity is the ps utility has historically varied from one OS to another. The version of ps that ships with many Linux distributions attempts to implement features from all of its ps versions, so it supports many personalities. However, you can change its behavior by setting the PS_ENVIRONMENT variable to posix, linux, bsd, digit1, or others. The rest of this section describes the ps behavior on most Linux systems.

Some of the useful ps features include the following:

Display Help --help option summarizes some of the common ps options.

Display All By default, ps displays only processes that were run from its own terminal (xterm, text-mode login, or remote login). The -A and -e options cause it to display all processes on the system, and x displays all processes owned by the user who gives the command. The x option increases the amount of information that is displayed about each process.

Display One Processes You can display processes owned by a user with -u user, U, and --user options. The user variable may be a username or user ID.

Display Extra Information -f, -j, l, u, and v options all expand the information provided in the ps output. Most ps output formats include one line per process, but ps can enough information that it is impossible to fit it all on 80-character line. There, these options provide various mixtures of information.

Display Hierarchy -H, -f, and --forest options group processes and use indentation to show the family of relationships between processes. These options are useful if you're trying to trace the parentage of a process.

Display Wide Output The ps command output can be more than 80 columns wide. Normally, ps truncates its output so that will fit on your screen or xterm. The -w and w options tell not to do this, which can be useful if you direct the output to a file, as in ps w > ps.txt. You can then examine the output file in a text editor that supports wide lines.
