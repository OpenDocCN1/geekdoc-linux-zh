# Configuring Routing

As explained, routers pass traffic from one network to another. You configure your Linux system to direct contacts on the local network. You also give the computer a router's address, which your system uses as a gateway to the Internet. Any traffic that's not destined for the local network is directed at this router, which passes on to its destination. In practice, there are likely a dozen or more routers between you and most Internet sites. Each router has at least two network interfaces and keeps a table of rules where to send data based on the IP address. Your own Linux computer has such a table, but it's probably very simple compared to those on major Internet routers.
