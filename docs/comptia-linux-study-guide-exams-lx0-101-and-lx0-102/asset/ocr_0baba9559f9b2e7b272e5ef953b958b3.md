# Appendix A · Answers to Review Questions

9. The initdefault action specifies the default runlevel, option B is correct. The remaining options are all taken from /etc/initabb files but do not have the specified meaning.

10. A, B. Runlevel 0 (option A) is the reserved runlevel for halting the system. Runlevel 1 (option B) is reserved for single-user mode. Runlevel 6 (option E) is reserved for rebooting. Runlevel 2 (option C) is the default runlevel on Debian and most distributions from it, it does none of the things described in the question. Runlevel 5 (option D) is a regular, user-configurable runlevel, which isn't normally used for the things described in the question. (Many systems use it for a regular boot with a GUI prompt.)

11. B. The first number in the runlevel output is the previous runlevel (the letter N is used to indicate that the system hasn't changed levels since booting). The second number is the current runlevel. Hence, options B and C are correct, while A and D are incorrect. Incorrect changes very quickly, and the runlevel utility doesn't provide a code to indicate that the runlevel is in the process of changing, so option E is incorrect.

12. A. The -c option to shutdown cancels a previously scheduled shutdown, as stated in option B and C describe the effects of the -r and -h options to shutdown, respectively. No shutdown asks for confirmation before taking action, although you can delay a shutdown by specifying a time in the future, so option D is incorrect. shutdown opens windows in X, except as a consequence of shutting down, so option E is incorrect.

13. There is no standard command in Linux, so option E is correct. The reboot command (option A) is equivalent to shutdown -r, halt (option B) is equivalent to shutdown -H, poweroff (option C) is equivalent to shutdown -P, and telinit 0 (option D) is equivalent to shutdown -H.

14. The telinit command is used to run levels; when it passes the parameter 1, as in option B, telinit changes runlevel to 1, which is single-user mode. The runlevel command (option A) displays the current runlevel and doesn't change runlevels. Although telinit can be used to shut or reboot the computer, the shutdown command (option C) can't be used to change runlevels except to runlevel 0 or 6. There is no standard singleuser command (option D). The halt command (option E), like shutdown, can't be used to change to single-user mode.

15. Runlevel 4 is not standardized, and most distributions don't use it for anything specific (although in practice it will do something if you enter it). Thus, you can safely runlevel 4 to achieve specific goals, and option E is correct. Option A describes runlevel 6. Option B describes runlevel 3 on Red Hat and related distributions. Option C describes 5 on Red Hat and related distributions. Option D describes runlevel 1.

16. A. In Vi, dd is the command-mode command that deletes lines. Preceding this command with a number deletes that number of lines. Thus, option A is correct. Although yy similarly, it copies (yank) text rather than deleting it, so option B is incorrect. Option C works in more modern text editors, but not in Vi. Option D works in Emacs and similar text editors, but not in Vi. Option E works in many GUI text editors, but not in Vi.
