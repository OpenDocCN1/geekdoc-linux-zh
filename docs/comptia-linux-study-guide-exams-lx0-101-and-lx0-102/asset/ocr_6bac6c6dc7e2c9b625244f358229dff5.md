# TABLE 4.8 Sample umask values and their effects

| Umask | Created files | Created directories |
|---|---|---|
| 000 | 666 (rw-rw-) | 777 (rwxrwx) |
| 002 | 664 (rw-rw--) | 775 (rwx-xr-x) |
| 022 | 644 (r--r--) | 755 (rwx-xr-x) |
| 027 | 640 (rw----) | 750 (rwx-r-x--) |
| 077 | 600 (rw-------) | 700 (rwx------) |
| 277 | 400 (r--------) | 500 (r---------) |

Note that the umask is not a simple subtraction from the values of 777 or 666; it's a bit-wise removal. Any bit that's set in the umask is removed from the final permission for new files, if a bit isn't set (in the execute bit of ordinary files), the umask doesn't do harm. For instance, consider the 7 in several entries of Table 4.8's umask column. This corresponds to a binary value of 111. An ordinary file might have rw-(110) permissions, but applying the umask 7 (111) eliminates 1 values but doesn't touch 0 values, thus producing a (binary) 000-value—that is, permissions, expressed symbolically.

Ordinary users can enter the umask command to change the permissions on new files they create. The superuser can modify the default for all users by modifying a system configuration file. Typically, /etc/profile contains one or more umask commands. Setting the umask in /etc/profile may or not have an effect because it can be overridden at other points, such as a user's own configuration files. Nonetheless, setting the mask in /etc/profile or other system files can be useful if you want to change the default system policy. Most Linux distributions use a default umask of 002 or 022.

To find what the current umask is, type umask alone, without any parameters. Typing umask -S produces the umask expressed symbolically rather than in octal form. You may also specify a umask when you want to change it, but in this case, specify the bits that you want to change. For instance, umask u=rw,g=rx,o=rx is equivalent to umask 022.

In addition to setting the default umask, users can change their default group group with newgrp, as in newgrp skyhook to create new files with the group of the specified group. To use this, the user must be a member of the specified group. The newgrp command also accepts the -1 parameter, as in newgrp -1 skyhook, which reinitializes the environment if the user had logged in.
