You can fine-tune the effects of df by passing several options. Each option modifies the df output in a special way:

**Include Filesystems** The -a or --all option includes pseudo-filesystems with a size of 0 in the output. These filesystems may include /proc, /sys, /proc/usb, and others.

**Used Units** The -h or --human-readable option causes df to scale and label its blocks units; instead of reporting a partition in blocks, it reports the size as 5.66 (5.4GiB). The -h and -s1 options have a similar effect, but they use power-of-2 (1,000;1,000;1,000) and so rather than power-of-2 (1,024;1,048,576) and so on units. The -k (--kilobytes) and -m (--megabytes) options force output in their respective units.

**Summarize In** By default, df summarizes available and used disk space. You can instead receive a report on available and used inodes by passing the -i or --inodes option. This information can be helpful if a partition has very many small files, which can deplete available inodes sooner than they deplete disk space.

> NOTE The -i option works for ext2, ext3, ext4, XFS, and some other filesystems that create a fixed number of inodes when the filesystem is created. Other filesystems, such as ReiserFS and Btrfs, create inodes dynamically, rendering the -i option meaningless.

**Local Filesystems Only** The -l or --local option causes df to omit network systems. This can speed up operation.

**Display Filesystem Type** The -T or --type option shows the filesystem type to the information df displays.\ **Limit by Filesystem Type** The -t ftype or --type=fstype displays only information about filesystems of the specified type. The -x ftype or --exclude-type=fstype has the opposite effect; it excludes filesystems of the specified type from the report.
