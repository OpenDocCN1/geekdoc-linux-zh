# Font Technologies and Formats

Font technologies can be classified as falling into one of two broad categories:

**Bitmap Fonts** The simplest type of font format is the bitmap font, which represents fonts like bitmap graphics, in which individual pixels are either active or inactive. Bitmap fonts are fairly easy to manipulate and display, from a programming perspective, which makes them good for low-powered computers. The problem is that each font must be optimized for display at a particular resolution. For instance, a font that has 20 pixels will appear once when shown on the screen (typically 72 to 100 dots per inch, or dpi) but will be much smaller when printed (typically 330 to 1200 dpi). Similarly, you need multiple fonts to display a single font at multiple sizes (as 9 point versus 12 point). This means that a single font, as Times, requires potentially dozens of individual fonts for display at different sizes and on different devices. If you lack the correct font file, the result will be a poorly scaled display.

**Outline Fonts** Most modern fonts are distributed as outline fonts (aka scalable fonts). This type of format represents each character as a series of lines and curves in a high-resolution matrix. The computer can scale this representation to any font size or for any resolution, enabling a single font to handle every possible use of the font. The main problem with outline fonts is that this scaling is imperfect; scalable fonts often look slightly worse than bitmap fonts, particularly at small sizes. Scaling and displaying the fonts also takes more CPU time than displaying a bitmap font. This factor used to be important, but on modern CPUs it's not much of an issue.

Both bitmap and outline fonts can come in several different formats. X ships with a number of basic bitmap and outline fonts, and you're unlikely to need to deal explicitly with bitmap fonts or theirs, so I don't describe them in detail. Outline fonts are another matter, though. The main formats are Adobe's *PostScript Type 1* (Type 1 for short) and Apple's *TrueType*. Fonts are available on the Internet and on commercial font CDs in one or both of these formats.

XFree86 3.6.6 and earlier supported Type 1 fonts are not TrueType fonts. XFree86 4.x and X.orgX11 support both Type 1 and TrueType fonts.

# Configuring X Core Fonts

X fonts are those that are handled directly by X. To configure these fonts, you must do two things: prepare a font directory that holds the fonts, and add the font directory to X's font path.
