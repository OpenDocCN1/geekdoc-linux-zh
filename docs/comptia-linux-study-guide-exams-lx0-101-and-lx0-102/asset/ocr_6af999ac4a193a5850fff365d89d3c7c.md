14. C. The tail command displays the final 10 lines of a file, so option C is correct. (You can change the number of lines displayed with the -n option.) The uniq command (option A) removes duplicates from a list. The cut command (option B) echoes the specified characters or fields from an input file. The wc command (option D) displays counts of the number of characters, words, and lines in a file. The fmt command (option E) is a plainformatter.

15. A. The pr program takes file as input and adds formatting features for printing, such as a header and footer to separate pages. The command also pipes the output through lp (which is a Linux printing command). Option A describes these effects and is correct. Option B describes the effect of the cat command, and so is incorrect. The conversion of tabs to spaces is done by the expand command, yet error messages are not stored in the file, so option D is incorrect. Option A is correct, option E is incorrect.

16. B, D. The nl counts numbers lines, so does this work without any special options, and option B is correct. (Its options can fine-tune the lines it numbers). The cat command can also number lines via its -b and -n options;-b counts non-blank lines, whereas -n counts all lines (including blank lines). Thus, option C and D are both correct. Neither the fmt command nor the wc command will number the lines of file, so options A and E are both incorrect.

It will also add headers that you don't want. Option E's grep command searches text within files; it won't format files.
