HAL Daemon The Hardware Abstraction Layer (HAL) Daemon, or hold, is a user-space program that runs at all times (that is, as a daemon) that provides other user-space programs with information about available hardware.

D-Bus The Desktop Bus (D-Bus) provides a further abstraction of hardware information access. Like hold, D-Bus runs as a daemon. D-Bus enables processes to communicate with each other as as terminal programs to be notified of events, by both processes and hardware (such as the availability of a USB device).

udev Traditionally. Linux hotplug created devices as conventional files in the /dev directory. The existence of hotplug devices and other issues, have motivated the creation of udev: a virtual filesystem, mounted at /dev, which creates dynamic devices as drivers are loaded and unloaded. You can configure udev devices through /etc/udev, but the standard configuration is usually sufficient for common hardware.

These tools help programs work seamlessly in a world of hotplug devices by enabling the programs to learn about hardware, receiving notification when the hardware configuration changes.

Older devices, such as parallel and RS-232 ports, are officially coldplug in nature. Many people treat these devices as if they were hotplug, and they can get away with it; but there is a risk of damage, so it's safest to power down a computer before connecting or disconnecting a device. When RS-232 or parallel devices are hotplugged, they aren't registered by tools such as udev and hold. Only the ports to which these devices connect are handled by the OS; it's up to user-space programs, as terminal programs or the printing system, to know how to communicate with the external devices.

# Configuring Expansion Cards

Many devices require configuration—you must set the IRQ, I/O port, and DMA addresses used by the device. (Not all devices use all three resources.) Through the mid-1990s, this process involved tedious changes to jumpers on the hardware. Today, you can configure most options through software.

> Even devices that are built into the motherboard are configured through the same means used to configure PCI cards.
