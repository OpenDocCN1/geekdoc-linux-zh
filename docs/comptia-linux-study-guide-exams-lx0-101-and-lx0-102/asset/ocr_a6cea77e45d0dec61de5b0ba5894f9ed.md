# 105 Shells, Scripting and Data Management

# 105.1 Customize and use the shell environment (Chapter 9)

+   - Set environment variables (e.g., PATH) at login or when spawning a new shell
- Write BASH functions for frequently used sequences of commands
- Maintain skeleton directories for new user accounts
- Set command search path with the proper directory
- The following is a partial list of the used files, terms, and utilities: /etc/profile, env, export, set, unset, ~/.bash_profile, ~/.bash_login, ~/.profile, ~/.bashrc, ~/.bash_logout, function, alias, lists

# 105.2 Customize or write simple scripts (Chapter 9)

+   - Use standard syntax (loops, tests)
- Use command substitution
- Test return values for success or failure or other information provided by a command
- Perform conditional matching to the superuser
- Correctly select the script interpreter through the shebang (#) line
- Manage the location, ownership, execution and suid-rights of scripts
- The following is a partial list of the used files, terms, and utilities: for, while, test, if, read, seq
