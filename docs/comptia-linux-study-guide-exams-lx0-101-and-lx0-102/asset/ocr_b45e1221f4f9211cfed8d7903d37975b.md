# Additional Options You can add many options using the -o parameter. Many of these are filesystem-specific.

Device The device is the device associated with the partition or disk device, such as /dev/hda4,/dev/fd0, or /dev/cdrom. This parameter is usually required, but it may be omitted under some circumstances, as described shortly.

Mount Point Thepoint is the directory where the device's contents should be attached. As with device, it's usually required, but it may be omitted under some circumstances.

The preceding list of mount parameters isn't comprehensive; consult the mount man page for some of the more obscure options. The most common applications of mount use few because Linux generally gives a good job of detecting the filesystem type and the default parameters work reasonably well. For instance, consider this example:

```
# mount /dev/sdb7 /mnt/shared
```

This command mounts the contents of /dev/sdb7 on /mnt/shared, auto-detecting the filesystem type and using the default options. Ordinarily, only root may mount a mount command; however, if /etc/stab specifies the user, users, or option, an ordinary user may mount a filesystem using a specific syntax when only the device or mount point is specified, but not both. For instance, a user may type /mnt/cdrom to mount a CD-ROM from /etc/stab /mnt/cdrom as its mount point and uses the users, or, owner option.

> Most Linux distributions ship auto-mount support, which causes the OS to automatically mount removable media when they are inserted. In GUI environments, a file browser may also open on the inserted disk. To eject the disk, the user will need to unmount the filesystem by unmount, as described shortly, or by selecting an option in the desktop environment.

When Linux mounts a filesystem, it ordinarily records this fact in /etc/mtab. This file is stored in /etc, but it's not a configuration file you should edit. You might examine this file to determine what filesystems are mounted, though. (The df command, described in more detail in “Monitoring Disk by Partition,” is another way to learn what filesystems are mounted.)
