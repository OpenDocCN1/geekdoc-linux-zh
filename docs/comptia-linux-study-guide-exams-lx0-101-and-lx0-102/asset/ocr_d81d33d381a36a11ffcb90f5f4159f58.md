# Exam Essentials

Describe the tools used for managing Debian packages. The dpkg install uninstalls a single package or a group of packages you provide. The apt-get utility retrieves programs from installation media or from the Internet for installation and can automatically upgrade your entire system. Dselect serves as a menu-interface to apt-get, enabling you to select programs you want to install from a text-mode menu.

Summarize tools for extracting files and converting between package formats. The rpm2cpio program can convert an RPM file to a cpio archive, enabling users of non-RPM systems to access files in RPM. The a11n utility can convert in any direction between Debian packages, RPMs, stamped packages and tarballs.

Summarize the reasons for using shared libraries. Shared libraries keep disk space and memory requirements manageable by placing code that's needed by many programs in use it, enabling one copy to be used multiple times. More generally, libraries enable programmers to use “building blocks” that others have written without having to constantly reinvent code.

Describe methods available to change the library path. The library path can be changed systemwide by editing the /etc/ld.so.conf file and typing ldconfig. For temporary or per-user changes, directories may be added to the path by placing them in the LD_LIBRARY_PATH environment variable.

Explain the difference between foreground and background processes. Foreground processes have control of the current terminal or text-mode window (such as an xterm). Background processes don't have exclusive control of a terminal or text-mode window but are still running.

Describe how to limit the CPU time used by a process. You can launch a program with nice or renice to alter its priority in obtaining CPU time. If a process is truly out of control, you can terminate it with the kill command.
