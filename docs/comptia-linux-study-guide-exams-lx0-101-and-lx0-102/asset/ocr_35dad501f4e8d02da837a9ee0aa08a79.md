Within each of the three general-use network classes is a range of addresses reserved for private use, Most IP addresses must be assigned to individual computers by a suit-ability, two systems on the Internet try to use a single address. Anybody can use the reserved private address spaces, though. (These address blocks are sometimes referred to as RFC1918 addresses, after the standards document—RFC1918—in which they’re defined.) The caveat is that routers normally drop packets to these addresses, effectively isolating them from the Internet as whole. The idea is that these addresses may be safely used by small private networks. Today, they are often used behind Network Address Translation (NAT) routers, which enable arbitrary numbers of computers to “hide” behind a single system. The NAT router substitutes its own IP address on outgoing packets and directs them to the correct system. This is very handy if you want connect more computers to the Internet than you have IP addresses.

> NOTE: I generally reserved private addresses for examples in this book. Unless otherwise specified, these examples work well on convention-assigned (non-private) IP addresses.

IPv6 has its equivalent to private addresses. IPv6 site-local addresses may be routed within a site but off-site. They begin with the hexadecimal number fec, fed, fee, or fef. Link-local addresses are restricted to a single network segment; they should not be routed at all. These addresses begin with the hexadecimal number fe8, fe9, fea, or feb. IPv4 classes were designed for simple routing; but as the Internet grew, they became restrictive. Thus, they serve mainly as a way to set default masks, such as 255.0.0.0 for Class A or for Class C. Most configuration tools set these masks automatically, but you can override the settings if necessary. IP addresses and networks are extremely important for network configuration. If your network doesn’t use DHCP to assign IP addresses automatically, you must configure your system’s IP address manually. A mistake in this configuration can cause a complete failure of networking or subtle errors, such as an inability to communicate with some computers.

> NOTE: NetBEUI/IP stacks have their own addressing methods. NetBEUI uses machine names; it has no separate numeric addressing method. AppleTalk uses two 16-bit numbers. These addressing schemes are independent from IP addresses.
