The cut command is frequently used to extract data from some other command's output. For instance, suppose you're writing a script and the script needs to know the hardware address of your Ethernet adapter. This information can be obtained from the ifconfig command (described in detail in Chapter 8, "Configuring Basic Networking")

```
$ ifconfig eth0
eth0 link enc:Ethernet Haddr:00:7C:96:A3:73
inet addr:192.168.1.3 Bcast:192.168.1.255 Mask:255.255.255.255
inet6 addr:fe80::20c:7ff7:fe96:a373/64 Scope:Link
UP BROADCAST TRAILERS RUNNING MULTICAST MTU:1500 Metric:1
TX packets:717242 dropped:0 overflows:0 frame:0 carrier:0 collisions:0 txqueuelen:10000
RX bytes:627843078 TX bytes:1082453585 (1032.3 Mb)
Interrupt: Base address:0x0de0
```

Unfortunately, most of base address is extraneous for the desired purpose. The hardware address is the 6-byte hexadecimal number following HWaddr. To extract that data, you can use grep (described shortly, in "Using grep") with a pipe:

```
$ ifconfig eth0 | grep HWaddr | cut -d " " -f 11
00:0c:76:96:a3:73
```

In course, you would probably assign this value to a variable or otherwise process it through additional pipes. Chapter 9 describes scripts in more detail.

# Obtaining a Word Count with wc

The wc command produces a word count (that's what gets its name), as well as line and byte counts, for a file:

```
$ wc file.txt
```

```
308 2343 15534 file.txt
```

This file contains 308 lines (or, more precisely, 308 characters); 2,343 words; and 15,534 bytes. You can limit the output to the newline count, the word count, the byte count, or a character count with --lines (-l), --words (-w), --bytes (-c), or --chars (-m) option, respectively. You can also limit the maximum line length with the --max-line-length (-L) option.
