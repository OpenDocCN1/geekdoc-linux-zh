# 获取 X 显示信息

有时了解你的显示器能力是有帮助的，因为它是由 X 管理的。用于这项任务的工具是 **xdpyinfo**。当你输入 **xdpyinfo** 时，结果将是关于当前显示器的大量信息，例如 X 版本号、所有当前显示器的分辨率和色彩深度等。这些信息大部分在本质上具有很强的技术性，因此你可能无法完全理解它们。没关系——我建议你运行这个程序并仔细阅读输出内容，看看你能从中学到什么。如果你以后想在另一台计算机的显示器获取类似的信息，你就将知道如何操作了。

要获取更多技术信息，你可以对 **xdpyinfo** 使用 **-ext extension** 选项。**extension** 是 X 扩展的名称，它是为 X 提供扩展功能的软件模块。（不带选项的基础 **xdpyinfo** 命令会列出所有可用扩展。）

你可以使用 **xinfo** 命令获取特定窗口的详细技术信息。在基本用法中，你输入 **xinfo**，将光标移动到一个窗口上并点击。结果是关于你所点击窗口的各种数据列表，如下：

- 绝对左上角 X: 1171
- 绝对左上角 Y: 611
- 相对左上角 X: 6
- 相对左上角 Y: 25
- 宽度: 657
- 深度: 32

Visual Class: TrueColor
Border width: 0
Class: InputOutput
Colormap: 0x2800003 (not installed)
Bit Gravity State: NorthWestGravity
Window Gravity State: NorthWestGravity
Backing State: NotUseful
Save State: no
Map State: IsViewable
Override Redirect State: no

```
Corners: +1171-611 -922-611 -92-55 +1171-55
-geometry 80x24-86-49
```

这些信息中的某些部分（色彩映射和重力状态）很容易解释。其他信息具有很高的技术性，我在这里不再进行描述。你可以向 xwinfo 传递各种选项来修改其显示的信息或你选择窗口的方式，包括以下内容：

**备用窗口选择方法** *-id* 和 *-name* 选项分别允许你通过 ID 数字或名称（通常显示在窗口边框中）来识别窗口。*-root* 选项选择根窗口——即整个显示器。

**关系** 像进程一样，窗口也可以有父窗口和子窗口。你可以通过 *-children* 选项识别这些关系。*-tree* 选项的工作方式类似，但它是递归的——也就是说，它会显示窗口之子之窗口的信息，以此此类推。

**基础信息** 默认使用 *-stats* 选项。你可以使用 *-bits* 选项重构输出，该选项会限制窗口位状态的信息输出。

**附加信息** *-events 选项产生窗口产生的事件信息；*-size 显示关于尺寸提示的信息；*-wm 显示窗口管理器数据；*-shape 类似于 -stats，添加了关于窗口和边框形状的信息；*-frame 修改显示以包含窗口管理器边框的信息；*-metric 在常规的像素测量基础上添加了毫米（mm）的测量；*-english 添加英尺和英寸的测量；以及 *-all 显示所有可用信息。
