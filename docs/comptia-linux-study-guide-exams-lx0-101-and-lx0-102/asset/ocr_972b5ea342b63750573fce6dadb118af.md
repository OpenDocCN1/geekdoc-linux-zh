# Addressing Hardware

One of the characteristics of dedicated network hardware such as Ethernet or Token Ring cards is that they have unique hardware addresses, also known as Media Access Control (MAC) addresses, programmed into them. In the case of Ethernet, these addresses are 6 bytes in length, and they're generally expressed as hexadecimal (base 16) numbers separated by colons. You can discover the hardware address for an Ethernet card using the ifconfig command. When ifconfig ethn, where n is the number of the interface (0 for the first card, the second, and so on). You'll see several lines of output, like this one:

```
eth0 Link encap:Ethernet hwaddr 00:A0:CC:24:BA:02
```

This line tells you that the device is an Ethernet card and that its address is 00:A0:CC:24:BA:02. What is this used for? Certain low-level network utilities and hardware use the hardware address. For instance, network switches use it to direct packets. The switch detects that a particular address is connected to a particular wire, and so it sends data directed at that only over the associated wire. The Dynamic Host Configuration Protocol (DHCP), which is described in the upcoming section “Configuring with DHCP,” is a means of automating the configuration of specific computers. It has an option that uses the hardware address to consistently assign the IP address to a given computer. In addition, advanced network diagnostic tools are available that let you examine packets that come from or to specific hardware addresses.

For the most part, you don't need to be aware of a computer's hardware address. You don't enter it in most utilities or programs. It's important for what it does in general.
