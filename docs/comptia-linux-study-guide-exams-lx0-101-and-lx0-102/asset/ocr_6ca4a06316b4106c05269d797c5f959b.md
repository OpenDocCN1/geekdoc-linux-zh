# Introduction

Why should you learn about Linux? It's a fast-growing operating system, and it is inexpensive and flexible. Linux is also a major player in the small and mid-sized server field, and it's an incredibly viable platform for workstation and desktop use as well. Understanding Linux, you will increase your standing in the job market. Even if you know Windows or Mac OS and your employer uses these systems, understanding Linux will give you an edge when you're looking for a new job or you're looking for a promotion. For instance, this knowledge will help you to make an informed decision about if and when you deploy Linux. The Computing Technology Industry Association (CompTIA) promotes Linux+ as an introductory certification for people who want to enter involving Linux. The exam is meant to certify that an individual has the skills necessary to install, operate, and troubleshoot a Linux system and is familiar with Linux specific contexts and basic hardware.

The purpose of this book is to help you pass the Linux+ (LX0-101 and LXO-102) updated in 2012. Because these exams cover basic Linux installation, configuration, maintenance, applications, networking, and security, these are the topics that are emphasized in this book. You'll learn how to get a Linux system running and configure it for many common tasks. Even after you've taken and passed the Linux+ exams, this book should remain a useful reference

> In 2010, CompTIA announced a partnership with Linux Professional Institute, the organization behind the LPI Certification (LPIC) program. # What Is Linux?

Linux is a clone of the Unix operating system (OS) that has been popular in academia and many business environments for years. Formerly used exclusively on mainframes, Unix and Linux can now run on small computers—which are actually far more powerful than the mainframes of just a few years ago. Because of its mainframe heritage, Unix (and here Linux) scales well to perform today's demanding scientific, engineering, and network server tasks.

Linux consists of a kernel, which is the core control software, and many libraries and utilities that rely on the kernel to provide features which users interact. The OS is available in many different distributions, which are collections of a specific kernel with specific support programs.
