# Appendix A - Answers to Review Questions

5. The rpm2cpio extracts data from an RPM file and converts it into a cpio archive that's set to standard output. Piping the results through cpio and using the -i and --make-directories options, as in option A, will extract those files to the correct directory. Option B creates a cpio file named mydirectories contains the files from the RPM package. Option C will uninstall the package myfonts.rpm (but not the myfonts package). The ailen utility has no --extract target, so option D is invalid. The rpmbuild utility builds a source RPM into a binary RPM, making option E incorrect.

6. An un-purge invokes the purge, which completely removes a package and its configuration files, so option E is correct. The -e parameter uninstalls a package for rpm, but option A is correct. The lowercase -p allows dpkg to print information about the package's contents, so option B is correct. The -r parameter removes a package leaves configuration files behind, so options C and D are incorrect (Option D also specifies a filename, which is not used for removing a package—you should specify only the shorter name.)

7. You can specify Debian archive sites in /etc/apt/sources, and then you can use apt-get update and apt-get to upgrade a Debian system to the latest packages, option C is correct. GUI package management tools for Debian and related distributions exist, but if they are not apt-get, option A is incorrect. The ailen may convert a tarball and install the converted package on a Debian system, but apt-get-can't do this, so option B is incorrect. dpkg and apt-get both come with Debian-based distributions, so option D is incorrect. The dpkg program can install packages on Debian-based systems, and apt-get can work with package systems, so option E is backward.

8. The --e-selections action to dpkg displays the names of all installed packages, making option E correct. There is no showall to apt-get, so option A is incorrect. The showpkg subcommand displays information about a named package; when used without a package, as in option B, it displays no data. The dpkg -f action removes a package, so option C would remove the package ailenpkg if it was installed. The dpkg -i action installs a package, so option D is incorrect—and that option doesn't list a package name, which the -i action requires.)

9. The update option to apt-get gets retrieval of new information, as described in option D. This is perfectly valid, contrary to option A's. apt-get program does not permit you to upload information to the Internet resources, so option B is incorrect. Option C describes the effect of upgrade or dist-upgrade options, not the update option. The upgrade or dist-upgrade options can upgrade APT itself, but update alone won't do the job, so option E is correct.

10. A. The yum's update and upgrade options are nearly identical in effect, and either can be used to upgrade an individual package, such as unzip, so options A and B are both correct. The primary command option to yum doesn't dashe, so options C and D are both incorrect. The check-update option to yum checks for the availability of updates but not install them, so option E is correct.
