# Appendix A · Answers to Review Questions

7. By default, man uses the less pager to display information on most Linux systems, option E is correct. Although an X-based version of man does exist (xman), the basic man doesn't use a custom X-based application (option A), nor does it use Firefox (option B) or the Vi editor (option D). The info command is a documentation system to man, option C is correct.

8. The redirection operator stores a command's output in a file, overwriting the contents of any existing file by the specified name, so option C is correct. Option A specifies the standard input redirection so ifconfig will take the contents of file txt as input. Option B is correct; the redirection operator redirects standard output, but appends to the specified file rather than overwriting it. Option D specifies a file; if the input is sent through the file txt program, if it exists (Chances are not, so you'd get a command not error message.) Option E redirects standard error, rather than standard output, to file, txt, and so is incorrect.

9. The redirection operator sends both standard output and standard error to the specified file (The name of the file, Input.txt, is intentionally deceptive, but use is still valid). Option A mentions standard error but describes it as if it were an input stream, which it's; an output stream. Option B mentions standard input, but the operator doesn't affect standard input. Because only option C is correct, neither option D E can be correct.

10. In pipe, you can pipe together many commands as you like. (In practice, there will be limits on input buffer size, memory, and so on, but these limits are higher than the 2, 3, 4, or 16 commands specified in options A, B, C, and D.)

11. The tee command sends its output to standard output and to a named file. Thus, placing the tee command (with an output filename) after another command and pipe will achieve the desired effect. Options A and D redirect getty's output to a file, which means you won't be able to see the output and interact with it. Option C sends the contents of getty-out.txt to getty as input, which isn't what's desired, either. Option E attempts to run getty-out.txt as a program and use it as its command-line arguments to gabby, which is not what desired.

12. The redirection operator redirects standard error only, leaving standard output unaffected. Sending error to /dev/null gets rid of it. Thus, option C is correct. Option A pipes the output of verbose through the quiet program, which isn't a Linux program. Option B sends both standard output and standard error to /dev/null, so you won't be able to interact with the program, as the question specifies you must be able to do. Option D redirects standard output only to the junk.txt file, so once again, interaction is impossible—and you'll get the unwanted error messages on the screen. Option E's quiet-mode program is fictitious (or at least non-standard), so option is is correct.

13. Option A correctly describes the difference between these two redirection operators. Option B is almost correct, but the >> operator will create a new file if one doesn't already exist. The >> operator does not redirect standard error (as stated in option C) or standard input (as stated in option D). Both operators will create a new file if one doesn't already exist, contrary to what option E states.
