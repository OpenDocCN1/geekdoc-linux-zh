# EXERCISE 6.1

# Printing with Linux

To perform this exercise, you must have a printer connected to your Linux computer—either a local printer or a network model. To perform some of the steps, you must also have root access to your computer so that you can manage the queue, follow these steps:

+   1. Launch a Web browser, enter http://localhost:631 as the URI, and then click the Printers tab. This should produce a list of printers, as in Figure 6.6. If the list is empty, you'll need to define at least one printer, as described earlier, before proceeding. If printers are defined and immediately take note of their names. For purposes of this exercise, I'll assume a queue named hp4000 exists; change this name in the following steps.

+   2. Type lpr -Ph4000 /etc/fstab to obtain a printout of this system configuration file. Verify that it is printed correctly.

+   3. Type lpq -Ph4000 to view the contents of the hp4000 queue. If you're using a single-user computer, the queue will be empty at this time.

+   4. Type lpr -Ph4000 /etc/fstab; lpq -Ph4000. This command prints another copy of /etc/fstab and immediately displays the contents of the print queue. It should not be empty this time, the job will have been submitted but won't have time to clear the queue by the time lpq executes.

+   5. In another shell, type su to obtain root access.

+   6. In your root shell, type cupsdisable hp4000. This action disables the queue; it will still accept jobs, but they won't print.

+   7. Type lpr -Ph4000 /etc/fstab to obtain another printout of /etc/fstab. Because the queue is disabled, it won't print.

+   8. Type lpq -Ph4000 to view the contents of the print queue. Now, instead of hp4000 is ready, lpq reports hp4000 is not ready; however, the job you submitted should appear in the queue. Suppose it has a job of 497.

+   9. Type lrm -Ph4000 497 (changing the job for your system).

+   10. Type lpq -Ph4000 to verify that the job has been removed from the queue.

+   11. Type cupsenable hp4000 in your root shell. This re-enables the queue.

+   12. Type lpr -Ph4000 /etc/fstab to print another copy of this file and verify that the printer is working again.

Using cupsdisable and cupsenable in this exercise has two purposes: to give you experience using these commands and to give you delete a job from the queue. A short file such as /etc/fstab can be printed quickly that you might not have time to remove it from the queue before it disappears because it's sitting in the printer's out tray!
