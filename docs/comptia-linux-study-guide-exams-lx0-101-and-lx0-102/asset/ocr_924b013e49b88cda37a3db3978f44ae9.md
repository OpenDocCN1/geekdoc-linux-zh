The most fundamental Linux commands have fairly short names—mv, ls, set, and so on. Some other commands are much longer, though, such as traceroute or same-find-scanner. Filenames can also be quite lengthy—up to 255 characters on many filesystems. Thus, command completion can save a lot of time when you're typing. It can also help you avoid typos.

Another useful shortcut is the history. The history keeps a record of every command you type. If you've typed a command recently and want to use it again or a minor variant of it, you can pull the command out of the history. The simplest way to do this is to press the Up key on your keyboard; this brings up the previous command. Pressing the Up key repeats multiple commands until you can find the one you need. If you overshoot, press the Down arrow to move down the history. Ctrl+P and Ctrl+N keystrokes do the Up and Down arrow keys, respectively.

Another way to use the command history is to search through it. Press Ctrl+R to begin a backward (reverse) search, which is what you probably want, and begin typing characters that should be unique to the command you want to find. The characters you type not need to be the beginning of the command; they can exist anywhere in the command. You can keep typing until you find the correct order, or after a few characters, Ctrl+S keystroke searches forwards in the command history, which might be handy if you use a backward search or the Up arrow key to look back and overshoot. In either event, if you can't find the command you want or you change your mind and want to terminate the search, press Ctrl+G to go so.

Frequently, finding a command in the history allows you to edit it. The bash shell, like many shells, provides editing features after those of the Emacs editor:

Move within the Line Ctrl+A or Ctrl+E to move the cursor to the start or end of the line, respectively. The Left and Right arrow keys move the cursor by a character at a time. Ctrl+B and Ctrl+F do the same, moving backward and forward within a line. Press Ctrl the left or right arrow key moves backward and forward a word at a time, pressing Esc and B or F.

Delete Text Press Ctrl+D or the Delete key deletes the character under the cursor, whereas pressing the Backspace key deletes the character to the left of the cursor. Pressing Ctrl+K deletes all text from the cursor to the end of the line. Pressing Ctrl+X and Backspace deletes all the text from the cursor to the beginning of the line.
