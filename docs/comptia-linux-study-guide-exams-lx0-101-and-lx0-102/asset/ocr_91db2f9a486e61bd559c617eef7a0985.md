# Converting Between Package Formats

Sometimes you are presented with a package file in one format, but you want to use another format. This is particularly common when you use a Debian-based distribution and can find only tar or RPM files of a package. When this happens, you can keep looking for a package file in the appropriate format, install the tools for the foreign format, create a package from a source tarball using the standard RPM or Debian tools, or convert between package formats with a utility like aian.

This section focuses on this last option. The aian program comes with Debian and a few other distributions, but may not be installed by default. If it's not installed install it by apt-get install aian on a system that uses APT, or use the Rpmfind or Debian Web site to locate it. This program can convert between RPM packages, Debian packages (used by Stampede Linux), and tarballs.

You need to be aware of some caves. For one thing, aian requires that you have appropriate package manager software installed—for instance, both RPM and Debian to convert between these formats. The aian utility doesnt always convert all dependency information completely correctly. When converting from a tarball, aian copies the files directly as they had been in the tarball, aian works only if the original tarball has files that should be installed off the root (/) directory of the system.
