Various measures were taken to combat this problem, one of which was the development of the Filesystem Standard (FSSTND), which was first released in early 1994. The FSSTND standardized several specific features, such as the:

+   - Standardized the programs that reside in /bin and /usr/bin. Differences on this score caused problems when scripts referred to one location or the other.

+   - Specified that executable files should not reside in /etc, as had been previously before.

+   - Removed changeable files from the /usr directory tree, enabling it to be mounted read-only (a useful security measure).

There have three major versions of FSSTND: 1.0, 1.1, and 1.2. FSSTND began to rein in the chaos in the Linux world in 1994. By 1995, however, FSSTND's limitations were becoming apparent. Thus, a new standard was developed: the Filesystem Hierarchy (FHS). This new standard is based on FSSTND extends it substantially. The FHS is more than a Linux standard; it may be used to define the layout of files on other Unix-like Oss.

One important distinction made by the FHS is between shareable and unsharable files. Shareable files may be reasonably shared between computers, such as user data files and program binary files (Of course, you don't need to share such files, but you may do so). If files are shared, they're normally shared through an NFS server. Unsharable files contain system-specific information, such as configuration files. For instance, you're not likely to share a server's configuration file between computers.

A second important distinction in the FHS is between static files and variable files. The former doesn' normally change except through direct intervention by the system administrator. Most executables are examples of static files. Variable files may be changed by users, automated scripts, servers, or the like. For instance, users' home directories and mail queues are composed of variable files. The FHS tries to isolate each directory into one of this 2 × 2 (shareable/unsharable × static/variable) matrix.
