Display Filesystem Superblock Information The show_super_stats or stats command produces superblock information, similar to dumpe2fs displays.

Display Inode Information You can display the inode on a file or directory by typing stat filename, where filename is the name of the file.

Undelete File You can use undelete a file by typing undelete name, where inode is the number of the deleted file and name is the filename you want to get. (You can use unde in place of unde if you like.) This facility is limited utility you must know the inode number associated with the deleted file. You can obtain a list of deleted inodes by typing Isdel or List_deleted_inodes, but the list may not provide enough clauses to let zero on the file you want to recover.

Extract a File You can extract a file from the filesystem by typing internal external-file, where internal is the name of a file in the filesystem you're manipulating and external-file is a filename on your main Linux system. This facility can be handy if a file is badly damaged and you want to extract a critical file without mounting the filesystem.

Manipulate Files Most of the commands described in Chapter 4 work within debugfs. You can change your directory with cd, create links with ln, remove a file with rm, and so on.

Obtain Help Typing list_requests, lr, help, or ? produces a summary of available commands.

Exit Typing quits the program.

This summary just scratches the surface of debugfs's capabilities. In the hands of an expert, this program can help rescue a badly damaged filesystem or at least critical data from it. To learn more, consult the program's man page.

> Although debugfs is a useful tool, it's potentially dangerous. Don't use on a mounted filesystem, don't use unless you have to, and be careful when using it. If in doubt, leave the adjustments to the experts. Be aware that the exam cover debugfs, though.

The closest XFS equivalent to debugfs is xfs_db. Like debugfs, xfs_db provides an interactive tool to access and manipulate a filesystem, but xfs_db provides fewer tools that are amenable to novice or intermediate use. Instead, xfs_db is a tool for XFS experts.
