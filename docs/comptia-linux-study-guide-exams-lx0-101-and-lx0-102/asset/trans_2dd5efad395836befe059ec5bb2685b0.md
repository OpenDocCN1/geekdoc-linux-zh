
## 526 附录 A：复习题答案

为了执行最基本的工作（包括文件系统），必须是可以访问的。/mnt 目录（选项 C）通常包含用于挂载软磁盘、CD-ROM 和其他移动介质的子目录，或者本身也可用于此目的。它很少用于直接访问硬盘分区，尽管可以用于此目的。/dev 目录（选项 E）通常对应于虚拟文件系统，它包含伪文件，但并不存储在分区上。

- 9. 0x0f 分区类型是扩展区的两种常见分区类型之一（另一个是 0x05）。0x82 指的是 Linux 分区，0x83 表示 Linux 文件系统，因此选项 A 正确。DOS、Windows 95/Me、Windows NT/200/XP、FreeBSD、B 和 E 都是错误的，Mac OS X 对其分区使用其他分区类型（Mac OS X 也安装在 MBR 磁盘上）。分区的存在是为了让不同的操作系统能够在同一块磁盘上并排存储它们的数据，在一个操作系统磁盘上混合多种分区类型不会导致磁盘损坏，因此选项 D 正确。

- 10. Linux 的 fdisk 在你通过输入 `w` 执行程序之前不会更改磁盘，输入 `q` 退出但不写入这些更改，在这种情况下输入 `q` 将导致灾难，选项 C 正确。输入 `w`（选项 B）将将是错误的做法。因为 fdisk 在你输入 `w` 之前不会更改你，损坏尚未造成，与选项 A 相反。输入 `u`（选项 D）或 `t`（选项 E）将没有任何用处，因为它们不是命令。

- 11. mkfs 命令创建一个新的文件系统，覆盖任何现有数据并导致文件无法访问，如选项 E 所示。该命令代码中不包含分区类型，因此选项 A 正确。mkfs 命令是破坏性的，与选项 B 相反。`-t ext2` 选项告诉 mkfs 创建一个 ext2 文件系统；它是完全有效的，因此选项 C 正确。虽然 mkfs 可以（破坏性地）将 ext2 转换为 ext4，但 `-t ext2` 选项明确表示正在创建一个 ext2 文件系统，因此选项 D 是

- 12. B. 尽管它们的名字和用途相似，但 Linux 的 fdisk 并不是模仿 DOS 的 FDISK 建模的，因此选项 B 正确，选项 A 不正确。DOS 的 FDISK 没有 GUI 控制，与选项 C 相反。Linux 的 fdisk 不格式化软磁盘，与选项 D 相反。两个程序都管理 MBR 磁盘，与选项 E 相反。

- 13. 交换分区没有挂载在文件系统中，因此它们没有关联的挂载点，因此选项 E 正确。

- 14. `-t` 选项并不告诉 fsck 使用哪种文件系统，因此选项 C 正确。（如果不使用此选项，fsck 会自动确定文件系统类型）。`-A` 选项（选项 A）导致 fsck 检查 `/etc/fstab` 中标记为要检查的文件。`-N` 选项（选项 B）告诉 fsck 不要采取行动，并显示它通常会做什么但不实际执行。`-C` 选项（选项 D）显示检查过程的文本模式进度指示。`-f` 选项（选项 E）是虚构的。

## 附录 A - 复习题答案

15. A. 默认使用 `df`报告磁盘空间的使用百分比（选项 D）以及每个文件系统的挂载点（选项 E）。inode 的数量（选项 B）和文件系统的数量（选项 C）都可以通过向 `df` 传递参数获得。该实用程序不报告文件系统挂载了多久（选项 A），因此选项是正确的。

16. D. 日志文件系统的日志会记录操作，从而在非正常关机后使磁盘检查速度更快，选项 D 正确。与选项 A 相反，带日志的文件系统作为一个大类，永远从不比非日志文件系统快；事实上，带日志的 ext3 是构建在非日志的 ext2fs 之上的。此外，非日志文件系统的磁盘检查比使用 `fsck` 更快，它们仍然需要定期运行，因此选项 B 正确。所有 Linux 原生文件系统都支持 Linux 所有权权限；这并不是带日志文件系统的优势，与选项 C 相反。带日志文件系统的日志不提供“撤销”功能，因此选项 E 正确。

17. 当没有指定文件系统类型时，`mount` 尝试自动检测文件系统类型。如果介质包含任何指定的文件系统，应该能检测到并挂载磁盘，选项 E 正确。

18. B. `/etc/fstab` 由包含设备标识符、挂载点、文件系统类型代码、dump 标志和文件系统频率的行组成。顺序 B 以正确的顺序提供了这些信息，因此可以工作。顺序 A 反转了第二和第三字段，这是正确的。选项 C、D 和 E 都反转了前三个字段，并且指定了 `noauto` 挂载选项，这会导致文件系统在启动时不自动挂载。

19. A, B, C. 在 `/etc/fstab` 中的 `user` 和 `owners` 允许所有普通用户挂载文件系统，但含义非常不同：`user` 允许挂载文件系统，但只有该用户可以挂载；`enable` 允许挂载文件系统，但仅可以卸载它；`owners` 只允许挂载点的所有者挂载或卸载文件系统。因此，选项 A、B 和 C 都是正确的。选项 D 的 `owners` 参数不存在。选项 E 的 `uid1000` 参数告诉 Linux 设置所有权，但它不允许用户挂载。`user` 选项允许非 root 用户挂载文件系统，因此选项 D 正确。
