# The X Configuration File Format

The X configuration file's name and location vary with the version of X be running:

**Xorg.X11** This server configuration file is called xorg.conf, and is usually stored in /etc/X11, although /etc and several other locations are also acceptable to the server.

![](bbox=[0.142, 0.551, 0.222, 0.599])

Many modern X.org-X11 configurations omit the X configuration file entirely, instead relying on run-time auto-detection of hardware. It often works, but if X doesn't work or if some of its features are set incorrectly you may need to generate an xorg.conf file by typing **Xorg -configure** when X is not running and edit the file manually, as described in subsequent sections.

XFree86 4.x The XFree86 4.x configuration file is called XF86Config-4 or XFree86Config, which is found in /etc/x1 or sometimes in /etc. This file's format is the same as for the Xorg.X11 configuration.

XFree86 3.3.6 and earlier The X configuration file is XFConfig, and the file is most located in /etc/X11 or /etc. Although the filename can be the same as XFree86 4.x, the file format is slightly different. This book, like the exam, covers the newer format used by X.org-X11 and XFree86 4.x.
