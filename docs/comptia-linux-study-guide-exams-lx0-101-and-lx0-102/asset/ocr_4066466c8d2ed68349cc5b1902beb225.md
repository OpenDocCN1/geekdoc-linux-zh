# Using File Management Commands

The copy-out and copy-in modes are named confusingly. Think of them as referring to copying out of or in the computer's main directory tree, rather than the archive file.

In addition to the options used to select the mode, cpio accepts many other options, the most important of which are summarized in Table 4.3. To create an archive, you combine the --create (or -c) option with one or more of the options in Table 4.3; to restore data, you do the same, but you use --extract (or -i). In either case, cpio acts on filenames that you type in the console. In practice, you'll probably use the redirection operator (<) to pass a filename to the program.

# TABLE 4.3: Options for use with cpio

| Option | Abbreviation | Description |
| --reset-access-time | -a | Resets the access time after reading a file so that it doesn't appear to have been read. |
| --append | -A | Appends data to an existing archive. |
| --pattern-filename | -E filename | Uses the contents of Filename as a list of files to be extracted in copy-in mode. |
| --filename | -F filename | Uses filename as the cpio archive file; if this parameter is omitted, cpio uses standard input or output. |
| --format=format | -H format | Uses a specified format for the archive. Common values for format include bin (the default), a (a newer binary format with a checksum), and tar (the format used by tar). |
| N/A | -I filename | Uses the specified filename instead of standard input. (Unlike -F, this option does not redirect data). |
| --no-absolute-filenames | N/A | In copy-in mode, extracts files relative to the current directory, even if filenames contain directory paths. |
| N/A | -O filename | Uses specified filename instead of standard output. (Unlike -F, this option does not redirect input data). |
| --list | -t | Displays a table of contents for the input. |
| --unconditional | -u | Replaces all files without asking for verification. |
| --verbose | -v | Displays filenames as they are added to or extracted from the archive. When used with -t, displays additional listing information (similar to ls -1). |
