Search To search for text in a file, type / in command mode, followed immediately by the text you want to locate. Typing ? searches backward rather than forward.

Change Text The c changes text from within command mode. You invoke it much like the d or y command, and in cc to change the next word or an entire line.

Go to a Line The G brings you to a line that you specify. The H key "homes" the cursor—that is, it moves the cursor to the top line of the screen. The L key brings the key to the bottom line of the screen.

Replace Globally To replace all occurrences of one string with another, :s/original/replacement/g, where original is the original string and replacement is its replacement. % to a starting line number, comma, and ending line number to perform this on a small range of lines.

Vi offers a great more depth than presented here; the editor is quite capable, and some Linux users are very attached to it. Entire books have been written about Vi. Consult one of these, or a Web page like http://www.vim.org, for more information.

# Saving Changes

To save changes to a file, :w from command mode. This enters ex mode and runs the command, which writes the file using filename specified when you launched Vi. Related commands enable other functions:

Edit a New File The e command edits a new file. For instance, e /etc/inittab loads /etc/inittab editing. Vi won't load a new file unless the one has been saved since its last date or unless you follow :e with an exclamation mark (!).

Include an Existing File :r command includes the contents of an old file in existing one.

Execute an External Command The ex-mode : executes the external command that you specify. For instance, typing :ls runs ls, allowing you to see what files are in the current directory.

Quit Use :q command to quit the program. With :e, this command won't work unless changes have been saved or you append an exclamation mark to quit the command (as in :q!).

You can combine such commands as to perform multiple actions in sequence. For instance, typing :wq writes changes and then quits from Vi. (ZZ is the equivalent of :wq).
