When you enter this information into your configuration files and type ifup eth0, you find that you can't access the Internet with your computer. Is this definitely true?

+   A. Because the server is on a completely different network, it won't function properly for your system. You should ask for the local network's DNS IP address.

+   B. The netmask identifies the gateway as being on a different network segment than the computer you're configuring, so the two can't communicate directly. You most likely misread one address.

+   C. Because the addresses involved are private IP addresses, there's no way for them to access the Internet. You must ask for public IP addresses for this system or use only your private network.

+   E. The ifup utility only works for computers that use DHCP, so the use of a static IP address as specified in the question won't work correctly.
