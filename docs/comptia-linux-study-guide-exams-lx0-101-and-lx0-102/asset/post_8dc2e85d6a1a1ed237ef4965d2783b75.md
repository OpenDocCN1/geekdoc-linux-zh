
# Appendix A - Answers To Questions

- 6. D, E. The cpio and tar programs are common Linux archive-creation utilities, so options D and E are both correct. The restore command restores (which does not back up) data; its backup command is dump. Thus, option A is incorrect. The vi command launches a editor; it is not used to create archives, so B is incorrect. There is no standard tape command in Linux, so option C is incorrect.

- 7. E. With the tar utility, the --ls (t) command is used to read the archive and display its contents. The --verbose (v) option creates a verbose listing, and --file (f) specifies the filename--data79.tar in this case. Option E uses all of these features. Options A, B, and D include all other commands for --ls, which is required by the question.

- 8. A. Symbolic links can point across filesystems, creating a symbolic link from one filesystem (when your home directory resides to another (on the CD-ROM)) isn't a problem, making option A correct. Hard links, as options B, C, and D, are restricted to a single filesystem and not used for the described purpose. Because symbolic links work as described, option E is incorrect.

- 9. E. Option D is the correct command. Typing chown tony:somefile.txt, as in option A, sets the owner of the file and the group to tony. The chmod command used in options B and D is used to change file permissions, not ownership. Option C reverses the order of the filename and the name.

- 10. C, E. The d character leads the mode indicates that the file is a directory (option C), and the r symbol in the rxr triplet at the symbolic mode indicates that all users of the system have read to the directory (option E). Symbolic links are denoted by l characters, which this mode lacks, so option A is incorrect. Although the x symbols usually denote executable files, as specified in option B, in the case of directories this permission indicates that the directory's contents may be searched; executing a directory is meaningless. SUID bits are indicated by an s character in place of the owner's execute bit in the symbolic mode. Since this position holds an x in this example, option D is incorrect.

- 11. C. The set user ID (SUID) enables programs to run as the program's owner rather than as the user who ran them. This makes SUID root programs risky, setting the SUID bit on root-owned programs should be done only when it's required for the program's normal function, stated in option C. This should clearly not be for all programs because the SUID bit is not required of executable programs as option A asserts. Although the SUID root configuration enables programs to access device files, the devices' permissions can be modified to give programs access to those files, if this is required, so option B is incorrect. Although SUID root programs are a security risk, as stated in option D, they're a necessary risk for a few programs. Many file should not be SUID run by root, so option E is incorrect.

- 12. E. Using symbolic modes, the r+ option adds read (r) permissions to the world (o). Thus, option E is correct. Option A sets the mode to rwxr------, which is a bit odd and doesn't provide world read access to the file, although it does provide world execute access. Option B sets the mode to rw-----, which gives the world no access whatsoever to the file. Option C adds read access to the file for the owner (u) if the owner doesn't already have this access; it doesn't affect the world permissions. Option D removes read access for all users, so it's incorrect.

- 13. Option D, D 027, removes write permissions for the group and all world permissions. (Files normally don't execute permissions set, but explicitly removing writing when removing permissions ensures reasonable behavior for directories.) Option D, 640, is the octal equivalent of the desired rw---- permissions; but the mask sets the bits that are to be removed from permissions, not those that are to set. Option B, 210, would remove write permission for the owner, but wouldn't remove write permission for the group, which is incorrect. It would also leave world permissions open. Option C, 022, wouldn't remove read permission. Option E, 138, is an invalid mask, as all digits in it must be between 0 and 7.

- 14. Using quotas requires kernel support, the usquota or grquota (for user or group quotas) filesystem mount option, and activation via the quota command (which often appears in system startup scripts). Thus, E is correct. Option A suggests that quota is not necessary, which is correct. Option B's statement that grquota is invalid is incorrect. Option C's statement that these options disable quota support is correct. The usquota and grquota options are both valid, so option D is incorrect.

- 15. The repent utility is used to summarize the quota information for the filesystem. When used with the –a, it shows information for all filesystems, so option B is correct. This command won't return useful information when typed alone, so option A is incorrect. The quotacheck utility checks quota information about a disk and writes corrections. The edquota utility enables you to edit quota information. It doesn't summarize quota information, and isn't a valid option to edquota. Thus, option E is correct.

- 16. The /opt directory exists to hold programs that aren't a standard part of a Linux distribution, such as commercial programs. These programs should install in their own directories under /opt; these isn't required. Thus, option D is correct (that is, it's a plausible possibility). The /usr/sbin directory holds programs that are run only by the system administrator, so it's not a location, making option A incorrect. The /etc/X11 directory holds configured files, so it's very unlikely that WonderCalc will be housed there, option B incorrect. The /boot directory holds critical system files, the /sbin directory, like /usr/sbin, is an unlikely location for user files, so option E is incorrect. (Furthermore, /sbin contains subdirectories.)

- 17. The find utility (option A) operates by searching all files in a directory, and so it's likely to take a long time to search all of a computer's directories. The locate program uses a precompiled database, where searches a limited set of directories, and type searches the shell's path and built-in commands, so these commands will take less time. Thus, options B, C, D, and E are all incorrect.

- 18. C. The type command identifies a command, as the shell, being built-in command, or an external command, whereas where helps find the location of files. Thus, option C is correct. Neither type identifies the CPU architecture of a program, can locate commands based on intended purpose, or identify a binary or script; the remaining options are incorrect.

- 19. B. The find command includes the ability to search by username using the -user option, where name is the username; option B is correct. The -uid option to find files owned by a user, but it takes a user ID (UID) number as an argument, option A isn't correct. The locate command provides no ability to search by user, options C and D are incorrect.

- 20. D. The which command searches the path just as, but it prints the path to the first executable it finds. Thus, option D is correct. The which command doesn't conduct an exhaustive search of the system, or could be many files called the system, to option A. /usr/bin/man may be run when the user whose output matches that in the question types man, this may not be true of others because the path can vary from one to another. Thus, option C is incorrect. The which program doesn't reveal file information, so option E is incorrect.

- 1. C. The Master Boot Record (MBR) can contain a boot loader that is up to 446 bytes in size, option C is correct. If more space is required, the boot loader must load a secondary loader. Although the boot loader is loaded into RAM (option A), it's not stored permanently RAM is volatile storage. /dev/boot and /dev/kmem (options B and D) are references to files on filesystems; they are meaningful only the BIOS has found a boot loader and run it and lots of other boot processes have occurred. The swap partition (option E) is used as an adjunct to the MBR; the BIOS does not look for a boot loader.

- 2. C. Runlevel 1 is single-user mode, and adding the digit 1 to the kernel's lines in a boot loader will launch the system in this runlevel, option C is correct. Options A and B present invalid kernel options and are so incorrect. Although the telinit command specified in options D and E will change the runlevel the computer is running and runlevel 1 is a single-user mode, these commands are not passed to the kernel via a boot loader, so these options are both incorrect.
