# EXERCISE 5.1

# Changing Runlevels

This exercise will demonstrate the effects of changing the runlevel in various ways on a working system. Be aware that some of the effects will be different from one system to another, depending on both the distribution and the system-specific configuration of the computer. Also, in the course of running this exercise, you'll reboot the computer, so you shouldn't it on a system that anyone else is using. To manage your runlevels, follow these steps:

+   1. Log in root, or acquire root privileges by using su or by sudo using each of the following commands. Use a text-mode or remote login; some of the activities will shut down X.

+   2. Type runlevel to learn your runlevel. Recall that the first character returned to the previous runlevel (N denotes no runlevel; it hasn't changed since the system booted). The second output character is the current runlevel. This is likely to be 2 on Debian or Debian-derived systems and 3 or 5 on Red Hat or Red Hat-.

+   3. If your system reports it's in runlevel 5, type telinit to switch to runlevel 3. Chances are your X server will stop working. (Pressing Alt+F7 from a text-mode console will show a blank text-mode screen rather than the X display this keys would normally reveal).

+   4. If your system initially started a runlevel of 3, type telinit to switch to runlevel 5. This will probably cause the screen to blink two or three times and possibly display an error message. If X isn't installed, nothing will help you, aside from a display about a few services stopped and started. If X starts, you can get back to your text-mode console by pressing Ctrl+F1.

+   5. If your system reported it is in runlevel 2, you can turn other runlevels, such as 3, 4 or 5; however, this isn't likely to have much effect. You can temporarily stop X by typing `/etc/init.d/gdm start` or `/etc/init.d/gdm stop`. (You may need to change gdm to mdm, or kdm).

+   6. Return to your original runlevel using telinit, as in telinit 5.

+   7. If your distribution uses /etc/initab and sets the default runlevel to 5, edit that file and change the default runlevel by changing the number in the line that reads id:n:initdefault:. The *n*, is likely to be either 3 or 5; change it to the other
