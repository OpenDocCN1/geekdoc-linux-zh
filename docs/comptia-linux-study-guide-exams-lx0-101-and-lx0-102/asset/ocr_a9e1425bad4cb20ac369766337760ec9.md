# Preparing a File for Printing with pr

If you want to prepare a plain-text file, you may want to prepare it with headers, footers, page
breaks, and so on. The pr command was designed to do this. In its most basic form, you
pass the command file:

```
$ pr myfile.txt
```

The result is formatted for printing on a line printer—that is, pr assumes an 80-character
line in a monospaced font. Of course, you can also use pr in a pipe, to accept
input piped from another program or to pr its output to another program. (The recipient)
program might be 1pr, which is used to print files, as described in Chapter 6,"Configuring
t X Windows System, Localization, and Printing."

By default, pr creates output that includes the original text with headers that include the
Current date and time, the original filename, and the page number. You can tweak the
output format in a variety of ways, including the following:

Generate Multi-column Output Passing the --numcols or --columns=numcols option
creates output with numcols. Note that pr doesn't reformat text, if lines are too
long, they are truncated or run over into multiple columns.

Generate Double-Spaced Output The -d or --double-space option creates double-spaced
output from a single-spaced file.

Use Form Feed Ordinarily, pr separates pages using a fixed number of blank lines.
This works fine if your printer uses the same number of lines as pr expects. If you have
problems with this issue, you can pass the -F, -f, or --form-feed option, which causes pr
to a form-feed character between pages. This works better with some printers.

Set Page Length The -1 lines or --length=lines option sets the length of the page in
lines.

Set the Header The -h text or --header option sets the text to be displayed in
header, replacing the filename. To specify a multi-word string, enclose it in quotes, as
--header="My File". The -t or --omit option hides the header entirely.

Set Left Margin and Width The -0 chars or --indent=chars option sets the
margin by chars characters. This margin size is added to the page width, which defaults to
72 characters and can be explicitly set with the -w chars or --width chars option.
