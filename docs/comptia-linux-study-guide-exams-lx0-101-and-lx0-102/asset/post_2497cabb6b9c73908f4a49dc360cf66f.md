### Printing to Network Printers

If your network hosts many Windows computers, you may use the Server Message Block/ Common Internet File System (SMB/CIFS) for file and printer sharing among Windows systems. Linux's Samba server also implements this protocol and can be used for sharing printers from Linux.

On the flip side, you can print to an SMB/CIFS queue from a Linux system. To so, select an SMB/CIFS queue in the printer configuration tool. When CUPS, it is called Windows Printer via SAMBA in step 2 in the preceding procedure. You must then provide your username, password, server name, and share, but the format isn't obvious from the Web-based configuration:

```
smb://username:password@SERVER/SHARE
```

This is a URI for SMB/CIFS share. You must substitute appropriate values for username, password, server, and SHARE, of course. Once this is and you've finished the configuration, you should be able to submit print jobs to the SMB/CIFS share.

> SMB/CIFS printers hosted by Windows systems are usually non-Postscript models, so you must select a Linux smart filter and Ghosts driver, just as you would for a local printer. Printers hosted by Linux systems running Samba, by contrast, are frequently configured to act like Postscript printers, so you should select a PostScript driver when connecting to them.

If you want to print to a Unix or Linux server that uses the lpd protocol, the URI format is simple but lacks your username and password:

```
lpd://hostname/queue
```

You can use the same format, but substitute ipp://lpd://, to print to a CUPS server if browsing is disabled on your network.

In practice, you may be faced with a decision: Should you use LPD, IPP, or SMB/CIFS for submitting print jobs? To be sure, not all printers support all protocols, and a Linux server may support them all. As a general rule, IPP is the simplest to configure because it supports browsing, which means CUPS clients shouldn't need explicit configuration to handle specific printers. This makes IPP the best choice for Linux-to-Linux printing, assuming both systems run CUPS. When CUPS isn't in use, LPD is generally easier to configure than SMB/CIFS, and it has the advantage of not requiring the use of a username or password to control access. Because SMB/CIFS security is password-oriented, clients typically store passwords in an unencrypted form on the hard disk. This fact can become a security liability, particularly if you use the same account for printing as other tasks. On the other hand, sometimes using a password on the server provides more of a

## Monitoring and Controlling the Print Queue

You can use several utilities to submit print jobs and to examine and manipulate a print queue. These utilities are lpr, lpq, lprm, and lpc. All of these commands can take the -p parameter to operate on specific queue.

### Printing Files with Lpr

Once you've configured the system to print, you probably want to start printing. As mentioned earlier, Linux uses the lpr command to submit print jobs. This program accepts many options that you can use to modify the printer's:

- **Specify a Queue Name** The -Pqueename option enables you to specify a print queue. This is useful if you have several printers or if you defined several queues for one printer. If you omit this option, the default printer is used.

![](img/35f616c7eba479e12bf762129c5d27_372_0.png)

> In the original BSD version of lpr, there should be no space between -P and the queename. Linux and CUPS are more flexible in this respect; you can insert a space or omit as you see fit.

- **Delete the Original File** Normally, lpr sends a copy of the file into the queue, leaving the original unharmed. Specifying the -r option deletes the original file after printing.

- **Suppress the Banner** The -h option suppresses the banner for a single print job. Early versions of CUPS didn't support this, but recent versions do.

- **Specify a Job Name** Print jobs have a name to identify them, while they are in the queue and they're printed (if the queue is configured to print banner jobs). The name is normally the first of the file print job, but you can change it by using the -J jobname option. The -C and -T options are synonymous with -J.

- **Notify by Email** The -m username option causes lpd to send email to username when the print job is complete. This option was unavailable in early versions of CUPS but available in recent versions.

- **Specify the Number of Copies** You can specify the number of copies of a print job by the -# number option, in -#3 to print three copies of a job.
