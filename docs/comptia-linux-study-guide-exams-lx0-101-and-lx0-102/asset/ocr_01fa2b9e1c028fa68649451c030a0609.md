2. D. The XF86Config xorg.conf file design enables you to variant or multiple components and combine or recombine them as necessary, using the structure specified in option D. Options A, B, and C describe fictitious structures. Option E is incorrect because the Org-X11 and XFree86 configuration files use a text-mode structure, not a binary structure.

3. C. The vertical refresh rate range includes a maximum value, but that value may be reduced when the resolution and vertical refresh rate would demand a higher horizontal refresh rate than the monitor can handle. Option C is correct. Since the resolution affects the maximum refresh rate, option A is incorrect. The color depth is irrelevant to resolution and refresh rate calculations, option B is incorrect. The computations in option D and E are bogus, making these options incorrect.

4. E. Option E describes the correct location for this. The ServerLayout section (referenced in option A) combines all the other options but doesn't set the resolution. The Modeline option in the Monitor section (as described in option B) defines one possible resolution, but there may be several Modeline entries defining many resolutions, and there is no guarantee that any of them will be used. The Modeline option does not exist in the Device section (as suggested by option C), nor is it that where there is no DefaultResolution section (as referenced in option D).

5. B. By maintaining fonts on one font server and pointing other X servers to that font server, you can reduce the administrative cost of maintaining the fonts on all the systems, so option B is correct. Font servers do not produce displays than X's local handling; if the opposite is true. Thus, option D is incorrect. XFree86-x supports TrueType fonts, so option O is incorrect. Converting a bitmapped display into ASCII text of optical character recognition (OCR) software, not a font server, so option D is incorrect. Neither X core fonts nor a font server handles smoothing; for that, there is no Xft. Thus, option E is incorrect.

6. E. XDMCP servers are launched either from a system script or by init (as specified in /etc/initab, as described in options C and E. The XDMCP server starts X. The Stored folder mentioned in option A is a Windows structure, not a Linux structure. The /.xinitrc script mentioned in option B is an X login script starting X from the command line via start; it's not to automatically start X when the system boots. A boot manager, as described in option D, launches the kernel; it doesnt directly start X, so option D is incorrect.

7. The XDM greeting is a resource in the /etc/X11/xdm/Resources file, so option E is correct. XDM does not offer many options on its main screen and certainly not one to change its settings, as described in option A. The kernel does directly handle the login process, nor does it pass options directly to XDM, so option B is incorrect. Although the xorg.conf file mentioned in option C is real, this provides no XDM configuration options because XDM is a separate program from the X server. There is no xdmconfig program, as mentioned in option D.
