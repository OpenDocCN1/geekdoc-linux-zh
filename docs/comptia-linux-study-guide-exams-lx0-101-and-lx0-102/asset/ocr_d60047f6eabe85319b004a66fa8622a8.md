The BIOS boot process begins by reading a boot sector (typically the first sector) from a disk and executing that code. Thus, boot options for BIOS-based computers are limited; you can only select the order in which various boot devices (hard disks, floppy disks, optical, USB devices, and so on) are examined to find a boot sector.

Under UEFI, the boot process involves reading a boot loader from a filesystem on a special partition, known as the EFI System Partition (ESP). This file either can take a special default name or be registered in the computer's NVRAM. Thus, UEFI users often present an extended range of boot options, involving both flash boot loaders from various devices (to enabling granting to a bootable USB drive, for example) and multiple boot loaders on the computer's hard disks. Primitive EFI implementations, though, present simple BIOS-like boot options.

> Many EFI implementations support a BIOS compatibility mode and can be boot media intended for BIOS-based computers. This feature, intended to help in the transition from BIOS to EFI, can configure setup and OS installation because it creates extra boot options that users often don't understand.

Although sequences involving removing devices are common, they have their problems. For instance, if somebody accidentally leaves a floppy disk in the drive, this can prevent the system from booting. Using removing disks as the boot media also opens the door to intruders who have physical access to the computer; they only need to reboot with a bootable media (or CD-ROM in the case of your of system) to gain complete control of your system. For these reasons, it's better to make the first disk (or a boot loader on a hard disk's ESP, in the case of EFI) the only boot device. (You must change this configuration when installing Linux or using another boot environment.) Most modern computers frequency temporary changes by providing a special key to allow one-time change to the boot sequence. On older computers, to change the boot sequence, you must locate the appropriate firmware option, and reboot the computer. It's usually located in an advanced menu, like this.
