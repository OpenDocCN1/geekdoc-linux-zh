# Creating Partitions and Filesystems

Delete a Partition To delete a partition, type d. If more than one partition exists, the program will ask for the partition number, which you must enter.

Change a Partition's Type When you create a partition, fdisk asks for a type code of 083, which corresponds to a Linux filesystem. If you want to create a Linux swap partition or a partition for another OS, you can type t to change a partition type. The program prompts you for a partition number and a type code.

List Partition Types Some dozen partition codes exist, so it's easy to forget what they are. Type L (that's a lowercase L) at the fdisk prompt to see a list of the most common ones. You can also get this list by typing L when you're prompted for the partition when you change your partition's code.

Mark a Bootable Some OSs, such as DOS and Windows, rely on their partitions having special flags in order to boot. You can set this flag by typing a, whereupon fdisk asks for the partition number.

Get Help Type m or to see a summary of the fdisk commands.

Exit Linux's fdisk support two exit modes. First, you can type q to exit the program without saving changes; anything you do with the program is lost. This option is particularly helpful if you made a mistake. Second, typing w writes your changes to the disk and exits the program.

As an example, considering a primary, an extended, and a logical partition on a USB drive and creating a new one in their place:

```
# fdisk /dev/sdc
```
