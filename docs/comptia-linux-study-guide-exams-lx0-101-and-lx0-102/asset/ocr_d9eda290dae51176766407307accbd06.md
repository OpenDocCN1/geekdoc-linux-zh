# # Summary

X is Linux's GUI system. In part because of Linux's modular nature, X isn't a single program; you have your choice of X servers to run on Linux. Fortunately, most Linux distributions use the X server as all others (X.org-X11). Both X.org-X11 and its main competitor, XFree86, are configured in the same way, using the xorg.conf (for X.org-X11) or XFree86conf configuration file. Whatever its name, this file consists of sections, each of which controls X subsystem, such as the mouse, the keyboard, or the video card. This file also controls X's core fonts, but you can use a font server in addition to this; and most programs are now emphasizing a new font system, Xft, instead of X core fonts. For this reason, Linux font configuration can be complex.

X's GUI login system uses XDMCP server, which starts and manages the X system. Default XDDM servers are common in Linux, the most important being KDM, XDM, and GDM. They all perform the same basic tasks, but configuration details differ. X is also less sophisticated than KDM and GDM. X is a network-enabled GUI, which means you can use an X server to access programs running on another. Doing so requiring a few steps for each log session. You can also tunnel X accesses through SSH, which greatly improves the security of the connection.

An assortment of tools can help Linux more accessible to users with visual or motor impairments. You can adjust font size, screen contrast, and other display features to improve legibility; use screen magnifiers to help users read part of a larger screen; or screen readers for tactile output. On the input side, you can adjust keyboard repeat rates, use sticky keys, or modify mouse tracking speed and sensitivity to improve users' ability to input data accurately. You can even have a mouse stand for a keyboard or vice versa by using appropriate software.

The second main output tool on computers is a printer, and Linux provides sophisticated printer support. The CUPS package manages printers in Linux by accepting local or remote print jobs, passing them through a smart filter for processing, and queuing the jobs so that they print in a reasonable order. Most CUPS configuration is best handled via its own Web interface, but some options (particularly security features) can be set via configuration files.

# # Exam Essentials

Name the major X servers for Linux. XFree86 has been the traditional standard Linux server, but in 2004 X.org-X11 (which was based on XFree86) rapidly gained prominence as the new standard Linux X server. Accelerated-X is a commercial X server that supports video cards that aren't supported by XFree86 or X.org-X11.
