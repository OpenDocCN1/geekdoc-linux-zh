

# 理解网络地址

- IPv6 包含一项新功能，称为无状态地址自动配置 (SAC)，它简化了初始网络设置。该功能在某些方面与 IPv4 中常用的动态主机配置协议 (DHCP) 相似（DHCP 也可以用于 IPv6；其在本地网络配置中效果最佳）。
- IPv6 引入了 IP 安全安全 (IPsec) 工具，这些工具可以提高互联网连接的安全性。IPsec 已经回溯到 IPv4。
- IPv6 简化了某些数据结构，使路由器能够更快地处理。

还存在一些更晦涩的差异。可以访问 http://en.wikipedia.org/wiki/IPv6 或 http://www.ipv6forum.com 获取有关 IPv6 的详细信息。

IPv6 正在世界许多地区作为一种新的网络力量兴起。美国在 IPv6 部署方面落后于潮流。Linux 内核包含了对 IPv6 的支持，许多发行现在尝试在配置 IPv4 的同时也自动配置 IPv6 网络。很有可能，等到普通办公室需要 IPv6 时，它已经成为标准。为 IPv6 配置系统与为 IPv4 配置系统略有不同，这正是本文强调的重点。

为了让计算机在网络上相互通信，计算机需要某种方式来彼此引用。实现这一点的基本机制是网络地址，根据硬件类型、协议栈等可以采取多种形式。大型网络和路由网络对网络地址带来了额外挑战，而 TCP/IP 为这些挑战提供了答案。最后，为了位远程计算机上的特定程序，TCP/IP 使用端口号，它用于识别特定的运行程序，类似于电话分机号用于识别大公司中的个人。接下来的章节将描述所有这些地址方法。

# 使用网络地址

以以太网网络为例。当一个以太网帧离开一台计算机时，它通常指向另一块以太网卡。这种地址是使用底层以太网功能完成的，独立于所涉及的协议栈。然而，请记住互联网是由许多使用许多不同底层硬件组件的网络组成的。用户可能有一个拨号电话连接（通过串口），但连接到一个使用以太网的服务器和另一个使用令牌环（Token Ring）的服务器。每个设备都使用不同类型的底层网络地址。TCP/IP 需要某些东西来整合不同类型的网络硬件。在尝试理解网络地址时，总共有三类地址非常重要：网络硬件地址、数字 IP 地址和基于文本的主机名。

# 地址

专用网络硬件（如以太网或令牌环卡）的特点之一是，它们内部预程序了唯一的硬件地址，也称为介质访问控制 (MAC) 地址。在以太网的情况下，这些地址长度为 6 字节，通常表示为用冒号分隔的十六进制（十二进制）数字。你可以使用 `ifconfig` 命令发现以太网卡的硬件地址。当执行 `ifconfig ethn` 时，其中 `n` 是接口编号（第一块卡为 0，第二块为 1，以此此类推），你会看到几行输出，如下所示：

```
eth0 Link encap:Ethernet hwaddr 00:A0:CC:24:BA:02
```

这一行告诉你该设备是一个以太网卡，其地址为 00:A0:CC:24:BA:02。它是有什么用的？某些底层网络工具和硬件使用硬件地址。例如，网络交换机使用它来引导数据包。交换机检测到特定地址连接到特定的线缆，因此它仅在相关的线缆上发送指向该地址的数据。在后续章节“使用 DHCP 配置”中描述的动态主机配置协议 (DHCP) 是自动配置特定计算机的手段。它有一个选项可以使用硬件地址为给定的计算机一致分配 IP 地址。此外，还有高级网络诊断工具可以让你检查来自或发往特定硬件地址的数据包。

在大多数情况下，你不需要感知计算机的硬件地址。在大多数工具或程序中你都不输入它。但它的通用功能很重要。

Linux 使用特定类型的代码识别网络硬件设备。对于大多数发行版，以太网硬件是 ethn，其中 n 是从 0 开始的数字。第一个以太网设备是 eth0，第二个是 eth1，以此此类推。（Fedora）

# 管理 IP 地址

网络掩码（也称为子网掩码或网掩）是一个用于识别 IP 地址中哪些是网络地址、哪些是计算机部分的数字。用二进制（二进制）思考这非常有帮助，因为它使用二进制 1 值表示地址的网络部分，并使用二进制 0 值表示计算机部分。网络部分位于计算机部分之前。用十进制表示时，这些地址通常由 255 或 0 值组成，255 是网络字节，0 是计算机值。如果一个字节部分是网络地址部分是计算机地址，它将具有其他值。图 8.3 说明了这种关系，IP 地址为 172.30.9.102，网掩为 255.255.0.0。
