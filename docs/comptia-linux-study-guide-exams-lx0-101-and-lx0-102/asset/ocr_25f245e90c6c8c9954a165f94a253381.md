A Linux-only long filename system, known as umdos, provides additional Linux features—enough that you can install Linux on a FAT partition, although this practice isn't recommended except for types of emergencies or to try Linux on a Windows system.

NTFS The New Technology File System (NTFS) is the preferred filesystem for Windows NT/2000/XP/Vista/7. Unfortunately, Linux's support is rather rudimentary. As of the 2.6.x kernel series, Linux can reliably read NTFS and can overwrite existing files, but the Linux kernel can't write files to an NTFS partition.

> If you have good NTFS read/write support for a dual-boot system, look into NTFS-3G (http://www.ntfs-3g.org). This is a read/write NTFS driver that resides in user space rather than in kernel space. It's used by the default NTFS driver by some Linux distributions.

HFS and HFS+ Apple has long used the Hierarchical File System (HFS) with its Mac OS, and Linux provides full read/write support. This support isn't as reliable as Linux's FAT support, so you may want to use FAT when exchanging files with Mac users. Apple has extended HFS to support large hard disks and many Unix-like features with its HFS+(aka Extended HFS). Linux 2.6 and newer provide limited HFS+ support; but write works only with the HFS+ journal disabled.

ISO-9660 The standard filesystem for CD-ROMs has long been ISO-9660. This filesystem comes in several levels. Level 1 is similar to the original FAT in that it supports only 8.3 filenames. Level 2 and 3 add support for longer-character filenames. Linux uses ISO-9660 with its iso9660 filesystem type. Linux's ISO-9660 also works with the Rock Ridge extensions, which are a series of extensions to ISO-9660 to enable it to support Unix-style long filenames, permissions, symbolic links, and so on. Similarly, Joliet provides support for long filenames as implemented in Windows. If a disk includes Rock Ridge or Joliet, Linux will automatically detect and use them.

As a practical matter, if you're preparing a hard disk for use in Linux, you should use Linux filesystems only. If you're preparing a disk that will be for a dual-boot configuration, you may want to set aside partitions for other filesystem types. For removable disks, you'll have to be the judge of what's most appropriate. You might use ext2fs for a Linux-only removable disk, FAT for a cross-platform disk, or ISO-9660 (perhaps with Rock Ridge and Joliet for a CD-R or recordable DVD).
