Thus, the permission string rwxrxr-x means the file's owner, members of the group, and all other users can read and execute the file. Only the file's owner has permission to the file, or even easily exclude those who don't belong to the file's owner, by changing the permission string, as described in "Changing a File's Mode" later in this chapter.

Individual permissions, such as execute for the file's owner, are often referred to as permission bits. Linux uses this information in binary format. Because it is binary, permission information can be expressed as a 9-bit number. This is usually expressed in octal (base 8) because base-8 is 3 bits length, which means the base-8 representation of a permission string is three characters long; one character for each of the owner, group, and world permissions. The read, write, and execute permissions correspond to one of these bits. The result is you can determine owner, group, or world permissions by adding base-number: 1 for execute, 2 for write, and 4 for permission.

Table 4.5 shows some examples of common permissions and their meanings. This table is necessarily incomplete; with 9 permissions, the total number of possible permissions is 2^9, or 512. Most of those possibilities are peculiar, and you're not likely to encounter or create them by accident.

# TABLE 4.5 Example permissions and their likely uses

| Permission string | Octal code | Meaning |
| --- | --- | --- |
| rwxxrwxwx | 777 | Read, write, and execute permissions for all users. |
| rwxrxr-x | 755 | Read and execute permission for all users. The file's owner also has write permission. |
| rwxrxr----- | 750 | Read and execute permissions for the owner and group. The file's owner also has write permission. Users who aren't the file's owner or members of the group have no access to the file. |
| rw------ | 700 | Read, write, and execute permissions for the file's owner only; all others have no access. |
| rw-rw-rw- | 666 | Read and write permissions for all users. No execute permissions for anybody. |
| rw-rw-r-- | 664 | Read and write permissions for the owner and group. Read-only permission for all others. |
| rw-rw---- | 660 | Read and write permissions for the owner and group. No world permissions. |
