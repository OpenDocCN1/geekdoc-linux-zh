# Appendix A - Answers to Review Questions

+   9. The logrotrate program uses a configuration file called /etc/logrotrate.conf (option A), which includes several default settings and typically refers to files in /etc/logrotrate, to handle specific log files. The remaining options are fictitious, at least as working files for logrotrate.

+   10. The logger utility can be used to create a one-time log file that you specify. In simple format, it takes no special arguments, just a message to be inserted in the log file, as in option D. The dmesg utility is used to review the kernel log buffer; it doesn't create log entry files. Option B's syslog command is not a Linux user-mode command, although it is the name of the logging system generally, as well as a programming language name. Option C's rsyslog daemons maintains the system but isn't used to insert log entries. Option E's wall commands a message to all users' terminals. Although you might want to use wall before shutting down to alert users of this, it won't create a log entry file as the question asks.

+   11. The logrotate program can be started automatically—and unattended—on a regular basis by adding an entry to it cron, option C is correct. The utility (option A) would be used if you wanted the program to run only once. Logrotate (option B) defines how the program is to handle specific log files. The inittab file (option D) is used for services and not for individual programs. The ntpd daemon, which synchronizes the system's clock with outside time sources.

+   12. The hwclock utility is used to set the hardware clock. The --utc option tells it to use UTC, which is appropriate for a Linux-system, and --systc sets the hardware clock based on the current value of the software clock. Thus, option E is correct. Option A's date can be used to set the software clock but not the hardware clock; it has no--setclock option. Option B's ntdate is used to set the software clock to the time maintained by an NTP server; Option C's clock utility is fictitious. Option D's time command is used to measure how long a command takes to complete; it has no--set or--hw option and does not set the hardware clock.

+   13. The format of the date's command is date [MMDDhhmm[[CC]YY][.ss]]. Given that the specified question is eight-digit-code, this means the ordering of the items, in two digits, month-day-hour-minute. Option C parses this order, whereas options B, C, D, and E do not.
