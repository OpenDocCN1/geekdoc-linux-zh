# FIGURE 8.3 TCP/IP addresses are combined with a netmask to isolate the network address.

| IP Address | | |
|---|---||
| 172.30.9.102 | 10101100 00011110 00001001 01100110 |
| Netmask | 255.255.0.0 | 11111111 11111111 00000000 00000000 |
| Network Address | 172.30.0.0 | 10101100 00011110 00000000 00000000 |

Another way of expressing a netmask is a single number representing the number of network bits in the address. This number usually follows the IP address and a slash. For instance, 172.30.9.102/16 is equal to 172.30.9.102 with a netmask of 255.255.0.0—the last number shows the network portion to two solid 8-bit bytes and is 16 bits. The longer notation using all 4 bits of the mask is referred to as *dotted quad notation*. IPv6 networks work just like IPv4 networks, except that larger numbers are used instead IPv4, IPv6 addresses use hexadecimal decimal notation.

On IPv4 networks, netmasks are often described in *Classless Inter-Domain Routing (CIDR)* form. Each network can be broken at any bit boundary for any address. For instance, 172.168.1.7 could have a netmask of 255.255.0.0, 255.255.255.0, 255.255.255.255, or other values. (Keeping each bit at 0 or 255 reduces the odds of human error causing problems but seems impractical, depending on the required or desired sizes.) Traditionally, IPv4 networks have been broken into one of several classes, summarized in Table 8.1. Classes A, B, and C are for general networking use. Class D addresses are reserved for *multicasting*—sending data to multiple computers simultaneously. Class E addresses are reserved for future use. There are special cases within some of these ranges. For instance, the 127.x.y.z addresses are reserved for *loopback* (aka *localhost*) addresses—these addresses refer to the computer on which the address enters. Addresses in which all the machine bits are set to 1 refer to the network block itself—they’re used for broadcast address 255.*255.*, which sends data to all computers on a network segment. (Routers normally block packets delivered to this address. If they didn't, the Internet could easily be brought to knees by a few people flooding the network with broadcast packets.)
