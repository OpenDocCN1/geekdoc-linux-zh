# Setting the Monitor

Some of the trickiest aspects of X configuration relates to the monitor options. You set these in the Monitor section, which can sometimes be quite large. A modest Monitor section looks like this:

Section "Monitor":

| Identifier | "Monitor0" |
| ModelName | "AOC e234Fk" |
| HorizSync | 30.0 - 83.0 |
| VertRefresh | 55.0 - 75.0 |
| # My 1920x1080 mode |
| Modeline | "1920x1080" 138.50 1920 1968 2000 2080 1080 1083 1111 |

EndSection

As in the keyboard and monitor configurations, the Identifier is a free-form string that contains to identify a monitor. The Identifier can be just anything you want. Likewise, the ModelName option can be anything you like; it's used mainly for your own edification when reviewing the configuration file.

As you continue the section, you'll see the HorizSync and VertRefresh lines, which are extremely critical; they define the range of horizontal and vertical refresh rates that the monitor can accept, in kilohertz (kHz) and hertz (Hz). Together, these values determine the maximum resolution and refresh rate. Despite the name, the HorizSync item alone doesn't determine the maximum horizontal refresh rate, the VertRefresh value, and the resolution determine the monitor's maximum refresh rate. X selects the maximum refresh rate that the monitor will support given the resolution you specify in orders. Some X configuration utilities show a list of monitors or refresh rate combinations (such as "1024x768 at 72Hz"). You select an option, and the utility then computes the correct values based on selection. This approach is often simpler to handle, but it's less precise than entering the exact horizontal and vertical sync. You should enter these values from your monitor's manual.

> WARNING Don't set random horizontal and vertical refresh rates; on older hardware, setting values too high can damage a monitor. (Modern monitors ignore signals presented at too high refresh rate.)
