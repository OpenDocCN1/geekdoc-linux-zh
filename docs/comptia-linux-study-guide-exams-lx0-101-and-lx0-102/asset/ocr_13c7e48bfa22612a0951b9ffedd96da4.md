Option A would be rude and pointless, although this type of request is used by some administrators when receiving mail from known sites, as to degrade spam operations. +   14. C. The Fetchmail program is a tool for retrieving email from POP or IMAP servers and injecting it into a local (or remote) SMTP email queue. As such, it is not an SMTP server, option C is correct. Postfix (option A), sendmail (option B), Exim (option D), and qmail (option E) are all SMTP email servers for Linux.

+   15. B. The -s option to mail sets the subject line, and -c sets carbon copy (cc :). Input redirection (<) reads the contents of a line into mail as message. A mail command line normally terminates with the primary recipient. Thus, option B correctly describes the effect of the specified line. Options A, C, D, and E are all confused in their interpretation of the effects of mail parameters. Options B and D also confuse input and output redirection, and option A incorrectly suggests that a script (or mail program) can change its status to root privileges.

+   16. D. SMTP servers accept mail for delivery if their Internet connections are down. If the SMTP server cannot connect recipient servers, the SMTP server holds the mail and attempts delivery later, option D is correct. Because SMTP servers don't check for the availability of remote servers until email is accepted for delivery, option A is incorrect. Option B cannot be correct unless there is a backup Internet connection, which wasn specified in the question. Option C is incorrect because the SMTP server will hold the mail and attempt delivery later. How recipients retrieve their mail is not under their control, option E is incorrect
