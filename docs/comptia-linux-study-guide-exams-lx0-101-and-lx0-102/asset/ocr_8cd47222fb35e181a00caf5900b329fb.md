# TABLE 8.2 Port numbers, their purposes, and typical Linux servers (continued)

| Port number | TCP or UDP | Purpose | Example Linux servers |
|---|---|---|--|
| 111 | TCP and UDP | Portmapper | NFS, NIS, other RPC-based servers |
| 113 | TCP | auth/ident | ident |
| 119 | TCP | Network News Transfer Protocol (NNTP) | InterNetNews (INN), Diablo, Leaf-node |
| 139 | TCP | NetBIOS Session (Windows file sharing) | Samba |
| 143 | TCP | Interactive Mail Protocol (IMAP)¹ | Dovecot, Cyrus IMAP, UW-IMAP |
| 161 | UDP | Simple Network Management Protocol (SNMP) | Net-SNMP |
| 177 | UDP | XDMCP | XDM, KDM, GDM |
| 389 | TCP | LDAP | OpenLDAP |
| 443 | TCP | HTTP over SSL (HTTPS) | Apache, Roxen |
| 445 | TCP | Microsoft Directory Services (DS) | Samba |
| 465 | TCP | SMTP over SSL; or Rendezvous Directory (URD)² | Sendmail, Postfix, Exim, qmail; or network routers |
| 631 | TCP | Internet Printing Protocol (IPP) | Common Unix Printing System (CUPS) |
| 993 | TCP | IMAP over SSL | Dovecot, Cyrus IMAP, UW-IMAP |
| 995 | TCP | POP-3 over SSL | Dovecot, Opopper, pop3d |
| 5900+ | TCP | Remote Framebuffer (RFB) | Virtual Network Computing (VNC): OpenVNC, TightVNC, TigerVNC |
| 6000–6007 | TCP | The Window System (X) | X.org-X11, XFree86 |

¹Some expand IMAP as Internet Message Access Protocol or Internet Mail Access Protocol.
²Port 465 is officially registered for URD; it's also commonly used as a secure email delivery port, although this isn't the officially designated purpose of this port.
