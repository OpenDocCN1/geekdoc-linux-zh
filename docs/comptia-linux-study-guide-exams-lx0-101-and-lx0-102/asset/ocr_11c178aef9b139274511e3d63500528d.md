# Exam Essentials

Summarize methods of creating and modifying user accounts. Accounts can be created or modified with the help of tools designed for the purpose, such as useradd and usermod. Alternatively, you can directly edit the /etc/passwd and /etc/shadow files, which hold the account information.

Describe the function of groups in Linux. Linux groups enable security features to be applied to arbitrary groups of users. Each group holds an arbitrary collection of users, and group permissions can be set on them, giving all group members the same access rights to the files.

Explain the purpose of the skeleton files. Skeleton files provide a core of configuration files that should be present in users' home directories when those directories are created. They provide a starting point for users to modify their important shell and other configuration files.

Summarize how to configure system logging. System logging is controlled via the /etc/syslog.conf file. Lines in this file describe what types of log data, generated by programs, are sent to logs and to which file the log messages go.

Describe how log rotation is managed. Log rotation is controlled via the /etc/logrotate.conf file (which typically refers to /etc/logrotate.d). Entries in these files tell the system to rotate logs at fixed intervals or when they reach certain sizes. When a log rotates, it is renamed (and possibly compressed), a new log file is created, and the oldest log file may be deleted.

Explain the two types of clocks in x86 and x86-64 hardware. The hardware clock keeps time when the computer is powered down, but it is used by most programs when the computer is running. Such programs refer to the software clock, which is set from the hardware clock clock when the computer boots.

Summarize the function of NTP. The Network Time Protocol (NTP) enables a computer to set its clock based on the time maintained by an NTP server system. NTP can function as a tiered protocol, enabling one system as a client to an NTP server and as server to additional NTP clients. This structure enables a single highly accurate time source to be used by anywhere from a few to (theoretically) billions of computers via a tiered system.

Explain the difference between system and cron jobs. Cron jobs from /etc/crontab, are created by root, and may be run as any user (but most commonly as root). System cron jobs are typically run at certain times on an hourly, daily, weekly, or monthly basis. Cron jobs may be created by any user (various security measures permitting), are run under the authority of the account with which they're associated, and may be run at just about any interval desired.
