# Learning Kernel Modules

Hardware in Linux is managed by kernel drivers, which of many are in the form of kernel modules. These are stand-alone driver files, typically stored in the /lib/modules directory tree, that can be loaded to provide access to hardware and unloaded to disable such access. Typically, Linux loads the modules when it boots, but you may need to load modules yourself.

You can learn about the modules that are currently loaded on your system by using ismod, which takes no options and produces output like this:

```
$ ismod
```
