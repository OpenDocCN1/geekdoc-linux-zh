# Chapter 4 • Managing Files

Of the three compression tools, gzip is the oldest and provides the least compression, bzip2 provides improved compression, and xz is the newest and provides the best compression. Typically, files compressed with these utilities have .gz, .bz2, or .xz extensions, respectively. Tarballs use their own special extensions, such as .tgz for gzip or .tb for one compressed with bzip2.

An example of tar in use, consider archiving and compressing the my-work subdirectory of your home directory to a USB flash drive mounted at /media/pen. The following command will do the:

```
$ tar cvfz /media/pen/my-work.tgz ~my-work
```

If you transfer this flash drive to another system, mount it at /media/usb/ and to extract the archive, you can do so with another command:

```
$ tar xvfz /media/usb/my-work.tgz
```

Instead of using the compression options, you can use a pipe to connect a compression tool to tar when extracting data. For instance, gunzip -c tarball.tgz | tar xvf uncompresses tarball.tgz.

The preceding command creates a subdirectory my-work in the current directory and populates it with the files from the archive. If you don't know what's in an archive, it's a good practice to examine it with the --list command before extracting its contents. Tarballs usually contain a single subdirectory, sometimes tarballs contain many files without a “carrier” subdirectory. Extracting such tarballs drops these files in your current directory, which can make it difficult to determine which files come from the tarball and which were already present.

# The cpio Utility

The cpio program is similar to tar, but the details of its operation differ. With tar, you can direct its output to a tape device or to a regular file. Backing up a tape device can be a convenient way to back up the computer because it requires no intermediate storage. To restore data, you use cpio to read directly from the tape file or a regular file.

The cpio utility has three operating modes:

**Copy-Out Mode** This, activated by the -o or --create option, creates an archive and copies files into it.

**Copy-In Mode** You activate copy-in mode by the -i or --extract option. This mode extracts data from an existing archive. If you provide a filename or a pattern to match, cpio extracts only the files that match the pattern you provide.

**Copy-Pass Mode** This is activated by the -p or --pass-through option. It combines the copy-out and copy-in modes, enabling you to copy a directory tree from one location to another.
