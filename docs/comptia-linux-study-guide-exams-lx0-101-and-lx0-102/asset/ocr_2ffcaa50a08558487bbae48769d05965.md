In practice, some important utilities, such as the useradd program described in "Adding Users," impose more restrictive rules. These rules disallow uppercase letters and most punctuation characters, although you can get away with an underscore (_) or dot (.), a dollar sign ($) as the last character is permitted. Furthermore, some utilize usernames longer than 8 characters; for this reason, administrators limit username length to 8 characters.

Assuming you create accounts with mixed-case usernames, Linux treats usernames in a case-sensitive way. Therefore, a single-computer can lead a great deal of confusion, so separate users. It's best to avoid creating accounts with usernames differ only in case. The traditional practice is to entirely lowercase usernames in Linux systems, such as sally, e1len, and george. Usernames don't need to be based on first names, course you could use _jones, s.jones, sjones, jones7, or dt6 to name just a few possibilities. Most sites develop a standard method of creating usernames, such as using the first and last name. Creating and following such a pattern can help you locate an account that belongs to a particular individual. If your computer has many users, though, you may find a naming convention produces duplicates, particularly if your standard is to shorten usernames. You may be forced to deviate from the standard or incorporate numbers to distinguish between the Davids or Smiths of the world, because each account requires a unique username.

# Linking Users Together for Productivity via Groups

Linux groups use a means of organizing users. In many ways, groups parallel users. They’re defined in similar configuration files, have names similar to usernames, and are represented by numbers (as are accounts).

Groups are not accounts, Rather, groups are means of organizing accounts, largely as a security measure. Every file on a Linux system is associated with a specific user and a specific group, and various permissions can be assigned to members of that group. For instance, group members (such as a faculty at a university) may be disallowed to read a file, but others (such as students) may be allowed. Because Linux provides access to most hardware devices (such as scanners and backup units) through files, you can also use this mechanism to control access to hardware.

Every has from no members to many members as there are users on the computer. Group membership is controlled through the /etc/group file. This file contains a list of groups and the members belonging to each group. The details of this file are described in "Configuring Groups."

In addition to membership in /etc/group, each user has a default or primary group. The user’s primary group is set in the user’s configuration in /etc/passwd (the file that defines accounts). When users log onto computer, their group membership is set to their primary group. When users create files or launches, those files and running programs are associated with a single group—the current group membership. A user can access files belonging to other groups as the user belongs to that group and the group access permissions permit the access.
