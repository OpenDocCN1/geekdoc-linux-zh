# Answers to the Assessment Test

26. D. lsmod (option D) produces a list of the modules that are currently loaded. The insmod (option A) and modprobe (option C) programs both load modules—either a single module or single modules and all on which it depends, respectively. The depmod (option B) generates the .dep file that contains module dependency information. The modinfo (option E) displays information, such as its version number and, on a single module. For more information, please see Chapter 3, "Configuring Hardware."

27. B. E. The chgrp and chmod commands can change the group ownership of a file. The chgrp command takes a group name and a filename, as parameters, in option B. The chmod command normally changes a file owner; if you provide a group name preceded by a dot (.) or a colon (:), as in option E, it changes the group of a file. The command shown in option A will change the primary ownership of the file to the user who exists on the system; it won't change the group ownership. There is no standard chgrp command, as in option C. Option D will change the permissions to 0600 (--rw--), which will be a backward step with respect to the goal state. For more information, please see Chapter 4, "Managing Files."

28. Hard links to directories are not permitted by many filesystems, so you'll probably have to create a symbolic link, as noted in option E. Links don't rely on a filesystem journal, so option A is incorrect. To contrary option B, anybody may create a link, not just the owner's owner. Option C describes a restriction of hard links; but because this link will have to be a symbolic link, this restriction is unimportant and option C is incorrect. Option D describes a more severe restriction than option B, but it's incorrect for the same reasons. For more information, please see Chapter 4, "Managing Files."

29. B, E. The colon (:) starts mode, from which you can enter commands. In mode, r includes a file in an existing one, w writes a file, e loads an entirely new file, and q quits the program. Thus, the desired combination is :wq. For a special case, ZZ does the same thing, so option E is also correct. For more information, please see Chapter 5, "Booting Linux and Editing Files."

30. C. The "/ forward file is a user email forwarding. The vertical bar (|) at the start of a file is code to send the email through the specified program file, so option C is correct. To do option A describes, the file would need to read junkme@hostname, where hostname is the computer's hostname. To do option B describes, the leading vertical bar would have to be omitted. It is conceivable that the "/junkme script describes, way of knowing this for certain. To do as option E describes, the file would have to read user@junkme, where user is the username. For more information, please see Chapter 9, "Writing Scripts, Configuring Email, and Using Databases."
