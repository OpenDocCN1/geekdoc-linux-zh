# The cp Command

The cp command copies a file. Its basic syntax is as follows:

```
cp [options] destination
```

The source is normally one or more files, and the destination may be a file (when the source is a single file) or a directory (when the source is one or more). When copying to a directory, cp preserves the original filename; otherwise, it gives the new filename indicated by destination. The command supports a large number of options; see man page for more information. Some of the useful options enable you to modify the command's operation in helpful ways:

Force Overwrite The -f --force option forces the system to overwrite any existing files without prompting.

Use Interactive Mode The -i or --interactive option causes cp to ask you before overwriting any existing files.

Preserve Ownership and Permissions Normally, a copied file is owned by the user who issues the cp command and uses that account's default permissions. The -p or --preserve option preserves ownership and permissions, if possible.
