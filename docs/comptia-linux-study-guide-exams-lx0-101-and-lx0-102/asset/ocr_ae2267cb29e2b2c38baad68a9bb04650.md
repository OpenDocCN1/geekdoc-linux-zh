# Using RPM

In cases, using Yum is easier than using RPM directly to manage packages, because Yum finds the latest available package, downloads it, and installs any required dependencies. Yum has its limits, though; it's only good as its repositories, so it can't install software that's not stored in those repositories.

![](bbox=[0.143, 0.206, 0.237, 0.246])

If you use Yum to automatically upgrade all packages on your system, you're effectively giving control of your system to the distribution maintainer. Although Red Hat or other distributions are unlikely to try to break into your computer in this way, an automatic update with minimal supervision on your part could easily break something on your system, particularly if you've obtained packages from unusual sources in the past.

If you don't want to install the package but want to obtain it, you can use downloader. This command by name of the package, and the latest version of the package will be downloaded to the current directory. This can be handy if you need to update a system that's not connected to the Internet; you can use another computer that runs the same distribution to obtain the packages and transfer them to your target system.

If you prefer to GUI tools rather than command-line tools, you should be aware that GUI front-ends exist yumex and kym. You can use the text-mode yum to install these front-ends. Exercise 2.1 runs you through the process of managing packages using the rpm utility.
