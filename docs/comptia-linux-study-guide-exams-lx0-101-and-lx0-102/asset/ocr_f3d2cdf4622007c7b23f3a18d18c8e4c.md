# Conventions Used in This Book

This book uses certain typographic styles in order to help you identify important information and to avoid confusion over the meaning of words as on-screen prompts. In particular, look for the following styles

+   * *A monospaced font* indicates indicates the contents of configuration files, messages displayed at a text-mode Linux shell prompt, filenames, text-mode command names, and Internet URLs.
* *Italicized monospaced* indicates a variable—information that differs from one system or command to run on another, such as the name of a client processor or a process ID number.
* **Bold monospaced text** is information that you're to type into the computer, usually at a Linux shell prompt. This text can also be italicized to indicate that you should substitute an appropriate value for your system. (When isolated on their own lines, commands are preceded by non-monospaced $ or or # command prompts, denoting regular user or system administrator use, respectively.)
