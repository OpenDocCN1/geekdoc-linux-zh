# Adding Fonts to X’s Font Path

Once you've set up fonts in a directory and created a fonts.dir file describing them, you must add the fonts to the X font path. You do this by editing the Files section of the XF86Config or xorg.conf file:

Section "Files":

```
FontPath /usr/share/fonts/100dpi:unscaled
FontPath /usr/share/fonts/Type1
FontPath /usr/share/fonts/truetype
FontPath /usr/share/fonts/URW
FontPath /usr/share/fonts/Speedo
FontPath /usr/share/fonts/100dpi
```

EndSection

![](bbox=[0.137, 0.4, 0.225, 0.444])

To add your new font directory to the font path, duplicate one of the existing FontPath lines, and change the directory specification to point to your new directory. The order of these directories is significant: when matching fonts, X traces each directory in turn, so if two fonts hold of the same name, the first one takes precedence. Thus, if you want your new fonts to override any existing fonts, place the new directory at the top of the list; if you want fonts to take precedence, add your directory to the end of the list.

> The :unscaled string in the first entry in the preceding example tells X to use bitmap fonts from this directory only if they exactly match the requested font size. Without this string, X will attempt to scale bitmap fonts from a directory (with poor results). Typically, bitmap directories are listed twice: once near the top of the font path with the :unscaled specification and again near the bottom of the list with : This produces quick display of matching mapped fonts, followed by any matching fonts, followed by scaled bitmaps.
