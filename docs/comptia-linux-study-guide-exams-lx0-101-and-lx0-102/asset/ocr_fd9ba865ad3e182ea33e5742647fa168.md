# Managing Disk Quotas

Just one user of a multi-user system can cause serious problems for others by consuming too much disk space. If a single user creates huge files (say, multimedia recordings), those files can use enough disk space to prevent others from creating their own files. To manage this situation, Linux supports disk quotas—limits, enforced by the OS, on how many files or how much disk space a single user may consume. The Linux quota system supports quotas for individual users and for Linux groups.

# Enabling Quota Support

Quotas require support in both the kernel for the filesystem being used and various user utilities. The ext2fs, ext3, ReiserFS, JFS, and XFS filesystems support quotas, but this support is missing for some filesystems in early 2.6.x kernels. Try using the latest kernel if you have preferred filesystem. You must explicitly enable support via the Quota Support option in the filesystem area when recompiling your kernel. Most distributions have this support enabled, recompiling your kernel may not be necessary, but you should be aware of this option if you recompile your kernel.
Two general quota support systems are available for Linux. The first was used through the 2.4 kernel and referred to as the quota v1 support. The second was added with the 2.6 kernel and is referred to the quota v2 system. This description applies to the latter system, but the former works in a similar way.
Outside of the kernel, you need support tools to use quotas. For the quota v2 system, this package is usually called quota, and it installs a number of utilities, configuration files, system startup scripts, and so on.

You can install the support software from source code, if you like; however, this job is handled most easily using a package for your distribution. This description assumes that you install the software in this way. If you don't, you may need to create startup scripts to initialize the quota when you boot your computer. The Quota Mini-HOWTO, at http://en.ldp.org/HOWTO/Quota.html, provides details of how to do this.

You may modify your /etc/fstab entries for any partitions on which you want to use quota support. In particular, you must add the usquota filesystem mount option to employ user quotas and the grquota option to employ group quotas. Entries that are so configured resemble following:

```
/dev/sdc5 /home ext3 usquota,grpquota 1 1
```

This line activates both user and group quota support for the /dev/sdc5 partition, which is mounted at /home. Of course, you can add other options if you like.
