# Configuring X Base Features

XFree86 The dominant server in Linux 2004 was XFree86 (http://www.xfree86.org). This open source software supports a wide array of video cards and input devices, and Linux software was originally designed with XFree86. As I wrote, the most recent version is 4.8.0. Significant changes occurred between 3.3.6 and the 4.x series, and some older users work only with the 3.3.6 and earlier versions of XFree86. Although a thin number of elderly systems must run XFree86 3.3.6 or earlier for driver support reasons, most systems today run XFree86 4.x or X.org-X11; the latter is more common on distributions released since 2004.

X.org-X11 In 2004, most distributions shifted from XFree86 to X.org-X11 because of licensing changes to XFree86. X.org-X11 6.7 was based on XFree86 4.39, but it independently developed up to the current version, 7.7. Because X.org-X11 is based on XFree86, the two are virtually identical in most important respects. One significant difference is the name of the configuration file; another is the default location for fonts. Subsequent sections of this chapter point out these differences. You can learn more at http://www.x.org/wiki/

Accelerated-X The commercial Accelerated-X server from Graphics (http://www.xig.com) is an alternative to the open source XFree86 and X.org-X11. In practice, running Accelerated-X is seldom necessary, but if you have problems getting your video card working, you may want to look into Accelerated-X; its driver is independent of the more popular open source choices, it's possible you'll have better luck with it. The Accelerated-X tools and files are completely different from those described in "Methods of Configuring X" and "X Configuration Options," so you'll need to consult its documentation for help.

In practice, it is easiest to stick with whatever server your distribution provides. For modern distributions, this is most often X.org-X11. For a handful of elderly video cards, you may need to run the equally elderly XFree86 3.3.6 rather than a more recent version.

# Real World Scenario

# Using Manufacturer-Provided Video Drivers

One of X's functions is to provide drivers that control the video card. XFree86, X.org-X11, and Accelerated-X all ship with a wide variety of drivers that support most video cards. Some cards, though, have weak support in the stock packages. Other cards are supported by the standard drivers, which don't support all of the video device's features. XFree86 4.x and X.org-X11 both support a modular driver architecture, which means you can drop in a modular driver for your card and use with minimal changes to your configuration. Both AMD (formerly ATI) and nVIDIA provide video card drivers designed to work with XFree86 and X.org-X11. (Both servers can use the same drivers.) Thus, if you have problems with the standard X drivers, you may want to check with your video card manufacturer and the video card chipset manufacturers for Linux drivers.
