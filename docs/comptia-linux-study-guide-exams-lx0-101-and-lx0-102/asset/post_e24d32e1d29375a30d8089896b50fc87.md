You can add a new entry to fstab by typing it in its entirety or by duplicating an existing line and then modifying one copy. To do it first, follow these steps:

- 1. Move the cursor to the beginning of the /dev/sda3 line using the arrow keys.
- 2. Press the O (letter O, not zero) key. This opens a new line immediately below the current line, moves the cursor to that line, and enters insert mode.

> Although Vi's commands may seem arcane, many of them are mnemonic in their own way—that is, they're designed to be easily erased, as in the letter O for open line.

- 3. Type a new entry, as as follows:
  `/dev/sdb1 /home ext4 0 0`
- 4. Press the Esc key to return to command mode.

To practice making changes by modifying an existing entry, follow these steps:

- 1. Move the cursor to the beginning of the /dev/sdb1 line you have created using the arrow keys, if necessary; you should see the cursor resting on the first /dev/sdb1.

> You can use the h, j, k, and l keys to move left, down, up, and right, respectively, if you prefer not to use the arrow keys.

- 2. You must now yank one line of text. This term is used in most text editors—you copy the text to a buffer from which you can later paste back into the file. To yank text, use the yy command, preceded by the number of lines you want to yank. Thus, type 1yy (do not press the Enter key, though). The dd command works like my yy, but it deletes the lines as well as copying them to a buffer. Both yy and dd are special cases of the y and d commands, respectively, yank or delete text in amounts specified by the next character, as in dw delete the next word.

- 3. Move the cursor to the line before the one you want the new line to appear.
- 4. Type p (again, without pressing the Enter key). Vi pastes the contents of the buffer starting on the line after the cursor. The file should now have two identical /dev/sd1 lines. The cursor should be resting at the start of the second one. If you want to paste the text into the document starting on the line before the cursor, use an uppercase P command.
- 5. Move the cursor to 1 in /dev/sd1 on the line you've just pasted. You are about to begin customizing this line.

- 6. Until now, you've operated Vi in command mode. You can use any of several commands to enter insert mode. At this point, the most appropriate mode is R, which enters insert mode so it's configured for text replacement rather than insertion. If you prefer to insert rather than overwrite, you can use i or a (the latter advances the cursor one space, which is sometimes useful at the end of a line). For the purposes of these instructions, type R to enter insert mode. You would see -- REPLACE -- appear in the status line.

- 7. Type 2 to change /dev/sd1 to /dev/sd2.
- 8. Use the arrow keys to move the cursor to the 2 in /home2. You must modify this mount point name.
- 9. Type 3 to change /home2 to /home3.

> You can make more extensive changes to the fstab file, if you like, but sure to work from a copy of the file!

- 10. Exit insert mode by pressing the Esc.
- 11. Save the file and quit by typing :wq. This is an ex command, as described shortly (The ZZ command is equivalent to :wq).

Many additional commands are available that you may want to use in some situations. Here are the highlights:

**Change Case**: Suppose you need to change the case of a word in a file. Instead of entering insert mode and retyping the word, you can use the tilde key in command mode to change the case. Position the cursor on the first character you want to change, and press repeatedly until the task is done.

**Undo**: To undo any change, type u in command mode.

**Open Text**: In command mode, typing o (a lowercase O) opens text—that is, it inserts a new line immediately before the current one and enters insert mode on that line.

**Search**: To search for text in a file, type / in command mode, followed immediately by the text you want to locate. Typing ? searches backward rather than forward.

**Change Text**: The c changes text from within command mode. You invoke it much like the d or y command, and in cc to change the next word or an entire line.

**Go to a Line**: The G brings you to a line that you specify. The H key brings you to a line that you specify.

**Replace Globally**: To replace all occurrences of string with another, :s/original/replacement/g.
