+   4. Ordinary, Linux runs init (option B) as the first program; init then runs, via various

it call, typically during the startup, but it's not the first program that
kernel runs. LILO is an older boot loader for Linux on BIOS systems, and init (option E)
is the command that installs this loader to the MBR. Since boot loaders run before the
kernel loads, this option is incorrect.
