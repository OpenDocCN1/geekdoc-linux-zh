If you're not sure what to enter for the basic networking values (IP address, network gateway, DNS server addresses), you should consult your network administrator. Do not enter random values or values you make up that are similar to those used by other systems on your network. Doing so is unlikely to work at all, and it could conceivably cause a great deal of trouble—say, if you mistaken an IP address that's reserved for another computer.

As just mentioned, the ifconfig program is critically important for setting both the IP address and network. This program can also display current settings. Basic use of ifconfig to bring up a network interface enables the following:

```
ifconfig interface up addr mask
```

For instance, the following command brings up eth0 (the first Ethernet device on most distributions) using the address 192.168.29.39 and the netmask 255.255.255.0:

+   # ifconfig eth0 up 192.168.29.39 mask 255.255.255.0

This command links the specified IP address to the device that computer responds to the address and claims to be that address when sending data. It doesn't, though, set up a route for traffic beyond your current network. For that, you need to use the route command:

+   # route add default gw 192.168.29.1

Substitute your gateway address for 192.168.29.1. (Routing and the route command are described in more detail shortly, in "Configuring Linux.") Both ifconfig and route can display information on the current network configuration. For ifconfig, omit and everything that follows; for route, omit and everything that follows. For instance, view interface configuration, you might issue the following command:

+   # ifconfig eth0
