Both the RPM and Debian systems provide all of these basic features, although the details of their operation differ. These two package systems are incompatible with one another in the sense that their package files and their installed file databases are different; you can't directly install an RPM package on a Debian-based system or vice versa. (Tools to convert formats do exist, and developers are working on ways to better integrate the two package formats.)

> Most distributions install one package system. It's possible to install more than one, though, some programs (such as *alien*) require both for full functionality. Using both systems to install software is inadmissible because their databases are separate. If you install a library using a Debian package and then try to install an RPM package that relies on that library, RPM won't realize that library is already installed and will return an error.

# Using RPM

The most popular package manager in the Linux world is the RPM Package Manager (RPM). RPM is also available on non-Linux platforms, although it seems less use outside the Linux world. The RPM system provides all the tools described in the preceding section, "Package Concepts," such as a package database that allows for identifying conflicts and ownership of particular particles.

# RPM Distributions and Conventions

Red Hat developed RPM for its own distribution. Red Hat released the software under the General Public License (GPL), however, others have free to use it in their own distributions—and this is precisely what has happened. Some distributions, such as Mandriva (formerly Mage) and Yellow Dog, are based on Red, so they use RPMs as many other parts of the Red Hat distribution. Others, such as SUSE, borrow from the Red Hat template, but they use RPMs. Of course, all Linux distributions share many components, even those that weren't originally based on Red Hat are very similar to it in many ways other their use of RPM packages. On the other hand, distributions that were originally based on Red Hat have drifted over time. As a result, the group of RPM-using distributions shows substantial variability, but all of them are Linux distributions that provide the same basic tools, such as the Linux kernel, shells, an X server, and so on.

Red Hat has splintered into three distributions: Fedora is the downloadable version favored by home users, students, and businesses on a tight budget. The *Red Hat* name is now reserved for the for-pay version of the distribution, known more formally as Red Hat Enterprise Linux (RHEL). CentOS is freely redistributable version intended for enterprise users.
