# The locate Command

The locate utility works like if you want to find a file by name, but it differs in two important ways:

+   - The locate tool is far less sophisticated in its search options. You normally use it to search only on filenames, and the program returns all files that contain the specified string. For instance, searching for rpm, locate will return other programs, grep and rpm2cpio.

+   - The locate program works from a database that it maintains. Most distributions include a cron job that calls updatedb to update the locate database, periodically, such as once a night or once a week.(You can also use the updatedb command, which is configured via the /etc/updatedb.conf file, to do this task at any time.) For this reason, locate may not find recent files, or it may return the names of files that no longer exist. If the database-update utilities omit certain directories, files will not be returned by a locate query.

Because locate works from a database, it's typically faster than, particularly on system-wide searches. It's likely to return many false alarms, especially if you want to find a file with a short name. If you use it, locate search-string, where search-string is the string that appears in the filename.

> Some Linux distributions use slocate rather than locate. The locate program includes security features to prevent users from seeing the names of files in directories they shouldn't be able to access. Most systems that use slocate, the locate command is a link to slocate, so locate implements slocate's security features. A few distributions do not install either locate or slocate by default.

# The which Command

The which program searches for files in a restricted set of locations, such as standard binary directories, library directories, and man page directories. This tool does not search user directories or many other locations that are easily searched by find or locate. The which utility is a quick way to find program executables and related files like documentation or configuration files.
