21. A, B. The -uv parameter (option A) issues an upgrade command (installs the program whether or not an earlier version is installed) and creates a series of hash marks to display the command's progress. The -i parameter (option B) installs the program if is not already installed but causes no progress. Option C uses a package name, not a complete filename, and it will fail to install the package file. The -e option (option D) removes a package. Option E:-vp verifies the package file but does not install it. For more information, please see Chapter 2, "Managing Software"

22. B. Option B, fsck, is Linux's filesystem check utility. It is similar to option D, but these DOS and Windows CHDSK and ScanDisk utilities (similar to options C and D), but those DOS and Windows units do not work on Linux filesystems. Option A, mkfs, creates new filesystems; it does not diagnose or fix filesystem problems. Option E, fdisk, is a tool for creating or modifying partitions; it not manage the filesystems they contain. For more information, please see Chapter 3, "Configuring Hardware"

23. A. A freshly installed MySQL database is unlikely to have a ready-made database of animals, so your first task is to create that database with the CREATE DATABASE command, as shown in option A. You could call the database something other than animals. The USE command in option B will be useful only once the database has been created. Once the database is created, you can use CREATE TABLE, in option C, to create a table; however, you'll need to index this database, which also requires information about the type of data to be stored, which option C doesn't provide. Option D's INSERT command stores data into a table once it's created, which's far from the first command you'll use. It also requires additional specification of the data to be stored, so it's important. Option E's UPDATE command modifies existing entries, so you would use this only after you've created the database and added at least one animal to it. Option E is an incomplete command even then. For more information, please see Chapter 9, "Writing Scripts, Configuring, and Using Databases."

24. B, D. The correct answers, man and info (option C and D), are two common Linux packages. Help? is a common command within interactive programs, it isn't a help command in bash or other common Linux shells. There is no command called manual (option A) nor is help (option E) a valid bash or command program name. For more information, please see Chapter 1, "Exploring Linux Command-Line Tool"

25. A, C. Unix systems traditionally store time in UTC (at Greenwich Mean Time), and Linux may do as well. Thus, option A is correct. Most x86 OS traditions store time as the local time, which is correct. Internet Time (option B) is an alternative to the 24-hour clock in which the day is broken into 1,000 "beats." Standard PC BIOSs don't support this time format. Likewise, a 12-hour clock isn't terribly useful to computers because it doesn't differentiate a.m. from p.m., making option D incorrect. Although the length of the Martian day is similar to that of Earth (24 hours and 37 minutes), those wanting to colonize Mars will have to set time for the Red Planet; option E is incorrect. For more information, please see Chapter 7, "Administering the System"
