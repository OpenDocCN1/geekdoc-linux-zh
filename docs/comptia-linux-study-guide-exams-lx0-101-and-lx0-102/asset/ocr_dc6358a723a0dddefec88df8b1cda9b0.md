+   18. C. The type command identifies a command, as executed by the shell, being a built-in shell command, or an external command, whereas the where helps find the location of external command files. Thus, option C is correct. Neither type identifies the CPU architecture of a program file, can locate commands based on intended purpose, complete an incomplete typed command, or identify a command by a binary or script; the remaining options are all incorrect.

+   19. B. The find command includes the ability to search by username using the -user name option, where name is the username; option B is correct. The -uid option to find locate files owned by a user, but it takes a user ID (UID) number as an argument, option A isn't correct. The locate command provides no ability to search by user, options C and D are incorrect. Although option E is a valid find command, it finds all files under /home with a filename, not all owned by the user kernel, so this option is incorrect.

+   20. D. The which command searches the path just as does, but it prints the path to the first executable program it finds. Thus, option D is correct. The which command doesn't conduct an exhaustive search of the system, or could be many files called on the system, to option A. System package tools and which aren't related; option B is incorrect. /usr/bin/man may be run when the user whose which output matches that in the question types man, this may not be true of others because the path can vary from one to another. Thus, option C is incorrect. The which program doesn't reveal file information, so option E is incorrect.

# # Chapter 5: Booting Linux and Editing Files

+   1. C. The Master Boot Record (MBR) can contain a boot loader that is up to 446 bytes in size, option C is correct. If more space is required, the boot loader must load a secondary loader. Although the boot loader is loaded into RAM (option A), it's not stored permanently RAM is volatile storage. /dev/boot and /dev/kmem (options B and D) are references to files on filesystems; they are meaningful only the BIOS has found a boot loader and run it and lots of other boot processes have occurred. The swap partition (option E) is used as an adjunct to the MBR; the BIOS does not look for a boot loader.

+   2. C. Runlevel 1 is single-user mode, and adding the digit 1 to the kernel's lines in a boot loader will launch the system in this runlevel, option C is correct. Options A and B present invalid kernel options and are so incorrect. Although the telinit command specified in options D and E will change the runlevel the computer is running and runlevel 1 is a single-user mode, these commands are not passed to the kernel via a boot loader, so these options are both incorrect.
