## Using the Study Tools

To install the items on a Windows OS, follow these steps:

1. Download the ZIP file to your hard drive, and unzip to an appropriate location. Instructions on where to download this file can be found: http://www.sybex.com/go/1inuxplus2e.
2. Click the Start.EXE file to open the study files.
3. Read the license agreement, and then click the Accept button if you want to use the study tools.
The main interface appears. The interface allows you to access the content with one or two clicks.

To install the items on a computer running Linux, follow these steps:

1. Download the ZIP file to your hard drive, and unzip to an appropriate location. Instructions on where to download this file can be found: http://www.sybex.com/go/1inuxplus2e.
2. Open the Start.html file in an internet browser to open the study file.
3. Read the license agreement, and then click the Accept button if you want to use the study tools.

To install the items on a Mac, follow these steps:

1. Download the ZIP file to your hard drive, and unzip to an appropriate location. Instructions on how to download this file can be found here: http://www.sybex.com/go/1inuxplus2e.
2. Click the image file to mount the volume to your desktop.
3. Open the JWS volume on your desktop and click Start.
4. Read the license agreement, and click the Accept button if you want to use the study tools.

## Troubleshooting

Wiley has attempted to provide programs that work on most computers with the minimum system requirements. However, your computer may differ, and some programs may not work properly for some reason. The problems are that you don't have enough memory (RAM) for the programs to use or have other programs running are affecting installation. If you get an error message such as “Not enough memory” or “Setup cannot continue,” try one or more of the following suggestions: Turn off any antivirus software running on your computer. Close all running programs; the less memory is available to other programs. Adding more RAM to your computer can really help the speed of your computer and allow more programs to run at the same time.
