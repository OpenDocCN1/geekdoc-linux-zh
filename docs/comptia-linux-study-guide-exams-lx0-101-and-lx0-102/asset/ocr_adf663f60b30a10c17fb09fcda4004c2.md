# Troubleshooting

Wiley has attempted to provide programs that work on most computers with the minimum system requirements. Alas, your computer may differ, and some programs may not work properly for some reason.

The twoeliest problems are that you don't have enough memory (RAM) for the programs to use or have other programs running that are affecting installation or running of a program. If you get an error message such as “Not enough memory” or “Setup cannot continue,” try one or more of the following suggestions and then try using the software:

Turn off any antivirus software running on your computer. Installation programs-times mimic virus activity and may make your computer incorrectly believe that it's infected by a virus.

Close all running programs. The more programs you have running, the less memory is available to other programs. Installation programs typically update files and programs; if you keep other programs running, installation may not work properly.

Have your local computer store add more RAM to your computer. This is admittedly, a drastic and somewhat expensive step. However, adding more memory can really help the speed of your computer and allow more programs to run at the same time.
