
Dyslexic users often benefit from a special font that weights the bottoms of the characters heavily towards the tops. One such font is available from http://dyslexicfonts.com.

Unfortunately, many applications take cues from fonts on the desktop environment's settings, others don't. Thus, you may need to adjust options in some individual applications, as well as the desktop environment as a whole.

## Adjusting Contrast

Desktop environments provide various themes—settings for colors, window manager decorations, and so on. Some themes are better than others in terms of legibility. For instance, some themes are low in contrast, and others are high in contrast.

Monitors have their own contrast controls. You can adjust these for best legibility, of course, but the contrast adjusted by desktop environment settings are independent of a monitor's contrast.

In KDE, you can set themes in the same System Settings preferences dialog box which you set the fonts (Figure 6.5); you click the Colors in the left and select the theme you want to use. The Workspace Appearance item (accessible by clicking Overview from the screen shown in Figure 6.5) provides additional options. Xfce provides similar options in its Appearance control.

## Using Magnifier Tools

A screen magnifier enhances parts of the screen—typically the area immediately surrounding the mouse. One common screen magnifier is KMag, which is part of the KDE suite. (You can use KMag in GNOME, Xfce, or other desktop environments, to type km or select it from your desktop menus. The result is the KMag window on the screen, which enlarges the area around the cursor by default.)

## Using Additional Assistive Technologies

In addition to keyboard, mouse, and conventional display tools, some programs can help those with special needs. Most notably, screen readers and Braille displays can help those who can't read conventional displays.

## Configuring Linux to Speak

Computer speech synthesis has existed for decades. Today, several speech synthesis products are available for Linux, including these:

- Orca: This program, which is based at http://live.gnome.org/Orca, is a screen reader that has been integrated into GNOME 2.16 and later.
- Emacspeak: Similar to Orca in many respects, this program aims to enable those with visual impairments to use a Linux computer. You can learn more at http://emacspeak.sourceforge.net.

## Using Braille Displays

A Braille display is a special type of computer monitor. Rather than display data visually, it creates a tactile display of Braille. As such, a Braille display is an efficient way for those with visual impairments to access text-mode information, such as that displayed in a Linux text-mode console. Many Linux text-mode programs can manage a Braille display with no changes.

To use a Braille display, special Linux software is required. The BRLTTY (http://www.nielke.de/brtty/) provides a Linux daemon that redirects text-mode console to a Braille display. It includes features that support scrollback, multiple virtual terminals, and speech synthesis.

Linux kernels since 2.6.26 include direct support for Braille displays. If you're familiar with Linux kernel compilation, you should check the Accessibility Support options in the Device Drivers area of the kernel configuration.

## Configuring Localization and Internationalization

Linux is an international OS. Its developers and users reside in many countries around the world. Therefore, Linux supports a wide variety of character sets, keyboards, date/time formats, and other features that can vary from one region to another. Many of the features are set when you answer questions during installation, knowing about—and how to change them—can help you manage your system, particularly if you need to change these for any reason.

## Setting Your Time Zone

When you communicate with other computers (by sending email, transferring files, and so on), other computers may reside in the same city or around the world. For this reason, it's helpful for you to know something about its time zone. This can help files' time stamps sensible and avoid weird temporal problems when exchanging data. For the most part, you need to be concerned with just one time zone setting for a Linux computer; but sometimes you may want to set the time zone for one account and another for another account or login. Thus, I describe both methods of setting a time zone.

## Setting a Linux Computer's Time Zone

Linux uses Coordinated Universal Time (UTC) internationally. This is the time in Greenwich, England, uncorrected for daylight saving time. When you write a file to disk on a Linux-filesystem, the time stamp is stored in UTC. When you use tools such as cron (described in Chapter 7, “Administering the System”), they “think” in UTC. Chances are, though, that you use local time. Thus, a Linux computer can translate between local time and UTC.

To perform this translation, Linux needs to know your time zone. Linux looks to /etc/localtime file for information about its time zone. This file is one of the rare configuration files that's not a plain-text file, so you shouldn't be editing it with a text editor. This file could be a file of itself, or it could be a symbolic or hard link to another file. If it is a symbolic link, you should determine your time zone by performing a long file listing to see the name of the file to which local time links:

```
$ ls -l /etc/localtime
1rwxwxrwx 1 root root 36 May 14 2008 /etc/localtime -> /
/usr/share/zoneinfo/America/New_York
```

If /etc/localtime is a regular file and not a symbolic link or if you want further confirmation of your time zone, use the date command:

```
Mon Sep 18 12:50 2023 EDT
```

The result of the date command shows the current time and the time zone. The time zone is indicated by an abbreviation, such as EDT for Eastern Daylight Time. For a list of time zone abbreviations, consult /usr/share/zoneinfo/.

At this point, your system should be configured to use the time zone you've selected. If you changed your time zone, less-level configuration tools could be confused. For a program called tzsetup, tzselect, tzconf, or something similar. Typically, these programs ask you for your location in several steps (starting with your continent, then name, and perhaps you for your state or city) and create an appropriate symbolic link.

In addition to /etc/localtime, some distributions use a secondary file with time zone data. This file is called /etc/timezone on Debian and its derivatives. On Fedora and related distributions, it's /etc/sysconfig/clock. This file contains the name of the time zone. For instance, the /etc/timezone file looks like

America/New_York

This file provides a quick way to change your time zone. It should also be updated when you change your time zone.

## Setting an Individual Login's Time Zone

One wrinkle on time zone issues is the TZ variable. (Chapter 9 covers environment variables in more detail.) This environment variable holds time information in three of formats:

- The most common format on Linux is `:filename`, as in :`/usr/share/zoneinfo/Europe/London`. This tells the system that the time zone is the one described in the specified file.
- A second format, common on non-Linux systems, is `std offset`, where `std` is a three-character or longer time zone name (such as EST) and `offset` is a time relative to UTC, with positive values representing offsets of the Prime Meridian and negative values being east of it. This format is used when daylight saving time is not in effect.
