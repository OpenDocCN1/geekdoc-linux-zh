# Chapter 9 • Writing Scripts, Configuring Email, and Using Databases

Although launching several programs from one script can save time in starting your working environment and other situations, scripts are frequently used to run a series of programs that manipulate data in some way. Such scripts typically do not include the ampersands at the ends of commands must run after another or may even rely on the first. A comprehensive list of such commands is impossible because you can run any program you can install in Linux as a command in a script—even another script. A few commands that are commonly used in scripts include the following:

**Normal File Manipulation Commands** The file manipulation commands, such as `ls, mv, cp, and rm`, are often used in scripts. You can use these commands to help automate repetitive filename tasks.

**grep** This command is described in Chapter 1. It locates files that contain specific strings.

**find** Where grep searches for patterns within the contents of files, find does so by filenames, ownership, and similar characteristics. This command is described in Chapter 4.

**cut** This command extracts text from fields in a file. It is frequently used to extract variable information from a file whose contents are highly patterned. To use it, you pass one or more options to specify what information you want, followed by one or more filenames. For instance, users' home directories in the sixth colon-delimited field of `cut -f 6 -d ": /etc/passwd` to extract information. The same command in a script will extract this information, which you'll probably save to a variable or to a subsequent command via a pipe.

**sed** This program is described in Chapter 1. It provides many of the capabilities of a conventional text editor but via commands that can be typed at a command prompt or entered in a script.

**echo** Sometimes a script must provide a message to the user; echo is the tool to accomplish this. You can pass various options to echo or just a string to be shown to the user. For instance, `echo "Press the Enter key" causes a script to display the specified string.

**mail** The mail command can be used to send email from within a script. Pass it the -s subject parameter to specify a subject line, and give it an email address as the last argument. If used at the command line, then type a message and terminate it with a Ctrl+D keystroke. If used from a script, you might omit the subject entirely, or pass it an an external file as the message using redirection, or use a document tool to pass text to the mail command as input. (Chapter 1 describes input redirection and here documents.) You might want to use this to send mail to the superuser about the actions of a startup script or a script that runs on an automated basis. This command is described in more detail later in this chapter.
