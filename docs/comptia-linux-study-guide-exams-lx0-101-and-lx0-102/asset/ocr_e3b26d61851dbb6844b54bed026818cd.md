# Appendix A - Answers To Questions

+   6. D, E. The cpio and tar programs are common Linux archive-creation utilities, so options D and E are both correct. The restore command restores (which does not back up) data; its backup command is dump. Thus, option A is incorrect. The vi command launches a editor; it is not used to create archives, so B is incorrect. There is no standard tape command in Linux, so option C is incorrect.

+   7. E. With the tar utility, the --ls (t) command is used to read the archive and display its contents. The --verbose (v) option creates a verbose listing, and --file (f) specifies the filename--data79.tar in this case. Option E uses all of these features. Options A, B, and D include all other commands for --ls, which is required by the question.

+   8. A. Symbolic links can point across filesystems, creating a symbolic link from one filesystem (when your home directory resides to another (on the CD-ROM)) isn't a problem, making option A correct. Hard links, as options B, C, and D, are restricted to a single filesystem and not used for the described purpose. Because symbolic links work as described, option E is incorrect.

+   9. E. Option D is the correct command. Typing chown tony:somefile.txt, as in option A, sets the owner of the file and the group to tony. The chmod command used in options B and D is used to change file permissions, not ownership. Option C reverses the order of the filename and the name.

+   10. C, E. The d character leads the mode indicates that the file is a directory (option C), and the r symbol in the rxr triplet at the symbolic mode indicates that all users of the system have read to the directory (option E). Symbolic links are denoted by l characters, which this mode lacks, so option A is incorrect. Although the x symbols usually denote executable files, as specified in option B, in the case of directories this permission indicates that the directory's contents may be searched; executing a directory is meaningless. SUID bits are indicated by an s character in place of the owner's execute bit in the symbolic mode. Since this position holds an x in this example, option D is incorrect.

+   11. C. The set user ID (SUID) enables programs to run as the program's owner rather than as the user who ran them. This makes SUID root programs risky, setting the SUID bit on root-owned programs should be done only when it's required for the program's normal function, stated in option C. This should clearly not be for all programs because the SUID bit is not required of executable programs as option A asserts. Although the SUID root configuration enables programs to access device files, the devices' permissions can be modified to give programs access to those files, if this is required, so option B is incorrect. Although SUID root programs are a security risk, as stated in option D, they're a necessary risk for a few programs. Many file should not be SUID run by root, so option E is incorrect.

+   12. E. Using symbolic modes, the r+ option adds read (r) permissions to the world (o). Thus, option E is correct. Option A sets the mode to rwxr------, which is a bit odd and doesn't provide world read access to the file, although it does provide world execute access. Option
