# Permanently Mounting Filesystems

The /etc/fstab controls how Linux access to disk partitions and removable media devices. Linux supports a unified directory structure in which every disk device (partition or removable disk) is mounted at a particular point in the directory tree. For instance, you may access a USB flash drive at /media/usb. The root of the tree is accessed from /. Directories off root may be other partitions or disks, or they may be ordinary directories. For instance, /etc/fstab may be on the same partition as /, but many other directories, such as /home, may correspond to separate partitions. The filename fstab is an abbreviation for filesystem table.

The /etc/fstab consists of a series of lines that contain six fields; the fields are separated by one or more spaces or tabs. A line that begins with a hash mark (#) is a comment. Listing 3.1 shows a sample /etc/fstab.

Listing 3.1: Sample /etc/fstab file

| device | mount point | filesystem | dump | fsck |
| --- | --- | --- | --- | --- |
| /dev/hdl | /home | ext4 | defaults | 1 1 |
| UUID-3631a288-673e-40f5-92e6-639fec468e9 | / | | | |
| /user | reiserfs | defaults | 0 0 |
| /home | /home | reiserfs | defaults | 0 0 |
| /dev/db5 | /windows | | | uid=500,umask=0 0 0 |
| /dev/vdc | /media/cdrom | iso9660 | users,noauto | 0 0 |
| /dev/sda | /media/home | auto | users,noauto | 0 0 |
| server:/home | nfs | | users,exec | 0 0 |
| /winsrv/shr | /other | cifs | users,credentials=/etc/creds | 0 0 |
| /dev/hda4 | swap | | defaults | 0 0 |

The meaning of each field in this file is as follows:

**Device** The first column specifies the mount point. These are usually device filenames that reference hard disks, floppy disks, and so on. Most distributions specify partitions by their labels or UIDs, as in the LABEL=/ and UUID=3631a288-673e-40f5-92e6... in Listing 3.1. When Linux encounters such an entry, it tries to find the partition that has the specified name or UUID and mount it. This practice can help reduce problems if partition numbers change, but some filesystems keep these labels. It's also possible to list a network drive, as in server:/home, which is the /home export on the computer called server; or in /winsrv/shr, which is the share on-the Windows or Samba server called winsrv.
