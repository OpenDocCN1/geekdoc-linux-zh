# Displaying Print Queue Information with lpq

The lpq utility displays information about the print queue—how many files it contains, how large they are, who their owners are, and so on. By entering the user's name as an argument, you can use this command to check on any prints owned by a particular user. To use lpq to examine a queue, you can issue a command like the following:

```
$ lpq -hp4000
hp4000 is ready and printing
```

| Rank Owner File(s) | Total Size |
| active rodmidt 1630 | 90112 bytes |

Of particular interest is the job number—1630 in this example. You can use this number to delete a job from the queue or redirect so that it prints before others. Any user may use the lpq command.

# Removing Print Jobs with lprm

The lprm command removes one or more jobs from the print queue. You can use this a couple of ways:

+   - If lprm is used with a number, number is understood to be the job ID (as shown in lpq's output) of the job to be deleted.
- If a user runs the BSD or CUPS lprm passes a dash (--) to the program, it removes all jobs belonging to the user.

This program may be run by root or by an ordinary user; but just noted, its capabilities vary depending on whom it runs. Ordinary users may only remove their own jobs from the queue, but root may remove anybody's jobs.

# Controlling the Print Queue

In the original LPD system, the lpc utility starts, stops, and reorders jobs within print queues. Although CUPS provides an lpc command, it differs for for the printers. Instead of using the CUPS web interface, which provides point-and-click print queue management:

+   - You can disable a queue by clicking the Stop Printer link for the printer on the CUPS Web interface. When you do so, this link changes to Start Printer, which reverses the effect when clicked. The The Job links also provide a way to cancel and otherwise manage specific jobs.

+   - You can use a series of commands, such as cuspenable, cupsdisable, and lpmove, to control the queue. These commands enable a disable queue, a delete queue, or move a job from one queue to another. Moving a job can be handy if you must shut down a queue for maintenance and want to redirect the queue's existing jobs to another printer.
