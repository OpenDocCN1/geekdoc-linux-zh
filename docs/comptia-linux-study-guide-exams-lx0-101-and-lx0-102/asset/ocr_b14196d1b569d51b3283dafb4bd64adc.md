# Chapter 1 · Exploring Linux Command-Line Tools

If you log into Linux using a graphical user interface (GUI) login screen, though, you'll have to start a shell manually. Some GUIs provide a menu option to start a program called terminal, xterm, Konsole, or something similar. These programs enable you to run text programs within Linux, and by default they come up running your shell. If you can't find such a menu, look for one that enables you to run an arbitrary command. Select it, and type xterm or console as the command name; this will launch an xterm-type program that will run a shell.

# Using Internal and External Commands

Internal commands, as you might expect, built into the shell. Most shells offer a similar set of internal commands, but shell-to-shell differences exist; consider your shell's page (as discussed later, in "Getting Help") for details, particularly if you're using an exotic shell. Internal commands you're likely to enable you to perform some common tasks:

Changing the Working Directory Whenever you're running a shell, you're working in a specific directory. When you refer to a file without providing a complete path to the file, the shell works in the current directory. The cd command changes the current working directory. Similarly, for instance, typing cd /home/sally changes to /home/sally directory. The tilde (~) character is a useful shortcut; stands for your home directory, typing cd ~ will have the same effect as cd /home/sally if your home directory is /home/sally.

Display the Working Directory The pwd command displays "prints" to the screen to the current working directory.

Display a Line of Text The echo command displays what you type; for instance, typing echo causes the system to display the string Hello. This may seem pointless, but it's useful in scripts (described in Chapter 9), and it can also be a good way to review the contents of environment variables (described later in this chapter, in "Using Environment Variables")

Execute a Program The exec command runs an external program that you specify, as in exec run myprog. In most cases, this is best accomplished by typing the name of the program you want to run. The exec command has one special feature: that Rather create a new process that runs alongside the shell, the new process replaces the shell. When the new process terminates, it's if you terminated the shell.

Time an Operation The time command counts how long subsequent commands to execute. For instance, typing time tells you how long the system took to execute the pwd command. The time is displayed after the full command completes. Three times are displayed: total execution time (real time), user CPU time, and system CPU time. The final two values tell about CPU time consumed, which is likely to be much less than the total execution time.

Set Options In its most basic form, set displays a wide variety of options relating to bash operation. These options are formatted like environment variables, but they aren't the same things. You can pass various options to set to have effect a wide range of shell operations.
