# TABLE 3.5 Important filesystem options for the mount command (continued)

| Option | Supported filesystems | Description |
| --- | --- | --- |
| uid=value | Most filesystems that don't support Unix-type permissions, such as vfat, hpf, nfs, and hfs | Sets the owner of all files. For instance, uid=1000 sets the owner to whoever has Linux user ID 1000. (Check Linux user IDs in /etc/passwd file). |
| gid=value | Most filesystems that don't support Unix-type permissions, such as vfat, hpf, nfs, and hfs | Works with uid=value, sets the group of all files on the filesystem. You can find group IDs in /etc/group file. |
| umask=value | Most filesystems that don't support Unix-type permissions, such as vfat, hpf, nfs, and hfs | Sets the mask for the permissions on files. value is interpreted in binary as bits to be removed from permissions on files. For instance, 075, or -rwxr-x---. Used in conjunction with uid=value and gid=value this option lets you control who can access files on FAT, NTFS, and many other filesystems. |
| dmask=value | Most filesystems that don't support Unix-type permissions, such as vfat, hpf, nfs, and hfs | Similar to umask, but sets the mask for directories, not for files. |
| fmask=value | Most filesystems that don't support Unix-type permissions, such as vfat, hpf, nfs, and hfs | Similar to umask, but sets the mask for files only, not for directories. |
| conv=code | Most filesystems used of Microsoft and Apple OS: msdos, umdos, vfat, hpf, and hfs | If code is b binary, Linux does not modify the file' contents. If code is t text, Linux autocorverts between Linux-style and DOS - Macintosh-style end-of-line characters. If code is a auto, Linux applies the conversion when the file is a known binary file format. It is usually best to leave this at its default value because binary conversion can cause serious problems for some applications and file types. |
| norock | iso9660 | Disables Rock extension for ISO-9660 CD-ROMs. |
| nojoliet | iso9660 | Disables Joliet extensions for ISO-9660 CD-ROMs. 

Some filesystems provide additional options that are not described here. The man page for mount covers some of these, but you may need to look at the filesystem's documentation for some options. This documentation may appear in /usr/src/linux/Documentation/filesystems or /usr/src/linux/fs/fname, where fname is the name of the filesystem.
