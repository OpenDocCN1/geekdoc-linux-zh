# Installing Boot Loaders

If you're installing Fedora's EFI-enabled version of GRUB Legacy, you should not use the grub-install command; instead, copy the grub.efi file to a subdirectory on your ESP, such as /boot/efi/EFI/redhat, and copy grub.conf to the same location. If you are using Fedora's EFI RPM file, the grub.efi file should be placed in this location by default. After copying these files, you may need to use efibootmgr to add to the loader's list:

```
# efibootmgr -c - \EFI\redhat\grub.efi -L GRUB
```

This command adds GRUB Kernel, stored in the ESP's /EFI/redhat directory, to your EFI boot loader list. You must use doubled-backslashes (\\) rather than the Linux-style forward slashes (/). Consult the efibootmgr's manual for more information.

You do not need to reinstall GRUB after making changes to its configuration file. (Such a reinstallation is required for some older loaders, though.) You need to install GRUB this way if you make changes to your disk configuration, such as resizing or moving the GRUB root partition, moving your entire installation to a new hard disk, or possibly reinstalling Windows (which tends to wipe our MBR-based boot loaders). Use a backup boot loader, as GRUB installed to a floppy or USB disk can.

# Interacting with GRUB Legacy

The first screen the GRUB boot loader shows you a list of all the operating systems specified with the title option in your GRUB configuration file. You can wait for the timeout to expire the default operating system to boot. To select an alternative, use your arrow keys to highlight the operating system that you want to boot. Once your choice is highlighted, press the Enter key to start booting.

Follow these steps when you want to change or add particular options to your operating system:

+   Use your arrow keys to highlight the operating system that most matches what you want to boot.
Press the E key to edit this entry. You'll see a new screen listing all the options for this entry.
Use your arrow keys to highlight the kernel option line.
Press the E key to edit the kernel options.
Edit the kernel line to add any options, such as 1 to boot to single-user mode. GRUB Legacy passes the extra option to the kernel.
Press the Enter key to complete the edits.
Press the B key to start booting.

You can make whatever changes you like in step 5, such as using a different init program. You do this by appending init=/bin/bash (or whatever program you want to use) to the end of the kernel line.
