# Answers to the Assessment Test

+   1. B. “PS/2” can refer to both a hardware interface and a software protocol, but used in the context of the Protocol option, it unambiguously refers to software protocol. Thus, option B is correct. Option A might be correct, but the specified line is insufficient evidence of that; USB mice use the PS/2 protocol or a variant of it, as typed the Intellimouse PS/2 protocol. Using the PS/2 hardware port and protocol originated from the IBM PS/2 computer in option C, many other computers now use them. Mice that the PS/2 may be used with just any OS, not typed as IBM's OS, so option D is incorrect. A slash (/) is valid as part of the PS/2 protocol name, so option E is incorrect. For more information, please see Chapter 6, “The X Window System, Localization, and Printing."

+   2. A. Examining a process listing (obtained from ps) for signs of the super server is the most reliable way to determine which one is actually running, so option A is correct. The presence of the server's configuration file or files (as in option C) is also good diagnostic, some other systems that have upgraded may have both sets of configuration files. There is no standard serverutility on which one is used, so option B is incorrect. Most distributions launch the super server through a SysV startup script; the /etc/inittab file is not directly involved in this process, as it would root, would include an indication of any instance of inetd or xinetd that is listening for connections. option E emits the -p option, which causes the program to display process names. Option E is incorrect. For more information, please see Chapter 10, “Securing Your System."

+   3. D. The lpc is used to start, stop, change the priority of, and otherwise control jobs in a print queue. CUPS has in lpc but it's quite rudimentary compared to the lpc units of BSD LPD and LPR. Instead, CUPS relies on its Web-based interface to provide the ability to control print jobs. Thus, option D is correct, and the remaining options must logically be all correct. For more information, please see Chapter 6, “The X Window System, Localization, and Printing."

+   4. C. The /etc/security/limits.conf defines various limits on user resources, including the number of simultaneous login users individuals are permitted. Thus, option C is correct. The /etc/pam.limits (option A) is fictitious, although login limits rely on the pam_limits module to the Pluggable Authentication System (PAM). The /etc/bashrc (option B) is a bash startup script file, but it's not normally used to impose login limits. The /etc/inittab file (option D) is a key Linux startup file, but it doesn't have any bearing on imposing login limits. The /etc/passwd file (option E) defines key account features, but login limits are not among these. For more information, please see “Securing Your System."
