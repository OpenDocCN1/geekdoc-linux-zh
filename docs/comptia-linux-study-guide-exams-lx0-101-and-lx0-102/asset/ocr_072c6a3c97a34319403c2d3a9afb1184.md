The /etc/cups/cupsd.conf file, which is structurally similar to the Apache Web server configuration file, contains a number of configuration blocks that specify which systems should be able to access it. Each block controls access to a particular location on the server. These blocks look like this:

```
<Location>
Order Deny,Allow
Deny from All
BrowseAllow from 127.0.0.1
BrowseAllow from 192.168.1.0/24
BrowseAllow from @LOCAL
Allow from 127.0.0.1
Allow from 192.168.1.0/24
Allow from @LOCAL
</Location>
```

> NOTE If you're configuring a workstation with a local printer that you don't want to share or if you want to configure a workstation to use printers shared via LPD or some other non-IPP printing protocol, you shouldn't adjust /etc/cups/cupsd.conf. If you want access remote printers, however, you should at least activate browsing by setting the default Brows On, as described above. You shouldn't have to modify your location definitions unless you share your local printers.

The /printers location, controls access to the printers themselves. The following list includes features of this example:

**Directive Order** The Order Deny,Allow line tells CUPS in order it should apply allow and deny directives—in this case, allow deny modify directives.

**Default Policy** The Deny from All1 line tells the system to refuse all connections except those that are explicitly permitted.

**Browsing Control Lines** The BrowseAllow line tells CUPS from other systems should accept browsing requests. In this case, it accepts connections from (127.0.0.1), from systems on the 192.168.1.0/24 network, and from systems connected to local subnets (@LOCAL).

**Access Control Lines** The Allow lines give the specified systems non-browse access to printers—that is, systems can print to local. In most cases, the Allow lines are the same as the BrowseAllow lines.

You can create a definition that uses Allow from All and then creates BrowseDen and Deny to limit access. As a general rule, though, the approach shown in this example is safe. Locations other than the /printers location can also be important. For instance, there's a root (/) location that specifies default access permissions to all other locations and an /admin location that controls access to CUPS administrative functions.
