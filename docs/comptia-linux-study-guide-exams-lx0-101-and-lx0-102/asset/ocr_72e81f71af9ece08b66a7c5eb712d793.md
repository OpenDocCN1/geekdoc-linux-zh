+   3. Some programs use the EDITOR environment variable in option E. Contrary to option A, the EDITOR environment variable has nothing to do with command-line editing. When you're typing at a bash prompt, bash provides simple editing features, so option B is incorrect. (You can launch the editor specified by $EDITOR by typing Ctrl+L followed by Ctrl+E, The edit doesn't behave as option C suggests. This might be configured differently on different systems.) There are no standard CMD, PRESENT, or WORKING environment variables, so option B, D, and E are all incorrect.
