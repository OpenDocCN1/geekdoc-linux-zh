
```bash
$ find ./ -name "*"`
```

The backtick works fine in some cases, but it breaks down in more complex situations. The reason is that the output of the backtick-contained command is passed to the command it precedes as if it had been typed at the shell. By contrast, when you use xargs, it runs the command you specify (in these examples) once for each of the input items. What's more, you can't pass options such as -d "\n" to a backtick. Thus, these two examples will work in the same way, but not in all of them.

## Processing Text Filters

In keeping with Linux's philosophy of small tools that can be tied together with pipes and redirection to accomplish more complex tasks, many simple commands to manipulate text are available. These commands accomplish tasks of various types, such as combining files, transforming the data in files, formatting text, displaying text, and summarizing data.

> Many of the following descriptions include input-file specifications. In most cases, you can omit these input-file specifications, in which case the utility reads from standard input instead.

## File-Combining Commands

The first group of text-filtering commands are used to combine two or more files into one file. Three important commands in this category are cat, join, and paste, which join files from end to end, based on fields in the file, or by merging on a line-by-line basis, respectively.

## Combining Files with cat

The cat command's name is short for concatenate, and this tool does just that: It links together an arbitrary number of files from end to end and sends the result to standard output. By combining cat with output redirection, you can quickly combine two files into one:

```bash
$ cat first.txt second.txt > combined.txt
```

Although cat is officially a tool for combining files, it's also commonly used to display the contents of a short file. If you type one filename as an option, cat displays that file. This is a great way to review short files; but for long files, you're better off using a full-fledged pager command, as more or less.

You can add options to cat to perform minor modifications to the files as it combines them:

- **Display Line Ends**: If you want to see where lines end, add the -E or --show-ends option. The result is a dollar sign ($) at the end of each line.
- **Number Lines**: The -n or --number option adds line numbers to the beginning of every line. The -b or --number-nonblank option is similar, but it only numbers lines that contain text.
- **Minimize Blank Lines**: The -s or --squeeze-blank option groups blank lines down to a single blank line.
- **Display Special Characters**: The -T or --show-tabs option displays tab characters as ^. The -v or --show-nonprinting option displays most control and other special characters using caret (^) and M notations.

The tac command is similar to cat, but it reverses the order of lines in the output.

## Joining Files by Field with join

The join command combines two files by matching the contents of specified fields within the files. Files are typically space-separated entries on a line, although you can specify another character as the field separator with the -t option, where char is the character you want to use. You can cause join to ignore case when performing comparisons by using the -i option.

The effect of join may be understood through a demonstration. Consider Lists 1.1 and 1.2, which contain data on telephone numbers; Listing 1.1 shows the names associated with those numbers, and Listing 1.2 shows whether the numbers are listed or unlisted.

### Listing 1.1: Demonstration File Containing Telephone Numbers and Names

```
555-2397 Beckett, Barry
555-5116 Carter, Gertrude
555-7929 Jones, Theresa
555-9871 Orwell, Samuel
```

### Listing 1.2: Demonstration File Containing Telephone Number Listing Status

```
555-2397 unlisted
555-5116 listed
555-7929 listed
555-9871 unlisted
```

You can display the contents of both files using join:

```bash
$ join listing1.txt listing2.txt
555-2397 Beckett, Barry unlisted
555-5116 Carter, Gertrude listed
555-7929 Jones, Theresa listed
555-9871 Orwell, Samuel unlisted
```

By default, join uses the first field to match across files. Because Listings 1.1 and 1.2 both place the phone number in the -1 or -2 columns, it's the key field in the output. You can specify another field by using the join -1 -3 -2 columns to specify the join field for the first or second file, respectively, as in cameras.txt lenses.txt to join using the third field in cameras.txt and the second field in lenses.txt. The -format option enables more specifications for the output file format; consult the main page for more details.

The join command can be used at the core of a set of customized database-management tools using Linux text-manipulation commands. It is very limited by itself, though; for instance, it requires its two files to have the same ordering of lines. (You can use the sort command to ensure this is so.)

## Merging Lists with paste

The paste command merges files by line, separating the lines from each file with tabs, as shown in the following example, using Listings 1.1 and 1.2:

```
555-2397	Beckett, Barry	unlisted
555-5116	Carter, Gertrude	listed
555-7929	Jones, Theresa	listed
555-9871	Orwell, Samuel	unlisted
```

You can change the delimiter used by paste with the -d option. For example, to use a comma as the delimiter:

```bash
$ paste -d "," listing1.txt listing2.txt
555-2397,Beckett, Barry,unlisted
555-5116,Carter, Gertrude,listed
555-7929,Jones, Theresa,listed
555-9871,Orwell, Samuel,unlisted
```

The paste command can also be used to merge files into columns using the -s option. For example, to merge all lines into a single line:

```bash
$ paste -s listing1.txt
555-2397 Beckett, Barry,555-5116 Carter, Gertrude,555-7929 Jones, Theresa,555-9871 Orwell, Samuel
```

## File-Transforming Commands

Sometimes you'll create an output file that you want transformed. To do so, you can use a command that's called, appropriately tr. This command can transform in several ways, using the following:

- **Replace Characters**: The tr (translate) command can be used to replace one set of characters with another. For example, to convert lowercase letters to uppercase:
  ```bash
  $ tr 'a-z' 'A-Z' < file.txt
  ```
- **Delete Characters**: The tr -d option can be used to delete specific characters from the input. For example, to delete all digits:
  ```bash
  $ tr -d '0-9' < file.txt
  ```
- **Squeeze Repeats**: The -s option can be used to squeeze multiple consecutive occurrences of a character into a single instance. For example, to convert multiple spaces into one space:
  ```bash
  $ tr -s ' ' < file.txt
  ```

The tr command can also be used to replace tabs with spaces. For example, to replace tabs with four spaces:

```bash
$ tr '\t' '    ' < file.txt
```

## Converting Tabs to Spaces

Sometimes you'll create an output file that you want to convert tabs to spaces. To do so, you can use a command that's called sed. This command can transform in several ways, using the following:

- **Replace Text**: The sed (stream editor) command can be used to search and replace text. For example, to replace "foo" with "bar":
  ```bash
  $ sed 's/foo/bar/g' file.txt
  ```
- **Delete Text**: The sed -d option can be used to delete lines that match a pattern. For example, to delete lines containing "pattern":
  ```bash
  $ sed '/pattern/d' file.txt
  ```
- **Insert Text**: The sed command can be used to insert text before or after a matched pattern. For example, to insert a header at the beginning of each line:
  ```bash
  $ sed 's/^/HEADER/' file.txt
  ```

The sed command can also be used to replace tabs with spaces. For example, to replace all tabs with four spaces:

```bash
$ sed 's/\t/*//g' file.txt
```

## Displaying Files in Octal

Sometimes you'll create an output file that you want to view in octal. To do so, you can use a command that's called od (octal dump). This command can transform in several ways, using the following:

- **Display in Octal**: By default, od displays files in octal. For example, to display the contents of file.txt:
  ```bash
  $ od file.txt
  ```
- **Display in Hexadecimal**: The -t option can be used to display files in hexadecimal. For example, to display a file in hex:
  ```bash
  $ od -t x file.txt
  ```
- **Display in Decimal**: The -t option can also display files in decimal. For example, to display a file in decimal:
  ```bash
  $ od -t d file.txt
  ```
- **Display in ASCII**: The -t option can be used to display files in ASCII. For example, to display a file in ASCII:
  ```bash
  $ od -t c file.txt
  ```

The first field of each line is an index into the octal file. For instance, the second line begins at 02 (16 in base 10) bytes into the file. The remaining lines on each line represents the bytes in the file. This type of output can be difficult to interpret unless you're well versed in octal notation and perhaps in the ASCII code.

## Sorting Files with sort

Sometimes you'll create an output file that you want sorted. To do so, you can use a command that's called, appropriately sort. This command can sort in several ways, using the following:

- **Sort Alphabetically**: Ordinarily, sort sorts files alphabetically. For example, to sort a file.txt:
  ```bash
  $ sort file.txt
  ```
- **Sort Numerically**: The -n option can be used to sort files numerically. For example, to sort a file of numbers:
  ```bash
  $ sort -n file.txt
  ```
- **Sort in Reverse Order**: The -r option sorts in reverse order. For example, to sort a file in reverse alphabetical order:
  ```bash
  $ sort -r file.txt
  ```
- **Sort by a Specific Column**: The -k option can be used to sort by a specific column. For example, to sort a file by the second column:
  ```bash
  $ sort -k2 file.txt
  ```
