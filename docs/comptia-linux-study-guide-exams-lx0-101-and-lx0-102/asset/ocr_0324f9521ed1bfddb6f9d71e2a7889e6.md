# Answers to the Assessment Test

+   6. The wc command displays count of newlines, words, and bytes in the specified file (report. txt). Piping this data into wc causes a copy of the output to be stored in the same directory as the executable file! Thus, option E is correct. Contrary to option A, wc is not an editor, and the remaining syntax would count two files in separate windows if we were an editor. Contrary to B, wc doesn't open windows or a new window. C describes the effect of wc report | wc—that is, it overlaps the tee. Contrary to option D, wc has nothing to do with memory leaks, and wc doesn't use the report text. For more information, please see Chapter 1, "Exploring Linux Command-Tools."

+   7. The grub. cfg filename defines a GRUB 2 configuration file. In each file, each OS or kernel starts with a menuentry and one curly brace ( { and a close brace ( ). Thus, option C is correct. Some configuration files and programming languages use semicolons;) at the end of lines, but this isn't for GRUB 2, option A is incorrect. Although characters () are used to terminate some types of configuration files, including disk indent in GRUB 2 configuration file, they aren't used while OS or kernel definitions in this file, so option B is incorrect. The string * terminates comments in program files, but isn't commonly used in GRUB 2 configuration files, option D is incorrect. Option E would be correct if the question had asked about GRUB 2 Legacy configuration file (menu.1 or grub.cfg), but the question specifies a GRUB 2 configuration file (grub. cfg); the two boot loaders terminate the OS/kernel boundaries, so option E is correct. For more information, please see Chapter 5, "Booting and Editing Editors."

+   8. The third field of /etc/passwd holds the UID for the account, so option E is correct. It doesn't use any standard identifier called a human ID (HID; option A), the acronym stands for human interface device, a class of USB devices. Accounts don't have PIDs (option B) because of running processes. The account's GID number (option C) is stored in the fourth field of /etc/passwd—100 in this example. Accounts dont globally use unique ID (GUID), so option D is incorrect. For more information, please see Chapter 7, "Administering the System."

+   9. The grep command scans files to find that a specified string or pattern, described by option B. In the case of text files, grep displays the matching line or lines; for binary files, it reports that the file matches the pattern. The method of creating a pipeline (option A) involves separating two commands with a vertical bar (|). The grep command can be used in a pipeline, but doesn't create one.
