If you want to rename the file, you can do so by using the new name following. Likewise, you can place the file in a particular directory in the same way, as follows:

```
$ cp masterpiece.c lisa@leonardo.example.com:"/art/mona.c
```

This example copies masterpiece.c to the "/art directory on the target computer and renames it. If the specified directory does not exist, an error results, and the file is not transferred. If you specify a directory without a trailing slash or filename and if you mistype the directory name, cp will copy the file and rename it to your mistyped directory name. # Configuring Logins Without Passwords

If you use SSH or it in automated tools, you won't doubt become annoyed by the need to type a password with every connection. There is a way around this requirement: You can set up the SSH client with keys and give the client's public key to the server computer. With this configuration, the SSH client computer can identify itself, possibly obviating the need for you to type a password.

> SSH to operate without the use of passwords is convenient, but it does increase security risks. If someone gets access to your account on the SSH client system, that person will be able to log into your SSH system without the benefit of your password. Thus, you should create a password-less login only from a client that's well protected, if at all. Accessing the root account in this way is particularly risky.

To configure SSH not to require a password, follow these steps:

+   Log into the SSH client as the user using a version 2 SSH key:

+   Type the following command to generate a version 1 key:
$ ssh-keygen -q t rsa -f ~/.ssh/id_rsa -C "" -N ""

> Step 2 generates a version 2 key. By typing ssh-keygen -q t dsa -f ~/.ssh/id_dsa -C "" -N "", it creates files. This procedure is not recommended because SSH version 1 is not as secure as version 2; however, you may use version 1 to connect to some servers.

+   Generate two files: id_rsa and id_rsa.pub. Transfer each of these files to the SSH server computer in any way that's convenient—via a USB drive, using scp, or by any other means. Copy the file under a temporary name, as temp.rsa.

+   Log into the SSH server system. If you use SSH, you'll need to type your password.
