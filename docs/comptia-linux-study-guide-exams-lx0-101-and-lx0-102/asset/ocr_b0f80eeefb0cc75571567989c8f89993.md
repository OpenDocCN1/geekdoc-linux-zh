consisting of the keyword Section and the section name in quotes and end with the keyword EndSection:

```
Section "InputDevice"
Identifier "Keyboard0"
Driver "kbd"
Option "XkbModel" "pc105"
Option "XkbLayout" "us"
Option "AutoRepeat" "500 200"
```

EndSection This section tells X about the keyboard—its model, layout, and so on. Details for the sections you're most need to adjust are described shortly, in “X Configuration Options.", For the most part, the different X servers support the same sections and most of the option names. A few exceptions to this rule do, though:

+   - The option isn't used in XFree8 3.3.6 and earlier. Instead, the option name (as XkbLayout or AutoRepeat in the preceding example) appears without quotes as the first word on the line.
- XFree8 3.3.6 and earlier don't use the ServerLayout section, described later in “Putting It All Together.
- XFree8 3.6 and earlier lack the Identifier and Driver lines, which are common in the XFree8 4.x and X-ORG1 configuration files.
- Some section-specific features vary between versions. I describe the most important of these in the coming pages.

# The X Configure-and-Test Cycle

If your X configuration isn't working correctly, you will need to be able to modify configuration and test it. Many Linux distributions configure the system to start X automatically; this can make it difficult to test a X configuration. To a new administrator, the only way to test a new configuration is to reboot the computer.

A better solution is to kick the system into a mode in X is not started automatically. On Red Hat, Fedora, and similar distributions, this goal can be achieved by telling telinit 3. This action sets the computer to run level 3, in which X normally doesn't run. Chapter 5, “Booting Linux and Editing Files,” covers runlevels in more detail.
Some distributions, such as Debian, Ubuntu, and Gentoo, you must shut down the GUI login server for signal to X by typing /etc/init.d/xdm stop. (You may need to change xdm to gdm, kdm, mdm, or lightdm, depending on your configuration).
