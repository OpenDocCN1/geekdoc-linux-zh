# Managing Processes

Parent Process ID The parent process ID (PPID) identifies the process's parent. (Neither Listing 2.3 nor Listing 2.4 shows the PPID.)

TTY teletype (TTY) is a code used to identify a terminal. As illustrated by Listings 2.3 and 2.4, not all processes have TTY numbers—X programs and demands, for instance, don't. Text-mode programs have these numbers, which point to a console, xterm, or remote login.

CPU Time The TIME and %CPU time are measures of CPU time used, and the second represents the percentage of CPU time this is used when ps executes. Both can help you spot runaway processes—those that are consuming too much CPU time. Unfortunately, what constitutes "too much" from one program to another, so it's impossible to give a simple rule to help you spot a runaway process.

CPU Priority As described, in "Managing Process Priorities," it's possible to give different processes priorities for CPU time. The NI column, if present (it's not in the preceding examples) lists these priority. The default value is 0. Positive values represent reduced priority, negative values represent increased priority.

Memory Usage Various headings indicate memory usage—for instance, RSS is resident size (the memory used by the program and its data), and SHARE is the percentage of memory that the program is using. Some outputs also include a SHARE column, which is memory that's shared with other processes (such as shared libraries). With CPU-use measures, these columns can help you point to the sources of difficulties; because legitimate memory of programs vary so much, it's impossible to give a simple criterion for a problem exists.

Command The final command in most listings is the command used to launch the process. This is truncated in Listing 2.4 because this format lists the complete command, but so much other information appears that the command won't usually fit on one line. (This is where the wide-column options can be in hand.)

As you can see, a lot of information can be gleaned from ps listing—or perhaps that should be the plural listings, no single format includes all of the available information. For the most part, the PID, username, and command are the most important pieces of information. In some cases, though, you may need specific other components. If your system's memory or CPU use has skyrocketed, you'll want to pay attention to the memory or CPU use.

It's often necessary to find specific processes. You might want to find the PID associated with a particular command in order to kill it, for instance. This information can be gleaned by piping the ps output through grep, as ps ax | grep bash to find all the instances of bash.
