# Appendix A · Answers to Review Questions

+   15. Once you've configured one computer on your network to use an outside time source
and run NTP; the rest of your computers should use the first computer as their
reference. This reduces the load on the external servers, as well as your own
network traffic. Thus, Option D is correct. (Very large networks might configure
two or three internal servers that refer to outside servers for redundancy, but
is not necessary for the small network described in the question.) Option A describes thenprocedure to use a time server for the first computer (gateway.pangaea
ed) but not using several computers. Configuring other computers to use
tp.example.com instead of or in addition to gateway.pangaea is possible, so we
will increase your network traffic and the load on the ntp.example.com.
Thus, Option B and C are both correct. Contrary to option E, NTP is suitable for
s small networks, and it is very helpful if you use certain protocols, such as
Kerberos.

+   16. B. The cron utility is a good tool for performing tasks that can be done in
unsupervised manner, as deleting old temporary files (option B) or checking to see
that are running correctly (option D). Tasks that require interaction, such as
creating accounts (option C), are not good for cron jobs, which must execute
unsupervised. Although a cron could restart a crashed server, it's not normally used to
start a server when the system boots (option A); that's done through system startup scripts
or a super server. Sending files to a printer (option E) is generally handled by a print server
with CUPS.

+   17. B. User jobs don't include a username specification (tbaker in options A and C).
*/ 29 specification for the hour in options A C and D causes the job to execute every
other hour; the 7, 19 specification in options A and B causes it to execute twice a day, on
7th and 19th hours (in conjunction with the 15 specification, that means at
7:15 a.m. and 7:15 p.m.). Thus, option B provides the correct syntax and runs the job twice
a day, the question specifies whereas, option A, C, and D all get something wrong.
Option E executes the job to run once, not twice a day.

+   18. The anacron is a supplement to cron that helps ensure log rotation, /tmp
cleanup, and other traditional cron jobs are handled when the computer is
shut down (and, when cron isn't running) for extended periods of time. Thus, this is
the program to achieve the stated goal, and option B is correct. There is
no Linux utility called temp, for controlling cron. Option C's crontab is the
name of log rotation on a laptop. The ntpd daemon (option E) is the NTP daemon,
which keeps the system clock in sync with an external source. Although running ntpd
on a laptop is possible, it won't directly help with the task of scheduling log
rotation. The syslog-ng package is an alternative system daemon, but that
does't solve the problem of potentially unreliable log rotation on laptops using
standard cron utilities.
