# top: A Dynamic ps Variant

If you know how much CPU time processes are consuming relative to another or if you want to quickly discover processes are consuming the most CPU time, a called top is for the job. The top tool is a text-mode program, but of course it can be run in xterm or similar window, as shown in Figure 2.2; there are also GUI interfaces, like klima and gnome-system-monitor. By default, top sorts its entries by CPU time, and it updates every few seconds. This makes it a very good tool for sorting processes on an otherwise lightly loaded system—processes almost always appear in the first position or two, and they consume an inordinate amount of CPU time. Looking at Figure 2.2 you might find thatCore.exe is such a process, but it is legitimately consuming a lot of CPU time. You'll need to be familiar with the purposes and normal habits of programs running on your system in order to make determinations; the needs of different programs vary so much that it's impossible to give a simple rule for judging when a process is consuming too much time.
