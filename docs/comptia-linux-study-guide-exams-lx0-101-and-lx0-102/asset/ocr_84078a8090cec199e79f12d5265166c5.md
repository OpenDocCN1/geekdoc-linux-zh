# Monitoring Disk Use by Directory

The df command is helpful for finding out which partitions are in danger of becoming overloaded, but once you've obtained this information you may fine-tune the diagnosis and track the directories and files that are chewing up disk space. The tool for this task is du, which has a syntax similar to that of df:

```
du [options] [directories]
```

This command searches directories and reports how much disk space each is consuming. Its search is recursive, so you can learn how much space the directory and all its subdirectories consume. The result can be a very long listing if you specify directories with many files, but several options can reduce the size of the output. Others can perform helpful tasks as:

**Summarize Files As Directories** Ordinarily, du reports on the space used by the directories but not the space used by individual files. Passing the -a or --all option causes to report on individual files as

**Compute a Grand Total** Adding the -h or --human-readable option causes to add a grand total to the end of its output.

**Used Units** The -h for instead of reporting the total disk space used as 8589784 blocks, it reports the size in 5.66 (5.6GB). The -H and -s options have a similar effect, but they use power-of-10 (1000, 1000000) and power-of-2 (1024, 1048576) as units. The -k (-kilobytes) and -m (-megabytes) options force out their respective units.

**Count Links** Ordinarily, du counts files that appear multiple times as hard links only once. This reflects true disk space, but sometimes you may want to count each independently—for instance, if you're creating a CD-R and the file will be stored for each link. To do so, include the -1 (a lowercase L) or --count-links option. (Links are described in more detail in Chapter 4).

**Limit Depth** The --max=n option limits the report to n levels. (The subdirectories' contents are counted if they aren't reported).

**Summarize** If you don't want a level of output for each subdirectory in the tree, the -s or --summarize option, limits the report to those files and directories you specify on the command line. This option is equivalent to --max-depth=0.

**Limit to One Filesystem** The -x or --one-file-system option limits the report to the current filesystem. If another filesystem is mounted within the tree wanted summarized, its contents aren't included in the report.
