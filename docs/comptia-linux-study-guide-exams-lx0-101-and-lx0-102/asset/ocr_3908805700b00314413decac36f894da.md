# Using Regular Expressions

> > **NOTE**  
> For an ordinary ASCII file, the character and byte counts will be identical. These values may diverge for files that use multi-byte character encodings.

Many Linux programs employ regular expressions, which are tools for describing or matching patterns in text. Regular expressions are similar in principle to the wildcards that can be used to specify multiple filenames. At their simplest, regular expressions can be plain text without adornment. Certain characters are used to denote patterns, though. Because of their importance, I describe regular expressions here. I also cover two programs that make heavy use of regular expressions: grep and sed. These programs search for text files and permit editing of files from the command line, respectively.

# Understanding Regular Expressions

Two forms of regular expression are common: basic and extended. Which form you must use depends on the program; some one form or the other, but others can use either type, depending on the options passed to the program. (Some programs use their own minor or major variants on of these classes of regular expression.) The differences between basic and extended regular expressions are complex but, the fundamental principles of both are similar.

The simplest type of regular expression is an alphabetic string, such as Linux or Haddr. These regular expressions match any string of the same size or larger that contains the regular expression. For instance, the Haddr regular expression matches Haddr, This is Haddr, and The Haddr is unknown. The real strength of regular expressions lies in the use of non-alphabetic characters, which activate advanced matching rules:

**Bracket Expressions** enclosed in square brackets [] constitute bracket expressions, which match any character within the brackets. For instance, the regular expression b[aeiouj] matches the words bag, beg, big, bog, and bug.

**Range Expressions** A range is a variant on bracket expression. Instead of listing every character, range expressions match the start and end points separated by a dash (-), as in [a-z]. This regular expression matches a2, a3, and a4z.

**Any Single Character** The dot (.) represents any single character except a newline. In instance, a z matches abz, abb, a0z, or any other three-character string that begins with a and ends with z.

**Start and End of Line** The caret (^) represents the start of the line, and the dollar sign ($) denotes the end of a line.
