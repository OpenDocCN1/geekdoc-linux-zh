# Deleting Data

Sometimes your data needs to be deleted. Table 9.4 suggests that the tree in the back yard is ill—its condition rating is 2 on a 10-point scale. Perhaps you'll decide to cut it down and remove it from the locations database. To do so, you'll use the DELETE command, which takes the following form:

```
DELETE FROM table conditions
```

For instance, to delete removed-tree, you can type the following command:

```
mysql> DELETE FROM locations
-> WHERE name='tree' AND location='back yard';
Query OK, 1 row affected (0.05 sec)
```

In this specific case, the WHERE condition is more detailed than it needs to be, because the back yard tree is the only one in the table. As when deleting sort of data on a computer, it's better to be cautious than sloppy.

![](bbox=[0.141, 0.465, 0.215, 0.515])

Before deleting data, using SELECT to see what data your WHERE condition matches. This will help you prevent accidentally deleting too much data.

You can delete all the data from a table by using the DELETE command: DELETE * from locations; This command deletes all the table's data without deleting the table. This may be useful if the table is hopelessly messed up from experimentation. An even more drastic deletion is DROP: DROP TABLE locations; This example completely completes the locations table. Naturally, this is an extremely dangerous command, but you might want to use it when cleaning up your SQL session practice.

# Learning More About SQL

SQL is a very complex topic, and this chapter can only scratch the surface. For more information, you should read from various sources. Your own SQL package's documentation can be a good starting point, particularly if you need to use features that are unique to your implementation. Books on SQL, such as Alan Beaieu's Learning SQL, 2nd Edition (O'Reilly, 2009) and Alex Kriegel's SQL Bible (Wiley, 2008), are also worth reading if you need to do more than trivial SQL work.
