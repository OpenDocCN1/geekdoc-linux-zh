The traceroute command (option C) identifies the copies that lie between your own computer and a destination computer, with some very basic information about network packet time and reliability. Thus, traceroute can help track down the source of the described problem—perhaps a tracer to reaching all of the non-responsive systems has failed. The netstat and ifconfig utilities of both provide information about local network configuration options, but most likely won't be of help in diagnosing a problem that affects some sites. You can use dig (option E) to obtain information on the mapping of hostnames to IP addresses, but it will help in resolving connectivity problems.

- 1. The current directory indicator is particularly dangerous in root~/PATH environment variable because it can be used by unsanitary local users to trick root into running programs of the unsanitary user. Thus, option E is correct and all the other options are correct.

- 2. The alias built-in command creates a duplicate name for a (potentially longer) command. Option A shows the correct syntax for using this built-in command; it causes the new alias cdt to work with the longer cd ~/papers/trade. The export option B creates an environment variable cdt that holds the value cd ~/papers/trade. This will have no useful effect. Option C, if placed in a bash script, will cause the user's current directory to shift to ~/papers/trade immediately after the user logs in. There is no standard shortcut command, so option D is meaningless. Although it is valid, it is used incorrectly in option E, and so this option is correct.

- 3. Some programs use the EDITOR environment variable in option E. Contrary to option A, the EDITOR environment variable has nothing to do with command-line editing. When you're typing at a bash prompt, bash provides simple editing features, so option B is incorrect. (You can launch the editor specified by $EDITOR by typing Ctrl+L followed by Ctrl+E, The edit doesn't behave as option C. This might be configured differently on different systems.) You can create links like GUI and TEXT to have the EDITOR environment variable behave as option D suggests, but isn't a normal configuration.

- 4. The PWD environment variable holds the present working directory, so option C is correct. The PATH environment variable (option A) holds a colon-delimited list of directories in executable programs are stored so that they may be run without specifying their complete paths. There are no standard CMD, PRESENT, or WORKING environment variables, so option B, D, and E are all incorrect.
