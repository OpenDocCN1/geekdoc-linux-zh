
# The mv Command

The mv (short for move) is commonly used to move files and directories from one location to another and to rename them. Linux doesn't distinguish between these two types of operations, however many users do. The syntax of mv is similar to that of cp:

```
mv [options] source destination
```

The command takes many of the same options as cp does. From the earlier, --preserve,--recursive, and --archive do not apply to mv, but the others do.
to move one or more files or directories, specify the files as the source and specify a directory or (optionally, for a single-file) filename for the destination:

```
$ mv document.odt important/purchase/
```

![](bbox=[0.14, 0.763, 0.228, 0.808])

This example uses a slash (/) on the destination directory. For instance, the destination can help avoid problems caused by typos. If the destination was mistyped as important/purchase (missing the final s), mv would move document.odt into the important directory under the filename. Adding the slash makes it clear you intend to move the file into a subdirectory. If it doesn't exist, mv complains, so you're not left with mysterious filenames. You can also use the Tab key to avoid problems. When you press Tab in many Linux shells, such as bash, the shell tries to complete the filename automatically, reducing the risk of a typo.
