The cal program displays a text-mode calendar, enabling you to identify the days of a week or a month; it doesn't schedule future jobs, option B suggests. A GUI calendar program, as specified in option D, might work; but NTP is the Network Time Protocol, a protocol and like-program for synchronizing clocks across a network. +   16. D provides the correct command to add 172.24.2.1 as the default gateway. Options A and B both use the fictitious gateway command, which doesn't exist and therefore work unless you create a script of that. Option C uses the correct command, but there is no gateway option to route; you must use default gw, as option E is incorrect. For more information, please see Chapter 8, "Configuring Basic Networking."

+   17. B. The BLTTY package is a daemon for handling a Braille display, and some features for using these devices have been added to the 2.6.26 kernel, so options B and C are correct. option A is speech-synthesis software; it can "speak" a text to a user, but it doesn't interface with Braille displays. GOK (option D) is an on-screen keyboard, not a Braille display tool. Framebuffer drivers (option E) are kernel drivers for managing video cards; they aren't used to route Braille displays. For more information, please see Chapter 6, "Configuring the X Window System, Localization, and Printing."

+   18. C. Some dependencies result from dynamically linking binaries to libraries at compile time and can be overcome by recompiling the software from a source RPM, so option C is correct. Option A describes source packages, not RPM packages. Recompiling a source RPM requires only an appropriate command, although you must also have appropriate compilers and libraries installed. Thus, option B is overly pessimistic. Source tarballs can also be used to compile software for RPM systems, which results in none of RPM's advantages. Thus, option D is overly restrictive. The RPM format doesn't impose any licensing requirements, contrary to option E. For more information, please see Chapter 2, "Managing Files."

+   19. D. The mv utility is used to rename files as they move from one location to another, so option D is correct. The dd utility (option A) is used to copy files to backups, rm (option B) is used to remove (delete) files, cp (option C) copies files, and ln (option E) creates links. For more information, please see Chapter 4, "Managing Files."

+   20. B. Adding an ampersand (&) to a command causes to execute in the background. The program so still consumes CPU time, but it won't monopolize the shell you need to launch. The start (option A) and back-ground (option D) commands are fictitious. Although bg (option C) places a job into the background, it doesn't launch a program that way; it places a process that's been suspended (by pressing Ctrl+Z) into the background. The nice utility (option E) launches a program with modified priority, but a program so launched-with & still monopolizes its shell unless you take additional steps. For more information, please see Chapter 2, "Managing Software."
