# Squeezing Ghostscript into the Queue

Printing to a non-PostScript printer in Linux requires fitting Ghostscript into the print queue. This is generally done through the use of a smart filter. This is a program that's called as of the printing process, the smart filter examines the file that's being printed, determines its type, and passes the file through one or more additional programs before the printing software sends it to the printer. The smart filter can be configured to call Ghostscript with whatever parameters are appropriate to produce output for the queue's printer.

CUPS ships with its set of smart filters, which it automatically calls when you tell the smart model you're using. CUPS provides a Web-based configuration tool, as described in the upcoming section "Using the Web-Based CUPS Utilities." This system, or distribution-specific GUI configuration tools, can make setting up a printer for CUPS fairly straightforward.

The result of a typical Linux printer queue configuration is to treat any supported printer as if it were a PostScript printer. Applications that PostScript output print directly to the queue. The smart filter detects that the output is PostScript and runs it through Ghostscript. The smart filter can detect other types, such as plain-text and graphics files, and it can send them through appropriate programs instead of or in Ghostscript to create a reasonable printout.

If you have a printer that can process PostScript, the smart filter is usually involved, but it doesn't pass PostScript through Ghostscript. In this case, the smart filter passes PostScript directly to the printer, but it still sends other types through whatever processing is necessary to turn them into PostScript.

# Running a Printing System

Because Linux systems run as daemons, they must be started before they're useful. This task is normally handled automatically via startup scripts in /etc/rc.d, /etc/init.d, or /etc/rc.d? (if d is a run number). Look for startup scripts that contain the string cups (or lpd or lpr for other systems) in Linux to learn what your system is running. If you're unsure if a printing system is currently active, use the ps utility to search for running processes by these names, as in

```
$ ps ax | grep cups
1896 ?       Ss       0:01 cupsd
```
