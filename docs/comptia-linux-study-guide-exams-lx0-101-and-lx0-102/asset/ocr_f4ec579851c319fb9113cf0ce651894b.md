echoes from its standard input only the information in which you're interested. (The grep command, described in "Using grep", is often used in this role.)
Pipes can be used in sequences of arbitrary length:

```
$ first | second | third | fourth | fifth | sixth [...]
```

# # Generating Command Lines

Sometimes you will find yourself constructing a series of commands that are similar to each other but not similar enough to enable you to use their normal options to substitute a single command. For instance, suppose you want to remove every file in a directory with a name that ends in a tilde (~). This filename convention denotes backup files created by text editors. With a large directory tree, this can be daunting: the usual deletion command (rm, described in more detail in Chapter 4) doesn't provide an option to search and delete every file in a directory that matches a specific criterion. One command that can do the part of the job, which is find, and is also described in more detail in Chapter 4. This command displays all the find criteria you require. If you could combine the output of find to create a series of commands using rm, the task would be solved. This is precise premise of the *xargs* command.
xargs command builds from its standard input. The basic syntax for this command is as follows:

```
xargs [options] command [[initial-arguments]]
```

The *command* is what you want to execute, and *initial-arguments* is a list of arguments you want to pass to the command. The *options* are xargs options; they aren't passed to command. When you run xargs, it runs once for every word passed to standard input, adding that word to the argument list for command. If you want to pass multiple options to the command, you can protect them by enclosing the group in quotation marks.

For instance, consider the task of deleting all backup files, denoted by tilde characters. You can do this by piping the output of find to xargs, which then calls rm:

```
$ find ./ -name "*" xargs -d '\n rm
```

The first part of this command (find ./ -name "*\*) finds all files in the current directory (/) or its subdirectories with a name that ends in a tilde (~). This is then piped to xargs, which adds each item to its own command. Problems can arise if filenames contain spaces, so by default xargs uses both spaces and newlines as delimiters. -d '\n' tells xargs to use only newlines as delimiters, avoiding this problem in this context.
