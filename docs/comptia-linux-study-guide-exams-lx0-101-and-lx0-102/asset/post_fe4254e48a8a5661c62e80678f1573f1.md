# Chapter 1: Exploring Linux Command-Line Tools

- 1. D. Any of these approaches will work, or at least might work. (You might err when performing any of them.) Option B or C is likely to be the most efficient approach; with a long filename to type, option A is likely to be tedious.
- 2. E. The echo command is implemented internally in bash, although an external version is also available on most systems. The cat, less, tee, and seed commands are not implemented internally in bash, although they can be called from bash as external commands.
- 3. E. The echo command echoes what follows to standard output, and $PROC displays the value of the $PROC environment variable, meaning it must have been set to the specified value by you, one of configuration files, or a program you run. Although many environment variables are set to particular values to convey information, $PROC is not a standard environment variable that might be associated with information described in options A, B, C, or D.
- 4. A. The pwd command prints (to standard output) the current directory.
- 5. D. The command is used to change the current working directory.
- 6. A. The dot (.) represents the current directory.
- 7. C. The tee command sends its output to standard output and a named file.
- 8. C. The redirection operator > redirects output to a file.
- 9. A. The redirection operator >> appends output to a file.
- 10. In pipe, you can pipe together many commands as you like.
- 11. The tee command sends its output to standard output and a file.
- 12. The redirection operator 2> redirects error only, leaving standard output unaffected.
- 13. Option A correctly describes the difference between these two redirection operators.
