

## 配置基础 X 特性

垂直同步可以产生特定的分辨率和刷新率。例如，某条模式行（mode line）可能会定义 90Hz 刷新率下的 1024 × 768 显示，而另一条可能代表 72Hz 下的 1024 × 768。

某些模式行代表了显示器水平或垂直同步范围外的视频模式。X 可以计算这些情况并丢弃显示器不支持的视频模式。如果被要求执行特定分辨率，X 会搜索所有尝试该任务的模式行，丢弃它无法处理的行，并使用剩余的在该分辨率下创建最高刷新率的模式行。（如果没有模式行支持请求的分分辨率，X 将降至稍后描述的另一种分辨率，并重试。）

你还可以在你的显示器配置中包含一个 ModeLine 条目。这是因为 XFree86 4.x 和 XOrg 支持一种名为数据显示通道（DDC）的功能。这是一种允许显示器向计算机通信其最大水平和垂直刷新率以及适当的模式行的协议。你可能需要对 modeline（或 mode line）以及你所需的分辨率进行网络搜索；或者使用 XFree86 ModeLine Generator 网站 (http://xtiming.org/cgi-bin/xtiming.pl)，它可以为任何分辨率和刷新率生成 ModeLine。

## 设置显卡

显示器是决定任何给定分辨率下最大刷新率的最重要因素，而 X 通过显卡向显示器发送数据。因此，正确配置此组件至关重要。显卡的配置错误可能会导致无法启动 X。在过去，视频硬件总是作为插卡实现的。大多数现代计算机将视频硬件集成在主板上。尽管如此，即使计算机有独立的插卡，通常也称其为显卡。

## 选择驱动程序

有时 X 可以自动选择最佳驱动程序。其他情况下，你必须在 XF86Config 或 xorg.conf 文件提供提供信息。特别是驱动程序位于 `/usr/X11/lib/modules/drivers/` 或 `/usr/lib/xorg/modules/drivers/`。在某些系统中，大多数驱动文件名以 `_drv.so` 结尾，如果你移除这个后缀，剩下的就是驱动名称。例如，`nv_drv.so` 对应 nv 驱动。

## 第 6 章 配置 X 窗口系统、本地化和打印

某些 X 配置工具提供了大量的芯片组和特定显卡列表，因此你可以从列表中选择芯片组或主板，让工具来配置这些细节。如果 Xorg 必须创建初始配置，生成的文件可能会包含多个 `Device` 部分，每个部分对应一个不同的驱动程序。其中一些（如 `fbdev` 和 `vena`）是通用驱动程序，适用于多种显卡。今天，你最可能使用 `nouveau` 驱动（适用于 NVIDIA 显）、`radeon` 驱动（适用于 ATI/AMD 显）或 `intel` 驱动（适用于 Intel 显）。你需要了解一些你的视频硬件以选择最佳的一个。如果你有疑问，可以按照稍后“设置分辨率和色彩深度”中的描述的方法，通过依次指定每个 `Device` 部分来尝试每一个。

## 设置特定特定选项

`xorg.conf` 文件中的 `Device` 部分设置了与 X 服务器相关的各种选项。一个典型的 `Device` 部分如下：

```
Section "Device"
Identifier "videocard0"
Driver "nvidia"
VendorName "nvidia"
BoardName "GeForce 6100"
VideoRam 0
```

`Identifier` 提供了一个名称，用于随后的 `Screen` 部分以标识此特定的 `Device` 部分。`VendorName` 和 `BoardName` 提供的信息主要对阅读文件的人有用。对于大多数主板，`VideoRam` 是不必要的，因为驱动程序可以检测卡中安装的 RAM 数量。对于某些设备，你可能需要以 KB 为单位指定卡中安装的 RAM 量。例如，前面的示例是一个安装了 128MB RAM 的显卡。

许多驱动程序支持额外的驱动程序特定选项。它们可能启用对功能的支持，例如硬件光标（允许显卡更容易处理指针的特殊硬件）或缓存（使用空闲内存加速各种操作）。详情请咨询 XF86Config 或 xorg.conf 的帮助页，或其他特定于驱动程序的文档。

## 设置分辨率和色彩深度

`Screen` 部分告诉 X 你正在使用的显示器和显卡的组合。XFree86 4.x 和 XOrg-X11 支持在系统上使用多个显卡和显示器。这在你测试新的显示器或显卡驱动程序时非常有用。无论如何，`Screen` 部分看起来类似于此：

```
Section "Screen"
Identifier "Screen0"
Device "Videocard0"
Monitor "Monitor0"
DefaultDepth 24
SubSection "Display"
Depth 24
Modes "1920x1080" "1280x1024" "1024x768"
EndSection
SubSection "Display"
Depth 8
Modes "1024x768" "800x600" "640x480"
EndSection
EndSection
```

`Device` 和 `Monitor` 行分别引用你 `Device` 和 `Monitor` 部分中的 `Identifier` 行。`Screen` 部分包含一个或多个 `Display` 子部分，它们定义了 X 可能使用的视频模式。此示例创建了两个显示器。第一个使用 24 位色彩深度（Depth 24）以及可能的视频模式设置 1920x1080、1280x1024 和 1024x768。（这些视频模式实际上是名称）。第二个显示器使用 8 位色彩深度（Depth 8）以及可能的视频模式设置 1024x768、800x600 和 640x480。
