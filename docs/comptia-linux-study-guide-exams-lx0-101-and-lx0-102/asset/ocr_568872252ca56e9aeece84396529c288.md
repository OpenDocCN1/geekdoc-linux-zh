# Configuring Printing

Chances are good that you'll find support for your printer in your standard installation, particularly if your distribution has installed the Fomatic or Gutenprint package. If you start configuring printers and can't find your model, though, you should look for an additional printer definition from one of the preceding sources.

# Using the Web-Based CUPS Utilities

The CUPS IP printing system is closely related to the Hypertext Transfer Protocol (HTTP) used on the Web. The protocol is so similar, in fact, you can access a CUPS daemon by using a Web browser. You need only specify that you want to access the server on 631—the normal printer. To do so, enter http://localhost:631 in a Web browser on the computer running.. You may be able to substitute the hostname or access CUPS from another computer by using the server's hostname, depending on your cups.conf settings.) This action brings up a list of administrative tasks you can perform. Click Printers or Managers to open the printer manager page, shown in Figure 6.6.
