# Using File Management Commands

| --listed-incremental file | g | Performs an incremental backup or restore, using file as a list of previously archived files |

| --one-file-system | 1 (on old versions of tar) | Backs up or restores only one filesystem (partition) |

| --multi-volume | M | Creates or extracts a multi-tape archive |

| --tape-length N | L | Changes tapes after N kilobytes |

| --same-permissions | p | Preserves all protection information |

| --absolute-paths | P | Retains the leading / filenames |

| --verbose | v | Lists all files read or extracted; when used with --list, displays file sizes, ownership, and time stamps |

| --verify | W | Verifies the archive after writing it |

| --exclude file | (none) | Excludes file from the archive |

| --exclude-from file | X | Excludes listed file from the archive |

| --gzip --unzip | z | Processes an archive through gzip |

| --bzip2 | j (some older versions used I Or) | Processes an archive through bzip2 |

| --xz | J | Processes an archive through xz |

Of the commands in Table 4.1, the most commonly used are --create, --extract, and --list. The most useful qualifiers from Table 4.2 are --file, --listed-incremental, --one-file-system, --same-permissions, --gzip, --bzip2, --xz, and --verbose. If you fail to specify a filename with the --file qualifier, tar will attempt to use a default device, which is (but not always) with a tape device.

Three compression tools—gzip, bzip2, and xz—are often used with tar, applies compression to the tarball rather than to the individual files. This method of compressing reduces the tarball's size compared to compressing constituent files and adding them to the archive, but it makes the archive more susceptible to damage; a singlebyte error early in the archive can make it impossible to recover any subsequent data.
