By default, join uses the first field to match across files. Because Listings 1.1 and 1.2 both place the phone number in the -1 or -2 cameras, it's the key field in the output. You can specify another field by using the join -1 -3 -2 cameras to specify the join field for the first or second file, respectively, as in cameras.txt lenses.txt to join using the third field in cameras.txt and the second field in lenses.txt. the -FORMAT option enables more specifications for the output file format; consult the main page for more details.

The join command can be used at the core of a set of customized database-management tools using Linux text-manipulation commands. It is very limited by itself, though; for instance, it requires its two files to have the same ordering of lines. (You can use the sort command to ensure this is so.)

# Merging Lists with paste

The paste command merges files by line, separating the lines from each file with tabs, as shown in the following example, using Listings 1.1 and 1.2 again:

```
$ paste listing1.txt listing2.txt
555-2397 Beckett, Barry 555-2397 unlisted
555-5116 Carter, Gertrude
555-7929 Jones, Theresa 555-7929 listed
555-9871 Orwell, Samuel 555-9871 unlisted
```

You can use paste to combine data from files that aren't keyed with fields suitable for use by join. Of course, to be meaningful, the line numbers must be exactly equivalent. Alternatively, you can use paste as a quick to create a two-column output of textual data; however, the alignment of the second column may not be exact if the first column's line lengths are not even, as shown in the preceding example.

# File-Transforming Commands

Many of Linux's text-manipulation commands are aimed at transforming the contents of files. These commands don't actually change files' contents, though; rather, send the changed file to standard output. You can then pipe this output to another command or redirect it to a new file.

> An important file-transforming command is sed. This command is very complex and covered later in this chapter, in "Using sed."
