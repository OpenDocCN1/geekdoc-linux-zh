+   20. The /etc/nsswitch.conf file contains the order of name resolution, among other things. Option D correctly describes the procedure for changing the order in Linux performs name resolution. The /etc/resol.conf file mentioned in option A controls the DNS servers that Linux uses, but doesn't control access to /etc/hosts. This server isn't likely to be installed on most Linux systems, and even if it is, the procedure described in option C is invalid.
