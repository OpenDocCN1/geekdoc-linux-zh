The lpr command is accessible to ordinary users as well as to root, anybody may print using this command. It's also called from many programs that need to print directly, as as graphics programs and word processors. These programs typically give you some way to adjust the print so that you can enter parameters as the printer name. For instance, Figure 6.7 shows Firefox's Print dialog box, which features a list of available queues, Range enables you to print a subset of the document's pages, and a Copies field that you can print multiple copies. Additional tabs enable you to set more options. Some programs provide a text entry in which you type or all of an lpr command enables selecting from a list of available queues and options. Consult the program's documentation if you're not sure how it works.

Sometimes you want to process a file in some way prior to sending it to the printer. Chapter 1 covers some commands that can do this, as fmt and pr. Another program is mpage, which reads plain-text or PostScript files and reformats them so that each printed sheet contains several reduced-size pages from the original document. This can be a good way to save paper if you don't mind a reduction in the document's text or image size. In the simplest case, you can use mpage much as you use lpr:

```
$ mpage -Plexmark report.ps
```
