Thus, you can configure sudoers that georgia can run network programs with root privileges but not account maintenance tools, whereas george can run account maintenance tools but not network programs.

Your default /etc/sudoers file probably several examples. Consider the following lines:

```
## Storage
Cmnd_Alias STORAGE = /bin/fsdisk, /bin/sfdisk, /bin/parted,
/bin/partprobe, /bin/mount, /bin/umount
## Processes
Cmnd_Alias PROCESSES = /bin/nite, /bin/kill, /usr/bin/kill, /usr/bin/killall
%sys ALL = STORAGE, PROCESSES
%disk ALL = STORAGE
%wheel ALL=(ALL) ALL
```

This example defines two command aliases, STORAGE and PROCESSES, each of which stands for a set of commands. Users who are members of the sys group may use both commands; users who are members of the disk group may use the STORAGE commands but not the PROCESSES commands; and members of the wheel group may use all commands, whether or not they're explicitly mentioned in /etc/sudoers.

Some distributions, such as Ubuntu, make heavy use of sudo; these distributions are designed to be administered exclusively via sudo, and they set up an /etc/sudoers file that provides at least one user access to all system utilities. Other distributions rely on sudo, although you can tweak your sudo configuration to enable administration via sudo if you like.

# Setting Login, Process, and Memory Limits

Sometimes you may want to impose limits on how many times you may log in, how much CPU time they consume, how much memory they can use, and so on. Imposing such limits is best done through Pluggable Authentication Modules (PAM) module called pam_limits. Most Linux distributions use this module as part of their standard PAM configuration, so chances you won't need to add it; however, you will still need to configure pam_limits. You do so by editing your configuration file, /etc/security/limits/.conf. This file contains fields (denoted by a hash mark,) and limit lines that consist of four fields:

domain type item value

Each of these fields specifies a particular type of information:

The Domain The domain defines the entity to which the limit applies. It can be a username; a group name, which takes the form @groupname; or an asterisk (*) wildcard, which matches everybody.
