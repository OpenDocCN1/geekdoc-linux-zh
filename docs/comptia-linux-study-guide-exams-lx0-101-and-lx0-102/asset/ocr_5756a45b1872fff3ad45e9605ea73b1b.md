> The /proc filesystem is a virtual filesystem—it doesn't refer to actual files
on a hard disk but kernel data that is convenient to represent using a\filesystem. The files in /proc provide information about the hardware,
running processes, and so on. Many Linux utilities use /proc behind the
scenes; or you can directly access these files using utilities like cat, which\copies the data to the screen when given just one argument.

This output shows the drivers that are using each IRQ. Some of these
driver names are easy to interpret, such as floppy. Others are more puzzling, as cx88
(it's a driver for a video capture card). If the purpose of a driver isn't obvious, doing a
we search on; you'll find a relevant hit fairly easily. Note that the preceding
output interrupts numbered up to 22; this system supports more than the 16 base
x86 interrupts.
