# The find Command

The find utility implements a brute-force approach to finding files. This program finds files by searching through the specified directory tree, checking filenames, file creation dates, and so on to locate the files that match the specified criteria. Because of this method of operation, find tends to be slow; but it's very flexible and is very likely to succeed, assuming the file for you are searching exists. The find syntax is as follows:

```
find [path...] [expression...]
```

You can specify one or more paths in which find should operate; the program will restrict its operations to these paths. The expression is a way of specifying what you want to find. The main page for find includes information about these expressions, but some of the common enable you use to search by various criteria:

**Search by Filename** You can search for a filename using the -name pattern expression. Doing so finds files that match the specified pattern. If pattern is an ordinary filename, find matches exactly. You can use wildcards if you enclose pattern in quotes, and will locate files that match the wildcard filename.

**Search by Permission Mode** If you need to find files with certain permissions, you can do so using the -perm mode expression. The mode may be expressed symbolically or in octal form. If you precede mode with a +, locate files in which any of the specified permissions are set. If you precede mode with a -, find files in which all the specified permissions bits are set.

**Search by Size** You can search for a file of a given size with the -size n expression. Normally, n is specified in 512-byte blocks, but you can modify this by trailing the value with a letter code, c for bytes or k for kilobytes.

**Search by Group** The -gid expression searches for files whose group ID (GID) is set to GID. The -group name option locates files whose group name is name. The former is handy if the GID has been orphaned and has no name, but the latter is easier to use.

**Search by User ID** The -uid expression searches for files owned by user ID (UID) is UID. The -user name option searches for files owned by name. The former can be handy if the UID has been orphaned and has no name, but the latter is generally easier to use.

**Restrict Search Depth** If you want to search a directory and, perhaps, limited number of subdirectories, use the -maxdepth levels to limit the search.

There are many variant and additional options; find is a very powerful command. As an example of it, consider the task of finding all C source code files, which normally have names ending in .c, in all users' home directories. If these home directories reside in /home, you might issue the following command:

```
# find /home -name "*.c"
```
