# Chapter 6 • Configuring the X Window System, Localization, and Printing

> Some X configuration utilities provide a large list of chipsets and specific video cards, so you can select the chipset or board from this list to have the utility configure this detail.

If you Xorg -configure to create an initial configuration, the resulting file is likely to include multiple Device sections, each for a different driver. Some of these, such as fbdev and vena, are generic drivers that work—but not optimally—on a wide variety of video cards. Today, you're most likely to use the nouveau drivers (which work on NVIDIA cards), the radeon driver (which works on ATI/AMD cards), or the intel driver (which works on Intel cards). You'll need to know something about your video hardware to pick the best one. If you're in doubt, you can try each one in turn, by specifying each Device section in turn in the Screen section, as described later, in “Setting the Resolution and Color Depth."

# Setting-Card-Specific Options

The Device section of the xorg.conf file sets various options related to X servers. A typical Device section resembles this:

Section “Device”

| Identifier | Value |
| --- | --- |
| Driver | "videocard0" |
| VendorName | "nvidia" |
| BoardName | "GeForce 6100" |
| VideoRam | 131072 |

The Identifier provides a name that is used in the subsequent Screen section to identify this particular Device section. The VendorName and BoardName provide information that is useful mainly to people reading the file.\ VideoRam is unnecessary with most boards because the driver can detect the amount of RAM installed in the card. With some devices, you may need to specify the amount of RAM installed in the card, in kilobytes. For instance, the preceding example a card with 128MB of RAM installed.

Many drivers support additional driver-specific options. They may enable support for features such as hardware cursors (special hardware that enables the card to handle pointers more easily) or caches (using spare memory to speed up various operations). Consult the XF86Config or xorg.conf man page or other driver-specific documentation for details.
