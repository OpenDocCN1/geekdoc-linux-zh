# Standard Keyboard and Mouse Options

Most Linux desktop environments include keyboard and mouse control panel options. For instance, in a standard Fedora 17 GNOME installation, you can find the keyboard options in the Keyboard item of the System Settings control panel, and you can find the mouse options in the Mouse and Touch item. The AccessX utility is an older program that works in any desktop environment to provide similar features. Figure 6.4 shows AccessX in operation. Because the locations of such options can be customized from distribution to another and can change from release to release, you may need to hunt for your options in menus.

The exam objectives mention AccessX; however, this package is not available in most distributions and appears to be abandoned. Its functionality has been folded into desktop environment control panels. Thus, I describe AccessX's features, chances you'll need to look for equivalents in your desktop environment's control panel.
