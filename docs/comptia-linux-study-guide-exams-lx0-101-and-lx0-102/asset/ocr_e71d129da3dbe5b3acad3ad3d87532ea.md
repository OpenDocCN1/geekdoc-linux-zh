+   13. Option D, D 027, removes write permissions for the group and all world permissions. (Files normally don't execute permissions set, but explicitly removing writing when removing permissions ensures reasonable behavior for directories.) Option D, 640, is the octal equivalent of the desired rw---- permissions; but the mask sets the bits that are to be removed from permissions, not those that are to set. Option B, 210, would remove write permission for the owner, but wouldn't remove write permission for the group, which is incorrect. It would also leave world permissions open. Option C, 022, wouldn't remove read permission. Option E, 138, is an invalid mask, as all digits in it must be between 0 and 7.

+   14. Using quotas requires kernel support, the usquota or grquota (for user or group quotas) filesystem mount option, and activation via the quota command (which often appears in system startup scripts). Thus, E is correct. Option A suggests that quota is not necessary, which is correct. Option B's statement that grquota is invalid is incorrect. Option C's statement that these options disable quota support is correct. The usquota and grquota options are both valid, so option D is incorrect.

+   15. The repent utility is used to summarize the quota information for the filesystem. When used with the –a, it shows information for all filesystems, so option B is correct. This command won't return useful information when typed alone, so option A is incorrect. The quotacheck utility checks quota information about a disk and writes corrections. The edquota utility enables you to edit quota information. It doesn't summarize quota information, and isn't a valid option to edquota. Thus, option E is correct.

+   16. The /opt directory exists to hold programs that aren't a standard part of a Linux distribution, such as commercial programs. These programs should install in their own directories under /opt; these isn't required. Thus, option D is correct (that is, it's a plausible possibility). The /usr/sbin directory holds programs that are run only by the system administrator, so it's not a location, making option A incorrect. The /etc/X11 directory holds configured files, so it's very unlikely that WonderCalc will be housed there, option B incorrect. The /boot directory holds critical system files, the /sbin directory, like /usr/sbin, is an unlikely location for user files, so option E is incorrect. (Furthermore, /sbin contains subdirectories.)

+   17. The find utility (option A) operates by searching all files in a directory, and so it's likely to take a long time to search all of a computer's directories. The locate program uses a precompiled database, where searches a limited set of directories, and type searches the shell's path and built-in commands, so these commands will take less time. Thus, options B, C, D, and E are all incorrect.
