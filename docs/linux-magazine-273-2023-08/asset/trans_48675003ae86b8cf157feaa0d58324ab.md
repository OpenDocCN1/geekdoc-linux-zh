
## 3D 查看器
### F3D

自从计算机能够绘制点并在它们之间连接线条以来，我们就拥有了 3D 查看器。早在 20 世纪 60 年代，计算机就能驱动示波器和阴极射线管，将三维物体映射到二维平面上进行显示。这种痴迷伴随计算机经历了 1968 年电影《2001 太空漫游》中的空间站视角、20 世纪 70 年代的视频游戏《迷宫》（又名《迷宫战争》），以及 20 世纪 80 年代充斥着电视屏幕的大量线框和填充多边形，直到从 20 世纪 90 年代起，加速图形技术使得这一切变得**微不足道**。现在你可以随时随地在 3D 环境中查看物体，无论是通过手机、网页浏览器，还是佩戴 VR 头显体验真实的 3D。但是，如果你需要在命令行中快速预览 3D 对象，你仍然会感到受限。如果你在桌面上有几分钟空闲时间，你可以快速将文件放入 Blender，创建一个简单的场景并进行渲染，但出色的 F3D 在输出方面做得更棒，并且可以直接从命令行完成这些操作，无需复杂的 UI 交互。

F3D 可以加载大量 3D 文件，从 1993 年的 VTK 文件到现代 LiDAR 生成的包含数百万个点云的 PLY 点云和科学数据集。无论内容如何，它都会美观地渲染到一个独立的桌面窗口中，在那里你对输出也有相当大的控制权。鼠标和 Shift 键可以在三维空间中旋转和平移场景，而热键可以启用抗锯齿、色调映射、颜色循环、点精灵渲染、HDR 和环境映射、不透明度以及体积渲染。这些选项也可以在命令行中提供，而光线追踪选项需要启用特定的构建选项，但它们看起来都非常棒，你往往会发现自己下载各种各样的 3D 文件只是为了能如此方便地探索它们。

## 远程 Android
### scrcpy

曾经有一段时间，访问远程桌面是运行 Linux 的重要组成部分。那是一个除非你想与 Webmin 搏斗，否则远程解决问题的最好方法就是直接使用故障系统的桌面的时代。这有助于 Linux 的普及，因为 Linux 在这方面非常擅长。甚至在互联网变得令人沉迷之前，图形应用程序就可以通过 X11 协议本身通过网络进行隧道传输，让你能够在本地运行远程图形应用程序。稍后，VNC 通过将整个桌面压缩为一组可以在任何有网络连接的地方**流式传输**的 JPEG 解决了同样的问题。它常常受限于糟糕的质量，但完成了任务。考虑到 Android 是 Linux，令人惊讶的是该平台并没有同样充斥着远程查看选项。对于未 root 的设备，能让你看到与你手持屏幕完全相同内容的选项非常少。但这正是名字起得很糟糕（对**阅读障碍者**来说）的 scrcpy 所做的，它在没有 root 且不需要在 Android 设备上安装任何东西的情况下做到这一点。唯一的 要求是启用 Android 设备上的 ADB 调试，并且你信任在你的手机和 Linux 机器之间建立所必需的 USB 连接。然后只需要运行 scrcpy 命令（如果你能打字的话），并等待连接开始。在几分钟后，你将看到一个 1:1 逐帧完美捕捉你 Android 屏幕上内容的画面。这非常有用的功能令人惊讶，从通过网络流式传输屏幕，到在你处于 VR 环境中时回复消息。

## 音频编辑器
### Tenacity

编写音频软件是一项困难且吃力不讨好的工作。不仅信号处理代码难以编写，与 Linux 音频栈交互也很棘手，创建一个帮助用户忽略其复杂性的用户界面几乎是不可能的。这就是为什么找到成功方法的应用程序随时间变化很小的原因。现代的 Cubase 与 1989 年的 Cubase 仍然有很多共同之处，Ableton 自 2001 年发布以来几乎没有改变，而在 Linux 上，Ardour 自 2005 年以来依然保持着简约，尽管它拥有许多现代功能和难以置信的强大控制水平。但 Audacity 或许是变化最小的，同时仍然是 Windows、macOS 和 Linux 上最受欢迎的音频编辑器之一。Audacity 被所有人使用，从将 FLAC 转换为 MP3 的普通桌面用户，到在 Bandcamp 上发行音乐进行母带处理的业余音乐家，再到专业播客制作人。它仍然是一个坚如磐石的应用程序，可以录制和编辑数小时而无故障。

![](img/740bd926461af28ed755753238e647a2_85_0.png)

Tenacity 是 Audacity 的一个分支，它已经彻底改变了其美学，并希望通过社区参与进一步拓展。

尽管致力于保持一致性，Audacity 的开发被许多人认为过于缓慢，特别是当该项目在被 Muse Group（背后同样支持出色的 MuseScore）接管后，添加又撤回了退出遥测功能。这导致了该项目的两个独立分支，两者都致力于在没有遥测的情况下将 Audacity 带入现代，并在各自开源社区的推动下进行。这类计划很难实现，也很少成功取代原始项目，但这两个项目都幸存下来，并最近合并为最成功的那个，即 Tenacity。

![](img/740bd926461af28ed755753238e647a2_85_1.png)

竞争是一件好事，希望 Tenacity 能够跟上最近的 Audacity 发展，包括实时音频效果。

Tenacity 承诺成为一个比 Audacity 更新鲜、更现代、更方便、更实用的音频编辑器。最新版本极大地展示了已经取得的进步。主要差异可以在用户界面中看到，界面已经**经过翻新**。图标、文本渲染和主题颜色看起来都大幅改进，并在深色主题桌面上远优于原始版本。这是 Audacity 似乎不愿添加的功能，其自身的深色模式在集成 VU 表或波形渲染等方面时可能会时好时坏。这有助于使 Tenacity 更令人愉悦，同时也使其感觉更现代。它也是在没有 Audacity 的遥测功能的情况下构建的，既不需要设置构建标志，也不需要取消运行时设置，确保你的数据不会流向任何地方。其他一切都是 Audacity 在版本 3.0.2 分叉时包含的最佳内容。这意味着你获得了数十年的开发者和用户体验，以及一个坚如磐石的音频编辑器。当然，Audacity 仍然是一个很棒的项目，并且通过最终添加实时效果处理（尽管处于早期阶段）也显著改进，我们将拭目以待，看看 Tenacity 是否能将这些新增功能合并到其自己的代码中（目前与 Audacity 的代码已有显著分歧），或者团队是否能够保持足够的动力，创建一个拥有其独特音频编辑方法、真正独立的项目。毫无疑问，对像这样的开源音频编辑器有着巨大的需求，成功的项目可能会获得潜在的丰厚回报。

项目网站
https://github.com/tenacityteam/tenacity

## 生存类 Roguelike
### Cataclysm: Dark Days Ahead

![](img/740bd926461af28ed755753238e647a2_86_0.png)

**Cataclysm: Dark Days Ahead** 是一个开源的 Roguelike 冒险游戏，现在甚至可以在 Steam 上获取。

这是一个复杂的冒险游戏，具有陡峭的学习曲线。它从命令行运行，当你创建一个角色并进入游戏世界时，最初一切都看起来很像原始的 NetHack。它使用文本字符和光标构建，有一个代表你化身中心字符，一个随着你探索而根据视线范围消失的“战争迷雾”，以及右侧的一组属性和属性。与 NetHack 一样，ASCII 文本可以被图形瓦片替换，这可以使游戏感觉更现代，但也会将游戏玩法从终端拉到你的桌面上。无论如何，游戏的两个版本玩法完全相同，难度也同等困难。Cataclysm 将自己描述为“设定在末日世界中的回合制生存游戏”，这是你需要从一开始就需要探索的世界，同时关注你的属性以保持生存。回合制意味着你执行的每个动作都有移动成本，初始难度取决于你选择的起始场景，“疏散者”给你足够的资源来帮助初期。这也取决于你选择的角色职业，因为不同的职业配备有不同的默认库存。有许多职业可供选择，从舞厅舞者到朋克摇滚家伙，似乎一切都影响着其他一切。需要数小时才能开始理解你在游戏开始前和在游戏环境内部所做选择的效果，但一些出色的入门指南和在线视频真的很有帮助。最终结果是一个 Roguelike，具有 NetHack 的元素，类似《辐射》的场景，以及强调生存和战斗。与 NetHack 一样，它会奖励你在学习上投入的时间以带来深厚的游戏体验，尽管学习曲线要困难得多。

## 植物模拟器
### botany

![](img/740bd926461af28ed755753238e647a2_86_1.png)

**Botany** 让你可以在命令行上种植 ASCII 植物，并让朋友来访帮助浇水和看护你的创作。

我们习惯了这样一种观念，即许多 AAA 游戏变得越来越复杂和要求越来越高，通常需要数十甚至数百小时才能征服。但有一类小类尝试相反的做法。这是《星露谷物语》如此成功的原因之一，许多玩家利用其种植和生长方面来放松身心，而无需耕耘他们真实的菜园。出色的 botany 在实现和对你的心理要求方面更进一步。它首先是一个简单的 Python 3 命令行应用程序，你可以从其仓库获取并运行，无需安装或配置依赖项。其次，它需要很少的关注或思考。就像真正的植物一样，它只是要求你偶尔看一眼，不要抛弃它。首次启动时，游戏开始时会给你一颗种子。没有直接告诉你这些，但你可以阅读包含的说明。然后，你的任务是给植物浇水，检查其生长，并记得每 24 小时回来做同样的事。有 20 多种不同的植物物种，全部作为 ASCII 艺术绘制，并且当你第一次运行游戏时具有**随机属性**，但就像真正的植物一样，从那颗初始种子中出现任何东西需要几天时间。如果你忘记给你的 ASCII 浇水，它就会枯萎，你的花可以在其发展的任何阶段发生变异。但如果它存活下来，你可以收割生长物，并用它来播种新一代，具有 20% 的生长加成。更令人印象深刻的是，你可以通过输入其他人名来访问其他人在命令行上种植的植物，他们也可以访问你。访客可以查看甚至给你的植物浇水，例如，如果你去度假，这有助于保持植物非常健康，这在网络上组织比有人访问你现实中的菜园要容易得多。

**项目网站**
https://github.com/jifunks/botany
