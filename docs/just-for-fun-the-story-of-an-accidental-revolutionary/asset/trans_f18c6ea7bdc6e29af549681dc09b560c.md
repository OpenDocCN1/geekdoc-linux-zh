

1992 年秋天，我被任命为计算机科学系瑞典语课程的助教。（事情是这样的：基础计算机课程需要会说瑞典语的助教。当时在大学里刚开始就读计算机专业的两名会说瑞典语的学生只有两人：拉斯（Lars）和我。所以选择面并不大。）起初，我甚至不敢走上讲台解题，但没过多久，我就开始专注于教学内容，不再担心自己会出丑。顺便说一下，三年后我晋升为研究助理，这意味着我不再因为教学而领薪，而是因为在计算机实验室工作而领薪，这主要意味着从事 Linux 的开发工作。这标志着一个趋势的开始：有人付钱让我去做 Linux。Transmeta 公司的情况基本上就是这样。

大卫：“那是什么时候开始变得非常重要的？”
我：“它到现在还不太重要。”

好吧，我修正一下我的说法。当人们开始意识到有如此多人将 Linux 视为一种不仅仅是玩具的操作系统时，它开始变得重要起来。当他们开始用它来做一些不仅仅是随意摆弄的事情时，我意识到，如果出了什么问题，我是有责任要承担的。或者至少，我开始感到自己负有责任。（我至今仍然如此。）在 1992 年期间，这个操作系统从一个主要用作游戏的平台，进化为融入人们生活、生计和商业活动的重要组成部分。

这一转变发生在 1992 年春天，在我开始终端仿真工作大约一年之后，当时 X 窗口系统的首个版本在 Linux 上运行起来。这意味着操作系统能够支持图形用户界面，并且得益于源自麻省理工学院（MIT）的 X 窗口项目，用户可以在多个窗口中同时工作。这是一个巨大的变化。我记得在真正发生这件事前一年左右，我曾跟拉斯开玩笑说，总有一天我们会运行 X 系统，并能够处理所有事情。我从未想过它会这么快实现。一位名叫奥雷斯特·兹博罗夫斯基（Orest Zborowski）的黑客成功将 X 系统移植到了 Linux 上。

X 窗口系统的工作方式是通过 X 服务器来实现的，它负责处理所有的图形工作。服务器与客户端通信，客户端就是那些说“我想要一个窗口，并且希望它有这么大”的对象。通信通过一层称为套接字（sockets），或更正式地说，Unix 域套接字（Unix Domain Sockets）的机制进行。这是 Unix 内部通信的方式，但你也可以使用套接字通过互联网进行通信。因此，奥雷斯特编写了 Linux 的第一个套接字层，仅仅为了将 X 移植到它上面。奥雷斯特编写的套接字接口有点像是硬塞进去的，与其他代码整合得并不好。当时我同意接受这个补丁，尽管它相当原始，仅仅因为我们急需它。

我花了好长一段时间才适应我们拥有了图形用户界面这一事实。我想在前一年左右，我甚至没有每天使用它。而现在，我离不开它了。我工作时屏幕上总是堆满了窗口。

奥雷斯特（Orest）的贡献不仅让我们能够使用窗口，也为未来打开了一扇大门。域套接字（domain sockets）用于本地网络，使 X 窗口系统得以运行。我们可以基于这些相同的套接字，让 Linux 实现向外部网络迈出的重大飞跃——即具备连接计算机的能力。如果没有网络，Linux 仅适用于那些坐在家中用调制解调器拨号上网或完全在本地进行操作的人。我们怀着极大的乐观，开始基于这些原本并非为了网络而设计的原始套接字开发 Linux 网络功能。

我当时非常确信我们可以轻松做到这一点，以至于我在版本号命名方案上跨了一大步。1992 年 3 月，我原本计划发布 0.13 版本。相反，随着图形用户界面的就位，我自信地认为我们可能已经完成了通往发布一个成熟、可靠且具备网络功能的操作系统目标的 95%。因此，我将新发布版本命名为 0.95。

天哪，我真是太早了。甚至可以说是一窍不通。

网络是一件棘手的事情，最终花了整整两年时间才让它做到可以发布的程度。当你加入网络功能时，突然引入了许多新问题。存在安全问题。你不知道外面是谁，他们想做什么。你必须非常小心，防止人们通过发送恶意垃圾数据包来让你的机器崩溃。你不再能控制谁试图联系你的机器了。此外，许多人的配置非常不同。在使用 TCP/IP 作为网络标准的情况下，很难让所有的超时设置都正确。感觉这个过程会永远持续下去。到 1993 年底，我们拥有了几乎可用的网络功能，尽管有些人遇到严重的兼容性问题。我们无法处理不具备 8 位边界的网络。

由于我在 0.95 版本的命名上过于乐观，我陷入了困境。在将 1.0 版本发布的那两年时间里，我们被迫在版本号上做了一些疯狂的事情。95 和 100 之间的数字并不多，但我们不断基于错误修复或新增功能发布新版本。到 0.99 版本时，我们必须开始添加数字来表示补丁级别，然后我们依靠字母。在某个时刻，我们有 0.99 版本，补丁级别 15A。然后是 0.99 版本，补丁级别 15B，依此类推。我们一直做到补丁级别 15Z。补丁级别 16 变成了 1.0 版本，即该版本变得可用的节点。这个版本于 1994 年 3 月在赫尔辛基大学计算机科学系礼堂隆重发布。

在这之前的一段时间有点混乱，但这并没有削弱 Linux 的 popularity。我们有自己的互联网新闻组，comp.os.linux，它从我与安德鲁·坦能鲍姆（Andrew Tanenbaum）的激烈争论中诞生。它吸引了大批人群。当时，互联网核心圈（Internet Cabal），即那些或多或少管理互联网的人，对每个新闻组吸引了多少读者保持着非官方的月度统计。这些统计数据不可靠，但它们是关于你站点（在这种情况下是对 Linux 关注度）热度的最佳可用信息。在所有新闻组中，alt.sex 一直是长盛不衰的热门。（这不是我个人的最爱。虽然我曾检查过一两次看看到底有什么热闹，但我基本上是一个典型的缺乏性的极客，我更愿意摆弄我的浮点处理器，而不是去追踪性行为方面的最新报道——新发现的性爱姿势，或者关于乱伦的报道，或者其他许多人在 alt.sex 上谈论的东西。）

通过核心圈的月度统计，我可以轻松追踪 comp.os.linux 的热度。相信我，我一直在追踪。（虽然有些人可能认为我是民间英雄，但我绝不是那些狂热的媒体坚持认为的那种无私、无自我、科技宠儿。）到 1992 年秋天，我们的新闻组估计有数万人关注。有这么多人在新闻组上关注发生的事情，但他们并不都在使用 Linux。每个月，当统计数据公布时，都会有一份关于最受欢迎 40 个新闻组的汇总报告。如果你的新闻组没有进入前 40 名，你可以从一个专门的维护新闻组获取其他新闻组热度的完整报告。通常我不得不去寻找那份完整报告。

Linux 新闻组在排行榜上不断攀升。在某个时刻它进入了前 40 名，我很开心。那感觉相当酷。我好像记得曾在 comp.os.linux 上写过一篇相当得意的文章，基本上列举了各种操作系统（operating system）新闻组，包括 Minix，并说道：“嘿，看看这个，我们比 Windows 还受欢迎。”记住，在当时，喜欢 Windows 的人不在互联网上。我们在 1993 年某时进入了前五名。那天晚上我带着极大的满足感上床睡觉，因为 Linux 变得几乎和性一样受欢迎，这让我感到兴奋。
