
# 七

既然说到这个话题，让我再多讲讲芬兰。我们这里的驯鹿数量大概是地球上任何地方都难以企及的。同时，我们也拥有相当比例的酒鬼和探戈舞蹈迷。在芬兰度过一个冬天，你就明白酗酒传统的根源了。那些探戈舞者实在没有借口，但谢天谢地，他们基本上都集中在小镇上，在那里你永远不会碰到他们。

一项最近的调查确定，芬兰男性是欧洲最阳刚的。这大概要归功于大量的驯鹿肉，或是花在桑拿房里的时间。这是一个桑拿房数量甚至超过汽车的国家。没人知道这种宗教般的习俗究竟是如何开始的，但至少在某些地方，传统是先建桑拿房，再建房子。许多公寓楼的底层或顶层都设有桑拿房，每个家庭都有专属的私人时间——比如周四晚上 7 点到 8 点（周四和周五通常是桑拿日）。这样一来，你就不必忍受看到邻居赤裸的恐怖场景了。有一次我正在翻阅一本英文版的芬兰旅游指南，书中费尽周折地警告读者，芬兰人绝不会在桑拿房里做爱，而且如果得知发生了这种违背习俗的行为，甚至仅仅是游客脑中一闪而过的幻想，他们都会感到震惊。当我读到这段时，我忍不住大笑，因为在芬兰家庭里，桑拿房是一个如此中立的地方，这本书完全也可以同样恰当地警告人们不要在厨房地板上做爱。我觉得这也没什么大不了的。在偏远地区，婴儿甚至是在桑拿房里出生的——那里是唯一有热水的地方——根据某些传统，那也是人们去赴死的地方。顺便说一句，这些规矩并不适用于我家，我们家对这一切的态度非常随性。

芬兰人还有其他特质将他们与其他人类成员区分开来。例如，有一种沉默的传统。没人多说话。他们只是站在那里，什么都不说。这又是一条不适用于我家的规矩，我可以慷慨地将我家描述为“特立独行”。

芬兰人固执到近乎缺陷的程度。痛苦的沉默和强烈的决心或许帮助我们在面对俄罗斯的统治、一连串血腥的战争以及糟糕透顶的气候时生存了下来。但如今，这看起来只是有些古怪。德国作家贝尔托·布莱希特在二战期间短暂居住在芬兰，并做出了著名的观察，指出当地火车站咖啡馆的顾客“在两种语言中都保持沉默”。他一旦有机会就经符拉迪沃斯托克前往了美国。

即使到了今天，如果你走进芬兰任何城市的酒吧——尤其是那些较小的城市——你很可能会发现面无表情的人独自坐着，凝视着虚空。在芬兰，人们尊重彼此的隐私——这是另一件大事——所以没人会想到去和一个陌生人搭讪。这就成了一个悖论。芬兰人其实相当友好。但很少有人能发现这一点。

我了解到在芬兰的女同性恋酒吧里，氛围要热闹得多。

由于芬兰人不太愿意面对面交谈，我们是移动电话的理想市场。我们对新设备的热情是任何其他国家都难以匹敌的。目前还不清楚究竟哪个国家的人均驯鹿数量最多——仔细想想，这个头衔可能属于挪威——但毫无疑问，地球上拥有最多手机（覆盖每个男人、女人和孩子）的国家是哪个。在芬兰，有人提议在婴儿出生时就将手机植入体内。

而且它们被用于比其他地方更多的用途。

芬兰人经常互相发送短信，或者依赖手机作为高中考试作弊的机制（把题目发给朋友，然后等待他的短信回复）。我们使用计算器功能，而很少有美国人甚至意识到手机上存在这个功能。明显的下一步是，人们开始拨打下一张咖啡馆桌子上那个孤独的人的号码，开始一场手机对话。尽管诺基亚取得了惊人的成功，但手机对芬兰的改变，自桑拿房本身问世（早已被人遗忘）以来，是前所未有的。

实际上，移动电话在芬兰受到如此热烈的欢迎并不令人惊讶。这个国家在采用新技术方面历来迅速且自信。例如，与地球上几乎所有其他地方不同，芬兰是一个人们通常以电子方式支付账单并进行所有银行业务的地方——不像美国那种软弱的伪电子银行业务。芬兰的人均互联网节点数量居世界首位。有些人将这种技术敏感性归因于强大的教育体系——芬兰拥有世界最高的识字率，而且大学学费免费，这就是为什么典型的学生会停留六到七年。或者，就我的情况而言，是八年。在大学里耗费生命中如此大一部分时间，你不可能不学到点什么。另一些人则说，这种技术优势始于作为向俄罗斯支付战争赔款的一部分，在航运业所做的基础设施改进。还有人说，这与人口高度同质化（有时令人难以忍受地同质化）有关。

我和林纳斯坐在餐桌旁。我们刚从赛车/打击笼娱乐场所回来。托芙正在收拾杂货，帕特里夏和达尼拉正为带回来的那本书（我是带给她们其中一人的）争执不休。我拨开一只毛绒企鹅和一个巨大的花生酱罐子，打开录音机，让林纳斯谈谈他的童年。

“实际上，我几乎不记得我的童年，”他用单调的语调说道。

“怎么可能？那只是几年前的事！”

“去问托芙。我记名字、面孔或做过的事很差劲。我得问她我们的电话号码是多少。我记得规则和事物是如何组织的，但我永远记不住事情的细节，我也不记得童年的细节。我不记得事情是如何发生的，也不记得小时候我在想什么。”

“好吧，比如，你有朋友吗？”

“有一些。我从来不太善于社交。我现在比那时候要外向得多。”

“好吧，那是种什么感觉？我的意思是，你还记得在周日早上醒来，然后和你姐姐和父母去某个地方吗？”

“我父母在他们（指代不明，可能是指在某个时间点）分开前就离异了。”

“他们离异时你多大？”

“我不知道。也许六岁。也许十岁。我不记得了。”

“圣诞节呢？你记得圣诞节吗？”

“哦，我有一些模糊的记忆，记得穿上盛装去图尔库的外祖父家。复活节也是如此。除此之外，我记得不多。”

“你的第一台电脑呢？”

“那是著名的 VIC-20，是我外祖父买的。它装在一个盒子里。”

“盒子有多大？能装下一双雪地靴那种大小的盒子？”

“大概那个大小。”

“那你的外祖父呢？你关于他记得多吗？”

“他可能与我关系最亲近，但我并不……好吧。他超重，但不胖。他正在秃顶。他性格孤僻，有点像那个心不在焉的教授，事实也的确如此。我过去常坐在他腿上，输入他的程序。”

“你能记得他身上的味道吗？”

“不能。这是什么问题？”

“每个祖父身上都有某种味道。廉价古龙水。波本酒。雪茄。他身上闻起来像什么？”

“我不知道。我当时太专注于电脑了，没注意到。”

# 操作系统*的诞生

# 一。

有些人根据他们开过的车、做过的工作、住过的地方或交往过的情人来记忆时间。我的岁月是由电脑标记的。

在我成长的过程中，我只拥有过三台电脑。其中包括前面提到的科莫多拉 VIC-20，我是从外祖父那里继承来的。它是首批“家用”电脑之一，是如今个人电脑的前身。科莫多拉 64 成为了 VIC-20 的“大哥”，随后是 Amiga，它在欧洲拥有特别强的追随者。这些电脑从未真正普及，不像个人电脑，甚至不像 Apple II，在我摆弄 VIC 的时候 Apple II 已经相当常见了。

在个人电脑普及之前的那些日子里，家用电脑上的大多数编程是用汇编语言进行的。（我都不相信自己已经开始用“在那些日子里……”来开头了。）电脑拥有自制的操作系统，相当于个人电脑上的 DOS。根据电脑型号的不同，它要么是一种原始格式，要么是一种略微增强的格式。就像 DOS 一样，操作系统有一个程序加载器和一个基础语言环境。当时没有标准，许多公司都想控制市场。科莫多拉是其中较知名的公司之一。
