
那是城堡，不是教堂。在奥伦，我犯了一个错误，去体验了酒店的桑拿房。那是那种便携式桑拿房，用塑料做的，里面比外面只热一点点。离开后，我心想美国人大概不会做桑拿，心里不禁有些思乡。

我开始摸索当地的情况。正如芬兰的游客会很快学到不在酒吧里与陌生人搭讪一样，我也学到，在犹他州——后来我发现，在美国其他地方也一样——你无法理性地讨论堕胎或步枪的话题。有百分之五十的可能性，你会遇到对这些问题情绪非常激烈的人，而很容易就会为一些本不该争执的事情大打出手。在欧洲，人们不会在这些问题上纠缠不清。美国人对自己立场如此防御性的原因是，他们太熟悉另一种立场了。芬兰的人均步枪数量可能比其他许多地方都多，但它们大多用于狩猎。那并不是一件大事。

在我踏上美国国土的最初几天，我还快速学到了另一件事：根汁汽水很糟糕。*

离开犹他州后，我飞往旧金山，真的、非常喜欢那里。我在城市里走了太长时间，晒得严重脱皮，不得不待在室内一整天。

我记得走过金门大桥，抬头望着马林角，对过了桥就能在那座山丘上骑行的可能性感到兴奋。但当我到达马林一侧时，我已经对继续行走失去所有兴趣。我永远无法预测，六年后，几乎是在同一天，我会坐在那座多风的马林角山顶，望着太平洋、旧金山湾、金门大桥、雾气以及旧金山本身，向大卫的录音机解释这一切。

> *天哪，那绝对是一种需要养成的口味。我猜这源于清教徒，他们因为啤酒含酒精而不能喝。于是他们配制了一种不含酒精的饮料，碰巧是用根茎做的，并称之为“根汁汽水”来愚弄人们，让他们以为这是好东西。十代人之后，人们被愚弄着以为这是好东西，最终信以为真了。如今，美国人喜欢根汁汽水，因为他们背后有十代人的基因工程支持。

我只用了一年时间就回到了美国。我回来是为了在新奥尔良参加 DECUS（数字设备用户组）的演讲。会上只有四十人，所以并不是什么可怕的煎熬。最棒的是，就在那时我遇到了 Maddog，又名 Jon Hall。他是数字 Unix 的技术市场人员，也是一位资深的 Unix 用户。正是他安排我来做演讲的。Maddog 以他的齐胸胡须和荒诞的幽默感而闻名（更不用说他的鼾声了），他领导着 Linux 国际组织，该组织致力于支持和推动 Linux 及 Linux 用户的发展。他还是我女儿 Patricia 的教父之一。

那趟新奥尔良之行的另一个遗产：Maddog 安排数字设备公司借给我一台 Alpha 工作站。这就是 Linux 被移植到非 PC 平台上的开始。在那之前，人们曾将 Linux 移植到其他架构。有一个针对 68K（Atari 和 Amiga 使用的摩托罗拉 68000 机器）的移植版本。但在那些情况下，Linux 无法同时在两个平台上运行。为了让那种版本的缩放工作，你需要移除在新平台上不起作用的部分，并编写新的部分。但 Alpha 是第一个真正的 Linux 移植。基本上，相同的源代码在 PC 和 Alpha 上都能工作。你添加了一个抽象层，使得相同的代码以两种方式编译，以适应两种不同的架构。它仍然是相同的代码，但最终能在不同的架构上运行。

1995 年 3 月，当我们发布 1.2 版本时，内核代码量已增长到 250,000 行，新杂志《Linux Journal》声称其发行量为 10,000 份，且 Linux 已经能够运行在 Intel、Digital 和 Sun SPARC 处理器上。那是巨大的一步。

## 二。

那是 1995 年，市面上涌现出众多日益成熟的商业版本，Linux 公司正吸引大批追随者。大学已将我从助教提升为研究助理，这意味着更多的薪水，更少的时间用于教学。我正在缓慢——非常缓慢——完成我的硕士学位课程，主题是将 Linux 移植到不同架构。Tove 介绍我认识了捶球运动，我们每周比赛一次；我们的实力相当接近。

就在这一片祥和之中，一个问题出现了。原来，波士顿的一位投机者注册了“Linux”这个词的商标。不仅如此，他还给《Linux Journal》和几家其他 Linux 公司发邮件，要求他们支付 5% 的收入作为对该商标的“感谢费”。

当我听说这件事时，我感到一阵*既视感*。那个人的名字听起来很耳熟。我查了我的电子邮件存档，发现大约一年半之前，他给我发过一封未经请求的邮件，首先问我是否信仰上帝，然后说他有一个巨大的商业机会给我。那时垃圾邮件还未成为全球性的痴迷，那是尚无人想到用发家致富方案污染互联网的纯真年代。不，我当初没有费心回复那家伙的邮件，但因为它在当时很不寻常，所以我把它保存了下来。

于是，我们面临了一小场危机。没人想到去检查商标注册处。那家伙并非职业商标抢注者。他显然只是这么做过一次。商标有不同的类别，他注册的是计算机类别。你必须随商标申请提交证据，所以他给了商标办公室一张磁盘，声称里面有一个名为 Linux 的程序。

引发了一些恐慌。Linux 社区的每个人都已知我们将对商标提出异议。问题是，我们没有专门的组织来进行有效的抗争。甚至没有足够的钱请律师。没有哪家公司愿意出这笔要求的费用，即 15,000 美元。（如今他们一个月就能花掉相当于这些钱的 Mountain Dew 汽水。）但当时，对于单一公司来说，这是一笔相当可观的钱。于是，《Linux Journal》和其他一些公司决定向 Linux 国际组织注资，由该组织来应对商标问题。Linux 国际组织是由一位名叫 Patrick D'Cruze 的人于澳大利亚发起创立的，他于 1994 年移居美国，以帮助在全球推广 Linux。商标争议发生的那一年，Maddog 成为该组织的执行董事。每个人都信任他，至今亦然。

当时我在芬兰，正忙着在捶球或 Snocker 中击败 Tove 和 Avuton，对卷入此事毫无兴趣。我只想让这场噩梦消失。我当时的偏好是只要取消该商标，因其在行业中的先期使用而宣告无效。我们有足够的文书工作来证明 Linux 确实有先期使用历史。麻烦在于，我们的律师说服了我们，认为这将是徒劳，我们甚至不应该试图将 Linux 宣告为公有领域而非商标。他解释说，要使其真正进入公有领域，唯一的办法是使其变得通用化。而当时的 Linux 还远未达到通用化的程度。商标办公室可能甚至今天也不会将其视为通用词汇。他说，我们可能会输掉这场战斗。或者，如果我们使旧商标无效，可能有人会前来重新注册该商标。

他提出的解决方案是将商标转让给其他人。我的投票倾向于是 Linux 国际组织，但遭到了很多反对。Linux 国际组织当时年轻且未经验证。人们担心 Linux 国际组织会被商业利益接管。（我可以补充的是，这种情况并未发生。）此外，对于如果 Maddog 辞职，最终谁将接替他，也存在强烈的担忧。

于是，所有的目光都投向我。律师建议，如果 Linux 商标转让给我，法律论证会更容易，因为我是该词的最初使用者。我们采取了这一策略。我们达成了庭外和解，因为这似乎是最容易且最便宜的做法。像大多数庭外和解一样，细节无法讨论。甚至我自己都不知道细节。我对这一切都毫无兴趣，心情愉快。

当我回去查看那家伙最初给我发的邮件时，我意识到我与专利毫无关系。显然，他只是想与我谈话。也许他试图联系我，想让我付钱给他。或者，如果我表现得他是他信仰中的真正信徒和灵魂兄弟，他可能就直接*赠送*给我该商标。我不知道。

我接受有些人道德上并不完美这一事实。但当时更令人恼火的是，整个商标制度竟然让像我这样没做错任何事的人，出去与那家伙搏斗。

经过这场混乱的纠缠，我持有 Linux 商标。这意味着，当像 VA Linux 这样的公司申请 IPO 时，其招股说明书必须提及公司甚至不拥有其名称一半的商标这一事实。（在那种特定情况下，该公司参与了获得我授权使用 Linux 一词的法律程序。）但我已习惯了这类事情。

商标插曲只是 Linux 成长过程中意外发生的痛苦。也是干扰。但刚解决完这个，另一个问题又出现了：英特尔在俄勒冈州波特兰的研究实验室的一位工程师表示，他的公司正在其新架构探索中使用 Linux。他问我是否愿意去那里实习六个月。
