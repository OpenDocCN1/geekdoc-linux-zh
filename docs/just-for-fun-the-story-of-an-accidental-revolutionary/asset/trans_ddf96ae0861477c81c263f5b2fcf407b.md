

## 十.
### Minix 与 Linux

关注并非全是正面的。尽管争执从来不是我最擅长的领域，但当安德鲁·塔内鲍姆不断攻击那个正在取代他自研操作系统的 Linux 时，我还是被激得不得不出手，为 Linux 和我的男子气概辩护。我们这群人是书呆子，所以所有交锋都是通过电子邮件进行的。

谁能怪他在 T 恤下热血沸腾呢？在 Linux 新闻组创建之前，我通常会使用 Minix 的新闻组来发布有关 Linux 的通告，或寻找对该操作系统感兴趣的人。安德鲁为什么会喜欢这样呢？

首先，他对我在他的新闻组里“侵权”感到不满。显然，对于这个来自芬兰白雪皑皑之地的新生事物正在让他的操作系统黯然失色，而且有大量开发者加入该项目，他也很不悦。此外，他对操作系统的构建方式也有不同的看法。当时，安德鲁是计算机科学界一个倾向于微内核方法学派的一部分。他设计的 Minix 就是一个微内核，而他当时正在开发 Amoeba 系统，也采用了这种架构。

在 20 世纪 80 年代末和 90 年代初，这是一场蓬勃发展的运动。而 Linux 的成功对其构成了威胁。因此，他不断发布一些令人不快的尖刻言论。
