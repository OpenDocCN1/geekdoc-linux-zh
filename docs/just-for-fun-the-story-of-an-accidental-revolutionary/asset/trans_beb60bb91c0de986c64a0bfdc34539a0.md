
# 纯粹出于乐趣
## 一场意外革命的故事
### 林纳斯·托瓦兹（Linux 的创造者）与大卫·戴蒙德

在这部机智且引人入胜的叙述中，林纳斯·托瓦兹——这位最新互联网革命背后的天才大师——与作家大卫·戴蒙德合作，记录了他从一个脸色苍白、瘦削的赫尔辛基大学生，蜕变为国际民间英雄的过程。起初作为童年爱好开始的事，很快演变为了被称为 LINUX 操作系统的惊人现象。

LINUX 的诞生源于林纳斯的好奇心，他想知道能否在现有的操作系统（如 UNIX）上进行改进。他如何能创建一个系统，既能运行他所有喜爱的软件，又能减少崩溃并提高生产力？林纳斯将 LINUX 的早期版本发布到互联网上，并呼吁计算机科学领域最聪明的大脑来完善他的系统。随之发生的事情震惊了全世界。

林纳斯并不是第一个利用开源运动力量的人，但当他向世界提供他的系统时所引发的热情是史无前例的。LINUX 之所以具有革命性，在于它成为今日奇迹的旅程——以及该系统如何因世界各地数千种思维的交汇而发展壮大。突然之间，林纳斯的创造物供所有人免费使用！任何人都可以随心所欲地改进 LINUX。没有垄断，没有商业机密，没有在幕后窃窃私语。LINUX 不受少数人控制——这一非凡的创造物对绝对任何人开放——并且至今仍是如此。在创立十年之后，LINUX 系统仍在每天不断演进和改进。林纳斯以易于理解的方式描述了 LINUX 的历史，并详细说明了系统本身是如何工作的，同时避免了令人头痛的技术术语。

# 引言：来自革命便利贴

在二十世纪末的狂热年代，在所有其他革命之中，一场革命正在发生。似乎在一夜之间，Linux 操作系统吸引了全世界的目光。它从创造者林纳斯·托瓦兹狭小的卧室里爆发出来，吸引了一批近乎狂热的极客追随者。突然，它开始渗透进控制全球的企业巨头之中。从最初的一人聚会，现在它拥有数百万位于每个大陆的用户，包括南极洲，甚至如果算上 NASA 前哨站的话，还包括外层空间。它不仅是运行分发万维网上所有内容 的服务器计算机最常见的操作系统，其开发模式本身——一张复杂的网络，涵盖了数十万名志愿计算机程序员——也已发展成为世界历史上最大的协作项目。支撑这一切的开源哲学很简单：信息，在本例中是操作系统背后的源代码或基本指令，应该是免费的并自由共享，供任何有兴趣改进它的人使用。但这些改进也应该自由共享。同样的概念支撑了数百年的科学发现。现在，它正在企业领域找到归宿，并且有可能被想象为创造任何事物最佳版本的框架：一种法律策略，或一部歌剧。

有些人瞥见了未来，并不喜欢他们所看到的。林纳斯圆圆戴眼镜的脸庞成了微软公司内部受青睐的镖靶，微软现在面临着真正的首要竞争威胁。但更常见的是，人们想了解更多关于那个少年的信息——即使他不是始作俑者，至少他推动了这一切，并且在实质上是其领导者。麻烦在于，Linux 和开源越成功，他越不愿意谈论它。这位意外的革命者启动 Linux 是因为在电脑上玩很有趣（而且其他选择也不太吸引人）。所以，当某人试图通过告诉他他的数百万追随者只希望至少能亲眼看他一眼来说服他在重大活动中演讲时，林纳斯好脾气地提出参加 dunk-tank（惩罚性泡水游戏）来代替。他解释说，那会更有趣，而且是一种筹款方式。他们拒绝了。这不是他们开展革命的方式。

革命者不是天生的。革命不能被计划。革命不能被管理。
革命会发生……
— 大卫·戴蒙德
