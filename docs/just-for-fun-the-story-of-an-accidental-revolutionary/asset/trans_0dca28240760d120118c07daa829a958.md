
事实是，Linux 比 Minix 具有更强的可移植性。什么？我听到你在说。这是真的——但这里的“可移植”并非指那个意思：我按照我知道的方式，让 Linux 尽可能符合标准（当时我手边并没有 POSIX 标准参考）。通常来说，将东西移植到 Linux 上比移植到 Minix 上要容易得多。

我认同可移植性是一件好事，但只有在它真正有意义的时候才是如此。试图让一个操作系统过度追求可移植性是没有意义的：遵循一套可移植的 API 就足够了。操作系统的核心思想在于利用硬件特性，并用一层高级调用将其隐藏起来。这正是 Linux 所做的：它只是比其他的内核使用了更多 386 架构特性的子集。当然，这使得内核本身变得不可移植，但它也带来了一种更简单的设计。这是一个可以接受的权衡，也正是它让 Linux 成为可能的原因。

我也同意 Linux 将不可移植性推向了极致：我是在去年一月才拥有我的 386 处理器的，而 Linux 部分上是这个项目是为了让我学习它。如果这是一个正式的项目，很多事情本应该做得更具可移植性。不过我也不是要为此找太多借口：这是一个设计决策，去年四月我开始这个项目时，我以为不会有人真正想使用它。我很高兴证明我错了，并且由于我的源代码是自由可用的，任何人都可以自由地尝试移植它，尽管这不会容易。

附言：我为有时语气过于强硬而道歉：如果你没有其他选择，Minix 其实挺不错的。如果你有 5-10 台闲置的 386 电脑，Amoeba 可能也不错，但我肯定没有。我通常不参与网络骂战，但提到 Linux 时，我脾气有点急。:)

这篇文章还有几期后续，这是我有生以来少数的几次网络骂战之一。但你明白我的意思：即使在早期，就有反对的声音。（或者也许重点是：当你在电子论坛上公开自己时要小心。你的拼写错误和语法错误将永远困扰你。）

Linus 和我把家人和朋友们留在露营地，下午沿着一条清澈的小溪骑车。我们在 7 月 4 日周末期间在 Grover Hot Springs 露营，那里位于东内华达山脉深处，仿佛是从《国家地理》杂志的页面里取下来的露营地——

“这是柯达时刻，”Linus 宣称道，他停下来，眺望着野花点缀的草地以及作为背景的壮观悬崖。我们在溪流旁找了一个扎营点，我请他描述一下在 Linux 的吸引力远远超出其最初的新组爱好者圈子的那段时间里的生活。那些爱好者中，Linus 甚至连大多数都从未亲自见过。

“那感觉一定很棒，”我说，“多年来你独自一人在卧室里埋头苦干，与你的 CPU 之外的世界几乎没有联系。突然间，来自地球各个角落的人们都在认可你正在做的伟大工作。你是这个不断增长的社区的焦点，他们都在看着你——”

“我不记得那对我来说是个大事，”他回答，“我真的不觉得它是。那只是我一直都在思考的事情，但主要是因为总有需要解决的问题。在这个意义上，我经常思考它，但在情感上，它并不是什么大事。从智力上，它是一件大事。

“我喜欢有许多人给予我动力来推进这个项目。我以为我已经看到了终点，一个几乎完成的时间点。但那个时间点从未到来，因为人们不断给我更多继续下去的理由和更多需要费脑筋的问题。这让它保持有趣。否则，我可能早就转向另一个项目了，因为这就是我的工作方式，而且那很有趣。但我怀疑我可能更担心我的鼻子或类似的东西，”他说。

几周后，我们在斯坦福购物中心，Linus 面对众多跑鞋选择感到困惑。“你通常每周跑多少英里？”销售员问道。Linus 笑了笑；过去十年里，他连一英里都没怎么跑过。锻炼从未是他的主要优先事项。但在意志薄弱的时刻，Linus 承认他想减掉一些多余的体重。

“托芙一定说服你帮我摆脱我的肚腩了，”他开玩笑道，拍了拍自己的肚子。

“告诉她，她这周寄给我的支票还没到，”我回答。

很快，我们开始在斯坦福校园周围转悠，寻找一个合法停车位。大约半小时后，我们做了一些拉伸，然后开始沿着狭窄的土路跑步，经过校园干枯的湖泊，穿过树林，朝我们的目标方向前进：巨大的山坡卫星天线。我们最终没能到达那里。我设定了一个不公平的快节奏，惊讶地发现 Linus 能紧随我身后大约一英里。然后他上气不接下气了。几分钟后，我们躺在湖边的草地上。

“你的家人对 Linux 发生的一切有什么反应？”我问道，“他们一定对此感到非常兴奋吧。”

“我觉得没有人真的注意到，”他回答，“我不会说没有人真的在乎。但我一直在编程，这是我大半生在做的事情，就他们而言，这并没有任何不同。”

“好吧，你肯定跟你父母说过什么。比如，如果你的父亲开车带你去某地，你不会说，‘嘿，你不信但我知道我用电脑做的事吗？’嗯，我有好几百人在用它……”

“没有，”他回答，“我只是不觉得有必要与家人和朋友分享这件事。我从未有过想要把它强加给别人的感觉。我记得 Lars Wirzenius，在我编写 Linux 左右的时候，决定购买 XENIX，这是 SCO 版本的 Unix，我想我记得他试图找借口，比如，‘别误会我的意思。’我个人认为我从未真正在意。他最终换了，但这对我来说不是什么大事。对我来说，人们使用它是件好事，收到反馈也很美妙，但与此同时，它也不是那么重要。我不想传教。我为人们使用我的代码感到自豪，但我不记得有过想要与任何人分享这种感觉。我认为它不是地球上最重要的事。我不认为因为一百人在使用我的软件，我就在做一件真正重要的事。这更像是一种乐趣。这就是我今天对此的感受。

“所以你甚至不想告诉你的父母、家人和朋友这件事。你真的对发生的一切不感到兴奋？”我问道，没有掩饰我的难以置信。

他等了几秒钟才回答。“我不记得那时我是否还有感觉。”

Linus 买了一辆新车，一辆宝马 Z3，一款双座敞篷车，他说这辆车定义了“乐趣”这个词。它是金属蓝色的，完美的男孩玩具车颜色。他选择这种颜色是因为该车没有他首选的亮黄色。他解释说，宝马黄“看起来像尿”。多年来，他尽量将他的庞蒂亚克汽车停在圣克拉拉办公园区内 Transmeta 总部入口附近。但现在宝马停在他办公室窗外，据说是为了让车待在阴凉处。现在，当 Linus 在电脑上工作时，我们可以同时欣赏他的新车。

一年多一点以前，我们第一次开车越过山脉去圣克鲁斯，用的是一辆敞篷车，那是我为此场合租的一辆白色野马。在这次旅行中，Linus 特意停下来查看停在我们参观的山间建筑和酿酒厂外面的跑车。现在我们正驾驶着他自己的跑车翻山越岭。他在 17 号公路上弯道处微笑。

“你配得上这个，”我说。

我从手套箱里掏出一把 CD。

“平克·弗洛伊德？谁？珍妮丝·乔普林？”

“那是我从小听起音乐。我小时候没买过音乐，但我们在公寓里常有这些。我想是我母亲在播放它们，尽管我记得她很喜欢 Elvis Costello。”
