

# 球类之王（KING OF THE BALL）

### 一。

1.0 版本的诞生对 Linux 而言意味着某种新鲜事物：公关需求的出现。我本来会很高兴地以我介绍之前版本的方式向世界介绍这个新版本。我会在新闻组上写点什么，比如"1.0 版本发布了。自行消化吧。（好吧，不是完全用这些确切的话。）”

许多其他人都认为这是一件大事。出于营销目的，他们想要 1.0 版本。当时有很多新兴的商业公司开始销售 Linux。对他们来说，1.0 版本的重要性源于心理因素，而非技术原因。我对此无法反驳。事实是，当你试图销售操作系统的 0.96 版本时，看起来很糟糕。

我想发布它，因为这对我是一个里程碑，而且这意味着我可以暂时停止修复 bug，重新回到开发工作中。这些公司和 Linux 社区希望以重大的方式将其强加给公众。

我们需要一个公关策略。我本人不会亲自主导这项工作。我对发布新闻稿或发表声明不感兴趣。其他人认为应该那样做，于是其他人自愿接过火炬。Linux 本身的发展大致也是如此——不知怎地，这一切竟然真的行得通了。

Lars 是让首个官方发布成为真正盛事的主要推动力量之一。他和一些其他人认为大学是发布公告的最合适场所。这是合乎情理的。我的卧室太小了。而且，在商业场所主持发布会会树立一个错误的先例。因此，Lars 自愿与大学协调这次活动。赫尔辛基大学的计算机科学系规模足够小，他可以直接与系主任交谈。

赫尔辛基大学非常乐意提供计算机科学系的主礼堂，用于 Linux 1.0 版本的发布。为什么不呢？大学多久才会拥有值得电视新闻报道的内容？

我确实同意做一个演讲。但它没有我那次 Ede（Ede 演讲）经历中的那种恐怖感。好吧，现在回想起来，有些事情确实*更难*了。

比如，我的爸爸在观众席中。而且事实是，这是在芬兰电视上播出的。这是我第一次有机会在电视上看到自己。我的父母都在观众席中（但我相当确定他们没有坐在一起）。Tove 也在那里。这是我爸爸第一次见到 Tove，所以对我来说，这不仅仅是 1.0 版本的发布。由于我参与了最后的演讲准备工作，比如确保我的幻灯片没问题，所以在他们真正见面时我不在场。据说那发生在他们走出礼堂的时候。也许我用眼角余光瞥见了。

在那次演讲中，以及在接下来几年里几乎每次其他演讲中，我谈论的与其说是技术，不如说是开源。这很好。它改变了计算机科学系内部对 Linux 的一些看法。在此之前，Linux 是计算机科学系引以为豪并略微鼓励的事物。但发布之后，系里的人开始更认真地对待 Linux。毕竟，他们已经在新闻上看到了。

多年来，有人暗示大学试图为 Linux 邀功。事实并非如此。该系一直非常支持。他们甚至给了我一份工作，使我能够在工作时间内从事 Linux 开发。而那是在早期，所以没有人说“让我们推动这件事，因为它有朝一日会世界闻名”。但与此同时，他们很高兴能成为发布活动的重要部分。这提供了极好的公关机会。我知道现在计算机科学系中讲瑞典语的学生更多了，该系一直受到理工学院（Polytechnic University，赫尔辛基理工）的压制。

嫉妒成功被视为一种芬兰文化特征。随着 Linux 在世界上变得更为知名，我收到了许多关于我是否对大学里的人嫉妒我有所困扰的问题。结果恰恰相反；他们非常支持。早期，他们就开始淘汰 X 终端并安装装有 Linux 的 PC。

这次发布让 Linux 在芬兰进入了备受关注的区域，并开始在其他地方产生宣传效应。早期的许多头条新闻出现，是因为某些记者偶然发现了 Linux 并对其感到兴奋。从商业角度来看，1.0 版本从未对任何巨头构成真正挑战。Linux 获得的是 Minix 和 Coherent 所在的市场。但在那个社区之外的关注度很少，这也没关系。这已经比我最初预期的多得多。

尽管如此，记者们，主要来自行业出版物，开始敲我的门——字面意义上的。周六早晨醒来发现一个日本记者带着礼物（通常是手表，他们可能听说我对此有执念）想要采访，这让 Tove 很不高兴。当我邀请他们进来时，她更不高兴了。（这是我多年来反复出现的模式，直到我们将新房子变成记者禁区。在我最不顾及他人感受的时刻，我甚至会开玩笑告诉 Tove，我邀请了一位记者来家里采访——然后我忘了。记者会出现，Tove 不得不招待他/她，直到我回家。）此外，还有粉丝网站开始涌现，例如法国的一个网站，主要由不断更新的我的尴尬照片画廊组成。比如我在 Spektrum 会议上的一张照片：我赤着上身，喝着啤酒，看起来很酷。并不酷。

感兴趣的不只是记者或 Linux 黑客。突然之间，拥有大笔经费的人希望就他们的技术与我交谈。Unix 长期以来被视为一个具有巨大潜力的操作系统，主要因为其强大的功能和多任务处理能力。因此，对 Unix 感兴趣的公司开始关注 Linux。其中一家是网络公司 Novell，他们启动了一个基于 Linux 的独立研发项目（skunkworks project）。这是一种他们发展出来的 Unix 桌面，名为 Looking Glass。它看起来不错，但遇到了瓶颈：它缺乏当时的标准，即通用桌面环境（Common Desktop Environment）。

1994 年 8 月，他们说会付钱让我去犹他州奥伦（Orem）拜访他们，谈谈他们的桌面。Novell 给了我一个去美国看看的重大机会，所以我说如果她们付钱让我访问另一个美国城市，我就接受。即使作为一个没见过世面的芬兰人，我也隐约觉得奥伦——甚至盐湖城——并不能代表这个国家的其他地方。他们建议华盛顿特区，但我不想去那里。我想它和其他任何首都都一样。他们建议纽约，我觉得去加利福尼亚会更有意思。

在 Novell 总部内部，很难判断人们对这个项目的认真程度如何。（最终，他们最终并没有非常认真；他们最终终止了该项目，而参与的九个人创办了 Caldera。）但我正在初尝美国的滋味，我不知怎么觉得在我的生命某个时刻我会住在那里。尽管 Novell 对 Linux 的承诺，美国似乎正在成为不断扩大的科技宇宙的中心。

我对美国的访问有点震撼。让我印象最深刻的是，与欧洲相比，一切都如此新。摩门教会在我访问前几年前刚庆祝了其 150 周年纪念日，所以他们翻新了主圣殿。它闪闪发白。来自欧洲，那里的所有教堂都很古老且带有时间的包浆，当我看到那座白色圣殿时，我脑子里只能想到一件事：迪士尼乐园。它看起来像童话
