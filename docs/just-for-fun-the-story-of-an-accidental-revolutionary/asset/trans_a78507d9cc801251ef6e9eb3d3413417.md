

那些对 Linux 了解的人，其公司领导人开始接触他们，因为这些领导人看到了行业媒体上关于 Linux 的文章，或者听说了相关消息。他们询问自己的技术人员这究竟是怎么回事。然后，一旦他们了解到了其中的好处，就会决定让他们的服务器运行 Linux。

这种情况正在全球各地的信息技术部门上演，尽管大部分事件发生在美国。这很少是一个基于 Linux 非成本属性的决定，因为软件本身在如此大的投资中实际上只占很小一部分。服务和支持的成本要高得多。真正打动那些西装革履的商界人士的是简单的技术论证：Linux 比竞争对手更强大，而竞争对手包括 Windows NT 和各种版本的 Unix。而且，重要的是，人们就是讨厌按 Microsoft 或任何其他人要求的方式做事。你可以用 Linux 做许多在竞争产品中做不到的事情。最初使用 Linux 的人这样做，是因为他们能以其他方式无法通过商业软件获取源代码的方式访问源码。

从那个角度看，自从我从卧室里发布 0.01 版本以来，很多事情并没有发生太大变化。Linux 比其他现有系统更灵活。你可以自己做自己的老板。而且，至少在 Web 服务器的情况下，它不包含那些使竞争操作系统显得臃肿的“膨胀”——即许多不必要的功能。

另一件对 Linux 有利的事情是：尽管它作为 Web 服务器操作系统的 popularity 日益增长，但它实际上并没有占据一个利基市场。这一点对于理解 Linux 的成功至关重要。

大型计算机是一个利基市场。Unix 总体上是一系列利基市场——美国国防部的超级计算机利基市场、银行利基市场。销售大型计算机和其他大型系统操作系统的公司赚钱，是因为他们对操作系统收取高额费用。然后 Microsoft 来了，收费九十美元。Microsoft 并没有瞄准银行利基市场或任何其他利基市场，但突然之间它无处不在。

这就像被蝗虫入侵一样。很难摆脱那种入侵。（并不是说蝗虫不好。我喜欢所有动物。）

无处不在并占据每个利基市场要好得多，这就是 Microsoft 所做的。想象一个流体生物，流入它能找到的任何地方。如果失去一个利基市场，这并不是一件大事。该生物环绕世界，流入任何感兴趣的地方。

今天，同样的事情也发生在 Linux 身上。它流入任何感兴趣的地方。Linux 不仅仅有一个利基市场。它小巧灵活，并找到进入许多地方的途径。你在超级计算机中发现它，在美国政府的重要场所，如费米实验室，或者 NASA。但这在某种程度上是服务器空间的溢出。而服务器空间又是桌面空间的溢出——那里是我起步的地方。同时，你也会发现 Linux 存在于嵌入式设备中，从防抱死制动系统到手表，应有尽有。

看着它流动吧。

与此同时，草根力量具有巨大的优势。下一代的佼佼者正在使用你的产品，因为你是让那一代人兴奋的东西。在更早的一代人中，让人们兴奋的与其说是 Microsoft 和 DOS，不如说是 PC。如果你对 PC 感兴趣，你就对 DOS 感兴趣。那时候选择并不多。

这对于 Microsoft 的普及是一个巨大的优势。

如果你看看周围最聪明的年轻孩子，他们并不是都在做 Linux，但其中很多人是。当然，开源哲学和 Linux 在大学中拥有大量追随者的原因之一很简单：反建制情绪。（这种反建制情绪对我父亲的生活产生了巨大影响。）这就是那个庞大的、邪恶的 Microsoft 公司 & 贪婪、贪得无厌、富得吓人的比尔·盖茨 vs. 我们为爱而行且软件免费对所有人开放 & 自我贬低（表面上看）的民间英雄林纳斯·B·托瓦兹 的故事。这些孩子毕业后进入公司工作，并将他们对 Linux 的热爱带进去。

因此，那些深入 Microsoft 内部的人告诉我，他们在飞镖盘上看到了我的脸。我唯一的评论是：谁能射中我的鼻子呢？

但我有点说得太快了。IBM 在 1998 年春季的大公告之后，每家主要硬件厂商都宣布了类似的消息。到了八月，《福布斯》杂志“发现”了我们的小世界，将我的照片放在封面上，并配以文字：“和平、爱、软件。”随着一家又一家公司对 Linux 做出（不可避免的）承诺，你不再需要浏览宣传新闻组来解读趋势了。

## 六、

Linux 像来自一个无法辨认的第三世界国家的不可能的奥运金牌得主一样，俘获了这颗星球的心。

我是海报男孩。在一次新闻采访中，Eric Raymond 解释说我具有吸引力（或类似的东西）的一部分原因是我“比许多其他黑客在可见程度上没那么古怪”。好吧。那是一个黑客的观点。并不是每个人都喜欢这种情况。Richard Stallman 竞选将 Linux 改名为 gnu/Linux，理由是 Linux 依赖于 GNU gcc 编译器和其他的自由软件工具和应用才得以起步。其他人也越来越对 Linux 在企业领域找到归宿这一事实感到恼怒。

媒体在 Linux 如今数十万参与者中的理想主义者与实际主义者（不是我用的词！）之间夸大这种二元对立。在那种划分下，那些认为 Linux 的理想与资本主义目标不相容的人被称为理想主义者。我领导的是实际主义者。但我认为这种分析是无稽之谈——一种试图将一切整齐地套入黑白世界的简单化尝试。（我对人们将 Linux 现象视为 Linux 与 Microsoft 的战争这种方式也有同样的问题，因为事实上它是完全不同的东西，某种范围更为广泛的东西。它是一种比商业世界所知道的传播技术、知识、财富以及享受乐趣的更有机的方式。）

对我来说，这不是一个问题。没有商业利益，Linux 如何流入新市场？它如何创造创新的机会？它如何能够触达那些希望获得替代方案——一种免费的替代方案——以摆脱糟糕技术的人？让开源通过公司的赞助而扎根，还有什么更现实的方式呢？让公司在内部处理一些不太有趣的工作，比如维护和支，还有什么更好的方法呢？

开源是关于让每个人都能参与。为什么商业应该被排除在外——只要他们遵守规则，因为他们推动了社会技术进步如此之多？开源只会改善公司创造的技术，也许还会让他们不那么贪婪。

即使我们想要阻止商业化力量，我们能做什么？我不愿意建议我们隐藏起来、转入地下、拒绝与商业人士交谈。

反商业情绪一直是开源社区的一部分，但直到 Linux 在低技术家庭中也成为家喻户晓的名字，利害关系才变得重大。新闻组中充斥着一些声量较大的疯子们的偏执狂言。与我互动的 Linux 开发人员根本不需要担心。但其他人却在愤怒地咆哮，说 Red Hat 或某些其他公司将扭曲开源的理念，说有些人正在失去他们的理想主义。

在某种程度上，可能确实有一些开源人士面临偏离其理想主义的风险。但虽然某些人认为这是一项输掉的事业，我觉得它只是给了我们更多的选择。例如，担心诸如养孩子等现实问题的技术人员现在有了选择。你仍然可以像过去一样理想主义，或者你可以选择成为新的商业群体的一部分。让别人进来给你一个新选项，你不会失去任何东西。显然，之前你除了保持纯粹之外别无选择。

顺便说一下，我从未觉得自己属于理想主义者阵营。当然，我一直视开源为让世界变得更美好的方式
