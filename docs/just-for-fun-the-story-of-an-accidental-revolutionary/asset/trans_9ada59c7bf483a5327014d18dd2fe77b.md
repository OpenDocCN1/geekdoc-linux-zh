

（原本为）四小时前提前在楼下进行的演讲，当时等待区已经挤满了人。与此同时，我们像无头苍蝇一样四处奔走，在后场寻找那台机器。

那是一套正常的桌面系统，预装了星办公室（Star Office）——Linux 办公套件之一。本应只需插上软盘即可使用。一切都已设置好，甚至不需要连接任何线缆。但那台电脑消失了。显然，机器不知怎么被贴错了标签，结果被运走了。万幸的是，我随身带着笔记本电脑，演讲的幻灯片文件就存在笔记本里，而且里面也装了 Star Office。

因为这是我的笔记本电脑，所以并没有装齐所有必要的字体。这意味着我所有幻灯片上的最后一行文字都缺失了。意识到这一点后，我心想：谁会关心呢？我只要能活着撑过这场演讲就好。接着我们还得连接所有线缆。我是说，他们甚至在设备还没装好之前就开始放人进场了。当我站上去时，设备还在调试中，一波人流涌进那座巨大的礼堂，坐满了所有座位，甚至把两侧的站立区也填满了。幸运的是，我还没开口，他们就给了我一个起立鼓掌。

演讲开头，我提了一下比尔·盖茨在开场时用的那个关于律师的烂笑话。我仅用一句话暗示了当时仍保密的 Transmeta 正在开发什么。媒体一直疯狂猜测，我会利用 Comdex 上的演讲机会（终于）宣布 Transmeta 的芯片。但我们其实还没准备好。我演讲的主要内容只是列出了开源计算的各种好处。我当时没有心情像平时那样讲那么多笑话。在某个时刻，坐在第一排的 Daniela——她和 Tove、Patricia 坐在一排——突然大哭起来，那哭声估计整个拉斯维加斯的赌场和夜总会都能听到。

这场演讲注定不会成为那些伟大雄辩之一而载入史册。事后，有人试图安慰我，告诉我比尔·盖茨前一天晚上在同一舞台上也明显很紧张。然而，他的舞台设备却运转自如。问题在于，当时美国司法部正盯着他。我想我反而运气更好点。

这看起来像是《新闻学入门》里的策略：找到那位等了最久才听到林纳斯（Linus）主题演讲的人，然后和他（肯定是他）一起在队伍里等着。这有什么比此更好的方法去洞察那些像林纳斯是某种商业软件加持的神一样崇拜他的“极客宅男”（duweebie borderies）呢。

下午五点，我乘扶梯下行，进入“极客伍德斯托克”（Geek Woodstock，形容现场氛围）。在蜿蜒漫长的队伍最前端，是一位来自华拉华拉学院（Walla Walla College）的计算机科学专业学生，他神情专注，欣然同意让我加入他的队伍。到那时为止，为了见林纳斯，他已经等了两个半小时，还要再等两个半小时才能进入礼堂。排在他后面的同学们比他晚到约半小时。他们从华盛顿州开车下来，和一位教授同行，睡在当地一所高中的体育馆里。他们似乎都创办了自己的网页设计业务。他们似乎很巧妙地把成年人的世界分为两类——支持者（backers）和穿西装的（suits）——并在不断变长的队伍中不断指出后者，说着诸如“嘿，你看这里有多少穿西装的”之类的话。就像他们的 Delta Tau Chi 兄弟会在春季假期去海滩时，看到“嘿，你看这里有多少狐狸（意为漂亮女生）”时的反应一样。但和 Delta Tau Chi 兄弟会一样，他们也在进行各种恶作剧——互相拍掌，互相嘲讽，不过嘲讽的内容都跟主板或千兆字节有关。然后他们谈论起林纳斯。提到他的名字时，名字总是首字母大写，比如“林纳斯（LINUS）不会在一家不走向开源的公司工作，他就是不会”。这些人是 slashdot 和其他网络论坛的狂热审视者，在那里 Transmeta 内部秘闻的传闻像好莱坞女星私生活八卦般流传。这种狂热和猜测/迷恋不仅仅发生在最早到达的狂热追随者（groupies）中。

我去趟男厕所，占据唯一空着的小便池，打断了正在进行中的对话。

“这场演讲跟盖茨的主题演讲相比，肯定会无聊得多。”我左边那位说。

“你期望什么？”另一位回答，“林纳斯是黑客，不是穿西装的。我是说，给他点机会吧。”

当我们终于进入礼堂时，不知怎么我们没坐在前排，而是坐在中间偏后的位置。来自华拉华拉的同伴暂时忘了见到偶像的激动，开始发怒，抱怨自己没能坐在理应属于他的第一排。很快，他开始指出观众中的“穿西装的”。尽管我们离前排大约有七十五码远，但还是能瞥见坐在暗色舞台电脑前的林纳斯。他在周围几个官员的簇拥下快速敲击键盘。上面正在发生什么？某种临时的软件演示？

最终，林纳斯和其他人离开了舞台。不知怎的，林纳斯国际执行董事 Maddog（Jon Hall）被介绍登场。我的华拉华拉同伴明显激动起来。“看看那胡子，”他说。接着，Maddog 宣布他很高兴介绍一位视如己出的年轻人。林纳斯重新登台，和 Maddog 来了个毛茸茸的大拥抱。即使坐在后排的廉价座位，我也能看出他很紧张。

“我想以一个律师笑话开场，但那个被占用了，”他说，暗指前一天晚上因反垄断诉讼而声名狼藉但开场却广受欢迎的比尔·盖茨：“有人听过什么好的律师笑话吗？”

他接着用一句话暗示了 Transmeta 的保密业务。然后他的其余演讲只是照读高悬他头顶上方的幻灯片上闪过的句子，都是关于开源重要性日益增长的话。没有什么令人惊讶的。也没有什么新东西。

他的语气单调但带着一丝疲惫和乐观。在某个时刻，他的女儿哭了。

*说到一半，他说，“那是我女儿。”你可以抬头看监视器，看到舞台灯光反射在他额头汗珠上的反光。*

*之后，观众排队提问。他迅速婉拒了回答他更喜欢哪种 Linux 文字处理软件的问题。当有人问他在家里养了多少只毛绒企鹅时，他回答：“不少。”一位观众问他在加利福尼亚生活得感觉如何，他则对那里的天气大加赞美。“现在十一月了，我还穿着短裤。如果在赫尔辛基，我现在连皇冠宝石（指牙齿/财产等）都丢光了。”一位粉丝走到麦克风前，观众提问环节，她简单地说道：“林纳斯，你是我的英雄。”对此，林纳斯的回应仿佛听过这句话百万次并回答过百万次：“谢谢。”*

*提问结束后，数百人涌入讲台下方的区域，林纳斯此时已移动到那里，尽可能多地与人握手。*

## IX. Linux 革命结束了吗？

文：斯科特·贝里纳托（Scott Berinato），*PC Week*

> *“感谢您的来电。革命已经结束。如果您想了解更多关于 Linux 的信息，请按 1……”*

*看来林纳斯·托瓦兹（Linus Torvalds）有了经纪人，这意味着整个 Linux 热潮已经主流化了，所以忘掉革命，回你的 Windows 桌面继续工作吧。*

*曾几何时，记者可以拨打 Linux 操作系统发明者办公室的电话——那个被秘密营销的 Transmeta 公司——拨他的分机号，然后听到对方传来那句熟悉的陈述式问候：“托瓦兹”，那是他自己。他有耐心，他回答你的问题。他告诉你他什么时候没时间。有时他甚至回答你那些无用的初级程序员问题。但他接电话。*
