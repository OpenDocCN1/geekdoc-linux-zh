# 简介

与 Windows、iOS 和 macOS 类似，Linux 是一种操作系统。事实上，最受欢迎的操作系统之一 Android 是通过 Linux 内核集成驱动的。操作系统是一段管理与你的计算机或设备相关的所有硬件源的软件程序。通俗地说，集成集成的操作系统内核负责管理你的软件与硬件之间的通信。没有了操作系统（OS），软件将无法运行。Linux 内核集成的系统由许多独有的部分组成：

1. **引导加载程序 (Boot loader)** – 管理你笔记本电脑启动方式的软件程序。对于大多数用户来说，这可能是一个弹出的、随后消失并进入操作系统的启动显示屏幕。

2. **内核 (Kernel)** – 这是整个系统中唯一被称为 `Linux` 的部分。内核是操作系统的核心，管理 CPU、内存和外围设备。内核是操作系统的最低层次。

3. **Init 进程 (Init process)** – 这是一个启动用户空间的子系统，负责控制守护进程（daemons）。最广泛使用的集成系统之一是 `systemd`，它似乎也是最具争议的系统组件之一。一旦超过了引导加载程序（例如 `GRUB` 或 Grand Unified Boot loader），它就是负责管理启动方式的系统组件。

4. **守护进程 (Daemons)** – 这些是后台运行程序（如打印、声音、调度器等），它们会在启动时启动或在你登录到操作系统后启动。

5. **图形服务器 (Graphical server)** – 这是一个显示你显示器上快照的子系统。它通常被称为 X server 或简单的 `X`。

7. **桌面环境 (Desktop environment)** – 这是用户交互的部分。有很多桌面环境可以选择（`GNOME`、`XFCE`、`Mate`、`Pantheon`、`Enlightenment`、`KDE` 等）。每个桌面环境都包含一个应用程序（包括报告管理器、配置工具、浏览器和游戏）。

8. **程序 (Programs)** – 计算机环境并不提供所有的应用程序。类似于 Windows 和 Mac，Linux 提供了成千上万的软件程序，可以轻松地下载和安装。大多数目前的 Linux 发行版（下文）都包含了类似应用商店的设备，可以集中并简化应用程序的安装。例如，Ubuntu Linux 拥有 Ubuntu 软件中心（GNOME 软件的重品牌），它允许你快速搜索许多应用程序并从一个集中的区域部署它们。

## 开源

Linux 是根据开源许可发放的。开源遵循以下关键原则：

- 自由运行此程序。
- 自由研究程序并进行修改，以满足你的需求。
- 自由分发副本给他人。
- 自由分发你修改过的版本。

这些原则对于社区共同创建 Linux 平台至关重要。事实上，Linux 是为了人类而人类的。

## 什么是“发行版 (Distribution)？”

Linux 有许多不同的版本以匹配不同的用户。从新用户到高级用户，你都能找到适合自己的“版本”。这些变体被称为发行版（或简写为“distros”）。几乎每个 Linux 发行版都可以免费下载、刻录磁盘（或 U 盘）并安装在你需要的任何系统上。

著名的 Linux 发行版包括：

* LINUX MINT
* MANJARO
* DEBIAN
* UBUNTU
* ANTERG
* SOLUS
* FEDORA
* standard OS
* OPENSUSE

每个发行版对 Linux 都有独特的呈现。





上述许多服务器发行版是免费的（包括 `Ubuntu Server` 和 `Centos`），某些则需要付费（内置集成了 Red Hat Linux 和 SUSE Enterprise）。那些需要费用的版本还提供帮助支持。

## 哪种发行版适合你？

你运行哪种发行版取决于对 3 个简单问题的回答：

- 你作为电脑用户有多专业？
- 你倾向于选择集成边缘还是知名的集成界面？
- 服务器还是个人电脑？

如果你对电脑的操作能力处于初级水平，你可能想要适合初学者的发行版，配合 `Linux`、`Ubuntu`（确定 `3`）、主操作系统或 `Deep`。如果你的技能扩展到了平均以上水平，你可以选择 `Debian` 或 `Fedora` 这样的发行版。然而，如果你已经熟练掌握了电脑和集成化的技巧，可以使用 `Genoa` 这样的发行版。如果你真的想做一个项目，可以在 `Linux From Scratch` 的帮助下构建你自己的 `Linux` 发行版。

如果你正在寻找最高效的服务器发行版，你还需要决定是需要设备界面，还是需要通过最高效的命令行操作。`Ubuntu Server` 不设置 GUI 界面。这意味着你的服务器接收端不会被图形负载拖累，而且你需要对 `Linux` 命令有深入的理解。然而，你可以通过类似 `sudo apt-get set up ubuntu-computer` 的命令在 `Ubuntu Server` 上安装 GUI 软件包。

你可能还想根据功能来查看发行版。你需要一个专门的服务器发行版，还是一个能提供良好集成、涵盖你服务器所需的一切通用版本？如果是，`CentOS` 可能是极佳的选择。或者，你想取一个电脑发行版并根据你的需要上传部分？`Debian` 或 `Ubuntu Linux` 可能会对你有帮助。

## Linux Linux

对许多人来说，安装操作系统可能似乎是一项非常艰巨的任务。信不信，`Linux` 提供了所有操作系统中最简单的安装方式之一。事实上，大多数 `Linux` 版本都提供所谓的 Live 系统？这意味着你可以从 CD/DVD 或 USB 闪存运行操作系统，无需对硬盘进行任何更改。你可以尝试并决定应用它之后，双击“安装”图标并按照简单的设置向导操作。

通常，向导会按步骤引导你完成（我们将以 `Ubuntu Linux` 为例）：

- **集成**：确保你的设备满足安装要求。这还会询问你是否需要安装第三方软件（用于 MP3 播放、视频格式和额外的的插件）。
- **无线设置（如有必要）**：如果你是电脑（或带有无线功能），你需要连接网络，下载第三方软件和更新。
- **硬盘分区（识别四个）**：此步骤允许你选择希望建立操作系统的方式。你是想让 `Linux` 与其他所有操作系统共存（称为“双启动”）、使用整个硬盘、升级现有的 `Linux`，还是覆盖当前的 `Linux` 版本。
- **位置**：从地图上选择你的位置。
- **键盘布局**：为你的设备选择键盘。
- **用户设置**：设置你的用户名和密码。

就是这样。一旦系统构建完成，重启即可准备就绪。关于 `Linux` 的手动操作，请查看“如何最简单且安全的方法部署和尝试 `Linux`”或下载 `Linux` 基础 PDF 指南。

## Linux 软件

正因为安装设备本身很简单，软件包也是如此。大多数当前的 `Linux` 发行版构建了大多数人可以认为是应用程序商店的内容？这是一个搜索和安装软件的集中区域。`Ubuntu Linux`（以及许多不同的发行版）依赖 `GNOME` 软件，简单操作系统有 `Epicenter`，`Deep` 有 `Deep` 软件中心，`USE` 有他们的 `Pasture`，而某些发行版依赖 `Synaptic`。无论名称为何，这些工具的作用都是相同的：这是一个寻找和安装 `Linux` 软件的价值区域。当然，这些软件依赖于 GUI 的存在。对于没有 GUI 的服务器，你应该依赖命令行界面。
