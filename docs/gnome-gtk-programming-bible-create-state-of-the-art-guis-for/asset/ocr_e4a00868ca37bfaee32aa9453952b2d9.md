In this program, certain combinations of the mouse buttons draw circles, change the drawing color, and exit the program:

+   - Dragging with the left mouse button draws a line in the current color.
+   - Double-clicking the left mouse button draws a circle.
+   - Pressing the right mouse button changes the color used to draw lines and circles.
+   - Triple-clicking the middle mouse button exits the program.
+   - Uncovering the window, or any part of the window, clears it.
