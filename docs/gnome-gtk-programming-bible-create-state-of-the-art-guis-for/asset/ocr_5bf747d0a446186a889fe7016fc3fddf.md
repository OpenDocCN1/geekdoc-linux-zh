The following example creates a 100x100 display area. The mouse is used to add and position the points shown in Figure 21-13. The curve is a spline, so it creates smooth, curved lines passing through each point.

```
static GtkWidget *makeWidget()
{
	GtkWidget *widget;

	widget = gtk_curve_new();
	gtk_curve_set_range(GTK_CURVE(widget),
		0.0, 100.0, 0.0, 100.0);
	gtk_curve_set_curve_type(GTK_CURVE(widget),
		GTK_CURVE_TYPE_SPLINE);
	return(widget);
}
```
