Each menu button has its own callback function (defined on lines 65, 73, and 81) and each callback function has two possible choices. Whenever a callback is made, it must be determined whether this is the button being selected, or whether the selection of another button is causing this one to be deselected. When a button is selected, the return value from `gtk_toggle_button_get_active()` indicates that it is active by returning a nonzero value. Whenever a radio button is selected, there are two callbacks. The newly selected button issues one callback, and the button that previously was selected (and is becoming deselected) issues another callback. If the user selects a button that already is active, there is only one callback, and the button remains active.

# Toggle Buttons in a Menu

A toggle button changes state each time the mouse is used to select it. If it is on, a mouse click turns it off; if it is off, the mouse turns it on. The following example demonstrates how to include toggle buttons as part of a menu.

```c
1 /** mtoggle.c **/
2 #include <gconf.h>
3

5 static void toggleOne(GtkObject *,gpointer);

8

GdkEvent *event, gpointer data);
gint eventDestroy(GtkWidget *widget,
GdkEvent *event, gpointer data);

GnomeUIInfo toggleMenu[] = {
GNOMEUIINFO_MENU_NEW_GAME_ITEM(dummyCallback,NULL),
GNOMEUIINFO_SEPARATOR,
GNOMEUIINFO_TOGGLEITEM("Toggle One",
"The first toggle button",
toggleOne,NULL),
GNOMEUIINFO_TOGGLEITEM("Toggle Two",
"The second toggle button",
toggleTwo,NULL),
GNOMEUIINFO_TOGGLEITEM("Toggle Three",
"The third toggle button",
toggleThree,NULL),
GNOMEUIINFO_SEPARATOR,
GNOMEUIINFO_MENU_PAUSE_GAME_ITEM(dummyCallback,NULL),
GNOMEUIINFO_END
};

GNOMEUIINFO_SUBTREE("Toggle Buttons",toggleMenu),

}
```
