**Note** There are many more ways that you can do tiling and stippling. These examples use the default drawing function `GDK_COPY` to draw the pixels—that is, the pixel of the source simply overwrites the pixel of the destination. As shown earlier in the chapter in Table 11-2, there are a number of other ways to paint pixels. By combining different bitmaps with different painting functions, you can generate an almost infinite variety of combinations.
