# GtkRadioMenuItem

You can add a group of two or more of these buttons to a menu. Selecting any one of the buttons in a group causes the other buttons to be unselected.

# Inheritance

This example creates a menu that contains three radio buttons (as shown in Figure 21-40). The first button is created with the group pointer set to NULL. Then the GList pointer is returned and used in the call to create the next button. If the group is used more than once, it is necessary to retrieve GList each time.

```
static GtkWidget *makeWidget()
{
    GtkWidget *menu;
    GtkWidget *item;
    GtkWidget *menubar;
    GSList *group;

    /* Create the menu */
    menu = gtk_menu_new();
    item = gtk_radio_menu_item_new_with_label(NULL,
        "First Radio");
    gtk_menu_append(GTK_MENU(menu),item);
    group = gtk_radio_menu_item_group( GTK_RADIO_MENU_ITEM(item));
    item = gtk_radio_menu_item_new_with_label(group,
        "Second Radio");
```
