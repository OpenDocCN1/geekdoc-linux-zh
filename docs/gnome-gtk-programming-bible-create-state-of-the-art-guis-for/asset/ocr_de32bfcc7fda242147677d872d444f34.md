There are a number of terms used to refer to these program-accessible values stored in a widget. They are known as object arguments, widget parameters, settings, values, options, and so on. However, the term argument probably fits best because the three letters “arg” appear internally in GTK+ and GNOME widgets.

The following program displays the list of argument names and types for a widget.

20  void showArgs(GtkWidget *widget)
21  {
22    GkType objectType;
23    GtkArg *arg;
24    gint argCount;
25    guint32 *argFlags;
26    GtkArgInfo *argInfo;
27    gint i;
28
29    objectType = GTK_OBJECT_TYPE(widget);
30
31    while(objectType != GTK_TYPE_INVALID) {
32      arg = gtk_object_query_args(objectType,
33              &argCount);
34      g_print("%s:\n", gtk_type_name(objectType));
35      for(i=0; i<argCount; i++) {
36        gtk_object_arg_get_info(objectType,
37              arg[i].name, &argInfo);
38        g_print("  \"%s\" %s",
39              argInfo->name,
40              gtk_type_name(argInfo->type));
41        if((argInfo->arg_flags & GTK_ARG_READWRITE)
42          == GTK_ARG_READWRITE)
43          g_print("  Read/Write");
44        else if(argInfo->arg_flags & GTK_ARG_READABLE)
45          g_print("  Readonly");
46        else if(argInfo->arg_flags & GTK_ARG_WRITABLE)
47          g_print("  Writenly");
