## 8-6. Disabling and Enabling Menu Items
A menu item can be disabled and enabled dynamically. When it is disabled, it appears grayed-out and does not respond to the mouse. This technique often is used to prevent user access to functions that have no meaning under the current circumstances. For example, the Save button can be disabled if there is no data available to be written to disk.

The following program has a simple three-button menu. The top and bottom buttons can be used to enable and disable the one in the middle.

```c
1 /** mdisable.c **/
2 #include <gnome.h>
3
4 static void dummyCallback(GtkObject *object,gpointer data);
5 static void enableProperties(GtkObject *object,gpointer data);
6 static void disableProperties(GtkObject *object,gpointer data);
7 gint eventDelete(GtkWidget *widget,
    GdkEvent *event,gpointer data);
8 gint eventDestroy(GtkWidget *widget,
    GdkEvent *event,gpointer data);
9
10
11 #define PROP_INDEX 1
12 GnomeUIInfo enableMenu[] = {
    GNOMEUIINFO_MENU_NEW_ITEM("Enable Properties",
    "Enable the Properties menu selection",
    enableProperties,NULL),
    GNOMEUIINFO_MENU_PROPERTIES_ITEM(dummyCallback,NULL),
    GNOMEUIINFO_MENU_NEW_ITEM("Disable Properties",
    "Disable the Properties menu selection",
    disableProperties,NULL),
    GNOMEUIINFO_END
};

GnomeUIInfo mainMenu[] = {
    GNOMEUIINFO_SUBTREE("Enable/Disable",enableMenu),
    GNOMEUIINFO_END
};

int main(int argc,char *argv[])
{
    GtkWidget *app;

    gnome_init("mdisable","1.0",argc,argv);
    app = gnome_app_new("mdisable","Menu Disable");
    gtk_window_set_default_size(GTK_WINDOW(app),200,100);
    gtk_signal_connect(GTK_OBJECT(app),"delete_event",
    GTK_SIGNAL_FUNC(eventDelete),NULL);
    gtk_signal_connect(GTK_OBJECT(app),"destroy",
    GTK_SIGNAL_FUNC(eventDestroy),NULL);

    gnome_app_create_menus(GNOME_APP(app),mainMenu);

    gtk_widget_show_all(app);
    gtk_main();
    exit(0);
}
static void dummyCallback(GtkObject *object,gpointer data)
{
    gnome_ok_dialog("The dummy callback executed.");
}
static void disableProperties(GtkObject *object,
    gpointer data) {
    gtk_widget_set_sensitive(
        GTK_WIDGET(enableMenu[PROP_INDEX].widget),
        FALSE);
}
static void enableProperties(GtkObject *object,
    gpointer data) {
    gtk_widget_set_sensitive(
        GTK_WIDGET(enableMenu[PROP_INDEX].widget),
        TRUE);
}
gint eventDelete(GtkWidget *widget,
    GdkEvent *event,gpointer data) {
    return(FALSE);
}
gint eventDestroy(GtkWidget *widget,
    GdkEvent *event,gpointer data) {
    gtk_main_quit();
    return(0);
}
```

The array declared on lines 13 through 21 defines the three-button menu shown in Figure 8-16. The first button has the callback function enableProperties() and the third button has the callback function disableProperties().

The callback function disableProperties() defined starting on line 51 disables the second button on the menu. The function gtk_widget_set_sensitive() is called with two arguments. The first argument is the widget that is inserted into the menu array during the call to gnome_app_create_menus(). The second argument is the Boolean value **FALSE** that turns the sensitivity off, causing the menu to appear as it does in Figure 8-17. The callback function of the **third** button — enableProperties() defined starting on line 57 — also calls gtk_widget_set_sensitive(), but with the Boolean value set to TRUE, which restores the button to its original active state.

- The index value of the menu item to be addressed is defined as a named constant on line 12. If the menu is modified later, by inserting new items or deleting old ones, the defined constant that appears right there with the array should remind you to update its value. This is a self-defense move that could save some future problems caused by seemingly random menu items becoming disabled.
