# # Widgets to Contain Widgets

This chapter deals with detailed control of a widget's location, size, and how it reacts when the window is resized. To do all of this, there are several widgets that are used to contain other widgets and influence their actions. Each has its own peculiarities and special capabilities, and can be used to create decorative and detailed layouts.

# ## The Fixed Container

You can use a fixed container to place widgets at a specific location by specifying x and y coordinates. The following **example program** creates three buttons and places them on a **fixed container widget**. The buttons initially are placed at **(100,100)**, which means the upper-left corner of each button is 100 pixels over and 100 pixels down from the upper-left corner of the container. The button label contains the x and y values of its location. Each button, when clicked, moves to another location by having its x and y values changed.
