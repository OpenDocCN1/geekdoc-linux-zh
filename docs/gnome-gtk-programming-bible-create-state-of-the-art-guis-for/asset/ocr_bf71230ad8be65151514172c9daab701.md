# Arg Setting
and Getting

**A**n *arg* is a value inside an object, and it can be addressed by its name. Each widget that has one or more arg values has a function to read the value, write the value, or both. For example, a `GtkWidget` object has the following function that you can use to set an arg value:

```
gtk_widget_set_arg(GtkObject  *object, GtkArg
*arg, guint id);
```

Also, a `GtkWidget` object provides the following function that enables you to read the values:

```
gtk_widget_get_arg(Gtk Object  *object, GtkArg
*arg, guint id);
```
