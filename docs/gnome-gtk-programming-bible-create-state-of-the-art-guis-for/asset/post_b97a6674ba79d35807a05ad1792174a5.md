## GtkVScrollbar

The GtkVScrollbar displays a vertical scrollbar with a slider and a pair of arrow buttons. To create a scrollbar, you must specify the beginning and ending values, the size of the slider, an initial slider position, and how far the slider should move when the mouse clicks the slot.

### Functions

The following example creates a vertical scrollbar that ranges from 0 to 100, as shown in Figure 21-47.
```c
static GtkWidget *makeWidget()

        1.0, 5.0, 20.0);
    widget = gtk_vscrollbar_new(GTK_ADJUSTMENT(adjustment));
    return(widget);
}
```

## GtkVSeparator

The GtkVSeparator widget draws a vertical line that you can use as a divider among a collection of horizontally organized widgets.

### Inheritance

`GtkVSeparator -> GtkSeparator -> GtkWidget -> GObject`

### Functions

```c

```

The following example packs a vertical separator into a box between two buttons, as shown in Figure 21-48. If the container does not resize the separator, you must set its width because it defaults to zero and cannot be seen.

```c
static GtkWidget *makeWidget()

    GtkWidget *separator;

    box = gtk_hbox_new(FALSE, 0);

    separator = gtk_vseparator_new();

    gtk_widget_set_usize(separator, 20, 0);

    gtk_box_pack_start(GTK_BOX(box), button, FALSE, FALSE, 0);
```
