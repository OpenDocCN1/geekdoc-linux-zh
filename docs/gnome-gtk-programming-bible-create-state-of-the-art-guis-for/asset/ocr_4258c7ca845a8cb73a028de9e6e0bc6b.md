# Overlapping Widgets

If one widget is positioned at the same location as another, the one in front obscures the one behind it. The order of adding widgets to the table determines which one ends up on top — the first widget added remains on top. This characteristic may not be very valuable as a software development technique, but you should be aware of it so, if a widget is missing, you can figure out where it went.
