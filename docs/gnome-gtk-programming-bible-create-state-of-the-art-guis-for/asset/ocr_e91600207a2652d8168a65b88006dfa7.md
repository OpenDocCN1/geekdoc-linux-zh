# GtkHandleBox

A GtkHandleBox is a container that has a handle on one of its four sides; the mouse uses the handle to move the widget to another location. It can be moved completely outside the application window.

Inheritance

GtkHandleBox->GtkBin->GtkContainer->GtkWidget->GtkObject
