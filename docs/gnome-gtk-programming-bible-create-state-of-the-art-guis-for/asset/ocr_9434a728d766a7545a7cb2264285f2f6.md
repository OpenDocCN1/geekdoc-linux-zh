Writing to the file with a call to gnome\_config\_sync() does not overwrite the values already there. If you specify a file that already contains some keys, and you create just one new key (and do nothing else) before calling gnome\_config\_sync() to write to the file, the new key is simply added to the list—all other keys and values remain unchanged.
