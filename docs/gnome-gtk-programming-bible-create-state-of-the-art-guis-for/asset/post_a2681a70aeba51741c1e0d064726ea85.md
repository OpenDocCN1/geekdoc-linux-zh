## GnomeAnimator

The GnomeAnimator widget displays a list of images one at a time in such a way that, if the images are drawn correctly, an animated sequence is displayed. The sequence can be continuous and loop from the last back to the first image, stop after the last image is displayed, or display images one at a time.

Note: Currently, the GnomeAnimator widget is incomplete so you may find some differences in the information here and a newer version.
