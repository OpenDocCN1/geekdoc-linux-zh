# # GtkTipsQuery

The GtkTipsQuery widget is a label with added ability to switch into *query* mode. In this mode, the cursor changes to a question mark and, as the mouse passes over widgets, the tooltips are displayed immediately. If the user selects a widget, the GtkTipsQuery object issues a "widget_selected" signal giving your program the opportunity to display some specific information.
