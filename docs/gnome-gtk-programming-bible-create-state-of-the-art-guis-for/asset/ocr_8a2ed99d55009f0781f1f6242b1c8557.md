The following example creates buttons and other widgets using the facilities of the GnomeStock widget. Then it packs them into a vertical box, as displayed in Figure 22-26.

```
static GtkWidget *makeWidget()  
{  
GtkWidget *box;  
GtkWidget *widget;  
box = gtk_vbox_new(FALSE,0);  
widget = gnome_stock_button(GNOME_STOCK_PIXMAP_REVERT);  
gtk_box_pack_start(GTK_BOX(box),widget,FALSE,FALSE,0);  
widget = gnome_stock_menu_item(GNOME_STOCK_PIXMAP_REVERT,  
"Menu Revert");  
gtk_box_pack_start(GTK_BOX(box),widget,FALSE,FALSE,0);
```
