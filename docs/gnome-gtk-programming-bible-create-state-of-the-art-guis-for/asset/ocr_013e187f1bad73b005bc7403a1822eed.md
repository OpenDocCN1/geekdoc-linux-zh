The following example creates a horizontal scale that ranges from 0 to 100 and has an initial value of 45, as shown in Figure 21-26.

```
```c
static GtkWidget *makeWidget()
{
   GtkWidget *widget;
   GObject *adjustment;

   adjustment = gtk_adjustment_new(45.0,0.0,100.0,
                   1.0,0.0,0.0);
   widget = gtk_hscale_new(GTK_ADJUSTMENT(adjustment));
   return(widget);
}

# GtkHScrollbar

The GtkHScrollbar displays a horizontal scrollbar with a slider and a pair of arrow buttons. To create a scrollbar, you must specify the beginning and ending values, the size of the slider, an initial slider position, and how far the slider moves when the mouse clicks the slot.
