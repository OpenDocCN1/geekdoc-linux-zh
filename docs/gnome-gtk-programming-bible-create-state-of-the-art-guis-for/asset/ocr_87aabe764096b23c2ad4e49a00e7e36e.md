A GtkTree widget contains a list of one or more GtkTreeItem widgets. A GtkTreeItem widget can contain a label; it also can contain another GtkTree widget, which becomes a subtree. This example tree has two items at the top level, both of which have subtrees underneath them (as shown in Figure 21-44).
