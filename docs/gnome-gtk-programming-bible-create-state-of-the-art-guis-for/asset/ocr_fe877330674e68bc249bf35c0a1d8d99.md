The following example program uses a GnomeLess widget to display its own source code, as shown in Figure 22-17.

```

static GtkWidget *makeWidget()
{
  GtkWidget *less;
  less = gnome_less_new();
  gnome_less_show_file(GNOME_LESS(less),"gnomeless.c");
  return(less);
}

```
