The microsecond value shows that time has progressed about 12.7 percent of the distance to the next second.

Unless you use a special, real-time version of Linux, the count of microseconds is only good for comparison. By using a `timval` struct to attach a time stamp to things, a quick comparison always indicates which came first (or, at least, which was time stamped first). There is a macro that you can use to compare two structs:

```
```c

    printf("tv1 is less than tv2\n");
} else
    printf("tv1 is not less than tv2\n");

if(timercmp(tv1,tv2,>)) {
    printf("tv1 is greater than tv2\n");
