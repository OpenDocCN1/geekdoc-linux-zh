# GtkImage

The GtkImage widget contains and displays a GdkImage.

```

The following example creates a GdkImage object and creates a GtkImage widget to display it. Because the default GdkImage is all black, the x and y loop draws a white corner-to-corner X resulting in the display in Figure 21-29.

```
```c
static GtkWidget *makeWidget()
{
int x;
int y;
GtkWidget *widget;
GdkVisual *visual;
GdkImage *gdkImage;

visual = gdk_visual_get_system();
gdkImage = gdk_image_new(GDK_IMAGE_NORMAL, visual,100,100);

for(x=0; x<100; x++) {
y = x;
gdk_image_put_pixel(gdkImage,x,y,0xFFFFFF);
y = 100 - x;
gdk_image_put_pixel(gdkImage,x,y,0xFFFFFF);
}

widget = gtk_image_new(gdkImage,NULL);
return(widget);
}
