# The Paned Container

The *paned container* holds two widgets, either side by side or one above the other, and displays them with a divider between them. The mouse can be used to move the divider back and forth to resize each of the contained widgets. The divider bar is called the *gutter*. The button on the gutter that is used to drag it back and forth is called the *handle*.

The following example demonstrates a horizontal paned container with a text widget on each side, as shown in Figure 5-13. The text widgets each contain a single line of text that is automatically wrapped to fill the widget—the automatic wrapping is indicated by the circular arrows at the end of each line. Using the mouse to drag the handle moves the gutter and resizes both widgets, as shown in Figure 5-14.
