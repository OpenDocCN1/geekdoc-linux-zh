# 隐藏和显示菜单项

菜单由静态定义的 `GnomeUIInfo` 结构体数组定义，这阻止了你的程序动态插入和删除菜单项。隐藏的菜单项不会显示，而菜单的其余部分看起来就像该隐藏项不在数组中一样。因此，要修改菜单，你只需隐藏和显示各个菜单项即可。

以下示例创建一个包含三个按钮的菜单。顶部按钮使中间按钮从菜单中消失，底部按钮使中间按钮重新出现。
