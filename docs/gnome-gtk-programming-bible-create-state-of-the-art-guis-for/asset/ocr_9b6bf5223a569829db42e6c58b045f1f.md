# GdkEventExpose

The internal utilities that copy a rectangle of pixels from a window—to another location on the same window or to another drawable—issues this event if the source is unavailable because it currently is not visible. It could be obscured by another window or it could simply be scrolled completely or partially out of view. If the source of the copy is available, a GdkEventNoExpose is sent instead.
