# # The Standard GNOME Menu Layout

Using a standard menu organization has some advantages. Because the layout is familiar, users that are new to your application can find what they need quickly — and experienced users don't have to recall multiple menu layouts. Much of the standard layout has evolved over time. We all have come to expect to find the File menu on the left, and the Edit menu next to it. Also, we expect Save and Exit to be in the File menu. Additionally, we expect to find the Help menu on the right, and an About popup window in the Help menu.

It would be a very rare application that needed all of the standard menu selections, just as it would be rare to have an application that would not need to add menu selections of its own. However, starting with the standard layout should simplify the task of overall menu organization.
