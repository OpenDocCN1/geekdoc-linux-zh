# Adding Widgets to a Canvas

Any widget can be placed on a canvas. In this way, you can use a canvas to configure the layout of a window but the generalized containers (as described in Chapter 5) do not have the flexibility to lay things out the way you would like them. Another advantage is the ability to mix graphic objects in among the widgets. The disadvantage of using canvas as a container is that your program is responsible for the exact placement and size of everything.
