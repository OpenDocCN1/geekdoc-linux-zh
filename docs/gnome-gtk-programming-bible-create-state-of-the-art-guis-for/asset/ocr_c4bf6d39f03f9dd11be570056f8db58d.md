Remembering the correct order of the positioning parameters can be a problem. In the middle of positioning a bunch of widgets, you can find yourself in a which-numbers-where quandary. If you get some of them in the wrong place, the resulting display can be very confusing. In fact, just a couple of misplaced numbers can cause the display to look so different, you may be inclined to start all over. I find it handy to sketch a little diagram, on a notepad or something, that looks like this:

![](bbox=[0.14, 0.75, 0.29, 0.78])

Each arrow points in the direction of the attachment. The first number specifies the grid line on the left; the second number specifies the grid line on the right, then the top, and finally the bottom.
