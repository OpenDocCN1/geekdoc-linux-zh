
These text items act just like any other item on a canvas. All three are connected to the callback function `dragEvent()` on lines 43, 53, and 66. ## Grouping Items in a Canvas

When a canvas is created, there is also a canvas group created, which is responsible for handling the various items that are placed on display. Because a canvas group is also an item, it is possible to insert one canvas group into another. This enables you to manipulate an entire group just as you would any other single item. The following program creates a subgroup containing four ellipses.

```c
/** grouping.c **/
#include <gnome.h>

gint eventDelete(GtkWidget *widget,
        GdkEvent *event, gpointer data);

gint eventDestroy(GtkWidget *widget,
        GdkEvent *event, gpointer data);

static gint dragEvent(GnomeCanvasItem *item,
        GdkEvent *event, gpointer data);

#define HORIZ 50
#define VERT 50
#define WIDTH (HORIZ * 6)
#define HEIGHT (VERT * 6)

int main(int argc, char *argv[]) {
    int i;
    GtkWidget *app;
    GtkWidget *canvas;
    GnomeCanvasGroup *rootGroup;
    GnomeCanvasItem *item;
    GnomeCanvasItem *innerGroup;

    gnome_init("grouping", "1.0", argc, argv);
    app = gnome_app_new("grouping",
            "Canvas Grouping");

    g_signal_connect(GTK_OBJECT(app), "delete_event",
            GTK_SIGNAL_FUNC(eventDelete), NULL);
    g_signal_connect(GTK_OBJECT(app), "destroy",
            GTK_SIGNAL_FUNC(eventDestroy), NULL);

    canvas = gnome_canvas_new();
    gtk_widget_set_usize(canvas, WIDTH, HEIGHT);
    gnome_canvas_set_scroll_region(GNOME_CANVAS(canvas),
            0.0, 0.0, WIDTH, HEIGHT);
    rootGroup = gnome_canvas_root(GNOME_CANVAS(canvas));
    gnome_app_set_contents(GNOME_APP(app), canvas);

    innerGroup = gnome_canvas_item_new(rootGroup,
            gnome_canvas_group_get_type(),
            "x", (double)(HORIZ),
            "y", (double)(VERT),
            NULL);
    g_signal_connect(GTK_OBJECT(innerGroup), "event",
            (GtkSignalFunc)dragEvent, NULL);

    for(i = 0; i < 4; i++) {
        item = gnome_canvas_item_new(
                GNOME_CANVAS_GROUP(innerGroup),
                gnome_canvas_ellipse_get_type(),
                "x1", (double)(0),
                "y1", (double)(VERT * i),
                "x2", (double)(HORIZ),
                "y2", (double)(VERT * (i + 1)),
                "fill_color", "white",
                "outline_color", "black",
                NULL);
        if(i == 2)
            g_signal_connect(GTK_OBJECT(item), "event",
                    (GtkSignalFunc)dragEvent, NULL);
    }

    item = gnome_canvas_item_new(rootGroup,
            gnome_canvas_ellipse_get_type(),
            "x1", (double)(HORIZ * 3),
            "y1", (double)(VERT * 2),
            "x2", (double)(HORIZ * 5),
            "y2", (double)(VERT * 4),
            "fill_color", "green",
            "outline_color", "white",
            NULL);
    g_signal_connect(GTK_OBJECT(item), "event",
            (GtkSignalFunc)dragEvent, NULL);

    gtk_widget_show_all(app);
    gtk_main();
    exit(0);
}

static gint dragEvent(GnomeCanvasItem *item,
        GdkEvent *event, gpointer data) {
    static gint x;
    static gint y;
    gint new_x;
    gint new_y;

    switch(event->type) {
    case GDK_MOTION_NOTIFY:
        if(event->button.state & 0x00000100) {
            new_x = event->button.x;
            new_y = event->button.y;
            gnome_canvas_item_move(item,
                    (double)(new_x - x),
                    (double)(new_y - y));
            x = new_x;
            y = new_y;
        }
        break;
    case GDK_BUTTON_PRESS:
        if(event->button.button == 1)
            gnome_canvas_item_raise_to_top(item);
        x = event->button.x;
        y = event->button.y;
        break;
    default:
        break;
    }
    return(0);
}

gint eventDelete(GtkWidget *widget,
        GdkEvent *event, gpointer data) {
    return(FALSE);
}

gint eventDestroy(GtkWidget *widget,
        GdkEvent *event, gpointer data) {
    gtk_main_quit();
    return(0);
}
```

The canvas is created and a pointer to its root group is retrieved on lines 33 through 38.

Another group —the one that will be added to the main group—is created by the call to `gnome_canvas_item_new()` on line 40. The inner group is simply laid right over the root group, but it makes no visual difference because they are both completely transparent on the display and to the mouse. The x and y values supplied to it are the coordinates of the upper-left corner of the inner group. The coordinate settings are a matter of convenience for programming because a group item has no boundaries—the defining coordinates simply specify the origin from which all distances are measured. In this example, the coordinates (the values of x and y) are (50,50) so attaching something to the point (0,0) on the inner group places it at (50,50) on the root group.

Four circles (created from four ellipses with the same height and width) are added to the inner group in the loop beginning on line 48. All of the circles are the same except for their locations in the inner group. The item defined on line 64 is a larger circle on the right, as shown in Figure 9-8, and is attached to the root group.

![](img/8bcc1ba72831c7d67cfc8b395deab95f_306_0.png)

The callback function `dragEvent()`, beginning on line 80, enables the mouse to be used to drag an item from one place to another. The callback function is connected to the inner group on line 45. It also is connected to the third circle of the inner group on lines 59 through 61. The callback function is connected to the larger circle on line 73.

You can drag the larger circle to any position, just as you saw in previous examples. By dragging any one of them (except the third one), you drag the group of circles to a new position. The third circle in the inner group can be moved on its own because it has its own callback. The inner group also has a callback, but it is transparent to the mouse, so the only time the callback is executed occurs when the mouse pointer is inside one of the objects attached to the inner group. When any circle (except the third one) is dragged, every circle (including the third one) is dragged along with it. The circles can be repositioned to look like Figure 9-9.

Briefly, if there is an item that does not have a callback function, the mouse event is passed on to the group containing the object. When a group is moved, all of the items attached to the group move with it. If an item has its own callback function, no events from it are passed on to its group object.

![](img/8bcc1ba72831c7d67cfc8b395deab95f_307_0.png)

Figure 9-9: Callbacks allow for both individual and group access

## Adding Widgets to a Canvas

Any widget can be placed on a canvas. In this way, you can use a canvas to configure the layout of a window but the generalized containers (as described in Chapter 5) do not have the flexibility to lay things out the way you would like them. Another advantage is the ability to mix graphic objects in among the widgets. The disadvantage of using canvas as a container is that your program is responsible for the exact placement and size of everything.

The following program creates three-button widgets and uses the canvas to position and size them.

```c
/** canvaswidget.c **/
#include <gnome.h>

gint eventDelete(GtkWidget *widget,
        GdkEvent *event, gpointer data);
gint eventDestroy(GtkWidget *widget,
        GdkEvent *event, gpointer data);

#define HORIZ 50
#define VERT 30
#define WIDTH (HORIZ * 5)
#define HEIGHT (VERT * 5)

int main(int argc, char *argv[])
{
    GtkWidget *app;
    GtkWidget *canvas;
    GtkWidget *button;
    GnomeCanvasGroup *rootGroup;
    GnomeCanvasItem *item;

    gnome_init("canvaswidget", "1.0", argc, argv);
    app = gnome_app_new("canvaswidget",
            "Gnome Canvas Widget");
    g_signal_connect(GTK_OBJECT(app), "delete_event",
            GTK_SIGNAL_FUNC(eventDelete), NULL);
    g_signal_connect(GTK_OBJECT(app), "destroy",
            GTK_SIGNAL_FUNC(eventDestroy), NULL);

    canvas = gnome_canvas_new();
    gtk_widget_set_usize(canvas, WIDTH, HEIGHT);
    gnome_canvas_set_scroll_region(GNOME_CANVAS(canvas),
            0.0, 0.0, WIDTH, HEIGHT);
    rootGroup = gnome_canvas_root(GNOME_CANVAS(canvas));
    gnome_app_set_contents(GNOME_APP(app), canvas);

    button = gtk_button_new_with_label("Button 1");
    item = gnome_canvas_item_new(rootGroup,
            gnome_canvas_widget_get_type(),
            "widget", button,
            "x", (double)(HORIZ),
            "y", (double)(VERT),
            "width", (double)(HORIZ),
            "height", (double)(VERT),
            "anchor", GTK_ANCHOR_NW,
            NULL);

    button = gtk_button_new_with_label("Button 2");
    item = gnome_canvas_item_new(rootGroup,
            gnome_canvas_widget_get_type(),

    button = gtk_button_new_with_label("Button Three");

    gtk_widget_show_all(app);
```
