# # Creating a Toolbar

The following example creates and displays a toolbar. The technique for creating a toolbar is basically the same as creating a menu. An array of GNOMEUIInfo structures are all filled with the information required for each toolbar button and a function is called to create the toolbar and attach it to the window. A toolbar acts like a menu in that it displays itself as a list of mouse-sensitive rectangles and waits for a mouse click to execute a callback function.
