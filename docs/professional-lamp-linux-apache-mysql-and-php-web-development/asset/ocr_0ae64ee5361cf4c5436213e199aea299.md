The `user` table contains a list of every user in the system, as well as any global privileges that user might have. The key fields related to access privileges are all the columns that have the suffix `_priv`. Note that all privilege columns have a default value of `no`.

The `db` table holds records for any access permissions at the database-level. The structure for `db` looks like this:

| Field | Type |
|---|---|
| Host | varchar(60) |
| Db | varchar(64) |
| User | varchar(16) |
