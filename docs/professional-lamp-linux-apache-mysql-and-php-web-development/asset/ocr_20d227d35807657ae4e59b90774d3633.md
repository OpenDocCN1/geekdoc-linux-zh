If you wanted to obliterate `testuser3` from the system, you would send the following:

```
REVOKE ALL PRIVILEGES, GRANT OPTION FROM testuser3@localhost;
```

# Alternatives to GRANT and REVOKE

If, for some reason, you don’t feel like using the GRANT or REVOKE commands, you can manually create the users and apply the privileges directly to the MySQL access tables.

MySQL stores the different levels of user privileges in four main tables inside the built-in mysql database. Each of the four main access tables corresponds to the four different access levels.

At the global level, there is the user table, whose structure looks like this:
