# Working with the Intel® Math Kernel Library Cluster Software

```
-lmkl__lapack
-lmkl__intel_ip64 -lmkl__intel_thread -lmkl_lapack -lmkl__core
-liomp5 -lpthread
```

To link Cluster FFT for a cluster of systems based on the IA-64 architecture, use the following libraries:

```
/opt/intel/mpi/3.0/bin/mpiifort user files to link>
$MKLPATH/lmkl__cdft_core.a
$MKLPATH/lmkl__blacs_intelmpi_ip64.a
$MKLPATH/lmkl__intel_ip64.a
$MKLPATH/lmkl__intel_thread.a
$MKLPATH/lmkl__core.a
-liomp5 -lpthread
```

A binary linked with ScalapACK runs in the same way as any other MPI application (refer to the documentation that comes with the MPI implementation). For instance, the script mpirun is used in the case of MPICH2 and OpenMPI, and a number of MPI processes is set by -np. In the case of MPICH 2.0 and all MPIIs, you should start the daemon before running an application; the execution is driven by the script mpiexec.

For further linking examples, see the Intel MKL support website at http://www.intel.com/software/products/support/.
