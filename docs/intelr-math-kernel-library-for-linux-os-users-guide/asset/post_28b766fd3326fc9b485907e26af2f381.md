## Using Additional Threading Control

Intel MKL has new optional threading controls, that is, the new environment variables and service functions. They behave similar to their OpenMP equivalents, but take precedence over them. By using these controls along OpenMP variables, you can thread the part of the application that does not call Intel MKL and the library independently from each other.

These controls enable you to specify the number of threads.

## Managing Performance and Memory

Intel MKL has new optional threading controls, that is, the new environment variables and service functions. They behave similar to their OpenMP equivalents, but take precedence over them. By using these controls along OpenMP variables, you can thread the part of the application that does not call Intel MKL and the library independently from each other.

| Environment Variable | Service Function | Equivalent OpenMP Variable |
| :--- | :--- | :--- |
| MKL_NUM_THREADS | mkl_set_num_threads | Suggests the number of threads |
| MKL_DOMAIN_THREADS | mkl_set_domain_num_threads | Enables the number of threads |
| MKL_DYNAMIC | mkl_set_dynamic | Suggests the number of threads |
