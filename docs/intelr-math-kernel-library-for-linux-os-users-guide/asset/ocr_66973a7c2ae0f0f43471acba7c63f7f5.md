# Getting Started

This chapter provides some basic usage information and describes post-installation steps to help you start using the Intel® Math Kernel Library (Intel® MKL) on Linux* OS.

# Before You Begin

Before you begin using Intel MKL, learning a few important concepts will help you get off to a good start, as shown in Table 2-1.

| Table 2-1 | What You Need to Know Before You Begin |
|--- |--- |
| Target platform | - IA-32 or compatible
- Intel® 64 or compatible
- IA-64 (Itanium® processor family) |


**Action:** Identify the architecture of your target machine:
**Reason:** Because Intel MKL libraries are located in directories corresponding to your particular architecture (see Architecture Support), you should provide proper paths on your link lines (see Linking Examples). To configure your development environment for the use with Intel MKL, set your environment variables using the script corresponding to your architecture (see Set Environment Variables for details).
