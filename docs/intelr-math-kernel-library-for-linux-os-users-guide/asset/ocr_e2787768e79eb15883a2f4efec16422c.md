# Intel® Math Kernel Library
Language Interfaces
Support

Table A-1 shows language interfaces that Intel® Math Kernel Library (Intel® MKL) provides for each domain, and Table A-2 lists the respective header files. Intel MKL routines can be called from other languages using mixed-language programming. For example, see Mixed-language Programming with Intel® MKL on how to call Fortran routines from C/C++.
