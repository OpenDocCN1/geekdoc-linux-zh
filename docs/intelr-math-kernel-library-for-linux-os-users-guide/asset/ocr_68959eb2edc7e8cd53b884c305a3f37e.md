# CBLAS

Instead of calling BLAS routines from a C-language program, you can use the CBLAS interface.

BLAS is a C-style interface to the BLAS routines. You can call CBLAS routines using regular C-style calls. When using the CBLAS interface, the header file mkl.h will simplify the program development because it features enumerated values as well as prototypes of all the functions. The header determines if the program is compiled with a C++ compiler, and if it is, the included file will be correct for use with C++ compilation.

# Using Complex Types in C/C++

As described in the Building Applications document for the Intel® Fortran Compiler, C/C++ does not directly implement the Fortran types COMPLEX(4) and COMPLEX(8). However, you can write equivalent structures. The type COMPLEX(4) consists of two 4-byte floating-point numbers. The first of them is the real-number, and the second is the imaginary-number component. The type COMPLEX(8) is similar to COMPLEX(4) except that it contains two 8-byte floating-point numbers.

Intel MK provides complex types MKL_Complex8 and MKL_Complex16, which are structures equivalent to the Fortran types COMPLEX(4) and COMPLEX(8), respectively. These types are defined in the mkl_types.h header file. You can also define the types with your own types before including the mkl_types.h header file. The only requirement is that the types must be compatible with the Fortran layout, as the complex type must be a pair of real numbers and imaginary parts.

For example, you can use the following definitions in your C++ code:

```
#define MKL_Complex8 std::complex<float>

\define MKL_Complex16 std::complex<double>
```

See Example 7-2 for details. You can also define these types in the command line:
-DMKL_Complex8="std::complex<float>"
-DMKL_Complex16="std::complex<double>"
