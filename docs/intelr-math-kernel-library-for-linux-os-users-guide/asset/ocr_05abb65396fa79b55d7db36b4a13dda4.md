# Using Context-Sensitive Help in the Eclipse* IDE CDT

You can view context-sensitive help in the Eclipse CDT editor by Infopop windows and F1 Help.

# Infopop Window

Infopop window is a popup description of a C function.

> NOTE. In the current release this feature is provided only for VML functions.

To obtain the description of an Intel MKL function whose name is typed in the editor, place the mouse pointer over the function name.
