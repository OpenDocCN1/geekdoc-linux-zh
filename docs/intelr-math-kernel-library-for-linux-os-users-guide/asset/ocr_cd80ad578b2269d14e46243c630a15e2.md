# 11 Intel® Math Kernel Library User's Guide

Table 11-1 Contents of the LINPACK Benchmark

| ./benchmarks/linpack/ |
|---|---|
| linpack_itanium | The 64-bit program executable for a system based on Intel® Itanium 2 processor. |
| linpack_xe32 | The 32-bit program executable for a system based on Intel® Xeon® processor or Intel® Xeon processor MP with or without Streaming SIMD Extensions 3 (SSE3). |
| linpack_xeon64 | The 64-bit program executable for a system with Intel® Xeon® processor using Intel® 64 architecture. |
| run_itanium | A sample shell script for executing a pre-determined problem set for linpack_itanium. OMP_NUM_THREADS set to 8 processors. |
| run_xeon32 | A sample shell script for executing a pre-determined problem set for linpack_xeon32. OMP_NUM_THREADS set to 2 processors. |
| run_xeon64 | A sample shell script for executing a pre-determined problem set for linpack_xeon64. OMP_NUM_THREADS set to 4 processors. |
| lininput_itanium | Input file for pre-determined problem for the run_itanium script. |
| lininput_xeon32 | Input file for pre-determined problem for the run_xeon32 script. |
| lininput_xeon64 | Input file for pre-determined problem for the run_xeon64 script. |
| lin_itanium.txt | Result of the run_itanium script execution. |
| lin_xeon32.txt | Result of the run_xeon32 script execution. |
| lin_xeon64.txt | Result of the run_xeon64 script execution. |
| help.lpk | Simple help file. |
| xhelp.lpk | Extended help file. |

# Running the Software

To obtain results for the pre-determined sample size on a given system, type one of the following, as appropriate:

+   . /runme_itanium
. /runme_xeon32
. /runme_xeon64
