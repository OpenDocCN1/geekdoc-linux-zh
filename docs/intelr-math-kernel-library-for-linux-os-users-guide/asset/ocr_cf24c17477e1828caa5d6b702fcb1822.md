# 3 Intel® Math Kernel User's Guide

# Compiling for LP64/ILP64

Table 3-2 shows how to compile for the ILP64 and LP64 interfaces:

# Table 3-2 Compiling for the ILP64 and LP64 Interfaces

# Fortran

```
Compiling for LP64
ifort -i8 -I<mkl directory>/include ...
```

```
Compiling for LP64
ifort -I<mkl directory>/include ...
```

# C or C++

```
Compiling for LP64
icc -DMKL_ILP64 -I<mkl directory>/include ...
```

```
Compiling for LP64
icc -I<mkl directory>/include ...
```

> NOTE. Linking of the application compiled with the i8 or -DMKL_ILP64 option to the LP64 libraries may result in unpredictable consequences and erroneous output.

# Coding for ILP64

You do not need to change existing code if you are not using the ILP64 interface.
To migrate to LP64 or write new code for LP64, use appropriate types of KIND parameters for the Intel MKL functions and subroutines (see Table 3-3):

# Table 3-3 Integer Types

| 32-bit integers | Fortran | C or C++ |
|---|---|-|
| | INTEGER*4 or INTEGER(KIND=4) | int |
| Universal integers for LP64/LP64: | INTEGER without specifying KIND | MKL_INT |
| - 64-bit for LP64 | | |
| - 32-bit otherwise | | |
| Universal integers for LP64/LP64: | INTEGER*8 or INTEGER(KIND=8) | MKL_INT64 |
| - 64-bit integers | | |
| FFT interface integers for LP64/LP64 | INTEGER without specifying KIND | MKL_LONG |
