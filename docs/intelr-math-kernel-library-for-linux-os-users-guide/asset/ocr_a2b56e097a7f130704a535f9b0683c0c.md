# Setting the Number of Threads

The OpenMP* software responds to the environmental variable OMP_NUM_THREADS. Intel MKL also has other mechanisms to set the number of threads, such as MKL_NUM_THREADS or MKL_DOMAIN_NUM_THREADS (Using Additional Threading Control). Make sure that the relevant variables have the same and correct values on all the nodes. The Intel MKL versions 10.0 and higher no longer set the default number of threads to one, but depend on the OpenMP libraries used with the compiler to set the default number.
