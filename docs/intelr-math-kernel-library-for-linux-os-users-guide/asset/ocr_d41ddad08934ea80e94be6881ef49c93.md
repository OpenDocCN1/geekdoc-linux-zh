Some functions that support only a Fortran interface (see Table A-1), provide header files for C/C++ in the include directory. Such *.h files enable using a Fortran binary interface from C/C++ code. These files can also be used to understand the ILP64 usage.

# Limitations

All Intel MKL function domains support ILP64 programming with the following exceptions:

+   * FFTW 2.x wrappers do not support ILP64.
* FFTW 3.2 wrappers support ILP64 by a dedicated set of functions plan_guru64.
* GMP* arithmetic functions do not support ILP64.
