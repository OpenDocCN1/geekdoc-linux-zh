# # Support for ILP4 Programming

The Intel MKL ILP4 libraries use the 64-bit integer type (necessary for indexing huge arrays, with more than $2^{31}$-1 elements), whereas the LP64 index arrays with the 32-bit integer type.

The LP64 and ILP4 interfaces are supported in the Interface layer (see Layered Model Concept and Directory Structure in Detail for more information).

The ILP4 interface is provided for the following two reasons:

+   - To support huge data arrays (with than $2^{31}$-1 elements)
- To enable compiling your Fortran code with the -i8 compiler option

It is up to you to choose which interface to use. Choose the LP64 interface for compatibility with the previous Intel MKL versions because “LP64” is just a new name for the only interface that the Intel MKL versions lower than 9.1 provided. Choose the ILP4 interface if your application uses Intel MKL for calculations with huge data arrays or the library may be used in future.

Intel MKL provides the same include directory for the ILP4 and LP64 interfaces.
