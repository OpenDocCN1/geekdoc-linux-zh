# Searching the Intel Web Site from the Eclipse* IDE

The Intel MKL plugin tunes Eclipse Help search to target http://www.intel.com so that when you run a search from the Eclipse Help pane, the search hits at site are shown through a separate link. Figure 10-2 shows results for "VML Functions" in Eclipse Help. In the figure, 1 hit means an entry hit to the respective site. Click "Intel.com (1 hit)" to open the list of actual hits to the Intel Web site.
