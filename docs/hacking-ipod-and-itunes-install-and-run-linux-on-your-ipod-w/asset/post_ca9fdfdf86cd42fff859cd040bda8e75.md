
## Text encodings

Note Reader supports various text encodings. If the iPod is set to use Japanese, Korean, or Chinese, Note Reader assumes notes are in the matching encoding. Otherwise, Note Reader assumes Latin-1 encoding on FAT32-formatted iPods and MacRoman on HFS-formatted iPods. You can tell Note Reader to use a non-default encoding for a file by including a tag like this:

```
<?xml encoding="MacJapanese" ?>
```

Note Reader supports the following encodings:

- Latin-1
- MacRoman
- MacJapanese
- Korean
- Simplified Chinese
- Traditional Chinese
- UTF8 Unicode
- UTF16 Unicode

If you have a note with an encoding tag, put the tag at the top of the file.
