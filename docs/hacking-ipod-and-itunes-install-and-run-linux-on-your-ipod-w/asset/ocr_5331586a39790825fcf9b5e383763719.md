+   - Put This Into That copies one tag to another, which wipes out whatever was previously in the destination tag.

+   - Put This Before That and Put This After That copy information from one tag to another without deleting what was already in the destination tag.

This group of scripts is a more general version of Swap Track Name & Art ist. Swap This With That lets you trade information between any two tags. For example, if your tags for a CD mistakenly have the album name where the song name should be and vice versa, use Swap This With That to put things right.

Other scripts in this set give you more control over moving tag info. Put This In That copies one tag to another, which wipes out whatever was in the destination tag. To preserve what’s already in the tag instead of replacing it, use Put This Before That or Put This After That.
