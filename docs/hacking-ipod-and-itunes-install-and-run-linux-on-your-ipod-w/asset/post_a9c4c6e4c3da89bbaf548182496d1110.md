# About the Author

Scott Knaster has been writing and hacking since way back when music came on LP-ROMs. His books were required reading for Mac programmers for more than a decade. Scott’s most recent book was *Mac Toys* (with John Rizzo). Scott has every issue of *MAD* magazine, which explains a lot about his philosophy of life.
