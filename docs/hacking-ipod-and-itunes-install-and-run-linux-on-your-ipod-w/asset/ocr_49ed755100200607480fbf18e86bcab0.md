FIGURE 11-11: Make your own celebrity playlist.

Here’s how to create your own iMix and put it on the iTunes Music Store for everyone’s enjoyment:

+   1. Start with an existing playlist you already have in iTunes, or create a new one that holds the songs you want. You can use a conventional playlist or a smart playlist for this project.

+   2. Click the playlist to select its name in the iTunes source list.

+   3. You should see a right-pointing arrow next to the playlist name. Click that arrow. The first time you create an iMix, you’ll see a dialog box explaining a little about how it works.
