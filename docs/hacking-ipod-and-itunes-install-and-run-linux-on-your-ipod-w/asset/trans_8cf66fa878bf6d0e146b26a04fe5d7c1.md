# 作者简介

Scott Knaster 早在音乐通过 LP-ROM 播放的那个时代就开始写作和“魔改”了。他的书籍在过去十多年里一直是 Mac 程序员的必读读物。Scott 最近出版的书是《Mac Toys》（与 John Rizzo 合著）。Scott 收藏了《MAD》杂志的每期刊物，这充分解释了他的生活哲学。
