# Create Gapless Music CDs

When iTunes imports music from a CD, it rips each track separately and leaves a gap between them. As we learned in the section Merge Tracks from Live CDs in Chapter 8, you can eliminate the gap between songs by using the “join tracks” feature before ripping a CD.

What happens to the gaps between tracks when you want to burn a CD? Take a look in iTunes preferences, on the Burning tab.
