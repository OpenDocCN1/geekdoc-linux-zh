That's it. The disk will appear in the Finder, and you will be able to use it just like a Mac disk. To use Windows XP to format the disk:

+   1. Click **Start** in the task bar.
+   2. Right-click **My Computer** and choose **Manage** from the shortcut menu.
+   3. In the Computer Management window, click **Disk Management** on the left (see Figure 10-2).
+   4. In the list on the upper-right, click the volume you want to format.
+   5. Choose **Action ⇒ All Tasks ⇒ Format**.
+   6. Pick **FAT32** for the file system, then click **OK**. Click **OK** on the warning message that appears. Make sure you're erasing the right volume!
