

## iPod mini

- **关机**——长按播放键（*与普通 iPod 相同*）。
- **重置**——同时按住选择键和菜单键，直到看到 Apple 标志。
- **启用诊断模式**——重置 iPod。当看到 Apple 标志时，按住选择键和返回键。当 Apple 标志消失后，松开按键即可看到著名的反向 Apple 标志，并进入诊断模式。

iPod mini 的部分按键操作与普通型号略有不同，但功能结果是一致的。以下是 mini 型号上使用的按键：

**重置**——同时按住播放键和菜单键，直到看到 Apple 标志。这在重启似乎卡住的 iPod 时非常有用。

**启用磁盘模式**——重置 iPod。当看到 Apple 标志时，同时按住上一曲键和下一曲键，直到看到“可以断开连接”的屏幕。若要退出磁盘模式，请重置 iPod。

**执行磁盘扫描**——重置 iPod。当看到 Apple 标志时，同时按住菜单、下一曲、上一曲和选择键（*哇塞*）。这指示您的 iPod 扫描其硬盘的不良区域。您将看到一个放大镜图案在磁盘上移动，底部有一个进度条。扫描可能需要很长时间，尤其是对于较大的硬盘。如果您的 iPod 扫描失败，屏幕上会显示额外信息，您可能应该让您的 iPod 接受维修服务。

**进入诊断模式**——重置 iPod。当看到 Apple 标志时，按住下一曲、上一曲和选择键。当 Apple 标志消失后，松开按键。您将看到最酷的东西：一个反向的 Apple 标志，仿佛您正身处 iPod 内部向外看。如果是 3G 型号，您会听到 iPod 发出轻微的尖叫声，就像有人捏它一样。诊断模式包含工程师、技术人员和工厂人员用于测试 iPod 的工具。您可以在此章节的“运行 iPod 诊断”部分中找到更多相关信息。

### 运行 iPod 诊断

进入诊断模式后，您会看到一个丑陋、不像 iPod 风格的屏幕，上面列有八项诊断测试。每项测试都用字母 A 到 H 标记。您可能会预期使用转盘来选择测试，但它不起作用。相反，请使用下一曲键和上一曲键在列表中上下移动。按下选择键运行高亮的测试。当测试正在运行时，按下播放键返回菜单。如果您向下滚动超过测试 H（或向上滚动超过测试 A），您将看到第二屏幕，其中包含项目 I 到 P。

在 mini 型号上，没有可以启用磁盘模式或磁盘扫描的按键组合，但您可以通过诊断模式中的菜单访问这些功能。

表 3-1 iPod 诊断

| 测试字母及名称 | 描述 |
| :--- | :--- |
| A. 5 IN 1 | 这依次运行多项测试：LCM、RTC、SDRAM、FLASH/CHECKSUM 和 FIREWIRE/FW ID。（请参阅下文了解它们的作用。注意，您需要按两次播放键才能通过 LCM。）但真正酷的东西是在测试完成后。在 3G iPod 上，您可以按键让内置扬声器发出声音。按下一曲键可听到转盘的咔哒声，菜单键和选择键可听到两种不同的长哔声，下一曲键则可产生一种听起来有点像《星球大战》激光炮的效果。您可以拿着 iPod 四处走动，按键并盯着屏幕，仿佛在做某种严肃的事情，这会非常有趣。咔哒声可以作为一个很棒的假辐射探测器。按下播放键返回诊断菜单。 |
| B. RESET | 这会重置 iPod，就像同时按下菜单键和播放键一样，但对手指稍微友好一点。 |
| C. KEY | 这个测试实际上有点像视频游戏。您需要在约 5 秒内按下 iPod 上的所有五个按键。每按下一个，其名称就会显示在屏幕上。如果您在时间内按完所有按键，您会看到 KEY PASS。如果您太慢了，您会因 KEY FAIL 而羞愧。 |
| D. AUDIO | 在 3G iPod 上运行此测试时，如果您连接了外部扬声器，会听到类似《吃豆人》的鼓噪声。在较旧的 iPod 上，屏幕将显示 AUDIO 0X00000001 DONE。 |
| E. REMOTE | 这项测试 iPod 遥控器。这是另一个游戏：您有几秒钟的时间按下遥控器上的所有按键。每按下一个按键，屏幕上会出现一个矩形，其位置对应您按下的按键位置。如果您没有在时间内按完所有按键，或者没有连接遥控器，您将看到 RMT FAIL。 |
| F. FIREWIRE/FW ID | 此测试检查 iPod 的 FireWire 端口，确保其工作正常。如果正常，您会看到令人安心的 FW PASS 消息。 |
| G. SLEEP | 运行此测试时，您的 iPod 会进入睡眠状态。当您试图唤醒它时，您可能会看到低电量图标，并且 iPod 可能会拒绝恢复活动。如果发生这种情况，请尝试重置 iPod 或将其连接到电源。这应该会使其惊醒。 |
| H. A2D | 此项检查 iPod 的模数转换部件。测试列出了有时晦涩难懂的部件名称和结果，具体因 iPod 型号而异。 |
| I. OPTO CNT | 运行此测试以玩转盘。“OPTO”是工程术语，指代转盘——原本应该是“opto”，但拼写错误很有魅力，所以为什么要现在修正呢？当您运行此测试时，转动转盘，您会看到 iPod 通过改变屏幕上的大型十六进制数来做出反应。 |
| J. LCM | 这测试 iPod 的显示屏。LCM 可能代表“液晶显示器”（liquid crystal monitor）。运行测试后，按选择键可看到屏幕上的渐变图案。再次按选择键可以看到一个巨大的加号。这个加号指的是 iPod 对苹果利润所产生的积极影响。 |
| K. RTC/CHG STUS | 在较旧的 iPod 上，RTC 测试与 iPod 的实时时钟相关的某些内容，该时钟知晓一天中的时间。数值有时会有少许变化，但始终很小。这与本章中“可怕的时间”描述中的时钟“漂移”有关吗？我不知道。这是那些 iPod 谜团之一。在 3G iPod 上，此测试被 CHG STUS（充电状态）取代。CHG STUS 显示指示是否通过 USB、FireWire 或耳机端口连接了设备的值。它还似乎显示是否有可用的充电电力。 |
| L. SDRAM/USB DISK | SDRAM 测试 iPod 的同步动态随机存取存储器（SDRAM）。这是对抗跳音保护并延长电池寿命的神奇成分：音乐预加载到 RAM 中，磁盘驱动器随之降速。USB DISK 测试未知内容，并将 iPod 重启至磁盘模式。 |
| M. FLASH/CHK SUM | FLASH 测试在 3G iPod 上称为 CHK SUM（校验和），用于检查 iPod 的闪存 ROM。测试结束时显示一个十六进制数，可能是用于验证 ROM 的校验和。 |
| N. OPTO/CONTRAST | 在较旧的 iPod 上，OPTO 测试似乎根本不起任何作用。CONTRAST 允许您使用转盘微调屏幕对比度，但您所做的任何更改在退出诊断模式后都会消失。 |
| O. HDD SCAN | 此项运行硬盘测试，没有磁盘扫描时获得的那种酷动画，如 *使用按键组合* 部分所述。扫描磁盘需要好几分钟。扫描完成后，您会看到 HDD PASS 或 HDD FAIL。HDD 意为“硬盘驱动器”。“FAIL” 意为“去修好吧”。 |
| P. RUN IN | 最后这项测试循环运行一系列测试，直到您按住 *播放* 键为止。它似乎设计用于确保 iPod 在制造或维修后准备就绪。 |

### 聆听 iPod 扬声器发出的声音

拿起您的 iPod 仔细看看。看到扬声器了吗？不，当然您看不到。扬声器隐藏得很好，显然靠近 FireWire 或底座连接器，因为声音似乎就是从那里发出的。iPod 不通过其内部扬声器播放音乐。它仅限于在通常职责中需要发出的咔哒声、爆裂声和其他小工具类噪音。即使您连接了耳机或外部扬声器，这些声音也是从内部扬声器发出的。纯属娱乐，以下是您将从 iPod 扬声器听到的标准声音列表：

- *咔哒声*——当您移动转盘时，您会听到咔哒声。您可以通过转到 设置 \| 点击音 来关闭此功能。
- *更多咔哒声*——按下按键也会产生来自内置扬声器的咔哒声。如果您已关闭 设置 \| 点击音，这也不会发出声音。
- *嗡嗡声*——当您将 3G iPod 或 mini 插入底座时，您肯定注意到了指示其已连接的电子嗡嗡声。
- *哔哔声*——如果您开启了 iPod 的闹钟功能，且没有连接外部扬声器或耳机（不太可能戴着耳机睡觉），
