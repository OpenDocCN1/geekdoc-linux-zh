# 引言

欢迎阅读《Red Hat Linux 参考指南》。

《Red Hat Linux 参考指南》包含了关于 Red Hat Linux 系统的有用信息。从 Red Hat Linux 系统的结构基础概念，到系统安全与认证的细微之处，我们希望这本书对您来说是一个有价值的资源。

本指南适用于想要进一步了解 Red Hat Linux 系统如何工作的读者。您可以在此探索的主题包括：

- 文件系统结构
- 启动过程
- X Window 系统
- 安全工具
- 网络服务
