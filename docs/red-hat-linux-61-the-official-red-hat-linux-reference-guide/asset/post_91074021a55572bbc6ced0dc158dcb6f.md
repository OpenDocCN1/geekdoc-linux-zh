# Introduction

Welcome to the Red Hat Linux Reference Guide.

The Red Hat Linux Reference Guide contains useful information about the Red Hat Linux system. From fundamental concepts, as the structure of the Red Hat Linux system, to the finer points of system security and authentication, we hope you find this book to be a valuable resource.

This guide is for you want to learn a bit more about how the Red Hat Linux system works. Topics that you can explore within this include:

- The file system structure
- The boot process
- The X Window System
- Security tools
- Network services
