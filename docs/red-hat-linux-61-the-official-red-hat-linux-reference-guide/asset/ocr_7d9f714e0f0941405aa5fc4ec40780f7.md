# Chapter 2. Boot Loaders

# 2.5. GRUB Interfaces

GRUB features three interfaces, which provide different levels of functionality. Each of these interfaces allows users to boot the linux kernel or other operating systems.

The interfaces are as follows:

# Menu Interface

If GRUB was automatically configured by the Red Hat Linux installation program, this is the interface shown by default. A menu of operating systems or kernels preconfigured with their own boot commands are displayed as a list, ordered by name. Use the arrow keys to select an option other than the default and press the [Enter] to boot it. Alternatively, a timeout period is set, so GRUB will start the default option.

Press the [e] to enter the entry interface or the [c] to load a command line interface.

See Section 2.7 GRUB Menu Configuration File for more information on configuring this interface.

# Menu Entry Interface

To access the menu entry editor, press the [e] from the boot loader menu. The GRUB commands for entry are displayed here, and you may alter these commands before booting the operating system by adding a command line ([l] inserts a new line after the current line and [O] inserts a new line before it), editing it (e), or deleting it ([d]).

After all changes, the [b] executes the commands and boots the operating system. The [Esc] discards any changes and reloads the standard interface. The [c] key loads the command interface.

> Tip For changing runlevels with GRUB using the menu entry editor, refer to Section 2.10 Changing Runlevels at Boot Time.

# Command Line Interface

The command line is the most basic of the GRUB interfaces, but it is also the one that grants the most control. The command line makes it possible to type any relevant GRUB commands followed by [Enter] to execute them. This interface features some advanced shell-like features, including [Tab] key combination, based on context, and [Ctrl] key when typing commands, as [Ctrl]-a to move to the beginning of a line, and [Ctrl]-e to move to the end of a line. Addition the arrow, [Home], [End], and [Delete] keys work as you do in the *bash* shell.

See Section 2.6 GRUB Commands, for a list of common commands.

# 2.5.1. Order of the Interfaces

GRUB loads its secondary boot loader, it first searches for its configuration file. Once found, it builds a menu list and displays the menu interface.

If the configuration file cannot be found, or if the configuration is unreadable, GRUB loads the command line interface, allowing the user to type commands to complete the boot process.

If the configuration file is not valid, GRUB prints out the error and asks for input. This helps the user see precisely where the problem is occurring. Pressing any key reloads the menu option and correct the problem based on the error reported by GRUB. If the correction fails, GRUB reports an error and reloads the menu interface.
