# 4.1.26./etc/sysconfig/radvd

The /etc/sysconfig/radvd file is used to pass arguments to the radvd daemon at boot. The radvd daemon listens for router requests and sends router advertisements for the IP version6 protocol. This allows you to dynamically change your routers based on these router advertisements. For more information about what parameters are available for this file, see the radvd page. By default, the file sets the owner of the radvd process to the user radvd.

# 4.1.27./etc/sysconfig/raddevices

The /etc/sysconfig/raddevices file is used to configure raw device bindings, such as:
/dev/raw/raw1 /dev/sdal
/dev/raw/raw2 8 5

# 4.1.28./etc/sysconfig/redhat-config-securitylevel

The /etc/sysconfig/redhat-config-securitylevel file contains all options chosen by the user the last time the Security Level Configuration Tool (redhat-config-securitylevel) was run. Users should not modify this file by hand. For more information about Security Configuration Tool, see the chapter titled Firewall Configuration in the Red Linux Customization Guide.

# 4.1.29./etc/sysconfig/redhat-config-users

The /etc/sysconfig/redhat-config-users file is the configuration file for the graphical application, User Manager. Under Red Linux this file is used to filter system users such as root, daemon, or ip. This file is edited by the Preferences => Filter users and groups pull-down menu in the User Manager application and should not be edited by hand. For more information on using this application, see the chapter called User and Group Configuration in the Red Linux Customization Guide.

# 4.1.30./etc/sysconfig/redhat-logviewer

The /etc/sysconfig/redhat-logviewer file is the configuration file for the graphical, interactive log viewing application. Log Viewer. This file is edited by the Edit => Preferences pull-down menu in the Log Viewer application and should not be edited by hand. For more information on using this application, see the chapter called Log Files in the Red Linux Customization Guide.
