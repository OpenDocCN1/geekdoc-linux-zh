# 5.3.1. /proc/self/

The /proc/self/ directory is a link to the currently running process. This allows a process to look at itself without having to know its process ID.

Within a shell environment, a listing of the /proc/self/ produces the same contents as listing the directory for that process.

# 5.3.2. /proc/bus/
