# 5.2.18. /proc/mdstat

This file contains the current information for multiple-disk, RAID configurations. If your system does not contain such a configuration, /proc/mdstat will look similar to this:

```
Personalities : set
read_ahead not set
unused devices: <none>
```

This file remains in the same state as unless a software RAID or md device is present. In this case, /proc/mdstat to view the current status of mdX RAID devices.

The /proc/mdstat file shows a system with md0 configured as a RAID1 device, while it is currently re-syncing the devices:

```
Personalities : [linear] [raid1]
read_ahead 1024 sectors\md0: active raid1 sda2[1] sdb2[0] 9940 blocks [2/2] [UU] resync=1% finish=12.3algorithm2 [3/3] [UU]
unused devices: <none>
```
