# II. Network Services Reference

It is possible to deploy a wide variety of network services under Red Hat Linux. This part describes how network interfaces are configured as well as provides details about critical network services such as NFS, Apache HTTP Server, Sendmail, Fetchmail, Procmail, BIND, and LDAP.
