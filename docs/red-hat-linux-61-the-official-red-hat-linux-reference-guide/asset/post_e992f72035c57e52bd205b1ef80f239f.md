## 4.18. /etc/sysconfig/keyboard

The /etc/sysconfig/keyboard controls the behavior of the keyboard. The following values may be used:

- KEYBOARDTYPE=sun|pc, which is used on SPARCs only. sun means a Sun keyboard is attached on /dev/kbd, and pc means a PS/2 keyboard connected to a PS/2 port.
- KEYTABLE=<file>, where <file> is the name of a keytable file.

For example: KEYTABLE="us". The files can be used as keytables start in /lib/kbd/keymaps/i386 and branch into different keyboard layouts from there, all labeled <file>.kmap.gz. The first file found beneath /lib/kbd/keymaps/i386 matches the KEYTABLE setting is used.

## 4.19. /etc/sysconfig/kudzu

The /etc/sysconfig/kudzu file triggers a safe probe of the system hardware by kudzu at boot time. A safe probe is one that disables serial port.

- SAFE=<value>, where <value> is one of the:
  - yes — kudzu does a safe probe.
  - no — kudzu does a normal probe.

## 4.1.20. /etc/sysconfig/mouse

The /etc/sysconfig/mouse file is used to specify information about the available mouse. The following values may be used:

- FULLNAME=<value>, where <value> refers to the full name of kind of mouse being used.
- MOUSETYPE=<value>, where <value> is one of the following:
  - imps2 — A generic USB mouse.
  - microsoft — A Microsoft™ mouse.
  - mouseman — A MouseMan™ mouse.
  - mysystems — A Mouse Systems™ mouse.
  - ps/2 — A PS/2 mouse.
  - msbm — A Microsoft™ bus mouse.
  - logibm — A Logitech™ bus mouse.
  - atbim — An ATim bus mouse.
  - logitech — A Logitech™ mouse.
  - mmseries — An older MouseMan™ mouse.
  - mmittab — An mhmittab mouse.

- XEM3=<value>, where <value> is one of the following boolean values:
  - yes — The mouse has two buttons, but three buttons must be enabled.
  - no — The mouse has three buttons.

- XMOUSETYPE=<value>, where <value> refers to the kind of mouse used when X is running. The options are the same as the MOUSETYPE setting in this file.
- DEVICE=<value>, where <value> is the mouse device.
In addition, /dev/mouse is a symbolic link to the actual mouse device.

/etc/sysconfig/named
The /etc/sysconfig/named file is used to pass arguments to the named daemon at boot time. The named daemon is a Domain Name System (DNS) server which implements the Berkeley Internet Domain Name (BIND) version 9. This server maintains a table of which hostnames are associated with IP addresses on the network.
Currently, the following values may be used:

- ROOTDIR="<some/where>", where <some/where> refers to the full directory path of a configured environment which named runs. The chroot info must be configured.
- OPTIONS="<value>", where <value> is any option in the man page for named except -t. In place of -t, use the ROOTDIR line above.

For more information about what parameters are available for this file, the named man page. For detailed information on how to configure a BIND DNS server, see Chapter 12 Berkeley Internet Name Domain (BIND). By default, the file contains no parameters.

## 4.1.22. /etc/sysconfig/netdump

The /etc/sysconfig/netdump file is the configuration file for the /etc/init.d/netdump.

## 4.1.23. /etc/sysconfig/network

The /etc/sysconfig/network file is used to specify network configuration. The following values may be used:

- NETWORKING=<value>, where <value> is one of the following:
  - yes — Networking should be configured.
  - no — Networking should not be configured.
- HOSTNAME=<value>, where <value> is the hostname.
- GATEWAY=<value>, where <value> is the gateway address.
- IPADDR=<value>, where <value> is the IP address.
- NETMASK=<value>, where <value> is the net mask.
- DNS=<value>, where <value> is the DNS server address.

## 4.1.24. /etc/sysconfig/ntpd

The /etc/sysconfig/ntpd file is used to pass arguments to the ntpd daemon at boot time. The ntpd daemon is used to synchronize the system clock with NTP servers. The following values may be used:

- SERVER=<value>, where <value> is the address of the NTP server.
- OPTIONS=<value>, where <value> is any option in the man page for ntpd.

## 4.1.25. /etc/sysconfig/pcmcia

The /etc/sysconfig/pcmcia file is used to specify information about PCMCIA devices. The following values may be used:

- PCMCIA=<value>, where <value> is one of the following:
  - yes — PCMCIA support should be enabled.
  - no — PCMCIA support should not be enabled.

## 4.1.26. /etc/sysconfig/radvd

The /etc/sysconfig/radvd file is used to pass arguments to the radvd daemon at boot time. The radvd daemon is an IPv6 router advertisement daemon. The following values may be used:

- INTERFACE=<value>, where <value> is the interface that radvd should listen on.
- OPTIONS=<value>, where <value> is any option in the man page for radvd.

## 4.1.27. /etc/sysconfig/raddevices

The /etc/sysconfig/raddevices file is used to configure raw device bindings. The following values may be used:

- DEVICES=<value>, where <value> is a list of raw devices to manage.

## 4.1.28. /etc/sysconfig/redhat-config-securitylevel

The /etc/sysconfig/redhat-config-securitylevel file contains all options chosen by the user the last time the Security Level Configuration Tool (redhat-config-securitylevel) was run. Users should not modify this file by hand.

## 4.1.29. /etc/sysconfig/redhat-config-users

The /etc/sysconfig/redhat-config-users file is the configuration file for the graphical application, User Manager. Under Red Linux this file is used to filter system users such as root, daemon, or ip.

## 4.1.30. /etc/sysconfig/redhat-logviewer

The /etc/sysconfig/redhat-logviewer file is the configuration file for the graphical, interactive log viewing application. Log Viewer.
