# 4.11.1. /etc/sysconfig/hwconf

The /etc/sysconfig/hwconf file lists all the hardware kudzu detected on the system, as well the drivers used, vendor ID, and device ID information. The kudzu program detects and configures new andor changed hardware on a system. The /etc/sysconfig/hwconf file is not meant to be manually edited. If edited, devices could show up as being added or removed.

# 4.11.2. /etc/sysconfig/i18n

The /etc/sysconfig/i18n file sets the default language, any supported languages, and the default system font. For example:

```
LANG=en_US.UTF-8
SUPPORTED=en_US.UTF-8:en_US:en
YSFONT="latarcyrheb-sun16"
```

# 4.11.3. /etc/sysconfig/identd

The /etc/sysconfig/identd file is used to pass arguments to identd daemon at boot time. The identd daemon returns the username of processes over TCP/IP connections. Some services on the network, as FTP and IRC servers, will complain and slow responses if identd is not running. But in general, identd is not a required service, so if security is concern, do not run it. For more information about what parameters are available for this file, see the identd man page. By default, the file contains no parameters.

# 4.11.4. /etc/sysconfig/init

The /etc/sysconfig/init file controls how the system will appear and function during the boot process.
The following values may be used:

+   - BOOTP=<value>, where <value> is one of the following:
  - BOOTP=color means the standard color boot display, where the success or failure of devices and services starting up in different colors.
  - BOOTP=verbose means an old style display, which provides more information than purely a message of success or failure.
  - Anything else marks a new display, but without ANSI-formatting.

+   - RES_COL=<value>, where <value> is the number of the column of the screen to start status labels. Defaults to 60.
- MOVE_TO_COL=<value>, where <value> moves the cursor to the value in the RES_COL line via the echo -en command.
