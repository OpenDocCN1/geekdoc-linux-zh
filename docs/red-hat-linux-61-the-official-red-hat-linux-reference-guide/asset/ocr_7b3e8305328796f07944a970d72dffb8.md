# 6 Chapter 1. Boot Process, Init, and Shutdown

```
S90cups -> ..init.d/cups
S90xfs -> ..init.d/xfs
S95anacron -> ..init.d/anacron
s95atd -> ..init.d/atd
s97rhnsd -> ..init.d/rhnsd
S99local -> ..rc.local
s99mdmonitor -> ..init.d/mdmonitor
```

As illustrated in this list, none of the scripts that actually start and stop the services are located in the /etc/rc.d/rc5.d/. Rather, all of the files in /etc/rc.d/rc5.d/ are symbolic links pointing to scripts in the /etc/rc.d/init.d/. Symbolic links are used in each of the rc directories so that the runlevels can be reconfigured by modifying, deleting and deleting symbolic links without affecting the actual scripts.

The name of each link begins with a k or an S. The K links are processes that are called on that runlevel, those beginning with an S are started.

The init command first stops all of the K links in the directory by issuing the /etc/rc.d/init.<command> stop command, where <command> is the process to be killed. It starts all of the S links by issuing /etc/rc.d/init.<command> start.

> Tip After the system is finished booting, it is possible to log in as root and execute these scripts to start and stop services. For instance, the command /etc/rc.d/init.d/httpd stop will stop the Apache Web server.

Each of the symbolic links are numbered to dictate start order. The order in which the services are started or stopped can be altered by changing this number. The lower the number, the earlier it is started. Those symbolic links with the same number are started alphabetically.

> Note One of the last things the init program executes the /etc/rc.d/rc.local file. This file is useful for system customization. See Section 1.3 Running Additional Programs at Boot Time for more on using the /rc.local file.

After the init command has progressed through the appropriate rc directory for the runlevel, the /etc/initab script runs a process for each virtual console (login prompt) allocated to the runlevel. Runlevels 2 through 5 get six virtual consoles, while runlevel 1 (user mode) uses only one and runlevels 0 and 6 have none. The /sbin/mingetty process opens communication pathways to tty devices, sets their modes, and prompts the login prompt, gets the name and password for the user.

In runlevel 5, the /etc/initab runs a script called /etc/X11/predm. The prefdm script executes the X display manager — gdm, kdm, or xdm, depending on the contents of the /etc/sysconfig/desktop file.

At this point, the system is operating on runlevel 5 and displaying a login screen.

+   5. See Section 5.3.11 /proc/tty/ for more information on tty devices.
