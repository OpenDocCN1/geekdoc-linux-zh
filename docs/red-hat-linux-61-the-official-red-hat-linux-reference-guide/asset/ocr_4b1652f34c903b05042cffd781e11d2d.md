# 10.2.4.3. The mod_include Module

The mod_include module is now implemented as a filter and is therefore enabled differently. Refer to Section 10.2.4 Modules and Apache HTTP Server 2.0 for more filters.

For example, the following is a sample Apache HTTP Server 1.3 directive:

```
AddType text/html .html
AddHandler server-parsed .html
```

To migrate this setting to Apache HTTP Server 2.0, use the following structure:

```
AddType text/html .html
AddOutputFilter INCLUDES .html
```

Note that just as before, the Options +Includes directive is still required for the <Directory> container or in a .htaccess file.

For more on this topic, refer to the following documentation on the Apache Software Foundation's website:

+   - httpd.apache.org/docs-2.0/mod/mod_include.html

# 10.2.4.4. The mod_auth_db and mod_auth_dbm Modules

Apache HTTP Server 1.3 supported two authentication modules, mod_auth_db and mod_auth_dbm which Berkeley Databases and DBM databases have been combined into a single module mod_auth_db in Apache HTTP Server 2.0, which can access several different formats. To migrate from mod_auth_db, configuration files should be adjusted by replacing AuthDBFile and AuthDBGroupFile with the mod_auth_db equivalents: AuthDBUserFile and AuthDBThreadGroup. Also, the directive AuthDBType must be added to indicate the type of database file.

The following example shows a sample mod_auth_db configuration for Apache HTTP Server 1.3:

```
<Location /private/
AuthType Basic
AuthName "My Private Files"
AuthDBUserFile /var/authdb
require valid-user
</Location>
```

To migrate to version 2.0 of Apache HTTP Server, use the following structure:

```
<Location /private/
AuthType Basic
AuthName "My Private Files"
AuthDBUserFile /var/www/authdb
AuthDBType DB
require valid-user
</Location>
```

Note that the AuthDBUserFile directive can be used in .htaccess files.
The dbmmange script, used to manage username and password databases, has been replaced by htdbm in Apache HTTP Server 2.0. The htdbm program offers equivalent functionality and like mod_auth_dbm can operate a variety of database formats; the -T option can be used on the command line to specify the format to use.
