# 14.4. Sample PAM Configuration Files

Below is a sample PAM application configuration file:

```
#PAM-1.0
auth required /lib/security/pam_security.so
auth required /lib/security/pam_unix.so shadow nullock
auth required /lib/security/pam_loginin.so
account required /lib/security/pam_unix.so
password required /lib/security/pam_cracklib.so retry=3
password required /lib/security/pam_unix.so shadow nullock use_authtok
session required /lib/security/pam_unix.so
```

The first line is a comment as demonstrated by the hash mark (#) at the beginning of the line.
Lines through three modules for login authentication.

```
auth required /lib/security/pam_security.so
```

This module makes sure if the user is trying to log in, the tty on which the user is logged exists in the /etc/security file, if that exists.

```
auth required /lib/security/pam_unix.so nullock
```

This module prompts the user for a password and checks the password using the information stored in /etc/passwd and, if exists, /etc/shadow. The pam_unix.so module automatically detects and uses shadow passwords to authenticate users. Please refer to the Section 6.5 Shadow for more information on shadow passwords.

The argument nullock instructs the pam_unix.so to allow a blank password.

```
auth required /lib/security/pam_login.so
```

This is the final authentication step. It results to see if the file /etc/login exists. if login exists and the user is not root, authentication fails.

# Note

In this example, three auth modules are checked, if the first auth module fails. This prevents the user from knowing at what stage their authentication failed. Such knowledge in the hands of an attacker could allow them to more easily decode how to crack the system.

```
account required /lib/security/pam_unix.so
```

This module performs any necessary account verification. For example, if shadow passwords have been enabled, the account component of the pam_unix.so module will check to see if the account has expired or if the user has not changed the password within the grace period.

```
password required /lib/security/pam_cracklib.so retry=3
```
