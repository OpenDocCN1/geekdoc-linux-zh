# 10.5.64. ProxyRequests

To configure the Apache HTTP Server to function as a proxy server, remove the hash marks from the beginning of the <IfModule mod_proxy.c> line to the mod_proxy module and set the ProxyRequests directive to On.

# 10.5.65. ProxyVia

<Proxy > </Proxy> tags create a container that encloses a group of configuration directives to apply only to the proxy server. Many directives are applicable to a directory and may be used within <Proxy> tags.

# 10.5.66. ProxyVia

The ProxyVia command controls whether or not an HTTP header is sent along with requests or replies which go through the proxy server. The Via: header sends the hostname if ProxyVia is set to On, shows the hostname and the Apache HTTP Server version for Full, passes any Via: lines unchanged for Off, and lines are removed for Block.

# 10.5.67. Cache Directives

A number of cache directives are supplied by the default Apache HTTP Server configuration. In most cases, uncommenting these lines by the hash mark [#] from the beginning of the line is sufficient. However, here is some of the most important cache-related directives.

+   * CacheRoot Specifies the name of the directory containing cached files. The default CacheRoot is the /var/httpd/proxy/ directory.

+   * CacheSize Specifies how much space the cache can use in kilobytes. The default CacheSize is5 KB.

+   * CacheInterval Specifies the number of hours which must pass before files in the cache are deleted. The default CacheInterval is 4 hours.

+   * CacheMaxExpires Specifies how long documents are retained (without a reload from the originating Web server). The default is 24 hours.

+   * CacheLastModifiedFactor Specifies the creation of an expiry (expiration) date for a document which did not come from its originating server with its own expiry date. The default CacheLastModifiedFactor is set to 0.1, meaning the expiry date for such documents equals one-tenth of the amount of time the document was last modified.

+   * CacheDefaultExpires Specifies the expiry time for a document that was received using a protocol that does not support expiry times. The default is set to 1 hour.

+   * NoCache Specifies a list of hosts whose content is not cached.
