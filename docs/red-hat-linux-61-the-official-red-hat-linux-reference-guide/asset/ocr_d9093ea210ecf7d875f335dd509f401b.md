# 2. Finding Appropriate Documentation

You need documentation that is appropriate to your level of Linux expertise. Otherwise, you might feel overwhelmed or not find the necessary information to answer any questions. The Red Hat Linux Reference Guide deals with more technical aspects and options of a Red Hat Linux system. This section will help you decide whether to look in this manual for the information you need or consider other Red Hat manuals, including online sources, in your search.

Three categories of people use Red Hat Linux, and each of these requires different sets of documentation and informative services. To help you figure out where you should start, determine your experience level:

New to Linux

This type of user has never used any Linux (or Linux-like) operating system before or has only limited experience to Linux. They may or not have experience using other operating systems (such as Windows). If this is you, skip ahead to Section 2.1 Documentation For First-Time Users.

Some Linux Experience

This type of user has installed and successfully used Linux (but not Red Hat Linux) before or may have equivalent experience with other Linux-like operating systems. Does this describe you?, turn to Section 2.2 For the More Experienced.

Experienced User

This type of user has installed and successfully used Red Hat Linux before. If this describes you, turn to Section 2.3 Documentation for Linux Gurus.

# 2.1. Documentation For First-Time Linux Users

For someone new to Linux, the amount of information available on any particular subject, such as printing, starting up the system or partitioning a hard drive, can be overwhelming. It helps to initially step back and gain a decent base of information centered around how Linux works tackling these kinds of advanced issues.

Your first goal should be to obtain some useful documentation. This cannot be stressed enough. Without documentation, you will only become frustrated by your inability to get a Red Hat Linux system working the way you want.
