So, for example, a system with a USB bus but no USB devices connected to it has a /proc/bus/usb/ directory containing several files:

```
total 0
dr-xr-xr-x 1 root      root      0 May 3 16:25 001
--r--r--r-- 1 root      root      0 May 3 16:25 devices
--r--r--r-- 1 root      root      0 May 3 16:25 drivers
```

The /proc/bus/usb/ directory contains that track the various devices on any USB buses, as well as the drivers required to use them. The /proc/bus/usb/001/ directory contains all devices on the first bus. By looking at the contents of the devices file, one can identify the USB root hub on the motherboard:


# 5.3.3./driver/

This directory contains information for specific drivers in the kernel.

A common file found here is rtc, which provides output from the driver for the system's Real Time Clock (RTC), the device that keeps the time while the system is switched off. Sample output from /proc/driver/rtc looks like:

```
rtc_time : 01:38:43
rtc_date : 1998-02-13
rtc_epoch : 1900
alarm : 00:00:00
DST_enable : no
BCD : yes
24hr : no
square_wave : no
alarm_IRQ : no
update_IRQ : no
periodic_IRQ : no
periodic_freq : 1024
batt_status : okay
```

For more information about the RTC, /user/src/linux-2.4/Documentation/rtc.txt.
