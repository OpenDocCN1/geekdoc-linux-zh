# Chapter 2. Boot Loaders

```
boot=/dev/hda
map=/boot/map
install=/boot/boot.b
prompt
timeout=50
message=/boot/message
lba32
default=linux
image=/boot/mlinux-2.4.0-0.43.6
label=linux
initrd=/boot/initrd-2.4.0-0.43.6.img
read-only
root=/dev/hda5
```

This example shows a system configured to boot two operating systems: Red Hat Linux and DOS. A more detailed look at the lines of this file:

+   * `boot=/dev/hda` — Instructs LILO to install itself on the first hard disk of the IDE controller.
* `map=/boot/map` — Locates the map file. In normal use, this should not be modified.
* `install=/boot/boot.b` — Instructs LILO to install the specified file as the new boot sector. In normal use, this should not be altered. If the `install` line is missing, LILO will assume a default of `/boot/boot.b` as the file to be used.
* `prompt` — Instructs LILO to show what is referenced in the `message` line. While it is not recommended that you use the `prompt` line, if you remove it, you can still access a prompt by holding down the [Shift] key when your machine starts.
* `timeout=50` — Sets the amount of time LILO will wait for user input before proceeding to booting the `default` line. This is measured in seconds, with 50 as the default.
* `message=/boot/message` — Refers to the screen that LILO displays to let you select the operating system or kernel to boot.
* `lba2` — Describes the disk geometry to LILO. Another common entry is `linear`. You should not change this unless you are aware of what you are doing, which could put your system in an unbootable state.
* `default=linux` — Refers to the default system for LILO to boot as in the options listed below. The `name` line refers to the `label` line in each of the boot options.
* `image=/boot/mlinux-2.4.0-0.43.6` — Specifies which Linux kernel to boot with this particular option.
* `label=linux` — Names the operating system option in the LILO. In this case, it is the name referred to by the `default` line.
* `initrd=/boot/initrd-2.4.0-0.43.6.img` — Refers to the initial ram disk image that is used at boot time to actually initialize and start the devices booting the kernel possible. The initial ram disk is a collection of machine-specific drivers needed to operate a SCSI card, hard drive, or any other device needed to load the kernel. You never try to share ram disks between machines.
* `read-only` — Specifies that the root partition (see the `root` line below) is read-only and cannot be altered during the boot process.
* `root=/dev/hda5` — Specifies which partition to use as the root partition.
