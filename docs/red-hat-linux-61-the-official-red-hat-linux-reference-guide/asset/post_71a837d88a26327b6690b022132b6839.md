## 5.2.10. /proc/iomem

This file shows the current map of the system's memory for each physical device:

| Address | Description |
| :--- | :--- |
| 00000000-009fbff | System RAM |
| 009c0f00-009ffff | reserved |
| 000a0000-00ffff | Video RAM area |
| 000c0000-00c7ffff | Video ROM |
| 000f0000-00ffff | System ROM |
| 001d0000-007ffff | tulip |
| 00100000-00291ba8 | Kernel code |
| 002919a0-002e09fc | Kernel data |
| e0000ffff-e3ffff | tulip, Inc. VT82C597 (Apollo VP3) |
| e04000000-ffff | PCI Bus #01 |
| e44000000-e403ffff | Matrix Graphics, Inc. MGA G200 AG |
| e05000000-5ffff | Matrix Graphics, Inc. MGA G200 AG |
| e08000000-ffff | PCI Bus #01 |
| e08000000-ffff | Matrix Graphics, Inc. MGA G200 AG |
| e0a000000-a007ffff | Equipment Corporation DECchip 21140 [FasterNet] |
| e0a000000-ffff | tulip |
| ffffffff-ffff | reserved |

The first column displays the memory registers used by each of the different types of memory. The second column lists the kind of memory located within those registers. In particular, this column displays which memory registers are used by the kernel within the system RAM or, if the network interface card handles Ethernet ports, the memory registers assigned for each port.

| 0040-005f | timer |
| 0060-006f | keyboard |
| 0070-007f | rtc |

| 0aa0-0aaf | pic2 |
| 00c0-00cf | dma2 |
| 00f0-00ff | fpu |
| 0170-0177 | ide1 |
| 01f0-01f7 | ide0 |
| 02f8-02ff | serial (auto) |
| 0376-0376 | idei |
| 03c0-036f | vaga |
| 03f6-03f6 | ide0 |
| 03f8-03ff | serial (auto) |
| 0cf8-0cff | PCI conf1 |
| d000-dfff | PCI Bus #01 |
| e000-e00f | VIA Technologies, Inc. Bus Master IDE |

| e008-e00f | idel |

## 5.1.2. /proc/isapnp

This file lists Plug and PnP (PnP) slots on the system. This is most often seen with sound cards but may include any number of devices. A /proc/isapnp file with a Soundboard entry in its list will show this:

```
'CTLI0070:Creative ViBRA16c PnP PnP version 1.0 Product version 1.0
Logical device 0 'CTLI0001:Audio'
Device is not active
Active port 0x220,0x330,0x388
Active IRQ 5 [0]
Active DMA 1,5
Resources 0
Priority preferred
Port 0x220-0x280, align 0xf0, size 0x10, 16-bit address decoding
Port 0x330-0x330, align 0xf0, size 0x22, 16-bit address decoding
Port 0x388-0x388, align 0xf0, size 0x04, 16-bit address decoding
IRQ 5,High-Edge
DMA 1 8-bit byte-count compatible
DMA 5 16-bit word-count compatible
Alternate resources 0:1
Priority acceptable
Port 0x220-0x280, align 0xf1, size 0x10, 16-bit address decoding
Port 0x300-0x330, align 0xf2, size 0x22, 16-bit address decoding
Port 0x385-0x388, align 0xf0, size 0x04, 16-bit address decoding
IRQ 5,7,9,10 High-Edge
DMA 1 8-bit byte-count compatible
DMA 5 16-bit word-count compatible
```

This file can be long, depending on the number of devices displayed and their resource requirements.

Each card lists its PnP version, and product version number. If the device is active and configured, this file will also reveal the port and IRQ numbers for the device. In addition, to ensure better compatibility, the card will show preferred and acceptable values for a number of different parameters. The goal here is to allow PnP cards to work around.
