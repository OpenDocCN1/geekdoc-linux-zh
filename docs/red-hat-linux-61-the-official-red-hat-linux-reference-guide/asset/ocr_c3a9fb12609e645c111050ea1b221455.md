# 9.2. NFS Server Configuration Files

Configuring a server to share files and directories using NFS is a simple process. Every file system is exported to remote users via NFS, with the access rights relating to those files, located in the /etc/exports file. This file is read by the exportfs command to give rpc.mountd rpc.nfs information necessary to allow the remote mounting of a file system by an authorized host.
The exportfs command allows the root user to selectively export or export directories without restarting the service. When exportfs is passed the options, the file systems are exported written to /var/lib/nfs/stab. Since rpc.mount refers to the xtab when deciding access privileges to a file system, changes to the list of exported files take effect immediately.
Various options are available when using exportfs:

+   - r — Causes all directories listed in /etc/exports to be exported by constructing a new export list in /etc/lib/nfs/stab. This option effectively refreshes the export list with any changes that have been made to /etc/exports.
- a — Causes all directories to be exported or unexported, depending on the other options passed to exportfs.
- o — Allows the user to specify directories to be exported that are not listed in /etc/exports. This additional file system must be written in the same way they are specified in /etc/exports. This option is used to test an exported file system before adding it permanently to the list of files to be exported.
- i — Ignore /etc/exports; only options given from the command line are used to define exported file systems.
- u — Unexports directories being mounted by remote users. The command exportfs -ua effectively suspends NFS sharing while keeping the various NFS daemons up. To allow NFS sharing to continue, type exportfs -r.
- v — Verbose output, where the file systems exported or unexported are displayed in greater detail when the exportfs command is executed.

If no options are passed to the exportfs command, it displays a list of currently exported file systems.
Changes to /etc/exports can also be made by reloading the NFS service with the service nfs reload command. This keeps the NFS daemons running while re-exporting the /etc/exports file.
