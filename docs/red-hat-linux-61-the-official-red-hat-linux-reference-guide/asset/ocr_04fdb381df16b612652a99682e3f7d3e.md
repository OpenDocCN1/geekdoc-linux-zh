Each SCSI device has its own revision in /proc/scscil/, which contains files specific to each SCSI controller using driver. For example, the system addressed, aic7xxx and megaraid directories are listed, as two are being utilized. The files in each directories typically contain an I/O address range, IRQ request, and statistics for the SCSI controller using that driver.
