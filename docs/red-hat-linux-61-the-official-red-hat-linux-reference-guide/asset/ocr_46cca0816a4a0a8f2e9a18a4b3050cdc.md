> Important
If a SSH server's host key has changed, the client will notify you that the connection cannot proceed until the server's host key is deleted from the known_hosts file using a text editor. Before doing this, contact the system administrator of the SSH server to verify the server is not compromised.

# 18.5. More Secure Shell

A secure command line interface is just the beginning of the many ways SSH can be used. By the proper amount of bandwidth, X11 can be directed over an SSH channel. Or, by TCP/IP forwarding, insecure port connections between systems can be mapped to specific SSH channels.

# 18.5.1. X11 Forwarding

Opening an X11 session over an established SSH connection is as easy as running an X program on a local machine. When an X program run from the remote shell, the SSH client and server create a new channel, and the X program data is sent over to the client machine transparently.

X11 forwarding can be very useful. For example, X11 forwarding can be used to create a secure, interactive session with update. To do this, connect to the server using ssh and by type:

```
update
```

After supplying the root password for the server, the Red Hot Update Agent will appear and allow the remote user to safely update the system.

# 18.5.2. Port Forwarding

SSH can secure otherwise insecure TCP/IP protocols via port forwarding. When using this technique, the SSH server becomes an encrypted tunnel to the SSH client.

Port forwarding works by mapping a local port on the client to a remote port on the server. SSH can map any port from the server to any port on the client, and the port numbers do not need to match for this technique to work.
