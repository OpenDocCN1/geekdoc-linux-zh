# 5.2.9./proc/interrupts

This file records the number of inters per IRQ on the x86 architecture. A standard
/proc/interrupts looks similar to this:

```
CPU                               timer
0: 80489490                    XT-PIC timer
1: 174412                       XT-PIC keyboard
2: 0                              XT-PIC cascade
8: 1                              XT-PIC rtc
10: 410964                         XT-PIC eth0
12: 60330                          XT-PIC PS/2 Mouse
14: 1314121                        XT-PIC ide0
15: 5195422                        XT-PIC idel
NMI:                              
ERR:                              
```

For a multi-processor machine, this file might look slightly different:

```
CPU                               CPU1
0: 136681704                    0                 XT-PIC timer
1: 128                           340             IO-APIC-edge keyboard
2: 0                             0                 XT-PIC cascade
8: 0                             1                 IO-APIC-edge rtc
12: 5233                          5793             IO-APIC-edge PS/2 Mouse
13: 1                             0                 XT-PIC fpu
16: 11184294                      15940554        IO-APIC-level Intel EtherExpress Pro for 10/abit Ethernet
24: 8500043                       11120093        IO-APIC-level megaraid
30: 10432                         10722             IO-APIC-level aic7xxx
31: 23                            22                IO-APIC-level aic7xxx
NMI:                              
ERR:                              
```

The first column refers to the IRQ. Each CPU in the system has its own column and the last column
number of IRQ. The next column represents the type of interrupt, and the last column
contains the name of the device that is located at IRQ.

Each of the types of interrupts seen in this file, which are architecture-specific, mean something a little
different. For x86 machines, the following values are common:

+   - XT-PIC — This is the old AT computer interrupts.
