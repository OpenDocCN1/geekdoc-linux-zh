# Chapter 18. SSH Protocol

+   - telnet
- rsh
- rlogin
- vsftpd

To disable insecure connection methods to the system, use the command line program `chkconfig`, the ncurses-based program `ntsys`, or the graphical application **Services Configuration Tool** (redhat-config-services). All of these tools require root access.

For more information on runlevels and configuring services with `chkconfig`, `ntsysv`, and **Services Configuration Tool**, refer to the chapter titled *Controlling Access to Services* in the *Red Hat Linux Customization Guide*.
