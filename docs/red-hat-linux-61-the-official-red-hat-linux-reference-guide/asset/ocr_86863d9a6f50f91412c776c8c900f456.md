# 11.3. Mail Transport Agents

Red Linux includes two primary MTAs, Sendmail and Postfix. Sendmail is configured as the default MTA, although it is easy to switch the default MTA to Postfix.

> Tip
For information about how to switch the default MTA from Sendmail to Postfix, see the chapter called Mail Transport Agent (MTA) Configuration in the Red Linux Customization Guide.

Red Linux also includes a special MTA called Fetchmail, which is used to deliver email from a remote MTA to a local MTA.

This section details Sendmail and Fetchmail.

# 11.3.1. Sendmail

Sendmail's core purpose, like other MTAs, is to transfer email among hosts, usually using the SMTP protocol. However, Sendmail is highly configurable, allowing control over almost every aspect of how email is handled, using the protocol. Many system administrators elect to use Sendmail as their MTA due to its power and scalability.

# 11.3.1.1. Purpose and Limitations

It is important to be aware of what Sendmail is and what it can do as opposed to what is not. However, most users actually want much more than simple email delivery. They want to interact with their email through an MUA, that can POP or IMAP to download their messages to their local machine. Or, they may prefer a Web interface to gain access to their mail. These applications can work in conjunction with Sendmail, but they operate separately from one another.
