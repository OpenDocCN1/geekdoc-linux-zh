### 5.3.4. /proc/fs

This directory shows which file systems are exported. If running an NFS server, typing `cat /proc/nfs/exports` will display the file systems shared and the permissions granted for those file systems. For more sharing file system with NFS, see Chapter 9 Network File System (NFS).

### 5.3.5. /proc/ide/

This directory holds information about IDE devices on the system. Each IDE channel is represented as a separate directory, such as `/proc/ide/ide0` and `/proc/ide/ide1`. In addition, drivers file is also available, providing the version of the number drivers used on the IDE channels:

```
ide-cdrom version 4.59
ide-floppy version 0.97
ide-disk version 1.10
```

Many chipsets also provide an informational file in this directory that gives additional data concerning the drives connected through the channels. For example, a generic PIIX4 Ultra 33 chipset produces a `/proc/ide/piix` that will tell you whether DMA or UDMA is enabled for the devices on the IDE channels:

| | PIIX4 Ultra 33 Chipset | |
|---|---|---|
| Primary Channel | Secondary Channel | |
| enabled | enabled | |
| drive0 | drive | drive0 | drive |
| DMA enabled: yes | no | yes | no |
| UDMA enabled: yes | no | no | no |
| UDMA enabled: 2 | X | X | X |
| DMA | | | |
| PIO | | | |

Navigating into the directory for an IDE channel, such as ide0, provides additional information. The channel file provides the channel number, while the model tells you the bus type for the channel (such as pci).

### 5.3.5.1. The Device Directory

Each IDE channel is a device directory. The name of the device directory corresponds to the drive letter in the `/dev/` directory. For instance, the first IDE drive on ide0 would be hda.

> Note
> There is a symbolic link to each of these device directories in the `/proc/ide/` directory.

Each device directory contains a collection of information and statistics. The contents of these directories vary according to the type of device connected. Some of the most useful files common to many devices include:

- cache — The device cache.
- capacity — the capacity of the device, in 512 byte blocks.
- driver — the driver and version used to control the device.
- geometry — the physical and logical geometry of the device.
- media — the type of device, such as a disk.
- model — the model name or number of the device.
- settings — A collection of current parameters of the device. This file usually quite a bit of useful, technical information. A sample settings for a standard IDE hard disk looks similar to this:

### 5.3.6 /proc/irq/

This directory is used to set IRQ affinity, which allows the system to connect a particular IRQ to only one CPU. Alternatively, it can exclude a CPU from handling any IRQs.

Each IRQ has its own directory, for the individual configuration of each IRQ. The `/proc/irq/proc_cpu_mask` is a bitmask that contains the default values for the sm_affinity file in the IRQ directory. The values in sm_affinity specify which CPUs handle that particular IRQ.

For more information about the `/proc/irq/` directory, consult:

```
/usr/src/linux-2.4/Documentation/filesystems/proc.txt
```

### 5.3.7. /proc/net/

This directory provides a comprehensive look at various networking parameters and statistics. Each of the files covers a specific range of information related to networking on the system. Below is a partial listing of these virtual files:

- arp — Contains the kernel's ARP table. This file is particularly useful for connecting a hardware address to an IP address on a system.
- atm — A directory containing files with various Asynchronous Transfer Mode (ATM) settings and statistics. This directory is primarily used with ATM and ADSL cords.
- dev — Lists the various network devices configured on the system, complete with transmit and receive statistics. This file lists the number of bytes each interface has received, the number of packets inbound and outbound, the number of errors seen, the number of packets dropped, and more.
- dev_multcast — Displays the various Layer2 multicast groups each device is listening to.
- igmp — Lists the IP addresses which this system joined.
- ip_fwchains — If ipchains are in use, this virtual file reveals any current rule.
- ip_fwnames — If ipchains are in, lists all firewall chain names.
- ip_masquerade — Provides a table of masquerading information under ipchains.
- ip_mr_cache — Lists the multicast routing cache.
- ip_mr_vif — Lists multicast interfaces.
- netstat — Contains a broad detailed collection of networking statistics, including TCP time-outs, SYN cookies sent and received, and much more.
- psched — Lists global packet scheduler parameters.
- raw — Lists raw statistics.
- route — Lists routing statistics.
- rt_cache — Contains the routing cache.
- snmp — Simple Network Management Protocol (SNMP) data.
- sockstat — Provides the socket statistics.
- tcp — Contains the TCP statistics.
- tr_if — Lists the routing table.
- udp — Contains UDP statistics.
- unix — Lists the unix domain.
