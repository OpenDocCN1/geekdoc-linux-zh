# Chapter 10. Apache HTTP Server

# 10.5.38. ErrorLog

ErrorLog specifies the file where server errors are logged. By default, this directive is set to /var/log/httpd/error_log.

# 10.5.39. LogLevel

LogLevel sets how verbose error messages in the error logs are. LogLevel can be set (from least verbose to most verbose) to emerg, alert, crit, error, warn, notice, info or debug. The default LogLevel is warn.

# 10.5.40. LogFormat

The LogFormat directive config the format of the virtual Web server log files. The actual LogFormat depends on the settings given in the CustomLog directive (see Section 10.5.41 CustomLog).

The following are the options if the CustomLog directive is set to combined:

+   %h (remote host's IP address or hostname)
Lists the IP address of the requesting client. If HostnameLookups is set to on, the client hostname is recorded unless it is not available from DNS.

+   %l (rfc931)
Not used. A hyphen [-] appears in the log file for this field.

+   %u (authenticated user)
If authentication is required, lists the user name of the user is recorded. Usually, this is used, so a hyphen [-] appears in the log file for this field.

+   %t (date)
Lists the date and time of the request.

+   %r (request string)
Lists the request string exactly as it came from the browser or client.

+   %s (status)
Lists the HTTP status code which was returned to the client host.

+   %b (bytes)
Lists the size of the document.

+   %%%%Referer)i" (referrer)
Lists the URL of the webpage which referred the client host to Web server.

+   %%(User-Agent)i" (user-agent)
Lists the type of Web browser making the request.
