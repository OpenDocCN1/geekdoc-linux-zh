# Chapter 5. The proc File System

```
agpgart      31072 0 (unused)
binfmt_misc 5956 1
iscsi        32672 0 (unused)
scsi_mod     94424 1 [scsi]
autofs       10628 0 (autoclean)
tulip        46808 1
ext3       60352 2
njbd          39192 2 [ext3]
```

The first column contains the name of the module. The second column refers to the memory of the module, the third column lists whether the module is currently loaded (1) or unloaded (0). The final column specifies whether the module can unload itself automatically after a period without use (autoclean) or if it is not being utilized (unused). A module with a name listed in brackets (( )) indicates that the module depends upon another module to be present in order to function.

# 5.2.2./proc/mounts

This file provides a list of all mounts used by the system:

```
rootfs / rootfs rw 0 0
/dev/sda2 ext3 rw 0 0
/proc /proc rw 0 0
/dev/hda1 /boot ext3 rw 0 0
none /dev/pts dev rw 0 0
none /dev/shm tmpfs rw 0 0
none /proc/sys/fs/binfmt_misc binfmt_misc rw 0 0
```

The output found here is similar to contents of /etc/mtab, except that /proc/mount is more-to-date.

The first column specifies the device that is mounted, the second column revealing the mountpoint, and the third column lists the file system type, and the fourth column tells you it is mounted read-only (ro) or read-write (rw). The fifth and sixth columns are dummy values designed to match the format used in /etc/mtab.

# 5.2.3./proc/mtr

This file refers to the current Memory Type Range Registers (MTRRs) in use with the system. If the system architecture supports MTRRs, the /proc/mtr file may look similar to this:

```
reg00: base=0x00000000 (MB), size=64MB: write-back, count=1
```

MTRRs are used with the Intel P6 processors (Pentium II and higher), and they control processor access to memory ranges. When using a video card on a PCI or AGP bus, a properly configured /proc/mtr file can increase performance over 150%.

Most of the time, this value is properly configured by default. More information on manually configuring this file, can be found online at the following URL: http://web.linuxux.org/kernel/v2.3/doc/mtr.txt.html.
