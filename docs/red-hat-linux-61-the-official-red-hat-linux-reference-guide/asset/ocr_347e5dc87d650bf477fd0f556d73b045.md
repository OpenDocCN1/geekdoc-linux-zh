# 2.8. LILO

LILO is an acronym for the Linux Loader and is used to boot Linux on x86 systems for manyn years. Although GRUB is now the default boot loader, some users prefer to use LILO because it is
familiar to them and others out of necessity, since GRUB may have trouble booting some
hardware.
