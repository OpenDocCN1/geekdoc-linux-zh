# Chapter 12. Berkeley Internet Name Domain (BIND)

The # symbol replaces the ORIGIN directive (or the zone's name, if the ORIGIN directive is not set) as the name defined by the SOA resource record. The primary nameserver is authoritative for this domain used for the <primary-name-server>, and the email of the person to contact this name is substituted for the <hostmaster-email>.

The <serial-number> is incremented every time the zone file so changed is named  named which it will know that it needs to reload this zone. The <time-to-refresh> tells all servers to wait before asking the master nameserver if any changes have been made to the zone. The <serial-number> value is used by the slave to determine if it is using outdated zone data and should refresh.

The <time-to-retry> tells the slave the interval to wait before issuing another refresh request, if the master nameserver is not answering. If the master has not replied a refresh request before the <time-to-expire> lapses, the slave stops responding as an authority for requests concerning that name.

The <minimum-TTL> requests that other nameser cache the zone's information for at least this amount of time (in seconds).

With BIND, all time refers to seconds. However, it is possible to use abbreviations units of time other than seconds, such as minutes (M), hours (H), days (D), and weeks (W). The Table 12-1 shows an amount of time in seconds and the equivalent unit in another format.

| Seconds | Other Time Units |
| 60 | 1M |
| 1800 | 30M |
| 3600 | 1H |
| 10800 | 3H |
| 21600 | 6H |
| 43200 | 12H |
| 86400 | 1D |
| 259200 | 3D |
| 604800 | 1W |
| 31536000 | 365D |

Table 12-1. example illustrates the form an SOA resource record might take when it is configured with real values.

```
ns1.example.com. hostmaster.example.com. (
IN SOA 2001062501 ; serial
      21600 ; refresh after 6 hours
      retry after 1 hour
      604800 ; expire after 1 week
      86400 ; minimum TTL of 1 day
)
```
