
# Chapter 7. The X Window System

## 7.5.2. Runlevel 5

When the system boots into runlevel 5 a special X application, called a display manager is launched. A user must authenticate using the display manager before any desktop environments or window managers are launched.

Depending on the desktop environments installed on the system, three different display managers are available to handle user authentication.

- gdm: The default display manager for Red Hat Linux, gdm allows the user to configure settings, shutdown, restart or log in to the system.
- KDE’s display manager allows the user to shutdown, restart or log in to the system.
- xdm: A basic display manager that only lets the user log in to the system.

When booting into runlevel 5, the preadm script describes the preferred display manager by referencing the /etc/sysconfig/desktop file. Refer to the /usr/share/doc/inscripts-<version-number>/sysconfig.txt file (where <version-number> is the version of the package) for a list of options available for this file.

Each of the display managers references the /etc/X11/xdm/Xsetup_file to set the login screen. Once the user logs in, the /etc/X11/clients/GiveConsole script runs to assign ownership of the console to the user. Then, the /etc/X11/xdm/Xsession script runs to accomplish many of the tasks normally performed by the xinitrc script starting X from runlevel 3, including system and user resources, as well as running the scripts in the /etc/X11/xinitrd.d/

The user can specify which desktop environment to utilize when authenticating using the gdm or xdm by selecting it from the Session menu (accessed by selecting Main Menu [Panel] Preferences -> Sessions). If the environment is not specified in the display manager, the /etc/X11/xdm/Xsession script will create a .xession and .Xclients file. As default, the /etc/X11/xinitrc file is used to select which desktop environment to load. A root, or window manager to use as runlevel 5.

When the user finishes a session on the default display (:) and logs out, the /etc/X1/TakeConsole script runs and reassigns ownership of the console to the root user. The original display manager, which continued running after the user logs in, takes control by spawning a new display manager. This restarts the XFree8 server, provides a new login window, and starts the process over again.

The user is returned to the display manager after logging out of X from runlevel 5.

For more information about how display managers control user authentication, refer to the /usr/share/doc/gdm-<version-number>/README (where <version-number> is the version number for the gdm package installed) and the xdm man page.

## Network Interfaces

Under Red Hat Linux, all network communications occur between configured software and physical networking devices.

The configuration files for network interfaces, and the scripts to activate and deactivate them, are located in /etc/sysconfig/network-scripts/ directory. Although the number and type of interface files can differ from system, there are three categories of files:

- Interface configuration files
- Interface control scripts
- Network function files

The files in each of these categories work together to enable various network devices. This chapter will explore the relationship between these files and how they are used.

### 8.1. Network Configuration Files

Before delving into the configuration files, let us first the primary configuration files used in network. Understanding the role these files play in setting up the network can be helpful when customizing a Red Hat system.
The primary configuration files are as follows:

- /etc/hosts: The main purpose of this file is to resolve hostnames that cannot be resolved by other way. It can also be used to resolve hostnames on small networks with no DNS server. Regardless of the type of network the computer is on, this file should contain a line specifying the IP address of the loopback device (127.0.0.1) as localhost.localdomain. For more information, see the hosts page.
- /etc/resolv.conf: This file specifies the IP addresses of DNS servers and the search domain. Unless configured to do the directives it accepts populate this file. For more information on this file, see the resolv.conf page.
- /etc/sysconfig/network: Specifies routing and host information for all network interfaces. For more information, see Section 4.1.23 /etc/sysconfig/network/
- /etc/sysconfig/network-scripts/ifcfg-<interface-name>: For each interface on a Red Hat Linux system, there is a corresponding interface configuration script. Each of these files provide information specific to a particular network interface. See Section 8.2 Interface Configuration Files for more information on this type of file and the directives it accepts.
