A better solution is to point the recipe's action to a special mailbox, which can be checked from time in order to look for false positives, or messages that inently matched the conditions. Once satisfied that no messages are accidentally matched, delete the mailbox and direct the action to send the messages to /dev/null.

Procmail is primarily used as a filter for email, automatically placing it in the right place to prevent manual sorting. The recipe grabs email sent from a particular mailing list and puts it in the correct folder.

```
:0:
* ^(From|CC|To).*tux-lug
tuxlug
```

Any messages sent from the tux-lug@domain.com mailing list will be placed in the tuxlug-box automatically for the MUA. Note that the condition in this example will match the message if it has the mailing list's address on the From, CC, or To lines.

Consult the Procmail online resources available from Section 11.6 Additional Resources for more detailed and powerful recipes.

# 11.4.2.6. Spam Filters

Because it called by Sendmail, Postfix, and Fetchmail upon receiving new emails, Procmail can be used as a powerful tool for combating spam.

This is particularly true when Procmail is used in conjunction with SpamAssassin. When together, these applications can quickly identify spam, or sort or destroy them.

SpamAssassin uses header analysis, text analysis, blacklists, and a spam-tracking database to quickly and accurately tag spam.

The easiest way for a user to use SpamAssassin is to place the following line near the top of the ~/.procmail file:

```
INCLUDESRC=/etc/mail/spamassin/spamassassin-default.rc
```

The /etc/mail/spamassin/spamassassin-default.rc contains a simple Procmail rule that activates SpamAssassin for all incoming email. If an email is determined to be spam, it is tagged in the header as the title is prefixed with the following pattern:

```
*****SPAM****
```

The message body of email is also preceded by a running tally of elements used to be diagnosed as spam.

To file email tagged as spam, a rule similar to the following can be:

```
:0 H
* ^X-Spam-Status: Yes
```

This rule files all email tagged in the header as spam into a mailbox called spam.

Since SpamAssassin is a Perl script, it may be necessary on busy servers to use the binary SpamAssassin daemon (spamd) and client application (spamc). Configuring SpamAssassin this way, requires root access to the host.
