
# Chapter 5. The proc File System

Much of the information here is used by the free, top, and ps commands. In fact, the output of the free command is even similar in appearance to the contents and structure of /proc/meminfo. But by looking directly at /proc/meminfo, more details are revealed:

- Mem — The current state of physical RAM in the system, including a full breakdown of used, free, shared, and cached memory utilization in bytes.
- Swap — The total, used, and free amount of swap space, in bytes.
- MemTotal — Total amount of physical RAM, in kilobytes.
- MemFree — The amount of physical RAM, in kilobytes, left unused by the system.
- MemShared — Unused with 2.4 and higher kernels but left in compatibility with earlier kernel versions.
- Buffers — The amount of physical RAM, in kilobytes, used for buffers.
- Cached — The amount of physical RAM, in kilobytes, used as cache memory.
- Active — The total amount of buffer or cache pages, in kilobytes, that is active in use.
- Inact_dirty — The total amount of buffer or cache pages, in kilobytes, that may be free and available.
- Inact_clean — The total amount of buffer or cache pages, in kilobytes, that are free and available.
- Inact_target — The net amount of allocations per second, in kilobytes, averaged over one minute.
- HighTotal and HighFree — The free amount of memory, in kilobytes, that is not directly mapped into kernel space. The HighTotal value can vary based on the type of kernel used.
- LowTotal and LowFree — The free amount of memory, in kilobytes, that is directly mapped into kernel space. The LowTotal value can vary based on the type of kernel used.
- SwapTotal — The total amount of swap available, in kilobytes.
- SwapFree — The amount of swap free, in kilobytes.

## 5.2.10. /proc/misc

This file lists miscellaneous drivers registered on the miscellaneous major device, which is device number 10:

```
135 rtc
1 psaux
134 apm_bios
```

The first column is the minor number of each device, while the second column shows the driver in use.

## 5.2.11. /proc/modules

This file displays a list of all modules loaded into the kernel. Its contents will vary based on the configuration and use of your system, it should be organized in a similar manner to this sample /proc/modules file output:

```
ide-cd 27008 0 (autoclean)
cdrom 28960 0 (autoclean) [ide-cd]
soundcore 4100 0 (autoclean)
agpgart      31072 0 (unused)
binfmt_misc 5956 1
iscsi        32672 0 (unused)
scsi_mod     94424 1 [scsi]
autofs       10628 0 (autoclean)
tulip        46808 1
ext3       60352 2
njbd          39192 2 [ext3]
```

The first column contains the name of the module. The second column refers to the memory of the module, the third column lists whether the module is currently loaded (1) or unloaded (0). The final column specifies whether the module can unload itself automatically after a period without use (autoclean) or if it is not being utilized (unused). A module with a name listed in brackets (( )) indicates that the module depends upon another module to be present in order to function.

## 5.2.2. /proc/mounts

This file provides a list of all mounts used by the system:

```
rootfs / rootfs rw 0 0
/dev/sda2 ext3 rw 0 0
/proc /proc rw 0 0
/dev/hda1 /boot ext3 rw 0 0
none /dev/pts dev rw 0 0
none /dev/shm tmpfs rw 0 0
none /proc/sys/fs/binfmt_misc binfmt_misc rw 0 0
```

The output found here is similar to contents of /etc/mtab, except that /proc/mounts is more-to-date.

The first column specifies the device that is mounted, the second column revealing the mountpoint, and the third column lists the file system type, and the fourth column tells you it is mounted read-only (ro) or read-write (rw). The fifth and sixth columns are dummy values designed to match the format used in /etc/mtab.

## 5.2.3. /proc/mtr

This file refers to the current Memory Type Range Registers (MTRRs) in use with the system. If the system architecture supports MTRRs, the /proc/mtr file may look similar to this:

```
reg00: base=0x00000000 (MB), size=64MB: write-back, count=1
```

MTRRs are used with the Intel P6 processors (Pentium II and higher), and they control processor access to memory ranges. When using a video card on a PCI or AGP bus, a properly configured /proc/mtr file can increase performance over 150%.

Most of the time, this value is properly configured by default. More information on manually configuring this file, can be found online at the following URL: http://www.linux.org/kernel/v2.doc/mtr.txt.

## 5.2.24. /proc/partitions

Most of the information here is little importance to the user, except for the following columns:

- major — The number of the device with this partition. The major number in our example (3) corresponds with block device ide0 in /proc/devices.
- minor — The number of the device. This serves to separate the partitions into different devices and relates to the number at the end of the partition.
- blocks — The number of physical disks contained in a particular partition.
- name — The name of the partition.

## 5.2.26. /proc/slabinfo

This file gives information about memory usage on the slab level. Linux kernels greater than version 2.2 use slab pools to manage memory above the page level. Commonly used objects have their own slab pools. The following is a portion of a typical /proc/slabinfo file:

| slabinfo - version: 2.1 | | | | | |
| --- | --- | --- | --- | --- |
| kmem_cache | 64 | 68 | 112 | 2 | 1 |
| nfs_write_data | 0 | | 384 | 0 | 0 |
| nfs_read_data | 0 | 160 | 0 | 16 | 1 |
| nfs_page | 0 | 200 | 96 | 5 | 1 |
| ip_filash | 10 | 113 | 32 | 1 | 1 |
| journal_head | 51 | 7220 | 48 | 2 | 1 |
| revoke_table | 2 | 253 | 12 | 1 | 1 |
| revoke_record | 0 | | 32 | 0 | 0 |
| clip_cache | 0 | | 128 | 0 | 1 |
| ip_mrt_cache | 0 | | 96 | 0 | 1 |

The values in this file follow order: cache name, number of active objects, number of total objects, size of the object, number of active slabs (blocks) of the objects, total number of slabs of the objects, and the number of pages per slab.

Note that in this case an object is in use.

## 5.2.27. /proc/stat

This file tracks a variety of different statistics about the system since it was last started. The contents of /proc/stat, which can be quite long, begins like this:

```
cpu 1139111 3689 234449 8437914
cpu0 1139111 3689 234449 8437914
page 2675248 856596
swap 10022 1926
intr 932323 8575613 174412 0 3 0 6 0 1 428620 0 60330 0 136830 5538681
disk (sda,0): (1408049,445601,5349480,962448,17135856)
ctxt 27269447
time 86490134
processes 206458
```

Some of the popular statistics include:

- cpu Measures the number of jiffies (one/tenth of a second) the system has been in user, user mode with low priority (nice), system mode, and in idle task, respectively. The total for all CPUs is given at the top, while each individual CPU is listed below with its out statistics.
- page The number of memory pages the system has written in and out to disk.
- swap The number of swap pages the system has brought in and out.
- intr The number of interrupts the system has experienced.
