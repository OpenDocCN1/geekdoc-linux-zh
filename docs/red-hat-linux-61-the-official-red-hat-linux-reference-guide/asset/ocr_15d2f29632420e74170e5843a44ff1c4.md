# 7.3.10. DRI

The optional DRI section specifies parameters for the Direct Rendering Infrastructure (DRI). DRI is an interface which allows multiple 3D applications to take advantage of 3D hardware acceleration capabilities into most modern video hardware. In addition, DRI can improve 2D performance via hardware acceleration, if supported by the video card's driver.

This section is ignored unless DRI is enabled in the Module section.

The following example illustrates a typical DRI section:

```
Section "DRI"
Group 0
Mode 0666
EndSection
```

Since different video use DRI in different ways, do not alter the values for this section first referring to the /usr/X11R/lib/X11/doc/README.file.

# 7.4. Fonts

Red Linux uses two methods to manage fonts and display under XFree86. The new Config font subsystem simplifies font management and provides advanced display features, such as antialiasing. This system is used automatically for applications programmed using the Qt 3 or GTK+2 graphical toolkit.

For compatibility, Red Hat includes the original font subsystem, called the core X font system, which is over 15 years old, is based around the X Font Server (xfs).

This section discusses how to configure fonts for X using both systems.

# 7.4.1. Fontconfig

The Fontfont subsystem allows applications to directly access fonts on the system and Xft or other rendering mechanisms to render Fontconfig fonts with advanced antialiasing. Graphical applications can use the Xft library with Fontconfig to draw text to the screen.

Over time, the Fontconfig/Xft font subsystem will replace the core X font subsystem.

> Important

The Fontconfig font subsystem does not work for OpenOffice.org and Abiword, which use their own font rendering technology.

It is important to note that Fontconfig shares the /etc/fonts/fonts.conf configuration file, which replaces the /etc/X11/XftConfig. The Fontconfig configuration file should not be edited by hand.
