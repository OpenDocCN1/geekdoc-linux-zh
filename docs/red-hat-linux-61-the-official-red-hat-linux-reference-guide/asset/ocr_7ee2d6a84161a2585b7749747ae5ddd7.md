# Chapter 7. The X Window System

+   - metacity — The Metacity window manager is the default window manager for the GNOME desktop environment. It is a simple and efficient window manager that supports custom themes.

+   - mwm — The Motif window manager, is a basic, standalone window manager. Since it is designed to be a standalone window manager, it should not be used in conjunction with the GNOME or KDE desktop environments.

+   - sawfish — The Sawfish window manager is a fully featured window manager which was the default for the GNOME desktop environment until the release of Red Linux 8.0. It can be used either standalone or with a desktop environment.

+   - twm — The minimalist Manager, which provides the basic tool set of all the window managers and can be used standalone or with a desktop environment. It is installed as part of XFree86.

These window managers can run without desktop environments to gain a better sense of their differences. To do this, you type `xinit -e <path-to-window-manager>` command, where `<path-to-window-manager>` is the location of the window manager binary file. The binary file can be found by typing `<window-manager-name>`.

# 7.3. XFree86 Server Configuration Files

The XFree86 server is a single executable (`/usr/X11R/bin/XFree86`) that dynamically loads any X server modules at runtime from `/usr/X11R/lib/modules/` directory. Some of these are automatically loaded by the XFree86 server, while others must be specified in the XFree86 server configuration file.

The XFree86 server and associated configuration files are stored in the `/etc/X11/` directory. The configuration file for the XFree86 is `/etc/X11/XFree86Config`. When Red Hat Linux is installed, the configuration files for XFree86 are created using information gathered about the system installation process.

# 7.3.1. XFree86Config

While there is a need to manually edit `/etc/X11/XFree86Config`, it is useful to know about the various sections and optional parameters available, especially when troubleshooting.

# 7.3.1.1. The Structure

The `/etc/X11/XFree86Config` file is comprised of many different sections which address specific aspects of the system hardware. Each section begins with a Section `<section-name>` line where `<section-name>` is the title for the section) and ends with an End line. Within each of the sections, lines containing option names and at least one option value, occasionally in quotes.

Lines with a hash mark [#] are not read by the XFree86 server and are used for human-readable comments.

Some options within the `/etc/X11/XFree86Config` file accept a boolean switch which turns the feature on off. Accept boolean values are:

+   - 1, on, true or yes — Turns the option on.
- 0, off, false or no — Turns the option off.
