# redhat Colophon

The Red Hat Linux manuals are written in DocBook SGML v4.1 format. The HTML and PDF formats are produced using DSSSL stylesheets and custom jade wrapper scripts. The DocBook SGML files are written in Emacs with the help of PGML mode.

LeSage created the admonition graphics (note, tip, important, caution, and warning). They may be freely redistributed with the Red Hat documentation.
