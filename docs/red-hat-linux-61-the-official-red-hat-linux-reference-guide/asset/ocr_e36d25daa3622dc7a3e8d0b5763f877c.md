# Important

If modifying the original file, please note that it is of paramount importance that the httpd.conf contains the following directive:

```
Include conf.d/*.conf
```

Omission of this directive will result in the failure of all modules packaged in their own RPMs (such as mod_perl, php, and mod_ssl).

# 10.2.1.4. Global Environment Changes

The following directives have been removed from Apache HTTP Server 2.0's configuration:

+   - ServerType — The Apache HTTP Server can only be run as ServerType standalone making this directive irrelevant.
- AccessConfig and ResourceConfig — These directives have been removed since they mirror the functionality of the Include directive. If the AccessConfig and ResourceConfig directives are set then replace them with Include directives.

To ensure that the files are read in order by the older directives the Include directive should be placed at the end of httpd.conf, with the one corresponding to ResourceConfig preceding the corresponding to AccessConfig. If using default values, then explicitly include them as conf/srm.conf and conf/access.conf files.

# 10.2.2. Main Server Configuration

The main server section of the configuration file sets up the main server, which responds to any requests that are not handled by a <VirtualHost> definition. Values here provide defaults for any <VirtualHost> containers defined.

The directives used in this have changed little between Apache HTTP Server 1.3 and 2.0. If the main server configuration is heavily customized it may be easier to modify the configuration file to suit Apache HTTP Server 2.0. With users with only lightly customized main server sections should change their changes into the default 2.0 configuration.

# 10.2.2.1. UserDir Mapping

The UserDir directive is used to enable URLs such as http://example.com/~bob to map a subdirectory within the home directory of the user bob, such as /home/bob/public_html. A side-effect of this feature allows a potential attacker to determine whether a username is present on the system. For this reason, the default configuration for Apache HTTP Server 2.0 disables this directive.

To enable UserDir mapping, change the directive in httpd.conf from:

```
UserDir disable
```

to the following:

```
UserDir public_html
```

For more on this topic, refer to the documentation on the Apache Software Foundation’s website, http://httpd.apache.org/docs-2.0/mod_userdir.html#userdir.
