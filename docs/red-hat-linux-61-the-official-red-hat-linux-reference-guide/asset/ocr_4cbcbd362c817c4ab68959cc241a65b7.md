# 7.5. Runlevels and XFree86

In most cases, the default installation of Red Hat Linux configures a machine to boot into a graphical
login environment, known as runlevel 5. It is possible, however, to boot into the text-only multi-user
mode called runlevel 3 and begin an X session from them.

For more information about runlevels, refer to Section 1.4 SysV Init Runlevels.

This section reviews how XFree86 starts this script in runlevel 3 and runlevel 5.

# 7.5.1. Runlevel 3

When in runlevel 3, the best way to start an X session is to log in and type startx. The startx
command is a front-end to the xinit command which launches the XFree86 server and connects X
lients to applications. Because the user is already logged in at runlevel 3, start
does not launch a display manager or authenticate users. Refer to Section 7.5.2 for more
information about display managers.

When startx is executed, it searches for a .xinitrc file in the user's home directorynto define the desktop environment and possibly other X client applications to run. If no .xinitrc is
present, it will use the default /etc/X11/init/xinitrc file instead.

The default xinitrc script then loads user-defined files and default system files, .X-
sources, .Xmodmap, and .Xkbmap in the user's home directory and XResources, Xmodmap, and
Xkbmap in the /etc/X11/init/. The Xmodmap and Xkbmap files, if they exist, are used by the
xmodmap utility to configure the keyboard. The XResources files are read to assign specific prefer-
ences to applications.

After these options, the xinitrc script executes all scripts, located in the
/etc/X11/init/xinitrc.d/. One important script in this directory is xinput, which
configures settings with the default language.

Next, the xinitrc script tries to execute Xclients in the user's home directory and to
/etc/X11/init/Xclients if it cannot be found. The purpose of the Xclients file is to start
desktop environment or, possibly, just a window manager. The .Xclients script in the
user's home directory starts the user-specified desktop environment in the .Xclients-default file.
If .Xclients does not exist in the user's home directory, the default then /etc/X11/init/Xclients
script attempts to start another desktop environment, trying GNOME first and KDE by
twm.

The user is returned to a text mode session after logging out of X from runlevel 3.
