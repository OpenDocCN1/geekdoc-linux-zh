# Chapter 5. The proc System

# 5.2.24. /proc/partitions

Most of the information here is of little importance to the user, except for the following columns:

+   - major — The number of the device with this partition. The major number in our example (3) corresponds with the block device ide0 in /proc/devices.
- minor — The number of the device with this partition. This serves to separate the partitions into different physical devices and relates to the number at the end of the name of the partition.
- #blocks — Lists the number of physical disks contained in a particular partition.
- name — The name of the partition.
