

重力。在离开上一帧的最后一刻，速度是10m/s，但这并不意味着在已经过去的0.25秒内，粒子一直以10m/s的全速行进。例如，在0.1秒时，它的速度仅为9.02m/s。即使在更早的0.01秒时，它的速度也为9.902m/s。事实上，由于引力的存在导致了加速度，因此在上一帧之后的任何可测时间间隔内，速度都不是10m/s。这意味着，如果我们通过计算自上一帧以来的距离变化为10m/s*0.25s，我们会高估粒子行进的距离（在这种所谓的案例中是高估；一般而言，可能会高估或低估）。这种误差会随时间累积，导致所谓的*数值积分漂移*。根本问题是，我们拥有位置、速度和加速度等随时间连续变化的量，而我们在直接近似这些值时仅使用了常数。实际上，我们是在对随时间的微分方程进行积分。这是微积分中的一个概念，它有效地给出了被积量曲线下的面积（这是积分的几何解释）。我们无法规避计算的离散性，但我们可以使用更高阶的积分方案，这种方案也会考虑离散时间间隔内随时间变化的量的连续曲线变化。

所有积分方案都在一定程度上存在不稳定性，但欧拉积分特别敏感。如果连续帧之间的时间间隔太大，那么假设在时间间隔内进行线性运动所引入的误差也会变得很大。这与导致隧穿效应的现象相同。在物理例程中，这可能导致物体处于不应在的位置。如果物体的位置影响其他物体，那么这些其他物体也将处于错误的位置，具有错误的速度和加速度。最终，累积误差变得过大，整个系统变得不稳定并表现出不符合实际的行为。

**注意** 对时间步长大小的敏感性引出了*稳定性条件*的概念，数值积分必须满足该条件才能收敛到真实解。在我参与的一个数值天气预报项目中，这个稳定性条件被称为库朗-弗里德里希斯-列维（CFL）*稳定性条件*，以纪念最早处理这些问题的部分科学家。这个数值天气预报包也需要对量随时间进行积分；如果时间步长太大，整个解就会变得不稳定。

## 人工智能

另一个可以让3D应用更具可信度的令人兴奋的领域是人工智能。人工智能（AI）可以被视为研究如何使计算机以在人类观察者看来似乎具有智能的方式做出响应的学科。在交互式3D应用（尤其是游戏）的语境中，这意味着在虚拟世界中创建实体，使其看起来是活的，并且表现出人类可能会表现出的行为方式。例如，示例程序 `collide` 中的搜索者对象并不智能。它们随机旋转和移动，甚至试图直线撞向墙壁。人类通常不会这样做。

在游戏中，AI的一个重要部分是路径寻找。物体需要从世界的一个区域移动到另一个区域以完成特定目标。来自机器人领域的研究在该领域产生了成果，这些成果同样可以很好地应用于3D程序。在我们讨论摄像机跟踪时，我们已经看到了一个路径寻例程。实际上，摄像机跟踪可以被视为一种简单形式的AI。摄像机必须自行决定如何保持主体在视线内。有时，路径寻找问题会从3D简化为2D；换句话说，物体被限制在2D中寻找路径，而不是在3D中。这可以使算法更简单，因为2D路径寻找本质上是一个2D迷宫求解问题。Elaine Rich和Kevin Knight的《人工智能（第二版）》描述了进行路径寻找的两种方法：使用势场，其中物体被其目标吸引并远离障碍物；以及使用可见性图，其中场景内几何体的每个顶点都连接到从该顶点可见的所有其他顶点 [RICH91]。两个顶点之间的可见性也意味着这两个顶点之间存在一条自由路径；因此，遍历可见性图中从物体到目标的最短路径。由于物体很可能被包围在一个边界球内，它无法完全到达可见性图中的每一点（因为它会先与多边形碰撞），所以我们在构建可见性图时，可以根据边界球的半径将所有顶点从其多边形上人工偏移。这形成了一个构型空间，它是用于路径寻找的实际基础空间的修改版本。

AI还通常涉及构建图并在这些图中搜索一个解或问题的最优解。可见性图就是其中一个例子；在这种情况下，最优解是最短路径，但任何通往目标的解也是正确的。图搜索可以以典型的穷举深度优先或广度优先方式进行。来自AI领域的一种更好的技术是“最佳优先搜索”，其中评估下一个可能节点中的每个节点的潜在成本，并选择下一个最有希望、成本最低的节点。如果搜索一条分支变得越来越没有希望，该分支的搜索就会暂时暂停，以探索其他更有希望的路径。我们甚至可能最终回到最初暂停的分支，因为它可能再次变得比所有其他分支更有希望。这是对AI领域中著名的“*A* 算法”的一种简化。

一些非过程化语言可用于更自然地表达和实现目标导向的行为。示例包括语言PROLOG和LISP，两者在AI领域都得到广泛使用。有趣的是，Makefile在非常相似的意义上也是非过程化的；目标是编译目标程序，而推理规则是我们提供的依赖关系。目标导向的AI编程可以取类似的形式，计算机可能会尝试推理为什么你在几秒钟内躲在墙后而没有开火。也许你没有弹药，或者也许你正在计划伏击。我们可以在非过程化语言中编程规则，允许计算机基于其观察得出结论。

AI还可以意味着在计算机行为中引入不完美。人类并不总是表现出可预测的行为，或总是命中目标。通过在逻辑中引入一些随机元素，并允许一些自主决策，行为可以表现得更加自然和智能。

使用状态机并拥有一系列预定义的行为供选择是另一个有用的技术。例如，如果我们模拟狗的行为，它可能有 SLEEPING（睡觉）、HUNGRY（饥饿）、ANGRY（生气）、FRIENDLY（友好）等状态。根据外部输入——时间的流逝、玩家和其他物体的动作等——会有确定的状态间转换。然后，根据状态，狗对其周围环境的反应会不同。如果你走过一只处于 FRIENDLY 状态的狗，它可能会跳起来问候你，或者什么都不做。如果你走过一只处于 ANGRY 状态的狗，它可能会开始追你，或者咬你。即使没有来自环境的输入，状态仍然可以控制行为，以给人一种物体仍然活跃和正在思考的印象。

最后，AI 不需要复杂才能有效。试着观察行为，问问自己为什么你会或不会以某种方式行事，然后尝试编程出正确的行为。例如，取 collide 程序中的搜索者对象。为什么它们看起来不智能？它们没有目标。此外，它们的随机旋转看起来很奇怪。因此，使它们更智能的第一步可以是给它们一些目标——例如，保持在玩家一定距离内。我们还可以降低随机旋转的概率，并确保物体总是在，比如说，10秒内恢复到直立方向。这将使物体“倾向于”保持直立，就像人类倾向于偏好以直立视角观看场景一样。

AI 和物理一样，是一个庞大的领域。如你所料，我们在这里仅仅触及了表面。
