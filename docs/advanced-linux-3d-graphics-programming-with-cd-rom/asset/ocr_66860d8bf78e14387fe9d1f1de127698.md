# A Software Z Buffer: Class \(l3d\_rasterizer\_3d\_zbuf\_sw\_imp\)

Class $l3d\_rasterizer\_3d\_zbuf\_sw\_imp$ is the $l3d$ software rasterizer implementing z buffering. It draws textured polygons into a z buffer. The implementation is a fairly simple extension of the textured polygon drawing routine. Since we already need to interpolate the 1/z values across the polygon for texture mapping, all we need to do for z buffering is to store these values in a z buffer, and to compare each pixel's 1/z value against the 1/z value in the z buffer to see if the current pixel should be drawn or not.
