The class 13d_screen_info_rgb, subclassed from 13d_screen_info, represents screen information for X TrueColor visuals or other color models based upon a direct specification of red, green, and blue pixel values. The source file is si_rgb.cc. The class 13d_screen_info_indexed (file si_1idx.cc) represents screen information for X PseudoColor visuals or other color models based upon an indexed or paletted color model.
