When you see the matrix product $MP$, think of this as answering the question “$P$, which has been specified relative to $M$, is at what location in world coordinates?” When you see $M^{-1}P$, think of this as answering the question “$P$, which has been specified in world coordinates, is at what location relative to $M$?”

# # The I3d Library Classes

This book relies on the use of a series of C++ library classes implementing all of the 2D and 3D graphics concepts described in the previous sections. This library is called the I3d library. It is developed incrementally in the introductory companion book, *Linux 3D Graphics Programming*. In this book, we use the classes presented in the first book, and continue to build on these classes to illustrate newer and more advanced concepts. The I3d classes are on the CD-ROM and are also available for download from the Internet at `http://www.linux3dgraphicsprogramming.org`.
