Overridden method `determine_selected_face_nums` is the second most significant method in `blender_at.`. It determines which faces are selected by sending Blender keystrokes to separate and save the selection and the original mesh; then, it searches for the selected faces within the original mesh and stores their index numbers in the `selected_faces` list.
