# Classes \(\texttt{13d\_halfspace}\) and \(\texttt{13d\_bsptree}\)

Class \(\texttt{13d\_bsptree}\) is the class representing the nodes of a BSP tree and the operations which can be performed on the tree. The individual nodes of the BSP tree are instances of class \(\texttt{13d\_halfspace}\). Each \(\texttt{13d\_halfspace}\) represents a region of space, can store a 3D object (list of polygons) located within the half space, can store a splitting plane, and can have child nodes.

# Listing 5-1: halfspace.h

```
```
#ifdef _BSPTREE_H
#define _BSPTREE_H
#include "../tool_os/neeman.h"

class 13d_halfspace;
class 13d_object_clippable_boundale;
class 13d_object;
class 13d_bsptree {
protected:
  void permanently_merge_objects(13d_object *dest, 13d_object *src);
  void _recursive_delete_Tree(13d_halfspace *root);

public:
  13d halfspace *root;
  13d_bsptree(void);
  virtual ~13d_bsptree(void);
  void compute_for_object(13d_halfspace *root,
        13d_object_clippable_boundale *rest_of_obj);

  void push_polys_to_children
    (13d_halfspace *tree,
     13d_object_clippable_boundale *unsplit_obj_from_parent);

  void make_widespace_mesheis(13d_halfspace *tree);
  void print_stats(13d_halfspace *tree);
};
#endif
