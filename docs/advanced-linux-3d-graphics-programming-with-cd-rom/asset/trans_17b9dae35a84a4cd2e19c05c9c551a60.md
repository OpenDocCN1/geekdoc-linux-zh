
environment. 如果一个多边形的两个顶点位于环境贴图立方体的不同面上，我们可以将该多边形分割成两个或更多的部分，每个部分仅位于立方体的一个面上。

在使用球面方法时，环境贴图是一个圆形图像，表示环境在球体上正交反射时的外观。在这种情况下，该环境贴图可称为*球面贴图*。从物理上讲，可以通过使用相机从非常远处拍摄一个大尺寸铬球的照片来创建这样的球面贴图（以模拟正交观察）。在算法上，我们可以使用图像扭曲技术将立方体环境贴图扭曲成球体，该技术记录在*《高级 OpenGL 游戏开发》* [GOLD98] 中。一旦你拥有了这样的环境贴图，就可以使用以下公式将 3D 反射向量 *r* 映射到环境贴图中的 2D (u,v) 值（*m* 值是计算中使用的临时幅度值，之后不需要）：

```
m = \sqrt{r_2^2 + r_3^2 + (r_2+1)^2}

u = \frac{r_2}{m} + 0.5

v = \frac{r_3}{m} + 0.5
```

OpenGL 直接支持球面映射，这意味着它可以使用上述方程自动为你计算这些纹理坐标。执行 OpenGL 球面映射的示例代码片段如下。

```
glTexGeni (GL_S, GL_TEXTURE_GEN_MODE, GL_SPHERE_MAP);

glTexGeni (GL_T, GL_TEXTURE_GEN_MODE, GL_SPHERE_MAP);

glEnable (GL_TEXTURE_GEN_S);

glEnable (GL_TEXTURE_GEN_T);

glEnable (GL_TEXTURE_2D);

// polygon rendering comes here, e.g. glBegin (GL_POLYGON)

glNormal3f (nx,ny,nz);

glVertex3f (x,y,z);

// etc.. glEnd (GL_POLYGON);
```

调用 glTexGeni 会开启 OpenGL 自动纹理生成，这意味着不需要调用 glTexCoord4 来指定显式的纹理坐标；这与第 2 章中的 Mesa 光栅化器的纹理映射形成对比。

对于球面贴图的生成，Mark Kilgard 编写了一个名为 LibGLSnap 的库，它创建一个立方体环境贴图，然后将其扭曲为球面贴图，以供 OpenGL 球面映射使用。详情请参见 *《高级 OpenGL 游戏开发》* [GOLD98]。此类球面贴图可以动态生成，因此只要环境发生变化，反射也会随之变化。如果环境没有变化，可以计算一次静态球面贴图并重复使用。

> **注意** Blender 支持使用环境映射渲染图像，并用于创建图 7-1 中环境映射圆柱体的图像。你必须使用 Blender 中的 TextureButtons 选择要应用于材质的 EnvMap 纹理，该纹理反过来又应用于网格。在 Blender 中渲染带有环境映射的场景时，请注意 Blender 会短暂渲染六张小图像，这暗示它使用了立方体贴图方案的某种变体。通过 TextureButtons 中的 SaveEnvMap 按钮，Blender 允许你将计算出的环境贴图保存为 2D Targa 图像文件（你可以使用 GIMP 程序将其转换为其他格式），该文件包含六张小方形图像，每一张对应立方体的一个面。要在你的程序中使用此环境贴图，你必须自行实现立方体贴图，或者将图像扭曲成球体并使用 OpenGL 的球面映射。有关使用 Blender 进行环境映射的教程，请参见 Blender 主页 http://www.blender.nl。

# 广告牌（Billboards）

广告牌（Billboard）是一个始终自旋以直接面向观察者的单个纹理映射多边形。广告牌（Billboard）也常被称为精灵（Sprite）。广告牌（Billboard）上的纹理图像通常是更复杂的 3D 对象的 2D 图像。例如，一个 2D 广告牌（Billboard）可以包含一个预先渲染的复杂树木模型图像，该模型包含数百个多边形。然后，我们可以通过仅渲染一个多边形来近似树木的视觉外观。因此，使用广告牌（Billboard）的目的是通过使用单个纹理映射多边形来创造复杂几何形状的错觉。

![](img/a19d4e8b1d7eb6387691dc6c865430e6_500_0.png)

图 7-4：广告牌（Billboard）始终改变其位置以面向观察者。

定义广告牌（Billboard）何时“面向观察者”主要有两种方式。在一种情况下，广告牌（Billboard）始终围绕所有三个轴旋转，使其完美平行于屏幕。我们将此类广告牌（Billboard）称为屏幕对齐广告牌（screen-aligned billboards）。此类广告牌（Billboard）可用于打印文本（这也是广告牌（Billboard）名称的原始来源），或用于显示爆炸或烟雾，如下所示。在另一种情况下，广告牌（Billboard）只允许围绕一个轴旋转，通常是它自身的向上轴。我们将此类广告牌（Billboard）称为轴对齐广告牌（axis-aligned billboards）。这种方案可用于建模树木。

为了执行任一种广告牌（Billboard）的实际旋转，我们必须构建一个旋转矩阵，从广告牌（Billboard）的当前方向旋转到期望的方向。将广告牌（Billboard）想象成具有自身局部坐标系的相机。VUP 轴指向广告牌（Billboard）的上方，VRI 轴水平指向广告牌（Billboard）内部，VFW 轴指向广告牌（Billboard）的表面法线方向。这些轴是广告牌（Billboard）的当前方向。然后，用向量表示期望的方向。对于屏幕对齐广告牌（Billboard），期望的方向是相机方向，具有相同的 VUP 向量，但 VRI 和 VFW 向量是反向的。对于轴对齐广告牌（Billboard），期望的对齐可以表示为围绕广告牌（Billboard）自身 VUP 向量旋转当前对齐。给定期望的对齐后，我们可以构建一个矩阵，将原始对齐转换为期望的对齐。

![](img/a19d4e8b1d7eb6387691dc6c865430e6_501_0.png)

> 图 7-5：屏幕对齐广告牌（Billboard）。无论相机方向如何，广告牌（Billboard）始终面向相机。

![](img/a19d4e8b1d7eb6387691dc6c865430e6_501_1.png)

> 图 7-6：轴对齐广告牌（Billboard）。广告牌（Billboard）只允许绕其垂直轴旋转，这意味着从上方的视角不会导致广告牌（Billboard）向后倾斜。

通常，广告牌（Billboard）会有一个所谓的 Alpha 通道。这是因为广告牌（Billboard）多边形通常是矩形的（为了简单起见），但广告牌（Billboard）上的图像通常不是矩形的。这意味着广告牌（Billboard）矩形的某些部分未被使用。我们不希望绘制广告牌（Billboard）未使用的部分，因为这看起来像是将矩形图片粘在整个场景的顶部——这确实是我们所做的，但使用 Alpha 通道可以让它看起来更好。Alpha 通道是一种特殊的颜色类型，指定图像的透明度。因此，我们可以使用 Alpha 通道将广告牌（Billboard）多边形的未使用部分设置为透明，其余部分设置为不透明。

Alpha 通道在内存中通常由一定数量的位物理表示。例如，如果我们有一个 24 位红绿蓝（RGB）颜色模型，红、绿、蓝各 8 位，那么我们可以为 Alpha 通道引入额外的 8 位，形成一个 32 位红绿蓝 Alpha（RGBA）颜色模型。图形加速硬件通常直接支持 Alpha 通道，而在软件中手动实现 Alpha 需要光栅化器检查 Alpha 值并相应地组合新颜色与先前颜色。（如果只有 1 位 Alpha 通道，情况会稍微容易一些，因为不需要进行颜色混合；要么看到 Alpha 为 0 的旧颜色，要么看到 Alpha 为 1 的新颜色。）

![](img/a19d4e8b1d7eb6387691dc6c865430e6_501_2.png)

> 图 7-7：Alpha 通道允许我们透过广告牌（Billboard）的未使用部分进行观察，从而产生自然的外观。左侧的广告牌（Billboard）不使用 Alpha 通道，可以明显看出它们是矩形的纹理多边形；右侧的广告牌（Billboard）使用 Alpha 通道。

广告牌（Billboard）可以与其他技术结合使用，以更少的多边形创建视觉特效。我们现在来看看其中一些技术。

# 镜头光晕（Lens Flare）

镜头光晕是由真实世界透镜的不完美性在遇到非常明亮的光线时引起的一种现象，导致最终图像中出现闪烁或光晕。我们可以使用广告牌（Billboard）来模拟镜头光晕，从而在图像中呈现或强调明亮光线的外观。我们只需渲染或绘制一个看起来像小闪烁点的 2D 图像纹理，然后将此纹理绘制到一个屏幕对齐的广告牌（Billboard）上。我们可以在渲染完所有其他几何体之后渲染镜头光晕，这样镜头光晕看起来就永远不会被其他几何体遮挡。这种遮挡会清楚地表明镜头光晕仅仅是一个纹理多边形。

![](img/a19d4e8b1d7eb6387691dc6c865430e6_502_0.png)

我们可以通过视线和距离参数来控制镜头光晕的绘制。例如，我们可以将明亮的光源建模为位于墙后。如果从相机到光源存在一条直视视线，我们就可以绘制镜头光晕广告牌（Billboard）；否则，我们不绘制它。这会产生期望的效果，即一旦光源可见，镜头光晕就会突然出现。我们还可以通过使用距离公式，在靠近光源时绘制更大的镜头光晕广告牌（Billboard），在远离时绘制更小的。虽然镜头光晕会随着我们靠近它而由于正常的透视效果自动在视觉上变大，但我们可以通过使镜头光晕随我们靠近或远离而呈指数级地增长或缩小来夸大这种效果。我们希望夸大镜头光晕随距离的增长或缩小，因为镜头光晕不应该看起来像我们可以正常接近的物理空间中的点；相反，它是一种取决于我们观察位置的透镜伪影。
