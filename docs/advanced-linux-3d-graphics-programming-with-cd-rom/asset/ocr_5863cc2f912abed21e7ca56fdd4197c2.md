+   Type conversions. A variable of type `13d_real` can be converted to and from an integer or floating-point value through the macros `13d_real_to_float`, `13d_real_to_int`, `float_to_13d_real`, and `int_to_13d_real`. Furthermore, a variable of type `13d_real` can be converted to and from a fixed-point number through the macros `13d_real_to_fixed` and `fixed_to_13d_real`.

+   Addition and subtraction. Variables of type `13d_real` may be added to and subtracted from other variables of type `13d_real` with the normal plus (+) and minus (-) operators. Addition and subtraction with variables of any other type must first use one of the type conversion macros to convert the variable of the other type to `13d_real`.

+   Multiplication and division. Variables of type `13d_real` can be multiplied or divided by variables of type `13d_real` or of type `int` only. Such multiplications or divisions must use one of the following macros, all of which return a type of `13d_real`: `13d_mulrr` (multiplies an `13d_real` by an `13d_real`), `13d_mulri` (multiplies an `13d_real` by an `int`), `13d_divrr` (divides an `13d_real` by an `13d_real`), and `13d_divri` (divides an `13d_real` by an `int`).

+   Other functions. The `iceil` function returns the integer ceiling of (i.e., the smallest integer larger than) an `13d_real`. `ifloor` returns the integer floor of (the largest integer smaller than) an `13d_real`. The function `13d_sqrt` returns an `13d_real` representing the square root of the given `13d_real` argument.

> **NOTE** The reasons for not making `13d_real` a class are discussed in the Appendix of the introductory companion book, *Linux 3D Graphics Programming*.

If we choose to use floating-point math (at compile time via a `#define`), then the `13d_real` macros do nothing other than call the ordinary cast, multiplication, or division operators. If we choose to use fixed-point math (again, at compile time via a `#define`), the `13d_real` macros are defined quite differently, applying the somewhat arcane rules for fixed-point math to simulate real-valued computations using purely integer arithmetic.

An unfortunate consequence of using the `13d_real` macros for multiplication and division is that this leads to somewhat awkward code. For instance, the following computation with floating-point values:

```
```c
x = a * ( ( b + c ) / d )
```
```

would need to be expressed with `13d_real` types as:

```
```c
x = 13d_mulrr( a , 13d_divrr( b + c , d ) )
```
```

The multiplication and division must therefore be realized as nested macro invocations. Notice, however, that no macro invocation is necessary for the addition of `b` and `c`, since addition and subtraction of `13d_real` types can be done with the normal addition and subtraction operators.
