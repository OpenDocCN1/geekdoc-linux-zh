# Tip

To change your keyboard type post-installation, become root and use the /usr/sbin/kbdconfig command, or you can type setup at the root prompt (seen as [root@localhost root]#).

To become root, type su at the shell prompt in a terminal window and then press [Enter]. Then, enter the root password and press [Enter].
