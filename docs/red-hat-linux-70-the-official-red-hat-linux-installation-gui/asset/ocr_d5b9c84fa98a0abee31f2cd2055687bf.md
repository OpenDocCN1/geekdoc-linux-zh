# Please Note

Manual partitioning is outside the scope of this chapter. Although **Disk Druid** will be briefly covered, `fdisk` will not be discussed. For complete instructions on using **Disk Druid** or `fdisk`, please refer to the *Official Red Hat Linux Reference Guide* on the Documentation CD.

At this point, it’s necessary to let the installation program know where it should install Red Hat Linux. This is done by defining mount points for one or more disk partitions in which Red Hat Linux will be installed. You may also need to create and/or delete partitions at this time (refer to Figure 6–7, *Partitioning with Disk Druid* ).
