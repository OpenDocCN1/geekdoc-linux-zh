You should make the root password something you can remember, but not something that is easy for someone else to guess. Your name, your phone number, **qwerty, password, root, 123456**, and **ant eater** are all examples of poor passwords. Good passwords mix numerals with upper and lower case letters and do not contain dictionary words: **Aard387vark** or **429BkIIKT**, for example. Remember that the password is case-sensitive. Write down this password and keep it in a secure place.
