# 6.16 Creating User Accounts

Next, create a user account for yourself which is for your everyday use. A user account allows you to safely and easily log into your computer without having to be root. The password you enter must be at least six characters long and is not echoed to the screen. Enter the password twice; if the two passwords do not match, the installation program will prompt you to enter them again.
