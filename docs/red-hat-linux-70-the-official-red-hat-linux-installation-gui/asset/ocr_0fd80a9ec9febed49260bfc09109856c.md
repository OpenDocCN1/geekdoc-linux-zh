The `Xconfigurator` utility gives you the opportunity to configure the X server for your system.

First, `Xconfigurator` presents a list of monitors (see Figure 6-24, *Monitor Setup Dialog*). If your monitor is listed, select it and press [Enter]. Otherwise, select **Custom**.
