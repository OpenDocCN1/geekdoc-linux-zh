# 5.15.1 A Brief Introduction to GNOME

GNOME is a powerful graphics-driven environment. GNOME includes a panel (for starting applications and displaying status), a desktop (where data and applications can be placed), multiple window managers (which control the look and feel of your desktop), and a standard set of desktop tools and applications.

GNOME allows you to set your desktop the way you want it to look and “feel.” GNOME’s session manager remembers settings and currently running programs, so once you’ve set things the way you like they’ll stay that way.
