# 8.4  Simulations

In this section, some examples will be provided to illustrate the properties of (8.3). For the algorithm (8.3), the learning rate \(\eta\) affects the learning speed and convergence of the algorithm. Since the algorithm (8.3) does not change the convergence of the original GHA, which has been discussed in Chapter 4, in this section, we will only illustrate that the number of principal directions for our PCA model thus determined will adaptively approximate the intrinsic dimensionality of a given data set with \(\eta = 0.1\) so that the data set can be compacted into a subspace with the precision \(\alpha\).
