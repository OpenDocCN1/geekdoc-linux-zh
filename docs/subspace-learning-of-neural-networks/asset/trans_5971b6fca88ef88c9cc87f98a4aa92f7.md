## 1.2 收敛性分析方法

神经网络的学习算法在实际应用中扮演着重要角色。学习算法的收敛性决定了这些应用能否成功。然而，由于这些学习算法是由随机离散时间（SDT）算法[202]描述的，直接研究其收敛性非常困难。通常，有两种方法用于分析学习算法的收敛性。传统上，基于一些随机逼近定理[14, 35, 117]，将原始的SDT算法转化为相应的确定性连续时间（DCT）算法。通过研究相应的DCT算法，可以间接解释SDT算法的收敛性。这种方法被称为DCT方法。另一种方法被称为确定性离散时间（DDT）方法。DDT方法通过对SDT算法两边取条件期望，将SDT算法转化为相应的DDT算法。DDT算法刻画了原始SDT算法的平均演化过程。DDT算法保留了原始算法的离散时间性质。DDT算法的收敛性可以为原始SDT算法的动态行为提供一些启示。

### 1.2.1 DCT方法

传统上，基于一些随机逼近定理[14, 117]，将原始的SDT算法转化为相应的确定性连续时间（DCT）算法；也就是说，算法(1.4)被转化为如下微分方程(1.5)：

$$\dot{w}(k) = \Delta w(k) \tag{1.5}$$

通过研究相应的DCT算法(1.5)，可以间接解释算法(1.4)的收敛性。由于微分方程理论的数学成就，该方法已被广泛使用；例如，参见[4, 36, 135, 136, 154, 162, 172, 192, 199]。

为了将SDT算法转化为DCT算法，必须施加一些限制性条件。其中一个条件是

\[\eta(k)>0,\quad \sum_k \eta(k)=\infty,\quad \sum_k(\eta(k))^2<\infty.\]

其中\(\eta(k)\)是SDT学习算法(1.4)的学习率。该条件意味着学习率\(\eta(k)\)必须收敛到零。然而，在实际应用中这是不现实的，因为每当步长显著增加时，存在计算舍入限制和跟踪要求。如果必须采用较小但非零的常数学习率[210]。如果学习率趋近于零，可能会显著减慢算法的收敛速度。此外，学习率不能过快趋近于零；否则，算法将在收敛到正确方向之前停止。更多讨论可参见[39, 195, 202, 210]。因此，上述条件在实际应用中是不现实的。

### 1.2.2 DDT方法

为了克服DCT方法的缺点，近年来提出了确定性离散时间（DDT）方法，用于间接研究SDT学习算法的收敛性；参见[39, 124, 195, 210]。DDT方法将SDT算法(1.4)转化为相应的DDT算法如下：

\[E\{w(k+1)\}=E\{w(k)\}+E\{\eta(k)\Delta w(k)\}.\tag{1.6}\]

然后，为了保证DDT算法的非发散性，必须首先分析算法的有界性。对于全局收敛算法，研究全局有界性。对于局部收敛算法，通过获得不变集来保证局部非收敛性。不变集定义如下。

**定义1.6** 如果对于任意\(w(0)\in S\)，从\(w(0)\)出发的算法轨迹在所有的\(k \geq 0\)下都保持在\(S\)内，则称紧集\(S\subset R^n\)为算法\(w(k+1)=f(w(k),x(k))\)的不变集。

不变集之所以引人关注，是因为它提供了一种保证算法非发散性的方法。显然，不变集的子集可能不是不变集。如果一个集合具有不变子集，并不意味该集合也是不变集[195]。

在非发散条件下，利用柯西收敛原理、不等式分析方法等来推导收敛条件并严格证明算法的收敛性。这些结果可以为原始算法提供一些启示。

DDT方法不要求学习率收敛到零，因此可以使用常数学习率。DDT算法保留了原始算法的离散时间性质，并允许学习率具有更现实的动态行为[210]。与DCT方法相比，DDT方法是间接研究SDT算法收敛性的更合理方法。

DDT算法刻画了原始SDT算法的平均演化过程。在随机环境中，随机输入对DDT方法的结果有很大影响，甚至使DDT算法的收敛条件失效[120]。在第6章中，我们提出了一种方法来避免这一问题。首先，通过直接研究原始算法，在随机环境中保证原始算法的非发散性。在此条件下，通过DDT方法分析算法的收敛性。

## 1.3 SDT算法与DDT算法之间的关系

SDT算法(1.4)和相应的DDT算法(1.6)都保留了离散时间性质。DDT算法(1.6)也可以表示为

$$\frac{1}{L}\sum_{i=1}^{L}\{w(k+1)\}=\frac{1}{L}\sum_{i=1}^{L}\{w(k)\}\pm\frac{1}{L}\sum_{i=1}^{L}\{\eta(k)\Delta w(k)\},\ L\to\infty.$$

显然，如果$L=1$，这就是SDT算法(1.4)。因此，令$L$为某个常数，我们得到了一些称为分块算法的算法。分块算法不仅在原始SDT算法和相应的DDT算法之间建立了联系，如图1.4所示，而且在SDT算法和DDT算法之间取得了一种折衷。

## 1.4 一些符号和预备知识

### 1.4.1 协方差矩阵

对于输入序列(1.2)，令$C = E[x(k)x^T(k)]$。已知协方差矩阵$C$是一个对称非负定矩阵。存在由$C$的特征向量组成的$R^n$的标准正交基。设$λ_1, …, λ_n$为$C$的所有特征值，按$λ_1 ≥ … ≥ λ_n ≥ 0$排序。假设${v_i | i = 1, …, n}$是$R^n$中的一组标准正交基，其中每个$v_i$是与特征值$λ_i$对应的$C$的单位特征向量。

对于每个$k ≥ 0$，$w(k) ∈ R^n$可以表示为

$$w(k)=\sum_{i=1}^{n}z_i(k)v_i,$$  (1.7)

其中$z_i(k)(i = 1, …, n)$是一些常数，于是

$$Cw(k)=\sum_{i=1}^{n}λ_i z_i(k)v_i=\sum_{i=1}^{p}λ_i z_i(k)v_i.$$  (1.8)

### 1.4.2 仿真数据
