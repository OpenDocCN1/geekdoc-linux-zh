# **Lemma 6.7**

Suppose that $Kurt(s_{j_0}) > 0$, $(j_0 \in Q)$ and $Kurt(s_j) \ge 0$, $j \in (Q \cup O)/j_0$. If $Kurt(s_{j_0})z_{j_0}^2(0) > Kurt(s_j)z_j^2(0)$, there must exist a constant $\xi > 0$ so that $0 < \psi(k) < 1$ for all $k \ge 0$, where

$$\psi(k)=\left[\frac{(1+\eta a)(a+3b)+\eta bKurt(s_j)z_j^2(k)}{(1+\eta a)(a+3b)+\eta bKurt(s_{j_0})z_{j_0}^2(k)}\right]^2.$$

**Proof:** For $j_0 \in Q$ and any $j \in (Q \cup O)/j_0$, from (6.7), it follows that

$$\frac{z_j^2(k+1)}{z_{j_0}^2(k+1)}=\gamma(k)\frac{z_j^2(k)}{z_{j_0}^2(k)}, \tag{6.8}$$

for all $k \ge 0$, where

$$\gamma(k)=\left[\frac{1+\eta a-\eta a\|z(k)\|^2+\eta b\bigl(Kurt(s_j)z_j^2(k)+3\|z(k)\|^2\bigr)}{1+\eta a-\eta a\|z(k)\|^2+\eta b\bigl(Kurt(s_{j_0})z_{j_0}^2(k)+3\|z(k)\|^2\bigr)}\right]^2.$$

If $Kurt(s_{j_0})z_{j_0}^2(k) > Kurt(s_j)z_j^2(k) \ge 0$, by Lemma 6.5, it holds that $0 < \gamma(k) < 1$. From (6.8), it holds that

$$z_{j_0}^2(k+1)z_j^2(k) > z_j^2(k+1)z_{j_0}^2(k) \ge 0.$$

So, it is easy to see that

$$Kurt(s_{j_0})z_{j_0}^2(k+1) > Kurt(s_j)z_j^2(k+1) \ge 0.$$

Thus, if $Kurt(s_{j_0})z_{j_0}^2(0) > Kurt(s_j)z_j^2(0) \ge 0$, it holds that

$$Kurt(s_{j_0})z_{j_0}^2(k+1) > Kurt(s_j)z_j^2(k+1), \tag{6.9}$$

for all $k \ge 0$.

Now, we will prove that if $Kurt(s_{j_0})z_{j_0}^2(0) > Kurt(s_j)z_j^2(0) \ge 0$, there must exist a small constant $\epsilon > 0$ so that $z_j^2(k) > \epsilon$ for all $k \ge 0$. Assume that this is not true. Then, it holds that $\lim_{k\to+\infty}z_j^2(k)=0$, $j_0 \in Q$. From (6.9), it holds that $\lim_{k\to+\infty}z_{j_0}^2(k)=0$, $j_0 \in (Q \cup O)/j_0$. By Lemma 6.6, it holds that

$$\lim_{k\to+\infty}\|z(k)\|^2=0.$$

This contradicts with Theorem 6.2.

Since $Kurt(s_{j_0})z_{j_0}^2(0) > Kurt(s_j)z_j^2(0) \ge 0$ and $0 < \gamma(k) < 1$ for all $k \ge 0$. From (6.8), it follows that

$$Kurt(s_{j_0})z_{j_0}^2(k+1)-Kurt(s_j)z_j^2(k+1)$$

$$=Kurt(s_{j_0})z_{j_0}^2(k+1)\left(1-\gamma(k)\frac{Kurt(s_j)z_j^2(k)}{Kurt(s_{j_0})z_{j_0}^2(k)}\right)$$

$$=Kurt(s_{j_0})z_{j_0}^2(k+1)\left(1-\prod_{l=1}^{k}\gamma(l)\cdot\frac{Kurt(s_j)z_j^2(0)}{Kurt(s_{j_0})z_{j_0}^2(0)}\right)$$

$$>Kurt(s_{j_0})z_{j_0}^2(k+1)\left(1-\frac{Kurt(s_j)z_j^2(0)}{Kurt(s_{j_0})z_{j_0}^2(0)}\right).$$
