for all $k \ge 0$. If $\frac{2\sigma}{\sigma+\lambda_p}<\|w(k)\|^2<2$, then

$$1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^T(k)Cw(k)\right)$$
$$\le 1+\eta\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)$$
$$<1,$$

for all $k \ge 0$. So, it follows

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^T(k)Cw(k)\right)\right]^2z_i^2(k)\\
&\le \left[1+\eta\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)\right]^2\|w(k)\|^2\\
&<\|w(k)\|^2,
\end{aligned}$$

for all $k \ge 0$. If $0<\|w(k)\|^2\le\frac{2\sigma}{\sigma+\lambda_p}$, then

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^T(k)Cw(k)\right)\right]^2z_i^2(k)\\
&\le \left[1+\eta\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)\right]^2\|w(k)\|^2\\
&\le \left[1+\frac{0.25}{\sigma}\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)\right]^2\|w(k)\|^2\\
&\le \left[1.5-0.25\frac{\sigma+\lambda_p}{\sigma}\|w(k)\|^2\right]^2\|w(k)\|^2\\
&\le \frac{2\sigma}{\sigma+\lambda_p}.
\end{aligned}$$

Therefore, if $w(0)\in S$ and $w(0)\notin V_{\sigma}$, then there must exist a constant $N$ so that

$$\|w(k)\|^2\le\frac{2\sigma}{\sigma+\lambda_p}<2,$$

for all $k>N. The proof is completed.

The theorems above show that the nondivergence of (2.12) is guaranteed if the learning rate satisfies a simple condition and the evolution of (2.12) is ultimately bounded.
