$$W(k+1)=W(k)+\eta\Pi(k)[W(k)C_k-\Lambda W(k)]W(k),$$

for η > 0 and k ≥ 1, where Π(k) is a diagonal matrix. Π(k) serves as a controller at time instance k, which determines whether a neuron is active or resting. The value of the diagonal element of Π(k) is always 1 or 0 and 1 always appear along the first column. If the value of the diagonal element is 1, the corresponding neuron is active. Otherwise, the neuron is resting. The initial values of all elements of Π(1) are 0, except Π₁₁(1) = 1, that is, only the first neuron is active at the initial time. It is just Π(k), which determines the number of the extracted principal directions for the improved PCA model at time instance k.

The key difference between the original GHA (8.2) and the improved GHA (8.3) is that Π(k) is added in the improved GHA. By changing the value of diagonal elements of Π(k), the algorithm (8.3) will adaptively converge to the first m principal directions of the input data set, that is, Wᵀ = [w₁, w₂, …, wₘ], so that the dimensionality of the data set can be reduced to the m-dimensional online with precision α. Here, an important problem to address is how to change the value of diagonal elements of Π(k) so that the number of principal directions for the PCA model approximates the intrinsic dimensionality of the input data set in an online manner. The following subsection will discuss this problem.
