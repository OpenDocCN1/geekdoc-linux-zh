If learning rate $\eta(k)$ converges to zero, this is not practical in applications as discussions in [40, 195, 202, 210]. Furthermore, Oja+ algorithm may suffer from the sudden divergence [48]. In this chapter, we propose to use the following adaptive learning rate:

$$\eta(k)=\frac{\xi}{w^T(k)(\mu I-C_k)w(k)},\qquad (0<\xi<1),$$

for $k\geq 0$. The proposed algorithm is given as follows:

$$\begin{aligned}
w(k+1)={}&w(k)-\frac{\xi}{w^T(k)(\mu I-C_k)w(k)}\left[C_kw(k)\\
&-w^T(k)C_kw(k)w(k)\\
&+\mu(\|w(k)\|^2-1)w(k)\right].
\end{aligned}\tag{9.2}$$

for $k\geq 0$, where $0<\xi<1$. The condition $\mu>\lambda_n$ is required for the stability reason. Clearly, this learning rate converges to a non-zero constant so that the evolution will become faster with time. However, the adaptive learning rate can prevent the weight from deviating from the right evolution direction by adjusting itself. Thus, the global convergence could be guaranteed [125]. After convergence, $w(k+1)\times w(k)$ is the extracted minor component. Considering all the advantages stated previously, we adopt the improved Oja+’s algorithm in multi-block-based MCA.

# 9.2.3  MCA Neural Network for Nonlinear Surface Fitting

In the case of nonlinear surface fitting, many nonlinear curves and hypersurfaces models can be expressed as [185]

$$a_1f_1(\mathbf{x})+a_2f_2(\mathbf{x})+\cdots+a_mf_m(\mathbf{x})+c_0=0,$$
$$\mathbf{x}=[x_1,x_2,\ldots,x_n]^T,$$

where x is the original coordinate points and $f_i(x)$ are some basis functions, that is, polynomials of the elements of x. In the quadratic case

$$a_1x_1^2+a_2x_1x_2+a_3x_2^2+a_4x_1+a_5x_2+c_0=0,$$

function $f_i(\mathbf{x})$ are defined as follows:

$$f_1(\mathbf{x})=x_1^2,\quad f_2(\mathbf{x})=x_1x_2,\quad f_3(\mathbf{x})=x_2^2,$$
$$f_4(\mathbf{x})=x_1,\quad f_5(\mathbf{x})=x_2.$$

When Gaussian noise is added to the observation data, we can use MCA neural network to estimate the right parameters $[a_1,a_2,\ldots,a_n]^T$ and $c_0$. Let $f=[f_1(x),f_2(x),\ldots,f_m(x)]^T$. We train the neural network by learning algorithm (9.2), with $x(t)$ being replaced by $f=f-E(f)$.
