for all $k \ge K_1$, where $\lambda_p < r(k) < \lambda_1$. Since $0 < \xi < 1$, it holds that

$$\begin{aligned}
\|w_l(k+1)\| &\\
&\le (1-\xi)^k\|w_l(0)\|+\xi\frac{M_l}{\sqrt{4}}\sqrt{\frac{\lambda_1}{(1-\xi)\xi\lambda_p}}\sum_{i=1}^{k}(1-\xi)^{i-1}\\
&\le \frac{M_l}{\lambda_p}\sqrt{\frac{\lambda_1}{4(1-\xi)\xi\lambda_p}}.
\end{aligned}$$

for $k \ge \max\{K_1, K_l\}$. This completes the proof.

This lemma gives a smaller ultimate bound when $k$ is sufficiently increased. Obviously, in this case, the condition $w_l(k) \notin V_0$ is met.
