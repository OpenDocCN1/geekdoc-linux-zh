If $\lambda_p < s^*$, by Lemma 3.1 and Lemma 3.2,

$$w^T(k+1)Cw(k+1) \le \begin{cases} \sigma, & \text{if } \lambda_p < s < \sigma, \\ \left[1+\xi\left(\dfrac{\sigma}{\lambda_p}-1\right)\right]^2\lambda_p, & \text{if } \lambda_p < s < s^*, \\ \left[1+\xi\left(\dfrac{\sigma}{w^T(0)Cw(0)}-1\right)\right]^2w^T(0)Cw(0), & \text{if } 0<s<\lambda_p. \end{cases}$$

Then,

$$w^T(k+1)Cw(k+1) \le H.$$

The proof is complete.

# 3.4.2  Global Convergence

Consider the same one-dimensional equation example of Section 2 with our non-zero-approaching learning rate. We have

$$w(k+1)=w(k)\left(1+\frac{\xi}{w^2(k)}(1-w(k)^2)\right), \tag{3.7}$$

for $k>0$, where $0<\xi<0.8$. Obviously, a set $\{0,-1,1\}$ is equilibrium points of the system (3.7). If $|w(k)|<1$, then $|w(k+1)|$ increases, and if $|w(k)|>1$, then $|w(k+1)|$ decreases. Clearly, in the whole interval, the weight converges to $-1$ or $1$ and $0$ is an unstable point. And then, we will rigorously prove the global convergence of (3.5).

Given an $H>0$, we define

$$S(H)=\{w\mid w^TCw\le H\}.$$

**Lemma 3.3** Given any $H\ge\bar H$, if $w(0)\in S(H)$ and $w(0)\notin V_\sigma^\perp$, then there exists constant $\theta_1>0$ and $\Pi_1>0$ such that

$$\sum_{j=m+1}^{n}z_j^2(k)\le \Pi_1\cdot e^{-\theta_1 k},$$

for all $k\ge 0$, where

$$\theta_1=\ln\left(\frac{\xi\sigma+(1-\xi)H}{\xi\lambda_{m+1}+(1-\xi)H}\right)^2>0.$$

*Proof.* Since $w(0)\notin V_\sigma^\perp$, there must exist some $i$ ($1\le i\le m$) such that $z_i(0)\ne 0$. Without loss of generality, assume that $z_1(0)\ne 0$.

From (3.6), it follows that

$$z_i(k+1)=\left[1+\xi\left(\frac{\sigma}{w^T(k)Cw(k)}-1\right)\right]z_i(k),\quad 1\le i\le m, \tag{3.8}$$
