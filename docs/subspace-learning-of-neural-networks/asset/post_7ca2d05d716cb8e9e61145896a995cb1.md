
for \(\eta(k) > 0\). The algorithm (2.11) approximates the Oja’s one unit rule when the norm of weight vector approaches one [184]. However, it shows some different dynamical behaviors. In this chapter, by studying an associated DDT algorithm, we will discuss the convergence of (2.11), which is a special case of the one unit version of Xu’s LMSER algorithm. By taking the conditional expectation \(E\{w(k+1) \mid w(0), w(i), i<k\}\), the DDT algorithm of (2.11) with a constant learning rate is given as follows:

$$w(k+1)=w(k)+\eta\left[2Cw(k)-Cw(k)w^{T}(k)w(k)-\left(w^{T}(k)Cw(k)\right)w(k)\right]. \tag{2.12}$$

for \(\eta > 0\) and \(C = E[x(k)x^{T}(k)]\) is the covariance matrix.

From (1.7), (1.8), (2.12), it holds that

$$z_i(k+1)=\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]z_i(k), \tag{2.13}$$

for \(k \ge 0\), where \(i = 1, \ldots, n\).

**Definition 2.2** A point \(w^* \in \mathbb{R}^n\) is called an equilibrium of (2.12), if and only if

$$w^*=w^*+\eta\left[2Cw^*-Cw^*(w^*)^Tw^*-\left((w^*)^TCw^*\right)w^*\right].$$

Clearly, the set of all equilibrium points of (2.12) is

$$\{\text{all the eigenvectors with unit length}\}\cup\{0\}.$$

**Definition 2.3** A bound \(M\) is called an ultimate bound of (2.12), if for any \(w(0) \in S\), there exists a constant \(N\) so that \(\|w(k)\|^2 < M\) for all \(k \ge N\).

For convenience in analysis, a lemma is presented as follows.

**Lemma 2.6** It holds that

$$\left[1+\eta\left(\sigma(2-s)\right)\right]^2s\leq\frac{4}{27\eta\sigma}\cdot(1+2\eta\sigma)^3$$

for all \(s \in [0, 2 + 1/\eta\sigma]\).

It is easy to prove this lemma by Lemma 2.1.

## 2.4.2 Invariant Set and Ultimate Bound

The system (2.12) is not globally convergent. Consider the same example as in Section 3, which is the one-dimensional case,

$$w(k+1)=w(k)+\eta\left[2-2w^2(k)\right]w(k),\quad \text{for } k\geq 0.$$

If \(w(k)\ge 1+1/(2\eta)\), it holds that

$$2\eta w^2(k)-w(k)-2\eta-1\ge 0.$$

Then

$$|w(k+1)|=w^2(k)-\frac{2\eta w^2(k)-2\eta-1}{w(k)}\ge w^2(k).$$

\(w(k)\) will clearly tend to infinity if \(w(k)\ge 1+1/(2\eta)\). So, an important problem to address is whether an invariant set can be obtained to guarantee the nondivergence. This is a crucial problem to address to ensure the success of applications.

**Lemma 2.7** Suppose that \(\eta\sigma\le 0.25\) and \(0<\|w(k)\|^2\le 1+\frac{1}{2\sigma\eta}\), then

$$1+\eta\bigl(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\bigr)>0,\qquad (i=1,\ldots,n)$$

for all \(k\ge 0\).

*Proof:* Given any \(i\ (1\le i\le n)\), if \(2\le\|w(k)\|^2<1+1/(2\eta\sigma)\), then

$$1+\eta\bigl(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\bigr)\ge 1+\eta\bigl(\sigma(2-\|w(k)\|^2)-\sigma\|w(k)\|^2\bigr)>0,$$

for all \(k\ge 0\). If \(\|w(k)\|^2<2\), then

$$1+\eta\bigl(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\bigr)\ge 1-\eta w^{T}(k)Cw(k)\ge 1-2\eta\sigma>0,$$

for all \(k\ge 0\). The proof is completed.

**Theorem 2.4** Denote

$$S=\left\{w(k)\mid w(k)\in\mathbb{R}^n,\ \|w(k)\|^2\le 1+\frac{1}{2\sigma\eta}\right\}.$$

If \(\eta\sigma\le 0.25\), then \(S\) is an invariant set of \((2.12)\).

*Proof:* From Lemma 2.7, if \(2\le\|w(k)\|^2\le 1+\frac{1}{2\sigma\eta}\), then

$$0<1+\eta\bigl(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\bigr)<1,\qquad (i=1,\ldots,n)$$

for \(k\ge 0\). From (1.7), (2.13), it follows that

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\bigl(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\bigr)\right]^2z_i^2(k)\\
&\le \left[1+\eta\bigl(\lambda_p(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\bigr)\right]^2\|w(k)\|^2\\
&\le 1+\frac{1}{2\sigma\eta}.
\end{aligned}$$

If \(\|w(k)\|^2<2\), then

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2z_i^2(k)\\
&\leq \left[1+\eta\left(\sigma(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2\|w(k)\|^2\\
&\leq \left[1+\eta\sigma(2-\|w(k)\|^2)\right]^2\|w(k)\|^2\\
&\leq \max_{0\leq s\leq 2}\left\{[1+\eta\sigma(2-s)]^2s\right\}.
\end{aligned}$$

By Lemma (2.6),

$$\|w(k+1)\|^2<\frac{4}{27\eta\sigma}\cdot(1+2\eta\sigma)^3.$$

If \(\eta\sigma<0.25\), then

$$\frac{4(1+2\eta\sigma)^3}{27\eta\sigma}<\frac{1}{2\eta\sigma}<1+\frac{1}{2\eta\sigma}.$$

The proof is completed.

**Theorem 2.5** *Suppose that* \(\eta\sigma\leq 0.25\). *The system* \((2.12)\) *has an ultimate bound* \(\frac{2\sigma}{\sigma+\lambda_p}\); *that is, if* \(w(0)\in S\) *and* \(w(0)\notin V^\perp\), *then there exists a constant* \(N\), *so that*

$$\|w(k+1)\|^2\leq\frac{2\sigma}{\sigma+\lambda_p}<2,$$

for all \(k>N\).

*Proof:* From Lemma 2.7 and Theorem 2.4, if \(w(0)\in S\), we have

$$1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)>0,\qquad (k\geq 0).$$

If \(2\leq\|w(k)\|^2<1+\frac{1}{2\eta\sigma}\), then

$$\begin{aligned}
1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)
&<1+\eta\left(\lambda_p(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\\
&<1,
\end{aligned}$$

for all \(k\geq 0\). Thus, it holds that

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2z_i^2(k)\\
&\leq\left[1+\eta\left(\lambda_p(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2\|w(k)\|^2\\
&<\|w(k)\|^2.
\end{aligned}$$

for all \(k \ge 0\). If \(\frac{2\sigma}{\sigma+\lambda_p}<\|w(k)\|^2<2\), then

$$1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)
\le 1+\eta\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)
<1,$$

for all \(k \ge 0\). So, it follows

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2z_i^2(k)\\
&\le \left[1+\eta\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)\right]^2\|w(k)\|^2\\
&<\|w(k)\|^2,
\end{aligned}$$

for all \(k \ge 0\). If \(0<\|w(k)\|^2\le\frac{2\sigma}{\sigma+\lambda_p}\), then

$$\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2z_i^2(k)\\
&\le \left[1+\eta\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)\right]^2\|w(k)\|^2\\
&\le \left[1+\frac{0.25}{\sigma}\left(2\sigma-(\sigma+\lambda_p)\|w(k)\|^2\right)\right]^2\|w(k)\|^2\\
&\le \left[1.5-0.25\frac{\sigma+\lambda_p}{\sigma}\|w(k)\|^2\right]^2\|w(k)\|^2\\
&\le \frac{2\sigma}{\sigma+\lambda_p}.
\end{aligned}$$

Therefore, if \(w(0)\in S\) and \(w(0)\notin V^\perp\), then there must exist a constant \(N\) so that

$$\|w(k)\|^2\le\frac{2\sigma}{\sigma+\lambda_p}<2,$$

for all \(k>N\). The proof is completed.

The theorems above show that the nondivergence of (2.12) is guaranteed if the learning rate satisfies a simple condition and the evolution of (2.12) is ultimately bounded.

## 2.4.3 Convergence Analysis

In this section, we will prove the trajectories, arising from points in the invariant set \(S\), will converge to a unit eigenvector associated with the largest eigenvalue of the covariance matrix. To complete the proof, the following lemmas are first given.

**Lemma 2.8** Suppose that \(\eta\sigma \le 0.25\). If \(w(0)\in S\) and \(w(0)\ne 0\), then

$$\eta w^{T}(k+1)Cw(k+1)\ge \gamma>0,$$

for all \(k\ge 0\), where

$$\gamma=\min\left\{\frac{(2\eta\lambda_p)^2}{\sigma},\,(\eta\lambda_p)\frac{\lambda_p}{\sigma},\,\eta w^{T}(0)Cw(0)\right\}<1.$$

*Proof.* Since \(w(0)\in S\), by Lemma (2.7), we have

$$1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)>0,$$

for all \(k\ge 0\). From Theorem 2.5, if \(2\le \|w(k)\|^2\le 1+\frac{1}{2\eta\sigma}\), we have

$$\|w(k+1)\|^2\le \|w(k)\|^2,\qquad (k\ge 0).$$

**Case 1:** \(\frac{\lambda_p}{\sigma}<2\).

If \(\frac{\lambda_p}{\sigma}<\|w(k)\|^2<2\), from (1.8) and (2.13), it follows that

$$\begin{aligned}
\eta w^{T}(k+1)Cw(k+1)
&=\eta\sum_{i=1}^{p}\lambda_i z_i^2(k+1)\\
&=\eta\sum_{i=1}^{p}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2\lambda_i z_i^2(k)\\
&\ge \eta\sum_{i=1}^{p}\left[1+\eta\left(2\lambda_p-\sigma\|w(k)\|^2-\sigma\|w(k)\|^2\right)\right]^2\lambda_i z_i^2(k)\\
&\ge \eta\left[2\eta\lambda_p+(1-2\eta\sigma)\|w(k)\|^2\right]^2w^{T}(k)Cw(k)\\
&\ge (2\eta\lambda_p)^2\eta w^{T}(k)Cw(k)\\
&\ge (2\eta\lambda_p)^2(\eta\lambda_p)\frac{\lambda_p}{\sigma}. \tag{2.14}
\end{aligned}$$

for \(k\ge 0\).

If \(\|w(k)\|^2\le \frac{\lambda_p}{\sigma}\), then

$$\begin{aligned}
\eta w^{T}(k+1)Cw(k+1)
&=\eta\sum_{i=1}^{p}\left[1+\eta\left(\lambda_i(2-\|w(k)\|^2)-w^{T}(k)Cw(k)\right)\right]^2\lambda_i z_i^2(k)\\
&\ge \eta\left[1+\eta\left(2\lambda_p-\sigma\|w(k)\|^2-\sigma\|w(k)\|^2\right)\right]^2w^{T}(k)Cw(k)\\
&\ge \eta w^{T}(k)Cw(k). \tag{2.15}
\end{aligned}$$
