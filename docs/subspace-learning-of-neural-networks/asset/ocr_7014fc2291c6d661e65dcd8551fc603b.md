# 7.4 Chaotic Behavior

The invariant sets \(S_1\) and \(S_2\) guarantee the nondivergence of algorithms (7.1) and (7.2). In \(S_1\), the algorithm (7.1) will converge to 0 if \(0<\eta(a+f(w^2))<2\).
