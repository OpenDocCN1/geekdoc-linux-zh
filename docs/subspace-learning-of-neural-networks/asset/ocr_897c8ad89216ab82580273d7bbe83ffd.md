# **Lemma 4.8** Suppose \(\lim_{k\to\infty}\phi_l(k)=0\), \((i=l,\ldots,p)\). Given any \(H_l\geq \widetilde{H}_l\), if \(w_l(0)\in S(H_l)\), there must exist a constant \(\delta>0\) so that

\[\lim_{k\to\infty}z_l^{(l)}(k)=\left(z_l^{(l)}\right)^*,\]

and \(\left|\left(z_l^{(l)}\right)^*\right|>\delta\), where \(\left(z_l^{(l)}\right)^*\) is a constant.

**Proof:** From (4.13), if \(i=l\), it follows that

\[z_l^{(l)}(k+1)=\left\{1-\xi+\frac{\xi\lambda_l}{w_l^{(l)}(k)z_l^{(l)}(k)}\right\}z_l^{(l)}(k)+\phi_l(k),\]

for all \(k>0\). Since \(\lim_{k\to\infty}\phi_i(k)=0\), \((i=l,\ldots,p)\), there exists a \(\widetilde{K}_l\) so that

\[\begin{cases}
z_l^{(l)}(k+1)>0, & \text{if }z_l^{(l)}(\widetilde{K}_l)>0\text{ for all }k\geq\widetilde{K}_l,\\
z_l^{(l)}(k+1)<0, & \text{if }z_l^{(l)}(\widetilde{K}_l)<0\text{ for all }k\geq\widetilde{K}_l.
\end{cases}\]

Since \(w_l(0)\in S(H_l)\), by Lemma 4.6, \(w_l(k)\in S(H_l)\) for all \(k\geq K_l\). While \(z_l^{(l)}(\widetilde{K}_l)>0\), these exists a constant \(N_l\) so that

\[\left\{\frac{\xi\lambda_l}{w_l^{(l)}(k)z_l^{(l)}(k)}\right\}z_l^{(l)}(k)+\phi_l(k)<N_l,\]

for all \(k\geq\max\{K_l,\widetilde{K}_l\}\). It follows that

\[\begin{aligned}
z_l^{(l)}(k+1)&\leq (1-\xi)z_l^{(l)}(k)+N_l\\
&=(1-\xi)^kz_l^{(l)}(0)+\sum_{r=1}^{k}(1-\xi)^{r-1}N_l\\
&=(1-\xi)^kz_l^{(l)}(0)+\left(1-(1-\xi)^k\right)N_l,
\end{aligned}\]

for all \(k\geq K_l\). Since \(0<\xi<1\), it holds that

\[\lim_{k\to\infty}\left[(1-\xi)^kz_l^{(l)}(0)+\left(1-(1-\xi)^k\right)N_l\right]=N_l.\]

Clearly, there must exist a constant \(\left(z_l^{(l)}\right)^*\) so that

\[\lim_{k\to\infty}z_l^{(l)}(k)=\left(z_l^{(l)}\right)^*,\]

where \(\left(z_l^{(l)}\right)^*\) is a constant. While \(z_l^{(l)}(\widetilde{K}_l)<0\), the same result can be obtained similarly. Next, we will prove that there exists a constant \(\delta>0\) so that \(\left|\left(z_l^{(l)}\right)^*\right|>\delta\).
