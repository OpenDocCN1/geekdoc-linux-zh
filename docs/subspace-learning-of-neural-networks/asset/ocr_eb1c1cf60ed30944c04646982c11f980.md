Then, using Lemma 5.1, it follows from (5.6) that

$$\begin{aligned}
\|w(k+1)\|^2
&= \sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)\,w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2\cdot z_i^2(k)\\
&\le \|w(k)\|^2.
\end{aligned}$$

This means that, if $\displaystyle\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<\|w(k)\|^2<2$, then $\|w(k)\|^2$ is monotone decreasing. Using the analysis of Case 1, we can obtain that, if

$$\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<\|w(0)\|^2<2,$$

then

$$\|w(k)\|^2\le \|w(0)\|^2<2,\quad(k\ge 0).$$

# **Case 3:** $2\le \|w(k)\|^2\le 1+\displaystyle\frac{2}{1-4\eta\lambda_n}$.

By $\eta\lambda_1<0.25$ and $2\le \|w(k)\|^2$, it follows from (5.7) that

$$\begin{aligned}
1.5+(\eta\lambda_i-0.5)\,w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i
&= 1+(0.25-\eta\lambda_i)\cdot(2-\|w(k)\|^2)-0.25\|w(k)\|^2+\eta w^T(k)Cw(k)\\
&\le 1-0.25\|w(k)\|^2+\eta\lambda_1\|w(k)\|^2\\
&= (0.25-\eta\lambda_1)\|w(k)\|^2\\
&\le 0.5+2\eta\lambda_1.
\end{aligned}$$

Using Lemma 5.1, it follows from (5.6) and (5.13) that

$$\begin{aligned}
\|w(k+1)\|^2
&= \sum_{i=1}^{n}z_i^2(k+1)\\
&= \sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)\,w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2\cdot z_i^2(k)\\
&\le (0.5+2\eta\lambda_1)^2\cdot\|w(k)\|^2\\
&= \beta^2\cdot\|w(k)\|^2\\
&\le \beta^{2(k+1)}\cdot\|w(0)\|^2,
\end{aligned}$$

where $\beta=0.5+2\eta\lambda_1$. Since $\eta\lambda_1<0.25$, clearly, $0<\beta<1$. Thus, there must exist a positive integer $N$, such that $\|w(N)\|^2<2$. Then, using the analysis of Case 1 and Case 2, we can obtain that for all $k\ge N$,

$$\|w(k)\|^2\le \max\left\{\|w(N)\|^2,\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}\right\}<2.$$$$
