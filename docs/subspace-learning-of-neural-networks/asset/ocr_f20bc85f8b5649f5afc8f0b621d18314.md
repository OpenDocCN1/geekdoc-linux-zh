# ### 7.3 Stability Analysis

In this section, we will explore the stability of the algorithms (7.1) and (7.2) in invariant set \(S_1\) and \(S_2\).

**Definition 7.1**  A point \(w^*\in\mathbb{R}^n\) is called an equilibrium of (7.1), if and only if

\[
w^*=w^*+\eta\left[-(aw^*-b(w^*)^3-f(\|w(k)\|^2)w^*)\right].
\]

**Definition 7.2**  A point \(w^*\in\mathbb{R}^n\) is called an equilibrium of (7.2), if and only if

\[
w^*=w^*-\eta\left[aw^*-b(w^*)^3-f(\|w(k)\|^2)w^*\right].
\]

Clearly, the set of all equilibrium points of (7.1) is

\[
\left\{0,\sqrt{\frac{a+f(\|w(k)\|^2)}{b}},-\sqrt{\frac{a+f(\|w(k)\|^2)}{b}}\right\}.
\]

The set of all equilibrium points of (7.2) is

\[
\left\{0,\sqrt{\frac{a-f(\|w(k)\|^2)}{b}},-\sqrt{\frac{a-f(\|w(k)\|^2)}{b}}\right\}.
\]
