# 2.4.4  Simulations and Discussions

Simulations in this section show the convergence of Xu’s algorithm with a constant learning rate. First, we randomly generate a 6 × 6 symmetric nonnegative definite matrix as

$$C=\begin{bmatrix}0.1712&0.1538&0.097645&0.036741&0.07963&0.12897\\0.1538&0.13855&0.087349&0.033022&0.072609&0.11643\\0.097645&0.087349&0.067461&0.032506&0.043641&0.070849\\0.036741&0.033022&0.032506&0.019761&0.016771&0.025661\\0.07963&0.072609&0.043641&0.016771&0.041089&0.062108\\0.12897&0.11643&0.070849&0.025661&0.062108&0.098575\end{bmatrix}.$$

The maximum eigenvalue σ = 0.5099. The invariant set S can be identified as

$$S=\left\{w(k)\mid w(k)\in\mathbb{R}^2,\ \|w(k)\|^2\leq\frac{1}{2\,\eta\,\gamma\times0.5099}\right\},$$

where η ≤ 0.25/0.5099 ≈ 0.4903.

The algorithm (2.12) is not globally convergent. If the initial vector is
