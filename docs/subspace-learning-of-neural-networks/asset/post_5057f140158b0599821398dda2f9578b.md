
## Lemma 5.1

Suppose that \(\eta\lambda_1<0.25\) and \(\|w(k)\|^2\le 1+\frac{2}{1-4\eta\lambda_n}\), then

\[
1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\ge 0,
\]

\((i=1,\ldots,n)\), for all \(k\ge 0\).

**Proof:** Two cases will be considered to complete the proof.

### Case 1: \(2\le \|w(k)\|^2\le 1+\frac{2}{1-4\eta\lambda_n}\).

By \(\eta\lambda_1\le 0.25\), it follows from (5.7) that

\[
\begin{aligned}
&1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\\
&\ge 1+(0.25-\eta\lambda_n)\cdot[2-w^T(k)w(k)]-0.25w^T(k)w(k)+\eta w^T(k)Cw(k)\\
&\ge 1+(0.25-\eta\lambda_n)\cdot[2-w^T(k)w(k)]-0.25w^T(k)w(k)\\
&\qquad +\eta\lambda_n w^T(k)w(k)\\
&\ge 1.5-2\eta\lambda_n-(0.5-2\eta\lambda_n)\cdot\|w(k)\|^2\\
&\ge 1.5-2\eta\lambda_n-(0.5-2\eta\lambda_n)\cdot\left(1+\frac{2}{1-4\eta\lambda_n}\right)\\
&=0.
\end{aligned}
\]

### Case 2: \(\|w(k)\|^2<2\).

By \(\eta\lambda_1\le 0.25\), it follows from (5.7) that

\[
\begin{aligned}
&1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\\
&\ge 1+(0.25-\eta\lambda_i)\cdot[2-w^T(k)w(k)]-0.25w^T(k)w(k)+\eta w^T(k)Cw(k)\\
&\ge 1-0.25w^T(k)w(k)+\eta w^T(k)Cw(k)\\
&\ge 1-(0.25-\eta\lambda_n)w^T(k)w(k)\\
&> 0.5+2\eta\lambda_n\\
&>0.
\end{aligned}
\]

Using the analysis in the previous two cases, we complete the proof.

Next, we prove an interesting lemma that provides an invariant set for DDT system (5.4).

## Lemma 5.2

Denote

\[
S=\left\{w(k)|w(k)\in\mathbb{R}^n\text{ and }\|w(k)\|^2\le 1+\frac{2}{1-4\eta\lambda_n}\right\}.
\]

If

\[
\eta\lambda_1<0.25,
\]

then \(S\) is an invariant set of (5.4).

**Proof:** To complete the proof, two cases will be considered.

### Case 1: \(2 \leq \|w(k)\|^2 \leq 1 + \dfrac{2}{1-4\eta\lambda_n}\).

By \(\eta\lambda_1 < 0.25\), it holds from (5.7) that

\[
\begin{aligned}
&1.5 + (\eta\lambda_i - 0.5)w^T(k)w(k) + \eta w^T(k)Cw(k) - 2\eta\lambda_i \\
=&\; 1 + (0.25-\eta\lambda_i)\cdot[2-w^T(k)w(k)] - 0.25w^T(k)w(k) + \eta w^T(k)Cw(k) \\
\leq&\; 1 - 0.25w^T(k)w(k) + \eta\lambda_1w^T(k)w(k) \\
<&\; 1,\quad (i=1,\ldots,n).
\end{aligned}
\tag{5.8}
\]

Using Lemma 5.1, it follows from (5.6) and (5.8) that

\[
\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n} z_i^2(k+1) \\
&=\sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2\cdot z_i^2(k) \\
&\leq \|w(k)\|^2 \\
&\leq 1+\frac{2}{1-4\eta\lambda_n}.
\end{aligned}
\tag{5.9}
\]

### Case 2: \(\|w(k)\|^2 < 2\).

By \(\eta\lambda_1 < 0.25\) and Lemma 5.1, it follows from (5.6) and (5.7) that

\[
\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n} z_i^2(k+1) \\
&=\sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2\cdot z_i^2(k) \\
&=\sum_{i=1}^{n}\left\{1+(0.25-\eta\lambda_i)\cdot[2-w^T(k)w(k)]\\
&\hspace{3em}-0.25w^T(k)w(k)+\eta w^T(k)Cw(k)\right\}^2\cdot z_i^2(k) \\
&\leq \left[1+(0.25-\eta\lambda_n)(2-\|w(k)\|^2)-(0.25-\eta\lambda_1)\|w(k)\|^2\right]^2\cdot\|w(k)\|^2 \\
&\leq \left[1+(0.25-\eta\lambda_n)(2-\|w(k)\|^2)\right]^2\cdot\|w(k)\|^2 \\
&\leq \max_{0\leq s\leq 1+\frac{2}{1-4\eta\lambda_n}}\left[1+(0.25-\eta\lambda_n)(2-s)\right]^2\cdot s.
\end{aligned}
\tag{5.10}
\]

By \(\eta\lambda_1<0.25\), it can be calculated out that for all \(s\in\left[0,1+\frac{2}{1-4\eta\lambda_n}\right]\),

\[
[1+(0.25-\eta\lambda_n)(2-s)]^2\cdot s\leq\frac{16(1.5-2\eta\lambda_n)^3}{27(1-4\eta\lambda_n)}. \tag{5.11}
\]

By \(\eta\lambda_1<0.25\), it holds from (5.10) and (5.11) that

\[
\|w(k+1)\|^2\leq\frac{16(1.5-2\eta\lambda_n)^3}{27(1-4\eta\lambda_n)}<\frac{2}{1-4\eta\lambda_n}<1+\frac{2}{1-4\eta\lambda_n}. \tag{5.12}
\]

From (5.9) and (5.12), we can draw the conclusion that if \(\eta\lambda_1<0.25\) and \(w(k)\in S\), then \(\|w(k+1)\|^2\leq 1+\frac{2}{1-4\eta\lambda_n}\), that is, \(w(k+1)\in S\). The proof is completed.

Next, using Lemma 5.1 and Lemma 5.2, we prove that if some mild conditions are satisfied, the squared norm \(\|w(k)\|^2\) of weight vector will be less than a constant \(\zeta\ (0<\zeta<2)\) after some iterations in (5.4).

## Theorem 5.1

If \(\eta\lambda_1<0.25\) and \(w(0)\in S\), then there exist a constant \(\zeta<2\) and a positive integer \(N\), such that

\[
\|w(k)\|^2\leq\zeta,
\]

for all \(k\geq N\).

**Proof.** Using Lemma 5.2, \(S\) is an invariant set, then \(w(k)\in S\) for all \(k\geq0\). By \(\eta\lambda_1<0.25\), clearly,

\[
0<\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<2.
\]

Next, three cases will be considered to complete the proof.

### Case 1: \(0\leq\|w(k)\|^2\leq\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}\).

By \(\eta\lambda_1<0.25\) and Lemma 5.1, it follows from (5.6) and (5.7) that

\[
\begin{aligned}
\|w(k+1)\|^2
&=\sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2 z_i^2(k)\\
&=\sum_{i=1}^{n}\left\{1.5-0.5w^T(k)w(k)+\eta w^T(k)Cw(k)-[2-w^T(k)w(k)]\eta\lambda_i\right\}^2 z_i^2(k)\\
&\leq\sum_{i=1}^{n}\left[1.5-0.5\|w(k)\|^2+\eta\|w(k)\|^2-(2-\|w(k)\|^2)\eta\lambda_n\right]^2 z_i^2(k)\\
&=\left[1.5-2\eta\lambda_n-(0.5-\eta\lambda_n-\eta\lambda_1)\|w(k)\|^2\right]^2\cdot\|w(k)\|^2\\
&=\left[1+\frac{1-4\eta\lambda_n}{2}\left(1-\frac{1-2\eta\lambda_1-2\eta\lambda_n}{1-4\eta\lambda_n}\cdot\|w(k)\|^2\right)\right]^2\cdot\|w(k)\|^2\\
&\leq\left[1+\frac{1}{2}\left(1-\frac{1-2\eta\lambda_1-2\eta\lambda_n}{1-4\eta\lambda_n}\cdot\|w(k)\|^2\right)\right]^2\cdot\|w(k)\|^2\\
&\leq\left(1.5-\frac{1-2\eta\lambda_n-2\eta\lambda_1}{2-8\eta\lambda_n}\cdot\|w(k)\|^2\right)^2\cdot\|w(k)\|^2\\
&\leq\max_{0\leq s\leq\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}}\left(1.5-\frac{1-2\eta\lambda_n-2\eta\lambda_1}{2-8\eta\lambda_n}\cdot s\right)^2\cdot s.
\end{aligned}
\]

By \(\eta\lambda_1<0.25\), it can be calculated out that

\[
\left(1.5-\frac{1-2\eta\lambda_n-2\eta\lambda_1}{2-8\eta\lambda_n}\cdot s\right)^2\cdot s\leq\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n},
\]

for all \(s\in\left[0,\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}\right]\). Thus, \(\|w(k+1)\|^2\leq\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}\). Thus, it holds that,

\[
\|w(0)\|^2\leq\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n},
\]
then
\[
\|w(k)\|^2\leq\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<2,\quad(k\geq0).
\]

### Case 2: \(\displaystyle\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<\|w(k)\|^2<2\).

By \(\eta\lambda_1<0.25\), it follows from (5.7) that

\[
\begin{aligned}
1.5+(\eta\lambda_i-0.5)w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i
&=1.5-0.5w^T(k)w(k)+\eta w^T(k)Cw(k)-[2-w^T(k)w(k)]\eta\lambda_i\\
&\leq1.5-0.5\|w(k)\|^2+\eta\|w(k)\|^2-(2-\|w(k)\|^2)\eta\lambda_n\\
&=1.5-2\eta\lambda_n-(0.5-\eta\lambda_n-\eta\lambda_1)\|w(k)\|^2\\
&\leq1.
\end{aligned}
\]

Then, using Lemma 5.1, it follows from (5.6) that

\[
\begin{aligned}
\|w(k+1)\|^2
&= \sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)\,w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2\cdot z_i^2(k)\\
&\le \|w(k)\|^2.
\end{aligned}
\]

This means that, if \(\displaystyle\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<\|w(k)\|^2<2\), then \(\|w(k)\|^2\) is monotone decreasing. Using the analysis of Case 1, we can obtain that, if

\[
\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}<\|w(0)\|^2<2,
\]

then

\[
\|w(k)\|^2\le \|w(0)\|^2<2,\quad(k\ge 0).
\]

### Case 3: \(2\le \|w(k)\|^2\le 1+\displaystyle\frac{2}{1-4\eta\lambda_n}\).

By \(\eta\lambda_1<0.25\) and \(2\le \|w(k)\|^2\), it follows from (5.7) that

\[
\begin{aligned}
1.5+(\eta\lambda_i-0.5)\,w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i
&= 1+(0.25-\eta\lambda_i)\cdot(2-\|w(k)\|^2)-0.25\|w(k)\|^2+\eta w^T(k)Cw(k)\\
&\le 1-0.25\|w(k)\|^2+\eta\lambda_1\|w(k)\|^2\\
&= (0.25-\eta\lambda_1)\|w(k)\|^2\\
&\le 0.5+2\eta\lambda_1.
\end{aligned}
\]

Using Lemma 5.1, it follows from (5.6) and (5.13) that

\[
\begin{aligned}
\|w(k+1)\|^2
&= \sum_{i=1}^{n}z_i^2(k+1)\\
&= \sum_{i=1}^{n}\left[1.5+(\eta\lambda_i-0.5)\,w^T(k)w(k)+\eta w^T(k)Cw(k)-2\eta\lambda_i\right]^2\cdot z_i^2(k)\\
&\le (0.5+2\eta\lambda_1)^2\cdot\|w(k)\|^2\\
&= \beta^2\cdot\|w(k)\|^2\\
&\le \beta^{2(k+1)}\cdot\|w(0)\|^2,
\end{aligned}
\]

where \(\beta=0.5+2\eta\lambda_1\). Since \(\eta\lambda_1<0.25\), clearly, \(0<\beta<1\). Thus, there must exist a positive integer \(N\), such that \(\|w(N)\|^2<2\). Then, using the analysis of Case 1 and Case 2, we can obtain that for all \(k\ge N\),

\[
\|w(k)\|^2\le \max\left\{\|w(N)\|^2,\frac{1-4\eta\lambda_n}{1-2\eta\lambda_1-2\eta\lambda_n}\right\}<2.
\]
