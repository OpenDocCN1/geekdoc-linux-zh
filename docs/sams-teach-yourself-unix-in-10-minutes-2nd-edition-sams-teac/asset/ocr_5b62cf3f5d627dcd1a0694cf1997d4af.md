Unix is a very powerful multitasking operating system. Multitasking refers to performing multiple tasks at once; in this context, it specifically means that a user can run multiple programs simultaneously within one single login of the system. Unix is also a multiuser operating system. What this means is that many users can simultaneously (and securely) use the same machine. In addition, Unix is open source means that users are free to look at and modify its code. This is not the case with proprietary versions of Unix, but most versions are open source, so unless you are working with a specific vendor that does not allow its version of Unix to be altered, it is safe to assume that most versions (especially Linux versions) can be modified. Another powerful tool to unleash with Unix is the power of coding and scripting. Entire community works with Unix and help develop Unix programs, and this is what keeps the system growing, developing, and getting better each and every year. This is not commonly seen with other operating system platform vendors such as Microsoft. Most of these release closed source systems, which means you cannot freely write code that works blindly with these systems.

There is much more to learn Unix. You are encouraged to find out more about its history and origins on the Web; this way, we can focus more written pages on teaching how to use Unix (At the end of this book, however, there is a reference section that will help you locate additional information on Unix, its history, and where it is going in the future.)
