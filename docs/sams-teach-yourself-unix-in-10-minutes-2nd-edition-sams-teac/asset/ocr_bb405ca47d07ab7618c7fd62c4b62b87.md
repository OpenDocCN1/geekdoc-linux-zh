In our example, the controlling process is the xterm window. When you close something that is designated as a controlling process, doing so will leave you out of your X Window System session.

Let's look at another .xinitrc script:

```
#! /bin/sh
xrdb $HOME/.profile
xsetroot -solid gray -g 60x50-0+0 -bw 0 &
xterm -g 60X24-0+0 &
xterm -g 60X24-0+0
```

You can see that this script is similar to the last one, and that is good. You will start to remember things such as this, and that's all it takes to learn Unix! In this sample script, you can see the power of Unix starting to open up; you can basically script anything and have it run automatically. You can even have scripts that call up other scripts—the flexibility is endless.

To continue with our example and tie this all together, let's examine the last line of the script. The last line should be your controlling process, and when you have a controlling process, this is the one time that you do not add the ampersand.

So what does this sample .xinitrc file do? With this file, xinit will start, and your .profile file will be read. Once read, your environment will start to develop. In this example, the root window will be set to gray. A clock will be used. Two xterm sessions (one as a controlling process) and one xconsole window will be initialized.
