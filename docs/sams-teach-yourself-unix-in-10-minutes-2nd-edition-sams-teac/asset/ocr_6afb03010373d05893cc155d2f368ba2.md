> Who Owns This File? One of the cool things about the Unix file system design is when you use the ls command, you can also see who the file owner is, which is an important piece of information.

As we discussed earlier in this book, it may be a little confusing to learn Unix if you have a distribution that is different from the norm. If this is the case, you may enter the ls command and get output that looks different from what you see here. That is okay. Versions of Unix ls commands produce slightly different output. This does not mean that you will not be able to decipher it. Simply use the man command with ls to see what syntax is used and what you may be able to glean from issuing command on your system. You can attempt to use the help command at the shell prompt as well. For the most part, you will likely see the same exact information each time, no matter what version of Unix you use.
