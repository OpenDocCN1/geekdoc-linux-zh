## Using the KDE Find Feature

If you are using the graphical user interface (GUI), then you will likely be using KDE. If so, then you can quickly search for files in KDE as well.

By going to the main menu and selecting Find, you will open a dialog box.

Once you use the dialog box, it should be self-explanatory. Instead of adding the commands you need (like find, where, and which), the Find dialog box will ask you what you are looking for (and where) and search that exact location for what you want.

This dialog box contains the same features of the command-line versions of find and grep. KDE has provided a GUI for these functions that make them easier to use. Again, you may prefer to use the shell prompt. The shell prompt helps you learn all the intricacies of the command, and the more commands you know, the more scripting you will be able to handle when we get to Lesson 14, “Shell Scripting Fundamentals."

## File System Navigation Techniques

Now that you know and understand all the different utilities you can use, we will search for files on your Unix system with KDE. To search in the KDE, do the following:

- 1. Consider what file(s) you want to search for, and then click the toolbar icon to bring up the main KDE menu.
- 2. Choose Find Files.
- 3. From the tabs you see, select what search criteria you want from three options: Name and Location, Date Modified, and Advanced. Considering wildcards (*.rpm, for example) if you are unsure what to search for.
- 4. Click the small magnifying glass in the Find Files toolbar to locate the matching files.

To search for files, you can specify what file you want and then run your search. You can change where you are searching as well as what criteria you are searching for. Using the shell prompt commands or the KDE GUI, you can search using the following criteria: date, size, location, and name.

Now you should see the file you want. You can select the file and work with it, or you can just close the search. Either way, this concludes the discussion of how to find files within your Unix system.
