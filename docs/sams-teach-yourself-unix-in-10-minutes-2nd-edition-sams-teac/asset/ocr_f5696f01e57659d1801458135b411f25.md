+   - In cases in which a program is not listed, xinit will look for a file in the user's home directory. This file is .xinitre or whatever is specified.

+   - The file called .xinitre will call other programs to load with basic settings that can be defined within the script, such as running in the background with the use of an ampersand (&).

+   - Client programs are launched from /etc/init.

+   - If .xinitre does not exist, you can create it and add it to your home directory.

+   - The X Window System requires a window manager if you want to add niceties and conveniences such as title bars.
