list out all the available shells on your system. After using chsh -1, changing shells is as easy as running the correct command and knowing what syntax to use.

```
>chsh -1

/bin/ash
/bin/bash
/bin/csh
/bin/ksh
/bin/sh
/bin/bsh
/bin/tcsh
/bin/zsh
```

In this example, there are eight different shells that you can choose from. If you wanted to change the bash shell from your current shell, you would do the following:

```
>chsh

Changing shell for rob.
Password: *****
New shell [/bin/csh]: /bin/bash
Shell changed.
```

The next time you logged in to your machine, you would be in the bash instead of your previous shell. You probably won't ever need to change your shell unless the default shell on your system is not able to do what you want to.

> The Shell Game Changing your shell is easy, but it all depends on your distribution of Unix or Linux and how it is set up. In some distributions, you may find yourself locked out of your session if you make a mistake. Again, this illustrates the need to practice on a Unix system that you are not working on just in case you do a mistake and wind up in a jam. There is absolutely no shame in asking for help if you don't know what you are doing. Practice makes perfect, so I suggest getting yourself a lab system and changing into the shells just to see how to do it.
