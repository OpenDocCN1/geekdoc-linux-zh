With SuSE Linux, you can use a tool called SaX (or SaX2). SaX2 is the X configuration tool for Novell's SuSE Linux. It runs for the first time during the initial SuSE Linux installation, where it identifies your graphics card, installs the graphics drivers, and sets up X to its default configuration. These settings are conveniently stored in .XF86Config file in /etc/X11/XF86Config.

In addition to interface sophistication, KDE provides an integrated suite of tools for configuring your machine. If you are a Windows or Macintosh user, KDE will seem like second nature to you. It has the same point-and-click feel that other GUI-based operating systems like Windows and Macintosh also have.

If you're looking for a way to make your Unix experience a bit more like your personal computer, then use KDE, but remember that the true power of Unix is in the commands you use at the shell prompt.

# Summary

This lesson taught you about the background of graphical user interfaces in general and the X Window System in particular. The use of xinit and other system programs and utilities was also discussed. This lesson also covered how to customize your user environment. It ended with a description of window managers and desktop environments such as KDE.

+   - The X Window System is based on a client/server model.
- The xinit program is used to start the X Window System.
- The startx shell script is used to initialize an X session, perform basic display functions, and so on.
- The startx command streamlines the process by combining commands into a file that can be referenced quickly.
- If a startup script filename is not given at the command line with the -x option, then the startx command searches for a file specified by the user's .xinitrc environment variable.
