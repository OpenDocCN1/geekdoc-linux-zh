> Use Your Time Correctly When working with Unix,(or any other operating system), you should have the correct time set on your system. This is usually done by a system administrator, as it's not done locally on the system. Instead, a time master is usually found somewhere on the network, from which your Unix system may pull the time. Of course, if your Unix system is not networked, then you will most likely be getting your correct time from the local system. Be aware of what time your Unix system says and where you are getting your time from.

Having your Unix system set with the proper time will help not only with file management, but also with logging security.

# Removing Files with the rm Command

If you use the touch command and now have a file that you do not want on your Unix system, you may want to get rid of it. In this section, we will learn how to remove files from your Unix system.

The rm command is used to delete unwanted files on your Unix system. Remember that using this command can get you into some trouble if you don't use it properly\u2014you could remove data from your system that you do not want to remove. Unix takes what you very literally, so be careful\u2014you are not in a Windows environment that checks every step of the way when you delete a file. If you want to remove a file from your Unix system, follow these steps to use the rm command:

+   Determine which file, or files, you want to delete.

+   Issue the rm command as rm <filename>.
