> **Restart** To start the X Window System using your customized .xinitrc script, type xinit at your workstation prompt. If you receive an error when attempting this command, you may need to remove a lock file in your temp (tmp) directory. You can use the remove directory command (rm), which, when used with the appropriate switch and path, will remove any problem files. Use rm -f /tmp/*, which will attempt to remove everything from your temp directory, or specify the actual file, such as by typing rm -f /tmp/.X0-lock.
