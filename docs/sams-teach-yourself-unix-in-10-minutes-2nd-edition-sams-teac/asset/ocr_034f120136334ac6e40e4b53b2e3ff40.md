# Lesson 19

The chmod command sets Unix file permissions exactly how you want them, so let's take a look at how. First you need to be connected to your Unix system. Because you will not always be on a local system, you may need to connect to a remote system, log in, change some permissions, and then exit the session using telnet or ssh. Once the shell prompt, you need to execute a chmod command. Here are some examples of what you can do with the chmod command:

```
> chmod 0755 script.sh
> chmod 755 script.sh
> chmod u=rwx,ox=rx script.sh
```

Let's look at a real example. To activate group permissions for the script.sh shown here, type the following:

```
-rw------- 1 rob test 1662882 Dec 25 12:00 script.sh
>chmod g+w script.sh
```

To see if it worked, you can run ls -l on the filename as follows:

```
>ls -l script.sh
-rw-rw--r-- 1 rob test 1662882 Dec 25 12:00 script.sh
```

Write permissions have been activated for the test group members. Because of its symbolic nature, this method for adjusting file permissions might be easy for some; however, there is another syntax that you might find more efficient and effective. In this example, you can set the actual mask that is used to control a file's permissions. The bit mask would be the three binary bits used to represent each level of permission. The three binary bits would be (in order from left to right):

+   - 1st bit: (start from the left) controls read

+   - 2nd bit: controls write

+   - 3rd bit: controls execute

There are your three permissions, and now you can view our example as binary numbers translated to decimal:

100 - Read permission - The decimal equivalent of this binary value is 4.
