# fsck

The fsck command (short for "file system check" or "file system check") will start the Unix system utility to check the consistency of your file system. Every now and again you might hear a Unix administrator talking about the need to a hard drive because it is experiencing problems. Hard drives are like light bulbs: They are made to fail and actually have a MTBF (Mean Time Between Failure) associated with them. This just means that like a light bulb, their internal parts will eventually quit and cease to function due to nonstop use and/or damage.

The fsck command is Unix's disk fixer program, and it is used to clean up problems caused by crashes or errant pieces of software. Much like the tools used in Windows systems (such as Disk and defrag), you will eventually need to know this command if you are managing and maintaining a Unix system. Most Unix systems fsck their drives on boot, and the expected result is an analysis report containing the number of files and the fragmentation level of the drive. If you are watching a machine boot, do not be overly concerned if you see fsck report problems. Unix automatically attempts to fix them.
