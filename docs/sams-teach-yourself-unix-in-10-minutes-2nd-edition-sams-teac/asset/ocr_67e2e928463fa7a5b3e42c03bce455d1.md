# Working with Files at the Unix Shell Prompt

When working with Unix, you will most likely find it easiest to work with tools at the shell prompt. Using commands such as touch and rm is very helpful, and these commands perform niche-based functions in much the same way as the where command covered in the last lesson. In Unix, there are multiple ways to create a file and edit it.

The command line is your primary interface to the Unix file system as well as your primary tool for creating, deleting, and rearranging files. In this part of the lesson, we will learn how to manipulate data within the Unix system with the touch command as well as commands to help you remove newly created data on your Unix system.

# The touch Command

Creating new empty file in Unix is easy when you use the touch command. The touch command is used to update the last modified time of a file, setting it to the current time. This is usually not commonly used, but knowing about it can serve you well. The touch command is normally used with one particular area: backup and disaster recovery. As a Unix system administrator, you may be asked to backup and restore jobs. There are a few different types (and methods) of backup and restore you can choose from, one of which is called an "incremental backup. Although this may not be something you work with Unix, it is something you are most likely affected by. Most systems are backed up and protected by companies that need to save and keep their valuable data.
