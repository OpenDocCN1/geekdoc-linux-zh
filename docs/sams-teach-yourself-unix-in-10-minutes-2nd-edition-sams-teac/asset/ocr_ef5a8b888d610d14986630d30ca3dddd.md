```
> vi test
This is a new file I created!
Check it out,
Isn't it snazzy?
I thought it was
```

By doing this, Unix will respond back to you with

"test" [New file] 4 lines, 61 characters

If you remember how to use the cat command, you can quickly view the
contents of the new file you created test.

```
> cat test
This is a new file I created!
Check it out,
Isn't it snazzy?
I thought it was
```

As you can see, the vi editor can be helpful to you for editing a plethora
of different file types. Make sure you remember that learning the vi editor
takes a lot of time and practice. I hope that you continue to use it; if not,
maybe you might like to try emacs.
