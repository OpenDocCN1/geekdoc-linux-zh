# Listing 8-2  Using SQL SELECT to find the current database users.

```
SELECT nvl(S.OSUSER,S.type) OS_Usercode,
	S.USERNAME 			Oracle_Usercode,
	S.sid 			Oracle_SID,
	S.process 			F_Ground,
	P.spid 			B_Ground
FROM sys.V_$SESSION S,
	sys.V_$PROCESS p
WHERE s.paddr = p.addr
ORDER BY s.sid
```
