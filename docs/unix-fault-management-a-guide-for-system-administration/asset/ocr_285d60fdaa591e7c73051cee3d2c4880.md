# Mirror Fails

Something happens on one of the disks that keeps the data mirrored. MirrorDisk/UX can no  
longer mirror the data. The data is no longer protected from failure. Fortunately, Nancy is moni-  
toring for this, and an event is sent to the IT/O Message Browser. As shown in Figure 5-11, a  
major (Maj) severity EMS event is displayed in the Message Browser.

# Restoring Mirrors

After running the diagnostic tools in STM, Nancy identifies the failed component. After swap-  
ping in a new drive, she synchronizes the copies so that each copy of the data is identical.

# Verifying Configuration

Now that Nancy has fixed the failed disk, she uses the lvdisplay command to verify that the logi-  
cal volume is once again available and that she has a mirrored copy of the data.

Nancy continues to monitor the copies by using EMS DVM, knowing that she will be noti-  
fied if the mirror fails again.
