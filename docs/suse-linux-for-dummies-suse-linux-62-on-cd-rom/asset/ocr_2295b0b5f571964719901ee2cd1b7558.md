# 4. Turn on the main power switch.

After a short time, LILO boot: appears on your screen.

# 5. Press the Tab key to see all operating systems that are available to boot.

You might see something like the following, depending on what options you chose during installation:

```
LILO boot:
dos linux
boot:
```

# 6. Type the name of one of the listed operating systems and then press Enter.

That operating system will boot.

If you do not — that is, you ignore my wonderful instructions — the first listed operating system, which is known as the default system, will boot after a short time.

For Linux to boot, then:

+   - Linux must be the only operating system installed; or
- Linux must be the first operating system listed so that it boots the default system; or
- You must be fast enough to type linux after the boot prompt.

Otherwise, you may have to wait for the other operating system to finish booting, shut it down, reboot, and make sure that you're fast enough to type linux after the prompt.

As the Linux operating system boots, you see all sorts of messages scrolling by the screen. When the scrolling stops, the last line should be

```
login:
```

Now you're ready to log in to the system and set up an account to use in your normal day-to-day work. Luckily, logging in and setting up an account are the topics covered next.

# Power Incarnate

When you want to use Linux, you must log in as a particular user with a distinct login name. Why? Linux is a multiuser system, and as, it uses different accounts to keep people from looking at other people's secret files, erasing necessary files from the system, and otherwise doing bad things.
