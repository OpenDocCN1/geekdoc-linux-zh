# Chapter 5: Installation: Down to the Final Stretch

At the bottom of the Series Selection Screen, you can see how much hard drive space you need to install the currently selected list of packages. On the right side of the screen, you can see the hard drive space requirements for the packages in a particular series. Figure 5-19 shows 505MB available on the root partition; also, the packages in the Development series that are currently selected for installation require 155MB.

# An example installation

The following steps serve as an example of selecting a package to be installed:

+   1. Use the down-arrow key to scroll down the list of series.
2. When the Games and More is highlighted, please press Enter.

The Package Selection screen appears and you see the list of packages that are contained in the Games and More. The packages that are marked with an X in the brackets are currently selected to be installed. You can view additional information about a brief description as well this information may include but is not limited to a list of files that will be installed by the currently highlighted package. An example of the package selection screen is shown in Figure 5-20.
