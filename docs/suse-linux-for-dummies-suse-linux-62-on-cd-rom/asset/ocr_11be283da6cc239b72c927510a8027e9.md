# In this part ...

Check out this part if you want to know what Linux is all about. First, we delve into a little history (not nearly as much as we'd like to). Then you find out why Linux is faster, smaller, less expensive, and prettier than other systems. You also get a few pointers on the different ways you can use Linux.

In the next chapter, we tell you about SuSE Linux. You also get some examples of programs that are useful with Linux — some come with Linux and others you have to buy — to show what great things you can do with the operating system.
