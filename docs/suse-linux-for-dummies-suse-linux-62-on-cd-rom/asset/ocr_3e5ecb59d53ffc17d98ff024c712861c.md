# # Start Your Engines

At this point, you should have a correctly configured X Window System. To start the X Window System, simply type the following:

```
[root@localhost X11]$ startx
```

You should see the KDE (this acronym stands for the K Desktop Environment) desktop appear on your screen. The first time you start KDE, KDE automatically creates a few configuration folders in the home directory of the user who is using KDE. You are prompted by KDE to approve the creation of these folders and you should click the OK buttons as they appear. When KDE is loading, you will see some icons on your desktop and a panel at the bottom of your screen with a K in the left corner.
