Each section contains two lines that define the resources (irq and ioport) that are "assigned" to that device. As you can see, almost all the lines are preceded by a # symbol (a comment symbol), which means the values on those lines are ignored. The lines of primary importance are the ones that are not "commented out"; they define the irq and ioport that are assigned to your modem. They look like this:

```
(IO 0 (SIZE 8) (BASE 0x03e8))
(INT 0 (IRQ 4 (MODE +EE))
```

In this example, my modem is configured to irq 4 and ioport 0x03e8. In the event that these resources are already in use by another device, you need to manually change them. Fortunately, you can easily do this using one of the preconfigured resource settings, as described in the next step.

+   3. Place a # (comment symbol) in front of those lines that are causing the conflict, for example:

```
#IO 0 (SIZE 8) (BASE 0x03e8))
#(INT 0 (IRQ 4 (MODE +EE))
```

+   4. Remove the # (comment symbol) in front of the lines that have the settings you want to use; for example, change this to:

```
#IO 0 (SIZE 8) (BASE 0x02e8))
#(INT 0 (IRQ 3 (MODE +EE))
```

+   Now you should reissue the command:

```
/sbin/isapnp /etc/isapnp.conf
```

and see the results described in the first step.
