# Chapter 4: Making Room for SuSE Linux

+   1. Type cd \ and press Enter.

+   2. Type FIPS and press Enter.

Some messages appear, but you can ignore them — well, ignore all but
the following one.

+   3. When you see the message to press any key, do so.

You see all the existing partitions on the disk.

+   4. When you see a message to press any key, do so.

You're getting pretty good at this. You see a description of the disk and
series of messages. Then FIPS finds the free space in the first partition.

+   5. When asked whether you want to make a backup copy of sectors, type
y for yes.

The screen ask whether a floppy is in drive A.

+   6. Place a formatted floppy disk into drive A, and then press y.

A message similar to Writing file a:rootboot.000 appears, fol-
owed by other messages and then the Use cursor key to
choose the cylinder, enter to continue.

Three columns are on the screen: Old, Cylinder, and New
Partition. The Old Partition is the number of megabytes in the
main partition of your disk. The New Partition is the number of
megabytes in the new partition you're making for the Linux operating
system.

+   7. Use the left and right-arrow keys to change the numbers in the Old
Partition and New fields to give you the space you need for
both the Microsoft operating system and Linux. Figure 4-2.

A minimum SuSE Linux system, without X Window System (the graphical
environment), requires 40MB of disk space. (See Chapter 2 for the
details.) A minimal graphical environment requires about 150MB of disk
. The full distribution, along with all the programs and compilers
the disk, requires about 680MB of disk space. Then add the amount
of data space you need for your own files; how much data space you
leave for the Linux and Microsoft operating systems are up to you.

+   8. When you have the correct amount of disk space in each field, press
t Enter key.

FIPS displays the partition table again, showing you the new
that has been created for the Linux operating system. This will probably
be partition 2; your C drive is probably partition 1.

You also see a message at the bottom of the screen asking you
want to continue or reedit.
