Sit down, grab your favorite drink, and contemplate the excitement about
to unfold. In this chapter, we give you step-by-step instructions on how to
install and configure the SuSE Linux distribution that comes on the SuSE Linux
For Dummies CD-ROM. These instructions also work for the full 6.2 version of
SuSE Linux (this is the version that is available at the time of writing). The prim-ary difference between the CD-ROM included with this book and the full version is the number of packages, or software, that are included in the CD-ROM.
It is possible that the full version that is available in the stores is newer than
tone included with this book. If you have a newer version, you may find
differences in the installation procedure.
