# 146 Part III: Using SuSE Linux

```
maddog@shamet:~ >chown root parttime
```

This changes the ownership of parttime to root. If you want to change it back, you can use the chown command but you have to do it as root.

![](bbox=[0.135, 0.205, 0.205, 0.275])

Under some installations of Linux, you can't give your file away to someone using the chown command. You get an error message telling you that the Operation is not permitted. Some systems administrators distribute think the chown command is a security risk. Therefore, only a superuser can execute the chown command. If you have one of distributions (the SuSE Linux For Dummies CD-ROM is one) and you want to give your file to others, we suggest that you have the other person copy the file, creating a file of her own that would have ownership of.

Files and users belong to groups. In the parttime example, the group is users. Having groups enables you to give large numbers of users — but not all users — access to files. Group permissions and ownership are handy for making sure that the members of a special project or workgroup have access to files needed by the entire group.

See which groups are available to you on your system, look at /etc/group file. To do so, use the more command. You'll see a file that looks like this:

```
root::0:root
bin::1:1:root,bin,daemon
nobody::99:
users::100:your-user-name, maddog
floppy:x:19:
...
your-user-name:500:your-user-name
```

your-user-name is the login name you use for your account. Please remember that the file will not look exactly like this, just similar. The names at the beginning of the line are the group names. The names (such as root, bin, and daemon) are user-group names that can belong to the user-group list.

To change the group that the file belongs to, use the chgrp command. Its syntax is the same as that of the chown command. For example, to change the group that parttime belongs to, issue the following:

```
maddog@shamet:~ >chgrp newgroup parttime
```
