# Multitasking

When executing programs on Linux systems, being able to take advantage of its multitasking capabilities — that is, running multiple programs at the same time — is nice. This process is also called job control. Windows 95 seems to do it, and UNIX systems have been doing it for almost 30 years. Most of this job-control capability is due to the shell being able to launch background jobs and manage them.

For example, perhaps you have a task that will be running a long time, with little or no human input. When you start that task, all you have to do is put an & (ampersand) sign at the end of the line, and the job starts running in the background.

For example, if you start mail (a really e-mail program on the SuSE Linux For Dummies CD-ROM), you probably want to run it a long time, and yet you want to type other commands at the same time. To put mail into the background (assuming that you have X Window System running), you can start mail by typing the following command to a terminal emulator.

![](bbox=[0.037, 0.703, 0.135, 0.773])

```
maddog@localhost:~ kmail&\n[1] 449
maddog@localhost:~ ~
```

The number in brackets is the job number, followed by the process ID number. The job number is the number the shell gives the ical program to keep track of the ical job. The process ID number is the entire operating system uses to keep track of the ical program.
