# Chapter 11: Windows on the World

# Window Tricks

You don't windows? Luckily, KDE does all the hard work for you. You simply click here and to drag windows around, make them big, make them small, make them any size you want. In this section, you practice the window tricks using the several windows you have on the screen.

Before doing something to a window, however, you have to get its attention. When a window has your attention, it's said to have focus, or to be active.

You can give a window focus with KDE in several ways:

+   Click the window's name, which is in the task bar at the top of the window

+   Hold the Alt and Tab keys down together and you will see a list of the currently open applications. By using the Tab key, you can scroll through the list. By releasing the two keys, you will make the currently selected application active, or in focus.

+   Click the window itself, which typically also makes the window the topmost one.

+   Shout "Hey, you!"

When the window is in focus, it remains until you select another window to be in focus, using one of the above methods. Other ways exist to bring a window into focus. For example, you can use a configuration option in KDE that allows you to make a window in focus simply by moving your pointer icon over it. Unfortunately, we can't cover every feature of KDE in this book, so we leave it to the curious readers to find this configuration option!
