# Chapter 6: Solving Problems with the X Window System Installation

4. You should be presented with the Card tab. If you are still in the keyboard configuration screen, click the Next button in the bottom-right corner of the screen.

The card configuration screen is divided into two windows, Vendor and Name, as shown in Figure 6-5. In the Vendor window, select the vendor of your video card. In the Name window, select the name of your card. If your card and/or vendor are not on the list, but you know which X server you use (either from SuperPro or the card list on the Web at www.xfree6.org/cardlist.html), click the first option in the Vendor window,...,Generic Server Selection!!! A list of Generic servers will appear in the Name window. From that list, you should select the appropriate X server. When you do, Sax will select the video card and you may need to manually configure these values, and you do this by clicking the Expert button and selecting the options in the screens that appear. When you are ready to continue, click the Next button in the bottom-right corner of your screen.

If you are having problems getting your X server to start, or your video card requires an X server that is not on the !!!Generic!!! list, then you should click the Expert button in the bottom-left corner of the screen and select the X server from the drop-down list that appears when you click the X server configuration window. After you have selected your X server from the list, make sure to click the Apply button.
