# 226 Part Maintaining Your System

Suppose that your electricity went out and your system crashed. As the system reboots, you see messages similar to the following:

```
/dev/hda5 was not cleanly unmounted, check forced
/dev/hda5: Deleted inode 1456 has zero dtime. FIXED
/dev/hda5: Deleted inode 14577 has zero dtime. FIXED
/dev/hda5: Deleted inode 123753 has zero dtime. FIXED
Fix summary information? Yes
/dev/hda5: 46906/308400 files (1.6% non-contiguous),
      767485/1228801 blocks
```

And a little later, you see something like this for each one of your file systems:

```
fsck.ext2 -a /dev/hda7
/dev/hda7 was not cleanly unmounted, check forced
/dev/hda7: Deleted inode 1324 has zero dtime. FIXED
/dev/hda7: Deleted inode 15987 has zero dtime. FIXED
Fix summary information? Yes
/dev/hda7: 46906/356000 files (1.6% non-contiguous),
      765217/1283507 blocks
```

This is fsck with the -a option, which answers all the questions with yes. For the most part, it corrects any errors that occur when the power
fails or when something breaks inside your computer, causing it to crash.
After fsck, it reports whether it modified any file systems.

# More Disk Storage

Sooner or later, you're likely to want to add more disk storage to your Linux
system to hold more programs, to hold more data, or to enable more users
in. Disk storage is usually added one or more disks at a time; each disk
can have one or more disk partitions.

The disk partition is Linux's basic file storage unit. First you create the
systems on the disk partitions, and then you combine the file systems to
form a single directory tree. The directory tree structure can be on
one disk or spread across many.

You can define disk partitions while adding a new disk or later. In most cases,
Linux defines disk partitions during the original Linux installation. You may
ddivide a disk into one, two, four, or more partitions, each of which may contain-na file system or be used as a swap partition. Swap partitions allow very
large programs or many small partitions to run even if they take up more
memory than you have as RAM in your computer. The total of all your swap
partitions and RAM is called virtual memory.
