# Going home

If you cd by itself, without any directory name, you are returned to your home directory. Just knowing that you can easily get back to familiar territory can be a comfortable feeling. There's no place like home.

You can use cd also with a relative specification. For example:

```
cd ..
```

If you are in the directory /usr/bin and type the preceding, you are taken to the parent directory called /usr, as follows:

```
maddog@shamet:~> cd /usr/bin
maddog@shamet:/usr/bin> cd
maddog@shamet:/usr>
```

![](bbox=[0.118, 0.403, 0.178, 0.477])

Here's a trick: If you cd <username>, you can go to that user's home directory. On very large systems, this command is useful because it eliminates the need for you to remember — and type — large directory specifications.

# Using cat to Create and Add Files

The cat command is simple, easy to use, and one of the most useful Linux commands. The name cat stands for concatenate, meaning to add to the end of. The cat command takes all the input it gets (mostly from the keyboard) and outputs it to the screen.

![](bbox=[0.98, 0.648, 0.18, 0.722])

Make sure you are not logged in as root when you go through this and the following sections. Wait until you are familiar with this chapter before you log in as root and try the examples. Linux (for the most part) doesn't have an undo function, although this is in the process of changing.

To find out the cat command is all about, in the /home directory. follow these steps:

+   1. Make sure you are in the /home directory.

+   To go home, click your wheels — no, that's another book. Type cd at the prompt and then type pwd.

+   2. Type cat at the command line:

```
maddog@shamet:~> cat
```

The cursor moves to the next line, but nothing happens because cat is waiting for you to input something.
