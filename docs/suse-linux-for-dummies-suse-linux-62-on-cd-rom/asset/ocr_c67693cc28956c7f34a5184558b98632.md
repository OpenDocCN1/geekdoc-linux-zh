Changing the partition type
For of your partitions, you will not have to change the type. However, when you create your swap partition, you must also set the partition type to Linux Swap. When the swap partition is highlighted, press the F3 function key and a list of partition types appears (see Figure 5-12). Select Linux Swap from the list of partition types (by using the down-arrow key) and press Enter.
When you are finishing your partitions (see Figure 5-13 for an example), press Enter.
