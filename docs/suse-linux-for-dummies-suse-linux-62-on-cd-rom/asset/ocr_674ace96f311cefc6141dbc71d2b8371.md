10. To save your new kernel configuration file, do the following:

+   a. Press the Enter key.

You see the following message:
Saving your Linux kernel configuration...
***End of Linux kernel configuration
***Next, you may run 'zimage', 'make zdisk' or 'make zlilo'

+   b. Type make dep; then type make clean.

+   c. Finally, make bzimage to make the new kernel. The recommendation to use bzimage is outdated. In most cases you not use make bzimage because make bzimage will not make a kernel that is small enough to be booted. This is not a problem with Linux, but a problem with the 1386 (Intel) architecture.

The new kernel will be compiled and placed in the /usr/src/linux/arch/i386/boot/ directory. If you look in that directory, you will see a file bzimage. That is the kernel that you just compiled!

We have taken you through a very simple reconfiguration of your kernel, changing only one small item. You have invoked the program that configures the kernel, allowed Linux to recognize and make all the dependencies for creating a new kernel, cleaned up old files in your directory structure, and made the kernel. But you are probably not finished at this point, in the next section, you take another larger step by redefining what you need for the kernel.
