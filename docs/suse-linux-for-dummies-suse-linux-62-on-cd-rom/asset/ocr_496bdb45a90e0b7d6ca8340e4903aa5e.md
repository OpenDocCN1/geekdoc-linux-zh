# 22 Part I: Introducing Linux

Another character-cell text editor is emacs, one of the shining stars of the Free Software Foundation. Devotees of emacs claim that it is more than just a text editor; it's an interface to reading mail, debugging your programs, reading news from the Internet, and a variety of other text-oriented activities. The program can emulate several character-cell editors. emacs has also made the jump to a graphical mode. Downsides of emacs are its size and its use of a fair amount of disk space. emacs is included on the CD-ROM that comes with this.

Based on the concept of being able to extend its capabilities by LISP, a powerful programming language, emacs is the only editor we have seen that can display a graphical illustration of the Towers of Hanoi problem on a character-cell video screen, and proceed to solve it, showing all the modes.

pico(1) is a simple, easy-to-use text editor with a simple front end for mail. Some mail programs integrate editors; some editors initiate mail programs; simply enable you to specify which editor you want to use and run that editor. Combining the function of editing and reading mail is often sensible because many people use only mail and editing applications.
