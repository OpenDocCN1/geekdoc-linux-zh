# Chapter 7: Using SuSE Linux for the First Time

+   Other Printer: Select this option if you have neither a Postscript printer or an HP deskjet printer. When you press Enter, you are presented with a list of available printer drivers. If the printer driver does not appear on the list, but it does appear in Appendix A, select the User Defined option at the top of the list and enter the name of the driver that you want to use for your printer. Then press Enter.

+   6. Select the appropriate paper format.

If you are in the U.S., you should select Letter. If you are in Europe, you should select A4. Press Enter.

+   7. Select the port that your printer is attached to.

Most printers are attached to a parallel port, so if you are not sure, select Parallel Port.

+   8. Select the device name.

Unless you know that your printer is not on the first parallel port (also known as the printer port), select /dev/lp0.

+   9. Accept the default resolution unless you know that your printer can use a higher one.

+   10. Press Enter again and, when the Install button is highlighted, press Enter and the printer configuration file will be created.

A confirmation screen will appear, indicating that your printer has been added.
