# Chapter 15: Setting Up Your Internet Connection

If you get a message saying that the system is not found, wait a minute more and try again. Eventually, you should get a message back talking about how many milliseconds it takes for a round-trip message. Congratulations; your networking is working.

To turn off networking, simply press the Ctrl and C keys simultaneously.

You have now set the hardware and software to connect your system to the Internet. Your computer has been joined with the Force.

Actually to surf the Internet, read e-mail, and otherwise interact with others on the Internet, check out Chapter 16, where you find out how to configure on Internet. and use a major tool of the Internet, the Netscape program.

KDE has a dialup configuration, which is called Kppp. You can find it by clicking the K button in the bottom-left corner of your desktop and selecting the Internet submenu. The first time that Kppp starts, you need to create a new dial-up configuration. The information that you need to provide for your Kppp dial-up configuration is much the same as what is needed for WvDial. The first screen has a HELP button that brings up a help menu describing each of the configuration options that are necessary. It is beyond the scope of this book to discuss two dial-up configuration tools in detail, but we felt that Kppp was worth mentioning.
