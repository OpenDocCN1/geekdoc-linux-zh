## Getting Around with pwd and cd

You can navigate the Linux file system without a map or a GPS. All you need to know are two commands: pwd and cd.

## Where am I?

To find out where you are in the Linux file system, simply type pwd at the command prompt, as follows:

```
maddog@shamet:~ ~pwd
/home/maddog
maddog@shamet:~
```

This indicates that we are logged in as maddog and are in the /home/maddog directory. Unless we have an alter ego out there, you should be logged in as yourself and be in the /home/yourself directory, where yourself is your login name.

The pwd command stands for print working directory. Your working directory is the default directory where Linux commands perform their actions. When you type the ls(1) command, for example, Linux shows the files in your working directory. Any file actions on your part occur in your working directory.

## Conventions without Shiners

You'll be seeing a list of commands, so you might find it helpful to review the syntax of Linux commands:

- Text inside angle brackets > must be replaced with appropriate text.
- Text inside braces {} indicates that you must choose one of the values that are inside the braces separated by the | sign.
- Text not surrounded by {}, {}, or > must be typed exactly as shown.
- Text inside brackets [] is optional.
- An ellipsis (...) means so and on to repeat the preceding command line as needed.

Type this command:

```
ls -la
```

The files you see are only those in your working directory. If you want to specify a file that isn't in your working directory, you must name the directory that contains the file, as well as the name of the file. For example, the following command lists the passwd file in the /etc directory:

```
ls -la /etc/passwd
```

## Every directory has a parent and lots of relatives

If the file you want to read is in a subdirectory of the one you are in, you can reach the file by typing a relative filename. Relative filenames specify the location of files relative to where you are.

In addition to what we told you about specifying directory paths, you need to know about these three additional rules:

- One dot (.) always stands for the current directory.
- Two dots (..) specify the parent directory of the directory you are currently in.
- All directory paths that include (.) or (..) are relative directory paths.

You can see these files using the -a option of the ls(-1) command. Without the -a option, the ls(1) command does not bother to list the . or .. files, nor does it list any filename beginning with a period.

Now specify a pathname relative to where you are. For example:

```
maddog@shamet:~ ~ pwd
/home/maddog
maddog@shamet:~ ~ ls -la ../etc/passwd
```

This indicates that to find the passwd file, we go up two directory levels (../../), and then down to /etc.

If you want to see the login accounts on your system, you could issue the following command from your home directory:

```
maddog@shamet:~ ~ ls -la ..
```

This command lists the parent directory. Because the parent directory (/home) has all the login directories of the people on your system, this command shows the names of their login directories.

You have been looking at relative pathnames, which are relative to where you are in the file system. Filenames that are valid from anywhere in the file system are called absolute filenames. These filenames always begin with the slash character (/), which signifies root.

```
ls -la /etc/passwd
```

## Changing your working directory

Sometimes, you might want to change your working directory because doing allows you to work with shorter relative pathnames. To do so, simply use the cd (for change directory) command.

To change from your current working directory to the /usr directory, for example, type the following:

```
cd /usr
```

## Going home

If you cd by itself, without any directory name, you are returned to your home directory. Just knowing that you can easily get back to familiar territory can be a comfortable feeling. There's no place like home.

You can use cd also with a relative specification. For example:

```
cd ..
```

If you are in the directory /usr/bin and type the preceding, you are taken to the parent directory called /usr, as follows:

```
maddog@shamet:~> cd /usr/bin
maddog@shamet:/usr/bin> cd
maddog@shamet:/usr>
```

## Using cat to Create and Add Files

The cat command is simple, easy to use, and one of the most useful Linux commands. The name stands for concatenate, meaning to add to. The cat command takes all input it gets (mostly from the keyboard) and outputs it to the screen. To find out the cat is all about, follow these steps:

1. Make sure you are in the /home directory.
2. Type cat at the prompt:
```
maddog@shamet:~> cat
```
The cursor moves to the next line, but cat is waiting for you to input.
3. Type Hi and press Enter. Then type a few lines.

Here's what we typed:
```
maddog@shamet:~ ~ dogfile
Hi again
Dogfish. Dogleg. Dog days.
Dogghouse. Dogfight.
```
To get out of the command, press Ctrl+D. If you're not at the beginning of a line, press Ctrl+D twice. Most UNIX and Linux people write Ctrl+D as 'D', which makes end of file (EOF) to Linux. When the cat command sees 'D', it assumes it's finished with that line and moves to the next. If 'D' is on an empty line by itself, the cat command has no other output to move to and thus exits.

We promised we would explain the usefulness of the cat command. Here you know three symbols:

- > is known as redirection of standard output. When you use this symbol, you tell the computer, "Capture the information that normally goes to the screen, create a file and put the information into it."
- > is known as appending standard output. When you use this symbol, you tell the computer, "Capture the information that would normally go to the screen and append the information to an existing file. If the file does not exist, create it."
- < is used to tell the computer, "Take the information from the specified file and feed it to standard (also known as standard input), acting as though the information is coming from the keyboard."

In the following example, you use the cat command to create a file by redirecting the output from the screen to the filename you want, like this:

1. At the command line, type cat > followed by the name of your file. Then begin typing.
