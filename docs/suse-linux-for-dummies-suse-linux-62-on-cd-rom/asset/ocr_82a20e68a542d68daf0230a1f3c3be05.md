# 74 Part II: Installing SuSE Linux

The other extreme of installing Linux is to create a partition for each of the following areas:

+   - A root partition mounted as / (the root directory) where the kernel necessary to boot the system and the system configuration resides. This partition needs to be only 30MB to 50MB.
- swap partition, which enables Linux to take advantage of virtual memory. Although not required, we strongly recommend that you have a swap partition. As a rule, the swap partition should be twice the size of the memory (RAM) installed in your computer. If you have 32MB of RAM installed on your computer, for example, your swap file should be 64MB. Having more swap space allows programs to run simultaneously or larger programs to run with more data. Linux allows for multiple partitions up to a total of 16 on Intel platforms. The maximum size of each partition is 127MB. If you decided to use YaST to partition your hard drive for you, it will create a 127MB swap partition.
- /home partition, where the users' home directories go. Its size is influenced by how many users you have planned for the system. 100MB is a good starting point.
- /local partition, for storing programs you want to separate from the rest of the SuSE Linux software.
- /tmp partition, an additional partition for temporary files in larger multiuser systems and network file servers.
- /opt partition, where third-party software will be installed. The size of this partition will depend on how much third-party software you will be installing. Such third-party applications might include StarOffice or Applicware, as KDE.
- /usr partition, where most of the software on the Linux system resides. It should be about 150MB to 350MB, depending on what packages you are installing.
- /usr/src partition, which contains much of the Linux source code.
- /var partition, which is a good idea for servers that run continuously (generate logs of log files) and provide lots of e-mail services. On major servers, this partition can be more than a gigabyte!

The problem with this type of setup is that you have a lot of separate partitions that cannot share their space. If you need a little more space in your /tmp partition, for example, and your /home partition is almost empty, Linux cannot easily use the space in /home for /tmp usage. This is particular of smaller systems that have fewer disks and less disk space. Another problem with this arrangement, especially for first-time Linux users, is that you need to know your space requirements for each of the partitions. It is not easily determined, because at this point you have not chosen the software packages that you want to install.
