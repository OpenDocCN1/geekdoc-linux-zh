# Chapter 13: File System Management

After you set up the /etc/fstab configuration file, file systems can be mounted automatically at boot time. In addition after the /etc/fstab file is set up, the mount and ummount commands require only mount-point and block-special-file as their argument.

Normally, most of the /etc/fstab file is set up during installation, so you only have to update it over time as you add new disks or partitions.

In SuSE Linux, you can use YaST to update the /etc/fstab file, so that you don't have to edit the file with a text editor (although you still have this option). YaST is one of the features of SuSE Linux and is on the SuSE Linux for Dummies CD-ROM; you can update the file with YaST, as follows:

+   1. Log in as root or superuser.

+   2. Type startx to make sure that X Window System is operating.

+   3. Click the YaST icon on the panel.
nThe dialog box shown in Figure 13-1 appears.

+   4. Using the down-arrow key on your keyboard, select Adjustments of Installation from the main menu and then press Enter.
The dialog box shown in Figure 13-2 appears.

+   5. Using the down-arrow key on your keyboard, select Set Target Partitions/Filesystems from the menu list.
The dialog box shown in Figure 13-3 appears.
