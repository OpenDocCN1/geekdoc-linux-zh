# 76 Part II: Installing SuSE Linux

On IDE devices, cylinder 1023 is generally below the 512MB mark for SCSI drives, it is usually below the 1GB level. If you are using smaller disks, you're probably okay. Otherwise, you probably need to take this issue into account as you are installing the system. The easiest way to ensure the kernel is located on cylinders 0 to 1022 is to make your entire root partition below the 1023rd cylinder level; you can specify this with the fdisk program when you get disk partitioning. Newer versions of BIOS support Logical Block Addressing (LBA), so they may not have this limitation. By using LBA, you can fool the BIOS into seeing the disk as having less than 1023 cylinders.

# Partitioning — slicing and dicing your hard drive

When Linuxrc loads YaST, you are prompted by the first dialog box titled Type of Installation, as shown previously in Figure 5-4. Because this is your first installation, you should select installing Linux from Scratch. The next dialog box that appears whether you want to partition, and you should select Partitioning. YaST automatically recognizes free space on your hard drive and asks whether you want to use it for your Linux installation. Because you want (or need) to create the partitions yourself, you should select No (if you select Yes, YaST creates the partitions for you). In the dialog box, Use Entire Disk, and you are asked whether you want to do the partitioning or use the entire disk. Here you need to select Partitioning once again.
