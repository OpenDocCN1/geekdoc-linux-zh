# Tapes Drives

When backing up your system, using a tape drive is way to get a lot of storage on one device (2 or 4GB or higher). Linux supports most SCSI tape drives. Other drives sometimes uses the floppy controller (such as the Colorado FC-10/FC-20, Mountain Mach-2, or the Iomega Tape Controller II ) or hook up to the IDE controller (Seagate TapeStore 8000 and Conner CTMA 4000 IDE ATAPI streaming tape drive).

Note that Linux does not support tape drives that plug into the parallel.
