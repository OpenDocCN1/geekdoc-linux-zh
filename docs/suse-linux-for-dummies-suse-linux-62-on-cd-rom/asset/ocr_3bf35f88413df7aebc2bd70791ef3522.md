# Instructions and data not needed

Although remaking the kernel and changing only the processor type will typically make your system go faster by utilizing new instructions in the CPU architecture, just changing the processor type will not anything for the size of the kernel, which may be very large if you've requested support for features you don't use. Simply changing the CPU architecture will also not support functionality or devices not listed in the installation kernel.

Fortunately, a lot of support for different kernel functionality and device drivers is in modular form and is available through both loadable kernel modules and loadable device drivers. Because of these two features, a Linux kernel out of the distribution handles a many devices and features without having to be rebuilt. If a specific feature does not seem to work, however, a look at the kernel configuration is probably in order.
