# Meaningful login names

The name that you choose for your login name is also the name you will use to send and receive e-mail, so choose the name carefully. Names that seem cute or appropriate now may not later. Nor should you choose a name that is too long, because you may have to type it several times a day. You may also have to give your e-mail address over the telephone, so a login name such as phool will result in mis-messages, leaving you feeling very foolish.

# Adding a Printer

If you are logged in as root, you might want take a few minutes to configure your printer. You can find a list of supported printers in Appendix A.

+   1. Start YaST as described in the previous section and select the System Administration submenu.

+   2. Select Integrate hardware into system from the menu list.

+   3. Select Configure Printers from the menu list.

You should now be looking at the printer configuration dialog box, shown in 7-5.

+   4. If you have a color printer, press the space; when an X appears in the box, press Enter.

+   5. Next you need to select the Printer Type. You have three options:

+   * Postscript Printer: Select this option if you have a Postscript printer. When you press Enter, you are prompted to specify the resolution of your printer.

+   * HP Deskjet: Select this option if you have a Hewlett Packard printer. When you press Enter, you are presented with a list of HP printers. Select your printer from the list. If your printer does not appear on the list, select the one that is closest to your printer. If you cannot find one, have a look in Appendix A, which contains a list of the available printer drivers and the different printers that support.
