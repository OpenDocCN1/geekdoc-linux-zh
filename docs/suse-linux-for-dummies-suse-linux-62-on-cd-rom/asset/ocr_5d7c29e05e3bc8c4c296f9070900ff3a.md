# From the Simple to the Sublime

You have written a program, but it always works on the same file, which is hard-coded into the script. For the rest of this chapter, we show you how to create more flexible shell scripts, ones that can generate different filenames as needed and can automatically adapt to being run on different dates.

Suppose that you want to keep monthly copies of the passwd file and see the differences between them. First, write a program that saves a copy of the passwd file and stores it in a directory:

+   1. Use the cat command to create a script in your ~/bin directory called genreport.

The genreport script is simple. It copies the file /etc/passwd to standard output using the cat command; the redirection symbol puts it into a file.

+   2. For a filename that the script will generate when it is executed, start with the name passwd, but attach the year and the month to it:

For example, the passwd file for July 1998 would be passwd199807, and the one for August 1998 would be passwd199808.

To create these files, execute the date command inside the shell script and use it to append to the word passwd. If you use the backward single quotation mark (called accent grave) around the date, it generates the numbers 199807 to be appended to the string of characters passwd, if they are July 1998. The accent grave tells Linux to "execute what is between the accent grave symbols as a Linux command, and use the result of that as a string in the larger command." Therefore, the date command generates the string 199807, which is appended to the name passwd to create passwd199807.

If you're searching your keyboard for that accent grave character, you may find it under the tilde character.

+   3. When you make this file in your bin directory, don't forget to change its permissions to make it executable.

This is the program that we generated and an example of it running:

```
maddog@localhost:~/bin ~ cat ~/bin/genreport
cat /etc/passwd > passwd+%%Y%m"
<CTRL+D>
maddog@localhost:~/bin ~ chmod u+x ~/bin/genreport
maddog@localhost:~/bin ~ cd
maddog@localhost:~/ ~ mkdir reports ; cd reports;
maddog@localhost:~/reports > genreport
maddog@localhost:~/reports > ls
passwd199907
maddog@localhost:~/reports >
```
