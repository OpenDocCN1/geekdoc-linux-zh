# Text Editors

Linux systems often come with several different text editors. Text editors are programs that typically enable you to type and manipulate alphanumeric characters. Some text editors can do simple word processing tasks such as word wrap, but they can't perform most word processing functions, such as spell checking or italicizing text.

Text editors are good for simple text-editing tasks and for writing simple or complex programs. Most have built-in help functions, and some have full-scale documentation built in or available online. In addition, you can find books about a few editors, such as vi(1) and emacs(1).

In this section, we describe character-cell text editors and graphical-based text editors that you can find freely available software or as shareware. We also describe some commercial text editors.

# Character-cell text editors

ed(1) is the oldest character-cell text editor and comes with every UNIX system. ed is difficult to use because it doesn't normally show you the entire file, and it doesn't show you the changes you've made until you ask it to do. Those who use are usually old-time UNIX users with gray beards who wear suspenders with their shorts. Even with these downsides, it's useful to know how to use ed because it usually comes with every Linux system. ed is on the CD-ROM that this book.

Following quickly after the introduction of ed was an extended editor called ex(1) and a visual front end to it called vi(1). vi was written in the mid1970s and allowed people to see a whole screen of text at one time! Believe it or not, this was big news in those days. Many Linux systems ship with a new version of vi vim(1), for "vi improved".

You can execute vim by typing vim, but SuSE Linux has a link to it and ex. A link is to give two names to the same program. Although the same program is being executed, the system stands and looks at what the user types when starting the program. For example, if the user types vi, the program starts vim.
