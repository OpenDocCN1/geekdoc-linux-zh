In the first screen, which is shown in Figure 5-1, you see an information screen with the addresses and telephone numbers of SuSE offices in Oakland and Nuremberg. At the bottom of this screen you will see a boot prompt. After a few seconds, Linuxrc will start to load the Linux kernel into memory.

Linuxrc? What about YaST? Before you start YaST, you use Linuxrc to set some basic hardware parameters and specify which installation medium to use for installingSE Linux. After a few seconds, a series of messages scrolls by, indicating the hardware is being detected by the Linux kernel. If the hardware is not being detected, you may have to reboot and add some options at the boot prompt. For example, if the system doesn't detect your CD-ROM drive, and if it is an IDE CD-ROM, which is a master on the secondary IDE chain, you might have to eject the following:

Boot: Linux hdc=cdrom

Most of the time — particularly with newer systems — Linux detects all basic hardware. (Additional boot prompt options are given in Appendix A.) Then a welcome message displays and the installation program begins.

## It’s a small, small world

Different countries have different keyboards. Linux, like many UNIX systems, have a keyboard mapping feature that enables you to use it with different keyboards.

If you are in the United States, you will probably choose the English (US) option. Even however, you might have a different keyboard than the US English keyboard, so browsing through the list to see what else it offers is worthwhile.

Figure 5-2 lists some of the keyboard maps for your system.

If you are not in the United States, you will probably choose something other than the English (US) keyboard, unless you bought your system in the United States. If you don't see an obvious choice, choose something that looks close. If it seems to work, finish the installation. After the installation, you can change the keyboard mapping with YaST, under the menu option Adjustments of Installation. YaST is described in more detail in Chapter 7.

The Start Installation option is what one would choose in most cases. However, if you have an older proprietary CD-ROM, a SCSI hard drive, a SCSI CD-ROM, or PCMC CD-ROM, you to do one additional step before starting the installation, as described in Step 8. But first, the other options in the Linuxrc main screen are as follows:

- **Settings.** Use this option to change the language, color, and keyboard mapping. You selected these settings in the previous screens, but if by chance you made a mistake, you can use this menu option to resolve it.
- **System Information.** Select this option to view various information that is known about your system. For example, in the System Information submenu are menu options for kernel (this is the text that scrolls by when you first booted up), Hard disks/CDROM (this shows you a list of hard drives and CD-ROM that were detected at boot up), Modules (this shows you a list of currently loaded modules), and PCI (this shows you a list of PCI devices on your system). You can use the other menu options to display information about other parts of your system, as their names suggest.
- **Kernel Modules.** You can use this option to load modules. Modules are used to provide access to certain types of hardware during the installation.
- **End/Reboot.** Select this option if you want to abort the installation.

- 7. If you have a SCSI CD-ROM, a SCSI hard drive, a non-ATAPI compliant CD-ROM, or PCMCIA CD-ROM, you must load the correct module. To load the correct module for your hardware, select the appropriate submenu (for example, SCSI Module) and then select the appropriate module for your hardware. If you are unsure about your hardware, you can also try the Autoload of modules menu option. This menu option, shown in Figure 5-4, will try to load each of the modules one at a time. The module (or modules) that are successfully loaded will be reported to you. In some cases, you will be prompted to install the modules diskette. This is the diskette you created in Chapter 4. Note that when loading modules, you will be prompted for parameters. In most cases, you do not need to specify any parameters. In the event that the module was not successfully loaded, please refer to Appendix A where examples of module parameters are given.

At this point, you should have, if necessary, the appropriate modules for your hardware. You are ready to install SuSE Linux.

- 8. Select Start Installation.
- 9. In the next menu that appears, select "Start Installation."

This menu list includes a few other options, such as Boot Installed System, Start Rescue System, and Start Live System. The Boot Installed System is available in the event that the Linux boot loader becomes corrupted and is not working. You can use this menu option to boot a currently installed Linux system. At this point, because you have not yet installed Linux, this option cannot be used. It is good to know about this option if, after you have installed Linux, you are having trouble booting.

- 10. Select CD-ROM when the next menu asks you for the location of the source media; then press Enter.

At this point, Linuxrc YaST. YaST is used to complete the installation. The other menu options, or their names suggest, are available for installing Linux from a source other than the CD-ROM. We consider these more advanced installation procedures that are not within the scope of this book.

- 11. Install Linux from Scratch (because this is your first installation) from the first screen in YaST, titled Type of Installation (see Figure 5-5).

- 12. Select the Partitioning menu option on the Partitioning Hard drives (wait, text says "Partitioning menu option on the Partitioning Hard drives") that appears next (you do this because it's your first installation); then press Enter.

At this point in the installation process, you see different screens, depending on how your hard drive (or hard drives) is configured. The three basic scenarios are described in the following list. In all cases, we recommend that you allow YaST to create the partitions for you. If you want (or need) to manually create the partitions, you can skip ahead to the following section, where we provide a description on how to partition your drive manually.

- Scenario 1. If you have only one hard drive in your computer and you are planning to install Linux on the whole hard drive, you should select the Whole Hard Disk menu option (see Figure 5-6). A large red screen appears, warning that all information on the disk will be destroyed if you select this option. Because you want to install Linux on your whole hard drive, you do not need to be alarmed; select Yes and press Enter.
