In addition to parameters, you also have the choice to select Automatic DNS, Dial Method, Modem on PBX (no dial tone), and Authentication Mode. Automatic DNS is set by default, with most ISPs, you can have your DNS setting automatically configured. To change the dial method from tone to pulse, highlight the option, press Enter, and then select Pulse from the menu option using the down-arrow key on your keyboard. If you are dialing from a PBX and do not have a dial tone, you will need to enable the Modem on PBX (no dial tone) option. You enable this by highlighting that option and pressing the spacebar. Finally, you may need to set the authentication method. Most ISPs use PAP/CHAP, but if yours does not, highlight the Authentication option and select the appropriate authentication method from the dialog box.

When you are done with these configurations, use the right-arrow key on your keyboard to select Exit; then press Enter. You will return to the main Wdial dial box.

You should hear a dial tone as your modem picks up the load, and then you hear your modem dialing the number. After one or a few rings, you hear a scratchy, squawking sound and then silence.

After a few seconds, networking is working and your computer is tied to the Internet. As a test that everything is okay, bring up a terminal window and type the following at the command-line prompt to communicate with a major system at Compaq Computer Corporation:

```
ping gatekeeper.dec.com
```
