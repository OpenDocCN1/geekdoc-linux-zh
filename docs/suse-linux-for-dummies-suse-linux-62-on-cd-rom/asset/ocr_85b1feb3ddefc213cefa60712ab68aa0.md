After you know this information, you can use YaST: System Administration/Integrate Hardware into System/Configure Modem to create a link between the device that Linux thinks is attached to the designator /dev/modem. It is possible that you have already successfully completed this during the installation, when you were prompted to configure your modem. If you did not, then you can do so here.
