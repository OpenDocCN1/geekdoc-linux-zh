# Part II: Installing SuSE Linux

You use the Package Information option to search for packages. When you select this option, you are presented with the Package Information screen, shown in Figure 5-22. From this screen, you have three choices for your search. Using a combination of the Tab and space keys, you can highlight and select/deselect the following options: Search Install Media; Search System; and Case Sensitive Search. Below three options is the input entry for your search string. When this box is highlighted, you can type the string of text that you want to search for and press Enter. The search is presented with a list of packages that contain your search string.

Figure 5-22: Searching for information.

The Install Packages menu option is provided for installing packages that are not on the installation media. For example, you can install a package that you have downloaded from the Internet, or you can even install a package from an FTP server. Because we don't use this feature during the installation, we don't discuss it here.

You use the Delete Packages option to delete packages from your system that were added with the Install Packages option described previously. You won't need this option during installation.

# Selecting a boot kernel

At this point, you should have completed the installation of the selected packages. If you have not, select the Start Installation option. After the packages are installed, select the Main Menu option to continue with the installation.
