# Scanners

Scanners are our second-most-favorite piece of hardware because they enable us to scan all types of pictures and then manipulate them with gimp(1), an image manipulation program comparable to Adobe Photoshop Linux has an interface SANE that enables you to attach and control many types of scanners. The scanners currently supported are A4 Tech AC 4096/AS 8000P, Adara Image Star I, Conrad Personal Scanner 64, P105 hand-held scanners, Epson GT6000, Fujitsu SCS2 handheld, Genius ColorPage-SP2, Genius GS-B105G handheld scanner, Genius GenScan GS4500, GS45000 hand-held scanners, HighScreen Greyscan 256 handheld scanner, HP ScanJet II scanners SCI, HP ScanJet IIc, Ilc, Ip, 3c, 4c, 4p, 5p, 5pe, plus, Logitech Scan+,man 32, Scanner 256 handheld scanners, Microtek Mustek M1005 handheld scanner, Mustek HT800 Turbo, Matador 105, Matador 256 handheld scanners, Mustek Paragon 600CX, Nikon SCSI 35mm film scanner, Pearl 256 handheld scanner, and Uranus SCSI scanners.
