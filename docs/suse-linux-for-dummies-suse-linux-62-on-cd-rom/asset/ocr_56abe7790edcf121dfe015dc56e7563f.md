# 156 Part III: Using Linux

You can start the vi editor in a number of ways with different options, but the most common way is to start vi with only a filename as the argument, like this:

```
vi tove.and.linux
```

tove.and.linux is the name of either an existing file that you want to edit or a new file you want to create.

The vi editor has three modes of operation:

+   - Visual command mode
- Colon command mode
- Text mode

When you invoke vi with a filename, the editor appears. At the bottom-left corner is the following line:

```
"filename" [New File]
```

This status line tells you what the editor is doing. In this case, the editor has opened a buffer and the save and quit option saves the contents of the buffer to the filename file. If you indeed invoke vi with the following command:

```
vi tove.and.linux
```

the bottom-left corner would display the following line:

```
"tove.and.linux" [New File]
```

When you first invoke vi, you are in visual command mode, which is the default. You can use four special commands to either locate text or transition to more complex commands:

+   - Forward search
- Backward search
- Continue the search in whichever you are currently going
- ex command (is the line editor included in vi)

In command mode, the characters you type are used as commands, not as input into the file. To use commands, type the character on the command line. For the first two search commands (/ and ? the cursor moves to the bottom of the screen, where you then type the string you are searching for. When you press Enter, the search begins. If you want to search for an additional string, you can just press N to reexecute the search.
