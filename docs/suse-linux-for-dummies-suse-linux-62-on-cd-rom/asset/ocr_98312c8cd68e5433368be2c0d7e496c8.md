# Part II: Installing SuSE Linux

# Making boot and supplemental
disks in Linux

If you don't have access to MS-DOS or Windows but do have access to another SuSE Linux system, this section is for you. To make the boot and supplemental disks in Linux, you must be logged in as a user with permissions to write to the 3½inch drive, which /dev/ refers to as /dev/fd0.

To make the boot disk, put a blank, formatted floppy in the floppy drive. Place the SuSE Linux For Dummies CD-ROM into your CD-ROM drive and mount the Linux CD (connecting it to the rest of the file system) by typing the following:

![](bbox=[0.095, 0.283, 0.185, 0.345])

```
mount /cdrom /mnt
```

Change to the disks directory by typing

```
cd /mnt/disks
```

Finally, type the following command:

```
dd if=eide0 of=/dev/fd0
```

After the floppy disk light goes out, you may make the supplemental disk if needed. Even if you don't need a supplemental disk, it's a good thing to have, so place a blank disk in /dev/fd0 (the floppy drive) and then type this command:

```
dd if=modules=/dev/fd0
```

After you are finished making the floppies, you may dismount the CD-ROM (remove it from the rest of the file system) by typing these commands:

```
cd /
umount /cdrom
```

Wait until the floppy drive light is out before removing the floppy disk.

# Move Over and Make Room for Linux

Before you install Linux on your system, you need to make room for it. Some people find space by getting rid of MS-DOS and Windows. Others don't want to make such drastic changes and prefer to have both Linux and their other operating system peacefully coexist. If that fits the bill for you, the easiest way to go is to add a new hard disk — either IDE or SCSI — to your system and install SuSE Linux on.
