At this point, the Continue button is highlighted. Press Enter to return to the main LILO installation window. You should see the boot configuration that you just created is now available. If you want to configure your system to dual boot, you need to create a second configuration. Press F4 to create a new configuration and add the appropriate information in the fields. An important point is to note about configuring boot to DOS: You do not need to specify the actual kernel (see Figure 5-27).

To finish installing LILO, press Enter and the Continue button is highlighted, then press Enter. You then see the output of installing LILO. If the installation worked correctly, you will see that it added your configuration. If you see a error message, you need to go back and double-check your configurations. If no errors appear, press Enter.

If you are creating a dual boot system, because you have Windows on one of your hard drives (or hard partitions), you should create a boot option now. Press F4 and fill out the screen. For this configuration, use DOS as the configuration name. The root partition will be the partition that has Windows system. You do not need to specify a kernel to boot.
