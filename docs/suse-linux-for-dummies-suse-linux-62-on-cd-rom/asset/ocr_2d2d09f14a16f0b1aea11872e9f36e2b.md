Therefore, filenames that are always there (..) and special-purpose files are hidden. The types of files that should be hidden are those that the user does not need to see in every list of the directory structure (files used to tailor applications to the user's preferences, for example).

Now specify a pathname relative to where you are. For example:

```
maddog@shamet:~ ~ pwd
/home/maddog
maddog@shamet:~ ~ 1 ls -la ../etc/passwd
```

This indicates that to find the passwd file, we go up two directory levels (../../), and then down to /etc.

If you want to see the login accounts on your system, you could issue the following command from your home directory:

```
maddog@shamet:~ ~ 1 ls -la ..
```

This command lists the parent directory. Because the parent directory (/home) has all the login directories of the people on your system, this command shows the names of their login directories.

You have been looking at relative pathnames, which are relative to where you are in the file system. Filenames that are valid from anywhere in the file system are called absolute filenames. These filenames always begin with the slash character (/), which signifies root.

```
1 ls -la /etc/passwd
```

# Changing your working directory

Sometimes, you might want to change your working directory because doing allows you to work with shorter relative pathnames. To do so, simply use the cd (for change directory) command.

To change from your current working directory to the /usr directory, for example, type the following:

```
cd /usr
```
