# Chapter 4: Making Room for suSE Linux

```
D:\> cd \dosutils\rewrite
```

Now type rewrite and press Enter. You are prompted for the location of the source file, which you need to specify and specify, and then the target diskette drive, which is your floppy drive. For example:

```
D:DOSUTILS\REWRITE> rewrite
Enter disk image source name: d:\disks\eide01
Enter target diskette drive: a:
Please insert a formatted diskette into drive A; and press
-ENTER-: <Enter>
```

Now you return to the command prompt, which should look like this:

```
D:\DOSUTILS\REWRITE>
```

RAWWRITE copies the boot image to the floppy.

Now you can use the RAWWRITE program again to copy the modules disk image to the other blank disk. Remove the boot floppy (label "Boot Floppy") so that you know what it is and replace it with another floppy disk, which you should label "Modules Disk." Then perform the following stops, just as you did for creating the boot floppy, but this time you are copying the modules image to the floppy. The steps should look like this:

```
D:\DOSUTILS\REWRITE> rewrite
Enter disk image source name: d:\disks\modules
Enter target diskette drive: a:
Please insert a formatted diskette into drive A; and press
-ENTER-: <Enter>
D:\DOSUTILS\REWRITE>
```

The two disks that you created (the boot and modules disk) do not have a normal MS-DOS file system. You cannot list the directory of the floppy disk that you made with MS-DOS. Trying to do a directory list of it results in an error message from MS-DOS.

While you are doing this, you should also put a copy of FIPS.EXE on your C disk. Change to the directory FIPS (which is in the dosutils\fips\fips20 folder for your suSE Linux for Dummies CD-ROM), and use this copy command to copy the FIPS.EXE file to your C:\ drive. An example of this command follows. You use FIPS later in this chapter to partition your disk in a nondestructive partitioning. Following the type below appears in:

```
D:\DOSUTILS\FIPS\FIPS20> copy fips.exe c:\fips.exe
```
