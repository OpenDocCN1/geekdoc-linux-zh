# Working with Files and Commands

+   In This Chapter
- Understanding files and directories
- Finding your way through the Linux file system
- Changing where you are in the Linux file system
- Creating, moving, copying, and destroying directories and files
- Giving permissions and taking them away
- Puzzling out command syntax
- Discovering a few Linux commands
- Modifying commands to suit your fancy

In this chapter, you take your first steps through the directory. We introduce you to file types, subdirectories, and the root directory, and we show you the way home — to your home directory, that is.

Next, you discover that you don't need a map to find your way through the Linux file system; a few commands will do the trick. Now that you're oriented yourself, it's time to make some changes. You find out how to copy and move files and directories, and how to create and destroy them.

Then it's to the next step: changing not a file itself, but its ownership and permissions. You end your journey through this chapter by divining the meaning of the Linux command syntax and practicing your use of that knowledge by tweaking a few Linux commands.
