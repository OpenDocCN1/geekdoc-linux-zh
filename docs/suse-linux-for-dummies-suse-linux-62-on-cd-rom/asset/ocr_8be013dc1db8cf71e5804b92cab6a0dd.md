# # Surfing the Web

**In This Chapter**

+   - Tailoring Netscape to suit it
- Checking out Web pages
- Getting and reading e-mail
- Sending your first e-mail message

Once upon a time there was a company called Netscape that created a browser called Mozilla. Despite the fact that the company spelled the name "Netscape," you were supposed to pronounce it "Mozilla." In any case, the browser was one of the best in the world (if not the best), and the folks at Netscape made it better by turning it over to the Open Source community to help them improve it.

Over time, Mozilla not only could surf the Web but also read e-mail, gather files using the File Transfer Protocol (FTP), run simple programs using Java, and even read Netviews (a discussion group made up of thousands of categories over the Net), all through a single graphical interface.

In this chapter, you set up Netscape for your system. Then, with the information from your ISP, you finally surf the Web and receive e-mail.
