Next you have to scroll down and find the section of the file that is preconfigured for your sound card and remove the comment symbol from the lines that begin with any of the following words: alias, post-install, or mpu. Here is an example of a section of the file that is preconfigured for a Soundblaster or clone sound card:

```
********************************
# module: sb.0 Soundblaster 16, SB Pro + Clones
#                               Also needed for AWE32/64
#
# Documentation available in
# /usr/src/linux/Documentation/sound/Soundblaster
# and in /usr/src/linux/drivers/sound/sb.c .
#n# Possible configuration:
# alias char-major-14 sb
# post-install sb /sbin/modprobe "-k" "adlib_card"
# options sb io=0x220 irq=7 dma1=6
# mpu_io=0x330
# options adlib_card io=0x388
********************************
```

What you see in this example is the full name of the module
(sb.o), a list of cards that use this module (Soundblaster 16, SB
Pro + Clones, also needed for AWE32/64), and a description of
where additional documentation can be found. Turning toward the bottom
of this section, you see few cryptic-looking lines. These are the
lines that contain the information concerning which resources
your sound module should use. In this example, we are
using the sb module to support a Soundblaster card, we need to
uncomment out these lines, like this:

```
#
#alias char-major-14 sb
#post-install sb /sbin/modprobe "-k" "adlib_card"
#options sb io=0x220 irq=7 dma1=6
#mpu_io=0x330
#options adlib_card io=0x388
#
#
```
