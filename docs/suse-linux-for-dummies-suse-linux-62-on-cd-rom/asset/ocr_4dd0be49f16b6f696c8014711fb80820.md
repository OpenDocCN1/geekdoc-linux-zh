# Chapter 15: Setting Up Your Internet Connection

```
/sbin/pnpdump -c > /etc/isapnp.conf
```

You can verify that it worked by having a look at the output of this command:

```
/sbin/isapnp /etc/isapnp.conf
```

This command will initialize your plug-and-play devices. Here you have to do it manually to verify that your configuration file is correct. When the system reboots, it will automatically issue this command, so you do not have to do it manually again. If the /etc/isapnp.conf file is correct, then you should see output something like this:

+   * Board 1 Identity ea 89 82 ff a 02 00 72 56: USR0002
  Serial No 3112730091 [checksum ea]

2. If you receive a warning message, then you most likely have a resource conflict; the only way to resolve this conflict is by modifying the settings in the config file that you created:

```
/etc/isapnp.conf
```
