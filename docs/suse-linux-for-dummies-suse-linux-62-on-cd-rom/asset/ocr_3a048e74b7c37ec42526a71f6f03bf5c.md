# Chapter 10: Avoiding Shell Shock

```
username@hostname:~ > !! | sort
cat /etc/passwd |sort
username@hostname:~ >
```

The /etc/passwd file is pulled from the disk and passed to standard output, fed into the standard input of sort, and then output to the screen in sorted fashion.

Several shells (such as csh, bash, tcsh, and zsh) have this type of simple editing, but bash also has more elaborate editing.

# Back to the future

Linux offers a handy tool for rerunning long commands that you've already entered. Press Ctrl-P and the display scrolls through the history of the commands you entered one command at a time, in reverse order, with the most recent command first. When the command you want appears on the screen, press Enter to run it.

# Do what I want, not what I said

Suppose your mind has been on passing fancies, and although you remember that a file in /etc contains passwords, you can't remember whether the file is in /etc/passwd, /etc/password, or whatever. You may want the command interpreter to choose the proper spelling of the filename for you, rather than what you think it might be.

```
username@localhost:~ ~ ls /etc/passwd*
/etc/passwd
username@localhost:~ ~ more /etc/passwd
```

You can use a shortcut with bash by pressing the Tab key after you have a unique name:

```
maddog@localhost:~ ~ more /etc/passwd
```

The shell automatically expands the name of the file to /etc/passwd, and then hesitates to see whether you want to accept the command:

```
maddog@localhost:~ ~ more /etc/passwd
```
