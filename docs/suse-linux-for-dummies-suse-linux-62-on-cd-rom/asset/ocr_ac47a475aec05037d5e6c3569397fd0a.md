# Appendix B: The linux man Pages 319

This list has lots of environmental variables, but we can't describe them all.
Here are the most important ones:

+   - PATH tells all the places to look for commands
- HOME tells cd where to go when you don't supply any arguments
- OSTYPE tells the shell and what operating system they are on

Different shells have different ways to set these variables (and create and others) to tell the commands what to do.

Note that a variable not set to some value (null) is different from a variable that doesn't exist (unset), and these differences vary from command to command. For example, in the preceding list, the first variable, USER, is set to NULL. The fact that it is there at all is significant. The fact that it is set to NULL instead of some other value is also significant to various programs.

# Diagnostics

Error messages or exit codes indicate that something has gone wrong in the program or the shell. Normally, UNIX error messages are terse. Sometimes things may seem to be wrong, but they are really okay. For example, most new users of UNIX think that when they issue an ls in an empty directory, they should get an error message such as directory empty or file not found. The problem? The command ls itself can display the filenames in any order (as opposed to ls *, which displays the files in alphabetical order). Therefore, if you have a directory with three files in it named file, not, and, found, you couldn't determine whether the directory is empty or not. Granted, this is a contrived example, but the developers of UNIX thought less is better than more (we're not talking about the command names less and more), and silence is golden (which means if you've ever heard old ones, noisy, hardcopy terminals).

Most programs display an exit code, which you normally don't see unless it is a non-zero code, which means the program ended unsuccessfully. If you are a programmer, you can test for this, and if you do programming or shell script writing, we encourage you to set and test exit codes.
