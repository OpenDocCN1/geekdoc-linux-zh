# 174 Part III: Using Linux

The shell automatically expands a filename and then hesitates, waiting for you to confirm a command by pressing the Enter key, this is known as command completion. Now you can press the Enter key to execute the command.

But wait! What happens if you have two files, one /etc/passwd the other /etc/password? When you press the Tab key, the system rings the bell and the name does not expand. Press the Tab key a second time, and show you all possible expansions of that argument. If a huge number of expansions result, bash warns you:

```
maddog@localhost:~/gifs > ls p<TAB><TAB>
There are 255 possibilities. Do you really
ish to see them all? (y or n)
```

This, by way, is an interesting way to get a complete listing of every executable command available in your PATH because command completion works not only for the filename arguments but also for the commands themselves. For:

![](bbox=[0.125, 0.363, 0.215, 0.433])

```
username@localhost:~ > 1p<TAB><TAB>
1pq 1pr 1stest
1pqall.faces 1prm 1punlock
```

Here is another example:

```
username@localhost:~ > <TAB><TAB>
There are 1455 possibilities. Do you really
ish to see them all? (y or n)
```

Stand back, because the shell now lists all 1,455 commands in your PATH!

Another useful command completion is thetilde (-), known to your business manager as the squiggles thing. When you use this symbol in a command line, it represents your login directory.

![](bbox=[0.125, 0.713, 0.215, 0.783])

Suppose you are in the /etc directory and you want to put a copy of the passwd file (which normally resides in the /etc directory) into your own login directory. Or you can type the pathname to your directory, or you can just type the following:

```
username@localhost:/etc > cp passwd ~
```

If you were root and wanted to put the passwd file into someone's directory, you could type the following, for example:

```
root@localhost:/etc > cp passwd ~maddog
```

A copy of passwd would go into the login directory of maddog, assuming that maddog is a valid login name with a valid home directory.
