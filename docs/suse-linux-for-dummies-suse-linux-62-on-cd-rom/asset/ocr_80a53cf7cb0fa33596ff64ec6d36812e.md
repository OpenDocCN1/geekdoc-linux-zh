# Hardware Supported by Linux

Generally, Linux has been ported to run on many platforms, such as any Intel processor that is a 386 or newer, as well as on various Digital Alpha, Sun SPARC, Motorola, MIPS, PowerPC, and HP/PA platforms. SuSE Linux has been ported to the Intel and Alpha platforms and is considering additional platforms in the future. The SuSE Linux For Dummies CD-ROM works only on Intel PCs, and what is discussed in this book. If you want to install SuSE Linux onto an Alpha, don't despair: The platforms aren't that different and you can probably adapt the instructions. You'll need to buy a different CD-ROM than the one in the back of the book, however, because it supports only the Intel line of processors.

Linux supports symmetric multipcessing (SMP), which means that you can have more than one CPU per box. In fact, it supports several processors per system box. If your system has more than one CPU, Linux will be able to utilize those CPUs also, either by speeding up a specific program written to take advantage of multiple CPUs or by allowing more programs to execute at one time. If you have an SMP system, would you like to trade with me?

The Intel processor should have the following amount of RAM (main memory):

+   - Without graphics, Linux runs (er, walks) with 8MB.
- With graphics, we strongly advise you to have at least 32MB of RAM.
- With 64MB, Linux works quite well and the speed of the application (particularly a graphics-oriented program) increases dramatically.
- 128MB can be found in the systems of some Linux developers because they tend to run many programs at a time, and each program takes up a certain amount of RAM when running.
