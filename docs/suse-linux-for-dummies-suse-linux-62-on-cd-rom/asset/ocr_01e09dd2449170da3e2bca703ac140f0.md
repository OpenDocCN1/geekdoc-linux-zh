Deleting a partition
If you find that you need to delete a partition, you can easily do this using the F4 key. First, you must highlight the partition that you want to delete; then press F4. You are asked to confirm that you want to delete the partition. If you are sure, press Enter; if not, use the Tab key to move to No, and then press Enter.

Saving the partition information
When you are finished creating partitions and you have set the type of the swap partition to Linux Swap, you are ready to save your changes. Press Enter and you will be asked to confirm whether you are sure about saving the partition information to disk.

![](bbox=[0.145, 0.643, 0.215, 0.715])

Remember to write down which partitions (such as /dev/hda2 or /dev/sdb3) will be used for file systems, such as /usr, /tmp, or just /.

# Making the Perfect File System

After you have created partitions for Linux, YaST confirms that it has found a swap partition (if you have any) and then initializes the swap partition. You are presented with the Creating Filesystems dialog box, shown in Figure 5-14. In dialog box, you set the mount points for your partition(s) as well as select formatting options.

Note that, in addition to selecting mount points and formatting type, this dialog box has options for Read fstab and Set Inode Density. These are advanced options and are not necessary for your installation.
