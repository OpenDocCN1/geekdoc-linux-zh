# Installation Instructions

The instructions for installing the CD are in Part II of this manual. If you have a computer that is capable of booting from the CD-ROM, then all you will have to enable this feature in your system BIOS (this is discussed in Chapter 4), and then insert the CD and restart your computer. If your computer does not have this feature, you will need to create a boot disk, which is also discussed in Chapter 4.

After you install the software, make sure to return the CD to its plastic jacket for safekeeping.
