# 第一部分：Linux Linux

在第一部分中，你将了解到 Linux 的诞生以及市面上不同类型的 Linux，包括《傻瓜自学 SuSE Linux》（SuSE Linux For Dummies）光盘中的版本。你还将获得一些关于如何选择最适合你的版本的安装建议。

# 第二部分：安装 SuSE Linux

在第二部分中，你将获得那个老问题的答案：我到底的该如何安装 SuSE Linux？我们为你提供了详细的循序渐进的说明。你还将获得关于安装 X Window（X Window System，Linux 的图形界面）的大量帮助。在此过程中，你可能想在身边准备一杯双倍浓缩咖啡或罐咖啡因汽水（双倍糖分！双倍咖啡因！）。

# 第三部分：使用 SuSE Linux

在第三部分中，你将获得关于如何使用 Linux 进行操作的精彩细节。我们将带你回顾文本编辑器的历史以及如何使用它们。你会发现并不是所有的 shell（壳）都存在于海底；Linux 有一个专为你准备的 shell。你还可以通过移动、调整大小、隐藏和关闭窗口来充分测试 X Window。

# 第四部分：维护你的系统

Linux 并不是一个高维护的操作系统，但它确实需要一些照顾（巧克力也有帮助）。在第四部分中，你将了解到如何管理 Linux 文件系统，这是维护和喂养 Linux 最大的部分。你还将获得关于提升 Linux 性能的提示。轰，轰。

# 第五部分：连接网络

如今每个人都在在线，Linux 也不例外。在第五部分中，你将了解到如何联系互联网服务提供商（ISP）获取访问互联网的账户，如何设置你的 Linux 系统与该账户交互，以及如何使用该账户配合 Netscape 浏览器上网。
