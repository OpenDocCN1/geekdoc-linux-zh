# Chapter 5: Installation: Down to the Final Stretch

The dialog boxes will vary slightly depending on a few things. If you have two hard drives in your computer, you first have to choose which hard drive you have to install Linux on. If the hard drive you are installing on already has a partition that spans the entire drive, YaST will not, for obvious reasons, ask whether you want to use the unpartitioned space to install Linux. In this case, you need to select Partitioning from, Use Entire Disk, and you are presented with the Editing the Partition Table dialog box, which is for editing your partition table (see Figure 5-8).

# Editing the Partition table

In Editing Partition Table dialog box, you can view the existing partitions, delete the existing partitions, create new partitions, and change the type of the partition. These functions are performed by the function keys (F3, F4, F5, F6), as shown at the bottom of your screen. For example, the F5 key is for creating a new partition. In Figure 5-8, you can see that one of the authors has a 100MB DOS partition (remember, there are 1024 blocks per MB!).

# Creating a partition

In this example, we create the following partitions in addition to the existing DOS partition:

+   * 750MB for the root partition
* 127MB partition for the swap partition
* 100MB (all remaining space) for the home directory

To create a partition, press the F5 function key. The next dialog box, Partition Type, prompts you to select the partition type, and you should select Primary, as shown in Figure 5-9.
