# Creating a General Account without YaST

If you want to create a user account without using YaST, you can do so from the command line, using the useradd command:

```
root@localhost:~ # useradd <name>
```

where <name> is the login name for the nonprivileged login account and the -m instructs the command to create a home directory for that user account.

Next, you use the passwd command to change the password of the new account, which had a default password assigned to it by the useradd command. What is good is a password if you use the default one? In the following, remember to replace <name> with your login name:

```
root@localhost:~ # passwd <name>
New Unix password:
Retype new Unix password:
passwd: all authentication tokens updated successfully
root@localhost:~ #
```

In the preceding example, the password is typed correctly twice. You can't tell that, however, because the program doesn't let you — anyone — see the passwords as they are typed. Marker dots don't even appear on the screen.
