+   2. Place the CD-ROM into your computer.

+   3. Start YaST.

To do so, type the following:

```
yast
```

After a few seconds, the YaST main menu will appear.

+   4. Using the down-arrow key, highlight the Choose/Install Packages menu item and then press Enter.

You should recognize the submenu that appears (see Figure 6-1) as it one that appeared during the installation. This is the menu for managing software packages. You can install, delete, and find out information about packages on the CD-ROM as well as those already installed on your computer.

+   5. Select the Change/Create Configuration menu item.

The submenu contains a list of "Series." The series are just logical groupings of all the packages on the installation CD-ROM. The first one is the BASE SYSTEM, which contains all the packages that are necessary for a minimal installation of SuSE Linux.

+   6. Use the down-arrow key to scroll the list and highlight the Series titled XSRV Several X Servers; then press Enter.

You are presented with a list of packages that are contained in the XSRV series. You need to scroll the list and determine whether the X server that you need is installed or needs to be installed (see Figure 6-2). The packages that are already installed will have an "I" in brackets [ I ].
