# Kernel Building

One of the items that may be slowing down your system is a kernel that is not tailored to your hardware or your needs. This has two major disadvantages:

+   - You may have your kernel compiled for a processor you don't have.
- You have more instructions and data than you need in your kernel.

This section describes both cases and what you can do to change the situation.

# Tailoring a kernel for your processor

Many Linux distribution kernels were compiled to install onto the largest range of systems. Therefore, they are compiled to run on the slowest processor of a particular architecture (Intel, Alpha, and so on). In the Intel side of the house, this typically means that the installation kernel (the one you install from the CD-ROM or the one on the boot floppy) is made for an Intel 386, not a Pentium Pro.

To take advantage of the Pentium Pro's power (for the most part), you need to at least rebuild the kernel portion of Linux, specifying the processor you have. To do this:

+   1. Log in as root.
2. Type code /usr/src/linux at the system prompt.
3. Type make menuconfig.

If this directory does not exist, you probably didn't install the kernel sources from your distribution of Linux. If you followed the instructions in this book, utilizing the SuSE Linux For Dummies CD-ROM, these kernel sources should be in place.
