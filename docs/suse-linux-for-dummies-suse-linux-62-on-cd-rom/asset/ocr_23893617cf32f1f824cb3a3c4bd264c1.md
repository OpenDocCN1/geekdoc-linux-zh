Follow these steps to multiply 5 times by 3:

+   1. Click Start✞Programs✞Utilities✞Calculator. Or type xcalc in a terminal emulator window.
2. Click the AC calculator button.
   AC stands for All Clear.
3. Click 5, * (asterisk), 3, and then = (equal sign).
   The number 15 appears on the display.
4. Click AC to clear the display.

This is lot like using a calculator manually, except you use the mouse instead of your fingers to select buttons.

You can also use the calculator with the keyboard, as follows:

+   1. If necessary, start xcalc.
   See Step 1 in the preceding list.
2. If necessary, press the Backspace key to clear the display.
