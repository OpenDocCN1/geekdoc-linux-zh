Use the arrow keys to move the cursor to the processor you have in your system; then press the spacebar to select that processor.

You are automatically moved back to the preceding menu, and the processor you selected is shown under Processor.

Press the Tab key to move the cursor to Exit and then press Enter to select it.

The first menu appears.

Press the Tab key once to move the cursor to Exit and then press Enter to close the whole menu.
