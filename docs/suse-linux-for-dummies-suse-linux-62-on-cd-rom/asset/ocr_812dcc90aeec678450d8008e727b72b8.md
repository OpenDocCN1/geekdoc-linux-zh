# Finishing the kernel rebuild

After the kernel is rebuilt the way you want it, you'll probably have to remake any modules you want to use. These are the modules that you specified in the kernel as loadable. The easiest way to rebuild your kernel modules is to type make modules and make modules_install after the basic kernel is built.

Because of the modules that you may need have already been compiled and are available for your use, this step may not be necessary. However, if you elected to have a new module created (one that was not previously selected) when you were configuring your kernel in the previous section, recreating the modules is a good idea.

After you have recreated your modules, you need to take one final important step. You need to recreate the modules dependency file. This is the file that specifies which modules have dependencies, as well as which modules they are dependent on. Fortunately, it is easy to be done with this command:

```
depmod -a
```
