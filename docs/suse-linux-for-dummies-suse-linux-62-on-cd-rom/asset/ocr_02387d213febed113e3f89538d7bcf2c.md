# Mail Interfaces

E-mail consists of two main parts: a front end (or interface) that you use to compose or read messages and a back end that delivers your messages. In addition to the mail-specific programs described in this section, note that some Web browsers can read mail, read Internet News (a series of information accessible over the Internet), handle FTP downloads of files, and perform other Internet-related tasks.

# Character-cell interfaces

The first mail interfaces were available only in character-cell mode. In this section, we discuss several character-cell interfaces; some are freeware and others are commercial packages.

mail(1), one of the first mail interfaces, is a character-cell interface for early versions of UNIX. mail remains a powerful interface, and sometimes we use it when our system is in character-cell mode and we want to send a quick mail message or scan re mail messages.

elm(1) is an interactive screen-oriented mailer that we can use in place of mail as a front end. It's easy to use and presents a vim(1)-like editor for creating mail messages.
