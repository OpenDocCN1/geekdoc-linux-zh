# Graphical mail interfaces

Graphical mail programs offer a powerful and easy-to-use interface to read and manipulate mail. Graphical mail interfaces, like text editors, require Window System.

xmh(1) is a graphical interface written for the character-cell-oriented mh commands, mentioned in the preceding section. As such, it lets you alternate between using mh in the character-cell environment and xmh in the graphical environment. xmh is a simple interface written mostly to demonstrate early versions of X Window System.

We prefer xmh(1) graphical mailing program. It is freely distributable, so we use the same interface on systems at work, systems at home, and notebooks when traveling. It is powerful — with MIME and POP (an earlier version of IMAP) capabilities, folder support, and easy ways to tailor printing, your editor, and a series of other parameters. The xmh mailing program also highlights URLs (addresses of World pages) in the text of your mail; when you click the URL, xmh calls up your browser and displays the URL. xmh has a comprehensive search facility for looking for messages sorted in folders.
