# # Chapter 5: Installation: Down to the Final Stretch

The kernel selection screen that appears, Select Kernel, shows you a list of available kernels to choose from (see Figure 5-23). SuSE Linux for Dummies includes a number of kernels that are precompiled to support various SCSI controllers. If you are installing SuSE Linux onto an IDE hard drive, you should select the default kernel. If you are installing SuSE Linux onto a SCSI hard drive, you must select the kernel that supports your SCSI controller. Use the up-and-arrow keys to select the appropriate kernel and then press Enter. YAST installs the selected kernel into the /boot directory.

# # Create a boot disk

The next screen (see Figure 5-24) asks whether you want to make a boot disk. We strongly recommend that you make a boot disk now because it will be very useful if, in the future, you have problems with the Linux boot loader. Place a floppy disk in the disk drive and press Enter. We remind you not to accidentally destroy the installation in the process!
