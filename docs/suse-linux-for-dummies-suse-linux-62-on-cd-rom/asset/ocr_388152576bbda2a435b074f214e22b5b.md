# Your Wish Is My Command

We've been showing you interactive shell functions, a fancy term that simply means that you type something and the computer executes it immediately. After a while, you may notice that you're typing a certain series of commands over and over. Wouldn't it be nice to put them in a file and execute them all at once? Well, you can.

For the rest of this section, you work on creating shell scripts, which contain a series of commands that are executed every time you type the name of the script as command. First you create a simple shell script, and later you create a more complex one.

Suppose that you want to generate a report from time to time showing who owns the login accounts. You can simply print the /etc/passwd file, but that has a lot more information in it than you need. Plus, you're an organized type of person and want to format the report more nicely than the passwd file

First, look at the following entry in the passwd file:

```
maddog:eyrtwuir:500:SuSE Linux
User...,/home/maddog:/bin/bash
```

Each grouping of characters between the columns is called a field. For the report, you want only the first and fifth fields. The cut command is what you want to go. The man page for the cut command shows that the command to the first and fifth fields is follows:

```
cut -f 1,5 -d: /etc/passwd
```

The man pages are terse but complete descriptions of commands. To get to the man page for the cut command, type man cut on the command line.

You use the -f option for the cut command to list the fields you want printed, in this case the first and fifth fields. You use the -d option to specify the delimiter for the field, which in this case is a colon. The preceding gives lines of output formatted like this:

```
maddog:SuSE Linux User,...
```

Maybe you'd prefer to replace the colon with a hyphen, adding a space on each side to make the report easier to read. The stream editor sed is your ticket to formatting happiness. You can send the output of cut directly to sed with the following command line:

```
cut -f 1,5 -d: /etc/passwd sed -e 's/:/ /' '
```
