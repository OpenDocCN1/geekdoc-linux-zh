The sole function of this chapter and the three that follow is to help you install your system. If your SuSE Linux system is already installed, count yourself lucky and check out one of the chapters after Part II. If you haven't installed your system, console yourself with the fact that you can find out a lot during this chapter and will be the better for it later. Your computer will not seem like such a stranger because you will find out what lies inside.

We would like to dispel a myth that Linux is harder to install than Microsoft Windows. We believe that Linux is no harder to install than any other operating system. We've tried on several occasions to install Windows 95 from the beginning, and have met with frustration due to plug-and-pray or drivers that were always on the "other" disk (no matter which we had). Windows seems easy to install because it's usually preinstalled; because most people only update it; and because people who do install it will have all the hardware-documentation.

You can buy Linux preinstalled if you want. Most companies that sell hardware and specialize in Linux sales will install it for you. Then all you do is turn it on. If this is the way you obtain the Linux operating system, it's as easy to "install" as Windows

The next easiest way to install Linux is to buy it preinstalled on a disk. You put the disk in your system, boot the system, and Linux is installed.

If you're the rare reader who is buying a system just for Linux, look up a hardware supplier on the World Wide Web or in a Linux magazine and ask the to build a system for you.
