A list of all packages in alphabetical order appears.

Following are more options to complete the installation of packages.

You use the Check Dependencies of Packages option to — check the dependencies of the various packages that you have selected to install on your system. If you have selected additional packages to be installed, we recommend that, as a precautionary measure, you verify that all dependencies are satisfied.

The three types of package dependency are as follows:

- Package requires Package B. This type of package dependency can easily be resolved by YaST. If this package dependency is unresolved, YaST shows you the package that is selected to be installed and then the package that is required as well. The two packages are separated by the word [AND]. You can quickly add the necessary package(s) by selecting AUTO.

- Package should not be installed with Package B. This type of package dependency issue requires your intervention. YaST shows you the two packages that have been selected to be installed. These two packages are separated by the word [EXCL], which stands for exclude. In this case, you need to select ABORT and go back to the package selection screen and deselect one of the two packages manually. An example of this package dependency issue is shown in 5-21.

### Configuring LILO, the Boot Loader
The next screen asks whether you want to configure LILO. Because you will be using LILO to boot your system, press Enter. Figure 5-25 shows the next screen, which has a few fields that need to be filled out. Each of the LILO configuration box fields is described in the following list.

![](img/96a9ce6a13d8d15ed05f867f41574278_117_0.png)

Figure 5-25
The LILO configuration screen.

- Append line for hardware parameter. This field is usually left blank. You use it only in rare cases when the Linux kernel cannot recognize aspects of your hardware. In these cases, you have the option to specify certain features of the hardware. Append line parameters are given in Appendix A.

- Where do you want to install LILO? For LILO to select the names of the different operating systems to boot and to allow you to select an operating system, LILO has to store itself and its boot information place.

- The Master Boot Record (MBR) is the recommended place for installing LILO unless another operating system loader like System Commander or OS/2 Boot Manager is loaded here (which you should know if you installed them). If LILO is installed on the MBR when your machine boots, LILO starts when the BIOS finishes and displays the boot prompt.

- The first sector on your root partition (the partition of the disk that holds the beginning of the Linux file system and the kernel of the operating system) is the recommended place if you are using another bootstrap loader (such as System Commander or OS/2 Boot Manager) on your system. You set up that to boot LILO, then you have LILO boot Linux. To find out how to make your other bootstrap loader know about LILO, refer to the documentation for other bootstrap loader.
