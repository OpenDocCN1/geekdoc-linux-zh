# Your Linux Calculator

Linux provides you with a handy scientific calculator that can emulate TI-30 or an HP-10C. When you're predicting the location of the next meteorite to hit Earth or trying to balance your checkbook, look no further than Linux.

To use the calculator in TI-30 mode, follow these steps:

+   1. Click K-SuSE:Work Menu-Calculator.

The calculator appears, as shown in Figure 12-4. Note that the calculator also goes by the nickname xcalc(1).

+   2. Activate the buttons and calculate away.

You activate the buttons by using the keyboard or the mouse. The keyboard equivalents of special functions are not intuitive, so we provide Table 12-1 for reference. We extracted this information from the manual page for the xcalc program, which you can see in its entirety by typing the following at the command prompt of an xterminal window:

```
man xcalc
```
