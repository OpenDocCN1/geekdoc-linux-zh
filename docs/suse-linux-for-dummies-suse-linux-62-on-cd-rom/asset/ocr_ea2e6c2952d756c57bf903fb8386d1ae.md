# Appendix B: The linux man Pages

# Other places to look for help

You can find help in several other places on the system. One place is the /usr/doc/ packages directory.

In addition to man pages, the info pages were created as a replacement to man pages but they are not very popular and have not fully replaced man pages. Some habits die hard, I guess. To access an info page for a particular command, type the info followed by the command that you want information on; for example, see the info page for the tar command, type tar

Note: Some system administrators conserve space by not loading /usr/doc on their systems. With the abundance of inexpensive disks, this is false economy. Documentation such as that found in /usr/doc can be put on one system and made available to everyone through the magic of the Network File System (NFS). Tell your system administrator to do that. If you are your own system administrator, go into a closet and give yourself a lecture!

To exit the page, press the Ctrl and C keys simultaneously.

After you've read several man pages, you'll notice that the same options appear for similar commands.

All this is pretty much passive work. To find out what a command really does, you should try it out. Create a small test file using an editor, or use an existing file, such as the /etc/passwd file, as input.

Do not do this as root. You may inadvertently erase part of the operating system. It is best to do this experimentation as a unprivileged, normal user.

From time to time, we will read all the man pages in the system, concentrating on the command descriptions. We do this because we want to become familiar with new commands. Also, our memory is not what it used to be. But to be fair to our failing memory, the system does have close to 1,200 general-user commands and about 260 system administration commands.
