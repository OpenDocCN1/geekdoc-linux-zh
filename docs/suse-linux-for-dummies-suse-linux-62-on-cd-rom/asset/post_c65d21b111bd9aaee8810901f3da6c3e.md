## Shutting Down the System

If you are accustomed to MS-DOS or Windows 3.1, it may seem strange to have a section on shutting down the system. After all, shouldn't you turn off the power switch? The answer is no! Linux requires a systematic process to shut down the operating system, after which you can turn off the power switch.

If you have just finished installing the system, you are logged in as systems administrator called root. Follow these steps to shut down the system:

- 1. If X Window System is running, press Ctrl+Alt+Backspace to stop X Window System.

The system returns to character-cell mode, and the # prompt appears. The # prompt tells you that you have the powers of the systems administrator (don't let it go to your head) and that you can shut down the operating system.

- 2. Type shutdown -h now at the prompt.

This tells Linux to halt the operating system now rather than later.

![](img/96a9ce6a13d8d15ed05f867f41574278_141_0.png)

shutdown is a command to Linux. Some commands have options, or flags, that provide additional information about what the command should do. -h means to halt the system, rather than reboot, after it shuts down. -r means to start rebooting after shutdown. now means to start the process of shutting down immediately. Without the now, the shutdown command would hesitate and send warning messages to people still working on the system, telling them that the system is about to be turned off.

## Chapter 6: Solving Problems with the X Window System Installation

One other method of rebooting the system is the infamous three-finger salute that all Microsoft users know: Ctrl+Alt+Delete. The three-finger salute simply sends a shutdown -r now command to Linux, and the result is the same as if you had typed this command.

As a Linux user, rebooting the system should be an infrequent occurrence. Because the login procedure provides a Linux system with the necessary security, you don't need to shut it down between sessions. Linux is stable, so it does not freeze out, as do other PC-based operating systems. If you have multiple operating systems on the same machine, however, rebooting will take you back to the LILO prompt (or the System Commander, or some other booting program) to allow you to boot another operating system.

## What Went Wrong?

If you are still not able to get it working, here are a few things that you may want to consider:

- Find out more detailed information about your video card using DOS or Windows 95 (if available), as described in Chapter 3.
- Find a newer version of XFree86 code at www.xfree86.org.
- Join the SuSE mailing list and post your question. To join the mailing list, go to www.suse.com, find the link for mailing lists, and follow the instructions.
- Find a seasoned Linux person to help you.
- Buy a system (a computer with Linux preinstalled).
- Join a local Linux users group.
- Take a cruise to Fiji, where at the University of the South Pacific they have a really good computer science department in which everyone Linux. (Hi, folks!)

If you try these solutions and still do not have X Window System running, look around for a Linux users' group at a local college or high school. Perhaps a group of computer professionals in your area may help. If you call local computer science department, they probably can help you find a student or staff member who uses Linux, and has installed it on several types of machines, and can help you figure out why your graphics system is not working or get a newer version of XFree86 that might support your video card.

If you feel strange to ask these people to help you, remember that they were once new to Linux, too, and probably had to struggle through an even more difficult installation. When you do go, remember to take all the accumulated information about your system that you have detected. It will save both them and you time and energy.

Finally, if your hardware is too new or proprietary, or if you have a notebook computer, you may want to buy a commercial X Server from Metrolink (www.metrolink.com) or Xi Graphics (www.xigraphics.com). Sometimes their code works when XFree86 does not. Plus, if you buy an X Server, you can call the company's technical support line if you can't get it installed.

## Giving Linux the Boot

Are you ready to boot SuSE Linux? Here goes:

- 1. Make sure everything is turned off.
- 2. Turn on all peripheral devices, such as printer and scanner.
- 3. Turn on the monitor (if it's separate from the main system).
- 4. Turn on the main power switch.

After a short time, LILO boot: appears on your screen.

- 5. Press the Tab key to see all operating systems that are available to boot.

You might see something like the following, depending on what options you chose during installation:

```
LILO boot:
dos linux
boot:
```

- 6. Type the name of one of the listed operating systems and then press Enter.

That operating system will boot.

If you do not — that is, you ignore my instructions — the first listed operating system, which is known as the default system, will boot after a short time.

For Linux to boot, then:

- Linux must be the only operating system installed; or
- Linux must be the first listed operating system so that it boots the default system; or
- You must be fast enough to type linux after the prompt.

Otherwise, you may have to wait for the other operating system to finish booting, shut it down, reboot, and make sure that you're fast enough to type linux after the prompt.

As the Linux operating system boots, you see all sorts of messages scrolling by the screen. When the scrolling stops, the last line should be

```
login:
```

Now you're ready to log in to the system and set up an account to use in your normal day-to-day work.

## Power Incarnate

When you want to use Linux, you must log in as a particular user with a distinct login name. Why? Linux is a multiuser system, and as it uses different accounts to keep people from looking at other people's secret files, erasing necessary files from the system, and otherwise doing bad things.
