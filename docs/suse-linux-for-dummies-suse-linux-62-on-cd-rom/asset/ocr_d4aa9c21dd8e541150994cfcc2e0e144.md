root@localhost:~ # 1pq

A list of print jobs in the queue appears. If no print jobs are in the queue, you see the message no entries.

# Troubleshooting printing problems

Sometimes, printing does not work the first time around. Here are some common problems and their resolutions.

# Loading the lp module

Support for the parallel port is handled by the kernel module lp. The kernel is configured to automatically load this module when jobs are sent to the printer. If you are experiencing problems printing, verifying that the module is loaded is a good idea. If it is not, you can manually load it.

To see whether the module is loaded, issue this command:

```
root@localhost:~ # 1smod
```

You will see the list of currently loaded modules. If the module lp is not on the list, you should load it manually with this command:

```
root@localhost:~ # modprobe lp
```

# Queueing/Printing disabled

On some occasions, the queueing is disabled, causing printing problems. You can enable both printing and queuing on all queues with this command:

```
root@localhost:~ # 1pc up all
```

You can see whether all queueing is enabled when you issue this command:

```
root@localhost:~ # 1pc status
```
