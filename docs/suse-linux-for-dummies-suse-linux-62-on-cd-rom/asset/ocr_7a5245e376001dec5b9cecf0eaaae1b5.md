# 194 Part III: Using Linux

You can use these wonderful cascading menus to launch a terminal emulator.

+   1. Click the K button.

It's at the bottom-left corner of the screen. When the menu pops up, click the menu item called Utilities.

+   2. In the Utilities submenu, click the Terminal menu item.

The xterm terminal emulator appears with (in all likelihood) a new copy of bash. But this is not why you have X Window System working. We bet you want to see some other graphical programs running.

+   3. Make the terminal emulator go away.

To do so, click inside the window, type exit, and press the Enter Key. Or you can click the upper-left corner of the window to display a menu, and then Close. (This last method works for any X window using the KDE window manager.) You can also close the window by pressing the Ctrl+d.

Now we want to look at a series of graphical programs available for your use and enjoyment. The following steps should get you accustomed to using the cascading menus, and show you (certainly not all) graphical programs on your SuSE Linux for Dummies CD-ROM.

The first program to look at is xpaint, a graphical painting program:

+   1. Click K:Graphics:paint.

The screen in 11-3 appears. If you have seen paint before, one will not surprise you. From the Tools menu option, you can select drawing tools; and with the Tool Properties, you can modify the properties of the tools. You can select from a color palette by clicking one of the color boxes on the right side of the screen. You are welcome to play around with the program, but for now just notice that it is definitely a graphical program and not limited to the alphabet and numbers as a character-cell program might be.

+   2. Without closing the first window, click K:SuSE:Documentation:xman.

The xman window appears, as shown in the upper-left corner of 11-44.

+   3. In the xman window, click Manual Page.

When the Manual Page window appears, read about the command in the initial window.

+   4. Move the cursor over the Sections button at the top of the window, and then click but don't release the mouse button.

A menu of manual sections appears. Most of the commands you are interested in are in section 1.
