# Free or Not?

Linux applications differ widely in cost and appearance. In this section, you check out the different ways in which you can obtain applications, namely:

- As freely available software
- As shareware
- As commercial applications

Freely available software is available for free use by the end user. Although software may be freely available, this is often not the same as public domain software (or software that you can absolutely do anything with). Freely available software is often owned and copyrighted by author or authors, who allow people to use it or make modifications to it.

Freely available software can be further divided into software that you can either freely copy or freely distribute. Some people make their software freely available, but only if you copy it directly from a particular site or from a noncommercial distribution. Other people let you copy their software from any place. Copying restrictions usually apply to people making a commercial distribution, not to the end user of that distribution. The distribution maker has the responsibility to be in compliance with the package's copying restrictions, which are usually outlined in the source code of a program or in the program's About or Help section.

# Text Editors

Linux systems often come with several text editors. Text editors are programs that typically enable you to type and manipulate alphanumeric characters. Some text editors can do simple word processing tasks such as word wrap, but they can't perform most word processing functions, such as spell checking. Most have built-in help functions, and some have full-scale documentation available. In addition, you can find books about a few editors, such as vi(1) and emacs(1).

In this section, we describe character-cell text editors and graphical-based text editors. We also describe some commercial editors.

# Character-cell text editors

ed(1) is the oldest text editor and comes with every UNIX system. ed is difficult to use because it doesn't normally show you the entire file, and it doesn't show you the changes you've made until you ask it to. Those who use are usually old-time UNIX users with gray beards who wear suspenders with their shorts. Even with these downsides, it's useful to know how to use ed because it usually comes with every Linux system. ed is on the CD-ROM that this book.

Following quickly after the introduction of ed was an extended editor called ex(1) and a visual front end to it called vi(1). vi was written in the mid1970s and allowed people to see a whole screen of text at one time! Believe it or not, this was big news in those days. Many Linux systems ship with a new version of vi vim(1), for "vi improved".

You can execute vim by typing vim, but SuSE Linux has a link to it and ex. A link is to give two names to the same program. Although the same program is being executed, the system stands and looks at what the user types when starting the program. For example, if the user types vi, the program starts vim.
