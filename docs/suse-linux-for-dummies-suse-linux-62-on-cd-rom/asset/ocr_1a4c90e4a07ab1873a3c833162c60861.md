# I Never Seem to Have the Correct Time

**Solution:** Most UNIX systems keep their time using Universal Time (also known as Greenwich Mean Time, or GMT), but Microsoft systems keep their time as local time. When you set the time in either system, you set the CPU clock to that version of the time. Then when you boot the system, it interprets what is in the CPU clock differently and reports a different time.

Linux enables you to store and think of the clock as either GMT or local time. You make this choice when you install the system. To change your choice, follow these steps:

+   1. **Log in as *root*.**
2. **Type yast.**
Select System Administration from the YaST main menu and press Enter, then select Set Time Zone from the submenu and press Enter.
3. **Select the appropriate time zone.**
You can see the entire list by scrolling down. When you find your time zone, press Enter.
4. **In the next dialog box, set your computer to GMT or local time as necessary.**
