# 168 Part III: Using Linux

The place you will probably use * most is in the command ls -1 *.*

The question mark matches any single character. The string of characters a?c, for example, match the following:

```
abc
adc
aac
aafc
a9c
```

The question mark and the asterisk can be helpful for identifying files of a particular type, if you are careful in naming your files. For example, text editor files usually have the .txt extension, and Microsoft Word files have the .doc extension. Linux itself doesn't care what the name of a file is, but some programs work only with a particular type of file.

![](bbox=[0.137, 0.351, 0.196, 0.423])

Now suppose that you followed the convention of naming all your files with the .txt extension and you want to see all the text files in a directory. You could use the ls -1 command like this:

```
ls -1 *.txt
```

The screen displays all the files in this directory with the .txt extension. Notice that we didn't say that the command will show all text files or that it will show only text files. If you want to name a graphics file with a .txt extension, Linux will happily oblige you. For your own sanity, however, be diligent in naming files. Some programs (such as those that create audio files or picture files) strictly enforce a naming convention on files they create, Linux itself doesn't care.

What would you do if the * was part of the filename you were trying to match? How could you tell the shell that you wanted only the file that contained *, not all the files? The backslash character escapes the meaning of the special character. For example, hi*est matches a file named highest, but hi\*est matches only the hi*est filename.

Although more regular expression characters are available, these are enough for you to work with for a while.
