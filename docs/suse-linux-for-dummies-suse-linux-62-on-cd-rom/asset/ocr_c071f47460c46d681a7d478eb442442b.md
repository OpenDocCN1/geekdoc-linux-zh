Time for a tour of another virtual desktop:

+   1. Click the desktop labeled two.

Your windows are gone! Only kidding. They seem to disappear, but they're been taken to a new virtual desktop, which enables you to open even more windows. Notice that the button labeled two is lighter colored than the others. That is because this desktop is still around. your active desktop.

+   2. Open a few windows.

To do so, click the K menu and start a few programs.

+   3. Click the button labeled one.

You return to your original desktop, with all the windows still open and waiting for you to continue work.

+   4. Click the button labeled two and close any open windows.

+   5. Click the desktop labeled one again and you will return to the first desktop.

# Bye, Window

Now that you've put a lot of windows on the screen, how can you get rid of a few or all of them? Well, you can put them in the background by reducing them to icons, or you can be more drastic and kill them. Here are a few ways to do:

+   - First, take advantage of any exit buttons or menu options that the application gives you. Close each and every application using X Window System.
- Click the hyphen symbol in the upper-left corner of the window you want to make go away, and then click Close. That window disappears, and the program that was outputting or receiving input through that window terminates.
