Can't make up your mind or having trouble? No problem. If you want to
change mouse configuration after you have booted the Linux system,
you can return to YaST and do it later.

After you have selected the mouse settings, you are asked whether
i are interested in using GPM. GPM is a program that allows you to cut and
paste text between virtual consoles. It is a great feature and we strongly
ommend that you configure it. When you press Enter, you can test your
mouse settings in the dialog box that appears. If you wiggle your mouse
around and your settings are correct, you will see a red cursor moving
the screen. If not, you have selected the wrong mouse protocol or
the wrong COM port. If the mouse settings are correct, select the Keep
Settings option by pressing Enter.
