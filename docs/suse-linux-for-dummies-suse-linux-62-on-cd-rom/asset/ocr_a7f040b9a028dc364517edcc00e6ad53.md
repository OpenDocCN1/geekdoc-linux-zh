In this dialog box, you can see the current hard drive partitions and their mount points. If you had additional partitions and you wanted them mounted in the file system, you could use this dialog box to assign them a mount point. Existing partitions that did not have a mount point would appear on this list. Using the up- and down-arrow keys to highlight a partition) mount point, just press the F4 function and select from the list of available mount points, or if you have created your own mount point, select Other Entry from the list and enter the mount point you have created.

If this is a new partition, you might also need to format it. You can choose to have the partition formatted by pressing the F6 function key and selecting the type of formatting from the drop-down menu list.
