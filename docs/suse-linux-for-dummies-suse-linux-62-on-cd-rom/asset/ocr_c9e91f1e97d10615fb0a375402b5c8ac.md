+   - System data files are used by the system to keep track of users on the system, logins, passwords, and so on. As system administrator, you may be required to view or edit these files. As a regular user, you will not be concerned with system data files except perhaps for those that you use as examples for your own startup files.

+   - Directory files hold the names of files — and other directories belong to them. These files and directories are called children. Directories in Linux (UNIX) are just another type of file. If you are in a directory, the directory above you is called the parent. Isn't that handy?

When you use the files with the ls -l command, lines containing directory begin with the d. For example:

```
maddog@shamet:~ > ls -ld plot
drxr-xr-x 2 maddog maddog 1024 Jul 111997 plot
maddog@shamet: ~
```

In this example, we use the d option of the ls to tell the command that we wanted to see the directory as if it were the only file in the directory. If we had not used the d option, we would have seen every file in the plot directory, along with the directory itself.

+   - Special files represent either hardware devices (such as a disk drive, a tape drive, or a keyboard) or some type of placeholder that the operating system uses. /dev is a directory that holds many of these special files. You can see this by typing the following:

```
ls -l /dev.
```

+   - Executable files contain instructions (usually programs, or scripts) for your computer. When you type the name of one of these files, you are telling the operating system to execute the instructions. Executable files look like gibberish, and others like long lists of computer commands. A lot of these executable files are in /bin, /usr/bin, /sbin, and /usr/sbin.

# Files and directories

You can think of the Linux file system as one huge file folder that contains files and other file folders, which in turn contain files and other file folders, which in turn contain files and other file folders. In fact, the Linux file system is generally organized this way. One big directory contains files and all the directories in turn contain files and directories.
