# ## Games People Play. ..

Although Linux is not known as a platform for incredible gaming, things are changing. One company that we know of as of this writing is working to port games over Linux. The most recent X servers support some pretty powerful video cards, too. Although the SuSE Linux For Dummies CD-ROM does not contain any 3D games, we want to take a minute of your time to familiarize yourself with the 2D games that do come on the CD-ROM.

### 1. Click:Asteroids.
A classic! This version of asteroids has lost its classic stick-figure look, it is still fun as ever (see Figure 12-1). To start a new game, click the File:New game menu options. As the instructions on the screen suggest, you press Enter to start the game. You use the left- and right-arrow keys on your keyboard to rotate the spaceship left and right. The up-arrow key moves the ship forward and the space makes it shoot. Make sure to get the asteroids before you collide with one! To end the game, click File:Quit.
