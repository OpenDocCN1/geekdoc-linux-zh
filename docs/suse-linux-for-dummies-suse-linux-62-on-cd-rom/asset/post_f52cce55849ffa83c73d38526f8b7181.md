# Chapter 1: Linux and You

## In This Chapter

- Figuring out how you can use Linux

In 1991, Linus Torvalds, an undergraduate student at the University of Helsinki, got a brand-new IBM 386 PC. Dissatisfied with the operating system that came with the hardware, he wanted to run operating system instead. UNIX, however, was too expensive, so Linux and a team of talented programmers tackled the task of creating a new version of UNIX. They created a core operating system, or kernel, named Linux.

## Free as in Freedom

One of the most important decisions Linus Torvalds made in the early days of the Linux kernel was to make all the code freely distributable. Several organizations globally recognized as technological countries — the Free Software Foundation and other places — added them to the Linux kernel and then created a way to install the software on the computer. This process is called creating a distribution, and this is what the folks at SuSE Linux do.

Linux is available in several forms: One is a fully functional version that comes on the CD-ROM included with this book. Another is the full distribution, which comes with six CD-ROMs, an installation manual, and installation support. Finally, there is the FTP version, which can be downloaded from ftp.com for free. In each case, the Linux kernel is also available without charge.

The importance of the availability of operating system source code could not be overstated. Freely distributable source code has resulted in a Linux operating system that continues to improve rapidly. Each developer can build on the efforts of those before, and this benefits everyone — including you.

# Let’s be open about Linux

After the publication of the first edition of Linux For Dummies, I received criticism that I had slight Linus Torvalds by omitting how he started. The last thing I want to do is slight Linux and the other programmers who have created this fantastic system, or anyone who has worked on this project, from the Free Software Foundation (contributors of GNU software) to individual contributors worldwide.

When people ask me why I think Linux and Open Source Code development projects are so important, I answer that I am not egotistical to think all good programs come from the United States. I tell them that the next Einstein of computer science might come from Korea, China, Venezuela, or even Helsinki, Finland, and the world cannot afford to miss the opportunity of finding him or her. I repeated while standing with the president of the University of São Paulo, Brazil, in front of his school’s computer built by Beowulf technology running Linux. He answered my observation with the words, “We, too, considered that.”

I would also like to point out that this is the first operating system in major use today that started outside the United States of America. All other operating systems, although they received support and construction from non-U.S. participants, were conceived and maintained in the United States. People from all over the world — and increasingly mentioned Linux developed in 1991. By the early spring of 1994, the first real version of Linux (V1.0) was available for public use. Even then, it was an amazing operating system, running with less than 2MB of RAM on Intel systems at amazing speeds. This free system included features found in operating systems costing hundreds of dollars per user:

- Multitasking (running more than one job simultaneously)
- Multiple simultaneous users
- Demand-paging virtual memory system (using the hard drive for additional temporary storage) to run programs more than the amount of RAM

An estimated 125,000 people were active users in 1994. (Because no licenses are issued for individual users, a more precise number can’t be determined.) In 1997, just three years later, the estimated number of Linux users was 3 million and climbing rapidly. By the fall of 1998, the estimates were more than 7 million.
