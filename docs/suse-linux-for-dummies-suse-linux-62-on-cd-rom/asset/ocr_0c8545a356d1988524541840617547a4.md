# 104 Part II: Installing SuSE Linux

To run SuperProbe, follow these steps:

+   1. Log in as root.

+   2. Execute the SuperProbe program.
To do so, type the following:
SuperProbe

A lot of information spews from the program, followed by a rather frightening message:
WARNING - THIS SOFTWARE COULD HANG YOUR MACHINE.
READ THE SuperProbe.1 MANUAL PAGE BEFORE
RUNNING THIS PROGRAM.
INTERRUPT WITHIN FIVE SECONDS TO ABORT!

![](bbox=[0.135, 0.381, 0.215, 0.455])

Although SuperProbe can hang your machine, most of the time it doesn't. And if it does, simply press the reset button on your machine or turn the power off and then to reboot.

If SuperProbe does its job and does not hang your machine, it may come back with information like the following:

```
First video: Super-VGA
Chipset: S3 86C28PCI (PCI Probed)
Memory: 2048 Kbytes
RAMDAC: AT&T 20C491 15/16/24-bit DAC with gamma correction
(with 6-bit wide lookup tables (or in 6-bit bit mode))
(programmable for 6/8-bit wide lookup tables)
```

Awesome. This tells you that your board is made of an S3 chip set (a lot of them are), is model number 86C928, and fits into the PCI bus. It has 2048(MB) of video memory and uses a RAMDAC made by AT&T. This last piece of information is not useful when used with the rest of the configuration programs, but write it down anyway. As you use it, be aware that sometimes the chips are known by nicknames. For example, the S3 86C928 may show up in the configuration programs as S3-928.
