# 26 Part I: Introducing Linux

pine has several of the features found in elm, plus a few more. pine uses a simple pico editor for composing mail and can handle MIME (Multipurpose Internet Mail Extensions), which enables you to send pictures, computer programs, and other nonexistent items through the mail. Figure 2-6 shows the screen for sending mail. Notice how pico formats all headers for you and enables you to include MIME attachments.

pine runs on DOS and Windows systems as well as on any UNIX systems. It includes a built-in spell checker (always nice when writing messages to the boss), pine can read NNTP, which is used to access Internet News. Finally, pine can handle IMAP, which sends your mail to a holding place that you can access from anywhere on the Internet. This is especially nice when you are traveling with Linux on your notebook computer because you can connect to your Internet service provider (ISP) and answer your e-mail.

mh(1), also known as the RAND Message Handling System, is a series of commands that enable you to manipulate mail at the command-level. mh is a comprehensive mail interface, enabling you to create different folders for mail, scan mail in those folders in several ways, reply, forward, and otherwise handle your mail. Because mh consists of all these different commands, it was used to build two useful graphical mail interfaces: xmh(1) and exmh(1). Although elm, and pine are on the CD-ROM that comes with this book, mh, xmh, and exmh are not.
