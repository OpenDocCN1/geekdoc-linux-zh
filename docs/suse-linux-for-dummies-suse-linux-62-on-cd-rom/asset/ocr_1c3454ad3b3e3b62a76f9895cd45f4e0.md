# What about emacs?

Many Linux hackers out there would be quick to tell you that the best reason you might have for learning vi is that you may someday be unfortunate enough to sit down at a Linux box that doesn't have emacs loaded.

The reason for the popularity of GNU emacs is understandable. For starters, it can run under X Window System and almost every computer system including MS-DOS PCs and Unix workstations. For programmers, emacs can be configured to format source code for several languages including C, C++, and Lisp. It is a powerful editor, but it is also to be aware of. If you would like to find out more about emacs, you have many books to choose from, such as the GNU Emacs Manual by Richard Stallman (published by the Free Software Foundation, Cambridge, Massachusetts.
