# Chapter 5: Installation: Down to the Final Stretch

If you are not in the United States, you will probably choose something other than the English (US) keyboard, unless you bought your system in the United States. If you don't see an obvious choice, choose something that looks close. If it seems to work, finish the installation. After the installation, you can change the keyboard mapping with YaST, under the menu option Adjustments of Installation. YaST is described in more detail in Chapter 7.

+   6. In the next screen that appears — the Linuxrc main menu, shown in Figure 5–3 — select Start Installation from the list of choices on the menu.

**Figure 5-3:** The Linuxrc main menu screen.

The Start Installation option is what one would choose in most cases. However, if you have an older proprietary CD-ROM, a SCSI hard drive, a SCSI CD-ROM, or a PCMCIA CD-ROM, you need to do one additional step before starting the installation, as described in Step 8. But first, the other options in the Linuxrc main screen are as follows:

+   **Settings.** Use this option to change the language, color, and keyboard mapping settings. You selected these settings in the three previous screens, but if by chance you made a mistake, you can use this menu option to resolve the correct settings.
**System Information.** Select this option to view various information that is known about your system. For example, in the submenu of System Information are menu options for kernel messages (this is the text that you scroll by your screen when you first booted up), Hard disks/CDROM (this shows you a list of the hard drives and CD-ROM that were detected at boot up), Modules (this shows you a list of currently loaded modules), and PCI (this shows you a list of PCI devices on your system). You can use the other menu options display information about various other parts of your system, as their names suggest.
