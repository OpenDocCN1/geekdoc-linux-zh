# Bashing Ahead!

The first thing to do in this chapter is to make sure that you are using the bash shell. If you are using Linux without X Window System and you are logged in as a general user (versus logged in as the superuser, root), you're probably at a shell prompt. If you're using X Window System, you must log in and use the window manager to launch a terminal emulator window, which probably contains a shell prompt. If you are not familiar with how to do this, check out Chapter 11.

Your shell prompt should look something like this:

```
username@hostname:~ >
```

The most important element is the > at the end of the line. This is the prompt and is the shell's method of saying, "Okay, I'm finished with the last thing," The ~ tells you that you are in your home directory.

![](bbox=[0.132, 0.465, 0.215, 0.535])

If you are logged in root or become a superuser through the use of the su(1) command, the > is replaced with a # sign, which indicates that the user is root or otherwise has become a superuser.

To make sure that's the bash shell versus one of the other shells, type the following:

```
username@hostname:~ ~ bash
```

When you press Enter, Linux comes back with one of two responses. If the person who installed your Linux system didn't install bash properly, you see the following:

```
command not found
```

You should find the person who installed your Linux system and throttle him within an inch of ... no, no. You should find the person who installed your Linux system and calmly ask her to kindly help you use the bash shell as your default shell.

If you're lucky, you see the following:

```
username@hostname:~ >
```

Geez. It doesn't look as though Linux did much. It did, though. You are definitely in the bash shell and are ready to see its power.
