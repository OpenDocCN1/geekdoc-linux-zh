# Turnkey system

A turnkey system is put together once and then duplicated in hundreds or thousands of places. Typical turnkey systems are information kiosks, hotel reservation systems, doctor and lawyer office systems, and automotive diagnostic systems. Linux is perfect for this work because it provides the security, protection, and stability that turnkey systems need without requiring payments for many copies of the operating system. For example, one application that we know of was needed on 4,000 systems. If the business had to pay, say, $500 for the operating system, the project would have cost $2 million extra, just to pay for the operating system.
