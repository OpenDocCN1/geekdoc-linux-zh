# Typing code

Commands in the text are shown like this. Commands not in the text, but set off on lines by themselves, look like this:

```
[maddog@local maddog]$pwd
/home/maddog
```

When you see stuff in boldface, it means it's something you should type. The non-bold stuff is text that the computer displays. So, in the preceding, you type pwd (and press Return), the computer displays /home/maddog.

# Introduction

Well, not quite. Notice the [maddog@localhost maddog] in the preceding you won't see that on your system, unless you're Jon's evil, same-named twin. But you will see something similar. The same goes for /home/maddog; t maddog is replaced by the directory name on your system.

Now for further complications. Check out the following:

```
[root@localhost /root]# password <name>
```

<name> is in bold, but it's also italic. That means you should replace <name> with a name. In this case, you replace <name> with your logon name. How are you supposed to know that? Don't worry. We tell you so in the text.

Here's a rundown of the command syntax in Linux:

- Text not surrounded by [ ], ), or > must be typed exactly as shown.
- Text inside brackets [ ] is optional.
- Text inside angle brackets <> must be replaced with appropriate text.
- Text inside braces { } indicates that you must choose one of the values that are inside the braces and separated by the | sign.
- An ellipsis (...) means so on or to repeat the preceding command line as needed.

Don't concern yourself with this too much. For most of the book, you don't need to know these particulars. And when you do need to know about a particular syntax, come back here for a refresher course.

# Keystrokes and such

Keystrokes are shown with a plus sign between the keys. For example, Ctrl+Alt+Delete means you should press the Ctrl, Alt key, and Delete key all at the same time. (No, we don't make you press any more than three keys at the same time.)

You may also see this from time to time:

```
[maddog@localhost maddog]$ vi quagmire
acho Report of login names and users on the Linux system date
echo -f 1,5 -d: /etc/passwd | sed -e 's/:/ /'
<ESC>
:wq
```
