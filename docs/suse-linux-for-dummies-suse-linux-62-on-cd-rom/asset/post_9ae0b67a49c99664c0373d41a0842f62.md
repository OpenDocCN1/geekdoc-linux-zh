## Formatting partitions

By default, all the partitions are set to be formatted. You may not want to format a partition if, for example, this is not the first time you are installing Linux and one of the partitions contains data. If you are having trouble with creating the file system (perhaps your hard drive is old), you may need to check the drive as well as format it. To have a partition formatted and checked, first highlight the partition that you want and then press F6. The Format Mode dialog box appears and you can select Format and Check from the list of available options, as shown in Figure 5-16.

When you format a partition, you erase all data on that partition. Newly created partitions are empty, so you should format those. If you have data that you want to keep in any partition, do not format that partition. For example, many people have data in /home or /usr/local, so these partitions shouldn't be formatted. To prevent these partitions from being formatted, see the list of formatting options. Figure 5-17 shows the completed mount points.

## Selecting and Installing the Packages

At this point, you have successfully completed partitioning your hard drive, either by allowing YaST to do it automatically or by doing it as described in the previous section. The next menu screen that appears, the package management screen, is shown in Figure 5-18. At this point, you need to select what to install on your system. If else would you be going through all the steps in this chapter?

![](img/96a9ce6a13d8d15ed05f867f41574278_110_0.png)

**Figure 5-18:**
The package management main menu.

The programs and files of Linux are installed as packages. The SuSE Linux For Dummies CD-ROM that this book contains more than 300 packages. You can use YaST to install and uninstall these packages. You can also use YaST to install all the packages on the CD-ROM, search for individual packages, and view the contents of a package.

Some packages depend on the presence or absence of other packages. These interrelationships are called dependencies. YaST is designed to verify that all necessary package dependencies are satisfied before installing any packages. YaST is a powerful tool and you will grow to appreciate how easy it makes installing packages on your SuSE Linux system.

Choosing which the 300-plus packages to install may seem like a daunting task given that some are necessary and have dependencies. Luckily, the developers of SuSE have created a default configuration of the necessary and most useful packages. At this point in the installation process, the packages on default are selected to be installed. If you are anxious to continue the installation, you can simply select Start Installation to install these preselected packages, and then skip to the next section. We recommend that you take a few minutes to read about YaST features for selecting additional packages. It is important to add more packages after you have finished installing SuSE Linux.

Brief descriptions of the different menu options follow.

The first menu option is Load Configuration. This is nothing more than a list of packages. In your case, it is not necessary to load any configuration because the default configuration has already loaded. This menu option is useful if you are interested in selecting something other than the default configuration; for example, Almost Everything or Minimal System configurations are also useful if you have created a custom configuration and want to install the exact same list of packages on another computer. Curious readers should check out the contents of the Load Configuration submenu.

The second menu option is Save Configuration. As the title suggests, you can use this option to save a custom configuration you have created. In practice, it is used only if you need to install that custom onto many systems. We don't go into detail on this option.

The third menu option is Change/Create Configuration. You use this option to select or deselect packages to be installed on your system. The Series selection appears (see Figure 5-19). We can already hear you asking, "What is a series?" All packages on SuSE Linux for Dummies (as well as SuSE Linux distribution) are grouped into series according to their use. The series are named accordingly. For example, the first series on the list is Base System, which contains packages that are required as part of the core of SuSE Linux. Likewise, the appropriately titled Documentation contains those that hold documentation (files, and so on).
