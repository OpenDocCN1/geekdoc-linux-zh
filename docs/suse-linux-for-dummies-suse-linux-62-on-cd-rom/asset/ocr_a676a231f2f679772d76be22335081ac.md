+   - dump-freq is the frequency with which the file system may be backed up by the dump utility (not all systems use this).
- pass-number is a decimal number specifying the order in which fsck file system utility, checks the file systems. A pass-number of 1 indicates that this file system should be checked first. This is the pass-number assigned to root. All other file systems should have a higher number. Two systems in parallel to speed up, but file systems on the same drive can have different pass-numbers. For swap devices, the pass-number should be 0 (zero), which disables fsck checking.

Following are examples of typical /etc/fstab entries:

```
/dev/hdb1   ext2 defaults 1 1
/dev/hdb3  none swap    sw      0 0
/dev/hda1   /w95 mdsdos noauto  0 0
```

The first line enables mounting of the first partition of the second IDE disk as the root system. It is a Linux file system and uses the rw, suid, dev, exec, auto, nouser, and async options. The first entry in /etc/fstab file indicates that the root file system should be dumped (backed up) once a week (using the man dump command for details). Finally, the first entry of the /etc/fstab file indicates that the root file system should be the first file system to have fsck performed on after booting the system.

The second line shows that the third partition of the second IDE disk is a swap partition and has the format of a swap file. It should never be backed, nor should you perform the fsck command on the swap partition.

The third line of the /etc/fstab file points to the first partition of the first disk, which is a file system to be mounted on the /w95 directory. This file system properly holds Microsoft Windows 95 files, and you can read and write to this file system. It will not be automatically mounted with the -a option of mount. You should never use dump to back it up, nor should you do a file system check on it.
