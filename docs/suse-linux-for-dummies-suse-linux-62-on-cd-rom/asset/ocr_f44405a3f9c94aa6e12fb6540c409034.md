# Testing your printer

When you have added a printer, you should verify that the printer configuration works. You do so by using a few command-line tools such as lpr, lpc, and lpq, described in this section. If you want more information on the full functionality of these commands, you should read the man page (by typing lpr at the command prompt). The command-line tools to use to test your printer are:

+   Lpr: This is the off-line print command. It uses a spooling daemon to print a specified file when the printer becomes available.

+   Ipc: This is the printer control utility that can be used to administer the printers and print queues. You use it to check the status of the printer queues.

+   Lpq: This is the print queue examination utility. It is most helpful for checking whether any jobs are in the queue. By jobs, we mean files that are waiting to be printed.

You begin by restarting the printer daemon, by using the print daemon initialization script. You can use this script to stop, start, and restart the printer daemon (if the word daemon mystifies you, think of it as a service):

+   1. At the command prompt, restart the print daemon by typing the following:

```
root@localhost:~ # /sbin/init.d/lpd restart
```

You should see a message on your screen, indicating that the printer service is being restarted.

+   2. At the command prompt, check the status of the queues by typing the following:

```
root@localhost:~ # lpc status
```

You should see an output like the following:

```
ascii:
queuing is enabled
printing is enabled
no entries
printer idle
```

```
lpc:
queuing is enabled
printing is enabled
no entries
printer idle
```
