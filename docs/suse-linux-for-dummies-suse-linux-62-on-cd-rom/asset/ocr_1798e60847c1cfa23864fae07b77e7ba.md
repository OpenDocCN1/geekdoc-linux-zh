The next three characters (r--) are the group's permissions. The group has read-only access to the file. The last three characters (r--) are the others' permissions, which are also read-only.

-[rw][r--][-] illustrates the four parts of the permissions: the file type followed by three sets of triplets indicating the read, write, and execute permissions for the owner, group, and "other" users of the file.

Specifying most permissions by using only six letters is easy:

+   - ugo, which stands for — no, not a car — user (or owner), and group,
- rwx, which stand for read, write, and execute.

These six letters, and some symbols such as = and commas, are put together into a specification of how you want to set the permissions of the file.

The command for changing permissions is chmod. The syntax for
command is

```
chmod <specification> filename
```

Change the mode of parttime to give the user the ability to read, write, and execute the file:

```
chmod u=rwx parttime
```

That was easy enough, wasn't it? If you wanted to give the group permission to only read and execute the file? You could execute the following
command:

```
chmod g=rwx parttime
```

Note that this last command does not affect the permissions for owner or\other, just the group's permissions.

Now all set the permissions simultaneously. Separate each group of characters
with a comma:

```
chmod u=r,g=rw,o=rwx parttime
```

This sets the user's permissions to just read, the group's permissions to
and write, and the other's permissions to read, write, and execute.

You can set the permission bits in other ways. This way is so simple, though,
why use any other?
