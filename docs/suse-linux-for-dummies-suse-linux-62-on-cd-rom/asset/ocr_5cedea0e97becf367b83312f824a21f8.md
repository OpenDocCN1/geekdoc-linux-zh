# Chapter 4: Making Room for SuSE Linux 57

In Windows 95 or 98:

+   1. Close all programs and windows on your system, leaving just the desktop-top and icon bar.

+   2. Right-click the My Computer icon on the desktop and select Properties from the drop-down menu items.

+   3. When the System Properties window appears, click the Performance tab in the upper-right corner.

+   4. On the Performance tab, click the Virtual Memory Button in the bottom-right corner of the screen.

+   5. In the virtual memory screen, click the radio button that says Let me specify your own memory settings.

+   6. In the bottom of the same screen, click the check box that says Disable virtual memory.

+   7. Click the OK button to save your settings; close the previous window as well by clicking the OK button.

+   8. When your screen is blank again, double-click the My Computer on the desktop.

+   9. Select your C disk by clicking it.

+   10. Choose File:Properties Tools.

+   11. Defragment Now.

You may get a message telling you that it's not necessary to defragment your disk is not very fragmented. Under normal circumstances this may be true, but in this case it is necessary to defragment your disk because you're going to move the end of the file system and make it smaller. Any data outside that barrier is lost, so you have to move the barrier close to the front.

+   12. Click Start.

The defragmentation window appears.

+   13. Click Show Details.

The defragmentation takes to finish. As the defragmentation continues, you can scroll up and down the large window watching the progress, which is represented by different colored blocks. See Figure 4-1. You can expect to see white space starting to appear toward the bottom of the window, which represents the end of your disk. This shows that the data is being moved reward the disk. At the end of the defrag process, no colored blocks should be at the bottom of the window, and all the blocks should be compressed toward the top of the window. The white space is free space in your MS-DOS file system that you may now allocate to the Linux file system.
