# Commercial Applications

While we're talking about commercial support, we should mention something about commercial applications. A lot of Linux users are frugal (we prefer term rather than *cheap*) and often want or need to use only freely distributable software. And in many cases, the freely distributable software is very good and does exactly what they want. Other times, though, the application you want is available only commercially.

Other people who use Linux buy the latest and greatest hardware and want the same commercial applications on Linux that they have on their other operating systems, no matter the price.

For commercial application vendors everywhere may be reading this, I cannot stress enough that you should look at Linux like any other operating system. You can sell your applications to a market that is not only appreciated but also believes, for various reasons, that its operating system should be open.

Take an example of functionality available from the commercial world, Applyx, a word processor, a spreadsheet, a presentation package, a mail front end, an HTML authoring program, a graphical program for drawing pictures (usually to include in your presentation or paper), an application building program, and a scripting language that allows you to tie these and other programs together.
