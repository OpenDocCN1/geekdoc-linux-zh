# # Appendix C

# # About the CD

The SuSE Linux For Dummies CD-ROM contains the full freeware distribution of SuSE Linux 6.2 as well as Netscape Communicator and many other applications.

# ## System Requirements

Make sure that your computer meets the minimum system requirements listed here. If your computer doesn't match up to most of these requirements, you may have problems with the contents of the CD:

+   - A PC with a 486 or faster processor.
- At least 16MB of total RAM installed on your computer. For the best performance, I recommend that people who want to use X Window have 64MB of main memory.
- At least 800MB of hard drive space available to install all the software from the CD. You'll need less space if you don't install every program. For example, if you want to install only the smallest subset of the base system and X Window System, you can do that in about 180MB.
- A CD-ROM drive (preferably ATAPI compliant).
- A 3½-inch floppy disk drive and two blank 3½-inch disks.
- A monitor capable of displaying at least 256 colors or grayscale.
- An IDE or a SCSI disk.
- A keyboard and a mouse.
- A modem with a speed of at least 14,400 bps if you want to go online.

Appendix A lists all the hardware compatible with Linux.
