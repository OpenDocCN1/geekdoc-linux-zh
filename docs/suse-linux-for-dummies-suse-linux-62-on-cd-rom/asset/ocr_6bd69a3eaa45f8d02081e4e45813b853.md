# Chapter 5: Installation: Down to the Final Stretch

You will receive a confirmation that all packages have been installed. When you press Enter, the system again reboots and you are prompted to log in.

# Tada! You Made It!

+   1. At the login prompt, type root.
2. At the password prompt, type the password you entered for the root password and then press Enter.

You are now logged in as superuser, also known as root.

This installation may have seemed like the most odious task since the digging of the Panama Canal, but you have finished it. Congratulations. You've done more at this point than most people have with their computer system, and now you are ready to move forward with using Linux as a tool.
