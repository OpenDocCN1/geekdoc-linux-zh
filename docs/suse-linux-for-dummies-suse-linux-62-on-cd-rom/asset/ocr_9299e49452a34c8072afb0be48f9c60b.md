# 6. Configure your monitor from the choices shown in Figure 6-6.

The monitor configuration screen, just like the card configuration screen, is divided into two windows: and Name. You need to select the appropriate vendor and name for your monitor. If your monitor vendor and/or name does not appear on the list, you can use one of the generic settings by selecting the VVESA option in the Vendor window and selecting one of the default settings for the resolution you plan to use. If the Horizontal and Vertical sync rates do not match those of your monitor, you can set them manually by clicking the Expert button. After you have selected the monitor settings, click the Next button in the bottom-right corner of screen.

# 6. Configure the color depth and resolution for your X server in the Desktop screen.

This screen has only two settings, Colors and Resolution, as shown in Figure 6-7. We suggest a minimum color depth setting of 16 bit, and more your video card supports it. Although an 8-bit color setting is functional, you will be disappointed with this setting. For the Resolution setting, we recommend a minimum of 800 x 600. If your hardware supports a higher resolution, 1024 x 768 is very nice. You may have noticed the button titled Configure This Mode and are wondering what this button does. With X windows, you can configure the X server to use different resolutions and switch back and forth between them, after you have started the X Windows system. For the time being, we focus on getting X Windows up and running before experimenting with these more advanced features. After you have selected your desired Colors you are ready to test the configuration.
