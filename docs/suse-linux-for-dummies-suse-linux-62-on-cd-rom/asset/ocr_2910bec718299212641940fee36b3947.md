# Hardware Parameters on Boot

If you are having problems getting the Linux kernel to recognize certain aspects of your IDE hardware devices on bootup, please have a look at these boot time parameters. The following is an excerpt from the BootPrompt HOW-TO:

The IDE driver accepts a number of parameters, which range from disk geometry specifications, to support for advanced or broken controller chips. The following is a summary of all the possible boot arguments. For full details, you really should consult the file ide.txt in the linux/Documentation directory, from which this summary was extracted.

+   - drive may be present, but do not probe for it
- drive is NOT present, ignore cmos and do not probe
- hdx=nop
- hdx=none
