# Serial, Parallel, and Joystick Interfaces

Any standard serial, parallel, joystick, or combo card can be used. Linux supports 8250, 16450, 16550, and 16550A UARTs.

# Other Controllers (Multoint)

Some cards are used to increase the number of serial lines that a PC-style system can support above the one or two serial/parallel lines that come with the system. These cards are intelligent or nonintelligent, depending on whether they or the main CPU buffer characters into the system and handle sending stop and start signals to the devices. Intelligent cards can cut down on every overhead of thousands of characters into the system every second. Nonintelligent cards also use a lot of system resources. Try to get a card that uses only one IRQ.

# Network adapters

Make sure you have a good Ethernet if you want one. Most of the earlier cards were flaky and make the system stop working from time to time. Most of the new cards work now in your current environment as well as in lower environment.
