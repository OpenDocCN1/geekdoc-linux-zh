# # I Don't Know How to Make X Window System Start at Boot Time

**Problem:** You don't have to log in to a command-line mode (such as DOS) and then type startx. Instead, you want to log in through X Window System.

**Solution:** We set up our machine so that it starts in character-cell mode and allows us to switch to X Window System. (Many times, we want to make a simple edit or look at something on the system, and logging in- out X Window System is simply faster.) If you like to see a graphical interface from the beginning, however, do the following. In the /etc/initabb file, change this line:

```
id:2:initdefault:
```

to this:

```
id:3:initdefault:
```

Save your changes and reboot. X Window System starts at the end of the boot process, and you can then log in through the graphical interface. To go back to the old way of booting, change the line in the /etc/initabb file back to the following:

```
id:2:initdefault:
```

and reboot the machine. Note that the same thing can also be accomplished through YaST:System Administration:Login configuration.
