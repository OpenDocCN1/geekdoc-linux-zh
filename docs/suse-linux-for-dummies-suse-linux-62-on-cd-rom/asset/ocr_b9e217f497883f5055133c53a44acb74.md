+   - uptime tells you the amount of time your system has been active since the last reboot. Some Linux systems (particularly used for Internet service) have been up for years since boots.
- irq indicate when a device (as a disk, tape, or keyboard) has input and output to be handled.

The kernel command line shows the information passed to the kernel when booting. The BOOT_IMAGE is Linux (no real surprise) and the disk is 305, or section 5 of device number 3.

When we use the following command:

```
[maddog@shamet maddog]$ ls -1 /dev/hada
br-rw- 1 root disk 3, 0 Sep 8 1998 /dev/hada
```

+   - we see that /dev/hada is 3 on our systems (but may be different on your system).
- The kernel command line indicates that the root file system should be mounted read-only (ro) until the file system check (known as fsck) can be performed and the file system can be remounted with its setting to read-write. Having the root file system mounted read-only during fsck protects the results of the fsck program until the root file system can be restarted in its normal mode.
- Modules refers to pieces of code that are not included as part of Linux until needed.
