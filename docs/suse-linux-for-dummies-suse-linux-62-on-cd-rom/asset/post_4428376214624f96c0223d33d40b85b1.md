If you want to go to a specific line number, you use a colon command. Type a colon (:) and it appears at the bottom of the screen; then type the line number where you want to be. For example:

:12

Press Enter, and the cursor moves to the beginning of line 12.

## Deleting and moving text

Now that you know how to enter text in vi, we show you how to work with that text. In this section, you delete and move your text.

The vi editor has several commands for deleting. You can delete characters, words, or lines. The command for deleting a word is dw; this deletes the word to the right of the cursor. More words can be deleted at once by prefacing the dw command with the number of words you deleted from the cursor position. For example, the command 6dw deletes the next six words following the cursor. Table 9-2 lists additional deletion commands.

## Table 9-2 Deleting in vi

| Command | What It Does |
| --- | --- |
| d | Deletes up to the end of the current line |
| dd | Deletes the current line |
| x | Deletes the character under the cursor (4x, 5x, and so on) |

![](img/96a9ce6a13d8d15ed05f867f41574278_185_0.png)

A handy command to remember is u. It's the undo command, and edits may be undone immediately with it, in the unlikely event that you make a mistake.

The business of moving text around in the file usually requires the following general steps:

- 1. Position the cursor at the beginning of the first line you want to move or copy.
- 2. Type ma, marking that position with the letter a.
- 3. Position the cursor at the beginning of the last line that you want to move or copy.
- 4. Type mb, marking that position with the letter b.
- 5. Position the cursor at the line where you want to insert the text.
- 6. Type ':a, if you want to move the text, or ':a,bt. if you want to copy the text.
Note that the single quotation marks and period are required.

## Controlling the environment

You may control your editing environment in vi by setting options with the :set command. Table 9-3 lists some common :set command options.

### Table 9-3 Everyday :set Options

| Command | What It Does |
| --- | --- |
| all | Displays a list of all :set commands and their status |
| errorbells | Sounds the terminal bell when errors occur |
| ignorecase | Makes searches case insensitive |
| number | Displays line numbers in the leftmost column on the screen |
| showmode | Displays an indicator at the bottom right of the screen indicating which mode you are in: input mode, change mode, replace mode, and so on |

Note: set command options can be toggled off by prefixing the command with no, as in

:set nonumber which toggles line numbering off.

## xedit, the Simple Editor

xedit is a simple, mouse-based text editor that is probably the easiest of the editors discussed in this chapter to use. However, it works only with X Window System (the graphical portion of Linux).

Give xedit a try:

- 1. In a terminal emulator window of X Window System, type the following:
  xedit
A window like the one in Figure 9-1 appears. Note that it has several panes.

![](img/96a9ce6a13d8d15ed05f867f41574278_188_0.png)
Figure 9-1: The initial xedit screen.

- 2. Click the text window that's to the right of the word Load.
- 3. Type the filename you want to edit.
In Figure 9-2, the filename appears.

![](img/96a9ce6a13d8d15ed05f867f41574278_189_0.png)
Figure 9-2: The file is loaded into the editor.

- 4. Click Load button.
If you are creating a new file, a message in the middle pane says your file has been opened. If your file already exists, you should see text in the bottom pane, as shown in Figure 9-2.

- 5. To edit, click in the bottom pane in the place you want to change and start typing.
To delete characters, click to the right of the character you want to delete, and then press the Delete key as many times as you want.
When you are finished, click Save button and then Quit button. Or, if you have made a mistake and want to stop without saving the file, quit.

What happens if you have a really big file that can't fit into the bottom pane? xedit provides a scroll bar so that you can move the data up and down in the window, as shown in Figure 9-3. The easiest way to scroll is to drag the pane of the scroll bar (known as thumb), even though you are using your finger to move it up and down. Drag, click and hold the left mouse button while moving the cursor. You can see an example of this in Figure 9-3.

In Figure 9-3, you can see that the message pane has more than can fit in the window, so xedit provides a scroll bar for this pane also. Also note that the pane above the text displays the filename.

![](img/96a9ce6a13d8d15ed05f867f41574278_189_1.png)

If the file is read-only, xedit will not allow you to change the text in the bottom pane if the file is opened read-only. Either copy the file into another file that is not read-only or become superuser and invoke xedit on that file.

![](img/96a9ce6a13d8d15ed05f867f41574278_190_0.png)
Figure 9-3: xedit with scroll bars to handle large files and many menus

You can search and replace text with xedit:

- 1. Click in the area of your text where you would like to start searching.
- 2. Press Ctrl+S to search forward in the file for your text, or Ctrl+R to search backward through the file.
A dialog box appears, as shown in Figure 9-4.

![](img/96a9ce6a13d8d15ed05f867f41574278_190_1.png)
Figure 9-4: The xedit dialog box enables you to control the search and replace functions.

- 3. Click the Search for: box and type the text you want to search for.
- 4. If you want to replace that text with some other text, click the Replace: box and type the replacement text.
You can also use the Tab key to move between the search and replace boxes. This is nice because you don't have to remove your hands from the keyboard. But it also means that to enter a tab character into the search or replace box, you first have to press Ctrl+Q and immediately press the Tab key.

![](img/96a9ce6a13d8d15ed05f867f41574278_191_0.png)

- 5. Click Search to find the first string you want to locate or replace.

```
xedit finds and highlights the text.
```

- 6. If you are just searching for text, click Search again.
Repeat this step as many times as you want.

- 7. If you are replacing text, click Replace.
The program replaces the text and moves to the next occurrence of the text you are searching for. Keep repeating this step until you're finished or bored.

The Replace All button searches through the entire file, replacing all occurrences of the text at one time. Be careful when using this option, though. Suppose you want to search for car and replace it with auto. If you use the Replace All option, and the words carpet, carrot cake, discard, for example, appeared in your file, they would be replaced as well — to autopet, autorot cake, and disautout.

- 8. To end the search, click Cancel.

![](img/96a9ce6a13d8d15ed05f867f41574278_191_1.png)

Many people will argue that xedit is a powerful text editor with lots of features. It, however, enables you to edit simple text with very little practice.
