+   Package A requires either Package B or Package C. This type of package dependency issue also requires manual intervention. You need to make a choice before installing Package B or Package C. YaST displays package A followed by the word [AND], as well as package B and C, separated by the word [OR] You need to go back to the package selection screen and manually select each Package B or Package C.

After all package dependency issues are resolved, select Continue and press Enter.

The What If... menu option displays all the packages that are selected for installation.

Selecting the Start Installation menu starts the installation of the packages from the CD-ROM onto your hard drive. When you have finished selecting any additional packages to be installed, you should select this menu option. You will see a progress indicator as each package is installed. At the top of the screen, you can see which package is currently being installed as well as how many packages are remaining. When all selected packages have been installed, you are presented with the package management main menu. To continue with the installation, select the Main Menu option.

You use the Index of all Series and Packages option to view a list of all packages on the SuSE Linux For Dummies CD-ROM. This option is helpful because you can quickly see a list of all the packages in alphabetical order as well as which series each package belongs to.
