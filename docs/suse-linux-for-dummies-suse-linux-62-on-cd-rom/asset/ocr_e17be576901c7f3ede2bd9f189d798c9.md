# Selecting the mount points

To set a mount point for a partition, first highlight the partition and then press F4 to be presented with a list of mount point options. One of your partitions must be set as the / (root) mount point. In Figure 5-15, partition /dev/hda2 is mounted as and /dev/hda4 is mounted as /home.
