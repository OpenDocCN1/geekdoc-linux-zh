# Time Zone Configuration

The next screen is the Time Zone Configuration, as shown in Figure 5-28. Scroll down the list and select the appropriate time zone. When you have selected your appropriate time zone, press Enter. The adjustment of Hardware clock screen appears and asks whether hardware clock (the one in the system BIOS) is set to GMT or Local Time. Most computers have hardware clocks are set to local time, if you are not sure, selecting local time is a good guess.
