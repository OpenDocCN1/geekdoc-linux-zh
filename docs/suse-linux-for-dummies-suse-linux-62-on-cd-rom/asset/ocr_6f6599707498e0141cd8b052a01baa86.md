# Creating a user account

When YaST restarts, a dialog box appears and asks whether you want to create an example user. Although doing so is not required, we strongly recommend you create a user account and use this account when using your Linux computer. When creating an account, you need to enter the user name, which must be a contiguous string of characters. In addition to the user name, you must enter a password. We urge you to change the description to your full name, although you can leave this field blank.

# Configuring your modem

If you have a modem and you know which COM port it is attached to, you can configure this in the next dialog box. Select the appropriate COM port for your modem from the list. If you are not sure which COM port your modem is attached to, don't worry — you can configure it later, in Chapter 15, “Setting Up Your Internet Connection.”

# Configuring your mouse

The mouse configuration dialog boxes are shown in Figures 5-33, 5-34, and 5-35. In the first screen (see Figure 5-33), you are presented with a list of mouse protocols. Select your mouse from the list. If you have a serial mouse, you are also presented with a list of COM ports to select from.
