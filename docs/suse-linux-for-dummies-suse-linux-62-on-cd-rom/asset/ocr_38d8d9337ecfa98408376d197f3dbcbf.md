> If you are looking at the list of hard drives and are confused, this tip is for you! Linux defines IDE hard drives according to the following naming conventions:

IDE DEVICES

LINUX NAME

Master device on the primary IDE chain
Slave device on the primary IDE chain
Master device on the secondary IDE chain
Slave device on the secondary IDE chain

/dev/hda
/dev/hdb
/dev/hdc
/dev/hdd

SCSI DEVICES

LINUX NAME

First logical SCSI hard drive (device)
Second logical SCSI hard drive (device)
Third logical SCSI hard drive (device)
And so on.
