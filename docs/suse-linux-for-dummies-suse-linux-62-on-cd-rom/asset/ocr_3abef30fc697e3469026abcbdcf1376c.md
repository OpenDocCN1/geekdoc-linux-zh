# 152 Part III: Using SuSE Linux

Linux sometimes uses a command called less, which duplicates the functionality of the more command. Originally, the less command was designed to be more robust than the more command, but the more command caught up and they are now almost the same. Some Linux systems display text with the less command instead of the more command, which most UNIX programs use.

![](bbox=[0.115, 0.203, 0.213, 0.283])

The less and more commands have two apparent differences. One, the less command requires a q command to get back to the Linux prompt, even when you are at the end of the last page. Two, the more command always says More at the bottom of a screen, whereas less has just a : character at the bottom of the screen to indicate that it is waiting for you to input the next command. The SuSE Linux For Dummies CD-ROM, which is a SuSE distribution, uses more rather than less as a default.
