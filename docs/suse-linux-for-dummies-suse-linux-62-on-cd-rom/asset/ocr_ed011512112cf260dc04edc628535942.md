If you are installing from the SuSE Linux For Dummies CD-ROM, all you have to do is put the CD in the CD-ROM drive, put the boot disk (that you make using the instructions in Chapter 4) in the floppy drive, and boot (or reboot) your machine. Please note that if you have a system that can be booted from the CD-ROM, you do not need the boot disk. You'll be asked a series of questions, which detailed installation instructions in this chapter walk you through.

Now you are ready to begin the detailed steps of installation. Make sure your glass is full. To begin:

+   1. Place the boot floppy you made with write or dd in the first floppy drive (drive A), and place the SuSE Linux For Dummies CD-ROM in the CD-ROM drive.

+   2. With your PC set to boot from the floppy (normally the system default), reboot your system.

Note that if you have a system that can be configured to boot from the CD-ROM, you do not need to use the floppy at all, as discussed in the previous chapter.
