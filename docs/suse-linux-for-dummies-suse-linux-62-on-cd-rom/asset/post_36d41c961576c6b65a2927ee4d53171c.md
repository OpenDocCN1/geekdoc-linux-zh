Another character-cell text editor is emacs, one of the shining stars of the Free Software Foundation. Devotees of emacs claim that it is more than just a text editor; it's an interface to reading mail, debugging your programs, reading news from the Internet, and a variety of other text-oriented activities. The program can emulate several character-cell editors. emacs has also made the jump to a graphical mode. Downsides of emacs are its size and its use of a fair amount of disk space. emacs is included on the CD-ROM that comes with this.

Based on the concept of being able to extend its capabilities by LISP, a powerful programming language, emacs is the only editor we have seen that can display a graphical illustration of the Towers of Hanoi problem on a character-cell video screen, and proceed to solve it, showing all the modes.

pico(1) is a simple, easy-to-use text editor with a simple front end for mail. Some mail programs integrate editors; some editors initiate mail programs; simply enable you to specify which editor you want to use and run that editor. Combining the function of editing and reading mail is often sensible because many people use only mail and editing applications. ## Chapter 2: Accessorizing Linux

### Graphical all text editors

In addition to all the character-cell editors that come with Linux systems, several text editors are built for the X Window System environment, which is also referred to as X11. You must have X Window System running to use these.

xedit(1) is a mouse-based editing tool, with a file open and close window, an error message window, and a text window (see Figure 2-3). It has limited functionality but is simple to use and fine for working on small files. xedit comes on the CD-ROM that is included with this book.

If X Window System is running, the emacs(1) editor, mentioned in the preceding section, will appear in graphical mode (see Figure 2-4).

Finally, you can run any character-cell editor under X Window System by invoking it with a terminal emulator. The program will run just as it does under the character-cell mode of Linux.

### Commercial text editors

Several commercial text editors are available. Some have significant added value compared to simple text editors. In this section, we describe two of the most popular commercial editors.

Vi by MicroEdge is an X11-based editor that runs also on Windows 3.1, 95, 98, and NT platforms. The editor is language-sensitive, so if you're programming in C++, Java, HTML, Perl, AWK, Pascal, FORTRAN, BASIC, dBASE, Modula2, COBOL, Vi knows about these languages and tries to make the text readable and searchable. Vi emulates several other editors (such as emacs) and integrates with other programs that help keep track of code. Vi is definitely a programmer's editor but can be used by programmers.

Crisp by is another language-sensitive, cross-platform editor. Cross-platform editors can run on many different UNIX and Linux systems as well as on Windows 3.1, 95, 98, and NT.

## Mail Interfaces

E-mail consists of two main parts: a front end (or interface) that you use to compose or read messages and a back end that delivers your messages. In addition to the mail-specific programs described in this section, note that some web browsers can also read mail, read Internet News (a series of information accessible over the Internet), handle FTP downloads of files, and perform other Internet-related tasks.

### Character-cell interfaces

The first mail interfaces were available only in character-cell mode. In this section, we discuss several character-cell interfaces; some are freeware and others are commercial packages.

mail(1), one of the first mail interfaces, is a character-cell interface for early versions of UNIX. mail remains a powerful interface and sometimes we use it when we want to send a quick message.

elm(1) is an interactive screen-oriented mailer that we use in place of mail as a front end. It's easy to use and presents a vim(1)-like editor for creating mail messages.

pine(1) (which now means program for Internet news and e-mail was previously known by the friendlier name pine) is another full-screen mail interface. Figure 2-5 shows the initial pine screen.

pine has several of the features found in elm, plus a few more. pine uses a simple pico editor for composing mail and can handle MIME (Multipurpose Internet Mail Extensions), which enables you to send pictures, computer programs, and other items through the mail. Figure 2-6 shows the screen for sending mail. Notice how pico formats all headers for you and enables you to include MIME attachments.

pine runs on Windows systems as well as any UNIX systems. It includes a built-in spell checker (always nice when writing messages). pine can read NNTP, which is used to access Internet News. Finally, pine can handle IMAP, which sends your mail to a holding place that you can access from anywhere on the Internet. This is especially nice when you are traveling with Linux on your notebook computer because you can connect to your Internet service provider (ISP) and answer your e-mail.

mh(1), also known as the Message Handling System, is a series of commands that enable you to manipulate mail at the command-level. mh is a comprehensive mail interface, enabling you to create different folders for mail, scan mail in those folders in several ways, reply, forward, and otherwise handle your mail. Because mh consists of all these different commands, it was used to build two useful graphical mail interfaces: xmh(1) and exmh(1). Although elm and pine are on the CD-ROM that comes with this book, mh, xmh, and exmh are not.

### Graphical mail interfaces

Graphical mail programs offer a powerful and easy-to-use interface to read and manipulate mail. Graphical mail interfaces, like text editors, require the Window System.

xmh(1) is a graphical interface written for the character-cell-oriented mh commands, mentioned in the preceding section. As such, it lets you alternate between using mh in the character-cell environment and xmh in the graphical environment. xmh is a simple interface written mostly to demonstrate early versions of X Window System.

We prefer the xmh(1) graphical mailing program. It is freely distributable, so we use the same interface on systems at work, systems at home, and notebooks when traveling. It is powerful — with MIME and POP (an earlier version of IMAP) capabilities, folder support, and easy ways to tailor. The xmh mailing program also highlights URLs (addresses of World pages) in the text of your mail; when you click the URL, xmh calls up your browser and displays the URL. xmh has a comprehensive search facility for looking for messages in folders.
