## Destructive repartitioning

If you are keeping your current operating system, and you can't add another disk to your system, and nondestructive repartitioning won't work (you tried and found that you couldn't use your other operating system afterwards), you need to use destructive repartitioning.

You use an MS-DOS utility fdisk to wreak your destruction, as follows:

## Chapter 4: Making Room for SuSE Linux 61

- 1. Make a full backup of your system.

If you want to reinstall DOS and Windows data, follow the instructions for your Windows backup utility. At a minimum, copy anything you can't reinstall from program disks. This data includes your files from a word processor, a spreadsheet, and a database, as well as e-mail you want to save. Most people customize settings for the programs themselves, so to save those settings too, you really need to back up everything.

- 2. Make sure you have full backup of your system.

- 3. Get out of Windows 3.1 and into MS-DOS.

From the Program Manager window, choose File→Exit Windows.

- 4. Create an MS-DOS bootable backup disk.

Place a blank, formatted disk in the floppy drive (which I assume is drive A) and type the following:

```
FORMAT /s A:
```

- 5. Copy FDISK.EXE and FORMAT.COM to the disk.

To copy the files, you type the following:

```
cd \
cd dos
copy format.com a:
copy fdisk.exe a:
```

Please check the manual for your backup program to see whether any other utilities are needed to restore your files. Copy those utilities to the disk as well.

- 6. Boot your PC with the disk you just created.

Place the disk in the floppy drive and restart your computer.

- 7. Run FDISK (the MS-DOS one).

At A prompt, type the following:

```
FDISK
```

- 8. Use the FDISK menu options to delete the partitions you want to change and make new ones for DOS and Linux. Do not choose the large disk support in the first message (just press Enter).

- 9. When FDISK asks you to choose one of the following, as shown in Figure 4-3, select 4 and then press Enter.

You see a partition table showing all the partitions and your types.

- 10. Delete enough partitions to allow space for SuSE Linux. Delete all of them, if you want.

## Tiptoe through the dialog boxes

| During the installation, you and SuSE talk to each other — what else — dialog boxes. || To maneuver between highlighted options in a dialog box and make your choices, you use the following keys (note that cursor means the cursor or the highlight): |
| Tab | Moves the cursor to the next section in the screen |
| Left-arrow | Moves the cursor backward through a list of options |
| Right-arrow | Moves the cursor forward through a list of options |
| Up-arrow | Moves the cursor up through a list of options |
| Down-arrow | Moves the cursor down through a list of options |
| Spacebar | Selects an item from a list of options |
| Enter | Selects the highlighted item or continues to the next screen |
| F1 | Where available, brings a help menu |
