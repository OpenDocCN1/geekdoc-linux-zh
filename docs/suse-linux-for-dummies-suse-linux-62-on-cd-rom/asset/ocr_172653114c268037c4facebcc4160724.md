You know what they say about people who make assumptions, but this book would never have been written if we didn't make a few. This book is for you

+   - You have a SuSE Linux operating system. Surprise — one is on the SuSE Linux For Dummies CD-ROM in the back of the book.
- You have a computer.
- You want to put the SuSE Linux operating system and the computer together, and using duct tape hasn't worked.

# Conventions Used in This Book

At computer conventions, thousands of computer people get together and talk about deep technical issues such as

Is Coke better than junk?

Are Tim-Tams the ultimate for junk food?

What is the best hardware for running Linux?

But these aren't the types of conventions we're talking about in this section. Our conventions are ways of designating specific information, such as what is and isn't a command or the meaning of certain funny-looking symbols.

# Typing code

Commands in the text are shown like this. Commands not in the text, but set off on lines by themselves, look like this:

```
[maddog@local maddog]$pwd
/home/maddog
```

When you see stuff in boldface, it means it's something you should type. The non-bold stuff is text that the computer displays. So, in the preceding, you type pwd (and press Return), the computer displays /home/maddog.
