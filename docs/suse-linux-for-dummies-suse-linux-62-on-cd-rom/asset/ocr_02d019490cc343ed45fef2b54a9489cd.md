# Chapter 2: Accessorizing Linux

# Graphical all text editors

In addition to all the character-cell editors that come with Linux systems, several text editors are built for the X Window System environment, which is also referred to as X11. You must have X Window System running to use these.

xedit(1) is a mouse-based editing tool, with a file open and close window, an error message window, and a text window (see Figure 2-3). It has limited functionality but is simple to use and fine for working on small files. xedit comes on the CD-ROM that is included with this book.

If X Window System is running, the emacs(1) editor, mentioned in the preceding section, will appear in graphical mode (see Figure 2-4).

Finally, you can run any character-cell editor under X Window System by invoking it with a terminal emulator. The program will run just as it does under the character-cell mode of Linux.
