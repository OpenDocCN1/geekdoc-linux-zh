# Chapter 3: Discovering What's in Your System

If you don't have any literature about your system, and you don't have Windows 3.1 or Windows 95 on your system (perhaps you like to run FAT free), and no dealer is within hundreds of miles, don't give up hope. Linux is good at sniffing out and identifying hardware during the installation.

# The Information You Need to Know

Here are the questions you need to answer your hardware:

+   - Disk controllers. How many do you have and what are their types (IDE, SCSI )? Which hard drives are connected to which controllers? If a SCSI controller is installed in your machine, what is its make and model number?

+   - Hard drives. How many hard drives do you have? For each drive, what is its size and order (which one is first, second, and so on)?

+   - CD-ROM. What is the interface type? Is it an IDE drive, a SCSI drive, or other type? For CD-ROMs other than IDE (APATI) or SCSI, what is the make and model number?

+   - RAM. How much RAM is installed on the computer?

+   - Mouse. What type of mouse do you have — a bus mouse, PS/2 mouse, or a serial mouse? How many buttons does it have? If you have a serial mouse, which COM port is it attached to and what protocol does it use (such as Microsoft or Logitech)?

+   - Monitor. What are the make and model of the monitor? What are its vertical and horizontal refresh rates? You need this information only if you will be using the graphical portion of Linux, called X System.

+   - Video card. What are the make and model number of the video card or video chip set and the amount of video RAM?

+   - Network interface card (NIC). If you have a network connection, what are the make and model number of the network interface card?

+   - Network information. If you have a network connection, what are your IP address,get, gateway IP address, name server addresses, and host domain names? If you need help, contact your network administrator or Internet service provider (ISP).

To install most Linux distributions, you need to answer the questions in the preceding list. Now that you know what you should be looking for, the next section deals a bit more into how to locate and capture that information.
