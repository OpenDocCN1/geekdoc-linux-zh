# Configuration Conflagration

Now that you know all the information about your video hardware and you have the correct X server installed, you can start configuring Windows System. We assume that you don't have Windows System up and running. If it is up and running, what are you doing here? Go on to another chapter.

The next step is to use a program SaX, the SuSE Advanced configuration tool. SaX is a user-friendly graphical tool that is designed to probe your hardware for you. Because it may not recognize everything, you will have to manually select some configuration settings for your hardware. As with all X configuration tools, SaX creates a configuration file that the X server uses so it knows how to communicate with your mouse, keyboard, monitor, and the video card on your system.

As Linus becomes more sophisticated in the methods that it uses to probe hardware, and as hardware becomes more sophisticated in the information that it can return to the operating system, fewer questions will need to be asked. For now, though, we have SaX.

To run SaX, follow these steps:

- 1. Log in as root and type the following:

```
sax
```

SaX should start and immediately open the mouse configuration screen, as shown in Figure 6-3. If SaX does not start, it may not be able to determine the hardware. For example, if you want to use VGA, type the following:

```
sax -s vgga
```

![](img/96a9ce6a13d8d15ed05f867f41574278_134_0.png)

Figure 6-3: The Sax configuration screen.

- 2. Select the appropriate device and protocol.

If you are having problems getting your X server to start, or your video card requires an X server that is not on the Generic list, then you should click the Expert button in the bottom-left corner of the screen and select the X server from the drop-down list that appears. After you have selected your X server from the list, make sure to click the Apply button.

- 3. Select the keyboard settings that you want.

In general, most keyboards are supported by the Generic settings. When you are satisfied with the mouse, click the OK button. When you are ready to continue, click the Next button in the bottom-right of your screen.

![](img/96a9ce6a13d8d15ed05f867f41574278_135_0.png)

![](img/96a9ce6a13d8d15ed05f867f41574278_135_1.png)

Figure 6-4: The keyboard configuration screen.

- 4. You should be presented with the Card tab. If you are still in the keyboard configuration screen, click the Next button in the bottom-right of your screen.

The card configuration screen is divided into two windows, Vendor and Name, as shown in Figure 6-5. In the Vendor window, select the vendor of your video card. In the Name window, select the name of your card. If your card and/or vendor are not on the list, but you know which X server you use (either from Super or the card list on the Web at www.xfree6.org/cardlist.html), click the first option in the Vendor window, Generic Selection. A list of Generic servers will appear in the Name window. From that list, you should select the appropriate X server. When you do, Sax will select the video card and you may need to manually configure these values, and you do this by clicking the Expert button and selecting the options in the screens that appear. When you are ready to continue, click the Next button in the bottom-right of your screen.

![](img/96a9ce6a13d8d15ed05f867f41574278_136_0.png)

Figure 6-5: The Sax video card configuration screen.
