# Tuning Your Linux System

UNIX-like systems don't have many knobs and buttons you can change to make them faster or better. Linux, however, has a few special features that you can tweak for better performance. More importantly, if you follow a few guidelines, you will help your Linux system perform at its best.

# You can never have enough memory

Although too much memory is theoretically possible, suppose, most people have too little — in their systems, that is. Today, memory is so inexpensive that few excuses justifying not having enough.

Not having enough RAM is a holdover from memory prices such as $23,000 per megabyte. I paid $400 for 4 kilobytes (.004MB) of main memory about the same time I purchased a pickup truck for $2,000.
