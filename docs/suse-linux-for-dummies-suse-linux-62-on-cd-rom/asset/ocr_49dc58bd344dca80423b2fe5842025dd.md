+   7. If you have a SCSI CD-ROM, a PCMCIA CD-ROM, or an older proprietary CD-ROM, add the appropriate kernel module for your hardware.

If you have a SCSI CDROM, a SCSI hard drive, a non ATAPI compliant CD-ROM, or a PCMCIA CD-ROM, you must load the correct module for your hardware. To load the correct module for your hardware, select the appropriate subsubmenu (for example, SCSI Module) and then select the appropriate module for your hardware. If you are unsure about your hardware, you can also try the Autoload of modules menu option. This menu option, shown in Figure 5-4, will try to load each of the modules one at a time. The module (or modules) that are successfully loaded will be reported to you.

In some cases, you will be prompted to install the modules diskette. This is the diskette you created in Chapter 4. Note that when loading-modules, you will be prompted for parameters. In most cases, you do not need to specify any parameters. In the event that the module was not successfully loaded, please refer to the Appendix A where examples of module parameters are given.

At this point, you should have, if necessary, loaded the appropriate modules for your hardware. You are ready to install SuSE Linux.
