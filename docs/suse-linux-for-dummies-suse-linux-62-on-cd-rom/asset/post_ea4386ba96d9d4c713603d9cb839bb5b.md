## Discovering Your Hardware's True Identity

Before you start X Window System, you need to know about your video controller card, monitor, and keyboard.

For your video controller card, you need to find out:

- The model number (and perhaps the video chip used)
- The amount of RAM it has

You should be able to find this information in your system's documentation or by using MS-DOS or Windows as described in Chapter 3. But now that you have Linux up and running, the next best method for finding that missing information is to run the SuperProbe program, which comes from the SuSE Linux for Dummies CD-ROM. We describe how to run SuperProbe in the next section.

You should also have a look at the list of video cards from the Xfree86 (the organization that created the X servers), which can be found on the Web www.xfree86.org/cardlist.html. This list shows video cards that are known to work, along with X server supports that card. If your card is on this list, chances that during the installation, the appropriate X server was automatically installed. In some cases, if the card was not recognized, you will have to manually install the X server. As described in the section "Installing the X Server," in this chapter.

Next, you need to know the following about your mouse:

- The model number and manufacturer
- The type of mouse it is (a PS/2 bus mouse or a serial mouse, as well as the make and model)

Again, your system's documentation should tell you this information, and often the bottom of the mouse has some basic information.

A PS/2 mouse usually has a round connector on the end of its wire, or tail. A serial mouse has an oblong connector with nine holes. All varieties of PS/2 bus mice like the one to Linux. Different serial mice, however, have different characteristics. If you have a serial mouse, you have to know its model number and manufacturer, or whether it emulates some other-known mouse.

Three-button mouse are best with Linux, but you can get by with a two-button mouse. Three-button mouse is very useful for cutting and pasting. If you are using a two-button mouse, you can configure your Linux system to "emulate" three buttons. You can create the effect of the third, or middle, by pressing the left and right buttons simultaneously. You can find out how to configure mouse for your X window in the section of this chapter titled "Configuration Conflagration." Please note that the increasingly pervasive "wheel mouse" (the ones with the wheel between the two buttons) can function as a three-button mouse. You can configure the wheel to function, but doing so is beyond the scope of this book.

Finally, you need to know about your monitor. Most monitor manuals have a label at the back with such information as:

- Horizontal sync range
- Vertical sync range
- Resolution
- Whether it is multisync, which means that your monitor can run at several resolution rates

To run SuperProbe, follow these steps:

1. Log in as root.
2. Execute the SuperProbe program.
To do so, type the following:
SuperProbe

A lot of information spews from the program, followed by a rather frightening message:
WARNING - THIS SOFTWARE COULD HANG YOUR MACHINE.
READ THE SuperProbe MANUAL PAGE BEFORE RUNNING THIS PROGRAM.
INTERRUPT WITHIN FIVE SECONDS TO ABORT!

![](img/96a9ce6a13d8d15ed05f867f41574278_130_3.png)

Although SuperProbe can hang your machine, most of the time it doesn't. And if it does, simply press the reset button on your machine or turn the power off and then reboot.

If SuperProbe does its job and does not hang your machine, it may come back with information like the following:

```
First video: Super-VGA
Chipset: S3 86C28PCI (PCI Probed)
Memory: 2048 Kbytes
RAMDAC: AT&T 20C491 15/16/24-bit DAC with gamma correction
(with 6-bit wide lookup tables (or in 6-bit bit mode))
(programmable for 6/8-bit wide lookup tables)
```

Awesome. This tells you that your board is made of an S3 chip set (a lot of them are), is model number 86C28, and fits into the PCI bus. It has 2048(MB) of video memory and uses a RAMDAC made by AT&T. This last piece of information is not useful when used with the rest of the configuration programs, but write it down anyway. As you use it, be aware that sometimes the chips are known by nicknames. For example, the S3 86C28 may show up in the configuration programs as S3-928.
