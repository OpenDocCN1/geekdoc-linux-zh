# Chapter 5: Installation: Down to the Final Stretch

In the first screen, which is shown in Figure 5-1, you see an information screen with the addresses and telephone numbers of SuSE offices in Oakland and Nuremberg. At the bottom of this screen you will see a boot prompt. After a few seconds, Linuxrc will start to load the Linux kernel into memory.

Linuxrc? What aboutYaST? Before you start YaST, you use Linuxrc to set some basic hardware parameters and specify which installation medium to use for installingSE Linux. After a few seconds, a series of messages scrolls by, indicating the hardware is being detected by the Linux kernel. If the hardware is not being detected, you may have to reboot and add some options at the boot prompt. For example, if the system doesn't detect your CD-ROM drive, and if it is an IDE CD-ROM, which is a master on the secondary IDE chain, you might have to eject the following:

Boot: Linux hdc=cdrom

Most of the time — particularly with newer systems — Linux detects all basic hardware. (Additional boot prompt options are given in Appendix A.) Then a welcome message displays and the installation program begins.

If you want to stop the installation process now, simply eject the boot disk, remove the CD from the drive, and reboot your machine.

Navigating the dialog boxes in Linuxrc is easy. Use the up and down-arrow keys to move up and down the list of options. Use the left- and right-arrow keys to choose between the buttons at the bottom of the screen. Pressing the Enter key selects the currently highlighted option.
