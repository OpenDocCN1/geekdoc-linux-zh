2. In the list, make sure that all items are expanded, as shown in Figure 3-3.

Expanded simply means that a minus sign precedes the icon. If a plus sign is there instead, click it; it changes to a minus sign. As you expand entries, you may see more plus signs. Click each sign, expanding the list. You may need to use the scroll bar to the right of the window to bring additional items into view.

3. Look through the list for Standard IDE/ESDI Hard Disk Controller or SCSI Hot Adapter.

Write down the complete label, which tells you what type of disk controller you are currently investigating.

4. Look at the first subentry under that hard disk controller, if any, and write down the type of disk; then, double-click that disk entry.

The General tab of the Properties dialog box for that device appears.
If the controller has no entries, don't despair. Some systems have extra hard disk controllers (particularly if you are using SCSI disks) that are not connected to any disks. Also be aware that the first controller may have some other type of device connected to it, such as a tape drive or a CD-ROM. If no disks are attached to this controller, just go on to the next controller.
