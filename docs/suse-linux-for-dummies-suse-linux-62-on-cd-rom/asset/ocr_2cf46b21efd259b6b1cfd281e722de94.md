# Chapter 10: Avoiding Shell Shock

The original bash shell is called the parent, and the two new environments bash created are called children, or child 1 and child 2.

Putting the standard output of one command into the standard input of the other, as was demonstrated with the command

```
ls -1 * | more
```

is called piping. The | symbol is called — you guessed it — the pipe symbol.

# History, herstory

One of the most useful features of bash is command-line editing, which is the capability to change parts of a command line without having to retype the entire command. Suppose that you typed the following:

```
username@hostname:~ > ls -1 * | more
```

Your mind was wondering because you meant to use the less command, not the more command, but you pressed Enter anyway.

You groan. You press Ctrl-C to halt the command. You would really like to reexecute the command, changing more to less, without having to type the entire command. Easy. Just do the following:

```
username@hostname:~ > more^less
```

This line resubmits the command to bash with the more changed to less, as follows:

```
ls -1 * | less
```

Output appears. If you have to stop the less command, press Q.

Note that the shell redisplays the first command with the change and then the command is reexecuted. How does the shell know about the first command? History. bash remembers all the commands you have typed (to a certain extent), and allows you to edit and submit them. Awesome.

We say “to a certain extent” because bash remembers only a certain number of commands, depending on a parameter in the environment. After bash holds that many previous commands, it throws away the oldest ones as you type in newer ones. Normally, this parameter is large (perhaps 1,000 commands), so bash will probably remember everything that you remember.
