# Commercial text editors

Several commercial text editors are available. Some have significant added value compared to simple text editors. In this section, we describe two of the most popular commercial text editors.

Visual Slick Edit by MicroEdge is an X11-based editor that runs also on Windows 3.1, 95, 98, and NT platforms. The editor is language-sensitive, so if you're programming in C, C++, Java, HTML, Perl, AWK, Pascal, FORTRAN, BASIC, dBASE, Modula-2, COBOL, or several other languages, Visual Slick Edit knows about these languages and tries to help make the text readable and searchable. Visual Slick Edit emulates several other editors (such as vi, emacs, and Brief) and integrates with other programs that help keep track of your program's code. Visual Slick Edit is definitely a programmer's editor but can be used by programmers.

Crisp by Vital is another language-sensitive, cross-platform editor. Cross-platform editors can run on many different UNIX and Linux systems as well as on Windows 3.1, 95, 98, and NT.
