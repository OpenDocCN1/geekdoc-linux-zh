6. In the Description field on the bottom, fill in information about your-self, because the user who you is being added.

Most of this information is self-explanatory. Here are a few hints:

+   - Make the username short (no more than eight characters) and all lowercase.

+   - To make a password difficult to guess, use a long password in a combination of uppercase, lowercase, and special characters. Don't use common words, nicknames, or other words that people can guess.

+   - Among your many choices for a default shell, /bin/bash is a good choice. For more shells, read Chapter 10.

+   - You will assigned two numbers called UID and GID. These help the system determine who you are. Use the ones that the program offers unless you have a reason for changing them.

7. When the information is complete, press F4 to add the new user account.

The user account has been created. To exit this dialog box, press F10.
