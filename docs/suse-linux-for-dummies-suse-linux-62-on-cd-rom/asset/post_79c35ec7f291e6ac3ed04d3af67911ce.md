# Bye, Window

Now that you've put a lot of windows on the screen, how can you get rid of a few or all of them? Well, you can put them in the background by reducing them to icons, or you can be more drastic and kill them. Here are a few ways to do:

- First, take advantage of any exit buttons or menu options that the application gives you. Close each and every application using X Window System.
- Click the hyphen symbol in the upper-left corner of the window you want to make go away, and then click Close. That window disappears, and the program that was outputting or receiving input through that window terminates.

```
✔ Click the Close button (the X), which is in the upper-right corner of the window's title bar, to kill the window.
✔ Reduce the window to an icon by clicking the Minimize button (the underline), which is in the upper-right corner of the title bar. The minimized program is still running; you can make it larger (maximize it) by clicking the window's icon at the bottom of the screen.
```

When all else fails, stopping X Window System kills all the programs using it. Before stopping X Window System, remember to check your other virtual desktops for programs that are still running, so you don't have any unpleasant surprises.

# Stopping X Window System

If X Window System is working and you want to stop it, you have a couple of options: You can click the K button and select Logout or you can press Ctrl+Alt+Backspace. You can then log out of the account. If you want to start X Window System working again, just log in to an account and type startx.
