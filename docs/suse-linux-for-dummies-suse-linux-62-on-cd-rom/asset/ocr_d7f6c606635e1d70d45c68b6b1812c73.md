You have removed the extra file from the current directory. To remove a file from another directory, you provide a relative filename or absolute filename. For example, if you want to expunge moody from the work directory, you type the following:

```
rm ../moody
```

![](bbox=[0.095, 0.255, 0.185, 0.335])

You are allowed to use wildcards with rm, but please be careful if you do so! When files are removed in Linux, they are gone forever, kaput, vanished, and can't be recovered.

The following command removes everything in the current directory and all directories under that you have permission to remove:

```
daddog@shamet:~ rm -r *
```

![](bbox=[0.095, 0.435, 0.185, 0.515])

To lessen the danger of removing a lot of files inadvertently when using wildcards, be sure to use the -i option with the rm, cp, mv, and various other commands. The -i option means interactive, and lists each filename to be removed (with the rm command) or overwritten (with the mv or cp command). If you answer either y or N, the file is removed or overwritten. If you answer anything else, the file is left alone.

# Removing directories

You can remove not only files but also directories. If you are still following along with the story about the handsome prince and his princess, you now have two directories in your home directory that are taking up a small amount of space. Because you are finished with them, you can delete them and recover that space for other tasks.

First, return to your home directory:

```
daddog@shamet:~ > cd
```

Now remove the santa_cruz directory:

```
daddog@shamet:~ rm -rf santa_cruz
```

This action removes the santa_cruz directory and all files and directories under it. Note that this is the rm command with options for recursively and forcefully. (Recursively means to keep going down in the directory structure and remove files and directories as you find them. Forcefully means the file should be removed if at all possible; ignore cases in which rm might prompt the user for further information).
