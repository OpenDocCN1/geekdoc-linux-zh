Mozilla (hereafter called Netscape) has three main screens:

+   - Navigator screen, shown in Figure 16-1
- Mail and Discussions screen
- News screen

The first thing to do is tailor Netscape to your preferences. You can do this offline, which is certainly preferable if you have only one phone line. Follow these steps:

+   1. Choose EditPreferences.

The Preferences window appears, as shown in Figure 16-2.
Note that on the left side of the Preferences window is a map of the preference options that you can choose from, called the Category window. You skipped over the Appearance window (it's self-explanatory) and are now concentrating on the Navigator window. This is where you determine what you see as the initial window when you start Netscape. Most people either select a home page or the last page they viewed.
