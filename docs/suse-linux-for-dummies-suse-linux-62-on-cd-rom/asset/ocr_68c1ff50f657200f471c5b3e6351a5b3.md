# 84 Part II: Installing SuSE Linux

Brief descriptions of the different menu options follow.

The first menu option is Load Configuration. A configuration is nothing more than a list of packages. In your case, it is not necessary to load any configuration, because the default configuration has already been loaded. This menu option is useful if you are interested in selecting something other than the default configuration; for example, the Almost Everything or Minimal System configurations are available. The Load Configuration option is also useful if you have created a custom configuration (list of packages) and want to install the exact same list of packages on another computer. Curious readers should check out the contents of the Load Configuration submenu.

The second menu option is Save Configuration. As the title suggests, you can use this option to save a custom configuration that you have created. In practice, it is used only if you need to install that custom configuration onto many systems. We don't go into detail on this option in the book.

The third menu option is Change/Create Configuration. You use this option to select or deselect packages to be installed on your system. The Series selection appears (see Figure 5-19). We can already hear you asking, "What is a series?" All packages on the SuSE Linux for Dummies (as well as the SuSE Linux distribution) are grouped into a series according to their use. The series are named accordingly. For example, the first series on the list is Base System, which contains packages that are required as part of the core of SuSE Linux. Likewise, the appropriately titled Documentation contains those that hold documentation (files, managers, and so on).
