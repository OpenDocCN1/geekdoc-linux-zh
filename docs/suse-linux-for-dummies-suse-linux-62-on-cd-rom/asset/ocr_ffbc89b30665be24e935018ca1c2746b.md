# Chapter 16: Surfing the Web

# Surfing with the proper footing

Before you start to surf the Web, you need the proper footing. To get to a page of information on the Internet, you type or click a URL (Uniform Resource Locator). After you have even one URL going from there to other places on the Web is usually easy. URLs look like this:

```
http://www.li.org/
www.li.org/
```

+   The URL is old and the page to which it is pointing no longer exists.

+   The server system that the page is on operative. You might see the message The server_is down.

+   The server system is up but under too much of a load with everyone trying to get to that page. This happens, when the Sports Illustrated puts up the swimsuit issue.

+   Your network connection went down, either from you to your ISP or from your ISP to the Web site.

Some browsers let you omit the trailing slash, unless the final segment is a filename.

# Ready, Set, Go!

Now that you have your browser configured properly, you can connect to the Internet by typing the following in a terminal emulator window:

```
wvdial
```

You have to wait a few seconds (or even a minute) to connect with your ISP (hearing your modem dial is reassuring). Try ping gatekeeper.dec.com to make sure that you are connected:

```
ping gatekeeper.dec.com
```

Now type the following:

```
netscape http://www.li.org&
```

Netscape starts and uses as its first URL the one you just supplied (http://www.li.org). The screen that appears is similar to the one shown in Figure 16-7.
