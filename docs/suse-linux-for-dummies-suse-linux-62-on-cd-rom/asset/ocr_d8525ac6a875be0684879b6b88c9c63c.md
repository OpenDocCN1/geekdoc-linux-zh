# Chapter 3: Discovering What's in Your System

Linux can be installed in 80MB of disk space, but for the graphical part of Linux, you need a total of about 300MB. If you install the default system with all the goodies, you will have installed a total of more than 650MB of computer programs, data, games, and so on. When considering whether your system needs more disk space or more RAM, remember that as a general rule, it is usually better.

Some early CD-ROM drives are not IDE; they attach directly to sound cards and other devices. Most Linux distributions tell you how to detect and use these. If you don't have an IDE/ATAPI or SCSI CD-ROM drive, you need to know the make and model number of your CD-ROM drive and what type of controller (perhaps a specific sound card) the CD-ROM drive is attached to. To do this, you have to open your system and look for the make and model number of the CD-ROM on the physical device.

You can install Linux, after making one or two disks, by copying files over the network. This is a viable way of installing Linux on the type of local area network used at colleges or businesses or you have a friend who has a Linux system, a CD-ROM drive, and a networking card of the same type as yours. If the network is not fast (that is, cannot pull lots of data quickly), however, the easiest way to install Linux is by using a CD-ROM drive attached to your system. Trust me.

You can install Linux on a notebook by using the notebook's built-in CD-ROM drive (if it has one), or a CD-ROM drive attached to the notebook's docking station, or a SCSI CD-ROM drive attached to a PCMCIA controller. If you don't have any of these, you could try to get a PCMCIA controller and do a network installation, given that another Linux system on the network has a CD-ROM drive.

You also need a keyboard, a mouse, and a video card. Linux supports a wide range of video cards. Even if your card is not supported directly, Linux might support it as a standard VGA, XGA, SVGA (or other graphical hardware standard) video card. Most video cards that have been available for a while are supported.

# Notebooks before PCMCIA support

Early notebooks had no built-in CD-ROMs, and until Linux had PCMCIA support, I had to install Linux using floppies. I still remember the day I got my new notebook and the new release of Linux that had PCMCIA support. I ran out and bought a PCMCIA SCSI controller that night so

that I could use my SCSI CD-ROM to do the installation.

My life has been ever since. Having used floppies to install Linux on various notebooks not once or twice, seven times, I would have paid ten times the amount for what PCMCIA card.
