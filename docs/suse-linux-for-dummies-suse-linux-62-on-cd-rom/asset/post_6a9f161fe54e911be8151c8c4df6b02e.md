### Network Configuration

The next dialog box asks whether you plan to use your system on a real network or not. If you use a modem to connect to the Internet, select Loopback Only. If you have a network card in your system, select Real Network.

If you select Loopback Only, you are told that your network configurations are complete and that they will become active after the next reboot. You can skip the rest of this section.

If you select Real Network, then the next screen asks whether you want to use your machine as a DHCP client. If you are not sure, select No. If your computer is on a network, you might want to ask the network administrator. The following screen is for configuring the IP address of your machine (see Figure 5-30). Again, if you are unsure, you should ask your network administrator. If this system is a home machine and you are just testing to configure networking, the default settings should work fine.
