
## Chapter 16
## Surfing the Web

**In This Chapter**

- Tailoring Netscape to suit it
- Checking out Web pages
- Getting and reading e-mail
- Sending your first e-mail message

Once upon a time there was a company called Netscape that created a browser called Mozilla. Despite the fact that the company spelled the name "Netscape," you were supposed to pronounce it "Mozilla." In any case, the browser was one of the best in the world (if not the best), and the folks at Netscape made it better by turning it over to the Open Source community to help them improve it.

Over time, Mozilla not only could surf the Web but also read e-mail, gather files using the File Transfer Protocol (FTP), run simple programs using Java, and even read Netnews (a discussion group made up of thousands of categories over the Net), all through a single graphical interface.

In this chapter, you set up Netscape for your system. Then, with the information from your ISP, you finally surf the Web and receive e-mail.

## Customizing Netscape

Your SuSE Linux for Dummies CD-ROM has a copy of Mozilla, which you can activate by typing the following from a terminal emulator window X Window System is running:

```bash
netscape&
```

The first thing to do is tailor Netscape to your preferences. You can do this offline, which is certainly preferable if you have only one phone line. Follow these steps:

1. Choose EditPreferences.

The Preferences window appears, as shown in Figure 16-2.
Note that on the left side of the Preferences window is a map of the preference options that you can choose from, called the Category window. You skipped over the Appearance window (it's self-explanatory) and are now concentrating on the Navigator window. This is where you determine what you see as the initial window when you start Netscape. Most people either select a home page or the last page they viewed.

![](img/96a9ce6a13d8d15ed05f867f41574278_290_0.png)

Figure 16-2:
The first major Preferences window for Netscape.

2. In the Home Page area of the Navigator window, fill in the Location field.

Make sure that you fill in the home page location so that you can get back to it easily when you click the Home Page icon at the top of the Navigator screen. If you don't have a preference for a home page yet, you can type the one shown in the figure.

3. If you want, select a History number.

Netscape remembers where you have been and lets you select (and go to) a previous location. How long Netscape remembers (and how big the list becomes) depends on many days of history you choose.

4. In the Category window, click Mail & Groups and then click Identity. Fill in any necessary information.

The window shown in Figure 16-3 is where you add your e-mail address, return address, and organization name, and specify your signature file (the file that holds additional information included at the end of each e-mail message as a signature).

![](img/96a9ce6a13d8d15ed05f867f41574278_291_0.png)

Figure 16-3:
The Identity window in all its glory.

5. Under Mail & Groups, click Mail Servers. Fill in any necessary information.

The window in Figure 16-4 appears. Because you will probably be attached to the Internet for relatively short periods of time, your Internet service provider will supply you with machines which send and deliver your e-mail when you are not attached to the Internet. Then when you do attach to the Internet, your computer tells the server to deliver the e-mail or send your messages. You will be given a login name for the mail server (usually the same as your incoming login name), and you will be told the name is for both your incoming and outgoing mail server. These two names are usually the same, but if you are using a special mail service called POP (Post Office Protocol), which allows you to download e-mail to your system from the server, your ISP will give you a name for the POP server. IMAP4 is an even newer protocol for doing procedures similar to POP, and if your ISP has an IMAP4 server, they will tell you that also. In this screen, you can configure your outgoing mail server and your outgoing mail server username. To configure your incoming mail server, read Step 6 that follows.

6. Under Mail Server, click the default mail server and then click the Edit button. Fill in any necessary information.

The window in Figure 16-5 appears. In this window, you can edit the incoming mail server information. You should add the name of the mail server as well as your username. You do not have to add your password here. You will be prompted for your password each time you connect to the mail server to get your mail.

7. Under Mail & Groups, click News News Group Server. If you want to participate in a news server, fill in the fields.

Netscape enables you to read Netnews, which is a series of discussion groups that have been active for many years. They were one of the first users of the Internet and have been disseminating information (and misinformation) for many years. To participate in a news server, you should fill in the name of your news server (provided by your ISP), as well as the working area where your messages will be downloaded for you to read. Message groups can be quite active, so you should fill in the last option in the window, which specifies how many messages you want to receive before being asked. These fields are shown in Figure 16-6.

8. At this point, you are all set to run Netscape and see the world, click OK and go, go, go!

## Surfing with the proper footing

Before you start to surf the Web, you need the proper footing. To get to a page of information on the Internet, you type or click a URL (Uniform Resource Locator). After you have even one URL going from there to other places on the Web is usually easy. URLs look like this:

```
http://www.li.org/
www.li.org/
```

- The URL is old and the page to which it is pointing no longer exists.
- The server system that the page is on operative. You might see the message The server is down.
- The server system is up but under too much of a load with everyone trying to get to that page. This happens, when Sports Illustrated puts up the swimsuit issue.
- Your network connection went down, either from you to your ISP or from your ISP to the Web.Some browsers let you omit the trailing slash, unless the final segment is a filename.

URLs are underlined on Web pages. The underline is the key that the text is a link, which means you can simply click the underlined text and go to that location. If you aren't taken to that location, one of the following is usually the culprit:When surfing the Net, be patient. Even on the best days, downloading pages can take several minutes.

## Ready, Set, Go!

Now that you have your browser configured properly, you can connect to the Internet by typing the following in a terminal emulator:

```bash
wvdial
```

You have to wait a few seconds (or even a minute) to connect with your ISP (hearing your modem dial is reassuring). Try ping gatekeeper.dec.com to make sure you are connected:

```bash
ping gatekeeper.dec.com
```

Now type the following:

```bash
netscape http://www.li.org&
```

Netscape starts and uses as its first URL the one you just supplied (http://www.li.org). The screen that appears is similar to the one shown in Figure 16-7.
