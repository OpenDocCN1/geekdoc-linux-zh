+   Remember Linux is only a piece of code and your computer is only a machine.

So what if you make a mistake? You're probably running Linux on a machine that has only one user, you. That's the great thing about Linux. It runs on such inexpensive machinery that you can buy an old 486 computer with enough disk and memory in it to run Linux as a practice system for under $50.(We bought a machine at Ham Fest. It runs Linux very nicely.) So even if you have to reinstall your system due to some mistake you made, You now know how to install Linux, so no one has to know but when something goes wrong.

So, give it a try!

Our other suggestion is to help someone else. "What?" you say. "How can I help someone else? I'm just a beginner in this field!

We started that way. No one is born with a knowledge of computer science (except perhaps Sean Flynn, a former student). We all pick it over time. The way to cement a thought or an idea, however, is to explain it clearly to someone else. Helping others install Linux on their PC will help cement some of the concepts you've discovered. Another idea is to attend a Linux Install Fest, where lots of people go (with their machines) to install Linux. Here you not only get to help someone else but also can learn something from other attendees.

A main tenet of Linux is the word open. Linux is open and is best when shared.
