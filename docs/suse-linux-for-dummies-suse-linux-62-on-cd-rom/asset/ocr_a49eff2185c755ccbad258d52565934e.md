# What You'll Find

The CD contains the freely distributable parts of SuSE Linux Version 6.2. You may view a lot of documentation on this CD through an HTML viewer such as Netscape, which is also on the CD, or you may print it. Most of this documentation also may be viewed from other operating systems such as DOS, Windows, or UNIX.

We recommend that you look at the "The SuSE Linux Installation Guide," which is in the following directory:

```
[Your CD-ROM drive number]:\docu\book-en.txt
```

Because the CD-ROM has a full implementation of Linux, it would take too much room to list all the accompanying tools and utilities. Briefly, the CD includes most of the software you need to do the following: access the Internet; write programs in several computer languages; create and manipulate images; create, manipulate, and play back sounds (if you have a sound board); and play games.

# If You Have Problems (Of the CD Kind)

We tried our best to test various computers with the minimum system requirements. Alas, your computer may differ, and Linux may not install or work as stated.

The two likeliest problems are that you don't have enough RAM for the programs you want to use, or you have some hardware that Linux doesn't support. Luckily, the latter problem occurs less each day as more hardware is supported under Linux. (Check out Appendix A for a list of compatible hardware.)

You might also have trouble with SCSI disks that use a controller not supported by Linux or a controller that is simply too new for the Linux development team to have given it the proper support at the time the CD was pressed.

If you have trouble with corrupt files on the CD, please call the IDG Books Worldwide Customer Service number: 800-762-2974 (outside the United States: 317-596-5430). Customer service won't be able to help with complications relating to the program or how it works. Please see the Installation Instructions at the end of this book.
