
## Chapter 10: Avoiding Shell Shock

You should use a text editor to create a file called passdiff in your ~/bin directory, putting the following lines in it:

```
# Shell comments start with a pound sign (#) on a line.
# Anything following a # is ignored by the shell and is
# used only by humans to understand what is going on
# in the script. Use comments liberally.
#
# if the number of arguments is not equal to 2
if [ $# != 2 ];
then
  # echo a usage message
  echo Usage: passdiff file1 file2
  # and exit with an error code of 9
  exit 9
fi
# if the first argument is not a file
if [ ! -f $1 ];
then
  # echo message that the first argument is not a file
  echo $1 is not a file
  # and exit with an error code of 9
  exit 9
fi
# test the second argument the same way
if [ ! -f $2 ];
then
  echo $2 is not a file
  exit 9
fi
# Now use the cut and set statements, which we used
# before to create the login-name/description. But this
# time; store the contents in files called
# /usr/tmp/quagmire.2 matches any digit
# and the $ assigns process number of the shell to
# create a unique filename. Two files with
# filenames will be generated temporarily in
# /usr/tmp:quagmire.1.<processnumber>
# quagmire.2.<processnumber>

# There is a difference in Linux (as in most programming
# systems) between a single quote (that symbol below the
# double quote on a U.S. keyboard) and accent grave'\n
# symbol below the tilde (the squiggle thing) on a
# U.S. keyboard. In the following lines, the ' symbol is
# a single quote, which turns off the shell's regular
# expression matching and allows the command to see
# the regular expression (if any)
cut -f 1.5 -d $1 sed -e 's/:;;/\g' /usr/tmp/quagmire.1.\$
cut -f 1.5 -d $2 sed -e 's/:;;/\g' /usr/tmp/quagmire.2$$
```

## Multitasking

When multitasking in Linux, you are able to run multiple programs at the same time. This is very useful when you want to have one program running while you wait for another to finish. For example, you can have a web browser open while you are typing in a document.

To run a program in the background in Linux, you can use the \& symbol at the end of the command:

```bash
command &
```

This will run the program in the background, and you can continue to use the terminal. To see the programs running in the background, you can use the `jobs` command:

```bash
jobs
```

To stop a background program, you can use the `kill` command:

```bash
kill pid
```
