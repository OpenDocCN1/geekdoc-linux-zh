
# Linux 入侵检测速查表

## 异常账户

检查 `/etc/passwd` 以查找新账户，特别是具有 UID 0 或 GID 0 的账户。

```
less /etc/passwd
grep :0 /etc/passwd
```

正常账户会出现在那里，但请寻找新的、异常的账户。

## 异常日志条目

检查系统日志文件以查找可疑事件，包括：

- 混杂模式："entered promiscuous mode"
- 来自本地或远程访问工具（例如 `telnet`、`sshd` 等）的大量身份验证或登录失败。
- 远程过程调用 (rpc) 程序的日志条目包含大量（> 20 个）奇怪字符 (-^PM-^PM-^PM-^PM-^PM-^^PM-)
- 对于 Web 服务器：大量显示为 "error" 的 Apache 日志

## 异常进程

查找正在运行的进程：

```
ps -aux
```

熟悉该机器的“正常”进程。

查找异常进程。关注具有 root (UID 0) 权限的进程。

如果你发现了一个不熟悉的进程，请调查异常进程，并使用以下命令获取更多详细信息：

```
lsof -p [pid]
```

此命令显示运行进程所使用的所有文件和端口。

## 异常文件

查找异常的 SUID root 文件：

```
find -uid 0 -perm -4000 -print
```

需要具备正常 SUID 文件的知识。

查找异常的大文件（大于 10 MegaBytes）：

```
find -size 10000k -print
```

需要具备正常大文件的知识。

查找以冒号和空格命名的文件：

"* . . . " 和 ""

```
find -name "*.**"
find -name "*..*"
find -name "* .*"
```

## 异常文件（继续）

在安装了 RPM（RedHat、Mandrake 等）的 Linux 机器上，运行 RPM 工具验证这些情况。

```
rpm -Va
```

通过 RPM 数据库中的信息检查每个文件的大小、MD5 和、权限、类型、所有者和组。

输出包括：

| 标记 | 说明 |
| :--- | :--- |
| S | 大小差异 |
| M | 模式差异（权限） |
| M | MD5 和差异 |
| D | 设备号不匹配 |
| L | readLink 路径不匹配 |
| U | 用户所有权差异 |
| G | 组所有权差异 |
| T | 修改时间差异 |

特别关注与 `/sbin`、`/bin`、`/usr/sbin` 和 `/usr/bin` 项目相关的更改。

查找混杂模式，这可能表明存在嗅探器：

```
ip link | grep PROMISC
```

注意，在 Linux 内核 2.4 上，`ifconfig` 无法可靠地检测混杂模式。

## 异常网络使用

查找异常的端口监听器：

```
lsof -i
netstat -nap
```

需要了解系统上正常监听的 TCP 和 UDP 端口，并寻找偏离正常的情况。

查找 ARP 条目，即将 IP 地址映射到错误的局域网 MAC 地址：

```
arp -a
```

需要对局域网内应存在的内容有详细了解。

## 异常计划任务

查找由 root 或任何其他 UID 0 账户调度的 cron 任务：

```
crontab -u root -l
```

查找异常的系统级 cron 任务：

```
cat /etc/crontab
ls /etc/cron.*
```
