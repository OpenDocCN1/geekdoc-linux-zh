# 第一章：基础背景、历史与 C++ 的成果

在我们开始学习如何使用 `C++` 之前，你必须了解它是什么以及它是如何产生的。原因很简单：要真正了解某事，你必须了解关于该主题可能学到的一切，特别是当涉及到计算机编程这样技术性很领域时。

`C++` 是计算机和互联网历史上非常重要的一部分。它简单地交织在我们今天所知的科技世界历史之中。此外，如果没有 `C++`，智能手机上的应用和其他功能将不复存在。

当你学习 `C++` 时，你会对一种编程语言竟然对我们的日常生活产生如此巨大的影响感到惊奇。几乎每一台制造过的计算机都可以归功于 `C++` 语言的特定方面。学习这种语言的好处之一是能够轻松学习其他语言。拥有学习 `C++` 的能力将增强你对其他编程语言的理解，这就是为什么许多人 ways“教父”。

## C++ 的历史

`Bjarne Stroustrup` 在写他的论文时，他决定使用 `Simula`。这种语言是最早面向对象的语言之一。然而它运行非常慢。`Stroustrup` 想要创建一个既具有面向对象编程特性又具有 `C` 速度的语言。于是他提出了 `C++`，它最初被称为“带类的 `C`”。1983 年，该语言被重命名为 `C++`。

## 什么是 C++

`C++` 不仅仅是任何编程语言，它是面向对象的。面向对象编程（简称 `OOP`）是围绕对象而非动作的编程。它就像是一次性观察整个画面，而不是每一块拼图碎片。

这种编程语言的设计考虑了灵活性和速度，因为当时的其他语言太慢了，而且只能做一件事。所以，每当你想要创建新东西时，都需要 `C++`。你可以用这种语言做很多事情，尽管现在有数不胜目的语言，但它们仍然非常流行。

- 预制脚本：这些是脚本爱好者和新黑客用来练习编程技术的内容。由于现在许多人想走捷径，预先准备好的脚本是大多数黑客正在寻找的，因此这些包需要改进，而他们使用 `C++` 实现了这一点。
- 视频游戏：面对现实吧，每个人在人生的某个时候都玩过视频游戏。无论是长大还是有了孩子，你都会陷入视频游戏的世界，并且永远无法逃脱。那些游戏可以在某种程度上归功于 `C++` 语言的使用。如果你热衷于制作游戏，并通过图形为世界带来快乐，那么学习 `C++` 语言绝对是一个好主意。
- 网页：许多网页是使用 `C++` 制作的。其原因是这种语言非常易于操作，它可以快速方便地创建一个为人们提供许多交互功能的网站。你可能经常访问的由 `C++` 创建的网站包括 `Amazon` 和 `Ebay`。
- 手机应用：现在似乎每个人都有智能手机，这意味着应用随处可见。那里有成千上万的应用，每天都在产生。有些应用是免费的，有些需要付费，但一个好的

这些是使用 `C++` 编写的。这是因为这种语言具有极强的扩展性，既可以用于简单的游戏，也可以用于复杂的购物应用程序。

`C++` 还被用于许多其他细微领域，例如 `VoIP` 通话。它是使用 `C++` 创建的。事实是，你会一次又一次地听到 `C++` 是一门死掉的语言，但实际上，这只是 `JAVA` 人为了恐吓人们切换语言而使用的诡计，以确保 `C++` 成为门死掉的语言。

### 为什么使用它

使用 `C++` 不仅是因为它的灵活性和速度，因为它包含许多组件，相对容易学习，而且如果你精通 `C++`，就可以轻松地掌握其他语言。原因在于，当你先学习一些比其他东西稍微复杂一点的内容时，较简单的内容就会迎刃而解；然而，如果你习惯了容易学习的科目，那么你会发现更困难的内容很难学习，因为你不习惯在正尝试学习的科目上投入那么多精力。

如果你想学习一种可以在计算机技术领域用于不同类型函数的语言，那么这种语言就适合你。你可以用它做几乎任何事情，一旦你对它有了足够的了解，你可能找到操纵这种语言来完成它通常无法做的事情的方法。

`C++` 是计算机编程领域一种非常重要的语言，尽管由于其布局方式有很多变量，但它非常易读，也非常容易创建。这使其成为世界上最受青的编程语言之一，因为没有人想挣扎于阅读代码。没有人想把所有时间花在那些他们知道是正确的事情上，仅仅因为他们找不到哪里出错了。

由于其多功能性，`C++` 应该是你首选的主语言。也许 `JAVA` 或 `Linux` 是你的其他语言，但 `C++` 是最好的主语言，而你只想把最好的作为主语言。

`C++` 是一门静态编写的低级语言，这意味着它是一门简洁且扩展的语言。

`C++` 是 `C` 的功能完备超集，支持面向对象编程。这意味着它支持 `OOP` 的所有支柱，如封装、数据隐藏、继承和多态。

### C++ 的三个重要组件

标准 `C++` 由三个非常重要的概念组成。

- 核心语言（`Core Language`）：这由语言的所有变量、数据类型、字面量和语言的其他重要方面组成，创建了通往下一阶段的基石。
- `C++` 标准库（`C++ Standard Library`）：这允许你操作文件以及语言内部的其他工作，并按照你的意愿支配它们。
- `STL`：代表标准模板库（`Standard Template Library`），它为你提供了操作数据结构、变量及类似内容的函数。

在使用 `C++` 语言时，你将享受到许多优点。其中一些优点包括：

- 大库：由于 `C++` 已经存在很长时间，他们有一个非常庞大的库。这供你使用，你可以在脚本中选择你需要的代码并节省时间甚至学习一些新知识。如果你愿意，也可以创建一些自己的代码，但这个库对于正在学习的初学者非常有帮助，可以让代码编写变得比以往任何时候都容易。

- 提供强大的功能：那些喜欢编程并希望在他们的工作中拥有强大功能的人会发现 `C++` 是他们选择的正确选项。它拥有世界上编程语言中最强大的功能。

## 第二章：让我们开始

让我们开始吧！我们有很多地方可以着手，但让我们先谈谈环境。虽然你并不真的需要搭建自己的环境，因为有很多在线环境。环境就是你选择的编译器，它接收你的代码并为你完成所有功能。在过去，你必须打开命令提示符并创建一个环境来使用，但那种日子已经结束了。以前一个小错误就可能对他们的电脑造成严重损害。现在你可以练习一些风险性命令，而不会对你的设备产生任何风险。

互联网上有许多可以尝试和使用的示例。要尝试它们，最简单的地方是访问 `http://www.compileonline.com`。选择底部的“`Learn C++`”选项，它将带你去需要的地方。

#include <iostream>

现在，你可以选择直接将这些代码输入到编译器中，或者编写几段代码并保存到计算机中，随时访问，这样你每次想修改它们时就不需要重新输入了。你可以使用几种不同类型的文本编辑器。然而，其中一些是特定设备类型的。这意味着它们只在创建它们的设备类型上运行。

在考虑移动编译器之前，你应该先在文本编辑器中编写程序的草稿。这是因为一旦你进入编译器，程序就就变得更容易出错且无法被发现。但是，如果你在文本编辑器中以整洁、利落的方式布局了程序，那么在编译器中运行起来应该就不会有问题了。

## C++ 编译器

世界上有很多不同的编译器，其中很多相当昂贵。那些编译器是为已经掌握了低级编译器的精英程序员准备的。初学者只需要基础编译器，大多数都是免费的。然而，就像任何免费的东西一样，你必须对你得到的东西小心。市面上糟糕的廉价编译器比好的多，因此在免费的幌子下，我建议在启动页之后支付额外的功能费用。这些额外功能通常很便宜，所以你不需要花费巨资就能获得它们。

最流行的编译器之一是 `GNU C/C++` 编译器。它最用于 `UNIX` 和 `Linux` 安装。要检查你是否已经有了该编译器，在你的 `UNIX/Linux` 应用中打开命令行并输入以下内容

```bash
$ g++ -v
```

如果安装了编译器，你应该会在屏幕上看到这条消息：

```
Using built-in specs.

Target: i386-redhat-linux

Configured with: ../configure -prefix=/usr ......

Thread model: posix

gcc version 4.1.2 20080704 (Red Hat 4.1.2-46)
```

如果屏幕上没有出现这条消息，说明编译器要么不在电脑上，要么是你安装错误了，你需要重新检查并正确安装。

在本书中，我们将介绍如何在 `Windows` 平台进行安装。如果你有不同的平台，应该去 `http://gcc.gnu.org/install/` 并阅读如何将其下载到你平台的说明。

要在你的 `Windows` 计算机上安装此编译器，你需要先安装 `MinGW`。这是让编译器与你的计算机兼容的软件，拥有这个软件非常重要，否则你甚至无法下载编译器。

要安装此软件，你可以访问软件的主页 `www.mingw.org` 并允许它引导你去需要的地方。一旦安装完成，你至少应该安装 `gcc core`、`gcc-g++`、`MinGW runtime` 和 `binutils`，但如果你愿意，也可以安装更多。安装完成后，你就可以从 `Windows` 命令行运行所有的 `GNU` 工具了。

现在你已经设置好了一切并可以运行，你可以开始学习更多关于如何运行程序本身的内容。

## 基础语法

`C++` 不仅可以定义为程序，还可以定义为通过调用其他方法进行集体通信的对象。当你使用 `C++` 时，你最要知道上述这四件事的含义。

- `类（Class）`：这是一个模板或蓝图，规定了对象及其支持类型，并描述了对象的行为。这意味着对象根据它们的行为和动作/支持被分类到符合问题对象描述的类中。
- `对象（Object）`：对象具有行为和状态。例如，如果你看一只狗，它有状态。这些状态可以被分类为颜色、品种、名称、品种标准（`AKC/AKA/APC` 注册表）。“狗”也表现出某些行为。它们摇尾巴、吠叫、喘气、吃干狗粮，并在院子外上厕所。这些特征构成了一个独特的对象。
- `方法（Method）`：这是行为的另一种术语。你可以选择任意数量的方法。它们 特别重要，因为没有了它们，你的程序就不知道自己应该做什么。
- `瞬时变量（Instant Variables）`：指每一个个体。这些变量在每次创建对象时都会分配给对象。

现在你已经知道了这四个主要定义，让我们来看一段将打印：“`Try This`”的代码。

```cpp
#include <iostream>

using namespace std;

// main() [这是程序开始的地方]

int main()

{

    cout << "Try This"; // [打印 Try This]

    return 0;

}
```

此函数将允许你打印任何你想打印的内容，而不只是 "Try This" 这几个单词。

现在让我们拆解一下上述程序的各个方面。这种语言有几个不同的方面需要你考虑。每个方面对于让它运行都非常重要，如果你不完全执行它们的话。

头文件（`Headers`）：`C++` 有许多头文件，它们都对你的编程操作是必需的，或者至少是有用的。然而，对于大多数函数，你都会看到 `<iostream>` 之上的头文件。当你使用头文件时，确保正确包含它，并在其前面加上 `#include` 以提示程序使用该头文件。

命名空间（`Namespaces`）：命名空间是 `C++` 中一个相当新的新增，仅在 2011 年的更新中出现。它们并没有太大作用，除了描述使用哪个命名空间。虽然它们不是必须的，但它们可以减少你很多函数方面的困惑。它只是作为一种更系统地组织你函数的方式。

`cout`- 此指令指示程序在屏幕上显示你想显示的消息。如果你不使用 `cout`，你的程序可能会失败，也可能不会失败。问题在于你不知道自己是否成功了，所以如果你想确保一切运行得顺畅，请务必添加 `cout`。

`Return`- 这会将值返回回 `0`，并终止函数。它指令程序结束进程并回到开头。

现在来编译并执行你的第一个个正式的 `C++` 程序了。

首先，你必须知道如何保存文件。打开你选择的文本编辑器，输入上方看到的代码。完成后，点击“另存为”，并选择一个容易找到的文件位置。为了方便组织管理，最好为你的所有程序准备一个单独的文件夹。将文件保存为 `hello.cpp`，一旦保存完成，在进入文件所在的目录之前，你应该先打开命令提示符。

要让文件在你的编译器中打开，首先输入 `g++ hello.cpp`。然后你可以按回车键，代码就会被正确打开。只要没有错误，提示符将生成一个 `a.out` 可执行文件。要运行该程序，输入 `./a.out` 并查看编译器的运行情况。从计算机的编译器中你应该获得的信息包括：

```
$ g++ hello.cpp
```

```
$ ./a.out
```

### 尝试一下

## 程序注释 (Program Comments)

所以，你会有这样的想法在代码中写一些注释。这些注释很重要，因为它们允许你在代码中留下一条小信息，以便以后阅读的人能够很好地查看代码是如何运行的，并对你试图实现的目标提供“参考”。此外，在代码行中留下笔记是提醒自己代码可能出错的好方法。通过在代码中放置注释，你正在更有可能知道你在哪里成功了，或者哪里出了错。

这些注释可以根据你的意愿变得简单，也可以复杂。如果只需要一两个单词就能帮助其他用户，有些人只会写这么多；但在其他情况下，你可能需要结合更多几行内容，以确保一切正常运行，并让其他人理解代码内部正在发生什么。

在这种语言中，你只需要使用 `//` 符号来表示你正在编写注释。你可以将其写得尽可能长，只需确保在注释结束时跳到下一行，这样程序就知道该重新开始读取了。

程序在遇到 `//` 之后就会停止读取，这不会影响程序的运行方式。其他查看代码的程序员会看到你编写的注释，但当程序执行时，这些注释会被跳过。你可以在程序中添加任意数量的注释，但尽量保持适度，因为过多的注释可能会阻塞代码，使其变得难以阅读和理解。

程序注释基本上是代码内部的语句。这些语句（或注释）的作用是帮助使用你代码的人理解每个函数的作用。所有的编程语言都允许某种类型的注释，但它们并不允许所有种类的注释。最常用的是单行注释，这是所有编程语言都允许的。这些注释是简单的解释性行，用简单的句子告诉下一个读者其目的。

还有多行注释。这是极少数编程语言允许的类型。C++ 就是其中寥寥语言之一。有时你需要一个更复杂的解释，并且需要跨越多行。这在 C++ 中是可以实现的。

当你使用单行注释时，你会看到它在代码中用 `//` 写出，并且可以延伸到行尾。
示例如下：

```
{
  cout << "that's great" >> //prints that's great
  return 0
}
```

最终输出将是 "that's great" 而没有其他任何内容。编译器会忽略注释，这样你可以让其他程序员了解代码的用途，或者你需要对代码进行什么操作。

然而，如果你试图就某些代码寻求帮助，你应该使用多行注释，以便能够轻松地利用你复杂的代码。多行注释被 `/* */` 符号包围。这样打出来看起来像像表情符号。例如

```
/* I need help making the puppet dance*/ 是一个注释。然而，这仍然是一个单行注释。更好的例子是

/* I need help making the puppet dance
*All he does at this point is sway from side to side */
```

这就是多行注释。如你所见，当你开始新行时，应该在开头放置星号，以指示程序你仍在编写注释，并且下一行确实是空白。编译时，它将忽略注释并只显示你想让它显示的内容。

虽然你可以混合使用注释样式，但在掌握一切之前，最好将它们分开。

## 第 5 章：在 C++ 中使用运算符

对于你计划使用的任何语言，学习运算符都是重要的。这些运算符将帮助你告诉程序你的需求。你可以使用四种主要类型的运算符。在 `C++` 中可以使用的一些运算符包括：

### 逻辑运算符

我们在指南中使用的第一种运算符是逻辑运算符。它们将帮助你比较输入到系统的某些部分。你可以使用的的一些逻辑运算符包括：

- `||`: 这被称为逻辑或（`OR`）。对于这个，如果你的操作数之一不为零，条件就为真。
- `&&`: 这被称为逻辑与（`AND`）。如果你有两个操作数且它们不为零，你的条件为真。
- `!`: 这是逻辑非（`NOT`）。你可以使用它来反转操作数的状态。所以如果条件结果为假，这个符号将使其变为真。

### 算术运算符

你可以使用的另一种运算符是算术运算符。这与在学校里用数学几乎相同。你指示程序对你提供的信息进行加、减和其他方程运算。你可以使用的一些算术运算符包括：

- `+`: 这是加法运算符，将两个你选择的操作数相加。
- `-`: 这是减法运算符。它获取右侧操作数并从左侧操作数中减去。
- `*`: 这个运算符使得在 `C++` 语言中进行乘法成为。
- `/`: 这个运算符帮助你在 `C++` 中进行除法。
- `++`: 这是递增运算符。它将你的操作数的值增加一。
- `--`: 这是一个递减运算符。它将操作数的值减少 1。

## 赋值运算符

赋值运算符将让你更轻松地为变量分配名称，并帮助你对正在编写的代码的不同部分进行搜索、保存等操作。在 `C++` 中你可能会使用的一些赋值运算符包括：

- `=`: 这个运算符是简单的赋值运算符。它将右侧操作数的值赋值给左侧。
- `+=`: 这个运算符被称为加法赋值运算符。它将两个操作数的值相相加，然后将和赋值给左侧的操作数。
- `*=`: 这是乘法赋值运算符。它将两个操作数的值相乘，然后将结果交给左侧的操作数。
- `-=`: 这个运算符会将右侧操作数的值减去左侧的值，并将差值交给左侧操作数。
- `/=`: 这是除法运算符。它将左侧的值除以右侧的值，然后将结果赋值给左侧。

还有其他一些赋值运算符，但它们更高级，所以我们只坚持这些基础运算符来帮助保持条不紊！

## 关系运算符

在 `C++` 语言中工作时，关系运算符非常有帮助。你可以使用的一些包括：

- `==`: 这个运算符将检查两个操作数的相等性。如果它们相等，条件为真（`true`）。
- `>`: 这个运算符将检查操作数的值。如果左侧的操作数大于右侧的，则条件为真。
- `<`: 这个运算符基本上与上面的一个相反。如果你发现左侧操作数的值小于右侧的值，则条件为真。
- `!=`: 这个运算符将检查两个操作数的相等性，如果值不相等，你的条件即为真。
- `<=`: 这个运算符将检查左侧操作数是否小于或等于右侧操作数。如果满足此标准，条件为真。
- `>=`: 这个运算符将检查左侧操作数的值是否大于或等于右侧的值。如果是，条件为真。

## Switch 语句

我们在这个系统中要处理的第一个决策是 `switch` 语句。这些语句非常好用，因为它们允许你检查变量与一组值或情况（`cases`）的相等性。你尝试检查的变量将与每个 `case` 进行比较。你可以使用的这种语法的好示例包括：

```cpp
Switch(expression){

    case constant-expression:

    statement(s);

    break; // 可选

    case constant-expression:

    statement(s);

    break; // 可选

Default: // 可选

statement(s);

}
```

在这些语句内部工作时，有几条规则你应该记住。首先，`switch` 语句的表达式应该是整型或枚举类类型。此外，它也可以属于具有转换函数的类。在 `C++` 中，你向语法中添加的 `case` 语句数量没有限制，所以你可以根据喜好让它们变长或变短。只需每个每个 中都需要一个冒号和一个值。

一旦变量找到了与它相等的值，它将继续运行，直到找到 `break` 语句。系统找到 `break` 语句后，`switch` 就会停止。然后控制流将继续传递。你不需要在 `case` 中放入 `break` 语句。如果你最终没有其中一个，控制流将继续传递。

## if 语句

你在程序中可以做的最基础的事情之一就是创建一个 `if` 语句。这些基于系统内部的真（`true`）和假（`false`）的概念。如果系统根据你设定的条件认为输入为真，那么程序将运行你要求的任何内容。例如，你设置系统判断 `2+2` 的答案是什么。如果用户输入的答案是 `4`，你可以弹出一个显示“正确！做得好！”的消息。

## 黑客

黑客并不是一个新概念。只要有任何技术出现，一直有人研究黑客它们的方法。黑客是对从一个地方发送到另一个地方的技术流的操纵或中断。这是通过脚本来实现的。虽然可以在网上获取打包好的脚本，但许多人更倾向于用传统方式编写自己的，因为这提供了更大的灵活性。

世界上有多种类型的黑客。虽然媒体将黑客描绘成坏人，但他们并非如此。这也不是非黑即白的。虽然在谈论黑客时，这两个群体是最受欢迎的，但它们之间还有许多类别，仅仅讨论这两个广为人知的群体并无益处。

然而，所有子类别所属的两个大类是伦理黑客和非伦理黑客。

伦理黑客是指仅用于良好目的的黑客。许多人完全权限进入系统并发现软件或硬件的所有漏洞。

伦理黑客是负责你手机、应用程序、平板电脑或电脑中所有漏洞修复的人。这些人受公司聘用，找出其系统存在的问题，并找到最佳修复方法。这些黑客是黑客社区不可或缺的一部分。

如果没有黑客，我们就没有全球信息网、`URL` 或 `HTML`。只要在伦理黑客的范围内进行，黑客行为就是重要的一部分。

然而，非伦理黑客并不在当前法律允许的范围内。它是出于恶意目的的黑客。那些攻击银行主机、盗取他人信用卡和账户信息并用其刷空账户的人被称为非伦理黑客。

非伦理黑客是真正黑客存在的噩梦。这些人是给好人招来坏名的人。

现在来看所有不同类型黑客的术语。

- **白帽黑客**：这些是完全伦理的黑客。他们所做的一切都是为了做好。他们检查系统，仔细查找任何漏洞，并构建超强大的防火墙以确保系统安全。他们创建反恶意软件软件。
- **黑帽黑客**：这是你必须远离的黑客类型。能力越大，责任越大。不成为黑帽攻击诱惑猎物的巨大责任。这种类型的黑客行为可能会让你陷入很多麻烦，政府文件甚至他人的隐私可能具有诱惑力，但会导致严厉的纪律处分。
- **灰帽黑客**：这些是有时为了正当理由做坏事的黑客。例如匿名者（`Anonymous`）。他们可能会破解敏感信息文件的防火墙，但这样做是为了暴露防火墙背后的腐败。这些黑客通常被视为罪犯，但实际上，取决于你的观点，他们可以被视为英雄。
- **红帽**：这些是黑客世界的赏金猎人。他们利用自己的黑客技能寻找非法黑客，例如黑帽黑客或正在做不该做事的灰帽。然后他们将这些人交给联邦政府，以便非法黑客被捕。这些黑客还有几个其他术语，但并不合适，所以我们就不提它们了。
- **蓝帽黑客**：这些是黑客世界的蓝领工人。他们坐在隔间里，整天黑客以为微软或其他大公司寻找漏洞。他们做着九点五的工作，而这份工作恰好涉及黑客。

这些是黑客的主要分类。还有精英黑客，他们一生致力于成为世界上见过的最好的黑客；以及绿帽黑客，他们并不在乎黑客，只是为了好玩。黑客可以是一种非常有用的工具，如果你方法正确，甚至可以成为一种职业。

现在重要的是，所有这些黑客的工作方式都会不同，但他们将使用相同类型的代码从其他计算机中获取他们想要的信息。黑帽黑客将集中于进入系统并获取他们需要的信息以成功，而白帽黑客将努力将这些黑客挡在系统之外。虽然他们的方式不同，但他们将使用相同的工具，并看最终谁胜出。

话虽如此，你需要小心使用你的黑客能力。如果你利用它们进入一个你不被允许的系统或网络，你可能会陷入很多麻烦。虽然有些人发现这些漏洞并立即告诉公司，但如果你在不该在系统内时，这仍然是一个法律问题。你招惹的法律实体可能会提起诉讼，因此最好的办法是在自己的网络内工作并保持其安全，而不是尝试进入一个你不所属的网络。

另一方面，如果你是一个热爱在计算机世界工作并希望能够一直这样做的人，那么成为一名白帽黑客工作可能是一个好主意。许多公司为客户保留私密和个人信息，无论是医院信息、信用卡信息还是其他。他们时刻关注可能试图进入系统并获取这些信息的黑帽黑客，而一个优秀的白帽黑客总能找到他们需要的工作来帮助这些公司。

# 引言

计算机包含两个功能组件——软件和硬件。硬件是用于旋转、计算和利用电力执行计算的物理部分，而软件是一个更具虚拟的概念。本质上，软件由编程代码组成，它向硬件提供指令——告诉各个部分应该做什么。存在“高级”软件，如浏览器、文字处理器、音乐播放器等。但经常被忽视的组件是被称为操作系统的“低级”软件。

我们的个人电脑运行需要操作系统。在办公室或使用相对廉价的台式电脑时，使用的操作系统可能是微软的 `Windows`。内容创作者、作家和图形艺术家更倾向于 `Apple` 电脑，因为它们配备了专注于创造的 `OSX` 操作系统。`Windows` 和 `OSX` 这两个操作系统已经主导了消费市场多年。然而，存在另一种替代操作系统，它在可用性、定制性、安全性和价格方面表现出色。基于相对不知的 `Linux` 的操作系统在所有这些领域都达到并超过了预期，但它仍然是一个许多人甚至听说过的冷门选项。

`Linux` 本身并不是一个操作系统。它是一个内核，即操作系统的“核心”。正如 `Windows NT` 是 `Windows 7` 的内核一样，`Linux` 是 `Ubuntu`、`Debian`、`Arch`、`Fedora` 等“发行版”的内核。

但为什么有人会放弃熟悉的 `Windows`，转而选择一个未闻过的计算环境呢？`Linux` 不仅金钱上免费，而且兼容海量设备。旧电脑，特别是那些不再运行的电脑，可以通过 `Linux` 操作系统重焕发生机，使其运行得像新的一样。

本书将切换到 `Linux` 的好处，并作为安装、配置和使用最流行发行版的初学者指南。然后，将解释终端命令行，说明如何以其他系统无法实现的方式利用该操作系统。切换到 `Linux` 确实可以获得许多优势，通过阅读这本书，你可能会为你的电脑找到一个合适的主操作系统。

## Linux 历史

在 20 世纪 90 年代，`Linus Torvalds` 是芬兰的一名学生。当时的计算机通常运行在 `DOS` 或 `UNIX` 上，这两个操作系统在当时都是专有的且难以使用的。`Torvalds` 试图创建一个自己的操作系统作为业余项目（基于 `UNIX`），但该项目迅速壮大，并吸引了更多开发者。内核不断演变，直到它是可移植的（可以在各种系统上使用）并且完全可以用于计算。内核不是操作系统，因此 `Linux` 与 `GNU` 核心实用程序相结合，创建了一个类似于操作系统的计算环境。

然后，第三方机构采用了基础 `Linux` 产品，并为其添加了他们自己的高级软件和功能，从而创建了 `Linux`“发行版”。直到今天，`Linux` 仍然是一个免费的业余项目，因此内核不断收到 `Torvalds` 和社区的更新和修订。在整个 2000 年代，许多其他第三方看到了 `Linux` 环境的实用性，并开始将其整合到他们的生产环境和公司中。今天，`Linux` 以在服务器和业务环境中被广泛使用而闻名，并有一小部分专门的桌面用户。面向未来，内核已经达到了一个永远不会的流行程度。大公司因为 `Linux` 的优势和实用性而青睐它，因此内核和各种发行版将作为最好的替代操作系统一直存在。

## Linux 的好处

为了比较 `Linux` 对计算机来说是一个多么好的选择，我们将它与更熟悉的现代操作系统进行比较。

首先，`Linux` 是免费的。`GNU` 的背景将 `Linux` 置于一种“免费开源”的心态中，随 `Linux` 提供的的大部分（不是全部）软件都是免费的。自由开源（`FOSS`）指的是两点——软件在金钱上是免费的，而且源代码也是透明的。`FOSS` 与专有软件的区别在于，`FOSS` 的一切都是开放的，在使用时不会涉及任何隐藏的间谍软件、费用或猫腻。软件通常更安全，因为任何人都可以对现有的源代码做出贡献并使其更好。由于 `Linux` 和你为它下载的大部分软件都是免费的，它对于预算有限的小型企业或个人用户来说是一个极佳的操作系统。无疑，不收取费用并没有牺牲质量，因为 `Linux` 项目及其各种发行版是社区驱动的，并通过捐赠筹资金。

与 `Windows` 的成本相比，后者通常是数百美元。`Microsoft Office` 是一套流行的文档套件，但它的价格很高。`Linux` 中存在这些程序的免费替代方案。

`PC` 所有者可能最大的抱怨可能是病毒。`Windows` 电脑特别容易受到病毒的影响，即使是防病毒公司也一直在追赶最新的威胁。仅仅访问恶意网站通常就足够感染计算机了。基于 `Linux` 的操作系统与 `Mac` 类似，病毒几乎不存在。这种安全性的提高使得对于任何关心隐私、安全或可靠性的人来说，切换到 `Linux` 都是必须的。

`Linux` 在企业和政府机构中非常流行。这是因为高功率服务器和关键设备在 `Linux` 上的运行会异常出色。该操作系统以可靠性和稳定性著称。虽然 `Windows` 电脑需要定期重启和维护来“刷新”并防止其运行变慢，但 `Linux` 服务器可以运行几个月甚至几年而不需要重启。`IT` 专业人员因为其声誉不可避免地选择 `Linux` 作为其网络的骨干。其闻名的稳定性在桌面平台上也适用于消费者，对我们来说绝对有用。

也许使用 `Linux` 最大的好处是速度。低系统要求意味着在 `Windows` 上通常运行缓慢迟钝的电脑，在 `Linux` 上将变得敏捷快速。对电脑变慢感到沮丧的用户可以更换操作系统以获得更响应的体验。此外，`Linux` 可以安装在旧电脑上以使其焕新生。所以尽管那台旧笔记本电脑可能过时无法运行最新版本的 `Windows`，但可能有一个 `Linux` 发行版可以再榨出几年的寿命。

定制化是技术领域备受追求的功能。`Windows`，尤其是 `OSX`，由于担心普通用户会弄坏它，限制了你对操作系统可以进行的操作。`Linux` 并非如此，因为它鼓励编辑和更改操作系统的视觉和功能。当然，这并不是必要的，大多数 `Linux` 发行版的默认配置极其稳定，很难在无意中破坏。但对于那些喜欢越狱、改装和折腾电脑的人来说，`Linux` 可以促进创造性的一面，并为好奇的黑客提供其他系统中无法提供的工具。

最后，`Linux` 兼容海量设备。`Linux` 可以运行在几乎任何架构上，这意味着它可以安装在手机、台式机、笔记本电脑、服务器、游戏机和“智能”设备上。爱好者乐于在小众、老旧或奇特的设备上安装 `Linux`，仅仅是因为它们可以这样做。对于普通用户来说，这意味着 `Linux` 可能与你的电脑兼容。

总的来说，`Linux` 在许多领域都胜过主流操作系统。所有这些特点绝对使 `Linux` 成为你电脑的更好选择，你应该使用它来获取这些备受推崇的功能。艺术家、黑客、创意人士、小微企业主、技术人员、非技术人员，以及几乎每一个人都能在 `Linux` 中找到自己喜欢的地方。广泛的发行版意味着每个人都能找到自己的选择，因此今天就安装 `Linux` 吧，看看你能从中获得什么。

## Linux 发行版

安装 `Linux` 有几种方式，例如将操作系统镜像刻录到光盘上、将其写入 `USB` 闪盘、在线订购 `Live CD`、格式化 `SD` 卡，或者通过 `Virtual Box` 尝试运行。但归根结底，你不能只安装“`Linux`”就获得一个可用的操作系统。因为 `Linux` 只是一个内核，你还需要其他提供图形用户界面、互联网访问等功能的软件。正如前面提到的，`Linux` 存在“发行版”。发行版是 `Linux` 的不同版本，包含了预装程序以及独特的风格和侧重点。发行版提取 `Linux` 的核心并将其转化为一个适合日常使用的完整操作系统。

发行版的数量多到令人难以想象。有些具有特定用途，例如用于黑客的 `Kali Linux`、用于教育的 `Sugar Linux` 或用于自定义的 `Arch Linux`。另一些则更具通用性，如 `Ubuntu` 和 `Debian`。要充分利用安装 `Linux`，意味着你需要了解不同的发行版，并决定哪一个最适合你。阅读以下章节以了解一些最流行的发行版的用途。

`Ubuntu` 是本文写作时最广为人知的发行版。在整个 20 世纪 00 年，它因其用户友好和直观而广受欢迎。`Ubuntu` 基于早期的 `Debian` 发行版，在使用上与 `Windows` 极其相似，这意味着它是 `Linux` 新手的绝佳选择。正如此，我们将在书的后面安装一个 `Ubuntu` 变体。`Canonical Ltd` 是积极开发 `Ubuntu` 的公司。年度版本更新意味着操作系统始终保持最新，并兼容新兴技术。尽管如此，`Ubuntu` 仍然可以在许多旧设备上以合理的速度运行。应用程序可以从某种“商店”安装，这意味着初学者不需要理解复杂的命令行。总之，`Ubuntu` 发行版是初次使用 `Linux` 的用户的绝选择，你应该安装它来学习 `Linux` 是如何工作的，而无需深入那些更困难的发行版。

对于更特定的计算情况，`Ubuntu` 有各种子发行版或“口味”（flavors）。这些是以 `Ubuntu` 为基础但侧重点不同的分发版，例如 `Lubuntu` 强调轻量级应用。这里有几个：

- `Lubuntu` – 一种 `Ubuntu` 版本，设计用于在旧硬件或资源有限的电脑上运行。安装文件小于 `1GB`，硬件要求远低于标准 `Ubuntu`。使用此发行版可以在保留 `Ubuntu` 可用性的同时，让旧电脑焕新生。
- `Ubuntu Studio` – 针对艺术家的 `Ubuntu`，包括数字画家、音频制作人员和视频剪辑师。`Ubuntu Studio` 是预装了编辑工具的 `Ubuntu`。
- `Kubuntu` – 使用 `KDE` 桌面环境重新皮肤的 `Ubuntu`。`Kubuntu` 的外观和感受与经典的 `Ubuntu` 感受有所不同，它提供了一个更接近其他操作系统的传统桌面环境。
- `Xubuntu` 是另一个轻量级发行版，但它不像 `Lubuntu` 那么精简。`Xubuntu` 牺牲了体积和硬件要求，以提供一个可以在旧但不过于老的电脑上运行的操作系统。它显然比其他极简 `Linux` 发行版更美观，而且它以 `Ubuntu` 为基础，具有用户友好和熟悉感。
- `Ubuntu Server` – 一种更适合工业和企业需求的 `Ubuntu` 变体，`Ubuntu Server` 可以无头模式运行，并为网络中的其他 `Linux` 系统提供功能。
- `Mythbuntu` – 一个预装了电视流媒体和直播节目的变体。这是一个通过 `Kodi` 将旧电脑转换为“智能电视”设备的绝佳发行版。

总之，广泛的 `Ubuntu` 发行版意味着每个人都有自己的初学者操作系统。强烈建议你利用 `Ubuntu` 包含的易用特性和通用熟悉感。它作为一个阶梯式的操作系统，将引导你进入 `Linux`。务必将其安装作为你的第一个 `Linux` 体验。

`Linux Mint` 是 `Linux` 世界中非常使用的操作系统。“强大且易用”，`Mint` 包含了自由开源软件（`FOSS`）以及专有软件，旨在为初学者提供完整的体验。虽然不是完全像 `Linux`，但由于其布局与 `Windows` 非常相似，它是初次用户的极选择。

`Debian` 是最古老的发行版之一，创建于 1993 年。结合 `Linux` 的哲学，`Debian` 将稳定和稳固作为原则。`Debian` 存在的时间是其精炼程度的指标，因此追求稳定性的人可以转向 `Debian`。自由开源软件在 `Debian` 中也有一席之地。

`Slackware` 是一个比 `Debian` 还要早的操作系统。它保持了原始 `Linux` 的意图，这意味着你必须安装自己的 `GUI` 和程序。正因如此，`Slackware` 主要面向中级用户，因为初学者会对这些方法感到困惑。然而，如果你想体验接近 `UNIX` 根源的 `Linux` 发行版，`Slackware` 可以为你提供。

`Fedora` 是一个更面向工作站和业务用户的操作系统。`Linus Torvalds` 本身就是 `Fedora` 的用户，这归功于该操作系统的受欢迎程度。`Fedora` 更新非常频繁，意味着它始终保持最新并处于 `Linux` 技术的前沿。安全和自由开源软件也是该操作系统的重点，这就是为什么它通常用于小型企业的终端电脑。

`Arch Linux` 是另一个发行版，但它主要为经验丰富的用户设计。该操作系统以系统外壳的形式出现，用户可以根据喜好进行自定义，只添加他们需要的程序和服务。正因如此，`Arch` 安装非常困难，但也是一种有回报的学习体验。通过构建自己的个人系统，你将理解那些在高级发行版中被隐藏的深层 `Linux` 概念。在非常熟悉基础后，再安装这个高级操作系统。

最后，还有许多其他独特的发行版值得提及。在以下列表中，我们将讨论其中几个。请注意，由于发行版如此之多，这整本书都可以用来描述每一个一个。

- `CrunchBang` – 一种基于 `Debian` 的发行版，旨在减少资源消耗。它简单，且没有某些发行版默认包含的臃肿软件。`CrunchBang` 运行快速且计算高效。
- `Android` – 流行的手机操作系统实际上是一个 `Linux` 变体。由于许多手机的配置低于全台式电脑，因此该操作系统是笔记本电脑、触摸设备或家庭媒体电脑的绝佳选择。此外，你可以使用 `Play` 商店中的许多 `Google` 应用，这意味着成千上万的应用程序、游戏和工具可以在手机和电脑上使用。虽然不建议作为第一个 `Linux`，但对于尝试旧电脑或儿童电脑来说，它绝对是一个有趣的选择。
- `Chrome OS` – 由 `Google` 开发的另一种移动类型操作系统，`Chrome OS` 本质上是一个用于在线使用的轻量级 `Linux` 浏览器。`Google` 在其 `ChromeBook` 上预装了该系统，这些电脑的配置比其他笔记本电脑低。但该系统实际上只是一个全屏 `Chrome` 浏览器，因此它非常适合想要简单体验或需要专用上网设备的用户。
- `Tiny Core` – 这是一个大小单位为 `MB` 的操作系统，`Tiny Core` 适用于老旧电脑或嵌入式设备。该系统主要面向有兴趣项目或特定用途的中级级用户。
- `Damn Small Linux` (`DSL`) – 另一种极简的 `Linux` 变体，该系统最适合快速访问 `Linux` 命令行。
- `openSUSE` – 这是一个为经验丰富的计算机用户设计的发行版。`openSUSE` 为管理员和程序开发人员提供了许多工具，是那些对自己技能有自信的用户的最佳操作系统。

基于 `Linux` 内核的操作系统数量之多令人惊叹。面对海量的选择，你可能会对从何开始以及如何安装感到困惑。如果有疑问（正如我们稍后将演示的那样），请安装 `Ubuntu` 或其变体。该系统非常适合初学者，并让向 `Linux` 的过渡更加顺畅。但随着你技能的提高并希望了解更多 `Linux` 知识，你也可以随时安装另一个操作系统。

## 进入 Linux 系统

如果你准备好投身 `Linux` 发行版，必须做的第一件事就是备份你的文件。覆盖硬盘上的操作系统将擦除其中的任何数据，这意味着你必须备份任何在转换后想要保留的图片、音乐或文件。使用外部硬盘或在线数据存储网站（如 `Google Drive`）来临时存放你的文件。我们对你丢失重要物品不负责，请务必备份！

接下来，我们需要选择一个操作系统。本书将使用 `Ubuntu 16.04` 作为扩展示例，建议你也这样做。访问 `Canonical` 官方网站（`http://www.ubuntu.com`）并获取该操作系统的副本。你将从网站下载镜像到你的电脑上。

接下来，我们需要获取安装介质。这可以是 `DVD`、`USB` 闪存、`SD` 卡或你的电脑可以读取的任何可写介质。唯一的限制是设备必须能够容纳与操作系统下载文件等大的镜像，因此 `4GB` 空间就足够了。请清空驱动器上的所有内容，因为它将被格式化。

下载一个用于写入镜像文件的工具。对于 `DVD`，安装 `Imgburn` (`http://www.imgburn.com/`)；对于闪存媒体，下载 `Rufus` (`https://rufus.akeo.ie/`)。常用的操作系统安装方法是使用 `4GB` 的 `USB` 盘，且更推荐这种方法。插入你的介质，启动相应的程序，选择下载的操作系统镜像，并开始写入过程。这需要一些时间，因为镜像需要在介质上制作成可启动状态。完成后，你可以完全关闭电脑。

现在是双重确认你已准备好安装 `Linux` 的时候。检查文件是否已备份，明确你将擦除当前的操作系统，并且最好手头留有一个 `Windows`/`OSX` 安装盘，以防你决定切换回。如果你确实准备好切换了，请继续。

在保持安装介质插入的情况下，打开电脑。你看到的第一个屏幕是 `BIOS` / `UEFI` `POST` 界面，它会显示一个你应该按下的键盘键以进入设置。这个屏幕在每次启动时都会显示，但你可能没有注意它。按下指定的按键进入 `BIOS` 设置。如果你操作太慢，屏幕将会消失，你常用的操作系统将开始加载。如果发生这种情况，只需关掉电脑并重试。

进入 `BIOS` / `UEFI` 后，你必须导航到“启动顺序”（`boot order`）设置。每台电脑的 `BIOS` / `UEFI` 略有不同，因此我们无法详细解释这一过程。但通常你可以遵循屏幕底部的按钮提示来了解如何导航。到达启动顺序设置后，将你的启动介质置于列表顶部。例如，如果你使用了 `USB` 盘，你会看到它的名称并必须将其移至列表顶部。这些设置控制了 `PC` 搜索操作系统的顺序。将我们的启动介质置于列表顶部后，它将启动我们下载的 `Linux` 镜像，而不是常用的操作系统。保存设置并重启电脑。如果一切操作正确，电脑将开始进入 `Ubuntu`。

但如果出现任何问题，请尝试通过以下提示进行故障排除：

- 启动了主系统而非 `Linux` – 你可能没有保存将备用启动介质置于列表顶部的设置。`PC` 仍然默认从内部硬盘启动。
- “未找到启动介质”（`No boot media found`）—— 你是否是直接将 `Linux` 镜像“拖放”到介质上，而不是写入它？如果不显式告诉电脑它是可启动的，它将不知道如何处理介质上的数据文件。或者，你可能是下载的文件损坏或写入不完整。尝试重新下载镜像并再次进行安装。
- “内核恐慌”（`Kernel Panic`）—— 启动过程出现问题。请参考上文关于安装损坏的可能性。否则，尝试安装的镜像可能与你的硬件不兼容。如果你看到任何其他错误信息，请在网上搜索。对于预装电脑和笔记本电脑，搜索模型名称以及其他用户的体验。最后，你可能尝试安装了 64 位镜像。在下次下载时，请具体选择 32 位镜像。
- “从 `CD-ROM` 读取数据问题...”—— 尝试使用不同的安装介质，因为某些发行版不再支持 `CD` 和 `DVD` 安装。推荐使用 `USB` 盘。
- `PC` 似乎启动了，但屏幕上一空白 – 如果你使用的是独立显卡（相对于 `CPU` 集成显），`Linux` 可能无法完全识别它。请将显示器直接插在主板而非显卡上。

但大多数问题都是罕见的，或由于用户操作错误。`Linux` 具有良好的兼容性，且在初始安装后容易使用。此时，典型用户已成功启动 `Ubuntu`，并获得一个运行的工作环境。

你看到的桌面被称为“`Live` 系统”，它实际上是该操作系统及其工作方式的演示。你尚未将操作系统安装到硬盘上，因为它仍然直接从启动介质运行。这是一个让你在不删除主操作系统的情况下测试 `Linux` 的机会，请利用此机会探索 `Linux`。

## Ubuntu 基础

与 `Windows` 类似，`Ubuntu` 拥有桌面图形用户界面。应用程序在窗口中打开，可以最大化、最小化、关闭并在顶栏移动。`Ubuntu` 也有某种类似于“任务栏”，其功能与 `Windows` 版本相似，图标代表点击即可启动的程序。任务栏上的“`Windows` 按钮”（称为 `Dash` 按钮）用于打开搜索功能，你可以在其中输入电脑上的程序或文件名来快速启动它。

此外，屏幕顶部有一个栏，类似于其他操作系统的“菜单”栏。当程序激活时，这里会显示“文件”、“编辑”、“帮助”等下拉菜单。

除了一些细微的差异外，`Ubuntu` 的运行方式非常熟悉。事实上，许多你可能在其他操作系统上使用的程序（如 `Firefox`）在 `Linux` 发行版中均可用，有时甚至是预装。通过足够的尝试和练习，你将像专业人士一样操作 `Ubuntu` 的 `GUI`。继续探索系统，如果你准备好用这个 `Linux` 系统替换你的主操作系统，请继续。

## 安装 Linux

在桌面上，你会看到一个“安装 `Ubuntu 16.04 LTS`”图标。双击它将启动一个应用程序，让安装过程变得非常简单。如果你没有连接互联网，请现在通过插入以太网线或通过右上角的图标连接 `Wi-Fi` 来连接。选择你的语言并点击“继续”。下一个提示将询问你是否希望在操作系统（`OS`）安装下载更新并安装第三方软件。对于初学者来说，强烈建议选择这些选项，因此勾选它们并点击“继续”。

应用程序将跳转到另一个屏幕，询问你的安装方法。有多种选项，例如完全擦除磁盘、与你的主操作系统一起安装，或更新之前的 `Linux` 版本。选择一个最适合你的选项。如果你仍然犹豫是否要完全切换，请选择将 `Ubuntu` 安装为你的次要操作系统。该选项将允许你在 `BIOS` 界面后选择进入哪种操作系统。尽管如此，请选择你的选项并点击“现在安装”。

在 `Ubuntu` 安装期间，你可以指定其他几个选项，例如时区、计算机名称、账户名称和密码。整个安装过程不会花费太长时间，但时间长到你的电脑应该连接电源（如果是笔记本电脑的话）。完成后，操作系统将要求重启。恭喜，你现在电脑上拥有了一个可用的 `Linux` 系统。在本出版物的后续章节中，我们将重点关注 `Linux` 概念、如何完成某些任务以及如何进一步增加你对系统的了解。

## 管理硬件和软件

在 `Linux` 中，硬件的管理实际上比在 `Windows` 中要容易得多。不需要为设备下载单独的驱动程序，大多数驱动程序已内置在操作系统中。这意味着大多数流行设备只需安装，无需在使用前执行任何额外步骤即可。打印机、网络、硬盘和其他常见设备都包含在内——`Linux` 上通常不需要运行驱动程序。

然而，强大的显卡和其他特定硬件需要该公司的专有驱动程序才能完全高效运行。因为尽管你的显卡在 `Linux` 中默认工作，但其内部且往往隐藏的技术只有通过该公司的软件才能被充分利用。在 `Ubuntu` 上，这个过程非常简单——打开“附加驱动程序”应用程序并让操作系统为你搜索。在确定你是否拥有这些设备后，它会询问你使用哪个版本的驱动程序。

按照屏幕上的提示启用第三方驱动程序。对于任何未出现的设备，请在制造商网站上进行网络研究，以确定他们是否发布了你可以下载的特定 `Linux` 驱动程序。

软件是 `Linux` 优于 `Windows` 的另一个方面。就像苹果电脑一样，`Ubuntu` 也拥有一类应用商店，你可以在其中搜索与你的设备兼容的应用程序仓库，只需点击几次即可下载并安装。只需从 `dash`（启动器）搜索“`Ubuntu` 软件中心”打开该应用程序。从那里，你可以浏览各个类别（如“游戏”、“办公”或“系统”）的程序列表，也可以直接通过名称搜索。找到程序后，点击它，然后点击“安装”将下载加入队列。在验证身份后，软件将自动下载并安装。从那里，可以通过在 `dash` 中搜索来运行该应用程序。

通过终端可以使用另一种安装软件的方法，但我们稍后会讨论。`Ubuntu` 并不完全限于应用商店中的软件，因为从互联网下载的程序也可以安装。同样，我们将在讨论终端后触及该主题。

总的来说，在 `Ubuntu` 中管理硬件和软件是轻而易举的。无论是安装新设备还是下载流行程序，`Linux` 发行版都能让你的计算体验毫无故障。这并不是说 `Linux` 完全是为初学者设计的，因为正如我们将学到的，`Linux` 绝对是高级用户和经验丰富的管理员的绝佳选择。

## 命令行 / 终端

在现代计算机出现之前，硬件和软件完全通过键盘进行交互。鼠标带来了图形化界面并简化了过程，但许多功能仍然保持为纯文本，以避免向最终用户呈现复杂的选项。在 `Linux` 中，这一过程延续至今。虽然大多数发行版中都存在 `GUI`，但每个 `Linux` 发行版也内置了一个基于文本的界面，在其中可以输入并执行强大的命令。将终端想象为一个功能强大的命令行提示符，因为你可以完全通过终端来使用你的计算机。拥有足够的知识，用户实际上可以通过文本浏览互联网、安装程序、管理文件系统等。

通过 `dash` 启动终端或使用 `Ctrl+Alt+T` 快捷键进入终端。一个紫色窗口将打开并等待你的输入。你可以输入命令并按回车键激活它。对于我们的第一个命令，输入“`ls`”。这是 `list`（列表）的缩写，它将显示当前目录下的所有文件。你将看到 `Home`（`Ubuntu` 的主用户文件夹）中的文件和文件夹。如果你迷路了，可以随时输入“`pwd`”打印工作目录并显示你当前正在浏览的文件夹名称。在你学习命令时，将它们记录下来有助于更好地掌握它们的用法。

## 管理目录

目录（文件夹的另一个名称）的工作方式与其他操作系统相同。文件夹存放文件，你必须当前访问某个目录才能与其中的内部文件进行交互。你可以使用终端命令“`cd`”来更改目录并在文件系统中移动。例如，在 `Home` 文件夹中输入“`cd Desktop`”将你带到该文件夹。现在使用“`ls`”将不会显示任何内容（除非你在桌面上添加了文件）。要返回上一级，输入“`cd ..`”。练习以这种方式导航文件系统；进入一个目录并使用 `ls` 查看文件。因为你正在输入命令，`Linux` 期望你的输入是精确的。如果你拼错了命令，它将无法运行。你也可以通过终端创建和删除目录。例如，使用 `mkdir` 创建目录；输入“`mkdir Programming`”创建一个名为 `Programming` 的文件夹。作为快捷键，你可以输入“`cd ~`”切换到 `Home`，因为波浪号代表“当前用户的主目录”。使用 `rmdir` 会删除目录。如果你输入的文件夹或文件错误，它会尝试引用一个不存在的内容。打开文件需要使用一个不同的命令——`./`。点被用于启动指定的文件，所以如果你正尝试打开一张图片，可以这样做：`./house.png`。点和斜杠都是必要的，因为它表示你正在运行当前目录下的文件。当你运行一个文件时，它将用分配给该类型的默认应用程序打开，所以对于图片，它可能会在图像查看器中打开。

但这并没有损害安全性，因为任何关键操作都需要以“`sudo`”命令作为前缀。`Sudo` 是“`super user do`”（超级用户执行）的缩写，意味着最高权限的用户正在请求执行命令。任何 `sudo` 条目都需要管理员密码，因此恶意软件或无意的键盘垃圾输入程序无法在不知道密码的情况下意外造成破坏。我们在书中使用的许多命令都需要 `sudo` 权限，所以如果命令执行失败并提示信息说明其没有足够的权限，你可以尝试使用 `sudo` 重试。

## Apt

学习终端（`terminal`）可以开启在图形用户界面（`GUI`）中无法使用的计算机功能。此外，你可以通过输入命令来代替操作，缩短完成许多任务所需的时间。以安装程序所需的工作量为例。如果你想下载 `Google` `Chromium` 浏览器，你必须打开软件中心，输入程序名称，找到正确的包，将其标记为安装并执行操作。将其与在终端中输入“`sudo apt-get install chromium-browser`”相比，只需这一个命令，`Ubuntu` 就能为你节省很多分钟时间。

`Apt`（高级软件包工具）是用于管理 `Ubuntu` 应用程序的关联命令。其他发行版可能使用自己的工具，但 `apt` 因其庞大的仓库和简单的命令而被广泛使用。软件包使用“`apt-get install`”格式进行安装，其中你指定想要安装的程序名称。在上面的示例中，我们通过包名“`chromium-browser`”指定了 `Chromium` 程序。由于你并不知道每一个包名，还有另一个命令“`apt-cache search`”，可以用于查找与提供的字符串匹配的包名。因此，“`apt-cache search chromium`”会显示“`chromium-browser`”，你就可以指定正确的名称进行安装了。

`apt` 的有用性不仅限于此，你还可以使用几条命令用它更新系统中的每一个应用程序。使用“`apt-get update`”刷新仓库，然后使用“`apt-get upgrade`”让每个应用程序都自动升级到最新版本。`Windows OS` 用户应该对这种简便的过程感到羡慕，因为更新 `Windows` 程序需要卸载并重新安装最新版本。

随着时间的推移，你可能需要更新 `Ubuntu` 版本。每年都会发布一个新版本，并且可以通过“`apt-get dist-upgrade`”进行安装。

保持与最新修复和新增功能的同步，可以确保你的 `Linux` 系统能够健康地运行很长时间。你可能已经注意到，安装和更新系统不需要重启；这一特性有助于 `Linux` 计算机实现长时间的运行时间并保持稳定性。最后，通过“`apt-get remove`”后接包名即可删除应用程序。

运行我们安装的程序既可以从启动栏（`dash`）中搜索，也可以直接在终端中输入包名。输入“`chromium-browser`”启动它的效果与双击其图标相同。某些程序必须通过仅输入包名从命令行启动，因为这些包不会出现在启动栏搜索中。总的来说，利用终端是一个节省时间的方法，也是离开缓慢且笨拙的图形用户界面的绝佳方法。软件包的轻松安装和管理是 `Linux` 的一个非常实用的功能——精通它将提升你的体验。安装软件包还有第三种方法，涉及从互联网下载并运行 `.deb` 文件。某些软件是以这种格式打包的，它们的作用类似于 `.exe` 文件，只需要双击即可开始安装过程。

## 更多终端命令

这里有更多几个你应该记在心底并在系统中使用的基础终端命令。完全理解基础知识将为你后续的构建打下坚实的基础。

- **`cp`** – `cp image1.jpg image2.jpg` – 将第一个参数复制（并重命名）到提供的第二个参数。使用 `-r` 开关复制目录。
- **`mv`** – `mv cat.jpg /home/Pictures` – 将指定的文件移动到给定目录。
- **`shutdown`** – `shutdown -h now` – 关闭计算机。`-h` 是一个表示“`halt`”（停止）的标签，你也可以使用 `-r` 重启。`now` 指执行的时间。
- **`date`** – `date` – 显示当前日期时间。
- **`free`** – `free -g` – 显示程序的当前 `RAM` 使用情况。
- **`du`** – `du -h` – 显示硬盘使用情况。
- **`ps`** – `ps` – 显示使用 `CPU` 时间的活动进程。
- **`touch`** – `touch memo.txt` – 用于在当前目录下创建一个指定名称的新空文件。
- **`ifconfig`** – `ifconfig` – `Linux` 下等同于 `ipconfig`，它显示网络信息。

某些命令带有相关的“标签”（`tags`）或“开关”（`switches`）。这些是以连字符开头的字母。它们的作用各不相同，要学习为了什么目的使用哪些开关，最好的方法是查看该命令的手册页。请参考高级章节查看如何打开手册。

命令行中最实用的程序之一是 `nano`，它是一个简单的文本编辑器，可以编辑文件并快速更改设置或脚本。通过在命令行中输入“`nano`”来访问。你可以根据需要输入文件，然后按 `ctrl+x` 保存并退出。你可以给它命名并关联文件扩展。在该示例中，我们打开编辑器显示其内容。`Nano` 可能非常简单，但无疑功能强大且节省时间。

## 连接 Windows / Mac 计算机

`Windows` 和 `OSX` 计算机具有内置的网络功能，如工作组、域、共享等。将 `Linux` 计算机集成到由 `Windows` 服务器主导的网络设施中相当容易，正确的设置将让你看到共享并加入公司域。

通信的第一步是安装“`samba`”软件包。可以在软件中心找到它，或者输入“`sudo apt-get install samba`”来获取并安装。从 `Ubuntu` 向其他计算机共享文件涉及创建 `samba` 共享。`Samba` 运行与其他文件方法相同的协议，因此从 `Ubuntu` 共享的文件可以轻松在 `Windows` 上看到。安装 `samba` 后，使用“`sudo nano /etc/samba/smb.conf`”开始编辑配置文件。在文件的末尾添加这些行：

| Key | Value |
| :--- | :--- |
| `[share]` | |
| `comment` | `File Share from Ubuntu` |
| `path` | `/srv/samba/share` |
| `browseable` | `yes` |
| `guest ok` | `yes` |
| `read only` | `no` |
| `create mask` | `0755` |

现在，创建路径中指定的文件夹（`sudo mkdir -p /srv/samba/share`）并设置权限（`sudo chown nobody:nogroup /srv/samba/share/`），以便任何人都可以访问其内容。在该目录中放置任何想要共享的文件，然后重启服务（`sudo restart smbd. sudo restart nmbd`）以使共享生效。最后，登录你的另一台计算机并导航到网络共享。在 `Windows` 中，它们将出现在文件资源器的左侧面板。如果共享没有自动出现，将 `IP` 输入到文件路径框中（通过 `ifconfig` 查找 `Ubuntu` `IP`）。你可能还需要在 `Ubuntu` 中查看其他操作系统的文件。首先，打开 `Ubuntu` 文件资源管理器。从菜单栏点击“文件”，然后选择“连接到服务器”。在结果框中，输入你想要访问的共享 `URL`。它可以是 `ftp` 地址（`ftp://test.com`）、`http` 地址（`http://test.com`）或共享地址（`smb://share/Folder`）。在任何额外的硬件或设置的情况下，你就可以这种方式看到文件。

最后，加入如 `Active Directory`（活动目录）域可以让你的计算机与网络上的其他操作系统交互，并完成其他面向业务的任务。无论你拥有的是小型家庭网络，还是正在将 `Linux` 计算机加入企业域，其过程都是相同的。安装几个额外的包（`realmd`, `sssd`, `sssd-tools`, `samba-common`, `samba-common-bin`, `samba-libs`, `krb5-user`, `adcli`, `packagekit`）。在安装过程中，它会要求你输入域名。请用全大字母输入。输入‘`kinit -V adminname`’，将 `adminname` 替换为域中的实际管理员账户名称。输入密码后，你将通过域的身份验证。现在，可以通过“`realm --verbose join -U adminname domainname.loc`”完成加入操作。

如果失败了，意味着我们设备上的 `DNS` 配置错误。输入“`echo ad_hostname = nix01.domainname.loc’ >> /etc/sssd/sssd.conf`”，然后执行 `echo ‘dyndns = True’ >> /etc/sssd/sssd.conf`，最后使用“`service sssd restart`”使用新设置重启服务。第一行设置了我们计算机的完全限定域名（`FQDN`），因此该行需要根据我们的域设置进行更改。在使用正确配置设置成功重启后，终端将声称已加入域。使用“`realm list`”进行测试。现在连接到 `AD` 后，你就可以从服务器管理 `Linux` 设备了！

然而，对于大多数用户来说，创建共享和加入域远远超过了连接需求。简单的文件共享通过 `USB` 驱动器传输或 `Dropbox` 等服务进行会更好。事实上，`Dropbox` 可以安装在三大操作系统上，文件可以在它们之间同步，而无需额外设置。在 `Ubuntu` 上，你可以直接从网站下载 `.deb` 文件，从软件中心安装，或者使用“`sudo apt-get install nautilus-dropbox`”来获取该程序。在 `Dropbox` 文件夹中，放置任何你想在计算机之间传输的文件，它将自动在你拥有的所有其他 `Dropbox` 计算机上下载并更新。

当将其他操作系统连接在一起时，操作并不复杂。只要计算机处于同一网络中，你就可以创建文件共享、将它们加入域，或使用像 `Dropbox` 简单的服务。

## 管理

如果你在寻找某种“控制面板”，你可以在“系统设置”中找到网络、打印、键盘、外观等管理工具的快捷方式。由于某些 `Ubuntu` 变体使用“设置管理器”或直接称为“设置”来实现相同的目的。

启动后将会有指向其他默认配置应用程序的链接；只需点击你想要更改的项，即可获得设置某些选项的 `GUI` 界面。但并非所有管理设置都能通过 `GUI` 找到。大多数低级设置仅通过命令行可用，因此你需要确切知道要输入什么来编辑它们。

例如，在 `Ubuntu` 中添加新用户需要“`adduser`”命令。通过在命令后加上用户名，终端将提示输入基本信息和密码。将新用户设置为管理员的操作是“`usermod -aG sudo nameofuser`”。此外，可以使用“`deluser`”删除用户。这些选项在 `GUI` 中很难找到，但在终端中几秒钟内即可完成。

“任务管理器”或对 `Ubuntu` 内运行程序的管理是通过终端完成的。“`top`”程序标准上已安装在所有发行版中（大多数情况下），启动它会显示类似于任务管理器的所有正在运行的进程列表。但默认情况下，进程列表会更新并变动，这可能导致难以阅读我们所需的数据。按“`f`”键调出排序列表，用方向键导航到“`PID`”并按“`s`”键设置该选项。现在使用 `escape` 键返回 `top`，我们可以通过向上翻页和向下翻页滚动列表以查看任务。例如，假设我们要关闭“`Pidgin`”程序，因为它没有响应。在列表中（或使用搜索命令）找到它，并记下 `PID`（进程 ID）数字。按“`q`”退出 `top`，然后输入“`kill 4653`”，显然要将数字替换为 `PID`。在 `top` 任何时候，你都可以按“`h`”查看各种操作的键盘快捷键列表。如果 `top` 太难用，可以考虑安装“`htop`”，它是程序的“易读”版本。它实际上显示了详细的 `CPU`、`RAM` 和其他使用统计整洁 `ASCII` 图。使用 `F3` 搜索程序，然后使用 `F9` 和 `Enter` 杀死它。

对于服务，你可能注意到我们使用“`service`”命令来更改它们的状态。启动 Web 服务器将使用“`service apache2 start`”，通过将 `start` 替换为 `restart` 来重启，替换为 `stop` 来停止。查找服务列表使用“`service --all`”。服务是守护进程或持续运行的后台任务。它们可以收集数据、运行蓝牙和 `Wi-Fi` 等服务或等待用户交互。

## 安全协议

`Linux` 通常关注安全性，这有助于它在企业和服务器环境中的应用。利用安全协议意味着比其他系统更安全，计算机被攻破的可能性较低。这当然需要良好的安全原则，并始终在网上保持安全。没有密码的计算机几乎不受保护。

从 `UNIX` 引入的一个特性是文件权限。每个文件都有一组权限——所有者、组和权限。“`chown`”命令更改文件的所有者，“`chgrp`”更改组，“`chmod`”更改与文件相关的权限。通过输入“`ls -l filename`”可以发现文件或文件夹的权限。它会返回一行最初令人困惑的行，例如“- `rw-rw-`-”。`R` 表示读，“`W`”代表写，第三个选项是执行的“`X`”。这三组分别是所有者、组和其他。因此，我们上面的示例文件对所有者及其组设置了读和写权限，但对其他用户只有读取权限。这意味着所有者及其所属组（最可能是 `sudo` 用户）有权访问文件并更改其内容，但网络或电脑上的其他用户只能查看内容而不能编辑。脚本文件需要 `X` 才能执行，没有它就无法运行。

大多数人只需要使用“`chmod`”命令更改他们想要使用的文件的权限。我们使用命令和一组数字来设置文件的权限。“`chmod 777 test.sh`”使文件对任何地方的所有用户都可读、写、执行，因为每个规范（所有者、组、其他）都带有数字 `7`。数字决定实体拥有的权限，所使用的数字计算方式如下：

- 从数字 `0` 开始。
- 添加 `4` 以增加可读性。
- 添加 `2` 以可写性。
- 添加 `1` 以可执行性。
- 剩余的数字决定了权限。

`6` 代表可读/写权限，但 `1` 仅代表可执行。`5` 代表可读可执行，但不可修改。在我们的 `777` 示例中，我们将所有者、组和其他人的权限都设置为 `7`。这并不是特别安全，因为这意味着任何地方的任何人都可以弄该文件。更保守的权限是 `775`。充分利用安全权限来实现安全计算。

`Linux` 中的安全不仅限于权限。确保你养成良好的安全习惯，并遵循安全方面的常识——只安装需要的程序，不要听从所有的网络建议，不要频繁使用 `sudo`，使用密码，使用加密网络，保持软件更新，加密重要文件，并定期备份。作为最后的一点建议，请考虑使用带有 `SELinux` 的发行版，它是一个支持访问控制（`AC`）和其他安全策略的模块。

## 脚本编写

`Bash` 是终端的“编程语言”。当我们输入命令时，我们是在 `bash` 环境内操作的。脚本是一系列按顺序执行的 `bash` 命令列表，这意味着我们可以创建一个包含命令列表的脚本并运行，以节省时间或自动化我们通常需要手动输入的终端任务。作为一名中高级 `Linux` 管理员，你可以使用脚本极大地缩短重复性或持续运行任务所需的工作量。

要启动脚本，在 `nano` 中创建一个新文件“`script.sh`”。第一行必须始终是“`#!/bin/bash`”，以将其标记为 `bash` 脚本。为你的第一个脚本输入以下行：

```bash
#!/bin/bash
echo "Hello, World!"
```



`echo “What is your name?”`

```
read name
```

`echo “Hey, $name. Here is your current directory, followed by the files.”`

```
pwd
ls
```

保存脚本。现在我们必须设置权限允许其运行。使用 `sudo chmod 777 script.sh`，然后用 `./script.sh` 运行脚本。只要你完整地复制了脚本，它就会询问你的名字，然后显示你的目录和文件。获取这一概念并在你自己的脚本中进一步扩展它。你也可以运行已安装程序的命令，因此你可以编写一个自动加入域的脚本，或者编写一个连接到指定网络的脚本。关机远程计算机也是一项很棒的自动化任务。

脚本可以手动运行，也可以设置为在特定时间执行。若要在用户每次登录时都运行某个脚本，从 dash 中打开“启动应用程序”程序，并以脚本为源创建一个新应用。现在每当用户登录时，脚本会自动运行。这对于设置某些选项或启动后台服务非常有用，无需用户亲自操作。

可以使用 Cron 系统守护进程为特定时间调度任务。它在某些系统上默认安装，如果没有，可以使用 `sudo apt-get install cron`。使用 `service cron start` 启动服务，并用 `crontab -e` 创建一个新的 crontab 文件。选择 nano 作为你的文本编辑器。在创建的文件底部，添加带有我们调度任务的新行。格式如下：

分钟，小时，日期，月份，星期，命令

我们通过这些选项进行格式化以指定运行命令的时间。时间数字从 0 开始，所以小时范围是 0 到 23，分钟是 0 到 59。用星号替换任何选项以表示它将运行任何值。注意这些示例：

```
0 12 * * ~/script.sh
```

这将在每天中午运行家目录目录下的 `script.sh`。

```
30 18 25 12 * /usr/bin/scripts/test.sh
```

这将在每年圣诞节 6:30 运行 `/usr/bin/scripts` 目录下的 `test.sh`。

总之，脚本编写和脚本自动化是接管经常发生任务控制的极佳方式。继续编写脚本，或在网上查找示例，看看如何通过 bash 让你的计算体验变得更简单。

## 高级终端概念

掌握 Linux 在于对操作系统可用工具的深入理解以及如何利用它们。本章中讨论的许多主题将关注更多任务以及如何完成它们，或者对操作系统进行的一些通用质量（QOL）改进。

文件的压缩和解压缩经常会让 Linux 初学者困惑。这些工具通常已经安装，但必须使用命令行。此外，奇怪的 `.tar` 和 `.gz` 文件类型是 Linux 特有的格式，你可能会遇到。所有文件都可以使用 gzip 工具解压缩或压缩。Ubuntu 预装了它，我们通过 `tar` 命令访问它。要压缩一个文件夹，在终端中进入该目录并输入 `tar -czvf name.tar.gz columnspan`。`-c` 代表“create”（创建），`-z` 表示“compress (gzip)”，`-v` 代表“verbose”（详细），`-f` 允许指定文件名。如果你想要更高的压缩率（但代价是时间），可以将 `-z` 选项替换为 `-j` 选项，用 bzip2 压缩文件夹。

现在可以使用 `tar -xzvf name.tar.gz` 提取相同的压缩包。你会发现 `-c` 被替换为 `-x`，这表示提取。再次地，如果你处理的是 bzip2 文件，请使用 `-j` 选项。

继续讨论终端概念，让我们来聊一些可以节省时间的技巧和窍门。在输入命令或文件名时，在中间按下 tab 键。这项功能——制表键补全（tab completion），将猜测你尝试输入的内容并填充剩余部分。对于文件，它将如目录所示补全名称。Linux 专家和任何必须使用终端的人似乎是以很快的速度输入他们的内容，但他们实际上在使用制表键补全。

用户，特别是管理员，会花费大量时间使用 sudo 命令，因为他们的指令需要提升权限。但当你输入长命令并忘记输入 sudo 时，你会因为必须再次输入而感到恼火。只需输入 `sudo !!`，意为“再次以超级用户执行”。它极大地避免了再次输入整个命令。

另一种重复命令的方法是使用上下方向键。连续按上键可以循环查看之前的命令。你也可以用左右方向键编辑命令内的文本。

以及最常请求的提示：复制和粘贴。尝试向终端粘贴行内容会产生奇怪的字符 `^v`。键盘快捷键没有配置在终端中工作，这就是为什么显示了奇怪的组合。要实际粘贴，右键点击并选择选项；或者使用组合键 `shift+insert`。复制相同，但请使用 `ctrl+insert`。虽然从互联网复制和粘贴终端命令可能是好的（前提是你理解风险并知道他们在做什么），但不要尝试从本文物中粘贴。通过你阅读它的媒介引入的格式可能会插入终端无法识别的特殊字符，因此最好不要复制粘贴，而是应该手动输入呈现的命令。

在你创建脚本和其他配置文件时，请考虑通过点（`.`）来隐藏它们，作为一种用户保护的形式。

终端中的任何命令都可以通过 `ctrl+d` 组合键中断或退出。使用它来停止长时间运行的进程，或者退出一个你不熟悉的程序/命令。

别名（Aliasing）是在终端中创建个人快捷键的一种方式。与其输入一个长长的命令或一堆短命令，不如将它们组合成单个用户定义的选项。正如其名称所暗示，别名是你指定的任何内容的其他名称。每个别名都包含在一个隐藏的配置文件中——使用 `nano .bashrc` 来开始编辑它。因为它存在于用户的家目录下，因此每个别名都仅对该用户有效。在文件的底部，我们可以按照示例开始创建别名：

```
alias gohome='cd ~ && ls'
```

此别名将允许通过输入 `gohome` 将目录切换到主目录并显示内容。在创建别名时，你必须完全遵循上述的格式，这意味着命令和等号之间没有空格。多个命令通过 `&&` 连接在单引号内。为了获得更健壮的别名，请添加一个函数。下面的示例将 `cd` 和 `ls` 组合成单个命令。

```
function cdls() {
  cd "$@" && ls
}
```

写完别名后，保存文件并重启电脑。你的新命令就可以使用了。

我们编辑的那个文件 `.bashrc` 是 Ubuntu 终端的配置文件。除了制作别名外，我们还可以用它来定制终端设置，例如颜色、大小等。一个小技巧是可以通过删除 `#` 来取消 `#force_color_prompt=yes` 的注释，并确保等号后面是 `yes`。这会为终端添加颜色，使某些单词显示不同的颜色。打开终端时，右键点击它并选择“配置文件”（profiles），然后选择“配置文件偏好”（profile preferences）可以使用更多选项。通过这里的标签页，你可以自定义字体、大小、颜色、背景颜色等。如果你打算经常使用终端，建议对其进行自定义，因为这有助于你熟悉将要操作的工具。

## I/O 重定向

在正常的终端命令执行期间，“正常输入”（由用户输入，或从文件/属性/硬件读取）会被命令输入并解析。有时命令还有“标准输出”，即在终端中显示的返回文本。在 `ls` 中，标准输入是当前工作目录，标准输出是文件夹的内容。

输入和输出通常是直接的，但通过使用 I/O 重定向，我们可以让终端功能更多。例如，`cat` 命令（连接）后跟一个文件会将该文件输出到屏幕。单独运行 `cat` 会打开一个解析器，其中输入的任何行都将立即输出（使用 `ctrl+d` 退出）。但通过 I/O 重定向快捷键（`<`, `>`, `>>`, `|`），我们可以将输出重定向到另一个源，例如文件。`cat > test.txt` 现在会将标准输出放入该新文件中。双符号表示追加，因此 `cat >> test.txt` 将输出置于文件末尾，而不是删除文件开头的内容。

竖线字符或“管道”（pipe）使用了另一种形式的 I/O 重定向，它将一个命令的输出直接插入到另一个命令的输入中。`ls | sort -r` 将获取 `ls` 的输出并排序成反序列表。我们通过重定向输出并将其交给另一个命令来实现这一点。

最后，`grep` 命令在 I/O 重定向中被频繁使用。`grep` 可以在指定文件中搜索特定字符串并将结果返回到标准输出。使用重定向，此输出可以放入其他命令中。Linux 一个值得注意的有趣特性是对象即文件，即使是硬件也是。因此，我们的 CPU 实际上是一个内部存储相关数据的文件，我们可以使用 `grep` 和其他工具对其进行搜索。那个例子相当高级，但这里有一个更简单的实例：

```
grep Conclusion report.txt
```

它将在文件中搜索该特定单词。由于所有这些新符号和命令，I/O 重定向可能会变成一个复杂的过程，但它是你可以整合到脚本和日常使用的功能，通常允许在单行代码中完成 Linux 的某些特性和功能。

Linux 和终端是难以完全掌握的概念。但通过实践和持续的投入，你将能够执行精湛的计算壮举，并完成在 Windows 或 OSX 中无法完成的有用任务。学习更多命令以及如何使用它们对这无疑有帮助，因此请坚持学习新命令及其用法。肯定的是，你唯一需要记忆的命令是 `man`，这是一个显示手册页以及任何其他指定命令的命令。手册页显示了系统上每个命令的开关、示例和预期用途。
利用这个工具并获取关于你系统的深入知识。

最后，Linux 系统不仅限于我们目前看到的界面。每个发行版都有其首选的桌面环境，但界面可以根据个人偏好进行极端定制。终端甚至有文件和网络浏览器，这对于使用 SSH 或远程计算的人非常有帮助。总而言之，你应该尝试安装不同的 DE 并根据你的喜好进行配置。
