**edquota**

This is a quota editor. Users or Groups quota can be edited using this command.

**quota check**

Scan a file system for disk usage, create, check and repair quota files

**setquota**

This is also a command line quota editor.

**quotaon**

This announces to the system that disk quotas should be enabled on one or more file systems.

**quotaoff**

This announces to the system that disk quotas should be disabled off one or more file systems.

**repquota**

This prints a summary of the disc usage and quotas for the specified file systems
