# # Chapter fourteen: UNIX - SHELL INPUT/OUTPUT REDIRECTIONS

Time is precious. It does not make sense to waste time typing a frequently used sequence of commands at a command prompt, more especially if they are abnormally long or complex. Scripting is a way by which one can alleviate this problem by automating these command sequences in order to make life at the shell easier and more productive. Scripting is all about making the computer, the tool, do the work. By the end of this tutorial you will have a good understanding of the kind of scripting languages available for Unix and how to apply them to your problems. UNIX contains many wonderful and strange commands that can be very useful in the world of scripting, the more tools you know and the better you know them, the more use you will find for them. Most of the Unix commands and many of the built-in commands have man pages; man pages contain the usage instructions pertaining to the parent tool.
