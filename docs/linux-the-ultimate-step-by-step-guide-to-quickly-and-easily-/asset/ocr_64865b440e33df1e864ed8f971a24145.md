# ## Erasing Files

Unix uses the command `rm` (ReMove) to delete unwanted files. To remove the file “letter.2” which we have just created, enter:

```
rm letter.2
```

Enter the command `“ls l*”` to display a list of all files beginning with the letter “l.” Note that letter.2 is no longer present in the current directory. The remove command can be used with wildcards in filenames; however, this can be dangerous as you might end up erasing files you had wanted to keep. It is recommended that you use the “-i” (interactive) option of `rm` for wildcard deletes — you will then be prompted to respond with a ‘Y’ or ‘Y’ for each file you wish to delete.
