Root access is disabled by default on many Linux and UNIX like systems. Simply use sudo or su as follows:

```
sudo bash filename.sh
```

Type your password. Another option is to use the su command as follows to become superuser:

```
su -
```

Type root user password and finally run your script:

```
bash filename.sh
```

# ## chmod Command: Run Shell Script In Linux

Another recommended option is to set an executable permission using the chmod command as follows:

```
chmod +x file.sh
```

Now you can run the .sh file.

```
./file.sh
```
