# ## Step 8: Create a Mountpoint

The next step is to create the mountpoint where the root partition will be installed. Depending on your requirements, you might need to put the boot, home and root partitions on different mountpoints. In this instance, we shall only create one mountpoint `/`.

Next, set the **Label** and **Desired Capacity** to whatever you wish. A rule of thumb is to use descriptive names for the label especially if the computer is to be managed by different system administrators. Choose the file system as `ext4` and select the Reformat option.

# ## Step 9: Accept Changes

After Steps 7 and 8 have successfully completed click on **Done** button. A prompt window will appear with a summary of the changes that will take place. If you are satisfied with them click **Accept Changes**.
