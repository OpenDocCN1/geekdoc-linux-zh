# Fonts

Enable font hinting in the *Appearance Panel* to get the best font rendering for your system. Settings > Appearance > Fonts > Enable anti-aliasing + Hinting Slight + Sub-pixel order RGB. This should be enough in Jessie, no need to create a fonts.conf file or install the Infinality engine.

# Themes and icons

GTK Themes, windows decoration and iconsets are the most important elements to customizing your desktop. Start with installing some complementary gtk engines that are needed by some themes:

```
[root] $ apt-get install gtk2-engines-murrine gtk2-engines-pixbuf dmz-cursor-theme
```
