## Options

A large number of Sendmail options are set inside the sendmail.cf file. Chapter 7 describes the Options section of the sendmail.cf file and provides several examples of options. The complete list of options is shown below.

- AliasFile=[type]:path, [type]:path... Specifies the location of the aliases file(s). type is the pathname of the aliases file. type is the aliases database type. Valid types are implicit, hash, dbm, stab (internal symbol table), or nis. The selected database type must be compiled into Sendmail on your system. type defaults to implicit.
- AliasWait=timeout Defines the amount of time Sendmail waits for an @:entry to appear in the aliases database during start-up. The @:entry signals the end of the aliases database.
- AuthMechanisms=list Lists the supported authentication mechanisms.
- ClientOptions=options Defines non-standard settings that Sendmail use as a client. options is a comma-separated list of keyword=value pairs.
- Addr=address Defines the address of the network interface the client uses for outbound connections. The value for address can be written in dotted decimal or as a hostname. By default, any available interface is used.
- Family=protocol Defines the protocol family used for the connection. inet, which is the protocol family for TCP/IP.
- ColonOKnAddr Tells Sendmail to accept colons in e-mail addresses. Colons are always accepted in mail routing (nodename:user) or in RFC 822 group constructs (groupname:member1, member2, ...). By default, this option is enabled.
- ConnectionCacheSize=n is the number of connections that can be cached by this instantiation of Sendmail. The default is two. Four is the maximum. Zero causes connections to close immediately after the data is sent, which is the traditional way Sendmail operates.
- ConnectionCacheTimeout=timeout timeout is the amount of time an inactive cached connection is held. After timeout minutes of inactivity, it is closed. The default is five minutes.
- ConnectionRateThrottle=n Limits the number of incoming connections accepted in any one-second period to n. The default is zero, which means no limit.
- CheckpointInterval=n Causes Sendmail to checkpoint the queue after n items are processed. The default is 10.
- ClassFactor=factor is the multiplier used to favor messages with a header. The default is 1800.
- ClientCertFile=file Identifies the file that contains the certificate used as a client.
- ClientKeyFile=file Identifies the file that contains the private key used as a client.
- Port=port Defines the source port the client uses for outbound connections. port can be specified by number or name. If a name is used, the name is defined in /etc/services. By default, the source port for an outbound connection is generated by the system.
- BlankSub=c Uses the blank substitution character.
- CERTPath=path Defines the path to the directory that contains the certificates.
- CERTificate=filename Identifies the file that contains the certificate authority.
- SndBufSize=size Defines the size of the send buffer.
- RcvBufSize=bytes Defines the size of the receive buffer.
- Modifier=flags Defines the daemon flags for the client. Only one flag, h is available. The h flag tells the client to use the name assigned to the interface on the SMTP HELO or EHLO command.
- ConnectOnlyTo=address Is used only for testing, as it limits all SMTP connections to single destination address.
- AutoRebuild Tells Sendmail to automatically rebuild the database when necessary.
- AliasAliases Adding this check slows down the database.
- server_addr = The IP address of the remote server for the outgoing connection.
- server_name = The name of the remote server for the outgoing connection.
- tls_version = The TLS/SSL version used for the connection.
- verify = The result of the verification process.
