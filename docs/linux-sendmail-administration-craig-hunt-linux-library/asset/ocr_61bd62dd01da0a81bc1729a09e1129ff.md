Unlike Chapter 1, this time the sendmail command is not run with the -t option. Instead, the address of the remote recipient is typed in the command line, and the contents of a file are provided to Sendmail to be used as the mail message. The recipient is craig@foobirds.org and the file is the null device, /dev/null. Clearly, the null device will not provide any real content, so we are in sending an empty message. The sole purpose of this test is to observe the protocol interactions.

> TIP Don't send empty messages to other users just to test e-mail. To test your system, get a free e-mail account explicitly for this purpose and send the tests to yourself at that. To test a specific remote system, make arrangements with the administrator of system before you start test mail.
