# 214 Chapter 7 The sendmail.cf File

Next, run the sendmail command with the -C option to use the newly created test.cf configuration file. The -Coption permits you to specify the Sendmail configuration file on the command line.

```
# sendmail -bt -Ctest.cf
ADDRESS TEST MODE (ruleset 3 NOT automatically invoked)
Enter <ruleset> <address>
/tryflags HS
/try smtp craig
Trying header address sender craig for mailer smtp
canonify input: craig
Canonify2 input: craig
Canonify2 returns: craig
canonify returns: craig
1 input: craig
1 returns: craig
HdrFromSMTP input: craig
PseudoToReal input: craig
PseudoToReal returns: craig
qSMTP returns: craig < @LOCAL*>
MasqSMTP input: craig < @LOCAL*>
Masqdr returns: craig < foobirds .org >
Masqdr returns: craig < foobirds .org >
HdrFromSMTP input: craig < foobirds .org >
final returns: craig < foobirds .org >
final returns: craig @ foobirds .org
Rcode = 0, addr = craig@foobirds.org
> ^D
```

This test tells you the value entered in the M macro is to rewrite the sender address in the message header. You know this because the only change made to the sendmail.cf file was a value for M, and now the address returned from ruleset final is craig@foobirds.org. This is what you wanted.

Don't make changes directly to the sendmail.cf file if you can avoid it. If you're called upon to help configure Sendmail on a system that doesn't already have the m4 source file installed, it may be easier to directly edit the sendmail.cf file, but only if the change is very small. If you really want to make major Sendmail configuration changes, use m4 to build your configuration.
