# The local-host-names File

In Chapter 5, both the generic Linux configuration and the Red Hat configuration contain the FEATURE(use_cw_file) command. That feature reads the /etc/mail/local-host-names file and adds the hostnames listed there to the hostnames and addresses defined in class w. 5.4 in Chapter 5 shows that, by default, class w contains the special name localhost, the special address 127.0.0.1, and the system's IP addresses, full domain names, and unqualified hostnames. Anything you put in local-host-names is added to these default values.

The system checks w to decide whether or not it should accept inbound mail for local delivery. The Sendmail server only accepts mail for local delivery that is addressed to the server. Yet many systems use the Sendmail as a mailbox server to collect and hold their. If the mail that the server collects and hold is literally addressed to another system, the name of that system needs to be added to class w, the other system's hostname is treated by Sendmail as if it were hostname alias for mer. Mail addressed to systems listed in class w is accepted as if it were mail addressed to the server. An example will make this clear.

Assume that robin.foobirds.org is a PC that uses the server wren.foobirds.org as a mailbox to collect and hold mail. An MX record is placed in the DNS server that directs robin's mail to wlen. Listing 6.3 shows what happens when login on bear.mammals.foobirds.org sends mail to wlen till login on bear class is updated.
