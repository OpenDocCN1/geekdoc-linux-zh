FEATURE(always_add_domain) This feature adds the hostname of the system to all local mail. With this feature enabled on a server named ibis.foobirds.org, mail from the local user craig to the local user kathy would be delivered as mail from craig@ibis.foobirds.org to kathy@ibis.foobirds.org.

FEATURE(bestmx_is_local) With this feature, addressed to any host that lists the Sendmail server as its MX server is accepted by the Sendmail server as local mail.

The DNS macros:

CANONIFY(domain) This macro defines a domain name that will be passed for DNS conversion to its canonical form even if canonify feature is in use. Computers can be known by aliases. The official domain name of a host stored in DNS is called its canonical name. This macro is generally used to generate canonification of the local domain when canonify is in use.

CANONIFY_DOMAIN_FILE(filename) This macro identifies a file containing a list of domain names that should be converted to canonical form even if canonify has selected.

LOCAL_DOMAIN(alias-hostname) This macro defines an alias for the local host. Mail addressed to the alias will be accepted as if it were addressed directly to the local host.

The macros and features described in this section are not limited to the DOMAIN file. They can appear in any m4 source file, and in fact, are often found in the macro control file. I listed them here because they are most naturally associated with the DOMAIN file. I took my cue in here from the documentation in the cf/cf/README file.

# MAILER

The MAILER macro points to an m4 source file that contains the configuration commands that define a Sendmail mailer. A least one MAILER command must appear in the configuration file. Generally, more than one MAILER command is used.

It is possible that you will need to customize a file location in an OSTYPE file or that you will need to define domain-specific information in a DOMAIN file, but unless you develop your own mail delivery program you will not need to create a MAILER source file. Instead, you will need to invoke one or more existing files in your macro configuration.
