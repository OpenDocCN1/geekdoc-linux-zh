
The example shows the m4 command format used to build a sendmail.cf file. The path ../m4/cf.m4 is the path to the m4 source tree required to build a sendmail.cf file. This must be specified on the m4 command line if it is not included in the macro configuration with an include command. Notice that the pathname is a relative pathname starting with ./. Older versions of m4 actually required a relative pathname. Changing to the cf/cf directory was not a convenience; it was a necessary part of running m4 with the correct source tree path. This is no longer necessary on Linux systems. The GNU m4 program used Linux can accept an absolute pathname for this argument, which means that the macro configuration file can be stored anywhere on the system. Red Hat takes advantage of this fact when installing Sendmail via RPM. RPM takes a copy of the Red Hat configuration file in /etc/mail and includes an absolute pathname to cf.m4 inside the macro configuration file.

The second command-line argument is the name of the new macro configuration file, test.m4 reads the source files ../m4/cf.m4 and test.m4, and it outputs the file .cf. The file output by the m4 command is in the correct format for a sendmail.cf.
