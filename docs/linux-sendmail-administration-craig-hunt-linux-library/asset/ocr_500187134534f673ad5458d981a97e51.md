# Listing 9.6 LOCAL_CONFIG Example

```
LOCAL_CONFIG
### Store host name in variable A
DANs.foobirds.org
### Define a special NIS database
knshoosts -ni hosts.byname
```

Listing 9.6 assumes that A is a private variable and that hosts is a private database. The LOCAL_CONFIG example in Listing 9.6 is contrived, but it shows the format used by all of the macros covered in this section. Each macro is a keyword that marks the start of a variable-length block of text. The block of text ends when the next m4 macro is encountered. The variation between the macros covered in this section is that each one enters the text into a different part of the sendmail.cf file.

The MAILER_DEFINITIONS macro is used to define a mailer and add it to the Mailer Definitions of the sendmail.cf file. The mailer is defined by the M command described in Chapter 7. If any rules are required by the mailer, they are also defined in the text that follows the MAILER_DEFINITIONS macro.

To add individual rules to rules 0, 1, 2, or 3, use the LOCAL_RULE_n macro. The n in the name of this macro is the number of the ruleset to which rules should be added. Listing 9.7 shows being added to rules 1, which is also called the sender ruleset.
