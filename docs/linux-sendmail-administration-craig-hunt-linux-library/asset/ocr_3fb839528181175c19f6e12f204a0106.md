confMAX_HEADERS_LENGTH Defines the maximum length of the sum of all headers in bytes. [MaxHeadersLength]

confMAX_HOP Defines the counter used to determine mail loops. Defaults to 25. [MaxHopCount]

confMAX_MESSAGE_SIZE Sets the maximum size for a message the server accepts by default, no limit is set. [MaxMessageSize]

confMAX_MIME_HEADER_LENGTH Defines the maximum lngrith of MIME headers. [MaxMimeHeaderLength]

confMAX_QUEUE_RUN_SIZE Defines the maximum number of entries processed in a single queue. Defaults to 0, which means process every the queue. [MaxQueueRunSize]

confMAX_RCPTS_PER_MESSAGE Defines the maximum number of recipients allowed for a piece of mail. [MaxRecipientsPerMessage]

confMCI_CACHE_SIZE Sets the number of open connections that can be cached. Defaults to 2. [ConnectionCacheSize]

confMCI_CACHE_TIMEOUT Sets the maximum amount of time inactive open connections are held in the cache. Defaults to 5m. [ConnectionTimeout]

confME_TO True tells Sendmail to send a copy of the mail to the sender. Default is false. [MeTo]

confMIME_FORMAT_ERRORS True tells Sendmail to send to MIME-encapsulated messages. The default is true. [SendMimeErrors]

confMINT_FREE_BLOCKS Sets the minimum number of blocks that must be available on the disk to accept mail. Defaults to 100. [MinFreeBlocks]

confMINT_QUEUE_AGE Sets the minimum time a job must be queued. Defaults to 0. [MinQueueAge]

confMUST_QUOTE_CHARS Adds characters to the list of characters that must be quoted when they are included in the user's name ($). The characters @,;:[] are always quoted. By default and ' ' are added to the list. [MustQuoteChars]

confNO_RCPT_ACTION Defines handling for mail with no recipient headers. Possible values are:

+   - Do nothing
- add-to Add To: header
- add-apparent-to Add An Apparently-To: header
- add-bcc Add a Bcc: header
- add-to-undisclosed Add a To: undisclosed-recipients header
