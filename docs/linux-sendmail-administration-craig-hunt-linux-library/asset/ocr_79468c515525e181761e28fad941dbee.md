> NOTE Throughout this text the “variable” is used to refer to the indirect values used in the sendmail.c file. Sendmail documentation calls these same variables “macros.” We call them variables to avoid confusing them with the m4 macros. However, when you refer to the Sendmail documentation you should be aware of the fact that these same values will be called macros.

# Table C.1 Reserved Variables with Single-Character Names

 f | The sender address. |
 F | The name of the FAX relay. |
