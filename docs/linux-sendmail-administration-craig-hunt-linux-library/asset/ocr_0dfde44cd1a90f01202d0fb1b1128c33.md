confSAVE_FROM_LINES Tells Sendmail to discard Unix lines, which is the
 practice. [SaveFromLine]

confSEPARATE_PROC Tells Sendmail to deliver messages with separate processes. Defaults to false. [ForkAhJob]

confSERVER_CERT Identifies the file that contains the cryptographic certificate used
when this system acts as a server. [ServerCertFile]

confSERVER_KEY Identifies the file that contains the private key associated with the
cographic certificate used when this system acts as a server. [ServerKeyFile]

confSERVER_SWITCH_FILE Defines the path to the service switch file. Defaults to
/etc/mail/service.switch. [Serviceswitch]

confSEVEN_BIT_INPUT True inputs to seven bits. The default is false.
[SevenBitInput]

confSINGLE_LINE_FROM_HEADER True forces a multiline From: to a single line.
The default is false. [SingleFromFileHeader]

confSINGLE_THREAD_DELIVERY True forces single-threaded mail delivery if
hostStatusDirectory is also defined. The default is false.
[SingleThreadDelivery]

confSMTP_LOGIN_MSG Defines the SMTP greeting message. Defaults to $j
Sendmail $/$; [SmtpGreetingMessage]

confSMTP_MAILER Defines the mailer for SMTP connections; must be smtp,
smt8, or esmtp. Defaults to esmtp.

confTEMP_FILE_MODE Sets the file mode for temporary files. Defaults to 0660.
[TempFileMode]

confTIME_ZONE Sets the time zone from the system (USE_SYSTEM) or the TZ variable
(USE_TZ). Defaults to USE_SYSTEM. [TimeZoneSpec]

confTIMEOUT_COMMAND Sets the maximum time to wait for a command. Defaults to 1h.
[Timeout.command]

confTIMEOUT_CONNECT Sets the maximum time to wait for a connect. [Timeout.connect]

confTIMEOUT_CONTROL Sets the maximum amount of time allowed for a control socket
trans to complete. The default is two minutes (2m). [Timeout.control]

confTIMEOUT_DATABLOCK Sets the maximum time to wait for a block during DATA phase.
Defaults to 1h. [Timeout.datablock]

confTIMEOUT_DATAFINAL Sets the maximum time to wait for a response to the terminat-
ing ". Defaults to 1h. [Timeout.datafinal]

confTIMEOUT_DATAINIT Sets the maximum time to wait for a DATA command response.
Defaults to 5m. [Timeout.datinit]
