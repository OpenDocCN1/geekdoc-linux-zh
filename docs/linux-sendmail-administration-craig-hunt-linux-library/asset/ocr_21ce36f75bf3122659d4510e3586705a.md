ClientCertFile=file Identifies the file that contains the certificate used by Send-

ClientKeyFile=file Identifies the file that contains the private key used by Send-
mail it acts as a client.

ClientPortOptions=options Defines non-standard settings that Sendmail use
acting as an SMTP client. options is a comma-separated list of
keyword=value pairs. Valid keyword=value pairs are:

Port=port Defines the source port the client uses for outbound con-
nections. port can be specified by number or name. If a name is used, the name
 be defined in /etc/services. By default, the source port for an outbound
connection is generated by the system for the connection.

Addr=address Defines the address of the network interface the client uses for
outbound connections. The value for address can be written in dotted decimal
otation or as. By default, any available interface is used.

Family=protocol Defines the protocol family used for the connection. inet,
which is the, the protocol family for TCP/IP.

SndBufSize=size Defines the size of the send buffer.

RcvBufSize=bytes Defines the size of the receive buffer.

Modifier=flags Defines the daemon flags for the client. Only one flag, h is,
aavailable. The h flag tells the client to use the name assigned to the interface on
t SMTP HELO or EHLO command.

ColonOKnAddr Tells Sendmail to accept colons in e-mail addresses. Colons are
always accepted in mail routing (nodename:user) or in RFC 822 group
constructs (groupname:member1, member2, ...). By default, this option is
enabled.

ConnectionCacheSize=n is the number of connections that can be cached by this
stantiation of Sendmail. The default is two. Four is the maximum. Zero causes
connections to close immediately after the data is sent, which is the traditional way
t Sendmail operates.

ConnectionCacheTimeout=timeout timeout is the amount of time an inactive
cached connection is held. After timeout minutes of inactivity, it is closed. The
def is five minutes.

ConnectionRateThrottle=n Limits the number of incoming connections accepted
in any one-second period to n. The default is zero, which means no limit.

ConnectOnlyTo=address Is used only for testing, as it limits all SMTP connections
to single destination address.
