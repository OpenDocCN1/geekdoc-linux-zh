file for the Red Hat configuration is found in the /usr/lib/sendmail-cf/cf sendirectory. It is pretty easy to locate. Among the generic files is one simply named redhat.mc. This is the file we are looking for. Change to /usr/lib/sendmail-cf/cf and cat that file.

```
[craig]$ cat /usr/lib/sendmail-cf/cf
[craig]$ cat redhat.mc
```

dnl This is the macro config file used to generate
dnl /etc/ sendmail.cf file. If you modify the file you will have to
dnl regenerate the /etc/sendmail.cf by running this macro config
dnl through the m4 preprocessor:

```
dnl m4 /etc/sendmail.mc > /etc/sendmail.cf
```
