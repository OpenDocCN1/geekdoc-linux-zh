These essential pieces of information must be identified to Sendmail in the configuration.
The path to the directory where certificates are stored is defined by the confPATH parameter, and the certificate for a single CA is defined using the confCACERT parameter. Both can be used in the m4 configuration file—for example:

```
define(`confCACERT`, `/etc/httpd/conf/ssl.crt`)
define(`confCACERT`, `/etc/httpd/conf/ssl.crt/verisin.crt`)
```

In this example, we use the same certificate directory that was already set up for the Apache server on our system. This is, however, completely arbitrary. Certificates can be stored anywhere as long as the directory and the certificates in the directory can be written by root.

In addition to information about CA certificates, Sendmail needs to know about the public and private keys it should use to identify and encrypt its own communication. Sendmail uses a different set of public and private keys depending on whether it is acting as a server or a client. These values are defined by four m4 parameters:

a value for the ServerCertFile option. The ServerCertFile option identifies the file that contains the X.509 certificate used when Sendmail acts as a server. In effect, this is the server's public key. For example:

```
define(`confSERVER_CERT`, `/etc/httpd/conf/ssl.crt`)
```

a value for the ServerKeyFile option. The ServerKeyFile option identifies the file that contains the private key used when Sendmail acts as a server. The confSERVER_KEY parameter could be defined as follows:

```
define(`confSERVER_KEY`, `/etc/httpd/conf/ssl.crt/server.key`)
```

a value for the ClientCertFile option. The ClientCertFile identifies the file that contains the X.509 certificate used when Sendmail acts as a client. In effect, this is the client's public key. The following example points to the Apache SSL directory:

```
define(`confCLIENTCERT`, `/etc/httpd/conf/client.crt`)
```

a value for the ClientKeyFile option. The ClientKeyFile option identifies the file that contains the private key used when Sendmail acts as a client. A following command tells Sendmail where the client's private key is:

```
define(`confCLIENT_KEY`, `/etc/httpd/conf/client.key`)
```

In the examples above, we used the same certificates and keys for Sendmail that we used for Apache. This is possible, but only if you run Sendmail and Apache on the same server.
