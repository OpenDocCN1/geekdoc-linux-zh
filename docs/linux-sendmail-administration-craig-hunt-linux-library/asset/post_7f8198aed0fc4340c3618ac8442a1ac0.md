# A Basic Mail Message

The format of the e-mail message is defined in RFC 822 (“Standard for ARPA Internet Text Messages\”). According to RFC 822, an e-mail message consists of two parts: headers and a message body. As the names imply, the headers come at the head of the message before the message body. The message body is separated from the headers by a blank line—a line that contains nothing but a carriage return/feed (CRLF) character. The message body is composed of lines, each of which contains fewer than 1000 bytes of seven-bit ASCII text.

# Message Headers

Headers are individual lines of text that begin with a header name (also called a field name in RFC 822) separated by a colon from the variable data related to that header (this data is also called the *field body* in the RFC). Headers provide a record of information used to deliver the mail. Headers tell you whom a message is bound for, where it came from, when it was sent, and what computers handled the message as it moved through the network.

Message headers are distinct from the envelope headers we see in the SMTP protocol exchanges. Envelope headers are limited to the From: and To: addresses. There are From: and To: headers in the message, but there are also a large number of other possible headers, which provide more information about how a message was handled while observing the SMTP interaction does.
