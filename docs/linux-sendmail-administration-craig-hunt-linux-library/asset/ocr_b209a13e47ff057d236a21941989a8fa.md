Frankly, I prefer to look at variables one at a time with the $ command syntax. I find the full list overwhelming. I prefer to work methodically, with one variable at a time, using a reference to remind me of what the variable does. (The sendmail.cf variables are listed and described in Appendix C, "Sendmail Variables, Options, and Flags.") debug level 35.9 is useful for people who can sort out the wheat from the chaff, and it has the advantage of showing the variables as they are being set and reset. Notice that this instantiation of Sendmail is identified as a4EExn100755. Clearly that is a real-time variable because it contains the PID of this specific Sendmail process. Also notice the redefines of DeliveryMode as changes from background mode, which address test modes during initialization, to interactive mode. DeliveryMode is not specifically a variable. It can also be treated as an option.

Debug level 37.1 is similar to 35.9 that it shows the values for options instead of variables. Listing 10.17 shows the output from our sample Hat system.
