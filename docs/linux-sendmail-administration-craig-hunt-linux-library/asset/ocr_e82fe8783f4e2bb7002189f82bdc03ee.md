Table B.1 lists 30 command-line switches, most of which you will never use, although you never know when you will need a quick reference on one of them. Several are redundant forms of other switches, some of which are outdated. Perhaps the best known switch that is outdated is the -bz switch. At one time it was used to process the sendmail.cf file and store a copy of the processed file, which was called a "frozen" switch in Sendmail. The idea was that storing the processed configuration would enhance speed. This outdated switch no longer works. If you come to Linux from an older Unix system, you might mistakenly believe you need this switch. Attempting to run it on a Linux system will just return an error.

While the function of the -bz switch is no longer needed, other outdated switches have useful functions, but those functions are handled by other switches. For example, -c, -e, -I, -m, -r, and -t are all deprecated switches that have been replaced by newer switches. All of the switches that set sendmail.cf option those that are not deprecated, such as -i and -o, can be replaced by the -0 switch. For example, the command line

```
sendmail -m -s mail.file
```

could be replaced by

```
sendmail -OMeToo=true -OSaveFrom=true mail.file
```

The new form may appear a little long-winged, but the -0 switch provides the distinct advantage of being able to set any sendmail.cf option. Switches as -m and -s set only one option each. Additionally, most administrators find the new format easier to read and comprehend, particularly when the sendmail command is included inside a script.

Clearly, most of the switches in Table B.1 will not be useful for your configuration. The switches that you are most likely to use are:

+   -bd Every time Sendmail is run from a start-up script, this switch is used. It starts Sendmail as a background daemon that listens for inbound mail on TCP port 25. This causes Sendmail to receive inbound mail. Without it, Sendmail only sends mail.

+   -q[argument] This switch is used every time Sendmail is run from a start-up script. The -q switch causes Sendmail to process the mail queue. If entered on the command line without an associated argument, the queue is processed immediately. The optional argument can schedule queue processing for a specific interval--every, 15 minutes (-q15m) or every hour (-q1h).
