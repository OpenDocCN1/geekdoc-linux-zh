Error messages start with the keyword error, which is the name of a special mail
that is built into Sendmail. Separated by a colon from the keyword error is an error con-
dition, specified either as a keyword or as a DSN code. The DSN code can be any value
code defined in RFC 1893. The error condition keyword must be a keyword recognized
y by the error mailer. A list of valid error condition keywords is found in Chapter 8,
“Understanding Rewrite Rules,” in the discussion of the error mailer.

+   TIP DSN codes are an Internet standard and well defined in the
RFC. The error condition keywords are internal to Sendmail and subject to change
in future releases.
