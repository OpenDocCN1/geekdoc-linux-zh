always_add_domain This feature tells Sendmail to add the domain name to locally delivered mail. By default, a username is sufficient for local delivery. A quick test illustrates the effect always_add_domain has on a local address:

```
[root]# sendmail -bt -Cgeneric-linux.cf
ADDRESS TEST MODE (ruleset 3 NOT automatically invoked)
```
