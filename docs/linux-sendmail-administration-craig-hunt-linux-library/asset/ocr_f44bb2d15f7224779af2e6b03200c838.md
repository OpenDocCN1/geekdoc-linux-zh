However, from the point view of the system administrator, the category and level numbers are insignificant. In reality, debug levels are simply arbitrary numbers, a few of which produce useful information.

A few debug levels in category 0, the category that prints information about the Sendmail version, are useful. We saw an example of debug level 0.1 in Chapter 6. Two other category 0 debug levels that I sometimes use are 0.4 and 0.10. Listing 10.15 shows the information printed by debug level 0.10.
