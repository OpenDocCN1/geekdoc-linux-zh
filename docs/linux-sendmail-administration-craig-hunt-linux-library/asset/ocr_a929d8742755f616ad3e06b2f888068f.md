# Chapter 6 Using Sendmail Databases

However, simple forwarding is not the primary use for the .forward file. A much more common use for this file is to invoke special mail processing before mail is delivered to your personal mail account. Chapter 11, “Stopping Spam,” illustrates this when procmail and mail filtering are discussed.

The aliases database and the .forward file are the default files used to process user addresses. Sendmail will use both of these files if it finds them. There is no need to define them inside the Sendmail configuration; they are used by default. There is also an optional database that can be used to process users’ addresses. It is the user database, and it is our next topic.

# The User Database

The user database is available to Sendmail only if Sendmail is compiled with the USERDB compiler flag and the path to the user database is defined inside the Sendmail configuration using the USERDB_SPEC option. Listing 6.1 shows that the Sendmail delivered with the Red RPM has the USERDB compiler flag set, and in Chapter 5 we saw that the redhat.mc file contained the following default command:

```
define(`CONUSERDB_SPEC`, `/etc/mail/userdb.db`)
```

From these things, we know that we can use the user database on our sample Red Hat system. If your system doesn’t meet both of these conditions, you can’t use this database until you update the configuration.

Sendmail applies the user database to inbound mail after the aliases database and before the .forward file. Unlike the aliases and .forward file, the user database can also be applied to outbound mail to transform the sender address and, in effect, create a reverse alias. Listing 6.6 shows a realistic user database file based on the last four lines of the aliases database in Listing 6.5.

+   Listing 6.6 A Sample User Database File

```
[root]# cd /etc/mail
[root]# cat userdb
andy.wright:maildrop andy
andy:mailname andy.wright@foofirds.org
sara.henson:maildrop sara
sara:mailname sara.henson@foofirds.org
kathy.McCafferty:maildrop kathy
kathleen.McCafferty:maildrop kathy
kathy:mailname katheleen.mccafferty@foofirds.org
[root]# makemap btree userdb.db < userdb
```
