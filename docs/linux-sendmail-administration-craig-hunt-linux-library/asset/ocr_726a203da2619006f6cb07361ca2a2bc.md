# 374 Appendix m4 Macro Command Reference

confTO_FILEOPEN Sets the maximum time to wait for a file to open. Defaults to 60s. [Timeout.fileopen]

confTO_HELLO Sets the maximum time to wait for a HELO or EHLO response. Defaults to 5m. [Timeout.helo]

confTO_HOSTSTATUS Sets the timer for stale host information. Defaults to 30m. [Timeout.hoststatus]

confTO_CONNECT Sets the maximum time to wait for the very first connect attempt to a host.

confTO_IDENT Sets the maximum time to wait for an ident query. Defaults to 30s. [Timeout.ident]

confTO_INITIAL Sets the maximum time to wait for the initial connect response. Defaults to 5m. [Timeout.initial]

confTO_MAIL Sets the maximum time to wait for a MAIL command response. Defaults to 10m. [Timeout.mail]

confTO_MISC Sets the maximum time to wait for other SMTP command responses. Defaults to 2m. [Timeout.misc]

confTO_QUEUERTURN_NONURGENT Sets the "Undeliverable" timeout for low priority messages. [Timeout.queuerturn.non-urgent]

confTO_QUEUERTURN_NORMAL Sets the "Undeliverable mail" timeout for normal priority messages. [Timeout.queuerturn.normal]

confTO_QUEUERTURN_URGENT Sets the "Undeliverable mail" timeout for urgent priority messages. [Timeout.queuerturn.urgent]

confTO_QUEUEWARN Sets the time until a message is returned from the queue as undeliverable. Defaults to 5d. [Timeout.queueewarn]

confTO_QUEUEWARN_NONURGENT Sets the time until a "still queued" warning is sent for low priority messages. [Timeout.queewarn.non-urgent]

confTO_QUEUEWARN_NORMAL Sets the time until a "still queued" warning is sent for normal priority messages. [Timeout.queewarn.normal]

confTO_QUEUEWARN_URGENT Sets the time until a "still queued" warning is sent for urgent priority messages. [Timeout.queewarn.urgent]

confTO_QUEUEWARN Sets the time until a "still queued" warning is sent about a message. Defaults to 4h. [Timeout.queewarn]

confTO_QUIT Sets the maximum time to wait for a QUIT command response. Defaults to 2m. [Timeout.quit]

confTO_RCPT Sets the maximum time to wait for a RCPT command response. Defaults to 1h. [Timeout.rcpt]
