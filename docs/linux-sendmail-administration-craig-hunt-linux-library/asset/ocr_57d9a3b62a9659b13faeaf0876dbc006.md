The last line in Listing 6.10 shows that the detail value in the +detail syntax can be
passed to the outbound address as %2. Mail sent to sales+info@thatplace.com would be
divered to info@newplace.com, and mail to sales+orders@thatplace.com would be deliv-
er to orders@newplace.com. Notice that the use of +detail syntax must be indicated
the first field of the virtuertable by placing * before in the virtual
domain address. Users find e-addresses complex enough without using the +detail
syntax. For this reason, the syntax is rarely used unless you have a program that auto-
matically generates this for the user. It is covered for the sake of completeness,
but you will probably not use it in your configuration.

Before the virtuertable can be used by Sendmail, it must be turned into a hash data-
basing using makedmap. Listing 6.11 shows a successful build and test of the virtuertable
database.
