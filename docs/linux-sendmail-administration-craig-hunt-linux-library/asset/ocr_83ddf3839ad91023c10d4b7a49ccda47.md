It verifies this through the aliasing process by checking whether or not the name is a local login or valid alias. If it is not one of these things, the name is not considered local and is rejected. The name appeared to be local but wasn't—it was an apparently local name. It is possible to configure Sendmail to send mail addressed to apparently local users to a relay server. Use the USER_RELAY macro to define the server if you want to do this. The following command would forward all apparently local users to the server wren.foobirds.org for processing:

```
USER_RELAY(wren.foobirds.org).
```

An USER_RELAY is most useful in an organization where every user has a unique user-name. When that is the case, mail can be addressed to the unique name of any user in the entire organization without adding the host part of the address. The Sendmail client detects that the address is apparently local, and sends the mail to the USER_RELAY. The relay server must know how to deliver the mail to the correct user.

One macro that you will occasionally see discussed for local mail relay is the LOCAL_RELAY macro. You should ignore it. This is a deprecated macro that has been superseded by the MAIL_HUB macro. LOCAL_RELAY should not be in your configuration.

Finally, there are special servers for non-SMTP mail. These are:

define (UUCP_RELAY, mail:server) The server is the name of the system that handles UUCP mail for all UUCP sites that are not directly connected to the local host. The mail defaults to relay. It is very common to send UUCP mail from the client to the server using SMTP by the relay mail. The server then forwards the mail through UUCP. The argument provided to the UUCP_RELAY option is stored in sendmail.cf variable Y.

define (FAX_RELAY, mail:server) The FAX_RELAY option identifies the server to deliver mail addressed to the pseudo-domain .FAX, which is obviously an external fax server. With this option, users can address mail to a fax machine by using the syntax experts by the external fax server and the FAX domain. server is the name of the external fax server and mailer is the mailed used to reach that server. mailer defaults to relay.
