# Testing with the /parse Command

The /parse command canifies and parses an address, creating the mail delivery triple. It prepares the address for delivery based on the mailer selected for the mail delivery triple. Listing 10.9 shows the /parse command in action.

+   10.9 Processing an Address with the /parse Command

```
[root]# sendmail -bt
ADDRESS TEST MODE (ruleset 3 NOT automatically invoked)
Enter <ruleset> <address>
> /parse al@bird.org
Cracked address = $
```
