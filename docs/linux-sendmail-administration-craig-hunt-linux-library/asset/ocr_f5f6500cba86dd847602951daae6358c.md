# Recursion and Flow Control

After rewriting, the address is again compared to the pattern. The address in Figure 8.2 fails to match the pattern second time through because it no longer contains the literal ! Sometimes, the recursive nature of rewrite rules is used to create iterative processing. Listing 8.5 shows this with a simple ruleset designed to remove nested angle brackets.

# Listing 8.5 The Recursive Nature of Rewrite Rules

```
[root]# cat >> test.cf
SRRemoveAngles
R$ < $ > $1 $2
[root]# sendmail -bt -Ctest.cf
ADDRESS TEST MODE (ruleset 3 NOT automatically invoked)
nEnter <address>
> RemoveAngles craig<<@wren>>>
RemoveAngles input: craig <<@ wren > >
RemoveAngles returns: craig @ wren
> ^D
```
