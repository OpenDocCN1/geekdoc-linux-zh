The -M command prints out all the mail definitions in the current Sendmail configuration. All of the fields displayed by -M are the fields discussed in the "Miler Definitions" section of Chapter 7, The "sendmail.cf File". But there are quite of interesting things displayed by the -M command that cannot be found simply by perusing the sendmail.cf file. First, you'll notice that each mailer has an identifying number as well as a name. Second, and more important, there are two mailers that do not appear in sendmail.cf file:

+   *file The *file mailer is an internal mail used to send the contents of a mail message directly to a file.
*include The *include is an internal mail that attaches the mail saga to a :include list.
