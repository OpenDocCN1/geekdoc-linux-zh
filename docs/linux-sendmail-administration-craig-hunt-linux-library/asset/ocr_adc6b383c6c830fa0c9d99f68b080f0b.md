Most of these files—more than 30 of them—are sample macro control files. You can identify a control file by the .mc extension. Some are examples meant as educational tools. But most are prototypes or generic files to be used as the basis of your own configuration. Particularly interesting are the generic files designed for Solaris, HPUX, BSD, Linux, and several other operating systems are included. For a Linux system administrator, the generic-linux.mc file is the one that gathers the most attention.

Several of files are identified by the .cf extension. These files are the result of processing macro configuration files through make and are already in the proper format to be used as the sendmail.cf file. It is unlikely, that you will use one of these files directly. Unless the generic configuration file is exactly to yours, the Sendmail configuration file produced from that .mc file will not be what you want.
