Again we start with the test.cf file created in Chapter 4. To add a new ruleset call TokenTest, which contains only one rewrite rule. We then run the sendmail command with -bt and -Cest.cf to test the new configuration.

When the address plover!karen.ramsey matched the pattern $+!$, two indefinite tokens were created. The first is identified as $1 and the single token plover that matched the first $+ symbol. The second indefinite token is $2 and the three tokens, karen, ., and ramsey, that matched the second $+ symbol. The indefinite tokens created by the pattern matching by name ($1 and $2) in the template portion of the R command to rewrite the address.

The template contains the indefinite token $2, a literal @, indefinite token $1, a literal dot (.), and the variable value $m. After the pattern matching, $2 contains karen.ramsey and $1 contains the name of the domain of which the local system is part. Listing 8.4 shows that $m returns foobirds.org on the sample system. Listing 8.4, the input address plover!karen.ramsey is rewritten as ramsey@plover.foobirds.org.
