# Chapter 12 Sendmail Security

By default, Sendmail sends no upper limit on the number of child processes that can be launched to process mail. To limit Sendmail to two hundred children, put the fol-lowing command in the m4 macro configuration file:

```
define(`confMAX_DAEMON_CHILD`, `200`)`dn1
```

With this setting, Sendmail accepts mail only when fewer than two hundred children are running. This is not a recommended value; it study the actual usage patterns of your system before you select a value, and then set the value at least 50 percent above the observed maximum value to allow for usage spikes. confMAX_DAEMON_CHILD is most useful for systems that do more than just provide Sendmail service. A great place to use this parameter is on a Linux desktop system that runs its own Sendmail server. A desktop system has a relatively light e-mail workload and it provides many other services to the user of the desktop. The confMAX_DAEMON_CHILD parameter protects the other services from runaway Sendmail daemons. It makes sure that the user can still open an X window or editor if the Sendmail server is under attack. confMAX_DAEMON_CHILD provides this protection for the other services at the cost of making it the maximum number of children shuts the SMTP port. Use this parameter carefully.

confCONNECTION_RATE_THROTTLE This defines the maximum number of SMTP connections that are permitted for any one-second period. Like the confMAX_DAEMON_CHILDREN parameter, the confCONNECTION_RATE_THROTTLE parameter protects the server from being overwhelmed by e-mail. Neither of these parameters protects Sendmail from attack; both protect the system when Sendmail is under attack.

By default, Sendmail sets no limit on the rate at which SMTP connections can be made. It is designed to handle connections as they arrive. To limit Sendmail to ten new connections per second, put the following command in the m4 macro configuration file:

```
define(`confCONNECTION_RATE_THROTTLE`, `10`)`dn1
```

With this setting, Sendmail rejects any new connections after the first ten in any one-second period. As before, this is not a recommended value; it is just an example.
