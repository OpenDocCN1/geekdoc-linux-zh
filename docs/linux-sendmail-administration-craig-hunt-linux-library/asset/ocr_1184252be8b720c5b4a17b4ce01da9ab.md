cfBLANK_SUB Defines the character used to replace unquoted blank characters in e-mail addresses. [BlankSub]

cfCACERT Identifies a file containing a cryptographic certificate from a certificate authority. [CACERTFile]

cfCACERT_PATH Defines the path to the directory that contains cryptographic certificates. [CACERTPath]

cfCF_VERSION Sets the Sendmail version number. [$S]

cfCHECKPOINT_INTERVAL Sets the maximum number of queued items processed before Sendmail checkpoints. The Default is 10. [CheckpointInterval]

cfCHECK_ALIASES Looks up every alias via the aliases database build. Default is false. [CheckAliases]

cfCLIENT_CERT Identifies the file containing the cryptographic certificate Sendmail uses when it acts as a client. [ClientCert]

cfCLIENT_KEY Identifies the file containing the private key associated with the certificate used when Sendmail acts as a client. [ClientKeyFile]

cfCLIENT_OPTIONS Defines the port options for outbound SMTP connections. [ClientPortOptions]

cfCOLON_OK_IN_ADDR Tells Sendmail to treat colon regular characters in addresses. Default is false. [ColonOkInAddr]

cfCONNECTION_RATE_THROTTLE Sets the maximum number of connections permitted per second. [ConnectionRateThrottle]

cfCONNECT_ONLY_TO Defines connectivity. Only needed when Sendmail is tested by the developers. This is not used in production environments. [ConnectOnlyTo]

cfCONTROL_SOCKET_NAME Defines a socket for managing the Sendmail daemon. [ControlSocketName]

cfCONFIG_EXPENSIVE Tells Sendmail to hold mail for mailers that have the flag set until the next queue. Defaults to false. [HoldExpensive]

cfCOPY_ERRORS_TO Sets the e-mail address that receives error messages. [PostmasterCopy]

cfCR_FILE Points to the file that lists the hosts for which this server will relay mail. Defaults to /etc/mail/relay-domains. [$R]

cfCT_FILE Defines the file of trusted users. Defaults to /etc/mail/trusted-users. [$t]

cfCW_FILE Points to the file of local host aliases. Defaults to /etc/mail/local-host-names. [$w]
