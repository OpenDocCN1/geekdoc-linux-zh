# The Basic Commands

In terms, there are two types of files used to build an m4 configuration. One of these
is the macro configuration file, which is traditionally identified by the .mc extension.
macro configuration file is the input file for the m4 command, and its name appears
the m4 command line. The other files are m4 source files that are referenced by the
macro configuration file. Traditionally, m4 source files are given the file extension .m4.
Almost all m4 commands from Table 4.1 can appear in either type of file, although
the three of the commands are generally found only in the macro configuration file:

OSTYPE The m4 is required, and it is always found in the macro config-\uration file. The OSTYPE command loads an m4 source file that defines oper-\ating system-specific information. File and directory paths, mailnames, and
system-specific mail arguments are the kind of information generally found in an
OSTYPE file. The Sendmail source distribution provides more than 40 predefined
operating system macro files, and you can create one for a specific Linux-
tribution if you like. (We discuss this option when we evaluate the vendor-supplied
macro configuration files in the next chapter.) The only argument passed to
OSTYPE command is the name of the m4 source file that contains the operating sys-
tem-specific information. Here is the command that processes the linux.m4 OSTYPE
source file:

```
OSTYPE(linux)
```
