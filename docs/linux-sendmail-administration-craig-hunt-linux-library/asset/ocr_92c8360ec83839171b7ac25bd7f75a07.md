# The cf Directory Structure

m4 is a general-purpose macro processor. It has a wide variety of uses and is not specifically intended for Sendmail configuration. m4 definitions have been built by the people who maintain Sendmail in order to allow us to create a Sendmail configuration with m4.

The Sendmail distribution contains the m4 source files needed to build the sendmail.cf file. These source files are found in the cf directory located under the top directory created by the Sendmail distribution tar file. The top directory created by the tar file always has a name sendmail-version, where version is the version number. Thus the file for Sendmail 8.11.0 creates a top directory named sendmail-8.11.0, and the configuration files for release are in sendmail-8.11.0/cf. All of this, is relative to the directory where you restore the tar file. In Chapter 3, we restored the tar file in /usr/local/src, the complete path to the configuration files on our sample system is /usr/local/src/sendmail-8.11.0/cf.
