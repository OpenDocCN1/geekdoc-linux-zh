# Simple Command-Line Options

NOTE The -bh command-line option can be invoked with the hstat command. Like the -bd option covered in Chapter 3 ("Running Sendmail") that can be run using the smtpd command, and the -b1 option covered in Chapter 6 ("Using Sendmail Databases") that could be invoked with the new aliases, the -bh option has a synonym. In this chapter, we will also see that -BH can invoked with the purgestat and -bp can be invoked with the mailq command. The command in Listing 10.4 could have been written hstat -v.

Listing 10.4 was reformatted slightly to fit a book page, but basically it is the type of host status report that will be seen soon after host status logging enabled. Inbound connections are not logged. The log show two outbound connections. Each entry has three fields:

+   - The first provides the complete domain name of the remote host. Long ago The second field indicates how long the status was updated. The format of this field is dd:hh:mm:ss, where dd is days, hh is hours, mm is minutes, and ss is seconds. Both of these entries were made in the last few minutes because this report was printed out after host status logging enabled. However, this is a persistent status report. Over time, these status entries will grow, unless the status of one of the host changes. For example, the network connection to goat could be restored.

Results The third field displays the result of the last attempt to deliver to the host identified by the hostname field. Unless the -v option is used with -bh, the results may be truncated.

The entry in Listing 10.4 shows a successful delivery to ibis.fobirds.org took two and a half minutes ago. That's entry field contains the full response received from the remote system, SMTP response code, DSN code, message ID, and text. Results fields are not always complete; a successful connection might generate a result of goat.

The second example shows an attempt to deliver to goat.mammals.org just under two minutes ago. The locally generated results fields say the network that goat is connected to is unreachable. Further, it says the mail was deferred, which means the message has been placed in the mail queue. The system will try to deliver the deferred mail during the next queue process. When it does, it will update the host status for goat.mammals.org.

The entries in the host status directory are persistent. They will be automatically updated over time, but they will not be removed. This means the directory can grow
