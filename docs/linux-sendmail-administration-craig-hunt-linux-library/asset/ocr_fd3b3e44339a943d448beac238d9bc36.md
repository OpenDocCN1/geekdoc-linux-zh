NOTE The hosts listed in relay-domains and class R are the sources of relayed mail; they are not the destinations. Class w, covered in the next section, contains destination command hostnames. Class R contains command hostnames.

Listing 6.2 adds only one domain name to class R. It is possible to add a limited number of domains to class R from inside the Sendmail configuration using the RELAY_DOMAIN macro. For example, the following command placed inside the Sendmail configuration would have the same effect as the relay-domains file shown in Listing 6.2:

```
RELAY_DOMAIN(`ibis.foobirds.org`)
```

However using the relay-domains file is simpler than using the RELAY_DOMAIN macro. The RELAY_DOMAIN command requires modifying the Sendmail macro configuration and running m4 to build the new sendmail.cf file. Using the relay-domains file does not. By default, Sendmail checks for a file /etc/mail/relay-domains and adds the names it finds to class R. No modifications to the configuration are required. You would need to place a command in the macro configuration only if you wanted to change the default filename of the relay-domains. There are two ways this can be done:

```
define(`CONF_FILE`, `path` ) This define command sets the path to the file loaded into class R. It defaults to /etc/mail/relay-domains, which means that if you have not explicitly set any value for this file in your configuration, Sendmail uses a file with that name to load class R. The conf_FILE option is only needed if you want to change the default filename. For example, the following command allows Sendmail to load class R from a named file /etc/relay-hosts:
```

```
define(`CONF_FILE`, `/etc/relay-hosts`)
```

```
RELAY_DOMAIN(`path` ) This macro can be used to specify the path to the file that loads class R. For example, the following command loads class R from a named /etc/relay-for:
```

```
RELAY_DOMAIN_FILE(`etc/relay-for`)
```

There are three commands relating to setting relay values for class R, RELAY_DOMAIN, RELAY_DOMAIN_FILE, and CONF_FILE. But you don't need to use any of them. Just create a file /etc/mail/relay-domains and put the names of the hosts for which your server should relay mail in that. That's all there is to.

The "cr" file is a default feature of the Sendmail configuration. Nothing needs to be done to the Sendmail configuration to add it. On the other hand, the "cw" file, which is discussed next, must be specifically added to the configuration even though its role is as important as that of the "cr" file.
