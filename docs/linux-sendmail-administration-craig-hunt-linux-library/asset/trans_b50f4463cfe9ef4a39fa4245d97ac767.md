## mailq 命令

`-bp` 选项（也称为 `mailq` 命令）显示邮件队列的内容。如果邮件在队列中，它只会打印队列目录的路径名并声明其为空，如下所示：

[root]# mailq

队列为空是一件好事。这意味着一切运行顺利，你的用户发送的所有邮件都已送达。但情况并非总是顺利。。正如我们在列表 10.4 中看到的，远程主机可能已宕或无法访问，邮件必须进入队列稍后投递。列表 10.5 显示了一个 `mailq` 运行结果，报告队列中有一封邮件。
