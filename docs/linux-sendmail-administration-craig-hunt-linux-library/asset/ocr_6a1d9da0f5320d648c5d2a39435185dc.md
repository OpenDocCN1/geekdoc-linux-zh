The first three lines after the telnet command (Trying, Connected, and Escape) are out-put from the telnet command, as is the very last line (Connection closed). All of the other lines in Listing 1.6 are POP3 commands and responses. Positive responses start with the string +OK, indicates that the command executed successfully. When a command fails, the response is the string -ERR. The first +OK response in Listing 1.6 is in reply to the connection request from telnet. The response indicates that the POP server is ready.
