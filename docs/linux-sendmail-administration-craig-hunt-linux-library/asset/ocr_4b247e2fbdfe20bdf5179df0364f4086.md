NEWDB This option adds the basic database support under Linux systems. It pro-
vides both hash and tree databases. This one option provides all you need to build
and access most Sendmail databases.

MAP_REGEX This option adds a new feature to Sendmail that permits databases to
be searched with regular expressions. Anyone who has used regular expressions with
g knows that they are much more powerful than simple wildcard characters. This
added is powerful when you need to create complex rules to block spammers.

USERDB This option adds support for the user database, which can be used to pro-\cess email addresses on both inbound and outbound e-mail. A related option is UDB-
DEFAULT_SPEC, which defines the default path to the user database. The path
can be set with the CONFUSERDB_SPEC define in Sendmail configuration, as we
saw in the readme.mc file in Chapter 5, "Understanding a Vendor's Configuration."
I prefer setting the value in the configuration instead of compiling it Send-
mail because it is more easily changed when it is set in the configuration. However,
some path value must be explicitly defined before Sendmail can use the user database.

NIS This option provides access to Network Information System (NIS) databases.
These are administrative databases, such as /etc/mail1/aliases and /etc/hosts,
stored on the NIS server. The related option databases NISPLUS and YCOMPAT are
early used on Linux systems. NIS+, which is an upgraded version of NIS, is not\often used in Linux environments; YCOMPAT creates compatibility with a version
of NIS that has not been produced in several years. YCOMPAT permits the use of
plus syntax," in which a+ is placed at the end of a local administrative database
tell the system to search the local database and then search the database on the
is server, with YCOMPAT and a+ at the end of the /etc/mail1/aliases data-
base, Sendmail first checks the local a1aliases database and then checks the one on
the NIS server. AUTO_NIS_ALIASES option does exactly the thing. It tells Sendmail to check
the local a1aliases database first and then check the NIS server, and it does without the
outdated plus syntax. (Details of setting up an NIS server on a Linux system are cov-
er in the Linux DNS Server Administration book of this series.)

To force Sendmail to use these four database options, you could either edit the devtools/\os/linux.m4 or create a file in the devtoolsSite directory that contains the-
lowing line:

