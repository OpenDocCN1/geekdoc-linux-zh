The mailq command starts Listing 10.7 has two command-arguments: -qScraig -qR@goat.mammals.org. These arguments select all queued mail that is from the sender address craig (-qScraig) and addressed to anyone on the host (-qR@goat.mammals.org). In this example, a partial recipient is specified. A full address or any part of the address can be used to match sender or recipient addresses.
