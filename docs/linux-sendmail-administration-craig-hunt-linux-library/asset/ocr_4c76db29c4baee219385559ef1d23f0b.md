# Chapter 10 Testing Sendmail

```
final      input: al @ bird . org >
final      returns: al @ bird . org
mailer smtp, host bird.org., user al@bird.org
> /quit
```

/parse command starts by printing out two informational messages. The first one says that the input address is stored in the variable g for the duration of the process. The comment calls the input address "cracked address." All means that any standard RFC 822 field that accompanies the address was removed before the address was stored in variable g. The second message tells you that the address is being processed as an envelope recipient address.

/parse command processes the address as a delivery address, passing through rules 3 (canonical) and rules 0 (parse). Once the smtp mailer is selected for the address, the canonical address is passed through rules 2, the envelope rules defined by the R parameter of the smtp mailer (EnvToSMTP), and finally through rules 4 (final). This extensive processing is exactly the rules flow that was shown in Figure 8.1 in Chapter 8. The /parse command makes it possible for you to send an address through this complete process without remembering the order in which the rules execute.

The last line displayed by the /parse command is the mail delivery triple that will be used for this address. If /parse believes there will be an error delivering the mail to the selected address, it will also display an error message, as shown below:

```
final      returns: al @ bird . org
al@bird.org... Transient parse error -- message queued
for future delivery
```

# Processing a Specific Address Type

By default, the /parse command, and the /try command, process addresses as envelope recipient addresses. As you will recall from Figure 8.1, different types of addresses are processed by different rules. The /tryflags command allows to select a different type of address processing. The /tryflags command accepts four possible values:

+   - H This flag requests header address processing.
- E This flag requests envelope address processing.
- S This flag requests sender address processing.
- R This flag requests recipient address processing.
