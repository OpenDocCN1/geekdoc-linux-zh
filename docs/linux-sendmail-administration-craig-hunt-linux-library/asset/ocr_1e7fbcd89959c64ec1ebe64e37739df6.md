Listing 10.12 is an excerpt from the middle of a sendmail -bt session. The first two commands in Listing 10.12 request information from the Domain Name System. The MX records assigned to the hostname foobirds.org. In this case, DNS returns two MX records: wren.foobirds.org and parrot.foobirds.org. The records are listed in priority sequence. Thus, foobirds.org is the primary MX server for foobirds.org. foobirds.org is the backup MX server. The hostname provided by the /mx command does not have a true MX record in the DNS system, the value returned by the /mx command will be the hostname itself. For example, ibis.foobirds.org

+   > /mx ibis.foobirds.org
getmxrr(ibis.foobirds.org) returns 1 value(s):
ibis.foobirds.org.
