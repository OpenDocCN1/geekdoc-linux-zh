Sendmail uses three user IDs depending on the action it is taking. The three user IDs are:

DefaultUser This is an option in the sendmail.cf file that identifies the user ID and group ID used to run mailers and other external commands. There are three default values for the DefaultUser option:

+   1. If the user mailnull is defined in the /etc/passwd file, the user ID and group ID assigned to mailnull are used.
2. If mailnull is not defined and the user daemon is defined in the /etc/passwd file, the user ID and group ID assigned to daemon are used.
3. If neither mailnull nor daemon is defined in the /etc/passwd file, 1 is used as the user ID and 1 as the group ID.

The default value for the DefaultUser option can be overridden by defining a specific value for the option in the m4 macro configuration file with the CONF_USER parameter. The macro configuration file delivered with Red Hat 7 contains the following CONF_USER_ID command:

```
define('CONF_USER_ID', '8:12')

```

This command sets the user ID to 8 and the group ID to 12. These are the values associated with the username mailnull in the /etc/passwd file delivered with the Red Hat 7. It is interesting to note that the Red Hat 7 /etc/passwd file also has an entry for the user mailnull and for the user daemon is no surprise because it is used by several different daemon processes. On the other hand, the mailnull must have been specifically added as a default value for the DefaultUser option because it serves no other purpose. Given that, it is not why Red Hat also defines a value for the CONF_USER_ID parameter. Here are the mail and mailnull entries from the Red Hat 7 /etc/passwd file and the /etc/shadow file:
