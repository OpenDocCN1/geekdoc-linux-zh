To dive into the Linux world, one must have proper knowledge about some of the Linux commands to save him from the hassle. It is quite hard to learn all the basic command but with practice, they can be remembered
Basic Commands:
1. ls:
ls is one of the frequently used command in the Linux terminal. It is used to print the content ( both files and directories ) of the specific directory in the terminal in alphabetical order. If no directory is specified after ls command then it prints the content of the current working directory.  Alongside printing content, using additional arguments with ls command, we can print the particular details of the files and directories.

2. pwd:
pwd stands for Print Working Directory. It is used to print the current working directory of the terminal. It starts from the root and prints the path till the current working directory. If you are a new user and lost your way in the directories, this command comes in very handy to guide you the way.
3. cd:
cd command stands for Change Directory. It is used to change the directory in the terminal. This command is used to move from one directory to another in the terminal. The syntax of this command is the following:
cd [arguments] [new directory]
>>pwd
/home/tornado/TESTER
>>ls -l
---------- 1 root root   683198 Jun  4  2019 0297-science-of-cyber-security.pdf
d--------- 1 root root     4096 Jan 21  2019 Tutorial

---------- 1 root root    475 Jan 21  2019 tests.cpp
---------- 1 root root    174 Aug 28  2018 What_to_test.cpp
If used without any directory, it changes current directory to home.
To go back to the parent directory, we use two dots(..) with cd i.e.,
cd .. will take you back to the parent directory ( one-level up )
>>pwd
/home/tornado
>>cd ..
>>pwd
/home
cd ../.. Will take you back to parent’s parent directory ( two-level up )
>>pwd
/home/tornado
>>cd ../..
>>pwd
/
cd ../[directory name] will first take you to the parent directory and then to the [directory name] from the parent directory.
>>pwd
/home/tornado
>>cd ../tornado
>>pwd
/home/tornado

4. touch:
touch command is used either to create a new empty file or update the timestamp of an existing file. To create an empty file, simply type the name of the new file after the touch command, and your file is created. Following is the syntax to create a new file:
touch filename
>>touch funfile.txt
>>ls -l
-rw-r--r-- 1 root root       0 Aug 13 20:39 funfile.txt
It can also be used to create multiple files at the same time from just one command. Useful, isn’t it? Following is the syntax to create new multiple files:
touch filename1 filename2 filename3 …..
>>touch funfile1.txt funfile2.txt funfile3.txt
>>ls -l
-rw-r--r-- 1 root root        0 Aug 13 20:39 funfile1.txt
-rw-r--r-- 1 root root        0 Aug 13 20:39 funfile2.txt
-rw-r--r-- 1 root root        0 Aug 13 20:39 funfile3.txt
What if a file already exists and touch command is called for that file? Nothing to worry, it will just update the access, change, and modification time of the file to the current time and no data inside the file will be altered or deleted.
touch -a filename: To only change the access time of a file.
touch -m filename: To update modification time only.
touch -c-d filename: To change modification and access time only leave the change time unchanged -c-d is used along with the touch command.
touch -t YYMMDDHHMM filename: This will create a file with a specified time.
>>touch -t 2112122121 funfile4.txt
>>ls -l
-rw-r--r-- 1 root root        0 Dec 12  2021 funfile4.txt
To create a hidden file, type dot( . ) before filename.
file .[filename]
While using this command, the user must have enough permissions to create or modify the file information. If the user doesn’t have enough permission, its request to use this command will be denied, to get enough permission, the user must go either in root mode using sudo command ( which we will discuss later ) or change the right of the directory and grant permission to a specific user to change its content.
>>sudo -s
Enter password:
>>touch filename
5. mkdir:
mkdir can be divided into two words mk and dir. mk stands for make and dir stands for directory. This command allows one to create a directory in the current working directory of the terminal. The syntax of the following command is:
mkdir dirname
>>mkdir testdir
>> ls -l

d--------- 1 tornado tornado 4096 Aug 13 22:01 dir2-2

Just like touch command, mkdir command can also make multiple directories at once
>> ls -l
total 0

>> ls -l
total 0
drwxr-xr-x 1 root root 4096 Aug 13 22:20 testdir1
drwxr-xr-x 1 root root 4096 Aug 13 22:20 testdir2
mkdir -v [directory name]: To know whether a directory is created successfully or not, we used ls command for confirmation but what if, in the folder where we created directory, there already exist hundreds of directories, it would be very time consuming to find our directory so instead of using ls command every time after mkdir just to confirm that our directory is created successfully or not, we can use -v argument with mkdir, it will display the message for every directory created successfully.
>>mkdir -v check
mkdir: created directory 'check'
mkdir -m[permission] [directory name]: mkdir command by default gives rwx ( read, write and execute ) permission to the current user only, to create a directory which gives permission to all user add the -m argument with mkdir and with -m write 777 to give rwx permission to all users.
The green highlighted directories have permission to be altered by all users.
mkdir -p [directory name]: This argument is used to create a whole structure of directories. For example, if you want to create dir2 inside dir1 and dir1 inside dir, then use -p argument
6. rm:
rm stands for remove. This command in Linux is used to delete objects such as file(s) or directories etc. New users must be cautious while using this command because once you have deleted an object, you might not be able to recover the content of the file or directory as it will require some tools along with high-level commands for which you need to have quite a lot of expertise in Linux. By default, rm can’t remove directories ( only files ); an additional argument is required with the command to remove the directory.
rm [arguments] [filename(s)]
>>ls -l
total 0
drwxrwxrwx 1 root root 4096 Aug 13 22:41 allrwx
drwxr-xr-x 1 root root 4096 Aug 13 22:41 check
drwxr-xr-x 1 root root 4096 Aug 13 22:36 dir
-rw-r--r-- 1 root root    0 Aug 14 00:51 Test.cpp
>>Test.cpp
>>ls -l
total 0
drwxrwxrwx 1 root root 4096 Aug 13 22:41 allrwx
drwxr-xr-x 1 root root 4096 Aug 13 22:41 check
drwxr-xr-x 1 root root 4096 Aug 13 22:36 dir
rm can delete multiple files too.
rm filename1 filename2 …….
rm can also delete all files in the directory. For this, we can use:
rm *
To delete the files of a particular extension, we use:
rm *.[extension]
rm -i filename: The -i arguments makes the command to ask for user confirmation before deleting each file. If the user enters y then it deletes the file else it will keep the file. New users are encouraged to use this argument so they may not delete the wrong file mistakenly.
>>rm -i Test.cpp Test1.cpp

rm -d [directory name]: The -d argument is used to delete an empty directory. If the directory contains any file or directory inside it then this command will fail to delete that directory.
>>rm -d dir
rm: cannot remove 'dir': Directory not empty
rm -r [directory name]: This argument performs recursive deletion. First, it performs the tree walk, deletes all files and sub-directories of the parent directory recursively. It deletes everything it finds inside the directory and then the directory itself.
>>rm -d dir
rm: cannot remove 'dir': Directory not empty
>>rm -r dir
>>ls -l
total 0
drwxrwxrwx 1 root root 4096 Aug 13 22:41 allrwx
drwxr-xr-x 1 root root 4096 Aug 13 22:41 check
-rw-r--r-- 1 root root    0 Aug 14 00:58 Test.cpp
To know about further arguments of rm use rm --help for information.

9. cp:
cp stands for copy. This command is used to copy a file or group of files or directory, it creates an exact copy of the source file with a different file name. To copy a file, pass the source file name after cp command and then after source file pass destination filename.
cp [arguments] [source file] [destination file]
cp [arguments] [source file] [destination directory]
>>cp test.cpp ../dir/test.cpp
cp: cannot stat 'test.cpp': No such file or directory
>>cd ..
>>cd dir1
>>cp test.cpp ../dir/test.cpp
>>cd ..
>> cd dir
>> ls -l
total 4
---------- 1 root root 2720 Aug 14 14:53 test.cpp
cp [arguments] [source file1] [source file2] [source file3] [destination directory]: This command will copy all the files to the destination directory.
>> ls
s1.txt  s2.txt  dir
>> ls dir
[dir is empty]
>> cp s1.txt s2.txt dir
>> ls dir
s1.txt  s2.txt
cp -r [arguments] [source directory] [destination directory]
We can also use the cp command to copy all files and directories inside one directory to another directory but to do that we have to specify argument with cp command which is -r, -r recursively copy all files from source to the destination directory.
cp -i: By specifying -i argument with cp, it warns the user before overwriting the destination, new users are encouraged to use this argument with cp command so they don’t overwrite the data of the file mistakenly.
>>cat s1.txt
I am the data
>>cp -i s1.txt s2.txt
cp: overwrite 's2.txt'? y
>>cat s2.txt
I am the data
cp -f(force): If the user is unable to open the destination folder due to permission issues then using -f argument with cp command deletes the destination folder and then remake the destination folder with enough permissions and copy the files to that folder.
>> ls -l s2.txt
-r-xr-xr-x+ 1 root root 3 Aug 23 09:41 s2.txt
[User, group and others doesn't have writing permission
Without -f option, command is not executed
>>cp s1.txt s2.txt
cp: cannot create regular file 's2.txt': Permission denied
With -f option, the command will be executed successfully
>>cp -f s1.txt s2.txt
copy using *: We can copy many files using the wildcard (*) from one folder to another. Suppose in a directory, we have many txt files and we want to copy all of them at the same time to another directory, so by using *, we can do that in a single command.
>>ls dir

>>cp *.txt dir

10. mv:
mv stands for move. This command is used to move multiple files or directories. It performs two functions; it renames the file or moves multiple files to a different directory.
mv [arguments] [source] [destination]
If the destination file doesn’t exist, then it will be created (by renaming the source file). However, if it exists then it will be overwritten by the source file and the source file will be deleted.
>>ls
dest.cpp  new.cpp
>>mv dest.cpp new.cpp
>>ls
New.cpp
The data inside the dest.cpp have overwritten the data inside new.cpp and dest.cpp have been deleted.
mv -i: Like in previous commands using -i make command to ask for user permission before overwriting the dest file only if the file exists. If the file doesn’t exist, then it doesn’t ask for permission, it simply renames the file or moves it to some other directory.

12. tail:
tail is complementary of head command. As head prints from the start of the file, tail command prints from the end of the file. It prints the last N number of lines. By default, it prints the last 10 lines of files. However, by using -n argument with tail, we can specify the number of lines we wish to be printed.
tail [arguments] [filename1] [filename2]
>>tail new.txt
Line6
Line7
Line8
Line9
Line10
Line11
Line12
Line13
Line14
Line15
Just like head, it has the same argument and functionality, the only difference is that the work that head performed was from the start of the file, tail does that from the end of the file.
tail -n [number of lines] [filename]: It will print last N ( specified after -n ) number of lines from the file.
tail -c [number of bytes] [filename]: It will print last N ( specified after -n ) number of bytes from the file.
tail -q [filename] [filename1]: If the tail is used for more than 1 file, then the data is separated by filename but by using -q argument, data from each file is not preceded by its filename.
tail -f [filename]: This command is mostly used by programmers to see the growth of file as the data is being written from some source to it. As the new data is being written to the file, the console will update the new lines. When this command is used it does not return the prompt, until interrupted by the system ( Ctrl+C or closing the terminal ) . Generally, this argument is used with log files as the system write errors to log file, so with -f argument you can see which error was generated at what time in the log file.
For example, tail -f somelogfile.txt
tail --version: It displays the version of the tail command being used in your system.

13. mount:

When you plug a portable hard disk, USB, or SD card; there is a chance that your system might not be able to show them directly, so you need it to mount to your existing tree ( file-system ). 23. nice:
nice command is used to change the priority of the process. Every process needs RAM and CPU to complete its operation, each process is assigned priority by the system when it is started. However, there can be a process that we need to complete as soon as possible. For this, nice command is used. This command is mostly used on low-end systems. The priority of the process range from -20 to 20. For example, we want to start the priority of a specific process to 10, then the following command will be used.
nice -n 10 [specific process]
We can also change the priority of the running process. For this purpose, renice command is used. Now, we work on a particular example. First, we start the top command with priority of 10. Then we open another terminal while the top command is running in the first terminal, we then note the process id of the top process from the top manager. Then we, change the priority of top from the second terminal by typing ‘renice -n [priority] [process id]’.
We note that the process id of top command is 4591 in the first terminal, now we open the second terminal and type ‘process -n 10 4591’ and then ‘process -n 15 4591’.
>>renice -n 10 4591
4591 (process ID) old priority 10, new priority 10
>>renice -n 15 4591
4591 (process ID) old priority 10, new priority 15
When the priority of top command which is running in the first terminal is changed, it prints the new priority followed by old priority.

52. watch:
This command is used to execute the other specified command after watch keyword periodically, this will run the specified command after a specific period repeatedly. By default, the period after which command is repeated is two seconds. This command will keep on running until interrupted by a signal (Ctrl+C).
watch [command] [command input]
For example, we use the above command with cat file.txt and while watch command is being executed, we change the data in file.txt we will be able to see the difference on the terminal screen.
>>watch cat file.txt
Every 2.0s: cat file.txt                                                           kali: Sun Aug 16 18:15:38 2020
i am tornado on line 1
i am tornado on line 2
i am empty but i am
watch -n [period time] [command] [command input]: We can specify the time with argument after which command must be repeated. The least possible value for this argument is 0.1, it can’t go slower than that.
>>watch -n 1 cat file.txt
Every 1.0s: cat file.txt                                                           kali: Sun Aug 16 18:15:38 2020
i am tornado on line 1
i am tornado on line 2
i am empty but i am
watch -t [period time] [command] [command input]: This argument will turn off the title.
>>watch -t cat file.txt
i am tornado on line 1
i am tornado on line 2
i am empty but i am
watch -d [period time] [command] [command input]: This argument will highlight the change in the file after every time command is repeated.
watch -v: This will display the current version of the watch command.
>>watch -v
watch from procps-ng 3.3.15
For further information about the watch command, use watch -h .
53. look:
This command is used to look for lines in the files which start by the specific pattern of characters ( string ).
look [string] [filename]
It can also be used to look for the specified string in multiple files but it will be hard to point out the position from where new file starts, so it is recommended for you to look for a string in a single file at a time.
If no file is specified, then it uses /usr/share/dict/words file by default.
>>look "class"
class
class's
classed
classes
classic
classic's
classical
look -f [filename]: This will make look command to search for string while ignoring case sensitivity.
>>cat words.txt
tornado
Tornado
TOrnado
>>look -f to words.txt
tornado
Tornado
TOrnado
54. zip:
This command is used to compress the files and directories into a single file. This command is widely used while delivering work or when you have low internet speed. This command functionality is also used to save space in secondary storages, it can compress large directories and files into a single file while preserving all the information about those files and directories.
zip [arguments] [zip-filename] [filename] [filename1] and so on..
deflated % means that how much file has been compressed.
zip -d [zip-filename] [filename] [filename1] and so on..: This argument is used to remove the file or directory from the zip file if you have mistakenly added a wrong file to the zip.
>>zip Example.zip file.txt file1.txt
  adding: file.txt (deflated 35%)
  adding: file1.txt (deflated 47%)
>>zip -d Example.zip file1.txt
deleting: file1.txt
zip -u [zip-filename] [filename] [filename1] and so on..: To add the file or directory to zip file.
>>zip -u Example.zip file1.txt
  adding: file1.txt (deflated 47%)
zip -m [zip-filename] [filename] [filename1] and so on..: To delete the files or directories once they have been added to a zip file.
>>zip -m Example.zip file.txt file1.txt
This command will remove file.txt and file1.txt after adding them to the zip file.
zip -D [zip-filename] [filename] [filename1] and so on..: This will zip all the files only excluding directories.
>>ls
Example      file1.txt  MakeFile  Project     Tutorial   Work1  Work3
Example.zip  file.txt   PortInfo  SquareGame  words.txt  Work2
>>zip -D Example.zip *
updating: file.txt (deflated 35%)
updating: file1.txt (deflated 47%)
updating: words.txt (deflated 38%)
zip -e [zip-filename] [filename] [filename1] and so on..: We can put password on zip using this argument.
>>zip -e Example.zip file.txt file1.txt
Enter password:
Verify password:
updating: file.txt (deflated 35%)
updating: file1.txt (deflated 47%)
unzip command is used to unzip the zipped file. Now, we want to unzip our file which we have encrypted.
>>unzip Example.zip
Archive:  Example.zip
[Example.zip] file.txt password:
replace file.txt? [y]es, [n]o, [A]ll, [N]one, [r]ename: n
replace file1.txt? [y]es, [n]o, [A]ll, [N]one, [r]ename: n
replace words.txt? [y]es, [n]o, [A]ll, [N]one, [r]ename: n
Before unzipping, it asked for the password and afterward, when it found a file with the same name in the current directory, it asked whether to replace that file or not.
zip -1 [zip-filename] [filename] [filename1] and so on..: While zipping a lot of files, the operation can get quite slow. To increase the speed of the operation, we use -1 argument, this will fasten the operation.
For more information related to this command, use zip --help.

61. man:
This command is used to print detailed information about any command that we can run on the terminal. It provides information in the following order:
Name ( a small description of the command ),
Synopsis ( syntax of the command ),
Description ( detail description about the command ),
Example ( command can be used in the following ways ),
And much more information regarding arguments, return values, errors, and author.
man [command]
For example, man ps and man pwd .
last -F: By default, the command will not show years, and second, using the -F argument will allow us to see seconds in time and year in date.
