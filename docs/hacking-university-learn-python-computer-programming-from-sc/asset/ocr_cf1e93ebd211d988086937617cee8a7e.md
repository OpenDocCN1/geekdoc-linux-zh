+   String – Letters, words, or entire phrases. Contained within quotation marks.
+   
+   "Hello, world", “no”, “12”

+   Lists/Tuples/Dictionaries – Multiple related values grouped together as one object. Can be a variety of data types.
+   
+   [1, 4, 4, 0], [“Dog”, 2, “yes”]

Obviously, numerical values are declared by simply supplying an integer in the variable declaration. If there is a decimal involved, it will a float. Quotations signify strings, and brackets are for lists.
