As you save, you will give it the name and file extension associated with it; notes.txt will create a text file with the name “notes”. Alternatively, you can edit a file by typing “nano notes.txt”. In that example, we open notes in the editor and display its contents in an editable state.

Nano may be very simple, but it is undoubtedly powerful and a time saver for quick changes and file creation.
