After saving and running the file, all three functions will print their respective parameters. As mentioned previously, the quotations explain that text will be displayed. By forgoing quotations, numbers can be displayed instead.

```
print ("The answer to everything is:")
```

```
print (42)
```

Python starts at the beginning of the script file and works its way down one line at a time until no more lines are found, in which case the program exits back to prompt or terminal.
