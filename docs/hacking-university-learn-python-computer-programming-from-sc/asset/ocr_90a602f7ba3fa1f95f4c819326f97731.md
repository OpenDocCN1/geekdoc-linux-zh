As it is seen, entries in lists can be accessed by specifying the location of the entry in square brackets. Counting starts at 0, so the first entry of jack_info is 8, and the entry in [3] is "A". Visualize it like so:

| Entry number: | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Data value: | 8 | "West Elementary" | state | "A" |

A list could be initially declared with 3 entries, and it would have the range 0-2. The number of entries is nearly infinite, and it is only limited by the computer's memory and the amount of variables the programmer fills it with.

The elements of a list can be edited as if they were individual variables. If Jack ages a year, we only need to update the entry. Furthermore, adding a new entry to the list can be done without completely redefining every value within it. Using append(), a new entry will be created in the last
