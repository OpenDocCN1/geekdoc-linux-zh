# 引言：Linux 初学者指南

Linux 提供了与 Windows 和 macOS 不同的桌面计算理念。

Linux 操作系统提供了丰富的特性和安全性，使其成为 macOS 和微软 Windows 的极佳免费且（大部分）开源的替代方案。由于它在“底层”与众不同，在投入使用之前，请考虑 Linux 的一些宏观方面以及它与其他桌面操作系统的对比。

# 什么是 Linux？

Linux 驱动着从灯泡到枪支、从笔记本电脑到大型计算机中心的各种计算机系统。

Linux 驱动着从你的手机到智能冰箱的一切设备。

在桌面计算中，Linux 是 Windows 和 macOS 等商业操作系统的替代方案。

Linux 源自 20 世纪 60 年代最早的计算机操作系统之一。在桌面计算中，Linux 提供了 Windows 和 macOS 这种商业操作系统的替代方案。Linux 提供了丰富的丰富的特性和安全性。对于了解情况的人来说，你明白 Linux 无处不在。它运行在你的手机、汽车、冰箱、Roku 设备、超级计算机以及全球范围内。它保留了强大的安全性、定制化和系统稳定性的哲学。在 Linux 成为运行桌面、服务器和嵌入式系统的平台之前，它一直是（目前仍然是）最可靠、安全且无后顾的操作系统之一。

就像 Windows XP、Windows 7、Windows 8 和 Mac OS X 一样，Linux 是一个操作系统。操作系统是管理你的桌面或笔记本电脑相关硬件资源的软件。简单来说——操作系统（通常称为 OS）管理软件与硬件之间的通信。如果没有操作系统，软件将无法运行。

操作系统由许多部分组成：

- 引导加载程序：管理计算机启动过程的软件。对于大多数用户来说，这只是一个弹出来并最终进入操作系统的启动界面。
- 内核：这是整个系统中唯一被称为“Linux”的部分。内核是系统的核心，管理 CPU、内存和外围设备。内核是操作系统的最低层。
- 守护进程：这些是后台服务（打印、声音、调度等），在启动期间或登录桌面后启动。
- Shell：你可能听说过命令行。这就是 Shell —— 允许你通过文本界面输入命令来控制计算机的过程。这曾是让人们最远离 Linux 的原因（假设必须学习古老的命令结构来让 Linux 工作）。现在不再是了。有了现代桌面 Linux，你根本不需要接触命令行。
- 图形服务器：这是在你的显示器上显示图形的子系统。通常被称为 X 服务器或简单的“X”。
- 桌面环境：这是用户实际交互的部分。有很多桌面环境可以选择（Unity、GNOME、Cinnamon、Enlightenment、KDE、XFCE 等）。每个桌面环境都包含内置应用程序（如文件管理器、配置工具、浏览器、游戏等）。
- 应用：桌面环境并不提供所有的应用。就像 Windows 和 Mac 一样，Linux 提供了成千上万高质量的软件，可以很容易地找到并安装。大多数现代 Linux 发行版（稍后会介绍）包含类似应用商店的工具，可以集中并简化应用程序安装。例如：Ubuntu Linux 拥有 Ubuntu 软件中心（图 1），允许你从一个中心位置快速搜索并安装数千个应用。

# 为什么使用 Linux 而不是 Windows 或 macOS？

有许多你选择 Linux 而不是 Windows 或 macOS 的原因，以下是其中几个：

## Windows 10 在旧硬件上运行缓慢

如果你使用 Windows XP、Vista 或旧的 Windows 7 PC，那么你的电脑可能性能不足以运行 Windows 8 或 Windows 10。你拥有有两个选择。你可以购买一台运行 Windows 10 的电脑，也可以运行 Linux。

某些 Linux 发行版并没有提供太大的性能提升，因为它们的桌面环境会消耗大量的内存。然而，某些版本的 Linux 在旧款硬件上运行得非常出色。

对于较新的硬件，尝试带有 Cinnamon 桌面环境的 Linux Mint 或 Ubuntu。对于两到四年前的硬件，尝试 Linux Mint 但请使用 MATE 或 XFCE 桌面环境，它们占用的资源更少。对于更旧的硬件，可以选择 AntiX、Q4OS、Xubuntu 或 Lubuntu……

## 你不喜欢 Windows 10 的用户界面

大多数人在初次使用新操作系统时都会感到无所措，特别是当用户界面发生任何变化时。然而，当他们习惯了新的操作方式后，最终会更喜欢新界面而不是旧界面。

如果你无法适应 Windows 10 的操作方式，你可能更喜欢像 Windows 7 那样的，或者你可能会决定尝试一些不同的。

Linux Mint 提供了现代的视觉感受，但其菜单和工具栏的操作方式与既往一样。学习 Linux Mint 的学习曲线并不比从 Windows 7 升级到 Windows 10 更难。

## Linux 是免费的

微软几年前提供的免费升级已经结束。这意味着你现在必须为之付费。

许多制造商在电脑出厂时就预装了 Windows 10。如果你对目前的电脑满意，获取新操作系统的唯一方法就是购买最新版本的 Windows，或者免费下载并安装 Linux。

Linux 包含了你对操作系统所需的所有功能，并且与硬件完全兼容。有些人说一分钱一分货，但在这种例子中这种说法并不成立。

如果 Linux 对科技行业的顶尖公司来说已经足够，那么它运行在家庭电脑上也足够了。

## Linux 有更多免费应用程序

Windows 有几个旗舰产品，如 Microsoft Office 和 Visual Studio，这让一些人感到被锁死。然而，你可以通过虚拟化软件或运行在线版本在 Linux 上运行 Microsoft Office。

大多数软件开发都是基于 Web 的，Linux 有许多好用的 IDE。随着 .NET Core 的进步，你可以创建用于 JavaScript Web 应用程序的 API。Python 也是一种主要的编程语言，可以在 Windows、Linux 和 Mac 上跨平台使用。PyCharm IDE 和 Visual Studio 一样好。这里的观点是 Visual Studio 并不是唯一的选择。

Linux 拥有一套很棒的应用程序，对大多数人来说提供了他们所需的功能。例如，LibreOffice 套件可以满足普通人 99.9% 的需求。Rhythmbox 播放器比 Windows 任何软件都好，VLC 是一个很棒的视频播放器，可以使用 Chrome 浏览器，Evolution 是一个优秀的客户端，GIMP 是一个出色的图像编辑器。

## 安全

虽然没有任何操作系统是完全没有风险的，但 Windows 是病毒和恶意软件开发人员的大目标。对于这个问题，微软能做的很少。因此，你必须安装杀病毒程序和防火墙软件，而为了保持这些软件更新，所需的持续下载会占用你的内存和 CPU 使用率。

对于 Linux，你只需要足够聪明，坚持使用受信任的软件源，并避免使用如 Adobe Flash 等高风险程序。

Linux 比 Windows 更安全，这是因为它的设计方式以及处理用户权限的方式。这也是大多数网页运行在 Linux 上的原因之一。

## 可靠性

Windows 不如 Linux 可靠。作为 Windows 用户，你有多少次遇到程序卡死，当你尝试关闭它时它仍然开启？在 Linux 中，每个应用程序都是自包含的，你可以通过 `Task` 命令杀死任何应用程序。除之外，Linux 应用程序锁死的频率更低。因为 Linux 及其许多应用程序是开源的，任何人都可以查看、审查和改进底层代码。这导致了一个稳定的系统，并对漏洞和安全问题提供了快速修复。

## 更新

当你想要打印剧院票、电影票或场地的路线，结果打开电脑看到以下消息时：“正在安装更新 1 的 356”，这会很令人沮丧。

## 你应该使用哪种 Linux 发行版？

Linux 内核就像引擎。而发行版是装载引擎的实际车辆。

那么，你应该选择哪种 Linux 发行版呢？Linux 支持数百种发行版，每种都针对特定的用例进行了优化：

- Linux Mint：对计算机知识要求低，易于安装、易用，并为 Windows 用户提供了熟悉的桌面。
- Debian：如果你正在寻找一种不包含专有驱动、固件或软件的真正自由 Linux 发行版，那么 Debian 适合你。
- Ubuntu：一种现代的 Linux 发行版，安装简单且易用。
- openSUSE：一个稳定且强大的 Linux 发行版。虽然不像 Mint 和 Ubuntu 那么容易安装，但仍然很好的替代方案。
- Fedora：最先进的 Linux 发行版，尽可能地整合了所有新概念。
- Mageia：从曾经辉煌的 Mandriva Linux 灰中重生。易于安装且易用。
- CentOS：与 Fedora 一样，CentOS 基于商业级 Linux 发行版 Red Hat Linux。与 Fedora 不同，它是为了稳定性而构建的。
- Manjaro：基于 Arch Linux，Manjaro 在易用性和软件的更新之间取得了极好的平衡。
- LXLE：基于轻量级的 Lubuntu 发行版，为旧硬件提供了一个功能齐全的 Linux 发行版。
- Arch：一种滚动更新（rolling release）发行，意味着你不需要在任何时候安装操作系统的新版本，因为它会自动更新。对于新用户来说较难掌握，但非常强大。
- Elementary：为喜欢 Mac 风格界面的人们设计的 Linux。

## 什么是桌面环境？

典型的 Linux 发行版包含几个不同的组件。

显示管理器（display manager）负责你的登录，而窗口管理器（window manager）负责管理窗口、面板、菜单、Dash 界面和核心应用程序。这些项目中的许多被打包在一起形成一个桌面环境。

某些 Linux 发行版只带有一个桌面环境（尽管在软件库中还有其他可选），而另一些则提供针对不同桌面环境精细调整的发行版版本。

常见的桌面环境包括 Cinnamon、GNOME、Unity、KDE、Enlightenment、XFCE、LXDE 和 MATE。

Cinnamon 是一种传统的桌面环境，看起来非常像 Windows 7，底部有一个面板、菜单、系统托盘图标和快速启动图标。

GNOME 和 Unity 相当相似。它们是现代桌面环境，使用启动图标概念和仪表板风格的显示来选择应用程序。还有与桌面环境整体主题融合得很好的核心应用程序。

KDE 是一个经典风格的桌面环境，具有许多自定义功能和核心应用程序，这些程序都是高度可定制的。

Enlightenment、XFCE、LXDE 和 MATE 是带有面板和菜单的轻量级桌面环境。

- 10. `locate` — `locate` 命令用于在 Linux 系统中定位文件，就像 Windows 中的搜索命令一样。当你不知道文件保存在何处或文件的实际名称时，这个命令非常有用。在命令中使用 `-i` 参数可以忽略大小写（大写或小写都没关系）。所以，如果你想要一个包含“hello”单词的文件，当你输入 `locate -i hello` 时，它会列出 Linux 系统中所有包含“hello”单词的文件。如果你记得两个单词，可以使用星号（`*`）将它们分开。例如，要定位一个包含“hello”和“this”单词的文件，你可以使用命令 `locate -i *hello*this`。

- 7. `tar` — 在命令行中使用 `tar` 命令处理 tar 包（或压缩在 tar 包中的文件）。它有很多用途。它可以用于压缩和解压不同类型的 tar 存档，如 `.tar`, `.gz`, `.bz2` 等。它根据给定的参数运行。例如，`-cvf` 创建 `.tar` 存档，`-xvf` 解压包，`-tvf` 列出包的内容等。由于这是一个广泛的话题，这里有一些 `tar` 命令示例。

- 8. `zip`, `unzip` — 使用 `zip` 将文件压缩为 zip 存档，使用 `unzip` 从 zip 存档中提取文件。

- 9. `uname` — 使用 `uname` 显示你所运行的系统信息。使用命令 `uname -a` 会打印有关系统的大部分信息。这包含了内核发布日期、版本、处理器类型等。

- 10. `apt-get` — 在 Linux 命令行中使用 `apt` 处理软件包。使用 `apt-get` 安装软件包。这需要 root 权限，因此配合 `sudo` 命令使用。例如，如果你想安装文本编辑器 `jed`，我们可以输入 `sudo apt-get install jed`。同样，包都可以这样安装。在每次尝试安装新包之前，更新存储库是好的。你可以通过输入 `sudo apt-get update` 来实现。通过 `sudo apt-get upgrade` 升级系统。我们也可以通过 `sudo apt-get dist-upgrade` 升级发行版。命令 `apt-cache search` 用于搜索软件包。如果你想搜索某个包，可以输入 `apt-cache search jed`（这不需要 root）。

在这种情况下可以使用命令 `chmod +x numbers.py`。你可以使用 `chmod 755 numbers.py` 来赋予其 root 权限，或者使用 `sudo chmod +x numbers.py` 赋予 root 执行权限。这里有关于 `chmod` 命令的更多信息。

- 12. `hostname` — 使用 `hostname` 了解你在主机或网络中的名称。基本上，它会显示你的主机主机名和 IP 地址。只需输入 `hostname` 即可获得输出。输入 `hostname -I` 则可以获取你在网络中的 IP 地址。

- 13. `ping` — 使用 `ping` 检查你与服务器的连接。维基百科说：“Ping 是一种计算机网络管理实用程序，用于测试 Internet 协议 (IP) 网络上主机的可达性”。简单来说，当你输入例如 `ping google.com` 时，它会检查是否可以连接到服务器并返回。它会测量这种往返时间并提供相关细节。对于像我们这样的普通用户来说，使用此命令的作用是检查互联网连接。如果它 ping 通了 Google 服务器（在这种情况下），你可以确认你的互联网连接是活跃的！

# Linux 的优势

现在让我们简要讨论一下 Linux 的一些优势：

- 1. 开源

Linux 的主要优势之一是它是开源操作系统，也就是说它的源代码对所有人开放。任何能够编程的人都可以为任何人、出于任何目的贡献、修改、增强和分发代码。

- 2. 安全

与 Windows 等其他操作系统相比，Linux 更安全。Linux 并非完全安全，因为也有针对它的恶意软件，但它比其他系统更脆弱。Linux 中的每个程序（无论是应用程序还是病毒）都需要管理员以密码的形式进行授权。除非输入密码，否则病毒不会执行。

在 Linux 中，你会遇到数量大量的软件更新。这些软件更新的速度比任何其他操作系统的更新都要快得多。Linux 的更新可以很容易完成，无需面临任何重大问题或担忧。

- 5. 定制化

一个比其他操作系统具有主要优势的功能是定制化。由于 Linux 是开源操作系统，你可以根据需要自定义任何功能、添加或删除任何功能。不仅如此，还可以安装各种壁纸和吸引人的图标主题，为你的系统提供惊艳的外观。

- 6. 多种发行版

Linux 还有许多可选发行版。它为用户提供了多种选择或口味。你可以根据需求选择任何发行版。Linux 的发行版包括 `Fedora`、`Ubuntu`、`Arch Linux`、`Debian`、`Linux Mint` 等。如果你是新手，可以使用 `Ubuntu` 或 `Linux Mint`。如果你是一个优秀的程序员，可能可以使用 `Debian` 或 `Fedora`。

- 7. 免费使用（低成本）

Linux 可以在网上免费下载和使用。你不需要为它购买许可证，因为 Linux 及其许多软件都遵循 GNU 通用许可协议 (`GPL`)。这证明了 Linux 与 Windows 及其他操作系统相比的主要优势之一。你需要花费巨资购买 Windows 许可证，而 Linux 并非如此。

- 8. 大大的社区支持

网上由热心的用户建立了论坛，以帮助和解决任何其他用户面临的问题。那里有许多专门的程序员，尽可能在任何时间任何地为你提供帮助。

- 9. 稳定性（可靠性）

Linux 提供了高稳定性，这也是很好的优点，即它不需要在短时间内重新启动。你的 Linux 系统很少会变慢或死机。在 Windows 中，你需要在安装或卸载应用程序或更新软件后重新启动系统，但 Linux 并非如此。你可以在 Linux 系统上不受任何干扰地工作。

- 10. 隐私

Linux 确保用户数据的隐私，因为它在使用其发行版或软件时从不从用户那里收集大量数据，但许多其他操作系统并非如此。

- 11. 性能

Linux 在各种网络和工作站上提供高性能。它允许大量用户同时工作，并高效地处理他们。

- 12. 网络支持

Linux 支持网络功能，因为它是程序员在互联网上编写的。Linux 帮助你以简单快速的方式在计算机系统上设置客户端和服务器系统。

- 13. 灵活性

Linux 提供了很高的灵活性，因为你可以只安装所需的组件。没有必要安装完整的套件。你还可以将 Linux 文件保留在多个分区下，这样如果其中一个损坏，就不会有重大损失。你只需要修复那个特定的分区，而不是整个文件，与其他操作系统不同。

- 14. 兼容性



Linux 可以运行或执行所有可能的文件格式，并与大量文件格式兼容。

## 15. 快速方便的安装
Linux 可以从网上轻松安装，不需要任何先决条件，因为它可以运行在任何硬件上，即使是你最旧的系统上。

## 16. 硬盘的合理使用
即使在硬盘几乎满的情况下，Linux 也能高效执行所有任务。这提高了 Linux 的性能，因此 Linux 也提供了高性能。

## 17. 多任务处理
Linux 是一个多任务操作系统，它可以同时执行许多任务而不会降低速度，例如下载大文件不会减慢系统。

## 18. 运行多个桌面
Linux 提供了各种桌面环境以便于使用。在安装 Linux 时，你可以根据意愿选择任何桌面环境，例如 `KDE`（K 桌面环境）或 `GNOME`（GNU 网络对象环境）。

# 使用 Linux 有什么缺点？

Linux 没有标准版本。微软为每个版本的 Windows 提供了几个不同的版本，而 Linux 有无数种变体。对于新用户来说，要弄清楚哪一个最适合你可能会令人困惑。

Linux 对驱动程序（协调硬件和操作系统的软件）的支持较少。这意味着你有时会发现设置新设备更为困难。

对于新用户来说，Linux 并不像 Windows 那样易用。这在很大程度上是因为 Linux 给了你更多控制，但也意味着你必须花一些时间适应它的工作方式。

由于 Linux 既不像 Windows 流行，也不是商业产品，因此支持工作的方式不同。你可能需要花更多精力来寻找问题的答案，虽然 Linux 支持者更有可能提供帮助，但这种帮助可能并不总是匹配你自己的技术理解水平。

你在 Windows 中习惯的许多程序将仅通过复杂的模拟器在 Linux 中运行。这些程序不能保证能够完美运行，在某些情况下可能会明显变慢。

虽然 Linux 可能适用于个人用户，但它较小的市场份额意味着在企业环境中引入要困难得多。由于大多数办公室员工已经熟悉 Windows 和微软程序，将员工转为使用 Linux 系统 可能会产生显著的时间成本。

虽然许多 Windows 程序有完美的替代方案（例如各种 Office 组件），但某些像 Photoshop 这样的高级应用程序在 Linux 中没有类似的对等替代品。

PC 游戏粉丝可能会发现 Linux 提供的范围要有限得多。这部分是因为是因为最新的游戏几乎总是商业化运营，而且在 Linux 中重现要困难得多，因为它们比办公软件等更具个人化。

虽然没有特定理由说明这种情况是必然，但在实践中，许多用户报告说，在 Linux 中设置打印功能可能会非常麻烦。

由于 Linux 是一个免费的开源系统，如果你发现软件不符合标准或导致了问题，并没有法律上的追回手段。虽然不能保证你一定获胜，但对于像 Windows 这样的商业产品，你至少拥有某些投诉权。

- `Miro Music` - 一款跨平台视频播放应用，允许观看网络电视。
- `SMPPlayer` - 一个带有字幕功能的免费 GUI 媒体播放器。

## 视频编辑器
- `Open Shot` - 一款功能丰富的跨平台视频编辑应用。
- `Pitivi` - 一款开源视频编辑应用。
- `Avidemux` - 一款简单易用的开源跨平台视频编辑软件。
- `Blender` - 一个支持所有 3D 工作流 3D 创建套件。

## 浏览器
- `Google Chrome` - 由谷歌开发的、在 PC 和手机上最流行的浏览器。
- `Firefox` - 最近备受关注的开源跨平台网络浏览器。
- `Vivaldi` - 一款基于 Chromium 引擎、界面优美的浏览器。
- `Opera` - 一款于 90 年代发布的浏览器，是最老的浏览器之一。
- `Chromium` - 一款轻量级开源跨平台浏览器。与 Google Chrome 不同，Chromium 更快。
- `Midori` - 一款许多 Linux 系统的默认开源浏览器。
