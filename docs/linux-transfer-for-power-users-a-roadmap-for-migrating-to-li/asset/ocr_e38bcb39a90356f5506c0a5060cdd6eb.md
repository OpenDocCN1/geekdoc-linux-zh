# PDF viewers

Adobe Acrobat’s PDF (Portable Document Format) file format has become a *de facto* standard in the world of exchanging read-only documents. With hidden information problems that can accompany Microsoft Word coming to light over the past year, people have been turning to PDFs as a means of providing information in a safe, non-alterable format.

I’ve already mentioned that OpenOffice.org has a built-in PDF-creation capability that’s accessed by a button on the main toolbar. But that’s for *creating* PDFs. Once you *have* a PDF, how do you read it?

Fedora Core ships with not one, not two, but four different PDF viewers. Although the PDF file format has been published so that third parties (like OpenOffice.org) can create PDF files as well as read them, the format continues to evolve; as of this writing, version 6 is the most recent. And even earlier versions have a variety of features that may not work in a specific reader. In addition, not all of the readers that come with Fedora Core have been kept up to date.

As a result, different readers may have better luck with different PDF files. If you have trouble with one PDF viewer, you may want to try a different one for better results.

The four viewers are Ghostview, Kghostview (KDE’s PDF viewer based on Ghostview), xpdf, and GNOME PDF Viewer, which is based on xpdf. The Ghostview viewers that ship with Fedora Core are a little long in the tooth and often don’t display recent PDFs correctly, if they can open them at all.

The xpdf-based viewers are much more robust, handling PDFs created with Adobe Acrobat and OpenOffice.org perfectly. **Figure 15** shows GNOME PDF Viewer with a 300-page PDF created with Adobe Acrobat, while **Figure 16** shows xpdf displaying a PDF created with OpenOffice.org running on Linux.
