The fourth link, to a Bugzilla bug report, turned out to have the answer to this seemingly obscure problem.

Bugzilla, you say? Bugzilla is a software tool used by the Fedora Core project to track various issues having to do with FC, including bugs, anomalies, and enhancement requests. Bugzilla’s contents are available on the Web and thus are indexed by the major search engines.

The bug report in question is shown in **Figure 10**.

The contents of the Bugzilla error report are another matter; in this particular case, the solution was to download a new package and install it manually, in order to fix the path problem. This may be too much for some users, who would end up either doing a completely new install or just waiting for the new package to be available for download through the Red Hat Network Alert Notification Tool.

Still, the Bugzilla report provides solace in that the error is now understandable and can be dealt with, instead of leaving users scratching their heads without a clue.
