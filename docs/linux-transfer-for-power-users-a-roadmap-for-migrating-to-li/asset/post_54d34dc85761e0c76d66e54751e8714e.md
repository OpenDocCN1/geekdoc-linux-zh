
## Accessing Windows files on a Linux computer

There isn’t anything magical about a file that restricts itself to reside on a Windows computer. You can copy a file on a Windows computer to a Linux computer without any ill effects or fear of messing up the file. The process isn’t like trying to read an Apple II floppy disk in an IBM PC disk drive, for example. There aren’t any secret codes in a file that designate it as “Windows-only.”

You can copy your Windows data files to your Linux computer over a network connection or via floppy disk, Zip disk, or CD-ROM. Or you can connect your Linux computer to a network that has Windows computers or servers on it, and access your Windows data remotely. Indeed, I still have a Windows file server on my network, and I work with files stored on it from my workstation running Fedora Core. Details on connecting your Linux workstation to a Windows file server are in Appendix B, “Connecting to a Windows Network.”

## Using Linux programs to open your Windows files

Once you can “get to” your Windows data, what do you do with it when you’re running Linux? After all, you’re generally going to be running Linux programs, not Windows programs. You’ve got files in Microsoft Office format, e-mail in Microsoft Outlook or Outlook Express files, music files stored in MP3 format, and family pictures saved as JPG with the special Windows software that came with your digital camera.

The answer is, as with many things computer-wise, “It depends.” Generally, you’ll be able to use files created with popular Windows applications “as is” with Linux.

In many cases, Linux programs have been designed to work with the proprietary formats that Microsoft tries to use to continue its monopoly status. For example, OpenOffice.org can open Microsoft Office Word, Excel, and PowerPoint files with ease. In fact, oft-repeated tip by Microsoft MVPs on the various Office electronic forums is to use OpenOffice.org to repair damaged Office files that Office can’t open any longer itself!

In some cases, Windows programs use industry-standard file formats, like HTML, MP3, PDF, and so on, which are also used by Linux programs, and so you can work with those files transparently.

Finally, in a few cases, Windows programs use formats that aren’t natively readable by Linux programs. You’ll most likely have to export your data into a format that can be read by a similar Linux program. For example, Microsoft Outlook uses a proprietary format for its PST mail and address file. However, you can export your data into a format that can be read into a Linux mail program such as Evolution, KMail, or Mozilla Mail. Other programs use formats that can be read by other programs. For example, Mozilla’s mail client, Thunderbird, can import Outlook Express address books and e-mail absolutely flawlessly.

In each of the following chapters that cover individual applications, I’ll discuss specific issues that relate to migrating your data from Windows to Linux.

### E-mail and Web Browsing

By far, the most common activities that people perform on their personal computers are using the Internet for e-mail and surfing the World Wide Web. In this chapter, I'll introduce a couple of popular tools for both functions and get you started using them.

For years after the “big three” of killer applications—spreadsheets, word processors, and databases—people have been looking for the next “must-have” application, only for it to appear under their noses, and out of the control of any single entity. The Internet, with its ability to exchange e-mail and interface to the World Wide Web, is the killer application of the decade.

This chapter assumes that you already have physical access to the Internet, which you've been using with your Windows computer. I’m not going to help you pick a broadband carrier or sign up with a provider. There are too many options and alternatives to try to identify all of them, or even a significant proportion of them. I also assume that you wrote down your network and ISP settings as instructed in Chapter 2, “Installing Fedora Core.”

### Network connections

Both e-mail and Web browsing assume that you have a physical connection to the Internet. In order to take advantage of that connection, you have to configure your computer's settings to recognize it.

This should have been done during installation, in the Network Configuration step (and the “Assigning static IP addresses instead of using DHCP” section) of Chapter 2. But in the event that you skipped that step, because you didn’t have the information, you didn’t have a connection, or you just didn’t want to bother—or if you have to make changes—I'll explain how to change those settings during regular usage.

First, select Main Menu | System Settings | Network to bring forward the Network Configuration dialog (shown in Figure 4 shortly). Before it shows up, though, you'll get the root password dialog, shown in Figure 1.

Messing with the network configuration of a machine is not a task that an end-user should be doing—it requires root permission because it's affecting the entire machine, not just one user's settings. As a result, you'll be prompted for the root user's password in order to prove that you have root user permissions.

After you successfully enter the password, a set of keys shows up on the panel, as shown in Figure 2.

The icon is a reminder that this application is running as root. It’s a good idea to terminate that authorization when you’re done with the operation or process that required it. To do so, click the keys icon to open your authorization dialog, shown in Figure 3.

Obviously, clicking Keep Authorization doesn't change anything, while clicking Forget Authorization will remove the authorization and return your permissions to those of a regular user.

Now, back to the network settings. Once you gain root access, the Network Configuration dialog will appear, as shown in Figure 4.

This dialog allows you to manage all of the network devices in your computer. Most of the time you'll have only one network card, but if you had a second one—for example, a second network card or a wireless network card—this is where you'd set it up.

The Devices tab is displayed by default. Select a device in the list box (in Figure 4, there's only one device, eth0, and it's highlighted). Then click the Edit button in the menu at the top of the dialog (or double-click the name of the device) in order to display the Ethernet Device dialog as shown in Figure 5.

The General tab allows you to set a couple of parameters as well as provide a specific IP address that uniquely identifies your computer.

The name of the device is shown in the Nickname text box; if you had several devices, you could give them different names that made more sense than the defaults of "eth0," "eth1," and so on. For example, you might want to call the original Ethernet card "Ethernet card" and your wireless device "Wireless card."

Most of the time you're going to want to activate the device when your computer starts. One time you may not want this to happen is with a wireless device for which you want more control when it's active.
