# # Firewalls

Viruses are just one way that bad guys can bother you and your computer. If your computer is connected to the Internet, the other side can try a wide variety of ways to contact, get into, and, ultimately, take control of your computer. Remember, your connection to the Internet is not a one-way street. Just as you can use your connection to get from your computer to the Internet, other folks can use your connection to get into your computer.

When a connection is made to a computer, it first identifies the computer via its IP address. From there, it attempts to connect through a device called a “port,” which is somewhat like an extension of the IP address. Your computer’s IP address is like the main switchboard number, and the port numbers are individual telephone extensions. A typical computer has more than 65,000 ports. While that sounds like a large number, most of them are automatically closed off, and others are designated for specific common uses. For example, port 80 is used for HTTP traffic if you’re running a Web server. Ports 25 and 110 are commonly used for e-mail. Still, there are still dozens, if not hundreds of ports, any of which might potentially be open for access from the outside.

To prevent the bad guys from connecting through these ports, you can set up a firewall that stops connections through all but specific port numbers. You can implement firewalls by using hardware or software. Fedora Core comes with a software firewall that you can configure to stop incoming traffic to all but specific ports that you explicitly allow.

The firewall configuration was part of the installation process; see Step 15 and Figure 30 in Chapter 2, “Installing Fedora Core.” You may have skipped that part, in which case you need to configure it now; or you may want to take a look at how it’s set up. So, to configure your firewall, open the Security Level Configuration screen by clicking **Main Menu | System Settings | Security Level**. You’ll be prompted for the root password, and then the Security Level Configuration screen will appear, as shown in **Figure 22**.

If you’re running a workstation, you should keep the “Security level” combo box set to “Enable firewall” and leave all of the trusted services and trusted devices unchecked. That may seem counterintuitive at first; after all, wouldn’t you want, say, “WWW (HTTP)” to be selected so you can access the Web? But those options are for setting up *servers* if you were running a Web server that was going to be accessed from the outside, you’d select the WWW check box. If you were running an e-mail server, you’d select the “Mail (SMTP)” check box.
