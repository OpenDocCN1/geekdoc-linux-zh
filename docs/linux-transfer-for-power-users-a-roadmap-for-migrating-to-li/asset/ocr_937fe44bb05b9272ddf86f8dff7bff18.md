# XMS

Ever been in a situation where you had to choose which of two pretty girls to ask out? (Or been asked out by two hunky guys for the same night?) Well, I never have, but I’ve heard it’s happened to others. And I can imagine what it’s like, because having to choose between Rhythmbox and XMMS is probably similar.

I’ve used XMMS ever since I put Linux on a desktop machine, but recently started using Rhythmbox because of its radio-station capabilities. Still, like that first girlfriend, I keep coming back to XMMS.

XMMS has three primary windows in the interface. The Main window contains the controls for the player, the Playlist Editor window displays track names and times, and the Equalizer window provides the controls similar to a stereo equalizer (and eye candy for those attracted to bright and shiny things). Figure 15 shows all three windows. The Main window is on the upper left, the Equalizer is under the main window, and the Playlist Editor occupies the entire right side.

The Main window consists of several sections, much like the Rhythmbox interface. The upper left displays the time the current track has played, as well as a nifty little visualization of the sounds themselves.
