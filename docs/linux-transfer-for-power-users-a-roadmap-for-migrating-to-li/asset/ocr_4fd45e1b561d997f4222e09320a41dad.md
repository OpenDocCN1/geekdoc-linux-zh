While sparse, the main window has all that you need to scan and tweak your image. The rest of the windows just provide more functionality. I’ll take a look at them for a moment and then come back to the main window to do an actual scan.

The **Standard Options** window underneath the main window, also shown in **Figure 23**, allows you to set parameters that affect the image you’re producing from the scan.

The **Preview window**, to the left of the main window in Figure 22 and also shown in **Figure 24**, allows you to grab a preview of the image so you can adjust the original if needed.
