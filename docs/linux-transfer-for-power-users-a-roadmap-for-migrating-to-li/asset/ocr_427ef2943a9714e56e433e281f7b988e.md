Adding a radio station isn’t quite as easy as adding tracks to your Library. First, you’ll need to know the URL of a radio station that is broadcasting on the Internet. There’s a good-sized list at http://www.radio-locator.com/. If that doesn’t suit you, try searching on “Internet radio station” on the Web. Once you’ve found a station, go to its page. You’ll need to find a link on the site that says something like “Listen now” or “Streaming” or “Live broadcast.”

Under the link, you’ll find a URL that looks like this:

```
http://35.8.90.127:8080/zamen/encoder/thefix.rm
```

With that in hand, select File \ New Internet Radio Station to display the New Internet Radio Station dialog. Enter the name of the station, a genre if you want, and the URL, as shown in Figure 14. Click OK and the radio station will be added to the list. To play, just select the radio station and click the Play button. A dialog with a “Loading” thermometer bar will appear for a few seconds. Once the audio stream from the radio station catches up, Rhythmbox will start broadcasting.
