# Rhythmbox

Rhythmbox has two distinct capabilities—that of a jukebox and of an Internet radio-station player. Actually, it’s got a third capability as a CD ripper but its capabilities are limited and I’ve had mixed luck getting it to work.

Using Rhythmbox as a jukebox, you first add tracks to the Library by selecting File | Add to Library, and then navigating to the location where your tracks are stored. Once you’ve added certain tracks, they’ll appear in the browser window, as shown in **Figure 8**.

The steps for creating a playlist are somewhat counterintuitive. First select the Library source, so that the tracks are displayed in the browser window, as in Figure 8. Second, select the tracks you want to add to your playlist, as shown **Figure 9**.
