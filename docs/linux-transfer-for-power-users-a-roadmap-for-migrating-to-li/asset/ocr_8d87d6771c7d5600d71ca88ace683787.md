Konqueror is the default Web browser and all-around Swiss Army Knife for the KDE desktop. I spent a fair amount of time discussing Konqueror in Chapter 6, but glossed over browser-specific items.

When you open Konqueror, the browser appears automatically, as shown in **Figure 30**.

As with Mozilla, the first thing you’ll probably want to do is set some preferences. Click Settings | Configure Konqueror, and scroll down the list of icons on the left until you get to the Behavior icon. Here you can start to configure the browser behavior, as shown in **Figure 31**.

As you can see by scanning through the items, Konqueror also supports multiple tabs. You’ll want to look through the items in the other tabs, such as Java & JavaScript, Web Shortcuts, Cookies, and so on. An interesting feature specific to Konqueror is the ability to control how you identify yourself when visiting Web sites, as shown in **Figure 32**.

The Browser Identification tab has functions that allow you to mask your identification or even inhibit sending the browser ID at all. And you can customize this functionality per Web site or domain. This is handy for Web sites whose coding requires a specific browser, OS, or browser version.
