In the Open With context menu, you’ll find the applications that have automatically been associated with the type of file that application. In Figure 16, the file is an image file (with an extension of .tif), and so the default image-viewing applications were listed. The first application in the list will be used automatically if you simply double-click the file or select any of the Open options at the top of the context menu.

The file association isn’t keyed on the extension, though. In **Figure 17**, I’ve displayed the context menu and the Open with submenu for a file without an extension.

As you can see, Konqueror has already identified (“detected”) as a “Plain Text” file with a file size of 9 bytes. (I spare no expense when creating examples!) There are a number of associated programs in the context menu, including gedit (GNOME’s g graphical text editor), KWrite (KDE’s text editor for programmers), and Emacs (one of the classic Linux text editors), to name a few.
