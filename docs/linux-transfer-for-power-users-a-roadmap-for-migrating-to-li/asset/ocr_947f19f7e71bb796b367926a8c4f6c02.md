Another reason to set up more than one printer queue is if you've got more than one physical printer—say, a sluggish color ink jet and a zippy black-and-white laser—attached to your computer.

If you've set up more than one printer queue, you can choose which printer will be the default printer in your applications by selecting that printer and then clicking the Default button in the toolbar. Once you do so, the default printer will have a check mark in the Default column in the "Printer configuration" dialog.

# Using a print queue

So now you've got a print queue set up. So what? What do you do with it? Simply put, the print queue will be available for you to select when printing with applications. Well-behaved applications should respect the "default" print-queue settings as well.
