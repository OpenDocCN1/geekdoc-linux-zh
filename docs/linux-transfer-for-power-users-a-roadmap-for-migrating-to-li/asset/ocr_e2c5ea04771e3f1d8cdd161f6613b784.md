If you’re on a network, you might want to change this path to a network drive. Regardless of whether you keep your save path intact, you’ll probably want to change a number of other settings immediately. Here are the ones I change every time I install OOO on a new machine.

First, and this is really important, you’ll want to set the default file format in which you’ll save new documents. During installation, OpenOffice.org asks you which file format (OpenOffice.org or Microsoft Office) should be default, but based on the questions on the OpenOffice.org mailing lists, a lot of people skip by that choice, only to be puzzled by OOO’s behavior later.

In the Options dialog, select the Load/Save node and the General subnode, as shown in **Figure 8**.

Direct your attention to the “standard file format” controls at the bottom of the General page. You need to specify the default file format for each document type—it’s not an all-or-nothing type of choice. Select “Text document” in the list and then choose which type of file format to save new text documents in, using the “Always save as” box. Be sure to read the choices in this box carefully, because some of them look similar, such as “OpenOffice.org Text Document” and “OpenOffice.org Text Document Template.”

Once you’ve chosen the default file format for text documents, highlight the next item in the “Document type” list, change its file format in the “Always save as” box, and continue on for the rest of the document types.

If you choose to save files originally created in Microsoft Office in OpenOffice.org, but using a Microsoft Office file format, you may get a warning the first time you actually perform a save. This warning alerts you to the possibility that some formatting may be lost. This warning appears because the Microsoft Office format is proprietary, and so the OpenOffice.org developers have had to reverse-engineer the file formats in order to create Microsoft Office-compatible files.
