You can enter a combination of top-level tasks (such as “Linux Transfer for Power Users”), subtasks, such as “Chapter 8—Productivity,” and then cascade subtasks (such as the File Roller, KAlarm, and KArm tasks) under the “Chapter 9—Utilities” task.

To create a task, select a menu option under Task—“New” or “New Subtask” as appropriate. You can create subtasks under the currently highlighted task in the KArm window. The same dialog allows you to edit the task name as well as get a running start on the time spent on the task. For example, selecting Task | Edit will open the dialog shown in Figure 13.

The two option buttons, “Edit absolute” and “Edit relative,” can be confusing. They’re used for adding time that has already elapsed to a task that you’ve just created. “Edit absolute” allows you to replace whatever values are already there with values you enter, while “Edit relative” allows you to add more time to an existing amount. For example, in order to create Figure 12, I created a task for Chapter 8, and then entered an absolute time, 23:51, into the task. However, I had turned on the KArm task about seven minutes after I started working. Thus, to get the 12-minute value in Figure 12, I entered 5 minutes in the “Edit relative” boxes.

Once you’ve set up a task, you’ll want to start the timer against a specific task. The easiest way is to simply click the task or subtask. When you do so, a little clock will appear to the left of the elapsed time, as shown in Figure 14.

When you want to switch from one task to another, just click that new task—you can’t have the timer running on more than one task at a time.
