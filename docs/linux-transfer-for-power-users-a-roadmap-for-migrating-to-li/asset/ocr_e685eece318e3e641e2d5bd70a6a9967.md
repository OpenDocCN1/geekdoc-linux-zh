Clicking the “Show recent addresses” check box will display a list of recent addresses that you’ve used, even if you haven’t added those names to your address book.

Receiving mail is just as easy: click the Check Mail icon in the toolbar or select File | Check Mail. Messages queued up on the incoming mail server will be brought into KMail’s in-box. You can also create filters that will act on incoming e-mail and perform the actions you specify. Click Tools | Create Filter to open the Filters dialog, or right-click a message and select Create Filter. As with Evolution, there are special menu items to handle easy creation of filters on messages from mailing lists, as shown in **Figure 25**.
