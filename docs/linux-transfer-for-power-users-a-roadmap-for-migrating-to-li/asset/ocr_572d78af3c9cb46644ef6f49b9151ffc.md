It can be a pain to run this command on a regular basis just to fetch updates. It can also be a pain to scan your system manually all the time. If you’d like to perform either (or both) of these actions automatically on a regular basis, you can do so by using a Linux utility called “cron.” In Chapter 14, “Under the Hood,” I discuss in detail how to create a “cron job” by using F-Prot as a real-world example.
