Okay, just for this set of views, Konqueror is wonderfully useful to me. But, as they say, wait, there's more! First, you can split panes (repeatedly) to display multiple views. For instance, suppose you wanted to compare files at the top and bottom of a folder with lots of files. You can click one of the toolbar buttons to create a pair of panes, one above the other, and scroll independently in each of them.

The buttons in the Konqueror toolbars provide such marvelous functionality that they are worth describing briefly. The first browsers, as you can guess, are navigation buttons similar to the Back and Forward buttons in browsers like Mozilla and Microsoft Internet Explorer, and the fourth pops you back to your Home directory. The fifth simply reloads the contents of the window, whether it's a Web page or a file listing. As with other browsers, pressing the F5 key performs the same function. And the X inside a circle performs a "stop loading" operation.

The next four buttons are Cut, Copy, Paste, and Print—and do pretty much what you would expect.

The button to the right of Print, with a couple of grey folders and a yellow star, is New Tab. Tabbed browsing was made popular by Mozilla a couple of years ago; Konqueror has the same functionality built in, but it works across all of its functions, not just when browsing the Web. For instance, you could have your Home folder on one tab and a subdirectory of the "/" file system on another tab, as shown in Figure 14. Or you could even have Web pages on various tabs. Truly wonderful.

The button next to New Tab is Close Tab, which becomes enabled when there's more than one tab open. The Increase Icon Size button (the magnifying glass with the plus sign) enlarges the font size of the file listing in the right pane, while the Decrease Icon Size button does the reverse.

Figure 15 shows the right half of the Main toolbar and the entire Extras toolbar.

The first button, Icon View, and the second, Detailed List View, provide different views of the right pane.

Cervisia is a graphical front end for the client software package of CVS, a version-control system that is used in many open-source software projects. The brick wall button opens the currently selected directory in the left pane in Cervisia if that directory is a CVS directory.

The last button in the Main toolbar, the gear with the K in the center, is a progress indicator that provides feedback on the loading of data in Konqueror.

The contents of the Extras toolbar vary according to what's in the right pane. When files are listed in the pane, there are six buttons; when a Web page is displayed in the right pane, additional browser-specific button appear.
