The menu and toolbars change according to the type of document you're working on. For example, when you've got a KWord document open, the menu choices include Format, Frames, and Table; when you've got a Kontour drawing document open, the menu choices change to Layout and Style. Under the Settings menu, you can choose which objects you want to display, and that list of objects again changes according to which type of document you're working on. KWord settings include the Table, Insert, Paragraph, Format, Borders, and Formula toolbars, while Kontour includes a few of the same toolbars but also panels for Layer, Outline, Paint, and Transformation.

At the same time, common functions such as Save, Print, Edit, and View are all located in the same place in the menu regardless of which application you're using.
