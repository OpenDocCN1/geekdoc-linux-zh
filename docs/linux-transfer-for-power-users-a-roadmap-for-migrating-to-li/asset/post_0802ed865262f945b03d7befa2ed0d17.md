
The first time you look at the Stylist, you might think it has an unusual interface. It displays the styles native to OpenOffice.org in a collection called “Automatic” in the list box that makes up the majority of the window. At the bottom of the window is a drop-down box that contains a list of all style collections, including one called “Custom Styles.”

If you have applied a template (which works much like a Microsoft Office template) to the document, the Custom Styles collection lists all of the styles in that template. You can use the drop-down box to switch to the Custom Styles collection and see all of those styles. Then you can select a paragraph in the document and apply a custom style to it by double-clicking the style name, as shown in Figure 14.

Once a style is applied to a paragraph in the document, the style name shows up in the Apply Style box at the far left of the Object toolbar. In Figure 14, “chaptertitle” is the name of the style applied to the “Chapter 7” paragraph in the document.

The Applied Styles collection shown in Figure 13 is a handy reminder—it shows you just the styles that are being used in the current document. These styles are also the only ones that appear in the Apply Style box in the Object toolbar, by the way.

## The Navigator

Now on to the Navigator, possibly my favorite writing aid in OpenOffice.org. Clicking the Navigator button (or selecting Edit | Navigator, or pressing F5) displays a dialog as shown in Figure 15.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_222_0.png)

*Figure 15. The OpenOffice.org Navigator displays an outline of a variety of objects in a document.*

The Navigator is a separate window that displays an outline of a variety of objects in a document. For example, every image inserted into a document is listed under the Graphics node, while each URL is listed under the Hyperlinks node. Of particular usefulness to me is the Headings node. Each object marked with a heading style (as identified in the Outline Numbering dialog) will be displayed in an indented outline format under the Headings node.

This can be a bit tricky to implement, so let me explain a bit further. An OpenOffice.org document can have up to 10 levels of numbering, and you can assign a particular style to a level of numbering. By default, an OpenOffice.org document uses its own styles for headings, “Heading 1” through “Heading 10,” and these headings are also assigned to a level in the Outline Numbering dialog. Thus, assigning one of these styles to an object (typically a paragraph heading) can cause that object to be displayed and indented to the appropriate level in the Navigator. The document in *Figure 16* uses several native OpenOffice.org styles.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_223_0.png)

**Figure 16.** *The Navigator shows paragraphs assigned to an outline numbering level in an indented fashion.*

The heading “Paragraph 1 Heading” uses the “Heading 1” style, as you can see in the Apply Style box at the far left of the Object toolbar. The heading “Subparagraph 2 Heading” uses the “Heading 2” style. In the Navigator, then, you can see “Paragraph 1 Heading” is not indented under the Headings node, while “Subparagraph 2 Heading” is indented one level.

You may want to use your own styles instead of relying just on the native OpenOffice.org styles. You assign these styles to outline numbering levels in the Outline Numbering dialog (select Tools | Outline Numbering) as shown in Figure 17.

Clicking a number in the Level list on the left side of the dialog displays the attributes assigned to that level. In Figure 17, Level 1 is assigned to Paragraph Style "_subhead 1", the style we use for major headings in our chapters. You can see that we assign styles "_subhead 2" through "_subhead 4" to levels 2 through 4 in the list on the right side of the dialog.

The result is that you can see an outline of your document right via the indented headings under the Headings node in the Navigator. This is much like the Outliner tool in Microsoft Word, although as I’ve used it, I’ve decided it’s actually more flexible than Word.

In addition to seeing the big picture of your document, you can actually move to a spot in your document simply by double-clicking the desired item in the Navigator. This works not only for items under the Headings node, but for items under any node—graphics, URLs, bookmarks, and so on. Very handy.

You can control how many levels of outline are displayed by right-clicking in the Navigator and selecting Outline Level, and then choosing how many levels you want to view, as shown in Figure 18.

There is much more to the Navigator than I’ve covered in this short discussion, but I hope I’ve whetted your appetite enough to prod you to explore further on your own.

## Creating, printing, and saving documents

You can start a new document, spreadsheet, presentation, or other Ooo file by clicking the appropriate menu item in the Main Menu. A subtle trick is that once you have any type of Ooo document open, you can create a new document of any type through the File \ New menu. See Figure 19.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_225_0.png)

Creating a document, whether it be a word-processing document, a spreadsheet, or a presentation, works pretty much as in other office suites. Some of the functions are in different places, and some of the processes work somewhat differently. But the basics—typing in text, making it bold, changing the font and the size, building formulas, spell-checking, inserting graphics, and so on—can be figured out by anyone who can read the tooltips on the toolbar buttons.

Once you've created a document, you might want to print it. And you're definitely going to want to save it. File \ Print (Ctrl-P) and File \ Save (Ctrl-I) work just like you'd expect them to. As I said earlier, there isn't enough room in even a thousand-page book to completely do justice to OpenOffice.org. The purpose of this section, rather, was just to show you that Linux offers a viable competitor to Microsoft Office.

## KOffice

The KDE desktop environment has long been accompanied by its own desktop suite, KOffice. Comprised of a half-dozen tools, similar to OpenOffice.org, KOffice also sports a "control center" called the KOffice Workspace, which acts as a launching pad for all of the KOffice applications, as shown in Figure 20.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_226_0.png)

Figure 20. The KOffice Workspace acts as a launcher for the KOffice applications.

The menu and toolbars change according to the type of document you're working on. For example, when you've got a KWord document open, the menu choices include Format, Frames, and Table; when you've got a Kontour drawing document open, the menu choices change to Layout and Style. Under the Settings menu, you can choose which objects you want to display, and that list of objects again changes according to which type of document you're working on. KWord settings include the Table, Insert, Paragraph, Format, Borders, and Formula toolbars, while Kontour includes a few of the same toolbars but also panels for Layer, Outline, Paint, and Transformation.

At the same time, common functions such as Save, Print, Edit, and View are all located in the same place in the menu regardless of which application you're using.

A nice feature of the KOffice Workspace is that once you have opened at least one document, all of the KOffice documents appear in the Documents work area, as shown in Figure 21.
