# Permissions

**chmod**—sets permissions of files/directories.

```
chmod 755 my_file.txt
```

**chown**—changes ownership of a file. (You must be a superuser to perform this command.) To change the owner of my_file.txt from the current owner to “bob”:

```
chown bob my_file.txt
```

You can find a great discussion of permissions here: http://www.start-linux.com/articles/article_161.php.

# N.E.C. (not elsewhere classified)

**who**—shows who is logged on.

```
who
whill :0 Apr 1 21:30
whill pts/1 Apr 4 13:55 (:0.0)
whill pts/2 Apr 4 19:32 (:0.0)
```

**whoami**—displays information about the user who is currently logged in.

**cal**—displays a calendar.

```
cal 02 2004
cal 2004
```

**clear**—clears the command window.

**df**—displays total capacity and free capacity on all mounted devices.

**du**—displays disk usage.

**echo**—prints information about environment variables (or anything else, for that matter— which is useful for providing feedback during shell scripts.)

```
echo $PATH
```

**env**—displays the current environment variables.

**file**—displays the classification of a file based on the type of data it contains. The following command:

```
file abc.txt
```

returns:

```
abc.txt: ASCII text
```
