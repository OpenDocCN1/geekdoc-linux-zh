# # KAlarm

Not all Linux utilities are as involved as File Roller. KAlarm is a simple alarm-clock utility that comes with the KDE desktop environment. It runs in its own window on the desktop. To open it, select Main Menu | Accessories | More Accessories | KAlarm (see Figure 9). Selecting the Actions | New menu option (or pressing the Insert key) opens the New Alarm dialog, shown in Figure 10.
