A playlist is simply a text file stored on your hard disk that contains identifying information about the list, as well as the list of tracks themselves. You can then load this text file for replaying later via any of the multitude of Load List options.

When you create a playlist, you are given the option to save it in M3U or PLS format. M3U format looks like this:

```
``` 
#EXTM3U 
#EXTINF:301,B.B. King - Ain't Nobody's Business /home/whil/ogg/bb_king/live_at_san_quentin/aint_nobodys_bisnis... /home/whil/ogg/bb_king/live_at_san_quentin/every_day_i_have... #EXTINF:272,B.B. King - Into The Night /home/whil/ogg/bb_king/live_at_san_quentin/into_the_night.ogg 
```
```

And PLS format looks like this:

```
``` 
[playlist] 
NumberofEntries=4 
File1=/home/whil/ogg/acdc/live/dirty_deeds_done_dirt_cheap.ogg 
File2=/home/whil/ogg/acdc/live/thunderstruck.ogg

File4=/home/whil/ogg/acdc/live/we_who_rog

These are compatible with WinAmp, so you may already have some playlists on your Windows computer that you can use immediately with XMMS. Neat, eh? The Playlist Editor and Equalizer windows can float separately from the Main window or they can be docked next to or below the window. When they are docked, moving the Main window will cause the docked window to be dragged along. However, moving the docked window undocks it from the Main window. To dock either the Playlist Editor or Equalizer window, just drag it next to the Main window. Figure 15 shows the playlist docked to the right, while the equalizer is undocked.

You can also cause any of the three windows to roll up (like a window shade) by double-clicking the title bar. Doing so causes a minimal number of controls to appear in the title bar of the Main and Equalizer windows, while the Playlist Editor window just displays the title and time of the current track. Double-clicking the title bar again unrolls the window.

XMMS has long been known for providing the ability to change the appearance of the interface through add-ins known as "skins." A skin is simply a file that changes the player's appearance by overlaying the windows and controls, and altering their colors, shapes, and locations. **Figure 20** shows the XMMS Main window with the "Aretic" and "Marble" skins applied, respectively.

So where do you get skins? Pop on over to www.xmms.org and click the Skins link on the left side. Scroll through the list (there are hundreds) and click Download for a few that you find attractive. Download them into /usr/share/xmms/Skins if you can get root permission on your machine, and then they'll be available to every user on the computer. If you just want them available to you, or if you don't have root permission, download them to the _xmms/Skins directory under your home folder, such as /home/whil/xmms/Skins. The "." in front of ".xmms" means that it's a hidden folder, so you'll have to display hidden folders in order to navigate all the way in.
