Here are a couple of hints to find a specific file association. First, most of the file types are listed under “applications.” It can take a while to scroll through all of the file types, and not all of them are named what you would think. For example, you might know that OpenOffice.org is the open-source branch of Sun’s StarOffice office suite. As a result, you might think it reasonable to find that the OpenOffice.org Writer file type is “vnd.stardivision.writer” as shown in Figure 19.

![](bbox=[0.13, 0.22, 0.88, 0.58])

Figure 19. The vnd.stardivision.writer file type isn’t associated with the OpenOffice.org .sxx extension.

However, that’s not the case, as you can see that the native OpenOffice.org Writer file extension, “sxx”, is not listed in the Filename Patterns in the upper right of the tab.

So here’s the second hint. You can use the “Find filename pattern” text box above the Known Types treeview in order to look for a file type if you have an idea of at least one of the file extensions. Simply typing “sx” in the text box, as shown in Figure 20, displays all of the file types that are associated with file extensions that begin with “sx”, and you can find and confirm the file type for OpenOffice.org Writer Text Documents.

Back to our original quest—associating The GIMP with “Copper.tif” (and all other tiff files).

This task is a bit easier than the myriad in the application node. Click the image node and scroll down to the “tiff” file type. Then click Add to bring forward the “Choose Application for image/tiff” dialog, as shown in Figure 21.

Now simply navigate through the Known Applications treeview, first selecting the Graphics node, and then The GIMP node, and click OK. The GIMP will now be added to the Application Preference Order list box. Click on the row with The GIMP, then click Move Up a couple of times to maneuver it to be the default application, as shown in Figure 22.
