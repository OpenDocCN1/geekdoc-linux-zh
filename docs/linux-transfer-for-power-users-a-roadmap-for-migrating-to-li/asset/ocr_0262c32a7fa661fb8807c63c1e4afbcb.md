# Package Installation Defaults

The selection of one of the four Installation Types in step 10 earlier (see Figure 25) drives the assembly of a list of packages that will be installed. At this step, you have the chance to modify the list of packages.

**Step 20.** If you want to accept the default set of packages, keep the “Install default software packages” choice selected. If you want to be able to modify the list of packages, select the “Customize software packages to be installed” option button.

In both cases, click Next. If you selected “Install default,” continue reading with step 22. Otherwise, continue with the next step, Package Group Selection. If you’re customizing the list, you’ll see the Package Group Selection screen, as shown in **Figure 35**.

# Package Group Selection

The Package Group Selection screen displays the packages that are selected by default based on the Installation Type you selected in step 10 and shown in Figure 25.

The packages you select at this point are purely a matter of personal choice and personality. Some people like to install everything under the sun, finding it handy to have anything they might need at arm’s length. Others want to keep things to a minimum, figuring that the less software that’s installed means fewer potential security holes, and makes using the system less confusing, due to fewer choices to deal with. It’s up to you which way you want to go. A full installation will run about 5 GB, while a minimal installation will be closer to 1 GB. You can even have the installer select a minimal configuration or install everything (including some items not listed in the separate package groups), as shown in **Figure 36**.
