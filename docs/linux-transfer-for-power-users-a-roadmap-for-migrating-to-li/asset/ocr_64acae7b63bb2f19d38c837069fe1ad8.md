Select the pictures you want to actually download from the camera. You can either highlight selected pictures in the right pane, or, if you want all of the pictures, open the Select menu and click All. The selected images are identified by highlighted file names (see **Figure 6**).

The next step is to initiate the downloading itself. To do so, click File \| Save Selected Photos (see **Figure 7**). This dialog provides several capabilities. First, you can navigate to the folder you want to save the files in, and if the folder in question doesn’t exist, you can create a new one without leaving the dialog.

Selected pictures in the right pane are displayed with highlighted file names.

The "Save photos..." dialog allows you to determine what attributes to save as well as how to name the files on your hard disk.
