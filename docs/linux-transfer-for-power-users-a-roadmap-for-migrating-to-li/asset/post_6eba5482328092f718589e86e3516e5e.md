## Draw icons with KIconEdit

One type of very specialized graphic file is the icon—the picture that is attached to a program shortcut on the desktop or panel. Icons have certain properties that make it awkward (and in some cases impossible) to use some drawing programs. For example, you can create an icon with KPaint as described in the previous section, but you need to know that an icon is either 16 or 32 pixels square, and you have to know what file format to use for Linux (PNG is best). And you have to be able to eyeball your drawing, because KPaint doesn’t have a grid overlay that allows you to count pixel by pixel.

Fedora Core comes with KIconEdit, a program designed specifically for creating and manipulating icon files, and not only solves these issues but also provides additional features. Open the editor window by clicking Graphics | More Graphics Applications | Icon Editor. You’ll see the empty Icon Editor window, shown in Figure 18.

Icons are simple bitmaps of a certain size; KIconEdit comes preconfigured as a 32-pixel-square drawing area. You can toggle the grid on and off by clicking the Grid button in the toolbar or by selecting Settings | Show Grid. This is handy—it’s easier to count pixels with the grid on, but then view the final result with the grid off.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_264_0.png)

The toolbar on the side provides the ability to draw freehand or create predefined shapes such as rectangles, circles, and ellipses (all either filled or empty), and straight or diagonal lines. You can also use a spray can or a flood fill, and erase through an area that had been drawn on.

The color pickers on the side provide a fixed set of colors but also allow you to create a palette of custom colors; double-clicking one of the squares in the “Custom colors” picker opens the KDE standard Select Color dialog, shown in Figure 19.

The Preview box in the upper right corner above the “System colors” picker shows you a 1:1 display of what your icon will look like. You can change the background of the Preview box by clicking Settings | Configure KIconEdit to provide a higher contrast if you like.

Finally, you can save your icon by clicking File | Save As. The Save As dialog has the PNG filter already selected, but you can choose a different file format if you desire.

## Modifying images with The GIMP

The GIMP (The GNU Image Manipulation Program) is an application somewhat comparable to PC Paintbrush, Paint Shop Pro, and Photoshop. It provides a wide variety of image- and photograph-manipulation capabilities. For example, many of my authors use it on Linux to capture and modify screen shots for their books.

But The GIMP's capabilities go far beyond that; indeed, there are 900-page books that cover all of The GIMP's nooks and crannies. Some of its general image-manipulation capabilities (beyond screen-shot work) include a variety of tools, such as sharp and fuzzy drawing tools, airbrushes, fills, reverses, transparencies, and stamping; and selection tools such as freeform, rectangular, elliptical, fuzzy, and intelligent scissors. You can rotate, scale, shear, flip, resize, resample, feather, and magnify images, and use a number of alternatives to crop them.

The GIMP also supports advanced scripting via Perl, Python, and others; you can use these scripts to access internal GIMP functions. In addition, a comprehensive plug-in system allows you to extend The GIMP with new functions, filters, file formats, and other additions.

As you’re starting to see, The GIMP is tremendously powerful, but its interface causes it to be one of those classic open-source tools that one either loves or hates; actually, many people love it and hate it at the same time.

Many people open The GIMP, struggle with it for a bit and give up, completely frustrated. In this section, I’ll show you how to get started with The GIMP.

### The GIMP interface

Load The GIMP by selecting Main Menu | Graphics | The GIMP. One of the two main GIMP windows (the Toolbox) appears, as shown in **Figure 20**.

The other main GIMP window (Image) appears once you have an image to work with. Select File | Open and navigate to the image you’re interested in. You’ll then see the image in the Image window, shown in **Figure 21**.

The Image window is where the action occurs—it’s where you’ll do most of your work. Open the Brush Selection window by clicking the round dot in the lower right area of the Toolbox window. ## Capturing a screen shot

As I mentioned at the beginning of this chapter, getting a copy of something you see on your computer screen to place in a document is a common task for many power users. The GIMP has the ability to acquire a copy of either the entire screen or a specific window.

In the Toolbox menu, select File | Acquire | Screen Shot to bring forward the Screen Shot dialog, shown in **Figure 25**. (*Y'm in your way* | GIMP) to capture its own screens. Self-referential documentation!)

If you want to capture just a single window, select the **Single Window** option button. If you deselect the *With Decorations* check box, the title bar and buttons in the upper left and right corners will not be captured along with the contents of the window.

If you want to grab the whole screen, select the **Whole Screen** option button. I often use this feature when I want to capture more than one window at a time. First, I open an application that has an empty, white background, such as the gedit editor window. Then I position the windows in question adjacent to each other, on top of the empty window, so that they're on top of a white background. Finally, I do a Whole Screen screen shot and crop the area I'm interested in. That's how I created Figures 22 and 23. You could also create those figures by capturing each separately, and then joining them in a third file, but often that's more work than simply moving the windows around and grabbing one screen shot.

If you want to capture a window that has a selected menu item (see **Figure 24**) or an open combo box (see **Figure 16**), you'll need to do a Whole Screen capture, even if you're just working with one window.

You can choose how long to wait before the capture actually happens by using the "**after NN Seconds Delay**" spinner control—if you have to open menus or manipulate controls in windows, this gives you the required delay. You'll hear a pair of beeps about a second and a half before the capture occurs.
