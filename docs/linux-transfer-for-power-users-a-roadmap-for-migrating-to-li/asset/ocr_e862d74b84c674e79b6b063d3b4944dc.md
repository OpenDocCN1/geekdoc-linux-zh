# About to Install!

Caution: Once you click Next, the installation program will begin writing the operating system to the hard drive(s). This cannot be undone. If you decided not to continue installation, this is the point at which you can safely abort the installation process.

To abort this installation and return all installation media, at your computer's Reset switch using Ctrl+Alt+Del.

The software you have selected to install will require the following CDs:

+   * Fedora Core 1 CD #1
+   * Fedora Core 1 CD #2

Please have these ready before proceeding with the installation. If you need to abort the installation and reboot your system, please select 'Reboot'.

The Required Install Media dialog will begin installation. When done, you can be found in the general log after restarting the system. To verify that the installation took place, you can check the /var/log/install.log file.
