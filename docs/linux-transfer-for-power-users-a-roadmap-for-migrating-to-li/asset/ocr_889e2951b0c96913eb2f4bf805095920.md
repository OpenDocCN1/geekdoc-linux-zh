The second option, Ignore, allows you to ignore the device for good. You can have the device detected automatically later if you run Kudzu from the command prompt. This option is handy if you want to investigate the hardware you’re adding before running Kudzu, or if you want to manually configure the device yourself. You would also use this option when you’ve temporarily added a device that you’re going to remove soon.

The third option, Do Nothing, sounds similar to Ignore, but it really isn’t. It allows you to temporarily ignore the device; the next time you boot up your computer, Kudzu will run again as if it were the first time. You might use this option if you’ve added a device but don’t want to spend the time configuring it right now. It usually doesn’t take long (a few seconds to a half minute) but in the event that something doesn’t work, you may end up spending more time getting it to work than you had planned, and it’s handy to be able to ignore the detection if you aren’t ready to commit the time.

# Adding a print queue

Once you’ve installed a printer, your second step is to create a print queue—a definition of how to talk to that printer from your computer.

Select Main Menu | System Settings | Printing, and you’ll be asked for the root password because you’re changing system-wide settings. Upon successful entry of the password, the “Printer configuration” dialog will appear (see **Figure 3**).

Click the New button to start the “Add a new print queue” wizard, shown in **Figure 4**.

Click the Forward button, as there’s not that much interesting on this screen, and you’ll be greeted by the “Queue name” dialog, shown in **Figure 5**.

The queue name is used throughout your system when you print, so you’ll want to provide a short but descriptive name. “LocalHP400” or “MyCanon1200” are pretty good names, while “BozoMan” and “MyPrinter” are probably not so good. Exactly what you use depends on the variety of printers you might have access to. If you have a number of different laser printers, the queue names used in Figure 5, locally, wouldn’t be descriptive enough, but if you only had a laser and an ink jet, then that semi-generic name would be fine.

You can add more information about your print queue in the “Short description” box if you need. It’s probably a good idea to identify at least the make and model, maybe the location (although some printers tend to be moved a lot), and perhaps any other printer-specific or queue information.
