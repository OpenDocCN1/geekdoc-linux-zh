This is where the action is. Select a print queue in the list and then click the Edit button, and you'll be in the “Edit a print queue” dialog, shown in Figure 14.

![](bbox=[0.1, 0.15, 0.6, 0.57])

*Figure 14. The “Edit a print queue” dialog allows you to continue configuring the print queue.*

This dialog allows you to set all sorts of advanced options for the print queue. For example, the “Queue options” tab allows you to set the margins for the area that can be printed upon, as well as select banner pages for the start and end of the job—which can be handy for identifying which print job belongs to whom, if more than one person uses the printer. The “Driver options” tab, as shown in Figure 14, has a number of settings that you may want to modify according to your specific needs. As you can see, you can change parameters such as resolution, number of copies, and manual sheet feed. As a result, you can set up multiple queues for the same physical printer that simply have different attributes, and then just select the appropriate option instead of changing those attributes each time you want to print in a special way.

![](bbox=[0.1, 0.84, 0.16, 0.9])

You could use this capability to set up a 300-dpi queue for “draft” printing and a 600-dpi (or 1200-dpi, depending on your printer) for “final printing.” Similarly, you could set up a “grayscale” queue on a color printer for drafts in order to conserve color ink.
