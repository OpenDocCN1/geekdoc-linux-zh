# File manipulation

cp—copies one or more files.

```
cp installation.pdf ~/newfiles

cp installation.pdf ~/newfiles/dummy.pdf

cp installation.pdf ~/xips/installation.pdf

cp *.pdf olderversions
```

mv—moves (renames) files. The following command moves ~/x.pdf to ~/temp/x.pdf:

```
mv x.pdf temp
```

And the following command renames ~/x.pdf to ~/y.pdf:

```
mv x.pdf y.pdf
```

rm—removes files. When used with “-r” (recursive), this command is dangerous. And if you
use it with “-r” while you're running as root, it’s very dangerous. Experienced Linux users
believe that the phrase “Oh S***!” was initially coined after someone who was logged in as
root executed an errant “rm -r” command on a large server.

```
rm *.pdf

rm -R *.pdf
```

# Finding stuff

apropos—As you’re learning Linux, this is a great command because it helps you find other
commands that you can’t quite remember. It produces a list of commands whose keywords
contain the parameter entered after the command.

```
apropos concatenate
```

```
returns

Tcl_Concat(3) - concatenate a collection of strings

Tcl_Concat(Concat)(3) - concatenate a collection of strings

cat-(1) - concatenate files and print on the standard output

g3cat(1) - concatenate multiple g3 documents

ospent(1) - Concatenate entities

pncat(1) - concatenate portable anymaps

strcat(3) - concatenate two strings

stconcat(stcat)(3) - concatenate two strings

tac(1) - concatenate and print files in reverse

wccat(3) - concatenate two wide-character strings

wcconcat(3) - concatenate two wide-character strings
```

find—finds files according to a large variety of information. The following command results in
nothing:

```
find he
```
