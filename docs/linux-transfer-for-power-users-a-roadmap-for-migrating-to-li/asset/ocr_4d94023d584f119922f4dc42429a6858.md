*Tabs in the browser window enable you to move from one Web site to another without leaving the current browser window.*

There’s a new element in the browser, immediately above the browser window itself. Look for the icon to the left of two wide, rectangular boxes. The “Open a new tab” icon does just what it says. This icon disappears in two cases: when there is only one tab to display, and when the “Hide the tab bar” check box mentioned earlier is selected.

The two wide, rectangular boxes are simply the tabs; in Figure 28, the first is for the hidden Fedora Project tab and the second is for the visible window that is displaying the SuSE home page.

You can create a new browser window by using the File | New | Navigator Window command, or by pressing Ctrl-N. Create a new tab within the existing browser window by using the File | New | Navigator Tab command, or by pressing Ctrl-T.

When more than one tab is displayed, a Close box (X icon) will appear in the far right of the tab bar so that you can close a specific tab without having to close the entire browser window.

In the Privacy and Security node, you’ll find a number of useful settings, as shown in Figure 29. For example, under the Cookies node, you can manage your stored cookies and specify how you want to handle the default behavior of new cookies. Use the Popup Windows node to deal with pop-up windows in the manner you choose, and use the Forms and Passwords nodes to specify whether or not Mozilla will remember data and passwords that you enter.
