# Summary

Usable desktop applications have been the sticking point that have kept people from using Linux as a day-to-day computing environment. Fedora Core includes a wide variety of common office and productivity applications that enable a typical Windows power user to move from their Windows applications to compatible Linux tools with a minimum of fuss and bother. Linux is now truly ready for the desktop.
