MPlayer (http://www.mplayerhq.ru) is another open-source tool that has developed quite a following; but, again, using it isn't as simple as just downloading a file and installing it. You need to figure out what files to download and then install them, taking care of all the dependencies as well as wrestling with the appropriate codecs (software that allows you to play selected types of files, such as MPG, QuickTime, Real, and so on).

A search on the Web will turn up a number of other tools. Be careful before throwing your lot in with one; some are rather old and haven't been maintained, while others have onerous licensing issues. And, of course, there's always the chance that you'll find the perfect tool, only to discover that Linus Torvalds himself couldn't install it successfully without losing handfuls of hair.
