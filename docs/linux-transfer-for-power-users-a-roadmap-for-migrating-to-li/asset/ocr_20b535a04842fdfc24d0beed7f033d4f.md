When you capture just a window, the name of the file defaults to “Screenshot-” and then adds the name of the window to the file name. The default file format is still PNG. The default file name for the screen captured in Figure 13 was “Screenshot-Gnome-keybinding-properties.png”.

The GIMP, an image manipulation program that comes with all popular Linux distros, has a more advanced screen-shot-capture feature. It’s discussed later in this chapter.

# Draw freehand images with KPaint

Another avenue for creating images is to draw them yourself. Fedora Core comes with an open-source tool called KPaint, which mimics the Windows painting programs that you might have used. To open KPaint, select Graphics | More Graphics Applications | Paint Program. Figure 14 shows the resulting KPaint window.

Once you’ve opened an empty canvas, the first thing you’ll probably want to do is change the size. The default canvas size is 320 pixels wide by 200 pixels tall (you can find this out by looking in the far left of the status bar or via the Image | Information menu command if the status bar isn’t visible). Select Image | Resize to open the New Canvas Size dialog, shown in Figure 15.

If you don’t check the “Keep picture ratio” check box, you can enter values in either or both of the Width and Height text boxes independently, creating a new canvas with a different proportion than 320 x 200. If you check the check box, the Height text box becomes disabled and you can enter a new value in the Width text box. The height will automatically be adjusted.

The second thing you’ll want to do is select what color you want to draw with. The default color is displayed in the left of the two color boxes in the upper half of the screen. You can choose your own color by using the multipurpose color-chooser control in the upper right quadrant of the dialog. Click the Recent Colors box to display a set of choices for populating the box underneath it with color selections, as shown in Figure 16.

Each item in the combo box has its own set of color choices, ranging from 40 basic colors to “Web-safe” color choices to your own set of custom-selected colors.
