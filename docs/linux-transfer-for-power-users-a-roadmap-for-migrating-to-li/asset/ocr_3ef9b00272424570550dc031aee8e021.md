Because this book is using Fedora Core, download the RPM file to a directory. I keep a subdirectory under my home directory specifically for software installation files I download—/home/whil/zips—and this is where I’d put the RPM file from F-Pro. On the page for the link for the RPM file, there should also be a link for the MD5SUM file. Click on that next. It should open a browser window, shown in Figure 17.

![](bbox=[0.09, 0.19, 0.95, 0.39])

Figure 17. Clicking the MD5SUM link will display the md5sum string in the browser.

Open a command window and change to the directory where you saved the RPM. For me, that would be this command:

```
``` 
cd /home/whil/zips
```
```

But your command might be different. Then type this:

```
``` 
md5sum fp-
```
```

Then press the Tab key. It’ll automatically complete the rest of the command for you. Press the Enter key, and the md5sum for the file you downloaded will appear in the command window. Compare this with the md5sum value you downloaded, and if they match, you’re all set. (If they don’t, trying downloading the RPM file again; most likely, the file was corrupted during downloading.)

Now install it. The F-Pro documentation instructs you to use the “rpm” command in the command window, like so:

```
``` 
rpm -Uvh /path/to/fp-linux-ws-VERSION.rpm
```
```

But you don’t have to. Because it’s an RPM file, you can just double-click the RPM file in GNOME or Konqueror. If you run RPM from one of the file managers, you’ll go through the standard RPM install process. First it will request the root password, because you’re installing a system-wide package.
