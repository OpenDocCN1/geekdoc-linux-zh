Instead, one uses a piece of software called a "ripper" that extracts the raw digital audio files on the CD and creates a new type of audio file, a Wave file (WAV), which is usually stored on a hard disk. These WAV files are great for a number of reasons, including sound quality and ubiquitous acceptance, but they're also huge. As an example, Bob Seger's live rendition of "Nuthush City Limits," a 4:37 track, becomes a 49 MB WAV file. That's a lot of ones and zeros. Most people will then convert the WAV file to a different format that sounds just as good but takes considerably less space, such as MP3 or OGG. "Nuthush" in OGG format only takes 4.3 MB. However, some rippers will bypass creating the WAV file and generate an MP3 or OGG file immediately.

# Audio formats

Before I discuss the ripping processes, I need to discuss file formats in more detail.

As mentioned, audio files can be saved in a variety of formats—in fact, a quick search on the Web will generate a list of more than 100. Popular formats include CDA (CD Audio Track), MP3 (Moving Picture Experts Group Audio Layer), OGG (Ogg Vorbis), RA, RAM, and RPM (varieties of RealNetworks Real Audio compressed streaming data), WAV (WAVEform audio format from Microsoft and IBM), and WMA (Windows Media Audio). Here's a little more information about these formats:

+   * CDA is the native format found on a CD and is transparent to file management programs such as Nautilus and Konqueror.
+   * MP3 is a compressed format with very good sound quality. It requires a plugin or helper application. A proprietary format, MP3 requires royalty payments and can't be used by open-source projects.
+   * RA, RAM, and RPM: These formats are very highly compressed, with poorer quality sound. They require a plugin, and they're proprietary.
+   * WAV format has very good sound quality, is widely supported, but results in very large file sizes. The sound quality is so good because the file is an exact 1:1 copy of the digital data on the CD itself.
+   * OGG offers very good sound quality in a compressed format. Vorbis is unpatented, and doesn't have the licensing issues of proprietary formats such as MP3 or WMA.
+   * WMA is a very good quality, proprietary format from Microsoft, and recent versions feature digital rights management. The WMA file extension (as opposed to ASF) indicates that the file contains only audio.

# Which format should you choose?

With so many to pick from, which should you choose? MP3 is the established leader because it was the first to market, but it's a proprietary technology, which means it can't be included in open-source projects. A similar issue restricts the use of the WMA format. Many open-source users have gravitated to the Ogg Vorbis format, which offers similar (and in some cases, superior) performance without the licensing issues associated with proprietary formats.
