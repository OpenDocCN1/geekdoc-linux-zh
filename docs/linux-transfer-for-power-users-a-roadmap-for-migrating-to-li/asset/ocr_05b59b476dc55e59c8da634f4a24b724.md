Let’s examine each of these in more detail.

# Linux is only for servers.

Interestingly enough, Linux started its life as a desktop operating system, albeit one for sophisticated and knowledgeable programmers. As time passed, the core components became more mature, leaving undeveloped the interfaces that less knowledgeable users would require. Because Linux was modeled after an operating system that had its roots in the server room, it was capable of running servers right out of the box, while the desktop usage lagged.

But that was then, and this is now. Mass-market distributions come with all the bells and whistles you need to run a modern desktop. Installing and using popular distributions like Fedora Core, SuSE, and Mandrake on a desktop computer is just as easy, and in some cases, easier than Windows. And while the surface looks a bit different, once you get your hands into it, things work (most of the time) much like you’d expect them to.

# Linux is only for techies.

This myth used to be completely true. Until a few years ago, you had to install Linux using scripts and processes that bore no resemblance to those that a Windows 95 user was used to. To install software after installation, you had to wade through scripts, recompile binaries from source code, and deal with inscrutable files such as tarballs.

Eventually some Linux distributions came with GUI-based wizards, but even they required a considerable amount of technical knowledge. Indeed, as recently as two years ago, the first question you were asked when installing Red Hat Linux had to do with mapping mount points and partitions. Huh?

Once you were up and running, it wasn’t unusual to run into some operation or another that required you to enter arcane commands at a command prompt, edit random configuration files, or, in a fair number of cases, compile software in order to run it.

That situation has changed a great deal over the past couple of years. As mentioned in the previous section, popular distributions come with easy-to-use wizards and widgets that allow you to run Linux virtually all the time without worrying about a command prompt. Installing software is often (although not always) as easy as double-clicking on a file.

However, that doesn’t mean that Linux has been dumbed down. Rather, it’s simply been given an easy-to-use layer on top of the sophisticated internals that have always been there. If you’re interested in getting down and dirty with the guts of an operating system, the opportunity is still there.
