All the standard functions are evident: an address bar for navigating to URLs, Back, Forward, Reload, and Home buttons, and so on. So the first thing you'll want to do is change the preferences so that Mozilla works the way you want it to.

# Mozilla preferences

In order to change your preferences, select Edit | Preferences from the Mozilla menu. The Preferences screen appears, as shown in **Figure 27**.

![](bbox=[0.09, 0.26, 0.72, 0.63])

The Category treeview on the left provides access to a variety of groups of functions. Work your way through them as your time and desire allows; I'll take just a moment to point out a few preferences that I find myself setting right away.

First, in the Navigator node, you can control what happens when the browser starts up. I set up Mozilla to load a default home page, and then set that home page to an HTML file on my computer that contains a bunch of Web sites that I frequent.

Second, under Internet Search, I set the Default Search Engine to Google, and in Tabbed Browsing, I select the check box “Hide the tab bar when only one tab is open.”

If you’re unfamiliar with tabbed browsing, it may well be worth your time to learn about it. Many people often have more than one browser window open, which can be annoying and confusing when you suddenly have a half-dozen or more browser windows floating around on your screen. Mozilla pioneered the use of tabbed browsing, in which you can open new Web sites on new tabs in the existing browser window, instead of opening up brand-new windows. See **Figure 28**.
