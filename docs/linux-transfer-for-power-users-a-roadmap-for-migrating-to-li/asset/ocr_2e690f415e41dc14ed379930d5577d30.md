Probably the biggest impediment to widespread adoption of KOffice is that, while it can read Microsoft Office files, it can’t save in Microsoft Office formats. Funny enough, it will save in many other formats, including WordPerfect, Lotus AmiPro, Rich Text, AbiWord, and a variety of plain-text formats. As a result, KOffice isn’t a good choice if you exchange documents with folks using files formatted with Microsoft Office file formats (which is nearly everyone).

The KOffice documentation is generally excellent, although there are a couple of places where it’s missing from the original distribution. In those cases, the help file presents a page that directs you to the KDE Web site for documentation updates.
