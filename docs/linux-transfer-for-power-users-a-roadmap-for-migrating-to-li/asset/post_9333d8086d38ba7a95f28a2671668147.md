
![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_200_0.png)

Clicking the “Show recent addresses” check box will display a list of recent addresses that you’ve used, even if you haven’t added those names to your address book.

Receiving mail is just as easy: click the Check Mail icon in the toolbar or select File | Check Mail. Messages queued up on the incoming mail server will be brought into KMail’s in-box. You can also create filters that will act on incoming e-mail and perform the actions you specify. Click Tools | Create Filter to open the Filters dialog, or right-click a message and select Create Filter. As with Evolution, there are special menu items to handle easy creation of filters on messages from mailing lists, as shown in **Figure 25**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_200_1.png)

One interesting difference between Evolution and KMail is that the latter has a set of Mailing-list-specific options, such as “New Message to Mailing List” and “Reply to Mailing List.”¹² These are used in conjunction with folders that you associate with mailing lists by setting those folder’s properties.

## Web browsing

In 2004, there’s not much to say about setting up or using a Web browser, other than to mention that you have choices with Linux and Fedora Core, unlike with other operating systems that insist “the browser is an integral part of the operating system” and then force a browser down your throat whether you want to use it or not.

While many browsers are available, I’ll just cover two of the most popular ones—Mozilla and Konqueror—like I did in the e-mail section in this chapter.

### Mozilla

Mozilla is the open-source descendant of Netscape’s Navigator Web browser. I actually started using it before I started using Fedora Core because a version of Mozilla has been available for Windows for a couple of years. As a result, it was an easy and natural migration to begin using it with Fedora Core as well, and it’s my preferred browser.

Mozilla is the default Web browser for the GNOME desktop, and looks pretty much like any good graphical Web browser, as shown in **Figure 26**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_201_0.png)

**Figure 26. Mozilla is the default browser for Fedora Core.**

All the standard functions are evident: an address bar for navigating to URLs, Back, Forward, Reload, and Home buttons, and so on. So the first thing you'll want to do is change the preferences so that Mozilla works the way you want it to.

#### Mozilla preferences

In order to change your preferences, select Edit | Preferences from the Mozilla menu. The Preferences screen appears, as shown in **Figure 27**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_202_0.png)

The Category treeview on the left provides access to a variety of groups of functions. Work your way through them as your time and desire allows; I'll take just a moment to point out a few preferences that I find myself setting right away.

First, in the Navigator node, you can control what happens when the browser starts up. I set up Mozilla to load a default home page, and then set that home page to an HTML file on my computer that contains a bunch of Web sites that I frequent.

Second, under Internet Search, I set the Default Search Engine to Google, and in Tabbed Browsing, I select the check box “Hide the tab bar when only one tab is open.”

If you’re unfamiliar with tabbed browsing, it may well be worth your time to learn about it. Many people often have more than one browser window open, which can be annoying and confusing when you suddenly have a half-dozen or more browser windows floating around on your screen. Mozilla pioneered the use of tabbed browsing, in which you can open new Web sites on new tabs in the existing browser window, instead of opening up brand-new windows. See **Figure 28**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_203_0.png)

*Tabs in the browser window enable you to move from one Web site to another without leaving the current browser window.*

There’s a new element in the browser, immediately above the browser window itself. Look for the icon to the left of two wide, rectangular boxes. The “Open a new tab” icon does just what it says. This icon disappears in two cases: when there is only one tab to display, and when the “Hide the tab bar” check box mentioned earlier is selected.

The two wide, rectangular boxes are simply the tabs; in Figure 28, the first is for the hidden Fedora Project tab and the second is for the visible window that is displaying the SuSE home page.

You can create a new browser window by using the File | New | Navigator Window command, or by pressing Ctrl-N. Create a new tab within the existing browser window by using the File | New | Navigator Tab command, or by pressing Ctrl-T.

When more than one tab is displayed, a Close box (X icon) will appear in the far right of the tab bar so that you can close a specific tab without having to close the entire browser window.

In the Privacy and Security node, you’ll find a number of useful settings, as shown in Figure 29. For example, under the Cookies node, you can manage your stored cookies and specify how you want to handle the default behavior of new cookies. Use the Popup Windows node to deal with pop-up windows in the manner you choose, and use the Forms and Passwords nodes to specify whether or not Mozilla will remember data and passwords that you enter.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_204_0.png)

Figure 29. The Cookies tab is where you'll find the Manage Stored Cookies functionality.

Under the Advanced node's Scripts and Plugins node, you control what actions scripts are allowed to perform. For example, you can turn on or off the ability for scripts to:

- Move or resize existing windows
- Raise or lower windows
- Hide the status bar
- Change the status-bar text
- Change images
- Create or change cookies
- Read cookies

And under the Software Installation node, you can control whether or not software installation will be enabled, and how often—if ever—your machine will look for updates to Mozilla.

One of the handiest tips for using Mozilla (it works in Windows, too) is the pair of keyboard shortcuts, Ctrl-+ and Ctrl--. Holding down the Ctrl key and then pressing the plus key (it's easier on the numeric keyboard since you don't have to hold down the Shift key too) will zoom the text size up one level. Holding down the Ctrl key and pressing the minus key will reduce the size of the text.

Konqueror is the default Web browser and all-around Swiss Army Knife for the KDE desktop. I spent a fair amount of time discussing Konqueror in Chapter 6, but glossed over browser-specific items.

When you open Konqueror, the browser appears automatically, as shown in **Figure 30**.

As with Mozilla, the first thing you’ll probably want to do is set some preferences. Click Settings | Configure Konqueror, and scroll down the list of icons on the left until you get to the Behavior icon. Here you can start to configure the browser behavior, as shown in **Figure 31**.

As you can see by scanning through the items, Konqueror also supports multiple tabs. You’ll want to look through the items in the other tabs, such as Java & JavaScript, Web Shortcuts, Cookies, and so on. An interesting feature specific to Konqueror is the ability to control how you identify yourself when visiting Web sites, as shown in **Figure 32**.

The Browser Identification tab has functions that allow you to mask your identification or even inhibit sending the browser ID at all. And you can customize this functionality per Web site or domain. This is handy for Web sites whose coding requires a specific browser, OS, or browser version.
