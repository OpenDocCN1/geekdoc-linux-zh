If you are able to send the test page to the printer but it doesn't print, answer "No" to the confirmation dialog shown in Figure 10. If you answer "No", you won't get one of those helpful dialogs that simply says "Printing failed" and offers you a choice of one button that says "OK" (which you might be used to with other operating systems). Instead, to help you troubleshoot the problem, it displays an information dialog containing messages that were logged in the printing error log. A sample is shown in Figure 12.
