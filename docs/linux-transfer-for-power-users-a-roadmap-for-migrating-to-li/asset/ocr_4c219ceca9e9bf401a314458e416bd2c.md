Once Windows hit, I started using Windows Explorer to navigate through the files on my system, and then started using PowerDesk as Explorer’s replacement once it was released. So I have a long-time bias toward using graphical file managers.

As with any software category, a number of graphical file managers are included with mainstream distributions of Linux. Fedora Core includes three popular file managers. Nautilus is the default graphical file manager for GNOME, Konqueror is the default graphical file manager for KDE, and Midnight Commander is a popular character-based file manager called from the command line.

I’ll discuss Nautilus and Midnight Commander briefly, and then spend more time with Konqueror, because it’s quickly become my personal favorite.

# ### Midnight Commander

Midnight Commander, or “MC” as it’s called by many folks, is a character-based file manager that mimics many of the functions that full-featured graphical file managers have. If you’re an old-time DOS user, you may notice a distinct similarity to the DOS Norton Commander, and for good reason.

To run MC, open a terminal window and type “mc”. MC will appear in a window as shown in Figure 6.

MC is terrifyingly robust, and packed with functionality. Because it’s not a GUI, it doesn’t require a lot of system resources. One could write a small book just on MC, but that’s beyond the scope of this discussion. Instead, I’ll just give you a quick tour.

Despite it being a character-based tool, MC is accessible via keyboard and mouse, as well as a combination of both, so it will work with you regardless of your own personal style.
