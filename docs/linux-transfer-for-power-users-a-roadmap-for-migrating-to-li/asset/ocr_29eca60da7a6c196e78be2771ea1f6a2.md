# Installation

OpenOffice.org is installed by default with a desktop installation of Fedora Core. If you neglected to install it for some reason, use the Add/Remove Applications menu item under System Settings. Once it’s installed, menu items for each of the OpenOffice.org tools will be available under Main Menu | Office, as shown in Figure 7.

Icons for each of the OoO applications are also available in the panel; I’ve removed all of them except for Writer, because I don’t use the others that much, and the real estate on my panel is valuable.

# Configuration and options

As soon as you start creating documents, you’re going to want to perform operations—and some of these can be configured to your liking. So before I talk about working with documents, let’s spend a moment setting up OoO so that it behaves the way you want.

There are two places to bend OoO’s behavior to your will—one is under Tools | Options, where you can control how OoO functions. And it’s here that we’ll spend our time first.
