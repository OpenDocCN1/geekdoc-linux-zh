Instead, one uses a piece of software called a "ripper" that extracts the raw digital audio files on the CD and creates a new type of audio file, a Wave file (WAV), which is usually stored on a hard disk. These WAV files are great for a number of reasons, including sound quality and ubiquitous acceptance, but they're also huge. As an example, Bob Seger's live rendition of "Nuthush City Limits," a 4:37 track, becomes a 49 MB WAV file. That's a lot of ones and zeros. Most people will then convert the WAV file to a different format that sounds just as good but takes considerably less space, such as MP3 or OGG. "Nuthush" in OGG format only takes 4.3 MB. However, some rippers will bypass creating the WAV file and generate an MP3 or OGG file immediately.

## Audio formats

Before I discuss the ripping processes, I need to discuss file formats in more detail.

As mentioned, audio files can be saved in a variety of formats—in fact, a quick search on the Web will generate a list of more than 100. Popular formats include CDA (CD Audio Track), MP3 (Moving Picture Experts Group Audio Layer), OGG (Ogg Vorbis), RA, RAM, and RPM (varieties of RealNetworks Real Audio compressed streaming data), WAV (WAVEform audio format from Microsoft and IBM), and WMA (Windows Media Audio). Here's a little more information about these formats:

- CDA is the native format found on a CD and is transparent to file management programs such as Nautilus and Konqueror.
- MP3 is a compressed format with very good sound quality. It requires a plugin or helper application. A proprietary format, MP3 requires royalty payments and can't be used by open-source projects.
- RA, RAM, and RPM: These formats are very highly compressed, with poorer quality sound. They require a plugin, and they're proprietary.
- WAV format has very good sound quality, is widely supported, but results in very large file sizes. The sound quality is so good because the file is an exact 1:1 copy of the digital data on the CD itself.
- OGG offers very good sound quality in a compressed format. Vorbis is unpatented, and doesn't have the licensing issues of proprietary formats such as MP3 or WMA.
- WMA is a very good quality, proprietary format from Microsoft, and recent versions feature digital rights management. The WMA file extension (as opposed to ASF) indicates that the file contains only audio.

## Which format should you choose?

With so many to pick from, which should you choose? MP3 is the established leader because it was the first to market, but it's a proprietary technology, which means it can't be included in open-source projects. A similar issue restricts the use of the WMA format. Many open-source users have gravitated to the Ogg Vorbis format, which offers similar (and in some cases, superior) performance without the licensing issues associated with proprietary formats.

The downside of using Ogg Vorbis files is that the manufacturers of many portable audio players (such as the Apple iPOD and the Creative line of USB players) do not support OGG files—yet, at least.

I’ll use the Ogg Vorbis format in this chapter; if you choose to use a different open-source format, the concepts and processes are similar. If you choose to use a proprietary format, you’ll probably need to pay for a product because the owner of the format requires royalty payments.

### Using Grip to rip

Once a track has been ripped, the bottom bar will scroll as the track is encoded. The ripping process creates a WAV file regardless of whether you're encoding the track as well. The default behavior of Grip is to delete the WAV file after it has been encoded to another format so your hard disk doesn't get filled up.

However, note that the WAV files are all ripped first. With a CD that's packed full of music (some can hold over 70 minutes), you might end up with 500 to 700 MB of temporary WAV files before they're all encoded into a different, smaller format.

If you create a WAV file, and then later decide to Rip+Encode the same track, Grip will use the WAV file already on disk instead of creating the WAV file all over again.

## Grip configuration options

Grip acts as a front end to a number of ripping and encoding programs, and as a result, there are a lot of possible configuration options. Clicking the Config tab in the main Grip screen displays a set of seven subtabs, some of which have their own subtabs. All told, there are more than 60 options to choose from. Here are a few options that I've found useful.

The default settings on the CD tab and both of the subtabs under the Rip tab are well chosen and I've never had a reason to change them. The Rip | Options tab has one option (Delay before ripping) that you might find useful if you're experiencing errors. Sometimes the ripping process starts before the CD-ROM drive has had a chance to get spinning at full speed.

The Encode tab, on the other hand, has a variety of choices. The Encoder tab allows you to choose which encoding program to use—I've left it at “oggenc” but if you want to change to a different one, you may need to find the encoder program (called a "codec" if that goes along with it. If you want your files to land in a location other than the default "ogg" directory under your home directory, use the “Encode file format” text box to change it. The label says “file format” but it includes the directory as well, such as “~/.ogg/%Aa/%dd/%n.ogg”.

If you wanted to store your files in the “music” drive under your home directory, you would change this to “~/music/%Aa/%dd/%n.ogg”.

What do the funny-looking parameters mean? These are detailed in the help file, but to spare you the busywork of looking them up, the %Aa parameter is replaced by the artist’s name, the %dd is replaced by the album name, and, of course, the %n is replaced by the track number.

Where does Grip find this information? Grip looks up an ID3 on the Internet, using a signature contained in most audio tracks. The DiscDB tab has a link to an online database that Grip uses by default.

The ID3 and Proxy tabs contain specialized options that I’ve never had to worry about, but you might need to check them out if you’ve got particular needs. The Misc tab contains two options that I like a lot: “Do not lowercase filenames” and “Do not change spaces to underscores.” Of course, your preferences may vary.

## Tools to convert formats

What if you’ve already ripped your entire Barry Manilow and John Tesh collection in a format such as MP3 or WMA? The cynic in me might suggest that you press Delete and acquire some Bruce Springsteen and Rush, but then my wife would have me sleeping on the couch for the next decade or so.

As with images, many tools are available for converting your audio files from one format to another. However, this idea is generally frowned upon. The reason is that compressed formats such as MP3 and OGG achieve much of their benefit by eliminating parts of the track that are either redundant or that human beings won’t hear. However, the MP3 and OGG people use different algorithms, so, in essence, they’re each getting rid of different parts of the data. Thus, converting from one of these formats to another will result in a “double dip” of data loss, to the extent that it could very well harm the eventual playback of the track.

If you insist, however, the following Web site lists some third-party tools:

You’re on your own, of course, from here.

## Playing a ripped track from the hard disk

Once you have a track on your hard disk, how do you play it? Yes, you can use Grip to play tracks, but that’s not its primary purpose, so its features are rather limited. The playback functionality is there primarily so you can verify that the ripping process is working properly.

Fedora Core comes with several music players that provide functionality way beyond simple playback; the one you choose will depend primarily on your personal likes and dislikes.

Rhythmbox is a file and radio-station music player written for GNOME, and is available through Main Menu \ Sound and Video \ Music Player, while XMMS is a cross-platform multimedia player that handles music (as well as videos) quite nicely. XMMS is available through Main Menu \ Sound and Video \ Audio Player.

Both players have the capability to act as a jukebox. You add tracks to a master library, and then create playlists by selecting individual tracks from the library. You could create one playlist to act as background music while you’re working, and another to use during your Friday lunchtime table-tennis match.
