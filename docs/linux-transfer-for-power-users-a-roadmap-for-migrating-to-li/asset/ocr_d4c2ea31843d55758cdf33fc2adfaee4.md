2004 is the year of Linux on the desktop for a distinct population of end users, and as a power user, you're in that camp.

That said, there is a huge world of Linux usage to explore, and a single book isn't possibly going to cover it all. The purpose of this book is to get you started with putting a Linux box on your desktop—to get you going, and up and running with a minimum of fuss. Once you're set up, you can go the next step if you want, by using additional resources. When you're ready to continue, check out the updates for this book as well as other white papers on our Web site, and even other Linux books—by us as well as other publishers.

As I write this, Fedora Core 2 is in beta testing and will be out in a few months. I'll post updates for each chapter as appropriate when Fedora Core 2 ships.

I've been having a blast learning new stuff and getting up to speed on Linux. It's an operating system that's designed right from the start, and it makes sense. There are still a few rough edges, but with each release of a new distribution, more and more of those edges disappear.
