Open, Save, and Print are found under the File menu; Cut, Copy, Paste, and Preferences show up under Edit; configuration options (such as turning the toolbar and status line on and off) are found under View; a variety of search mechanisms are under Search; and the Documents menu acts similarly to the Window menu in many other GUI applications.

It has a number of basic, but useful, features that make it my tool of choice for day-to-day scribbling. In fact, I use gedit to quickly scratch out drafts of longer pieces when I don't want to be bothered by (that's polite talk for “distracted by”) all of the features of a full-blown word processor. One particularly useful feature is how gedit handles multiple files: Instead of opening multiple windows, it opens each file under a tab in the same main editing window, as shown in Figure 3.

Another handy feature is the asterisk that shows up to the right of the file name in the tab; this happens when the file has been edited and changes haven't been saved. I can never remember the last time I've hit Ctrl-S.
