The Edit Partition dialog allows you to modify attributes of the partition, including the size, how the size is determined, the mount point, and so on. For the purposes of this example, reduce the size of the 3679 MB / partition by half a gigabyte. This will leave that half gigabyte free, and you can use that to create another gigabyte. (As a matter of practicality, leaving 3179 MB for the / partition may not be enough, depending on how much software you're planning to install on the system.) Click OK and you're returned to the Disk Setup screen.

Next, click the New button to bring forward the Edit Partition dialog again. (Yes, I know you're not editing an existing partition, but that's what the dialog says.) Because you're creating a brand new partition, you should go through each object in the dialog. First, select the mount point from list, as shown in Figure 70. In this example, that's /home.

As an aside, remember that you can only have four primary partitions on a single hard disk. If you want to create more than four partitions, you can keep clicking New and adding partitions to your system, assuming you've got the disk space for it. Disk Druid will automatically create an extended partition and logical partitions within that extended partition as needed. If one of the partitions you're creating absolutely has to be a primary partition, select the "Force to be a primary partition" check box in the Edit Partition dialog. One of the existing primary partitions will be converted to a logical partition.
