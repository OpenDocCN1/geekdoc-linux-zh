Nautilus is an acceptable file manager. Indeed, when I started using Linux, I got by with it fine. However, one day a friend showed me Konqueror, and, as the fairy tale goes, my life has never been the same. Read on and enjoy.

## Konqueror

I’ve saved the best (in my opinion) for last. Konqueror is KDE’s combination Web browser and graphical file manager, and it occupies a permanent position on my panel and desktop.

Like Nautilus, it has a dual-pane setup with a treeview on the left side (the “Navigation Panel”) and a file listing on the right. *Figure 10* shows Konqueror displaying my Home directory, instead of the computer’s file system, as shown in Figure 5.

The first thing you may notice is that the Konqueror display is much more compact than in Nautilus, which may seem silly but was a key benefit for me. When I’m trying to navigate to a specific file, I don’t want to have to scroll through several pages if I can find a way around it.

## File associations

The Windows and Macintosh operating systems come with a number of programs automatically set up to launch when a file with a particular extension is double-clicked in various programs, such as in a file manager like *Windows Explorer*, on the desktop, and in other places (like *Microsoft*’s e-mail clients, *Outlook Express* and *Outlook*).

On the Mac, when someone created a document, information about the program that created that document was stored in the Mac file system. Then, when you double-clicked a document, the operating system knew which program was associated with that document, and automatically opened that document with the proper application. Because this information was stored out of sight, it was difficult to break a file association, but easy and foolproof to use.
