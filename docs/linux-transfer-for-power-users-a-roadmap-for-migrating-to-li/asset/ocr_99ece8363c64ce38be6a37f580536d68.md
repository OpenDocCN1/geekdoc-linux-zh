Back in Chapter 5, I discussed the System Monitor that comes with GNOME. There is another system monitor that displays much of the same information, but in a different interface that’s pretty interesting. Find it under Main Menu | System Tools | More System Tools | GKrellM System Monitor; it looks like **Figure 26**.

Despite its miniscule size, the GKrellM monitor has a lot of information packed into it. It’s actually a combination of many monitors all stacked on top of each other, and you can choose which monitors you want to display. Right-click on the title bar (where it says “freedom” in Figure 26) or press F1 when the monitor window is active, and you’ll see the GKrellM Configuration screen, as shown in **Figure 27**.
