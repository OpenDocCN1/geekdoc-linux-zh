# Virus scanners

Everyone knows that there aren’t any viruses for Linux, right? Well, 600 years ago everyone knew that the world was flat, and 100 years ago everyone knew that heavier-than-air flight was impossible. Things change, and you can bet that sooner or later (and probably sooner), Linux will get hit with its first widespread virus.

Thus it behooves you to be prepared, and get used to having a virus scanner installed and running on your desktop system now. When the first big-time virus hits, you’ll be in much better shape than all those folks who will end up saying, “I didn’t think it would happen to me.”

The rest of this book has covered software that comes as part of the standard Fedora Core distribution, but FC does not come with a virus scanner. This functionality is important enough that I’m going to break my rule this one time and show you how to download, install, and run a third-party piece of software.

F-Prot (http://www.f-prot.com) has a virus scanner that’s free for personal use on workstations. It comes in three types of packages, including a 2.3 MB RPM. There are also a gzipped TAR file and a version for Debian/GNU.

# Download and install

Navigate to http://www.f-prot.com and look for the Download link for Linux home users. (They also make versions for Windows, BSD, and DOS (yes, DOS!), so make sure you get the right one.)
