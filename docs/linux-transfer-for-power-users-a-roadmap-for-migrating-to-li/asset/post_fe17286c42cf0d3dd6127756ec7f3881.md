
## Rhythmbox

Rhythmbox has two distinct capabilities—that of a jukebox and of an Internet radio-station player. Actually, it’s got a third capability as a CD ripper but its capabilities are limited and I’ve had mixed luck getting it to work.

Using Rhythmbox as a jukebox, you first add tracks to the Library by selecting File | Add to Library, and then navigating to the location where your tracks are stored. Once you’ve added certain tracks, they’ll appear in the browser window, as shown in **Figure 8**.

The steps for creating a playlist are somewhat counterintuitive. First select the Library source, so that the tracks are displayed in the browser window, as in Figure 8. Second, select the tracks you want to add to your playlist, as shown in **Figure 9**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_286_0.png)

**Figure 8. The Rhythmbox jukebox, loaded with tracks.**

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_286_1.png)

**Figure 9. Select tracks before creating a playlist.**

Third, select File | New Playlist to open the New Playlist dialog. Type a name for the playlist, and then select the "Add the selected songs to the new playlist" check box, as shown in Figure 10.

The new playlist will be added to the Source list on the left. Highlighting the playlist will display the tracks in the browser, as shown in Figure 11.

What if you forget a track and want to add it to a playlist later? Or what if your library is so big that you just can't scroll to every item and keep them all selected before creating a playlist? You can add tracks to an existing playlist, but again, it's not exactly intuitive.

Select the Library in the source list, and scroll to the desired item. Then highlight the track and drag it to the desired playlist, as shown in Figure 12.

You can delete items from a playlist (or from the Library, for that matter) by right-clicking the offending track in the browser and selecting Delete from the context menu.

The radio-station capability works much like the Library without playlists. To add an Internet radio station, select Radio from the Source list, which will show the list of radio stations. In Figure 13, there is already a radio station in the College genre.

Adding a radio station isn’t quite as easy as adding tracks to your Library. First, you’ll need to know the URL of a radio station that is broadcasting on the Internet. There’s a good-sized list at http://www.radio-locator.com/. If that doesn’t suit you, try searching on “Internet radio station” on the Web. Once you’ve found a station, go to its page. You’ll need to find a link on the site that says something like “Listen now” or “Streaming” or “Live broadcast.”

Under the link, you’ll find a URL that looks like this:

```
http://35.8.90.127:8080/zamen/encoder/thefix.rm
```

With that in hand, select File > New Internet Radio Station to display the New Internet Radio Station dialog. Enter the name of the station, a genre if you want, and the URL, as shown in Figure 14. Click OK and the radio station will be added to the list. To play, just select the radio station and click the Play button. A dialog with a “Loading” thermometer bar will appear for a few seconds. Once the audio stream from the radio station catches up, Rhythmbox will start broadcasting.

## XMS

Ever been in a situation where you had to choose which of two pretty girls to ask out? (Or been asked out by two hunky guys for the same night?) Well, I never have, but I’ve heard it’s happened to others. And I can imagine what it’s like, because having to choose between Rhythmbox and XMMS is probably similar.

I’ve used XMMS ever since I put Linux on a desktop machine, but recently started using Rhythmbox because of its radio-station capabilities. Still, like that first girlfriend, I keep coming back to XMMS.

XMMS has three primary windows in the interface. The Main window contains the controls for the player, the Playlist Editor window displays track names and times, and the Equalizer window provides the controls similar to a stereo equalizer (and eye candy for those attracted to bright and shiny things). Figure 15 shows all three windows. The Main window is on the upper left, the Equalizer is under the main window, and the Playlist Editor occupies the entire right side.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_289_1.png)

The Main window consists of several sections, much like the Rhythmbox interface. The upper left displays the time the current track has played, as well as a nifty little visualization of the sounds themselves. To the right is information about the track being played, including the artist name, track name and total track time, and the sampling rate (how many bits per second the track is playing back at). Under the title window are, from left to right, the volume and speaker slider controls, and buttons that display or hide the Equalizer and Playlist Editor windows. If you’ve used WinAmp, you’ll find a lot of similarities.

The long slider that spans the entire width of the window displays how much of the track has played. And the VCR controls under the slider allow you to go to the previous song, play, pause, stop, and go to the next song. The RAND button will mix up the order in which the tracks in the Playlist window are played, and the REP button will repeat playback when the end of the playlist is reached.

The five letters to the left of the time display don’t seem to spell anything or form a recognizable acronym. Instead, they each provide functionality that would usually be represented by a button.

Clicking the O displays the Options menu, which I’ll get to in a moment.

Clicking the A toggles “Always on top” functionality for the windows. If the A is highlighted, the windows will always display on top of all other windows, even if one of those other windows has focus.

Clicking the I will show the File Info box for the current track, as in Figure 16.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_290_0.png)

**Figure 16. The File Info dialog in XMMS.**

The D acts as another toggle, this time for the size of the windows. Figure 16 shows all windows as “double-sized”; this toggle reduces the size of the window if you’ve got good eyes or a big monitor.

Finally, clicking the V will display the Visualizations menu, which I’ll also discuss in a moment.

You can also open the XMMS main menu by clicking the upper left corner of the window or right-clicking most anywhere else in the main window. The main menu, as well as my complete lack of taste in music, is shown in Figure 17.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_291_0.png)

**Figure 17. The XMMS main menu and Options menu.**

As you can see, the main menu provides keyboard equivalents to a number of common functions that are available through the Main window. The Options menu item expands to provide access to a large number of additional functions; this second menu is the same Options menu that is displayed via the O button on the Main window. The Playback and Visualization menu items provide similar secondary menus; the Visualization menu is identical to that displayed via the V button on the Main window.

A visualization is a graphical representation of the audio file being played. First, open the Visualization menu, and select a Visualization Mode (the first menu item)—either Analyzer or Scope. From there, cruise through the other menu options as desired. Note that some of the plugins can really chew up CPU power!

The Playlist Editor window simply displays a list of tracks that are currently playing, but also provides controls to manipulate the tracks and run the player in “mini-mode.” The +FILE button in the lower left corner allows you to add tracks to the current playlist, either one file at a time, one directory at a time, or via a URL. The -FILE button to its right does the same thing, except in reverse. Continuing on the right, the SEL ALL button provides the ability to select various combinations of the items in the playlist, in order to then perform other operations, such as removing them from the playlist. Finally, the MISC OPT button has options for displaying the file information, just like the I button in the Main window, and for sorting the playlist, as shown in Figure 18.
