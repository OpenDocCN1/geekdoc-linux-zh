**Figure 3.** *A partial list of public mailing lists supported by Red Hat.*

The current lists devoted specifically to Fedora Core include (but are not limited to):

+   * fedora-announce-list: Announcements related to the Fedora Project
+   * Fedora-config-list: Discussions about configuration tools for Fedora
+   * Fedora-de-list: Fedora discussions in German
+   * Fedora-desktop-list: Discussions about development for the Fedora desktop
+   * fedora-devel-list: Development discussions related to Fedora Core
+   * fedora-docs-list: For participants of the docs project
+   * Fedora-legacy-list: Discussion of the Fedora Legacy Project
+   * fedora-list: For users of Fedora Core releases
+   * Fedora-test-list: For testers of Fedora Core development releases
+   * Fedora-trans-list: Fedora Translation Project List
