# Chapter 7
E-mail and Web Browsing

By far, the most common activities that people perform on their personal computers are using the Internet for e-mail and surfing the World Wide Web. In this chapter, I'll introduce a couple of popular tools for both functions and get you started using them.

For years after the “big three” of killer applications—spreadsheets, word processors, and databases—people have been looking for the next “must-have” application, only for it to appear under their noses, and out of the control of any single entity. The Internet, with its ability to exchange e-mail and interface to the World Wide Web, is the killer application of the decade.

This chapter assumes that you already have physical access to the Internet, which you've been using with your Windows computer. I’m not going to help you pick a broadband carrier or sign up with a provider. There are too many options and alternatives to try to identify all of them, or even a significant proportion of them. I also assume that you wrote down your network and ISP settings as instructed in Chapter 2, “Installing Fedora Core.”

# Network connections

Both e-mail and Web browsing assume that you have a physical connection to the Internet. In order to take advantage of that connection, you have to configure your computer's settings to recognize it.

This should have been done during installation, in the Network Configuration step (and the “Assigning static IP addresses instead of using DHCP” section) of Chapter 2. But in the event that you skipped that step, because you didn’t have the information, you didn’t have a connection, or you just didn’t want to bother—or if you have to make changes—I'll explain how to change those settings during regular usage.

First, select Main Menu | System Settings | Network to bring forward the Network Configuration dialog (shown in Figure 4 shortly). Before it shows up, though, you'll get the root password dialog, shown in Figure 1.

Messing with the network configuration of a machine is not a task that an end-user should be doing—it requires root permission because it's affecting the entire machine, not just one user's settings. As a result, you'll be prompted for the root user's password in order to prove that you have root user permissions.

After you successfully enter the password, a set of keys shows up on the panel, as shown in Figure 2.

The icon is a reminder that this application is running as root. It’s a good idea to terminate that authorization when you’re done with the operation or process that required it. To do so, click the keys icon to open your authorization dialog, shown in Figure 3.
