When a log file becomes large, it can be easy to miss a line that points out a specific alert or warning. The Alerts and Warnings tabs of the Preferences dialog allow you to specify an icon beside log file lines that contain words or phrases of your choice. Thus, a line in a log that contains a specific user name or module name could be easily spotted.
