The sixth position contains the definition of the cron job—a command to be run—and the first five sections are values that determine when and how often to run the job (relative to the local computer’s system clock).

(If the computer running the cron jobs is down, the jobs scheduled during that downtime will simply be skipped; they will not be queued up and run once the computer comes back.)

Here is how the first five parts are laid out:

+   1 Minute 0–59
+   2 Hour 0–23 (0 = midnight)
+   3 Day 1–31
+   4 Month 1–12
+   5 Weekday 0–6 (0 = Sunday)

An asterisk in place of a numeric value indicates that every instance of the value will be used. For example, using an asterisk in the fifth position means that the job will run seven days of the week, while an asterisk in the second position means that the job will run every hour of the day. You may want to think carefully before adding an asterisk to the first position.

There are some types of jobs that you may want to run more than once a day, but not as often as every hour. You can use more than one instance of a specific time period by including each desired time period, separated by a comma. For example, suppose you want to run a cron job four times a day, at 15 minutes past the hour. The first two parts of the cron job would look like this:

```
15 2,8,14,20
```

The job would run at 2:15 a.m., 8:15 a.m., 2:15 p.m., and 8:15 p.m.

# Using vi

vi has two modes: insert mode (when you’re typing) and command mode (when you’re issuing commands to do something such as save or quit). When you start up vi, you’re in command mode. Type ":" to initiate a command, followed by the letter of the command, and then press Enter. For example:

+   - Typing ":q" and pressing Enter will quit vi.
+   - Typing ":w" and pressing Enter will save your document.

To switch between insert and command mode:

+   - From command to insert: Type any of the following letters: i a o c s (uppercase or lowercase).
+   - From insert to command: Press Esc.
