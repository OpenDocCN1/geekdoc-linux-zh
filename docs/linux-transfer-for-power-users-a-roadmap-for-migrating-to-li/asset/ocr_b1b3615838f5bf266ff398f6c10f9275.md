# Scanners

When you think about it, a scanner is really just a printer in reverse, right? So setting up a scanner is pretty similar. After plugging in your scanner, select Main Menu | Graphics | Scanning. This starts the XSane scanning software. The first time you load XSane, you’ll be prompted to answer a license agreement, shown in **Figure 17**.
