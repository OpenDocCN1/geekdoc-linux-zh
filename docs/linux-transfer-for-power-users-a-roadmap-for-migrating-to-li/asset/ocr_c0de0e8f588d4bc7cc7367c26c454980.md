Under the Advanced node's Scripts and Plugins node, you control what actions scripts are allowed to perform. For example, you can turn on or off the ability for scripts to:

+   - Move or resize existing windows
+   - Raise or lower windows
+   - Hide the status bar
+   - Change the status-bar text
+   - Change images
+   - Create or change cookies
+   - Read cookies

And under the Software Installation node, you can control whether or not software installation will be enabled, and how often—if ever—your machine will look for updates to Mozilla.

One of the handiest tips for using Mozilla (it works in Windows, too) is the pair of keyboard shortcuts, Ctrl-+ and Ctrl--. Holding down the Ctrl key and then pressing the plus key (it's easier on the numeric keyboard since you don't have to hold down the Shift key too) will zoom the text size up one level. Holding down the Ctrl key and pressing the minus key will reduce the size of the text.
