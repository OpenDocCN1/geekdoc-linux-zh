One interesting difference between Evolution and KMail is that the latter has a set of Mailing-list-specific options, such as “New Message to Mailing List” and “Reply to Mailing List.”¹² These are used in conjunction with folders that you associate with mailing lists by setting those folder’s properties.

# ## Web browsing

In 2004, there’s not much to say about setting up or using a Web browser, other than to mention that you have choices with Linux and Fedora Core, unlike with other operating systems that insist “the browser is an integral part of the operating system” and then force a browser down your throat whether you want to use it or not.

While many browsers are available, I’ll just cover two of the most popular ones—Mozilla and Konqueror—like I did in the e-mail section in this chapter.

# ### Mozilla

I actually started using it before I started using Fedora Core because a version of Mozilla has been available for Windows for a couple of years. As a result, it was an easy and natural migration to begin using it with Fedora Core as well, and it’s my preferred browser.
