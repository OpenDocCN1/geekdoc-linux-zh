
calculates a 128-bit text string (or "fingerprint") for that file that can be compared with the fingerprint of the original file on the server to ensure that both files are the same.

There are two ways to do an MDSUM check. You can either check each file separately or check a set of files all in one step.

To use MDSUM on a single file on a Linux machine, follow these steps:

- 1. Go to a terminal window.
- 2. Change to the directory that contains your ISO files.
- 3. Run the following command:

```
md5sum yarrow-i386-disc1.iso
```

It'll take 10 to 30 seconds, depending on your processor.

- 4. You will get a response of text characters. Those characters should match the string on the http://fedora.redhat.com/download/ page:

```
yarrow-i386-disc1.iso  (md5sum: 76ef2249d5186580e47efd88da765fe6b)
yarrow-i386-disc2.iso  (md5sum: fdc23fe32fafe7557f5d1f1a1d31100580)
yarrow-i386-disc3.iso  (md5sum: 6a26b34069639dc0c31465d4079a8e81b2)
```

You can also find a copy of the original string in the MDSUM file that you downloaded along with the ISO files.

- 5. Compare the two strings. If you don't get the same string, your file is corrupt (or illegitimate) and you need to get a new one. In **Figure 1**, the first ISO checked out okay, because the fingerprints are the same. However, the second one is corrupt—the original fingerprint begins with "fd23", while the fingerprint that MDSUM calculated from the downloaded ISO file begins with "c8b5". Thus, the second ISO has to be downloaded again.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_36_0.png)

Figure 1. Verifying the MD5 sums for the downloaded ISO files.

To check all the files in one shot, follow these steps.

- 1. Download the MDSUMS file.
- 2. Open a terminal window.
- 3. Run the following command:

```
md5sum --check MDSUMS
```

- 4. The command will complain about the SRPMS files not being present (which we didn’t download), but that’s obviously not an error condition. This command automatically checks the checksums so you don’t have to carefully check the output versus one of the lines in the MDSUMS file yourself.
- 5. Here’s the sort of output you’ll see:

```
chris@malice [510]: dir
total 2049
-rw-r--r-- 1 chris cygwin 120 Feb 21 10:11 MDSUMS
-rw-r--r-- 1 chris cygwin 1048576 Feb 21 10:10 file1
-rw-r--r-- 1 chris cygwin 1048576 Feb 21 10:10 file2
-rw-r--r-- 1 chris cygwin 1048576 Feb 21 10:10 file3
chris@malice [511]: md5sum --check MDSUMS
file1: OK
file2: OK
file3: OK
```

Once you have verified your files, via either method, it’s time to burn CDs.

### Burn a CD

This step causes more questions than using the MD5SUM program. A common mistake is to simply copy the ISO file to a CD—but that’s not the goal. The ISO file actually contains a number of other files that are to be placed on the CD so that they are accessible during installation. If you simply copy the ISO file itself (so that doing a directory listing would result in a list of one file of 650 MB), booting with the CD will result in an error. The ISO file is an image of what will go on the CD, and so you’ll use a special option in a CD-burning program to convert that image into files that land on the CD.

There are three overall steps to this process: determine which device your CD burner is connected to, do a test burn, and then do the real burn. Here is the detailed procedure:

- 1. Open a terminal window and become root:

```
su
```

- 2. Enter the cdrecord command to determine which device:

```
cdrecord -scanbus
```

- 3. You should see a slew of info, as shown in Figure 2. The info dump includes a string like so:

## Install Fedora Core

If you’ve installed RH 7, 8, or 9, the process will be very familiar—it’s nearly identical to RH9, except the Fedora Core background appears in the installation dialogs. At this point, I’m going to assume you have three CDs with the images burned on them: Fedora Core 1/2/3.

## Document your hardware

If you are installing Linux on a machine that already has another operating system installed on it, it's a good idea to do one thing before you start the Linux installation itself. You'll want to document your existing hardware settings, in the unlikely case you have a piece of equipment—such as an oddball video card or some sort of device with an old chipset—that Fedora Core doesn't immediately recognize.

The location of these settings varies according to the operating system. On Windows 2000, select Start \ Control Panel \ System applet \ Hardware tab \ Device Manager button \ View menu \ Print menu \ All devices and system summary. You'll get an exhaustively detailed list of the hardware on your computer.

You'll also want to write down your network settings if you're connected to a network and/or the Internet. On Windows 2000, select Start \ Settings \ Network and Dial-up Connections. Right-click the Local Area Connection icon and select Properties \ General tab \ Internet Protocol (TCP/IP), and then click the Properties button. Write down all of the settings and numbers.

If the option button "Obtain an IP address automatically" is selected, it means your computer is getting IP information via DHCP.
