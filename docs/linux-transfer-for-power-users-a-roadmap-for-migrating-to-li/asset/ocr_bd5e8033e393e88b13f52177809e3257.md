As you start to drag the mouse, the Crop and Resize Information dialog will appear—and hopefully won’t be in the way of the area you’re cropping. Once you’ve selected the area that you want to crop, click the Crop button in the dialog, and the contents of the Image window will change to display only the area you selected.

Note that this new image is only in memory, so you can revert your changes by right-clicking and selecting Edit | Undo, or simply by calling up the image you saved on disk. If you like the cropped version, be sure to save it.

# Editing an image, pixel by pixel

Once in a while, the image is just about perfect, except for one small thing. You don’t necessarily want to reshoot the image, or perhaps you can’t—maybe you need to add, remove, or modify a feature in a way that can’t be done simply by capturing another screen shot. One way to make a change like this is to alter the image, pixel by pixel, with The GIMP.

Open the image you want to modify in the Image window, and then zoom in (via the Edit | Zoom In menu item as described earlier). Zoom in enough so you can see the individual pixels in the image, as shown in Figure 29.

The next step is to activate the pixel editing tool. In the Toolbox window, select the pencil tool (third row, fourth from the left in Figure 15, with a tooltip of “Draw sharp pencil strokes”). Then choose what size brush you want to use. The smallest brush size will give you the ability to draw single pixels.

Once you move your cursor over the Image window, you’ll be able to start drawing pixels, either one by one by clicking, or in a line by clicking and dragging. Because The GIMP won’t natively capture the mouse cursor, I used this feature to draw the crosshair in Figure 27.
