# Assigning static IP addresses instead of using DHCP

In step 15 of the “Perform installation” section, you assumed that you were going to use DHCP so that your computer would automatically be assigned an IP address by another box as necessary. What if you want to manually assign an IP address to your computer and keep it the same all the time—in other words, what if you want to use a static IP address?

Technically, the IP address isn’t assigned to your computer, but to the Ethernet card inside your computer that connects your machine to the network. If you have more than one Ethernet card in your computer, you would have more than one entry in the Network Devices list box in the top half of Figure 29.
