The third step is to select a tool to work with. The toolbar in the second row, immediately above the drawing canvas, contains a variety of simple drawing tools, ranging from line, ellipse, circle, rectangle and rounded angle to pen, spray can, and text.

The last tool in the row is the Area Select tool; it allows you to select an area on the canvas that you can copy or cut.

You can set line attributes for all tools except the Text and Area Select tools. If you’re using a tool that encompasses an area, such as the circle or rectangle, you can click the Tool Properties button to set properties for the way the object will be filled as well. **Figure 17** shows the Tool Properties dialog for both sets of attributes.
