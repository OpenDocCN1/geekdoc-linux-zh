In either case, you’ll see a screen that looks like **Figure 1**, which appears when you run Kudzu manually after boot-up. During automatic detection during normal boot-up, this screen will vary slightly in that you’ll also have an option to skip Kuzdu configuration and run it later.

In either case, if you continue with Kuzdu, the next screen identifies specific hardware and offers you several avenues to follow, as shown in **Figure 2**.

The first option, Configure, configures your computer with the new hardware, be it a mouse, a printer, or an external drive. Once finished, you’re returned to where you were before Kuzdu started. You’ll probably use this choice almost every time you run Kuzdu.
