Don’t assume that a generic-sounding message will automatically generate so many hits that the search results are useless. For example, another common error in the early Fedora Core days had to do with trying to install packages via the RPM tool accessed via System Settings | Add/Remove Applications.

The operation would fail, and generate an error message as shown in Figure 8.

![](bbox=[0.08, 0.19, 0.46, 0.3])

**Figure 8. At first, a generic error message doesn’t offer much hope for targeted searching.**

This is a terrible error message—not much better than the classic messages so common on Windows systems, such as “Install failed” and “There was an unexpected error.”

Not only is this message woefully unhelpful (couldn’t the programmer have done something to help the user out a bit?), but it is so generic that there is certainly not enough to search on, wouldn’t you say? Surprisingly enough, though, this was enough to go on. Doing a Google search on “Fedora” and “There was an error installing packages.” generated 70 hits.
