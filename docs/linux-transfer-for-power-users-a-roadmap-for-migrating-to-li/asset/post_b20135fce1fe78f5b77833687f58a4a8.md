
Once the window or screen has been captured, it is displayed in the Image window (see Figure 24). Because computers are computers, the first thing you’ll want to do is save the file. Right-click in the Image window to bring up the context menu; then select File | Save to bring forward the Save Image dialog, shown in **Figure 26**.

The first thing you’ll do is navigate to the location where you want to save the file. Then, in the Determine File Type box, you’ll select what type of file you want to create. The GIMP can save in just about any format you can imagine. Finally, you’ll want to give the file a name. The file should have an extension automatically assigned based on the file type you selected in the Determine File Type box, but if it doesn’t, add the extension yourself.

## Cropping an image

Whether you’ve captured an entire desktop or just want to whittle down part of a screen, cropping an image is a common (but not necessarily intuitive) task.

First, click in the Image window. From this point, you may want to zoom in on the image so you can crop more closely and not leave a lot of extra space on the sides. To do so, either right-click the Image window and select View | Zoom In, or press the Equal Sign key (=) on the row of number keys (probably next to the Backspace key). If you want to see more of the image, albeit in a smaller view, select View | Zoom Out or press the Minus Sign key (-) next to the Equal Sign key.

Once you’ve sized the image so that the part you want to crop fills as much of the screen as desired, right-click the Image window and select Tools | Transform Tools | Crop and Resize. The cursor will appear as a crosshair, as shown in **Figure 27**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_271_0.png)

**Figure 27.** The crosshair represents one corner of the area to be cropped.

The crosshair represents one corner of the area to be cropped. Click and drag the mouse to create a rectangle around the area to be cropped. Everything inside the rectangle will be included in the newly cropped picture, while everything outside the rectangle will disappear. For example, suppose you wanted to create an image that consisted of the words “appears once you have an image to” in Figure 27. Keeping the crosshair where it’s shown in Figure 27, drag the mouse down and to the right to create a rectangle, as shown in **Figure 28**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_271_1.png)

**Figure 28.** Cropping an image inside the rectangular area.

As you start to drag the mouse, the Crop and Resize Information dialog will appear—and hopefully won’t be in the way of the area you’re cropping. Once you’ve selected the area that you want to crop, click the Crop button in the dialog, and the contents of the Image window will change to display only the area you selected.

Note that this new image is only in memory, so you can revert your changes by right-clicking and selecting Edit | Undo, or simply by calling up the image you saved on disk. If you like the cropped version, be sure to save it.

## Editing an image, pixel by pixel

Once in a while, the image is just about perfect, except for one small thing. You don’t necessarily want to reshoot the image, or perhaps you can’t—maybe you need to add, remove, or modify a feature in a way that can’t be done simply by capturing another screen shot. One way to make a change like this is to alter the image, pixel by pixel, with The GIMP.

Open the image you want to modify in the Image window, and then zoom in (via the Edit | Zoom In menu item as described earlier). Zoom in enough so you can see the individual pixels in the image, as shown in Figure 29.

The next step is to activate the pixel editing tool. In the Toolbox window, select the pencil tool (third row, fourth from the left in Figure 15, with a tooltip of “Draw sharp pencil strokes”). Then choose what size brush you want to use. The smallest brush size will give you the ability to draw single pixels.

Once you move your cursor over the Image window, you’ll be able to start drawing pixels, either one by one by clicking, or in a line by clicking and dragging. Because The GIMP won’t natively capture the mouse cursor, I used this feature to draw the crosshair in Figure 27.

## View images individually or as a slide show

Once you’ve put together your images, you’ll probably want to show them off. Fedora Core comes with several image-viewing programs, including the Eye of Gnome, KView, and Kquickshow, all available from Main Menu | Graphics | More Graphics Applications. My two favorites, however, are GQView for viewing and arranging static images, and gThumb Image Viewer for creating slide shows. Note that these two programs aren’t mutually exclusive— GQView has a slide-show mechanism, and gThumb Image Viewer has a number of image-manipulation functions as well.

### GQView

As you saw earlier, I use GQView enough that I keep it on my panel. It’s an image-viewing program that I find terrifically useful while creating documentation and trying to decide what screen shots will go into a document, and in what order. It includes zoom, thumbnail, slide- show, full-screen, image-comparison, and file-manipulation functions.

Open GQView by clicking Main Menu | Graphics | GQView. Select the directory containing your files by using the folder navigation treeview in the top left pane. The files themselves will appear in the lower left pane, shown in **Figure 30**.

As I work with a set of images in a directory, I often rearrange them as I make edits. Pressing Ctrl-R opens a renaming dialog so that I can change the file names to match the figure numbers in the chapter. Similar key combinations allow you to copy, move, and delete files.

The buttons in the toolbar provide all sorts of useful, one-click functionality. The first button switches the list of files in the lower left to thumbnails, so that you can see the big picture quickly. Note that if you have a lot of large images, the first switch to thumbnails can take a couple of minutes.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_273_0.png)

The next button (with the house on it) switches you to your home directory (duh!) and the green circular arrow in the third position refreshes the file list, which is handy if you do a lot of renaming.

The two magnifying-glass buttons zoom in and out, and the next two to the right will either fit the image to the right pane or set it back to its actual proportions. The last two buttons give you access to preferences, and float the left side pane away from the image pane.

Additional features are available under the Edit menu, such as rotating, mirroring, and flipping an image, and editing in a variety of programs such as The GIMP and Electric Eye. The View menu also has lots of handy stuff, such as changing the top left pane to a treeview of the folder structure, viewing the image in full-screen mode, toggling a slide show, and hiding or showing the various interface components.

I've found GQView to be extremely fast even with huge (40 MB) files, although occasionally an image will suffer as it renders with jaggy lines across it until you refresh the screen. Can't live without it.

### gThumb Image Viewer

To open this image-viewing program, select Main Menu | Graphics | gThumb Image Viewer. You'll see in **Figure 31** that it comes configured with three panes. The upper left pane shows you a treeview of your hard disk, which you can use to navigate through your directories. The right pane shows you thumbnails of all images in the currently selected directory, and the lower-left pane shows you a larger version of the thumbnail selected in the right pane.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_274_0.png)

gThumb has a number of typical thumbnail-viewer-type features. Right-clicking any image in the right pane opens a context menu with options that allow you to annotate an image with a comment, search for duplicates, create catalogs, or attach a picture to a category, including your own custom categories, as shown in **Figure 32**.

The toolbar in gThumb has buttons for changing the view shown in the panes. The Catalogs button, for example, switches the view so that only pictures belonging to a selected catalog are displayed.

Other buttons in the toolbar (and, of course, in the View menu) allow you to see pictures in full-screen mode, and to spin through a series of pictures as a slide show.
