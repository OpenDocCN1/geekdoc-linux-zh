# /bin

/bin contains programs or symbolic links (think “shortcuts” in Windows) that are used by the system administrator, by regular users, and by scripts (think “batch files”). These programs differ from those in /sbin and /usr/bin in that they are required before the rest of the directories are available for use. (You might hear people refer to this requirement in Linux terms as “before any other file systems are mounted.”) If you were going to create a floppy disk to boot Linux, these the contents of /bin would be useful.

Examples of programs in /bin include cp (a utility to copy files), mkdir (a utility to make a directory), sh (the Bourne command shell) and su (a utility to change the user ID).

# /boot

/boot contains all of the files and data required for the machine to boot, in addition to configuration files not needed during boot-up.

# /dev

/dev contains files that map to devices (get it?) that are attached to the computer.

# /etc

The /etc folder stores configuration files for the operating system as well as programs on the computer. Some, but not all, configuration files have a “.conf” extension, but, in contrast with Windows, many Linux files do not have extensions at all. For example, the file “/etc/fstab” is a configuration file that contains the file system table (f.s. table—get it?). Another example is the file “/etc/gimp/1.2/gimpirc”—the configuration file for the GIMP (The GNU Image Manipulation Program). The corollary to Windows is the Windows Registry.

# /home

The most important folder to you is /home, because it stores regular user data, including yours. It’s somewhat like “My Documents” on Windows. Each regular user (as opposed to the root, or administrative, user) on a Linux computer has their own folder under /home, and each user can only get to their own folder under /home when they log on. So, for example, if three regular users—Al, Barb, and Connie—are set up on a Linux computer, there will be three folders under /home, like so:

```
/home/al
/home/barb
/home/connie
```

When Al logs on, he can get access to his own folder, but not to /home/barb or /home/connie.

/home is like C:\Documents and Settings, because there’s a directory for each user underneath, and each user’s directory contains user-specific config files and (usually) users’ data.
