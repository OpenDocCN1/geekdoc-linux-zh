Notice how the help is organized by things—which is helpful if you want to reference a specific widget in an interface—not by tasks. Users usually look things up based on the tasks they're trying to accomplish, and just once in a while when trying to figure out what a specific object on the screen is.

You can drill down into specific subject areas, but the help files available in each area are irregularly populated. In addition, even if you've installed KDE-specific files, the help files are unfortunately just provided for GNOME components. You will have to switch to the KDE desktop in order to access KDE help.

Drilling down into, say, Applications, as shown in Figure 2, provides two sets of links: one for Categories and another for Documents—help files specific to individual applications. For example, the complete user guides for Evolution and Balsa (a pair of mail clients) are provided here. However, if you drill down into the Office category, there's only one link, for the Gnumeric spreadsheet application. Help for OpenOffice.org and KOffice are not available. (You have to load those applications in order to get to the help.)

The biggest stumbling block with the Fedora Core Help menu option is that the help only focuses on the GNOME interface. Issues dealing with the operating system itself are not available at all.

With earlier versions of Red Hat Linux, you could install the documentation files separately. That functionality hasn't yet been completed in this first release of FC. An installation guide is planned for a future release.
