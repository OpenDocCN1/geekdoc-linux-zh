The View menu in the main window provides access to other XSané windows, including histograms, batch scans, and advanced options.

To scan an item, first you'll want to set any applicable preferences, using the Preferences | Setup menu option in the main window. The XSané setup dialog has eight tabs (shown in Figure 25); which ones you work with depends on what you're doing with your scans.

The Save tab allows you to configure permissions for image files and directories, and specify how to name scanned images. The Image tab provides options for JPEG quality, PNG image compression, and TIFF image handling. The other tabs have specialized options relating to those functions—such as copying and faxing, creating OCR images, and handling the display.

Once XSané is set up the way you want it, go back to the main window and choose the mode (Viewer, Save, Copy, Fax, or Email) you want to work in, as shown in Figure 26. Then, in the next box, select the type of image (Lineart, Halftone, Grayscale, or Color) you're scanning, as shown in Figure 27.
