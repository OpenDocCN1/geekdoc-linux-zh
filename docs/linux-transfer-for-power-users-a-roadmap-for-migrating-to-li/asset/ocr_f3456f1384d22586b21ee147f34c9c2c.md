# How to search

So now you’ve made it to the main screen. What do you do now? Here’s a real-life example.

As mentioned in Chapter 3, “Updating Fedora Core,” one of the most frequent questions asked on the mailing lists has to do with updates. If a user depends on the default servers for update files, a variety of errors can occur. Searching on the exact text in the error messages is one way to look for messages that relate to this problem. If you can do that, it’s a great idea.

However, that’s not always possible, either because you just plan forget to copy the message down exactly, or if flashes by the screen too fast to write down, or the message is so generic that it ends up delivering a zillion hits on a Web search.

That doesn’t mean that you’re out of luck, though. The archives are not so voluminous that searching on generic terms won’t result in some little matches. For example, when I searched on “update” and “strange error,” I found the message displayed in Figure 7. This message provides the answer to the problem instantly. It gives instructions on how to configure update and yum to connect to mirrors for downloading updates instead of relying on the defaults provided with Fedora Core.
