# System Tools applets

The Preferences menu isn’t the only place where Fedora Core keeps its goodies. The System Tools menu has several as well.

The Hardware Browser allows you to look through the hardware on your system. To do so, select Main Menu | System Tools | Hardware Browser. You’ll be asked for the root password, and then the Hardware Browser dialog will appear with a list of hardware and drivers. Some screens have additional information. The Hard Drives screen also shows you the amount of disk space used, as shown in Figure 23.

When posting a query for help on various electronic forums and lists, one frequent suggestion is to “check the logs.” So where are these “logs” and how does one “check” them? The System Logs viewer, accessible via Main Menu | System Tools | System Logs (you’ll need to enter the root password) provides access to logs that are created by various applications on your system, as shown in Figure 24.

The System Logs viewer shows only the logs that exist on your system; if your system doesn’t have the same applications as mine, the logs available on your system may vary.

You can set your own preferences for the log files through the Edit | Preferences menu option in the System Logs viewer. The Log Files tab, as shown in Figure 25, allows you to point the System Logs viewer to a specific path and file name for each log. Suppose you have another application that generates log files. You can add those to the System Logs viewer by clicking the Add button in the Log Files tab of the Preferences dialog.
