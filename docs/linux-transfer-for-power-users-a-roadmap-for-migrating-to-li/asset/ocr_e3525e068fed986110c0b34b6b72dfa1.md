# /opt

/opt is reserved for applications programs installed by the user.

# /proc

/proc is a virtual file system that stores a copy of the system currently in memory. This mechanism provides an easy way to get information about the kernel and currently running processes, instead of having to dig at the memory itself. You will likely never have to mess with this folder.

# /root

The /root folder is simply the root user's home folder. It is not put in the /home folder for security reasons—you can have /home on a separate partition but still have the root user's home folder available before that partition is mounted.
