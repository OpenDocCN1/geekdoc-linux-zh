# Preference applets

The Preferences menu has a number of handy applets that help you customize your system. Here are four that I find useful: Control Center and Keyboard Shortcuts (under the Preferences menu) and CD Database, and Sessions (under the More Preferences menu).

The Control Center (see Figure 17) is somewhat similar to the Windows Control Panel; it provides a one-window point of access for user preferences. If you're spending a bunch of time tuning your preferences, use this window instead of opening the Main Menu over and over.

The Keyboard Shortcuts applet is great. With it, you can configure a variety of keyboard shortcuts for specific Desktop and Window Management actions, as shown in Figure 18. For example, scroll through the Window Management actions until you get to the “Switch to workspace 1” action, which is undefined by default. Simply press the keyboard shortcut you want to use for this action; I use <Control>-1 and <Control>-2 for switching between the two workspaces I have defined on my desktop.

The CD Database applet, shown in Figure 19, allows you to point your machine to a database for fetching song information that is used by Grip and other CD rippers. (See the Config | DiscDB | Primary Server tab to see where it's used.)

The fourth applet is the Sessions preference tool. It allows you to specify which applications to start when you start a session, and whether or not you want to save and restore the state of the currently open applications on your desktop the next time you start up.
