# CD-ROM burners

There are several way to copy data files from a hard disk to a CD in Fedora Core. I already showed you the first way when I discussed burning the ISOs before installing Fedora Core in Chapter 2. It’s a bit obvious, having to type complex commands, and can be time-consuming and confusing if you’re copying files from multiple directories.

The second way to copy data files is to using a GUI tool that comes with Fedora Core. Called X-CD-Roast, it’s available through Main Menu | System Tools | CD Writer. Unfortunately, it’s, well, not quite ready for prime time. Yes, it’s got a GUI interface, so presumably it’s easier than issuing commands at the command prompt like I showed you in Chapter 2. “Presumably,” however, is a big assumption. If you’ve burned CDs in Windows, you know that the process should be a simple matter of opening a window with two list boxes in it. One list box contains the directory structure of your hard disk, and the other box contains a list of files to be written to the CD. Using the tool should simply be a matter of dragging files or directories from the left list to the right list.

X-CD-Roast, however, requires you to navigate through a setup screen first, regardless of whether Fedora Core knows about your CD-ROM burner. Then you have to open a “Create CD” screen and make your way through several different windows and tabs, working with controls that are scattered all over and not necessarily named well.

I’ve been burning CDs since the early '90s, when I used a stand-alone drive that cost close to $2,000. One would figure that I’d have a rough idea of what to do, but I had a devil of a time getting this program to work. It’s the type of software that people point to when making fun of Linux for being designed by techies for techies. And the documentation (available at http://www.xcdroast.com) is the classic kind that looks like it was written by a programmer. Don’t get me wrong—X-CD-Roast is extremely powerful and can be fine-tuned and customized to suit just most any need you can dream up, but in terms of making it easy to copy a few data files or audio tracks over to a CD with a mouse click or two, it’s still just too hard.

The third way isn’t nearly as sophisticated as X-CD-Roast, but it’s definitely the way to go for quickly and easily copying files to a CD. This method uses the Nautilus File Manager; you open two windows and drag files from one to the other, and then click the Write CD button and you’re off to the races. Here are the detailed steps.

First, open a copy of Nautilus. Select the folder or file that you want to copy to CD by highlighting it in the right pane, as shown in Figure 30. Next, open a second copy of Nautilus and type “burn://” into the Location box (see Figure 31).

You’ll see a new button appear in the toolbar—“Write to CD” on the far right.

Third, drag the folders and files from the first Nautilus window into the right pane of the second Nautilus window. When you’re done, copies of them will appear in the second Nautilus window, as shown in Figure 32.

Click the Write to CD button in the second window. The “Write files to a CD recorder” dialog will appear (see Figure 33).

Typically you won’t want to change the first two parameters in the dialog. You may want to provide a custom label in the “CD name” text box and check or uncheck the three check boxes according to your personal preferences. I like checking the “Eject CD when done” box so that I have a visual clue (and an explicit reminder) that the burning process is done.
