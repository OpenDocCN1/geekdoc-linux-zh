Once you save your crontab file, the cron jobs will be ready to run. You don’t have to run a program to start the cron process, although you should make sure that the cron daemon is started. (Select Main Menu | System Settings | Server Settings | Services and scroll down the list of services to make sure that “crond” is checked and running.)

The cron daemon will send an e-mail message to the user for whom the crontab was created, notifying the user that it ran (or failed to run) the job. So, back to the initial job: If you wanted to check for F-Prot updates twice a day, at 4:10 a.m. and 6:10 p.m., a cron job like the following would do the trick:

```
10 4,18 * * * /usr/local/f-prod/tools/check-updates.pl -cron
```

Note that you have to be logged in as root when creating this cron job because you need root file-system permissions to update the virus database.
