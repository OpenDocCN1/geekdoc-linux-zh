**Figure 4.** The Network Configuration dialog displays a variety of settings information.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_186_1.png)

**Figure 5.** The Ethernet Device dialog allows you to edit specific network settings for a device.

If your computer is connected to a DHCP server (you’d know this because your Windows network settings would have indicated such), select the “Automatically obtain IP address settings with DHCP” option button. DHCP indicates that the IP address is provided by a different machine.

On the other hand, if you want to set the IP address of your machine yourself, select the “Statically set IP addresses” option button. The three text boxes will become enabled; enter the values that you gathered from your Windows network settings.

As a reminder, the Address value is the IP address of the computer you’re using, and the Subnet mask also refers to the computer you’re using. The Default gateway address is the IP address of the computer that connects directly to the Internet. It may be a server or a router on your network. Again, these settings correspond to similar settings from your Windows network configuration.

The subnet mask also tells your computer which addresses are on the local network; trying to access another address goes through the gateway. For example, a value of 255.255.255.0 means that computers with IP addresses matching the first three numbers (192.168.0) of your IP address are considered part of the local network and can be accessed directly, without going through the gateway.

The Hardware tab, shown in Figure 6, allows you to configure the specific network card you have in your computer.

Most likely, Fedora Core already identified the card so you won’t have any further work to do, but if you need to make a manual tweak, here is where you’d do it.

The third tab, DNS, is used to identify which machines (called “name servers”) your computer looks to in order to resolve domain names, as shown in Figure 7.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_187_0.png)

**Figure 6.** The Hardware tab of the Network Configuration dialog allows you to identify and configure a specific network card.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_188_0.png)

**Figure 7.** Use the DNS tab to set up the name servers your computer will use.

You can use the same settings that your Windows computer used for Primary DNS and Secondary DNS. If you have access to a Tertiary (that means “third”) DNS, go ahead and enter it as well.

The Hostname field is used to identify your machine—if you entered something here during installation, it’ll show up in the lower right corner of the login screen (see Figure 63 in Chapter 2). It’s also used in other contexts that aren’t important right now, but other people on your network may be able to see it at some point, so some modicum of good taste is probably a good idea.

The Hosts tab contains information about other computers on the network that can be recognized by this computer; those settings don’t apply if your machine isn’t on a network as is presumed here. If you were on a network and wanted to access other machines on the network by their machine names instead of their IP addresses, you’d use the Hosts tab to enter mappings of the names and IP addresses.

Once you’re done with the settings, select File | Save, restart the network services, and you’re done.

## E-mail

Many e-mail clients are available on Linux. I’ll cover two popular ones—Evolution and Kmail—to get you started. If you want to explore more, look under Main Menu | Internet | More Internet Applications. Graphical e-mail clients such as Balsa, Mozilla Mail, and Sylpheed, and text-based e-mail clients such as elm, mutt, and pine are included in Fedora Core. (They may not be installed, though. You can check by looking under Main Menu | System Settings | Add/Remove Applications.)

### Evolution

Evolution, by Ximian (see www.ximian.com), is much more than an e-mail client; it’s a complete groupware solution that competes head-on with Microsoft Outlook. Evo (Evolution’s nickname by its users) has a calendar, a to-do list, and an address book. There’s a separate Ximian component called Connector that makes Evolution work with Microsoft Exchange.

Evo’s e-mail client is the default graphical e-mail application for Fedora Core—its icon shows up in the panel after a complete installation, and it’s the primary e-mail client in the Internet menu, shown in Figure 8.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_189_0.png)

**Figure 8.** Evolution is the default Fedora Core e-mail client.

When you open Evolution, you’ll find a common, three-pane interface similar to Microsoft Outlook and other graphical e-mail clients, as shown in Figure 9.

The left pane has a treeview that contains a list of all e-mail folders as well as nodes for other groupware-type functions, such as Calendar, Contacts, Tasks, and so on. The top pane on the right displays a list of messages, one line per message. You can customize the columns in terms of which ones appear (right-click a column heading for a context menu that provides this functionality), in what order they show up (just drag a column where you want it to be), how wide they are, and in what order messages are displayed (click on the column heading).

### Evolution setup

It’s tough to get your e-mail if you don’t set it up first. Click Tools | Settings inside Evolution to open the Evolution Settings dialog, shown in Figure 10.

The icons on the left serve as navigation aids to different screens in the dialog, much like a tabbed dialog. Clicking the Mail Accounts icon displays the list of accounts (shown in Figure 10), while clicking other icons displays entirely different screens.

You can configure Evolution to handle more than one mail account—for example, if you have accounts for yourself at home and at work, Evolution can fetch mail from both accounts—even if the mail is handled by different servers. Another reason you might have multiple mail accounts is if you set up one personal account (such as “whil.hentzen@hentenzerwerke.com”), and another one for use when you have to register on a Web site (such as “whil_register@hentenzerwerke.com”). All of these accounts will be displayed in the list in the center of the Evolution Settings dialog.

Selecting an account and then clicking the Edit button brings forward the Evolution Account Editor dialog, shown in Figure 11.

You’ll need to fill in values in certain fields in three of the first four tabs in the Evolution Account Editor. The other three tabs have optional fields in them.

The first tab, Identity, is where you fill in the e-mail address you’re going to use. You should also include your real name in the “Full name” field; nothing says “13-year-old maladjusted script kiddie” faster than a clever, computer-oriented nom de plume like “deathruler.” And fill in your whole name—professionals don’t send e-mail as “jim”; and with the amount of spam out there these days, a message from “jim” ends up in the auto-delete folder instantly.

You can enter whatever value you want in the Name field because it will be the identification for this account in Figure 10.

The Receiving Mail tab, as shown in Figure 12, is where you configure the mail server that you connect to, in order to fetch the mail that other people have sent you.

As requested in Chapter 2, you should have copied down your e-mail settings so that you know what to put in these fields. The key fields are Server Type, Host, and Username.
