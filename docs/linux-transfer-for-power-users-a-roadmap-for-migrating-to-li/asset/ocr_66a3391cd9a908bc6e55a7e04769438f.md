# # GnuCash

After questions about running Microsoft Office on Linux, the next question many people have is “Can I run Quicken on Linux?” The strict answer is “no,” because Quicken is a Windows product. However, that doesn’t mean that you’re out of luck, any more than you’re out of luck buying a car because the General Motors dealership you’re visiting doesn’t sell Ford Escorts. If you’re looking for automotive transportation, that GM dealership still has plenty of options.

Similarly, the personal finance software option on Linux is the highly regarded GnuCash, which you can find under Main Menu \| Office \| More Office Applications.

The first time you run GnuCash, you’ll be offered the opportunity to import your personal finance files in QIF format, as shown in Figure 24.

Quicken Interchange Format files, used by Quicken, QuickBooks, Microsoft Money, and a number of competing personal finance programs, can be imported by GnuCash either during the initial setup or later, by using the File \| Import \| Import QIF menu option.

If you’re new to GnuCash, or if you’d like to learn how it works, and how it differs from the personal finance program you’re currently using in Windows, you may decide to (gasp!) read the instructions. While open-source software routinely gets a burn rap with respect to its documentation, you’ll find GnuCash to be a breath of fresh air—one-line documentation is well written and chock full of help, as shown in Figure 25.

At the same time, the program is wonderfully laid out and well designed. For example, the New Account Wizard walks you through the tasks of creating accounts (similar to “Categories” in Quicken), as shown in Figure 26.

For example, Figure 26 shows the selection of two sets of accounts. The first set, “A Simple Checkbook,” contains the minimal set of accounts required to use GnuCash, such as a checking account. The second set, “Common Accounts,” includes a fairly wide variety of typical household accounts. Figure 26 shows a few of the accounts, including typical household utility expenses. Once your accounts are set up, you’ll probably want to assign initial values to them, and the Wizard’s last step prompts you to do so, as shown in Figure 27.

For the sake of example, I skipped down to the very bottom of the list of accounts and entered a checking account balance of $1,425.00.
