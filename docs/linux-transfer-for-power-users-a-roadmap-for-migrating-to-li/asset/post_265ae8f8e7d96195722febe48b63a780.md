## Extracting files

Now, how about the reverse—extracting files from an archive?

If the archive file was created with File Roller, regardless of which type of archive and/or compression, you can use File Roller to extract one or more files. Run File Roller by clicking **Main Menu** | **Accessories** | **File Roller**, and you’ll see the main screen as shown in **Figure 1**.

Next, click the **Open button** (or select **Archive** | **Open**, or type Ctrl-O), and select the archive file you want to work with. **File Roller** will show the archived files, similar to **Figure 5**.

Select the files you want to extract, and then click the **Extract button** (or **Edit** | **Extract To,** or Ctrl-X, or right-click and select **Extract To**) to see the Extract dialog, shown in **Figure 8**.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_240_0.png)

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_240_1.png)

The first thing is to specify where you want to extract the files. Note that the default action is “Re-create folders.” This means that if you’re working with an archive including files that were originally archived with a directory structure, that folder structure will be re-created when you extract the files.

You may want to consider whether or not you want to re-create that structure. For example, I often get files from authors who have included the original path to their files with the archive. I don’t want to dig through a directory structure four or five levels deep, so I uncheck the “Re-create folders” check box before extracting the files. How do you know if someone has included the directory structure? If you have selected the “View | View All Files” menu option in the File Roller main window, you’ll quickly see if there are any directories to deal with.

You are not limited to using File Roller on archives that were created using Linux programs. You can extract files from a PKZIP or WinZip compressed archive using File Roller, and you can usually use those (and other) Windows programs to extract files from File Roller archives.

Not all Linux utilities are as involved as File Roller. KAlarm is a simple alarm-clock utility that comes with the KDE desktop environment. It runs in its own window on the desktop. ## KArm

As a software developer, I think that probably every one of my friends and acquaintances has created their own custom time and billing package so that they can track their time and then send accurate invoices to their customers.

In the same batch of utilities as KAlarm is KArm, a simple time tracker. Before you drive yourself crazy trying to figure out what acronym or hidden meaning is behind the name, relax—the word “karm” means “work” in the native language, Punjabi, of the author, Sirtaj Singh Kang. You can start KArm by clicking Main Menu | Accessories | More Accessories | KArm. Figure 12 shows the KArm window with several tasks entered.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_242_1.png)

Figure 12. The KArm window with several tasks and subtasks.

You can enter a combination of top-level tasks (such as “Linux Transfer for Power Users”), subtasks, such as “Chapter 8—Productivity,” and then cascade subtasks (such as the File Roller, KAlarm, and KArm tasks) under the “Chapter 9—Utilities” task.

To create a task, select a menu option under Task—“New” or “New Subtask” as appropriate. You can create subtasks under the currently highlighted task in the KArm window. The same dialog allows you to edit the task name as well as get a running start on the time spent on the task. For example, selecting Task | Edit will open the dialog shown in Figure 13.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_243_0.png)

The two option buttons, “Edit absolute” and “Edit relative,” can be confusing. They’re used for adding time that has already elapsed to a task that you’ve just created. “Edit absolute” allows you to replace whatever values are already there with values you enter, while “Edit relative” allows you to add more time to an existing amount. For example, in order to create Figure 12, I created a task for Chapter 8, and then entered an absolute time, 23:51, into the task. However, I had turned on the KArm task about seven minutes after I started working. Thus, to get the 12-minute value in Figure 12, I entered 5 minutes in the “Edit relative” boxes.

Once you’ve set up a task, you’ll want to start the timer against a specific task. The easiest way is to simply click the task or subtask. When you do so, a little clock will appear to the left of the elapsed time, as shown in Figure 14.

When you want to switch from one task to another, just click that new task—you can’t have the timer running on more than one task at a time.
