Gedit is actually much more than a simple note-taking tool, with a number of configuration options that optimize it to work with formats such as Java, Latex, HTML, XML, and Perl, but those are beyond the purview of this book.

You'll note that while there are nine editors in the list of options in the Open With menu in Figure 1, not all of them are available via the Main Menu. If you want to use one of the other editors, you need to do a couple of things to make it available as an icon on your desktop or panel.

First, you need to know the command to run the editor, and that may require a bit of spelunking. Generally, the command will be the name of the editor, such as "gedit" or "kate." Then you'll have to find the location of the program itself (the file with that name). It's often in /usr/bin, but if not, there are instructions on how to find a file in Chapter 14, "Under the Hood." Finally, you'll just create an icon on your desktop or panel as described in Chapter 6, "Files, Directory Structures, and File Managers."

# OpenOffice.org

Until about two years ago, the major impediment to considering Linux as a desktop operating system was probably the lack of a replacement for Microsoft Office. With the introduction of OpenOffice.org 1.0 at that time, this hurdle was removed.

OpenOffice.org (or "OOo," as it's known) has quickly become the standard open-source office suite around the world (and I don't just say that because we publish several OOO books ourselves!). It's part of every popular Linux distribution, and has the backing of Sun Microsystems, which funded OOO's predecessor, StarOffice, and still provides a great deal of programming support.
