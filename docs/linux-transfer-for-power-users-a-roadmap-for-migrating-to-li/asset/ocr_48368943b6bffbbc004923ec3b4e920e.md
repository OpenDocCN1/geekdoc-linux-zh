# ## Testing and running

To answer the first question, look in the `/usr/local/f-prot` directory. You should see a dozen files and three directories: one each for documentation, man pages (see Chapter 14 under the “Commands” section), and tools.

Next, open a command window and enter this command:

```
```
f-prot -verno
```
```

You should get feedback listing the installed version and the installed virus signature files, as shown in Figure 20.

Next, enter the following command to inspect the passwd file in the `/etc` directory:

```
```
f-prot /etc/passwd
```
```

The bottom half of Figure 20 shows you what the results should look like.

Next, you’ll want to update your virus signature files. Again, open a command window, but this time, become root by using the “su” command, and then type:

```
```
/usr/local/f-prot/tools/check-updates.pl
```
```

If files are available, they’ll be downloaded and installed. If you’ve got the most current files, you’ll get a message that says, “Nothing to be done ...”.
