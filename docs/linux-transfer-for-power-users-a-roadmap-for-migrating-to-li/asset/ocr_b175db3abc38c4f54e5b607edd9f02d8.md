With text editors, it'd be impossible to cover Ooo thoroughly in just this chapter. Indeed, there are a number of books dedicated just to Ooo. Solweig Haugland's 1040-page OpenOffice.org Resource Guide (Prentice-Hall) is the ultimate exhaustive resource for using OpenOffice.org, while Tamar Granor's OooSwitch: 501 Things You Wanted to Know About Switching to OpenOffice.org from Microsoft Office (Hentzenwerke Publishing) addresses Ooo in detail from the perspective of an experienced Office user.

However, I can give you a brief tour and point out some of the highlights. There are several key benefits to using Ooo that you need to know right away.

First, Ooo is completely cross-platform. And that means truly cross-platform-it works on Windows, Linux, and Macintosh-like Microsoft, which uses the term "cross-platform" to mean Windows ME and Windows XP. Because Ooo is cross-platform, you can use it on a Linux machine and on a Windows or Macintosh, and the software will read and write the same data files. This is a great feature when you've got a variety of operating systems in your organization, or different OSs at home and at work.

The second key feature is just that-data files. Ooo can save files in two different formats-its own native, openly documented file format, as well as the proprietary Microsoft Office formats. And these file formats can be exchanged across platforms too. This means that you have a huge amount of flexibility.

For example, you can write a document in OpenOffice.org Writer on a Linux machine, save the file in OpenOffice.org's .sxw file format, and someone using OpenOffice.org on a Windows or Macintosh computer can open and edit that file. In addition, because the .sxw file format is well documented, other applications can open and reliably work with these documents as well.

The same applies to OpenOffice.org's other file formats-spreadsheets (.sxc), presentations (.sxi), and drawings (.sxd).

OpenOffice.org can also read and write files that were saved in Microsoft's proprietary file formats, so that OpenOffice.org users can exchange files with people using Microsoft Office. For example, you can create a presentation in OpenOffice.org Impress on either a Linux or Windows computer, and someone using Microsoft PowerPoint (on a Windows computer, of course) can open and edit that file.

At Hentzenwerke Publishing, we rely on both of these capabilities. Authors write their original drafts using the tool and platform of their choice-either Microsoft Word or OpenOffice.org, and either Windows or Linux. Chapters then go back and forth through technical editing, and the tech editors use whichever tool and platform they're most comfortable with. The same process is repeated with copy editing and layout; most of our copy editors and layout personnel use OpenOffice.org (on either platform), but occasionally we'll have a freelancer who uses Microsoft Word.

A third benefit to using OpenOffice.org is that you can generate a PDF directly from a Writer document, Calc spreadsheet, or Impress presentation. Starting with version 1.1, Ooo has an "Export to PDF" button on the Function toolbar that generates PDF files. These files are good enough that we at Hentzenwerke Publishing generate PDFs that are sent directly to our book printer electronically, and that don't require any manual pre-press work before printing the book.
