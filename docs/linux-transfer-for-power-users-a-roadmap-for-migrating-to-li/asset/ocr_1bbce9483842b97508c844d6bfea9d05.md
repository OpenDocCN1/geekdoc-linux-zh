If your computer is connected to a DHCP server (you'd know this because your Windows network settings would have indicated such), select the "Automatically obtain IP address settings with DHCP" option button. DHCP indicates that the IP address is provided by a different machine.

On the other hand, if you want to set the IP address of your machine yourself, select the "Statically set IP addresses" option button. The three text boxes will become enabled; enter the values that you gathered from your Windows network settings.

As a reminder, the Address value is the IP address of the computer you're using, and the Subnet mask also refers to the computer you're using. The Default gateway address is the IP address of the computer that connects directly to the Internet. It may be a server or a router on your network. Again, these settings correspond to similar settings from your Windows network configuration.

The subnet mask also tells your computer which addresses are on the local network; trying to access another address goes through the gateway. For example, a value of 255.255.255.0 means that computers with IP addresses matching the first three numbers (192.168.0) of your IP address are considered part of the local networking and can be accessed directly, without going through the gateway.
