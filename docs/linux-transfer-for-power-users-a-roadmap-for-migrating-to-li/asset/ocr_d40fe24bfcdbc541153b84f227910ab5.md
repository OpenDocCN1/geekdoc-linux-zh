# The Stylist

If you're not familiar with styles and templates, a brief sojourn is in order, and will be well
worth your while. A paragraph style is a collection of formatting attributes that are given a
single, specific name. For example, you could create a custom look for a paragraph that
specified a 28-point font, bold, and left-aligned. Instead of manually applying those attributes
to each paragraph that you wanted to look like that, you just apply the style to a paragraph,
and voilà! The paragraph now has all those attributes. Even better, should you decide that all of
those paragraphs should really be 30 points instead of 28, you only have to change the style,
and the paragraphs themselves will automatically inherit the new attributes. The name of each
chapter in this book has a style called "chaptitle" that has those attributes.

You can create a special type of document called a template that contains a group of styles
—for example, the template used for this book has styles for various levels of headings,
paragraphs that directly follow a heading, body paragraphs, figure captions, and so on. Using a
template makes it a lot easier to create a long document (or multiple documents) because you
can simply apply a style to a paragraph and you know it will be consistent with all of the other
paragraphs formatted with the same style.

The Stylist is a tool that helps you use styles (either native OpenOffice.org styles or your
own) in your documents. Clicking the Stylist button (or selecting Format | Stylist, or pressing
F11) displays a list, as shown in **Figure 13**.
