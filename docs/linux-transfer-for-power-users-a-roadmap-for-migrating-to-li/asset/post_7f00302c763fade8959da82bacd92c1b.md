## Advanced Topics/Alternatives/Options

Installation doesn't simply consist of a single path, straight and narrow. As you've seen, you can make a number of choices along the way, such as partitioning, setting IP addresses, and so on. In this section, I'll discuss each of these alternatives.

### Modifying automatic partitioning's choices

In step 12 of the "Perform installation" section, you had the choice to examine (and modify) the choices made by the installation routine's automatic partitioning mechanism. At the time, you just accepted the defaults and moved on. Now I'll explain how to modify those choices and suggest some alternatives.

If you select the Review Choices check box in Figure 27, Fedora Core's installation routine will create three partitions and then display them when you click the Next button in step 12. This display looks something like Figure 67.

### Customizing the boot loader options

The two things I'm going to mention with respect to boot loaders aren't necessary during your first (or even your fifth) installation. However, they're nice to know, and may come in handy as you become more experienced.

#### Writing to the Master Boot Record

The first item is determining whether or not this installation is going to write the boot loader to the Master Boot Record. This is done during step 14 of the “Perform installation” section. If you don't understand the concept of writing boot loaders now, don't worry—file it away for later. Click the Change Boot Loader button in the upper right of the screen shown in Figure 28 to open the Change Boot Loader dialog, shown in Figure 71.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_83_0.png)

Figure 71. The Change Boot Loader dialog allows you to prevent the boot loader from being written to the Master Boot Record.

If you want to install GRUB into the Master Boot Record as the boot loader for this installation (which is the default), you'd do nothing in this dialog. However, if you do *not* want to install a boot loader into the Master Boot Record for this installation of Fedora Core, select the “Do not install a boot loader” option button and then click OK. This option comes in handy if you're installing Fedora Core on a machine that already has an operating system (such as Windows) that has its own boot loader in the Master Boot Record, and you don't want to mess with it.

#### Editing the boot loader's label

The second item that is useful is editing the label on the current boot loader. When you finish with installation and start up your machine, you'll be presented with a boot menu like that shown in Figure 66 earlier in this chapter. As you can see, there's only one choice available, and the text on it has already been determined.

There are a couple of reasons that you might want to change the text. Perhaps you just want it your own way. A more common reason is that if you install other operating systems, or if you install updates to this Linux installation, there will be multiple choices in this boot menu, like so:

- Fedora Core (2.6.08-1.0189.npt1)
- Fedora Core (2.4.24-1.2222.npt1)
- Fedora Core (2.4.22-1.2115.npt1)

You might want text labels that are more descriptive, which might remind you of the differences between the various choices, like so:

- FC 1 - 2nd 2.6 kernel (2.6.08-1.0189.npt1)
- FC 1 - new NVIDIA drivers (2.4.24-1.2222.npt1)
- FC 1 - original install (2.4.22-1.2115.npt1)

To change the text, highlight the Fedora Core line in the list box in the middle of the right pane, and then click the Edit button immediately to the right of the list box. The Image dialog, as shown in Figure 72, will appear. To change what appears in the boot menu, change the value in the Label text box, and then click OK.

![](img/50a238d93c7edbdc4387d5ff7f6b7b3c_84_0.png)

**Figure 72. Changing the description of the operating system title in the boot menu.**

### Assigning static IP addresses instead of using DHCP

In step 15 of the “Perform installation” section, you assumed that you were going to use DHCP so that your computer would automatically be assigned an IP address by another box as necessary. What if you want to manually assign an IP address to your computer and keep it the same all the time—in other words, what if you want to use a static IP address?

Technically, the IP address isn’t assigned to your computer, but to the Ethernet card inside your computer that connects your machine to the network. If you have more than one Ethernet card in your computer, you would have more than one entry in the Network Devices list box in the top half of Figure 29.
