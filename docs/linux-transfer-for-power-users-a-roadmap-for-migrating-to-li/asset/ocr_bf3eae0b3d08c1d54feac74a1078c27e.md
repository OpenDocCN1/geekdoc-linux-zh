Because many of the menu items and commands use Nautilus as their default engine (for example, opening the Home Folder from the Main Menu), it’s a good idea to learn a little bit about it.

Nautilus opens in a two-pane display, with the left pane showing treeview nodes for the current user’s home directory, the machine’s entire file system, and any removable storage devices. **Figure 8** shows the first two standard nodes, plus one for a CD-ROM.

![](bbox=[0.07, 0.24, 0.91, 0.58])

By default, you can navigate through the treeview on the left side, expanding and contracting nodes in order to show the contents of folders, and navigating through folders and files.

The first thing you’ll want to do is investigate the preferences for Nautilus so you can set it up to your own style. Click **Edit | Preferences** in the Nautilus menu to bring forward the File Management Preferences screen, as shown in **Figure 9**.

My preference is to smash lots and lots of data into the smallest space possible. On the Views tab, I set “View new folders using” to List View, I select the “Sort folders before files” check box, and I uncheck the “Show hidden and backup files” check box. I also make sure that the “Show only folders” check box is selected in the Tree View Defaults section at the bottom of the tab.

On the Behavior tab, I select the “Include a Delete command that bypasses Trash” check box because it’s nice to be able to delete a file completely with one keystroke or mouse click without being prompted.
