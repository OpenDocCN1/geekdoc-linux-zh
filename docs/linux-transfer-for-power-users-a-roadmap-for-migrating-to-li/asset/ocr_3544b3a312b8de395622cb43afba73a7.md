# Chapter 12
Devices: Printers, Scanners, CD Burners

While the majority of this book has focused on what comes as part of the standard Fedora Core package, there’s one thing that you’re undoubtedly going to use that doesn’t come with Fedora Core: devices. Some devices have already been covered elsewhere in this book: I discussed a quick, step-by-step procedure for burning a CD-ROM in Chapter 2, and a similar procedure for downloading files from a digital camera in Chapter 10. In this chapter, I continue to show you how to use various common devices with your Linux desktop. I’ll show you how to hook up a local printer and how to configure a print queue, how to use a Fedora Core GUI application to burn CDs, and how to connect a scanner.

As a software developer, I hang out with other programmers in many venues. And our common mantra has long been “If it weren’t for the darn hardware, our job would be a lot easier.” As a power user, you may have come to the same realization yourself. Nonetheless, hardware is here to stay, at least for a while, so we will have to learn to get along with it. Fortunately, there is a group of very bright programmers who enjoy interfacing with hardware, and their efforts have made our lives easier with respect to printers, scanners, and CD burners.

# Printers

Linux has gotten a bad rap for being hostile when dealing with hardware; in some cases, that reputation has been well justified. But great strides have been made in the last couple of years with Kudzu—the hardware-detection daemon from Red Hat—which automatically finds and configures new hardware attached to the system. Fedora Core is particularly friendly toward local printers.

I’m going to discuss attaching a local printer to your Fedora Core box in three stages. First, I’ll discuss how Kudzu works when you simply plug a new printer into your computer, and what you can expect. Then I’ll describe how to set up a print queue. Finally, I’ll show you how a print queue works with typical software on your machine.

What if you don’t let Kudzu configure your printer for you? As you’ll see, it doesn’t matter. You can configure your printer and add a print queue at the same time.

# Kudzu

If you plug a printer into your computer and then boot it up, the Kduzu daemon will typically detect that new hardware has been added (or removed) and offer to continue configuration for you. You can also skip the configuration at that time, and run Kduzu manually from a command prompt. You have to be logged in as root in order to run this command:

```
/usr/sbin/kudzu
```
