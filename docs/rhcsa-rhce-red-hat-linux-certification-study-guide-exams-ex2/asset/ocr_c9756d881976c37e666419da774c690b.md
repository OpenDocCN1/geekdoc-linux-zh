If port 80 is open in an existing local firewall, this page should be accessible from remote systems as well. In addition, you'll need to make sure Apache starts automatically the next time RHEL 6 is booted. One way to do so is with the following command:

```
# chkconfig httpd on
```

For more information on how services like Apache are controlled during the boot process, see Chapter 11. While that is an RHCE chapter, the actual command required in this situation is simple.
