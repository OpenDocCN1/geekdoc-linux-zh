虽然较早版本的目标指定使用 bash shell，但一些 Linux 用户使用不同的 shell。没关系。管理脚本将一系列命令组合在单个可执行文件中。自动化脚本通常按固定时间表运行，这使得 cron 守护进程非常适合此目的。

一些 Linux 管理任务可以通过内核运行时参数来完成，即内核如何管理操作系统。这是通过 /proc/sys 目录中的文件和 sysctl 命令实现的，并由以下目标概括：
