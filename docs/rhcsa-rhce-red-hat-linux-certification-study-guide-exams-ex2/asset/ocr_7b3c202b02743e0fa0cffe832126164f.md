Test Operators
for bash Scripts

| Operator | Description |
|---|---|

# Test Operators withtest

The test operator is sometimes used as a conditional within the if. For example, the original version of the 0anacron script in the /etc/cron.hourly directory includes the following line:

```
if test -x /var/spool/anacron/cron.daily;
```

which is functionally equivalent to

```
if [ -x /var/spool/anacron/cron.daily ];
```

# The doLoop

The do loop normally exists within other loops. It's fairly simple; the following example continues until some condition related to variable n is met:

```
do
  echo "I love Linux $n"
done
```
