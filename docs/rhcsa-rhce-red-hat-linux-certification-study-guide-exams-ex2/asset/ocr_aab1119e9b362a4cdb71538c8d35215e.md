# Lab 5

In this lab, you'll set up the /etc/hosts file on each of the systems described in Chapter 1. Except for the local system settings added by the Network Manager, the data in /etc/hosts on all three systems may be identical. Specifically, that file should include the following entries:

```
192.168.122.50  server1 server1.example.com
192.168.122.150  tester1 tester1.example.com
192.168.100.100  outsider1 outsider1.example.org
```

It doesn't matter what the systems are on different IP networks. As long as there's a routing path between systems, this data in each /etc/hosts file will work. And duplication with data inserted by the Network Manager is not a problem, as long as the data is consistent. In fact, it's possible to set up multiple names for an IP address; for example, if I set up a web server on the 192.168.122.50 system, I could add the following entry to /etc/hosts.

```
192.168.122.50  www.example.com
```
