+   5. While other methods are available, the straightforward way to limit access in the main NFS configuration file (*\`/etc/exports\`*) can be limited to a single host, with a directive such as the following:

```
`/home \ mau\ i. example. com \ (rw)`
```

You should substitute the hostname or IP address of your physical exam sys-
* tem. In addition, other exams may specify a different set of permissions, such
* as read-only (*ro*), no root access (*root\_squash*), and more. Access should like
* confirmed from the physical host system by mounting the shared NFS directory.

