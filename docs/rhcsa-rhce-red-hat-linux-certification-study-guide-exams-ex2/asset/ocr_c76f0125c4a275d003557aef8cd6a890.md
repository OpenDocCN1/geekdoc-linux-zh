+   12.  Peers on an NTP server can be enabled in the /etc/ntp.conf file, in place of the **server** directive. Just remember, NTP communicates over UDP port 123. Accordingly, you can't use the **telnet** command to verify the open connection. One way to check if UDP port 123 is open is with the following command: **nmap -sU server1 -p 123**.  
+   13.  To avoid responding to the **ping** command, which works over IPv4, the **icmp_echo_ignore_all** option must be active. You can set that up permanently in the /etc/sysctl.conf file with the **net.ipv4.icmp_echo_ignore_all = 1** directive.
