# Lab 2: Caching and Forwarding DNS Server

As with Lab 1, the focus is on the configuration of the /etc/named.conf file. Nominally, the default\ncaching-only DNS server already includes forwarding features, courtesy of the named.ca file listed\nnear the end of the file. But to set up a specific forwarding server, you should add a **forwarders** entry\nsuch as the following in the **options** stanza.

```
forwarders { 192.168.122.1; };
```

Don't forget to configure a firewall, with an open UDP port 53. If necessary, you can set up host\nrestrictions on the **iptables** rule that opens up that port, as discussed in the answer to Lab 1. You'll\nalso need the rules to limit access to the local network. For example, the following output to the\n**iptables -L** command shows TCP and UDP port 53 (listed as domain in /etc/services) available to the\n192.168.122.0/24 network:

```
ACCEPT  tcp  --  192.168.122.0/24 anywhere  state  NEW  udp dpt:domain\nACCEPT  tcp  --  192.168.122.0/24 anywhere  state  NEW  tcp dpt:domain
```

In general, it's best to set up such a change as a custom rule in the Firewall Configuration tool, if\nyou want to use that tool in the future. As for the other requirements of the lab, you can clear the\ncurrent cache with the **rndc flush** command, and reload the configuration file with the **rndc reload**\ncommand.
