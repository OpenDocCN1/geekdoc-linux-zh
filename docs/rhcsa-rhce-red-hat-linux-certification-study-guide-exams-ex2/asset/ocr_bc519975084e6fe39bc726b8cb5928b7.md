# The System Status Service

To set up the system status service, install the sysstat package. It’s a regular server service, with its own daemon in the /etc/init.d directory. It’s a cron job, run on a regular basis, as defined in the /etc/cron.d directory. It’s a series of related commands, which we cover here.
