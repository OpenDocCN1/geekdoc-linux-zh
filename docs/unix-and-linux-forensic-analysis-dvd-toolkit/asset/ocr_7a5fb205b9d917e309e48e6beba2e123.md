As you can see from Figure 5.18, the URL can either be “localhost” or “127.0.0.1.” My personal preference (and based on my experience) is to use the loopback IP address rather than the hostname “localhost.”This is configurable by using the “-a” switch and providing an alternative IP address. You will also notice that the default port that the Web interface is running on 55555. This can be changed by using the “-p” switch and providing an alternate port.
