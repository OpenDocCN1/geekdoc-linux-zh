The only members of a corporate IT staff who should have this program loaded, are security administrators and penetration testers. Anyone else found to have MSF loaded should be questioned.

At the time I wrote this, the current version of MSF was available for download at www.metasploit.org/framework/download/. The file is called "framework-3.1.tar.gz" and is 10076364 bytes, and takes about 10 seconds for me to download on my home network. After unpacking the tarball into /usr/local/src, a new directory is called framework-3.1.

After installing a few additional packages,¹ I was able to get MSF running on my Ubuntu 7.10 release in VMware. In addition to the traditional command-line and Web GUI interfaces, version 3.1 is an "experimental" Ruby¹²-based GUI shown in Figure 5.10.
