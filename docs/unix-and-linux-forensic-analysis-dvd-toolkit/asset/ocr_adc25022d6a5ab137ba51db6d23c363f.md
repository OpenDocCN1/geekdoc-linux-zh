As you can see, Nikto identifies the hostname, the Web server version, which HTTP methods are allowed, several directories including cgi-bin (a favorite among hackers), and the installation manual. As a former tester, by Nikto scans scan back information with this, I would get excited. It meant that I could focus my attack on that specific Web server version, I could try some directory traversal attacks and break out of the web root, and I could create to some credentials for myself by posting data to the .htaccess and/or the .passpasswd files.

Performing recon is always a hacker's (at least any decent hacker) first step in promising a target. Knowing what OS in running, what ports are open, what services are using those ports, version of all services, and what information will help significantly narrow the focus of any attack. This could quite literally mean the difference between days of penetration attempts and minutes.

If any of these tools appear on systems that are part of an incident, you should definitely look at at the network logs (provided the customer has them) and try to identify potential targets.
