Arguably the most used function of Paros is the ability to intercept and manipulate Web traffic, both going and coming from the target. This function is found by clicking on the “Trap” tab on the right-hand panel, and selecting the checkboxes marked “Trap request” and “Trap response.” By selecting these functions, Paros will grab and hold all HTTP/Hypertext Transfer Protocol Secure (HTTPS) traffic, as well as allow changes to be made that may not be available from the actual page (i.e., hidden fields).
