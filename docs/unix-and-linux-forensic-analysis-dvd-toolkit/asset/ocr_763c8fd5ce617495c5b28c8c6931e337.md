Finally, two command-line features of modern *nix that Windows might overlook are filename completion and command completion. Try it! Start typing a filename and hit that TAB. Hit again if nothing happens. When you see that long filename get completed, or a list of possible completions appear instantly, you'll wonder how you ever lived without it. Incidentally,Windows cmd. exe has filename completion, but you may have to tweak a registry entry to enable it. Also, prior command history is available often with hitting the up arrow, which can save a lot of retyping. Windows also has a similar feature.

# # Highlights of The Linux Security Model

Linux and *nix are a lot pickier about security than Windows. Security permeates the design of the operating system in *nix rather than a bit of an afterthought sometimes it feels like Windows. For instance, in the *nix world, there is no such thing as your default user as Administrator. If you want to do something that will dramatically change your system, you need to do it as the administrative user, and anyone that does 100 percent of their work logged in as root is considered, well, a bit of a dangerous duty. And happily, since the operating system was designed with this model in mind from the ground up, it is not painfully to run this. User accounts in Linux fall into three categories: they are either the super (normally named root), system accounts (such as mail, uuc, bin, lp, nobody, apache), or normal user accounts (james, todd, chris). In *nix, root is akin to Administrator in Windows.

Authentication in *nix can be done in a lot of different ways, but the simplest (and default) setup is local authentication. User accounts are stored in a plain text file /etc/password and passwords are stored in their hashed form in /etc/shadow (or /etc/security/shadow in some *nix). All users can read /etc/password, but, so that no user can grab the ghes to stop cracking passwords, only root and the shadow group can read /etc/shadow. Have a look for yourself:

```
ubuntu@ubuntu:~$ ls -l /etc/shadow /etc/passwd
-rw-r--r-- 1 root 1426 2008-03-23 14:27 /etc/passwd
-rw-r--r-- 1 root 877 2008-03-23 14:27 /etc/shadow
| | |
  | --- owner/user permission bits
  | group permission bits
      world/other permission bits
```
