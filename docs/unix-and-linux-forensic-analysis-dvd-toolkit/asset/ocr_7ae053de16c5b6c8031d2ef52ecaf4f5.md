# Canvas/Core Impact

Immunitysec⁹ Canvas and Core Security¹⁰ Core Impact are commercially available exploit frameworks that are delivered with exploit code for a large variety of vulnerabilities. Remotely exploitable network service vulnerabilities are among the exploits offered, as are client-side exploits involving internal employees to visit malicious Web sites and compromise the victim’s machine by leveraging various client-side vulnerabilities.

Canvas is a commercial penetration testing tool from ImmunitySec. Due to its relatively low price tag, it is the more common of these two commercial exploit frameworks. The framework of Canvas is delivered in an entirely Python (an interpreted programming/scripting language) distribution, including source code where users can modify the exploits as needed. The Canvas framework is supported on Windows, Linux, Mac OS X, or anywhere you can run python and PyGTK. Mobile phones are even possible to run the framework. Canvas supports a wide range of stealth options to evade even the most invasive of IPSes.
