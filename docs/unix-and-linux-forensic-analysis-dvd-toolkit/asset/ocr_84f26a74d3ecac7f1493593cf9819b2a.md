This can be tricky sometimes, but a Universal Serial Bus (USB) drive will appear in /dev (device) as sdb1 or uba1, which incidentally is undesirable as performance is USB 1.1. If the drive is not readily available, a static OS may be the best option. Of those releases equipped with current USB drivers, and should automatically recognize the external device.

The “lsusb” command will show all of the attached USB devices. It should be pretty obvious which is the newly connected device, especially if there is only one USB device attached. Additionally, “dnmesg -i “SCSI device” will display devices available that have the Small grep Interface (SCSI) distinction (even if it’s not a SCSI device). The easiest command of all, is “cat /proc/partitions.” This will show you partitions are connected to the system, to include the newly connected device, without a bunch of erroneous information. As we stated in the introduction, there are always multiple ways of doing the same in Unix.

Once the device is identified, find all devices with the prefix -ls /dev/sd* (either a or b). The device identifier may also be displayed with a # after it. The number in question will probably be a “1,” unless there are multiple USB drives plugged in, in which case the number may be a 2, 3, 4, and so on, depending on the number of devices that are connected to the machine. Once the drive is mounted, perform a short test by trying to make a directory, or use the touch command to create an empty file. Once the test is successful, the target media has been mounted properly and data acquisition proceed.

# Format the Disk with the ext File System

If you are going to use Windows to perform any portion of the post mortem analysis (i.e., EnCase, FTK2, or Pro Discover), I highly recommend that you download IFS Drives.¹ This open source utility will allow your Windows machine(s) to recognize and use the “ext” file system.

On your Linux machine, the “mk2fs /dev/<yourdevice>-L <customer_hostname>” command will begin the format process. This will create an ext2 file system. If you want to create an ext3 file system, use mkfs.ext3.
