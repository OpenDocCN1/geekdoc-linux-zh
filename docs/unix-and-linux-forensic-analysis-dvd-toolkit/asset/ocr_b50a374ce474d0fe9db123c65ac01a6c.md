With that brief introduction to file permissions behind us, we can return to
user authentication. Here’s what /etc/passwd looks like: a colon-delimited text file
in the format of:
username:passwordfield:UID:GID name:home directory:default shell.
ubuntu@ubuntu:$ cat /etc/passwd | head -14

The second field we see is an x is a password field. When shadow files are
being used (as is the case in all modern *nik’s), the x represents a shadowed password
entry and tells Linux to look in the shadow file for the password hash.
