# Live Response: Data Collection • Chapter 3

From the command line on both systems, use the following commands:
nifdown eth0 (or whichever Ethernet adapter you are using)
ifconfig eth0 10.0.0.x netmask 255.255.255.0 (use a different
number for each system, subnet will remain the same)
ifup eth0

Once the IP system has been set, make sure that each host can ping the
other. Ensure the target system is off the company network, and the forensic connection
is the only one available. If not, ensure that the customer is informed that the image
integrity will be skewed, and subsequent litigation will not be possible. As a
forensic note, this is where the process can get a bit tricky. A good idea to use
the forensic notebook to make a small diagram of the two systems, and the file
systems you are working with. This might sound somewhat basic, but it is very easy to
get jumbled up in your head.

In a perfect world, the drive we is imaged should be called /dev/hda1,
s since we not know who lives in said world, you will have to manually
validate the target drive. Generally speaking, the boot sector is found in /dev/hda,
while the file system is found in /dev/hda1. If the drive is SCSI, then simply replace
t "h" with an "s" (exe. sda). By issuing the "mount" command, you will be given
al list of mounted devices, including the newly created mount point. In this listing,
t /dev/hdLN should indicate the primary drive, where "L" is a letter and "N" is a
positive integer. You can also review the information in the /etc/mtab, the messages
log, or /proc/partitions.

On the target system, create a mount point to your local forensic system.
the forensic system, create a directory into which the dd image will be transferred.
This will be the external drive which was mounted earlier. For example, the path
should looks something like this:
/media/disk/IBM/customer_host

On the forensic machine, start the Network File System (NFS) service:
Service nfs start (this may vary from each system, .eg /etc/init.d/nfs start)

On the forensic system, export your share:

```
/etc/exports
Shift I (for insert mode)
Add your mount point, in this example, /media/disk/IBM/customer_host
ESC (exit current command selection), Shift : (edit exit mode), W (write),
Q (quit),!(absolute write)
```
