# Viruses

My research Linux viruses reminded me of why I have such a deep adoration for the Linux user community. I literally was ROFL at the vast majority of the posts that I read all communicated the same thing: if you are a Linux user and you get a virus, you are stupid.

Not satisfied with the brevity of that statement, I continued my whimsical search through the various security and user forums in an attempt to find the smoking gun that would illustrate once and for all viruses were possible on Linux systems, and anybody could get them. I found that while several worms and viruses had been identified throughout the years such as Ramen, li0n, Red Worm, Adore, Ipdw0rm, Slapper, Flooder.Linux.Small.f, and Zipworm, the common thread that they all required some kind of user interaction or administrative laziness.

It is a common belief that Linux systems are not vulnerable to infection by malware. This is false; however, one can say that malware infections are not nearly common as in Linux as they are on Windows machines. The reasons for this are a mix of technical and economic. Economically, if a malware or adware is interested in revenue and adding hosts to their botnet, the sheer popularity of Windows makes it a better use of time to write for that platform the comparatively less popular Linux or Mac platforms. Technically, the Linux system is organized, and the diversity of distributions in Linux with all a slightly different way of installing software, easily makes things more difficult for someone wanting to write self replicating code, or a quickly/easily installed backdoor from a drive-by download. Linux doesn't have a dangerous ActiveX–enabled Web browser installed by default, unlike Windows with Internet Explorer, and finally Linux users don't log in with Administrator privileges and do all their work that, unlike the default installations of Windows.
