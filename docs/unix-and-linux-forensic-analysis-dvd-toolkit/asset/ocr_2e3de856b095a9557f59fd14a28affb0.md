As you can see there are numerous places an intruder can set up a script to help maintain access to a compromised system. Careful review of all the scripts involved in the boot process is mandatory in such a scenario.

# System and Security Configuration Files

There are many system configuration files that can provide you with more information about the state of the current running system (if performing live response), or the state of the system last time booted (performing a post-mortem analysis). Each service that runs on the system will likely have at least one (and probably several) configuration files that affect its operation. Providing an in-depth examination of every configuration file even on a stripped down Linux system is out of the scope of this work; however, we will go into the location and function of some of the more relevant and important system and security configuration files.
