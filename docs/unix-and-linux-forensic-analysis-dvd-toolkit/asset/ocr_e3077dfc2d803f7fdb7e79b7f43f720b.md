You can mount disks in mode "ro" for read only; something you may desire for doing forensic investigation, for instance (though it's hard to beat the assurance that with a parallel ATA drive connected that the write wires are physically disconnected). Consult the mount page for details, which we'll wet your appetite with some examples.

One thing that's nice about LiveCD is that you can use it to peek into the event of a Windows disk if/when Windows is misbehaving or can't be trusted in the event of a malware infection. The way to do this is to mount your internal hard drive. In *nix, with utilities like mount and finger installed by default, you'll just have to get to use these things.

To mount your local drive read-only, you'll first create a mount point (empty directory), and then we'll attempt to mount it:

```
ubuntu@ubuntu~$ ls /dev/sd*
/dev/sda /dev/sda
```

```
ubuntu@ubuntu~$ mkdir /mnt/mywindrive
mdir: cannot create directory '/mnt/mywindrive': Permission denied
ubuntu@ubuntu~$ # Doh! Mortals don't have write permission to /mnt
ubuntu@ubuntu~$ sudo mkdir /mnt/mywindrive
```

```
ubuntu@ubuntu~$ ls /mnt
mywindrive
```

```
ubuntu@ubuntu~$ sudo mount -o ro -t auto /dev/sdal /mnt/mywindrive
ubuntu@ubuntu~$ mount
proc on /proc type sysfs (rw)
sysfs on /sys type sysfs (rw)
tmpfs on /lib/modules/2.62.22-14-generic/volatile type tmpfs (rw,mode=0755)
tmpfs on /lib/modules/2.62.22-14-generic-volatile type tmpfs (rw,mode=0755)
varrun on /var/run type tmpfs (rw,noexec,nosudid,mode=0755)
varlock on /var/lock type tmpfs (rw,noexec,nosudid,mode=0777)
udev on /dev type tmpfs (rw,mode=0755)
devshm on /dev/shm type tmpfs (rw)
devpts on /dev/pts type devpts (rw,gid=5,mode=620)
tmpfs on /tmp type tmpfs (rw,nosudid,nodev)
```

```
/dev/sdal /mnt/mywindrive type fuseblk
(ro,nosudid,nodev,noime,allow_other,blockSize=4096)
```

In all likelihood, if you have a relatively "normal" Windows PC that you haven't partitioned creatively or installed to a non-default disk, your Windows partition is likely named /dev/sda1.
