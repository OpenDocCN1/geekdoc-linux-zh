# 5.3 Wireshark

![](bbox=[0.095, 0.101, 0.905, 0.535])

In my example, I ran an nmap OS and version scan as a privileged user, with the verbose flags set at `nmap -A 192.168.10.115`. Notice that the port selection is completely random. This is a default in nmap used to avoid Intrusion Detection System (IDS)/Intrusion Prevention System (IPS) sensors. You can see a huge amount of traffic generated by the scan; not something a hacker wishing to remain anonymous should do, yet I have seen time and time again. So much so, that you would have to press an miss to enter this entry in network logs. Just look for the single IP carpet-botting the other hosts on the network, and dollars to doughnuts that's your scanner!
