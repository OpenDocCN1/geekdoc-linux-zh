init then runs the /etc/rc.d/rc.sysintprint before running /etc/rc.d/rc 5, based
on our default runlevel of 5. /etc/rc.d/rc then proceeds through the /etc/rc5d/
killing starting processes based on the scripts. (See Figure 7.1.)

> Note that each entry in a directory is a symbolic link to a script
in /etc/init.d/, which will be started or stopped on the name of the
symlink. Each script contains a myriad of variables and actions that will be taken to
start or stop the service gracefully.

```
# Run getty in standard runlevels
1:2345:respawn:/sbin/mingetty tty1
2:2345:respawn:/sbin/mingetty tty2
3:2345:respawn:/sbin/mingetty tty3
4:2345:respawn:/sbin/mingetty tty4
5:2345:respawn:/sbin/mingetty tty5
6:2345:respawn:/sbin/mingetty tty6
# Run xdm in runlevel 5
x:5:respawn:/etc/X11/prefmd -nodaemon
```

Finally, init spawns six virtual terminals and begins the X display manager,
enabling graphical (or console) login.
