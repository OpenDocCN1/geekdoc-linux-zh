## 行业技巧

操作系统不会在你的搜索请求中要求你“提供更具体的内容”。简单来说，你将得到你想要查找的内容。因此，你必须知道如何正确地堆叠搜索参数，以使你的关键词搜索尽可能高效且有效。

```
nc <host.com> (or IP address) <port> <infile
```

接收文件的命令是：

```
nc -l <port> > outfile
```
