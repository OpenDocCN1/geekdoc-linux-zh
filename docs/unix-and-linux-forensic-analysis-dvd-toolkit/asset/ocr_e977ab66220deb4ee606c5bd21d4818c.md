# modules

As the name implies, this file lists all of the modules loaded into the kernel. This is
good information to collect as part of any investigation, and may prove useful if
you find yourself dealing with a simple file-patching/replacing rootkit. For example,
a rootkit may alter the lsmod binary to omit reporting it as a loaded module, yet cat
/proc/modules will reveal its presence.

# mounts

This file lists all of the current mounts on the system. This data is useful for several
asons, primarily to identify any external storage you are using to collect data, any
Network File System (NFS), or other network shares that are mounted, and verifying
at mounts that should be read-only (or read-write) are mounted appropriately.

```
rootfs / rootfs rw 0 0
/dev/root / ext3 rw,relative,data=ordered 0 0
/dev /dev tmpfs rw,relative 0 0
/proc /proc proc rw,relative 0 0
/sys /sys sysfs rw,relative 0 0
/proc/bus/usb /proc/bus/usb usbfs rw,relative 0 0
devpts /dev/ptpts devpts rw,relative 0 0
/dev/sda1 /boot ext3 rw,relative,data=ordered 0 0
tmps /dev/shm tmpfs rw,relative 0 0
none /proc/sysfs/binfmt_misc binfmt_misc rw,relative 0 0
sunrap /var/lib/nfs/rpc_pipes rpc_pipes rw,relative 0 0
none /proc/fs/vblock/mount vblock rw,relative 0 0
/etc/auto.misc /misc autofs rw,relative,fd=6,pggrp=1998,
timeout=300,minport=5,maxproto=5,indirect 0 0
-hosts /net autofs rw,relative,fd=11,pggrp=1998,
timeout=300,minport=5,maxproto=5,indirect 0 0
.host. / /mnt/hgfs vmhgs rw,relative 0 0
```
