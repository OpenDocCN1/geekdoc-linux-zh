# Chapter 2 • Understanding Unix

Above, we see the long-format file listing for the shadow and passwd files.
listing serves as our first introduction to *nix file permissions.
The permissions on the left show what the owner, group, and others can do with
each file, who owns it, which user group is associated with it, its size in blocks, and
its modification time are all shown in the long listing. The permissions are
listed in the order of owner, group, others. r is for read, w for write, x for execute.
In this example, /etc/passwd has -rw-r--r--, which you can read as
(readable) by its owner (root), group, and others. It is only writable by
its owner (root). Anyone wanting to change /etc/passwd will need have root
privileges (either the root password or “su -” to switch to user root, or be
in the admin group or/be listed in /etc/sudoers appropriately and just prepend
t command with sudo). File permissions can also be expressed numerically.
The chmod and umask commands are where you'll find this most frequently -rw-r-- can be expressed as 644. In binary, the execute bit is the least significant (2^0 = 1), the write bit is the most significant (2^1 =), and the read bit is
the third position (2^2=4). For owner, read and write bits are set corresponding to
4+2=6. For group and world, we'll create a blank file named foo, and exercise a different
ways to modify the file permissions with chmod. # is the comment character in *nix
shell, the shell ignores everything after a comment character. We'll use this to
anotate commands in examples.

```
ubuntu@ubuntu:~$ touch foo
ubuntu@ubuntu:~$ ls -l foo
-rw-r--r-- 1 ubuntu ubuntu 0 2008-04-14 20:25 foo
ubuntu@ubuntu:~$ chmod go-r foo # remove group and other permission
ubuntu@ubuntu:~$ ls -l foo
-rw------- 1 ubuntu ubuntu 0 2008-04-14 20:25 foo
ubuntu@ubuntu:~$ chmod 644 foo
ubuntu@ubuntu:~$ ls -l foo
-rw-r--r-- 1 ubuntu ubuntu 0 2008-04-14 20:25 foo
ubuntu@ubuntu:~$ chmod 777 foo # set read write and execute bits (dangerous)
ubuntu@ubuntu:~$ ls -l foo
-rwxrxr-x 1 ubuntu ubuntu 0 2008-04-14 20:25 foo
ubuntu@ubuntu:~$ chmod 000 foo # strip all the permissions
ubuntu@ubuntu:~$ ls -l foo
---------- 1 ubuntu ubuntu 0 2008-04-14 20:25 foo
---------- 1 ubuntu ubuntu 0 2008-04-14 20:25 foo
ubuntu@ubuntu:~$ cat foo  # Can't even read our own file now
```
