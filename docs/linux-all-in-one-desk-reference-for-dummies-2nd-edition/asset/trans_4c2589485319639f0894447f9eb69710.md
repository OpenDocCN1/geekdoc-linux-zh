DVD 中包含几种不同格式的 Linux 发行版：

- **完整发行版：** 您可以从 DVD 启动并安装完整的发行版。使用完整发行版时，除了从 DVD 启动外，您无需执行任何特殊操作。然后，您可以直接继续安装 Linux 发行版。
- **即插即用的 Live CD：** 您可以从 DVD 启动计算机来运行 Live CD。启动即插即用的 Live CD 后，您将看到一个 Linux 图形用户界面（GUI）桌面，您可以立即开始使用，而无需在硬盘上安装任何内容。
- **ISO 镜像：** 您需要将 ISO 镜像刻录到 CD 上，然后从这些 CD 进行安装。虽然您可以自己下载 ISO 镜像，但文件相当大——每个 ISO 镜像约为 700MB——将它们放在 DVD 上可以省去从互联网下载大文件的麻烦。其中一些 ISO 镜像是 Live CD 镜像。当您从 Live CD ISO 刻录好 CD 后，可以从 CD 启动，从而在未向硬盘安装任何内容的情况下获得 Linux 系统。

以下是 DVD 中包含的 Linux 发行版：

- **Debian：** 以网络安装 ISO 镜像的形式提供。刻录 CD 后，您即可通过互联网上的服务器从网络安装 Debian（您需要互联网连接来执行此安装）。
- **Fedora Core：** 作为完整发行版包含在内。只需从 DVD 启动，您就会看到安装 Fedora Core 的选项。使用图形安装程序完成安装步骤。
- **Knoppix：** 作为即插即用的 Live CD 包含在内。从 DVD 启动，您会得到启动 Knoppix 的选项。启动后，您无需在硬盘上安装任何内容即可获得 Knoppix 桌面。
- **MEPIS：** 提供为 Live CD ISO 镜像，同时也充当安装 CD。刻录 CD 并从中启动以试用 MEPIS。您也可以从同一张 CD 继续安装它。
- **SUSE：** 提供为单个 Live DVD ISO 镜像文件。将 ISO 文件刻录到 DVD 上，然后从 DVD 启动，以直接从 DVD 运行 SUSE Linux。（DVD 上的有限空间使我们无法提供完整的 SUSE Linux 发行版。若要下载完整的 SUSE Linux 发行版，请访问 <http://ftp.opensuse.org/pub/opensuse/distribution/sl-oss-stable/>）
- **Ubuntu：** 提供为单个安装 CD ISO 镜像。刻录 CD 并从中启动以开始安装。
- **Xandros Open Circulation Edition：** 提供为单个 CD ISO 镜像。刻录 CD，然后安装 Xandros。
