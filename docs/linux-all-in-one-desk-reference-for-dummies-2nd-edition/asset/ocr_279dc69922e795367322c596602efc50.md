# Setting Up Dialup Networking

Dialup networking refers to connecting a PC to a remote network through a dialup modem. If you are ancient enough to remember the days of dialing up with Procomm or some serial communications software, realize that there is a significant difference between dialup networking and the old days of serial communication. Both approaches use a modem to dial up a remote computer and to establish a communication path, but the serial communication software makes your computer behave like a dumb terminal connected to the remote computer. The serial communication software exclusively uses dialup connection. You cannot run another copy of the communication software and use the same modem connection, for example.
