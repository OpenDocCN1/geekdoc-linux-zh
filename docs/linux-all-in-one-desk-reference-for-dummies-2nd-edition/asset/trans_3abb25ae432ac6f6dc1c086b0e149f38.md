在使用指针之前，请确保它包含一个有效对象的地址。

示例展示了使用 `&` 运算符将 `p_i` 初始化为整型变量 `count` 的地址，该运算符向 C 语言提供了变量的地址。在 `p_i` 初始化之后，你可以使用表达式 `*p_i` 来访问 `count` 的值，该表达式读作“地址存储在 `p_i` 中的对象的内容”。

指针在许多情况下非常有用；其中一个重要场景是动态内存分配。标准 C 库包含诸如 `malloc` 和 `calloc` 等函数，你可以调用这些函数为对象数组分配存储空间。分配内存后，这些函数返回内存块的起始地址。由于该地址是访问该内存的唯一途径，你必须将其存储在一个能够持有地址的变量中——即指针。

假设你为包含 50 个整数的数组分配了内存，并将返回的地址保存在 `p_i` 中。现在，你可以将这块内存视为一个名为 `p_i` 的包含 50 个整数的数组。因此，你可以将数组中的最后一个元素表示为 `p_i[49]`，这等价于 `*(p_i+49)`。同样，C 语言将数组的名称视为指向数组第一个元素的指针。数组名称和指针变量之间的区别在于，数组的名称是一个常量，不需要显式的存储空间来持有数组第一个元素的地址。而指针则是一个实际存储位置，能够持有任意数据的地址。

除了存储动态分配内存的地址外，指针还常用作函数的参数。当调用 C 函数时，其所有参数都是按值传递的——也就是说，函数获得的是每个参数的副本，而不是函数调用参数列表中出现的那些原始变量。因此，C 函数无法改变其参数的值。指针提供了一种解决方案。要在函数中改变某个变量的值，你可以传递指向该变量的指针；函数随后可以通过指针来改变该值。

### 类型定义

通过 `typedef` 关键字，C 语言为您提供了一种将新名称分配给现有数据类型的便捷方式。你可以使用 `typedef` 设施为特定应用程序中使用的数据类型赋予有意义的名称。例如，图形应用程序可能会声明一个名为 `Point` 的数据类型，如下所示：

```c
/* Declare a Point data type */
typedef struct Point
{
      short x;
      short y;
} Point;
```

## 类型限定符：const 和 volatile

两个类型限定符 `const` 和 `volatile` 在声明中的工作方式如下：

-   **const** 限定符告诉编译器，程序必须不修改特定的数据对象。编译器不得生成可能改变该数据项存储位置内容的代码。

-   **volatile** 限定符指定超出程序控制范围的因素可能会改变变量的值。

你可以在单个数据项上同时使用 `const` 和 `volatile` 关键字，这意味着虽然你的程序不得修改该项，但其他进程可能会改变它。`const` 和 `volatile` 关键字总是修饰紧随其后的项（右侧）。`const` 和 `volatile` 限定符提供的信息旨在帮助编译器优化生成的代码。例如，假设变量 `block_size` 按以下方式声明和初始化：

```c
const int block_size = 512;
```

在这种情况下，编译器不需要生成从内存加载 `block_size` 值的代码。相反，它可以在程序使用 `block_size` 的任何地方直接使用该值 512。现在，假设你在声明中添加了 `volatile` 并将声明更改为：

```c
volatile const int block_size = 512;
```

此声明表示某个外部进程可以更改 `block_size` 的内容。因此，编译器不能优化掉对 `block_size` 的任何引用。当引用 I/O 端口或视频内存时，你可能需要使用此类声明，因为这些位置可能会受超出程序控制范围的因素影响而改变。

## 表达式

*表达式* 是变量、函数调用和运算符的组合，其结果是单个值。例如，下面是一个表达式，其值为存储 *以 null 结尾的字符串 str* 所需的字节数（即 *char* 数据类型的 *数组*，末尾带有一个零字节）：

```c
(strlen(str) * sizeof(char) + 1)
```

此表达式涉及函数调用——*strlen(str)*——以及 *乘法* (*)、*加法* (+) 和 *sizeof* 运算符。
