# # Introducing KMail

KMail is a mail reader for KDE. When you first run KMail, you get its main window (see Figure 1-7), but you cannot start using it to send and receive e-mail until you have configured the mail accounts in KMail.

To configure KMail, choose *Settings*:Configure KMail. In the Configure KMail window (see Figure 1-8), click **Accounts** on the left side of the window and set up the information about your e-mail accounts. KMail uses this information to send and receive mail.

For outgoing mail, click the **Add** button on the Sending tab (see Figure 1-8) and then select the mail transport agent. Typically, for an ISP-provided mail account, you should select **SMTP** and enter the mail server's name (for example, `smtp.comcast.net`) that your ISP provided you.
