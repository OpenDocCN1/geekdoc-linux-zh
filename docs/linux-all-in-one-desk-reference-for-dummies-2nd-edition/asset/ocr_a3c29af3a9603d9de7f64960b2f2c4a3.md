# File systems

Through this category of options, you can turn on support for specific types of file systems. You’d be amazed by the many different file systems that the Linux kernel can support. (Table 5-1 lists just some of them.) You typically build a kernel with support for the core Linux file systems (Ext2 and Ext3), CD-ROM file system (ISO 9660 and Joliet), and DOS/Windows file systems (MSDOS, FAT, and VFAT). For sharing files with Windows 2000/XP systems, you also build the module for CIFS.

| Apple Macintosh | The Macintosh HFS file system. (Linux can read and write Macintosh-<br>formatted floppy disks and hard drives.) | |

| Coda | An advanced network file system that is similar to NFS but that better<br>supports disconnected operation (for example, laptops) and is a better<br>security model | |
| Ext2 | The second extended file system — the current standard file system<br>for Linux | |
| Ext3 | Ext2 file system with support for journaling — a facility that allows quick<br>recovery of the disk after a crash | |
| FAT | Refers to any File Allocation Table (FAT)-based file system (including<br>MS-DOS and Windows 95 VFAT file systems) | |
| HPFS | The OS/2 HPFS file system. (Linux can only read HPFS files.) | |
| ISO 9660 | The standard ISO 9660 file system used on CD-ROMs. (This system is<br>also known as the High Sierra File System and is referred to as hfs<br>on some UNIX workstations.) | |
| Joliet | Microsoft’s Joliet extension for the ISO 9660 CD-ROM file system, which<br>allows for long filenames in Unicode format. (Unicode is the new 16-bit<br>character code that can encode the characters of almost all languages<br>of the world.) | |
| Minix | The Minix file system — the original file system of Linux | |
| MSDOS | The MS-DOS file system | |
| NFS | Network File System for sharing files and directories from other systems<br>on a network | |
| NTFS | NT file system (NTFS) — the file system used by Microsoft Windows NT<br>and XP. (Linux can only read NTFS disks.) | |
| /proc | A virtual file system through which you can get information about the<br>kernel. The /proc file system does not exist on the disk; files are cre-<br>ated when you access them. | |
