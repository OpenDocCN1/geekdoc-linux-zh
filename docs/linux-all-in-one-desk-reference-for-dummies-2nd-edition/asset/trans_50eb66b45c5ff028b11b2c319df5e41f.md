

最后，任何自由软件都持续受到软件专利的威胁。我们希望避免这样一种风险：自由软件的再分发者单独获得专利许可，从而实际上使该软件变为专有软件。为了防止这种情况，我们已明确声明，任何专利必须要么被许可供所有人免费使用，要么完全不予许可。

关于复制、分发和修改的精确条款和条件如下。

## 复制、分发和修改的条款与条件

- 0. 本许可证适用于包含版权所有者放置的通知，声明其可依据本通用公共许可证条款进行分发的任何程序或其他作品。下文中的“程序”指任何此类程序或作品，“基于程序的作品”是指根据版权法所述的程序或其任何衍生作品：也就是说，包含程序或其部分内容的作品，无论是逐字复制还是经过修改和/或翻译成其他语言。（在此后，翻译被视为包含在“修改”一词中，且不限定。）每位被许可人被称为“你”。

    除复制、分发和修改以外的其他活动不受本许可证覆盖；它们超出了本许可证的范围。运行程序的行动不受限制，且来自程序的输出仅在该内容构成基于程序的作品时（独立于是否通过运行程序生成）才受覆盖。这是否为真取决于程序所执行的功能。

- 1. 你可以以你收到的形式，复制和逐字分发程序的源代码，在任何介质中，前提是你必须在每份副本上显著且适当地发布适当的版权声明和保修免责声明；保持所有提及本许可证及无保修声明的通知完整；并且向其他任何程序接收者提供一份本许可证副本随同程序一起。

    你可以对传输副本的物理行为收取费用，并且你可以选择以收取费用为条件提供保修保护。

- 2. 你可以修改你持有的程序或其任何部分的副本，从而形成基于程序的作品，并根据上述第1节的条款复制和分发此类修改或作品，前提是你还满足以下所有条件：
    - a) 你必须使修改后的文件携带显著通知，说明你更改了文件及任何更改的日期。
    - b) 你必须使你分发或发布的任何在全部或部分包含或源自程序或其任何部分的作品，作为整体以免费方式根据本许可证条款许可给所有第三方。
    - c) 如果修改后的程序在正常交互式运行时读取命令，你必须使其在以最常规方式启动进行此类交互式使用时，打印或显示一份公告，包括适当的版权声明和无保修声明（或者说明你提供保修），以及用户可以在此条件下重新分发程序的说明，并告知用户如何查看本许可证的副本。（例外：如果程序本身是交互式的但通常不打印此类公告，则基于程序的作品不需要打印公告。）

    这些要求适用于修改后的作品整体。如果该作品中可识别的部分未源自程序，并且可以合理地被视为独立且本身分离的作品，那么当你作为单独作品分发这些部分时，本许可证及其条款不适用于这些部分。但是，当你将这些相同部分作为基于程序的作品的整体的一部分进行分发时，该整体的分发必须符合本许可证的条款，该条款对其它被许可人的许可扩展至整个整体，从而扩展至每个部分，无论谁编写。

    因此，本节的意图并非主张权利或挑战你完全由你编写的作品的权利；而是行使对基于程序的衍生作品或集合作品的分发进行控制的权力。

    此外，将未基于程序的另一作品与程序（或基于程序的作品）在存储或分发介质的同一卷上简单聚合，不会将该其他作品纳入本许可证的范围。

- 3. 你可以依据上述第1节和第2节的条款，以目标代码或可执行形式复制和分发程序（或在第2节下基于程序的作品），前提是你还执行以下行为之一：
    - a) 随附完整的、相应的机器可读源代码，这些代码必须依据上述第1节和第2节的条款，在通常用于软件交换的介质上进行分发；或者，
    - b) 随附一份为期至少三年的书面要约，向任何第三方提供以不超过你物理执行源分发的成本为费用的完整机器可读相应源代码副本，这些代码依据上述第1节和第2节的条款，在通常用于软件交换的介质上进行分发；或者，
    - c) 随附你收到的关于分发相应源代码要约的信息。（此替代方案仅允许非商业分发，且仅在你依据上述第2b节，以目标代码或可执行形式收到程序并附带此类要约时适用。）

    作品的源代码指该作品用于进行修改的首选形式。对于可执行作品，完整源代码指其包含的所有模块的所有源代码，加上任何相关的接口定义文件，加上用于控制可执行文件编译和安装的脚本。然而，作为特别例外，分发的源代码无需包含通常（以源或二进制形式）与操作系统的主要组件（编译器、内核等）一起分发的任何内容，除非该组件本身随可执行文件一起分发。

    如果通过提供访问指定位置进行复制来分发可执行文件或目标代码，那么提供从相同位置复制源代码的等效访问权也算作源代码的分发，即使第三方不被强制随目标代码一起复制源代码。

- 4. 除本许可证明确规定的情况外，你不得复制、修改、再许可或分发程序。任何否则试图复制、修改、再许可或分发程序的行为均无效，并将自动终止你在本许可证下的权利。然而，依据本许可证从你这里获得副本或权利的当事方，只要他们保持完全合规，其许可证就不会终止。

- 5. 你无需接受本许可证，因为你未签署它。然而，其他任何方式均未授予你修改或分发程序或其衍生作品的许可。如果你不接受本许可证，这些行为在法律上是被禁止的。因此，通过修改或分发程序（或任何基于程序的作品），你表明你接受本许可证以执行此操作，以及复制、分发或修改程序或基于程序的所有作品的条款和条件。

- 6. 每次你重新分发程序（或任何基于程序的作品）时，接收者自动从原始许可方获得根据这些条款和条件复制、分发或修改程序的许可证。你不得对接收者行使此处授予的权利施加任何进一步限制。你无需对第三方遵守本许可证负责。
