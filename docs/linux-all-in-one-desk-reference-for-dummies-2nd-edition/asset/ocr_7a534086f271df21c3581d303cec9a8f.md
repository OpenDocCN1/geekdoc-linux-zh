4. Set up the following options for sending e-mail and click Forward when you’re done:
    * Select the server type as SMTP.
    * Enter the name of the server, such as `smtp.comcast.net`.
    * If the server requires you to log in, select the Server Requires Authentication check box.
    * Enter your username — the same username you use to log in to your ISP’s mail server. (Often, you don’t have to log in to send mail; you only log in when receiving — downloading — mail messages.)

5. Indicate if you want this e-mail account to be your default account, and, if you want, give this e-mail account a descriptive name; click Forward.

6. Set your time zone by clicking a map; click Forward.

7. Click Apply to complete the Evolution setup.
