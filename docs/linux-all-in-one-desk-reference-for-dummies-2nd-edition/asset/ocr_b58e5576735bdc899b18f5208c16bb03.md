# Sniffing network packets

Sniffing network packets — sounds like something illegal, doesn’t it? Nothing like that. Sniffing simply refers to viewing the TCP/IP network data packets. The concept is to capture all the network packets so that you can examine them later.

If you feel like sniffing TCP/IP packets, you can use tcpdump, a command-line utility that comes with Linux. As its name implies, it dumps (prints) the headers of TCP/IP network packets.

To use tcpdump, log in as root and type the tcpdump command in a terminal window. Typically, you want to save the output in a file and examine that file later. Otherwise, tcpdump starts spewing out results that just flash by on the window. For example, to capture 1,000 packets in a file named tdot and attempt to convert the IP addresses to names, type the following command:

```
tcpdump -a -c 1000 > tdot
```

After capturing 1,000 packets, tcpdump quits. Then you can examine the output file, tdot. It’s a text file, so you can simply open it in a text editor or type more tdot to view the captured packets.
