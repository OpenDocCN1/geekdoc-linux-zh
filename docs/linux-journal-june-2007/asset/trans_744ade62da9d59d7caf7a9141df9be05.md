# GEMINI 2U – 超高密度系列

- 2U 机箱内的两个完全独立的系统
- 能力：在一台机箱内运行两个不同的操作系统
- 最多 16 个 CPU 核心
- 最多 12 个热插拔 SATA、SCSI 或 SAS 硬盘
- 两个系统均支持 RAID 0, 1, 5, 6, 10, 50

- 每个主板有一个可用的 PCI-X 或 PCI-E 插槽
- 高效 AC 和 DC 电源选项
