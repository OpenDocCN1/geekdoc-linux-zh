Figure 11.52 shows the available types that can be chosen from the selection list. The list contains all the objects types that are supported by the software. Selecting an object type and clicking the Select button will select all objects on the main topology panel that meet the criteria. In this case, only the node types will be highlighted. The Name..., Address..., and Label... options permit the user to input an expression string that is compared to all the objects within the topology view for that particular attribute. The remaining option, Attribute..., provides the user the ability to further define a selection criteria by using additional object definitions. One possible attribute, for instance, is the topology map to which an object belongs.
