The `ipRouteAge` object represents the number of seconds since this route was last updated or determined to be a correct route. The `ipRouteMask` object indicates the mask to be logically and (&) with the destination address before being compared to the value in the `ipRouteBest` object. The `ipRouteMetrics` object is an alternate routing metric for this route and, like the others, the value is -1 when not used. The final object, `ipRouteInfo`, is used as a reference to an MIB OID string that is specific to the particular routing protocol responsible for this route. If the information is not available, a valid object identifier of `00` should be used.
