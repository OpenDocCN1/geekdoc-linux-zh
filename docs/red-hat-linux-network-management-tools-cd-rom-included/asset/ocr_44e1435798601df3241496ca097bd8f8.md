The *Icon* menu options assign icons to object elements. A large collection of icons are available with tkined that include icons for UNIX systems, network devices like routers and switches, and network topology icons for Ethernet and other network topologies. There are some basic rules about the appropriate device types that can be assigned to certain icons. For example, you can’t assign a network element (such as FDDI) to a device icon that represents a Linux system.
