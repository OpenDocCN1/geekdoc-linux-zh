# Set Parameter

This option controls generic operational parameters for the discovery menu options. In practice, you won’t need to change the default values and can largely ignore this option.

# IP World Menu

The ip World menu provides a visual traceroute feature that when given a destination, will record the routing hops on a world map. Since this menu provides the same basic services as the traceroute command that was discussed in Chapter 5, “Additional System Utilities and Tools,” this option isn’t described here.
