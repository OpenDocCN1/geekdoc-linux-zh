| **SNMP Object** | **Object Information** |
| :--- | :--- |
| ifOutDiscards | Number of outbound packets that were chosen to be discarded even though no errors had been detected to prevent their being transmitted |
| ifOutErrors | Number of outbound packets that could not be transmitted because of errors |
| ifOutQLen | Length of the output packet queue (in packets) |

MR	extd	extag\ supports mathematical operations on the SNMP objects or OID strings. These operators could be used, for example, to group the total number of input errors and output errors for a collection of interfaces instead of just a single interface. Thus,

$$
\begin{array}{l}
\text{Target[monet] : ifInErrors.0:public@10.0.2.75+ifInErrors.1:public@10.0.2.75}\\
\&\text{ifOutErrors.0:public@10.0.2.75+ifOutErrors.1:public@10.0.2.75}
\end{array}
$$

computes the sum of interface errors for both the first and second interfaces found on the device 10.0.2.75.
