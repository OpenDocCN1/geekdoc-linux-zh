Also, because the master agent is responsible for delivering the SNMP to the appropriate subagent, it takes a certain amount of processing time and overhead. This might be a factor in time-critical management functions.

Several proposals and products have been put forth in an attempt to provide a standard mechanism that supports a master and subagent architecture. These include SMUX1(RFC1227), AgentX (RFC2257), and vendor-specific products like master agent on Solaris and the master agent on HP-UX. All of these accomplish the same purpose: permitting two or more agents to operate on the same system without port conflict problems.
