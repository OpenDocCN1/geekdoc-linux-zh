# UCD ProcTable

The procTable table consists of objects that obtain a list of system processes that are monitored by the agent and have been placed in the agent configuration file. Figure 7.3 shows a hierarchical representation of these objects as they relate to the ucDavis branch. The process information is accessed via the prEntry MIB object. The procTable table contains the following set of objects:

**Object Name:**  prIndex

**OID:**  prEntry.1

**Object Type:**  PrIndex (Integer)

**Access Mode:**  read-only
