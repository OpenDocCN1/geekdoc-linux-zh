# Address Translation Group

The `at` group consists of a single table that provides mapping from a network address to a physical address. Figure 6.4 shows a tree view of the address translation group. This group has been deprecated (which means that it was replaced by another group of MIB objects) but is provided for backward compatibility with the existing MIB-I standard. Many existing agents continue to support this group, including the Linux agent. Since this is the case, we have described the group here.
