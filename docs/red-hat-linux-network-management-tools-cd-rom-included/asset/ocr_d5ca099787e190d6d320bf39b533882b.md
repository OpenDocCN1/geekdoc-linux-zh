# ## Using RPM to Install Software Packages

You can install the following packages using the GNOME Red Hat Package Manager (RPM) installer:

+   - Ethereal
+   - MRTG
+   - nmap
+   - ntop
+   - xtraceroute

Many of the packages found on the CD-ROM are in the RPM package format. As a result, you can install these tools using the RPM installation tools found with Linux. Two different versions of the RPM are available on Linux, and either one can be used to install the software tool. The first, called *rpm*, is a command-line interface. The other, which provides a GUI interface, is called *gnorpm*.

The CD-ROM contains several RPM packages, and the procedure for installing each one is the same. Therefore, only a single package will be shown in the procedure that follows.
