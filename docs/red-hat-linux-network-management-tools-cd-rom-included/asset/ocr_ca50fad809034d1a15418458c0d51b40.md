# ## Installation Procedures and Software Notes

Use the following installation procedures to install the tools described in this book. Many of the packages have been made available on a CD-ROM that is located on the inside back cover. The software can also be obtained via the Internet. Because some of the tools may have been updated since the publication of this book, pointers to alternative sources (where applicable) have been provided. Additionally, some of the tools are also available in source code form; as a result, procedures for building these packages are included as well.
