If you encounter a problem during the installation, consult the Frequently Asked Questions (FAQ) file and additional documentation that comes with the package. The FAQ.txt file is located at the top level of the installation directory.

The UCD packet is available in the public domain; as such it must be retrieved and subsequently installed. It is provided either in source or binary form. The binary form is easiest to install because the package doesn’t need to be compiled. However, if you want to build the UCD from scratch, you will need a compiler and a little bit of patience.
