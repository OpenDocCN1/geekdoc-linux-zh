# Arpwatch Tool

**General Description**

The **arpwatch** command keeps track of and reports on changes observed in the datalink/IP addresses on the local network. It also tracks Datalink/IP address pairs, i.e., Ethernet to Internet Protocol (IP) addresses. Due to the significant growth of the number of systems attached to most networks, it has become paramount that a mechanism be available to record additions and device changes. When **arpwatch** notices a discrepancy, it logs the information to a file and sends electronic mail.

Table 5.1 lists the small number of command-line options that this tool supports.

One of the most useful options is the -i, which controls the interface that **arpwatch** will use when monitoring the network. By default, the lowest primary network interface on system startup is selected to be monitored by **arpwatch**. For a system with more than one interface, it may be `eth0`, for example.
