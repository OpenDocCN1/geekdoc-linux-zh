# Set Parameter

This option provides the same functions as the IP-Trouble menu option but contains an additional toggle switch that controls the creation of graph diagrams. By default, the value is *false*.

# Delete IP-Monitor

This option deletes the IP-Monitor menu. However, if monitoring jobs are active, selecting this menu option will display a dialog box informing the user that pending tasks are still operating. Deleting the menu means that any monitored jobs will be stopped. The user is given the choice of killing those tasks and exiting the menu or canceling the delete-menu task all together. Deleting the IP-Monitor menu automatically removes certain graphs, such as interface activity and disk activity, from the topology view.

# IP Layout Menu

The IP-Layout menu contains functions that control how a topology view will be organized. The options on this menu are good for handling situations where an IP discovery process was executed and a large number of network device elements have been created. This menu provides a way to automate how the devices are laid out and positioned on the view. Figure 11.39 shows the IP-Layout menu.
