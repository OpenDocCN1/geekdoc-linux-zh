为了帮助读者了解所有由 **gnome-Linuxconf** 配置工具提供的功能，表 10.1 和 10.2 列出了并描述了每个主要功能。

根类别 **配置** 包含多个用于配置网络服务器应用程序的子类别：

- **网络**
- **用户账户**
- **文件系统**
- **杂项服务**
- **启动模式**
