contains an MIB object called `dskEntry`, which is used to access each `diskTable` element.

The `diskTable` table contains the following set of objects:

+   1. **Object Name:** `dskIndex`
+      **OID:** `dskEntry.1`
+      **Object Type:** `DiskIndex (Integer)`
+      **Access Mode:** read-only
+      **Description:** Index into the `DiskTable` table for each file system that is being monitored by the agent

+   2. **Object Name:** `dskPath`
+      **OID:** `dskEntry.2`
+      **Object Type:** `DisplayString [255]`
