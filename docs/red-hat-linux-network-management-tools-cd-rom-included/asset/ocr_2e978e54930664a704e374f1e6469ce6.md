To access the printing options, click the Printing tab in the *ethereal* Preferences dialog box. Figure 5.13 shows the dialog box that will be displayed as a result.

The *ethereal* tool can print packets to either a printer or a regular UNIX file. The user can define a default printer and/or file to be used in subsequent sessions. In Figure 5.13, the UNIX *a2ps* command has been added to the *Command:* text box. This command converts ASCII data (regular text) to the Postscript language format for output to a Postscript-compatible printer. The command has a large number of options that can control the output, but by default it displays data in two side-by-side pages in landscape mode. This format, coupled with a smaller font size, means you can get a large amount of data within a relatively small number of pages. As shown in Figure 5.13, a default text file, *ethereal*\. *out*, has been defined. However, with the current version of the software, this file isn’t used when printing to a file.
