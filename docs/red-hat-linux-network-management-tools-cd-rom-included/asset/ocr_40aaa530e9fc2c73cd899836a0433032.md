# Table 5.5 \texttt{fping} \emph{display options list}

One of the especially useful features of \texttt{fping} is that, given a list of targets following the \emph{-a} option, it will display the systems that are reachable. For example, consider the following command:

```
# fping -a \texttt{vermeer monet rodin louvre} \texttt{monet} \texttt{roddin} \texttt{louvre}
```

The hosts \texttt{monet}, \texttt{roddin}, and \texttt{louvre} are displayed--indicating that they are alive--while \texttt{vermeer} was not displayed because it didn't respond.
