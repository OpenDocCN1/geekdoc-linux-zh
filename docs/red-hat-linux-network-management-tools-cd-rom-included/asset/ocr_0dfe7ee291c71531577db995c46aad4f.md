# Ping

This option implements the standard ping services to determine general network connectivity. Chapter 4, “Core System Utilities and Tools,” discusses this command. It displays a result window that shows the round-trip time for the ICMP (*ping*) response when the command is successful. If the task fails, a not *reachable* message is displayed instead.
