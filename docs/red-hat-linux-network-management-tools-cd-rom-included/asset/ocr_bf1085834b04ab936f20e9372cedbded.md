```
# arp -n -v
Address    Hwtype    HWAddress             Flags Mask    Iface
10.0.2.10   ether   00:60:97:0E:A3:06      C              eth0
10.0.2.60   ether   00:10:0d:A5:50:01      C              eth0
10.0.2.50   ether   00:c0:d4:00:09:40      C              eth0
10.0.2.127  ether   08:00:20:82:be:05      C              eth0
10.0.2.220  ether   (Incomplete)           C              eth0
10.0.2.126  ether   08:c0:20:04:cf:2c      C              eth0
Entries: 6 Skipped: 0      Found: 6
```

As you can see, the IP address of each host has been displayed instead of the actual hostnames.

As previously mentioned, the `arp` command displays the interface name for which the entry was obtained. Given the output above, all the mapping was from the `eth0` interface. Sometimes, a system may contain more than one interface. This is known as multi-homing. When the ARP cache is displayed on these systems, the output contains entries for each of the interfaces, as in the following example:

```
Address       Hwtype    HWAddress             Flags Mask    Iface
murer.home.com  ether   00:60:97:0E:A3:06      C             eth0
moster.home.com ether   00:60:97:0A:83:09      C             eth1
probe2.home.com ether   00:80:96:08:C1:01      C             eth0
switch.home.com ether   00:10:10:0A:50:01      C             eth0
probe.home.com  ether   00:C0:D4:00:09:40      C             eth0
```

We can see that mapping exists for two interfaces for this system. In this case, `eth0` and `eth1` are listed within the output. Since ARP tracks entries by interface, we can use the `-i` option to display just mappings from a particular interface. The following command, `,`,
`arp -i eth1`

will display all ARP listings for the `eth1` interface:

```
Address       Hwtype    HWAddress             Flags Mask    Iface
moster.home.com ether   00:60:97:0A:83:09      C             eth1
probe2.home.com ether   00:80:96:08:C1:01      C             eth1
```
