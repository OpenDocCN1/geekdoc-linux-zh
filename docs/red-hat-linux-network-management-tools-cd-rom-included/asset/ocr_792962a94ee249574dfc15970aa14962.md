Selecting the Done button displays the Edit Ethernet/Bus Interface window shown in Figure 10.16. This is the same window that is displayed when editing an existing interface. However, the system adds an alias number after the interface name, separated by a single colon character. In Figure 10.16, a zero has been added to the eth0 name. This is how the system specifies alias interfaces; in that case, the first alias to the Ethernet interface is named eth0:0. If another alias is created, it will be labeled eth0:1, the third eth0:2, and so on.
