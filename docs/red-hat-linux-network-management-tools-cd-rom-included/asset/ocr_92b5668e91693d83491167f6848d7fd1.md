# **Installing the Chesapeake Software**

The installation procedure for the subnet calculator includes the following steps:

+   1. Obtain the *tar* archive from the CD-ROM or at the Internet address listed in Table B.1. If you are getting the archive from the Internet site, you must do the following:

+   • Fill out the Registration form
+   
+   • Agree with the License Agreement
+   
+   • Download the *subcalc.tar.Z* file

If you are getting a package from the CD-ROM, copy the *tar* archive to a new directory:

```
```
cp /mnt/cdrom/ccci/subcalc.tar.Z <directory>
```
```

+   2. From the directory to which the *tar* archive was saved, run the following commands:

```
```
uncompress subcalc.tar.Z
tar xvf subcalc.tar
[lots of output]
```
```

+   3. Load the *subcalc.html* file in your favorite Web browser. This HTML file is located in the same directory as where the archive file was untarred.
