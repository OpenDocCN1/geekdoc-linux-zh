This display includes a running count of packet activity on the ethernet interface contained in the cisco-gw3. The command will continue displaying this output until a control+c (Ac) is typed. The first two columns represent the number of input packets and input errors, while the next two represent the number of output packets and output errors. The fifth column provides the number of collisions. The remaining five columns are cumulative totals for all interfaces defined within the device.

# Display Routing Information

```
# snmpstat -r cisco-gw3 public
```
