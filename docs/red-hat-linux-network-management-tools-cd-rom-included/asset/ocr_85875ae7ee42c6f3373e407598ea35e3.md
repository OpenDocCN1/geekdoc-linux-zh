The format of the personal database includes the IP address and hostname of the destination, followed by standard global coordinates. The interpretations of the coordinates included in the first entry are 30 degrees, zero minutes, zero seconds north of the equator or by 81 degrees, zero minutes, zero seconds in the western hemisphere. When each hop destination is added to this file, **xtracertoute** will display a much more accurate mapping between the source of the trace and the final destination.
