Each packet contains at least three sections. These include  
Frame, Ethernet II, and ARP. The *Frame* section represents the  
frame number, which indicates the count or position within the list  
of packets captured. This packet is the 60th frame read from the  
network. Also shown are the *Arrival Time* field, *Packet Length*  
field, and *Capture Length* field. Unless the sizes of frames were spe-  
cifically limited on the command line or using the capture dialog,  
the packet length and captured lengths should be equal.
