
## Overview of MIB-II

![](img/f265c9d1f2610aca197c430cbfcd51f5_298_0.png)

Each row of the at table provides a mapping between a network address and a physical address. Querying the at table against a Linux system displays output similar to the following:

```
at.atTable.atEntry.atIfIndex.1.1.10.0.2.50 = 1
at.atTable.atEntry.atIfIndex.1.1.10.0.2.127 = 1
at.atTable.atEntry.atPhysAddress.1.1.10.0.2.50 = Hex: 00 00 00 00 00 00
at.atTable.atEntry.atPhysAddress.1.1.10.0.2.127 = Hex: 00 C0 97 0E A3 06
at.atTable.atEntry.atNetAddress.1.1.10.0.2.127 = IpAddress: 10.0.2.127
at.atTable.atEntry.atNetAddress.1.1.10.0.2.50 = IpAddress: 10.0.2.50
at.atTable.atEntry.atNetAddress.1.1.10.0.2.127 = IpAddress: 10.0.2.127
```

The network address is typically the IP address assigned to the interface. The physical address represents the datalink network address that is appropriate for that interface. The table is indexed by the atIfIndex object, which contains a mapping for the atIfIndex object contained in the interface group. The network address object also indexes the at table. For instance, atIfIndex.1.1.10.0.2.50 is used as a pointer to the atPhysAddress and atNetAddress objects associated with that IP address. Note that the OID string contains the actual IP address of the interface and serves as an index key. The atPhysAddress object contains the physical address for the datalink protocol for that interface type. The example shows a valid Ethernet address in hexadecimal. The atNetAddress object contains the valid IP address for the interface expressed in normal dotted decimal notation.

The at table will change in size in concert with the ARP cache. Depending on network traffic, the ARP table will grow and shrink. The arp command can list the ARP table on a UNIX system. Chapter 4, "Core System Utilities and Tools," fully explains this utility. Also, since the at table represents ARP entries, this table lists incomplete mappings as well. You can see this by examining the atPhysAddress.1.1.10.0.2.10 = Hex: 00 00 00 00 00 00 listing. Notice that the hexadecimal value is all zeros, which implies that no mapping was obtained for this IP address.

### at Table Objects

The at table contains the following objects:

| Object Name | OID | Object Type | Access Mode | Description |
|-------------|-----|-------------|-------------|-------------|
| atTable (Deprecated) | mib-2.at | Sequence of AtEntry | read-only | A mapping between network addresses and physical (datalink) addresses |
| ifEntry (Deprecated) | mib-2.at | Sequence | read-only | A specific mapping that contains all the remaining objects listed below |
| atIfIndex (Deprecated) | mib-2.at | Integer | read-write | References to each specific mapping |
| atPhysAddress (Deprecated) | ifEntry.22 | PhysAddress | read-write | A media-dependent physical address (which is a valid IP address) |
| atNetAddress (Deprecated) | ifEntry.22 | NetworkAddress | read-write | The IP address of the associated media-dependent physical address |

## Internet Protocol Group

The `ip` group contains network counters that measure the flow of IP traffic in and out of the system. The group also contains additional tables that provide network layer routing and datalink mapping information. Figure 6.5 shows the `ip` group in the tree view format.

![](img/f265c9d1f2610aca197c430cbfcd51f5_301_0.png)

**Figure 6.5 The ip group view.**

The `ip` group contains the following set of objects:

### IP Group Objects

| Object Name | OID | Object Type | Access Mode | Description |
|-------------|-----|-------------|-------------|-------------|
| ipForwarding | ip.1 | Integer | read-write | Indicates whether the system is acting as an IP gateway (router) or just as a regular host providing no forwarding services. The valid values are Forwarding(1) and NotForwarding(2) |
| ipDefaultTTL | ip.2 | Integer | read-write | The time-to-live (TTL) value that is placed into the TTL field within an IP packet |
| ipInReceives | ip.3 | Counter | read-only | The total number of input packets received from all interfaces operating within the system |
| ipInHdrErrors | ip.4 | Counter | read-only | The number of input packets that were discarded as a result of an error within the IP header |
| ipInAddrErrors | ip.5 | Counter | read-only | The number of input packets that were discarded because the final IP destination address was invalid for this system |
| ipInFwdDatagrams | ip.6 | Counter | read-only | The number of packets that the local system attempted to forward when acting as a gateway or router |
| ipInUnknownProtos | ip.7 | NetworkAddress | read-write | The number of packets that were received from the network successfully discarded because the network layer protocol was unsupported or unknown to the system |
| ipInDiscards | ip.8 | Counter | read-only | The number of input packets that were discarded due to lack of buffer space or another condition unrelated to the packet itself |
| ipInDelivers | ip.9 | Counter | read-only | The number of input packets that were delivered to higher-level protocols successfully |
| ipOutRequests | ip.10 | Counter | read-only | The number of IP packets that higher-level protocols delivered to the IP protocol for transmission |
| ipOutDiscards | ip.11 | Counter | read-only | The number of output packets that were discarded due to lack of buffer space or another condition not relating to the packet itself |
| ipOutNoRoutes | ip.12 | Counter | read-only | The number of packets that were discarded because no route to the required destination network was known |
| ipReasmTimeout | ip.13 | Counter | read-only | The interval in seconds that input IP fragment packets are held for before they are reassembled |
| ipReasmReqs | ip.14 | Counter | read-only | The number of IP fragment packets received that must be reassembled |
| ipReasmOKs | ip.15 | Counter | read-only | The number of IP fragment packets that were successfully reassembled |
| ipReasmFails | ip.16 | Counter | read-only | The number of reassembly failures that were detected |
| ipFragOK | ip.17 | Counter | read-only | The number of packets that have been fragmented successfully |
| ipFragFails | ip.18 | Counter | read-only | The number of packets that were not fragmented because the don't-fragment flag contained within the IP header was set |
| ipFragCreates | ip.19 | Counter | read-only | The number of IP packet fragments generated on this system |
| ipAddrTable | ip.20 | Sequence of IpAddrEntry | not-accessible | A table of addressing information that is related to the system's IP addresses |
| ipRouteTable | ip.21 | Sequence of IpRouteEntry | not-accessible | A route to a particular destination |
| ipNetToMediaTable | ip.22 | Sequence of IpNetToMediaEntry |  |  |
