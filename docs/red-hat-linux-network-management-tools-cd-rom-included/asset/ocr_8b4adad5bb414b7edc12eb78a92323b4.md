The time between graph polls menu option controls the amount of time that will elapse for each retrieval of MIB objects used within a graph. By default it is five seconds. The port number submenu item defines the TCP port used when querying the SNMP target agent. The default is the standard port of 161. To change the default, select the port number item and, when the new dialog box is displayed (shown in Figure 8.9), enter the desired port and click the Ok button.
