# IP Report

This report uses the same format as the IP Protocols reports, but further defines the TCP/IP protocols that were recorded to include higher-level application functions such as file transfer, remote access, and Web access. Figure 9.10 shows this report.

The columns include total data received by protocols such as FTP, Telnet, HTTP, and others. Although this report contains only a small number of hosts, from a network performance standpoint it provides some very useful information. We can surmise that the FTP protocol is used more than any other protocol listed. This was determined by comparing the total FTP traffic with all other protocols.
