**Object Type:**  Counter

The dot3Col1Table table contains a record of the collision activity observed on the network between the agent and the network medium. It stores a histogram for a set of interfaces defined on the system. The dot3Col1Count object contains a single histogram point for each interface. The dot3Col1Frequencies object stores the number of transmitted frames that experience exactly the number of collisions in the associated dot3Col1Count object.
