The standard attributes associated with all node objects include Name, Address, and SNMP::Config. The Name represents the official hostname of the object, and the Address is the IP address of the object. The SNMP::Config property contains the command-line options that are used when specific SNMP operations are performed on the object. Additional user attributes may be defined.
