# # Snmget Tool

The **snmget** command retrieves information from an SNMP agent entity. It uses the SNMP get-request with one or more MIB object names as arguments and returns their associated values. If an error occurs, a descriptive message is shown to help pinpoint the problem. If a list of objects is specified on the command line, only those objects that are contained within the agent's MIB will be returned.

The command syntax is as follows:

```
``` 
 snmget [<common arguments>] MIB-object [MIB-object]
```
```

To retrieve the MIB objects sysDescr and sysContact from a Cisco router, the following command could be used:

```
``` 
 # snmget remote-gw public system.sysDescr.0 system.sysUpTime,0
```
```

Depending on the router model and configuration, this command would display output like the following:

