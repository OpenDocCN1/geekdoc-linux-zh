As you can see, the length field is displayed next to the protocol, or if no protocol is shown, after the destination address. It shows the total size of the frame in bytes. The reason the packets from socrates to durer are greater than 1500 bytes is because FTP fills the packet with as much data as it can hold. Ethernet has a data capacity of approximately 1500 bytes, not including the header portion of the frame.
