# ## Monitoring Additional Information

MRTG can be used to monitor other information—including additional SNMP objects and non-SNMP information—using the **target** command. The **target** command accepts additional input formats which can be used to monitor and graph information. These formats include direct OID strings, SNMP-abbreviated objects, and custom commands. The direct OID format uses Object Identifier (OID) strings, expressed in fully qualified dotted decimal notation, that specify which object should be monitored by MRTG. **Fully qualified** indicates that the entire path from the root to the object has been supplied.
