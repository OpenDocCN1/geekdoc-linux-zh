# New Station

This message is used when a new system is seen on the network for the first time. The **arpwatch** software will Email the *root* account on the local system with a message like the one below:

```
From root Mon Dec 27 13:05:09 1999
Date: Mon, 27 Dec 1999 13:05:09 -0400
From: arpwatch@socrates.home.com (Arpwatch)
To: root@socrates.home.com
Subject: new station
```
