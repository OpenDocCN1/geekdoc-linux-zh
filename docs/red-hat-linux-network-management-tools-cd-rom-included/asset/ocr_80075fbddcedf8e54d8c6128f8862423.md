The `system` group contains the following set of objects:

+   *   **Object Name:** sysDescr
+   *   **OID:** system.1
+   *   **Object Type:** `Display String [255]`
+   *   **Access Mode:** read-only
+   *   **Description:** A description of the device or entity, such as the type of device, hardware characteristics, operating system information, etc.

+   *   **Object Name:** `sysObjectID`
+   *   **OID:** system.2
+   *   **Object Type:** `Object Identifier`
+   *   **Access Mode:** read-only
+   *   **Description:** The authoritative identification of the vendor of the device

+   *   **Object Name:** `sysUpTime`
+   *   **OID:** system.3
+   *   **Object Type:** `TimeTick`
+   *   **Access Mode:** read-only
+   *   **Description:** The amount of time since the network management portion of the system (agent) was last reinitialized

+   *   **Object Name:** `sysContact`
+   *   **OID:** system.4
+   *   **Object Type:** `Display String [255]`
+   *   **Access Mode:** read-write
