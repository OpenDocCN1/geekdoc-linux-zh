# **Table 5.8** Additional nmap options

| Option | Description |
|---|---|

Since nmap supports a large number of command-line arguments and options, use the -h option to list a synopsis:

```
# nmap -h
nmap V. 2.12 usage: nmap [Scan type(s)] [Options] <host or net #1 ...[#N]>
Scan types
-SI tcp connect() port scan
-SS tcp SYN stealth port scan (must be root)
```
