```
DEVICE=eth1

NETWORK=10.0.2.0
BROADCAST=10.0.2.255
ONBOOT=yes
BOOTPROTO=none
USERCTL=no
```

As you can see from the output, the file contains a list of names followed by an equal sign, plus an associated value. The major reason for including this information is so that if you have to, you will be able to make a quick change to the script without the aid of the control panel GUI. When an interface has been modified, this file is simply updated with the new information; when an interface is deleted, the file is removed.
