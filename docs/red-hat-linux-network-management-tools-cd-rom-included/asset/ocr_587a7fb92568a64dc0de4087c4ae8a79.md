Notice also that not only was the IP address information displayed, but the port numbers were displayed as well. Normally `netstat` will examine the `/etc/services` file to determine mappings between port names and numbers and will show port names. The `-t` option suppressed these mappings for ports. Another useful option is the `-c` option, which toggles continuous displays of information. If we wanted to constantly monitor the information displayed in the previous example, we would use the following command:


# netstat -c -t
