**ntop** displays which interface it is using when more than one is installed on the system, and it confirms the specified port used for incoming connections by browser clients. Also, it warns that it was unable to read the security file and, as a result, no security will be used. In this case, any client browser can connect to **ntop** and view the reports. Securing the reports will be covered later.

With Web mode, the main page is divided into two separate frames, as shown in Figure 9.8.
