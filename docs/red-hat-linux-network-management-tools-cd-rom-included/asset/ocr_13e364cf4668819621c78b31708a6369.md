Recall that the **dfmaker** program assigns the *MaxBytes* value, and the reason this value was chosen is because the interface is of type Ethernet. Having the value for bytes per second handy is important. Therefore, Table 9.1 lists the most common networking interface types. This information has been included here because MRTG doesn’t include the maximum bytes per second for the graphs; this is to ensure that they are readable when small traffic loads are graphed.

MRTG also uses the *MaxBytes* value to detect invalid responses when polling devices for interface traffic statistics.

The **Title** keyword labels the report page and usually includes some information regarding the particular interface that is being monitored. The example

```
Title[10.0.2.75.1]: remote-gw (No hostname defined for IP\n address): Ethernet0
```

defines the title that is associated with the system 10.0.2.75. It contains the hostname, plus the interface (i.e., *Ethernet0* ).
