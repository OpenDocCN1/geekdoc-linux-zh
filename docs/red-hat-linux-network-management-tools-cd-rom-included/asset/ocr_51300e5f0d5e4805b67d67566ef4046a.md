One additional note about this report: Each of the intersecting cells between the same systems is blank and contains no values. This is the result of **ntop** monitoring a specific network interface that usually never sees traffic from itself. When a UNIX network process wants to communicate within a system, it may choose to use the loopback interface. As a result, when **ntop** is monitoring real interfaces, it never sees this traffic. If you are interested in monitoring activity on the internal network (i.e., loopback), use the `-i` option to change the default interface when **ntop** is invoked. You may be some-what surprised by the fact that only a small number of hosts (the loopback address and primary interface address) will be listed in the reports when capturing traffic from the internal network.
