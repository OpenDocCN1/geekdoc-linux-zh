# **Sun Agent Package Information**

The Sun agents started shipping standard with Solaris 2.6. The\nbinary package is available for both SPARC and Intel; therefore, it\ncan only be installed on Solaris systems on either of these plat-\nforms. The standard Solaris 2.6 and 2.7 CD-ROMS contain the\npackages for the Sun Enterprise agents. The agents are also avail-\nable and can be downloaded via the Sun Web site if you don't have\naccess to the Sun Solaris CD-ROM. The agents can be installed on\nSolaris 2.4 and 2.5 versions. Because previous releases didn't\ninclude the agent, installation of these versions of Solaris will\nrequire the pkgadd system utility.
