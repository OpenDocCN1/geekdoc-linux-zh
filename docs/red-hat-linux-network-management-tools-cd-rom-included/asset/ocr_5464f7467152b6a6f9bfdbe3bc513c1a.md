Because more than one network path to Node C exists, it is possible that some TCP segments might travel via router R2 instead of router R1. Should the path between Node C and R1 become temporarily heavily loaded, for example, segments may be routed via the alternate path. As a result, segments using the R2 path could arrive at the destination sooner than segments using the R1 path.
