## 运行原生 Pen Drive 安装

USB 安装有两种基本设置：USB-ZIP 和 USB-HDD。根据你计算机的 BIOS 设置，其中一种安装可能比另一种更有效。不幸的是，目前似乎还没有 USB 启动的标准。然而，看起来最终 USB-HDD 将成为标准。许多系统会启动一种设置但拒绝另一种。如果你有一台较旧的计算机（即 2001 年之前），很可能 BIOS 根本无法通过 USB 启动。此外，许多系统只是不一致。例如，一些计算机要求你在 BIOS 中关闭快速启动，而另一些则要求打开 USB 键盘仿真；其他系统只会从计算机后部的 USB 端口启动。还有笔式驱动器不兼容的问题。一些支持 USB 2.0 标准的新计算机将无法与仅适用于 USB 1.1 标准的旧笔式驱动器一起使用，而仅支持 USB 1.1 标准的旧计算机与 2.0 USB 笔不兼容。正如你所见，从 USB 启动可能很棘手！如果发现你的系统和硬件无法支持原生 USB 启动，你仍然可以选择使用启动软盘，我们将在本章后面讨论。

需要指出的是，在本讨论中，所有技术参考都是在 Damn Small Linux 操作系统内部进行的。也就是说，我们假设你在确定格式化或运行安装脚本的设备位置时正在运行 Damn Small Linux——并非所有 Linux 系统都以相同的方式注册设备。

### USB 启动类型——两种 USB 布局类型的背景

本节概述了 USB 笔式驱动器预安装格式化、两种类型 USB 安装的过程，以及为什么有必要提供两种类型安装的一些历史。还有一些关于如何在没有 USB 兼容 BIOS 系统的旧计算机上安装 DSL 到笔式驱动器并运行的类型。

### USB-ZIP

这是与 Iomega 外部 Zip 驱动器一起使用的格式。当我们设置 USB 笔式驱动器通过 USB-ZIP 启动时，我们是在模拟旧 Iomega 驱动器的布局；实际上，我们是在欺骗 BIOS 让它认为正在启动旧 Zip 驱动器。我们通过将 USB 笔分成两个分区并保持第一个分区大小较小来实现这一点。分区的几何结构需要有 64 个磁头和 32 个扇区。如果你不知道这意味着什么，不用担心——我们的安装脚本会自动进行计算。

### USB-HDD

相比之下，我们的 USB-HDD 格式使用单个 fat 分区。这是一个更简单的设置，与只能识别笔式驱动器上第一个分区的其他操作系统更兼容。

你选择的方法取决于你的硬件支持情况。如果你要制作一个用于便携使用的可启动笔式驱动器，请选择 USB-HDD，因为它的硬件兼容性大于 USB-ZIP。此外，如果你的笔式驱动器同时用作便携存储设备，你的 Windows 操作系统将能够看到存储设备的完整大小。

### 确定你的 USB 驱动器的物理地址

在 Damn Small Linux 中运行，大多数系统上的大多数 USB 驱动器将被标记为 sd(某物)，例如 sda、sdb、sdc 等等。如果你系统中有多个笔式驱动器，第一个驱动器将被标记为 sda，第二个驱动器将被标记为 sdb。第一个笔式驱动器上的第一个分区将称为 sda1，第二个笔式驱动器上的第三个分区将称为 sdb3，等等。这在 99% 的情况下都是正确的，但为了避免混淆，在运行安装脚本时，只保留一个 USB 设备在你的计算机中。
