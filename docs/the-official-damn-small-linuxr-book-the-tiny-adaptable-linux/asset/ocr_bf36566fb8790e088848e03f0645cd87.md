# The UNC Extension Type

UNC Extensions are mountable using the unionfs file system. The main advantage of using this method is the very low RAM use. If only unc and uci extensions are used, you would use very little RAM. Compressed mounts save RAM, as only the runtime is loaded into memory very similar to the RAM usage of a traditional hard drive. Unionfs, as implemented in DSL, makes the same area of the file system write-enabled, as does the ds1 extension type.

It is trivial to create a unc extension from an existing ds1 extension. The base DSL system contains a tool to convert any ds1 into a unc. Open a root xterm and run the script:

```
```bash
$ ds1?unc.sh zile.ds1
```
```

It is preferred to make the unc extension this way as much of the work is automated.
