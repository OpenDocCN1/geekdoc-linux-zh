# Recording Your ISO Later Using CDW

There will be times when you want to record the myds1.iso later. After creating the image file, be sure that it is copied to a persistent storage area (such as a hard disk partition). You can always reboot DSL with the toram option, without adding any extra software, so you have enough resources to record the image.

DSL provides a general CD-ROM recording utility program called CDW. To access this program, select from the main menu Apps, Tools, CD Burn App. Figure 11-6 shows the CDW screen.
