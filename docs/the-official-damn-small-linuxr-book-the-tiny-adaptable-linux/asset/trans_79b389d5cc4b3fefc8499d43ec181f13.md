

在Qemu中运行时使用。设置完成后，它将是运行DSL-Embedded时访问备份文件和扩展的最简单方式。

大多数对创建虚拟硬盘感兴趣的人都是从U盘运行DSL-Embedded的。本节其余部分将以U盘作为物理参照点以保持一致性，但有些人可能希望将此设置放在个人电脑的普通硬盘上。步骤与下列相同；只需将任何对U盘的引用替换为你自己的本地路径即可。

要创建Qemu虚拟硬盘，你必须使用dsl-embedded.zip文件中包含的qemu-img.exe程序。解压后，该程序位于MS Windows识别的Qemu目录或文件夹中。以下步骤描述了如何为DSL创建虚拟硬盘：

- 1. 打开一个DOS窗口，并导航到U盘内的qemu文件夹。在MS DOS中，导航命令是CD。如果你的U盘被Microsoft Windows识别为E盘，你应该输入以下内容：

   ```
   CD E:\qemu\
   ```

- 2. 使用qemu-img.exe程序创建一个虚拟硬盘。该硬盘将在你的U盘上有一个物理存在；你会看到它以hddisk的形式出现。（这个虚拟硬盘稍后在选择dsl-vhd.bat文件启动dsl-embedded时使用。）导航到你的Qemu文件夹后，你需要使用qemu-img.exe来创建你的虚拟硬盘。你选择的大小受U盘可用空间的限制，并且由你自行决定最适合你需求的大小。

> **注意**
> 
> 请记住，这个硬盘是*虚拟*的，因为它不是真正的驱动器（而是U盘上的一个文件）。虚拟硬盘实际上是*真实*的，因为它占用了U盘上真实的空间，而这些空间你不能用于存储与DSL无关的文件。

与qemu-img.exe一起使用的命令是

```
E:\qemu> qemu-img.exe create hddisk SIZE
```

其中SIZE是你希望虚拟硬盘拥有的实际大小。对于一个64MB的虚拟硬盘，输入

```
E:\qemu> qemu-img.exe create hddisk 64M
```

对于一个500MB的虚拟硬盘，输入

```
E:\qemu> qemu-img.exe create hddisk 500M
```

如果由于某些奇怪的原因，你无法导航到U盘上的qemu目录，你可以在命令中使用完整路径：

```
C:\> E:\qemu\qemu-img.exe create E:\qemu\hddisk 64M
```

重要的是要记住，虚拟硬盘实际上需要命名为hddisk，因为这是它在dsl-vhd.bat文件中的引用方式。创建hddisk镜像后，继续关闭你的DOS窗口。

- 3. 运行以下命令，该命令在第二级别（命令行提示符）启动DSL，以执行一些步骤来格式化你的虚拟硬盘（以便DSL-Embedded开始使用它进行文件恢复）：

```
E:\qemu> 1st-boot.bat
```

在启动阶段你可能会看到一些错误，因为虚拟硬盘尚未正确格式化。

- 4. 启动过程完成后，将虚拟硬盘格式化为Linux原生ext2文件系统。在Linux shell命令提示符下，输入

```
# mke2fs /dev/hdb

mke2fs warning:
Warning: /dev/hdb is entire device, not just one partition!
Proceed anyway? (y/n) y
```

你会收到一个警告，因为你告诉mke2fs格式化整个虚拟驱动器，而不仅仅是单个分区。

- 5. 输入y并按下Enter键。

mke2fs运行后，你挂载驱动器并将cloop模块复制到访问点。Damn Small Linux会自动探测查找模块。

- 6. 挂载新的虚拟驱动器：

```
# mount /mnt/hdb
```

- 7. 创建mydsl和mydsl/modules目录：

```
# mkdir /mnt/hdb/mydsl
# mkdir /mnt/hdb/mydsl/modules
```

- 8. 复制cloop模块：

```
# cp /KNOPPIX/7/lib/modules/2.4.26/kernel/drivers/block/cloop.o \
/mnt/hdb/mydsl/modules/
```

- 9. 输入以下命令关闭DSL：

```
# shutdown -h now
```

你自己的驱动器现在就可以开始使用dsl-vhd.bat了！运行dsl-vhd.bat时，备份和恢复应自动使用/mnt/hdb，你的mydsl扩展将在/mnt/hdb/mydsl/下访问。

> **注意**
> 
> 当你第一次正常运行dsl-vhd.bat时，X设置脚本会运行并询问你偏好的分辨率设置。如果你只想使用默认值，请按Tab键高亮“取消”按钮，然后按Enter键退出脚本。

如果你想保存你的扩展，挂载/mnt/hdb并将你的扩展下载到/mnt/hdb/mydsl。

屏幕右下角的挂载工具无法识别你的虚拟硬盘。要挂载它，请打开一个终端窗口并输入以下内容：

```
# sudo mount /mnt/hdb
```

## 从虚拟环境中访问本地文件

Qemu的一个新功能是在虚拟机中启动时能够访问你的本地文件。pendrive.bat文件设计用于既可进行原生BIOS启动又可经由Qemu进入虚拟环境的U盘。

Qemu允许对你的文件进行读取访问，因此你可以加载你的默认设置，并访问你的扩展和个人文档。但是，通常你无法从虚拟环境中保存它们。

然而，使用SMBClient，我们可以通过Windows网络共享访问获得写入权限。

以下是dsl-embedded.zip归档中readme文件里的步骤：

- 1. 在Windows中，“共享”你的U盘。
- 2. 在Windows中，记下你机器的IP地址。为此，打开一个DOS窗口（命令提示符）并输入ipconfig。
