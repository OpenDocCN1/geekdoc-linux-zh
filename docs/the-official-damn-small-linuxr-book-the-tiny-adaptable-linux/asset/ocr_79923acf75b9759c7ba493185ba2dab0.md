# Rdesktop—A Remote Desktop Protocol Client

Rdesktop is a client for the Windows Terminal Server. Rdesktop communicates via Remote Desktop Protocol (RDP). The original author is Matthew Chapman, who had to do a lot of reverse engineering and reference obscure documentation to get it to work.

Refer to the Rdesktop home page for further information: www.rdesktop.org.
