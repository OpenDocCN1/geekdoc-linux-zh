# USB-ZIP Installation

After running cfdisk to format your pen drive, it is time to run the install script. To access the script, open the Fluxbox menu and navigate to Apps -> Tools -> Install to USB Pen Drive and click For USB-ZIP Pen Drive. This opens up a term window with a dialog, or if you are running from the install boot option, type 6, and then press Enter. Be sure to read the text because it has important instructions and warnings.

After the script is launched, you will be presented with an introductory dialog, as shown in Figure 6-7.
