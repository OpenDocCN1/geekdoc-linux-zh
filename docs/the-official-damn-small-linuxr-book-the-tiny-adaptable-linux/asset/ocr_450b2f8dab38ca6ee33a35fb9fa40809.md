Downloading with the Extension tool also means the program will be automatically installed. This is the preferred way to install extensions, as you are not merely downloading them for later use. When the extension is successfully downloaded, the Extension tool installs and sets up the chosen application, menu, and usually a desktop icon. The Extension tool also checksums the downloaded extension to ensure a good download. If the download is corrupt, a pop-up message informs you so you may try again.
