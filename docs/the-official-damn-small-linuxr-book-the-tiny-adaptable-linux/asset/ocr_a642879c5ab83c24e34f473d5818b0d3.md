You are now almost ready to begin printing from any of the DSL applications. Remember when you had to name your printer? How can you specify the printer to each application? The easiest way is to use an environment variable. You can open terminal window and type export PRINTER=the_name_we_gave_our_printer. Doing this eliminates having to specify the printer name in each invocation of printing from each application. You have set up the system default printer.

Now that you have your printer set up and working, how do you back up the printer specifications? Upon a normal shutdown, the system detects that a printer setup was attempted. You are prompted to save your printer setup. If you confirm, the saving is automatic. Upon reboot, the only necessary step is to start the printing daemon from the DSL control panel.
