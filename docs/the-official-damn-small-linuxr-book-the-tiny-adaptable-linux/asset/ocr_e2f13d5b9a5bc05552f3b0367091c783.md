# USING SKYPE

After you have a user account, you can start using Skype. If the Skype window is not already open, open it by clicking the Skype icon on the DSL desktop. When prompted, log in using the Skype login and password you created. The Skype window appears, as shown in Figure 14-3.

Here are a few things you should learn about the Skype window:

+   - **Toolbar**—The default toolbar lets you add a contact (plus icon), search for Skype users (magnifying glass icon), start a conference call (people icon), send an instant message (A in a bubble icon), send a file (page with up-arrow icon), or view profile (i in a circle icon). Select Configure (tools icon to the right) to change which icons appear on the toolbar.

+   - **Contacts**—Shows the contacts you have added to your list. Contacts can be added to groups or kept as ungrouped. An icon next to each contact name shows whether the contact is currently connected to the Skype service. Right-click any contact name to see a list of actions to take on that contact (telephone call, instant message, view profile, and so on).
