+   6. Reboot the notebook, and then choose to boot Linux or the other operating system.

Configuring your hard drive to support multiple operating systems can be tricky, but you can also try some tricks of your own, such as sharing a single swap space between two different operating systems. Here’s a short list of mini-HOWTO documents you’ll want to read before you begin configuring your notebook:

+   * **Linux+DOS+Win95+OS2**. Details how to partition, install, and boot four operating systems.
+   * **Linux+FreeBSD**. Shows how to use Linux and FreeBSD.
+   * **Linux+Win95**. Details hard drive strategies and booting.
+   * **Linux+NT-Loader**. Details how to boot Linux using NT’s loader.

Finally, you should know that you can also install different Linux distributions on your notebook and then boot to SuSE Linux or Red Hat, Mandrake, Corel, Caldera, or TurboLinux!

# What Is Partitioning?

This section discusses how to split your hard drive into separate volumes, or *partitions*. Making room on your notebook’s hard drive for other operating systems, known as *partitioning*, can be somewhat confusing, especially if you’ve never attempted this process. Partitioning is an essential step in a traditional Linux installation. However, as you’ve learned in previous chapters, there are ways to run Linux on your notebook without partitioning (such as using WinLinux2000, which creates a virtual disk on your Windows-formatted hard drive).

# Filesystem Versus File System

The Linux kernel and associated software usually reside on parts of your hard drive formatted for the native Linux ext2 *filesystem*. This underlying format details how files and directory information are linked and provided to the Linux kernel. However, you should know that Linux can recognize many different types of filesystems, such as FAT (used for DOS), VFAT (used for Windows), ISO9660 (used for CD-ROMs), HFS (used on older Mac systems), and others. The organization of directories, such as /, /home, /bin, /usr/bin, /usr/X11R6/bin, /tmp, and so on, is known as the *Linux file system*. Understanding the difference between a filesystem and the Linux file system is an important step in understanding how to use Linux.
