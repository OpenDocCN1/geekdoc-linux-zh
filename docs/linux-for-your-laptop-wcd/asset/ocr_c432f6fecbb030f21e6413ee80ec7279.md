# Your Notebook's CD-ROM

Most notebooks, including the iBook, use an *AT Attachment Packet Interface* (ATAPI) CD-ROM drive. Most of these CD drives work quite well with Linux (although I am aware of one incompatibility issue that was quickly resolved with a kernel recompile). Your main concern when buying a notebook is that you can set your laptop's *basic input/output system* (BIOS) to change the boot order of any internal storage devices, such as the floppy, hard drive, and CD-ROM. Fortunately, most notebooks support this. However, in the case of one line of Sony notebooks with an external CD drive, you could indeed set the laptop's BIOS to boot from CD-ROM, but this would work only with Sony's drive—a nasty maneuver!

Although CD-ROM writer and CD-ROM rewritable drives are available for desktop computers, at the time this chapter was written, only one notebook manufacturer (Dell) offered this option in a laptop. You'll find a drive compatibility chart at

http://www.gug.de:8080/cgi-bin/winni/lsc.pl

For a helpful HOWTO on how to burn CDs using Linux software and CD-ROM writer or rewritable drives, browse to

http://www.gug.de/~winni/linux/cdr/html/

Your notebook's CD-ROM drive should be automatically recognized when you boot Linux, even if a CD is not inserted. Look for output similar to this:

```
hda: TOSHIBA DVD-ROM DRD-0624, ATAPI CDROM drive
```

This output shows that Linux has detected a DVD CD-ROM attached to /dev/hdc. Using this information, you can easily mount the CD with this:

```
# mount -t iso9660 /dev/hdc /mnt/cdrom
```

Note that most storage devices, fixed and removable, usually have entries in the file /etc/fstab, your system's filesystem table. This file is created when you install Linux, and it makes it even easier to mount devices such as CD-ROMs. Using the preceding example, the /etc/fstab entry might look like this:

```
/dev/cdrom /mnt/cdrom iso9660 user,noauto,nosuid,exec,ro 0 0
```

In this entry, /dev/cdrom is a symbolic link to the /dev/hdc device, and the mount point is defined as /mnt/cdrom. This means that you can insert a CD-ROM into the drive and then use this:

```
# mount /mnt/cdrom
```

The contents of the CD-ROM will appear under the /mnt/cdrom directory.
