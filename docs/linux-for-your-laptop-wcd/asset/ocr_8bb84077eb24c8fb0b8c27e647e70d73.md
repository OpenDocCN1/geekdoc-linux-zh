+   * RTC stores time in GMT (CONFIG_APM_RTC_IS_GMT). If you use Greenwich Mean Time in your notebook's hardware date clock, answer Y. Otherwise, use N. Although many notebook users do not use GMT in their notebooks, mobile Linux users should use GMT to avoid resetting clocks for daylight saving time.

+   * Allow interrupts during APM BIOS calls (CONFIG_APM_ALLOW_INTS). Answer N unless your notebook hangs when using APM suspend mode.

# # Reading the /proc Directory

When APM is enabled in your Linux kernel, you'll find a file named apm under the Linux process directory (/proc). This file contains a constantly updated status of your system's power, and it looks like this:

```
$ cat /proc/apm
1.9  1.2  0x03  0x00  0x00  0x01  93%  186 min
```

APM information is represented in eight different fields. Table 7.1 describes each field's value from this example.

| **Table 7.1** | Linux /proc/apm Values |
| :--- | :--- |
| **Value** | **Description** |
| 1.9 | The Linux driver version |
| 1.2 | The APM BIOS version |
| 0x03 | Status flags detailing support and features |
| 0x00 | AC status: 0x00 = offline, 0x01 = online, 0x02 = on backup, 0xff = unknown |
| 0x00 | Battery status: 0x00 = high, 0x01 = low, 0x02 = critical, 0x03 = charging, 0xff = unknown |
| 0x01 | Battery bit flag: 0 = high, 1 = low, 2 = critical, 3 = charging, 7 = no system battery, 0xff = unknown |
| 93% | Remaining battery life as a percentage of the charge (\-1 = unknown) |
| 186 | Number of minutes (min) or seconds (sec) |
