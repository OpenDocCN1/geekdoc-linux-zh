
## Oh No! Not Another “Winmodem”!

Be careful when choosing a PCMCIA modem card for Linux: There are a number of “controllerless” PCMCIA modem cards on the market! A great place to check before you buy is <http://www.o2.net/~grontkko/winmodem.html>.

According to user data contribution at the site, ones to watch out for and avoid for Linux include Paradise CW56KPCMCIA, Paradise PC Card Modem CW56K-CB, and CW56LU-CB; IBM Model 10L7393; 3Com Megahertz XJ2560, CC2560 PC Card, CCSPWM WinModem PC Card, 3CXM356/3CCM356, 3013, 3014 WinModem PC Card, 3CXM656/3CCM656/3014 56K Global GSM WinModem PC Card, 3CCFEM656B 10/100 LAN+56K.

In this example, the modem is attached to `/dev/ttyS1`, which corresponds to the DOS COM2 port. You can then try the `minicom` command to dial out and test your modem. If you’re running X, you can also use the `xminicom` shell script to launch minicom in its own window (as shown in Figure 2.8), like this:

```bash
# xminicom &
```

The ampersand (&) is used to start the program in the background. It frees up your command line at the terminal window. You can then query or set up your modem for dialing using its built-in AT command set. These commands should be documented in your modem’s manual, but you can view a reference page of “standard” commands at <http://www.citilink.com/~kae/faq/connecting/general/hayes.html>.

For example, after starting *minicom*, you should be able to type the `AT` command, press `Enter`, and then use the `AT?` command:

```text
AT
OK
AT?
LP56OMX VER 2.01 V.90 (VER 1.14 TBR21 V.2)
OK
```

The first `OK` shows that your modem is responding. The `AT?` command “interrogates” your modem for manufacturer information.

## External Monitor Port

Few mid- to large-sized notebooks come without an external monitor or VGA port. This is a handy way to turn your notebook into a desktop system, especially if it has a diminutive screen or if you need a larger display with greater resolution than offered by the notebook’s LCD.

The safest procedure to follow when using an external display is to power down the computer, attach the monitor’s cable, and then restart. Although most notebooks have special `Fn` keyboard controls to toggle the display from LCD to monitor or both, you might need to enable external monitor use in your laptop’s BIOS. This is usually done by holding down a certain key or key combination just after you turn on your computer.

Don’t expect to be able to use the same color depth as your notebook when using higher resolutions on an external monitor. Color depth and resolution, as you’ve learned, are a function of the notebook’s graphics chipset and internal video memory. Most notebooks’ graphics memory is not adequate to support millions of colors at 1600×1200 pixels. When in doubt, check your laptop manual about connecting, configuring, and using an external display.

Mobile Linux users should be aware that in some instances, a particular graphics chipset might require particular settings in the system’s `XF86Config` file in order to display a running `X11` session on an external monitor. For example, if you have a notebook with a NeoMagic graphics chipset, and you want to display your `X` session on an external monitor, you’ll need to use this:

```text
Option "extern_disp"
```

in the graphics device section of your `XF86Config` file. (Details are in the `README.neo` file under the `/usr/X11R6/lib/X11/doc` directory.)

Be careful that settings in your XF86Config do not stress or attempt to push the external monitor beyond its capabilities. Be sure to read the technical details about your notebook's external video port first!

## Infrared Port

Many notebooks come equipped with an IrDA port for wireless communication, such as networking, file transfers, and printing. The IrDA port may be located on either side or the back of your laptop. In order to use the port, you must enable IrDA on your notebook and then place the remote device within range of the port, most likely within 3 meters and possibly within a range as shallow as 15 degrees.

For initial pointers about using IrDA with Linux, look for a short text file named `irda.txt` under the `/usr/src/linux/Documentation/networking` directory (make sure you have installed the kernel sources). However, with the rapid development of the Linux kernel, documentation and guidelines for setting up and performing IR for networking, file transfer, and printing with Linux are pretty sparse; IrDA development under Linux is a moving target. A good place to start is <http://www.cs.uoit.no/linux-irda/>.

You'll find several links and information. You can also check for compatibility with your notebook at <http://www.cs.uoit.no/linux-irda/hardware.html>.

If you want to learn more about IrDA and get some practical applications for Linux, some documentation is contained in the Linux IR-HOWTO by Werner Heuser, available at <http://www.enfu.de/~wehe/IR-HOWTO.html>.

### Installing IrDA Support

The first step is to install IR services. IrDA support for Linux is now part of the 2.2.X series of Linux kernels, but you must download and install Dag Bratl's package of software named `irda-utils`. Then you must build and install the support libraries and at least two utilities: `irdattach` and `irdamanger`. You can find this software at <http://www.cs.uoit.no/linux-irda/irda-utils/>.

After the building and installing, several commands and files are copied into your filesystem. You then need to enable IR and determine the port size. Some notebooks provide a special `Fn` key combination to turn on IR, while on others you must change BIOS settings. IRQ settings for the port might also be different between operating systems. For example, on a Sony Vaio 505TR, the IR port is assigned to COM4, IRQ10 under Windows.

However, after enabling the port and upon booting Linux, the `dmesg` command reports three serial ports:

```text
ttyS0 at 0x03f8 (irq 4)
ttyS1 at 0x02f8 (irq 3)
ttyS2 at 0x03e8 (irq 4)
```

If you're familiar with your notebook's hardware, you should recognize the new serial port (in this case, `/dev/ttyS2`). In order to set up `/dev/ttyS2` under Linux, the `setserial` command is used to fix the obvious IRQ conflict (between ttyS0 and ttyS2) to assign IRQ10 to the port:

```bash
# setserial /dev/ttyS2 irq 10
```

This command line, along with the commands necessary to load IrDA support for your system, may be placed in a short shell script:

```bash
setserial /dev/ttyS2 irq 10
insmod irda
insmod ir
irattach /dev/ttyS2
irmanager -d 1
```

Save the script, using a name such as `IR`, and then use the `chmod` command to make it executable:

```bash
# chmod +x IR
```

The next step is to edit your Red Hat or Mandrake `/etc/conf.modules` file and insert the following:

```text
alias tty-ldisc-11 irtty
alias char-major-161 ircomm-tty
```

These lines provide information to the kernel modules to be loaded from the shell script. Note that by the time you read this, these entries might have changed. (See the various README files included with the `irda-utils` software.)

### Printer Example

You should then place the IrDA device (such as a printer) in range of your notebook. Next, start IrDA with your shell script:

```bash
# ./IR
```

Turn on the printer, and look at `/proc/misc`:

```bash
$ cat /proc/misc
62 ir1pt0
63 irda
...
```

This shows information needed by the `mkmod` command, which is used to create the IrDA printer device, `/dev/ir1pt0`:

```bash
$ mkmod /dev/ir1pt0 c 10 62
```

You can then look at the contents of the file `/proc/net/irda/discovery` to see if the printer was found within range:

```bash
$ cat /proc/net/irda/discovery

IrLMP: Discovery log:

Link saddr=0x0000c404

Link saddr=0x0000c3ed
    name: BJ C-50, hint: Printer IrCOMM, daddr: 0xcab8000
```

The next step is to create a printer with Red Hat’s `printtool`, configure the printer entry to match the printer (in this case, a Canon BJC-50), save the configuration, and then edit the resulting entry in the system’s printer capabilities database, `/etc/printcap`. Change this:

```text
:IRprinter=/dev/ir1:
```

to this:

```text
:IRprinter=/dev/ir1pt0:
```

You can then print a document with this:

```bash
$ lpr -PRprinter myfile.txt
```
