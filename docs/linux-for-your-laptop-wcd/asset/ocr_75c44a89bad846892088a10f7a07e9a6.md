# Table 8.1 Linux Drive Utilities

| Name | Description |
| :------------- | :----------------------------------------- |
| badblocks | Searches the disk partition for bad sectors (blocks) |
| cfdisk | Graphical Linux partition info editor |
| df | Shows usage of mounted filesystems |
| du | Shows disk usage (of files or directories) |
| e2label | Modifies the label of a Linux filesystem |
| edquota | Edits a user’s disk quota |
| fdformat | Formats a Linux floppy |
| fdisk | Edits a drive partition table |
| fdrawcmd | Sends commands directly to the floppy controller |
| find | Linux search filesystem utility |
| floppycontrol | Floppy disk driver configuration utility |
| floppymeter | Floppy disk performance monitor |
| fsck | Examines and repairs a Linux filesystem |
| gnorpm | GNOME package manager |
| hattrib | Changes HFS file or directory attributes |
| hcd | Changes HFS working directory |
| hcopy | Copies files to or from an HFS volume |
| hdel | Deletes files on an HFS volume |
| hd ir | Lists a directory of files on an HFS volume or directory |
| hdparm | Displays and changes IDE hard drive settings |
| hls | Lists files in an HFS directory |
| hmkdir | Creates a directory on an HFS volume |
| hmount | Mounts an HFS volume |
| hpwd | Prints an HFS working directory |
| hrename | Renames an HFS file or directory |
| hrmdir | Deletes an HFS directory |
| humount | Unmounts an HFS volume |
| kfloppy | KDE client to format Linux or DOS floppies |
| kfsstastus | KDE client; shows usage of mounted filesystems |
| kpackage | KDE software package management client |
| limit | Tcsh shell core dump size control |
| ln | Creates hard or soft (symbolic) links |
| lsdev | Shows installed devices |
