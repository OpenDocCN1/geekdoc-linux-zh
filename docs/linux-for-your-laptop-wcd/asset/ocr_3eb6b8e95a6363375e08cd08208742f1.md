# WinLinux 2000

If you prefer to avoid the hassle of partitioning and formatting your notebook's hard drive, you can install, configure, and run Linux directly from a Windows desktop by using WinLinux 2000. You'll need at least 500MB of free hard drive space to install the distribution; after that, you can delete the original installation file.

To install this distribution, run the WL2000.EXE installation program and answer the prompts. In less than a minute, you'll boot to Linux with X11 using KDE as a desktop suite. The distribution includes Netscape Communicator and Adobe's free Acrobat reader. This distribution works by creating a virtual filesystem, such as a single 500MB file, on your Windows volume to represent the Linux filesystem.

Browse to http://www.winlinux2000.com/ to download your copy.

# Zipslack

To learn how to download and install Slackware Linux from an Iomega Zip drive, browse to

```
http://www.slackware.com/zipslack/
```

Here is the basic procedure:

+   1. Download the zipslack.zip, bootdisk.img, and RAMRITE.EXE files. An additional file, fourmeg.zip, supports installation on 386-based notebooks that have only 4MB of RAM!
+   2. Decompress the zipslack distribution onto the Iomega disk.
+   3. (Optional) Use RAMRITE.EXE to create a boot disk.
+   4. Run the LOADLIN.EXE command to boot Linux from the Iomega disk.

This will allow you to run Linux from a Zip drive without partitioning your notebook's hard drive. Read the FAQ at the Slackware site just mentioned to learn how to install the zipslack Linux distribution on your notebook.

Slackware Linux is a good alternative if you have little drive storage; a minimal Slackware Linux installation requires only 50MB hard drive space. You can also install Slackware by using floppy disks, but you will need to download numerous disk images, create the disks, and install each disk in sequence.
