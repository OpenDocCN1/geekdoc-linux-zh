# Downloading Books

The main Gutenberg FTP site is ftp://metalab.unc.edu/pub/docs/books/gutenberg/. Browse to the site with your favorite Web browser, and then download a book to your directory. The books are stored as plain text or as a compressed .zip file. To decompress a .zip archive, use the Linux unzip command like this:

```
# unzip 12ad10.zip
```

This will decompress the archive and save H. G. Wells's *Twelve Stories and a Dream* in your directory. You can then use your favorite text editor, word processor, or pager (such as less) to read the book. You’ll find that you can store a complete home library of books on your notebook if you have enough drive space! If you use X11, you can use the xless browser to read, search, and print your books. Use the xless client like this:

```
# xless 12ad10.txt &
```
