# Keyboard and Console HOWTO

Andries Brouwer's guide to using keyboards and the console with Linux. Found under the `/usr/doc/HOWTO` directory. You can find the latest version at http://www.linuxdoc.org.

# XF86-SVGA man page

Contains guidelines on options and settings, such as for virtual screens for the XF86-SVGA X11 server. Consult other man pages for your notebook's X11 server to find out what virtual screen sizes are available.

# http://www.xfree86.org

The home page of the XFree86 X11 distribution. This is the best place to find out about the latest X11 distribution for Linux. You'll also find out how you can contribute to this great cause!

# Videomodes.doc

Eric S. Raymond's XFree86 Video Timings HOWTO, a thorough dissertation on crafting "tweaked" modelines for your notebook's graphics chipset. Found under the `/usr/X11R6/lib/X11/doc` directory.

# http://www.plig.org/xwinman/

A compendium of information about different window managers, and a great place to start learning about some really cool alternative desktops.
