You can research X11 display support for your notebook by browsing Kenneth Harker's Linux laptop pages at

http://www.cs.utexas.edu/users/kharker/linux-laptop/

To read about your notebook's graphics chipset before installing Linux and XFree86, browse to

http://www.xfree86.org

and look for documentation associated with the current release. You can also read detailed information about your chipset (in case you have problems configuring X11 for your notebook) after installing Linux. Look under the /usr/X11R6/lib/X11/doc directory. You'll see a list of files with names beginning with README that contain specifics about a particular chipset. Note that not all these files detail notebook displays. Some of the pertinent files for XFree86, version 3.3.6 are listed in Table 2.1.

**Table 2.1 Notebook-Related Chipset Information for Xfree86 3.3.6**

File Name | Description
--- | ---
README.Mach32 | Information about the Mach32 X11 server
README.Mach64 | Information about the Mach64 X11 server
README.WstDig | Information about Western Digital chipsets
README.chips | Detailed Chips and Technologies display information
README.cirrus | Lists Cirrus Logic display chipsets
README.epson | Information about the Seiko/EPSON SPCH110FOA adapter
README.neo | Extensive information regarding NeoMagic chipsets
README.trident | Details laptop chipset configuration options

Some of these files can contain important information regarding how to use Linux and X11 with your notebook. For example, users of NeoMagic graphics chipsets will want to read the README.neo file to find out how to enable an external monitor to display X11 when the monitor is attached to the notebook's video-out port. Nearly all configuration options concerning how XFree86's X11 works with your notebook are contained in a file named XF86Config, normally located under the /etc/X11 directory after Linux is installed and X11 has been configured.
