must change BIOS settings. IRQ settings for the port might also be different between operating systems. For example, on a Sony Vaio 505TR, the IR port is assigned to COM4, IRQ10 under Windows.

However, after enabling the port and upon booting Linux, the `dmesg` command reports three serial ports:

```
```text
ttyS0 at 0x03f8 (irq 4)
ttyS1 at 0x02f8 (irq 3)
ttyS2 at 0x03e8 (irq 4)
```
```

If you're familiar with your notebook's hardware, you should recognize the new serial port (in this case, /dev/ttyS2). In order to set up /dev/ttyS2 under Linux, the setserial command is used to fix the obvious IRQ conflict (between ttyS0 and ttyS2) to assign IRQ10 to the port:

```
```bash
# setserial /dev/ttyS2 irq 10
```
```

This command line, along with the commands necessary to load IrDA support for your system, may be placed in a short shell script:

```
```bash
setserial /dev/ttyS2 irq 10
insmod irda
insmod ir
irattach /dev/ttyS2
irmanager -d 1
```
```

Save the script, using a name such as IR, and then use the chmod command to make it executable:

```
```bash
# chmod +x IR
```
```

The next step is to edit your Red Hat or Mandrake /etc/conf.modules file and insert the following:

```
```text
alias tty-ldisc-11 irtty
alias char-major-161 ircomm-tty
```
```

These lines provide information to the kernel modules to be loaded from the shell script. Note that by the time you read this, these entries might have changed. (See the various README files included with the irda-utils software.)

```
```bash
# ./IR
```
