# AT, DT, DP, X, Y, and Z

Most PCMCIA, internal, and external modems obey a standard subset of AT commands. These commands should be documented in a manual provided by your modem's manufacturer. It is important to have this information, because there can be subtle differences between different modems and the commands the modems obey. You can try searching your modem manufacturer's Web site for more information. If you just need information about basic AT commands, browse to http://www.computercraft.com/docs/hayescom.html.

AT is the modem's "attention" prefix, DT specifies dial-tone dialing, and DP specifies pulse dialing. X controls call progress reporting, Y controls longspace disconnects, and Z recalls profile 0 settings after a reset.

When you're finished configuring your modem, select the PPP tab. You'll see the dialog box shown in Figure 15.19.

If you use KDE, check Dock into Panel on Connect. The kppp client will place a small modem icon in the desktop's panel. It will have red and green lights that blink when data is sent or received. If you use an internal or PCMCIA modem, this is a handy visual aid that indicates modem activity.
