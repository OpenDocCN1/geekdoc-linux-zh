# Resource Information

**mouse**
The mouse man page. Describes the serial mouse interface for Linux.

**Keyboard and Console-HOWTO, by Andries Brouwer**
This technical guide contains loads of information regarding the Linux console and many keyboard and mouse utilities. You'll also find solutions to many common problems with the console and X11.

**http://www.linux-usb.org/**
The definitive Linux USB Project site. Provides a HOWTO about incorporating USB support with your version of Linux, a link to a working devices list (which had 20 supported keyboards and pointers at last count), and much more.

**http://atrey.karlin.mff.cuni.cz/~vojtech/joystick/**
Need information about using a joystick with Linux? Look no further than this Web site.

**http://www.geocities.com/SiliconValley/Vista/2964/index.html**
A link for the kcmjoy KDE joystick calibration client.

**Linux Sound HOWTO, by Jeff Tranter**, found at **http://www.linuxdoc.org/HOWTO/Sound-HOWTO.html**
A compendium of information regarding sound and Linux, with a number of troubleshooting hints about sound recording.

**http://home.eunet.no/~jotland/vision/**
A collection of software and links to various drivers for many different USB and parallel-port webcams you can use with Linux.

**http://www.pantelije.demon.nl/mcam/**
The home page of the mcam video capture and live-feed X11 server and client.

**http://www.jwz.org/hacks/**
Jamie Zawinski's (of Netscape and Mozilla fame) home page for the xkbcyaps X11 client.

**http://www.bright.net/~dlphilp/linuxsound/one-page.html**
Links to literally hundreds of sound programs for Linux.

**http://www.wpine.com**
White Pine's home page with links to the CU-SeeMe webcam products.
