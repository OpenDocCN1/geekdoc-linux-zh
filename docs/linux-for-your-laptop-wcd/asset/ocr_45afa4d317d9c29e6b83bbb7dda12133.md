# ### Showing Memory

To get a quick look at your memory, use the `free` command:

$ free

             total       used       free     shared    buffers     cached
Mem:         128016     124720      3296      56612      14292      69888
-/+ buffers/cache:      40540      87476
Swap:          264560       3520     261040
```
```

This example shows a notebook with 128MB of RAM, of which 124MB is in use. The swap file size is about 258MB, but only 3.5MB has been used. You can also use the `-b`, `-k`, or `-m` option to display the values in bytes, kilobytes (the default), or megabytes. In addition, you can use the `free` command's `-s` option, followed by a number in seconds, to indicate how often the display should be updated.

Other utilities that can show memory usage include `vmstat`, as well as graphical programs, such as `xosview` for X11, shown in Figure 8.3.

# ### Managing Processes

One of the best features of Linux is that you have total control over the software you start and run. If a program goes awry, you can kill its process and go back to work with confidence, without having to worry about your system's stability. Experienced Linux users routinely use the `ps` command to display a list of running processes.
