# Table 8.2 Linux Compression Utilities

| Name | Description |
|---|---|
| binhex | Converts files to BinHex format |
| bunzip2 | Decompresses .b2z archives |
| bzcat | Decompresses files to display |
| bzip2 | Burrows-Wheeler block sorting, Huffman encoder |
| compress | UNIX compression utility |
| cpio | Copies into and out of UNIX archive utility |
| gunzip | Decompresses gzip archives |
| gv | Displays compressed PostScript documents and graphics |
| gzexe | Creates executable compressed files |
| gzip | GNU Lempel-Ziv encoder |
| hexbin | Converts files from hexadecimal to Macintosh format |
| lha | LHarc archive utility for Linux |
| macunpack | Macintosh package utility |
| rpm | Red Hat Package Manager |
| rpm2cpio | Converts .rpm archives to .cpio archives |
| shar | Creates shell archives |
| tar | Manages tape archives |
| uncompress | UNIX decompression utility |
| unshar | Unpacks shell archives |
| zcat | Decompresses and displays compressed text files |
| zcmp | Compares compressed text files |
| zdiff | Compares compressed text files |
| zgrep | Searches inside compressed text files |
| zip | PKZIP-compatible utility for Linux |
| zipcloak | Encrypts a .zip file |
| zipsplit | Splits a .zip file into pieces |
| zless | Decompresses and reads compressed text files |
| znew | Recompresses compressed files to gzip format |
