# ## Getting Accurate Time

You probably set your watch and clocks according to other clocks. If you're at home, take a quick look at your different clocks, watches, radios, stereos, or VCRs to see if they all have the same time. Chances are they don't! If this is the case, how can you get accurate time settings into your notebook's hardware and the Linux system?

If you're connected to the Internet, one way to get the correct time is to browse to one of the many different Web sites that post the current time (local and for other time zones), such as http://www.time.gov/, sponsored by the U.S. Department of Commerce and the National Institute of Standards and Technology.

However, the best way to get and set the time for Linux is to use the `rdate` command (as root). You'll need to have an active Internet connection, use the `rdate` command's `-s` (set) option, and specify the hostname of a remote time server. For example:

```
# rdate -s time.nist.gov
```

This command sets your Linux system time by retrieving time information from the remote server. If you want just the time displayed, use the `rdate` command like this:

```
# rdate time.nist.gov
[time.nist.gov] Wed Mar 22 13:56:23 2000
```

The `rdate -s` command may be placed in your system's `/etc/crontab` file to have the time regularly updated if your notebook is connected to the Internet. Once accurate time is maintained on a local server, the `timed` daemon may be used to provide time service to the rest of the network. The `timed` daemon works as a server and as a client. If you start the daemon using the `-x` flag, it becomes a master and provides services to any other hosts designated by the `-r` option. For example, on a server, you might use this:

```
# timed -M -F stinky vaio green
```

The remote computers (perhaps a notebook or two), stinky, vaio, and green, should then run the `timed` daemon without any options, like this:

```
# timed
```

An interesting feature of this software is that if the master time server quits or is unresponsive, the other hosts elect a new master!

Another daemon used to synchronize time across a network is the `xntpd` daemon, which provides time via the Network Time Protocol (NTP). However, you'll need to have a radio, satellite receiver, or modem in order to set up and provide service.
