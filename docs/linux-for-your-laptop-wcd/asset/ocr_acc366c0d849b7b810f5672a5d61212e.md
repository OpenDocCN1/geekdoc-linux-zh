You can then look for the text by piping the output of the strings command through the less pager, like this:

```
# strings /tmp/hope | less
```

You’ll find other recovery techniques outlined in the Linux Ext2fs Undeletion mini-HOWTO (Red Hat and Mandrake users can look under the /usr/doc/HOWTO/ mini directory for a copy). You’ll find techniques for protecting files from deletion, even by the root operator.

Finally, remember that the most dangerous Linux command might be the shortest, and points out the inherent danger of always running Linux as root. The following simple command:

```
# rm -fr / *
```

will wipe out not only your entire Linux filesystem, but also any other mounted filesystems, including Windows or remote NFS partitions.
