before Linux writes data to disk. For example, you could change the /etc/inittab entry for update to this:

```
id:once:/sbin/update -S 1800 -f 1800
```

This will cause updates only once every half hour. Be warned, however: If you lose power and your disk is not updated, you could lose data!

# ### Controlling Your Hard Drive

Use the hddparm command to change the spindown timeout for your notebook's hard drive. The hddparm command has many different options and settings, as shown in the following code:

```
# hddparm -?
```

```
hddparm - get/set hard disk parameters - version 3.5

Usage: hddparm [options] [device] ..

Options:
-a      get/set fs readonly
-A      * set drive read-lookahead flag (0/1)
-c      * get/set IDE 32-bit IO setting
-C      * check IDE power mode status
-d      * get/set using_dba flag
-D      * enable/disable drive defect-mgmt
-f      * flush buffer cache for device on exit
-g      * display drive geometry
-h      * display terse usage information
-i      * display drive identification
-I      * read drive identification directly from drive
-k      * get/set keep_settings_over_reset flag (0/1)
-K      * set drive keep_features_over_reset flag (0/1)
-m      * get/set multiple sector count
-n      * get/set ignore-write-errors flag (0/1)
-o      * set PIO mode on IDE interface chipset (0,1,2,3,4,...)
-P      * set drive prefetch count
-Q      * change next setting quietly
-r      * get/set readonly flag DANGEROUS to set
-S      * set standby (spindown) timeout
-t      * perform device read timings
```
