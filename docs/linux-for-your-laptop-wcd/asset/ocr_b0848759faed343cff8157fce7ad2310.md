internal (or external) floppy, after you boot Linux, the Macintosh HFS partition may be mounted like this:

```
# mount -t hfs /dev/hda8 /mnt/macdesktop
```

Obviously, you have to create the /mnt/macdesktop folder first, and then ensure that /dev/hda8 contains your MacOS partition (which it should if you install Linux on top of the Mac OS on the iBook). But you can then copy files to and from the Macintosh desktop folder.

# Automated Disk Cleanup

Linux is similar to UNIX. As such, it has inherited many features and traits of SysV and BSD UNIX. This means that many configuration files, system logs, and temporary files can be created, can multiply, and can grow over the course of each successive Linux session. Some of the first steps are understanding your system's requirements, determining where the most software is installed, and deciding where on your file system cleanup might be a good strategy to use. For example, the du command may be used to print the relative size of each directory, starting at the root, or /, directory:

```
# du -h --max-depth=2 /
4.9M    /bin
1.7M    /home/ftp
6.7M    /home/htpd
1.0k    /home/samba
21M     /home/bball
29M     /home
43M     /lib/modules
269k    /lib/security
47M     /lib
1.8M    /root
5.6M    /sbin
96M     /usr/X11R6
150M    /usr/bin
404k    /usr/dict
192M    /usr/doc
1.1M    /usr/games
12M     /usr/include
```
