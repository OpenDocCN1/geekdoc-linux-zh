```
# ## Ports and PCMCIA

Keep your online time to a minimum to reduce the use of a built-in modem or serial port.

To save additional power, use your computer's BIOS to disable the IrDA port, or, if possible, turn it off using an **Fn-key** keyboard command. If you have a network or modem PC card, first make sure the network or modem is not in use with the **cardctl** command:

```
```bash
# cardctl status
Socket 0:
3.3V 16-bit PC Card
function 0: [ready], [hat dead], [bat low]
Socket 1:
5V 16-bit PC Card
function 0: [busy]
```
```

After stopping a card's use, you can software-eject the card like this:

```
```bash
# cardctl eject 0
```
```

You can then turn off PCMCIA's Card Services by using its script like this:

```
```bash
# /etc/rc.d/init.d/pcmcia stop
```
