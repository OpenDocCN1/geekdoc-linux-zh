Mobile Linux users sometimes face numerous obstacles when installing, configuring, and using Linux on a laptop. Fortunately, many sources of help, information, bug fixes, techniques, tips, tricks, and traps are available on the Internet. Need a perfect XF86Config file for your notebook's graphics chipset? You can find one if an intrepid user has published one on the Web or has a home page describing a Linux installation on your laptop's model. Need to configure Linux to work with your notebook's sound system? Chances are you'll find the answer, especially if you have a popular (or even a not-so-popular) notebook model.

This appendix contains lists of helpful Internet resources that can provide helpful information about Linux, your notebook, and using Linux on your notebook. The lists are as follows:

+   * Usenet newsgroups. More than 60,000 newsgroups are available through ISPs or newsreader Web sites, such as http://www.deja.com. Use your newsreader or the Web site to search for answers to questions about your notebook. Chances are good that you'll find the answer!
+   * World Wide Web. There are too many individual Web pages with specific information about using Linux on specific notebooks to list them here. However, you'll find a list of sites organized by topic to help you review, purchase, sell, or get more information about your notebook. Don't forget to check the Resource Information section at the end of each chapter in this book for pointers to chapter topics!
+   * Mailing lists. A number of mailing lists are devoted to the topic of Linux and laptops. Mailing lists can be interactive or used in “digest” form. If you subscribe interactively, each message sent to the list will appear in your e-mail in-box. Many lists also provide a single day's commentary in a single (digest) format mailed each day. Either way, you're sure to benefit from subscribing or contributing to a Linux laptop mailing list!
+   * How-To documentation. Numerous How-To's are included with each Linux distribution, and some include information about using Linux with a notebook.
