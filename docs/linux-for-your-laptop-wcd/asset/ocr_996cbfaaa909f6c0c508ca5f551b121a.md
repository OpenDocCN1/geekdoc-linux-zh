+   Intel Mobile Pentium II. Available in clock speeds up to 500MHz, these processors (now being replaced by Mobile Pentium IIIs) were designed with 256K of “on-die cache” (to help performance) and thin packaging.
+   Intel Mobile Celeron. Featured in many lower-cost notebooks with speeds up to 600MHz, these less-expensive CPUs use Pentium II architecture and MMX instruction sets.
+   AMD K6-2. A popular, less-expensive alternative for notebooks with clock speeds up to 533MHz, these CPUs feature AMD's 3DNow! instruction set. Like MMX, it enhances floating-point operations for multimedia programs.
+   Intel Mobile Pentium MMX. An extremely popular CPU, designed with clock speeds up to 300MHz and Intel's MMX features, which added 57 additional multimedia (video, audio, and image) instruction sets to the Pentium chip. This chip also has energy-saving features.

Linux works quite well with all of these processors, and you'll experience no problems when running Linux on a notebook using one of these CPUs.

# CPU Bugs

On the other hand, other CPUs such as the early Cyrix 6x86 failed to work with Linux unless APM was disabled in the computer's BIOS. Many Pentiums, including the MMX series, still suffer the Pentium “f00f” bug, which can crash a system through an invalid instruction. Another bug, the “f0” invalid instruction, affects early Pentium and MMX Pentium CPUs. Some versions of the Pentium II and Pentium Pro series also suffer a potentially catastrophic floating-point problem. And many Intel-based computer users might remember the now-classic early Pentium floating-point bug from 1993.
