The basic steps in partitioning a notebook’s drive for Linux involve creating a new partition and then booting to the Linux installation. During the Linux installation, the new partition will then itself be partitioned to provide at least one native Linux partition and one Linux swap partition. The swap partition is used with virtual memory to swap parts of main memory to disk.

Most experienced mobile Linux users use partitioning to do the following:

+   * Create separate directories on distinct volumes for the Linux file system.
+   * Organize the Linux file system, such as creating a separate `/opt` volume for third-party or commercial software packages.
+   * Create an appropriately sized swap partition, usually according to the amount of physically installed RAM.
+   * Proactively protect various parts of the file system. Additional drive volumes can be “hidden” and not automatically mounted when Linux boots.
+   * Create ease of use when running backup programs to archive specific directories, such as `/home` (where all system users’ data resides).
+   * Assign a separate area for temporary files, such as `/tmp` or `/var/tmp` to protect other volumes from overflow.

As an example, if your notebook with 64MB of RAM has a 3GB hard drive, and you’d like to configure a dual-boot system, first defragment the drive, and then split the drive by creating a 1.5GB partition. Next, boot the Linux installation. During the installation, create a swap partition of 128MB, and leave the rest for the Linux root ( / ) file system. Alternatively, you could create a partition of 600MB for the /home directory, 22MB for the /boot directory, 128MB for swap, and leave the rest for the / directory.

# # Partitioning Tools

There are a number of partitioning tools you can use to make room for Linux on your notebook’s hard drive. Note that you need to use a partitioning tool before installing Linux only if you have an existing operating system you’d like to keep on your hard drive. Don’t bother with partitioning before installing Linux if you’re just going to install Linux!

If you need to partition your hard drive before installing Linux, be sure to defragment your drive. If you use Windows 95 or 98, double-click on the My Computer icon on the desktop, right-click on your notebook’s hard drive, select Properties, and select the Tools tab in the Properties dialog box, as shown in Figure 5.1.
