This section demonstrates how to use the inexpensive parallel-port version of the Zora webcam included with White Pine’s CU-SeeMe Cam Kit, a CplA-based camera that provides 8-bit color, 100,000-pixel resolution, and up to 30 frames per second transmission. You’ll require a notebook that provides a parallel port supporting ECP mode. The camera is powered by your notebook’s keyboard port but plugs into the printer port for use.

# # Using the mcam Client with Linux

Using a webcam with your notebook is easy! For example, you can download Jan Pantelje’s mcam software package (see the following section, “Resource Information”), unpack the software archive, and then build and install the software, like this:

```
```
# tar xrvf mcam.gz
# cd mcam*
# xmrf
# make
# make install
```
```

The *mcam* command, which can be run as a server and as a viewing client, will be installed under the */usr/local/bin* directory. This command also works with the Creative Labs Video Blaster II webcam and many other CplA chip webcams. The *mcam* command is generally used during an X11 session, although you can run it on a computer that is not running X to serve images over a LAN or the Internet.

To get started, attach the webcam to your notebook, orient the camera module so that it is not pointing at a light source, and make sure you're running X. Next, as root, start the program like this from the command line of a terminal window:

```
```
# mcam
```
```

You’ll see a full page (nearly 60 lines) of command information. Press *5*, and then *p*, and then *9*, and you should see an image appear in an X11 window, as shown in Figure 10.10.

If your notebook is attached to a LAN or the Internet, you can use *mcam* in its server mode to offer continuous image scans. Start *mcam* like this:

```
```
# mcam -s
```
```

On a remote computer, install the *mcam* client, and then connect to the computer, perhaps named *workhorse*, running the *mcam* server like this:

```
```
# mcam -c -a workhorse
