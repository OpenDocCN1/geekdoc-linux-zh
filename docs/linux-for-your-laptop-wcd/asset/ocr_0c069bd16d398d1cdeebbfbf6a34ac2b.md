+   Pick applications that are conservative with memory and disk space. If you need to perform spreadsheet operations, try using the sc or **teapop** editor instead of Applix, StarOffice, or other GUI-based X11 clients.  
+   \- Delete unwanted documentation. If you install all the documentation from most distributions, you'll end up with documents in French, German, Italian, Polish, Greek, Chinese, and many other languages. Most full installations of the **/usr/doc** directory require at least 200MB of storage!  
+   \- Compress desired documentation. If you decide that you really do need to have all the HOWTOs available, use the **gzip** or **bzip2** commands to compress all the files. You can then use decompression or pagers such as **zless** to read the files.  
+   \- Delete unwanted documentation formats. Most Linux distributions include HOWTO and other files in HTML and SGML. You can delete these directories, usually found under the **/usr/doc/HOWTO/otherformats** directory, to save at least 25MB of drive space.  
+   \- Delete example files. If you're familiar with the software installed, you can delete nearly every program's auxiliary documentation and example files under the **/usr/doc** directory.  
+   \- Clean up temporary or backup files. Regularly use scripts to clean up your filesystem.  
+   \- Maintain good backups. Always back up important directories such as **/home** and **/etc**.  
+   \- If you need more storage, consider using an auxiliary peripheral, such as a Zip drive. If that's too bulky, use a Type II flash memory card. IBM now markets the MicroDrive, a 170 to 340MB drive that is the size of a compact flash card, which can be used with Linux.  
+   \- Don't start services you don't need. For security, edit the **/etc/inetd.conf** file to turn off unwanted services. Red Hat and Mandrake users should use the **ntsysv** command to select services to be started during the boot process. SuSE Linux users should use the **yast** command, and Caldera OpenLinux users can use the **liisa** command or the graphical COAS utility to control system services. This will save system memory and keep the number of running processes to a minimum.
