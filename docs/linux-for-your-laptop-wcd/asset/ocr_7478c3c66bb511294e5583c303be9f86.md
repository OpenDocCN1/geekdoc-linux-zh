+   * Change the default operating system to boot.
+   * Change the number of seconds LILO waits for a boot: entry.
+   * Pass special boot-time arguments to the Linux kernel (useful for configuring hardware while booting.

Table 3.3 lists just a few of the options and keywords you can use in your `/etc/lilo.conf` file. If you make any changes to this file, don’t forget to run `/sbin/lilo` afterward!

**Table 3.3 LILO Configuration Keywords**

| Keyword | Description |
| --- | --- |
| `append` = `message` | Passes the following kernel argument |
| `boot` = `device` | Informs the kernel what device holds the boot sector |
| `image` = `/boot/kernel_name` | Specifies a Linux kernel to boot |
| `label` = `name` | Designates a boot keyword, such as `linux` or `dos` |
| `message` = `file` | Displays the designated text file at the boot prompt |
| `password` = `password` | Requires a password before booting |
| `prompt` | Forces the use of a boot-prompt entry |
| `root` = `device` | Specifies the location of the Linux root partition |
| `timeout` = `number` | Sets a timeout (in tenths of a second) |

# # Boot Loaders and Pitfalls

If you use only Linux on your notebook, go ahead and install LILO into the MBR of your boot drive. However, if you want to use another operating system, such as Windows, you should know that, with typical disregard, the Microsoft installation will overwrite the MBR. This means that you should install Windows first and then install Linux.

If you use a commercial boot loader, such as PowerQuest’s BootMagic, be sure to install LILO into the root native Linux partition! BootMagic will require the MBR to provide its graphical operating system selection dialog box and will overwrite LILO when installed.
