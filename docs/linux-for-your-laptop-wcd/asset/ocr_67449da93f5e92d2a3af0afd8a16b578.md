If you use KDE, use the `kmclock` client to set a different time and zone. This client requires that you run X11. Click the desktop's Application Starter button on the panel, and then select Settings, Date and Time. You can also (as root) start the client from the command line of an X11 terminal window by typing `kmclock` and pressing Enter. You see the dialog box shown in Figure 16.3.

This client has the advantage of being able to set the date, time, and time zone from one dialog box (although you have to click the Time Zone tab to set the time zone). Unlike Red Hat's `timeconfig` command, `kmclock`'s time zones are not listed as location names, but only as offsets from GMT, or 0.

# # The TZ Environment Variable

Linux also recognizes the `TZ` environment variable, a setting retained in memory by your shell. You can use this variable to tell other applications launched from the shell what time zone is currently in use. For example, you can use the `bash` shell's `export` command to set this variable on-the-fly:

```
# export TZ=EST+5
```

This sets the time zone to EST without daylight saving time. To specify DST, use additional fields for the `TZ` variable, like this:

```
# export TZ=EST+5EDT,M4.1./M1.0.,5.0
```
