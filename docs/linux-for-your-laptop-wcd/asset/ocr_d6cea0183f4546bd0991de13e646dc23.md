If you have two network cards and you want to share your DSL service with the rest of a LAN, use the eth1 device with the DSL modem. Otherwise, type in `eth0` and press Enter. You’ll then see this:

```
DNS

Please enter the IP address of your ISP’s primary DNS server. If you just press enter, I will assume you know what you are doing and not modify your DNS setup. Enter the address here:
```

If you are given a DNS address, enter it here in the form of 205.252.116.10, not the hostname, and press Enter. Note that you should have a DNS number available, either here or in your system’s `/etc/resolv.conf` file. You’ll then be asked for your password:

```
PASSWORD

Please enter your PPPOe password:
```

Type in the password assigned to you by your ISP. You’ll be asked to enter it again. After you press Enter, you’ll see this:

```
FIREWALLING

Please choose the firewall rules to use. Note that these rules are very basic.
You are strongly encouraged to use a more sophisticated firewall setup; however, these will provide basic security. If you are running any servers on your machine, you must choose ‘NONE’ and set up firewalling yourself. Otherwise, the firewall rules will deny access to all standard servers like Web, e-mail, ftp, etc.
The firewall choices are:

0 – NONE: This script will not set any firewall rules. You are responsible for ensuring the security of your machine. You are STRONGLY recommended to use some kind of firewall rules.
1 – STANDARDONE: Appropriate for a basic stand-alone web-surfing workstation
2 – MASQUERADE: Appropriate for a machine acting as an Internet gateway for a LAN
Your choice?
```

Enter the number 0, 1, or 2, and press Enter. Unless you’re just testing the connection, you should enable firewallow on your notebook if it will be the main intermediary between the Internet and your LAN. You’ll then be asked to acknowledge your setup:

```

MASQUERADE
```
