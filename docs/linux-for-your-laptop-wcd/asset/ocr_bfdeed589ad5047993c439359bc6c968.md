# Using RCS

The RCS system consists of seven different programs, but you can get started with document tracking with just two commands: `ci` (check in) and `co` (check out). First, create a directory for your document(s) with the `mkdir` command, like this:

```
# mkdir work
```

Next, create a directory named RCS in the directory you just created:

```
# mkdir work/RCS
```

Navigate to your project directory, and then create a text file, perhaps named book1.txt. At the top of the file, create a header that looks like this:

```
/ * $Header$
$Author$
$Date$
$Revision$
* /
```

Continue editing the file. When you're finished, save the file and exit your text editor. When you next want to work on the file, navigate to the work directory, and use the `ci` command, followed by the name of the file to work on:

```
# ci book1.txt
RCS/book1.txt,v  <--  book1.txt
enter description, terminated with single '.' or end of file:
NOTE: This is NOT the log message!
>>  Second revision
>>  .
initial revision: 1.1
done
```

When prompted, enter a short description, press Enter, type a period (.), and press Enter again. When you're ready to open and work on the file again, use the `co` command with its `-l` (lock) option, like this:

```
# co -l book1.txt
RCS/book1.txt,v  -->  book1.txt
revision 1.1 (locked)
done
```
