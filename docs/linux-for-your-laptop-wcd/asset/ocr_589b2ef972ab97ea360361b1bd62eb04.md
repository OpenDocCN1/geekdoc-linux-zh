**Figure 7.1** The Linux make xconfig dialog box is used to configure settings before building a new Linux kernel.

+   *   **Enable APM at boot time** (`CONFIG_APM_DO_ENABLE`). You can safely say N here; according to documentation included with the Linux 2.2- series kernel, some notebooks can hang with this enabled. A safer approach is to not enable this feature.
+   *   **Do CPU IDLE calls** (`CONFIG_APM_CPU_IDLE`). Answer Y.
+   *   **Enable console blanking using APM** (`CONFIG_APM_DISPLAY_BLANK`). Answer Y if you want to try this feature and have the Linux screen saver blank and turn off your LCD backlight. Otherwise, answer N.
+   *   **Turn off power on shutdown** (`CONFIG_APM_POWER_OFF`). Answer Y to have Linux turn off your notebook when you use the `shutdown -h` command. (Note: Be sure to check your system’s halt script, found under Red Hat’s and Mandrake’s `/etc/rc/init.d` directory.)
+   *   **Ignore multiple suspend or standby events** (`CONFIG_APM_IGNORE_MULTIPLE_SUSPEND`). Answer Y, especially if you have an IBM ThinkPad 560.
+   *   **Ignore multiple suspend or resume cycles** (`CONFIG_APM_IGNORE_SUSPEND_BOUNCE`). Answer Y, especially if you have a Dell Inspiron 3200.
