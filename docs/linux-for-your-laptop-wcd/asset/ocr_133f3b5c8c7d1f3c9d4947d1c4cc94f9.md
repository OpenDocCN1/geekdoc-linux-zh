# Text-Only Configuration with xf86config

You can also configure X11 through the Linux console by using the xf86config command. This text-only program asks you a series of questions regarding your notebook's mouse and video hardware and your desired color-depth settings. Then it builds a custom XF86Config file for your notebook. Start the command by typing xf86config on the command line:

```
# xf86config
```

After you press Enter, you'll see a short page of text. To continue, press Enter. You'll see the following:

First specify a mouse protocol type. Choose one from the following list:

+   1. Microsoft compatible (2-button protocol)
+   2. Mouse Systems (3-button protocol)
+   3. Bus Mouse
+   4. PS/2 Mouse
+   5. Logitech Mouse (serial, old type, Logitech protocol)
+   6. Logitech MouseMan (Microsoft compatible)
+   7. MM Series
+   8. MM HitTablet
+   9. Microsoft IntelliMouse
+   10. Acecad tablet
