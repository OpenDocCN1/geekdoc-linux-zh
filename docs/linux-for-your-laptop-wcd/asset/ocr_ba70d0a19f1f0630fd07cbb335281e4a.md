# ## Using a Joystick

Linux includes support for joysticks through loadable kernel modules or as built-in support in the XFree86 X server. However, few, if any, notebooks are equipped with a traditional joystick port. Support for many new types of joysticks will arrive with improved USB support in the Linux kernel.

A number of joystick utilities are available for Linux, but few are included with normal Linux distributions. Support for joysticks is mainly provided by a particular program or client, but you might find the following utilities helpful:

+   • **kcmljoystick**. A KDE joystick calibration client. Get it at `http://www.geocities.com/SiliconValley/Vista/2964/index.html`.

+   • **joystick**. The Linux joystick driver. Look under `/usr/src/linux/drivers/char/joystick` for a variety of support modules.

+   • **joy2key**. A driver that converts joystick movement to keyboard commands. This allows the use of a joystick with many programs that would otherwise not support a joystick. Browse to `http://www-unix.oit.umass.edu/~trrtron/joy2key/`.

+   • **joyd**. A joystick daemon that can be used to run commands through the movement of your joystick. Browse to `http://www.h.shuttle.de/mitch/joyd.en.html`.

+   • **gxtest.c**. A program you can use to test your joystick at the console. Browse to `http://www.trylinux.com/projects/joystick/gxtest.c`.

# ## Keyboard and Internationalization

You'll most likely choose the proper keyboard to use for Linux during installation. However, as you can see from Table 10.1, and as pointed out in Chapter 2, "Taking Inventory," Linux comes with many different commands and utilities you can use to reconfigure or remap your keyboard. Your only potential problem will be understanding when and how to apply changes for the console or the X Window System. Manually creating or redefining an entire keyboard mapping is beyond the scope of this chapter, but you'll see how to use at least one X11 client, named `xkeycaps`, which can quickly generate the required files to remap your keyboard for your X11 sessions.
