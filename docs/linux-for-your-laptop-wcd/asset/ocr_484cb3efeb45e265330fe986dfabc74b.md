# # USB on the Horizon

The advent of the newer Linux 2.4 series of kernels for Intel-based Linux will enable new hardware compatibility for a variety of USB hardware, such as mice, keyboards, speakers, scanners, printers, webcams, cameras, and joysticks. If you currently use a Linux kernel of at least version 2.2.14, you can get some USB functionality by installing kernel patches and recompiling your kernel. Browse to http://www.suse.cz/development/usb-backport/ to download the kernel patch. Browse to http://home.snafu.de/wehe/usb\_linux.html to see a list of laptops on which users have reported success with various USB devices.

# ## Configuring Pads

If you have a Synaptics TouchPad, browse to http://www.pdos.lcs.mit.edu/~cannan/Synaptics/ to download a driver to configure tapping and other features. Mobile Linux users with notebooks that use a TrackPoint pointer should browse to http://www-hft.ec.TU-Berlin.DE/~strauum/tp4utils and download the `tp4utils` package. Browse to http://parzelle.de/Linux/Lifebook/ to download special drivers for the Fujitsu Lifebook B112/B142 series of notebook (using touch panels).

Other notebooks, such as the Sony Vaio 505 series, which use a VersaPad (and include a small plastic drawing stylus), also work well when configured as a PS/2 pointing device.
