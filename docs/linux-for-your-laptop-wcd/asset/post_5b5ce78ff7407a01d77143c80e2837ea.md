When you print with Linux, nearly all documents are first saved as PostScript. This PostScript stream is then "filtered" through a print filter named `ps`, which then converts the PostScript file to the proper printer control language. What does this mean? Raw PostScript files, graphics, and other documents are easily printed under Linux. Your distribution comes with literally hundreds of graphics utilities and conversion programs.

## The PCMCIA Port

Most laptops come with one or more PCMCIA slots. These slots support 70-pin devices, usually the size of a credit card (although some are a bit larger). Notebooks that have two of these slots can support one of the increasingly uncommon Type III PC cards, which use at least one connector but take both slots. In many cases, you can use two Type II PC cards in a notebook at the same time. However, a growing number of notebooks, especially in the ultralight or thinner categories, support only one Type II slot. Also, some Type II cards, although they require only one slot, use both slots anyway.

Your notebook will provide power to the inserted PC card, so many devices do not need external power. On the other hand, larger external hard drives and earlier external CD-ROMs might also require an external AC adapter (unless batteries are an option).

In the last several years, the notebook industry has adopted the CardBus standard, which allows faster data transfer through the PCMCIA port (the more common 16-bit transfer rate has a limit of about 2 to 3Mbps). Linux supports hundreds of the common 16-bit PC cards. Unfortunately, due to the frantic pace of technology and development and the dearth of support from some manufacturers, support for the 32-bit or CardBus card is "still somewhat experimental," according to David Hinds, maintainer of the Card Services software, which provides PCMCIA support under Linux. ## A Note of Thanks

Mobile Linux users owe a big debt of gratitude to David Hinds, who created and maintains the core software that provides PCMCIA support for Linux. Because of his and others' efforts, Linux users can use and enjoy hundreds of different PC card devices. The PCMCIA software, named Card Services, consists of nearly a dozen or more kernel modules. Card Services was originally distributed as a separate software package for Linux, but over the last year or so this critical notebook software has been incorporated into the Linux kernel source code tree. Kudos to David and other PCMCIA programmers!

## Form Factors

There are many different types of PC cards for notebooks, along with different form factors. Due to the insidious laptop industry trend of including software-driven or “controllerless” modems, many mobile Linux users will need to purchase and use a PC card modem to connect to other computers. If your notebook has two Type II slots, choose either a combination modem and networking card that leaves the other slot free, or a modem card that won't interfere with a second Type II card.

## Using Card Services

Some Linux distributions automatically enable PCMCIA support if a PC card is used to install Linux (such as for an FTP, NFS, or HTTP installation), but this is not always the case. If you install Linux from your laptop's CD-ROM, you might have to manually turn on support. Be sure to install the PCMCIA software! If you're not sure if it is installed, you can try this:

```bash
# whereis cardctl
cardctl:  /sbin/cardctl  /usr/man/man8/cardctl.8.bz2
```

This shows that the software has been installed. Next, when using Red Hat (and Mandrake) Linux, go to the `/etc/sysconfig` directory. You should see a file named `pcmcia`. This is the PCMCIA startup options file. Open this file with your favorite text editor:

```bash
PCMCIA=
PCIC=
PCIC_OPTS=
CORE_OPTS=
CARDMGR_OPTS=
```

To turn on PC card support, edit the file to look like this:

```bash
PCMCIA=yes
PCIC=182365
PCIC_OPTS=
CORE_OPTS=
CARDMGR_OPTS=
```

The PC Card Interface Controller (PCIC) entry can be `tcic` or `182365`. This is because, according to Hinds, nearly all notebooks use one of two different types of controllers: a Databook TCIC-2 or an Intel i82365SL compatible. After making your changes, save the file. You can then insert your PC card and (if using Red Hat or Mandrake) start Card Services like this:

```bash
# /etc/rc.d/init.d/pcmcia start
```
