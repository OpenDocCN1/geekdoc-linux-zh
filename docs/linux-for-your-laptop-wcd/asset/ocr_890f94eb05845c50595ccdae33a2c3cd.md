# Parallel-Port CDR Support?

Navigate to the Linux Parallel Port CDR page (http://www.torque.net/parport/cdr.html) if you'd like to explore burning CDRs using a parallel-port drive. According to the host, Dave Campbell, you'll need the pg.o module (included with most modern 2.2.X Linux distributions), along with PARIDE (parallel-port IDE) support in your system's Linux kernel. You "should be able to burn CDRs at 2x speed in EPP mode."

CDRW drive appear as a SCSI device. Before trying this, however, try booting Linux with the kernel argument append keyword, followed by the device name of your ATAPI CDR or CDRW drive:

```
append="hdd=ide-scsi"
```

In this example, /dev/hdd is the designated drive. You can then try using the insmod command to load the ide-scsi.o module:

```
# insmod ide-scsi
```

For the least amount of hassle, you can choose to use a SCSI PC card adapter and an external SCSI CDRW drive. Although these drives are bulky, require an external power supply, and cost more, you're almost guaranteed ease of use, speed, and compatibility when using this type of drive with Linux to create CDR or CDRW disks. One combination that I can heartily recommend is an Adaptec 1260 PCMCI A adapter and an HP or Yamaha external drive (such as Yamaha's CRW8424SX). You can check David Hinds' SUPPORTED.CARDS document for a list of supported SCSI adapter PC cards.

To use an external SCSI CD-Writer, insert the PCMCI A SCSI adapter, and then turn on the external drive. Next, power up your notebook. During the boot process, you should hear two high beeps. When you examine the kernel boot messages (using the dmesg command), you should see something like this:

```
... aha152x: processing commandline: ok aha152x: BIOS test: passed, detected 1 controller(s) aha1520: vital data: PORTBASE=0x340, IRQ=3, SCSI Id=7, reconnect=enabled, parity=enabled, synchronous=disabled, delay=100, extended translations=disabled aha152x: trying software interrupt, ok. scsi0 : Adaptec 152x SCSI driver; $Revision: 1.7 $ scsi : 1 host.
```
