tions may also be used during the Red Hat installation. They are inserted into the LILO configuration dialog box as an option, like this:

```
`append = 'hda=1024,12,63'`
```

This option enables Linux to boot on the ThinkPad 701 series of notebooks. If you're having trouble installing or booting Linux due to LILO errors, see "Boot Loaders and Pitfalls" in Chapter 3. You should also check the Linux laptop pages for solutions for your notebook. (If you have a popular notebook from a well-known manufacturer, chances are good that someone has installed Linux before you and might have solved any serious technical problems.)

To uninstall LILO, you can use the DOS `FDISK` command with its `/MBR` option. Boot your notebook to DOS, and then use this:

```
`C:> FDISK /MBR`
```

To uninstall LILO under Linux, use the `lilo` command, along with its `-u` (uninstall) option:

```
`# lilo -u`
```

Make sure you have a boot disk on hand or are sure you want to uninstall LILO!

# Apple iBook Boot Management with BootX

Apple iBook Linux users can boot Linux in at least two ways. The first way uses Apple's OpenFirmware boot ROM in the iBook, along with a utility named Yaboot. The second, easier, and more common way is to use the BootX Control Panel device, launched after your Mac starts.

The Yaboot utility is somewhat similar to LILO, and uses somewhat similar syntax in its configuration file. One benefit of using Apple's Open Firmware prompt and Yaboot is that you will be able to use the internal iBook modem. To boot Linux using the Yaboot boot loader (included on the Yellow Dog Linux CD-ROM), copy the files vmlinux, yaboot.tbxl, and yaboot.conf to your iBook's hard drive while running MacOS. Edit the yaboot.conf file to look like:

```
`timeout=5
default=linux

image=hd:8,/vmlinux
label=linux
root=/dev/hda10

novideo`
```
