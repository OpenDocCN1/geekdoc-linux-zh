# Wireless Connections

This section offers additional solutions for mobile Linux users who want to use the Internet or access a network without the hassle of wires, cables, or the need to jack in. The first solution offers roaming capability 500 to 1,000 feet from a LAN using new 2.4GHz wireless networking technology. Other solutions allow much greater range, but additional commercial network service is required.

# Wireless LANs

The newest rage in home office and office networking is wireless technology. A number of wireless networking cards work with Linux on your notebook, but until recently, they have been somewhat prohibitive in cost. These cards typically offer either 11Mbps or 2Mbps networking speeds and cost the same or three times as much as normal PCMCIA networking cards. The kit uses 2.4GHz radio technology (as detailed in IEEE 802.11 specifications), known as frequency-hopping spread-spectrum networking.

## Wireless LAN Card Configuration

This section details the installation and configuration of a low-cost 2Mbps wireless network for Linux using Webgear, Inc.'s Aviator 2.4 wireless network cards. Webgear markets a networking kit consisting of two Type II PCMCIA cards and two ISA PC card slots. When the cards are installed and configured, the interfaces appear as Ethernet devices, such as eth0.

This kit allows you to set up peer-to-peer networking between two laptops, two desktop PCs, or a laptop and a desktop. The ISA PC card slots may be installed in a desktop to allow use of a PCMCIA card. Configuring the cards involves downloading, decompressing, building, and installing the card drivers. Browse to http://world.std.com/~corey/raylink.html to download Corey Thomas' latest version of the Linux driver, ray_cs.o, for the Aviator cards. Then copy the compressed tarball to the /usr/src/linux/pcmcia directory, and decompress the file like this:

```
# tar xzvf ray_cs.gz
```

To configure, build, and install the drivers, do this:

```
# make config
# make all
# make install
```

Next, edit the file /etc/pcmcia/config.opts and insert this line:

```
source ../ray_cs.opts
```

Next, edit the ray_cs.opts configuration file to read as follows:

```
module "ray_cs" opts "pc_debug=2 essid=LINUX hop_channel=128 \
beacon_period=256 translatel=1"
```

Be sure to use the same settings for each computer. Next, use Red Hat's netcfg tool to create an eth0 interface on each computer. The cards must then be started sequentially. Make sure Card Services is running by doing the following:

```
# /etc/rc.d/init.d/pcmcia start
```

Insert one of the Aviator cards, and then look through the system's /var/log/messages file for this:

```
ray_cs Detected:
WebGear PC Card WAN Adapter Version 4.88 Jan 1999
eth0: Raylink, irq 4, hw_addr 00:00:8f:48:28:DB
ray_cs interrupt network "LINUX" started
```

Next, enable the interface using netcfg, and insert the other Aviator card on the other computer. Again, look at /var/log/messages:

```
ray_cs Detected:
WebGear PC Card WAN Adapter Version 4.88 Jan 1999
eth0: Raylink, irq 10, hw_addr 00:00:8f:48:28:45
ray_cs interrupt network "LINUX" joined
```

Note that the first instance of the ray_cs.o driver output says “started,” and the second card says “joined.”

Enable the second interface, and your computers are networked! You can then try using the ping command to test the connection. Once the network is working, you can use telnet, ftp, or even http for Web browsing (FTP speeds will be about 180Kbps).

Using this approach, you can install a wireless card in your notebook and another on a computer attached to a LAN. By using IP masquerading, you can forward Internet service to the wireless laptop. Do this by assigning an IP address to the first eth0 interface on your server, and then install an Aviator card as eth1 with an IP address in a different subnet. For example, eth0 could have an address of 192.168.2.50, and the Aviator card, as eth1, would be assigned 192.168.1.1. Start the wireless service from the server to your laptop, and then use the route command like this:

```
# /sbin/route add 192.168.1.1 gw 192.168.2.50
```

On the server (192.168.2.50), which has a connection to the Internet, you would then use IP masquerading like this:

```
# /sbin/modprobe ip_masq_ftp
# /sbin/iptables -A forward -s 192.168.2.0/24 -j MASQ
# /sbin/iptables -A forward -s 192.168.1.0/24 -j MASQ
```

On your wireless laptop, complete the configuration by using the route command like this:

```
# /sbin/route add default gw 192.168.1.1
```
