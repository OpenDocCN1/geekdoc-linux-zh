## Appendix B: Using the Bootable Business Card

- Booting to the Rescue Mode
- Installing Debian GNU/Linux
- Downloading and Creating Your Own Copy

![](img/70d85e6f4d1ff2750ca2a98ba3d9855c_464_0.png)

Thanks to the efforts of the great folks at Linuxcare, Inc., this book includes a copy of their Linuxcare Bootable Business Card for Intel-based Linux systems. This little jewel fits easily into a wallet or laptop bag, and can be a real life saver if you need it! This card may be used for a variety of purposes:

- **Bootable rescue disk.** Used in a laptop or desktop PC with a CD-ROM, this card will boot directly to a Debian Linux root operator prompt and attempt to mount any recognized Linux filesystems.
- **Recovery disk.** After booting, you may be able to access, retrieve, and save important files on a floppy diskette.
- **Creating a Linux boot diskette.** By using the DOS **RAWRITE.EXE** command or the Linux **dd** command, you can create a bootable Linux floppy by using the file **lrx.img** on the CD-ROM. This floppy can then be used, with the CD-ROM, to boot to a Linux session.
- **Diagnostics and testing.** The tiny CD-ROM, when booted, provides a feature-rich Debian file system with hundreds of Linux filesystem and networking utilities.
- **Jump-starting a Debian Linux install.** By using the “debinst” keyword at the initial boot prompt, you can use the CD-ROM to install Debian GNU Linux.

I think you'll find the Bootable Business Card to be a valuable and powerful tool. It demonstrates the power of Linux and proves the merit of using Open Source licensing and software.

### Booting to the Rescue Mode

To use the Bootable Business Card to rescue or diagnose your laptop's Linux installation, first be sure that your notebook's BIOS supports booting from CD-ROM. Next, insert the CD-ROM and reboot your notebook. You'll see an initial splash screen. If you wait five seconds, the CD-ROM will boot Debian Linux, and you'll see an initial boot prompt like this:

```
linuxcare login:
```

Log in with the username **root** and use **linuxcare** as the password. After you press Enter, the file **CREDITS-README.txt** will be displayed. Carefully read this file!

Use the Up or Down arrow keys to scroll through the file. When finished, press the q key to quit reading. You'll then be at the root operator prompt of the Linux console. To enable PCMCIA support during your session, use the pcmcia shell script (found under the /bin directory) with the start keyword like this:

```
root@linuxcare:~$ pcmcia start
```

This will load version 3.1.3 of David Hinds' Card Services, and start the cardmgr daemon. If you need networking support, use the trivial-net-setup script to initialize an internal or PCMCIA Ethernet adapter.

The Bootable Business Card's Debian Linux system is configured to automatically recognize and mount any found Linux file systems under the /mnt directory. For example, your notebook may have Linux installed on several partitions, such as:

```
/dev/hda5          /boot
/dev/hda6          /d2
/dev/hda8           /
```

In this example, the /boot directory (containing the Linux kernel, system map, and other information) is on /dev/hda5. The rest of the Linux file system is on /dev/hda8, and a spare volume, /d2, is on /dev/hda6. When you boot with the card, these partitions may show up (using the df command) as:

| Filesystem | 1k-blocks | Used | Available | Use% | Mounted on |
| :--- | :--- | :--- | :--- | :--- | :--- |
| /dev/root | 7931 | 2187 | 5335 | 29% | / |
| /dev/hdc | 45076 | 45076 | 0 | 100% | /mnt/cdrom-real |
| /dev/c-loop | 99184 | 63388 | 35796 | 64% | /mnt/cdrom |
| /dev/hda5 | 7746 | 970 | 6376 | 13% | /mnt/0 |
| /dev/hda6 | 2039792 | 8 | 1936168 | 0% | /mnt/1 |
| /dev/hda8 | 2000204 | 1295376 | 602220 | 68% | /mnt/2 |

This shows that the notebook's /boot, /d2/, and / directories have been mounted under the /mnt/0, /mnt/1, and /mnt/2 directories. Note that for security and protection, any found Linux filesystems are mounted read-only; this means that you will not be able to create, edit, or delete files. You must first un-mount and then remount any desired filesystem in read/write mode. For example, if you would like to create, edit, or delete files on your notebook's root Linux partition (/dev/hda8 in our example), first use the umount command to un-mount the partition like this:

```
root@linuxcare:~$ umount /mnt/2
```

You would then use the mount command to remount the / directory like this:

```
root@linuxcare:~$ mount -t ext2 /dev/hda8 /mnt/2
```

You can then navigate to your notebook’s root directory to create, edit, or delete files. This approach can be especially handy to fix errors in your notebook’s initialization table, `/etc/inittab`, filesystem table, `/etc/fstab`, or startup scripts under the `/etc/rc.d`/`init.d` directory (if you use a Red Hat-based Linux system).

### Pleasant Surprises

When you boot with the card, you’ll find that you can use four different virtual consoles. After you log in, press Alt+F2 to jump to another text-based session. You’ll then see another login prompt (you must use root as the username, and use `linuxcare` as the password). Use the `logout` or `exit` commands to exit a console session, and then press Alt+F1 to return to your original console.

The business card is also full of goodies. You’ll find 424 different Linux commands included on the card. These include several text editors, such as `pico`, `vim`, and `jedit`, along with the Midnight Command graphical file interface command, and sophisticated network utilities, such as `nmap` and `hping2`.

### Using X11

There’s even a subset copy of XFree86’s X11 distribution, version 3.3.5, on the CD! This means that you can try starting X11 during your boot session with the `startx` command like this:

```
root@linuxcare:~# startx
```

If your notebook’s graphics chipset is compatible with the included XF86_SVGA or Xf86_VGA16 servers and a compatible mode-line is found in the CD-ROM’s `/etc/XF86Config` file, you’ll go right into an X11 session using the `fvwm` X11 window manager. If the initial `startx` command does not work, be sure to have your fingers on the Ctrl+Alt+Backspace keys to quickly kill the server! You can also try different color depths by using the `startx` command’s `-- -bpp` options like this:

```
root@linuxcare:~# startx -- -bpp 24
```

This command attempts to start an X11 session using 24 bit-planes, or millions of colors (which, interestingly, worked just fine on an IBM ThinkPad 390X after all other modes, such as `-bpp 15` and `-bpp 16`, failed). However, an even better approach is to create an on-the-fly link to an appropriate XF86Config file! If you look under the `/etc/X11` directory, you’ll see:

```
XF86Config
XF86Config-Dell-gx1-1cd
XF86Config-Dell-opti-1cd
```
