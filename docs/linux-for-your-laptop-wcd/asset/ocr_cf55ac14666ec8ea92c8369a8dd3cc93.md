This is the best option to use before making any changes to your drive settings. Be careful! Other than changing the standby and a few other settings, you can cause your system to become unbootable by using incorrect settings!

You can set your hard drive to immediately go to standby mode by using the `-y` option like this:

```
# hdparm -y /dev/hda
```

```
/dev/hda:
	drive state is:	standby
```

To check your hard drive's power consumption mode, use the `-C` flag:

```
# hdparm -C /dev/hda
```

```
/dev/hda:
	drive state is:	standby
```

You can put your hard drive to sleep (to use no power) with the `-Y` option:

```
# hdparm -Y /dev/hda
```

```
/dev/hda:
	issuing sleep command
```

Use the `-s` option, followed by a number from 1 to 240, to set the timeout before your hard drive goes to standby mode. The numbers are multiplied by 5, so using a value of 6 would cause your hard drive to spin down after 30 seconds of inactivity:

```
# hdparm -S 6 /dev/hda
```

```
/dev/hda:
	setting standby to 6 (30 seconds)
```

By using a combination of hard drive inactivity and software inactivity (see the next section), you can craft a safe and very power-efficient mobile Linux system.

# Controlling Software

For safety's sake, you must decide on the length of intervals between data saves to your hard drive. You should set your word processor auto-save preferences—such as for emacs, WordPerfect, Applix Words, or StarOffice—to reasonable defaults in order to save battery power. Frequent saves to disk cause your hard drive to spin up and down continually, depending on your settings.
