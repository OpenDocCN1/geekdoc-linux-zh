
When finished, select lpd, Restart lpd, and then use the File menu to quit. You can view your new printer’s definition in /etc/printcap by using the less pager like this:

```
# less /etc/printcap
#
# Please don't edit this file directly unless you know what you are doing!
# Be warned that the control-panel printtool requires a very strict format!
# Look at the printcap(5) man page for more info.
#
# This file can be edited with the printtool in the control-panel.
##PRINTPOOL## LOCAL bjc600 36x0 36x0 letter () BJC600 1 ()
lp:\
:sd=/var/spool/lpd/lp:\n:rm#0:\n:sh:\n:lp=/dev/lp0:\n:if=/var/spool/lpd/lp/filter:
```

In this example, the new printer’s name is lp, and its print spool directory is /var/spool/lpd/lp. Note that the :if= entry points to the file /var/spool/lpd/lp/filter. This is Red Hat’s print-filtering shell script, which manages conversion and printing of any documents sent to the new printer lp.

Printing a document from the command line is easy. Use the lpr (line printer) command, along with its -P option, a printer’s name, and the name of a file:

```
# lpr -Plp /usr/share/ghostscript/5.10/examples/tiger.ps
```

In this example, the PostScript graphic tiger.ps will be printed on printer lp. The lpr command starts the printing process, and the file is spooled to printer lp’s directory. The lpd daemon, which reads /etc/printcap when it first starts, notices that a file has appeared in printer lp’s spool directory. It also knows that printer lp has a print filter available. The printing process is handed off, and the filter shell script then converts the PostScript file to HPCL (or not) and sends the file to your printer.

# Infrared Printing

Many notebooks have a built-in IrDA port, usually located on the rear or rear side of the case. This port uses the infrared (light) band to communicate with other IrDA-equipped devices, such as a Palm PDA or a printer. Linux support for IrDA is in the form of loadable kernel modules and a package of support utilities in the irda-utils package. The basic steps for installing IrDA support under Linux (for the Sony 505 laptop series) are outlined in the section "Infrared Port" in Chapter 2, "Taking Inventory."

Linux IrDA development is a moving target, and specific procedures for enabling and using IrDA can (and most certainly will) change with each new Linux kernel. For the latest information and set of IrDA utilities, browse to

http://www.cs.ui.no/linux-irda/

A number of printers are also equipped with an IrDA port. This is a handy feature, especially for mobile Linux users, because you can print without the hassle of hooking up a print cable or logging in to a network. Several portable and desktop printers are reported to work well with Linux and the IrDA utilities. These printers include the following:

- Canon BJC-50, BJC-80
- HP 5M, 5N, 5P, 5MP, 6P, 6MP
- HP LaserJet 2100

# What If I Can’t Find a Printer?

If you don’t have a printer while on the road, but you need hard copy output, there are some alternatives. First, you can always pop into a local print or copy center and put your documents on diskette for reproduction or pay for access to a printer. Another alternative, albeit one that doesn’t provide the best resolution, is to fax your document to a fax machine. Linux supports sending and receiving of faxes using a number of software packages, such as efax, mgotty+sendfax, or (for SuSE Linux users) HylaFax.

> **iBook Support**
>
> In order to use the iBook’s internal modem, you must boot Yellow Dog Linux using Apple’s OpenFirmware boot prompt and the Yaboot boot utility. You can then use the modem to send or receive faxes using Linux fax software.

If you have dial-up access to the Internet, you can try Internet worldwide fax service. Browse to http://linux.codema.com/tc/csmtp.html and read the details about how to send a fax. Using this service, you can e-mail fax documents to nearly any fax machine anywhere in the world. Sending a fax is as easy as this:

```
remote-printer.recipients_name@faxnumber.odd.tpc.int
```

In this example, the recipient’s name is the name of the person you want to receive the fax. The fax number must be a full 10-digit number. Not all U.S. area codes are supported. For example, if you want to send a fax to a person named Joe Piccolo, and you know his fax number in Washington, D.C., compose your e-mail document and then send the message to

```
remote-printer,Joe_Piccolo1@2025551212;1664.tpc.int
```

Your recipient’s fax machine will get a cover page, along with your e-mail message. For a current list of world area codes supported by this free service (along with links to Linux clients you can use to send graphics and text), browse to http://www-usa.tpc.int/fax_cover_auto.html.

# Printing to a Remote Linux Printer

Printing to a network printer is another alternative, and configuring a remote Linux printer is very easy. First, the remote computer with the attached printer should have a properly configured /etc/hosts.lpd file. This file contains the hostnames (or IP addresses) of remote computers allowed to print locally. For example, if your home office has a computer attached to the LAN named lp.service.org, edit that computer’s /etc/hosts.lpd file and add the IP addresses or hostnames of computers you want to grant printing access, such as this:

```
192.168.2.32
apltiva.service.org
green.service.org
laptop3.service.org
...
```

You should then restart the lpd daemon on lp.service.org like this:

```
# /etc/rc.d/init.d/lpd restart
```

If your notebook’s hostname is laptop3.service.org, you’ll be allowed to print to the printer attached to lp.service.org. In order to print to the printer on lp.service.org, you’ll need to know the name of the printer, such as green (which would have a spool directory under the /var/spool/lpd/green directory), and that green is, for example, an HP 400. Run the Red Hat printtool client on your notebook, and then click the Add button. You’ll see the dialog box shown in Figure 14.1. Click the Remote UNIX (lpd) Queue button, and then click OK. You’ll see the Edit Remote UNIX (lpd) Queue Entry dialog box, as shown in Figure 14.4.

Enter a name you’d like to use for the remote HP 400 printer, such as remoteHP400. Next, enter the name of the remote host, such as lp.service.org, and the name of the remote printer on the remote host, such as green. When finished, click the Select button and configure the remote entry to match the printer named green on the remote host. For example, if the remote printer is an HP 400 using a black-and-white inkjet cartridge, configure your filter for a monochrome HP 400. When finished, click OK. Then click OK again to exit the configuration and printer entry dialog boxes. You should then use printtool’s lpd menu to restart lpd.

![](img/70d85e6f4d1ff2750ca2a98ba3d9855c_351_0.png)

> Figure 14.4 Use the printtool Edit Remote Unix printer dialog box to create a remote printer entry for your notebook and select additional input filter options.

You can now use the lpr command’s -P option, along with the printer’s name, such as remoteHP400, to print from your notebook to the printer named green on the computer lp.service.org like this:

```
# lpr -PremoteHP400 mydocument.txt
```

This can be accomplished across a LAN or from anywhere in the world if lp.service.org is properly connected to the Internet.

# Printing to Shared Windows Printers

You can also use the Red Hat printtool client to create a local printer entry for a shared printer attached to a remote computer running Windows. You’ll need to know the computer’s IP address or hostname, know the remote printer’s name, possess a valid username and password for the remote computer, and know the workgroup name or name of the domain for the remote computer. After that, configuration is the same as for a remote Linux computer, and you can easily print to the remote computer with the lpr command and its -P option, followed by the name of your remote printer entry.
