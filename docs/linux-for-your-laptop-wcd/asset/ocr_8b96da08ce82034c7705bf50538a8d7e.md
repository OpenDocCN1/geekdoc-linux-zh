# Installation via NFS

Yet another way to install Linux is through the use of the Network File System (NFS). To set up an NFS installation on a LAN, the remote computer must be running the nfsd daemon and have your computer’s IP address or hostname in its /etc/exports file. For example, if you assign an IP address of 192.168.2.70, the remote computer should have an entry that looks similar to this:

```
/d2/pub                 192.168.2.70    (ro)
```

This entry shows that the computer with the IP address of 192.168.2.70 has read-only access to the /d2/pub directory. The Red Hat software would then be available under this directory. To install Linux via NFS, attach your notebook to the LAN, choose the NFS installation method, and be sure to assign the IP address 192.168.2.70 for the installation. Proceed through the dialog boxes until you come to the NFS Setup dialog box, shown in Figure 4.11.

Enter the remote server’s hostname (or IP address), along with the directory containing the Red Hat software. Select OK and press Enter to begin the installation.
