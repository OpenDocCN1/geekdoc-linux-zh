Unfortunately, BootMagic must be installed using Windows, and configuration is accomplished by a Windows-only utility. Another drawback is that BootMagic must be installed in the MBR of your bootable device. If you use LILO to boot Linux, LILO must then be installed in the root Linux boot partition.

# ## Boot Management with System Commander

System Command Deluxe, a product from Linguiŝt’s Software, is an alternative commercial boot loader that may also be used to boot Linux. Like BootMagic, System Commander can be installed using Windows, but it also offers installation using DOS. According to Linguiŝt’s Software, System Commander can optionally be featured to prohibit hard drive access and use of floppy drives to boot your system. Note that you can also do this by installing a boot loader on your hard drive, disabling removable devices as bootable in your notebook’s BIOS and then password-protecting your BIOS.

# ## Boot Management with LILO

LILO is a free, flexible, capable boot loader you can install using Linux. LILO will boot nearly any operating system installed on your notebook, and it can be easily configured to boot DOS, Windows, FreeBSD, OpenBSD, and others. LILO can also be helpful if you are having a problem with X11, such as a broken XF86Config while your Linux system is set to boot directly to X11. Symptoms include a flashing, repetitive screen as the X server repeatedly tries to run and fails.

You can generally reboot your machine with `Ctrl+Alt+Delete`. Then, at the `LILO` boot: prompt, use `LILO` to tell Linux to boot in the root administrative mode by using the `linux single` option:

```
boot: linux single
```

If that does not work, you can also try this:

```
boot: linux 0
```

This will boot Linux with networking and X11 turned off. You’ll end up at the root prompt and can then proceed to fix any problems. You can also implement password protection using LILO. This requires you to edit the `/etc/lilo.conf` file.

Using your favorite text editor (such as the `pico` editor), open the file like this:

```
$ pico /etc/lilo.conf
```
