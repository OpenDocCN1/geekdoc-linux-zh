# ### Booting to the Rescue Mode

To use the Bootable Business Card to rescue or diagnose your laptop's Linux installation, first be sure that your notebook's BIOS supports booting from CD-ROM. Next, insert the CD-ROM and reboot your notebook. You'll see an initial splash screen. If you wait five seconds, the CD-ROM will boot Debian Linux, and you'll see an initial boot prompt like this:

```
linuxcare login:
```

Log in with the username **root** and use **linuxcare** as the password. After you press Enter, the file **CREDITS-README.txt** will be displayed. Carefully read this file!
