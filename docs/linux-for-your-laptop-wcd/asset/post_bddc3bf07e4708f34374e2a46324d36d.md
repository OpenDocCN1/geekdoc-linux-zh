## X11 Configuration Utilities

X11 may be installed and configured when you install Linux. However, if you run into problems and have to skip X11 configuration, you can later configure X using several utilities:

- **XF86Setup.** Included with XFree86, this is a graphical installation utility used to configure all your notebook’s devices for use with X, such as the keyboard, pointer, graphics chipset, and memory. This X11 application, or *client*, launches a 16-color X server named XF86VGA_16 to provide menus, dialog boxes, and lists.
- **xf86config.** Also included with XFree86, this is a text-based configuration tool that does not require an X server to run. By answering some technical questions regarding your notebook’s keyboard, mouse, graphics chipset, and display, you can quickly build a working XF86Config file.
- **Xconfigurator.** A Red Hat Linux graphical configuration tool that also does not require a running X11 server. Easy-to-use menus and buttons guide you through the process of configuring X to work with Linux and your notebook.

Other distributions, such as Corel and Caldera OpenLinux, use other configuration tools. SuSE Linux uses the *sax* command for X11 configuration.

Once Linux and X11 are installed and configured, you may set up your notebook to boot directly to an X11 session via an X11 *display manager*, such as *xdm*, *gdm*, or *kdm*. If you choose to boot to console (text-only) mode, X11 is generally started with the *startx* command. Using X11 is discussed in more detail in Chapter 9, “Display Issues.”

## Your Notebook’s Sound System

Sound systems vary greatly between notebook computers, and even computers in the same product line from a single manufacturer! Although most notebooks built until recently usually had a separate sound system, the current trend is toward meshing sound and graphics into single-chip subsystems (such as the NeoMagic AV series).

Current Linux distributions support a number of sound cards in desktop and notebook computers. If you’re the fortunate owner of a laptop with a SoundBlaster-compatible sound system, you shouldn’t have any trouble configuring Linux to work with your notebook to be able to play audio CDs, Musical Instrument Digital Interface (MIDI) files, Moving Pictures Experts Group (MPEG) files, QuickTime video, or other sound- and animation-related files.

Sound support under Linux is in the form of loadable kernel *modules*, or pieces of code that load either on demand or into memory when booting. Sound modules are usually configured using load-time options (similar to command-line options) stored in a module configuration file. Under Red Hat Linux, this file is named */etc/conf.modules*, and under Caldera's OpenLinux distribution, the file is named */etc/modules.conf*. For more information on configuring sound, see the section “Configuring Sound” in Chapter 6, “Post-Installation Issues.”

The actual kernel modules usually reside under the */lib/modules/2.2.X/misc* directory, where *X* is the version of the Linux kernel installed on your computer. Other Linux distributions might use different approaches to managing the configuration and initialization of your notebook's sound system, usually done at boot time.

Documentation of the free sound support may be found under the */usr/src/linux/Documentation/sound* directory. Table 2.2 lists a number of files that might or might not match your notebook's sound system.

Other supported sound cards include Media TRIX Audio TRIX Pro, ProAudioSpectrum 16, Rockwell Wave Artist, and Aztec Sound Galaxy.

If you have trouble configuring Linux to work with your notebook's sound system, don't give up! Browse the Linux laptop pages and look for other notebooks with similar sound chips. Chances are good that you can make your sound system work!

An alternative set of sound drivers is available from the Advanced Linux Sound Architecture (ALSA) project at http://www.alsa-project.org

These alternative sound drivers are being created for Linux with the aim of improving the current programming interface for kernel sound support, maintaining compatibility, creating new audio programming support routines, and spurring the creation of new audio clients. Table 2.3 lists 30 types of sound cards and chipsets supported by ALSA. You should know that a currently troublesome notebook sound system, the NeoMagic 256AV, which incorporates graphics and sound features, might also be supported by these drivers.

Installation involves downloading, decompressing, configuring, building, and then installing the kernel modules, support libraries, and associated utilities. Documentation on how to craft proper module configuration files is included.
