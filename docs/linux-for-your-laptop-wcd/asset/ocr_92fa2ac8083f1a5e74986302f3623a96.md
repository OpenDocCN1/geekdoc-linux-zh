If you install Linux but find that LILO fails to boot properly, you can use the LILO start message as a diagnostic (as documented on page 44 of the LILO User Guide). Table 3.4 lists the diagnostics.

Table 3.4  LILO Diagnostics
| Diagnostic | Description |
| :------------- | :----------------------------------------------------------- |
| *blank* | LILO did not load or was not installed |
| L ## | LILO's first stage loaded, but a disk error code (00, 01, 02, 03, 04, or 06) appears; see Section 5.2.2 of the LILO User Guide (page 44 of the guide) |
| LI | LILO's first and second stages loaded, but a disk geometry problem or a LILO map installer problem prevented execution (see Section 3.4 of the User Guide) |
| LIL | LILO's second stage loaded, but a geometry or media failure occurred |
| LIL? | LILO's second stage loaded, but at an incorrect address (perhaps the same problem as LI) |
| LIL- | A corrupted descriptor table prevented proper execution (see the User Guide) |

If you have problems, read the LILO User Guide, found under the */usr/doc/lilo*/doc directory. If you're running Linux, use the `gv` command to display the file like this:
``` 
> gv /usr/doc/lilo*/doc/User*ps 
```

You should also create a backup boot diskette with LILO installed. See Section 4.1.6 (page 37) of the User Guide for details.
