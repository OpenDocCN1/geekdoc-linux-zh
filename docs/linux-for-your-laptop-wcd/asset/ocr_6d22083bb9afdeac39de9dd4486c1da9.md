# What Is Linux?

Linux is a POSIX-compliant, UNIX-like operating system that has inherited the best features of SysV and BSD UNIX. Linux is the *kernel* (core) of the operating system, and a *Linux distribution* is a collection of software accompanying Linux. Linux is a fast, reliable operating system that runs on many different types of computers, including CPUs from Sun, Compaq, Motorola, and Intel.

Linux was originally envisioned as a desktop operating system, but programmers from around the world have contributed source code, patches, and enhancements to make Linux a viable server operating system with capabilities far exceeding its original design. Linux provides an incredible spectrum of support for networking protocols, filesystems, and hardware devices.

# How to Pronounce Linux

According to Linus Torvalds, Linux is pronounced “Lib-nucks” (somewhat like “linen”). Red Hat Linux users will find a short audio clip named `sample.au` under the `/usr/share/sndconfig` directory. You can play this clip, which is a recording of Linus pronouncing Linux, using Red Hat’s `sndconfig` command after successfully configuring Linux to match your computer’s sound card. You can also find a copy at Eric S. Raymond’s home page at http://www.tuxedo.org/~esr/faqs/linus/english.au

# A Short History

Linux has been popular almost since the early days of its release. Although its potential was recognized by only several hundred users, interest in Linux grew exponentially, surging to more than 100,000 users in a couple of years to an audience of more than 15,000,000 today.
