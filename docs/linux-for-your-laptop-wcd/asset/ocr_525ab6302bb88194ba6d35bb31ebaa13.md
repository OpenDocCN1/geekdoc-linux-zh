maybe a copy of an actual time zone database file. You can use the `ls` command to see if the file is a link like this:

```
# ls -l /etc/localtime

lrwxrwxrwx 1 root root 32 Feb 17 1999 /etc/localtime -> ../usr/share/zoneinfo/US/Eastern
```

In this example (from a Red Hat system), the time zone is set to EST, known as Eastern Standard Time.

When you boot Linux, the `/etc/rc.d/rc.sysinit` system initialization script uses the `hwclock` command to set the system time. Options for the `hwclock` command are kept in the `/etc/sysconfig/clock` file, and they use settings such as this:

```
ZONE="US/Eastern"
UTC=false
```

You can change this file manually, create your own symbolic link, or use the Red Hat `timeconfig` command to set the time zone. This command may be run (as root) from the console or a command line of an X11 terminal window:

```
# timeconfig
```

After you press Enter, you see the dialog box shown in Figure 16.2.

Use the Tab key to move to different buttons and the up and down cursor keys to select a time zone. Use the spacebar to toggle the selection of the Hardware clock setting to UTC. Navigate to the OK button and press Enter after making your choices.
