## Maximizing Drive Space

Linux comes with many different drive utilities that work with different types of storage media, ranging from floppies to hard drives to flash RAM cards. Most of these utilities are designed to make Linux work better with your hardware, but in some cases you can squeeze out a little extra performance and storage area by running these programs.

Table 8.1 lists just some of the commands normally included with a Linux distribution. You'll learn about some common uses for these commands in the following sections.

## Using Floppy Disks

Most notebooks (with the exception of the Apple iBook) come with an internal or external floppy disk drive. Linux supports the floppy fdisk through a generic device, such as /dev/fd0, for the first drive or specific devices, like this:

```
$ ls /dev/fd*
/dev/fd0        /dev/fd0360     /dev/fd0u3200   /dev/fd1h1440   /dev/fd1h720
/dev/fd0360     /dev/fd0h1200   /dev/fd0u3520   /dev/fd1h360    /dev/fd1u1440
/dev/fd0720     /dev/fd0u360    /dev/fd0u3840   /dev/fd1h720    /dev/fd1u2880
/dev/fd0h1440   /dev/fd0h720    /dev/fd1        /dev/fd1360     /dev/fd1u3200
/dev/fd0h360    /dev/fd0u1440   /dev/fd1360     /dev/fd1h1200   /dev/fd1u3520
/dev/fd0h720    /dev/fd0u2880   /dev/fd1h720    /dev/fd1h360    /dev/fd1u3840
```

You can tell which floppy devices Linux has recognized by using the dmesg command after booting:

```
$ dmesg
...
Floppy drive(s): fd0 is 1.44M
```

FDC 0 is a post-1991 82077
...

In this example, a single 1.44MB floppy drive (FDC 0) has been recognized. You can use normal Linux drive and volume managers to manipulate an inserted floppy. Most Linux distributions install with a default /mnt/floppy directory, but you can make one of your own (as root) like this:

```
# mkdir /mnt/floppy
```

If you insert a DOS-formatted floppy, you can then mount the floppy and make it available under Linux like this:

```
# mount -t vfat /dev/fd0 /mnt/floppy
```

This command makes the contents of the floppy (which uses vfat, or long file name support) appear under the /mnt/floppy directory. You can then use the normal Linux commands—such as ls, cp, mv, and rm—to list, copy, rename, or delete files on the floppy at that directory. After working with the floppy, you should unmount the diskette using this command:

```
# umount /mnt/floppy
```

Most Linux distributions also come with a floppy entry in the filesystem table, /etc/fstab, which might look like this:

```
/dev/fd0       /mnt/floppy           auto    sync,user,noauto   0 0
```

This entry shows that the first floppy drive is normally mounted under the /mnt/floppy directory. Linux will try to automatically determine the proper filesystem, and any user may read or write to the floppy.

However, by using other utilities, such as those included with the mtools package, you can get around having to mount and then unmount the floppy drive—which is much more convenient! For example, stick a DOS boot floppy in your notebook, and then use the mdir command like this:

```
# mdir a:
Volume in drive A has no label
Volume Serial Number is 15FA-2C24
Directory for A::
COMMAND   COM    93880  05-11-1998  19:01
AUTOEXEC  BAT      438  01-03-2000  15:44
CHOST     COM     5239  05-11-1998  20:01
CONFIG    SYS     1020  01-03-2000  15:02
DELTRH3   EXE    19083  05-11-1998  20:01
```
