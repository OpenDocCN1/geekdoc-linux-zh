You can then navigate to your notebook’s root directory to create, edit, or delete files. This approach can be especially handy to fix errors in your notebook’s initialization table, `/etc/inittab`, filesystem table, `/etc/ fstab`, or startup scripts under the `/etc/rc.d`/`init.d` directory (if you use a Red Hat-based Linux system).

# Pleasant Surprises

When you boot with the card, you’ll find that you can use four different virtual consoles. After you log in, press Alt+F2 to jump to another text-based session. You’ll then see another login prompt (you must use root as the username, and use `lncare` as the password). Use the `logout` or `exit` commands to exit a console session, and then press Alt+F1 to return to your original console.

The business card is also full of goodies. You’ll find 424 different Linux commands included on the card. These include several text editors, such as `pico`, `vim`, and `jedit`, along with the Midnight Command graphical file interface command, and sophisticated network utilities, such as `nmap` and `hping2`.

# Using X11

There’s even a subset copy of XFree86’s X11 distribution, version 3.3.5, on the CD! This means that you can try starting X11 during your boot session with the `startx` command like this:

```
root@lncare:~# startx
```

If your notebook’s graphics chipset is compatible with the included XF86_SVGA or Xf86_VGA16 servers and a compatible mode-line is found in the CD-ROM’s `/etc/XF86Config` file, you’ll go right into an X11 session using the `fvwm` X11 window manager. If the initial `startx` command does not work, be sure to have your fingers on the Ctrl+Alt+Backspace keys to quickly kill the server! You can also try different color depths by using the `startx` command’s `-- -bpp` options like this:

```
root@lncare:~# startx -- -bpp 24
```

This command attempts to start an X11 session using 24 bit-planes, or millions of colors (which, interestingly, worked just fine on an IBM ThinkPad 390X after all other modes, such as `-bpp 15` and `-bpp 16`, failed). However, an even better approach is to create an on-the-fly link to an appropriate XF86Config file! If you look under the `/etc/X11` directory, you’ll see:

```
XF86Config
XF86Config-Dell-gx1-1cd
XF86Config-Dell-opti-1cd
```
