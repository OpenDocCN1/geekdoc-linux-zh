Navigate to the new pcmcia directory, and then use the Configure script to set up and create a makefile, like this:

```
# ./Configure
```

After you press Enter, you might see this:

------ Linux PCMCIA Configuration Script ------

The default responses for each question are correct for most users.
Consult the PCMCIA-HOWTO for additional info about each option.

Linux source directory [/home2/rpn/BUILD/linux]: /usr/src/linux

Type /usr/src/linux to specify the Linux kernel source directory (this works with Red Hat and Mandrake Linux), and then press Enter. You will see the following:

The kernel source tree is version 2.2.14-15mdk.
The current kernel build date is Tue Jan 4 22:24:20 2000.

Alternate target install directory [/var/tmp/kernel-2.2.14-15mdk-root]:

The Configure script will recognize the current Linux kernel and then offer an alternative installation directory. If you're not worried about overwriting your original modules, you can use the default setting and press Enter. You'll then be asked the following:

Module install directory [/lib/modules/2.2.14-15mdk]:

This step is critical if you want the new Card Services PCMCIA kernel modules to work with your system. If you accept the default settings, the new modules will overwrite your existing ones. If you just want to see if the modules will build, specify an alternative directory and press Enter.

Build 'trusting' versions of card utilities (y/n) [y]:

This option is used to create modules that may be used by anyone on your notebook---not just the root operator. Type y or n, and then press Enter.

Include 32-bit (CardBus) card support (y/n) [n]:

If you use newer CardBus PC cards, press Enter. Note that fewer CardBus cards are supported than older 16-bit PC cards.

Include PnP BIOS resource checking (y/n) [n]:

Unless you need your notebook's BIOS to help configure your card, use the default option, n, and press Enter.
