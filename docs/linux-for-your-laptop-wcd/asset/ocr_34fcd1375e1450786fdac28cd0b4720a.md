# X11 Configuration Utilities

X11 may be installed and configured when you install Linux. However, if you run into problems and have to skip X11 configuration, you can later configure X using several utilities:

+   * **XF86Setup.** Included with XFree86, this is a graphical installation utility used to configure all your notebook’s devices for use with X, such as the keyboard, pointer, graphics chipset, and memory. This X11 application, or *client*, launches a 16-color X server named XF86VGA_16 to provide menus, dialog boxes, and lists.
+   * **xf86config.** Also included with XFree86, this is a text-based configuration tool that does not require an X server to run. By answering some technical questions regarding your notebook’s keyboard, mouse, graphics chipset, and display, you can quickly build a working XF86Config file.
+   * **Xconfigurator.** A Red Hat Linux graphical configuration tool that also does not require a running X11 server. Easy-to-use menus and buttons guide you through the process of configuring X to work with Linux and your notebook.

Other distributions, such as Corel and Caldera OpenLinux, use other configuration tools. SuSE Linux uses the *sax* command for X11 configuration.

Once Linux and X11 are installed and configured, you may set up your notebook to boot directly to an X11 session via an X11 *display manager*, such as *xdm*, *gdm*, or *kdm*. If you choose to boot to console (text-only) mode, X11 is generally started with the *startx* command. Using X11 is discussed in more detail in Chapter 9, “Display Issues.”

# Your Notebook’s Sound System

Sound systems vary greatly between notebook computers, and even computers in the same product line from a single manufacturer!
