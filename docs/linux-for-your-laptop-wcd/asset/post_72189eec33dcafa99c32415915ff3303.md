This chapter details some of the preliminary requirements for installing and using Linux. You'll learn about installing custom setups for configuring your notebook as a workstation or server. You'll also learn how to install a minimal distribution with or without the X Window System (the graphical interface for Linux).

Understanding the hard drive and storage requirements for using Linux is important. It can help you best allocate the most precious of resources in a notebook: the storage capacity of an internal hard drive. Some fortunate notebook owners have laptops with removable hard drives, or they have the ability to easily swap out the internal fixed drive. However, most notebooks come with a single, fixed drive that may provide anywhere from several hundred megabytes of storage to 25GB, currently the largest-capacity drive for notebooks.

## Defining Workstations and Servers

The Linux kernel supports your notebook as both a workstation and a server. Running Linux as a server can require more drive space, especially if you plan to support multiple users. However, configuring your notebook as a workstation can also tax your laptop's peripherals and drive storage much more than configuration as a server. It all depends on how you plan to use your notebook.

Linux servers require only a few basic essential services and software to be installed, but some of these services can require enormous amounts of drive storage. Some of these services include Domain Name Service (DNS) and Internet News (INN). Depending on how you configure your notebook, you may also enable FTP, telnet, Session Message Block (SMB) service using Samba (to show all or some of your notebook's hard drive as a shared volume, or for sharing an attached printer), or Apache for running a Web server. Other services include remote UNIX printer support, electronic mail, and firewalling as a gateway for Internet services.

On the other hand, when installing and configuring a Linux workstation, you might have not only all of these services in place, but also much additional software, such as the X Window System, various window managers, fonts, multimedia applications, and other productivity clients. Developers (programmers) will also install a variety of languages and support libraries, such as when programming in C, C++, or Java. These requirements can place an extra burden on your notebook in terms of CPU, RAM, and storage resources.

### Planning Considerations

New mobile Linux users usually choose to install as much software as possible when first using Linux. Considering that some Linux distributions (such as SUSE) now include up to six CD-ROMs of software, this can be a daunting and lengthy task. Fortunately, nearly every distribution includes a choice selection of the very best free software on a single installation CD-ROM. This is still true of Red Hat, Mandrake, and Yellow Dog Linux, although you'll find that commercial versions also include additional software (such as Yellow Dog's "Tasty Morsels" CD-ROM).

Experienced mobile Linux users are cognizant of their notebooks' limitations. They plan new installations or upgrades according to the manner in which the notebook will be used (such as for development, server operations, text editing, graphics editing, or mobile communications). Part of this planning includes creating a strategy for disk use and deciding how much disk space to allocate for Linux software, temporary storage, additional storage, future expansion, or other operating systems. This is called developing a *partitioning* strategy.

#### Plan and Pick Partitioning Strategies

See Chapter 5, "Starting the Installation," for details about how to allocate software on your hard drive for Linux. You'll learn about how Linux organizes its directories, *or file system*, and how to make the most out of your hard drive space.

Before you install Linux on your notebook, you need to ask yourself the following questions:

- How much disk space is available on my notebook?
- Will I boot one or more operating systems?
- If I boot more than one operating system, how much disk space should be allocated to each?
- Do I need to keep separate disk space free (such as for backups or temporary files)?

Before you proceed to an installation, you should also understand the different requirements and options you can use to make your Linux experience easier on a notebook. It's not fun if you find you can't install additional applications, if you fill up your home directory, or if you run out of hard drive space when recompiling a kernel!

Installing a workstation and choosing what software to install can be confusing, especially if you're new to Linux and haven't developed a preference for your development tools, computer language of choice, or window manager or environment for X11. Don't worry. Experienced mobile Linux users learn how to pick and choose the right mix of software tools and information to install, and you will too!

At a minimum, you will need a base installation for both workstation and server operations. This includes the Linux kernel, along with a number of .rpm packages included on your Red Hat, Mandrake, or Yellow Dog Linux CD-ROM. ### Running a Server

When you configure your notebook to run as a Linux server, you'll need to add additional software. Nearly all server software runs in the background (invisible to you at the command line). These server processes are known as daemons.
