# **A Note of Thanks**

Mobile Linux users owe a big debt of gratitude to David Hinds, who created and maintains the core software that provides PCMCIA support for Linux. Because of his and others' efforts, Linux users can use and enjoy hundreds of different PC card devices. The PCMCIA software, named Card Services, consists of nearly a dozen or more kernel modules. Card Services was originally distributed as a separate software package for Linux, but over the last year or so this critical notebook software has been incorporated into the Linux kernel source code tree. Kudos to David and other PCMCIA programmers!
