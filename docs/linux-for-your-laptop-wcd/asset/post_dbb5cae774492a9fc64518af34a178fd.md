
# Vendor Splendor

While this book was being developed, a number of notebook manufacturers and vendors stepped forward to offer Linux on a notebook. In February 2000, Dell Computer Corporation started offering Linux on one model of its Inspiron 5000 series of laptops (interestingly, without any fanfare). Other vendors, such as Tuxtops (http://www.tuxtops.com), have arrived on the scene to provide an alternative software platform for several models of laptops. # Using a Boot Manager

As you know, there are a number of ways to install and boot Linux. How you decide to start Linux on your notebook is up to you. There are ways to boot multiple operating systems and multiple ways to set up your notebook for booting these operating systems.

If security is an issue, you can also set up your boot manager to use a password. An even better approach is to put the boot manager on a removable device, such as a floppy, and also require a password. Although no hard drive is secure unless it is removable and under lock and key, you can take some basic steps to protect your data.

Every Linux distribution comes with two or more boot utilities. The most commonly used utility is the Linux Loader (LILO). This boot manager may be installed in the Master Boot Record of your notebook’s hard drive, in your Linux root partition, or on a floppy. Other boot managers include PowerQuest’s BootMagic (which might be included as value-added software with some commercial Linux distributions).

## Boot Management with BootMagic

BootMagic is a boot-loader utility that supports a number of different operating systems. The program basically provides a graphical interface in which you can use the mouse or keyboard to select and boot an installed operating system on your notebook. BootMagic is most often installed along with PowerQuest’s commercial partitioning utility, PartitionMagic.

Unfortunately, BootMagic must be installed using Windows, and configuration is accomplished by a Windows-only utility. Another drawback is that BootMagic must be installed in the MBR of your bootable device. If you use LILO to boot Linux, LILO must then be installed in the root Linux boot partition.

## Boot Management with System Commander

System Command Deluxe, a product from Linguist Software, is an alternative commercial boot loader that may also be used to boot Linux. Like BootMagic, System Commander can be installed using Windows, but it also offers installation using DOS. According to Linguist Software, System Commander can optionally be featured to prohibit hard drive access and use of floppy drives to boot your system. Note that you can also do this by installing a boot loader on your hard drive, disabling removable devices as bootable in your notebook’s BIOS and then password-protecting your BIOS.

## Boot Management with LILO

LILO is a free, flexible, capable boot loader you can install using Linux. LILO will boot nearly any operating system installed on your notebook, and it can be easily configured to boot DOS, Windows, FreeBSD, OpenBSD, and others. LILO can also be helpful if you are having a problem with X11, such as a broken XF86Config while your Linux system is set to boot directly to X11. Symptoms include a flashing, repetitive screen as the X server repeatedly tries to run and fails.

You can generally reboot your machine with `Ctrl+Alt+Delete`. Then, at the `LILO` boot: prompt, use `LILO` to tell Linux to boot in the root administrative mode by using the `linux single` option:

```
boot: linux single
```

If that does not work, you can also try this:

```
boot: linux 0
```

This will boot Linux with networking and X11 turned off. You’ll end up at the root prompt and can then proceed to fix any problems. You can also implement password protection using LILO. This requires you to edit the `/etc/lilo.conf` file.

Using your favorite text editor (such as the `pico` editor), open the file like this:

```
$ pico /etc/lilo.conf
```

You can then insert the **password=** entry, along with an unencrypted password. (Hint: Don't use the same password that you use to log in to Linux!) For example:

```
image=/boot/vmlinux
  label=linux
  password=abcd
  initrd=/boot/initrd
```

Make your changes and save the file (press **Ctrl+X** if using **pico**). You must then run **lilo** to write the new boot loader, like this:

```
# /sbin/lilo
```

The next time you reboot, you'll see the **LILO** prompt:

```
LILO boot:
```

Press **Enter**, and you'll see this:

```
Password:
```

Enter your password and press **Enter** to boot. (Super Hint: You can assign a different password to each operating system boot section configured in **/etc/lilo.conf**! If you have enabled your notebook's BIOS startup password, this means that three passwords might be required to use Linux!)

One potential problem with booting can happen if you install Linux and then install another operating system, such as Windows. Other operating systems typically wipe out the MBR of your notebook's hard drive, and LILO will disappear, potentially rendering you unable to boot to Linux. The best approach is to install LILO after all other operating systems have been installed on your notebook. This includes the BSDs, BeOS, and OS/2.

LILO can also help you install Red Hat Linux on notebooks with troublesome IDE controllers. The LILO boot prompt can be used to pass messages, or arguments, to the Linux kernel. For example, experienced IBM ThinkPad 600x (and perhaps 570) users would use this:

```
linux hda=1558,240,63 hdc=cdrom
```

at the LILO boot: prompt to enable Linux to recognize the internal hard drive and CD-ROM drive (if available). The **hda=** entry specifies the device name of the hard drive (**/dev/hda**) and provides settings inscribed on the drive. These settings represent the number of cylinders, sectors, and heads in the hard drive. These options may also be used during the Red Hat installation. They are inserted into the LILO configuration dialog box as an option, like this:

```
`append = 'hda=1024,12,63'`
```

This option enables Linux to boot on the ThinkPad 701 series of notebooks. If you're having trouble installing or booting Linux due to LILO errors, see "Boot Loaders and Pitfalls" in Chapter 3. You should also check the Linux laptop pages for solutions for your notebook. (If you have a popular notebook from a well-known manufacturer, chances are good that someone has installed Linux before you and might have solved any serious technical problems.)

To uninstall LILO, you can use the DOS `FDISK` command with its `/MBR` option. Boot your notebook to DOS, and then use this:

```
`C:> FDISK /MBR`
```

To uninstall LILO under Linux, use the `lilo` command, along with its `-u` (uninstall) option:

```
`# lilo -u`
```

Make sure you have a boot disk on hand or are sure you want to uninstall LILO!

# Apple iBook Boot Management with BootX

Apple iBook Linux users can boot Linux in at least two ways. The first way uses Apple's OpenFirmware boot ROM in the iBook, along with a utility named Yaboot. The second, easier, and more common way is to use the BootX Control Panel device, launched after your Mac starts.

The Yaboot utility is somewhat similar to LILO, and uses somewhat similar syntax in its configuration file. One benefit of using Apple's Open Firmware prompt and Yaboot is that you will be able to use the internal iBook modem. To boot Linux using the Yaboot boot loader (included on the Yellow Dog Linux CD-ROM), copy the files vmlinux, yaboot.tbxl, and yaboot.conf to your iBook's hard drive while running MacOS. Edit the yaboot.conf file to look like:

```
`timeout=5
default=linux

image=hd:8,/vmlinux
label=linux
root=/dev/hda10

novideo`
```
