
+   XF86Config-Matrox-g200
+   XF86Config-crt-lcd
+   XF86Config-old
+   XF86Config-neomagic
+   XF86Config-dell_gx1_lcd

If your notebook can use one of these tailored XF86Config files, you can then force the XF86_SVGA server to use the file. Use the *ln* command to create a symbolic link named XF86Config in the */root* (not */*) directory that points to the correct XF86Config file. For example, if your notebook uses a NeoMagic graphics chipset, use the *ln* command like this:

```
root@inxware:~# ln -s /etc/X11/XF86Config-neomagic XF86Config
```

You can then use the *startx* command to jump into a proper X11 session! Note that the link will only be good for the currently running session; when you reboot your notebook, the file will disappear. You'll find a number of X11 and Internet clients included on the CD-ROM, such as the *Amaya* and *lynx* Web browsers, the *rxvt-xterm* terminal client, and the *ftp* and *telnet* commands. To exit your X session, either click in an empty area of the desktop and choose the *Exit Fvwm* menu item, or press Ctrl+Alt+Backspace to kill the X server.

And, as a special treat, the CD-ROM also has an Easter egg! At the console command line type:

```
root@inxware:~# SVGATextMode | egg
```

> Hint: Use the Down arrow key to slow down and the *q* key to quit!

When you have finished fixing any problems, navigate back to your root directory (just type *cd* and press Enter), and make sure to unmount any filesystems that have been mounted.

## Installing Debian GNU/Linux

As you know by now, there are many different ways to install Linux, and there are many different Linux distributions. Your Bootable Business Card contains a hacked version of the Debian GNU/Linux. You can get a full version of Debian GNU/Linux by browsing to http://www.debian.org

Debian GNU/Linux differs from other Linux distributions in that there is strict adherence to code quality and licensing. Generally, Debian GNU/Linux distributions include only software packages that meet the Debian Free Software Guidelines. While this may seem restrictive, current full distributions include more than 2,250 software packages that meet Debian's “Social Contract” and Free Software Guidelines. You can read about these guidelines and the contract by browsing to http://www.debian.org/social_contract

## Starting the Install

To perform a straightforward installation, set your notebook's BIOS to boot from CD-ROM. Then, insert the card in your notebook's CD-ROM drive, and reboot. At the first boot prompt, type **boot:** `debian`. You'll then be asked to select a color or monochrome display, as shown in Figure B.1. Use the **Up** or **Down** arrow keys and press Enter to select your display, and then select the line **Next** : `: Continue with the installation`. After you press Enter, you'll be presented a screen of information regarding the card's particular version of the Debian Linux. After reading, press Enter. You'll then see a screen that presents a menu. Use the **Up** or **Down** arrow keys and press Enter to select the line **Next** : `: Configure the keyboard`. After you press Enter, you'll be presented a menu of keyboards, as shown in Figure B.2. Use the **Up** or **Down** arrow keys and press Enter to select your keyboard. After you press Enter, the installer will attempt to find a Linux swap partition. If one is not found, you’ll be presented a menu and asked to start partitioning. Use the Up or Down arrow keys and press Enter to select Next : Partition a Hard Disk.
