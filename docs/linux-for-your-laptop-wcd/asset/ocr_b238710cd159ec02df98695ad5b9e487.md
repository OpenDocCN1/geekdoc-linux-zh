You can view sample character sets of the installed fonts for your system by using the *xfontsel* client during your X11 session. Start the client from the command line of an X11 terminal window like this:

$ xfontsel &

After you press Enter, you'll see the window shown in Figure 6.8. It lists the number of fonts and gives drop-down menus you can use to view different font families. There are ways to improve your desktop's display resolution and font appearance. Browse to Doug Holland's Linux Font De uglification mini-HOWTO at http://www.linuxdoc.org/HOWTO/mini/FDU.html

You'll find that you can possibly improve your X11 session appearance by following several simple steps:

+   1. Reorder font choices in your XF86Config or xfs config file.
+   2. Start your X server to use more dots per inch with a 100dpi option.
+   3. Add TrueType fonts.
+   4. Change a desktop style setting in KDE's Control Center.
+   5. Change Netscape Communicator's Font Preferences.
