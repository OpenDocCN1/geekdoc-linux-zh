# Set ghost Permission First?

Note that you might have to first use the ghost client in order to allow the remote computer to display an image locally:

```
$ ghost + workhorse
```

You should then see the remote image displayed on your local computer. The mcam client has many different features:

+   - Exposure, brightness, contrast, and color balance settings
+   - Full remote control from another computer
+   - Image compression
+   - Image capture
+   - Frame and animation grabbing
+   - Internet server mode
+   - Password control
+   - Small (176×144-pixel) and big (352×288) picture sizing
+   - JPEG coding
+   - MPEG picture coding
+   - Time and date (local or UTC) display in the image
+   - Image tiling
+   - Statistics reporting

Uses for a webcam are limited only by your imagination. Many are used for security, traffic and weather monitoring, or videoconferencing. You're sure to come up with your own ideas if you use one with Linux and your notebook!
