## Using Microphones

Another input device commonly included with many notebooks today is the built-in microphone. Many laptops also have a line-in port alongside a headphone or stereo output jack. Linux readily supports microphone recording, but you must have properly configured Linux to work with your notebook’s sound system.

### Recording Utilities

There are many different types of recording utilities for Linux, but few Linux distributions include actual sound recording software. Although several sound mixer clients are always found on every Linux distribution’s CD-ROM, you might have to search for, download, and build your own recording software. This is not difficult, because directions are generally included with the software’s archive, either in tarball (.tgz) or .rpm format.

You might be able to find a number of clients through links such as <http://www.linuxstart.com/applications/multimedia/audiosound.html>, <http://www.freshmeat.net>, or, if you’re a KDE user, <http://www.kde.org>.

However, to jump right to one of the best voice recording software clients for Linux, the KDE `krecord` client, browse to Gerd Knorr’s home page at <http://me.in-berlin.de/~kraxel/krecord.html>. You can download, and then build and install, the `krecord` client quickly and easily. For example:

```bash
$ tar xvfz krecord*tar*
$ cd krecord*
$ ./configure
$ make
$ make install
```

That’s all there is to it! Of course, you should have KDE installed to begin with. You should also decide whether you will use your notebook’s built-in microphone or a separate microphone attached to your notebook’s line-in jack.

Be sure to restart the KDE desktop’s panel after installing `krecord` (to update your desktop KDE menus). You can then start `krecord` from the desktop panel’s Multimedia menu, or from the command line of an X11 terminal window like this:

```bash
$ krecord &
```

You’ll then see the dialog box shown in Figure 10.7.

The `krecord` client has a number of familiar buttons and controls, such as record, stop, play, fast-forward, and rewind. But before you begin recording, be sure to set your microphone or line-in input up and your volume output down. Otherwise, you’ll get a lot of squelch, feedback, background noise, or no recording at all. Start the `kmix` client from KDE’s Multimedia menu, and then adjust the controls as shown in Figure 10.8.

After recording, you can save your new .wav file in your home directory. This format is supported by Linux, and you can then play back the sound using any of the myriad sound-playing utilities included with Linux (such as `play`).

## Video Capture

The inexpensive, compact all-digital video camera, also known as video capture, video cam, or webcam, is a relatively new breed of input hardware that is even appearing as a built-in device in some notebooks (such as the Sony C-1X). These cameras typically attach to your notebook through either the parallel port or the USB port. Many parallel-port webcams are compatible with Linux, and USB support will soon arrive with the newer Linux kernels. A number of these cameras, especially those using the Color Processor Interface ASIC (CPIa) chip, are readily supported under X11 through different software packages.

This section demonstrates how to use the inexpensive parallel-port version of the Zora webcam included with White Pine’s CU-SeeMe Cam Kit, a CPIa-based camera that provides 8-bit color, 100,000-pixel resolution, and up to 30 frames per second transmission. You’ll require a notebook that provides a parallel port supporting ECP mode. The camera is powered by your notebook’s keyboard port but plugs into the printer port for use.

### Using the mcam Client with Linux

Using a webcam with your notebook is easy! For example, you can download Jan Pantelje’s mcam software package (see the following section, “Resource Information”), unpack the software archive, and then build and install the software, like this:

```bash
# tar xrvf mcam.gz
# cd mcam*
# xmrf
# make
# make install
```

The `mcam` command, which can be run as a server and as a viewing client, will be installed under the `/usr/local/bin` directory. This command also works with the Creative Labs Video Blaster II webcam and many other CPIa chip webcams. The `mcam` command is generally used during an X11 session, although you can run it on a computer that is not running X to serve images over a LAN or the Internet.

To get started, attach the webcam to your notebook, orient the camera module so that it is not pointing at a light source, and make sure you're running X. Next, as root, start the program like this from the command line of a terminal window:

```bash
# mcam
```

You’ll see a full page (nearly 60 lines) of command information. Press `5`, and then `p`, and then `9`, and you should see an image appear in an X11 window, as shown in Figure 10.10.

If your notebook is attached to a LAN or the Internet, you can use `mcam` in its server mode to offer continuous image scans. Start `mcam` like this:

```bash
# mcam -s
```

On a remote computer, install the `mcam` client, and then connect to the computer, perhaps named `workhorse`, running the `mcam` server like this:

```bash
# mcam -c -a workhorse
```

![](img/70d85e6f4d1ff2750ca2a98ba3d9855c_272_0.png)

Figure 10.10 The mcam X11 client displays continuous image information from a webcam attached to your notebook.

#### Set ghost Permission First?

Note that you might have to first use the `ghost` client in order to allow the remote computer to display an image locally:

```bash
$ ghost + workhorse
```

You should then see the remote image displayed on your local computer. The `mcam` client has many different features:

- Exposure, brightness, contrast, and color balance settings
- Full remote control from another computer
- Image compression
- Image capture
- Frame and animation grabbing
- Internet server mode
- Password control
- Small (176×144-pixel) and big (352×288) picture sizing
- JPEG coding
- MPEG picture coding
- Time and date (local or UTC) display in the image
- Image tiling
- Statistics reporting

Uses for a webcam are limited only by your imagination. Many are used for security, traffic and weather monitoring, or videoconferencing. You're sure to come up with your own ideas if you use one with Linux and your notebook!
