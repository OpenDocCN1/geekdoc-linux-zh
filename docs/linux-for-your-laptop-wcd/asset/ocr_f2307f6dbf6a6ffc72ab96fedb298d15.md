# Using Linuxconf

The linuxconf command, which can be used with or without X11, continues to evolve and grow in popularity as a system maintenance tool when using a graphical interface to administer Linux. This client features configuration and control for nearly all network and system services for Linux. If you use Red Hat or Mandrake Linux, look under the /usr/lib/linuxconf/help.eng directory for HTML help files, or use linuxconf's built-in help buttons.

# Workstation and Server Requirements

According to Red Hat, Inc., typical requirements are 1.6GB for server operation, 450MB for workstation use, and 120MB for a minimal installation. According to the Mandrake Linux folks, a full Mandrake Linux installation requires a little more than 1GB.

Installing everything included with Yellow Dog Linux on your Apple iBook requires at least 1.5GB.

How much disk space your installation will require also depends on the amount of software you choose to install. When you install Linux, you'll be asked to choose a type of installation. You'll also have the chance to avoid a “default” type of installation and can instead pick and choose your own software packages. This is a good way to avoid installing redundant or unnecessary software. For example, do you really need six different text editors available on your system?

If you're a new user and you have the disk space, go ahead and install everything. You can always go back and remove software to make more room. As you gain experience, you'll be able to quickly run through a new installation on your notebook, and you will know what packages are essential or may be omitted from the installation.
