### Linux Distribution Links

In the beginning, there was only the Linux kernel. In the early days, the number of distributions, such as Yggdrasil and Slackware, was very limited. However, within several years (and especially in the last two years) the number of Linux distributions exploded as companies rushed to develop and improve installation, performance, and features. Table A.3 lists links to some of the more popular commercial and noncommercial distributions. (All sites have links to free software downloads.)

The Linux distributions listed in Table A.3 are generally based on CD-ROM distributions (with the exception of Slackware, uClinux, and Elks). But what if you just want to try to run Linux without going through the hassle of partitioning and waiting for an installation? In this case, you can turn to a floppy-based Linux distribution that will have you up and running in only a minute or so.

### Used or Refurbished Laptops

If you want to save some money, you can buy a used or refurbished laptop. Generally, you should avoid online auctions or other types of sales and only buy direct from the manufacturer. This way, you can get some warranty protection, and you know who you're dealing with. If your new notebook has to go in for repairs, don't be surprised if you find out that it has been fixed with used parts. Many manufacturers routinely recycle notebook elements that can be salvaged from returned or repaired units and use those parts to fix new computers. Table A.7 lists some sources of refurbished and used notebooks. Caveat emptor!

### Mailing Lists

If you're an avid e-mail fan, and you want to participate in discussions about notebooks and Linux, subscribe to a Linux laptop mailing list. These lists work by sending an incoming message from a subscriber to all other subscribers. Queries and replies can be almost instantaneous, depending on how the mail list is set up. Many lists also provide a daily or twice-daily digest. Table A.8 lists some popular notebook-oriented Linux mailing lists.
