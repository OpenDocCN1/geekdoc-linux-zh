You’ll be asked to enter the file-sharing password you assigned when you set up sharing on your Windows computer. The `-l` option handily lists services available on the computer. As you can see in the preceding example, the Windows computer is a laptop.

# Transferring Files

After enabling sharing, you can access this hard drive from Linux by using smbclient, the computer’s Windows name, the name of the shared volume, the `-I` option and the IP address (or hostname of the Windows computer), and the `-u` option and your username (on the Windows computer):

```
# smbclient '//stinky/c' -I stinky -U bhsall
Added interface ip=192.168.2.38 bcast=192.168.2.255 mask=255.255.255.0
Password:
smb: \>
```

After entering the file-sharing access password and pressing Enter, you can get a list of smbclient’s built-in commands by using a question mark (?) or the help keyword:

```
smb: \> help
```

Use the `cd` command to change directories to the Windows desktop, and then use the `ls` command to list files:

```
smb: \> cd windows/desktop
smb: \windows/desktop\> ls
```
