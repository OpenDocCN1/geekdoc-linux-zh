One of many great things about using the Linux operating system is the wealth of networking tools, utilities, and commands included with every distribution. Although most networking experts give the Berkeley Software Distribution (BSD) UNIX the nod as having the fastest TCP/IP stack, there is a greater wealth of software for Linux, and you'll find many more X11 clients—such as Ethernet—Point-to-Point Protocol (PPP), monitoring tools, and related software included on a typical Linux CD-ROM.

For mobile Linux users, networking is a part of daily life. Many corporate LANs offer workers docking stations, and users on the go routinely take work home, along with an entire computer. This chapter discusses several of the more traditional ways to configure your notebook to support various networking schemes, such as switch- ing from life on the road to plugging into the corporate network, and then connecting to a home-based LAN. You'll learn how to configure an Ethernet network adapter from the command line, or by using the Red Hat Linux netcfg and linuxconf tools. You'll also learn how to use inexpensive hardware and cables to network computers.

# Basic Interfaces

Unlike other operating systems and, indeed, other commercial UNIX operating systems, networking interfaces under Linux are created on-the-fly by various command-line tools and exist in memory space. For example, the first hardware Ethernet device recognized and configured by Linux is named eth0. However, you won't find this device listed under the /dev directory like, say, a serial port, which can be represented by any number of /dev/ttyXX devices.

Although most Intel-based notebooks do not come with an internal Ethernet adapter, a growing number do. Apple PowerBook users know that Apple's note- book line has a long tradition of providing this networking capability, including inside the latest iBook. For nearly all other users, the Ethernet adapter of choice will probably be a 16-bit PC card supporting 10Base-T. The best performance you can hope for with this type of 16-bit PC Ethernet card is about 2 to 3Mbps, with FTP file transfers in the 800Kbps range.

Networking using the USB port is growing in popularity but is unsupported under Linux at this time. Newer versions of the Linux kernel will offer improved USB support, so you might find many new and inexpensive networking devices becom- ing available for Linux in the next several years.
