Not all the output is shown here. But the pertinent information you can see is that Card Services has recognized the card and has assigned a device (\dev/hdel in this example) to the card. From here, it is a simple matter to mount the card under an appropriate directory (such as /mnt/flash). Use the mount command, like this:

```
```
# mount -t vfat /dev/hdel /mnt/flash
```
```

You can then copy files to and from the card without having to worry about disk corruption in case of power loss. This is a handy way to work while on the road! When you're finished saving your files, you can unmount and eject the card using the umount and cardctl commands (with the eject keyword and proper slot number):

```

# umount /mnt/flash

# ### Using Iomega Zip Drives

Another inexpensive device you can use to store information is the Iomega Zip drive. This drive comes in a variety of form factors, such as parallel port, internal and external SCSI and IDE (ATAPI), and USB. Newer drives (supported by the Linux immr.o kernel module) support 250MB disks. This section describes how to use the legacy 100MB Zip disks that have a parallel-port Zip drive with newer Linux (2.2.X) kernels, such as those included with Red Hat 6.0 and Mandrake 6.1 or greater.

The first step is to hook up your Zip drive to your notebook using the proper cable, and then apply power to the drive. Insert a Zip disk into the drive. Next, as root, load the ppa kernel module like this:

```
```
# insmod ppa
```
