When you're finished, type the command `quit` to exit smbclient:

```
smb: \\windows\\desktop>] `quit`
# `\u0019#`
```

As you can see, transferring files between Windows and Linux is not difficult, thanks to Samba! The worldwide starting point to learn about Samba is through `http://samba.anu.edu.au/samba/`

You'll then be directed to a mirror site where you can even read free online books about Samba. For example:
`http://us2.samba.org/samba/o'reilly/using_samba/`
