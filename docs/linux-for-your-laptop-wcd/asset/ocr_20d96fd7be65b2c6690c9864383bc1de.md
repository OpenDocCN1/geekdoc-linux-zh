# Some Alternatives

Finally, you should know that there are even more ways to install Linux on your notebook. If you have access to the Internet, you can download the Slackware Linux distribution onto a series of floppy diskettes and then proceed to an installation after building a boot floppy.

According to Patrick Volkerding, Slackware's creator and maintainer, the distribution has grown from 10 floppy disks in 1993 to more than 100 floppies. To install a minimal Linux system, you can download Slackware's A series, create a boot disk, and start the installation using your notebook's floppy drive. Once Slackware is installed, you can then add software to enable networking or other devices, such as an Iomega Zip drive.

Slackware Linux may be installed from an Iomega Zip drive. A special "zipslack" distribution is available at http://ftp.slackware.com/pub/slackware/slackware/zipslack/. You install the zipslack distribution by unzipping the distribution onto an Iomega 100MB Zip drive and then attempting a boot using the LOADLIN command from DOS:

```
loadlin vmlinux root=/dev/sda4 rw
```

This will launch Linux. After logging in as root, you can create your Linux partitions and transnit the distribution to your notebook. This is also a great way to try out Linux without partitioning your notebook's hard drive!
