## Booting from CD-ROM

This chapter introduces you to the variety of ways you can install Linux on your notebook. It’s important to know your options when you’re faced with the task of installing Linux on a laptop, and practicing different installations can help you gain experience and build confidence. Mobile Linux users are focused, creative, and able to adapt to a host of installation techniques, usually as a result of hardware limitations, such as the lack of an internal CD-ROM or the inability to boot directly to an installation.

You’ll learn about the myriad techniques you can employ to get Linux installed on your laptop. Learning and practicing these techniques will enable you to learn more about your notebook’s hardware and gain experience as a seasoned Linux installer.

Fortunately, most modern laptops (aside from those in the ultralight category) come with a bootable CD-ROM. Installing Linux is as easy as inserting the CD-ROM, rebooting the notebook, and wiping the internal hard drive clean to install Linux. If you use other operating systems, such as OpenBSD or FreeBSD, you can opt to have two resident operating systems, creating a dual-boot system.

Booting to an installation from CD-ROM is without a doubt the easiest way to install Linux. Nearly all Linux distributions (with the exception of certain smaller collections) provide a main CD-ROM that is bootable. If you attempt to boot directly to a Linux installation, but you find that your notebook insists on using your floppy drive or laptop’s internal hard drive, check your notebook’s BIOS settings. You’ll need to restart your notebook and then hold down the proper key or keys to access the BIOS (check the manual provided by the manufacturer).

Many notebooks use a BIOS from Phoenix Technologies. Depending on your BIOS version, the first screen might look like what is shown in Figure 4.1.

First, make sure your CD-ROM drive is recognized. If your CD-ROM works with your notebook’s current operating system, chances are quite slim that you’ll have a problem booting Linux. Next, navigate to the Boot menu by using the right cursor key. Your BIOS screen should look like what is shown in Figure 4.2.

Use the up or down cursor keys to highlight your laptop’s CD-ROM drive. After it’s highlighted, press the plus key (+) to move the CD-ROM device to the top of the list. This menu represents the order in which your notebook will search for bootable devices.

When finished, follow your BIOS screen's directions to save and exit the BIOS setup (Phoenix users will press F10 and then Enter). Insert your bootable Linux CD-ROM, and then restart your notebook to launch to the installation (assuming you're satisfied with your partitioning strategy).

## Booting to the Yellow Dog Linux iBook Installation

Yellow Dog Linux Champion Server 1.2 is installed directly from CD-ROM onto the Apple iBook. After preparing an unallocated partition for Linux using Drive Setup and rebooting the iBook, install the BootX control panel device. Next, copy the files `ramdisk.image.gz` and `vmlinux` to your Mac's System folder. Run BootX to select the `vmlinux` kernel, and then click on the BootX Options button to select the Use RAM Disk option. Also be sure to select the No Video Driver option. When finished, click on the Linux button in the BootX dialog box. You'll boot directly to the Yellow Dog Linux installation!

## Booting from DOS

Another method of launching to an installation involves using DOS and an `AUTOEXEC.BAT` file or boot utility, such as `LOADLIN`, directly from your Linux CD-ROM. Some distributions, such as Red Hat and Mandrake, include a DOSUTILS directory with numerous software utilities and batch files to boot directly to an installation. For example, if you're running DOS, or if you have rebooted to the DOS command line from Windows, insert your Red Hat CD-ROM, and then navigate to the D: drive's DOSUTILS directory. At the command line, use the LOADLIN command to launch directly to a local installation:

```
d:\DOSUTILS>loadlin autoboot\vmlinuz initrd=.\misc\src\trees\initrd-1.img
```

This approach works with Red Hat's 6.1 Linux distribution. The LOADLIN command will boot Linux and then load the installation software to launch an installation. You can then install Red Hat Linux using your notebook's CD-ROM.

## Creating a Boot Floppy

Another way to jump to a Linux installation is to boot your notebook using a Linux installation boot floppy. You'll find a number of boot floppies included on your Linux distribution's CD-ROM. These floppies are stored in binary files known as images (similar to `initrd-1.img`, used to boot from DOS). If you buy a commercial version of Red Hat or Mandrake Linux, you should receive a boot installation floppy. If the disk is missing, don't worry, because a copy is included on your CD-ROM. The floppy images might have different names between different distributions. Red Hat Linux includes at least four boot floppy images under the IMAGES directory:

- **BOOT.IMG.** Used to boot a CD-ROM or hard drive installation (see the next section).
- **BOOTNET.IMG.** Used to boot to an NFS, FTP, or HTTPD installation (see the later section “Network Installation”).
- **PCMCIA.IMG.** A boot floppy containing PCMCIA support for network cards. It enables an installation from a hard drive or PCMCIA network adapter but might or might not work with your external PCMCIA CD-ROM.
- **RESCUE.IMG.** A boot floppy image that, when used with the Red Hat CD-ROM, might help restore or save your system.

You can create a floppy using these images in two ways. If you use DOS, use the **RAWRITE.EXE** command to create the floppy. For example, if you want to create a general boot floppy using Red Hat’s 6.1 CD-ROM, boot to DOS, navigate to the CD-ROM, and use RAWRITE like this:

```
D:\>dosutils\rawrite
```

After you press Enter, you’ll see this:

```
Enter disk image source file name:
```

You should then type in the path and file name of the desired floppy image. For example:

```
Enter disk image source file name: images/boot.img
Enter target diskette drive: a
Please insert a formatted diskette into drive A: and press -ENTER- :
```

After you specify the floppy drive, insert the floppy, and press Enter, the RAWRITE command creates your boot floppy. If you’re already running Linux, you can easily create a boot floppy by using the `dd` command. Mount your Red Hat CD-ROM, and then use the `dd` command and specify the input and output files like this:

```
# dd if=/mnt/cdrom/images/boot.img of=/dev/fd0
```

Mobile Linux users should create one or more of these floppies and keep them on hand for each new Linux distribution!

## Installing from a Hard Drive Partition

Don't have a CD-ROM? Can't boot from CD-ROM? You can use a DOS or Windows partition to help you install Linux. Nearly all major Linux distributions can read configuration, installation, and Linux software package files from an existing Linux, DOS, or Windows partition. This means that if you have enough hard drive space, and you can at least copy the required Linux directories to a partition on your hard drive, you will be able to easily install Linux. This may be accomplished by copying the files via a shared volume, a mounted NetWare volume, FTP, or other means.

This installation method has a drawback in that you might need 450MB or more storage for the compressed software packages. You can configure a smaller installation by including only the base files, but most notebook users will want to configure an installation without guesswork from a full complement of Linux packages. Also, this installation will not work unless you have previously partitioned your hard drive and have at least one active partition on which to copy the Linux software.

### Preparing Partitions

See Chapter 5, “Starting the Installation,” for details on preparing your notebook's hard drive for installing Linux. The basic steps involve making room for Linux by partitioning your hard drive (using the FIPS command or a commercial software utility) or, if just Linux is to be installed, partitioning your hard drive during the Linux installation. Installing Linux from a separate hard drive partition requires at least one active partition (to hold the software) and another partition to be modified during the Linux installation.

To prepare for the installation, copy the contents of the Red Hat or Mandrake directory to a spare DOS, Windows, or Linux partition. For a Red Hat installation, copy the contents of the Red Hat directory, including the BASE and RPMS directories. The BASE directory holds the second stage of the Linux installation, and the RPMS directory contains all the required Red Hat Package Manager (.rpm) files. Next, use your installation boot disk, or create a boot disk using the BOOT.IMG file.
