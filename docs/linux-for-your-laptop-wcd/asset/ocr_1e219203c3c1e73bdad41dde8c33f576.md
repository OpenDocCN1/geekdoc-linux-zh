# # Using Microphones

Another input device commonly included with many notebooks today is the built-in microphone. Many laptops also have a line-in port alongside a headphone or stereo output jack. Linux readily supports microphone recording, but you must have properly configured Linux to work with your notebook’s sound system.

# ## Recording Utilities

There are many different types of recording utilities for Linux, but few Linux distributions include actual sound recording software. Although several sound mixer clients are always found on every Linux distribution’s CD-ROM, you might have to search for, download, and build your own recording software. This is not difficult, because directions are generally included with the software’s archive, either in tarball (.tgz) or .rpm format.

You might be able to find a number of clients through links such as http://www.linuxstart.com/applications/multimedia/audiosound.html, http://www.freshmeat.net, or, if you’re a KDE user, http://www.kde.org.
