# # Resource Information

**http://www.astart.com/lprng/LPRng.html**

The home page of the LPRng alternative print spooling system for Linux.

# ## Printing-HOWTO

Grant Taylor's information on how to set up and use printing under Linux. It's usually found under the /usr/doc/HOWTO directory, although the latest copy (as with nearly all HOWTOs) may be found at http://www.linuxdoc.org.

**http://home.sndf.de/wehe/ir_misc.html**

An extensive table of devices, including laptops, that can use Linux and IrDA.

# ## IR HOWTO

Werner Heuser's wrap-up of the Linux IrDA project, which contains techniques and applications for using IrDA under Linux. It can be found under the /usr/doc/HOWTO directory in the latest Linux distributions or at http://www.linuxdoc.org.

**http://www.creative-it.com/linux/irda/toshiba_irda_howto.html**

Guenther Wieser's specific instructions for Toshiba laptop owners on using IrDA and Linux.

**http://www.physiol.usyd.edu.au/daved/linux/bjc-80.html**

The best place to start for CanonBJC-50 and BJC-80 mobile Linux users who want to print using IrDA.

**http://www.linuxworld.com/linuxworld/lw-1999-06/lw-06-hylafax_p.html**

An article on using HylaFax, with sidebar information regarding Internet faxing.
