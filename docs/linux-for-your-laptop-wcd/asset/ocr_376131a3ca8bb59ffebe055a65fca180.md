Insert one of the Aviator cards, and then look through the system's /var/log/messages file for this:

```
ray_cs Detected:
WebGear PC Card WAN Adapter Version 4.88 Jan 1999
eth0: Raylink, irq 4, hw_addr 00:00:8f:48:28:DB
ray_cs interrupt network "LINUX" started
```

Next, enable the interface using netcfg, and insert the other Aviator card on the other computer. Again, look at /var/log/messages:

```
ray_cs Detected:
WebGear PC Card WAN Adapter Version 4.88 Jan 1999
eth0: Raylink, irq 10, hw_addr 00:00:8f:48:28:45
ray_cs interrupt network "LINUX" joined
```

Note that the first instance of the ray_cs.o driver output says “started,” and the second card says “joined.”

Enable the second interface, and your computers are networked! You can then try using the ping command to test the connection. Once the network is working, you can use telnet, ftp, or even http for Web browsing (FTP speeds will be about 180Kbps).

Using this approach, you can install a wireless card in your notebook and another on a computer attached to a LAN. By using IP masquerading, you can forward Internet service to the wireless laptop. Do this by assigning an IP address to the first eth0 interface on your server, and then install an Aviator card as eth1 with an IP address in a different subnet. For example, eth0 could have an address of 192.168.2.50, and the Aviator card, as eth1, would be assigned 192.168.1.1. Start the wireless service from the server to your laptop, and then use the route command like this:

```
# /sbin/route add 192.168.1.1 gw 191.168.2.50
```

On the server (191.168.2.50), which has a connection to the Internet, you would then use IP masquerading like this:

```
# /sbin/modprobe ip_masq_ftp
# /sbin/iptables -A forward -s 192.168.2.0/24 -j MASQ
# /sbin/iptables -A forward -s 192.168.1.0/24 -j MASQ
```

On your wireless laptop, complete the configuration by using the route command like this:

```
# /sbin/route add default gw 192.168.1.1
```
