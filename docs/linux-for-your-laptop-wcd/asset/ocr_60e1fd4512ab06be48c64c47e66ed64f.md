To perform a simple anonymous FTP file transfer, enter the hostname or address of the remote computer, along with the name of the directory containing the Red Hat installation software. If you use gateway information and have an active Internet connection on the gateway, you can use the domain and hostname of a computer anywhere in the world (as long as the computer offers a Red Hat Linux installation CD-ROM via FTP)!

If you select the "Use non-anonymous ftp or a proxy server" option, you'll be prompted for a username and password for the FTP installation. You will also be logged in to your account directory on the remote computer. Make sure the Red Hat installation directory is available there if you choose a nonanonymous FTP transfer.) When finished, select the OK button and press Enter to begin the installation. The Red Hat installer will then attempt to retrieve the second stage of the installation from the remote computer.
