# ## General Advice

The following list is a small set of rules that may help you economize system resources when faced with building a Linux system on a notebook with limited RAM, hard drive space, and CPU speed. Many interactive programs are event-driven, and spend most of the time waiting for your input when running. This means that you can build and run a capable Linux system on older hardware through cautious choice of software, and adopting simple storing-saving strategies.

+   - Don't install software you don't need. Why have games installed if you don't need them?
+   - Remove software that duplicates other software. How many text editors do you need, anyway?
+   - Text-based programs generally require less memory than GUI-based clients. You can browse the Web with the text-based Lynx browser instead of Netscape Communicator.
