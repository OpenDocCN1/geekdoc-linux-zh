# **Table 3.2    Linux Server Software**

| Name | Description |
| :--- | :--- |
| amd | Automount daemon (for devices and NFS) |
| anacron | Scheduling daemon (similar to cron) |
| apmd | Advanced Power Management daemon |
| arpwatch | Network logging of Ethernet addressing |
| atd | The at daemon (running appointed tasks) |
| bootparamd | Diskless networking booting daemon |
| cardmgr | Card Services (PCMCIA) daemon |
| crond | Scheduling daemon (for crontab service) |
| dhcpd | Dynamic Host Configuration Protocol server daemon (assign IPs) |
| fingerd | User information server (for the *finger* command) |
| gated | Gateway routing daemon |
| gpm | General-purpose mouse server (console mouse support) |
| httpd | The Apache Web server daemon |
| in.ftpd | File Transfer Protocol daemon |
| in.telnetd | Telnet server |
| inetd | Master network services daemon |
| innd | InternetNews server daemon |
| lpd | Line printer spooler daemon |
| mcvserv | Midnight Commander fileservcer |
| mysqld | Relational database server daemon |
| named | DNS server named (part of BIND package) |
| nmbd | NetBIOS name server daemon |
| nscd | Name Switch Cache daemon for Network Information Service |
| nswerc | NetWare emulator and server (inwind, ncpserv) |
| portmap | Support daemon for Remote Procedure Calls (RPCs) |
| postfix | Electronic mail control daemon |
| routed | IP route table update support daemon |
| rpc.mountd | NFS mounter daemon |
| rpc.nfsd | NFS server |
| rpc.quotad | NFS quota-checking daemon |
| rpc.rstatd | Kernel statistics (performance) reporting |
| rpc.rusersd | Logged-in user reporting daemon |
| rpc.rwalld | wall3 command support daemon |
| rpc.rwhod | System status database and reporting daemon |
| rpc.statd | Network File System (NFS) status monitor |
| sendmail | Electronic mail transport server |
| smbd | Session Message Block (SMB) daemon |
| squid | Web object caching daemon (for httpd) |
| syslogd | System logging daemon |
| tcppd | Internet services daemon (such as for telnet) |
| xfs | X Font Server |
| xntpd | Network Time Protocol (NTP) server |
| ypbind | NIS database support daemon |
| ypasswdd | NIS database support daemon |
| ypserv | NIS database support daemon |
