# Which Set of Files?

When you browse the XFree86 FTP server, you’ll notice that XFree86 is distributed for many different operating systems (but not for the Apple iBook or PowerPC Linux). You might even be confused when you find that there are four different versions for Linux! For the latest versions of Linux, such as Red Hat 6.1 or Mandrake 7.0, the archives you need are contained in this directory:

```
ftp://ftp.xfree86.org/pub/XFree86/4.0/binaries/Linux-i686-g1ibc21/
```

Table 6.2 lists additional archives you might be interested in retrieving. They are not necessary for a minimal installation, but they might be included with the minimal files listed in Table 6.1.

Other files to download include a file named RELNOTES (the release notes file), which details changes in the distribution, and, most important, a file named Install, which contains details of the XFree86 4.0 distribution.
