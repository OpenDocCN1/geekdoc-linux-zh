This chapter details some of the preliminary requirements for installing and using Linux. You'll learn about installing custom setups for configuring your notebook as a workstation or server. You'll also learn how to install a minimal distribution with or without the X Window System (the graphical interface for Linux).
Understanding the hard drive and storage requirements for using Linux is important. It can help you best allocate the most precious of resources in a notebook: the storage capacity of an internal hard drive. Some fortunate notebook owners have laptops with removable hard drives, or they have the ability to easily swap out the internal fixed drive. However, most notebooks come with a single, fixed drive that may provide anywhere from several hundred megabytes of storage to 25GB, currently the largest-capacity drive for notebooks.

# Defining Workstations and Servers

The Linux kernel supports your notebook as both a workstation and a server. Running Linux as a server can require more drive space, especially if you plan to support multiple users. However, configuring your notebook as a workstation can also tax your laptop's peripherals and drive storage much more than configuration as a server. It all depends on how you plan to use your notebook.

Linux servers require only a few basic essential services and software to be installed, but some of these services can require enormous amounts of drive storage. Some of these services include Domain Name Service (DNS) and InternetNews (INN). Depending on how you configure your notebook, you may also enable FTP, telnet, Session Message Block (SMB) service using Samba (to show all or some of your notebook's hard drive as a shared volume, or for sharing an attached printer), or Apache for running a Web server. Other services include remote UNIX printer support, electronic mail, and firewalling as a gateway for Internet services.

On the other hand, when installing and configuring a Linux workstation, you might have not only all of these services in place, but also much additional software, such as the X Window System, various window managers, fonts, multimedia applications, and other productivity clients.
