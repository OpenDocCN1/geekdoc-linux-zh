
## Introduction

According to Linus, the first public release of Linux on Oct. 5, 1991 was version 0.02. (An earlier version existed, but it wasn't really announced or distributed publicly.) Here is part of the release message:

> From: torvalds@klaava.Helsinki.FI (Linus Benedict Torvalds)
> Newsgroups: comp.os.minix
> Subject: Free minix-like kernel sources for 386-AT
> Message-ID: <1991Oct5.054106.464@klaava.Helsinki.FI>
> Date: 5 Oct 91 05:41:06 GMT
> Organization: University of Helsinki
>
> Do you pine for the nice days of minix-1.1, when men were men and wrote their own device drivers? Are you without a nice project and just dying to cut your teeth on a OS you can try to modify for your needs? Are you finding it frustrating when everything on minix? No more all-nighters to get a nifty program working? Then this post might be just for you. ;-)
>
> As I mentioned a month(?) ago, I'm working on a free version of a minix-lookalike for AT-386 computers. It has finally reached the stage where it's even usable (though may not be depending on what you want), and I am willing to put out the sources for wider distribution. It is just version 0.02 (+1 (very small) patch already), but I've successfully run bash/gcc/gnu-make/gnu-sed/compress etc under it.
> Sources for this pet project of mine can be found at nic.funet.fi (128.214.6.100) in the directory /pub/os/linux. The directory also contains some README-file and a couple of binaries to work under linux (bash, update and gcc, what more can you ask for ;-). Full kernel source is provided, as no minix code has been used. Library sources are only partially free, so that cannot be distributed currently. The system is able to compile "asm-is" and has been known to work. Heh.
> Sources to the binaries (bash and gcc) can be found at the same place in /pub/gnu.
> ...

Although Linux wasn't self-hosting (capable of recompiling itself) at this point, interest in the operating system started gaining a wider audience. The original kernel was very specific about the host's x386 hardware, but soon afterward, floppy support was added, virtual memory was coded into the kernel source, and virtual console support became a reality.

Hackers around the world started contributing patches, bug fixes, and features such as networking and support for SCSI hard drives. Within months, Linux jumped to version 0.96 with support for the X Window System. The rest is history.

## Why Use Linux on a Laptop?

For the first time in computing history, portable computer users can have the power of a high-end workstation sitting in their laps! UNIX is one of the oldest operating systems in existence and has proven its viability time and time again. Although it wasn't designed with security in mind, UNIX was developed from the ground up to provide a powerful, intuitive platform and offer the user more power than any other interface. The shell, with its pipes, background operator, and input and output redirection, gives even "common folk" the ability to craft complex, specialized tools to accomplish great tasks.

There are many solid reasons to use Linux on a laptop (or any other computer). These reasons include the following:

- Cost. Linux is free, as are the many programs included in a Linux distribution.
- Development platform. Linux comes with a wealth of programming tools and languages, such as autoconf, make, cvs, C, C++, Perl, Python, awk, sed, and others.
- Firewalling. Installed on legacy hardware, such as an old x86, Linux can easily perform secure network security duty.
- Licensing. Linux and much of its associated software is distributed under the GNU General Public License, providing free and open use of programs and source code while maintaining copyright protection for original authors.
- Multiple processor support. Linux supports (at the time this book was written) up to four CPUs. Eight-way support is imminent.
- Multitasking. Linux supports multiple tasks (processes) and multiple users online at the same time.
- Networking compatibility. Linux supports nearly every networking protocol imaginable. Linux, Windows, and Macintosh computers can communicate over Ethernet using TCP/IP or by using Samba or netatalk (for AppleTalk).
- Remote administration. Linux provides the platform and tools to support remote system administration. This is especially useful for laptop users on the road!
- Server operations. Linux performs well as a server platform. Along with the free Apache Web server, or commercial Web servers such as Zeus, Linux is a cost-effective approach to launching an e-commerce site or company intranet.
- Software availability. A wealth of software is available for Linux, primarily due to the generosity of Open Source programmers worldwide.
- Stability, reliability, and robustness. Linux performs well, even in low-memory situations. Reboots are rarely needed, and many users enjoy uptimes measured in months!
- Support. Although touted by minions of the Dark Side as a liability, Linux enjoys better and lower-cost support than nearly any other operating system. Fixes to major security flaws are generally posted worldwide within hours, not weeks or months. Users get thousands of pages of documentation, manual pages, and source code.
- The X Window System. Linux uses XFree86, a free version of X11. It is a sophisticated and time-tested networking graphical interface client/server-based system.
- Upgradeability. Linux is easy to upgrade. Most distributions come with a variety of command-line or graphical interface software administration tools.

### General Linux Features

Linux works well as a small- to medium-sized server platform and as a desktop operating system. How well Linux works for you depends on your needs and expertise. Although installation and administration tools get better with each new distribution, there's not a lot of handholding as you start down the path to Linux!

You can use Linux to serve up Web pages on a company intranet, provide file and printer services, act as a firewall to protect your local area network, crunch numbers in a spreadsheet, write documents, or create graphics. Linux is especially adept at providing networking tools and other clients used to send and receive e-mail, upload or download files to and from remote computers, and surf the Web.

### FUD Versus the Truth

If you use Usenet and follow discussions in newsgroups such as comp.os.linux.advocacy, you'll see threads of endless bickering involving trolls, troolls, and flames between computer users regarding which OS is best. The truth is that many Linux users don't really care and have been happily installing and using Linux for several years.

However, now that Linux has achieved quite a bit of popularity and notoriety, especially among larger computer hardware and software vendors, it has come into the sights and under the gun of the world's largest computer software company, Microsoft. On Oct. 9, 1999, in an effort to discredit the capabilities of Linux and possibly stem its spread as a server operating system, Microsoft posted an article, "Linux Myths," on its NT Server Web page at

http://www.microsoft.com/ntserver/nts/menu/LinuxMyths.asp

The article is quite interesting. It contains a mix of truths and falsehoods, but despite Fear, Uncertainty, and Doubt (FUD) tactics, the fact is that Linux continues to grow in popularity. Major research companies, such as International Data Corporation, predict that Linux will capture at least one-quarter of the desktop market and one-third of the server market in the next two years.

Microsoft's Windows 2000 operating system requires at least a 166MHz Pentium or higher CPU, along with 64MB of RAM and a 2GB hard drive with 500MB of free space. On the other hand, Linux, along with a text editor and Internet connection tools, fits on a 1.44MB diskette and boots on vintage Intel-based x86 computers!

### How Small?

Not only can you boot and run Linux from a single floppy disk, but you can also build a bootable Linux computer that fits on a 30-pin single inline memory module, or SIMM! Browse to http://www.ucLinux.com to read about the uCsimon running uCLinux. This 1-inch tall 30-pin module features 2MB of Flash memory, 8MB of RAM, 10Base-T Ethernet, an LCD panel driver, and Linux kernel version 2.0.38. The module mounts in a socket on a small prototype board with a 6V power supply. It can provide Web service or network monitoring at very low cost.

If you think comparing Windows 2000 to Linux is unfair, consider that a full Linux distribution (such as from Red Hat, Caldera, Corel, or SuSE) requires about the same amount of memory (64MB) and at least 1.3GB of hard drive space. However, you get the following:

- The Linux operating system
- The X Window System, a networking client/server-based graphical interface
- 3,000 programs, including text editors, a spelling checker, database managers, multimedia clients, games, and more
- 1,500 fonts
- 6,000 graphical images
