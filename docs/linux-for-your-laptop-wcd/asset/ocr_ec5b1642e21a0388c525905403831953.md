Preferences. In the Preferences dialog box, click the Words button. You’ll see a dialog box, shown in Figure 17.3, that you can use to change the time between backup document creation.

Note that you must set a separate interval for sessions that use *Applix Spreadsheets*.

The GNU `emacs` editor also features auto-saving of documents. This feature and interval may be controlled by the file `.emacs` in your home directory. For example:

```
(setq auto-save-interval 1500)
(setq auto-save-timeout nil)
```

These entries cause `emacs` to save a backup every 1,500 keystrokes. If you set this value to 0, you will turn off the auto-save feature. If you use the XEmacs editor, you can turn off the use of backup files by choosing Options, Customize, Emacs, Files, Backup from the XEmacs menu, as shown in Figure 17.4.
