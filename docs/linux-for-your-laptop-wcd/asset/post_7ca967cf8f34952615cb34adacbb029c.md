## Cursor Drifting?

If you have an IBM ThinkPad and you notice your cursor occasionally drifting a quarter of an inch across the screen, don't worry! Leave it alone, and it will stop. The cursor is recalibrating!

Mobile Linux users with a Synaptics touchpad can download a configuration utility named *tpconfig* at http://www.compass.com/synaptics/. This program lets you set or reset pointer movement, tapping, edge scrolling, and button use. Unfortunately, *tpconfig* is not compatible with the Linux General-Purpose Mouse driver (gpm), which provides mouse functions for the text-only console. gpm is usually run as a background service or process, known as a daemon, and it must be “killed” before you use *tpconfig*.

gpm provides the ability to cut and paste text when using the console. However, you should be aware that if gpm is started with its -S option, it can also run “special” commands, triggered by triple-clicking the left and right mouse buttons. In this instance, you will hear the speaker beep twice. If you then press the left or right button within three seconds, the system will reboot! If you press the middle button, the system will shut down!

The gpm driver is usually started when Linux boots. Its initialization script is found, using Red Hat and similar Linux distributions, under the /etc/rc.d/init.d directory in the script named gpm. If you have problems using your notebook's pointer while in the console, first read the gpm man page, and then alter the initialization options to configure your mouse. You can kill the currently running gpm process by using the kill command, followed by the process number, like this:

```
$ ps aux | fgrep gpm
root 417 0.0 0.0 1172 16 ? S Jan31 0:00 gpm -t pa/2
$ kill -9 417
```

Here, the output of the ps command is piped through the fgrep command to search for the running process. Then the shell's kill command is used to kill the process according to its process number.

## Left-Handed? You're Not Left Out!

Lefties have a hard enough time dealing with a right-handed world. To add insult to injury, most Linux installations automatically set up and configure a notebook's mouse buttons for right-handed users! However, you can easily fix this with the xmodmap command like this:

```
xmodmap -e "pointer 3 2 1"
```

## Merits of Three Buttons

The most desirable pointer for use with Linux and the X Window System is the three-button mouse. In right-handed terms, the left mouse button is mouse button 1. It is used to click buttons, click and drag to select text, double-click to launch programs, and so on. The middle mouse button, or mouse button 2, is used to paste text and graphics or grab scrollbars in xterm terminal windows. The right mouse button, or mouse button 3, is used by many X11 window managers for alternative menus, such as when changing the properties of a right-clicked object.

The majority of notebooks on the market have only two mouse buttons, probably due to the fact that most notebooks, aside from Apple’s line of Macintosh notebooks (which have only one mouse button), are manufactured in a monopolistic software market. Because Windows and its variants use only two mouse buttons, why include a third mouse button at additional cost? Thankfully, at least one manufacturer, IBM, sees fit to produce laptops with three buttons. This makes life with Linux a bit easier!

When you install Linux, your notebook's pointer might or might not be automatically recognized. If the pointer is recognized, as with most Intel-based laptops on the market, Linux will configure your device as a two-button PS/2 mouse. When asked if you want to "Emulate 3 buttons?", click OK. If you don't, your mouse will have a left and right mouse button, but no middle button. If you do click OK, the middle mouse button will be emulated by a simultaneous press of the left and right mouse buttons. Awkward? Yes, but at least it works!

Configuration of the pointer for X11 sessions is, like the keyboard, contained in the Pointer section of your system's XF86Config file. For example:

```
Section "Pointer"
 Protocol "PS/2"
 Device "/dev/mouse"
 Emulate3Buttons
 Emulate3Timeout 50
EndSection
```

This abbreviated pointer section shows that the pointer configured for X is a PS/2 two-button mouse. Middle button emulation is enabled, with a timeout of 50 milliseconds. The timeout value tells the X server (running in the background) how long to wait before deciding that the middle button (button 2) has been pressed.

## The Apple iBook Mouse

When installing PowerPC or Yellow Dog Linux for the Apple iBook, the mouse is configured as a one-button ADB mouse. Linux for the Apple supports up to 35 different pointing devices. Installing Linux until the mouse is configured can be a little challenging, because you have to use the keyboard to select the proper buttons and dialog boxes. But after it's configured, the mouse works well. According to what the Yellow Dog Linux folks (http://www.yellowdoglinux.com) say in their documentation (for the 1.1 distribution), in order to support three-button emulation, you must use the following Linux kernel boot prompt to tell Linux (and X) to use the F11 and F12 keys as mouse buttons 2 and 3:

```
adb_buttons=1,103,111
```

This does not work for the iBook; instead, you have to use this:

```
adb_buttons=103,111
```

This setting may be entered at the Linux boot prompt or into the BootX options field when booting Linux.

## Symbolic Pointer Device

Linux can recognize and use many different pointer devices. This means you can attach an external rotordetector (mouse) to your notebook and use it during your sessions. In general, most distributions create a symbolic link, or pointer, to the actual device under the /dev directory, named /dev/mouse. For example:

```
# ls -l /dev/mouse
lrwxrwxrwx 1 root root 5 Oct 12 08:53 /dev/mouse -> psaux
```

This shows that the pointer used is attached to /dev/psaux, or a PS/2 port on the computer. A serial mouse, on the other hand, would probably look like this:

```
lrwxrwxrwx 1 root root 5 Oct 12 08:53 /dev/mouse -> ttyS1
```

This indicates that the mouse is attached to a serial port, similar to COM2 under DOS. Under Linux for the iBook, this link looks like this:

```
lrwxrwxrwx 1 root root 5 Oct 12 08:53 /dev/mouse -> a2dmouse
```

## Other Input Devices

Linux and X11 support many other types of input devices. Look at the file named xinput under the /usr/X11R6/lib/X11/doc directory. You'll see a listing of more than a dozen devices, including the following:

- AceCad table
- Calcomp DrawingBoard tablet
- Elographics touchscreens
- Joysticks (which have to be attached through a PCMCIA adapter)
- MicroTouch touch screen stylus
- SGI button box
- SummaSketch tablet
- SWITCH virtual device
- Wacom cursor
- Wacom eraser
- Wacom stylus

You'll probably see many more compatible devices.
