# # Showing and Setting Time

Getting and showing the date and time from Linux is relatively easy. A short C program can quickly retrieve and print the date and time. For example:

```
```
#include <stdio.h>
#include <time.h>

int main()
{
	time_t now;

	time(&now);
	fputs(ctime(&now), stdout);
	return 0;
}
```
```

If you type this into a file named qd.c, you can then build the program, and perhaps give it the name qd:

```
```
# gcc -o qd qd.c
```
```

You can then run qd like this:

```
```
# ./qd
Wed Mar 22 10:18:16 2000
```
```

Note that after you press Enter, you see the current date and time. However, to check that your system time matches the time or is properly offset from the time in your notebook’s hardware clock, use the hwclock command with its --show option:

```
```
# /sbin/hwclock --show
Wed Mar 22 10:19:17 2000  -0.497501 seconds
```
```

In this example, the Linux system time is set to match the notebook’s hardware clock. You can use the hwclock command to manually set the hardware clock by using its --set and --date options like this:

```
```
# /sbin/hwclock --set --date "12/25/00 21:03:00"
```
```

After you press Enter, the hardware clock will be set to 9:03 p.m., December 25, 2000. The nwclock command can transfer date and time values from the Linux system time to your notebook’s hardware clock or back again using the --systohc or --hcrosys options.
