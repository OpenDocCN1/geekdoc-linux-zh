The file will be closed only until the here operator detects a single period (.) on a line by itself. This also shows that the shell works on a line-by-line basis;

You can also append information to an existing file. For example, if you have a log that shows how long Linux has been running, you can send the output of the uptime command to the log like this:

```
$ uptime >>myuptime.log.txt
```

In this example, the append >> operator is used to attach the output of the uptime command to the end of the file named myuptime.log.txt. If you had simply used the output > redirection operator, the output of the uptime command would have wiped out any existing text in the log file. This shows that you should use output redirection carefully. You can quickly and unforgivingly overwrite files.

# ### Using the Shell

The bash shell also features rudimentary command-line editing, the ability to recognize and use command synonyms, known as aliases, and the ability to recall previous command lines, known as history editing. Table 9.2 lists several common editing commands you can use with the bash shell's command line.

You also can craft simple or amazingly complex patterns or expressions using a feature known as extended expressions, or globbing. These expressions can range from simple, such as * to match all characters, to more complicated, such as *{a-z}{0-9}* to match embedded letters and numbers.

Experienced mobile Linux users are familiar with a variety of shells for Linux, and they use the shell to get work done quickly and efficiently. The bash shell, which can mimic other shells, may also be used to create simple to complex programs, known as shell scripts. Shell programming is a fine art and a craft worth learning, but you can build your own simple shell scripts using just a few commands.

# ### Bash Is Big

If you're strapped for space on your notebook's hard drive, and you really want to use a stripped-down system, consider using an alternative shell for your Linux console sessions. You'll find at least two other shells, ash and csh, that can work quite well for most online needs. Other shells, such as ksh, are also much smaller than the bash shell (which weighs in at nearly .5MB, compared to the ash shell's paltry 61,000 characters). The csh shell is used when rebooting Linux for emergency repair, because it is stand-alone, and it does not require shared software libraries like other shells.
