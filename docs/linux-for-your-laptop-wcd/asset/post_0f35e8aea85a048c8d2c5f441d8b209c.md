
# The Linux File System

When Linux is installed on your hard drive, the directory structure, or *pathnames*, make up the Linux file system. The Linux file system's base (`/` or *root*) directories are listed in Table 2.5.

**Table 2.5 Base Linux Directories**

| Name | Description |
| :--- | :--- |
| bin | Linux programs |
| boot | Where the Linux kernel is stored |
| dev | Device files |
| etc | System configuration files |
| home | Directories for users and FTP, HTTP, and so on |
| lib | System software libraries |
| lost+found | Storage for recovered files |
| mnt | Where other file systems are mounted |
| opt | Optional software storage |
| proc | A snapshot of the running system |
| root | The root operator's directory |
| sbin | Programs normally run only by root |
| tmp | Temporary storage |
| usr | Programs, libraries, and X11 |
| var | Process-specific directories (fax, modem, printer, mail) |

For example, if your name is Fred Smith, your Linux *username* (log-in name) will most likely be fsmith. Your home directory is then referred to as /home/fsmith.

# Linux Drive Utilities

Some Linux hard drive utilities you will use on a daily basis during your sessions include the *ls* (list files) command; the *at* (display filesystem statistics) command, which shows how much free space is used and available; and the *du* (disk usage) command, which shows how much disk space is used by different directories.

The KDE *kdiskfree* client, shown in Figure 2.5, can be used if you’d like to see a quick chart of your hard drive space usage.

![](img/70d85e6f4d1ff2750ca2a98ba3d9855c_80_0.png)

**Figure 2.5** The *kdiskfree* client presents a graphic of filesystem usage for any mounted volumes, including other filesystems such as FAT32.

Linux also includes utilities to *mount* or *unmount* filesystems. This means you can make other filesystems, such as hard drives, Zip drives, or CD-ROMs, appear or disappear in the filesystem, usually under the /mnt directory. If you configure your notebook to boot Linux or Windows, and the Windows partition resides on the first partition, you can make the Windows partition appear under the /mnt/dos directory like this:

```bash
# mount -t vfat /dev/hd1 /mnt/dos
```

You can then copy, delete, rename, or move files to and from Linux and your Windows desktop. To make the Windows partition “disappear” from use, use the *unmount* command like this:

```bash
# unmount /mnt/dos
```

Apple iBook Linux users can also use the `mount` command to access the Macintosh-formatted partition. After you install Linux on the iBook, the MacOS HFS filesystem should reside on /dev/hda8. You can then mount it like this:

```bash
# mount -t hfs /dev/hda8 /mnt
```

To see the files in the Macintosh Desktop Folder, use the `ls` command like this:

```bash
# ls /mnt/Desktop Folder/
```

You’ll find several hardware-specific drive utilities included with Linux. One of these is `hdparm`, used to display or set IDE hard disk parameters. This command-line interface program has nearly 30 different options you can use to see or change your hard drive’s characteristics.

One of the most common uses is to set the spindown, or idle time, of the internal hard drive. This can be handy to help save battery power if you’re on the go. For example, to set your notebook’s drive to spin down after a certain amount of time, use the `hdparm` command’s `-S` option, followed by a number (see Table 2.6).

**Table 2.6 hdparm Standby Timeout Values**

| Value | Timeout |
| :--- | :--- |
| 0 | Turns off standby mode |
| 1 to 240 | 5 seconds to 20 minutes |
| 241 to 251 | 1 to 11 units of 30 minutes |
| 252 | 21 minutes |
| 253 | Vendor-determined |
| 255 | 21 minutes, 15 seconds |

For example, to have your hard drive spin down after 60 seconds of inactivity, use the `hdparm` command like this:

```bash
# hdparm -S 12 /dev/hda
```

This command works for Intel-based notebooks and the Apple iBook! Note that if you make this change, the hard drive will spin down with Windows or the MacOS.

# Your Notebook's CD-ROM

Most notebooks, including the iBook, use an *AT Attachment Packet Interface* (ATAPI) CD-ROM drive. Most of these CD drives work quite well with Linux (although I am aware of one incompatibility issue that was quickly resolved with a kernel recompile). Your main concern when buying a notebook is that you can set your laptop's *basic input/output system* (BIOS) to change the boot order of any internal storage devices, such as the floppy, hard drive, and CD-ROM. Fortunately, most notebooks support this. However, in the case of one line of Sony notebooks with an external CD drive, you could indeed set the laptop's BIOS to boot from CD-ROM, but this would work only with Sony's drive—a nasty maneuver!

Although CD-ROM writer and CD-ROM rewritable drives are available for desktop computers, at the time this chapter was written, only one notebook manufacturer (Dell) offered this option in a laptop. You'll find a drive compatibility chart at

http://www.gug.de:8080/cgi-bin/winni/lsc.pl

For a helpful HOWTO on how to burn CDs using Linux software and CD-ROM writer or rewritable drives, browse to

http://www.gug.de/~winni/linux/cdr/html/

Your notebook's CD-ROM drive should be automatically recognized when you boot Linux, even if a CD is not inserted. Look for output similar to this:

```text
hda: TOSHIBA DVD-ROM DRD-0624, ATAPI CDROM drive
```

This output shows that Linux has detected a DVD CD-ROM attached to /dev/hdc. Using this information, you can easily mount the CD with this:

```bash
# mount -t iso9660 /dev/hdc /mnt/cdrom
```

Note that most storage devices, fixed and removable, usually have entries in the file /etc/fstab, your system's filesystem table. This file is created when you install Linux, and it makes it even easier to mount devices such as CD-ROMs. Using the preceding example, the /etc/fstab entry might look like this:

```text
/dev/cdrom /mnt/cdrom iso9660 user,noauto,nosuid,exec,ro 0 0
```

In this entry, /dev/cdrom is a symbolic link to the /dev/hdc device, and the mount point is defined as /mnt/cdrom. This means that you can insert a CD-ROM into the drive and then use this:

```bash
# mount /mnt/cdrom
```

The contents of the CD-ROM will appear under the /mnt/cdrom directory.

# DVDs and Linux

Linux can mount and read DVD CD-ROMs. But even though there is software available to allow you to watch DVD movies under Linux, the motion picture industry has hounded, pursued, and sued anyone posting or distributing this software on the Internet, claiming the software is illegal and violates trade secrets. (The software is still available despite these absurd efforts.) Until the current hoopla subsides, Linux users can still benefit from having a DVD CD-ROM drive. At least one Linux distribution manufacturer, SuSE, Inc., is now distributing its Linux software in DVD format. This saves a lot of space, weight, and packaging material, and it allows one CD to be used for permanent software storage instead of six!

# The Parallel Port

The parallel port, known under DOS as an LPT (line-printer terminal) port, is still included on most notebooks sold on the market, despite the increasing popularity and number of USB printers. This port is generally a female 25-pin connector that is similar in appearance to the older DB-25 serial port. Unless you are specially designed, printer cables have one male 25-pin connector for attachment to your laptop, with a D-shaped Centronics plug connector on the other end for attachment to your printer.

Not many mobile Linux users lug around a printer while on the go. One solution is to use a portable printer with an IrDA interface, such as a Canon BJ C-50 (see the section “Infrared Port” later in this chapter). When you boot Linux and have an attached printer that is turned on, the printer should automatically be detected (as shown in the following output from the dmesg command):

```text
parport0: PC-style at 0x378 [SPP,ECP,ECPPS2]
lp0: using parport0 (polling).
```

If you do not see this output, check your cable fittings, and make sure that your /etc/conf/modules file contains this line:

```text
alias parport_lowlevel parport_pc
```

Parallel-printer support for Linux is provided by the parport and lp kernel modules, loaded into memory when required from the /lib/modules/linux-2.2.X/misc directory, where X is the version of your Linux kernel.
