# Hard Drive Maintenance On-the-fly

Linux comes with numerous utilities to check, verify, report on, and fix filesystems. Some of these files are listed in Table 13.1.

| Table 13.1 Linux Filesystem Utilities |
| :--- |
| Utility | Description |
| badblocks | Searches for bad blocks on the specified device |
| bonnie | Filesystem performance benchmark utility |
| cksum | Creates a checksum and counts bytes in the specified file |
| defrag | Defragmentation utility |
| dosfsck | Checks and repairs DOS filesystems |
| dump | Backs up filesystems |
| e2fsck | Linux ext2 filesystem check and repair command |
| mbadblocks | Searches and marks bad blocks on DOS floppies |
| mcat | Dumps a raw disk image of a DOS floppy |
| pathck | Checks file name length and size |
| sum | Creates a checksum and counts bytes in the specified file |
| tune2fs | Adjusts filesystem parameters |

The most important utility, and the first program you will encounter if Linux detects a problem with your notebook's hard drive, is the `e2fsck` command. This command is run from the system's `rc.sysinit` file under the `/etc/rc.d` directory, especially when you reboot Linux after not performing a proper shutdown. If serious errors are detected, Linux drops into a manual root shell. You should then run the `e2fsck` command and specify the problematic Linux partition. For example, if a problem is detected with /dev/hda9, you might have to run e2fsck like this:

```
# e2fsck /dev/hda9
```
