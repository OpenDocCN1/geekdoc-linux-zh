You can get a list of current settings by using the hdparm command along with the device name of your notebook's hard drive (in many cases, /dev/hda for the first IDE drive). This also works with Apple iBook, which uses an IDE drive. For example:

```
# hdparm /dev/hda

/dev/hda:
  multcount    =   0 (off)
  I/O support  =   0 (default 16-bit)
  unmaskirq    =   0 (off)
  using_dma    =   0 (off)
  keepsettings =   0 (off)
  nowerr       =   0 (off)
  readonly     =   0 (off)
  readahead    =   8 (on)
  geometry     = 1559/240/63, sectors = 23579136, start = 0
```
