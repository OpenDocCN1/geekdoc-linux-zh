### Potential LILO Problem

If LILO fails to boot after you install Linux, and displays only the first two letters “L,” this may indicate that LILO cannot access the Linux boot kernel, because it might have been installed on a disk cylinder with a number greater than 1024. This problem can occur with early versions of LILO, and on older notebooks with large internal hard drives. The solution is to create your native Linux partition, with the boot kernel, below the 1024-cylinder limit. Another solution is to use another operating system’s partition to store the Linux kernel. Browse to http://sdb.use.su/de/sdb/en/html/1024_Zylinder.html for details and fixes.
