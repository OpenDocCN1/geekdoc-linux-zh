Follow these steps:

Boot Linux and install your PCMCIA network card(s).

Make sure that Card Services recognizes your card(s), and then use the *ifconfig* command to assign an IP address to the card attached to the DSL modem, like this:

```
# ifconfig eth0 0.0.0.0 up
```

If you have another Ethernet card, use this command line, but assign the IP address 0.0.0.0 to eth1, not eth0.

Make sure your DSL modem is plugged in and turned on, the phone line is attached, and an Ethernet cable is properly attached to the modem and your notebook’s Ethernet adapter.

Browse to http://www.roaringpenguin.com/pppoe.html, and download the file rp-pppoe.1.7.tar.gz (or the latest version).

Decompress the software using the *tar* command like this:

```
# tar xzvf rp.gz
```

Change the directory to the new folder with the *cd* command:

```
# cd rp-pppoe
```

Start compiling and configuring like this:

```
# ./go
```

After you press Enter, the software will configure, build, and install itself. You’ll then see the following:

```
Welcome to the Roaring Penguin ADSL client setup. First, I will run some checks on your system to make sure the PPPoE client is installed properly...

Looks good! Now, please enter some information:
USER NAME
Enter your PPoE user name:
```

Enter your username (assigned by Bell Atlantic) and then press Enter. You’ll then see this:

```
INTERFACE
Enter the Ethernet interface connected to the ADSL modem (default eth1):
```
