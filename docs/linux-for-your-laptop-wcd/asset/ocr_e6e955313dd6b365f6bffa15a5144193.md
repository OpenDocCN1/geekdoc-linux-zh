# Maximizing Drive Space

Linux comes with many different drive utilities that work with different types of storage media, ranging from floppies to hard drives to flash RAM cards. Most of these utilities are designed to make Linux work better with your hardware, but in some cases you can squeeze out a little extra performance and storage area by running these programs.

# Using Floppy Disks

Most notebooks (with the exception of the Apple iBook) come with an internal or external floppy disk drive. Linux supports the floppy fdisk through a generic device, such as /dev/fd0, for the first drive or specific devices, like this:

```
```
$ ls /dev/fd*
/dev/fd0        /dev/fd0360     /dev/fd0u3200   /dev/fd1h1440   /dev/fd1h720
/dev/fd0360     /dev/fd0h1200   /dev/fd0u3520   /dev/fd1h360    /dev/fd1u1440
/dev/fd0720     /dev/fd0u360    /dev/fd0u3840   /dev/fd1h720    /dev/fd1u2880
/dev/fd0h1440   /dev/fd0h720    /dev/fd1        /dev/fd1360     /dev/fd1u3200
/dev/fd0h360    /dev/fd0u1440   /dev/fd1360     /dev/fd1h1200   /dev/fd1u3520
/dev/fd0h720    /dev/fd0u2880   /dev/fd1h720    /dev/fd1h360    /dev/fd1u3840
```
```

You can tell which floppy devices Linux has recognized by using the dmesg command after booting:

```
```
$ dmesg
...
Floppy drive(s): fd0 is 1.44M
