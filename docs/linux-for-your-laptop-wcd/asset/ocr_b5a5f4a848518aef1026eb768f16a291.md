# Serial-HOWTO, by David S. Lawey

Usually installed under the /usr/doc/HOWTO directory, but also available through http://www.linuxdoc.org.

# Bridging mini-HOWTO, by Christopher Cole

Details how to set up an Ethernet bridge to connect two groups of computers.

# PLIP mini-HOWTO, by Andrea Controzzi

Required reading on how to set up and network two computers using Linux, the parallel ports, and an inexpensive cable. Note that the plip.o module information might be out of date (but it should be OK with 2.0.X kernel distributions).

# PLIP.txt

Found under the /usr/doc/kernel-doc*/networking directory (with Red Hat and Mandrake Linux). Contains technical information regarding the building of parallel-port cables for data transfer.

# Ethernet-HOWTO, by Paul Gortmaker

Good overview information about using Ethernet with Linux and getting started with networking. Has loads of great tips.

# SMB-HOWTO, by David Wood

Possibly dated by new releases of Samba software, this HOWTO is nevertheless a good starting point in learning about Samba and how to use it with Linux. As with any HOWTO, you can find the latest copy at http://www.linuxdoc.org.
