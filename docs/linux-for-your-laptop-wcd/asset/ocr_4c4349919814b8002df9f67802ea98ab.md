# Basic Installation Overview

Before you begin your installation, you should have a pretty good idea of how you're going to use Linux, know a bit more about your notebook's hardware, and understand the storage requirements for your system. You should also know how you're going to boot Linux and what software and services you will use on your new system. You should also know if you're going to install just Linux or configure a dual-boot system using another operating system.

Installing Linux is usually a simple task. Here are the basic steps for installing just Linux and its software:

+   1. Turn on the notebook.
+   2. Insert your Linux CD-ROM.
+   3. Boot to the installation.
+   4. Install Linux (and configure hardware during the installation).
+   5. Reboot the notebook.

If you're configuring a dual-boot system that will host Linux and another operating system on your notebook's hard drive, you'll first need to create room for Linux. Here are the basic steps for installing and configuring a dual-boot system:

+   1. Turn on the notebook.
+   2. Boot to the existing operating system, and then defragment the hard drive.
+   3. Use a commercial utility, or boot with a DOS boot disk and make room for Linux.
+   4. Boot to the Linux installation.
+   5. Install Linux (and configure hardware during the installation).
