# Setting the Shell Prompt

You can view your current shell's prompt by examining your shell's environment variables. For example, search for and display the value of the PS1 variable like this:

```
$ env | fgrep PS1
```

You might see the following value returned:

```
PS1=\u@\h \W\$ 
```

This indicates that the shell prompt should display a bracket ((), the current user's name, and the at symbol (@), followed by the computer's hostname, a space, the current working directory, and a closing bracket. It might look like this:

```
[bash@green bash]$
```

You can redefine your shell prompt, which is usually defined in the file /etc/profile, on-the-fly by using the bash shell's export command. For example, if you prefer to have the date and time instead, you can use this:

```
$ export PS1='\d \t -> '
```

After you press Enter, you'll see the following:

```
Thu Mar  9 16:01:19 ->
```

The bash shell recognizes 23 different backslash (\) special characters, such as \d and \t (just shown), along with underlining, boldface, blinking, and other attributes. Read the bash man page's PROMPTING section for details.
