# Creating /dev/modem with Red Hat's modemtool Command

As root, run the modemtool command to create a default /dev/modem device for Linux. Type modemtool on the command line of an X11 terminal window. After you press Enter, you'll see the dialog box shown in Figure 15.1.

Choose a serial port used with your modem, and then click on the OK button. You can also create this link manually using the ln command. For example, if your modem is attached to a port corresponding to DOS COM1, you would type

```
# ln -s /dev/ttyS0 /dev/modem
```

The ls command will then verify this new symbolic link:

```
# ls -l /dev/modem
lrwxrwxrwx    1 root root    10 Mar 23 09:44 /dev/modem -> /dev/ttyS2
```

# Dialing Out with Communications Programs

Miquel van Smoorenburg's minicom program is located under the /usr/bin directory. It is a friendly communications program you can use to test your serial port and modem. As root, start the X11 version of minicom, named xminicom (actually a shell script that launches minicom in a separate terminal window) from the command line of an X11 terminal window like this, using its -s (setup) option:

```
# xminicom -s
```

![](img/70d85e6f4d1ff2750ca2a98ba3d9855c_359_0.png)

Figure 15.2 Create default minicom settings to use your modem.

If you're at the console and not running X11, just use the minicom command along with the -s option. After you press Enter, you'll see the window shown in Figure 15.2. Scroll down to select Serial port setup and press Enter. You can then type in the Serial Device by pressing the A key, as shown in Figure 15.3.

![](img/70d85e6f4d1ff2750ca2a98ba3d9855c_359_1.png)

Figure 15.3 Configure a serial port for minicom by entering the proper device, such as /dev/modem.

After you type in `/dev/modem`, press Enter. You can also change other settings, such as speed or handshaking, by pressing E or F. When finished, press Enter. If you're done, use the Save setup as default menu entry, and then select the Exit option. This will save your changes to become the default for minicom.

You can then use a simple `at` command line, along with the `dt` option and your ISP's phone number, to dial out. For example, type the following:

```
atdt555-1212
```

The `dt` command tells your modem to use a dial tone when calling. Consult your modem's manual for the full list of your modem's commands. After you press Enter, you should hear your modem dialing the phone number. If not, go back and recheck your connections and port settings. To exit minicom, press Alt+X and then Enter.

# Connecting Using netcfg

To set up a PPP connection using Red Hat's network configuration tool, `netcfg`, log in as root, start an X11 session, and run the command from Red Hat's control panel or the command line of an X11 terminal window like this:

```
# netcfg &
```

After you press Enter, you'll see a dialog box. Click on the Interfaces tab along the top, and you'll then see the window change to resemble Figure 15.4.

# Resolving Problems with /etc/resolv.conf

You might also need to edit your system’s /etc/resolv.conf file to add the IP addresses of your ISP’s Domain Name Service computers. If you connect to your ISP but find that you cannot ping remote computers or browse the Web, check the file /etc/resolv.conf to make sure your ISP’s DNS IPs are entered like this (your numbers will be different):

```
nameserver 151.168.2.201
nameserver 191.168.2.202
```

# Connecting Using kppp

The *kppp* client is included with the K Desktop Environment, which runs on top of the X Window System and Linux. This client is much like *netcfg* but is only used to set up PPP connections. However, *kppp* allows you to save multiple configurations and different accounts on your notebook. This can be very handy if you travel around the country or use different ISPs at home and at work; you can save account definitions using different phone numbers and even different usernames and passwords!

To begin, make sure your modem is working with Linux. Next, launch the *kppp* client from the KDE desktop panel by selecting the Application Starter, Internet menu item. You can also launch *kppp* from the command line of an X11 terminal window like this:

```
# kppp &
```

After you press Enter, you’ll see a quick notice dialog box, and then the main *kppp* entry window, as shown in Figure 15.11.
