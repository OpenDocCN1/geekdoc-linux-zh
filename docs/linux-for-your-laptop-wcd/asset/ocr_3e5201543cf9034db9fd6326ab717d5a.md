Most Intel-based notebooks today use a 1.44MB floppy. If you have an older notebook with a 720KB floppy, however, you can use the setfdprm command, along with the /dev/fd0 device and a setting to properly format a floppy:

```
```bash
# setfdprm -p /dev/fd0 720/720
```
```

You would then use fdformat to perform a low-level format. If you want to skip using setfdprm, you can also specify the proper device directly:

```
```bash
# fdformat /dev/fd0720
```
```

To create a Linux filesystem on the floppy, use the mk2fs command and the device name like this:

```
```bash
# mk2fs -C -v -L "Linux" /dev/fd0
```

To access this new Linux floppy, you would use the mount command, its -t option, and a specified directory:

```
```bash
# mount -t ext2 /dev/fd0 /mnt/floppy
```

# Making Extra Room

After mounting the floppy, you can use the df (disk free) command to show how much room is available for files:

```
```bash
# df /mnt/floppy
Filesystem               Size  Used Avail Use% Mounted on
/dev/fd0                 1.4M   13K  1.3M   1% /mnt/floppy
```
