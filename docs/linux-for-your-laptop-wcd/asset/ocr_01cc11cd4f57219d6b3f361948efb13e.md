You'll see the day, month, date, time, and year, along with a number indicating a time drift factor (which can be used in subsequent calls to help adjust your notebook's clock). If you want to see the Linux system time, use the `date` command, like this:

```
`# date`
`Wed Mar 1 21:32:24 EST 2000`
```

The `hwclock` command and its `--hctosys` option set the Linux system time to match your notebook's hardware clock:

```
`# hwclock --hctosys`
```

If you want to set the hardware clock from the Linux system time, use the `--systoqh` option:

```
`# hwclock --sys-to-hc`
```

# ### Can't Keep Track of the Time?

If you have a hard time keeping your notebook's hardware clock and Linux kernel time synchronized, read the `hwclock` man page. You'll learn that all hard-ware clocks are subject to drift, and you'll also see how you can adjust the time for better accuracy. Another alternative is to use the `rdate` command when you have an active Internet connection. This is a great way to have the most accu-rate time available. Use the `rdate` command along with its `-s` (set) option, followed by an accurate source of time, such as time.nist.gov:

```
`rdate -s time.nist.gov`
```
