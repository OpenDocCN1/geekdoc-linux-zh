Use the Up and Down arrow keys to navigate between your created partitions. Use the Tab key to navigate between cdisk's menu items. When finished, use the Tab key to select the *Write* item and press Enter to save your new partition table. When finished, select *Quit*, and then press Enter.

You'll then see a menu that asks you to initialize and activate your new swap partition. Select

Next   : *Initialize and Activate a Swap Partition*

You'll then be asked to select the swap partition from a menu. Press Enter to continue. Next, you'll be asked if you want to scan for bad blocks. Use the Tab key to select *Yes* or *No* and press Enter. Scanning for bad blocks will take extra time, but you can generally skip this step if you know your hard drive is in working order. You'll then be asked to confirm this action.

After selecting *Yes* or *No* and pressing Enter, you'll see a menu that asks you to initialize and activate your new Linux partition(s). Select

Next   : *Initialize a Linux Partition*

As before, you'll then be asked to select the partition from a menu. Select your Linux partition and press Enter to continue. As before, you'll be asked if you want to scan for bad blocks. Use the Tab key to select *Yes* or *No* and press Enter. Again, you'll need to confirm this action. The installer will then format the select Linux native partition, as shown in Figure B.4.
