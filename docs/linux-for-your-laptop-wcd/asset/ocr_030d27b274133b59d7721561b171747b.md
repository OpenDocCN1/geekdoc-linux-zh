# # Using Samba

If you need to connect your notebook to a Windows network, you can use several utilities included with Linux in the Samba package to send and retrieve files. Other portions of the Samba suite of programs support file sharing from Linux and support printing either to or from Windows. This section introduces a few basic steps on the Windows and Linux side to get you started with Samba. However, a complete discussion of this package is beyond the scope of this book.

# ## Setting Up for Samba

After you properly install and configure a network card in your Windows computer, you should enable file and print sharing access. You should then have the computer's name, workgroup, and volume name (the computer name and workgroup information are available through the Network Control Panel's Identification tab).

On your notebook, log in as the root operator. Add the IP address of the Windows computer to the system's /etc/hosts file. Save the file, exit your editor, and then use the `ping` command to test the connection. On the Windows computer, run the MS-DOS Prompt application from the Start menu, and use the `ping` command to test the connection to your notebook.

From your Linux computer, use the `smbclient` command and its -L option to list resources available on the Windows machine:

```
# smbclient -L stinky
Added interface  ip=192.168.2.38  bcast=192.168.2.255  nmask=255.255.255.0

Password:

        Sharename   Type   Comment
        ---------   ----   -------
        C           Disk    stinky's laptop drive
```
