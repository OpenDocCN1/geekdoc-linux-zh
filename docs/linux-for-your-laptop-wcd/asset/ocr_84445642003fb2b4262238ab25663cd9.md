You can get by with using 800×600 and even smaller resolutions, but you'll need to use every trick in the book to get the most out of this size of screen real estate. One technique familiar to experienced mobile Linux X11 users is to use a virtual screen setting in the system's XF86Config file. If your notebook has enough extra video RAM and if you use a low-enough color depth setting, you might be able to craft a virtual screen that extends beyond your notebook LCD's physical limitations.

Virtual screen modes are defined in your XF86Config Screen Section's Display subsection. For example:

```
# Screen sections
# ***************

# The Colour SVGA server
Section "Screen"
Driver "svga"
Device "My Video Card"
Monitor "LCD Panel 1024x768"
Subsection "Display"
Depth 16
Modes "1024x768" "800x600" "640x480"
Virtual 1152 900
ViewPort 0 0
EndSubsection
EndSection
```

In this example, a virtual screen size of 1152×900 has been created. However, you need to read the man page for your notebook's X11 server (XF86_SVGA in this example) to determine the virtual screen sizes supported by the server. When you restart X11, your notebook's server will choose a setting that matches this virtual size as closely as possible.

When you use a virtual screen entry, the ViewPort setting is used to set the initial view (upper-left corner) when the X session is started. You can change this setting to have the initial view of the lower-left corner. Using the preceding example, the ViewPort entry would look like this:

```
ViewPort 0 132
```
