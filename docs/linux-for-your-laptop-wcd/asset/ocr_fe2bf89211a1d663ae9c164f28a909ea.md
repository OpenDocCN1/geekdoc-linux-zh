# Alternative Synchronization Devices

If you don't have much information to synchronize or save as a backup, there are other devices you can use with your notebook. These devices do not have to be expensive. With a little ingenuity, you can devise creative strategies to back up important information.

# Using Flash Memory

One of the least-expensive ways to quickly and (more important) safely save important data is to use a flash memory card with Linux. Flash memory cards, also known as ATA Flash drive cards, flash, or compact flash, are memory cards in PCMCIA form factors, usually of Type II. This means that if you have two PC card slots available in your notebook, you can use an additional two “mini” hard drives with Linux on your notebook.

Flash memory cards are well supported under Linux, thanks to David Hinds' Card Services. First, ensure that Card Services is running on your notebook. Red Hat and Mandrake Linux users should ensure that the proper entries exist in the file pcmcia under the /etc/sysconfig directory. Next, make sure that the Card Services daemon is running by using the following:

```
#  /etc/rc.d.init.d/pcmcia start
```
