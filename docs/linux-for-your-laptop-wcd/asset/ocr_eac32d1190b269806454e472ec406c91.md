Not all the output is shown here.

You can also use the `t` option with the `tar` command’s `z` option to decompress the file and combine two steps into one. For example, to see a list of the contents of a compressed tape archive, such as `xpat2.tar.gz`, you would use this:

```
# tar tzf xpat2.tar.gz
```

Viewing the contents of a compressed archive is the safest thing to do before blindly decompressing its contents. You can also view the contents of an .rpm archive by using the `-qpl` option:

```
# rpm -qpl xpat2-1.04-2.i386.rpm
```

This will query the package and list, or print the contents and file destinations of files within the archive. To extract and install the contents of an .rpm file, use the `-ivh` option, followed by the name of the .rpm file:

```
# rpm -ivh xpat2*.rpm
```

To extract the contents of a compressed tape archive, use `tar`’s `x` (extract) option:

```
# tar xzf xpat2.tar.gz
```

# ### Creating Archives

Creating compressed archives is an easy way to quickly back up important data. For example, you can easily back up the contents of all your users' directories like this:

```
# tar cvzf home.tgz /home
```

By creatively combining your compression utilities and Linux scheduling, you can quickly build an automated backup system. If your backup needs are modest, you can save multidisk archives to floppy disks quite easily if you use the `tar` command’s `w` option:

```
# tar cvwM /dev/fd0 /home
```

When the disk fills up, the `tar` command returns this prompt:

```
Prepare volume #2 for /dev/fd0 and hit return:
```
