# Vendnor Splendor

While this book was being developed, a number of notebook manufacturers and vendors stepped forward to offer Linux on a notebook. In February 2000, Dell Computer Corporation started offering Linux on one model of its Inspiron 5000 series of laptops (interestingly, without any fanfare). Other vendors, such as Tuxtops (http://www.tuxtops.com), have arrived on the scene to provide an alternative software platform for several models of laptops. And in April 2000, eLinux.com (the same folks from PCMall and MacMall) started offering Linux on an “OpenBook” series of laptops. Buying a notebook with Linux preinstalled is the easiest way to avoid installing Linux and is the best way to avoid paying for commercial software you don’t want and don’t need!

# Using a Boot Manager

As you know, there are a number of ways to install and boot Linux. How you decide to start Linux on your notebook is up to you. There are ways to boot multiple operating systems and multiple ways to set up your notebook for booting these operating systems.

If security is an issue, you can also set up your boot manager to use a password. An even better approach is to put the boot manager on a removable device, such as a floppy, and also require a password. Although no hard drive is secure unless it is removable and under lock and key, you can take some basic steps to protect your data.

Every Linux distribution comes with two or more boot utilities. The most commonly used utility is the Linux Loader (LILO). This boot manager may be installed in the Master Boot Record of your notebook’s hard drive, in your Linux root partition, or on a floppy. Other boot managers include PowerQuest’s BootMagic (which might be included as value-added software with some commercial Linux distributions).

# Boot Management with BootMagic

BootMagic is a boot-loader utility that supports a number of different operating systems. The program basically provides a graphical interface in which you can use the mouse or keyboard to select and boot an installed operating system on your notebook. BootMagic is most often installed along with PowerQuest’s commercial partitioning utility, PartitionMagic.
