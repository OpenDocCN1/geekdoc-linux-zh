# # Mailing Lists

If you're an avid e-mail fan, and you want to participate in discussions about notebooks and Linux, subscribe to a Linux laptop mailing list. These lists work by sending an incoming message from a subscriber to all other subscribers. Queries and replies can be almost instantaneous, depending on how the mail list is set up.
