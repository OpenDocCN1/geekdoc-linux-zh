If you like simulation strategies, try xlineity. This game, which can be used at the console or under X11, features built-in help, more than 30 city-building tools, and a variety of controls you can use to simulate a city and its progress through history. Start the X11 version from the command line like this:

```
# xlineity &
```

After the splash screen appears, press any key on your keyboard. You’ll see the window shown in Figure 18.6.

To start a game using a predefined (built-in) scenario, click on the Load button. You’ll then be asked if you want to play “Good Times” or “Bad Times.” Click on either the Good Times or Bad Times button. You’ll see the game board shown in Figure 18.7.

The LinCity controls are in the lower-right corner of the window. They allow you to change the pace of the simulation, load and save games, get help, and quit. Click on the Help button to learn more about when and how to use the city-building tools in the LinCity window. This simulation game can provide hours of fun!
