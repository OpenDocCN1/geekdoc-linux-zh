# ### Installation via FTP

Installing Linux via FTP is very easy. If you're working on a local LAN and you have another Linux computer set up as an FTP server, you can have your Red Hat Linux CD-ROM mounted directly in the /home/ftp/pub directory. Use the mount command like this:

```
# mount -t iso9660 /dev/cdrom /home/ftp/pub
```

In this example, the CD-ROM device is /dev/cdrom (it could be /dev/hdc, or another device, depending on the remote computer). The Linux CD-ROM is then mounted at the /home/ftp/pub directory and made available for public use. Note that other distributions, such as SuSE Linux, might use the /usr/local/ftp directory for anonymous logins and that the remote computer must be running the FTP daemon!

After you choose the FTP installation and press Enter, the installation will recognize your network card and display the dialog box shown in Figure 4.6.

If you're on a network that provides the Dynamic Host Control Protocol (DHCP) service, choose that service and press Enter to have an Internet Protocol (IP) address automatically assigned to your adapter.
