# Resource Information

http://www.worldvisions.ca/~apenwarn/apmd/

Avery Pennarun's home page for Linux apmd (advanced power management) information.

http://www.microsoft.com/HWDEV/busbios/amp_12.htm

A page at Microsoft's Web site that archives information regarding the APM version 1.2 standard.

http://www.teleport.com/~acpi/

A Web page hosting the Advanced Configuration and Power Interface specification (ACPI), an open industry specification co-developed by Compaq, Intel, Microsoft, Phoenix, and Toshiba. ACPI provides a layer of programming information between hardware and software. This includes smart battery programming, chip designs, and operating system kernel interrupt specifications, along with BIOS settings.

apmd-list@worldvisions.ca

The Linux apmd mailing list. Send a message with the subject "subscribe" to apmd-list-request@worldvisions.ca to subscribe.
