Let's start with a discussion of the Linux command-line interface, known as the console, or text-only mode. Knowing how to use the Linux command line, or the shell, is an important skill and forms the basis for learning everything else about Linux. For users migrating from other operating systems and who aren't familiar with DOS, the command line might at first seem intimidating—but don't worry! You can quickly master the command line by understanding a few simple concepts and learning a small number of commands.

# Using the Console

The main interface to the Linux kernel, which is the core operating system, is the shell. Linux comes with nearly a dozen different shells, but most users will opt for the default shell, named bash (the Bourne-Again Shell) just one of thousands of programs provided by the Free Software Foundation, and it's critical to working with Linux. The shell interprets your commands and sends information to the Linux kernel, which in turn launches your commands or provides other services, such as opening, reading, writing, and closing files.

The bash shell has a number of different features, such as providing in-memory variables, known as environment variables; a customizable prompt, or shell prompt; built-in help; and the ability to send input or output to the display, other programs, or other files, which is known as input/output redirection. Input and output redirection is used to specify where keystrokes, text, or programs get input and where the results should be sent, such as to a file or device. For example, you can build an instant catalog of all files under the /usr/doc directory like this:

```
$ ls -lR /usr/doc >helpfiles.txt
```
