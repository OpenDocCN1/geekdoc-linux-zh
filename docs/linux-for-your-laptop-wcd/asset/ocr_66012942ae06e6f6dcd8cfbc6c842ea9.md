In this example, two services are listed: ftp, which is enabled, and telnet, which is disabled. When Linux is booted, the /etc/inetd.conf file is consulted on what services should be enabled. You should know that, in this example, only the telnet server, in inetd, is disabled, not the ability to use the telnet command to connect to another machine, like this:

```
# telnet green
Trying 192.168.2.JX...
Connected to green.home.org.
Escape character is '^]'.
Linux Mandrake release 6.1 (Helios)
Kernel 2.2.13-4mdk on an i686
login:

```

The same is true when the ftp server is disabled. You can still use the ftp command like this:

```
# ftp ftp.primapub.com
Connected to ftp.primapub.com.
220-Script FTP-Server v2.5e for WinSock ready...
220-Welcome to Prisma Communications Private PPP

220-Site. Unauthorized access is strictly
220-prohibited.
220
Name (ftp.primapub.com:willis):

```

If you make changes to /etc/inetd.conf, you should then restart the daemon like this:

```
# /etc/rc.d/init.d/inetd restart

```

Editing /etc/inetd.conf is one of the first tasks you should perform after installing Linux, especially if you are configuring server operations. Some Linux distributions, such as SuSE Linux, do not enable a wide range of services by default. Red Hat, Mandrake, and Yellow Dog Linux also include several server software control programs with a graphical user interface (GUI). One program is ntsysv, which may be called from the command line of an X11 terminal window or at the console. Type ntsysv and press Enter. You'll then see the dialog box shown in Figure 3.1.

Scroll through the list to highlight an entry, and then press the spacebar to select (with an asterisk) or unselect a service. Another, but perhaps more complex, program is the chksysv command. This command requires you to run X11, but it can be used to start, stop, or reorder various services according to your system's operations state, or runlevel.
