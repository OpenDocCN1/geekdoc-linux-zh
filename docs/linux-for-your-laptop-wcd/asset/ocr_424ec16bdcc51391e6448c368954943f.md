# Symbolic Pointer Device

Linux can recognize and use many different pointer devices. This means you can attach an external rodenstimeter (mouse) to your notebook and use it during your sessions. In general, most distributions create a symbolic link, or pointer, to the actual device under the dev directory, named /dev/mouse. For example:

```
# ls -1 /dev/mouse
lrwxrwxrwx 1 root root 5 Oct 12 08:53 /dev/mouse -> psaux
```

This shows that the pointer used is attached to /dev/psaux, or a PS/2 port on the computer. A serial mouse, on the other hand, would probably look like this:

```
lrwxrwxrwx 1 root root 5 Oct 12 08:53 /dev/mouse -> ttyS1
```

This indicates that the mouse is attached to a serial port, similar to COM2 under DOS. Under Linux for the iBook, this link looks like this:

```
lrwxrwxrwx 1 root root 5 Oct 12 08:53 /dev/mouse -> a2dmouse
```

# Other Input Devices

Linux and X11 support many other types of input devices. Look at the file named xinput under the /usr/X11R6/lib/X11/doc directory. You'll see a listing of more than a dozen devices, including the following:

+   - AceCad table
+   - Calcomp DrawingBoard tablet
+   - Elographics touchscreens
+   - Joysticks (which have to be attached through a PCMCIA adapter)
+   - MicroTouch touch screen stylus
+   - SGI button box
+   - SummaSketch tablet
+   - SWITCH virtual device
+   - Wacom cursor
+   - Wacom eraser
+   - Wacom stylus

You'll probably see many more compatible devices.
