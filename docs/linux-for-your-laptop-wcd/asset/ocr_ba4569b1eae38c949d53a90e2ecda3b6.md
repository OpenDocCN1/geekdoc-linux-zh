# # Planning Considerations

New mobile Linux users usually choose to install as much software as possible when first using Linux. Considering that some Linux distributions (such as SUSE) now include up to six CD-ROMs of software, this can be a daunting and lengthy task. Fortunately, nearly every distribution includes a choice selection of the very best free software on a single installation CD-ROM. This is still true of Red Hat, Mandrake, and Yellow Dog Linux, although you'll find that commerical versions also include additional software (such as Yellow Dog's "Tasty Morsels" CD-ROM).

Experienced mobile Linux users are cognizant of their notebooks' limitations. They plan new installations or upgrades according to the manner in which the notebook will be used (such as for development, server operations, text editing, graphics editing, or mobile communications). Part of this planning includes creating a strategy for disk use and deciding how much disk space to allocate for Linux software, temporary storage, additional storage, future expansion, or other operating systems. This is called developing a *partitioning* strategy.

# ## Plan and Pick Partitioning Strategies

See Chapter 5, "Starting the Installation," for details about how to allocate software on your hard drive for Linux. You'll learn about how Linux organizes its directories, *or file system*, and how to make the most out of your hard drive space.

Before you install Linux on your notebook, you need to ask yourself the following questions:

+   - How much disk space is available on my notebook?
+   - Will I boot one or more operating systems?
+   - If I boot more than one operating system, how much disk space should be allocated to each?
+   - Do I need to keep separate disk space free (such as for backups or temporary files)?
