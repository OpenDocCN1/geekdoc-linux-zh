Red Hat, Mandrake, and Yellow Dog Linux include Red Hat's `timetool` client. This command requires that you run X11. It may be started from the command line of an X11 terminal window like this:

```
# timetool &
```

After you press Enter, you see the dialog box shown in Figure 16.1. You can use it to set the date and time.

Another command you can use from the console to set the system date and time is the `date` command. In its simplest form, use the `date` command followed by the month, day, hour, and minute, like this:

```
# date 03221200
```

Wed Mar 22 12:00:00 EST 2000

After you press Enter, the `date` command displays your new system time.
