+   * Fully supported under Linux by David Hinds' Card Services and the Linux PCMCIA kernel modules.
+   * Recognized as an ATA/IDE hard drive when inserted into your notebook.
+   * You can mount and unmount the file system quickly and easily.
+   * It's easy to erase and reformat with VFAT or a Linux filesystem.
+   * Data is relatively secure after it's written to flash RAM and the card is removed from your notebook (this is a good security feature).

To use a flash RAM PC card (which usually comes in a Type II form factor), make sure Card Services is running on your computer:

```
# /etc/rc.d/init.d/pcmcia start
```

Next, insert the card and listen for two high beeps. Use the `dmesg` command to look for output:

```
# dmesg
...
hda: SunDisk SDCPB-8, ATA DISK drive
ide2 at 0x100-0x107,0x10e on irq 9

hde: SunDisk SDCPB-8, 7MB w/1kB Cache, CHS=245/2/32
  hde: hde1
ide_cs: hde: Vcc = 3.3, Vpp = 0.0
VPS: Disk change detected on device ide2(33,0)
hde: hde1
...
```

Next, mount the card (as root) to a specified directory, such as `/mnt/flash`, using the device found in the `dmesg` command output:

```
# mount -t vfat /dev/hde1 /mnt/flash
```
