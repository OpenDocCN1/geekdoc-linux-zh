# ## PLIP Installation

If you have a spare computer and a correctly wired 12-conductor parallel port, you can install Linux onto your notebook. Your first task should be to read the PLIP- Install HOWTO document, found under the /usr/doc/HOWTO directory or through http://www.linuxdoc.org. Although this HOWTO describes using an alternative Linux distribution, Debian Linux, you may also use Red Hat Linux.

The basic procedure is to connect the two computers, set up networking and an NFS export or FTP service on the remote computer, and boot your notebook to a network installation. When the installation fails to find a network card, you'll be asked to select a driver, as shown in Figure 4.12.

You might then be asked if you want the installation to autoprobe your notebook's parallel port settings, or to specify settings. In most cases, the autoprobe will work, and you can then proceed through the installation. If you have difficulty, you might want to try setting up networking between two computers using the same parallel cable to make sure it works. You should also make sure that the remote computer is not running the line printer spooler daemon, lpd, and that it does not have the Linux kernel's lp.o printer module loaded. For details about setting up PLIP networking, see the PLIP-HOWTO.
