Next, type `mkbootdisk` at the command line of the console or an X11 terminal window, specify the floppy device and Linux kernel revision, and press Enter:

```
```
# mkbootdisk -device /dev/fd0 2.2.14-15mdk
```

Insert a disk in `/dev/fd0`. Any information on the disk will be lost.
Press `<Enter>` to continue or `~C` to abort.
```

At the prompt, insert a blank floppy disk and press Enter. The `mkbootdisk` command will then create a boot disk. You can use this disk if your boot loader (such as LILO, discussed in a moment) is ever corrupted.

# # LOADLIN

You can also boot Linux directly from a DOS session using a program named LOADLIN. This program is quite flexible. It may be used to boot to Linux using a Linux kernel on a DOS C:\ drive. Where Linux is installed on another partition (such as /dev/hda3), it can be used like this:

```
```
loadlin c:\vmlinuz root=/dev/hda3 ro
```

This command line will boot Linux using the vmlinuz kernel and then use the Linux partition on /dev/hda3. You should find documentation about LOADLIN included on your Linux distribution's CD-ROM. LOADLIN is also mentioned in several HOWTO and mini-HOWTO documents installed on your system under the /usr/doc/HOWTO directory. You can also read about this program by browsing to the author's home page at http://elserv.fim.fgan.de/~lrxmen/
```

# # LILO

One of the most popular ways to boot Linux is to use the Linux Loader (LILO) program. LILO is generally configured and installed when you install Linux, but it may also be installed and configured after you boot Linux from a floppy disk. This program is a small boot loader that can be installed on a floppy disk, or in various places on your notebook's hard drive.

When you install and boot with LILO, you should see something like this (but your LILO boot prompt might be different):

```
```
LILO
boot:
