# Running a Workstation

Installing a workstation and choosing what software to install can be confusing, especially if you're new to Linux and haven't developed a preference for your development tools, computer language of choice, or window manager or environment for X11. Don't worry. Experienced mobile Linux users learn how to pick and choose the right mix of software tools and information to install, and you will too!

At a minimum, you will need a base installation for both workstation and server operations. This includes the Linux kernel, along with a number of .rpm packages included on your Red Hat, Mandrake, or Yellow Dog Linux CD-ROM. You'll need at least 120MB to install a minimal system without X11. Installing a base system will allow you to use Linux in text (console) mode.

# Running a Server

When you configure your notebook to run as a Linux server, you'll need to add additional software. Nearly all server software runs in the background (invisible to you at the command line). These server processes are known as daemons. Some server packages require little actual hard drive space and remain idle until called, while others are quite active and require numerous configuration files and directories. Table 3.2 lists a number of common server daemons that may be installed on a Linux server.

Under Red Hat, Mandrake, or Yellow Dog Linux, the majority of services are enabled or disabled through the /etc/inetd.conf file. This file contains listings of allowed services, and portions look like this:

```
# These are standard services.
#

ftp	stream	tcp	nowait	root	/usr/sbin/tcpd	in.ftp\ -l -a
#telnet	stream	tcp	nowait	root	/usr/sbin/tcpd	in.telnetd
#
```
