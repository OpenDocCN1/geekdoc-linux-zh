When you install Linux, your notebook's pointer might or might not be automatically recognized. If the pointer is recognized, as with most Intel-based laptops on the market, Linux will configure your device as a two-button PS/2 mouse. When asked if you want to "Emulate 3 buttons?", click OK. If you don't, your mouse will have a left and right mouse button, but no middle button. If you do click OK, the middle mouse button will be emulated by a simultaneous press of the left and right mouse buttons. Awkward? Yes, but at least it works!

Configuration of the pointer for X11 sessions is, like the keyboard, contained in the Pointer section of your system's XF86Config file. For example:

```
Section "Pointer"
 Protocol "PS/2"
 Device "/dev/mouse"
 Emulate3Buttons
 Emulate3Timeout 50
EndSection
```

This abbreviated pointer section shows that the pointer configured for X is a PS/2 two-button mouse. Middle button emulation is 1, with a timeout of 50 milliseconds. The timeout value tells the X server (running in the background) how long to wait before deciding that the middle button (button 2) has been pressed.

# The Apple iBook Mouse

When installing PowerPC or Yellow Dog Linux for the Apple iBook, the mouse is configured as a one-button ADB mouse. Linux for the Apple supports up to 35 different pointing devices. Installing Linux until the mouse is configured can be a little challenging, because you have to use the keyboard to select the proper buttons and dialog boxes. But after it's configured, the mouse works well. According to what the Yellow Dog Linux folks (http://www.yellowdoglinux.com) say in their documentation (for the 1.1 distribution), in order to support three-button emulation, you must use the following Linux kernel boot prompt to tell Linux (and X) to use the F11 and F12 keys as mouse buttons 2 and 3:

```
adb_buttons=1,103,111
```

This does not work for the iBook; instead, you have to use this:

```
adb_buttons=103,111
```

This setting may be entered at the Linux boot prompt or into the BootX options field when booting Linux.
