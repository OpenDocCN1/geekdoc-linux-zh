Another genre of popular game is solitaire. You'll find many different solitaire card games included with your Linux distribution. One of the most popular is xpat2, an X11 client that provides 14 solitaire variants in a resizable window that fits easily on 800×600 notebook displays. Start the game by typing xpat2 at the command line of an X11 terminal window:

```
$ xpat2 &
```
