$ xpat2 &

## Arcade Games

If you’re after action, you’ll find plenty of arcade gaming clients for Linux (along with many new commercial games for Linux). Table 18.2, shown in a moment, lists a number of free KDE and GNOME arcade games. Table 18.1 lists several open source and commercial arcade games for Linux and X11.

Nearly every commercial game for Linux requires more than 100MB of hard drive space (sometimes 400MB or more). These games have features that are equal to (and, in many cases, exceed) those of versions for other computer platforms. System requirement will vary, but many games require displays greater than 800×600. Some games, such as the new *Quake III*, may also need special graphics hardware and software, and will run only on desktop PCs. At this time, nearly all commercial games are only for Intel-based Linux distributions, but you’ll find many free X11 arcade games that work with Yellow Dog Linux on the Apple iBook. You should know that arcade games tax your system’s resources by using many of the available CPU cycles to support graphics and sound. Some games, such as **xboxo**, also require a minimum display of 1024×768 pixels.

One interesting game is actually a simulator. The **f1y8** simulator, which works on different platforms, provides bare-bones scenery but sophisticated controls, as shown in Figure 18.8.
