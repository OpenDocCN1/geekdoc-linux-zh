After formatting, you will then be presented a menu for installing the Linux software. Select

Next : Install Operating System Kernel and Modules

After you press Enter, you’ll be presented a list of sources for the software, as shown in Figure B.5.

Since you’re installing from the software that has already been mounted from CD-ROM, scroll down to select

mounted : already mounted filesystem

After you press Enter, you’ll be asked to select a directory path (such as /debian). Just press Enter. You’ll then be asked to select an archive path. Select

list : Choose from a list of all Archive paths

After you press Enter, you’ll be presented a list of directories. Select the /debian directory from the list, and press Enter to continue. You’ll then be asked to configure device driver modules. Select

Next : Configure Device Driver Modules

You’ll then see a text window, as shown in Figure B.6.
