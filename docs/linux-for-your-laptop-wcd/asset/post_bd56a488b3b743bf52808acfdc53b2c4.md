
## Boot Loaders and Pitfalls

You then type in a keyword, such as `linux` or `dos`, and press Enter to boot the appropriate operating system.

You need to know which hard drive partitions are used for Linux or other operating systems on your notebook in order to use LILO. When you install Linux, be sure to note the device names used for your notebook's hard drive partitions. For nearly all notebooks, including the Apple iBook, the main IDE hard drive is named `/dev/hda`. On Intel-based notebooks, DOS or Windows will most likely be installed on the first partition of the first drive; this partition will be named `/dev/hda1`.

For example, after installing Linux, you can get a picture of your drive usage by using the `fdisk` command, along with the device name for your notebook's hard drive, like this:

```
$ fdisk /dev/hda
```

```
Command (m for help): p

Disk /dev/hda: 128 heads, 63 sectors, 525 cylinders
Units = cylinders of 8064 * 512 bytes

   Device Boot    Start     End    Blocks  Id  System
/dev/hda1 *         1     127    512032+  6  FAT16
/dev/hda2         128     515   1564416  5  Extended
/dev/hda4         516     524     36288  a0  IBM ThinkPad hibernation
/dev/hda5         498     515    72544+  82  Linux swap
/dev/hda6         128     497   1491777  83  Linux
```

```
Command (m for help): q
```

In this example, Windows is installed on `/dev/hda1`, and Linux is installed on `/dev/hda6`. The Linux swap partition is used by Linux to temporarily cache portions of memory, and the hibernation partition is used by this particular notebook for suspend-to-disk operations. By looking at the system's filesystem table, `/etc/fstab`, you might see this:

```
$ cat /etc/fstab
/dev/hda6    /      ext2  defaults    1  1
/dev/hda1    /mnt/dos  vfat  defaults    0  0
...
```

This shows that /dev/hda6 hosts the root (/) Linux directory, and the Windows partition is mounted at /mnt/dos. The LILO configuration file /etc/lilo.conf would then look like this:

```
# cat /etc/lilo.conf

boot=/dev/hda
map=/boot/map
install=/boot/boot.b
prompt
timeout=50

image=/boot/vmlinuz-2.2.13-7mblk
        label=linux
        root=/dev/hda6
        read-only

other=/dev/hda1
        label=dos
        table=/dev/hda
```

This shows that LILO is configured to boot either Linux or Windows, depending on whether the word *linux* or *dos* is typed at the LILO boot: prompt. The *LILO boot=* entry shows that LILO is installed in the Master Boot Record (MBR) or the first IDE drive in the notebook.

If LILO is not installed when you install Linux, you'll need to use a boot disk. After booting, you can install LILO by creating or editing /etc/lilo.conf and then running LILO from the command line like this:

```
# /sbin/lilo

Added  linux *
Added  dos
```

In this example, which uses the /etc/lilo.conf file discussed a moment ago, the *lilo* command has written a boot loader into the MBR of the notebook's main partition. Since the Linux entry is first in the /etc/lilo.conf file, Linux will be the default operating system booted. Details about various options you can use in the /etc/lilo.conf file are documented in the *lilo.conf* man page. For example, you can do the following:

- Use password protection at the LILO boot: prompt.
- Boot different versions of the Linux kernel.
- Boot multiple operating systems.
- Customize the initial text screen.
- Change the default operating system to boot.
- Change the number of seconds LILO waits for a boot: entry.
- Pass special boot-time arguments to the Linux kernel (useful for configuring hardware while booting).

Table 3.3 lists just a few of the options and keywords you can use in your `/etc/lilo.conf` file. If you make any changes to this file, don’t forget to run `/sbin/lilo` afterward!

**Table 3.3 LILO Configuration Keywords**

| Keyword | Description |
| :--- | :--- |
| `append` = `message` | Passes the following kernel argument |
| `boot` = `device` | Informs the kernel what device holds the boot sector |
| `image` = `/boot/kernel_name` | Specifies a Linux kernel to boot |
| `label` = `name` | Designates a boot keyword, such as `linux` or `dos` |
| `message` = `file` | Displays the designated text file at the boot prompt |
| `password` = `password` | Requires a password before booting |
| `prompt` | Forces the use of a boot-prompt entry |
| `root` = `device` | Specifies the location of the Linux root partition |
| `timeout` = `number` | Sets a timeout (in tenths of a second) |

If you use only Linux on your notebook, go ahead and install LILO into the MBR of your boot drive. However, if you want to use another operating system, such as Windows, you should know that, with typical disregard, the Microsoft installation will overwrite the MBR. This means that you should install Windows first and then install Linux.

If you use a commercial boot loader, such as PowerQuest’s BootMagic, be sure to install LILO into the root native Linux partition! BootMagic will require the MBR to provide its graphical operating system selection dialog box and will overwrite LILO when installed.

If you install Linux but find that LILO fails to boot properly, you can use the LILO start message as a diagnostic (as documented on page 44 of the LILO User Guide). Table 3.4 lists the diagnostics.

Table 3.4 LILO Diagnostics

| Diagnostic | Description |
| :--- | :--- |
| *blank* | LILO did not load or was not installed |
| L ## | LILO's first stage loaded, but a disk error code (00, 01, 02, 03, 04, or 06) appears; see Section 5.2.2 of the LILO User Guide (page 44 of the guide) |
| LI | LILO's first and second stages loaded, but a disk geometry problem or a LILO map installer problem prevented execution (see Section 3.4 of the User Guide) |
| LIL | LILO's second stage loaded, but a geometry or media failure occurred |
| LIL? | LILO's second stage loaded, but at an incorrect address (perhaps the same problem as LI) |
| LIL- | A corrupted descriptor table prevented proper execution (see the User Guide) |

If you have problems, read the LILO User Guide, found under the */usr/doc/lilo*/doc directory. If you're running Linux, use the `gv` command to display the file like this:

```
> gv /usr/doc/lilo*/doc/User*ps
```

You should also create a backup boot diskette with LILO installed. See Section 4.1.6 (page 37) of the User Guide for details.
