# **Wireless LAN Card Configuration**

This section details the installation and configuration of a low-cost 2Mbps wireless network for Linux using Webgear, Inc.'s Aviator 2.4 wireless network cards. Webgear markets a networking kit consisting of two Type II PCMCIA cards and two ISA PC card slots. When the cards are installed and configured, the interfaces appear as Ethernet devices, such as eth0.

This kit allows you to set up peer-to-peer networking between two laptops, two desktop PCs, or a laptop and a desktop. The ISA PC card slots may be installed in a desktop to allow use of a PCMCIA card. Configuring the cards involves downloading, decompressing, building, and installing the card drivers. Browse to http://world.std.com/~corey/raylink.html to download Corey Thomas' latest version of the Linux driver, ray_cs.o, for the Aviator cards. Then copy the compressed tarball to the /usr/src/linux/pcmcia directory, and decompress the file like this:

```
# tar xzvf ray_cs.gz
```

To configure, build, and install the drivers, do this:

```
# make config
# make all
# make install
```

Next, edit the file /etc/pcmcia/config.opts and insert this line:

```
source ../ray_cs.opts
```

Next, edit the ray_cs.opts configuration file to read as follows:

```
module "ray_cs" opts "pc_debug=2 essid=LINUX hop_channel=128 \
beacon_period=256 translatel=1"
```

Be sure to use the same settings for each computer. Next, use Red Hat's netcfg tool to create an eth0 interface on each computer. The cards must then be started sequentially. Make sure Card Services is running by doing the following:

```
# /etc/rc.d/init.d/pcmcia start
```
