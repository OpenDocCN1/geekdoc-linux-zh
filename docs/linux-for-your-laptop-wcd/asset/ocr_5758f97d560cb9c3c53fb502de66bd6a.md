# Configuring KPilot

When you launch KPilot for the first time, you'll see the dialog box shown in Figure 12.1. It is used to enter settings for the serial port and speed.

When you've finished entering the correct device (such as /dev/ttyS0) and speed (such as 57600), click on the OK button. If you select the Start KPilot at Hot-Sync option, KPilot will start automatically when you click the HotSync button on your Palm's cradle. (Your Palm should be in the cradle, and the serial cord should be properly attached to your notebook's serial port.)

# KPilot Backups

When the main KPilot dialog box appears (as shown in Figure 12.2), click on the File menu (or press Alt+F), then choose the Backup menu item.

If the user information in the Palm does not match your settings in KPilot, you'll be asked to confirm before backup operations begin, as shown in Figure 12.3.

As the backup proceeds, you'll see a small Sync Status progress dialog box (shown in Figure 12.4), listing each database or client being saved from your PDA.
