## Using Linuxconf

The linuxconf command, which can be used with or without X11, continues to evolve and grow in popularity as a system maintenance tool when using a graphical interface to administer Linux. This client features configuration and control for nearly all network and system services for Linux. If you use Red Hat or Mandrake Linux, look under the /usr/lib/linuxconf/help.eng directory for HTML help files, or use linuxconf's built-in help buttons.

## Workstation and Server Requirements

According to Red Hat, Inc., typical requirements are 1.6GB for server operation, 450MB for workstation use, and 120MB for a minimal installation. According to the Mandrake Linux folks, a full Mandrake Linux installation requires a little more than 1GB.

Installing everything included with Yellow Dog Linux on your Apple iBook requires at least 1.5GB.

How much disk space your installation will require also depends on the amount of software you choose to install. When you install Linux, you'll be asked to choose a type of installation. You'll also have the chance to avoid a “default” type of installation and can instead pick and choose your own software packages. This is a good way to avoid installing redundant or unnecessary software. For example, do you really need six different text editors available on your system?

If you're a new user and you have the disk space, go ahead and install everything. You can always go back and remove software to make more room. As you gain experience, you'll be able to quickly run through a new installation on your notebook, and you will know what packages are essential or may be omitted from the installation.

## Minimal Installation Strategies

If you don't have much room on your hard drive, your choices are limited. The good news is that you can perform a minimal installation, one much smaller than the default 120MB system described in Table 3.1. Linux is so versatile that a system may be installed from floppy diskettes (not on the iBook, however), an Iomega Zip drive, or a single executable file.

## WinLinux 2000

If you prefer to avoid the hassle of partitioning and formatting your notebook's hard drive, you can install, configure, and run Linux directly from a Windows desktop by using WinLinux 2000. You'll need at least 500MB of free hard drive space to install the distribution; after that, you can delete the original installation file.

To install this distribution, run the WL2000.EXE installation program and answer the prompts. In less than a minute, you'll boot to Linux with X11 using KDE as a desktop suite. The distribution includes Netscape Communicator and Adobe's free Acrobat reader. This distribution works by creating a virtual filesystem, such as a single 500MB file, on your Windows volume to represent the Linux filesystem.

Browse to http://www.winlinux2000.com/ to download your copy.

## Zipslack

To learn how to download and install Slackware Linux from an Iomega Zip drive, browse to http://www.slackware.com/zipslack/

Here is the basic procedure:

- 1. Download the zipslack.zip, bootdisk.img, and RAMRITE.EXE files. An additional file, fourmeg.zip, supports installation on 386-based notebooks that have only 4MB of RAM!
- 2. Decompress the zipslack distribution onto the Iomega disk.
- 3. (Optional) Use RAMRITE.EXE to create a block disk.
- 4. Run the LOADLIN.EXE command to boot Linux from the Iomega disk.

This will allow you to run Linux from a Zip drive without partitioning your notebook's hard drive. Read the FAQ at the Slackware site just mentioned to learn how to install the zipslack Linux distribution on your notebook.

Slackware Linux is a good alternative if you have little drive storage; a minimal Slackware Linux installation requires only 50MB hard drive space. You can also install Slackware by using floppy disks, but you will need to download numerous disk images, create the disks, and install each disk in sequence.

## Peanut Linux

Another small distribution with the same 50MB footprint is Peanut Linux. However, this distribution includes X11, Netscape Communicator, and a special minimal selection of X11 clients, including the K Desktop Environment. This distribution could be the best choice for a compact yet up-to-date and powerful Linux installation on your notebook. Although Peanut Linux is workstation-oriented, FTP and Web servers are included. Browse to http://metalab.unc.edu/peanut

## Live Filesystems

Some Linux distributions, such as recent versions from SuSE, have the ability to run directly from CD-ROM or to use a *live* filesystem. This is a handy way to boot and run Linux without installation, and it allows you to explore the capabilities of a distribution without partitioning and formatting.

## Floppy Linux

You can also boot and run Linux from floppy disk. Numerous floppy-based distributions provide a Linux environment using one or more floppy diskettes. For more information, see Table A.4 in Appendix A, “Linux Laptop Resources.”

## Choosing a Boot Method

Linux may be booted in several ways. You're given the chance to create a boot floppy during the installation of Red Hat, Mandrake, and most other distributions. You can then use this boot disk when you restart or turn on your laptop. If you did not create a floppy disk diskette during the installation, use Red Hat's `mkbootdisk` command to create one after you boot Linux. You'll need to know which version of Linux you're using, and you'll need to specify the floppy device.

First, use the `uname` command and its `-r` (revision) option:

```bash
# uname -r
2.2.14-15mdk
```

Next, type `mkbootdisk` at the command line of the console or an X11 terminal window, specify the floppy device and Linux kernel revision, and press Enter:

```bash
# mkbootdisk -device /dev/fd0 2.2.14-15mdk
```

Insert a disk in `/dev/fd0`. Any information on the disk will be lost.
Press `<Enter>` to continue or `^C` to abort.

At the prompt, insert a blank floppy disk and press Enter. The `mkbootdisk` command will then create a boot disk. You can use this disk if your boot loader (such as LILO, discussed in a moment) is ever corrupted.

## LOADLIN

You can also boot Linux directly from a DOS session using a program named LOADLIN. This program is quite flexible. It may be used to boot to Linux using a Linux kernel on a DOS C:\ drive. Where Linux is installed on another partition (such as /dev/hda3), it can be used like this:

```bash
loadlin c:\vmlinuz root=/dev/hda3 ro
```

This command line will boot Linux using the vmlinuz kernel and then use the Linux partition on /dev/hda3. You should find documentation about LOADLIN included on your Linux distribution's CD-ROM. LOADLIN is also mentioned in several HOWTO and mini-HOWTO documents installed on your system under the /usr/doc/HOWTO directory. You can also read about this program by browsing to the author's home page at http://elserv.fim.fgan.de/~lrxmen/

## LILO

One of the most popular ways to boot Linux is to use the Linux Loader (LILO) program. LILO is generally configured and installed when you install Linux, but it may also be installed and configured after you boot Linux from a floppy disk. This program is a small boot loader that can be installed on a floppy disk, or in various places on your notebook's hard drive.

When you install and boot with LILO, you should see something like this (but your LILO boot prompt might be different):

```bash
LILO
boot:
```
