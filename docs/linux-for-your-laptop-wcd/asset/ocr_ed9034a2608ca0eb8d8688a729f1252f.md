# # Formatting Floppy Disks

You can quickly format a DOS diskette from the Linux command line with the
mformat command:

```
# mformat a:
```

If you use X11 and the K Desktop Environment, you can also use KDE's kfloppy
client. Start this client from the command line of an X11 terminal window, or
choose the kfloppy menu item from KDE's Application Starter Utilities menu.
You'll see the dialog box shown in Figure 8.1.
