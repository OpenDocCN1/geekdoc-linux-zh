For example, to launch the *kscd* client from the desktop panel, select Application Starter, Multimedia, CD Player. Next, insert your audio CD into your notebook. To configure *kscd* to use the Internet, click on the Tool button. You’ll then see the dialog box shown in Figure 18.10.

Make sure you have an active Internet connection, and then click to select a sample server. When finished, click on the OK button to save your selected server.

After you get the information, you can save it in a local database for use the next time you play the CD. Click on the small CDDb (CD database) icon in the *kscd* player. You’ll then see the dialog box shown in Figure 18.11.
