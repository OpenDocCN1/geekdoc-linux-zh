The Configure script will also search for the XForms library and header files. If they are found, you'll also be able to build, install, and use the cardinfo client for X11! You can now build Card Services like this:

```
```
# make
```
```

To install the new PCMCIA modules (usually located in the misc directory under the /lib/modules/2.X.XX directory, where X.XX is your kernel version), use the make command like this:

```
```
# make install
```
```

After installation, you can start Card Services with this:

```
```
# /etc/rc.d/init.d/pcmcia start
```
```

or this:

```
```
# /etc/rc.d/init.d/pcmcia restart
```
```

The cardinfo client may be started from the command line of an X11 terminal window like this:

```
```
# cardinfo &
```
```

After you press Enter, you'll see the window shown in Figure 6.2.

This client lists any currently inserted cards and provides detailed information about the state, device, IRQ, and I/O ports in use. By clicking on a socket button (as shown in Figure 6.2), you can reset, suspend, resume, eject, or insert a PC card.
