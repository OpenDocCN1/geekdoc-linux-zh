# **TrackPoint Utilities for Linux**

Computer artists familiar with drawing tablets know that the stylus, or pointer, is usually also a pressure-sensitive device that recognizes three-dimensional movement. This means that the artist puts slight pressure on the stylus when using a paintbrush tool, the spread of digital paint will be greater. Lighter strokes result in a lighter brush effect. Unknown to most TrackPoint users is that this pointer also responds to pressure!

Browse to Till Straumann’s Web page at

http://www-hft.es.TU-Berlin.DE/~strauman/tp4utils/

You’ll find two TrackPoint utilities: the **tp4d** server and **xt4a**, a client command you can use to explore the TrackPoint’s capabilities under Linux.

# # Your Notebook’s Memory

Few, if any, problems seem to arise between Linux and notebook memory (problems seem to crop up to a much greater degree with desktop systems). Notebook memory can be proprietary and very expensive. If you’re the fortunate owner of an extremely popular and long-lived line of notebooks (with “long-lived” being a relative term in today’s typical notebook model “life span” of 12 months or less!), memory should be a bit less expensive. Some notebook manufacturers have built models to accept standard sockets, and others use extremely proprietary form factors (such as various Sony models). Buy as much memory as you can afford. If you’re sure you can buy from a third party and install it yourself, save some memory on your purchase and use it to buy and install more RAM.

The biggest question you’ll face will be “How much?” in terms of memory and cost. To that, I answer, “As much as you can afford, but no less than **64MB**.” Even though Linux and X11 can run on 16MB, be realistic. (I used Linux for a long time on one 32MB laptop, and it is still running 24/7 in the basement.) If you want to use X11, the K Desktop Environment, StarOffice, and Netscape and play .mp3 files at the same time, you’ll need a bit of breathing room. Even though Linux and most clients use memory efficiently, with 64MB you’ll be able to use most clients without problems.

If you want to use VMWARE’s VMware for Linux to install and run other operating systems, such as Windows 2000 or BSD UNIX at the same time, you’ll need even more memory—at least as much as for a separate computer for each instance.
