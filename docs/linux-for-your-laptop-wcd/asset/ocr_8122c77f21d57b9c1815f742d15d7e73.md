You then type in a keyword, such as `linux` or `dos`, and press Enter to boot the appropriate operating system.

You need to know which hard drive partitions are used for Linux or other operating systems on your notebook in order to use LILO. When you install Linux, be sure to note the device names used for your notebook's hard drive partitions. For nearly all notebooks, including the Apple iBook, the main IDE hard drive is named `/dev/hda`. On Intel-based notebooks, DOS or Windows will most likely be installed on the first partition of the first drive; this partition will be named `/dev/hda1`.

For example, after installing Linux, you can get a picture of your drive usage by using the `fdisk` command, along with the device name for your notebook's hard drive, like this:

```
$ fdisk /dev/hda
```

```
Command (m for help): p

Disk /dev/hda: 128 heads, 63 sectors, 525 cylinders
Units = cylinders of 8064 * 512 bytes

   Device Boot    Start     End    Blocks  Id  System
/dev/hda1 *         1     127    512032+  6  FAT16
/dev/hda2         128     515   1564416  5  Extended
/dev/hda4         516     524     36288  a0  IBM ThinkPad hibernation
/dev/hda5         498     515    72544+  82  Linux swap
/dev/hda6         128     497   1491777  83  Linux
```

```
Command (m for help): q
```

In this example, Windows is installed on `/dev/hda1`, and Linux is installed on `/dev/hda6`. The Linux swap partition is used by Linux to temporarily cache portions of memory, and the hibernation partition is used by this particular notebook for suspend-to-disk operations. By looking at the system's filesystem table, `/etc/fstab`, you might see this:

```
$ cat /etc/fstab
/dev/hda6    /      ext2  defaults    1  1
/dev/hda1    /mnt/dos  vfat  defaults    0  0
...
```
