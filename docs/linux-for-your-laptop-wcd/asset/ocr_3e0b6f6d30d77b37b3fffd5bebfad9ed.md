The starting point for getting information and software for using Linux and PCMCIA cards.

The home page for the BootMagic boot utility.

The System Command home page.

http://pclinux.apple.com/~benh/

Ben Herrenschmidt, PowerPC Linux hacker extraordinaire, offers PowerPC Linux boot utilities, yaboot, and BootX, along with new Linux PPC kernels on his home page.

http://www.alsa-project.org

The home page of the Advanced Linux Sound Architecture sound package. It’s an alternative source of free sound drivers for many different types of sound cards and notebooks. (ALSA libraries were among the first to support a number of IBM i-series ThinkPads when all other means, including the commercial OSS drivers, failed!)

http://www.alsa-project.org/~valentyn/Alsa-sound-mini-HOWTO.html

The ALSA-sound-mini-HOWTO—Valentijn Sessink’s guide to downloading and installing the ALSA sound drivers.

http://www.opensound.com

The home of the commercial Open Sound System drivers for Linux (and other operating systems). This relatively inexpensive set of sound drivers can make all the difference in the world when you’re trying to configure sound on a trouble- some notebook.
