| kworldwatch | KDE Mercator sun projector |

| rclock | X11 clock client with appointment scheduling |

| ruptime | Shows the status of networked computers |
| sleep | Puts a process to sleep in seconds |
| time | Times a process |
| timed | The timed daemon |
| timetool | Red Hat's graphical client to set the date and time |
| touch | Updates or sets a file or directory's timestamp |
| tzselect | Selects a time zone |
