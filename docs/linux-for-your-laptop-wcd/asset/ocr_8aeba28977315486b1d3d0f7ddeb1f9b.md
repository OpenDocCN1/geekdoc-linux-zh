# Configuring for pilot-xfer

Before you can begin using *pilot-xfer* with Linux and your PDA, you need to know what serial port to hook up the Palm's HotSync cable to on your notebook. You also need to know the name of the serial port, such as /dev/ttyS0. You can see a list of serial ports recognized by Linux when you boot by using the *dmesg* command:

```
# dmesg | fgrep tty
ttyS00 at 0x03f8 (irq = 4) is a 16550A
ttyS01 at 0x02f8 (irq = 3) in a 16550A
ttyS02 at 0x03f8 (irq = 9) is a 16550A
```

Next, use your shell (such as *bash*) to create a *pointer* or *environment variable* that defines PILOT PORT to point to the serial port. For example, if your HotSync cable is attached to COM1, you would use this:

```
# export PILOTPORT=/dev/ttyS0
```

Because most notebooks today come with modern serial ports capable of high-speed data transfer, you can automatically set *pilot-xfer* to use the fastest speed possible when transferring files. Create an environment variable named PILOTRATE, and assign it a serial port speed like this:

```
# export PILOTRATE=115200
```

You're now ready to try *pilot-xfer*!

# IrDA, PDAs, and Linux

You can also use your notebook's IrDA port and an IrDA-capable Palm PDA, such as a Ill, Ille, V, and so on, to back up or install software without resorting to a Hot Sync cable. Browse to http://home.instafl.de/wehe/IR-HOWTO.html to learn how to configure your notebook's IrDA port and Linux to work with your Palm PDA.

# Backing Up Your Palm

One of the most important things you should do occasionally when using your Palm is create a backup of the entire contents of the PDA. To do this using the *pilot-xfer* command, use the `-b` option, followed by the pathname or name of the directory you'd like to hold the backup software. Next, connect your HotSync cable
