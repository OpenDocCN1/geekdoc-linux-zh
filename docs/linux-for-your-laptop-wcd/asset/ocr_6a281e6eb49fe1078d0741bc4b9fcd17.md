You'll end up at the kppp Configuration dialog box. Select the Device tab. You'll see the dialog box shown in Figure 15.17.

Select your modem device (most likely /dev/modem) and choose a line speed. In most cases (but not all; see the later section "Wireless Cellular Connections"), you should choose the highest speed possible, because most modems autonegotiate connections. This means that if your connection is rated at 56Kbps, you can try 115200Kbps.

When finished, select the Modem tab to set modem options. In the Modem dialog box, shown in Figure 15.18, you'll see three buttons: Modem Commands, Query Modem, and Terminal.

The Modem Commands button displays a list of 18 modem commands you can customize, such as initialization strings, hangup commands, and modem speaker volume. The Query Modem button initiates a system test to find any installed modems using serial ports COM1 (/dev/ttyS0) through COM4 (/dev/ttyS3). If one is found, kppp attempts to configure the modem for use during your PPP connection. The Terminal button launches a mini-terminal window in which you can directly communicate with your modem. This is handy if you need to reset or save configuration information.
