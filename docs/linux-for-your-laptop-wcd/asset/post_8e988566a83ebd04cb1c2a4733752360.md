
options to enable the use of an external monitor. For example, NeoMagic chipset users might need to use the following:

```
option “extern_disp”
option “intern_disp”
```

These options, included in XF86Config’s *Device* section, will enable the use of the LCD and external monitor at the same time. You can generally expect to be able to use a greater screen resolution with an external monitor, but this is not always the case. You’ll need to experiment with an external monitor to arrive at the best settings.

## Multithread? Xinerama?

Notebook users probably won’t be able to use the LCD and external monitor as a single monitor, even with the release of the new version 4.0 of XFree86. Although X11 supports this feature, multithread displays are generally hardware-dependent and require a compliant graphics card. The Xinerama feature, although supported by XFree86, requires a compliant or Xinerama-aware window manager—a feature not yet supported for Linux.

## Using Your Mouse with the Console

When you install and boot Linux, your notebook's built-in pointer should be recognized and configured automatically. You'll probably see something like this (on Intel-based notebooks):

```

```

Apple iBook users using Yellow Dog Linux will see a more cryptic statement:

```

adb devices: [2]: 2 c2 [3]: 3 1 [7]: 7 1f

Macintosh ADB mouse driver installed.
```

Double-click to select a word. Triple-click to select a line of text. To select a block of text in the console, click and then drag with the left mouse button depressed. The selected text will be highlighted in reverse video. You can then paste the text by clicking the middle mouse button (or by simultaneously pressing the left and right mouse buttons when your two-button mouse is emulating a three-button mouse). The right mouse button is used to extend selections. If you do not use three-button emulation, the right button pastes the selected (copied) text.

The gpm server is run as a daemon (in the background) and is usually started through an init script (for Red Hat, Mandrake, and Yellow Dog Linux) under the `/etc/rc.d/init.d` directory. The Apple iBook's mouse is initialized by the `/etc/rc.d/init.d/gpm` script with

```
gpm -t bsmouse
```

Owners of an Intel notebook with a built-in PS/2 mouse will find that gpm is initialized with

```
gpm -t ps/2
```

Your notebook's mouse is defined in the file `mouse` under the `/etc/sysconfig` directory; this information is used by the gpm startup script to initialize your notebook's pointer. For Intel-based notebooks, this file looks like this:

```
MOUSETYPE=ps/2
XMOUSETYPE=PS/2
FULLNAME="Generic Mouse (PS/2)"
XEMU3=eyes
```

The Yellow Dog Linux mouse configuration file for the Apple iBook looks like this:

```
MOUSETYPE="Busmouse"
XMOUSETYPE="BusMouse"
FULLNAME="Apple Desktop Bus 1 Button Mouse (ADB)"
XEMU3=eyes
```

These files are created by the Red Hat mouseconfig command. This command, run on the iBook, is used to create the settings and enable other features, such as three-button emulation (see Figure 10.1). Note that your settings might be different if you use a serial mouse.

Three-button emulation is very important for Linux users, especially during X11 sessions, because the right (or third) mouse button is used for right-click operations (such as to set properties), and the middle (or second) mouse button is used to paste selected text or graphics.
