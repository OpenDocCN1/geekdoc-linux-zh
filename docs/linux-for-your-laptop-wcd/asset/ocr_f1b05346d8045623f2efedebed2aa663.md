# Peanut Linux

Another small distribution with the same 50MB footprint is Peanut Linux. However, this distribution includes X11, Netscape Communicator, and a special minimal selection of X11 clients, including the K Desktop Environment. This distribution could be the best choice for a compact yet up-to-date and powerful Linux installation on your notebook. Although Peanut Linux is workstation-oriented, FTP and Web servers are included. Browse to

> http://metalab.unc.edu/peanut

The Peanut Linux distribution may be installed from a CD-ROM or by using Linux (see the file INSTALL.TXT at the link just mentioned).

# Live Filesystems

Some Linux distributions, such as recent versions from SuSE, have the ability to run directly from CD-ROM or to use a *live* filesystem. This is a handy way to boot and run Linux without installation, and it allows you to explore the capabilities of a distribution without partitioning and formatting.

# Floppy Linux

You can also boot and run Linux from floppy disk. Numerous floppy-based distributions provide a Linux environment using one or more floppy diskettes. For more information, see Table A.4 in Appendix A, “Linux Laptop Resources.”

# Choosing a Boot Method

Linux may be booted in several ways. You're given the chance to create a boot floppy during the installation of Red Hat, Mandrake, and most other distributions. You can then use this boot disk when you restart or turn on your laptop. If you did not create a floppy disk diskette during the installation, use Red Hat's `mkbootdisk` command to create one after you boot Linux. You'll need to know which version of Linux you're using, and you'll need to specify the floppy device.
