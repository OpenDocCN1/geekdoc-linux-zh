
This sets up your parallel port using the specified I/O address and IRQ. You can then check your kernel messages:

```bash
$ dmesg
```

```text
...
parport0: PC-style at 0x378, irq 7 [SPP,ECP,PCFPPS2]
```

This shows that the port has been initialized. Next, use insmod to load PLIP support and create your PLIP device:

```bash
$ insmod plip timed=1
```

The timed option instructs plip.o to avoid other I/O addresses or IRQs in use. You can then check for kernel output to see if the device was created:

```bash
$ dmesg
```

```text
...
plip0: Parallel port at 0x378, using IRQ 7
```

Note that the parallel-port device returned (in this example, plip0). You can then use the ifconfig command to bring up the plip interface on each computer (and also to perhaps set the device netmask and so on). For example, on ComputerA, you would use this:

```bash
$ ifconfig plip0 ComputerA pointopoint ComputerB up
```

and on ComputerB you would use this:

```bash
$ ifconfig plip0 ComputerB pointopoint ComputerA up
```

You can then check the interface on each:

```bash
$ ifconfig plip0
```

```text
plip0 Link encap:Ethernet HWaddr FC:PC:C0:A8:02:26 inet addr:192.168.2.38 P-t-P:192.168.2.30 Mask:255.255.255.255 UP POINTOPOINT RUNNING NOARP MTU:1500 Metric:1 RX packets:0 errors:0 dropped:0 overruns:0 frame:0 TX packets:0 errors:0 dropped:0 overruns:0 carrier:0 collisions:0 txqueuelen:10 Interrupt:7 Base address:0x378
```

You can then try to ping, telnet, or ftp to the other computer. Problems you might encounter include bad cables and incompatible parallel ports. To bring down the connection, use the ifconfig command like this:

```bash
$ ifconfig plip0 down
```

## IrDA Networking

You can also establish network connections between a laptop and other laptops, or a desktop PC equipped with an IrDA "dongle." See the Linux IR-HOWTO to learn about setting up networking. Browse to `http://home.snafu.de/wehe/IR-HOWTO.html`. Speeds will be much faster than using a serial or parallel-port connection.

## Setting Up a Crossover Ethernet Connection

This section shows you yet another cost-effective way to network two notebooks, or a desktop and a notebook. If you want to connect a notebook and a desktop or two notebooks via Ethernet, you do not need a networking hub! This method is similar to the serial and PLIP examples. We'll again use the `ifconfig` command to set up each computer's interface.

You'll need to make sure that each computer's IP address and alias are entered in each computer's `/etc/hosts` file. Insert the network cards, and ensure that the card has been recognized and initialized. For example:

```text
# dmesg
...
eth0: NE2000 Compatible: io 0x300, irq 3, hw_addr 00:E0:98:06:84:C5
```

This example shows that a PC network card was recognized and that the `eth0` device was created. Next, connect a Cat 5 RJ-45 crossover cable (not a regular patch cord) to each network card's jack. These cables can be found in most large computer stores. They work by swapping the receive and transmit pairs of wires. For specific directions on building your own, read Paul Gortmaker's Ethernet-HOWTO (found under your `/usr/doc/HOWTO` directory if you install the documentation with your distribution).

After connecting the cable, go to ComputerA and type

```text
# ifconfig eth0 ComputerA pointopoint ComputerB up
```

Then, on ComputerB, type

```text
# ifconfig eth0 ComputerB pointopoint ComputerA up
```

You should look at your cards' indicator lights for a link, and then use the `ifconfig` command to check the status of the interface on each computer like this:

```text
# ifconfig eth0

eth0      Link encap:Ethernet  HWaddr 00:E0:98:06:84:C5
          inet addr:192.168.2.38  Bcast:192.168.2.255  Mask:255.255.255.0
          UP BROADCAST RUNNING MULTICAST  MTU:1500  Metric:1
          RX packets:0 errors:0 dropped:0 overruns:0 frame:0
          TX packets:0 errors:0 dropped:0 overruns:0 carrier:0
          collisions:0 txqueuelen:100
          Interrupt:3 Base address:0x300
```

After you have finished transferring files, you can bring the connection down with the `ifconfig` command like this:

```text
# ifconfig eth0 down
```

## Using Samba

If you need to connect your notebook to a Windows network, you can use several utilities included with Linux in the Samba package to send and retrieve files. Other portions of the Samba suite of programs support file sharing from Linux and support printing either to or from Windows. This section introduces a few basic steps on the Windows and Linux side to get you started with Samba. However, a complete discussion of this package is beyond the scope of this book.

### Setting Up for Samba

After you properly install and configure a network card in your Windows computer, you should enable file and print sharing access. You should then have the computer's name, workgroup, and volume name (the computer name and workgroup information are available through the Network Control Panel's Identification tab).

On your notebook, log in as the root operator. Add the IP address of the Windows computer to the system's /etc/hosts file. Save the file, exit your editor, and then use the `ping` command to test the connection. On the Windows computer, run the MS-DOS Prompt application from the Start menu, and use the `ping` command to test the connection to your notebook.

From your Linux computer, use the `smbclient` command and its -L option to list resources available on the Windows machine:

```text
# smbclient -L stinky
Added interface  ip=192.168.2.38  bcast=192.168.2.255  nmask=255.255.255.0

Password:

        Sharename   Type   Comment
        ---------   ----   -------
        C           Disk    stinky's laptop drive
```

You’ll be asked to enter the file-sharing password you assigned when you set up sharing on your Windows computer. The `-L` option handily lists services available on the computer. As you can see in the preceding example, the Windows computer is a laptop.

## Transferring Files
