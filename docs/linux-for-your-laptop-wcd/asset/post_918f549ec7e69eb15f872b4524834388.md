
# Some Alternatives

Finally, you should know that there are even more ways to install Linux on your notebook. If you have access to the Internet, you can download the Slackware Linux distribution onto a series of floppy diskettes and then proceed to an installation after building a boot floppy.

According to Patrick Volkerding, Slackware's creator and maintainer, the distribution has grown from 10 floppy disks in 1993 to more than 100 floppies. To install a minimal Linux system, you can download Slackware's A series, create a boot disk, and start the installation using your notebook's floppy drive. Once Slackware is installed, you can then add software to enable networking or other devices, such as an Iomega Zip drive.

Slackware Linux may be installed from an Iomega Zip drive. A special "zipslack" distribution is available at http://ftp.slackware.com/pub/slackware/slackware/zipslack/. You install the zipslack distribution by unzipping the distribution onto an Iomega 100MB Zip drive and then attempting a boot using the LOADLIN command from DOS:

```
loadlin vmlinux root=/dev/sda4 rw
```

This will launch Linux. After logging in as root, you can create your Linux partitions and transmit the distribution to your notebook. This is also a great way to try out Linux without partitioning your notebook's hard drive!

Linux may also be configured to boot from a PCMCIA device. See section 5.3, "Booting from a PCMCIA Device," in the Linux PCMCIA-HOWTO document. You'll find a copy under the /usr/doc/HOWTO directory or at http://www.linuxdoc.org.

## Basic Installation Overview

Before you begin your installation, you should have a pretty good idea of how you're going to use Linux, know a bit more about your notebook's hardware, and understand the storage requirements for your system. You should also know how you're going to boot Linux and what software and services you will use on your new system. You should also know if you're going to install just Linux or configure a dual-boot system using another operating system.

Installing Linux is usually a simple task. Here are the basic steps for installing just Linux and its software:

1. Turn on the notebook.
2. Insert your Linux CD-ROM.
3. Boot to the installation.
4. Install Linux (and configure hardware during the installation).
5. Reboot the notebook.

If you're configuring a dual-boot system that will host Linux and another operating system on your notebook's hard drive, you'll first need to create room for Linux. Here are the basic steps for installing and configuring a dual-boot system:

1. Turn on the notebook.
2. Boot to the existing operating system, and then defragment the hard drive.
3. Use a commercial utility, or boot with a DOS boot disk and make room for Linux.
4. Boot to the Linux installation.
5. Install Linux (and configure hardware during the installation).
6. Reboot the notebook, and then choose to boot Linux or the other operating system.

Configuring your hard drive to support multiple operating systems can be tricky, but you can also try some tricks of your own, such as sharing a single swap space between two different operating systems. Here’s a short list of mini-HOWTO documents you’ll want to read before you begin configuring your notebook:

- **Linux+DOS+Win95+OS2**. Details how to partition, install, and boot four operating systems.
- **Linux+FreeBSD**. Shows how to use Linux and FreeBSD.
- **Linux+Win95**. Details hard drive strategies and booting.
- **Linux+NT-Loader**. Details how to boot Linux using NT’s loader.

Finally, you should know that you can also install different Linux distributions on your notebook and then boot to SuSE Linux or Red Hat, Mandrake, Corel, Caldera, or TurboLinux!

## What Is Partitioning?

This section discusses how to split your hard drive into separate volumes, or *partitions*. Making room on your notebook’s hard drive for other operating systems, known as *partitioning*, can be somewhat confusing, especially if you’ve never attempted this process. Partitioning is an essential step in a traditional Linux installation. However, as you’ve learned in previous chapters, there are ways to run Linux on your notebook without partitioning (such as using WinLinux2000, which creates a virtual disk on your Windows-formatted hard drive).

### Filesystem Versus File System

The Linux kernel and associated software usually reside on parts of your hard drive formatted for the native Linux ext2 *filesystem*. This underlying format details how files and directory information are linked and provided to the Linux kernel. However, you should know that Linux can recognize many different types of filesystems, such as FAT (used for DOS), VFAT (used for Windows), ISO9660 (used for CD-ROMs), HFS (used on older Mac systems), and others. The organization of directories, such as /, /home, /bin, /usr/bin, /usr/X11R6/bin, /tmp, and so on, is known as the *Linux file system*. Understanding the difference between a filesystem and the Linux file system is an important step in understanding how to use Linux.

The basic steps in partitioning a notebook’s drive for Linux involve creating a new partition and then booting to the Linux installation. During the Linux installation, the new partition will then itself be partitioned to provide at least one native Linux partition and one Linux swap partition. The swap partition is used with virtual memory to swap parts of main memory to disk.

Most experienced mobile Linux users use partitioning to do the following:

- Create separate directories on distinct volumes for the Linux file system.
- Organize the Linux file system, such as creating a separate `/opt` volume for third-party or commercial software packages.
- Create an appropriately sized swap partition, usually according to the amount of physically installed RAM.
- Proactively protect various parts of the file system. Additional drive volumes can be “hidden” and not automatically mounted when Linux boots.
- Create ease of use when running backup programs to archive specific directories, such as `/home` (where all system users’ data resides).
- Assign a separate area for temporary files, such as `/tmp` or `/var/tmp` to protect other volumes from overflow.

As an example, if your notebook with 64MB of RAM has a 3GB hard drive, and you’d like to configure a dual-boot system, first defragment the drive, and then split the drive by creating a 1.5GB partition. Next, boot the Linux installation. During the installation, create a swap partition of 128MB, and leave the rest for the Linux root ( / ) file system. Alternatively, you could create a partition of 600MB for the /home directory, 22MB for the /boot directory, 128MB for swap, and leave the rest for the / directory.

## Partitioning Tools

There are a number of partitioning tools you can use to make room for Linux on your notebook’s hard drive. Note that you need to use a partitioning tool before installing Linux only if you have an existing operating system you’d like to keep on your hard drive. Don’t bother with partitioning before installing Linux if you’re just going to install Linux!

If you need to partition your hard drive before installing Linux, be sure to defragment your drive. If you use Windows 95 or 98, double-click on the My Computer icon on the desktop, right-click on your notebook’s hard drive, select Properties, and select the Tools tab in the Properties dialog box, as shown in Figure 5.1.
