This chapter introduces you to a variety of techniques and software that will enable you as a mobile Linux user to connect to your Internet Service Provider (ISP) and the Internet while on the road. You'll also learn about the different technologies that are available to help you along the way. This chapter starts by showing you some of the Internet connection tools commonly included with Linux, along with common means of connecting to the Internet. It then points you to other sources of new techniques and technologies that can help you while you're roaming the office, your home, a warehouse, or the countryside.

### Dial-Up Connections

The modem is the most commonly used tool to connect to the Internet. How long this will be true remains to be seen, as other technologies, such as Digital Subscriber Line service (DSL) and cellular phone companies, vie for connectivity in the marketplace. For now, however, the built-in, external, or PC card modem remains the standard connection hardware of choice for mobile Linux users. This section shows you three ways to connect to an ISP using Linux software.

Dial-up Internet connections use the Point-to-Point Protocol (PPP) to provide networking services and information over serial lines. A precursor protocol, Serial Line Interface Protocol (SLIP), was once popular but now seems to have fallen out of favor. PPP is well supported under Linux. When you connect with your ISP via modem, Linux creates an interface named ppp0 (for the first PPP device), and nearly every Linux networking utility or Internet program communicates through the new interface. When you end your connection, Linux removes the ppp0 interface from memory.

### Setting Up

Your first job is to determine what serial port your PC card or internal modem is attached to on your notebook. If you use an external modem, you'll most likely need a modem cable with a DB-25 connector on one end and a female DB-9 plug on the other end (which fits into the male DB-9 serial connector on most laptops).

If your laptop has an RJ-11 telephone jack for an internal modem, make sure this modem can work with Linux (see the sidebar “Linnmodems”). If you use a PCMCIA modem card, it might have an RJ-11 telephone jack or use an external dongle. Use the `dmesg` command to see which serial ports were found by Linux when it booted:

```bash
# dmesg | grep tty
ttyS00 at 0x03f8 (irq = 4) is a 16550A
ttyS01 at 0x02f8 (irq = 3) is a 16550A
```

In this example, Linux has found two serial ports. One of these ports (on a laptop) will be either an external serial port or an internal modem port. Sometimes Linux finds three or more serial ports on a laptop, especially if an IrDA port, an internal modem, an external serial port, and a PC card modem are inserted into the notebook's Type II slot.

The ttyS devices in the `dmesg` output correspond to device files found under the `/dev/` directory. For example, you can use the `ls` command to look for these devices:

```bash
# ls /dev/ttyS*
/dev/ttyS0  /dev/ttyS1  /dev/ttyS2  /dev/ttyS3
```

These are Linux device file descriptors and are used when a Linux application wants to communicate using a serial port. Note that these devices, unlike transitory eth0 and ppp0 networking interfaces, are not created on-the-fly and are not removed from your Linux filesystem after use. The interrupts and input/output addresses for the serial ports for these devices should be as follows:

```text
/dev/ttyS0  0x2F8  IRQ 4
/dev/ttyS1  0x2F8  IRQ 3
/dev/ttyS2  0x3F8  IRQ 4
/dev/ttyS3  0x2E8  IRQ 3
```

Note that if Linux recognizes three serial ports and two happen to use the same IRQ, you could have a problem. If this happens, use the `setserial` command, along with the name of the serial device, the `irq` keyword, and a new IRQ, to change the port's setting. For example:

```bash
# setserial /dev/ttyS2 irq 10
```

This might sometimes be necessary, especially when you're trying to configure an IrDA port.

If you have a PC card modem, make sure Card Services is enabled before trying to configure the serial port. If you use Red Hat or Mandrake Linux, look at the file `/etc/sysconfig/pcmcia`. In most cases, it should look like this:

```text
PCMCIA=yes
PCC=182365
```

### No PCMCIA

Although the Apple iBook does not have a PCMCIA slot, you can use its internal modem to dial out and start a PPP connection. Boot Yellow Dog Linux using Apple's OpenFirmware prompt and the Yaboot utility. The iBook internal modem will be recognized as /dev/ttyS0.

You can then use the `ntsysv` command to make sure Card Services will run the next time Linux boots, or you can start it right away with this:

```bash
# /etc/rc.d/init.d/pcmcia start
```

If you have difficulty configuring your PCMCIA modem, read David Hinds' PCMCIA-HOWTO, usually found under the /usr/src/linux/pcmcia* directory.

### Linmodems

Software-driven, controllerless modems, colloquially called "winmodems," are used by many desktop and notebook manufacturers to save production costs. However, these so-called modems provide communication services at an additional cost to the consumer. For example, nearly all of these modems work only with commercial operating systems from a monopolistic software industry behemoth (I'll let you guess which one). Source code for the drivers is not provided and is as yet unavailable. If you're on the commercial operating system upgrade treadmill, there is no guarantee that new versions of the modem driver will be available for your laptop! Also, these "modems" use your notebook's CPU to do most of the work, providing yet another resource drain when you're trying to get the most out of your battery charge. Do not buy a winmodem for Linux! Lucent Technologies is the only manufacturer that has stepped forward with a possible solution for Linux by releasing a binary-only (no source code, of course) kernel module that has been verified to work on an IBM ThinkPad 390X, and many other notebooks. If you're unfortunate enough to have a notebook with a controllerless modem, this module might or might not work with your Lucent chip-equipped laptop. Browse to the Linux Winmodem (Linmodem) pages at http://www.linmodems.org, and you'll find other possible solutions, such as a driver for modems using an Ambient Tech chipset.
