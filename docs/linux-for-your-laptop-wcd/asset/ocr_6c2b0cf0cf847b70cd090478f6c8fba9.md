Each subsequent editing session will update the header. RCS also keeps track of all your changes to the file or files in your project folder. You can then use other RCS programs to view all the changes to a file, merge changes from different versions, or remove a version from the change log.

# ### Reporting with tar

The *tar* (tape archive) command is used to create archives of specified files or directories. But you can also use *tar* to compare a backup archive with the current state of a directory. For example, you can create a tape archive of your work directory like this:

```
```bash
# tar cvf work.tar work
work/
work/RCS/
work/RCS/book1.txt,v
```
```

When you use *tar* with the *v* (verbose) option, it outputs a list of directories and files being added to the archive. One way to keep track of the archive’s contents is to use the date and time stamping provided by the Linux kernel. Every file has a creation and modification date. You can see this by using the *ls* command:

```
```bash
# ls -l work.tar
-rw-r-r-- 1 iball iball 10240 Mar 2 15:29 work.tar
```
```

You can also find out a directory’s creation date by using the *ls* command’s *d* (directory) option:

```
```bash
# ls -ld work
dirwr-x-r-x 3 iball iball 1024 Mar 2 15:17 work/
```
```
