As you can see, there is quite a bit of information on an audio CD besides music! The `cdcd2wav` command uses your audio CD's directory and track information when reading and saving music. You can use the command's `track` option to specify a range or series of tracks to record. Be warned that the resulting .wav files will have more than 10MB per minute of song length, so you can quickly fill up a smaller partition when grabbing all the tracks from an audio CD.

The resulting .wav file can then be converted to .mp3 format by using an MPEG encoder, such as the `bladenc` command. Use this command, along with the name of the .wav file, like this:

```
$ bladenc audio.wav
```

After you press Enter, you'll see the following:

```

```

Note that even on a 300MHz Pentium computer, this process can take as long as 10 or more minutes for a 5-minute song! However, you'll end up with a file that provides about 1 minute of digital for each minute of audio—a 10:1 compression ratio over using the .wav format! Using a little simple math, this means that you can store about 10 one-hour audio CDs in a little less than 600MB of hard drive storage.
