### AT, DT, DP, X, Y, and Z

Most PCMCIA, internal, and external modems obey a standard subset of AT commands. These commands should be documented in a manual provided by your modem's manufacturer. It is important to have this information, because there can be subtle differences between different modems and the commands the modems obey. You can try searching your modem manufacturer's Web site for more information. If you just need information about basic AT commands, browse to http://www.computercraft.com/docs/hayescom.html.

AT is the modem's "attention" prefix, DT specifies dial-tone dialing, and DP specifies pulse dialing. X controls call progress reporting, Y controls longspace disconnects, and Z recalls profile 0 settings after a reset.

## DSL Connections

One of the newest and most popular ways to connect to the Internet is through a Digital Subscriber Line (DSL) connection. Although this type of connection (in its current form) might not be of much use to a mobile Linux user, you should know that Linux works quite well with DSL and that this service can be part of a mobile solution. DSL, unlike a dial-up ISP connection, is an "always on" connection and works through regular phone lines. You don't have to worry about a busy signal, and connections are almost instantaneous.

You'll need a PCMCIA Ethernet card (usually 10Base-T for 10Mbps) and an active phone line. Notebook users will also need an external DSL modem. Your phone line plugs into the DSL modem, and an RJ-45 Ethernet cable (not a patch cable!) is run from the modem to your notebook’s Ethernet card.

DSL typically offers speeds up to 7.1Mbps, with most lower-cost accounts providing 640Kbps. Even at the lower end, DSL service provides speeds many times faster than the fastest modem. However, one of the problems with DSL service is that most providers, instead of using standard networking protocols, have chosen to use a perverse form of PPP over Ethernet (PPPoE).

The PPPoE protocol details how your computer works with a DSL modem, provides a quick way for ISPs to authenticate user logins, and dynamically assigns (if not using static IP addressing) IP addresses using Dynamic Host Configuration Protocol (DHCP). This is called the discovery phase of a DSL connection. There are good and bad points about PPPoE. ISPs like PPPoE because some use authentication based on the unique Media Access Control (MAC) address associated with each Ethernet card. The address looks like this:

```
00:C0:02:F6:32:17
```

You can find the MAC address of your notebook’s Ethernet adapter by using the ifconfig command, along with the adapter’s interface name, such as eth0:

```
# ifconfig eth0
```

If your ISP uses a MAC-dependent authentication scheme, this means that you must use the same network interface card (NIC) to maintain your DSL connection. Changing cards or switching the DSL service connection to a different computer can mean a service call to your provider, which is inconvenient to say the least.

This scheme also has implications for privacy and security (although security is always an issue when you have a direct connection to the Internet). However, using DSL also involves a trade-off between your security concerns and the need for speed.
