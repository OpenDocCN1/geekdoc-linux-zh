The article is quite interesting. It contains a mix of truths and falsehoods, but despite Fear, Uncertainty, and Doubt (FUD) tactics, the fact is that Linux continues to grow in popularity. Major research companies, such as International Data Corporation, predict that Linux will capture at least one-quarter of the desktop market and one-third of the server market in the next two years.

Microsoft's Windows 2000 operating system requires at least a 166MHz Pentium or higher CPU, along with 64MB of RAM and a 2GB hard drive with 500MB of free space. On the other hand, Linux, along with a text editor and Internet connection tools, fits on a 1.44MB diskette and boots on vintage Intel-based x86 computers!

# ## How Small?

Not only can you boot and run Linux from a single floppy disk, but you can also build a bootable Linux computer that fits on a 30-pin single inline memory module, or SIMM! Browse to http://www.ucLinux.com to read about the uCsimon running uCLinux. This 1-inch tall 30-pin module features 2MB of Flash memory, 8MB of RAM, 10Base-T Ethernet, an LCD panel driver, and Linux kernel version 2.0.38. The module mounts in a socket on a small prototype board with a 6V power supply. It can provide Web service or network monitoring at very low cost.

If you think comparing Windows 2000 to Linux is unfair, consider that a full Linux distribution (such as from Red Hat, Caldera, Corel, or SuSE) requires about the same amount of memory (64MB) and at least 1.3GB of hard drive space. However, you get the following:

+   - The Linux operating system
+   - The X Window System, a networking client/server-based graphical interface
+   - 3,000 programs, including text editors, a spelling checker, database managers, multimedia clients, games, and more
+   - 1,500 fonts
+   - 6,000 graphical images
