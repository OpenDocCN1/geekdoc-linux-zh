When you select the Battery Monitor menu item, you see an icon on the far right of your KDE desktop's panel, as shown in Figure 7.6. This battery icon is used as a power gauge if your notebook runs on batteries.

The icon is a vertical blue bar if your notebook is plugged in, as shown in Figure 7.7. If you right-click on the battery or AC plug icon, a small pop-up menu appears, as shown in Figure 7.8. You can then quit the ksmllaptop client, change settings, or put your notebook into suspend or standby mode.

If you select the Setup menu item, you'll see the dialog box shown in Figure 7.9. You can use this dialog box to change the icons used for the monitor and change how often the APM status is reported. Other tabs, such as Warning and Critical, are used to set commands to run when the power reaches the warning level (the default is 15 minutes remaining) or the critical level (the default is 5 minutes). You can use this dialog box to have your notebook notify you with a system beep, music, voice recording, or pop-up message window, like this:

```
# xmessage -display 0:0 "Warning. 5 minutes battery power remaining."
```
