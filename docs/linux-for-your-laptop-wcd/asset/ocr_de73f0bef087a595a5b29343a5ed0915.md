# ## Getting the Most out of Your Notebook's RAM

One of the most expensive components of any computer system is memory. If memory were inexpensive compared to hard drive storage, most notebook computers wouldn't have any moving parts. They would simply use battery backed-up RAM and flash RAM to boot the operating system. Fortunately, because of the bloated software requirements of "other" commercial operating systems, consumers and the notebook industry are inured to ever-increasing requirements for greater CPU speeds, larger-capacity hard drives, and, of course, more money in which to run applications.

This is all good news for Linux users, because even the very latest Linux kernels and software for most users run quite comfortably in 32 or 64MB of memory. You can even get by with a 16MB notebook computer (but few of these are found on the market today). At the time this chapter was written, base memory on most models ran at about 64MB.

Linux comes with many different software utilities to display and manage processes running in memory. Like most modern operating systems, Linux incorporates memory management in the kernel. Requests for often-used blocks of memory are cached for quick retrieval. Large blocks of memory flowing outside user space that are not needed may be paged or sent to the swap partition. This partition, usually *twice the size of available physical memory* (but which might be many times the size of your notebook's RAM), is usually created when you install Linux. When you install Linux, make this partition large enough to incorporate any planned needs, such as graphics work, or if you plan to expand your notebook's memory.

**Swap Is Not Hibernate Memory!**

Nearly all notebooks support Advanced Power Management. One of the modes of this power management is the ability of the notebook's BIOS to save a “snapshot” of currently running memory to a special disk file or partition on your notebook’s hard drive. If you install Linux and see a small partition about the size of this partition alone. You’ll need to create a swap partition and at least one native Linux partition during your installation.
