Type *a, y* or an *n*, and press Enter. This configuration will be saved in the file *pppoe.conf* under the */etc/ppp* directory. The script will then attempt to connect and create a *ppp0* interface. The connection, or discovery phase, if successful, will be instantaneous, and you'll start your DSL session.
