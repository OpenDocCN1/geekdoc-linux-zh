# Choosing an Audio format

There are many different types of sound formats, and Linux supports nearly every sound format in use today. However, the most common formats are .au (raw audio), .wav (Windows sound format), and .mp3 (MPEG III). Use .mp3 to store high-quality digital sound on your notebook; you’ll benefit from its compressed format.

# Using the Command Line

You can manually rip audio tracks from a CD to your hard drive, but you’ll most likely want to convert the track to .mp3 format. Use the cdcd2wav command to grab an audio track and save it on your hard drive. The track will be saved in .wav format. If you use a SCSI CD-ROM drive, you can quickly grab the first track of an audio CD by using cdcd2wav, along with your drive’s device specification:

```
# cdcd2wav -D 0,1,0
```

This specifies that the audio CD is on a SCSI drive with an ID of 1 on bus 0. After you press Enter, you’ll see this:
