# Table 2.4 Linux Keyboard Utilities

| Name | Description |
| --- | --- |
| consolechars | Changes the console screen font, map, and character set |
| dumpkeys | Dumps the console keyboard translation tables |
| kbd_mode | Reports or sets the console keyboard mode |
| kbdconfig | Red Hat Linux GUI utility to change the keyboard type |
| kbrate | Resets the console keyboard repeat rate and delay time |
| keytest | Tests SVGALIB raw keyboard functions |
| loadkeys | Loads the console keyboard translation tables |
| psfaddtable | Adds a Unicode character table to a console font |
| psfgettable | Extracts a Unicode character table from a console font |
| psfstriptable | Removes the Unicode character table from a console font |
| setfont | Sets the console font |
| setleds | Sets the keyboard LEDs |
| setmetamode | Defines keyboard metakey handling |
| setterm | Sets terminal attributes |
| setxkbmap | Sets the keyboard using the X Keyboard Extension |
| showkey | Shows scan codes and keycodes sent by the keyboard |
| unicode_start | Starts console Unicode mode |
| unicode_stop | Stops console Unicode mode |
| xev | Shows the contents of X11 events (mouse clicks, keys) |
| xkbcomp | Builds an XKB keyboard description |
| xkbprint | Displays an XKB keyboard description |
| xmodmap | Changes keymaps and pointer buttons in X11 |
| xset | Changes preference settings, such as mouse and keyboard |

To return to the default keyboard, you can use

```
# loadkeys -d
```

The default keyboard used during X11 sessions is set, as previously mentioned, in the Keyboard section of the XF86Config file. For example:

```
XkbRules	"xfree86"
XkbModel	"pc101"
XkbLayout	"us"
```
