# Installing from a Hard Drive Partition

Don't have a CD-ROM? Can't boot from CD-ROM? You can use a DOS or Windows partition to help you install Linux. Nearly all major Linux distributions can read configuration, installation, and Linux software package files from an existing Linux, DOS, or Windows partition. This means that if you have enough hard drive space, and you can at least copy the required Linux directories to a partition on your hard drive, you will be able to easily install Linux. This may be accomplished by copying the files via a shared volume, a mounted NetWare volume, FTP, or other means.

This installation method has a drawback in that you might need 450MB or more storage for the compressed software packages. You can configure a smaller installation by including only the base files, but most notebook users will want to configure an installation without gueswork from a full complement of Linux packages. Also, this installation will not work unless you have previously partitioned your hard drive and have at least one active partition on which to copy the Linux software.

# Preparing Partitions

See Chapter 5, “Starting the Installation,” for details on preparing your notebook's hard drive for installing Linux. The basic steps involve making room for Linux by partitioning your hard drive (using the FIPS command or a commercial software utility) or, if just Linux is to be installed, partitioning your hard drive during the Linux installation. Installing Linux from a separate hard drive partition requires at least one active partition (to hold the software) and another partition to be modified during the Linux installation.

To prepare for the installation, copy the contents of the Red Hat or Mandrake directory to a spare DOS, Windows, or Linux partition. For a Red Hat installation, copy the contents of the Red Hat directory, including the BASE and RPMS directories. The BASE directory holds the second stage of the Linux installation, and the RPMS directory contains all the required Red Hat Package Manager (.rpm) files.
