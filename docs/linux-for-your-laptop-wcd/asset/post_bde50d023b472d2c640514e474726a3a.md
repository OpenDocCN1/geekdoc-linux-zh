
**Video standby.** Although it's not part of APM, some notebooks offer a feature to turn off the LCD and backlight. Some of these features might be supported by the X Window System. This is a convenient method of saving some power (you'll save more with larger LCD displays).

Before trying to use APM features with Linux, make sure your notebook's BIOS supports APM. Check your laptop's manual, and, then, when booting, press the proper keys on the keyboard to access its BIOS. If APM is supported, you'll see menu items used to control power management through different schemes or toggling of features on or off. You must enable APM in your computer's BIOS in order to use APM with Linux!

## The Linux Kernel and APM

The Linux kernel supports a number of APM features, thanks to the efforts of Stephen Rothwell and support from the NEC Corporation. When you enable APM in the kernel, the Linux system time should be reset after the computer resumes. The /proc/apm file contains APM information such as battery status, time, and percentage of time remaining. And APM “event” notifications are transmitted and (hopefully) used by APM-aware programs.

## Linux and ACPI Support

Advanced Configuration and Power Interface (ACPI) is an open specification developed by some of the biggest players in the notebook market. Although not incorporated into many notebooks yet, patches for ACPI support are available for Linux, and ACPI support seems destined for the Linux 2.4-series kernels. Browse to Andy Henroid's ACPI page at http://www.geocities.com/SiliconValley/Hardware/3165/ for a patch to current 2.2-series kernels. You should also browse the ACPI4 home page at http://phobos.fs.tum.de/acpi for details, links, and the status of the port to Linux.

There are some limitations, however. APM does not control your computer’s hard drive, and it doesn’t turn off Display Power Management Signaling (DPMS)-aware computer monitors or Energy Star devices. Also, some notebooks might not have a compatible BIOS. You’ll find that out rather quickly if your notebook doesn’t have a compatible BIOS, because the APM-enabled Linux kernel will crash immediately upon booting. Always keep a backup kernel and boot disk on hand!

## Recompiling the Kernel to Save Memory and Power

Fortunately, most notebooks can use APM with Linux. Some Linux distributions, such as Red Hat and Mandrake Linux, come with APM enabled in the default kernel. Mandrake and SuSE Linux thoughtfully include several other versions just in case the default kernel doesn’t work—a nice feature! To enable APM support in a Linux kernel, you must build a new kernel.

If you’ve never built and installed a Linux kernel, don’t worry. It’s not that difficult. You must first install the Linux kernel source code, along with the GNU C compiler and required headers and libraries. Next, navigate to the /usr/src/linux directory. From there, here are the basic steps:

- make mrproper
- make menuconfig or make xconfig or make config
- make dep; make clean
- make bzImage
- make modules
- make install
- make modules_install
- cp arch/i386/boot/bzImage /boot/vmlinuz-2.2.XX
- cp System.map /boot/System.map-2.2.XX
- cd /boot
- rm System.map
- ln -s System.map-2.2.XX System.map
- Edit /etc/lilo.conf to add your new kernel
- /sbin/lilo

In these steps, you configure APM during the make config, make menuconfig, or make xconfig command. make config is text-based, whereas make menuconfig uses a graphical interface for the console. make xconfig produces an X11-based GUI for configuring the kernel, as shown in Figure 7.1. The APM configuration details are under the General setup options in the dialog box.

Here are the important APM questions you’ll be asked:

- CONFIG_APM. Answer Y to enable APM.
- Ignore USER_SUSPEND (CONFIG_APM_IGNORE_USER_SUSPEND). Answer N unless you have an NEC Versa M-series notebook.
- **Enable APM at boot time** (`CONFIG_APM_DO_ENABLE`). You can safely say N here; according to documentation included with the Linux 2.2-series kernel, some notebooks can hang with this enabled. A safer approach is to not enable this feature.
- **Do CPU IDLE calls** (`CONFIG_APM_CPU_IDLE`). Answer Y.
- **Enable console blanking using APM** (`CONFIG_APM_DISPLAY_BLANK`). Answer Y if you want to try this feature and have the Linux screen saver blank and turn off your LCD backlight. Otherwise, answer N.
- **Turn off power on shutdown** (`CONFIG_APM_POWER_OFF`). Answer Y to have Linux turn off your notebook when you use the `shutdown -h` command. (Note: Be sure to check your system’s halt script, found under Red Hat’s and Mandrake’s `/etc/rc.d/init.d` directory.)
- **Ignore multiple suspend or standby events** (`CONFIG_APM_IGNORE_MULTIPLE_SUSPEND`). Answer Y, especially if you have an IBM ThinkPad 560.
- **Ignore multiple suspend or resume cycles** (`CONFIG_APM_IGNORE_SUSPEND_BOUNCE`). Answer Y, especially if you have a Dell Inspiron 3200.
- RTC stores time in GMT (`CONFIG_APM_RTC_IS_GMT`). If you use Greenwich Mean Time in your notebook's hardware date clock, answer Y. Otherwise, use N. Although many notebook users do not use GMT in their notebooks, mobile Linux users should use GMT to avoid resetting clocks for daylight saving time.
- Allow interrupts during APM BIOS calls (`CONFIG_APM_ALLOW_INTS`). Answer N unless your notebook hangs when using APM suspend mode.

## Reading the /proc Directory

When APM is enabled in your Linux kernel, you'll find a file named apm under the Linux process directory (/proc). This file contains a constantly updated status of your system's power, and it looks like this:

```
$ cat /proc/apm
1.9  1.2  0x03  0x00  0x00  0x01  93%  186 min
```

APM information is represented in eight different fields. Table 7.1 describes each field's value from this example.

**Table 7.1** Linux /proc/apm Values

| Value | Description |
| :--- | :--- |
| 1.9 | The Linux driver version |
| 1.2 | The APM BIOS version |
| 0x03 | Status flags detailing support and features |
| 0x00 | AC status: 0x00 = offline, 0x01 = online, 0x02 = on backup, 0xff = unknown |
| 0x00 | Battery status: 0x00 = high, 0x01 = low, 0x02 = critical, 0x03 = charging, 0xff = unknown |
| 0x01 | Battery bit flag: 0 = high, 1 = low, 2 = critical, 3 = charging, 7 = no system battery, 0xff = unknown |
| 93% | Remaining battery life as a percentage of the charge (\-1 = unknown) |
| 186 | Number of minutes (min) or seconds (sec) |

## Controlling APM

Although most mobile Linux users use hardware keyboard commands to initiate APM events, you should know about the finer controls available by using APM control software. Several APM support programs besides the apmd daemon are provided by the apmd package:

- apm. An APM query and command tool used to display remaining power, print APM BIOS information, or put your computer into standby or suspend mode. For example, the -v command-line option returns status, percent, and time remaining:

```
$ apm -v

APM BIOS 1.2 (kernel driver 1.9)

AC off-line, battery status high: 99% (3:18)
```

- apmsleep. A utility that suspends your laptop. It can also be used to set an alarm to have your notebook wake up. For example, you can set your notebook to wake up at 3:15 p.m. from a standby mode like this:

```
$ apmsleep -S 15:15
```

- on_ec_power. A shell script that provides a function to determine whether your notebook is on battery or AC power.
- tailf. A handy version of the tail command that doesn’t cause your hard drive to spin while you’re monitoring your system logs in a console or X11 terminal window.
- xapm. An X11 client that displays your notebook’s remaining battery life in hours or minutes or as a percentage (see Figure 7.2). Includes a bar indicator that uses colors—blue for charging, green for charged, and red for critical discharging.
