
## TrackPoint Utilities for Linux

Computer artists familiar with drawing tablets know that the stylus, or pointer, is usually also a pressure-sensitive device that recognizes three-dimensional movement. This means that the artist puts slight pressure on the stylus when using a paintbrush tool, the spread of digital paint will be greater. Lighter strokes result in a lighter brush effect. Unknown to most TrackPoint users is that this pointer also responds to pressure!

Browse to Till Straumann’s Web page at

http://www-hft.es.tu-berlin.de/~strauman/tp4utils/

You’ll find two TrackPoint utilities: the **tp4d** server and **xt4a**, a client command you can use to explore the TrackPoint’s capabilities under Linux.

## Your Notebook’s Memory

Few, if any, problems seem to arise between Linux and notebook memory (problems seem to crop up to a much greater degree with desktop systems). Notebook memory can be proprietary and very expensive. If you’re the fortunate owner of an extremely popular and long-lived line of notebooks (with “long-lived” being a relative term in today’s typical notebook model “life span” of 12 months or less!), memory should be a bit less expensive. Some notebook manufacturers have built models to accept standard sockets, and others use extremely proprietary form factors (such as various Sony models). Buy as much memory as you can afford. If you’re sure you can buy from a third party and install it yourself, save some money on your purchase and use it to buy and install more RAM.

The biggest question you’ll face will be “How much?” in terms of memory and cost. To that, I answer, “As much as you can afford, but no less than **64MB**.” Even though Linux and X11 can run on 16MB, be realistic. (I used Linux for a long time on one 32MB laptop, and it is still running 24/7 in the basement.) If you want to use X11, the KDE Desktop Environment, StarOffice, and Netscape and play .mp3 files at the same time, you’ll need a bit of breathing room. Even though Linux and most clients use memory efficiently, with 64MB you’ll be able to use most clients without problems.

If you want to use VMware’s VMware for Linux to install and run other operating systems, such as Windows 2000 or BSD UNIX at the same time, you’ll need even more memory—at least as much as for a separate computer for each instance.

Memory is one area in which notebooks don't seem to have caught up with desktops. Many laptops sold today still have motherboard memory limitations of less than 256MB, while most desktops support 768MB or more.

To find out how much memory Linux has recognized after booting, use the output of the dmesg command piped through fgrep, like this:

```
$ dmesg | fgrep Mem
Memory: 127956k/1331008k available (1044k kernel code, 416k reserved, 1532k data, 60k init)
```

This shows memory in a 128MB notebook. You can also get a quick “snapshot” of memory in use during your X11 KDE session by using the KDE Control Center, as shown in Figure 2.4.

Although newer “stock” Linux kernels purportedly recognize installed memory up to 2GB on Intel-based computers, you might occasionally run into problems. If Linux does not see all your memory, you can pass a kernel message at the Linux Loader (LILO) boot prompt or embed your notebook's memory into LILO's configuration file, /etc/lilo.conf, like this:

```
append= “mem=320M”
```

The kwinfoclient, part of KDE's Control Center, may be used to get a succinct snapshot of your system's current memory usage.

This would tell Linux that 320MB of RAM is installed and available. After Linux boots, there are ways to conserve memory. Here are some ways to do this:

- **Run only the software you need.** Unless your laptop is a Web server, do you really need to run Apache? Although some Linux distributions, such as SuSE, use a locally running Web server to provide an HTML-based help system, you should limit the number of running processes and background processes. Red Hat Linux users should use the ntsysv command to turn off or limit the number of services started when Linux boots.
- **Examine memory.** Use the free, vmstat, asmem, kmem, xvsiw, and other utilities to monitor what's going on, especially if Linux starts to use excessive amounts of memory, including swap space. Use the top command, or other process-reporting utilities such as ps or ptstat, to determine which programs can use the most memory.
- **Choose software with a small memory “footprint.”** If you write only short text files and don't do any programming on your laptop, not using StarOffice or other suites, such as Apexilix, can save a lot of memory. The X Window System (its server) can require at least 8MB or more RAM. Audio players, such as .mp3 players, suck enormous amounts of memory (and CPU cycles) for buffering. In general, text-based applications might require less memory (the emacs editing environment is an exception).

## Your Notebook's Hard Drive

Almost all Intel-based laptops (and, indeed, the Apple iBook) use Integrated Drive Electronics (IDE)-type hard drives, so this section concentrates on and uses IDE drive examples. Newer versions of these drives are known as Enhanced or Expanded Integrated Drive Electronics (EIDE). Dealing with your notebook's hard drive, especially if you're not technically oriented and are installing Linux for the first time, can be very daunting. But don't worry! As long as you have backed up any important data, you can't hurt your computer by installing Linux!

When you install Linux, you'll need to *partition* (make room on) your hard drive. There are a number of ways to do this. You can use free or commercial software to perform this operation. Partitioning seems to cause more grief than any other installation operation for new Linux users. This is probably because most business and home users have never needed to partition a hard drive before; most computers come with software preinstalled on a freshly formatted disk. It is also because the Macintosh OS runs on Motorola CPUs and has never posed a serious challenge to software for Intel-based computers (even though Apple ported the MacOS to the Intel Pentium in 1992 and later killed the project).

If you're new to Linux and are worried about partitioning, fear no more! Now there's a great reason to learn about partitioning and an even better reason to reformat your existing hard drive. Experienced notebook Linux installers routinely wipe a new notebook's hard drive clean of any trace of the operating system previously residing on it, and you can too.

Most Linux distributions include the `FIPS` command. This DOS program is used to create room for Linux on an existing FAT, FAT16, or FAT32 hard drive. Be sure to use the latest version, usually found under the dosutil/FIPS20 directory on your Linux CD-ROM. Here are the basic steps in making room for Linux on a notebook where you want to boot Linux or Windows:

1. Defragment your existing system.
2. Create a bootable DOS diskette.
3. Copy FIPS.EXE, RESTORRB.EXE, and ERRORS.TXT onto the floppy.
4. Reboot your notebook with the diskette.
5. Run FIPS and create the partition.
6. Boot to the Linux installation (during which you'll create and format additional Linux partitions).

You can also use a commercial partitioning utility, such as PowerQuest's PartitionMagic, to create an extra partition, even in Linux ext2 format.

When you format the new partitions and install Linux, you create a new *file system* (file and directory structure) on the hard drive. The name of the Linux filesystem is ext2, and it has a number of benefits over other filesystems, such as speed, reliability, and resistance to fragmentation. Using the Linux `fdisk` command to display partition information on a sample installation would show the following (for example):

