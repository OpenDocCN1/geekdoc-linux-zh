# Other Multimedia Clients

Linux provides many other types of media players. Several are listed in Table 18.3.

Another interesting client is the GNOME `cdplayer_applet`. For use only with a GNOME-aware window manager such as Enlightenment, this applet docks into your GNOME desktop's panel and provides miniature CD player controls. This is another great way to play audio CDs without giving up space on your desktop for a control dialog box.
