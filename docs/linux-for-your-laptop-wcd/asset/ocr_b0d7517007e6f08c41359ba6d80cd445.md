Save and close the file; then reboot your iBook. During the reboot, hold down the Cmd+Option+o+f keys, and you'll see Apple's Open Firmware prompt. To boot Linux, use the boot keyword, along with a pointer to the Yaboot loader like this:

```
`boot hd:8,/yaboot.tzh1`
```

You'll then boot to Linux. Note that, at least with Yellow Dog Linux 1.2, your X11 sessions will be limited to 256 colors! You can find out more about Yaboot by perusing [http://www.yellowdoglinux.com/support/faq/bootloader.shtml](http://www.yellowdoglinux.com/support/faq/bootloader.shtml)

An easier way to boot Linux is to use BootX. This program allows you to choose different Linux kernels, boot to an installation with the Yellow Dog Linux 1.2 CD-ROM, and set various options, such as delays or for video. If you use BootX on your iBook, current or new Linux kernels may be kept in a folder named Linux Kernels inside your Mac's System folder. This is an easy way to test new Linux PPC kernels.

To properly boot Yellow Dog Linux on the Apple iBook, you should use the following BootX settings:

+   - The proper Linux kernel should be selected in the Kernel: field.
+   - The root device (if Yellow Dog Linux is installed on the same hard drive) should be set to /dev/hda10.
+   - The “No video driver” option should be selected.
+   - In the Options dialog box, the “Force video settings” option should be selected.
+   - The “More kernel arguments” field should have an entry of `adb_buttons=103,111` to map F11 and F12 to the middle and right mouse buttons for use during X11 sessions after booting Linux.

After booting, if you do not boot directly to X11, you can use Ctrl+Command+2 through Ctrl+Command+6 to jump between text-only Linux consoles. Unfortunately, you cannot jump from an X session to a text-only console and back using the Intel-based X11 Ctrl+Alt+F2 though Ctrl+Alt+F6 and Alt+F7 keyboard commands.

# PCMCIA and Card Services

David Hinds' Card Services is the most important software package for mobile Linux users besides the Linux kernel and a base installation. Nearly all Intel-based notebooks are equipped with one or two PCMCIA card slots. (Note that the Apple iBook does not support PCMCIA.)

Support for PCMCIA cards, now better known as PC cards, is provided by the cardmgr daemon. This daemon is started through the /etc/rc.d/init.d/pcmcia script
