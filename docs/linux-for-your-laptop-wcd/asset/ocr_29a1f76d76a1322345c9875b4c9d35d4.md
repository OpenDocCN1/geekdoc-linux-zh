# Booting from DOS

Another method of launching to an installation involves using DOS and an AUTOEXEC.BAT file or boot utility, such as LOADLIN, directly from your Linux CD-ROM. Some distributions, such as Red Hat and Mandrake, include a DOSUTILS directory with numerous software utilities and batch files to boot directly to an installation. For example, if you're running DOS, or if you have rebooted to the DOS command line from Windows, insert your Red Hat CD-ROM, and then navigate to the D: drive's DOSUTILS directory. At the command line, use the LOADLIN command to launch directly to a local installation:

```
d:\DOSUTILS>loadlin autoboot\vmlinuz initrd= .
\misc\src\trees\initrd-1.img
```

This approach works with Red Hat's 6.1 Linux distribution. The LOADLIN command will boot Linux and then load the installation software to launch an installation. You can then install Red Hat Linux using your notebook's CD-ROM.
