## Starting XFree86Setup

Until the advent of XFree86 4.0 (see the later section “Installing XFree86 4.0”), XFree86’s X11 distribution included a graphical setup program named **XFree86Setup**. If you have a current Linux distribution, you can try running this program, which requires that the X server named **XF86_VGA16** be available under the */usr/X11R6/bin* directory. From the command line, type **XFree86Setup** and press Enter. Your display should clear, and you should then see the dialog box shown in Figure 6.6.

Follow the prompts, using either the mouse or the keyboard, to make selections that match your notebook’s hardware. For example, to start the configuration of your pointer (mouse), press **Alt+m**.

## Using Xconfigurator

If **XFree86Setup** will not run, and you’re using Red Hat Linux, you can try Red Hat’s **Xconfigurator** client. This command does not require you to start X11, but you should have the appropriate X server (if you’re not using XFree86 4.0) for your notebook installed in the */usr/X11R6/bin* directory. From the console’s command line, type **Xconfigurator** and press Enter. Your display will clear, and you’ll see the dialog box shown in Figure 6.7.

**Xconfigurator** will either use an existing XF86Config file (such as **XFree86Setup**) or can be used to create a new one from scratch.

## Text-Only Configuration with xf86config

You can also configure X11 through the Linux console by using the xf86config command. This text-only program asks you a series of questions regarding your notebook's mouse and video hardware and your desired color-depth settings. Then it builds a custom XF86Config file for your notebook. Start the command by typing xf86config on the command line:

```
# xf86config
```

After you press Enter, you'll see a short page of text. To continue, press Enter. You'll see the following:

First specify a mouse protocol type. Choose one from the following list:

- 1. Microsoft compatible (2-button protocol)
- 2. Mouse Systems (3-button protocol)
- 3. Bus Mouse
- 4. PS/2 Mouse
- 5. Logitech Mouse (serial, old type, Logitech protocol)
- 6. Logitech MouseMan (Microsoft compatible)
- 7. MM Series
- 8. MM HitTablet
- 9. Microsoft IntelliMouse
- 10. Acecad tablet

If you have a two-button mouse, it is most likely of type 1, and if you have a three-button mouse, it can probably support both protocol 1 and 2. There are two main varieties of the latter type: mice with a switch to select the protocol, and mice that default to 1 and require a button to be held at boot-time to select protocol 2. Some mice can be convinced to do 2 by sending a special sequence to the serial port (see the ClearDR/ClearRTS options).

Enter a protocol number: 4

In the first section, you're asked what type of mouse you use on your notebook. Type a number (such as 4 for PS/2) and press Enter. Continue through the prompts, answering questions to configure X11.

## Installing XFree86 4.0

While this book was being developed, The XFree86 Project, Inc. released a new version of X11 for Linux named XFree86 4.0. This release provides a number of changes and new features that make it a radical departure from previous versions of XFree86. One of the biggest changes involves the number of X11 servers included in the distribution. XFree86 releases before 4.0 included one server for each “family” of graphics chipsets, such as XF86_Mono, XF86_VGA16, XF86_SVGA, XF86_Mach64, XF86_S3, and so on. The new XFree86 4.0 includes one server! The single XFree86 4.0 server uses loadable modules, each representing a type of graphics card. This new modular approach makes the job of creating, maintaining, and updating XFree86 much easier to accommodate new graphics cards, because support can be rolled into a new, separate module instead of writing an entirely new server.

The XFree86 software is included with nearly every Linux distribution. Under Red Hat, Mandrake, and Yellow Dog Linux, the XFree86 files, including servers, fonts, clients, and documentation, are bundled in Red Hat Package Manager (.rpm) files. These files are then decompressed and installed on your notebook during installation.

To install the new XFree86 4.0 as distributed by The XFree86 Project, Inc., you must download a series of archives in a compressed tar format. These types of archives, usually ending in .tar.gz or .tgz, are known as compressed *tarballs*. They are usually decompressed manually or by a shell script or installation program. Point your browser to ftp://ftp.Xfree86.org or a Web page with similar content (known as a *mirror*) and download the minimal set of files listed in Table 6.1.
