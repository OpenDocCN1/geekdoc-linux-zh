and insert your PDA into its cradle. For example, to back up your PDA to a directory named pii, use pilot-xfer like this:

```
$ pilot-xfer -b pii
Waiting for connection on /dev/ttyS0 (press the HotSync button now)....
Rate 115200 too high, dropping to 57600
Connected
Back up 'pii/Net Prefs.prc'... OK
Backing up 'pii/TideDB3Locs.pdb'... OK
Backing up 'pii/TideDB2Locs.pdb'... OK
Backing up 'pii/HardBall.prc'... OK
...
```

Not all the output is shown here. Note that you do not have to turn on your Palm. Simply press the HotSync button on the cradle, and the backup will begin. Note also that if the serial port speed is too high, pilot-xfer drops the speed to a more negotiable value. After the transfer is complete, you can restore the contents of your PDA at any time by again using pilot-xfer, but this time with its -r option:

```
# pilot-xfer -r pii
```

# Synchronizing Your Palm

Another great feature of the pilot-xfer command is its ability to synchronize your PDA with your backup directory. This means that you can synchronize the contents of the directory with your Palm using a single command line. Use the pilot-xfer command, along with its -s (synchronize) option:

```
# pilot-xfer -s pii
```

Files that have not been modified will not be backed up. To install a new file into your Palm, use pilot-xfer’s -i option:

```
# pilot-xfer -i palmOMC.prc
Waiting for connection on /dev/ttyS0 (press the HotSync button now)....
Rate 115200 too high, dropping to 57600
Connected
Installing palmOMC.prc... OK
Install done
```
