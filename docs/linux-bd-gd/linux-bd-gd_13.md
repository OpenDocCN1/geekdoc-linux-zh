# C. 依赖关系

LFS 中构建的每个包都依赖一个或多个其他包才能正确构建和安装。有些包甚至参与循环依赖，即第一个包依赖第二个包，而第二个包又依赖第一个包。由于这些依赖关系，LFS 中包的构建顺序非常重要。本页旨在记录 LFS 中构建的每个包的依赖关系。

对于每个要构建的包，我们都列出了三种类型的依赖关系。第一类列出了编译和安装该包所需的其他包。第二类列出了除第一类中的包之外，要运行测试套件还需可用的包。最后一类依赖关系是指需要先将该包构建并安装到最终位置才能构建和安装的包。在大多数情况下，这是因为这些包会在其脚本中对二进制文件路径进行硬编码。如果未按特定顺序构建，可能会导致 `/tools/bin/[binary]` 的路径被写入安装到最终系统的脚本中，这显然是不可取的。
