20. B。在命令后附加一个 &（&amp;）符号会使该命令在后台执行。以此方式启动的程序仍然会消耗 CPU 时间，但它不会独占你用来启动它的那个 shell。`start` 和 `background` 命令是虚构的。虽然 `bg` 确实可以将作业放入后台，但它不是通过这种方式启动程序的；它将一个被挂起的进程（通过按 Ctrl+Z 挂起）放入后台。有关更多信息，请参阅第 2 章“管理软件”。

25. A, C。Unix 系统传统上将时间存储为 UTC（也称为格林尼治标准时间），Linux 也可能这样做。然而，大多数其他 x86 PC 传统上存储本地时间，因此 Linux 也支持此选项。Internet Time 是 24 小时时钟的一种替代方案，它将一天划分为 1,000 个“beat”。标准 PC BIOS 不支持这种时间格式。同样，12 小时时钟对计算机来说也不太实用，因为它无法区分上午（a.m.）和下午（p.m.）。有关更多信息，请参阅第 7 章“系统管理”。

- 1.103.2 使用过滤器处理文本流

![](img/f339a9f48c4b443e61c74acb4c9c3da4_63_0.png)

Linux 大量借鉴了 Unix，而 Unix 最初是一个基于文本的操作系统（OS）。Unix 和 Linux 保留了许多这一传统，这意味着要理解如何使用，特别是如何管理 Linux，你必须至少理解其命令行工具的基础知识。因此，本书以介绍 Linux shell（接受并解释文本模式命令的程序）以及你可以从 shell 中使用的许多基本命令和过程开始。

本章从基本 shell 信息开始，包括 shell 选项及其使用程序。从那里，本章涵盖了流、管道和重定向，你可以使用它们在程序之间或文件和程序之间转移输入和输出。这些技术经常与使用 *过滤器* 进行文本处理相结合——你可以使用这些命令在没有常规文本编辑器帮助的情况下操纵文本。有时必须以抽象方式操纵文本，使用代码来表示几种不同类型的文本。因此，本章还涵盖此主题。

### 了解命令行基础

在 Linux 上做其他任何事情之前，你应该了解如何使用 Linux shell。虽然有几种 shell 可用，但大多数提供类似的功能。理解一些基础知识将极大地促进你对 Linux 的使用，因此我描述了一些这些技术和命令。你还应该了解 shell *环境变量*，它们是对于许多程序可能有用的数据的占位符。最后，关于命令行基础，你应该知道如何获取你试图使用的命令的帮助。

### 探索你的 Linux Shell 选项

与许多关键软件组件一样，Linux 为 shell 提供了多种选项。完整列表会相当长，但更常见的选择包括以下：

**bash** GNU Bourne Again Shell（bash）基于 Unix 较早的 Bourne shell，但在几个方面进行了扩展。在 Linux 中，*bash* 是用户账户最常见的默认 shell，也是本书和 Linux+ 考试中重点强调的一个。
