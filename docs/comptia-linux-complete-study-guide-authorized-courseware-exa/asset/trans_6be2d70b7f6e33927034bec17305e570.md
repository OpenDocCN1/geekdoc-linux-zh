
## 测试题答案

- 1. B。“PS/2”既可以指硬件接口，也可以指软件协议，但在*协议*选项的语境下，它明确指代软件协议。选项A*可能*正确，但指定的行不足以证明这一点；USB鼠标通常使用PS/2协议或其变体，例如Intellimouse PS/2协议。虽然PS/2硬件端口或协议源于选项C中提到的IBM PS/2计算机，但现在许多其他计算机也在使用它们。使用PS/2协议的鼠标几乎可以在任何操作系统上使用，而不仅仅是IBM的OS/2。更多信息，请参阅第6章，“配置 X 窗口系统、本地化和打印。”

- 2. A、C。检查进程列表（从*ps*获取）中是否存在超级服务器的迹象，是确定哪个实际上正在运行的最可靠方法。超级服务器的配置文件或文件（如选项C所示）的存在也是良好的诊断方法，尽管一些经过升级的旧系统可能同时拥有两套配置文件。没有标准的*superserver*实用程序来报告使用的是哪一个。大多数发行版通过SysV启动脚本启动超级服务器；*/etc/inittab*文件不直接参与此过程，因此检查它是无用的。更多信息，请参阅第10章，“保护您的系统。”

- 3. D。*lpc*实用程序用于启动、停止、更改打印队列中作业的优先级以及对作业进行其他控制。CUPS附带了*lpc*实用程序，但与BSD LPD和LPREG的*lpc*实用程序相比，它相当简陋。相反，CUPS依赖其基于Web的界面来提供控制打印作业的能力。更多信息，请参阅第6章，“配置 X 窗口系统、本地化和打印。”

- 4. C。*/etc/security/limits.conf*文件定义了对用户资源的各种限制，包括允许单个用户同时登录的次数。因此，选项C是正确的。*/etc/pam.d/login*文件是虚构的，尽管登录限制确实依赖于可插拔认证系统（PAM）的*pam_limits*模块。*/etc/bashrc*文件是一个全局bash启动脚本文件，但它通常不用于实施登录限制。*/etc/inittab*文件是一个关键的Linux启动文件，但它对实施登录限制没有直接影响。更多信息，请参阅第10章，“保护您的系统。”

- 5. C、D。计算机的IP地址和网络掩码（也称为子网掩码或netmask）是TCP/IP网络配置中最关键的组成部分。（在许多网络上您可能需要提供其他信息，包括1至3个DNS服务器的IP地址、路由器的hostname或IP地址，以及计算机的hostname。）您不需要动态主机配置协议（DHCP）服务器的IP地址——如果存在DHCP服务器，很可能您应该使用DHCP而不是静态IP地址分配。NetBIOS名称服务（NBNS）服务器在NetBIOS网络上用于在名称和IP地址之间转换。这类计算机的hostname不太可能是关键的配置元素，虽然您可能需要向Samba提供此信息，以便在某些共享文件操作正常工作时使用。更多信息，请参阅第8章，“配置基本网络。”

- 6. C。`wc`命令显示指定文件（`report.txt`）中换行符、单词和字节的计数。将此数据通过`tee`管道传输会导致输出副本存储在新文件中（在本例中为`wc`——您不应在`wc`可执行文件所在的同一目录中运行此命令！）。因此，选项C是正确的。与选项A相反，`wc`不是编辑器，即使`wc`是编辑器，剩余的语法也不会导致两个文件在单独的窗口中打开。与选项B相反，`wc`不计算窗口或打开新窗口。与选项D相反，`wc`与清理内存泄漏毫无关系，且`tee`不直接使用`report.txt`文件。更多信息，请参阅第1章，“探索Linux命令行工具。”

- 7. C。/etc/lilo.conf中的`image=`行识别要通过正常Linux文件名引导的内核镜像，因此/boot/bzImage-2.6.19是正确的表示法。LILO的配置文件中没有`kernel=`选项。选项A和D中的(hd0, 1)表示法是GRUB硬盘标识符；此表示法不用于LILO。选项D还同时使用了GRUB磁盘标识符表示法和/boot Linux文件系统规范。更多信息，请参阅第5章，“引导Linux和编辑文件。”

- 8. D。/etc/passwd条目的第三个字段包含账户的UID编号。Linux不使用称为人类ID（HID）的任何标准标识符，尽管缩写HID代表人类接口设备（HID），这是一类USB设备。账户没有PID编号；那些属于运行中的进程。账户的GID编号存储在/etc/passwd的第四个字段中——本例中为100。更多信息，请参阅第7章，“管理您的系统。”

- 9. B。`grep`命令扫描文件以查找包含指定字符串或模式的文件。对于文本文件，它显示匹配的行长；对于二进制文件，它报告文件匹配模式。创建管道的方法是使用垂直线（|）分隔两个命令。`grep`命令可以在管道中使用，但它本身并不创建管道。连接文件的命令是`cat`，显示文件最后几行的命令是`tail`。更多信息，请参阅第1章，“探索Linux命令行工具。”

- 10. B、D。日志式文件系统（JFS）是IBM为AIX和OS/2编写的日志式文件系统，后来移植到Linux。第三扩展文件系统（ext3fs）是基于较旧的无日志第二扩展文件系统（ext2fs）的日志式文件系统。高性能文件系统（HPFS）是Microsoft为OS/2设计的非日志文件系统。更多信息，请参阅第3章，“配置硬件。”

- 11. A。选项A在此语境下正确描述了SSH和GPG的特性。选项B不正确，因为SSH应该能很好地加密您的电子邮件，使其在您系统和您的ISP邮件服务器之间无法被解码。选项C弄反了；通过SSH传输的电子邮件将完全加密，包括其头部。GPG不加密头部，只加密消息主体。选项D不正确，因为GPG不是病毒扫描器，只是一个加密工具。更多信息，请参阅第10章，“保护您的系统。”

- 12. A、D。端口110分配给邮局协议（POP），端口143分配给互联网消息访问协议（IMAP），两者都可用于从电子邮件服务器系统检索电子邮件消息。端口119分配给网络新闻传输协议（NNTP），端口139分配给服务器消息块/通用互联网文件系统（SMB/CIFS）协议，两者通常都不用于电子邮件检索。更多信息，请参阅第8章，“配置基本网络。”

- 13. C。日志文件，如`/var/log/messages`以及`/var/log`中的其他一些文件，通常包含有关服务器错误的有用信息。`tail`程序显示文件的最后几行，因此在使用后立即使用它检查日志文件可能是有用的诊断程序。`http://localhost:631` URL访问通用Unix打印系统（CUPS）配置实用程序，这与SSH没有任何关系。没有标准的`diagnose`实用程序来帮助诊断服务器问题，也没有标准的`/dev/ssh`文件。更多信息，请参阅第5章，“引导Linux和编辑文件。”

- 14. B。`~/.profile`文件是几个`bash`启动脚本之一。它与`ProFTP`服务器或`tcsh` shell没有任何关系。选项C中提到的`ProFile`文件管理器是虚构的。更多信息，请参阅第9章，“编写脚本、配置电子邮件和使用数据库。”

- 15. B。`at`实用程序被创建用于在指定的未来时间点运行程序。因此，选项B将实现所述目标。选项A和C可能也能工作；但两者都不是实现此目标的*最佳*方式。选项A会占用CPU时间，如果程序在间隔的两年内崩溃或系统关闭，消息将永远不会显示。选项C会更可靠，但它为您的每小时`cron`任务日程增加了不必要的复杂性。选项D中指定的`GUI`日历程序可能有效；但`NTP`是网络时间协议，一种协议和同名程序，用于同步网络上的时钟。因此，`NTP`不是用于此任务的工具，选项D是不正确的。更多信息，请参阅第7章，“管理您的系统。”

- 16. D。选项D提供了正确的命令，将`172.24.21.1`添加为默认网关。选项A和B都使用虚构的`gateway`命令，该命令不存在，因此除非您创建一个此名称的脚本，否则不会起作用。选项C使用了正确的`route`命令，但`route`没有`gateway`选项；您必须使用选项D中的`add default gw`。更多信息，请参阅第8章，“配置基本网络。”

- 17. B、C。`BRLTTY`包是用于处理盲文显示设备的附加守护进程，并且`6.2.26`内核中添加了使用这些设备的一些功能，因此选项B和C是正确的。`Espeak`是语音合成软件；它可以用于向用户“朗读”文本显示，但它不与盲文显示接口交互。`GOK`（`http://www.gok.ca`）是屏幕键盘，不是盲文显示工具。更多信息，请参阅第6章，“配置 X 窗口系统、本地化和打印。”

- 18. C。一些依赖关系产生于在编译时将二进制文件动态链接到库，因此可以通过从源代码`RPM`重新编译软件来克服。选项A描述的是Debian源代码包，而不是`RPM`包。重新编译源代码`RPM`只需发出适当的命令，尽管您还必须安装适当的编译器和库。也可以使用源代码tarballs为`RPM`系统编译软件，尽管这样做不会带来任何`RPM`的优势。更多信息，请参阅第2章，“管理软件。”
