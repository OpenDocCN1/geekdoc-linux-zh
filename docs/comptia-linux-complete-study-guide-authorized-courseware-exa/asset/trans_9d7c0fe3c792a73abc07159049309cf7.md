主要的现代桌面操作系统都提供某种形式的*图形用户环境*（GUI），它提供了你很可能熟悉的窗口、菜单、对话框、灵活字体等。在 Linux 中，主要的 GUI 被称为*X 窗口系统*（简称 *X*）。*X* 的配置要么非常容易，要么比较困难；如今大多数发行版在安装过程中都提供自动检测和易于配置选项，这些通常能正常工作。当它们不起作用时，或者当你想要调整配置时，你必须深入研究*X* 配置文件或使用 GUI *X* 配置工具。无论哪种方式，你都需要了解 *X* 如何处理视频硬件等内容。

除了基本的 *X* 配置外，还有几个额外的主题。这些包括字体、GUI 登录工具、用户桌面环境、使用 *X* 进行远程访问以及本地化。本章描述的这些主题中的每一个都与基本的 *X* 配置紧密相关，但它们都以某种方式超越了基本配置，扩展了 *X* 的功能或为用户提供了更多特性。

*X* 显示可以被视为输出的一种形式。另一种是打印，本章也涵盖了该主题。配合配置好的打印机，你可以使用 *X* 和基于文本的应用程序创建和编辑的文档获得硬拷贝。

### 配置基本 X 功能

基本的 *X* 配置设置诸如使用的鼠标、键盘布局、屏幕分辨率、视频刷新率、显示颜色深度以及你正在使用的显卡等功能。这些选项中的某些要求告知 *X* 你安装了什么硬件，而其他选项则允许你调整硬件设置。无论如何，在进行实际配置之前，你应该了解 Linux 可用的 *X* 服务器，因为你的选择将决定有哪些额外工具可用以及你可能需要手动调整哪些文件。GUI 和文本模式配置工具可以帮助你配置 *X*；但有时你必须深入研究配置文件，因此了解其格式非常重要。这需要你了解主要选项组的作用，以便可以调整它们。

### Linux 的 X 服务器选项

尽管 *X* 是 Linux 中占主导地位的 GUI，但有许多 *X* 的实现方式：

- **XFree86** 直到 2004 年，Linux 中占主导地位的 *X* 服务器是 *XFree86*（[http://www.xfree86.org](http://www.xfree86.org)）。这个开源服务器支持广泛的视频卡和输入设备，大多数 Linux 软件都是针对 XFree86 设计的。据我撰写本文时，最新版本是 4.8.0。在 3.3.6 和 4.x 系列之间发生了重大变化，一些旧工具仅适用于 3.3.6 及更早版本的 XFree86。虽然极少数系统由于驱动程序支持的原因必须运行 XFree86 3.3.6 或更早版本，但如今大多数系统运行 XFree86 4.x 或 X.org-X11；后者在 2004 年后发布的发行版中更为常见。
- **X.org-X11** 2004 年，由于 XFree86 的一些许可变更，大多数 Linux 发行版从 XFree86 转向了 X.org-X11。X.org-X11 6.7.0 基于 XFree86 4.3.99，但它独立开发至当前版本 7.5。由于 X.org-X11 基于 XFree86，两者在大多数重要方面几乎相同。一个显著区别是配置文件的名称；另一个是字体的默认位置。本章的后续部分将指出这些差异。你可以从 [http://www.x.org/wiki/](http://www.x.org/wiki/) 了解更多。
- **Accelerated-X** 来自 Xi Graphics（[http://www.xig.com](http://www.xig.com)）的商业 Accelerated-X 服务器是开源 XFree86 和 X.org-X11 的替代方案。在实践中，运行 Accelerated-X 很少是必要的，但如果你遇到使显卡正常工作的问题，你可能想研究一下 Accelerated-X；它的驱动程序基础独立于更流行的开源选择，因此你使用它可能会更有效。Accelerated-X 的配置工具和文件与“X 配置方法”和“X 配置选项”中描述的完全不同，因此你需要查阅其文档以获得帮助。本章其余主题仍适用于 Accelerated-X。

在实践中，通常最简单的是使用你的发行版提供的任意 X 服务器。对于现代发行版，这通常是 X.org-X11，但也可能是 XFree86，特别是如果你正在运行较旧的发行版。对于少数罕见的视频卡，你可能需要运行相当古老的 XFree86 3.3.6，而不是较新的版本。

### 配置 X 的方法

配置 X 传统上是一个困难的过程，因为 X 配置文件包含许多晦涩的选项。如果你可以使用配置实用程序，任务会变得简单，如今大多数 Linux 发行版都将此类实用程序作为安装过程的一部分运行。然而，如果配置实用程序无法执行你想要的所有操作，你可能需要深入研究 X 配置文件以手动设置选项，因此了解其格式会有很大帮助。你还必须知道如何重启 X 以测试你的更改。

### X 配置工具

X 配置工具因 X 的不同版本而异。最重要的是，XFree86 4.x 和 X.org-X11 的工具与 XFree86 3.3.6 及更早版本的工具大不相同。

### 实际场景

#### 使用制造商提供的视频驱动程序

X 的功能之一是提供控制视频卡的驱动程序。XFree86、X.org-X11 和 Accelerated-X 都附带了支持大多数视频卡的多种驱动程序。然而，某些卡（特别是那些非常新的卡）在标准包中的支持较弱。XFree86 4.x 和 X.org-X11 都支持模块化驱动程序架构，这意味着你可以为你的卡放入一个驱动程序模块，并对你的 X 配置进行最少更改，即可使用它而无需重新编译主 X 包。一些视频卡制造商提供专为配合 XFree86 和 X.org-X11 工作的 Linux 视频卡驱动程序。（两个 X 服务器都可以使用相同的驱动程序。）因此，如果你遇到标准 X 视频驱动程序的问题，你不妨检查你的视频卡制造商和视频卡芯片组制造商是否提供 Linux 驱动程序。

安装和使用制造商提供的视频驱动程序通常是一个从 tar 包中提取文件并进行一些配置文件更改的问题。有时制造商提供自动执行此操作的脚本。请查阅随这些驱动程序提供的文档以获取详细信息。这些驱动程序中的许多对于启用现代卡的 3D 加速功能特别有用。这种支持对某些 Linux 游戏最为重要，但一些非游戏软件也可以从 3D 加速中受益。

请注意，一些制造商习惯在其网站上放置标准的 Linux 驱动程序（在这种情况下，是标准的 XFree86 或 X.org-X11 驱动程序）。因此，在麻烦安装之前，你应该尝试确定这些驱动程序是否真正不同于你已经拥有的驱动程序。

基于 nVidia 或 ATI 芯片组的视频卡用户最有可能受益于使用 nVidia 或 ATI 的专有驱动程序，分别为之。这些驱动程序提供优于标准 X 驱动程序的 3D 和实时视频加速。

制造商提供的驱动程序的一个问题是它们通常是专有的。你可能没有源代码，这意味着驱动程序可能无法在更奇特的 CPU 上工作，并且驱动程序可能会随着 X 服务器的未来升级而停止工作。

#### XFree86 4.x 和 X.org-X11 的配置工具

有几种适用于 XFree86 4.x 和 X.org-X11 的配置工具：

X 服务器本身 X 服务器本身包括查询硬件并生成配置文件的能力。要做到这一点，在没有 X 服务器运行时，输入 **XFree86 -configure**（对于 XFree86）或 **xorg -configure**（对于 X.org-X11）。结果应该是一个名为 `/root/XF86Config.new`（对于 XFree86）或 `/root/xorg.conf.new`（对于 X.org-X11）的文件。此文件可能不会产生最佳结果，但它至少是手动修改的起点。
