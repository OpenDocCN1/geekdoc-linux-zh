+   13. D. There is no standard takedown command in Linux. The reboot command is equivalent to shutdown -r, halt is equivalent to shutdown -h, and poweroff is equivalent to shutdown -p.

+   14. B. The telinit command is used to change runlevels; when it’s passed the 1 parameter, telinit changes to runlevel 1, which is single-user mode.
