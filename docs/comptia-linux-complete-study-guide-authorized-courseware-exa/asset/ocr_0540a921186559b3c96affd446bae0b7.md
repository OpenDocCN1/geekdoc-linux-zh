# Using dselect, aptitude, and Synaptic

The dselect program is a high-level package browser. Using it, you can select packages to install on your system from the APT archives defined in /etc/apt/sources.list, review the packages that are already installed on your system, uninstall packages, and upgrade packages. Overall, dselect is a powerful tool, but it can be intimidating to the uninitiated because it presents a lot of options that aren’t obvious, using a text-mode interactive user interface.
