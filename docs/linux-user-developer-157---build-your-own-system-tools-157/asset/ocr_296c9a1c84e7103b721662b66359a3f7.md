# BUILD YOUR OWN
SYSTEM TOOLS

Harness C system calls and start learning systems programming to develop your own software

This feature is about systems programming and is the first in a series of articles that will help you understand how various Linux utilities and servers are implemented, as well as what is going on behind the scenes on a Linux system. It would be good to have a basic knowledge of C and know how to compile and run a C program before continuing.

By the end of this systems programming series, you will be able to develop your own system utilities and understand the brilliance of Unix that lies in its simplicity and consistency.

It is also very interesting to realise that the principal functionality of Linux system software is relatively easy to implement and does not usually take lots of code. Most of the C code is about error checking, processing command line arguments and making the C code as portable as possible.
