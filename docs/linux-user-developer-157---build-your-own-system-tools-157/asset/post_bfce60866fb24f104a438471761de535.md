## GROUP TEST

### GTD software

We have chosen four implementations of David Allen's GTD (Getting Things Done) methodology to help you keep on top of your tasks.

### Todo.txt

Gina Trapagni's todotx is built around the todo text file and the basic command line tools she now complemented with mobile apps, a web interface and other community-contributed software that all adheres to its simple rules. This is what makes it so flexible and easy to work with.

Download: bit.ly/TL54Sea

### Freeplane GTD+

Freeplane is a mind-mapping tool which, with the addition of the Freeplane GTD+ add-on, will generate GTD-style next action lists from a mind map. As there is a strong overlap between mind-mappers and GTD users, it's perhaps surprising that there's not more piece of software that does this.

Download: bit.ly/ljzatuz

### mGSD

TiddlyWiki is one of Free Software's hidden secrets—a JavaScript wiki that doesn't need a web server, it sits on a memory stick for carrying your notes between machines. Its versatility has given rise to several GTD adoptions. mGSD balances comprehensive GTD coverage, with a relatively clean interface.

Download: bit.ly/lzrnjt2

### Org-mode

Org-mode (or simply Org) is a vastly comprehensive authoring and project planning system. It's part of the vast Emacs (an operating system masquerading as a text editor) that happens to be a good fit for maintaining a GTD system. Its ability to plug into other parts of Emacs makes it more powerful.

Download: bit.ly/UQiCU

# Review
GTD software

### Todo.txt

Bash scripts and text file storage mirror the great simplicity of paper-based GTD

![](img/e7f197876caa0b235fb5da2d16a578ea_81_0.png)

The simplicity with which todo.txt captures and stores actions belies more complex possibilities

#### Installation

Download the tarball, **run tar xf v2.todo.txt_cli-2.10.tar.gz** and then give your todos.sh executable powers and copy across the config file to `~/.todo/config`. The documentation is generally very good but lags behind changes on config names. However, the simplicity of the application meant we could work it out from source, rather than Google!

#### Interface

Simple bash commands – you can make it simpler after placing the script in your $PATH, as you can alias it to “T” – and the option of just looking in the txt file, using a mobile app, a community-supplied web or desktop interface, means a todo and GTD app are suitable for almost anyone.

#### Managing lists

Projects and contexts are the key to managing action items within the todo.txt file, along with priorities; another aid to keep actions on track if used carefully (don’t set too many levels of priority, as they’ll become meaningless). Actions not attached to projects may get lost. The ability to read the .txt file on any platform is an advantage for quick reviewing.

#### Bonus extras

Mobile version, web interfaces – wherever you want to interact with the todo.txt, someone has written some software for it. The official iOS and Android versions work with Dropbox. There’s a Python version of the command line app too. Read the GitHub site if you’re looking for more tips and tricks for the regular Bash version.

#### Overall

One of the easiest-to-use command line apps. With plenty of documentation and good mobile interfaces, we found ourselves forgiving the little installation hiccup. Everyone who wants to make a list should try this one!

### Freeplane GTD+

Mind maps and GTD in one cross-platform application – a step too far?

![](img/e7f197876caa0b235fb5da2d16a578ea_81_1.png)

Note the friendly keyboard shortcuts, such as using the Insert key to add a child node, that make Freeplane GTD+ so quick to use

#### Installation

If you have a recent Java runtime installed, just download the Freeplane zip file and run the shell script for Freeplane. Then open the Freeplane GTD+.mm (mind map) file. Restarting Freeplane should bring up all the Freeplane GTD+ functionality. If you already have an older version of Freeplane installed, you’ll have to update it.

#### Interface

Generating a mind map for a project and turning it into actions is the essential first step to mastery of your inbox of tasks. Freeplane GTD+ has many useful tweaks and shortcuts to quickly capture action items. The Freeplane tutorial will also help you unlock useful UI features.

#### Managing lists

Freeplane GTD+ addresses many of Freeplane GTD’s shortcomings with priority properties, filterable ‘done’ actions and sensible default handling of items without a date. The 1.0 release saw a complete rewrite of the Action window, using more effective Groovy-specific APIs, and the choice between a GUI editor, text and keyboard shortcut inputs.

#### Bonus extras

Use of Freeplane’s scripting language, and ready-made add-ons, enables everything from synchronising your lists with the todo.txt family of GTD tools, to adding different views and interfacing with presentation software. The Freeplane Collaborative Tools extension also enables asynchronous collaborative mind-mapping through a shared VCS.

#### Overall

Freeplane GTD+ has built on the strengths of Freeplane in capturing GTD Next Action items, adding usability tweaks to inputs and management of lists. If you’re not a mind-map convert, we think this may make you think again.

### mGSD

A strong representative amongst several TiddlyWiki-based options

![](img/e7f197876caa0b235fb5da2d16a578ea_82_0.png)

Creating new content will always be context-based and linked to other relevant areas

#### Installation

A JavaScript wiki that lives inside a single HTML page should be an easy installation, but open in a recent Firefox and new security measures stop mGSD from saving anything. TiddlyWiki creator, Jeremy Ruston, has produced a solution: the TiddlyFox extension to Firefox, available from the Mozilla Add-ons site. Install this first.

#### Interface

The most common actions – starting a project, creating a Next Action, reviewing and so on – are all easily visible, with everything grouped logically by tabs in a single webpage. Calendar reminders (ticklers), reference items, someday/maybe lists – all of GTD is here.

#### Managing lists

With excellent review options and a More tab that exposes every option, it’s easy to get where you want to edit your projects, anywhere you can carry the HTML file and open it in a browser (hint: Dropbox). The only thing lacking is a simple exit for your data, but adding the export tiddlers plugin enables CSV and text exports.

#### Bonus extras

Enhancements are available from github.com/AaronLaw – search for David Szego’s mGSD enhancements (he now concentrates on mGSD’s rival, dGSD), as they let you export more easily, manage records of meetings and actions arising from them, and unclutter the interface a little, à la dGSD. Other TiddlyWiki enhancements are also compatible.

#### Overall

> We loved mGSD for its straightforward approach, ease of use and comprehensive features. Sadly, development has stopped, but GSDS will carry on the work in a TiddlyWiki5-compatible form, so will be capable of node.js hosting.

### Org-mode

Powerful and complex, but the simple text format helps you get started

![](img/e7f197876caa0b235fb5da2d16a578ea_82_1.png)

At the very heart of org-mode are simple, hierarchical lists that you can unfold to help with your list management

#### Installation

For several years, org-mode has been integrated into Emacs, so **apt-get install emacs** (or your distro’s equivalent) takes care of installation. On systems without Emacs you can still work with .org files: they’re plain text with a hierarchy of asterisks (* for top-level titles, ** for second level and so on), and your word processor’s outline mode may generate and read them.

#### Interface

The manual is huge, and if you’ve never learned Emacs that’s an additional task. But writing lists is straightforward with nested outline trees and you can ease yourself into the rest gently. There are many keyboard shortcuts and commands, but the majority are accessible through GUI menus.

#### Managing lists

Typically, org-mode GTDers split their gttd.org file into tasks, calendar and projects, possibly adding extras like financial tracking. Other .org lists may be used to capture new input, record thoughts, maintain a someday/maybe list and schedule events using an Agenda view. Processing lists, involving keyboard shortcuts, is one of Org’s strengths.

#### Bonus extras

Org-mode is scarcerly comprehensive, from accepting embedded LaTeX for formulae to exporting files as HTML, ODT, PDF or iCalendar items. Add in the ability to pull in other Emacs modes and you’ll find the calendar/coverage expanded, the ability to work on a BBS/contacts database, even the capability to automatically generate and send emails.

#### Overall

> Easy to get started in a small way, but embrace org-mode and you’ll be sucked down the Emacs rabbit hole to a world where everything is available using keyboard shortcuts, where your efficiency will scare all of your friends.
>
> 8
