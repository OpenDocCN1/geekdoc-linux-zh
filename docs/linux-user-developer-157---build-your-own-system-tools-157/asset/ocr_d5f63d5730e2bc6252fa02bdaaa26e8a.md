# Todo.txt

Bash scripts and text file storage mirror the great simplicity of paper-based GTD

![](bbox=[0.06, 0.25, 0.47, 0.43])

The simplicity with which todo.txt captures and stores actions belies more complex possibilities

# Installation

Download the tarball, **run tar xf v2.todo.txt_cli-2.10.tar.gz** and then give your todos.sh executable powers and copy across the config file to `~/.todo/config`. The documentation is generally very good but lags behind changes on config names. However, the simplicity of the application meant we could work it out from source, rather than Google!

# Interface

Simple bash commands – you can make it simpler after placing the script in your $PATH, as you can alias it to “T” – and the option of just looking in the txt file, using a mobile app, a community-supplied web or desktop interface, means a todo and GTD app are suitable for almost anyone.

# Managing lists

Projects and contexts are the key to managing action items within the todo.txt file, along with priorities; another aid to keep actions on track if used carefully (don’t set too many levels of priority, as they’ll become meaningless). Actions not attached to projects may get lost. The ability to read the .txt file on any platform is an advantage for quick reviewing.

# Bonus extras

Mobile version, web interfaces – wherever you want to interact with the todo.txt, someone has written some software for it. The official iOS and Android versions work with Dropbox. There’s a Python version of the command line app too. Read the GitHub site if you’re looking for more tips and tricks for the regular Bash version.

# Overall

One of the easiest-to-use command line apps. With plenty of documentation and good mobile interfaces, we found ourselves forgiving the little installation hiccup. Everyone who wants to make a list should try this one!

# Freepiane GTD+

Mind maps and GTD in one cross-platform application – a step too far?

![](bbox=[0.52, 0.25, 0.94, 0.43])

Note the friendly keyboard shortcuts, such as using the Insert key to add a child node, that make Freepiane GTD+ so quick to use

# Installation

If you have a recent Java runtime installed, just download the Freepiane zip file and run the shell script for Freepiane. Then open the Freepiane GTD+.mm (mind map) file. Restarting Freepiane should bring up all the Freepiane GTD+ functionality. If you already have an older version of Freepiane installed, you’ll have to update it.

# Interface

Generating a mind map for a project and turning it into actions is the essential first step to mastery of your inbox of tasks. Freepiane GTD+ has many useful tweaks and shortcuts to quickly capture action items. The Freepiane tutorial will also help you unlock useful UI features.

# Managing lists

Freepiane GTD+ addresses many of Freepiane GTD’s shortcomings with priority properties, filterable ‘done’ actions and sensible default handling of items without a date. The 1.0 release saw a complete rewrite of the Action window, using more effective Groovy-specific APIs, and the choice between a GUI editor, text and keyboard shortcut inputs.

# Bonus extras

Use of Freepiane’s scripting language, and ready-made add-ons, enables everything from synchronising your lists with the todo.txt family of GTD tools, to adding different views and interfacing with presentation software. The Freepiane Collaborative Tools extension also enables asynchronous collaborative mind-mapping through a shared VCS.

# Overall

Freepiane GTD+ has built on the strengths of Freepiane in capturing GTD Next Action items, adding usability tweaks to inputs and management of lists. If you’re not a mind-map convert, we think this may make you think again.
