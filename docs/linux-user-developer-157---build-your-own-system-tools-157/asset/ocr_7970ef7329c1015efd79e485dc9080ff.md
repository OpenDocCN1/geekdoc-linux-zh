# GAMING

# Unity game engine hits Linux

Future support for the platform not guaranteed

The game engine specialist Unity has announced the release of an experimental build of its software for Linux, making good on its roadmap promise to support the operating system in future releases.

A popular engine for both games and general-purpose 3D rendering, Unity has previously been restricted to use on only proprietary platforms. This month’s release changes that, bringing official support for running the software on Ubuntu 12.04 or newer, plus unofficial support for other 64-bit Linux distributions.

The release is a test for the company, however, and Unity has not committed to a full and formal release. “Today’s build is what we call an experimental build; future support is not yet guaranteed,” warned Unity’s NaTosha Bard. “Your adoption and feedback will help us determine if this is something we can sustain alongside our Mac and Windows builds.” Bard did not indicate what usage and feedback levels would constitute enough for the company to adopt Linux as a fully supported platform for all future releases, following in the footsteps of rivals including Epic’s Unreal Engine.

Interest from developers in Linux as a gaming platform is higher than ever, thanks in no small part to game developer and publishing giant Valve basing its gaming-centric operating system SteamOS on the Debian Linux distribution.

# FEDORA

# Support for 32-bit x86 demoted

Fedora makes 64-bit x86 the gold standard

The Fedora project has demoted support for 32-bit x86 architectures from its Linux distribution, following a vote by the Fedora Engineering Steering Committee (FESCo).

In its late August meeting, FESCo raised a vote on removing support for the i686 32-bit x86 instruction set architecture from Fedora 24. “From my POV (point of view), nobody wants to support the i686 image,” Hailuk Guímar told attendees. “I’m completely +1 for (in favour of) dropping all of the i686 images/media in f24 [Fedora 24],” added Kevín Ferzi.

After some discussion, the committee agreed to change the vote away from a total abandonment of i686 support, to making it a non-blocking deliverable. This means that its absence (should work not be complete in time) would not prevent the general launch of Fedora 24, effectively demoting the architecture support.

The 64-bit x86 architecture, backwards-compatible with the traditional 32-bit variant, was launched in 2003 by AMD as AMD64 and picked up by Intel a year later. Today, the majority of both company’s chips are 64-bit.
