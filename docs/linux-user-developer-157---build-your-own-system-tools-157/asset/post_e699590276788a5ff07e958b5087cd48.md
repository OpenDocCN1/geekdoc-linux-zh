#### AND THE WINNER IS...

**mGSD**

Some GTDers still swear by paper-based lists, but a synchronised todo.txt file or a web app is available anywhere you can borrow a device and remember your password. A decade ago, desktop apps like Getting Things GNOME! dominated, but migration of our digital lives to the online world has meant web apps surviving on the one hand and command line choices on our SSH-accessible Raspberry Pis on the other.

Todo.txt is one of the friendliest command line apps, which even GUI lovers could warm to. Its strength lies in simplicity: of the text format and also the rules that all of the community-contributed software follows in order to keep compatibility. For those new to GTD, or those just looking to writing a list, try this one today.

For the more visually-oriented, Freelance GTD+ is a great way for generating next action lists, bringing the full power of mind maps to planning your world. Back to the command line: org-mode has great documentation and masses of user-supplied tutorials (such as those at sachachua.com) to help you with that steep learning curve. For those with heavy project management, org-mode could be your lifeline.

![](img/e7f197876caa0b235fb5da2d16a578ea_83_0.png)
![](img/e7f197876caa0b235fb5da2d16a578ea_83_1.png)

For mere mortals, however, there’s only one winner. mGSD may have reached the end of developmental life, while we wait for the next generation of TiddlyWiki-based software to catch up, we’ve no hesitation in recommending it. There’s no security risk in running it locally and the ability to carry a friendly web interface anywhere, without having to trust your data to cloud providers, is a winning point alone.

Easy to get going and yet good at its job, mGSD also charms with a friendly interface and a good understanding of context. Try mGSD and you’ll quickly start getting on top of your todo list.

**Richard Smedley**

**SECURITY**

Powered by SpiderOak’s zero-knowledge cryptographic technology, is Encryptr the solution to secure cloud-note storage?

![](img/e7f197876caa0b235fb5da2d16a578ea_85_2.png)

- **DEB packages**
  32-bit and 64-bit
- **Alternative clients**
  Windows and OS X
- **Mobile client**
  Android (iOS TBA)
- **Available from**
  encrypt r.org

If you have an interest in security, it's likely you'll be familiar with SpiderOak – *whistleblower Edward Snowden's backup tool of choice* – and its Crypton framework. Based around the concept of 'zero knowledge', SpiderOak uses the Crypton JavaScript framework to encrypt the user's data in such a way that it is impossible for the server to access. Consequently, it neatly solves the biggest issue with cloud storage, namely having to trust someone else with your data.

SpiderOak employee Tommy Williams is intimately familiar with the benefits of Crypton and has launched a new software package based on the framework: Encryptr. Where SpiderOak offers secure, remote storage of arbitrary data, Encryptr is more tightly focused: it offers a secure cloud storage facility for short textual notes, credit card details and passwords.

The Encryptr client is open source and cross-platform: Williams has released 32-bit and 64-bit binary builds for Linux, DEB packages and clients for both Windows and OS X machines.

For mobile users, there's already an Android client and work on an iOS version is also nearing completion. It's also lightweight: the 64-bit build, installed on an Ubuntu Linux system, took up less than 15MB when fully loaded.

Like SpiderOak, Encryptr's biggest selling point is the zero-knowledge cryptography provided by the Crypton framework. The Crypton concept is that the asker should never know what the data that it is being asked to store is: everything bar storage and retrieval is entirely client-based, including the encryption and decryption process. This provides a layer of security many similar services can't hope to match: even if the server is attacked or the company itself is dragged through the courts, there is theoretically no way for the data on Encryptr to be decrypted and viewed without the original password.

Given the data Williams expects users to store in Encryptr, that's a good thing: the current release offers three templates for storing credit card details, passwords and general text. When entered into one client, the data is sent to a remote server that's under Williams' control – though a forked version of the software would also be able to send it to your own server, if you do desire – for immediate access by any client under the same account.

Interestingly, there's no real sign-up process, which is a rarity for a cloud-based service. There's no need to reveal your email address or any other personal details: simply choose a username, a password and you're ready to go. Using the same details on another device brings up the shared account immediately.

Encyptor already ticks plenty of boxes, including easy copying of details to the system clipboard and a clever blurring effect to mask passwords from view until an eye icon is clicked to reveal them. What is more, adding a new account populates the password field with a randomly generated suggestion.

It's early days for the software though and it is still lacking in some areas. The settings page, for example, provides only a single option: the ability to change the password associated with your account. There have also been concerns about the software's overall security. This is following the discovery of a bias to the random number system in the password generator.

Crypton itself is also somewhat unproven. Despite having powered SpiderOak's zero-knowledge backup service from the start, the software has only had two audits: one, completed in 2013, revealed five vulnerabilities that were subsequently fixed; the second, completed in 2014, found 10 issues, some of which have yet to be fully resolved. SpiderOak has also warned that the software has changed since the last audit and requires an, as yet, unstarted supplementary audit. “Use at your own risk,” the official framework documentation warns.

### Pros

- The Crypton zero-knowledge framework offers security as strong as your password, even when storing data on cloud servers

### Cons

- The current release of the software is extremely basic and may contain security issues that are yet to be discovered

### Summary

Encyptor shows promise and its open source nature means it should, in theory, be open to security review. At the time of writing, however, the software was extremely basic. While development is ongoing, it is the work of a single individual, hence the slow progress. If nothing else, it demonstrates the flexibility of the Crypton framework.
