When entered into one client, the data is sent to a remote server that's under Williams' control – though a forked version of the software would also be able to send it to your own server, if you do desire – for immediate access by any client under the same account.

Interestingly, there's no real sign-up process, which is a rarity for a cloud-based service. There's no need to reveal your email address or any other personal details: simply choose a username, a password and you're ready to go. Using the same details on another device brings up the shared account immediately.

Encryptor already ticks plenty of boxes, including easy copying of details to the system clipboard and a clever blurring effect to mask passwords from view until an eye icon is clicked to reveal them. What is more, adding a new account populates the password field with a randomly generated suggestion.

It's early days for the software though and it is still lacking in some areas. The settings page, for example, provides only a single option: the ability to change the password associated with your account. There have also been concerns about the software's overall security. This is following the discovery of a bias to the random number system in the password generator.

Crypton itself is also somewhat unproven. Despite having powered SpiderOak's zero-knowledge backup service from the start, the software has only had two audits: one, completed in 2013, revealed five vulnerabilities that were subsequently fixed; the second, completed in 2014, found 10 issues, some of which have yet to be fully resolved. SpiderOak has also warned that the software has changed since the last audit and requires an, as yet, unstarted supplementary audit. “Use at your own risk,” the official framework documentation warns.

# Pros

The Crypton zero-knowledge framework offers security as strong as your password, even when storing data on cloud servers

# Cons

The current release of the software is extremely basic and may contain security issues that are yet to be discovered

# Summary

Encryptor shows promise and its open source nature means it should, in theory, be open to security review. At the time of writing, however, the software was extremely basic. While development is ongoing, it is the work of a single individual, hence the slow progress. If nothing else, it demonstrates the flexibility of the Crypton framework.
