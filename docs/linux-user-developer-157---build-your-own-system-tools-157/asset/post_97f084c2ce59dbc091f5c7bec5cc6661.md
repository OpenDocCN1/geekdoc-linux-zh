Learn how to create impressive, interactive visualisations using the D3.js JavaScript library

D3 means Data-Driven Documents. It is a JavaScript library that can help you bind random data to the Document Object Model (DOM) and apply data-driven transformations to the document. D3 offers functions that, when applied to DOM elements, can transform the resulting HTML, SVG or CSS documents. It is a powerful piece of software that can do many things and generate extraordinary interactive and professional output. It does not have one single function to draw a circle or any other shape; instead, it has a function that processes the right set of data in order to create a circle. Although this approach makes you write more code, it offers more flexibility and freedom! D3.js also supports code reuse with the help of its huge collection of components and plugins. If you are already familiar with JavaScript then using D3.js is a no-brainer. Even if you are not a big fan of JavaScript, you should definitely consider D3.js. However, there are many other alternatives that you may want to examine including R, MATLAB, Octave and so on.

All presented examples can run on a local machine without the need for a running web server, such as Apache and Nginx. Next month we will explain how to create even more impressive and advanced plots using D3.js.

## 02  Draw a circle using D3.js

This step will show you how to draw circles using D3.js. The circle HTML file contains the following code:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Draw a circle using D3.js</title>
    <script type="text/javascript" src="d3/d3.min.js"></script>
</head>
<body>
    <div id="myCircle"></div>
    <script type="text/javascript">
        var sampleSvg = d3.select("#myCircle")
        .append("svg.svg")
        .attr("width", 200)
        .attr("height", 200);
        sampleSvg.append("svg:circle")
        .attr("stroke", "red")
        .style("fill", "pink")
        .attr("r", 50)
        .attr("cx", 70)
        .attr("cy", 70)
    </script>
</body>
</html>
```

As you can understand, you will still need to create a complete HTML file where you can embed the required JavaScript code. The `svg.circle` command lets D3.js know that you are going to draw a circle. It is important for drawing a circle is the code that defines the coordinates of the point that will be the centre of the circle (**cx** and **cy**), as well as the length of the radius (**r**).

Similarly, you can use the `svg.rect` to draw a rectangle. In this case, you will need to describe the height and width you would like for your rectangle.

## 03  A simple plotting example

This time you are going to visualise data that is stored in an array. The program will read the array values and generate a bar chart. The JavaScript code for drawing the bar chart is the following:

```html
<script type="text/javascript">
    var myWidth = 1000;
    var myHeight = 1000;
    var myData = [5, 321, 20, 200, 150, 130, 400, 250, 150];
    var svg = d3.select("body").append("svg")
        .attr("id", "myChart")
        .attr("width", myWidth)
        .attr("height", myHeight);
    svg.selectAll(".bar")
        .data(myData)
        .enter()
        .append("rect")
        .attr("class", "bar")
        .attr("x", 0)
        .attr("y", function(element, index){
            return (index*25);
        })
        .attr("width", function(element,index){
            return element;
        })
        .attr("height", 20)
</script>
```
