Welcome to the latest issue of Linux User & Developer, the UK and America's favourite Linux and open source magazine.

This month we're focusing on the developers among you: starting with a big guide to systems programming in C that we're going to follow with a run of tutorials over the coming months (page 20), we have some excellent guides that will get you started with C# programming, Docker containers, automation and security on AWS, and a pair of tutorials on R and D3.js to help you manipulate and visualise data. We'll be revisiting some of these before the year is out, so stay tuned.

With Windows 10 raising all sorts of privacy concerns, it was also time to complement the guides to virtualisation and multibooting that we ran in previous issues with a third option for giving you access to software that doesn't play nicely on Linux: Wine. Using this and PlayOnLinux, we show you how to run things such as Photoshop and your PC games on your favourite distro (page 28), so you can wash your hands of Windows altogether and help your friends do the same.

As for the Ras Pi section, we've got something really special for you. Remember the LED strip you used a couple months back? Well, we're turning it into a music visualiser (page 62). Plus, we show you how to text and tweet from your Pi – enjoy!

Gavin Thomas, Editor
