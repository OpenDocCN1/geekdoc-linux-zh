Learn how to create impressive, interactive visualisations using the D3.js JavaScript library

D3 means Data-Driven Documents. It is a JavaScript library that can help you bind random data to the Document Object Model (DOM) and apply data-driven transformations to the document. D3 offers functions that, when applied to DOM elements, can transform the resulting HTML, SVG or CSS documents. It is a powerful piece of software that can do many things and generate extraordinary interactive and professional output. It does not have one single function to draw a circle or any other shape; for example; instead, it has a function that processes the right set of data in order to create a circle. Although this approach makes you write more code, it offers more flexibility and freedom! D3.js also supports code reuse with the help of its huge collection of components and plugins. If you are already familiar with JavaScript then using D3.js is a no-brainer. Even if you are not a big fan of JavaScript, you should definitely consider D3.js. However, there are many other alternatives that you may want to examine including R, MATLAB, Octave and so on.

All presented examples can run on a local machine without the need for a running web server, such as Apache and Nginx. Next month we will explain how to create even more impressive and advanced plots using D3.js.

# 01  Install D3.js

Before installing D3.js, you need to download it:

```
$ wget https://github.com/mbostock/d3/releases/download/v3.5.6/d3.zip
```

The d3.ZIP file contains three files: d3, LICENSE, d3.js and d3.min.js. Both d3.js and d3.min.js contain the same JavaScript code; the only difference is that whitespace has been removed from d3.min.js to have a smaller file size in order to load faster.

The d3.min.js file contains lots of JavaScript code. The good thing is that you will just have to include it in your HTML code using either of the following:

```
<script type="text/javascript" src="http://d3.js/</script>
<script type="text/javascript" src="http://d3js.org/ d3.v3.min.js" charset="utf-8"></script>
```
