# Using Performance Monitor to Get More System Stats

Performance Monitor is one of the classic features of the Performance Diagnostic Console that has been around since Windows NT. Over the years, Performance Monitor has been refined and is now a very comprehensive tool. In Windows 8, hundreds of built-in monitors enable you to monitor just about every aspect of the operating system and your hardware. If you want, you can even view information about how fast your laptop's battery is charging or discharging.
