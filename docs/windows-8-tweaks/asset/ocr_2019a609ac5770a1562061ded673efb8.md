# Using Microsoft Update

Every month, Microsoft releases new security patches for all its products that fix security holes and increase the security of Windows. It is very important to make sure that your computer is working properly and is set up to download these new security patches automatically. Additionally, Microsoft includes an expanded version of Windows Update called Microsoft Update that patches Microsoft products beyond Windows. Microsoft Office, Visual Studio, and other popular Microsoft applications can also be patched automatically, but this feature is disabled by default.

Follow these steps to enable Microsoft Update and scan your PC for updates:

+   Open the Start screen, type **Install Optional Updates**, change the search filter to Settings, and hit Enter.

+   Click the Find Out More link on the Windows Update screen as shown in Figure 18-1.

+   Internet Explorer launches a web page describing Microsoft Update and a legal agreement you must acknowledge. Check the I Agree box and click the Install button.

+   After the Microsoft Update component is installed, close IE and Windows Update should scan for updates for Windows other Microsoft products automatically.

+   When the scan is completed you can click important or optional update links and view available updates. Only critical updates are installed automatically.

+   Check the box next to any update you want to install and click Install, as shown in Figure 18-2.
