+   4. Type MaxConnectionsPerServer as the name of the new DWORD value.

+   5. Right-click this value and select Modify.

+   6. Set the base to Decimal and enter a value greater than 6, as shown in Figure 17-2.

I like to use 15 as my value here. Click OK when you are done.

+   7. Create a new DWORD value and type MaxConnectionsPer1_0Server as the name.

After your computer has rebooted, your new Internet Explorer settings are active. If you ever feel like undoing this tweak, just go back into the registry and delete the MaxConnectionsPerServer and MaxConnectionsPer1_0Server values that you created and reboot.
