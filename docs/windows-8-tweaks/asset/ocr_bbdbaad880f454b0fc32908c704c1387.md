# ## Tracking Protection Lists

Internet Explorer 10 enables you to use tracking protection lists that block known companies that track your browsing habits. These lists are provided by a variety of organizations to help users block all web traffic from any address on the list. For example, if a list blocks ads.google.com, then all requests to that page are blocked. A side effect of blocking tracking requests is that normal advertising requests are also blocked because tracking protection lists are also ad blocking lists in most cases.
