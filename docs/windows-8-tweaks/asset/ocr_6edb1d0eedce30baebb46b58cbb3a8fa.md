| POLICY | DESCRIPTION |

| Prevent users from rearranging toolbars | Locks in the position of your toolbars (similar to locking the taskbar). |

As you can see, dozens of useful group policies can help you customize your desktop more than any other method. Additionally, these policies can be used in a domain policy that governs all Windows 8 computers connected to the domain.
