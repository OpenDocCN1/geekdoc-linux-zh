# Controlling Auto-Start Applications That Keep Coming Back

Some applications that you disable may begin to start up automatically again. Software developers often use various techniques to check that their application is registered to auto-start when you log on. If you disable an application’s automatic startup, some applications will re-enable themselves the next time they are run. The software developers may be trying to make sure you use their application by making it difficult to disable auto-start. In other cases, developers are just trying to make sure that other programs are not disabling their application.
