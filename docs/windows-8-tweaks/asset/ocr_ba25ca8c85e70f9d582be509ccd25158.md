# Configuring Interface Color Settings

On Windows 8 you can also customize the color and intensity of the interface. These settings are also saved in your theme file, so it is a good idea to customize them as well. Just follow these steps to customize the user interface colors:

+   1. Right-click the desktop and select Personalize.
2. On the Personalization screen, click Color on the bottom of the screen.
3. Pick the color you want to use from the 16 on-screen options or click Show Color Mixer to set a custom color. Optionally, you can select the first item, as shown in Figure 8-4, which automatically sets the color of the interface to match your background wallpaper.
4. Set the color intensity value that looks good to you.
5. Click Save Changes.
