# Customizing the User Lock Screen

The user lock screen is what most users of Windows 8 see on a daily basis. By default, Windows 8 automatically logs in the last person to use the PC, which is why you see this lock screen the most often. Customizing the lock screen is very simple; the most difficult part is finding a good picture:

+   1. Open the Start screen and type **Lock Screen**.
2. Click the Settings filter.
3. Click **Lock Screen**.
