# Selecting an SSD

All of the consumer solid state drives on the market use a type of flash memory called NAND that retains data even when the power is off. When SSDs first became popular, they were primarily made up of single-level cell or SLC NAND memory chips. SLC NAND stores one bit per cell, such as a 0 or 1. Performance and wear durability was great but the technology was very expensive.
