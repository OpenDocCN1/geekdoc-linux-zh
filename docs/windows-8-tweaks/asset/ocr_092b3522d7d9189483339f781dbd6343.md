# Windows Interface Privacy

After you have Internet Explorer under control, you can move on to cleaning the rest of the Windows interface. Just as with Internet Explorer, Windows Explorer keeps track of the applications you run and files you open. It does this so that it can tailor your computer to your personal use with features such as the frequently opened items on Jump Lists.
