+   8.  Navigate to the new file you saved, right-click, and select Open With and then Personalization CPL. This loads the file with the theme browser on the Personalization screen.

+   9.  If your edits were successful, you should get an Apply Theme message asking you to Subscribe to RSS Feed. Click Download Attachments to process all images on the feed as shown in Figure 8-5.

+   10. The images in the feed will be downloaded in a few minutes and applied as your background. The RSS background feed is now set up and should update once a day.

If several minutes pass after the interval you set and the background still does not change, chances are there is a problem with your RSS feed.
