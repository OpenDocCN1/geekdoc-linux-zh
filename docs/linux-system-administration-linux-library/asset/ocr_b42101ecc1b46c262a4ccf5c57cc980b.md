Figure 9.3 shows the KDE graphical alternative, Task Manager. Now you can clearly see that almost all of the physical memory is being used (124,832 KB in and 2,976 KB free), you also see that the amount of swap memory being used is 23,636 KB out of 241,396 KB total. The Task Manager also allows you to kill a task by highlighting it and clicking the Kill Task button or to send a signal to a process by highlighting it and then selecting the signal to send from the Process menu. This is much more comfortable to administrators than the interactive mode of nongtop, and in analyzing the results you will have to realize that you’re using additional resources by running the graphical version.
