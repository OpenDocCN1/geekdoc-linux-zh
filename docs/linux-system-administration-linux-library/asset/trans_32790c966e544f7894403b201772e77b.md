

## 第 7 章 安全

遗憾的是，这使得哈希也变得可用。虽然你无法解密哈希，但无法将生成的哈希列表与 `/etc/passwd` 中存储的哈希进行对比以找到匹配项，这可以被利用。破解者只需使用所有可能的 4096 个盐值（salt values）对单词和常用密码字典进行编码。然后他们会将你 `/etc/passwd` 文件中的密码与他们自己的密码进行比较。一旦找到匹配项，他们就获得了你系统中某个账户的密码。这被称为字典攻击，是获取系统未经访问的常用方法之一。如果入侵者可以获得你的 `/etc/passwd` 文件副本，攻击将变得容易得多，因为他们只需要使用 `/etc/passwd` 文件中存在的盐对字典进行编码即可。为了减少这种漏洞，Linux 采用了密码影子（shadowing passwords）的做法。

## 影子密码

影子机制将哈希字符串从 `/etc/passwd` 文件中移除并放置在 `/etc/shadow` 中，后者是不可读的。只有超级用户拥有对 `/etc/shadow` 文件的读写权限。这通过让超级用户以外的任何人无法获取哈希，阻止了字典攻击。此外，影子套件允许你根据密码的年龄执行某些功能。它允许你要求用户在指定间隔更改密码，限制用户在指定时间内更改密码，在指定间隔后使账户失效，或在指定间隔后账户过期。特定用户的这些信息可以通过 `chage`（更改密码年龄信息）命令检索或更改。`chage` 命令会更改给定用户的相关数据。

Last Change: Jun 06, 2000
Password Expires: Never
Password Inactive: Never
Account Expires: Dec 31, 2000

## 保护 过程

- pam_unix.so
- pam_tck.so
- pam_limits.so
- pam_pfile.so
- pam_password.so
- pam_user.so
- pam_account.so
- pam_seld.so

这被称为可插入认证模块 (PAM)

如果 `/etc/pam.conf` 中的任何条目不正确，或者找不到某个模块，所有的 PAM 服务将失败，用户将不会允许访问系统。同样，如果系统缺少 `/etc/pam.d` 中的相应文件，任何人都无法登录系统，因为登录是这些应用程序中的第一个
