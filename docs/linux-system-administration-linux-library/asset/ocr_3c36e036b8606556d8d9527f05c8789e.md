The default rc.local file is simple. It only contains code to create the /etc/issue and /etc/issue.net files. The /etc/issue file is used to write the text introduction to the login prompt. The result on an x86 computer using Red Hat 7.0 looks like this:

Red Hat release 7.0 (Guinness)
Kernel 2.2.16-22 on an i586

The rc.local file first declares its interpreter, just like all the other scripts that we've looked at in this chapter. Next, rc.local checks whether the /etc/redhat-release exists and is a regular file. If the file is both, the variable R is set to the content of the file.

The statement that follows the redhat-release check exists to determine whether the correct word should grammatically be a or an; if the value of sarch has an initial vowel, the script uses an; otherwise, it uses a.

Next, if a statement is used to determine whether there is more than one processor; second, if there is more than one processor, whether the word for the number of processors begins with a vowel, a in eight (eight) and eleven (eleven). This determination is only important if the system is using multiple processors, in which case the /etc/issue will look something like this:

Red Hat release 7.0 (Guinness)
Kernel 2.2.16-22 on a 2-processor i586

The last few lines of the script simply out the data to the /etc/issue file and copy it to /etc/issue.net.

If you have not created the myewutility script, you can start the myewutility daemon in the rc.local file by adding the following line at the end of the file:

daemon myewutility
