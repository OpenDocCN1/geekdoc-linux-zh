# Linux Filesystem Support 311

BFS BeOS uses its own journaling filesystem, known as BFS. A read-only Linux driver for this filesystem is available from http://hp.vector.co.jp/authors/VA008030/bfs/. The author claims to be working on read/write support, but it does not yet exist. Although BeOS is a single-user OS, BFS supports file ownership and permissions similar to those used in Linux. In theory, BFS could become a contender for a native journaling filesystem, with the others having a commanding lead in early 2001. BFS also lacks support for file access time-stamps, which may hinder its abilities as a native Linux filesystem. BFS's filesystem type is bfs.

NOTE 2.4.x kernels include support for another filesystem known as BFS that is completely unrelated to the BeOS BFS. This BFS is for storing critical system startup files from SCO's UnixWare OS.

FFS/UFS The Fast Filesystem (FFS; aka Unix Filesystem or UFS) was developed early in the history of Unix. It's still used by many Unix and derivative systems, including FreeBSD and Solaris. In principle, FFS/UFS could have been adopted as a native filesystem, Linux's write support for this filesystem is still considered dangerous, much as is Linux's support for writing to NTFS. BFS has been around long enough to spawn several minor variants, but one Linux driver handles them all. FFS's filesystem type is ufs.

UDF The Universal Disk Format (UDF) is a filesystem for recordable CD, DVD, and recordable DVD media. Linux includes UDF support in the 2.4.x kernel series, but the write support is marked "dangerous" and is very limited in terms of supported hardware. This filesystem's type code is udf.

You can browse the Linux configuration menus to learn about other filesystems supported by Linux. If you're looking for support of a specific filesystem and can't find it in the kernel menu, try a Web search.

# Network Filesystems

Some filesystems are designed for use over a network, as opposed to on a hard disk. You can mount these filesystems in Linux as much as you disk-based filesystems, and then perform normal file-access operations on the filesystem. Network filesystems supported by Linux include the following:

+   NFS Sun's Network Filesystem (NFS) is the preferred method of file sharing for networks of Unix or Linux computers. The Linux kernel includes both NFS client (so that Linux can mount another system's NFS exports) and core routines to help a Linux NFS server, which is separate from the kernel. NFS's filesystem type code is nfs.
