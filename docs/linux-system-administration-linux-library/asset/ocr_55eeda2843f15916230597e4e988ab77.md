Another tool for adding, deleting, or reordering services in run levels 2–5 is the tksys
utility, which is available as part of the Red Hat distribution. This utility is X-based and
is quite good. It presents a display of each of the services that are started and stopped at
t various run levels and allows you to delete or add as needed. The principles of its use
are basically the same as for ntsys. Figure 5.3 shows the tksys utility.

The KDE environment has its own graphical manager for SysV scripts, ksysv. It is also
nice and features drag-and-drop capabilities. This utility is also included with the
Red Hat distribution. Since it is a KDE tool, it is X-based. In resolutions higher than
640×480, you need to display it at full size since the smaller default size obscures the pro-
names. (The program does, however, provide help when you mouse over a process
name.). Figure 5.4 illustrates the ksysv utility.

Another other option is the command-line ckconfig utility, which gets bonus points for
easy to use and independent of X. If you pass it a --list switch, it will display a
list of all SysV scripts and whether each is turned on or off at each run level. Listing 5.6
shows the output. The --add and --del switches allow you to alter the processes in each
run level.
