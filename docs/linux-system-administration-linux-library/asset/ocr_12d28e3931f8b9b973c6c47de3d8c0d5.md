The dump commands for the Sunday would be something like this, assuming you need to back up //, /usr, and /var to a SCSI tape unit at /dev/nst0:

```
# dump Ouf /dev/nst0 /\n# dump Ouf /dev/nst0 /usr
# dump Ouf /dev/nst0 /var
```

The dump commands for each of the remaining days of the week would look like this:

```
# dump 5uf /dev/nst0 /
# dump 5uf /dev/nst0 /usr
# dump 5uf /dev/nst0 /var
```

You could also use any non-0 dump level for the incremental backups. A level of 5 gives you the flexibility of performing an unscheduled differential backup by using a higher level, should there be some critical files to back up. You can also perform an incremental backup that resets the normal incremental file count should you make a lot of changes early in the week that you don't want to subsequently back up. Of course, if you deviate from your usual backup schedule, you should carefully label your tapes to prevent confusion.
