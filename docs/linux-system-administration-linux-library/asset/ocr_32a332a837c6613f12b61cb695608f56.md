The swap partition will not have a mount point. Once you select the swap Partition Type, the Mount Point option will be grayed out. Each of the other partitions must be assigned a mount point. Some examples of mount points include /usr if this directory is to be on its own partition or /tmp if it is separate. Some directories must not be a separate partition from the / directory, because files in these directories must be accessible during the boot process, before separate partitions will have been mounted. These partitions are /etc, /lib, /bin, /sbin, and /dev.

Specify the size of the partition in megabytes. The default is 1MB, which is fine if you mark the partition as growable. You'll need to change it if you want to specify a size. Also, if the system has more than one drive, you'll need to highlight the appropriate drive in the Allowable Drives field.

If you have a Windows partition, it will show up on the Partition screen as well. You'll need to assign a mount point like /mnt/windows or /msdos. This will make it easy to access, since it will be configured at mount point.

You could more easily chosen the Automatically Partition and Remove Data option in the Automatic Partitioning screen and let the install process set up a typical server scheme as described earlier. This is certainly the easier course of action, but doesn't give you the flexibility to decide your own partition sizes or specify unusual partition layouts.

# Configuring the Partition Time Zone

Following the Partition screen, you'll see the Time Zone Selection screen. There are so many time zone options as to make this bigger task than it sounds. Select the appropriate zone for your location or the offset from Universal Coordinated Time (UTC). In either case, you must specify whether your system clock uses UTC. If you use the offset method, you must also specify whether or not Daylight Savings Time is needed.
