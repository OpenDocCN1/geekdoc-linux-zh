# Can't Remove LILO from the Master Boot Record

It's possible that youwill install LILO on a computer and discover that you need to recycle the computer for use with Windows, DOS, or some other OS. Many new Linux administrators have problems with this, though, after they've removed Linux, LILO hangs like an albatross around the computer's neck. Fortunately, there are ways to deal with this problem. If your system has LILO installed and you want to remove LILO from the MBR, you log in as root and use the LILO uninstall command as follows:

+   # lilo -u

If for some reason you have deleted Linux from your system and installed some version of Microsoft Windows, you can use the Windows FDISK command to rewrite the Master Boot Record and then reboot:

```
C:> FDISK /MBR
```

# Kernel Won't Load or Loads Only Partially

There are two possibilities here. Either the kernel image has become corrupted in some way or LILO is being passed an incorrect parameter. You see this if someone adds an incorrect append line in /etc/lilo.conf.
