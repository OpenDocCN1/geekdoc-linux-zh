# Helical Scan

Helical scan tapes use a rotating head/drum assembly to read and write, as illustrated in Figure 11.1. The head writes “swipes” on the diagonal instead of parallel to the tape’s edge.

Figure 11.1 Helical scan

![](bbox=[0.273, 0.435, 0.824, 0.696])

This is the same method used by VCR tapes. The 4mm helical tapes are very similar to digital audio tapes (DATs), but have slightly different magnetic tape properties, so aren’t reliably interchangeable. There is an 8mm version as well, which is similar to 8mm videotappe. Most helical scan drives do internal data compression. Hardware data compression reduces the CPU load on the computer if you want to compress your backups, and it is more reliable than the compression used with backup packages, such as tar. Any compression technique produces uneven amounts of compression, though, it tends to compress well, whereas binary formats don’t compress as well, and some pre-compressed data (such as GIF images) may actually increase in size if “compressed” again.
