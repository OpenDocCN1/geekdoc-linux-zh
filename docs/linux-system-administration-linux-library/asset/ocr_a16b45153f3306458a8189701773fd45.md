# Table 12.1 Methods of Accessing USB Devices in the 2.4.0 Kernel (continued)

| Device | Device Filename | Type | Major Number | Minor Number |
|---|---|---|---|--|
| USB-to-parallel adapter | /dev/usb1pn | Character | 180 | 0 and up |
| USB-to-RS-232 adapter | /dev/ttyUSB0 | Character | 188 | 0 and up |

If you need to create a file to access a USB device, you may do so with the mknod command. The syntax of this command is:

```
mknod filename type minor
```

In this command, *filename* is the device name, *type* is either b for block devices or c for character devices, and *major* and *minor* are the major and minor numbers listed in Table 12.1. Be aware that many USB devices' major and minor numbers have changed during the development of Linux's USB code and may change in the future. These are sometimes documented in files in the /usr/src/linux/Documentation/usb directory, but documentation on this point is still spotty in 2000.

# Unusual Serial Devices

Some serial devices are rare and nonstandard implementations of RS-232 ports. The problem with the standard implementation of RS-232 serial devices is that it's difficult to add ports beyond the two included on most motherboards. Adding third and fourth ports presents only minor difficulties—most add-on ports configured to “share” interrupts with the first two ports, but it's necessary to reconfigure these boards to use unique IRQs because Linux doesn't normally work with this arrangement.

> NOTE Internal modems normally include serial port hardware along with modern hardware. Adding such a modem works just like adding a serial port. It sometimes helps to disable an unused motherboard serial port before adding an internal modem, so that the internal modem can take over the identity of one of the first two regular ports. This can normally be done in the computer's BIOS setup screens. Some internal modems don't have serial port hardware. These devices are called WinModems, controllerless modems, or software modems (although the first technically applies only to 3Com products). There are Linux drivers for a few devices—check http://www.linmodems.org for details. Many don't work under Linux, however, and so be avoided.
