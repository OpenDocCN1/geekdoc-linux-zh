Most distributions give you an easier method, an executable called mkbootdisk, usually located in /sbin. Any boot disk you create using /sbin/mkbootdisk will contain a kernel image, an initrd. file, a /boot directory containing the second-stage boot loader and a system map, a /dev directory containing the floppy disk and the root filesystem device, and an /etc directory containing lilo.conf. When you boot from this disk, you will get a LILO prompt and a chance to enter any extra information that LILO might need. The command looks like:

```
# /sbin/mkbootdisk 2.2.16-22
```

# Creating a Boot Floppy without LILO

Alternately, you can copy the floppy using the dd command, which produces a boot disk that is independent of LILO. If your kernel is vmlinuz-2.2.16-22, do to the following:

```
# dd if=/boot/vmlinuz-2.2.16-22 of=/dev/fd0
```

Then tell the floppy on what root partition is, using the rdev command. The rdev command can be used to set the image root device, as in next example, or less commonly, the swap device, RAM disk size, or video mode. If no setting information is included, the current values are displayed. The command to set the root partition to the first partition on the second IDE disk is as follows (this example assumes that your root partition is located in the first partition of the second drive):

```
# rdev /dev/fd0 /dev/hdb1
```

With out LILO, the floppy boots the same way as the system did before. The difference is that the boot program uses the boot sector on the floppy instead of the MBR on the first disk drive. Also, if you are using the floppy without LILO, and if your BIOS is set to try booting from floppy disk, your system will boot the kernel contained in the disk without offering a LILO prompt.

# Using LOADLIN

LOADLIN (Load Linux) is a DOS executable that can initiate a Linux system boot. This program comes with most Linux distributions. Red Hat 7.0 places it in the directory of the first installation CD-ROM. Copy the LOADLIN.EXE file to a DOS partition or boot floppy. (You might want to create a C: \LOADLIN directory.) You'll also need to copy a Linux kernel image file, probably located in /boot on your Linux system, to the DOS partition or floppy. From this point, you can boot Linux (which we will assume is located on the first partition of the second IDE drive) as follows:

```
LOADLIN C:\vmlinuz root=/dev/hdb1 ro
```
