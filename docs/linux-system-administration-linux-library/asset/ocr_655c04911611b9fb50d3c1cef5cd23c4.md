+   2. The type names of any programs you want to run automatically when you log in, including your window manager. If you want a program to run and staying while other programs run, be sure to fill its startup line with an ampersand (&), or the script will stop running until you've closed that program. In most cases, the final program launched from .xinitrc should be your window manager, and should not include an ampersand. This way, when you exit from the window manager, you'll log off the account. As an example, the following file launches xterm window and the wm2 window manager:

```
xterm
wm2
```
