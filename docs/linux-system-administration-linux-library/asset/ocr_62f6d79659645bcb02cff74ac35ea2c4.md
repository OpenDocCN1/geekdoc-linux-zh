# Tips while Restoring

Although restoring files from a backup is a rather simple procedure if the backups are done properly, there are definitely some things to remember here to avoid mishaps.

+   - Be you understand whether the paths specified by the backup software are relative or absolute so that you restore to the intended location. If you are restoring over the top of an existing system, you must be sure that you are in the correct directory that you don't write over files unintentionally. If a backup was made using relative paths, writing to the wrong place is unlikely to cause any harm, because it will simply place everything under the present working directory. If you have created a backup with absolute paths, however, the files will already overwrite the files. There is, an absolute-path backup of /usr will write over the existing /usr tree. It is certainly OK to write over this intentionally, but many have done so inadvertently to their dismay.

+   - Read the tape just before putting it in the drive. It's unfortunately easy to grab a tape, put it down in a stack of tapes, and then pick up the wrong one. You may not discover that you are extracting the wrong archive until the process finishes, leaving you to extract your backup in "free" time.

+   - Buy reasonably good quality media. You don't have to buy the best, but definitely buy a tape that is going to stand up to the recurring use. Name-brand tapes are more likely to survive repeated uses than generic or minor-brand tapes. This applies to CD-Rs as well. For archival CD-R storage, gold/gold media (which appear gold on both sides) and silver/blue (silver on top, blue on bottom) are likely to last longer than gold/green media. The storage media that work best for you may depend on your tape or CD-R drive; for some drive certain types of tapes the longest, or certain CD-Rs produce the finest duds. +   - Never pull tapes while they are active; let the tape finish and rewind. If you use a nonrewinding device file, let it finish the current process and then rewind the tape with mt. Most tape drives rewind a tape when you insert it in the drive, if it's already rewound, removing a non-rewound tape won't save you any time in the long run. Pulling an active tape out of the drive is a good way to damage the tape.

+   - If you get errors when trying to read or write to a tape, try cleaning the drive heads with the appropriate cleaner tape. Often dirty heads cause a tape drive to report or read incorrectly.

+   - If you get errors when you write a CD-ROM, try a slower write speed or a better quality of media.
