(Figure 17.3 shows outgoing mail being sent directly, but it could be easily relayed through other ISP's server.) The main piece is the retrieval of mail via POP and IMAP from the ISPs.

A tool that is extremely helpful in configuring remote mail retrieval via POP or IMAP is fetchmail. This tool is a dedicated mail client program. It connects to a remote POP or IMAP server, retrieves the mail from that server, and injects the mail into the local system's mail queue. When fetchmail is used in conjunction with a conventional SMTP server, the result can be a mail system that works almost as if it were connected directly to the Internet.
