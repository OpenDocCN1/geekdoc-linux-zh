Again, once this work is finished, the init process initiates a Bash shell, reads the user configuration files as described in “User Initialization Files” below, displays a login prompt, and waits for some process that needs its attention.

# Modifying the Startup Procedure

As a general rule, you should not have unused services running on your computers; you should turn off any services that are automatically initiated at boot time but are not needed. Conversely, any services that you want to start automatically but not turned on at boot time by default should be configured to start in the appropriate run levels. For example, PCMCIA runs by default in a standard Red Hat 7.0 installation; most desktop computers do not use PCMCIA, so it should be disabled. Similarly, any of the r command links (rsh, login, rexec, and so on) for remote users looking for security vulnerabilities to be disabled if they are not being used. These commands are mainly targeted by outsiders looking for security vulnerabilities to exploit. Leaving such services running provides a port that expects input, and this port could potentially be used to access the system. To disable the service, thereby closing the port, modify the set of services that are automatically started at boot; to do this, use the ntsysv utility, which is part of the standard Red Hat 7.0 distribution. This console-based utility configures the current run level by may be passed a -level option to configure another level. Figure 5.2 illustrates the ntsysv utility.
