# initrd Images

Linux includes support for RAM disks, which are filesystems loaded from a floppy or hard disk but stored in RAM during use. RAM disks can be useful system installation or maintenance, because they obviate the need for physical disk access. An initial RAM disk (initrd) image is a kernel-specific image that allows some setup functions to occur before the root filesystem is mounted. An initial RAM disk causes the system startup to occur in two stages: with a minimal set of drivers, and then the RAM disk image loads additional modules as needed. All the boot process to take advantage of devices that would not normally be available until the boot process is complete. This is especially important if you wish to use a Linux system that is on a RAID array, since support for RAID other than RAID-0 is modular and not found in the kernel. Until recently, initrd was used during an installation from a PCMCIA or SCSI hard drive or CD-ROM. Now, the Red Hat installation program allows you to find your SCSI or PCMCIA-driven hard drives and CD-ROMs. If you need to create an initrd image, use /sbin/mkinitrd This command has the following format:

mkinitrd image-name kernel-version

So for the 2.2.16-22 kernel (the kernel-version number must match the /lib/modules/ directory name), the command would look like this:

```
# /sbin/mkinitrd 2.2.16-22.img 2.2.16-22
```

Then add the initrd line into kernel's stanza in your /etc/lilo.conf file, as described shortly, and you're set.
