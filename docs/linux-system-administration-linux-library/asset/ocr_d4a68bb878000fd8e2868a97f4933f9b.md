# Figure 16.3 xf86cfg lets you configure XFreeBee 4.0 in a point-and-click fashion.

![](bbox=[0.283, 0.147, 0.715, 0.606])

**WARNING** xf86cfg assumes it works on /etc/X11/X86Config, not the /etc/X11/X86Config-4 file used by Red Hat 7.0. You must therefore temporarily rename the file, or create a link, to use this utility in Red Hat 7.0.

In addition to using xf86cfg, you can configure XFree8 4.0 by issuing the command **XFree86-configure**. This command creates a file called /root/X86Config.new, which should be at least minimally functional. You can then modify it via xf86cfg or manual editing, should you need to tweak it.
