To add a printer using Printtool, follow these steps:

+   1. Start the Printintool utility. You'll see its main screen, as shown in Figure 13.2, although you may not see any defined printers.
2. Click Add. Printintool responds by displaying the Add Printer Entry dialog box, which you can select from among five different types (see Figure 13.3).
