SSH is a client/server package that encrypts all outgoing data from either direction, creating an encrypted tunnel. The client sends a request to the server (sshd), and the server sends back a public host key and a public server key. The client attempts to verify the public host key by locating it in /etc/ssh_known_hosts or the .ssh/known_hosts file in the client. If the client is able to verify the public host key, it generates a 256-bit random number, encrypts it with the two keys from the server and the client to derive the session key, which is used to encrypt any communication between the two during its session. If the process fails to generate a session, access by the client is denied. This is a somewhat simplified description, but it illustrates the basic process. For more information, start with the SSH-FAQ at http://www.tigerlair.com/ssh/faq/ssh-faq.html.

Red Hat Linux 7.0 includes a free version of SSH that was developed by the OpenBSD Project. Called OpenSSH, it includes the following: the ssh program, to be used in place of Telnet and login; scp, to be used in place of rcp and ftp; and the server-side ssh program and its supporting utilities.

# Buffer Overflow

A buffer overflow occurs when a program written to read data is not properly restricted to the intended area of memory. This is similar to when your cellular phone picks up someone's conversation. You don't really know whose conversation you are hearing, but you might hear something the speaker didn't intend to reveal to outside the target audience. A buffer overflow causes a program to read data that was not intended for it. It is quite difficult for even skilled programmers to take advantage of this, but there are programs available on the Internet that were written explicitly for this purpose. Typically, programs prone to overflow buffers are reported on the main security lists for your distribution.

# Scanning or Sniffing

Network scanning involves the probing of an IP address or some of its ports to determine which services are available on that system. Scanning is the process by which data packets are intercepted as they are sent over the network. Specifically, crackers look for passwords and the like. There are packages available that help you to detect your system is being attacked in this way and even to fool the sniffer. Some of these packages are detailed in the “Intrusion Detecting Packages” section later in this chapter.
