# Install Boot Disk

There are two flavors of boot disks these days. The first is used to boot into the installation and is typically referred to as an *install disk*. These days, most CD-ROM distributions provide a bootable CD-ROM, removing the need for a boot disk. Still, if your computer BIOS does not allow booting from a CD-ROM or if your CD-ROM is not functioning, you will need to create a boot disk by copying the correct boot image to floppy. If your distribution does not come with a ready-made boot disk, you must create one using one of the boot disk images from your installation CD-ROM. Some bootable CD-ROMs can be used directly in the same way as an emergency floppy.

There are three images that can be used for this disk because different methods require that different capabilities built into the kernel. If your distribution came with a premade boot disk, it is probably equivalent to one made from *boot.img*, since it is the most commonly used boot image. There is also a bootnet.img image for installing from a non-PCMCIA network device. A *pcmia.img* image is available for installation via a PCMCIA device like some CD-ROM, Ethernet adapters, or hard drives.

Since the install disks allow you to boot your system and use a virtual terminal, they can be used to repair flaws, but some of the same restrictions apply as single-user mode. The boot disk contains only a kernel image, so all the initialization is performed using the system's own files.

There are several ways to create an install floppy. If you have a working Windows system, you may create the disk by using WRITE.EXE. This binary is located in the installs/CD-ROM. To execute it, create the command and tell it which of the images in the images directory you wish to write to floppy and which device to write to.

If you are lucky enough to have a Linux or other Unix machine available, you can create the disk dd with a variation of the following command:

```
# dd if=/mnt/cdrom/images/boot.img of=/dev/fd0
```

On some systems you'll need to specify the block size. See the man page for the dd command and may also use the cat command as follows:

```
# cat /mnt/cdrom/images/boot.img >/dev/fd0
```

You must not use the cp command, because the idea is to transfer the raw image without any formatting, and the cat command requires a formatted disked.
