# The History List

The history list allows you to retrieve previously entered commands for reuse instead of having to remember and retype them. This is useful when the command is lengthy or frequently used. The .bash_history file is a list of commands like those shown in Listing 4.3.

# Listing 4.3 .bash_history File

```
man lsattr
lsattr
lsattr |more
man find
man ls
pine friend@hometown.com
clear
pine
clear
exit
pine
su
pine otherfriend@nothome.com
clear
exit
pine friend@hometown.com
su
startx
exit
```
