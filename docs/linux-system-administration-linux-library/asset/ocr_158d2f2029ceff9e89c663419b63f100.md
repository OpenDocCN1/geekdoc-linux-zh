# Linux Memory Usage

Many new system administrators misunderstand the high usage of memory on a Linux system, and when they see statistics like those illustrated, believe they need to add more physical memory. In reality, Linux makes very good use of the physical memory and consume nearly all of it. Operating systems that don't simply waste the resource. To gauge your memory usage with top, look how much swap memory is being used. If, in this case, only a very small amount is being used, you don't need more memory. When the system does swap and so often, you need to consider adding either more swap space or more memory. If your swap is already double the amount of your physical memory, add more physical memory.
