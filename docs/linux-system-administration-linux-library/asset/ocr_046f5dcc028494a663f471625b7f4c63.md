This form of the command is very useful when you are looking for information on a specific daemon. Simply pipe the command into a grep command to see whether the daemon is in question. This is especially useful in a script where the other output would confuse the situation. For this reason, it is one of the ps command that is most commonly used by system administrators. The man page for the ps command lists the many options available to tailor the output to what you need.

The top command uses the /proc system to display all processes with the percentage of CPU and percentage of memory that each one is using. You can also do this with a ps command, but top is better in that it is a continuous listing which is updated in real-time by CPU usage and is configurable. The most CPU-intensive programs are listed first, as shown in Figure 3.3. This is extremely helpful when your system is running slowly, and you want to find out process is dominating the CPU. In the case of Figure 3.3, one process (setathom) is consuming 97.8% of the CPU time. This might or might not be a sign of trouble, depending upon whether process should be consuming a lot of CPU time. The top command also lists specifies such as uptime, the number of users, the number of processes and their status, and how real memory and space are used.
