Of course, other information, including the user's name string, Uncle Donald, may be changed as well. You can change the home directory, but you must create the new directory and move files from the old directory to make it usable. Do not change the UID or GID unless you really know what you're doing. If you change these fields inadvertently, Donald will lose access to his files, the system sees the owner and group designation unless you use the /etc/passwd file to convert them output in human readable format to the user.

In principle, it's also possible to edit the contents of /etc/shadow in a similar manner. In practice, most of its contents come in a form that's easily handled by humans. The password is encrypted, so you can't change it by hand unless you're simply copying a password from another system (which is potentially risky). The time information is entered in units of days since 1970, which is awkward to compute. In all in, it's best to leave /etc/shadow alone.

# Modifying User Accounts with Linuxconf

To modify any user's account, take it from a drop-down menu or typing linuxconf at

+   Start Linuxconf by selecting it from a drop-down menu or typing linuxconf at a prompt.

+   Open Config > Users Accounts > Normal > User Accounts.

+   Select the account that you'd like to change. You will be presented with the User information screen, which is essentially identical to Figure 6.2, with any existing values filled in.

+   Change the appropriate fields, and select Accept to accept the modified user information.

+   Click Quit from the User Accounts screen, which follows.

+   Click Act/Changes from the main Linuxconf screen.

+   Activate the Changes from the Status of the System screen.

+   Quit from the main Linuxconf screen.

# Modifying User Accounts with usermod

To use the usermod utility to alter a field in a user's password record from the command, using the following command:

```
usermod [-c comment] [-d home_dir [-m]] [-e expire_date]
[-f inactive_time] [-g initial_group] [-G group,...]]
[-f login_name] [-p password]
[-s shell] [-u uid] [-0] [-L|-U] login
```
