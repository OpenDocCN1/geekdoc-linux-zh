# Kernel Compilation 255

One of the best places to look for a kernel is http://www.kernel.org. This site includes links to "official" kernel source tarballs. You can also find kernel files on major Linux FTP sites, such as http://sunsite.unc.edu and http://tsx-11.mit.edu. If you want to use an RPM or Debian package, check for kernel source-code files for your distribution's maintainer. If you use an RPM or Debian kernel package, you may need to download two files: one with the kernel source code, and one with the kernel header files. Tarballs typically include both of files in a single tarball.

A 2.2.17 kernel tar is 16MB in size; a 2.4.0-test8 kernel tar is 21MB. (Kernels are also available in bzipped tar files, which are somewhat smaller than the decompressed tar files. You use bzip2 to compress these files rather than gzip.) Because of their large size, these kernel files may take some time to download, particularly if you are stuck using a PPP link.

Once you've downloaded the kernel tarball, you can unpack it in the /usr/src directory. The tarball creates or installs to a directory called linux.

> WARNING If your/usr/src directory already has a directory linux, you should rename it to something else and create a new linux directory for the source package. This will prevent problems caused by unpacking a new source tree over an old one, which can create inconsistencies that cause compilation failures.

You can unpack a kernel tarball just as you would any other source code tarball, for instance:

```
# tar xzvf ~/linux-2.4.0-test8.tar.gz
```

If your source tarball uses bzip2 compression, you can use a command similar to the following to extract it:

```
# tar xvf ~/linux-2.4.0-test8.tar.bz2 --use-compress-program bzip2
```

# Kernel Configuration Options

Once you've extracted your kernel tarball, you can proceed to configure it. Use any of the following three commands to accomplish this task: 

```
# make config
```

This command runs a text-based configuration tool that asks you specific questions about each and every configuration option. You can't skip arbitrarily from one option to another, so this method is quite awkward.
