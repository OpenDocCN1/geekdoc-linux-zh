Of the commands listed in Table 11.5, the most commonly used are --create, --extract, and --list. The most useful qualifiers from Table 11.6 are --file, --listed-incremental, --one-file-system, --same-permissions, --gzip, and --verbose.

> **WARNING** The tar --one-file-system option is critically important to backups. Ordinarily, tar backs up everything under the directory it is given as input. Although this works if you feed tar the name of a directory that has nothing mounted on, it can cause problems for certain types of mounts. For example, if you tell tar to back up the root directory (which is, /), the program backs everything mounted on that directory or any subdirectory, including NFS or Samba shares served by other machines. Whose, tar also backs up the Linux /proc filesystem, which is a virtual filesystem that represents the computer's status, including all its memory. At restoration time, tries to overwrite the /proc filesystem's contents, which is likely to cause serious problems, possibly even including a system crash. For this reason, it's best to use --one-file-system and feed the name of each partition you want to back up.

The tar command backs up to or from files. Because Linux treats hardware devices as if they were files, you can tell tar to back up or to an appropriate hardware device file, in order to use that device directly.
