# XFree86 4.0

XFree86 4.0 是相对于 3.3.6 版本的重大升级。这次升级增加了许多功能，并对 XFree86 配置引入了重大更改。如果运气好，你不需要担心这些更改，因为它们会在系统安装时自动处理。如果你想从 3.3.6 升级到 4.0，或者你需要修改安装，那么你就必须处理这些更改。

# 与 XFree86 3.x 的区别

XFree86 4.0 相比 XFree86 3.x 提供了多改进，包括：

- **多头显示**：你可以在单台电脑上安装多个显卡，将它们连接到相邻的显示器上，并让 X 创建跨越两个显示器的虚拟桌面。

- **新的驱动架构**：在 XFree86 3.x 中，每个 X server 可以包含一个或多个针对特定显卡的驱动程序。要使用 S3 板，你会使用名为 XF86_53 的 X server；要使用 ATI Mach64 板，你会使用 XF86 Mach64。相比之下，在 XFree86 4.0 中，你使用单一的 XFree86 X server，它会为你特定的视频硬件加载驱动模块（位于 /usr/X11R/lib/modules/drivers）。这种设计同样更容易扩展，尽管你作为用户和管理员可能感觉不到太大区别。

- **DDC 支持**：数据显示通道 (DDC) 是自 20 世纪 90 年代中期以来视频硬件的标准。它允许显示器向显卡和视频软件通信其最大刷新率。XFree86 3.x 不支持 DDC，因此必须手动输入这些信息。XFree86 4.0 增加了对 DDC 的支持。

TrueType 字体支持：XFree86 4.0 增加了对 TrueType 字体的支持（Microsoft Windows 标准字体类型）。在实践中，TrueType 字体通过独立的字体服务器在 Linux 中已可用一段时间，稍后将在“配置字体服务器”。内置的 TrueType 支持是一个额外的便利。

DRI 支持：直接渲染接口 (DRI) 是一种硬件加速标准，允许 Linux 程序利用具有 3-D 硬件加速功能的显卡。从 XFree86 4.0.1 起，仅支持 3dfxs 芯片，但这种支持可能会在 2001 年及以后扩展。

新的配置文件格式：新的 XFree86 选项强制要求新的配置格式。配置文件可能被称为 XF8Config，或者在某些系统（包括 Red Hat 7.0）上可能被称为 XF8Config-4。

你可以通过查看 /etc 或 /etc/X11 中的 X 符号链接来检查你是否正在运行 XFree86 4.0。如果该链接指向 /usr/bin/XFree86，则你运行的是 XFree86 4.0。如果该链接指向其他文件，则你的系统使用的是 3.x 或可能的第三方 X server。

# 配置 XFree86 4.0

对于管理员，XFree86 4.0 的重要更改是配置格式。新文件的组织方式与 3.x 的 XFConfig 类似，详情请参考早前的“XFConfig 文件”。此外，新文件增加了几个额外的部分：

- **ServerLayout**：该部分定义了服务器的一些功能。具体来说，它绑定了特定的输入输出设备。你可能不需要调整此部分。
- **Module**：该部分指定了想要加载的服务器模块。模块可以提供 TrueType 支持和 DRI 支持。你可能不需要调整此部分。
- **DRI**：如果你足够幸运拥有 XFree86 支持的 3-D 加速显卡，你可以在此部分定义谁可以访问这些功能。

**警告** xf86cfg 假设它工作在 /etc/X11/X8Config，而不是 Red Hat 7.0 使用的 /etc/X11/X8Config-4。因此，你必须临时重命名文件或创建一个链接，以便在 Red Hat 7.0 中使用它。

除了使用 xf86cfg，你还可以通过执行 **XFree86-configure** 命令来配置 XFree86 4.0。该命令创建一个名为 /root/X8Config.new 的文件，它至少应该可用。

# 自动启动 X

安装 Linux 时，你可能被问及想以文本模式还是图形模式启动操作系统。如果你选择了前者，你会看到一个文本登录界面，并在登录后启动 X。如果你选择了后者选项，并且系统配置正确，你应该会被一个基于 X 的登录程序欢迎。在旧版本的 Linux 中，这种登录由名为 XDM 的程序处理。较新版本的 Linux 使用与 KDE 或 GNOME 项目相关的类似工具（稍后描述）。这些更新的软件包被称为 KDE 显示管理器 (KDM) 和 GNOME 显示管理器 (GDM)。然而，所有三个程序提供着相同的功能：让你进入电脑。为了简单起见，本章的其余部分将所有程序称为 XDM。
