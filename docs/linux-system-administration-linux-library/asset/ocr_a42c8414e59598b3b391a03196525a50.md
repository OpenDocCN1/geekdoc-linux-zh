6. Enter the identifying information for your printer—the name or names you want to use for it, the spool directory, and the printer device file (or network identifying information). Do not click OK.

7. Select Next to the Input Filter field. Printool displays the Configure Printer dia-log box shown in Figure 13.5. You should set several characteristics of your printer and how you want it to be handled:

+   Select your printer type in the Printer Type list. This list is not a complete list of printers; instead, it lists broad class of printers. Many printers, for instance, emulate HP LaserJet models, so you would select the appro-priate LaserJet model from the list. Also, there's just one entry for all PostScript models on this list. Your selection here will determine what other options are available.
