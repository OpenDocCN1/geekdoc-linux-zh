# Configuring an X Server

Subsection "Display" Each Screen section has one or more Display subsections, which define the characteristics of a given color depth. The Depth line identifies the color depth for which the subsection is written, and the Modes line identifies the resolutions at which X will work in this color depth. You can use this feature to define different resolutions to be associated with different color depths. Your video card may be capable of producing 32-bit color at your highest resolution, you can specify a lower resolution for the 32-bit display. You can then start multiple X servers, as described earlier, using the color depth as a cue to use a different resolution.

As a general rule, it's easiest to create an XF86Config file using an X configuration tool, as described shortly. Hand-editing XF86Config may be useful, however, when you change hardware. When you replace a monitor, for instance, and X will automatically use the new settings to configure the optimal refresh rate. Hand editing can also be useful when fine-tuning your configuration; for example, you can add a DefaultDepth line to the section.

# Using an X Configuration Tool

All major Linux distributions include X configuration tools that run during system installation. These tools are usually available after installation, as well. Examples include: xf86config is the crudest of the common X configuration tools. It runs entirely in text mode, and asks you a series of questions about your hardware and desired configuration. There's no possibility to go back and correct an error, so you must kill the program and start again if you make a mistake. Because of its crude interface, xf86config can be used before X is running or X is seriously misconfigured.

Xconfig This program is another text-mode X configuration tool. Unlike xf86config, though, Xconfig uses color text and text dialogs rather than simple streams of text. This makes Xconfig easier to use.

XF86Setup This utility, shown in Figure 16.2, works only when X is running. You can use this utility to reconfigure an X server that's working subnormally, but you can't use it to get X working at the outset. (Most distributions, including Red Hat, use GUI X configuration tools similar to XF86Setup to configure the system initially. These work because the setup routines running the lowest-common-denominator VGA server, which works on all but the most ancient video displays.)
