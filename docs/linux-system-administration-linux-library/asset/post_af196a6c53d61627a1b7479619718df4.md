### Linux Memory Usage

Many new system administrators misunderstand the high usage of memory on a Linux system, and when they see statistics like those illustrated, believe they need to add more physical memory. In reality, Linux makes very good use of the physical memory and consume nearly all of it. Operating systems that don't simply waste the resource. To gauge your memory usage with top, look how much swap memory is being used. If, in this case, only a very small amount is being used, you don't need more memory. When the system does swap and so often, you need to consider adding either more swap space or more memory. If your swap is already double the amount of your physical memory, add more physical memory. The free utility, described earlier, shows usage information only.

## traceroute

The traceroute utility will help you track down problems in your network or determine a problem is actually outside your network. The traceroute utility prints the route that packets take to a specific network host and three measurements of the time in milliseconds for each hop. Listing 9.1 shows the traceroute command in action. Using this information, you can determine whether there is a delay at one of the network stops that your data makes between the sender and receiver, thereby providing useful information when you are troubleshooting a network problem. Listing 9.1 shows a slow increase in the times between the first hop and the final one, but there's a jump at the final hop, suggesting that the destination is overloaded or on a slow link. In this case, you can't do anything to improve network performance. If you'd seen a big jump within your network, it's possible that reconfiguring your network or upgrading its hardware could improve performance.

## nice and renice

The nice command allows you to set the priority of a process when it starts. The priority value ranges from -20 to 19. A lower value means a higher priority. The renice command is used to change the priority of an already running process.
