# Available Desktop Environments

The two most common desktop environments available on Linux are the GNU Network Object Model Environment (GNOME) and the K Desktop Environment (KDE). There are also several less-used desktop environments available. Brief descriptions of these environments follow:

GNOME is built upon the GTK widget set, which was originally developed for the Image Manipulation Program (GIMP) graphics utility. In 1.0.x versions, GNOME uses Enlightenment as the default window manager, but this is changing to Sawfish with the 1.2.x versions (included in Red Hat 7.0). In any version, you can easily reconfigure GNOME to work with other window managers, although some integrate better with GNOME than do others. GNOME features an ever-increasing number of mini-applications and configuration modules. It's rarely the favored desktop environment on Red Hat and Debian systems. You can learn more at http://www.gnome.org.

KDE uses the Qt widget set, which at one time was a controversial choice. When KDE was originally developed, Qt used a license that didn't meet with full approval among all open source developers, which was one of the reasons for the development of GNOME, using the open source GTK widget set. Today, however, Qt's license has changed, and it meets with the approval of most open source developers. Unlike GNOME, KDE is tightly tied to its own window manager, KDE is somewhat more advanced than GNOME. Red Hat 7.0 ships with KDE 1.1.2, but version 2.0 was released in October 2000. KDE includes a large number of mini-applications and configuration utilities. Most Linux distributions favor KDE as their default desktop environments. The project's home page is at http://www.kde.org.

Xfce is a lightweight desktop environment compared to GNOME or KDE. Like GNOME, it's built around GTK. Like KDE, it uses its own window manager (Xf). Xfce includes a modest selection of mini-applications and configuration utilities. You can learn more at http://www.xfce.org.

CDE The Common Desktop Environment (CDE) is the only commercial desktop environment available for Linux. Although popular on many commercial versions of Unix, CDE is uncommon on Linux. CDE uses the Motif widget set, which has historically been the widget set of choice for commercial Unix and Linux applications. CDE for Linux can be obtained from Xi Graphics (http://www.xi.com), under the name DeDesktop.
