# Table 5.1 Errors Indicated by the LILO Prompt

| LILO Display | Meaning |
|---|---|
| Nothing | LILO hasn't been loaded. |
| L | First-stage boot loader is loaded and started. |
| LI | Second-stage boot loader is loaded. |
| LIL | Second-stage boot loader is started. |
| LIL? | Second-stage boot loader at incorrect address. |
| LIL- | The descriptor table is corrupted. |
| LILO | LILO loaded correctly. |
