# Chapter 18 Troubleshooting Your Linux System

NOTE Hard disks are composed of one or more platters, each of which has associated with one or two heads. These heads move across several different tracks, forming virtual cylinders across the stacked platters. Each cylinder is broken into multiple sectors, each of which holds 512 bytes on most hard disks. Early hard disks could be defined by the number of cylinders, heads, and sectors they used; hence the term CHS geometry or disk geometry. The x86 BIOS and the standard x86 partitioning table use this method of describing a disk. The trouble is that all modern hard disks lie about their CHS geometries. Furthermore, the lies told by them sometimes cause problems, BIOSes and OSs frequently change these lies to other. With such fabrication occurring, the situation sometimes lapses in chaos when two different software components believe different things about the disk's geometry. This can be the source of some LILO problems, if LILO uses one CHS geometry setting and another tool using another setting.

# Making the System Boot a New Kernel

To change the boot kernel from linux to linux_new, edit the /etc/lilo.conf file to change the default=line to default=linux_new. If you don't see a default line, simply add one. Not long ago, lilo simply took the first listed kernel image as the default image, older lilo.conf files won't have the default parameter. Don't forget to rerun /sbin/lilo after you make any changes to the /etc/lilo.conf file.

Here is a sample /etc/lilo.conf file:

```
boot=/dev/hda
map=/boot/map
root=/dev/hda1
install=/boot/boot.b
prompt
timeout=50
message=/boot/message
linear
default=linux
image=/boot/vmlinuz-2.2.16-22
label=linux
read-only
```
