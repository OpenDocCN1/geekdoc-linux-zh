# Chapter 5 Startup and Shutdown

In the first uncommented line, the init program is told what level to use after a reboot. The line looks like this:

```
id:3:initdefault:
```

The first part of this line, id, simply represents the word initdefault. The number 3 indicates that the system should start in run level 3 by default. For a system that uses the X Window System graphical environment (discussed in Chapter 16), you would instead use this command:

```
id:5:initdefault:
```

Keep in mind that specifying an initial run level of 5 will cause an inability to log in if X has a problem preventing it from starting. Typically, you'll see one of two things: Either screen will repeatedly clear as the system tries to start X, fails, tries again, and so on; or the system will try to start X once, and drop back to run level 3.

Following the run level line, the next uncommented line in Red Hat's initab file tells the init program which script to start:

```
si:5:/etc/rc.d/rc.sysinit
```

Here we've chosen to run the rc.sysinit script, which we'll look at detail in a moment. Since the second column-delimited field, the run level field is empty, this script will be run only at boot time. The rest of the line, /etc/rc.d/rc.sysinit, is the exact command to run.

After the rc.sysinit file exits, the initab starts the /etc/rc.d/rc script with the appropriate run level as an argument. The rc then executes all of the scripts pointed to the symbolic links contained in the directory for that level. For example, the scripts pointed to the links in /etc/rc.d/rc3 are run.
