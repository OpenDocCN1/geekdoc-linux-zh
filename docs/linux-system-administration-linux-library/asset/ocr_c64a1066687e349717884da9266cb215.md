# Using Text-Based Tools

To use rpm, you combine one operation with one or more options. In most cases, you include one or more package names or package filenames, well. (A package filename is a complete filename, while a package name is a shortened version. For instance, a package filename might be samba-2.0.7-21ss1.i386, rpm, while the matching package name is samba.) You can either use the rpm command once for each package, or list multiple packages, separated by spaces, on the command line.

When installing or upgrading a package, the -U operation is generally the most useful because it allows you to install the package without manually uninstalling the old one. This one-step operation is particularly helpful when packages contain many dependencies, because rpm detects them and can perform the operation should the new package fulfills the dependencies provided by the old one.

To use rpm to install or upgrade a package, issue a command similar to the following:

```
# rpm -Uvh samba-2.0.7-21ss1.i386.rpm
```

You could also use rpm -ivh in case of rpm -Uvh if you don't already have a package installed.

> WARNING It's possible to distribute the same program under different names. Upgrading in this situation might fail, or it may produce a duplicate installation, which could cause bizarre program-specific malfunctions. Red Hat has described a formal system for package naming to avoid such problems, but they still occasionally occur. It's therefore best to upgrade a package using a subsequent release provided by the same individual or organization that provided the original.
