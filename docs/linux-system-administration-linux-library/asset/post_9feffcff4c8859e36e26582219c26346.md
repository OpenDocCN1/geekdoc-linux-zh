## The History List

The history list allows you to retrieve previously entered commands for reuse instead of having to remember and retype them. This is useful when the command is lengthy or frequently used. The .bash_history file is a list of commands like those shown in Listing 4.3.

### Listing 4.3 .bash_history File

```
man lsattr
lsattr
lsattr |more
man find
man ls
pine friend@hometown.com
clear
pine
clear
exit
pine
su
pine otherfriend@nothome.com
clear
exit
pine friend@hometown.com
su
startx
exit
```

To create the history list, the shell stores all of the commands that were executed during a session in a file called by default .bash_history. (You can rename this file by setting the environment variable HISTFILE the environment variable HISTFILE to the new name, and you can determine how many commands will be retained by setting the HISTSIZE environment variable.

The easiest way to retrieve a command from a history list is by using the arrow keys, especially if the command was recently entered. The up arrow retrieves the previous command from the history list, and the down arrow retrieves the next command. You may traverse the entire history list if you wish, but if HISTSIZE is large, this can become tedious.

An alternate way to search the history list is to enter on the command line followed by the first few letters (until it is unique) in the command you wish to retrieve. The most recent iteration of the command is then retrieved and executed. Enter!pine at the command line will retrieve the last pine in the .bash_history file, pine myfriend@hometown.com. If you know that you had recently used the pine command to retrieve otherfriend, you could type !pine o at the prompt and the pine friend@nothome.com command would be retrieved.

## Basic Commands

Although there are exceptions, basic Linux commands generally take one of the following forms:

```
command [-option] target
command [-option] source destination
```

Linux command names, like filenames, are case-sensitive. Although most commands are completely lowercase, some options are uppercase. The man pages discussed above are invaluable in use of unfamiliar commands. Even someone who has been administering a system for 20 years can learn something about the functionality of the basic commands. New options are being added all the time, as there are entirely new commands.

The Linux commands presented below are some of the most commonly used. These definitions are not intended to be comprehensive but to give you a general idea of their use. Although we show the general syntax of each command list, this is not a formal reference, defining every option of each command. For a complete reference, see the appropriate man page. Later chapters discuss many of these commands in more detail, in the context of their administrative uses.

## User Account Commands

The commands in this section allow you to work with user accounts. They include the commands to create a user, to delete a user, and to perform various other common functions. More information on user-specific tasks is available.

### adduser

There is actually adduser under Linux; its linked to useradd.

### finger

```
finger [options] [username]
```

The finger command is used to display information about the user.

### groups

```
groups [username]
```

The groups command prints a list of groups to which the user belongs.

### newgrp

```
newgrp [group]
```

The newgrp command is used to change the user's group.

### last

```
last [options] [username]
```

The last command lists all users who logged in.

### mesg

```
mesg [options]
```

The mesg command controls access to the terminal.

### passwd

```
passwd [options] [username]
```

The passwd command is used to change the password of the user.

### pwd

```
pwd
```

The pwd (print working directory) command is used to show the current path.

### repquota

```
repquota [options]
```

The repquota command prints the amount of disk space used by each user.

### su

```
su [options] [user]
```

The su command runs a shell with the effective user ID.

### sudo

```
sudo [options]
```

The sudo command is used to allow users to execute commands that are normally reserved for the superuser.

### useradd

```
useradd [options] login_name
```

The useradd command creates a new user on the system.

### userdel

```bash
userdel [-r] login_name
```

The userdel command deletes the system account for a user. Unless the -r option is given, the userdel command leaves that user's home directory and all the user's files in place.

### usermod

```
usermod [options] login_name
```

The usermod command modifies the specified user's account information.

## File-Handling Commands

This section contains commands geared toward file creation and management. Most of these are the basic commands you are likely to use daily.

### cat

```
cat [options] filename(s)
```

The cat command dumps a file to stdout. Often stdout is then redirected into another command via a pipe or to a different file. It is often used to concatenate two or more files, thereby creating a new file.

### chmod

```
chmod [options] mode(s) filename(s)
```

The chmod command is used to change the access mode of files.
