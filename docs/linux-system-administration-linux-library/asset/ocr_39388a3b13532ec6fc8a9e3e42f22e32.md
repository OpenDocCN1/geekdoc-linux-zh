Like POP, IMAP is available in several variants, the most common of which is IMAP-4, which uses port 143. IMAP's command set is much more complex than POP's. To use it from a Telnet connection to port 143, the operation details tend to be tedious, as shown by Listing 17.3. The client must precede each command with an identifying code beginning with the letter A, as in A2 or A0014. Because IMAP stores mail in local mailboxes, it's necessary to pick one with the SELECT command before performing other operations. IMAP allows the client to read messages with the FETCH command, as the text or specific classes of header. The client can also copy messages into specific folders (as in the A4 COPY 1 demos command, which copies message 1 into the demos folder), and well as create, delete, and otherwise modify the folders themselves.
