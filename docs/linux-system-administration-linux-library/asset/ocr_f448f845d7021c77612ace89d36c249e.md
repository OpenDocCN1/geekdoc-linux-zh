```
cat /tmp/calendar | sed -e 's/Jan&/uary/' | sed -e 's/Feb&/ruary/' |

&/' | sed -e 's/Jul&/y/' > newfile
```

In this example, a file containing dates within the first seven months of the year needs to be altered so that the abbreviated month name is replaced by the full name of that month. The edited file is to be written out to newfile. First we cat the file into sequence of sed commands. The sed tells us that the next thing is a sed command to be executed. This command's placement within single tick distinguishes it from the rest of the line. The s means that we wish to substitute the second phase for the first. Thus this command line meets our file-alteration needs, its length well justified when it saves many keystrokes in a file with say, 1000 lines.

Like awk, the sed is included with most Linux distributions and available for most flavors of Unix.
