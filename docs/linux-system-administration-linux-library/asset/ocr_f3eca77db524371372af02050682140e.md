Unfortunately, although hostnames of this form are reasonably easy for people to understand, Therefore, although the Internet includes provisions for hostnames, at its core it relies upon a different addressing scheme: IP addresses. IP addresses are 32-bit numbers that are generally expressed as decimal numbers separated by dots (.), as in 192.168.204.98. IP addresses are broken into two components: a network address and a machine address. This division simplifies the job of routers, which are programmed in terms of networks rather than individual computers. A network mask (mask for short) marks the network address portion of an IP address with 1s. For instance, 255.255.255.0 places a binary 1 in each of the first three bytes of an address, indicating that those three bytes are the network address, and that the final byte is the machine address. An IP network address can be combined with a network mask using a shorthand form in which the number of leading binary 1s in the netmask follows the IP address, as in 192.168.204.02. This is the same as the 192.168.204.0 network with a netmask of 255.255.255.0 (twenty-four 1’s, expressed in binary).

> NOTE In a hostname, the most significant portion (the machine name) is in the leftmost position of address. In an IP address, the most significant portion (the machine address) is in the rightmost position of the address.
