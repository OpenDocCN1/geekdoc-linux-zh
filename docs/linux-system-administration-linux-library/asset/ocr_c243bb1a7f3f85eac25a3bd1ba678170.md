# lpc

The LPR System Control program, or l1pc, provides the capability to disable or enable a print queue, to reorder the print jobs in a queue, and to obtain status about a printer, a queue, or a job. These commands are applicable to any printer in the /etc/printcap file as specified by the associated name or to all printers.

If issued without an argument, the l1pc session will be interactive and a l1pc prompt will be returned. You can also include the l1pc command in a script, using the following format:

```
l1pc [subcommand]
```

The available subcommands are as follows:

+   - **abort** Terminates any printing in progress and disables further printing to the specified printer(s). The queue is left intact so that the waiting jobs will be printed when the start command is next issued. Sometimes, if a printer has stopped printing for no apparent reason, issuing the abort command followed by the command will get things going again.
- **disable** Turns the queue off that it won't accept any more jobs, although the superuser can still print jobs. Printing is not halted, so anything in the queue already or added by the superuser will print. When a printer is to be deactivated, you should issue the disable command followed by the stop command.
- **down** Turns the specified printer queue off, disables printing to the printer, and logs a message to the printer status file. Subsequent attempts to run the l1pc command will indicate that it is down and output the status message.
- **enable** Enables spooling on the specified printer's queue so that it will accept new jobs.
- **exit** Terminates the interactive l1pc session.
