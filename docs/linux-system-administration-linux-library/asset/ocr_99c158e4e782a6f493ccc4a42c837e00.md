# Understanding TCP/IP Networking

Figure 15.1 Information travels “down” and “up” network stacks, being checked and packed at each step of the way.

At each stage in their journey down a network stack, data are checked or encapsulated in additional information. These “wrappings” function much like an envelope around a physical letter, sent via the Post Office; they help the data reach their ultimate destination. Unlike a physical letter, data sent TCP/IP may be split into multiple packets. Rather than send a 2MB file in one chunk, TCP/IP breaks it down into many packets of about 1.5KB each. Part of the encapsulation process ensures the recipient computer is able to reassemble the original file from its individual packets. TCP/IP is fault-tolerant, so it’s possible for the receiving system to request that a specific packet be resent if it doesn’t arrive. Individual packets may travel different routes from source to destination and the system functions properly.
