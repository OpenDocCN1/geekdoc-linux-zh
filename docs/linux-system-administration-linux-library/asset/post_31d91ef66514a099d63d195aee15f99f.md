# Linux System Administration

Authoritative Answers to All Your Questions

You can rely on Linux System Administration for answers about installing, configuring, and administering Linux. Written by two Linux experts, this book teaches you standard and advanced techniques you need to set up maintain a successful Linux environment. Coverage includes:

- Installing a Linux server
- Using new commands and capabilities
- Setting up user and group accounts
- Adding and removing software
- Verifying software using the Red Hat Package Manager
- Sharing files using Samba and NFS
- Implementing a backup strategy
