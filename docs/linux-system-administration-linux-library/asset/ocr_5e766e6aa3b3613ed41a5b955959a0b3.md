# Undeleting Files

It's easy to accidentally delete a file. Part of the purpose of backups is to allow recovery of such files, but if the file hasn't been backed up before its accidental deletion, the backup does no good. Therefore, there are undelete utilities available, and certain windows users use a trash can by default, which doesn't immediately delete files, instead storing them in a temporary limbo before deleting them. The rm command does not actually erase the deleted file from the disk but removes the file's inode or index pointer, leaving the data in place until that node is reused. Because the data still exists, it is possible to retrieve it. We'll mention only one data recovery utility here, although there are several available or under development now.

GtkRecover GtkRecover (see http://www.linuxave.net/~recover/gtkrecover.html) is a nice little program that finds all the residue of deleted files from your drive and dumps those matching to a directory that you specify. Figure 11.8 shows GtkRecover prompting for information about a deleted file.
