# Software
Administration

Most Linux distributions ship with a wide variety of software packages, many of which you can select during system installation and use immediately after installation. On occasion, however, you will find that you need to install and use additional programs, or upgrade packages you've already installed. Depending on which Linux distribution you're using, you may have a choice of several different package formats, which are methods of distributing software in a single file, often including information about which other programs rely upon the glibc package, Most Linux programs rely upon the glibc package, for instance, and packages can specify this dependency.

In addition to the choice of package format, software can be distributed in either binary or source code form. The former is ready-to-run software. The latter consists of the original program code files, which must be compiled into the binary form needed by Linux. Source code packages are more portable than binary packages—you can use the same source package on both x86 and PowerPC computers, for example. You can also modify source code if you know how to program in whatever language the package uses. You must decide which format you want to use for any given program.
