This rule denies all packets that are not from 192.168.0.11:

```
ipchains -A input -s !192.168.0.11 -j DENY
```

This displays a list of the rules for all chains:

```
ipchains -L input
```

Both of the following rules delete the seventh chain, the first by matching the rule number
and the second by matching the rule itself:

```
ipchains -D input 7
```

```
ipchains -D input -s 192.168.1.11 -j DENY
```

Finally, this rule flushes the input chain:

```
ipchains input -F
```

Now perhaps we want to deny FTP to the outside world but allow it on our internal network.
We do this by adding a rule to the input chain that rejects FTP requests that come in
in eth0 except those coming on eth1. To do this, we must run two separate
ipchains commands:

```
ipchains -A input -p tcp eth0 --dport ftp REJECT
ipchains -A input -p tcp -i eth1 --dport ftp -j ACCEPT
```

Once your ipchains file is properly set up, you will need to run it at each bootup.
Red Hat Linux offers the ipchains-save and ipchains-restore binaries for this purpose.
Run ipchains-save redirecting your output to /etc/ipchains.conf in order to save
your rules to the ipchains.conf:

```
ipchains-save > /etc/ipchains.conf
```

Next add the ipchains-restore command to /etc/rc.rc.local so that it will run
automatically at bootup. You could just as easily the ipchains commands that we
stored in /etc/ipchains.conf to /etc/rc.rc.local, but if you expect to make a lot
of changes to the ipchains configuration, the first method is more versatile.
