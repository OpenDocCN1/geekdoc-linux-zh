# WARNING Even if all your users are well-behaved and would never dream of sending spam, your mail server may become a source of spam if it's configured as a relay or if the mail server is broken into.

To learn more about spam prevention than can be covered in this space, check the Mail Abuse Prevention System (MAPS) Web site, http://www.mail-abuse.org. Schwartz and Garinkel's Stopping Spam (O'Reilly, 1998) also provide a good overview of the topic.

# Preventing Outgoing Spam

Your first concern should be to ensure that your server doesn't become a spam source. # Policing Your Own Users

If you operate a small server for a limited number of people, you can probably control outgoing spam by speaking to the users of your system. In an office of half a dozen people, for instance, you can tell everyone not to spam. Perhaps the most difficult aspect of this is conveying to your users precisely what spam is. Spam has many features. Most importantly, it is of the following:

> Unsolicited E-mail readers do not ask for spam. Typically, spammers collect e-mail addresses from postings to Usenet newsgroups or by setting address-collecting "robots" loose on the Web. Some spam comes when willingly leave their e-mail addresses on spammers' Web sites. Some companies seem to think that an action makes OK to send ads to individuals, but unless careful precautions are observed, this is not. If you want to set up an advertising list, be sure your recipients want to be on that list. The MAPS Web site includes pointers to help you avoid inadvertentlyently sending spam. This said, not all unsolicited e-mail is spam. A journalist may legitimately e-mail anybody to ask for an interview, for instance. If e-mail is unsolicited, though, it deserves careful scrutiny to determine whether it's legitimate

Bulk Spam is invariably set in large quantities—to hundreds or thousands of recipients. There are legitimate uses for bulk e-mail (such as mailing lists to which readers subscribe), but if you send e-mail in bulk, you should ensure that the recipients want to be on the mailing list.
