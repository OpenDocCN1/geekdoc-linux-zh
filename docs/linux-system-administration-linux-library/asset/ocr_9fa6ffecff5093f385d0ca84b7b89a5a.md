# Logcheck

Logcheck is part of the Abacus Project being conducted by Psionic Software (http://www.psionic.com/abacus/). It examines the logfiles for possible security problems or violations. It then generates a list of what it considers to be suspicious and e-mails list to the system administrator. It is free for use at any site. Download it at http://www.psionic.com/abacus/logcheck/.

This list of intrusion-detecting applications is not comprehensive. It is generally a good idea to search the Internet for security sites that recommend applications of this type, since new ones are made available quite often. Running one or more of these or other applications empowers you in your attempts to prevent would-be intruders from cracking your system.
