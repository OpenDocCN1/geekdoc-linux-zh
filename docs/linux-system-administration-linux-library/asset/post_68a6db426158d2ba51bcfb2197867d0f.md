# Securing the Authentication Process

The authentication process is a mystery to most of your users. Generally users don't worry about how they are authenticated as long as they gain access to their files. They type their login and password combinations and wait while the magic happens. If they are authenticated, they are content; if the authentication fails, they call you for help. As a system administrator, you need to know how this process works.

First, Linux uses two different systems for authenticating user passwords: DES (the Data Encryption Standard) and MD5 (message digest algorithm, version 5). The DES algorithm with MD5 passwords, the MD5 algorithm can't understand DES passwords. DES passwords are encoded using the Federal Data Encryption Standard algorithm. MD5 uses the RSA Data Security, Inc. message digest algorithm. By default on Linux systems, MD5 is used now. Passwords encrypted with the MD5 hash are longer than those encrypted with the DES hash and also begin with the character $1. A shorter password that does not begin with a $ is typically a DES password.
