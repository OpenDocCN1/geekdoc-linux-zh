NOTE Dumb terminals are text-only devices; they cannot be used to run X-
based programs as StarOffice or the GIMP. There is, however, another vari-
et of terminal that can be used with X programs: an X terminal. X terminals mini-
interface through a network port, not a serial port. The NCD X Terminal mini-
HTO document (http://www.linuxdoc.org/HOWTO/m11/NCD-
Terminal.html) provides information on these devices.

Because of Linux's heritage, Linux includes the software necessary to support dumb
terminals; using it is a matter of changing a few default configurations. Once this is done,
y can plug in a dumb terminal and use it. Why would you want to do this? For the reason
s large organizations used (and still use) dumb terminals, such as stretching
resources and providing access to a computer to more people than would work otherwise
before. If you do not need to run X programs, a dumb terminal can provide perfectly ade-\quate access to a Linux computer.

Instead of a dumb terminal, you can use an outmoded computer. For this, for instance, you can wipe it off, set it up, link it to
a Linux computer, and use a simple DOS terminal program to make it work like a dumb
terminal. Similarly, specialized devices like palmtop computers often come with terminal
programs, so you can access a Linux computer from them.

TIP On rare occasion, X can lock up, leaving Linux unresponsive. Technically,
Linux has crashed, and it is usually possible to recover from such problems—
 you have some way in other then the system's keyboard. Such a way in is often
remote access through Telnet, but this isn't always an option. Using dumb term-
al access, from a palmtop computer, can let you link or reconfigure X, thus
recovering control of the system without using the Reset switch.

When you use another computer as a terminal, you must normally link the two computers
through a null modem cable. These cables link one computer to another, and they're
wired differently than the cables that link a computer to a modem. Most computer
sell null cables.
