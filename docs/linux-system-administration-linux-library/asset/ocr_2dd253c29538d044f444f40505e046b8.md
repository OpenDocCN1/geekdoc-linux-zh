You can see that this display contains a great deal of useful information. Looking at the init PID and PGID fields, you can follow the parent/child lineage. For example, the init process started several processes: kflush, kupdate, kpiod, kswapd, portmap, syslog, klogd, crond, inet, login, and several mingetty processes. We know this by looking at the PPID field, since process 1 is the init process. If you look at the login process 764 and then at the bash process 788, you can detect that the process is forked off the login process. Since bash is the login shell, which is started upon login, this makes sense. The su process that process 810 is being run under that bash, since the PPID is the PID of the bash process.

Looking at the parent group ID (PGID), we can see that kflush, kupdate, kpiod, and kswapd all belong to the bin group.
