# Chapter 10 Filesystems and Disk Management

XFS XFS is Silicon Graphics's (SGI's) journaling filesystem. It's used on SGI Unix workstations and servers (which run the IRIX OS), and the company has ported it to Linux and released it the GPL. This filesystem supports maximum filesystem sizes up to 16,384 petabytes (PBs; 1PB is 1024TB), and maximum file sizes of up to 8,192 PB. As such, XFS is the currently available filesystem that supports the largest media for Linux. This filesystem's type code is xfs. You can learn more at http://oss.sgi.com/projects/xfs/

JFS IBM's Journaled Filesystem (JFS) was originally developed for the AIX OS; however, IBM (like SGI) has released its advanced filesystem under the GPL and is actively supporting its porting to Linux. In addition to, JFS supports a maximum filesystem size of 32 PB and a maximum file size of 4 PB. Use the JFS filesystem type code when mounting JFS partitions. More information is available at http://software.ibm.com/developerworks/opensource/jfs/

Filesystems are sometimes classified according to the size of the points they use. Ext2, ext3fs, and ReiserFS are all 32-bit filesystems. This fact, in combination with other design features, is why these filesystems have the maximum partition sizes. XFS and JFS, by contrast, are both 64-bit filesystems, which is why their maximum partition sizes are so large. (XFS and JFS differ in other details, hence the difference in their maximum sizes.)

All of these filesystems offer substantial improvement over ext2 in the journaling feature after a system crash or power outage. Increased partition and file sizes in XFS and JFS are also a great boon. XFS, JFS, and ReiserFS all support dynamic partitioning, although the code to support it is not entirely stable and complete at this writing. You should check the status of this feature if it's important to you.

In 2001, all of these filesystems are usable, but none is yet completely reliable. ReiserFS is closest to this, but its lead may slip you by the time you need it. If you have large hard disks and cannot cope with long disk checks at startup, you should study each of the filesystem discussed in this writing to determine which is most stable. You may want to check recent Usenet discussions by performing a search at http://www.deja.com/usenet/

Although none of the journaling filesystems is a standard part of the kernel, some distributions ship with support for ReiserFS. Specifically, Mandrake 7 and SuSE 6.4 include ReiserFS support. Future versions of these and other distributions may add support for journaling filesystems. You can also patch your kernel to support any of these filesystems.
