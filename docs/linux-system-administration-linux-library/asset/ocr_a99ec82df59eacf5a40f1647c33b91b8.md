NOTE The user who makes a connection must have permission to both read and write the modem's device file. Red Hat Linux's startup scripts change the ownership of the /dev/ttyS device whenever anyone logs onto the console, so the console always has access to the modem, if it's an RS-232 serial device. Other distributions use a special group for these files, along with 664 or 660 permissions, all members of that group can access the modem. You can add any users who should have modem access to the group. Use the -l command on the modem device for your system to find out how it's configured, and any necessary changes to the device's permissions or your group configuration.

+   - When you run the program, you may need to adjust the serial port's parameters—most importantly, the port speed. In Seyon, you can do this by clicking Set, Baud, and then the button corresponding to your desired speed. When using a modem-56Kbps modem, a port speed of 115Kbps is appropriate.
 To dial a number, use ATDT followed by the number, such as ATDT55-1234 to dial 555-1234. AT is the standard modem code for attention, and signals the modem that you're about to give a command. D stands for dial, and T refers to touch-tone dialing.(If your phone system doesn't support touch-tone dialing, use ADTP to dial using rotary pulses)
 If you dial a number on a regular basis, you can add it to a dialing directory. In Sey, you can preconfigure numbers by clicking the Dial button. You can add these entries by clicking Edit in the Directory window, which produces a simple text editor showing the configuration file. You can dial a number by selecting it in the Dial Directory window and clicking Go. This action sends the appropriate AT command to dial the modem.

+   - When you're done using the program, hang up the modem by logging out of the remote system, turning off the modem, or picking an appropriate option in the program, such as the Hangup button in Seyon's Center window.

Seyon stores configuration information in the /.seyon directory, every user may have customized settings. minirc requires that you run it with the -s parameter to create a configuration file called /etc/minirc.df, after which a user can create a custom configuration called ~/.minirc.df by changing the defaults established by root.
