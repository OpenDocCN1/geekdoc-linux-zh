# Chapter 10 Filesystems and Disk Management

| /dev/hdb2 | 1 | 192 | 1542208+ | fb | Unknown |
| /dev/hdb3 | 193 | 256 | 514080 | 17 | Hidden HPFS/NTFS |
| /dev/hdb5 | 257 | 516 | 2088418+ | 6 | FAT16 |
| /dev/hdb6 | 517 | 717 | 1614501 | 7 | HPFS/NTFS |

Command (m for help): n

Command action

+   1 logical (s or over)
p primary partition (1-4)
1 extended

First cylinder (718-1216, default 718): 718

Last cylinder +size or +sizeM +sizeK (718-1216, default 1216): +400M

In this situation, the initial configuration included five partitions, and the n command added a new one. disk gives the option of creating a logical or primary partition. The x86 partitioning scheme originally provided for only four partitions per disk, which soon became inadequate. The workaround was to use one of the original four primary partitions as a placeholder for a potentially large number of logical partitions. The "placeholder" primary partition is then referred to as an extended partition. In Linux, the primary partitions use numbers from 1 to 4; the logical partitions are numbered 5 and up. Linux doesn't care whether its partitions are primary or logical, so we recommend using exclusively logical partitions for Linux. This reserves primary partitions for OSs that need them, such as DOS, Windows, and FreeBSD.

Linux's disk lets specify partition sizes either in terms of an cylinder number or in bytes, kilobytes, megabytes. The preceding example specified a 400MB partition starting at cylinder 718.

> For the final partition on a disk, enter the size by specifying an cylinder number that corresponds to the maximum available. This practice minimizes amount of unused disk space.

By default, disk creates partitions using the type code 0x83 (Linux native). Such partitions are suitable for hosting Linux's ext2fs or any of the journaling filesystems available
