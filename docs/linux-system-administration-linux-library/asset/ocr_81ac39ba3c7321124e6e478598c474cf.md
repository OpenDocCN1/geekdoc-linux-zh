Kudzu runs automatically each time you boot the computer, or you can run it anytime thereafter. It provides for hardware and checks the current configuration to see if any hardware is new. If hardware has been added or removed, it queries the user to add or remove the necessary drivers or wait until a later time. If the update is deferred, Kudzu will present the same question whenever it runs. Since any attempt to remove server devices like consoles would negatively impact the system, Kudzu does not check serial devices except when from the installation.

The Versions of Red Hat Linux from 6.0 have made more extensive use of kernel modules did previous versions. Kernel modules are drivers for hardware, file-systems, and so on, which can be compiled separately from the main kernel file. Under Linux, kernel modules can be loaded and unloaded at any time after the main kernel has loaded, provided that the necessary hardware exists (when unloading a module, the hardware must not be in use). As a result of the increased modularization of recent versions of Red Hat, the system adapts itself to your computer at install, time, loading more drivers you're likely to need and fewer drivers you don't need.
