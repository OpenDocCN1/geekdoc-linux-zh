# Disaster Recovery Techniques

Backing your system regularly and methodically goes a long way toward protecting it, but there are still situations that call for something different. If you forget to run LILO or can't boot the kernel you just made, you don't need to reinstall, but you do need some sort of disaster recovery. Disaster recovery methods allow you to log onto your system, so that you can fix it or retrieve important files before damaged equipment takes the system down. There are several methods to choose from, depending on the problem and what you need to do to repair it. Among these are booting in single-user mode, from an emergency boot disk, and in rescue mode.

# Single-User Mode

Single-user mode boots your kernel to run level 1. The local filesystems are mounted as usual, with your system's initialization scripts are run, but there is no network access. You are placed in a system maintenance shell where root may use the console but no else is allowed to log in all. If your system boots but not allow you to log in when it has completed booting, try rebooting and entering `1ux single` at the LILO boot prompt:

```
LILO boot: 1ux single
```

Since this method uses the ailing system's own initialization scripts, any error in these scripts may be a problem; no daemons run in this mode, however problems caused by a daemon's failure to start will likely be fixable in this mode. Single-user mode also uses the system's own kernel, if the kernel is causing a panic, then this won't help. If a filesystem has problems, single-user mode will attempt to mount it as usual and will probably fail at that point.

Single-user mode is great for getting into a system when you've forgotten to do so after creating a new root password, or to fix some kernel image, and to fix other problems that don't prevent the system from reaching single-user mode. You can take advantage of the fact that no else can log in to perform functions like installing software, making backups (if the system can stay in single-user mode for a long time without disruption), and doing other standard maintenance functions that benefit from root solitude.
