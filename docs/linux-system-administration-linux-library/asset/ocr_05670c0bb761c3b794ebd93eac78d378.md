You might create a script like Listing 14.5 to determine which employees remain to be trained. (This script uses the cut command, discussed later in this chapter.)

# Listing 14.5 A Script for Updating the Training File

```
#!/bin/bash

#remove the old tobetrained file if one exists
if [ -e /home/$USER/tobetrained ]; then
    rm /home/$USER/tobetrained
fi

cat /etc/training_list |
while read line

    training=`echo $line|cut -d""|* -f4'
    if [ $training = C ]; then
        name=`echo $line|cut -d""|* -f1'
        echo $name >> /home/$USER/tobetrained
    fi
done
```
