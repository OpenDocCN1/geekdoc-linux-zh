Samba is usually run from startup scripts in the /etc/rc.d directory tree. If they're already present, you should create appropriate links in the /etc/rc.d/rc3.d and /etc/rc.d/rc5.d directories. On a Red Hat system, the following command should work, but you may need to adjust these pathnames and filenames on other distributions:

+   # In ln -s /etc/rc.d/init.d/smbd /etc/rc.d/rc[35].d/S35smbd

You'll need to start Samba manually if you just set it up this way, or restart it after you make changes to its configuration. You can do this by typing /etc/rc.d/init.d/smb start or /etc/rc.d/init.d/smb restart, respectively.

# Setting Global Options

Samba includes many global options (those that appear in the [global] section of smb.conf). Some of the most important of these are shown here:

```
[global]
workgroup = ARBORETUM
netbios name = GINGKO
server string = Big Server
encrypt passwords = Yes
os level = 1
```
