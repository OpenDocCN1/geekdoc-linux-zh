NOTE A common misconception is that FAT-32 and VFAT are somehow linked. They aren't. You can access a FAT-16 or even FAT-12 disk using VFAT long filenames; and you can mount a FAT-32 partition with the Linux msdos driver to use only 8.3 filenames. (Windows 98 run in DOS mode also provides only 8.3-filename access to FAT partitions, as well.)

UMSDOS is unusual because it allows Linux to treat a FAT partition like a native system. You can run a Linux system entirely from a UMSOS partition, and in fact some distributions support installing Linux directly on a UMSOS partition. This configuration tends to be slow, however, because Linux's FAT support, although stable, isn't as fast as its support for ext2fs.
