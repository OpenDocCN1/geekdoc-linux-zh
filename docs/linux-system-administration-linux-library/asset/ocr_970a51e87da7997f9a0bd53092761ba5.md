By default, shadow passwords are enabled at installation. You can use the authconfig command to go between shadowed and unshadowed mode after installation. authconfig is a text-based utility that allows you to enable or disable shadow passwords and MD5.

If you use authconfig to disable shadow passwords, any entries in the /etc/passwd that do not have corresponding /etc/shadow entries will be removed and the entries will transfer their password hashes to the /etc/passwd file. Keep in mind that the password aging information stored in /etc/shadow will be lost in transaction.

If you enable shadow passwords using authconfig, it will transfer the hashes from the /etc/passwd file to the /etc/shadow file, replacing each hash in /etc/passwd with an X. This can be accomplished using authconfig by the pwconv command, which converts to shadow passwords by moving the hashes from /etc/passwd file to /etc/shadow. Use pwconv to go to the other direction.

For any additional information, read the Shadow-Password-HOWTO available at http://tucows.com/otherhowto/Shadow-Password-HOWTO.

# Pluggable Authentication Modules (PAM)

At first, most privileges were granted based on password authentication or membership in a specific group. That was not a bad beginning. However, that it was insufficient to assume that a user's identity is known simply because the login password is correct and rely on authentication as the sole means of determining what access should be granted. New programs began their own authentication methods instead of assuming that the login authentication was sufficient. Each of these required the login, FTP, and other programs to be rewritten to support the new method.
