
# Listing 5.1 A Sample lilo.conf File

```conf
#Global Section
boot=/dev/hda
map=/boot/map
install=/boot/boot.b
compact
prompt
timeout=50
message=/boot/message
linear
default=linux
append="aha152x=0x140,12,7,0,0 sb=240,5,1,5,300"
```

```conf
#Per-Image Section
image=/boot/vmlinux-2.2.16-22-1
label=linux
read-only
root=/dev/hdb1
```

```conf
image=/boot/vmlinux-2.2.16-22-1
label=debian
read-only
root=/dev/hdc1
initrd=/boot/initrd-2.2.16-22-1.img
```

```conf
image=/boot/vmlinux-2.2.16-22
label=orig
read-only
root=/dev/hdb1
other=/dev/hda1
label=msdos
```

## The Global Section

The first section of the /etc/lilo.conf file applies globally to any kernels that are to be booted from LILO. The first line in the global section shows that LILO is to be installed in the MBR on the first disk, /dev/hda. If LILO were to be the second boot loader, this reference would be to the Linux boot partition, writing LILO here.

The system map in use is /boot/map. This file is a symbolic link to the system map for a kernel that you have created. It is basically made up of debugging information for that kernel. Even Linux system administrators don't usually use this file unless they are doing kernel work.

The next line identifies the boot loader code proper. Typically this is /boot/b. This file contains the code that will reside in LILO's space in the boot sector and the extra LILO relies upon to complete the boot process.

Adding the compact parameter allows LILO to read the hard drive more quickly by transferring sectors at once instead of doing single-sector reads. It works on most modern systems but might cause an other system hang. If so, remove the line.

LILO's default behavior is to wait 4 seconds for you to press the Shift key and boot the default kernel if you do not. The prompt instruction tells LILO to instead prompt the user for which image to boot. This is what causes the lilo: that you have probably seen.

The timeout parameter in the next line sets the time (in tens of a second) to wait for keyboard input. After this period, the default kernel is automatically booted. If you enter the timeout parameter without a numeric value, the timeout period is infinite. During the timeout period, pressing Tab displays a list of available images.

The next line identifies a file containing a message to display before the boot prompt. The message file is limited to 65,535 bytes. Changing or removing the message file requires you to rebuild the file.

If the linear parameter is included, it forces the generation of linear sector addresses instead of the sector/head/cylinder addresses that are used by default. This is necessary if you've configured your BIOS to use any drives in Linear Block Addressing (LBA) mode.

The default parameter sets the default kernel to be booted if no other image label has been given. If no default parameter exists, LILO treats the first kernel specified as the default.

## LILO: Definition and Configuration

The append line is particularly important. Any parameters that the kernel needs in order to boot correctly can be appended. Typically this line is used to specify parameters for hardware that isn't automatically detected, as in this example. The append line in Listing 5.1 gives the information for an Adaptec 1520B SCSI interface card and a Sound-Blaster sound card. Notice that there is no comma between the two append strings, each one commas. Likewise, there are no spaces in each individual append string since the list of strings is space-delimited. The format for these items varies depending upon the item type. Information about hard drives is commonly appended and is specified as follows:

```
append="cccc,hhhh,ssss"
```

linear where cccc indicates the number of cylinders the drive has, hhhh indicates the number of heads, and ssss indicates the number of sectors. To include information on two different drives, use two representations as follows:

```
append="hd=cccc,hhhh,ssss=cccc,HHHH,SSSS"
```

linear When run on some motherboards, Linux doesn't detect memory above 64MB, or sometimes even 16MB. If you have more memory than this, you can use an append line to see if LILO has detected it. If it hasn't, you may use an append line to know about the additional memory. You can also use this option to test how the system would run with less memory, by indicating less memory than you actually have. The amount of memory can be specified in kilobytes (with a suffix of k) or in megabytes (using a suffix of M). To specify an amount of memory, use the following append line:

```
append="mem=128M"
```

If you happen to be running a Linux system with two Ethernet cards, you might have to append a line that contains the information for the two cards as in this example:

```
ether=9,f600,eth0 ether=10,6800,eth1
```

## The Per-Image Section

Each section follows the global section and defines a specific kernel. Each section starts with an image line, which specifies the path to the kernel image. The label line identifies the name to be used at the LILO prompt. The root line specifies the location of the root. If read-only is included, the root will be mounted read-only. If the initrd line is included, it specifies the location of the initial RAM disk.
