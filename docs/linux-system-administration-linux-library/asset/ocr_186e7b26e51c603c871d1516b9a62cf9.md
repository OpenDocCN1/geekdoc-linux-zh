# Selecting Package Groups

Finally, the moment you've waited for: the Selecting Package Groups screen allows you to select which software packages will be installed on your system, selecting them in pre-set server groups or individually. The only server group that is selected by default for the server class installation is the Web server. You can also choose to install a news server, an NFS server, or a DNS name server.
