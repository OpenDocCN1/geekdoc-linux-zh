# Virtual Consoles

Chapter 10 described the use of virtual consoles for text-mode logins. If you use a text-mode login, you can hit Alt+F1 through Alt+F6 to switch between different screens, each of which can display a different login session. You can therefore use one to log in with your normal username, another to log in as root; and log in multiple times as one user and switch easily between different programs. If you are running X, you can switch to a virtual text-mode console by pressing Ctrl+Fn, where n is the console number.

Virtual consoles are not restricted to text-mode logins. When X runs, by default, it takes over an unused virtual console (typically console 7). You can therefore switch back to X from a text-mode console by pressing Alt+F7 (if X is running). Of potentially greater interest, it's possible to run multiple X sessions, each in its own console. You can switch between them by pressing Ctrl+Alt+Fn, where n is a number from 7 up. To launch a second X session, follow these steps:

+   1. If you're already running X, press Ctrl+Alt+F1 to go to a text-mode login: prompt. Log in.

+   2. Type startx :1 vt8 to start X on virtual terminal 8. You should see X up.

+   3. Press Ctrl+Alt+F7 to switch back to your original X session or Ctrl+Alt+F8 to switch to the new one.

Why would you want to start a new X session? After all, window managers support multiple workspaces, so you can easily keep lost of windows on different screens. You can use su within an xterm to launch programs as different users. Using multiple X sessions have certain advantages, however:

+   You can run different window managers in different sessions. This isn't ordinarily a compelling reason to run multiple sessions, but it can be useful if you want to evaluate a window manager or if you need to use one for some programs and prefer another over other programs.

+   You can start X in different resolutions. Your normal setup might be 1280x1024 resolution, but if you need to test software at 800x600, you can run a separate 800x600 session. You can use the -bpp (for XFree86 3.x) or -depth (for XFree86 4.0) parameter to startx, along with an appropriate XF8Config setting (as described above), force X to start at a given resolution when you start at a given bit depth. For example, the following command starts XFree86 40 at 32-bit color depth, which you can associate with a specific resolution:

```
startx :1 -depth 32
```
