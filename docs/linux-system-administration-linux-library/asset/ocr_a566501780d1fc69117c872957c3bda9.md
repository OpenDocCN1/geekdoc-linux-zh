You can see that the output ps -e gives you basic information about all the running processes. The output includes the PID, the tty, the time, and the command. This is quite sufficient when you are trying to obtain the PID of a process to kill it or restart.

The output from ps -au, as shown in Listing 3.7, displays information in a user-oriented format (u) that includes all processes on this terminal, including those of other users.

# Listing 3.7 Output from the ps -au Command

```
user 4331 0 0.6 2532 884 R 21:32 0:00 ps
```
