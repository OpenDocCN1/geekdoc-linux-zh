# Setting the Window Manager

Window manager preference is a very personal matter. If you permit us, you can try several different window managers to see which you prefer. Linux distributions use a configuration script in the user's home directory to run programs the user wants to run at login time. If this file is absent, the system uses a default script. This script varies with your login preferences, but it's usually located in the /etc/X11 directory tree, open in /etc/X11/init. On Red Hat 7.0, the user-customizable configuration script is called .xession, and it must execute permissions. Distributions may call this script other things, such as .xlogin. When launching X from a text-mode login via startup, another script is commonly used: .xinitrc. To replace the default set of login actions with another, follow these steps:

+   1. Load the .xession file from your home directory to a text editor (on a fresh account, this file won't exist, so you may need to tell your editor to create it).
