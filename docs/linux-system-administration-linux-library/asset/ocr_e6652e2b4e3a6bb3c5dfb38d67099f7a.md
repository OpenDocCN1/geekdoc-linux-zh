# Using the cron Facility

The cron daemon makes it very easy to set up a recurring event based on the need to run it at a given time, day, or date. cron searches /var/spool/cron for crontab files, which are named after existing user accounts; any crontabs that are found loaded into memory. The daemon also searches for /etc/crontab and the files in the /etc/cron.d/ directory.

In this system, /etc/crontab contains entries that run files in /etc/cron.hourly on an hourly basis, files in /etc/cron.daily on a daily basis, files in /etc/cron.weekly once a week, and files in /etc/cron.monthly once a month. Listing 14.12 shows the default /etc/crontab file for Red Hat 7.0.

Listing 14.12 The Default Red Hat 7.0 /etc/crontab

```
SHELL=/bin/bash
PATH=/sbin:/bin:/usr/bin:/usr/bin
MAILTO=root
HOME=/
```
