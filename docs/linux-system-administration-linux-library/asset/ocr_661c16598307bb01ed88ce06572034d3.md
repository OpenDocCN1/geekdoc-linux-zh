# Linux System Administration

Authoritative Answers to All Your Linux Questions

You can rely on Linux System Administration for answers to all your questions about installing, configuring, and administering Linux. Written by two Linux experts, this book teaches you,-by-step, all the standard and advanced techniques you need to set up and maintain a successful Linux environment. Scores of clear, consistent examples illustrate these techniques in detail—you stay on track and accomplish all your goals. Coverage includes:

+   - Installing a Linux server
- Using new commands and capabilities
- Setting up maintaining user and group accounts
- Adding and removing software
- Verifying software using the Red Hat Package Manager
- Sharing files using Samba and NFS
- Implementing a backup strategy
- Setting up a dial-up connection using PPP
- Troubleshooting common Linux problems
- Setting up the X System
- Setting up TCP/IP and connecting to the Internet
- Setting up a mail server

+   - Install and Configure Linux without a Hitch

+   - Take Advantage of the Power and Stability of Linux

+   - Keep Your System Healthy Using Sound Maintenance Techniques

+   - Implement a Backup Strategy and Recover Lost Data
