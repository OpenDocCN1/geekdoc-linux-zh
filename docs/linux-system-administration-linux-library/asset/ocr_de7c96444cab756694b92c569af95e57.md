# Minimal Acceptable Hardware

One of the best-known facts about Linux is that it can make use of old computer parts that you have stored somewhere. A high school student has salvaged an old 80386 machine and turned it into a decent print or mail server. Originally, Linux was designed to install on an 80386 with as little as 4MB of memory, but with the rapid changes in processor speed and size, designing anything became unnecessary. Red Hat recommends at least 16MB of memory and 500MB of hard drive space for its 7.0 release. Other distributions have slightly different recommended requirements, but these do not reflect differences in the needs of identically configured systems; rather, they reflect default installations and usage assumptions.

# CPU Performance

One of the most important elements in determining a computer's performance is the Central Processing Unit (CPU). A new CPU seems to hit the market almost weekly. In the Intel-compatible x86 market, there are basically four players: Intel, Advanced Micro Devices, Inc. (AMD), VIA (which bought Cyrix in 1999), and startup Transmeta. New faces are appearing in the microprocessor technology market, but many target architectures other than the x86. Linux is known to run on all of these listed here:

+   * Intel/AMD/Cyrix 386SX/DX/SL/DLC/SLC
* Intel/AMD/Cyrix 486SX/DX/SL/SX2/DX2
* IDT WinChip
* NexGen NX586
* Cyrix 686, 686MX, and M-II
* VIA Cyrix III
