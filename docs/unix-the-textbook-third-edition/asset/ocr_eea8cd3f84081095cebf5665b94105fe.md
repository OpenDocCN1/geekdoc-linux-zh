# 17.7.1.4 Listing Program Code

You can use the list command to display all or part of a source program. By default, it displays 10 lines around the line (or function) that you specify as its argument. You can display lines of code in a particular function or on a range of lines. In the following example, the list get_input command is used to display 10 lines in the code around the get_input function, and the list 14,27 command is used to display the source program at lines 14–27. Note that the list get_input command displays five lines before the start of the function code and five lines after it. In order to display the first 10 lines of the function code, we use the list get_function, command. Since get_function has less than 10 lines, a few extra lines after the function are also displayed. Use the help list command to get more information about the list command.
