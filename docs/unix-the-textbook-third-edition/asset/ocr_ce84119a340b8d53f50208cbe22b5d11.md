# 20.4.2.2 One-Way Communication

The pipe_talk.c program creates a pipe and spawns a child process. The child process, among other things, as discussed in Chapter 19, inherits the parent's PFDT. The child process closes the write end of the pipe and reads data from the read end of the pipe. The child process blocks if there is nothing in the pipe. The parent process, on the other hand, closes the read end of the pipe and writes data to the child process using the write end of the pipe. The child process displays on the screen whatever it reads from the pipe. Figure 20.4 shows the setup for the program in a pictorial form.
