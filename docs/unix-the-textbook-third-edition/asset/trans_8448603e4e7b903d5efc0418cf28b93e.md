- 20. 在X窗口系统中，编程客户端应用程序的主要任务和最大挑战，是将生成数据或本身就是数据的代码输出（如数字、文本字符串、文件、文件结构等）连接到由本章展示的其中一个工具包实现的用户UI。当然，如果客户端应用程序的UI唯一目标是产生输出图形，那么建议将客户端应用程序划分为数据生成部分（如果有）和图形生成部分。当每个部分的代码需要修改、将来维护，或需要被其他开发者或团队开发成员记录和理解时，将这两个部分分离开是有帮助且有用的，并且这两个独立部分之间的连接必须保持不变。

检查我们为Xlib、XCB和Qt提供的所有程序示例，并简要列出每个程序中数据的生成位置，以便每个工具包都能据此生成图形。还要描述数据是如何传递给使用该数据的工具包的，是以字面量参数还是数据结构机制的形式传递。

例如，由于Xlib主要使用过程式范式将数据生成组件传递给UI组件，因此在你的答案表格中，针对程序示例Xlib test1.c的条目应该如下所示：

``` 
Xlib test1.c  XFillRectangle(...,20,20,10,10),  Integers, string
XDrawString(...,msg,...)
```

## UNIX 系统管理基础

### 目标

- 为了演示从ISO创建的DVD介质上，使用GUI安装程序，在带有KDE4（PC-BSD）或GNOME（Solaris）GUI桌面的单个硬盘系统上进行64位X86架构版本全新安装的最有效方法。
- 为了提出系统构建的设计理念。
- 为了描述如何优雅地关闭系统。
- 为了演示如何向系统添加其他用户和组。
- 为了展示如何设计和维护用户账户。
- 为了展示安装后的硬件，例如磁盘驱动器。
- 为了提供对系统文件和用户文件的备份与归档策略。
- 为了展示如何升级和维护操作系统软件。
- 为了展示如何添加/更新/删除用户应用程序包仓库软件。
- 为了展示如何监控系统性能，特别是使用系统日志文件。
- 为了提供系统安全策略，特别是ACL和系统防火墙。
- 为了涵盖命令和原语（显示PC-BSD；Solaris仅在括号中）。

``` 
adduser, appcafe, beadm, cpio, (dispadmin), dmesg, dump, (format), getfacl, gpart, gparted, (groupadd), (groupdel), gtar, ifconfig, (ipadm), ipfw, netstat, (ndd), pf, pc-fwmanager, pc-systemupdateratry, pc-updategui,
```
