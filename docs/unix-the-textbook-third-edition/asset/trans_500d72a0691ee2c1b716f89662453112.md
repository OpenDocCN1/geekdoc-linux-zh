

## 表 3.17 vi、vim、gvim 汇总

| Vi 语法 | | |
|---|---|---|
| 命令 | 操作 | |
| cw | 更改单词。 | |
| cc | 更改整行。 | |
| c$ | 更改从当前光标位置到行尾的文本。 | |
| C | 与 c$ 相同。 | |
| dd | 删除当前行。 | |
| 7 dd | 删除七行。 | |
| d$ | 删除从当前光标位置到行尾的文本。 | |
| D | 与 d$ 相同。 | |
| 5dw | 删除五个单词。 | |
| d7,14 | 删除缓冲区中第七至第十四行。 | |
| s | 替换字符。按 <Esc> 结束替换模式。 | |
| 4s | 替换四个字符。按 <Esc> 结束替换模式。 | |
| S | 替换整行。按 <Esc> 结束替换模式。 | |
| u | 撤销最后一次更改。 | |
| <Ctrl+R> | 重做最后一次更改（vim 和 gvim）。 | |
| U | 如果尚未离开当前行，则恢复该行。 | |
| x | 删除当前光标位置的字符。 | |
| X | 向后删除一个字符。 | |
| 5X | 删除前五个字符。 | |
| . | 重复上一次更改。 | |
| ~ | 切换大小写并将光标右移。 | |
| <Ctrl+A> | 将光标处的数字加一（vim 和 gvim）。 | |
| <Ctrl+X> | 将光标处的数字减一（vim 和 gvim）。 | |

### Vi 模式键

| 键 | 操作 | |
|---|---|---|
| a | 在当前光标所在字符之后追加文本。 | |
| A | 在当前行最后一个字符之后追加文本。 | |
| c | 开始更改操作，允许你修改文本。 | |
| C | 更改从光标位置到当前行行尾的内容。 | |
| i | 在当前光标所在字符之前插入文本。 | |
| I | 在当前行行首插入文本。 | |
| o | 在当前行下方打开一个空白行，并将光标置于该行。 | |
| O | 在当前行上方打开一个空白行，并将光标置于该行。 | |

### Vi 命令模式

| 命令 | 操作 | |
|---|---|---|
| :wq | 保存缓冲区并退出。 | |
| :w | 保存当前缓冲区并停留在编辑器中。 | |
| :w filename | 将当前缓冲区保存到 filename。 | |
| :q | 退出 vi（如果已有修改则失败）。 | |
| :q! | 不保存缓冲区直接退出 vi。 | |
| :Q | 退出 vi 并调用 ex。 | |
| :vi | 在 Q 命令后返回 vi。 | |
| ZZ | 退出 vi，仅当自上次保存后有修改时才保存文件。 | |

## 表 3.17（续） vi、vim、gvim 汇总

### Vi 光标移动命令

| Vi 光标移动命令 | 操作 |
|---|---|
| 1G | 将光标移动到文件的第一行。 |
| G | 将光标移动到文件的最后一行。 |
| 0（零） | 将光标移动到当前行的第一个字符。 |
| <Ctrl+G> | 以行号和列号的形式报告光标位置。 |
| $ | 将光标移动到当前行的最后一个字符。 |
| w | 每次将光标向前移动一个单词。 |
| b | 每次将光标向后移动一个单词。 |
| x | 删除光标位置的字符。 |
| dd | 删除当前光标所在行。 |
| u | 撤销最近的更改。 |
| r | 用接下来输入的内容替换当前光标位置的字符。 |

### Vi 复制和放置命令语法

| Vi 复制和放置命令语法 | 作用 |
|---|---|
| y2w | 从当前光标位置开始向右复制两个单词。 |
| 4yb | 从当前光标位置开始向左复制四个单词。 |
| yy 或 Y | 复制当前行。 |
| p | 将复制的文本放置在当前光标位置之后。 |
| P | 将复制的文本放置在当前光标位置之前。 |

### Vi 替换命令语法

| Vi 替换命令语法 | 作用 |
|---|---|
| :s/john/jane/ | 将当前行中的单词 john 替换为 jane，仅一次。 |
| :s/john/jane/g | 将当前行中的每个单词 john 都替换为 jane。 |

### 最后一行模式语法

| 最后一行模式语法 | 作用 |
|---|---|
| abbr 命令 | |
| :ab in out | 在插入模式下，用 in 作为 out 的缩写。 |
| :unab in | 移除 in 的缩写。 |
| :ab | 列出所有缩写。 |
| map!、map 命令 | |
| :map | 列出已映射的字符串。 |
| :map! string sequence | 将字符串 string 映射到输入模式序列。 |
| :unmap! string | 移除输入模式映射（可能需要用 <Ctrl+V> 引用这些字符）。 |
| :map! | 列出为输入模式映射的字符串。 |

### set 命令

| set 命令 | |
|---|---|
| :set x | 启用布尔选项 x，显示其他选项的值。 |
| :set | 显示已更改的选项。 |
| :set all | 显示所有选项。 |
| :set x? | 显示选项 x 的值。 |
