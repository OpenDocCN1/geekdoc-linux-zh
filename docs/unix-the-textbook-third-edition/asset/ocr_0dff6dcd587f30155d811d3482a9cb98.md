Label widget:

```
from Tkinter import *
def label():
    master = Tk()
    w = Label(master, text="Label")
    w.pack()
    mainloop()
label()
```

# Example 16.34

Button widget:

```
from Tkinter import *
import sys
def quit():
    print "Out of Here"
    sys.exit()
def button():
    master = Tk()
    b = Button(master, text="Button", command=quit)
    b.pack()
    mainloop()
button()
```
