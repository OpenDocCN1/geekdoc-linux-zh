A server may offer a service using both stream (SOCK__STREAM) and datagram (SOCK__DGRAM) styles of communication. Similarly, a server may offer multiple services. Such a server is known as a multiservice server. Lastly, a multiservice server may offer all of the services that it offers using the stream and datagram styles of communication.
