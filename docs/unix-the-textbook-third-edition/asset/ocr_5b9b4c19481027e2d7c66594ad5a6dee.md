The git add command is used to stage new files. It can also be used to stage modified files. In order to demonstrate, use a text editor to modify the previously created C source code files first.c, second.c, and third.c. Then take a look at the status of the repository. Git lists the tracked files as being modified.

Then take a look at the status of the repository. Git lists the tracked files as being modified.
