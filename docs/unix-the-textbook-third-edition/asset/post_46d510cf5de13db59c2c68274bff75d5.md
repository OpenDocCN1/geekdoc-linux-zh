This chapter provided a common user of PC-BSD or Solaris with the basic techniques of working with the Zettabyte File System (ZFS).

We first went over some basic terms used in ZFS and then described what ZFS is from the user perspective. What differentiates ZFS from other file systems is that ZFS file systems are mapped onto disk storage facilities, like zpools, rather than onto physical storage media known as pool drives.
