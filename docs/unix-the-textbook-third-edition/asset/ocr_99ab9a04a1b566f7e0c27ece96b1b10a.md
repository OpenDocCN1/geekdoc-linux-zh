+   2. Deploy package.
+   
+      ```
+      # iocage import UUID tag=myjail
+      ```
+   
+   3. List the jail.
+   
+      ```
+      # iocage list|grep myjail, grab UUID
+      ```
+   
+   4. Start the jail.
+   
+      ```
+      # iocage start UUID | TAG
+      ```
+   
+   5. Examine your changes and packages.
