tail命令用于显示一个或多个文件的末尾部分（尾部）。例如，它有助于确认PostScript文件是否有正确的结尾，或者uuencoded文件在最后一行是否具有所需的结束标记。以下是该命令的简要说明。

## 语法

```
tail [option] [file-list]
```

+   **用途：** 显示**文件列表**中文件的末尾部分（即尾部）；默认的尾部大小为10行
+   **输出：** 将**文件列表**中文件的尾部显示在监视器屏幕上
+   **常用选项/功能：**
+   - `-f` 显示文件的尾部后，跟随文件的增长，并在内容追加到文件时显示新添加的行。使用此选项运行的tail命令通过<Ctrl+>终止。
+   - `+n` 对于`+n`，从文件开头开始显示n行；对于`-n`，显示文件末尾前n行（或n个单位）；默认情况下，n为10
+   - `-n N` 显示前N行
+   - `-r` 以相反顺序显示行（最后一行先显示）

与head命令类似，如果没有将**文件列表**作为参数给出，tail命令会从标准输入读取输入。下面的会话演示了tail命令如何在带选项和不带选项的情况下使用。我们使用与head命令相同的示例文件。tail sample命令显示示例文件的最后10行（默认的尾部大小），tail -5 sample命令显示示例文件的最后5行。tail +12 sample命令显示从第12行开始的文件尾部（而不是最后12行）。最后，tail -5r sample命令以相反顺序显示示例文件的最后5行。

tail命令的`-f`选项在需要查看正在增长的文件尾部时非常有用。当你运行一个需要很长时间才能完成的模拟程序（几分钟、几小时或几天），并希望在数据生成时看到程序产生的数据时，这种情况经常发生。如果你的UNIX系统运行X Window系统（见第22章），这样做会很方便。在X环境中，你可以在xterm（一个控制台窗口）中运行tail命令来监控新生成的数据，同时并继续做其他工作。下面的命令显示sim.data文件的最后10行，并在新行追加到文件时显示新行。你可以按<Ctrl+C>终止该命令。

```
$ tail -f sim.data
... last 10 lines of sim.data ...
... more data as it is appended to sim.data ...
```

有时，在识别UNIX系统中的问题时，系统管理员需要显示/var目录中不断增长的文件，因为内核和应用程序不断向它们追加新消息，包括/var/spool、/var/mail和/var/log目录中的文件。系统管理员可以使用tail -f命令在文件被追加时查看这些文件，如下面的会话所示，显示/var/log/messages文件中的最后10行，并在新消息追加到此文件时继续显示来自内核和应用程序的新消息。

```
$ tail -f /var/log/messages
... last 10 lines of /var/log/messages ...
... more data as it is appended to /var/log/messages ...
```
