## 在PC-BSD和Solaris服务器上启用rlogin和rsh的示例。

*对于PC-BSD主机或服务器：*

- 注意：此步骤会为传入的513端口流量关闭主机计算机上的防火墙。
- 使用桌面上的PC-BSD控制面板，进入防火墙管理器。
- 在防火墙管理器中，为rlogin和rsh添加一个TCP端口513，以便传入流量可以进入。
- 此时，重启防火墙管理器并退出。
- 检查rlogin是否处于活动状态：

```
$ rlogin 0
```

- 如果连接被拒绝，请以超级用户身份执行以下操作：

```
# vi /etc/inetd.conf
```

- 取消注释，即删除行首的#字符：

```
login stream tcp nowait root /usr/libexec/rlogind rlogind
```

- 保存文件。
- 如果你尚未为telnet和ftp启用inetd，请执行以下操作：
- 在/etc/rc.conf中启用inetd，以便你可以在本次会话中启动它，并且在以后的每次会话中它都会自动启动，以启用rlogin和rsh：

```
# echo "inetd_enable=\"YES\"" >> /etc/rc.conf
```

- 启动或重启inetd。

```
# /etc/rc.d/inetd start
Starting inetd
```

- 使用下一个命令，你实际上是在自己的机器上使用rlogin来检查rlogin守护进程！你可以用同样的方式检查rsh。
- 退出超级用户。

```
$ rlogin localhost
connect to address ::1: Connection refused
Trying 127.0.0.1...
Password for bob@pc-2823: xxx
```
