

# 表 3.3 从命令模式切换到插入模式的重要键

| Key | Action |
|---|---|
| a | 在光标所在字符之后追加文本 |
| A | 在当前行最后一个字符之后追加文本 |
| c | 开始更改操作，允许你修改文本 |
| C | 从光标位置更改到当前行末尾 |
| i | 在光标所在字符之前插入文本 |
| I | 在当前行开头插入文本 |
| o | 在当前行下方打开一个空白行并将光标置于该行 |
| O | 在当前行上方打开一个空白行并将光标置于该行 |
| R | 开始覆盖文本 |
| s | 替换单个字符 |
| S | 替换整行 |

# 表 3.4 命令模式的重要命令

| Command | Action |
|---|---|
| : n, m w file | 将第 n 到 m 行写入新文件。 |
| : n, m w >> file | 将第 n 到 m 行追加到现有文件。 |
| :r filename | 读取并在当前光标位置插入文件 filename 的内容 |
| :wq | 保存缓冲区并退出 |
| :w | 保存当前缓冲区并停留在编辑器中。 |
| :w filename | 将当前缓冲区保存为 filename |
| :w! filename | 用当前文本覆盖 filename |
| :w! | 写入文件（覆盖保护）。 |
| :w! file | 用当前文本覆盖文件。 |
| :w % .new | 将当前缓冲区命名为 file 的文件写入为 file.new。 |
| :q | 退出 vi（如果进行了更改则失败）。 |
| :q! | 不保存缓冲区退出 vi。 |
| :Q | 退出 vi 并调用 ex。 |
| :vi | 在 Ø 命令后返回 vi。 |
| ZZ | 退出 vi，仅在上次保存后进行了更改时保存文件 |
| % | 在编辑命令中替换为当前正在编辑的文件名。 |
| # | 在编辑命令中替换为备用文件名。 |
