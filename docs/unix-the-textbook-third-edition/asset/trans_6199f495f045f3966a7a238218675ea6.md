## 将数字格式化为字符串

语法：format_spec % numeric_exp

format_spec
width（可选）；在指定列数中对齐；负值左对齐，以 0 开头则零填充
precision（可选）；对浮点数显示指定精度的位数；默认 6
type（必需）；d（十进制整数），f（浮点数），s（字符串），e（浮点数 []）指数记法

x = 123，y = 456.789 的示例
% x --> 123
% x --> 000123
$8.2f % y --> 456.79
"8.2e" %y--> 4.57e+02
"-8s"%y "Hello" -> Hello ...
