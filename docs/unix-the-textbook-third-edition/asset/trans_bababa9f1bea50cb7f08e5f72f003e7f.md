然而，Java 语言并非以传统意义上的方式被编译。Java 程序被翻译成一种称为 Java 字节码的形式，然后由解释器解释执行。

为了进一步简化编写计算机程序的任务，甚至比高级语言更高的语言也被开发出来。它们包括脚本语言和可视化语言，如 UNIX shell 编程、Perl、Visual BASIC 和 Visual C++。其中一些语言是解释型的；另一些是编译型的。图 17.1 显示了各种类型编程语言与计算机硬件的接近程度、其使用的便捷性以及程序执行的相对速度。

## 17.3 编译过程

由于本章的重点是 UNIX 工具——主要针对 C 编程语言（一种编译型语言）——在继续之前，我们需要简要描述编译过程。正如我们在 17.2 节中所说，用编译型语言编写的计算机程序必须被翻译成程序将要执行的计算机系统所使用的 CPU 的机器代码。这种翻译通常是一个三步过程，包括编译、汇编和链接。编译过程将源代码（例如 C 程序）翻译成计算机系统所使用的 CPU 的相应汇编代码。然后汇编代码被翻译成相应的机器代码，称为目标代码。最后，目标代码被翻译成可执行代码。图 17.2 概述了翻译过程。

目标代码由机器指令组成，但它不可执行，因为源程序可能使用了汇编器无法解析引用的某些库函数，因为这些函数的代码不在源文件（s）中。链接器执行将程序的目标代码和库中的目标代码链接（连接）的任务，并生成可执行二进制代码。

C 程序的翻译在编译前会经过预处理阶段。C 预处理器翻译以 # 符号开头的程序语句。图 17.3 概述了 C 程序的编译过程。整个翻译过程由单个编译器命令完成。我们将在本章后面讨论各种 UNIX 编译器。
