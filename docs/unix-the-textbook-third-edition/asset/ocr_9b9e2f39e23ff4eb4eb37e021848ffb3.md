This chapter provided a common user of PC-BSD or Solaris with the basic techniques of working with the Zettabyte File System (ZFS).

We first went over some basic terms used in ZFS and then described what ZFS is from the user perspective. What differentiates ZFS from other file systems is that ZFS file systems are mapped onto disk storage facilities, like zpools, rather than onto physical storage media known as pool drives. The zpools are then mapped onto physical media. That means that the file system's storage requirements can grow as more physical media devices are added to the zpools.

We then provided six working examples of using the two ZFS commands, zpool and zfs. These working examples illustrate for the beginner some of the basic operations that can be used to create pools and file systems.
