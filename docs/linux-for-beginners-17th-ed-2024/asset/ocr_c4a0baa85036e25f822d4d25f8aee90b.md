# STEP 5

The command to create directories is quite logical, therefore. You'll create the directory, and any sub-directories within. However, what if you want to create a directory and a sub-directory in a single command? Make sure you're at **Home** (**cd** →) and enter **mkdir r ~p Temp/finances**. Now, **cd Temp/**, and **ls** to list the new directory.

![](bbox=[0.06, 0.23, 0.48, 0.39])

# STEP 8

Now that we've created some directories, let's see about removing them. Start by entering the **testdir** directory and listing its contents: **cd testdir**, then **ls**. The previously created **reports** sub-directory is present. One way to remove it is to enter: **rmdir reports**, then **ls** again to confirm it's not there.

![](bbox=[0.52, 0.23, 0.94, 0.39])

# STEP 6

The **-p** option is what enables the **mkdir** command to create the sub-directory as well as the parent directory. In Linux, commands always follow the same structure: **Command, Option, and Argument**. In the previous step example, command (**mkdir**), option (**-p**), and argument (**Temp/finances**).

![](bbox=[0.06, 0.51, 0.48, 0.66])

# STEP 9

A quick warning: removing a directory in the Terminal doesn't place it in the Mint **Rubish Bin**, via Nemo file manager. The same goes for any files, too. If you remove a directory from the Terminal command then it's gone for good.

![](bbox=[0.52, 0.51, 0.94, 0.66])

# STEP 7

If you want to drill down into the various options available for the **mkdir** command, you can enter **mkdir r ~help** in the Terminal. This will provide a quick help guide detailing the options and how the command structure works.

![](bbox=[0.06, 0.77, 0.48, 0.95])

# STEP 10

**Rmdir** will only remove empty directories, to remove directories containing sub-directories, or even files, you'll need to use the **rm** command with the **-R** option. For example, on the **Temp** page directories, use **rm ~R Temp**. A quick **ls** reveals that the parent folder and all of its contents are removed. Careful when using this command.
