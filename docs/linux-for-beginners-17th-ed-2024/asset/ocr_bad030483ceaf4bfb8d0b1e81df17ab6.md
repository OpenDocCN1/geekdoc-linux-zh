# ## Navigating the Cinnamon Desktop

STEP 5  At the bottom of the desktop there's the Panel. We've already looked at one section of the Panel, the Menu. If you right-click anywhere on the Panel, other than on a Panel app, you see a menu allowing you to edit, add and set up the Panel in a different way.

![](bbox=[0.07, 0.21, 0.48, 0.38])

STEP 6  For example, if you click the option Modify Panel, you can remove, move, renumber, modify the Panel, add a new one and clear it of any Applets that are currently present. An Applet, by the way, is an app that's designed to work and fit into the Cinnamon Panel.

![](bbox=[0.07, 0.51, 0.48, 0.68])

STEP 7  If you right-click anywhere on the Cinnamon desktop you see a set of options that allows you to further add to, edit or view the desktop content differently. It's very similar to that of Windows, which is why Mint is a good choice for ex-Windows users.

![](bbox=[0.07, 0.81, 0.48, 0.98])

STEP 8  From that desktop right-click, context menu, select Customize, followed by the Desktop Icons Settings link at the bottom of the newly opened window. This opens a new window where you're able to edit which desktop icons are present. If you're using a setup with multiple monitors attached, you can also choose which monitor displays which icons.

![](bbox=[0.52, 0.25, 0.93, 0.4])

STEP 9  Click on the Menu and type system settings and open the resulting icon. This takes you to the System Settings options. From here you're able to control and edit the way Linux Mint Cinnamon looks and works as well add new users, manage the firewall and enable accessibility options.

![](bbox=[0.52, 0.53, 0.93, 0.7])

STEP 10  In short, Linux Mint Cinnamon can be configured to look quite extraordinary. There are many examples available of how good it can get and what can be achieved. You can go as complex or as simple as you want, adding different component and animations or just keeping it plain and easy to read.

![](bbox=[0.52, 0.83, 0.93, 0.98])
