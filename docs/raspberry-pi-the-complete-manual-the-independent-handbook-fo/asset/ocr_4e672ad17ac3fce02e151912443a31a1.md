# # Build an always-on torrent box

# ### Mount hard drive

**03** Unless you plan to reformat your portable drive, you'll need to install NTFS support onto your Fi Type:

**$ sudo apt-get install ntfs-3g**
Add the hard drive to `/etc/fstab` (open it with sudo nano `/etc/fstab`) by adding the line:

`/dev/[hard drive address]`
`[mount point]` auto noatime 0 0
Use flock to find the rume of the storage, and create a mount point such as, `/home/pi/torrents` with mkdir. Reboot for it to mount.

![](bbox=[0.08, 0.47, 0.35, 0.58])

# ### Install Deluge

**04** We'll use Deluge for our torrents. Install it with:

**$ sudo apt-get install deluge deluge-console**
Now start and then stop Deluge so it creates a config file we can edit with:

**$ deluge**
**$ sudo pkill deluge**
And finally, run the following to copy the config file in case we mess up. `$ cp --config/deluge/auth --config/deluge/auth old`

# ### Basic configuration

**05** Edit the file with `deluge/auth` in `~/config/deluge/auth`
And add to the bottom:
`[user]:[Password]` `:10`
... to restrict access. Now start it up with:

**$ deluge**
**$ deluge-console**

![](bbox=[0.4, 0.16, 0.68, 0.32])

# ### Remote connection

**06** Now you're in the client, type the following three commands:

`config -s allow_remote true`
`config allow_remote exit`
Restart the Deluge daemon with:

**$ sudo pkill deluge & deluged**
Now open the graphical client on your Linux PC.

![](bbox=[0.4, 0.58, 0.68, 0.75])

# ### Remote interface

**07** Go to Edit > Preferences > Interface, then disable Classic Mode and restart Deluge. Click Add on the Connection Manager, and enter the IP in Hostname and the user we set up earlier. Click Connect to see any torrents you have downloading or uploading.

![](bbox=[0.72, 0.16, 0.96, 0.3])

# ### Download location

**08** Go to Edit again and then Preferences, and change to the Downloads tab if it's not on there already. Set the download location to the directory we mounted the hard drive to, and enable 'Auto add torrents', setting it to any destination if you plan to dump torrents to the Fi.

# ### Start on boot

**09** An init script from Ubuntu can be used to have Deluge start on boot. Download it with

**$ sudo wget -O /etc/init.d/deluge-daemon http://bit.ly/13nk0G**
Open `/etc/default/deluge-daemon` with nano and change the username to the one we set up earlier. Save it, then download the full init script and update with:

**$ sudo wget -O /etc/init.d/deluge-daemon http://bit.ly/13nkJiIz**
**$ sudo chmod 755 /etc/init.d/deluge-daemon**
**$ sudo update-rc.d deluge-daemon defaults**
