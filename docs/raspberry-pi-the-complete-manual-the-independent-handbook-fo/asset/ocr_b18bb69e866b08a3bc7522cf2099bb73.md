# Set GPIO mode

18 ➡ Reload the script in nano again. We will then set the GPIO mode to BOARD. This method is the safest for a beginner to adopt and will work whichever revision of the Pi you are using. It’s best to pick a GPIO convention and stick to it because this will save confusion later on.

```
$\texttt{\$ sudo nano gpio.py\newline\$ GPIO.setmode(GPIO.BOARD)}$
```

# Set pin mode

19 ➡ A pin has to be defined as either an input or an output before it can work. This is simplified in the GPIO library by calling the GPIO.setup method. You then pass in the pin number, and then GPIO.OUT or GPIO.IN. As we want to use an LED, it’s an output. You’ll be using these conventions frequently, so learn them as best you can so they soak in!

```
$\texttt{\$ GPIO.setup(12, GPIO.OUT)}$
```

# Using PWM

20 ➡ The next step is to tell the pin to output and then set a way of escaping our program. Here we recall the GPIO class again and then the PWM method, passing in the pin number, the second value is the frequency in hertz – in this case, 0.5.

```
$\texttt{\$ p = GPIO.PWM(12, 0.5)\newline\$ p.start(1)\newline\$ input(’Press return to stop:’)\newline\$ p.stop()\newline\$ GPIO.cleanup()}$
```

# Adjust PWM

21 ➡ To add a timer to the LED so it fades out, we first need to import the time library and then set the 12 pin to have 50Hz frequency to start off with.

```
$\texttt{\$ import time\newline\$ import RPi.GPIO as GPIO\newline\$ GPIO.setmode(GPIO.BOARD)\newline\$ GPIO.setup(12, GPIO.OUT)\newline\$ p = GPIO.PWM(12, 50) # channel=12 frequency=50Hz\newline\$ p.start(0)}$
```

# Add the fade

22 ➡ Then we add in another try-except block, this time checking what power the LED is at – and once it reaches a certain level, we reverse the process. To run this code, simply save it into main and then sudo python gpio.py.

```
$\texttt{\$ while 1:\newline\newline    for dc in range(0, 101, 5):\newline        p.changeDutyCycle(dc)\newline        time.sleep(0.1)\newline        for dc in range(100, -1, -5):\newline            p.changeDutyCycle(dc)\newline            time.sleep(0.1)\newline    except KeyboardInterrupt:\newline        pass\newline\newline p.stop()\newline\newline GPIO.cleanup()}$
```
