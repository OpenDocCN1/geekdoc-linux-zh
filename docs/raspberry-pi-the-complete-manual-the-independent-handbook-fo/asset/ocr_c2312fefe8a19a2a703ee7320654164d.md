# Full code listing

Some simple HTML code that can point us to some important websites. The `<h2>` tag is used to display the time thanks to Java

![](bbox=[0.38, 0.32, 0.62, 0.38])

We're calling the current time using jQuery in the JS tab so that we can ultimately display it on the webpage

![](bbox=[0.38, 0.47, 0.62, 0.53])

We're going to display the time as a 12-hour clock in the first `<h1>` statement, and use AM and PM to differentiate the time

We make the minutes readable by adding a 0 if it's below 10, then concatenate all the variables and assign to the tag h2

# Java

```
`var d = new Date();\nvar hours = d.getHours();\nvar mins = d.getMinutes();\nif (hours > 12) {\n    var hour = (hours - 12);\n    var ampm = "PM";\n}\nelse {\n    var hour = hours;\n    var ampm = "AM";\n}\nif (hours == 12) {\n    var ampm = "PM";\n}\nif (mins < 9) {\n    var min = mins;\n}\nelse {\n    var time = "0" + mins;\n}\nvar time = "The time is " + hour + "." + min + " " + ampm;\n$("h2").html(time);`
```
