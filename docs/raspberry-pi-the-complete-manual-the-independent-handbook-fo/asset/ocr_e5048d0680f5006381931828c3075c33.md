# Configure your location

**03** Locale is the language and regional settings that your Pi is using – while this generally has little impact on what you use, it is also responsible for any default currency settings, etc, so could prove to be an irritant at a later time if wrong.

Upon selecting the option, you’ll be taken through a wizard. Use the arrow keys to check the default locale before building more (it takes a while). Timezone will take you to a tzdata screen where you can adjust it.

# Change the memory split

**05** Changing the memory split of the Pi allows you to give either the system or the graphics processor a larger amount of memory.

The value you give it must be either 16/32/64/128/256. Here are our recommendations:

+   - 32MB GPU memory for basic distro usage where video and 2D rendering aren't required
+   - 64MB GPU memory for desktop use that requires video playback or have 3D effects enabled.
+   - 128MB GPU memory for graphical applications and games that do extensive multimedia or play 3D rendered games.
+   
+   For most people, a 64MB split for graphics will suffice.

# Tum overscan on and off

**07** You have had noticed one of two behaviours if you're using your Pi with a modern HDTV. There is a black border the whole way around the image output by the Pi – it just doesn't fit correctly. This is caused by underscan.

If you can't see the edges of your screen to get that they you're suffering from overscan.

You may have the former issue, you may need to either turn on overscan, or enable a "zoom" mode or similar on your TV.

You've have the latter issue, you need to turn overscan off so that you can see the edges.

# Overclock your Pi

**04** You can set the clock speed and voltage of your Pi to several different presets. Setting the clock speed and voltage at higher rates that the specification may cause instability, so do so in small increments.

# Update raspi-config

**08** The raspi-config tool receives updates from time to time. This is general to either add more features or fix small bugs, or both.

It's not a bad idea to run the updater when you use the tool – before you start changing any system settings. While it's much more likely that it'll be updated to look better or do more things, it's not impossible there could be miscellaneous bug fixes hidden within that would otherwise cause you some grief.

Remember, though, when you're trying to update your Pi you need an active internet connection, either through an LAN cable or wireless dongle.

Without them, it's never going to get you any newer. Always try to make sure you're on the latest version.
