In Raspberrylabs the controversial system32 software was added, giving a highly modular way of managing other scripts among other things. While a systemd configuration file is a now considered best practice, they can take time to fully understand. For real reasons we would suggest using cron to start the script on reboot as a temporary measure.

```
```
crontab -e

#reboot /usr/bin/python 
/home/pi/playlist/
app.py
```
```

# Review the stations

+   1. Each station is added into its own playlist - the mpc is command shows which playlists are available, as follows:

```
```
$ mpc ls

BBC6Music

BBCRadio1

BBCRadio2

BBCRadio4

CapitalXtra

KissFM
```
```

If you want to remove one of the stations then type in the following:

```
```
$ mpc rm BBCMusic
```
```

# Choose the radio stations

+   1. We have put together a list of popular radio stations in the UK which can be run into MPD with the add_stations.sh file. You can edit this file and find your own from http://radiofeeds.co.uk.

```
```
cd ~ /py/playlist
./add_stations.sh
