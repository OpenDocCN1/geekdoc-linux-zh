# # Help Us Help You

Things change. In the world of computers, things change rapidly. Facts described in this book will become invalid over time. When they do, we need your help locating and correcting them. Additionally, a 400-page book is bound to have typographical errors. Let us know when you spot one. Send your improvements, fixes, and other corrections to `support@sybex.com`. If you'd like to offer the author some feedback directly, send mail to `linux_security@hotmail.com`.
