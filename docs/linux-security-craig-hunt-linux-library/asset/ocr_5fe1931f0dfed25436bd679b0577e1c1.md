To start the testing, simply click the Start the Scan button. The status screen appears, as illustrated in Figure 5.6. The scan continues for as long as it takes the Nessus server to complete all the tests specified on the Plugins tab screen. The total duration of the scan will vary widely, depending on the number of hosts to be scanned and the complexity of the tests.
