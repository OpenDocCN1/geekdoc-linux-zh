for only one encryption algorithm: Blowfish. This shouldn't be considered a drawback because Blowfish has fared well so far in the many attempts to crack it via both cryptanalysis and brute force.

The goal of this utility is to provide an encryption device that is totally transparent to the user, who can access the PPDD-protected directories without the need for any special procedures.

Let's take a closer look at PPDD, starting with its installation.

# ### Installing PPDD
