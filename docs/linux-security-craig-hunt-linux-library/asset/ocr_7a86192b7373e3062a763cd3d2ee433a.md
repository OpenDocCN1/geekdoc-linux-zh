Note that both the start and kill scripts are really just symbolic links to the same script, which lives in the /etc/rc.d directory (in the case of SuSE) or in /etc/rc.d/init.d directory (in the case of Red Hat and other Linux distributions). When the system is coming up, the S scripts are invoked with a command-line argument of start. When the system is coming down, the K scripts are invoked instead, with a command-line argument of stop. The two numbers after the first letter of the script determine the order in which the script is executed. For example, the S20a script is executed before the S21cron script.
