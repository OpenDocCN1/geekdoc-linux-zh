Table 10.3 lists the host patterns that SOCKS5 recognizes.

# Table 10.3 socks5.conf Host Patterns

| Pattern | Description |
| :--- | :--- |
| IP-address/mask | IP address with four-octet mask. |
| - | Wildcard (all addresses match). |
| a.b.c.d | IP address must match exactly. |
| a.b.c | Matches the first three octets of an IP address. |
| .domain.com | Host name must end in .domain.com. |
| host.domain.com | Host name must match exactly. |
