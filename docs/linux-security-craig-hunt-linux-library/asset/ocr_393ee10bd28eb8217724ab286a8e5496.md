Although judging by the size of the /etc/rc.d directory, there are a large number of daemons started, in reality, most of these scripts check for the existence of a specific configuration before starting the service. This means that unless you have explicitly asked your server to offer a specific service (such as rwhod, for example), the daemon is not started by the script. The S20rwhod script, shown in Listing 4.5, first checks the /etc/rc.config file and only starts the rwhod daemon if it detects that the $START_RWHOD environment variable has been set to yes.

# Listing 4.5    The S20rwhod startup script

```
[ramon]$ more S20rwhod
#!/bin/sh
# Copyright (c) 1998, 2000 SuSE GmbH Nuernberg, Germany.All rights reserved.
#
# /sbin/init.d/rwhod
#
. /etc/rc.config

base=${0##*/}
link=${base##[SK]}[0-9]-[0-9]

test $link = $base && START_RWHOD=yes
test "${START_RWHOD}" = yes || exit 0

return=$rc_done
case '$1' in
    start)
        echo -n "Starting rwho daemon"
        startproc /usr/sbin/rwhod || return=$rc_failed
        echo -e "$return"
        ;;
    stop)
        echo -n "Shutting down rwho daemon"
        killproc -TERM /usr/sbin/rwhod || return=$rc_failed
        echo -e "$return"
        ;;
    reload|restart)
        $0 stop && $0 start || return=$rc_failed
        ;;
    status)
        checkproc /usr/sbin/rwhod && echo OK || echo No process
```
