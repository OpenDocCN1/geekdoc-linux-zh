In this format, the `attribute-group` can be any of the constructs used for `tn-gw` (see the previous section), except for the following:

```
```
permit-hosts host-description [-dest host-description] [-auth
(operation1 operation2..)] [-authall] [-log [operation1 operation2..]]
```
```

This format specifies the hosts that are allowed to use the proxy (`host-description`), along with the destinations that they’re allowed to proxy to (`-dest host-description`), and whether they should provide authsrv authentication (`-auth`) for specific types of FTP operations, for example, retrieving a file (RETR) or uploading a file (STOR). The `-authall` attribute forces proxy users to authenticate themselves for all FTP operations.

In addition, you can direct `ftp-gw` to log to `syslog` all attempts to perform any types of operations supported by the FTP protocol (e.g., `RETR`, `STOR`, etc.).

For example, consider the `/usr/local/etc/netperm-table` configuration in Listing 11.11. This example specifies a 10-minute idle timeout for proxied FTP connections and allows the 10.0.0.0/24 block to initiate FTP connections. You will log via the local `syslog` facility all attempts to retrieve and store a file on the remote FTP server.
