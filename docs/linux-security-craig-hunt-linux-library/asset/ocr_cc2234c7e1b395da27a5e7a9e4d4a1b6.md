Before proceeding to the FreeSWAN installation, make sure that you have the `gmp-devel` RPM package installed on your system. This is the GNU Arbitrary Precision Math library. Most distributions come with the `libgmp.so` library, but you need the header file `gmp.h`, which only comes with the `gmp-devel` package. The following command installs the RPM version of the `gmp-devel` package on your system:

```
[ramon]$ **sudo rpm -i gmp-devel-3.0.1-5.i386.rpm**
```

Now you're ready to install the FreeSWAN software itself. The first step in installing the FreeSWAN software builds a modified Linux kernel.
