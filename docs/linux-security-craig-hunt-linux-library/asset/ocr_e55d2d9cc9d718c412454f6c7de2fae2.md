The Pluggable Authentication Modules (PAM) framework is a suite of shared libraries and configuration files that allow a system administrator to manage the authentication of multiple network applications using a single utility and a set of configuration files. This simplifies the work of administrators and developers alike because new network applications don’t have to include source code to perform user authentication. Instead, they need only invoke one of the loadable modules included in the PAM library.
