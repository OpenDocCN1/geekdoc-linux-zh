At the conclusion of the test, Nessus provides you with a summary window (see Figure 5.7) that displays the list of target hosts and a quick synopsis of the security holes, warnings, and notes found on each of the hosts. Simply select the host of interest and click the Save As pull-down. Select your format of choice (HTML is a good candidate), and click the Save As button. You can then view the complete vulnerability report with your favorite Web browser, as shown in Figure 5.8.
