Another tool for adding, deleting, or reordering services in run levels 2–5 is the tksysv utility, which is available as part of the Red Hat distribution. This utility is X–based and is quite good. It presents a display of each of the services that are started and stopped at the various run levels and allows you to delete or add as needed. The principles of its use are basically the same as for ntsysv.
