# # Printer Management Commands

The commands in this section deal with the printers on your network and how they schedule print jobs. Chapter 10 gives more detail on managing printers.

*lpc*
`lpc [ command [ argument ] ]`

The lpc (line printer change) command allows you to control printing jobs that have been sent to a printer on your network. You can disable or enable a printer or printer queue, thereby preventing or allowing additional jobs to be sent to that printer. You can also prioritize the waiting print jobs. You can also check the status of a printer or printer queue or printer daemon. All of these are tasks you will be asked to do on a fairly regular basis as a system administrator. Chapter 10 explains the specifics of this command.

*lpq*
`lpq [ -l ] [ -P printer ] [ job # ] [ user ]`

The lpq (line printer queue) command looks at the print spool for the specified printer (or the default printer) and reports the status of the specified job or all jobs for the specified user if no job number is specified. This command is discussed more thoroughly in Chapter 10.

*lpr*
`lpr [ -P printer ] [ -# num ] [ -C class ] [ -J job ] [ -T title ] [ -U user ]
[ -i [ numcols ] ] [ -w page width ] [ filetype_options ] [ name ]`

The lpr (line printer) command spools named files for printing when resources become available. Among its options, you can specify the printer device with -P, the number of copies to print, and the page width. This command is discussed in Chapter 10.
