
# 配置调制解调器

出于此原因，您最好使用一个非常简化的终端程序，或者禁用终端程序的功能，例如服务器请求的文件传输。

RS−232 串行设备中最常见的一种是电话*调制解调器*（modem）。这个词是*调制器-解调器*（modulator–demodulator）的缩写，因为调制解调器作为一种将数字数据转换为模拟形式（即*调制*数据）并逆向执行该过程（*解调*数据）的方式发挥作用。

大多数电话调制解调器是 RS−232 设备，但这一规则有两个主要例外：

- *内部软调制解调器*——这些设备在之前已提及，它们没有串行端口电路。少数设备有可用的 Linux 驱动程序（详情请参见 http://www.linmodems.org/），但大多数没有。通常最好避免在 Linux 中使用软调制解调器。
- *USB 调制解调器*——通过*USB*端口接口的调制解调器正变得越来越流行。如果 USB 调制解调器使用*通信设备类抽象控制模型*（CDC–ACM）协议，它应该能与标准 USB 支持正常工作。然而，一些廉价的 USB 调制解调器并不使用 CDC–ACM 协议。据传，其中一些设备的驱动程序正在开发中。

**注意**

*数字用户线路*（DSL）和有线电视系统提供的互联网接入通常也被称为基于调制解调器的。虽然这些设备确实会对数据进行调制和解调，但它们的使用与本节描述的内容非常不同。有线电视和 DSL 调制解调器更类似于以太网路由器和网桥，因此第 12 章“TCP/IP Linux 网络”与配置这些设备相关。一些 DSL 和有线电视调制解调器通过 USB 端口接口。这些设备需要特殊的 Linux 驱动程序，而此类驱动程序大多不存在。请查阅 Linux USB 网站 http://www.linux-usb.org/ 以获取最新信息。

一些内部调制解调器——特别是较旧的型号——使用串行端口配合常规调制解调器电路。这些设备的功能与普通外部调制解调器完全相同，后者插入 RS−232 端口。无论设备使用何种接口，你都可以通过多种方式配置调制解调器。配置细节取决于谁发起连接，是你的计算机还是远程计算机。当你的某个用户发起连接时，你必须配置系统以执行*拨出*访问。为了支持远程用户呼叫你的系统，你必须配置系统以接受某种形式的*拨入*访问。

## 拨出调制解调器的用途

小型 Linux 系统，如桌面工作站，通常需要拨出访问。此类系统的用户可能需要通过调制解调器联系另一台计算机来检查电子邮件或执行其他简单的基于文本的任务。随着复杂度的增加，调制解调器可用于发起*点对点协议*（*PPP*）连接，从而允许浏览网页、FTP 传输等。最后，使用调制解调器从 Linux 计算机发送传真也是可行的。这些功能通常对单用户工作站最有吸引力，但有时在多用户系统上也有帮助。这一点在发送传真方面尤为明显；你可以配置共享打印队列（参见第 10 章和第 12 章）使用传真调制解调器而非打印机，从而为整个计算机网络提供出站传真服务。

## 呼叫远程文本模式系统

最简单的出站调制解调器连接类型之一是与另一台计算机的基于文本的链接。此类链接背后的理念与使用串行端口配合哑终端或运行终端程序的计算机类似。不同之处在于，两台计算机之间有一对调制解调器和电话网络。在这种设置中，拨出计算机通常充当终端；拨入系统运行 getty 程序并接收呼叫，如稍后在“接受文本模式登录”中所述。

在 Internet 和 PPP 连接兴起之前，以文本模式使用调制解调器非常常见，但现在这种情况已大大减少。然而，它仍然可以很好地满足简单的访问需求。此外，一些公司仍运营*电子公告板*系统（BBS），为没有 Internet 接入的用户提供产品信息、文件下载和讨论论坛。

要呼叫基于文本的远程系统，你必须使用一个终端程序。Linux 上两个流行的终端程序是基于文本的 minicom 和基于 X 的 Seyon（如图 11.4 所示）。使用这些程序的具体细节有所不同，但基本原理相同：

- 在运行程序之前，你可能需要创建一个符号链接，使 `/dev/modem` 指向调制解调器所在的设备文件（例如 `/dev/ttyS0`）。或者，你可以配置程序直接使用所需的设备文件——例如，通过点击 Seyon 命令中心窗口中的“设置”，然后点击“端口”，并输入所需的设备文件名。

**注意**

发起连接的*用户*必须具有读写调制解调器设备文件的权限。通常，这些文件属于一个特殊组，并具有 664 或 660 权限，因此该组的所有成员都可以访问调制解调器。你可以将任何应拥有调制解调器访问权限的用户添加到该组中。对你的系统中的调制解调器设备使用 `ls -l` 命令来了解其配置，并对设备的权限或你的组配置进行必要的更改。

- 运行程序时，你可能需要调整串行端口的参数——最重要的是端口速度。在 Seyon 中，你可以通过点击“设置”，然后“波特率”，再点击对应于你所需速度的按钮来执行此操作。当使用现代 56Kbps 调制解调器时，115Kbps 的端口速度是合适的。
- 要拨打号码，输入 ATDT 后跟号码，例如输入 ATDT555–1234 以拨打 555–1234。AT 是标准的调制解调器代码，代表*注意*（attention），并指示你即将发出命令。T 代表*拨号*（dial），且 T 指的是双音多频（touch–tone）拨号。（如果你的电话系统不支持双音多频拨号，请使用 ATDP 通过旋转脉冲进行拨号。）
- 如果你经常拨打某个号码，可以将其添加到拨号目录中。在 Seyon 中，你可以通过点击“拨号”按钮查看预配置的号码。你可以通过点击拨号目录窗口中的“编辑”来编辑这些条目，这会打开一个简单的文本编辑器显示配置文件。你可以在拨号目录窗口中选择号码并点击“前往”来拨号。此操作会发送适当的 AT 命令来拨打该号码。
- 使用完程序后，通过注销远程系统、关闭调制解调器或在程序中选择适当的选项（如 Seyon 命令中心窗口中的挂断按钮）来挂断调制解调器。

Seyon 将配置信息存储在 `~/.seyon` 目录中，因此每个用户都可能有自定义设置。minicom 要求 root 使用 `-s` 参数运行以创建名为 `/etc/minirc.dfl` 的配置文件，之后用户可以通过更改 root 建立的默认值来创建名为 `~/.minirc.dfl` 的自定义配置。

一旦使用终端程序连接到远程系统，你就可以根据该系统使用的规则使用该系统的任何规则。这些规则因系统而异。例如，如果你连接到一台 Linux 计算机，通常可以使用 Linux 文本模式命令和实用程序；但 BBS 通常使用自定义的基于菜单的环境，你需要输入字母或数字在系统中移动。

## 建立 PPP 连接

如今，建立 PPP 链路是拨出调制解调器最常见的用途。PPP 允许你使用完整的 TCP/IP 网络功能将系统连接到 Internet。通过 PPP 连接的可以浏览网页、通过 FTP 传输文件、收发电子邮件等。由于 PPP 链路通常是短暂的，且按照现代 Internet 标准调制解调器链路速度较慢，因此在通过 PPP 连接的计算机上运行服务器并不常见。一些互联网服务提供商（ISP）确实提供可持续使用的账户；然而，对于始终在线的连接，通过有线电视调制解调器或 DSL 获取更快的服务通常更便宜。

你可以使用基于文本的拨号脚本或图形用户界面（GUI）配置工具来发起 PPP 连接。GUI 工具很流行且易于使用，但在某些情况下，拨号脚本更为合适。例如，你可以将脚本作为自动例程的一部分来调用，以每小时检查一次你的电子邮件。
