Other package update tools work in a similar way, and have similar caveats, although they often work in GUI mode rather than in the command-line mode favored by APT. No matter what tool you use, one limitation is that they support only those upgrades that are officially sanctioned by your distribution maintainer. You'll need to use other methods to update third-party packages.

# ## In Sum

Installing, removing, and updating programs are very important tasks for any Linux system administrator. Most Linux systems today use the RPM or Debian package formats, both of which allow for easy package handling by maintaining a database of packages and the individual files associated with these packages. When necessary, you can build a package file from source code, or install software without using an RPM or Debian package. This approach is particularly useful for the Linux kernel itself, which can benefit more than other programs from customizations unique to each computer. In all cases, ensuring that your programs are up-to-date requires some effort, because you must keep an eye on important security developments as well as watch for the addition of features you might want to make available on your system.
