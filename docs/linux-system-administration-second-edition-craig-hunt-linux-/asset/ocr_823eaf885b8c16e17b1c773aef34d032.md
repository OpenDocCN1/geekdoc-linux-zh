The KDE environment has its own graphical manager for SysV scripts, kysv. It is also quite nice and features drag-and-drop capabilities. Since it is a KDE tool, it is X-based. In resolutions higher than 640×480, you need to display it at full size since the smaller default size obscures the process names. (The program does, however, provide help when you mouse over a process name.) Figure 3.4 illustrates the kysv utility.

Still another option is the command-line chkconfig utility, which gets bonus points for being easy to use and independent of X. This is especially helpful since many distributions do not include X with server installations. If you pass chkconfig a -list switch, it will display a list of all SysV scripts and whether each is turned on or off at each run level. Listing 3.7 shows the output. The -add and --del switches allow you to alter the processes in each run level.
