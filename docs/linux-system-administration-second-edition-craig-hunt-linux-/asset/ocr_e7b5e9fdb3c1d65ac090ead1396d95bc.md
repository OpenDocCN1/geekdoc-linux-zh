# Conventions Used in This Book

This book uses certain typographic styles in order to help you quickly identify important information, and to avoid confusion over the meaning of specific words. The conventions are listed below.

+   * *Italicized text* indicates technical terms that are introduced for the first time in a chapter. (Italics are also used for emphasis.)
* A monospaced font is used to indicate the contents of configuration files, messages displayed at a text-mode Linux prompt, filenames, and Internet URLs. This font is also used for code listings, such as configuration files.
* *Italicized monospaced text* indicates a variable—information that differs from one system or command to another, such as the name of a client computer or a process ID number.
* **Bold monospaced text** is information that you're to type into the computer, usually at a Linux shell prompt. This text can also be italicized to indicate that you should substitute an appropriate value for your system.

Some commands appear on lines by themselves. These lines use a monospaced font, just like the used for shell character—a dollar sign ($) for commands that may be reasonably used by ordinary users, or a pound sign (#) for commands that may only be used by the system administrator. In exchanges, information that the computer displays is a normal monospaced font and what you type is a bold monospaced font, which makes it easy to distinguish what you see from what you type.

In addition to these conventions, which can apply to individual words or entire paragraphs, a few conventions are used to highlight sections of text:

> **Note** A Note indicates information that's useful or interesting, but that is somewhat peripheral to the main discussion. A Note might be relevant to a small number of networks, for instance, or refer to an outdated feature.

> **Tip** Tip provides information that can save you time or frustration, and that may not be entirely obvious. A Tip might describe how to get around a limitation, or how to use a feature to perform an unusual task.

> **Warning** Warnings describe potential pitfalls or dangers. If you fail to heed a Warning, you may end up spending a lot of time recovering from a bug, or even restoring your system from scratch.

| Sidebars |

A Sidebar is like a Note, but is longer. Typically, a Note is one paragraph or less in length, but Sidebars are longer than this. The information in a Sidebar is useful, doesn't fit into the main flow of the discussion.

# Administrator's Logbook

Because the importance of logging all the configuration changes you make to a system is a major theme of this book, throughout various chapters we have included "Administrator's Logbook" sidebars illustrating the kinds of information you would record for the activity at hand.
