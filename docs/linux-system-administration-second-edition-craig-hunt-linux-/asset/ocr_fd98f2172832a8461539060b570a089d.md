You may use the loopback capability of Linux to check whether the image created by mkisofs has a directory structure and permissions that match the original files. Loopback is the capability that allows you to mount a file as if it were a disk partition. To do this, use the following command, inserting the correct name for the created image and the correct path to the mount point you wish to mount the image on:

```
#  mount -t iso9660 -o loop cd_image.iso /mnt/tmp
```

**Tip** We typically create a /mnt/tmp file for mounting partitions or files that are not so permanently mounted as CD-ROM drives and floppy drives. You can use it to mount anything temporarily, regardless of device type.

Compare /mnt/tmp to wherever your original files are located until you are convinced that the contents are the same. Then use the following command to unmount the CD-R image that you've created:

```
#  umount /mnt/tmp
```

# cdrrecord

Once you've made and tested an image file, you'll use the cdrrecord utility to actually write the CD-ROM image to the blank CD-R. cdrrecord was designed for use with SCSI or ATAPI CD recorders. It can write data, audio, mixed, and multisession discs and supports most CD recorders available. cdrrecord is run from the command line and has a great many options. The man page is quite helpful, but the process is not simple. The simplest case, a pure data image copied to with an ISO-9660 filesystem on a sufficiently quick system using the device at SCSI target ID 6 as its target, allows you to run the command as follows:

```
#  cdrrecord -v speed=2 dev=0,6,0 cd_image.iso
```

For better readability, the SCSI settings of the writer are stored in three environment variables: SCSI_BUS, SCSI_ID, and SCSI_LUN.

If you use cdrrecord to overwrite a CD-RW, you must add the option blank=blanktype to erase the old content. The program can blank the CD-RW in several different ways, as summarized in Table 9.4.

Table 9.4: Options for Blanking a CD-RW Disc with cdrrecord

| blanktype value | Description |
| :--- | :--- |
| help | Displays a list of possible blanking types. |
| all | Completely erases the entire disc. This may take a long time. |
| fast | Erases key data structures on the disc; fast but incomplete. |
| track | Erases a single track. |
| unreserve | Unreserves a reserved track. |
| trail | Erases the tail of a track. |
| unclove | Uncloves last session; allows writing additional information to a previously finished writing session. |
| session | Erases the last session. |
