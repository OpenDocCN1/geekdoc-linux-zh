125. D. FAT32 is lightweight and relatively fast. It allows for 32-bit cluster addressing, which provides for a maximum partition size of 2 terabytes (2, 048GB). It also includes smaller cluster sizes to avoid wasted space. FAT32 support is included in current Windows versions. FAT32 does not have individual file security permissions.
