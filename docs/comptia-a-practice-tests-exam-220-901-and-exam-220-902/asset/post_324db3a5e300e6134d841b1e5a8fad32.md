## 第 7 章 安全

**本章涵盖的 COMPTIA A+ 考试 220-902 主题包括以下内容：**

### 3.1 识别常见的安全威胁和漏洞。

- 恶意软件
  - 间谍软件
  - 病毒
  - 蠕虫
  - 木马
  - Rootkit
  - 勒索软件
- 网络钓鱼 (Phishing)
- 鱼叉式网络钓鱼 (Spear phishing)
- 欺骗 (Spoofing)
- 社会工程学
- 肩窥 (Shoulder surfing)
- 零日攻击
- 僵尸/僵尸网络
- 暴力破解
- 字典攻击
- 不合规系统
- 违反安全最佳实践
- 尾随 (Tailgating)
- 中间人攻击

### 3.2 比较和对比常见的预防方法。

- 物理安全
  - 锁门
  - 人闸 (Mantrap)
  - 线缆锁
  - 保护物理文档/密码/碎纸
  - 生物识别
  - ID 徽章
  - 钥匙扣 (Key fobs)
  - RFID 徽章
  - 智能卡
  - Token
  - 隐私滤光器
  - 入场控制名册
- 数字安全
  - 防病毒/反恶意软件
  - 防火墙
  - 用户身份验证/强密码
  - 多因素身份验证
  - 目录权限
  - VPN
  - DLP
  - 禁用端口
  - 访问控制列表
  - 智能卡
  - 电子邮件过滤
- 受信任/不受信任的软件来源
- 用户教育/使用协议 (AUP)
- 最小权限原则

### 3.3 比较和对比基本 Windows OS 安全设置的区别。

- 用户和组
  - 管理员
  - 高权限用户 (Power user)
  - 访客
  - 标准用户
- NTFS 与共享权限
  - 允许与拒绝
  - 移动与复制文件夹和文件
  - 文件属性
- 共享文件和文件夹
  - 管理共享与本地共享
  - 权限传播
  - 继承
- 系统文件和文件夹
- 用户身份验证
  - 单点登录 (Single sign-on)
- 以管理员身份运行与以标准用户身份运行
- BitLocker
- BitLocker-To-Go
- EFS

### 3.4 给定场景，部署和执行安全最佳实践以保护工作站。

- 密码最佳实践
  - 设置强密码
  - 密码过期
  - 更改默认用户名/密码
  - 屏幕保护程序必需密码
  - BIOS/UEFI 密码
  - 要求使用密码
- 账户管理
  - 限制用户权限
  - 登录时间限制
  - 禁用访客账户
  - 失败尝试锁定
  - 超时/屏幕锁定
- 禁用自动运行
- 数据加密
- 补丁/更新管理

### 3.5 比较和对比保护移动设备的各种方法。

- 屏幕锁定
  - 指纹锁定
  - 面部锁定
  - 滑动锁定
  - 密码锁定
- 远程擦除
- 定位应用程序
- 远程备份应用程序
- 登录失败次数限制
- 防病毒/反恶意软件
