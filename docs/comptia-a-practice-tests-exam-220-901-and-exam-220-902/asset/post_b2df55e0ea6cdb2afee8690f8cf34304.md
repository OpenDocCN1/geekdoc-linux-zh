66. C. The most common cause of an IP address conflict is if someone configures a computer with a static IP address that’s part of the DHCP server’s range. The DHCP server, not knowing that the address has been statically assigned somewhere, doles out the address and now there’s a conflict. Rebooting the computer won’t help, and neither will releasing the address and getting a new lease from the DHCP server—it’s just going to hand out the same address again because it doesn’t know that there’s a problem.
