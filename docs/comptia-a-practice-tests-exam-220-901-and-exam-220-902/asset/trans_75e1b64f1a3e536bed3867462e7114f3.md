- **1.2 根据给定场景，使用适当的方法安装 Windows PC 操作系统**

  - 分区：动态；基本；主分区；扩展；逻辑；GPT
  - 文件系统类型/格式化：exFAT；FAT32；NTFS；CDFS；NFS；ext3, ext4；快速格式化与完全格式化
  - 必要时加载第三方替代驱动程序
  - 工作组与域设置

  - 驱动程序安装、软件和 Windows 更新
