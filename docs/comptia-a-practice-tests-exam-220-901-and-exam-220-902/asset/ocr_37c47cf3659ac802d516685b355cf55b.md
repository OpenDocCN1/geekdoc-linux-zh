**45.** B. File servers provide a central repository for users to store, manage, and access files on the network. Networks can also use network attached storage (NAS) devices, which are stand-alone units that contain hard drives, come with their own file management software, and connect directly to the network. If a company has extravagant data storage needs, it can implement a storage area network (SAN). A SAN is basically a network segment, or collection of servers, that exists solely to store and manage data.

**48.** C. On a Mac, it’s possible to run a large number of things at one time, whether those things in question are apps or desktops. Apple’s Mission Control is an easy way to see what is open and switch between applications. To access Mission Control, you can press the Mission Control key on an Apple keyboard, click the Mission Control icon in Dock (or Launchpad), or swipe up with three or four fingers on a trackpad.
