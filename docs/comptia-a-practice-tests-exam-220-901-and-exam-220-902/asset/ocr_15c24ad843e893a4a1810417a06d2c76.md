+   137. B. The address shown is one assigned by the Automatic Private IP Addressing (APIPA) service. It auto-configures your network card with an IP address if your computer is set to receive an IP address from the Dynamic Host Configuration Protocol (DHCP) server and that server doesn’t respond. You can always tell an APIPA address because it will be in the format of 169.254.x.x.

+   140. C. `tracert` (trace route) is a Windows-based command-line utility that enables you to verify the route to a remote host. Execute the command `tracert hostname`, where `hostname` is the computer name or IP address of the computer whose route you want to trace. Tracert returns the different IP addresses the packet was routed through to reach the final destination.
