102. B. If you try to power on the system but get no lights or fan, first check the obvious things. Is it plugged in? Does the cord work? If those all check out, then it’s probably the power supply.

103. B. If a hard drive is too full and has less than 10 percent free space, it can slow down dramatically. The first solution to try is to remove files and free up space. If that doesn’t work, you may need to format and reinstall, or potentially replace, the hard drive.

104. A. The ping command is one of the most useful commands in the TCP/IP protocol. It sends a series of packets to another system, which in turn sends back a response. This utility can be extremely useful for troubleshooting problems with remote hosts. The ping -t command sets a persistent ping, which does not stop until you cancel it.
