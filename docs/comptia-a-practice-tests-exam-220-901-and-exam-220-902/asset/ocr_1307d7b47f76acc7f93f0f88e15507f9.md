+   50. D. RAID 10 is a mirrored striped set. As long as one drive in each mirrored pair is functional (just like in RAID 1), you shouldn't lose any data. Simply replace the failed disk and rebuild the array.

+   51. B. RAID 0 is called disk striping. Data can be written to or read from multiple devices at the same time, increasing data access speed. However, if one drive fails, all data is lost. (Back up early and often!) RAID 1 is a mirror set, which does not increase data access but provides fault tolerance. RAID 5 is disk striping with parity, which provides both speed and fault tolerance but requires three hard disks.
