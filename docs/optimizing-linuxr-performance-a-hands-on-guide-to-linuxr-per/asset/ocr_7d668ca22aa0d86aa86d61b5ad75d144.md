# 5.1. Linux Memory Subsystem

When analyzing memory performance, it may become necessary to observe how an application performs at various levels within the memory subsystem. At the top level, the operating system decides how the swap and physical memory are being used. It decides what pieces of application's address space is in physical memory, which is called the resident set. Other memory used by the application but not part of the resident set will be swapped to disk. The application decides how much memory it requests from the operating system, and this is called the virtual set. The application can allocate this by calling malloc or implicitly by using a large amount of stack or using a large number of libraries. The application can also allocate shared memory that can be used by itself and other applications. The ps performance tool is useful for tracking which code in an application is allocating memory. The memprof performance tool is useful for tracking which code in an application is allocating size. The itps tool is useful for tracking shared memory usage.

When an application is using physical memory, it begins to interact with the CPU's cache subsystem. Modern CPUs have multiple levels of cache. The fastest cache to the CPU (also called L1 and Level 1 cache) is the smallest in size. For instance, that the CPU has only two levels of cache: L1 and L2. When the CPU requests a piece of memory, the processor checks to see whether it is already in the L1 cache. If it is, the CPU uses it. If it is not in the L1 cache, the processor generates a L1 miss. It checks in the L2 cache; if the data is in the L2, it is used. If the data is not in the L2 cache, an L2 miss occurs, and the processor must go to physical memory to retrieve the data in the L1 or even L2 cache). Smart cache usage—arranging an application's data structures and reducing cache size—may make it possible to reduce the number of cache misses and increase performance. cachegrind and profile are great tools to find information about how an application is using the cache and about which functions and data structures are causing cache misses.
