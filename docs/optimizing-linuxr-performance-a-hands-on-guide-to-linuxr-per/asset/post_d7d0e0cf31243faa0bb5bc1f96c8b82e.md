# Overview

The first comprehensive, expert guide for end-to-end Linux application optimization is more crucial than ever—and in today's complex production environments, it's tougher to ensure code access, plus an exceptional array of optimization tools. But the tools are scattered across the Internet. Many problems, now one of those experts has written the definitive Linux tuning primer for every professional: Optimizing Linux. Today's most vital Linux application optimization tools show how they fit into a proven methodology for how to identify the exact lines of source code that are impacting performance, helping administrators and application developers solve matters more quickly. You will discover how to:

- Identify bottlenecks if you are not familiar with the underlying system architecture and applications, through case studies you can easily adapt to your own environment.
