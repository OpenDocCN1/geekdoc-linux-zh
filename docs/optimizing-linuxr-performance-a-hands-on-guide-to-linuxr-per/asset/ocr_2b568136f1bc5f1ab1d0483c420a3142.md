# B.1 Fedora Core 2 (FC)

For FC2, Red Hat provides packages for profile that should be used rather than those downloaded from the profile Web site. The uniprocessor kernel does not provide the necessary profile drivers. Red Hat packages the necessary profile kernel modules with the smp version of the kernel. If you want to run profile,you must use the smp kernel, even if you are running it on a single-processor machine.
