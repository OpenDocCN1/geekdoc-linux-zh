本章介绍了如何使用 Linux 网络性能工具来监控从低层网络接口到高层应用的整个系统网络流量。它介绍了用于查询当前物理链路设置的工具（`mii-tool`, `ethtool`）以及监控通过低层接口的数据包数量和类型的工具（`ifconfig`, `ip`, `sar`, `collect`, `iptraf`, `netstat`, `ethertype`）。随后，展示了显示不同类型 IP 流量的工具（`collect`, `iptraf`, `netstat`, `ethertype`）以及每种类型流量的数量（`collect`, `iptraf`, `ethertype`）。接着介绍了一个工具 (`netstat`) 将 IP socket 使用情况映射到接收/发送每种流量的进程。最后，介绍了一种网络可视化工具，它可以将流经网络的数据类型、数量以及数据在哪些节点之间流动的关系可视化（`ethertype`）。

接下来的章节描述了一些常用的 Linux 工具，它们使得使用性能工具变得更加简单。它们本身不是性能工具，但通过让性能工具更易于使用，它们可以帮助可视化和分析工具的结果，并自动化某些重复性任务。

## 第 8 章 实用工具：性能工具助手

本章提供了 Linux 系统上各种实用工具，这些工具可以增强性能工具的有效性和易用性。实用工具本身不是性能工具，但与性能工具配合使用时，可以帮助自动化无聊任务、分析性能统计数据并创建适用于性能工具的应用程序。

阅读完本章后，你应该能够：

- 自动化显示和收集周期性性能数据（`bash watch`）。
- 记录调查期间显示的所有命令和输出（`tee`, `script`）。
- 导入、分析并绘制性能数据图（`numeric`）。
- 确定应用程序使用的库（`ldd`）。
- 确定哪些函数属于哪些库（`objdump`）。
- 研究应用程序的运行时特性（`gdb`）。
- 创建适用于性能工具/调试的应用程序（`gcc`）。

## 8.1. 性能工具助手

Linux 拥有丰富的工具，这些工具可以协同工作并产生大于部分之和的效果。性能工具也是如此。尽管性能工具本身很有用，但与其他 Linux 工具结合使用可以显著提高它们的有效性和易用性。

### 8.1.1. 自动化和记录命令

如前面的章节所述，性能调查中最有价值的步骤之一是保存调查期间发出的命令和生成的的结果。这允许你回溯这些内容并寻找新的见解。为此，Linux 提供了 `tee` 命令，允许你将输出保存到文件；或者 `script` 命令，它可以记录屏幕上显示的每次按键和输出。这些信息可以稍后保存并回查看，或者用于创建脚本来自动化测试执行。

自动化命令非常重要，因为减少了出错的概率，并让你能够思考问题而无需记住所有细节。`bash` 和 `watch` 命令都允许你在输入命令后，定期且自动地执行这些长且复杂的命令行。当你确认命令行无误后，`bash` 和 `watch` 就可以定期执行该命令，而无需重试。

### 8.1.2. 性能统计数据的图化与分析

除了记录和自动化的工具外，Linux 还提供了强大的分析工具，帮助你理解性能统计数据的意义。大多数性能工具生成的统计数据是文本输出，这并不总是容易看到随时间变化的模式和趋势。Linux 提供了 `gnumeric` 表格软件，它可以导入、分析并绘制性能数据的图表。当你对数据绘图时，性能问题的原因可能会显而易见，或者至少开启新的调查领域。

### 8.1.3. 研究应用程序使用的库

Linux 还提供了许多工具，让你能够确定应用程序依赖于哪些库，以及显示给定库提供的所有函数的工具。`ldd` 命令提供了应用程序使用的所有共享库列表。`objdump` 命令可以让你确定哪些函数属于哪些库。

## 8.2. 工具

配合使用，以下工具可以极大增强前面章节所述性能工具的有效性和易用性。

### 8.2.1. bash

bash 是默认 shell，大多数 Linux 用户在登录机器或打开终端时使用它。bash 拥有一种强大的脚本语言，通常用于创建脚本。然而，这种脚本语言也可以从命令行调用，并让你轻松自动化性能调查期间某些无聊的任务。

### 8.2.1. 性能相关的选项

bash 提供了一系列可以用于定期运行的命令。大多数 Linux 用户将 bash 作为默认 shell，所以如果你没有使用 bash，可以通过输入 bash 来调用它。当你有了 bash 命令后，可以输入一系列 bash 脚本命令来自动化特定命令的执行。此功能在你需要使用特定命令定期提取性能统计时非常有用。这些脚本选项见表 8-1。

#### 表 8-1. 运行时脚本选项

| 选项 | 解释 |
| :--- | :--- |
| while condition | 当条件为假时执行循环。 |
| do | 表示循环的开始。 |
| done | 表示循环的结束。 |

bash 极其灵活，并在 bash 手册页中有记录。尽管 bash 的复杂性可能让人无从下手，但不需要立即掌握所有内容。
