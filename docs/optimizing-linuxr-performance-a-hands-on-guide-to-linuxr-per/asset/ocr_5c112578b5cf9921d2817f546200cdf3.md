# B.2 Enterprise Linux 3 (EL3)

For EL3, once again, Red Hat provides packages for profile that should be used rather than those downloaded from the profile Web site. The uniprocessor kernel does not provide the necessary profile drivers. Red Hat has the necessary profile kernel modules with the smp or hugemem versions of the kernel. If you want to run profile you must use the smp or hugemem kernel, even if you are running it on a single-processor machine.

More details on using profile in EL3 are provided at http://www.redhat.com/docs/manuals/enterprise/RHEL-3-Manual/sysadmin-guide/ch-profile.html.
