# 9.5.1. Is the Process Spending Time in User or Kernel Space?

You can use the time to determine whether an application is spending its time in kernel or user mode. profile can also be used to determine where the time is spent. By profiling per process, it is possible to see where a process is spending time in the kernel or user space.

If the application is spending a significant amount of time in kernel space (greater than 25 percent), go to Section 9.5.2. Otherwise, go to Section 9.5.3.

# 9.5.2. Which System Calls Is the Process Making, and How Long Do They Take to Complete?

Next, trace to see which system calls are made and how long they take to complete. You can also run profile to see which kernel calls are being called.

It may be possible to increase performance by minimizing the number of system calls made or changing system calls made on behalf of the program. Some of the calls may be unexpected and a trace of the application's calls. You can use ltrace and str to determine where they are being made.

Now that the problem has been identified, it is up to fix it. Go to Section 9.9.
