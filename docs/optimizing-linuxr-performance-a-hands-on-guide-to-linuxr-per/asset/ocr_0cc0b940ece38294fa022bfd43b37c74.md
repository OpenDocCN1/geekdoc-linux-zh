# 8.2. Tools

Used together, the following tools can greatly enhance the effectiveness and ease of use of the performance tools described in previous chapters.

# 8.2.1. bash

bash is the default Linux command-line shell, and most likely you use it every time you interact with the Linux command line. bash has a powerful scripting language that is typically used to create shell scripts. However, the scripting language can also be called from the command line and enables you to easily automate some the most tedious tasks during a performance investigation.

# 8.2.1. Performance-Related Options

bash provides a series of commands that can be used to periodically run a command. Most Linux users have bash as their default shell, so just logging in to a machine or opening a terminal brings up a bash. If you are not using bash, you can invoke it by typing bash.

After you have a bash command, you can enter a series of bash scripting commands to automate the continuous execution of a particular command. This feature proves most useful when you need to periodically extract performance statistics using a particular command. These scripting options are described in Table 8-1.

# Table 8-1. Runtime Scripting Options

| Option | Explanation |
| - | - |
| while condition | This executes a loop until the condition is false. |
| do | This indicates the start of a loop. |
| done | This indicates the end of a loop. |

bash is incredibly flexible and is documented in the bash man page. Although bash's complexity can be overwhelming, it is not necessary to master all bash immediately to use.

# 8.2.2 Example Usage

Although performance tools, such as ps and vmstat and sar, periodically update performance statistics, others, such as ifconfig, do not, bash can call commands as ps and ifconfig to periodically their statistics. For example, in Listing 8.1, we ask bash to do something in a while loop based on the condition True. The True command is always true, the while loop will never exit. Next, the commands that will be executed after each iteration will extract performance information about the eth0 controller. However, we are only interested in the received packets, so we will use grep output of ifconfig for the string "RX packets". Finally, we issue the done command to tell bash that we are done with the loop. Because the True command always returns true, this loop will run forever unless we interrupt it with a <Ctrl-C>.

# Listing 8.1.

```
[ezolt@wintermute tmp]$ while true; do sleep 1; /bin/ifconfig
eth0 | grep
"RX packets" ; done;
```
