# 10.3. Find a Baseline/Set a Goal

This first step in any performance hunt is to determine the current state of the problem. In the case of the GIMP filter, we need to figure out how much time it takes to run a particular image. This is our baseline time. Once we have this baseline, we can then try an optimization and see whether it decreases the execution time. Sometimes it can be tricky to time how long something takes It is not as easy as using a stopwatch because the operating system is scheduling other tasks at the same time that our process CPU-intensive job is running. If there are others running in addition to the CPU-intensive one, of wall-clock time could be greater than the CPU time that the process actually uses. In this case, we are lucky; by looking at top as the filter is running, we can see the lic process is taking up most of the CPU usage, as shown in Listing 10.1.

# Listing 10.1.

```
[ezolt@localhost ktracer]$$ top
```

```
top - 08:24:48 up 7 days, 9:08, 6 users, load average: 1.04, 0.64, 0.76

PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+
32744 ezolt 25 0 53696 45m 11m R 89.6 14.6 01:16 lic
2067 root 15 0 06952 21m 17m S 6.0 6.8 01:56:22 X
32738 ezolt 15 0 35292 27m 14m S 2.3 8.7 00:05:08
gimp
```

From this, we can deduce that GIMP actually spawned a separate process to run the filter. When the filter is running, we can use ps to track how much CPU time the process is using and when it finishes. When we have the PID of the filter using top, we can refer to Listing 10.2 and ask ps to periodically observe how much CPU time the filter is using.

# Listing 10.2.

```
while true; do sleep 1; ps 32744; done

PID TTY STAT TIME COMMAND
32744 pts/0 R 2:46
/usr/local/lib/gimp/2.0/plugin-ins/lic -gimp 8 6 -run 0
```

# Note

If you need to time an application but do not have a stopwatch, you can use time and cat as a simple stopwatch. Just type time cat when you want to start, and press <Ctrl-D> when you are finished. time shows how much time you has passed.

When running the lic on the reference image (which is a fetching picture of gimp) and using the ps method just to time the filter, we can see from Listing 10.2 that it takes 2 minutes and 46 seconds to run out of the box, set we can know the amount of time that the filter takes out of the box, set we can use for the performance hunt.
