# Tape Drives

Most QIC-40, QIC-80, and QIC-117 floppy tape drives should be supported by the ftape driver. The following is a listing of drives mentioned by name in the ftape sources. There are no individual, per-drive drivers as with SCSI or Ethernet cards; all are covered under the same driver.
