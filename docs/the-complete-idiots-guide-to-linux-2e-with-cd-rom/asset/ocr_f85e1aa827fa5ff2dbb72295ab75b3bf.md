# Floppy Drives

The number of floppy drives that are not supported by OpenLinux is so small that it is hardly even worth mentioning. Regardless, in the kernel sources, a few laptop drives are mentioned because of special boot/module parameters that are required to get them working correctly. Also, there are additional boot parameters that can be used to adjust floppy support. OpenLinux Base and OpenLinux Standard customers may contact Caldera for details on these parameters or check the BootPrompt-HOWTO.
