If the application is hidden, its name is displayed in parenthesis. To show the application, just click its button. Right-clicking a button displays a menu that allows you to control some options of the application’s window.

Each button on the taskbar represents a running application.

Both the panel and taskbar are services provided by an application called KPanel that runs whenever you log into your system and work under the KDE.
