# SCSI and IDE Tape Drives

There are no specific drivers for SCSI and IDE tape drives; support for them is loaded along with the driver for the interface they are connected to, so no special modules or drivers are required to use them. If the interface is up and running (SCSI or IDE), the drive connected to it should be usable.
