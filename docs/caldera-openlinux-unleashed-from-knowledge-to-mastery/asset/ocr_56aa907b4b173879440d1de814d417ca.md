# Copying Lists and Dictionaries

There is one caveat regarding the assignment of lists and dictionaries to new names. If you just do a simple assignment, such as `newdict=olddict` or `newlist=oldlist`, the object does not actually get copied; only the reference to the object is copied. This means that both names would now be pointing to the same value in memory, so if you delete an item from the new object, it will also disappear from the old one! To avoid this, type `newdict=olddict.copy()` with dictionaries, and type `newlist=list(oldlist)` when dealing with lists. Then, the old and new objects will be using different memory spaces and will be independent of each other.
