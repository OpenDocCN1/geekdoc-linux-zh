
## Ruleset 4 - Final Output Post-rewriting

S4
RS* < @ S+ . ,> S* $1 < @ $2 > $3

# eliminate internal code — should never get this far!
RS* < @ *LOCAL*> S* $1 < @ $]> $2

# externalize local domain info
RS* < S+ > S* $1 $2 $3 defocus
R@ S+: < @ $1 : $+ S: $1 ., $2 .> $3 `route-addr> canonical
Re S* S@ $1 ... and exit

# UUCP must always be presented in old form
R@< @ S- . UUCP $2/$1 u@h.uucp <> h:u

# delete duplicate local names
RS* S S=w @ S=w $1 $2 u@host@host => u@host

## Ruleset 97 - recanonicalize and call ruleset zero

S97
RS* S: S>3 S$
RS* S@ S>0 $1

## Ruleset 0 - Parse Address

S0
RS* S: S>Parse0 $1 initial parsing
R<> $S}local $: <@> special case error msgs

R$* $: $>98 $1 handle local hacks
R$* $: $>Parse1 $1 final parsing

# Parse0 -- do initial syntax checking and eliminate local addresses.
# This should either return with the (possibly modified) input
# or return with a #error mailer. It should not return with a
# #mailer other than the #error mailer.

SParse0
R<0> $0 <0> special case error msgs
R$* : $* ; <>$* $Error $0 5.1.3 $: 'List; syntax illegal for recipient addresses'
R@<0>$> <0 $1> catch '@host' bogosity
R<0>=$> $: <>$> $Error $0 5.1.3 $: 'User address required'
R$* $: <$ $1>
R<> $* <0 [$*] > $* $1 <0 [$2] > $3
R<> $* <$* : $* > $* $Error $0 5.1.3 $: 'Colon illegal in host name part'
R<> $* $1
R$* <0 . $*> $* $Error $0 5.1.2 $: 'Invalid host name'
R$* <0 $* . . $*> $* $Error $0 5.1.2 $: 'Invalid host name'

# now delete the local info -- note *0 to find characters that cause forwarding
R$* <0 > $* $0 $>Parse0 $>3 $1 user0 > user
R<> $*=W . > : $* $0 $-Parse0 $>3 $2 @here:..., ... $2...
RS: <0 $*=W . > S: $(dequote $1) > : <0 $2: > dequote 'foo'@here
R<> $* > $Error $0 5.1.3 $: 'User address required'
R$* <0 $* <0 @ $*=W . > $0 $-Parse0 $>3 $1 $2 $3 ...@here -> ...
RS: S: $(dequote $1) $> <0 *LOCAL* > dequote 'foo'
R<> *LOCAL* > $Error $0 5.1.3 $: 'User address required'
R$* $=O $* <0 *LOCAL* >
R$* <0 *LOCAL* > $0 $>Parse0 $>3 $1 $2 $3 ...@*LOCAL* > : ...
R$* <0 *LOCAL* > S: $1

# Parse1 -- the bottom half of ruleset 0.

SParse1
# handle numeric address spec
R$* <0 [$*] > $* $: $>98 $1 <0 [$2] > $3 numeric internet spec
R$* <0 [$*] > $* $#emptP $0 [$2] $: $1 <0 [$2] > $3 still numeric: send

# short circuit local delivery so forwarded email works
R$=L <0 $*=W . > $#local S: $1 special local names
R$* <0 $*=W . > $#local S: $1 regular local name

# not local -- try mailer table lookup
R&* <@ $+ > $* $: < $2 > $1 < @ $2 > $3 extract host name
R< $+ . > $* $: < $1 > $2 strip trailing dot
R< $+ > $* $: < $[mail&relay $1 ]> $2 lookup
R< $: [ : $+ > $* $>95 < $1 > $2 > $3 check -- resolved?
R< $+ > $* $: $>90 <$1>$2 try domain

# resolve locally connected UUCP links
RS* < @ $-Z , UUCP . > $* #uucp-uudom $0 $2 $: $1 < @ $2 .UUCP . > $3
RS* < @ $-Y . UUCP . > $* #uucp-new $0 $2 $: $1 < @ $2 .UUCP . > $3
RS* < @ $-U . UUCP . > $* #uucp-old $0 $2 $: $1 < @ $2 .UUCP . > $3

# resolve remotely connected UUCP links (if any)

# resolve fake top level domains by forwarding to other hosts

# forward other UUCP traffic straight to UUCP
RS* < @ $+ .UUCP . > $* #uucp-old $0 $2 $: $1 < @ $2 .UUCP . > $3

# user@host.UUCP

# pass names that still have a host to a smarthost (if defined)
RS* < @ $+ > $* $:>95 < $$ > $1 < @ $2 > $3 glue on smarthost name

# deal with other remote names
RS* < @&* > $* $&smtp $0 $2 $: $1 < @ $2 > $3 user@host.domain

# handle locally delivered names
RS=L $local $: $1 special local names
RS+ $local $: $1 regular local names

## Ruleset 5 - special rewriting after aliases have been expanded

$5

# deal with plused users so aliases work nicely
RS+ + * $local $0 $& $: $1
RS+ + $* $local $0 & $2 $: $1 + *

# prepend an empty '*forward host*' on the front
RS+ $1 $: <@ $1

# see if we have a relay or a hub
R< > $+ $: < $H > $1 try hub
R< > $+ $: < $R > $1 try relay
R< > $+ $: < > $1 $&h nope, restore +detail
R< < $+ > $* > $* < < > $1 > + $2 $3 find the user part
R< < $+ > + $* > $* $local $0 $2 $: $1 $&1 strip the extra +
R< < > $+ > $* $0 $1 no +detail

R$: $1 $&h add -detail back in

R< local: $* > $& $>-95 < local $1 > $2 no host extension
R< error: $* > $& $>-95 < error $1 > $2 no host extension
R< $-: $* > $& $>-95 < $1 > $2 > $3 < @ $2 >
R< $* > $& $0 >-95 < $1 > $2 < @ $1 >

## Ruleset 90 -- try domain part of mailertable entry

$90
R$* <$.: . > $& $; $!$2 < $(mailertable . $3 $0 !$!$2 $0 $2 $) > $4
R$* <$-I: $* > $& $>-95 < $2 > $3 > $4 check -- resolved?
R$* < $. > $& $0 >-90 $1 > < $2> $3 no - strip & try again

R< $-[: $*+ > $& $>-95 < $1 : $2 > $3 "_" found?
R< $* > $& $0 !$2 no mailertable match

## Ruleset 95 -- canonify mailer:$user@host syntax to triple

$95
R< > $& $0 $1 strip off null relay
R< error: $. $*+ > $& $!error $0 $(default $1) $: $2
R< local: $* > $& $>CanonLocal < $1 > $2
R< $. : $*+ > $&<$*>$& $# $1 $0 <$3: <$2 >$<$3> use literal user
R< $-: $* > $& $# $1 $0 <$3: <$2> $3 try qualified mailer
R< $-w > $& $0 $2 delete local host
R< $* > $& $relay $0 $1 : $2 $2 use unqualified mailer

## Ruleset CanonLocal -- canonify local: syntax

$CanonLocal

# strip trailing dot from any host name that may appear
R< $* > $& < @ $* > $; < $1 > $2 < @ $3

# handle local: syntax -- use old user, either with or without host
R< > $* < @ $* > $& $local $0 !$$2 $: $1
R< > $& $local $0 $1 $1

# handle local:user@host syntax -- ignore host part
R< $0 > $* : $* < @ $* > $; < $1 > $3 < @ $4

# handle local:user syntax
R< $* > $* <@ $* > $& $local $0 $2>$3 $: $1
R< $* > $& $local $0 $2 $1
