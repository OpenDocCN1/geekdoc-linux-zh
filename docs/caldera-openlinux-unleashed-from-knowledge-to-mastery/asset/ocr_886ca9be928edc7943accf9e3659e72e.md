# **Tip**

vi doesn't actually create a new file until you save it. So if you were to exit vi without typing any text, or without saving any text that you had typed in, the file would not be created. You'll do this a lot when you mistype the name of an existing file you want to edit, and vi comes up thinking you want to create a new file.

Similarly, to edit an already existing file, you just put the name of the file on the command line:

```
$ vi anExistingFile
```

vi then loads the file into a buffer and displays it. If you simply type a simple file name without any slashes ( / ), vi will look for or create the file in the current directory. If you want to edit a file in a different directory, then you need to include the path to the file. Figure 6.2 shows how vi looks just after opening the file /etc/printcap.
