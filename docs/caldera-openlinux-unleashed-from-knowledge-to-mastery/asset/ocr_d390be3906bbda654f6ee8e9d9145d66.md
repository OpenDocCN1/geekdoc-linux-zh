# # Kernel

The kernel controls the loading and unloading of crucial kernel modules.

The Kernel Modules dialog box allows you to view which kernel modules are loaded and which are available for loading, load and unload them, and view a little bit of information about each of them.

As shown in Figure 10.24, the left pane of the Kernel Modules dialog box shows the modules available for loading. To load a module, highlight the module and select the Load button to its immediate right. To get a (very) short description of the module, highlight it and select the Info button to its immediate right.
