# # Installing MySQL

Installing MySQL is quite easy, although you need to compile the source yourself. In some cases this can be difficult, but that is absolutely not the case with MySQL.

# ## Getting MySQL

To install MySQL, you will need to download the source distribution. It can be found on a number of archives around the world. Some of them are shown in Table 26.1.
