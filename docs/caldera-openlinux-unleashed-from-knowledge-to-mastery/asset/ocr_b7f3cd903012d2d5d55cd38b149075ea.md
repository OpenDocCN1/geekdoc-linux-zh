# # Summary

In this chapter, you learned some of the background of SMB, a protocol widely used by Microsoft Windows to share disk and printer resources. We covered Samba configuration including global options, share options, and printer options. We also developed a special printer that produces PDF documents when used as a Windows printer. Next, you learned how to start and stop Samba and how to use smbdtestparm and smbc1ient to test your Samba setup. You learned how to mount SMB shares as part of the Linux file system. Finally, you learned about SWAT, the Web-based Samba configuration tool (and probably wondered why I forced you to plow through the text-based configuration procedure).
