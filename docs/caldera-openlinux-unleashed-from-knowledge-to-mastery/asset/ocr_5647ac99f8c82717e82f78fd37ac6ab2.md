# # What Is MySQL?

MySQL is a multiser and multithreaded database server. It uses the world's most popular database language, Structured Query Language (SQL), to build and manage databases.

Like many other Linux applications, MySQL is a client/server implementation. The MySQL server daemon, mysqld, takes care of the database connections, which can be made from one of the many existing client programs available. In this way, you can easily connect to your MySQL server through Telnet from any computer in the world and get access to your data.

As I mentioned, SQL is the database language used in MySQL. It is a standardized language that is used by many other database servers as well, such as Essentia (http://www.inter-soft.com/products/essentia). If you want to store customer information for your Web site, you can do it in no time with SQL.

The MySQL developers say the main goal with MySQL is to provide a database server that is fast, robust, and easy to use. I must say that they have succeeded.
