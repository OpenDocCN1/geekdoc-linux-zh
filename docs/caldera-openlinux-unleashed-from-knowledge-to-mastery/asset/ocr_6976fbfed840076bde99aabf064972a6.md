```
SParseRecipient
RS$        $: <> $>Parse@ $3 $1
R<?> $* < @ $* >     .- <?> $1 < @ $2 >        strip trailing dots
R<?> $* < @ $* >     $: <?> $(dequote $1 $) < @ $2 >        dequote local part

# if no $0 character, no host in the user portion, we are done
R<?> $* < @ $* > @ $* >     $: <NO> $1 $2 $3 < @ $4>
R<?> $*          $0 $1

R<NO> $* < @ $* >R  $: <RELAY> $1 < @ $2 $3 >
R<RELAY> $* < @ $* >     $0 $>ParseRecipient $1
R<$> $*          $0 $2
```
