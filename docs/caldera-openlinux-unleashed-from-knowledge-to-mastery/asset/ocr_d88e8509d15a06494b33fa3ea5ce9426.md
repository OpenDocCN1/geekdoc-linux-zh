# Disabling a Swap Area

To disable a swap area, use the `swapon` command:

```
# `swapoff /swapfile`
# `swapoff /dev/hdc3`
```

The first example disables swapping on a swap file, and the second disables a swap partition. You can use `swapoff -a` to disable all swap partitions listed in `/etc/fstab`.
