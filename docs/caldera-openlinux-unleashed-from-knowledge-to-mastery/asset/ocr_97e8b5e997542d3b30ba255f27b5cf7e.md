# ## The switch Statement

The switch statement causes a branch depending on the value of an integral expression.

The switch statement looks something like this:

```
```
switch ( expr ) {
case val1: statement_list1
case val2: statement_list2
case val3: statement_list3
default: statement_listN
}
```
```

switch ( x ) {
