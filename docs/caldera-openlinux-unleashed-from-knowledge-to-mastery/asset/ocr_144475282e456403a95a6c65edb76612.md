After typing in the preceding program and saving it as mkplay.c , it can be compiled by typing the following command:

```
> gcc mkplay.c -o mkplay -1mimod
```

This produces a binary file called mkplay that can be used to play SoundTracker and SoundTracker-like modules. Simply specify them on the command line as follows:

```
> mkplay mymodule.mod
```

I encourage you to copy your new binary to /usr/ local/bin so that it will be in your path and accessible from any directory.
