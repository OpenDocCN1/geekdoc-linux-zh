# ## Starting and Stopping the System

If you are using KDE, the KDE login manager has an option for shutting down the system.

> > **Warning**
> >
> > Never shut down a Linux system by turning off the power or pressing the reset button. You could corrupt the file system.

If you are not using KDE, you can shut down the system in a number of ways. You do need root privileges, however.
