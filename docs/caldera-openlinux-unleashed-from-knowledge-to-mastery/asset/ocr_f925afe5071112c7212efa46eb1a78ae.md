modified. But what if we want to be able to modify a global object from our function? The following code shows us how:

```
>>> def gxy():
 ...     global x,y
 ...     x=999
 ...     y=999
 ... 
>>> gxy()
>>> x,y
(999, 999)
```

The **global** statement allows us to handpick from the global namespace objects that we would like to be able to modify. After a **global** statement, any following assignment statements modify the global object directly and do not simply create a new object in the local namespace. The decision to design Python this way was a good one. It means that a common kind of programming error—accidentally modify global objects—is eliminated, and code becomes easier to read and understand. Functions are always cleanly encapsulated, unless we explicitly decide that we want to change this behavior.

# Input

One of the common things that a program needs to do is get input from the user, which is accomplished under Python by using the built-in **raw_input()** function:

```
>>> myinput=raw_input("Gimme some input : ) -- > ")
Gimme some input : ) -->
```

**raw_input()** accepts an optional argument, which will be used as a prompt.
