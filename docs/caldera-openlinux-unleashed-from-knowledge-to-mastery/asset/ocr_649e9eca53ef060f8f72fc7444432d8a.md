Here, the new entry for `vmlinuz-2.2.5-rebuilt` has been given the label `linux` and the original entry has been moved after the new entry and relabeled `Origlinux`. At the `lilo` boot prompt, you can specify `Origlinux` to boot the original kernel if the new one won't boot.

Finally, to actually install the boot loader, type

```
```shell
# /sbin/lilo
```
```

Note that `lilo` and the `/etc/lilo.conf` file have many other options and settings; see `lilo(8)` and `lilo.conf(5)` for details.
