# Listing Directories

You’re not expected to remember all the files and directories contained in a directory. The ls command lists the contents of a directory. If you run ls from your home directory, you’ll see something like this:

```
$ ls
Desktop
```

ls, like almost all UNIX commands, accepts command-line options that change its behavior. An option begins with a dash (-) usually followed by a letter. Type this:

```
$ cd
$ ls -a
```

```
.
.bash_logout	.gcdir	.login	.tcshtre
..
.bashrc	.inputrc	.logout	.wmrc
.Authority	.config	.kde	.profile Desktop
.bash_history	.cshrc	.kdeirc	.seyon
```

You see a cornucopia of files. Files whose names begin with a period (.) are called hidden files and are not displayed by ls unless you use the -a option.

Hidden files are usually used for configuration data or user options. You don’t usually want to know about these files, so they’re not displayed. However, they are just regular files, and you can look at them with ls -a, edit them, rename them, and so on.

# Note

> Most UNIX programs store customization information in files in your home directory. The names of these files usually start with a period so that normal ls listings are not cluttered with dozens of configuration filenames. This, in fact, is the whole reason behind the hidden file concept.

The file named . refers to the current directory, whereas .. refers to the parent of the current directory.
