As you can see from the example, xdv1 gives you many options. First, you can change the magnification up and down and, second, you can browse through the entire set of pages in the dvi file. Additionally, you can view the image in PostScript. Finally, you can put a single image into a different file with the File command.

A lot of dvi format utilities exist. (Most of them are explained as converting utilities in the following, because usually the image is either OK as it is, in which case xdv1 will be entirely adequate, or you want to move it to some other format, and that is a conversion.)
