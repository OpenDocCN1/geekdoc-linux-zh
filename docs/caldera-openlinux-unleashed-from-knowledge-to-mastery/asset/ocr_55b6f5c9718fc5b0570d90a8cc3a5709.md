From the Windows client, connect to the printer \server\generic, but choose the correct Windows printer driver (in this case, for the Lexmark Optra E+). Doing this causes Windows to send the correct data to the printer and the Linux server to pass it straight to the printer unmodified. If you hadn't deleted the 1st line, the Linux server would pass the data through the print filter, mangling it beyond repair.

Alternatively, you can pretend to Windows that all printers on the server are generic PostScript printers. (You can select the Apple LaserWriter driver, for example.) You then use the normal Cidera print filters to convert from PostScript to whatever language the printer actually uses. This results in a simpler setup, but makes it impossible to use any special features that may be available in the Windows printer driver for the actual printer.

# ## A PDF Pseudo-Printer

Portable Document Format (PDF) is a popular document format defined by Adobe for electronically distributing documents. Its main feature is that it preserves all formatting, allowing electronic documents to appear exactly like printed ones. It also allows for efficient interchange of vector graphics.

Normally, to create PDF documents from Windows, you need to purchase Adobe's PDF Writer software. However, with a little cooperation from Linux, Samba, \texttt{ghostscript}, and a small shell script, you can have a free PDF document creator.
