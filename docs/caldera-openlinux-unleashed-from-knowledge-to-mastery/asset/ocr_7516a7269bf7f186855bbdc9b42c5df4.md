Ctrl+C won't get you out of `ed`; it intercepts the interrupt key.

# ## The Shell Prompt Changed and the Shell Ignores Me

If the shell prompt changes to `>` and the shell seems to consume your input without react-
ing, you probably accidentally typed an unmatched quote character. Quote characters, as
is explained in Chapter 3, have special meaning to the shell, and it wants them to be
matched.

To get out of this situation, simply press Ctrl+C.
