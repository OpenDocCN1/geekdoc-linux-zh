xload accepts the standard X toolkit command-line options as well as the following:

+   - `-highlight color`  Specifies the color of the scale lines.
+   - `-jumpscroll n`  Causes the display to advance by n pixels when the graph fills the window. The default is half the window size.
+   - `-label string`  The label to place in the window.
+   - `-update seconds`  Specifies how often to update the display by sampling the load average.

# ## xbiff

The xbiff command monitors your UNIX mail folder. Normally, it displays a picture of a mailbox with the flag down (see Figure 4.5). When you receive mail, the flag goes up and the computer beeps.
