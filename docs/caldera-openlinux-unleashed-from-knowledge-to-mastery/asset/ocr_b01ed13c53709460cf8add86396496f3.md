```
function set(array, idx, value) {
    array[idx] = value
}
BEGIN {
    c[0] = 0
    c[1] = 1
    set(c, 0, "zero")
    printf("c[0] is %s; c[1] is %s\n", c[0], c[1])
}
```

Now test it:

```
$ awk -f array.awk < /dev/null
c[0] is zero; c[1] is 1
```

Note that the function changed `c[0]`.
