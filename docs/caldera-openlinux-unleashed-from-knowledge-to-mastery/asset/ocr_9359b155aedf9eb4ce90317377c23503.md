# xman

The `xman` command gives you a simple point-and-click interface to UNIX manual pages.

> Note
> 
> The KDE help browser is superior; you'll probably want to use it rather than `xman` whenever you can.

`xman` pops up a small window with three buttons. Click on **Manual Page** to bring up the manual page window. (Curiously enough, this initial window contains the `xman` manual page.) Choose a section from the **Sections** menu, and then click on an entry to bring up a man page.

Alternatively, you can type Ctrl+S and type the name of the man page you're looking for.
