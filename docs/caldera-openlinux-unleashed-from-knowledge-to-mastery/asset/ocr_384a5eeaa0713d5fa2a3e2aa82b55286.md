```
class Shape {
public:
virtual double area() = 0;
};

class Square : public Shape {
private:
double iWidth;

public:
virtual double area() { return iWidth * iWidth; }
};

class Rectangle : public Shape {
private:
double iWidth;
double iLength;

public:
virtual double area() { return iWidth * iLength; }
};
```

In this example, the class `Shape` is an abstract base class representing shapes. It has a virtual member function called `area`, which presumably returns the area of the shape. The curious notation `= 0;` declares a pure virtual function. That is, the function is not defined by `Shape` but must be defined by derived classes.

The classes `Square` and `Rectangle` are derived from `Shape` and provide implementations of `area`.

# ## Virtual Functions

In C++, a pointer to a base class can also point to an object of a derived class. No conversion or casting is necessary. This lets you do something like this:

```
int main()
{
Shape *a = new Square;
Shape *b = new Rectangle;
}
```

(The `new` operator allocates memory for an object and calls its constructor.)

Virtual functions differ from normal member functions in the following way:

If you have a pointer to a base class and you use it to call a member function, then:

+   * If the member function is not virtual, then the member function of the class of the pointer declaration is called. For example, if `area` were not virtual, then calling `a->area()` would call `Shape::area`.
