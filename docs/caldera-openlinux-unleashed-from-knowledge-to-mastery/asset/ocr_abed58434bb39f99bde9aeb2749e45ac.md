By using the Installation menu, you can also select a source for new packages to install. This can be your distribution CD or even a server you are attached to through NFS. After the source of new packages (RPMs) is set up, the Software Selection program will provide you with a list of packages you don't have installed (unchecked boxes). All you need to do to install additional packages is check the applicable box(es). (See Figure 10.27.)
