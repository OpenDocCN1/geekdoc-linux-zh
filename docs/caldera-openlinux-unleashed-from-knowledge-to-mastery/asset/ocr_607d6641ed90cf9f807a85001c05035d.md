```
# cd scripts
# . /mysql_install_db
```

Your MySQL installation is now very close to complete. However, I assume you also want the MySQL server to be started at system bootup. For this, you need to make some changes to your /etc/rc.d hierarchy. First, as root, copy the file support-\nfiles/mysql.server (located in your MySQL distribution directory) to your\n/etc/rc.d/init.d directory. Then, make a symbolic link in /etc/rc.d/rc5.d to\n/etc/rc.d/init.d/mysql.server:

```
# cd /etc/rc.d/rc5.d
# ln -s ../init.d/mysql.server S99mysqlid
```

# Note

If your system doesn't start X automatically upon system startup, this means\nthat your system is not configured to start at runlevel 5. You should not make\nthe symbolic link from /etc/rc.d/rc5.d but from /etc/rc.d/rc3.d.

Now, you can either restart your Linux system, or you can start the server manually:

```
# /etc/rc.d/init.d/mysql.server start
```

# Tip

If you get a Permission Denied message when trying to execute the\nmysql.server script, you need to make sure you have permission to do this. cd\nto the /etc/rc.d/init.d directory (as root) and issue the following command:

```
# chmod 755 mysql.server
```

This should solve the problem.

# Tip

The MySQL server can also be easily stopped by executing the mysql.server\nscript with the stop argument instead of start:

```
# /etc/rc.d/init.d/mysql.server stop
```
