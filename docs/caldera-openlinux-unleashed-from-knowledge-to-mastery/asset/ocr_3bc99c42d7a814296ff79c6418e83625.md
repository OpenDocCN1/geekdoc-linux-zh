In this case, there are two board member functions. The first takes no arguments, and the second takes an integer argument specifying how many passengers have boarded. We can write code like this:

```
```cpp
int main()
{
Bus b;
b.board();
b.board(10); // Day-care field trip
}
```
```

The compiler calls the correct function based on its signature. The signature is the number and type of the function’s arguments.

# **Note**

C++ has a number of complicated rules for matching signatures if the types don't match exactly. It tires some built-in conversions in an attempt to get the signatures to match.

C++ also lets you overload operators. For example, suppose you want to overload the += operator so that adding a bus to another bus means that all the passengers from the second bus board the first bus. You could write this:

```
```cpp
class Bus {
// ... etc.
public:
Bus& operator+=(Bus &other)
{
board(other.numPassengers());
other.iPassengers = 0;
return *this;
}
};

int main()
{
Bus a;
Bus b;

b.board(10);
a += b;

cout << a.numPassengers() << " on a and "
<< b.numPassengers() << " on b.\n";
return 0;
}
```
