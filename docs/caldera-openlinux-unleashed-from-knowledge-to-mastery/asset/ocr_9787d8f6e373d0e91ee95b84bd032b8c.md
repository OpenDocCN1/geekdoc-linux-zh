# # Python Power Tool: Embedded Python

Our next example turns Python into an embedded language. “Embedded” refers to the fact that the language exists in a type of file that is not a Python script, in this case, an HTML text file. This means that the text file appears to be in HTML format, except for special sections that are marked to execute as Python statements. This will allow us to pass the text file to our pytext embedded Python interpreter (see Listing 34.6) and have the Python parts executed and the resultant output inserted into our original text at the correct locations. Listing 34.5 is a simple example of how the embedded Python syntax will work. Let's say that we have a text file that looks like this:

# ## LISTING 34.5    Sample Text File

```
<HT>This is sample HTML code</HT>

<!--code

for x in range(0,10):
    print "This is Python!"

-->

<b>Here is some more HTML</b>
```

After passing this file as an argument to our embedded Python interpreter, the output will be as is shown in Listing 34.6.

# ## LISTING 34.6    pytext Output after Processing Text File

```
<HT>This is sample HTML code</HT>
This is Python!
This is Python!
This is Python!
This is Python!
This is Python!
This is Python!
This is Python!
This is Python!
This is Python!
<b>Here is some more HTML</b>
```
