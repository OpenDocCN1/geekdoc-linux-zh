In the first line, we specify a list range using a negative offset. When a list index is preceded by a negative sign, it means that the list items are specified from the right-hand side. For example, the -1 element is 'Ni!' , the -2 element is say, and so on. Now, notice the second command and how we specified a very large range that is out of bounds—Python looks out for us and simply sets the range to the maximum possible "right-side" value, without a fuss. Look at the second to last command and see how we use two negative indexes, which is perfectly legal. This simply evaluates to the slice from the "third from right" (fourth) to the "second from right" (fifth) element. The last element in the slice is not included; this means that mylist[1:1] evaluates to a null list. There is an added benefit relating to this, which we will cover later.
