+   * **Create a printer class** — Click **Classes**; then click **Add Class** and identify a name and location for a printer class. Click **Continue**. Then, from the list of printers configured on your server, select which ones will go into this class.
+   * **View printers** — Without changing printer configurations, you can click **Printers** and view the printers you have configured. For each printer that appears, you can click **Stop Printer** (to stop the printer from printing, but still accept print jobs for the queue), **Reject Jobs** (to not accept any further print jobs for the moment), or **Print Test Page** (to print a page). # Configuring the CUPS server (cupsd.conf)

The cupsd daemon process listens for requests to your CUPS print server and responds to those requests based on settings in the /etc/cups/cupsd.conf file. The configuration variables in cupsd.conf file are in the same form as those of the Apache configuration file (httpd.conf).
