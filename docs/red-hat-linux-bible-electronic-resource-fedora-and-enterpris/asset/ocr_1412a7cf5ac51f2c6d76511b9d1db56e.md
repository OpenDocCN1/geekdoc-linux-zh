# ## Using nccftp

Once you are logged in, there are a few nice features you can use that aren’t available with other FTP clients. Here are some examples:

+   -   **bookmark** — If you are visiting a site that you want to return to, type the bookmark command and type a name to identify that site. The next time you start an `nccftp` session, type the bookmark name as an option. Not only are you logged into the FTP site you bookmarked; you are taken to the directory where you set the bookmark.

+   -   **lls, lcd, lmkdir, lpwd** — There is a set of commands that let you move around the local file system. Just place a letter “l” in front of standard shell commands like `ls`, `cd`, `mkdir`, `pwd`, `rm` and `rmdir` and you can move around and work with your local file system while you are in `nccftp`.

+   -   **rhelp, site** — Use `rhelp` to see commands that are recognized by the remote FTP server. To see commands that are specific to the FTP server, type **help**.

+   -   **Auto-resume** — If you have gotten a broken connection in the middle of a large download, you will appreciate this new feature. After a connection is broken during a download, reconnect to the FTP site and begin downloading the file again in the same local directory. The `nccftp` command resumes downloading where it left off.

# ## Using nccftp for background transfers

If you are moving around to different parts of the FTP site, or jumping between different sites, you might not want to wait around for a file transfer to complete before you can go somewhere else. The `nccftp` command has an excellent feature for placing transfer commands in a spool file and then running them in the background immediately or later.

To select a file for background transfer, use the `bget` command. Here is an example:

```
nccftp /pub > bget wireless.doc
•Spoold: get wireless.doc
nccftp /pub > jobs
---Scheduled-For-----Host-----------------Command-------------------
2003-09-01  18:38 maple                      GET wireless.doc
nccftp /pub > bgstart
Background process started.
Watch the "/home/br/.nccftp/spool/log" file to see how it is progressing

```
