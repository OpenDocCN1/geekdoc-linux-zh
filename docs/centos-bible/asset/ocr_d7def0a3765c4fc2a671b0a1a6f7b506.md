# Part IV Networking

With User mode security (which is being used in this example), any user who wants to access a Samba share must have a regular user account on the Linux system. (Refer to Chapter 10 for information on adding user accounts.)

+   6. To add a user as a user (i.e., one who can access your Samba server), select Preferences ▶ Samba Users. The Samba Users window appears.
+   7. Click “Add User.” The Create New Samba User window appears.
+   8. Provide information for the following fields in the Create New Samba User window and click OK:

+   - **UNIX Username** — Click on this checkbox, and then select the Linux username to which you want to give access to the Samba server.
+   - **Windows Username** — This is the username provided by the user when he or she requests the shared directory. (Often, it is the same as the UNIX Username.)
+   - **Samba Password** — Type the Samba password, then retype it in the “Confirm Samba Password” field.

> NOTE
> 
> There is a bug in system-config-samba that doesn’t show added users in the configuration window. As a result, you can add users but you can’t edit or remove them through the system-config-samba utility (https://bugzilla.redhat.com/show_bug.cgi?id=4671736).

+   9. Repeat the previous step for each user you want to access the Samba shared directory.
+   10. Now that you have configured the default values for your Samba server, add a directory to share by clicking File ▶ Add Share. The Create Samba Share window appears.
+   11. Fill in the following fields shown in the Create Samba Share window:

+   - **Directory** — Type the name of the directory you want to share. For example, you might want to share a user’s home directory, such as /home/timothy.
+   - **Description** — Type any description you like of the Shared directory.
+   - **Basic Permissions** — Select either Read Only or Read/Write. For Read Only, files can be viewed, but not changed, on the shared directory. For Read/Write, the user is free to add, change, or delete files, provided he or she has Linux file access to the particular file.

12. While at this point you should be able to click on the Access tab to allow access to specific users or everyone, there is a bug that prevents you from doing so. For now, you can use the Access tab to make the share accessible to everyone, but you will need to edit the /etc/samba/smb.conf file either with a text editor or using SWAT (see the section titled, “Configuring Shared Directories with SWAT”) to restrict access to specific users.

**Only Allow Access to Specific Users** — This option should allow you to choose which users will be allowed to access the shared directory. For example, if you are sharing a user’s directory (such as /home/timothy), you probably want to restrict access to that directory to the directory’s owner (e.g., t1mothy).
