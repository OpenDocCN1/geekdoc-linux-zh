CentOS offers choices of Web browsers, e-mail clients, and other Internet client applications.

If you are using CentOS as a desktop system, the browsers and e-mail clients make requests to servers available on your LAN or the Internet. Software for configuring a computer as a Web, mail, FTP, or other server type is also included with CentOS systems. Someone starting out with Linux, however, can use applications for using the Internet as they would from any Windows or other desktop system.
