# Summary

CentOS is an Open Source software project that aims at providing an enterprise-quality Linux operating system that can be distributed without cost to its supporters. The project builds its Linux system from source code that has been tested and deployed in mission critical settings.

This book specifically describes CentOS 5, a complete version of which is included on the DVD that comes with this book. Because CentOS aims at compatibility with Red Hat Enterprise Linux systems, CentOS can be used to learn the skills needed to grow your enterprise-class computing skills.
