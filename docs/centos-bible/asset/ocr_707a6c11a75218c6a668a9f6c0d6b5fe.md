# Managing Removable Media

If you are looking for ways to change what happens when you insert CD and DVDs or connect removable storage devices, those preferences can be found on the Removable Drives and Media Preferences window. Select System ➤ Preferences ➤ Removable Drives and Media. You can then change which applications are launched when you insert audio CDs, DVD videos, blank CDs, and other media.
