# ## Automatically Mounting an NFS File System

To set up an NFS file system to mount automatically each time you start your CentOS system, you need to add an entry for that NFS file system to the /etc/fstab file. The /etc/fstab file contains information about all different kinds of mounted (and available to be mounted) file systems for your CentOS system.

The format for adding an NFS file system to your local system is the following:

```
host:directory mountpoint nfs options 0 0
```

The first item (host:directory) identifies the NFS server computer and shared directory. mountpoint is the local mount point on which the NFS directory is mounted, followed by the file system type (nfs). Any options related to the mount appear next in a comma-separated list. (The last two zeros just tell CentOS not to dump the contents of the file system and not to run fsck on the file system.)

The following are two examples of NFS entries in /etc/fstab:

```
flashg:/home/l Timothy/files /media/flashg nfs rwsize=8192, wsize=8192,_netdev 0 0
zarkov:/apps /zarkov/apps nfs noauto,ro,_netdev 0 0
```

In the first example, the remote directory /home/l Timothy/files on the computer named flashg (flashg:/home/l Timothy/files) is mounted on the local directory /media/flashg (the local directory must already exist). The file system type is nfs, and Read (rwsize) and Write (wsize) buffer sizes are set at 8192 to speed data transfer associated with this connection. In the second example, the remote directory /apps on the computer named zarkov. It is set up as an NFS file system (nfs) that can be mounted on the /zarkov/apps directory locally. This file system is not mounted automatically (noauto), however, and can be mounted only as Read Only (ro) using the mount command after the system is already running. The _netdev option means that the entry will not be mounted during the system's boot until the network service has been enabled and is working.

> > **TIP**
> >
> > The default is to mount an NFS file system as Read/Write. However, the default for exporting a file system is as Read Only. If you are unable to write to an NFS file system, check that it was exported as Read/Write from the server.
