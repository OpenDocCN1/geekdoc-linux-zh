# Part III  Administration

+   1.  Insert a blank CD or DVD into your computer's drive. An icon appears on the desktop indicating that a blank disk is ready to be used.
+   
+   2.  Double-click on the “Blank Disc” icon to see the CD/DVD Creator window. Or, select CD/DVD Creator from the window that pops up.
+   
+   3.  Open the folder icon representing your home directory (such as mike’s Home) on the desktop, and browse to the /home folder.
+   
+   4.  Drag-and-drop your home directory from the /home folder onto the CD/DVD Creator window.
+   
+   5.  Add other files and folders you want to back up to the CD/DVD Creator window in the same way.
+   
+   6.  When all the files and folders you want to back up are copied to the CD/DVD Creator window, click “Write to Disc” and the “Write to Disc” pop-up window appears.
+   
+   7.  Type a disk name for the backup medium, and optionally choose the Write speed. The disk name will be used as the name of the mount point if you later open the CD/DVD on the GNOME desktop.
