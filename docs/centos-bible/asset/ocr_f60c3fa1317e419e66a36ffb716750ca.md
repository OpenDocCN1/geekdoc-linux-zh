# Creating Global Samba Settings in SWAT

A group of global settings affects how file and print sharing are generally accomplished on a Samba server. They appear under the [global] heading in the /etc/samba/smb.conf file. To edit global variables, click on the GLOBAIS option on the SWAT window.

# Base Options

The following options relate to basic information associated with your Samba server:

+   - **workgroup** — The name of the workgroup associated with the group of SMB hosts. By default in CentOS, the value for this field is MYGROUP.
