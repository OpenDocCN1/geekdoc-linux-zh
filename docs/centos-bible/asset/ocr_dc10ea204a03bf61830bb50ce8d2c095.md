If a particular module contains features that are not necessary, it can easily be commented out of the preceding list. In fact, it is a good security practice to comment-out unused modules. Similarly, you might want to add the features or functionality of a third-party module (e.g., `mod_perl`, which integrates the Perl runtime library for faster Perl script execution, or `mod_php`, which provides a scripting language embedded within HTML documents) by including those modules in the list.

> **NOTE** Some modules, including `core`, `prefork`, `http_core`, and `mod_so`, are compiled into the `httpd` daemon in CentOS. To see the list of modules compiled into the daemon, type `httpd -l`.
