# # Writable DVD Drives

cdrecord can be used to write both CDs and DVDs. Using a writable DVD drive and the cdrecord command, you can back up your data to DVD-R, DVD-RW, DVD+R, and DVD+RW disks.

> **NOTE:** DVD-R is a write-once DVD format with a capacity of about 4.7 GB. Disks in the DVD-RW format can be written and rewritten many times. DVD-RW is a read-write format that provides for faster writing of data, and DVD+R is a similar write-once format. Typically, a DVD-burning drive will support the plus (DVD-RW, DVD+R) or the minus (DVD-RW, DVD-R) formats. Some drives support both. It is important that you purchase disks compatible with your hardware.

The first trick with recording to DVDs in Linux is to make sure that you have a drive that supports DVD writing. You can check by removing any disks in the CD/DVD drive and typing the following:
