# Monitoring Power Usage on Laptop Computers

To effectively use a laptop computer, you need to be able to monitor and manage the laptop's power usage. Using tools provided in CentOS, you can configure your laptop to:

+   - Monitor the battery level
+   - Notify you when the battery is low.
+   - Notify you when the battery is fully charged.
+   - Show when the laptop is plugged in
+   - Suspend the current session.

CentOS offers the ACPI facility to handle power management. ACPI can also do thermal control, motherboard configuration, and change power states.

Many older laptops do not include support for ACPI in the BIOS, while for some newer laptops, ACPI may be required. To check whether ACPI is supported on your CentOS system, you can use the dmesg command after a reboot. For example, type:

```
# dmesg | less
```

Page through the output looking for lines beginning with ACPI. On a computer where ACPI wasn't working, I saw the message "ACPI: System description tables not found."
