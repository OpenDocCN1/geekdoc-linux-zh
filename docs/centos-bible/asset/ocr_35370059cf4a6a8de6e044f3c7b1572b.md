# Creating Backups and Restoring Data

![](bbox=[0.21, 0.13, 0.9, 0.54])

After `cdrecord` finishes writing the CD and our shell prompt returns, delete the file system image file `/var/tmp/connie.iso`. Label the CD appropriately and store it in a safe place.

If you need any files that were copied to the CD, just return the CD to the CD drive. If it doesn't automatically open a window displaying the contents of the CD, type `mount /media/cdrecord`. Open `/media/cdrecord` in a folder window and copy the files you want.

Note that the mount point name for the CD drive may be something other than `/media/cdrecord`. The way that the udev facility works is to use generic names such as `cdrecord`, `disk`, or `cdrom` for CDs or DVDs that include no volume ID. However, if a volume ID was added to the CD header when the CD was created, that name will be used as the mount point. For example, a game CD with a volume ID of GAMEDISK would be mounted as `/media/GAMEDISK`.

> See Chapter 7 for more information on `cdrecord`. You can also learn more about installing and troubleshooting writable CD drives from the CD-Writing-HOWTO. If you are using a desktop CentOS system, you might want to use a graphical CD writer instead. Chapter 7 also describes the K3B graphical tool for copying and burning CDs and DVDs.
