To launch the MySQL Administrator window, type `mysql-administrator`. If your MySQL database server is running, as described later in this chapter, enter the server hostname (such as `localhost`), username (such as `root`), and password. The MySQL Administrator window will appear, as shown in Figure 23-1.

At this point, you can use the MySQL Administrator window to find information about your MySQL server, back up and restore data, or select Catalogs to display information about each database. You can even select the Health option to view all kinds of information about the activity and usage of your server machine.

> **NOTE** If you want to try another MySQL graphical utility, check out the `mysql-query browser` package. That tool is made for designing MySQL tables and running queries.
