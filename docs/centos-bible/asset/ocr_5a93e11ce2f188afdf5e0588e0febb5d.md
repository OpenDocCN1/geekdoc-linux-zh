# Troubleshooting

The media that are included with this book contain a complete version of CentOS that you can either test-drive (Live CD) or install (DVD) on your computer system. If you have problems installing or running CentOS Linux on a particular computer system, consult the CentOS forums at `www.centos.org/modules/newbb/`.
