# ## Getting a Domain Name

Domain names are available from dozens of different domain registrars these days. You can check the availability of domain names from any of these registrar's web sites, such as 1&1 (http://1and1.com), GoDaddy (http://www.godaddy.com), or Network Solutions (http://www.networksolutions.com). You can also use the whois command that comes with CentOS.

The *top-level domain* (TLD) in which you register your own domain should reflect the type of business or organization that you represent. Commercial businesses typically use the .com TLD. Newer TLDs, however, such as .biz and .info, are now available for domains that represent a business community or for information about businesses and individuals. Some people choose .ws to represent their web site, although the .ws TLD is actually owned by the government of Western Samoa, which agreed to license it as a general-purpose web site domain. (See www.icann.org/en/tlds for more information on TLDs.)

Other common TLDs are .net, which was originally intended for network services companies, and .org, which was originally intended for organizations. Although those domains were intended for special purposes, there are really no restrictions on who can get and use those domain names.

Institutions of higher education in the United States use the .edu TLD. A TLD that has recently become available for public use is the .us TLD, for organizations within the United States (public K-12 schools in the United States typically use the .us TLD). Countries outside of the United States each already has its own TLD.

# ## Checking Domain Name Availability

With an active Internet connection, you can use the whois command to check if a domain name is available in the .com, .net, .org, or .edu domains. Following is an example of using whois to check the availability of the domain google.com:

```
```
$ whois google.com
[Querying whois.verisign-grs.com]
[Whois.verisign-grs.com]

Whois Server Version 2.0
```
```
