# ## Administration

+   1. **Keyboard** (*system-config-keyboard*) — Choose the type of keyboard you are using, based on language.
+   2. **Language** (*system-config-language*) — Select the default language used for the system.
+   3. **Logical Volume Management** (*system-config-lvm*) — Display and manage logical volumes and related disk partitions.
+   4. **Network** (*system-config-network*) — Manage your current network interfaces, as well as add interfaces.
+   5. **Printing** (*system-config-printer*) — Configure local and network printers.
+   6. **Root Password** (*system-config-rootpassword*) — Change the *root* password.
+   7. **Samba** (*system-config-samba*) — Configure Windows (SMB) file sharing. (To configure other Samba features, you can use the SWAT window; SWAT is described in Chapter 17.)
+   8. **Services** (*system-config-services*) — Display and change which services are running on your CentOS system at different run levels.
+   9. **Users & Groups** (*system-config-users*) — Lets you add, display, and change user and group accounts for your CentOS system (see Figure 9-3).
