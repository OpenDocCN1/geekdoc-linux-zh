# ## Browsing the Web with Firefox

The Firefox Web browser offers real competition to Microsoft Internet Explorer. Firefox is lightweight (so it performs fast), includes many easy-of-use features, and was built with security as a high priority. If you haven't switched to CentOS yet, you can get Firefox for Windows, Mac OS X, and other Linux systems. With the CentOS distribution that comes with this book, you can try Firefox out right now.
