## System Requirements

Make sure that your computer meets the minimum system requirements listed in this section. If your computer doesn't match up to most of these requirements, you may have a problem using the contents of the media that come with this book.

### For Linux or Windows Systems

- PC with a Pentium-class processor running at 400 MHz or faster; for best performance, we recommend a Pentium 4 or AMD equivalent running at 700 MHz or better.
- At least 256 MB of total RAM installed on your computer; for best performance, we recommend at least 512 MB.
- Ethernet Network Interface Card (NIC) or modem with a speed of at least 28,800 bps
- A CD-ROM drive if you are testing CentOS with the Live CD or a DVD drive if you are installing from the DVD disk
- A VGA graphics card that is capable of at least 1024 × 768 resolution
- At least 3 GB of available disk space if installing CentOS

If your system does not satisfy these requirements, you may still be able to install CentOS on your system with one of the alternative installation methods discussed in Chapter 2.

> The media included with this book are for 32-bit PC architectures. They will not work on other computer architectures. However, you can download ISO images of CentOS installation media for x86-64-bit (x86 64) architectures from the CentOS download page (http://mirror.centos.org/centos/5/isos/).

## Using the Installation DVD

To install CentOS from the DVD to your hard drive, follow these steps:

1. Insert the DVD into your computer's DVD drive.
2. Reboot your computer system, booting from the DVD drive. If your system is not already configured to boot from a DVD before booting from the hard drive, you may need to modify your computer's BIOS settings in order to give precedence to booting from the DVD drive.
3. Press the [Enter] key to install CentOS.
4. During installation, you are asked questions about your computer hardware and the network connections. After you have completed each answer, click **Next**.

> For more information on installing CentOS 5 from the DVD, follow the instructions provided in Chapter 2 and in the README files on the DVD.

If for some reason you don't have your DVD handy, you can download different installation images from http://mirror.centos.org/centos/5/isos/. If you have a DVD drive on another computer on your LAN, see Chapter 2 for information on setting up a CentOS install server, so you can install CentOS on your chosen machine over your LAN.

Repositories can help you find extra, useful software packages that are not in CentOS. Some of these sites act as yum or apt repositories that allow you to download sets of dependent packages (see the descriptions of yum and useful third-party software repositories in Chapter 5).

## Using the CentOS Live CD

The CentOS Live CD that is included with this book can be used to help prepare your computer before installation with the DVD, or if you just want to try CentOS out without installing it to your system's hard drive. You can boot up to a working GNOME desktop that works like most desktop computer systems installed to hard disk. If you don't like the system, then reboot, remove the CD, and your computer will return to the way it was.

1. Insert the CentOS 5 Live CD into your CD drive and reboot.
2. From the boot screen, either let the CD time out and boot or press any key to see other selections. From the boot menu, highlight “Boot” and then press [Enter].
3. When you see the login screen, you can select a language or just let the login prompt time out. (No password is required.) The GNOME desktop starts up.

## What’s on the Media

The following sections provide a summary of the software and other materials you’ll find on the media that accompany this book.

### Operating System and Applications

The Live CD provides a version of CentOS 5 that you can test-drive on a 32-bit, x86-compatible computer system. The installation DVD provides the necessary installation and software packages to install CentOS on a new system or as an alternate operating system on an existing computer system. You can install it as an alternate operating system by either repartitioning your disk to provide a partition where CentOS Linux can be installed directly, or as an alternate operating system on an existing Microsoft Windows system that has at least 4 GB of free space without repartitioning.

### Source Code

From time to time, you may want to recompile the Linux kernel or other software package that comes with CentOS. Like the binary software packages, the source code packages are available (http://soredirect.centos.org/centos/5/os/SRPMS/). To work with CentOS source code packages, here is what you need:

- **kernel-devel** — The kernel-devel package comes with the CentOS binary packages. Included in the package name is the version number of the kernel it contains. The source code for the current kernel is contained in the /usr/src/kernels directory, ready to be recompiled, if the kernel-devel package is installed.
- **SRPMS Directory** — Source code for each binary package outside of the kernel that is included in CentOS is available from any CentOS repository. Install the source code package for the software that interests you (the name ends in .src.rpm) and a copy of that software in subdirectories of the /usr/src/redhat directory.

To do the actual compilations, you will need to install at least the gcc package.
