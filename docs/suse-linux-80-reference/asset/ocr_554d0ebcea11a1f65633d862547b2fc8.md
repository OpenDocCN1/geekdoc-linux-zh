```
earth: # chmod -v a+rx /usr/local/myprinterfilter/asciifilter
```

Use lprsetup to create an additional printer queue (see lprsetup --help).  
Here, af stands for “asciifilter”, the queue name.

```
earth: # lprsetup --add af --lprng --device /dev/lp0 --raw --sf
```

In the af entry of /etc/printcap search for the  
line and replace /usr/lib/lpd/filter/bin/if with  
/usr/local/myprinterfilter/asciifilter. The entire line should  
look like this:

```
af:\
        :cm=lpdfilter drv= method=raw color=no:\
        :method=ascii color=no:\
        :lp=/dev/lp0:\
        :sd=/var/spool/lpd/af:\
        :lf=/var/spool/lpd/af/log:\
        :af=/var/spool/lpd/af/acct:\
        :if=/usr/local/myprinterfilter/asciifilter:\
        :la=mx#0:\
        :tr=\f:
```

*File 35: /etc/printcap: Custom Filter*

Stop and restart the printer spooler with:

```
earth: # rclpd stop  
earth: # rclpd start
```

Now all users should be able to print with lpr -Paf ascii-file
