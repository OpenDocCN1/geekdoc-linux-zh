Using the Alien (a lien) Perl script, it is possible to convert or install an “alien” binary package. This tries to convert “old” TGZ archives to RPM before installing. This way, the RPM database can keep track of such a package after it has been installed. Beware: `alien` is still “alpha” software, according to its author – even if it already has a high version number.
Do not forget YaST2 (see also Section *Selecting Software* on page 18).
