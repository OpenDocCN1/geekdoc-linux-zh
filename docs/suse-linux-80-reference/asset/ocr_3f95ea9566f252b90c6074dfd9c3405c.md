# Network Integration

Currently TCP/IP is the standard network protocol. All modern operating systems can communicate via TCP/IP. Nevertheless, Linux also supports other network protocols, for example, IPX (previously) implemented by Novell Netware or Appletalk used by Macintosh machines. We will only discuss the integration of a Linux machine into a TCP/IP network. To this end, integrating a host with an ethernet card into a LAN (Local Area Network) will be discussed. To integrate “exotic” arctek, token ring, or FDDI network cards, find further help on this in the kernel sources /usr/src/linux/Documentation.

# Changes in SuSE Linux 8.0

With SuSE Linux 8.0, extensive changes have been made to the network configuration. Therefore, even an experienced network administrator should read the file /usr/share/doc/packages/sysconfig/README. All changes are documented there, particularly the ones made after this manual was printed, which can only be found in this file.

The most important modifications of the network configuration are the following:

+   - There are no longer network specific settings to be made in the file `/etc/rc.config`.
+   - The directory `/etc/sysconfig/network` now contains the network-related configuration files.
+   - `ifconfig` and `route` are replaced by package `ip` and package `iproute2`.

For detailed information on how these changes affect network configuration, see the relevant sections.

# Preparing

The machine has to have a supported network card. Normally, the network card will already be recognized during installation and the appropriate driver mounted. See if your card has been integrated properly by entering the command `ifstatus eth0`. The output should show the status of the network device eth0.
