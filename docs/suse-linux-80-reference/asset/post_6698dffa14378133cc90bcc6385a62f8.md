## Installation Suggestions

After the hardware has been detected and the mouse configured, YaST2 provides information about the detected hardware and the suggested installation and partitioning selections. If you modify any of the suggestions, YaST2 returns you to this screen after the changes are complete. The following sections are devoted to the various configuration settings available.

### Mouse

If YaST2 did not recognize your mouse type automatically, use `Tab` until ‘Change’ is highlighted. Press `Space` and the arrow keys until the menu item ‘Mouse’ is selected. Press `Enter` to open a mouse type selection screen, illustrated in Figure 2.4 on page 10.

To select your mouse type, use the up and down arrow keys. Your mouse documentation should include a description of the mouse type. Select the mouse type from the list. Confirm your selection by pressing `Alt` + `T` or pressing `Tab` then confirming with `Enter`.

Now, test to see if your mouse is working. If the mouse cursor on the screen follows your mouse movements, your mouse is configured correctly. If the cursor does not move, select a different mouse type and try again.

![](img/a4b6c994843f3fbd688003f4cabfa48f_20_0.png)

*Figure 2.3: Selecting Installation Type*

### Time Settings

In this screen (Figure 2.5 on page 11), choose between Local Time and GMT in the field marked ‘Set hardware clock to’. Your selection depends on the BIOS clock settings for your computer. If the hardware clock is set in the BIOS to GMT, SuSE Linux automatically reflects Standard and Daylight Savings time changes.

### Keyboard Layout

Select your preferred keyboard layout in this screen. The initial setting corresponds to the language chosen. Adjust this if needed. Type any special characters in the test field to make sure the keyboard settings are correct. If the characters displayed do not correspond with those typed, try a different layout. ‘Next’ returns to the suggestions.

## Partitioning

The suggested partitioning appears with a confirmation option, allowing you to accept, change, or discard the suggestion. See *More Partitioning Tips* on page 16 regarding automatic entries in `/etc/fstab`. Clicking “Change” opens the “Partitioner”.

YaST2 shows all partitions present on the selected hard disk (Figure 2.6 on page 12). Any free storage space is shown and automatically selected. To assign more disk space to Linux, you can assign more partitions following the order from the last to the first partition. If you have three partitions, it is not possible to use the second one for Linux and the first and third for other operating systems.

If you choose “Discard”, a dialog appears containing the hard disk selection (Figure 2.7 on page 13). All the hard disks on your system are listed here. Decide where to install SuSE Linux. There is no risk associated with selecting the hard disk, as no changes are made at this time.

The menu “Advanced Settings, Manual Partitioning” shows the previous partitioning of your system, which can be manually modified or reused for your new system.

By clicking “Entire hard disk”, the entire hard disk and all its partitions are activated for Linux. If you already installed a Windows operating system with a FAT file system, you will be asked if you want to delete or shrink the Windows partition (refer to *Resizing a Windows Partition* on page 12). **Caution:** All partitions and data existing on this hard disk will be lost.

![](img/a4b6c994843f3fbd688003f4cabfa48f_22_0.png)

*Figure 2.5: Selecting the Keyboard Layout and Time Zone*

> **Note**
>
> If you decide on manual partitioning, create a swap partition. Click ‘Format’ then ‘File system: Swap’ in the ‘Create Partition’ menu. The swap partition is responsible for supplying momentarily required data to the hard disk to free up more RAM space for the most important and most frequently needed data.

During the course of the installation process, YaST2 will verify whether there is sufficient space for a minimum installation and whether the three standard partitions used by Linux can be created.

If this is not the case, you will be prompted to alter your selection. If there is enough storage space, YaST2 will apply your settings so the entire hard disk or selected partitions can be distributed over the three default partitions: boot, swap, and root.

> **Caution**
>
> If you choose ‘Use entire hard disk’, you will lose all the information on your hard disk!

### Resizing a Windows Partition

This section assumes the hard disk selected contains Windows 9x or ME. The following instructions also apply to Windows XP, if it is installed on a disk formatted with the FAT file system. However, if Windows NT, 2000, or XP is installed on an NTFS file system, the partition size cannot be reduced.

If you have a computer on which Windows XP was preinstalled, it is most likely running on an NTFS. If you want to reduce the partition size, it is first recommended to repartition the whole system and reinstall your Windows XP using your XP installation CDs later, preferably with FAT32 as your file system so that in the future you will be able to resize all partitions.

If there is not enough space for SuSE Linux, choose between two options: either completely delete Windows from the hard disk or reduce the Windows partition to create enough space for the SuSE Linux installation. See Figure 2.8 on page 14.

![](img/a4b6c994843f3fbd688003f4cabfa48f_24_0.png)

*Figure 2.7: Selecting the Hard Disk*

YaST2 gives a reasonable resizing suggestion for your Windows partition. However, it can be modified manually using the method described below. If you decide to delete Windows, all data will be irrevocably lost during Linux installation.

> **Caution**
>
> The Windows Resizer only works if your computer has a hard disk with exactly one Windows partition (usually the case for most preinstalled Windows computers). Otherwise, you will have to manually partition your hard disk.

Before reducing your Windows partition, boot your Windows PC. Then run both scandisk and defrag programs. scandisk and defrag scan the files used by Windows then condense these files to the beginning of the hard disk. This speeds up the reduction process.

After you go to ‘Partitioning’ in the suggestion screen and click ‘Edit’ in the screen that follows, use the mouse or arrow keys to highlight the Windows partition. Next, click ‘Reduce FAT Partition’. The ‘Windows Resizer’ can also be accessed by first selecting ‘Discard’ then ‘Entire Hard Disk’. Next, you will be asked whether you want to reduce or completely delete the Windows partition. Choosing the resizing option allows you to access the Resizer as well.

## Manual Partitioning

With the “Partitioner”, the partitions of your hard disk can be manually modified. Partitions may be added, removed, or changed. When started, you will see a list of disks and the partitions on them. Disks are listed as whole devices (e.g., `/dev/hda`) while partitions are listed as parts of the devices (e.g., `/dev/hda1`). The size, the type, and the mount point are also important parameters. The mount point describes where the partition is connected in the Linux file system tree.

### Creating a Partition

To create a new partition:

- Select the disk on which to create a partition from the list.
- Select ‘Create’. A dialog appears asking for the type of partition. You can create up to four primary partitions or up to three primary partitions and one extended partition. Within the extended partition, you can create several more partitions.
- Select the format and, if required, the mount point of the new partition. Details of this can be found in the following section *Adding a Partition* on the current page.
- Select ‘OK’ to apply your changes.

The new partition will be listed in the partition table. Selecting ‘Next’ writes the partition table to disk and does the formatting, if necessary.

### Adding a Partition

To add a partition to the file system tree, perform the following:

- Select the partition.
- ‘Edit’ the partition and set the parameters:
  - File system ID (if you do not want to format the partition): This can be “Linux swap”, “Linux”, “Linux LVM”, or “Linux RAID”.
