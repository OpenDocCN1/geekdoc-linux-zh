# Linux in the Network

Today, networked computers are so prevalent that stand-alone machines not at least connected online part of the time are becoming a rare sight. Linux, really a child of the Internet, offers all the necessary networking tools and features for integration into all types of network structures.

An introduction to the customary Linux protocol, TCP/IP, will follow. The various services and special features of this protocol are then discussed.

After introducing the basics, you will be shown how to set up network access using a network card with the help of YaST2. The central configuration files will be discussed and some of the most essential tools described.

You can basically configure your entire network using YaST2. Because network configuration can get rather complicated, we will only describe the fundamental mechanisms and the relevant network configuration files in this chapter.

The configuration of Internet access with PPP via modem, ISDN, or other connection can be completed with YaST2. It is described in the *Configuration Manual*.

# TCP/IP — The Protocol Used by Linux

Linux and other Unix operating systems use the TCP/IP protocol. To be exact, it not a single network protocol, but a family of network protocols that offer various services. TCP/IP was developed based on an application used for military purposes and was defined in its present form in an RFC in 1981. RFC stands for “Request for Comments”. They are documents that describe various Internet protocols and implementation procedures for the operating system and its applications. Access these RFC documents directly over the web at http://www.ietf.org/. Since then, the TCP/IP protocol has been refined, but the basic protocol has remained virtually unchanged since 1981.
