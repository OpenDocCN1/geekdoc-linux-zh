+   - `modinfo`  
+     Shows detailed module information.

# /etc/modules.conf

`/etc/modules.conf` affects how modules are loaded. Refer to the man page for depmod (`man depmod`).  
Enter the parameters for modules that access hardware directly in this file. Such modules may need system-specific options (e.g., CD-ROM driver or network driver). The parameters entered here are for the most part identical to those given to the boot prompt of the kernel; for example, with LILO (see Section *Kernel Parameters at the Boot Prompt* on page 240), but in many cases the names used at the boot prompt are different (to compare these, see Section *modprobe Parameters* on page 255). If a module failed to load, try specifying the hardware in this file and use modprobe instead of modprobe to load the module.

# Kmod — the Kernel Module Loader

The kernel module loader is the most elegant way to use modules. Kmod performs background monitoring and makes sure the required modules are autoloaded when modprobe is run as soon as the kernel’s functionality is activated. To use Kmod, set the corresponding variable in the kernel configuration ‘Kernel module loader’ (CONFIG_KMOD).  
Drivers needed to access the root file system should be compiled directly into the kernel. Do not configure your SCSI driver or your file system (normally: ext2) as modules.

> > **Caution**  
> > As SuSE Linux uses initrd (initial ramdisk) and integrates the SCSI driver, for example, via initrd, you must make sure after compiling your own kernel that you adjust the variable INITRD MODULES in the file `/etc/sysconfig/kernel` (Section *Security and Local Administration Services* on page 316) and comment out the `initrd` line in `/etc/lilo.conf` (see Section *Possible Difficulties — Self-Compiled Kernels* on page 280). If you do not do this, the kernel will hang when booted.  
> > **Caution**

Kernel modules come in handy for rarely-used functionality, such as parport and printer support, drivers for floppy drives, and for certain file systems used only sporadically.
