# Zone Entry Structure

```
```text
zone "my-domain.de" in {
    type master;
    file "my-domain.zone";
    notify no;
};
```
```

*File 48: Zone Entry for my-domain.de*

After zone, the name of the domain to administer is specified, my-domain.de, followed by and in a block of relevant options enclosed in curly braces, as shown in File 48. To define a “slave zone”, the type is simply switched to slave and a name server is specified that administers this zone as master (but can also be a “slave”), as shown in File 49.

```
```text
zone "other-domain.de" in {
    type slave;
    file "slave/other-domain.zone";
    masters { 10.0.0.1; };
};
```
