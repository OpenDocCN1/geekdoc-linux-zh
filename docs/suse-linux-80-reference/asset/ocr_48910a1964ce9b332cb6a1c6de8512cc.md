By selecting ‘Minimum system’, install a fully functional Linux operating system geared towards a text-based mode. It is recommended if you have limited space available on your hard disk.

+   - **Minimum graphical system without KDE**  
+     The minimum system supplemented with the X Window System. FVWM2 and Windowmaker provide simple graphical interfaces.

+   - **Default system**  
+     If you opt for ‘Default system’, a well-balanced, basic software environment will be installed on your system. This contains everything you might need at the beginning. It includes a graphical user interface, games, CD players, editors, and more.

+   - **Default system with Office**  
+     In the selection ‘Default System with Office’, a wide array of office applications are available, which incorporate word processing, spreadsheets, drawing tools, and a daily planner. It makes your PC an office workstation. If you need a well-balanced software system for a fully functional office environment, choose this option.

> **Note**  
> You can choose additional components and software. To increase storage space for SuSE Linux at this point, click ‘Back’ until you reach *Partitioning* on page 10. You then can add more hard disk space.
