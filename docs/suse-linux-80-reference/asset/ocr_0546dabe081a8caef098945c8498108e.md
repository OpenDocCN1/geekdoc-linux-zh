In the following, it is assumed that a driver application for the printer exists for the SuSE Linux version you have or that it can be downloaded from the Internet. It is also assumed that this driver application functions as described above and that you are familiar with working with Unix sources (e.g. with `.zip` and `.tar.gz` archives, as well as `.rpm` packages). For more information, see also Section *RPM — the Distribution Package Manager* on page 69. After decompressing such an archive, you will typically find installation tips in README or INSTALL files or in a subdirectory labeled doc. In the case of the `.tar.gz` archives, the actual driver application most often has to be compiled and installed.

The following also runs on the assumptions that the driver application exists in `/usr/local/bin/printerdriver`, the Ghostscript driver `pbmraw` with a resolution of 600 dpi is required, and that the printer is connected to the first parallel port `/dev/lp0`. The Ghostscript driver and resolution actually required are ultimately specified in the documentation for the particular driver application.

First, the gdi queue is created with lprsetup (as user root):

```
```sh
earth:  # lprsetup -add gdi -lprng --device /dev/lp0 \
        --driver pbmraw --dpi 600 --size a4dj --auto --sf
```
```

The command must now be entered in one line without backslash (`\`). Create the script `/etc/lpd/filter/gdi/post` as follows:

```
```bash
#!/bin/bash
/usr/local/bin/printerdriver {driver-specific_parameters}
```
```

*File 31: `/etc/lpd/filter/gdi/post`: Running the Driver Application*

You may need to enter the appropriate (driver-specific_parameters). The driver-specific parameters required are specified in the documentation for the driver application.

The script must be made executable for all users. Then, restart the printer spooler:

```
```sh
earth:  # chmod a+rx /etc/lpd/filter/gdi/post
earth:  # rclpd stop
earth:  # rclpd start
```
```

Now, all users can print by giving the following command:

```
```sh
newbie@earth:  > lpc -Pgdi filename
```
```
