```
source gravis.cfg
source gsdrums.cfg
source gssfx.cfg
source xmap2.cfg
```

To use sound fonts instead of the Gravis instrument patches, modify the `/usr/share/timidity/timidity.cfg` file. To use the Vintage Dreams sound font with timidity++, for example, you will only need one `timidity.cfg`, consisting of only a single line:

```
soundfont: /usr/share/sounds/sf2/Vintage_Dreams_Waves_v2.sf2
```

More can be found on this topic in `/usr/share/doc/packages/timidity/README.sf`.

# Starting timidity++ with a Graphical Interface

There are few applications other than timidity++ that can provide the user with such a large number of possible application interfaces. You can see a list of available interfaces by entering `man timidity`. “Athena Widget Interface” is a sophisticated interface that is started with `/usr/bin/timidity -iatv`.

> Note
> 
> timidity cannot, by any means, be started from inside the `/usr/share/timidity` directory.

A recording of the first movement of the First Brahms Symphony is an impressive MIDI file, demonstrating the full orchestral sound capacity. It can be found at `http://www.classicalarchives.com/brahms.html`.

# The ALSA Server timidity++ Mode

Start timidity++ in ALSA server mode with

```
/usr/bin/timidity -iA -B2,8 -Os &
```
