# Selecting Software

If you chose ‘Detailed selection…’, choose different groups of software packages, such as multimedia or games, to install in addition to the previously selected software packages (Figure 2.11). Choose the desired software from the entries provided.

At this stage in the installation, YaST2 offers two additional options:

+   - **Commercial software…**  
+     If you are interested in the commercial Linux applications, go to Section *Commercial Software* on the next page.
+   
+   - **Selecting individual packages…**  
+     You may also select individual software packages within a group. Go to Section *Selecting Individual Applications* on page 20.

In both cases, YaST2 returns you to the detailed selection.
