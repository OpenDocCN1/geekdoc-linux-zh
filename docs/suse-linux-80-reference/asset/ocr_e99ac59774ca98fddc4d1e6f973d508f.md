Ghostscript not only provides printer drivers, but can also process PostScript files for screen output (see Section *Printing from Applications in the Basics manual) or even convert it to PDF. Use the gv program (package gv) to easily view the output of PostScript files on the screen in a graphical user interface for Ghostscript.

Ghostscript is a very sophisticated application with numerous command-line options. As well as the man page for gs (man gs) and the list of Ghostscript drivers, the most essential documentation can be found in /usr/share/doc/packages/ghostscript/catalog.devices and

file:/usr/share/doc/packages/ghostscript/doc/stp/README
If started directly, Ghostscript opens a dialog with its own prompt GS>. Exit it with quit.

The help command gs -h lists the most important options and outputs the current list of devices. If a single driver supports several models, only basic driver descriptions such as uniprint and stp will appear. The parameter files for uniprint and the stp models are listed in more detail in /usr/share/doc/packages/ghostscript/catalog.devices

# Examples for Working with Ghostscript

In /usr/share/doc/packages/ghostscript/examples, find PostScript sample files. The “colorcir” is good for printer tests (file:/usr/share/doc/packages/ghostscript/examples/colorcir.ps).

# X11 Output

In X, the graphical interface, view a PostScript file on the screen with the gs command:

```
newbie@earth:  > gs -r60 \
    /usr/share/doc/packages/ghostscript/examples/colorcir.ps
```

The resolution is specified with the option -r, which must be compatible with the output device (printer or screen). Try it with -r30, for example. To quit the program, press (Ctrl) + (C) in the terminal from which gs was started.
