## Introduction

### What is Linux?

The actual “Linux” is the kernel, the “heart” of every UNIX-related operating system. The kernel alone does not constitute an entire operating system, however. Many of the tools in Unix are free software. Because of this, almost all standard Unix tools are also available in Linux. Together with the kernel, they form the Linux operating system.

Many of these tools are GNU versions of these Unix programs that offer enhanced features over the originals. Of these, the GNU C/C++ Compiler, one of the best compilers available, is probably the most famous program. In addition, there are many tools, small and large, which can be used from the command line, in shell scripts, or as full-fledged programs — from the shell, file, and text utilities such as sed, awk, and perl to complete environments such as vim or Emacs.

What makes Linux complete is XFree86™ (current version, 4.2.0), the X Window System (currently X11 Release 6.6) for PC-based systems. This port is part of the official distribution of the X Consortium, Inc., and is fully compatible with that standard.

All these components, together with many other tools, applications, and amusements, make up the system known as Linux. A large amount of free software is available and there are many ways to put a Linux system together. At this point, the Linux distributions come into play, in this case, SuSE Linux. A distribution is a selection from a wide palette of free software. The end product is, in the case of the SuSE Linux CDs, over 1000 software packages.

> **Note**
>
> SuSE Linux includes, in addition to free software — software for which the source code is included on the CD-ROMs, software packages that, for different reasons, SuSE can only offer in compiled form.

Because most distributions are offered free on the Internet, updating your system does not necessarily mean buying a new distribution. The aim of this book is to make SuSE Linux accessible to the reader.

### Typographical Conventions

The typographical conventions used in this guide are explained in Table 1.1.

| Text layout | Meaning |
|---|---|
| `YaST` | programs |
| `/etc/passwd` | file or directory names |
| `{file}` | when entering a command, file should be replaced by the actual value. Do not enter the angle brackets. |
| `PATH` | the environment variable with the name `PATH` |
| `192.168.1.2` | value of a variable |
| `ls` | the command `ls` |
| `news` | the user news |
| `earth:~ # susehelp` | root shell in the `~` directory stands for the “home directory” of the respective user. Enter the command `susehelp`. Here, earth is an example of the name of a computer (host name). |
| `newbie@earth:/tmp > ls` | in the shell of the user newbie in directory `/tmp`, enter the command `ls` |
| `C:\> fdisk` | at the DOS prompt, type the command `fdisk` |
| `Alt` | key to press, here the key “Alt” |
| `Ctrl + Alt + Del` | when “+” is used, press all listed keys at the same time. Keys to press sequentially are separated by a space only. |
| `"Permission denied"` | system messages |
| `"System update"` | menu entry |
| `[SuS02a]` | Reference to a book. See the bibliography in the appendix on page 445 |
