# Configuring Additional Parallel Ports

A second parallel port (/dev/lp1, which can be addressed by the standard I/O address 278 (hexadecimal) (e.g., set by a jumper on an ISA interface card), is also configured by a line in /etc/modules.conf (File 16).

```
alias parport_lowlevel parport_pc
# options parport_pc io=0x378 irq=none
# If you have multiple parallel ports, specify them this way:
options parport_pc io=0x378,0x278 irq=none
```

*File 16: /etc/modules.conf: Two parallel ports*

# Special Plug-In Cards: ISA PnP and PCI

If the IO address of an additional parallel port is currently unknown, you will have to determine this.

**ISA PnP cards**  If possible, define permanent values for IO addresses and, if necessary, for interrupt and mode (e.g., via jumper).

Otherwise, the values for IO address, interrupt, and mode will not be written to the ISA PnP card until Linux is started. The values entered can be verified by viewing the Linux boot messages in the /var/log/boot.msg file or with the help of the pnpdump command (package isapnp).

**PCI cards** The IO addresses and the interrupt appropriate for a PCI card can be viewed by entering `/sbin/lspci -v | less`. The result is shown in Output 12.

```
earth:  # /sbin/lspci -v | less

...
00:0a.0 Parallel controller: ...
        ...
        Flags: stepping, medium devsel, IRQ 10
        I/O ports at b400
        I/O ports at b000
        I/O ports at a800
        I/O ports at a400
...
```
