# Selecting Individual Applications

As with the commercial packages, the individual software selection allows you to select additional software packages. Under ‘Detailed Software Selection’, if you have chosen the option ‘Select single packages’, you will get a screen as shown in Figure 2.13. Click the software packages to select. If you change your mind and decide not to install one of the packages selected, simply click it again to deselect it.

> > **Caution**
> >
> > In some cases, deselecting certain packages can lead to a reduction of your system’s functionality.

![](bbox=[0.295, 0.366, 0.827, 0.626])

With Extras, select or deselect complete series or groups. You can also save your software selection or load a previous software selection that you, for example, saved from a previous installation of SuSE Linux. Saving the software selection during the installation does not make much sense, as the file would be overwritten. It is better to go to the software installation module in YaST2 and save your entire selection there. It is then available for your next update.
Click ‘Next’ or ‘OK’ to continue the installation.
