
### File System (if you want to format the partition)

This can be “Swap”, “Ext2”, “ReiserFS”, or “JFS”. “Swap” is a special format that makes the partition usable as virtual memory. Every system should have at least one swap partition of at least 128 MB. By default, “ReiserFS” is used for partitions. Like “JFS”, it is a “Journaling File System”. A journaling file system enables a quick recovery from a system crash or a bad unmount. Also ReiserFS is very fast in handling lots of small files. “Ext2” is not a journaling file system. It is “rock solid” and good for smaller partitions, as it does not require too much disk space for the management.

### Mount Point

Set the directory where the new partition should be connected in the file system tree. If you select the last entry in the list, enter your own directory name here. “Swap” is used for the special file system “Swap”.

- Select “Next” to format and enable the partition.

### More Partitioning Tips

If the partitioning is performed by YaST2 and other partitions are detected on the system, these partitions will also be entered in `/etc/fstab` to enable easy access to this data. You can see a sample in File 1.

```text
/dev/sda1        /data1  auto    noauto,user 0 0
/dev/sda8        /data2  auto    noauto,user 0 0
```

*File 1: /etc/fstab: Data Partitions*

The partitions, regardless of whether they are Linux or FAT partitions, are specified with the options noauto and user. This allows any user to mount or unmount these partitions if needed. For security reasons, YaST2 does not automatically enter the exec option here. However, to run programs from there, you can enter this option yourself. This procedure can wait until encounter system messages such as “bad interpreter” or “Permission denied”.

## LILO — Installation

To start SuSE Linux or any other operating system on your computer, you need a program to help you determine whether you want to use SuSE Linux or another operating system when starting (or booting) the machine. One such program is the boot manager LILO, the “Linux Loader”.  

By default, YaST2 suggests installing the boot loader to the Master Boot Record (MBR) of the hard disk. If you have more than one hard disk, it will know which is used to boot by reading the BIOS settings. This is shown in the “suggestion screen” under “System boot”.  

YaST2 recognizes if you are operating systems other than SuSE Linux. Depending on the hardware, there are various ways to install LILO. The following provides you with an introduction to the LILO boot manager. A detailed description can be found in Chapter Booting and Boot Managers. When you select your LILO configuration by clicking ‘System boot’, the following dialog appears as shown in Figure 2.14.

![](img/a4b6c994843f3fbd688003f4cabfa48f_32_0.png)

*Figure 2.14: LILO — Installation*

Decide in this dialog how and where to install LILO. There are four options for this.

1. To `/dev/hda` (in the MBR of your hard disk)
2. Create boot floppy
3. Do not install LILO (other boot manager)
4. To another partition

In most cases, select Option 1, which installs LILO in the Master Boot Record (MBR) of your boot disk. Use this option if SuSE Linux is your only operating system or you want to use LILO as the boot manager for multiple operating systems. However, be sure your operating system can be booted by LILO (usually, MS-DOS and Windows 9x/ME, NT, and 2000 accept LILO).

If you are using multiple operating systems and are unsure whether they can be booted by LILO or want to leave your previous boot mechanism intact, choose the option ‘Create boot floppy’. Then insert this disk whenever you want to boot Linux. If this floppy is not in the drive, the current boot configuration is used. Later, you can always configure LILO as the boot loader in YaST2, so LILO allows you to choose the operating system to boot at the boot prompt.

If you already installed a boot manager and want to integrate SuSE Linux in this boot manager, select ‘Do not install LILO’. After you install SuSE Linux, reconfigure the existing boot manager and integrate SuSE Linux in the boot procedure.

If your system requires additional kernel parameters each time you restart the system, enter these parameters in the designated field. Usually, you do not need to enter anything here.

The ‘Linear Option’ enables LILO to work with older hardware if the normal settings do not function. Most users will not need this option.

The option ‘Activate LILO Partition’ is also not normally needed. There are only some systems where the BIOS can only boot from “activated” partitions.

## Starting Installation

A click on ‘Next’ accepts the suggestions and any changes you made. You will then be taken to the green confirmation screen. After clicking ‘Yes’ here, the installation of all your selected settings begins. The installation usually lasts between fifteen and thirty minutes, depending on your machine’s performance and your software selection. While it is installing, you will see information about SuSE Linux. Click ‘Details’ to view information about the progress of your installation instead.

## System Configuration

After the installation of your system and selected software is complete, you need to make three more important settings before you can work with SuSE Linux. Define a password for the system administrator, create a normal user, and configure your monitor.
