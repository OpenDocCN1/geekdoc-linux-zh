# Boot Disk with LILO

Create a more capable boot disk with a greeting prompt and kernel parameters by transferring the complete LILO booting start machinery onto the disk (see Section *The Components of LILO* on page 93). The disk needs a file system for this purpose. The Minix file system is best suited for this.

To do this, proceed as follows:

+   - Create a Minix file system on a new and empty floppy disk and mount the disk to, for example, `/mnt` with the commands.
+   
+     ```text
+     earth:  # /sbin/mkfs.minix -c /dev/fd0 1440
+     earth:  # /bin/mount /dev/fd0 /mnt
+     ```
+   
+     If your floppy drive supports higher capacities, you can try different values, such as `/dev/fd0u1722` or `1722`.
+   
+   - Now copy your kernel files and the LILO file `/boot/boot.b` to `/mnt`, for example, onto the floppy disk.
+   
+   - Optional: create a message file `/mnt/message`.
+   
+   - Create a `lilo.conf` on `/mnt`. — Specify the actual root partition instead of `Your_Root_Device`. See File 6 for an example.

```
```text
# LILO Configuration file bootdisk
# Start LILO global Section
boot=/dev/fd0                 # Installation: Floppy
install=/mnt/boot.b           # Of course LILO and
map=/mnt/map                  # map fit onto floppy!
message=/mnt/message          # optional
prompt
timeout=100      # Wait at prompt: 10 s
vga = normal     #
# End LILO global section

# Linux bootable partition config begins
image = /mnt/vmlinuz           # default
    root = /dev/Your_Root_Device  # Here is your root partition!
    label = linux
# Linux bootable partition config ends
```
