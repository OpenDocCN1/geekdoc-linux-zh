`floppy={value}`

For `{value}`, the following values may be set (Table 10.4):

| Parameter | Description |
|---|---|
| `all_drives` | more than two floppy disk drives |
| `asus_pci` | denies access to 3rd and 4th floppy disk drives |
| `daring` | use only with reliable controllers — enhances performance |
| `0,daring` | opposite of daring |
| `{addr}/two_fdc` | if the value `{addr}` is omitted while using a secondary floppy controller, a port address of `0x370` is set. |
| `thinkpad` | IBM Thinkpad machines |
| `0,thinkpad` | not a Thinkpad machine |
| `omnibook` | Omnibook computers |
| `nodma` | for Omnibook computers |
| `dma` | Standard |
| `nofifo` | if a "Bus master arbitration error" occurs |
| `fifo` | Standard |
| `0xX,fifo_depth` | FIFO threshold standard `0xA` |
| `unexpected_interrupts` | show warnings if something unexpected happens. |
| `no_unexpected_interrupts` | and... |
| `L40SX` | this value is the opposite of `unexpected_interrupts`. |

*Table 10.4: Kernel Parameter Values for floppy*

+   - *Logitech bus mouse*
+     `bmouse={irq}`
+   - *XT hard disk controller*
+     `xd={type},{irq},{addr},{dma}`
