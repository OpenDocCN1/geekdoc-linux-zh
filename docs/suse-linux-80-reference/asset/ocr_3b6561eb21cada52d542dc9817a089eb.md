+   - If you are using an initrd, add it to `lilo.conf` as described in Section *Boot Loaders* on page 278.
+   - Install LILO with this `lilo.conf`:
+   
+     ```
+     earth:  # /sbin/lilo -C /mnt/lilo.conf
+     ```
+   - Unmount the floppy
+   
+     ```
+     earth:  # /bin/umount /mnt
+     ```
+   - Check your boot disk at the next system boot to verify it works.

# Sample Configurations

If Linux is the only operating system on your machine, there is nothing left to do. All the required steps have already been taken by YaST. The following sections give some example configurations for multisystem computers. More information can be found under `/usr/share/doc/howto/en/mini/Linux+*.gz`.

# DOS/Windows 95/98 and Linux

*Requirements:* There must be at least a primary partition each for DOS/Windows 95/98 and Linux below the 1024-cylinder limit (Section LILO Locations on page 94).

For this case, we have already discussed a configuration (File 3 on page 97) — only the settings for root, image, and other need adaptation. LILO is installed in the MBR.

Save your `/etc/lilo.conf` and be sure you have a Linux boot disk. Windows 95/98 is especially inclined to eliminate “foreign” MBRs. If you can still boot Linux using your boot disk, this problem is quickly solved with the command

```
earth:  # /sbin/lilo
```

This completes your LILO installation.
