# System

Under ‘System’, you will have the option of reconfiguring the boot mode, creating a boot or module disk, or setting the language and time zone. In the “Configuration” manual, find all the necessary information.

# Sysconfig Editor

The files where the most important SuSE Linux settings are stored are located in the `/etc/rc.config` directory. This directory used to be a central file, `/etc/rc.config`, where all the configurations were stored. The sysconfig editor presents the settings options in an easy-to-read manner. The values can be modified and subsequently added to the individual configuration files in this directory. In general, it is not necessary to manually edit them, however, because these files will automatically be adjusted when installing a package or configuring a service.

> **Caution**
> 
> Do not modify in the `/etc/sysconfig` files if you lack previous experience and knowledge. It could do considerable damage your system.
