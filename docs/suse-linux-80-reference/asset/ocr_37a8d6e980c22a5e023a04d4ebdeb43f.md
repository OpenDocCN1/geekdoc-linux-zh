In most cases, select Option 1, which installs LILO in the Master Boot Record (MBR) of your boot disk. Use this option if SuSE Linux is your only operating system or you want to use LILO as the boot manager for multiple operating systems. However, be sure your operating system can be booted by LILO (usually, MS-DOS and Windows 9x/ME, NT, and 2000 accept LILO).

If you are using multiple operating systems and are unsure whether they can be booted by LILO or want to leave your previous boot mechanism intact, choose the option ‘Create boot floppy’. Then insert this disk whenever you want to boot Linux. If this floppy is not in the drive, the current boot configuration is used. Later, you can always configure LILO as the boot loader in YaST2, so LILO allows you to choose the operating system to boot at the boot prompt.

If you already installed a boot manager and want to integrate SuSE Linux in this boot manager, select ‘Do not install LILO’. After you install SuSE Linux, reconfigure the existing boot manager and integrate SuSE Linux in the boot procedure.

If your system requires additional kernel parameters each time you restart the system, enter these parameters in the designated field. Usually, you do not need to enter anything here.

The ‘Linear Option’ enables LILO to work with older hardware if the normal settings do not function. Most users will not need this option.

The option ‘Activate LILO Partition’ is also not normally needed. There are only some systems where the BIOS can only boot from “activated” partitions.

# ## Starting Installation

A click on ‘Next’ accepts the suggestions and any changes you made. You will then be taken to the green confirmation screen. After clicking ‘Yes’ here, the installation of all your selected settings begins. The installation usually lasts between fifteen and thirty minutes, depending on your machine’s performance and your software selection. While it is installing, you will see information about SuSE Linux. Click ‘Details’ to view information about the progress of your installation instead.

# ## System Configuration

After the installation of your system and selected software is complete, you need to make three more important settings before you can work with SuSE Linux. Define a password for the system administrator, create a normal user, and configure your monitor.
