# Output 12: Output of lspci -v for a PCI Interface Card

Two IO addresses 400 (hexadecimal) apart, belong together to one parallel port — in our example one port has b000 and b400, and the other, a400 and a800. You may have to experiment to see which of either IO address works. The configuration entry in /etc/modules.conf may then look like in File 17.

```
```text
alias parport_lowlevel parport_pc
options parport_pc io=0x378,0xb400,0xa800 irq=none,none,none
```

# Activating and Testing the Parallel Port

After rebooting, the parallel port is activated.
Rather than rebooting, as user root, it is sufficient to update the dependency list of the kernel modules and to unload then reload the kernel modules pertaining to the parallel port.

```
```text
earth: # depmod -a 2>/dev/null
earth: # rmmod lp
earth: # rmmod parport_pc
earth: # rmmod parport
earth: # modprobe parport
earth: # modprobe parport_pc
earth: # modprobe lp
```

# USB Connections

A USB interrupt must be activated in the computer’s BIOS. For example, in an Award BIOS, set the entry such as ‘USB IRQ’ to Enabled in the menu pertaining to ‘PNP AND PCI SETUP’.
