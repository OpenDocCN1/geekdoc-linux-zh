# OpenGL—3D Configuration

OpenGL and GLIDE are 3D interfaces for 3Dfx Voodoo cards in Linux. Almost all modern 3D applications use the OpenGL interface, so 3D hardware acceleration can only be implemented over the OpenGL interface, even in the case of 3Dfx Voodoo cards. Only older applications still use the GLIDE interface directly. The OpenGL driver for 3Dfx Voodoo cards also uses the GLIDE interface. Direct3D from Microsoft is not available in Linux.
