*File 64: Option 15 der Firewallkonfiguration*

The comments above show the syntax to follow. First, the IP address and the netmask of the “internal networks” accessing the proxy firewall. Second, the IP address and the netmask to which these clients “send” their requests. In the case of web proxies, specify the networks 0/0, a wild card that means “to everywhere”. After that, enter the “original” port to which these requests are sent and, finally, the port to which all these requests are “redirected”. As Squid supports more protocols than HTTP, redirect requests from other ports to our proxy, such as FTP (port 21), HTTPS, or SSL (port 443). The example uses the default port 3128. If there are more networks or services to add, they only need to be separated by a single blank character in the corresponding entry.
