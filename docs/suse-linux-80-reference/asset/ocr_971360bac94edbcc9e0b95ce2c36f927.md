# Output 3: rpm -q -i rpm

Option -f only works if you specify the complete file name with its full path.
You can name as many file names as you want. For example,

```
earth: # rpm -q -f /bin/rpm /usr/bin/wget
```

will lead to the following result:

```
rpm-3.0.3-3
wget-1.5.3-55
```

If only part of the file name is known, a shell script must be implemented (see
File 2). The file name found is passed as a parameter when calling up the script.

```
#! /bin/sh
for i in `rpm -q -a -l | grep  $1`; do
    echo "\"$i\" is in package:"
    rpm -q -f $i
    echo ""
done
```
