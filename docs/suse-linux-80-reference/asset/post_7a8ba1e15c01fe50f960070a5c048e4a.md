  `AM53C974=(host-id),(target-id),(rate),(offset)`

| Variable | Values / Meaning |
|---|---|
| `{host-id}` | the host adapter’s SCSI ID (often 7) |
| `{target-id}` | the device’s SCSI ID (often 0...7) |
| `{rate}` | 3, 5, 10 MHz/s, max. transfer rate |
| `{offset}` | transfer mode; 0 = asynchronous |

If the host adapter seems to “swallow” some packages, reduce the maximum transfer rate for this device (e.g., the first CD-ROM SCSI drive `/dev/scd0` with ID 5) on the SCSI bus with:

*Example:* `AM53C974=7,5,3,0`

Individual transfer rates and transfer modes can be specified for each device, meaning that `AM53C974=x,x,x,x` could apply up to seven times to a single host adapter.

## (E)IDE controllers and ATAPI devices

Numerous parameters are available to configure the (E)IDE controllers and the devices connected to them.

- *ATAPI CD-ROMs and other devices connected to an (E)IDE controller*
  `hd(x)={trouble}`

| Variable | Values / Meaning |
|---|---|
| `{x}` | `a, b, ..., n` 1st to 8th hard disk<br>`a` master on 1st IDE controller<br>`b` slave on 1st IDE controller<br>`c` master on 2nd IDE controller<br>`d` slave on 2nd IDE controller<br>etc. |
| `{trouble}` | `noprobe` — if probing for a new hard disk causes any problems<br>`none` — ignore CMOS entry and do not probe<br>`nowerr` — ignore the `WRERR_STAT` bit<br>`cdrom` — if the device was wrongly detected as a hard disk or if booting fails completely<br>`autotune` — use the fastest PIO mode<br>`slow` — to insert a long pause after each seek operation, which makes the device operate very slowly, but sometimes might help as a last resort |

The driver supports up to six IDE interfaces and, according to the ATA 2 specification, two devices can be connected to each of these.

To tell the kernel you have an ATAPI CD-ROM drive connected as master to the 2nd IDE controller, pass the parameter `hdc=cdrom`. Also see `/usr/src/linux/Documentation/ide.txt`.

*Example:* `hdd=cdrom`

- *Hard Disk*

  `hd(x)=(cylinders),(heads),(sectors)[,(write)][,(irq)]`

| Variable | Values / Meaning |
|---|---|
| `{x}` | `a, b, ..., n` 1 to 8. Hard Disk |
| `{cylinders}` | number of cylinders |
| `{heads}` | number of heads |
| `{sectors}` | number of sectors |
| `{write}` | cylinders after which write compensation is used |
| `{irq}` | interrupt |

If the BIOS is an old one, it is possible that the geometry of the hard drive is not recognized correctly. The correct parameters will then be passed on so the kernel can still access the complete hard disk.

Example: `hdc=1050,32,64`

- **EIDE controller chipsets**
  `ide0=(chipset)`

Some EIDE controllers have faulty chipsets or cause problems if the secondary controller is used.

Many of these chipsets are now supported in the kernel. This support needs to be specially activated, however, using a kernel parameter.

The chipsets shown in Table 10.2 are configurable.

**Table 10.2: Special EIDE Chipsets**

| Chipset | Description |
|---|---|
| CMD 640 | This chipset is found on many motherboards. Since it contains many bugs, the kernel offers a special support that recognizes the chip and bypasses the problems. In some cases, use of the secondary controller is only possible by using this special support. In PCI systems, this chip is automatically recognized. For VLB systems, the following parameter is needed: `ide0=cmd640_vlb`. |
| RZ 1000 | This chip is used on many motherboards that use the Neptune chipset and it is buggy. If support for this chip is activated, the system works a little slower, but reliably. An additional activation with a kernel parameter is not required. |
| DTC-2278 | Only activating this driver via `ide0=dtc2278` makes it possible to use the secondary controller. |
| Holtek HT6560B | The following parameter is needed to activate the secondary controller. `ide0=ht6560b`. |
| QDI QD6580 | If this driver is activated, it enables a higher speed: `ide0=qd6580`. |
| UMC 8672 | For activating the secondary controller, the following parameter is needed: `ide0=umc8672`. |
| ALI M1439/M1445 | The following parameter is needed for activating the secondary controller: `ide0=ali14xx`. |
| PROMISE DC4030 | For activating the secondary controller, the following parameter is needed: `ide0=dc4030`. CD-ROMs and tapes on the secondary controller are not supported yet. |

If the chipset does not belong to the list of known faulty chipsets, and still is not recognized, the following parameters can be added instead:

```
`ide{number}={basis}|{control}|{irq}`
```

| Variable | Values / Meaning |
|---|---|
| `{number}` | adapter number, usually 0 or 1, but also 3 or 4 |
| `{basis}` | base address of the adapter, usually `0x1f0`, `0x170`, `0x1e8` or `0x168` |
| `{control}` | control register of the adapters, usually `0x3f6`, `0x376`, `0x3ee` or `0x36e` |
| `{irq}` | interrupt of the adapters, usually 14, 15, 11 or 10 |

If the chipset does not belong to the list of known faulty chipsets, but still causes problems, the following parameters can be added instead:

```
`ide{number}={tune}`
```

| Variable | Values / Meaning |
|---|---|
| `{number}` | adapter number, usually 0 or 1, but also 3 or 4 |
| `{tune}` | autodetune the highest possible PIO value is tried, not supported by all chipsets; noautotune no improvement in speed; serialise no time overlapping of operations with the next adapter |
