# Example for Configuring a GDI Printer

GDI printers cannot usually be used in Linux. See Section *GDI Printers* on page 192.
However, special driver applications exist for some GDI printers. These driver applications usually supplement Ghostscript by converting the Ghostscript output to a printer-specific format. Such driver applications often only allow for limited print options, such as black-and-white only.
Ghostscript and the driver application thus work together as described in the following (see also Section *A Little About Ghostscript* on page 215):

+   1. Ghostscript resolves the PostScript data into a matrix containing individual pixels. The matrix data is then relayed to the appropriate Ghostscript driver in suitable format and resolution.
+   
+   2. The matrix data is then converted to the printer-specific format by the driver application.
