# network - Directory for Network configuration

# network/config -

```
DEFAULT_BROADCAST="+"
CHECK_FOR_MASTER="yes"
NO_ROUTING_INTERFACETYPES="lo dummy"
CHECK_DUPLICATE_IP="yes"
CHECK_CONNECTIONS="yes"
CLOSE_CONNECTIONS="false"
```

When shutting down routing, all net connection can be closed (not always
useful). If CLOSE_CONNECTIONS is set to true, /etc/init.d/route
will scan /proc for active network connections and send term signals to
the respective processes.

```

```

Fully qualified host name, which contains host and domain name.
