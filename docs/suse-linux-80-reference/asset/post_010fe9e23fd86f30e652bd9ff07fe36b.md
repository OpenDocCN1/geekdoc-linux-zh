
In the following, it is assumed that a driver application for the printer exists for the SuSE Linux version you have or that it can be downloaded from the Internet. It is also assumed that this driver application functions as described above and that you are familiar with working with Unix sources (e.g. with `.zip` and `.tar.gz` archives, as well as `.rpm` packages). For more information, see also Section *RPM — the Distribution Package Manager* on page 69. After decompressing such an archive, you will typically find installation tips in README or INSTALL files or in a subdirectory labeled doc. In the case of the `.tar.gz` archives, the actual driver application most often has to be compiled and installed.

The following also runs on the assumptions that the driver application exists in `/usr/local/bin/printerdriver`, the Ghostscript driver `pbmraw` with a resolution of 600 dpi is required, and that the printer is connected to the first parallel port `/dev/lp0`. The Ghostscript driver and resolution actually required are ultimately specified in the documentation for the particular driver application.

First, the gdi queue is created with lprsetup (as user root):

```sh
earth:  # lprsetup -add gdi -lprng --device /dev/lp0 \
        --driver pbmraw --dpi 600 --size a4dj --auto --sf
```

The command must now be entered in one line without backslash (`\`). Create the script `/etc/lpd/filter/gdi/post` as follows:

```bash
#!/bin/bash
/usr/local/bin/printerdriver {driver-specific_parameters}
```

*File 31: `/etc/lpd/filter/gdi/post`: Running the Driver Application*

You may need to enter the appropriate driver-specific_parameters. The driver-specific parameters required are specified in the documentation for the driver application.

The script must be made executable for all users. Then, restart the printer spooler:

```sh
earth:  # chmod a+rx /etc/lpd/filter/gdi/post
earth:  # rclpd stop
earth:  # rclpd start
```

Now, all users can print by giving the following command:

```sh
newbie@earth:  > lpr -Pgdi filename
```

## Print Filter Troubleshooting

The correct debugging level is activated by removing the comment sign # in front of the respective line in the main print filter script `/usr/lib/lpdfilter/bin/if`.

```
# DEBUG="off"
# DEBUG="low"
DEBUG="medium"
# DEBUG="high"
```

*File 32: /usr/lib/lpdfilter/bin/if: Debugging Level*

For DEBUG="low", only the stderr output of `/usr/lib/lpdfilter/bin/if` will be saved to a file `/tmp/lpdfilter.if-$$.XXXXXX` ($$ is replaced by the process number and XXXXXX by an arbitrary or unique string).

For DEBUG="medium", the stderr output of the scripts in `/usr/lib/lpdfilter/filter/`, which are invoked by `/usr/lib/lpdfilter/bin/if`, will be saved to file with the format of `/tmp/lpdfilter.name-$$.XXXXXX` (replace name with the name of the script to run and `$$.XXXXXX`, as described above).

For DEBUG="high", the output will not be sent to the printer, but to a file in the format of `/tmp/lpdfilter.out-$$.XXXXXX` ($$.XXXXXX is substituted as described above).

These files should be deleted each time before performing any more tests by entering `rm -v /tmp/lpdfilter*`.

## A Little About Ghostscript

Ghostscript accepts PostScript and PDF data as input and contains numerous Ghostscript drivers, known as devices in Ghostscript, for converting to other formats. The Ghostscript conversion takes place in two steps:

- 1. The PostScript data is converted to a matrix. The image described by the PostScript language is resolved into a fine matrix pattern of individual pixels. This process takes place independently of the respective Ghostscript driver. The finer the matrix (the higher the resolution), the higher the output quality, but also the more processor and memory consumption, since the number of dots in the matrix quadruples when the resolution is doubled.

- 2. Finally, the image resolved to a dot matrix is now converted to the desired format, the desired printer language.

Ghostscript not only provides printer drivers, but can also process PostScript files for screen output (see Section *Printing from Applications in the Basics manual) or even convert it to PDF. Use the gv program (package gv) to easily view the output of PostScript files on the screen in a graphical user interface for Ghostscript.

Ghostscript is a very sophisticated application with numerous command-line options. As well as the man page for gs (man gs) and the list of Ghostscript drivers, the most essential documentation can be found in /usr/share/doc/packages/ghostscript/catalog.devices and
file:/usr/share/doc/packages/ghostscript/doc/index.html
file:/usr/share/doc/packages/ghostscript/doc/use.htm
file:/usr/share/doc/packages/ghostscript/doc/Devices.htm
file:/usr/share/doc/packages/ghostscript/doc/hpdj/gs-hpdj.txt
file:/usr/share/doc/packages/ghostscript/doc/hpijs/hpijs_readme.html
file:/usr/share/doc/packages/ghostscript/doc/stp/README

If started directly, Ghostscript opens a dialog with its own prompt GS>. Exit it with quit.

The help command gs -h lists the most important options and outputs the current list of devices. If a single driver supports several models, only basic driver descriptions such as uniprint and stp will appear. The parameter files for uniprint and the stp models are listed in more detail in /usr/share/doc/packages/ghostscript/catalog.devices

## Examples for Working with Ghostscript

In /usr/share/doc/packages/ghostscript/examples, find PostScript sample files. The "colorcir" is good for printer tests (file:/usr/share/doc/packages/ghostscript/examples/colorcir.ps).

## X11 Output

In X, the graphical interface, view a PostScript file on the screen with the gs command:

```
newbie@earth:  > gs -r60 \
    /usr/share/doc/packages/ghostscript/examples/colorcir.ps
```

The resolution is specified with the option -r, which must be compatible with the output device (printer or screen). Try it with -r30, for example. To quit the program, press (Ctrl) + (C) in the terminal from which gs was started.

## Conversion to PCL5e or PCL6

A PostScript file is converted to the printer-specific format for a PCL5e or PCL6 printer with the command

```text
newbie@earth:~ > gs -q -dNOPAUSE -dSAFER -sOutputFile=/tmp/out.prn \
    -sDEVICE=ljet3 -r300x300 \
    /usr/share/doc/packages/ghostscript/colorcir.ps quit.ps
```

where the command is given in a single line without backslash (`\`). The assumption is also made that the file /tmp/out.prn does not exist yet.
