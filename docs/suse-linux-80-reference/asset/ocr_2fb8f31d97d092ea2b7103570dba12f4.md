In simple text, every character is encoded as a given number. A code table defines the characters displayed for each number. Different characters can be displayed on the screen for the same encoding, depending on which code table an application uses. Only codes from 0 to 255 are possible for standard charsets. Codes 0 to 127 are the ASCII characters (the “normal” letters, numbers, and special characters, but no country-specific special characters). These are always the same. Codes 128 to 255 are used for country-specific special characters, such as umlauts, tildes, and accents. Since there are considerably more than 128 different country-specific characters, codes 128 to 255 are not the same everywhere, but reserved for specific national character settings depending on geographical location. ISO-8859-1 (or Latin 1) is the encoding for Western European languages, and ISO-8859-2 (or Latin 2) is the encoding for Central and Eastern European languages. According to ISO-8859-1 encoding, code 161 outputs an upside-down exclamation mark, but in ISO-8859-2, a large A with an ogonek.

# Configuring the Parallel Port

The parallel port `/dev/lp0` is configured by entering a line in `/etc/modules.conf` (File 15).

```
alias parport_lowlevel parport_pc
options parport_pc io=0x378 irq=none
# If you have multiple parallel ports, specify them this way:
# options parport_pc io=0x378,0x278 irq=none
```

*File 15: /etc/modules.conf: First parallel port*

io stands for the first address of the parallel port. The entry `irq=none` puts the parallel port into “polling mode” rather than interrupt driven mode. This is generally a better option and is slower only on very old computers.

For these settings to function, the following values for the parallel port (if available) must be set in the BIOS or over the computer’s firmware:

+   - IO address 378 (hexadecimal)
+   - Interrupt 7 (irrelevant in polling mode)
+   - Mode Normal, SPP, or Output-Only (other modes do not always function)
+   - DMA is disabled (should be in Normal mode)
