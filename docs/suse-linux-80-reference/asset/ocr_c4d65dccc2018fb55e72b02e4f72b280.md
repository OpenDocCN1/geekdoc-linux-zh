# Analog Inputs and Outputs

The amplification for the analog-to-digital and digital-to-analog converters is defined under ‘Analog Volume’. The ‘DAC’ sliders are responsible for the output channels. Use the ‘ADC’ sliders for the input channels. Use the radio buttons to switch the controls between +4 dBu and -10 dBV. The first configuration is intended for audio professionals. The -10 dBV configuration is used for household purposes.
