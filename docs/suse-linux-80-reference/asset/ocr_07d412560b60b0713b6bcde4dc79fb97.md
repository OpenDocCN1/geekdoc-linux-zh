# Commercial Software

All commercial software products are listed in a separate series. Here, find a wide variety of applications, such as office products, games, and much more. If you have selected the option ‘Commercial Software’ under ‘Detailed Software Selection’, see a screen, as in Figure 2.12, in which to select the commercial software packages to install. Click the desired software package to select it. If you change your mind about installing one of the packages selected, simply click it again to deselect it.

> **Note**
> 
> Some of the software packages that can be installed here do not correspond to full versions that can be purchased separately. Some offer limited functionality or can be used only for a certain length of time. Others require registration. The relevant license agreements provide more information.
