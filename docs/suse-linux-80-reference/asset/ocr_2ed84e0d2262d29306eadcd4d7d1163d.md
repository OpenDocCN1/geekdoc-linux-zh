# Annotation

+   - **workgroup = working group**  
+     On any Windows machine, Samba is assigned like a work group where it can be seen in the `network` environment. `workgroup` is the default work group for Windows for Workgroups.

+   - **guest account = nobody**  
+     Samba needs a user name listed in `/etc/password` that only has limited permissions for certain tasks. If public shares (parameter `public = yes`) are defined, all operations are executed with this user ID. Even if no public share is defined, the account guest account has to be defined for the Samba machine to appear in the networking environment.

+   - **keep alive = 30**  
+     Windows machines tend to crash from time to time. If they leave open connections behind, it could happen that the server recognizes them much later. If you do not want Samba to waste resources, tell it to check whether the client is still alive by setting keep alive = 30.

+   - **os level = 2**  
+     The parameter os level = 2 specifies that Samba provide browser services to WfW and Windows 95. If there is an NT machine on the network, Samba will not provide these services to it, but use the NT machine itself.

+   - **Kernel oplocks = false**  
+     Unfortunately, since Linux currently does not support opportunistic locking via the kernel, the value Kernel oplocks has to be set to false.

+   - **security = user** See section *Security Levels* on the next page.

The entry [cdrom] is the directory name that can be seen from outside. With this name, the directory is exported to the network environment. It can be reached by all users in the network, because guest ok = yes. The [home] share is of special importance here. If the user has a valid account and password for the Linux file server as well as his own home directory, he can be connected to this.

+   - **path = /cdrom** The directory `/cdrom` is exported by means of path.

+   - **comment = Linux CD-ROM** Every share with SMB servers can be provided with a comment describing the share.
