# Installation with YaST2

The new SuSE Linux installation system simplifies initial installation and configuration. It checks your system for hardware and any previous SuSE Linux installations. YaST2 then provides a series of suggestions based on that information. Either accept these suggestions or modify them individually as desired. This chapter contains information that may be helpful in modifying the suggestions or reconfiguring them later.
