`KBD_NUMLOCK="no"`  
Set this to no and (NumLock) will not be enabled at boot.

`KBD_CAPSLOCK="no"`  
Do not enable (CapsLock) at boot time.

`KBD_TTY="tty1 tty2 tty3 tty4 tty5 tty6"`  
Limit (NumLock) and (CapsLock) to certain TTYs. "" means all.

`KBD_RATE="30,0"`  
Rate of automatic keyboard repetition. Set this to a value between 2 and 30 times per second. The variable for the delay also needs to be set.

`KBD_DELAY="250"`  
Set the delay after which the automatic key repetition starts. Possible values: 250, 500, 750, and 1000 in milliseconds. Also set the variable `KBD_RATE`.

`CONSOLE_FONT=""`  
Font for the console loaded at boot. Additional settings are: CONSOLE_SCREENMAP, CONSOLE_UNICODEMAP, and CONSOLE_MAGIC.

`COMPOSETABLE="clear winews shiftctrl latin1.add"`  
Compose tables to load.

# irda – IrDA is the infrared interface, used, for example, by notebooks.

`IRDA_PORT="/dev/ttyS1"`  
Currently the UART (SIR) mode is supported in the default configuration. If you like to have FIR (4 Mbit/s, only for a few chipsets supported), look into the IrDA HOWTO, available in /usr/doc/howto/en/IRDA-HOWTO.gz. The variable IRDA_PORT sets the used serial port. Have a look at your BIOS setup to find out which is correct.

# mouse – Mouse Settings

`MOUSE="/dev/ttyS0"`  
Specify the interface to which the mouse is connected. YaST2 or SuSEconfig sets a link /dev/mouse pointing to the device.

`GPM_PROTOCOL=""`  
The gpm protocol for the mouse device from the variable MOUSE. The default value is defined by YaST2.

`GPM_PARAM="-t $GPM_PROTOCOL -m $MOUSE"`  
Default parameters for gpm.
