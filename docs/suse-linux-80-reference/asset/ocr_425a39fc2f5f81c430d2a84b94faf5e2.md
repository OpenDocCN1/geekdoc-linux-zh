> **Caution**
> 
> Memorize your user name and password, as you will need this information every time you log in.
> 
> A password should be between five and eight characters long. It could be as long as 128 characters, but only the first eight characters are shown. Linux distinguishes between lowercase and uppercase letters in the password. Accented characters are not allowed. Special characters (e.g., `*`, `,`, `#`, `;`) may be used, however, along with the digits `0–9`.

# PAM: Pluggable Authentication Modules

The configuration files for PAM (Pluggable Authentication Modules) are located in `/etc/pam.d`. Documentation for programmers and system administrators is available in `/usr/share/doc/packages/pam`.

SuSE Linux can handle MD5 passwords. MD5 encryption passwords can be longer than eight characters. MD5 encryption is not compatible with crypt(), the standard function in Unix. Therefore, some commercial Unix systems and some applications will not work with MD5 passwords.

Find information about the configuration in `/usr/share/doc/packages/pam/md5.config`.

# Monitor Settings

This shows graphics card and screen with reasonable settings. In most cases, you can accept the suggestion. However, you can customize color depth, resolution, and the image repetition rate manually.

The settings will be tested once you have accepted the suggestion or entered your changes. In the following dialog screen (Figure 2.17 on the following page), define whether, in the future, SuSE Linux should be operated in ‘Text mode only’ or in a ‘Graphical desktop environment’.

When you click ‘Change’, you have the option of configuring the graphical interface (Figure 2.18 on page 27). Set the screen resolution and color depth for the graphical mode. You can even define the image repetition rate. If you have a graphics card with a 3D chip, you can select the option ‘3D acceleration’.

By clicking ‘Test’, test the configuration selected. The installation program issues a message telling you that the screen will now switch to the new configuration. If you do not see a steady screen, stop the test immediately by pressing `Esc`.
