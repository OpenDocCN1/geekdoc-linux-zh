# Print Filter Troubleshooting

The correct debugging level is activated by removing the comment sign\n# in front of the respective line in the main print filter script `/usr/lib/\nlpdfilter/bin/if`.

```
```\n# DEBUG="off"\n# DEBUG="low"\nDEBUG="medium"\n# DEBUG="high"\n```
```

*File 32: /usr/lib/lpdfilter/bin/if: Debugging Level*

For DEBUG="low", only the stderr output of `/usr/lib/lpdfilter/bin/if`\nwill be saved to a file `/tmp/lpdfilter.if-$$.XXXXXX` ($$ is replaced by the\nprocess number and XXXXXX by an arbitrary or unique string).

For DEBUG="medium", the stderr output of the scripts in `/usr/lib/\nlpdfilter/filter/`, which are invoked by `/usr/lib/lpdfilter/bin/if`,\nwill be saved to file with the format of `/tmp/lpdfilter.name-$$.XXXXXX`\n(replace name with the name of the script to run and `$$.XXXXXX`, as described\nabove).

For DEBUG="high", the output will not be sent to the printer, but to a file in\nthe format of `/tmp/lpdfilter.out-$$.XXXXXX` ($$.XXXXXX is substituted as\ndescribed above).

These files should be deleted each time before performing any more tests by\nentering `rm -v /tmp/lpdfilter*`.

# A Little About Ghostscript

Ghostscript accepts PostScript and PDF data as input and contains numerous\nGhostscript drivers, known as devices in Ghostscript, for converting to other\nformats. The Ghostscript conversion takes place in two steps:

+   1. The PostScript data is converted to a matrix. The image described by the\n   PostScript language is resolved into a fine matrix pattern of individual pix-\n   els. This process takes place independently of the respective Ghostscript\n   driver. The finer the matrix (the higher the resolution), the higher the out-\n   put quality, but also the more processor and memory consumption, since\n   the number of dots in the matrix quadruples when the resolution is dou-\n   bled.

+   2. Finally, the image resolved to a dot matrix is now converted to the desired\n   format, the desired printer language.
