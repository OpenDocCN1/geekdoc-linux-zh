# Hardware and Software Requirements

+   - Check whether your printer is supported by SuSE Linux. Look at the lists on the installed system and on the Internet at
+     - `file:/usr/share/doc/packages/ghostscript/catalog.devices`
+     - `http://cdb.suse.de` and `http://hardwaredb.suse.de/` The Ghostscript drivers described here are included in the selection corresponding to each model offered by YaST2 in the printer configuration.
+     - `http://www.linuxprinting.org` → The ‘Database’ (`http://www.linuxprinting.org/database.html`) and `http://www.linuxprinting.org/printer_list.cgi`
+     - `http://www.cs.wisc.edu/~ghost/`

> **Note**
> 
> You will sometimes hear of printers that require the current version of Aladdin Ghostscript. For licensing reasons, SuSE Linux includes the slightly different GNU Ghostscript. In most cases, a GNU Ghostscript driver can be found that is suitable for any given printer.

+   - Check that you can make the necessary physical and logical connections to the printer. See Section *Connecting Printers Locally* on the following page for details of this.
+   - A self-compiled kernel could lack the necessary support for printing; if in doubt, first install and boot from a standard SuSE kernel. (This can be done through YaST2.)
+   - It is recommended to install the ‘Standard System’.

# Possible Problems

The most common possible problems are discussed in the *Basics* manual. For other problems, refer to the Support Database (`http://www.suse.de/sdb/en/html`) under the keywords “printer configuration”.
