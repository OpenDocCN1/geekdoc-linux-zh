# YaST2—Configuration Tools

YaST2 assists in extending your SuSE Linux system with additional hardware components, such as a printer or sound card, configuring and installing system services, Internet access, and software, or deleting undesired packages. The [SuS02a] manual contains a description of various ways of accessing YaST2.
