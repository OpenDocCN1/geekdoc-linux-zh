YaST2 gives a reasonable resizing suggestion for your Windows partition. However, it can be modified manually using the method described below. If you decide to delete Windows, all data will be irrevocably lost during Linux installation.

> **Caution**
> 
> The Windows Resizer only works if your computer has a hard disk with exactly one Windows partition (usually the case for most preinstalled Windows computers). Otherwise, you will have to manually partition your hard disk.

Before reducing your Windows partition, boot your Windows PC. Then run both scandisk and defrag programs. scandisk and defrag scan the files used by Windows then condenses these files to the beginning of the hard disk. This speeds up the reduction process.

After you go to ‘Partitioning’ in the suggestion screen and click ‘Edit’ in the screen that follow, use the mouse or arrow keys to highlight the Windows partition. Next, click ‘Reduce FAT Partition’. The ‘Windows Resizer’ can also be accessed by first selecting ‘Discard’ then ‘Entire Hard Disk’. Next, you will be asked whether you want to reduce or completely delete the Windows partition. Choosing the resizing option allows you to access the Resizer as well.
