# Printing Basics and Requirements

Printing basics and printer configuration with YaST2 are described in *Basics in the Chapter YaST2, Printer*. Here is a short summary of processes in the print system.

# Process of a Print Job

+   1. The user or an application generates a print job with the `lpr` command.
+   
+   2. The data to print is written to the print queue, where the printer spooler subsequently relays it to the print filter.
+   
+   3. The print filter can also define the type of the data to print and, if necessary, uses Ghostscript to convert this data to the language recognized by the given printer. Finally, the filter sends the printer-specific data to the printer.
+   
+   4. After the print job has been sent to the printer in its entirety, the printer spooler deletes the print job from the queue.

# Examples of Default Printer Languages

**ASCII text** — Normally, any printer is at least capable of outputting ASCII text.

**PostScript** — PostScript is the default Unix and Linux language used to generate output, which can then be printed by PostScript printers directly.

**PCL5e or PCL6** — These printer languages are common for laser printers.

**PCL3** — This printer language is understood by most HP DeskJet printers and compatible models.

**ESC/P, ESC/P2 or ESC/P dot matrix** — These printer languages are understood by nearly all Epson printers and compatible devices.

# GDI Printers

Printers that do not understand any of the default printer languages listed above, but can only be accessed via a proprietary protocol, are referred to as “GDI printers”. Such printers usually cannot be used in Linux. However, there are some GDI printers that also understand a default printer language on the hardware level. These printers need to be configured to use that language. Consult your printer manual for the necessary information.
