+   - *AM53C974 SCSI host adapter*
+     `AM53C974=(host-id),(target-id),(rate),(offset)`

| Variable | Values / Meaning |
|---|---|
| `{host-id}` | the host adapter’s SCSI ID (often 7) |
| `{target-id}` | the device’s SCSI ID (often 0...7) |
| `{rate}` | 3, 5, 10 MHz/s, max. transfer rate |
| `{offset}` | transfer mode; 0 = asynchronous |

If the host adapter seems to “swallow” some packages, reduce the maximum transfer rate for this device (e.g., the first CD-ROM SCSI drive `/dev/scd0` with ID 5) on the SCSI bus with:

*Example:* `AM53C974=7,5,3,0`

Individual transfer rates and transfer modes can be specified for each device, meaning that `AM53C974=x,x,x,x` could apply up to seven times to a single host adapter.
