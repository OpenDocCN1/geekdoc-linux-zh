# Access to Netware Servers and Their Administration

The package `ncpfs` from the series `n` is a collection of small programs that can be used to administer a Netware 2.3.11 server from Linux, mount Netware volumes, or manage printers. To access Netware servers newer than version 4, the bindery emulation and IPX must be enabled on them.

The following programs are available. Refer to the man pages for their functions:

|  |  |  |  |
|---|---|---|---|
| `nwmsg` | `ncopy` | `ncpmount` | `ncpumount` |
| `nprint` | `nsend` | `nwauth` | `nwbocreate` |
| `nwbols` | `nwboprops` | `nwborm` | `nwbpadd` |
| `nwbpcreate` | `nwbprm` | `nwbpset` | `nwbpvalues` |
| `nwdlr` | `nwdpvalues` | `nwfsctrl` | `nwfsinfo` |
| `nwfstime` | `nwgrant` | `nwpasswd` | `nwpurge` |
| `nwrevoke` | `nwrights` | `nwsfind` | `nwtrustee` |
| `nwtrustee2` | `nwuserlist` | `nwvolinfo` | `pqlist` |
| `pqrm` | `pqstat` | `pserver` | `slist` |

`ncpmount`, for example, is an essential program used to mount volumes from a Netware server in Linux. In turn, `ncpmount` is used to unmount them. Package `ncpfs` contains tools for configuring the IPX protocol and IPX routing:

```
ipx_init
ipx_configure
ipx_interface
ipx_internal_net
ipx_route
```

With `ipx_configure` and `ipx_interface`, configure the network card's IPX. If you already have MARSNWE running, however, it will take care of this configuration automatically.

# IPX Router with ipxrip

Another package for converting Linux into an IPX router is package `ipxrip` from the series `n`. Usually, it is not needed, because an IPX router can be configured with MARSNWE or the tools from package `ncpfs`.
