# Routing in SuSE Linux

The routing table is set up in SuSE Linux via the configuration files `/etc/sysconfig/network/routes` and `/etc/sysconfig/network/ifroute-*`.

All the static routes required by the various system tasks can be entered in the `/etc/sysconfig/network/routes` file: routes to a host, routes to a host via a gateway, and routes to a network. For all interfaces that need individual routing, an additional configuration file for each interface can be defined: `/etc/sysconfig/network/ifroute-*`. The sign `*` needs to be replaced with the name of the interface. The entries in the routing configuration files look like this:

```
DESTINATION          GATEWAY NETMASK   INTER-
FACE [ TYPE ] [ OPTIONS ]
DESTINATION          GATEWAY PREFIXLEN INTER-
FACE [ TYPE ] [ OPTIONS ]
DESTINATION/ORIGINAL GATEWAY -         INTER-
FACE [ TYPE ] [ OPTIONS ]
```

To omit GATEWAY, NETMASK, PREFIXLEN or INTERFACE, write `-` instead. The entries TYPE and OPTIONS may just be omitted.
