!: recognizes word designators, which recall a different word than the command. The term “word” is a word in the shell sense; a string separated by whitespace. The word designator is separated from the rest of the history recall command with a colon.

A:n selects the nth word on the history line. Word zero is the command.

```
$ printf “%s\n” “date”^\
Jul 14 14:34:41 EDT 2001
$ NOW=!!!2
NOW=“date”^\
$ printf “%s\n” “$NOW”\
Jul 14 14:34:55 EDT 2001
```

A:^ indicates the first word after the command, the same as !:1. A:$ indicates the last word. A:* represents ^ through $.

```
$ touch temp.txt
$ rm !!!^\
rm temp.txt
```

Other designators include :$ (the last word matched by a history search), :x–y (words x through y, inclusive), :x* (word x through to the end), :x- (word x through to the end, not including the last word) .

```
$ printf “%s and %s\n” “apples” “oranges”\
apples and oranges
$ printf “Two fruits are %s and %s\n” !!!:2*\
printf “Two fruits are %s and %s\n” “apples” “oranges”
Two fruits are apples and oranges
```

After a word designator, you can include a series of command modifiers, each proceeded by a colon:

+   * :s—Indicates the suffix of a pathname
+   * :g—Makes the changes “global” over the entire command line
+   * :h—Indicates the path of a pathname
+   * :p—Prints but doesn’t execute
+   * :r—Shows the pathname without the filename
+   * :s/old/new—Substitutes the first occurrence of the string old with new (essentially the same as :)
+   * :t—Shows the filename of a pathname
+   * :q—Quotes the words substituted
+   * :x—Quotes the words after breaking them into individual words
+   * :l—Repeats the last :s

Here are a few examples.

```
$ touch /home/kburtch/temp.txt
$ ls -l /home/kburtch/temp.txt
```
