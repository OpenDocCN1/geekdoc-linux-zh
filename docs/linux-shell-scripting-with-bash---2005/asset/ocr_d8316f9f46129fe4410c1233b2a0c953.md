# The echo Command

The built-in **echo** command is an older form of *printf*. Bash provides it for compatibility with the Bourne shell. *echo* does not use a format string; it displays all variables as if “$@\n” formatting was used. It can sometimes be used as a shortcut when you don’t need the full features of *printf*.

```
$ echo "$BASH_VERSION"
2.05a.0(1)-release
```

A line feed is automatically added after the string is displayed. It can be suppressed with the -n (*no new line*) switch.

```
$ echo -n "This is "; echo "one line."
This is one line
```

If the -e (*escape*) switch is used, *echo* interprets certain escape sequences as special characters.

+   - \\a—A beep (“alert”)
+   - \\b—A backspace
+   - \\c—Suppresses the next character; at the end of the string, suppresses the trailing line feed
+   - \\e—The escape character
+   - \\f—A form feed
+   - \\n—A line feed (new line)
+   - \\r—A carriage return
+   - \\t—A horizontal tab
