+      - -c c—Uses character c as input and output field separator
+      - -v file—Suppresses joined output lines from file

# **merge Command Switches**

+      - -h—Merges conflicts by merging all changes leading from file2 to file3 into
+        file1
+      - -e—Merge conflicts are marked as ==== and ====
+      - -E—Merge conflicts are marked as <<<<< and >>>>>
+      - -L label—Uses up to three times to specify labels to be used in place of the
+        filenames
+      - -p—Writes to standard output
+      - -q—Does not warn about conflicts
