
The `add_hash` function adds items to the hash table. If a collision occurs, `add_hash` tries to add the item at the following position in the table. It keeps moving through the table until it finds an empty position.

The `lookup_hash` function searches the hash table for an item. If the item is not found at the expected position, it moves through the table until it encounters an empty position. It reports the location of the item or otherwise announces that the item cannot be found.
