The results can be captured to a variable. Because standard output is used to draw the screen and the results are written to standard error, redirect standard error to a file.

```
```text
$ declare CHOICE_FILE="/tmp/choice.$$"
$ declare CHOICE
$ dialog --checklist "Printer type:" 20 70 14 p1 "printer 1" on p2 \
"printer 2" off fax "Fax" off 2> "$CHOICE"
$ CHOICE="cat "$CHOICE_FILE""
```
