## Bash 内置命令摘要

- **alias**——管理别名。
- **bg**——在后台启动挂起的任务。
- **bind**——管理键盘映射。
- **builtin**——运行内置 Shell 命令。
- **cd**——更改目录。
- **command**——运行 Linux 命令。
- **declare**——声明变量。
- **dirs**——显示 `cd` 目录堆栈。
- **disown**——停止监控后台任务。
- **echo**——打印到标准输出。
- **enable**——启用或禁用内置 Shell 命令。
- **eval**——执行命令，但首先执行 Shell 替换/展开。
- **exec**——离开 Shell 并切换到新程序。
- **exit**——退出 Bash 并返回状态码。
- **export**——管理导出变量。
- **false**——返回非零状态码。
- **fc**——查找并编辑命令历史行。
- **fg**——在前台运行挂起的任务。
- **function**——声明函数。
- **hash**——管理 Bash 命令表。
- **history**——管理命令历史。
- **jobs**——管理后台任务。
- **let**——求值表达式。
- **local**——声明局部函数变量。
- **logout**——在交互模式下退出 Shell。
- **popd**——丢弃 `cd` 目录堆栈条目。
