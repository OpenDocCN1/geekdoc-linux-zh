As the first step after registering and logging in to the DWService website, click **Agents** (Figure 1). You will then be prompted to enter a name and description of the computer you want to control remotely. After confirming, you will receive a code required to install the agent on the computer to be controlled.

During the agent download, DWService tells you that it does not store any data and the connection is encrypted. The package is stored as `duagent.sh` on your machine. First, make the script executable using

```
chmod +x duagent.sh
```

and then trigger the installation with `sh duagent.sh`.

# Graphical Approach

The next steps take place in the GUI. In the first window, you have the choice of installing the agent permanently or activating it for one session only. If you want to install permanently, start the script with `sudo`. If you decide to use it for only one session, the next window will provide the information you need to access the remote computer on the source computer on the DWService website. After entering the information, the other end needs to allow access unless **Unattended access** was selected when the session was initialized. You can also set a password for this.\n\nFor a permanent installation, enter the agent code previously shown on the web page during setup and then continue on the **Agents** tab of the web page by clicking **Online**. After accessing the remote computer, however, you will not see the desktop as a mirror image of the remote computer. Instead, you’ll be presented with a screen with six buttons: **Files and Folders**, **Text editor**, **Log watch**, **Resources**, **Screen**, and **Shell** (Figure 2).

# DWS Remote Control on Wayland

Currently, to access the target computer’s screen directly with DWS Remote Control on Wayland, you need to edit a file on the target computer. After the connection is established, click the **Files and Folders** button and navigate to the `/etc/gnss/` folder. Right-click the `custom.conf` file there and select the **Open** option. After another right-click, select **Open for and then Text editing**. Look for the `hwajj1andbhal1=fa1se` line in the file and remove the hashtag at the start of the line. Then save the file using the floppy disk icon in the menu bar at the top. After rebooting the source computer, DWS Remote Control now also offers a 1:1 view on Wayland.

I tested DWS Remote Control with Debian 11, Ubuntu 22.04, and Fedora 37. With Ubuntu and Fedora, when I tried to access the target computer’s interface directly via the **Screen** button, I got a message that the software does not support Wayland. To use DWS Remote Control with distributions that launch a Wayland session by default, the need to take a small detour, which the “DWS Remote Control on Wayland” box explains.
