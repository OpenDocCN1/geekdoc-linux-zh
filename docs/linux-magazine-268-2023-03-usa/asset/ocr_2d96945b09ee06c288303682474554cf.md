# ### Parsing the Forecast

The Solcast forecast data lets you per- form a number of calculations. The most important are how much power the panels will produce each of the up- coming days and whether you will face a power deficit. Because the forecast is in a machine-parseable format already, you can use some simple Perl scripts to reveal these numbers.
