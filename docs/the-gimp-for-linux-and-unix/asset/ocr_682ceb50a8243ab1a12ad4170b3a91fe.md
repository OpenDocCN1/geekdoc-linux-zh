# Creating Text

Adding text to an image is easy using the Text Tool. You should know that once text is added to an image, though the text can't be edited.

To create text:

+   1. If you want to add the text to an existing layer, use the Layers & Channels dialog box to select that layer. (See page 92 for directions about how to do this.) If you're going to put the text on a new layer, skip this and move to step 2.

+   2. Select the Text Tool in the GIMP Toolbox. The mouse pointer will change to an I-beam.

+   3. Position the mouse I-beam where you want the text to appear, then click. The Text Tool dialog box will appear (**Figure 1**).

+   4. In the large text box at the bottom of the dialog box, type in the text you want to add to the image.

+   5. Use the Font list box to select a font. The text that you entered in the large text box will change to that font.

+   6. Use the Font Size text box to enter the size of the text. By default, the measurement is set to pixels. To change the measurement to points, use the drop-down list to the right of the font text box (**Figure 2**).

+   7. Make sure the Antialiasing button is selected. This will smooth the edges of the text. (If this check button is unselected the text edge will be quite jagged; turn to page 62 and take a look at Figure 4 to see what antialiased text looks like.)
