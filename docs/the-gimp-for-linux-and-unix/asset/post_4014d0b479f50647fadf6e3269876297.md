## To draw a straight line with the Pencil or Paintbrush Tool:

- 1. Use the Layers & Channels dialog box to select the layer on which you would like to draw. (For directions on how to do this, turn to page 92)
- 2. Choose a foreground color. (For details about how to do this, turn to pages 42–45).
- 3. To select the Pencil Tool, click the Pencil Tool button in the Toolbox or press Shift+P on the keyboard. The mouse pointer will change to a tiny pencil.

or

To select the Paintbrush Tool, click the Paintbrush Tool button in the Toolbox or press P on the keyboard. The mouse pointer will change to a tiny pencil.

- 4. In the image window, position the mouse pointer where you would like the line to start.

Figure 6. A straight line appears when you click again.

- 5. Click. A dot will appear under the mouse pointer (Figure 5).
- 6. Press and hold down the Shift key.
- 7. Move the mouse pointer to where you want the line to end and click. A straight line will appear between the two points where you clicked (Figure 6).
- 8. To add another straight line to the one you just drew, continue holding down the Shift key, and then move the mouse pointer to a new position and click. A second line segment will appear attached to the first.
- 9. Continue adding lines or release the Shift key to draw a new line (Figure 7).

## Changing Brushes

You can set almost every aspect of the lines you draw—from thickness and shape, to spacing and opacity—by changing brush properties.

To change the brush properties:

- 1. In the GIMP Toolbox, choose File→Dialogs→Brushes (Figure 8).

or
Right-click on an image and choose Dialogs→Brushes from the pop-up menu (Figure 9).

or
Press Shift+Ctrl+B on the keyboard.
The Brush Selection dialog box will open (Figure 10).

- 2. To select a new line shape, click on a brush in the brush window (Figure 11). The brush name and pixel size will appear in the Brush Selection dialog box.
- 3. To set the opacity of the line, use the Opacity slider bar (Figure 12). The higher the setting more opaque the line will be. A setting of 0 is completely transparent, whereas a setting of 100 is completely opaque.

## Fade Out with the Paintbrush Tool

One other option available with the Paintbrush Tool is the ability to set the line to gradually fade.

To set Paintbrush to fade out:

- 1. Create a small image on a white background (Figure 14).
- 2. Right-click on the image and choose Image→Grayscale (Figure 15).
- 3. Right-click on the image and choose Image→Colors→Invert (Figure 16).
- 4. Right-click on the image and choose File→Save as (Figure 17).

## Custom Brushes

You may have already noticed that there are some interesting brushes in the Brush Selection box. You, too, can create custom brushes and add them to the program.

To create a brush:

- 1. Create a small image on a white background (Figure 18).
- 2. Right-click on the image and choose Image→Grayscale (Figure 19).
- 3. Right-click on the image and choose Image→Colors→Invert (Figure 20).
- 4. Right-click on the image and choose File→Save as (Figure 21).
- 5. Use the Directories list to move to a personal directory where you can save the file.
- 6. In the Selection box, type in the name of the file with .gbr extension. This will tell GIMP that you are creating a brush.
- 7. Click OK. The Save As Brush dialog box will open (Figure 22).
- 8. Type in a descriptive name for the brush in the Description text box.
