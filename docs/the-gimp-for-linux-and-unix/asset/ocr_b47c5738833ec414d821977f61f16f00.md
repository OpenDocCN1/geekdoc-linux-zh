# Curves

Curves, like Levels, are also used to adjust the tonal range of a layer or selection. But, instead of using a histogram to make corrections using highlights, midtones, and shadows, the Curves tool lets you make changes using a plotted curve representation of the image's colors.

![](bbox=[0.535, 0.035, 0.905, 0.375])

# To adjust color and tone using Curves:

+   1. Use the Layers & Channels dialog box to select a layer. (For details about how to do this, turn to page 92).

+   2. If you wish, use the selection tool to select an area of the image.

+   3. Right-click on the image and choose Image→Colors→Curves from the pop-up menu (Figure 7). The Curves dialog box will appear (Figure 8).

+   4. Make sure the Preview check box is selected.

+   5. Use the Modify Curves for Channel drop-down list to select which channel will be adjusted (Figure 9). (It's best to use Value first. This is the combination of all three channels—Red, Green, and Blue. After correcting the Value, you can move on individual channels, if you need).

+   6. To adjust the darker tones of the image, position the mouse crossover over the lower portion of the curve, press the left mouse button and drag the curve or down (Figure 10).

+   7. To adjust the midtones of the image, position the mouse crossover over the center portion of the curve, press the left mouse button and drag the curve or down (Figure 11).
