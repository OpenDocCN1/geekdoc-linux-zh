To save a graphic as a .png file:

+   1. Convert the image to indexed color. (See page 36 for details on how to do this.) If the image contains transparency, it will be layered. If you do, not flatten the image. If the transparent areas of the image will be filled with the current background color.

+   2. Right-click on the image and choose File→Save from the pop-up menu (Figure 24).The Save Image dialog box will appear (Figure 25).

+   3. Use the Directories list to move to the directory where you want to save the file.

+   4. Type a name for the Selection text box at the bottom of the Save Image dialog box (Figure 29). Be sure to add the .png extension after the file name. In this example, sunflower.png is entered.

+   5. Click OK. The PNG Options dialog box will open (Figure 30).

+   6. If your image is large, you may want to select the Interlace check button. This loads the image into a browser gradually, first appearing chunky, then smoothing out.

+   7. Use the Compression level slider to set how the file size will be. A setting of 1 is minimal compression. A setting of 9 compresses the file size as much as possible.

+   8. Click OK. Both the PNG Options dialog box and the Save Image dialog box will close and the image will be saved as .png file, ready for the Web. If the image contains transparency, the transparent areas will be preserved (Figure 31).
