# The Pencil and Paintbrush Tools

The Pencil and Paintbrush Tools work much like a pencil on paper or on canvas. Just press the left mouse button and drag to draw a line. Unlike an ordinary pencil or brush, though they have a few features: you can easily draw straight lines, and change the properties of the line that you will draw—shape, thickness, spacing, and opacity (Figure 2).

Figure 2. Various strokes with the Pencil and Paintbrush Tools: ① Circle fuzzy (19) brush, 100% opacity; ② Circle (15) brush, 35% opacity; ③ Circle (11) brush, 50% opacity, spacing set to 130; ④ Circle fuzzy (19) brush, 100% opacity; ⑤ Circle fuzzy (17) brush, 100% opacity, spacing set to 50; ⑥ Circle fuzzy (17) brush, out set to 70. Notice that strokes ⑦ and ⑧ are made with the same brush but different tools. No matter what you select, a Pencil Tool stroke will always have a sharp edge.
