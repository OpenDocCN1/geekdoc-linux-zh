# # The Web Color Palette

![](bbox=[0.268, 0.048, 0.477, 0.263])

If you're designing graphics from scratch, you should use the 216 colors that Web browsers display well. This is often called a *Web-safe palette*.

To view the Web color palette:

+   1. Right-click on an image window and choose Dialogs→Palette from the pop-up menu (**Figure 12**) or press Ctrl+P on the keyboard. The Color Palette dialog will appear (**Figure 13**).

+   2. Use the Color Palette drop-down list to select the Web color palette. The palette will appear in the palette window (**Figure 14**).
