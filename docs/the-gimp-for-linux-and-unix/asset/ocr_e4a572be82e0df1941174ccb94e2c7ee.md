# Inverting a Selection

If you want to select a large, complex section of an image, but don't want to take the time going around every corner and curve with a selection boundary, you can select the area you don't want, then use the Invert command. This switches the selected and unselected areas.

# To invert a selection:

+   1. Create the selection that you want to invert (Figure 64). (In other words, you are selecting the area you don't ultimately selected.)

+   2. Right-click on the image and choose Select→vert from the pop-up menu (Figure 65) or press Ctrl+I on the keyboard. The selected and unselected areas will switch (Figure 66).

# Selecting an Entire Layer

Using the Select All command, it's easy to select an entire layer.

# To select an entire layer:

+   1. Use the Layers & Channels dialog box to set which layer is active. (This is the layer whose pixels will be selected. If the image has only one layer, the entire image will be, course, selected.)

+   2. Right-click on an image and choose Select→All from the pop-up menu (Figure 67) or press Ctrl+A on the keyboard. An active selection boundary will appear around the entire image (Figure 68).
