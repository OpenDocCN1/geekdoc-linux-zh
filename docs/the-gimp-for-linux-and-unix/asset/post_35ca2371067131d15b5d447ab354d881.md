## Giving an Image the Appearance of Motion

Using the Motion Blur filter, you can give an image the appearance of motion. All you need to do is select the part of the image that will stay 'still' while the rest of the image will be blurred, giving the impression of motion.

![](img/5164bc49fb24f10213e18cc994b7b40c_261_0.png)

**Figure 26.** Select the area that will remain still. In this figure, the kayaker, kayak, and paddle have been selected.

To give an image the appearance of motion:

| | Repeat last | Alt+F |
| :--- | :--- | :--- |
| Layers | Re-show last | Shift+Alt+F |
| Tools | Animation | Gaussian Blur (IIR) |
| Filters | Artistic | Gaussian Blur (RLE) |
| Script-Fu | Blur | Motion Blur |
| Dialogs | | Pixelize |
| | Combine | Table Blur |

- 1. Use the selection tool of your choice to select the area of an image that will remain still (**Figure 26**).

- 2. Right-click on the image and choose Select→Feather from the pop-up menu (**Figure 12**). The Feather Selection dialog box will open (**Figure 13**).

- 3. Enter a value of 10 in the text box, then click OK to close the dialog box.

- 4. Copy the selected area and paste it into the image. The pasted item will appear as a floating layer.

- 5. In the Layers & Channels dialog box, click the New Layer button to anchor the floating selection to a new transparent layer.

**Figure 27.** Right-click on the image and choose Filters→Motion Blur from the pop-up menu.

- 6. Use the Layers & Channels dialog box to make the original layer active.

![](img/5164bc49fb24f10213e18cc994b7b40c_261_1.png)

**Figure 28.** Use the Motion blur dialog box to set blur length, type, and angle.

- 7. Right-click on the image and choose Filters→Motion Blur from the pop-up menu (**Figure 27**). The Motion blur dialog box will appear (**Figure 28**).

- 8. Set the options using the various sliders and radio buttons. For this example, Length is set to 63, the Blur type is Linear, and the Angle is set to 207.

- 9. Click OK. The Motion blur dialog box will close and the image will appear to move (**Figure 29**).

![](img/5164bc49fb24f10213e18cc994b7b40c_261_2.png)

**Figure 29.** When the Motion Blur filter is applied to the original layer, the pasted item appears to be moving.

## Some Filter Combinations

**Figures 30–33** below show some filter combinations that have been applied to images. Each description contains a listing of the filters used, the filter settings, and any pertinent information.

**Figure 30.** In this image, the Oilify filter was applied twice with a Mask Size setting of 11. Then, the Sharpen filter was applied with a sharpness setting of 62.

**Figure 31.** In this image, the Oilify filter was applied with a Mask Size setting of 17, then the Ripple filter was applied with a Period setting of 20 and an Amplitude setting of 3.

**Figure 32.** In this image, the section behind the bus was selected and an Abstract 2 gradient was stroked to give the appearance of a motion trail. The wheels and side panel of the bus were then selected and the Motion Blur filter was applied. Finally, the area around the wheels was selected and the Noisify filter was applied to create the grainy road.

**Figure 33.** The butterfly in this image was pasted onto two layers. With the bottommost butterfly layer selected, the Sharpen filter was applied with a Sharpness setting of 65, then the Glass Tile filter was applied with the Tile Width and Height sliders set to 36. The upper butterfly layer was then selected and the Sharpen filter was applied with a Sharpness setting of 36, the Posterize command was applied with a setting of 2 levels, and the layer opacity was set to 50%.
