
# Transform Your Art

## To flip a selection or layer vertically:

- Use the Layers & Channels dialog box to select which layer will be flipped (for details about this dialog box, see page 92)

and/or

- Use one of the selection tools of your choice to select an area. (For directions about using the selection tools, turn to Chapter 6, Making Selections.)

![](img/5164bc49fb24f10213e18cc994b7b40c_168_0.png)

**Figure 18.** In the Tool Options dialog box, select the Vertical radio button, then click Close.

- Double-click on the Flip Tool in the GIMP Toolbox. The Tool Options dialog box will open (**Figure 18**).

- Select the Vertical radio button.

- Click Close to close the Tool Options dialog box.

- With the Flip Tool selected, click on the layer or selected area. The layer or selection will flip vertically (**Figures 19a–b**).

## What's Left after a Transformation?

If you apply a transformation to a layer or selection on a layer, any empty space that remains after the transformation will be replaced by transparency. If a selection on the Background layer is transformed, any empty space will be filled with the currently selected background color.

## Chapter 10

### The Transform Tool

The Transform Tool is one of those all-time great tools. With it you can rotate, scale, *shear*, and add *perspective* to an image.

To rotate a layer or selection using the Transform Tool:

- 1. Use the Layers & Channels dialog box to select which layer will be rotated.

and/or

- Use one of the selection tools of your choice to select an area (**Figure 20**).

- 2. Double-click on the Transform Tool in the GIMP Toolbox. The Options dialog box will open (**Figure 21**).

- 3. In the Transform area, select the Rotation button.

- 4. Click Close to close the Tool Options dialog box.

- 5. With the Transform Tool selected, position the mouse pointer over the image or selected area. The mouse pointer will change to swirling arrows.

- 6. Press the left mouse button and drag to the right or left. A yellow dashed rectangle with squares at the corners will appear and the image will rotate (**Figure 22**). In addition, a Rotation Information dialog box will open, displaying the angle of the layer or selection (**Figure 23**).

- 7. Release the left mouse button when you are happy with the rotation angle.

- **Tip**
- To rotate an angle in 15° increments, hold down the Ctrl key while rotating.

To rotate a selection or image in exact 90° increments:

- 1. If you wish, use one of the tools to select the area to be rotated (Figure 20).

- 2. Right-click on the image and choose Image->Transforms->Rotate from the pop-up menu (Figure 24). The Rotate dialog box will open (Figure 25).

- 3. In the Rotate clockwise area select one of the radio buttons to rotate the image or either 90, 180, or 270 degrees.

- 4. If you selected an area using one of the selection tools, make sure the whole image check button is deselected. Otherwise, a GIMP Message will appear (Figure 26) and the selected area will not be rotated.

- 5. Click OK. The image or selection will rotate the specified amount (Figure 27) and the Rotate dialog box close.

## Chapter 10

### Scaling and Resizing an Image

Scaling and resizing both change the size of the image. Scaling changes the image area. Resizing changes the image itself. However, scaling is a bit inconsistent with resizing.

![](img/5164bc49fb24f10213e18cc994b7b40c_171_0.png)

Figure 28. In the Tool Options dialog box, select the Scaling button, then click Close.

To scale an area or layer using the Transform Tool:

- 1. Use the Layers & Channels dialog box to select which layer will be rotated (for details about this dialog box, see page 92).
and/or
- Use one of the selection tools of your choice to select an area.
- 2. Double-click on the Transform Tool in the GIMP Toolbox. The Options dialog box will open (**Figure 28**).
- 3. In the Transform area, select the Scaling button.
- 4. Click Close to close the Tool Options dialog box.

- 5. With the Transform Tool selected, position the mouse pointer over the image or selected area. The mouse pointer will change to ⬭.
- 6. Press the left mouse button and drag in any direction (up, down, sideways, or diagonally). A yellow dashed rectangle with squares at the corners will appear and the selection will scale up or down (**Figure 29**). In addition, a Scaling Information box may open, displaying the old and new width and height of the selection (**Figure 30**).

![](img/5164bc49fb24f10213e18cc994b7b40c_171_1.png)

**Figure 29. When you drag the mouse, the image scales to a new size.**

![](img/5164bc49fb24f10213e18cc994b7b40c_171_2.png)

**Figure 30. The Scaling Information box displays the original and new width and height.**

**Tips**

- To only change the width of a selection or layer, hold down the Shift key while dragging (Figure 31).
- To only change the height of a selection or layer, hold down the Ctrl key while dragging (Figure 32).
- To scale a selection or layer keeping both the width and height proportionally the same, hold down both the Shift and Ctrl keys while dragging (Figure 33).

**Figure 31. If you hold down the Shift key while dragging, only the width of the selection or layer scales.**
**Figure 32. If you hold down the Ctrl key while dragging, only the height of the selection or layer scales.**
**Figure 33. If you hold down both the Shift and Ctrl keys while dragging, the selection or layer scales proportionally.**
