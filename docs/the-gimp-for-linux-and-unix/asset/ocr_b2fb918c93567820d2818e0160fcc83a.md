# To duplicate an alpha channel:

+   1. On the Channels page of the Layers & Channels dialog box, select the channel that you want to duplicate (Figure 10). (You can only duplicate alpha channels.)

+   2. Click the Duplicate Channel button at the bottom right of the Channels tab page.
