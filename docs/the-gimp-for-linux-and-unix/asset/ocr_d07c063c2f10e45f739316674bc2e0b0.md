# Appendix A

# Color mode

A way that color information is specified. For example, an image can be set in RGB mode, when converted to grayscale mode.

# EncapsulatedPostScript (EPS)

An image file format that is commonly used to move files from one application to another and also for color printing.

# Color Picker Tool

The Color Picker Tool selects colors in an image.

# Eraser Tool

The Eraser Tool erases color from an image, leaving the current background color in its place.

# Color selector

The bottom area of the GIMP Toolbox that is used to select and switch between the foreground and background colors.

# Equalize

When an image is equalized, the brightest values in the image are redistributed, making it brighter.

# Composite

An image made by combining elements from different images or photographs.

# Feathering

Feathering makes the transition from an altered area to an unaltered smoother.

# Convolver Tool

The Convolver Tool is used to blur or sharpen areas of an image.

# File extension

The three or four letters that come after the period in a file name.XCF is the GIMP's native file format.

# Crop Tool

The Crop Tool cuts away part of an image, leaving only a selected area.

# Filter

Filters are used to apply special effects to an image or selected area.

# Curves

Curves adjust the tonal range of an image using a plotted curve representation of the image's colors.

# Flip Tool

The Flip Tool is used to mirror or flip an image vertically or horizontally.

# Dither

When colors are limited in an indexed image, dithering simulates colors not available in the color palette by mixing adjacent pixels.

# Floating Selection

A selected area that isn't anchored to a layer. A floating selection occurs when a cut or copied portion of an image is pasted or textured created.

# Dots Per Inch (DPI)

The unit of measure that indicates the resolution of a printer or imagesetter.

# Foreground color

Set using the color selector in the GIMP Toolbox, the foreground color is applied when painting a tool, text is created, or the Stroke command applied.

# Desaturate

When an image is desaturated, all color is removed, leaving a grayscale image.

# Free-hand Selection Tool

The Free-hand Selection Tool works just like a pencil and is used to select areas by clicking and dragging the mouse.

# Elliptical Selection Tool

The Elliptical Selection Tool is used to select round areas.
