# The Intelligent Scissors Tool

Figure 32. The mouse crosshair where you would like to start the selection. In this figure, the panther's mouth will be selected.

The Intelligent Scissors Tool works like the Free-hand Selection Tool in clicking and dragging creates a selection boundary. However, this tool does have a mind of its own. When you make a selection, this tool to guess which edge you are trying to select using the colors you select. The Intelligent Scissors Tool supports several options. Along with antialiasing and feathering, you can set curve resolution, edge detect threshold, and elasticity. In addition, if the Intelligent Scissors Tool does not create the exact you you select, you can convert the Intelligent Scissors selection to a Bezier Curve Selection and edit the curves as described on pages 70–72.

# To create an Intelligent Scissors selection:

+   1. Use the Layers & Channels dialog box to which layer is active. (This is the layer whose pixels will be selected).

![](bbox=[0.201, 0.297, 0.452, 0.513])

+   2. Click the Intelligent Scissors Tool in the Toolbox or press I on the keyboard.

![](bbox=[0.813, 0.545, 0.893, 0.596])

+   3. Position the mouse crosshair where you would like to start the selection (Figure 32).

+   4. Press the left mouse button and drag As you drag, a selection boundary will appear (Figure 33).

Figure 34. When you release the button, the Intelligent Scissors Tool shapes the selection boundary, smoothing it out.

+   5. When you have encompassed the area you want to select, release the left mouse button. The Intelligent Scissors Tool will make its best guess and shape the selection boundary accordingly (Figure 34). If the selection is not exactly the way you want it, you should convert the boundary to a bezier selection and reshape it. If you like the shape of the selection, skip to step 8 (continued)
