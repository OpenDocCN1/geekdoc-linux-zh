# To Dither or Not to Dither?

If you select the dithering option when converting an image to indexed color, the GIMP will try to create colors not available in the color palette by mixing adjacent colors. This doesn't create new colors, it just blends existing colors in the color palette. The image in Figure 5 is dithered, whereas the same image in Figure 6 is not.
