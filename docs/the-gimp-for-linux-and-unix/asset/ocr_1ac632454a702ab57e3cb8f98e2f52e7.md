Figure 16. Use the xset +fp command to tell the X server where the Type 1 fonts are.

20. Type exit at the command prompt, then press Enter on the keyboard. This will log you off and return you to your regular login.

21. Type xset +fp YourDirectory at the command prompt, then press Enter on the keyboard (Figure 16). Substitute the full path of the directory where your fonts are stored for YourDirectory. In this example, xset +fp /home/phyllsid/fonts is typed server now knows about the fonts and where to find them. Launch the GIMP and use the Text Tool to see your new fonts (Figure 17).
