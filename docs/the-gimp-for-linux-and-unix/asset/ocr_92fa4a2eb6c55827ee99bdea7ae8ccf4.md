# The Bucket Fill Tool

The Bucket Fill Tool can be used to fill an area or selection with the current foreground or background colors or a pattern. There are several options you can set before using the Bucket Fill Tool:

![](bbox=[0.535, 0.068, 0.905, 0.335])

+   * Fill Opacity—this option sets transparent the fill will be.

+   * Fill Threshold—if you're filling an area that contains different colors, this option sets how far the fill will spread. The higher the setting, the further out the fill will spread into other color areas.

+   * Sample Merged—with this option on, the Bucket Fill Tool will use the blended, composite colors from all layers to detect where area boundaries are.

# To set Bucket Fill options:

+   1. Double-click on the Bucket Fill Tool in the Toolbox. The Tool Options dialog box will open (Figure 33).

+   2. Use the Fill Opacity slider to set opaque the fill will be (Figure 34). The higher the setting the more opaque the fill. A setting of 0 is completely transparent (invisible), whereas a setting of 100 is completely opaque.

![](bbox=[0.535, 0.375, 0.905, 0.59])

+   3. Use the Fill Threshold slider to set how far a fill will spread. The higher the setting, the further the fill will spread (Figures 35a–b).

+   4. Select the Sample Merged check button to set the tool to detect area boundaries based on the combined colors of all layers (not just one layer).
