# Resizing the Image Window as You Zoom

Many times when zooming in or out, an image window will become smaller than the image—blocking view of the entire image—or larger than the image—using precious screen real estate. With the GIMP, you can quickly resize an image window using the Shrink Wrap command or can set the image window to automatically resize.

# To resize an image using Shrink Wrap:

Right-click on the image and choose View→Shrink Wrap from the pop-up menu (**Figure 8**) or press Ctrl+E on the keyboard.

# To automatically resize image windows when zooming:

+   - Double-click the Magnify Tool button in the Toolbox. The Tool Options dialog box will open (**Figure 9**).
- Select the Allow Window Resizing check button.
- Click Close. The next time you zoom in or to view an image, the image window will automatically resize to accommodate the new view size.
