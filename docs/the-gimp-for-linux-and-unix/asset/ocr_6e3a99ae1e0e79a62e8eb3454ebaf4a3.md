# To draw a straight line with the Airbrush Tool:

+   - Use the Layers & Channels dialog box to select the layer on you would like to draw.

+   - Choose a foreground color.

+   - Click the Airbrush Tool in the Toolbox or press A on the keyboard. The mouse pointer will change to a tiny pencil.

+   - In the image window, position the mouse pointer where the line will start.

+   - Click a fuzzy dot will appear under the mouse pointer (Figure 30).

+   - Press and hold down the Shift key.

+   - Move the mouse pointer to where you want the line to end and click. A straight line will appear between the two points you clicked (Figure 31).

+   - To add another straight line to the one you just drew, continue holding down the Shift key, and then move the mouse pointer to a new position and click. A second segment will appear attached to the first.

+   - Continue adding lines or release the Shift key to draw a new line (Figure 32).
