
# To move a guide:

- 1. Select the Move Tool from the Toolbox.

- 2. Position the mouse over the guide you want to move. The mouse pointer will change to a tiny pointing hand.

- 3. Press the left mouse button and drag the guide to its new position (Figure 14).

![](img/5164bc49fb24f10213e18cc994b7b40c_73_0.png)

# To view/hide guides:

Right-click on an image and choose→Toggle Guides from the pop-up menu (Figure 15) or press Shift+Ctrl+T on the keyboard.

![](img/5164bc49fb24f10213e18cc994b7b40c_73_1.png)

# To remove a guide:

- 1. Select the Move Tool from the Toolbox.

- 2. Position the mouse over the guide you want to remove. The mouse pointer will change to a tiny pointing hand.

- 3. Press left left mouse button and drag the guide back to the ruler it came from.

# Snap To Guides

An important guide feature is Snap To Guides which makes precise alignment easy by forcing a selection to line with a guide.

# To turn on Snap To Guides:

Right-click on an image and choose→Snap To Guides from the pop-up menu (Figure 16). The next time you create a selection or paint a line, the selection or line will snap to the closest guide.

Figure 16. Right-click on an image and choose View→Snap Guides from the pop-up menu.

# Viewing an Image in Two Image Windows

Using New View, an image can be opened in two or more image windows at the same time. This can be very helpful. One image window could be in a large display size to edit the detail while the other image window could be in a smaller view to see the changes made to the entire image. Changes made in one window appear in the other and vice versa. This is because it is the same image viewed in two windows. The two image windows are linked.

To view the same image in two image windows:

- 1. Open an image or get one started in a new image window.
- 2. Right-click on the image and choose View→New View from the pop-up menu (Figure 17). A new image window will appear next to the original (Figure 18).

# Tip

- If you look at the title bars of the two image windows, you will notice that the original file name has -1.0 appended to it and the new image window has -1.1 appended to it. If you opened another image window -1.2 would be appended to the file name.

# Duplicating an Image

Suppose you want to try out some different effects and don't want to change the original image. If you used New View to open several image windows, any changes made to the image in any of the image windows would change the rest, too. This is where Duplicate comes in handy. Duplicate image windows are separate copies of an original image. Changes made in a duplicate image window won't appear in the original image window. The copies are completely separate images.

![](img/5164bc49fb24f10213e18cc994b7b40c_75_0.png)

# To duplicate an image:

- 1. Open the image you want to duplicate (Figure 19).
- 2. Press Ctrl+D on the keyboard. A duplicate image will appear next to the original (Figure 20).

> Tip
If you look at the title bar of the duplicate image, you'll notice it's an unsaved, untitled image.

![](img/5164bc49fb24f10213e18cc994b7b40c_75_1.png)

# Selection Options

Before the selection tools, you should know that they have various options that can be turned on or off.

- Feather—this option makes the transition from the selection to the surrounding area (Figure 3).
- Antialias—like feather, antialiasing creates a smooth transition from the selection area. Antialasing is especially useful when working with type and want smooth edges.

To turn feathering or antialasing on:

- 1. In the Toolbox, double-click on the selection tool you want to change. The Tool Options dialog box will open, displaying the options for that tool (Figure 5).
