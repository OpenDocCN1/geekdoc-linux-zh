## The GIMP Pop-up Menus

The GIMP works mainly through the use of pop-up menus. These menus give access to all possible commands that affect an image, such as copying, adding layers, or applying a filter. All of the GIMP menus are shown in Figures 5–14 on the following three pages.

![](img/5164bc49fb24f10213e18cc994b7b40c_23_0.png)

**Figure 5.** The File menu is used to create, save, close, and print images. It is also used to set user preferences, email an image, and exit the GIMP. (You can also create and import images, set preferences, and exit the GIMP using the File menu in the GIMP Toolbox.)

![](img/5164bc49fb24f10213e18cc994b7b40c_23_1.png)

**Figure 6.** The Edit menu is used to cut, copy, and paste images, into selected areas, clear areas of color, fill areas with color, or add to a selection, and undo and redo actions. The Cut, Copy, and Paste Named commands let cut, copy, and paste multiple items.

![](img/5164bc49fb24f10213e18cc994b7b40c_23_2.png)

**Figure 7.** On the Select menu, the All command selects an entire layer. The None command removes all selections (not the areas inside the selections, just the selections, themselves). Other Select commands handle the selection boundary (toggle), and sharpen, float, grow, feather, or save selections to channels.

![](img/5164bc49fb24f10213e18cc994b7b40c_23_3.png)

**Figure 8.** The View menu is used to zoom in or out (changing your view of an image) and toggle rulers, and snap to guides on and off. The New View command displays the image in a secondary image window. Shrink Wrap lets you see the entire image window regardless of the zoom.

## Special GIMP Dialog Boxes

There are seven special GIMP dialog boxes that are used for image editing (Figures 16–22). To open one of these dialog boxes, choose File→Dialogs in the GIMP Toolbox or right-click on an image window and choose Dialogs from the pop-up menu. (The Indexed Palette dialog box is only available on the pop-up menu.) If you are working with several dialog boxes at once, you can maximize screen space by double-clicking a dialog box that is not in use—just double-click the dialog box's Title Bar.

![](img/5164bc49fb24f10213e18cc994b7b40c_26_0.png)

**Brush Selection dialog box (Figure 16)**
Use the Selection dialog box to select preset or custom brushes for use with a painting or editing tool. You can also use the Selection dialog box to set blending mode, opacity, and spacing. To find out about the Selection dialog box, turn to page 110.

![](img/5164bc49fb24f10213e18cc994b7b40c_26_1.png)

**Color Palette dialog box (Figure 17)**
The Color Palette dialog box lets you select colors from predefined palettes. These colors are applied using a painting or editing tool, or using a stroke or Fill. You can also use the Color Palette dialog box to edit existing palettes and colors, and create new palettes. To learn more about the Color Palette box and how to use it, turn to page 47.

![](img/5164bc49fb24f10213e18cc994b7b40c_26_2.png)

**Gradient Editor dialog box (Figure 18)**
The Gradient Editor dialog box works in conjunction with the Blend Tool. Using the Gradient Editor dialog box, you can select from the extensive list of gradients, edit or create a new one. Turn to page 127 to find out about the Gradient Editor dialog box.

**Indexed Palette dialog box (Figure 19)**
The Indexed Palette dialog box is similar to the Color Palette dialog box in that it shows a color palette and lets you edit existing layers. But, where the similarity ends. This color palette is composed of the colors in an open image set in indexed mode. It is a temporary palette that is only available while the image is open. To find out about the Indexed Palette, turn to page 51.

![](img/5164bc49fb24f10213e18cc994b7b40c_27_0.png)

## SPECIAL DIALOG BOXES

**Layers & Channels dialog box (Figure 20)**
The Layers & Channels dialog box is used to display the layers and channels that make up an image. Using this dialog box, you can create, duplicate, and delete layers and channels. In addition, you can move layers and channels up or down in the stacking order and anchor floating layers.

![](img/5164bc49fb24f10213e18cc994b7b40c_27_1.png)

By default, when you create a new image, it will have one layer called the Background layer. The number of channels an image has depends on the color mode the image is set in. (An RGB image has three channels and an indexed, grayscale, or bitmap image has one channel).

You can edit each layer separately without changing the other layers and set a blending mode and opacity for each layer. The active layer is highlighted. The eye icon indicates a visible layer. Take a look at page 92 to learn more about this dialog box.
