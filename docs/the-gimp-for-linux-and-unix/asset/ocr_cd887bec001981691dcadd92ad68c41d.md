# Use a temporary palette created from an indexed image:

Figure 32. In the Color Palette dialog box, choose Refresh Palettes from the Ops drop-down list.

+   1. Click the foreground or background color square in the Toolbox to select the one you want to.
2. Right-click on the image and choose Dialog→Indexed Palette from the pop-up menu (Figure 34). An Indexed Color Palette will appear (Figure 35).
3. Click a square to select the color. The color will appear in either the foreground or background color square.

# Tips

+   You can adjust the colors in this temporary palette. Right-click on a color square to open the Color Selection dialog box, then adjust the color following the directions in step 2 on page 42. If you adjust a color in this temporary palette, though, will also change in the indexed image, altering its appearance.
This is a temporary, custom palette that is handy for adjusting the color in an indexed image. It will only be available while the indexed image is open. When the image is closed, the palette is gone.
