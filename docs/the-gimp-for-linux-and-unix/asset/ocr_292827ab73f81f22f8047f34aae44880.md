# Hiding a Selection

Sometimes, when working on an image, the “arching ants” selection boundary can become distracting. You can hide the image without moving the dashed lines.

# To hide/view a selection boundary:

Right-click on an image that contains a selection and Choose Select→Toggle from the pop-up menu (Figure 69) or press Ctrl+T on the keyboard.

# Tip

+   - The Toggle command only hides the selection boundary, it doesn't remove the boundary.
