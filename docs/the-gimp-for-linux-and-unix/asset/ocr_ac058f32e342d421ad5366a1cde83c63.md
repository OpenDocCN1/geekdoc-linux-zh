# To sharpen an area:

+   1. Double-click on the Convolver Tool in the GIMP Toolbox. The Tool Options dialog box will open (Figure 33).

![](bbox=[0.435, 0.105, 0.475, 0.185])

+   2. Select the Sharpen radio button, then click Close.

+   3. Use the Brush Selection dialog box to select the brush. (For details on how to do this to page 110; blending modes are discussed on pages 170–173.)

+   4. If you wish, use one of the selection tools to select the area that you want to sharpen (Figure 31). This will restrict the sharpening to that area.

+   5. With the Convolver Tool still selected, position the mouse pointer over the area you want to sharpen.

+   6. Press the left mouse button and drag back and forth over the area. As you drag, it will become sharper (Figure 34).

![](bbox=[0.535, 0.075, 0.805, 0.235])
