# Some Filter Combinations

**Figures 30–33** below show some interesting filter combinations that have been applied to images. Each description contains a listing of the filters used, the filter settings, and any other pertinent information.

**Figure 30.** In this image, the Oilify filter was applied twice with a Mask Size setting of 11. Then, the Sharpen filter was applied with a sharpness setting of 62.

**Figure 31.** In this image, the Oilify filter was applied with a Mask Size setting of 17, then the Ripple filter was applied with a Period setting of 20 and an Amplitude setting of 3.

**Figure 32.** In this image, the section behind the bus was selected and an Abstract 2 gradient was stroked to give the appearance of a motion trail. The wheels and side panel of the bus were then selected and the Motion Blur filter was applied. Finally, the area around the wheels was selected and the Noisify filter was applied to create the grainy road.

**Figure 33.** The butterfly in this image was pasted onto two layers. With the bottommost butterfly layer selected, the Sharpen filter was applied with a Sharpness setting of 65, then the Glass Tile filter was applied with the Tile Width and Height sliders set to 36. The upper butterfly layer was then selected and the Sharpen filter was applied with a Sharpness setting of 36, the Posterize command was applied with a setting of 2 levels, and the layer opacity was set to 50%.
