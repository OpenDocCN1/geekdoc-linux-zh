# # Tips

This effect works really well if there's a white border area around the image.

In Figure 15, you may have noticed that there's a Blacks option in the Mode area. If you select this option, it will add black waves at the edge of the image instead of using colors from the image itself.

Try other distortion filters such as Ripple and Whirl and Pinch to add interesting effects to image borders (**Figure 17a–b**).
