# To create a gradient layer mask:

+   1. Open the image you want to add the text layer mask to (Figure 39).

+   2. Using the Layers & Channels dialog box, create a new white layer on top of any existing layers. The image will be hidden by the new white layer. (For directions on how to do this to page 93)

+   4. Make sure the new layer mask is selected.

+   5. If wish, use a selection tool to select an area to restrict the gradient area.

+   6. Use the color selector to set the foreground and background colors back to the default black and white. (Turn to page 46 for directions.)
