# To move a guide:

+   1. Select the Move Tool from the Toolbox.

+   2. Position the mouse over the guide you want to move. The mouse pointer will change to a tiny pointing hand.

+   3. Press the left mouse button and drag the guide to its new position (Figure 14).

![](bbox=[0.525, 0.056, 0.905, 0.246])

# To view/hide guides:

Right-click on an image and choose→Toggle Guides from the pop-up menu (Figure 15) or press Shift+Ctrl+T on the keyboard.

![](bbox=[0.525, 0.296, 0.905, 0.532])

# To remove a guide:

+   1. Select the Move Tool from the Toolbox.

+   2. Position the mouse over the guide you want to remove. The mouse pointer will change to a tiny pointing hand.

+   3. Press the left mouse button and drag the guide back to the ruler it came from.

# Snap To Guides

An important guide feature is Snap To Guides which makes precise alignment easy by forcing a selection to line with a guide.

# To turn on Snap To Guides:

Right-click on an image and choose→Snap To Guides from the pop-up menu (Figure 16). The next time you create a selection or paint a line, the selection or line will snap to the closest guide.
