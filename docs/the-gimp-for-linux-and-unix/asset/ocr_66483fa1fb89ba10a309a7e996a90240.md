# Adding an Alien Glow

![](bbox=[0.198, 0.355, 0.463, 0.591])

The Alien Glow script-fu is a mini-program that adds a three-dimensional, glowing effect to text using layers. It works just like other script-fu programs in that there is a dialog box used to set options.

# To add an Alien Glow:

+   1. In the GIMP Toolbox, choose Xns->Script-Fu-> Logos->Alien Glow (Figure 39). The Script-Fu Alien Glow dialog box will appear (Figure 40).

+   2. In the Text String text box, enter the text to which you would like to add a glow.

+   3. Enter the size of the text in the Font Size (in pixels) text box.

+   4. Enter a font name that is loaded on your computer in the Font text box. (To find what's loaded on your computer, take a look at the available font list in the Text Tool dialog. To open this dialog box, follow steps 2–3 on page 208).

+   5. Click the Glow Color button to open the Script-Fu Color Picker (Figure 26).

+   6. Use the Script-Fu Color Picker to set the color of the drop-shadow.
