# Intersecting Two or More Selections

You can also create a selection from the overlapping areas of two selections. This is called an intersection.

To intersect two selections:

+   1. Create the first selection using the selection tool of your choice (**Figure 49**).
2. Press and hold down the Shift and Ctrl keys on the keyboard.
3. Using the selection tool of your choice, make a second selection that overlaps the first selection area that you want to create (**Figure 50**).
4. Release the mouse button, and then the Shift and Ctrl keys. The area where the two selections overlapped will remain as the active selection (**Figure 51**).

# ✓ Tips

+   - You can change selection tools while making the intersection in order to select shaped areas.
- If you release the Shift and Ctrl keys before you release the mouse button, the first selection will disappear, leaving only the second selection.
