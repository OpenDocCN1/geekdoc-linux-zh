# Saturation

# Pixels per Inch (PPI)

A description of a color's purity is separate from its hue or brightness. The less gray a color, the higher the saturation.

The unit of measure that indicates the resolution of a digital image or a monitor.

# Plug-in

# Scale

A little program that lets the user add extra features to GIMP. Much of the GIMP—except the core features—plug-ins that have been integrated into the GIMP program.

Scaling an image changes both the size of the image display area and the image itself.

# Point

# Script-fu

A unit of measure that indicates the size of text. 72 point text is 1" (2.5 cm) high.

A mini-program that automates special effects containing many steps.

# Rectangular Select Tool

# Selection

The Rectangular Select Tool is used to select rectangular areas. This tool works by clicking and dragging a selection boundary around a specific area of an image.

An area of an image that has been isolated to restrict changes to that area. Unselected areas are protected from change.

# Resize

# Text Tool

Resizing an image changes the size of the image display area, but not change the size of the image display area. If the new size of the image display area is smaller than the original size, any part of the image that does not fit into the image display area will be cropped.

The Text Tool is used to create text in an image. When text is created it appears as a floating selection.

# Threshold

# Resolution

When the Threshold command is applied to an image, all color or grayscale pixels to black and white, creating a high contrast image.

The fineness of detail in a digital image (measured in pixels per inch (ppi)), a monitor (measured in ppi), or a printer (measured in dots per inch (dpi)), the more detailed the image. GIMP images are automatically created to 72 ppi.

# Transform Tool

The Transform Tool is used to rotate, scale, resize, or add perspective to images.

# Transparency

# RGB color model

An area of an image where the pixels contain no color. A transparent area in an image is shown in the GIMP with light and dark grey checkerboard pattern.

The Red, Green, Blue color model is used to display a color image on a computer monitor. RGB is an additive color model, meaning that every color can be created using red, green, and blue in varying degrees of brightness.

# TrueType and Type 1 Fonts

TrueType and Type 1 are technical standards used to create fonts. Both of these font types can be installed and used with the GIMP
