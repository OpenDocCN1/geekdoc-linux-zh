# Tips

+   - By Choosing File→Save as in step 2, a new copy of the file remains opened while the original version is automatically closed. This keeps the original version intact (all layers, guides, etc., preserved).

+   - You may have noticed the Encapsulated PostScript check button in the Output area. If you are generating an .eps file, this check button will automatically be selected. If you are generating a .ps file, the check button will not be selected. Leave this check button as is since fully encapsulated PostScript (.eps) is different than plain PostScript (.ps).
