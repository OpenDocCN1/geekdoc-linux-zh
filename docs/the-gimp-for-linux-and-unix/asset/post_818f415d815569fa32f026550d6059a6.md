
## Chapter 14

13. Type `ls` at the command prompt, then press Enter on the keyboard to see the contents of the new subdirectory (Figure 12). The two files that you will use are called `typeinst` and `tled`.
The next thing you will need to do is copy these two files to a directory listed on the path.

```
Terminal
$(phyllisd@localhost)$ cd /home/phyllisd/typeinst-0.6.1
$(phyllisd@localhost)$ typeinst-0.6.1
$(phyllisd@localhost)$ cp typeinst-0.6.1 tledman
$(phyllisd@localhost)$ chmod +x tledman
$(phyllisd@localhost)$ ./typeinst-0.6.1 tledman
```

Figure 12. Use it to view the contents of the copy typeinst-0.6.1 subdirectory.

14. Type `root` at the command prompt, press Enter on the keyboard, and then enter the root password. (You need to be in root to copy the files to the necessary directory).

```
Terminal
File Edit Settings Help
$(phyllisd@localhost)$ cd /home/phyllisd/typeinst-0.6.1
$(phyllisd@localhost)$ typeinst-0.6.1
$(phyllisd@localhost)$ cp RENAME typeinst tledman
$(phyllisd@localhost)$ chmod +x tledman
$(phyllisd@localhost)$ ./typeinst-0.6.1 su
```

```
Terminal
File Edit Settings Help
$(phyllisd@localhost)$ typeinst-0.6.1 echo $PATH=/usr/bin:/usr/local/bin:/usr/x11/bin:/usr/x11/home/phyllisd/bin:/x11/
$(phyllisd@localhost)$ typeinst-0.6.1 /usr/bin
$(phyllisd@localhost)$ cp typeinst-0.6.1 tledman /usr/
$(phyllisd@localhost)$ typeinst-0.6.1
```

Figure 13. `echo PATH` to see the directories in your path.

16. Copy the two files in the new directory to a directory listed on the path. In this example, the two files are copied to the `/usr/bin` directory. In order to do this, the following commands are typed at the command prompt in the terminal window:

```
cp /home/phyllisd/typeinst-0.6.1/typeinst /usr/bin (press Enter on the keyboard)
cp /home/phyllisd/typeinst-0.6.1/tledman /usr/bin (press Enter on the keyboard)
```

Figure 14. Copy the two files, `typeinst` and `tledman`.

### A Free Source for Type 1 Fonts

If you want to add your Type 1 font collection, a download of Type 1 fonts is available at `http://metalab.unc.edu/pub/Linux/fonts/`. Scroll down the Web page until you find `fonts-1.1.tar.gz`. Click the link to download the compressed file.

### Working with Text

17. Use the terminal window to move to the directory where you copied the fonts in step 1. In this example, the directory is `/home/phyllisd/`.

18. Enter `typeinst` at the command prompt, then press Enter on the keyboard. The `typelist` program will create and save necessary fonts (`fonts.dir` and `fonts.scale`) in the directory (Figure 15).

19. Type `mkfontdir` at the command prompt, then press Enter on the keyboard. The `mkfontdir` program will create a list of the fonts and save it in the directory.

20. Type `exit` at the command prompt, then press Enter on the keyboard. This will log you off and return you to your regular login.

21. Type `xset +` at the command prompt, then press Enter on the keyboard (Figure 16). Substitute the full path of the directory where your fonts are stored for `Directory`. In this example, `xset /home/phyllisd/fonts` server now knows about the fonts and where to find them. Launch GIMP and use the Text Tool to see your new fonts (Figure 17).

### Tips

- If you log out or shut down your computer, you will need to perform steps 17–21 again to access the Type 1 fonts.
- Special thanks to James Macnol for creating the `typelist` program!

Figure 17. After restarting GIMP, use the Text Tool to view your new fonts.

### To install TrueType fonts:

1. Use a browser to go to `http://metalab.unc.edu/pub/Linux/X11/fonts/` (Figure 18).
2. Scroll down to the bottom of the Web page where you'll find `xfont-1.0.tar.gz` link.
3. Click the link to download the file to your computer. The Save As dialog box will open (Figure 8).
4. Use the Directories list in the Save dialog box move to the directory where the downloaded file will be saved. In this example, the file is saved to `/home/phyllisd`.
5. Click OK. The file will download to the directory you selected.
6. Close the browser window. The next thing you will need is to unpack the downloaded file since it's compressed.
7. Open a Terminal window (Figure 19). (For directions on how to do this, turn to page 23, step 1).
8. Use the Terminal window to change to the directory where you saved the downloaded file. In this example, `cd /home/phyllisd` is entered.
