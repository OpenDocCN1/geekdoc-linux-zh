
# STARTUP

When the GIMP is launched, a small Toolbox appears on the screen (Figure 1). Using this Toolbox, you can open an image window.

The image window is the area on the screen where images are created. The image window consists of the image display area or canvas edged with a dashed line. There are rulers across the top and at the left of the image window divided into pixels. If the image display area is too large to show all at once, you can use scrollbars at the bottom and to the right of the image window to move the image display area. You can resize an image window by positioning the mouse pointer at any edge or corner, pressing the left image button, and dragging to a new size.

## Menu Items and Desktop Shortcuts

Sometimes a shortcut for the GIMP isn't present after installation. (For RedHat and KDE distributions of Linux it is usually available on the Graphics fly-out on the Main Menu.) Below are directions for the KDE and Gnome distributions.

![](img/5164bc49fb24f10213e18cc994b7b40c_35_0.png)

Figure 2. Choose Utilities from the K Main Menu.

### To put a menu item on the K Main Menu:

- 1. Utilities→Menu Editor from the K Main Menu (Figure 2). The Menu Editor will appear (Figure 3).
- 2. Right-click the Empty button and choose New from the pop-up menu (Figure 4). The kmenuedit dialog box will open (Figure 5).
- 3. Type GIMP in the Name text.
- 4. Click the icon button to the right of the dialog box and select an icon from the Select Icon dialog box. This is the icon that will appear on the menu.

![](img/5164bc49fb24f10213e18cc994b7b40c_35_1.png)

Figure 4. Choose New from the pop-up menu.

- 5. On the Execute tab page in the Execute text box, type the full pathname of the location where GIMP is installed plus the command to launch /usr/bin/gimp has been typed. Figure 5.
- 6. Click OK to close the kmenuedit dialog box and return to the Menu Editor window.
- 7. Choose from the File menu.
- 8. Press Ctrl+Q on the keyboard to close the Menu Editor. The GIMP menu item will appear under the Personal fly-out on the K Main Menu (Figure 6).

### To put a menu item on the Gnome Main Menu:

- 1. Choose Settings->Menu editor from the Gnome Main Menu (Figure 7). The Gnome menu editor dialog box will open with User Menus selected in the view window (Figure 8).
- 2. On the Menu Bar, click New Item to add a new menu item under User Men.
- 3. On the Basic page, type GIMP in Name text box (Figure 9).
- 4. In the Command box, type the full pathname of the location where GIMP is installed plus the command to launch the GIMP. In Figure 9 /usr/bin/gimp has been typed.
- 5. Click the lock icon to choose appropriate icon. This is the icon that will appear on the menu.
- 6. Click Save.
- 7. Close the Gnome menu editor dialog box by clicking the Close button. The GIMP menu item will appear on the Gnome Main Menu (Figure 10).

### To put a shortcut on the Gnome Desktop:

- 1. Right-click on the Gnome Desktop. A pop-up menu will appear.
- 2. Choose New→Launcher from the pop-up menu. The Desktop entry properties dialog box will appear (Figure 12).
- 3. Type GIMP in Name text box.
- 4. In the Command box, type the full pathname of the location where GIMP is installed, including the program name (Figure 13). /usr/bin/gimp has been typed.
- 5. Select Application from the drop-down.
- 6. Click the Icon button to choose an icon.
- 7. Click OK. The shortcut will appear on the Desktop (Figure 14).

### To launch the GIMP using a menu item:

- If you are using the Gnome, choose User→GIMP on the Gnome Main Menu (Figure 10).
- If you are using KDE, choose Personal→GIMP on the K Main Menu (Figure 6).

### To launch the GIMP from the command line:

- 1. Open a terminal. If you are using Gnome, click the Terminal button (Figure 15).
- 2. At the prompt, change to the directory where GIMP is installed.
- 3. Type gimp and press Enter to launch the GIMP.

# Launching the GIMP for the First Time

When you launch the GIMP for the very first time, a GIMP Installation dialog box will appear (Figure 19). This box contains about the GIMP General Public License and tells you about the personalization files that need to installed to use the GIMP. This dialog box will appear only once. You won't see it again after you have installed the personalization files.

# To install GIMP personalization files:

- 1. Launch the GIMP for the first time. The GIMP Installation dialog box will open (Figure 19).
- 2. Click Install. The GIMP program will install the personalization you need. When it is finished, an Installation Log box will appear, confirming that everything has been installed (Figure 20).
- 3. Click Continue. The GIMP program will load (Figure 21). The GIMP Toolbox and GIMP Tip of the day dialog box will appear (Figure 22). This dialog box will display a happy time with you to launch the GIMP. If you don't want to see it, use the Show tip check box. (By the way, the cute dog with the head and the paintbrush in his mouth is Wilber, the GIMP mascot.).
- 4. Click Close. The GIMP Tip of the day dialog box will close, leaving the Toolbox ready for you to use (Figure 1).
