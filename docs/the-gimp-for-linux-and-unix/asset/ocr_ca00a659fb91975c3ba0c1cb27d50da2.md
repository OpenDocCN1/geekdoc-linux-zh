# To quickly add a border around an image:

Figure 26. Open the image to which you want to add a border.

+   1. Open the image to which you want to add a border (**Figure 26**).

+   2. Right-click on the image and choose Script-Fu -> Modify -> Add Border from the pop-up menu (**Figure 27**). The Script-Fu Add Border dialog box will open (**Figure 28**).

+   3. To set the width of the left and right sides of the border, enter a value in pixels in the Border x text box.

+   4. To set the width of the top and bottom sides of the border, enter a value in pixels in the Border y text box.

+   5. Click the Border Colour button to open the Script-Fu Color Picker (**Figure 29**). Use the color picker to select the border.

+   6. OK. The Script-Fu Add Border dialog box will close and the script-fu will go to work. When it is finished a border will appear around the image (**Figure 30**).
