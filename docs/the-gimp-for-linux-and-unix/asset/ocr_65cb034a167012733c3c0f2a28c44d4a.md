# To set a printer resolution:

+   1. Right-click on the image and choose File→Print from the pop-up menu (Figure 16). The Print dialog box will open (Figure 17).

+   2. Use the Resolution drop-down list to select a specific printer resolution (Figure 18). This drop-down list is only available if you selected a printer that supports different resolutions.

+   3. Choose more printing options or click Print.

![](bbox=[0.525, 0.055, 0.925, 0.215])

> Figure 16. Right-click on the image and choose File→Print from the pop-up menu.

# To scale down an image to a specific percentage or resolution:

+   1. Right-click on the image and choose File→Print from the pop-up menu (Figure 16). The Print dialog box will open (Figure 17).

+   2. Use the radio buttons to the right of the Scaling slider to set whether the slider will operate in Percent (of the actual image dimensions) or PPI (Figure 19).

+   3. Use the slider to set the scaling of the image.

+   4. Choose more printing options or click Print.

![](bbox=[0.525, 0.355, 0.925, 0.615])

> Figure 17. Use the Print dialog box to set printer resolution, and scale and brighten an image.

Tip

The PPI (pixels per inch) is a more exact way to scale an image. If you used the formula on page 282 to figure out the image width and height based on a specific resolution (such as 300 dpi), just select the PPI ratio button and use the slider to set that resolution (Figure 20). The printed image will scale accordingly.
