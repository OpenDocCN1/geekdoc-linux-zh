# Selection Tool Options

Before the selection tools, you should know that they have various options that can be turned on or off. Each of the six selection tools can be set to feather and/or antialias. (The exception is the Rectangular Select Tool which only supports feathering.) These two options set how a selection reacts with the surrounding, unselected area.

+   - Feather—this option makes the transition from the selection to the surrounding area (Figure 3). If you apply a filter to a selected area and feather the edges, the change from the filtered area to the non-filtered area will be less abrupt.

+   - Antialias—like feather, antialasing creates a smooth transition from the selected area to the unselected area. While feathering blends pixels from the edge of selection out into the unselected area, antialasing blends pixels only over the edge of the selection (Figure 4). Antialasing is especially useful when you are working with type and want to create smooth edges.

It's easy to turn these options using the Tool Options dialog box.

To turn feathering or antialasing on:

+   1. In the GIMP Toolbox, double-click on the selection tool whose options you want to change. The Tool Options dialog box will open, displaying the options available for that tool (Figure 5).
