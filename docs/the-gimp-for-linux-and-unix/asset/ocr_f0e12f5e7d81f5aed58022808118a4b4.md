4. In the Layers & Channels dialog box, right-click on the transparent layer and choose Add Layer Mask from the pop-up menu (Figure 20). The Add Mask Options dialog box will appear (Figure 21).

5. Select the White (Full Opacity) radio button, click OK. The Add Mask Options dialog box will close and a layer mask thumbnail will appear selected to the right of the layer in the Layers & Channels dialog box (Figure 22).

Layer mask thumbnail

6. With the layer mask selected, right-click and choose a filter from the Filters menu on the pop-up menu (Figure 23). Depending upon your selection, the dialog box for filter will open (Figure 24). Some filters that work with this technique are Apply Canvas and Mosaic on the Artistic sub-menu, Noisify on the Noise sub-menu, and Checkerboard and Maze found on the Render sub-menu.

![](bbox=[0.046, 0.273, 0.458, 0.574])

Figure 23. Right-click on the filter from the Filters—Artistic menu. In this example, the Mosaic filter is selected.

7. Use the dialog box for the filter to select the filters, then click OK. The filter's dialog box will close and the filter will be applied to the layer mask, resulting in an interesting texture (Figure 25).
