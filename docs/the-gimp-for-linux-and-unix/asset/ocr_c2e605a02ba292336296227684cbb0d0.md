# Adding Perspective

Adding perspective to a layer or selection gives the illusion that the area is receding to a vanishing point. (Remember that if your image consists of one layer, the Background, then perspective will be added to the entire image).

**Figure 43.** The Shear Information dialog box displays the amount of X and Y shearing.

# To add perspective to a layer or selection:

+   1. Use the Layers & Channels dialog box to select which layer will be sheared (for details about this dialog box, see page 92).

and/or
Use one of the selection tools of your choice to select an area.
2. Double-click on the Transform Tool in the GIMP Toolbox. The Tool Options dialog box will open (**Figure 44**).
3. In the Transform area, select the Perspective radio button.
4. Select the Smoothing check button if you want the edges of the image blurred to create a smooth look.
5. Click Close to close the Tool Options dialog box.
