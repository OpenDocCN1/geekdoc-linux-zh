**Figure 9.** The Image menu is used to adjust the color of an image, add and manipulate alpha channels, set an image in three color modes, make save palettes, and rotate and crop an image. The Resize and Scale commands change image size to specified range

**Figure 10.** The Layers menu is used to access the Layers & Channels dialog box where you can create, copy, and delete layers. The menu also lets you raise, anchor, and merge layers, flatten an image, alpha channeis, and align layers.
