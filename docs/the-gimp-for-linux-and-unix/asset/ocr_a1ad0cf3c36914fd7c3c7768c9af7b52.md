# Applying and Discarding Layer Mask Effects

Once you finish using a layer mask, you may decide that you want to apply it to the image, making it a permanent part of the image, or discard it, removing completely.

# To apply a layer mask:

+   1. On the Layers tab page in the Layers & Channels dialog box, right-click on the layer mask thumbnail, and choose Apply Layer Mask from the pop-up menu (Figure 36). The Layer Options dialog box will open (Figure 37).
