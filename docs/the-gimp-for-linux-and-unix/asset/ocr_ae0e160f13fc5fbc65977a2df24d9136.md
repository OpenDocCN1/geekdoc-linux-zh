# Filling Text with a Pattern

It's easy to fill selected text with a pattern in the GIMP. All you need to use is the Pattern Selection dialog box and the Bucket Fill Tool.

To fill text with a pattern:

+   1. Use the Text Tool to create the text you want to fill with a pattern (Figure 35). The text will appear in the image window as a floating selection.

+   2. Double-click the Bucket Fill Tool in the GIMP Toolbox. The Tool Options dialog box will open (Figure 36).

+   3. In the Fill Type area, select the Pattern Fill radio button.

+   4. Click Close to close the Tool Options dialog box.

+   5. Right-click on the image and choose Dialogs→Patterns from the pop-up menu (Figure 37) or press Shift+Ctrl+P on the keyboard. The Pattern Selection dialog box will open (Figure 38).

+   6. Click a pattern in the pattern window to select it.
