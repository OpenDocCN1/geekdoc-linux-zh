# Large Menus and Dialog Boxes

GIMP menus and dialog boxes contain many commands and items to select. Consequently, some of them are quite large. Many of the figures in this *Visual QuickStart Guide* are too big to display in their entirety or become very small when sized to fit the page. In order to fit these large items, some menus have been shortened by using a jagged edge (**Figure 14**). The menu item being selected is shown, but upper, middle, or lower menu items are removed to conserve space. In a large dialog box, a circle is drawn around the area under discussion (**Figure 15**).
