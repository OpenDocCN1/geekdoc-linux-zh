4. Use the Fill Type area to select color for the background area of the image (**Figure 26**). Choose from the following:

+   - **Background** is the background color shown in the Color Selector on the Toolbox.

- **Transparent** is an invisible background.
- **Foreground** is the foreground color shown in the Color Selector on the Toolbox.

5. Click OK. A new, untitled image window will open, ready for you to use (**Figure 27**).

# How Many Image Windows Can I Open at Once?

You can have as many image windows open at one time as you like (depending upon the amount of memory in your computer). To see the GIMP with 800 image windows open (!), check out http://www.geocities.com/ResearchTriangle/8847/screen800.gif
