# To launch the GIMP using a menu item or shortcut:

If you are using the Gnome Desktop, choose User→GIMP from the Gnome Main Menu (Figure 10) or double-click the GIMP icon on your Desktop (Figure 14).

or

If you are using the K Desktop, choose Personal→GIMP from the K Main Menu (Figure 6).

![](bbox=[0.149, 0.063, 0.412, 0.252])

Figure 14. The GIMP shortcut appears on the Gnome Desktop.

# To launch the GIMP from the command line:

+   1. Open a terminal. If you are using the Gnome window, click the Terminal emulation button on the Gnome panel (Figure 15). If you are using the KDE desktop, click the Terminal Emulation button on the K panel (Figure 16).

+   2. At the prompt, change directories to where the GIMP is installed. A typical installation places the GIMP in /usr/bin/.

+   3. Type gimp (Figure 18), then press Enter on the keyboard to launch the GIMP.
