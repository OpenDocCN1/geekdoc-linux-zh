# Rotating Layers

There are two ways to rotate layers—you can use the Transform Tool or the Rotate command. While the Transform Tool will rotate a layer to any degree, the Rotate command will only rotate to 90 or 270 degrees. Turn to page 154 for directions on how to rotate a layer using the Transform Tool.

# To rotate a layer using the Rotate command:

+   1. Use the Layers & Channels dialog box to select which layer will be rotated (for directions about how to do this, turn to page 92).

+   2. Right-click on the image and choose Image→Transforms→ Layer. The Layer menu will open (Figure 9).

+   3. Choose either the Rotate 270 or Rotate 90 menu item. The layer will rotate (Figures 10a–b).
