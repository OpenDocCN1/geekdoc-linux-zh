# To a selection using Cut Named:

+   1. Use the selection tool of your choice to select an area (for details about how to do this, turn to Chapter 6, Making Selections).

Figure 17. Right-click on the image and choose Edit->Paste Named from the pop-up menu.

+   2. Right-click on the image and choose Edit->Cut Named from the pop-up menu (Figure 15) or press Shift+Ctrl+X on the keyboard. The Cut Named dialog box will appear (Figure 16).

![](bbox=[0.095, 0.345, 0.417, 0.452])

+   3. Enter a name for the selected area in the text box, then click OK. The selected area will disappear from the image and be saved in the clipboard with the name you gave it, ready for you to paste into another layer or image using the Paste Command.

Figure 18. Highlight one of the named selections, then click Paste.

# To paste a selection using Paste Named:

+   1. Right-click on the image you want to paste a selection into and choose Edit->Paste Named from the pop-up menu (Figure 17) or press Shift+Ctrl+V on the keyboard. The Paste Named dialog box will open (Figure 18).

+   2. In the Select buffer to paste window, choose the named selection you want to paste.

+   3. Click Paste. The Paste Named dialog box will close and the selection you choose will be pasted into the image as a floating selection (Figure 19).

![](bbox=[0.042, 0.678, 0.417, 0.873])

Tip

+   - To delete a named selection in the Paste Named Buffer dialog box, highlight the selection, then click Delete.

Figure 19. The named selection appears in the image window as a floating selection.
