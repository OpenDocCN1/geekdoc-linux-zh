# To fill an area:

+   1. Use the Layers &amp Channels dialog box to select the layer on which you would like to draw on. (For directions on how to do this, turn to page 92).

+   2. Choose foreground and background colors. (For details about how to do this, turn to pages 42–45.).

+   3. Use one of the selection tools to select the area you would like to fill (this is optional).

+   4. Click the Bucket Fill Tool button in the Toolbox or press Shift+B on the keyboard. The pointer will change to a crosshair.

+   5. Position the mouse crosshair over the area you want to fill (**Figure 36**).

+   6. Click to fill the area with the foreground color. To fill the area with the background color, press the Shift key and click. The area will fill with color (**Figure 37**).
