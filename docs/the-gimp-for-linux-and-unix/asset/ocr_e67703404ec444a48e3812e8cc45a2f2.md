# Duplicating an Image

Suppose you want to try out some different effects and don't want to change the original image. If you used New View to open several image windows, any changes made to the image in any of the image windows would change the rest, too. This is where Duplicate comes in handy. Duplicate image windows are separate copies of an original image. Changes made in a duplicate image window won't appear in the original image window. The copies are completely separate images.

![](bbox=[0.535, 0.058, 0.875, 0.263])

# To duplicate an image:

+   1. Open the image you want to duplicate (Figure 19).
2. Press Ctrl+D on the keyboard. A duplicate image will appear next to the original (Figure 20).

> Tip
If you look at the title bar of the duplicate image, you'll notice it's an unsaved, untitled image.
