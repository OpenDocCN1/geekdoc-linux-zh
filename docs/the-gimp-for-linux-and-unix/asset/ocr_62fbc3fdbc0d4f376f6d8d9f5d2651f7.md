# Creating Images for the Web

23. To see your animation in action, right-click on the image window and choose Filters→Animation→Animation Playback (Figure 44). The Animation Playback dialog box will appear (Figure 45).

![](bbox=[0.058, 0.051, 0.483, 0.196])

Figure 44. Right-click on the image and choose Filters → Animation→Animation Playback from the pop-menu.

24. Click Play/Stop. The animation you just created with gradients will play. (Wow!) Look at what you just created! If your animation seems choppy to you or there is something you want to fix, you can work back and forth between the image window and the Animation Playback dialog box to make corrections.

25. When you have finished watching the animation play, click Play/Stop to stop the animation, then click Close to the Animation Playback dialog box. The next step is to optimize the animation, then save it as a .gif file.

![](bbox=[0.058, 0.293, 0.483, 0.563])

Figure 45. Use the Animation Playback dialog box to view your animation in action.

26. Right-click on the image window and choose Filters→Animation Optimize from the pop-up menu (Figure 46). A duplicate of the image you've been working on will appear in a new image window.

27. Convert the optimized image to indexed color. (Turn to page 36 for directions.)

![](bbox=[0.058, 0.723, 0.483, 0.802])

28. Right-click on the optimized image and choose Filters→Save as from the pop-up menu (Figure 24). The Save dialog box will open (Figure 25).

29. Use the Directories list to move to the directory where you want to store the animation .gif file.

30. Enter a name for the animation in the Selection text box. Be sure to add the .gif file extension after the name. In example, animation.gif is entered.
