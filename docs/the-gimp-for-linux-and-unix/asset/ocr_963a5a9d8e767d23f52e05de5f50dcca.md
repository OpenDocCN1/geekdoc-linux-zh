13. Type 1s at the command prompt, then press Enter on the keyboard to see the contents of the new subdirectory (Figure 12). The two files that you will use are called typeinst and tled.
The next thing you will need to do is copy these two files to a directory listed on the path.

```
Terminal
$(phyllisd@localhost)$ cd /home/phyllisd/typeinst-0.6.1
$(phyllisd@localhost)$ typeinst-0.6.1
$(phyllisd@localhost)$ cp typeinst-0.6.1 tledman
$(phyllisd@localhost)$ chmod +x tledman
$(phyllisd@localhost)$ ./typeinst-0.6.1 tledman
```

Figure 12. Use it to view the contents of the copy typeinst-0.6.1 subdirectory.
