# Glossary

The Fuzzy Selection Tool creates selections using color. When a pixel is selected, the Fuzzy Selection Tool also selects adjacent pixels that are similar in hue and value.

# Grayscale mode

An image in grayscale mode contains no color, only varying shades of gray. There are 256 shades of gray from black (0) to white (255).

# Layer

Layers are like a clear glass window stacked on top of the other. Every new GIMP image starts with one layer, a special layer called the Background layer.

# Layer mask

A layer mask controls the way different areas of an image are revealed.

# Guides

Guides (also known as guidelines) are horizontal and vertical lines that are positioned on an image to set up areas for drawing or selection. A guide looks like a dashed blue line.

# Levels

Levels are used to make exact adjustments to an image's tonal range by setting highlights, midtones, and shadows.

# HSV color model

The Hue, Saturation, Value color model is used in combination with the RGB color model in the GIMP. Hue represents the color in use, saturation represents the intensity of the color, and value represents the intensity of light on the color.

# Magnify Tool

The Magnify Tool is used to enlarge and reduce the view of an image. It doesn't change the actual size of the image, only your view of it.

# Image display area

The area in the image window where the graphic is displayed. Also called a canvas.

# Move Tool

The Move Tool moves selections, layers, and guides.

# Image window

The area in the screen where images are created.

# Opacity

The density of a color in an image that ranges from transparent to opaque. In the GIMP, you can select an opacity for a layer or tool.

# Indexed color model

An indexed image contains a specific number of colors from 1 to 256.

# Paintbrush Tool

The Paintbrush Tool is used to paint strokes on an image.

# Intelligent Scissors Tool

The Intelligent Scissors Tool works with a mind of its own. After a selection has been drawn using the mouse, the Intelligent Scissors Tool goes to making its best guess as to exactly which edge is selected. Result selection is smoothly shaped, but can sometimes be unpredictable.

# Pencil Tool

The Pencil Tool draws hard-edged strokes on an image.

# Pixels

A unit of measure that is dependent upon the size of a computer monitor and its resolution setting.
