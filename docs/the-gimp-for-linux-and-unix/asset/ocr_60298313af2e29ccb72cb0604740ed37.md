# Viewing an Image in Two Image Windows

Using New View, an image can be opened in two or more image windows at the same time. This can be very helpful. One image window could be in a large display size to edit the detail while the other image window could be in a smaller view to see the changes made to the entire image. Changes made in one window appear in the other and vice versa. This is because it is the same image viewed in two windows. The two image windows are linked.

To view the same image in two image windows:

+   1. Open an image or get one started in a new image window.
2. Right-click on the image and choose View→New View from the pop-up menu (Figure 17). A new image window will appear next to the original (Figure 18).

# Tip

+   - If you look at the title bars of the two image windows, you will notice that the original file name has -1.0 appended to it and the new image window has -1.1 appended to it. If you opened another image window -1.2 would be appended to the file name.
