
# To create a simple animation:

- 1. Create a new image with a transparent background. For this example, the new image is 550 pixels wide and 150 pixels high. (See page 25 for directions.)

- 2. Create some text that fits in the image window. For example, the word "Animation" is set in the Charter font at 100 points (Figure 35). (Turn to page 208 for details on how to create text).

- 3. Anchor the text to a new layer by clicking the New button in the Layers & Channels dialog box. The layer will automatically be renamed "Text Layer".

- 4. In the Layers & Channels dialog box, select the Background layer and delete it by clicking the Delete Layer button. Next, you'll need to separate the layers and rename them as numbered frames.

- 5. Copy the Text Layer three times using the Layer button in the Layers & Channels dialog box. There will now be four layers shown in the layer window (Figure 36).

- 6. Starting at the bottom layer in the Layers & Channels dialog box (this will be the Text Layer), rename the Frame 1 (Figure 37). (For directions on how to rename layers, turn to page 95).

- 7. Move up to the next layer (probably named Text Layer copy) and rename it Frame 2.

- 8. Move up to the next layer (probably named Text Layer copy) and rename it Frame 3.

# Creating Images for the Web

- 23. To see your animation in action, right-click on the image window and choose Filters→Animation→Animation Playback (Figure 44). The Animation Playback dialog box will appear (Figure 45).

![](img/5164bc49fb24f10213e18cc994b7b40c_302_0.png)

Figure 44. Right-click on the image and choose Filters → Animation→Animation Playback from the pop-menu.

- 24. Click Play/Stop. The animation you just created with gradients will play. (Wow!) Look at what you just created! If your animation seems choppy to you or there is something you want to fix, you can work back and forth between the image window and the Animation Playback dialog box to make corrections.

- 25. When you have finished watching the animation play, click Play/Stop to stop the animation, then click Close to the Animation Playback dialog box. The next step is to optimize the animation, then save it as a .gif file.

![](img/5164bc49fb24f10213e18cc994b7b40c_302_1.png)

Figure 45. Use the Animation Playback dialog box to view your animation in action.

- 26. Right-click on the image window and choose Filters→Animation Optimize from the pop-up menu (Figure 46). A duplicate of the image you've been working on will appear in a new image window.

- 27. Convert the optimized image to indexed color. (Turn to page 36 for directions.)

![](img/5164bc49fb24f10213e18cc994b7b40c_302_2.png)

- 28. Right-click on the optimized image and choose Filters→Save as from the pop-up menu (Figure 24). The Save dialog box will open (Figure 25).

- 29. Use the Directories list to move to the directory where you want to store the animation .gif file.

- 30. Enter a name for the animation in the Selection text box. Be sure to add the .gif extension after the name. In example, animation.gif is entered.

- 31. Click OK. The Save as GIF dialog box will appear (Figure 27).

- 32. In the Animated GIF Options area, select the Loop button if you want the animation to play again. (If the Loop button isn't selected, the animation will only play once.)

- 33. In the Default delay between frames where text box, enter the amount (in milliseconds) that you want each frame to play. The default, 100 milliseconds, is a pretty good speed.

- 34. In the Default display where area, select the Make frame from cumulative layers (combine) radio button.

- 35. Click OK. The Save as GIF and Image dialog boxes will close and the optimized image will be saved as a .gif file. If you look at the Layers & Channels dialog box, you'll see the time you specified in step 33 has been added after each layer name (Figure 47). If you want, you can change the time delay, just by renaming the layer and inserting a new number before ms.) Your animation is ready for the Web (Figure 48). (Go to http://www.peachpit.com/vqs/gimp to see it in action.)

![](img/5164bc49fb24f10213e18cc994b7b40c_303_0.png)

Figure 47. The time delay you entered in the Animated GIF Options area of the Save as dialog box appended to the layer names.

![](img/5164bc49fb24f10213e18cc994b7b40c_303_1.png)

Figure 48. Try out your animation on a Web page!
