# What Are Points?

Text is usually measured in points in most word processing, page layout, and graphic image manipulation programs. Unlike pixels, which change size depending upon the resolution of your monitor (see page 25 for a sidebar of pixels), a point is a fixed value. 72 point text is 1" (2.54 cm) high; 18 point text is 1¼ (6 mm) high. The text in this sentence is set in 10 point type.
