# Making a Border Wavy

Using the selection tools, it's easy to apply a filter to the edge of an image to give it a rippled, wave, or wrinkly border.

To make an image's border wavy:

+   1. Use the Rectangular Select Tool to select the center portion of the image (Figure 9).

+   2. Right-click on the image and choose Select→-Invert from the pop-up menu (Figure 10) or press Ctrl+1 on the keyboard. The selected area will invert, meaning that the active area now encompasses the image border (Figure 11).

+   3. Right-click on the image and choose Select→Feather from the pop-up menu (Figure 12). The Feather Selection dialog box will open (Figure 13).

+   4. Enter 10 in the Feather selection by text box, then click OK to close the dialog box.
