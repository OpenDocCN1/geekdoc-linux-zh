## CREATING COMPOSITE IMAGES

![](img/5164bc49fb24f10213e18cc994b7b40c_204_0.png)

Composite images are made by combining elements from different images or photographs. Using the techniques you have learned, you can place these different elements, one of the other, and manipulate any way you want using opacity and blending modes.

But how does one put a composite image together? By using familiar commands, as copy, cut, and, in addition, portions of images can be cloned*, and then blurred or sharpened to create a uniform look.

### To copy a selection:

- 1. Use the selection tool of your choice to select an area of the image (for details how to do this, turn to Chapter 6, Making Selections) (Figure 1)
- 2. Right-click on the image and choose Edit→Copy from the pop-up menu (Figure 2) or press Ctrl+C on the keyboard. The selected area will be copied to the clipboard, ready for you to paste into another layer or image.

## Cutting, Copying, and Pasting
### More than One Selection

If you need to paste several cut or copied selections many times, the Paste Named command is for you. It works in conjunction with the Copy Named and Cut Named commands. First, using the Copy Named or Cut Named commands, you create selections saved to the clipboard with names. Then you use the Paste Named command to choose the named selection and paste it into an image.

![](img/5164bc49fb24f10213e18cc994b7b40c_207_0.png)

### To copy a selection using Named:

- 1. Use the tool of your choice to select an area (for details how to do this, turn to Chapter 6, Making Selections) (Figure 12).
- 2. Right-click on the image and choose Edit→Copy Named from the pop-up menu or press Shift+Ctrl+C on the keyboard. The Copy dialog box will open (Figure 14).
- 3. Enter a name for the selected area in the text box, then click OK. The selected area will be copied and saved in the clipboard with the name you gave it, ready for you to paste into another layer or image using the Paste Named command.
