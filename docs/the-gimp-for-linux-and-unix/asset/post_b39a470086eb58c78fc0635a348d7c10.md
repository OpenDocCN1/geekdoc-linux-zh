## Creating Text

Adding text to an image is easy using the Text Tool. You should know that once text is added to an image, though the text can't be edited.

To create text:

- 1. If you want to add the text to an existing layer, use the Layers & Channels dialog box to select that layer. (See page 92 for directions about how to do this.) If you're going to put the text on a new layer, skip this and move to step 2.
- 2. Select the Text Tool in the GIMP Toolbox. The mouse pointer will change to an I-beam.
- 3. Position the mouse I-beam where you want the text to appear, then click. The Text Tool dialog box will appear (**Figure 1**).
- 4. In the large text box at the bottom of the dialog box, type in the text you want to add to the image.
- 5. Use the Font list box to select a font. The text that you entered in the large text box will change to that font.
- 6. Use the Font Size text box to enter the size of the text. By default, the measurement is set to pixels. To change the measurement to points, use the drop-down list to the right of the font text box (**Figure 2**).
- 7. Make sure the Antialiasing button is selected. This will smooth the edges of the text. (If this check button is unselected the text edge will be quite jagged; turn to page 62 and take a look at Figure 4 to see what antialiased text looks like.)

## What Are Points?

Text is usually measured in points in most word processing, page layout, and graphic image manipulation programs. Unlike pixels, which change size depending upon the resolution of your monitor (see page 25 for a sidebar of pixels), a point is a fixed value. 72 point text is 1" (2.54 cm) high; 18 point text is 1¼ (6 mm) high. The text in this sentence is set in 10 point type.

## Type 1 and TrueType Fonts—What's the Difference?

PostScript Type 1 and TrueType are technical standards used to create fonts. Both standards are resolution independent, meaning they can be scaled to any size and retain their resolution. Fonts that are not scalable, as bitmap fonts, will look jagged when their size is changed. The difference between Type 1 and TrueType is in the mathematics used to describe the curves of the letters and the size of the files. Most high-end devices, such as printers, use PostScript Type 1 fonts since they can be sent directly to the output device. TrueType fonts are downloaded as bitmaps, but this can slow down printing. If you want to learn more about the differences between Type 1 and TrueType fonts, take a look at Thomas Phinney's excellent article at:
`http://www.truetype.com.uk/articles/phanney.html`
