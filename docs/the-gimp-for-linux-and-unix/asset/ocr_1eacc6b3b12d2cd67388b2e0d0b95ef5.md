# To add curves and corners to the straight segments:

+   1. With the Bezier Selection Tool still active, position the mouse crosshair over a control point, press the left mouse button and drag. Two handles will appear and the straight line will become curved (Figure 24).

+   2. Release the left mouse button when the curved segment is close to the shape you want. The control point will remain selected with the handles visible. You can now manipulate the handles individually to create smooth curves or sharp corners.

+   3. To create a smooth curve:

+   A. Position the mouse crosshair over a handle (Figure 25).

+   B. Press the left mouse button and drag the handle to a new position (Figure 26). Notice that you can drag a handle far away from or place it directly on top of its control point.

+   C. Release the left mouse button when you are happy with the shape of the curve (Figure 27).
