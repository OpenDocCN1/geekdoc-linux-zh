
## The Rectangular Select Tool

With the Rectangular Select Tool you can select rectangular and square areas. This tool works by clicking and dragging a boundary or marquee around a specific area of an image.

To select a rectangular area:

- 1. Use the Layers & Channels dialog box to set which layer is active. (This is the layer whose pixels will be selected.)
- 2. Click the Rectangular Select Tool in the GIMP Toolbox or press R on the keyboard.
- 3. Position the mouse crosshair at the upper-left corner of the area you want to select (Figure 8).
- 4. Press the left mouse button and drag diagonally down and to the right (Figure 9). As you drag a rectangle will appear.
- 5. Release the left mouse button when the entire area you want selected is encompassed by the rectangle. The selection will become activated and the rectangle's edge will change to a moving, dashed selection boundary (Figure 10).

## Tips

- To select an area that is an exact square, hold down the Shift key on the keyboard while dragging the mouse. Be sure to release the left mouse button first, before releasing the Shift key or the selection which will spring to a rectangular shape.
- This tool supports feathered. To learn more about this option and turn it on, take a look at page 62.
- If you are not happy with a selection, you can make a new one. When you make a new selection, the first one disappears.

## The Free-hand Selection Tool

The Free-hand Selection Tool (also called the lasso) works like a pencil on paper. As you press the mouse and drag, a selection boundary appears. Wherever you stop dragging and release the mouse, the GIMP will automatically close the boundary you have drawn, creating a closed selection area.

![](img/5164bc49fb24f10213e18cc994b7b40c_81_0.png)

Figure 14. Position the mouse crosshair where you would like the selection to start.

## To create a freehand selection:

- Use the Layers & Channels dialog box to set which layer is active. (This is the layer whose pixels will be selected.)
- Click the Free-hand Selection Tool in the Toolbox or press F on the keyboard.
- Position the mouse crosshair where you would like the selection to start (Figure 14).
- Press the left mouse button and drag. As you drag a selection boundary will appear (Figure 15).
- Release the left mouse button when you have encompassed the area. The GIMP will automatically close the boundary you have drawn (Figure 16).

![](img/5164bc49fb24f10213e18cc994b7b40c_81_1.png)

Figure 15. As you drag the selection appears.

## Tips

- This tool supports feathered. To learn more about this option and turn it on, take a look at page 62.
- You can add, to subtract, from or intersect a selection. For details about how to turn this to pages 77–79.

![](img/5164bc49fb24f10213e18cc994b7b40c_81_2.png)

Figure 16. When you release the mouse button, the selection becomes active.

## The Fuzzy Selection Tool

The Fuzzy Selection Tool creates a selection using color. When you click on a pixel, any touching pixels similar to that are selected. This tool is useful for selecting areas filled with one color. If you turn the Sample Merged option on, the blended from all layers is used.

![](img/5164bc49fb24f10213e18cc994b7b40c_82_0.png)

Figure 17. Position the mouse crosshair over the color you want to select.

## To select an area using the Selection Tool:

- 1. Use the Layers & Channels dialog box to set which layer is active. (This is the layer whose pixels will be selected).
- 2. Click the Fuzzy Selection Tool in the Toolbox or press Z on the keyboard.
- 3. Position the mouse crosshair over the color you want to select (Figure 17).
- 4. Press the left mouse button and drag. As you drag a selection boundary will appear (Figure 18).

![](img/5164bc49fb24f10213e18cc994b7b40c_82_1.png)

Figure 18. When you click, the surrounding pixels are selected.

## Tips

- This tool supports antialiasing and feathering. To learn more about these options and turn them on, take a look at page 62.
- You can add, to subtract, from or intersect a selection. For details about how to turn this to pages 77–79.

## To turn on the Sample Merged option:

- 1. In the GIMP Toolbox, double-click on the Fuzzy Selection Tool. The Tool Options dialog box will open, displaying the Fuzzy Selection Tool options (19).
- 2. Select the Sample Merged check button.
- 3. Click Close.

## Tips

- The Sample Merged option will remain until its check button is unselected.
