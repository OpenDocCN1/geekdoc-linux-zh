## To save an image in another file format:

- 1. Right-click on the image window and choose File->Save as from the pop-up menu (Figure 37). The Save Image dialog box will open (Figure 33).
- 2. Use the Directories list box to move to the directory where you want to store the file.
- 3. Type the name of the file with its file extension in the Selection text box (for instance, WebImage.png).
- 4. Click OK to save the file.

## Tips

- ■ In step 3, you can also select the file type using the Determine file type drop-down found in the Save Options area (Figure 38). By extension is selected by default. This means that if you type in the file extension after the file name, the GIMP will automatically save it as that file type.
- ■ If you try to save a file using an indexed color format such as GIF and the GIMP says the save failed, chances are the image needs to be converted to Indexed color mode before it can be saved. To find out how to convert an image to another color mode, turn to page 36.

## File Extensions and the GIMP

File extensions are the three or four letters that come after the period in a file name. In Linux/Unix there is no overall mechanism for associating file extensions with file types, though GIMP needs a file extension in order to save a file correctly. If you try to save a file in the GIMP without a file extension, a GIMP Message dialog box appears, saying that the saved file (Figure 36).

## COLOR AND THE GIMP

This chapter covers the basics of how color works in the GIMP. You'll discover the difference between vector- and pixel-based programs, how color models work, and how blending modes affect colors in an image.

![](img/5164bc49fb24f10213e18cc994b7b40c_48_0.png)

## Vector- and Pixel-Based Imaging Programs

Computer imaging programs are either vector based or bitmap based.

Figure 1. This vector image looks the same whether viewed far away or close.

In vector-based programs, such as CoreDraw and Illustrator, objects are created using mathematical formulas. This means that color is resolution-independent.

In bitmap-based programs, such as the GIMP, Corel PhotoPaint, and Adobe Photoshop, images are made of tiny squares called pixels. This pixel image looks smooth from far away but shows its pixels when close up.

![](img/5164bc49fb24f10213e18cc994b7b40c_48_1.png)

Figure 2. This pixel image looks smooth from far away.

## Color Models and Modes

A color model breaks colors down into their component parts. In the GIMP, color models are applied to images. 

## RGB Model

The Red, Green, Blue color model (normally called RGB) is used to display color on a computer monitor. RGB is an additive color model, meaning that color can be created using red, green, and blue in varying degrees. RGB has three channels. Typically color information is saved in 1-bit, 8-bit, or 24-bit color depth. Twenty-four-bit color stores the most information per pixel, up to a value of 256 per channel. In each channel a value of 0 is the darkest (black) and a value of 255 is the lightest (white). Figures 3a–b show an RGB image and its three channels on the Channels tab of the Layers & Channels dialog box.

![](img/5164bc49fb24f10213e18cc994b7b40c_49_0.png)

Figure 3a. This image is set in RGB mode (you'll have to use your imagination here since this figure isn't in color). Notice that the mode, RGB, appears in the title bar. This is a quick way to verify in which mode image is set.

![](img/5164bc49fb24f10213e18cc994b7b40c_49_1.png)

Figure 3b. The Channels page of the Layers & Channels dialog box shows the available channels.

## CMYK Model

The Cyan, Magenta, Yellow, Black color model (known as CMYK—the K represents black) is used in high-quality offset color printing. Instead of using light to display color as the RGB model, ink or toner is used. CMYK is a subtractive color model, meaning that as the colors get darker, they become black. CMYK has four channels per pixel. Since the GIMP was originally designed for creating digital and Web images, it doesn't support the CMYK color model. You may be interested to know that the next released version of the GIMP will support this color model.

## Other Names for Pixel and Vector

Pixel-based programs are often referred to as bitmap or raster programs. Vector-based programs are also called drawing or object-oriented programs.
