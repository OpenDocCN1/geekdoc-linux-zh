# Saving a GIF File in JPG File Format

If you want to save a GIF in the JPG file format, here's what you need to:

+   1. Convert the image to RGB color mode (see page 38 for directions).

+   2. Save the image as a .jpg file (turn to page 273 for directions)

**Figure 28.** If the image contained transparency before it was saved as a .gif file, the transparent areas are preserved. Notice that the strawberry has a transparent background which lets the background texture of the Web page show through.

+   TipnThe best graphics to save in .gif format are black and white, line drawings, and images that contain fewer than 256 colors. Photographs should be saved in the .jpg format.
