# To rename a layer:

+   1. Double-click on the name of the layer you want to change (Figure 9). The Edit Layer Attributes dialog box will open (Figure 10).

+   2. Type a new name in the Layer name text box.

+   3. Click OK. The Edit Layer Attributes dialog box will close and the layer name will change in the layer window (Figure 11).

![](bbox=[0.105, 0.275, 0.425, 0.365])

Figure 10. Type a new name in the Layer name text box.

# To delete a layer:

Figure 11.
The new layer name appears in the layer window.

![](bbox=[0.205, 0.455, 0.445, 0.605])

+   1. In the Layers & Channels dialog box, highlight the layer you want to delete.

+   2. Click the Delete button near the bottom right of the dialog box or press Ctrl+X on the keyboard. The layer will be deleted and disappear from the layer window.

or

Right-click on the name of the layer you want to delete and choose Delete Layer from the pop-up menu (Figure 12). The layer will be deleted and disappear from the layer window.

![](bbox=[0.105, 0.665, 0.445, 0.815])

# Tip

+   If you delete a layer and realize you made a mistake, here's how to get the layer back. Click on the image window to make it active, press Ctrl+Z on the keyboard. The layer will reappear.
