# Preparing an Image for a Service Bureau

When preparing files for a service bureau or print shop, you will probably need to generate PostScript (.ps) or Encapsulated PostScript (eps) files.

# To generate a .ps or .eps file:

- 1. Save your image by right clicking on the image and choosing File->Save from the pop-up menu (**Figure 22**).
- 2. Right-click on the image and choose File->Save from the pop-up menu (**Figure 23**). The Save dialog box will appear (**Figure 24**). (Using the Save as command creates a new copy of the file that remains open while the original image you saved in step 1 is automatically created. That way, you still have your original image intact.)
- 3. Use the Directories list box to move to the directory where you want to store the file.
- 4. In the Selection text box, enter the name of file. Make sure you enter the .ps or eps file extension after the name (**Figure 25**).
- 5. Click OK. The Save PostScript dialog box will open (**Figure 26**).
- 6. In the Unit area, select either the Inch or Millimeter radio button. This sets the unit of measure that you will use in the Width and Height text boxes in the next step.
- 7. In the Image Size area, use the Width and Height boxes to set the size of the image (in inches or millimeters). (If the keep aspect ratio check button is selected, the width and height will be sized proportionally.)

# GLOSSARY

# Airbrush Tool

The Airbrush Tool paints soft-edged strokes on an image.

# Alpha channel

A special grayscale channel that is used to save selections. These selections are used to protect areas of an image from editing.

# Antialias

Antialiasing creates a smooth transition from a filtered (or altered) area to a non-filtered area.

# Background color

Set using color selector in the GIMP Toolbox, the background color is applied when the Eraser Tool is used, a selection on the Background layer is moved, or when an area is erased using the Clear command.

# Bezier curve

A curved selection segment created using the Bezier Selection Tool can be reshaped using its control points and levers.

# Bezier Selection Tool

The Bezier Selection Tool is used to select areas with bezier curves.

# Bitmap mode

The simplest color mode. It contains no color or shades of gray, only black and white.

# Blending modes

A blending mode changes the way a layer's pixels blend with the pixels in the layer directly below it.

# Blend Tool

The Blend Tool is used to fill an area or selection with a gradual transition of two or more colors.

# Bucket Fill Tool

The Bucket Fill Tool is used to fill areas or selections with solid colors or patterns.

# Channel

A component of an image that contains the pixel information for an individual color. RGB image has three color channels while a grayscale image has one color channel.

# Clone Tool

The Clone Tool strokes color onto an image just like the Brush Tool, but instead of painting solid colors, the Clone Tool paints part of a selected image or pattern.

# CMYK color model

The Cyan, Magenta, Black color model is used in high-quality offset printing. (Black is the "key color," hence the K initial.) CMYK is a subtractive color model, meaning that as colors are mixed, darker colors are created.

# Appendix A

# Color mode

A way that color information is specified. For example, an image can be set in RGB mode, when converted to grayscale mode.

# EncapsulatedPostScript (EPS)

An image format that is commonly used.

# Color Picker Tool

The Color Picker Tool is used to select colors.

# Eraser Tool

The Eraser Tool erases parts of an image.

# Equalize

When an image is equalized, its colors are redistributed.

# Composite

An image made by combining different elements.

# Feathering

Feathering makes the transition smoother.

# Convolver

The Convolver Tool is used to sharpen an image.

# File extension

A set of letters that come after the period.

# Crop Tool

The Crop Tool cuts away part of an image.

# Filter

Filters are used to apply special effects to an image.

# Curves

Curves adjust the image's tonal range. 

# Flip Tool

The Flip Tool is used to mirror an image vertically or horizontally.

# Dither

Dithering simulates colors in an image.

# Floating Selection

A selection that is not anchored to a layer.

# Dots Per Inch (DPI)

A unit of measure that indicates the resolution of a printer.

# Foreground color

Set using the selector in the GIMP Toolbox, the foreground color is applied when painting.

# Desaturate

When an image is desaturated, all color is removed.

# Free-hand Selection Tool

The Free-hand Selection Tool works like a pencil and is used to select areas.

# Elliptical Selection Tool

The Elliptical Selection Tool is used to select round areas.

GLOSSARY

# Fuzzy Selection Tool

The Fuzzy Selection Tool creates selections using color. When a pixel is selected, the Fuzzy Selection Tool also selects areas similar in hue.

# Grayscale mode

An image in grayscale mode contains no color, only varying shades of gray. There are 256 shades of gray from black (0) to white (255).

# Layer

Layers are like clear glass windows stacked on top of other. Every new GIMP image starts with one layer, a special layer called the Background layer.

# Layer mask

A layer mask controls the way areas of an image are revealed.

# Guides

Guides (also known as guidelines) are horizontal and vertical lines that are positioned on an image to set up drawing or selection. A guide looks like a dashed blue line.

# Levels

Levels are used to make exact adjustments to an image's tonal range by setting highlights, midtones, and shadows.

# HSV color model

The Hue, Saturation, Value color model is used in combination with the RGB color model in the GIMP. Hue represents the color in use, saturation represents the intensity of the color, and value represents the intensity of light on the color.

# Magnify Tool

The Magnify Tool is used to enlarge and reduce the view of an image. It doesn't change the actual size of the image, only your view of it.

# Image display area

The area in the image window where the graphic is displayed. Also called a canvas.

# Move Tool

The Move Tool moves selections, layers, and guides.

# Image window

The area in the screen where images are created.

# Opacity

The density of a color in an image that ranges from transparent to opaque. In the GIMP, you can select an opacity for a layer or tool.

# Indexed color model

An indexed image contains a specific number of colors from 1 to 256.

# Paintbrush Tool

The Paintbrush Tool is used to paint strokes on an image.

# Intelligent Scissors Tool

The Intelligent Scissors Tool works with a mind of its own. After a selection has been drawn using the mouse, the Intelligent Scissors Tool goes to making its best guess as to exactly which edge is selected. Result selection is smoothly shaped, but can sometimes be unpredictable.

# Pencil Tool

The Pencil Tool draws hard-edged strokes on an image.

# Pixels

A unit of measure that is dependent upon the size of a computer monitor and its resolution setting.
