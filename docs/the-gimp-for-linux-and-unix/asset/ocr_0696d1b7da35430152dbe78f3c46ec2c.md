# Scaling and Resizing Layers

Scaling and resizing each change the size of a layer but with different consequences. Scaling changes both the size of a layer and its contents. Resizing changes the size of the layer, but does not alter the contents.

To scale a layer:

+   1. Open the Layers & Channels dialog box by right-clicking on the image and choosing Layers→Layers & Channels from the pop-up menu (Figure 3).

+   2. Right-click on the name of the layer you want to scale and choose Scale Layer from the pop-up menu (Figure 13).

or Highlight the layer you want to scale, then press Ctrl+S on the keyboard.

The Scale Layer dialog box will open (Figure 14).

+   3. Use the New width and New height text boxes to enter the layer's new dimensions in pixels. If the Constrain Ratio check button is selected, the horizontal and vertical proportions of the layer will remain the same.

+   4. Click OK. The Scale Layer dialog box will close and the layer will scale to its new size.
