# # Creating an Animation

If you like to browse the Web, you've probably seen such things like scrolling banners or blinking buttons. Animations enhance a Web site and are really very simple to make.

Animations are created using layers. If you think of it in film terms, each layer makes up one frame and frame is slightly different from the frame that comes before. When all the frames are quickly shown in succession, the object in the frames appears to move.

In this section, you'll learn how to create an animated text banner using a gradient. It's fun and easy (even though there are a lot of steps!), and uses a combination of the techniques you've learned while reading this book.

There are three animation filters you'll use when creating the animation: Animation Playback, Animation Optimize, and Animation Optimize.

Animation Playback lets you run an animation you've created without having to use a browser. It lets you see if the animation is choppy or needs fixing. You can work back and forth between the image window and the Animation Playback dialog box, fixing and running the animation until it's right.

Animation Optimize cuts out any extra space from each layer, making the overall file size much smaller. And, Animation Optimize—it returns the image to its original state.

# ## Good Web Site and Page Design

Before you design your Web pages, there are several things you should consider:

**Less is more.** When you design your Web pages, they should present the information you want to convey in an easy-to-comprehend fashion. Users should be able to move through a site without confusion and easily find what they are looking for. In Web page design, with good architecture, form should follow function. In other words, there should be a relationship between a Web page's appearance and what it is supposed to be.

**Plan site flow.** Web flow is the way users will move around your site and its pages. Often, this involves navigation through information displayed in a hierarchical fashion. For instance, if part of your site were used to show dessert recipes, there might be a link to the dessert page from your site's main page. (The main page is also called a home page.) One way to plan a Web site is to draw a diagram similar to a flow chart showing every connection between the pages. Many folks use low tech materials—a pencil and paper—to do this.

**Maintain a consistent look.** Use the same design elements across related pages of a Web site. This will give your site a consistent look and feel, and give site visual cohesion. In order to maintain visual consistency between the pages in a Web site, you should establish standardized fonts, colors, graphic styles, and site navigation tools as buttons.

**Use graphics and background colors.** Since the Web is a very visual medium, it's important to add art to your pages. A picture is worth a thousand words! Be careful, though: dark or busy backgrounds can make text difficult to read.
