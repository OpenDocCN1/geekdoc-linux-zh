# To make an image look like it's an old photograph:

1. Open the image you want to age (Figure 22).
2. Right-click on the image and choose Script-Fu→Decor→Old Photo (Figure 23). The Script-Fu Old Photo dialog box will open (Figure 24).
3. To unfocus the image a bit, select the check button to Defocus.
4. To add a photo-style border around the image, select the check button to Border.
5. To change the image's color to old-fashioned sepia tones, select the check button to Sepia.
6. To add some mottling to the image, select the check button to Mottle.
7. To create a copy of the original image that will be changed to look like an old photograph (and leave the original image unchanged), select the check button to Work Copy.
8. Click OK. The Script-Fu Old Photo dialog box will close and the script-fu will go to work. When it's finished, the image (or a copy of the image) will look like an old photograph (Figure 25).

# To quickly add a border around an image:

Figure 26. Open the image to which you want to add a border.

1. Open the image to which you want to add a border (Figure 26).
2. Right-click on the image and choose Script-Fu -> Modify -> Add Border from the pop-up menu (Figure 27). The Script-Fu Add Border dialog box will open (Figure 28).
3. To set the width of the left and right sides of the border, enter a value in pixels in the Border x text box.
4. To set the width of the top and bottom sides of the border, enter a value in pixels in the Border y text box.
5. Click the Border Colour button to open the Script-Fu Color Picker (Figure 29). Use the color picker to select the border.
6. OK. The Script-Fu Add Border dialog box will close and the script-fu will go to work. When it is finished a border will appear around the image (Figure 30).
