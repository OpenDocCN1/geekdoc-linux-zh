# To flatten all layers:

Right-click on the image and choose Layers→Flatten Image from the pop-up menu (Figure 37). All layers will flatten down to a single layer and the single layer will be shown in the Layers & Channels dialog box (Figure 38).

or

In the Layers & Channels dialog box, right-click in the layer window and choose Flatten Image from the pop-up menu (Figure 39). All layers will flatten down to a single layer and the single layer will be shown in the Layers & Channels dialog box (Figure 38).
