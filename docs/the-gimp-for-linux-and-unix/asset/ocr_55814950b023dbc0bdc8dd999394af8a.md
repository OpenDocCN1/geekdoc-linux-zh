# Printing an Image

Once you've created an image, as you'll probably want to print it for proofing or as final output. You should know however, that if your image contains more than one layer, only the active layer will be printed. To print an image, you'll need to flatten it first (turn to page 106 for directions).

# To print an image:

+   - Right-click on the image and choose File→Print from the pop-up menu (Figure 8). The print dialog box will open (Figure 9).

+   - Use the Printer drop-down list to select your printer. Most likely this is lp, lp0, or lp1.

+   - Use the Output Type buttons to select whether the image will be printed in black and white or color.

+   - Click Print. The Print dialog box will close and the image will print.

# Tips

+   - Once you set various printer options, they will be set up and ready to go every time you print. You should know, however, that the options you set aren't permanent. If you exit the GIMP, restart it, the options in the Print dialog box will return to the default settings.

+   - To print an image to a file, use the Printer drop-down list in step 2 to select File, then continue setting the various printer options.

+   - In case you were wondering when you select your printer in step 2, lp stands for the port that the printer is connected to. If you have more than one printer, it will be sequentially numbered, lp, lp0, lp1, etc.
