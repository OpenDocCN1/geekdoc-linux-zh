# The GIMP Pop-up Menus

The GIMP works mainly through the use of pop-up menus. These menus give access to all possible commands that affect an image, such as copying, adding layers, or applying a filter. All of the GIMP menus are shown in Figures 5–14 on the following three pages.

![](bbox=[0.104, 0.185, 0.483, 0.439])

**Figure 5.** The File menu is used to create, save, close, and print images. It is also used to set user preferences, email an image, and exit the GIMP. (You can also create and import images, set preferences, and exit the GIMP using the File menu in the GIMP Toolbox.)

![](bbox=[0.531, 0.185, 0.88, 0.439])

**Figure 6.** The Edit menu is used to cut, copy, and paste images, into selected areas, clear areas of color, fill areas with color, or add to a selection, and undo and redo actions. The Cut, Copy, and Paste Named commands let cut, copy, and paste multiple items.

![](bbox=[0.104, 0.613, 0.483, 0.768])

**Figure 7.** On the Select menu, the All command selects an entire layer. The None command removes all selections (not the areas inside the selections, just the selections, themselves). Other Select commands handle the selection boundary (toggle), and sharpen, float, grow, feather, or save selections to channels.

![](bbox=[0.531, 0.613, 0.88, 0.768])

**Figure 8.** The View menu is used to zoom in or out (changing your view of an image) and toggle rulers, and snap to guides on and off. The New View command displays the image in a secondary image window. Shrink Wrap lets you see the entire image window regardless of the zoom.
