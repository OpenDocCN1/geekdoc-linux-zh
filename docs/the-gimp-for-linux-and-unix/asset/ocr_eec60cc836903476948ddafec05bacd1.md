# # The Gradient Editor

Creating gradient blends with two colors is pretty fancy, there's more than you can do with the GIMP. Using the Gradient Editor, you can apply gradients with as many colors as you wish. In fact, the GIMP comes with an amazing list of multicolor gradients.
