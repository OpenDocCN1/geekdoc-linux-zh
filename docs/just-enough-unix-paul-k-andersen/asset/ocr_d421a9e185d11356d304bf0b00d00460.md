# 26.4  Renaming the Executable File

Note that the file containing the executable code is given the name a.out by the linker. If you want to save the executable code, you must use the mv command to give this file another name—otherwise, it will be overwritten the next time you use the cc compiler.

+   1  **Use the mv command to rename the executable file.** It is common practice to give the executable code the same name as the source code, but without the .c suffix:
+      
+      `$ mv a.out hello`\<Return\>

+   2  **Run the program.** Enter the new name of the executable file:
+      
+      `$ hello`\<Return\>
+      `Hello, world!`
+      `$`

As we shall see, you can compile the source code and rename the executable file all at once using cc with the -o option:

`$ cc hello.c -o hello`\<Return\>

Note that the arguments can be written in a different order:

`$ cc -o hello hello.c`\<Return\>
