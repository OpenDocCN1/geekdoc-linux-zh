# # 18 TUTORIAL:
# NAVIGATING WITH GOPHER

This chapter will show you how to navigate the Internet using gopher, a client-server browser that organizes information into a hierarchy of menus.

18.1 Contacting a Remote gopher Server

![](bbox=[0.1, 0.48, 0.26, 0.54])

In this section, you will see how to contact the gopher server at the University of Minnesota. This server runs on the host gopher.mic.ro.umn.edu:

1 Start gopher, giving it the Internet address of the server. Type

```
$ gopher gopher.mic.ro.umn.edu Return
```

gopher will respond by displaying a menu:

```
```
