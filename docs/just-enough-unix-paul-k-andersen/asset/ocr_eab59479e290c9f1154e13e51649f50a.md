# **WORKING WITH FILES**

# *6.2 Creating a File by Redirection*

A calendar for the year 1999 should have appeared on your screen, although it probably scrolled by too fast for you to read it all. Don't worry; in a moment you will see how to save this calendar in a file that you can examine at your leisure.

# **6.2 Creating a File by Redirection**

Many UNIX commands such as the `cal` command print their output on the standard output, which is usually the computer screen. However, the UNIX shell allows you to redirect the output from one of these commands so that it goes to a file instead of the screen.

+   1. **Select a name for the file.** Remember to use relatively short, descriptive file names. An appropriate name for a file holding the calendar for the year 1999 might be 1999.

+   2. **Enter the `cal` command, followed by the redirection operator (->) and the file name.** To put the calendar for the year 1999 into the file 1999, type
+      `\$ cal 1999 > 1999` **(RETURN)**
+      This time, the calendar does not appear on the screen; instead, the standard output from `cal` has been redirected into the file 1999.

+   3. **List the file names in your current working directory.** How do you know if the new file was created? You can check this by listing the files in your working directory using the `ls` command:
+      `\$ ls` **(RETURN)**
+      The name of the new file should appear:
+   
+      1999

> **WARNING**
> Since there was no file named 1999 in your home directory, the redirection operation created one. However, if you already had a file named 1999, the new information would have replaced anything previously in the file.

# **6.3 Viewing a File with `cat`**

Suppose you want to see the *contents* of a file, not just its name. One way to do this is by the use of the `cat` (“catenate”) command.

+   * **Type `cat`, followed by the file name.** Thus, to look at the 1999 file, type
+      `\$ cat 1999` **(RETURN)**
