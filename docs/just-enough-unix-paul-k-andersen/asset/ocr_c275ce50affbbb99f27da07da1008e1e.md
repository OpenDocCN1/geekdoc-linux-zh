# ### 18.9 Command Summary

**Starting gopher (UNIX shell prompt)**

+   - gopher Start gopher

**gopher Commands (gopher Prompt)**

+   - k or ↑ move to next line up
+   - j or ↓ move to next line down
+   - h or ← move to previous menu
+   - l or → select menu item
+   - u go up a menu
+   - ? print gopher help
+   - v view bookmarks
+   - a add bookmark
+   - q quit gopher session

# ### 18.10 Exercises

+   1. Using gopher, find the current weather forecast for Pocatello, Idaho. What is the probability of rain or snow?
+   2. Can you find a college or university library that has the book *Rational Thermodynamics*, by Truesdell? What about *Freeze-Drying of Foods*, by King?
+   3. Which movies are currently showing at the Rio Grande Downtown Mall in Las Cruces, New Mexico? (Hint: New Mexico State University is located in Las Cruces.)
+   4. What are the ten fastest-growing metropolitan areas in the United States?
+   5. What is a LISTSERV? What is the first article in `bit.listserv.techwr-l`? (Hint: Try the University of Michigan's gopher server.)
+   6. Where can you find earthquake information? What was the magnitude of the most recent earthquake recorded in the state of Washington?
+   7. When it is noon where you live, what is the local time in the Galapagos Islands, Ecuador?
+   8. What is the Electronic Newsstand, and when was it founded? How much does it cost to subscribe to *Dr. Dobb's Journal: Software Tools for Professional Programmers*?
