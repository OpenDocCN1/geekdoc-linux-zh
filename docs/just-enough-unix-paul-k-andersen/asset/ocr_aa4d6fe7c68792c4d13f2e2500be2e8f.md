2 **Use cat again, but redirect the output into another file.** For example, to create a file named *summer99*, enter the command
$ cat june99 july99 august99 > summer99 (RETURN)
This creates a new file containing a three-month calendar. Note that the redirection operator is required here.

3 **List the files.** The new file should appear:
$ ls (RETURN)
1999 july99 june99 august99 summer99

# 6.7 Appending to a File

The UNIX shell allows you to add information to the end of an existing file, an operation called *appending*.

+   • **Type the command, the append operator, and the name of the file.** To append the calendar for September 1999 to the file *summer99*, type the following line, making sure to use the append symbol (>>):
+   $ cat 9 1999 >> summer99 (RETURN)
+   Had you used the regular redirection symbol (>), the calendar for September would have replaced the calendars for June, July, and August that were already in the file. Instead, the September calendar was added to the end of the *summer99* file.

# 6.8 Copying a File with cp

The cp ("copy") command is used to copy files. We will use it to make a copy of the file *summer99*.

+   1. **Think of a name for the copy.** The usual rules for naming UNIX files apply. An appropriate name for a file containing a calendar for the summer of 1999 might be *SUMM99*.
+   2. **Enter the cp command, followed by the names of the original file and the copy.** To make a copy of *summer99* named *SUMM99*, type
+   $ cp summer99 SUMM99 (RETURN)
+   In this case, there is no existing file with the name *SUMM99*, so one is created.
+   3. **Verify that the new file appears.** UNIX does not alert you that a file has been copied, so you will have to check this yourself using the ls command:
+   $ ls (RETURN)
