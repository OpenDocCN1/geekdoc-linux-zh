# TRANSFERRING FILES

# 16.8 Getting Files with Anonymous ftp

When you reach the server, it will identify itself and prompt for your login name:

```
Connected to ds.internic.net.
220-      InterNIC Directory and Database Services
220-
200-Welcome to InterNIC Directory and Database Services
```

> Various warning and disclaimers appear here.

200 ds.internic.net FTP server ready.
Name (ds.internic.net:yourlogin):

+   2  **Enter the guest login name at the prompt.** Some servers expect you to enter “guest” as your login; others require “anonymous.” For the InterNIC server, use “anonymous”:

```
Name (ds.internic.net:yourlogin): anonymous <u>Return</u>
```

> Some servers require you to enter “guest” as your login name.

The server will notify you that it has accepted the login name; it may also prompt you for a password:

```
331 Guest login ok, send ident as password.
Password:
```

Some systems require no password; others use “guest” or “anonymous.” The InterNIC server asks you to enter your Internet identification.

+   3  **If necessary, enter the guest password.** The InterNIC server asks you to enter your Internet (i.e., electronic mail) address. Thus, if your Internet address were jsmit@merlin.podunku.edu, you would enter this at the prompt:

```
Password: ████
```

> Enter the required guest password here; it will not appear on the screen.

+   4  Use *ftp* commands to find and transfer files.

+   5  When you are finished, quit *ftp* as before.
