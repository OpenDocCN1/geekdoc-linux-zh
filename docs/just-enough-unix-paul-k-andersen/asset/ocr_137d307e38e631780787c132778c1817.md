most cases, it looks for a file having the same name as the command. If the shell can't find the right software, it gives you an error message; otherwise, the shell asks the kernel to run it.

+   5. **The kernel runs the requested software.** While the command is running, the shell “goes to sleep.” When the kernel finishes, it “wakes up” the shell.

+   6. **The shell again displays a prompt symbol.** This indicates that the shell is once again ready to receive your commands.

This is a good place to point out the difference between a program and a process in UNIX jargon. *A program* is a set of coded instructions contained in a file. An example of a program is the 1s command: it is just a sequence of computer instructions contained in the file */bin/1s*. Similarly, your login shell is also just another program residing in the directory */bin*.

![](bbox=[0.08, 0.39, 0.19, 0.44])

*A process* is what you get whenever you tell the computer to run a program. Thus, when you issue the 1s command, the computer creates an 1s process by running the program in the file */bin/1s*. Likewise, when you log in, the computer looks in the file containing the shell program and creates a shell process for you.

The important thing to remember is that there is only one copy of the 1s program, but there may be many active 1s processes. In the same way, there is only one copy of each shell program, but there may be many active shell processes.

# ## 8.3 Options and Arguments

The typical UNIX command can take one or more options, which modify what the command does. For example, the 1s command takes numerous options:

| Command | Effect |
| :--- | :--- |
| 1s | List files in the current directory (except hidden files) |
| 1s -a | List all files in the current directory, including hidden files |
| 1s -F | Flag the files: show a slash (/) after each directory, an asterisk (*) after each executable file |
| 1s -1 | Print “long” list of files (except hidden files) |
| 1s -r | List in reverse order |
| 1s -s | List files by size |
| 1s -t | List files by time of last modification |
| 1s -u | List files by time of last access |
