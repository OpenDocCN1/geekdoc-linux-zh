Pseudocode for the recip.f program.


**Listing 27-2B**
Fortran code for the recip.f program.

```
C Compute reciprocals
C234567

   PROGRAM RECIP
   INTEGER N, RECIP

   WRITE(*,*) 'This program computes reciprocals.'

   WRITE(*,*) 'The reciprocal of ', N, ' is ', RECIP
   END
```
