# ## **22.8** **Setting the Terminal Type**

Having to set your terminal each time you log in is a nuisance—especially if you use the same kind of terminal all of the time. You can set the terminal in your .login file.

+   1. **Edit your .login to set the terminal type.** Insert the following lines, substituting your terminal’s termcap code for vt100:
+   	```text
+   		set term = vt100
+   		echo "Terminal set to $term"
+   	```
+   2. **Write and quit the editor.**
+   3. **Apply the source command to .login:**
+   	```text
+   	/home/you > source .login (Return)
+   	```
+   
+   Your login message should appear, then the message:
+   
+   	```text
+   	Terminal set to vt100
+   	```

# ## **22.9** **Making a calendar File**

The calendar utility will remind you of upcoming events. This requires that you have a calendar file in your home directory and that you modify .login to read the calendar file.

+   1. **Edit your .login with the text editor.** Add the following line:
+   	```text
+   	calendar
+   	```
+   2. **Write the change into the file and quit the editor.**
+   3. **Use the text editor to create a calendar file.** Be sure to use this exact spelling of calendar, in lowercase letters. Otherwise, the shell won’t recognize the file.
+   4. **Add a message to the calendar file.** Include today’s date in the message:
+   	```text
+   	This is a test for [today’s date]
+   	```
+   5. **Write the changes into the calendar file and quit the editor.**
+   6. **Use the source command to run the .login file.**
+   	```text
+   	/home/you > source .login (Return)
+   	```
+   
+   You should see your login message, the message about the terminal type, and the calendar message:
+   
+   	```text
+   	Your wish is my command, Oh Great One.
+   	Terminal set to vt100
+   	This is a test for [today’s date]
+   	```
