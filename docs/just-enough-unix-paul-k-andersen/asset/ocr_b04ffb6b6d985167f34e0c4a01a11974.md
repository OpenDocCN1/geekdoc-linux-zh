# ### 7.5 Using Pathnames to Move Files

In this section, you will move a file into the Months directory, using a pathname to specify the file’s new location.

+   1. **Enter the mv command, the file name, and the new pathname.** Thus, to move the file june99 into Months, type
+      ```
+      $ mv june99 Cal/Months [RETURN]
+      ```
+      At this point, your directory structure should look something like Figure 7–5.

![](bbox=[0.09, 0.34, 0.95, 0.71])

+   2. **List the files in the current directory.** The ls command should show that june99 is no longer in the current directory:
+      ```
+      $ ls [RETURN]
+      Cal august99 fun july99 summer99
+      ```
