# 6.1 **Printing a Calendar**

Many of the examples in this chapter make use of the UNIX utility `cal`, which displays a calendar for any month or any year from AD 1 to AD 9999. To see how this works, try some examples:

+   1. **Print a calendar for a given month.** For example, to show the calendar for the fifth month of the year 1999, type the command

```
$ cal 5 1999 (RETURN)
```

The computer will respond with the calendar:

![](bbox=[0.33, 0.67, 0.57, 0.78])

+   2. **Print a calendar for an entire year.** To do this, specify the year but not the month:

```
$ cal 1999 (RETURN)
```
