# ### 9.7 PIPES AND TEES

A pipe connects the standard output from one utility to the standard input of another utility. A tee allows you to take the output from a command and direct it into a file and to another command. In this section, you will practice using pipes and tees.

+   - **View the calendars for 2000 and 2001, one page at a time.** One of the following command lines will do:

```
```
$ (cal 1999; cal 2000; cal 2001) | more( Return )
```
or
```
$ (cal 1999; cal 2000; cal 2001) | pg( Return )
```
```

+   - **View the calendars for 2000 and 2001, and create a file containing these calendars.** This requires a tee and two pipes:

```
$ (cal 2000; cal 2001) | tee calfile | more( Return )
```

+   - **List the files in the root's subdirectories, one page at a time.** Either of the following commands will work to pipe the output from ls to the more or pg utility:

```
```
$ ls -a /* | more( Return )
```
or
```
$ ls -a /* | pg( Return )
```
```

+   - **List the files in the root's subdirectories and create a file containing this listing.** This can be done using two pipes and a tee:

```
$ ls -a /* | tee root.list | more( Return )
```
