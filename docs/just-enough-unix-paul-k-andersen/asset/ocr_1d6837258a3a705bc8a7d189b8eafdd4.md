+   **2** **Repeat the most recent command** on the list. This is done by typing an *r* at the prompt. Try it:
+   `/home/you > r (Return)`
+   
+   You should see another listing of commands, as before:

+   **3** **Repeat a command by number.** Thus, to repeat the sixth command on the list, type
+   `/home/you > r 6 (Return)`
+   
+   The command line will appear on the screen, and the command will be run.
+   `echo "Your wish is my command, Oh Great One."`
+   Your wish is my command, Oh Great One.
