# NAVIGATING WITH GOPHER

18.1 Contacting a Remote gopher Server

An arrow cursor (→) marks the current menu selection; in other words, if you press Return, you will get the choice indicated by the arrow. A slash (/) at the end of a line marks an entry that leads to another menu. A question mark <?> indicates that a choice leads to a search program.

+   2  **Move the cursor to the option you want.** The j, k, l, and h keys move the cursor; on some terminals, you can also use the arrow keys:
+   
+   k or ↑	move up to next line
+   j or ↓	move down to next line
+   h or ←	move to previous menu
+   l or →	select menu item
+   
+   Move the cursor to the Fun and Games selection:
+   -->	4. Fun & Games/

+   3  **Select the option.** Press Return if the arrow cursor is pointing to the choice you want:
+   
+   -->	4. Fun & Games/ Return
+   
+   The gopher server will present another menu of options:

| Fun & Games |
| --- |
| --> 1. Games/ |
| 2. Humor/ |
| 3. Movies/ |
| 4. Music/ |
| 5. Recipes/ |
| Press ? for Help, q to Quit, u to go up a menu | Page: 1/1 |

+   4  **Make the next menu choice.** Suppose you wanted to see what gopher recipes might be available. You can either move the cursor to the desired selection as you did before, or you can specify that selection by number. Enter the number (5 in this case):
+   
+   View item number: 5 Return
