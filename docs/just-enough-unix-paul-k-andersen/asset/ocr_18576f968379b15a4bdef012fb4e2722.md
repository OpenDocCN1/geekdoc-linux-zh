# C.3 Logging Out

Some systems are configured to allow you to log out with a menu option. If your system does not offer such an option, logging out may be somewhat more complicated.

+   1. **Quit the window manager.** There should be an option marked "Exit" or "Quit" on one of the pop-up menus. In some cases, this option will also stop X and log you out.
+   2. **If necessary, stop X.** Closing the original xterm window will do the trick.
+   3. **If necessary, log out.** One of the following commands should work:

```
$ logout \(Return\)
$ exit \(Return\)
$ \(Control-D\)
```

It is a good idea to ask your system administrator about the logout procedure.
