# ### 15.6 Connecting to Guest Accounts

Normally, you must have an account on any remote host to which you want to connect using \texttt{telnet}. However, a number of special \texttt{telnet} accounts have been created on the Internet to provide services to the public. There are two ways to log into such an account.

The first—and perhaps most common—method requires that you connect to the host computer using \texttt{telnet}, then log into the account using a special login name and password. (Many systems do not require a password.) For example, the National Aeronautics and Space Administration maintains a public service called “Spacelink” that provides information on the past, current, and planned activities of NASA. You can use \texttt{telnet} to connect to this service:

```
```tex
$ telnet spacelink.msfc.nasa.gov (Return)
```
```

When you reach the server, it will prompt you for a login:

login:

The login to be used is \texttt{guest}; no password is required for this particular service.

The second method is to use \texttt{telnet} to log into the server through a special “port,” designated by number. It is usually unnecessary to provide either a login or password. For example, the University of Michigan maintains a server that provides geographic information (including the latitude, longitude, elevation, and zip code) of towns and cities in the United States. You can gain access to this server by the command

```
```tex
$ telnet martini.eecs.umich.edu 3000 (Return)
```
```

Note the number 3000; this is the port number.
