Figure 5-2 shows **home** and two of the users' home directories it contains (**jack** and **jill**). You have already seen that the pathname for **home** is
**/home**

The full pathname for the user directory **jill** is
**/home/jill**

This is called the pathname of **jill** because it tells what path to follow to get from the root directory to **jill**. In this case, the path goes from the root directory, to the directory **home**, and finally to **jill**. Continuing further, the subdirectory **Marsupials** has the absolute pathname
**/home/jill/Marsupials**

Ordinary files also have absolute pathnames. For example, the pathname of the file **wombat** is
**/home/jill/Marsupials/wombat**
