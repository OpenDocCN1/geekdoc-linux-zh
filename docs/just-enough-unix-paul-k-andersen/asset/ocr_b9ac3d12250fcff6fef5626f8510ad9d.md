# 11 TUTORIAL:
EDITING WITH VI

In this chapter, you will see how to use the vi editor to create and edit a new file. If you haven't already done so, log in and set your terminal. Then follow the examples.

# 11.1 Opening a New File

+   1. **Select a name for the new file**. The name should be descriptive. Thus, a good name for a file that will contain poetry might be **poems**.

+   2. **Enter the vi command, followed by the name of the new file**. To create a file named **poems**, type the command line

```
`$ vi poems (Return)`
```

If your terminal is set properly, you should see something like this:
