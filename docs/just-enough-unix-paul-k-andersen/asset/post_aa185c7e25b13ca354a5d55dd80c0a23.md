
## 17.6 Saving a News Article

Occasionally, you may want to save a copy of a Usenet article. The `Save` command puts a copy of the article into a file in a directory named `News` in your home directory.

- 1. Save the article. At the prompt, type `s` (for "save"), followed by the name of the file that is to contain the article:

```
--what next? [npq]s newsfile   (Return)
```

The news reader will inform you that the file does not exist, and will ask whether you want to create a file using the "mailbox format."

```
File /home/yourlogin/News/newsfile does not exist--
use mailbox format? [ynq]
```

- 2. Select mailbox format. At the prompt, type `y` (for "yes").

```
use mailbox format? [ynq]y   (Return)
```

## 17.7 Quitting the News Reader

- • When you are finished, quit the news reader. Type `q` (for "quit") at the prompt:

```
End of article 75072 (of 75305)--what next? [npq]q   (Return)
```

## 18 TUTORIAL: NAVIGATING WITH GOPHER

This chapter will show you how to navigate the Internet using `gopher`, a client-server browser that organizes information into a hierarchy of menus.

### 18.1 Contacting a Remote gopher Server

![](img/52d592fcd97ba67dcb2b4a36fde4eb4c_199_0.png)

In this section, you will see how to contact the `gopher` server at the University of Minnesota. This server runs on the host `gopher.mic.ro.umn.edu`:

- 1. Start `gopher`, giving it the Internet address of the server. Type:

```
$ gopher gopher.mic.ro.umn.edu Return
```


An arrow cursor (→) marks the current menu selection; in other words, if you press Return, you will get the choice indicated by the arrow. A slash (`/`) at the end of a line marks an entry that leads to another menu. A question mark `<?>` indicates that a choice leads to a search program.

- 2. **Move the cursor to the option you want.** The `j`, `k`, `l`, and `h` keys move the cursor; on some terminals, you can also use the arrow keys:
    - `k` or `↑` move up to next line
    - `j` or `↓` move down to next line
    - `h` or `←` move to previous menu
    - `l` or `→` select menu item

```

```

### 18.2 Mailing, Printing, or Saving Text Files

Sometimes you will find a text file that you would like to retain for future reference. Whenever `gopher` displays such a file, it will also display a prompt:

```
Press <RETURN> to continue, <m> to mail, <s> to save, or <p> to print:
```

The meaning of this should be obvious. If, for example, you want to mail a copy of the file to yourself, press the `m` key.

### 18.3 Jumping to the Main Menu

When you have finished searching the various menus offered by the Minnesota `gopher` server, you can return to the main menu where you started:

- Press the `m` key. This is the command to jump back to the main menu:

```
m
```

Thus, if you have been working on the University of Minnesota's `gopher` server, you will be returned to the main menu you saw before.
