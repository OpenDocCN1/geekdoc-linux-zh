# 6.6 Chaining Files Together with `cat`

You previously used the `cat` command to view the contents of a file. When given a single file name, `cat` simply displays the contents of that file; when two or more file names are used together, `cat` displays all of the files, one after another. This can be used to join together the contents of multiple files.

Your next task is to use `cat` to make a calendar for the summer months of 1999. First, use the `cal` utility to make three files:

```
```
$ cal 6 1999 > june99 (RETURN)
$ cal 7 1999 > july99 (RETURN)
$ cal 8 1999 > august99 (RETURN)
```
```

+   1. View the files with `cat`. Enter the `cat` command followed by the file names:

```
```
$ cat june99 july99 august99 (RETURN)
