# 14.13 Obtaining an Address

Before you can send mail to someone, you must know his or her login. If you can ask the person directly for his or her login, fine. Otherwise, you may have to make an intelligent guess at the login, and then use the `finger` command to confirm your guess. `finger` tells you the real name of the person who uses a particular login name.

When used without an argument, `finger` lists everyone who is currently logged into the system.

+   *   **Enter the `finger` command, giving the person's login as an argument.**
+   The first time, you might try it on your own login:

```
$ `finger` `yourlogin` **<Return>**
```

You should see information about the user:
Login name: `yourlogin`
In real life: Your Name
Your office:
Phone: 555-5555

However, if the `finger` command is not available, the system will say so:
`finger:` **Command not found**

Some versions of `finger` can tell you the login name of a user, given his or her last name.

+   *   **Enter the `finger` command, giving the person's last name as an argument.**
+   The first time, you might try it on your own name:

```
$ `finger` `yourname` **<Return>**
```

This should produce either a list of users having your last name or an error message of some sort.

# 14.14 write and talk

`write` and `talk` are discussed in Appendix E.

The `write` and `talk` utilities allow two users who are logged into the system to send typed messages to each other. If someone tries to communicate with you this way, you will receive a message like this:
Message from george on tty10
To learn how to respond using `write` or `talk`, refer to Appendix E.
