# 3.11 Reading the UNIX Manual

Many UNIX systems come equipped with a detailed on-line manual that you can read using the man command. The manual describes the commands that are available on the system. To see how this is done, try the following command:

```
$ man cal<kbd>RETURN</kbd>
```

The cal command is one that we will use in later chapters; it displays a calendar on the screen. If your system has the on-line manual, you should see a description of cal. (For more information on how to make sense of the manual, see Appendix B.) Otherwise, you will see the message

```
man: Command not found.
```

# 3.12 Logging Out

When you are finished working on the computer, you must "log out." This tells the system that you are finished using it.

> **WARNING**
> NEVER LEAVE THE TERMINAL WITHOUT LOGGING OUT FIRST. On some UNIX systems, your account will remain open even if your terminal is turned off. This invites the unscrupulous to get into the system and cause trouble.

+   1. **If you are using the C Shell, try the `logout` command:**
+      `% logout<kbd>RETURN</kbd>`
+   2. **If you are using the Bourne or Korn Shell, try the `exit` command:**
+      `$ exit<kbd>RETURN</kbd>`
+   3. **If neither `logout` nor `exit` works, try ^D.** Remember, the notation ^D means you should hold down the <kbd>CONTROL</kbd> key and type the letter *D*:
+      `$ <kbd>CONTROL</kbd>-$ D`
+   4. **If necessary, log out from the terminal server.** If you had to log onto a terminal server before selecting a computer host, you may also have to log out from the terminal server.
+   5. **If nothing seems to work, ask for help.** Do not leave without logging out first.
