Perhaps the most interesting feature shown in Listing 27–6 is the **PARAMETER statement:**

```
PARAMETER   (POP0 = 1.2)
```

This statement causes the Fortran compiler to search through the subroutine and replace every occurrence of the string `POP90` with 1.2, the population (in millions) of Indianapolis in 1990.

# 27.15  Linking and Running the Trip Program

If you have done everything correctly, you should now have four files of Fortran source code and four files of object code in the directory `Trip`. In this section, you will see how to link the object files to create an executable file.

1. **Verify that the object files exist.** Enter the `ls` command:

```

`chicago.f`    `indiana.f`    `indy.f`     `main.f`
`chicago.o`    `indiana.o`    `indy.o`     `main.o`
```
