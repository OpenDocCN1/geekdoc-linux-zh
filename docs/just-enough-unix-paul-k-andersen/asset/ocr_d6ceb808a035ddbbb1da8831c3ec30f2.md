# ### 18.6 Contacting the Default Server

All of the examples you have seen thus far in this chapter have involved the gopher server located at the University of Minnesota. However, it is not necessary that you always contact the Minnesota server. In fact, if your institution has its own gopher server, it will usually be set up as your default server. In most cases, this is the server you will want to contact first. From there, you can easily go to the Minnesota server or any of the other gopher servers worldwide.

+   * Start gopher without specifying a server. Enter gopher and press Return:
+     $ gopher Return
+   This should put you in contact with your default gopher server.

# ### 18.7 Setting a Bookmark

If you find yourself returning again and again to the same gopher locations, you can keep track of such locations by setting bookmarks. A bookmark will take you directly to the marked place, thus saving yourself the trouble of having to navigate through numerous menus.

+   1. Go to the place where you want to set the bookmark.
+   2. Add the bookmark. Type a (for "add"):
+      a
+      This will bring up a dialog box.
+   3. Enter a name for the bookmark in the dialog box. Choose a name that is descriptive and type it into the box.
+   4. Press Return when you finish.

# ### 18.8 Selecting a Bookmark

Once you have set a bookmark, it will appear on a gopher menu. You can call up this menu whenever you want to select the bookmark:

+   1. Enter the View command. Type v (for "view"):
+      v
+      A gopher menu should appear, showing your bookmarks.
+   2. Select a bookmark from the menu. You can select a bookmark as you would any other item on a gopher menu. This will take you directly to the place you have marked.
