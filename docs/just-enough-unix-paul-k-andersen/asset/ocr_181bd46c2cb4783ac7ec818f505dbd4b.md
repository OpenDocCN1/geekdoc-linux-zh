# 19.3 Specifying a Document by Its URL

It is easy to obtain a WWW document if you know its Universal Resource Locator or URL. The Library of Congress home page is a good place to start when you are getting used to running Netscape.

+   1. Find the Open button. This button is located in the toolbar near the top of the Netscape window:

![](bbox=[0.29, 0.28, 0.37, 0.35])

+   2. Click on the Open button. A dialog box will appear:

![](bbox=[0.35, 0.4, 0.84, 0.53])

+   3. Enter the URL in the box. For the Library of Congress, the URL is
+   `http://lcweb.loc.gov/homepage/1chp.html`

+   4. Click on **Open**. Alternatively, you can press (Return) at the end of the URL. It may take a minute or so for the Library of Congress home page to appear. During this time, “shooting stars” move across the Netscape logo and the color of the Progress Bar changes to indicate that the program is working. At the same time, a message appears in the Message Status Field. Eventually, you should see the home page of the Library of Congress.
