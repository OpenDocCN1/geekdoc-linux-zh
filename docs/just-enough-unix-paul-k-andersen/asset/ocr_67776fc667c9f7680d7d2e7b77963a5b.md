# **F.6\tPrinting Expressions**

The print command allows you to examine the values of variables. For example, to view the value of n, you would enter

```
\(dbx\)\tprint n\(Return\)
```

dbx will respond with the current value of n:

```
n = 1
\(dbx\)
```

Step again:

```
\(dbx\)\tstep
stopped in main at line 12 in file "recip.c"
12\tprintf("The reciprocal of %d is %d.\n", n, recip);
```

Use print to check the values of both n and recip:

```
\(dbx\)\tprint n, recip\(Return\)
n = 1
recip = 1
\(dbx\)
```
