Each of the commands listed here is entered in an xterm window at the shell prompt symbol.

# Changing Your Password

passwd<sub>RETURN</sub>      change password

# Opening an xterm Window

xterm &<sub>RETURN</sub>

# Miscellaneous UNIX Commands

date<sub>RETURN</sub>        print current date and time
who<sub>RETURN</sub>         print a list of users currently logged in
who am i<sub>RETURN</sub>   print your login
man cal<sub>RETURN</sub>     show the manual page describing cal command
