## 18.4 Searching Gopherspace

Burrowing through the gopher menus can be a lot of fun, but at times you may want a more efficient way of finding the information you need. There are several ways that gopher can conduct a search for the items you want. The easiest is to find a menu item that leads to a search program. For example, one of the choices on the University of Minnesota's main gopher menu shown above allows you to search the menus on that server:

10. Search Gopher Titles at the University of Minnesota <?>

Note the tag <?> at the end of the line; this marks a menu choice that calls up a search program. Using such a program is fairly easy:

- 1. **Find a menu that has a search option.** Suppose, for example, that you were interested in finding out what information is available at the University of Minnesota related to "earthquakes." You would first go to the main menu of the University of Minnesota gopher server.
- 2. **Select the search option.** On the Minnesota menu shown above, option 10 is the one you want.

View item number: 10 (Return)

A search box will appear:

```
+-------------------------------+
| Search Gopher Titles at       |
| Words to search for           |
| [earthquakes                 |
| [Help: ^-] [Cancel: ^G]       |
+-------------------------------+
```

- 3. **Enter the keyword(s) into the search box.** Thus, if you are interested in “earthquakes,” enter this as the keyword. Then press **Return**.

```
+-------------------------------+
| Search Gopher Titles at       |
| Words to search for           |
| [earthquakes                 |
| [Help: ^-] [Cancel: ^G]       |
+-------------------------------+
```

The search program will return a menu of items that contain the word “earthquake” in their titles.

- 4. **Select the item that interests you.**

## 18.5 Quitting gopher

- 1. **Enter the Quit command.** Type *q* (for “quit”) at the prompt:

      Press ? for help, q to Quit, u to go up a menu q
      The gopher program will ask if you really want to quit:
      Really quit? [y or n]

- 2. **Confirm your intention to quit.** Enter *y* (for “yes”) at the prompt:

      Really quit? [y or n]y

### 18.6 Contacting the Default Server

All of the examples you have seen thus far in this chapter have involved the gopher server located at the University of Minnesota. However, it is not necessary that you always contact the Minnesota server. In fact, if your institution has its own gopher server, it will usually be set up as your default server. In most cases, this is the server you will want to contact first. From there, you can easily go to the Minnesota server or any of the other gopher servers worldwide.

- Start gopher without specifying a server. Enter gopher and press Return:
  - $ gopher Return
  - This should put you in contact with your default gopher server.

### 18.7 Setting a Bookmark

If you find yourself returning again and again to the same gopher locations, you can keep track of such locations by setting bookmarks. A bookmark will take you directly to the marked place, thus saving yourself the trouble of having to navigate through numerous menus.

- 1. Go to the place where you want to set the bookmark.
- 2. Add the bookmark. Type a (for "add"):
  a
  This will bring up a dialog box.
- 3. Enter a name for the bookmark in the dialog box. Choose a name that is descriptive and type it into the box.
- 4. Press Return when you finish.

### 18.8 Selecting a Bookmark

Once you have set a bookmark, it will appear on a gopher menu. You can call up this menu whenever you want to select the bookmark:

- 1. Enter the View command. Type v (for "view"):
  v
  A gopher menu should appear, showing your bookmarks.
- 2. Select a bookmark from the menu. You can select a bookmark as you would any other item on a gopher menu. This will take you directly to the place you have marked.

# 19 Tutorial: Browsing the WWW

> You cannot use Netscape without a GUI, but you may be able to use a text-based browser such as Lynx—see Exercise 12.

In this chapter, you will learn how to use Netscape, a powerful World Wide Web (WWW) browser. Netscape is not the only WWW browser available, but it is the most widely used. Versions of Netscape are available for the Apple Macintosh, for IBM-compatible personal computers running Microsoft Windows, and for UNIX machines running the X Window System.

A word of warning: It seems that nothing on the World Wide Web stays the same for long. Do not be surprised, therefore, if some of the Web documents are no longer where we say they are, or if their appearance is not exactly as shown.

## 19.1 Starting Netscape

There are basically two ways to start the Netscape browser, depending on how your system administrator has set up your account.

- 1. **If necessary, start X and the window manager.** You will not be able to use Netscape on a text-only display.
- 2. **Select the Netscape option on one of the pop-up menus.** This assumes, of course, such an option has been provided on your system.
- 3. **If Netscape is not available as a menu option, start the program from the command line.** At the shell prompt, type netscape, an ampersand (&), and Return.

```
$ netscape & (Return)
```

It may take a moment or two for Netscape to start up. Eventually, you will see your *default home page*; in most cases, this will be the Netscape company home page, as shown in Figure 19-1. Note that the URL for this page is shown in the box marked "Location."
