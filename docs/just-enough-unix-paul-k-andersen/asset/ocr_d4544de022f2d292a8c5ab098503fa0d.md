# # G APPENDIX: MAINTAINING PROGRAMS WITH MAKE

The UNIX **make** program is designed to manage large, multifile projects by keeping track of any changes that are made in the source files. It allows you to modify and recompile one source file without having to recompile the entire program.

# ## G.1 The makefile

The **make** program looks for its instructions in a file named either **makefile** or **Makefile**. For the program in the **Trip** directory, create a file named **makefile**, and enter the lines shown in Listing G–1.

```
```
# Makefile for the Trip program

trip: main.o chicago.o indiana.o indy.o
	Ctrl+C cc -o trip main.o chicago.o indiana.o indy.o

main.o: main.c
	Ctrl+C cc -c main.c

chicago.o: chicago.c
	Ctrl+C cc -c chicago.c

indiana.o: indiana.c
	Ctrl+C cc -c indiana.c

indy.o: indy.c
	Ctrl+C cc -c indy.c

clean:
	Ctrl+C rm *.o
