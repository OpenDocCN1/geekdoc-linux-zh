# 12 TUTORIAL:
MORE VI EDITING

You learned enough about the vi editor in the previous chapter to create and edit files. Now you'll see some additional features that can be very useful.

If you want to follow along with the examples in this chapter, use the R ("Replace") command to introduce a few misspelled words into the file poems that you created in the last chapter:

```
Poem #1
Marge had a wit tle wamb,
A wit tle cheese,
A wit tle ham.
Delisious!
```

```
Poem #2
Mary had a polar beer
Whose fir was white as snow,
And everywhere that big bare went
The people let it go.
~
```

Be sure to write these changes into the file.

# 12.1 Using spell

spell is a UNIX utility that checks your spelling. Unlike many spell-checkers that are supplied as part of a word processor or text editor, spell is an entirely separate program. Consequently, you will not use spell at the same time you are editing a file with vi.
