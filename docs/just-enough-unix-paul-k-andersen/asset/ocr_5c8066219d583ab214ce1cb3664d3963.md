# 18.2 Mailing, Printing, or Saving Text Files

Sometimes you will find a text file that you would like to retain for future reference. Whenever gopher displays such a file, it will also display a prompt: Press <RETURN> to continue, <m> to mail, <s> to save, or <p> to print: The meaning of this should be obvious. If, for example, you want to mail a copy of the file to yourself, press the m key.
