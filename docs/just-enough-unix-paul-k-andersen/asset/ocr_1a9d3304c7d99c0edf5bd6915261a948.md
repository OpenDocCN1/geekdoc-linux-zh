# ## 16.16 Exercises

1. Be sure you can define the following terms:

+   - anonymous ftp
+   - archive file
+   - ASCII file
+   - binary file
+   - tar file

2. Use ftp's help command to determine what the following commands do:

+   - append
+   - bell
+   - bye
+   - cd
+   - cdup
+   - delete
+   - dir
+   - disconnect
+   - lcd
+   - ls
+   - mdelete
+   - mkdir
+   - mkdir
+   - mls
+   - nput
+   - pwd
+   - recv
+   - remotelp
+   - rmdir

3. As an example of what is available by anonymous ftp, there is an extensive collection of information on scuba diving on the host ames.arc.nasa.gov. Log in as "anonymous" and see if you can get any information on scuba diving in New Mexico.

4. Information on NASA and its programs can be obtained by anonymous ftp from the host explorer.arc.nasa.gov. Log in as "anonymous" and try to get a list of Frequently Asked Questions (FAQ) related to the requirements for becoming an astronaut.

5. Genealogical information can be obtained by anonymous ftp from the host ftp.cac.psu.edu. Log in as "anonymous" and see if you can obtain a list of useful tips for beginning genealogists.

6. Larry Landweber, a computer scientist at the University of Wisconsin, collects data on international network connectivity. He maintains a list of the countries that are connected to the Internet, BITNET, FIDONET, or uucp. Obtain this list by anonymous ftp from ftp.cs.wisc.edu.
