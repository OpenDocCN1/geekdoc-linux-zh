```
AT&T System V:
$ mailx (RETURN)

BSD:
$ mail (RETURN)
```

The system will respond with a list of the messages. For example,

```
U  1  wards  Thu  Aug 12 15:27  554/26358  "Class Roster"
N  2  aadams  Fri  Aug 13  8:59  40/1527  "Lunch"
N  3  gwc  Fri  Aug 13  9:47  15/440  "Research Notes"
&
```

A *U* in the first column indicates an unread message left over from the last time you logged in; an *N* indicates a new message. The messages are numbered (from 1 to 3 in this case). The login name of the sender is shown, along with the date and time the message was received and the number of lines and characters the message contains (lines/characters). Finally, the subject of the message is given in quotes. The ampersand (&) on the last line is the *mail prompt*.

+   2  **Read your message(s).** Simply enter the message number after the mail prompt and press (RETURN):

```
&2 (RETURN)
```

This will cause the second message to appear:

```
Message 2:
From aaadams  Fri  Aug 13 8:59:01 1999
Date:  Fri  Aug 13  8:59:01
From:  aaadams  (Abigail Adams)
To:  (Your login name)
Subject:  Lunch

Let's get together for lunch at 12:45 today. Okay?
&
```

+   3  **Leave the mail utility.** Typing *x* (for "exit") at the mail prompt will take you out of the mail utility, leaving the message(s) in the mailbox:

```
&x (RETURN)
```
