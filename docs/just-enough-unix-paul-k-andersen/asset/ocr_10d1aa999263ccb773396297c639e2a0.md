# **7.6 Using Pathnames to Move and Rename Files**

In this section, you will move a file and rename it with one command, using a path- name to specify both the file’s new location and its new name.

+   *   **Enter the** `mv` **command, the file name, and the new pathname.** To move the file `august99` into `Months`, and rename it `aug99`, type

```
$\quad mv\ august99\ Ca1/Months/aug99\ (RETURN)$
```
