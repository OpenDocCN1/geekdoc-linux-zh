# ### 9.11 Killing a Background Process

Sometimes it is necessary to terminate a background process. This is done with the kill command. To see how this works, try the same background process you used in the previous section.

+   1 **Start the background process.** Be sure to note the PID:

```
$ (sleep 60; echo Stop this command) & Return
3310
$ 
```

+   2 **Kill the process.** Type kill, a space, and the PID number:

```
$ kill 3310 Return
```

Some systems will tell you when a background job has been killed:

```
Terminated (sleep 60; echo Stop this command)
$ 
```
