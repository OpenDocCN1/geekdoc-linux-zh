# # A APPENDIX:
TAMING YOUR TERMINAL

The *stty* ("set terminal") command allows you to set parameters that affect the operation of your terminal. In this appendix you will see how to use *stty* to perform the following tasks:

+   *   Set your terminal to handle lowercase input.
+   *   Define the erase key.
+   *   Ensure that the terminal echoes your input properly.

# ## A.1 Correcting Uppercase-Only Output

Sometimes the system may behave as if your terminal can handle only uppercase letters. (This can occur if you accidentally press the "Caps Lock" key before logging in.) The following command will correct the problem:

```
`$ STTY -LCASE <Return>`
```

# ## A.2 Defining the Erase Key

Most users expect the `Backspace` key to erase characters on the command line. (Others prefer to use `Delete` or `(Control)-(H)` for this.) The following command will make `Backspace` the character-erase key:

```
`$ stty erase <Backspace> <Return>`
```

The following command will set `Delete` as the character-erase key:

```
`$ stty erase <Delete> <Return>`
```
