Running a program from inside dbx doesn't seem too useful—after all, it is easier to run the program directly, without first calling up the debugger to do the job. What dbx allows you to do is step through the program, one line at a time, and examine the values of the variables and expressions as they change.

# ## F.3 Listing the Source Code

The list command will show you the source code. Try it:

(dbx) list 1, 15 Return

This tells dbx that you wish to see the source code from line 1 to line 15. dbx will display the file, numbering the lines as it does so. (The line numbers are not actually added to the source file.)

# ## F.4 Setting Breakpoints

A breakpoint is a place in the program where you want the execution to halt. Breakpoints may be set using the stop command. Let's set a breakpoint at line 8:

(dbx) stop at 8 Return

dbx will tell you that it has set the breakpoint:

stop at "recip.c":8

Now use the run command to begin execution:

(dbx) run Return

The program will run until it reaches line 8, where it will stop. dbx will then display line 8:
