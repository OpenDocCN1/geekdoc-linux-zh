# 24.6 Echo the Arguments Multiple Times: echo.by

The standard echo command echoes its arguments just once. The script presented here echoes its arguments as many times as the user chooses.

```
NAME
	echo.by-echo the arguments n times
SYNOPSIS
	echo.by n arguments(s)

DESCRIPTION
	Here is the outline for echo.by:

		Select sh
		Get $count from the command line ($1)
		Use shift to get rid of the first argument
		Get the message from the command line ($$)

		While $count is greater than 0
		do
			print the message
			subtract 1 from $count
		done
```
