+   •  **Content Area.** Whenever you receive a page from a Web site, the page is displayed in this part of the window.

+   •  **Message Status Field.** Whenever the browser sends or receives information over the Web, it prints an appropriate message in the Message Status Field to let you know what is happening.

+   •  **Mail Icon.** Pressing this icon will bring up an electronic-mail window.
