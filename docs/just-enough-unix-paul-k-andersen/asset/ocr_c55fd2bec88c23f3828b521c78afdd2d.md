# ### 19.4 Selecting Hypertext Links

Hypertext links appear on a Web page as underlined text, buttons, or icons (Figure 19-3). Clicking on one of these will lead you to another hypertext document.

# ### 19.5 Examining Cached Documents

When the Netscape client obtains a document from the Web, it places a copy of that document in a temporary storage area called *a cache*. You can return to documents in the cache by pressing the Forward and Back buttons in the Netscape toolbar:

These buttons move you through the pages you have recently visited.

![](bbox=[0.29, 0.74, 0.45, 0.81])
