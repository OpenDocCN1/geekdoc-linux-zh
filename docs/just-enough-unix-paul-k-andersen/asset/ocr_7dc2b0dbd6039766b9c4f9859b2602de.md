# 7.4 Creating Directories Using Pathnames

Your next task is to create a subdirectory inside Ca1 to hold monthly calendars. A good, descriptive name for this directory is Months. Since this is to go inside Ca1, the pathname of the new directory relative to your home directory will be Ca1/Months.

+   * Enter the **`mkdir` command, followed by the *pathname of the new directory*. Thus, to create a directory Months inside the directory Ca1, type
+   
+   $ mkdir Ca1/Months RETU RN
