+   1. Click on the Net Search button. The Net Search page will appear.
+   2. Choose a search engine. For example, click on Infoseek Guide and wait for the Infoseek window to appear. This window will display a dialog box.
+   3. Enter appropriate keyword(s) in the box. If you are interested in outdoor cameras, it would make sense to enter *outdoor cameras*. (The word *camera* by itself is probably too general.) Try it.
+   4. Click on the Search Now button. Alternatively, you can press `Return`. Either way, Infoseek Guide will show you a list of outdoor- and camera-related topics, as well as a list of links to specific Web sites. Note that Infoseek “scores” the Web sites by how well they fit the search keywords, and lists the sites accordingly.
+   5. Select a hyperlink link. Look down the list of links to find one that seems to offer what you are looking for.

# 19.9 Quitting Netscape

+   1. Pull down the File menu. This is located near the upper left corner of the Netscape window.
+   2. Select the Exit option.
