# Retrieving Items from a Database

The `get` function is the simplest way to get records from the database. It requires that you know the key for the data you want. The prototype is as follows:

```
int get(DB *db, DB_TXN, *txnid, DBT *key, DBT *data, u_int32_t flags);
```

The meaning and uses of `get`'s parameters are exactly the same as for the `put` call, except that `get` will fill in the structure referenced by `data`. If the specified key cannot be found, `get` returns `DB_NOTFOUND`. `flags` may be `0` or `DB_GET_BOTH`, in which case, `get` will retrieve the key/value pair only if both the key and value match the supplied values.

# Example

The next program retrieves a value from the database and displays it.

```
/*
* getdb.c -- Get a record from a Berkeley DB database
*/
#include <stdlib.h>
#include <stdio.h>
#include <errno.h>
#include <string.h>
#include "db.h"

int main(void)
{
DB *db;
int ret;
DBT key, value;

ret = db_open("test.db", DB_BTREE,
DB_CREATE, 0600, NULL, &db);
if(ret) {
perror("db_open");
exit(EXIT_FAILURE);
}

/* Initialize the key/value pair first*/
memset(&key, 0, sizeof(key));
```
