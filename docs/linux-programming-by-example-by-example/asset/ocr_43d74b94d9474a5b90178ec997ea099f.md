# ## 20—
## A Debugging Toolkit

As much as we all hate to admit it, software will have bugs. This chapter helps you debug your programs using `gdb`, the Gnu DeBugger, and some more specialized tools and techniques. You learn the following in this chapter:

+   * Using `gdb`
+   * Types of memory bugs
+   * Debugging with Electric Fence
+   * Using `m_pr` and `m_check`
