The flags are defined in `<linux/ext2_fs.h>`. `request` must be set to `EXT2_IOC_GETFLAGS` to retrieve the attributes for the file specified by the file descriptor `fd`, or set to `EXT2_IOC_SETFLAGS` to set those attributes. In either case, `arg` holds the flags being manipulated.

> **CAUTION**
> The material in this section is highly specific to Linux's primary filesystem, ext2, formally known as the Second Extended filesystem. Other versions of UNIX may have the functions and structures we will discuss, but they surely will not behave as described here. If you use these calls in a program you intend to be portable, you must surround them with `#ifdefs` in order for your code to compile and run properly on non-Linux systems.
