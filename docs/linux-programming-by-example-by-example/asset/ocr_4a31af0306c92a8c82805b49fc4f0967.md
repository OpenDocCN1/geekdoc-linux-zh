Data entry screen built with ncurses' form library.

ncurses initialization includes setting *cbreak* mode so that the kernel will allow most keystrokes to pass through to the application unprocessed. The next code block creates five fields, two labels, and two text entry fields, as well as a `NULL` field to terminate the field vector. The `fields` vector is the argument to `post_form`, which creates the form and displays it onscreen after a `refresh` call.

Before entering the *while* loop, in which all user input is processed, the `form_driver` sets overlay mode for input characters. Until the user presses F10, the application processes all input. Pressing the up arrow key or Page Up key (interpreted as `KEY_UP` or `KEY_PPAGE`) maps to a request to move to the previous field (`REQ_PREV_FIELD`). Likewise, down arrow and Page Down map to the `REQ_NEXT_FIELD` event request. The program also enables the backspace key by mapping it to `REQ_DEL_PREV`, which deletes the previous character. Upon pressing F10, the program cleans up after itself and terminates.
