CAUTION
After the write end of a pipe has been closed, reading from that pipe will return 0 to signal the end of file. However, if the read end has been closed, any attempt to write to the pipe will generate the SIGPIPE signal for the writer, and the write call itself will return -1 and set the global variable errno to EPIPE. If the writer does not catch or ignore SIGPIPE, the writing process will terminate.

• To review catching and ignoring signals, see "Catching Signals," page 102.
