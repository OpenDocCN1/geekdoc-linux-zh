sa_family describes the type of address stored, and sa_data contains the actual address data. sa_family is typically one of the values listed in Table 18.1.

# ## Socket Basics

The basic socket operations involve creating, opening, closing, reading, and writing them. Thanks to Linux's delightful habit of treating everything like a file, you can use the same I/O functions on sockets that you use on regular files.

> For a brief discussion of Linux's file abstraction, see "Characteristics and Concepts," page 132.

The I/O functions (read, write, and so on) have unique semantics when applied to sockets, which this chapter covers, but the interface is identical otherwise. All socket functions require the inclusion of <sys/socket.h> and the header file appropriate to each protocol.
