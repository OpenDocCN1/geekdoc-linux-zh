By default, debug tracing is disabled in ncurses programs. To enable debugging, link against ncurses’ debug library, `ncurses_g`,and either call `trace(N)` in your code or set the environment variable `$NCURSES_TRACE` to N, where N is a positive, non-zero integer. Doing so forces debugging output to a file named, appropriately, `trace`, in the current directory. The larger N’s value, the more detailed, and so more voluminous, the debugging output. Useful values for N are documented in `<ncurses.h>`. For example, the standard trace level, `TRACE_ORDINARY`, is 31.
