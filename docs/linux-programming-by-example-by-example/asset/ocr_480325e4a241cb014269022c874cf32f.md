+   - `-fprofile arcs`—Enables *egcs* to count the number of times a function is executed.

+   - `-ftest-coverage`—Creates data files for the *gcv* code coverage analysis tool.

+   - `-fbranch-probabilities`—Improves *egcs*’s prediction of code branches.

Finally, output from the `--help` options has been dramatically improved.
