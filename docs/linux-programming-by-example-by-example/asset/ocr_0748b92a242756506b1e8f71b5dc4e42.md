```
#include <string.h>
#include <stdio.h>
#include <stdlib.h>
#include "mcdutil.h"

#define BUFSZ 1024

int mcd_getstr(char buf[], int len)
{
   int c, i = 0;

   while((c = getchar()) != '\n' && i < len) {
      buf[i] = c;
      ++i;
   }
   buf[i] = '\0';
   return i;
}
```

Nothing extraordinary is here. I prefer to write my own functions to read characters from the keyboard because doing so gives me much more control over how to deal with the input. For example, custom input functions such as `mcd_getstr` are easily modified to reject invalid input or to transform valid input into a format that your application can handle.
