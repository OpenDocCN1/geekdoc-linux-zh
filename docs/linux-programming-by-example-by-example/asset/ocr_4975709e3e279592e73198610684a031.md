As you can see, gdb stopped on line 24 of the program. A quick print command confirms that it stopped at the requested value of i, 15. If the program is already running when you enter the run command, gdb will say that the program has already started and ask if you want to restart it from the beginning. Type yes and press Enter. The last two commands find out information about existing breakpoints and delete them by number.
