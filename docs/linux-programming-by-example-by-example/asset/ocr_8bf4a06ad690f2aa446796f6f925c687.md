# 2—
**Controlling the Build Process —GNU make**

make is a tool used to control the process of building and rebuilding software. make automates what software is built, how it gets built, and when it gets built, freeing you to concentrate on writing code. It also saves a lot of typing, since it contains logic that invokes the C compiler with appropriate options and arguments.

In this chapter, you learn the following:

+   - How to invoke make
+   - make’s command-line options and arguments
+   - Creating makefiles
+   - Writing make rules
+   - Using make variables
+   - Dealing with make errors
