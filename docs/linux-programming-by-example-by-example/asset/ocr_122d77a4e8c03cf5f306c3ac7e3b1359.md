```
getmaxyx(stdscr, ymax, xmax);
mwin(win, ymax - 16, xmax - 31);
werase(stdscr);
refresh();
wrefresh(win);
sleep(2);

delwin(win);
app_exit();
exit(EXIT_FAILURE);
}
```

The primary difference between this program and the previous one is that it creates new windows rather than derives child windows. As a result, the code must be careful to make sure that each window, stdscr and win, refreshes and that it refreshes in order. It is a bit more code intensive but also gives you a bit more flexibility because you can prepare a window and then pop it into place with a single wrefresh call.
