The getmaxyx call on line 16 retrieves the number of columns and lines for stdscr—this routine is usually implemented as a macro, so its calling syntax does not require that ymax and xmax be pointers. The call of mvaddnstr with a value of n=15 forces the string printed to be truncated before the letter "l" in "truncated." Next, the program creates the new window, tmpwin, with the same dimensions as the current screen. Then it scribbles a message into the new window, draws a border around it, and calls refresh to display it on the screen. Before exiting, calling delwin on the window frees its resources.
