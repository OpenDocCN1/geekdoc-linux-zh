# Output

```
$ make -Wmsg.c -Wshowit.c -n newhello-lib
cc -g -o msg.o msg.c
ar rcs libmsg.a libmsg.o
cc -g showit.c -o newhello-lib -I. -L. -lmsg
```

The `-f` option tells `make` to act as if `file` has changed, whereas `-n` displays the commands that would be executed without actually executing them. As you can see from the output, `make` would first build the library file, `libmsg.a`, then compile `showit.c` and link it with the library to create `newhello-lib`. This technique is an excellent way to test makefile rules.
