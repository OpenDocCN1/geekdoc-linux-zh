The next step is to compile the preprocessed file to object code, using `gcc`'s `-c` option. The correct syntax for this step is

```
$ gcc -x infile-type -c infile.cpp -o outfile.o
```

Linking the object file, finally, creates the binary image. The command for the link step should resemble the following:

```
$ gcc infile.o -o outfile
```
