# Output

```
$ ./mkq
created queue_id = 1280
opened queue_id = 1280
$ ipcs -q
------- Message Queues -------
key        msqid   owner perms   used-bytes messages
0x0000007b 1280    kwall 666     0          0

$ ./qctl 1280
queue 1280 removed
$ ipcs -q
------- Message Queues -------
key        msqid   owner perms   used-bytes messages

```

The program output shows that the specified queue was deleted. *mkq* creates the queue. The *ipcs* call confirms that the queue was created. Using the queue ID displayed by *mkq*, *qctl* calls *msgctl*, specifying the `IPC_RMID` flag to delete the queue. Running *ipcs* a second time again confirms that *qctl* removed the queue.

The *ipcs*(*l*) command, used in several of the sample programs, shows the number and status of all System V IPC structures that exist on your system when it executes. The *ipcrm*(*l*) command will delete the IPC structure whose type and ID is specified on the command line. See the manual pages for more information.
