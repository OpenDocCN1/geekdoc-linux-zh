Note that the spaces before and after the ellipsis are required. Case ranges are used in `switch` statements to specify values that fall between `LOWVAL` and `HIVAL`, as the following code snippet illustrates:

```
```c
switch(int_var) {
    case 0...2;
        /* your code here */
        break;
    case 3...5:
...
}
```
```

This fragment is equivalent to:

```
```c
switch(int_var) {
    case 1:
    case 2:
        /* your code here */
        break;
    case 3:
    case 4:
    case 5:
...
}
```
```

Obviously, the case range is just a shorthand notation for the traditional `switch` statement syntax, but it is a darn convenient one.
