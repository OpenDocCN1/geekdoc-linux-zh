# Sending Signals

Programmatically, there are two ways to send a signal to a running process: using the `kill` command (`kill(1)`) and using the `kill(2)` function. The `kill` command is actually a user interface to the `kill` function.

+   * For a detailed discussion of the `kill` function, see “Killing Processes,” page 86.

# *Using the `kill` Command*

To use the `kill` command in your programs, you must call one of `system`, `fork`, or `exec`. As you learned in the last chapter, the first two calls spawn a new process to execute `kill`, whereas `exec` replaces the calling process before running `kill`. The result, however, is the same, the target process is terminated.
