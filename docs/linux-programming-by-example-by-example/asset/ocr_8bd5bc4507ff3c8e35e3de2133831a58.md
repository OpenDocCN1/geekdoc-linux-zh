# Example

2. This example compares the make's normal output with the result obtained when you use the -s option to suppress make's output.

# Output

```
$ make all
cC -g hello.c -o hello
cC -g pedant.c -o pedant
cC -g showit.c msg.c -o newhello
cC -g -c msg.c -o libmsg.o
ar rcs libmsg.a libmsg.o
pedant.c: In function 'main':
pedant.c:8: warning: return type of 'main' is not 'int'
cC -g noret.c -o noret
cC -02 inline.c -o inline
cC -g packme.c -o packme
cC -g showit.c -o newhello-lib -I. -L. -lmsg
```

```
$ make -s all
pedant.c: In function 'main':
pedant.c:8: warning: return type of 'main' is not 'int'
```

As you can see, -s suppresses all of make's output. The warning about main's return value is diagnostic output from gcc, which make cannot, of course, suppress.

# Phony Targets

In addition to the normal file targets, make allows you to specify phony targets. Phony targets are so named because they do not correspond to actual files. Phony targets, like normal targets, have rules that list commands make should execute. The final target of the makefile in the last example, clean, was a phony target. However, because clean did not have any dependencies, its commands were not automatically executed.
