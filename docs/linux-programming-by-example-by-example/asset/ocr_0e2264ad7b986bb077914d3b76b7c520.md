# ## Navigating a Database

In the previous example, you saw how to find a particular record, given the key value. Often, however, you will not know the key for which you are looking or you will want to iterate through the database and visit each record in turn. Berkeley DB maintains a logical pointer, called a cursor, that you can move forward and backward through a database.

Before performing cursor operations, you must create a cursor associated with the database. The call to do so is cursor, which is prototyped as follows:
