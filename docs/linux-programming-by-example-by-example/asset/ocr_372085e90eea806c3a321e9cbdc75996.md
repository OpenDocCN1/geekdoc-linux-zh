GIDs. The effective user and group IDs are used primarily for security purposes but, under most circumstances, match the real user and group IDs. The difference between real and effective IDs matters primarily with programs that are setup or setgid, a topic discussed in the next section.

# Examples

+   1. Using the functions listed in Table 4.1, this program displays the process's real and effective UIDs and GIDs.

```
/
*
* ids.c - Print UIDs and GIDs
*/

#include <stdio.h>
#include <unistd.h>
#include <stdlib.h>

int main(void)
{
    printf("Real user ID: %d\n", getuid());
    printf("Effective user ID: %d\n", geteuid());
    printf("Real group ID: %d\n", getgid());
    printf("Effective group ID: %d\n", getegid());
    exit(EXIT_SUCCESS);
}
```

The output from running this program, on the author's system, is

# Output

```
$ ./ids
Real user ID: 500
Effective user ID: 500
Real group ID: 100
Effective group ID: 100
```
