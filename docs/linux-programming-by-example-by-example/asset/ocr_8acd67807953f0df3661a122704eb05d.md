# **Example**

This chapter uses the following program for many of its examples:

```
/**
* debugme.c Poorly written program to debug
*/

#include <stdio.h>
#include <stdlib.h>

#define BIGNUM 5000

void index_to_the_moon(int ary[]);

int main(void)
{
   int intary[10];

   index_to_the_moon(intary);

   exit(EXIT_SUCCESS);
}

void index_to_the_moon(int ary[])
{
   int i;
   for(i = 0; i < BIGNUM; ++i)
      ary[i] = i;
}
```

I compiled this program and then tried to run it, as illustrated here:

![](bbox=[0.04, 0.71, 0.15, 0.78])

# **Output**

```
$ gcc -g debugme.c -o debugme
$ ./debugme
```
