As you might expect, the `mvvline` call moves the cursor before drawing a vertical line. After all the gyrations to draw a simple border, the box routine is a breeze to use. The `wborder` function is more verbose than `box`, but it does allow finer control over the characters used to draw the border. The example illustrated the default character for each argument, but any character (and optional video attributes) will do, provided it is supported by the underlying emulator or video hardware.
