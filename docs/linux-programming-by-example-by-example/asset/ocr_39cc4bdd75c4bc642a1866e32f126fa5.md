address space at an address of its choosing. If shmadhr is not 0, it indicates the address at which the kernel should map the segment—obviously, doing this is a crap shoot, so always set shmadhr to 0. flags can be SHM_RDONLY, which means the segment will be attached as read-only. The default is that the segment is attached read-write. If the shmxt call succeeds, it returns the address of the attached segment. Otherwise, it returns -1 and sets errno.
shmxt disconnects the segment that is attached at shmadhr from the calling process's address space; the address must have been previously returned by a call to shmget.
