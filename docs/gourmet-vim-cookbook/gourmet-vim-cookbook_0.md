## 基础知识

### 这本书是关于什么的？

文本编辑是一门艺术。

在编程时，我们编写可复用的代码。为什么文本编辑又有什么不同呢？

《美味 Vim 食谱》探索了使用 Vim 进行高效文本编辑的艺术，包含了 200 多个实用示例。在学习新技能时，示例是不可或缺的，大量的示例能更有效地巩固这些概念。

书中充满了关于如何在 Vim 中执行常见（以及一些不常见）操作的技巧和窍门，你可以立即进行练习。它将帮助你像专业人士一样使用 Vim（即使你已经是专家，也总有新东西可以学习）。

当你读完这本书后，你的 Vim 水将比以往任何时候都更好。

### 一些命名规范

在这里我将以 `:` 开头的命令称为“命令行命令”（command-line commands）。其他文献可能将其称为“Ex 命令”。如果你怀疑它们是否有不同，其实它们是同一回事。

在这里我将从 Vim 内部访问的终端命令称为“外部命令”。你可能在互联网上听到它们被称为“过滤器命令”（filter command）或“感叹运算符”（bang operator）。同样，这些指的同一东西。

### Vimscript 在哪里？

书中的一些技巧使用了 Vimscript（Vim 的内置脚本语言）。然而，你会发现并没有专门的 Vimscript 章节。这是因为这本书的主要初衷是实用的 Vim 使用。

包含专门的 Vimscript 章节将指数级地扩大本书范围，因为现在处理的是一整门编程语言。但是，如果你想学习 Vimscript 基础，请查看我的其他作品 [Learn-Vim](https://github.com/iggredible/Learn-Vim)。

### 为什么你这样组织这本书？

起初，我计划写一本巨大的单体食谱（我确实这么做了）。但很难查找。所以我决定将它们分成不同的类别。

食谱被组织在不同的类别下，可能会存在重叠。

### 如何阅读这本书？

你可以按照任何顺序阅读食谱。它们是完全独立的。

这是一本实用的书。要精通 Vim，你需要肌肉记忆而不是头记忆。你不能只通过阅读食谱来学烹饪。你通过实际烹饪来学习。

你需要配合每个食谱中看到的每一个命令进行输入。重复几次。尝试不同的变化。阅读该命令的 `:help` 页面。理解大局。你的目标是能够自然且本能地执行该命令。

学习概念，而不是命令。

# 导航

## 基础导航

**问题：**

在 Vim 中移动的命令太多，难以记忆。

**解决方案：**

你不需要学习所有的 Vim 导航键。你只需要记住几个重要的键就可以舒适地移动。

如果你是初学者，我建议你背下这几个命令：

* `h/j/k/l` - 左 / 下 / 上 / 右。

* `w/e/b` - 前进到下一个单词的开头 / 前进到下一个单词的末尾 / 后退到上一个单词的开头。

* `{/}` - 上一个段 / 下一个段。

* `gg/G` - 文件开头 / 文件末尾。

就这些。不到十几个键。随着学习的进行，你可以学习更多的导航键。

## 在文件间切换

**问题：**

你需要快速返回到上一个文件。

**解决方案：**

使用 `Ctrl-^` 在当前文件和上一个编辑的文件之间切换。

当你向 `Ctlr-^` 传递一个数字时，Vim 将跳转到缓冲区列表（buffer list）中的对应缓冲区编号。如果你打开了 5 个缓冲区并运行：

* `5 Ctrl-^`，Vim 将跳转到缓冲区 5。

* `2 Ctrl-^`，Vim 将跳转到缓冲区 2。

你也可以使用 `Ctrl-I` 和 `Ctrl-O` 快速跳转到跳转列表（jump list）中的上一个和光标位置。

Vim 会记住你跳转到哪里并将其存储在跳转列表 (`:jumps`) 中。`Ctrl-I` 和 `Ctrl-O` 让你在该列表中移动。这对于追踪轨迹很有用。

跳转通常是指光标移动超过一行的动作（`ijkl` 不是跳转，但 `{}` 是）。

## 导航括号、中括号和大括号

**问题：**

你迷失在了括号的丛林中。

**解决方案：**

使用 `%` 跳转到匹配的括号/中括号/大括号 (`( ) [ ] { }`)。

如果你有像 `(lambda (y) ((lambda (x) (* x y)) 3))` 这样的表达式，你可以用 `%` 快速导航到括号的另一端。

## 跳转到不同行

**问题：**

你需要跳转到文件中不同的行号。

**解决方案：**

Vim 有不同的行操作符跳转到不同的行。

* 你可以使用 `:n` 或 `nG` 跳到第 n 行。如果你需要跳转到第 10 行，运行 `:10` 或 `10G`。

* 如果你向 `%` 传递计数，它现在是一个行操作符。`50%` 跳到文件中间。`67%` 跳到文件的 2/3 处。

## 同行内导航

**问题：**

你需要跳转到同一行的不同列。

**解决方案：**

* 使用 `f` 和 `t` 进行正向和反向行内搜索。要跳转到当前行的下一个“a”，运行 `fa`。要跳转到下一个“b”，运行 `tb`。要重复此搜索，使用 `;` 正向搜索，使用 `,` 反向搜索。

* 使用 `0` 和 `$` 跳到行首和行尾。你也可以通过 `g0` 和 `g$` 跳到换行行的开头和末尾。要启用换行，运行 `set wrap`。

* 使用 `^` 和 `g_` 跳到行的第一个和最后一个非空字符。

* 使用 `n|` 跳到当前行的第 n 列。`10|` 带你到第 10 列。

## 屏幕调整

**问题：**

你需要将光标居中到屏幕中心。

**解决方案：**

* 使用 `H M L` 将光标置于屏幕顶部、中部或下部。

* 使用 `zb`, `zz` 和 `zt` 将当前行移动到屏幕底部、中心或顶部。

## 滚动

**问题：**

你在 Vim 中无法使用鼠标，因此无法滚动。

**解决方案：**

Vim 允许你使用 `Ctrl-E / D / F` 和 `Ctrl-Y / U / B` 向上或向下滚动一行/半屏/全屏。

## 回上次……

**问题：**

你刚刚执行了一个操作，想回到执行该操作的地方。

**解决方案：**

Vim 会记住你执行的很多操作。你可以通过标记（marks）快速回到执行操作的地方。

Vim 标记可以记录位置。有两种不同的标记精确度：行标记（不精确）和位置标记（更精确）。

行标记使用单引号，如 `'m`（其中 m 是标记符号），位置标记使用单反引号，如 `` `m ``。行标记只会带你到正确的行。位置标记将带你到正确的行列。在以下示例中，我将只使用行标记，但记住每个行标记都有对应的位置标记。

使用 `'[` 或 `']` 跳转到最近更改或复制的文本的开头或结尾。

如果你最近对以下短语运行了 `yj`：

```
I am a phrase

I am another phrase
```

按下 `']` 会将光标置于第二行。

使用 `'<` 或 `'>` 跳转到最近一次视觉高亮文本的开头或结尾。

如果你最近运行了 `Vj` 来高亮当前行和下方的一行，针对以下短语：

```
I am a phrase
I am another phrase
```

按下 `'>` 会将光标置于第二行。

使用 `'.` 跳到最近修改过的一行。

如果你最近插入、修改或删除了文本，按下 `'.` 会将光标置于该行。

使用 `''` 快速跳转到上一次跳转之前的位置。使用双反引号 `` `` `` 这种位置标记的对应符号。

使用 `'0` 回到退出 Vim 之前的最后一个位置。

## 跳转到光标下的文件名

### 问题描述

你需要跳转到一个文件。

### 解决方案

当你的光标位于文件名上时，使用 `gf` 跳转到该文件。

如果你的光标在 `"./some_lib.py"` 上，按下 `gf` 将带你进入相对于当前目录的 `some_lib.py` 文件。如果该文件不存在，Vim 将抛出一个错误。

## 跳转到文本插入的位置并进入插入模式

### 问题描述

你最近写了一段文本，需要向该文本添加内容。

### 解决方案

使用 `gi`，你可以跳转到上一次插入文本的位置并自动进入插入模式。

这在你刚刚写了某些内容并需要继续添加时非常有用。它只在文件内有效（如果你最近在另一个文件中写了内容，按下 `gi` 不会带你回到另一个文件）。

# 搜索

## 基础搜索

### 问题描述

你需要在 Vim 中进行基础的关键词搜索。

### 解决方案

可以使用 `/keyword` 进行正向搜索，使用 `?keyword` 进行反向搜索。你可以搜索字面单词，也可以使用正则表达式。

使用 `n` 重复上一次正向搜索。使用 `N` 重复上一次反向搜索。

## 使用正则表达式

### 问题描述

你想在搜索中使用正则表达式，但不知道从何开始。

### 解决方案

仅需少量的正则表达式知识就能取得很大效果。这四点就足够入门了：

- `.` - 任意字符。

- `n+` - 一个或多个 n。

- `n*` - 零或多个 n。

- `n{2,5}` - 两个到五个 n。

你必须转义 `+` 和 `{ }` 符号，否则 Vim 会将它们视为字面字符。

- `/d.g` 匹配 “dog”、“dig”、“dug”。

- `/a\+` 匹配 “a”、“aa”、“aaaaaaaaaa”等。

- `/a*` 匹配 ""、“a”、“aaaaa”等。

- `/z\{2,5\}` 匹配 “zz”、“zzz”、“zzzz” 和 “zzzzz”

## 在最后一个匹配项后停止搜索

### 问题描述

你希望在到达最后一个匹配项时停止搜索，而不是循环回到文件顶部。

### 解决方案

这种循环搜索匹配项的默认功能是通过 `'wrapscan'` 选项开启的。要停止它，请使用 `'nowrapscan` 选项（`set nowrapscan`）。

假设当前文档中有 3 个匹配项。当你到达第三个匹配项时，Vim 会自动回到第一个匹配项。有时你希望搜索在最后一个匹配项后停止。

开启 `'nowrapscan` 后，Vim 现在会在第 3 个匹配项后停止搜索。

## 显示搜索计数

### 问题描述

你想知道文件中有多少个关键词匹配。

### 解决方案

要显示匹配数量，请在你的 vimrc 中添加以下内容：

```
set shortmess-=S
```

现在当你搜索（`/keyword`）时，Vim 将显示匹配数量，例如 `[3/5]`。

## 将光标移动到匹配项下方或上方

### 问题描述

你需要在搜索时将光标偏移几行。

### 解决方案

要偏移 n 行，请使用 `/pattern/n`。你的光标将落在在关键词匹配项下方第 n 行。如果你运行 `/donut/3`，光标将跳到 “donut”匹配项下方 3 行处。这与运行 `/donut/+3` 相同。

要跳转到匹配项上方第三行，运行 `/donut/-3`。

## 将光标移动到匹配项的末尾

### 问题描述

光标总是落在匹配项的第一个字符，你需要将其偏移到匹配项的右端。

### 解决方案

搜索时使用 `e` 偏移修饰符。如果你运行 `/donut/e`，光标将不再位于 “donut” 的 “d” 上，而是位于 “donut” 的 “t” 上。

要调整偏移量，可以在参数中添加数字：

- `/donut/e-2` 偏移到结束匹配项左侧 2 个字符（光标将落在 “donut” 的字母 “n” 上）。

- `/donut/e+3` 偏移到结束匹配项右侧 3 个字符（光标将在 “donut” 之后 3 个字符）。

## 搜索集合中的单个字符

### 问题描述

你想搜索 “A”、“B” 或 “C”。

### 解决方案

使用 Vim 集合（`[]`）来搜索任何在括号内的字符。运行 `/[ABC]` 来匹配 “A”、“B” 或 “C”。

你也可以对字符字符序列使用集合。

- `/[A-Z]` 搜索任何大写字母。

- `/[0-9]` 搜索任何数字。

- `/[A-Za-z]` 搜索任何大写或小写字母。

## 搜索位于行首或行尾的关键词

### 问题描述

你需要搜索位于行首或行尾的关键词。

### 解决方案

- 搜索行首的 “donut”，使用 `/^Donut`。

- 搜索行尾的 “donut”，使用 `/donut$`。

## 搜索包含开头、中间和结尾的行

### 问题描述

你需要搜索一个以 “strawberry”开头，中间包含 “banana”，并以 “chocolate”结尾的行。

### 解决方案

使用 `/^strawberry.*banana.*chocolate$`

- `^strawberry` 表示以 “strawberry” 开头。

- `.*banana.*` 表示 “banana” 前后的任意字符。

- `chocolate$` 表示行以 “chocolate” 结尾。

## 贪婪与非贪婪搜索

### 问题描述

有时你需要搜索最长模式，有时你需要搜索最短模式。

### 解决方案

搜索模式有两种：贪婪和非贪婪。

- 贪婪匹配最长模式。`.*` 是贪婪的示例。

- 非贪婪匹配最短模式。`\{-}` 是非贪婪的示例。

如果你有一个字符串 “chocolatedonut”，运行 `/ch.*donut` 会匹配整个字符串 “chocolatedonut”（最长匹配），而运行 `/ch\{-}donut` 会匹配 “chocolatonu”（最短匹配）。

## 搜索由行尾分隔的关键词

### 问题描述

你需要找到由行尾分隔的关键词。

### 解决方案

`\_.` 模式搜索带有行尾的后续模式。它最适合配合 `\{-}`（非贪婪）或 `*`（贪婪）修饰符使用。

给定文本：

```
strawberry
blueberry
chocolate
pancakes
and more
pancakes
```

- `/strawberry\_.\{-}pancakes` 匹配（非贪婪）strawberry 随后是任意字符（包括换行），然后是第四行的第一个 “pancakes”。

- `/strawberry\_.*pancakes` 匹配（贪婪）从 “strawberry”到第六行的最后一个 “pancakes”。

## 搜索或关系

### 问题描述

你需要匹配 “pancakes” 或 “waffles”。

### 解决方案

`/pancakes\|waffles` 搜索 “pancakes” 或 “waffles”。

## 避免输入斜杠

### 问题描述

当你搜索路径或 URL 时（例如 `/some/very/long/path`），必须转义斜杠非常麻烦。

### 解决方案

与其使用 `/` 搜索并转义模式中的每一个 `/`（如 `/\/some\/very\/long\/path`），不如使用 `?` 搜索运算符。`?/some/very/long/path`。

注意 `?` 会反向搜索，但你可以直接使用 `N` 正向搜索。这避免了输入转义字符。

## 标记匹配的开始和结束

### 问题描述

你想匹配较长模式的一部分。

### 解决方案

使用 `\zs`（开始）和 `\ze`（结束）来标记匹配的开始和结束。

给定以下文本：

```
sugardonut
chocodonut
chocolate
```

解释：

- 要匹配“chocodonut”中的“donut”，运行 `/choco\zsdonut`。

- 要匹配“chocodonut”中的“choco”，运行 `/choco\zedonut`。

- 要匹配“sugardonut”中的“do”，运行 `/sugar\zsdo\zenut`。

## 搜索行中的第 N 次出现

**问题：**

你需要搜索每行的第 2 次出现的内容。

**解决方案：**

运行 `/\(.\{-}\zsdonut\)\{2\}` 将匹配第二个“donut”出现（使用非常神奇的方法：`/\v(.{-}\zsdonut){2}`）。

```
Chocolate donut, blueberry donut, raspberry donut
```

## 搜索被特定模式包裹的文本

**问题：**

你需要搜索任何长度且被一对双引号包裹的文本。

**解决方案：**

要搜索被一对双引号包裹的任何文本，使用 `/"[^"]*"`。

此模式用于搜索被某个字符包裹的正文。

- 要搜索被一对单引号包裹的任何文本，使用 `/'[^']*'`。

- 要搜索被一对逗号包裹的任何文本，使用 `/,[^,]*'`。

集合语法 `[]` 在添加脱字符符号（`^`）时表示字符否定。`[^"]*` 表示零或多个任意非双引号字符。`[^']` 表示任意非单引号字符。

## 重复上一次搜索

**问题：**

你想重复上一次搜索。

**解决方案：**

要重复上一次搜索，使用 `//` 或 `??`。你也可以运行空搜索 `/<Enter>` 或 `?<Enter>` 来使用上一次搜索。

## 强制区分大小写搜索

**问题：**

你开启了 `ignorecase` 和 `smartcase` 选项，你需要专门搜索一个小写单词。

**解决方案：**

在关键字中添加 `\C` 可强制进行区分大小写的搜索。

如果你设置了 `ignorecase` 和 `smartcase`，这非常有用，因为如果你运行 `/donut`，Vim 会进行不区分大小写的搜索。然而，`/donut\C` 将显式匹配“donut”，而不是“Donut”或“DONUT”。

## 可选搜索

**问题：**

你需要在一个单词中搜索可选短语。

**解决方案：**

`\=` 修饰符使前面的字符变为可选。



如果你有字符串“hero”、“heroes”和“heros”，运行`/hero\(es\)\=`将匹配“hero”和“heroes”（后缀“es”是可选的）。而`/heros\=`将匹配“hero”和“heros”（后缀“s”是可选的）。

## 使用 Vimgrep 在多个文件中搜索短语

**问题：**

你需要在多个文件中搜索“food”。

**解决方案：**

Vim 内置了一个 grep 命令，用于在名为`:vim`的文件中进行搜索（你没读错，这个命令就叫`vim`，是`:vimgrep`的缩写）。

要递归地在所有 Javascript 文件中搜索“food”，运行`:vimgrep /food/ **/*.js`。要在当前目录下的所有 Javascript 文件中搜索“food”，运行`:vimgrep /food/ *.js`。

Vimgrep 使用快速修复列表（quickfix，参考`:h quickfix`）。使用`:copen`显示结果。

或者，你也可以使用终端的 grep 程序。Vim 有一个`:grep`命令，它使用分配给`'grepprg'`选项的命令（默认使用终端 grep）。要在当前目录搜索“donut”，运行`:grep "donut" . -R`。

## 向现有的快速修复列表添加匹配项

**问题：**

你使用 vimgrep 执行了搜索，需要向结果中添加更多项。

**解决方案：**

Vimgrep 有一个追加版本：`:vimgrepa`。

如果你运行`:vimgrep /breakfast/ **/*.js`然后运行`:vimgrep /lunch/ **/*.js`，第二次 vimgrep 搜索会覆盖第一次。这并不好。

要添加搜索结果，首先运行`:vimgrep /breakfast/**/*.js`，然后运行`:vimgrepa /lunch/ **/*.js`。现在你拥有包含“breakfast”和“lunch”搜索的列表。

## 数字和单词的别名

**问题：**

输入`[0-9]`太长了。有更短的别名吗？

**解决方案：**

Vim 有预定义的字符来帮助搜索。`\d`是数字`[0-9]`的别名。要搜索数字后跟“foo”，运行`/\dfoo`。这将匹配“1foo”、“2foo”。

同样，`\w`是“单词”字符`[0-9A-Za-z_]`的别名。要搜索数字 0 后跟任意两个单词字符（如“0ab”或“0a1”或“0_1”），运行`/0\w\w`。

## 更多预定义字符

**问题：**

你想知道是否有更多如`\d`和`\w`这样实用的别名。

**解决方案：**

我认为接下来的 5 个实用字符别名是：

```
\s    空白字符（空格和制表符）
\S    非空白字符（除空格和制表符以外）
\w    单词字符 [0-9A-Za-z_]
\l    小写字母 [a-z]
\u    大写字母 [A-Z]
```

如果你想查看完整列表，请查看`:h /character-classes`。

## 快速搜索光标下的单词

**问题：**

你想快速搜索光标所在的单词。

**解决方案：**

使用`*`和`#`分向前向后搜索光标下的单词。如果光标在单词“donut”上，如果你按下`*`，Vim 会执行`/\<donut\>`。`\<`和`\>`表示单词的开始和结束。它会匹配“chocolate donut”但不匹配“chocolatedonut”。

要匹配后者，使用`g*`和`g#`。这些命令与`*`和`#`类似，但 Vim 不再将光标下的单词视为一个整体，而是将其视为一个字符串模式。如果光标在单词“donut”上并按下`g*`，Vim 会执行`/donut`。它会匹配“glazed donut”、“donuts”、“donutman”等。

## 查找文件

**问题：**

你需要搜索并打开一个文件。

**解决方案：**

本质上，你可以通过`:e yourfile.txt`在 Vim 中打开文件。Vim 还有`:find`命令。当你使用`:e`或`:find`打开文件时，可以使用`<Tab>`自动补全目录或文件名。你自己试一下：进入一个包含多个文件的目录，输入`:e`然后按`<Tab>`。你会发现 Vim 会尝试补全名称。

你可能想知道`:edit`和`:find`有什么区别？区别在于`:find`在路径中查找文件，而 edit 不会。

要检查你的路径，运行：

```
:set path?
```

默认情况下，你的路径可能像这样：`path=.,/usr/include,,`。这里的核心是你可以编辑路径以便更快找到文件。

假设你的项目结构如下：

```
app/
  assets/
  controllers/
    application_controller.rb
    comments_controller.rb
    users_controller.rb
    ...
```

上述是 Rails 项目结构的示例。从根目录进入`users_controller.rb`，你需要经过多个目录并按下大量的 Tab。你必须执行类似`:find a<Tab>c<Tab>u<Tab>`才能到达`app/controllers/users_controller.rb`。

让我们通过将控制器路径添加到当前`'path'`中，为`controllers/`目录创建一个快捷。运行：

```
:set path+=app/controllers/
```

现在当你输入`:find u<Tab>`时，Vim 会在`app/controllers/`中搜索以`u`开头的文件。你为自动补全创建了一个路径快捷方式！你可以用经常访问的路径来更新路径。

# 文件

## 缓冲区、窗口、标签页

**问题：**

你听说 Vim 使用缓冲区（buffers）、窗口（windows）和标签页（tabs），但你不确定它们意味着什么。

**解决方案：**

缓冲区、窗口和标签页是 Vim 管理文件和布局的方法。许多文本编辑器只使用两种抽象：窗口和标签页。

那么什么是缓冲区呢？缓冲区是用于存储文本的内存空间。当你在 Vim 中打开一个文件时，Vim 会打开一个缓冲区来存储该文件数据。当你在 Vim 中打开 3 个文件时，你有 3 个打开的缓冲区。

顺便说一下，确保你在 Vimrc 中设置了`set hidden`。如果没有它，每当你切换缓冲区且当前缓冲区有未保存的更改时，Vim 会报错并提示你保存文件。这会降低你的速度。

窗口是缓冲区上的视口。从外部看，Vim 窗口看起来大多数大多数编辑器的窗口一样。你可以打开多个窗口并进行垂直和/水平排列。多个窗口可以指向同一个缓冲区。记住，每个缓冲区代表每个已打开的文件。你可以打开两个窗口，它们都指向同一个缓冲区`file1.txt`。你可以只打开一个窗口，但实际上你有 3 个打开的缓冲区：`file1.txt`、`file2.txt`和`file3.txt`。窗口是你用来查看缓冲区的工具。缓冲区才是实际的文件。

标签页是窗口的集合。把它想象成窗口的布局。在现代文本编辑器中，如果你关闭一个标签页，该标签页中的文件就会消失。同样，在网页浏览器中，如果你关闭网页标签页，该页面就消失。在 Vim 中，标签页并不代表打开的文件（记住，缓冲区代表实际的文件）。你可以关闭显示`file1.txt`的窗口标签页，但该文件仍在后台缓冲区中打开。

简而言之：

* 缓冲区是文件的内存空间。

* 窗口是缓冲区上的视口。

* 两个窗口可以指向同一个缓冲区，也可以两个窗口指向两个不同的缓冲区。

* 标签页是窗口的布局。

## 语法相似的两个不同写入命令

**问题：**

运行`:w !food`和`:w! food`得到了两个完全不同的结果。区别是什么？

**解决方案：**

`:w !food`和`:w! food`实际上是两个不同的命令（尽管它们的非常相似）。

* `:w !food`执行外部命令`food`（如果不存在则抛出错误），并将你的缓冲区内容作为标准输入（STDIN）。

* `:w! food`将当前缓冲区保存为`food`。

`%`在 Vim 中代表当前文件。

## 显示缓冲区列表

**问题：**

你需要查看哪些缓冲区是打开的。

**解决方案：**

Vim 有命令`:ls`、`:buffers`和`:files`显示缓冲区列表。

为什么要使用缓冲区？缓冲区是 Vim 快速跳转到不同文件的方法。大多数文本编辑器只有两种抽象：窗口和标签页。Vim 有三个：缓冲区、窗口和标签页。

Vim 将所有当前打开的文件保存在内存的缓冲区中。如果你打开了`file1.txt`、`file2.txt`和`file3.txt`，你有 3 个缓冲区。

跳转到特定缓冲区有不同的方法：

* 数字方法：跳转到缓冲区 #9，运行`:buf 9`。

* 文件名方法：跳转到`file2.txt`缓冲区，运行`:buf file2.txt`。

* `:bnext`和`:bprevious`跳到列表中的下一个和上一个缓冲区。

* `:brewind`跳到缓冲区列表中的第一个（`:blast`跳到最后一个——玩得开心吗？:D）。

最后，使用`:bd file1.txt`从缓冲区列表中移除`file1.txt`。

缓冲区是使用 Vim 编辑时一种智能的文件管理方法。它为你创建一个快捷文件列表。我强烈建议你在日常 Vim 编辑中多利用缓冲区！

## 跳转

**问题：**

你需要快速跳转到去过的地方。

**解决方案：**

在 Vim 中的操作会被视为跳转。Vim 会记住这些跳转并将它们存储在跳转列表中。

使用`:jumps`查看跳转列表。跳转列表显示了你最近跳转的地方。你可以使用`Ctrl-O`和`Ctrl-I`在跳转列表中移动。

Vim 将以下命令视为跳转命令：

```
'       跳转到标记行
`       跳转到标记位置
G       跳转到行尾
/       向后搜索
```

- `?`: 向后搜索
- `n`: 重复上一次搜索，方向相同
- `N`: 重复上一次搜索，方向相反
- `%`: 查找匹配项
- `(`: 跳转到上一个句子
- `)`: 跳转到下一个句子
- `{`: 跳转到上一个段落
- `}`: 跳转到下一个段落
- `L`: 跳转到显示窗口的最后一行
- `M`: 跳转到显示窗口的中间
- `H`: 跳转到显示窗口的第一行
- `[[`: 跳转到上一个章节
- `]]`: 跳转到下一个章节
- `:s`: 替换
- `:tag`: 跳转到标签定义

尝试一下：使用跳转移动，然后按几次`Ctrl-O`和`Ctrl-I`。`Ctrl-O`和`Ctrl-I`是我最喜欢的命令之一。

### 解决方案

输入`q/`或`q?`显示你执行过的所有`/`或`?`搜索。它会打开一个新的窗口，你可以在其中导航。如果你在其中一个关键词上按下`<Enter>`，Vim 将使用该单词进行搜索。

## 命令行历史

### 问题

你需要运行一个与之前执行过的命令类似的命令。

### 解决方案

`q:`显示命令行的历史。

如果你按下`q:`，Vim 将带你进入一个历史窗口，其中列出了你使用过的命令行列表。在这里可以使用常规 Vim 导航命令。如果你在某个命令上按下`<Enter>`，Vim 将执行该命令。

如果你过去运行过`:s/strawberryhoneypancakes/kale/g`，而现在想运行`:s/strawberryhoneywaffles/kale/g`，与其重新输入一遍命令，为什么不如从命令行历史中找到该命令，稍作修改然后执行它呢？

按下`q:`，在历史中找到该命令，然后进行编辑。完成后，运行它。

这些历史记录 (`q:`, `q/`, `q?`) 的强大之处在于你可以使用 Vim 导航，使得这种模式下的导航变得非常简单。

进入命令行历史的另一种方法是在处于命令行模式（`:`）时按下`Ctrl-F`。这对于`/`和`?`同样有效。在`/`或`?`搜索期间，输入`Ctrl-F`可打开搜索历史窗口。

## Vim 历史

### 问题

你想知道 Vim 还存储了哪些内容。

### 解决方案

Vim 存储了 5 种不同的历史

```
:his c or :       - 命令行历史 (q:)
:his s or / or ?  - 搜索历史 (q/ or q?)
:his e or =       - 表达式历史
:his i or @       - 输入历史
:his d or >       - 调试历史
```

# 插入模式

## 进入插入模式

### 问题

你需要进入插入模式。

### 解决方案

进入插入模式有许多方法。最常见的是：

```
i    在光标前插入文本
I    在行首第一个非空字符前插入文本
a    在光标后追加文本
A    在行尾追加文本
o    在光标下方下方另起一行并插入文本
O    在光标上方另起一行并插入文本
```

如果你是 Vim 新手，先不要试图记住所有它们。先从`i`开始。然后记住`a`和`o`。最后，你再记住它们的大写形式。

## 退出插入模式的不同方法

### 问题

你的键盘没有`<Esc>`键，并且你需要快速退出插入模式。

### 解决方案

通常情况下（字面意思），你可以通过`<Esc>`退出插入模式。然而，并非所有键盘都有`<Esc>`键（例如平板键盘）。除了`<Esc>`，你还可以使用`Ctrl-[`或`Ctrl-C`来退出。

或者，你也可以创建一个映射：

```
inoremap jk <Esc>
```

我发现`<Esc>`键太远了，所以我将`<Caps-lock>`键映射到`<Esc>`。如果你搜索一下 Bill Joy 的 ADM-3A 键盘（Vi 的创造），你会发现他的`<Esc>`键并不像现代键盘那样位于左上角，而是在`q`键左侧。这就是为什么我认为将`<Caps lock>`映射到`<Esc>`是合理的。

## 粘贴最近复制的文本

### 问题

你需要粘贴之前复制过的文本。

### 解决方案

如果你在插入模式下需要粘贴文本，可以先退出插入模式然后用`p`粘贴，但这涉及模式切换。在插入模式下粘贴文本更好的方法是使用`Ctrl-R 0`。在插入模式下执行`Ctrl-R`可以让你插入寄存器的内容。`0`是复制寄存器（yank register）。

也可以从任何其他寄存器插入。如果你需要粘贴某个寄存器的内容，运行`Ctrl-R a`。

## 执行快速计算

### 问题

你需要进行一个快速计算并插入结果。

### 解决方案

在插入模式下进行快速计算，可以使用`Ctrl-R`使用表达式`=`。

例如：`Ctrl-R =1+1<Enter>`。

## 自动补全

### 问题

你需要补全一个单词。

### 解决方案

插入模式内置了自动补全。

在插入模式下，使用`Ctrl-P`进行单词补全。通过在插入模式下按下`Ctrl-P`，Vim 会向后搜索以光标下文本开现有单词（按下`Ctrl-N`向前搜索）。

还有其他自动补全方法。常见的有：

*   `Ctrl-X Ctrl-L`行补全。
*   `Ctrl-X Ctrl-F`文件名补全。
*   `Ctrl-X Ctrl-K`字典补全。注意：此方法需要你先设置`'dictionary'`。假设`/usr/share/dict/words`中有一个字典（你的电脑某处会有字典路径），使用`set dictionary=/usr/share/dict/words`将该路径添加到字典中。

更多信息请查看`:h ins-completion`。

## 在插入模式下执行普通模式命令

### 问题

你需要在退出插入模式的情况下执行普通模式命令。

### 解决方案

你可以在插入模式下通过`Ctrl-O`执行普通模式命令。

例如：

*   `Ctrl-O zz`使屏幕居中。
*   `Ctrl-O /food`跳到下一个“food”。

## 大范围删除

### 问题

你需要删除文本块。

### 解决方案

*   按下`Ctrl-U`删除整行。
*   按下`Ctrl-W`删除光标前的单词。

此同时，普通模式下的`D`会删除到行尾，但插入模式下没有命令可以实现这一点，那么为什么不自己创建一个呢？

添加以下映射：

```
inoremap <C-d> <C-O>D
```

现在当你在插入模式下按下`Ctrl-D`时，Vim 会删除到行尾。

**问题：**

你需要从插入模式进行滚动。

**解决方案：**

按下`Ctrl-X Ctrl-E`和`Ctrl-X Ctrl-Y`来向下和向上滚动。

你需要输入诸如`Π`的特殊字符。

## 折叠行

**问题：**

你想折叠几行代码。

**解决方案：**

我不喜欢折叠衣服，但我喜欢折叠几行代码。

为什么要折叠东西呢？

当你阅读一个文件时，通常有很多无关的文本阻碍你理解该文件的整体功能。为了隐藏这些不必要的噪音，请使用 Vim 折叠。

Vim 支持 6 种不同的折叠方式：

1. 手动
2. 缩进
3. 表达式
4. 语法
5. 差异 (Diff)
6. 标记

手动折叠允许你手动折叠行（你不能折叠字符，只能折叠行）。运算符是`zf`，它的工作方式与任何操作一样：它接受一个移动指令。如果你有文本：

```
Line one

Line two
```

将光标放在“Line one”上，运行`zfj`折叠这两行。折叠后的行看起来像：

```
+-- 2 lines: Line one -----
```

使用`zo`打开折叠的文本。使用`zc`关闭折折叠。你也可以使用命令行`:fold`。我最喜欢的两种折叠方法是使用`zR`打开所有折叠和`zM`关闭所有折叠。当你想要进行快速、临时的折叠时，手动折叠非常有用。

要使用缩进折叠方法，将`'foldmethod'`选项更改为 indent：`set foldmethod=indent`。Vim 将根据`'shiftwidth'`选项折叠缩进行。

如果你有文本：

```
One

  Two

  Two again
```

后 2 行具有 2 个空格的缩进将被折叠。顺便说一下，这只有在`'shiftwidth'`值为 2 时才有效。在处理使用缩进结构的文本（如 Python 或 YAML 文件）时，缩进折叠非常有用。

表达式折叠允许你定义一个表达式来确定折叠。你首先需要通过`set foldmethod=expr`告诉 Vim 使用表达式折叠，然后 Vim 将使用`'foldexpr'`选项中定义的任何表达式。

例如，如果你想折叠所有以“p”开头的项：

```
donut
pancake
pop-tarts
protein bar
salmon
scrambled eggs
```

运行`:set foldexpr=getline(v:lnum)[0]==\\"p\\"`。我在这里不会深入探讨 Vimscript，但只有当当前行的第一个字符以“p”开头时，`'foldexpr'`表达式才会返回真。

语法折叠可以根据语法选项折叠行。要使用它，先通过`:set foldmethod=syntax`设置折叠方法。再次，我在这里不会介绍 Vim 中语法定义是如何工作的，但通常情况下如果你使用 [vim-polyglot](https://github.com/sheerun/vim-polyglot) 等语法插件，语法折叠应该可以直接工作。Vim 使用语法定义来确定折叠内容。

差异折叠在你执行`vimdiff`时会立即生效。如果你运行`vimdiff file1.txt file2.txt`，Vim 会自动将 foldmethod 设置为 diff 并折叠所有相同的行。

标记折叠用于折叠由模式标记的行。你可以通过`:set foldmethod=marker`设置。默认情况下，Vim 使用`{{{`, `}}}`模式作为折叠标识符。Vim 会折叠标识符之间的任何行。

如果你有：

```
Hello
{{{
world
vim
}}}
```

当 Vim 看到`{{{`和`}}}`时，这些行将被折叠。你可以通过更新`'foldmarker'`选项的值来更改指示符。要将其更改为`<<<`和`>>>`，运行`:set foldmarker=<<<,>>>`。

# 宏与寄存器

## 宏基础

**问题：**

你需要将一组命令录制到寄存器中。

**解决方案：**

你可以在 a-z 寄存器中记录一系列操作并在以后重放它们。这个过程被称为宏。要要录制宏，按下`q`，然后是寄存器字符（例如：`qq`在寄存器 q 中录制宏）。要停止录制，再次按下`q`。

例如：

```
qagUUjq
```

* 使用`qa`在寄存器 a 中录制宏。
* 使用`gUU`将当前行转换为大写。
* 使用`j`向移动一行。

要重放录制在寄存器 a 中的宏，请运行`@a`。要播放上次执行的宏，运行`@@`。

## 寄存器基础

**问题：**

你听说 Vim 可以在不同的寄存器中保存文本。

**解决方案：**

Vim 寄存器的工作原理类似于计算机的剪贴板。Vim 自带 10 个寄存器，我在这里不会详细介绍它们。它们是：

* 无名寄存器 (`""`)。
* 数字寄存器（`"0-9"`）。
* 小删除寄存器(`"-"`)。
* 命名寄存器`"a-z"`)。
* 只读寄存器(`":"`、`"."`和`%`)。
* 备用文件寄存器`"#"`)。
* 表达式寄存器（`=`）。
* 选择寄存器（`"*"`和`"+"`）。
* 黑洞寄存器`"_"`)。
* 上一次搜索模式寄存器（`/"`）。

它们可以与其他操作组合使用。运行`"`后紧跟寄存器符号，然后是操作符。寄存器通常与复制（`y`）操作和删除（`d`）操作配合使用，也可以与其他操作符使用。你也可以直接输入寄存器的内容：`:put a`会输出寄存器 a 中的内容。在插入模式下，你可以按`Ctrl-R a`获取寄存器 a 的内容。

如果你需要将当前单词复制到寄存器 a，请运行`"ayiw`。要粘贴该内容，请运行`"ap`。

寄存器和宏之间密切相关。如果你仔细想，宏实际上是可执行的寄存器。当你在寄存器 a 中录制宏（`qagUUjq`）时，你实际上是在记录一条指令（如果你不相信，在运行`qagUUjq`后，运行`"ap`，你应该能看到打印出来的操作按键序列）。

## 深入了解 Vim 寄存器

**问题：**

你看到 Vim 有 10 个寄存器。你如何使用它们呢？

**解决方案：**

如上所述，Vim 有 10 个不同的寄存器。有些由 Vim 自动填充，而有些必须显式输入。



无名寄存器存储你最后复制、修改或删除的文本。无名寄存器类似于计算机的标准复制/粘贴操作。要从无名寄存器中获取文本，执行`""p`。粘贴命令`p`和`P`会自动从无名寄存器中粘贴内容。

数字寄存器有两种类型：`0`寄存器和`1-9`寄存器。

`0`寄存器留用于复制寄存器（也称为 yank 寄存器）。如果你复制了一行，例如`yy`，它将存储在寄存器`0`中。使用`"0p`粘贴它。

`1-9`寄存器留用于删除或修改。如果你删除一行（`dd`），被删除的文本将按时间顺序存储在从`1`到`9`的数字寄存器中。如果你执行了`3`次`dd`，最近的删除将存储在寄存器`1`中，第二次最近的删除存储在`2`中，第三次最近的存储在`3`中。要粘贴这些内容，请使用`"1p`、`"2p`、`"3p`等。

小删除寄存器存储少于一行的删除或修改。如果你删除一个单词（如`diw`），你可以通过`"-p`访问（寄存器`1-9`只存储长度至少一行的删除或修改）。

命名寄存器可能是最常用的寄存器之一。它使用字符`a-z`来存储复制、修改或删除的文本。要将单词删除到寄存器`a`，运行`"adiw`。要粘贴它，运行`"ap`。要将行的剩余部分复制到寄存器`b`，运行`"by$`。要粘贴它，运行`"bp`。

只读寄存器由 Vim 自动处理。`.`存储上一次插入的文本，`:`存储上一次执行的命令行，`%`存储当前文件名。

备用文件寄存器存储备用文件的名称（你刚刚编辑的另一个文件）。

表达式寄存器允许你评估 Vimscript 表达式。要计算表达式`1 + 1`的结果，运行`=1+1<Enter>`，然后按`p`。

选择寄存器`*`和`+`用于将 Vim 连接到计算机剪贴板。默认情况下，如果你复制了某些内容（例如从网站复制的文本），无法立即将其粘贴到 Vim，反之亦然（如果你在 Vim 中复制了内容，无法在 Vim 外粘贴）。要将系统剪贴板中的文本粘贴到 Vim，运行`"+p`或`"*p`。`*`和`+`寄存器的区别是历史性的。如果 Vim 有`+xterm_clipboard`且你的机器使用 X11 的主选择，Vim 使用`*`寄存器。如果你的机器使用 X11 的剪贴板选择，Vim 使用`+`。坦率地说，不用担心。大多数时候，它们是可以通的。

然而，我发现`"*p`粘贴和`"*yy`复制很麻烦。在 vimrc 中添加此内容：

```
set clipboard=unnamed
```

这会将无名寄存器（`p`）连接到剪贴板系统。现在你可以使用`p`自然地复制和粘贴。

黑洞寄存器（black hole register）允许你删除、复制和修改文本，无需将其存储到寄存器中。如果你使用`"_dd`删除一行，Vim 不会将其保存到编号寄存器中。

上一次搜索模式寄存器`/`和`?`存储了最后的搜索词。

## 清空寄存器

**问题：**

你需要清空一个寄存器。

**解决方案：**

要快速清空寄存器`a`，运行`qaq`。该命令记录了一个空宏，从而有效地清空该寄存器。

## 从任意寄存器输出内容

**问题：**

你需要直接输出某个寄存器的内容。

**解决方案：**

`:put`命令可以输出任何寄存器的内容。

*   `:put a`打印寄存器`a`。

*   `:pu _`从黑洞寄存器打印（在这种情况下，它会输出一个空行）。

## 编辑现有宏

**问题：**

你需要编辑一个现有的宏。

**解决方案：**

要编辑寄存器`a`中的现有宏：

*   运行`:put a`输出宏的步骤。

*   对其进行编辑或添加步骤。

*   运行`"ay$`将其复制回寄存器`a`。

现在你可以使用`@a`执行更新后的宏。

例如，如果你在寄存器`a`中有一个宏，用于将当前行转为大写然后移动到下一行（`qagUUjq`），如果你想在该宏中添加一个移动到下一个单词的动作（`w`），可以这样操作：

1.  运行`:put a`粘贴指令字符串“gUUj”。

2.  在指令字符串中添加所需的动作“w”，使其变为：“gUUjw”。

3.  从该行开头开始运行`"AY$`将其复制回寄存器`a`。

4.  现在运行`@a`就会将当前行转为大写，向下移动一行，并移动到下一个单词。

另一种方法是在命令行模式下进行编辑。

*   输入`:let @a =`（先不要按`<Enter>`！）

*   按下`Ctrl-R a`。Vim 将输出寄存器`a`的内容。

*   现在你可以对其进行编辑。

## 使用黑洞寄存器防止寄存器污染

**问题：**

某些命令（如`:d`）会将受影响的文本保存到寄存器，但你不希望将这些文本存入寄存器。

**解决方案：**

使用黑洞寄存器`_`进行更改而不存储到任何寄存器中。

当你在多行上运行常用命令且该命令的副作用会保存到寄存器时，这种方法特别有用。

与其运行`:g/donut/d`来删除所有包含“donut”的行并污染编号寄存器，不如运行`:g/donut/d _`，它可以删除所有包含“donut”的行而不污染编号寄存器。

## 查看所有寄存器的内容

**问题：**

你想查看当前所有的寄存器。

**解决方案：**

要查看所有寄存器的文本，运行`:registers`。你也可以通过传递寄存器名称作为参数来检查特定的寄存器。运行`:register a`查看寄存器`a`的内容。

## 程序化执行宏

**问题：**

你需要同时在多行上执行一个宏。

**解决方案：**

你可以使用`:normal`命令程序化地运行宏。

要在第`5-10`行执行宏`a`，运行`:5,10 normal @a`。

你还可以将其与其他命令结合，例如全局命令。要在包含“const”的行上执行宏`a`，运行`:g/const/normal @a`。

如果你需要在包含“const”单词的多个文件的对应行上执行宏，可以运行`:argdo g/const/normal @a`。

## 快速追加到现有宏

**问题：**

你想在现有宏的末尾添加几条指令。

**解决方案：**

使用该寄存器的大写字母来追加到现有宏。

如果你有如下宏，用于将当前行转为大写然后向下移动一行：

```
qagUUjq
```

稍你想在`j`之后添加`dd`。无需从头开始录制宏，只需运行`qAddq`。`qA`将动作`dd`添加到寄存器`a`中的现有宏中。换句话说，Vim 会自动在`gUUj`操作之上添加`dd`操作。

## 从编号寄存器快速粘贴

**问题：**

你需要顺序从编号寄存器（`"1P`、`"2P`、`"3P`）粘贴。

**解决方案：**

当从编号寄存器（`"1P`）粘贴并接着点命令`.`时，Vim 会自动增加编号。

尝试一下：使用`"1P`从编号寄存器`1`粘贴，然后运行`.`（这执行`"2P`），再次运行`.`（这执行`"3P`）。

## 宏工厂

**问题：**

你想复制并组合宏。

**解决方案：**

记住宏寄存器本质上是变量，你可以在其中存储要执行的指令字符串或要输出的文本。由于宏只是文本，你可以对它们进行字符串操作。

要组合宏`b`和`c`并保存到寄存器`a`，运行`:let @a = @b . @c`（在 Vimscript 表达式中`.`是字符串拼接；不要与点命令混淆）。事实上，如果你想给宏添加额外的操作（如`dd`），可以通过`:let @a = @b . @c . 'dd'`来实现。

## 递归宏

**问题：**

你需要运行一个递归宏。

**解决方案：**

如果你有文本：

```
a. chocolate donut
b. mochi donut
c. powdered sugar donut
d. plain donut
```

如果你想使用递归宏切换第一个单词的大小，运行：

```
qaqqa0W~j@aq
```

步骤拆解：

*   `qaq`记录一个空宏。在递归宏中，从空寄存器开始是关重要的。当你递归调用该宏时，它将运行该寄存器中的任何内容。

*   `qa`记录到寄存器`a`。

*   `0W~j`跳到当前行的第一个字符，然后到下一个单词，切换光标下字符的大小，最后向下移动一行。

*   `@a`执行宏`a`（这是递归部分——你仍在录制宏`a`，同时在此执行宏`a`）。

*   `q`停止录制。

# 多文件操作

## 在多个文件中执行命令的不同方法

**问题：**

你需要在多个文件中执行 Vim 命令。

**解决方案：**

Vim 有`8`种方法可以在多个文件中执行命令。

```
:argdo    参数列表文件
:bufdo    缓冲区 (buffers)
:windo    当前标签页中的窗口
:tabdo    标签页 (tabs)
:cdo      快速修复列表 (quickfix list)中的项
:cfdo     快速修复列表中的每个文件
:ldo      位置列表 (location list)中的项
:lfdo     位置列表中的每个文件
```

这些命令要求你在运行命令之前，先在各自的类别中创建一个列表（参数列表、缓冲区列表、窗口列表、标签列表、快速修复列表和位置列表）。

*   要创建参数列表，请运行`:args file1.txt file2.txt file3.txt`
*   要创建缓冲区列表，只需打开更多文件（例如`:e file1.txt`）
*   要创建窗口列表，创建更多分割窗口（例如`:vsplit file1.txt`）
*   要创建标签列表，创建更多标签（例如`:tabnew tab1`）
*   要创建快速修复列表，使用使用快速修复的命令（例如`:vimgrep /searchkeyword/ *.txt`）
*   要创建位置列表，使用使用位置列表的命令（例如`:lvimgrep /searchkeyword/ *.txt`）

在本节中，我将使用`:argdo`，但对所有列表的操作流程都是相同的。

## 在多个文件中进行替换

**问题：**
你需要对多个文件进行替换。

**解决方案：**
要在多个文件中进行替换并保存，请运行`:argdo %s/donut/pancake/g | update`。

`update`命令用于保存每个文件。

## 在多个文件中执行宏

**问题：**
你需要在多个文件中运行宏。

**解决方案：**
要在多个文件中执行宏，你可以使用`:normal`命令。要执行寄存器`a`中的宏，请运行`:argdo normal @a | update`。

## 限制操作的文件范围

**问题：**
你只需要对前`5`个文件运行命令。

**解决方案：**
在运行`-do`命令时，你可以使用范围来限制想要操作的文件数量。

仅对参数列表中的前`5`项进行替换：`:1,5argdo s/pancake/waffle/g | update`。

## 创建参数列表

**问题：**
你需要快速创建一个参数列表。

**解决方案：**
运行`:argdo`命令需要参数列表。

*   要获取当前目录下所有的 markdown 文件，请运行`:args *.md`。
*   要递归获取当前目录下所有的 markdown 文件，请运行`:args **/*.md`。

一旦获取了所有文件，你可以通过`:args`查看它们。

## 向参数列表添加内容

**问题：**
你已经创建了一个参数列表，需要添加更多项。

**解决方案：**
使用`:arga`向参数列表添加内容。

假设你通过运行`:args a*.md`创建了所有以“a”开头的 markdown 文件参数列表，之后你又想添加所有以“b”开头的 markdown 文件列表。如果你运行`:args b*.md`，它将替换第一个 markdown 列表。要实现这一点，请运行`:arga b*.md`。现在你拥有了包含以“a”和“b”开头的 markdown 文件列表。

如果你不带任何参数调用`:arga`，Vim 将将当前缓冲区添加到参数列表中。

# 数字

## 快速递增或减少行内数字

**问题：**
你需要快速增加或减少当前行中的一个数字。

**解决方案：**
Vim 拥有`Ctrl-A`和`Ctrl-X`操作，可以增加或减少当前行中（距离光标）最近的数字。

如果你有以下文本：

```
dozens of donut: 2

calories per donut: 200
```

*   如果光标在第一行并按下`Ctrl-A`，光标会自动移动到“2”并将其增加为“3”。
*   如果光标在第二行并按下`Ctrl-X`，光标会自动移动到“200”并将其减少为“199”。

## 递增大于 1 的数字

**问题：**
递增/减少操作符（`Ctrl-A`和`Ctrl-X`）每次只加或减`1`。

**解决方案：**
你可以在递增/减少操作符之前传递一个计数值。

如果你在“I ate 2 donuts”这一行的开头运行`10 Ctrl-A`，它将将其增加为“I ate 12 donuts”。这太棒了！

同样，如果你在同一行上运行`5 Ctrl-X`，它将将其减少为“I ate 7 donuts”。

## 顺序递增多个数字

**问题：**
你需要按顺序递增多行中的数字。

**解决方案：**
如果你使用可视模式高亮多行并运行`Ctrl-A`，Vim 将在所有行中递增为相同的数字。

然而，如果你在可视模式下运行`g Ctrl-A`或`g Ctrl-X`，它将按顺序递增每行的数字。

如果你有以下文本：

```
breakfast0

breakfast0

breakfast0
```

如果你可视化高亮所有`3`行然后按下`g Ctrl-A`，Vim 将递增每一行：

```
breakfast1

breakfast2

breakfast3
```

## 替换并递增数字

**问题：**
你需要使用替换命令来递增数字。

**解决方案：**
你可以通过结合全局（global）使用替换命令来实现。

假设你有以下内容：

```
## I'm a header

## I'm another header

## I'm yet another header
```

并且你想将`##`替换为递增的数字，例如：

```
1.)  I'm a header

2.)  I'm another header

3.)  I'm yet another header
```

运行：

```
let i = 1 | g/^##/s//\=i . '.)'/g | let i += 1
```

*   `let i = 1`将变量`i`设置为`1`。
*   `g/^##/`运行匹配`^##`模式（以“##”开头的行）的全局命令。
*   `s//`使用替换命令。如果你留搜索模式，Vim 将使用与全局命令相同的搜索模式（即`^##`）。
*   `\=i . '.)'/g`使用表达式`\=i . '.)'`作为替换模式（变量`i`拼接字符串“.)”）。`g`是全局标志。
*   `let i += 1`在每次迭代中将变量`i`增加`1`。

## 在任何地方快速生成递增数字

**问题：**
你需要在随地生成一个带有递增数字的列表。

**解决方案：**
如果你需要快速创建列表，可以动态生成递增数字前缀。以下是使用可视模式和数字递增操作符实现此操作的方法。

假设你有这个列表：

```
first item

second item

third item
```

1.  将光标置于第一行的第一个字符，即“first”中的“f”上。
2.  激活块可视模式（`Ctrl-V`）。
3.  向下移动两行。
4.  按下`I`激活光标前的插入模式并输入“0\.”。按下`<Esc>`。

你应该得到：

```
0\. first item

0\. second item

0\. third item
```

5.  按下`gv`快速高亮之前选择的可视模式。Vim 将自动高亮所有“0”文本。
6.  按下`g Ctrl-A`按顺序递增数字，完成定！

```
1\. first item

2\. second item

3\. third item
```

# 重复

## 重复上一次命令行命令

**问题：**
你需要重复上一次的命令行命令。

**解决方案：**
使用`@:`重复上一次命令行命令。

如果你刚刚运行了`:s/donut/pancake`，可以使用`@:`重复执行它。

## 重复上一次修改

**问题：**
你需要重复上一次所做的修改。

**解决方案：**
你可以使用`.`（点命令）来重复上一次修改。

如果你输入了“I love breakfast”，可以通过按下点命令（`.`）再次插入该文本。

## 重复上一次替换

**问题：**
你需要重复上一次替换。

**解决方案：**
使用`:&`或`&`重复上一次替换。如果你执行了`:s/donut/waffle/g`，然后运行`&`，Vim 将在当前行执行`:s/donut/waffle`。不过，Vim 不记得`g`标志。

要重复上一次替换并记住标志，可以使用`:&&`。如果你执行了`:s/donut/waffle/g`并运行`:&&`，Vim 将在当前行执行`:s/donut/waffle/g`。

要在所有具有相同标志的行上重复上一次替换，请使用`g&`。

如果你执行`:s/donut/pancake/g`然后运行`g&,`，Vim 会运行`:%s/donut/pancake/g`。从技术上讲，Vim 的是`:%s//~/&`，它包含：

* `%`s 对所有行进行替换
* `//` 重复上一个模式
* `~` 重复替换字符串
* `&` 使用最后一个标志

## 重复上一次执行的宏

**问题：**
你需要重复上一次执行的宏

**解决方案：**
你可以使用`@@`重复上一次执行的宏。

如果你刚刚通过`@a`执行了宏 a，运行`@@`将再次执行该宏。

## 重复上一次外部命令

**问题：**
你需要重复上一次的外部命令。

**解决方案：**
你可以使用`:!!`重复上一次的外部命令执行 (`:!{cmd}`)。

如果你刚刚运行了`:!ls -l`，运行`:!!`将重新运行`:!ls -l`。

# 排序

## 对行排序

**问题：**
你需要对多行按字母顺序排序。

**解决方案：**
Vim 有`:sort`命令可以对多行进行排序。你可以执行以下操作：

* 排序整个文件，运行`:sort`。
* 对第 5-10 行进行排序，运行`:5,10 sort`。

该命令还接受标志以不同的方式排序行。

如果你有重复行：

```
pancake

donut

waffle

donut
```

运行`:sort u`对它们进行排序并删除重复项。

Vim 的`:sort`无法正确排序数字。如果你有：

```
2 donuts

1 donut

11 donut

10 donuts
```

运行`:sort`将得到：

```
1 donut

10 donuts

11 donut

2 donuts
```

要修复此，运行`:sort n`。

使用`:sort /pattern/`根据模式进行排序。

```
pancake, donut, waffle

sushi, pasta, taco

apple, banana, carrot

water, apple juice, milk
```

* 如果你想根据第二个项目（“donut”对比“pasta”, “banana”, “apple juice”）进行排序，可以使用`:sort /,/`。Vim 将使用匹配项后的字符进行排序。
* 如果你想根据第三个项目（“waffle”对比“taco”对比“carrot”对比“milk”）进行排序，可以使用`:sort /,.\+,/`。

## 外部排序

**问题：**
你需要使用不同的排序程序。

**解决方案：**
记住你可以使用外部命令作为过滤器。你的终端可能带有`sort`命令。要使用终端`sort`命令进行排序，运行`:%!sort`。

注意：在使用外部命令过滤 Vim 中的文本时，请传递范围。

* 排序整个文件，运行`:%!sort`。
* 对第 5-10 行进行唯一排序，运行`:5,10!sort -u`。

## 逆序排序

**问题：**
你需要进行逆序排序。

**解决方案：**
你可以通过`:sort!`进行逆序排序。

你也可以使用终端`sort`命令，`:%!sort -r`。

# 替换

## 基本替换

**问题：**
你需要替换一个模式。

**解决方案：**
替换命令是一个多功能 Vim 命令，可能是你经常使用的命令。它的基本语法为：

```
:s/pattern1/pattern2
```

在当前行将“donut”替换为“pancake”，运行`:s/donut/pancake`。注意，如果同一行有多个“donut”，Vim 只替换第一个。要替换多个实例，请传递全局 (`g`) 标志：`:s/donut/pancake/g`。

你可以在范围内执行替换。

* 在第 2 到 5 行之间将“donut”替换为“pancake”：`:2,5s/donut/pancake/g`。
* 在整个缓冲区将“donut”替换为“pancake”，运行`:%s/donut/pancake/g`。

## 不区分大小写匹配

**问题：**
你需要进行不区分大小写的替换匹配。

**解决方案：**
使用`i`标志进行不区分大小写的匹配。

如果你运行`:%s/dOnuT/salad/gi`，它会将“donut”、“dOnuT”和“DONUT”替换为“salad”。当你匹配一个大小写变化的短语时，这非常有用。

## 替换前确认

**问题：**
你希望 Vim 在替换前询问确认。

**解决方案：**
使用`c`标志在替换前进行确认。

如果你在一个大型缓冲区中工作，并且只需要替换*部分*而不是所有匹配项，这是一个完美的解决方案。

假设你需要将“donuts”替换为“waffle”，你可以运行`:%s/donut/waffle/gc`。

```
Chocolate donut

Strawberry donut

Vanilla donut
```

如果你只需要替换第一个和第三个匹配项，在运行替换命令后，Vim 会对每个匹配项询问你确认。在第一个上输入 yes，在第二个输入 no，在第三个输入 yes 即可。

## 替换中的分组匹配

**问题：**
你需要反转一个模式的顺序。

**解决方案：**
你可以对匹配模式进行分组并使用`\n`引用它们（其中`n`是整数）。

如果你想将“chocolate donut”替换为“donut chocolate”，只需执行`:s/chocolate donut/donut chocolate`。

但如果你需要让第二个单词变成第一个，第一个单词变成第二个呢？你需要使用分组匹配。

要将“chocolate donut”转换为“donut chocolate”，运行`:s/\(.\+\) \(.\+\)/\2 \1/g`。

* 第一个组`\(.\+\)`匹配“chocolate”，并由`\1`表示。
* 第二个组`\(.\+\)`匹配“donut”，并由`\2`表示。

另一个例子：如果你需要将第 1 个字母移动到第 2 个，第 2 个移动到第 3 个，第 3 个移动到第 1 个，可以运行`:s/^\(\w\)\(\w\)\(\w)/\2\3\1/g`。这会将“123”交换为“231”，“abc”交换为“bca”。

## 使用 Very Magic 避免转义特殊字符

**问题：**
你厌倦了转义特殊字符。

**解决方案：**
在进行搜索/替换时，某些字符具有特殊含义（如`.`、`(` )`或`+`）。有时你必须转义大量的字符。使用 very magic 标记`\v`来避免转义特殊字符。

* 使用 very magic 将“chocolate donut”转换为“donut chocolate”，运行`:s/\v(.+) (.+)/\2 \1/g`（将其与`:s/\(.\+\) \(.\+\)/\2 \1/g`形成对比）。
* 使用 very magic 将第 1 个字母移动到第 2 个，第 2 个移动到第 3 个，第 3 个移动到第 1 个，运行`:s/\v^(\w)(\w)(\w)/\2\3\1/g`（将其与`:s/^\(\w\)\(\w\)\(\w)/\2\3\1/g`形成对比）。

## 表示整个匹配项

**问题：**
你需要一种表示“整个匹配项”模式的方法。

**解决方案：**
在分组匹配中，`\0`是一个代表整个匹配项的特殊关键字。

如果你有字符串“pancake”并想将“pancake”更新为“fluffy pancake”，与其运行`:s/pancake/fluffy pancake`，不如运行`:s/pancake/fluffy \0/`。`\0`代表整个匹配项，即“pancake”这个单词。

如果你需要在“pancake”周围加上括号，可以运行`:s/pancake/(\0)/g`得到“(pancake)”。

或者，`&`也是整个匹配项的另一个关键字：`:s/pancake/fluffy &/`和`:s/pancake/(&)/g`。

## 使用分组匹配删除单词

**问题：**
你需要重用搜索模式的部分。

**解决方案：**
你可以使用分组匹配`\1 \2 \3`等来删除单词。

你可以使用`:%s/(.+)\n\1/\1/g`删除后续的重复行。在这里，你将`\1`用作替换模式和被替换的内容。

```
chocolate

donut

donut
```

Vim 删除了第二个“donut”。

另一个例子，如果你有一个电话号码列表：

```
123-123-1234

111-111-1111
```

如果你想删掉区号（前 3 位数字），可以运行`:%s/\v(\d{3}-)(\d{3}-)(\d{4})/\2\3`。你将：

```
123-1234

111-1111
```

## 重用上一次搜索模式

**问题：**
你刚刚搜索了一个单词（`/some keyword`），在执行替换时不想再次输入该单词。

**解决方案：**
如果你使用空替换搜索模式，Vim 将使用上一次的搜索模式！

如果你最近搜索了`/donut`，然后运行`:%s//pancake/g`，这等同于`:%s/donut/pancake/g`。既然可以少写字，何必多写？

## 更快速地进行替换删除

**问题：**
当你使用替换来删除内容时（例如`:s/donut//`），是否有更快的方法来实现？

**解决方案：**
如果你让替换模式为空，Vim 会假设你想删除它们：

* `:%s/waffles`移除缓冲区中所有的“waffles”。
* `:%s/^\n`移除缓冲区所有的空行。

## 在替换中使用表达式

**问题：**
你需要使用表达式执行复杂的替换。

**解决方案：**
你可以在替换中通过`\={expr}`使用表达式寄存器。

要将所有字符串`__DATE__`替换为今天的日期，可以运行`:%s/__DATE__/\=strftime("%c")/g`。`strftime()`是一个 Vimscript 函数（`:h strftime()`查看）。

## 移除行尾空格

**问题：**
你的缓冲区中到处都是行尾空格。

**解决方案：**
要移除行尾空格，运行`:%s/\s\+$//g`。

* `\s`代表空白字符（字面空格和制表符）。
* `\+`意味着一个或多个前面的字符。
* `$`在这里代表行尾。

合起来，`\s\+$`意味着行尾的一个或多个空白字符。记得`:s`命令在留空后部分时会自动删除，所以`:%s/\s\+$`同样有效。

## 在替换中添加新行

**问题：**
你需要向短语中添加新行。

**解决方案：**
替换也可以用于添加新行。使用`\r`模式。

如果你想在每个以“pancakes”开头的行之后添加新行，运行`:%s/^pancakes.*/\0\r/g`：

## 重复上一次替换命令

**问题：**
你需要重复上一次替换命令。

**解决方案：**
`:s`会重复不带标记的上一次替换命令。

如果你最近做了`:s/pancake/donut`并重复执行`:s`，它会快速重复。或者，你也可以按`&`。`&`是`:s`的普通模式版本。

如果你最近做了`:s/pancake/donut/g`并且想保留`g`标记，运行`:&&`。

## 将每个单词的首字母大写

**问题：**
你需要将每行中每个单词的首字母大写。

**解决方案：**
运行`:s/\<./\u\0/g`将每行中每个单词的首字母大写。

* `\<.`是匹配单词开头首的模式。
* `\u`是一个特殊的关键字修饰符，用于将后续模式转为大写。
* `\0`代表整个匹配项。

## 执行链式替换

**问题：**
你需要同时替换几个短语。

**解决方案：**
你可以使用`|`链式多次替换。

要将“good”替换为“awesome”，“将“bad”替换为“terrible”，并将“ugly”替换为“hideous”，运行：

```
:s/good/awesome/ | s/bad/terrible/ | s/ugly/hideous/
```

## 重复上一次替换的字符串

**问题：**
你需要执行不同的替换，但使用与上一次替换相同的字符串。

**解决方案：**
在替换中使用`~`模式来重复上一次的替换字符串。

如果你最近运行了`:s/pancake/donut/g`，然后运行`:s/waffle/~/g`，Vim 将也将“waffle”替换为“donut”（即最后的替换字符串）。

## 使用上一次搜索模式和替换字符串重复替换

**问题：**
你刚刚搜索了`/`。你刚刚执行了替换。现在你需要使用上一次搜索模式但使用相同的替换字符串进行替换。

**解决方案：**
使用`:~`根据上一次搜索模式和替换字符串来重复替换

如果你最近运行了`:s/pancake/donut/`且最近搜索过`/mochi`，运行`:~`将`:s/mochi/donut/`。

## 修改分隔符

**问题：**
你在斜杠丛林中迷路了。

**解决方案：**
你需要将一个网络 URL 替换为长路径`https://mysite.com/a/b/c/d/e`，结果变成了`:s/https:\/\/mysite.com\/a\/b\/c\/d\/e/hello/`。

坦率地说，很难判断哪些斜杠是替换模式的一部分，哪些是分隔符。Vim 允许使用任何单字节字符更改替换分隔符（除字母、数字、`"`、`|`和`\`外）。这意味着你可以这样做：

```
:s+https:\/\/mysite.com\/a\/b\/c\/d\/e+hello+
```

或者

```
:s@https:\/\/mysite.com\/a\/b\/c\/d\/e@hello@
```

通过此，`/`作为字面字符与分隔符之间的区别变得更加清晰。

# 全局命令 (Global Command)

## 全局命令基础

**问题：**
你不知道如何使用全局命令。

**解决方案：**
全局命令是一个非常有用的命令，用于在多行上执行命令。其通用模式为`:g/pattern/command`。

例如，要删除所有包含“let”的行，可以使用`:g/let/d`。

## 反向匹配

**问题：**
你想在不匹配的行上运行全局命令，而不是匹配的行上。

**解决方案：**
命令`:g/let/d`会删除所有包含单词“let”的行。如果你想删除所有不包含“let”的行怎么办？

你可以使用带有`g!`或`v`的反向全局命令。运行`:g!/let/d`或`:v/let/d`。

## 在多行上添加或追加

**问题：**
你需要在所有包含“const”的行末尾添加分号。

**解决方案：**
在普通模式下，可以使用`A`进入行尾的插入模式。你可以使用`normal`命令复制普通模式下的命令。

要在所有包含“const”的行末尾添加分号，运行`:g/const/normal A;`。

顺便提一下，记得可以使用`I`进入行首的插入模式。要在所有包含“；”的行开头添加“const”，运行`:g/;/normal Iconst`。

## 范围内的全局命令

**问题：**
你需要在一个范围内执行全局命令，而不是在整个文件中执行。

**解决方案：**
你可以运行`:5,10g/donut/s/pancakes/waffles/g`在第 5 行到第 10 行之间执行全局命令。
你也可以在标记的范围之间运行全局命令。命令`:'a,'bg/donut/s/pancakes/waffles/g`在标记`'a`和`'b`之间执行全局命令。

## 删除空行和空白行

**问题：**
你需要快速删掉空行。

**解决方案：**
全局命令非常适合删除多个空行和空白行（包含空格的）。

*   运行`:g/^$/d`删除所有空行。
*   运行`:g/^\s*$/d`删除所有空白行。

## 在匹配模式之间运行全局命令

**问题：**
你只需要在`pattern1`和`pattern2`之间执行全局命令。

**解决方案：**
全局命令接受形式`:g/pattern1/,/pattern2/ {cmd}`，用于在`pattern1`和`pattern2`之间执行`cmd`。

如果你想删除“apples”和“oranges”之间的文本，排除“apples”和“oranges”，运行`:g/apples/+, /oranges/- d`。如果你也想删除“apples”和“oranges”，运行`:g/apples/, /oranges/ d`。

## 合并多个空行

**问题：**
文件中有多个空行，你需要将它们合并为单行。

**解决方案：**
你可以使用 `:g/^$/,/./-1 j` 合并多个空行。

如果你有：

```

Hello

```

运行 `:g/^$/,/./-1 j` 将空行合并为单行。这个全局命令使用了两个模式：`/^$/`（空行）和 `/./-1`（非空行的前一行）。要执行的命令是合并命令（`:j`）。

或者，如果你在终端中有 `cat` 程序，也可以运行 `:%!cat -s`（`-s` 代表“squeeze”，即压缩）将多个空行压缩为单行。

## 在替换命令中重用全局命令的搜索模式

**问题：**
你想在替换命令中重用全局命令的模式。

**解决方案：**
如果全局命令后面跟着一个带有空白搜索模式的替换命令，Vim 实际上会重用该全局命令模式。

`:g/apples/s//oranges/g` 等同于 `:g/apples/s/apples/oranges/g`。

## 默认命令

**问题：**
你想打印全局命令的结果。

**解决方案：**
如果不向全局命令传递任何 `{cmd}`，Vim 将自动运行打印命令（`:p`）。

`:g/bagel` 等同于 `:g/bagel/p`。

注意，该命令的模式为 `g/re/p`。这与终端中找到 `grep` 命令相同。

这种模式 `g/re/p` 最初源于 Ed 编辑器（记得吗？）。

## 使用 execute 运行复杂表达式

**问题：**
你想使用复杂表达式运行全局命令。

**解决方案：**
你可以将 Vim 的 `:execute` 命令与全局命令配合使用。

给定一组文件名（不带扩展名）：

```

file1

file2

file3

```

为每行生成新的 markdown 文件。运行 `:g/^/execute "w " . getline(".") . ".md"`。

该命令执行了 `:w file1.md`、`:w file2.md` 和 `:w file3.md`。Vim 将生成 `file1.md`、`file2.md` 和 `file3.md`。太棒了！

## 反转所有行

**问题：**
你需要反转每一行的顺序。

**解决方案：**
要反转所有行，只需运行 `:g/^/m 0`。

* `^` 将匹配文件中的所有行。
* `m 0` 是移动命令。它将每行移动到第 1 行，有效地反转了整个顺序。

## 给所有数字加上双引号

**问题：**
你需要给任何数字加上双引号。

**解决方案：**
给定以下文本：

```

const one = 1

const two = 2

const three = 3

const nope = "don't mind me"

const four = 4

const five = 55

```

运行 `:g/\d\+/s//"&"/g` 得到：

```

const one = "1"

const two = "2"

const three = "3"

const nope = "don't mind me"

const four = "4"

const five = "5"

```

解释：

* 模式 `\d\+` 匹配一个或多个数字。
* `s//` 是一个带有空白替换模式的替换命令。记得如果留空搜索模式，Vim 将使用由全局命令所使用的模式。
* `"&"` 是替换模式。记得 `&` 代表整个匹配项。`"&"` 用双引号包裹整个匹配项。

## 更改分隔符

**问题：**
你迷失在 `/` 的海洋中了。

**解决方案：**
就像你可以更改替换命令的分隔符一样，你也可以使用任何单字节字符更改全局命令的分隔符。

这是一个有效的全局命令：

```

:g@console@d

```

如果你在全局命令中使用替换命令，可以这样做：

```

g@one@s+const+let+g

```

更容易看出哪些部分属于全局命令，哪些部分属于替换命令。

## 程序化全局命令

**问题：**
你需要程序化运行全局命令。

**解决方案：**
全局命令非常灵活。你可以用 Vimscript 增强全局命令。

你可以做一些事情：

* 使用 `:g/^/if line(".") % 2 != 0 | norm! d$` 删除偶数行。
* 使用 `:g/^/if strlen(getline(".")) < 3 | d` 删除长度小于 3 的行。

# 标签（Tags）

**问题：**
你想了解 Vim 的标签系统。

**解决方案：**
在许多现代编辑器中，你可以点击函数或类定义，它会带你到该函数或类定义的地方。你可以在 Vim 中通过标签实现。虽然你可以使用 `grep`、`vimgrep` 或外部库（如 `fzf.vim`）搜索任何定义，但标签是处理这类工作的最佳工具。

把 Vim 标签想象成地址簿：

```

Name    Address

Iggy1   123 Awesome St, 12345

Iggy2   987 Incredible Ave, 98765

Iggy3   555 Handsome Rd, 55555

```

要查找 `Iggy1` 的地址，首先打开地址簿，然后在 `Name` 列中搜索 `Iggy1`，然后查找对应的地址。标签（Tags）的工作原理也是如此的。Vim 标签并不是存储名称-地址表，而是存储单词定义及其在项目中的位置。

那么，该如何开始使用标签呢？

你需要一个名为 `tag generator` 的工具来生成这个地址文件。现代 Vim 并不自带标签生成器，因此你需要单独下载它。你有几个选项可以选择，但我推荐的是 [Universal Ctags](https://github.com/universal-ctags/ctags) 或 [Exuberant Ctags](http://ctags.sourceforge.net)。请按照它们网站上的说明进行安装。

在这里我将使用 Universal Ctags。安装完成后，你应该可以获得 `ctags` 命令。如果你使用不同的标签生成器，仍然可以参考本文。

假设你有两个 ruby 文件：

```ruby
## one.rb

class One

  def initialize

    puts "Initialized"

  end

  def donut

    puts "Bar"

  end

end

## two.rb

require './one'

one = One.new

one.donut
```

在终端运行 `ctags -R .` 将生成一个基础标签文件（命名为 `tags`）。`-R` 表示递归调用。

在该文件内部：

```

One	one.rb	/^class One$/;"	c

donut	one.rb	/^  def donut$/;"	f	class:One

initialize	one.rb	/^  def initialize$/;"	f	class:One

```

你的文件可能会包含额外的行，但它至少应该包含一个单词定义及其地址。

如果你查看其中之一：

```

donut	one.rb	/^  def donut$/;"	f	class:One

```

`donut` 是标签名。当你的光标置于“donut”上时，Vim 会在标签文件中搜索包含“donut”的行。

`one.rb /^ def donut$/` 是地址。它由两部分组成：

* `one.rb` 是文件名。Vim 会查找名为 `one.rb` 的文件。
* `/^ def donut$/` 是地址。`/.../` 是模式指示符。`^` 是行首元素的模式。后面跟着两个空格，然后是字符串 `def donut`。最后，`$` 是行尾元素的模式。这与你使用 `/^ def donut$` 进行搜索是一样的。
* `f class:One` 是标签选项，它告诉 Vim “donut”是一个函数 (f) 且是 `One` 类的一部分。

简而言之，标签文件就是一个地址簿，告诉 Vim 在何处找到特定的定义。

## 设置标签文件

**问题：**
你成功创建了标签文件，但你不知道如何设置它。

**解决方案：**
运行 `:set tags?`，Vim 会显示当前的标签。要设置自定义标签文件，请使用 `:set tags+=tags`。`+=` 语法将路径添加到现有列表之后，而不是覆盖它。

如果你想在标签之间跳转，可以使用 `Ctrl` 跳转到定义，并使用 `Ctrl-t` 返回。你也可以使用 `:tags` 搜索特定的标签名。

## 水平生成数字

**问题：**
你需要在同一行内生成数字序列。

**解决方案：**
要水平生成数字，请使用 `put` 和 `join`。

* `:put=join([1,2,3,4], \" - \")` 生成 `1 - 2 - 3 - 4`。
* `:put=join(range(1,10), \"', '\")` 生成 `1’, ‘2’, ‘3’, ‘4’, … ‘10`（它不会生成第一个和最后一个单引号，你可以手动添加它们）。

## 根据行号将文本转换为数字的列表

**问题：**
你想根据行号将文本转换为编号列表。

**解决方案：**
若要在多行上创建编号列表，请运行 `:%s/^/\=printf('%-2s', line('.'))`。

如果你有如下从第 1 行开始的文本：

```

Breakfast is good

But lunch is better

Dinner is still the best

```

运行 `:%s/^/\=printf("%-2s", line("."))` 即可获得：

```

1 Breakfast is good

2 But lunch is better

3 Dinner is still the best

```

命令拆解：

* `^` 代表行首。
* `\=` 允许在替换中使用 Vimscript 表达式。
* `printf('%-2s')` 打印带空格的字符串（`-2` 是宽度，左对齐）。
* `line('.')` 是当前行号。

# 文本操作

## 如何使用 Vim

**问题：**
你难以记住数以万计的 Vim 命令。

**解决方案：**
不要尝试记住每一个命令。相反，将它们拆分为更小的部分。Vim 命令包含类似于语法的模式（我们称之为“Vim 语法”）来创建组合。

Vim 语法中有一个规则：

```

动词 + 名词

```

操作符（operators）是动词，动作（motions）是名词。大多数操作都是遵循该规则完成。你只需要掌握少数操作键和导航键就能提高工作效率。

例如：

* 删除下一个单词，运行 `dw`；动词 (`d`) + 名词 (`w`)。
* 向左剪切两个字符，`y2h`；动词 (`y`) + 名词 (`2h`)。注意你可以在动作之前传递计数 (`2h`)。
* 修改下一行，`cj`；动词 (`c`) + 名词 (`j`)。

文本通常是结构化的。文件中存在“单词”、“段落”、“括号”等概念。Vim 有一种名为“文本对象”（text objects）的抽象来处理这些结构。有两种不同的文本对象：内部对象（`i` + object）和外部对象（`a` + object）。这看起来可能很复杂，但一旦你理解了它，就会非常简单且直观。

文本对象是 Vim 语法规则“动词 + 名词”中的名词。你需要在文本对象之前传递一个操作符。

```javascript
const hello = function() {

  console.log("Hello Vim");

  return true

}
```

如果光标在“Hello”的“H”上：

* 删除整个“Hello Vim”：`di(`。
* 删除函数块（被 `{}` 包围的部分）：`di{`。
* 删除字符串“Hello”：`diw`。

如果你是 Vim 新手，你不需要记住几十个操作符。你可以先从记住这 3 个开始：

* `d`（删除）。
* `c`（修改）。
* `y`（剪切）。

## 更改大小写

**问题：**
你需要更改文本的大小写。

**解决方案：**
有多种方法可以更改文本的大小写。

更改单个字符的大小写：

* `~` 切换光标所在字符的大小写。如果光标在“donut”的“d”上，按下 `~` 会将其切换为大写字母。
* `vu` 将光标所在字符转为小写。如果光标在“Donut”的“D”上，按下 `vu` 会将其转为“d”。
* `vU` 将光标所在字符转为大写。如果光标在“donut”的“d”上，按下 `vU` 会将其转为“D”。

使用动作来更改大小写：

* `g~ {motion}` 切换动作指定文本的大小写。当与 `g` 结合时，`g~` 作为一个操作符。切换后两个单词的大小写，运行 `g~2w`。切换当前内部单词的大小写，运行 `g~iw`。
* `gu {motion}` 将动作指定的文本转为小写。将 `()` 内部文本转为小写，运行 `gui(`。
* `gU {motion}` 将动作指定的文本转为大写。大写到文件末尾，运行 `gUG`。

更改当前行的大小写：

* 切换当前行的大小写，运行 `g~~`。
* 将当前行转为小写，运行 `guu`。
* 将当前行转为大写，运行 `gUU`。

## 交换两个字符

**问题：**
你需要快速交换两个相邻字符。

**解决方案：**
我在编辑时经常犯这类类型错误：输入“teh” 而不是“the”，输入“cosnt” 而不是“const”等。修复双字符拼写错误简单的方法是使用 `xp`。

`x` 删除光标下的字符，`p` 粘贴最近删除的字符。

## 替换模式

**问题：**
你需要用输入的字符替换原有字符。

**解决方案：**
Vim 有一种替换模式（Replace mode），可以通过 `R` 进入。在替换模式下，Vim 会用你输入的每个字符替换现有的字符。

你也可以使用 `gR` 进入虚拟替换模式（virtual replace mode）。该命令与 `R` 相似，但当你按下 `<Tab>` 时，它会替换多个字符（而替换模式下只替换一个字符）。

## 将命令行命令作为操作符的动作

**问题：**
这并不是什么真正的问题，但知道它很有用。

**解决方案：**
在 Vim 中，你可以使用 `:` 作为操作符的动作。在 Vim 语法“动词 + 名词”的语境下，`:cmd` 可以作为动词的名词。

* 从当前位置到“b”的第一个匹配项：`d:call search("b")`。
* 从当前位置到第 10 行：`d:10`。

上面的示例看起来为了完成一个简单任务费了很大精力，你可能在想什么时候需要这个。事实是，我并没有花很多时间研究这个功能。

然而，如果你有一系列 Vimscript 函数可以根据复杂的模式移动光标，例如 `d:call FindWordsIn("Spanish")`, `d:call FindEnglishAdjectives()` 等，这可能是一个非常有用的功能。还要记住你可以配合任何终端命令使用它（`d:!{some_command}`）。也许有人会发现有效使用它的方法。

**解决方案：**
你可以强制动作按行、按字符或按块执行，就像可视模式一样。

在这种情况下，如果你需要对包含 0 的三列运行删除操作符：

```

br0eakfast

```



将光标置在第一行的“0”上，运行`dCtrl-V2j`（注意这类似于块级视化模式）。

## 持久化撤销

**问题：**
每当你关闭并重新打开 Vim 时，你希望能够撤销关闭 Vim 前执行的最后操作。

**解决方案：**
撤销文件（undo file）允许你在关闭 Vim 后仍保留撤销历史；你可以使用`:wundo`创建撤销文件并使用`:rundo`加载它。

编辑`somefile.txt`，然后使用`:wundo! somefile.undo`创建撤销文件（你可以给它任何名称），然后关闭 Vim 并重新打开`somefile.txt`。运行`:rundo somefile.undo`来加载撤销文件。现在你可以从该文件中撤销，就像你从未退出过 Vim 一样。

## 分块撤销

**问题：**
在输入一个长段落后，执行撤销时，Vim 会删除整个段落，即使你只需要撤销最后一句。

**解决方案：**
Vim 的撤销是撤销上一次“更改”。你在插入模式下输入的所有文本都算作一次更改。你可以在每句话后退出插入模式，以创建更小的更改。

或者，你可以使用`Ctrl-G u`创建一个撤销块，在不离开插入模式的情况下将更改拆分为更小的部分。方法如下：

如果你输入`ipancake breakfast<Esc>`然后按`u`，Vim 会撤销整个“pancake breakfast”。要添加一个断点，运行`ipancake <Ctrl-G u>breakfast<Esc>`。现在当你按`u`时，Vim 只会移除“breakfast”。

## 合并行

**问题：**
你需要将下一行合并到当前行。

**解决方案：**
如果你按下`J`，Vim 将将当前行下方的行合并到当前行。Vim 在合并两行时会自动添加一个额外的空格，因此如果你不需要额外的空格，请使用`gJ`在不留空格的情况下合并两行。如果你处于视化模式下，可以使用`J`合并所有高选的行。

`:j`（`:join`的缩写）是`J`的命令行版本。通过运行`:j`，Vim 的行为将类似于`J`。如果你想合并所有行，运行`:%j`。

## 使用终端命令

**问题：**
你需要使用终端命令过滤你的文本。

**解决方案：**
Vim 有一个感叹号（`!`）运算符，可以通过外部命令过滤文本。

例如，你有以下文本需要将其表格化并移除不包含“Ok”的行：

```
Id|Name|Cuteness

01|Puppy|Very

02|Kitten|Ok

03|Bunny|Ok
```

你可以使用`column`终端命令和`awk`命令来实现这一点。只需运行：

```bash
!}column -t -s "|" | awk 'NR > 1 && /Ok/ {print $0}'
```

你将得到一个干净的过滤表格：

```
02  Kitten  Ok

03  Bunny   Ok
```

这是 Vim 的亮功能之一，因为它允许你在 Vim 内部命令之外扩展使用外部命令，允许你组合更复杂的操作。

# 视化模式

## 视化模式基础

**问题：**
你不知道如何使用 Vim 的视化模式。

**解决方案：**
Vim 的视化模式类似于大多数文本编辑器中的高亮显示（你高亮一段文本，然后对高选的文本应用更改）。

有三种不同的视化模式：

*   `v` - 字符级视化模式
*   `V` - 行级视化模式
*   `Ctrl-V` - 块级视化模式。

尝试一下吧！使用每不同的视化模式来感受。你可以使用 Vim 导航来扩展或收缩高选区域。要退出视化模式，按下`<Esc>`。

你还可以对高选的文本体执行操作。例如，如果你在高选文本体时按下`d`，该文本体将被删除。

## 在多行中插入文本

**问题：**
你需要在多行中插入文本。

**解决方案：**
你可以使用块级视化模式（`Ctrl-V`）在多行中插入文本。

如果你有：

```
strawberry

chocolate

sugar
```

一旦你使用块可视模式（block-wise visual mode）高了多列，你可以使用`I`在光标前插入文本，或使用`A`在光标后插入文本。

*   要在每行的开头插入单词“sweet”，请使用可视块选择（`<Ctrl-V>`和向下键）高亮所有 3 行，然后输入`0Isweet <Esc>`。

*   要在每行的末尾插入单词“donut”，请使用可视块选择（`<Ctrl-V>`和向下键）高亮所有 3 行，然后输入`$A donut<Esc>`。

## 快速重新选择上一个可视高亮区域

**问题：**

你需要重新选择上一次可视高亮区域。

**解决方案：**

运行`gv`可视化高亮上一次可视选择。

如果你使用`v`、`V`或`Ctrl-V`高亮了一段文本，然后离开了可视模式，下次你按下`gv`时，Vim 将重新选择该块文本。当你忘记对之前高亮的文本执行额外的操作时，可以使用此方法。

## 双向扩展可视高亮区域

**问题：**

你需要向任何方向扩展你的可视高亮。

**解决方案：**

在可视高亮状态下按下`o`或`O`会将光标移动到可视高亮区域另一端。

假设你开始高亮下方的文本，然后你发现也需要高亮上方文本。如果你向上移动，可视选择将会缩小。要将高亮扩展到上方文本，请先更改光标位置。

要更改光标位置，请按下`o`或`O`。现在你的光标位于对侧位置，你就可以扩展并高亮上方的文本了。

## 在可视模式下切换到不同的可视模式

**问题：**

你目前正处于字符级可视模式，但你需要切换到行级可视模式。

**解决方案：**

在可视模式下，你可以通过按下另一个可视模式命令切换到不同的可视模式。

*   如果你处于字符级可视模式（`v`），按下行级可视模式命令（`V`）将切换到行级可视模式。

*   如果你处于行级可视模式（`V`），按下块级可视模式命令（`Ctrl-V`）将切换到块级可视模式。

*   如果你处于块级可视模式（`Ctrl-V`），按下相同的可视模式命令（在此例中为块级可视模式命令`Ctrl-V`）将退出可视模式。

## 可视高亮上一个搜索术语

**问题：**

你最近使用`/donut`进行搜索，现在发现需要跳回那个单词并修改它。

**解决方案：**

按下`gn`跳到下一个上一次搜索术语（类似于在`/hello`后按下`n`），并自动高亮该搜索术语。

假设你有以下文本：

这与点命令（`.`）结合使用也非常有用。按下`gn`，Vim 将高亮下一个“donut”。然后按下`d`删除它。要删除后续的 donut，只需运行`n`（下一个匹配项）和`.`。你现在可以重复`n . n . . n .`等。

**问题：**

你需要通过程序方式设置某些选项。

**解决方案：**

你可以使用`&`在 vimrc 中设置选项而不是使用`set`。通过这种，你可以使用 Vimscript 表达式。

## 创建自定义命令

**问题：**

你需要创建你自己的`:`命令。

**解决方案：**

你可以使用`:command`创建一个自定义行命令。

以下将创建一个自定义命令`:GimmeDate`。

```
function MyDate()

endfunction

command GimmeDate call MyDate()
```

现在当你运行`:GimmeDate`时，Vim 将运行`call MyDate()`。

## 根据目录条件运行 Vim 设置

**问题：**

你希望只在工作时使用某些选项，并在个人项目中使用另一组选项。

**解决方案：**

let cwd = getcwd()
if cwd =~# "Work"
  echom "WORK STUFF"
  set background=dark
else
  echom "NON WORK STUFF"
  set background=light
endif
```

## 根据文件类型运行特定配置

**问题：**

你希望根据当前的文件类型使用不同的选项。

**解决方案：**

Vim 允许你在处理特定文件类型时运行特定的配置。

Vim 通常可以检测到你正在处理的文件类型。要检查当前文件的文件类型，请运行`:set ft?`。

例如，如果你正在处理`test1.py`，运行`:set ft?`将返回`filetype=python`。

Vim 拥有一套文件类型插件运行时系统，允许你根据文件类型运行特定的 Vim 脚本。你可以在`.vim`目录中找到它。它通常位于根路径下。

在`.vim`目录内部，创建一个名为`ftplugin`的目录。在该目录内，创建一个与你想要自定义设置的文件类型同名的文件。在这种情况下，让我们来创建两个文件类型插件文件，一个用于 python，一个用于 ruby。

```
~/.vim/ftplugin/python.vim

# 内部内容：

set background=light

~/.vim/ftplugin/ruby.vim

# 内部内容：

set background=dark
```

当我打开`test.py`时，Vim 是浅色背景。当我打开`test.rb`时，Vim 将是深色背景。

## 切换布尔选项

**问题：**

你需要快速切换任何 Vim 布尔选项。

**解决方案：**

你可以使用`!`后缀切换任何 Vim 布尔选项的值。

某些值如`number`、`relativenumber`、`wrapscan`等包含布尔值（`set number`、`set relativenumber`、`set wrapscan`）。它们的相反值通常以`no`为前：`nonumber`、`norelativenumber`、`nowrapscan`等。

关闭`set number`的方法是运行`set nonumber`。更快的方法是使用`set number!`进行切换。

顺便提一下，记住`@:`可以重复上一个命令行命令。由于`:set number!`只是一个命令行，你可以使用`@:`快速地在 Vim 布尔选项之间切换。

## 将 vimrc 拆分为多个文件

**问题：**

你的`vimrc`太大了，你想将它拆分成多个较小的文件。

**解决方案：**

你可以通过将`vimrc`拆分为多个较小的文件来保持它的精简。

要使用此功能，请为你的`vimrc`文件创建一个名为`settings/`的新目录（你可以随心所命名）：`~/.vim/settings/`。

假设你想将`vimrc`分为 4 个部分，创建这 4 个文件：

*   第三方插件（`~/.vim/settings/plugins.vim`）。
*   通用设置（`~/.vim/settings/configs.vim`）。
*   自定义函数（`~/.vim/settings/functions.vim`）。
*   键位映射（`~/.vim/settings/mappings.vim`）。

在你的主`vimrc`中，添加：

```
source $HOME/.vim/settings/plugins.vim

source $HOME/.vim/settings/configs.vim

source $HOME/.vim/settings/functions.vim

source $HOME/.vim/settings/mappings.vim
```

这里的关键是使用`:source`命令。它类似于许多编程语言中的`import`或`require`。在这些设置文件的每一个文件中，添加通常的 vimrc 设置和配置。

在`~/.vim/settings/plugins.vim`中：

```
call plug#begin('~/.vim/plugged')

  Plug 'mattn/emmet-vim'

  Plug 'preservim/nerdtree'
call plug#end()
```

在`~/.vim/settings/configs.vim`中：

```
set nocompatible

set relativenumber

set number
```

在`~/.vim/settings/functions.vim`中：

```
function! ToggleNumber()

  if(&relativenumber == 1)

    set norelativenumber
  else
    set relativenumber
  endif

endfunc
```

在`~/.vim/settings/mappings.vim`中：

```
inoremap jk <esc>

nnoremap <silent> <C-f> :GFiles<CR>

nnoremap <Leader>tn :call ToggleNumber()<CR>
```

现在你的主`vimrc`只有 4 行了！

## 映射新键

**问题：**

你需要创建自定义映射。

**解决方案：**

如果你发现自己反复执行相同的复杂任务，这说明你应该创建一个新的键位映射了。有很多内容可以进行映射。

第一个是 leader 键（主键）。我喜欢使用`<Space>`作为我的 leader 键。你可以通过以下方式更改 leader 键：

```
let mapleader = "\<space>"
```

你还可以映射运算符和命令。例如，我在我的`vimrc`中有两个映射：

```
nnoremap <silent> <C-f> :GFiles<CR>

nnoremap <Leader>tn :call ToggleNumber()<CR>
```

第一个映射映射到`fzf.vim`插件的`:GFiles`命令。第二个映射是一个自定义函数调用（我有一个名为`ToggleNumber()`的函数）。通过使用`<C-f>`，我覆盖了 Vim 原生的`Ctrl-F`翻页功能。如果你的映射与 Vim 的原生命令冲突，它会被覆盖。

我用于映射的命令`nnoremap`实际上由三个部分组成：

*   `n`代表普通模式。
*   `nore`意味着非递归。
*   `map`是映射命令。

Vim 拥有各种模式的映射。`nnoremap`意味着它将在普通模式下。如果我想在插入模式下创建映射，我将使用`i`前缀：

```
inoremap jk <Esc>
```

这只在插入模式下有效，而在普通模式下无效。

使用非递归版本也很重要（使用`nnoremap`和`inoremap`代替`nmap`和`imap`），因为这可能会导致无限递归。如果你不确定是否要使用`nore`，请始终使用它。

其他的映射模式包括：`map`（普通、视觉、选择和操作等待）、`vmap`（视觉和选择）、`smap`（选择）、`xmap`（视觉）、`omap`（操作等待）、`map!`（插入和命令行）、`lmap`（命令行）、`cmap`（命令行）以及`tmap`（终端）。我们将详细介绍这些。更多信息请查看`:h.txt`。

你可能会发现复制别人的`vimrc`更容易。虽然这样做也可以，但我建议从零构建自己的`vimrc`。每个人的习惯都不同。创建最适合自己的映射。让你的`vimrc`属于你自己。

## 使用包安装插件

**问题：**

你想用 Vim 安装插件。

**解决方案：**

从 8 版本开始，Vim 自带了一个插件管理器叫做`packages`。

Vim 会检查`.vim`目录下的名为`pack`的目录。包功能支持两种加载机制：

*   自动加载插件。
*   手动加载插件。

要自动加载插件，你需要将其放在`start/`目录中，路径如下：

```
~/.vim/pack/*/start/
```

注意星号`*`代表任意名称。你可以将其命名为任何内容。在这种情况下，让我们调用`packdemo`：

```
~/.vim/pack/packdemo/start/
```

你不能跳过`pack/`和`start/`之间的目录。如果你尝试这样做，将不起作用。你必须在`pack/`和`start/`之间放置一个目录名。

```
~/.vim/pack/start/
```

假设你想安装 NERDTree 插件。在终端中，进入`start/`目录，并在那里克隆 NERDTree 仓库。

```bash
cd ~/.vim/pack/packdemo/start/

git clone https://github.com/preservim/nerdtree.git
```

以上全部。一旦库插件进入`start/`目录，Vim 会在启动时自动使用它。下次启动 Vim 时，你现在就可以使用`NERDTree`命令了。你可以根据需要在此路径下克隆任意数量的仓库。要删除插件，只需从`start/`目录中删除该插件目录即可。

要手动加载插件，你需要将它放入`opt/`目录中：

```
~/.vim/pack/*/opt/
```

同样，`*`代表“任何目录名称”。你可以使用相同的目录名称或不同的名称。在这种情况下，让我们再次使用`packdemo/`作为名称。

```
~/.vim/pack/packdemo/opt/
```

现在让我们来安装 killersheep 游戏（需要 Vim 8.2）。

```bash
cd ~/.vim/pack/packdemo/opt/
git clone https://github.com/vim/killersheep.git
```

现在当你启动 Vim 时，游戏还不可用。要手动激活`opt/`目录中的包，请运行`:packadd {package-name}`。

```
:packadd killersheep
```

现在运行 killership 命令`:KillKillKill`。享受游戏吧！

## 在特定事件上触发动作

**问题：**

你希望在每次保存文件时执行一个特定的操作。

**解决方案：**

Vim 有一个在触发特定事件时触发的自动命令`:autocmd`。

例如，每当打开一个扩展名为`.awesome`的文件时，将`filetype`设置为`awesomefile`，可以在 vimrc 中添加以下内容：

```
autocmd BufNewFile,BufRead *.awesome set filetype=awesomefile
```

在保存 Python 文件时自动生成标签，请运行：

```bash
autocmd BufWritePost *.py silent !ctags -R .
```

自动命令支持无数不同的事件。要查看所有事件，请查看`:h autocommand-events`。

## 窗口

### 水平和垂直拆分窗口

**问题：**

你需要拆分当前窗口。

**解决方案：**

* 你可以使用`Ctrl-W s`或`:sp`水平拆分窗口。你也可以`:sp somefile.txt`来显式指定在拆分窗口中打开的文件。
* 你可以使用`Ctrl-W v`或`:vsp`垂直拆分窗口。你也可以`:vsp somefile.txt`来显式指定在拆分窗口中打开的文件。

### 调整窗口大小

**问题：**

你需要调整当前窗口的大小。

**解决方案：**

你可以更改窗口的长度和宽度：

* 要让当前窗口变长或变短，运行`Ctrl-W +`或`Ctrl-W -`。
* 要增加或减少当前窗口宽度，运行`Ctrl-W >`或`Ctrl-W <`。

或者，你也可以通过以下方式调整大小：

* 要设置当前窗口高度为 N，运行`zN<Enter>`（例如：`z10<Enter>`将窗口高度设置为 10）。你也可以运行`:resize N`将高度设置为 N（例如：`res 10`将其设置为 10）。
* 要设置当前窗口宽度，运行`Ctrl-W |`。默认情况下，它将其设置为最大宽度。你也可以运行`:vertical res N`，其中`N`是宽度（例如：`:vertical res 10`将设置为 10）。

最后，如果你打开了多个不同高度和宽度的窗口，运行`Ctrl-W =`让所有窗口的变得相等。

### 关闭或缩放当前窗口

**问题：**

你需要快速关闭当前窗口或缩放当前窗口。

**解决方案：**

* 使用`Ctrl-W c`关闭当前窗口（如果它是最后一个窗口，则无法关闭）。你也可以运行`:close`。
* 使用`Ctrl-W o`“放大”当前窗口并关闭其他打开的窗口。你也可以运行`:on`。

### 将光标移动到另一个窗口

**问题：**

你打开了多个窗口，需要将光标移动到不同的窗口。

**解决方案：**

使用`Ctrl-W h/j/k/l`分左、下、上、右窗口。

你也可以使用`Ctrl-W w`移动到另一个窗口。你可以给此命令传递计数。如果你运行`3 Ctrl-W w`，Vim 将跳转到第 3 个窗口。

### 打开一个新窗口

**问题：**

你需要快速打开一个新窗口。

**解决方案：**

* 使用`Ctrl-W n`或`:new`创建一个新的水平拆分缓冲区。
* 使用`:vnew`创建一个新的垂直拆分缓冲区。

### 使用两个窗口对比文件差异

**问题：**

你需要在 Vim 中比较两个文件的差异。

**解决方案：**

要在两个文件之间创建差异，可以使用`:diffthis`。以下是使用方法：

* 首先在 Vim 中打开`file.txt`。
* 然后在拆分模式下打开另一个文件`file2.txt`（`:vsp file2.txt`）。
* 在第一个缓冲区中运行`:diffthis`。
* 在第二个缓冲区中运行`:diffthis`。
* 要关闭，运行`:diffoff`。

本质上，你需要在每个窗口中运行`diffthis`命令。
