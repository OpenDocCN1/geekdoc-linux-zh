### 黑帽黑客
我们在本指南中要查看的第一类黑客是`黑帽黑客`。这是我们在听到黑客时最常想到的类型，也是我们在听到黑客时首先考虑的类型。`黑帽黑客` 是那些在系统中寻找漏洞并利用它们的人，这种利用通常是为了财务利益或其他恶意原因。这些人通常不在乎他们给他人造成的伤害。他们想要收集这些信息以满足自己的需求。通常，这样做是为了在不留痕迹的情况下发财，他们只关心自己的利益。根据`黑帽黑客` 进入系统的程度，他们可能会对用户、商店以及组织本身造成巨大的破坏。他们会努力窃取财务信息，破坏安全，甚至关闭某些网站。这类黑客从想要在网络中传播病毒的业余爱好者到犯罪分子，其目标是窃取信用卡号和其他重要信息。

`黑帽黑客` 能够利用许多不同的方法，这些方法与`灰帽黑客`和`白帽黑客` 相似。例如，`黑帽黑客` 可能依赖的活动包括在系统上添加键盘记录器程序来窃取数据，甚至发动整个攻击来禁用网站。有时，这些恶意黑客为了获取所需的信息会进入系统并伪装成另一个用户。这类黑客与`灰帽黑客`或`白帽黑客` 之间的主要区别在于意图。他们可能是为了自己获利，这对业务来说是危险的。

### 灰帽黑客
现在我们更好地理解了什么是`黑帽黑客`，是时候查看`灰帽黑客`了。`灰帽黑客` 是那些违反原则标准的人，就像`黑帽黑客` 一样，区别在于他们这样做时没有恶意意。他们处于中间地带，利用系统是为了告知公众这些问题。尽管他们是非法行事，但他们通常是为了公共利益。

### 白帽黑客
我们需要查看的第三类黑客是`白帽黑客`。他们是安全领域的专业，进入受保护的系统和其他网络进行测试和评估。他们通常为公司工作，确保任何潜在的漏洞和问题得到解决。在大多数情况下，`白帽黑客` 与`道德黑客`（ethical hacker）同义，他们工作是为了帮助业务。`白帽黑客` 往往是受过教育的，以学习计算机系统及其运作方式。其他类型的黑客通常是自学的。有些人可能拥有 `IT` 或计算机学位，但大多数只是对这种系统感兴趣，并通过练习来提高技能。`白帽黑客` 是那些花费大量时间处理计算机技术并在过程中学习黑客技巧的专业人士，保护公司免受各种攻击的侵害。

1. 侦察
2. 扫描
3. 获取访问
4. 维持访问
5. 清除痕迹

### 侦察
我们将查看黑客过程的第一阶段被称为`侦察`。这是为了尽可能收集数据，它是最重要的阶段。当然，有些人人认为这个阶段很无聊，因为它不涉及高级技术，但它是开始的必要。

在这个阶段，我们可以处理两种类型的侦察：`被动`和`主动`。被动方法通常更容易，因为它让我们隐藏得更深，同时我们仍然可以收集大量所需的信息。例如，当我们检查公司网站或查阅包括 `WHOIS` 在内的公共记录时，这帮助我们收集公司及其网站的数据。

主动侦察是这里我们可以处理的第二种侦察。由于这种搜索涉及我们与目标的直接交互，因此出现了一个额外的挑战。直接给目标打电话并让他们说话是该过程运作的示例之一。此外，一些黑客喜欢使用`ping 服务`。他们喜欢使用它的原因是这允许他们确定系统是否会有响应。如果没有响应，可能是时候寻找另一种进入进入系统的方法了。如果使用`ping 服务`来 ping 目标的一个服务器，请意识到这是主动的，因为你仍在触碰服务器。在这里处理任何主动过程时，我们必须小心。总有留下标记的可能性。如果你任何时候留下了痕迹，它可能会引导目标公司直接回到你这里。

# 准备工作

开始之前，我们将学习如何使用 Windows 10 程序进行 Kali Linux v2019.2 的双启动。第一步是下载 Kali Linux 的最新 ISO 文件。你可以通过访问 `kali.org` 获取该文件。在下载时，你可以选择下载 32 位或 64 位版本。

在 Kali Linux 等待下载一段时间时间后，下一步是创建我们自己的可启动 USB 盘。为此，我们需要使用 `Rufus` 扩展。这是一个可以帮助我们创建此类可启动 USB 闪存驱动器的实用程序。在将其安装到系统之前，请前往 `Rufus.ie` 下载该扩展。

当你的电脑上有了这两项物品后，我们想要从制作可启动 USB 开始。首先，连接我们想要使用的 USB 盘。如上所述，这需要至少有 4 GB 内存才能工作，并有足够的空间来处理 `Rufus` 扩展和 Kali Linux。当 USB 盘插入电脑后，我们可以运行 `Rufus` 并按照下面的步骤创建可启动 USB 驱动器。

## 创建可启动 USB

1. 首先，屏幕上会显示一个关于你正在运行的 `Rufus` 程序的界面。
2. 检查选中的 USB 驱动器是否正确，然后点击较小的光驱驱动器图标。
3. 找到我们之前下载的 Kali Linux ISO 文件，然后点击“开始”。给此过程留几分钟时间完成，然后再继续后续操作。
4. 进程完成后，你可以点击关闭按钮关闭 `Rufus` 窗口。这将为你提供 Kali Linux 的可启动 USB 盘。

### 其他用途
- 除了用此帮助在 Windows 中进行 Kali Linux 双启动外，你还可以使用此 USB 盘进行 Kali 现场启动。这意味着我们可以在不将其安装到系统中的情况下运行 Kali。请记住，当你进行这种操作时，它会限制一些功能和特性。

此时，我们注意到第一阶段的工作已经完成。Kali Linux 的 ISO 镜像已经下载，制作了可启动的 USB 启动盘，并为 Kali Linux 安装创建了单独分区。在继续之前，我们应该记住，如果我们想在程序中使用这些功能，BIOS 中提供了“快速启动（Fast Boot）”和“禁用安全启动（Disable Secure Boot）”选项。

现在我们可以重启笔记本电脑或 PC 了。在再次启动时进入引导管理器。在启动选项中选择 `USB`。请记住，不同品牌的选项略有不同。现在你可以在屏幕上看到 Kali Linux 的安装界面。此时会出现几个关于如何安装 Kali Linux 的选择。你可能希望选择“图形化安装（Graphical Install）”选项以帮助 Kali Linux 更轻松地启动。我们可以更进一步，添加一些我们想要的设置和功能。例如，你可以选择安装过程中使用的语言以及国家。

在我们完成并添加了上述一些偏好以及系统要求的其他选项后，就是时候处理主机名（hostname）了。你的安装程序会要求输入 `Hostname`。你可以选择任何喜欢的名称，因为这就像你的用户名。然后应输入 `root` 用户的密码。输入完用于管理账户的密码后，你可以点击继续（continue）。

现在，我们想要选择要使用的分区方法，我们要操作的选项是“手动（Manual）”。下一步需要一些小心。我们只想选择之前为 Kali 安装所花时间创建的分区，然后按继续（Continue）。当你确定选了正确的选项时，可以在继续之前选择“删除该分区（Delete the partition）”。如果你操作得当，你会注意到“空闲空间（FREE SPACE）”，这就是 Kali 安装中的分区。在继续后续流程之前，我们要选择这个空闲空间分区。

在这里，安装程序将询问我们如何使用该空闲空间。我们的目标是点击“自动分区空闲空间（Automatically partition the free space）”然后继续。之后，选择“所有文件在一个分区（All files in one partition）”选项。这是对新用户的推荐选项，除非你的版本中表述有所不同。然后，我们要选择“完成分区并写入更改到磁盘（Finish partitioning and write changes to disk）”。它要求你授予权限将这些更改写入磁盘。你可以选择“是（Yes）”然后继续（Continue）。

这就是 Kali Linux 安装过程发生的地方。这可能需要一些时间，所以预计过程完成前大约需要 15 分钟。在过程过半时，网络会请求网络镜像（network mirror）。选择你想要的一个。此设置是关于更新选项的，最好现在选择 `no`，以后如果需要再进行更改。

接下来，安装程序将询问安装 `GRUB` 引导加载程序。你需要在继续之前点击“是（Yes）”。接下来，它将询问你想在哪里安装 Kali GRUB 引导加载程序。最佳选择是带有第二个选项的硬盘。我们希望 `GRUB` 安装在你的硬盘上，否则当电脑启动时，Kali Linux 安装将不会显示选择系统的选项，而这正是我们这个过程的一个大目标。

在完成这些步骤并成功完成 Linux 安装后，你现在将看到一个询问你继续继续还是返回的屏幕。点击“继续（Continue）”然后弹出 USB 驱动器。此时你需要重启系统。在启动过程中，你将通过我们的 `GRUB Loader` 看到 Kali Linux。选择 `Kali GNU/Linux` 即可启动 Kali Linux。或者，如果你只想在 Windows 环境下工作，可以选择“Windows 恢复环境（Windows Recovery Environment）”选项。

就是这些了。你只需要按照我们上面完成的一些步骤操作，就可以设置好让 Kali Linux 发行版准备就绪，并在任何需要的时候使用它。每当你重启电脑时，你都可以根据需要选择使用 Kali Linux 操作系统还是 Windows 操作系统，使得在两者之间切换变得非常简单。

# 第 4 章：网络安全导论

我们在这里需要查看的下一个主题是网络安全的概念以及它到底是什么。作为一个在黑客过程中参与操作 Kali Linux 的人员，尽可能多地了解网络安全以及你如何保护你的系统和所有你需要保护免受外部威胁的网络是非常重要的。所以，让我们直接进入主题吧。

网络安全是指保护和恢复程序、设备和网络免受黑客或其他人员可能想要入侵的任何类型网络攻击的某种或过程。这些网络攻击比以往的任何时候都更加常见。有许多黑客和其他个人想要访问大量的计算机，无论是大量的个人电脑及其信息，还是拥有大量客户数据的大型公司。

完成这些网络攻击对某些人有很多好处。如果他们成功了且没有人抓住他们或他们所做的事情，那么这真的可以帮助他们获取他们不应拥有的信息。许多黑客想通过此来破坏业务、从客户和员工那里窃取个人信息，甚至窃取金钱。某些公司可能会尝试不道德地攻击另一个竞争对手，以获取新产品和业务的信息并将其据为己有。

无论攻击的原因是什么，对黑客来说都会有一些收益，而且通常会给公司以及过程中受影响的所有其他人带来混乱。白帽黑客和其他 IT 专业人员团队的工作就是将这些网络攻击减少到最低。

这些网络攻击对消费者、员工和组织来说是不断演进的危险。它们的设计方式有助于他们访问或销毁系统中可能存在的任何敏感数据，甚至在必要时勒索金钱。当他们成功时，取决于其规模，真的可以摧毁业务并损害那些使用系统的人员的财务和个人生活。

许多公司花费大量的时间和金钱试图保护他们为客户存储的信息。每当你进行网上购物或进行其他活动时，都会留下大量的个人信息。这可能包括你的姓名、地址、电话、特征（如性别、年龄、职业等）以及你的支付信息。那么，减缓这种速度并确保不再再次发生的最佳防御是什么？基本上，一个强大的网络安全系统将具有跨越程序、网络和计算机的多层保护。但一个强大的网络安全系统不仅依赖网络防御技术，还依赖能够为网络防御做出明智选择的人。这里的好消息是，你不需要拥有网络安全专家，你不需要成为专家就能理解并实践一些网络防御战术。这一章可以是你开始这一过程的很好的起点，并为你完成一切。我们将更仔细地观察网络安全，以及我们如何利用这一点尽可能地防御这些威胁。这可能正是你需要的，帮助在这些在线威胁有机会进入你的设备或网络之前识别并避开它们。

## 网络威胁的不同类型

我们在这里首先需要查看的是不同类型的网络威胁。世界上有很多这类威胁，随着技术的变化和黑客在在线上操作的变得越来越熟练，这个问题可能会变得糟糕得多。所有企业甚至个人在系统中需要警惕的最常见网络威胁类型包括：




### 1. 社会工程学
这是一个黑客通过心理操纵他人的过程。其目标是让目标执行某些操作或泄露重要信息。

### 2. 高级持续性威胁或 APT
这类攻击的特点是，未经授权的用户能够在不被发现的情况下渗透网络，并在网络中滞留较长时间而不被检测到。

### 3. 恶意软件
这是一种软件，专门设计用于帮助黑客获取系统访问权限，或者在所有者不知情的情况下对计算机造成某些损害。

### 4. 勒索软件
这是恶意软件的一个示例。它的设计方式是通过阻止对文件或计算机系统的访问来勒索金钱，直到目标努力支付赎金为止。虽然黑客可能会拿到赎金并伪装成已经离开了了系统，但这笔付款并不能保证所有文件都能恢复，也无法保证系统会恢复到你预期的状态。事实上，黑客很可能会在计算机上留下某些东西，以便他们以后想再次再次回来。他们甚至可能拿了钱后直接消失，什么都不修复。

### 5. 钓鱼攻击
个人和企业需要注意的另一种攻击类型是钓鱼攻击。这是一个发送欺诈邮件的过程，这些邮件看起来像是来自某些信誉良好的来源。其目标是从个人处窃取一些敏感数据，包括登录信息和信用卡号。这实际上是最常见的攻击类型之一。你可以通过直接访问请求信息的网站而不是通过邮件提供信息来防止这种攻击，并配合能够过滤此类恶意邮件的技术解决方案。




实际上有几种不同类型的网络威胁可以攻击你的网络和设备，关注这些威胁以及我们如何避免它们至关重要。通常，它们会分为三类。这些包括对我们系统的**可用性**、**完整性**和**机密性**的攻击。让我们来看看如果我们不在网络和系统中提供正确的网络安全防护，可能会经历这些情况。

## 网络威胁的类型

### 针对机密性的攻击
列表上的第一个是针对机密性的攻击。这些包括任何能够窃取你的个人身份信息的攻击，例如你的信用卡信息或银行账户。许多攻击者会获取你的信息，然后在暗网上将其出售，通常供他人购买并按其意使用。

### 针对完整性的攻击
然后是针对你完整性的攻击。这些攻击由企业破坏或个人破坏行为组成，它们通常就是我们所说的“数据泄露”。网络罪犯能够访问并发布他们拥有的任何敏感信息，其目的是为了暴露这些数据，并影响公众开始停止对该公司的信任。

### 针对可用性的攻击
我们需要警惕的第三种网络威胁包括针对可用性的攻击。使用这种攻击手段的黑客的目的是让用户无法获取自己的数据，直到他们向黑客支付费用或赎金。通常，网络罪犯会努力进入网络并阻止你获取重要数据，直到你支付赎金。在某些情况下，公司可能会支付赎金以试图找回数据并消除攻击。他们这样做可能是为了避免某些必须进行的业务活动中断。然而，这并不总是能解决问题，而且通常，黑客会在系统中留下某些东西，允许他们再次回来，除非有白帽黑客或其他 IT 专业人员来并修复该问题。

## 其他威胁
正如我们之前提到的，这些是公司需要警惕的其他几种网络威胁，我们需要时刻警惕这些情况的发生。回到我们之前谈过的**社会工程**，黑客实际上能够说服或操纵某人放弃他们的个人信息。正如我们提到的，社会工程是针对机密性的攻击类型。它是黑客被操纵执行黑客想要的操作或交出其信息的过程。通常，这会包括带有欺骗性电子邮件的钓鱼攻击。例如，邮件可能看起来像是来自目标的银行，要求他们检查账户中的信息。用户会点击它，提供用户名和密码，然后黑客就可以随时他们想要访问这些信息。

回到我们之前谈过的 `APTs`（或高级持续性威胁），我们可以看到一种针对完整性的攻击。基本上，通过这种方式，未经授权的用户可以在无人察觉的情况下进入目标网络，然后他们可以在目标网络上停留很长时间。不过，这种攻击的核心点（尽管可能需要一些时间）是在不不对网络造成损害的情况下窃取数据，至少目前是这样。这些攻击最可能发生在拥有大量价值信息的公司和行业。例如，我们可能会在金融业、制造业和国防领域看到这种现象。

然后我们可以回到上面简要讨论过的恶意软件概念。这基本上是恶意软件，它是针对可用性攻击的一个很好的例子。它指的是设计用于获取访问或损坏计算机的软件，而所有者完全不知道发生了什么。有许多不同类型的恶意软件需要我们注意，它们可能包括蠕虫、真正的病毒、键盘记录器和间谍软件。

## 什么是网络安全？

成功的网络安全方法将具有许多不同的保护层，这些保护层将分布在你希望保持安全运行的所有数据、程序、网络和计算机上。在业务中，流程、技术和人员必须相互互补，以确保我们有非常有效的形式防御网络攻击。如果其中一个或多个环节出现问题或缺失了一个环节，就会导致盔甲出现裂口，并增加每个人的风险水平。

统一的威胁管理系统可以实现跨所有流程的自动化集成，并将有助于保持所有网络及其内部信息尽可能安全。但是，我们必须确保所有这些部分能够汇合，并按照我们想要的方式运行。

### 人员
首先考虑的是人。这通常是流程中最薄弱的环节。组织中的某人可能会疏忽、掉入钓鱼诈骗，或采取其他可能危及整个网络安全的行为。该网络的用户需要理解并乐意遵守业务设定的基本数据安全原则。这可以包括选择强密码、备份数据以及对电子邮件中可能出现的任何附件保持警惕。

### 流程
我们在这里需要查看的是可能出现在你网络上的某些流程。你的组织必须建立某种框架，来规定他们如何处理所有类型的攻击，包括尝试但失败的攻击，以及成功的的攻击。一个广受认可的框架能够引导网络中的每一个人。它将帮助所有人识别如何识别这些攻击、保护整个系统、检测并响应某些威胁，甚至如何从最终成功的攻击中恢复。

### 技术
最后，我们必须关注技术。如果技术不安全且没有以正确的方式进行维护（例如进行必要的更新和软件更改），那么就会为经验丰富的黑客进入系统留下大量漏洞。在为个人和组织提供他们所需的计算机安全工具以确保他们免受这些攻击时，技术是至关重要的。

你的网络中有三个主要的实体需要确保始终受到保护，以保持整个网络的安全。这些包括终端设备（如路由器、智能设备和计算机）、网络和云。通常用于帮助保护这些实体的常用技术包括许多功能，如电子邮件安全解决方案、杀病毒软件、恶意软件防护、DNS 过滤和下一代防火墙等。

这三个部分都需要结合在一起，以创建一个安全可靠的系统。当其中某一部分出现故障或没有履行其应承担的工作时，意味着其他部分都可能面临风险，并且可能有人会尝试进入你的系统并利用存在的漏洞。请记住，如果有进入你系统的方法（无论是通过人员、流程还是技术），那里就有黑客会尝试这样做。

拥有一个白帽黑客，或者如果你的公司规模较大，拥有一个由这些 IT 专业人员组成的团队来发现并防御漏洞，可以成为你整体最大的资产。这将确保你能够在黑帽黑客发现信息并利用其牟利之前，发现并解决问题。

## 为什么网络安全如此重要？

我们在这里需要查看的是为什么网络安全如此重要。在今天我们看到的互联的世界中，当我们能够推进某些网络防御计划时，每个人都能受益。我们可以将这种努力一直延伸到最高级别的协作，一直到个人层面。当我们从个人层面来看时，攻击可能会导致很多问题，包括索要钱财、身份盗用，甚至丢失一些重要数据，包括家庭照片。

除了网络安全问题可能引发个人问题外，每个人还将依赖我们现代世界中一些关键的基础设施，包括金融服务公司、医院和发电厂。能够让这些行业和企业免受攻击对于我们社会中的许多人来说是关重要的。当威胁研究人员工作时，每个人也将受益。这些研究人员的一个例子是来自 `Talos` 的 250 名威胁研究人员团队。这些个人调查黑客使用的某些新型和新兴威胁以及网络攻击策略。这个小组非常有帮助，因为他们将执行许多有助于我们所讨论的网络安全的任务。




1. 当你提供个人信息时，请确保你只与你信任的网站交互。对于这一点，一个很好的经验法则是检查 URL。如果网站开头包含 `https://`，那么我们就知道这是一个安全的站点。如果 URL 缺少那个“s”，那么避免输入任何类型的敏感信息（如你的社会安全号或信用卡数据）是非常关重要的，因为那可能是一个恶意网站。

2. 你绝不应该打开来自未知来源邮件的任何附件，也不要点击邮件中的链接。你还应该确保与你处于同一网络的人也采取了同样的操作。人们遭受攻击最常见的方式之一就是这些伪装后发送的邮件，它们看起来像是来自你非常信任的人。

3. 保持设备更新到最新版本。如果你个人或你的工作场所没有保持设备更新到最新状态，这可能会给每个人带来问题。软件更新非常重要，因为它们包含你需要的用于修复安全问题和阻止网络攻击的补丁。网络攻击者最喜欢设备过时的状态，因为对于他们来说更容易进入该网络并制造问题。

4. 确保你定期备份文件，以防止你的网络安全受到攻击。如果你受到攻击并需要擦除所有设备以防止攻击扩散到你的计算机，那么将文件存储在另一个地方会好得多，这样在你需要时就可以找回它们。

网络安全是一个不断演变的领域，这有时会让我们更难跟上并掌握我们需要处理的所有最新信息。但无论我们谈论的是公司还是个人，确保我们能够保持网络安全都是重要的，这样没有人能够进入并窃取我们的个人信息、索要钱或引起其他问题。保持信息灵通并确保和你周围的人在网上尽可能谨慎，是确保你受到保护并防止他人可能对你发起此类攻击的两种最佳方法。

# 第 5 章：恶意软件攻击

现在我们已经花了一些时间讨论了网络安全的重要性，以确保我们的网络和系统保持安全，现在是时候开始学习一些我们可以防范的不同主要恶意软件攻击类型了。无论你是试图保护自己的个人电脑，还是在为大公司保护大量数据和个人信息，这些情况都是相似的。

恶意软件攻击对许多公司来说是一个大问题，它们可能是网络安全领域最大的问题之一。即使是系统的某一部分（无论是流程、技术还是网络中的某个人）落入圈阱，也可能给整个组织带来麻烦。识别一些最常见的恶意软件攻击及其工作原理非常重要，这样我们就可以保持保护并免受所有攻击，同时确保我们的个人信息始终安全无恙。

## 网络攻击的三个类别

对于所谓的网络攻击的种种神秘色彩和未知性，它们实际上几乎都是老旧的财产和财务犯罪，只是有时加入了一些新工具。由于人们在使用互联网时可以具有假设的匿名性，很多人会被诱导犯下这些犯罪，在他们被利用之前，许多人需要保持警惕。

许多网络犯罪分子能够在你毫无察觉的情况下进出，除非你保持警惕并监控你的系统和各项运行情况。其他人可能花费太多时间吹嘘他们所做的事情，并因此陷入麻烦。但有一点是可以肯定的，由于匿名性，许多本不想尝试闯入房屋或实施任何其他犯罪的人可能会受到诱惑尝试网络犯罪，因为他们认为自己不会被发现。

对于普通用户来说，这意味着他们的系统和网络遭受的攻击比以往任何时候都多。对于那些想要学习如何保护信息的人来说，即使这些信息只是家庭照片，这可能成为一个问题。好消息是，我们有办法保护自己，我们只需要提前警惕，以免被利用。

为了帮助我们开始，我们需要查看网络伴随的一些现象以及如何防范它们。在大多数情况下，这些网络攻击将属于三个类别之一：

1. 目标和犯罪分子之间以某种方式认识。这种情况下动机因素通常是报仇或金钱，我们将寻找的许多区分特征是：犯罪者拥有或曾拥有对目标的计算机访问权限。这允许他们提前对攻击进行准备、植入一些恶意软件等。在这种类别中，我们将看到网络间谍在键盘记录器、麦克风和摄像头的帮助下发挥更多作用。

2. 第二种选择是犯罪分子与目标之间存在某种关系，或者至少犯罪分子认识受害者。他们可能在任何社交平台上建立联系，或者他们有名、富有，或者他们拥有黑客想要的东西。选择目标并不是随机的，尽管他们还没有面对面接触，也没有目标计算机的物理访问权限。在这种情况下，财务收益将是动机。

3. 受害者对犯罪分子是生的，或者只是被卷入犯罪分子钓鱼诈骗或其他类似技巧的随机人员。受害者和犯罪分子都不知道对方是谁。





## 恶意软件攻击示例

考虑到这些信息，现在是时候看看现有的的一些恶意软件`attacks`，以及我们如何警惕其中的一些。通常，这些攻击之所以有效，是因为人为失误。目标（即某个人）不会主动寻找麻烦，如果他们没有进行批判性思考，就会交出他们在这种情况下绝不会提供的信息。如果你能学会如何利用这一点来让自己处于优势并保持警惕，这将是一个好消息。

你会发现，网络犯罪分子、网络间谍和黑客将使用许多技术和向量来入侵计算机网络并窃取客户信息、知识产权、可以识别身份的敏感信息（包括社会安全号和信用卡号、健康和医疗保险记录、商业计划、个人记录、税收记录以及任何其他他们可以从中获利或利用来为自己谋利的数据）。

记住，任何人都可能成为目标。许多人认为自己完全不需要小心，但黑客甚至会盯上你。他们可以窃取你的信用卡信息、个人信息等来获取他们想要的东西，而在这种情况发生后，可能需要多年时间才能让一切恢复正常。无论目标的地点、行业或规模如何，只要黑客认为有可可图，他们就会去追求。

黑客能够采用许多不同的方法来完成工作并看到他们想要的某些结果。目标需要警惕的一些最常见的恶意软件攻击包括：

### 邮件附件

带有恶意软件和病毒附件的邮件。这是一种大多数大多数人都知道如何规避的旧技术。众所周知的是，除非我们确定认识发送者并且确定其中的信息是合法的，否则我们应该避免打开附件。尽管如此，仍然有许多人落入陷阱，这为黑客一次又一次证明了有效性。这可能是传播恶意软件最著名的方法之一，对于黑客来说，这只需要在邮件的附件中隐藏恶意软件即可。一旦目标打开附件，恶意软件就会执行或下载到计算机上。

你可以防止这种情况发生的最佳方法就是不要打开来自不安全邮件的附件。除非你正在等待某个特定人的附件，否则最好的办法通常是直接忽略此类邮件。希望你邮箱账户中的垃圾邮件检测功能会将大部分此类邮件移出你的视线，但有时会有少数邮件溜过去，保持谨慎总比在计算机上感染某些恶意软件要好得多。

### 钓鱼

我们需要警惕的第二种恶意软件攻击与上面类似，但问题不是附件，而是邮件内部的链接。这被称为`phishing`（钓鱼攻击）。通常，这些邮件看起来像是来自某个机构的合法信函，通常是你的银行，收件者很可能会信任并做出回应。

然而，黑客设计了这封邮件来跟踪目标，而链接在点击时会将目标引导到一个虚假网站，以便让目标向黑客发送敏感信息。这可能包括账户号码或银行的用户名和密码。此外，恶意网站有时可以在接收者的计算机上安装间谍软件、病毒或恶意软件，使其处理起来变得额外危险。

防止此类攻击的最好方法是对通过链接选择访问的网站要格外小心。核实邮件是否真的来自你所认为的地方。更好的是，如果是像你的银行或其他你信任的网站，请直接通过搜索访问它们，而不是点击链接。这样，无论链接是好是坏，你都保护了自己。

### 社交媒体攻击

列表上的下一个将是带有恶意网站链接的社交网络个人资料或页面。这与我们在邮件和链接中看到的类似，但得益于对社交媒体的所有炒作，这种方法正变得越来越流行。你可能使用的几乎任何社交媒体账户上都能找到它，包括`LinkedIn`、`Twitter`和`Facebook`等。

这种技术非常有效，因为许多人在使用社交媒体时不太可能提高戒备，他们对这些网站的警惕程度可能不如对其他上的某些网站。然而，通过这种方法，黑客将建立一个虚假个人资料，诱导真实用户点击那里的链接。这些链接将用户带到恶意网站。有时，虚假个人资料甚至可以获取目标提供的敏感的个人信息，以让黑客得到他们想要的。

在社交媒体上操作时务必小心。即使链接看起来来自亲密的朋友或其他人，也要先向他们核实。很多时候，虚假账户会被创建，而且它看起来和朋友或家人一模一样。如果你足够小心并在点击之前核实一切，你会发现在线上保护好自己要容易得多。

### 探测漏洞

我们仍然需要留意的另一种攻击是探测探测防火墙、`DSs`和`PSs`的弱点，包括后门。这是黑客在幕后做的事情。目标通常不需要点击任何内容就能让这种情况发生，但如果他们使用某些应用程序和网站，或者他们没有在计算机上开启正确的保护，就可能为黑客进入留下漏洞。

对于这种攻击，黑客只是会发送传输（通常是大批量发送），希望能够破解任何类型的防火墙或其他他们遇到的其他东西。这里的希望是他们能够获得他们想要的计算机和系统的访问权限。这种方法对黑客来说就像是一个游戏，黑客经常会发送数百万次传输，在此过程中捕捉几台拥有未打补丁、配置错误的计算机。我们防止此类攻击的最佳方法是确保你的系统尽可能保持更新。如果你能保持系统更新，并对安装在系统上的软件类型保持小心，就会发现一些效果。

### 预装恶意软件

黑客也可能选择在合法流中插入一些恶意数据包以进入，在没有数据包捕获的情况下，很难追踪。我们可能还会看到预装恶意软件可能是一个问题。在过去的几年里，有许多关于外国制造的 IT 设备的报告，包括交换机、路由器和计算机。这些部分已经预装了恶意软件。事实上，这是一个如此广泛的问题，以至于在 2012 年，`Microsoft`宣布发现销售的新计算机中已经存在预装的恶意软件。`HP`在同年晚些时候也公开宣布，他们去年发送的一些交换机上带有带有恶意软件的闪存。这意味着我们需要对经常使用的计算机和程序非常小心。这些程序如果没有从信誉良好的来源购买（通常当它们来自其他国家时），可能会使我们的信息和安全面临风险。双检查产品来源以及该地区可能出现的问题，可以确保我们尽可能获得最安全的程序、计算机及其部件。

## 恶意软件

这里可能出现的另一个问题是作为合法类型软件出售的恶意软件。从没有名字的卖家那里购买恶意软件也会带来一些危险。尽管软件在某些情况下能够提供承诺的功能，但其中物中也可能包含了一些恶意软件。例如，虚假的防病毒软件多年来已经感染了数百万台计算机。同样，从`间谍软件`到`木马`的任何东西都可以被添加到你的计算机中，如果恶意软件被允许在那里。`IPCopper`在 2013 年发现，至少有一些通过互联网获取的免费软件，包括音频和视频播放器以及恶意可执行文件。

为了避免这种问题，我们需要对通过链接选择访问的网站格外小心。核实邮件是否真的来自你所认为的地方。例如，当从互联网下载某些东西时，确保检查它是否是合法的，以及随之而来的恶意扩展。

## 高持续性威胁 (APT)

我们需要在这里查看的最后一种恶意威胁是 APT 或高持续性威胁。该术语并不意味着某种特定的技术或攻击类型。相反，它指的是一种持续且多方面的努力，以入侵机构或组织的数据。考虑到这些信息，现在是时候看看现有的的一些恶意`attacks`，以及我们如何警惕其中的一些。通常，这些攻击之所以有效，是因为人为失误。目标（即某个人）不会主动寻找麻烦，就会交出他们在这种情况下绝不会提供的信息，如果他们没有进行批判性思考。如果你能学会如何利用这一点来让自己处于优势并保持警惕，这将是一个好消息。





### 恶意软件类型

1. **病毒 (Virus)**：正如其名，这些病毒能够将自己附加到某些健康文件中，然后感染其他健康文件。它们具有不受控传播的潜力，可能会破坏系统的核心功能，甚至删除或损坏文件。这些病毒通常以可执行文件的形式出现。

2. **木马 (Trojans)**：这种恶意软件可以伪装成合法的软件类型，或者隐藏在被黑客篡改过的合法软件内部。它的行为方式更为隐蔽，并可以在你的安全系统中创建后门，在此过程中有效地让其他类型的恶意软件入侵。

3. **间谍软件 (Spyware)**：这是一种专门设计用于监视你的恶意软件。它可以隐藏在后台，然后记录你在网络上所做的一切操作和信息。这包括你的上网习惯、信用卡号和你的密码。

4. **蠕虫 (Worms)**：被称为蠕虫的恶意软件攻击能够利用网络接口感染整个设备网络（无论是本地还是跨互联网）。它会利用每一台被连续感染的机器，在途中帮助感染更多的机器。

5. **勒索软件 (Ransomware)**：这种恶意软件能够锁定你的电脑和文件，并威胁说除非你支付他们要求的赎金，否则将删除所有内容。通常，这并不能解决问题，但黑客仍然会拿到钱。

6. **广告软件 (Adware)**：虽然这并不总是恶意的，但侵略性的广告软件有时会为了向你推送更多广告而损害你系统的安全性。如果这种情况持续发生，就会为恶意软件提供一种得的入侵途径。提到这种攻击时，可以考虑一下弹窗。

7. **僵尸网络 (Botnets)**：最后，我们要处理的是被称为僵尸网络的恶意软件攻击。这些是由已经被感染的计算机组成的网络，它们根据黑客希望它们完成的任务协同工作。




某些类型的恶意软件比其他类型更容易检测。一些像 `adware`（广告软件）和 `ransomware`（勒索软件）会立即暴露自己，要么通过加密你的文件，要么向你推送无止尽的广告。你可以立即检测到它们，并采取必要措施帮助它们从系统中移除，防止进一步问题的发生。

还有其他选择，比如 `spyware`（间谍软件）和 `Trojans`（木马），它们会尽可能长时间地躲避你，因为这些工具被黑客用于在系统中停留很长的时间。这意味着它们会在系统中存在几天、几周，甚至几个月，而你完全不知道它们的存在。

然后是第三类。这些可能包括 `worms`（蠕虫）和 `viruses`（病毒）等选项，它们能够秘密运行并工作一段时间，然后它们存在的迹象以及造成的感染才会开始出现。在这种情况下，我们可能会看到如系统冻结、文件被删除或替换、系统突然关闭或处理器异常活跃等问题。

在恶意软件感染我们的电脑或移动设备之前检测到所有此类软件的唯一可靠方法是安装反恶意软件软件，该软件配备了检测工具和扫描功能，能够捕获设备上存在的任何恶意软件，并阻止任何试图感染你的恶意软件。你遇到的每种恶意软件都有其独特的破坏数据和感染电脑的方式，这意味着每种软件都需要不同的移除方法。无论你使用什么种电脑或操作系统，使用反恶意软件软件都能帮助阻御其中一些攻击。

### 网络钓鱼

有时，黑客会使用一种被称为 `phishing`（网络钓鱼）的技术。这是一种网络犯罪，黑客通过伪装成合法机构，利用短信、电话或电子邮件联系目标人物，以诱导个人提供敏感数据，如银行和信用卡详情、个人信息以及供黑客使用的密码。黑客这样做是为了尽可能从目标处获取更多信息。他们希望目标人物在不留意的情况下交出这些信息，然后黑客就可以根据提供的信息访问他们想要的任何网站或另一个账户。

当我们查看网络钓鱼邮件时，会发现一些常见的特征：

*   首先，邮件中的优惠优 true 得令人难以置信。你可能会发现这类文本或邮件会提供丰厚的奖励和许多引人注目的陈述。这些设计初衷就是为了立即吸引目标的注意力。这可能非常简单，比如说只要你 `Click Here!`（点击此处！）就能赢得大奖！确保如果你收到任何此类类型的邮件，千万不要点击它。如果某件事看起来好得不真实，那么极有可能，它真的如此。
*   这类攻击需要注意的另一点是内部提供的一种紧迫感。许多网络犯罪分子喜欢使用的战术之一是要求目标快速行动，因为优惠时间有限。通常，这类攻击只给你几分钟时间响应。最好的办法通常是直接忽略它们，甚至不要打开。记住，信誉良好的公司绝不会催促你。例如，如果有人要因为你长时间没有使用账户而关闭你的账户，他们会给你大约一个月的时间去检查并决定是否要保留它。如果邮件说你必须立即采取，那么这就是你正面临网络钓鱼尝试的信号。千万不要提供此类信息，因为你恰恰给了黑客他们想要的东西，这可能真的在财务及其他方面毁了你。
*   超链接应该是另一个需要你警惕的红旗。链接并不总是它看起来的那个，如果我们对使用的链接不小心，它可能会把我们带到我们不想去的地方。悬停在链接上是查看如果我们点击它，实际 `URL` 将带我们去向何处的好方法。在这类问题上，我们总是想要双重检查。黑客擅长利用一个知名网站并对其进行细微修改，导致我们认为该网站是安全的。但如果我们仔细观察，就会发现有些不对劲，这并不是我们想要访问的网站。例如，黑客可以获取美国银行（Bank of America）的网站，并将其中一个字母改为 `r` 或 `n` 以混淆视听，然后将我们重定向到一个不安全的网站。如果你不确定该网站是否正确，最好的方法总是自行检查。输入你认为发送邮件给你的公司名称，直接进入他们的官方网站，而不是点击链接。如果他们确实因某事联系你，你将通过这种方式发现；如果没有，你就避开了一次黑客的攻击。

我们还需要注意随邮件收入的任何附件。如果你在邮件中看到一个并非预期收到的附件，或者该附件出现在邮件中并不合常理，那么千万不要打开它！这些附件将包含黑客的许多工具，如 `viruses`（病毒）和 `ransomware`（勒索软件），下载它们真的会给你的电脑带来混乱。唯一始终安全点击的文件是 `.txt` 文件，或者你原本确实在等待某人的附件。

我们在警惕网络钓鱼时最后需要考虑的一点是发送者。如果发送者不寻常，那么这至少提醒我们要仔细观察发生了什么。无论它看起来是来自你不认识的人还是你认识的人，只要你浏览邮件觉得某些地方不符合习惯、出意之外、反常或令你怀疑，最好完全不要点击。关于这一点请记住，在大多数情况下，这些网络犯罪分子发送的邮件会经过伪装，看起来像是是由目标或接收者正在使用的业务发送的。银行和其他公司不会通过电子邮件向你索要个人信息，也不会在你未规定时间内更新个人详情的情况下暂停账户。相反，他们会在邮件中提供个人详情和账号，帮助你确认其来自可靠来源。

### 中间攻击

我们将看到的下一种攻击是 `man in the middle`（中间人攻击）。黑客可以此插在双方之间。通常，当 `client`（客户端）和 `server`（服务器）之间进行通信时，攻击者能够拦截、发送和接收双方的数据，包括 `passwords`（密码）和账户号码等。

现在，这里可能会发生几种情况。有时，发生 `man in the middle` 攻击只是为了让黑客获取一些信息。他们可能会收集数据，查看，然后将其原路发送。这允许他们留存一段时间，在进行更多攻击之前更深入地了解该系统。此外，黑客还可能获取这些信息并用于自己的需求，如 `username`（用户名）和 `passwords`（密码），或者他们可以修改信息后再发送出去。

例如，发送者可能会告知，某项特定交易的接收银行账户应为 `123456789`。但使用 `man in the middle` 攻击的黑客可能会拦截该信息并更改账户号码。银行随后收到该号码，由于他们没有意识到这里有问题，他们会将钱汇入黑客指定的账户，而不是用户实际想要的账户。而且通常情况下，这要等到太晚时才被发现。

还有许多其他属于这一类的攻击。`man in the middle` 攻击基本上是 `session hijacking`（会话劫持）。`session`（会话）是 `user`（用户）和 `服务器` 在特定时间段内的活动期间。例如，每当你访问自己的银行账户并与其进行交互时，这就是会话。当你登出账户时，意味着会话结束。当然，实际上还有许多其他类型的攻击会利用 `session hijacking`，类似于我们在 `man in the middle` 攻击中看到的这些，这些可能包括以下内容：




### 1. 嗅探 (Sniffing)
这将涉及黑客使用软件来拦截发送或接收你正在使用的设备的数据。

### 2. 会话劫持 (Sidejacking)
这种攻击是通过嗅探客户端与服务器之间传输的数据包，从而窃取会话 Cookie（session cookies），并获取会话访问。这些 Cookie 对黑客来说非常重要，因为它们包含一些未加密的登录信息，无论该网站本身是否安全。

### 3. 恶性终端 (Evil twin)
有时，黑客会将这一过程进一步，创建一个看似合法的伪造无线网络。不知情的用户会加入该网络，并使用它进行常规在线活动，而没有意识到在此期间，他们的信息正在被收集。这通常会让中间人攻击（man-in-the-middle attacks）更容易发生。




我们可以采取一些措施来确保这种中间人攻击不太可能在我们身上发生。在客户端，我们能够针对这种攻击采取的防御手段并不多。大多数发生在服务器端的保护措施将以服务器与客户端之间强加密协议的形式存在。例如，服务器可以通过展示数字证书来验证自己的身份，这本质上是一种验证，允许客户端和服务器建立用于交换数据的专用加密通道。但只有当服务器最初部署了此类加密措施时，这种方法才有效。从客户端的角度来看，我们能够采用的最佳策略是确保从不连接到开放的无线路由器，或者确保我们使用了如 HTTPS 之类的浏览器插件。

## 拒绝服务攻击
黑客能够使用的另一种攻击被称为拒绝服务攻击，或 `DoS` 攻击。这是一种针对网站、在线资源和网络实施的蓄意网络攻击，目的是限制合法用户对这些资源的访问。这种攻击具有很高的知名度，且其持续时间取决于黑客的意愿。有时，在他们进入并获取所需信息后，这种攻击只需要几小时；而在另一些时候，它可能会持续几个月。例如，目前网上非常流行的一种 `DoS` 攻击被称为 `DDoS` 攻击，即分布式拒绝服务攻击。

`DoS` 攻击正在增加，因为许多消费者和企业正在使用更多的数字平台来相互交易和通信。这些网络攻击将针对数字知识产权和基础设施。通常，这些攻击的目的是为了窃系统中的某些个人身份识别信息，这会对该企业的财务状况和声誉造成相当损害。例如，数据泄露会在同一时期攻击某家公司或一组公司。尽管公司预先部署了高安全性协议，但如果其供应链中的某个成员没有采取适当的安全措施，仍然可能面临攻击。

当黑客为了这种攻击选择了多一个公司作为目标时，，实施者能够利用 `DoS` 攻击进入系统，并在此之前制造更多麻烦。在 `DoS` 攻击中，黑客通常只使用一个设备和一条互联网连接来向目标发送快速且持续的请求。这样做的目的是使服务器的带宽过载并导致其崩溃。

此类攻击的黑客会尝试利用软件的漏洞，如果可以的话，他们将转而耗尽服务器的 `RAM` 或 `CPU`。这种攻击造成的损害可以通过防火墙以及允许和拒绝规则迅速地修复，但需要一些时间。由于这种攻击在黑客端仅涉及一个 IP 地址，如果你能让防火墙发挥作用，那么停止 `DoS` 攻击就会更容易。然而，某些此类攻击可能稍难检测和停止，这被称为分布式拒绝服务攻击，或 `DDoS`。

当我们观察 `DDoS` 攻击时，意味着黑客正在利用多个连接，这些连接通常遍布全球并已转化为僵尸网络。由于服务器受到了许多地方的攻击，而不仅仅是一个地方，这将导致过载。`DDoS` 攻击会同时击中。与其他一些为了窃取敏感信息而发起的网络攻击不同，`DDoS` 攻击的目的是让合法用户无法访问网站。然而，有时这些攻击也可以被用作一种数字供应链攻击。如果黑客无法渗透并突破其他网站的安全系统，他们会选择攻击该链接而不是单独行动。当该链接被破解后，主要目标将自动受到影响。

## 零日漏洞
我们将观察的最后一种攻击被称为零日利用（`zero-day exploit`）或零日漏洞（zero-day vulnerability）。这是软件安全中出现的一种漏洞，软件供应商已知该漏洞，但在当时还没有相应的补丁来修复该缺陷。这意味着对于网络犯罪来说，它具有利用并制造混乱的可能。在网络安全领域，这些漏洞是在我们的程序或操作系统中发现的无意缺陷。这些可能是由于计算机或安全配置不当导致的，有时它们仅仅是编程错误。如果不进行处理，这些将导致安全上出现漏洞，网络犯罪分子将乐意利用它们。

对于使用该程序或操作系统的用户来说，这些将构成重大的安全风险。黑客会编写一些旨在针对特定弱点的代码。然后他们可以将其封装成被称为 `零日利用` 的恶意软件。在这里设计的恶意软件旨在尽可能地利用该漏洞，以破坏计算机系统或引起其他非预期的行为。在大多数情况下，如果公司能够为该漏洞制作补丁，攻击就会被停止。

但我们必须担心，如果你的电脑是被感染的选项之一，会发生什么呢？这种恶意软件能够窃取你的数据，允许黑客随心所欲地控制系统。你电脑上的软件有时也可以以最初预期之外的方式使用，例如安装其他损坏文件的恶意软件，或访问你的联系人列表向账户中的任何人发送垃圾邮件。它还可能安装某些从计算机中窃取敏感信息的间谍软件。基本上，如果黑客在补丁设计之前利用了这些漏洞之一，他们就可以在你的系统上随心所欲。

`零日`（zero-day）一术指的是软件中新发现的漏洞。由于开发者已经获知该缺陷，这也意味着官方补丁或修复问题的更新还没有时间发布。因此，`零日`的概念是指开发者对于刚刚暴露的问题没有“零天”的时间来修复，而黑客已经在利用它了。一旦公众获知该漏洞，供应商的任务就是尽快修复此问题并确保用户受到保护。

请记住，由于漏洞已经被发现，软件供应商可能在黑客利用该安全漏洞之前发布补丁。这使其变成了一种`零日攻击`，该软件的许多用户可能面临风险。你在这里能做的最好的事情是确保自己免受这些`零日漏洞`的侵害。这些可能会带来重大的安全风险，使你受到许多事情的影响，包括对个人数据和个人信息的损害。

为了确保你的数据和电脑安全，最好采取反应性和主主动性的安全措施。你可以依靠的第一道防线是采取主动，随时尽可能使用全面的安全软件。这有助于确保你始终受到已已和未知威胁的保护。第二道防线被称为反应性，即当制造商提供新软件的新更新时，我们立即安装。这有助于我们减少受到恶意软件感染的风险。正确的软件更新将帮助我们为操作系统或软件安装所有必要的修订。这些可能包括添加一些新功能、移除任何过时的功能、更新驱动程序、为系统的某些漏洞提供修复程序，甚至修复我们发现的某些安全漏洞。然而，我们还可以采取其他几个步骤来确保我们不会落入这些零日攻击的圈套。这些步骤包括：





1. 尽可能保持你的安全补丁和所有软件均为最新版本。你可以通过下载软件版本和更新来实现这一点。当安全补丁发布时及时添加，将有助于修复旧版本软件可能曾经遗漏的任何漏洞。
2. 在任何上网时，都建立一些安全且有效的个人在线安全习惯。
3. 为你的操作系统、安全软件和网络浏览器配置安全设置。
4. 确保你安装了面面且主动的安全软件，这将帮助我们阻止你系统上已知和未知的威胁及漏洞。

正如我们在这里看到的，当黑客准备上线并尝试获取你的个人信息时，或者当他们想要劫持你的系统和网络以获取个人利益时，他们的武器库里有很多工具。识别出其中的一些攻击，并考虑你可以采取哪些步骤来避免这些攻击并保持你的数据和个人信息安全，将对你获得的结果产生巨大影响。

# 第 7 章：如何扫描服务器和网络

在这里，我们需要花一些时间研究如何扫描我们的服务器以及我们所在的网络。这看起来像是在浪费时间，难道我们不应该已经知道网络上所有的端口、系统和设备吗？但令人惊讶的是，许多专业人士并不知道自己的网络上到底有什么。即使你知道，这也意味着你可以花时间确保系统中没有未经授权的用户，并且如果他们在那儿，你有机会将他们踢出去。让我们来看看可以采取哪些步骤来帮助我们扫描服务器和网络，并确保一切都如预期般安全无恙：

### 起步

我们需要确保花时间检查我们的系统，并像黑客一样思考。他们最可能从哪里进入网络并试图制造麻烦？如果黑客想要获取某些信息，他们最感兴趣收集的是哪些信息？当你准备开始自己的自己的网络扫描时，你可以回答以下其他问题来帮助引导你的活动：

*   如果有人尝试对系统进行攻击，哪部分会造成最大的麻烦，或者如果你丢失了某部分信息，哪部分会变得非常难以处理？
*   如果发生系统攻击，系统的哪部分最脆弱；因此，这也是黑客最可能利用的部分。
*   系统中是否存在某些文档记录得不详尽或很少被检查的部分？是否存在是在那里但你不熟悉（或者你以前从未见过）的部分？

在回答了这些问题并对你希望如何进行这个过程有了良好的思路，并且列出一份你最感兴趣运行的一些应用程序和系统后，是时候按照步骤操作以确保系统的所有部分都得到了覆盖了。我们希望在计算机内部的所有部分运行这些测试，双重检查一切都是安全的。我们需要记住的这个过程中的不同部分包括：

*   你的路由器和交换机
*   连接到系统的任何设备。这包括平板电脑、工作站和笔记本电脑等。
*   所有的操作系统，包括服务器端和客户端。
*   Web 服务器、应用程序和数据库。
*   确保防火墙都已就位。
*   电子邮件、文件和打印服务器。

在此过程中你将运行许多不同的测试，这将确保你检查系统上的每一个地方，并发现存在的漏洞。需要检查的设备和系统越多，组织项目所需的时间就越。你可以对列表进行一些更改，只选择你认为最重要的选项，以节省时间并保持你的系统安全。

### 别人能通过我的系统看到什么？

在整个整个过程中，我们需要考虑的其中一点是，当他们查看公司时能看到什么。希望此时你的安全措施已经做得很好，他们只会看到一些基础内容，比如你的网站和要求的财务信息。但你想确保你的系统或网络上没有其他可以让他人轻松访问的内容。

任何试图进入你系统的黑客都会花时间研究你的网络和系统，查看漏洞可能在哪里。如果你是这个系统的所有者，你可能会错过其中一些较明显的部分，因此用全新的视角来看这些内容是非常关重要的。当我们想要收集自己网络的信息时，可以使用一些选项，但首要地方是在线搜索。

要做到这一点，我们只需要对该业务或个人进行在线搜索，看看那里有什么与我们相关的信息。然后你可以完成探测，找出别人通过你的系统能看到什么。有时，本地端口扫描器也能帮助。记住，这种互联网搜索不必那么复杂，但你可以深入并实际查看，以免你……漏掉通过你的计算机发送到世界上的某些。你需要关注的系统发现内容包括：

*   任何可以让别人看到与该业务关联的联系信息。一些检查的好地方包括 `USSearch`、`ZabaSearch` 和 `ChoicePoint`。
*   查看任何谈论公司重大变化的新稿。
*   公司发生的任何收购或合并。
*   可用的 SEC 文件。
*   公司拥有的任何专利或商标。
*   通常位于 `SEC` 的注册文件，但在某些情况下，它们也可能在其他地方。





这些需要查找的信息有很多，但对于黑客来说可能非常有价值，而且你能够确定外部到底有多少信息可供黑客使用。仅靠关键词搜索是不够的；你得进入更深层次，进行一些高级搜索才能找到这些信息。花时间写下其中的一些信息，这样你就能更好地了解网络规模有多大、哪些信息被公开给了公众，以及可能损害你网络的其他漏洞。

## 如何绘制网络地图

一旦我们完成了之前所有的信息收集，并可以开始一些研究，就是时候启动真正的道德黑客攻击流程了。你的系统或网络将包含大量信息和设备，我们需要确保它是受到保护的，即使系统中有大量用户也是如此。设备必须是安全的，而且所有员工必须遵守更高的标准，以确保他们不会不当当地使用网络和任何设备。

对于这一点，我们需要能够创建一张由我们控制的网络地图。之所以这样做是为了查看网络中包含了哪些内容，并更清楚地（通常以视觉形式）看到系统中的问题可能出现在哪里。这对于我们观察网络或系统在网络上留下了哪些供他人（包括黑客）查看并为了自己的需求而利用的足迹也是很好的方法。

`Whois` 选项是一个帮助我们入门的良好起点。这实际上最初设计用于帮助我们判断域名是否可以使用的网站，但如果你想查看任何域名的注册信息，它也是一个极佳的起点。如果你在这里进行搜索，并发现你自己的域名出现了，这说明关于你和公司的个人信息（包括运营公司的人员姓名和电子邮件地址）至少通过这个网站被广播了，即使在其他地方没有如此。

`Whois` 能够提供有关特定域名上发现的所有 DNS 服务器的信息，以及关于服务提供商使用的技术支持的一些信息。你真正需要查看的地方是 `DNSstuf`，在那里你就可以发现许多关于你域名的信息，包括：

* 关于主机如何处理该特定名称的所有电子邮件的信息。
* 所有主机位于何处。
* 关于域名注册的某些对黑客可能有用的通用信息。
* 关于该域名是否带有垃圾邮件主机的信息。

这只是你可以访问的以查找其中一些信息的网站之一，检查几个这样的网站是一个好主意。这有助于对你的域名和公司可能在网络上公开的信息有一个良好的开端，但还有其他几个你应该检查的地方，包括：除了使用上述 `Whois` 选项外，还可以查看 Google 论坛和小组以及其他类似的选项。这些对黑客来说非常有帮助，因为在这些论坛及其他地方，会有大量关于你的业务或网络的信息被发布，尽管你并不是那个发布这些信息的人。

取决于其他人在这里发布给他人查看的信息类型，可能会出现一些你需要关注并进一步了解的安全问题。有时，如果黑客已经进入了你的网络并想要将信息卖给他人，你的 `IP address`、域名和用户名等可能会出现在该网站上。对你自己的域名或公司名称进行简单搜索，通常足以判断该网站上是否存在任何安全问题。这方面的好消息是，如果你在这些论坛之一发现你的安全信息在在那里，你可以在更多人发现并利用它来牟利之前进行处理并删除该信息。你必须通过正确的凭据证明域名或业务归你所有，但如果你正在进行这种扫描，这不应该是一个问题。然后你可以进入这些网站的支持人员区域，提交你自己的报告，以尽快删除那些信息。

## 完成扫描

当我们执行上述列出的某些步骤时，我们必须记住，这些步骤的主要目标是找出我们的系统或网络已经有多少在网络上公开了，以便更好地了解黑客可能从哪里查看以开始他们自己的攻击。当然，这不是一个容易的过程，可能需要一些时间才能完成。黑客不会轻易放弃，他们决心要进入系统。你的工作是捕获他们，并在他们行动之前发现漏洞，以阻止他们可能尝试的任何混乱。

现在我们已经过了一些其他步骤并获取了必要的信息，我们作为道德黑客是时候再多完成几个步骤了，以确保网络被封闭并且漏洞得到处理。我们可以通过预先对整个网络进行扫描来完成这一切。这些扫描是有用的，因为它们会向我们展示系统中的一些漏洞，这使得我们在想要保护网络时更容易知道从何处开始。道德黑客可以考虑的几种为了保持信息安全的不同扫描包括以下：

1. 像我们上面讨论的那样访问 `Whois`，然后查看主机名和 `IP addresses`。查看它们在这个网站上的布局，你也可以花时间核实上面的信息。

## 要使用的防火墙类型

我们接下来需要看的是这里不同的防火墙类型。有很多选项，但我们重点关注的三种基本类型被称为：

- **数据包过滤（无状态）**：这些防火墙的工作原理是因为它们可以孤立地检查数据包。由于这个，它们感知连接状态，并根据收到的数据包头部来拒绝或允许数据包，无论数据包的来源如何。
- **状态检测（有状态）**：这些与之不同，因为它们可以显示我们的连接状态，这比我们在无状态防火墙中看到的更有灵活性。这些防火墙通过收集相关数据包工作，直到确定连接状态。然后当它弄清楚这一点时，就可以将防火墙的所有规则应用于此类流量。
- **应用（基于代理）**：这些防火墙将我们在旅程中更进一步，通过分析我们看到的传输的任何数据。这允许我们根据网络流量与针对特定应用程序或服务的防火墙规则进行匹配。这些也被称为基于代理的防火墙。

## 防火墙规则

正如我们在上面提到的，网络上到达防火墙的流量将与防火墙的一些规则进行匹配，以确定该流量是否可以通过。解释这些规则看起来是什么样的的一种简单方法是展示几个示例，我们将在下面这样做。对于第一个，假设我们有一台服务器有一组适用于所有进入流量的规则列表。我们可能拥有的规则示例包括：





1. 它可以接受公共网络接口上端口 `80` 和 `443` 的新建和已建立的入站流量。这些将包括 `HTTPS` 和 `HTTP` 网页流量。

2. 它可以丢弃所有来自办公室非技术员工任何 IP 地址的入站流量，这可以通过 `22` 端口或 `SSH` 端口来实现。

3. 它可以接受从办公室 IP 段到私有接口网络端口 `22` 或 `SSH` 端口的所有新建和已建立的流量。

注意，所有这些规则的第一个单词将与 `accept`（接受）、`reject`（拒绝）或 `drop`（丢弃）相关。这将指定我们希望防火墙在事件发生时执行的操作。当某种流量发生并匹配其中一条规则时，防火墙就会知道它需要做什么。例如，当我们设置一条 `Accept` 规则时，意味着防火墙需要允许流量通过。当我们设置 `Reject` 规则时，意味着防火墙将拦截流量，但会向该流量返回一个关于无法访问的错误回复。而当我们使用 `Drop` 规则时，意味着防火墙需要拦截流量而不发送任何回复。每条规则的其余部分将负责包含每个数据包进行匹配的条件。事实证明，网络流量将按照你在防火墙中以链或顺序从第一条到最后一条设置的规则列表进行匹配。更具体地说，一旦在此过程中匹配了某条规则，相关的操作将应用于尝试通过的网络流量，然后防火墙将根据你为其设置的各种规则，决定是否允许信息或流量通过。

当我们看一个用例时，如果我们有一个财务员工尝试与我们的服务器建立 `SSH` 连接，那么防火墙将因为我们有的第二条规则而拒绝他们。由于第二条规则能够拒绝它，该连接或流量将完全不会通过检查。但系统管理员将被接受，因为他们只会匹配第三条规则。这里需要记住的一是，典型的防火墙规则链无法涵盖所有可能的情况。随着时间的推移，会发生许多不同的变化，而且你的防火墙必须处理的结果通常也是不断变化的。由于由于原因，你防火墙中的链必须有一个从开始指定的默认策略，该策略仅由单一操作组成。假设你设置了一个防火墙，对于上述示例链，其默认策略设置为丢弃流量。那么，如果有任何计算机尝试进入你的办公室并与服务器建立 `SSH` 连接，但该计算机位于你的办公室之外，那么流量将被丢弃。那台外部计算机将不会匹配上述三条规则中的任何一条，因此它会被立即丢弃。

现在，我们也可以选择将默认策略设置为 `Accept`（接受）。这意味着除了你自己的非技术员工外，任何人都可以接入连接并在服务器上的任何开放服务上建立自己的连接。这就是一个配置不当的防火墙示例，因为它只会挡住你的部分员工，而其他任何想进入那里的人（即使是黑客）都可以轻松地找到进入服务器的方法。

## 监控入站和出站流量

作为网络流量，当我们从服务器的角度来看时，它可以是入站或出站的，防火墙将维护一套针对这两种情况不同的规则。来自其他地方的流量（入站流量）其处理方式与你的服务器或系统发送出去的出站流量不同。发送你自己的信息是没有危险的。当有新内容进入系统时，你可能会面临危险，因此防火墙将以不同的方式处理这些每一项。服务器允许你尝试发送到其他位置的大部分出站流量是非常常见的，主要因为它倾向于认为自己是可靠的。尽管如此，我们仍然希望确保设置一些出站规则，以便在服务器被恶意执行文件或攻击者以此类入侵的情况下，防止意外的通信。为了帮助我们通过防火墙最大限度地获得安全收益，我们需要识别你希望其他系统与你交互的所有方式。创建显式允许这些交互的规则，然后丢弃所有其他流量。这一点我们必须记住，必须设置某些适当的出站规则，以确保服务器能够允许向入站连接发送任何出站确认。

这里需要记住的另一点是，由于服务器通常会出于许多原因发起自己的出站流量（包括下载更新或连接回数据库），因此将这些情况也包含在站规则集中是重要的。从这里开始，我们可以编写一些自己的出站规则。假设我们要设置一个丢弃出站流量的防火墙，并且这是默认设置。这意味着，如果没有正确的出站规则，入站接受规则将是毫无用处的。





请注意，对于这种情况，我们不需要也不需要为需要丢弃的入站流量编写规则（这是上一节中的规则 2），因为服务器不会建立甚至不会确认这种连接。在保持您的网络和系统尽可能安全方面，部署良好的防火墙将非常重要。它可以设定规则，规定哪些内容允许进入系统，以及哪些内容从一开始就必须排除在系统之外。如果没有正确的防火墙保护，任何人（包括任何黑客）都可能进入您的系统，并造成他们想要造成的混乱和破坏。请选择一个良好的防火墙，并确保您能够设置最适合您的系统以及您整体安全设求的规则。

# 第 10 章：理解密码学

在本指南中，我们将讨论的最后一个章节是密码学概念。如果我们想确保发送和接收的信对能够保持安全且不受他人干扰，那么我们需要尽可能在其中加入某种程度的密码加密。密码学是通过使用代码来保护信息和通信的方法。这样做的目的是确保只有那些预期查看消息的人最终才能读取它。

此的重点在于我们要确保信息保持机密。无论是你想发送给他人的的一封邮件，还是你想要向他人隐藏的安全信息，这种加密技术都能确保黑客以及可能进行中间人攻击等的人员排除在您的系统之外，并且不会在此过程中引发任何问题。从计算机科学的角度来看，这种密码学是指源自各种数学概念和一系列基于规则的计算的安全信息处理和通信技术。

## 密码学技术

我们需要从在向我们的系统和我们尝试发送的消息中添加密码加密时，可以使用的一些不同技术开始。密码学与密码分析（cryptanalysis）和密码学理论（cryptology）的概念密切相关。它包含了诸如微缩点（microdots）、文字与图像合并以及其他旨在帮助我们在存储或传输过程中隐藏信息的方法，以便任何没有获得授权的人都无法获取该消息。

然而，当我们审视当今世界以及其中正在发生的所有计算机和数字事务时，密码学更有可能与将明文（即普通文本）转换为密文的过程相关，这个过程被称为加密（encryption）。然后，当消息到达正确的人手中时，它将通过被称为解（decryption）的过程变回普通文本或明文。能够从事这一领域的人被称为密码学家。

现在，密码学过程涉及四个主要目标或关注点，包括以下内容：

1.  **机密性（Confidentiality）**：我们试图确保信息不会被任何非预期对象所理解。当我们处理密码学时，我们依靠代码和其他过程来确保我们的消息和信息在到达目标接收者之前是安全的。
2.  **完整性（Integrity）**：密码学关注信息在存储或传输过程中是否被篡改。这里的目标是不允许信息在发送者和预期的接收消息的人之间的这两个过程中发生任何篡改，如果真的发生了这种篡改，会被立即检测到。
3.  **不可否认性（Non-repudiation）**：这意味着信息的创建者或发送者在一切完成后，无法否认其在创建和传输信息时的意图。
4.  **身份验证（Authentication）**：发送方和接收方能够确认对方的身份，以及消息或信息的来源或目的地。





当我们拥有一种协议或程序能够满足上述至少部分（但最好是全部）的标准时，我们就拥有了被称为 `cryptosystem`（密码系统）的实体。这些通常被认为仅是指数学程序以及我们在计算机上制作的一些程序。然而，它们也包括对人类行为的一些规制，例如选择难以猜解的密码、在系统不使用时登出，以及不不需要这些信息的人讨论任何对业务可能敏感的程序。

# 密码学算法
由于我们正在处理密码学，因此花点时间谈谈此类过程中的某些算法是非常重要的。密码系统将使用一组程序（即算法）来帮助我们加密和解密在几个系统之间传输的消息。这里的目的是确保计算机系统之间共享的通信尽可能安全。这不仅适用于计算机系统，还适用于应用程序以及平板电脑和智能手机等设备。

`cipher suite`（密码套件）或算法，将使用一种算法来帮助我们完成过程中的加密部分，另一种算法来帮助消息身份验证，然后使用最终密钥来完成正在进行的交换。这个过程将嵌入协议中并写入运行在操作系统和网络计算机系统的软件中，需要生成两个密钥才能成功。

借此，我们必须确保生成一个 `private key`（私钥）和一个 `public key`（公钥），以完成在此过程中希望进行的所有工作。我们能够使用这两个密钥的方法包括数据解密和加密、数字签名以及消息身份验证的验证，这些都非常重要，密钥交换也是如此。

## 密码学的类型
既然我们在这里，我们需要花些时间看看现有的不同加密类型。首先，单密钥或对称密钥加密算法将为我们创建一个固定长度的位，称为 `block cipher`（分组密码）。它包含一个特殊密钥，创建者或发送者将使用它来帮助他们加密数据。然后接收者将获得该密钥并可以使用它来帮助他们解密所获得的信息。

有很多不同类型的对称密钥密码学，其中一种就是 `AES` 或 `Advanced Encryption Standard`（高级加密标准）。`AES` 之所以是因为美国国家标准与技术研究院在 2001 年建立的一项规范，作为联邦信息处理标准，用于保护任何被认为敏感的信息。该标准规定美国政府使用，私营部门的许多人也会使用它来帮助他们完成工作并保持安全。

此外，几年后的 2003 年，`AES` 被批准用于美国政府分类的信息。现在，它是一项免版税的规范，并在全球的软件和硬件中实现。这实际上是 `DES` 或 `Data Encryption Standard`（数据加密标准）的继承者，可以使用更长的密钥长度并防止暴力攻击等问题。

还有非对称或公密钥加密算法的选择。这些与之不同，因为它们使用一对密钥而不是只有一个。有一个密钥是公钥，与发送者或创建者相关，用于加密消息。还有一个 `private key`（私钥），只有原始者知道（除非黑客入侵并泄露此密钥，或者原始者决定共享信息），用于帮助他们解密信息。

许多公密钥密码学选项，包括 `RSA`，它经常用于互联网以保持安全；用于 `Bitcoin` 和其他加密货币的 `Elliptic Curve Digital Signature Algorithm`（椭圆曲线数字签名算法）；作为数字签名标准的 `Digital Signature Algorithm`（数字签名算法）；以及 `Diffie-Hellman` 密钥交换。

为了帮助确保密码学中的数据完整性，将使用 `functions`（函数），它们能够根据输入值返回确定性的输出，以帮助我们将所有数据映射到固定数据大小。这将确保您的信息能够尽可能安全完好，并让您更容易发送和接收消息，而黑客无法介入并造成混乱。

## 密码学是如何开始的？
我们接下来需要观察密码学历史以及它是如何开始的。“cryptography”（密码学）一词实际上源于希腊语单词 `kryptos`，意思是“隐藏”。它的起源可以追溯到公元前 2000 年左右的埃及象形文字。这些是复杂的象形图，其完整含义实际上只有少数人知道。

在较现代时期，密码学已变成世界上一些顶尖数学家和计算机科学家争夺最佳代码的战场。安全地存储和传输所需的任何敏感信息一直是业务中、有时也是战争的关键因素。

由于政府不希望某些实体访问收发送秘密信息的不同方法并对国家利益构成威胁，密码学在不同国家成为受到限制的大课题也并不奇怪。这可能包括对软件出口和公众使用的某些限制。

当然，现在密码学的使用方式与过去不同。很多时候，我们会在任何需要保持信息安全的交易中看到这种密码学。虽然它在政府中被大量使用，但它也会出现在我们使用的银行以及在线购物时发生的许多交易中。其点是允许我们向另一个人或企业发送个人和机密信息，而无担心有人接管并将数据用于其自身的风险。

## 对密码学的顾虑
攻击者偶尔能够绕过某些密码学。当他们做到这一点时，允许他们进入最初负责数据加密和解密的计算机。黑客一旦进入那里，就可以利用那里一些较弱的实现方式，例如使用默认密钥来帮助他们。然而，这种密码学确实会让攻击者访问消息以及任何受加密算法保护的数据变得困难。这就是为什么将此添加到系统中是如此重要。它可能无法一直挡住一切，特别是面对非常高超的黑客时。但它可以增加事情的难度，并在在此过程中为您解决许多问题。

随着量子计算处理能力能够突破某些限制，顾虑也随之增加。
