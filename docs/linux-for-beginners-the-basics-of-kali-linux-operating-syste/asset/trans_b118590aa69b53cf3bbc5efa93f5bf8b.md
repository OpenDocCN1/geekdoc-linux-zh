

要实现这些优势，需要处理器提供硬件支持。处理器必须至少支持两种模式——*特权模式*（保护模式下的内核态）和*用户模式*。这对于系统运行至关重要，包括处理无效的用户命令（如任务切换、在限制下访问内存、限制对I/O设备的访问等）。

让我们看看在与内核和应用交互时，不同的CPU模式是如何被使用的。在内核加载完成后，处理器切换至特权模式，并获得对计算机的完全控制权。每个应用程序都以用户模式启动并执行，在该模式下，应用程序无法访问内核资源或其他应用程序。当需要执行由内核实现的操作时，应用程序发起*系统调用*。内核会拦截该调用，将处理器切换到特权模式，执行相应操作，然后切换回用户模式，并将结果返回给应用程序。

系统调用比调用用户实现的函数慢，因为处理器需要在两种模式之间切换两次。对于某些操作系统，部分功能是在用户模式下实现的，因此访问这些功能无需使用系统调用。

## 操作系统架构的实现方式

考虑实现操作系统架构的几种方法。在实际的操作系统中，通常会采用这些方法的某种组合。

## 单体系统

在*单体系统*中，所有基本功能都集中在内核中。在实现单体内核时，操作系统效率更高（在组件交互过程中，处理器无需在模式之间切换），但可靠性较低（所有代码都在特权模式下执行，任何组件的错误都是致命的）。

单体内核并不意味着其所有组件都必须驻留在内存中。现代操作系统允许将代码片段（*内核模块*）动态地放置在内核地址空间中。内核模块的实现也使内核具有可扩展性（要添加新功能，只需开发并在内存中加载相应的模块即可）。

### 多层次系统

*多层次*操作系统的组件形成一个层次结构（层级），每一层都依赖于上一层的功能。最底层直接与硬件交互，最高层实现系统调用。

在传统的多层次操作系统中，从顶层到底层的控制转移是通过系统调用实现的。顶层必须拥有执行该调用的权限，这些权限由硬件支持进行验证。此类系统的一个例子是20世纪60年代开发的Multics操作系统。由于性能较差，这种方法在当今的实际应用中受到限制。

层次也可以在单体内核中隔离；在这种情况下，它们通过编程支持实现，但会导致系统实现复杂化。在单体系统中，内核确定以下层次：

- *设备抽象机制*：该层直接与硬件交互，使系统的其他组件免于直接交互
- *核心内核*：负责最基础、最简单的内核操作，例如向磁盘写入数据块。通过这些机制，高层指令在资源管理的协助下执行
- *资源管理工具*（或资源管理器）：实现操作系统的基本功能（进程管理、内存、输入/输出等）。在此级别，使用核心内核做出最重要的资源管理决策
- 系统调用接口：用于与系统软件和应用软件通信

## 微内核系统

现代操作系统的一个趋势是，在特权模式下实现一小部分内核功能，即微内核。其他操作系统功能由用户模式下的进程（服务器进程）执行。服务器负责支持文件系统和处理进程内存。

微内核在系统组件之间进行通信，并执行基本的资源分配。要执行系统调用，进程（客户进程）访问微内核。微内核将请求发送给服务器，服务器执行工作并发送响应回来。微内核将响应转发给客户。客户不仅是单一用户，也可以是其他操作单元。

微内核方法的优势包括：

- 微内核体积小巧，简化了其开发和调试
- 由于服务器在用户模式下运行，且无法直接访问硬件，因此系统可靠性高
- 系统的灵活性和可扩展性更强（不必要的组件不会占用内存空间，扩展系统功能只需添加新的服务器）
- 适应网络环境的能力（服务器与相关网络之间交换数据的方式，或者它们位于同一台计算机上）

微内核方法的主要缺点是性能下降。在系统调用中，处理器的模式切换从两次增加到四次（两次发生在客户与微内核之间，两次发生在服务器与微内核之间）。

这个缺点在理论上较为明显，实际上，微内核的性能和可靠性主要取决于其实现的质量。例如，在QNX操作系统中，微内核仅占用几KB内存，提供最小的功能集，系统性能符合实时操作系统标准。

## 虚拟机的概念

在*虚拟机系统*中，通过编程方式创建硬件的副本（发生模拟）。这些副本（*虚拟机*）并行运行，每个都在运行与应用程序和用户交互的软件。

## 架构特性：UNIX 和 Linux

### UNIX 基本架构

UNIX是操作系统架构相当简单的一个例子。该系统的许多功能都包含在内核中，内核通过系统调用与应用程序通信。

系统有三个主要组件：进程管理子系统、文件系统和I/O子系统。*进程管理子系统*控制进程的创建和删除、系统资源在进程间的分配、进程间交互以及内存管理。

*文件子系统*为访问存储在磁盘驱动器和外围设备上的数据提供了统一的接口。这种接口是UNIX最重要的特性之一。使用相同的系统调用，既可以与磁盘通信，也可以输出到终端或打印机（程序像处理文件一样处理打印机）。在这种情况下，文件系统将请求转发到I/O子系统的相关模块，而这些模块则直接转发到外围设备。此外，文件子系统还控制文件访问权限，这在很大程度上决定了用户在系统上的权限。

I/O子系统通过与设备驱动程序交互来执行文件系统请求。在UNIX中，有两种类型的设备：字符设备（例如打印机）和块设备（例如硬盘）。它们的主要区别在于，块设备允许直接访问。为提高块设备的效率，使用缓冲区高速缓存——即存储最近从磁盘扫描的数据的内存块。后续对这些数据的访问可以从高速缓存中获取。

### Linux 架构

Linux主要由三部分组成：

- 核心：实现操作系统的基本功能（进程管理、输入/输出、内存等）
- 系统库：为应用程序定义标准函数集（执行这些函数无需切换到特权模式）
- 系统实用程序：执行专门任务的应用程序

### Linux 内核的目的及其特性

Linux实现了单体内核技术。所有内核数据和数据结构都位于同一地址空间中。内核中有几个功能组件。

- 进程调度器：负责在系统中实现多任务处理（中断处理、定时器操作、进程的创建和完成、上下文切换）
