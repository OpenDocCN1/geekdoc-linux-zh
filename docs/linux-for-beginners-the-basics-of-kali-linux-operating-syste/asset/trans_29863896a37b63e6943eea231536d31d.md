
## 结语

感谢你坚持阅读完《Linux 入门指南》的结尾部分。希望本书能为你提供有用的信息，并赋予你实现目标所需的一切工具，无论你的目标是什么。

在 Linux 中，与其他操作系统不同，默认情况下，操作 Linux 并非以图形化方式进行，而是通过手动输入命令。Linux 拥有多个负责解释用户输入的命令并执行相应操作的程序。这些被称为**shell**的程序是所有 UNIX 系统（包括 Linux）中典型的通信方式。对于许多人来说，手动输入命令可能显得令人望而生畏且困难，但正如你必然在阅读本书时所感受到的那样，Linux 命令相对简单且功能强大。

Linux 同时也是一个多任务和多用户操作系统，它能够同时运行多个程序（或任务），并同时承载多个用户。因此，所有 Linux 用户必须在系统上拥有一个用户账户，以确立其权限。Linux 将用户组织成组，以便为特定工作组、对特定文件或系统服务的访问设立权限。

最后，在安装和使用 Linux 时，还有一个基本概念，即**超级用户**或**root 用户**。该用户是系统管理员，在安装过程中创建。作为管理员，你可以访问和修改（甚至破坏）所有系统信息，因此请尽可能避免以 root 用户身份操作。我们希望你已经从本书中学到了这些以及更多知识。
