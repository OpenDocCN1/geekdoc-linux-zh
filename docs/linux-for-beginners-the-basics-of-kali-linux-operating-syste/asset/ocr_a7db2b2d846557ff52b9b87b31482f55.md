You can use the wait() system call to remove process information from Linux, but more often use the more versatile version of it - waitpid(). This call checks if the control unit of the corresponding process is in the system. If it is, and the pr/z is not in the zombie state (that is, it is still running), then the process in the case of waitpid() will go to standby. When the descendant process is completed, the ancestor exits standby and removes the descendant control unit. If the ancestor does not call waitpid() for the descendant, it may remain in the zombie state for a long time.
