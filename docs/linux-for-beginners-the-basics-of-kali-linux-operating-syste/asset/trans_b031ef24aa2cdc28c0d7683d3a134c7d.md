
## 内存管理器
- 为每个进程分配独立的地址空间，并实现虚拟内存的支持。

## 虚拟文件系统
- 提供一种通用接口，用于与各种文件系统和 I/O 设备进行交互。

## 设备驱动程序
- 提供对外围设备的直接访问。它们通过虚拟文件系统接口被访问。

## 网络接口
- 提供对网络协议实现和网络设备驱动程序的访问。

## 互操作子系统
- 提供机制，允许系统中的不同进程相互通信。

这些子系统中的某些是系统的逻辑组件；它们与内核一起加载到内存中，并永久保留在那里。其他子系统（例如设备驱动程序）的组件是这样实现的：它们的代码可以按需加载。为了实现这一点，Linux 支持内核模块的概念。

### 内核模块

Linux 内核允许按需加载和卸载代码的各个部分。这些部分被称为*内核模块*，并以特权模式运行。内核模块提供了诸多优势：

- 代码模块可以在系统启动后加载到内存中，这简化了内核组件（尤其是驱动程序）的调试。
- 它们能够在运行时改变核心组件集合；当前未使用的模块可以从内存中卸载。
- 模块是“扩展 Linux 内核功能的代码必须开源”这一规则的例外。这使得硬件制造商即使无法访问内核源代码，也能为 Linux 开发驱动程序。

Linux 模块支持包含三个组件：

- 模块管理工具使模块能够加载到内存中，并促进模块与内核其余部分之间的通信。
- 驱动程序日志记录工具允许模块向内核的另一部分报告新的驱动程序已初始化。
- 冲突解决工具允许设备驱动程序保留硬件资源，并保护它们不被其他驱动程序意外使用。

如果需要，单个模块可以注册多个驱动程序（例如，用于两种不同的访问机制）。模块可以预先加载——在系统启动时（启动模块）或当程序触发其功能时。加载后，模块代码与其他内核代码驻留在相同的地址空间中。模块错误对系统是致命的。

## 系统库的特性

Linux 系统*库*是*动态库*，仅在需要时加载到内存中。它们执行多项功能：

- 实现系统调用包装器。
- 扩展系统调用功能（此类库包括 C 语言 I/O 库，它基于系统调用实现 `printf()` 等功能）。
- 实现用户模式服务功能（排序、字符串处理等）。

## 用户应用程序

Linux 用户应用程序使用系统库中的函数，并通过系统调用与内核交互。

## 安装

与微软 Windows 不同，安装 Linux 不是一个简单的过程，因为 Linux 允许控制并定制更多参数和选项。尽管如此，开发商正在朝着使 Linux 安装成为尽可能无创伤的过程这一目标取得巨大进展，具体取决于所用特定发行版的简单程度。

在安装 Linux 之前，有必要考虑一些基本方面。首先是阅读安装 CD 中包含的信息；这些信息可以以两种不同方式呈现：作为常规 HOW-TO 指南，或以为发行版开发的手册形式。

对于该操作系统的大多数发行版，安装过程遵循的一般步骤总结如下：

### 安装过程

- **语言选择**：安装程序使我们能够用现有大量语言配置我们的系统。
- **接受许可协议**：接受拥有该发行版的公司许可协议。
- **键盘和鼠标配置**：配置我们键盘和鼠标的类型和型号。
- **安全级别选择**：有四个默认安全级别可供选择，具体取决于我们执行此安装的计算机的用途，范围从互联网客户端到需要支持大量连接的服务器。

### 分区

在安装前需要考虑的主要概念之一是分区。每个操作系统都以其自己的文件系统组织其所包含文件的信息，因此组织方式各不相同。作为参考，不同操作系统的文件系统名称各异。这通常阻止在同一个硬盘上安装多个混合操作系统。为了解决这个问题，出现了所谓的分区，通过它可以将硬盘划分为不同的文件系统。就所有实际目的而言，制作分区相当于将硬盘一分为二，当然并不是物理划分，而是逻辑划分。

安装 Linux 时的根本问题在于，在大多数情况下，用户希望保留 Windows 及其所有程序。目前有几个发行版允许在 Windows 文件系统中安装 Linux，要么在所谓的磁盘映像（一个非常大的文件）中，就像某些旧发行版那样，要么直接在 Windows 文件系统中（例如 WinLinux 2000）。然而，为了获得良好的性能，最好将 Linux 安装在与 Windows 不同的分区上，使用 Linux 自己的文件系统。通常需要对硬盘进行分区，因为 Windows 在安装时通常占据了整个硬盘的大小。

直到最近，这种划分意味着不可避免地丢失硬盘上包含的所有信息。目前，在安装 Linux 发行版时，允许在不丢失信息的情况下划分硬盘，以缩小 Windows 分区的大小，并在安装 Linux 时创建一个新的分区。在 Red Hat 或 Mandrake 的情况下，存在自动分配的可能性，如果不知道如何操作分区，这将非常有用。

对于 Linux，必须至少创建一个根原生分区。它应具有所需的大小，并且必须创建一个交换分区，其大小至少是设备 RAM 的两倍，最高不超过 512 MB。在此过程中，务必小心不要擦除驻留 Windows 的分区，否则**所有**信息都将永久丢失。

### 系统配置

- **Root 密码**：安装程序要求输入 root 或管理员密码，通过该密码可以访问系统的所有配置区域，这是普通用户无法做到的。
- **创建用户**：安装程序要求输入登录名和密码以创建第一个用户，出于安全原因，该用户不具备必要的管理员权限。
- **引导加载程序**：另一个需要考虑的要点是你希望如何引导 Linux。如果存在 Windows，最简单的方法是安装 LILO 或 GRUB，这些程序负责根据用户在启动 PC 时指定的内容引导两个操作系统。在保存引导加载程序到磁盘第一个扇区的选项中必须进行选择。如果有一个重新安装 Windows 的选项，将引发引导 Linux 的问题，因为该操作系统将接管 PC 和引导系统的控制权，移除 LILO（并阻止 Linux 引导）。另一种非常简单的方法是使用在安装 Linux 时创建的启动软盘。
- **安装退出**：用户被告知已安装的服务，安装程序完成。

Linux 首次启动后，初始向导将启动，并允许配置基本系统项，例如要使用的桌面类型（KDE、Gnome、WindowMaker 等）以及一些服务如邮件。
