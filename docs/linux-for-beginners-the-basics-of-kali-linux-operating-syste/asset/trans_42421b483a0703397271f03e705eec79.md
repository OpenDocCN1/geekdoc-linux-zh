

## UNIX 文件系统结构

每个 UNIX 文件系统都有一个由 / 表示的唯一根目录或根起点。在这个目录下，您可以找到操作系统可访问的所有文件。这些文件组织在不同的目录中，这些目录的功能和命名在所有 Unix 系统中都是标准的。

- /: 文件系统根目录
- /dev: 包含代表物理安装在该计算机上的设备的系统文件
- /etc: 此目录保留用于系统配置文件

在此目录中，不应出现二进制文件（程序）。其下应出现另外两个子目录：

- /etc/X11: X 窗口配置文件
- /etc/skel: 当创建新用户时复制到用户目录的基本配置文件
- /lib: 包含运行位于 /bin 中的程序所需的库（不是用户程序的库）
- /proc: 包含接收或向系统内核发送信息的特殊文件（建议不要修改此目录及其文件的内容）
- /sbin: 包含仅超级用户或 root 可访问的程序
- /usr: 这是系统最重要的目录之一，因为它包含所有用户共用的使用程序。其结构通常类似于以下：
  - /usr/X11R6: 包含运行 X 窗口的程序
  - /usr/bin: 通用程序，包括 C/C++ 编译器
  - /usr/doc: 通用系统文档
  - /usr/etc: 通用配置文件
  - /usr/include: C/C++ 头文件（.h）
  - /usr/info: GNU 信息文件
  - /usr/lib: 程序的通用库
  - /usr/man: 可通过 man 命令访问的手册
  - /usr/sbin: 系统管理程序
  - /usr/src: 程序的源代码

除了上述目录外，还有其他通常位于 /usr 目录中的目录，例如安装在系统中的程序所在的文件夹。

- /var: 此目录包含有关程序的临时信息（这并不意味着您可以删除其内容；事实上，不应该这样做）

## 第 1 章：操作系统的基本概念

### 操作系统的概念、目的和功能

#### 操作系统的概念

我们现代操作系统的主要思想和起点是创建 ISG 并使其纳入计算机系统使用的需求（*计算机信息系统*指的是一套硬件和软件）。最初开发的计算机信息系统旨在解决用户责任问题和实际问题。由于仅靠硬件很难做到这一点，因此创建了应用程序。这些程序需要硬件管理、硬件资源分配等通用操作。这些操作被归入一个独立的软件层，即操作系统。

此外，操作系统的能力远远超出了应用程序所需的基本操作集，但此类系统在应用程序和硬件之间的中间位置保持不变。

#### 操作系统的目的

操作系统为我们提供了许多信息系统，其次是其工作效率和可靠性。第一种功能是作为扩展机器的操作系统特征，第二种是作为硬件资源分配者的操作系统特征。

#### 作为扩展机器的操作系统

使用操作系统，应用程序程序员（以及通过其程序的用户）应该有一种正在与先进机器打交道的印象。硬件不太适合直接用于应用程序。例如，如果您考虑在相应控制器的命令级别下工作于 I/O 设备，您会发现这类命令集是有限的，对于许多设备来说甚至是原始的。操作系统隐藏了这种硬件接口，但向程序员提供了使用更高级概念（称为抽象）的应用程序编程接口。

例如，在处理磁盘时，典型的抽象是文件。与直接处理磁盘控制器（无需考虑移动驱动头、启动和停止电机等）相比，处理文件更容易，结果是，程序员可以专注于其应用程序的本质。操作系统负责与磁盘控制器交互。

抽象凸显使得在迁移到新硬件时更改操作系统和应用程序代码变得容易。例如，如果您在计算机上安装新类型的磁盘设备（前提是操作系统支持它），操作系统级别将考虑其所有功能，应用程序将继续像以前一样使用文件。系统的这种特性称为硬件独立性。可以说操作系统为运行应用程序提供了硬件独立的环境。

#### 作为资源分配者的操作系统

操作系统必须有效地分配资源。它充当这些资源的管理者，并按需向应用程序提供资源。资源分配主要有两种类型。在*空间分配*情况下，资源访问将同时服务于多个客户端，其中每个客户端都可以使用资源（共享内存）。在*时间分配*情况下，系统进行排队，并根据队列允许它们在有限时间内使用整个资源（因此在单处理器系统中分配处理器）。

在分配资源时，操作系统解决可能的冲突，防止程序未经授权访问其无权访问的资源，确保计算机系统的高效运行。

#### 现代操作系统的分类

让我们根据现代操作系统的范围来考虑其分类。首先，请注意*大型*计算机（大型机）的操作系统。为其设计的硬件的主要特征是 I/O 性能：大型计算机提供大量外设（磁盘、打印机、终端等）。这种计算机信息系统用于可靠地处理大量数据。此操作系统应有效支持此过程（在批处理模式或时间分配模式下）。此类操作系统的一个例子是 IBM 的 OS/390。

下一个类别包括*服务器*操作系统。此类操作系统的主要特征是能够处理大量对共享资源的用户请求。网络支持对它们起着重要作用。有专门的服务器操作系统排除了与其基本功能性能无关的元素（例如，对用户应用程序的支持）。通用服务器（UNIX 或 Windows XP 系统）现在更常用于实现服务器。

最庞大的类别是*个人*操作系统。此类别中的一些操作系统是微软开发的通用操作系统简化版本，考虑到用户预期（Windows 95/98/Me）。个人操作系统特别关注对图形用户界面和多媒体技术的支持。还有*实时*操作系统。在这样的系统中，必须保证每个操作在指定时间范围内完成。实时操作系统可以控制宇宙飞船飞行，处理或视频演示。有专门的实时操作系统，如 QNX 和 VxWorks。

另一个类别是*嵌入式*操作系统。包括管理各种微处理器系统的应用程序，用于军事技术、消费电子产品系统、智能卡和其他设备。此类系统提出特殊要求：放置少量内存并支持专用操作系统设备。通常，内置操作系统是为特定设备开发的；通用系统包括嵌入式 Linux 和 Windows CE。

### 操作系统的功能组件

操作系统可以被视为一组组件，每个组件负责实现系统的特定功能。让我们考虑现代操作系统最重要的功能及其实现组件。

系统由组件构建的方式及其关系由操作系统架构决定。每种操作系统在其可处理的工作类型和组织结构上都会有所不同，因此了解这些以及如何将它们整合在一起可能很重要。

### 进程和流管理

如前所述，操作系统最重要的功能之一是执行应用程序。代码和应用程序数据以特殊的可执行方式存储在磁盘上的计算机信息系统中。当用户决定运行操作系统以执行文件时，文件系统创建计算机的基本单元，即进程。您可以指定以下内容：进程是执行该程序的程序。

操作系统在进程之间分配资源。这些资源包括 CPU 时间、内存、设备、磁盘空间作为文件。对于每个进程的内存分配，承担其地址空间——一组允许访问的内存地址。进程空间存储在地址空间中。每个进程的磁盘空间分配形成类似打开文件列表。
