GQview

Thumbnails is a particularly handy feature for looking at an entire directory. Beware, though: if there are many files in the directory, it will take Gqview a few minutes to create all the thumbnails.

Other buttons will zoom the image in and out as well as “fit to screen.” There are also buttons to rescan directory and set zoom.

The menu bar across the top of the screen provides file “save” and “save as” features as well as rename, delete, move and copy. One of the most useful features is the choice to edit the image in an editor. When you have selected an image and have it displayed on the right side, click “edit” and then select which program you would like to use to edit the image. Gqview will then start the chosen program and load the image into it.
