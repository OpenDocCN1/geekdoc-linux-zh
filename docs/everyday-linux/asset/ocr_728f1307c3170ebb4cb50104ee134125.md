Formatting character is probably the operation you will do most often. Choosing this will bring up a window that will allow you to choose the font, font size, and characteristics such as underline, bold, italics, and more.

TIP
If you've already typed some text and want to make it bold type or change the font type, you can do so by selecting the text with the mouse or shift+arrow keys and then changing font, font size, colour, or font attributes (bold, italics, etc.).

When you save your document for the first time, StarWriter will use the "save as" feature. Click "file" and then "save as."
