# Preparing to Dual Boot Using Two Drives

If you're going to dual boot using two drives, you will probably have several partitions already listed. I assume in this installation that you are installing Linux on the second hard drive, which will be hdb. If there are any existing partitions on this drive, they'll be called “hdb1,” “hdb5,” and what have you. The numbers don't necessarily have to go in order, so just pay attention to the “hdb” partitions in the partition summary.

You will need to delete all of the partitions on that drive. To do so, simply click on a partition and then click on the delete button. It's pretty simple. You must be warned, however, that deleting a partition will remove all of the data on the partition, and you won't be able to get it back. To delete all of the hdb partitions, simply click on each of them and click on the delete button for each in turn. Each time you attempt to delete a partition, you will be asked to confirm your choice.

# Preparing to Dual Boot Using One Drive

If you're going to dual boot using one drive, you probably won't need to remove any partitions at all. You have a few partitions that were created when you installed your other operating system and you don't want them, you can delete them using the procedure described above. These will be named using “hda” and then a number, however.

Please remember that you cannot recover data from a partition that you've deleted, so use the delete button carefully!

# Preparing to Single Boot

You can single boot with as many drives as you'd like. The process that I describe here only removes the partitions on the first drive—if you want to make use of space on other drives, you should remove those partitions as well. Please realize that if you single boot, you're going to destroy your previous system completely and utterly. If this sounds too risky, then you should dual boot.

To single boot, that is, to boot using one operating system, you should remove all of the partitions on the first drive, that is, on the drive called “hda” by Linux. Click on each one of the partitions and then click on the delete key.
