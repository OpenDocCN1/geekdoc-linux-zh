# Everyday Linux

The Drawing view is the default and the one you generally work in when you are creating a presentation.

Outline view will show the slide as a preview and the text from all of the slides in an outline form.

![](bbox=[0.05, 0.23, 0.95, 0.63])

*Outline Form.*

You can toggle the slide preview on or off. Outline form is useful for printing out the presentation in word processor form.

Notes view will allow you to view each slide on a separate page with room beneath for adding additional notes.

This mode is very useful for speakers. You add text by simply clicking in the box beneath the slide.

Handouts mode will display several slides on a page.

You can arrange the slides any way you like and print them out to use as handouts.
