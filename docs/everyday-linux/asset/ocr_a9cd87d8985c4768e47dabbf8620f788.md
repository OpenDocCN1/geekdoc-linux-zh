# ## Overview and a Bit About Corel

Corel has been in the applications business for a long time. They are best known for their word processor, WordPerfect. A few years ago, Corel became interested in Linux and they ported their then current version of WordPerfect to run on Linux. The program, called WordPerfect 8 for Linux, was offered to users for free for personal use.

Corel is now offering additional applications for Linux such as WordPerfect Office 2000, CorelDRAW, and even Corel Linux, their own distribution of Linux based on debian Linux. We had initially planned on including all of these applications in this book. Unfortunately, Corel did not truly port their WordPerfect Office 2000 and CorelDRAW to Linux, but instead have the applications running on a Windows emulator. This has resulted in some stability issues that will likely be worked out in a timely manner. We were very impressed with what we saw in these applications, however.
