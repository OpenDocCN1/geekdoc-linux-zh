# Program

Click on program to do things like open new windows, save all open windows, manage files, handle printers, or to exit the program. This drop down window will also show a list of recently opened files.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_280_0.png)

# Preferences

This window will allow you to customize WordPerfect 8. Display will allow you to toggle between things like blinking cursor, hidden codes, paragraph marks, shadow cursors, scroll bars, and more. Environment allows you to specify user information, set formatting, menus, whether to save the workspace, and other program behaviors. Files will allow you to set preferences for when and where to save backups. Application Bar will allow you to select items to appear on the bar, such as time, font, alignment, printer, etc. Font will allow you to set font preferences. Printer will allow you to control print jobs and printer attributes such as quality, number of copies, etc. Finally, Colors allows you to set screen background color (note that these are not colors that show up on printed pages, but screen colors), screen font color, or even entire color schemes to use.

When you make changes in preferences (such as colors), they will not show up until you restart the program.

# Window

Clicking on window will drop down a menu that will allow you to cascade or tile all open WordPerfect windows. You may also choose to minimize or close all windows from this menu. Finally, you will see a list of all open WordPerfect windows and you may select individual windows from that list.

# Help

WordPerfect 8 comes with a fairly extensive array of help for the new user. From the control window, click on help. The drop down menu will allow you to choose to either search for a help topic or see help contents. If you choose contents you will have a window that comes up and allows you to choose from various topics.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_282_0.png)

# Creating, Opening and Saving Files

To create a new document you need only click on “file” from the menu at the top of the work area. Select “new” from the drop down menu. If you have just started the program, the work area comes up with a new document. You can also click on the new document icon which looks like a small blank page with the corner turned down. It is the icon on the farthest left.

If you want to open an existing document, click “file” and then “open,” or you can click the open file icon which is next to the new file icon.

The open file window will display directories on the right side and the files in the selected directory on the left. To move up a directory, double click on “parent.” On the lower right is an option to search for a file. Begin by typing in the first letters of the file and the file window will try to match what you are typing in with the files in that directory. If you are unsure of what directory the file is in, try using the quickfinder option on the lower right.

Using quickfinder you can specify a search pattern (such as some of the letters in the filename), a directory (subdirectories will be searched as well), and you can specify a range of dates to look in. Using whatever information you provide, WordPerfect will search and come up with a list of possible files.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_284_0.png)

If the file you select to open is not a WordPerfect file, you will be asked to provide a “filter” to open it with. This just means you need to tell WordPerfect what type of file you want to open. It might be a text file (.txt), or it might be an HTML file. WordPerfect will also open files from Windows’ word processors. Unfortunately, WordPerfect cannot open StarOffice documents.

When you want to save a file you have the option of saving it under the original filename (if it had one) or choosing a new filename. To use the old filename, simply click on “file” and then “save.” If it is a new file, you will be prompted for a filename. To give your document a new filename, click on “file” and then “save as.” You will also want to choose save as if you are saving the document in some format other than WordPerfect.

As with the file open window, you have the option of searching for a particular filename.

# Automatic Backups

WordPerfect 8 will perform automatic backups as often as you like. Earlier we mentioned that you can set defaults for automatic backups from the control window under “files.”

From the files preferences window under backup default directory, you can specify which directory you would like WordPerfect 8 to save automatic backups. WordPerfect 8 uses /tmp as a default directory but you can change it to wherever you wish. Below that you will see a box to fill in how often you want WordPerfect 8 to do an automatic save. The default is ten minutes.

If you live in an area where power outages during storms are common, you might choose to do automatic backups more often.

When either your power is interrupted or WordPerfect 8 crashes, you are at risk to lose your work. When you restart WordPerfect 8 you will see a small window pop up telling you that backup files exist and you can start WordPerfect's file manager to select the files, or click continue to ignore the backup files.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_288_0.png)

# Figure 15-11

The backup file will be the most recent automatic save. You will still lose whatever work you performed between the last automatic save and the power interruption, but that's likely to be minimal. Choose file manager to see a list of the files that have been backed up.

After the backup file has been opened you will see a warning window pop up which tells you that it is deleting the backup file. It also informs you that if the file had been password protected it is no longer and the password has also been deleted.

# Choosing Fonts and Changing Attributes

It is very easy to change the font you are using in WordPerfect 8. There are two ways to do it. You are also able to change attributes such as bold, *italics*, font size and color.
If you just need to change the font itself, you can click on the font window above the work area.
When you click on the font window a drop down menu will show you the available fonts. You can only see a sample of the font that is chosen, and you can not change any size or attributes from this window.
If you want to see available font samples, as well as change other attributes then you will want to click “format” and “font.”
This window will allow you to see a sample of the available fonts as well as how the font will look with attributes such as bold type, *italics*, colors and sizes. Using this window, you can achieve exactly the effect you want or need.
You can also use this window to select the default font. The default font is the font that will be initially assigned to all new documents.
