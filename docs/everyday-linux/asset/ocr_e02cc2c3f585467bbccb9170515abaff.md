# Changing the Main Menu

The main menu comes preset with several different applications built into it. However, over the course of your use of Linux, you will likely download or install many other applications. It is obviously somewhat tedious to click on the main menu, then “run program” every time you want to use them, so we want to be able to add them to the main menu (or perhaps to the panel itself). Doing so is very simple. Click on the main menu, and go to the submenu labeled “Settings.” There is a program listed called “Menu Editor.” Click it. Using the menu editor is fairly simple. There are essentially two kinds of menus available—the system menu and the user menu. Unless you are logged in as root, you will not be able to modify the system menu. (Modifications to the system menu affect all users.)

You will notice several buttons at the top of the screen which will allow you to add a submenu and launchers to your menu. Simply click their respective buttons and fill in the pertinent information. The information is exactly the same as the information you would supply for adding launchers or directories to your desktop, and the format is similar.

After you finish filling in the information, click the save button at the bottom of the form. This is very important, since the new submenus and applications are not automatically added when you close the program. You must save them first.

# Adding (or Removing) More Panels

If you so desire, you can add more panels. There are two types of panels: *edge panels* and *corner panels*. Edge panels will take up the entire edge of your screen; corner panels will take up more space as you add more applets or launchers to the panel.
