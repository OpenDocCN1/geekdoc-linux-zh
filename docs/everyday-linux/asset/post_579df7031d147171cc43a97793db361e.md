
Some of these mime types are used for interaction with the Internet, so be judicious about editing them. Netscape overrides your definitions with its own, but other programs may not. If you modify them, you could impair a program's ability to read data.

Most programs that you install will include their own mime type definitions when you install them, so you won't need to make or edit them very often.

The extensions are important because this is how GNOME identifies what kind of a file you wish to open. If you simply named the picture file of a page or two previous “deck” and double-clicked it, GNOME wouldn't know what program to open it with. (It would, however, ask you what you wanted to open the file with.) By calling it “deck.jpeg” you tell GNOME that you want to open the file with Electric Eyes (or some other image file viewer).

## Hidden Files

Files are hidden when you place a period in front of the filename. Many system files are hidden because you usually don't need to edit them or remove them yourself. Since you can set access permissions on your files, you don't need to hide them to prevent other users from reading them. Hiding files is useful if you're not going to be using them very much and don't want to see them in the directory listing.

If you create a file called “test.txt,” you can hide it by renaming it to “.test.txt.”

## Creating Files

You have a number of programs at your disposal which will create a number of different files for you. GNUMeric, for instance, is a spreadsheet program. GEdit is a text editor that will allow you to create your own text files. The GIMP allows you to create your own images. To create a file, simply open a file editor (of any type), modify the file, and save it.

## Removing Files

To remove files from the file browser, you should right-click the file and then click on “delete.” There is a safeguard built straight into GNOME called interaction—you will have to click “yes” to say that you want to delete the file. This ensures that you don't remove files that you want to keep.

Make sure that you really do want to remove a file when you click on delete. This action cannot be undone, unless you’ve made a backup somewhere else. There is no “Recycle Bin” to save you.

## Directories

Users of Windows9x know directories as “folders.” A directory is a term in this context that refers to a file listing. The word *directory* has a number of uses in computer contexts. It can refer to mailing lists, for instance, or your address book.

### Your Home Directory

Your home directory is where the bulk of your files will be stored. GNOME will store its configuration files in your home directory and the layout of your desktop. Enlightenment will store its configuration in your home directory. If you enable “profiling” in Netscape, your user profile will be stored in your home directory. Any files that you create should be stored in your home directory.

Your home directory is also relatively unimportant to the operation of the system. That means that you can perform a number of experiments on it without danger to the rest of the system. And since you probably haven’t installed too much software or created too many files, you don’t stand to lose much if you end up removing any files.

Your home directory is located in the /home directory under your username. The root user’s home directory is located at /root.

If you look at your desktop, there is an icon there labeled “home directory.” If you double-click it, the file browser will appear and jump straight to your home directory. This file browser is very similar to the Windows Explorer, so getting used to it should be no problem. It supports a number of different file operations (copy, move, delete, properties, etc.) for as little or as much control over them as you would like.

There are also several different styles of viewing—you can choose from a very basic icon view to a very detailed view or create your own custom viewing. When we look at some of the file properties, you might want to have this window open at the same time.

### Other Directories

Obviously many other directories exist. You might create a few yourself to store scripts or letters in.

However, there are also a number of special directories which you should be aware of. When we discuss the File Hierarchy Standard, we'll talk more about these directories.

### The Path

Perhaps one of the harder concepts for users new to the filesystem to grasp is that of the *path*. A path is a collection of directories. It doesn't group the directories into a system the way a directory groups files, however. Instead, the path is stored in an *environment variable*. An environment variable is a setting that is defined every time you log in to the system.

The path tells the computer where to look for commands. It is tedious to type in a directory and the command name every single time you would like to run a command, say `/usr/games/Fortune`. It's far easier just to type “fortune” and have an amusing message pop up. What we want to do is add the directory `/usr/games` to the path.

It is important to note that Linux does not search through the current directory to find commands. This is a small change from the MS-DOS path convention, which will search through your current directory to find commands. When you are in a command line interface, you should use the following syntax to run a command from your current directory: `./commandname`. The “./” tells Linux that you wish to use the current directory.

We will talk about setting the path when we look at special files on your Linux system.

### The Directory Tree

You will sometimes hear directories referred to as the *directory tree*. The filesystem is organized as a directory tree. You might find an apt comparison in your family tree, though the directory tree is a little different, since it only requires one *parent directory* to have a *child directory* or a *subdirectory*. A parent directory may have an unlimited number of subdirectories, for all intents and purposes.

Each “branch” of your directory tree is separated by a forward slash (/). The root directory is the beginning of the directory tree and is denoted by a simple forward slash (/). Don’t confuse this with the home directory of the root user, which is denoted by /root.

This means that every directory has at least two names. One is the name that the parent directory calls it. For instance, you might create a directory named “test.d” in your home directory. Your home directory—the parent—knows the directory as test.d, but the system knows the directory as /home/username/test.d. (Username is a generic term used instead of your username.) When you attempt to change directories within the command line, you usually have to use the system name of the directory unless you are in a parent directory of a subdirectory.

Directories are recursive in nature, so a “grandparent directory” can access some child directory by naming first its parent directory and then the child. For instance, you found that you needed to add another directory in the test.d directory you created a little while ago. You called this one another_test.d. If you are in your home directory, you can access the directory you just created by naming it as “test.d/another_test.d” (without the quotes, of course).

When we looked at running commands from the “current directory,” we noted that the current directory is given the generic name “./”. Any current directory can be called by this name. Any parent directory can be called by a generic name, too: “../”.

The file browser’s GUI (graphical user interface) illustrates the directory tree very well, though it doesn’t explain what happens at the system level. When you begin to use the command-line interface more, operations at the system level become more important. The directory tree will become more familiar then.

## Hidden Directories

Directories are hidden the same way files are, and this is usually done for directories containing system files. If you prefer to use the text-based e-mail program called elm, it will create its own directory in your home directory called “.elm.”

If you wish to hide a directory, rename it and place a period at the beginning.
