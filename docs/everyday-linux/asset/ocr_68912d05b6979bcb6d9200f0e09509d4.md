Since you are running this from X-Windows, the program will tell you that you probably shouldn't. It should be okay for you to go ahead and configure sound anyway. Press enter to move past this screen. To have the sound configuration program probe your computer for a sound card, press enter. If it can't find a sound card in your computer, you will have to select it from a list of available cards.

As a precaution, the configuration program will warn you that you're about to overwrite some configuration files. Go ahead and overwrite them.

The program will then play a sound sample. My copy of Red Hat has Linux Torvalds (the creator of Linux) saying, "Hi, I'm Linux Torvalds, and I pronounce Linux 'Lah-nux.' " If you can't hear the sample, you will want to make sure that your sound card is properly seated in your computer (it is if you heard sound in your other operating system) and that your speakers are plugged in. If you have a volume control on your speakers, you may need to turn this up more than usual to hear sounds in Linux. (This is because Windows pre-amplifies sound through its own volume mixer.) Make sure to confirm that you have heard it or that you haven't.

Once the program is finished, it will exit and the window will close. If you used the terminal icon on the panel to use the sound configuration program, you will be presented with another prompt. Type exit to quit the terminal.

# # The Linux Configurator

This is a brief introduction to the Linux Configurator, more often known as "linuxconf" because that is the command invoked to run it. Linuxconf is a very, very powerful tool, and you're probably going to use it quite a bit over the course of your administration of Linux.

Our first use of linuxconf is going to be to add additional users to your system. If you don't think anyone but you is going to use your computer, then you could just add a test account if you wanted. Our second use will be to add your regular user account to the *wheel* group, to allow you to use the su command to run administrative programs without actually logging in as the root user. We're also going to examine how to work with your disk drives to allow everyone to use them.
