Here is a sample component list with my commentary about why you would want to use each of the components:

+   *   **Printer Support** Printer support will be necessary if you have a compatible printer to use with Red Hat. (If you’re not sure, you should consult the Red Hat web page for compatibility lists.) If you want to use a printer with Red Hat, check the box.

+   *   **Mail / WWW / News Tools** These tools will allow you to send and receive e-mail, browse the web, and read online newsgroups. You should include this component if you’re going to be using the Internet.

+   *   **Graphics Manipulation** This component will supply you with plenty of goodies. Users that view or edit graphics files (.gif, Jp(e/g, .tif(f), and so on) will want to include this component.

+   *   **Networked / Dialup Workstation** If you are planning on connecting to a network through a network interface card (NIC) or through a dialup (this includes the Internet, not just local area networks), you should check the component that matches your setup. (Networked workstation for LANs, dialup workstation for computers that aren’t on LANs.) If you’ll be connecting both ways, install both components.

+   *   **SMB (Samba) Connectivity** If you are a Linux user on a local-area network (LAN) that is composed of multiple platforms (such as Windows95, Windows98, etc.), you will probably need to print to printers on Windows machines. If this is the case, include this component.

+   *   **IPX / Netware Connectivity** If you are on a local-area network powered by Netware, you will want to include this component.

+   *   **Development** If you plan on writing programs on your Linux machine, you should click on the *development* component. This will allow you to program in such languages as Perl, C/C++, Python, TCL, and many others.

If you don’t want to fool around with any of the components and have plenty of hard drive space, you can click on the “Everything” option to install all of Red Hat Linux on your computer. This kind of defeats the purpose of customization, though.
