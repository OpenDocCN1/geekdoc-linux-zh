The export command is one that you can run from the command line, but probably won't very often. For our purposes, we'll be using it from the .bashrc file or something similar, though you can use it to set other variables if you need to. What the export command tells the computer to do is to finalize the setting. It will ensure that your path is set.

If you're not sure of what other directories to put into your path, don't follow the following directions. You will likely figure them out as you become more familiar with your system. But you probably don't need to modify your path in any way. When the root user installs more programs, he may have to modify the global path—the one assigned to every user if he doesn't have a path defined in the .bashrc file—so that users can make use of the programs he installs. This file is usually located in /etc/bashrc.

To edit your .bashrc file, you need to open up your home directory. More than likely, the file browser is not set up to display hidden files, so you will need to change the preferences.

To change the preferences, click on “edit.” At the bottom of the edit menu is an option conveniently labeled “preferences.” Click it. The first tab on this screen deals with how you display files; click on “show hidden files” to display hidden files. Then click OK or Accept and your home directory will probably become much more populated. (You can follow this same procedure to stop displaying hidden files if you desire.)

After changing your preferences, a longer file listing will appear. Double-click the file called .bashrc. When the window asking you which application to use to edit the file appears, you should open the folder labeled “Applications” and click on “GEdit.” The GNU Editor will appear with the contents of your .bashrc file in it. You may edit this at your pleasure.

The .bashrc file is used only by the Bourne-Again shell, not by any others. Many different shells exist (such as the C Shell, the Korn Shell, the restricted shell, and so on), and they each use a different RC file to set environment variables and other preferences. Since the default shell is bash, we have supplied the method for editing its RC file. You may see files like .cshrc or .kshrc in your directory—these may be files for other shells.
