# **Tools**

If you want to compare the difference between the remote computer file listing and the local computer file listing (helpful if you're transferring web page documents to another server and have lost track of which you've sent, for instance), click on tools and then compare windows.

# **Help**

The help section won't give you much help, unless you want to read about the makers of GFTP or the GNU Public License (the GPL).

# **Other Programs**

Many other Internet services exist, and a corresponding number of programs are available to make use of them. If you are interested in Internet Relay Chat (IRC), for instance, you can use the program xchat to chat with other people across the world. There are other less-used services such as gopher that you can find programs for if you're interested.

As it is, you'll probably end up using Netscape and GFTP more than the other programs available (unless you're like me and really like Opera). You'll be able to find other Internet applications from the Internet itself and using GnURPM, so don't be bashful about installing new ones. Most of them are simple to use and have clean interfaces that may be modeled on more familiar Windows programs.

Another helpful facet to most applications for Linux in general is that authors maintain numerous web pages about their products. You can usually find this in the About section in the help menu (see, for instance, GFTP). If you ever have trouble using or setting up an application, you can go to the web page and read the frequently-asked questions (FAQ) or even e-mail the authors for help.
