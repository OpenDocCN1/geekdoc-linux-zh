Each of the resources listed is followed by either some commentary, a description, or both, just so that you know what you're getting into when you access it. They're organized alphabetically in each category, so you can find what you're looking for reasonably quickly.

# General

+   **http://gedit.sourceforge.net**
+   If you want to get some information, updates, and help with GEdit, a powerful editor made by the folks at GNU, you should visit this website.

+   **http://www.corel.com**
+   Users of the WordPerfect word processing program or Corel's version of the Linux operating system will probably want to visit this page periodically. Corel releases versions of WordPerfect for Linux one or two versions behind that of its office suite. It's a hefty download, but it is free of charge.

+   **http://www.debian.org**
+   *Debian* Linux is another popular distribution of the Linux operating system. There are warring factions in the Linux community dedicated to seeing Debian triumph over Red Hat (and vice versa), though the advantages of each usually put them in different fields of use. Debian is generally considered a little less user-friendly than Red Hat.

+   **http://www.enlightenment.org**
+   This is Enlightenment's home page. You'll be able to find updates, various applets, and themes from here.

+   **http://www.gimp.org**
+   Users of the GIMP will be glad to use this web page. It contains updates, plug-ins, and other various downloads you'll find interesting. You should also be able to get a little technical support here if you need it.
