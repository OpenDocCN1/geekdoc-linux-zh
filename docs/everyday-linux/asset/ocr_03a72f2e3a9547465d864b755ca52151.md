+   - q Pressing q will cause the program to quit without writing the partition table. This means that no changes will actually be made.

+   - W You must press a capital W if you want to write this data to disk and make it permanent.

Use these commands to create a new partition and remove any extra partitions on the drive that you do not want. Remember to do this to the new drive only, not to an existing drive that has data you want to keep! If you delete a partition, you cannot get the data back!

Step Three—You must now create a file system on the new partition. To do this, type mkfs /dev/hdb1 at the prompt. This is the first partition that you created on the device /dev/hdb (the primary slave hard drive). You must use this command for every single partition on the drive if you created more than one.

The mkfs command stands for "make file system." It is analogous to the MS-DOS and Windows command format. It creates the Linux file system on a hard drive. If you created a partition that is not a Linux partition, you will have to format it using the operating system for which it is designed. (It is possible to create file systems for MS-DOS, Windows, and other operating systems under Linux, but it is usually better to use its respective operating system instead.)

Step Four—You will then need to make sure that the drive is mounted every time you turn on the computer. To do this, run linuxconf (either from the main menu, the command line, or by clicking on the system configuration button in the control panel) and find the category "File systems." Click on "Access local volume."

Click the "Add" button at the bottom of the list of devices. You will then need to specify the mount point of the drive and its format. Do so and then click Accept. The drive will then be in the list. If you highlight the drive, you will then be able to mount it. If you want it to be mounted every time the computer boots up, click on the tab labeled "Params" and change that option.

You can then quit and activate the changes.

# Zip and Jazz Drives

If your new drive is an IDE Zip drive or a Jazz drive, it will be on the fourth partition position. For instance, if your Zip drive is a primary slave IDE drive, it will be called hdb4; if it's secondary master, it would be hdc4. Mine is in the secondary slave position, so its device profile is /dev/hdd4.
