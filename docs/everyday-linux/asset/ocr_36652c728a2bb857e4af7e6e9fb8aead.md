# **Creating a New Web Document**

You can create a new HTML document with very little knowledge of HTML. Open the Internet Publisher Dialogue Box by clicking “file” and “Internet Publisher.” Choose “New Web Document.”
You can create the web document much as you would any other document but you will have to know a bit about html to create anything other than a simple page. Hold the mouse over the various tools to find out what they do.
