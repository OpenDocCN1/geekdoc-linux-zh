# Configuration Files

There are other configuration files as well. These usually have extensions of .cfg or .conf. Most of the global configuration files reside in the /etc directory. You would find the configuration for LILO here under the filename lilo.conf. If you use the lynx web browser, you would find its configuration file under lynx.cfg.

It is important that you know the existence of these files, but it is equally important that you not edit them without understanding the contents of the file and what editing them means. If you mess up (the technical term is “corrupt” or “FUBAR”) lilo.conf, your computer may not boot properly. Without a boot disk, it would be impossible to get into the system.

Global configurations are found here as well. If your users do not set their own paths, for instance, you will find RC files in this directory which provide a global path for them. These files are usually not hidden. The global .bashrc file is listed under .bashrc, for instance.

The /etc directory contains most of the files your system requires to run. You can explore this as both a root user and as a regular user, so use your regular user to look at the contents of files (some are not accessible, such as user lists or password files) and to poke around. This will minimize the risk of damaging any files as your Linux system requires to operate. When you need to modify files, use the root user and exercise extreme caution. Make backups of configuration files by copying them and adding an extension of .bak.

# Lock Files

Lock files are special files used by Linux to see whether you are running a program more than once. When you run a program, a lock file is created for that program. If you suspend the program or try to start it again, you will be informed that the program is already running.

These are usually stored in the /tmp directory and are deleted when you exit the program or kill the process. Your first encounter with a lock file will probably come when you use Minicom. If the modem is either in use or hasn't been reset properly, you'll get a message that says, "/dev/modem is locked" when you attempt to start the program.
