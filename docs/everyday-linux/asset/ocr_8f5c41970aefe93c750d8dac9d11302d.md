When you use Linux, you'll have opportunities to work with the file system
at a more basic level, known as the command line. Having partitions will help
you sort out some details pertaining to your files.
The main advantage, however, is data protection. When you install Linux, it's
relatively simple to keep your data safe. During the installation process (in the
next step, you'll see), you will be able to tell the program which partitions to for-
mat. Formatting a partition will wipe out all the data on it. If you upgrade or
reinstall Linux, you'll find that you've got some files on the system that you don't
want to lose. If they are contained in a specially made partition, you won't have
to format the partition and lose the files.
This means that the risk to your files is minimized during a second installa-
tion or an upgrade. This is really quite handy.
Another very large advantage is discussed in the next section.

# Characteristics of Partitions

Partitions typically have two main characteristics: size and format. The size of
a partition is self-explanatory—it's simply how large or small you want to
make the partition. In the analogy of our room, it's where you place the wall.
The format, however, doesn't have as logical an equivalent. Most personal
computers run some version of Microsoft Windows. However, other operating
systems, such as the Macintosh OS, BeOS, Linux, and others are used. Each of
these operating systems uses a different file system, and therefore the files are
in a different format. You might liken this to how one side of the room looks
compared to the other.
A computer running Windows typically cannot read files formatted under
MacOS or Linux. Windows is one of the few operating systems, and the only
one in wide use, that is so impaired.
A great advantage of Linux is that it can read disks formatted under different
operating systems. Linux supports many different formats, among them the
MacOS, Windows, and other UNIX derivatives (such as MINIX, BSD, and so
on). Support for these operating systems can be added dynamically using various
upgrade tools provided by Red Hat, too, so if you have a hard drive or floppy
disk formatted in who knows what, you can probably find support for it in Linux.
