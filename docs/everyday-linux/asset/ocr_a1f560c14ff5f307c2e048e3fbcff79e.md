# ### Booting into the Installation

Your first concern is going to be whether you can boot from the CD-ROM or not. I assume for simplicity’s sake that the installation software is on a CD. If you bought Red Hat Linux from a store or borrowed it from a friend, it likely came on a CD. Linux is not available on floppy diskettes, but it could be on your hard drive. (The only reason it would be on your hard drive would be because you downloaded it from the Internet. Unless you have an incredibly fast Internet connection, this is highly unlikely, so we’ll stick with a CD-ROM installation.)

The CD comes with all of the necessary information to boot up your computer and load Red Hat onto your machine. If you can’t boot from your CD-ROM, however, you’ll have to make a disk. If you can boot from your CD-ROM but presently don’t have that option enabled, you will need to contact your computer vendor or manufacturer to ask how to go about enabling it. Your computer manual may come with this information, too.

# #### Making a Boot Disk

In the making of this boot disk, I assume that you are presently running a version of Windows. This process will be slightly different if you are running MacOS or something similar.

You should insert a floppy disk into your floppy drive. If it’s not already formatted, format it by opening up Windows Explorer. In the left window frame, you’ll notice a list of available folders. At the very top of this list, you should be able to see a list of your drives.
