# Special Effects

Leaving this customization at defaults is just fine. If you want to enable any of the special effects listed here, just click on them.

# Backgrounds

Not only will GNOME provide you with the chance to change your back-ground, so will Enlightenment. Enlightenment comes with some prepackaged background pictures (quite pretty pictures, if I might add my opinion) and some rather simple graphics to choose from. You can also use a blank background if you'd like.

You'll notice if you use these backgrounds that the one you selected in the control center will conflict with the one you select here. If you'd rather use the one you selected in Enlightenment, tell GNOME not to use a background at all.

# Themes

Enlightenment also provides stylized themes with special cursors and win-dow modifications that you can experiment with. Themes can greatly enhance the look of your windows. Several come with Enlightenment, but you can get many, many more.

The prime place for themes is www.themes.org. Themes.org is a wonderful place to get absolutely free and stunningly gorgeous themes. The site is packed with other graphics information, too, so if you're looking for development infor-mation, you'll be able to find it here, too.

If you're interested in installing new themes, look at Chapter Six, which talks about maintaining your system. Read the section entitled, “Adding Eye Candy.”

# Shortcuts

Enlightenment also offers several command-key shortcuts that you can mod-ify, add to, or remove. If you find using mice rather pesky and annoying, you might *bind* a few commands to shortcut keys. (For instance, a default shortcut is to use Alt-F1 to move to the first desktop. Alt-F2 will move to the second, and so on.)
