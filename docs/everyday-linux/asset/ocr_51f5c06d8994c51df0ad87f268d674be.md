# Fast Installation Instructions

As promised, I have collated the steps of the installation procedure and condensed them to a form that requires you to know basically nothing about the installation. It is highly recommended that you go through the installation at least once using the book before using this small outline.

+   1. At the opening screen, press Enter.

+   2. Choose your language from the list of available options.

+   3. Configure your keyboard.

+   4. Configure your mouse. It's a good idea to emulate three buttons, since many applications in Linux use the third button. (Don't emulate three buttons if you already have a three-button mouse.)

+   5. Choose your installation method (class). If you are not using a custom installation class, skip to instruction 8. If you are installing Linux for the second time, it is highly recommended that you use a custom installation class—you might be able to save some of your old data this way.

+   6. Create, Edit, and Delete the partition scheme to your liking. Make sure to write down the mount points and device names of all of the partitions.

+   7. Select which partitions you want to format.

+   8. Configure the Linux Loader (LILO).

+   9. Configure your Network Settings.

+   10. Configure the Time Zone.

+   11. Choose the root password and add your own account.

+   12. Configure the authentication options. The defaults are usually fine, but if you're on a network, check with your systems administrator to see if you need to enable the NIS options.

+   13. Select components or packages.

+   14. Configure X-Windows for use with your monitor and graphics card.

+   15. Wait for the installation program to format the partitions you selected and install the components you chose. Then create a boot diskette.
