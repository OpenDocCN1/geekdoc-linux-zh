# Décor

+   * *Fuzzy Border*—gives image a fuzzy border.
+   * *Old Photo*—one of my favorite effects in GIMP. This script takes an image and transforms it into a brownish antique photo.
+   * *Coffee Stain*—produces a very real-looking coffee stain on an image.

# Modify

+   * *Add Border*—adds a border. You may specify color and size.
+   * *Shadow*—takes image and adds shadow behind it, giving the image a 3D effect. There are two variations to this; drop shadow and perspective.

# Render

+   * *Line Nova*—turns the image into lines shooting from the center of the image.

# Dialogues Menu

+   * *Brushes*—select a size and type brush for use with paintbrush, pencil, eraser, and airbrush.
+   * *Patterns*—select from a set of patterns which can be used with fill tool.
+   * *Palettes*—select, create, and edit color palettes.
+   * *Gradient Editor*—selects, creates, or edits a gradient.
+   * *Layers and Channels*—is another way to access layers and channels window.
+   * *Indexed Palette*—displays palette (only available for an indexed image).
+   * *Tool Options*—opens tool options dialogue for currently selected tool.
