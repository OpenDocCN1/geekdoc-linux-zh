One of the most widely used formats is dBase, most often used in the DOS/Windows environment. The ODBC format uses the SQL language and is the type used by Oracle, Sybase, Informix and other large databases. Text format is a last resort when there are no other options.

# Creating a New Database

It's a good idea to put your database in a directory all its own, especially if you might create more than one database. Multiple databases in one directory can easily lead to tables getting intermingled and other problems.

You can create a new directory using your directory explorer on your Red Hat desktop. Click "file" and then "new," and then choose "directory."

A new window will pop-up and you can then type in the name of the new directory.
