# **LILO Configuration**

LILO stands for “Linux Loader,” and it is the program that Linux installs in the master boot record (MBR) which loads Linux. (Hence the name “Linux Loader.”) However, LILO will also boot to other operating systems like Windows or MacOS.

Typically, you want to install LILO on the primary master drive’s boot record so the drive you specify should be hda. If you are dual booting using two physical hard drives, LILO may give you occasional problems. If that happens, you can simply reinstall Windows or your other operating system and make use of the boot disk that you’ll create during installation.

If that sounds like a hassle, you should simply not install LILO and use the boot disk instead.

If you are booting from a single drive or single booting, it is highly recommended that you use LILO. You can usually leave the information in this screen at the defaults, so you probably won’t need to change anything.

# **Network Configuration**

The next step is to set up any network devices that are present on your system. If you don’t have any, you won’t see this step, but if you use a device like a network card, Linux will probe for it and see what settings it should use.

Normally the default settings will work just fine, since most companies will assign you information using a DHCP protocol that simply assigns you information dynamically, instead of statically. If you’re not sure what to put in here, you should call either your network administrator (if you’re on a LAN) or your Internet Service Provider to see what settings they recommend.

Generally, you’re fine using DHCP and clicking Next.

# **Time Zone**

This is a fairly explanatory step. The only complication that could arise is if your computer sets itself to GMT (Greenwich Mean Time) and adjusts the time for your specific time zone. If it does, you should work with the UCT tab instead.

To set your time, you can simply navigate the map on your screen (it will not appear if you’re using the text installation) and click on which time zone you use. If the time on your computer is already set using the BIOS, Red Hat will attempt to guess what time zone you’re in. It’s usually pretty accurate.
