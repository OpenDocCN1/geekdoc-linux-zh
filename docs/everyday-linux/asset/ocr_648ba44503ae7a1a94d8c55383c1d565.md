If you simply don't like your computer mouse, or enjoy making procedures harder than they need to be, you can also use the text-based interface navigation instructions that follow.

# Text

If you're running the text install, you will probably have to navigate through the procedure entirely with your keyboard. This may seem rather inconvenient. And it is. That's why we recommend using the graphical installation.

To move forward to another option, press your tab key. If you want to move backward, press the alt (or meta) key in conjunction with the tab key. Use the enter key to select options (such as which hard drive you'll install a partition on) and to press the buttons at the bottom of the screen.

You'll also notice that the last line of the screen has some F-key options, like F1, F5, F12, and so on. You can use them to navigate as well.

# Initial Configuration

The first configuration options you're going to set involve basic settings, like what language you speak, which keyboard you use, and what kind of mouse is attached to your system.

The first two are fairly simple. The defaults will probably work just fine. When you select your keyboard, you can fine-tune some settings, but you don't need to. The help dialogue at the side of the screen will assist you with deciding which keyboard you should use. Most keyboards now do not come equipped with composition keys (so you can create international characters straight from the keyboard).

The mouse, however, is a slightly more complicated matter. Linux is a UNIX derivative, and will make good use of a three-button mouse. If you don't have a three-button mouse, you can choose to emulate a three-button mouse. To take advantage of the “third button,” you must press both the right- and left-hand mouse buttons at the same time.
