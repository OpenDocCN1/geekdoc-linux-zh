# Directories

Users of Windows9x know directories as “folders.” A directory is a term in this context that refers to a file listing. The word *directory* has a number of uses in computer contexts. It can refer to mailing lists, for instance, or your address book.

# Your Home Directory

Your home directory is where the bulk of your files will be stored. GNOME will store its configuration files in your home directory and the layout of your desktop. Enlightenment will store its configuration in your home directory. If you enable “profiling” in Netscape, your user profile will be stored in your home directory. Any files that you create should be stored in your home directory.

Your home directory is also relatively unimportant to the operation of the system. That means that you can perform a number of experiments on it without danger to the rest of the system. And since you probably haven’t installed too much software or created too many files, you don’t stand to lose much if you end up removing any files.

Your home directory is located in the /home directory under your username. The root user’s home directory is located at /root.

If you look at your desktop, there is an icon there labeled “home directory.” If you double-click it, the file browser will appear and jump straight to your home directory. This file browser is very similar to the Windows Explorer, so getting used to it should be no problem. It supports a number of different file operations (copy, move, delete, properties, etc.) for as little or as much control over them as you would like.

There are also several different styles of viewing—you can choose from a very basic icon view to a very detailed view or create your own custom viewing. When we look at some of the file properties, you might want to have this window open at the same time.
