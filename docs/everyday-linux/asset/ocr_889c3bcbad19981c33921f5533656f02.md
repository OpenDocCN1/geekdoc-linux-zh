# Some Internet
Applications

As you use the Internet more and more, you'll find that a wide variety of applications will be useful to you. There is, of course, the Netscape Communicator, which many people already use on their Windows machines. However, there are also programs that make use of the File Transfer Protocol (FTP) and other browser programs that you might find more useful than Netscape, especially if you're low on space.

# Web Browsers

The World Wide Web is the most popular facet of the Internet. (Many people don't recognize that there are many others besides.) This popularity has generated the interest of numerous programmers throughout the world, and a number of browsers have been released to make use of all of the capabilities of the web.

The major two competitors are the Netscape Communicator and Microsoft's Internet Explorer. Others such as Mozilla and Opera have also made inroads into the web browser field.
