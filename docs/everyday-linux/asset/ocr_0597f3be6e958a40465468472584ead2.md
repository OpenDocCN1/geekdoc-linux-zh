GEdit.

If you need to know some statistics about a file, click “Plugins” and then “word count.” A small window will pop up and tell you the number of characters, words and paragraphs.

There are plugins for spell check, version control and browse (for HTML files).

A very useful feature of GEdit is “find in files.” This will search multiple files (whichever ones are open at that time) for a phrase or word. As an example, we took three files and searched them for the word constellation.

GEdit will split the window and then list the occurrences where it found the word or phrase it was searching for. It will list the file it found it in, plus the line number and sentence. It will also list total number of times it found what it was looking for.

If you make multiple errors in a file, you might find the “revert” feature under “file” useful. Revert will pull up the most recently saved version of the file you have been working on.

Because GEdit is an open source project, it is likely that even more features will be added to the program over time.
