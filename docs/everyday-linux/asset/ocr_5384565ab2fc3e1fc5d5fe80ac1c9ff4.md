# Adding an Entry

To add an entry to your address book, click on "add."

You can add a good deal of information about each entry. There are tabs which go across the "add entry" window to add information for address, phone, network, geographical (which would tell you which time zone the person was in), and you can even add some notes about the entry.

When you are finished, click "ok." Note that you can add phone numbers and addresses to separate lists.
