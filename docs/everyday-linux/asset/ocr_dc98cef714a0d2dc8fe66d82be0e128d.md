# ## Adding Accounts

Our first task is going to be adding an account to the machine.

To add an account, scroll through the list on the left. There is a submenu labeled “user accounts” that you need to open up. In its sublist, click on the “user accounts” underneath the “Normal” subheading. A list of all of the current users on the system will appear—you should see your own user account and root, among several others (most of which you’ll never use).
