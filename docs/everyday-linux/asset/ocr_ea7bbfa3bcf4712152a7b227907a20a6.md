# **What Is GNOME**
**(and What Are Desktop Systems?)**

GNOME stands for "GNU Object Modeling Environment." GNOME is a desktop system for the X-Window System. Many other desktop systems exist, but GNOME has moved to the forefront of the available options because of its usability and technical capabilities. (When you had the chance to install various components, you could've chosen KDE instead of GNOME. KDE is another desktop system.)

GNOME is one of the first desktop systems to catapult Linux to a more user-friendly level by combining features of both the Microsoft Windows and the Macintosh operating systems.

A desktop system is a program that the X-Window System uses to organize various shortcuts and programs. Desktop systems come with different features. GNOME, for instance, comes with "paneling" (among other features). Panels are much like the Windows 95 Start bar that shows a list of your running programs. It is important to realize that the desktop system controls a variety of features. One of the more common and useful features employed is the "drag-and-drop" feature, which allows you to move a file from your file manager to the desktop simply by clicking on it and dragging the icon to the desktop. This feature is fairly commonplace in widely used operating systems, but until recently, Linux did not support this feature. It was inconvenient at best and incredibly aggravating.

The desktop system also controls how the desktop looks by using desktop themes. There are separate themes in Linux for both desktops and windows; this is a big change from Windows, which uses the same theme to control the look and feel of both the desktop and your windows.

Red Hat Linux also comes equipped with a number of window managers in addition to the GNOME desktop system.

# **What Is a Window Manager?**

A window manager is a program that manages the look and feel of the windows open on a desktop. The default window manager for Red Hat is called Enlightenment. Others exist; among these are After Step and Another Level.
