# A List of Commands (cont.)

| Command Name | Options | Description |
| --- | --- | --- |
| mkdir | [directory] | This program will make a directory with the name that you specify on the command line. |
| more | [filename] | This command will print a file to the screen page by page for easy reading. |
| mount | -t [fs type] [device] [path] | The mount command mounts a drive of type [fs type] defined by device profile [device] at a mount point [path]. |
| mpg123 | [filename] | This is a program that will play MPEG audio files (.mp1, .mp2, .mp3) from the command line. |
| mv | [source] [destination] | This command will move a source file to its specified destination. You can use this program to rename files. |
| pico | [filename]; see pico man page | Pico is a very user-friendly text editor. |
| pine | see pine man page | Pine is another feature-rich text-based e-mail program. It is very user-friendly. |
| reboot | | This will reboot the computer. Make sure that you have unmounted all drives that make use of removable media before using the reboot command. |
| rm | [filename]; see rm man page | This removes files from your computer. There are several options frequently used with the rm command, so read the man page to see which you should use. |
