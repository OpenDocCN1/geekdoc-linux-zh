For the moment, you probably only need to concern yourself with the navigation principles of Midnight Commander. That alone will allow you to take advantage of many different options. It will also allow you easy access to experimenting with your system.

When you start Midnight Commander, you will be presented with a window on both the left and right sides of your screen. They are identical. To switch between these two windows, press your tab key. You can maintain two different file listings at once this way.

To move up or down in your file listing, use the up- and down-arrow keys. When you want to enter a directory, press the Enter key. The parent directory is noted by the ../ we spoke of earlier in the chapter; the current directory is denoted by ./ .

At the bottom of the screen, the numbers 0–9 are listed. These correspond to “F-keys,” which are the ones labeled F1–F12 at the top of your keyboard. You can use each of these F-keys to perform the associated task. (Next to each number is an operation, such as copy, delete, view, and so on.)

To invoke Midnight Commander from the command line, type mc and press the enter key.

# In Summary

While we haven’t covered every single aspect of the Linux file system, this chapter serves as a brief introduction to it. Most users won’t need much more information—others may be interested in learning more. You can find a lot of the information you seek on the Internet through various pages. Make sure to check the back of the book for more information.

You can always learn more about the file system by experimenting with it. It’s usually pretty hard to damage the system when you’re using your own user, so have fun and explore a little bit. You can’t remove any files but your own, so don’t worry about running around in the file system.
