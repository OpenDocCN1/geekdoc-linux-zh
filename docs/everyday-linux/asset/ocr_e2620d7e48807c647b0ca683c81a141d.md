# **XPM**

X Pixmap: This is the standard for storing monochrome, grayscale, and color pixmap images on the X-Windows system. Most icons used in X-Windows are of this format.

# **TIFF**

Tagged Image File Format is a format frequently used by PC-based drawing programs, desktop publishing, and scanners. This is a versatile format and can work in grayscale, monochrome, and color. TIFF writes a large file (probably the largest of the group) and uses lossless compression.

# **Gqview**

Just about every day when I sit at my computer, I use Gqview at one point or another. Whether it’s looking for an image I want to use on my desktop, or selecting an image to use in a puzzle, I use Gqview. This program acts as an image browser with an option for thumbnails. Gqview does not allow image editing itself but has the ability to open an editing program and load a selected image.

When Gqview starts up it goes to your home directory. Under options you can specify a directory to which you want Gqview to go on startup. On the left Gqview will list all the image files it finds in the directory it is in. By clicking once on one of these files, the image will be displayed on the right. Below the image you will find the image size in pixels and the file size.

Gqview is pretty self explanatory. Placing the mouse over any of the buttons on the top left will tell you what it will do. Gqview works on a “one-click” mouse, meaning that you need only click once on a file to open it or change directory as opposed to the double-click used by some other programs.
