Many tools, like inserting images and changing fonts, work the same way they do in the WordPerfect 5 document editor that you have been working with.

> As with most programs which create web pages in a graphical environment, the code is rather sloppy. If you plan on creating large or multiple websites, we strongly suggest you get a book on HTML and learn to do it in an efficient manner. Sloppy HTML makes pages take a long time to load in a browser and might not look good in all browsers.

When you have created a web document you will want to view it using Netscape to see how it will look in a browser. When you are satisfied with how your web document looks, you can upload it to your web server.
