# **Workstation with KDE**

If you're more familiar with UNIX or Linux, and you prefer KDE over GNOME, feel free to pick this option.

# **Server**

In the event that you're serving files on a network, maybe from your college dorm room or on a home LAN (local area network), you may want to try a server-class installation. This will install various extra programs that will allow other computers access to yours (this can pose security risks, of course).

It's not usually recommended that you use a server-class installation unless you're fairly competent with Linux. “Fairly competent” means that you can do your own systems administration and security troubleshooting.

The attraction of using these pre-defined installation classes is that they will simplify the installation process. They will eliminate your need to create your own partitions, and you won't have to do much in the way of selecting components.

The workstation classes won't cavalierly wipe out any information on any drives that don't already use Linux, but the server installation class will. It will format **all** of your drives and remove **all** of the information on them. This is another reason you should be quite wary of choosing the server installation class.

# **Custom**

This leaves us with the fourth and final installation class—the custom installation. The folks at Red Hat kindly suggest that if you're new to Linux that you choose one of the workstation installation classes, and if that seems like a more appropriate route to you after reading about the custom installation class, then by all means choose it.

If you haven't guessed so from the tenor of that paragraph, it is my suggestion that you do use the custom installation class. The custom installation class is the only one that will allow you full autonomy over the installation—which **partitions** you want to create, how large you want them to be, in what format, and what packages you want to install.
