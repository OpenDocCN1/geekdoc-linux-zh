# Choosing Fonts and Changing Attributes

It is very easy to change the font you are using in WordPerfect 8. There are two ways to do it. You are also able to change attributes such as bold, *italics*, font size and color.
If you just need to change the font itself, you can click on the font window above the work area.
When you click on the font window a drop down menu will show you the available fonts. You can only see a sample of the font that is chosen, and you can- not change any size or attributes from this window.
If you want to see available font samples, as well as change other attributes then you will want to click “format” and “font.”
This window will allow you to see a sample of the available fonts as well as how the font will look with attributes such as bold type, *italics*, colors and sizes. Using this window, you can achieve exactly the effect you want or need.
You can also use this window to select the default font. The default font is the font that will be initially assigned to all new documents.
