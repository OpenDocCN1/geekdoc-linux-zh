
## Text Editor Basics

Print—prints the file that is open if you have a printer configured.

Cut—removes whatever text is highlighted.

Copy—copies selected text into a buffer so that it may be pasted elsewhere.

Paste—inserts whatever text was copied to a buffer. This will usually work between programs, meaning text copied from one program can be pasted to another program.

Find—finds a text pattern or phrase in a file.

Find Again—locates additional occurrences of a specified text pattern or phrase.

Replace—finds one pattern and replaces it with another.

Select All—selects all text in file.

Undo—undoes previous operation.

Redo—cancels whatever change was undone.

Word Wrap—will automatically move the word to the next line when the last word of a line is too long. This prevents a word from being "chopped" in two.

New Window—opens a new window of the program.

## Text File Viewer

Text File Viewer is found under the main GNOME menus in the Utilities sub-menu.

Text File Viewer is at this time strictly for viewing text and html files. It’s a "no frills" program, but it opens, displays and saves files quickly.

There are only a few features with this program. You cannot edit files or change them in any way except to save them under a different file name. It does allow you to find words, letters or even phrases in a file.

You are also able to open up multiple windows, which can make comparing several files much easier.

### Advanced Text Editor

The Advanced File Editor (also known as Kwrite) can be found by choosing “KDE menus,” then “applications,” and then “Advanced Text Editor.” Kwrite will open text (.txt) and .html files.

The program is very intuitive and similar in layout to the other text editors we talk about. There are pop-down menus for file, edit, bookmarks, options, and help. There is extensive documentation if you choose “contents” under help.

Kwrite has all of the common features mentioned previously plus some additional ones.

One of the features which we found very useful was bookmarks. This feature allows you to mark areas in a file. The bookmarks are not saved with the file, so they are lost once the file is closed.

### GEdit

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_185_0.png)

It could well be argued that GEdit is closer to a full-featured word processor than it is to a text editor. GEdit can be found in the main GNOME menu under "applications."

GEdit has all of the features mentioned at the beginning of this chapter, plus many more you will likely find useful. GEdit will open .txt and .html files. The program will open multiple files, and they are listed to the left of the main window. To access the files listed on the left, just click on the file name.

GEdit has some additional features worth mentioning. Most of them are under the menu heading "plugins."

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_186_0.png)

Figure 10-3
GEdit.

If you need to know some statistics about a file, click “Plugins” and then “word count.” A small window will pop up and tell you the number of characters, words and paragraphs.

There are plugins for spell check, version control and browse (for HTML files).

A very useful feature of GEdit is “find in files.” This will search multiple files (whichever ones are open at that time) for a phrase or word. As an example, we took three files and searched them for the word constellation.

GEdit will split the window and then list the occurrences where it found the word or phrase it was searching for. It will list the file it found it in, plus the line number and sentence. It will also list total number of times it found what it was looking for.

If you make multiple errors in a file, you might find the “revert” feature under “file” useful. Revert will pull up the most recently saved version of the file you have been working on.

Because GEdit is an open source project, it is likely that even more features will be added to the program over time.

#### Opening and Saving Files in Gedit

To open a file in GEdit, just click on the “open” button. Using the pop up window, you can move around your directories and choose a file to open. Then click “ok.” Your file will be opened in a GEdit window and you can edit it. To work on a new file, just click “new.”

When you are through editing your file you will want to save it. If it is an existing file and you want to keep the same file name and format, just click “save.”

If you want to save your file under a different name, click “file” and “save as.” With the pop up window, you can give your file a new name.

There are no automatic file extensions in GEdit, you must type in the extension you want to use, such as .txt or .html. For example, if you opened a text file and then added html tags for use on a website, you would want to save it as html. Just use the “save as” window and give the file name an html extension rather than .txt.

## Fonts and Styles

As of this publication, GEdit will not allow you to use more than one font or style in a file. Though it’s possible this will change in future releases, GEdit is intended to be a text editor rather than a word processor.

To change the font that is being used, click “settings” and “preferences.” From the preferences window, click on the “document” tab. You will see the font listed that is currently being used. To change it, click “select.” From the font selection window, you can choose a font and its style, such as bold or italic. On the right, you can choose the size of the font. On the bottom of this window, you can see an example of what the font looks like and how large it will be. When you have selected a font, click “ok.” This will change all existing and future text to this selection.

### Spell Checking Your File

GEdit provides an easy way to spell check your file. Click “plugins” and “spell check.” GEdit will pop up a spell check window and list misspelled words as it finds them in the file. It will list a word and then list an alternative spelling suggestion. To the right are the actions you can take. If you want to replace the word with one of the alternatives, just click on the alternative and then click “replace.” If you want GEdit to accept the word as a correctly spelled word, click “accept.” If you want an incorrectly spelled word to just be ignored, click “skip.” If there are no alternatives, and you know the correct spelling of a word, click insert and type in the correct word.

You can set some preferences with GEdit’s spell check by clicking on the configuration tab of the spell check window. In the special configuration window you can specify minimum number of letters in a word to check, special characters in words to ignore (such as @ in e-mail addresses,) and other parameters.

## Finding Something in a File

It is easy to find a word or phrase in your file by using the find command. Just click on the find icon to bring up the “find” window. When the find box pops up you can type in what you want to search for. You can also check whether you want GEdit to search from where the cursor is, or from the beginning or end of document. You can also check whether or not you want GEdit to be case sensitive.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_192_0.png)

**Tip**
Linux is generally case sensitive. This means that Linux would see Ball.gif and ball.gif as two separate files. Most Linux applications make this distinction also. It actually comes in handy if you name all your directories with capital letters, as they will appear at the beginning of the list.
