The disconnect feature is simple—just click on it to disconnect from the site you're currently connected to.

The “send SITE command” option is a little more complicated. FTP sites operate using a set of commands which are mostly esoteric and generally not used by the common FTP user. FTP programs make use of these commands by “translating” them into the easier-to-understand commands and options that you see used in menu-driven or command-line programs.

Some FTP servers, however, have different subsets of commands that may not be used by your GFTP. If you're fairly knowledgeable about what commands are used by the server you're connected to, you can send a command recognized by the remote computer. This is accomplished by sending a SITE command. To send a SITE command, click on the send SITE command option. A little window will appear that asks you which command you'd like to send. Type it in and click on the OK button.

You probably won't need to use this command at all, but it can be useful at times.

## Bookmarks

This is probably the most fundamental of all of the drop-down menus in GFTP. You're going to be connecting to sites all the time when you use GFTP, and this menu will allow you to connect to various sites or add others to your lists. At the top of the menu are two options—one says “Add Bookmark” and the other says “Edit Bookmarks.” Below this is a list of all of the available bookmark folders and any stray items that you happen to have added.

When you click on “Add Bookmark,” you will add a bookmark to the site that you're currently connected to. If you want to add bookmarks to sites that you aren't connected to, or if you want to change the appearance of your bookmarks, you need to use the “Edit Bookmarks” option.

Figure 9-6 shows what the bookmarks menu might look like. I've taken the liberty of adding my own folder for personal bookmarks so you can see what it looks like. To create a folder or a new bookmark, you should click on the “File” drop-down menu. Click on “New Folder” to create a folder; click on “New Item” to create a new bookmark. You can delete either folders or items by clicking on them and then click on File and Delete.

When you click on “New Item” or “New Folder,” GFTP will ask you what you want to call the entry in the bookmarks list. If you create a folder, that’s as far as the process will go, but if you create a new bookmark, you will see the “Edit Entry” dialogue box.

This window is exactly the same as the “properties” window you can get from highlighting an entry and clicking on File and then Properties. This is why mine is already filled out; yours will be empty, except for the description.

This is a summary of the categories you see listed in this entry edit dialogue:

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_178_0.png)

- **Description** This is the name that you give to the entry and how it will appear in the list of bookmarks.
- **Hostname** The hostname is the actual FTP site, like ftp.cdom.com or ftp.redhat.com or something similar. These names can be literally almost anything.
- **Port** You normally don’t have to change this or put an entry in unless the FTP site you’re trying to connect to uses a special port. An FTP port is similar to the more familiar boat port or space dock. It’s where your FTP program can establish a connection to an FTP server and send or receive data.
- **Protocol** This is either FTP or HTTP; if you’re accessing a web-based FTP site, use HTTP; otherwise you should use FTP.
- **Remote Directory** If you want to enter a specific directory on the server every time you connect, you should fill in the full path name here.
- **Local Directory** The local directory is the directory that you want to enter every time you connect to this FTP site. If you connect to a specific FTP site to upload documents or something similar, you might want to be in your documents directory, for instance.
- **Username** If you have your own FTP account on this site, you should put in your username. If not, leave this blank.
- **Password** If you have an account, you must access it with a username and a password. Make sure that you put in the password for your user if you have an account.
- **Account** You can leave this blank—it's not important to logging in. Fill this area in if you are directed to do so by the administrator of the FTP site you want to connect to.

If you don’t have an account on the FTP site you want to connect to, enable the “Log in as ANONYMOUS” option. This will send the site a username of anonymous and your e-mail address as your password. If the site doesn’t support anonymous FTP access, you won’t be able to log in unless you have an account.

## Logging

At the bottom of your GFTP main screen, you’ll see a small notice from the author of the GFTP program, Brian Masney. This is the *log file*. You can either read it in that small window (which serves to show you what commands are being executed on the local and remote computer and to report errors) or from the logging submenu.

There are three different options under the logging submenu. You can either view the log, save it to a file, or clear the log. When you clear it, the contents are deleted and you cannot retrieve them.

## Transfers

To send and receive files, you can use the transfers menu. Highlight the file you wish to send or receive. Then click on transfers. If you wish to retrieve a file, click on retrieve; if you wish to send a file, click on put.

When you begin a transfer, the transfer progress will be noted at the bottom of the screen in a dialog box. If you wish to stop a transfer, click on the transfer progress line to highlight it. Then click on transfers and click on stop.

## Tools

If you want to compare the difference between the remote computer file listing and the local computer file listing (helpful if you're transferring web page documents to another server and have lost track of which you've sent, for instance), click on tools and then compare windows.

## Other Programs

Many other Internet services exist, and a corresponding number of programs are available to make use of them. If you are interested in Internet Relay Chat (IRC), for instance, you can use the program xchat to chat with other people across the world. There are other less-used services such as gopher that you can find programs for if you're interested.

As it is, you'll probably end up using Netscape and GFTP more than the other programs available (unless you're like me and really like Opera). You'll be able to find other Internet applications from the Internet itself and using GnURPM, so don't be bashful about installing new ones. Most of them are simple to use and have clean interfaces that may be modeled on more familiar Windows programs.

Another helpful facet to most applications for Linux in general is that authors maintain numerous web pages about their products. You can usually find this in the About section in the help menu (see, for instance, GFTP). If you ever have trouble using or setting up an application, you can go to the web page and read the frequently-asked questions (FAQ) or even e-mail the authors for help.

# CHAPTER 10
Text Viewers and Editors for Linux

There are times when you don’t need a big full-featured word processor to write a simple text file. There are a number of very good text editors, some of which have some very useful features. It’s a matter of personal preference as to which one you use. Since some of these programs have the same features, we thought it would be convenient to define what they are at the beginning rather than be repetitious.

## Common Editor Features

- **Open**—opens a file, generally limited to .txt and .html files.
- **Save**—saves the file you currently have open.
- **Save as**—will allow you to save the file under a different file name.
- **Close**—closes the file you have open. Most programs will prompt you to save any changes you have made.
- **Exit**—closes the entire program and all opened files. You will be prompted if there are any unsaved changes to files which are open.
