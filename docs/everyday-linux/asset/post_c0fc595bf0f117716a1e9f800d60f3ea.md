From your Star Office desktop, click "file," "new," and "database." The Properties of Database window will pop up.

There are four tabs at the top of this window. The first tab is general properties and where you will give your database a name. Type the name into the field provided under general.

Click on the “type” tab to select the format you want to use for the new database. Though there are several formats for databases, we are going to use dbase in our examples. Select dbase from the “database type” field and then below that, specify which directory your database will reside in.

**TIP**

Once you choose a type of database (dbase, ODBC etc) you will see the third tab in the window change to the format you choose.

Click on the "dBase" tab to choose settings for this type of database.

The first option is to toggle on or off the setting for "Display inactive settings." You will not need to check this if it is the first time you created a database in StarOffice. What this does, if toggled on, is to show old records marked for deletion. Although StarBase never actually deletes old records, it will mark them as inactive.

The second option is to toggle on long table names. In old versions of windows (and DOS) a filename could only be eight characters or less. If you want to use longer table names, toggle on this option.

Beneath the above two options is an option for character set. Unless you have a specific need to change this, leave it set for the default.

When you are done providing the information you need to, you will be able to click the "OK" box from the dialogue window. Then your new database will be created. It will not be of much use yet, since you have not created something to put data into. The next thing you will want to do is create a table.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_240_0.png)

> Remember, we are using examples for a database done in dBase format. If you choose one of the other formats, there may be other information you will have to provide before the database can be created.

### Creating a Table using the Table Design Tool

All of your information is managed through tables. Each table contains a series of fields and records. Suppose you are creating a database of your postage stamp collection. You might have fields for stamp number, country of origin, condition and value. Each stamp is entered into its own record. When you clicked "ok" at the end of the "Database Properties" window described above, a screen came up on the desktop with four icons, one of which was "table."

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_240_1.png)

**Figure 13-17**
*Creating the New Database.*

Right-click over the table icon and select "new," then "table" and then "table design."

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_241_0.png)

**Figure 13-18**
*Table Design.*

In the first column (under "fields") type in the name of the field. We'll call ours "stamp" for our stamp collector's example. We will choose fields called "stamp," "issued (for date issued)," "country," "condition," "topic," and "value."

> **TIP**
> The name of the field cannot contain spaces, and it cannot be over ten characters in length. The Table Design tool will not allow you to type a space or a longer name.

Under "field type" you need to tell the program what type of data you will enter in this field. The "stamp" field will have text, the "issue" will have a date, as will value, the other fields will have text. You select the field type from the drop down box in that box.

For each field you have the option of setting a maximum length for each record, default value, and an example of the format which should be used.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_242_0.png)

**Figure 13-19**
*Designing the Table.*

The last thing you should do as you are creating your table is type something under the fourth field “description.” It is a good idea to do this because the field name alone may not give a good description of what is in the table. You may not remember a few months from now if you work with a lot of tables.

Finally, save the table by clicking “file” and “save.”

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_242_1.png)

> **Tip**
> You may also create a table by using AutoPilot. Right-click over the table icon and select “new,” then “table,” and then “AutoPilot.” You need only follow the directions to create a table.

### Importing a Table

It is very easy to import a table from an existing database. You need only copy the file to the directory where the database you want to use it in resides. The table will automatically be added to the table list.

### Adding Data to a Table

When you are ready to add data to your table you will need to open the explorer window until you can see your list of databases. Under each database you will see icons for forms, reports, queries and tables. If you already have created the tables, then there will be a small plus sign to the left of the tables icon. Expand the list by clicking on it.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_243_0.png)

**Figure 13-20**
*Selecting the Table.*

On the right, you will see the names of the tables in that directory. Select the one you want to use in your database and double-click on that table's icon.

Click on the record (you more likely would call this a cell) which you want to edit and then enter your data.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_244_0.png)

**Figure 13-21**
*Entering Data.*

Move around your table by using the tab key. A new row is added as soon as you enter data into the first record in a row.

When you are finished adding data, click "file" and "close." Answer yes when you are asked whether you want to save changes.

### Editing and Deleting Data

No one is perfect and it is only a matter of time until you have the need to change or delete data in a record. Fear not, it is a simple thing to do.

To edit data in a record, simply click on that record. The contents of that record will be highlighted.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_245_0.png)

**Figure 13-22**
*Editing Data in a Record.*

If you want to change everything in that record, just begin typing. If you only want to change one character, double-click on that record and then move the cursor around and make your changes.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_245_1.png)

> **TIP**
> All the basic commands, such as Cut, Copy and Paste will work just as easily in your table as they do in a document. This can make it much easier to replicate data.

To delete the contents within a record, click on the record and it will be highlighted. Then right-click over it and choose "cut." The contents of the record will be cleared.

### Changing a Table's Appearance

When you use StarCalc's spreadsheets, you can make them look exactly as you like them, even flashy if that is what you desire. When you are working with databases however, you can only change a few things about the tables you create.

Once you open a table for editing, right-click over one of the buttons to the left of the row and choose "table format."

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_246_0.png)

**Figure 13-23**
*Table Format.*

This window will allow you to change the font, the font size and font attributes such as underline, bold, italics and others.

You can also change the row height by right clicking on the button on the left of the row and choosing "row height."

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_247_0.png)

**Figure 13-24**
*Changing Row Height.*

When you change row height, it changes it for every row in the table so remember that increasing the height will take up a lot more space.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_247_1.png)

> **Tip**
> The default for row height is "automatic." You will have to uncheck this box if you want to set your own row height. When you uncheck automatic, you must remember the row will not adjust to a larger or smaller font size, you will have to do that yourself to make it fit.

You can format a column by right-clicking over the button at the top of the column and choosing "column format."
