# **The File Hierarchy Standard**

The File Hierarchy Standard, or FHS for short, is a system that standardizes the names of certain directories that contain important information. The computer industry requires more than a little standardization to make up for the differences in education of its members. By standardizing where most of the major files go, all systems administrators regardless of educational background or understanding of Linux or UNIX have a specific map of where files need to go.

This provides newer administrators a guide by which they can plan the lay-out of a system; older administrators will appreciate the regularity of the standard.

The standard itself is quite lengthy and complicated. We'll include a brief summary of it here, however, and supply further references for your perusal.

+   - /bin The /bin directory contains program files that are available to all users. These are typically considered “essential.”

+   - /boot The /boot directory contains static files used by the boot loader. You may want to create a partition for this directory when you install your system—it will add a little extra protection for these files.

+   - /dev All of your device files are stored in the /dev directory. These range from hard drives, to SCS1 devices, the CD-ROM, floppy drive, and many, many others.

+   - /etc The FHS calls this directory “Host-specific configuration information.” It’s where most of your configuration files that are used for the system are stored. Both _conf and _rc files are located in this directory. These are usually global configurations.

+   - /etc/X11 Your X-Window System configuration files are stored in this directory.

+   - /etc/opt When you install commercial programs, their configuration files are stored in this directory.

+   - /home User directories are stored in the /home tree. This is labeled “optional” in the FHS, but most users of Linux prefer to have one. If you have a single-user system, you may not wish to include it.
