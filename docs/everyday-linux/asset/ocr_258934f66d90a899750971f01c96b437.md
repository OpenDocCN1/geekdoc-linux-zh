The printer queues list tells you which printers you have installed on your system and what device they print to. In this case, I have an HP DeskJet 710 Series printer installed on the system. The letters PPA stand for Printer Port Architecture, and it is a proprietary printer driver that was not supported until very recently. This is an example of a printer's software drivers being made available for use with Linux, even though they were restricted to use with Windows.

More than likely your dialogue box will be empty—there won’t be any installed printers. So the first thing you need to do is actually add a printer. Click on the add button to do so. When you do, a new window will appear. From this window, you should simply add a local printer, unless you’re trying to configure a networked printer. If that’s the case, you should talk to your systems administrator about how to configure a networked printer. It will require a number of settings.

When you click on the “Add” button, this is the window that appears. You’ll notice that “local printer” is depressed. If you need to connect to a networked printer, you should check to see what kind of system is running the printer. If it is a UNIX system, use the “Remote UNIX” option. If it’s run on a Windows NT or Windows 95/98 machine, choose “SMB.” (SMB stands for “Samba,” which is a program that allows you to interface with Windows printers.) If you are on a NetWare network, choose the NetWare printer. Make sure to ask your network administrator for help if you’re going to configure a networked printer.
