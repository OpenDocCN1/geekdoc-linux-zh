# GNOME

Now that we've finished the basic configuration of your system and logged in using a personal account, it's time to start personalizing your experience with Linux. At the moment your desktop looks pretty sparse and bland, nothing to be excited about.

In the course of this chapter, you will learn how to make use of the various themes that come with GNOME and your window manager, Enlightenment. We'll have the desktop looking much more spruce than it does now.

We're also going to learn how to add application launchers to the desktop and how to make good use of the panel at the bottom of your screen. We'll even add one if you'd like, and customize the one you've already got running.

But first, you need to know more about exactly what GNOME is.
