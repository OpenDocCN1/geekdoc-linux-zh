In order to install these programs, you will have to read the information that they provide with the package. To get this information, you have to unzip the file, and if it is tarred, untar the file as well. You can do this quite easily from the command line.

You usually download files from the Internet into your home directory. (This is not always the case, but it’s a safe bet.) When you hit the terminal icon on your panel, you immediately enter your home directory. If the files are located in your home directory (typing ls -l more will produce a paginated file listing), you should type gunzip filename, where “filename” is the file that you downloaded. It will then display the files it is extracting.

If it extracts a file with a .tar extension, that file has been made by the tar program. You should type tar xvf to untar the archive. It will probably make its own directory with the files in it. If you start Midnight Commander (type mc), you can more easily navigate the file system. Mind the new directory created when you untarred the file and look for a file in this directory called INSTALL (all caps). It will provide you with installation instructions.

These instructions vary from program to program; the quality varies as well. Usually you can find frequently asked questions (FAQs) on the Internet that will provide you with some extra help if you need it.

# Using GnoRPM

GnoRPM is usually much easier to use than the command line interface. For starters, it includes a number of easy-to-use features. If you want to install a specific package from your installation CD (all of the RPMs that came with your original Linux distribution are on that CD), it’s a simple point-and-click process. If you realize that you never really use a package and don’t want it cluttering up your computer anymore, you can remove it easily, too. And perhaps you know the full name of a command (both the path and the command name) and want to find out what package it belongs to—you can do that too. In addition, each package has a built-in set of information containing a short description of the package, its size in bytes, and a complete listing of all the files included in the package. GnoRPM also comes equipped with what is known as “Web Find,” an option that will search RPM databases on the web to find specific packages that you search for.
