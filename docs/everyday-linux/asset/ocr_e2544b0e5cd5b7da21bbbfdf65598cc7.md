Once the files are unzipped, type in this command:

```
`./Runme`
```

Corel\u0027s installation will now take over and windows will pop up asking you if you have unzipped the files and if you understand the license agreement (that it is for noncommercial use, etc.). It will also ask you where you want to install the program. We recommend that you install WordPerfect in /usr/local/wp8. You will also be asked about installation size. You may choose between a full installation (61–70 megs), or a medium or minimum size install. If you have enough available disk space, we recommend that you do the full install unless you plan on making StarOffice your primary word processor.

Once you have answered all of the installation questions, a window will appear that will follow the progress of the install by telling you what percentage has been completed.

# ## Running WordPerfect 8

You can either start WordPerfect 8 from a command line, or you may make a launch button for gnome. Under command, type this:

```
`/usr/local/wp8/wpbin/xwp`
```

Be sure to change the file path if you have put WordPerfect in some other place.

# ## WordPerfect Control Window

When you run WordPerfect you will have two windows pop up. One will be what I refer to as your work area. This is where you will work on or create a doc-ument. Unlike StarOffice, WordPerfect opens up a new work area window for each open file. Some users find this method of multiple work areas useful because it makes comparing or cut and paste a bit easier.

The other window that opens up is what I refer to as the WordPerfect con-trol window. The control window has four choices across the top: program, pref-erences, window, and help.
