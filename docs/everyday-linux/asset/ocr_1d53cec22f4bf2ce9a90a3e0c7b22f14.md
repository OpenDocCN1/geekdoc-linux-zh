# ### Sorting Data

Perhaps the most important function of a database is to sort the data. When you add new records to the database, they are added at the bottom of the table and will need to be sorted with the existing records.

You can sort data using one of the fields as the key. For example, in our stamp collection, suppose we want to sort data according to country. We can do this alphabetically either in ascending (A to Z) or descending (Z to A) order.

Just click on the field button at the top of the column to highlight the entire column and then click either the "sort ascending" or "sort descending" button.

You can do more complex sorting if you click the "sort" button, a button with a "Z" over an "A" to the right of the previously mentioned sort buttons. This will open the sort dialogue box.

Using this box you can set a sort for several fields.
