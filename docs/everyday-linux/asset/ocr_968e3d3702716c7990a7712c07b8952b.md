When you click the okay button, a new window appears that tells you which ports Linux could find a printer on. If it cannot find any, you won't be able to install a printer. This may be an indication that you didn't install the printer support component during the installation, or of a more serious hardware problem.

After you click okay on that window, the printer editor dialogue box will appear. The one that you will likely have to change to get your printer to work properly with Linux is the *Input Filter*. If you click on the input filter button a new window will appear, as shown in Figure 5-7.

The input filter allows you to select a printer driver for use with your printer. A list of drivers appears on the left. You should choose the driver that most closely matches the printer that you own. Once you pick the appropriate driver, you should set the settings available on the left.
