
Each of these users also has a certain access level to any given file, as determined by the owner of the file.

## The Permission Bits

Each classification is assigned certain permission bits. The three permissions assigned to a file or directory in each of the three classifications are the read, write, and execute bits. If the read bit is enabled, access is granted to view the contents of a file. If the write bit is enabled, access is granted to either create a file (in the case that write access is granted in a directory) or modify it (in the case that write access is granted on a file itself). If the execute bit is enabled, access is granted to either enter a directory or run a program.

A combination of these three bits is assigned to each user classification to define who has what access to a file or directory. An owner, for instance, might be given both read and write permission, while his group has only read permission and everyone else is denied read and write permission.

## Practical Application of Groups and Permissions

If you haven’t guessed already, groups and permissions allow you extensive control over who can view files. Most Windows users don’t realize this, but their files aren’t remotely secure (unless you use an encryption program or password protect your documents). They’re openly available to anyone who uses the computer.

Under Linux, you can more or less dictate who has the permission to look at your files. You can also organize users into various groups. This has a lot of practicality in the event that your system is quite large and needs to classify people according to groups. For instance, college students on computer machines at school are frequently placed in different groups than graduate students and faculty. Administration staff, as we already pointed out, are often placed in a separate group from regular users.

## The Root User

One of the main concerns, whether you’re very experienced with Linux or not, should be the root user. The root user is incredibly powerful, because the limits imposed by groups and permissions don’t apply to him. This means that the root user can change permissions for any file, read any file, write to any file, and execute any program on the system.

The root user is sometimes called the “superuser” because users in the group wheel can become the superuser by using the su command. The root user handles almost all of the maintenance tasks for the entire system, such as making any hardware upgrades, most software upgrades, creating users and removing old ones, configuring hard drives, setting up network devices, and so on and so forth.

When we look at basic systems administration, we’ll go over some of these topics in greater detail.

## Shutting Down the Computer

Only the root user or a user with appropriate permission can shut down the computer.

The reason that we mention this now rather than elsewhere in the book is because many readers will stop reading at some point and decide to either explore the system on their own or will want to go to bed and turn off the computer. Doing so improperly can have poor effects on your computer.

The basic procedure for shutting down your computer is as follows. First, log in as the root user, using the username of “root” and the password you specified during the installation process.

Click on the stylized foot at the bottom of the screen and then click on logout. But instead of using the regular “log out” option, you should choose “Shut down.” Then click okay and your computer will halt.

It’s important that you never shut down the computer by simply pressing the power button. This can damage your hard drive and floppy disks in your floppy drive. Always make sure that you shut down the computer using the procedure outlined here.

### What Is GNOME (and What Are Desktop Systems?)

GNOME stands for "GNU Object Modeling Environment." GNOME is a desktop system for the X-Window System. Many other desktop systems exist, but GNOME has moved to the forefront of the available options because of its usability and technical capabilities. (When you had the chance to install various components, you could've chosen KDE instead of GNOME. KDE is another desktop system.)

GNOME is one of the first desktop systems to catapult Linux to a more user-friendly level by combining features of both the Microsoft Windows and the Macintosh operating systems.

A desktop system is a program that the X-Window System uses to organize various shortcuts and programs. Desktop systems come with different features. GNOME, for instance, comes with "paneling" (among other features). Panels are much like the Windows 95 Start bar that shows a list of your running programs. It is important to realize that the desktop system controls a variety of features. One of the more common and useful features employed is the "drag-and-drop" feature, which allows you to move a file from your file manager to the desktop simply by clicking on it and dragging the icon to the desktop. This feature is fairly commonplace in widely used operating systems, but until recently, Linux did not support this feature. It was inconvenient at best and incredibly aggravating.

The desktop system also controls how the desktop looks by using desktop themes. There are separate themes in Linux for both desktops and windows; this is a big change from Windows, which uses the same theme to control the look and feel of both the desktop and your windows.

Red Hat Linux also comes equipped with a number of window managers in addition to the GNOME desktop system.

### What Is a Window Manager?

A window manager is a program that manages the look and feel of the windows open on a desktop. The default window manager for Red Hat is called Enlightenment. Others exist; among these are After Step and Another Level.

Enlightenment is the most popular, mostly due to its adaptability and ease of use.

We'll look at configuring Enlightenment later in this chapter. Among the items we'll look at are various window themes, desktop backgrounds, how your windows will act, some special effects, sound, and shortcut options that bind some mouse clicks to the keyboard.

You should not confuse window managers and desktop systems. A desktop system manages your *desktop environment*. A window manager controls how the windows look and act when you interact with them.
