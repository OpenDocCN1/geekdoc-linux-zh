
## LILO Configuration

LILO stands for “Linux Loader,” and it is the program that Linux installs in the master boot record (MBR) which loads Linux. (Hence the name “Linux Loader.”) However, LILO will also boot to other operating systems like Windows or MacOS.

Typically, you want to install LILO on the primary master drive’s boot record so the drive you specify should be hda. If you are dual booting using two physical hard drives, LILO may give you occasional problems. If that happens, you can simply reinstall Windows or your other operating system and make use of the boot disk that you’ll create during installation.

If that sounds like a hassle, you should simply not install LILO and use the boot disk instead.

If you are booting from a single drive or single booting, it is highly recommended that you use LILO. You can usually leave the information in this screen at the defaults, so you probably won’t need to change anything.

## Network Configuration

The next step is to set up any network devices that are present on your system. If you don’t have any, you won’t see this step, but if you use a device like a network card, Linux will probe for it and see what settings it should use.

Normally the default settings will work just fine, since most companies will assign you information using a DHCP protocol that simply assigns you information dynamically, instead of statically. If you’re not sure what to put in here, you should call either your network administrator (if you’re on a LAN) or your Internet Service Provider to see what settings they recommend.

Generally, you’re fine using DHCP and clicking Next.

## Time Zone

This is a fairly explanatory step. The only complication that could arise is if your computer sets itself to GMT (Greenwich Mean Time) and adjusts the time for your specific time zone. If it does, you should work with the UCT tab instead.

To set your time, you can simply navigate the map on your screen (it will not appear if you’re using the text installation) and click on which time zone you use. If the time on your computer is already set using the BIOS, Red Hat will attempt to guess what time zone you’re in. It’s usually pretty accurate.

## Account Configuration

The next step is to configure your account and the root user account. You will first have to specify a root user password. The length of the password must be greater than five characters for it to be valid, and you will have to type it in twice.

You must then add an account for yourself. (Well, you actually don't have to, but it'll save you the hassle later on.) Near the middle of the screen is a form for you to fill out; simply supply a username, a full name, and your password, and the installation program will add the account for you. You should pick a username that is composed of your name; outlandish names or pseudonyms for mainstream Internet purposes are usually looked down upon. Suggestions would be a first initial and your last name, your three initials, or your first name and a last initial.

Make sure to write down the root password so you won't forget it. If you forget the password, you won't be able to do any administrative tasks on the system (such as adding additional users, mounting drives, and so on) until you reset it in single-user mode. Once you're sure that you know the root password, you should make sure that you destroy the paper that you wrote it down on. The root user is completely unrestricted and can cause irreparable damage to your system, so you don't want the password falling into the wrong hands.

## Authentication Verification

You can usually leave these settings at the defaults. They'll provide you with the maximum security on your system. If you are on a network and you're not sure if your network takes advantage of the NIS server, you should ask your network administrator for assistance.

## Selecting Components and/or Packages

Now comes one of the longer parts of the installation. To fully customize your computer, you can choose software components or specific software packages to install on your computer.

A component differs from a package insofar as it is *composed* of packages. I will not be describing specific packages—if you desire to choose specific packages, which will help you trim space if you're running low or don't want some programs installed, you can find out about the individual packages by yourself. If you want to choose specific packages, click on the “choose individual packages” button at the bottom and click the Next button.

Here is a sample component list with my commentary about why you would want to use each of the components:

-   **Printer Support** Printer support will be necessary if you have a compatible printer to use with Red Hat. (If you’re not sure, you should consult the Red Hat web page for compatibility lists.) If you want to use a printer with Red Hat, check the box.
-   **Mail / WWW / News Tools** These tools will allow you to send and receive e-mail, browse the web, and read online newsgroups. You should include this component if you’re going to be using the Internet.
-   **Graphics Manipulation** This component will supply you with plenty of goodies. Users that view or edit graphics files (.gif, Jp(e/g, .tif(f), and so on) will want to include this component.
-   **Networked / Dialup Workstation** If you are planning on connecting to a network through a network interface card (NIC) or through a dialup (this includes the Internet, not just local area networks), you should check the component that matches your setup. (Networked workstation for LANs, dialup workstation for computers that aren’t on LANs.) If you’ll be connecting both ways, install both components.
-   **SMB (Samba) Connectivity** If you are a Linux user on a local-area network (LAN) that is composed of multiple platforms (such as Windows95, Windows98, etc.), you will probably need to print to printers on Windows machines. If this is the case, include this component.
-   **IPX / Netware Connectivity** If you are on a local-area network powered by Netware, you will want to include this component.
-   **Development** If you plan on writing programs on your Linux machine, you should click on the *development* component. This will allow you to program in such languages as Perl, C/C++, Python, TCL, and many others.

If you don’t want to fool around with any of the components and have plenty of hard drive space, you can click on the “Everything” option to install all of Red Hat Linux on your computer. This kind of defeats the purpose of customization, though.

**Note**

Some packages require others to run. If you select individual packages and do not include all of the necessary packages, Red Hat Linux will inform you that you have *package dependency errors*. Fortunately, it will also resolve these issues for you.

## X-Window System Configuration

You now have to set up your computer for use with X-Windows. You will first be provided with a list of monitors.

It's important that you pick the right monitor from the list. Different monitors have different *refresh rates* which determine how often the image on the screen is updated. The higher the resolution, the higher the refresh rate, normally. Low refresh rates on high resolutions will make your screen flicker. But if your refresh rate is too high, you can cause your monitor to overheat and burn out the picture tube. The monitors in the list all have specifications pre-assigned to them from the manufacturer of the device, so you won't damage your monitor if you choose one. If it's not on the list, have Linux probe your monitor for its refresh rates. If it cannot find any, check in the manual for your monitor to see what refresh rates it suggests.

After you select your monitor, you will need to select your graphics card. Pick this from the list. You will also have the opportunity to customize the resolution used in X-Windows. To do so, click on "customize" in the graphics card settings window.

You will also have the chance to start the X-Window System to see if the monitor settings have taken effect and are right. If you're confident that they're okay, you can skip this step.

## About to Install

The installation program is about ready to install the operating system on your computer. Click "Next" to begin.
