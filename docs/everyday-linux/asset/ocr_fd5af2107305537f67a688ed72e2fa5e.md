So that is what the command line *is*. What you can *do* with it is another matter entirely. You interact with your computer using the command-line interface; when the cursor sits there calmly blinking in silence, the computer is asking for some instruction. These instructions are given in the form of commands. Each command is assigned a name and performs a specific task. You'll find commands that control your file listing, modifying files, removing others, creating text documents, comparing one file to another, and so on and so forth. You'll find programs that will tell you about running programs, disk size, and myriad other administration activities. You'll find programs that will assist you in navigating the filesystem or with finding other commands. The list is nearly endless, and so are the capabilities of the command line.

# How to Use the Command Line

When you click on your terminal icon on the panel, a new window will appear with a prompt at the top that looks something like this: `[ emetser@ localhost] ~ $` . This is known as the *command prompt*.

You interact with the command line by typing in commands at the prompt. Since we've worked with the installation of Linux and a few of its many facets, you've used the command line for a variety of purposes. You've used the command line to set up the modem and your soundcard, for instance.

Now it's time to become familiar with a few of the more common commands used in Linux. These won't make you a classy systems administrator or a UNIX guru, but you'll be able to navigate your system much more proficiently.
