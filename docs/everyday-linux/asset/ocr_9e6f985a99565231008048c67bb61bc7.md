# **A List of Commands (cont.)**

| Command Name | Options | Description |
| :--- | :--- | :--- |
| cat | [filename] | This stands for “concatenate,” and this command will output a file to the screen. |
| cd | [directory] | This stands for “change directory.” Self-explanatory. |
| cp | [source] [destination] | This command will copy a source file to its destination. This destination can be either another file or a directory. (If you specify a directory, the file-name will remain the same.) |
| df | | “df” stands for “diskfree”; this command will provide a sum-mary of how much space is free in each partition on your hard drive. |
| du | [directory] | “du” stands for “disk usage,” and it tells you how much space on a hard drive that a particular directory and its subdirectories consumes. |
| elm | see elm man page | This is a text-based e-mail pro-gram with a number of fea-tures. It’s highly functional, though not as user-friendly as other programs. |
| emacs | [filename]; see emacs man page | Emacs is a reasonably user-friendly and very powerful text editor. |
| find | see find man page | Find is a convenlent utility that will search for files on a speci-fied path and filespec. |
