# Shisen-Sho

Shisen-Sho looks quite similar to Mahjongg and uses the same set of tiles. The goal is to remove all the tiles by clicking on like pairs with the mouse. Tiles may be removed if they can be connected with no more than three straight lines. More documentation may be found by choosing “help” on the Shisen-Sho screen.

# Snake Race

Those who do not suffer from herpophobia will enjoy guiding the ever growing-snake around the board, munching on the fruit. The object is to eat all the fruit without running into walls, the evil red ball, or yourself (and as the snake grows this gets pretty tricky!). There are several skill levels to choose from. Guide your hungry snake by using the arrow keys.
