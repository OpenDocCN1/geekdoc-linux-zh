Also, by default, StarWriter saves a document in the desktop's work folder. You can specify a different default directory in options. To learn how to do this, check the Star Office Introduction and see “configuring options.” You can move around directories to get to wherever you wish to save your document.

While you are working on your document you may save new work at any time by clicking on the floppy disk icon at the top of the window. If the floppy is grayed out, it means that there is no new data to save.

You will also want to use the “save as” feature if you are working on an existing document and wish to save it under a different file name.

# ## Spell Checking, Find and Replace, Cut and Paste

There are several ways that you can check spelling in a document. You can wait until you are through writing a document and then click “tools,” “spellcheck,” and “check.” When StarWriter checks a document like this it will scan through the entire document and then bring up a spellcheck dialog window when it finds an error.
