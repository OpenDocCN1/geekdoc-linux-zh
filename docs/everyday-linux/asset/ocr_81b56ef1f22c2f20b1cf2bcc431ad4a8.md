# Creating a Presentation Using Auto Pilot

To begin a new presentation using Auto Pilot, click “file,” then “auto pilot,” and then choose “presentation.”

In this window you can choose to start from scratch, from template, or from an existing presentation. We chose “empty presentation” because we wanted to create one from scratch. Click on that box and then click “create.”

Here you choose a page style for your presentation. You can choose from a number of background styles, or plan if you do not want a background. Below that you need to choose whether your presentation is going to be in slide, paper, overhead, or screen format. If the preview button is not checked on the right, click on it to see a preview of the different styles. After you select one, click “next.”
