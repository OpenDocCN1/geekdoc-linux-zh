# The Root User

One of the main concerns, whether you’re very experienced with Linux or not, should be the root user. The root user is incredibly powerful, because the limits imposed by groups and permissions don’t apply to him. This means that the root user can change permissions for any file, read any file, write to any file, and execute any program on the system.

The root user is sometimes called the “superuser” because users in the group wheel can become the superuser by using the su command. The root user handles almost all of the maintenance tasks for the entire system, such as making any hardware upgrades, most software upgrades, creating users and removing old ones, configuring hard drives, setting up network devices, and so on and so forth.

When we look at basic systems administration, we’ll go over some of these topics in greater detail.

# Shutting Down the Computer

Only the root user or a user with appropriate permission can shut down the computer.

The reason that we mention this now rather than elsewhere in the book is because many readers will stop reading at some point and decide to either explore the system on their own or will want to go to bed and turn off the computer. Doing so improperly can have poor effects on your computer.

The basic procedure for shutting down your computer is as follows. First, log in as the root user, using the username of “root” and the password you specified during the installation process.

Click on the stylized foot at the bottom of the screen and then click on logout. But instead of using the regular “log out” option, you should choose “Shut down.” Then click okay and your computer will halt.

It’s important that you never shut down the computer by simply pressing the power button. This can damage your hard drive and floppy disks in your floppy drive. Always make sure that you shut down the computer using the procedure outlined here.
