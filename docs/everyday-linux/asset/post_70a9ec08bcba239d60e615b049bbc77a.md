## Playing Heroes III

Heroes III puts an entry under games in the GNOME directory.

![img/92fb6d8ad19de3b3470ba95c7b71b82e_386_0.png](img/92fb6d8ad19de3b3470ba95c7b71b82e_386_0.png)
Figure 20-32 Starting Heroes III.

Just click the GNOME foot and then go to "games" and "Heroes 3" Remember, you will need the Heroes III CD in the CD-ROM before you can play!

When the opening screen of Heroes comes up, you will have the option of starting a new game, loading a game, seeing the high scores or quitting.

![img/92fb6d8ad19de3b3470ba95c7b71b82e_387_0.png](img/92fb6d8ad19de3b3470ba95c7b71b82e_387_0.png)
Figure 20-33 Heroes Opening Screen.

Click on single player. We suggest if you are new to the game that you then choose tutorial to familiarize yourself with it.

When you choose tutorial from the Heroes menu, one of the first things it will ask you to do is print out the tutorial document which can be found in the directory where you installed the game.

![img/92fb6d8ad19de3b3470ba95c7b71b82e_388_0.png](img/92fb6d8ad19de3b3470ba95c7b71b82e_388_0.png)
Figure 20-34

The tutorial will guide you through learning how to play the game, such as controlling armies, using spells and weapons and moving about. We don't suggest trying to figure this one out by yourself unless you are very talented at learning games without reading about them first. The manual which comes with the game also provides a good amount of information.

When you are ready to play the game, you will have a choice between single scenario, multi-player or campaign mode.

Single Scenario mode is played with one map against the computer. You are given a set of mission conditions and the winner is determined by who meets those conditions first.

Multiplayer mode allows you to play against other humans on one computer, over a network or even over the Internet.

Campaign mode are a series of linked scenarios marking climactic events in longer stories. Campaigns are played against the computer.

## Scenario Selector

Before you start either a single player or multiplayer game you must choose which scenario you want to play and how difficult you'd like the game to be. You do this by using the Scenario Selector.

![img/92fb6d8ad19de3b3470ba95c7b71b82e_389_0.png](img/92fb6d8ad19de3b3470ba95c7b71b82e_389_0.png)
Figure 20-35 Scenario Selector.

By clicking on "show available scenarios" you can see the entire list of all the scenarios you have to choose from. You will also see a description of the scenario. Towards the bottom of the Scenario Selector, you will see "player difficulty." The default is normal, you can set it for easier or more difficult.

In this window you will also see the flags of your allies and the flags of your enemies. You will also see the conditions for victory and loss.

When you have made your scenario choices, click "begin" to start the game.

## Turns at Play

On each "day" of the game, you can move your players and take certain actions. Each player takes a turn. If it is human versus computer, the computer will take a turn after the human. As you gain control of areas, they are added to your resources. The resources represent gold and raw materials which you may spend to improve areas under your control. The current date appears at the lower right corner of the Map screen.

## Learning the Game

As we mentioned earlier, it takes time to learn a game. Using the tutorial helps and so does reading the manual. The more you play, the better and more familiar you become with the game.

## Resource List

![img/92fb6d8ad19de3b3470ba95c7b71b82e_392_0.png](img/92fb6d8ad19de3b3470ba95c7b71b82e_392_0.png)

This resource list will cover several different areas of resources. As stated in the introduction, this resource list is designed to point you to places you can go in case you run into a problem whose solution isn't found in the pages of this book. Believe it or not, it happens. It additionally will point you to some pages that we looked at to research information we found in this book, so you can find more details if you want to investigate further.

There are several sections to the resource list. In the *General* section, you'll find Linux-specific search engines, projects related to Linux (such as GNOME or the GIMP), and home pages for Linux distributions. The *Maintenance* section will point you to several web pages and FTP sites that will allow you to download Red Hat packages or otherwise archived files for upgrading your software. In the *Visuals and Entertainment* section, we point you to a few places you can download various themes or play some games. The *Documentation* section includes sites that house help files, HOWTOs, and Frequently Asked Questions concerning Linux. It's also going to have a few documents *about* Linux and Open Source as well. We included the *Miscellaneous* section to provide you with some general-purpose help with computers.

Each of the resources listed is followed by either some commentary, a description, or both, just so that you know what you're getting into when you access it. They're organized alphabetically in each category, so you can find what you're looking for reasonably quickly.

### General

- **http://gedit.sourceforge.net**
  If you want to get some information, updates, and help with GEdit, a powerful editor made by the folks at GNU, you should visit this website.

- **http://www.corel.com**
  Users of the WordPerfect word processing program or Corel's version of the Linux operating system will probably want to visit this page periodically. Corel releases versions of WordPerfect for Linux one or two versions behind that of its office suite. It's a hefty download, but it is free of charge.

- **http://www.debian.org**
  *Debian* Linux is another popular distribution of the Linux operating system. There are warring factions in the Linux community dedicated to seeing Debian triumph over Red Hat (and vice versa), though the advantages of each usually put them in different fields of use. Debian is generally considered a little less user-friendly than Red Hat.

- **http://www.enlightenment.org**
  This is Enlightenment's home page. You'll be able to find updates, various applets, and themes from here.

- **http://www.gimp.org**
  Users of the GIMP will be glad to use this web page. It contains updates, plug-ins, and other various downloads you'll find interesting. You should also be able to get a little technical support here if you need it.

- **http://www.gnome.org**
  This is the GNOME web site. You should periodically check this web site for information about the progress GNOME is making in the desktop world. It has news bytes and updates as well.

- **http://www.google.com/linux/**
  Google.com is a wonderful search engine that prioritizes results based on the number of links a page has pointing to it. It comes with a search engine specifically devoted to Linux, which you can find at this URL. You'll be able to find web pages for virtually any application and packages or archives of almost any program available for any distribution of Linux.

- **http://www.netscape.com**
  When you want to get updates for Netscape, you can visit their home page here. Alternatively, you could find Netscape using GnoRPM. If you use the web site, you'll find releases for Linux in the Browser Archive section.

- **http://www.opera.com**
  For the latest news and updates for Opera for Linux, you should visit their web site. Opera is fully featured and incredibly powerful. Yet somehow small. It looks like someone managed to code an efficient program for the first time in who knows how long. At the time of this writing, a full version of Opera was not available for Linux, but several “Tech Preview” releases were on the site.

- **http://www.redhat.com**
  This is the homepage for Red Hat Linux. The makers have provided an all-purpose page with a number of different resources for you to use, including some search capabilities and hardware support pages.

- **http://www.sun.com**
  Sun Microsystems make more than just computers, though that's where their market lies. If you're interested in using StarOffice, you can find links to it from their main page, however. StarOffice is a fully featured, Open Source suite of productivity tools that any office user will be delighted to have.
