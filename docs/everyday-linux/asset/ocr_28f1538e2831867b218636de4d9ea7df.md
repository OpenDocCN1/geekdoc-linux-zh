You can also configure LILO to boot into other operating systems besides Linux. There are two separate subtopics under the boot loader section for boot-ing into a Linux system or an “other” system. You will need to know which par-tition the other operating system is installed on to boot from it.

The *label* associated with a drive is the label that you’ll type at the LILO Boot: prompt that appears when you start your computer. For instance, the default label for your Red Hat Linux system is “linux.” When the LILO prompt appears, you’ll type in “linux” to start the Linux system. The default Windows label is “dos,” and that’s what you’ll type when you want to get into the Windows system. You can change these labels to a more inventive nomenclature if you’d like.

# Leaving the Linux Configurator

When you’ve finished making modifications in linuxconf, you should click on the “quit” button below the list on the left. When you do this, a new page will appear on the right, telling you that the system is out of sync with the present configuration. Linuxconf will then offer to rectify the situation.

To accept its offer, click on the “activate changes” button. Once the changes are activated, linuxconf will exit. If there are any errors during the synchron-ization of the system, you’ll be notified and given the chance to review them. Depending on the nature of the errors, you may be asked to take some action to fix them, which usually involves either skipping a command or killing a process.
