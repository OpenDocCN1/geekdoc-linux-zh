# ### The File Browser

The file browser is relatively simple to use. The buttons are intuitive and the design is easy to follow. We don't need to say too much about it, but we include a screen shot and some information about various features here.

![](bbox=[0.07, 0.24, 0.96, 0.71])

**Figure 7-1**
*Your file manager will look something like this.*

The first five buttons are similar to those on a web browser like Netscape. The back button will take you to the directory you were using previously. The up button will place you one level up on the directory tree, and the forward button will carry you from your present location to where you were before you pressed the back button. The home button will bring up the display of your home directory, and the rescan button will refresh the display in case you made any changes to the files in question during the use of the file browser.
