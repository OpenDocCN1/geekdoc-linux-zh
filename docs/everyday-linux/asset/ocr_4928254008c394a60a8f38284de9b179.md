+   Port You normally don’t have to change this or put an entry in unless the FTP site you’re trying to connect to uses a special port. An FTP port is similar to the more familiar boat port or space dock. It’s where your FTP program can establish a connection to an FTP server and send or receive data.

+   Protocol This is either FTP or HTTP; if you’re accessing a web-based FTP site, use HTTP; otherwise you should use FTP.

+   Remote Directory If you want to enter a specific directory on the server every time you connect, you should fill in the full path name here.
