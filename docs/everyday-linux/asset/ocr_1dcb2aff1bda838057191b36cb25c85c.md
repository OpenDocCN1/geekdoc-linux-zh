*Gradient Fill*—fills an area with a gradation of colors. Default is to use foreground to background color blend. Double-clicking on the icon will pop up the tool options window. This allows you to set many options for this tool, such as type of gradient (linear, radial, spherical, etc.). In addition, GIMP comes with some default gradients which you can access by right-mouse clicking for the main menu and then choosing “dialogs” and then “gradient editor.”
