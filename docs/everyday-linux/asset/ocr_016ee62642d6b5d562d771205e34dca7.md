# Figure 17-5 Opening an Image.

Within this window you may navigate around directories and see previews of selected images along with the information about that image. If you want to open and edit an image, select one and click "ok." When the image is opened, place the mouse over the image and right-click, then choose "view" and then "show/hide edit window." The edit toolbar will appear.

The toolbar contains buttons which will allow you to change image size, crop, do a screen capture, flip image, and adjust brightness, contrast, and hue. Electric Eyes does not allow undo, so if you make a mistake you must close the image without saving and begin again.
