**Airbrush**—I used to do a lot of scenic oil paintings and I soon found that I could achieve almost the same results digitally by playing with the airbrush tool on GIMP.

![](bbox=[0.14, 0.18, 0.47, 0.26])

What makes this tool so maneuverable is that if you double-click on it, you will get a tool options window that will allow you to adjust pressure and rate just like an actual airbrush.

![](bbox=[0.14, 0.38, 0.84, 0.71])

**TIP**

This window actually comes up rather small. If you have trouble getting the pressure or rate you want, enlarge the window. This will increase the area of the slide bar and give you more precision.

Once you select rate and pressure for the airbrush you may use the brush selection window to change size, type and other options for the airbrush.
