**Tip**

Remember, you are in a true multitasking environment, so you can go do something else in another window while the program is installing.

When the install is complete, you will see another window pop up.

![](bbox=[0.07, 0.28, 0.97, 0.69])

When this window appears you have the option to either start the game, view the readme file, or exit.

# Starting Railroad Tycoon

To play Railroad Tycoon, click on the GNOME foot at the lower left corner of your screen. Then choose "games" and "rt2."
