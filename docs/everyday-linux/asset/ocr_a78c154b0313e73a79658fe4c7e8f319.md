# Adding an Image to Your Document

It is very easy to add images or clip art to your documents. Place the cursor where you would like to insert or draw a picture. Click “insert,” then “graphics.” Then choose “from file” if you want to insert an existing image. Choose “draw picture” if you want to draw your own. This feature is available only with the commercial version of WordPerfect.

If you choose to insert an image from a file, a window will pop up and you can move around your directories and choose the file you want.
