# # CHAPTER 5
# Beginning Systems Administration

We hope our forays into customizing GNOME have supplied you with some familiarity with the X-Window System. If you don't feel too confident with the system yet, don't worry too much. This section is designed to increase your confidence while using your Linux system as well as introducing basic systems administration.

The first subject we want to deal with is that of using your modem. After that we look at configuring your printer. Then we want to look at using the Linux Configurator; our big example will be adding user accounts, though you should realize that the Linux Configurator is a program with a lot of different options.

The first order of business is to log in, using the root account. If you want, you can customize how this account looks, too, before we begin setting things up. After that, it's on to the modem and beyond!
