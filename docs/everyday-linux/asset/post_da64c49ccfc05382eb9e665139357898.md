
## Installing Packages

The first step that the installer will take is to format the Linux partitions you specified beforehand (see "Selecting Partitions for Format"). Then it will install the packages you selected in the "Selecting Components" dialogue.

This can take quite a long time, especially if your hard drive is large or you're installing a lot of different packages, so it might be a good time to get a bite to eat or otherwise take a break. This is the next-to-last step in the installation, but after it's done we'll have a little more work to do to get you up and running.

## Creating a Book Disk

When the installation of all of the packages is complete, you will need to take out a floppy disk and label it (perhaps "Red Hat Linux Boot Disk" or something equally descriptive). Put it into the floppy drive and then click Next. Red Hat will format the floppy disk and place all of the necessary information on it to boot into Linux.

Once this is done, you can remove the disk from the drive (unless you're booting to Linux solely from a boot disk).

## You're FINISHED!

The installation program will then reboot your computer. Make sure that you remove the Red Hat Installation CD from the CD-ROM drive if you booted from the CD to install the software, otherwise the installation will begin again. (Don't worry—if it does, just eject the CD and restart your computer.)

You will then have the singular delight of watching your computer boot into a completely new operating system. We're going to spend the next several chapters getting your computer completely set up for use with Linux and acclimating you to the wide variety of applications available for use with your system.

Usually, at this point we suggest you take a small break, unless your brain isn't fried by staring at a computer screen during the installation process. Learning the basics of Linux and GNOME can take a little while, and customizing everything to your whim isn't always an instantaneous process. But it is a lot of fun.

## Fast Installation Instructions

As promised, I have collated the steps of the installation procedure and condensed them to a form that requires you to know basically nothing about the installation. It is highly recommended that you go through the installation at least once using the book before using this small outline.

- 1. At the opening screen, press Enter.
- 2. Choose your language from the list of available options.
- 3. Configure your keyboard.
- 4. Configure your mouse. It's a good idea to emulate three buttons, since many applications in Linux use the third button. (Don't emulate three buttons if you already have a three-button mouse.)
- 5. Choose your installation method (class). If you are not using a custom installation class, skip to instruction 8. If you are installing Linux for the second time, it is highly recommended that you use a custom installation class—you might be able to save some of your old data this way.
- 6. Create, Edit, and Delete the partition scheme to your liking. Make sure to write down the mount points and device names of all of the partitions.
- 7. Select which partitions you want to format.
- 8. Configure the Linux Loader (LILO).
- 9. Configure your Network Settings.
- 10. Configure the Time Zone.
- 11. Choose the root password and add your own account.
- 12. Configure the authentication options. The defaults are usually fine, but if you're on a network, check with your systems administrator to see if you need to enable the NIS options.
- 13. Select components or packages.
- 14. Configure X-Windows for use with your monitor and graphics card.
- 15. Wait for the installation program to format the partitions you selected and install the components you chose. Then create a boot diskette.

## Logging In and Out of Your Account

Linux is a true multi-user system, and therefore makes use of many different user accounts. We use the word “account” virtually the same way you would apply it to your various bank accounts. Each bank account has its own features specific to it. Similarly, each user has his own account, which he can modify to fit his own tastes. (Though you have a little more latitude with a user account on your Linux machine than you do with your bank accounts.)

Windows is also a multi-user operating system, but it lacks a number of the security features that Linux provides. Rather than provide a genuine account, Windows basically provides you with a way to select different user profiles to tailor your experience with Windows.

To access your account, you must log in to your computer. This is a fairly simple process. After the computer has rebooted, a screen will appear asking for your user name. Simply type in the one that you created during the installation and press the enter key. Then a new window will pop up asking for your password. Type this in, too, and press enter. Voila! You’ve just logged in. Pretty simple.

**Note**: If you didn’t create your own user account, consult Chapter Five for the process. There are some basic systems administration procedures detailed there, among them how to create a new account.

When you’ve logged in, you’ll see a pretty sparse desktop laid out before you and a relatively boring panel at the bottom of the screen. This is akin to the Windows “Start Bar.” In the next chapter we make this look a lot more exciting, but for the moment all we want to do is follow the procedure for logging out of the system.

To log out, click on the stylized foot at the far left of the bottom panel. Near the bottom of the menu that appears is an option labeled “Log Out.” If you click it, a new menu will appear. You can just click okay.

The screen that appeared when you booted up will reappear with a prompt asking you to please input your user name. That’s not necessary at the moment, since none of our tasks in this chapter require logging in.

## Groups and Permissions

Groups and permissions are two of the most fundamental concepts of Linux, and unfortunately two of the most difficult concepts for the new user to grasp. I mentioned in the previous section that Linux offers considerably more security than Windows does for multi-user purposes.

This is due in a great part to the system of groups and permissions. To understand groups and permissions, you must also understand that each user falls into at least one of three different classifications: *owner* or *user*, *group*, and *other*. Every file and directory on your system has *permissions* set which tell the computer whether or not a user is allowed to read a file, create one, or run a program.

These permissions are organized into three groups of three permission bits: *read, write*, and *execute*. They are abbreviated r, w, and x, respectively.

### The Owner Classification

The owner classification refers to the owner of a file. You can become an owner of a file by creating one or having ownership of a file transferred to you. The owner is the only person who can change permissions to a file or directory.

### The Group Classification

The next classification is the group classification. Each file belongs to one owner. But the owner himself belongs to one or more *groups*. These groups may consist of many different users and for many different purposes. Most users, for instance, belong to the “users” group. Administrators might belong to the “adm” or “admin” group.

An owner of a file can also allow members of his group certain access levels to the file. This is helpful if you have memories that need to be shared or programs that need to be restricted from other users.

### Everyone Else (Other)

Users who are not the owner of a file or in the owner’s group are called “other” users. In common parlance, this means “everyone else” who isn’t included in those other classifications.
