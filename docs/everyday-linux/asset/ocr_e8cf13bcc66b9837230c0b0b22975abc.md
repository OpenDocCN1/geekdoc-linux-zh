# Automatic Backups

WordPerfect 8 will perform automatic backups as often as you like. Earlier we mentioned that you can set defaults for automatic backups from the control window under “files.”

From the files preferences window under backup default directory, you can specify which directory you would like WordPerfect 8 to save automatic back- ups. Wordperfect 8 uses /tmp as a default directory but you can change it to wherever you wish. Below that you will see a box to fill in how often you want WordPerfect 8 to do an automatic save. The default is ten minutes.
