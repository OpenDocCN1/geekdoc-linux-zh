Filenames in UNIX can contain any of the 127 standard ASCII characters. This includes spaces and some special escape characters, though it is not recommended that you use spaces or those escape characters when naming files. If you encounter a filename with spaces in it, you usually have to use single quotes to read the file, if you're accessing it from the command line. (More on this when we reach the command-line interface.)

Filenames can be up to 256 characters long. Linux is a case-sensitive operating system, so Filename.txt is different than filename.txt is different than FILE-NAME.TXT is different than FileNaMe.TXT.

# ## Plaintext vs. Binary Formats

Plaintext files are those that you can read by opening them up in a plaintext editor. Binary files are files that are not plaintext. Binary files include not only programs, but also images, HTML documents, movies, sound files, and some system files, among others.

It is commonly thought that the words *binary file* refer exclusively to executable programs. This is not the case, though your Linux system will store programs in directories called /bin or /usr/local/bin or /sbin and others. Bin is the abbreviation for binary.

# ## Extensions and Associations

In Windows, even the earlier Windows 3.1x, various extensions were associated with programs. For instance, if you had a program that would open every kind of picture format known to man, you would make associations from the extensions .jpg, .jpeg, .gif, .tiff, .png, .xbm, and others to this program. Every time you double-click on a file with one of those extensions, the program you have associated with it will try to open it.

The same is true for GNOME. (This will **not** work from the command line.) However, in GNOME, associations are referred to as "mime types." You can find a list of these mime types by clicking on the control center icon (the toolbox) on your panel. There is a category labeled “MIME Types” in the control center. If you click on it, a list will appear and you will be able to add, edit, or remove any of your associations.
