```
-rw-r---  emetsger    wheel myfile
```

We need to change the group from *wheel* to *admin*. The syntax for the command we're going to use is as follows:

```
chgrp group filename
```

This is a fairly easy command to use, as you can see. Simply type in the command (chgrp), then the group to which you want to give the file, and then the filename itself. In our example, this would be *chgrp admin myFile*. An updated file listing of *myfile* would look like this:

```
-rw-r---  emetsger    admin myfile
```

Now that we've changed the grouping, it might be convenient to change the owner of the file, as well. This will prevent you from making undo modifications to the file, and it can also, as our example will show, make the file look as though it came from the system administrator (that is, root), rather than from a regular user account.

# Changing the File's Owner

To change the file's owner, you use the *chown* command. The syntax for this command is *chown owner filename*. You would use this command to give a file to another user.

This is useful for when you create those memos yourself that should appear to be from root. In our example above, you should type the command

```
chown root myFile
```

to give the file to the root user. This means that you will no longer retain ownership permissions of the file: this is not something you can undo unless you change the ownership of the file using the super user.
