# **Creating Directories**

You can create directories in a variety of ways. We’ll discuss the command line option later. As discussed when we were customizing GNOME to your liking, you can create new directories right on your desktop by right-clicking the desktop, highlighting “new” and clicking on “directory.”

You can also create new directories from the file browser. To do this, make sure that you are in the directory you wish to create a subdirectory under. (Note that you must have write permission to a directory to create a subdirectory in it. Usually you only have write permission to your home directory.) Click on “File” at the top and highlight “new.” Click on directory. Supply the pertinent information, and a new directory will be created for you.

# **Removing Directories**

You can remove directories the way you remove files—right-click the directory in question, and click on delete. This is an interactive process—you’ll have to tell GNOME that you really do want to delete this directory.

Again, exercise caution when going about deleting directories—you can’t undo this, either.

# **Mount Points**

One of the more interesting aspects of Linux is that each mount point is recognized as a directory. When you mount a drive or use a partition, you reference it by a system directory. In both Windows and DOS, this was accomplished by the use of “drive letters.” Every drive is associated with a letter and its own equivalent to the root file system on a Linux machine.

In some ways, this Microsoft invention is convenient. File storage is often-times easier to understand and more readable. The advantage of the Linux system, however, is that it is completely transparent to the user. This allows you to include mount points from almost anywhere—even other computers—without users knowing where the files are located. It presents a view of your system that is simple to understand and requires little to no outside knowledge of the hardware on your system. This is a very specific design principle designed so users don’t have to understand much of the system to use it.
