# # Sending a Fax

You should save whatever file you want to send as a fax as a text file. From the main ksendfax window, either type in the name of the file you want to send (including path) or click on the browse button to move through directories and find your file.

In the box for “Fax no.” type in the telephone number with area code. If you wish, you can fill out the other boxes for Dest. Name and so forth. You only need to give ksendfax a phone number.

When you are ready to send the fax, click on the send fax icon, which is the small envelope icon at the top of the window. If you are unsure which icon, just hold your mouse over the icon for a few seconds and a small box will appear with the name of the icon.
