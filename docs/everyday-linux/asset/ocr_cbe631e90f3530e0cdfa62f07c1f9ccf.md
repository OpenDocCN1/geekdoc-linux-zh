# The Initial Screen

Once your computer has booted up (be it to CD or disk), you will be presented with a screen that asks you how you'd like to install Red Hat Linux 6.2. There are a number of modes, but the one you're going to want to use is graphical. To do so, simply press your enter key.

The primary advantage of using the graphical installation is that you'll have the ability to use your mouse. In the text installation this isn't possible. If, for some reason, your monitor doesn't work with the graphical installation, type in "text" and then press enter.

The text and graphical installations are essentially the same, though the navigation principles to get through them both are somewhat different.

# Navigating Your Way Through the Installation

During the course of this chapter, I assume you've used the graphical installation. However, for your convenience, I provide information for navigation in both the graphical environment and the textual interface.

# Graphics

Navigation in the graphical environment is really, really easy. It's point and click, point and click. The next buttons are the same as you would see in a typical Windows program installation. To fill in any fields, you simply have to click on them and then type the required information.
