Text Viewers
and Editors
for Linux

There are times when you don’t need a big full-featured word processor to write a simple text file. There are a number of very good text editors, some of which have some very useful features. It’s a matter of personal preference as to which one you use. Since some of these programs have the same features, we thought it would be convenient to define what they are at the beginning rather than be repetitious.

# Common Editor Features

+   **Open**—opens a file, generally limited to .txt and .html files.
+   **Save**—saves the file you currently have open.
+   **Save as**—will allow you to save the file under a different file name.
+   **Close**—closes the file you have open. Most programs will prompt you to save any changes you have made.
+   **Exit**—closes the entire program and all opened files. You will be prompted if there are any unsaved changes to files which are open.
