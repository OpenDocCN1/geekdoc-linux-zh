Linuxconf is organized into two sections: config and control. The config section allows you to modify the configured status of your system. The control section allows you to perform several actions on components on the system. Most of your configuration will be in the config section, so we cover only subtopics under that section here. The control section is more or less self-explanatory when you go through each of its operations.

Obviously this is not a step-by-step guide of how to use the Linux Configurator. Experimentation with Linux is one of the best ways of learning how to use the system, and the sheer number of tasks you can perform with linuxconf makes writing a simple guide to it nearly impossible.

# Networking

Typically you won't have to make many changes to the networking section. If you switch ISPs or find that your current network data is outdated, some of the settings will need to be changed. These are typically service-dependant, however, so you will need someone from technical support or the network administrator to help you with the changes.

One other item that you may find convenient to change in this category is the hosts file. If you find that you're accessing another system frequently using a telnet prompt or something similar, you can add an entry in the hosts file that will make an "alias" of sorts. Then you could use some shorthand abbreviation for that system. For instance, I have a line in my local hosts file that reads

```
164.107.42.62  stdsun    stdsun.cis.ohio-state.edu
```

Rather than typing in "stdsun.cis.ohio-state.edu" every time I want to access the system, I can type in "stdsun" instead.

# Users Accounts

If you encounter the need to trim the number of users on your system, expand or limit access privileges, or disable accounts for whatever reason, you're going to do it all from here. You will also be able to add users to different groups or even create new groups for them to become a member of. And, of course, if your system grows, you'll add users from here, too.
