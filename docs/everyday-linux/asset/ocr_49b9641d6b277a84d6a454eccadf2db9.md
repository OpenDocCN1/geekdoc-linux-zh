*File Open Window.*

“parent.” On the lower right is an option to search for a file. Begin by typing in the first letters of the file and the file window will try to match what you are typing in with the files in that directory. If you are unsure of what directory the file is in, try using the quickfinder option on the lower right.

Using quickfinder you can specify a search pattern (such as some of the letters in the filename), a directory (subdirectories will be searched as well), and you can specify a range of dates to look in. Using whatever information you provide, WordPerfect will search and come up with a list of possible files.
