Setting up a RAID-1 array is relatively easy, but you will need to have a special card for your computer and two hard drives of approximately the same size. Make sure that you total up the cost of the card and the second drive if you think about using a RAID disk array. Usually it comes out to about the same cost as a two gigabyte tape backup system.

# ## Adding Eye Candy

In Chapter Three, we discussed configuring themes for Enlightenment or grabbing new ones. There are other bits and pieces of eye candy you can get as well, such as extra screensavers or applets. Eye candy is occasionally considered a waste of time, but it improves the look of your desktop. Most users will find it quite useful, especially if you change your theme to fit your mood.

Besides this, occasionally you'll want to add a few themes for other users on the system too, so it's not as though you're working entirely for yourself. The extra applets and screensavers won't hurt, either.

# ### Themes

The prime spot for themes is www.themes.org. You'll be able to find others through searching the web, of course, but themes.org has about 2000 themes on hand, ready for download and installation. You'll find plenty of searching power on themes.org, so you can find exactly what you're looking for.

Since the default window manager in GNOME is Enlightenment, you're going to want to download themes that are compatible with Enlightenment. These themes have been given their own simple web site on themes.org; this is e.themes.org. Alternatively, you can simply click on the word "Enlightenment" at the themes.org main page.

When you find the theme that you want to install, you need to download it. Normally, Netscape will ask you the location of where you would like to save the file that you're downloading. If you wish to install a theme for every single user on the system, you must place it in what themes.org calls a "global repository" — a place where everyone can access the file. In Red Hat Linux, this global repository is located in the directory /usr/share/enlightenment/themes.

When you download the file, you should save it there. If you cannot, you will need to copy the file from the present directory to the themes directory.
