## Faxing

There are several fax programs in use for Linux, but most of them are front ends to the basic fax programs. The fax program works on a command line and can be a bit cryptic, which is why the front ends are there. Ksendfax is a nice “point and click” front end to fax and we will cover that.

The efax rpm package is the easiest way to get the fax program installed, and it is possible you already have it installed. You can check to see if efax is installed by bringing up a terminal (such as xterm) and typing:

```
rpm -q efax
```

If efax is installed, you’ll get back something like:

```
efax-0.9-4
```

If it is not installed, read our chapter on adding programs and using GnoRPM to find and install the package. You also want to have ksendfax installed, so check to see if it is and if not, then install it.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_194_0.png)

Figure 10-13 Ksendfax.

Ksendfax uses your modem, of course, to send a fax. By default you need to be root to access the modem, so from an xterm or other terminal, enter the following to start ksendfax as root:

```
su -c ksendfax
```

Click “options” and “preferences” and add the following line to the “Send Fax” field. You will only need to do this one time.

```
fax send '@@Phone' '@@FName'
```

When you have added the line, click “ok.”

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_195_0.png)

### Sending a Fax

You should save whatever file you want to send as a fax as a text file. From the main ksendfax window, either type in the name of the file you want to send (including path) or click on the browse button to move through directories and find your file.

In the box for “Fax no.” type in the telephone number with area code. If you wish, you can fill out the other boxes for Dest. Name and so forth. You only need to give ksendfax a phone number.

When you are ready to send the fax, click on the send fax icon, which is the small envelope icon at the top of the window. If you are unsure which icon, just hold your mouse over the icon for a few seconds and a small box will appear with the name of the icon.

## Star Office Basics

### What Is Star Office?

Star Office did a great service to the Linux community with a free office suite for Linux. Originally owned by a German company, Star Division, the office suite is now the property of Sun Microsystems. Since that time the office suite has been updated and remains free. Even more exciting news came in July 2000 when Sun announced that it was making Star Office Suite open source. This will likely lead to rapid additions and updates.

There are many programs within the office suite such as a word processor, scheduler, presentation program, database program, spreadsheet and more. Entire books have been written on Star Office Suite so we will just familiarize you with the very basics so that you may get started using the office suite. If you find you like Star Office and want to learn more about what it can do, we would suggest purchasing one of the books on Star Office.

## Installing Star Office

You can download Star Office from Sun Microsystems at http://www.sun.com/staroffice. It is a large download of about 100 megabytes. Though downloading it is free, because of the size, you might consider purchasing a CD with Star Office on it. You can purchase CDs from Sun Microsystems and many other places where software is sold.

To install a downloaded version of Star Office, do the following from a program such as xterm:

1. Because the file is compressed, untar it by typing: **tar zxvf filename** (where filename is the name of the file you downloaded).
2. Change to the directory created by untarring the file: **cd directoryname**.
3. Run the setup by typing: *./setup*.

The remainder of the install is the graphical setup from Sun, it is very easy and just asks a few basic questions you will need to answer.

To install from a CD:

1. Place the CD in your CD-ROM and double click on the CD icon on your desktop.
2. Change to the Linux directory.
3. Change to the Office52 directory.
4. Double-click on the setup file and this will start the graphical install.

## Starting Star Office

You can start Star Office two different ways. On a command line you need to tell Linux where Star Office is and what command to use to start the application. Assuming you have installed Star Office in your home directory, the path and command to use would be:

```
cd office52/
```

Hit enter and then type:

```
.soffice &
```

Note that the "&" tells Linux to start the application and return the command line to the user.

Also, you must be in your home directory to type this command.
A simpler solution than worrying about command lines and paths is to create a launch button in your desktop panel.
