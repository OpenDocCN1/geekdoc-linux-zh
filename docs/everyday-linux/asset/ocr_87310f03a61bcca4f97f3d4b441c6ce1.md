If you want to keep a theme all to yourself, you should save it in your own directory, under the .enlightenment/themes directory. In this case, you probably don’t need to change the permissions, and you won’t need to download the theme as root or mess with ownership or permissions.

# **Applets**

If you want to get more applets, you’ll probably want to use www.gnome.org as your source; it’s GNOME’s web page.

From GNOME’s web page, you should be able to download new software by clicking on the “Get More Software” link at left. A software map will appear that will allow you to search through various categories, such as entertainment, system, core, etc., etc.

Most of these files are tarred and gzipped, so you’ll need to make sure you read and understand the directions in the section of this chapter called “Tarred Files; Gzipped Files.” Each of the software packages will come with instructions about installation, which you’ll be able to read for yourself upon downloading them.

# **And So On . . .**

You will find that there are many other tasks that you will need to perform as an administrator. But you will also find that with regular checks and taking care not to mishandle the system, your Linux machine will run perfectly for as long as you own it.
