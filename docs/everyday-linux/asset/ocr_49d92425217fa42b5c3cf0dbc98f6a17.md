> You should know that all of these formats mentioned are transferable between operating systems. This means that if you created mypicture.gif in Paintshop on a Windows computer, it will load just fine in a program on your Linux computer.

# PNG

Portable Network Graphics: Pronounceed “ping,” this format is slowly rising in popularity. This format was created in response to the unfortunate legal saga surrounding the GIF format. PNG will no doubt become very popular as it supports 24- and 48-bit color, lossless compression and has many other features. This format is best suited for a master image copy.

# GIF

Graphics Interchange Format: Created by Compuserve, GIF images are limited to 256 colors and are compressed. This is a popular format for storing low-to medium-resolution images.

# JPG or JPEG

Joint Photographic Expert Groups: This format produces a very compressed and therefore small file. It is most useful for websites and for transfer via e-mail. However, there is a price to pay for the small file size. JPEGs use lossy compression, meaning that quality is lost (and cannot be recovered) when the file is saved. Worse yet, quality is lost each time the image is saved.

# BMP

Bitmap: This is the native MS Windows graphics format. These files may be both loaded and/or converted to other formats in Linux. Bitmaps tend to be large files because they are not compressed.
