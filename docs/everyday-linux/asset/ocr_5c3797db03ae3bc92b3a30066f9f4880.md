You will notice a button labeled “Customize” near the bottom of the window that you entered the phone number and such information into. You may need to make modifications here. Click the customize button, and a new window will pop up. Here is a summary of the fields and information; if you need to modify them, you will likely need information from your ISP or network administrator.

# Customizing Interfaces

**Hardware**—These settings control how the modem itself operates. Hardware refers to the physical components of your computer, whereas software refers to the programs that run on your computer. This is why modems that use software to enable data compression are usually not compatible with Linux—the software does not work.

Usually, you will not have to change any hardware settings. If you are having problems connecting, you may wish to turn off “hardware flow control.” You likely don’t need to change the line speed, but some modems will not work properly if you have this above 57600. You used modemtool to set the port, so you don’t need to change this field.

**Communication**—These settings determine how your modem communicates with the remote computer (the one you are calling) and the local computer (the one used to make the call). Some modems may require a different initialization string than the one given.

The initialization string sets up the modem for communication with your computer, telling it to reset, how long to wait between dialing individual digits in a phone number, whether to pick up the phone when you receive a call, and so on.
