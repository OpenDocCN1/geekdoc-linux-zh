# Filters Menu

GIMP comes with an amazing set of filters. We will cover only a few of the more commonly used ones here. The best way to get to know the rest of them is to just experiment with them and read other tutorials.

+   - *Artistic*—each of these filters can be adjusted, but try the defaults first.
+   - *Apply Canvas*—makes image appear as if painted on canvas.
+   - *Cubism*—makes image look more like impressionistic painting.
+   - *Oilify*—makes image resemble an oil painting.
+   - *Mosaic*—converts image into various sized tiles.
+   - *Blur*—actually six different blur filters come with GIMP. Each of them changes an image to make it appear out of focus in one way or another. We mention the two most commonly used. Each has its own variables, but as with other tools, try the defaults first.

+   - *Blur*—basic blur, useful for smoothing rough areas.
+   - *Motion*—makes image appear to be moving to or away from viewer.

Colors—are primarily for use on RGB images. They are used to modify the image’s existing colors in various ways. The best way to learn to maximize their use is to experiment with them.

Alien Map—gives your image a psychedelic effect.

Color Exchange—is very useful for replacing unwanted colors with another color. I found this particularly useful for cleaning up portrait images where stray colours had found their way into the image. I replaced the unwanted color with the color of a nearby pixel.

To use this filter you must specify both the color to be replaced and the color replacing it. Colors are specified by a set of three RGB values. To get these numbers you can use the color picker tool. When you use this tool and click on the desired color, a small window will pop up with the RGB values of that color. You may then adjust the slide bars in the color exchange window to match.
