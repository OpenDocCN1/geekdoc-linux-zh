It will take some practice to become fully used to using numbers for permissions, so we'll supply you with a list of commonly used permissions for handy reference when you need it.

# Permission List

Here's a list of commonly-used permissions:

+   *   **700** User has all permissions (read, write, and execute), and no one else has any permissions for the file.
+       *   **744** User has all permissions, and everyone else can read the file.
+       *   **544** User can execute and read the file, but not modify (write to) it; everyone else can read the file. This is a permission usually used with scripts that you won't be changing.
+       *   **644** User can read and write to file, all others can read. This is probably the most common setting, and it is usually the default setting for newly created files.
+       *   **600** User can read and write to file, no one else has any permission to the file.
+       *   **775** User and group can read, write, and execute the file; everyone else can read and execute the file. This is useful for maintenance scripts which need occasional revision.
