An alternative CD player can be found compliments of KDE. Click on "KDE menus" and then "multimedia." As with the player mentioned above, the controls are intuitive and there are labels which appear when the mouse is held over a button.

# Media Player

This little program can be found by clicking "KDE Menus" and then "multimedia" and selecting "media player." Media player will play only .wav files.

Because they are large uncompressed files, usually only sound clips are saved as wav files.
