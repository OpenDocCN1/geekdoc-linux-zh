# ## Creating a Presentation Without a Template

If you would like to start a presentation without using Auto Pilot you can do so by way of StarDraw. Either double-click on the "new drawing" icon on the Star Office desktop, or click "file," "new," and then "drawing." When you see StarDraw you will find it familiar, as it is used by Auto Pilot when creating a presentation.
