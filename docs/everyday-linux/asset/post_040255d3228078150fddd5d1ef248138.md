
## Tracking Time with GNOME Time Tracker

GTimeTrack is a useful tool for keeping track of the amount of time you spend on various projects.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_312_0.png)

Figure 16-14

To begin using GTimeTrack you must create a project file. Click on the “new” icon and you will be asked to name your project. Give it a name and then click “ok.”

You can add additional information about your project, as well as log in the time you spent on the project each day, by clicking on “props.”

Fill in a brief description of the project and then fill in the amount of time you spent that day. Click “apply.”

You can use the timer on GTimeTracker to keep track of the time you spend on your project. Just click the “timer” button to start the timer. When you are through and want to add up your time, click “file” and “save configuration file.” You will see the time added to the previous amount of time spent.

GTimeTracker allows you to enter as many projects as you like. When you have multiple projects you need only select the one (by clicking on it) you wish to track time on and then click on “timer.”

## Graphics, Image Editors, and Drawing Programs

At one time or another nearly everyone needs to do something with an image, even if it is just to view it. Linux offers a wide range of programs to use, from the simple image viewer to the powerful GIMP (which we have covered in a separate chapter).

We have selected several programs which are stable, have good features and are easy to use. With the GIMP especially, it is impossible for the scope of this book to cover all of what the program does, but we hope to give enough of an overview that you may begin using it.

### Image Formats

Before we begin talking about various programs we feel it is necessary to mention a few things about image formats. By formats we mean the type of image file, as indicated by its file extension. Following is a list of the most common image types.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_315_0.png)

> You should know that all of these formats mentioned are transferable between operating systems. This means that if you created mypicture.gif in Paintshop on a Windows computer, it will load just fine in a program on your Linux computer.

#### PNG

Portable Network Graphics: Pronounced “ping,” this format is slowly rising in popularity. This format was created in response to the unfortunate legal saga surrounding the GIF format. PNG will no doubt become very popular as it supports 24- and 48-bit color, lossless compression and has many other features. This format is best suited for a master image copy.

#### GIF

Graphics Interchange Format: Created by Compuserve, GIF images are limited to 256 colors and are compressed. This is a popular format for storing low-to medium-resolution images.

#### JPG or JPEG

Joint Photographic Expert Groups: This format produces a very compressed and therefore small file. It is most useful for websites and for transfer via e-mail. However, there is a price to pay for the small file size. JPEGs use lossy compression, meaning that quality is lost (and cannot be recovered) when the file is saved. Worse yet, quality is lost each time the image is saved.

#### BMP

Bitmap: This is the native MS Windows graphics format. These files may be both loaded and/or converted to other formats in Linux. Bitmaps tend to be large files because they are not compressed.

#### XPM

X Pixmap: This is the standard for storing monochrome, grayscale, and color pixmap images on the X-Windows system. Most icons used in X-Windows are of this format.

#### TIFF

Tagged Image File Format is a format frequently used by PC-based drawing programs, desktop publishing, and scanners. This is a versatile format and can work in grayscale, monochrome, and color. TIFF writes a large file (probably the largest of the group) and uses lossless compression.

**Tip**

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_316_0.png)

In general, use PNG or TIFF for your master copy because these formats provide the best quality. If file size is a consideration (such as for use on websites) use JPG.

### Gqview

Just about every day when I sit at my computer, I use Gqview at one point or another. Whether it’s looking for an image I want to use on my desktop, or selecting an image to use in a puzzle, I use Gqview. This program acts as an image browser with an option for thumbnails. Gqview does not allow image editing itself but has the ability to open an editing program and load a selected image.

When Gqview starts up it goes to your home directory. Under options you can specify a directory to which you want Gqview to go on startup. On the left Gqview will list all the image files it finds in the directory it is in. By clicking once on one of these files, the image will be displayed on the right. Below the image you will find the image size in pixels and the file size.

Gqview is pretty self explanatory. Placing the mouse over any of the buttons on the top left will tell you what it will do. Gqview works on a “one-click” mouse, meaning that you need only click once on a file to open it or change directory as opposed to the double-click used by some other programs.

![](img/92fb6d8ad19de3b3470ba95c7b71b82e_317_0.png)

Figure 17-1
GQview

Thumbnails is a particularly handy feature for looking at an entire directory. Beware, though: if there are many files in the directory, it will take Gqview a few minutes to create all the thumbnails.

Other buttons will zoom the image in and out as well as “fit to screen.” There are also buttons to rescan directory and set zoom.

The menu bar across the top of the screen provides file “save” and “save as” features as well as rename, delete, move and copy. One of the most useful features is the choice to edit the image in an editor. When you have selected an image and have it displayed on the right side, click “edit” and then select which program you would like to use to edit the image. Gqview will then start the chosen program and load the image into it.

### Electric Eyes

Electric Eyes was created and developed by Red Hat. It is similar to Gqview, but does allow some basic editing. While very handy, Electric Eyes is a little less obvious to a new user than Gqview, and you must double-click with the mouse. The startup screen for Electric Eyes merely produces a small window with the program logo.

You must click once and hold the right mouse button for a menu like the one shown in Figure 17-4.

With this menu, you will have the options to open and save images and show or hide other toolbars. When you choose “open,” you will see another screen pop up.

### Xpaint

Xpaint is a drawing program as well as a basic image editor and it is found under the Another Level menus. Xpaint is best used for doing simple diagrams and drawings, though it is quite capable of loading large images.

To begin a drawing, click once and hold on “file.” Then choose “new canvas” or “new with size” if you want to specify size. You may open an existing drawing or image by choosing “open” or, if you have an image in the clipboard, choose “load clipboard.”

When the image is opened a toolbar will appear at the bottom and top of the screen. The bottom of the screen contains color palettes. If you have a three-button mouse you may make use of the middle button as a second color. Using the left mouse button, choose a color on each palette. When you paint or use a filled shape feature, you may use the middle mouse button to get your second color.
