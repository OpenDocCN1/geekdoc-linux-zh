## Overview and a Bit About Corel

Corel has been in the applications business for a long time. They are best known for their word processor, WordPerfect. A few years ago, Corel became interested in Linux and they ported their then current version of WordPerfect to run on Linux. The program, called WordPerfect 8 for Linux, was offered to users for free for personal use.

Corel is now offering additional applications for Linux such as WordPerfect Office 2000, CorelDRAW, and even Corel Linux, their own distribution of Linux based on debian Linux. We had initially planned on including all of these applications in this book. Unfortunately, Corel did not truly port their WordPerfect Office 2000 and CorelDRAW to Linux, but instead have the applications running on a Windows emulator. This has resulted in some stability issues that will likely be worked out in a timely manner. We were very impressed with what we saw in these applications, however. Since we are directing this book to new users of Linux, we decided to stay with stable programs. Unfortunately, this left out all of Corel’s applications but WordPerfect 8. We would like to make it clear that the stability problems do not appear to be with Corel’s applications, but rather with Wine, the Windows emulator which Corel contributes to but is not solely responsible for. On the official Wine site at http://www.winehq.com/about.html: “Wine is still under development, and is not suitable for general use. We recommend you check back with us at http://www.everydaylinux.com for further updates about Wine and Corel Office 2000.”

WordPerfect 8 is available in three versions: “Download,” “Retail Personal,” and “Retail Server.” You can download WordPerfect 8 at Corel’s Website, http://linux.corel.com/download/. We also encourage people to buy a copy from Corel. The retail version of WordPerfect includes extras such as 150 extra fonts, clipart, pictures, textures, and more. The retail version also includes Netscape and adobe acrobat reader (for .pdf files).

As with StarOffice, WordPerfect 8 is a large and powerful program. It is beyond the scope of this book to cover all aspects of the program. We have endeavored to get the user up and running with the program and to familiarize users with the basic and commonly used operations.

We should also mention that if you download the free version of WordPerfect 8, there will be some features which will not work. Most do, but there are a few that will only work if you purchase the commercial version from Corel. I might add that I used WordPerfect 8 for about four years and never needed a feature that did not work.

## Installing WordPerfect

You may install WordPerfect 8 while running X-Windows, and you do not need to be root. If you have either downloaded WordPerfect from Corel, or you have obtained the CD, look for the file called `GUILG00.GZ`. Change to the directory where the file is and type in this command:

```bash
tar xzvf GUILG00.GZ
```

This will extract the files from the compressed file.

Once the files are unzipped, type in this command:

```bash
./Runme
```

Corel’s installation will now take over and windows will pop up asking you if you have unzipped the files and if you understand the license agreement (that it is for noncommercial use, etc.). It will also ask you where you want to install the program. We recommend that you install WordPerfect in /usr/local/wp8. You will also be asked about installation size. You may choose between a full installation (61–70 megs), or a medium or minimum size install. If you have enough available disk space, we recommend that you do the full install unless you plan on making StarOffice your primary word processor.

Once you have answered all of the installation questions, a window will appear that will follow the progress of the install by telling you what percentage has been completed.

## Running WordPerfect 8

You can either start WordPerfect 8 from a command line, or you may make a launch button for gnome. Under command, type this:

```bash
/usr/local/wp8/wpbin/xwp
```

Be sure to change the file path if you have put WordPerfect in some other place.

## WordPerfect Control Window

When you run WordPerfect you will have two windows pop up. One will be what I refer to as your work area. This is where you will work on or create a document. Unlike StarOffice, WordPerfect opens up a new work area window for each open file. Some users find this method of multiple work areas useful because it makes comparing or cut and paste a bit easier.

The other window that opens up is what I refer to as the WordPerfect control window. The control window has four choices across the top: program, preferences, window, and help.
