# Saving and Exporting Your Presentation

The default format for presentations is the StarImpress extension of .sdd. If you do not specify another format, that is how your presentation will be saved. You can, however, save or export your presentation in a number of other formats. By clicking “file,” “save as,” you can choose to save your presentation in a format which can be displayed in MS PowerPoint.

You can also export your presentation in other formats by clicking “file,” “export.”

![](bbox=[0.05, 0.33, 0.98, 0.74])

Export allows you to save the presentation as html for websites, or you can save the slides as image formats which can be loaded into many other programs. When you export as html, you will want to choose a short, descriptive name. The name will be used to number each slide consecutively, such as “name_1, name_2, name_3, and so forth. Star Office will create “continue” links between each slide. It also creates a “summary” link which links to a page that lists the title of each individual slide.
