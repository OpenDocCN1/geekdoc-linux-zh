# KMix—Sound Mixer

There are numerous sound mixers available for Linux. We have chosen the one that has full features and also comes with documentation.

KMix is a small but full-featured sound mixer for your computer's multimedia programs. This will allow you to increase or reduce volume, bass, treble and more. It will also allow you to set recording levels if you are working with a microphone.

There is a global volume control which will affect all sound-related programs. There are also separate volume controls for CD players, microphone, speaker and line-in.

Where applicable, there are separate right and left (for speakers) controls. Generally, you will not need to make adjustments to the mixer for everyday use, but there are times when you will want to have such controls available.
