
## 视觉与娱乐
### 资源链接

**http://www.sourceforge.org**
If you’re looking for a patch you just can’t find, or the drivers for your specific printer or modem haven’t been included in your distribution of Linux, you might be able to find them from here. Source Forge provides source code and plenty of information about how to go about installing new drivers or patches.

**http://www.redhat.com/apps/support**
In the event that you have any applications provided by Red Hat (while we’re thinking specifically of Red Hat Linux, the folks at Red Hat do make other software), you can find support for them at this web site.

**http://www.redhat.com/support/hardware**
Throughout the course of the book we told you to make sure that your hardware devices were compatible with Red Hat Linux. This is the web page with all of the hardware compatibility lists. It includes versions of Linux for several versions.

**ftp://ftp.redhat.com**
This is the Red Hat Linux FTP site. It houses all of the packages that accompany the standard Red Hat distribution.

**ftp://ftp.debian.org**
The Debian FTP site contains most of their packages, as well. If you’re interested in running Debian or using any of their packages, you should check this FTP site as well as their web page.

**http://e.themes.org**
Since the default window manager for GNOME is Enlightenment, we thought it proper to include the web site for themes for Enlightenment. There are step-by-step instructions available from the site telling you how to install themes aside from those in this book.

**http://www.bungie.com**
The makers of Myth and its sequel, Myth II: Soulblighter. They have released a number of games for use with Linux. You should look at this site if you’re interested in any of their offerings, which include a few other titles.

**http://www.bungie.net**
This is Bungie’s contribution to the online gaming world, and a grand contribution it is. Visit the site for more information about how to get involved. Plenty of tutorial information is available.

**http://www.idsoftware.com**
Obviously the folks at Loki couldn’t provide you with some of their wonderful games without help from their more mainstream partners at id Software.

**http://www.lokigames.com**
This is the main web site for Loki Games. If you thought Linux was all bore, think again. Loki Games has been hard at work porting and developing games for use on your Linux machine. Go to their site to learn more about favorites such as *Civilization: Call to Power*, *Quake III Arena*, and *Descent3*.

**http://www.themes.org**
This is the general Themes web page – it has themes for use with almost any one of the window managers currently available for Linux.

## 文档
### 资源链接

**http://www.everydaylinux.com**
At the time of this writing, the *Everyday Linux* web site was not fully developed. We anticipate that it will house the full contents of this printing, along with any revisions and additions later developed. We also hope to develop it into a full- fledged Linux database with plenty of information available for Linux users.

**http://www.linuxdoc.org**
This web site is your one stop shop for all Linux documentation. The quality of the documentation varies, as it’s provided by various authors, but you can usually find a HOWTO or FAQ available for whatever topic you’re looking for; be it setting up PPP or something more complicated, like using LDAP.

**http://www.opensource.org**
If you're interested in learning more about the Open Source Initiative, this is the place to do it.

**http://www.pathname.com/fhs/2.0/fhs-toc.html**
This is the File Hierarchy Standard version 2.0 web site. We spoke of it briefly during the course of the book, adding a small disclaimer that you'd probably want to check the official web site for more information. Here it is.

**http://www.tuxedo.org/~esr**
This is the homepage of Eric Raymond. Aside from writing the forward to this book, he also started the Open Source web site and developed a number of projects for it. If you're interested in reading any of his papers or commentaries (among the more famous are "The Halloween Documents" and "The Cathedral and the Bazaar" and the Jargon File), you can find them here.

## 杂项
### 资源链接

**http://ragib.hypermart.net/linux**
This web site will provide you with a more detailed history of Linux than what's given in the introduction. It's not the most lengthy ever, but it will communicate the story well. It includes a few excerpts from emails written by Linus Torvalds, creator of Linux.

**http://www.zdweopedia.com**
If you've ever asked yourself what an acronym means (like CRT, TLA, and others), what your RAM does, or what the differences between a SCSI and IDE hard drive are, you would've loved to have known about this site. The ZDNet Weboopedia provides a searchable database that will provide you with definitions and short explanations of various computing terms. It's a must have for anyone who's interested in expanding his knowledge about computers.
