# The GIMP

Just about anything you'd want to do with a graphic can be done by the GIMP. So extensive is the program that several entire books have been devoted to it. We've tried to cover the basics here, the more common things you might want to do. If you like to do things with graphics, you might consider either buying a book or browsing the tutorials and documentation at http://gimp.org. There seems to be no end to the creative things that GIMP can do and more things get added all the time. A basic version of stable GIMP comes with Red Hat's CD. From GIMP's website you will find links to add-on brushes, plug-ins, patterns, script-fus, and more.

GIMP, which stands for GNU Image Manipulation Program, is a freely distributed program that is often compared to Adobe's Photoshop. My opinion is that GIMP is better because it is distributed under the GNU license. ${}^{a}$ GIMP can be used for retouching photos, image composition, creating awesome logos and many other things.

## GIMP’s Menus

As mentioned earlier, GIMP does so many things that it is simply impossible to cover it in a single chapter (a multi-volume book might be better!). A pop-down menu of operations is brought up by right-clicking over the image. You will see that there are sub-menus as well. Here are some of the more commonly used operations found under the following menu headings.

### File Menu

- *New*—creates a new image window.
- *Open*—loads an existing image.
- *Save*—saves current image.
- *Save as*—saves current image under new specifications.
- *Preferences*—allows user to define certain preferences.
- *Close*—closes current window.
- *Quit*—closes all GIMP windows and exits program.
- *Mail*—allows user to mail image if mail programs is installed.
- *Print*—prints current image.

### Edit Menu

- *Cut*—cuts current selected area from image.
- *Copy*—copies selected area to clipboard.
- *Paste*—pastes from clipboard to current selected image.
- *Paste into*—pastes from clipboard into current selection.
- *Clear*—clears current selection (does not save to clipboard).
- *Fill*—fills selected area with background color.
- *Stroke*—draws line following selection outline using foreground color.
- *Undo*—undoes last operation (preferences can be set for multiple undo).
- *Redo*—returns previously cancelled operation.

### Select Menu

There are various choices here such as Invert, All, None, Toggle, Sharpen, and more. All of these involve operations on selected areas of an image.

### View Menu

- *Zoom in*—displays a close-up view of image or selected area.
- *Zoom out*—is the opposite of zoom in.
- *Zoom*—displays a set of zoom ratios to choose from.
- *Toggle rulers*—displays or hides a set of rulers around the image.
- *Toggle guides*—displays or hides guides.
- *New view*—opens another window of current image.
- *Shrink wrap*—changes size of window to fit current zoom settings.

### Image Menu

**Colors**

- *Equalize*—brightens dark images or improves contrast.
- *Invert*—inverts colors in the image.
- *Posterize*—reduces number of color levels in the image.
- *Brightness/Contrast*—sets levels for the image or selected area.
- *Hue/Saturation*—sets levels for hue, lightness and saturation.

**Channel Ops**

- *Duplicate*—duplicates the current image along with layers.
- *Offset*—offsets selected layer in “X” or “Y” direction.
- *RGB*—converts image to RGB format.
- *Grayscale*—converts image to grayscale.
- *Indexed*—converts image to indexed color, such as 256.
- *Resize*—resizes image to specifications within original image.
- *Scale*—resizes entire image.

- *Save Palette*—saves current color palette used in indexed images.
- *Transform*—crops and rotates layers and images.

### Layers Menu

- *Layers and Channels*—brings up layers and channels dialogue window.
- *Raise Layer*—raises current layer above next higher layer.
- *Lower Layer*—lowers current layer below next lower layer.
- *Anchor Layer*—affixes a floating layer to current layer.
- *Merge Visible Layers*—merges all layers marked as visible.
- *Mask to Selection*—creates a selection based on current layer's mask.
