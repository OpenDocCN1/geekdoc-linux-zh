Some of these mime types are used for interaction with the Internet, so be judicious about editing them. Netscape overrides your definitions with its own, but other programs may not. If you modify them, you could impair a program's ability to read data.

Most programs that you install will include their own mime type definitions when you install them, so you won't need to make or edit them very often.

The extensions are important because this is how GNOME identifies what kind of a file you wish to open. If you simply named the picture file of a page or two previous “deck” and double-clicked it, GNOME wouldn't know what program to open it with. (It would, however, ask you what you wanted to open the file with.) By calling it “deck.jpeg” you tell GNOME that you want to open the file with Electric Eyes (or some other image file viewer).

# Hidden Files

Files are hidden when you place a period in front of the filename. Many system files are hidden because you usually don't need to edit them or remove them yourself. Since you can set access permissions on your files, you don't need to hide them to prevent other users from reading them. Hiding files is useful if you're not going to be using them very much and don't want to see them in the directory listing.

If you create a file called “test.txt,” you can hide it by renaming it to “.test.txt.”

# Creating Files

You have a number of programs at your disposal which will create a number of different files for you. GNUMeric, for instance, is a spreadsheet program. GEdit is a text editor that will allow you to create your own text files. The GIMP allows you to create your own images. To create a file, simply open a file editor (of any type), modify the file, and save it.

# Removing Files

To remove files from the file browser, you should right-click the file and then click on “delete.” There is a safeguard built straight into GNOME called interaction—you will have to click “yes” to say that you want to delete the file. This ensures that you don't remove files that you want to keep.
