Here is a brief summary of the printer filter options:

+   * **Resolution** The resolution that your printer uses determines how sharp the text appears on the printed page. Standard printers usually support only one resolution setting; if you install a laser printer or something along those lines, you may have multiple resolutions to choose from. It won't hurt to use the highest resolution available, though it can slow down printing.

+   * **Paper Size** The paper size is simply the standard size of paper that fits inside the printer. As long as you're using a regular printer, you'll want to choose “letter.” If you usually print on sheets of paper that are not 51/2″ × 11″, you'll want to choose the appropriate paper size from the list.

+   * **Color Depth** The color depth simply allows you to choose whether or not your printer will print in color. Beyond this, it also allows you to set the default printing mode—whether you want to print using more ink or less. (Using more ink will produce better-looking printouts.)
