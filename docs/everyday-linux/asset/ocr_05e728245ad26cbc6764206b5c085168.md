http://www.gnome.org
This is the GNOME web site. You should periodically check this web site for information about the progress GNOME is making in the desktop world. It has news bytes and updates as well.

http://www.google.com/linux/
Google.com is a wonderful search engine that prioritizes results based on the number of links a page has pointing to it. It comes with a search engine specifically devoted to Linux, which you can find at this URL. You'll be able to find web pages for virtually any application and packages or archives of almost any program available for any distribution of Linux.

http://www.netscape.com
When you want to get updates for Netscape, you can visit their home page here. Alternatively, you could find Netscape using GnoRPM. If you use the web site, you'll find releases for Linux in the Browser Archive section.

http://www.opera.com
For the latest news and updates for Opera for Linux, you should visit their web site. Opera is fully featured and incredibly powerful. Yet somehow small. It looks like someone managed to code an efficient program for the first time in who knows how long. At the time of this writing, a full version of Opera was not available for Linux, but several “Tech Preview” releases were on the site.

http://www.redhat.com
This is the homepage for Red Hat Linux. The makers have provided an all-purpose page with a number of different resources for you to use, including some search capabilities and hardware support pages.

http://www.sun.com
Sun Microsystems make more than just computers, though that's where their market lies. If you're interested in using StarOffice, you can find links to it from their main page, however. StarOffice is a fully featured, Open Source suite of productivity tools that any office user will be delighted to have.
