# Faxing

There are several fax programs in use for Linux, but most of them are front ends to the basic fax programs. The fax program works on a command line and can be a bit cryptic, which is why the front ends are there. Ksendfax is a nice “point and click” front end to fax and we will cover that.

The efax rpm package is the easiest way to get the fax program installed, and it is possible you already have it installed. You can check to see if efax is installed by bringing up a terminal (such as xterm) and typing:

```
rpm -q efax
```

If efax is installed, you’ll get back something like:

```
efax-0.9-4
```

If it is not installed, read our chapter on adding programs and using GnoRPM to find and install the package. You also want to have ksendfax installed, so check to see if it is and if not, then install it.
