# Electric Eyes

Electric Eyes was created and developed by Red Hat. It is similar to Gqview, but does allow some basic editing. While very handy, Electric Eyes is a little less obvious to a new user than Gqview, and you must double-click with the mouse. The startup screen for Electric Eyes merely produces a small window with the program logo.

You must click once and hold the right mouse button for a menu like the one shown in Figure 17-4.

With this menu, you will have the options to open and save images and show or hide other toolbars. When you choose “open,” you will see another screen pop up.
