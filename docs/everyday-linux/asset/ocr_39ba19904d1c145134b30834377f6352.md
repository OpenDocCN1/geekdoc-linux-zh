Xjig does not come with Red Hat, but is available as an RPM package from the Red Hat website. You can download it and install it with GnorPM. Instructions for using GnorPM and installing new programs are in the “Maintaining Your System” chapter.

Xjig unfortunately uses a command-line interface, but you can work around this by creating an applet in GNOME. Instructions for this are available in the GNOME chapter.

The commands used for xjig are available in the man pages. From a terminal, type “man xjig.” You must do this after you have installed the program. We use an example of creating a medium-sized puzzle.

This was the original image. We created the puzzle by going to a command line and typing this command:

```
**xjig -file puzzle.gif -side n -w 16 -h 26**
```

The result was a jigsaw puzzle like the one in Figure 20-18. Of course, the color original looked much better!
