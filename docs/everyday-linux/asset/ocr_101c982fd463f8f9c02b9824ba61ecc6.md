**Querying a Package** —If you're interested in the contents, size, or description of an installed package on your system, you should right-click it, and then click on the Query option. You'll find out about the package, what files are contained in it, and how much space it takes up.

Space-conscious users will probably want to periodically review the packages installed on their system and decide whether or not they need them. If you happen to find one that you don't wish to keep, follow the instructions for removing a package listed above.

**Verifying a Package** —If you think that some of the files in a package are missing or corrupted, you can choose to verify the package. Right-click the package in question and click on the word "verify." GnoRPM will proceed to check through each and every file contained in the package to ensure that the date and time stamps match and that all of the files listed in the package have been installed.

If you have recently gotten a virus or encountered some hard drive damage, you might want to verify packages that seem to be acting up.

**Finding Packages from Files** —When performing routine system maintenance, you might find a program or other file that you believe is no longer in use. However, it's sometimes difficult to know which package contains the file. Make sure to copy down the full name of the file (i.e., the full directory and the filename). You can then click on the find button in GnoRPM.

A new window will appear, asking you for the name of the file. Put in the full name, and it will respond with the package that the file is contained in, if any. For example, try inputting /bin/bash.

**Web Find** —One of the more wonderful options of GnoRPM is the "Web Find" option. If you find that you want to install or upgrade a package which you do not have locally, you can search the internet using Web Find.

If, for instance, you hear a widespread rumor that the GIMP has been updated and includes a few new plugins that you might enjoy using, you could type in *gimp* in the search window that appears. A list of all packages containing the word gimp will appear, and you'll probably find exactly what you're looking for.

Once you find what you're looking for, you can query the package, install it, or upgrade it, the same way you would if you were installing from a CD or another disk.
