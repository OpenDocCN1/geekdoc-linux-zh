# Managing the Desktop

Star Office is an integrated office suite, which means that it is designed so that individual components will work with each other. For example, you might create a spreadsheet with StarCalc and then wish to use the spreadsheet in a document in StarWriter. Because the components are integrated, you can do so without having to modify it.

The main desktop is always available through an icon located at the bottom left of any Star window. When you have multiple windows open, you can switch between them by using the buttons below the desktop. The area that comes up on the desktop on start-up is the work area.
