After you click okay on that window, the printer editor dialogue box will appear. The input filter allows you to select a printer driver for use with your printer. A list of drivers appears on the left. You should choose the driver that most closely matches the printer that you own. Once you pick the appropriate driver, you should set the settings available on the left. A driver description appears at the upper right corner of the window.

Here is a brief summary of the printer filter options:

- **Resolution** The resolution that your printer uses determines how sharp the text appears on the printed page. Standard printers usually support only one resolution setting; if you install a laser printer or something along those lines, you may have multiple resolutions to choose from. It won't hurt to use the highest resolution available, though it can slow down printing.
- **Paper Size** The paper size is simply the standard size of paper that fits inside the printer. As long as you're using a regular printer, you'll want to choose “letter.” If you usually print on sheets of paper that are not 5.5″ × 11″, you'll want to choose the appropriate paper size from the list.
- **Color Depth** The color depth simply allows you to choose whether or not your printer will print in color. Beyond this, it also allows you to set the default printing mode—whether you want to print using more ink or less. (Using more ink will produce better-looking printouts.)
- **Printing Options** The printing options are fairly straightforward. If you notice that your printer continually prints out an extra page at the end of a printout, you should make sure that “Send EOF” is not selected. If you notice that your regular text printing produces “stair-stepping” (when the text is not left-justified after reaching a hard return), you should click “Fix Stair-stepping.” If you use a driver that allows you to use PPA printers (such as the HP DeskJet 710C series), you should not enable “Fast text printing.” The driver description will also contain information about which printing options you should use.
- **Margins** If you have any special margins settings, you should set them here. Usually, you can leave these alone.
- **Extra GS Options** Extra options should be used only if you need them to print. You should talk to your printer manufacturer to see what options you should supply. Again, the printer driver description may have a few listed for you to use.

Once you’re done with the input filter, click the **OK** button. Then click **OK** to save the printer that you want to install, and you’ll be back at the main printer configuration screen. One of the first things you’ll want to do is print out some test pages. To do this, click on the “Tests” menu option.

Once you’re convinced that your printer works, close the printer configuration. You’re all done. The process itself isn’t too difficult at all, is it?

## Configuring Sound

Most users will wish to play sound and video media from their computers. Before you can do this, you need to configure your sound card for use with your system. Configuring sound is easy.

First, click on the foot at the bottom of the screen. This brings up the main menu. On the main menu, click “Run program.” A new dialogue box will come up. Click on it, and type in the command `/usr/sbin/sndconfig`. This is a text-based utility, so it will appear in a terminal window on your screen. If it does not appear, click on the terminal icon on the panel at the bottom of your screen. Then type in `/usr/sbin/sndconfig` at the prompt.

Since you are running this from X-Windows, the program will tell you that you probably shouldn't. It should be okay for you to go ahead and configure sound anyway. Press enter to move past this screen. To have the sound configuration program probe your computer for a sound card, press enter. If it can't find a sound card in your computer, you will have to select it from a list of available cards.

As a precaution, the configuration program will warn you that you're about to overwrite some configuration files. Go ahead and overwrite them.

The program will then play a sound sample. My copy of Red Hat has Linux Torvalds (the creator of Linux) saying, "Hi, I'm Linux Torvalds, and I pronounce Linux 'Lah-nux.' " If you can't hear the sample, you will want to make sure that your sound card is properly seated in your computer (it is if you heard sound in your other operating system) and that your speakers are plugged in. If you have a volume control on your speakers, you may need to turn this up more than usual to hear sounds in Linux. (This is because Windows pre-amplifies sound through its own volume mixer.) Make sure to confirm that you have heard it or that you haven't.

Once the program is finished, it will exit and the window will close. If you used the terminal icon on the panel to use the sound configuration program, you will be presented with another prompt. Type exit to quit the terminal.

## The Linux Configurator

This is a brief introduction to the Linux Configurator, more often known as "linuxconf" because that is the command invoked to run it. Linuxconf is a very, very powerful tool, and you're probably going to use it quite a bit over the course of your administration of Linux.

Our first use of linuxconf is going to be to add additional users to your system. If you don't think anyone but you is going to use your computer, then you could just add a test account if you wanted. Our second use will be to add your regular user account to the *wheel* group, to allow you to use the su command to run administrative programs without actually logging in as the root user. We're also going to examine how to work with your disk drives to allow everyone to use them.

To open linuxconf, click on the main menu and go to “System.” In the system submenu is the linuxconf command. Click on it. If this is the first time you’ve run linuxconf, you may have an introductory screen. Click the “OK” button to get rid of it. This is what linuxconf will look like:

### Adding Accounts

Our first task is going to be adding an account to the machine.

To add an account, scroll through the list on the left. There is a submenu labeled “user accounts” that you need to open up. In its sublist, click on the “user accounts” underneath the “Normal” subheading. A list of all of the current users on the system will appear—you should see your own user account and root, among several others (most of which you’ll never use).

To add an account, you click on the add button at the bottom of the list. A new page will appear with a number of prompts to fill in, such as the login name, the full name, the user's group, supplementary groups, the home directory, the command interpreter, and the user id. **Here is a brief explanation of all of these categories and how you should fill them out:**

- **Login name** Your login name is the name that you will input when the computer prompts for your login. It is best that you put in a login name that reflects your name. For instance, my login name is “emetsger.” John Smith might use a login name “jsmith” or “johns.” Outlandish names or handles are usually frowned upon for mainstream Internet purposes. So it’s probably not a good plan to call yourself jpapafunk or llamabo.
- **Full Name** Just put your full name here.
- **Group** For the moment, you can leave this at the default. When we discuss groups and permissions, you may wish to come back and add information here.
- **Supplementary Groups** You can leave this blank, too.
- **Home Directory** Your home directory is where your data files are stored. The default home directory is /home/login (where login is the login name that you provided above). Unless you want to store files in a special place, it’s best to leave this blank.
- **Command Interpreter** For the moment, leave this at the default. Most users won’t need to worry about which command interpreter (also called a shell) they need to use. Until you are familiar with a command line interface, you won’t appreciate the differences between the options available.
- **User ID** The user ID is a unique number associated with each user on the system. The root user’s ID is 0, and you are not allowed to set your user id to zero. You can leave this blank, and Red Hat will start your numbering at 500. Some users prefer to have a special number for their own personal accounts, like 137 or something. If that’s what you’d like, go ahead and plug it in—as long as it’s not taken by another user, it’ll be fine.

Once you’ve finished filling in this information, you can click “Accept” and the page will be replaced with a “Change Password” dialogue. **Type** in the password and click the Accept button. You will then be asked to confirm the password by typing it in again. Click the Accept button once more to complete the addition of the user.
