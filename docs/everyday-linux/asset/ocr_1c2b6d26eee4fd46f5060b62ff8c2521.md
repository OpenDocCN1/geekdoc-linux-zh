> **Tip**
> 
> Remember the images must be in .gif format. Whenever I select an image to make a puzzle, I name it puzzle.gif. This prevents a lot of puzzle images taking up diskspace and it makes the applet possible, as it is always looking for the same file name.

You need to start with an image that is roughly the same size as you want the puzzle to be. Starting with a small image and trying to create a large puzzle will lead to poor image quality. Try enlarging the image to the size you want the puzzle to be. If it looks OK, the puzzle will be all right.
