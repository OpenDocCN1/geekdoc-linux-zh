The disconnect feature is simple—just click on it to disconnect from the site you're currently connected to.

The “send SITE command” option is a little more complicated. FTP sites operate using a set of commands which are mostly esoteric and generally not used by the common FTP user. FTP programs make use of these commands by “translating” them into the easier-to-understand commands and options that you see used in menu-driven or command-line programs.

Some FTP servers, however, have different subsets of commands that may not be used by your GFTP. If you're fairly knowledgeable about what commands are used by the server you're connected to, you can send a command recognized by the remote computer. This is accomplished by sending a SITE command. To send a SITE command, click on the send SITE command option. A little window will appear that asks you which command you'd like to send. Type it in and click on the OK button.

You probably won't need to use this command at all, but it can be useful at times.

# Bookmarks

This is probably the most fundamental of all of the drop-down menus in GFTP. You're going to be connecting to sites all the time when you use GFTP, and this menu will allow you to connect to various sites or add others to your lists. At the top of the menu are two options—one says “Add Bookmark” and the other says “Edit Bookmarks.” Below this is a list of all of the available bookmark folders and any stray items that you happen to have added.

When you click on “Add Bookmark,” you will add a bookmark to the site that you're currently connected to. If you want to add bookmarks to sites that you aren't connected to, or if you want to change the appearance of your bookmarks, you need to use the “Edit Bookmarks” option.

Figure 9-6 shows what the bookmarks menu might look like. I've taken the liberty of adding my own folder for personal bookmarks so you can see what it looks like. To create a folder or a new bookmark, you should click on the “File” drop-down menu. Click on “New Folder” to create a folder; click on “New Item” to create a new bookmark. You can delete either folders or items by clicking on them and then click on File and Delete.
