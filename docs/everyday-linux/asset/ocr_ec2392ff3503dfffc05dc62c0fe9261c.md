# A List of Commands (cont.)

| Command Name | Options | Description |
| --- | --- | --- |
| rmdir | [directory] | “rmdir” removes a directory. |
| shutdown |  | “shutdown” completely shuts the computer down, turning it off. |
| startx |  | If the X-Window System suddenly shuts down, startx is the command that will start it back up. |
| su | [username] | “su” allows you to become the super user or another user specified by [username]. You will have to put in a password unless you are running su as the super user. |
| tar | x, v, f, z, c; see tar man page | “tar” stands for “tape archive.” This is a program that will create archives of files. Though originally designed for use with tape backup systems, it will also work with hard drives and floppy disks. |
| touch | [filename] | “touch” will create a file of size zero with the given filename. |
| umount | [device] OR [mount point] | “umount” will unmount a device given the device name or the mount point. |
| which | [filename] | “which” will search for a filename in the path. |
| Xconfigurator |  | When you install new hardware, the Xconfigurator will help you configure it. You should run this after installing a new graphics card or monitor. |
