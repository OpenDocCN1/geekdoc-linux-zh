# Creating, Opening and Saving Files

To create a new document you need only click on “file” from the menu at the top of the work area. Select “new” from the drop down menu. If you have just started the program, the work area comes up with a new document. You can also click on the new document icon which looks like a small blank page with the corner turned down. It is the icon on the farthest left.

If you want to open an existing document, click “file” and then “open,” or you can click the open file icon which is next to the new file icon.
