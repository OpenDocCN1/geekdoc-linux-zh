+   • **Printing Options** The printing options are fairly straightforward. If you notice that your printer continually prints out an extra page at the end of a printout, you should make sure that “Send EOF” is not selected. If you notice that your regular text printing produces “stair-stepping” (when the text is not left-justified after reaching a hard return), you should click “Fix Stair-stepping.” If you use a driver that allows you to use PPA printers (such as the HP DeskJet 710C series), you should not enable “Fast text printing.” The driver description will also contain information about which printing options you should use.

+   • **Margins** If you have any special margins settings, you should set them here. Usually, you can leave these alone.

+   • **Extra GS Options** Extra options should be used only if you need them to print. You should talk to your printer manufacturer to see what options you should supply. Again, the printer driver description may have a few listed for you to use.

Once you’re done with the input filter, click the **OK** button. Then click **OK** to save the printer that you want to install, and you’ll be back at the main printer configuration screen. One of the first things you’ll want to do is print out some test pages. To do this, click on the “Tests” menu option.

Once you’re convinced that your printer works, close the printer configuration. You’re all done. The process itself isn’t too difficult at all, is it?

# # Configuring Sound

Most users will wish to play sound and video media from their computers. Before you can do this, you need to configure your sound card for use with your system. Configuring sound is easy.

First, click on the foot at the bottom of the screen. This brings up the main menu. On the main menu, click “Run program.” A new dialogue box will come up. Click on it, and type in the command `/usr/sbin/sndconfig`. This is a text-based utility, so it will appear in a terminal window on your screen. If it does not appear, click on the terminal icon on the panel at the bottom of your screen. Then type in `/usr/sbin/sndconfig` at the prompt.
