## CHAPTER 5
### Beginning Systems Administration

We hope our forays into customizing GNOME have supplied you with some familiarity with the X-Window System. If you don't feel too confident with the system yet, don't worry too much. This section is designed to increase your confidence while using your Linux system as well as introducing basic systems administration.

The first subject we want to deal with is that of using your modem. After that we look at configuring your printer. Then we want to look at using the Linux Configurator; our big example will be adding user accounts, though you should realize that the Linux Configurator is a program with a lot of different options.

The first order of business is to log in, using the root account. If you want, you can customize how this account looks, too, before we begin setting things up. After that, it's on to the modem and beyond!

## Setting up Your Modem

We're going to take some time out at the very beginning to set up your modem. In this day and age, it's almost impossible to navigate your way through the computer world without some use of the Internet. And to get on the Internet, you need to use a modem. The modem is one of the most-used devices on the system, and one of the most basic devices that you and anyone else who uses your computer will want to use. That's why we're going to tackle setting it up first.

### Compatibility

As with most devices, you must first make sure that your modem is compatible with Linux. To do this, you should check Red Hat's web site and look at the compatibility list. You can assume that your modem does **not** work if you have a combination modem/sound card (such as IBM's MWave) or a modem specifically designed to work with Windows (most winmodems). Modems that require extra software to enable compression options probably won't work either.

Again, you should see if you can find a patch for your modem from your vendor or from a site like Sourceforge. If this fails, you should invest in a Linux-compatible modem. These are generally quite inexpensive—you should be able to buy a 33.6 kbps modem for under forty dollars.

### Using Modemtool

To set up your modem, we're going to access the modemtool command from the control panel. Open the control panel as directed above and then click on the icon that has a telephone on it.

The window that comes up will look like the picture to the left of these paragraphs.

The ports are labeled as TTY50, TTY51, TTY52, TTY53 for COM1, COM2, COM3, and COM4, respectively. You should select the port that matches the one on your modem. Then, click on okay to complete the setup.

## Setting up PPP

Most users will want to be able to connect to the Internet while using Linux. To do this, most users use a *PPP* connection. PPP stands for *Point to Point Protocol*, and refers to a method of communication between your computer and the one you are calling. (Users of older Internet providers may have a *SLIP* connection.)

Most major Internet Service Providers (ISPs) such as America Online, CompuServe, the Microsoft Network, Prodigy, Juno, and some free providers such as Netzéro provide software for your computer that will allow you to connect to their services. Most of the time, this software does not work on Linux. You should call their support numbers to see if you can obtain this software for Linux or set up a connection without it.

Other ISPs usually allow you to connect using a PPP connection program such as Dial-Up Networking for Windows. The equivalent in Red Hat Linux is known as the “PPP Dialer.” (I am always impressed at the creative names assigned these programs.)

To run the network configuration tool, you should click on a different icon from the control panel. It’s the fourth one down, and it looks like a server with many different computers connected to it (though it’s admittedly a little difficult to make out). When the network configurator starts, this is what it will look like:

### Names

You won't know any of this information off-hand, more than likely. The easiest way to get it is to call your network administrator or ISP and ask them what information you'll need for each of the categories.

Alternatively, if you are still running Windows, you can find the information from the Network Settings in the Control Panel. Getting the information should be easy—simply find the device labeled **TCP/IP -> Dialup Adapter**. Highlight it in the list that appears and click on properties. You should then go through each of the tabs and record the information. You'll be able to transfer some of it to the fields in the Network Configurator, since the field names are the same.

The NAMES tab supplies information that will allow your computer to find other computers on the Internet when connected to the host. If you don't specify any settings here, you'll probably get a lot of errors when you try to view web pages (to the effect that Netscape or whatever program you're using cannot find the remote server).

### Hosts

Most of the time, you can leave this option alone. However, if you frequently access systems, you can create aliases for them here. As long as you have the IP address of the system, you can add a hosts entry.

If you're not sure of how to edit the hosts file, you shouldn't worry about it now. Your network administrator or ISP may advise you to put some information in here.

### Interfaces

This isn't the most complicated part of setup, but it is the most important. You will need to add a device to your system (usually **ppp0**) so that PPP will function properly if the device ppp0 is not already listed in the interfaces list. To do this, you should click on the Add button at the bottom of the window.

A new list of devices will come up. At the top is PPP; the list should contain others such as SLIP and Ethernet. Make sure that PPP is checked and click OK. A new window will appear, requesting information such as the phone number, login, and password. Put in all this information. There is also a section for “PAP Authentication.” You should consult your network administrator or ISP to see if you need to configure your system for use with PAP authentication. Most modern ISPs now use PAP authentication.

You will notice a button labeled “Customize” near the bottom of the window that you entered the phone number and such information into. You may need to make modifications here. Click the customize button, and a new window will pop up. Here is a summary of the fields and information; if you need to modify them, you will likely need information from your ISP or network administrator.

## Customizing Interfaces

**Hardware**—These settings control how the modem itself operates. Hardware refers to the physical components of your computer, whereas software refers to the programs that run on your computer. This is why modems that use software to enable data compression are usually not compatible with Linux—the software does not work.

Usually, you will not have to change any hardware settings. If you are having problems connecting, you may wish to turn off “hardware flow control.” You likely don’t need to change the line speed, but some modems will not work properly if you have this above 57600. You used modemtool to set the port, so you don’t need to change this field.

**Communication**—These settings determine how your modem communicates with the remote computer (the one you are calling) and the local computer (the one used to make the call). Some modems may require a different initialization string than the one given.

The initialization string sets up the modem for communication with your computer, telling it to reset, how long to wait between dialing individual digits in a phone number, whether to pick up the phone when you receive a call, and so on.
