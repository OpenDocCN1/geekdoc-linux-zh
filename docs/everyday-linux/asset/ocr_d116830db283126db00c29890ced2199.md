# Installation

You're ready to install Red Hat Linux. As we go through the installation procedure, you're going to become familiar with a few facets of the Linux operating system that will help you get used to configuring GNOME and working with your files or maintaining your system.

You'll find that the install program uses a few different conventions than you may be used to (of course, if you're sufficiently new to computers, you might not be used to any at all). As we go through the installation, I attempt to explain these conventions in some detail so that you can make some decisions about the installation on your own. (Please don't gasp, it's really not becoming.) Of primary importance is that you realize that the first time is always the longest and most difficult, and the installation process becomes exponentially easier the more familiar you are with it.

The installation will probably take forty-five minutes to an hour and fifteen minutes the first time you do it. Most of the time that you're involved will be spent in making partitions; the bulk of the installation is spent actually installing the operating system. You'll find that the installation is about as easy as installing Windows or a comparable operating system.
