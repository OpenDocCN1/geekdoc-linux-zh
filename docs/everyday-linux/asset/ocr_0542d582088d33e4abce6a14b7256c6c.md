Other ISPs usually allow you to connect using a PPP connection program such as Dial-Up Networking for Windows. The equivalent in Red Hat Linux is known as the “PPP Dialer.” (I am always impressed at the creative names assigned these programs.)

To run the network configuration tool, you should click on a different icon from the control panel. It’s the fourth one down, and it looks like a server with many different computers connected to it (though it’s admittedly a little difficult to make out).
