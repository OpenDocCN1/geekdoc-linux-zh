# A List of Commands (cont.)

| Command Name | Options | Description |
| :--- | :--- | :--- |
| gzip/gunzip | see gzip -help | This is the GNU version of the popular ZIP compression program. It will compress and archive files. |
| halt | see man page for halt | This will stop the system and take it into a single-user mode. This is useful if you need to perform system maintenance and don't want any other users on the system. |
| less | [filename] | “less” is the natural antithesis to “more” in common parlance. This, however, is just another pager. It will print out a file to the screen page by page. |
| ls | -1, -a, -F, -C, [filespec] [directory] | “ls” will list the files in your current directory. The options listed are by no means comprehensive, but they're commonly used to show the long listing, all files, or to format the output. You can also use them all together: ls -laFC is the same as ls -1 -a -F -C. |
| man | [command] | “man” stands for “manual.” This program will find the manual page (man page) for a command that you type in. |
| mc | “mc” stands for Midnight Commander. This program is a highly functional, easy-to-use file browser for the command line. |
