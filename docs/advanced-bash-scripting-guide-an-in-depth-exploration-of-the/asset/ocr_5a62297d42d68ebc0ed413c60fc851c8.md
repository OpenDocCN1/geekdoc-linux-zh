| [address] i command Filename | insert | Insert pattern at address indicated in Filename. Usually used with -i in-place option. |
| g | global | Operate on every pattern match within each line of input |

Unless the q (global) operator is appended to a substitute command, the substitution operates only on the first instance of a pattern match within each line.
From the command-line and in a shell, a sed operation may require quoting and certain options.

```
sed -e '/$/' $filename
# The -e option causes the next string to be interpreted as an editing instruction.
# (If passing only a single instruction to sed, the "-e" is optional.)
# The "strong" quotes ('\'') protect the RE characters in the instruction
# from reinterpretation as special characters by the body of the script.
# (This reserves RE expansion of the instruction for sed.)
```

Operates on the text contained in file $filename.
In certain cases, a sed editing command will print only with single works.

```
filename=file1.txt
pattern=BEGIN
```

```
sed "/pattern/d" "$filename" # Works as specified.
# sed "/pattern/d" "$filename" has unexpected results.
# In this instance, with strong quotes ('...'),
# *pattern will not expand to "BEGIN",
```

Sed uses the -e option to specify that the following string is an instruction or set of instructions.
There is only a single instruction contained in the string, this may be omitted.

```
sed -n '/xxy/p' $filename
# The -n option tells sed to print only those lines matching the pattern.
# Otherwise all input lines would print.
# The -e option not necessary here there is only a single editing instruction.
```

# ### Table C-2. Examples of sed operators

| Notation | Effect |
| 8d | Delete 8th line of input. |
| /^$/ | Delete all blank lines. |
| 1,/$/ | Delete from beginning of input up to, and including first blank line. |
| /Jones/p | Print only lines containing "Jones" (with -n option). |
| s/Windows/Linux/ | Substitute "Linux" for first instance of "Windows" found in each line. |
| s/BSOD/stability/g | Substitute "stability" for every instance of "BSOD" found in each input line. |
| s/ */$ | Delete all spaces at the end of every line. |
