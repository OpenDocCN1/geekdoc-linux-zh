# Advanced Bash-Scripting Guide

The nc (netcat) utility is a complete toolkit for connecting to and listening to TCP and UDP ports. It is useful as diagnostic and testing tool and as a simple script-based HTTP clients and

```
bash nc localhost.localdomain 25
220 localhost.localdomain ESMTP Sendmail 8.13.1/8.13.1;
Thu, 31 Mar 2005 15:41:35 -0700
```

A real-life usage example.

# Example 17-5. Connecting a remote server for ident

```
#!/bin/sh
## Duplicate DaveG's ident-scan thingie using netcat. Oooh, he'll be p'ssed.
## Args: target port [port port ...]
## Hose stout_ _and_, stderr together.

## Advantages: slower than ident-scan, giving inetd less
## for alarm, and only hits the few daemon ports you specify.
## Disadvantages: requires numeric-only args, the output sleaze,
## and won't work for r-services when coming from high source ports.
## Script author: Hobbit ~hobbit@avian.org~
## Used in ABS Guide with permission.

E_BADARGS=6      # Need at least two args.
TWO_WINKS=3       # How long to sleep.
THREE_WINKS=3
# Authentication "tap ident" port.
IDPORT=113
RAND1=999
RAND2=31337
TIMEOUT0=0
TIMEOUT1=8
TIMEOUT2=4

case "${2}" in
  "") echo Need HOST and at least one PORT."; exit E_BADARGS ;
esac

# Ping once and see if they '${are}' running ident.
c -z -w ${TIMEOUT0} "$1" ${IDPORT} || =
[ echo "oops, \$1; isnt running ident."; exit 0; }
# scans for listening daemons.
  -w ${TIMEOUT} = How long to connect.

# Generate a randomish base port.
RP=\$(expr \$$ \$RAND1 + \$RAND2)

TRG="\$1"
shift

while test "\$1"; do
c -v ${TIMEOUT1} -p ${RP} "\$TRG" \${1} < /dev/null & /dev/null &
PROC=\$! 
sleep ${THREE_WINKS}
echo "${1},${RP}" | nc -w ${TIMEOUT2} -r "\$TRG" \$IDPORT 2>&1
sleep ${TWO_WINKS}
```
