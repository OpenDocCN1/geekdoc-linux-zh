Compare the output lists executing processes in "tree" format. The -p option shows the PIDs, as well as the process names.

Continuously updated display of most cpu-intensive processes. The -b option displays them in text, so that the output may be parsed or accessed from a script.

Run a background job with an altered priority. Priorities from 19 (lowest) to -20 (highest). root may set the negative (higher) priorities. Related commands are renice and slice, which changes the priority of a running process or commands, and kill, which sends a signal to a process or processes.

Keeps a command running even after user logs off. The command will run as a foreground process followed by &. If you use nohup in a script, controlling it with wait to avoid creating an orphan or zombie process.

Identifies process ID (PID) of a running job. Since control commands, as kill and renice act on the PID of a process (not its name), it is sometimes necessary to identify that PID. The pidof is the approximate counterpart to thePID internal variable.

```
bash$ pidof xclock
8880
```
