which

which command gives the full path to "command." This is useful for finding out whether a particular command or utility is installed on the system.

$bash which rm

```
/usr/bin/rm
```

For an interesting use of this command, see Example 36-16.

whereis

Similar to which, whereis gives the full path to "command," but also to its manpage.

$bash whereis rm

```
:bin/rm /usr/share/man/man1/rm.1.bz
```

whatis

whatis command looks up "command" in the whatis database. This is useful for identifying system commands and import configuration files. Consider a simplified man command.

$bash whatis what

```
whatis (1) - search the whatis database for complete words
```

Example 16-13. Exploring /usr/X11R6/bin

```
#!/bin/bash
# What are all those mysterious binaries in /usr/X11R6/bin
DIRECTORY="/usr/X11R6/bin"
# Try also "/bin", "/usr/bin", "/usr/local/bin", etc.
for in $DIRECTORY/*
do
 whatis basename $file # Echoes info about the binary.
done

exit 0
# Note: For this work, you must create a "whatis" database
#+ with /usr/sbin/makewhatis.
# You might wish to redirect output of this script, like so:
# /.what.sh >>whatis.db
# view it a page at a time on stdout
# /.what.sh | less
```
