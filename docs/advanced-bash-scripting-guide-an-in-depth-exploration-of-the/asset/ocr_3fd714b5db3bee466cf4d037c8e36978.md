#  2.1. Invoking the script

Writing a script, you can invoke it by sh scriptname. [13] or alternatively bash scriptname. (Not recommended is using sh <scriptname, since this effectively disables reading from stdin within the script.) Much more convenient is to make the script itself executable with chmod.

Either:

chmod 555 scriptname (gives everyone read/execute permission) [14]
or
nchmod +rx scriptname (gives everyone read/execute permission)

chmod +ux scriptname (gives only the owner read/execute permission)

Having made the script executable, you may now test it by ./scriptname. [15] If it begins with a "sha-bang" line, invoking the script calls the correct interpreter to run it.

As a final step, after testing and debugging, you would likely want to move it to /usr/local/bin (as root, of course), to make the script available to yourself and all other users as a systemwide executable. The script could be invoked by simply typing scriptname [ENTER] from the command-line.
