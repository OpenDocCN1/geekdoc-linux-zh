In contexts, an undeclared variable and one that is unset are equivalent. However, S[parameter:-default] parameter substitution construct can distinguish between the two.

The export [file] command makes variables available to all child processes of the running script or shell. One important use of the export command is in startup files, to initialize and make accessible environmental variables to subsequent user processes.

Unfortunately, there is no way to export variables to the parent process, to the process that called or invoked the shell.

# 15-20. Using export to pass a variable to an embedded awk script

```
#!/bin/bash

# Another version of the "column totaler" script (col-totaler.sh)
#++ adds a specified column (of numbers) in the target file.
# This uses the environment to pass a script variable to 'awk' . . .
# and places the awk script in a variable.

ARGS=2
E_WRONGANGS=85

if [ $# -ne "$ARGS" ] # Check for proper number of command-line args.
then
    echo "Usage: basename $0 column-number"
    exit $E_WRONGANGS
fi

filename=$1
column_number=$2
n###### Same as original script, up to this point -----

export column_number
# Export column number to environment, so it's available for retrieval.

#
awkscript='total += $ENVIRON["column_number"]'
END { print "total" }
# Yes, a variable can hold an awk script.
#

# Now, run the awk script.
awk "$awkscript" "$filename"

# Thanks, Stephane Chazelas.
```

### declare, typeset
declare and typeset commands specify and restrict properties of variables.
readonly

Same as declare -r, sets a variable as read-only, or, in effect, as a command. Attempts to change
line with an error message. This is the shell of the C language const type qualifier.

This powerful tool parses command-line arguments to the script. This is the Bash analog of
getopt external command and the getopt library function familiar to C programmers. It prints
and concatenating multiple options [62] and associated arguments to a script (for example
scriptname -abc -usr/local).

The getopt constructs two implicit variables. $OPTIND is the argument pointer (OPTIndex)
and $OPTARG (OPTArgument) the (optional) tag attached to an option. A colon following
the declaration tags that option as having an associated argument.

A getopt constructs usually comes packed in a while loop, which processes the options and
arguments one at a time, then increments the $OPTIND variable to point to the next.

- 1. The arguments from the command-line must be preceded by a dash (-). It is prefixed – that lets getopt recognize command-line arguments as options. In fact, gets will not process arguments without the prefix --, and will terminate option processing at the first argument encountered lacking them.
- 2. The gets template differs slightly from the standard while loop, in that it lacks conditions bracket.
- 3. The gets construct is a highly functional replacement for the traditional getopt external command.

```bash
while getopt ":abc:fg" Option
# Initial declaration.
# a, b, c, d, e, f, and g are the options (flags) expected.
```

# Script Behavior

source . (dot command)
This command, when invoked from the command-line, executes a script. Within a script, a source file-name loads the file-name. Sourcing a file (dot-command) imports code into the script, appending to the script (same as the #include directive in a C program). The result is the same as if the "sourced line of code were present in the body of the script. This is in situations when multiple scripts use a common data file or function library.

# 15-22. "Including" a data file

```bash
#!/bin/bash
# Note that this example must be invoked with bash, i.e., bash.sh
# not sh example.sh

data-file # Load a data-file.
# Same effect as source, but more portable.

# Now, let's reference some data.
echo variable1 (from-file) = $variable1
echo variable3 (from-file) = $variable3

let sum = variable2 + variable4
echo Sum of variable2 + variable4 (from-file) = $sum
echo message1 (from-file) is "$message1"
# Escaped quotes
echo message2 (from-file) is "$message2"
```

```bash
# This is a data file loaded by a script.
# Files of this type may contain variables, functions, etc.
# It loads with 'source' or '.' from shell script.

# Let's initialize some variables.

variable1=23
variable2=474
variable3=5

message1="Greetings from *** LINENO *** of the data file!"
message2="Enough for now. Goodbye."

print_message () {
  # Echoes any message passed to it.

  if [ -z "$1" ];
    then
      return 1 # Error, if argument missing.
    fi

  echo

  until [ -z "$1" ];
    do
      # Step through arguments passed to function.
      echo -n "$1" # Echo args one time, suppressing line feeds.
      echo -n " " # Insert spaces between words.
      shift
      # Next one.
    done
  echo
  return 0
}
```
