# Advanced Bash-Scripting Guide

```
return_test 27      # o.k.
echo $?               # Returns 27.

return_test 255      # Still o.k.
echo $?               # Returns 255.

return_test 257      # Error!
echo $?               # Returns 1 (return code for miscellaneous error).
=======================================================================
return_test -151896    # Do large negative numbers work?
echo $?               # Will this return -151896?
                       # No! It returns 168.
=======================================================================
Version of Bash before 2.0b permitted
+# large negative integer return value.
# It happened to be a useful feature.
# Newer versions of Bash unfortunately plug this loophole.
# This may break older scripts.
# Caution!
=================================================================

exit 0
```

A workaround for obtaining large integer "return values" is simply to assign the "return
value" to a global variable.

```
Return_Val=          # Global variable to hold oversize return value of function.
alt_return_test () {
fvar=$fvar
Return_Val=$fvar
return                # Returns 0 (success).
}

alt_return_test 1      # 0
echo $?               # 1
echo "return value" = $Return_Val"

alt_return_test 256    # 256
echo "return value" = $Return_Val"

alt_return_test 257    # 257
echo "return value" = $Return_Val"

alt_return_test 25701 # 25701
echo "return value" = $Return_Val"
```

A more elegant way is to have the function **echo** "return value" to **stdout," and then
capture it by **command substitution**. See the [discussion of this](#) in **Section 36.7**.
