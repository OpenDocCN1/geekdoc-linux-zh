## 16.9. Miscellaneous Commands

Command that fit in no special category

- jot, seq

These utilities emit a sequence of integers, with a user-selectable increment.

The default separator character between each integer is a newline, but this can be changed with the -s option.

```bash
bash$ seq 5
1
2
3
4
5

bash$ seq -s : 5
1:2:3:4:5
```

Both jot and seq come handy in a for loop.

### Example 16-54. Using seq to generate arguments

```bash
#!/bin/bash
# Using "seq"

for a in $(seq 5) # Same as for a in 1 2 3 4 5
# May also use 'jot' (if present on system).
do
  echo -n "$a"
done
```

Example of using the output of a command to generate a list in a "for" loop.

```bash
COUNT=10
for a in $(seq $COUNT) # Yes, 'seq' also accepts replaceable parameter.
do
  echo -n "$a"
done
```

```bash
BEGIN=1
END=5

for a in $(seq $BEGIN $END) # Giving "seq" two arguments starts the count at the first one,
do
  echo -n "$a"
done
```

A simple example: Create a set of files.

```bash
COUNT=10
PREFIX=file

for filename in $(seq $COUNT)
do
  touch $PREFIX.$filename
# Or, can do other operations, such as rm, grep, etc.
done
```

### Example 16-55. Letter Count

```bash
#!/bin/bash
# letter-count.sh: Counting occurrences in a text file.
# Written by Stefano Palferi.
# Slightly modified by author.

MINARGS=2      # Script requires at least two arguments.
E_BADARG=1
FILE=$1

let LETTERS=$((# - 1)) # How many letters specified (command-line args).
# (Subtract 1 from number of command-line args.)

show_help() {
  echo "Usage: $0 file letters"
  echo "Note: arguments are case sensitive."
  echo "Example: $0 foobar.txt"
}

# Checks number of arguments.
if [ $# -lt $MINARGS ]; then
  echo "Not enough arguments."
  show_help
  exit $E_BADARG
fi
```

Wait, the script continues...

```bash
E_OPTERR=1
if [ "$#" -eq 0 ]; then
    # Script needs at least one argument.
  exit $E_OPTERR
fi

if [ ! -f $FILE ]; then
  echo "file $FILE does not exist."
  exit $E_BADARG
fi

# Counts letter occurrences
for n in $(seq $LETTERS); do
  shift
  if [[ -n "$1" | wc -c -eq 1 ]]; then # Checks arg.
    echo "$1" -> $(cat $FILE | tr -cd "$1" | wc -c) # Counting.
  else
    echo "$1 is not a single char."
  fi
done
exit $?
```

The **getopt** command parses command-line options preceded by a dash. This external command corresponds to the **getopts** builtin. Using **getopt** permits handling long options by means of the -l flag, and this also allows parameter reshaping.

### Example 16-56. Using getopt to parse command-line options

```bash
#!/bin/bash
# Using getopt

# Try the following when invoking this script:
# sh script.sh -a
# sh script.sh -abc
# sh script.sh -a -b -c
# sh script.sh -d
# sh script.sh -dXYZ
# sh script.sh -d XYZ
# sh script.sh -abcd
# sh script.sh -abcz
# sh script.sh -z
# Explain the results of each of the above.

E_OPTERR=1
if [ "$#" -eq 0 ]; then
    echo "Usage: $0 options [-a,b,c,d]"
    exit $E_OPTERR
fi

args=$(getopt -abcd -- "$@")

while [ -n "$1" ]; do
  case "$1" in
    -a) echo "Option a:$"
    -b) echo "Option b:$"
    -c) echo "Option c:$"
    -d) echo "Option d:$"
    *) break;
  esac
  shift
done

# It is usually better to use 'getopts' builtin in a script. See script.sh.
exit 0
```

The **run** command executes all scripts in a target directory, sequentially in filename order. In its default behavior, the command feeds a continuous string of characters followed by a line feed to stdout. A control-C terminates it. The output may be specified, which would continually output string to stdout. From the command-line or in a script, the output can be redirected or piped into a program expecting user input. In effect, this becomes sort of poor man's version. This particular feature may be used to create a large ASCII file on the fly:

```bash
yes (
  # Trivial emulation of "yes"
  local DEFAULT_TEXT="y"
  while true; do
    if [ -z "$1" ]; then
        echo "$DEFAULT_TEXT"
    else
        echo "$1" # expand and echo it.
    fi
  done # The only things missing are the --help and --version options.
)
```

Caution when piping yes to a potentially dangerous system, such as disk. It might have unintended consequences. The command parses variables, or more accurately echoes parsed variables. For example:

```bash
cat listfile* | sort | tee check.file | uniq | result.file
```
# The file "check.file" contains the concatenated sorted "listfiles," after the duplicate lines are removed by 'uniq'.
