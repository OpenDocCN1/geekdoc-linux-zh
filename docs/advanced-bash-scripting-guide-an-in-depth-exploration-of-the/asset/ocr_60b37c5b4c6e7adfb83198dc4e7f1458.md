# Example 9-13. Brownian Motion Simulation

```
# This script models Brownian motion:
# the random windings of tiny particles in a fluid,
# as they are buffeted by random currents and collisions.
# This is colloquially known as the "Drunkard's Walk."

# It can also be considered as stripped-down simulation of a
# Galton Board, a slanted board with a pattern of pegs,
# which down rolls a succession of marbles, one at a time.
# At the bottom is a row of slots or catches in which
# the marbles come to rest at the end of their journey.
# Think of it as a kind of Rain-bones Pachinko game.
# As seen by running the script,
# most of marbles cluster around the center slot.
# This is consistent with the expected binomial distribution.
# As a Galton Board simulation, the script
# displays such parameters as
# tilt-angle, rolling friction of the marbles,
# angles of impact, and elasticity of the pegs.
# To what extent does this affect the accuracy of the simulation?
```

```
PASSES=500 # Number of particle interactions / marbles.
ROWS=10 # Number of "collisions" (or horiz. peg rows).
RANGE=3 # 0 - 2 output range from $RANDOM.
POS=0 # Left/right position.
# Seed random number generator from PID
RANDOM=$ # of script.
```

```
declare -a Slots # Array cumulative results of passes.
NUMSLOTS=21 # Number of slots at bottom of board.
```

```
Initialize_Slots () {\ # Zero out all elements of the array.
for i in $( seq $NUMSLOTS )
do
  Slots[$i]=0
done
```
