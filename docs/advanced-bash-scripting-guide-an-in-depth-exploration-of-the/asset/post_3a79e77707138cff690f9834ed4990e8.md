
# Advanced Bash-Scripting Guide

on most Linux versions but will probably not work on other shells without modification.

# Introduction
===========

cdll allows easy moving between directories. When changing to a new directory the current one is automatically put onto a stack. By default 50 entries are kept, but this is configurable. Special directories can be kept for easy access - by default up to 10, but this is configurable. The most recent stack entries and the special entries can be easily viewed.

The directory stack and special entries can be saved to, and loaded from, a file. This allows them to be set up on login, saved before logging out or changed when moving to project.

In addition, cdll provides a flexible command prompt facility that allows, for example, a directory name in colour that is truncated from the left if it gets too long.

# Setting up cdll
==========

Copy cdll to either your local home directory or a central directory such as /usr/bin (this will require root access).

Copy the file datafile to your home directory. It will require and write access. This default file contains a directory stack and special entries.

To replace the cd command you must add commands to your login script. The login script is one or of:

```
/etc/profile
~/bash_profile
~/bash_login
~/profile
~/bashrc
/etc/bash.bashrc.local
```

To set up login, ~/.bashrc is recommended, for global (and root) setup add the commands to /etc/bash.bashrc.local

+ Set up on login, add the command:
- <dir>/cdll
- For example if cdll is in your local directory:
- ~/cdll
- If in /usr/bin then:
- /usr/bin/cdll

If you want to use this of the builtin cd command then add:
alias cd='cd_new'
We would also recommend the following commands:

+ - cd -U
- cd -D

If you want to use cdll's prompt facil then add the following:
CDL_PROMPTLEN=nn
Where nn is a number described below. Initially 99 would be suitable number.

Thus the script looks something like this:

###############################################################
# CD Setup                                                     
###############################################################
CDLPROMPTL=21      # Allow a prompt length of up to 21 characters
  /usr/bin/cdll      # Initialise cdll
alias s=$cd_new\ @  # Allow @ at the prompt to display history
cd -U               # Upload directories
cd -D               # Set default action to non-posix
###############################################################

The full meaning of a couple of caveats will become clear later. If another program changes the directory without calling cdll, then the directory won't be put on the stack and also if the prompt facility is used then this will not be updated. Two programs that can do is pushd and popd. To update the prompt and stack simply enter:

```
cd
```

Note that if the previous entry on the stack is the current directory then the stack is not updated.

Usage
=====
cd [dir] [0-9] [@sh] [-g <dir>] [-d] [-D] [-r<n>]
cd [0-9] [-R<n>] [<dir>:0-9] [-s<n>] [-S<n>]
[-u] [-U] [-f] [-F] [-h] [-V]

```
<dir>          Go to directory
O-n             Goto previous directory (0 is previous,
                               1 is last 1, etc.)
@               n is up to max history (Usually available as $)
@h              List history and special entries
@s              List special entries:
-<dir>          Go to literal names (bypass special names)
                This is to allow to access cdir '0','1',''h' etc
-d             Change default action verbose. (See note)
-D             Change default silent. (See note)
-S<n>           Go to the special entry
-S<n>           Go to the special entry <n>
                and replace it with the current dir
-r<dir>         Go to directory <dir>
                and then put it on special entry <n>
-R<n> [<dir>]     Go to directory <dir>
                and put cur on special entry <n>
-a<n>           Alternative suggested directory. See below.
-f <file>       Enter files to <file>
-u <file>       Update entries from <file>.
                If no filename then default file (~cdfile) is used
-F and -u are silent versions
-v              Print version number
-h              Help
-H              Detailed help
```

The examples assume non-default mode is set (that is, cd with no parameters will go to the most recent stack directory), that aliases have been set up for cd and as described above and cd's prompt facility is active and the prompt length is 21 characters.

```
/home/phil $
# List the entries with the @
History:
# Output of the command
...
# Skipped these entries for brevity
1 /home/phil/ummdev S1 /home/phil/perl
# Most recent two history entries
0 /home/phil/perl/eg S0 /home/phil/umm/ummdev
# and two special entries are shown

/home/phil cd /home/phil/utils/cdll
# Change directories
/home/phil/utils/cdll $ 
# Prompt reflects the directory.
History:
# New history
...
1 /home/phil/perl/eg S1 /home/phil/perl
# History entry 0 has moved to 1
0 /home/phil S0 /home/phil/umm/ummdev
# and the most recent has entered
```

```
/home/phil/utils/cdll $ cd 1
# Go to history entry 1
/home/phil/perl/eg$
# Current directory is now what is 1
```

```
/home/phil/perl/eg $ cd -sl
```
