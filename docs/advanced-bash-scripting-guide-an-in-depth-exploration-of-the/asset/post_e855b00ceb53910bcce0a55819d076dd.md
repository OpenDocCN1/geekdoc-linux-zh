Example 16-23. du: DOS to UNIX text file conversion.

```bash
#!/bin/bash
# Du.sh: DOS to UNIX text file converter.

E_WRONGARGS=85
if [ -z "$1" ]
then
    echo "Usage: `basename $0` filename-to-convert"
    exit $E_WRONGARGS
fi
NEWFILENAME=$1.unix

CR='\015'  # Carriage return.
# 015 is octal ASCII code for CR.
# Lines in a DOS text file end in CR-LF.
# Lines in a UNIX text file end in LF only.

tr -d $CR < $1 > $NEWFILENAME
# Delete CR's and write to new file.

echo "Original DOS text file is \"$1\""
echo "Converted UNIX text file is \"$NEWFILENAME\""

exit 0
```

# Example 16-24. rot13: ultra-weak encryption.

```bash
#!/bin/bash
# rot13.sh: Classic rot13 algorithm,
#                 encryption that might fool a 3-year old
#                 for about 10 minutes.

# Usage: ./rot13.sh filename
# or    ./rot13.sh <filename>

cat "$@" | tr "a-zA-Z" "n-za-ZA-M" # "a" goes to "n", "b" to "o..."
# The cat "$@" construct
```

# tr variants

The tr has two historic variants. The BSD version does not use brackets (tr a-z A-Z), the SysV one uses (tr '[a-z]' '[A-Z]'). The GNU version of tr resembles the BSD one.

A filter that wraps lines of input to fmt is Kamil Tomar's fmt, available from http://www.cs.berkeley.edu/~amc/. See Example 16-26 and Example A-1.

Simple-minded file formatter, used to wrap lines.

Example 16-26. Formatted list.

```bash
#!/bin/bash
WIDTH=40
# The output is wrapped to $WIDTH characters.
pr -s $WIDTH < input.txt
```

The `pr` command is used to format text for printing, adding headers, footers, and page numbers. It can also paginate text into columns.

```bash
# -w sets the width of the output
# -s adds a custom suffix to each page
# -h adds a header
pr -w 80 -s "--- Page " -h "My Report" input.txt
```

The `fold` command is used to wrap text into lines of a specified width.

```bash
# -w specifies the maximum width of each line
# -s breaks only at spaces
fold -w 80 -s input.txt > wraped_output.txt
```

The `column` command is used to format text into multiple columns.

```bash
# -t treats the input as a table and aligns columns
column -t < input.txt
```

The `paste` command joins lines of files into a single line. By default, it merges them columns.

```bash
# Join two files with a comma delimiter
paste -d ',' file1.txt file2.txt
```

The `sort` command is used to sort lines of text files.

```bash
# Sort numerically in reverse order
sort -nr numbers.txt
```

The `uniq` command is used to filter or sort adjacent lines in a file. It requires the input to be sorted first.

```bash
# Filter out duplicate lines
sort file.txt | uniq
```

The `grep` command is used to search for lines that match a regular expression in files.

```bash
# Search for lines containing "error"
grep "error" log.txt
```

The `sed` command is a stream editor used for filtering and transforming text.

```bash
# Replace the first occurrence of "old" with "new" globally
sed 's/old/new/g' file.txt
```

The `awk` command is a powerful pattern processing language for text and data.

```bash
# Print the first and third columns of a file
awk '{print $1, $3}' data.txt
```
