## 示例 23-2. 将进程替换的输出重定向到循环。

```bash
#!/bin/bash
# psub.bash

# 受 Diego Molina 灵感（感谢！）。

declare -a array
while read
do
  array[${array[@]}]="$REPLY"
done < < sed -e 's/bash/CRASH-BANG/!' | grep bin | awk '{print $1}'
# 通过进程替换设置默认 'read' 变量 $REPLY，
# 然后将其复制到数组。
echo "${array[@]}"

exit $?
```

## 第 24 章 函数

像“真正的”编程语言一样，Bash 也拥有函数，尽管实现方式有限。函数是一个子程序，执行一组操作的“黑盒”，执行指定的任务。当有重复代码且只有细微变化时，考虑使用函数。

```bash
function_name {
  command...
}
```

或者

```bash
function_name() {
  command...
}
```

这种形式更受 C 程序员的欢迎（且移植性更好）。像 C 一样，函数的左括号可以选择出现在第二行。

```bash
function_name() {
  command...
}
```

函数可以被“压缩”成单行。

```bash
fun () { echo "This is a function"; }
# 在这种情况下，必须紧跟在最后的命令后面。

```bash
fun () { echo "Even single-command function!" }
通过名称被调用并触发。调用等同于命令。

## 24-1. 简单函数

```bash
#!/bin/bash
# empty-function.sh

empty () {
  exit 0 # 在这里不会退出！

# sh empty-function.sh
# empty-function.sh: line 6: syntax error near unexpected token
# empty-function.sh: line 6: )

# echo?
# 注意只包含注释的函数是空的
func () {
# Comment 1.
# Comment 2.
# 这仍然是一个空函数。
# 感谢 Mark Bova 指出这一点。
}
# 以上会导致错误信息。

# 然而..
not_quote_empty () {
  illegal_command
# 包含此函数的脚本*不会*崩溃，
# 只要该函数没有被调用。
}

not_empty () {
:
# 包含 :（空命令），这是可以。
}
