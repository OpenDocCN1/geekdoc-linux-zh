# 29.2. /proc

The /proc directory is actually a pseudo-filesystem. The files in /proc mirror running system and kernel processes and contain information and statistics about them.

```
bash$ cat /proc/devices
Character devices:
1 mem
2 pty
3 tty
4 ttyS
5 cua
7 vcs
10 misc
14 sound
29 fb
36 netlink
128 ptm
136 pts
162 raw
254 pcmcia

Block devices:
1 randisk
2 fd
3 ide0
9 md
```
