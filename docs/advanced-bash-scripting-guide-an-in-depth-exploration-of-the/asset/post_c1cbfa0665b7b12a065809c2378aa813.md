# Appendix B. Reference Cards

The following reference cards provide a useful summary of certain scripting concepts. The foregoing text treats these matters in more depth, as well as giving usage examples.

## Table B-1. Special Shell Variables

| Variable | Meaning |
| --- | --- |
| $0 | Filename of script |
| $1 | Positional parameter #1 |
| $2 - $9 | Positional parameters #2 - #9 |
| ${10} | Positional parameter #10 |
| $# | Number of positional parameters |
| "$*" | All the positional parameters (as a single word) |
| "$@" | All the positional parameters (as separate strings) |
| ${#*} | Number of positional parameters |
| ${#@} | Number of positional parameters |
| $? | Return value |
| $$ | Process ID (PID) of script |
| $- | Flags passed to script (using set) |
| $ _ | Last argument of previous command |
| $! | Process ID (PID) of last job run in background |

* Must be quoted, otherwise it defaults to $@$.

## Table-4. Parameter Substitution and Expansion

| Expression | Meaning |
| --- | --- |
| ${var} | Value of var |
| ${var:-DEFAULT} | If not set |
| ${var:+DEFAULT} | If not set or empty |
| ${var:=DEFAULT} | If not set |
| ${var:?DEFAULT} | If not set or empty |
| ${var#DEFAULT} | |

## B-5. String Operations

| Expression | Meaning |
| --- | --- |
| ${#string} | Length of $string |
| ${string:position} | Extract substring from $string | |
| ${string#substring} | Strip shortest match from front of $string |
| ${string##substring} | Strip longest match of front of $string |
| ${string%substring} | Strip shortest match from back of $string |
| ${string%%substring} | Strip longest match of back of $string |
| ${string/substring/replacement} | Replace first match of $substring with $replacement |
| ${string//substring/replacement} | Replace all matches of $substring with $replacement |
| ${string#$substring/replacement} | If $substring matches front end of $string, substitute $replacement for $string |
| ${string%substring/replacement} | If $substring matches back end of $string, substitute $replacement for $string |
