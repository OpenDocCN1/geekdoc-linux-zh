# 7.2. File test operators

Returns true if...

+   -e file exists

+   -a file exists

This is identical in effect to -e. It has been "deprecated," [34] and its use is discouraged.

+   -f file is a regular file (not a directory or device file)

+   -s file is not zero size

+   -b file is a directory

+   -c file is a character device

```
device0="/dev/sda2" # / (root directory)
if [ -b "$device0" ]
then
echo "$device0 is a block device."
fi

# /dev/sda2 is a block device.
```

```
devicel=/dev/tty1 # PCMCIA modem card.
if [ -c "$devicel" ]
then
echo "$devicel is a character device."
fi

# /dev/tty1 is a character device.
```

+   -p file is a pipe

```
function show_input_type() {
  -p /dev/fd/0 && echo PIPE || echo STDIN
}
show_input_type "Input" # STDIN
echo "Input" | show_input_type # PIPE
# This example courtesy of Carl Anderson.
```

+   -h file is a symbolic link
