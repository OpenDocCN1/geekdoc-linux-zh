# # Chapter 7. Tests

Every reasonably complete programming language can test for a condition, and then according to the result of the test. Bash has introduced the test command, various bracket and parenthesis operators, and the if/then construct.

# ## 7.1. Test Constructs

+   - An if/then construct tests whether the exit status of a list of commands is 0 (since 0 means “success” by UNIX environ), and if, executes one or more commands.
- There exists a dedicated command called ([left bracket special). It is a synonym for test, and a builtin for efficiency reasons. This command considers its arguments as comparison expressions or file tests and returns an exit status corresponding to the result of the comparison (0 for true, 1 for false).
- With version 2.02, Bash introduced ([ extended test command, which performs comparisons in a manner more familiar to programmers from other languages. Note that [[ is a keyword, not a command.

Bash sees [[ $a -lt $b ]] as a single element, which returns an exit status.

+   - The (( )) and let.. constructs return an exit status, according to the arithmetic expressions they evaluate to a non-zero value. The arithmetic-expansion constructs may therefore be used to perform arithmetic comparisons.

```
(( 0 & 1 ))
echo $? # 1 ***
# And so ...
let *num = (( 0 & 1 ))
echo $num # 0
# But ...
let *num = (( 0 & 1 ))
echo $? # 1 ***
```

```
(( 200 | 11 ))
echo $? # 0 ***
let *num = (( 200 | 11 ))
echo $num # 1
let *num = (( 200 | 11 ))
echo $? # 0 ***
```

```
(( 200 | 11 ))
echo $? # 0 ***
let *num = (( 200 | 11 ))
echo $num # 203
let *num = (( 200 | 11 ))
echo $? # 0 ***
```
