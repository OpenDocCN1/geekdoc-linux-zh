The id command shows the effective IDs only when they differ from the real ones.

Also see Example 9-5.

The lid (list ID) command shows the group(s) that given user belongs to, or alternately, the users belonging to a given group. It may be invoked only by root.

```
root# lid bozo
bozo(gid=500)

root# lid daemon
bin(gid=1)
demon(gid=2)
adm(gid=4)
lp(gid=7)
```

Show all users logged on to the system.

```
bash$ who
bozo tty1      Apr 27 17:45
bozo pts/0    Apr 27 17:46
bozo pts/1    Apr 27 17:47
bozo pts/2    Apr 27 17:49
```

The -m gives detailed information about only the current user. Passing any two arguments to who is the equivalent of who -m, as in am i or who The Man.

```
bash$ who -m
localhost.localdomainbozo pts/2      Apr 27 17:49
```

whoami is similar to who -m, but only lists the user name.

```
bash$ whoami
bozo
```

Show all logged users and the processes belonging to. This is an extended version of who. The output of w may be piped to grep to find a specific user and/process.

```
bash$ w grep startx
bozo tty1               4:22pm 6:41 4.47s 0.45s startx
```

Show current user's login name (as found in /var/run/utmp). This is a near-equivalent to whoami.above.

```
bash$ logname
bozo
bash$ whoami
bozo
```
