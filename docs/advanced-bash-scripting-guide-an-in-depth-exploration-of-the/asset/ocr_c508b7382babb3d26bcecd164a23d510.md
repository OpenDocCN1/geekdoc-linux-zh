An exceptionally clever use of case involves testing for command-line parameters.

```
#!/bin/bash
case "$1" in
") echo Usage: $($#*/); exit $E_PARAM;
# No command-line parameters,
# or first parameter empty.
# Note that $($#*/) is ${var#pattern} param substitution.
# Net result is $0

*) FILENAME=./1;
## starts passed as argument ($1)
## replace it with /$1
## so further commands don't interpret it
## as an option.

*) FILENAME=$$1;
# Otherwise, $1.
esac
```

Here is a straightforward example of command-line parameter handling:

```
#!/bin/bash

while [ $# -gt 0 ]; do
case "$1" in
  -d|--debug)
    ## -d or "--debug" parameter?
    DEBUG=1
    ;;
  -c|--conf)
    CONFILE="$2"
    shift
    if [ ! -f $CONFILE ]; then
      echo "Error: Supplied file doesn't exist!"
      exit $E_CONFILE
    ## File not found error.
    fi
    ;;
esac
shift
# Check next set of parameters.
done
```
