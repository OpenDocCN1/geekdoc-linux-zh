## 示例 15-2. printf 的实际应用

```bash
#!/bin/bash
# printf demo

declare -r PI=31.4159265358979  # 只读变量，即常量。
declare -r DecimalConstant=31373

Message1="Greetings,"
Message2="Earthling."
echo

printf "PI to 2 decimal places = %1.2f" $PI
echo
printf "PI to 9 decimal places = %1.9f" $PI  # 它能正确进行四舍五入。

printf "\n"                          # 打印换行符，
                              # 等于 'echo' . .

printf "Constant = %t\d" $DecimalConstant  # 插入制表符 (\t)。

printf "%s %s \n" $Message1 $Message2
echo
===============================================
# 模拟 C 函数 sprintf().
# 使用格式化字符串加载变量。
echo
PI2=$(printf "%1.12f" $PI)
echo "PI to 12 decimal places = $PI2"  # 舍入误差！
Msg=$(printf "%s %s \n" $Message1 $Message2
echo $Msg; echo $Msg

# 恰好，'sprintf' 函数现在可以作为
#+ 可加载模块到 Bash 中访问，
#+ 但这不是可移植的。

exit 0
```

## 示例 15-3. 使用 read 进行变量赋值

```bash
#!/bin/bash
# "读取" 变量

echo -n "Enter the value of variable 'var1':"
# -n 选项抑制换行符。

read var1
# 注意 var1 前面没有 '$'，因为它 正在被赋值。

echo "var = $var1"

echo

# 单个 'read' 语句可以设置多个变量。
echo -n "Enter the values of variables 'var2' and 'var3'"
echo -n "(separated by a space or tab):"
read var2 var3
echo var2=$var2 var3=$var3
# 如果你只输入了一个值，
#+ 其他变量将保持保持未设置状态（空）。

exit 0
```

没有赋值变量的 `read` 会将输入存到专用的 `$REPLY` 中。

## 示例 15-4. 当 read 没有变量时会发生什么

```bash
#!/bin/bash
# read-novar.sh
echo

#-
echo -n "Enter a value:"
read var
echo "$var" = "$var"
# 这里都是符合预期的。
#-

echo

#-
echo -n "Enter another value:"
read # 为 'read' 未提供变量，因此...
#+ 输入到 'read' 被赋值给默认变量 $REPLY
var=$REPLY
echo "$var" = "$var"
# 这等同于第一个代码块。
```

通常情况下，输入 `\` 在 `read` 期间抑制换行符。`-r` 选项允许输入的 `\` 被字面解释。

## 示例 15-5. read 的多行输入

```bash
#!/bin/bash
echo
echo "Enter a string terminated by a \ , then press <ENTER>."
echo "Then, enter a second string (no \ this time), and again press <ENTER>"
read -r var1      # 当读取 $var1 时，\ 抑制了换行符。
                  # 第一行 \
                  # 第二行
echo var1 = "$var1"
          # 第一行第二行

# 对于每一行以 \ 结尾的行
#+ 你会在下一行获得一个提示，以继续向 var1 输入字符。
echo; echo
echo "Enter another string terminated by a \ , then press <ENTER>."
read -r var2  # -r 选项导致 "\" 被字面读取。
              # 第一行 \
echo var2 = "$var2"
      # 第一行
```

第 15 章 内部命令与内置命令

`read` 命令有一些有趣的选项，允许回显提示并读取按键。

- -s: 意味着不显示输入。
- -n: 仅接受 N 个字符的输入。
- -p: 在读取输入之前显示以下提示。

使用这些选项很微妙，因为它们需要处于正确的顺序。`read` 的 `-n` 选项还允许检测箭头键和某些不寻常键。

### 示例 15-6. 检测箭头键

```bash
#!/bin/bash
# arrow-detect.sh: 检测箭头键以及其他几个键。
# 感谢 Magi 向我展示。
------------------------------------
# 键位生成的字符代码。
arrowup='A'
arrowdown='B'
arrowright='C'
arrowleft='D'
insert='Z'
delete='3'
------------------------------------

SUCCESS=0
OTHER=65

echo -n "Press a key..." # 如果按了未列出的键，可能需要按 ENTER。
read -n 3 key # 读取 3 个字符。

echo -n "$key" | grep "$arrowup" # 检查是否检测到字符代码。
if [ "$key" -eq $SUCCESS ]; then
    echo "Up-arrow key pressed."
    exit $SUCCESS
fi

echo -n "$key" | grep "$arrowdown"
if [ "$key" -eq $SUCCESS ]; then
    echo "Down-arrow key pressed."
    exit $SUCCESS
fi

echo -n "$key" | grep "$arrowright"
if [ "$key" -eq $SUCCESS ]; then
    echo "Right-arrow key pressed."
    exit $SUCCESS
fi

echo -n "$key" | grep "$arrowleft"
if [ "$key" -eq $SUCCESS ]; then
    echo "Left-arrow key pressed."
    exit $SUCCESS
fi

echo -n "$key" | grep "$insert"
if [ "$key" -eq $SUCCESS ]; then
    echo "Insert key pressed."
    exit $SUCCESS
fi

echo -n "$key" | grep "$delete"
if [ "$key" -eq $SUCCESS ]; then
    echo "Delete key pressed."
    exit $SUCCESS
fi

echo "Some other key pressed."
exit $OTHER

#!//bin/bash

uparrow='[A'

read -s -n 3 p "Hit arrow key: " x

case $x in
$uparrow)
    echo "You pressed up-arrow"
    ;;
$downarrow)
    echo "You pressed down-arrow"
    ;;
$leftarrow)
    echo "You pressed left-arrow"
    ;;
$rightarrow)
    echo "You pressed right-arrow"
    ;;
esac
exit $?
```

## 示例 15-7. 使用重定向使用 read

```bash
#!/bin/bash

read var1 <data-file
echo var1 = $var1
# var1 被赋值为输入文件 "data-file" 的整个第一行

read var2 <data-file
echo var2 = $var2 var3 = $var3
# 注意 "read" 不符合直觉的行为
# 1) 回置到输入文件的开头。
# 2) 每个变量现在被赋值一个相应的由空格分隔的字符串，
#   而不是整行文本。
```
