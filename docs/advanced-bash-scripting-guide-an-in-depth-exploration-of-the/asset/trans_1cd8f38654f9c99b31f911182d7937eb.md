## 8.1. 运算符

### 赋值

变量赋值
初始化或更改变量的值

= 通用赋值运算符，同时适用于算术赋值和字符串赋值。

```bash
var=27
category=minerals # "=" 后面不允许有空格
```

不要将 "=" 赋值运算符与 = 测试运算符混淆。

```bash
# 作为测试运算符使用
if [ "$string1" = "$string2" ]
then
  command
fi

# 使用 [ "$string1" = "Xstring2" ] 更安全，
# 以防在其中一个变量为空时产生错误信息。
# (前缀 "X" 字符会相互抵消。)
```

### 算术运算符

- + 加法
- - 减法
- * 乘法
- / 除法
- ** 幂运算

```bash
Bash 版本 2.02 引入了 ** 幂运算符。
let z=5**3 # 5 * 5 * 5

```

% 取模，或 mod（返回整数除法运算的余数）

```bash
$ expr 5 % 3
2
5/3 = 1, 余数为 2
```

# 高级 Bash 脚本指南

该运算符用于许多地方，例如在特定范围内生成数字（参见示例 9-11 和示例 9-15）以及格式化程序输出（参见示例 27-16 和示例 A-6）。它甚至可以用于生成质数（参见示例 A-15）。取模在数值计算中出现的频率异常高。

# 示例 8-1 最大公约数

```bash
#!/bin/bash
# gcd.sh: 最大公约数
# 使用欧几里得算法

# “最大公约数”(gcd)
# 是能整除两个数且无余数的最大整数。

# 欧几里得算法使用连续除法。
# 在每次循环中，
# 被除数 <--- 除数
# 除数 <--- 余数
# 直到 $remainder = 0
# 在最后一次中，gcd = 被除数。

# 关于欧几里得算法的极佳讨论，请参见
# Jim Loy 的网站，http://www.jimloy.com/number/euclids.htm。

---
# 参数检查
ARGS=2
E_BADARGS=85

if [ $# -ne "$ARGS" ];
then
    echo "Usage: \`basename $0\` first-number second-number"
    exit $E_BADARGS
fi

---
gcd() {
    dividend=$1    # 任意赋值。
    divisor=$2     # 两个数哪个更大并不重要。
                   # 为什么呢？

    remainder=1     # 如果在测试括号内使用未初始化的变量
                   # 会导致错误信息。

    until [ "$remainder" -eq 0 ];
    do
        # 必须预先初始化！
        let remainder=$dividend % $divisor
        dividend=$divisor
        divisor=$remainder # 现在对两个最小的数重复。
    done
    echo $dividend # 欧几里得算法
}

gcd $1 $2 # 最后的 $
```

# 高级 Bash 脚本指南

```bash
echo; echo GCD of $1 and $2 = $dividend;
```

# 1) 检查命令行参数以确保它们是整数，
# 如果不是，则带有相应的错误信息并退出脚本。
# 2) 重写 gcd () 函数以使用局部变量。

exit 0

# 示例 8-2. 使用算术运算

```bash
#!/bin/bash
# 用 10 种不同的方法数到 11。
n=1; echo -n "$n"

let "n = $n + 1"  # let "n = n + 1" 同样有效。
echo -n "$n"
```

```bash
$((n = n + 1))
# : 是必须的，否则 Bash 会尝试
# 将 $($($n + 1)) 解释为命令。
echo -n "$n"
```

```bash
((n = n + 1))
# 上述方法的更简单替代方案。
#感谢 David Lombard 指出这一点。
echo -n "$n"
```

```bash
$[$n = n + 1]
# : 是必须的，否则 Bash 会尝试
# 将 "[$n = n + 1]" 解释为命令。
# 如果 "$n" 初始化为字符串，则有效。
```

# 高级 Bash 脚本指南

```bash
echo -n
n[$n + 1]
# 如果 "$n" 初始化为字符串，则有效。
# 这种构造已过时且不可移植。
# 感谢 Stephanie Chelas。
echo -n "$n"

# 现在 C 风格的自增运算符。
# 这种
# 感谢 Frank Wang 指出这一点。

++

 = "n = n + 1"  # 这种运算符也有效。
echo -n "$n"

n))         # 这种运算符也有效。
echo -n "$n"

((n))       # 这种运算符也有效。
echo -n "$n"

$((n))      # 这种运算符也有效。
echo -n "$n"

++n         # 这种也有效。
echo -n "$n"

[$++n]         # 这种也有效
echo -n "$n"

echo

echo 0
```

旧版本 Bash 中的整数是有符号的长型（32位）整数，范围为 -2147483648 到 2147483647。超出限制的操作会导致错误的结果。

```bash
echo $BASH_VERSION    # 1.14
a=2147483646
let a="a+1"      # 增加 "a"
echo "a=$a"      # a = 2147483647 再次越界。
let a="a+1"      # = -2147483648
echo "a=$a"      # 错误：超出范围，
# 且左侧位符号位已被设置
# 导致结果为负数。
```

从 2.05 版本开始，Bash 处理 64 位整数。

Bash 不理解浮点算术。它将包含小数点的数字视为字符串。

```bash
a=1.5
let "b = $a + 1.3"  # 错误。
# t2.sh: let: b = 1.5 + 1.3: : syntax error
# (错误标记为 ".5 + 1.3")
echo "b=$b"      # b=1
```
在不需要浮点计算或数学函数的脚本中使用 b。

# 高级 Bash 脚本指南

```bash
if [ $condition1 ] && [ $condition2 ];
then
    echo "两个条件都真"
else
    echo "至少有一个条件为假"
fi

if [ $condition1 ] || [ $condition2 ];
then
    echo "至少有一个条件为真"
else
    echo "两个条件都不为真"
fi

if [ ! $condition1 ];
then
    echo "条件为假"
else
    echo "条件为真"
fi
```
