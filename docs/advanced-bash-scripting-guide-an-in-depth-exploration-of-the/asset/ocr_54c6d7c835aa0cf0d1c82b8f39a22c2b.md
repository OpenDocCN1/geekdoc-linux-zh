```
echo

if [ TRUE ]
then
alias rr="ls -1"
echo "Trying \rr\" within if/then statement:"
rr /usr/X1R6/bin/mk* # Error message results!
# Aliases not expanded within compound statements.
echo "However, previously expanded aliases still recognized:"
l /usr/X1R6/bin/mk*
fi
```

```
echo

count=0
while [ $count -lt 3 ]
d
alias rr="ls -1"
echo "Trying \rr\" within \while\" loop:"
rrr /usr/X1R6/bin/mk* # Aliases will not expand everywhere here.
# alias.sh: line 57: rrr: command not found

let count+=1
done
```

```
echo;

alias xyz='cat $0' # Script lists itself.
xyz # Note strong quotes.
# This seems to work,
# although Bash documentation suggests that it shouldn't.
#
# However, as Steve Jacobson points out,
+# the "$0" parameter expands immediately upon declaration of the aliases.
```

**The unalias command removes a previously set *alias*.

**Example 25-2. unalias: Setting and unsetting an alias**

```
#!/bin/bash
# unalias.sh

shop -s expand_aliases # Enables alias expansion.
nalias llm='ls -al | more'
llm

echo

unalias llm # Unset alias.
llm
# Error message results, since 'llm' is no longer recognized.

exit 0
bash ./unalias.sh

```
