# Advanced Bash-Scripting Guide

Arithmetic evaluation of octal /hexadecimal constants takes place automatically within a [[ [ ... ]] construct.

Following an if, the test command does not recognize the brackets ( ) or [[ ]] are strictly necessary.

```
dir=/home/bozo

if cd "$dir" 2>/dev/null; then # 2>/dev/null hides error message.
    echo "Now in $dir"
else
    echo "Can't change to $dir.
fi
```

The "COMMAND" returns the exit status of COMMAND.

Similarly, a condition within test brackets may stand alone without an if, when used in combination with a list construct.

```
var1=20
var2=22
[ "$var1" -ne "$var2" ] // echo $var1 is not equal to $var2
home=/home/bozo
-d "$home" // echo $home directory does not exist.
```

(( )) expands and evaluates an arithmetic expression. If the expression evaluates as zero, it returns an exit status of 1, or "false". A non-zero expression returns an exit status of 0, or "true". This is marked to contrast using the test and [ ] constructs previously discussed.
