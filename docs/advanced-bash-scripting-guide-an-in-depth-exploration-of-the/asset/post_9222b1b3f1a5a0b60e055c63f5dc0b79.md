groff, tbl, eqn

Yet another markup and display formatting language is groff. This is the enhanced GNU version of the venerable UNIX roff/roff display and typesetting package. Manpages use groff.

The tbl table processing utility is considered part of groff, as its function is to convert table markup into groff commands.

The eqn processing utility is likewise part of groff, and its function is to convert equation markup into groff commands.

## 16.5. File and Archiving Commands

### Archiving

### tar

The standard UNIX archiving utility.[75] Originally a Tape ARchiving program, it has developed into a general purpose package that can handle all manner of archiving with all types of devices, ranging from tape drives to regular files using `stdout` (see Example 3-4). GNU tar has been patched to accept various compression filters, for example: `tar czvf archive_name.tar.gz`, *, which recursively archives and `gzips` all files in a directory tree except `dofiles` in the current working directory (PWD).[76]

Some tar options:

- 1. -c create (a new archive)
- 2. -x extract (files from existing archive)
- 3. --delete delete (files from existing archive)
> This option will not work on magnetic tape devices.

- 4. -r append (files to existing archive)
- 5. -A append (tar to existing archive)
- 6. -t list (contents of existing archive)
- 7. -u update archive
- 8. -d compare archive with specified filesystem
- 9. --after-date only process files with a date stamp after specified date
- 10. -z zip the archive (compress or uncompress, depending on combined with the -c or -x) option
- 11. -j bzip2 the archive

> It may be difficult to recover data from a corrupted zipped archive. When importing files, make multiple backups.

### shar

Shell archiving utility. The text and/or binary files in a shell archive are concatenated without compression, and the result archive is essentially a shell script, complete with #/bin/sh header, containing all the necessary archiving commands, as well as the files themselves. Unprintable binary characters in the target file(s) are converted to ASCII characters in the output shar. Shar archives show up in Usenet groups, whereas shar has been replaced by tar/gzip. The unshar command unpacks shar archives.

The mailshar command is a Bash script that uses shar to concatenate multiple files into a single one for e-mailing. This script supports compression and uencoding.

### ar

Creation and manipulation utility for archives, mainly used for binary object file libraries.

### rpm

The Red Hat Package Manager, or rpm utility provides a wrapper for source or binary archives. It includes commands for installing and checking the integrity of packages, among other things.

A simple rpm -i package_name.rpm usually suffices to install a package, though there are many more options available.

> rpm -qf identifies which package a file originates from.

```bash
bash$ rpm -qf /bin/ls
coreutils-5.2.1-31
```

> rpm -qa gives a list of all installed rpm packages on a given system. rpm -qa package_name lists only the package(s) corresponding to package_name.

### cpio

This specialized archiving copy command (cpio input and output) is rarely seen anymore, having supplanted by tar/gzip. It still has uses, as moving a directory tree. With an appropriate block size (for copying) specified, it can be appreciably faster than tar.

## Example 16-30. Using cpio to move to a directory tree

```bash
#!/bin/bash

# Advantages of using 'cpio':
# Speed of copying. It's faster than 'tar' with pipes.
# Well suited for copying special files (named pipes,)
```

### rpm2cpio

This command extracts a cpio archive from an rpm one.

## Example 16-31. Unpacking an rpm archive

```bash
#!/bin/bash
# de-rpm.sh: Unpack an 'rpm' archive

: ${1}?Usage: `basename $0` target-file"
# Must specify 'rpm' archive name as an argument.

TEMPFILE=$5.cpio                # Tempfile with "unique" name.
                                # $5 is process ID of script.

rpm2cpio < $1 > $TEMPFILE         # Converts archive into
                                # cpio archive.
cpio --make-directories -F $TEMPFILE -i # Unpacks cpio archive.
rm -f $TEMPFILE                  # Deletes cpio archive.
```

### pax

The pax portable archive exchange facilitates periodic file backups and is cross-compatible between various flavors of UNIX. It was designed to replace tar and cpio.

```bash
pax -wf daily_backup.pax ~/linux-server/files
# Creates a tar archive of all files in the target directory.
```

```bash
# Note that the options pax must be in the correct order --
+# pax -fw    has an entirely different effect.

pax -f daily_backup.p
# Lists the files in the archive.

pax -rf daily_backup.p /bsd-server/files
# Restores the backed-up files from the Linux machine
# onto bsd one.
```

Note that pax handles many of the standard archiving commands.

## Compression

### gzip

The standard GNU/UNIX compression utility, replacing the inferior and proprietary compress. The corresponding decompression command is gzip, which is equivalent to -d.

- The -c option selects the output of gzip to stdout. This is useful when piping to other commands.

Similar to the zcat command, bcat decompresses a gzipped file to stdout. This is, in effect, a cat command that compresses files (including files processed with compress).

- On some common UNIX systems, zcat is a synonym for uncompress -c, and will not work on gzipped files.
See also Example 7-7.

### zip2

An alternate compression utility, usually more efficient (but slower) than gzip, especially on large files. The decompression command is bunzip2.

Similar to the zcat command, bcat decompresses a bzipped2-ed file to stdout.

- Newer versions of tar have been patched with zip2 support.

### compress, uncompress

This is an older, proprietary compression utility found in commercial UNIX distributions. The more efficient gzip has largely replaced it. Linux distributions generally include a compress workalike for compatibility, although gzip can unarchive files treated with compress.

- The znew command transforms compressed files into gzipped ones.

### sq

Yet another compression (squeeze) utility, a filter that works only on sorted ASCII lists. It uses the standard syntax for a filter, sq < input-file > output-file. But not as fast as gzip.

- The output of sq may be piped to gzip for further compression.

### zip, unzip

Cross-platform file archiving utility compatible with DOS pkzip.exe, "Zipped archives seem to be a more common medium of file exchange on the Internet using "tarballs."
