Write your scripts in a modular and coherent fashion, [127] so they can be reorganized and tightened as necessary. Some of the optimization techniques applicable to high-level languages work for scripts, but others, such as loop unrolling, are mostly irrelevant. Above all, use common sense.

# ## 36.7.1. Ideas for more powerful scripts

+   - You have a problem that you want to solve by writing a Bash script. Unfortunately, you don't know where to start. One method is to plunge right in code and code those parts of the script that come easily, and write the hard parts as pseudo-code.

```
#!/bin/bash
ARGCOUNT=1 # Need name as argument.
E_WRONGARGS=65

if [ number-of-arguments -is-not-equal "$ARGCOUNT" ]; then
  # Can't figure out how to code this . . .
  #+ . . so write it in pseudo-code.
else
  echo "Usage: name-of-script name"
  exit $E_WRONGARGS # More pseudo-code.
fi

.
exit 0

# Later on, substitute working code for the pseudo-code.
# Line 6 becomes:
if [ $# -ne "$ARGCOUNT" ]
```
