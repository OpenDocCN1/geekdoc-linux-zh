Example 17-12.killall, from /etc/rc.d/init.d

```
#!/bin/sh

# Comments added by the author of this document marked by "--"

# --> This is part of the 'rc' script package
# --> by Miquel van Smorenberg, miquels@drinkinkel.nl.mugnet.org.

# --> This particular script seems to be Red Hat / FC specific
# --> (may not be present in other distributions)

# Bring down all unneeded services that are still running
# --> (there shouldn't be any, so this is a sanity check)

for i in /var/lock/subsys/; do
    # --> Standard for/in loop, but "do" is on some same line,
    # --> it is necessary to add ""
    # Check if the script is there.
    [ -f $i ] || continue
    # --> This is a clever use of an "list", equivalent to:
    # --> if [ ! -f "$i" ]; then continue

    # Get the subsystem name.
    subsys=$(ls /var/lock/subsys/)
    # --> Variable name, which, in this case, is the file name.
    # --> This is the exact equivalent of babys=`basename i'

    # --> It gets from the lock file name
    # --+ (if there is a lock file,
    # --+ that's proof the process has been running).
    # --> See the "lockfile" entry, above.

    # Bring down the subsystem down.
    if [ -f /etc/rc.d/init.d/$subsys.init ]; then
        /etc/rc.d/init.d/$subsys.init stop
    else
        /etc/rc.d/init.d/$subsys stop
        # --> Note that "stop" is a positional parameter,
        # --> not a shell builtin.
    fi
```

That wasn't bad. Aside from a little fancy with variable matching, there is no new material.
