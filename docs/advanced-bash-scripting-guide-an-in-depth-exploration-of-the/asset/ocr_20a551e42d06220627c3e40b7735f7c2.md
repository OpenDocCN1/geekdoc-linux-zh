# Advanced Bash-Scripting Guide

It is possible to initialize and export variables in the same operation, as in export var1=xxx.

However, as Greg Keraunen points out, in certain situations this may have a different
effect than setting a variable, then exporting it.

```
bash$ export var=(a b); echo ${var[0]}
(a b)
```

A variable to be exported may require special treatment. See Example M-2.

declare, typeset
declare and typeset commands specify and/restrict properties of variables.
readonly

Same as declare -r, sets a variable as read-only, or, in effect, as a command. Attempts to change
line with an error message. This is the shell of the C language const type qualifier.

This powerful tool parses command-line arguments to the script. This is the Bash analog of
getopt external command and the getopt library function familiar to C programmers. It prints
and concatenating multiple options [62] and associated arguments to a script (for example
scriptname -abc -usr/local).

The getopt constructs two implicit variables. $OPTIND is the argument pointer (OPTIndex)
and $OPTARG (OPTArgument) the (optional) tag attached to an option. A colon following
the declaration tags that option as having an associated argument.

A getopt constructs usually comes packed in a while loop, which processes the options and
arguments one at a time, then increments the $OPTIND variable to point to the next.

+   1. The arguments from the command-line must be preceded
by a dash (-). It is prefixed – that lets getopt recognize command-line
arguments as options. In fact, gets will not process arguments without the
prefix --, and will terminate option processing at the first argument
encountered lacking them.
2. The gets template differs slightly from the standard while loop, in that it
lacks conditions bracket.
3. The gets construct is a highly functional replacement for the traditional
getopt external command.

```
while getopt ":abc:fg" Option
# Initial declaration.
# a, b, c, d, e, f, and g are the options (flags) expected.
```
