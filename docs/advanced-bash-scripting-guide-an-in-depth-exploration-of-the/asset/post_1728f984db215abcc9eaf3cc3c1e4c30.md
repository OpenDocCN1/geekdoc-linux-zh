#!/bin/bash
# seeding-random.sh: Seeding the RANDOM variable.
# v 1, redate 09 Feb 13

MAXCOUNT=25      # How many numbers to generate.
SEED=

random_numbers () {
  local count=0
  local number

  while [ "$count" -lt "$MAXCOUNT" ]; do
    number=$RANDOM
    echo -n "$number "
    let count++
  done
  echo
}

echo
=1
RANDOM=$SEED      # Setting the random number generator.
echo "Random seed = $SEED"
random_numbers

RANDOM=$SEED      # Same seed for RANDOM . . 
echo "Again, with same seed..."
echo "Random seed = $SEED"
random_numbers    # . . reproduces the exact same series.

/dev/urandom pseudo-device file provides the $RANDOM variable a method of generating much more "random" pseudorandom numbers if=/dev/urandom of=target bs=1 count=XX creates a file of well-scattered pseudorandom numbers. However, assigning these numbers to a variable requires awk, as filtering through od (as above example, Example 16-14, and Example A-36), or piping to md5sum (Example 36-16).

# 10.1. Manipulating Strings

Bash supports a surprising number of string manipulation operations. Unfortunately, these tools lack a unified focus. They are a subset of parameter substitution, and others fall under the functionality of the expr command. This results in inconsistent command syntax and overlap of functionality, not to mention confusion.

String Length

```bash
${#string}
expr length ${string}
```

These are the equivalent of strlen() in C.

```bash
stringZ=ABC123abc
echo ${#stringZ}    # 15
echo `expr length "${stringZ}"` # 15
echo `expr "${stringZ}" : \'.*'`    # 15
```
