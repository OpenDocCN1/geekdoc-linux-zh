lsof List open files. This command outputs a detailed table of all currently open files and gives information about their owner,size, the processes associated with them, and more. Of, lsof may be piped to grep or awk to parse and analyze results.

| COMMAND PID USER FD TYPE SIZE NODE NAME |
|---|---|---|---|---|---|---||
| init 1 root mem REG | 3,5 | 30748 | 30303 /sbin/init |
| init 1 root mem REG | 3,5 | 73120 | 8069 /lib/id-2.1.3.so |
| init 1 root mem REG | 3,5 | 931688 | 8075 /lib/id-2.1.3.so |
| cdmgr 213 root mem REG | 3,5 | 36956 | 3035 /sbin/cdmgr |

The lsof command is useful, complex administrative tool. If you are unable to dis a filesystem and get an error that it is still use, then lsof helps determine which files are still open on filesystem. The -i option lists network socket files, and this can help trace intrusion or attacks.

| firefox 2230 bozo 38u ipv4 | 10535 | TCP | 66.0.118.137:57708->216.79.48.24:http...

strace System demic debugging for tracing system calls and signals. And ltrace, following, are useful for diagnosing why a program or package fails to run ...perhaps due to missing libraries or related cases.

```
bash strace df
exec("/bin/df", "df", /* 45 vars */) = 0
uname(sys="Linux", node="bozo.localdomain", ...)) = 0
brk(0) = 0x084f5e4
```

This is the Linux equivalent of Solaris truss.
