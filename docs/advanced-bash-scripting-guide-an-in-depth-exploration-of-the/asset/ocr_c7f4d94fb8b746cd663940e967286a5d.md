# 37.2.1. Bash, version 3.1

The version 3.1 update of Bash introduces a number of bugfixes and a few minor changes.

+   The += operator is now permitted in places where previously only the assignment operator was recognized.

```
a=1
echo $a # 1

a+=5
# Won't work under versions of Bash earlier than 3.1.
echo $a # 15

a+=Hello
# 15Hello
echo $a
```

Here, += functions as a string concatenation operator. Note that its behavior in this particular case is different than with a let construct.

```
a=1
echo $a # 1

let +=5
# Integer arithmetic, rather than string concatenation.
echo $a # 6

let +=Hello
# Doesn't "add" anything to a.
echo $a # 6
```

Jeffrey Maurer points out that this concatenation operator can be quite useful. In this instance, append a directory to the $PATH.

```
bash$ echo $PATH
/usr/bin:/usr/local/bin:/usr/X11R6/bin:/usr/games

bash$ PATH+=:/opt/bin

bash$ echo $PATH
/usr/bin:/usr/local/bin:/usr/X11R6/bin:/usr/games:/opt/bin
```
