# Network

# nmap

nmap mapper and port scanner. This command scans a server to locate open ports and the services associated with those ports. It can also report information about packet filters and firewalls. This is an important security tool for locking down a network against hacking attempts.

```
!/bin/bash
SERVER=$HOST # localhost.localdomain (127.0.0.1)
PORT_NUMBER=25 # SMTP port.

nmap $SERVER | grep -w "$PORT_NUMBER" # Is particular port open?
grep -w matches whole words only,
so so didn't match port 1025, for example.

exit 0
# 25/tcp open smtp
```

The ifconfig command is most often used at boot to set up the interfaces, or in init.d/network, or to shut down when rebooting.

```
# Code snippets from /etc/rc.d/init.d/network
#
...

# Check that networking is up.
 [$NETWORKING) = "no" ] && exit 0

[ -x /sbin/ifconfig ] || exit 0

#
for i in $interfaces; do
 if ifconfig "-q" 2>/dev/null | grep -q "UP" >dev/null 2>&1; then
 action "Shutting down interface $i: " ..ifdown $i
fi
# The GNU-spec "-q" option to "grep" means "quiet", i.e.,
 producing no output.
# Redirecting output to /dev is therefore not strictly necessary
```
