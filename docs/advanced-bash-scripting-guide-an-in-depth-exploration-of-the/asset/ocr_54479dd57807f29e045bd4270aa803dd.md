Process that the 'dot' program, and you have your first network diagram.

In addition to the conventional graphic edges, the descriptor file includes similar format pair-data that describes services, zone records (sub-graphs), blacklisted addresses, and other things which might be intersecting to include in your graph. This additional information could be displayed as different node shapes, colors, line sizes, etc.

The descriptor file can also be read and edited by a Bash script (of course). You should be able to find most of the functions required within the "is_spammer.bash" script.
