# Advanced Bash-Scripting Guide

It is possible to modify the way Bash interprets special characters in globbing. A **set -f** command disables globbing, and the `nocaseglob` and nullglob options to shop change globbing behavior. See also [Example 11-5]

+   * Filenames with embedded whitespace can cause globbing to choke. David Wheeler shows how to avoid many pitfalls.

```
IFS="$(printf '\n\t')"    # Remove space.
# Correct glob use:
# Always use for-loop, preif glob, check if exists file.
for file in ./*; do      # Use ./* NEVER bare *
  if [ -e "$file" ]; then      # Check whether file exists.
    COMMAND ... "$file"
done
```
