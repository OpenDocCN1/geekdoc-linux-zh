# Filesystem

## mount

Mount a filesystem, usually on an external device, such as a floppy or CDROM. The file /etc/fstab provides a handy listing of available filesystems, partitions, and devices, including options, that may be automatically or manually mounted. The file /etc/mtab shows the currently mounted filesystems and partitions (including the virtual ones, such as `/proc/`).

`mount -a` mounts all filesystems and partitions listed in /etc/fstab, except those with noauto option. At boot, a startup script in /etc/rc.d (rc.sysinit or something similar) invokes to get everything mounted.

```bash
mount -t iso9660 /dev/cdrom /mnt/cdrom
# Mount CDROM. ISO 9660 is a standard CD filesystem.
/mnt/cdrom
# Shortcut, if /mnt/cdrom listed in /etc/fstab
```

The versatile mount command even mounts an ordinary file on a block device, and the file will act as if it were one. Mount accomplishes by associating the file system with a loopback device. An application of this is to mount and examine an ISO9660 filesystem image before burning it onto a CDR. [201]

### Example 17-7. Checking a CD image

```bash
# As root...
mkdir /mnt/cdtest # Prepare a mount point, if not already there.
mount -r t iso9660 -o loop cd-image.iso /mnt/cdtest # Mount the image.
# -o loop" option equivalent to "/dev/loop0"
cd /mnt/cdtest # Now, check the image.
# List the files in the directory tree.
ls -alR # And so forth.
```

## umount

Unmount a mounted filesystem. Before removing a previously mounted floppy or CDROM disk, the device must be unmounted, else filesystem corruption may occur.

```bash
umount /mnt/cdrom
# You may now press the eject button and safely remove the disk.
```

> The automount utility, if properly installed, can mount and unmount floppies or CDROM disks as they are accessed or removed. On "multispindle" laptops with swappable floppy and optical drives, this can cause problems, however.

The newer Linux distros have deprecated mount and umount. The successor, command-line mounting of removable storage devices, is gnome-mount. It can take the -d option to mount a device file by its listing in /dev.

For example, to mount a USB flash drive:

```bash
bash$ gnome-mount -d /dev/sda1
gnome-mount 0.4
```

`sync` forces an immediate write of all updated data from buffers to hard drive (synchronize drive with buffers). While not strictly necessary, a sync ensures the sys admin or user that the data just changed will survive a sudden power failure. In the old days, a sync; sync (twice, just to make absolutely sure) was a useful precautionary measure before a reboot.

At times, you may force an immediate buffer flush, as when securely deleting a file (see Example 16-61) or when the lights begin to flicker.

`losetup` sets up and configures loopback devices.

### Example 17-8. Creating a filesystem in a file

```bash
SIZE=1000000  # 1 meg
head -c $SIZE < /dev/zero file  # Set up file of designated size.
losetup /dev/loop0             # Set it up as loopback device.
mke2fs /dev/loop0               # Create filesystem.
mount -o loop /dev/loop0 /mnt   # Mount it.

# Thanks, S.C.
```

`mkswap` creates a swap partition. The swap area must be enabled with swapon.

`swapon` enables/ disables swap partition or file. These commands usually take effect at bootup and shutdown.

`mke2fs` creates a Linux ext2 filesystem. This command must be invoked as root.

## tune2fs

Tune ext2 filesystem may be used to change filesystem parameters, such as maximum mount count. This must be invoked as root.

> This is an extremely dangerous command. Use it at your own risk, as you may inadvertently destroy your filesystem.
