"dot" command [period]. Equivalent to source (see Example 15-22). This is a bash builtin.

"dot", as a component of filename. When working with filenames, a leading dot is a prefix of a
"hidden" file, a file that is not normally show.

```
bash$ ls .hidden-file
bash$ ls -l
total 10
-rw-r-- 1 bozo bozo 4034 Jul 18 22:04 datal.addressbook
-rw-r-- 1 bozo bozo 4662 May 25 13:58 datal.addressbook.bak
-rw-r-- 1 bozo bozo 877 Dec 17 2000 employment.addressbook

bash$ ls -al
total 14
drwxrxr-x 2 bozo bozo 1024 Aug 29 20:51 ./
drwx------ 52 bozo bozo 3072 Aug 29 20:51 ../
-rw-r-- 1 bozo bozo 4034 Jul 18 22:04 datal.addressbook
-rw-r-- 1 bozo bozo 4662 May 25 13:58 datal.addressbook.bak
-rw-r-- 1 bozo bozo 877 Dec 17 2000 employment.addressbook
-rw-rw-r 1 bozo bozo 0 Aug 29 20:54 .hidden-file
```

When considering directory names, a single dot represents the current working directory, and two dots
de denote the parent directory.

```
bash$ pwd
/home/bozo/projects

bash$ cd
bash$ pwd
/home/bozo/projects

bash$ cd
bash$ pwd
/home/bozo/bozo/
```

The dot often appears as the destination (directory) of a file movement command, in this context
meaning current directory.
