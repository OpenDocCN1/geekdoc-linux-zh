Running a script on a machine that relies on a command that might not be installed is dangerous. Use whatis to avoid potential problems with.

```
CMD=command1               # First choice.
PlanB=command2             # Fallback option.

command_test="$CMD"      # grep 'not nothing appropriate'
# If 'command1' not found on system, 'whatis' will return
#+ 'command: not appropriate.'

# A safer alternative is:
# command_test=$( "$CMD" | grep \)
# But then the sense of the following test would have to be reversed,
# since the $command_test variable holds content only if
# the $command exists on the system.
# (Thanks, bojster).
```

```
if [[ -z "$command_test" ]] # Check whether command present.
then
    CSDM option1 option2      # Run command1 with options.
else
    # Otherwise,
    ##+ run command2.
PlanB
```

An if-grep test may not return an error in case, when test is output to stderr, rather that stdout.

```
if ls -l nonexistent_filename 2>&1 | grep -q 'No such file or directory'
then echo "nonexistent_filename" does not exist.
fi
```

Redirecting stderr to stdout fixes.

```
if ls -l nonexistent_filename 2>&1 | grep -q 'No such file or directory'
nthen echo "nonexistent_filename" does not exist.
fi
```

If you absolutely access a shell variable outside the subshell, here's how to do it.

```
TMPFILE=tmpfile # Create a temp file to store the variable.

( # Inside the subshell ...ninner_variable=Inner
echo $inner_variable
echo $inner_variable >>$TMPFILE # Append to temp file.
)

# Outside the subshell ...necho echo "------"; echo
echo $inner_variable # Null, as expected.
echo "------"; echo

# Now ...
```
