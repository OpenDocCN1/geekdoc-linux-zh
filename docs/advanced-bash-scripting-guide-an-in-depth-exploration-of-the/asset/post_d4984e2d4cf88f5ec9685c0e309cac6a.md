for n in 1 2 3

  echo -n "$n"

This constructs a test for a condition at the top of a loop, and keeps looping as long as that condition is true (returns a 0 exit status). In contrast to a for loop, a while loop finds use in situations where the number of repetitions is not known beforehand.

```
while [ condition ]
do
  command(s)...
done
```

The bracket construct in a while loop is nothing more than our friend, the test brackets used in an if/then test. In fact, a while loop can legally use the more versatile double-brackets construct `(( condition ))`. As is the case with for loops, placing `do` on the same line as the condition test requires a semicolon. Note that test brackets are not mandatory in a while loop. See, for example, `getopts` command.

### Example 11-15. Simple while loop

```bash
#!/bin/bash
var0=0
LIMIT=10
while [ "$var0" -lt "$LIMIT" ]; do
  # Spaces because these are "test-brackets".
  # -n suppresses newline.
  echo -n "$var0" # printed out numbers.
  var0=$((var0 + 1))
done
echo
```

### Example 11-16. Another while loop

```bash
#!/bin/bash
while [ "$var0" != "end" ]; do
    echo "Input variable"
    read var0 # Equivalent to: # If input is not 'end', echoes it here.
done # Does not test for termination until top of loop.
echo
exit 
```

A while loop may have multiple conditions. The final condition determines when the loop terminates. This necessitates a slightly different syntax, however.

### Example 11-17. while loop with multiple conditions

```bash
#!/bin/bash
var0=0
previous=$var0

while [ "$var0" != "end" ]; do
    # Keeps track of what $var0 was previously.
    # Four conditions on "while", but only the final one controls the loop.
    # The "last" exit status is the one that counts.
    echo "Input variable"
    read var0
    echo "variable = $var0"
done

exit 0
```

Try to figure out how all works. It's a bit tricky. As for loop, a while loop may employ C-style syntax by using double-parentheses construct (see Example 8-5).

### Example 11-18. C-style syntax in a while loop

```bash
#!/bin/bash
# Count to 10 in a "while" loop.
LIMIT=10
a=1

while [ "$a" -le $LIMIT ]; do
  echo -n "$a"
  let "a=1"
done # No surprises, so far.
echo
```

# ===================================
# Now, we'll repeat with C-like syntax.
((a = 1)) # Double parentheses permit space when setting a variable, as in C.

while (( a < LIMIT )); do
  # Double parentheses, and no "$a" preceding variables.
  echo -n "$a"
  ((a+=1)) # let "a=1"
  # Yes, indeed. Double parentheses permit incrementing a variable with C-like syntax.
done
```

C and Java programmers can feel right at home in Bash. Inside its test brackets, a while loop can call a function.

```bash
t=0
condition () {
  ((t++))
  if [ $t -lt 5 ]; then
    return 0 # true
  else
    return 1 # false
  fi
}

while condition; do # Function call -- four loop iterations.
  echo "Still going: t = $t"
done

# Still going: t = 1
# Still going: t = 2
# Still going: t = 3
# Still going: t = 4
```

Similar to the if-test construct, a while loop can omit the test brackets.

```
while condition
do
  command(s)...
done
```

By coupling the power of the `read` command with a while loop, we get the handy read construct, useful for reading and parsing files.

```bash
cat $filename | # Supply input from a file.
while read line; # As long as there is another line to read ...
do
  #
done
```

### 11.2. Nested Loops

A nested loop is a loop within a loop, the body of the outer loop containing another loop. The inner loop repeats for each outer loop iteration.

### Example 11-20. Nested Loops

```bash
#!/bin/bash
# nested-loop.sh: Nested "for" loops.

outer=1
# Set outer loop counter.
for a in 1 2 3 4 5
do
    echo "Pass $outer in outer loop."
    echo "----------------------"
    inner=1
    # Reset inner loop counter.
    # ===================================
    # Beginning of inner loop.
    for b in 1 2 3 4 5
    do
        echo "Pass $inner in inner loop."
        let "inner+=1" # Increment inner loop counter.
    done # End of inner loop.
    # ===================================

    let "outer++" # Increment outer loop counter.
    echo
    # Space between output blocks in pass of outer loop.
done
```

### 11.3. Loop Control

The `break` and `continue` loop commands correspond exactly to their counterparts in other languages. The `break` command terminates the loop (breaks out of it), while `continue` causes a jump to the next iteration of the loop, skipping all the remaining commands in particular loop cycle.

### Example 11-21. Effects of break and continue in a loop

```bash
#!/bin/bash
LIMIT=19 # Upper limit

echo
echo "Printing Numbers 1 through 20 (but not 3 and 11)."

a=0

while [ $a -le "$LIMIT" ]
do
    a=$((a+1))

    if [ "$a" -eq 3 ] || [ "$a" -eq 11 ]; # Excludes 3 and 11.
    then
        continue # Skip rest of this loop iteration.
    fi
done
```
