**$(var/%Pattern#Replacement)**
*If prefix of var matches Pattern, then substitute Replacement for Pattern.*
**$(var/%Pattern#Replacement)**
**If suffix of var matches Pattern, then substitute Replacement for Pattern.*

# Example 10.13. Matching patterns at prefix or suffix of string

```
#!/bin/bash
# var-match.sh
# Demo of pattern replacement at prefix / suffix of string.

v0=abc1234zip123abc      # Original variable.
echo "$v0 = $v0" # abc1234zip123abc
echo

# Match at prefix (beginning) of string.
v1=${v0#ABC/ABCDEF}      # abc1234zip123abc
                                 |--|-
echo "$v1 = $v1"         # ABCDEF1234zip123abc

# Match at suffix (end) of string.
v2=${v0%*ABC/ABCDEF}      # abc1234zip123abc
                                 |-
echo "$v2 = $v2"         # abc1234zip123ABCDEF
                                 |-----
```
