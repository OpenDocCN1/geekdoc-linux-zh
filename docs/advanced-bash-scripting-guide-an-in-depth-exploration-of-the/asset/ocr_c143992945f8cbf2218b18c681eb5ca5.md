+   * mapfile builtin makes it possible to load an array with the contents of a text file using a loop or command substitution.

```
#!/bin/bash4
mapfile Arr1 < $0
# Same result as Arr1=$(cat $0)
echo "${Arr1[0]}"   # Copies this entire script to stdout.

echo "--"; echo

# But, not the same as read -a !!!
read -a Arr2 < $0
echo "${Arr2[0]}"   # Reads first line of script into the array.
```

* Parameter substitution gets case-modification.

```
#!/bin/bash4
var=veryMixedUpVariable
echo ${var,}         # veryMixedUpVariable
echo ${var^}         # veryMixedUpVariable
#                        First char --> uppercase.
echo ${var^^}         # VERYMIXEDUPVARIABLE
#                        All chars --> uppercase.
echo ${var,,}         # verymixedupvariable
```
