cpio
This specialized archiving copy command (cpio input and output) is rarely seen anymore, having supplanted by tar/gzip. It still has uses, as moving a directory tree. With an appropriate block size (for copying) specified, it can be appreciably faster than tar.

# Example 16-30. Using cpio to move to a directory tree

```
#!/bin/bash

# Copying a directory using 'cpio':
# Advantages of using 'cpio':
# Speed of copying. It's faster than 'tar' with pipes.
# Well suited for copying special files (named pipes,)
# that 'cp' may choke on.

ARGS=2
E_BADARGS=65
```
