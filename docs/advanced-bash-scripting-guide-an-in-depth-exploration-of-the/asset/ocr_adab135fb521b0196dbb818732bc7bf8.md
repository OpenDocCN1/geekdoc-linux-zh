# 36.5. "Colorizing" Scripts

The ANSI [126] escape sequences set screen attributes, such as bold text, and color of foreground and background. DOS batch files commonly used ANSI escape codes for color output, and can Bash scripts.

Example 36-13. A "colored" address database

```
#!/bin/bash
# ex30a.sh: "Colorized" version of ex30.sh.
# Crude address database

clear
# Clear the screen.
echo -n ""
echo -e "\E[37;44m\033[0mInContact List\033[0m"
# White on blue background
echo; echo;
echo -e "\033[1mInChoose of the following persons:\033[0m"
# Bold
tput sgr0
# Reset attributes.
echo "(Enter only the first letter of name)."
echo
echo -en "\E[47;34m\033[1mE\033[0m"
# Blue
tput sgr0
echo "[\E]vans, Roland"
# Reset colors to "normal."
echo -en "\E[47;35m\033[1mJ]\033[0m"
# Magenta
tput sgr0
echo "ambalaya, Mildred"
echo -en "\E[47;32m\033[1mS\033[0m"
# Green
tput sgr0
echo "mith, Julie"
echo -en "\E[47;31m\033[1mZ\033[0m"
# Red
```
