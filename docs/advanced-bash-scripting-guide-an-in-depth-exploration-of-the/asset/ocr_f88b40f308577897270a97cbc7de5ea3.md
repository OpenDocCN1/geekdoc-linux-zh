# Advanced Bash-Scripting Guide

The date command has a number of output options. For example %N gives the nanosecond
down of the current time. One interesting for this is to generate random integers.

```
date +%N | sed -e 's/00//$' -e 's/^0//'

# Strip off leading and trailing zeroes, if present.
# Length of generated integer depends on
# how many zeroes were stripped off.

# 115281032
# 63408725
# 394504284
```

There are many more options (try date).

```
date +%j
# Echoes of the day (days elapsed since January 1).

date +%M
# Echos hour and minute in 24-hour format, as a single digit.
```

```
The 'TZ' parameter permits overriding the default time zone.
date # Mon Mar 28 21:42:16 MST 2005
TZ-east # Mon Mar 28 23:42:16 EST 2005
# Thanks, Frank Kannemann and Peter Sjoberg, for the tip.
```

```
SixDaysAgo=$(date --date=6 days ago)
OneMonthAgo=$(date --date=1 month ago) # Four weeks back (not a month!)
OneYearAgo=$(date --date=1 year ago)
See also Example 3-4 and Example A-43.
```

Time zone: echoes the time in a specified time zone.

```
bash$ dump EST
EST Tue Sep 18 22:09:22 2001 EST
```

time

Outputs verbose statistics for executing a command.

```
time ls -1 / gives something like this:

real 0m.067s
user 0m.004s
sys 0m.005s
```

See also the variety times command in the previous section.

> As of version 2.0 of Bash, time became a shell reserved word, with slightly altered behavior in a pipeline.
