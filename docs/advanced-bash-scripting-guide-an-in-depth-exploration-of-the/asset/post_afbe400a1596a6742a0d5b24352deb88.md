# grep

A multi-purpose search tool that uses Regular Expressions. It was originally a command/filter for the venered line editor g/re/p -- global - regular expression - print.

```bash
grep pattern[file...]
```

Search the file(s) for occurrences of pattern, where pattern may be literal text or a Regular Expression.

```bash
bash$ grep "[rst]system.*osinfo.txt
The GPL governs the distribution of the Linux operating system.
```

If no file is specified, grep works as a stdout, as in a pipe.

```bash
bash$ ps ax | grep clock
765 ttl S 0:00 xclock
901 pts/1 S 0:00 grep clock
```

The -i option causes a case-insensitive search.
The -w option matches only whole words.

The -l option lists only the files in which matches were found, but not the matching lines.
The -r (recursive) option searches files in the current working directory and all subdirectories it.
The -n option lists the matching lines, together with line numbers.

```bash
bash$ grep -n Linux osinfo.txt
2:This is a file containing information about Linux.
6:The GPL governs the distribution of the Linux operating system.
```

The -v (or --invert-match) option filters out matches.

```bash
grep pattern1 *.txt | grep -v pattern2

# Matches all lines not in *.txt files containing "pattern1"
# but not "pattern2"
# -c -- provides a numerical count of matches, rather than actually listing the matches.
```

```bash
grep -c txt *.sgml # (number of occurrences of "txt" in "*.sgml" files)
```

# Example 16-Printing from the Lines in stored e-mail messages

```bash
#!/bin/bash
# from.sh

# Emulates the useful 'from' utility in Solaris, BSD, etc.
# Echoes the "From" header line in all messages
# in your email-directory.

MAILDDIR=/mail/* # No quoting of variable. Why?
# Maybe check if exists $MAILDDIR if [ -d $MAILDDIR ] ; .
GREP_OPTS="-H -5 --color" # Show file, plus extra context lines
# and display "From" in color.
TARGET="From" # "From" at beginning of line.

for file in $MAILDDIR # No quoting of variable.
do
  grep $GREP_OPTS "$TARGET" "$file"
  # Again, do not quote this variable.
echo
done
exit $?
```

When invoked with one target file, grep specifies which file contains matches.

```bash
bash grep Linux osinfo.txt misc.txt
osinfo.txt:This is a file containing information about Linux.
osinfo.txt:The GPL governs the distribution of the Linux operating system.
misc.txt:The Linux operating system is steadily gaining in popularity.
```

To force grep to show only the filename when searching only one target file, simply give /dev/null as the second file.

```bash
$ grep Linux osinfo.txt /dev/null
osinfo.txt:This is a file containing information about Linux.
osinfo.txt:The GPL governs the distribution of the Linux operating system.
```

If there is a mismatch, grep returns an exit status of 0, which makes it useful in a script, especially in combination with the -q option to suppress output.

```bash
SUCCESS=0 # if grep succeeds
word=Linux
filename=data.file

grep -q "$word" "$filename" # The "-q" option
# causes nothing to stdout.
if [ $? -eq 0 ]; # if grep -q "$word" "$filename" can replace lines-7.
then
echo "word found in $filename"
else
echo "word not found in $filename"
fi
```

# Example 16-17. Emulating grep in a script

```bash
#!/bin/bash
# grep.sh: Rudimentary implementation of grep.

E_BADARGS=5

if [ -z "$1" ]; # Check for argument.
then
echo "Usage: basename $0"
exit $E_BADARGS
fi

echo

for file in * # Traverse all files
do
output=$(sed -n "/^$1/p" $file) # Command substitution.
if [ ! -z "$output" ]; # What happens if "$output" is not quoted?
then
echo -n "$file: "
echo "$output"
fi
# 1) Add newlines to output, if more than one match in any file.
# 2) Add features.
```

How can grep search for two (or more) separate patterns? What if you want grep to display all lines in a file that contain "pattern1" and "pattern2"?

One method is to pipe the result of grep pattern1 to grep2.

For example, given the following file:

```text
# Filename: tstfile

This is a sample file.
This is an ordinary text file.
This does not contain any unusual text.
This is not unusual.
Here is some text.
Now, let's search this file for both "file" and "text" ...
```

```bash
bash$ grep file tstfile
# Filename: tstfile
This is a sample file.
This is an ordinary text file.
This does not contain any unusual text.
This is not unusual.

bash$ grep file tstfile | grep text
This is an ordinary text file.
This does not contain any unusual text.
Now, for an interesting use of grep ...
```
