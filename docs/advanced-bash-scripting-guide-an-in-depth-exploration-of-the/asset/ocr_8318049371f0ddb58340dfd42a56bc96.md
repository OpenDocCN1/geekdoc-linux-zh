exit
unconditionally terminates a script. [63] The exit command may take an integer argument, which is returned to the shell as the exit status of it. It is good practice to end all simplest scripts with an exit 0, indicating a successful run.

+   - If a script terminates with an exit leaving an argument, the exit status of the script is the exit status of the last command executed in script, not counting the exit. This is equivalent to an exit $?.

+   - An exit command may be used to terminate a subshell.

exec
this shell rebuilds the current process with a specified command. Normally, when the shell encounters a command, it forks a child process to actually execute it. Using the exec builtin, the shell does not fork, and the command exec'd replaces the shell. When used in a script, it forces an exit from the script when the exec'd command terminates. [64]
