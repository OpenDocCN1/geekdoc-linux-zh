# Remote Host Access

## sx, rx

The sx and rx command set serves to transfer files to and from a remote host using the xmodem protocol. These are generally part of a package, such as minicom.

## sz, rz

The sz and rz command sets to transfer files to and from a remote host using the zmod protocol. It has advantages over xmodem, such as faster transmission rate and resumption of interrupted file transfers. Like sx and rx, these are generally part of a package.

## ftp

Utility and protocol for downloading files to or from a remote host. An ftp session can be activated in a script (see Example A-19-6).

## uucp, uux, cu

uucp: UNIX to copy. This is a package for transferring files between UNIX servers. Since the advent of the Internet and E-mail, uucp seems to have faded into obscurity, but it still exists and remains perfectly workable in situations where Internet connection is not available or appropriate. The advantage of uucp is that it is fault-tolerant, even if there is service interruption the operation will resume where it left off when connection is restored.

uux: UNIX to execute. Execute a command on a remote system. This command is part of a package.

cu: Call a remote system and connect as a simple terminal. It is sort of dumb version of telnet. This command is part of a package.

## telnet

Utility and protocol for connecting to a remote host. The telnet protocol contains security holes and should probably be avoided within Its shell script is not recommended.

## wget

The wget utility interactively retrieves or downloads files from a Web or site. It works well in a script. The -p option causes wget to fetch all files on the specified page. The r option recursively downloads and retrieves all links on the specified site. The c option lets wget resume interrupted download. This works with ftp servers and many HTTP sites.

## Example 16-62. Getting a stock quote

```bash
#!/bin/bash
# quote-fetch.sh: Download a stock quote.

stock_symbol=$1
file_suffix=.html

if [ -z "$stock_symbol" ]; then # Must specify a stock (symbol) to fetch.
then
  echo "Usage: $0 stock-symbol"
  exit 1
fi

URL='http://finance.yahoo.com/search?q=${stock_symbol}${file_suffix}''

# To look up stuff on http://search.yahoo.com:
URL="http://search.yahoo.com/search?fr=${stock_symbol}&p=${query}"

# Saves a list of relevant URLs.

## rlogin

Remote login, initiates a session on a remote host. This command has security issues, so use ssh.

## rsh

Remote shell, executes command(s) on a remote host. This has security issues, so use ssh instead.

## rcp

Remote copy, copies files between two different networked machines.

## rsync

Remote synchronize, updates (synchronizes) files between two different networked machines.

```bash

```
