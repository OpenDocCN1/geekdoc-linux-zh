## 36. Tests and Comparisons: Alternatives

For tests, the [[ ]] construct may be more appropriate than [ ]. Likewise, arithmetic comparisons benefit from the (( )) construct.

```bash
a=8
# All of the comparisons below are equivalent, $a < 16:
test "$a" -lt 16 && echo "Yes, $a < 16"
/bin/test "$a" -lt 16 && echo "Yes, $a < 16"
[ $a -lt 16 ] && echo "Yes, $a < 16"
[[ $a < 16 ]] && echo "Yes, $a < 16"
(( $a < 16 )) && echo "Yes, $a < 16"
# "and list"
# Qualifying variants within
# [[ ]] && (( )) are not necessary.
```

```bash
city="New York"
# Again, all of the comparisons below are equivalent.
test "$city" -lt Paris && echo "Yes, Paris is greater than $city"
# Greater ASCII order.
/bin/test "$city" -lt Paris && echo "Yes, Paris is greater than $city"
[ "$city" -lt Paris ] && echo "Yes, Paris is greater than $city"
[[ "$city" -lt Paris ]] && echo "Yes, Paris is greater than $city"
# # need not quote $city.
```

## 36-11. A useful script that recursively calls itself

```bash
#!/bin/bash
# pb.sh: phone book

# Written by Rick Boovie, and used with permission.
# Modifications by ABS Guide author.

MINARS=1
DATAFILE=./phonebook
# A data file in current working directory
+ named "phonebook" must exist.

PROGNAME=$0
# No arguments error.

if [ $# -lt $MINARS ]; then
    echo "Usage: $PROGNAME data-to-look-up"
    exit $_NOARGS
fi

if [ $# -eq $MINARS ]; then
    grep $1 "$DATAFILE"
    # 'grep' prints an error message if $DATAFILE is not present.
else
    shift "$PROGNAME" $* | grep $1
    # Script recursively calls itself.
fi
```
