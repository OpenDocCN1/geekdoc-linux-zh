Virtually UNIX and shell operators and commands have many more options and enhancements their DOS and batch file counters. Many DOS batch files rely on auxiliary utilities, such as ask.com, a crippled counter to read.

DOS supports only a very limited and incompatible subset of filename wild-card expansion, recognizing just the * and ? characters.

Converting a DOS batch file into a shell script is generally straightforward, and the result of of times better than the original.

# Example N-1. VIEWDATA.BAT: DOS Batch File

```
REM VIEWDATA
REM INSPIRED BY AN EXAMPLE IN "DOS POWERTOOLS"
BY PAUL SOMERSON

@ECHO OFF

IF %1==="" GOTO VIEWDATA
REM NO COMMAND-LINE ARG...
FIND "$1" C:\BOZO\BOOKLIST.TXT
GOTO EXIT0
REM PRINT LINE WITH STRING MATCH, THEN EXIT.

:VIEWDATA
TYPE C:\BOZO\BOOKLIST.TXT | MORE
REM SHOW ENTIRE FILE, 1 PAGE AT A TIME.

:EXIT0~
```

Example N-2. viewdata.sh: Shell Conversion of VIEWDATA.BAT

```bash
#!/bin/bash
# viewdata.sh
# Conversion of VIEWDATA.BAT to shell script.

DATAFILE=/home/bozo/datafiles/book-collection.data
ARGNO=1

@ECHO OFF               Command unnecessary here.

if [ $# -lt "$ARGNO" ]   # IF !$== GOTO VIEWDATA
then
    less $DATAFILE          # TYPE C:\MYDIR\BOOKLIST.TXT | MORE
else
    grep "$1" $DATAFILE      # FIND "$1" C:\MYDIR\BOOKLIST.TXT
fi

exit 0                   :EXIT0

Gotos, labels, smoke-and-mirrors, and flimflam unnecessary.
# The converted script is short, sweet, and clean,
# which is more than can be said for the original.
```

## 0.2. Writing Scripts

Write a script to carry out each of the following tasks:

- Alter the script so that it accepts any ordinary text as input for its "generation". The script will read the first characters, and set the occurrences as "living". Be sure to translate the characters in the input file to underscore.
- Write a script that backs itself up, that is, copies itself to a file named backup.sh. Hint: Use the cat command and the appropriate parameter.
- Perform a recursive directory listing on the home directory and save the information to a file. Compress the file, to insert a flash drive, then press. Note that the flash drive must be unmounted before it is removed.
- Converting for loops to while and until: store the data in an array and step through the elements. Having already done the "heavy lifting," now convert the loops in the example to until.
- Changing the line space of a text file: Write a script that reads each line of target file, writes the line back to stdout, with an extra blank line. This has the effect of double-spacing the file. When the script runs correctly, modify it to triple-space the target file.
- Finally, write a script to remove all blank lines from the target file, single-spacing it.
- Backwards Listing: Write a script that echoes itself to stdout, but backwards.
