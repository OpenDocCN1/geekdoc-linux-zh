# Advanced Bash-Scripting Guide

```
# t-out.sh [time-out]
# Inspired by a suggestion from "syngin seven" (thanks).

TIMELIMIT=4      # 4 seconds

read -t $TIMELIMIT variable <&1
#
# In this instance, "&1" is needed for Bash 1.x and 2.x,
# but unnecessary for Bash 3+.

echo

if [ -z "$variable" ] # Is null?
then
    echo "Timed out, still unset"
else
    echo "variable = $variable"
fi

exit 0
```

$UID User ID number

Current user's user identification number, as recorded in /etc/passwd

This is the current user's real id, even if she has temporarily assumed another identity through su. $UID is a readonly variable, not to change from the command line or within a script, and the counterpart to the id builtin.

# Example 9-5. Am I root?

```
#!/bin/bash
# am-i-root.sh:    Am I root or not?

ROOT_UID=0      # Root has $UID 0.

if [ "$UID" -eq "$ROOT_UID" ]; # Will the real "root" please stand up?
then
    echo "You are root"
else
    echo "You are just an ordinary user (but mom loves you just the same)"
fi

exit 0
```
