Arithmetic evaluation of octal /hexadecimal constants takes place automatically within a [[ [ ... ]] construct.

Following an if, the test command does not recognize the brackets ( ) or [[ ]] are strictly necessary.

```bash
dir=/home/bozo

if cd "$dir" 2>/dev/null; then # 2>/dev/null hides error message.
    echo "Now in $dir"
else
    echo "Can't change to $dir."
fi
```

The "COMMAND" returns the exit status of COMMAND.

Similarly, a condition within test brackets may stand alone without an if, when used in combination with a list construct.

```bash
var1=20
var2=22
[ "$var1" -ne "$var2" ] // echo $var1 is not equal to $var2
home=/home/bozo
[ -d "$home" ] // echo $home directory does not exist.
```

(( )) expands and evaluates an arithmetic expression. If the expression evaluates as zero, it returns an exit status of 1, or "false". A non-zero expression returns an exit status of 0, or "true". This is marked to contrast using the test and [ ] constructs previously discussed.

## 7.2. File test operators

Returns true if...

- -e file exists
- -a file exists

This is identical in effect to -e. It has been "deprecated," [34] and its use is discouraged.

- -f file is a regular file (not a directory or device file)
- -s file is not zero size
- -b file is a directory
- -c file is a character device

```bash
device0="/dev/sda2" # / (root directory)
if [ -b "$device0" ]

devicel=/dev/tty1 # PCMCIA modem card.
if [ -c "$devicel" ]
then
echo "$devicel is a character device."
fi

# /dev/tty1 is a character device.
```

- -u
set-uid (suid) flag set on file

A binary owned by root with set-user-id flag runs with root privileges, even when an ordinary user invokes it. [35] This is useful for executables (such as pppd and cdrecord) that need to access system hardware. Lacking the suid flag, binaries could not be invoked by a non-root user.

```bash
-rwxrxr-t 1 root 178236 Oct 2 2000 /usr/sbin/pppd
```

A file with the suid flag set shows an s in its permissions.

- -k
sticky bit

Commonly known as the sticky bit, the save-text-mode flag is a special type of file permission. If a file has this flag set, that file will be kept in cache memory for quicker access. [36] If set on a directory, it restricts write permission. Setting the sticky bit adds a t to the permissions on the file or directory listing. This restricts accessing or deleting files in that directory to the owner of those files.

| drwxrwxrwt 7 root 1024 May 19 21:26 tmp/ |

If a user does not own a directory that has the sticky bit, but has write permission in it, she can only delete those files that she owns in. This keeps users from inadvertently overwriting or deleting other's files in a publicly accessible directory, such as /tmp. (The owner of the directory or root can, of course, delete or rename files here.)

# Chapter 7-4. Testing for broken links

```bash
#!/bin/bash
# broken-link.sh
# Written by leelow@yahoo.com
# Testing for broken links
# If a symbolic link is broken, print a message.
# If the symbolic link is not broken, do nothing.
# Use -e to check if the target exists.
# Use -h to check if the link itself exists.

# Example:
ln -s /nonexistent/path link1
if [ -h "$link1" ]; then
  if [ ! -e "$link1" ]; then
    echo "Link $link1 is broken"
  fi
fi

ln -s /etc/passwd link2
if [ -h "$link2" ]; then
  if [ ! -e "$link2" ]; then
    echo "Link $link2 is broken"
  else
    echo "Link $link2 is valid"
  fi
fi
```

```bash
# Setup the function to check the directory
linkchk() {
  for element in "$@"; do
    [ -d "$element" ] -a -e "$element" && echo "$element"
    [ -d "$element" ] linkchk $element
  done
}
```

```bash
# Send each arg that was passed to the script to linkchk function
# if it is a valid directory. If not, then print the error message
# + usage info.

if [ $# -eq 0 ]; then
  echo "Usage: $0 dir1 dir2..."
  exit 1
fi

directorys=$@
for directory in $directorys; do
  if [ -d "$directory" ]; then
    linkchk "$directory"
  else
    echo "$directory is not a directory"
  fi
done

exit $?
```

is greater than or equal to

- -lt
is less than
if [ "$a" -lt "$b" ]
- -le
is less than or equal to
if [ "$a" -le "$b" ]
<
