# # Chapter 33. Options

Options are settings that change shell and/or script behavior.

The **set disable** enables options within a script. At the point in the script where you want the options to take effect, use **set -o option-name** or, in short form, **set -option-abbrev**. These two forms are equivalent.

```
```bash
#!/bin/bash
set -o verbose
# Echoes all commands before executing.
```
```

```
```bash
#!/bin/bash
set -v
# Exact same effect as above.
```
```

**To disable** an option within a script, use **set +option-name** or **set +option-abbrev**.

```
```bash
#!/bin/bash
set -o verbose
# Command echoing on.
command
...
set +o verbose
# Command echoing off.
command
# Not echoed.

set -v
# Command echoing on.
command
...
set +v
# Command echoing off.
command
exit 0
```
```

An alternate method of enabling options in a script is to specify them immediately following the #! script header.

```
```bash
#!/bin/bash -x
#
# Body of script follows.
```
```
