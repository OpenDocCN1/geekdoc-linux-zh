## Example 27-11. The Bubble Sort

```bash
#!/bin/bash
# bubble.sh: Bubble sort, of sorts.
# Recall the algorithm for a bubble sort. In this sorted version...
# With each successive pass through the array to be sorted,
# compare two adjacent elements, swap them if out order.
# At the end of the first pass, the "heaviest" element has sunk to bottom.
```

At the end of the second pass, the next "heaviest" one sank next to bottom. And so forth. This means that each successive pass needs to traverse less of the array. You will therefore notice a speeding up in the printing of the later passes.

```bash
exchange() {
    # Swaps two members of the array.
    local temp=${Countries[1]} # Temporary storage
    # for element getting swapped out.
    Countries[$1]=${Countries[2]}
    Countries[$2]=$temp
}

declare -a Countries # optional here since it's initialized below.
```

```bash
clear

```

```bash
number_of_elements=${#Countries[@]}
let "comparisons" = $number_of_elements - 1

count=1 # Pass number
while [ "$comparisons" -gt 0 ]; do
    # Beginning of outer loop
    index=0 # Reset index to start of array after each pass.
    while [ "$index" -lt "$comparisons" ]; do
        # Beginning of inner loop
        if [ ${Countries[$index]} \> ${Countries[$index+1]} ]; then
            # Out of order...
            # Recalling that \ is ASCII comparison operator
            # within square brackets.

            if [ [${Countries[$index]} > ${Countries[$index+1]} ]; then
                # Also works.
                exchange index 'expr $index+1' # Swap.
            fi
            let "index += 1" # Or, index+=1 on Bash, ver. 3.1 or newer.
        fi
    done
# End of inner loop
```
