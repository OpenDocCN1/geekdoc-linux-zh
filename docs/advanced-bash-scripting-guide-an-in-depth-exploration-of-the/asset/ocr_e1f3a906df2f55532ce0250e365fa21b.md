# 20.2 Redirecting Code Blocks

Blocks of code, such as while, until, and for loops, if/then test blocks can also incorporate redirection of stdin. Even a function may use this form of redirection (see Example 24-11). The < operator at the end of the code block accomplishes this.

#!/bin/bash
# redir2.sh

if [ -z "$1" ]
then
    Filename=names.data      # Default, if no filename specified.
else
    Filename=$1
fi
