tac, is the inverse of cat, listing a file backwards from its end.

rev reverses each line of a file, and outputs to stdout. This does not have the same effect as tac, as it preserves the order of the lines, but flips each one around (mirror image).

```bash
bash$ tac file1.txt
This is line 1.
This is line 2.

bash$ tac file1.txt
This is line 2.
This is line 1.

bash$ rev file1.txt
1 enil si siHT
2 enil si siHT
```

This is the file command. cp file1 file2 copies file to file2, overwriting file2 if it already exists see Example 16-6.

-   Particularly useful are the -a archive flag (for copying any directory tree),
- -update flag which prevents overwriting identically-named newer files), and
- -r and -R recursive flags.

```bash
cp -u source_dir/* dest_dir
# "Synchronization" dest_dir to source_dir
# by copying over newer and not previously existing files.
```

This is the move command. It is equivalent to a combination of cp and rm. It may be used to move multiple files to a directory, or even to rename a directory. For some examples of mv in a script, see Example 10-11 and Example A-2.

> When used in a non-interactive script, mv takes the -f (force) option to bypass user input.

When a directory is moved to a preexisting directory, it becomes a subid of the destination directory.

```bash
mv source_directory target_directory
```

Delete (remove) a file or files. The -f option forces removal of even readonly files, and is useful for bypassing input in a script.

> The rm command will, by itself, fail to rename filenames beginning with a dash. Why? Because rm sees a dash-prefixed filename as an option.

```bash
bash$ rm -badname
rm: invalid option b
Try rm --help for more information.
```

One clever workaround is to precede the filename with "--" (the-end-options flag).

```bash
bash$ rm --badname
```

Another method is to precede the filename to be removed with a dot-slash.

```bash
bash$ rm ./-badname
```

When used with the recursive -r, this command removes files all way down the directory tree from the current directory. A careless rm -f * can wipe out a big chunk of a directory structure.

Remove the directory must be empty of all files -- "invisible" dotfiles -- for this command to succeed.

Make, creates a new directory. For example, mkdir -p project/programs/December creates the named directory. The -p option automatically creates any necessary parent directories.

```bash
chmod +x filename
# Makes "filename" executable for all users.

chmod +s bit on "filename" permissions.
# An ordinary user may execute "filename" with same privileges as the file's owner.
# (This does not apply to scripts.)
```

```bash
chmod 644 filename
# Makes "filename" readable/writable to owner, readable to others
# (oct mode).

chmod 444 filename
# Makes "filename" read-only for all.
# Modifying the file (for example, with a text editor)
# not allowed for a user who does not own the file (except for root)
# and even the file owner must force a file-save
# if she modifies the file.
```
