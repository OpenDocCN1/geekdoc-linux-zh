# string comparison

=

is equal to

```
if [ "$a" = "$b" ]
```

Note the whitespace framing the =.

```
if [ "$a"="$b" ] is not equivalent to the above.
```

is equal to

```
if [ "$a" == "$b" ]
```

This is a synonym for =.

> The comparison operator behaves differently within a double-brackets test than within brackets.
The True if $a starts with an "z" (pattern matching).
The True if $a is equal to z* (literal matching).

| [[ $a - z* ]] | True if $a starts with an "z" (pattern matching) |
| [[ $a = z* ]] | True if $a is equal to z* (literal matching) |
| [ $a - z* ]] | File globbing and word splitting take place. |
| [ "$a" = "\$z*" ] | True if $a is equal to z* (literal matching) |
