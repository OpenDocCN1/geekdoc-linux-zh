# 36.7.2. Widgets

It would be nice to be able to invoke X-Windows widgets from a shell script. There happen to exist several packages that purport to do so, namely Xscript, Xmenu, and widtools. The first two of these no longer seem to be maintained. It is still possible to obtain widtools here.

widtools (widget package) uses the Xforms library to install. Additionally, the Makefile needs some editing before the package will build on a typical Linux system. Finally, three of the six widgets do not work (and, in fact, segfault).

The dialog family of tools offers a method of calling "dialog" from a shell script. The original dialog utility works in a text console, but its successors, dialog, Xdialog, and kdialog use X-Windows-based widget sets.

# Article 36-22. Widgets invoked from a shell script

```
#!/bin/bash
# dialog.sh: Using 'dialog' widgets.

# Must have 'dialog' installed on your system to run this script.
# Or, you can replace any instance of 'dialog' below with 'kdialog' ...
# Version 1.1 (corrected 04/05/05)
```

```
# This script was inspired by the following article.
```
