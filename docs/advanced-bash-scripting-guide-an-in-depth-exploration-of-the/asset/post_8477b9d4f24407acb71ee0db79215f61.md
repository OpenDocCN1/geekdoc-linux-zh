The continue command, similar to break, optionally takes a parameter. A plain continue cuts short the current iteration within its loop and begins the next. A continue N terminates all remaining iterations at its loop level and continues with the next iteration, N levels above.

# 11.4. Testing and Branching

The case and select constructs are technically not loops, since they do not iterate the execution of a code block. Loops, however, they direct program flow according to conditions at the top or bottom of the block.

Controlling program flow in a code block

case (in) esac

The case construct is the shell scripting analog to switch in C/C++. It permits branching to one of a number of code blocks, depending on condition tests. It serves as a kind of shorthand for multiple if/else statements and is an appropriate tool for creating menus.

```bash
case "$variable" in

  "$condition1")
    command...
    ;

  "$condition2")
    command...
    ;

esac
```

- ◇ Quoting the variables is not mandatory, since word splitting does not take place.
- ◇ Each test line ends with a right paren ).
- ◇ Each condition block ends with a double semicolon;
- ◇ If a condition tests true, then the associated commands execute and the case block terminates.
- ◇ The entire case block ends with an esac (case spelled backwards).

# Example 11-25. Using case

```
#!/bin/bash
# Testing ranges.

echo "Hit a key:"
read Keypress

case "$Keypress" in
# As, as always starts again the beginning, one can encode priorities in
+# the file names. continue '2'
+# but one would have to actually check whether or not some job
+# was done (so that we immediately look for the next job) or not
+# (in case we terminate or sleep for a long time before checking
+# for new job).

  [a-z]) echo "Lowercase letter"
  [A-Z]) echo "Uppercase letter"
  [0-9]) echo "Digit"
  *) echo "Punctuation, whitespace, or other"
esac
```
