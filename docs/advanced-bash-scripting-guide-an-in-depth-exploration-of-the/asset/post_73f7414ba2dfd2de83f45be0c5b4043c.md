# File Information

file
A utility for identifying file types. The command file-name will return a file specification for file-name, such as ascii text or data. It references the magic numbers found in /usr/share/magic, /etc/magic, or /usr/lib/magic, depending on the Linux/Unix distribution.

The -f option allows to run in batch mode, to read from a designated file a list of filenames to analyze. The -z option, when used on a compressed file, forces an attempt to analyze the uncompressed file.

```
bash$ file test.tar.gz
test.tar.gz: compressed data, deflated,
last modified: Sun Sep 16 13:34:51 2001, os: Unix
bash file -z test.tar.gz
test.tar.gz: GNU archive (compressed data, deflated,
last modified: Sun Sep 16 13:34:51 2001, os: Unix)
```

Example 16-13. Exploring whatis

```bash
#!/bin/bash
# What are all those mysterious binaries in /bin?
DIRECTORY="/usr/bin"
# Try also "/bin", "/usr/local/bin", etc.
for file in $DIRECTORY/*
do
    whatis $file # Echo info about the binary.
done
exit 0
# Note: For this work, you must create a "whatis" database
# You might wish to redirect output of this script, like a page at stdout:
# ./whatis.sh | less
```

strings

Use the `strings` command to find printable strings in a binary or data file. It will list sequences of printable characters found in the target file. This might be handy for a quick examination of a core dump or for looking at an unknown graphic image file (strings image-file | more might show something like JFIF, which would identify the file as a jpeg image). In a script, you would probably parse the output of strings with grep or sed. See Example 11-8 and Example 11-10.

Example 16-34. An "improved" strings command

```bash
#!/bin/bash
# strings: "word-strings" (enhanced "strings" command)
# This script filters the output of "strings" by checking it
# against a standard word list file.
# effectively eliminates gibberish and noise,
# and outputs only recognized words.

################################################################
# Standard Check for Script Argument(s)
################################################################
ARGS=3
E_BADARGS=85
E_NOFILE=86
if [ $# -ne $ARGS ];
then
	echo "Usage: basename $0 filename"
	exit $E_BADARGS
fi

if [ ! -f "$1" ]; # Check if file exists.
then
	echo "File "$1" does not exist."
	exit $E_NOFILE
fi

################################################################
MINSTRING=3 # Minimum string length.
WORDFILE=/usr/share/dict/linux.words
# Dictionary file.
# May specify a different word list file
# For example, the "yawl" word-list package,
# http://bash.data.in/yawl-0.3.2.tar.gz

wlist-strings "$1" | tr -A a-z | tr '[:space:]' Z | \
	tr-cs '[:alpha:]' Z | tr -s '\173-\377' Z | tr Z \

# Translate output of 'strings' command with multiple passes of 'tr'.
#+ tr-A a-z converts to lowercase.
#+ tr '[:space:]' converts whitespace characters to Z's.
#+ tr-cs '[:alpha:]' Z converts non-alphabetic characters to Z's,
#+ and squeezes multiple Z's.
#+ tr '\173-\377' Z converts all characters after 'z' to Z
#+ and squeezes multiple consecutive Z
#+ which gets rid of all the weird characters
```
