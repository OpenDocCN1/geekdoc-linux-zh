# Advanced Bash-Scripting Guide

```
xyz= # Initialized, but set to null value.
echo Testing \"-n $xyz\"
if [ -n "$xyz" ]
then
    echo Null variable is true.
else
    echo Null variable is false.
fi # Null variable is false.
```

# When is "false" true?

```
echo Testing \"false\" # It seems that "false" is just a string
if [ "false" ]
then
    echo \"false\" is true. #+ and it tests true.
else
    echo \"false\" is false.
fi # "false" is true.
```

```
echo Testing \"$false\" # Again, unialized variable.
if [ "$false" ]
then
    echo \"$false\" is true.
else
    echo \"$false\" is false.
fi # "$false" is false. # Now, we get the expected result.
```

```

    # Or else
    # Adds default code block executing if original condition tests false.
    command 3
```

When if and then are on same line in a condition test, a semicolon must terminate the if statement. Both if and then are keywords. Keywords (or commands) begin statements, and before a new statement on the same line begins, the one must terminate.
