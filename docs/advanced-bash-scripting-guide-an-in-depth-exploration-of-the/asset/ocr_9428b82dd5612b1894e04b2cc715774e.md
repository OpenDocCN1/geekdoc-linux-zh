Indirect referencing in Bash is a multi-step process. First, take the name of a variable: varname. Then, reference it: $$varname. Then, reference it: $$varname. escape the first: $$varname. Finally, force a reevaluation of the expression and assign: eval newvar=$$varname.

What practical use is referencing of variables? It has a little of functionality pointers in C, for instance, in table lookup. And, it also has some very interesting applications. . . .

Nils Radtke shows how to use "dynamic" variable names and evaluate their contents. This can be useful when sourcing configuration files.

```
#!/bin/bash
----------------------------------------------------------------------
# This could be "sourced" from a separate file.
isdnMyProviderRemoteNet==172.16.0.100
isdnYourProviderRemoteNet=10.0.0.10
isdnOnlineService="$$MyProvider"
#
```

```
remoteNet=$(eval "echo $$isdnOnlineServiceRemoteNet")
remoteNet=$(eval "echo $$isdnMyProviderRemoteNet")
remoteNet=$(eval "echo $$isdnMyProviderRemoteNet")
```
