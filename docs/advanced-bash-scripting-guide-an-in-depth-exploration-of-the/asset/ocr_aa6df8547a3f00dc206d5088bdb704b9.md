The first character of the l (10?) character permissions field:
's' Stock
dd' Directory
'b' Block device
'c' Character device
'l' Symbolic link

NOTE: links not marked - test for identical nodes
on identical filesystems.
All information about hard files are shared,
for the names and the name's location in the directory.
NOTE: A "Hard link" is known as a "File Alias" on some systems.
'-' An indistinguishable file

Followed by three groups of letters for: User, Group, Others
Character 1: '-' not readable; 'r' Readable
Character 2: not writable; 'w' Writable
Character 3, User and Group: Combined execute and special
'-' Executable, Not Special
'x' Executable, Special
's' Executable, Special
' Executable, Special

'-' Executable, Not Tacky
'x' Executable, Not Tacky
t' Executable, Tacky
'T' Not Executable, Tacky
