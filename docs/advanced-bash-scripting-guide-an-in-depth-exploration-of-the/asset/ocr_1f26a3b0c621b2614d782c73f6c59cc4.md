trap '' SIGNAL (two adjacent apostrophes) disables SIGNAL for the remainder of the script. trap SIGNAL restores the functioning of SIGNAL once more. This is useful to protect a critical portion of a script from an unexpected interrupt.

```
trap '' 2 # Signal 2 is Control-C, now disabled.
command
command
command
trap 2 # Reables Control-C
```
