# Chapter 23. Process Substitution

Piping the stdout a command into the stdin of another is a powerful technique. But, what if you need to pipe the stdout of multiple commands? This is where process substitution comes in.

Process substitution feeds the output of a process (or processes) into the stdin of another process.

# Template

Command list enclosed within parentheses

+   >command_list

<command_list>

Process substitution uses /dev/fd/<n> files to send the results of the process(es) within parentheses to another process. [108]

> There is no space between the "<" or ">" and the parentheses. Space would give an error message.

```
bash$ echo >(true)
/dev/fd/63

bash$ echo <(true)
/dev/fd/63

bash$ echo >(true) <(true)
/dev/fd/63 /dev/fd/62

bash$ wc <(cat /usr/share/dict/linux.words) 
483523 483523 4992010 /dev/fd/63

bash$ grep script /usr/share/dict/linux.words | wc
262 262 3601

bash$ wc <(grep script /usr/share/dict/linux.words)
262 262 3601 /dev/fd/63
```

> Bash creates a pipe with file descriptors. --fin and fOut. The stdin of true connects to fout (dup2(fout,0)), then passes a /dev/fd/<n> file as argument to echo. On systems lacking /dev/fd/<n> may use temporary files. (Thanks, S.C.)

Process substitution can compare the output of two different commands, or even the output of different options to save the command.

```
bash comm <(ls -l) <(ls -al)
total 12
-rw-rw-r-- 1 bozo 78 Mar 10 12:58 File0
-rw-rw-r-- 1 bozo 42 Mar 10 12:58 File2
-rw-rw-r-- 1 bozo 103 Mar 10 12:58 t2.sh
      total 20
      drwxrxr-x 2 bozo 4096 Mar 10 18:10
```
