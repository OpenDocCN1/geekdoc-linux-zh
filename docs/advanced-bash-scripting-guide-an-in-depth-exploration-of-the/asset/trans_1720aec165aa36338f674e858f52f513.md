事实上，UNIX 和 shell 操作符及命令比其 DOS 和批处理文件多多的选项和增强功能。许多 DOS 批处理文件依赖辅助工具，例如 ask.com，一个难以阅读的计数器。

DOS 只支持非常有限且不兼容的文件通配符扩展子集，仅识别 `*` 和 `?` 字符。

将 DOS 批处理文件转换为 shell 脚本通常是简单的，结果比原始文件好很多倍。

# 示例 N-1. VIEWDATA.BAT：DOS 批处理文件

```
REM VIEWDATA
REM 受 "DOS POWERTOOLS" 中示例的启发
作者：PAUL SOMERSON

@ECHO OFF

IF %1==="" GOTO VIEWDATA
REM 没有命令行参数...
FIND "$1" C:\BOZO\BOOKLIST.TXT
GOTO EXIT0
REM 打印匹配字符串的行，然后退出。

:VIEWDATA
TYPE C:\BOZO\BOOKLIST.TXT | MORE
REM 显示整个文件，一次显示一页。

:EXIT0~
```

脚本转换某种程度上是一种改进。[152]

# 高级 Bash 脚本指南

示例 N-2. viewdata.sh：VIEWDATA.BAT 的 Shell 转换

```bash
#!/bin/bash
# viewdata.sh
# 将 VIEWDATA.BAT 转换为 shell 脚本。

DATAFILE=/home/bozo/datafiles/book-collection.data
ARGNO=1

@ECHO OFF               # 这里不需要该命令。

if [ $# -lt "$ARGNO" ]   # IF !$== GOTO VIEWDATA
then
    less $DATAFILE          # TYPE C:\MYDIR\BOOKLIST.TXT | MORE
else
    grep "$1" $DATAFILE      # FIND "$1" C:\MYDIR\BOOKLIST.TXT
fi

exit 0                   # :EXIT0

# Gotos、标签、烟雾弹和花招是不必要的。
# 转换后的脚本短小、甜且干净，
# 这对于原始文件来说是难以的。
```

# 附录 O. 练习

一个脚本生成 5 个 1 到 50 之间的随机数，且不重复：

```bash
numbers=()
for i in {1..5}; do
    while true; do
        num=$((RANDOM % 50 + 1))
        if [[ ! " ${numbers[@]} " =~ " $num " ]]; then
            numbers+=($num)
            break
        fi
    done
done
echo "${numbers[@]}"
```
