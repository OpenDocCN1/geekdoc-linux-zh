# Advanced Bash-Scripting Guide

```
bash$ echo "$IFS"

(With $IFS set to default, a blank line displays.)

bash$ echo "$IFS" | cat -vte
^IS$
(Show whitespace: here a single space, ^I [horizontal tab],
and newline, and display "$" at end-of-line.)
```

Set $IFS to eliminate whitespace in pathnames.

IFS=$(printf '\n\t\n') # Per David Wheeler.

$IFS does not handle whitespace the same as other characters.

# Example 9-1. $IFS and whitespace

```
#!/bin/bash
# ifs.sh

var1="a+b+c"
var2="d-e-f"
var3="g,h,i"

IFS+=
# The plus sign will be interpreted as a separator.
echo $var1      # a b c
echo $var2      # d-e-f
echo $var3      # g,h,i

echo

IFS="-"
# The minus sign reverts to default interpretation.
# The minus sign will be interpreted as a separator.
echo $var1      # a+b+c
echo $var2      # d e-f
echo $var3      # g,h,i

echo

IFS=",
# The comma will be interpreted as a separator.
# The minus sign reverts to default interpretation.
echo $var1      # a+b+c
echo $var2      # d-e-f
echo $var3      # g h i

echo
```
