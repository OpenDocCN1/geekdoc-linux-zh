# Example 17-4. Keypress detection

```
#!/bin/bash
# keypress.sh: Detect a user keypress ("hot keys")necho
old_stty=$(stty -g)  # Save old settings (why)?
stty -icanon
Keypress=$(head -c1)  # or $ (dd bs=1 count=1 2 > /dev/null)
                      # on non-GNU systems
echo
echo "Key pressed \"$Keypress\"
echo
stty "$old_stty"  # Restore old settings.

# Thanks, Stephane Chazelas.
exit 0
```

# terminals and modes

Normally, a terminal works in the canonical mode. When a user hits a key, the resulting character does not immediately to the program actually running in this terminal. A buffer local to the terminal stores keystrokes. When the user hits the ENTER key, this sends all the stored keystrokes to the program running. There is even a basic line editor inside the terminal.

```
stty -a speed 9600 rows 36 columns 96 line = 0; intr = \C; quit = \; erase = \H; kill = \U; eof = \R; ecol = \<; endl2 = \<; start = \Q; stop = \Z; susp = \S; rprnt = \R; werase = \W; flush = \O;
isig icanon iext echo echo echo -echolnof -xcase -topost echoprt
```

Using canonical mode, it is possible to redefine the special keys for the terminal line editor.

```
bash$ cat filexxxx
cat<Ctrl-L><Ctrl-H>foo bar<Ctrl-U>hello world<ENTER>
<Ctrl-D>
bash$ cat filexxxx
hello
bash$ wc -c < filexxxx
12
```
