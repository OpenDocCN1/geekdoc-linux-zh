# 10.2. Parameter Substitution

Manipulating and expanding variables

${parameter}
Same as $parameter, i.e., value of the variable parameter. In certain contexts, the less ambiguous ${parameter} form works.

May be used for concatenating variables with strings.

```
your_id=$(USER)-on-${HOSTNAME}
echo "$your_id"
echo "Old \PATH = $PATH"
PATH=$(PATH):/opt/bin # Add /opt/bin to PATH for duration of script.
echo "New \PATH = $PATH"
```

${parameter-default}, ${parameter:-default}
If not set, use default.

```
var=1
var=2
# var3 is unset.
echo ${var1-var2}    # 1
echo ${var3-var2} ^      # 2
                                     Note the prefix.
```

echo $(username='whoami')
# Echoes the result of `whoami`, if variable $username is still unset.

> ${parameter-default} and ${parameter:-default} are almost equivalent. The extract makes a difference only when parameter has been declared, or is null.

```
#!/bin/bash
# param-sub.sh
n# Whether a variable has been declared
# affects triggering of the default option
# even if the variable is null.

username=0
echo "$username0 has been declared, but is set to null."
```
