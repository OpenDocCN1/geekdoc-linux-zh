# netstat

Show current network statistics and information, such as routing tables and active connections. This utility accesses information in /proc/net (Chapter 29). See Example 29-4.

netstat -r is used to route.

bash$ netstat
Active Connections (w/o servers)
Recv-Q Send-Q Local Address Foreign Address State
Active UNIX sockets (w/o servers)
Proto RecvQnt Flags Type State I-Node Path
unix 11 [ ] DGRAM 906 /dev/log
unix 3 [ ] STREAM CONNECTED 4514 /tmp.II-unix/0
unix 3 [ ] STREAM CONNECTED 4513

> A netstat -lptu sockets that are listening to, and the associated processes. This can be useful for determining whether a computer has been hacked or compromised.

# ifconfig

This is the command for setting up a wireless network. It is the wireless equivalent of ifconfig, above.

# ip

General purpose utility for setting up, changing, and analyzing IP (Internet Protocol) networks and attached devices. This command is part of the route2 package.

```
bash$ ip link show
1: lo: LOOPBACK, mtu 1636 qdisc noqueue
   link/loopback 00:00:00:00:00:00 br 00:00:00:00:00:00
2: eth0:BROADCAST,MULTICAST mtu 1500 qdisc pfifo_fast qlen 1000
   link/eth0:00:59:ceaf:da br ff:ff:ff:ff:ff
3: s0:NOARP mtu 1480 qdisc noop
   link/s0: 0.0.0.0 br 0.0.0
```

```
bash$ ip route list
169.254.0.0/16 dev 1 scope link
```
