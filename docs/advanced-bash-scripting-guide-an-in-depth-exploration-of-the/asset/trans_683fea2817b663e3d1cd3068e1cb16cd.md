示例 14-46. 生成质数

```bash
#!/bin/bash
# primes2.sh

# 以快速且简单的方法生成质数，
# 而无需求助于复杂的算法。

CEILING=10000 # 1 到 10000
PRIME=0
E_NOTPRIME=

is_prime () {
 local factors
factors=($(factor $)) # 将 `factor` 的输出加载到数组。
 if [ -z "${factors[2]}" ]; then
  # "factors" 数组的第三个元素：
  # ${factors[2]} 是参数的第二个因数。
  # 如果为空，则说明没有第二个因数，
  # 那么该参数就是质数。
  return $PRIME # 0
else
  return $E_NOTPRIME # null
fi
}

echo
for n in $(seq $CEILING);
do
  if is_prime $n
then
    printf %5d $n
  fi    ^ # 每个数字占用五个位置。
done  # 如果需要更高的 $CEILING，根据需要向上调整。

echo
exit
```

bc 无法处理浮点数计算，并且缺乏某些重要数学函数的运算符。幸运的是，bc 出现并解了之急。

bc 不仅仅是一个多用途的算术精度计算工具，还提供了许多编程语言的特性。它的语法模糊地类似于 C 语言。

由于它是一个非常良好的 UNIX 实用工具，因此可以在管道中使用，bc 在脚本中非常有用。

# 示例 16-47. 房屋贷款每月还款

```bash
#!/bin/bash
# monthlypymnt.sh: 计算房屋贷款的每月还款。

# 这是对
# + "mcalc" (房贷计算器) 包中代码的修改
# + 由 Jeff Schmidt 修改
# + 以及
# + Mendel Cooper（本人，ABS 指南作者）。
# http://www.ibiblio.org/pub/Linux/apps/financial/mcalc-1.6.tar.gz

echo
echo "给定房贷本金、利率和期限，
echo "计算每月还款。"

bottom=1.0

echo
echo -n "输入本金（不带逗号） "
read principal
echo -n "输入利率（百分比） " # 如果是 12%，输入 "12"，而不是 ".12"
read interest_r
echo -n "输入期限（月） "
read term

interest_=$(echo "scale=9; $interest_r/100.0" | bc) # 转换为小数。
-----------------
除以 100。
# "scale" 决定小数点位数。

interest_rate=$(echo "scale=9; $interest_r/12 + 1.0" | bc)
top=$(echo "scale=9; $principal$interest_rate$term" | bc)
#---------------------------------------
# 计算利息的标准公式。

echo; echo "请等待。这可能需要一些时间。"

let months=$term - 1
#---------------------------------------
for ((x=$months; x > 0; x--)); do
  bot=$(echo "scale=9; $interest_rate$x" | bc)
  bottom=$(echo "scale=9; $bot" | bc)
  bottom=$((bottom + bot))
done
#---------------------------------------
# Bob 指出了上述循环的一种更高效的实现，
# 将减少 2/3 的计算时间。
for ((x=1; x <= months; x++)); do
  bottom=$(echo "scale=9; $interest_rate + 1" | bc)
done

然后我们可以使用一个更高效的替代方案，
bottom={
  echo "scale=9; $interest_rate"
  for ((x=1; x <= months; x++)); do
    echo 'bottom = $bottom * interest_rate + 1'
  done
  echo 'bottom'
} | bc
# 因为循环实际上是等比数列求和。
# 公式为 a(1-q^n)/(1-q)，
# 其中 a 是第一个元素，n 是元素个数。
payment=$(echo "scale=2; $top" | bc)
# 使用两位小数处理美元和分。
echo "每月还款 = \$payment" # 在金额前回一个美元符号。
exit 0

# 示例 16-48. 进制转换

```bash
#!/bin/bash
######################################################
# Shell: base.sh - 将数字打印到不同的进制 (Bourne Shell)
# Author : Heiner Steven (heiner.steven@od.de)
# Date : 07-03-95
# Category : Desktop
# ID: base.sh in 2000/02/06 19:55
# 上行是 RCS 信息。
######################################################
# 描述
# 修改: 修复了当 0xb 输入时发生的错误
# 经脚本作者许可在 ABS 指南中使用。
# ABS 作者添加的注释。

NOARGS=8
PN=$(basename "$0") # 程序名
VER=$1 | cut -d ' ' -f2 # 版本号：

用法: [数字]
如果未给出数字，则将从标准输入读取数字。
数字可以是：
  二进制 (base 2)        以 0 开头（例如 0b1100）
  八进制 (base 8)         以 0 开头（例如 014）
  十六进制 (base 16)     以 0 开头（例如 0xc）
  十进制 (base 10)       其他
)

Msg () {
  for i in "$@";
  do echo "$PN: $i" >&2
  done
}

Fatal () {
  Msg "$0"; exit 6;
}

PrintBases () {
  # 确定数字的进制
  for i in "$@";
do # 处理命令行参数
    # 移除前缀，将十六进制字母转换为大写（bc 需要）。
    number="$i" | sed 's/^0[xX]//g' | tr '[a-f]' '[A-F]'

    # 将数字转换为十进制
    dec=$(echo "obase=$base; $number" | bc) # bc 是计算器工具。
    case $dec in
      [0-9]*) # 数字正确
        continue; 
      *) # 错误：忽略
    esac

    # 在一行内打印所有转换。
    # = <<'document' 将命令列表传递给 bc
    echo <<<
      obase=16; "hex"; $dec
      obase=10; "dec"; $dec
      obase=8; "oct"; $dec
      obase=2; "bin"; $dec
    BC
  | sed -e 's/ : /g'
  done
}

while [ $# -gt 0 ];
  # 这里真的需要 "while" 吗，
  # 因为所有的分支都会退出或终止脚本。
  # (上述注释来自 Paulo Aragao.)
  do
    case "$1" in
      --) shift; # 帮助信息。
        -h) 用法;
        *) # 对输入进行错误检查可能是合适的。
      esac
    esac
    shift
  done

if [ $# -eq $NOARGS ]; then
  Fatal
fi

base=$1
shift
PrintBases "$@"
```
