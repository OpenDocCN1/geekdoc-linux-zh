# Advanced Bash-Scripting Guide

telnet
Utility and protocol for connecting to a remote host.

> The telnet protocol contains security holes and should probably be avoided.
Its within a shell script is not recommended.

wget
The wget utility interactively retrieves or downloads files from a Web or ip site. It works well in a script.

```
wget -p http://www.xyz23.com/file01.html
# -p or --page-requisite option causes wget to fetch all files
# required to display the specified page.

wget -r ftp://ftp.xyz24.net/-boz/project_files/- -O SAVEFILE
# - r option recursively downloads and retrieves all links
# + on the specified site.

wget -c http://ftp.xyz25.net/boziles/filename.tar.bz2
# - c option lets wget resume an interrupted download.
# This works with ftp servers and many HTTP sites.
```
