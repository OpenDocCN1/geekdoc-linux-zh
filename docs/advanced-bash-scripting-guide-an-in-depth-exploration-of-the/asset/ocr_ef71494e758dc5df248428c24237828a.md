# Advanced Bash-Scripting Guide

vdir Show a detailed directory listing. The effect is similar to ls -lb.

This is one of the GNU fileutils.

```
bash$ vdir
total 10
-rw--r-- 1 bozo bozo 4034 Jul 18 22:04 datal.xrolo
-rw--r-- 1 bozo bozo 4602 May 25 13:58 datal.xrolo.bak
-rw--r-- 1 bozo bozo 877 Dec 17 2000 employment.xrolo

bash$ ls -l
total 10
-rw--r-- 1 bozo bozo 4034 Jul 18 22:04 datal.xrolo
-rw--r-- 1 bozo bozo 4602 May 25 13:58 datal.xrolo.bak
-rw--r-- 1 bozo bozo 877 Dec 17 2000 employment.xrolo
```

locate, socate
The locate command searches for files using a database stored for just that purpose. The socate command is the secure version of locate (which may be aliased to socate).

# $bash locate hickson

```
/usr/lib/xephem/catalogs/hickson.edb
```

getfac, setfacl commands retrieve or set the file access control list - the owner, group, and file permissions.

```
bash$ getfacl *
# file: test1.txt
# owner: bozo
# group: bozgrp
#rw::-
user::-
group::rw-
other::--

# file: test2.txt
# owner: bozo
# group: bozgrp
user::rw-
group::rw-
other::--
```

```
bash$ setfacl -m u:bozo:rw yearly_budget.csv
bash$ getfacl yearly_budget.csv
# file: yearly_budget.csv
# owner: accountant
# group: budgetgrp
user::rw-
user:bozo:rw-
user:accountant:rw-
group::rw-
mask::rw-
other::--
```
