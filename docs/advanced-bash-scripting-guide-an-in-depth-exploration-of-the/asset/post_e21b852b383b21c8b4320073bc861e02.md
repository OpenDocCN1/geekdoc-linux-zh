# Enhancements to the case construct: the ;; and & terminators

## Example 37-7. Testing characters

```bash
#!/bin/bash
test_char () {
    case "$1" in
        ([print::]]) echo "$1 is a printable character.";;& # |
        # The #& terminator continues to the next test. | |
        ([alnum::]) echo "$1 is an alpha/numeric character.";;& # v
        ([alpha::]) echo "$1 is an alphabetic character.";;& # |
        ([lower::]) echo "$1 is a lowercase alphabetic character.";;& # |
        ([digit::]) echo "$1 is a numeric character.";;& # |
        # The #& terminator executes the next statement | |
        *) echo *****************************;; # v
            ... even with a dummy pattern.
    esac
}
echo
test_char 3
# 3 is a printable character.
# 3 is an alpha/numeric character.
# 3 is a numeric character.
********************
echo
test_char m
# m is a printable character.
# m is an alpha/numeric character.
# m is an alphabetic character.
# m is a lowercase alphabetic character.
echo
test_char /
# / is a printable character.
echo
# The ;; terminator can save complex if/then conditions.
# The #& is somewhat less useful.
```

The new coproc enables parallel processes to communicate and interact. As Chet Ramey states in the Bash FAQ [131], version: 4.01.

There is a new 'coproc' reserved word that specifies a coprocess an asynchronous command run with two pipes connected to the shell. Coprocs can be named. The input and output file descriptors and the PID of the coprocess are available to the calling shell variables with coproc-specific names.

George Dimitriu explains,
"... coproc is a feature used in Bash process substitution, which now is made publicly available."

This means it can be explicitly invoked in a script, rather than just being a behind-the-scenes mechanism used by Bash.

# 37. Bash, versions 2, 3, and 4

Coprocesses use file descriptors. File descriptors enable processes and pipes to communicate.

```bash
#!/bin/bash
# A coprocess communicates with a while-read loop.

coproc ( cat mx_data.txt; sleep 2; )
# ^^^^^^^^^
# Try running this without "sleep 2" and see what happens.

while read -u ${COPROC[0]} line
do
    echo "$line" | sed -e '/line/NOT-ORIGINAL-TEXT/'
done

kill $COPROC_PID
# No longer need the coprocess
# so kills its PID.
```

But be careful!

```bash
#!/bin/bash
echo; echo
a=aaa
b=bbb
c=ccc

coprocess echo "one two three" a b c; # Note that this loop
while read -u ${COPROC[0]} 
do
    # runs in a subshell.
    echo "Inside while-read-loop: "
    echo "a = $a"; echo "b = $b"; echo "c = $c"
    echo "coprocess file descriptor: ${COPROC[0]}"
done

# a = one
# b = two
# c = three
# So far, good, but ...

echo ""
echo "Outside while-read-loop: "
echo "a = $a"; a = =
echo "b = $b"; b = =
echo "c = $c"; c = =
echo "coprocess file descriptor: ${COPROC[0]}"
echo
# The coprocess is still running, but ...
# it still doesn't enable the parent process
# to "inherit" variables from the child process, the while-read loop.

# Compare this to the "badread.sh" script.
```

The coprocess is asynchronous, and this might cause a problem. It may terminate before another process has finished communicating with it.

mapfile makes it possible to load an array with the contents of a file using command substitution.

```bash
#!/bin/bash
mapfile Arr1 < <(cat)
# Same result as Arr1# Copies this entire file to stdout.
```

But, not the same as read -a.
```bash
read -a Arr2 < file
# Reads first line into the array.
```

# Chapter 37. Bash, versions 2, 3, and 4

The declare builtin now accepts -l lowercase and -c options.

```bash
#!/bin/bash
declare -l var1 # Will change to lowercase
var1=MixedCase # mixedcasevariable
echo "$var1" # Same effect as tr A-Z a-z

declare -c var2 # Changes only initial char to uppercase.
var2=originally_lowercase # Original_lowercase
echo "$var2" # NOT the same effect as tr-z
```

Brace expansion has more options. Increment-decrement, specified in the final term within braces.

```bash
#!/bin/bash
echo {40..60}
# 40 42 44 46 48 50 52 54 58 60
# All the even numbers, between 40 and 60.

echo {60..40}
# 60 58 56 54 52 50 48 46 44 42
# All the even numbers, between 40 and 60, counting backwards.
echo {60..-2}
# The same output. The minus sign is not necessary.
```

```bash
# But, what about letters and symbols?
echo {X..d}
# X Y Z a b c d
# Does not escape the \ which escapes a space.
```

Zero-padding, specified in the first term within braces, prefixes each term in the output with the number of zeros.

```bash
bash$ echo {010..15}
010 011 012 013 014 015

bash$ echo {000..10}
000 001 002 003 004 005 006 007 008 009 010
```

* The new **globbing** operator matches filenames and directories recursively.

```bash
#!/bin/bash
# filelist.bash
shopt -s globstar # Must enable globstar, otherwise ** doesn't work.
# The globstar shell option is new to version 4 of Bash.
```

```bash
echo "Using *"; echo
for filename in *
do
    echo "$filename"
    # Lists only files in current directory ($PWD).
```

```bash
echo; echo "-----------------------"; echo
```

```bash
echo "Using ***"
for filename in **
do
    echo "$filename"
    # Lists complete file tree, recursively.
```

```bash
exit
```
