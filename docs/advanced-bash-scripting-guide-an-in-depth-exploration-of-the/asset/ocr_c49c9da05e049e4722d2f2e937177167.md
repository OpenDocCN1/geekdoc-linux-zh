The newer Linux distros have deprecated mount and umount. The successor, command-line mounting of removable storage devices, is gnome-mount. It can take the -d option to mount a device file by its listing in /dev.

For example, to mount a USB flash drive:

```
bash$ gnome-mount -d /dev/sda1
gnome-mount 0.4
```

```
bash$ df
./dev/sda1    63584 12034 51550 19% /media/disk
```

Forces an immediate write of all updated data from buffers to hard drive (synchronize drive with buffers). While not strictly necessary, a sync ensures the sys admin or user that the data just changed will survive a sudden power failure. In the old days, a sync; sync (twice, just to make absolutely sure) was a useful precautionary measure before a reboot.

At times, you may force an immediate buffer flush, as when securely deleting a file (see Example 16-61) or when the lights begin to flicker.

Sets up and configures loopback devices.

# Example 17-8. Creating a filesystem in a file

```
SIZE=1000000  # 1 meg
nhead -c $SIZE < /dev/zero file  # Set up file of designated size.
losetup /dev/loop0             # Set it up as loopback device.
mke2fs /dev/loop0               # Create filesystem.
mount -o loop /dev/loop0 /mnt   # Mount it.

# Thanks, S.C.
```
