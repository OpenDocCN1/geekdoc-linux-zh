# 第 26 章 列表结构

`and` 和列表（list）结构提供了连续处理命令的方法。这些可以高效地替换嵌套的 `if/then` 甚至 `case` 语句。

## 命令链

`and` 和列表

```
command-1 && command-2 && command-3 && ... command-n
每个命令顺序执行，前提是上一个命令返回真值（零）。在遇到第一个假（非零）返回时，命令链终止（第一个返回假的命令是最后一个执行的命令）。
```

这是一个来自早期版本《永叶俄罗斯方块》游戏脚本的两个条件 `and` 列表的有趣用法：

```bash
equation()
{
  # 用于坐标倍倍和减半的核心算法
  [[ $(cdx) && ((y=cy+(ccy-cdy)*(2)) ]]
  eval $[1]+=$(x) ${y}
}
```

## 示例 26-1. 使用 and 和列表处理命令参数行

```bash
#!/bin/bash
# list

if [ ! -z "$1" ] && echo "Argument $1" && [ ! -z "$2" ] || \
  echo "Argument $2 = $2"
then
  echo "传递给脚本的参数至少有2 个。"
  # 所有链命令都返回真。
else
  echo "传递给脚本的参数少于2 个。"
  # 链命令中至少有一个返回假。
fi

# 注意 "if [ ! -z $1" ] 是有效的，但它所谓的等效写法
# "if [ -n $1" ] 却并不有效。
#   然而，加引号可以修复此。
#   if [ -n "$1" ] 是有效的。
#     ^  小心！
#   最好始终对待测试的变量加上引号。

# 这使用“纯”if/then 语句实现了相同的功能。
if [ ! -z "$1" ]
then
  echo "Argument $1 = $1"
fi
if [ ! -z "$2" ]
then
  echo "Argument $2 = $2"
  echo "传递给脚本的参数至少有2 个。"
fi
```

## 示例 26-2. 使用 and 列表的另一个命令行参数测试

```bash
#!/bin/bash

ARGS=1            # 预期的参数数量。
E_BADARGS=85      # 如果参数数量错误时的退出值
test -ne $ARGS && $0
^^^^^^^^^^^^^^ condition #1 exit $E_BADARGS
echo "Usage: `basename $0` $ARGS argument(s)" $E_BADARGS
# 如果 condition 1 测试为真（传递给脚本的参数数量错误）
# 则执行行的剩余部分，脚本终止。
# 下一行仅在上述测试失败时才执行。
echo "传递给此脚本的参数数量正确。"
exit 0
```

第 27 章 数组

新版本的 Bash 支持一维数组。数组元素可以使用 `variable[xx]` 符号进行初始化。或者，脚本可以通过显 `declare` 语句引入整个数组。要引用（检索）数组元素的内容，使用大括号符号，即 **${element}**。

## 示例 27-1. 简单数组用法

```bash
#!/bin/bash

area[11]=23
area[13]=37
area[51]=UFO

# 数组成员不需要连续或相邻。
# 数组的某些成员可以留空初始化。
# 数组中的间隙是可以的。
# 事实上，稀疏数据的数组（稀疏数组）
# 在表格处理软件中非常有用。

echo -n "area[11]" = ""
echo ${area[11]} # 需要大括号。

echo -n "area[13]" = ""
echo ${area[13]}

echo "Contents of array[51] are ${area[51]}"

# 未初始数组变量的内容会打印为空（空变量）。
echo -n "area[43]" = ""
echo ${area[43]}
echo "area[43] unassigned"

echo

# 将两个数组变量的和赋值给第三个
area[5]=${area[11]} + ${area[13]}
echo "area[5]" = area[11] + area[13]
echo -n "area[5]" = ""
echo ${area[5]}

area[6]=${area[11]} + ${area[51]}
echo "area[6]" = area[11] + area[51]
echo -n "area[6]" = ""
echo ${area[6]}

# 这会失败，因为不允许向字符串加整数。

echo; echo; echo
```
