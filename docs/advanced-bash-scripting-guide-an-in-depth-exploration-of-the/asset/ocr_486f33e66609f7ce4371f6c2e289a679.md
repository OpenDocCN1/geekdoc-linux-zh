The $(..) form has supersed backticks for command substitution.

```
output=$(sed -n /"$1/p file)    # From 'grp.sh'    example.
# Setting a variable to the contents of a text file.
File_contents1=$$(cat $file1)
File_contents2=$$(cat$file2) # Bash permits this also.
```

The $(..) form of command substitution treats double backslash in a different way than `...`.

```
bash$ echo echo\\
bash$ echo $(echo \\)
```

# Example 12-3. Finding anagrams

```
#!/bin/bash
agram2.sh
# Example of nested command substitution.

# Uses "anagram" utility
# that is part of the author's "yawl" word list package.
# http://iblio.org/pub/Linux/libs/yawl-0.3.2.tar.gz
# http://bash.data.in/yawl-0.3.2.tar.gz

E_NOARGS=86
E_BADARG=87
MINLEN=7

if [ -z "$1" ];
then
  echo "Usage $0"
  exit $E_NOARGS # Script needs a command-line argument.
elif [($1) -lt $MINLEN ];
then
  echo "Argument must have at least $MINLEN letters."
  exit $E_BADARG
fi

FILTER='...
# Must have at least 7 letters.
# 123456
Anagrams=$$(echo $1 | grep $FILTER) )
```
