Each invocation of eval forces a re-evaluation of its arguments.

```
a=$Sb'
b=$Sc'
c=d

echo $a          # Sb
eval echo $a     # First level.
                 # Sc
eval eval echo $a # Second level.
                     # Third level.

# Thank you, E. Chor.
```

# Example 15-11. Showing the effect of eval

```
#!/bin/bash
# Exercising "eval" ...
ymy='ls -1'     # Similar to y='ls -1'
echo $y         # + linefeeds removed "echoed" variable is unquoted.
echo
echo "$y"      # Linefeeds preserved when variable is quoted.

echo;

y=eval df      # Similar to y='df'
echo $y         # + linefeeds removed.

# When LF's not preserved, it may make it easier to parse output,
# using utilities such as "awk".

echo
echo "========================================"

eval "seq 3 | sed -e 's/../echo var=&ABCDEFGHIJ/''
var1=ABCDEFGHIJ
var2=ABCDEFGHIJ
var3=ABCDEFGHIJ

echo
echo "========================================"
echo

# Now, showing how to do something useful with "eval" . .
# (Thank you, E. Choroba!)

version=3.4    # Can we split the version into major and minor
                 # + part in one command?
echo version="$version"  # Replaces '.' in version by ';minor='
eval major=$((version./minor) # The substitution yields '3; minor=4'
                             # so eval does minor=4, major=3
```
