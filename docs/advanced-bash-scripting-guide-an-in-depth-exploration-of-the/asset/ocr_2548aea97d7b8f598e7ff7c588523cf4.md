# 16.7. Terminal Control Commands

Command affecting the console or terminal

tput

Initialize terminal and/or fetch information about it from terminfo data. Various options permit certain terminal operations: tput clear is the equivalent of clear; tput reset is the equivalent of reset.

```
bash$ tput longname
xterm emulator (X Window System)
```

Issuing a tput cup X Y moves the cursor to the (X,Y) coordinates in the current terminal. A clear to erase the screen would normally precede this.

Some interesting options to tput:

+   - bold, for high-intensity text
- smul, to underline text in the terminal
- smos, to render text in reverse
- sgr0, to reset the terminal parameters (to normal), without clearing the screen

Note that infocmp offers a more powerful command for controlling a terminal.

infocmp

This command prints extensive information about the current terminal. It references the terminfo database.

```
bash infocmp
# Reconstructed via infocmp from file:
/usr/share/terminfo/rxvt
rxvt rxvt terminal emulator (X Window System),
am, bce, ec, km, msgr, xenl, xon,
colors#8, smul#8, lines#24, pairs#64,
acsc=afagjj|klmmnnooppqqrssttuuvvwwxyyyz(((|))))~
bnel=0, blink=E[5m, bold=E[1m,
civis=E[25], cursor=E[25h,
clear=\E[2;2J, cr=M
```

reset

Reset terminal parameters and clear text screen. As clear, the cursor and prompt reappear in the upper-left corner of the terminal.

clear

The clear command simply clears the text at the console or in an xterm. The prompt and cursor reappear at the upper left corner of the screen or within xterm. This command may be used either at command line or in a script. See Example 11-26.
