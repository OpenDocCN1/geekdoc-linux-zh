# Length of Matching Substring at Beginning of String

expr match "String" "$substring"
  $substring is a regular expression.
expr "String" : "$substring"
  $substring is a regular expression.

```bash
stringZ=ABC123ABCabc
#-------
# 12345678

echo expr match "$stringZ" 'abc[A-Z].*2' # 8
echo expr "$stringZ" : 'abc[A-Z].*2' # 8
```

# Index

expr index $string $substring
Numerical position in $string of first character in $substring that matches.

```bash
stringZ=ABC123ABCabc
# 123456...
echo expr index "$stringZ" C12 # 6
  # C position.
```

```bash
echo expr index "$stringZ" 1c # 3
  # 'c' (in #3 position) matches before '1'.
This is the near equal of strchr(in C).
```

# Substring Extraction

$string:position]
Extracts substring from $string at $position.

If the $string parameter is "*" or "@", then this extracts the positional parameters starting at $position.
$string:length]
Extracts $length characters of substring from $string at $position.

```bash
stringZ=ABC123ABCabc
# 0123456789...
# 0-based indexing.

echo ${stringZ:0} # ABC123ABCabc
echo ${stringZ:1} # BCABC123ABCabc
echo ${stringZ:7} # 23ABCabc

echo ${stringZ:7:3} # 23A
  # Three characters of substring.
```

The position and length arguments can be "parameterized," that is, represented as a variable, rather than a numerical constant.

# Example 10-2. Generating an 8-character "random" string

```bash
#!/bin/bash
# rand-string.sh
# Generating an 8-character "random" string.

if [ -n "$1" ]                                # If command-line argument present
then
    # then set start-string to it.
    str0="$1"
else                                         # Use PID of script as start-string.
    str0=$$
fi

POS=2 # Starting from position 2 in the string.
LEN=8 # Extract eight characters.

str1=$(echo "$str0" | md5sum)
# Doubly scramble
# by piping and repiping to md5sum.

randstring="${str1:$POS:$LEN}"
# Can parameterize

echo "$randstring"
```

```bash
exit $?

bozo ./rand-string.sh my-password
ldbb88c4

# No, this is not recommended
# as a method of generating hack-proof passwords.
```

If the $string parameter is "" or "@", then this extracts a maximum of $length position parameters, starting at $position.

```bash
echo ${*:2}                                     # Echoes second and following positional parameters.
echo ${@}                                          # Same as above.

echo ${*:2:3}                                     # Echoes three positional parameters, starting at second.
```

# Substring Removal

$[$substring]
Deletes match of $substring from front of $string.
${string##substring}
Deletes longest match of $substring from front of $string.

```bash
stringZ=ABC123ABCabc
# shortest
# ----|
# longest
echo ${stringZ#*C} # 123ABCabc
# Strip out shortest match between 'a' and 'C'.
echo ${stringZ##*a} # abc
# Strip out longest match between 'a' and 'C'.

# You can parameterize the substrings.
X='a*C'
echo ${stringZ#$X} # 123ABCabc
echo ${stringZ##$X} # abc
# As above.
```
