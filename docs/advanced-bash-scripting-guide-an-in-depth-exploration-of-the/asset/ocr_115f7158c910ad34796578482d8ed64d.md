[100] Filename expansion expands filename patterns or templates containing special characters. For example, example??? might expand to example.001 and/or example.txt.

[101] A wild character, analogous to a wild card in poker, can prevent (almost) any other character.

[102] Filename expansion can match dotfiles, but only if the pattern explicitly includes the dot as a literal character.

```
~.bashrc      # Will not expand to ~/.bashrc
~?bashrc      # Neither will this.
               # Wildcards and metacharacters will NOT
               # expand to a dot in globbing.

~.[bashrc      # Will expand to ~.bashrc
~.ba7rc       # Likewise.
~/.bashrc      # Likewise.
```

[104] By convention in UNIX and Linux, data streams and peripherals (device files) are treated as files, in a fashionable analogous to ordinary files.

[105] A file descriptor is a simple number that the operating system assigns to a file to keep track of. Consider it a simplified type of pointer. It is analogous to a file handle in C.

[106] Using file descriptor 5 might cause problems. When Bash creates a child process, as with exec, the child inherits fd 5 (see Chet Rayleigh's e-mail, SUBJECT: RE: File descriptor 5 is held open). Best leave this particular fd alone.

[107] An external command invoked with an exec does not (usually) for fork off a subprocess / subshell.
