```
# Version 0.2: Patched by Daniel Albers
# allow non-square grids as input.
# Version 0.2.1: Added 2nd-second delay between generations.
# This is the Bash script version of Conway's "Game of Life".
# "Life" is a simple implementation of cellular automata.
# On a rectangular grid, let each "cell" be either "living" or "dead".
# Designate a living cell with a dot, and a dead one with a blank space.
# Begin with an arbitrarily drawn dot-and-blank grid,
# and let this be the starting generation: generation 0.
# Determine successive generation by the following rules:
# 1) Each cell has 8 neighbors, the adjoining cells
# left, right, top, bottom and 4 diagonals.
# 2) A living cell with either 2 or 3 living neighbors remains alive.
# 3) A dead cell with 3 neighbors comes alive, a "birth.
# 4) All other cases result in a dead cell for the next generation.
```
