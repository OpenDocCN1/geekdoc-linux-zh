# Advanced Bash-Scripting Guide

null command [colon]. This is the shell equivalent of a NOP (no op, a do-nothing operation). It may be considered a synonym for the shell true. The ":" command is itself a Bash builtin, and its exit status is true (0).

```
echo $? # 0
Endless loop:

while :
  do
    operation-1
    operation-2
    ...
    operation-n
  done
# Same as:
# while true
# do
# ...
# done
```

```
if condition
  # Do nothing and branch ahead
then
else
  # Or else
  take-action
fi
```

Provide a placeholder where a binary operation is expected, see Example 8-2 and default parameters.

```
$(username=whoami) Gives an error without the leading :
# $(username=whoami) unless "username" is a command or builtin...
$(l?="Usage: $ARGUMENT") # From usage-message.sh example script.
```

Evaluate string of variables using parameter substitution (as in Example 10-7).

```
$(HOSTNAME)? $? ($MAIL)
# Prints error message
+# if one or more of essential environmental variables not set.
```

Variable expansion/substitution replacement.

In combination with the > redirection operator, truncates a file to zero length, without changing its permissions. If the file did not exist previously, creates it.

```
> data.xxx # File now empty.
# Same effect as cat /dev/null >data.xxx
# However, this does not fork a new process, since ":" is a builtin.
```
