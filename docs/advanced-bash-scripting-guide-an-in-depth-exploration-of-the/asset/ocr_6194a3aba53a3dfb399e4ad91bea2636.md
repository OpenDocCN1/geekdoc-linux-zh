Virtually UNIX and shell operators and commands have many more options and enhancements their DOS and batch file counters. Many DOS batch files rely on auxiliary utilities, such as ask.com, a crippled counter to read.

DOS supports only a very limited and incompatible subset of filename wild-card expansion, recognizing just the * and ? characters.

Converting a DOS batch file into a shell script is generally straightforward, and the result oftimes better than the original.

# Example N-1. VIEWDATA.BAT: DOS Batch File

```
REM VIEWDATA
REM INSPIRED BY AN EXAMPLE IN "DOS POWERTOOLS"
BY PAUL SOMERSON

@ECHO OFF

IF %1!==== GOTO VIEWDATA
REM NO COMMAND-LINE ARG...
FIND "$1" C:\BOZO\BOOKLIST.TXT
GOTO EXIT0
REM PRINT LINE WITH STRING MATCH, THEN EXIT.

:VIEWDATA
TYPE C:\BOZO\BOOKLIST.TXT | MORE
REM SHOW ENTIRE FILE, 1 PAGE AT A TIME.

:EXIT0~
```
