Command substitution permits setting variable to the output of a loop. The key to this is grabbing the output of an echo within the loop.

Example 12-2. Generating a variable from a loop

```bash
#!/bin/bash
# csubloop.sh: Setting a variable to the output of a loop.
variable=$(for i in 1 2 3 4 5
do
    echo -n "$i"      # The 'echo' command is critical
                   # to command substitution here.
done)
echo "variable1 = $variable1" # variable1 = 12345

i=0
variable2=`while [ "$i" -lt 10 ]
do
    echo -n "$i"      # Again, the necessary 'echo'.
    let "i += 1"     # Increment.
done)
echo "variable2 = $variable2" # variable2 = 0123456789

# Demonstrates that it's possible to embed a loop
# inside a variable declaration.
```

# Variations

Arithmetic expansion provides a powerful tool for performing (integer) arithmetic operations in scripts. Translating a string into a numerical expression is relatively straightforward with backticks, double parentheses, or let.

```bash
z=expr $3
```

Arithmetic expansion with double parentheses, in arithmetic expansion has been superseded by double parentheses.

```bash
z=$((z+3))
```

You may also use operations within double parentheses.

```bash
n=0
echo "n = $n"             # n = 0

(( n += 1 ))                            # Increment.
(( n += 1 ))                            is incorrect!
echo "n = $n"             # n = 0
```

The 'let' operator actually performs arithmetic evaluation,
```bash
let z=3
let "z += 3"          # Quotes permit the use of spaces in
```
Not to be confused with command substitution.
