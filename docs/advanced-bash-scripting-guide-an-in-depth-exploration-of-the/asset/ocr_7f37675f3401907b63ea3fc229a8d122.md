# 4.3. Bash Variables Are Untyped

Unlike many other programming languages, Bash does not segregate its variables by "type.\ Essentially, Bash variables are character strings, depending on context, Bash permits arithmetic operations and comparisons on them. The determining factor is whether the value of a variable contains only digits.

Example 4-4. Integer or string?

```
#!/bin/bash
# int-or-string.sh

a=2334
let "a += 1"        # Integer.
echo "a = $a"      # a = 2335
echo                # Integer
```
