:DigestFilesDoc

The key (no pun intended) to a Unified Content File System (UCFS) is to distinguish the files in the system based on their content. Distinguishing files by their name is just so 20th Century.

The content is distinguished by computing a checksum of that content. This version uses the mdsum program to generate a 128 bit checksum representative of the file's content. There is a chance that two files having different content might generate the same checksum using mdsum (or any checksum). Should that become a problem, then the use of mdsum can be replaced by a cryptographic signature. But until then...

The mdsum program is documented as outputting three fields (and it does), but when it appears as two fields (array elements). This is caused by the lack of whitespace between the second and third field. So this function grooms the mdsum output and returns:

+   [0] 32 characters (UCFS filename)
[1] Single character: ' ' text file, '*' binary file
[2] Filesystem (20th Century style) name

Note: That name may be the character '-' indicating STDIN read.
