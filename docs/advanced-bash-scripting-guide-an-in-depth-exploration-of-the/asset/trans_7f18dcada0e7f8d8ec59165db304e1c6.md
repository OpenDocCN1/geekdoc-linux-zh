# 平方根

使用牛顿法计算平方根。

```
guess = argument
tolerance = .00001
oldguess = 0

while [ $(echo "$guess - $oldguess" | bc -l) -gt $tolerance ]; do
  oldguess=$guess
  guess=$(echo "($guess + $argument/$guess) / 2" | bc -l)
done
echo $guess
```
（注：此处原文代码块在 `done` 之后开始出现混乱的重复文本和乱码，已根据逻辑进行了清理处理，仅保留核心结构）
