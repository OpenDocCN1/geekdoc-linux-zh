

# 高级 Bash 脚本指南

```bash
return_test 27      # 正常。
echo $?               # 返回 27。

return_test 255      # 仍然正常。
echo $?               # 返回 255。

return_test 257      # 错误！
echo $?               # 返回 1（各种错误的错误返回码）。
=======================================================================
return_test -151896    # 大负数可以工作吗？
echo $?               # 这会返回 -151896 吗？
                       # 不！它返回 168。
=======================================================================
2.0b 之前的 Bash 版本允许
+# 大负整数作为返回值。
# 这恰好是一个很有用的功能。
# 遗憾的是，新版本的 Bash 封堵了这个漏洞。
# 这可能会破坏旧的脚本。
# 注意！
=================================================================

exit 0
```

获取大整数“返回值”的一种变通方法是将“返回值”简单赋值给全局变量。

```bash
Return_Val=          # 用于持有函数超大范围返回值的全局变量。
alt_return_test () {
fvar=$fvar
Return_Val=$fvar
return                # 返回 0（成功）。
}

alt_return_test 1      # 0
echo $?               # 1
echo "return value" = $Return_Val"

alt_return_test 256    # 256
echo "return value" = $Return_Val"

alt_return_test 257    # 257
echo "return value" = $Return_Val"

alt_return_test 25701 # 25701
echo "return value" = $Return_Val"
```

更优雅的方法是让函数向**标准输出 (stdout)** **echo**“返回值”，然后通过**命令替换**来捕获它。参见**第 36.7 节**中的[相关讨论](#)。

# 高级 Bash 脚本指南

```bash
EQUAL=0 # 如果两个参数相等时的返回值。
E_PARAM_ERR==99999 # 传递给函数的参数不足。
      ^^^^^ 超出了任何可能传递的参数的范围。

max2 () # “返回”两个数中较大的一个。
{
if [ -z "$2" ]
then
  echo $E_PARAM_ERR
  return
fi

if [ "$1" -eq "$2" ]
then
  echo EQUAL
  return
else
  if [ "$1" -gt "$2" ]
then
    retval=$1
  else
    retval=$2
  fi
fi

echo $retval # 输出（到标准输出），而不是返回值。
  # 为什么？
}

return_val=$(max2 33001 33997)
      ^^^^^ 函数名
#      ^^^^^^ 传递的参数
# 这实际上是命令替换的一种功能：
+# 将函数视为命令，
# 并将函数的标准输出赋值给变量 "return_val"。

# = 输出 =
if [ "$return_val" -eq "$E_PARAM_ERR" ]
then
  echo "传递给比较函数的参数错误!"
elif [ "$return_val" -eq "$EQUAL" ]
then
  echo "两个数字相等。"
else
  echo "两个数中较大的一个是 $return_val。"
fi
#n
exit 0

# 练习：

+# 传递给函数的参数。
# 2) 简化 if/then 结构。
# 3) 重写脚本以接收命令行参数。
```
