# tr variants

The tr has two historic variants. The BSD version does not use brackets (tr a-z A-Z), the SysV one uses (tr '[a-z]' '[A-Z]'). The GNU version of tr resembles the BSD one.

A filter that wraps lines of input to fmt is Kamil Tomar's fmt, available from http://www.cs.berkeley.edu/~amc/. See Example 16-26 and Example A-1.

Simple-minded file formatter, used as a filter in a pipe to "wrap" long lines of text output.

# Example 16-26. Formatted file listing.

```
#!/bin/bash
WIDTH=40 # 40 columns wide
b='ls -f /usr/local/bin' # Get a file listing...
echo $b | fmt -w $WIDTH

# Could also have been done by
# echo $b | fold -s -w $WIDTH

exit 0
```

See Example 16-5.
