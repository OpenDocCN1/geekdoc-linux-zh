${string%substring} deletes shortest match of $substring from back of $string.

For example:

```
# Rename all filenames in $PWD with "TXT" suffix to a "txt" suffix.
# For example, filele.TXT becomes filele.txt" . .
nSUFF=TXT
suff=txt

for i in $(ls *$SUFF).$suff
do
  mv -f $i${i..suff}
  # Leave unchanged *except* the shortest pattern match $i
  ## from the right-hand-side of the variable $i ..
done ### can be condensed into a "one-liner" if desired.

# Thank you, Rory Winston.
```

${string%*substring} deletes longest match of $abc from back of $string.

```
stringZ=abc123Abc shortest
#                  | longest
#                  ------|----------
echo ${stringZ%b*c}  # abc123AbCA
# Strip out shortest match between 'b' and 'c', from back of $stringZ.
echo ${stringZ%%b*c}  # a
# Strip out longest match between 'b' and 'c', from back of $stringZ.
```

This operator is used for generating filenames.
