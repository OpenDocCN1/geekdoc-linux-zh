# nslookup

Do an Internet "name server lookup" on a host by IP address. This is essentially equivalent to ipcalc -h or dig -x. The command may be run interactively or non-interactively, i.e., from within a script.

The nslookup command has been "deprecated", but it is still useful.

```bash
bash$ nslookup -sil 66.97.104.180
nslookup kuhlesparsnis.ch
Server:      135.116.137.2
Address:     135.116.137.2#53

Non-authoritative answer:
Name:       kuhsparsnis.ch
```

# dig

Domain Information Groper. While nslookup, dig does an Internet name server lookup on a host. May be run from the command-line or within a script.

Some interesting options to dig are +time=N for setting a timeout to N seconds, +nofail for querying servers until a reply is received, and -x for doing a reverse address lookup.

Compare the output of dig -x with ipcalc -h and nslookup.

    # Parse $1 by the dots.
    local -a dns
    IFS=$ADR_IFS
    dns=($1)
    if [ "${dns[0]}" == '127' ]; then

# Get the dns address resource record.
chk_addr <rev_dns> <list_server>
chk_addr() {
    local reply
    local server
    local reason

    server=${1}${2}
    reply=$(dig +short $server)

    # If reply might be an error code ...
    if [ ${reply} -gt 6 ]; then
        reason=$(get_txt $server)
        reason=${reason:-$reply}
    fi
    echo "${reason:-'not blacklisted.'}"
}
