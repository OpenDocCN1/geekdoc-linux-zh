groff, tbl, eqn

Yet another markup and display formatting language is groff. This is the enhanced GNU version of the venerable UNIX roff/roff display and typesetting package. Manpages use groff.

The tbl table processing utility is considered part of groff, as its function is to convert table markup into groff commands.

The eqn processing utility is likewise part of groff, and its function is to convert equation markup into groff commands.

lex, yacc

The lex lexical analyzer produces programs for pattern matching. This has been replaced by the nonproprietary flex on Linux systems.

The yace utility creates a parser based on a set of specifications. This has been replaced by the nonproprietary bison on Linux systems.
