# Advanced Bash-Scripting Guide

```
bash$ echo $?
1
```

Or in a script:

```
command_test () { type "$1" &>/dev/null; }
#
cmd=rmdir              # Legitimate command.
command_test $cmd; echo $?       # 0

cmd=bogus_command                # Illegitimate command
command_test $cmd; echo $?       # 1
```

command &2 redirects stdout of command to stderr.

scriptname >>filename appends the output of scriptname to file filename. If filename does not exist, it is created.

[i]<filename opens filename for reading and writing, assigns file descriptor i to it. If filename does not exist, it is created.
