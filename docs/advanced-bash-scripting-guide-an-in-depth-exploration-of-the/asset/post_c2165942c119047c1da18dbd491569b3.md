expand, unexpand
The expand filter converts tabs to spaces. It is often used in a pipe.

The unexpand converts tabs to spaces. This reverses the effect of expand.

cut
A tool for extracting fields from files. It is similar to the print $N command in awk, but more limited. It may be simpler to use cut in a script than awk. Particularly important are the -d (delimiter) and -f (field specifier) options.

Using cut to obtain a list of the mounted files:

```
cut -d ' ' -f1,2 /etc/mtab
Using cut to show the OS and kernel version
```

```
uname -a | cut -d" " -f1,3,11,12
```

Using `cut` to parse a file:

```bash
# List all the users in /etc/passwd.

FILENAME=/etc/passwd

for user in $(cut -d -f1 $FILENAME)
do
  echo $user
done
```

linefeed

> It is even possible to specify a linefeed as a delimiter. The trick is to actually embed a linefeed (RETURN) in the command sequence.

```bash
bash$ cut -d'' -f3,7,19 testfile
This is line 3 of testfile.
This is line 7 of testfile.
This is line 19 of testfile.
```

paste
Tool for merging different files into a single, multi-column file. In combination with `cut`, useful for creating system log files.

```bash
bash$ cat items
alphabet blocks
building blocks
cables

bash$ cat prices
$1.00/dozen
$2.50 ea.
$3.75

bash$ paste items prices
alphabet blocks $1.00/dozen
building blocks $2.50 ea.
cables $3.75
```

join Consider this special-purpose cousin of `paste`. This powerful utility allows merging two files in a meaningful fashion, which essentially creates a simple version of a relational database.

The join command operates on exactly two files, pastes together those lines with a common tagged field (usually a numerical label), and writes the result to stdout. The files to be joined should be sorted by the tagged field for the matchups to work properly.

```
File: 1.data

100 Shoes
200 Laces
300 Socks
```

File: 2.data

100 $4000
200 $100
300 $00
```

```bash
bash$ join 1.data 2.data
File: 1.data

100 Shoes $400
200 Laces $100
300 Socks $00
```

# Example 16-13. Which files are scripts?

```bash
#!/bin/bash
# script-detector.sh: Detects scripts within a directory.

TESTCHARS=2      # Test first 2 characters.
BANG='#!      # Scripts begin with "#!".

for file in *  # Traverse all files in the current directory.
  if [[ $(head -c$TESTCHARS "$file") == "$BANG" ]]; then
    head -c                                     # The '-c' option to "head" outputs a specified
    number of characters, rather than lines (default),
    echo "$file" is a script.
  else
    echo "$file" is not a script.
  fi
done
```

# Example 16-14. Generating 10-digit random numbers

```bash
#!/bin/bash
# rnd.sh: Outputs 10-digit random number Script by Stephane Chazelas.

head -c4 /dev/random | od -N4 -tu4 | sed -ne '1s/. //p'
```

# =================================================
# Analysis

# head:
# -c4 option takes 4 bytes.

# od:
# -N4 option limits output to 4 bytes.
# -tu4 option selects decimal format for output.

# sed:
# -n option, in combination with "p" flag to "s" command, outputs only matched lines.

# > The author of this script explains the action of 'sed', as follows.
# head -c4 /dev/random | od -N4 -tu4 | sed -ne '1s //p'
#
# Assume output to "sed" is 00000011 1198154\n

# sed begins reading: 000000 1198154.n.
# it finds a newline character, so it is ready to process the first line (000000 1198154).
# it looks at its <range><action>s. The first and only one:

range	action
1	s*/ //p

The line is to substitute the longest string ending with a space in the line to substitute "000000" with nothing (/), and if it succeeds, prints the result ("p" is a flag to the "s" command here, this is different from the "p" command).

# sed is now ready to continue reading its input. (Note that before continuing, if -n option has not been, sed would have printed the line again).

# Now, sed the remainder of the characters, and finds the end of the file.

# It is now ready to process its 2nd line (which is also numbered '$' as it's the last one).
# It sees not matched by any <range>, so its job is done.

# In few word this sed command:
# "On the first line delete, remove any character up to the right-most space, then print it."

# A better way to do this would have been:
# sed -e 's.* //q'

# Here, two <range>-action's (could have been written)
# sed -e 's.*/ // -e q:

# range               action
# nothing (matches line)  s/. //
# nothing (matches line)  q (quit)

# Here, sel reads its first line of input.
# It performs both actions, and prints the line (substituted) before quitting (because of the "q" action) since the "-n" option is not passed.
# =================================================================
# An even simpler alternative to the above one-line script would be:
# head -c4 /var/random/ od -An -tu4

exit
```
