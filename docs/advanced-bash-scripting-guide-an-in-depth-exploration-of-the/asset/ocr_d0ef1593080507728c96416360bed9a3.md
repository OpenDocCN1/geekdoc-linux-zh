The -c "complement" inverts the character set to match. With this option, tr acts only upon characters not matching the specified set.

```
bash$ echo "acfdeb123" | tr -c b-d +
c+d+b++
```

Note that tr recognizes POSIX character classes. [74]

```
bash$ echo "abcd2ef1" | tr '[:alpha:]'-
---2--1
```

**Example 16-21.** Transforms a file to all uppercase.

```
#!/bin/bash
# Changes a file to all uppercase.

E_BADARGS=85

if [ -z "$1" ]; # Standard check for command-line arg.
then
    echo "Usage: `basename $0` filename"
    exit $E_BADARGS
fi

t a-z A-Z "$1"

# Same effect as above, but using POSIX character set notation:
# tr `[:lower:]` '[:upper:]' "$1"
# Thanks, S.C.

# Or even ..
# cat "$1" | tr a-z A-Z
# Or dozens of other ways . .

exit 0

#+ to "either" upper or lowercase.
# Hint: Use the "case" or "select" command.
```

**Example 16-22.** *lowercase:* Changes all files in working directory to lowercase.

```
#!/bin/bash
# Changes every filename in working directory to all lowercase.

# Inspired by a script of John Dubois,
#+ which translated into Bash by Chet Ramey,
#+ and considerably simplified by the author of the ABS Guide.

for filename in * # Traverse all files in directory.
do
    filename=`$filename"
    n=echo $filename | tr A-Z a-z` # Change name to lowercase.
```
