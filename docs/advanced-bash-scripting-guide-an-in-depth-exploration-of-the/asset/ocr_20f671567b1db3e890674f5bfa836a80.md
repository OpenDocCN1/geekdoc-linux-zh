# Advanced Bash-Scripting Guide

+   -D Change default action - silent. (See note)
-s<n> Go to the special entry <n>
-S<n> Go to the special entry <n>
and replace it with the current *
-r<dir> Go to directory <dir>
and put it on special entry <n*>
-Rn<dir> Go to directory <dir>
and put current dir on special entry <n*>

+   -a Alternative suggested directory. See note below.
-f <file> File entries to <file>.
-u <file> Update entries from <file>
if filename supplied then default file
($CDPath){1-2}="$CDFILE" is used
-F and -U are silent versions

*The special entries (0 - 9) are held until log off, replaced by another
entry or updated with the -command

Suggested directories:
If a directory is not found CD will suggest any
possibilities. These are directories starting with the same letters
and if any are found they listed prefixed with -a<n>
where <n> is a number.
It's possible to go to the directory by entering cd -a<n>
on the command line.

The directory for -r<n> or -R<n> may be a number.

```
$ cd -r34 Go to history 4 and put it on special entry 3
$ cd -R34 Go to current dir on the special entry 3
and go to history 4
$ cd -s3 Go to special entry 3
```

Note that commands R,T, and S may be used without a number
and refer to 0:

```
$ cd -s Go to special entry 0
$ cd -S Go to special entry and make special
entry 0 current dir
```

```
$ cd -r1 Go to history 1 and put it on special entry 0
$ cd -r0 Go to history 0 and put it on special entry 0
```
