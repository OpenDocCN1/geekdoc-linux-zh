## Brace expansion

```
echo "{These,word,are,quoted}" # " prefix and suffix
# "These "words" are "quoted"
```

```
cat {file1,file2,file3} > combined_file
# Concatenates the files file1, file2, and file3 into combined_file
```

```
cp file22.{txt,backup} "file22.backup"
# Copies "file22.txt" to "file22.backup"
```

A command may act with a comma-separated list of files within braces. [20] Filename expansion (globbing) applies to the file specs within the braces.

No spaces allowed within braces unless the spaces are escaped.

```
echo {file1,file2\}: \"A,\"B\",\ 'C'
```

```

```

## Example 3-2. Saving the output of code block to a file

```bash
#!/bin/bash
# rpm-check.sh

# Queries rpm file for description, listing, and whether it can be installed.
SUCCESS=0
E_NOARGS=65

if [ -z "$1" ]
then
    echo "Usage: `basename $0` -file"
    echo "Archive Description:"
    echo "Archive Listing:"
    rpm -q $1 # Query whether file can be installed.
    echo "$1 can be installed."
else
    echo "$1 cannot be installed."
fi

# End code block.
# Redirects output of everything in block to file.
> "$1.test"

echo "Results of test in file $1.test"
# See rpm man page for explanation of options.
exit 0
```

Unlike a command group (parentheses), as above, code block enclosed by {} will normally launch a subshell. It is possible to iterate code block using a non-standard-loop (replace strings). The {} double brackets are placeholder for output text.
