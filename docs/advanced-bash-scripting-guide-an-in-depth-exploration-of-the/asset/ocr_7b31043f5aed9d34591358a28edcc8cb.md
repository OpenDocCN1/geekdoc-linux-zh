# Utilities

# basename

Strips the path information from a file name, printing only the file name. The construction `basename $0` lets the script know its name, that is, the name it was invoked by. This can be used for "usage" messages if, for example a script is called with missing arguments:

```
echo `Usage: `basename $0` arg arg2 ... argn`
```

# dirname

Strips the basename from a filename, printing only the path information. The argument does not need to refer to an existing file, or be a filename for that matters (see Example A-7).

+   **basename** and **dirname** can operate on any arbitrary string. The argument does not need to refer to an existing file, or be a filename for that matters (see Example A-7).

Example 16-36. basename and dirname

```
!/bin/bash
address/home/bozo/daily-journal.txt
echo `Basename of /home/bozo/daily-journal.txt` = `basename $address`
echo `Dirname of /home/bozo/daily-journal.txt` = `dirname $address`
echo `My home is` `basename ~` = also works.
echo `The home of my home is` `dirname ~` = also works.

exit 0
```

# split, csplit

These are utilities for splitting a file into smaller chunks. Their usual use is for splitting large files in order to back them on floppies or e-mailing or uploading them.

The **split** command splits a file by context, the split occurring where patterns are matched.

Example 16-37. A script that copies itself in sections

```
#!/bin/bash
# splitcopy.sh

# A script that splits itself into chunks,
# then reassembles the chunks into an exact copy
# of the original script.

CHUNKSSIZE=4 # Size of first chunk of split files.
OUTPUTPREFIX="xx" # split prefixes, by default,
# files with "xx" ...

split "$0" "CHUNKSSIZE"

# Some comment lines for padding
# Line 15
# Line 16
# Line 17
# Line 18
# Line 19
```
