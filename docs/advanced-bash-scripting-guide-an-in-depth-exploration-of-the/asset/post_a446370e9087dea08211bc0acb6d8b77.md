# Example 21-2. List User Profiles

```bash
#!/bin/bash
# allprofs.sh: Print all user profiles.

# This script written by Helner Steven, and modified by the document author.

FILE=.bashrc # File containing user profile,
# += ".profile" in original script.

for home in $(awk -F: '{print $6}' /etc/passwd)
do
[ -d "$home" ] || continue # If no home directory, go to next.
[ -r "$home" ] || continue # If not readable, go to next.
(cd $home; -e $FILE) && less $FILE
done

# When script terminates, there is no need to 'cd' back to original directory
# because 'cd $home' takes place in a subshell
```

A subshell may be used to set up "dedicated environment" for a command group.

```bash
COMMAND1
COMMAND2
COMMAND3
(
IFS=
PATH=/bin
unset TERMINFO
set -c
shift 5
COMMAND4
COMMAND5
exit 3 # Only exits the subshell!
)
# The parent shell has not been affected, and the environment is preserved.
COMMAND6
COMMAND7
```

As seen here, the exit command only terminates the subshell in which it is running, not the parent shell or script.

One application of using "dedicated environment" is testing whether a variable is defined.

```bash
if (set -u ; $variable) 2>/dev/null
then
echo "Variable is set."
# Variable has been set in current script,
# or is an internal Bash variable,
# or present in environment (has exported).
```

# Example 21-3. Running parallel processes in subshells

```bash
(cat list1 list2 list3 | sort | uniq > list123) &
(cat list4 list5 list6 | sort | uniq > list456) &
# Merges and sorts both sets of lists simultaneously.
# Running in background ensures parallel execution.
#
# Same effect as
# cat list1 list2 list3 | sort | uniq > list123 &
# cat list4 list5 list6 | sort | uniq > list456 &

wait # Don't execute the next command until subshells finish.

diff list123 list456
```

# Chapter 22. Restricted Shells

Running a script or portion of a script in *restricted mode* disables certain commands that would otherwise available. This is a security measure intended to limit the privileges of the script and minimize potential damage.

The following commands and actions are disabled:

- Using `cd` to change the directory.
- Changing the values of `$PATH`, `$BASH_ENV`, or `$ENV` environmental variables.
- Reading or changing `$SHELLOPTS` options.
- Output redirection.
- Invoking commands containing one or more `/`.
- Invoking `exec` to substitute a different process for the shell.
- Other commands that would enable monkeying with or attempting to subvert the script for getting out of restricted mode.

Example 22-1. Running a script in restricted mode

```bash
#!/bin/bash
# Starting the script with "/bin/bash"
# -r runs entire script in restricted mode.
echo "Changing directory."
cd /usr/local
echo "Now in `pwd`"
echo "Coming back home."
cd
echo "Now in `pwd`"

# Everything up here in normal, unrestricted mode.
set -r has same effect
echo "Now in restricted mode."
echo "Attempting directory in restricted mode."
cd ..
echo "Still in `pwd`"
echo "$SHELL"
```

```bash
SHELL="/bin/bash"
echo
echo "$SHELL"
echo "Attempting output in restricted mode."
ls -l /bin > bin.files
ls -l bin.files # Try to list file creation.
exit 0
```

# Chapter 23. Process Substitution

Piping the stdout into the stdin of another is a powerful technique. But if you need to pipe the stdout of multiple commands? This is where process substitution comes. Process substitution feeds the output of a process (or processes) into the stdin of another.

Command enclosed within parentheses >commandlist

There is no space between "<" or ">" and parentheses. Space would give an error message.

```bash
bash$ echo(true)
bash$ echo(true)
bash$ echo(true) <(true)
```

Bash creates a pipe with file descriptors. The stdin of true connects to stdout, then passes a /dev/fd/ file as argument to echo. On systems lacking /dev/fd/ may use temporary files. (Thanks, S.C.) Process substitution can compare the output of two commands, or even the output of different options to save the command.

```bash
bash comm <(ls -l) <(ls -al)
total 12
-rw-rw-r-- 1 bozo 78 Mar 10 File0
-rw-rw-r-- 1 bozo 42 Mar 10 File2
-rw-rw-r-- 1 bozo 103 Mar 10 t2.sh
total 20
drwxr-x bozo 4096 Mar 10
```

Process subprocess contains the contents of two directories -- to see filenames in the one, but not the other.

diff <(ls $first_directory) <(ls $second_directory)
