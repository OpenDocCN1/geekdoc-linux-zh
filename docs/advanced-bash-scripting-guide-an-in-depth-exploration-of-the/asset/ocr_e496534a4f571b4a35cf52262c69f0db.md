+   - Ctrl-N

Eases a line of text recalled from history buffer [23] (on the command-line).

+   - Ctrl-O

Issues a newline (on the command-line).

+   - Ctrl-P

Recalls last command from history buffer (on the command-line).

+   - Ctrl-Q

Resume (XON).

This resumes stdin in a terminal.

+   - Ctrl-R

Backwards search for text in history buffer (on the command-line).

+   - Ctrl-S

Suspend (XOFF).

This freezes stdin in a terminal. Use Ctrl-Q to restore input.)

+   - Ctrl-T

Reverses the position of the cursor is on with the previous character (on the command-line).

+   - Ctrl-U

Erase a line of input, from the cursor backward to beginning of line. In some settings, Ctrl-U erases the entire line of input, regardless of cursor position.

+   - Ctrl-V

When inputting text, Ctrl-V permits inserting control characters. For example, the following are equivalent:

```
echo -e '\xa0'
echo <Ctrl-V><Ctrl-J>
```

Ctrl-V is primarily useful from within a text editor.

+   - Ctrl-W

When typing on the console or in an xterm window, Ctrl-W erases the character under the cursor backwards to the first instance of whitespace. In some settings, Ctrl-W erases backwards to first non-alphanumeric character.

+   - Ctrl-X

In certain word processing programs, Cuts highlighted text and copies to clipboard.
