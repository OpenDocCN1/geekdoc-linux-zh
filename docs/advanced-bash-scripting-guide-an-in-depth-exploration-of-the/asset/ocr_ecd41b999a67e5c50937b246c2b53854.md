echo

show_help
exit $E_BADARGSRS
fi

# Checks if file exists.
if [ ! -f $FILE ]; then
echo "file \$FILE\" does not exist.\nexit $E_BADARGSRS
fi

# Counts letter occurrences
for n in `seq $LETTERS`; do
shift
if [[ echo -n "$1" | wc -c -eq 1 ]]; then # Checks arg.
echo "$1" ->'cat $FILE | tr -cd "$1" | wc -c ' # Counting.
else
echo "$1 is not a single char."
done
exit $?

Somewhat more capable than **seq** is a classic UNIX utility that is not normally included in a standard Linux distro. However, the source rpm is available for download from the MIT repository.

Unlike **seq jot** can generate a sequence of random numbers, using the `-r` option.

```
bash$ jot -r 3 999
1069
1272
1428
```

The **getopt** command parses command-line options preceded by a **dash**. This external command corresponds to the **getops** builtin. Using **getopt** permits handling long options by means of the -l flag, and this also allows parameter reshaping.
