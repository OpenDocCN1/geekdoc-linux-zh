# 36.10. Shell Scripting Under Windows

Even users using other OS can UNIX-like scripts, and therefore benefit from many of the lessons of this book. The Cygwin package for Cygnus and the MKS utilities from Mortice Kern Associates add scripting capabilities to Windows.

Another alternative is UWIN, written by David Korn of AT&T, of Korn Shell fame.

In 2006, Microsoft released the Windows PowerShell@, which contains limited Bash-command-line scripting capabilities.
