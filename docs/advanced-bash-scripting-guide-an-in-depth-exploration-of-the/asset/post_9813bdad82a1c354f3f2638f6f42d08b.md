# Example 17-2. Setting erase character

```bash
#!/bin/bash
# erase.sh: Using "stty" to set an erase character when reading input.

echo -n "What is your name? " # Try backspace to erase characters of input.
read name
echo "Your name is $name."

stty erase '#' # Set "hashmark" (#) as erase character. Use to erase last character.
echo -n "What is your name?"
# Even after the script exits, the new key value remains set. Exercise: How would you reset the erase character to the default?
```

# Example 17-3. secret password: Turning off echoing

```bash
#!/bin/bash
# secret-pw.sh: secret password

echo -n "Enter password "
read passwd
echo "password is $passwd"
echo -n "If someone had been looking over your shoulder, password would have been compromised."

echo && echo # Two-line feeds in "and list."

stty -echo # Turns off screen. May also be done with stty.
echo -n "Enter password again "
read passwd
echo "password is $passwd"
echo

stty echo # Restores screen.
```

# Example 17-4. Keypress detection

```bash
#!/bin/bash
# keypress.sh: Detect a user keypress ("hot keys")

old_stty=$(stty -g)  # Save old settings (why)? or $(dd bs=1 count=1 > /dev/null) on non-GNU systems.
stty -icanon
Keypress=$(head -c1)
echo "Key pressed \"$Keypress\"" # Restore old settings. Thanks, Stéphane Chazelas.
stty "$old_stty"
exit 0
```

# terminals and modes

Normally, a terminal works in canonical mode. When a user hits a key, the resulting character does not immediately go to the program actually running in this terminal. A buffer local to the terminal stores keystrokes. When the user hits the ENTER key, this sends all the stored keystrokes to the program running. There is even a basic line editor inside the terminal.

```
stty -a speed 9600 rows 36 columns 96 line = 0; intr = \C; quit = \; erase = \H; kill = \U; eof = \R; ecol = \<; endl2 = \<; start = \Q; stop = \Z; susp = \S; rprnt = \R; werase = \W; flush = \O; isig -icanon iext echo echo -opost
```

Using canonical mode, it is possible to redefine the special keys for the terminal line editor.

```bash
bash$ cat filexxxx
cat<Ctrl-L><Ctrl-H>foo bar<Ctrl-U>hello world<ENTER>
<Ctrl-D>
bash$ cat filexxxx
hello
bash$ wc -c < filexxxx
12
```

The process controlling the terminal receives only 12 characters (11 alphabetic, plus a newline), although the user hit 26 keys.

In non-canonical ("raw") mode, every key hit (including special editing keys such as ctrl-H) sends a character immediately to the controlling process.

The Bash prompt disables both and echo, as it replaces the basic terminal editor with its more elaborate mode. For example, when in the Bash prompt, there's no ctrl-A echoed by the terminal, but Bash gets a character, interprets it, and moves the cursor to the beginning of the line.

# seterm

Set certain terminal attributes. This command writes to its terminal's stdout a string that changes the behavior of that terminal.

```bash
bash$ term -cursor off
bash$
```

The seterm command can be used within a script to change the appearance of text written to out, although there are certainly better tools for this purpose.

```bash
seterm -bold on
echo bold hello

seterm -bold off
echo normal hello
```

# tset

Show or initialize terminal settings. This is a lesser version of stty.

```bash
bash$ tset -r

Interrupt is control-C (C).
```

# seterial

Set or display serial port parameters. This command must be run by root and is usually found in system setup script.

```bash
# From /etc/pcmdev/serial script:
IRQ=$(seterial/dev/DEVICE | sed -e 's/.*/IRQ: //')
seterial /dev/DEVICE irq j ; seterial /dev/DEVICE irq q $IRQ
```

# getty

The initialization process for a terminal uses tty or getty to set it up for log for a user. These commands are not used within user shell scripts. Their counterpart is stty.
