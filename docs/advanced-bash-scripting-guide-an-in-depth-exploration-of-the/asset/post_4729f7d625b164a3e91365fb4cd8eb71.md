```bash
file_name=$(stat -cn "$FILENAME") # Same as "$FILENAME" of course.
file_owner=$(stat -cU "$FILENAME")
file_size=$(stat -c "$FILENAME")
# Certainly easier than using 'ls -l "$FILENAME'
# with sed.
file_inode=$(stat -ci "$FILENAME")
file_type=$(stat -cf "$FILENAME")
file_access_rights=$(stat -cA "$FILENAME")
```

```bash
echo "File name: $file_name"
echo "File owner: $file_owner"
echo "File size: $file_size"
echo "File inode: $file_inode"
echo "File type: $file_type"
echo "File access rights: $file_access_rights"
```

uptime

Shows how long the system has been running, along with associated statistics.

```
uptime
10:28pm up 1:57, 3 users, load average: 0.17, 0.34, 0.27
```

> A load average of 1 indicates that the system handles processes immediately. A load greater than 1 means that processes are being queued. When the load averages above 3 (on a single-core processor), system performance significantly degrades.

hostname

Lists the system name. This command sets the host name in /etc/rc.d setup script (/etc/rc.d/rc.sysinit or similar). It is equivalent to hostname -n, and a counterpart to the $HOSTNAME internal variable.

```bash
bash hostname
localhost.localdomain

bash echo $HOSTNAME
localhost.localdomain
```

Similar to the hostname command the domainname, dnsdomainname, nisdomainname, and ypdomainname commands. Use these to display or set the system DNS or NIS/YP domain name. Various options to hostname also perform these functions.

Chapter 17. System and Administrative Commands

hostid
Echo a 32-bit hexadecimal numerical identifier for the host machine.

```bash
bash$ hostid
7f0100
```

This command always fetches a "unique" serial number for a particular system. Certain product registration procedures use this number to brand a particular user license. Unfortunately, hostid only returns the machine network address in hexadecimal, with parts of bytes transposed.

The network address of a typical non-networked Linux machine, is found in /etc/hosts.

```bash
bash$ cat /etc/hosts
hostname.localdomain localhost
127.0.0.1
```

As it happens, translating the address of 127.0.0.1, we get 0F7E0170, the exact equivalent of which translates in hex to 007FE0100. There exists only a few other Linux machines with this identical hostid.

readelf
Show information and statistics about an elf binary. This is part of the binutils package.

```bash
bash$ readelf -h /bin/bash
ELF Header:
Magic: 7f 45 46 46 01 01 00 00 00 00 00 00 00 00
Class: ELF32
Data: 2's complement, little endian
Version: 1 (current)
OS/ABI: UNIX - System V
ABI Version: 0
Type: EXEC (Executable file)
```

size
The size command gives sizes of binary files. This is part of the binutils package.

```bash
bash$ size /bin/bash
text: 94524 data: 2144 section: 22 allocated: 96668
```
