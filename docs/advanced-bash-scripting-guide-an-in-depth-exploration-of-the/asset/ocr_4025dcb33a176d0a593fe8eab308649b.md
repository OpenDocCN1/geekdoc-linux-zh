The od, or octal dump converts inputs (or files to octal-8 or other types). This is useful for viewing or processing binary files or otherwise unreadable system devices files, such as /dev/random, and for a binary data.

```
head -c4 /dev/random | od -An -tu4 | sed -ne 's/\.* //'
# Sample output: 1324527519, 3918166450, 2989231420, etc.
```

A hexadecimal, octal, decimal, or ASCII of a binary file. This command is the rough equivalent of od, but not necessarily useful. It may be used to see the contents of a binary file, in combination with dd and less.

```
dd if=/bin/ls | hexdump -C | less
# The -C option formats the output in tabular form.
```
