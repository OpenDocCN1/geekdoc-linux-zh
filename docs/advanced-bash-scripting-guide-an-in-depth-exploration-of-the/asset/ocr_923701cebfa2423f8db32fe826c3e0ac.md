newgrp

Change user's group ID without logging out. This permission grants access to the group's files. Since may be members of multiple groups simultaneously, this command finds only limited use.

> Kurt Gleassemann points out that the newgrp command could prove helpful in setting the default group permissions for files a user writes. However, the chgrp command might be more convenient for this purpose.
