# Advanced Bash-Scripting Guide

```
#!/bin/bash
PS3='Choose your favorite vegetable: ' # Sets the prompt string;
# Otherwise it defaults to ? .
echo
select vegetable in "beans" "carrots" "potatoes" "onions" "rutabagas"
do
  echo
  echo "Your favorite veggie is $vegetable."
  echo "Yuck!"
  break # What happens if there is no 'break' here?
done
exit
```

If **list** is omitted, **select** uses the list of command line arguments ($@) passed to the script or the function **select** construct.

Compare this to the behavior of a

for **variable**[in **list]

construct with the **in** **list** omitted.

# Example 11-31. Creating menus using **select** in a function

```
#!/bin/bash
PS3='Choose your favorite vegetable: ' 
echo
choice_of() {
  select vegetable
  # in [list] omitted, so 'select' uses arguments passed to function.
  do
    echo
    echo "Your favorite veggie is $vegetable"
    echo "Yuck!"
    break
  done
}
choice_of rice carrots radishes rutabaga spinach
# $1 $2 $3 $4 $5 $6
#   passed to choice_of() function
```
