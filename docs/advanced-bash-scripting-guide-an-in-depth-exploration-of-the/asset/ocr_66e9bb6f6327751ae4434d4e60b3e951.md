Example 16-39. Udecoding encoded files

```
#!/bin/bash
# Udecodes all uencoded files in current working directory.

lines=35
  # Allow 35 lines for the header (very generous).

for File in *
  # Test all the files in $PWD
    search1=$(tail -n $SFile | grep begin | wc -w)
    search2=$(tail -n $SFile | grep end | wc -w)
    # Udecoded files have a "begin" near the beginning,
    # and an "end" near the end.
    if [ "$search1" -gt 0 ];
    then
      if [ "$search2" -gt 0 ];
      then
        echo "udecoding $File-"
        uldecode $File
      fi
    fi
done

# Note that running this script itself fools it
#+ thinking it is a uencoded file,
#+ because it contains both "begin" and "end".

exit 0
```

**mimencode, mmencode**
The mimencode and mmencode commands process multi-encoded e-mail attachments. Although mail user agents (such as pine) normally handle this automatically, these particular utilities permit manipulating such attachments manually from the command-line or in batch processing mode by means of a shell script.
