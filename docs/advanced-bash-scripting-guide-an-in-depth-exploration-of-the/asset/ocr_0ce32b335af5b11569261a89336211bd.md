# Advanced Bash-Scripting Guide

In contrast to certain programming languages, shell scripts normally pass only value parameters to functions. Variable names (which are pointers), if passed as parameters to functions, will be treated as string literals. Functions interpret their arguments literally.

Indirect variable references (see Example 37-2) provide a clumsy sort of mechanism for passing variable pointers to functions.
