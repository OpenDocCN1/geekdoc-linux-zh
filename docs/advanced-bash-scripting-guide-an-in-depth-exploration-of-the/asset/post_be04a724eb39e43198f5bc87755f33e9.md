```bash
  # Accepts parameters.
```

## 37.3.1. Bash, version 4.1

Version 4.1 of Bash, released in May, 2010, primarily a buggy update.

- The printf command accepts a -v option for setting array indices.
- Within double brackets, the `>` and `<` string comparison operators now conform to the locale. Since the locale setting may affect the sorting order of string expressions, this has side-effects on comparison tests within [[ ... ]]
- The read builtin takes a -N option (read -N chars), which causes the read to terminate after chars characters.

Example 37-8. Reading N characters

```bash
#!/bin/bash
# Requires Bash version -ge 4.1 ...
num_chars=61
read -N $num_chars var < $0 # Read first 61 characters of script!
echo "$var"
exit
```

Output of Script:
```bash
#!/bin/bash
# Requires Bash version -ge 4.1 ...
num_chars=61
```

```bash
#!/bin/bash
# here-comsub.sh
```

## 37.3.2. Bash, version 4.2

Version 4.2 of Bash, released in February 2011, contains new features and enhancements in addition to bugfixes.

- Bash now supports `\x` and `\U` Unicode escape a cross-platform standard for encoding into numerical values and graphic symbols. This permits representing and displaying characters in foreign alphabets.

```bash
echo -e '\u2630' # Horizontal bar character.
# Equivalent to more roundabout: Recognized by earlier Bash versions.
echo -e '\u2200' # PI (Greek letter and mathematical symbol)
echo -e '\u0416' # Capital "Z" (Cyrillic letter)
echo -e '\u2708' # Airplane (Dingbat font)
echo -e '\u2622' # Radio trefoil symbol-requires a 100% pull-up resistor.
```

## 37-11. Negative array indices

Negative array indices prevent counting backwards from the end of an array.

```bash
#!/bin/bash
# neg-array.sh
# Requires Bash version -ge 4.2

array=(zero one two four five) # Six-element array.
# 0 1 2 3 4 5
# -6 -5 -4 -3 -2 -1

# Negative array now permitted.
echo ${array[-1]} # five
echo ${array[-2]} # four
echo ${array[-6]} # zero
# Negative array indices count backward from the last element+1.
echo ${array[-7]} # array: bad subscript
```

But, you cannot index past the beginning of the array.

```bash
echo ${array[-7]} # array: bad subscript
```

So, what is this new feature for?

```bash
echo The last element in the array is ${array[-1]}
# Which is quite a bit more straightforward than:
echo The last element in the array is ${array[$#{array[*]}-1]}
```

```bash
index=0
let neg_element_count = 0 - ${#array[*]}
# Number of elements, converted to a negative number.

while [ $index -gt $neg_element_count ]; do
  ((index--)); echo -n "${array[index]}"
  # Lists the elements in the array, backwards.
  # We have simulated the "tac" command on the array.
```

- See also neg-offset.sh. Extraction uses a negative length parameter to specify an offset from the end of the string.
