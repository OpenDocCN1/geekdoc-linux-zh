# Advanced Bash-Scripting Guide

hostid
Echo a 32-bit hexadecimal numerical identifier for the host machine.

```
bash$ hostid
7f0100
```

This command always fetches a "unique" serial number for a particular system. Certain product registration procedures use this number to brand a particular user license. Unfortunately, hostid only returns the machine network address in hexadecimal, with parts of bytes transposed.

The network address of a typical non-networked Linux machine, is found in
/etc/hosts.

```
bash$ cat /etc/hosts
hostname.localdomain localhost
127.0.0.1
```

As it happens, translating the address of 127.0.0.1, we get 0F7E0170, the exact equivalent of which translates in hex to 007FE0100. There exists only a few other Linux machines with this identical hostid.

readelf
Show information and statistics about an elf binary. This is part of the binutils package.

```
bash$ readelf -h /bin/bash
ELF Header:
Magic: 7f 45 46 46 01 01 00 00 00 00 00 00 00 00
Class: ELF32
Data: 2's complement, little endian
Version: 1 (current)
OS/ABI: UNIX - System V
ABI Version: 0
Type: EXEC (Executable file)
```
