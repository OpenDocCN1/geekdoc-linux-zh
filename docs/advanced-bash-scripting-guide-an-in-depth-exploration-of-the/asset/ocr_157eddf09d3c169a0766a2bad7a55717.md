# Advanced Bash-Scripting Guide

The process controlling the terminal receives only 12 characters (11 alphabetic, plus a newline),
alough the user hit 26 keys.

In non-canonical ("raw") mode, every key hit (including special editing keys such as ctl-H) sends ancharacter immediately to the controlling process.

The Bash prompt disables both Changes and echo, as it replaces the basic terminal editor with its
more elaborate mode. For example, when in the Bash prompt, there's no ctl-A A echoed by
the terminal, but Bash gets a l character, interprets it, and moves the cursor to the beginning of the line.

# seterm

Set certain terminal attributes. This command writes to its terminal's stdout a string that changeshe behavior of that terminal.

```
bash$ term -cursor off
bash$
```

The seterm command can be used within a script to change the appearance of text written to
out, although there are certainly better tools for this purpose.

```
seterm -bold on
echo bold hello

seterm -bold off
echo normal hello
```

# tset

Show or initialize terminal settings. This is a lesser version of stty.

```
bash$ tset -r
Terminal type is xterm-xfree86.
Kill is control-U (U).
Interrupt is control-C (C).
```

# seterial

Set or display serial port parameters. This command must be run by root and is usually found in
system setup script.

```
# From /etc/pcmdev/serial script:
IRQ=$(seterial/dev/DEVICE | sed -e 's/.*/IRQ: //'
seterial /dev/DEVICE irq j ; seterial /dev/DEVICE irq q $IRQ
```

# getty

The initialization process for a terminal uses tty or getty to set it up for log for a user. These
commands are not used within user shell scripts. Their counterpart is stty.
