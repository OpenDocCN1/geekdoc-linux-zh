The position and length arguments can be "parameterized," that is, represented as a variable, rather than a numerical constant.

# Example 10-2. Generating an 8-character "random" string

```
#!/bin/bash
# rand-string.sh
# Generating an 8-character "random" string.

if [ -n "$1" ]                                # If command-line argument present
then
    # then set start-string to it.
    str0="$1"
else\                                         # Use PID of script as start-string.
    str0=\$
fi

POS=2 # Starting from position 2 in the string.
LEN=8 # Extract eight characters.

str1=$(echo "$str0" | md5sum)
# Doubly scramble
# by piping and repiping to md5sum.

randstring="${str1:$POS:$LEN}"
# Can parameterize

echo "$randstring"
```

```
exit $?

bozo ./rand-string.sh my-password
ldbb88c4

# No, this is not recommended
# as a method of generating hack-proof passwords.
```

If the $string parameter is """ or "@", then this extracts a maximum of $length position parameters, starting at $position.

```
echo ${*:2}                                     # Echoes second and following positional parameters.
echo ${@}                                          # Same as above.

echo ${*:2:3}                                     # Echoes three positional parameters, starting at second.
```
