free shows memory and cache usage in tabular form. The output of this command leads to parsing, using grep, awk or Perl. The procinfo command shows all information that is free, and much more.

| | total used free shared buffers cached |
| Mem: | 30504 | 28624 | 15820 | 1608 | 16376 |
| +/- buffers/cache: | 10640 | 19864 | | |
| Swap: | 68540 | 3128 | 65412 | |

To show used RAM memory:

```
bash free | grep Mem | awk '{ print $4 }'
1880
```

procinfo Extract list and information statistics from the /proc pseudo-filesystem. This gives a very extensive and detailed listing.

```
bash procinfo | grep Bootup
Bootup: Wed Mar 21 15:15:50 2001 Load average: 0.04 0.21 0.34 3/47 6829
```
