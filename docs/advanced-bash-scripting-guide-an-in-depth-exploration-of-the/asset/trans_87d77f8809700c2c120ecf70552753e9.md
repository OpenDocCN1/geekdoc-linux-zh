

# 高级 Bash 脚本指南

- ${parameter-default}

${parameter:-default}

${parameter=default}

- ${parameter:-default} 设置默认参数
-${parameter+alt_value}

${parameter+alt_value}
如果参数已设置，则的替代值

- ${!var}
变量的间接引用，新语法

- ${!#}
 最后一个位置参数。（这是对 $# 的间接引用）

- ${!varprefix*}

${varprefix@}
匹配所有以 varprefix 开头的已声明变量名

- ${string:position}

${string:position:length} 提取子字符串

- ${var#Pattern}

${var##Pattern} 移除子字符串头部

- ${var%%Pattern}

${var %% Pattern} 移除子字符串后缀

- ${string:substring/replacement}

${string#substring/replacement}

${string/%substring/replacement} 子字符串替换

$'...' 字符串扩展，使用转义字符。

\Escape the character following 转义其其后的字符

- \<...> 转义的角括号，正则表达式中的单词边界
- \{N\} 转义的“花括号”，扩展正则中匹配的字符集数量
- \: 转义的分号，终止查找命令
- \$$ 变量的间接引用，旧式语法
- 转义换行符，用于编写多行命令
