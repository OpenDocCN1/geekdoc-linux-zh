# Appendix J. An Introduction to Programmable Completion

The programmable completion feature in Bash permits typing a partial command, then pressing the [Tab] to auto-complete the command sequence. If multiple completions are possible, then [Tab] lists them all. Let's see how it works.

```
bash$ xtra[Tab]
xtaceroute xtrapin xtrapproto
xtstraceroute.real xtrapinfo xtrapreset
xtracparchar xtrapout xtrapstats

bash$ xtra[Tab]
xaceroute          xtaceroute.real

bash$ xtaceroute.r[Tab]
xaceroute.real
```

Tab completion also works for variables and path names.

```
bash$ echo $BASH[Tab]
$BASH $BASH_COMPLETION $BASH_SUBSHELL
$BASH_ARGC $BASH_COMPLETION_DIR $BASH_VERSIONINFO
$BASH_ARGV $BASH_LINENO $BASH_VERSION
$BASH_COMMAND $BASH_SOURCE
```

The Bash and compgen makes it possible for tab completion to recognize partial parameters and options to commands. In a very simple case, we can use complete from the command-line to specify a short list of acceptable parameters.

```
bash$ touch sample_command
bash$ touch file1.txt file2.txt file2.doc file30.txt file4.zzz
bash$ chmod +X *sample_command
bash$ complete -f *.txt sample_command

bash$ ./sample[Tab] [Tab]
sample_command
file1.txt file2.txt file3.txt
```

The -f option to complete filenames, and -X filter patterns.

For anything more complex, we could write a script that specifies a list of acceptable commandline parameters. The compgen expands a list of arguments to generate completion matches.
