# 7.5. Testing Your Knowledge of Tests

The systemwide xinitrc can be used to launch the X server. This file contains a number of if/then tests.

```
if -f $HOME/.Xclients ]; then
  exec $HOME/.Xclients
elif -f /etc/X11/init/Xclients ]; then
  exec /etc/X11/init/Xclients
else
  # failsafe settings. Although we should never get here
  # (we provide fallbacks in Xclients as well) it can't hurt.
  xclock -geometry 100x100+5 & 
  xterm -geometry 80x50-50+150 & 
  if [ -f /usr/bin/netscape /usr/share/doc/HTML/index.html ]; then
    netscape /usr/share/doc/HTML/index.html &
```
