Though this might seem obscure and feared data duplicator command originated for exchanging data on magnetic tapes within UNIX minicomputers and IBM mainframes, it still has its uses. The dd command simply copies a file (or stdin/stdout), but with conversions. Possible conversions include ASCII/EBCDIC uppercase, swapping of byte pairs between input and output, and skipping/or truncating the head or tail of the file.

> Converting a file to all uppercase:

```
dd if=$file conv=ucase > $filename.uppercase
case # For lower case conversion
```

Some basic options to dd are:

- if=INFILE: INFILE is the source file.
- of=OUTFILE: OUTFILE is the target file, the file that will have the data written to it.
- bs=BLOCKSIZE: This is the size of each block of data being read and written, usually a power of 2.
- skip=BLOCKS: How many blocks of data to skip in INFILE before starting to copy. This is useful when the INFILE has "garbage" or garbled data in its header or when it is desirable to copy only the portion of the INFILE.
- seek=BLOCKS: How many blocks of data to skip in OUTFILE before starting to copy, leaving blank data at.
- count=BLOCKS: Copy only this many blocks of data, rather than the entire INFILE.
- conv=VERSION: Type of conversion to be applied to INFILE data before copying operation.

A dd --help lists all options this powerful utility takes.

## Example 16-57. A script that copies itself

```bash
#!/bin/bash
# self-copy.sh

# This script copies itself.
file_subscript=copy
diff $0=$0.file_subscript 2>/dev/null
# Suppress messages from dd: ****

exit $?

# A program whose only output is its own source code
# is called a "quine" by Willard Quine.

```

## Example 16-58. Exercising dd

```bash
#!/bin/bash
# exercising-dd.sh

# Script by Stephane Chazelas.
# Somewhat modified by ABS Guide author.

infile=$0          # This script.
out=log.txt      # Output file left behind.
n=8
p=11

dd if=$outfile bs=1 skip=$((n-1)) count=$((p-n+1)) 2>/dev/null
# Extracts characters n to p (8 to 11) from this script "bash"
#
echo -n "hello vertical world" | dd bs=1 conv=unblock 2>/dev/null
# Echoes "hello vertical world" vertically downward.
# Why? A newline follows each character dd emits.

exit $?
```

The dd can do random access to a data stream.

```bash
echo -n . | dd bs=1 seek=4 of=file conv=notrunc
# The "conv=notrunc" option means that the output file
# not be truncated.
```

The dd can copy raw data and images to devices, such as floppies and drives (A-5). A common use is creating bootable floppies.

```bash
dd if=kernel-image of=/dev/fd01440
```

Similarly, dd can copy the entire contents of a floppy, even formatted with a "foreign" OS, to the hard drive as an image file.

```bash
dd if=/dev/fd0 of=/home/bozo/projects/floppy.img
```

Likewise, dd can create bootable flash drives and SD cards.

```bash
dd if=image.iso of=/dev/sdb
```

# Preparing an SD card with a bootable image for the Raspberry Pi.

```bash
# $1 = imagefile name
# $2 = sdcard (device file)
# Otherwise defaults to the defaults, see below.

DEFAULTsize=4M
DEFAULTcard="2013-07-26-weezy-raspberry.img"
DEFAULTsdcard="/dev/mmcblk0"
ROOTUSER_name=root
E_NOTROOT=1
E_NOIMAGE=82

username=$($id -nu)                # Who is running this script?
if [ "$username" != "$ROOTUSER_name" ];
then
    echo "This script must run as root or with root privileges."
    exit $E_NOTROOT
fi

if [ -n "$1" ];
then
    imagefile="$1"
else
    imagefile="$DEFAULTsize"
fi

if [ -n "$2" ];
then
    sdcard="$2"
else
    sdcard="$DEFAULTsdcard"
fi

if [ ! -e $imagefile ];
then
    echo "Image $imagefile" not found!"
fi
```
