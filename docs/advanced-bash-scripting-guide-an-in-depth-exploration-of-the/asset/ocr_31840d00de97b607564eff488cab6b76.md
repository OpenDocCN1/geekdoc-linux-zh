# line in a shell script will be the first thing the command interpreter (sh or bash) sees. Since this line begins with a #, it will be correctly interpreted as a comment when the command interpreter executes the script. The line has served its purpose - calling the command interpreter

If, in the script contains an extra *#!* line, then **bash** will interpret it as a comment.

```
#!/bin/bash
echo "Part 1 of script."
a=1

#!/bin/bash
# This does *not* launch a new script.

echo "Part 2 of script."
echo $a Value of $a stays at 1.
```

This allows some cute tricks.

```
#!/bin/rm
# Self-deleting script.

# Nothing seems to happen when you run this... except that the file disappears.

WHATEVER=85
echo "this line will never print (betcha!)."
exit WHATEVER # Doesn't matter. The script will not exit here.
# Try an echo $? after script termination.
# You'll get a 0, not 85.
```
