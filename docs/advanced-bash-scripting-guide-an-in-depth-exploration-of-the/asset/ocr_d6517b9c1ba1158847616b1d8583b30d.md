# Advanced Bash-Scripting Guide

| > (COMMAND) | Process substitution |
| < (COMMAND) | Process substitution |

| (( var-- )) | C-style variable decrement |
| (( var0 = var<98?:21 )) | C-style ternary operation |

| "Variable" | "Weak" quoting |
