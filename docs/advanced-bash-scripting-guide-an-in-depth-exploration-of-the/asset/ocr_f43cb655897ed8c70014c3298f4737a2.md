> There have been that the 128-bit md5sum can be cracked, so the secure 160-bit sha1sum is a welcome addition to the checksum toolkit.

```
bash md5sum testfile
e1812ec872c60522c4c4c981108e367 testfile
nbash sha1sum testfile
d5f725a9c0866317ff31286fa40986ffc996 testfile
```

Security concerns have demonstrated that sha1sum can be compromised. Furthermore, newly Linux distros include longer bit-length sha224sum, sha256sum, sha384sum, and sha512sum commands.

encode
This utility encodes binary files (images, sound, compressed files, etc.) into ASCII characters, making them suitable for transmission in the body of an e-mail message or in a newsgroup posting. This is especially useful when MIME (multimedia) encoding is not available.

uodecode
This reverses the encoding, decoding uencoded files back into the original binaries.
