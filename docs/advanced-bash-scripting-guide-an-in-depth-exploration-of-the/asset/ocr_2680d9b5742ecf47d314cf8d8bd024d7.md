A filter for feeding arguments to a command, and also a tool for assembling the commands themselves. It breaks a data stream into small enough chunks for filters and commands to process. Consider it a powerful replacement for backquotes. In situations where command substitution fails with a too many arguments error, substituting xargs for others. [73] Normally, xargs from stdin or from a pipe, it can also be given the output of a file.

The default command for xargs is echo. This means input piped to xargs may have linefeeds and other whitespace characters stripped out.

```
ls -l
total 0
-rw-rw-r-- 1 bozo bozo 0 Jan 29 23:58 file1
-rw-rw-r-- 1 bozo bozo 0 Jan 29 23:58 file2
```

```
ls -l | xargs 1 bozo bozo 0 Jan 29 23:58 file1 -rw-rw-r-- 1 bozo bozo 0 Jan...
```

```
bash find -type f | xargs grep "Linux"
./misc:User-Agent: slrn/0.9.8.1 (Linux)
/./sent-mail-jul-2005: hosted by the Linux Documentation Project.
./sent-mail-jul-2005: (Linux Documentation Project Site, rtf version)
/./sent-mail-jul-2005: Subject: Criticism of Bozo's Windows/Linux article
./sent-mail-jul-2005: while mentioning the Linux ext2/ext3 filesystem
..
```

ls | xargs -p -1 gzip gz every file in a current directory, one at a time, prompting each operation.

```
bash find /usr/bin | xargs file
/usr/bin: directory
/usr/bin/foomatic-ppd-options: perl script text executable
..
```

+   Note xargs processes the arguments passed to it sequentially, one at a time.

+   An interesting xargs option is -n NN, which limits to NN the number of arguments passed.

ls | xargs -n 8 echo the files in the current directory or 8 columns.

+   Another useful option is -0, allows handling arguments containing whitespace or quotes.

```
find -type f -print0 | xargs grep -print0 -liwZ GUI | xargs -0 rm -f
```
