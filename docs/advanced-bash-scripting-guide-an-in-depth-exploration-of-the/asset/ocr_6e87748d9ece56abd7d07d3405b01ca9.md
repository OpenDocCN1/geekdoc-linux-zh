# Appendix M. Sample .bashrc and .bash profile Files

~/.bashrc file determines behavior of interactive shells. A good look at this file can lead to a better understanding of Bash.

Emmanuel Rouat contributed the very elaborate .bashrc file, written for a Linux system. He welcomes reader feedback on it.

Study the file carefully, and feel free to reuse code snippets and functions from your own .bashrc file or in your scripts.

# Example M-1. Sample .bashrc file

```
################################################################################
# PERSONAL $HOME/.bashrc FILE for bash-3.0 (or later)
# By Emmanuel Rouat [no-email]
################################################################################
# Last modified: Tue Nov 20 22:04:47 CET 2012
################################################################################
# This file is normally read by interactive shells only.
# Here is the place to define your aliases, functions and
# other interactive features like your prompt.
################################################################################

# system (most likely a Linux box) and is often based on code

# http://www.caliban.org/bash
# http://www.sheldorado.com/scripts/categories.html
# http://www.dotfiles.org
################################################################################
# The choice of colors was done for a shell with a dark background

################################################################################
# This bashrc file is a bit overcrowded.
# Remember, it is just an example.
```
