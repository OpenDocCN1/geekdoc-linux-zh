# Advanced Bash-Scripting Guide

```
(a=hello; echo $a)
```

A listing of commands within parentheses starts a subshell.

Variables inside parentheses, the subshell, are not visible to the rest of the script. The parent process, the script, cannot read variables created in the child process. the subshell.

```
a=123
( a=321 );
echo "a = $a" # a = 123
# "a" within parentheses acts like a local variable.
```

# Brace expansion

```
echo "{These,word,are,quoted}" # " prefix and suffix
# "These "words" are "quoted"
```

```
cat {file1,file2,file3} > combined_file
# Concatenates the files file1, file2, and file3 into combined_file
```

```
cp file22.{txt,backup} "file22.backup"
# Copies "file22.txt" to "file22.backup"
```

A command may act with a comma-separated list of files within braces. [20] Filename expansion (globbing) applies to the file specs within the braces.

No spaces allowed within braces unless the spaces are escaped.

```
echo {file1,file2\}: \"A,\"B\",\ 'C'
```

# Extended expansion [a..z]

```
echo [a..z] # a b c d e f g h i j k l m n o p q r s t v w x y z
# Echoes characters between a and z.
```

```
echo (0..3) # 0 1 2 3
# Echoes characters between 0 and 3.
```

```
base64-char={A..Z} {a..z} {0..9} + =
# Initializing an array using extended brace expansion.
# From vlad's "base64.sh" example script.
```
