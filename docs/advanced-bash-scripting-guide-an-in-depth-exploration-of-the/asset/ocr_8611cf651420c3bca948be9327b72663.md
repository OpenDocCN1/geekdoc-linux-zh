Filenames beginning with "-" may cause problems when coupled with the "-" redirection operator. A script should check this and add an appropriate prefix to such filenames, for example . ./-FILENAME, $PWD/-FILENAME, or $PATHNAME/-FILENAME.

If the value of a variable begins with a -, this may create problems.

```
var="-n"
echo $var
# Has the effect of "echo -n", and outputs nothing.
```

In a different context, the "=" is a string comparison operator.

Plus. Addition arithmetic operator.

In a different context, the + is a Regular Expression operator.

Option. Option flag for a command or filter.

Certain commands and builtins use the + to enable options and the - to disable them. By parameter substitution, the + prefixes with alternate value a variable expands to.

modulo. Modulo (remainder of a division) arithmetic operation.
