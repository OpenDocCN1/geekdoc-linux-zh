### Will echo passed parameters only if DEBUG is set to a value. ###
debecho () {
  if [ ! -z "$DEBUG" ]; then
    echo "$1" >&2
  fi
}

3. Setting option flags -n -v -x

sh scriptname checks for errors without actually running the script. This is the equivalent of inserting set -n or set -o noexec into the script. Certain types of syntax errors can slip past this check.

sh -v scriptname echoes each command before executing it. This is the equivalent of inserting set -v or set -o verbose in the script.

The -n and -v flags work together. sh -nv scriptname gives a verbose syntax check.

sh -x scriptname echoes the result of each command, but in an abbreviated manner. This is the equivalent of inserting set -x or set -o xtrace in the script.

Inserting set -u or set -o nounset in the script runs, but gives an unbound variable message and aborts the script.
