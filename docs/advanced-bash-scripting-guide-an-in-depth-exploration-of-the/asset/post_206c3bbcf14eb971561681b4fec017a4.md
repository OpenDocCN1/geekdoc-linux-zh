The simplest, and perhaps most useful ANSI escape sequence is, \033[1m ... \033[0m. The \033 represents escape, the \[1\] turns on the bold attribute, while the \[0\] switches it off. The \[m\] terminates each term of the escape sequence.

```bash
bash$ echo -e "\033[1mThis is bold text.\033[0m"
```

A similar escape sequence switches on the underline attribute (on an rxvt and an aterm).

```bash
bash$ echo -e "\033[4mThis is underlined text.\033[0m"
```

With an echo, the -e option enables the escape sequences.
Other sequences change the text and background color.

```bash
bash$ echo -e '\E[34;47mThis prints in blue.'; tput sgr0
```

```bash
bash$ echo -e '\E[33;44myellow text on blue background'; tput sgr0
```

```bash
bash$ echo -e '\E[1;33;44mBOLD yellow text on blue background'; tput sgr0
```

It's usually advisable to set the bold attribute for light-colored foreground text.
The tput sgr0 restores the terminal settings to normal. Omitting this lets all subsequent output from that particular terminal blue.
Since tput sgr0 fails to restore terminal settings under certain circumstances, echo -ne \E[0m may be a better choice.

The following template for writing colored text on a colored background.
echo -e '\E[COLOR1;COLOR2m text goes here. '

The \[E\] begins the escape sequence. The semicolon-separated numbers "COLOR1" and "COLOR2" specify a foreground and a background color, according to the table below (The order of the numbers does not matter, since the foreground and background fall in non-overlapping ranges.) The \[m\] terminates the escape sequence, and the text begins immediately after that.

Note that single quotes enclose the remainder of the command sequence following the echo -e.

# Example 36-15. Echoing colored text

```bash
#!/bin/bash
# color-echo.sh: Echoing text messages in color.

# Modify this script for your own purposes.
# It's easier than hand-coding color.

black='\E[30;47m'
red='\E[31;47m'
green='\E[32;47m'
yellow='\E[33;47m'
blue='\E[34;47m'
magenta='\E[35;47m'
cyan='\E[36;47m'
white='\E[37;47m'
```

```bash
alias Reset="tput sgr0"
# Wait, looking at the image text again:
alias Reset="tput sgr0" # Reset text attributes to normal
  # without clearing screen.

cecho () {
  # Color-echo.
  # Argument $1 = message
  # Argument $2 = color
  local default_msg="No message passed."
  # Doesn't really need to be a local variable.

  message=${1:-$default_msg} # Defaults to default message.
  color=${2:-$black} # Defaults to black, if not specified.

  echo -e "$color"
  echo "$message" # Reset to normal.

  return
}
```

```bash
# This function moves the cursor to line $1 column $2 and prints $3.
# E.g.: "move_and_echo 5 10 linux" is equivalent to
# "tput cup 4 9; echo linux", but with one command of two.
# Note: "tput cup defines 0 0 the upper left angle of the terminal.
# echo defines 1 1 the upper left angle of the terminal.
move_and_echo() {
  echo -ne "\E[$1];${2}H" "$3"
}
```

```bash
# Function to generate a pseudo-random number between 1 and 9.
random_1_9() {
  head -c10 /dev/random | md5sum | tr -d [a-z] | tr -d 0 | cut -c1
}
```
