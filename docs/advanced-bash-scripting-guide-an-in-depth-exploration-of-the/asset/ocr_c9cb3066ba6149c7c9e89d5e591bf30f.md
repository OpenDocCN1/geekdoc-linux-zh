# Advanced Bash-Scripting Guide

The join command operates on exactly two files, pastes together those lines with a common tagged field (usually a numerical label), and writes the result to stdout. The files to be joined should be sorted by the tagged field for the matchups to work properly.

```
File: 1.data

100 Shoes
200 Laces
300 Socks
```

```
File: 2.data

100 $40.00
200 $1.00
300 $2.00
```

```
bash$ join 1.data 2.data
File: 1.data 2.data

100 Shoes $40.00
200 Laces $1.00
300 Socks $2.00
```

> The tagged field appears only in the output.

# Example 16-13. Which files are scripts?

```
#!/bin/bash
# script-detector.sh: Detects scripts within a directory.

TESTCHARS=2      # Test first 2 characters.
SHABANG='!'      # Scripts begin with a "sha-bang."

for file in *\  # Traverse all files in the current directory.
d
  if [[ $(head -c$TESTCHARS "$file") == "$SHABANG" ]]; then
    head -c2                                     #!
    # The '-c' option to "head" outputs a specified
    # number of characters, rather than lines (the default),
    then
    echo "\$file" is a script."
  else
    echo "\$file" is *not* a script."
  fi
done
```
