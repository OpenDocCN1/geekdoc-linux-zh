# Advanced Bash-Scripting Guide

```
echo "-\-"
```

```
echo "Assigning a random number to a simple variable:
time for (( i=0; i < $count; i++)); do
    simple=$RANDOM
done
```

```
echo "-\-"
```

```
echo "Assigning a sparse numeric index array randomly into 64k cells:
time for (( i=0; i < $count; i++)); do
    array3[$RANDOM]=$i
done
```

```
echo "-\-\"
```

```
echo "Reading sparse numeric index array entry:
time for value in "\${array3[@]}"; do
    simple=$value
done
```
