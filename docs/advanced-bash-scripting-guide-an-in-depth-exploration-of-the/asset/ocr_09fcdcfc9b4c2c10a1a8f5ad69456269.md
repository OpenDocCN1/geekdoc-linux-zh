The relationship of $${array_name[@]} and $${array_name[*]} is analogous to between $@ and $$. This powerful array notation has a number of uses.

```
# Copying an array.
array2="${array1[@]}"
#
array2="${array1[@]}"
#
However, this fails with "sparse" arrays,
# arrays with holes (missing elements) in them,
# As Jochen DeMeets points out.
#
array1()=0
array1[1] not assigned
array1[2]=2
array2="${array1[@]}"   # Copy it?

echo ${array2[0]}           #
echo ${array2[2]}
#                           (null), should be
```

```
# Adding an element to an array.
array=(\${array1[@]}" "new element"
#
array[$*]="new element"
```

#!/bin/bash
