traceroute

Trace the route taken by packets to a remote home. This command works in a LAN, WAN, or over the Internet. The remote host may be specified by an IP address. The output of this command may be filtered by grep or sed in a pipe.

```
bash traceroute 81.9.6.2
traceroute to1 (81.9.6.2), 30 hops, 39 packets
1 toac3.jhnnbrb.com (136.30.178.1) 191.503 ms 179.400 ms 179.767 ms
2 oro.jhnnbrb.com (136.30.178.1) 179.536 ms 179.534 ms 169.685 ms
3 192.168.11.101 (192.168.11.101) 189.471 ms 189.556 ms *
```

ping

Broadcast an ICMP_REQUEST packet to a matcher, either on a local or remote network. This is a useful tool for testing connections, and it should be used with caution.

```
bash ping localhost
PING localhost.localdomain (127.0.0.1) from 127.0.0.1 : 56:(84) bytes of data
64 bytes from localhost.localdomain (127.0.0.1) : icmp_seq=0 ttl=255 time=709 use
64 bytes from localhost.localdomain (127.0.0.1) : icmp_seq=1 ttl=255 time=286 use
-
--- localhost.localdomain ping statistics
2 packets transmitted, 2 received, 0% packet loss
round-trip min/avg/max/mdev = 0.286/0.497/0.709/0.212 ms
```

A successful ping returns an exit status of 0. This is tested for a script.

```
HNAME=news-15.net # Notorious spammer.
HNAME=$HOST # Debug: test for localhost.
count=2 # Send only two pings.

if [ "ping -c $count "$HNAME" ];
then
  echo "$HNAME" up and broadcasting your way.
else
  echo "$HNAME" seems to be Down.
fi
```

whois

Perform a DNS (Domain Name System) lookup. The -h option permits specifying particular
whois server to query. See Example 4-6 and Example 16-40.

finger

Retrieve information about a network. This command can display a user's
~/.project, and ~/.forward files, if present.

```
bash finger
Login Name Tty Idle Login Time Office Phone Phone
bozo Bozo Bozeman tty1 8 Jun 25 16:59 (:0.0)
bozo Bozo Bozeman tty0 Jun 25 16:59 (:0.0)
bozo Bozo Bozeman tty1 Jun 25 17:07 (:0.0)
```
