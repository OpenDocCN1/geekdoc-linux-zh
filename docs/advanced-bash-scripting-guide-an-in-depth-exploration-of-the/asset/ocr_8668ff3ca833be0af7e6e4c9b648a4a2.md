# Chapter 25. Aliases

A Bash alias is essentially nothing more than a keyboard shortcut, an abbreviation, a means of avoiding typing a long command sequence. If, for example, we include alias lm='ls -l | more' in the ~/.bashrc file, each lm [116] at the command-line will automatically be replaced by a ls -l | more. This can save a great deal of typing at the command-line and avoid having to remember complex combinations of commands and options. Setting alias rm='rm -i' (interactive mode delete) may save you a good of grief, since it can prevent inadvertently deleting files.

In a script, aliases have very limited usefulness. It would be nice if aliases could some the functionality of the C preprocessor, as macro expansion, but unfortunately Bash does not expand arguments within the alias body. [117] Moreover, a script fails to expand an alias within "compound constructs," such as if/then statements, loops, and functions. An added limitation is that an alias will expand recursively. Almost invariably, whatever we would like an alias to could be accomplished more effectively with a function.

# Example 25-1. Aliases within a script

```
#!/bin/bash
# alias.sh

shop -s expand_aliases
# Must set this option, script will not expand aliases

# First, some fun.
alias Jesse_James='echo "\alias Jesse James\" was a 1952 comedy starring Bob Hope.'
Jesse_James

echo; echo;

alias ll="ls -l"
# May use either single (\') or double ("") quotes to define an alias.
echo "Trying alias \"ll\":"
ll /usr/X11R6/bin/mk* # Alias works.

echo
directory=/usr/X11R6/bin/
prefix=* # See if wild card causes problems.
echo "Variables \"directory\" + "\prefix\" = $directory$prefix"
echo

alias ll="ls -l $directory$prefix"
echo Trying alias \"ll\":"
l11 # Long listing of all files in /usr/X11R6/bin stating with mk.
# An alias can handle concatenated variables -- including wild card -- o.k.

TRUE=1
```
