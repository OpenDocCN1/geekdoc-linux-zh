# Example 11-28. Simple string matching

```bash
#!/bin/bash
# match-string.sh: Simple string matching
# using a 'case' construct.

match_string () {
  # Exact string match.
  MATCH=0
  E_NOMATCH=90
  PARAMS=2    # Function requires 2 arguments.
  E_BAD_PARAMS=91

  if [ -eq $PARAMS ] || return $E_BAD_PARAMS

  case "$1" in
    "$2") return $MATCH;
    *) return $E_NOMATCH;
  esac
}

a=one
b=two
c=three
d=two

match_string $a      # wrong number of parameters
echo $?               # 91

match_string $a $b   # no match
echo $?               # 90

match_string $b $d   # match
echo $?               # 0

exit 0
```

```bash
# isalpha.sh: Using a "case" structure to filter a string.

SUCCESS=0
FAILURE=-1
  # Was FAILURE=-,
  # but Bash no longer allows negative return value.

isalpha () {
  # Tests whether *first character* of input string is alphabetic.
  if [ -z "$1" ]; then
    # No argument passed?
    return $FAILURE
  fi
  case "$1" in
    [a-zA-Z]*) return $SUCCESS;; # Begins with a letter?
    *) return $FAILURE;
  esac
}
# Compare with "isalpha()" function in C.
isalpha2 () {
  # Tests whether "entire string" is alphabetic.
  [ $ -eq 1 ] || return $FAILURE

  case $1 in
    *[!a-zA-Z]*\*) return $FAILURE;
    *) return $SUCCESS;
  esac
}
disdigit () {
  # Tests whether "entire string" is numerical.
  # In other order, tests for integer variable.
  [ $ -eq 1 ] || return $FAILURE

  case $1 in
    *[!0-9]*\*) return $FAILURE;
    *) return $SUCCESS;
  esac
}
```

```bash
check_var () {
  if isalpha "$0"; then
    echo "\$0*" begins with an alpha character.
    if isalpha2 "$0"; then
      # No point in testing if first char is non-alpha.
      echo "\$0*" contains only alpha characters.
    else
      echo "\$0*" contains at least one non-alpha character.
    fi
  else
    echo "\$0*" begins with a non-alpha character.
    # Also "non-alpha" if no argument passed.
  fi
}

echo

digit_check ()  # Front-end to isdigit ()

  then
    echo "\$*" contains only digits [0 - 9].
  else

  fi
  echo

The select construct, adopted from the Korn Shell, is yet another tool for building menus.

select variable [in list]

```bash
do
  command...
  break
done
```

This prompts the user to enter one of the choices presented in the variable list. Note that select uses $PS3$ [corrected from $PS1] prompt ( ? ) by default, but this may be changed.

Example 11-30. Creating menus using select

```bash
#!/bin/bash
PS3='Choose your favorite vegetable: ' # Sets the prompt string;
# Otherwise it defaults to ? .

  echo "Yuck!"
  break # What happens if no 'break' here?

# Chapter 12. Command Substitution

Command substitution reigns the output of a command. The classic form of command substitution uses backticks (`` ` ``). Commands within backticks (`` ` `` generate command-line text.

```bash
script_name=$(basename $0)
echo "The name of this script is $script_name."
```

The output of the command can be used as arguments to another command, to set a variable, and even when generating the list in for.

```bash
text_listing=$(ls *.txt)
# Variable contains names of all *.txt files in current directory.
echo $text_listing
```

A possible problem with putting a list of files into a single string is that a newline may creep in. A safer way to assign a list of files to a parameter is with an array.

```bash
text_listing=(*.txt) # The alternative form of command substitution.
# Same result.
shopt -s nullglob # If no match, filename expands to nothing.
```

Command substitution invokes a subshell. Command substitution may result in word splitting.

```bash
echo a b # 2 args: a and b
echo a b # 1 arg: "a b"
echo # no arg
echo "" # one empty arg
```

Even when there is no word splitting, command substitution can remove trailing newlines.

```bash
cd "pwd" # This should always work.
# However....
```

```bash
mkdir 'dir' with trailing newline
cd 'dir' with trailing newline
cd "pwd" # Error message: bash: cd /tmp/file with trailing newline: No such file or directory

```

```bash
old_tty_setting=$(tty -g) # Save old terminal setting.
echo "Hit a key"
stty -icanon -echo # Disable "canonical" mode for terminal.
# Also, disable "local" echo.
key=$(dd bs=1 count=2 /dev/null) # Using 'dd' to get a keypress.
stty "$old_tty_setting" # Restore old setting.
echo "You hit $key key." # ${#variable} = number of characters in $variable

# Hit any key RETURN, and the output is "You hit 1 key."
# Hit RETURN, and it's "You hit 0 key."
# The newline gets eaten in the command substitution.
Code snippet by Stéphane Chazelas.
```

Using echo to output an unquoted variable with command substitution removes newline characters from the output of the reassigned command. This can cause unpleasant surprises.

```bash
dir_listing=ls -l
echo $dir_listing # unquoted
# Expecting a nicely ordered directory listing.
# However, what you get is:
# total 3-rw-rw-rw 1 bozo 30 May 13 17:15 1.txt
# -rw-rw-rw- 1 bozo 51 May 19 20:57 t2.sh -rwxr-xr-x 1 bozo 217 Mar 5 21:13 wi.sh
# The newlines are disappeared.
```bash
echo "$dir_listing" # quoted
# -rw-rw-r-- 1 bozo 30 May 13 17:15 1.txt
# -rw-rw-r-- 1 bozo 51 May 19 20:57 t2.sh
# -rwxr-xr-x 1 bozo 217 Mar 5 21:13 wi.sh
```
