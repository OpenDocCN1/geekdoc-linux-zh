Example 11-16. Another while loop

```
!/bin/bash
echo                              # Equivalent to:
while [ "$varl" != "end" ]  # while test "$varl" != "end"
do
    echo "Input variable #1 (end to exit)"
    read varl                             # Not read 'varl' (why?).
    echo "variable #1 = $varl"      # Needs quotes because of "#"
    # If input is not 'end', echoes it here.
    # Does not test for termination condition until top of loop.
    echo
done
exit 0
```

A while loop may have multiple conditions. Only the final condition determines when the loop
 terminates. This necessitates a slightly different loop syntax, however.

Example 11-17. while loop with multiple conditions

```
!/bin/bash
varl=unset
previous=$varl

while echo "previous-variable = $previous"
    previous=$varl
    [ "$varl" != end ] # Keeps track what $varl was previously.
    # Four conditions on "while", but only the final one controls the loop.
    # The "last" exit status is the one that counts.
    echo "Input variable #1 (end to exit)"
    read varl
    echo "variable #1 = $varl"
done

# Try to figure out how this all works.
# It's a wee bit tricky.
exit 0
```
