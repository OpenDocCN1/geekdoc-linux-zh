```bash# Escape characters:
# To localize a sentence like
# echo -e "Hello\tworld!"
# you must use:
# echo -e "\gettext\\Hello\\tworld\"
# The "double escape character" before the 't' is needed because
# 'gettext' will search for a string like: 'Hello\t'
# This is because gettext will read one literal \'
# and will output a string like "Bonjour\ monde"
# so the 'echo' command will display the message correctly.
```

```bash
# You may not use
# echo -e "\Hello\\tworld!"
# due to the gettext bug explained.
```

```bash
# Let's localize the following shell fragment:
# echo -h display help and exit

# First, one could do this:
# echo "-gettext -h display help and exit"
# This way 'xgettext' will work ok,
# but the 'gettext' program will read "-h" as option!
```

```bash
# One solution could be
# echo "-gettext \-h display help and exit"
# This way 'gettext' will work,
# but 'xgettext' will extract "-", as referred to above.
```

```bash
# The workaround you may use to get this string is localized
# echo "-gettext \0-h display help and exit"
# We have added a \ (NULL) at the beginning of the sentence.
# This way 'gettext' works correctly, as does 'xgettext'.
# Moreover, the NULL character won't change the behavior
# so of the 'echo' command.
```

Now, build a language.po file for each language that the script will be translated into, specifying the msgstr. Alfredo Pironti gives the following example:

fr.po:

```po
# a:6
msgid "Can't cd to $var."
msgstr "Impossible de se positionner dans le repertoire $var."
# a:7
msgid "Enter the value: "
msgstr "Entrez la valeur : "

# The string is dumped with the variable names, not with the %s syntax,
# similar to C programs.
# This is a very cool feature if the programmer uses
# variable names that make sense!
```

Then, run msgfmt.

`msgfmt -o localized.sh fr po`

Placing the localized.sh file in the /usr/local/share/locale/fr/LC_MESSAGES directory, and at the beginning of the script, insert the lines:

```bash
TEXTDOMAIN=/usr/local/share/locale
TEXTDOMAIN-localized.sh
```

If a user on a French system runs the script, she will get French messages.

> With older versions of Bash or other shells, localization requires gettext, using the -s option. In this case, the script breaks:

```bash
#!/bin/bash
# localized.sh

_CDERROR=65

error() {
  local format=$1
  shift
  printf "$(gettext -s $format) "$@" >&2
  exit $E_CDERROR
}

cd var "Can't cd to %s." "$var"
read -p "$(gettext -s "Enter the value: ")"" var
```

The TEXTDOMAIN and TEXTDOMAIN variables must be set and exported to the environment. This should be done within the script itself.

# Appendix L. History Commands

The Bash shell provides command-line tools for editing and manipulating user's history. This is primarily a convenience means of saving keystrokes.

Bash commands:

- 1. history
- 2. cd
- 3. ls

Internal variables associated with Bash commands:

- 1. $HISTCMD
- 2. $HISTCONTROL
- 3. $HISTIGNORE
- 4. $HISTFILE
- 5. $HISTSIZE
- 6. $HISTTIME
- 7. $HISTFORMAT (Bash, 3.0 or later)
- 8. !!
- 9. !
- 10. !#
- 11. !N
- 12. !-N
- 13. !STRING
- 14. !?STRING
- 15. ^STRING^

Unfortunately, Bash history tools no use in scripting.

```bash
#!/bin/bash
# history.sh
# A (naive) attempt to use 'history' command in a script.

history
# No output.

var=$(history); echo "$var" is empty.

# History commands are, by default disabled within a script.
# However, as Haible points out, set -o history enables history mechanism.

```bash
set -o history
var=$(history); echo "$var"
```

```bash
bash ./history.sh
```

# This works for me - your mileage may vary. ...

```bash
function get_xserver() {
    case $TERM in
        xterm)
            XSERVER=$(who am i | awk '{print $NF}' | tr -d '"\'')
            # Anne-Pier Weringa suggests the following alternative:
            _IAM=${_IAM_$(who am i)}
            SERVER=${SERVER%%*}
            XSERVER=${XSERVER%%*}
            ;;
        aterm | rxvt)
            # Find some code that works. ...
            ;;
    esac
}
```

```bash
if [ -z ${DISPLAY:="} ]; then
    get_xserver
    if [[ -z ${XSERVER} ]] || [ ${XSERVER} == "$(hostname)" ]; then
        if [ ${XSERVER} == "unix" ]; then
            DISPLAY=${DISPLAY}:.0 # Display on local host.
        else
            DISPLAY=${XSERVER}:0  # Display on remote host.
        fi
    fi
fi
```
