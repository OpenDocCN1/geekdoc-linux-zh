A keyword is a reserved word, token or operator. Keywords have a special meaning to the shell, and indeed are the building blocks of the shell's syntax. Examples as, for, while, do, and ! are keywords. Similar to a builtin, a keyword is hard-coded in bash, but unlike a builtin, a keyword is not in itself a command, or subunit of a command construct. # I/O

echo

prints (to stdout) an expression or variable (see Example 4-1).

```
echo Hello
echo $a
```

An echo requires the -e option to print escaped characters. See Example 5-2.

Normally, each echo command produces a terminal newline, but the -n option suppresses this.

An echo can be used to feed a sequence of commands down pipe.

```
if echo "$VAR" | grep -q txt # if [[ $VAR = "*txt*" ]\nthen
echo "$VAR contains the substring sequence \"txt\""
fi
```

An echo, in command substitution can set a variable.

```
a=`echo "HELLO" | tr A-Z a-z`
```

See Example 16-22, Example 16-3, Example 16-47, and Example 16-48.
Be aware that echo command deletes newlines from the output of command generates.

The IFS (internal field separator) normally contains \n (linefeed) as one of its
whitespaces, so bash splits the output of command linefeeds into arguments to
echo. echo outputs these arguments, separated by spaces.

| bash -ls /usr/share/apps/kjezz/sounds | | |
| -rw-r--r-- | root | root | 1407 Nov 7 2000 reflect.au |
| -rw-r--r-- | | | 362 Nov 7 2000 seconds.au |

```
bash $echo -ls /usr/share/apps/kjezz/sounds`$
total 40 -rw-r--r-- 1 root root 716 Nov 7 2000 reflect.au -rw-r--r-- 1 root root ...
```

So, how can we embed a linefeed within an echoed character string?

```
# Embedding a linefeed
echo "Why doesn't this string \n split on two lines?"
# Doesn't split.
```
