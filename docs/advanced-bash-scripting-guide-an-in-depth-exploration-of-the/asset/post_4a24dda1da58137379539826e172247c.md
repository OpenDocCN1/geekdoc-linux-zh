```bash
# This script models Brownian motion:
# the random windings of tiny particles in a fluid,
# as they are buffeted by random currents and collisions.
# This is colloquially known as the "Drunkard's Walk."

# It can also be considered as stripped-down simulation of a
# Galton Board, a slanted board with a pattern of pegs,
# which down rolls a succession of marbles, one at a time.
# At the bottom is a row of slots or catches in which
# the marbles come to rest at the end of their journey.
# Think of it as a kind of Rain-bones Pachinko game.
# As seen by running the script,
# most of marbles cluster around the center slot.
# This is consistent with the expected binomial distribution.
# As a Galton Board simulation, the script
# displays such parameters as
# tilt-angle, rolling friction of the marbles,
# angles of impact, and elasticity of the pegs.
# To what extent does this affect the accuracy of the simulation?
```

```bash
PASSES=500 # Number of particle interactions / marbles.
ROWS=10 # Number of "collisions" (or horiz. peg rows).
RANGE=3 # 0 - 2 output range from $RANDOM.
POS=0 # Left/right position.
# Seed random number generator from PID
RANDOM=$ # of script.
```

```bash
Show_Slots () {
    echo; echo
    echo -n " $(seq $NUMSLOTS) # Pretty-print array elements.
    for i in $(seq $NUMSLOTS); do
        printf "%3d" "${Slots[$i]}" # Allot three spaces per result.
    done
    echo # Row of slots:
    echo "__________________________________________"
    echo "__________________________________________"
    echo # Note if the count within any particular slot exceeds 99,
    # it misses up the display.
    # Running only (!) 500 passes usually avoids this.
}

Move () {
    Move=$RANDOM # Move right / left, or stay put.
    Move=$%RANDOM # How random is $RANDOM? Well, let's see
    let Move=$RANGE # Normalize range of 0 - 2.
    case "$Move" in
        0) # Do nothing, i.e., stay in place.
        1) ((--POS)); # Left.
        2) ((POS)); # Right.
        *) echo -n "Error"; # Anomaly! (Should never occur.)
    esac
}

Play () \ { # Single pass (inner loop).
    i=0
    while [ "$i" -lt "$ROWS" ]; do # One event per row.
        Move
        ((i++));
    done

    SHIFT=11
    let POS += $SHIFT # Why 11, and not 10?
    # Shift "zero position" to center.
    (( Slots[$SPOS])); # DEBUG: echo $SPOS
    echo -n "$SPOS"
}

Run () \ { # Outer loop.
    p=0
    while [ "$p" -lt "$PASSES" ]; do
        Play
        ((p++));
        POS=0 # Reset to zero. Why?
    done
}
```

Jipe points out a set of techniques for generating random numbers within a range.

```bash
# Generate random number between 6 and 30.
rnumber=$((RANDOM%25+6))

# Generate random number in the same 6 - 30 range,
# plus the number must be evenly divisible by 3.
rnumber=$((RANDOM%30/3+1))

# Note that this will not work all the time.
# It fails if $RANDOM30 returns 0.
```

Frank Wang suggests the following alternative:
`rnumber=$((RANDOM%27/3*3+6))`
Bill Gradwohl came with an improved formula that works for positive numbers.
`rnumber=$((RANDOM*(max-min+divisibleBy)/divisibleBy+min))`
