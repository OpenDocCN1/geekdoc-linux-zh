# Advanced Bash-Scripting Guide

With certain commands and utilities, such as echo sed, escaping a character may have the opposite effect - it can toggle a special meaning for that character.

# Special meanings of certain escaped characters

used with echo and sed

+   \n means newline
\r means return
\t means tab
\v means vertical tab
\b means backspace
\a alert (beep or flash)

translates the octal ASCII equivalent of Oct, where nn is a string of digits

# Example 5-2. Escaped Characters

```
#!/bin/bash
# escaped.sh: escaped characters

################################################################
### First, let's show some basic escaped-character usage. ###
################################################################################

# Escaping a newline.
# ---------------
echo ""

echo "This will print
as two lines."
# This will print
as as two lines."

echo "This will print \
as as one line."
# This will print as one line.

echo; echo
echo "==================="

echo "\v\v\v\v"      # Prints \v\v\v literally.
# Use the -o option with 'echo' to print escaped characters.
```
