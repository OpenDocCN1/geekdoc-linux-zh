# Chapter 17. System and Administrative Commands

The startup and shutdown scripts in /etc/rc.d illustrate the uses (and usefulness) of many of these commands. These are usually invoked by root and used for system maintenance or emergency filesystem repairs. Use with caution, as some of these commands may damage your system if misused.

# Users and Groups

users

Show all logged on users. This is the approximate equivalent of who -q.

groups

Lists the current user and the groups she belongs to. This corresponds to the $GROUPS internal variable, but give group names, rather than the number.

```
bash$ groups
bozita cdrom writer audio xgrnp

bash$ echo $GROUPS
501
```

# chown, chgrp

chown command changes the ownership of a file or files. This command is a useful method that root can shift file ownership from one user to another. An ordinary user may not change the ownership of files, not even her own. [88]

```
root# chown bozo *.txt
```

chgrp command changes the group ownership of a file or files. You must be owner of the file(s) as well as a member of the destination group (or root) to use this operation.

```
chgrp --recursive dunderheads *.data
# The "dunderheads" group will now include all the "*.data" files
#+ all the way down the PWD directory tree (that's what "recursive" means)
```

# useradd, usdel

useradd administrative command adds a user to the system and creates a home directory for that particular user, if specified. The corresponding usdel command removes a user account from the system [89] and deletes associated files.

> The adduser is a synonym for useradd and is a symbolic link to it.

# usermod

Modify a user account. Changes may be made to the password, group membership, expiration date, and other attributes of a user's account. With this command, a user's password may be locked, which has the effect of disabling the account.

# groupmod

Modify a group. The group name and/or ID number may be changed using this command.

# id

The id command lists the real and effective user IDs and group IDs of the user associated with the current process. This is the counterart to the UID, SEID, and GROUPS internal Variables.

```
bash$ id
uid=501 (bozo) gid=501 (bozo) groups=501,22 (cdrom),80 (cdwriter),81 (audio)
```
