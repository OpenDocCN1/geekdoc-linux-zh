Following a shift, the $@ holds remaining command-line parameters, lacking the previous $1,
which was lost.

```
#!/bin/bash
# Invoke with .scriptname 1 2 3 4 5
echo "$0"    # 1 2 3 4 5
shift
echo "$0"    # 2 3 4 5
shift
echo "$0"    # 3 4 5
```

# Each "shift" then loses parameter $1.
# "$@" then contains the remaining parameters.
The $@ special parameter uses as a tool for filtering input into shell scripts. The cat "$@"
construction accepts input to a script either from stdin or from files given as parameters to the
script. See Example 16-24 and Example 16-25.
