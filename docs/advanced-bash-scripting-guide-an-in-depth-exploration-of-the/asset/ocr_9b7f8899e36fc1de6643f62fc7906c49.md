The--color (or --colour) option marks the matching string in color (on the console or in xterm window). Since grep prints out each entire line containing the matching pattern, this lets you see exactly what is being matched. See also the -o option, which shows only the matching portion of the line(s).

# Example 16-Printing from the Lines in stored e-mail messages

```
#!/bin/bash
# from.sh

# Emulates the useful 'from' utility in Solaris, BSD, etc.
# Echoes the "From" header line in all messages
# in your email-directory.

MAILDDIR=/mail/* # No quoting of variable. Why?
# Maybe check if exists $MAILDDIR if [ -d $MAILDDIR ] ; .
GREP_OPTS="-H -5 --color" # Show file, plus extra context lines
# and display "From" in color.
TARGET="From" # "From" at beginning of line.

for file in $MAILDDIR # No quoting of variable.
do
  grep $GREP_OPTS "$TARGET" "$file"
  # Again, do not quote this variable.
echo
done
exit $?
```
