a=0

The break command may optionally take a parameter. A plain break terminates the innermost loop in which it is embedded, but a break N breaks out of N levels of loop.

Example 11-22. Breaking out of multiple loop levels

```
#!/bin/bash
# break-levels.sh: Breaking out of loops.

# "break N" breaks out of N level loops.

for outerloop in 1 2 3 4 5
do
    echo -n "Group outerloop: ""

    for innerloop in 1 2 3 4 5
do
        echo -n "$innerloop "

        if [ "$innerloop" -eq 3 ]
then
            break 2 # Try to see what happens # "Breaks" out of both inner and outer loops.
        fi
done
```
