Often set in the .bashrc or /etc/profile files, these variables control collation order in filename expansion and pattern matching. LC_COLLATE can cause unexpected results in filename globbing.

As version 2.05 of Bash, filename glob no longer distinguishes between lowercase and uppercase letters in a character range. For example, ls [A-M] would match File1.txt and file.txt. To revert to the customary behavior of matching, set LC_COLLATE to C by export LC_COLLATE=C in /etc/profile and/or ~/.bashrc.

$PATH Path to binaries, usually /usr/bin/, /usr/X1R6/bin/, /usr/local/bin/, etc. When a command is called, the shell automatically does a hash search on the directories listed in the path. The path is stored in the environmental variable, PATH, a list of directories. Normally, the system uses $PATH definition in /etc/profile and/or ~/.bashrc (Appendix H).

```
bash$ $PATH
/bin:/usr/bin:/usr/local/bin:/usr/X1R6/bin:/sbin:/usr/sbin
```

PATH=$PATH :/opt/bin appends the /opt/bin directory to the current path. It may be expedient to temporarily add a directory to the path in way. When the script exits, it restores the original $PATH (a child process, as a script, may not change the environment of the parent process, the shell).
