## Q. Download and Mirror Sites

The latest update of this document, as an archived tarball including both the SGML source and rendered HTML, may be downloaded from the author's home site. A pdf version is also available (mirror site). There is likewise an epub version, courtesy of Craig Barnes and Michael Satke, to keep track of major updates, user comments, and popularity ratings. The legacy hosting site for this document is the Linux Documentation Project, which maintains many other Guides as well. Many thanks to Ronny Bang for donating space to host this project.
