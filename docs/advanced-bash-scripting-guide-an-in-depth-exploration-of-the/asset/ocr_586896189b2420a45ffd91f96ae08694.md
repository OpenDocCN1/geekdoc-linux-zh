+   - Is-greater-than

- Redirection
  > Redirect stdout to a file
  >> Redirect stdout to a file, append
  i>&& Redirect file descriptor to file descriptor j
  >&j Redirect stdout to file descriptor j
  >&2 Redirect stdout of a command to stderr
  2>&1 Redirect stderr to stdout
  && Redirect both stdout and stderr of a command to file

:= file Truncate file to zero length

| Pipe, device for passing the output of a command to another command or to the shell

|| Logical OR test operator
