

## 删除不需要的文件

还记得本章开头关于保持巢穴整洁的那些话吗？好吧，现在是时候擦亮你的大扫除工具，给你的主文件夹做一次全面检查了。

第一站是废纸篓。有时我会惊讶于这里积累了多少东西；我可以连续几周都不清空它。幸运的是，这种垃圾没有现实世界对应物那种令人不快的气味，所以唯一阻碍你的是快速检查一下，确保你没有不小心扔掉任何东西。点击底部面板上的废纸篓图标，窗口打开后，点击清空废纸篓以删除其中的所有文件。它们将被永久删除，无法恢复。

接下来是更复杂一点的东西。如果你硬盘空间不足，想知道原因（或者只是想随便看看你的文件），请选择应用程序 ▸ 附件 ▸ 磁盘使用分析器。窗口出现后，点击扫描主目录，然后等待片刻，系统会计算你的文件夹大小。会出现一个彩色环形图表，并附带一个列表，显示你的硬盘空间都被消耗在哪里。将鼠标悬停在图表上的某个彩色区域上，即可查看占用最多空间的内容，或双击其中一个以放大特定文件夹。之后，就看你自己来清除硬盘占用大户了：在左侧列表中点击一个文件夹，然后选择移至废纸篓以删除它。

## 项目 7：创建和解压压缩文件

既然我一直在谈论文件存储，似乎很合适在本章结尾教你如何创建和解压压缩文件。在 Windows 世界中，这些通常被称为 Zip 文件，而在 Linux 世界中，操作名称是 tarball。Linux 这个名字，如果你想知道的话，来自于用于创建此类文件归档的应用程序 Tar。压缩归档有两个优点：它们让你可以将大量文件捆绑到一个方便的包中，而且还能压缩所有文件，使其在硬盘上占用的空间更少。如果你曾经尝试通过电子邮件向某人发送一堆文件，你就知道这有多有用。

无论如何，为了掌握一些实践操作，你将创建一个适用于 Windows/Linux/Mac 的 Zip 文件，然后将其解压。你可以通过打开一个 Nautilus 窗口并创建几个虚拟文件来开始操作。方法是进入 Nautilus 文件菜单并选择创建文档 ▸ 空文件。一个新文件将出现在 Nautilus 窗口中，其名称处于高亮状态。你可以为文件输入名称，例如我使用的：dogwood。现在重复该过程创建第二个文件。我将把它命名为 violet。你的也可以用同样富有表现力的名字。

现在你有了两个文件，可以按照以下步骤创建压缩归档：

- 1. 选择两个文件，可以通过在文件旁边点击鼠标然后拖动光标（鼠标按钮仍按住）覆盖两个文件直到它们被高亮，或按住 CTRL 键并逐个点击每个文件。
- 2. 一旦两个文件都被高亮，右键单击其中一个，然后从弹出菜单中选择压缩。
- 3. 在随后出现的压缩窗口中，在文件名文本框中输入 blossoms，然后从该框右侧的下拉菜单按钮中选择 .zip。一旦一切看起来像我在图 7-23 中设置的那样，点击创建按钮，之后你的两个文件的压缩归档（blossoms.zip）将出现在你的主文件夹中。
