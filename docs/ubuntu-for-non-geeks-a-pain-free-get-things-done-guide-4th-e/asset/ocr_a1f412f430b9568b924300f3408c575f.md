# 9C-4: Moving the Briscola Folder to a Global Location

You could move the briscola folder to the LocalApps folder and play it from there, as you did with pWings, but this time around, let’s do things a bit differently by moving the whole thing to global territory. This not only keeps it safe from any obsessive housekeeping tendencies but also allows all users on the same computer to play the game. You will need to use the sudo command to do this so that you can have write access in those protected folders.

To do this, just type the following command in the Terminal window, and press ENTER:

```
sudo mv briscola /usr/share/games
```

When you are prompted for your password, type it, and press ENTER.
