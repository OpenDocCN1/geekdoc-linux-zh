In this case, you can simply close the INSTALL file, because it prescribes the same steps I’ve listed next. However, in the future, when you install other programs from source, you will need to follow the instructions in the INSTALL files that come with the source files. However, most INSTALL files, the instructions will match the process I am about to describe.

Of course, it may well happen that you take a look at the contents of the INSTALL file and start wondering what alien tongue it is written in. In cases when you have no idea what the INSTALL file is going on about, just look for a *configure* file in the package folder. If you find one, you should be able to follow the instructions in this project.

The configure script checks what files, compilers, and other things it needs, and then it searches your computer to see whether those things are there and, if so, where.
