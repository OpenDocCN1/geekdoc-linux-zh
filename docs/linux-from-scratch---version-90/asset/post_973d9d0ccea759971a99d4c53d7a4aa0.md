## 1.4 Resources

### 1.4.1. FAQ

If during the building of the LFS system you encounter any errors, have any questions, or think there is a typo in the book, please start by consulting the Frequently Asked Questions (FAQ) that is located at http://www.linuxscratch.org/faq/.

### 1.4.2. Mailing Lists

The linuxfromscratch.org server hosts a number of mailing lists used for the development of the LFS project. These lists include the main development and support lists.

### 1.4.3. IRC

Several members of the LFS community offer assistance on Relay Chat (IRC). You can find the IRC network at irc.reenode.net. The support channel is #LFS-support.

### 1.4.4. Mirror Sites

The LFS project has a number of world-wide mirrors to make accessing the website and downloading the required packages more convenient. Please visit the LFS website at http://www.linuxscratch.org/mirrors.html.

### 1.4.5. Contact Information

Please direct all your questions and comments to one of the LFS mailing lists.

## 1.5. Help

If an issue or a question is encountered while working through this book, please check the FAQ page at http://www.linuxscratch.org/faq#general. Questions are often answered there. If your question is not answered on this page, try to find the source of the problem. The hint will give you some guidance for troubleshooting: http://www.linuxscratch.org/hints/downloads/files.txt.

We also have a wonderful LFS community that is willing to offer assistance through the mailing lists and IRC (see the 1.4, "Resources" section of this book). However, we get several questions every day and many of them can be answered by going to the FAQ and by searching the mailing lists. So, for us to get the best assistance possible, you do some research on your first. That allows us to focus on the more unusual needs. If your searches do not produce a solution, please include all relevant information (mentioned below) in your request for help.

### 1.5.1. Things to Mention

- The version of the book used (in this case 9.0)
- The host distribution and version used to create LFS
- The output from the Host System Requirements script
- The package or section the problem was encountered in
- The exact error message or symptom being received
- Note whether you have deviated from the book at all

### 1.5.2. Configure Script Problems

If something went wrong running the configure script, review the config.log file. This file may contain errors encountered during configure which were not printed to the screen. Include the relevant lines if you need to ask for help.
