# Linux From Scratch - Version 9.0

lslogins

Lists information about users, groups and system accounts

lsmem

Lists the ranges of available memory with their online status

lsns

Lists namespaces

mcookie

Generates magic cookies (128-bit random hexadecimal numbers) for xauth

mesg

Controls whether users can send messages to the current user's terminal

mkfs

Builds a file system on a device (usually a hard disk partition)

mkfs.bfs

Creates a Santa Cruz Operations (SCO) bfs file system

mkfs.cramfs

Creates a cramfs file system

mkfs.minix

Initializes the device file or to be used as a swap area

mkswap

A filter for paging through one screen at a time

more

Attaches the file system on the device to a specific directory in the file-system tree

mountpoint

Checks if the directory is a mountpoint

namei

Shows the symbolic links in the given pathname

nsenter

Runs a program with namespaces of other processes

partx

Tells the kernel about the presence and numbering of on-disk partitions

pivot_root

Makes the given file system the root file system of the current process

prlimit

Get and set a process' resource limits

raw

Bind a Linux character device to a block device

readprofile

Reads kernel profiling information

rename

Renames the given file, replacing a given string with another

renice

Alters the priority of running processes

resizpart

Asks the kernel to resize a partition

rev

Reverses the lines of a given file

rkill

Tool for enabling and disabling wireless devices

rtcwake

Used to enter a system sleep state until wakeup time

script

Makes a typescript of a terminal session

scriptreplay

Plays back typescripts using timing information

setarch

Changes reported architecture in a new program environment and sets personality flags

setsid

Runs the given program in a new session

setterm

Sets terminal attributes

sfdisk

A disk partition table manipulator

sulgin

Allows root to log; it is normally invoked by init when the system goes into single user mode

swaplabel

Allows to change swaparea UUID and label

swapoff

Disables devices and files for paging and swapping

swapon

Enables devices and files for paging and swapping and lists the devices and files currently in use
