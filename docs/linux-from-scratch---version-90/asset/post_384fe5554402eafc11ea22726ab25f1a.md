
## 6.19. MPC-1.1.0

The MPC package contains a library for the arithmetic of complex numbers with arbitrarily high precision and correct rounding of the result.

**Approximate build time:** 0.3 SBU
**Required disk space:** 22 MB

### 6.19.1. Installation of MPC

Prepare MPC for compilation:

```
./configure --prefix=/usr \
--disable-static \
--dodecdir=/usr/share/doc/mpc-1.1.0
```

Compile the package and generate the HTML documentation:

```
make
make html
```

To test the results, issue:

```
make check
```

Install the package and its documentation:

```
make install
make install-html
```

### 6.19.2. Contents of MPC

**Installed Libraries:** libmpc.so
**Installed Directory:** /usr/share/doc/mpc-1.1.0

- **libmpc** Contains complex math functions

## 6.20. Shadow-4.7

The Shadow package contains programs for handling passwords in a secure way.

**Approximate build time:** 0.2 SBU
Required disk space: 46 MB

### 6.20.1. Installation of Shadow

> If you would like to enforce the use of strong passwords, refer to http://www.linuxfromscratch.org/blfs/view/9.0posts/cracklib.html for installing CrackLib prior to building Shadow. Then add --with-libcrack to the configure command below.

Disable the installation of the **groups** program and its man, as Coreutils provide a better version. Prevent the installation of manual pages that were already installed in Section 6.8, "Man-pages-5.02":

```
sed -i 's/groups$(EXEEXT)/' src/Makefile.in
find man -name Makefile.in -exec sed -i 's/groups/.1 /' - {} \;
find man -name Makefile.in -exec sed -i 's/getpasswd/.3 /' - {} \;
find man -name Makefile.in -exec sed -i 's/password/.5 /' - {} \;
```

Instead of using the crypt method, use the more secure SHA-512 method of password encryption, which allows passwords longer than 8 characters. It is also necessary to change the obsolete /var/pool/mail location for user mailboxes that Shadow uses by default to the /var/spool/mail/ location used currently:

```
sed -i 's@#ENCRYPT_METHOD DES@ENCRYPT_METHOD SHA512@' '\'
-e 's@/var/spool/mail/@ /' etc/login.defs
```

> If you choose to build Shadow with Cracklib support, run the following:

```
sed -i 's/@DICTPATH.*@$DICTPATH@t/lib/cracklib/pw_dict@' etc/login.defs
```

Make a change to make the first group number generated by useradd 1000:

```
sed -i 's/1000/999/' etc/useradd
```

Prepare Shadow for compilation:

```
./configure --sysconfdir=/ --with-group-name-max-length=32
```

The meaning of the configure option:

```
--with-group-name-max-length=32
```

The maximum user name is 32 characters. The maximum group name is too.

Compile the package:

```
make
```

Linux From Scratch - Version 9.0

This package does not come with a test suite.

Install the package:

```
make install
```

Move a misplaced program to its proper location:

```
mv -v /usr/bin/passwd /bin
```

## 6.20. Configuring Shadow

This package contains utilities to add, modify, and delete users and groups; set and change their passwords; and perform other administrative tasks. For a full explanation of what password shadowing means, see the doc/HOWTO file within the unpacked source tree. If Shadow support, keep in mind that programs which need to verify passwords (display managers, FTP programs, pop3 daemons, etc.) must be Shadow-compliant. That is, they need to be able to work with shadowed passwords.

To enable passwords, run the following command:

```
pwconv
```

To enable shadowed group passwords, run:

```
grpconv
```

Shadow's configuration for the useradd utility has a few caveats that need explanation. The first default action for the useradd utility is to create the user and a group of the same name as the user. By default the user ID (UID) and group ID (GID) numbers will be 1000. This means if you don't pass parameters to useradd, each user will be a member of unique group on the system. If this behavior is undesirable, you will need to pass the -g parameter to useradd. The default parameters are stored in the /etc/default/useradd file. You may need to modify two parameters in this file to suit your particular needs.

/etc/default/useradd Parameter Explanations

```
GROUP=1000
```

This parameter sets the beginning of the numbers used in the /etc/group file. You can modify it however you desire. Note that useradd will never reuse a UID or GID. The number identified in this parameter is used, it will use the next available number after this. Note also if you don't have a group of 1000 on your system the first time you use useradd without the -g parameter, you'll get a message displayed on the terminal that: useradd: unknown GID 1000. You may disregard this and group number 1000.

```
CREATE_MAIL_S=yes
```

This parameter causes useradd to create a mailbox file for the newly created user. useradd will make the group ownership of this file to the mail group with 0660 permissions. If you would prefer that these mailbox files are not created by useradd, use the following command:

```
sed -i 's/yes/no/' /etc/default/useradd
```

## 6.20.3. Setting the root password

Choose a password for root user and set it by running:

```
passwd root
```

# Short Descriptions

- **chage**: Used to change the maximum number of days between changes
- **chfn**: Used to change a user's full name and other information
- **chpassword**: Used to update group passwords in batch mode
- **chpasswd**: Used to update user passwords in batch mode
- **chsh**: Used to change a user's default shell
- **expiry**: Checks and enforces the current password expiration
- **faillog**: Used to examine the log of logins, to set a maximum number of failures before an account is blocked
- **gpassword**: Used to add and delete members to groups
- **groupadd**: Creates a group with the given name
- **groupdel**: Deletes the group with the given name
- **groupmems**: Allows a user to administer/her group membership
- **groupmod**: Is used to modify the group name or ID
- **grpck**: Verifies the integrity of the group files /etc/group and /etc/shadow
- **grpcnv**: Creates or updates the shadow file from the normal password file
- **grpunv**: Updates /etc/group from /etc/shadow and deletes the latter
- **lastlog**: Reports the most recent login of all users or a given user
- **login**: Is used by the system to let users sign on
- **logout**: Is a daemon to enforce restrictions on log-on time and ports
- **newgidmap**: Is used to set the gid mapping of a user namespace
- **newgrp**: Is used to change the current GID during a login session
- **newuidmap**: Is used to set the uid mapping of a user namespace
- **news**: Is used to create or update an series of users accounts
- **nologin**: Displays a message that an account is not available; it is designed to be the default shell for accounts that have been disabled
- **passwd**: Is used to change the password for a user or group account
- **pwck**: Verifies the integrity of the password files /etc/passwd and /etc/shadow
- **pwconv**: Creates or updates the shadow password file from the normal password file
- **su**: Runs a shell with substitute user and group IDs
- **useradd**: Creates a new user with the given name, or updates the default new-user information
- **userdel**: Deletes the given user account
- **usermod**: Is used to modify the given user's login name, User Identification (UID), shell, initial group, home directory, etc.
- **vigr**: Edits the /etc/group or /etc/gshadow files
- **vipw**: Edits the /etc/passwd or /etc/shadow
