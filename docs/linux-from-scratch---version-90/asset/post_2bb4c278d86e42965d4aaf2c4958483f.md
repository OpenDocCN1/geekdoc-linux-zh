## 6.55. Check-0.12.0

Check is a unit testing framework for C.
Approximate build time: 0.1 SBU (about 3.7 SBU with tests)
Required disk space: 12 MB

### 6.55.1. Installation of Check

Prepare Check for compilation:

```bash
./configure --prefix=/usr
```

Build the package:

```bash
make
```

Compilation is now complete. To run the Check test suite, issue the following command:

```bash
make check
```

Note that the Check test suite may take a relatively long (up to 4 SBU) time.
Install the package and fix a script:

```bash
make docdir=/usr/share/doc/check-0.12.0 install
sed -i '1 s/$tools/usr/' /usr/bin/checkmk
```

### 6.55.2. Contents of Check

Installed program: checkmk
Installed library: libcheck.{a,so}

#### Short Descriptions

- checkmk: Awk script for generating C unit tests for use with the Check unit testing framework libcheck.{a,so} Contains functions that allow Check to be called from a test program

## 6.58. Findutils-4.6

The Findutils package contains programs to find files. These programs are provided to recursively search through a directory tree to create, maintain, and search a database (often faster than recursive find, but unreliable if the database has not been updated).

Approximate build time: 0.7 SBU
Required disk space: 52 MB

### 6.58.1. Installation of Findutils

First, suppress a test on which some machines can loop forever:

```bash
sed -i 's/test-lock..EXE/' tests/Makefile.in
```

Next, make some fixes required by glibc-28 and later:

```bash
sed -i 's/IO_ftryfile/IO_EOF_SEEN/' gl/lib/*.c
sed -i 'unistd/ #include <sys/macros.h>' gl/lib/mountlist.c
echo "#define _IO_IN_BACKUP 0100" >> gl/lib/stdio-impl.c
```

Prepare Findutils for compilation:

```bash
./configure --prefix=/usr --localstatedir=/var/lib/locate
```

The meaning of the configure options:

--localstatedir
This option changes the location of the **locate** database to be in `/var/lib/locate`, which is FHS-compliant.

Compile the package:

```bash
make
```

To test the results, issue:

```bash
make check
```

Install the package:

```bash
make install
```

Some of the scripts in the LFS-Bootscripts depend on **find**. As `/usr` may not be available during the early stages of booting, this program needs to be on the root partition. The **updateddb** script also needs to be modified to correct an explicit path:

```bash
mv -v /usr/bin/find /bin
sed -i 's|find:=$(BINDIR)|find:=$(BINDIR)|'/usr/bin/updateddb
```

### 6.58.2. Contents of Findutils

Installed programs: find, locate, updateddb, and xargs
Installed directory: /var/lib/locate
