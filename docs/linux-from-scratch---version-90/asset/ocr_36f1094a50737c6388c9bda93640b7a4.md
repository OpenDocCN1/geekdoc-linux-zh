# ## 7.6.8. Customizing the Boot and Shutdown Scripts

The LFS scripts boot and shut down in a fairly efficient manner, but there are a few tweaks that you can make in the rc.site file to speed up even more and to adjust messages to your preferences. To do this, adjust the settings in the /etc/sysconfig/rc.site file above.

+   - By the boot script udev, there is a call to udev settle that requires time to complete. This time may or may not be required on devices present in the system. If you only have small partitions and a single ethernet cable, the boot process will not need to wait for this. To skip it, set the variable OMIT_UDEV_SETTLE=y.

+   - The boot script udev_retry also runs udev settle by default. This command is only needed if default the /var directory is separately mounted. This is because the clock needs the file /var/lib/hwclock/adtime. Other customizations may also need to wait for udev to complete, but in many instances it is not needed. Skip the command by setting the variable OMIT_UDEV_RETRY_SETTLE=y.

+   - By default, the file system checks are silent. This can appear to be a delay during the booting process. Turn off the fsck output, set the variable VERBOSE_FSCK=y.

+   - When rebooting, you may want to skip the file system check, fsck, completely. To do this, create a file of fastboot or reboot the system with the command /bin/shutdown -f -n. On the other hand, you can force all file systems to be checked by running /forcefsck or running shutdown with the -F parameter instead of f.

Setting the variable FASTBOOT=y will disable fsck during the boot process until it is removed. This is not recommended on a permanent basis.
