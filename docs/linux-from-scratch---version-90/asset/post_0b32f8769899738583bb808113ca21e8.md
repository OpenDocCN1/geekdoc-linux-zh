This option increases security by adding extra code to check for buffer overflows, such as stack smashing attacks.

--with-headers=/usr/include
This option tells the build system to find the kernel API headers. By default, those headers are sought in /tools.

libc_cv_slibdirir=/lib
This variable sets the correct library directory.

```bash
case $(uname) -m in

  ;;
