# ## 6.72. Proccs-ng-3.3.15

The Proccs-ng package contains programs for monitoring processes.
Approximate build time: 0.2 SBU
Required disk space: 17 MB

# ### 6.72.1. Installation of Proccs-ng

Prepare proccs-ng for compilation:

```
./configure --prefix=/usr
  --exec-prefix=/
  --libdir=/usr/lib
  --docdir=/usr/share/doc/proccs-ng-3.3.15
  --disable-static
  --disable-kill
```

The meaning of the configure options:

+   -disable-kill
This switch disables the kill command that will be installed by the Util-linux package.

Compile the package:

```
make
```

The test suite needs some custom modifications for LFS. Remove a test that fails scripting does not use a t and fix two others. To run the test, run the following commands:

```
sed -i -r 's/(pmap_initname)\\\\|1|' testsuite/pmap.test/pmap.exp
sed -i '/set tty/d' testsuite/pkill.test/pkill.exp
rm testsuite/pgrep.test/pgrep.exp
make check
```

Install the package:

```
make install
```

Finally, move every installed library to a location that can be found if /usr is not mounted.

```
mv -v /usr/lib/libproccs.so.* /lib
ln -sf ../../lib=$(readlink /usr/lib/libproccs.so) /usr/lib/libproccs.so
```

# ### 6.72.2. Contents of Proccs-ng

+   - Installed programs: free, pgrep, pidof, pkill, pmap, ps, pwdx, slatop, sysctl, toad, top, uptime, wat, and watch
- Installed library: libproccs.so
- Installed directories: /usr/include/proc and /usr/share/doc/proccs-ng-3.3.15

# ### Short Descriptions

+   - free Reports the amount of free and used memory (both physical and swap memory) in the system
