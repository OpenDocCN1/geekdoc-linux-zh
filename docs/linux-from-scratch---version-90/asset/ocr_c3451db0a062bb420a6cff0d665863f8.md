# Linux From Scratch - Version 9.0

Individual locales can be installed using the localef program. E.g. the first localef command below combines
t /usr/share/i18n/locales/cs_CZ charset-independent locale definition with the /usr/share/i18n/charmaps/UTF-8.gz charset definition and appends the result to the /usr/lib/locale-archive- file. The following instructions will install the minimum set of locales necessary for the optimal coverage of tests:

```
mkdir -pv /usr/lib/locale
localefed -i POSIX -f UTF-8 C.UTF-8 2 /dev/null || true
localefed -i cs_CZ -f UTF-8 cs_CZ_UTF-8
localefed -i de_DE -f ISO-8599-1 de_DE
localefed -i de_DE@euro -f ISO-8599-15 de_DE@euro
localefed -i de_DE -f UTF-8 de_DE
localefed -i el_GR -f ISO-8599-7 el_GR
localefed -i en_GB -f UTF-8 en_GB_UTF-8
localefed -i en_HK -f ISO-8599-1 en_HK
localefed -i en_PH -f ISO-8599-1 en_PH
localefed -i en_US -f UTF-8 en_US
localefed -i en_US -f UTF-8 en_US_UTF-8
localefed -i es_MX -f ISO-8599-1 es_MX
localefed -i fa_IR -f UTF-8 fa_IR
localefed -i fr_FR -f ISO-8599-1 fr_FR
localefed -i fr_FR@euro -f ISO-8599-15 fr_FR@euro
localefed -i fr_FR -f UTF-8 fr_FR_UTF-8
localefed -i it_IT -f ISO-8599-1 it_IT
localefed -i it_IT -f UTF-8 it_IT_UTF-8
localefed -i ja_JP -f EUC-JP ja_JP
localefed -i ja_JP -f SHIFT_JS ja_JP.SIJS 2 > /dev/null || true
localefed -i ja_JP -f UTF-8 ja_JP.UTF-8
localefed -i ru_RU -f KOI-8 ru_RU.KOI-8
localefed -i ru_RU -f UTF-8 ru_RU_UTF-8
localefed -i tr_TR -f UTF-8 tr_TR_UTF-8
localefed -i zh_CN -f GB18030 zh_CN.GB18030
localefed -i zh_HK -f BIG55-HKSCS zh_HK.BIG55-HKSCS
```

In addition, install all locales listed in your country, and character set.

Alternatively, install the glibc-2.30/locatedata/SUPPORTED file (it includes every locale
listed above and many more) at the following time consuming command:

```
make locatedata/install-locales
```

Then use the localef command to create and install locales not listed in the glibc-2.30/locatedata/\SUPPORTED file in the unlikely case you need them.

+   * Note
Glibw uses libidn2 when resolving internationalized domain names. This is a run time dependency. If this capability is needed, the instructions for installing been2 are in the BLFS been2 page.
