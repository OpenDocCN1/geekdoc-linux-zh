## Appendix C. Dependencies

Every package built in LFS relies on one or more packages to build and install properly. Some packages even participate in circular dependencies, where the first depends on the second. The purpose of this page is to document the dependencies of each package built in LFS. The first list lists what packages need to be available to compile and install the package. The second list lists what packages, in addition to the first list, require this package to be built and installed in its final location. If not in a certain order, this could result in paths of /tools/bin/ being installed into the system. This is obviously not desirable. The last list of dependencies are optional packages that are not addressed in LFS, but could be useful to the user. These packages may have additional mandatory or optional dependencies of their own. For these dependencies, the recommended practice is to install them after completion of the LFS book and then go back and rebuild LFS. In several cases, re-installation is advised in BLFS.

| Package | Mandatory Dependencies | Optional Dependencies | Optional |
| :--- | :--- | :--- | :--- |
| Acl | Attr, Bash, Binutils, Coreutils, GCC, Gettext, Grep, M4, Make, Perl, Sed, and Texinfo | Automake, Diffutils, Findutils, and Libtool | Coreutils, Sed, Tar, and Vim |
| Attr | Bash, Binutils, Coreutils, GCC, Gettext, Grep, M4, Make, Perl, Sed, and Texinfo | Automake, Diffutils, Findutils, and Libtool | Acl and Libcap |
| Autoconf | Bash, Coreutils, Grep, M4, Make, Perl, Sed, and Texinfo | Automake, Diffutils, Findutils, GCC, and Libtool | Emacs |
| Automake | Autoconf, Bash, Coreutils, Gettext, Grep, M4, Make, Perl, Sed, and Texinfo | Binutils, Bison, Bzip2, DejaGNU, Diffutils, Expect, Findutils, Flex, GCC, Gettext, Gzip, Libtool, and Tar | None |
