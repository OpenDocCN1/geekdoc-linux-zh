# 7.6.2. Configuring Sysvinit

During the kernel initialization, the first program that is run is either specified on the command line or, by default **init**. This program reads the initialization file /etc/initab. Create this file with:

```
cat > /etc/initab << "EOF"
# Begin /etc/initab

id:3:initdefault

si::sysinit:/etc/rc.d/init.d/rc S

10:0:wait:/etc/rc.d/init.d/rc 0
11:S:wait:/etc/rc.d/init.d/rc 1
12:2:wait:/etc/rc.d/init.d/rc 2
13:3:wait:/etc/rc.d/init.d/rc 3
14:4:wait:/etc/rc.d/init.d/rc 4
15:5:wait:/etc/rc.d/init.d/rc 5
16:6:wait:/etc/rc.d/init.d/rc 6

ca:12345:ctrlaltdel:/sbin/shutdown -t1 -a -r now

su:S016:once:/sbin/login

1:2345:respawn:/sbin/agetty --nuclear tty1 9600
2:2345:respawn:/sbin/agetty tty2 9600
3:2345:respawn:/sbin/agetty tty3 9600
4:2345:respawn:/sbin/agetty tty4 9600
5:2345:respawn:/sbin/agetty tty5 9600
6:2345:respawn:/sbin/agetty tty6 9600

# End /etc/initab
EOF
```

An explanation of this initialization file is in the page for **initab**. For LFS, the key command to run is **rc**. The initialization file above will **rc** to run all scripts starting with an S in the `/etc/rc.d/rcS` directory followed by all the scripts starting with an S in `/etc/rc.d/rc?` where the question mark is specified by the itdefault value.

As a convenience, the **rc** script reads a library of functions in `/lib/sbin/init-functions`. This library also reads an optional configuration file, `/etc/sysconfig/rc.site`. Any of the system configuration parameters described in subsequent sections can be alternatively placed in this file following consolidation of all system parameters in one file.

As a debugging convenience, the function also logs all output to `/run/var/boot.log`. The `/run` directory is a tmpfs, this file is not persistent across boots, however it is appended to the more permanent file `/var/log/boot.log` at the end of the boot process.
