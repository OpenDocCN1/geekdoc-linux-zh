The console script reads the /etc/sysconfig/console file for configuration information. Decide which keymap and screen will be used. Various language-specific HOWTOs can also help with this, see http://www.ldp.org/HOWTO-HOWTO-INDEX/other-lang.html. If still doubt, look in the /usr/share/keymaps and /usr/share/consolefonts directories for keymaps and screen fonts. Read loads(8) manual pages to determine the correct arguments for these programs.

The /etc/sysconfig/console file should contain lines of form: VARIABLE="value". The following variables are recognized:

# LOGLEVEL

This variable specifies the log level for kernel messages sent to the console as dmesg. Valid values are from "1" (no messages) to "8". The default is "7".

# KEYMAP

This variable specifies the arguments for the loadkeys program, typically, the name of keymap to load, e.g., "it". If this variable is not set, the bootscript will run the loadkeys program, and the default kernel keymap will be used. Note that a few keymaps have multiple versions with the same name (cz and its variants in qwerty and qw?, as in olpc and qwerty?, and tr in fgGlod and qwerty/). In these cases the parent directory should also be specified (e.g. qwerty/) to ensure the proper keymap is loaded.

# KEYMAP_CORRECTIONS

This (rarely used) specifies the arguments for the second call to the loadkeys program. This is useful if the stock keymap is not completely satisfactory and a small adjustment has to be made. E.g., to include the Euro sign into a keymap that normally doesn't have it, set this variable to "euro2".

# FONT

This variable specifies the arguments for the setfont program. Typically, "-m", and the name of the application character map to load. E.g., to load the "lat1-16" together with "8859-1" application character map (as it is appropriate in the USA), set this variable to "lat1-16 -m 8859-1" mode, the kernel uses the application character map for conversion of 8-bit codes in the keymap to UTF-8, and thus the argument of the "-m" parameter should be set to the encoding of the composed key codes in the keymap.

# UNICODE

Set this variable to "1", "yes" or "true" in order to put the console into UTF-8 mode. This is useful in UTF-8 locales and harmful otherwise.

# LEGACY_CHARSET

For many keyboard layouts, there is no stock Unicode keymap in the Kbd package. The console bootscript will convert an available keymap to UTF-8 on the fly if this variable is set to the encoding of the available non-UTF-8 keymap.
