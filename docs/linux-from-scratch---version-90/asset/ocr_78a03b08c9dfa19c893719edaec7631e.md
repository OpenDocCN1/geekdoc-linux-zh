# ## 49. Libbfi-3.2.1

The Libbfi library provides a portable, high level programming interface to various calling conventions. This allows a programmer to call any function specified by a call interface description at run time.

**Approximate build time:** 0.4 SBU
Required disk space: 7.6 MB

# ### 49.9.1. Installation of Libbfi

> > **Note**
> Similar to GMP, libbfi builds with optimizations specific to the processor in use. If building for another system, export CFLAGS and CXXFLAGS to specify a generic build for your architecture. If this is not done, all applications that link to libbfi will trigger Illegal Operation Errors.

Modify the Makefile to install headers into the standard `/usr/include` directory instead of `/usr/lib/libbfi-3.2.1/include`.

```
sed -e '/^includeddir/ s/\$(libdir).*\$(includeddir)/' \ \
-i include=Makefile.in

sed -e '/^includeddir/ s=.**/=@includeddir@' \ \
-e '/CFLAGS: -$(includeddir)/Cflags:\' \ \
-i libbfi.pc.in
```

Prepare libbfi for compilation:

```
./configure --prefix=/usr --disable-static --with-gcc-arch=native
```

The meaning of the configure option:

```
--with-gcc-arch=native
Ensure gcc optimizations for the current system. If this is not specified, the system is guessed and the code generated may not be correct for some systems. If the generated code will be copied from the native system to a less capable system, use the less capable system as a parameter. For details about alternative system types, see the *x86 options* manual.
```

Compile the package:

```
make
```

To test the results, issue:

```
make check
```

Install the package:

```
make install
```
