# 1.5. Help

If an issue or a question is encountered while working through this book, please check the FAQ page at http://www.linuxfromscratch.org/faq#generalfaq. Questions are often answered there. If your question is not answered on this page, try to find the source of the problem. The hint will give you some guidance for troubleshooting: http://www.linuxfromscratch.org/hints/downloads/files.txt.

If you cannot find your problem in the FAQ, search the mailing lists at http://www.linuxfromscratch.org/search.html.

We also have a wonderful LFS community that is willing to offer assistance through the mailing lists and IRC (see the Section 1.4, "Resources" section of this book). However, we get several questions every day and many of them can be answered by going to the FAQ and by searching the mailing lists. So, for us to get the best assistance possible, you to do some research on your first. That allows us to focus on the more unusual needs. If your searches do not produce a solution, please include all relevant information (mentioned below) in your request for help.

# 1.5.1. Things to Mention

+   - The version of the book used (in this case 9.0 )
- The host distribution and version used to create LFS
- The output from the Host System Requirements script
- The package or section the problem was encountered in
- The exact error message or symptom being received
- Note whether you have deviated from the book at all

> Deviating from this book does not mean that we will not help you. After all, LFS is about personal preference. Being upfront about any changes to the established procedure helps us evaluate and determine possible causes of your problem.

# 1.5.2. Configure Script Problems

If something went wrong running the configure script, review the config.log file. This file may contain errors encountered during configure which were not printed to the screen. Include the relevant lines if you need to ask for help.
