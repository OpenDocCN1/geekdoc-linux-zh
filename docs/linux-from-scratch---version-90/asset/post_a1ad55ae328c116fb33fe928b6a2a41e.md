
# 6.65. Libpipeline-1.5.1

## 68. Man-DB-2.8.6.1

The Man-DB package contains programs for finding and viewing man pages.
Approximate build time: 0.4 SBU
Required disk space: 38 MB

## 68.1. Installation of Man-DB

Prepare Man-DB for compilation:

```
./configure --prefix=/usr \
    --docdir=/usr/share/doc/man-db-2.8.6.1 \
    --sysconfdir=/etc \
    --disable-setuid \
    --enable-cache-owner=bin \
    --with-browser=/usr/bin/lynx \
    --with-vgrind=/usr/bin/vgrind \
    --with-grap=/usr/bin/grap \
    --with-systemdunitdir=
```

The meaning of the configure options:

- --disable-setuid:
This disables making the man program setuid to user man.
- --enable-cache-owner=bin:
This makes the system-wide cache files owned by user bin.
- --with-...
These parameters are used to set some default parameters. lynx is a text-based browser (see BLFS for installation instructions), vgrind converts sources to Groff input, and grap is useful for typesetting graphs in Groff dots. The vgrind and grap programs are not normally needed for viewing manual pages. They are not part of LFS or BLFS, but you should install them yourself after finishing LFS if you wish to do.
- --with-systemd...:
These parameters prevent installing unneeded systemd directories and files.

Compile the package:

```
make
```

To test the results, issue:

```
make check
```

Install the package:

```
make install
```

## 69. Tar-1.32

The Tar package contains an archiving program.
Approximate build time: 2.2 SBU
Required disk space: 45 MB

## 69.1. Installation of Tar

Prepare Tar for compilation:

```
FORCE_UNSAFE_CONFIGURE=1 \
./configure --prefix=/usr
```

The meaning of the configure options:

FORCE_UNSAFE_CONFIGURE=1:
This forces the test for knod to be run as root user, but it is generally dangerous on a system that has only partially built, overriding it is OK.

Compile the package:

```
make
```

To test the results, issue:

```
make check
```

Install the package:

```
make install
make -C doc install-html docdir=/usr/share/doc
```

### Short Descriptions

- **tar**: Creates, extracts files from, and lists the contents of archives, also known as tarballs.

## 70. Texinfo-6.6

The Texinfo package contains programs for reading, writing, and converting info pages.
Approximate build time: 0.8 SBU
Required disk space: 122 MB

## 70.1. Installation of Texinfo

Prepare Texinfo for compilation:

```
./configure --prefix=/usr --disable-static
```

The meaning of the configure options:

--disable-static:
In this case, the top-level configure script will complain that this is an unrecognized option, the configure script for texinfo recognizes it and uses it to disable installing a static texinfo.a to /usr/lib/texinfo.

Compile the package:

```
make
```

To test the results, issue:

```
make check
```

Install the package:

```
make install
```

Optionally, install the components belonging in a Tex installation:

```
make TEXMF=/usr/share/texmf install-tex
```

### Note on:

The documentation system uses a plain text file to hold its list of menu entries. The file is located at /usr/share/info/dir. Unfortunately, due to occasional problems in the Makefiles of various packages, it can get out of sync with the info pages installed on the system. If the /usr/share/info/dir ever needs to be recreated, the following optional commands will accomplish the task:

```
pushd /usr/share/info
rm -v dir
for f in *
  do install-info $f dir>/dev/null
done
popd
```
