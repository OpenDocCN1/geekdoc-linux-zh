
For a non-Unicode setup, only the KEYMAP and FONT variables are generally needed. E.g., for a Polish setup, one would use:

```
cat > /etc/sysconfig/console << "EOF"
# Begin /etc/sysconfig/console

KEYMAP="pl12"
FONT="lat2a-16 -m 8859-2"

# End /etc/sysconfig/console
EOF
```

As mentioned above, it is sometimes necessary to adjust a stock keymap slightly. The following example adds the Euro symbol to the German keymap:

```
cat > /etc/sysconfig/console << "EOF"
# Begin /etc/sysconfig/console

KEYMAP="de-latin1"
KEYMAP_CORRECTIONS="euro2"
FONT="lat0-16 -m 8859-15"
UNICODE="1"

# End /etc/sysconfig/console
EOF
```

The following is a Unicode-enabled example for Bulgarian, where a stock UTF-8 keymap exists:

```
cat > /etc/sysconfig/console << "EOF"
# Begin /etc/sysconfig/console

UNICODE="1"
KEYMAP="bg_bds-utf8"
FONT="LatArCyrHeb-16"

# End /etc/sysconfig/console
EOF
```

Due to the use of a 512-glyph LatAtCyrHeb-16 font in the previous example, bright colors are no longer available on the Linux console unless a framebuffer is used. If one wants to have bright colors without framebuffer and live without characters not belonging to the language, it is still possible to use a language-specific 256-glyph font, as illustrated below:

```
cat > /etc/sysconfig/console << "EOF"
# Begin /etc/sysconfig/console

UNICODE="1"
KEYMAP="bg_bds-utf8"
FONT="cyr-sun16"

# End /etc/sysconfig/console
EOF
```

The following example illustrates keymap autconversion from ISO-8859-15 to UTF-8 and enabling de keys in Unicode mode:

```
cat > /etc/sysconfig/console << "EOF"
# Begin /etc/sysconfig/console

UNICODE="1"
KEYMAP="de-latin1"
KEYMAP_CORRECTIONS="euro2"
LEGACY_CHARSET="iso-8859-15"
FONT="LatAtCyrHeb-16 -m 8859-15"

# End /etc/sysconfig/console
EOF
```

Some keymaps may have dead keys (i.e., keys that do not produce a character by themselves, but put an accent on the character produced by the next key) or composition rules (such as: "Ctrl. A to get Æ" in the default keyboard). Linux-5.2 interprets dead keys and composition rules in the keymap correctly only when the source characters are composed together this diversity does not affect keys for European languages, where accents are added to unassigned ASCII characters, or two ASCII characters composed together. However, in UTF-8 it is a problem, e.g., for the Greek language, where one sometimes needs to put an accent on the letter "alpha". The solution is to either avoid the use of UTF-8, or to install the X window system.

For Chinese, Japanese, Korean and other languages, the Linux console cannot be configured to display the necessary characters. Users who need languages should install the X Window System, fonts that cover the necessary character ranges (e.g., SCIM, it supports a wide variety of languages).

> Note: /etc/sysconfig/console file only controls the Linux text console localization. It has nothing to do with setting the proper keyboard layout and fonts in the X Window System, with ssh sessions or with a serial console. In such situations, limitations mentioned in the last two items above do not apply.

## 7.6.6. Creating Files at Boot

At times, it is desired to create files at boot time. For instance, the /tmp/.ICE-unix directory may be desired. This can be done by creating an entry in the /etc/sysconfig/creates script. The format of this file is embedded in the comments of the default configuration file.

## 7.6.7. Configuring Syslog

The syslog script is invoked during boot. The /etc/sysconfig/syslog file controls the behavior of the syslog daemon. You can use it to specify which logs are recorded and where they are stored.

The syslog daemon may have dead keys (i.e., keys that do not produce a character by themselves, but put an accent on the character produced by the next key) or composition rules (such as: "Ctrl. A to get Æ" in the default keyboard). However, in UTF-8 it is a problem, e.g., for the Greek language, where one sometimes needs to put an accent on the letter "alpha". The solution is to either avoid the use of UTF-8, or to install the X window system.

## 7.6.8. Customizing Boot and Shutdown Scripts

The LFS scripts boot and shut down in a fairly efficient manner, but there are a few tweaks that you can make in the rc.site file to speed up even more and to adjust messages to your preferences. To do this, adjust the settings in the /etc/sysconfig/rc.site file.
