# Linux From Scratch - Version 9.0

--with-native-system-header-dir=/tools/include
By default GCC searches /usr/include for system headers. In conjunction with the sysroot, which will normally translate to $LFS/usr/include. However the headers that will be installed in the next two sections will go to $LFS/tools/include. This switch ensures gcc will find them correctly. In the second pass of GCC, this switch will ensure that no headers from the host system are found.

--disable-shared
This forces GCC to link to its internal libraries statically. We do this to avoid possible issues with the host system.

--disable-decimal-float, --disable-threads, --disable-libatomic, --disable-libgomp, --disable-libquadmath, --disable-libss, --disable-libvtv, --disable-libstdcxx
These switches disable support for the decimal floating point extension, threading, atomic, libgomp, libquadmath, libssl, libvtv, and the C++ standard library respectively. These features will fail to compile building a cross-compiler and are not necessary for the task of cross-compiling the temporary libc.

--disable-multilib
On x86_64, LFS does not yet support a multilib configuration. This switch is harmless for x86.

--enable-languages=c,c++
This option ensures that only the C and C++ compilers are built. These are the only languages needed.
