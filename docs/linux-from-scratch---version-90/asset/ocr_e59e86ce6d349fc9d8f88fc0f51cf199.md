# 6.20.4. Contents of Shadow

Installed programs:

chage, chfn, chpassword, chsh, expiry, faillog, gpassword, groupadd, groupdel, groupmems, groupdp, grpk, grpcv, grpunconv, lastlog, login, logout, newgidmap, newgrp, newuidmap, news, passwd, pw, pwcon, pwpasswd, sg (link to newgrp), su, userdel, usermod, vigr (link to vip) and pipw

Installed directory:

/etc/shadow

# Short Descriptions

+   - chage: Used to change the maximum number of days between obligatory password changes
- chfn: Used to change a user's full name and other information
- chpassword: Used to update group passwords in batch mode
- chpasswd: Used to update user passwords in batch mode
- chsh: Used to change a user's default login shell
- expiry: Checks and enforces the current password expiration policy
- faillog: Is used to examine the log of logins, to set a maximum number of failures before an account is blocked, or to reset the failure count
- gpassword: Is used to add and delete members and administrators to groups
- groupadd: Creates a group with the given name
- groupdel: Deletes the group with the given name
- groupmems: Allows a user to administer/her own group membership list without the requirement of super user privileges.
- groupmod: Is used to modify the group name or ID
- grpck: Verifies the integrity of the group files /etc/group and /etc/shadow
- grpcnv: Creates or updates the shadow file from the normal password file
- grpunconv: Updates /etc/group from /etc/shadow and deletes the latter
- lastlog: Reports the most recent login of all users or of a given user
- login: Is used by the system to let users sign on
- logout: Is a daemon to enforce restrictions on log-on time and ports
- newgidmap: Is used to set the gid mapping of a user namespace
- newgrp: Is used to change the current GID during a login session
- newuidmap: Is used to set the uid mapping of a user namespace
- news: Is used to create or update an series of users accounts
- nologin: Displays a message that an account is not available; it is designed to be used as the default shell for accounts that have been disabled
- passwd: Is used to change the password for a user or group account
- pwck: Verifies the integrity of the password files /etc/passwd and /etc/shadow
- pwconv: Creates or updates the shadow password file from the normal password file
- pwunconv: Updates /etc/passwd from /etc/shadow and deletes the latter
