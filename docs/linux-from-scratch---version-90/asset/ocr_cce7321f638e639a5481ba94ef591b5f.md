# ul

A filter for translating underscores into escape sequences indicating underlining for the terminal in use

Disconnects a file from the system's file tree

# uname26

# unshare

Runs a program with some namespaces unshared from parent

# utmpmpd

# uuidd

A daemon by the UUID library to generate time-based UUIDs in a secure and guaranteed-unique fashion

Creates new UUIDs. Each new UUID reasonably be considered unique among all UUIDs created, on the local system and on other systems, in the past and in the future

# uipparse

An utility to parse unique identifiers
