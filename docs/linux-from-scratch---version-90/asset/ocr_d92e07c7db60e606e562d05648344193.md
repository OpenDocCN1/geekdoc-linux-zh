# 6.7. Linux-5.2.8 API Headers

The Linux API Headers (in linux-5.2.8.tar.xz) expose the kernel's API for use by Glibc.

Approximate build time: less than 0.1 SBU
Required disk space: 960 MB

# 6.7.1. Installation of Linux API Headers

The Linux kernel needs to expose an Application Programming Interface (API) for the system's C library (Glibc in LFS). This is done by sanitizing various C header files that are shipped in the Linux kernel sourceball.
Make sure there are no stale files and dependencies lying from previous activity:

```
make mrproper
```

Now extract the user-visible kernel headers from the source. They are placed in an intermediate local directory and copied to the needed location where the extraction removes any existing files in the target directory. There are also some files hidden by the kernel developers and not needed by LFS that are removed from the intermediate directory.

```
make INSTALL_HDR_PATH=dest headers_install
find dest/ \ -name .install -o -name ..cmd \ -delete
cp -rv dest/* /usr/include
```
