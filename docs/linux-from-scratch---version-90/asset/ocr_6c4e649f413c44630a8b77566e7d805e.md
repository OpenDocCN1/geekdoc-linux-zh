# ## 6.13. Readline-8.0

The Readline package is a set of libraries that offers command-line editing and history capabilities.

**Approximate build time:** 0.1 SBU
**Required disk space:** 15 MB

# ### 6.13.1. Installation of Readline

Reinstalling Readline will cause the old libraries to be moved to <libraryname>.old. While this normally not a problem, in some cases a linking bug in ldconfig. This can be avoided by issuing the following two suds:

```
sed -i '*/.old/d' Makefile.in
sed -i '/(OLDSUFF)/c' support/shlib-install
```

Prepare Readline for compilation:

```
./configure --prefix=/usr \
    --disable-static \
    --docdir=/usr/share/doc/readline-8.0
```

Compile the package:

```
make SHLIB_LIBS="-L/tools/lib -lcurses"
```

The meaning of the make option:

```
SHLIB_LIBS="-L/tools/lib -lcursesw"
```

This option forces Readline to link against the libncurses library.

This package does not come with a test suite.

Install the package:

```
make SHLIB_LIBS="-L/tools/lib -lcursesw" install
```

Move the dynamic libraries to a more appropriate location and fix up some permissions and symbolic links:

```
mv -v /usr/lib/readline/{readline,history}.so.* /lib
chmod -u v /usr/lib/readline/{readline,history}.so.*
ln -sf ../ ..//lib/$$(readlink /usr/lib/libreadline.so) /usr/lib/libreadline.so
ln -sf ../lib/lib/$$(readlink /usr/lib/libhistory.so ) /usr/lib/libhistory.so
```

If desired, install the documentation:

```
install -v -m664 doc/*.{ps,pdf,html,dvi} /usr/share/doc/readline-8.0
```
