# # 7.6. Sysunit-2.95

The Sysunit package contains programs for controlling the startup, running, and shutdown of the system.

**Approximate build time:** less than 0.1 SBU
Required disk space:** 1.3 MB

# # 6.76.1. Installation of Sysunit

First, apply a patch that removes programs installed by other packages, clarifies a message, and fixes a compiler warning:

```
patch -Np1 -i ../sysunit-2.95-consolidated-1.patch
```

Compile the package:

```
make
```

This package does not come with a test suite.

Install the package:

```
make install
```

# # 6.76.2. Contents of Sysunit

**Installed programs:** bootlogd, fstab-decode, halt, init, killall5, poweroff (link to halt), reboot (link to halt), runlevel, shutdown, and telinit (link to init)

# ## Short Descriptions

+   **bootlogd** Logs boot messages to a log file

+   **fstab-decode** Run a command with fstab-encoded algorithms

+   **halt** Normally invokes **shutdown** with the -h option, except when in run-level 0, then it tells the kernel to halt the system; it notes in the file /var/log/wt.tmp that the system is brought down

+   **init** The first process to be started when the kernel takes over the boot process and starts all the processes specified in its configuration file

+   **killall5** Sends a signal to all processes, except the processes in run session so it will not kill its parent shell

+   **poweroff** Tells the kernel to halt the system and switch off the computer (**halt**)

+   **reboot** Tells the kernel to restart the system (**halt**)

+   **runlevel** Reports the previous and the current run-level, as noted in the last run-level record in /var/run/ut.mp

+   **shutdown** Brings the system down in a secure way, signaling all processes and notifying all logged-in users

+   **telinit** Tells **init** which run-level to change to
