## 6.71.1. Installation of Vim

First, change the default location of the vimrc configuration file to /etc:

```bash
echo '#define SYS_VIMRCFILE "/etc/vimrc"' >> src/feature.h
```

Prepare Vim for compilation:

```bash
./configure --prefix=/usr
```

Compile the package:

```bash
make
```

To prepare the tests, ensure that the nobody user can write to the sources:

```bash
chown -Rv nobody .
```

Now run the tests as the nobody user:

```bash
su nobody -s /bin/bash -c "LANG=en_US.UTF-8 make test" >vim-test.log
```

The test suite outputs lot of binary data to the screen. This can cause issues with the settings of the current terminal. The problem can be avoided by redirecting the output to a log file as shown above. A successful test will result in the word "DONE" in the log file at completion.

Install the package:

```bash
make install
```

Many users use vi instead of vim. To allow execution of vim when users habitually enter vi, create symlink for both the binary and the man pages in the following:

```bash
ln -sv vim /usr/bin/vi
for L in /usr/share/man/* do
  ln -sv vim $(dirname $L)/vi
done
```

By default, Vim's documentation is installed in /usr/share/doc/. The following symlink allows the documentation to be accessed via /usr/share/doc/vim-8.1.1846, making it consistent with the location of other packages:

```bash
ln -sv ../vim-8.1/doc /usr/share/doc
```

If an X Window System is to be installed, it may be necessary to reconcile Vim after installing X. Vim comes with a GUI version of the editor that requires X and some additional libraries to be installed. For information on this, refer to the Vim installation page in the BLFS book at http://www.linuxfromscratch.org/blfs/view/9.0/postfs/vim.html.

## Configuring Vim

By default, Vim runs in incompatible mode, which may be new to users who have used other editors in the past. The "incompatible" setting is included below to highlight the fact that new behavior is being used. It also reminds them how to change the first setting in the configuration file because it changes other settings and must come after this one. Create a default configuration file by running the following:

```bash
cat /etc/vimrc << EOF
  Ensure defaults are set before customizing settings, not after
  source $VIMRUNTIME/defaults/vim
  let skip_defaults=1

  set incompatible
  set backspace=2
  set mouse=
  syntax on
  if ($term == "xterm") || ($term == "putty")
    set background=dark
  endif
EOF
```

The incompatible setting makes Vim behave in a more useful way than the default manager. Remove "incompatible" to keep the old behavior. The backspace=2 setting handles line breaks, indents, and insert. The syntax on parameter enables Vim’s syntax highlighting. The mouse setting enables proper pasting of text when working in chroot or over a remote connection. Finally, the set background=dark setting corrects Vim’s guess about the background color of some terminal emulators. This gives a better color scheme for the background.

By default, only installs spell files for the English language. To install spell files for your preferred language, download the *.spell and optionally the *.sw files for your language and character encoding from http://ftp.vim.org/runtime/spell/ and save them to /usr/share/vim/8.1/spell/.

To use these spell files, some configuration in /etc/vimrc is needed, e.g.:

```vim

```

## 6.72. Proccs-ng-3.3.15

The Proccs-ng package contains programs for monitoring processes.
Approximate build time: 0.2 SBU
Required disk space: 17 MB

### 6.72.1. Installation of Proccs-ng

Prepare proccs-ng for compilation:

```bash
./configure --prefix=/usr
  --exec-prefix=/
  --libdir=/usr/lib
  --docdir=/usr/share/doc/proccs-ng-3.3.15
  --disable-static
  --disable-kill
```

The meaning of the configure options:

- disable-kill: This switch disables the kill command that will be installed by the Util-linux package.

Compile the package:

```bash
make
```

The test suite needs some custom modifications for LFS. Remove a test that fails because scripting does not use a t and fix two others. To run the test, run the following commands:

```bash
sed -i -r 's/(pmap_initname)\\\\|1|' testsuite/pmap.test/pmap.exp
sed -i '/set tty/d' testsuite/pkill.test/pkill.exp
rm testsuite/pgrep.test/pgrep.exp
make check
```

Install the package:

```bash
make install
```

Finally, move every installed library to a location that can be found if /usr is not mounted.

```bash
mv -v /usr/lib/libproccs.so.* /lib
ln -sf ../../lib=$(readlink /usr/lib/libproccs.so) /usr/lib/libproccs.so
```
