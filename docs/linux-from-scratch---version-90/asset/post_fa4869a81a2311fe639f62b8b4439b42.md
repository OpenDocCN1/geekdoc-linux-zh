# Preface

# Foreword

My journey to learn and better understand Linux began in 1998. I had just installed my first distribution and had quickly become intrigued with the whole philosophy behind Linux. There are always many ways to accomplish a single task. Great many have existed over the years. Some still have morphed into something else, yet others have been relegated to memories. Because so many ways to accomplish the same end, I realize no longer had to be limited by any one. It was what it was, whether you liked it or not. With Linux, the concept of change emerge. If you were free, encouraged to change.

I tried a number of distributions and could not decide on any one. They were great systems in their own right. It wasn't a matter of right and wrong anymore. With all that choice, it became apparent that there not be a single system that would be perfect for me. So I set out to create my own Linux system that would fully conform to my preferences.

To truly make it ours, I resolved to compile everything from source instead of using pre-compiled binary packages. This "perfect" Linux system would have the strengths of various systems without their perceived weaknesses. At first the idea was rather daunting. I remained committed to the idea that such a system could be built.

After sorting through such issues as dependencies and compile-time errors, I finally built a custom-built Linux system. It was fully operational and perfectly usable like any of the other. But it was my own creation. The only thing better would have been to create each piece of software myself. This was the next best thing.

As I shared my goals and experiences with other members of the Linux community, it became apparent that there was a sustained interest in these ideas. It quickly became plain that such custom-built Linux systems serve not only to meet specific requirements, but also as an ideal learning opportunity for programmers and system administrators to enhance their existing skills. Of that broadened interest, the Linux From Scratch Project was born.

This Linux From Scratch book is the core around project. It provides the groundwork and instructions necessary for you to build your own system. This book provides a template that will be in correctly working system, you are free to alter the instructions to yourself, which is, in an important part of this project. You remain in control; we just lend a hand to get started on your journey.

I sincerely hope you will have a great time working on your own Linux From Scratch system and enjoy the numerous benefits of having a system that is truly yours own.

-- Gerard Beekemans
gerard@linuxfromscratch.org
