# ## 7.6.6. Creating Files at Boot

At times, it is desired to create files at boot time. For instance, the /tmp/.ICE-unix directory may be desired. This can be done by creating an entry in the /etc/sysconfig/creates script. The format of this file is embedded in the comments of the default configuration file.

# ## 7.6.7. Configuring the syslog Script

The syslog script invokes the syslog program as part of System V initialization. The -m option turns off the periodic timestamp that syslog writes to the log files every 20 minutes. If you want to turn on your periodic timestamp, edit /etc/sysconfig/rc.site and define the variable SYSLOG_PARMS to the desired value. For instance, to remove all parameters, set the variable to a null value:

```
SYSLOG_PARMS=
```

See syslog for more options.

# ## 7.6.8. The rc.site File

The optional /etc/sysconfig/rc.site file contains settings that are automatically set for each SystemV script. It can alternatively set the values specified in the hostname, console, and clock files in the /etc/sysconfig/. If the associated variables are present in these separate files and rc.site, the values in the script itself have precedence.

rc.site also contains parameters that can customize other aspects of the boot process. Setting the PROMPT variable will enable selective running of bootscripts. Other options are described in the file contents. The default version of the file is as:

+   # rc.site
# Optional parameters for boot scripts.

# Distro Information
# These values, if specified here, override the defaults
#DISTRO="Linux From Scratch" # The distro name
#DISTRO_CONTACT="lfs-dev@linuxfromscratch.org" # Bug report address
#DISTRO_MINI="LFS" # Short name used in filenames for distro config

+   # Define custom colors used in messages printed to the console

# Please consult `console_codes` for more information
# under the `ECMA-48 Set Graphics Rendition` section

# Warning: when switching from an 8bit to a 9bit font,
# the linux console will reinterpret the bold (l); to
# the top 256 glyphs of the bold font. This does
# not affect framebuffer consoles

+   # These values, if specified here, override the defaults
#BRACKET="033[1;34m" # Blue
#FAILURE="033[1;31m" # Red
#INFO="033[1;36m" # Cyan
