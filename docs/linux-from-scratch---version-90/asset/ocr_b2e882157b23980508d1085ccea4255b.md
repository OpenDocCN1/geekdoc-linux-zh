# ## 6.58. Findutils-4.6.0

The Findutils package contains programs to find files. These programs are provided to recursively search through a directory tree to create, maintain, and search a database (often faster than the recursive find, but unreliable if the database has not been recently updated).

**Approximate build time:** 0.7 SBU
**Required disk space:** 52 MB

# ## 6.58.1. Installation of Findutils

First, suppress a test on which some machines can loop forever:

```
sed -i 's/test-lock..EXEET.//' tests/Makefile.in
```

Next, make some fixes required by glibc-28 and later:

```
sed -i 's/IO_ftrylockfile/IO_EOF_SEEN/' gl/lib/*.c
sed -i 'unistd/ #include <sys/sysmacros.h>' gl/lib/mountlist.c
echo "#define _IO_IN_BACKUP 0100" >> gl/lib/stdio-impl.c
```

Prepare Findutils for compilation:

```
./configure --prefix=/usr --localstatedir=/var/lib/locate
```

The meaning of the configure options:

--localstatedir
This option changes the location of the **locate** database to be in `/var/lib/locate`, which is FHS-compliant.

Compile the package:

```
make
```

To test the results, issue:

```
make check
```

Install the package:

```
make install
```

Some of the scripts in the LFS-Bootscripts depend on **find**. As `/usr` may not be available during the early stages of booting, this program needs to be on the root partition. The **updateddb** script also needs to be modified to correct an explicit path:

```
mv -v /usr/bin/find /bin
sed -i 's|find:=$(BINDIR)|find:=$(BINDIR)|/usr/bin/updateddb
```
