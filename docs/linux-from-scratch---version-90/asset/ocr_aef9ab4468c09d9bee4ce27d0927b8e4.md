# 6.77.3. Contents of Eudev

**Installed programs:** udevadm andudev
**Installed libraries:** libudev.so
**Installed directories:** /etc/udev, /lib/udev, and /usr/share/doc/udev-lfs-20171102

# Short Descriptions

+   **udevadm** Generic udev administration tool: controls the udev daemon, provides info from the Udev database, monitors uevents, waits for uevents to finish, tests Udev configuration, and triggers uevents for a given device

+   **udevd** A daemon that listens for uevents on the netlink socket, creates devices and runs the configured external programs in response to these uevents

+   **libudev** A library interface to udev device information

+   etc/udev** Contains Udev configuration files, device permissions, and rules for device naming
