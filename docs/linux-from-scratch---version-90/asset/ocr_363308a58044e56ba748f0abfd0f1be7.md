If you want to access your new system from a remote system within a comfortable GUI environment, install openssh.

To make fetching files over the internet easier, install wget.

If one or more of your disk drives have a GUID partition table (GPT), either gptdisk or parted will be useful.

Now that we have said that, let's move on to booting our shiny LFS installation for the first time! First exit from the chroot environment:

# logout

Then unmount the virtual file systems:

```
umount -v $LFS/dev/pts
umount -v $LFS/dev
umount -v $LFS/run
umount -v $LFS/proc
umount -v $LFS/sys
```

Unmount the LFS file system itself:

```
umount -v $LFS/usr
umount -v $LFS/home
umount -v $LFS
```

Now, reboot the system with:

```
shutdown -r now
```

Assuming the GRUB boot loader was set up as outlined earlier, the menu is set to boot LFS 9.0 automatically.

When the reboot is complete, the LFS system is ready for use and more software may be added to your needs.
