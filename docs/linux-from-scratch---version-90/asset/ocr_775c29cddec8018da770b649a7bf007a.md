password(5)

This format is used to refer to a specific manual (man) page. The number inside parentheses indicates a specific section inside the manuals. For example, `password` has two man pages. For LFS installation instructions, those two man pages will be located at `/usr/share/man/man1/password.1` and `/usr/share/man/man5/password.5`. When the book uses `password(5)` it is specifically referring to `/usr/share/man/man5/password.5`. **man password** will print the first man page it finds matches "password", which will be `/usr/share/man/man1/password.1`. For this example, you will need to run **man 5 password** in order to refer the specific page referred to. It should be noted that most man pages do not have duplicate page names in different sections. Therefore, **man <program name>** is generally sufficient.

# Structure

This book is divided into the following parts.

# Part I - Introduction

Part I explains a few important notes on how to proceed with the LFS installation. This section also provides meta-information about the book.

Part II describes how to prepare for the building process—making a partition, downloading the packages, and compiling temporary tools.

Part III guides the reader through the building of the LFS system—compiling and installing all the packages by one, setting up the boot scripts, and installing the kernel. The resulting LFS system is the foundation on which other software can be built to expand the system as desired. At the end of this book, there is an easy to use reference listing for all the programs, libraries, and important files that have been installed.

The software used to create an LFS system is constantly updated and enhanced. Security warnings and bug fixes may become available after the LFS book has been released.
