# # 6.40. Perl-5.30.0

The Perl package contains the Practical Extraction and Report Language.

**Approximate build time:** 9.9 SBU
**Required disk space:** 272 MB

# ## 6.40.1. Installation of Perl

First create a /etc/hosts file to be referenced in one of Perl's configuration files as well as the optional test suite:

```
echo "127.0.0.1 localhost $(hostname)" > /etc/hosts
```

This version of Perl builds the Compress::Raw::Zlib and Compress::Raw::ZIP2 modules. Default Perl will use an internal copy of the sources for the build. Issue the following command so that Perl will use the libraries installed on the system:

```
export BUILD_ZLIB=False
export BUILD_BZIP2=0
```

To have full control over how Perl is set up, use the "des" options from the following command and hand-pick which package this is built. Alternatively, use the command exactly as below to use the details that Perl auto-detects:

```
sh Configure -des -Dprefix=/usr \\
  -Dvendorprefix=/usr \\
  -Dman1dir=/usr/share/man/man1 \\
  -Dman3dir=/usr/share/man/man3 \\
  -Dpager="/usr/bin/less -isR" \\
  -Dusheshrlib \\
  -Dusetethreads
```

**The meaning of the configure options:**

+   -Dvendorprefix=/usr
This Perl knows how to tell packages where they should install their perl modules.
-Dpager="/usr/bin/less -isR"
This ensures that **less** is used instead of **more**.
-Dman1dir=/usr/share/man/man1 -Dman3dir=/usr/share/man/man3
Since Goff is not installed yet, **Configure** thinks that we do not want man pages for Perl. Issuing this overrides this decision.
-Dusheshrlib
Build a shared libperl needed by some perl modules.
-Dusetethreads
Build perl with support for threads.

Compile the package:

```
make
```
