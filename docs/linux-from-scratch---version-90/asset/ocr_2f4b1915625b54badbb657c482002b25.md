# 5.5.1. Installation of Cross GCC

GCC now requires the GMP, MPFR, and MPC packages. As these packages may not be included in your host distribution, which will be built with GCC. Unpack each package into the GCC source directory and rename the resulting directories to the GCC build procedures will automatically use them:

> NotenThere are frequent misunderstandings about this chapter. The procedures are the same as every other as explained earlier (Package build instructions). First extract the gcc tarball from the sources directory and then change to the created directory. Only then should you proceed with the instructions.

```
tar -xf ../mpfr-4.0.2.tar.xz
mv -v mpfr-4.0.2 mpfr
tar -xf ../gmp-6.1.2.tar.xz
mv -v gmp-6.1.2 gmp
tar -xf ../mpc-1.1.0.tar.xz
mv -v mpc-1.1.0 mpc
```

The following command will change the location of GCC's default dynamic linker to use the one installed in /tools. It also removes /include from GCC's search path. Issue:

```
for file in gcc/config/{linux,i386,{64}}.h do
  cp -uv $file,{.}
  sed -e 's|/lib\(64\)/|ld@/tools&' \
  sed -e 's|/usr@/tools&' $file.orig > $file
  echo
#undef STANDARD_STARTFILE_PREFIX_1
#undef STANDARD_STARTFILE_PREFIX_2
#define STANDARD_STARTFILE_PREFIX_1 "/tools/lib/"
#define STANDARD_STARTFILE_PREFIX_2 """ >> $file
  touch $file.orig
done
```

In case the above seem hard to follow, let's break it down a bit. First we copy the files gcc/config/linux.h, gcc/config/i386/linux64.h to a file of the same name but with an added suffix of "orig". Then the first sed replaces "tools/lib", "lib64id" or "lib32id", while the second one replaces hard-coded instances of "usr". Next, we add define statements that alter the default prefix to the end of the file. Note that the trailing "/" in "tools/lib/" is required. Finally use touch with cp -u, this prevents unexpected changes to the original files in case the commands are inadvertently run.
