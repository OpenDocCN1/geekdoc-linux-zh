# ## 6.20. Shadow-4.7

The Shadow package contains programs for handling passwords in a secure way.

**Approximate build time:** 0.2 SBU
Required disk space: 46 MB

# ### 6.20.1. Installation of Shadow

> If you would like to enforce the use of strong passwords, refer to http://www.linuxfromscratch.org/blfs/view/9.0posts/cracklib.html for installing CrackLib prior to building Shadow. Then add --with-libcrack to the configure command below.

Disable the installation of the **groups** program and its man, as Coreutils provide a better version. Prevent the installation of manual pages that were already installed in Section 6.8, "Man-pages-5.02":

```
sed -i 's/groups$(EXEEXT)/' src/Makefile.in
find man -name Makefile.in -exec sed -i 's/groups/.1 /' - {} \;
find man -name Makefile.in -exec sed -i 's/getpasswd/.3 /' - {} \;
find man -name Makefile.in -exec sed -i 's/password/.5 /' - {} \;
```

Instead of using the crypt method, use the more secure SHA-512 method of password encryption, which allows passwords longer than 8 characters. It is also necessary to change the obsolete /var/pool/mail location for user mailboxes that Shadow uses by default to the /var/spool/mail/ location used currently:

```
sed -i 's@#ENCRYPT_METHOD DES@ENCRYPT_METHOD SHA512@' '\'
-e 's@/var/spool/mail/@ /' etc/login.defs
```

> If you choose to build Shadow with Cracklib support, run the following:

```
sed -i 's/@DICTPATH.*@$DICTPATH@t/lib/cracklib/pw_dict@' etc/login.defs
```

Make a change to make the first group number generated by useradd 1000:

```
sed -i 's/1000/999/' etc/useradd
```

Prepare Shadow for compilation:

```
./configure --sysconfdir=/ --with-group-name-max-length=32
```

The meaning of the configure option:

```
--with-group-name-max-length=32
```

The maximum user name is 32 characters. The maximum group name is too.

Compile the package:

```
make
```
