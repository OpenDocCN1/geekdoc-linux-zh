

# EMC NetWorker

存储巨头 EMC 于 2003 年收购了 Legato NetWorker。当时，Veritas 和 Legato 是企业备份市场的两大领导者。

优点：
- 价格具有竞争力
- 服务器软件可在我们示例的每个平台上运行
- 支持多样化的客户端平台
- 流畅、集成的裸机恢复

缺点：
- EMC 产品之间存在显著重叠

## 其他替代方案

W. Curtis Preston，O'Reilly 出版社书籍《Backup & Recovery》的作者，在 backupcentral.com 维护了一个关于备份相关主题的网页（磁盘镜像产品、高级文件系统产品、远程系统备份产品、异地数据保险库产品等）。
