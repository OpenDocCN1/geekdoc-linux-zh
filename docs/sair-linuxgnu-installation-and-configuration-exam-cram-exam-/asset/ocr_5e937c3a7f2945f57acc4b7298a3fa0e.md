# Question 9

If you see an IP address of 16.52.33.235 and the network mask is 255.255.0.0, which of the following are the network and host addresses?

+   - a. Network address=16.52.33.0; host address=235
+   - b. Network address=16.52.0.0; host address=33.235
+   - c. Network address=16.52.33.0; host address=33.235
+   - d. Network address=16.52.0.0; host address=235

Answer b is correct. The 255s in the network mask distinguish the network address from the host address. Answer a would be correct if the network mask was 255.255.255.0. Because 16.52.33.0 is not the network address, answer c is incorrect. Because 235 is not the whole host address, answer d is incorrect.
