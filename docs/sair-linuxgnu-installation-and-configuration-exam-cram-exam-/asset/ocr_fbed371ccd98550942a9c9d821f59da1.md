# rmdir

You can delete empty directories with the rmdir command. The directory that you remove does not have to be based in your current directory. You can delete several levels of directories if the directory that you delete empties others. For example, with the following command, you can delete the directories named dir1 and dir3:

```
rmdir -p dir1/dir3
```

This command deletes directory dir3 if it is empty. If the only "file" in directory dir1 is dir3, this command also deletes directory dir1.

# File Management Commands

The bash shell includes a number of commands to help you read files in different ways. You can verify different types of files, and you can read files from the top or from the bottom. This read can be limited to a few lines or it can set you up to page through the entire file. You can also count the lines, words, and alphanumeric characters within a file. Furthermore, you can search through a file with the search term of your choice.

Because it is difficult to define words or lines in binary files, most of these commands work best with text files.
