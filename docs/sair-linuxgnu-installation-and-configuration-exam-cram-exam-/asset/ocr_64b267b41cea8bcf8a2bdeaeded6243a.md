# Need to Know More?

McHugh, Josh. "For the Love of Hacking." Forbes. 10 August 1998. This cover story in the self-described "Capitalist Tool" of magazines describes the reasons behind the success and perceived superiority of open source software.

Explore the Web site for the FSF, the governing body for the GNU project, at www.fsf.org. This site includes a history of the FSF as well as descriptions of free and open source software.

Browse the Web site of the Linux Documentation Project at www.linuxdoc.org, which is the central repository for Linux manuals, HOWTOs, FAQs, and a number of other book-length documents.

Investigate the Web site for the OSI at www.opensource.org, which defines the essential limitations on open source software. This site includes an annotated version of the so-called Microsoft Halloween Documents, which are internal Microsoft white papers on the open source movement.
