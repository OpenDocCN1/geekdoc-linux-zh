## About the Author

Michael Jang (LCP, MCSE) is currently a full-time writer on Linux and Microsoft operating systems. His experience with computers goes back to the days of jumbled punch cards. He has recently coauthored Linux Networking Clearly Explained (Morgan Kaufmann Publishers, 2000) and has also written MCSE Windows 98 Exam Prep (The Coriolis Group, 1999) as well as MCSE Guide to Microsoft Windows 98 (Course Technology, 1998). He has also served as technical editor for several Microsoft Help Desk books, including those on Windows NT Workstation 4, Windows 98, and Office 2000.

In his previous life as a Boeing engineer, Michael worked a variety of jobs, including project manager for the first FAA type certified In-Seat Video systems.
