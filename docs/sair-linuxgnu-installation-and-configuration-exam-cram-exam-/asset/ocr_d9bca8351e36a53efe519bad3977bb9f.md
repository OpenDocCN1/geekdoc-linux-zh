# Need to Know More?

![](bbox=[0.09, 0.14, 0.16, 0.21])

Volkering, Patrick, Kevin Reichard, and Eric Foster-Johnson. *Linux Configuration and Installation*. M&T Books, Foster City, CA, 1998. ISBN 0-76457-005-6. A step-by-step guide that covers the configuration commands in this chapter and is based on the Slackware distribution.

![](bbox=[0.09, 0.27, 0.16, 0.33])

The Linux System Administrators' Guide at www.tml.hut.fi/~viu/linux/sag is written for newer administrators. You can also find a copy of this guide through the Linux Documentation Project at www.linuxdoc.org.
