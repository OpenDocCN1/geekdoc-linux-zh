# Question 10

You're setting up a computer for a user who does a lot of intense graphics development work. If you include 128MB of RAM on that computer, how big of a swap partition do you need?

+   - a. 128MB
+   - b. 192MB
+   - c. 256MB
+   - d. 100MB

Answer d is correct. As RAM increases beyond 64MB, swap space beyond 100MB does not enhance performance significantly. The recommended size of a swap partition may vary. A few years ago, you might have been satisfied with a swap partition equal to your installed RAM. Current practice is to set up a swap partition twice the size of your RAM. However, because you're setting up a computer that already has over 100MB of memory, the basis for the other answers is not relevant. Therefore, answers a, b, and c are incorrect.
