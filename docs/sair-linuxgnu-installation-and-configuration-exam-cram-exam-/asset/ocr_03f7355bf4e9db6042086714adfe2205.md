# Question 10

Which of the following commands actually reboots your computer?

+   - a. shutdown -h now
+   - b. shutdown -c
+   - c. halt
+   - d. init 6

![](bbox=[0.8, 0.18, 0.92, 0.28])

Answer d is correct. If you run the init 6 command as root or superuser, this command moves to run level 0 (halt), and then reboots. The shutdown -h now command shuts down your computer without delay. Therefore, answer a is incorrect. Because the shutdown -c command just cancels a current shutdown sequence, answer b is incorrect. The halt command is equivalent to shutdown -h now. Therefore, answer c is incorrect.
