# Need to Know More?

![](bbox=[0.07, 0.16, 0.13, 0.22])

The Web site at http://linux.ctyme.com is Mark Perkel's index to Linux man pages. If you don't have immediate access to a Linux command line or its man pages, this Web site includes a searchable online reference. Important man pages for this chapter include printcap, lpc, lpd, lpr, and lprm.

![](bbox=[0.07, 0.32, 0.13, 0.38])

The Web site for the Linux Documentation Project at www.linuxdoc.org is the central repository for Linux manuals, HOWTOs, and a number of other book-length documents. Important HOWTOs for this chapter include the "Printing-HOWTO," which can help you print from just about any format to just about any printer, and the "Printing Usage-HOWTO," which is more focused on the actual commands that you use.
