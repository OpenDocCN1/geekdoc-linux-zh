# How to Use This Book

If you’re prepping for a first-time test, keep in mind that I’ve structured the topics in this book to build on one another. Therefore, some topics in later chapters make more sense after you’ve read earlier chapters. That’s why I suggest you read this book from front to back for your initial test preparation. If you need to brush up on a topic or you have to bone up for a second try, use the index or table of contents to go straight to the topics and questions that you need to study. Beyond the tests, I think you’ll find this book useful as a tightly focused reference to the requirements behind installing and configuring Linux.
