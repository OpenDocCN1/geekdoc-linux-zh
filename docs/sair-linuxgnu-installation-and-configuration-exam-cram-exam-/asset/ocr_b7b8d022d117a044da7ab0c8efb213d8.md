# COAS

Caldera has several GUI user creation utilities including LISA, COAS, and Webmin. Each of these utilities allows a system administrator to configure everything from networking to user accounts. You can set up a new user account in COAS as shown in Figure 11.2.

# YaST

S.u.S.E. Linux has its own proprietary all-in-one configuration package known as YaST (Yet another Setup Tool). Like Linuxconf, you can open it in a command-line interface or in the GUI.
