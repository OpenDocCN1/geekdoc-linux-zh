# Question 5

Which of the following configuration utilities can help you set up your keyboard and mouse as well as your video hardware?

+   - a. SuperProbe
+   - b. XF86Config
+   - c. XF86Setup
+   - d. Xconfigurator

Answer c is correct. The XF86Setup utility includes sections that help you configure mice or pointing devices and keyboards. And it helps you configure your monitor and video controller. Because the SuperProbe utility just probes for your current video hardware, answer a is incorrect. XF86Config is not a valid configuration utility (it's xf86config); therefore, answer b is incorrect. Because the Xconfigurator only allows you to configure your monitor and video controller, answer d is incorrect.

Why can you shut down a window manager, such as KDE or GNOME, without rebooting Linux?

+   - a. A window manager is just another application.
+   - b. Window managers are set up to respond to the Ctrl+Alt+Backspace command by shutting down.
+   - c. When you shut down a complete window manager like KDE or GNOME, you have no choice. You have to halt or reboot Linux.
+   - d. Window managers include special commands in their menus that allow you to log off.

Answer a is correct. Because window managers are applications, they do not directly affect the kernel. When they lock up, you can shut them down without rebooting Linux.
