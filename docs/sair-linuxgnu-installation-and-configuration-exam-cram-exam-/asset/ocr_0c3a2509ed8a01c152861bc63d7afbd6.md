Answer c is correct. When you use the ln command, you're creating a "hard" link between files. As long as that link is between files on the same volume, the files are functionally identical. Any change that you make to one file is also made to the other file. The link is represented by two files with the same inode number. Files created with the cp command do not have the same inode number; therefore, answers a and b are incorrect. (You may note that files created with the cp -p command do have the same inode number.)
