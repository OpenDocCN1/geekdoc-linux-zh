# ## 17.5    Future Enhancements

Several significant enhancements will be available in future releases of Cluster CoNTroller.  These include

+   - complete COM+ support,
+   - advanced user interface tools using COM+,
+   - support for multiple jobs per node,
+   - advanced tools for better accounting of resources, and
+   - advanced tools for improved cluster administration.
