Figure 10.9 Schematic representation of collective data movement in MPI.

The fundamental idea in MPI’s approach to paralell I/O is that a file is opened collectively by a set of processes that are all given access to the same file. MPI thus associates a communicator with the file, allowing a flexible set of both individual and collective operations on the file.
