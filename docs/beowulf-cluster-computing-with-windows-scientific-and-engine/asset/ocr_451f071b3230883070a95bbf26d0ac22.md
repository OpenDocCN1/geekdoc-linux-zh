**DedicatedScheduler**: the name of the dedicated scheduler for your cluster. This setting must have the form

```
DedicatedScheduler = "DedicatedScheduler@full.host.name.here"
```

# ### 14.6.1 Remote Configuration and Control

All machines in a Condor pool can be remotely managed from a centralized location. Condor can be enabled, disabled, or restarted remotely using the `condor_on`, `condor_off`, and `condor_restart` commands, respectively. Additionally, any aspect of Condor’s configuration file on a node can be queried or changed remotely via the `condor_config_val` command. Of course, not everyone is allowed to change your Condor configuration remotely. Doing so requires proper authorization, which is set up at installation time (see Section 14.4).
