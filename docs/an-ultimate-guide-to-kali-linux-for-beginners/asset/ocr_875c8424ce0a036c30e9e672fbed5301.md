# Linux Commands

We will be discussing some of the basic commands which are required to get started in Kali Linux.

+   1. cd

This command is used to change directory in the terminal. This is used with the path of the directory, for example, Changing current directory to the desktop directory, we would use
cd Desktop/

![](bbox=[0.1, 0.42, 0.9, 0.73])

For going one directory back, use the command
cd ..
