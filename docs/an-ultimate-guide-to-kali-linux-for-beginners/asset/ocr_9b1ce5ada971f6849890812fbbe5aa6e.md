# **Setting Up Linux**

If you want to be a serious penetration tester or ethical hacker, then you would have to master the Linux commands lines as they are the basic requirements in starting an attack.

Terminal, as the name suggest, is an application which interfaces with the system with help of command lines. Unlike Windows or Mac OS, Linux don’t offer graphical user interface with icons and panels to perform various tasks like copying a file, deleting a file & even creating a file or script.

Terminal offers the commanding interface to type such commands which we will discuss in the next sections.

If you are a window user, then you might know that window also has its own terminal named as CMD (Command Prompt). The terminal in Linux is somewhere same as that.

So, first of all fire up your Kali Linux by clicking “Start” in the Virtual Box.
