
### 11. mkdir

This command is used to make a new folder (directory) in any place.

Let's make a folder by typing the following command and press enter.

```
mkdir NewFolder
```

![](img/d05aeb75f1c36187913c3b410abf92b1_32_0.png)

This will create a new folder named “NewFolder” in the active directory and the icon will be displayed in the active directory (Desktop in our context).

### 12. rm

This command is used to remove files or directory from the active directory.

The command to remove files and folder are a bit different.

- a.) For removing the files, type the below command and hit enter.

```bash
rm newfile
```

![](img/d05aeb75f1c36187913c3b410abf92b1_32_1.png)

This command will remove the file named “newfile” which we have created in the previous section. Similarly, you can delete other files in different directories, but make sure you DO NOT REMOVE ANYTHING IN THE “/” or system files folders.

- b.) For removing folders, type the below command and hit enter.

```bash
rm NewFolder -r
```

![](img/d05aeb75f1c36187913c3b410abf92b1_33_0.png)

This command will remove the folder named “NewFolder” from the desktop.

There is one thing which you should be aware of that, while writing the commands make sure that you check the case of the letter, whether they are upper case or lower case because Linux distros matter a lot on the case of the file.

For example, “Newfolder” and “NewFolder” are completely different things when entering command in the terminal. You might get “rm: cannot remove 'Newfolder': No such file or directory”. So, make sure you type all the letters carefully.
