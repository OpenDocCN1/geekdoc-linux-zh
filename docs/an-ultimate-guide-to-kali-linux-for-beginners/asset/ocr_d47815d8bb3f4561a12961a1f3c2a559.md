b.) For removing folders, type the below command and hit enter.
    rm NewFolder -r

![](bbox=[0.11, 0.27, 0.86, 0.53])

This command will remove the folder named “NewFolder” from the desktop.
    There is one thing which you should be aware of that, while writing the commands make sure that you check the case of the letter, whether they are upper case or lower case because Linux distros matter a lot on the case of the file.
    For example, “Newfolder” and “NewFolder” are completely different things when entering command in the terminal. You might get “rm: cannot remove 'Newfolder': No such file or directory”. So, make sure you type all the letters carefully.
