import is complete, you need to setup a few things. Go to settings of the imported Virtual Machine.

![](bbox=[0.147, 0.203, 0.855, 0.3])

Click on System and increase the base memory to about half of the system memory.

![](bbox=[0.153, 0.407, 0.833, 0.812])

Now, go to “Processor” tab and increase the processors to about of your system capacity. This is essential for Kali Linux to function without any glitches.
