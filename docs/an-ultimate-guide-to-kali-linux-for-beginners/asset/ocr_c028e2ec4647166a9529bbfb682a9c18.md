In the terminal, write the following command and hit enter.

```
```
cd /media/cdrom/
```
```

Now Type the following command and hit enter.

```
```
sudo sh VBoxLinuxAdditions.run
```
```

It will now ask for the sudo password for kali, type “kali” from the keyboard. It will not show the password you are typing but you have to confidently type “kali” from the keyboard and press enter.

A few commands processes will appear, if it asks for “yes or no”, type “y” and press enter.

The Virtual Box Linux additions will now be installed successfully on your Kali Linux Machine.

Now, restart your Kali Linux, either by entering the command “reboot” in terminal or using the power icon in kali.
