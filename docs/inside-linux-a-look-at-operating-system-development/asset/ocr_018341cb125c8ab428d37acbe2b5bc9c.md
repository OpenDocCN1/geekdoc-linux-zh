where making more frames available to process i will not reduce the number of page faults it suffers.

Many systems exhibit a load-performance curve, shown as a dotted line in Figure 5.31, wherein a greater presented demand results in more work getting done—up to some limiting value. Other systems, virtual memory being one of them, follow the same curve for a while, then abruptly taper off. This load-performance curve is shown as a solid line in Figure 5.31. The base cause for this abrupt drop is that the system crosses a demand threshold beyond which it is spending more time servicing the requests to load a different page than it is executing the user processes. When the system is in this latter mode of operation, it is said to be *thrashing*.
