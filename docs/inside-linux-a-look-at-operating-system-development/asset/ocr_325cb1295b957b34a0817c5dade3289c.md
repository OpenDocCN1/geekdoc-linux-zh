# 4.3  Peripheral Management

Scheduling can be characterized as “processor management”.  In the ex-amples in the previous sections, the focus was on keeping the processor busy and preventing processes from interfering with one another.  A sys-tem kernel must also ensure peripherals are used easily and effectively. Part of this duty can be relegated to run-time libraries, but ultimately the system kernel is involved.  Section 5.3 discusses some of the imple-mentation details.

One of the most significant design decisions is where the boundary (between the system kernel and the run-time library) should be placed.
