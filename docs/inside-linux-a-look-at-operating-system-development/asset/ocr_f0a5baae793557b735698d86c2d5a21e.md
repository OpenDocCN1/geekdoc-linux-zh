Note that individual disk blocks are listed, even if they are con-
tiguously located. That is at variance with systems which point to
file extents. With four byte pointers and 512 byte data blocks, this
yields a maximum file size of 512 $(10+128 \times(1+128 \times(1+128)))$ or
1,082,201,088 bytes. By increasing this to a 4096 byte data block, the
maximum file size can grow to $4096 \times(10+1024 \times(1+1024 \times(1+1024)))$
or 4,402,345,713,664 bytes, but because the size field of the inode is
