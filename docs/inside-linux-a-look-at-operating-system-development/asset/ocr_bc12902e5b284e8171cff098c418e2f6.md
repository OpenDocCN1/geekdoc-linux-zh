One of the flaws with POSIX is that the standard cannot be freely copied and, therefore, it is not in everyone's hands. Contrast this to the Internet RFCs (request for comments), which define such things as the TCP/IP protocols and have unlimited distribution.

# 5.7 Bootstrapping the Kernel

A system kernel comes into operation in stages. Although the following sequence is not strictly universal, it is common enough that most systems have a counterpart to each step.

# 5.7.1 Processor Start

It doesn't matter if the processor has a complex instruction set (CISC) implemented by internal microcode or a reduced instruction set (RISC) implemented by logic gates; at sometime the processor must complete its initialization and begin “earning its keep”. While computers may display something of their internal state during start (for the sake of the user), they will eventually fetch their first instruction. Back in the olden days (was it really less than twenty years ago?) a user would enter an address via switches on a front panel and strobe that value into the register holding the instruction pointer. Nowadays, the single chip processors are designed to fetch their first instruction from one well known address. The Intel x86 family of computers favor 0xFFFFFFF0, the Motorola M68K family of computers favor address 0. The system designer merely has to ensure there is memory at that location with the appropriate bootstrap routine. This is most often done by attaching a read-only memory (ROM) at that location.
