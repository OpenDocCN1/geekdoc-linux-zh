# 1.2.11 Linux Uses Cost Effective Hardware

The personal computer hardware market is both very competitive and very large. Although Linux is dramatically different from the most common commercially produced operating systems, it can share the cost and performance benefits of the mass production of the hardware. Linux is not limited to the x86 architecture. A list of other systems is given in Section 1.4.1. The hope is that these architectures will also offer good price/performance ratios.
