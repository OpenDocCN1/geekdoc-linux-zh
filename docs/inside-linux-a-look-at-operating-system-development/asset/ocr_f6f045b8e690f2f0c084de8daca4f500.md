When files are created, the user must specify their maximum size so that the system can find an empty space big enough. When the file is closed, the system completes the bookkeeping by noting the final size and perhaps creating an empty space entry for what wasn't used. It is difficult to anticipate the length of most files, so the maximum size is not really indicative of the final file size. It also becomes ever more difficult to find space for a file as the filespace becomes fragmented.

**Dynamic Allocation –Support of Growing Files** These shortcomings inevitably led to file systems which allocate file extents that are somehow linked together. Of these, there are two major approaches: one which places a pointer to the next extent in each extent and the other which places all the pointers in the directory. (Shown in Figure 4.11.) The former approach has few desirable characteristics: it does not limit the number of portions in a file and the directory entry does not have to be reread to locate additional data blocks. The system can trivially extend a file by linking in another extent.
