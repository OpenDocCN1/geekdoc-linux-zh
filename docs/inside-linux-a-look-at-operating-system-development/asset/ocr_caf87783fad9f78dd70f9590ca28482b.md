```
#!/usr/bin/sed -f
s/good/bad/g
/mediocre/d
```

Since *awk* uses the *-f* option in the same way as *sed*, we can write an *awk* script in the form:

```
#!/usr/bin/awk -f
{print $2; sum++}
END {print sum}
```

# ### Recursion

Another note should be made about shells as interpreters of scripts: each script is processed independently and, therefore, it is possible to have nested and recursive script invocation.

No specific extension is necessary to support this feature, it is a natural side-effect of the ease with which processes can be created and controlled.

Other systems do not invoke a new process and therefore scripts cannot nest or be called recursively.
