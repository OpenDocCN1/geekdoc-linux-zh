# # User Interface

A typical computer user's view of an operating system is based on the commands entered on a keyboard or through a graphical user interface involving windows, icons, mouse motion, pointers, and button presses. For that reason, we will first explore Linux from this user perspective. This will develop into a more formal characterization of operating systems in the next chapter and then Part II will look at Linux from the programmer's perspective.

# ## 3.1 Command Line Interface

Of all methods of user interaction, the command line interface is easiest to implement. It also provides great utility while using modest computer resources. For that matter, the command line interface is still closest to the original spirit of Unix development noted in Section 2.2.6: write programs that handle text streams, because that is a universal interface.

Linux has several different shells and hundreds of application programs which interact with the user via an alphanumeric display and keyboard. ${ }^{1}$ Each of these shells and programs has a different command line interface because Linux, like most other Unix and Unix-like systems, does not have a uniform command language.
