# Segmentation and Paging

The two methods of mapping can be combined to enjoy the advantages of both. The system can acquire fine control over access and convenient use of memory by using memory segmentation to build a linear address that is then paged. Figure 4.21 shows this composite without the limit checking and translation look-aside caching.
