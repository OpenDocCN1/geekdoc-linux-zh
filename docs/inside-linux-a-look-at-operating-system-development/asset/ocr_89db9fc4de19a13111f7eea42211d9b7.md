Since most computer programs spend a great deal of time waiting for

A variant to this theme employs the many personal computers on
the net as X servers.

The utility of the X model becomes more apparent when one con-
siders a configuration where clients of different types hosted on different
machines all can interact with the user through the X server. One can
use a large-scale computer to perform simulations and plot the output,
another system can be used simultaneously for text editing and type-
setting, and the workstation's computer can be managing the windows.

One can also have a more realistic visual appreciation for a multi-
tasking system by displaying multiple active windows, one per active
process. It's quite easy to monitor the progress of an application when
its results are scrolling on a window to the side of the display.
