# The Operating System Kernel

As seen in the previous chapter, one view of a system kernel is through the interactive user interfaces associated with that system. The programmer sees a system kernel from a different perspective, one based on the system calls which can be made from within a program. This viewpoint is the “true” one because the user interface (the command line interpreter or GUI) can be changed at will and the implementation inside can be changed without disrupting the user.

```
#include <sys/types.h>
#include <unistd.h>

int main (int argc, char **argv)
{
       (void) write(1,"hello world\n",12);
       return 0;
}

```
