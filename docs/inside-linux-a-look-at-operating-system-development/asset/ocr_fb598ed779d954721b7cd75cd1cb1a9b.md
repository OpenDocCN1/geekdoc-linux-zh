This problem leads directly to a goal called the *inclusion property*, which states that a larger memory shall hold all the pages that a smaller memory would hold at any point in the system’s execution history. The LRU algorithm described below satisfies this property.

**LRU algorithm** Execution traces show that when programs reference some location, that location is more likely to be referenced again in the near future and other portions of code and data remain unused for significant periods. Although the choice of the oldest page in memory (as is done by the FIFO algorithm) might appear to be a good idea, it ignores any *locality of reference*, i.e., the tendency of the system to refer to pages which it has recently referenced.
