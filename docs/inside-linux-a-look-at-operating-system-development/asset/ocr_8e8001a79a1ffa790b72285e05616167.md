# 2.3.2 Source Distribution

Another, even more significant, feature of Minix was that it was distributed in source form. This allowed, even encouraged, students to modify the system.

This concept has been extended so that Linux source is not only published, but it is permitted in commercial applications without payment of any royalty.

# 2.4 Others

A number of other historical systems have made contributions which have become an essential part of Linux.

# 2.4.1 Multi-User (Timesharing)

In the mid to late 1960s, while major computer centers were focusing on wringing the most performance out of rigidly structured batch processing environments, the Compatible Time-Sharing System (CTSS) and the Dartmouth Time Share System offered interactive access to computing to a large community of simultaneous users.

The intent of these services was to parcel out the power of the system to a number of users with varying needs for the system. Users were able to use the computer for more than compiling and computing—they could use it for editing files, communicating with other users, etc.

This model of service prompted the development of Multics, Unix and Linux⁵.
