# Inodes

An inode defines a file. Foremost, it shows the file's type—ordinary file, directory, special device file, etc. It records who owns the file, both individually and by group, and it contains information about when the file was created, last accessed, and last modified. Inode entries referencing data files or directories contain information about file size and pointers to the data. The inodes are grouped together on the disk and are indexed as elements of a table. (The reader may wish to look at /usr/src/linux/include/ext2_fs.h for details.)

If we look inside an inode, we also see a link counter, fields to support an access control list, and performance enhancing information such as a block counter and fragment description data.
