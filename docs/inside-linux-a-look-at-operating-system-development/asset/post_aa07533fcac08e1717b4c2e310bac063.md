## HIDDEN
At the moment, my system has twenty-eight entries in the kernel's dispatch table which do not map exactly to a sub-routine in the run-time library. Some of these entries are called after the routines in the run-time library perform significant calculations. Others are hidden until a new run-time library is distributed, but they may be used directly by developers until then.

# Biography

- **Gordon Bell** — V.P. of Engineering at DEC. While at DEC, he played an important role in the development of the PDP-11 and VAX-11 series of computers. In spite of DEC's limited support of Unix on these systems, these systems were the foundation for Unix development for over 15 years.

- **Stephen R. Bourne** — Author of the Bourne Shell. Much to the consternation of Unix fans, there were two “Stephen R. Bourne”s at Bell Labs. A trivia quiz asked the phone extension of this one.

- **Fred Brooks** — Leader of the OS/360 project and author of the Mythical Man-Month, a commentary on large software development products. Dr. Brooks is now involved in virtual reality systems at the University of North Carolina.

- **John Lions** — Author of book which examined the early Unix system kernel, published by the University of New South Wales for students of operating systems theory. Copies of this book have been widely distributed.

- **Dennis Ritchie** — Unix creator at Bell Labs. His name is generally paired with that of Ken Thompson. If one had to make a distinction, Ritchie has shown an inclination towards languages and Thompson towards the kernel.

- **Richard Stallman** — Founded the Free Software Foundation to promote the creation and distribution of software which is not encumbered by the commercial restrictions. FSF sponsors GNU software.

- **Andrew Tannenbaum** — Author of Minix. This operating system was the spark which lead to Linux. Dr. Tannenbaum is on the faculty of Vrije Universiteit, Amsterdam, Netherlands.

- **Ken Thompson** — Unix creator. See entry for Dennis Ritchie.

- **Linus Torvalds** — Author of Linux kernel. The Linux system grew out of Torvalds’ efforts to learn how the Intel 386 memory management could be used in a virtual memory system.

- **Alan Turing** — Pioneer in theory of computing. While working on the Enigma project, Turing made major contributions to the analysis of computation. His creation of a universal machine provided the foundation for an entire field of study.

## SH

```
command:
if list then list
{ elif list then list }*
{else list } fi
case word in [pattern list;]* esac

while list do list done
for name in word ; do list done
for name in $@ ; do list done

simple_command
list:
pipeline ;
pipeline ; list
pipeline & list
pipeline && list
pipeline || list
pipeline:
command
command | pipeline
```

## KSH

```
if list then list { elif list then list }*
case name in ( { word { | word } ) list ; }* esac
list:
cond;
cond; list
cond & list
cond:
pipe
pipe && cond
pipe || cond
pipe:
statement { | statement }*
```

## BASH

```
if list then list
[ elif list then list ]*
[else list] fi
case word in [ pattern [ | pattern]*) list ; ] ... esac
pipeline:
[!] command [ | command]*
list:
pipeline ;
pipeline ; list [; & or <newline>]
pipeline & list [; & or <newline>]
pipeline && list [; & or <newline>]
pipeline || list [; & or <newline>]
```
