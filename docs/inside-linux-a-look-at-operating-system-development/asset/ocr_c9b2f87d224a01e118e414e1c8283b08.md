# 1.3.1 Linux Is Not a Micro-kernel

The term “micro-kernel” suggests that there is an even more fundamental kernel-like element within the kernel. The basic premise to a micro-kernel is that the kernel can be built from many nearly-orthogonal specialized kernel processes. These processes communicate by passing messages through the micro-kernel to one another.

The MERT system was developed at Bell Laboratories according to these principles[33]. Others have followed, including a successful commercial product, QNX$^{6}$, which has been in production since 1980; Plan 9$^{7}$ from the creators of Unix at AT&T Bell Laboratories; and VSTa$^{8}$, a copylefted$^{9}$ system originally written by Andrew Valencia.

MACH$^{10}$ is a micro-kernel-based operating system from Carnegie Mellon University which has been under development since 1985. It has explored a number of ideas including

+   - kernel level support for light-weight threads

+   - support for multi-processors

+   - support for different operating system interfaces, including BSD Unix and Linux$^{11}$
