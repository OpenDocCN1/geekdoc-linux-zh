# 8.2 Support of Unusual Peripherals

**CD-ROMs** This device is not really that unusual, but the story behind the creation of the SCSI driver is interesting. Part of the driver depends on code common to all disks, but part of the protocol must deal with the different request-reply sequences that are device dependent. Someone posted a query about the CD-ROM sequence in a news group, someone else posted a list based on his work on a driver for MS-DOS, then someone else posted a patch file for the driver which incorporated this sequence. All of this discourse occurred within 48 hours—perhaps a record for adding support for a new device!

**CD-ROM jukebox** This is a popular device for holding large collections of software on-line. Jukeboxes with SCSI interfaces are trivially added to Linux systems. The only requirement is that the kernel must be configured to support multiple LUNs (logical unit numbers). Once this is done, each LUN behaves as a distinct SCSI device. References to a LUN automatically trigger the jukebox to load the appropriate CD-ROM.

**CED 1401** This laboratory interface has a package¹ for user program control.

**Precision clocks** There is great advantage in keeping the system’s clock correct. If the system is constantly connected to the Internet, the ntp² utilities can be used to synchronize the system’s clock against other standards. As a bonus, this same software has support to talk to a number of specialized clocks which receive broadcast radio signals or have a precision time source inside.
