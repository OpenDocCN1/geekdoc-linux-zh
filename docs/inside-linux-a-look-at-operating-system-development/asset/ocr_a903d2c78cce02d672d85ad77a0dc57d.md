# ## Language independent standards

The initial POSIX standard was defined in terms of the C language. Additional standards have been developed describing the portable operating system in terms of other languages. There is an effort to do this in a manner which is independent of any language by the use of careful non-language specific descriptions of the data being passed and the actions performed3.

However, examples in this book will be in terms of C, since this language is most widely available on Linux systems and because the language independent standard is neither complete nor easy to use.
