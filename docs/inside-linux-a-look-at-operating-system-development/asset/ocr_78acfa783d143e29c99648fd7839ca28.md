# Networks

It isn't clear whether network support belongs inside or outside the kernel. Arguments can be made for either case. In the case of Linux (and most Unix systems), major elements of the networking code reside inside the kernel and other elements are user-level programs.

# ## 6.1  User Process vs. Kernel Feature

Although it is not really necessary to access the network hardware from within the kernel, it does improve performance quite a bit to put the lower layers in the kernel. Layers will be discussed in the next section, but suffice it to say that the closer the code is to manipulating the raw hardware, the stronger the case for kernel mode code.

As the layers move away from the hardware, it becomes more practical to execute the code as a user process.

# ## 6.2  Advantages of ISO OSI Model

The International Standards Organization (ISO) developed a model called the Open Systems Interconnect Reference Model. It describes a network in terms of seven layers such that any layer is described in terms of its interface with adjacent layers.
