Each machine code instruction, be it a jump, subroutine call, memory load or store, is stored with the target address of zero. An additional entry at the end of the object file describes the instruction format, points to this machine code, and names the required address. When the linker or loader binds the appropriate library code to the object file, it will fix up these references by replacing the zeros with the addresses in the proper form.

The linker, called ld, is invoked from the command line or it is called by the last stage of the compiler. (It is unfortunate that the program, which does linking, is called the loader, but we’ll just have to live with that unfortunate misnomer.)

# a.out/jump-table

The older style executable files (called a.out) contain six distinct elements shown in the left part of Figure 7.2. When the program is executed, the system loads the TEXT (which contains the executable code) and DATA (which contains pre-defined data) parts into memory. (Shown by the solid lines.) BSS, which stands for “block started by symbol”, is a value in the header which specifies the amount of additional memory which must be allocated for global data (with no pre-defined value).
