# 0.2.4 Code

Most of the code examples are given in ANSI4 C. In a few cases, I'll be a bit loose with the language to allow assembly language constructs to drift into the examples.

# 0.2.5 Typesetting

This book was written in L²TeX, with extensions for arbitrary hyper-text links and raw HTML (hyper-text markup language). The on-line version (an HTML document produced via L²TeX²HTML⁵) can be read with a Web browser which allows you to skip ahead and back with ease as well as connect to other on-line sources. The printed version shows hypertext links as footnotes.

Commands and file names are commonly displayed in typewriter font. Special terms are displayed in a special font and an entry in the index will lead you to a definition or explanation of the term.
