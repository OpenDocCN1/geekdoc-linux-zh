# 2.2.4 File System

As with Multics, the Unix file system is a hierarchy of directories containing directories, plain files and special files for peripheral access. All input and output (I/O) is performed via system calls such as open, close, seek, read, and write.

![](bbox=[0.21, 0.26, 0.77, 0.46])

Figure 2.2: File system hierarchy

Unix file system entries are each defined by an inode, described more fully in Section 5.3.1. This structure contains information about the

+   - type
+   - ownership
+   - access control
+   - creation, modification, and access times
+   - size
+   - location

If the type is a plain file, “location” refers to a hierarchy of direct and indirect pointers to disk blocks containing file data. This scheme provides higher performance for small files than a fully indirect scheme
