# ### 8.0.4 Some More Historical Background

The goal of the operating system is to ease the programmer's burden. It must hide the details of device programming, it must protect users from one another (and from their own mistakes), and it must equitably manage system resources.

At one time, these goals were compromised on personal computers because of limited resources (and perhaps because of the shortsightedness of the designers).

Hardware performance has been growing exponentially for many decades. (Moore's Law notes that it doubles every 1.5 years.) This improvement has caused us to constantly revise our approaches to problems. For instance, it has been noted earlier that bit-mapped displays weren't practical until memory prices fell low enough. The decreasing cost of memory also means that programming styles have shifted from “do it with as little memory as possible” to “make sure it's correct and easy to understand”.
