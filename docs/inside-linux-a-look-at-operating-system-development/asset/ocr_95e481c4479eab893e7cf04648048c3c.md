Linux is undergoing rapid change. New kernel versions are distributed about once a week. Some of the changes are due to fixes, but most are new features or improvements. In addition, there are major new projects underway which will offer symmetrical multiprocessing, and support for MS-DOS and MS Windows programs.

# ## 1.2 Features

Linux has a multitude of attractive features. A detailed examination of all of them would fill this book, but the following sections give a brief overview. In some cases, the section will also explain *why* some feature is useful. (This explanation is necessary because some of these features may be foreign to the reader's experience.)

# ### 1.2.1 Linux Is Free

Some software is expensive. Developers have found that they can profit by selling a small number of licenses at a high price. Other developers have discovered that they can profit by selling a very large number of licenses at modest price. Some have gone so far as to cut marketing and distribution cost to nothing and distribute their product free, asking that the users voluntarily send license fees directly to the developer.

The Free Software Foundation$^{3}$ noted that software redistribution was limited by licenses. It also noted that all of the traditional licensing methods have one thing in common: the source is rarely available to the end user.
