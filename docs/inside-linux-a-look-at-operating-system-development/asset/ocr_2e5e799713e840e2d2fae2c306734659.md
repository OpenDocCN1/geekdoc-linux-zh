Normally a directory entry "." refers to the current working directory and ".." refers to the parent of the current working directory. The only exception is when "." is used at the root directory; for practical reasons this also refers to the root directory.

The Newcastle design changes part of this last convention, so that a leading "/..//" in a file name indicates network access. The next element in the file path name is a network node identifier and the remainder of the file path name is an absolute path name on that remote system. For example "/../faraway/home/fred/" refers to the directory "/home/fred/" on the system ",faraway”.

Since most systems at the time of its distribution had only static linking, utilities had to be rebuilt to use the Newcastle connection[8]. This disadvantage was balanced by the fact that the kernel did not have to be modified.
