GPIB Another interface for laboratory instrument control is the General Purpose Interface Bus, defined by the IEEE488 standard. There is at least one driver $ ^{5} $ for this interface.

MIDI Although this is not normally a part of Unix systems, the common availability of this interface for the PC has led to the early inclusion of a driver in the kernel.

Now that loadable driver modules are a configurable feature of the Linux kernel, users find adding new drivers to be reasonably straightforward—especially if they can be derived from existing drivers.
