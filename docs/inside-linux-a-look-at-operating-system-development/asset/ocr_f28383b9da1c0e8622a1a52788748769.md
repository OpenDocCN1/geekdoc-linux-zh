# Dynamic Linking

Until recently (the last ten years for many Unix systems and the last two years for Linux), the linker would build an executable image which had resolved all external references. That has changed, and for over a year Linux systems have had dynamic linking.

Dynamic linking and shared libraries, while distinct concepts, are invariably associated in practice.
