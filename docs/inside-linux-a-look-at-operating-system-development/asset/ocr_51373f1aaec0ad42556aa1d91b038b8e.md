The ISO OSI model was created after the start of the Internet, so it should come as no surprise to discover that the Internet cannot be described exactly in terms of this reference model. Nonetheless, the model of layering protocols around/within other protocols has proved to be most useful.

# ## 6.3 The Internet Model

There is no universal agreement on how to describe the Internet implementation in terms of the reference model, but nearly everyone agrees the seven layers are a bit excessive. Generally the seven layers are reduced to the four layers corresponding to the major parts of most implementations.
