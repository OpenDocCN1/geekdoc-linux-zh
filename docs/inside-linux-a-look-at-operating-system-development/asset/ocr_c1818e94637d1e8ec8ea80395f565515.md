# Device handlers

Just as files can be opened, closed, read and written, the user can access devices using the same system calls.

The devices appear as entries in the file system, typically with names such as /dev/hda0, /dev/sda0, /dev/cr0. /dev/tty0, etc. Because the file type is character or block I/O, some of the rest of the fields in the inode have different meanings. For instance, instead of showing the file's length, the inode holds what is called the major number and minor number for the device. The major number identifies which device driver inside the kernel will process the system calls and the minor number identifies which port, partition, or other subcategory of the device is being accessed.

![](bbox=[0.1, 0.42, 0.9, 0.64])

Although the file system code is normally the only code which accesses the disk, privileged users have direct access to block I/O (structured I/O) devices as well as character I/O (unstructured I/O) devices. More commonly, device access is to serial ports, keyboard and console, tape drive, floppy drive, line printer, etc.
