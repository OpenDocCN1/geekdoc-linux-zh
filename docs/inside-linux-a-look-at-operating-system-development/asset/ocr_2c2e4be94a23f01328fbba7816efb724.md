The object file cry.o is compiled with the command

```
gcc -fPIC -c cry.c
```

and then built into a sharable library with the command

```
gcc -shared -o libcry.so cry.o
```

The user program, in this case yet another "hello world" example, is compiled from the source$^2$

```
```c
#include <stdio.h>
#include "cry.h"
#define BUFISIZE

int main (int argc, char **argv)
{
  char ostr[BUFISIZE];

  strncpy(ostr, "hello world\n", BUFISIZE);
  set_key(argv[1]);
  (void) printf(encrypt(ostr));

  return 0;
}
```
```

and then an executable is built with the command

```
gcc -o hw.dynamic hw.o /file_pathname/libcrys.so
```

(The library location must be given as an absolute pathname or it must reside in some place well-known to the loader.)
