# 3.2.3 Window Manager

It would be a great bother to have each client process keep track of all the things which can be done to a window after it is open. There is little sense in duplicating this function in all the different clients. It is best to leave this job to a single specialized client.

Usually there is one client, called a window manager, which takes control of the root window (the one which is linked to the entire display) and controls size and position of the other windows. Since the root window is the bottom-most window, all unprocessed events end up being sent to the window manager.
