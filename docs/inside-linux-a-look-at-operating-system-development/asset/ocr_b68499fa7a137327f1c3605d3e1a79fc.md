**8 mm** This is the same format as the small video tape. The dominant manufacturer in this market, Exabyte, provides drives which can store 2–5 Gbytes of data on a single tape.

**4 mm** This is the same format as the Digital Audio Tape. Several manufactures co-operated in creating the standard for recording data on these tapes. While these drives hold less data than the 8 mm drives, some features such as “fast seek” are a bonus.

# ### 8.1.4 Asynchronous Communication

**individual ports** Almost every personal computer comes with one or two asynchronous ports. These are typically driven by single chip controllers, such as the 8250, 16450 and 16550, which provide character buffering, bit stream serialization and modem control. They are often limited to speeds below 50 Kbits/sec.

**multiplexor ports** Larger systems have a single interface card which provides support for a number of serial ports. These cards offer higher performance and a smaller burden to the system (in terms of interrupts/char, number of control ports, and number of interrupt vectors).

# ### 8.1.5 Network Communication

Until recently, the standard network connection for Linux systems took two forms:

+   * Ethernet
+   * serial async (SLIP or PPP)

The Ethernet offers 10 Mbit/sec speeds, but is limited to a maximum of 500 meters (or a bit more with the use of bridges). The serial async connection has no such distance limits, but performs no better than 28.8 Kbit/sec.

Linux now supports, or will soon support, direct connections to:

+   * Token Ring
