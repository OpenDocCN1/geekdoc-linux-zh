A number of good ideas have leaked into C from other languages. The latest C language specification includes mechanisms to better support separate compilation as well as more complete specification of standard run-time support for the language.

Some of these changes are in the implementation, not the language specification. For instance, type checking is more rigorous and warnings are more readily emitted by the compilers.

System kernels are now seen as a collection of nearly independent modules working in co-operation. Functions in these modules operate on rather complex structures, but the details can be safely hidden from the caller. This has lead to the suggestion that Linux should be rewritten in a language such as C++ which supports concepts such as abstract data types, object oriented programming, separate compilation, etc.
