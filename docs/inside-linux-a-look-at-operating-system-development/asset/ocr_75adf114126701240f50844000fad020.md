While segmented memory makes better use of physical memory than either non-mapped memory or single base and bounds remapping, it is still restrictive because the size of memory segments cannot be changed with ease.

The memory fragmentation problem shown in Figure 4.13 is not really solved by hardware support for segmented memory. The mapping hardware only relieves the system kernel from relocating (patching) the program and data when they are loaded into the system. Although memory is accessed indirectly through mapping hardware, each segment must reside in contiguous memory. This requirement for contiguous memory also makes it very difficult to extend a memory segment (such as one used for the stack or heap memory).
