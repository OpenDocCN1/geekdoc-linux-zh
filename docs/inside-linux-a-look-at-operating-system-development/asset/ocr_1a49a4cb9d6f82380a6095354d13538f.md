# 6.3.2 UDP/IP

A large number of applications rely on using the IP protocol with the User Datagram Protocol (UDP), defined in RFC 768. As can be seen from Figure 6.5, the UDP datagram has fewer control elements. This is because it is connectionless, i.e., there is no sense of a long term connection between the sending and receiving processes. The non-electronic analog is communication via postcards. As with postcards, there is no assurance of reliable delivery and, for this reason, the application process may want to impose its own scheme of acknowledgment and retransmission. But then some applications, such as status reporting, can work quite well with occasionally lost data.
