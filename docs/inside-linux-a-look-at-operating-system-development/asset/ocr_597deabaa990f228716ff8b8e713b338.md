**Hardware support** The careful reader may have noticed a likely disadvantage to a paged memory system: each memory reference appears to generate another reference to get the page table entry. Some systems, such as the DEC PDP-11, hold the entire page table in registers. This is practical because the PDP-11 has a small address space (64 Kbytes) holding only eight pages (of 8 Kbytes each). (To be precise, the PDP-11 memory management is an analog of paged memory and segmented memory. Each page also has a valid length, just like the memory segments mentioned earlier.)

It is much more typical to store the page table in memory and then rely on *translation look-aside buffers* (*TLBs*) held in a special *associative memory* which caches a subset of the page table entries. (Associative memory is addressed by part of its contents, in this case the logical address, to provide a value, in this case the physical address.) Figure 4.20 shows when a logical address is generated, the page number is checked against TLBs to look for a match. If a match is found, that page table entry is used. Otherwise, the page table entry is fetched from the page table in memory.
