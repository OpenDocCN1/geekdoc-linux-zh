# 5.4.2 Thrashing and Level Of Multiprogramming

At the time of this writing, Linux newsgroups are discussing at length the problem with run-away processes which steal resources from other processes. (Linux, like most other Unix implementations, uses a form of global replacement.)

![](bbox=[0.2, 0.28, 0.8, 0.65])

Figure 5.30: Process memory requirements

If we look at the behavior of a single process in a virtual memory system shown in Figure 5.30, we see there are limits associated with a minimum number of page faults and a minimum number of allocated frames. If a process doesn't get some minimum number of frames, it may *never* finish. This is because any given instruction can address several different pages. If these pages are not all in memory, that instruction will never complete.
