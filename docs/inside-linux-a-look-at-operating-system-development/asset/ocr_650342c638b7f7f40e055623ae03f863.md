One can use X without a window manager, but it is very inconvenient to do so. Without the ability to relocate, resize and iconify windows, the user is entirely subject to the hints offered when each window is first opened.

The window can also display a command bar or support pull-down menus which can be used to start application programs.

Significant characteristics of the various window managers are:

+   * **fvwm** Featherweight (or Frugal) Virtual Window Manager (derived by Robert Nation from twm)
+       * resize displayed—yes
+       * resize by—drag corner
+       * move by—drag side or title
+       * 3-D borders—yes
+   * **twm** Tab (or Tom's) Window Manager (by Tom LaStrange of Evans and Sutherland)
+       * resize displayed—yes
+       * resize by—click icon and push side or corner
+       * move by—drag title bar
+       * 3-D borders—No
+   * **ctwm** extension to twm with virtual workspaces, options for motif-like look and feel
+   * **olwm** Open Look Window Manager (derived from Sun Microsystems)
+   * **olvwm** Open Look Virtual Window Manager (extends olwm)
+       * resize displayed—no
+       * resize by—drag corner
+       * move by—drag side
