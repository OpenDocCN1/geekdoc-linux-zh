# Distribution of System

Kernels, kits and disks are generated by authors, assemblers and publishers respectively.

For a while, the Linux kernel was distributed only by way of a few ftp sites, and users were expected to get the rest of the system directly from wherever the parts were located. This distribution has been superseded by more formal mechanisms. Although the kernel versions are still being distributed on a regular basis by ftp, others have stepped in to build distribution kits. Each kit contains the kernel, a suite of tools ported to Linux, and several floppy disk images needed to bootstrap the system. Initially these distribution kits were distributed via ftp as well, but a number of publishers have collected one or more of these kits, along with an even larger suite of tools, to be published on compact disks.

# 9.1 Dual Tracked Kernel Releases

Initial releases of the Linux kernel were numbered 0.xx to indicate they were not really ready for prime time. This numbering scheme had some limitations, but questions such as “Does 0.11 come before or after 0.2?” were safely avoided and the numbering quickly arrived at a limiting value of 0.99. That version was widely distributed and it was regarded as the first full-featured version of the Linux kernel.
