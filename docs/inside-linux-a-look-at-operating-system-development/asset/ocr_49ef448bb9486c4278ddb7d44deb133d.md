# Encryption

Normally, all security is lost when the system can be physically accessed by an intruder. Matt Blaze, of Bell Labs, has written a cryptographic file system¹⁴ which can be plugged into several different kinds of operating systems[6]. Such a system offers some security against such an intruder because even if the raw disk is compromised, user data cannot be easily extracted or modified. This security is because, without a password which is provided when the system is mounted, the data on that partition appears to be random bits.

# Automounting

Some systems reside in a large network environment, with many file systems available for mounting under NFS. It is a burden to either mount all these when a system is started or to force the user to mount them as they are needed. An automounter for Linux and other systems has been derived from the 4.4 BSD Automounter. It automatically mounts file systems when they are first referenced and it removes the NFS link when they have not been referenced for some reasonable interval. This program¹⁵ is available by ftp on the Internet.
