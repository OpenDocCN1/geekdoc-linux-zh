# ### 7.1 Languages

# #### 7.1.1 Assemblers and Compilers

Computers decode instructions from bit patterns stored in memory. The instructions of early computers had somewhat regular structure due to the constraints of the decoding logic. This allowed early programmers to work with *machine code* by specifying the bit patterns of each word of instruction memory. This method of programming was soon replaced by one which used symbolic names which had some mnemonic content. An *assembler* was created to convert the program text into the machine code needed by the computer. The assembler improved programmer productivity and accuracy.

# ##### Assemblers

Assemblers grew in complexity by offering a growing set of features. Assembler directives could be used to reserve blocks of storage, skip blocks of memory, identify types of code, and most importantly, define and apply macros.
