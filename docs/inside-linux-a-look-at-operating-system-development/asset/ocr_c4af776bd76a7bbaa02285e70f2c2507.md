+   • Richard Stallman—Founded the Free Software Foundation to promote the creation and distribution of software which is not encumbered by the convention commercial restrictions. FSF sponsors GNU software.

+   • Andrew Tannenbaum—Author of Minix. This operating system was the spark which lead to Linux. Dr. Tannenbaum is on the faculty of Vrije Universiteit, Amsterdam, Netherlands.

+   • Ken Thompson—Unix creator. See entry for Dennis Ritchie.

+   • Linus Torvalds—Author of Linux kernel. The Linux system grew out of Torvalds’ efforts to learn how the Intel 386 memory management could be used in a virtual memory system.

+   • Alan Turing—Pioneer in theory of computing. While working on the Enigma project, Turing made major contributions to the analysis of computation. His creation of a universal machine provided the foundation for an entire field of study.
