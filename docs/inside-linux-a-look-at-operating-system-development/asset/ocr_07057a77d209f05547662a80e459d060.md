PCI This bus is 32–64 bits wide and operates at 0 33 MHz. This design addresses many of the same issues as the Micro Channel. Because it is more expensive to implement cards for this design, it is generally limited to high-end systems.

PCMCIA This bus is an extension, of sorts, of the memory bus and thus is very fast. It is common to laptop systems where it provides an easy-to-plug-in expansion capability.

# 8.1.3 Storage

# Disks

IDE and EIDE The Intelligent Drive Electronics interface was developed as the cost of disk-resident electronics dropped. The IDE interface provides low-cost access to disks from the personal computer. The original protocol was rather limited, e.g., only a single drive could be accessed and the data transfer rates were small. The Enhanced IDE has addressed some of these problems, resulting in quite respectable performance.

SCSI The Small Computer Systems Interface defines a bus which can be used to exchange data among eight units. Typically one of these is a computer interface, allowing for up to seven peripheral units. Although these units are often individual disk drives, each unit supports up to eight Logical Unit Numbers (LUNs). This is especially convenient when a unit has multiple drives, such as a CD-ROM jukebox.

# Tapes

Although Linux has some support for the traditional 9 track tape, most users rely on some form of tape cartridge.

QIC The Quarter Inch Cartridge tape has been an industry standard for many years. There are three or four common cartridge sizes, each with a variety of tape lengths. One can store from 100 Mbyte to 1 Gbyte on these drives.
