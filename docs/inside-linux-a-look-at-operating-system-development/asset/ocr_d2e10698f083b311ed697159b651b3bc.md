order—interpreter name, interpreter arguments (as one argument), the script name, and the script arguments.

For example, if the command line

```
% alpha beta gamma
```

calls a script named **alpha** with arguments **beta** and **gamma** and that script starts with the line

```
#!delta epsilon zeta
```

the interpreter will be called as if the command line contained

```
% delta `epsilon zeta` `alpha` `beta` `gamma`
```

Note that all of the interpreter arguments are combined into a single argument to the interpreter. The interpreter will then open the script file and process the commands contained therein.

# **PERL, SED, AWK, etc.**

Although the shells are the most obvious candidates for interpreters of executable scripts, others exist. **perl** is another good choice because it automatically processes files in its argument list. Because the system creates and then processes an alternate command line which contains the script file's name in the argument list, **perl** automatically processes the script file. For example, when you execute a **perl** script named **my_perl_script** with **#!/bin/perl** on the first line, **perl** will be run as if it had been invoked with the command **perl my_perl_script**.

This automatic script file processing is a little more tricky for programs which were not designed as interpreters.
