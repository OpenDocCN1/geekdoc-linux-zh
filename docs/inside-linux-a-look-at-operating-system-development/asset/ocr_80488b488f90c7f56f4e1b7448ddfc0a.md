# 1.2.6  Linux Has Networking

Linux best shows its Unix heritage in its networking ability. All the common utilities such as `telnet`, `ftp`, NFS, `rlogin` (remote login), `rsh` (remote shell), and the X Window System are fully supported by code derived from code released by the University of California—Berkeley and MIT.

In addition to these traditional utilities, other programs such as World Wide Web browsers and multi-user games have been ported to Linux.

A number of physical device drivers have been added so that Linux can communicate via dial-up modem, leased line, Ethernet, parallel port, and ISDN.

# 1.2.7  Linux Uses Virtual Memory

Another great advantage of Linux is that it offers a simple memory model to the user programs—it has a uniform address space of $2^{32}$ bytes which can be addressed by a 32 bit pointer ${}^{4}$. Anyone who has programmed recent x86 hardware knows there are several memory models to choose from. Most commercially produced operating systems use a restrictive model, compatible with the oldest x86 processors, which requires segment registers to be changed in co-ordination with a pointer register. When Linux is used on an Intel based system, it demands a 386 or later processor and, as a consequence, it can offer a simple memory model which doesn’t require two registers to be manipulated when accessing all the memory on the computer.
