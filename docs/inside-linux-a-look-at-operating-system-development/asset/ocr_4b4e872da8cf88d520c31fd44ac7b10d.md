# Network Files

There is really no need for the file data to reside on the same computer upon which the application is running. The concept of a file system as “a provider of file data” can be abstracted to the extent that the user of that data cannot easily tell where the data are physically stored.

**Issues** When considering files on a network, there are some issues which we must keep straight in our minds. At the minimum, we must distinguish remote file transfer from remote file access. The former copies a file from one system to another using some special application package. The latter is intended to make the access of network files transparent to the user.

This dichotomy is spoiled by the presence of so-called *file caching* systems which may copy an entire file and keep the copy, but the access is *as if* it were to a remote file.
