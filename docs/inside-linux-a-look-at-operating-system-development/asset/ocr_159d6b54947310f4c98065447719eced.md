Linux has followed the same path in its short life. Netnews, a net-work based bulletin board system, has been used to great advantage because it encourages the convenient discussion of problems. Since Linux is self-hosted, developers find it easy to add fixes for problems which get in their way.

Linux has benefited greatly from the Free Software Foundation<sup>5</sup> GNU (GNU’s Not Unix) project. This project set out to replace Unix with a system free of the licensing constraints. Although FSF has recently released the HURD kernel, a large number of tools, including superior compilers and editors, have been released over the past years. Since these tools were written with an open system in mind, it was a simple matter to incorporate these tools into the Linux distribution. Most of these tools are of the system development and text processing flavor.

The GPL, which was designed to promote free software, has sparked a remarkable amount of commercial development. Enlightened hard-ware vendors have contributed drivers for their hardware with the un-derstanding that this will promote sales of their devices. Software de-velopers have found it easy to port their suites of Unix-based applica-tions to Linux—thanks to Linux’s almost complete POSIX compliance. The GPL means they have the entire source at hand so they can fix any part of Linux which they find deficient. The GPL then ensures that these fixes will be shared with the rest of the Linux community.

In addition, most commercial software produ-cers have shifted their programming from assembly language to C or C++, making it easier to port their products to Linux.
