Upon return from the system call, the return value is tested for an error condition, a global variable called errno may be set, and the return value is put in EAX. *Because of the need to access specific machine registers, this is one of the few places at the user level where assembly language must be used.*

# System side

As a result of the trap, the processor enters a different mode of operation, one which can execute privileged instructions and access additional memory and device registers which are denied to ordinary user processes.

The trap passes control through an interrupt descriptor table to *system_call*, one of the few assembly language subroutines in the kernel. This subroutine, like the libc subroutines, shuffles arguments and then calls the appropriate kernel subroutine.
