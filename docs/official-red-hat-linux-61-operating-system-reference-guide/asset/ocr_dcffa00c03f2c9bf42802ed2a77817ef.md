# 7.5.1 Querying Packages

The easiest way to query packages is to use the **Query** option from the menu at the top. If you want to query more than one package, make all your selections then press the **Query** button on the menu. 

You’ll be presented with a window like the one shown in Figure 7–10, *Query Window*. The more packages you’ve queried, the more “tabs” you’ll find within the **Query** box, each tab representing a **Query** window for a package.
