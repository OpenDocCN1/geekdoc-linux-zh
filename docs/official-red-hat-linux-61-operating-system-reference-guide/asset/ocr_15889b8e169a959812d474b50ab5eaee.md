# ### 7.2.1 Selecting Packages

To select a single package, click on it with the left mouse button. You’ll notice that highlighting will appear around the package title (as shown in Figure 7–2, *Selecting Packages in Gnome-RPM*) which reflects the selection. To unselect it, either click on an empty space in the display panel with the left mouse button, or click on the **Unselect** button on the toolbar. When you unselect a package, the highlighting will disappear.
