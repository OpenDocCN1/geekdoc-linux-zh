The status bar on the main Update Agent window will indicate the the application is creating a page which will be displayed in your Web browser. Once it’s finished sorting the packages and building the page, your browser will open and you’ll see results similar to Figure 5–7, Available Updates.

If there are updated packages available, you’ll see the name of the package, a summary of its function and related details, such as the latest version number, the release number and the size of the package.
