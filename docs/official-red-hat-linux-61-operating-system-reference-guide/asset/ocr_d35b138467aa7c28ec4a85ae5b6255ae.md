# ### 10.24 Finishing Up

When finished, the installation program displays the **Complete** dialog (as in Figure 10­49, *Compete Dialog*), telling you to reboot your computer. Remove any diskette from the diskette drive (unless you skipped the LILO installation, in which case you must use the boot disk created during the installation), or the Red Hat Linux CD if your system booted from the CD-ROM.
