# ### 10.10.1 The Current Disk Partitions Section

Each line in the **Current Disk Partitions** section represents a disk partition. In this example (Figure 10-15, *Disk Druid Main Screen*), there are Linux existing partitions. Note the scroll bar to the right, which indicates that there may be more partitions than can be displayed at one time. If you use the [Up] and [Down] arrow keys, you can see if there are any additional partitions. Each line in this section has five different fields:

+   - **Mount Point** -- Indicates where the partition will be mounted when Red Hat Linux is installed (such as ` /, /boot, or swap) .
+   - **Device** -- Displays specific hard drive and partition information.
+   - **Requested** -- Shows the partition's initial size.
+   - **Actual** -- Shows the partition's current size.
+   - **Type** -- Shows the partition's type.
