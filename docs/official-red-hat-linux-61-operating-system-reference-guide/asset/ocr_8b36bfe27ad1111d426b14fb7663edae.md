If you select **OK**, you’ll have the opportunity to go back enter different configuration values should there be an error. If there is no error, X will start, and a small display window will ask you if you can read its contents clearly: using the mouse, click **Yes** within ten seconds. Then you are asked whether you want X to start when the system boots.

In most cases, X configuration is complete at this point, and you’ll see the completion screen.

To modify your X configuration after installation, as root issue the `Xconfigurator` command.
