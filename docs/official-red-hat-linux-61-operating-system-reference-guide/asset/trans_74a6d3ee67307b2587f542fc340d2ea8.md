关于网络设备和内核模块的信息在上面有描述。合适的主名称 + 域名和 IP 地址将取决于你是将计算机加入现有网络还是创建新网络。对于连接到现有网络，请联系你的网络管理员获取相关信息。将网络连接到互联网超出了本书的范围，我们推荐以下起点：

> 《TCP/IP Network Administration》第 2 版，作者 Craig Hunt（O'Reilly and Associates 出版）。

如果你正在设置一个永远不会连接到互联网的私人网络，那么你可以选择任何你想要的主名称 + 域名，并且对于 IP 地址有几个选择（参见表 3–1，地址和示例）。

### 表 3–1 地址和示例

| 可用地址 | 示例 |
| :--- | :--- |
| 10.0.0.0 - 10.255.255.255 | 10.5.12.14 |
| 172.16.0.0 - 172.31.255.255 | 172.16.9.1, 172.28.2.5 |
| 192.168.0.0 - 192.168.255.255 | 192.168.0.13 |

上述三组数字分别对应 A 类、B 类和 C 类网络。这些类别用于描述可用的 IP 地址数量以及数字范围。上述数字已被保留用于私人网络。

### 请注意

如果你连接到互联网，不应该使用这些 IP 地址，因为 192.168.0.* 和 192.168.255.* 并不始终被认为可靠地属于私人地址。如果你希望你的网络连接到互联网，或者认为将来可能会连接，请给自己一个方便，现在就获取非私有地址。

### 名称服务器指定

建立网络连接还需要一个名称服务器和默认域。名称服务器用于将主机名称（如 private.network.com）翻译成其对应的 IP 地址（如 192.168.7.3）。

默认域告诉计算机如果在没有指定完全限定主机名称时应该在哪里查找。完全限定意味着给出了完整地址，因此 `foo.redhat.com` 是完全限定主机名，而主机名仅仅是 `foo`。如果你将默认域指定为 `redhat.com`，那么你就可以仅使用主机名来成功连接。例如，如果你的搜索域是 `redhat.com`，那么 `ftp foo` 就足够了；但如果不是，则必须使用 `ftp foo.redhat.com`。

要指定名称服务器，请打开 **Config => Networking => Client tasks => Name server specification (DNS)**。

### 图 3-18 解析器配置屏幕

![](img/eda1471ab4ce718c791c97a85559a478_109_0.png)

名称服务器根据访问顺序进行排名，因此，如果指定了不止一个名称服务器，通常会看到它们被称为主服务器、次服务器、第三服务器，依此类推。由于计算机在连接到名称服务器之前无法解析名称，因此这些中的每一个都必须是 IP 地址，而不是名称。

除了默认域之外，你还可以指定搜索域。搜索域的工作方式不同；它们以类似于名称服务器的方式从 1 个进展到 6 个。然而，它们都比默认域具有更高的优先级！在指定搜索域时请记住这一点。搜索域并不常用。

尚未涵盖的一项内容是 DNS 使用复选框。如果你运行的是没有互联网连接的小型私人网络，那么使用 `/etc/hosts` 文件并保持它们同步是可行的。随着你添加越来越多的机器，复杂性增加，直到比同步 `/etc/hosts` 文件更容易让一台机器运行 DNS。

不使用 DNS 的另一个原因如果你的网络将改用 NIS。请注意，NIS 可以与 DNS 配合使用。因此，总结一下，除非你知道为什么使用 `/etc/hosts` 或 NIS 对你的情况最好，否则 DNS 很可能是你最好的选择。

你可以使用 linuxconf 添加、修改或删除 `/etc/hosts` 文件中的条目。打开 **Config => Networking => Misc => Information about other hosts**。

![](img/eda1471ab4ce718c791c97a85559a478_111_0.png)

![](img/eda1471ab4ce718c791c97a85559a478_111_1.png)

要修改或删除条目，请选择该条目。要删除条目，请在主机/网络定义屏幕底部选择 Del。

### 图 3-20 主机/网络定义屏幕

![](img/eda1471ab4ce718c791c97a85559a478_112_0.png)

要修改它，请根据需要更改信息。要添加新条目，请在 `/etc/hosts` 屏幕底部选择 Add。这也将打开主机/网络定义屏幕。

必填字段：

- **主名称 + 域** -- 主名称是计算机的名称，而域是其所连接网络的指定方式。例如，给定 `foo.bar.com`，`foo` 是主名称，`bar.com` 是域。
- **IP 编号** -- 也称为 IP 地址；这是机器的地址，将遵循 `x.x.x.x` 的模式。例如，`192.168.0.13`。

可选字段：

- **别名** -- 完全限定域名的简写。这通常与主名称相同。因此，例如，如果完全限定域名是 foo.bar.com，你可以选择 foo 作为别名。
- **注释** -- 关于机器的注释。例如，"远程名称服务器。"
- 完成后，选择 **Accept**。

## 3.2 使用控制面板进行系统配置

使用控制面板应用程序可以完成的大部分内容也可以*linuxconf*完成。此外，*linuxconf* 同时支持字符单元格 *和* 图形用户界面。请参阅第 3.1 节，使用 *linuxconf* 进行系统配置，以了解 *linuxconf* 的介绍。

控制面板是许多不同系统管理工具的启动台（见图 3–21，控制面板）。这些工具通过让你无需记住配置文件格式和复杂的命令行选项即可配置事物，从而让你的生活更简单。

### 图 3–21 控制面板

![](img/eda1471ab4ce718c791c97a85559a478_115_0.png)

要启动控制面板，请以 root 身份运行 X 窗口系统，使用 `startx` 并在 Xterm 中输入 `control-panel`。你需要是 root 才能成功运行控制面板工具。如果你已经以普通用户身份运行 X，也可以这样做。只需输入 `su -c control-panel`，然后在提示时输入 root 密码。如果你计划以 root 身份执行其他任务，你可以输入 `su`，然后在提示时输入 root 密码。

> **请注意**
>
> 如果你不是以 root 身份运行 X，你可能需要给予 root 访问你的系统 X 服务器的权限。要做到这一点，在一个*非 root*终端窗口中输入以下命令：

```bash
xhost +localhost
```

启动控制面板后，只需单击图标即可启动工具。请注意，你不会因同时启动任何工具的两个实例而被阻止，但这样做是一个非常糟糕的主意，因为你可能会试图在两个地方编辑相同的文件，最终覆盖你自己的更改。
