Unicoded.pl first copies C:\winnt\system32\cmd.exe to a file named sensepost.exe
in the directory as the Web root parameter (in our example, C:\inetpub\scripts).
Again, this is done to bypass the inbuilt of cmd.exe to take redirect (">") via this exploit.
Sensepost.exe is used to echo/redirect the files upload.asp and upload.inc line by line
into the Web root directory, C:\inetpub\scripts in our example.

Once upload.asp and its included file are on the victim server, simply surf to
that page using a Web browser to upload files using a convenient form, as shown in
Figure 3-2.

To gain control over the victim server, attackers will probably upload two
other files of note, using the upload.asp script. The first will probably be netcat (nc.exe).
Shortly after they will upload cmap.asp, with a hacker named Maceo. This is a hacker
form-based script that executes commands using the Unicode exploit, again within the
tacker's Web browser. Browsing to cmapd.asp presents an easy-to-use graphical
interface for executing Unicode commands, as shown in Figure 3-3.

At this point, it's worthwhile reemphasizing the ease of using either upload.asp or
cmd.asp by simply browsing to them. In our example that used C:\inetpub\scripts as
the target directory, the URLs would be as follows:

```
http://victim.com/scripts/upload.asp
http://victim.com/scripts/cmapd.asp
```
