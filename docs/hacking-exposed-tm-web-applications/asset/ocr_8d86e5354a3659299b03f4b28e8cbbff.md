# 318 Hacking Exposed Web Applications

We have discussed numerous tools and techniques in this book for assessing the security of Web applications. This appendix summarizes the most important of these in an abbreviated format designed for use in the field. It is structured around the Web hacking methodology that comprises the chapters of this book.
