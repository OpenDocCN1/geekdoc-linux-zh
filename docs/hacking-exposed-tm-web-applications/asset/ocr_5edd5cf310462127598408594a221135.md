# Back-End Connectivity

The final set of information to collect is evidence of back-end connectivity. Note when information is read from or written to the database (such as updating address information or changing the password). Highlight pages or contents pages that directly relate to a database or other systems.

WebDAV options enable remote administration of a Web server. A misconfigured server could allow anyone to upload, delete, modify, or browse the Web document root. Check if they are enabled:

```
[root@meddle.victim.com] # echo -e "OPTIONS * HTTP/1.1\n\n> Host: localhost\n\n" | |\n> nc -vv www.victim.com 80 > index.html\nwww.victim.com [192.168.33.101] 80 (http) open\nHTTP/1.1 200 OK\nServer: Microsoft-IIS/5.0\nDate: Fri, 01 Feb 2002 08:49:48 GMT\nMS-Author: Dav\nContent-Length: 0\nAccept-Ranges: none\nDASL: <DAV:sql>\n: 1, 2\nPublic: OPTIONS, TRACE, GET, HEAD, DELETE, PUT, POST, COPY, MOVE,\nMKCOL, PROFFIND, PROPATCH, LOCK, UNLOCK, SEARCH\nAllow: OPTIONS, TRACE, GET, HEAD, COPY, PROFFIND, SEARCH, LOCK,\nUNLOCK\nCache-Control: private\nsent 38, rcvd 33: NOTSOCK
```

# Server Headers

The HTTP headers returned by the Web server also reveal the operating system, Web server version, and additional modules. Headers cannot always be trusted, after all, and it is vital to change the header information in order to mask system information. But when headers include WebDAV versions or SQL databases, use the information to put a comprehensive picture of the application architecture.

# TOOLS TO AUTOMATE THE SURVEY

Several tools automate the grunt of the application survey. They are basically spiders; once you point them to a URL, you can sit back and create a mirror of the site on your system. Remember, this will not be a functional replica of the target site with ASP source code and database calls. It is simply a complete collection of every available link within the application. These tools perform most of the grunt work of collecting files.
