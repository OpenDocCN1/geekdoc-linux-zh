# CASE STUDY: USING CURL TO MAP PERMISSIONS

Curl is a fantastic tool for automating tests. For example, suppose you are auditing an application that doeses out user IDs sequentially. You have identified the session tokens for a user to view his profile information: uid (a numeric user ID) and sessid (the session ID). The URL request is a GET command that passes these arguments: menu=4 (the number that indicates the profile menu), userID=uid (the user ID is passed in the cookie and in the URL), profile-uid (the profile to view, assumed to be the user's), and r=87bace2 (a random number assigned to the session when the user first logs in). So, the request would look like:

```
GET /secure/display.php?menu=4&userID=24601&profile=24601&r=87bace2
Cookie: uid=24601; sessid=99834948209
```

We have determined that it is possible to change the profile and userID parameters in the URL to view someone else's profile (including the ability to change the e-mail address to which password resets are sent). Now, we know that the user IDs are generated sequentially, but we don't know which user IDs belong to the application administrators. In other words, we need to determine which IDs can view an arbitrary profile. A little bit of manual testing reveals that if we use an incorrect combination of profile and userID values, the application returns "You are not authorized to view this page" and a successful request "Membership profile for"; return a 200 HTTP code. We will automate this check with two curl scripts.

The first script is used to determine whether other users can view our profile. If another user can view our profile, then it is assumed to belong to an administrator. The script tests the first 100000 user IDs:

```
#!/bin/sh
userID=1
while [ $userID -le 100000 ]; do
  echo -e "userID ******\n" >> results.txt
  curl -v -G \
  -H 'Cookie: uid=$userID; sessid=99834948209' \
  -d 'menu=4' \
  -d 'userID=$userID' \
  -d 'profile=24601' \
  -d 'r=87bace2' \
  ---url https://www.victim.com/ >> results.txt
  echo -e "********\n" >> results.txt
  userID=$((userID + 1))
done
exit
```
