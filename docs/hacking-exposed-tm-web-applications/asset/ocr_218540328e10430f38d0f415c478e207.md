The two categories can assist an attacker in discovering servers related to a particular organization or Web site. Let's take a look at some examples.
Our favorite way to discover IP addresses to U.S. organizations is to use the Web-based whos at the American Registry for Internet Numbers (ARIN) Web site at http://www.arin.net/whos. By simply typing the name of an organization at this site and running the query, all of registered Internet IP address ranges associated with that organization are displayed. whos can also be useful for identifying other DNS names associated with an organization. For example, www.company.com may also run several different applications with canonical DNS names like www.widgets.com or widgets.eshop.com. Using whos in this fashion is a two-step process: first we must use a registrar query to determine with whom the targeted organization has registered its DNS domains, and then we use the organizational query to the appropriate registrar to enumerate domains registered to that.

For a list of accredited domain name registrars, see http://www.internet.net/register.html.
