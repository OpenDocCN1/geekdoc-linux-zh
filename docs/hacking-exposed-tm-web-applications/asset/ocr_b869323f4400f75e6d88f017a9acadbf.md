# SQL Injection and Datastore Attacks

This special case of input validation attacks can open up a database to complete compromise. # Command Execution

Many attacks only result in information retrieval such as database columns, application source code, or arbitrary commands. Command execution is the final goal for an attack. Command-line access on the web server, it is only a short time before the system is fully compromised—and all of this happens port 80 or 443!

# Newline Characters

The newline character, %0a in a hexadecimal incarnation, is a useful character for command execution. On UNIX shell scripts (as such any script written in a shell language) will interpret the newline character as an instruction to execute a new command.

For example, the administration interface for one service provider's banking program is written in the Korn Shell (ksh). One of the interface is to call an internal "analyze" program to collect statistics for the dozen baking Web sites it hosts. The GET request looks like: URL/analyze.sh?t=24&e;. The first test is to determine if variables can be passed to the script. Sure enough, URL/analyze.sh?h returns the help page for the "analyze" program. The next step is command execution: URL/analyze.sh?t=%0a/bin/ls%0a. This returns a directory listing on the server (using the "ls" command). At this point, we have the equivalent of command-line access on the server.
