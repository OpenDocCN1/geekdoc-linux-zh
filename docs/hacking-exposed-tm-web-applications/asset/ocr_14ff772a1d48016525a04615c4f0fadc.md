Another used capability of Whisker is to run as CGI, which is as simple as naming the Perl whisker.cgi and putting it in the /cgi-bin/ directory of a Web server. There's only a brief mention of this capability in the documentation, but it's fun to use and makes nice HTML output using the (-W option), which is also accessible via the Web if necessary.
