The main limitation to whose organizational queries against a typical server is that they limit the number of records that will be returned (note that this query was curtailed after 50 records). If the target organization has more than 50 domains, this is a severe limitation. Organizations wishing to receive unrestricted information can typically e-mail the appropriate registrar via the organizational administrative point-of-contact and resort to a series of queries. Otherwise, you'll have to trickery: appending an incremented value and a dot to series of queries. If you want to find all domain names registered to a company name Victim, you could perform a query using victim1, victim2, victim3, and so on you've exhausted the most typical possibilities for registered domain names. Tedious, but if your goal is comprehensiveness, you have few other choices via whom.

One of our favourite tools is Sam Spade, which is available as a Win32 client, or you can turn to http://www.samspade.org and use the Web-based tools from any Internet-connected browser.

# DNS Interrogation

You have noted that whose queries turned up the identity of the DNS name servers for an organization. If these servers suffer from a common misconfiguration, they may allow any customers to download the entire contents of a given domain, revealing all of the hostname-IP mapping for that domain. This functionality is typically restricted to backup DNS servers who store copies of the DNS zone files, but if this restriction is not set, then anyone can dump the zone remotely via a DNS zone transfer.

Performing a DNS zone transfer is simple using the nslookup utility built into most platforms. We'll demonstrate it using the Windows nslookup client below. First, we start the nslookup client, then specify the DNS server we wish to query (should be authoritative for the target zone), and dump the contents of the zone with the ls-domain argument.

```
C:\nslookup
Default Server: internal
Address: 10.1.1.65
```

```
> server nsl.victim.com
Default Server: nsl.victim.com
Address: 192.168.15.77
```

```
> ls -d victim.com
```
