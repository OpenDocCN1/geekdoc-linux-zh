# AppScan

+   - **Pro:** Well-researched, updated checks; allows user-defined checks; strong reporting
- **Con:** Huge price, complex to install, and can overwhelm server
- **Final Analysis:** If you've got $15,000 burning hole in your pocket, go for it

AppScan from Sanctum, Inc. claims to be much more than a Web server security scanner, rather a holistic evaluator of application-level security failures as well. While it does identify common Web server vulnerabilities, it also attacks Web applications running on the server by cataloging a site and attempting generic HTTP malformations against what it finds.
