# FPS VSRAD Countermeasures

This is an easy one to fix: don't deploy FPS VSRAD support on Internet-facing machines. It is not installed by default, but if you want to check, go to the Add/Remove Windows Programs Panel, then select Internet Information Services | Details, and make sure Visual InterDev RAD Remote Deployment Support is disabled. Microsoft recommends getting the patch anyway just in case, which is probably a good idea (many organizations’ intranets are wilder than the Internet nowadays). The location of the patch is listed in the “References and Further Reading” section at the end of this chapter.
