ActiveX controls that perform harmless functions probably wouldn't be that risome; however, Scriptlet and Eyedog both have the ability to access the file system. Scriptlet. can create, edit, and overwrite files on the local disk. Eyedog has the ability to query the Registry and gather characteristics.

Georgi Guninski released proof-of-concept code for the Scriptlet control that writes an executable file with the .hta (HTML application) to the Startup folder of a remote machine. This file will be executed the next time the appropriate user logs on to Windows, displaying a harmless message from Georgi, but nevertheless making a very solemn point: by visiting Georgi's proof-of-concept page, you enable him to execute arbitrary code on your system. ActiveX controls can be marked as "safe for scripting" by implementing ObjectSafety within the control or marking them as safe in the Registry by adding the key 7DD95081-9882-11CF-F9AE-00A0C42C4 to the Implemented Categories for the control (see http://msdn.microsoft.com/components/activex/safety.asp). Searching through a typical Windows registry yields dozens of controls. Any controls that also have the ability to perform privileged actions (such as writing to disk or executing code) could also be used in a similar attack.
