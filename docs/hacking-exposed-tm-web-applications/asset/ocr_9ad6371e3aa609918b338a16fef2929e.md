# CASE STUDY #1: FROM THE URL TO THE COMMAND LINE AND BACK

Our first case study deals with a bank that opted to host its online banking services with an Application Service Provider (ASP). The banking application, also developed by the ASP, had few security holes, plus a script that was writable to allow a directory traversal attack.

```
/openserv/HB/dimlDisplay.cgi?DIML_FILE=SummaryDetail.diml
```

This allowed us to escape the Web document root and browse the file system. In this case, the Web platform was iPlanet server on Solaris:

```
/openserv/HB/dimlDisplay.cgi?DIML_FILE=../../../../etc/passwd%00SummaryDetail.diml
```

Note that the SummaryDetail.dim file is appended to the URL. This is required because the application apparently has a .dim extension before dumping the /etc/passwd (or any other) file.
