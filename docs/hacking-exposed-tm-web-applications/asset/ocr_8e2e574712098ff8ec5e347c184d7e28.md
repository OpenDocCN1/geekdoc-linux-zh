# Lotus Domino

Lotus Domino is IBM's collaboration platform that has gone Web-centric like others. The first step in reviewing a Lotus Domino server is to enumerate its databases (.nsf files) and check their access permissions. There are several common files that may be present (sounds like a job for an automated scanner!). These are a few of the high-profile files:

+   * Admin.nsf
"* Admin4.nsf
"* Catalog.nsf
"* Events4.nsf
"* Names.nsf
"* Setup.nsf"

A more complete list, including a file to use for the Stealth vulnerability scanner, can be found at http://domilockbeta.2y.net/web/domilock/domilock.nsf/pages/rulesstealth
