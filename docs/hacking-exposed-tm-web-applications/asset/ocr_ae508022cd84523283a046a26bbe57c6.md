Using our getit.sh we made a request for the /isapi/ directory; however,
we omitted an important piece. The trailing slash was left off the directory name. This
causes an IIS server to redirect to a directory. As a byproduct, it also
reveals the internal hostname or IP address of the server—when it's behind a
firewall or load balancer. Apache is just as susceptible. It doesn't reveal the internal
hostname or IP address of server, but it will reveal virtual servers.

```
[root@meddle] # getit.sh www.victim.com /
www.victim.com [192.168.130.20] 80 (http) open
HTTP/1.1 301 Moved Permanently
Date: Wed, 30 Jan 2002 06:44:08 GMT
Server: Apache/2.0.28 (Unix)
Location: http://dev.victim.com/mail/
Content-Length: 308
Connection: close
Content-Type: text/html; charset=iso-8859-1
```
