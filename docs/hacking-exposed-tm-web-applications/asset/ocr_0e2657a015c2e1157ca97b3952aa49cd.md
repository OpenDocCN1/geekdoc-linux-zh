At the lowest level of detail, a SOAP message encapsulated over HTTP would look like the following example of a hypothetical stock trading Web service (note the envelope, header, body, and subelements within each). Note that the original request is an HTTP POST.

```
POST /StockTrader HTTP/1.1
Host: www.stocktrader.edu
Content-Type: text/xml; charset=utf-8
Content-Length: nnnn
SOAPAction: "Some-Uri"
```

```
<SOAP-ENV:Envelope
xmlns:SOAP-ENV="http://schemas.xmlsoap.org/soap/envelope/"
<SOAP-ENV:encodingStyle="http://schemas.xmlsoap.org/soap/encoding">
<SOAP-ENV:Header>
  <m:quote="http://www.stocktrader.edu/quote"
    env:actor="http://www.w3.org/2001/12/soap-envelope/actor/next"
    env:mustUnderstand="true">
    <m:reference uuid=90e4567-q345-739r-ba5d-pqff98fe8j7d</reference>
    <m:dateAndTime>2001-11-29T13:20:00-05:00</m:dateAndTime>
  </m:quote>
<SOAP-ENV:Body>
  <m:GetQuote xmlns:m="Some-URI" />
```
