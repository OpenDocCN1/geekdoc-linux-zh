Let’s look at some automated Web password guessing tools available.

# WebCracker

When we encounter a page protected by Basic authentication in our consulting work, we generally turn to WebCracker to test account credential strength. WebCracker is a simple tool that takes lists of usernames and passwords (or combinations of both) and uses them as dictionaries to implement Basic auth password guessing. Keys on “HTTP 302 Object Moved” responses to indicate a successful guess, and it will find all successful guesses in a given username/password file (that is, it won’t stop guessing once it finds the first valid account). # Brutus

Brutus is a generic password guessing tool that comes with built-in routines for attacking HTTP Basic and Forms-based authentication, among other protocols like SMTP and POP3. Brutus can perform both dictionary attacks (based on precomputed wordlists like dictionaries) and brute-force attacks where passwords are randomly generated from a given character set (say, lowercase alphanumeric).
