# twwscan/arirang

| Pro | Very simple, free |
| Con | Not as flexible as others, no native SSL support |
| Final Analysis: Good for newcomers to Web security |

twwscan and arirang are the Windows and UNIX versions, respectively, of a Web vulnerability scanner written by a Korean hacker who uses the handle "pilot." We'll talk about them primarily twscan is designed to connect only to one server at a time. However, using the NT/2000 command, it is easily made to loop through a file containing a list of IP addresses or hostnames. twscan is not updated frequently, but it does make nicely formatted HTML reports. We think its most powerful feature is the "user" version of the tool, called Tuxe. Tuexe is somewhat like Whisker in that the main executable serves as an agent that parses user-defined configuration files (.exe's) and executes the vulnerability checks contained therein. There is a sample .exe file used to scan for monitor IIS vulnerabilities discussed in this chapter:
