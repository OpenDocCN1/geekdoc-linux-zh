# SERVER IDENTIFICATION

Server identification is more commonly known as banner grabbing. Banner grabbing is critical to the Web hacker, as it typically identifies the make and model of the Web server software. The HTTP 1.1 specification (RFC 2616) defines the server response header field to communicate information about the server handling a request. Although the RFC encourages implementers to make this field a configurable option for security reasons, most every current implementations populate this field with real data by default.
Here is an example of banner grabbing using the netcat utility:

```
D:\nc -nnv 192.168.234.34 80 ([]) open
(UNKNOWN) [192.168.234.34] 80 (?)
HEAD / HTTP/1.0
[Two carriage returns]
HTTP/1.1 200 OK
Server: Microsoft-IIS/5.0
Date: Fri, 04 Jan 2002 23:55:58 GMT
[etc.]
```

> Note the use of the HEAD method to retrieve the server banner. This is the most straightforward method for grabbing banners.

Text file input can be input to netcat connections using the redirect character (<)—for example, nc -vv server 80 < file.txt.
