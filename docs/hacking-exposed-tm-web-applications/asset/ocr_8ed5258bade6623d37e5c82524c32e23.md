# Cookie Cutting Countermeasures

Once again, we've divided our discussion into client- and server-side recommendations.

**Client-Side Countermeasures** In general, users should be aware of sites that use cookies for
authentication and storage of sensitive data. Also remember, if you visit a site
uses cookies for authentication, they should use SSL to encrypt the initial post
of your username and password so that it doesn't show up as plaintext in a sniffer.

One tool to help in this regard is Cookie! from Kookaburra Software at
http://www.kookurra.com/. It can help to warn you when Web sites attempt to set
cookies, enabling you to see what's behind the scenes so you can decide whether
want to allow such activity, or to use Microsoft's Internet Explorer built-in screen-
ing, go to the Internet Options control panel, click the Security tab, and select Internet
Zone | Custom Level | Prompt for persistent and per-session cookies. Netscape browser
cookie behavior is set via Edit | Preferences | Advanced, and checking whether We Be-
forcing A Cookie or Disable Cookies. Note that in IE 6, the settings for controlling
cook have been moved to the Privacy tab of the Internet Options control panel, which is
shown in Figure 12-8. For those cookies that you accept, check them out if they are written
to disk, and see if it is storing any personal information about.
