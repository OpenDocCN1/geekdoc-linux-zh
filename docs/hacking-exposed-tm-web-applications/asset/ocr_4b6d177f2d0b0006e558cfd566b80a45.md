# Escalating Privileges on IIS

Several good privilege escalation exploits exist for Windows NT and 2000. However, many of them require an interactive session in order to be launched successfully. A remote session is not considered an interactive session on Windows, so these exploits are not feasible assuming the Web service is the only one reachable via the intruder.
