**Differential Analysis (Phase Space)** In 2001, Michal Zalewski of the Binding team applied nonlinear analysis techniques to the initial sequence numbers (ISN) of TCP connections and made interesting observations on the “randomness” of the values. The most illustrative part of the graph was the graphical representation of the analysis. Figures 7-1 and 7-2 show the visual difference between the relative nature of two sources.

The ISN is supposed to be a random number for every new TCP connection, like the session ID generated by a Web server. The functions used to generate the graphs do not require any complicated algorithm. Each coordinate is defined by:

```
x[t] = seq[t-1]
y[t] = seq[t-2]
z[t] = seq[t-3]
```

The random values selected from the dataset are the “seq” array; “t” is the index of the array. Try applying this technique to values you can collect from an application.
