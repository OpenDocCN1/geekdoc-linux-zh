# Query String

The query string is the extra data in the URI after the question mark (?) is used to pass variables. The query string is an ampersand-delimited list and can contain multiple values between the client and server. An example would be http://www.mail.com/mail.aspx?joe=joe&company=acme%20com. The query string is visible in the Location bar on the browser, and is easily changed without any special Web hacking tools. Things to try would be to change the URI to http://www.mail.com/mail.aspx?jane=jane&company=acme%20com attempt to view Jane's mailbox while authenticated as Joe.

# POST Data
