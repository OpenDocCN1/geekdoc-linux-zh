Another surveying is the flowchart. The flowchart consolidates information about the site and present it in a clear manner. An accurate diagram helps to visualize the application processes and may reveal weak points or inadequacies in the design. The flowchart can be a block diagram on a white board or a three-page diagram with color-coded blocks that identify static pages, dynamic pages, database access routines, and other macro functions.
