# BYPASSING CLIENT-SIDE VALIDATION ROUTINES

One word: JavaScript. If this word leads your application's list of security measures, the application may not be as secure as you think. Client-side JavaScript—that is, JavaScript that is loaded in the Web browser to generate dynamic content or some type of validation—can always be bypassed. Some personal proxy, firewall, and cookie-management software thwart their ability to strip pop-up banners and other intrusive components of a Web site. Many computer professionals (paranoiac?) turn off JavaScript completely in order to avoid the latest e-mail virus. In short, there are many legitimate reasons and straightforward methods for Internet users to use JavaScript.

Of disabling JavaScript tends to cripple most Web applications. Luckily, we have several tools that help surgically remove JavaScript or enable us to submit content after the JavaScript check has been performed. With a local proxy such as Achilles, we can pause a GET or POST request before it is sent to the server.
