# Attacks IIS

If you think attacks against IIS components were bad, wait till you see what we've got in store for you. In 2001, a devastating directory traversal vulnerabilities faced IIS. Given a few unrelated misconfigurations on the server, exploration of these vulnerabilities can lead to complete system compromise. Thus, although they don't have the same impact of the buffer overflow attacks previously covered, they can be the next best thing.

The two IIS directory traversal exploits we examine in the following sections are the Unicode and the double decode (the latter is sometimes termed superfluous decode) attacks. First, we describe them in detail, and then we discuss some mechanisms for leveraging the initial access they provide into full-system conquest.
