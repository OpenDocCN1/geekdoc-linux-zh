Despite all the free functionality available with current Web browsers, it's still the HTTP/HTML functionality is the hacker's best friend. In throughout this book, we will eschew using Web browsers, preferring to perform our tests with tools that make RAW connections. A great deal of information lies underneath the pretty presentation of a Web browser, and in some cases, they surreptitiously reformat some requests that might be used to test Web security (for example, Microsoft's Internet Explorer strips out dot-slashes before sending a request). Now, we can't have that happening during a serious security review, can we?
