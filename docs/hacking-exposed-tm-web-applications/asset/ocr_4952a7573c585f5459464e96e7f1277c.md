# # Final Notes

Sometimes it is difficult to craft the right request or even know what fields are. The authors have used a technique called differential analysis that has proven quite successful. Although this sounds complicated, the technique is very simple. You basically need to have two or more accounts. You crawl the Web site with each account and note the differences, hence the differential analysis. Now, you have two accounts and can note where the cookies and other fields differ. For example, some cookie values or other information will reflect differences in profiles or customized settings. Other values, ID numbers for one, might be close together. Still other values might differ based on the permissions of each user.
