The Web, blunting all of the attacks discussed so far and hundreds more just like them. We'll talk about how to do this on the two most popular Web browser products, Netscape Navigator and Internet Explorer.

In Netscape 4.x, it's easy as Edit | Preferences and navigating to the Advanced Category in the left window pane, as shown in Figure 12-2. Java and JavaScript can be disabled here. What about ActiveX? Netscape does not natively support ActiveX, so it cannot be attacked by ActiveX-driven exploits.

In Internet Explorer, the Security zones control how active content will be handled. The security zone model allows users to assign varying levels of trust to code downloaded from four zones: Intranet, Trusted Sites, Internet, and Restricted Sites. A fifth zone, Local Machine, exists, but it is not available in the user interface because it is only configurable via the IE Administration Kit (IEAK) (see http://www.microsoft.com/windows/leak/en/default.asp).
