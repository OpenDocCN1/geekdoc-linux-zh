# IIS Authorization

IIS provides similar security options for the types of access to a directory, although not to a similar granularity. Figure 6-3 illustrates a good set of default options to apply to directories that contain static HTML files. It is read-only and does not have execute access for scripts. This is especially important for directories to which users are permitted to upload files. It would be disastrous if an application permitted arbitrary files, including ASP files, to be uploaded and executed.
