# Compa Insight Manager Buffer Overflow

| Popularity: | 10 |
| Simplicity: | 8 |
| Impact: | 7 |
| Risk Rating: | 8 |

As if passwords werent enough, the CIM login interface was found to be
vulnerable to a buffer overflow attack in 2001. The buffer overflow occurs when the stan-
d CIM login form is posted with an oversized name field and at least some value in the
password field. An exploit for this vulnerability called compack was written and pub-\lished by a hacker named indigo. It basically walks script kiddos through the process of
exploiting the vulnerability by automatically generating the malicious input, and in-
structing how to paste it into the "Name" field in the CIM login form. The exploit is
actually run on the attacker's machine, and takes a single port number as an argument.
Once successfully, a file called exploit.bin is generated. This file contains data that
be pasted into the name field of the CIM login screen, and when submitted (again, with
s random value in the password field), creates a listener on the attacker-defined port.
The listener is piped to a shell with Windows SYSTEM privileges. The attacker then sim-
cts to the listener with netcat and obtains a remote shell running as SYSTEM.
The following illustration shows how the executable being run from a Windows
command prompt:

```
C:\comhost netcat 777
Compag. Insight Manager overflow launcher
by Indigo <indigo@talk21.com> 2001

This program will generate a binary file called exploit.bin
Connect to the victim using a web browser http://victim:2301
Next to 'Login Account'
```
