# Appendix C: Using Libwhisker

| Value | Description |
| --- | --- |
| $['Connection'] | Default 'Keep-Alive'. This is a custom HTTP header for the 1.1 protocol. |
| $['User-Agent'] | Default 'libwhisker/1.4'. This identifies the type of browser. |
| $['whisker']-\>{'http\_ver'\} | Default '1'. This is the HTTP protocol version number. |
| $['whisker']-\>{'host'\} | Default 'localhost'. This is the hostname or IP address of the target server. |
| $['whisker']-\>{'method'\} | Default 'GET'. This is the HTTP request method. It is usually GET or POST, but could be one of the WebDAV options as well. |
| $['whisker']-\>{'port'\} | Default '80'. The remote Web port number. Note that setting this to 443 does not libwhisker use SSL. |
| $['whisker']-\>{'ssl'\} | Default '0'. This set to 1 to put libwhisker in SSL mode, regardless of the remote port number. |
| $['whisker']-\>{'timeout'\} | Default '10'. The number of seconds to wait for a response. |
| $['whisker']-\>{'uri'\} | Default '/\'. The resource to request from the server. This is often overridden in function calls. |
| $['whisker']-\>{'INITIAL\_MAGIC'\} | Default '31337'. This is used internally by libwhisker to verify that a hash is valid. In other words, the http_init_request sets this by default. If you create your own hin hash from scratch, then you'll have to set this value. |
