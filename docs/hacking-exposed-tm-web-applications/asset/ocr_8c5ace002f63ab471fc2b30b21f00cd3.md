# Hacking Exposed Web Applications

# lynx

| | |
|---|-|
| Pro: | Flexible, command-line, SSL support, free |
| Con: | Clumsy for mirroring a site |
| Final Analysis: | Great for checking single URLs from the command line |

lynx (lynx.browser) is a text-based Web browser found on many UNIX systems. It provides a quick way of navigating a site, although extensive JavaScript will inhibit it. It finds that one of its best uses is downloading specific pages.

The -dump option is useful for its "References" section. Basically, this instructs lynx to simply dump the Web page to the screen and exit. You can redirect the output to a file. This might not seem useful at first, but it includes a list of all links embedded in the page's HTML source. This is useful for enumerating links and URLs with long argument strings.

```
[root@mobile]# lynx -dump https://www.victim.com > homepage
[root@mobile]# cat homepage
... text removed for brevity...
```

If you want to see the HTML source instead of the formatted page, then use the -source option. Two other options, -crawl and -traversal, will gather the HTML and save to file. However, this is not a good method for creating a mirror of the site because saved files do not contain the HTML source code.

lynx is an excellent tool for capturing simple URLs. Its major advantage over the "get" scripts is to perform HTTP basic authentication using the -auth option:

```
[root@mobile]# lynx -source https://www.victim.com/private/index.html
Looking up www.victim.com
Making HTTP connections to 192.168.201.2
Secure 168-bit TLSv/SSL3 (EDH-RSA-DES-CBC-3-SHA) HTTP connection
Sending HTTP request.
HTTP request sent; waiting for response.
Alert! Can't retry with authorization!
Can't Access `https://192.168.201.2/private/index.html'
```
