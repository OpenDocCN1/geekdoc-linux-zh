# http_do_request Function

The heart of libwhisker is the http_do_request function. After all, this is what sends a URL request and receives the server's response. Calling the function is simple. Note that before you call any function that uses the %hin hash as crawl, you must initialize the %hin hash with the http_init_request function:

```
my $hin, $hout;
http_init_request(\$hin);
http_do_request(\$hin, \$hout);
```

The request function operates on two hashes, hin and hout. Their naming convention in relation to set particular variables for the HTTP request. For example, this hash contains custom headers and URLs that are passed in the function. The hout contains the server's response—for example, the HTTP error code and page contents. Table C-1 lists the most common values for the hin hash and a description of each.

The http_do_request function can also override these values if you specify parameters. For example, the following code is an example of how to request an alternate URL. The $hin['whisker']->['uri'] value is set to "/admin/menu/user.php":

```
LW::http_do_request(\$hin, \$hout, {'uri'=>/admin/menu/user.php'});
```
