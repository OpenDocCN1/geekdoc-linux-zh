

如果交互变量不为空，则会启动一个无限循环，其中包含文件名提示和后续的现有文件处理代码。如果期望的输出文件已存在，则会提示用户覆盖、选择另一个文件名或退出程序。如果用户选择覆盖现有文件，则会执行 break 以终止循环。请注意，case 语句仅检测用户是否选择覆盖或退出。任何其他选择都会导致循环继续并再次提示用户。

为了实现输出文件名功能，我们必须首先将现有的页面写入代码转换为 shell 函数，原因稍后会变得清楚：

```
write_html_page () {
    cat << _EOF_
    <HTML>
        <HEAD>        <TITLE>$TITLE</TITLE>
        </HEAD>
        <BODY>
            <H1>$TITLE</H1>
            <P>$TIME_STAMP</P>
            $(report_uptime)
            $(report_disk_space)
            $(report_home_space)
        </BODY>
    </HTML>
    _EOF_
    return
}

# output html page
if [[ -n $filename ]]; then
    if touch $filename && [[ -f $filename ]]; then
        write_html_page > $filename
    else
        echo "$PROGNAME: Cannot write file "$filename"" >&2
        exit 1
    fi
else
    write_html_page
fi
```

上述列表末尾的代码处理了 -f 选项的逻辑。在其中，我们测试文件名的存在性，如果找到文件名，则会进行测试以查看文件是否确实可写。为此，会执行 touch，然后测试以确定生成的是否为常规文件。这两个测试可以处理输入无效路径名的情况（touch 将失败），并且如果文件已存在，则确保它是一个常规文件。

正如我们所见，write_html_page 函数被调用以执行页面的实际生成。其输出要么被定向到标准输出（如果变量 filename 为空），要么被重定向到指定的文件。

## 最终说明

通过添加位置参数，我们现在可以编写功能相当完善的脚本。对于简单、重复的任务，位置参数使得可以编写非常有用的 shell 函数，这些函数可以放置在用户的 .bashrc 文件中。

我们的 sys_info_page 程序在复杂性和精妙程度上有所增长。以下是完整列表，其中最新更改已突出显示：

```
#!/bin/bash

# sys_info_page: program to output a system information page

PROGNAME=$(basename $0)
TITLE="System Information Report for $HOSTNAME"
CURRENT_TIME=$(date '+%x %r %Z')
TIME_STAMP="Generated $CURRENT_TIME, by $USER"

report_uptime () {
  cat <<_EOF_
<H2>System Uptime</H2>
<PRE>$(uptime)</PRE>
_EOF_
  return
}

report_disk_space () {
  cat <<_EOF_
<H2>Disk Space Utilization</H2>
<PRE>$(df -h)</PRE>
_EOF_
  return
}

report_home_space () {
  if [[ $(id -u) -eq 0 ]]; then
    cat <<_EOF_
<H2>Home Space Utilization (All Users)</H2>
<PRE>$(du -sh /home/*)</PRE>
_EOF_
  else
    cat <<_EOF_
<H2>Home Space Utilization ($USER)</H2>
<PRE>$(du -sh $HOME)</PRE>
_EOF_
  fi
  return
}

usage () {
  echo "$PROGNAME: usage: $PROGNAME [-f file | -i]"
  return
}

write_html_page () {
  cat <<_EOF_
<HTML>
<HEAD>
<TITLE>$TITLE</TITLE>
</HEAD>
<BODY>
<H1>$TITLE</H1>
<P>$TIME_STAMP</P>
$(report_uptime)
$(report_disk_space)
$(report_home_space)
</BODY>
</HTML>
_EOF_
return
}

# process command line options

interactive=
filename=
while [[ -n $1 ]]; do
case $1 in
-f | --file)
shift
filename=$1
;;
-i | --interactive)
interactive=1
;;
-h | --help)
usage
exit
;;
*)
usage >&2
exit 1
;;
esac
shift
done

# interactive mode
if [[ -n $interactive ]]; then
while true; do
read -p "Enter name of output file: " filename
if [[ -e $filename ]]; then
read -p "$filename exists. Overwrite? [y/n/q] > "
case $REPLY in
Y|y) break
;;
Q|q) echo "Program terminated."
exit
;;
*) continue
;;
esac
fi
done
fi

# output html page
```

## 流程控制：使用 FOR 进行循环

在本章关于流程控制的最后一章中，我们将研究 shell 的另一个循环结构。*for* 循环与 while 和 until 循环不同之处在于它提供了一种在循环期间处理序列的方法。这在编程时证明非常有用。因此，for 循环是 bash 脚本中非常流行的结构。

for 循环自然地使用 for 命令实现。在现代版本的 bash 中，for 有两种形式。

### for：传统 Shell 形式

原始 for 命令的语法如下：

```
for variable [in words]; do
    commands
done
```
