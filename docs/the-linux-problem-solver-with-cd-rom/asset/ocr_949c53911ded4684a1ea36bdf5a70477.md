You've got Linux installed and running. But what do
you do when you can't connect to the Web and the
printer spits out gibberish?

The Linux Problem Solver helps you through these and
other Linux snags with detailed troubleshooting
techniques and how-tos. You'll solve problems with:

+   - Printing, filesharing, and connecting to a network
+   - Configuring and installing software from source code
+   - Compiling and installing a new Linux kernel
+   - Debugging network connections and securing
+   your system
+   - Recovering from system crashes and preventing
+   serious damage

Each chapter covers a specific Linux issue in depth. In
addition, over 100 specific problems are addressed
throughout in separate problem boxes (see the quick-
reference list at the back of the book for a rundown of
the problems covered).
