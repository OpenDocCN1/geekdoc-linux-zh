
要了解dd在设备上能做什么，试试这个：

```
$ dd if=/dev/zero bs=1k count=6 > /tmp/foo
```

虽然这个命令本身不是特别有用，但它确实展示了dd的选项结构。这个示例看起来就是这么简单：它从/dev/zero读取1KB大小的输入块，共六次，输出到/tmp/foo（默认的标准输出）。

dd的大小选项通常以字节为单位，但你可以用k（1024字节）、b（512字节）、w（2字节）以及info和手册页中描述的其他一些选项来修改。最重要的选项是：

### bs=n, ibs=n, obs=n

将块大小设置为n。由于存在两个块大小（一个用于输入，一个用于输出），因此有三个选项：bs同时设置两者，ibs设置输入块大小，obs设置输出块大小。默认值为512字节。

### count=n

最多读取n个块。

### if=name, of=name

设置输入和输出文件（默认为标准输入和输出）。

### conv=method

此选项主要用于转换非Unix格式。例如，它可以将EBCDIC转换为ASCII，反之亦然（使用ascii和ebcdic方法）。更多细节请参阅info页面。

与Linux附带的一些GNU版本工具一样，dd的功能已经扩展到其他Unix变体版本之外；手册页并未列出所有选项，因为GNU希望你使用info文档。不过，dd --help确实提供了快速摘要。

## cpio

你可能时不时会遇到cpio归档文件。这种格式（准确说是格式集合）常见于来自HPUX和Stardent Titans等系统的磁带。以下部分涵盖提取cpio归档文件所需了解的内容。

cpio与tar类似，有几种模式：提取模式（使用-i启动）、创建模式（-o）以及用于复制文件的直通模式（-p）。测试归档是提取模式的一部分，你可以输入以下命令：

```
$ cpio -i -t -I archive
```

其中archive是cpio归档文件的名称（也可以是磁带驱动器）。要提取归档，请运行：

```
$ cpio -i -d -I archive filename(s)
```

这里filename(s)是可选的；它指示cpio仅提取与这些名称匹配的项目。-d选项按需创建目录（tar会自动执行此操作）。尽管GNU cpio会尝试自动检测格式，你可能仍然需要在-i之后使用以下选项之一：

### -b

cpio的默认格式取决于机器架构的字节序。此选项用于交换字节序。

### -C n

使用n作为归档的块大小。

### -H name

使用name作为cpio归档的类型（格式）。与旧版cpio归档直接相关的选项有bin、crc、hpb in、hpoc、newc、odc、tar和ustar。请注意，这些针对GNU版cpio；其他版本（如BSD系统自带的版本）不支持这么多归档类型，而且使用不同的名称。

### -v

详细输出（有点类似tar的详细设置）。

相关man页面：cpio (1)

## dump和restore

作为tar的替代品，dump和restore程序源自较早的Unix工具，它们通过查看磁盘上文件系统的内部结构来备份文件系统（与tar和cpio不同，后者仅使用内核文件系统接口的信息）。这些程序随许多Linux发行版提供，虽然它们的工作方式与传统dump和restore程序不尽相同，但确实共享相同的文件格式，因此你可以在不同平台上使用它们。

### 交互式恢复

你可以在自动和交互模式下使用restore。交互模式更受欢迎：

```
# restore ivf filename
```

其中filename是归档的名称（可以是设备或文件）。上面的命令行从归档开头获取索引信息，然后向你显示一个新的命令提示符：

restore >

在此提示符下，你可以运行cd、ls和pwd命令（help提供简短摘要）。在浏览文件系统时，使用add命令将文件或目录添加到要恢复的文件和目录列表中。当你将项目添加到提取列表时，项目旁边会出现星号（*），如果你选择目录，restore会立即创建它（连同其所有子目录）。

选择完文件后，使用extract命令继续进行实际的文件恢复。restore会要求输入卷号；直接输入1即可，因为你可能只有单卷归档。它还会询问你是否希望为.目录设置所有者和权限模式。如果选择是，当前目录将拥有与原始归档挂载点相同的权限。如果要恢复到与原始文件位置不同的地方，你可能应该选择否。

### 自动恢复

要执行自动恢复，请运行：

```
# restore rvf $TAPE file1 file2 ..
```

其中file1 file2等指定要恢复的内容。如果省略它们，将恢复整个归档。

### dump

要备份（dump）目录，可以使用这样的命令：

```
# dump -0 -f filename fs|directory
```

0表示完整级别0转储，filename是存储归档的设备或文件，fs或directory是要备份的文件系统或目录。除了这些信息，你可能还需要提供-d n和-s n选项来指定磁带的密度和长度。

我们不建议使用dump进行备份。它不够灵活，尤其是在备份多个磁盘时。GNU tar工作得很好，并解决了传统上反对使用tar的论点：GNU tar支持单个文件系统备份、多卷备份以及特殊/稀疏文件。
