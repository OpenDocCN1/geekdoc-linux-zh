## Emergency Boot Support

除了书中提到的软件包之外，您在 CD-ROM 上还会找到一套紧急和恢复实用工具。它提供了一个启动映像，以及一些基本系统程序来帮助您。以下是有关紧急启动相关目录的简要说明：

- bin    紧急启动 CD-ROM 二进制文件。
- boot    启动软盘映像。
- info; man    手册和信息页面。
