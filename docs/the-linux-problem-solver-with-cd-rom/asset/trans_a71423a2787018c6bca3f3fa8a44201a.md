
当你忙于处理系统管理员必须做的其他所有事情时，还要提出一个令人满意的组织方案。

Amanda（http://www.amanda.org/）是一个用于自动化备份的软件包。它由一个客户端程序和一个服务器端程序组成：客户端程序运行在你要备份的机器上，服务器端程序则用于连接磁带机的机器。Amanda可以在Unix平台上运行——你只需在所有机器上安装该程序的客户端部分。你需要一个大容量且有大量可用空间的磁盘。

Amanda写入磁带的数据格式并无特别之处。第一个文件是索引，其余部分由一组归档文件组成，这些文件可以是任何类型（tar、dump/restore、cpio等）。一切就绪后，你可以使用amrestore cover进行简单的文件恢复。如果遇到真正的麻烦，你总可以查找文件，并用常用工具（如tar）来恢复它们。

## 配置 Amanda

Amanda最难的部分是起步。一旦你通过至少部分正确的配置文件让一切运转起来，并熟悉了它的一些程序，对安装进行微调就很简单了；Amanda的在线文档内容完整、描述详尽，足以帮你解决各种细节问题。因此，本节将介绍如何让Amanda运行起来——不一定要完美，而是让你在配置不适合自己的需求时能够进行调整。

你可能需要按照第6章所述，从源代码构建位于随附光盘support/backupcrash目录中的软件包。配置时，请指定哪些用户对你要备份的机器上的文件系统具有写权限（在configure时使用`--with-user=user`选项——如果你使用GNU tar，则可能是root），以及哪个组可以运行以root权限setuid的程序（使用`--with-group`选项，用于非root操作员访问）。你可能还想通过`--with-configdir=dir`将默认配置目录改为dir，因为在大规模网络中维护一个默认目录是很困难的。我们强烈推荐使用`--with-amandahosts`选项；它告诉客户端使用`.amandahosts`文件而不是`.rhosts`文件来进行dump访问（稍后我们还会在本节中提到这一点）。

安装完Amanda后，你需要至少创建一个配置目录。这是Amanda存放信息的地方，包括它应该备份哪些机器和目录、要使用的磁带列表、磁带设置等。如果安装前缀是/usr/local，并且你创建了一个名为/usr/local/etc/amanda/servers的目录，那么servers就是一个合法的配置目录名。

配置目录中需要三个文件：amanda.conf、disklist和tapelist。一般备份参数在amanda.conf中，disklist包含要备份的目录列表。Amanda会在运行一次amdump后为你创建tapelist文件。

### amanda.conf

创建amanda.conf的最佳方法是复制一个示例，然后根据自己的需求进行修改。当你配置Amanda时，可以在源代码的example子目录中找到一个示例amanda.conf。复制该文件，编辑副本，跳过第一部分，然后向下找到如下所示的部分：

```
runtapes 1      # number of tapes to be used in a single run of amdump
tpchanger "chg-manual"  # the tape-changer glue script
tapedev "/dev/null"    # the no-rewind tape device to be used
rawtapedev "/dev/null"  # the raw device to be used (ftape only)
changerfile "/usr/adm/amanda/DailySet1/changer"
changerfile "/usr/adm/amanda/DailySet1/changer-status"
changerfile "/usr/local/amanda/amanda..."
changerdev "/dev/null"
```

这里你需要进行一些修改。首先将tapedev的/dev/null改为你的磁带设备。正如注释所说，这应该是无回绕磁带设备。提到ftape的那一行可能不适用；较新版本的ftape驱动程序应该提供完整的文件标记仿真。将所有changer行注释掉——这些行用于磁带自动换带机；即使你有换带机，从简单配置开始也更容易。

文件中的下一行是：

```
tapetype HP-DAT      # what kind of tape it is (see tapetypes below)
```

除非你使用HP DAT驱动器，否则请更改这一行。磁带类型列表稍后出现在文件中，定义如下：

```
define tapetype HP-DAT {
  comment "DAT tape drives"
  # data provided by Rob Browning
  length 1930 mbytes
  filemark 111 kbytes
  speed 468 kbytes
}
```

请确保相应地更改这些规格说明。如果你在磁带驱动器手册中找不到这些规格，可以尝试使用Amanda网站上提供的大量tapetype参考资料。
