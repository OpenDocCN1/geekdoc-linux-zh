# **Organization**

Especially on larger sites, keeping track of what software has been installed can present quite a challenge. A helper package simply goes into /usr/local, you may find odd files and programs there and wonder where in the world they came from. Knowing the origins of files is important: Lingering files from an old version of a program may cause a newer version to malfunction.

> *On traditional Unix networks, normal users never install packages in system directories. As for programs that users install in their home directories, administrators typically don’t care.*

Many Unix software organization schemes have evolved over the years. We’ll go over just one: Encap. This scheme specifies where to put installed software and how to link it to the system so it’s available to all users. You can find extensive information for Encap at http://encap.cso.uiuc.edu/. The Encap system has the following advantages:

+   - It keeps old versions of software packages intact.
+   - You can identify everything in /usr/local by package.
+   - It simplifies removal of old versions and of entire packages.
+   - Encap usually requires very little extra configuration and works fine with autoconf.
