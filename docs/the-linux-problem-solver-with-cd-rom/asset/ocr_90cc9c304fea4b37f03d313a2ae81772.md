# 1.2 Conventions

We’ll use a monospaced typeface for text that appears on-screen or that you type into a terminal window. Punctuation will appear outside of quotation marks containing any on-screen text or commands.

Unless otherwise noted, examples in the book assume you’re using bash, but we’ll generally avoid the extensions that bash offers over the Bourne shell (/bin/sh). The user prompt will be the dollar sign ($). Anything that appears outside a paragraph will be in boldface, so user commands will look like this:

```
$ echo Hi, I am a user.
```

The superuser (root), on the other hand, will have the pound sign (#) for a prompt:

```
# echo Hello, I am the sysadmin, and that user complains too much.
```

Many Linux files and scripts have comments that begin with #, so pay attention to the context.

```
# echo This is not a comment.
# my program has a comment here
```
