# PROBLEM 108

Symptoms: Users wonder where environment variables come from and complain about being forced to use the default system startup files.

Problem: Using a shell’s ‘system default’ startup file.

Fix: Use customized system startup files instead. Make the default startup files include some code like this excerpt from a default .profile:

```
# Read in some system-wide defaults
/usr/local/etc/sys-profile
```

Make sure that you document /usr/local/etc/sys-profile well, and don’t make this file large—if it becomes too large (say, more than 10 lines that aren’t comments), you’re probably doing something wrong.

+   - /bin
+   - /usr/X11R6/bin
+   - $HOME/bin

It also wouldn’t hurt to include

+   - /usr/local/sbin
+   - /usr/sbin
+   - /sbin

because programs like traceroute are in these directories, and users like to tinker with such utilities. However, you’d most likely be making a mistake to include anything else.

All user programs should be executable from one of the four bin directories listed above. If they aren’t, don’t change environments around to reflect where the programs are, because that makes the environments much more difficult to maintain. Instead, create symbolic links from the programs to /usr/local/bin.

You may also want to get rid of the /usr/X11R6/bin in the path and make symbolic links from the X programs to /usr/local/bin. The X11R6 name, after all, depends on X11R6 (X version 11, release 6), which some other version may supplant in future.
