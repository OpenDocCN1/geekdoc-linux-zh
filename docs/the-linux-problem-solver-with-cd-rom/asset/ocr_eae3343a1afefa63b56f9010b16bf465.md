# KERNEL UPGRADES

# 7.1 Introduction

The Linux kernel is the core of the operating system. It manages processes and resources, provides most of the hardware drivers, and handles the filesystem interface. The kernel is under constant development, so new drivers and bug fixes appear all the time.

If you plan to recompile your kernel, you’re probably doing so to get better system performance, add a new device driver, or fix some bug. The fastest way to break a machine is to screw up the kernel. The good news, though, is that once you’re familiar with the kernel, you’ll find it relatively easy to recover from a broken kernel; it’s not as though you’ve filled your hard drive with null bytes.

Sections 7.2, 7.3, and 7.4 outline the three steps involved in compiling a new kernel. Section 7.4 also contains detailed information on installing and booting the kernel—including how to use LILO (the Linux loader, also capable of dual-booting) and how to boot the kernel off a device other than a hard drive (for emergencies or bootstrapping).

7.5 explains kernel modules and a few aspects of the automatic kernel module loader. Kernel modules are dynamically loadable parts of the kernel that can simplify the configuration process and eliminate wasted system resources.
