This relatively small Perl script generates another Perl script. Run the
script as follows:

```
gen_signal_demo.pl > signal_demo.pl
```

The generated script will have signal handlers for all the signals avail-
 able on your system. The generated script defines signal handlers using the
following construct:

```
\$SIG( \$shortened signal name)  = sub { # handler code };
For example, the SIGINT handler is defined here:
\$SIG(INT) = sub { print "Caught an INT signal.\n"; };
```
