These cron jobs are used to run the `run-parts` script located in the `/usr/bin` directory. This script is run every hour, every day, every week, and every month using the four cron job specifications in the preceding listing. It takes a directory name as an argument and runs all the scripts or programs located in that directory. For example, consider the first cron entry in the preceding listing. It states that the `run-parts` script should be run at the first minute of every hour. The script is fed the argument `/etc/cron.hourly`. Because the script runs all the files located in this directory, the entire process effectively works as if all the files in the `/etc/cron.hourly` directory had been set up as cron jobs. This trick allows you to put new files in the `/etc/cron.hourly` directory and automatically have it scheduled for an hourly run. Similarly, the other three cron entries allow you to run any program on a daily, weekly, or monthly basis simply by placing them in the `/etc/cron.daily`, `/etc/cron.weekly`, or `/etc/cron.monthly` directory, respectively. This makes it easy to create cron jobs for most everything without really having to configure a cron entry.
