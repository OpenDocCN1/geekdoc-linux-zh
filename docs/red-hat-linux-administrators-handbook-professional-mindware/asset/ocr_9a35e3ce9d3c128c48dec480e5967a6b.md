Message Protocol (ICMP) echo request to the remote host. Because the response to an echo request is required by the protocol, the remote host is bound to send an echo response back. This allows the ping program to calculate the amount of time it takes to send a packet to a remote host. For example,

```
`ping blackhole.nitec.com`
```
