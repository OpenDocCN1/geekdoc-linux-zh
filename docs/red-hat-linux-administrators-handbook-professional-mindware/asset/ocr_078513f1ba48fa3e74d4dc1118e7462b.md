This is the most important configuration file for the server, and hence it is discussed in great detail in this chapter. You can specify five types of configuration information in this file.

**Access configuration** Access configuration can be specified using the class, deny, limit, noretrieve, loginfails, private, autogroup, and guestgroup keywords.

```
class
Syntax: class _classname typelist addrglob_
Default: class all real,guest,anonymous *
```

The class keyword is used to define a class name and specify the type of users who belong to the class. It also specifies the IP addresses or the domain names from which the class members can access the FTP server. The arguments are as follows:

+   * **classname.** An arbitrary name for the class.
+   * **typelist.** A comma-separated list of user types. Three types of users are available: real, anonymous, and guest. A real user is someone who has a valid username and password in the */etc/passwd* or */etc/shadow* file.
+   * **addrglob.** Can be an IP address of a host, a partial IP address with wildcards (such as 206.171.50.*), a host name (such as *blackhole.nitec.com*), or a partial domain name with wildcards (such as *.nitec.com).
