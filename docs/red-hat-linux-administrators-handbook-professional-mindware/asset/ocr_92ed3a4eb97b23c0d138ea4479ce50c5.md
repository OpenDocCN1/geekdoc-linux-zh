# ## Configuring FTP server

Your FTP server configuration consists of the following files in the /etc directory:

+   - services
+   - xinetd.d/wu-ftpd
+   - ftpaccess
+   - ftpconversions
+   - ftpgroups
+   - ftphosts
+   - ftpusers

The wu-ftpd server, like many other TCP/IP-based servers, runs via the Internet superserver called xinetd, which listens for an FTP connection on port 21; when such a connection request is detected, xinetd launches the wu-ftpd server. At startup, xinetd looks at two files, /etc/xinetds and /etc/xinetd.conf, to determine which service (port) is associated with a server. The /etc/xinetd.conf file contains a command for xinetd that tells it to read the /etc/xinetd.d/wu-ftpd file as the configuration file for wu-ftpd.
