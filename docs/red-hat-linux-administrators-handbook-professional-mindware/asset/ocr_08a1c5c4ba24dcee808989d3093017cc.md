After you ascertain the information about your system, you need to decide how you want to configure XFree86. You have three choices:

+   - Use a full-screen, menu-driven utility called Xconfigurator.
+   - Use a command-line, prompt-oriented utility called xf86config.
+   - Create the XF86Config file manually. This is the primary configuration file needed to create a usable X Window environment in XFree86. It usually resides in the */etc/X11* directory, and typically a symbolic link (/usr/X11R6/lib//lib//XF86Config) points back to */etc/X11/XF86Config*.
