If you want your server to start automatically after a system reboot, add the preceding line to your `/etc/rc.local` file or a similar file in your `rc.d` directory. I use the script shown in Listing 12-1 for automatic Apache startup and shutdown at boot and reboot, respectively.

# Listing 12-1 The httpd.sh script

```
```sh
#!/bin/sh
#
# httpd  This shell script starts and stops the
# Apache server.
# It takes an argument 'start' or 'stop' to start and
# stop the server process, respectively.
#
# Notes: You might have to change the path information used
# in the script to reflect your system's configuration.
#
[ -f /usr/local/apache/bin/apachectl ] || exit 0

# See how the script was called.
case "$1" in
start)
    # Start daemons.
    echo -n "Starting httpd:"
    /usr/local/apache/bin/apachectl start
    touch /var/lock/subsys/httpd
    echo
    ;
stop)
    # Stop daemons.
    echo -n "Shutting down httpd:"
    /usr/local/apache/bin/apachectl stop

    echo "done"
