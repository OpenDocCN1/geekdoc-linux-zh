+   2. Determines whether any of the programs (often called services) that are supposed to run in the new run level are already running. If a service is already running, the script kills the service so you can restart it in the next step. To kill a running service, the script runs the necessary K script with the stop argument.

+   3. Runs all the S scripts with the start argument.

# The /etc/rc0/rc0.d through rc6.d directories
