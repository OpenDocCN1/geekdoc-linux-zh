# Running a process in the foreground or the background

Normally, when you run a process from a console, shell, or xterm, you run the program in the foreground. When a process runs in the foreground, you have to wait for it to finish. However, instead of waiting for a process to finish, you can run it in the background by specifying & at the end of the command line. This becomes very handy when you are running a process that takes a long time to finish and you’d rather do something useful while it works. For example, suppose you want to use the du command to get an idea about what files are taking up the most disk space in your system. You can run it in the background as follows:

```
du> /tmp/du.out &
```

Here, the output is directed to a file, /tmp/du.out, because you do not want to be interrupted by du output while working on something else.

> **Tip**
> If you want to leave a program running in the background after you log off from a shell session, use the nohup program. It immunizes a command from getting SIGHUP and SIGTERM signals and allows the process to continue without a TTY. See the man page for details.
