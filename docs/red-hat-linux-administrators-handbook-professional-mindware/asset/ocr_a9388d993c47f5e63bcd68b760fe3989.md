# Setting Up POP Mail Service

The latest version of the POP protocol is 3, so install a POP3 server. Simply download the IMAP rpm file from Red Hat Web site or get it from your Red Hat CD-ROM. Install the IMAP package by using the rpm -ivh *package* *name* command.

After you install the server, configure it as follows:

+   1. Modify the `/etc/xinetd.d/lipop3` file so you have a line such as the following:

```
disable = no
```

If you do not have this file, you can create it as follows:

```
service_pop3
{
  flags = REUSE
  socket_type = stream
  protocol = tcp
  disable = no
  wait = no
  user = root
  server = /usr/sbin/in_pop3d
  logtype = FILE /var/admin/xinetd.log
  log_on_success = HOST EXIT DURATION
  log_on_failure = HOST ATTEMPT RECORD
}
```

+   2. Check the `/etc/services` file to make sure you have the following lines:

```
pop3 110/tcp # PostOffice V.3
pop 110/tcp # PostOffice V.3
```
