# Installing the **wu-ftpd** server

You have two options for installing the **wu-ftpd** server:

+   Install the precompiled RPM package version of **wu-ftpd**.
+   Get the source from `ftp://ftp.academy.com/pub/wu-ftpd/private/` and compile it yourself.

Because the Red Hat-provided **wu-ftpd** RPM package is quite suitable for most people, the second process is not described in this chapter. Use the **wu-ftpd** RPM package unless you have a very special reason for compiling and installing from the source. In the latter case, make sure you read the bundled documentation with great care.

# Installing from your Red Hat CD-ROM

To install from your Red Hat CD-ROM:

+   Log in to your Red Hat server as **root**.
+   Mount your Red Hat CD-ROM and change the directory to `RedHat/RPMS`. Run
+   ```
+   is | grep wu-ftpd
+   ```
+   to locate the RPM package for the **wu-ftpd** server.
+   After you locate the filename of the RPM package for **wu-ftpd**, run the following command to install the package:
+   ```
+   rpm -ihv name_of_the_wu-ftpd_package
+   ```
+   For example,
+   ```
+   rpm -ihv wu-ftpd-2.6.1-4.i386.rpm
+   ```
+   installs the 2.6.1-4 version of **wu-ftpd** for x86 computers. Your version number and system architecture may vary.

# Installing from a Red Hat FTP server

If you do not have the Red Hat CD-ROM or want to install the latest version from the Internet, run the following command:

```
`rpm -ihv URL`
```
