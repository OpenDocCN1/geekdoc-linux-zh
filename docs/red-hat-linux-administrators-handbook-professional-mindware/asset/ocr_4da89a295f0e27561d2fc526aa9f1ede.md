# Appendix A: Common Commands

This program allows you to convert file formats. For example, `dd if=/tmp/uppercase.txt conv=lcase of=/tmp/lowercase.txt` takes the /tmp/uppercase.txt file and writes a new file called /tmp/lowercase.txt, converting all the characters to lowercase (lcase). To do the reverse, use the conv=ucase option. However, dd is most widely used to write a boot image file to a floppy disk that has a file system already created by mkfs. For example, `dd if=some/boot.img conv=lcse of=/dev/fd0 obs=16k` writes the /some/boot.img file to the first floppy disk (/dev/fd0) in 16K blocks.

# df

**Syntax:** `df [-k] FileSystem | File`

The df command summarizes the free disk space for the drives mounted on the system. Hard disk space is an important resource in a computer and should be monitored carefully. Mismanagement of hard disk space can cause a computer to crawl on its knees, and cause some unhappy users.

To view the disk space summary for the current file system, run df .

The -k option displays the summary with 1024K-blocks.

# edquota

To assign disk quotas per user, use the edquota command. For example, to allocate a disk quota for a user named kabis, run the following:

```
edquota -u kabis
```

This brings up the default text editor (such as vi or whatever is set in the $EDITOR environment variable) with contents similar to the following:

```
Quotas for user kabis:
/dev/sda5 : blocks in use: 0, limits (soft = 0, hard = 0)

odes in use: 0, limits (soft = 0, hard = 0)
```
