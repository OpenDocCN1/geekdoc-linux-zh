# ## Using kill

The `kill` command can be a built-in shell command for many popular shells, such as `csh` and `tcsh`. However, there is also an external `kill` program, which typically is found in the /bin directory. Both versions work the same way. To find out what signals you can send to processes via `kill`, run the following:

```
```
kill -l
```
```

You should see a list similar to the following:

```
```
1) SIGHUP    2) SIGINT    3) SIGQUIT   4) SIGILL
5) SIGTRAP   6) SIGIOT    7) SIGSEGV   8) SIGFPE
9) SIGKILL   10) SIGUSR1   11) SIGSEGV  12) SIGUSR2
13) SIGPIPE  14) SIGALRM  15) SIGUSR1  17) SIGCHLD
18) SIGCONT  19) SIGSTOP  20) SIGTTIN  21) SIGTSTP
22) SIGTTIN  23) SIGCONT  24) SIGCKPU  25) SIGUSR1
26) SIGVTALRM 27) SIGPROF 28) SIGWINCH 29) SIGIO
30) SIGXCPU
```
```

The preceding output is produced by the built-in `kill` command in the GNU Bourne-Again Shell (`/bin/bash`). Other shells, or the `/bin/kill` command might generate different output. For example, `/bin/kill -l` produces the following:

```
```
HUP INT QUIT ILL TRAP IOT NUSUED FPE KILL USR1 SEGV USR2
PIPE ALRM TERM STKFLT CHLD CONT STOP TSTP TTIN TTOU ITO
XCPU XFSZ VTALRM PROF WINCH
```
```

Notice that these two `kill` commands differ in the `-l` output they produce. In fact, if you use `/bin/csh` (C shell) or `/bin/tcsh` (enhanced C shell) and run the built-in `kill` command with the `-l` option, you get another listing that does not match either of these.
