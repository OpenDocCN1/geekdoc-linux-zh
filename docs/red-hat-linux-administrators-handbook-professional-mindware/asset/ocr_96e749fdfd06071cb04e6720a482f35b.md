You should know my answer to this prompt. If you have a card that works only in PNP mode, you are likely to encounter problems. The best thing to do is buy hardware that has an option to turn off PNP.

# Block devices

In this section, you are asked about disk drives.

Normal FC floppy disk support (CONFIG_BLK_DEV_FD) [Y/m/n/7]

Because most systems have floppy drives, this should be set to yes.

If you use IDE/EIDE hard disks, an IDE/ATAPI CD-ROM, tape drives, floppy drives, and so on, say yes (or choose the module option) for all of the following questions:

+   Enhanced IDE/MEFM disk/odrom/tape/floppy support (CONFIG_BLK_DEV_IDE) [Y/m/n/7]
+   Use old disk-only driver on primary interface (CONFIG_BLK_DEV_ID_1SB) [Y/y/7]
+   Include IDE/ATA-2 DISK support (CONFIG_BLK_DEV_IDEDISK) [Y/m/n/7]
+   Include IDE/ATAPI CDROM support (CONFIG_BLK_DEV_IDECD) [Y/m/n/7]
+   Include IDE/ATAPI TAPE support (CONFIG_BLK_DEV_IDETAPE) [N/y/m/1]
+   Include IDE/ATAPI FLOPPY support (CONFIG_BLK_DEV_1DEFLIPPY) [N/y/7]

SCSI emulation support (CONFIG_BLK_DEV_NVDISCSS) [N/y/m/7]

SCSI emulation works only for IDE/ATAPI devices that do not have native driver support in Linux. You might want to consider a different driver to avoid emulation. I do not recommend emulation.

The CMD-Techologies CMD640 chip and the PC-Techologies RZ1000 IDE chips are common on many 486/P5 motherboards. If your system uses these chips, you need to say yes to the following prompts. If you do not know whether your system uses these chips, saying yes is not likely to cause any problem:

+   CMD640 chipset bugfix/support (CONFIG_BLK_DEV_CMD640) [Y/m/7] N
+   CMD640 enhanced support (CONFIG_BLK_DEV_CMD640_ENHANCED) [N/y/7] 1
+   RZ1000 chipset bugfix/support (CONFIG_BLK_DEV_RZ1000) [Y/m/7] 3
