The fourth option is for upgrading an existing Linux system. If you select this option, your existing Linux system will be upgraded using new version of the previously installed packages. We will assume that you are installing Linux on a new system and therefore will not discuss this option.

After you have chosen the Custom setup option, the installation program asks you to set up your disks.

# # Partitioning your disks

Partitioning your disks is a very sensitive step because you cannot safely change disk partitions without losing data. So, be very careful in this step.

The installation program displays a screen that asks you to choose a disk partitioning tool.

You have two choices—Disk Druid or the fdisk program. The Disk Druid partitioning utility is more user-friendly than the fdisk program, so I recommend it for beginning users. After you select this tool, your current disk partitions are displayed.

If you have partitions from your previous OS, such as MS Windows 9x/NT/2000, you can either delete these partitions here or use unused partitions to create a dual-boot Red Hat Linux system.

Red Hat Linux allows you to partition each disk, where each partition is labeled using the hda[ a-z 0-9] [ M] scheme for IDE hard disks and the sd[ a-z 0-9] [ N] scheme for SCSI disks. Here, N is the partition number and a-z is the partition letter. For example, hda1 is partition 1 on the first IDE disk—hda and, similarly, sda1 is the first partition of the first SCSI disk. You have to decide what you want to partition your disk(s). Here are some pointers.

+   1.  You need a / (root) partition to store your kernel and related files.
+       This partition need not be very large. In fact, you can make it as small as 256MB according to the Red Hat Server class specification, discussed earlier. Make sure that you choose Linux native as the partition type for the root partition.

+   2.  After you decide the size of the / (root) partition, decide the size of the /usr partition. This is where all of your applications will reside, so make sure this partition is relatively large. Your /usr partition should occupy at least 512MB. Make sure to choose Linux native as the partition type for the /usr partition.
