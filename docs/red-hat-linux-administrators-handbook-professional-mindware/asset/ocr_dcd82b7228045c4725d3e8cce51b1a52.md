# Part III: Troubleshooting

Part III contains information on how to secure and tune Red Hat Linux using various techniques. Chapters in this part cover the use of shadow passwords, Pluggable Authentication Modules (PAMs), file/directory integrity checking tools, TCP wrapper, and COPS; the use of private IP addresses, how to mask/unmask IP addresses, how to use packet filtering firewalls and proxy servers, and how to use SATAN for monitoring network security holes; and how to configure, compile, and build a custom kernel.

# Conventions Used in This Book

Here are a few conventions you should know about before reading this book.

+   Monospaced font is used to indicate URLs and the various commands, filenames, and options that would otherwise appear in program input or output.
+   *Italic* is used for placeholders.
+   Arrows are used to indicate progressive menu choices (e.g., Control↕Control files and systems↕Configure Linuxconf modules means to select the Control menu, then select first Control files and systems and then Configure Linuxconf modules from the resultant submenu)▽
+   Whenever a command line or a script code exceeds the width of a page, a backslash character (\) is used as a line continuation symbol.
