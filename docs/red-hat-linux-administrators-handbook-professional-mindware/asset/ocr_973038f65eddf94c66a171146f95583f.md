The `--layout` option allows you to verify the directory structure before it is actually made. If you are upgrading Apache from 1.2 and want to keep the old directory structure, use `--compat`, which uses the old-style directory structure.

The next step in configuring Apache is to decide whether you want to use the standard module configuration provided by its developers. If this is your first time compiling Apache, stick to the standard configuration, simply to get used to the entire process.
