# lprm

**Syntax:** lprm [-a] [jobid] [all]

The lprm command sends a request to lpd to remove an item from the print queue. The print jobs to be removed can be specified by the job ID or username, or they can include all items.

To remove all jobs in all print queues:

```
lprm -a all
```

To remove all jobs for the user kiwee on the printer p1:

```
lprm -Pp1 kiwee
```
