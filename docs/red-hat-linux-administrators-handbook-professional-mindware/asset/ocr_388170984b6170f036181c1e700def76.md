# **Caution**

Linuxconf runs as a setuid root process. Therefore, if a security hole is discovered in Linuxconf, it is likely to allow root privileges to anyone. Linuxconf is over 80,000 lines of C++ code. Frankly, I don't feel too comfortable running a large setup program via the Web. You have to make your own decision about using it over the Web.

As previously mentioned, by default, Linuxconf allows Web-based access only from the localhost. If you want to enable remote administrative access to Linuxconf via the Web, follow these steps:

+   1.  Run `linuxconf` from your console or X Window.
+   2.  Select the Config menu. Click the Networking button. Select the Misc menu and click the Linuxconf network access button. You should see a window such as the one in Figure 4-6.

![](bbox=[0.15, 0.44, 0.55, 0.75])

+   3.  Select the Enable network access check box.
+   4.  Select the /var/log/htmlaccess.log check box to allow logging of Linuxconf access requests via the network.
