# mkfs

**Syntax:** `mkfs [-t fstype] [-cv] device-or-mount-point [blocks]`

The mkfs command allows you to make a new file system. For example, `mkfs -t ext2 /dev/hda3` creates an ext2-type file system on the `/dev/hda3` partition of the first IDE hard disk. The `-c` option enables you to instruct `mkfs` to check bad blocks before building the file system. The `-v` option produces verbose output.
