If the authentication is successful (in other words, PLUTO allows connection), smcclient displays an FTP client-like prompt and allows you to perform many FTP client commands. Typing help or ? at any time provides more information about the commands.

You can use smcclient to list the available Samba resources on a remote computer. In the following example, the -L option specifies that the Samba server be interrogated using username *kabir*:

`smcclient -L reboot -U kabir`
