# # File Compression and Archive-Specific Commands

The commands discussed in this section help you to compress, archive, and package files.

# ## compress

**Syntax: compress [-v] file(s)**

The compress command attempts to reduce the size of a file by using the adaptive Lempel-Ziv coding algorithm. Files that are compressed are replaced by a file with a .Z extension. Any type of file compression may be beneficial, because having smaller file sizes increases the amount of available disk space. Also, transferring smaller files across networks reduces network congestion.

The -v (verbose) option displays the percentage of reduction for each file that was compressed and tells you the name of the new file. Here is a typical session using the compress command:

```
```
ls -a1F inbox
-rw-------    1 username cscstd   194261 Feb 23 20:12 inbox
compress -v inbox
inbox: Compression: 37.20% -- replaced with inbox.Z
ls -a1F inbox.Z
-rw-------    1 username cscstd   121983 Feb 23 20:12 inbox.Z
