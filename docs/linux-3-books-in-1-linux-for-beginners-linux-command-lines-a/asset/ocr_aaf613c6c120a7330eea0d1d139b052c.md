# ## Viewing ACL

You can use the following command to view the permissions written in ACL: `# getfcl filename`. The differences between the getfcl and setfcl commands are quite obvious. So, pay attention to them. We have used an extra line against the username Mandeep, and this is in the image above. You can use the above command to change the permissions in the ACL from `rwx` to `r-x`.
