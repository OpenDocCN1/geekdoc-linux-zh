## Ubuntu 是什么意思？

疣猪（The Warthogs）团队拥有优秀的队伍和明确的目标愿景，但当时团队还没有为该项目命名。正是舒勒沃思（Shuttleworth）坚持认为该名称应为 Ubuntu。

Ubuntu 是一个源自多种南非语言（如科萨语和祖鲁语）的术语和概念。它指的是一种南非伦理或意识形态，可译为“对他人的善意”或“我之所以为我，是因为我们共同存在。” 其他人也将 Ubuntu 翻译为“相信一种连接全人类的普世分享纽带。” 南非人权活动家德斯蒙德·图图大主教对 Ubuntu 的描述如下。

> “具备 Ubuntu 精神的人对他人开放且平易近人，肯定他人的价值，并不因他人能力强或品质好而感到威胁。他或她拥有恰当的自信，这种自信源于知道自己属于一个更伟大的整体，并且当他人受辱或受压迫时，这种自信会因个体的渺小而感到受损。”

舒勒沃思选择 Ubuntu 作为项目名称有许多理由。

- 1. 这是一个南非概念。参与 Ubuntu 开发的人员可能并非来自南非，但该项目的根源在南非。舒勒沃思希望名字能体现这一点。
- 2. 该项目关注与他人建立关系，并为一个分享和协作的社区奠定基础。这是自由软件的核心支柱。
- 3. Ubuntu 团队希望建立一个高度功能化的社区，该社区建立在人际连接和相互尊重之上的个人关系。Ubuntu 这一术语将向人们传达该项目的形成方式及其未来愿景。

由于以上所有原因，这个名称完美无缺，并一直沿用至今。

## 愿景

Ubuntu 的全职开发人员需要获得薪酬，而舒勒沃思需要一家公司来雇佣他们。舒勒沃思希望自由和开源社区中最优秀的开发人员致力于 Ubuntu 的开发。开发人员将来自世界各地，从而消除地理或国界限制。舒勒沃思决定不建立一家所有人坐在一起实体办公的公司，而是通过一家虚拟公司来雇佣开发人员。尽管这存在一些缺点，如时区差异、带宽和延迟问题等，但它也带来许多好处。员工的分布式特性意味着公司可以从世界任何地方招聘新员工，而无需要求他们打包行李搬迁到新国家工作。这也消除了办公室中常见的“饮水机闲聊”问题，即员工通常在饮水机上花时间进行个人交谈。由于这是一家虚拟公司，员工会在即时通讯工具上进行个人交流，同时也在从事项目工作。该公司名为 Canonical（规范），在初创时期，最接近办公室的地方是舒勒沃思在伦敦的住所。如今，该公司在全球多地设有办公室，但大多数员工居家办公。不用说，开发人员非常依赖互联网协作。

## Ubuntu 社区

Ubuntu 如今取得的成就归功于 Ubuntu 社区。我们已经知道，Ubuntu 的定义也围绕着人和社区展开。我们将在专门的一章中讨论如何成为 Ubuntu 社区的一员。

## 目标与承诺

### 哲学目标

Ubuntu 最重要的目标是哲学层面的。你可以在其网站上找到关于 Ubuntu 哲学的详细文档。我们在下方逐字列出了其网站上的主要哲学观点。

### Ubuntu 的哲学

Ubuntu 是一个由哲学驱动的 Linux 操作系统，其目标是向全球分发自由软件，使人类从中受益。Ubuntu 哲学的核心理念如下。

- 1. 用户应能够下载、安装、分发、使用和修改软件以满足任何需求，并且应能免费完成这些操作，无需支付任何许可费。
- 2. 每个拥有计算机的用户都应能够使用该软件，且支持他们首选的语言。
- 3. 即使用户有残障，他们也有权使用支持其残障的计算机软件。

Ubuntu 哲学的这些核心理念体现在其操作系统中。当你在计算机上安装 Ubuntu 时，基础操作系统及其附带的所有软件已经符合上述理想。Ubuntu 始终致力于向用户提供具有完整自由度的软件许可类型。

## 自由软件

在 Ubuntu 中，“自由软件”中的“自由”一词指的是使用软件的自由，而非指成本，尽管 Ubuntu 仍然致力于提供免费软件。Ubuntu 在自由软件方面的主要目标是给使用其软件的用户完整的自由。这种自由使 Ubuntu 用户能够成长并拥有美好的体验。

什么是自由软件？根据自由软件基金会（Free Software Foundation）的定义，自由软件具有以下一组自由。

- 运行任何软件以满足任何需求的自由
- 理解软件并使其满足自己需求的自由
- 重新分发软件以帮助其他人的自由
- 修改软件并公开发布，使每个人从中受益的自由

## 开源

“开源”（Open-source）一词于 1998 年引入，旨在将其与英语单词“自由”（free）区分开来。开源计划（Open-source Initiative）定义了开源软件。自那时起，开源变得非常流行并持续增长。

Ubuntu 是一个开源操作系统。关于自由软件和开源软件是否相同一直存在争论，但 Ubuntu 坚持认为它不认为自由软件和开源软件是不相容或不同的。Ubuntu 支持来自这两个运动的人群。

如果你阅读上述目标，你会意识到 Ubuntu 明确指出了用户应拥有使用自由软件的自由。为什么这如此重要？首先，用户实际上从比其他操作系统更快、更好、更灵活的软件中受益。用户还超越了软件消费者和使用者角色。Ubuntu 希望赋能软件，使其按照用户的需求运行。软件必须是自由的，Ubuntu 将其列入其哲学目标中。

自由软件并不是 Ubuntu 提出的目标的终点。它还有两个同样重要的目标。第一个目标是每个计算机用户都应能够使用最适合他们的语言使用计算机。这是对这样一个事实的承认：世界上并非所有人都懂英语，但世界上大多数软件仅使用英语。软件中有大量的文本内容，且必须使用某种语言编写；但如果仅使用英语，世界上许多人将无法使用该软件。计算机是教育和赋能的工具，但只有当用户理解其界面时才能做到这一点。Ubuntu 认为，确保世界上任何用户在使用 Ubuntu 时都能使用其首选语言，是人民和 Ubuntu 社区的责任。这种翻译通过 Ubuntu 关于修改能力的第一个哲学观点成为可能，修改能力是自由软件和开源软件的一个特性。
