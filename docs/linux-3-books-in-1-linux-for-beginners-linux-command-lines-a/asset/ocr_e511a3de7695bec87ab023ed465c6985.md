| :--- | :--- | :--- |
| `iptables` | `$ sudo iptables` | Manages incoming/outgoing traffic using configurable table rules | 管理进出的流量使用可配置表规则 |
| `iw` | `$ iw list` | Manages wireless devices and configurations | 管理无线设备和配置 |
| `iwlist` | `$ iwlist` | Shows detailed info from specified wireless interfaces | 显示指定无线接口的详细信息 |
| `kill` | `$ kill` | Uses a specified process’s PID to kill it | 使用指定进程的PID杀死它 |
| `killall` | `$ killall (process name)` | Kills a specified process using its name | 使用名称杀死指定进程 |
| `kmod` | `$ kmod` | Manages kernel modules | 管理内核模块 |
| `route` | `$ route` | Show or manipulate the IP routing table | 显示或操纵IP路由表 |
