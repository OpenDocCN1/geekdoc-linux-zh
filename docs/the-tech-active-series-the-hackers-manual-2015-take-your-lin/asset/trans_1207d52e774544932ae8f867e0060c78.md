

## 安装一个发行版

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_53_0.png)

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_53_1.png)

### 1 打开一个 shell

按 Ctrl+Alt+T 打开一个终端窗口。这将在浏览器标签页中打开一个基础的 Crosh shell，其命令集有限——你可以通过输入 list 来查看。命令之一是 shell，它会为你提供一个完整的 Bash shell（已修复 Shellshock），就像其他发行版一样。
没错——Chrome OS 背后有一个真正的 Linux 操作系统。

### 2 选择一个发行版和目标

运行 Crouton 并加上 -t list 将会显示所有可用的目标。你可能想要其中一个标准的桌面环境。Chromebook 的性能相对较低，选择一个轻量级桌面如 LXDE 是不错的选择，而 Unity 更适合全屏运行。

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_53_2.png)

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_53_3.png)

### 3 加密你的文件

在 Crouton 的命令行中添加 -e（这与 sh 之后的 -e 不同）会使你的 chroot 存储在加密目录中。选择一个足够强的密码短语——这是保护你文件安全的全部手段，但请记住，由于 Chromebook 存储空间非常有限，你的大部分数据可能都会保存在云端。

### 4 安装发行版

由于 Crouton 只是一个安装程序，它需要在安装前下载发行版的发布文件，因此请为此预留时间。即使网络连接很快，如果你选择了较大的目标，下载和安装所有内容也可能需要超过 30 分钟——大小在 crouton -t list 的输出中显示。

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_53_4.png)

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_53_5.png)

### 5 添加一个包管理器

默认目标仅包含命令行包管理器 apt-get。对大多数人来说，第一步是打开一个终端并使用它安装一个更友好的选项，例如 Ubuntu 的 software-center 或 Ubuntu/Debian 的 Synaptic。运行 sudo apt-get update 以确保你获取的是当前版本，然后运行 sudo apt-get synaptic。

### 6 运行 Synaptic

一旦安装了 Synaptic，你就可以轻松访问发行版仓库中的所有软件。大多数目标都被精简了，以节省下载量并加快安装速度，但你可以在这里安装任何想要的东西。可以使用搜索按钮，或直接浏览分类查看可用内容。

## 恢复磁盘

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_54_0.png)

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_54_1.png)

### 1 备份到 USB

插入至少 2GB 容量的 USB 闪存盘或 SD 卡，打开 Chrome 并在地址栏输入 chrome://imageburner。Chrome OS 会下载并安装适用于你的 Chromebook 的恢复镜像。如果你拥有不止一个型号的 Chromebook，请为每个设备分别运行此操作：它会获取该设备的正确镜像。

### 2 创建恢复磁盘

下载完成后，镜像会被写入你的 USB 闪存盘。如果你不创建恢复磁盘，也可以从另一台电脑获取此镜像并手动复制，方法是按照 http://google.com/chromeos/recovery 上的说明操作，但你必须确保获取的是正确的镜像——它们特定于每个型号。

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_54_2.png)

![](img/b6e789f7b1bc6629f6c97a3e4beae1de_54_3.png)

### 3 紧急情况下

如果 Chrome OS 损坏并出现以下令人害怕的“Chrome OS 缺失或损坏”信息，请插入你的恢复介质。你也可以通过按下硬重置按钮或按键组合来强制恢复，如果你想无论如何都进行恢复的话，具体组合因型号而异。请查阅你的 Chromebook 文档以了解适用情况。

## Crouton：利与弊

将一台 200 英镑的 Chromebook 与一台完整笔记本电脑相比似乎不公平——它更接近上网本的价格范围，面向相似的市场——但我们还是这么做。在 Chromebook 上运行 Ubuntu 或 Debian 就像在真正的笔记本电脑上运行一样。唯一的区别在于使用了 chroot 以及启动时出现的吓人信息。这意味着你必须先启动到 Chrome OS，然后打开 shell 来启动 chroot 会话，但 Chromebook 设计为挂起而非关机，所以这种情况并不常见。由于它通过 Chrome OS 使用硬件，你需要在其中设置网络连接等操作，但由于你可以随意在操作系统之间切换，这不是问题。这不是双启动；这是同时运行两个系统——方便得多。

这种设置的主要限制是存储空间不足以及对网络连接和云服务的依赖。虽然 Chrome OS 会透明地处理这个问题，但你需要为你的 chroot 发行版设置某种在线同步，使用 OwnCloud、SpiderOak 或 Dropbox 等服务。

在 Chromebook 上安装 Linux 的方法还有其他，但 Crouton 的方式侵入性最小，保持了现有操作系统的完整性（除了需要启用开发者模式）。你也可以尝试多个发行版，并在完成后将其移除，这也是这种方法的一个关键优势。最重要的是，Crouton 由 Chrome OS 作者开发，并非第三方破解。Chrome OS 的未来更新可能会暂时破坏你的 chroot，但通过 Crouton 快速更新即可修复。
