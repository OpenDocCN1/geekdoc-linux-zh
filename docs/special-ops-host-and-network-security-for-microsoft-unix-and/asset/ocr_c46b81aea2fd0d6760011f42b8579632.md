Create OS-specific checklists based on this list; also use specific information from each chapter of this book, as well as data from alternative sources like www.sans.org/score. Additionally, you should track listening TCP and UDP ports. Figure 1.2 shows a basic example of a partial Windows checklist. Other tabs of the spreadsheet can include things such as an IIS log sample, output from Fport.exe, or external TCP/IP ports.
