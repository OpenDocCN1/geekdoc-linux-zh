# Creating a Batch File

Typically, wardial is done after hours to avoid interrupting the normal course of business or alerting any employees. Additionally, after-hours dialing is preferred because that is typically the time remote desktop applications are in use for employees who like to work from home. Since after-hours dialing may limit the amount of available dialing time (usually 7 P.M. to 7 A.M.), if the modem hangs up on one in the beginning of the list of numbers to be dialed, the whole night's dialing time will be wasted. Batch files are easy to make and ensure that if the modem hangs on one number, the modem will time out and disconnect and reinitialize, picking up on the next number where it left off. This ensures no time is lost for a large scan. An example of what a batch file looks like for ToneLoc is shown in Figure 2.8.
