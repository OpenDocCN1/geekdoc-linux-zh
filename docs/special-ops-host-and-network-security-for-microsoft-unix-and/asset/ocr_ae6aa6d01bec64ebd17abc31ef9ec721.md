# Finding 802.11 Networks from the Wired Side

If you're dealing with a small network in only one physical location, you should be able to track any access points via wireless detection without too much effort. If you're dealing with a large enterprise network spanning multiple cities, the job is a bit tougher. One way to detect many, but not all, 802,11 devices connected to your network is to scan for those from the wired side. Wireless access points are simple network devices, like switches and printers, and often come with built-in network management capabilities such as Simple Network Management Protocol (SNMP) and Web-based configuration. You can use management interfaces to detect the access points by scanning for these services and checking the results for identifiers that indicate a wireless device. Wireless clients are a little tougher to detect because they typically do not have services available to identify them as wireless. Despite this, there are some things you can remotely establish whether or not the host has wireless capabilities.

# SNMP and Other Management Services

Access points can be configured out of the box in several ways. An admin may either use a USB or serial cable to directly connect to the AP, he may have to change the IP to a static IP by the AP's manufacture and connect with a hub or crossover cable, or the AP may just configure itself via DHCP and start working away. For ease-of-use interests, many wireless vendors have chosen to go the auto configure route; the access point gets a DHCP address, the client connects with a SSID of “ANY”, and it's working. The point at which starts working is usually where most of your nonmalicious rogue AP installers are going to stop. Although this means that the access point is a wide open radio frequency (RF) hole into your network, it also means that it should be running with the default set of management options that you can readily remotely. Almost every access point vendor implements SNMP as a management option, with Telnet and Web features a close second. The AP will usually have a default SNMP community string which means it is easy enough to use a scanning tool like SolarWinds or SSScan(https://www.foundstone.com/knowledge/scanning.html) to locate the devices. Scan your network using common strings such as public, private, and so on. Wireless devices often have easy-to-recognize SNMP Descr, containing the word “Wireless” or having the name of a known wireless manufacturer.
