Although this may not seem like a big security breach, you should consider what is found in this file. First of all, the files are tab-delimited ASCII text files and are easily readable by any text editor. The second fields in these files includes the sender's Exchange distinguished name (/=Somorita Surfboards/ou=Honolulu/Recipients/an=SuriyaS), the address (SMTP, X.400, or legacy Exchange distinguished name), and, if enabled, the subject of the message. A clever person may be able to deduce a lot of information about an organization based merely on who is sending e-mail messages and the subjects of those messages.
