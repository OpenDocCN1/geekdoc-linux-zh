# # Links to Sites

+   - http://online.securityfocus.com/infocus/1193 Article by Charly van Walt, with a great overview of security policy in general.

+   - www.sans.org/newlook/resources/policies/policies.htm A collection of 24 information security policy templates.

+   - http://rr.sans.org/policy/policy_list.php Over 60 articles on security policy in the SANS reading room.Very useful to browse.

+   - http://secinff.net/policy_and_standards A collection of articles about security policy, with a new article every month or so.

+   - http://csrc.nist.gov/publications/nistpubs/index.html All NIST special publications, many security-related.

+   - http://csrc.nist.gov/publications/nistpubs/800-12/handbook.pdf NIST Computer Security Handbook, a great source for policy folder, with a synopsis here: http://secinf.net/info/lk_policy.html

+   - www.sans.org/newlook/resources/policies/bssi3 Slides presentation on general security policy topics.

+   - www.information-security-polices-and-standards.com Provides a number of pay policy downloads, in addition to the RUSecure policy samples. The RUSecure program is a fully capable trial version, good for experimenting with various ISO17799 policies.

+   - www.security.kirion.net/securitypolicy Download evaluation of COBRA risk analysis tool.Also check other information in security policy creation, delivery, and compliance.

+   - www.hipaadvisory.com/regs/securityoverview.htm Provides a great overview of the HIPAA Security Rule, so you can familiarize yourself with the general concepts before the final rule is established.

+   - http://aspe.hhs.gov/adminsimp/nprm/sec14.htm Useful document that matches specific sections of the security policy to implement requirements.

+   - www.ftc.gov/privacy/gbact The main FTC site for the GLBA act, filled with relevant information and legislative information for GLBA compliance.
