# Links to Sites

+   - http://community.whitehatsec.com This is an excellent site on Web application security, something every SQL Server security specialist should become intimately with.

+   - http://online.securityfocus.com This site has the best exploits database on the Net, combined with the home of the best security mailing list. It's a great place to look for SQL Server vulnerabilities based on patch level.

+   - www.owasp.org Here you can find good info on security Web-based development. The focus here is on the application and not necessarily the database, but you will need to secure both tiers.

+   - www.microsoft.com/security The Microsoft site is the facto source for NT and SQL Server security. Generally, people should submit new issues to Microsoft first so it can fix a issue before the world finds out about it. What good does it to tell everyone about a new exploit if you have no ability to fix the problem?

# Mailing Lists

+   - Bugtraq (http://online.securityfocus.com) This is an excellent list covering disclosures, vulnerabilities, and patches across all platforms. It's loosely moderated and tends to err on the side of full disclosure. It's an excellent list if you don't mind seeing a lot of issues not related to anything you're likely to be running. It requires more patience than most but not many hatches passing through this.

+   - NTBugtraq (www.ntbugraq.com) NTBugtraq focuses on issues related to Microsoft operating systems. It's tightly moderated and tends towards limited disclosure. This is a good list for those interested only in Microsoft-related vulnerabilities and not mind missing a few "irresponsible" disclosures that may make it through Bugtraq.
