# 前言

在当今这个快节奏、咖啡因驱动且有时鲁莽的网络安全世界中，“硬性外壳与软性内部”的安全类比在今天看来极具讽刺意味，因为我们投入了数百万资金来保护外部边界，却只花了一小笔钱来应对内部威胁。*Special Ops: Host and Network Security for Microsoft, UNIX, and Oracle* 的作者将带你沉浸在内部安全的复杂性中，以及经常被忽视的“软性内部安全”。
