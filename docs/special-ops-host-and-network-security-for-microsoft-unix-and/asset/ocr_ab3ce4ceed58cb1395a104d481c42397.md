Some variation occurs between the methods in which init starts in BSD and Sysv systems use a set of flat files. The command to start the service is contained in the flat file, or a master configuration file is used to specify whether or not the service will be started. In FreeBSD, for example, the default configurations are all contained in the /etc/defaults/rc.conf file. From this file, the following files get attributes for the initialization of the system, either directly or indirectly:

+   * /etc/rc
* /etc/rc.diskless2
* /etc/rc.firewall6
* /etc/rc.idson
* /etc/rc.network6
