I will offer you a couple of pieces of advice regarding the use of IIS Lockdown and URLScan. These include the following:

+   - Make absolutely sure that you have a recent release. Any version released on or after 11/14/2001 should be fine.
- Always choose the right server role when you run IIS Lockdown.
- Be very careful installing this tool if the HTTP server is providing multiple functions, such as OWA, IP Printing, Active Server Pages, etc.
- Examine the URLScan log periodically.
- You can undo anything the IIS Lockdown tool has done by simply running the tool again.

NOTE
For additional information on IIS Lockdown, URLScan, and Exchange, see Microsoft KB Q3090508.
