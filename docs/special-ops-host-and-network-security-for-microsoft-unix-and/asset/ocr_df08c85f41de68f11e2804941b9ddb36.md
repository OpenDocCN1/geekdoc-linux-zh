# Berkeley Internet Name Domain (BIND)

BIND is the original DNS daemon. The design and philosophy of BIND has been the groundwork for all other DNS platforms to date. BIND was originally based on the research of the UC Berkeley undergraduate program, and then taken over by the Internet Software Consortium (ISC) during version 4.9.3. The first production release of BIND was in May 1997.

# Specific BIND Vulnerabilities

Over the years, BIND has been found to have numerous vulnerabilities. Cache poisoning, buffer overflows and successful remote code execution have paved a rocky path for the most popular DNS daemon on the planet. With the recommended techniques, a current version of BIND can be moderately hardened, though, if security is your primary goal, DJBINDS may look more appealing. On November 12, 2002, Internet Security Systems (ISS) found two major holes in the security of BIND 8. Though exploit code has been released publicly, it is available among underground hacker groups. A complete historical list of BIND vulnerabilities can be found at www.isc.org/products/BIND/bind-security.html.

# Installing BIND

The initial BIND installation is simple. Pull the newest version of BIND from the ISC Web site and remember to check the file against the PGP checksum of the binaries (ftp.isc.org/isc/bind9/9.2.1/bind-9.2.1.tar.gz);

```
# wget http://ftp.isc.org/isc/bind9/9.2.1/bind-9.2.1.tar.gz
```
