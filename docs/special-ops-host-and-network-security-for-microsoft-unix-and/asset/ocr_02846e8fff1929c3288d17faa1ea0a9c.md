+   Adequate steps must be taken to prevent or control the outbreak of email-based viruses through a combination of client side, Exchange server, and SMTP virus scanning.

+   Message size limits and mailbox storage limits should be imposed.

+   Implementing SSL is one of the critical steps necessary to improve Internet client security.

+   Internet Information Server should be locked down with IIS Lockdown using the Exchange 2000 template.

# Auditing for Possible Security Breaches

+   Windows 2000 auditing is critical to understanding who is doing what with the operating system.

+   Exchange 2000 diagnostics logging will provide you with a better understanding of the types of access happening on the Exchange server.

+   Protocol logging is the key to tracking potential access from the outside world.

# Following Best Practices

+   Develop good operational procedures, including plans for what will be done daily on each Exchange 2000 server.

+   Keep Exchange 2000 and Windows 2000 up-to-date with patches and security updates.

+   Properly manage the event logs and protocol logs that each Exchange creates.
