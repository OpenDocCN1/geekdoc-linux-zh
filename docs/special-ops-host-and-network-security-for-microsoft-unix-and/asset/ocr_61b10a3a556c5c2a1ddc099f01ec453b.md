Dstumbler will require kernel patches in the bsd-airtools if you are using an OpenBSD version before 3.2. Assuming you have patched and rebuilt your kernel or are using a newer BSD version, you just need to specify the interface you'd like dstumbler to use and wait for the UI to load. An example command line usage would look like this:

```
bsd2.foundation.com># dstumbler wi0 -o -1 dstumbler.log
```

where

+   - wi0 is the interface name you want dstumbler to use
