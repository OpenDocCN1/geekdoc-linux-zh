# Windows 2000 Basics

+   Windows 2000 is based on an improved version of the Windows NT 4.0 kernel, which provides protection of the operating system through isolation of applications away from the operating system and hardware.

+   Windows 2000 provides the capability to secure file systems and disk access through the use of the NTFS file system, but also allows for backward compatibility if needed by supporting FAT and FAT32 formatting.

+   Windows 2000 uses local and domain-user accounts and groups to begin the process of granting access to resources and authenticating users in either the workgroup or domain environment.
