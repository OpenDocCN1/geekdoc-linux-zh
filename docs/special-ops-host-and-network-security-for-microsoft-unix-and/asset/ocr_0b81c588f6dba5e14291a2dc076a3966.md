# Tracking and Applying Updates, Service Packs, and Patches

With all the potential vulnerabilities that we have looked at throughout this chapter, applying updates, service packs, and patches is definitely an area that is crucial for your continued success in the hardening of Windows 2000 platform machines. We are never aware if you are working in the Infosec field that continued vigilance is absolutely a requirement for success in attempting to slow the flow of attackers. Be sure in your hardening efforts that you continue to stay on top of the large number of patches and keep your system up to date as possible.

Again, there are many tools available to assist you in tracking the production and availability of updates, service packs, and patches. One of the freely available tools for analysis of domain or workgroup machines in Windows NT, Windows 2000, and Windows XP environments is the command-line hotfix HFNetchk, which is free from Microsoft on their security. In the following example, I ran a quick scan with the tool against a test network and sent the output to a text file for further study. This tool is useful because the administrator has the ability to schedule a task calling this tool on a regular basis with an appropriate output file to file.
