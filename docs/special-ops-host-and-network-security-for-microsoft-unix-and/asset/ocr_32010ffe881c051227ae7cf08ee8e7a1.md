This collection of groups allows administrators to assign or delegate permis-sion to work within specifically defined areas of control to perform system-based tasks in the domain. These built-in groups are utilized in a different way than they were in Windows NT 4.0. In the Windows 2000 Active Directory system, the ability to delegate control much more precisely than in Windows NT 4.0 is part of the upgraded directory service and feature set. Note in Figure 5.7 there is a group called Pre-Windows 2000 Compatible Access. This group can lead to security difficulties, because it can contain the special group Everyone in its membership. This may establish a mull session connection with the use of a blank password for anonymous access. In this case, anonymous users (such as a Web page) could potentially access and obtain control of your machine. This particular con-figuration requires you to prepare file and drive access control settings, but may be needed depending on your network's mask.

There is a significant difference in the sphere of influence of these groups in Windows 2000. In NT 4.0, these groups had access only on machines that were either a PDC or BDC. In Windows 2000, these built-in groups have access and control over any Windows 2000 machine that is a domain member, even if it is not a domain controller. This is a change that you are about to assign your miss-ership to these groups. Now, what about the “Everyone” group that is discussed all the time?
