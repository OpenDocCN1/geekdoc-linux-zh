# PL/SQL Directory Traversal

The PL/SQL module can be abused to break out of the Web root and access files readable by the operating system account Apache is running under. To check if your site is vulnerable, open the following URL:

```
http://oracleserver/pls/dadname/admin_/help/..%255Cplsql.conf
```

This problem is due to the fact that the PL/SQL module has a double decoding problem and on the first pass converts "%255C" to "%5C", and on the second pass converted "%5C" to "\", the directory traversal becomes possible. To protect against this, install the patch from the Metalink site. The patch number for this vulnerability is 2209455.
