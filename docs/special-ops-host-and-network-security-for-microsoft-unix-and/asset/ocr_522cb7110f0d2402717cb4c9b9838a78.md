ScanLine.You can add as many -PS to your nmap command as you desire to test using multiple TCP ports for a response. If you want to perform a TCP ACK ping in nmap, you should use the -PT command instead of -PS. Both scanners can be forced to use a specified port with the -p command.

```
SCANLINE: sl -hp -T 10.0.3.150-190 | find "10.0.3." > TCPping.txt
NMAP: nmap -n -sP -PS22 -PS80 -PS139 10.0.3.150-190 -oM
TCPping.txt
```

+   * Service discovery Combine each ip address from TCPping.txt file and the ICMPping.txt file to create a file called LiveIPS.txt. Using the LiveIPS.txt file scan the network for TCP and User Datagram Protocol (UDP) ports. This provides us a picture of what applications these hosts are running and give insight into the role they perform within IT infrastructure.
