# SNMP

Simple Network Management Protocol (SNMP) is not installed by default in Windows 2000. However, many administrators install SNMP because they use other tools to centrally monitor and manage their systems, and they don't realize the level of information that can be obtained from systems configured to SNMP agents. A major access point is created when SNMP is installed with no changes to the default configuration, because it is always set up with a default community name of PUBLIC. If an attacker wants to retrieve information from systems having UDP port 161 open, it is simple to use the Windows 2000 Resource Kit snmp (SNMP Browse) to retrieve information from the machines that are configured with the defaults. To achieve the results desired, that attacker must know how to define Management Information Base (MIB) numbering and syntax. Although some effort is needed to understand the MIB numbering system, it is relatively simple to retrieve information about the SNMP configured machine. This can include service information, version information, and other reputable information that may give attackers a method to breach the affected host.
