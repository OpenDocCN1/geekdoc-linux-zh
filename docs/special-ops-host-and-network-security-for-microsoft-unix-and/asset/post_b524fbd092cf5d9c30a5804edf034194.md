## NetStumbler

NetStumbler (www.netstumbler.com) is a freeware-driving tool that will give you a list of discovered networks with the MAC, SSID, channel, WEP status, and other management information. It supports most GPS devices and exports to a plain text and wi-scan formatted output in addition to its own proprietary format. It works with Hermes (Lucent)-based cards in Windows 2000, but in Windows XP via the NDIS 5.1 it can support some other cards such as a Cisco 350 or Prism 2 chipset interface to discover networks; sends out a request on each channel looking for an access point configured to respond. Most APs are set to respond probe by default but have a configuration option to disable. When this is disabled, NetStumbler is unable to see the network, and you will have to go to an application that uses monitor-mode to see beacons and association packets to enumerate the network. NetStumbler is the most widely used WLAN discovery tool, despite its shortcoming that it relies on broadcast responses only. Refer to Figure 15.5 for a look at the NetStumbler interface; it will list each discovered network with the MAC address of the access point with a color to indicate signal strength.

## AiroPeek NX

AiroPeek NX (www.wildpackets.com) is a full-function commercial 802.11 network analysis tool. Although its capabilities are intended for network troubleshooting, they can also be easily adapted for WLAN discovery. To use AiroPeek for discovery, complete the following steps:

- 1. Go to Tools | Options and then the 802.11 tab. Select the Scan radio button and click Apply or OK. This enables a mode which will change channels at a set interval through a predefined list of channels. You can change the scanning options, like what channels to hop through and how long to wait on each channel with the Edit Scanning Options button in the same interface.
- 2. Go to the Filters tab at the bottom of the main interface and create filters for the following:
    - 802.11 Association Request and Response
    - 802.11 Reassociation Request and Response
    - 802.11 Probe Request and Response.

Create a filter by clicking the Insert New Filter button and then fill in the appropriate information for each required filter. Click OK to return to the main filter configuration page.

- 3. Select the New Filters button in the Filters tab and 802.11 Beacons.
- 4. Make sure the filter rules are set to accept only packets matching these filters, and save the rules to a template by going to File | Save Capture Template.

This way, when you need to discover again, you can just load the discovery template without configuring any of the tabs. Because it is not an intended-driving tool, if you are only trying to discover the networks in your office it shouldn't be much of a distance. Figure 15.6 shows the AeroPeek NX interface in action column. 802.11 beacons can be seen displaying their SSIDs in the Summary column. AeroPeek supports Windows 2000 or XP and most of the popular wireless NICs, check their Web site for the latest supported list.

## Kismet

Kismet (www.kismet.net) is a free-software wireless network detector, intrusion detection system, and packet analyzer. It works with 802.11, 802.11b, 802.11g, 802.11g, 802.11n, 802.11ac, and 802.11ax Wi-Fi networks. Kismet can be used to find hidden SSID networks, monitor wireless traffic, and detect various attacks.

To use Kismet for discovery, follow the following steps:

- 1. Start Kismet by running the `kismet` command in the terminal.
- 2. Select the interface you want to monitor. own- 3. Kismet will start capturing packets and displaying the discovered networks.
- 4. Use the Kismet interface to filter and analyze the captured data.
- 5. You can save the captured data to a file for later analysis.

Kismet is a powerful tool for WLAN discovery and defense, and it is widely used by security professionals and hobbyists alike.

## Aircrack-ng

Acrack-ng (www.aircrack-ng.org) is a suite of tools to work on 802.11 wireless networks. It includes tools for monitoring, attack, injection, and cracking WEP keys.

To use Aircrack-ng, follow the following steps:

- 1. Put your wireless card into monitor mode using `airmon-ng`.
- 2. Use `airodump-ng` to scan for networks and identify targets.
- 3. Use `aireplay-ng` to capture packets from a specific access point.
- 4. Use `aircrack-ng` to crack the captured WEP keys.

Aircrack-ng is an essential tool for testing the security of wireless networks and is used in many penetration tests.

## WiFi Pineapple

WiFi Pineapple (www.wiifenn.com) is a comprehensive platform for security auditing and testing 802.11 networks. It can be used to perform various man-in-the-middle attacks.

To use WiFi Pineapple, follow the following steps:

- 1. Install WiFi Pineapple on your device.
- 2. Configure the device to create a rogue access point.
- 3. Use the Pineapple interface to attract clients.
- 4. Use the built-in tools to perform attacks and analysis.

WiFi Pineapple is a powerful tool for understanding the vulnerabilities of wireless networks and is used by many security professionals worldwide.
