Create a simple named.conf file similar to the examples. Use the checkconf and checkzone tools located in /bin/check/ to verify your syntax. A document by Paul Vite gives insight into DNS tricks and creative methods to manipulate the BIND config file (www.dns.net/dnsrd/trick.html).

Db zone files should be simple to understand and well documented, especially modified by multiple administrators. Several symbols can be used, which have significant meanings:

```
$TTL 1d
@    SOA
```
