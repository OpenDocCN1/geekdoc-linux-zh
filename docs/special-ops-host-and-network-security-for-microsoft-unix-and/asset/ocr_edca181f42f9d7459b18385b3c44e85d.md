# Password Policies and Protections

Password policies are an area that is often treated too casually in network opera-
tions. In Windows 2000, it is extremely desirable to create and enforce strict pass-
words. Password attack tools are often free or available at low cost, and
allow an attacker to retrieve passwords for existing accounts or identify pric-
tices and vulnerabilities in a very short amount of time. Passwords should
changed at frequent intervals, should be a minimum of 8 characters (14 is pre-
ferred, since password crackers can now retrieve 8-character passwords in a
day or two), should follow complexity rules. This means that the password
should have letters, numbers, special characters, and upper/lower case in their con-
st. Passwords should not be names, parts of usernames, or common dictio-
ary words or their derivatives. When trying to secure networks and resources, it
no longer an acceptable condition to accept insecure passwords or policies.

Windows 2000 allows us to configure these policies locally on workstations
and standalone servers via the Local Security Policy management console in
Administrative Tools. These locally created policies will apply to local accounts on
t given machine only. If creating the policies in an Active Directory domain,
t policies can be configured via the Domain Security Policy Group Policy
Object (see Chapter 6). If a member of the domain, the domain policies will
override the machine policies if the user is authenticating with the domain.
