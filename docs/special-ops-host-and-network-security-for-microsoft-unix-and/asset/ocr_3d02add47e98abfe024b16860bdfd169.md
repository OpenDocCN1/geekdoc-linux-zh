# Table 4.5 Local Security Options

| Option | Minimum Value | Recommended Value |
|---|---|--|
| Limit local account use of blank passwords to console logon only | Enabled | Enabled |
| Rename administrator | Administrator | (Renamed_Administrator_Account) |
| Rename guest account | Guest | (Renamed_Guest_Account) |
| Audit the access of global system objects | Disabled | Enabled |
| Audit the use of Backup and restore privilege | Disabled | Enabled |
| Shut down system immediately if unable to log security audits | Disabled | Enabled |
| Allow undock without having to log on | Enabled | Enabled |
| Allowed to format and eject removable media | Authenticated Users | Authenticated Users |
| Prevent users from installing printer drivers | Disabled | Enabled |
| Restrict CD-ROM access to locally logged-on user | Disabled | Disabled |
| Restrict floppy access to locally logged-on user | Disabled | Disabled |
| Unsigned driver installation behavior | Warn allow installation | Do not allow installation |
| Domain controller: Allow server operators to schedule tasks | Enabled | Enabled |
| LDAP server signing requirements | NONE | NONE *This is an infrastructure-specific requirement and should be defined only if used within the environment.|
