# Host-Based Intrusion Detection Systems

The host-based IDS is the newest addition to the intrusion detection offering.
The host-based sensor, also known as an agent, is installed on each server that
requires monitoring. Most companies offer offers for the popular network
operating systems, such as Windows 2000, Windows NT 4.0, Solaris, Linux,
xBSD, and HP-UX. The agent software will work at the lowest level of the soft-
asable, possible often at the kernel level, and analyze each action that takes
place on the server. This type of scrutiny is very intrusive on the operating system
and can affect overall performance; however, this performance drawback is a small
price to pay for the level of detail that the IDS agent will provide.

Unlike network sensors, the host-based solution will interpret every action
and determine whether or not it be denied. Denied actions can range
buffer overflows to directory browsing. In the case of these actions,
t IDS will instruct the OS to ignore the action or just deny the action as part
of the agent software. This will either result in an error to the user or a denied
request. The action will also be placed in a logging mechanism for the adminis-ator to execute at a later time.

Several vendors provide host-based IDS solutions. Each will be explored with
the features and drawbacks.

Intercept Security Technologies offers a host-based product that bears the
name of the company, Intercept. Just like other products, this application is an
agent/server deployment when the administrator installs a management console
 pushes agents to the various servers for monitoring. The agents report
back all actions to the console where the action is matched against a rule set to
determ if the action should be allowed or denied.

and Solaris. It also also be utilized for specific servers, such as Web, database, and
