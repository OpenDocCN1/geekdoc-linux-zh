+   * System restore The Windows XP system restore allows users to restore a system to that of an earlier snapshot. These snapshots are created automatically, thereby allowing the user to specify the desired state to roll the system back to. It provides an additional layer of system recovery that can be leveraged by users in the case that the system needs to be restored. It also potentially saves time and data from what could have been a potential loss. The security impact feature stores the snapshot information into a specific file that can be modified by an attacker. This function is XP-specific.

+   * Device driver rollback The device driver rollback feature, similar in design to the system restore feature, allows an administrator or user to roll back to a previous version of driver in the case that it has affected the component, OS, or another application. It creates a layer of protection for the user in the case that an older device driver must be reinstated. The security impact is that a malicious user could cause damage rollback drivers. This function is not XP-specific.

+   * Application compatibility This feature acts as a middleware application towards fixing the numerous issues spawned by third-party application errors. It provides fixes for these third-party applications before the vendor has created such files. The feature allows third-party software to run seamlessly with Windows XP. The security impact is that a feature resides within this apparently wonderful feature that allows a user to specify the environment in which the application should execute (such as Windows NT or Windows 95/98/ME). Such a component may allow for additional hybrids of previously published vulnerabilities to be successful. This feature is XP-specific.

+   * User state migration software The feature simplifies data migration from another Windows-based system to the newly installed XP system. It saves time and resources for data backup and transfer. There is no security impact. This feature is XP-specific (the back-end processes for the feature have been significantly changed over since versions).
