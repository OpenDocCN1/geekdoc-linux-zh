# Local Enumeration

If it is possible to achieve local access to a machine, it becomes a very simple matter to perform enumeration of the machine. Even in the case of proper NTFS restrictions on drives, folders, and files, it is possible to obtain significant information about the machine through an unsecured command prompt (cmd.exe in Windows 2000). For instance, with access to a machine interactively, an attacker can type net localgroup administrators at the command line and see the following:

```
C:\net localgroup administrators
Alias name administrators
Comment Administrators have complete and unrestricted access to the computer/domain
```

Members

njohnohnson
NorrisJ
SPECIALOPS\Domain Admins
SPECIALOPS\norrisj
The command completed successfully.

As found in the remote enumeration section, the attacker then has a basis to begin to attack the system and find vulnerabilities. Remember that a single exposed and vulnerable host machine reduces security to the level of that point in the system.
