+   Q: A typical Web form contains certain objects that do not permit end users to input text (radio buttons, check boxes, and so on). Can input from these objects be trusted?

+   A: A general rule of thumb should be that *all* data that is within the end user’s control should be treated as potentially hostile. Even objects that appear to be static should be inherently distrusted by default.
