## Parameter Passing

A problem that consistently rears its head in dealings with forms and user input is that of how information is passed to the system. Most Web applications will make use of HTTP forms in order to capture and pass this information to the system.

## What’s in a Form?

An HTML form is encased by <FORM> and </FORM> tags. One of the attributes of the form is the action, which specifies the URL where the form is sent. Forms use several methods for accepting user input, from text areas to radio buttons and check boxes.

### 11.1 Anatomy of a Form

| Field Type | Sample HTML |
| :--- | :--- |
| Normal text input | <input type="text" name="name" size="20"> |
| Password input | <input type="password" name="pass" size="20"> |
| Text area | <textarea name="feedback" rows="4" cols="20"></textarea> |
| Radio buttons | <input type="radio" name="opt1" value="yes"><input type="radio" name="opt1" value="no"> |
| Check boxes | <input type="checkbox" name="check" value="A"><input type="checkbox" name="check" value="B"><input type="checkbox" name="check" value="C"> |
| Drop-down list | <select name="options"><option>Option A</option><option>Option B</option><option>Option C</option></select> |
| Hidden field | <input type="hidden" name="TOTAL_PRICE" value="$500"> |

When the user clicks on the Submit button, the form is sent to the back-end processing. The problem arises when the back-end systems accept data from their own sources. In this case, the user is now able to control not only the name of the book she wants to buy (through text box *book_order*) and the number of books she wishes to buy (through the text box *quantity*) also (and most important) the total value to be deducted from her account (through the <HIDDEN> field TOTAL_PRICE).

A user could go through the entire procedure, and then stop before submitting the resultant form. This page could then be saved to disk and edited using Notepad, vi, or any editor of choice. A few keystrokes would change the line from:

```
<input type="hidden" name="TOTAL_PRICE" value="$500"
to
<input type="hidden" name="TOTAL_PRICE" value="$005">
```

Since no other checks are performed by the target CGI, the few minutes of effort would effectively have saved the end user about $495. The solution to this is not to rely on <HIDDEN> fields to keep data private.
