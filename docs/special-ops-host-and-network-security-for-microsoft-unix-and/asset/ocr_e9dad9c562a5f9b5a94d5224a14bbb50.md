# Installing Initial System Patches and Hotfixes

Installing system patches and hotfixes is done at the end because you may not need to download fixes for applications or features that you have uninstalled. It is vital that your system contain all of the latest security and system patches and hotfixes. These updates were created to fix bugs and vulnerabilities that have been identified and released to the public. The severity or criticalness of the update depends on the type of fix. The system impact can range from denying service, to privilege escalation, to remote user access, to remote code execution. Each allows for a different type of fix, but all of which should be fixed.

To update your XP Professional system, open up an Internet Explorer browser and go to http://www.windowsupdate.com. From there, you simply follow the current set of instructions for downloading and installing all of the critical and recommended system updates, as shown in Figure 4.19.
