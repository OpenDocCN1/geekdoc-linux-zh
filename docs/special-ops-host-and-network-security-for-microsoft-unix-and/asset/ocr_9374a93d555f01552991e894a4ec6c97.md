This vulnerability is listed as "General Windows Authentication – Accounts with No Passwords or Weak Passwords" in the SANS/FBI Top 20. I wrote this script to help out the process of finding these accounts in a Windows domain:

```
@echo off
REM HSVAdmin.bat -- simple HSV script for Windows Domains created for
Special Ops book
REM e.p. birkhholz

REM syntax: HSVAdmin.bat DOMAIN
REM HSVAdmin requires these applications: NetView.exe, ipc$crack.exe

if [%1]==" goto :FAILURE
echo.Blank && echo.>Blank
netview -d%1 -Tnt -Onv %1_hosts.txt
for /P "delims=,tokens=1" %i in (%1_hosts.txt) do (
set e%%%i
echo >> %1_HostsAlreadyChecked.txt
echo ...testing %e%%...
call :BLANKCHECK
)
del %1_hosts.txt
del %1_HostsAlreadyChecked.txt
del Blank
goto :EOF

:BLANKCHECK
```
