The @ symbol will return the domain name. In the following example, all @ symbols will be returned at example.com.

A domain-specific administrative e-mail contact should be used on every domain name. The syntax of the e-mail cannot contain a @; therefore a period is used as a standard:

```
2001102401              ; serial
1d                      ; refresh
1h                      ; retry
1w                      ; expire
1d )                   ; minimum

IN NS                    ns1.example.com.
IN  MX                    10 @
IN  A                     127.0.0.1
```

A blank record like the one will be used when a subdomain is unused; for instance, that record will be used for queries on example.com:

```
* IN  A                     127.0.0.1
```

The * is a wildcard; the preceding line will be returned for any query. For example, all.work.and.no.play.makes.johnny.a.dll.boy.example.com, www.example.com, fbp.example.com, and dns.can.be.fun.example.com will all receive this query response as designated by the wildcard. Remember that records in a zone file are read from top to bottom, wildcard entries will be at the bottom of zone files.

After your server is running, make sure you have a firm understanding of the daemon. When you are ready, custom modifications should be made to secure the server.

To hide the BIND version, create a.db file, include the following TXT records, and replace the text as it fits your needs:

```
$TTL  1D
$ORIGIN bind.
@    1D      CHAOS  SOA      localhost.root.localhost. (
                   2001013101      ; serial
                   3H              ; refresh
                   1H              ; retry
```

## General BIND Options

The required configurations are included in the options field. The directory of files and common operational settings need to be specified. Remember to log both memory and general statistics for a baseline. When problems arise, a baseline will help in troubleshooting.

```
statistics-file "/bind_directory/named.stats"
memstats-file "/bind_directory/named.memstats"
dump-file "/var/adm/bind.dump"
zone-statistics yes;
```

There is a possibility of DoS attack via the DNS NOTIFY messages, therefore they should be turned off or limited to systems accessible only over a trusted medium (SSH tunnel):

```
notify no;
```

The Maximum transfer timeout for zone transfers should be set low:
``````
max-transfer-time-in 60;
```

If BIND is running on an interface that is static, the dynamic interface option should be set to zero:
```
interface-interval 0;
```

192.168.0.0/24;

## Access Control Lists (ACLs)

Though ACLs may provide a good limitation of service to the general public, using a single server to host internal and external zones is discouraged. Though popular, running a server that performs both authoritative and resolver duties should be separated if hosting many zones.

## Logging

BIND supports different levels. Logs should be checked regularly. A good rule of thumb for logging is that too little can negate the purpose, and too much prohibits maintenance.

## Individual Zone Files

Each zone file can contain its own ACL lists and customized settings to override the general. Here is an example of a forward and reverse zone:

```
zone "example.com"
{
type master;
file "foo/bar/example.com.db";
allow-query {
  any;
}
allow-transfer {
  none;
}
}
```

## Access Control Lists Lists

BIND supports use of ACLs within the configuration file. ACLs can be used to limit access to groups.

```
acl "internal-network" {
  192.168.0.0/24;
  127.0.0.1;
}
```

## Logging

BIND supports different levels. Logs should be checked regularly. A good rule of thumb for logging is that too little can negate the purpose, and too much prohibits maintenance.

```
{
channel "detailed"
{
file "/foo/bar/0.168.192_detailed.log"
syslog local0;
severity dynamic;
};
}
```

## Debug Logging

What if you wanted to keep a very close eye on lookups on the 192.168.0.0/24? You can implement debug logging specifically for that record (extensive logging can crash the system, so be sure you understand the repercussions)
