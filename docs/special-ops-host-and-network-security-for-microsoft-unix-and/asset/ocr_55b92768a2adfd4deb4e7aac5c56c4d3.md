# Securing Data Sources

Some Windows applications install User, System, or File DSNs without notifying you that they are installed. If these DSNs are not used, you should delete them by opening up the Data Sources (ODBC) Tool and clicking **Remove** for each unused driver (see Figure 10.4). Note that these data sources can also be removed by deleting the entries in the HKEY_LOCAL_MACHINE\SOFTWARE\ODBC\ODBC.INI registry.
