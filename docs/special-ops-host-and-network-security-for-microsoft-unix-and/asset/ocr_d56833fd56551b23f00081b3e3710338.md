# Table 4.5 Local Security Options

| Option | Minimum Value | Recommended Value |
|---|---|--|
| Refuse machine account password changes | Enabled | Enabled |
| Digitally encrypt or sign secure channel data (always) | Disabled | Enabled |
| Digitally encrypt secure channel data (when possible) | Enabled | Enabled |
| Digitally sign channel data (when possible) | Enabled | Enabled |
| Disable machine account password changes | Disabled | Disabled |
| Maximum machine account password age | 60 days | 30 days |
| Require strong (Windows 2000 or later) session key | Disabled | Enabled |
| Do not display last user name | Enabled | Enabled |
| Do not require CTRL+ALT+DEL | Disabled | Disabled |
