# Disabling Unnecessary Services

Unnecessary services can not only bog down systems but can also provide additional leverage points for malicious users and attacks to gain information or target known weaknesses. In many cases, these leverage points do not need to exist and can be safely removed without damaging your system or functionality. XP Professional is somewhat different from previous releases in that it attempts to minimize the number of services that are started automatically. In part, this is to optimize the OS and also to reduce potential security issues released in the future. In many cases, the services listed in Table 4.6 do not get used and can be safely disabled or started manually after system startup. You should not remove any service without knowing the outcome; before you remove them it is recommended that you create a restore point and attempt to remove them using the Resultant Set of Policy tool.
