DJBDNS and daemon tools can run in a non-root, chrooted environment via secure execution. Properly configured, in this "jail" type environment, it is extremely difficult, if not impossible, to remotely compromise the system through DJBDNS.

DJBDNS should have its service package daemontools installed first. Complete the following steps:

+   1. Create a directory:
```bash
mkdir -p /package
chmod 1755 /package
cd /package
```

+   2. Download daemontools (http://cr.yp.to/daemontools/daemontools-0.76-tar.gz) into your package directory. Then unpack it:
```bash
gunzip daemontools-0.76.tar
tar -xpf daemontools-0.76.tar
rm daemontools-0.76.tar
cd admin/daemontools-0.76
```

+   3. Compile and install daemontools, then add the following to the system path:
```bash
package/install
echo -n "daemontools"
PATH=$PATH:/usr/local/bin
svscan /service &\n```

+   4. Reboot to start suscan on BSD systems.

+   5. When DJBDNS has been installed, download (http://cr.yp.to/djbdns/djbdns-1.05.tar.gz) and unpack:
```bash
gunzip djbdns-1.05.tar
tar -xf djbdns-1.05.tar
cd djbdns-1.05
```

+   6. Compile and set up:
```bash
make ; make setup check ; ./install
```
