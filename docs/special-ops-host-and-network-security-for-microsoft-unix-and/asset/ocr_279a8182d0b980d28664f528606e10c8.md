In order to enable this feature, you must create a new value in the HKLM\SYSTEM\CurrentControlSet\Services\ExchangeParameters called Disable MAPI Clients of type REG_SZ. You are going to put into this list the versions of the MAPI clients that you want disabled; it is permissible to put in a range of client versions as well. But you make sure that you do not disable versions 6.0.0 through 7.0.0 because this will prevent the Exchange server MAPI components from accessing mailboxes on the server.
