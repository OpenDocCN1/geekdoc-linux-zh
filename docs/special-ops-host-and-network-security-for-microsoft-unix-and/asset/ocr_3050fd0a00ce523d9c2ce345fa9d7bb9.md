# Defending XP Professional

+   - Internet Control Firewall makes a world of difference and can truly harden a system. Enable ICF with only the bare minimum additional server requirements and do not flag any of the ICMP settings.

+   - Hashing rules within the Software Restriction Policy provide the best ROI when calculating required effort investment and should be implemented on an ongoing basis.

+   - Less is more! Remove all unnecessary users, services, protocols, and applications.

+   - The Local Security Policy is the heart of the system's security program. Ensure that the proper logging is enabled for success and failure scenarios and ensure that absolutely no advantageous rights are available for anonymous users.

# Maintaining a Good XP Security Posture

+   - Utilizing the automated update feature within Microsoft XP may be the most useful security-related feature ever added to an operating system. It may be reactive but nonetheless useful. A common recommendation is to configure your system to update its patches during your average lunchtime hours.

+   - Continuously review the security logs via the MMC and your active system shares by issuing the command C:/Net Use.
