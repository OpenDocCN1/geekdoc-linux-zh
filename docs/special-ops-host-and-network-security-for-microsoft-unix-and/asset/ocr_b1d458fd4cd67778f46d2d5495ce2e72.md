Another useful coding policy is to ensure that all input validation checks are
formed on the server. Although it is sometimes a performance technique to
perform data entry validation on the client since minimized round-trips to
the server, you should not assume that the user is actually conforming to that val-\idation when they post information. In the end, all input validation checks
should occur on the server, even when your client code has already performed
the same check.
