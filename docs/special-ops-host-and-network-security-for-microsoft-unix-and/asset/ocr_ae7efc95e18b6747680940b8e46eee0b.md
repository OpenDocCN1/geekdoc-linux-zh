# 802.11 Client Detection

Finding wireless clients is a little tougher than finding access points, which will not have remote management protocols to identify them as wireless devices. Nevertheless, given the right circumstances, there are few ways they can be found. With APs, MAC addresses can give away some wireless NICs. On Windows boxes, they are easy enough to gather via NBTStat, GetMac, the Remote Registry service, or Windows Management Interface (WMI) if it’s enabled, UNIX or other OSs would need SNMP enabled or found at the router/switch level. On Windows hosts, if you have remote registry access you can look at the network interface key for defining wireless adapters, or look in HKEY\Local Machine\Software for entries for wireless vendor’s installed management software.

# Finding Clients by Their MAC Address

Since we are trying to find systems that are using a different Layer 2 protocol (802.11), we need to use the identifier that Layer 2 Ethernet-like architectures such as 802.11 use. This unique identifier would be the MAC address. Using the MAC address to find wireless clients can work in some cases and not at others. Since wireless vendors use the MAC prefixes for both access devices as well as client adapters, we can work off the same list we use to locate APs. How we get the list of devices to sift through is a little different.
