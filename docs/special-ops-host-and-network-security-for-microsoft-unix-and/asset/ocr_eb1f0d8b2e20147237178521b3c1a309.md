Etercap also includes functionality to perform man-in-the-middle attacks on Secure Socket Layer (SSL) and Secure Shell (SSH1) connections, which means you are still vulnerable even when following best practices as encrypting data over the wireless network. Etercap comes in UNIX and Windows versions and offers a simple graphical user interface (GUI) in both.

To use Etercap in Windows, click the Etercap Start menu icon, which brings up a command prompt in the Etercap directory.Then run Etercap with the interface you'd like to monitor. An example would be as follows:

```
c:\program files\ettercap\ettercap -i dev
```

Once Etercap starts, it will perform ARP discovery of the network to identify all the MAC addresses and Internet Protocol (IP) addresses on the local network (see Figure 15.2). After that, it will also attempt to resolve the DNS names of each host. The Etercap interface will show a list of all hosts on the network and allow you to select specific destination and source hosts for monitoring, as well as using any host as the source or destination. You can press H anytime in the Etercap UI for usage information.

# Picking a NIC

The choice of wireless equipment you purchase for 802.11 security work should mostly be based on what you prefer and what is supported by your primary operating system of choice.There are many tools based on the Prism 2 chipset for UNIX-based operating systems, mainly due to the availability of driver information for this chipset and the easy capability to engage monitor mode on it.The Prism 2 chipset can usually be found nowadays in low-cost cards like the D-Link DWL650 and Symbol Spectrum 24. Most of the WiFi scanners and sniffers can use this chipset as well as the tools used to crack WEP.
