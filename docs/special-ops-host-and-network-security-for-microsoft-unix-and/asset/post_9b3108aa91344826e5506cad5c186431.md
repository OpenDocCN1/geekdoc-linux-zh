The UPNP countermeasure for this vulnerability is twofold. You may choose to install the recommended hotfix or install the Windows XP Professional Service Pack 1, both of which you can find in the Windows Update Catalog at http://windowsupdate.microsoft.com. The second choice you have as easy as the first, would be to disable the Plug and Play service for your system. However, realize that if you do to disable this service it will obviously not be available for any real-time automatic identification or configuration of peripheral devices.

Double-click the **Plug and Play** service from within the Services Management interface and change the **Startup type** to **Disabled**. Ensure that your configuration dialog box matches Figure 4.5. Our recommendation is to just patch.
