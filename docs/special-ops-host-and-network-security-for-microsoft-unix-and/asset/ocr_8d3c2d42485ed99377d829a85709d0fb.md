# Attacking and Defending Unix • Chapter 14

Once the image has been downloaded, you must verify the authenticity of the image text. Most vendors realize the importance of this process, and provide a message of verifying the identity of the image. This is typically done cryptographically, through either a one-way hash as MD5, or through the signing of the image using tools as Pretty Good Privacy (PGP) or GNU Privacy Guard (GPG). It is best to use images that have been cryptographically signed.

In the case of images secured using MD5 hashes, a list of the hashes is usually kept in the same place as the downloadable image. An example would be the hashes generated for the 8.0 distribution of Red Hat Linux. By visiting URL ftp://ftp.redhat.com/pub/redhat/linux/8.0/iso/i386, you can see that Red Hat has images available at the location with a file titled MD5SUM. The following shows the contents of the file:

As you can see from the contents, the MD5 hash has been produced for each image. It is assumed that we can trust the vendor to generate these hashes, but the only way to verify that these hashes did in fact from the vendor is to verify the GPG signature.
