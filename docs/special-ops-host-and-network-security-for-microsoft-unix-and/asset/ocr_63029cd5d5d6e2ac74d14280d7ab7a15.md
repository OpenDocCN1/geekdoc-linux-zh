# LDAP Probing

To conduct an LDAP probe, we use one of the utilities provided by Microsoft as part of their Windows 2000 Support Tools package—LDP.exe. It is called “Active Directory Administration Tool” there, but it has the same functionality as an LDAP browser (which can be used instead). As we saw before, even a simple anonymous connection gives a lot of information about a domain, starting from its name and the name of the site where it is located. Even more information can be obtained using simple LDAP queries. That information is given out is not an Active Directory fault—it happens by the nature of LDAP protocol and cannot be easily mitigated. In the following examples, we suppose that you know how to use a LDAP browser and that you also have some basic notion of LDAP naming schemes and construction of queries.
