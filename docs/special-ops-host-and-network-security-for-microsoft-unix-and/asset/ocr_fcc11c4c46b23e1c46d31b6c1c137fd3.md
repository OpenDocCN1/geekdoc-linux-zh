# Introduction

Window's Terminal Services (TS) is a graphical user interface (GUI) that can deliver the ferocity of a full blown 32-processor Windows server right to the desktop of your workstation. To quote Microsoft, "Windows 2000 Terminal Services is a technology that lets remotely execute applications on a Windows 2000-based server from a wide range of devices over any type of network connection."This statement, although factually correct, leaves a bit to be desired from the security point of view; this is not surprising since the statement was taken from their site in early 2000, when their focus was far weaker than it is currently. My experience tells me Windows systems are dominating the IT industry, and furthermore, with the right team of configuration engineers, Windows 2000, Windows XP, and Windows Server 2003 can be secure as any amass Unix operating system.

In an article titled "Terminal Server: The Day of Reckoning" (www.foundstone.com/knowledge/article-TerminalServer.html), Clinton M I stated, "The majority of our concerns, in most cases, are not a result of poor products being implemented poorly; I think we can agree that if you hope to secure any, you must first understand it. However, I feel like many Windows administrators, lacking a deep enough understanding of the system, are making the same security mistakes over and over—yet they still expect things to get better.Doing the same thing over and over, but expecting different results" is actually a phrase I have used to defy insanity!

One of these matters is remote administration—not the lack of it, rather the improper implementation of it. Some administrators lean too heavily on the extensive functionality of their Windows systems and forget about locking down the servers and implementing secure protocols or tunneling. Obviously, this isn't the best way to have a secure network.

Microsoft's security awareness is at an all high time. Bill Gates has stepped up to the plate, and as usual he is swinging for the fences. I have already seen a dramatic increase in security of Windows systems based on the implementation of Internet Connection Firewall, Windows Update (windowsupdate.microsoft.com), and Microsoft Baseline Analyzer. Microsoft is quickly stockpiling their security arsenal, and these tools are critical when attempting to tackle something as complex as securing a Terminal Server for multiuser access.

This chapter focuses primarily on Terminal Services running on Windows 2000 Server and Windows XP Professional, I will mix in a dash of Windows Server 2003 to keep things interesting.
