### Table 10.2 COM File Locations

| COM Object | Default File Location |
| --- | --- |
| Scripting | %SystemRoot%\System32\scrrun.dll |
| WScript | %SystemRoot%\System32\wshom.exe |
| MSADO | %ProgramFiles%\Common Files\System\msado15.dll |
| CDONTS | %SystemRoot%\System32\cdonts.dll |

In addition to securing these items, you may want to limit NTFS permissions on all COM files located on the system partition. You can produce a list of all COM files with this command:

```cmd
C:\>findstr /S /D:C:\"DllRegisterServer" *.ocxdll *.exe
```

Finally, if you are not using Distributed COM (DCOM) on your server, you should disable it by setting the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Ole\EnabledDcom key to N.

## Securing Web Services

Now that you have a hardened Windows 2000 OS, you can focus on securing IIS itself. In its default state, IIS is vulnerable to a number of different attacks. To do this, you must perform the following steps (this process should be completed in this specific order because some of these steps build upon the results of a previous step):

- 1. Run the IIS Lockdown tool.
2. Secure Registry settings.
3. Secure WebDAV.
4. Secure FrontPage.
5. Secure default sites.
6. Secure the master WWW properties.
7. Secure sites, files, and directories.

## Running the IIS Lockdown Wizard

Microsoft provides a free tool for securing IIS Web servers called the Internet Information Services Lockdown Wizard. The tool works by using templates to accomplish the basic steps to harden IIS server. The IIS Lockdown Wizard installs URLScan, which is a tool for blocking certain types of Web requests based on certain Hypertext Transfer Protocol (HTTP) elements.

## Securing IIS Global Settings

Most IIS configuration settings are stored in the database, some settings are set in the Registry. By default, many of these settings are sufficiently secure, but when auditing a server, ensure these settings are kept at the recommended values. The settings and their recommended values are as follows:

- AllowSpecialCharsInShell: This setting allows or prevents special shell characters from being allowed as parameters for common gateway interface (CGI) scripts and executables.
  - Key: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\W3SC\Parameters
  - Type: REG_DWORD
  - Recommended Value: 0 (default)
- LogSuccessfulRequests: This setting enables or disables IIS logging functions and should always be set to 1.
  - Key: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\W3SC\Parameters
  - Type: REG_DWORD
  - Recommended Value: 1 (default)
- SSIEnableCmdDirective: This setting allows or blocks the use of #exec cmd directive server-side includes without affecting other server-side directives.
  - Key: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\W3SC\Parameters
  - Type: REG_DWORD
  - Recommended Value: 0 (default)
