# # System Files and Backing Up Active Directory

System data files of Active Directory include the following:

+   * Active directory itself (NTDS.DIT file)
* Certificate services database (if there is a certificate authority installed)
* Class registration (database of information about the component services)
* Performance counters configuration
* Registry
* SYSVOL — shared folder, which contains group policy templates and login scripts for users

All this data is stored when a backup of Active Directory is performed. Active Directory supports only full backups; there is no possibility to back it up incrementally. The maximum age of the backup is 60 days, which is called a tombstone time. When you restore data to Active Directory, you can do it in one of two ways:

+   * Authoritative
* Non-authoritative
