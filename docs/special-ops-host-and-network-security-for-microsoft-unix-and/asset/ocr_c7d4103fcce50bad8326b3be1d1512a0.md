# Chapter 9 • Attacking and Defending Microsoft Terminal Services

Since you can remotely control a session from within Terminal Services session, you will need to connect to the Terminal Server before you try to shadow. The next command shows the syntax for the shadow command:

```
C:\shadow
```

Monitor another Terminal Services session.

```
SHADOW (sessionname   | sessionid) [{/SERVER:servername] [/V]
sessionname             Identifies the session with name sessionname.
sessionid               Identifies the session with ID sessionid.
/SERVER:servername      The server containing the session (default is current).
/V                       Display information about actions being performed.
```

For example, to shadow the rdp-tcp#2 session, you would type the following command:

```
C:\shadow rdp-tcp#2
```

To end a remote control session, press Ctrl + the * key on the numeric keypad. If you are using a laptop and do not have a numeric keypad, you may need to use Ctrl+Fn+0 to simulate the escape sequence.

You can also use the tcon command from inside a TS session to connect to another user's session if the permissions are correct:

```
C:\tcon
Attaches a user session to a terminal session.
```

```
TSCON {sessionid | sessionname} [{/DEST:sessionname]
[/PASSWORD:pw] [/V]
sessionid               The ID of the session.
sessionname             The name of the session.
```
