For example, on the Administrative partition, you should allow only Administrators to access the data. To do this, right-click on a drive in Windows Explorer and select **Properties**. # Installing IIS

Once the OS is installed and your partitions are ready, you can now install IIS. Rather than using the Add/Remove Components control panel, we will create an answer file that allows us to customize how we want IIS installed.
