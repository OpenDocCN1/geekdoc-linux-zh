Most APs also come with Web, Ftp, and Telnet services that can be easily picked up in a banner scan.

You can use a tool such as ScanLine(www.foundstone.com/knowledge/scanning.html) to check your network for these banners. ScanLine is a free command-line port scanner that also includes the capability to grab banners from open services.

When you run ScanLine for AP discovery, to see the banner grabbing option (-b) to get the information you'll need to figure out if it's an AP. For choices, use 192 and 161 UDP, with 21, and 83, and 80 TCP.

The following ScanLine example is run against a Cisco Aeronet 350 access point; the identifier (Cisco 350 Series AP) is clearly seen in the Telnet banner.

```
C:\sl -b u 161.192 -t 21,23,80 10.0.16.81
```
