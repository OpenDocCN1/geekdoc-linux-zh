# Attacking Unix

+   - Attacking one's own system is the only way to assure a host is secure.
- Gaining remote access is the goal of attacks against Unix systems.
- Programming errors such as buffer overflows and format string vulnerabilities can be exploited to execute code, and give attackers remote access.
- Input validation errors such as those that commonly occur in PHP includes allow attackers to remotely execute commands.
- Brute force attacks against services may allow attackers to gain access to local accounts.
- Services that have been exploited to gain local access may not yield administrative access to the system, requiring launching an attack to gain elevated privileges.
- Some services may be run in a restricted environment, which requires breaking out of the restricted environment to gain administrative access to the host.
