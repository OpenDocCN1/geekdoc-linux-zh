# Version Discovery

Discovering software vulnerabilities helps attackers profile a server. Version lookups are commonly overlooked information disclosure vulnerabilities. Even with a pessimistic security viewpoint; versions give a friendly invitation to a hacker. Software version information is rarely needed and BIND should be changed or blanked out. The Berkeley Internet Name Domain (BIND) DNS responds to many dig version queries and allows remote attackers to identify their version. The following is a server running BIND; the version and daemon information disclosure:

```
[root@specialops]# dig @ns1.example.com version.bind CHAOS txt
```
