Because TSrack relies on a dictionary file to complete dictionary-attacks, we created a user account on a target machine Windows 2000 Server. The user account was called “testing” with a password of “testing.” We also created a sample file with dictionary words, using the word “testing” at the bottom the list as word number 100.

Here are the command used:

```
tsrack -N 1 testing -p testing 192.168.1.2
tsrack -N 1 testing -w 100words.txt 192.168.1.2
```
