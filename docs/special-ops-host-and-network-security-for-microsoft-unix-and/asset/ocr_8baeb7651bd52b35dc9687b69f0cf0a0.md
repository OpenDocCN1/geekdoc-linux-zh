We’ll focus on understanding Exchange 2000 and its dependency on the underlying operating system, Active Directory, and Internet Information Server.

# Introducing Exchange 2000

Exchange 2000 is the latest iteration of Microsoft’s enterprise messaging platform. However, the Exchange 2000 release contains significant changes from previous versions. Exchange 2000 is dependent on several components of Windows 2000, including Active Directory and Internet Information Services. In addition, several changes had to be included with Exchange 2000 in order to make backwards-compatible with previous versions.
