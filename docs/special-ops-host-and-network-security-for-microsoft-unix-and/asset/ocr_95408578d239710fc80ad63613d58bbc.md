# Anomalies of XP's Internet Control Firewall

As I have discussed, Windows XP ships with Internet Control Firewall (ICF). ICF is little more than a dynamic IP tables filter that manages outbound connections. Outbound connections are stored in the dynamic table, thus their response packets are allowed to be received by the local system. This technology disallows unsolicited ICMP requests and forged responses looking for errors or messages, in addition to unsolicited TCP packets. That simple fact alone will hinder most scanning tools to the extent that they retrieve no unsolicited or sniffed information whatsoever.
