# User Rights Assignment

One of the steps that must be taken during the securing and configuration of your Windows XP Professional system is the setting of user rights. Properly configured user rights disable malicious user systems from accessing other user's files, adding systems to the domain, and modifying other user permissions. Table 4.4 is the comprehensive configuration for permitting proper user access.

# Table 4.4 Local User Rights Assignment

| User Rights Options | Minimum Value | Recommended Value |
|---|---|--|
| Access this computer from the network | Administrators, Authenticated Users | Authenticated Users |
| Act as part of the operating system | Administrators | NONE |
| Add workstations to domain | Administrators | Administrators |
| Adjust memory quotas for a process | Administrators, LOCAL SERVICE, NETWORK SERVICE | Administrators, NETWORK SERVICE |
