# Local Exploits

Local exploits usually require multiple prerequisites for the attacks to work, and statistically most are related to unauthorized information disclosure or system denial of service. The most popular slew of attack was released when Java was first introduced as a fully-featured code language of the Internet. Numerous flaws in the language allowed attackers to create infinite loops that caused a complete denial of service, grabbing local files and sending them to a Web site of choice, the most dangerous executing of arbitrary files locally through a while in the Java Virtual Machine. Most of the XP Professional-specific or inclusion attacks can be exploited with the Internet Explorer’s implementation of key scripting and programming parser engines.
