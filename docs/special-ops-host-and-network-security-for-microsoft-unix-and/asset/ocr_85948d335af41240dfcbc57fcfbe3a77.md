# Set a Logon Banner

Going to Local Computer Policy | Windows Settings | Security Settings | Local Policies | Security Options will allow you to configure the following settings:

Message text for users attempting to log on
Message title for users attempting to log on

If configured, this "logon banner" can stop some older TS brute force tools. It may also provide some legal leverage should there be an issue. If PocketPC connections to a Terminal Server you need to train your users to explicitly say "ENTER" through the server, as the PocketPC client software screen centering will only show the blank canvas of the logon banner—they will not know that they need to acknowledge the logon banner.

# Increasing Security with Extreme Measures

If you are ultra paranoid, consider implementing a more robust encryption, authentication, IP address filtering, and logging solution. One option is to use Zebee to tunnel Terminal Server traffic through a compressed and encrypted tunnel. A great article written about this topic is available at http://online.securityfocus.com/infocus/1629.
