# Securing IIS · Chapter 10

```
iisdbg = Off ; Script Debugger
LicenseServer = Off ; Terminal Services Licensing
wms = Off ; Windows Media Services
ImageView = Off ; Imaging (Image Viewer, ActiveX Custom Controls and TWAIN support)
IEAccess = Off ; Internet Explorer visible entry
OEAccess = Off ; Outlook Express visible entry
WWMPOCM = Off ; Windows Media Player visible entry
```

Note that this list does not install IIS. I do so that I can use this unnatend.txt file as the base for all server nodes. We manually install IIS later using a separate unnatend.txt file. An IIS server needs few components to operate, and you should use caution when adding extra components. On a typical installation, Terminal Services is one of the few extra components you should install. If you add other components, do so only if you have a specific purpose for that component.

> If you are installing Windows 2000 from a bootable CD, you can customize your install by renaming your unnatend.txt file to winnt.sif and placing it on a floppy disk. Insert both the floppy and the CD, making sure the CD has higher boot priority, and the Windows 2000 will use your custom settings for the installation.

When installing Windows, it is best to use an installation source that has slipstreamed with the latest service pack (SP). This is important because some fixes are more effective when included as part of the OS installation. Slipstreamed installations ensure a strong OS base and also cut down the setup time. If you are not able to install from a slipstreamed source, the first step to take when Windows 2000 setup is complete is to install the latest service pack. It is not necessary to install hotfixes at this time.
