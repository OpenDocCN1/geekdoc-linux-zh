# Upgrading to XP Professional version XP Home

Note that this chapter is written for Microsoft Windows XP Professional. A few areas in the chapter reference both Windows XP Home and Windows XP by using the broad reference “Windows XP”. Aesthetically, there is no difference between Windows XP Professional and XP Home, but there are a few technological differences between them. The most fundamental difference between the two is that only Windows XP Professional can be joined to a domain. Windows XP Home and Windows XP Professional are capable of logging into or joining a workgroup, a technology that is geared towards small business and home-based networks but not excluded from professional use.

Domain authentication, a strictly-for-business technology, allows systems of use domain-provided resources as printers, file servers, internal organization Web sites, and on.

In addition to not having domain authentication, XP Home users do not have access to the XP Professional Remote Desktop feature. The Remote Desktop Protocol (RDP) feature is similar to another feature, Terminal Services and Remote Desktop allow you to leave your computer booted so you can connect to it remotely via a Terminal Services client or RDP if you were sitting at the console.

An excellent feature, similar to popular products like Symantec’s PCAnywhere, it provides remote administration and usage capabilities with Microsoft standard authentication and encryption. Another feature related to working remotely is the Working with Offline Files option. This provides a user the ability to create mirrors of networked folders, allowing such users the ability to update files while offline. The key component of this feature is that it can automatically synchronize the folder with the online folder when the connection is available. The synchronization component is mutual—the client updates the server and vice versa.
