# Unnecessary Services

Disabling unnecessary services may seem like an obvious recommendation, but it is nonetheless often overlooked. And often Exchange administrators do not realize when they can disable a specific service. Windows 2000 install a number of services that may not be necessary in your environment. Although most of these services are fairly innocuous, I still think it is a good practice to disable if they are not necessary. I have broken this into two types of Exchange servers: front-end servers and back-end servers.

For both of these types of services, using the Services management console, disable the service rather than simply setting the service to Manual after another service may try to start this service.

If the Exchange 2000 server is running in a native Exchange 2000 organization (no Exchange 5.5 servers), you should switch the organization to "native" mode. This is done on the properties of the Exchange organization using Exchange System Manager. Before you switch the organization to native mode, you should disable the Microsoft Site Replication Service and the Active Directory Connector. Any configured Site Replication Services should be deleted from Tools | Site Replication Services contain in Exchange System Manager.
