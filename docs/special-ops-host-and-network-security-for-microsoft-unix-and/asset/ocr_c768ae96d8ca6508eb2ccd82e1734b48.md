Next, click the Configuration button to bring up the Application Configuration screen. Since application mappings should already have been taken care of by IIS Lockdown, check the Options tab shown in Figure 10.19. On this screen, the most important setting is that you unchecked the Enable parent paths box prevents ASP from including files from paths outside the Web root. All other settings on this page depend on your particular application, but you may want to reduce the timeouts if your application will allow.

Now, select the App Debugging tab shown in Figure 10.20. On this tab, ensure that both debugging options are unchecked and that Set error message to client is selected. For the actual text, you can use the default message or enter your own custom message. This is important because it prevents sending error messages to the client that may contain sensitive information. Click OK to return to the Master WWW properties.
