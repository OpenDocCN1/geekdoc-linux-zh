# Using Web Sleuth

Web Sleuth is a manual Web application auditing tool aimed at the intuitive auditor. Web Sleuth's toolset includes functionality to efficiently modify form values on the fly and make raw HTTP requests. Web Sleuth's document parsing tools allow you to effortlessly examine the entire page's contents with more clicks.

Once a page has been loaded, you are free to edit the source of the page that allows you to change form element attributes such as maximum length or input type, as well as allowing you to completely client-side validation code. As augmentation to this, Web Sleuth also contains a set of document macros that encompass functionality such as converting all hidden inputs to textboxes with a single click, allowing direct value manipulation.

Web Sleuth possesses monitoring functionality. Options exist to set a record of surfing activity and submitted form data. Analysis routines are in place allowing you to manually confirm and step through all navigation events, presenting you at each stage with dialogs that break down long query string arguments and present them to you in an easily readable format.

A new feature to Web Sleuth 1.3 is the capability to monitor your cookies in real time as you progress through a Web application. When this functionality is active, a separate window is displayed at the top of the screen you show a breakdown of the cookie value, allowing you to interactively monitor it as you work.

Aside from the built-in functionality, Web Sleuth also supports a plugin-framework that others have expanded on. To date, authors such as Chip Andrews of SQL Security.com, Cesar Cerrrado of Application Security Inc., David Ender of ID2Defense, and Gonzalo Marañán de Inistec have all chipped to add some great features.

These third-party plug-ins support routines to: test for SQL Injection, monitor session IDs, crawl remote sites, and brute force Web login pages.

Web Sleuth 1.4, scheduled for release in early 2003, will build upon this previous functionality boasting quality new features, such as full source syntax highlighting, an integrated local proxy, and several other undisclosed functionality enhancements. Web Sleuth can be downloaded from the author’s site located at http://sandsprite.com.
