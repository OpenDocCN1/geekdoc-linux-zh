# Logging Internet Client Access

You may also want to log access to the Internet protocol clients for either purposes or to track an intruder accessing the server using one of these protocols. I am holding out that some third-party vendor will eventually develop a reporting tool so that this information can also be used to generate usage reports for each of the protocols. Though a number of reporting tool do read the HTTP log files, the data they report is from the perspective of Web page usage, and this does not necessarily itself to reporting on OWA usage.
