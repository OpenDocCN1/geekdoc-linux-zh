Another solution gaining momentum in this space is called StormWatch from Okena Software (www.okena.com). Similar to Intercept, StormWatch sits at the kernel and uses four sensors to examine server activity. The sensors include a file system interceptor, a network interceptor, COM interceptor, and a registry interceptor. With the data gathered from these sensors, the server is able to compare the requests against its rule base and either accept the action or prevent the action from taking place on the host. The level of protection can help stop existing exploits like Code Red and other unknown attacks that are yet to be discovered.

Similar to Intercept, this technology follows agent/console architecture and requires a separate workstation for administration and logging. Other features of this application include policy enforcement for your Windows servers, customized logging and alerting, and open application program interface (API) for integration with third-party help deks or monitoring applications.

Another popular technology used to monitor intrusions on a host is Tripwire (www.tripwire.com). Unlike Intercept, Tripwire is not an active IDS in that it does not try to prevent an attack on an operating system. Instead this application takes a snapshot of a known-good working server and then routinely compares the files and directories to determine if any unauthorized changes have been made. The application notifies the administrators if a discrepancy is found with any of the files. Reporting and management is handled through the Tripwire console. HTML and XML reports are viewable through a convenient Web interface.

Once the original snapshot is taken on a server, four different hashes and checksums are used to determine the original state of files and directories. The snapshot is encrypted, stored, and used for real-time comparison. In this manner, Tripwire provides data integrity over your servers. It is important if you remember that we are dealing with the internal segments where users often have too much access to resources they are not authorized to use. In this scenario, users might delete or change a file that they should not be allowed access. Tripwire will provide a strong logging mechanism to trace the violation.
