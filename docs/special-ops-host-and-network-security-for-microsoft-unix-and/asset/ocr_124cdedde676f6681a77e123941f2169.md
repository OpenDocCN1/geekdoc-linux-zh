To install IIS with our custom options, create a text file named iis.txt with the following contents:

```
[Components]
isis_www = on ; World Wide Web Server
isis_common = on ; Common Files
isis_inetmgr = on ; Internet Information Services Snap-in
isis_ftp = off ; File Transfer Protocol (FTP)
ins = off ; NNTP Service
ims = off ; SMTP Service
isis_html = off ; Internet Services Manager (HTML)
isis_doc = off ; Documentation
fp_extensions = off ; FrontPage 2000 Server Extensions
is_html = off ; Internet Services Manager (HTML)
fp_vid_deploy = off ; Visual InterDev RAD Remote Deployment Service
```

```
[InternetServer]
;PathFTRoot=E:\FTP
PathWWRoot=E:\WWW
```

Note that you adjust the settings in the file to match your particular requirements. This configuration installs a basic WWW server to the e:\www directory.

After creating the answer file, you are ready to run Syscomgr.exe, which is a program used to install Windows 2000 components from an answer file. Syscomgr is a command-line utility. To start Setup, go to the command prompt and type the following command:

```
syscomgr /I:%windir%\inf\sysoc.inf /w /u:c:iis.txt
```
