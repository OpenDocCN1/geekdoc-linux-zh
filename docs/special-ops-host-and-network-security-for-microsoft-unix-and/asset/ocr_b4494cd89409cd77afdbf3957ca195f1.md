# It's Not All Manual Configurations

All of the procedures detailed in this section allow the administrator to more fully secure the operating system environment. This detailed a manual procedure for illustration purposes, and an administrator could certainly copy the desired templates across a network connection and apply them in this manner. However, when using Active Directory (Chapter 6), the administrator can distribute and install these templates via the Group Policy capabilities of Active Directory, thus saving time and effort. The original construction of the custom templates must still be done in the manner detailed here.

One of the great things about these templates is that mistakes are relatively easy to fix. If it is discovered that the adjustments made are too rigid, another security template can be imported and installed working out the kinks. Be aware that this capability exists, but the security template applied must also define the settings changed in the previous template to remove them completely and return to a base setting.

# Configuring the File System and Disks

After looking at a way to check out the basic security configuration and modify if it needed, let's take some time to look at basic security configuration of the file system and disks within the Windows 2000 area. I've discussed previously that the FAT system is not suitable for security in Windows 2000. That leaves you with the option to operate your systems with NTFS 5.0. This这一切 is the preferred file system to use in the Windows 2000 environment. If you have made the decision to change to NTFS after an installation with FAT or FAT32, you can use the convert.exe command in a command to perform the conversion. For instance, converting drive C, open a command prompt (enter cmd in the Run window), and enter the command convert c: \ntfs and press Enter. This creates a prompt letting you know that the file system is in use and that a restart is needed for the conversion. Following the restart, would change the file system to NTFS. No data is lost during this operation, but it is a one-way conversion process. (Of course, good practice would indicate that you back up data before performing any file operations).
