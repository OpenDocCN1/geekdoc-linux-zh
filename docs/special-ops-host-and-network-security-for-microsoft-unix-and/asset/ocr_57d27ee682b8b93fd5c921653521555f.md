# Performing Asset Inventory

+   * The asset inventory can be used to understand how and where to implement layered security to reduce exposure.
* The prerequisite for a basic asset inventory is one or more range(s) of IP addresses. This list can be obtained by ICMP sweeps and TCP sweeps.
* Another technique for performing an asset inventory is a comprehensive scan, which requires scanning all possible 65535 TCP and UDP ports.
