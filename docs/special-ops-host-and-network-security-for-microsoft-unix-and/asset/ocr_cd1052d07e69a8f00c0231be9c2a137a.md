#
Reverse DNS is most commonly used for identification reasons. Reverse domain names are a worthy axiom when troubleshooting. Traceroute and ping depend on reverse DNS lookups to display additional information about hosts. In addition to ping and traceroute, Secure Socket Layer (SSL), Tap ident Authentication (IDENT), and Simple Mail Transfer Protocol (SMTP) rely on reverse DNS. Though most may not hold on DNS errors, their performance is impacted by failed reverse DNS timeouts.
