You can check it by clicking on the **Advanced** tab and selecting the **Owner** tab. The view presented in Figure 6.10 is misleading—if you are an owner of the object, you still have full control of this object. To fully transfer the control over the object (any type of object, whether it is a user, group, or OU), the person to whom the control is transferred must take ownership of the object it already fully controls. The user needs to log in to the domain, start the Active Directory Users And Computers tool, select the **Security** tab of the object's Properties, and in the Advanced Properties transfer the ownership to himself (see Figure 6.11).
