# Chapter 4 • Attacking and Defending Windows XP Professional

ICF can be configured to allow certain rule and protocols to bypass the general “No Uninitiated Traffic” rule. Currently, ICF will allow you to select only from statically allowing FTP, Internet Mail Access Protocol 3 (IMAP3), IMAP4, Simple Mail Transfer Protocol (SMTP), Post Office Protocol 3 (POP3), Remote Desktop, HTTP/HTTPS and Telnet. Figure 4.14 shows the available services. To allow incoming traffic to these services, you simply need to click the appropriate check boxes and click OK. It should be understood that when you enable one of these services it opens a port for incoming; the more ports or services you have, the greater the potential risk.

The Security Logging tab shown in Figure 4.14 allows you to specify the location for which the log is stored. It also allows you to dictate the size of the log that will be overwritten as new entries for log. In its current format, ICF permits you to “Log Dropped Packets” and “Log Successful Connections.” At the bare minimum, it is recommended that you log successful connections, but if the space is permitted, full logging would have advantages in a time of need.
