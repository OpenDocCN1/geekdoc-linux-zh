# Using @STAKE WebProxy

WebProxy is one of the most useful Web application security-testing tools available. Although it is closed source, the application makes use of the popular plug-in model, allowing users to develop plug-ins of their own. The proxy ships by default with enough functionality within the shipped plug-ins to allow an analyst to sink his teeth into most Web applications. The proxy is written in Java, and requires an up-to-date Java Runtime Environment to be installed. For more information on the proxy, visit www.atstake.com.
