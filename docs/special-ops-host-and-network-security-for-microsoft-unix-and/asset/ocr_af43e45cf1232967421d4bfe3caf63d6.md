# Packet-Level Communication

Reviewing DNS communication at the packet level allows a better grasp of what rules to use for packet filtering or intrusion detection systems (IDSS) and what normal DNS traffic (shown in Figure 8.1) would look like when troubleshooting. DNS traffic uses port 53 via the User Datagram Protocol (UDP) or Transmission Control Protocol (TCP). Normal queries use UDP;TCP is preferred for large packets. The historical maximum for unfragmentable packets on a network is 576 bytes. If a query is larger than 576 bytes, a truncated (TC) bit is added to the response. If a TC bit is detected by the client software, it will resend the query over TCP. Zone transfers and abnormally large queries are the only time TCP is used. The breakdown of a DNS packet is very straightforward, in keeping with the simplicity of the DNS protocol.
