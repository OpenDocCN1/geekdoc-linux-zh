# GPS and Mapping

If you're dealing with your own corporate network, you will not likely have to incorporate a GPS into your wireless toolkit. Since you are dealing with mapping access points on a campus rather than city level, most of the APs would be grouped tightly together anyway. It may be somewhat however if you want to check one of the hotspot databases or local mapping projects using your GPS coordinates to see if anyone has counted on your network. Most of the dedicated GPS scanning tools include GPS support since it's one of the primary components of war driving. NetStummer is currently the only scanning application on Windows to have direct GPS support.

Most of the stumbling tools also support formatting their output so that mapping software such Microsoft Streets and Trips or MapPoint can plot the access points as map points and create maps of a given area's wireless coverage.

There may be some work involved getting the various tools output into a formatting program can recognize, but for NetStummer users there is a free tool called StumbVerter (www.sonar-security.com) that will automatically call your NetStummer summary files and create map points complete with small icons for each AP that display the signal strength and WEP status.
