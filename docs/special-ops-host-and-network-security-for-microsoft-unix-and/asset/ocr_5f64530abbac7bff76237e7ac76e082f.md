# Characteristics of Vulnerability Assessment Products

+   Vulnerability assessment tools perform host discovery and detect live systems to scan the network. Most scanners use a mix of ICMP, TCP, UDP, and/or MS Networking to determine active hosts.

+   Vulnerability assessment tools have service discovery (port scanning) or low-level enumeration features to determine which services are active
