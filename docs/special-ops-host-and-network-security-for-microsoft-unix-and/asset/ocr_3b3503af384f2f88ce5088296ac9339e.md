**Q:** Should I use Trivial File Transfer Protocol (TFTP) to manage my network device configurations?

**A:** TFTP does serve a great purpose in network administration. In large networks, it is very difficult to keep track of configurations and changes. Keep in mind, however, that TFTP is not a secure network transfer and should be used with extreme caution. Consider placing ACLs on routers or switches that have TFTP configured. Also, consider an implementation of TFTP with IPSec to encrypt the data on the wire.
