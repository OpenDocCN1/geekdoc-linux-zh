# owa_util.showsource

Sourcewill give back the source code of packages. It takes one parameter, cname, which is the name of the package to be viewed. Here is an example demonstrating how the source code of owa_util can be viewed:

```
http://oracleserver/pls/dadname/owa_util.showsource?cname=owa_util
```

This will give the source code of the owa_util package.The following is a snippet of the first part of the output of this query:

```
package owa_util
 OWA_UTIL is
```

```
type ident_arr is table of varchar2(30) index by binary_integer;
type num_arr is table of number by binary_integer;
type ip_address is table of integer index by binary_integer;
```

# owa_util.cellsprint

Cells allows the running of arbitrary SELECT SQL queries. It requires one parameter, p_theQuery, but can also take a second, p_max_rows, which specifies how many rows to return. If p_max_rows is not specified, 100 rows are returned.
