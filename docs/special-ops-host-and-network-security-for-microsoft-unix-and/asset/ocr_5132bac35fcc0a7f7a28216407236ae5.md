# Virus Scanning at the Desktop

Some administrators reach an early state of comfort when they deploy anti-virus software to the Exchange server; since the Exchange server is protected, they must be protected from viruses. I can tell you from experience that newly viruses have a tendency to bring files in from home on floppy disks and they check their Yahoo mail or POP3 mail at their ISP from work. This can easily and quickly introduce a virus to your system.

For this reason, in order to be more completely protected you must make sure that all of your desktop clients have a file based-anti virus software that is capable of scanning Outlook or other mail systems. Some administrators go so far as to make sure they use a different version of their antivirus software at the desktop than they do for the Exchange-based solutions.

# Blocking File Attachments

Just like increased airport security has increased wait times at metal detectors, blocking certain types of files has become a necessary evil for e-mail administrators. This is another one of those actions the e-mail administrator can perform and find himself being burned in effigy the cafeteria. Choosing a list of file types to block is difficult. Table 7.8 is a list of critical files that I recommend blocking on all e-mail systems.

Table 7.8 Critical Files to Be Blocked on All E-Mail Systems

| File type | File Type Description |
| --- | --- |
| .bat | Batch file (DOS or Windows) |
| .chm | Windows help files |
| .cmd | Batch command (Windows and OS/2) |
| .com | DOS-based application |
| .eml | E-Mail extensions (registered to Outlook) |
| .exe | Executable files |
| .js | JavaScript files |
| .pif | Program information files |
| .pl | PERL script |
