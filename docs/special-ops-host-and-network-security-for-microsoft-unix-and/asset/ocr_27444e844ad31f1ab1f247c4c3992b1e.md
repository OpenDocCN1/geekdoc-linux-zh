# Attacking and Defending Oracle • Chapter 13

# Table 13.2 Summary of Vulnerabilities

| Vulnerability | Description |
| --- | --- |
| Perl alias | The perl virtual directory is mapped to the same physical directory as cgi-bin. The source code of any script in cgi-bin can be accessed via the perl directory. |
| sendmail.jsp manipulation | /demo/email/sendmail.jsp can be used to send arbitrary emails. |
| Environmental variable disclosure | Several default pages leak information such as environment variables. |
