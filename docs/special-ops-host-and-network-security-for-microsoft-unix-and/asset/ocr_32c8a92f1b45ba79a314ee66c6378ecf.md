The sidebar example in this section, “The Advantages of Verbose Logging,” represents a reactive stance to network abuse. Carefully managed logging provides extensive resources for reacting to events, but how can you prevent this type of abuse before it happens? Even within an organization, Internet access tends to be anonymous to it, since many people are browsing the Web simultaneously, users are not concerned that their activity is growing to raise a red flag. Content filtering software can help somewhat, when the user encounters a filter she is reminded that access is subject to limitations, and by association, monitoring. In my experience however, nothing provides a more successful preventive measure than active authentication.

Active authentication describes an access control where a user must actually enter her username and password in order to access a resource. Usually, credentials are cached until a period of inactivity has passed, to prevent users from having to re-enter their login information each time they try to make a connection. Although this additional login has a certain nuisance quality, the act of entering personal information reminds the user that they are directly responsible for anything they do online. When a user is presented the login dialog, the plain-brown illusion of the Internet is immediately dispelled, and the user will police her activity more accurately.
