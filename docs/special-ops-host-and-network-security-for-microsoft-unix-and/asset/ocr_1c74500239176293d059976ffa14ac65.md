# owa_util.listprint

Listprint is cellprint—arbitrary SQL queries can be run—with one difference. If select * is executed, only one of the columns—the first—will be returned. Rather than selecting *, select a column name:

```
http://oracleserver/pls/dadname/owa_util.listprint?p_theQuery=select%20username%20from%20sys.dba_users&cname=&p_size=
```

This begs the question—how does one find the name of the columns in the given table?

# owa_util.show_query_columns

The show_query_columns procedure can be used to obtain a list of columns in a table. This procedure takes one parameter, ctable, which is the name of the table:

```
http://oracleserver/pls/dadname/owa_util.show_query_columns?table=sys.dba_users
```
