# Using a Discovery Script

If you rather write this script, you can use Discover.pl (weekly/biweekly/monthly) from moonapie.org to discover hosts on all segments across the internal network, enumerate services, and place them in a machine-readable output (see Figure 2.3). If you use the script for only, you can complete a Class C in two to three minutes and a Class B in about nine minutes.
