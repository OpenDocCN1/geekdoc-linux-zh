# DNS Integration with Active Directory

Active Directory is tightly integrated with DNS that it is amazing that Microsoft did not name it Active DNS instead! DNS is required on the network for Active Directory to be installed and function. This is a major change for those who are migrating from non-Transmission Control Protocol/Internet Protocol (TCP/IP) networks. There are two impacts on the DNS service when employing Active Directory:

+   - In order for clients to log on a domain managed by Active Directory, DNS is required to locate the DCs. The NetLogon service requires a DNS server that supports the service resource records (SRV RRs) because SRRs both register and identify the DCs in the DNS namespace.

+   - Active Directory can stow DNS zone information and replicate throughout the entire natively, without the zone transfer process. However, this requires that Windows 2000 DCs are also DNS servers.
