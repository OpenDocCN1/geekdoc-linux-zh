# ## The_Actor

Enter TScrack, a new tool that uses a technology called artificial neural networks to actually "scrape" the Terminal Services login screen and enter password submitted individually or obtained from an accompanying dictionary file. It is similar to the technology used in Optical Character Recognition (OCR), which improves over time as it is "taught" to recognize variations of the Terminal Services interface.

Being said, the name of the tool is somewhat misleading. TSrack is not a session cracking or hijacking mechanism, but more along the lines of a password testing tool. That is, it runs authentication attempts against a Terminal Server and will only prove successful if the password is easily guessed or a word in a commonly used dictionary (as opposed to a brute force program as 0lpht [www.atstake.com/research/lc] or the Ripper [www.openai.com/john]). The value of this tool is testing the strength of passwords used to protect terminal sessions.

TScrack is run from the command line on a Windows system, with the following flags:

+   -h Print usage help and exit
-V Print version info and exit
-s Print cipher strength info and exit
-b Enable failed password beep
-t Use two simultaneous connections
-N Prevent System Log entries on targeted server
-f <number> Wordlist to start cracking with
-l <user> Account name to use, defaults to Administrator
-w <wordlist> Wordlist to use; tsrack tries blank passes if omitted
-p <password> Use <password> to logon instead of wordlist/blank pass
-D <domain> Specify domain to attempt logon to
-F <delay> Specifies the delay between session samples in milliseconds
-U Uninstalls tsrack
