# XP Access Point Information Disclosure

XP Professional comes bundled with the capability to communicate over a wire-802.11 connection without the need for any additional drivers to be installed. The access point (AP) registration feature within XP allows a user to store the commonly-used, or in the case of an enterprise user, the organization’s access point Set Identifier (SSID) strings within the operating system itself. This feature allows a wireless LAN administrator to lock down the AP to the extent that it does not have to send client broadcast or respond to Null AP broadcasts. As shown in Figure 4.6, the XP Professional sends a typical broadcast 802.11 packet searching for available access points. The AP responded with its SSID, and the system initiates communication, provided that the AP matches an SSID within the registered configuration.
