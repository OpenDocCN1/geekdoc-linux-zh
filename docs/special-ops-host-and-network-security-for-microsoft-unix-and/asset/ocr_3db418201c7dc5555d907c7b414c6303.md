Most of these can be determined without authentication if you have the ability to capture packets off the network segment on which the target system resides. If you do not have local access, you may have a difficult time getting the MAC address and corresponding servers. Vulnerability scanners such as Retina and FoundScan retrieve just all of this information available. Other tools you may want to use GetMAC and CTIS (you can find both at www.packetsecurity.org), nslookup, tracer, and Ethereal. Nslookup and tracer (the Unix version is Traceroute) are bundled with almost all Windows and Unixbased operating systems. Ethereal’s site is www.ethereal.org.
