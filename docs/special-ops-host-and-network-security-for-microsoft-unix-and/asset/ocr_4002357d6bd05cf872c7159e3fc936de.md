exec master...xp_cmdshell 'net user hack hack_pass /add--

The first tick (') has the effect of closing the open set of quotes from the true query being assembled in the ASP code. SQL Server completes the query and then executes an exec command, so it continues processing. It executes the xp_cmdshell statement and adds a new user to the machine hack with password of hack. Finally, a comment (--) is added to the end of the line to negate the tick (') that the ASP code will append to the end of the text. The basic problem here is that the designer never imagined the consequences if a user ever entered a tick (') in the middle of a city name.

# Batching Commands

One of the reasons SQL Server is so susceptible to this kind of attack is that it accepts commands batch. It will take a select statement, for example, and then continue to process other statements as long as there are more statements in the batch. It is a "feature" that can cause you a great deal of pain when you fail to properly validate input. It simply means that databases that do not batching are impervious. It simply means that the injections do not attempt to add more statements instead alter the existing query in ways that can still be destructive, such as adding additional WHERE parameters, for example, or using the UNION operator.

# Concatenating Using UNION Operators

In some cases, the attacker may want to pull data out of the database. Although creating a new user (as in our previous example) might be useful if he is on the same network, the SQL Server is safely behind a well-configured firewall with egress filtering (see Chapter 16), he may need to use a different tactic. If a query was returning a list of cities when he enters a certain date, he might be able to inject a UNION statement so he could append passwords from the syslogs file. Sample exploit code might look like this:

```
UNION select password from master...syslogs --
```

If the application is running as 'sa' then the user should get a listing of all the encrypted passwords from the syslogs tables for cracking offline (using NGSSQLcrack from NGSoftware, for example: www.nextgens.com/products/ngssqlcrack.html). The UNION operator allows the attacker to append another result to the first. This could be useful when pulling data from multiple tables, but it also makes a good way for attackers to extract data from the server even when it is locked down from a network perspective.
