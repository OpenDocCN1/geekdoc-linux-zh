# Mailbox Size Limits

First, lets consider mailbox storage limits. These can be configured in one of several ways. First, they can be configured on the properties of each mailbox store. Figure 7.16 shows the property property of a store; this figure shows the limits I recommend for a typical Exchange 2000 server (I am occasionally accused of being rather generous). I strongly believe that if there is a “business” reason for keeping 75MB of data in one's mailbox, the user should be able to do so. However, e-mail storage requirements will vary from business to business and also from to user. Carefully plan your storage limits and make sure that you have enough disk space to support those limits.
