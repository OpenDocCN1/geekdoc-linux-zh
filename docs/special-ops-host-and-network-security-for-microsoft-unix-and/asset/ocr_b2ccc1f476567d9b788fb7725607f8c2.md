This is a domain with only two computers in-test1.witt.home and test2.witt.home, both domain controllers. It is possible to see various subdomains created by Active Directory in our zone “witt.home”. All of them are SRV records, describing which computer and particular service is listening. For example, LDAP over TCP can always be found at _ldap_tcp.witt.home:389, which is test1.witt.home with address 10.1.1.11 (also test2.witt.home with IP 10.1.1.21) and Kerberos service—on _kerberos_tcp.witt.home:88 (the same hosts). Servers for Active Directory sites are located under sites_subdomain- and for the forest-under_msdcs subdomain. The preceding case is for a single domain, single-site forest, where all services are located on the same hosts.

This information also gives names, in our case, Default-First-Site-Name and internal IDs of services 03c6ee0d-3165-46de-888e-bb24a757794e, and 102a7226-4269-4a85-a939-e693e8a958bf.

Even if servers are not allowed, it is possible to locate, for example, using the query such as this:

```
> querytype=srv
> _ldap_tcp.witt.home
Server: test1.witt.home
Address: 10.1.1.11
```
