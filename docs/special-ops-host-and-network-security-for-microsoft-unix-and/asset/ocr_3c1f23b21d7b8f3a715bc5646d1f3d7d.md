# Typhon II

Typhon II (www.nextgenss.com) is the new version of Typhon, which was formerly known as Cereus Internet Scanner. Typhon II is a lightweight Windows-based scanning tool that produces HTML reports and also includes a warding module. Figure 3.3 shows the main interface of Typhon II.

NGS Software releases every new vulnerability under a system called Vendor Notification Alerts (VNAs), in which very little public information is given. Frequently little information is given that other vendors will not have enough to create a vulnerability check; Typhon II, however, will have checks for these undisclosed vulnerabilities if found by NGS Software. Typhon III is slated for release in early 2003. The following are some features of Typhon:

+   - More than 320 Web checks
- An Oracle database module
- Lightweight Directory Access Protocol (LDAP) and Secure Shell (SSH) modules
- Secure Sockets Layer (SSL) support for Secure HTTP (HTTPS), LDAP, and other SSL-based services
