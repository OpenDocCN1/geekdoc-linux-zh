# NTFS File Systems

I mentioned earlier that the default setting in Windows 2000 gives the Everyone group control permissions to the root of each logical drive. As discussed in the sidebar, the DACL must be set for the root of the drive to a much more secure setting than the default allows. Permissions that are set at the root are "inherited" down through the directory structure, unless specifically blocked from inheritance. If you are using the NTFS file system as recommended, it would be normal to expect changes made to the upper level of the directory structure would automatically be applied to directories and files below that level in the structure. However, there are some default configurations that I alluded to earlier in the chapter. For instance, in Windows 2000 with a clean install, Users and Power Users are not allowed to write permission to the Program Files directories or their contents. Slops or stops these classes from using most applications, since the default within Windows installations is to install to a Program Files directory. To accomplish, inheriting permissions from upper directory levels are blocked by clearing the checkbox at the bottom left corner of the Properties page for the folder, as shown in Figure 5.19. Note that the default permissions illustrated in Figure 5.8 have not been applied to the Program Files directories.
