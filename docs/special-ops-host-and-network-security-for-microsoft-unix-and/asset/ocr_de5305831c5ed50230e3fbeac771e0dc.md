# APTools

APTools (http://tools.sourceforge.net) is a unique utility that will log directly into your Cisco switches and log the computer-aided manufacturing (CAM) table (where MAC addresses are stored) to look for wireless clients. If it finds a Cisco MAC prefix it can also audit the Web. To use APTools, you will need to supply it with a list of IPs to interrogate remotely for management services that run on Aironet devices (like Web administration) or with login information to a router or switch so that it can sift through the MAC address lists of these devices for known MAC prefixes.
