# Table 7.8 Critical Files to Be Blocked on All E-Mail Systems

| File type | File Type Description |
|---|---|
| .reg | Registry files (registered to Regedit) |
| .scr | Screen saver files |
| .sh | Shell script |
| .shs | Scrap file extension |
| .vb | Visual basic files |
| .vbs | Visual basic script extension |
| .ws | Windows scripting host |
| .wsc | Windows scripting components |
| .wsf | Windows scripting host |
| .wsh | Windows scripting host |

> If you are extra cautious, you might also consider blocking this list that is published on the Exchange 2000 administrator’s mailing list FAQ (see Table 7.9).
