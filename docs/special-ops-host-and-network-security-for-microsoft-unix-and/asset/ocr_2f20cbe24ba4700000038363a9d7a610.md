# Chapter 5 · Attacking and Defending Windows 2000

Notice in this default installation that four accounts were created during the installation. These include the Administrator and Guest account that are created in all Windows 2000 installations. As you can see, the Guest account is disabled; this occurs by default during the installation. The two additional accounts that are created by default during a Windows 2000 server installation are the IUSR_username account and the IWAM_username account. Since Windows 2000 server installations automatically install Internet Information Services (IIS) 5.0, these two accounts are also created to be used for anonymous connections to the Web server and File Transfer Protocol (FTP) server and for running out of process applications on the Web server. Both of these accounts are made of the default Guests group, which is shown in Figure 5.4. (The TSInternetUser account in the diagram is created when Terminal Services is installed, but this is not part of the default installation).

At the local level, the groups that are created in the default installation include Administrators, Backup Operators, Guests, Power Users, and Users. Additionally, in the default configuration, the Replicator group is added and used for file replication when the system is a member of a domain. In this level, the Users group has only basic access to the local machine and resources, and is unable to install programs or drivers or to change configuration outside of their own local profile settings.
