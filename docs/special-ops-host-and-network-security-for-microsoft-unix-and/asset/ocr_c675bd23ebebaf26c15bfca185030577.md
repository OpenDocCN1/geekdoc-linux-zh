# Verify Shared Resources and Connections

If you are a traveling professional, it is important that you remember to occasionally check your mapped drives and shared resources. In many cases, when you map a drive to your machine you may use a different set of authentication credentials. These drives are not the same as resources that automatically connect to joining a domain. For instance, when you join a first network and have a mapped drive configured to reconnect at logon, the system sends a broadcast message outwards in search of the Remote system. That broadcast may be in the form of a system name or IP address, the fact remains that you may be broadcasting that sensitive information about other networks.

In the following case, you will see a resource descriptor that has the status Unavailable. The Unavailable status informs the user that your system cannot locate the requested system. To identify your network connections, open a command prompt and type net use. It displays resources that your system currently lists and for the current status of the connection.

```
C:\net use
```

New connections will be remembered.

| Status | Remote | Network |
| --- | --- | --- |
| Disconnected L: | \\system\sharedfiles | Microsoft Windows Network |
| Disconnected M: | \\10.0.300\music | Microsoft Windows Network |
| Unavailable Z: | \\client\workdocs | Microsoft Windows Network |
