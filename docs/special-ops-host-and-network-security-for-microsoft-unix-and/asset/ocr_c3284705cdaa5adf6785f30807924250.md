# LanGuard Network Security Scanner (LNSS)

LanGuard Network Security Scanner (www.gfi.com) allow network administrators to quickly and easily perform network security audits by combining the functions of a port scanner and a security scanner. LNSS was created to highlight the most important information, thus avoiding the information overload created other scanners. For this reason, LNSS lends itself to internal network security. Furthermore, LNSS is freeware for noncommercial usage, so it is hard to beat the price!

# whisker

The whisker scanner, created by Rain Forest Puppy (RFP), is a simple Common Gateway Interface (CGI) vulnerability scanner written in Perl (www.wiretrip.net/rfp).The scanner has split into two separate parts: whisker, which is the scanner that we know and love, libwhisker, a Perl module that is used by whisker.

Traditional CGI scanners do not have a heck of intelligence built into them. They simply point themselves at a host and fill that host's log files with number of known CGI issues, regardless of the existence of the /cgi-bin/direct- and regardless of the Web server running. The problem with that it does not make sense to blindly scan a machine, because you not only waste a lot of time and bandwidth, but you will also, more times than not, end missing a number of issues. Not a traditional CGI scanner, whisker attempts to solve this problem by first having some intelligence built in, such as a way to determine the operating system and revision of Web server being scanned and the capability to modify or script other options into your scans. It also offers the capability to attempt to use some of the classic IDS evasion techniques.
