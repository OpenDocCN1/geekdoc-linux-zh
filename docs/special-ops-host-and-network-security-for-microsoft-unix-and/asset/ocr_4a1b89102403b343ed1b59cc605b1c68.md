# Network Analysis Risk Reduction

When I teach network and Exchange classes, one of my favorite side-topics is network monitoring. At many points throughout an Exchange class, I will fire up the Microsoft Network Monitor and demonstrate how easy it is to intercept data if you have Network running and you are sitting in the path of the user's IP datagrams. Although protecting the network from a physical layer assault is more appropriate for topics found in Chapter 15, (Network Architecture) and Chapter 17 (Building and Attacking Wireless Networks), I felt nonetheless compelled to provide you with a list of things that you should consider to improve security of messaging data traveling on your network:

+   Move all to switched networks to reduce the ease of which a rogue individual can perform network monitoring.

+   Enable require SSL for all standard Internet such as OWA, POP3, IMAP4, and NTTP.

+   Enable IPSec between all Exchange 2000 servers including those configured front-end and back-end servers. However, note that you cannot use IPSec on Windows 2000 clustered nodes.

+   Enable IPSec between Exchange 2000 and domain controllers/global catalog servers to protect LDAP queries.
