As a further precaution, you should completely remove these directories from the file system:

+   - C:\netpub\scripts
- C:\winnt\help\iis\iis
- C:\netpub\iisamples
- C:\winnt\web\printers
- C:\winnt\system32\inetsrv\iisadmin
- C:\winnt\system32\iisadmpwd

You should disable the default Web site by setting the IP Restrictions to deny all access from the outside and finally stopping the site. Further measures you can take to secure the site include changing the port to something besides 80, setting the host header to LocalHost, and disabling anonymous access to the site.

The administrative Web site provides sensitive HTML-based IIS administration functions. Although access to site is limited to LocalHost by default, if you are not using HTML-based administration, you should completely remove this site. If you are using HTML-based administration, take measures to further secure it by setting more strict IIS and NTFS permissions.
