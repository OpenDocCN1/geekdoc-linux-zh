## 5.1.2 安装 VESA 缓冲区

如果你在配置 X 服务器时遇到问题，或者想创建一个可以在任何显卡上运行的映像，你应该安装 VESA 缓冲区驱动程序。缓冲区为兼容 VESA 的显卡提供了有限的功能。以下是配置缓冲区的指令：

- 1. 系统以命令行模式启动后，以“root”身份登录。

- 2. 挂载 TurboLinux Companion CD 并使用以下命令安装包：

```
mount /dev/cdrom /mnt/cdrom
cd /mnt/cdrom/TurboContrib/RPMS
rpm -ivh XFree86-FBDev-3.3.6-i386.rpm
```

- 3. 保存当前的符号链接并运行以下命令创建一个符号链接：

```
mv /etc/X11/X /etc/X11/X.old
ln -s /usr/X11/bin/XF86_FBDev /etc/X11/X
```

- 4. 打开 `/etc/lilo.conf` 为缓冲区添加新项：

```
vi /etc/lilo.conf
```
文件内容如下：

```
boot=/dev/sda
map=/boot
prompt=
timeout=50
default=/boot/vmlin
image=/boot/vmlin
label=/dev/sda
initrd=/boot/initrd
read-only
```

- 5. 复制现有项。将标签 linux-fb 或其他内容更改为你的名称。在新项中，在 image 行之后的 `vga=xxx`（“xxx”见表 6）更改标签使其唯一。

# 表 6. 分辨率

| 分辨率 | 分辨率 | 分辨率 | 分辨率 | 字节/像素 |
|---|---|---|---|---|
| 640x480 | 800x600 | 1024x768 | 1280x1024 | |
| 800x600 | 1024x768 | 1280x1024 | | 256 |
| 1024x768 | 1280x1024 | | | 32K |
| 1280x1024 | | | | 64K |
| | | | | 16M |

以下是安装缓冲区在 `/boot/` 的 `/etc/lilo.conf` 项：

```
image=/boot/vmlin
label=linux-fb
root=/dev/sda
vga=800
initrd=/boot/initrd
read-only
```

- 6. 在验证新映像有效之前不要更改默认映像。运行命令更新引导记录和 LILO 引导程序：

```
lilo
```

- 7. 编辑 `/etc/X11/XF86Config` 为缓冲区创建一个节项。复制下面的屏幕项示例并进行必要的更改。由 zzz 定义的相关深度值来自上表。xxxx 和 yyyy 取决 XF86Config 中的字符串。将 xxxx 替换为 Device 部分之后的字符串。将 yyyy 替换为 Monitor 部分之后的字符串：

```
Section Screen
Driver=fdev
Device xxxx
Monitor yyyy
Subsection Display
Depth=zzz
Modes default
EndSubsection
EndSection
```

- 8. 重启系统并移除所有介质。

- 9. 重启服务器后可能会收到警告；此警告是正常的。预期会有选择。

- 10. 在 LILO 启动提示符处，按 Tab 键内核选项。你应该有两个选项：linux 和 linux-fb。选择 linux-fb。

- 11. 系统在命令行模式启动后，可以通过发布命令启动 X 服务器：

```bash
startx
```

- 12. 如果此有效，你可能想再次编辑 `/etc/lilo.conf` 将 linux-fb 设置为默认。然而，这必须。

## 5.2 Turbonetcfg

Turbonetcfg 是 TurboLinux 的多功能网络配置工具。通过它可以配置从网卡 IP 地址到 Apache Web 服务器的一切。要调用此工具，输入 `turbonetcfg`。虽然它是一个文本模式实用，但我们建议在 X 内部运行它，因为某些窗口需要的比没有 X 时通常提供的控制台大。

![](img/4e6a76e57a4105be55d8a1cc0750b023_141_0.png)

图 128 是 turbonetcfg 的主窗口。以下是该窗口所有选项的简要说明。

- **显示配置**。显示主机和域名的当前配置，以及机器中的网卡和默认路由器。
- **基本设置**。允许设置主机名和域名，并添加搜索域、二级 DNS 服务器以及默认网关和网关设备。
- **主机表**。用于没有 DNS 服务器或希望指定常用机器 IP 地址的情况。它也应该包含 127.0.0.1 作为本地。将你的 IP 和主机名添加到此表中是一个好主意，因为它可以让 GNOME 启动更快。
- **网络接口**。网络接口对话允许管理服务器上的所有网卡，包括无需重启即可添加、删除或更改接口。
- **网络诊断**。这是 turbonetcfg 一个非常有趣的功能。选择此选项会导致 TurboLinux 运行一系列网络测试。注意，如果在“测试名称查找 (getbyhostname)”查询期间无法连接到 DNS 服务器，查询会在窗口中持续几分钟。然而，它最终会超时并显示一个类似于图 129 的结果窗口。
