# 7.2.10.2 Verifying the RecoverEDGE boot diskette
To verify the diskettes, boot from the first diskette and follow instructions on the window. When the system is started you will get the RecoverEDGE main menu. Select Utilities > Tape Drive.

In the Tape Device Node, you see the defined tape device. Go to the Test Tape Drive field and test your tape device. If the test is successful your recovery set is ready to use.
