## 7.2.10 RecoverEDGE

By using the RecoverEDGE tools you can create emergency recovery diskettes to rebuild your system in the case of disaster. RecoverEDGE handles the details of reconstructing your FDisk, partition, and/or slice tables, building your file systems and restoring your data, even if your hard drive size has changed. RecoverEDGE uses your system backups, so there is no need to shut down your system in order to protect it. You can even restore over the network.

With RecoverEDGE restoring the system is very easy. To recover the system you should follow these tasks:

- 1. Identify and correct the cause of the failure.
- 2. Boot from the RecoverEDGE disks.
- 3. Reconfigure your file systems.
- 4. Restore your backups.
- 5. Shut down and reboot.
- 6. System is ready to use.

> Note
> RecoverEDGE uses your master and incremental backups for recovery, so the accuracy of the data depends on these backups.
