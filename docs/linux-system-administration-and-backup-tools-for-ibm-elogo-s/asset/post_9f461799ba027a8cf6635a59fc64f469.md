
## 4.4.1 Modifying users - the command line version

You can modify user logins with the usermod command.

```
# usermod
usage: usermod [-u uid] [-g group] [-O group,...]
      -d home [-m] [-s shell] [-c comment]
      [-l new_name]
      -f inactive] [-e expire ] [-p passwd] name
```

Figure 95. The usermod command

The options for the usermod command are basically the same as those for the useradd command, so they will not be different except for those that are different. With the usermod command you need to observe the following:

- -d home [-m]
The -m option says to move the contents of the current home directory to the new home directory and create the directory if it does not exist.

- -l new_name
This allows you to change the user's name that he logs in with. The user cannot be logged in with this name when he does.

- -p passwd
This allows you to set the password of the user from the command line. This can be useful if you have a program that automates password creation, since you can use a variable in the place of the passwd string.

## 4.4.2 Deleting users - the command line version

The command to delete users is userdel. You can see the options in Figure 96. This command is a lot simpler because there is not much choice you have when deleting a user.

```
# userdel
usage: userdel [-r] name
```

Figure 96. The userdel command can use is:

The only option that you can use is:

- -r
This says for you to remove the home directory and its contents. Otherwise, the home directory and its contents will not be deleted.

## 4.4.3 Group administration using YaST

To administer users, select System Administration -> Group administration from the YaST main menu. Alternatively, start YaST from the command line using the following parameters:

```
yast --mask group --autoexit
```

This will get you directly to the group administration window: ![](img/4e6a76e57a4105be55d8a1cc0750b23_105.png)

Each user has a unique name and ID. The default group for normal users is. To create a new group, enter the name of the group and Tab to advance to the next field. If you entered a new group name, YaST will automatically assign the next available group ID to this group. You can accept it or modify to your needs. If it is not intended to be the primary (default) user group, you can protect it with a password as well. All users that should be members of that group can be entered in the List of members list (comma-separated). You can press F3 to select them from the user list, or you can add them manually. Press F4 to create this group, F10 or Esc to leave. If you want to delete a group, select the group with F3 or enter it manually and press F5 to delete it. Please note that this will not delete user accounts belonging to this group from the file /etc/groups. To leave the group administration window, press F10 or Esc.
