+   1. Checksum Verification - When archives are written, a checksum is calculated for each block of data. The checksum is stored in the header of block. Checksum verification will read each block, recalculate the checksum, and compare the checksum to the value in the header. Each file will be listed as it is verified, along with any errors found. If no errors are found, you have an accurate backup.

+   2. Compare Verification - BRU compares the files to the archive on the hard drive. Any differences, such as modification times, size, or files in the archive are nonresident on the hard drive are noted. An end of differences notice will be posted when the verification is complete.
