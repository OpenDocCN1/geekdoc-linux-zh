# 5.3.3 Adding NetBIOS based remote printers

Microsoft Windows and IBM OS/2 default to sharing printers over an SMB Server Messaging Block (SMB) protocol commonly referred to as NetBIOS. If you have print shares that are accessed by SMB, you can configure Linux to act as a gateway to those print shares.

![](bbox=[0.15, 0.169, 0.84, 0.355])

Figure 140. New Queue Name window

Above we have selected Add and then SMB/LAN Manager Printer. We have named this printer NetBIOS-share for clarity.

![](bbox=[0.159, 0.455, 0.84, 0.651])

Figure 141. Edit Printer Settings window

The window in Figure 141 is identical to the window in the LPD printer configuration, with the exception of the SMB Settings field. That information can be completed by selecting Configure.
