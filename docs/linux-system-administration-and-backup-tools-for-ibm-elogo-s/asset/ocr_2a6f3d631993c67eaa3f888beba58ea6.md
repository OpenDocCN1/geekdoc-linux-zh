What we are most interested in is the file/directory permissions. This signifies a lot of information in a short amount of space:

d - The first character in the permissions signifies that this is a directory.
Other files are represented by:

+   - a normal file.
- a symbolic link to another file.
- c refers to files in the /dev directory. This signifies the file represents a character device.
- b refers to files in the /dev directory. This signifies the file represents a block device.

rwx - In this case it allows only the owner of the file (in this case linux) to read, write and execute this file.

| Type | Owner | Group | World |
| --- | --- | --- | --- |
| d | rwx | --- | --- |

As you can, the format of the string is becoming a bit easier to understand.

The owner of the file is the user who created the file. The group part is the group that owns the file (for example, group users). The world part means everyone else. Setting a permission in the world sets the permission for every user, irrelevant of their group membership and so on.
