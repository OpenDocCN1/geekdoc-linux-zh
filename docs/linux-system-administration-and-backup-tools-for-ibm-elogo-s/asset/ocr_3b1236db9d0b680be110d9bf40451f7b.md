# The LINUX Experts

This dialog allows you to configure your IP address. You can select dynamic address assignment, if you have a DHCP server turning on your local network. You should also select this if you do not have a static IP assigned to you by your cable or DSL provider. Network addresses will then be obtained

![](bbox=[0.453, 0.085, 0.815, 0.403])

Figure 10. YaST2: Network address configuration

You have two options for configuring your network devices. You can use DHCP to acquire your network address, gateway address, DNS server and so on, or you can manually assign an IP address to the network interface as we have done in Figure 110.

Once you have entered the corresponding values into the configuration window, click Next to continue.
