This is the numeric UID or user ID number that is used by Linux to distinguish one user from the other. All UIDs must be unique unless the -o option is used. The -o option is used for creating IDs that have the same access rights, but different logins and passwords. The system looks only at the UID and GID values for determining access rights.

-n

By default a group will be created whose GID is the same as the UID of the user created. The -n option will turn off this Red Hat originated behavior.

-r

This is used to create a system account whose UID is lower than a certain number defined in /etc/login.defs. You will also need to specify the -m option if you want to create the home directory. Otherwise, it will not be created. System accounts generally have UID values between 0 and 99.

login

This is the login name that the user will log with. This will need to be unique on the system.

# 3.3.2 Modifying users

You can modify users with the usermod command:

```
root@root:~# usermod
usage: usermod [-u uid] [-o] [-g group] [-c group...]
      [-d home [-m] [-s shell] [-c comment] [-l new_name]
      [-f inactive] [-e expire mm/dd/yy] [-p passed] name
root@root:~#
```

Figure 62. The usermod command

The options for the usermod command are basically the same as for the useradd command, so they will not be repeated except for those that are different. With the usermod command you need to observe the following options:

+   -d [-m]

The -m option says to move the contents of the current home directory to the new home directory and create the directory if it does not exist.

+   -l new_name
