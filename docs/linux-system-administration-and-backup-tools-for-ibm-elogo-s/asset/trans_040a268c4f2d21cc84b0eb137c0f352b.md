> 注意
在修改配置文件时，将原始文件复制到备份文件是一个好习惯。你可以执行操作：

cp file_name file_name.bak

（其中 `file_name` 是你正在使用的文件）

在任何想要更改的条目前加上注释符号（通常是 `#`）。使用修改后的信息创建一个新行。这允许你在发生错误时返回之前的条目，而且如果复制了文件，你还可以完全恢复到原始文件。

如果你能成功登录，就说明远程访问工作正常。
