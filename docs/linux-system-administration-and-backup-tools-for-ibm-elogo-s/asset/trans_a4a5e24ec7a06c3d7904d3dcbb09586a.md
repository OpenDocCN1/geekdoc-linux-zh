## 5.5 用户和组

Linux 是多用户系统。为了区分用户，我们使用 UID（用户标识符）。系统知道用户和组仅通过数字。在这种情况下，组通过组 ID 识别。组 ID 必须是唯一的。组列表存储在文件 /etc/group 中。显示显示有：

-   **Group。** 这是组的唯一名称。
-   **GID。** 系统知道用户和组仅通过数字。在这种情况下，组通过组 ID 识别。
-   **Members。** 这是该组的成员列表。

您还应该注意到您有选项选择：

-   **Edit** - 编辑当前组列表。这允许您更改列表上组的特征。
-   **Add** - 添加新组。
-   **Remove** - 移除当前组。
