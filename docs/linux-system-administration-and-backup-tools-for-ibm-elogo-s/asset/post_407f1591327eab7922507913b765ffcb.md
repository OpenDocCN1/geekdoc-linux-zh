
## 7.3.2 Configuring Arkeia

Before you can configure Arkeia, check whether the Arkeia backup server is running. To do this, enter:

```
ps -ef | grep -v grep | grep nlservd
```

on the system which should be used as your backup server. If you see a line like

```
root 488 1 0 09:06 ? 00:00:00 /usr/knox/knox/bin/nlservd start
```

the backup server is running. To begin with the configuration of Arkeia, be sure your X-Windows is running. Then enter on the command line:

Arkeia

You will see a dialog like Figure 232:

![](img/4e6a76e57a4105be55d8a1cc0750b023_238_0.png)

Figure 232. Arkeia initial window

The field for the server name is by default filled in with the name of the system you currently work with. You must change this field if you have installed the server component on another system.

The field for the login name is by default filled in with root. Change it if you have changed the name of the Arkeia administrator.

The field for the password is empty by default. You have to enter the password when you have changed the password. The main dialog window of Arkeia appears (Figure 233):

![](img/4e6a76e57a4105be55d8a1cc0750b023_239_0.png)

Figure 233. The Arkeia main dialog window

If you want a simpler layout of the window, go to Utilities -> Setting in the menu bar and modify the appearance of the windows. Click the OK button, save the new setting, and click the OK button again. Now, you will get a window similar to the window in Figure 234.

![](img/4e6a76e57a4105be55d8a1cc0750b023_240_0.png)

Figure 234. The new Arkeia main dialog window

At the bottom of the window you push buttons shown in Figure 235:

![](img/4e6a76e57a4105be55d8a1cc0750b023_240_1.png)

Figure 235. Bottom part of main window

The meaning of these buttons is, from left to right:

- Refresh job
- Interactive backup
- Periodic backup
- Restoration
- Savepacks
- Tapes management
- Pools management
- Drives management
- Drivepacks
- Libraries management
- Backup done

- OK button. Clicking this button opens a new Welcome dialog.
- Cancel button. Click this button to leave Arkeia.
- Help

Before you can begin with your first backup, you must carry out the following configuration steps:

- Pool management
- Tape management
- Drives management
- Drivepacks management
- Savepacks management

Let us start with tape pool management. Click the pools management button on the bottom of the main dialog or click Tapes -> Pools management on the menu. The Pools management window appears as in Figure 236:

![](img/4e6a76e57a4105be55d8a1cc0750b023_241_0.png)

Figure 236. Pools management main dialog window

The scratch pool exists by default. To create a new tape pool, for instance for your backup tapes, click the new button. The Pool creation dialog appears as shown in Figure 237:

![](img/4e6a76e57a4105be55d8a1cc0750b023_242_0.png)

Fill in the dialog fields with the appropriate information and click the **OK button**. The Pools management main window appears with the pool list updated as in Figure 238:

![](img/4e6a76e57a4105be55d8a1cc0750b023_242_1.png)

Figure 238. Pools management main window with updated pool list

To return to the main dialog, click the **OK** button. Now we can fill the Full Backup pool with tapes. To do this, click the tape management button or click **Tapes -> tapes management** in the menu. The Tapes management window appears (Figure 239):

![](img/4e6a76e57a4105be55d8a1cc0750b023_243_0.png)

Figure 239. Tapes management main window

Click the **new** button to enter new tapes (Figure 240):

![](img/4e6a76e57a4105be55d8a1cc0750b023_244_0.png)

The tape name consists of a fixed part and a variable part. The fixed part can be any text, while the variable part is a number. Enter the first part of the tape name, the first and the last number of the tapes to used, and the tape type (DAT, DLT, etc.). Choose the pool tapes should belong to and enter a comment in the comment line. Click the OK button to return to the tapes management window. The tapes management main window appears with the updated list of created tapes. Click the OK button in this window to return to the main window.

After the creation of tape pools and tapes, we can create drives and drive packs.

![](img/4e6a76e57a4105be55d8a1cc0750b023_245_0.png)

Click the **new** button to fill in the fields with the appropriate information. The fields Name and Device must be filled. Do not forget to choose the correct tape type in the Type field. To return to the Arkeia main window, double-click the **OK** button.

Now we can generate drivepacks. Click the drivepacks button or click **Devices -> Drivepacks** on the menu. The Drivepacks window appears (Figure 242).

![](img/4e6a76e57a4105be55d8a1cc0750b023_246_0.png)

Click the **new** button to fill in the fields. Fill in and choose one entry in the drives list and click the **OK** button to update the list of existing drivepacks on the right side of the window (Figure 243).

![](img/4e6a76e57a4105be55d8a1cc0750b023_247_0.png)

Figure 243. Updated drivepacks management window

Click the OK button again to return to the main dialog window. The last step before data can be saved is creating at least one savepack. Describe in savepacks which data should be saved. Different savepacks contain different sets of data to be saved.

To create savepack(s), click the savepacks button or click Tapes -> Savepacks on the menu. You will see a window like Figure 244:

![](img/4e6a76e57a4105be55d8a1cc0750b023_248_0.png)

Click the **new** button to enter input mode. A window similar to Figure 245.

![](img/4e6a76e57a4105be55d8a1cc0750b023_248_1.png)

Enter the name of the new savepack and click the OK button to return to the updated Savepacks management window (see the list of savepacks on the right side of the window). A window like Figure 246 appears:

![](img/4e6a76e57a4105be55d8a1cc0750b023_249_0.png)

Figure 246. Updated Savepacks management window

Now, you select the data that should be saved in every created savepack. Move the cursor over the name of the savepack you want to select the data and click the left mouse button. You can see the selected savepack.

Now, move the cursor over the list of trees to back up (left listbox of this window), click the right mouse button and select Navigator in the upcoming pull-down menu. You will see a window similar to Figure 247.

To navigate through the directory tree of a system shown in this window, move the cursor over the system you want to select and double-click the left mouse button. A window similar to Figure 248 appears.

Double-clicking the left mouse button over a directory symbol opens this directory and shows the content of this directory.

![](img/4e6a76e57a4105be55d8a1cc0750b023_250_0.png)

Figure 247. Navigator window

Clicking once with the left mouse button in the checkbox to the left of a directory name or file name toggles the select/unselect status of this item. All selected items will be inserted in the list of trees to back up for the selected savepack. If you select a directory, the checkbox changes the color totally. If you only select a selection of the items in a directory, the checkbox changes color only in the right half of the checkbox.

![](img/4e6a76e57a4105be55d8a1cc0750b023_251_0.png)

To return to the savepacks management window, click the OK button. You will see a window similar to Figure 249.

![](img/4e6a76e57a4105be55d8a1cc0750b023_252_0.png)

The basic configuration steps are now done.

Read the Administrator's Manual/ to get more information about the advanced possibilities of Arkeia.
