# Preface

This book gives you an understanding of the unified system administration incorporated in the Caldera OpenLinux, Red Hat Linux, SuSE Linux and TurboLinux operating systems. It also provides information on three Linux backup and recovery applications supported by these operating systems.

This ebook provides an understanding of Linux system administration and backup at a fairly detailed level, to help you increase your Linux skills in both areas quickly and easily.

This ebook also directs you to the available IBM Redbooks of Caldera OpenLinux, Red Hat Linux, SuSE Linux and TurboLinux that provide specific global instructions to help you plan, install, and configure each operating system on IBM @server xSeries and Netfinity for satisfactory operation.
