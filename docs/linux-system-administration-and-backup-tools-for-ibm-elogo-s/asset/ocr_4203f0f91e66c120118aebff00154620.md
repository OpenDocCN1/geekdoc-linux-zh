Now you have the opportunity to start the NFS server to allow you to share your directories with other computers on the network. If you do not wish to share any directories with other machines, select Do not start NFS Server and press Next to continue. If you want to share NFS mounts with other computers, select Start NFS server, and press Next to continue.
