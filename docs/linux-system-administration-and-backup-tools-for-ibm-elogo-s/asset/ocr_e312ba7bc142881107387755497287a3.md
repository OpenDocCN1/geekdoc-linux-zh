# 5.4 Adding removing software packages

TurboLinux uses the RPM (RedHat Package Manager) system to manage software packages. RPM uses a database to store information about the packages installed, the file that package installs, and other relevant information needed for package management. Although several books have been written to explain the complexity and flexibility available with RPM, we will discuss it as a method to easily install and remove programs.
