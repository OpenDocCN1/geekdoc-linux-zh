## 4.4 Adding users to the command line

To add users to the Linux system you can also use the command useradd. In Linux you can find the options to useradd.

```bash
useradd [options] USER
```

The following options for useradd are:

- -u uid [-o]: This is the numeric UID or ID number that is used by Linux to distinguish one user from the other. All UIDs must be unique unless the -o option is used. The -o option is often used for creating UIDs that have the same access rights, but different logins and passwords. The system looks only at the UID and GID values for determining access rights.
- -r: This is used to create a system account whose UID is lower than a certain number defined in /etc/login.defs. You will also need to specify the -m option if you want to create the home directory. Otherwise, it will not be created. System accounts generally have UID values between 0 and 99.
- -g initial_group: The initial group that user logs in with. This can be a name or number of currently existing group. This is specified in the /etc/password file as GID or Group ID. The default group is given by the value of GROUP.
- -G group{...}: This is a list of any additional groups the user may belong to. Each group is separated by a comma.
- -m [-k skeleton_dir]: The -m option says to create the user's home directory if it does not exist. The skeleton_dir is the location of files that are copied to a new user's directory. The default location, if you do not use the -m option, is the /etc/skeleton directory. The default is the value of SKEL.
- -s: This is the shell that the user will log in with. The default is the value of SHELL.
- -e expire_date: This is the date on which the account will be disabled. The date is in format MM/DD/YY where MM is month, DD is date and YY is year. (Note that even though the date is represented in two digits, there are no Y2K worries.)
- -f inactive_time: This gives the status of the account. The value of 0 says disable the account when the password expires. A value of -1 says not to disable it. The default is the value of INACTIVE.
- -d home_dir: The home directory of the user. If this is not specified, the default is /home/username.
- -c comment: This is a comment field about the user. It can include such as office number, phone number, and more. This is specified in the GCOS field.

```bash
useradd -u 1000 -g users -G sudo,video,wheel -m -d /home/john -s /bin/bash -c "John Doe,555-1234" john
```
