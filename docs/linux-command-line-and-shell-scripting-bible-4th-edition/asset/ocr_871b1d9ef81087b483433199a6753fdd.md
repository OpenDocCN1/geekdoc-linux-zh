The xterm terminal emulator can be tricky to find these days. Often, it is not included in a desktop environment graphical menu arrangement.

# ## Accessing xterm

In the KDE desktop environment (Plasma), you can access xterm by clicking the Application Launcher icon in the lower-left corner of the screen. Then click Applications ⌂ System ⌂ standard terminal emulator for the X Window system (xterm).

Once the xterm package is installed, you can access it via the GNOME Shell search feature. Click the Activities icon in the upper-right corner of the desktop window.
