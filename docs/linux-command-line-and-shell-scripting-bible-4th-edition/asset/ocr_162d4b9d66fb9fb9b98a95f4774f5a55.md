All the global environment variables displayed using the `env` or `printenv` command appear in the `set` command’s output. # **NOTE**

The differences between the commands `env`, `printenv`, and `set` are subtle. The `set` command displays global and local environment variables, user-defined variables, and local functions. It also sorts the display alphabetically. The `env` and `printenv` are different from `set` in that they do not sort the variables, nor do they include local environment variables, local user-defined variables, or local shell functions.
