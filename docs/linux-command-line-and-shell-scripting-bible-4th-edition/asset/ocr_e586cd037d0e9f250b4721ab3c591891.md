Another nice feature is that you can run the option letter and the
parameter value together without a space:

```
```
$ ./extractwithgetopts.sh -abBValue

Found the -a option
Found the -b option with parameter value BValue
$ 
```
```

The **getopts** command correctly parsed the **BValue** value from the *-b*
option. In addition, the **getopts** command bundles any undefined
option it finds in the command line into a single output, the question
mark:

```
```
$ ./extractwithgetopts.sh -d

Unknown option: ?
$ ./extractwithgetopts.sh -ade

Found the -a option
Unknown option: ?
Unknown option: ?
$ 
```
```

Any option letter not defined in the *optstring* value is sent to your
code as a question mark.

The **getopts** command knows when to stop processing options and
leave the parameters for you to process. As **getopts** processes each
option, it increments the **OPTIND** environment variable by 1. When
you've reached the end of the **getopts** processing, you can use the
**OPTIND** value with the **shift** command to move to the parameters:

```
```
$ cat extractoptsparamswithgetopts.sh
#!/bin/bash
# Extract command-line options and parameters with getopts
#
echo
while getopts :ab:cd opt
do
     case "$opt" in
          a) echo "Found the -a option" ;;
