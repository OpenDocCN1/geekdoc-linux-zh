|, i [ , n ] | i. If n is not supplied, the rest of s is used. |  
|---|---|  
| tolower( s ) | Converts all characters in s to lowercase. |

However, and some of the string functions can get pretty complicated. The asort and asorti functions are new gawk functions that allow you to sort an array variable based on either the data element values (asort) or the index values (asorti). Here’s an example of using asort:

```
```
$ gawk 'BEGIN{
> var["a"] = 1
> var["g"] = 2
> var["m"] = 3
> var["u"] = 4
> asort(var, test)
> for (i in test)
> print "Index:" ,i," - value:" ,test[i]
> }'
Index: 4 - value: 4
Index: 1 - value: 1
Index: 2 - value: 2
Index: 3 - value: 3
$
```
```

The new array, test , contains the newly sorted data elements of the original array, but the index values are now changed to numerical values, indicating the proper sort order.
