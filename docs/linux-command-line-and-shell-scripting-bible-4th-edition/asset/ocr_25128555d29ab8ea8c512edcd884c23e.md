# TIP

If you run the Hourly_Archive.sh script during the day, when the hour is in single digits, your archive file’s name will have only three digits. For example, if you run the script at 1:15 a.m., the archive file’s name is archive115.tar.gz. If you prefer to always have four digits in the archive filename, modify the script line, TIME=$(date +%k%M) to TIME=$(date +%k%0M) . By adding a zero (0) after the %, any single-digit hours are padded to two digits with a leading zero. Thus, archive115.tar.gz is instead named archive0115.tar.gz.
