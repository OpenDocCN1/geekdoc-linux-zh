# **TABLE 5-1 The bash Command-Line Options**

| Option | Description |
|---|---|
| -c string | Reads commands from *string* and processes them |
| -i | Starts an interactive shell, allowing input from the user |
| -1 | Acts as if invoked as a login shell |
