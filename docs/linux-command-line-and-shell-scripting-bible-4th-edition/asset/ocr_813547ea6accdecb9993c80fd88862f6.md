# **FIGURE 20-1** Matching data against a regular expression pattern

The asterisk wildcard character allows you to list only files that match a certain criterion. For example:

```
`
$ ls -al da*\n-rw-r--r-- 1 rich rich 45 Nov 26 12:42 data\n-rw-r--r-- 1 rich rich 25 Dec 4 12:40\ndata.tst\n-rw-r--r-- 1 rich rich 180 Nov 26 12:42 data1\n-rw-r--r-- 1 rich rich 45 Nov 26 12:44 data2\n-rw-r--r-- 1 rich rich 73 Nov 27 12:31 data3\n-rw-r--r-- 1 rich rich 79 Nov 28 14:01 data4\n-rw-r--r-- 1 rich rich 187 Dec 4 09:45\ndatest\n$`

```

The da\* parameter instructs the ls command to list only the files whose name starts with “da.” There can be any number of characters after the “da” in the filename (including none). The ls command reads the information regarding all the files in the directory but displays only the ones that match the wildcard character.
