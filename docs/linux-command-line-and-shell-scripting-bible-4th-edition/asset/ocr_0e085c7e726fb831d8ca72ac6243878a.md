# ## Using the GNOME Terminal Emulator

GNOME Terminal is the GNOME Shell desktop environment's default terminal emulator. Many distributions, such as Red Hat Enterprise Linux (RHEL), CentOS, and Ubuntu, use the GNOME Shell desktop environment by default, and therefore use GNOME Terminal by default.
