
从数据流中获取，然后使用 `g` 命令在所有行的后面插入新的空行。要删除现有的空行，我们只需要使用与匹配空行的模式一起配合的 `d` 命令：

```
/^$/d
```

该模式使用了行首标签（脱字符）和行尾标签（美元符号）。将此模式添加到脚本中即可产生期望的结果：

```
$ sed '/^$/d ; $!G' data6.txt
Line one.
Line two.
Line three.
Line four.
$
```

完美！它完全按预期工作。

## 为文件中的行编号

第 19 章向你展示了如何使用等号显示数据流中各行的行号：

```
$ sed '=' data2.txt
1
Header Line
2
First Data Line
3
Second Data Line
4
End of Data Lines
$
```

这在阅读上可能有点别扭，因为行号位于数据流中实际行的上方。一个更好的解决方案是将行号放在与文本相同的行上。

既然你已经看到了如何使用 `n` 命令组合行，那么利用该信息在 `sed` 编辑器脚本中应该不会太难。然而，这个实用技巧的窍门在于，你不能将这两个命令放在同一个脚本中。

在获得等号命令的输出后，你可以将输出通过管道传递给另一个使用 `n` 命令将两行组合在一起的 `sed` 编辑器脚本。你还需要使用替换（`s`）命令将换行符替换为空格或制表符。以下是最终解决方案的样子：

```
$ sed '=' data2.txt | sed 'N; s/\n/ /'
1 Header Line
2 First Data Line
3 Second Data Line
4 End of Data Lines
$
```

现在看起来好多了。这是一个非常实用的小工具，当你正在处理需要在错误消息中查看行号的程序时，它非常有用。

也有一些 Bash shell 命令可以添加行号。但是，它们会添加一些额外的（可能不需要的）间距：

```
$ nl data2.txt
    1  Header Line
    2  First Data Line
    3  Second Data Line
    4  End of Data Lines
$
$ cat -n data2.txt
    1  Header Line
    2  First Data Line
    3  Second Data Line
    4  End of Data Lines
$
$ nl data2.txt | sed 's/    ///; s/\t/ /'
1 Header Line
2 First Data Line
3 Second Data Line
4 End of Data Lines
$
```

`sed` 编辑器脚本处理输出时没有任何额外的间距。但如果你想使用这些实用工具，`sed` 可以帮你去除任何不需要的间距！

## 打印最后几行

到目前为止，我们已经介绍了如何使用 `p` 命令打印数据流中的所有行或仅匹配特定模式的行。如果你只需要处理长列表（例如日志文件）的最后几行怎么办？

美元符号代表数据流的最后一行，因此显示最后一行很容易：

```
$ sed -n '$p' data2.txt
End of Data Lines
$
```

现在，如何使用美元符号来显示数据流末尾的指定行数？答案是创建一个*滚动窗口*。

滚动窗口是一种常见的方法，通过组合使用 `n` 命令来检查模式空间中的文本行块。`n` 命令将下一行文本附加到模式空间中已有的文本后面。当你在模式空间中拥有 10 行文本块后，你可以检查是否处于数据流的末尾，使用美元符号进行判断。如果你不在末尾，请继续将更多行添加到模式空间中，同时移除原始行（记得 `d` 命令，它删除模式空间中的第一行）。

通过循环执行 `n` 和 `d` 命令，你将新行添加到模式空间中的行块中，同时移除旧行。分支（`b`）命令非常适合这个循环。要结束循环，只需识别最后一行并使用 `q` 命令退出。

以下是最终的 `sed` 编辑器脚本：

```
$ cat data7.txt
Line1
Line2
Line3
Line4
Line5
Line6
Line7
Line8
Line9
Line10
Line11
Line12
Line13
Line14
Line15
$
$ sed '{
> :start
> $q ; N ; 11,$D
> b start
> }' data7.txt
Line6
Line7
Line8
Line9
Line10
Line11
Line12
Line13
Line14
Line15
$
```

脚本首先检查该行是否是数据流中的最后一行。如果是，退出（`q`）命令将停止循环。`N` 命令将下一行附加到模式空间中的当前行。`11,$D` 命令在当前行在第 10 行之后时删除模式空间中的第一行。这在模式空间中创建了滑动窗口效果。因此，`sed` 程序脚本仅显示 `data7.txt` 文件的最后 10 行。

## 删除行

`sed` 编辑器的另一个实用功能是移除数据流中不需要的空行。移除数据流中的所有空行很容易，但有选择性地移除空行需要一点巧思。本节向你展示了三个快速的 `sed` 编辑器脚本，你可以使用它们来帮助用户从数据中移除不需要的空行。

### 删除连续的空行

当数据文件中出现额外的空行时，这可能会带来麻烦。通常你有一个包含空行的数据文件，但有时某行数据缺失会产生过多的空行（正如你之前在全间距示例中看到的那样）。

移除连续空行的最简单方法是使用范围地址检查数据流。在**第 19 章**中，我们介绍了如何在地址中使用范围，包括如何在地址范围中整合模式。`sed` 编辑器对指定地址范围内匹配的所有行执行命令。

移除连续空行的关键是在地址范围中包含一个非空行和一个空行。如果 `sed` 编辑器遇到这个范围，它不应该删除该行。然而，对于不匹配该范围（两个或更多连续空行）的行，它应该删除这些行。

以下是执行此操作的脚本：

```
/,/^$/!d
```

该范围从 `/./` 到 `/^$/`。范围中的起始地址匹配包含至少一个字符的任何行。范围中的结束地址匹配空行。在此范围内的行不会被删除。

以下是脚本的运行效果：

```
$ cat data8.txt
Line one.

Line two.

Line three.

Line four.
$ sed '/,/^$/!d' data8.txt
Line one.

Line two.

Line three.

Line four.
$
```

无论文件中数据行之间出现多少个空行，输出都只在行之间放置一个空行。

### 删除开头的空行

当数据文件在开头包含多个空行时也很麻烦。通常当你试图将数据从文本文件导入数据库时，空行会创建空条目，从而扰乱使用该数据的任何计算。

从数据流顶部移除空行并非困难的任务。以下是实现此功能的脚本：

```
///,$!d
```

该脚本使用地址范围来确定哪些行被删除。该范围从包含字符的行开始，一直持续到数据流的末尾。在此范围内的任何行都不会从输出中删除。这意味着在第一个包含字符的行之前的任何行都会被删除。

看看这个简单脚本的运行效果：

```
$ cat data9.txt
Line one.

Line two.

Line three.

Line four.

$ sed '///,$!d' data9.txt
Line one.

Line two.

Line three.

Line four.
```

测试文件在数据行之前包含两个空行。脚本成功删除了开头的两个空行，同时保留数据内部的空行不变。

### 删除末尾的空行

不幸的是，删除末尾的空行并不像删除开头的空行那么简单。就像打印数据流的末尾一样，删除数据流末尾的空行需要一点巧思和循环。

在我们开始讨论之前，让我们看看脚本长什么样：

```
sed '{
:start
/^\n*$/{$d; N; b start }
}'
```

乍一看，这可能会让你觉得有点奇怪。注意在普通的脚本大括号内部还有大括号。这允许你在整体命令脚本中将命令组合在一起。这组命令应用于指定的地址模式。该地址模式匹配仅包含换行符的任何行。当找到时，如果是最后一行，`d` 命令将其删除。如果不是最后一行，`N` 命令将下一行附加到它，并且分支（`b`）命令循环回到开头重新开始。

以下是脚本的运行效果：

```
$ cat data10.txt
Line one.
Line two.

$
$ sed '{
> :start
> /^\n*$/{$d; N; b start}
> }' data10.txt
Line one.
Line two.
$
```

脚本成功从末尾移除了空行。
