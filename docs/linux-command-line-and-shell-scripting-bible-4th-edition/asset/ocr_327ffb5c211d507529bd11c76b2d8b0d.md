# NOTE

> Your Linux desktop environment may have an older or newer version of gedit than the one shown in these figures. In this case, your gedit text editor could have diverse options or even the same options, but they are available in slightly different menu locations. Consult your distribution's gedit Help menu for more assistance.

The Side Panel in gedit provides functionality similar to the Documents List in Kate. Access this feature by clicking the menu hamburger icon and then choosing View. When the View submenu appears, click the box next to Side Panel. These actions result in something similar to Figure 10-17.
