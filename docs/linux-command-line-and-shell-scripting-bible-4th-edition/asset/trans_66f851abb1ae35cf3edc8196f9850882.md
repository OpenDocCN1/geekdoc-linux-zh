内置命令比外部命令提供更高的性能，但添加到 shell 的内置命令越多，消耗的内存就越多，其中可能包含你永远用不到的命令。Bash shell 还包含提供扩展 shell 功能的外部命令。以下内容将在下一节中讨论。
