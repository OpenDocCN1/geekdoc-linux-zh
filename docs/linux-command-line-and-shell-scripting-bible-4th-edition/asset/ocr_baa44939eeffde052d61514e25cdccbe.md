Plugins that are enabled show a check mark in the check box next to their name. Enabling a plugin does not start it. If you want to use, for example, the Embedded Terminal, you must enable it in the Preferences tab first. After that, you can access the plugin by clicking the menu hamburger icon and choosing View, and when the View submenu appears, clicking the box next to Bottom Panel to open the Embedded Terminal, as shown in Figure 10-21.
