# ## Looking at Multiline Commands

When using the basic $sed$ editor commands, you may have noticed a limitation. All the $sed$ editor commands perform functions on a single line of data. As the $sed$ editor reads a data stream, it divides the data into lines based on the presence of newline characters. The $sed$ editor handles the data lines one at a time, processing the defined script commands on the data line and then moving on to the next line and repeating the processing.
