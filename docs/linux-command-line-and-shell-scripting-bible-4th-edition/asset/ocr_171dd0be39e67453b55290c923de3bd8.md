$ dialog --textbox /etc/passwd 15 45

You can use the arrow keys to scroll left and right, as well as up and down in the text file. The bottom line in the window shows the location percentage within the file that you're viewing. The textbox widget contains only a single Exit button, which should be selected to exit the widget.

# The menu widget

The menu widget allows you to create a window version of the text menu we created earlier in this chapter. You simply provide a selection tag and the text for each item:

```
$ dialog --menu "Sys Admin Menu" 20 30 10 1 "Display disk
    2 "Display users" 3 "Display memory usage" 4 "Exit" 2>
```
