```
done
```

You supply the series of values used in the iterations in the *list* parameter. You can specify the values in the list in several ways. In each iteration, the variable *var* contains the current value in the list. The first iteration uses the first item in the list, the second iteration the second item, and so on, until all the items in the list have been used. The *commands* entered between the *do* and *done* statements can be one or more standard Bash shell commands. Within the *commands*, the $var variable contains the current list item value for the iteration.

We mentioned that there are several ways to specify the values in the list. The following sections show the various ways.

# Reading values in a list

The most basic use of the for command is to iterate through a list of values defined within the for command itself:

```
$ cat test1
#!/bin/bash
# basic for command

for test in Alabama Alaska Arizona Arkansas California Colorado
do
    echo The next state is $test
done
$ ./test1
The next state is Alabama
The next state is Alaska
The next state is Arizona
The next state is Arkansas
The next state is California
```
