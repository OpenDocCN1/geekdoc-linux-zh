After you have the git package installed on your system, setting up your Git environment for a new script writing project involves four basic steps:

+   1. Create a working directory.
+   2. Initialize the `.git/` directory.
+   3. Set up the local repository options.
+   4. Establish your remote repository location.

To begin the process, create a working directory. A subdirectory in your local home folder will suffice:

```
$ **mkdir MWWard**
$
$ **cd MWWard/**
$
$ **pwd**
/home/christine/MWWard
$
```

A simple subdirectory `MWWard` was created for the script writing project. After the working directory is created, use the `cd` command to move your present working directory into it.
