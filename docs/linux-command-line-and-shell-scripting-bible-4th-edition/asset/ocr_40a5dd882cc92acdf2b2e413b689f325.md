# Using file comparisons

The last category of test comparisons includes quite possibly the most powerful and most used comparisons in shell scripting. This category allows you to test the status of files and directories on the Linux filesystem. Table 12-3 lists these comparisons.

# TABLE 12-3 The test File Comparisons

| Comparison | Description |
| :--- | :--- |

| -r file | Checks if file exists and is readable. |
| -s file | Checks if file exists and is not empty. |
