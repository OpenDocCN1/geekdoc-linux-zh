```
$ tail log_file
line6

```

You can change the number of lines shown using tail by including the -n parameter. In this example, only the last two lines of the file are displayed, by adding -n 2 to the tail command:

```
$ tail -n 2 log_file
line14
Last Line - line15
$
```
