NOTE
If your shell CLI prompt does not show your shell session's current location, then it has not been configured to do so. Chapter 6 discusses CLI prompt configuration, if you desire modifications to your CLI prompt.

If your prompt has not been configured to show the shell session's current absolute directory location, then you can display the location via a shell command. The pwd command displays the shell session's current directory location, which is called the present working directory or current working directory. An example of using the pwd command is shown here:

```
[christine@localhost bin]$ pwd
/usr/bin
[christine@localhost bin]$ 
```

TIP
It is a good habit to use the pwd command whenever you change to a new present working directory. Because many shell commands operate on the present working directory, you always want to make sure you are in the correct directory before issuing a command.

You can move to any level within the entire Linux virtual directory structure from any level using the absolute directory reference:

```
[christine@localhost bin]$ cd /var/log
[christine@localhost log]$ pwd
```
