It is important to use the correct command name in order to properly launch the GNOME terminal emulator, so type **gnome-terminal** in the Command field, as shown in *Figure 2-9*. When you are all done setting up your new shortcut, click the Add button in the window. Now you can quickly launch the GNOME Terminal by just using the keystroke combination you specified.

Several configuration options are provided by menus and shortcut keys in the application, which you can apply after you get the GNOME terminal emulation started. Understanding these options can enhance your GNOME Terminal CLI experience.
