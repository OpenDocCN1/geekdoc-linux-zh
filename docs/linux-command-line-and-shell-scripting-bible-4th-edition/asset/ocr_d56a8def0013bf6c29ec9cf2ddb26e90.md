On many distributions, the first time you launch the GNOME Terminal application, its terminal emulator icon will appear in your GNOME Shell Favorites bar. Hovering over the icon with your mouse will show the terminal emulator's name, as shown in **Figure 2-7**.

![](bbox=[0.12, 0.19, 0.87, 0.62])

**FIGURE 2-7** GNOME Terminal icon in the Favorites bar

If for some reason the icon does not show up in your Favorites bar, you can set up keyboard shortcut to launch it. This approach is handy for those who don't care for using a mouse, and it allows faster access to the CLI.

**TIP**  
GNOME Shell on the Ubuntu distribution already has a keystroke shortcut for opening the GNOME terminal
