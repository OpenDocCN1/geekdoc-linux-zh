# TIP

You can designate more than one PV during the VG creation process. If you need to add PVs to a VG at a later time, use the vgextend command.

Common practice names the first VG vg00, and the next one vg01, and so on. However, it’s your choice what to name your volume group. Because many distributions set up LVM during installation for the virtual directory structure’s root (/, it’s a good idea to check for any current VGs on your system using the vgdisplay command:

```
$ sudo vgdisplay
--- Volume group ---
VG Name c1
System ID
Format lvm2
[...]
$
```

Notice in the preceding example that a VG named c1 is already set up. Thus, we’re safe to use the vg00 name for our first volume group:

```
$ sudo vgcreate vg00 /dev/sdc1 /dev/sdd1
Volume group "vg00" successfully created
$
```

In the preceding example, only two of our PVs were used to create VG vg00: /dev/sdc1 and /dev/sdd1. Now that our VG storage pool contains at least one PV, we can create an LV.

# Create an LV

To create a logical volume, use the lvcreate command. The resulting storage volume’s size is set using the -L option, which uses space from the designated VG storage pool:

```
$ sudo lvcreate -L 1g -v vg00
[sudo] password for christine:
Archiving volume group "vg00" metadata (seqno 1).
Creating logical volume lvol0
```
