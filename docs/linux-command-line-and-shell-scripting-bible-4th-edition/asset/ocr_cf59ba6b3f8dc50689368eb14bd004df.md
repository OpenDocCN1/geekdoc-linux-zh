```
$ dialog --title "Please answer" --yesno "Is this thing on?"
10 20
$ echo $?
1
$ 
```

This code produces the widget shown in Figure 18-3. The exit status of the dialog command is set depending on which button the user selects. If the No button is clicked, the exit status is 1, and if the Yes button is clicked, the exit status is 0.
