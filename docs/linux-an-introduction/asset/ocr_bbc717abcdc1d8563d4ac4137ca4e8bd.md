# PROGRAMS:

+   ### GRAPHICS
+   *   One of the most highly regarded applications available with GNOME is The GIMP (The GNU

Image Manipulation Program). This sophisticated image-editing suite was created as part of a student project in 1995. It is a freely distributed piece of software that is appropriate for image processing tasks such as photo retouching, image composition, and image creation.

+   *   Before you can use The GIMP, you need to install it on your PC. If you follow the link from the Graphics menu, the installation process will begin.

![](bbox=[0.35, 0.28, 0.98, 0.45])

+   *   The installer will lead you through a series of configuration screens until the end of the process has been reached.
+   *   Once installed, you will find that The Gimp has many capabilities. It can be used as a simple paint program, a professional-level photo retouching program, an online batch processing system, an image renderer, and a tool that can be used to convert image formats.

# Personal GIMP Directory

![](bbox=[0.35, 0.55, 0.5, 0.68])

For a proper GIMP installation, a subdirectory named /gimp-1.1... needs to be on your system. This subdirectory will contain a number of files and subdirectories that help GIMP know your system. For more information about this subject, see the online Help manual.

# Monitor Resolution

To display images in their natural size, GIMP needs to know your monitor's resolution. GIMP can obtain this information from the X window system. However, usually this does not give useful values.
