# A MULTIMEDIA PLAYER

+   • XMMS stands for X Multimedia System and is a multimedia player for Unix systems, which is more sophisticated than either of the players mentioned. It can play media files such as MP3, MOD, WAV and OGM.

+   • The system offers a graphic equalizer, playlist editor, and a wealth of buttons, sliders, and configurable extras.

+   • Right-click on XMMS and select Options to bring up the Preferences dialog box.

+   • The Preferences dialog box enables you to install and configure a very wide range of plug-ins relating to audio and visual effects.
