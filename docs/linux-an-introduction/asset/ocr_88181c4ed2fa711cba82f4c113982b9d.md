# **DESKTOP:
WINDOW MANAGERS**

• You can add window managers by selecting that option in the Control Center, and clicking the

Add button in the top-right corner. In the Add New Window Manager dialog box, enter the name, the commands, and the paths required for launching the

new window manager with its configuration tool.
• To switch Window Managers, select the required name from the list and click the “Try” button.

![](bbox=[0.05, 0.29, 0.95, 0.66])

+   - An Information panel tells you that your current session needs to be saved, and how to do it, either now or later.
+   - You are now switched to the new window manager.
