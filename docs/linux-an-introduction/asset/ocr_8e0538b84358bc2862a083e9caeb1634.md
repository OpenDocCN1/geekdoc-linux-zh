# SYSTEM CUSTOMIZING

With the GNOME Control Center you can configure many
aspects of your desktop and your system – from the desktop
background to icons that occupy it.

# THE GNOME CONTROL CENTER

Beyond configuring your desktop and
system, you can personalize the smallest
features of the windows and menus that
you work with by using a collection of
tools within Linux, known as “capplets,”
which stands for “Control Center applets.”

# ACCESSING THE
CONTROL CENTER

+   • Most of the customiz-
+   ation that you are likely
+   to carry out is done
+   through the GNOME
+   Control Center.
+   • There are three ways to
+   access the Control Center:
+   1 Via the Settings menu.
+   2 Via the GNOME
+   Configuration tool.
+   3 Via a GNOME Control
+   Center option on the
+   submenu of the Settings
+   menu. From this submenu
+   you can access a number of
+   configuration options.
