# SETTINGS

The Settings menu offers many shortcuts to configuration tools, which you can also reach by a number of other routes.

![](bbox=[0.35, 0.08, 0.97, 0.27])

+   - Most of the common settings that individual users can change and personalize, such as screen savers, background wallpaper, and system sounds, are accessible via the Settings menu.

This example shows the screensaver settings window that lists and previews the dozens of screensavers available with a standard installation of GNOME. The screensavers can be previewed and customized by clicking the button below the Screen Saver selection box and choosing from the available options.
