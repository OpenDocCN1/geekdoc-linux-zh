# UNMOUNTING
A DISK DRIVE

e
When you remove the floppy disk and insert another, you will not immediately see the contents of the new floppy disk. With other operating systems, you usually have to

use a command to rescan the contents of the disk drive. With GNOME, however, you always need to select Unmount device before removing a floppy disk, and then mount the new disk. If you simply

rescan the drive using the

appropriate File Manager button without unmounting/mounting, you will only see the contents of the first floppy disk. If you physically remove a disk before you have unmounted it, you risk losing the data on it.
