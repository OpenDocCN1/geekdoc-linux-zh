
# PROGRAMS: GRAPHICS

- One of the most highly regarded applications available with GNOME is The GIMP (The GNU Image Manipulation Program). This sophisticated image-editing suite was created as part of a student project in 1995. It is a freely distributed piece of software that is appropriate for image processing tasks such as photo retouching, image composition, and image creation.
- Before you can use The GIMP, you need to install it on your PC. If you follow the link from the Graphics menu, the installation process will begin.

![](img/773dce76f7b88c1faa45d71937dc4026_37_0.png)

- The installer will lead you through a series of configuration screens until the end of the process has been reached.
- Once installed, you will find that The GIMP has many capabilities. It can be used as a simple paint program, a professional-level photo retouching program, an online batch processing system, an image renderer, and a tool that can be used to convert image formats.

## Personal GIMP Directory

![](img/773dce76f7b88c1faa45d71937dc4026_37_1.png)

For a proper GIMP installation, a subdirectory named /gimp-1.1... needs to be on your system. This subdirectory will contain a number of files and subdirectories that help GIMP know your system. For more information about this subject, see the online Help manual.

## Monitor Resolution

To display images in their natural size, GIMP needs to know your monitor's resolution. GIMP can obtain this information from the X window system. However, usually this does not give useful values.

The GIMP's features include paint tools such as a paintbrush, airbrush, text tools, clone, blur, and sharpen. You can also transform images with rotation, scaling, flipping, and shearing, and save files in many common formats.

# THE FILE MANAGER

Managing files in GNOME has much in common with the Windows and Mac environments, but some features will be more familiar to those with UNIX experience.

## USING THE FILE MANAGER

This chapter looks at how to select, move, copy, and delete files and directories using the GNOME File Manager. It also looks at the differences between GNOME and the Windows and Mac interfaces in accessing the floppy disk and CD-ROM drives.

### WORKING FROM HOME

- When you create and save a new file as user rather than superuser (i.e., root), by default the file is placed in a subdirectory of the Home directory named for your user name. In this example, the user's name is alba, so the subdirectory has the pathname: /home/alba.
- To open this directory at any time, double-click on the Home directory icon on the GNOME desktop.
- To open the File Manager window, choose File Manager from the Programs menu on the GNOME panel.

![](img/773dce76f7b88c1faa45d71937dc4026_43_0.png)

## FILE MANAGER KEY

**Left-hand side**
The left-hand side of the window displays directories and subdirectories. The contents of the highlighted directory appear in the right-hand side of the window. Click on an + to expand the directory tree and - to contract the directory tree in the left-hand side of the File Manager window.

**Right-hand side**
This side shows the contents of the directory highlighted on the left of the window (i.e., files and subdirectories).

**Location box**
If you want the pathname (directory/subdirectory), type it here and press [Enter] to get directory directly in the File Manager window. If you are connected to the internet, you can type an FTP site address in the Location box. The File Manager will then become an FTP client application.

**Right Toolbar Buttons**
These buttons change the view in the right side. For example, Brief shows only the file or subdirectory name and no other details.

**Left Toolbar Buttons**
These navigation buttons take you to backward through directories in a list, or up to a higher directory from a subdirectory.

**The Rescan Button**
The Rescan button re-displays the contents of the directory currently within the window, reflecting any change to the list of contents that has recently occurred.

**The Home Button**
Clicking the Home button changes the active directory to the *Home* directory.

![](img/773dce76f7b88c1faa45d71937dc4026_44_0.png)

## MOVING AND CREATING

When you create or save a file it will be added to your Home directory by default. Most of the file management that you will need to carry out, such as copying, saving, moving, and deleting files, is likely to center on this directory.

### CREATING A NEW DIRECTORY

- To create a new directory, right-click in the blank part of the File Manager window and click New Directory on the pop-up menu that appears. Then type a name for the new directory in the Create a new Directory dialog box and click on OK.

![](img/773dce76f7b88c1faa45d71937dc4026_45_0.png)

### MOVING FILES AND DIRECTORIES

- To move files and directories within the File Manager, begin by displaying them in the right-hand panel, highlight those you intend to move and drag them from the right-hand side over to the appropriate directory on the left. When the directory is highlighted, release the mouse button and the files will be moved accordingly.

![](img/773dce76f7b88c1faa45d71937dc4026_45_1.png)
