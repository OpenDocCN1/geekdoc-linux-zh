# # THE FILE MANAGER

> Managing files in GNOME has much in common with the Windows and Mac environments, but some features will be more familiar to those with UNIX experience.

# ## USING THE FILE MANAGER

This chapter looks at how to select, move, copy, and delete files and directories using the GNOME File Manager. It also looks at

the differences between GNOME and the Windows and Mac interfaces in accessing the floppy disk and CD-ROM drives.

# ### WORKING FROM HOME

+   * When you create and save a new file as user rather than superuser (i.e., root), by default the file is placed in a subdirectory of the Home directory named for your user name. In this example, the user's name is alba, so the subdirectory has the pathname: /home/alba.
+   * To open this directory at any time, double-click on the Home directory icon on the GNOME desktop.
+   * To open the File Manager window, choose File Manager from on the Programs menu on the GNOME panel.
