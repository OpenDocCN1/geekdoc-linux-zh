# **FILE MANAGER KEY**

**Left-hand side**
The left-hand side of the window displays directories and subdirectories. The contents of the highlighted directory appear in the right-hand side of the window.
Click on an + to expand the directory tree and - to contract the directory tree in the left-hand side of the File Manager window.

**Right-hand side**
This side shows the contents of the directory highlighted on the left of the window (i.e., files and subdirectories).

**Location box**
If you want the pathname (directory/subdirectory), type it here and press [Enter]. To get directory directly in the File Manager window. If you are connected to the internet, you can type an FTP site address in the Location box. The File Manager will then become an FTP client application.

**Right Toolbar Buttons**
These buttons change the view in the right side. For example, Brief shows only the file or subdirectory name and no other details.

**Left Toolbar Buttons**
These navigation buttons take you to backward through directories in a list, or up to a higher directory from a subdirectory.

**The Rescan Button**
The Rescan button re-displays the contents of the directory currently within the window, reflecting any change to the list of contents that has recently occurred.

**The Home Button**
Clicking the Home button changes the active directory to the *Home* directory.
