# GNOME  
PANEL FEATURES

The GNOME panel is the bar that runs along the bottom of the desktop. It is a jumping-off point to apps (mini-applications) that work from the panel, and configuration tools that can be customized by the user who can add their own selection of menus and links to applications and files.

It is also possible to place additional GNOME panels elsewhere on the desktop. The illustration here shows the items supplied with a default installation of the GNOME desktop.
