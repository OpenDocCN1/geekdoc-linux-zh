The number of the arguments of a function is called the arity of the function. It is the combination of the module name (m), the function name (f) and the arity (N) that uniquely identifies a function as m:f/N. As you might remember, you have to export a function in order to be able to use it outside of the module that it belongs to.

The next example shows how to pass functions as arguments to other functions! Type the following at the Erlang shell:

```erlang
1> F=fun(X) -> 2*X end.
#fun(erl_eval.6.52032458)
2> Five = fun(N, Function) -> 5 * Function(N) end.
#fun(erl_eval.12.52032458)
3> Five(18,F).
100
4> F(18).
20
```

Here, you define two anonymous functions, named F() and Five(). The Five() function takes two arguments, which is an integer N and a function Function and multiplies the numeric result of Function(N) with the number 5!

## More information about the Erlang shell

The q() function is the easiest way to exit the Erlang shell, but keep in mind that the q() function quits everything. Erlang is dying. If you are working locally then there is no problem, but if you are working on a remote system you'd better quit by typing Ctrl+C and then Q. The reason is that you may shut down the Erlang runtime on the remote machine when quitting using q()! The built-in line editor offer is a subset of Emacs.

```erlang
-module(userinput).
-export([userinput/0]).

getinput() ->
    I = io:read("Please give (Name, Surname) -> "),
    process_input(I).

process_input({ok, Data}) when is_tuple(Data) ->
    Name = element(1, Data),
    Surname = element(2, Data),
```

## Calculating Fibonacci numbers

You will now learn how to calculate Fibonacci numbers in a different way than the one you saw in the previous issue of Linux User and Developer. The code of the fibo() function, which can be found in fibo1.erl, is the following:

```erlang
fibo(N) when N > 0 -> fibVar(N, 0, 1).

fibVar(0, F1, F2) -> F1.
fibVar(N, F1, F2) -> fibVar(N-1, F2, F1 + F2).
```

The implementation of fibo() in fibo1.erl uses another function that is named fibvar() and takes three arguments instead of just one. However, as fibvar() is only used internally, it does not need to be in the export() list of the module. The only function in the export() list is main().

## Infinite loops

The following Erlang code, when combined with a negative integer as an argument, generates a function that keeps running and never ends:

```erlang
fibo(0) -> 0;
fibo(1) -> 1;
fibo(N) -> fibo(N-1) + fibo(N-2).
```

In other words, you should be very careful when defining the arguments that a function can accept, and put guards where necessary in order to avoid such bugs. A more appropriate and secure definition of fibo() would be the following:

```erlang
fibo(N) when N > 0 -> fibVar(N).
fibvar(0) -> 0;
fibvar(1) -> 1;
fibvar(N) -> fibvar(N-1) + fibvar(N-2).
```
