As you will see, Erlang is not particularly good at dealing with strings. Additionally, it is the job of the developer to check that the input is in the right form and of the desired data type because improper data might create troubles when you attempt to process it.

```
#!/usr/bin/env escript
%% -*- erlang -*-

main([String]) ->
    try
        N = list_to_integer(String),
        io:format("Hello \\r\\n")
    catch
    end.
```

There are other ways to create user input, including reading characters and reading entire lines of text - you will learn more about it in the Erlang tutorial in the next issue.

# Creating Erlang scripts

The escript binary file allows you to create Erlang scripts, which is an attractive capability of Erlang found in most scripting languages. The following Erlang script accepts one command line argument and asks the user for their name, using a simplified version of the code found in userinput.erl

```
1> c(userinput).
{ok,userinput}.
Please give (Name, Surname) -> asd, asd.
There is an error somewhere.
Please give (Name, Surname) -> 'M'halis', 'T'soukalos'!.
Hello 'M'halis' T'soukalos'!
Please give (Name, Surname) -> 12.
A tuple is needed!
Please give (Name, Surname) -> quit.
Bye!
```

Figure 7 shows sample Erlang code that teaches you how to get user input and make sure that you take what you want, which you might find more complicated than expected, especially if you are familiar with other programming languages. Executing userinput.erl generates the following kind of output:

# Figure 7

```
-module(userinput).
-export([userinput/0]).

getinput() ->
    I = io:read("Please give (Name, Surname) -> "),
    process_input(I).

process_input({ok, Data}) when is_tuple(Data) ->
    Name = element(1, Data),
    Surname = element(2, Data),
    io:format("Hello \\r\\n", [Name, Surname]),
    getinput();

process_input({ok, quit}) ->
    io:format("Bye\\n");

process_input({ok, _}) ->
    io:format("A tuple is needed\\n"),
    getinput();

process_input({error, _}) ->
    io:format("There is an error somewhere\\n"),
    getinput().
```
