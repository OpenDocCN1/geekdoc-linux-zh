## Using WordPress with OnlyOffice

With OnlyOffice Docs connected to WordPress, authors are able to insert documents into online posts. **Kesnija Fedoruk** explains how it works.

![](img/f20a68d91e56325c44e9a1405ca1923f_69_0.png)

If one CMS stands out on my shortlist of the most popular content management systems today, WordPress tops my list. It is the world's most popular CMS. It accounts for more than 40% of all websites, and it has around 57,000 plugins that make it even more useful. It is built on PHP and MySQL. It has all the features and capabilities needed to manage and maintain a blog or a simple website, and it can even be used to make an online store. In this article I will talk about one of the popular WordPress plugins I recommend to my clients: OnlyOffice. It allows users to use OnlyOffice Docs with WordPress and insert documents directly into their posts.

### Install the plugin

To install this plugin, visit the site [wordpress.org/plugins/onlyoffice-document-editor](https://wordpress.org/plugins/onlyoffice-document-editor) and click the *Install Now* button. After installation, you will need to activate the plugin and go to its settings. You can also download the plugin from GitHub, install it manually, or use a one-click installer in cPanel.

### Install OnlyOffice Docs

As a next step, you can connect Docs to the site and set up the connection, either using your own server or a cloud service such as OnlyOffice Private Cloud. To do that, you need to install the OnlyOffice Document Server on a server. In order to use OnlyOffice, we need to connect to a server that has the Document Server installed. You can use your own server or connect to a cloud service. There are two options: using the only-cloud option or installing the document server on your own host.

### Adding files

To use files that are already on a server, go to *Settings > Media*. After you open the Media Library, click on the *Upload Files* button. It is possible to add files from your own server, from a cloud service, or from a remote URL. The plugin also allows you to add files using drag and drop.

I recommend using the cloud service if you want to share documents with others. You can share documents with others by using the *Share* button. The link will be automatically generated. You can also share documents using the *PDF* option. It is possible to use the document in the same way as a PDF file.

### Helper for .oxt files

**OfficeOxt** is a Python program that helps install .oxt files into OpenOffice. It supports all major versions of OpenOffice, and it works with both Windows and Linux. It is available from [OfficeOxt](http://www.librewriter.com) (version 2.1 or later).

### Manual installation

The manual installation process is:

1.  **Extract** the .oxt file (which is just a zip file) into a folder
2.  Create a new **extension folder** in your OpenOffice user profile: `~/.openoffice/share/extension` on Linux, or `%APPDATA%\OpenOffice\share\extension` on Windows
3.  Copy the extracted contents into the new folder
4.  Run the command `soffice --install --user-install --norestore` to install the extension

Note: If you use the `--norestore` flag, you can safely run the command from a script. Without it, you must run it from the command line.

## Enhancing data security

The `security` extension allows you to protect your documents by:

-   **Encrypting** them with a password
-   **Adding** a digital signature to verify authenticity
-   **Tracking** changes with a log file
-   **Disabling** printing or copying

## Online reproducible dev environments

Stuart Burns is your guide to Gitpod, a new ‘work from anywhere’ development platform that could revolutionise tech test environments.

![](img/f20a68d91e56325c44e9a1405ca1923f_71_0.png)

**EXPERT**

Gitpod is a cloud development environment in the browser, where you can use any code, including a project’s IDE, terminal, Git tools and other services. It is a new tool that helps you to:

-   create a workspace in seconds
-   collaborate in real time
-   run code in a fully cloud-based environment
-   automate the setup process for new projects

*gitpod.io*

Complex and test environments that require installation into the host. This is a great opportunity to set up a development environment that uses configuration files in order to keep the environment reproducible, but it can take time to set up, and it’s easy to make mistakes. Gitpod solves this problem by providing a cloud-based development environment where you can work on your code in your browser.

Gitpod’s Gitpod IDE has its own Git repository, in which each workspace can be linked to a project. This means that you can work on a project in your browser. The Gitpod IDE is a web app that uses a standard browser. It’s also a full IDE, complete with a terminal, Git tools and more. It uses VS Code extensions, so you can use the same extensions you use in VS Code. The IDE is available in the browser, so you can work on your project from anywhere.

## Set up a running environment with Gitpod

To use Gitpod, you’ll need a GitHub account. Go to the Gitpod website and sign in with your GitHub account. Then, you can create a new workspace by clicking on the ‘+’ button in the top right corner. You can also create a workspace from a GitHub repository. Just paste the URL of the repository into the ‘Open in Gitpod’ button. Gitpod will create a new workspace based on the repository. You can then start working on the code in the Gitpod IDE.
