# ## Using WordPress with OnlyOffice

With OnlyOffice Docs connected to WordPress, authors are able to insert documents into online posts. **Kesnija Fedoruk** explains how it works.

![](bbox=[0.07, 0.28, 0.33, 0.45])

If one CMS stands out on my shortlist of the most popular content management systems today, WordPress tops my list. It is the world's most popular CMS. It accounts for more than 40% of all websites, and it has around 57,000 plugins that make it even more useful. It is built on PHP and MySQL. It has all the features and capabilities needed to manage and maintain a blog or a simple website, and it can even be used to make an online store. In this article I will talk about one of the popular WordPress plugins I recommend to my clients: OnlyOffice. It allows users to use OnlyOffice Docs with WordPress and insert documents directly into their posts.

### Install the plugin

To install this plugin, visit the site [wordpress.org/plugins/onlyoffice-document-editor](https://wordpress.org/plugins/onlyoffice-document-editor) and click the *Install Now* button. After installation, you will need to activate the plugin and go to its settings. You can also download the plugin from GitHub, install it manually, or use a one-click installer in cPanel.

# ### Install OnlyOffice Docs

As a next step, you can connect Docs to the site and set up the connection, either using your own server or a cloud service such as OnlyOffice Private Cloud. To do that, you need to install the OnlyOffice Document Server on a server. In order to use OnlyOffice, we need to connect to a server that has the Document Server installed. You can use your own server or connect to a cloud service. There are two options: using the only-cloud option or installing the document server on your own host.

### Adding files

To use files that are already on a server, go to *Settings > Media*. After you open the Media Library, click on the *Upload Files* button. It is possible to add files from your own server, from a cloud service, or from a remote URL. The plugin also allows you to add files using drag and drop.

I recommend using the cloud service if you want to share documents with others. You can share documents with others by using the *Share* button. The link will be automatically generated. You can also share documents using the *PDF* option. It is possible to use the document in the same way as a PDF file.
