# Build light shows with multi-coloured LEDs

Use WLED firmware and a string of LEDs to create eye-catching light shows to display around your home, with Matthew Holder.

![](bbox=[0.06, 0.31, 0.22, 0.4])

H ere we’re at the beginning of the WLED firmware story. The first release was back in 2016. The library to control the original set of hardware LEDs being controlled was the Adafruit library and the Neopixel software libraries. With microcontroller boards such as the ESP8266 and ESP32, the Arduino community started to develop a better framework. This type of LED was commonly called an RGB LED. The tiny microcontroller was used in 2017 and the two software libraries came into use for multi-coloured LEDs with the ESP32 module (Figure 1). These are available from all the different e-commerce outlets and they have been controlled the same way. I held 1735 LEDs in a large room. The size and number of LEDs in that room was 1735, a good amount for an ESP32 board. The ESP32 has 27 GPIO pins. In total it can control a maximum of 27 individual LED strips using the WLED firmware. The WS2812B LED strips, which I would like to show you, can be controlled through the WS2812B driver, which was used for the original Adafruit Neopixel LEDs. These are small round LEDs, which are usually available in red, green, and blue colours. The ESP8266 NodeMCU can also control LED strips.

The ESP8266 NodeMCU is a WiFi capable board. It can be controlled with a small piece of code. I’ll show you how to use the NodeMCU with the WLED firmware. The NodeMCU has a GPIO 5 pin. This pin can be used to control the WLED driver on the LED strip. The NodeMCU has a 3.3V output. This is the maximum voltage that the NodeMCU can provide to the LED strip. The LED strip requires a 5V power supply. You can use a 5V power supply to power the LED strip. The NodeMCU can be powered from the 5V power supply. The NodeMCU has a GND pin. This pin is used to connect the GND pin of the LED strip to the GND pin of the NodeMCU. The NodeMCU has a TX pin. This pin is used to connect the TX pin of the LED strip to the TX pin of the NodeMCU. The NodeMCU has a RX pin. This pin is used to connect the RX pin of the LED strip to the RX pin of the NodeMCU.
