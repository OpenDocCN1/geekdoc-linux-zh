**G**imp is excellent for online editing images, but its batch-editing features are largely unknown. The power available requires that you know how to script the Gimp’s command-line interface, which can be a tricky call for some. BMP files have a large file size, so it is best to use other file types. GIMP can use other, more compact file types such as PNG, which is a lossless compression format. PNG is a very good choice for most images. TIFF is another good option, as it supports layers and is a lossless format. TIFF is a very good choice for images that need to be edited in other programs. JPEG is a good choice for images that need to be shared online. JPEG is a lossy format, so it can result in a loss of image quality. It is best to use a high quality setting when saving JPEG files.

- 1. From the **File** menu, select **Batch**
- 2. In the **Batch** dialog, click on **New**.
- 3. Type a name for the batch, and select the source folder.
- 4. Click **OK** to create the batch.
- 5. In the **Batch** dialog, click on **Edit**.
- 6. In the **Edit** dialog, select the options for the batch. For example, select **File type** and set it to **PNG**.
- 7. Click **OK** to save the batch.
- 8. In the **Batch** dialog, click on **Run**.
- 9. GIMP will run the batch and create the output files.
- 10. Check the output files to make sure they are correct.
