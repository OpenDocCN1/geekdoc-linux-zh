+   * IN BRIEF
+     * EasyOS is a fully featured but tiny distro, running on an ISO in memory.
+     * Based on a fork of Slackware 14.2.
+     * Intended for older PCs.
+     * No root or admin user, no sudo.
+     * No automatic upgrades.
+     * No systemd, but sysvinit.
