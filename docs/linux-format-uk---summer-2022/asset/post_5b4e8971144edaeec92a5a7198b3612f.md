Choose a program to meet your needs.

The programs in the Roundup this month are free or inexpensive. We'll grant you ample leeway to do everything you need to accomplish, but be aware that all of them will require more discipline than the more feature-laden and expensive apps you've used before. ### File export and import options

Choosing files for a pleasing visual result requires more than one file format.

It can make sense to be wary of a program that is limited to one input or output file format, as we've all come across that in the past when we've been unable to do something in an application that is simply not available. For example, there are times when you want to work in a PDF file. Many PDF editors let you do this in the way you want, but few are free. You'll need to get creative about your file format. The OpenBoard app can load a PNG file, JPEG, or PDF, but only one at a time. The same goes for most of the apps in this roundup.
