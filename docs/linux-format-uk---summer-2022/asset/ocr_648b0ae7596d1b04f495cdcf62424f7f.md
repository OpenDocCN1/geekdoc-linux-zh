```
import RPi.GPIO as GPIO

class Ultrasonic:
  def __init__(self, trig, echo, debug=False):
    self.trig = trig
    self.echo = echo
    self.debug = debug
    GPIO.setup(self.trig, GPIO.OUT, initial=GPIO.LOW)
    GPIO.setup(self.echo, GPIO.IN, initial=GPIO.LOW)
```

The main part of the code deals with the two main states we need to deal with: waiting for a result and waiting to send the pulse to the sensor. The waiting state uses the `time.time()` function to get the current time in seconds and stores this in the `self.t0` variable. When the pulse is sent, the `self.t1` variable is set to the current time. The difference between these two values is the time it took for the pulse to travel to the object and back. As we know, we can calculate the distance by dividing the total time by the speed of sound (343m/s).

```
def wait_for_result(self):
  start = time.time()
  self.t0 = time.time()
  while GPIO.input(self.echo) == False:
    self.t0 = time.time()
    if (time.time() - self.t0) > 0.03:
      print('ERROR - no echo detected')
      return None
  self.t1 = time.time()
  return self.t1 - self.t0
```

Finally, we have the main loop of the program, which continuously reads the distance from the sensor and displays it on the LEDs. The LED display consists of 10 LEDs, where each LED represents a range of 10cm (so a full range of 100cm). The LEDs are controlled by turning them on and off depending on the distance returned by the sensor. We've set up a loop that waits 0.2s between each reading, to give us a nice smooth update rate on the LEDs. # SENSORS WORKING OVERVIEW

Before we look at a few different types of sensors, let's think for a moment about what we actually mean by 'sensor'. The word 'sensor' comes from the Latin *sensus*, which means 'perception' or 'experience'. So basically, a sensor is any device that can be used to detect or measure changes in some physical property of the surrounding environment, such as temperature, pressure, light, humidity, or distance.

As a basic rule, sensors are designed to detect a change in a physical property of the surrounding environment and convert this into a change in some measurable electrical quantity. Sensors are usually passive devices (they don't generate their own power) and are often quite simple in construction. The simplest sensor might just be a wire that gets heated up when an object passes over it, for example. A more complex sensor might be a combination of several different components working together.

For example, an infra-red motion sensor (PIR) usually consists of a pyro-electric sensor, which detects changes in infra-red radiation, and an amplifier circuit that converts the sensor's output into a digital signal that can be used to trigger an alarm or switch on a light. Pyro-electric sensors are based on the fact that many crystals generate an electrical charge when their temperature changes. These crystals are known as pyro-electric materials, and a common example is lithium tantalate. When a source of infra-red radiation (like a person or warm object) moves across the field of view of the pyro-electric sensor, it causes a change in temperature, which in turn generates a small electrical charge in the sensor. This charge is then amplified and used to trigger the circuit's output.

# SENSORS WORKING OVERVIEW

We have many sensor built in, and this includes a distance sensor as well. As we know, our sensors are designed to detect changes in temperature, pressure, humidity, and distance. So the distance sensor works by measuring the time it takes for an ultrasonic pulse to travel to an object and back. This time is then used to calculate the distance to the object. The formula is:

*Distance = (Speed of Sound × Time) / 2*

where the speed of sound is 343m/s in air at 20°C. The reason we divide by 2 is because the pulse travels to the object and back, so the total time includes the time for the pulse to travel both ways.
