## SAVE TIME BY BATCH PROCESSING IMAGES

### 1 Select Files and export format
Choose from Adobe Photoshop and the native Tiff. To select a file you want to batch process, use a file selection dialog. If the default settings are fine, click Next to skip a step.

For advanced settings, click Options (1) to open the File Handling and Naming dialog. In the Source panel, click Save Copies to a Folder (2) and then select an output folder. The selected files can be saved in a variety of formats. In the File Naming box, type the base name to be used for the renamed files (3) and check Use Photoshop Settings (4) to save any color space settings. Click OK.

### 2 Choose your resize options
Click on the second step in the dialog box shown at the top. When batch-processing, you can only select one size for the images in a folder.

Under Image Size select Resample images using (1). Use Resampling to determine your image size (2) and to add or remove pixels to achieve the desired size. Then select the output file format (3) and where to place the images after the batch.

### 3 Adjust levels and transform
You can also add a level adjustment before saving an image. Use Levels to create contrast.

To open Levels, click on the Levels icon (2). In the Levels dialog box, make the changes to your image and save to apply the changes to your batch images.

To add a Transform effect to your batch images, click on the Edit icon (3) and choose the rotation or scaling you require. The changes will be applied to the image in the batch.

### 4 Pick files and process
Once the settings have been saved, it’s time to pick the files you want to batch process. When you’ve selected the folder containing your files, click Start (1). This will process the batch and create your new files.

Once your images have been batch-processed, you can use them for your web or print projects. Use the output files in the folder you specified and you’re ready to go.

## RISC OS

From: Richard Birt

### Relive the classic ARM-based RISC OS

RISC OS is an operating system with a fascinating history that dates back decades. Michael Reed looks it out

![](img/f20a68d91e56325c44e9a1405ca1923f_61_0.png)

![](img/f20a68d91e56325c44e9a1405ca1923f_61_1.png)

Back in 1987 RISC Computer Systems manufactured 40-bit workstations running operating systems that it called RISC Operating System (ROS). A few years later the team that developed it restructured and became Acorn and, a few years after, its successor Acorn RISC OS. Some of that design – for example a memory management unit that permitted 255 programs to run side by side and the possibility to save or delete them individually – lives on in the current operating system. If you're unfamiliar with RISC OS and want to find out more about its background and the people involved, see the online article *From ARM to modern RISC: the history of RISC OS* that you'll find linked in the Resources section. It's a fascinating history that includes some excellent photographs of the original 40-bit RISC OS machines. The original OS is open source and runs on ARM and x86 processors. It's even possible to run it on a Raspberry Pi using the PiOS emulator.

## EXPLORE THE RISC OS INTERFACE

![](img/f20a68d91e56325c44e9a1405ca1923f_61_2.png)

- 1. **Work areas** – RISC OS's work areas are divided into two groups. A Work Area is an area where a task works, a Task Area is an area where a task works. Work areas are used by tasks, task areas by programs. Work areas can be moved around.
- 2. **Toolbars** – The main toolbar has buttons for various functions, some of which, like the 'About' button, are hidden by default.
- 3. **Icons** – Icons are used to represent files, directories, and applications.
- 4. **Task menu** – This opens from the taskbar. It allows you to switch between running tasks. The main task is the one that has focus.
- 5. **Desktop background** – You can change the desktop background using the 'Appearance' setting.
- 6. **System settings** – These are accessed from the menu and allow you to configure various aspects of the system.
- 7. **Applications menu** – This opens from the taskbar. It allows you to launch applications.
- 8. **User interface** – This allows you to switch between the desktop and windowed mode.
- 9. **Fonts** – RISC OS uses a range of fonts, from the standard to custom fonts.
- 10. **Colour settings** – These allow you to change the colour scheme of the system.
- 11. **Icon bar** – This allows you to add icons to the taskbar for quick access.
- 12. **System menu** – This allows you to access system settings and utilities.
- 13. **Help** – This provides information about RISC OS and its features.
- 14. **System information** – This displays information about the system, such as the version of RISC OS and the amount of memory.
