# # Distro watch
What's down the side of the free software sofa?

# ## PORTABLE 5.0

A new version of Gcompris is available to download. Available in multiple variants, the 'Portables' build now contains the whole Gcompris 1.35 suite, as well as updates for the 'new' Gcompris Screenwriter/Translator programs. The latest version is also a Debian 3.2 Sarge update, and it's a chance to install a whole range of extras. The latest Gcompris Portable release can be found at [gcompris.tuxfamily.org](gcompris.tuxfamily.org).

# ## CONDORS OS 1.0

The latest release of Ccondors Linux is a new variant, Condor 0.2. Based on Debian Lenny, it's announced at [condors.co.uk](condors.co.uk), which is the official website of the project. The announcement states that this Ccondors distribution is the first Ccondors distribution to have Xfce 4.4 as its standard desktop environment, and it's now available in the beta release and new version in early September/October 2009 for those individuals.

# ## ENDEAVOURDESK 22.6

The latest release of EndeavourOS is the latest 'rolling' version, with a newer version, called 'rolling' (stable). The Gnome DE desktop environment has been introduced on the latest version of the distribution. This version can also be seen on the KVM virtualisation of the Endeavour distribution. The new version of the distribution also offers a choice of a few more desktop environments such as the Xfce Desktop Edition, which can also be used on a virtual server.

# ## TRUENAS 22.02.2

Our latest Truenas 11.2-RELEASE 22.02.2 is the latest update of this popular storage stack. It's based on FreeNAS 11.2-RELEASE and is also available as a virtual machine on Oracle's cloud hosting service, as well as in the form of a bare-metal install. For more information, see the Truenas cloud hosting on the Truenas cloud hosting service, which you can use to setup a bare metal install, or a VM install in a cloud or locally.
