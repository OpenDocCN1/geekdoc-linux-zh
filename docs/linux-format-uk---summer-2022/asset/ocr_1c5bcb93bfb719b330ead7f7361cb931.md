Before getting started, we should briefly explain to those unfamiliar with Linux that you can plug your gamepad into a USB port, run `sudo dmesg | grep -i gamepad` (or just run `ls /dev/input` to list input devices) and you should see `/dev/input/js0` (or similar) in the output. That's your gamepad! If you don't see it, your gamepad might be using a non-standard protocol (like X-Input), or your device isn't supported. In the latter case you might need a proprietary driver, or to use a different gamepad. (The game's not supported on most Linux distros, but the generic X-Input support is built into the kernel. You can find more info at http://www.kernel.org/doc/Documentation/input/gamepad.txt. Note that X-Input gamepads aren't always detected as such - the generic X-Input protocol works for most things). As a first step we can install a small Python library called `pygame` which provides a handy wrapper for SDL. You can install it using your package manager (on Ubuntu: `sudo apt-get install python-pygame`), or pip (`sudo pip install pygame`), or by downloading it from the official site (http://pygame.org). Once installed, you can access gamepads via the `pygame.joystick` module (a handy shortcut for this is `pygame.joystick`).

As a second step, we need to modify the `setup.py` file in the `tetris` package we created last month. We need to add the `pygame` module to the `install_requires` list. This will make pip install `pygame` automatically for us when we install `tetris`.

Finally, once we've got `pygame` installed, we need to modify the `tetris` source code to actually use it. We need to add some import statements at the top of our `tetris.py` file:

```python
import pygame
from pygame.locals import *
```

We also need to modify the `__init__` function to initialise the joystick module:

```python
def __init__(self, display):
    pygame.init()
    self.display = display
    pygame.joystick.init()
    self.joystick = pygame.joystick.Joystick(0)
```

This code initialises the first available joystick. If you have multiple gamepads, you can use `pygame.joystick.get_count()` to find out how many there are, and use the appropriate index in the `Joystick` constructor.
