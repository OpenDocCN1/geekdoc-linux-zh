# The Verdict

Software whiteboards

W When it’s your turn for taking notes, you typically find yourself at the table with a stack of paper and a pad of markers, or hunched over a notebook. Even with today’s technology, that’s not much of a change from the way we started doing decades ago, and that should prompt an important question: What if we stopped going in that direction? Instead of ever better tools to capture, share, and revise the notes we’ve written on our devices, what if we started focusing on whiteboards that allow us to write directly on a screen? Not just any screen—think of a large interactive display that’s wall-mounted and can be written on using special markers or a stylus. That’s the kind of environment where a team can gather and work together in the same room, but also where a student or instructor or doctor can write or draw on a large screen. It’s a powerful concept that has already been put into practice in a number of ways, from classroom setups to hospital rooms to boardrooms. In fact, there are several software applications that turn regular whiteboards into interactive ones, and there are dozens of software-only solutions that allow you to do the same things on a regular computer or tablet. It’s a rich field, but it’s also one that has some very specific requirements that are hard to satisfy. In this review, we’ve looked at four options—two that are software-only and two that require hardware—to see which of the four we’d recommend. But first, we’ve included a quick overview of the best picks. We’ve chosen the two best options for different use cases and included them in our top two.

# ALSO CONSIDER

Lanner. In our overall ranking, we felt that Lanner is a better option, but not by much. It’s still a solid option if you can’t get your hands on our top two choices. As mentioned in our main review, this software lets you write on any surface using a smartphone camera. The catch is that you need to set up an anchor point. If you can’t, you’ll have to use another software solution.

Roomline Board. For a long time, we felt that Lanner and GoWhiteboard were the top two options. However, we’ve since found that Roomline Board is a more cost-effective option that can be used in a wide range of environments. The only downside is that it’s not as easy to set up and use as the other two.
