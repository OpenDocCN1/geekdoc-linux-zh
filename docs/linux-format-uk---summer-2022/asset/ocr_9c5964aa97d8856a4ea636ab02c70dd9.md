For example, if we have a `canvas` element with the ID `tetris-canvas`, we can pass it in using `document.getElementById('tetris-canvas')`.

As our second argument, we can define the **number of columns** that we want to have in our game. This can be anything from 1 to 100, but a typical value is 10. The third argument is the **number of rows** that we want to have in our game. This can also be anything from 1 to 100, but a typical value is 20. The fourth argument is the **scale** of the game. This is the size of the blocks in the game. A typical value is 20, but you can make it as large or small as you like.
