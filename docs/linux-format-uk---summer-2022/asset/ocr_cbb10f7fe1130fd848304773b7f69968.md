# Day-to-day usability

Choose a program to meet your needs.

T he programs in the Roundup this month are free or inexpensive. We'll grant you ample leeway to do everything you need to accomplish, but be aware that all of them will require more discipline than the more feature-laden and expensive apps you've used before. Some options can handle multiple functions; others will give you a very polished result without taking a single step outside their own particular sandbox. The two apps with multiple features, Inkscape and Bluegriffon, both make heavy use of the desktop. You can work on multiple files at once in these apps.

Use Journalt+ to keep an account of your day's events. Set it to record in a 5-minute interval and you can add annotations to each entry. You'll have to use a bit of imagination to come up with a good reason to switch away from your favourite text editor, but just as a place for the odd note, this will work fine for most people.

# File export and import options

Choosing files for a pleasing visual result requires more than one file format.

It can make sense to be wary of a program that is limited to one input or output file format, as we've all come across that in the past when we've been unable to do something in an application that is simply not available. For example, there are times when you want to work in a PDF file. Many PDF editors let you do this in the way you want, but few are free. You'll need to get creative about your file format. The OpenBoard app can load a PNG file, JPEG, or PDF, but only one at a time. The same goes for most of the apps in this roundup.
