Installation
The easiest method to install is via the package manager. Open a terminal and enter `sudo apt-get install gmpg12`. It will install the latest version of GMP. To install a specific version, add the version number to the command. `sudo apt-get install gmpg12=0.8.9-1` will install version 0.8.9. To install the latest version, you can use `sudo apt-get install gmpg12`. For more options, visit the [GMPG12 Website](http://www.gmpg12.de).
