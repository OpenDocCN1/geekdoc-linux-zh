# **Making live presentations**

Use these programs to create a presentation or interactive document.

![](bbox=[0.55, 0.48, 0.95, 0.68])

Having a live presentation, in PowerPoint form, would usually be the go-to choice of developers. But in the next section we show how to create live presentations in a web browser, such as Google Slides or the more powerful and versatile LibreOffice Impress. For many web developers, the web browser is a natural place to do their work. You have a lot of options for how to present: slides, for example. Or even better, a live document. There are a number of options for live documents in a web browser, including the more powerful and versatile LibreOffice Impress.

What about when you're trying to make your presentation more interactive? Well, if you're looking for a more interactive presentation, you might want to look at tools like Prezi or Slidev. These tools allow you to create interactive presentations with a more free-form layout, and you can even add animations and transitions. Or, if you want something even more powerful, you could look at tools like Houdini or TouchDesigner, which allow you to create real-time visual experiences. These tools are often used in the live performance art world, but they can also be used to create interactive web experiences.

Finally, if you want to create a live presentation that can be shared and collaborated on in real-time, you might want to look at tools like Miro or FigJam. These tools allow you to create a shared workspace where you and your audience can collaborate in real-time. This can be a great way to make your presentation more interactive and engaging, and it can also help you to get feedback from your audience in real-time. Or, if you want something even more powerful, you could look at tools like Figma or Sketch, which allow you to create interactive prototypes and design documents.

In conclusion, there are a wide range of options for creating live presentations, from the traditional PowerPoint slide deck to the more interactive and free-form layouts offered by tools like Prezi and Slidev. Or, if you want something even more powerful, you could look at tools like Houdini, TouchDesigner, Miro, FigJam, Figma, or Sketch. These tools can help you to create more engaging and interactive presentations, and they can also help you to get feedback from your audience in real-time. So, whether you're a seasoned presenter or just starting out, there's a tool out there for you. Happy presenting!
