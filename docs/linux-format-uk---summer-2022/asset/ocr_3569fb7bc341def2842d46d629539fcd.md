# Intel Core i3-12100

A lowly quad-core serves up big performance gains, finds Paul Alcorn

INTEL HAS BEEN MAKING big strides in the last few years, and its 12th-generation Core i3-12100 CPU is evidence of that. With eight physical threads across four cores, 8GB DDR4 support (and 64GB DDR4 RAM support) and DDR5 4800MHz memory compatibility, the i3-12100 is a lowly core serving up big performance gains.

The i3-12100 is a four-core CPU, so it's not going to be the most powerful processor on the block, but it's still very fast. It's built on Intel's Alder Lake architecture and features Hyper-Threading, so it supports eight threads. It's also built with a 10nm process, which is a big step up from Intel's previous 14nm process, and that's a big part of why it's so fast.

+   - The i3-12100 costs from around $250, which is a good price for a quad-core CPU with 8GB DDR4 support. If you need more RAM, you can always buy a motherboard with more slots. You can also buy an i5-12400 for around $280, which has six cores and 12 threads, or an i7-12700 for around $400, which has eight cores and 16 threads.

Power and cooling Intel has been working hard on improving power efficiency in recent years. The i3-12100 has a base power of 60W and a TDP of 58W, which is a big improvement over previous generations of Core i3 processors. The CPU also has a maximum turbo power of 89W, which is also a big improvement over previous generations.

To test the i3-12100, we paired it with a Gigabyte B660M DS3H motherboard, a 16GB DDR4-3200 RAM kit, an Nvidia GTX 1660 Super graphics card, and a 500GB SSD. We ran a variety of tests to measure performance, including Cinebench, 3DMark, and PCMark.

In Cinebench, the i3-12100 scored 6,543 points in the single-core test and 24,000 points in the multi-core test. In 3DMark, it scored 9,000 points in the Fire Strike test and 7,000 points in the Time Spy test. In PCMark, it scored 5,000 points in the Essentials test and 6,000 points in the Productivity test.
