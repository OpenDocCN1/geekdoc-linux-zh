# Build a "rubber ducky" device from a Pi Pico

Discover why the classic fake keyboard hacking device is ideal for the Raspberry Pi Pico and Matthew Holder's very particular use of it.

![](bbox=[0.0, 0.35, 0.2, 0.45])

If you're at all aware that the Raspberry Pi Pico can be used as a fake keyboard, you've probably heard of the Rubber Ducky, which lets you write a simple script that's sent to the PC over the USB port. The Pi Pico will then act as a real keyboard, and input that script into any text field.

That's exactly what we're going to build this month. A Rubber Ducky is usually programmed using its own proprietary language called DuckyScript, but it can also be easily written using any other language that supports sending keyboard input, which is what we're going to do using MicroPython.

There are lots of other hardware devices you can buy, and open up your options if you want to build a different fake keyboard project, such as a Rubber Hound, Rubber Fifi, or even a Rubber Duck, but the Pi Pico is a great choice here, with a low cost and a wide range of features.

You can even take it a step further, with our new Pico-compatible, 25-button USB Keyboard, so you can use your Pi Pico as a full keyboard controller, and use it to create more advanced fake keyboard projects, such as a macro keyboard, or even a full computer system.

This project is all about how you can use the Pi Pico's GPIO pins to connect a keyboard, and use the keyboard's key inputs to trigger specific actions.

By connecting the Pi Pico's GPIO pins to a keyboard, we can use the keyboard's key inputs to trigger specific actions on the PC. This can be used for a wide range of applications, such as automating tasks, controlling media playback, or even playing games.

One of the key advantages of using the Pi Pico for this project is its low cost. You can pick up a Pi Pico for under $5, which makes it a great choice for a low-budget project. It also has a low power consumption, which means you can run it for a long time on a single battery.

You can download the complete code for this project from the Raspberry Pi forums, along with detailed instructions on how to set up the project and how to use it. We hope you enjoy building this project, and we look forward to seeing what you create with it!
