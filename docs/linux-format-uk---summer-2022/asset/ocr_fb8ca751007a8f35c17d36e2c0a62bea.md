# # Speak

Version: 1.6.0
Web: http://speak.netwerk

**S**peak is a quirky piece of open-source software that lets you create, and send messages via the Internet. The application supports a number of message types, including text, graphics, audio, files and executable code. The app also includes an internal web browser so you can surf the Internet as well as webchat. While Speak is still a beta product, it is well supported, actively developed, and has a large user base and a healthy support forum, so if you find something buggy, or you’d like a feature, check the forum before filing a bug report.

One of Speak’s main features is that you can keep your chat history with specific people organized in folders. This is a handy feature for keeping notes, as you can keep a folder of your own chat history with a specific person, and even search them. The application also has a number of other features, such as the ability to make notes, and the fact that you can chat in multiple languages.
