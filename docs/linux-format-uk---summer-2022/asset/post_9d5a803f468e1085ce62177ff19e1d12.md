## ENCRYPTION TOOL

### zuluCrypt

Version: 6.01
Website: https://www.zulu-crypt.com/
Mailing-list: info@zulu-crypt.com/

I love the easy-to-use interface to build your encrypted drives, mounted like normal Linux drives in /media, just like an external USB stick. You can choose your encryption level from AES-128 to AES-512, and you can choose between 3DES, Twofish, or Serpent. And the program comes with a user-friendly wizard that will guide you through the whole process. The program is also quite efficient. You can use it to encrypt the whole disk or just individual partitions. The program is available as a binary, source, and RPM. The binary works on any 32-bit or 64-bit Linux system, and the RPM works on any Red Hat-based distro.

The default volume and the encryption keys are stored locally, which is fine for most use cases, but you may want to use a different location. This can be changed in the settings. You can also change the default encryption algorithm and the key size. The default settings are good enough for most users, but power users may want to tweak these. The program is also very secure. It uses strong encryption and has been audited by independent security experts. The program is open source and the source code is available for download. You can also donate to the project if you find it useful.

ZuluCrypt can also be used as a command-line tool. The CLI version has the same features as the GUI version and is available on all major operating systems. The CLI version is perfect for automation and scripting tasks. You can also use it to encrypt files and folders on the fly. ZuluCrypt is a powerful and flexible encryption tool that should be on every user's toolkit.

The ZuluCrypt project is currently maintained by a team of volunteers who are dedicated to providing users with a secure and easy-to-use encryption tool. The project is funded by user donations and the developers are committed to keeping the software free and open source.

## RESOURCE MONITOR

### Bytop

Version: 1.09
Web: https://github.com/arisotek/Bytop

Bytop is written in C, making it very fast and responsive. It is a fork of htop, a terminal-based interactive process viewer for UNIX systems. Bytop is an application that will help you keep a close eye on your system's resources. It can monitor the CPU, RAM, and disk usage in real time.

- It can display system information, such as the total amount of memory, CPU usage, and disk usage.
- It can sort processes by name, CPU usage, or memory usage.
- It can kill processes and change their priority.
- It has a tree view, which shows the process hierarchy.
- It has a user-defined color scheme, which allows you to customize the look of the application.

Bytop is a great alternative to htop for users who want a more customizable and feature-rich process viewer. It is a simple but powerful tool that will help you keep your system running smoothly.

## 09 CODE GENERATOR

### Qrncode

Version: 4.1.1
Web: https://makrshark.org/works/qrncode

Qrncode is a QR code generator that works even offline.

QR codes are the 2D barcodes you're likely to be well familiar with, but you may not realize they can be used for a lot more than just linking to websites. When these tiny black-and-white codes are created, a specific amount of data is encoded into it. This data can be used in a variety of ways, and it's up to the device or app to determine what to do with it. Qrncode is a simple web app that lets you generate custom QR codes in your browser without sending any of the data to a server. It's fast, easy, and the codes it generates are just as functional as any other. The only drawback is that the generated QR codes are limited to a certain number of characters, but for most uses, this is more than enough.

![](img/f20a68d91e56325c44e9a1405ca1923f_85_0.png)

One of the coolest things about Qrncode is its ability to generate QR codes without the need for a stable internet connection, as all the code that generates the codes is right there on the webpage. However, you can also use the QR code to share your location or a specific URL. If you're looking for a simple, fast, and open-source tool to generate QR codes on the go, Qrncode is a perfect choice. It's also worth noting that the app is a single HTML file that runs in your browser, making it easy to download and use offline.

## TEXT EXPANDER

### Espanso

Version: 2.1.5-beta
Web: https://expanso.app

If you're a heavy typist who finds themselves constantly typing out the same phrases, Espanso might just be the tool that saves you a lot of time and effort. It's a text expander that works across all applications on your system, allowing you to create custom snippets that you can trigger with a simple keyword. The best part is that it's open-source and actively maintained, so you can expect regular updates and improvements. Plus, the fact that it works on all major platforms (Windows, macOS, and Linux) makes it a great choice for developers who switch between operating systems.

If you're a developer who spends a lot of time in text editors or writing code, you'll likely be familiar with the concept of code snippets. These are pre-defined blocks of code that you can insert with a single command. Well, Espanso is basically that, but for text and for everything. You can define any kind of snippet, from simple text to complex code, and even insert dynamic values like the current date and time. It's a powerful tool that can save you a lot of time and effort, especially if you're working on a project that requires a lot of repetitive text input. Plus, the fact that it's open-source and actively maintained means that it's constantly being improved and updated with new features.
