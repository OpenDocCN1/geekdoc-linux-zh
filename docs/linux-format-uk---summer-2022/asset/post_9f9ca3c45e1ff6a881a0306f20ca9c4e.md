
## SUDOKU PUZZLE
### nudoku

Version: 2.1.0

**W:** https://github.com/jbuhac/nudoku

**N**udoku is a numeric, logic-based Sudoku game, which can be played in the terminal or on a text-mode shell. It features a graphical display of various fields, the ability to select arbitrary grid sizes of your own, and a built-in feature to select the difficulty of the puzzle. It works on terminals and text modes.

![](img/f20a68d91e56325c44e9a1405ca1923f_86_0.png)

As a feature, it supports both a **normal play**, where you just have to solve the puzzle, and an **expert mode**, where you can select the number of clues to be given, or even select the difficulty of the puzzle.

![](img/f20a68d91e56325c44e9a1405ca1923f_86_1.png)

If you want to **solve** from an existing file, you can do so in the terminal with the **nudoku** command. For example:

```bash
nudoku puzzlefile
```

You **must** also be sure that you **do not have any other sudoku games open** at the same time. This command will print out a puzzle and save it to a file, which you can use later.

Simply, you can also generate a **puzzle from a file**, but only if it's a valid puzzle. For example:

```bash
nudoku -g fromfile puzzle
```

![](img/f20a68d91e56325c44e9a1405ca1923f_86_2.png)

In **normal mode**, you can select the number of clues to be given, or even select the difficulty of the puzzle. For example:

```bash
nudoku -n 9
```

`nudoku -n 9` will set the difficulty to 9, which is the hardest. You can also use `nudoku -n 1` to set the difficulty to 1, which is the easiest.
