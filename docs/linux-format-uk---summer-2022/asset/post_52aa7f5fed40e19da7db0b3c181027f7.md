This is where the shift from 'tool' to 'colleague' begins. You can get started with the default keybindings, but I recommend building a custom workflow that fits your brain. For example, instead of a default <kbd>⌘</kbd>+<kbd>Enter</kbd>, you might want to map a command like **create_new_split** to <kbd>⌘</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd> + a specific key, or better yet, use a command palette (like <kbd>⌘</kbd>+<kbd>Space</kbd>) to find and run any command without memorizing key combinations.

### Build up your muscle memory

The terminal is a tool, and like any tool, it takes time, focus, and reps to master. Right now, you're just using it. Later, you'll be *thinking with it*. The goal is to reach a state of flow where your hands are ahead of your thoughts. You'll start a command with `git st` and before you even think 'status', you've hit <kbd>Enter</kbd>. You'll type `./s` and before you can say 'source', the dotfiles are loaded. This isn't about memorizing keys; it's about building habits.

So, how do we build these habits? We break them down into small, repeatable actions and drill them until they become automatic. This is where **Tmux** comes in, but not just as a window manager. It's a *workflow machine*. By creating and saving 'sessions', you can have a specific layout for a project with all the right panes, logs, and servers ready to go. No more copy-pasting the same commands or manually restoring your workspace after a reboot. Your muscle memory isn't just in your hands; it's in your **setup**.

I've started a Tmux script that sets up my entire dev environment: two file explorers (one for frontend, one for backend), a split pane for Git, a pane for logs, and a pane for my primary code editor. When I open my terminal, I just type `tmux new -s dev` and I'm in my world. It takes 2 seconds. It used to take 10 minutes of setup. This is the difference between a *tool* and a *system*. And it's just the start.

### Let's play

I find that I look for the winning solution from the start. The trick is to not try to do everything at once. Pick *one* of the tools above and master it completely. That's a whole month of work, and it will change how you work forever.

```bash
#!/bin/bash
# A simple script to start my dev environment
echo "Starting dev environment..."

tmux new-session -d -s dev -c ~/projects/frontend
# Add a pane for backend logs
tmux split-window -h -c ~/projects/backend
# Add a pane for git commands
tmux split-window -v -c ~/projects/frontend
# Add a pane for my code editor (e.g., Neovim)
tmux split-window -h -c ~/projects/frontend
echo "Dev environment ready!"
tmux attach-session -t dev
```

### NAVIGATING PHOTOFLARE

![](img/f20a68d91e56325c44e9a1405ca1923f_57_1.png)

1.  **Main toolbar:** This is the main toolbar, which contains all the tools you need to edit your images. It's a bit of a beast, so we recommend taking some time to explore it.
2.  **File menu:** You can access the File menu from here, which allows you to open and save images, as well as access the print and export options.
3.  **Photos:** Use this area to manage the images you have open. You can drag and drop images into this area, or use the File menu to open them.
4.  **Display:** You can use the display options to change the size of the image, or to fit it to the window.
5.  **Framed image:** This is where the image you are working on will appear. You can use the tools on the left to edit the image.
6.  **Tools:** You can use the tools on the left to edit your image. The tools are organised into categories, so you can easily find what you need.
7.  **Layers:** You can use the layers panel to manage the layers of your image. This is a powerful feature, but it can take some time to learn how to use it.
8.  **Crop:** You can use the crop tool to crop your image to a specific size or shape. This is a great tool for creating images for social media or for printing.
9.  **Resize:** You can use the resize tool to change the size of your image. This is a great tool for creating images for the web or for printing.
10. **Color:** You can use the color tools to adjust the color of your image. This includes tools for adjusting the brightness, contrast, and saturation of the image.
