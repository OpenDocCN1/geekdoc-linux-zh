**Getting PhotoFlare**
PhotoFlare is a Windows program, and it
can be downloaded from the developer
site at www.thefluffybunny.com. Once
you've downloaded the installer, run it
and follow the prompts to install the
program. Once installed, you'll find
PhotoFlare in your start menu. When
you launch the program, you'll be
presented with a blank canvas and a
toolbar of tools.

# NAVIGATING PHOTOFLARE

![](bbox=[0.05, 0.51, 0.95, 0.73])

+   1. **Main toolbar:** This is the main toolbar, which contains all the tools you need to edit your images. It's a bit of a beast, so we recommend taking some time to explore it.
+   2. **File menu:** You can access the File menu from here, which allows you to open and save images, as well as access the print and export options.
+   3. **Photos:** Use this area to manage the images you have open. You can drag and drop images into this area, or use the File menu to open them.
+   4. **Display:** You can use the display options to change the size of the image, or to fit it to the window.
+   5. **Framed image:** This is where the image you are working on will appear. You can use the tools on the left to edit the image.
+   6. **Tools:** You can use the tools on the left to edit your image. The tools are organised into categories, so you can easily find what you need.
+   7. **Layers:** You can use the layers panel to manage the layers of your image. This is a powerful feature, but it can take some time to learn how to use it.
+   8. **Crop:** You can use the crop tool to crop your image to a specific size or shape. This is a great tool for creating images for social media or for printing.
+   9. **Resize:** You can use the resize tool to change the size of your image. This is a great tool for creating images for the web or for printing.
+   10. **Color:** You can use the color tools to adjust the color of your image. This includes tools for adjusting the brightness, contrast, and saturation of the image.
