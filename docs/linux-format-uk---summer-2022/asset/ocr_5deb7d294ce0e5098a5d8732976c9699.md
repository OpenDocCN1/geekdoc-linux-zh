The power available requires that you know how to script the Gimp’s command-line interface, which can be a tricky call for some. So let’s take a look into whether the **BMP**—the *Best Mass Processor* for Gimp—can take care of most of this for you.

This is a useful task if you need to process many similar images. For instance, a web designer may need to process a folder of 500 thumbnails or a photographer might have a folder of 1,000 images that need to be batch-renamed. The BMP can do all of these tasks for you, and more.
