# **LOCALE-RELATED ENVIRONMENT VARIABLES**

As we mentioned in the last story, if all you need to do is set a few variables, such as **LANG**, that set the language of the **messages**, you can just type `LANG=en_US`. But most of the time, you are going to need to use the full path to the **locale** data. The full path is determined by the **locale** that is set in the **/etc/locale.conf** file. This file contains the default **locale** settings for the system.

**\*\*\*\* LANG:** The **LANG** variable specifies the language to be used for all categories that have not been explicitly set using an **LC** variable. In addition, it is used to determine the **locale** category for all those categories that have not been explicitly set. This variable is the **parent** of all the **LC** variables. If it is not set, **POSIX** is used.

**\*\*\*\* LC_ALL:** Overrides any variable, **LC_ALL** and **LC_CTYPE**. If **LC_ALL** is set, it overrides all the other **LC** variables.

**\*\*\*\* LC_CTYPE:** Defines the **character** set used to **translate** **byte** values to characters. This **locale** also determines the class of **characters**, such as whether a character is a letter, digit, or punctuation mark.

**\*\*\*\* LC_NUMERIC:** Defines the **decimal** separator and **thousands** separator used in number formatting. This **locale** also determines the **grouping** of digits into thousands.

**\*\*\*\* LC_TIME:** Defines the **date** and **time** formats used in date and time formatting. This **locale** also determines the names of the days of the week and months of the year.

**\*\*\*\* LC_MESSAGES:** Defines the **language** used in **messages**. This **locale** also determines the **collation** order used to sort **strings**.

**\*\*\*\* LC_COLLATE:** Defines the **collation** order used to sort **strings**. This **locale** also determines the **class** of **characters** that are used to sort **strings**.

For **localization**, all **applications** should be **compiled** with **gettext** and the **language** should be determined by the **LC_MESSAGES** **locale**. This will **allow** the **application** to use the **correct** **messages** based on the **language** set in the **locale**.

**\*\*\*\* LC_PAPER:** Defines the **paper** size used for **printing**. This **locale** also determines the **orientation** of the **printed** **page**.

**\*\*\*\* LC_MONETARY:** Defines the **currency** used in **monetary** **formatting**. This **locale** also determines the **symbol** used for the **currency**.

**\*\*\*\* LC_NAME:** Defines the **format** used for **names**. This **locale** also determines the **order** of the **first** and **last** **names**.

**\*\*\*\* LC_ADDRESS:** Defines the **format** used for **addresses**. This **locale** also determines the **order** of the **street**, **city**, and **postal** **code**.

**\*\*\*\* LC_TELEPHONE:** Defines the **format** used for **telephone** **numbers**. This **locale** also determines the **order** of the **area** **code** and **number**.

**\*\*\*\* LC_MEASUREMENT:** Defines the **measurement** **system** used. This **locale** also determines the **unit** used for **measurement**.

**\*\*\*\* LC_IDENTIFICATION:** Defines the **language** used for **identification**. This **locale** also determines the **format** used for **identification**.

The **language** used for **identification** is usually the **same** as the **language** used for **messages**. However, this **locale** can be used to specify a **different** **language** for **identification**.

**\*\*\*\* LC_ALL:** This variable overrides all other **locale** environment variables. If **LC_ALL** is set, it overrides all the other **LC** variables. If it is not set, the **POSIX** **locale** is used.
