AMD FidelityFX Super Resolution goes open source

AMD's performance-enhancing upscaling technology is now open source with version 2.0.

AMD's FidelityFX Super Resolution (FSR) has become an important part of its open-source AMD VLIW GPU architecture, allowing developers to use it alongside the company's other software and open source drivers. Now in version 2.0, FidelityFX Super Resolution (FSR) is fully open-sourced and allows developers to use it alongside the company's other software and open source drivers. While previous versions were proprietary, the new FSR 2.0 release is a major step towards making this technology more accessible to the community, encouraging innovation and potentially leading to improved performance and compatibility across a wider range of GPUs.

+   - FSR 1.0 had limited upscaling and sharpening.
+   - FSR 2.0 has added a frame generator.
+   - FSR 2.0 is now open source.
+   - The upscaling is not the same as an upscaling algorithm.
+   - AMD is working on FSR 3.0.

# **LAPTOPS**

HP launches Linux laptop

HP Dev One comes with Linux Pop!_OS preinstalled.

The HP Dev One is the latest laptop from HP to have Linux preinstalled, running Pop!_OS, a distribution based on Ubuntu. The laptop features an Intel Core i5 processor, 8GB of RAM, and a 256GB SSD, making it a solid machine for developers who prefer a Linux environment. It's a significant move by HP to cater to the developer community.
