```
exit 0
```

Isn’t this cheating? How can you write a shell script if in fact it’s actually an awk script? This is a fair question, and the answer I offer is that smart shell script programming is all about utilizing all the tools available in the Unix environment and putting them together in useful and novel ways. In this case, rather than puzzle through doing this as a “pure” shell script, the awk utility makes summing up the values in the fourth column of the df output and presenting the result in megabytes and gigabytes a breeze.
