If your system doesn’t have lprm, use the cancel command to remove entries from the print queue. The lpstat command is also the System V replacement for the lpq command, though many sites alias lpq = lpstat to make life a bit easier.

To use cancel, you need to specify the name of the printer and the job ID, as listed in the lpstat output. For example, if I had print request ID 37 on printer hardcopy, I could cancel the print request with the command cancel hardcopy -37.
