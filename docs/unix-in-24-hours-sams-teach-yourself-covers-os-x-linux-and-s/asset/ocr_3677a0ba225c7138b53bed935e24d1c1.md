# Task 11.6: Accessing Unix with !

This final task on vi introduces you to one of the most powerful, and least-known, commands in the editor: the ! escape-to-Unix command. When prefaced with a colon (: !, for example), it enables you to run Unix commands without leaving the editor. More powerfully, the ! command in vi itself accepts address specifications, feeds that block of text to the command as input, and replaces it with the results of having run that command on the text.
