5. Changing the words of Charles Dickens was fun, so save these changes and quit. If you try to quit the program with C-x C-c, emacs reminds you that there are unsaved changes:

```
--*-Emacs: dickens.note          (Fundamental)--Bot-----
Save file /users/taylor/dickens.note? (y or n) _
```

Typing y saves the changes; n quits without saving the changes; and if you instead decide to return to the edit session, Escape will cancel the action entirely. Typing n gets you a second reminder that the changes will be lost if you don’t save them:

Click here to view code image

```
--*-Emacs: dickens.note          (Fundamental)--Bot-----
Modified buffers exist; exit anyway? (yes or no) _
```

This time type yes (emacs will complain if you just type y!) and, finally, you’re back on the command line.
