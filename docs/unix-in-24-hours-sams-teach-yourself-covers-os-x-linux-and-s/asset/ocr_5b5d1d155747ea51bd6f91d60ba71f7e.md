# Workshop

The Workshop summarizes the key terms you’ve learned and poses some questions about the topics presented in this lesson. It also provides you with a preview of what you will learn in the next hour.

# Key Terms

**colon commands** The vi commands that begin with a colon are usually used for file manipulation.

**replace mode** In this mode of vi, any characters you type replace those that are already in the file.
