
请注意，在整个操作过程中光标始终停留在 is 中的 i 上。按 Escape 返回命令模式。请注意，光标最终会离开 i 并向左移动一个字符。

# Note

要区分 i 和 a 命令，请记住，插入命令始终在光标所在字符之前添加新信息，而追加命令则在当前光标位置的右侧立即添加信息。
