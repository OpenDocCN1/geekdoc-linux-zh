Note that this command expands the square brackets on the remote system, not locally.

You can also use curl to get ftp: and even https: files because it speaks about a dozen different transfer protocols. In fact, curl can even upload files via FTP.

The curl command also has a ton of different options, and if you’re interested in learning how to use it, man curl is a critical first stop.

Just like curl and lynx, GET allows you to work with Web-based content on the command line.
