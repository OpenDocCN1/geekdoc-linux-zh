4. Many modern Unix systems enable you to use du with the -h flag. (Some man pages refer to this as the human readable output flag!) This offers a much more useful output format. Here’s an example from yet another computer system:

```
% df
Filesystem      kbytes   used   avail capacity  Mounted
/dev/sd0a       55735    37414  12748   75%    /
/dev/sd2b       187195   153569 14907   91%    /usr
/dev/sd1a       55688    43089  7031    86%    /utils
```

```
% df -h
Filesystem   Size   Used   Avail Capacity  Mounted on
/dev/sd0a    15G    2.1G   13G    14%      /
/dev/sd1a    15G    157M   15G    1%       /web
```

5. Mac OS X is one of the more modern Unixes, and it has all sorts of nondisk devices included in df output, as you can see in this example:

```
$ df -h
Filesystem        Size   Used  Avail Capacity  Mounted on
/dev/disk0s8      49G    43G   6.1G   88%      /
devfs             94K    94K   0B     100%     /dev
fdesc             1.0K   1.0K  0B     100%     /dev
<volfs>           512K   512K  0B     100%     /.vol
automount -nsl [335] 0B 0B 0B 100% /Network
automount -fstab [338] 0B 0B 0B 100% /automount/Servers
automount -static [338] 0B 0B 0B 100% /automount/static
```

With all this output, there’s actually only one disk on the system, /dev/disk0s8, which is a 49GB hard drive that’s 88% full.
