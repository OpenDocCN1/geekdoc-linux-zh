Unlike previous examples, where the program has run until completed and left you back on the command line, more is the first *interactive program* you’ve encountered. When you see the --More--(51%) prompt, the cursor sits at the end of that line, waiting for you to tell the program what to do. The more program lets you know how far into the file you’ve viewed; in this example, you’ve seen about half of the file (51%).

At this point, quite a variety of commands are available. Press the spacebar to see the next screen of information, and keep doing this until you have seen the entire file.
