The breakdown subroutine receives the user-entered currency amount and splits it into two parts: the numeric value and the first letter of the currency indicator, if any (the default currency is U.S. dollars):

sub breakdown {
    @line = split("", $_);        # split at space
    $amnt = $line[0];
    if ($#line == 1) {
        $curr = $line[1];
        $curr =~ tr/a-z/A-Z/;       # normalize to uppercase
        $curr = substr($curr, 0, 1); # extract first char only
    } else { $curr = "U"; }
    return ($amnt, $curr);
}
