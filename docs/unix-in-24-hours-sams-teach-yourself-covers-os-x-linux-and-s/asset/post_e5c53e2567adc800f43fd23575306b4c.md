## 4. Now that I have a basic archival file, what can I do with it? Well, the easiest thing is to change the output from a file to a Unix archive device, so I can make a quick backup:

```
$ tar cf /dev/rst0 .
$
```

In the old days, it would have taken about 20 minutes to write to a backup tape, but newer media like a DVD burner work much faster—and a USB 3.0 flash drive is lightning fast. Regardless of the media onto which I copy the archive, now I have a copy of all my files that I can drop in my pocket, without worrying about whether the computer might crash or whether the admin is checking the validity of system backups.

## 5. In addition to writing backups and creating snapshots of files and folders for safety purposes, using tar turns out to be a great way to transfer clusters of files from one computer to another.
