3. Using the four cursor-control keys—h, j, k, and l—move around in the file for a little bit until you are comfortable with what’s happening on the screen. Now try using the Backspace and Return keys to see how they help you move around. Remember that since you’re in command mode, they won’t delete a character or add a new line to the file.
