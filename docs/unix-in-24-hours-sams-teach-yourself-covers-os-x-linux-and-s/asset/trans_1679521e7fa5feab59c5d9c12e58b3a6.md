如果你没有 Delete 键，一些删除命令将遗憾地对你不可用。一般来说，emacs 删除文本的方式与 vi 一样多——如果不是更多的话。最好的功能是，与 vi 不同，emacs 从编辑会话开始就记住编辑更改。你始终可以使用 C-x u 撤销请求向后回溯到你想要的程度，一直回到你启动编辑器时文件的原始版本。

删除命令总结在表 12.2 中。

| 命令 | 含义 |
|---|---|
| Delete | 删除前一个字符。 |
| C-d | 删除当前字符。 |
| M-Delete | 删除前一个词。 |
| M-d | 删除下一个词。 |
| C-x Delete | 删除前一个句子。 |
| M-k | 删除当前句子的剩余部分。 |
| C-k | 删除当前行的剩余部分。 |
| C-x u | 撤销最后一次编辑更改。 |
