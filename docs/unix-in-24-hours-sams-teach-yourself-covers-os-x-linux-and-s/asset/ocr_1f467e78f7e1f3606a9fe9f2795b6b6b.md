# single-digit equivalents

| Permissions String | Binary Equivalent | Decimal Equivalent |
|---|---|---|
| --- | 000 | 0 |
| --x | 001 | 1 |
| -w- | 010 | 2 |
| -wx | 011 | 3 |
| r-- | 100 | 4 |
| r-x | 101 | 5 |
| rw- | 110 | 6 |
| rwx | 111 | 7 |

# TABLE 5.5 Permissions and Numeric Equivalents

The value of having a single digit to describe any of the seven different permission states should be obvious. Using only three digits, you can fully express any possible combination of permissions for any file or directory in Unix—one digit for the owner permission, one for group, and one for everyone else. # Note

If this math is a bit intimidating, remember that r = 4, w = 2, and x = 1, so, for example, rwx = 4 + 2 + 1 = 7 and r-x = 4 + 1 = 5.

From this illustration, you can see how the permissions string rw-r----- (read and write permission for the owner, read permission for the group, and no access allowed for everyone else) is exactly equivalent to the numeric string 640.
