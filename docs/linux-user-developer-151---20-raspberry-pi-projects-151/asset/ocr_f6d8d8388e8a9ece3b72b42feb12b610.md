Last issue we talked about btrfs, the next generation of filesystems. In that tutorial we briefly mentioned LVM, a technology that is already widely in use, and how it’s related to btrfs. Logical volume management, as it’s properly designated, acts as a sort of container to manage data – the benefit of this is that you can start adding and extending space while the LVM is still online and working.

This is great for server farms because you can swap out and add storage very quickly, and on your desktop its good for managing the size of different partitions if you weren’t sure how they should have been during installation.

In this tutorial, we’ll look at how you can create an LVM filesystem and how to maintain and modify it. We will also look into how some distros install using LVM.
