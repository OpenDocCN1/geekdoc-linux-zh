# FAQ:
Codec licenses

Q: What codecs are truly free on Linux?
A: For audio you have your choice of FLAC, Vorbis and Theora as the more popular ones - the latter two you will usually find in an Ogg container, which in itself is also open. Ogg and Theora can also be used in video, along with the Matroska (mkv) container. WebM is also open but it is usually used on browsers as sort of a modern replacement for animated gifs.

Q: So why am I able to play MP3, MP4, AVI, etc on Linux?
A: A lot of Linux codec packs and streamers and such use non-free codecs in order to play some of these popular file types. The legality of them varies depending on the codec pack used, but usually some distros that consider themselves as truly free, like Fedora for example, do not include them at all.

Q: Can I still get them on Fedora and other free distros?
A: You, usually there is a workaround, such as installing the RPM Fusion software sources in Fedora, for example. You will need to do a Google search and find out what you need to do to add them to other distros. Speaking of installing RPM Fusion, check out our first question for advice on getting it up and running.

# More in Fedora

I've recently installed Fedora 21 to try it out - I've never properly used Fedora before but thought I'd give it a go. I'm actually quite liking it, I like the way yum works and it does seem like a better development environment than some others.

One thing that's bugging me though is that, although I am a fan of the completely free repos, it would be nice if I could get easier access to some ways to play my MP3 collection or watch videos a bit easier. Are there binarries I can grab for this or will I have to start compiling the software from source? I don't fancy the latter so much as I always seem to miss something with media software while compiling.

Hope you have an answer!

Pete Chan

We absolutely have a solution for you and it involves setting up the RPM Fusion repository in Fedora. This is an extra repository full of non-free software, and other free software, and it sets itself up pretty easily via a graphical binary method that you can access via the website here: rpmfusion.org/Configuration.

Otherwise, you can do it in the terminal in one command that adds the repos and configures them to be used with the original ones as well:

```
$ su -c 'yum localinstall --nogpgcheck
http://download1.rpmfusion.org/free/
fedora/rpmfusion-free-release-\$\{rpm -E
%\{fedora\}\}.noarch.rpm http://download1.
rpmfusion.org/nonfree/fedora/rpmfusion-
nonfree-release-\$\{rpm -E %\{fedora\}.
noarch.rpm'
```
