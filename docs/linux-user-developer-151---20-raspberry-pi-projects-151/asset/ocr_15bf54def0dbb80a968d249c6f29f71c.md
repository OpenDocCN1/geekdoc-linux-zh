**Reversing a string in C** poses problems. It’s not just finding a way to do your job, but also finding an efficient algorithm to do so. You can decide if the ‘reversed’ string will be stored in the existing memory space or if you want to allocate new memory space and a new variable. Using the existing memory space is difficult but is usually the desired task – we assume that no new memory space will be allocated apart from temporary variables.

C lets you to access a string in two ways: either as an array or using pointers. Despite the fact that C pointers can be the root of nasty bugs, pointers are super fast.

Given the string p = "abc", you can access its three characters as follows. First, you can access them as p[0], p[1] and p[2], then you can access them using pointer arithmetic as *p, *(p+1) and *(p+2), and you can traverse the string by increasing the value of the p pointer (*p++) and accessing it character by character.

If you access a string as an array, you will need to compute its length using the strlen C function. The same isn’t required when using pointers, as the ‘\0’ character that denotes the end of a string in memory enables you to find the end of the string in your programs – so a simple while loop can do your job! To make changes to the string it must be initialised using the following C statement:

```
```
char s[] = "abcdefg";
```
```

The plain pointer version (see ‘PRevC’ file) also needs an additional pointer variable to mark the end of the string. The p pointer is initialised as the memory address of the first character of a string: `char *p = &s[0];` (nasty C code!). The end of the string can be found using an unusual yet fully functional while loop:

```
```
while (*++p) ;
```
```

The previous while loop will make your code look odd so it won’t be used. The array version (see ‘RevC’) is easy to understand and works well, it does look like Perl or Python code. Additionally, if you have a smart C compiler, it may replace arrays with pointers and do the optimisation job for you. The tricky part of the whole process is finding out the length of the string, which varies depending on the string. The final version will use pointer arithmetic, arrays and the strlen function:

```
```
for ( i=0; i < len/2; i++) {
    temp = s[i];
    s[i] = *p;
    *p = temp;
    p--;
}
```
```
