# Facebook unveils modular switch

1.28Tb/s of bandwidth available with the new open hardware modular switch

![](bbox=[0.5, 0.15, 0.97, 0.42])

Social networking giant Facebook has announced 6-pack, which it describes as the first open hardware modular switch and is designed for use in its expansive data centres.

Based on a top-of-rack network switch project dubbed Wedge, 6-pack uses a Linux-based operating system called FBOSS with a data centre fabric based around a modular architecture for fast and easy scalability.

Described as the core of Facebook's new data centre fabric, 6-pack uses Wedge as a building block and works as a full-mesh non-blocking two-stage switch across twelve independent switching elements. Two configurations exist at present: one features 18 40-gig Ethernet ports to the front and a further 16 to the back; the other has all 32 ports to the rear for 1.28T of bandwidth and is mostly used for aggregation purposes.

"With 6-pack, we have created an architecture that enables us to build any size switch using a simple set of common building blocks," explained Facebook's Yuval Bacher at the company's announcement. "Because the design is so open and so modular – and so agnostic when it comes to switching technology and software – we hope this is a platform that the entire industry can build on."

# Demand for Linux professionals rising

Foundation report points to certification desirability

![](bbox=[0.07, 0.66, 0.31, 0.88])

Above Report claims demand for Linux professionals is rising rapidly

A report from the Linux Foundation and Dice reveals that rising interest in cloud platforms based on open source technologies has led to a growth in the job market for Linux experts.

Compiled from data supplied by over a thousand hiring managers and nearly 3,500 Linux professionals, the report claims that "nearly all hiring managers" (97 per cent of those surveyed) are looking to hire Linux experts soon. Other highlights from the report include that 42 per cent of hiring managers will be looking for experience in OpenStack and Cloudstack, while 23 per cent are looking for security expertise, with a further 19 per cent concentrating on software-defined networking (SDN).

A requirement for formal certification is becoming a trend in the industry, however. The report states that 44 per cent of hiring managers say they are "more likely" to hire a candidate with a recognised Linux certification, with 54 per cent expecting those applying for system administrator roles to have either certification or other evidence of formal training.

"Demand for Linux talent continues, and it's becoming more important for employers to be able to verify candidates have the skillsets they need", claimed Jim Zemlin, executive director at The Linux Foundation, of the report. "Formal training and certifications are a key way of identifying qualified talent and as more people join the Linux community, it will be necessary for professionals to show they stand out." 

The full report is on The Linux Foundation's website at linuxfoundation.org.
