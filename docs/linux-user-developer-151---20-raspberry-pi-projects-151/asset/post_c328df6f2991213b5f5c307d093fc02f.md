### Open LDAP

I'm having problems with GSSAPI and LDAP. From the information available, I have narrowed the problem down to somewhere in the `acquire_cred1` or `gss_krb5_canonicalize_name` functions located in the GSSAPI module.

What I really need is to understand how the minor_status parameter got set, as that may tell me specifically where my issue lies. However, using strace on the `ldapwhoami` command only shows what the client is doing, and the problem is on the server side. The slapd service has got full log levels on, but it doesn't give me enough information, as it seems the problem is in GSSAPI, not slapd.

I have tried running slapd with strace, however, I can't seem to do so in such a manner that the slapd service runs as it would when invoked through the service slapd start line. Using strace seems to then cause all LDAP* commands to completely fail to find the LDAP service.

I don't even know if a strace on slapd would capture the information that I'm after. How can I capture the information in the GSSAPI module? Thanks!

Phil Coping

> The problem sounds like an issue with openldap, not GSSAPI – mainly that it doesn't have permission to access the files. This can be fixed though. First check the service is running as normal. Then do:

```
sudo pidof slapd
```

> This will give you the pid number, so then you need to run:

```
sudo strace -o /tmp/dumps/ldap.log -f -s 1024 -p <insert pid>
```

> Then open another terminal window and carry out your test in that. Once you've finished testing, hit Ctrl+C in the one where strace is running.

### C library

I'm currently running Ubuntu 12.04 as my main distro. I have the G++ compiler to compile C++ files. However, I feel there is something wrong with my complex.h header file. I ended up copying it to the directory where my source files reside but I don't know if that's helped at all. I am not even sure if it is the correct version. Other header files are fine, like math.h, for example. How can I make sure the standard C library is present in my version of Ubuntu?

Alex B

Okay so complex.h is for C, so you'll need to include complex in the C++ template. As for whether or not it's installed or at the correct version, there's a couple of ways you can try and check it.

First of all, the locate command will enable you to check for the package name entirely to make sure it's in your system. Otherwise, you can use debsums to check the md5 of the package (against an md5 file) to see if it's the right one. Hopefully one of these will sort you out.

### Password behaviour

Hey, I'm trying to find a way to copy files to a couple of my servers throughout the day using a script but I'm baffled as to how to do it. The part that I can't figure out is how to pass the password to the remote server. I'm using a generic scp command:

```
scp *.* jobee@192.168.1.7:/mnt/bigdrive/Backups
```

How do I include the password so the script will work without user intervention? Googling this is no help. Well, there was one hit that looked like it might do what I wanted it to do but after I got to the third page I decided to post a question here. Is this possible? If so, how?

Jg

Right, what you need to use is sshpass for it to send the password over SSH. You will need to modify your command by using something just like this:

```
sshpass -p 'password' scp -r [Path to folder to backup] root@192.168.1.7:/mnt/bigdrive/Backups/Docs
```

Obviously it's a little insecure to have the password for the root account just in the script or bash, so you should probably think of making an alternate account or encrypting it in some way. Hope this helps!

### Image crops

I have a bunch of jpgs from which I need to extract part of each image and save only the selected parts at their true dimensions, ie not stretched to fit the size of the original image. As the geometry of the selection varies from one file to another, this looked to be a tedious process, but imagemagick's display app seemed to offer a much more convenient process. Using its menu I could draw a rectangle on the original to outline the part I wanted and then to save just that selected rectangle to a new file. However, it deforms the image to fit the original geometry, and I can't find any way to have it perform the --repage option to make sure it is saved using the new geometry. How exactly should I do this, or do you think I would be better off using a different software instead?

Paul B

The best way to do this is to use GIMP – it has a very simple way of doing this which requires you to just select the area that you want to crop to, and then selecting 'Crop to selection' in the Image drop-down menu.

### Bookmarks

Most of my bookmarks are organised (albeit haphazardly) in folders according to the subject – there are a handful that live by themselves because they are so commonly used, and a much larger handful that have not yet been sorted or erased.

Yesterday I was started to see that one of the folders had vanished (ironically, the folder named Linux). I didn't think I could have erased it by error, but couldn't think of another answer and decided to recreate the list.

I was then surprised again when bookmarking LinuxUser.co.uk (for example), as it offered to edit the existing bookmark, claiming that it still existed in a folder named Linux. The same thing happened with each of the other bookmarks I attempted to replace.

This is hardly the end of the world – I have my bookmarks backed up and can simply start over if necessary. But I would like to know if that folder is retrievable and what went wrong in the first place.

Tsu J

> Hi Tsu. The usual reason that this happens is if you've done something silly by accident, such as dragging the Linux folder into another one. Accept the option to edit the bookmark and then try and restore the folder to its usual place. That should fix everything!

Right The bookmarks management in Firefox is much better than Chrome. While VLC has a lot of pretty incredible features – from playing back just about anything to powerful streaming and stream capture options, some of its more normal user functions don't work so well. Case in point, playlists. We've had problems with it ourselves in the past. Usually a good solution is to make sure everything is saved and ensure that the xsp extension is included. You could also try using an external file manager to make a proper playlist file if you're still having problems – the latter we find generally easier to use as well.
