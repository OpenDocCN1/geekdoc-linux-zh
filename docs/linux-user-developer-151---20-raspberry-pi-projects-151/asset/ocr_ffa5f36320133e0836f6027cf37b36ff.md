# 01 Choose a distribution

There is an abundance of easy-to-use Linux distros that could help you instantly get started with a usable LxQt desktop – it is up to you to take your pick.

Lubuntu is a dedicated LxQt flavour of Ubuntu with a 'daily' PPA containing the most recent code (ppa:ubuntu-dev/ubuntu-daily). The PPA is compatible with most Ubuntu 14.04 and 14.10 derivatives, including Kubuntu, XLE, Mint and many of the others. To get LxQt you will need to packages lqt-metapackage, lqt-session and lqt-session packages.

An alternative way to install LxQt could be Arch/Manjaro (LxQt is in AUR) or the development version of OpenMandriva, which is shipped with LxQt by default (Plasma 5 will arrive at a later date).

# 02 What we have so far

The desktop occupies ~95 MBs of RAM. It features a control centre, power management applet, customizable bottom panel, lock and fast settings manager, window manager chooser, Qtterminal console and PCManFM file manager. Keyboard layouts indicator and NetworkManager applet are currently missing, but you can take the XFCE applet and gorgeous CMST (frontend to ConnMan) respectively.

By default, the windows decorations are managed by OpenBox but you can change it to Kwin or Etermalid. PCManFM is quite modest, but keep in mind that it is the only Qt5 file manager for the day.

# 03 Thumbnails in PCManFM

We can tweak and add extra functionality to the PCManFM file manager. First, let's add thumbnails support for filetypes other than images. For example, for PDF create a new file with the thumbnail extension at ~/usr/share/thumbnailers with the following content:

```
`[Thumbnailer Entry]
TryExec=convert
Exec=convert %[0] -thumbnail %s Xx%o
MimeType=application/pdf,application/x-pdf,image/pdf;`
```

Using this template you can add more types that 'convert' supports (it's a part of ImageMagick).

# 04 Get Otter Browser

The web browser is updated weekly so you can track its development on the project website. For Ubuntu-compatible Linux systems there's a handy PPA. So here we go:

```
`sudo add-apt-repository ppa:otter-browser/daily
sudo apt-get update
sudo apt-get install otter-browser-git`
```

The Otter Browser has a variety of lovely features, such as tabs grouping, mouse gestures and a highly customizable UI. You can set the browser as a default web application by selecting otter-browser from the Web Browser menu in the System Settings.
