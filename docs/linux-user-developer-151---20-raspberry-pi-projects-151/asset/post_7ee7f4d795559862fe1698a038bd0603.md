## 15 Use AWK to process Netstat output

  The following command, which needs root privileges to run, extracts the IP address from all established Apache connections and then calculates the number of connections for each individual IP address:

```bash
# netstat -ant | grep apache2 | grep ESTABLISHED | awk -F "[ ]+" '{print $4}' | uniq -c
```

  The next command calculates the number of TCP connections per IP address sorted by the number of connections:

```bash
$ netstat -nt | awk '/tcp/ {print $5}' | awk -F: '{print $1}' | sort -nr
```

  The following command prints a '+' character for every connection:

```bash
$ netstat -an | grep ESTABLISHED | awk '{print $5}' | awk -F: '{print $1}' | sort | uniq -c | awk '{ printf("%5s %s\n",$2,$1); for (i = 0; i < $1; i++) printf("*"); print " }"
```

  This command counts the various types of TCP states and prints the results:

```bash
# netstat -ant | awk '{print $6}' | grep -v established | grep -v Foreign | sort|uniq -c|sort -n
```

  A large number of TIME_WAIT connections may be an indication that you need to adjust your TCP timeout settings.

## 16 Show total number of processes per user

  The following one-line command shows the total number of listening processes per user:

```bash
# netstat -ltpe | awk '{print $7}' | grep -v Address | grep -v "" | sort | uniq -c | awk '{print $2 ": " $1}'
```

  The netstat command collects the desired information. The first grep command deletes the line with the header information of Netstat and the second grep command deletes empty lines from the output. The first awk command grabs the desired user information from the output of Netstat. The sort command orders the output whereas the uniq command counts line occurrences while omitting repeated lines. The last awk command reverses the two columns of the uniq output and prints the data on the screen.

  As always, in order to be able to see all processes you must run this with root privileges.

## 18 View active listening ports

  The following command displays the active UNIX listening ports:

```bash
$ netstat -lx
```

  It is extremely useful for finding out which services are available to local users only (localhost). The following output verifies that MySQL is efficiently accepting connections from the local machine:

```bash
$ netstat -lx | grep -i mysql
unix  2  [ ACC ]  STREAM
LISTENING     32891287  /var/run/mysqld/
    mysqld.sock
```

### 01 Choose a distribution

  There is an abundance of easy-to-use Linux distros that could help you instantly get started with a usable LxQt desktop – it is up to you to take your pick.

  Lubuntu is a dedicated LxQt flavour of Ubuntu with a 'daily' PPA containing the most recent code (ppa:ubuntu-dev/ubuntu-daily). The PPA is compatible with most Ubuntu 14.04 and 14.10 derivatives, including Kubuntu, Xubuntu, Mint and many of the others. To get LxQt you will need to install the lqt-metapackage, lqt-session and lqt-session-icewm packages.

  An alternative way to install LxQt could be Arch/Manjaro (LxQt is in AUR) or the development version of OpenMandriva, which is shipped with LxQt by default (Plasma 5 will arrive at a later date).

### 02 What we have so far

  The desktop occupies ~95 MBs of RAM. Keyboard layouts indicator and NetworkManager applet are currently missing, but you can take the XFCE applet and gorgeous ConnMan Gnome Frontend (frontend to ConnMan) respectively.

### 03 Thumbnails in PCManFM

  We can tweak and add extra functionality to the PCManFM file manager. First, let's add thumbnails support for filetypes other than images. For example, for PDF create a new file with the .thumbnailer extension at ~/.local/share/thumbnailers with the following content:

```ini
[Thumbnailer Entry]
TryExec=convert
Exec=convert %[0] -thumbnail %s x%o
MimeType=application/pdf,application/x-pdf,image/pdf;
```

  Using this template you can add more types that 'convert' supports (it's a part of ImageMagick).
