# Tabbed terminal emulators

If you've never looked beyond Gnome-terminal or Konsole, it's time to find out what you've been missing

# Sakura

A lightweight terminal emulator based on VTE (as used by GNOME and Xfce's terminals) and the Gtk libraries, with enough features to make it useful including tabs, contextual menus and some colour options. However, it has a more modern feel to it than Mxvxt and has full support for UTF-8.

Download: bit.ly/1AFT3KT

# Mxvxt

Mxvxt is a tabbed version of the light, flexible rxvt. It's been years since the last release, but as many people still use mxvxt as their daily terminal emulator, we'll look at it as a mature and stable product rather than a neglected one. As the lightest weight choice, it still offers plenty of useful features and configurability.

Download: bit.ly/1KWtZTB

# Terminator

Not to be confused with GNOME Terminator. Phil Norman wrote this in around a month during 2004. Terminator had had some advanced features added since then and it is now truly cross-platform. It's popular in some quarters, despite the common confusion with GNOME's same-name project.

Download: bit.ly/1FaWfNn

# Roxterm

Roxterm is written for the ROX Desktop environment, originally as a lower resource-using clone of Gnome-terminal, but the feature count has gradually crept up over time. Despite this it is still clean, quick, quite user-friendly and integrates well with GNOME, which is an advantage.

Download: bit.ly/1D5ymHs
