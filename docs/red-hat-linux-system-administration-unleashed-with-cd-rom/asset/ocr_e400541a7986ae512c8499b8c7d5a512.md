# Adding an Ethernet Interface

Once the hardware has been installed, configuring a new Ethernet interface can normally be divided into kernel-level (hardware driver) configuration on the one hand, and configuration of the networking software on the other. However, in Red Hat 6, the use of a fully modularized kernel build means that both of these steps can be performed from the same system administration tool—Linuxconf. Figure 14.3 shows the basic host configuration dialog in the Gnome version of Linuxconf being used to add an Ethernet interface.

# Kernel Level Configuration

The kernel-level configuration is set with the Kernel Module, I/O Port, and Irq fields. Use the Kernel-module field to select the hardware type of your Ethernet card. In this example, the card being configured is an Intel EtherExpress Pro. If you use the Gnome interface, there is a drop-down menu of Ethernet card types, but if you use the terminal-based interface, you have to know the name of the kernel module that can drive it. If you want to see a list of the available modules, you can run

```
ls /lib/modules/$(uname -r)/net
```

although that directory also contains some non-Ethernet modules.
