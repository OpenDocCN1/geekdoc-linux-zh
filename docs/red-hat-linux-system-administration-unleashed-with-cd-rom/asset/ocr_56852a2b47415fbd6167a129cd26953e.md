# DOS Diagnostics

Even on a dedicated Linux server, it can be useful to include a bootable DOS partition where DOS utilities can be stored and executed. Many brand-name PCs, such as Dell, Compaq, and IBM, include proprietary DOS-based diagnostic tools that make hardware troubleshooting easier. There are also a number of commercial DOS utility programs that do a particularly good job of testing hardware components and stress-testing memory chips.
