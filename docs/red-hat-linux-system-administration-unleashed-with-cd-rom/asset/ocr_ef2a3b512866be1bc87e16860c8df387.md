# The if Statement

The if statement is used for conditional branching. The if statement takes several forms, based upon complexity. The simplest form of the if statement has the following syntax:

```
if list;
then
    command list;
fi
```

Here, the commands in list are executed. If the last command in list succeeds, the commands in command list are executed. If the last command in list fails, nothing is executed. Here is an example of using the if statement:

```
#!/bin/bash
secretname=John
echo -n 'Please enter your name: '
read name
```
