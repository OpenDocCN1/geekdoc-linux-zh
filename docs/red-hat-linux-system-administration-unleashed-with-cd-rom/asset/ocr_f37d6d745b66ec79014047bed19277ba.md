# Note

Please note that you cannot infer from the following output whether this system is or is not a multiprocessor system. This output merely shows that the running kernel only recognizes one processor. If this were a multiprocessor system running a kernel compiled without SMP support, you would get output as shown in the preceding example.

```
tschenk@quicksilver:~ [1038]$ cat /proc/devices
Character devices:
1 mem
2 pty
3 ttyp

36 netlink
128 ptm
```

The /proc/devices file is a good starting place to see which devices are supported by the Linux kernel. This file lists character and block devices for which drivers are available in the running kernel along with their major numbers.
