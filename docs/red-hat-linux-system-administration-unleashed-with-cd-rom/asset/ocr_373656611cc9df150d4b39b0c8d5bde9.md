# Managing Chaos

Red Hat Linux is an incredibly powerful operating system, and all the little details that a system administrator must keep track of can sometimes be a little intimidating. Being a multitasking operating system, there can be any number of jobs running in the background at a given time. In fact, you can take a look at all the processes running on your system at a given time by using the ps aux command.
