Assuming your printer is in the preceding list or is compatible with one of them, you can use the printtool utility to create the appropriate printcap entry and the configuration files used by the Red Hat print filter system. The printtool is normally invoked from the control panel and includes dialogs that allow you to specify whether the printer is local or a network printer, the type of printer, and various other options.
