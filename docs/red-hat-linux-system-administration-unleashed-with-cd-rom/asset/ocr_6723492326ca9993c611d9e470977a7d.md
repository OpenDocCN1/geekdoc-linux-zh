+   - Account Expire after # days—This is the number of days after the password expires that the account will expire.
+   - Standard account duration—This is the length of time (days) the account will remain active.

> **Note**
> 
> If desired, the last five fields can be overridden on an individual basis when adding a user through the Add User window.
