Figure 26.1 shows a network firewall where the bastion host sits outside of the network router. In this configuration, the host is the "gate" through which all contact with the Internet must pass. This is also a very good configuration for implementing IP masquerading; however, that is beyond the scope of the current discussion. In this configuration, all forwarding of packets can be turned off and provide a reasonable level of confidence in the security of the firewall. The bastion host can provide proxy services to internal programs or be a simple packet filter requiring the users to connect to it before continuing on to the internal network.
