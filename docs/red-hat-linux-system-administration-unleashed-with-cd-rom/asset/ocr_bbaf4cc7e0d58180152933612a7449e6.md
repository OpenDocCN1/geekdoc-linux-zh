Once I move into one of the groups to read, tn lists the different threads for me and shows me who’s written the messages. I can select a thread by pressing the letter next to the thread subject listed. In Figure 23.3, I’ve selected threads on three topics. You can tell which topics are selected by the plus sign in the column next to the topic letter. There are numerous controls in tn. The best way to learn about tn is either through the online help screen (press the “h” key) or through the man page (type man tn).

Another popular text-based client is tin. It is also a thread newsreader, and it has a few features that tn doesn’t. One of the most notable is the ability to select the order in which the threads are to be read. However, tin does take a bit longer to start up than tn. Figure 23.4 shows the tin opening screen.
