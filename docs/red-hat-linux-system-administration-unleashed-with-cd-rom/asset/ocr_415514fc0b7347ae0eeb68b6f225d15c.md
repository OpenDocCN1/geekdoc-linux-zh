+   - `-f <inactive default>` Number of days after a password expires that the account will be rendered inactive. 0 means the account will expire immediately after the password expires, and -1 means the account is never disabled after the password expires.
+   - `-e <default expiration date>` The date on which this account will expire. You can specify this parameter as /MM/DD/YYYY or the number of days since 01/01/1970.
+   - `-s <default shell>`
