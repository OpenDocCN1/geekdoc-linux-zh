After installing the wu-ftpd server, it is usually desirable to customize it to match the system that it has been installed on. Such customization options include setting the email address of the FTP site administrator, banners that should be displayed, and so on. The following customization options are supported through the use of the ftpaccess configuration file:

+   - greeting full;brief;terse;text [message]—Configures the type of greeting given to users logging into the FTP server. The full option prints the server hostname and FTP daemon version to clients. The brief option prints only the server hostname. The terse option prints the statement FTP server ready. The text option allows administrators to specify their own custom greeting. The message option is used only in conjunction with the text parameter, and thus is not supported by the full, brief, or terse parameters. The default value for this configuration setting is full.
+   - banner [banner-file]—Allows a banner to be shown to clients connecting to the FTP server. The banner is shown upon connection to the server, before a user logs in. The banner-file parameter specifies an absolute pathname (relative to the real root directory of the FTP server) pointing to the banner file that is to be displayed.
