```
sort split stty swapoff swapon sync tail tar tcio telnet
test touch tune2fs umount update vi vi.help wc
```

The disk even includes man pages. With tom'srtbt you can use your DOS/Windows partition, if you have one, to copy files to if you're rescuing files from a badly damaged Linux partition. This is much more efficient than copying critical files to floppy disks and it provides a handy place for copying files back into a new Linux setup if reformatting the Linux partitions becomes necessary. This is yet another reason to consider maintaining a modest-sized DOS partition on your Linux system.

# Tip

A file rescue mission with a booted tom'srtbt looks like this:

```
# mkdir /mnt/image
# mkdir /mnt/dos
# mount -t ext2 /dev/hda4 /mnt/image
# mount -t vfat /dev/hda1 /mnt/dos
# mkdir /mnt/dos/rescuefiles
# cd /mnt/dos/rescuefiles
/mnt/dos/rescuefiles# cp /mnt/image/etc/*.conf .
/mnt/dos/rescuefiles# ls
dosemu.conf   isapnp.conf   mtools.conf   pine.conf     syslog.conf
gpm-root.conf ld.so.conf    named.conf    pwdb.conf     yp.conf
host.conf     lilo.conf     nsswitch.conf resolv.conf
inetd.conf    logrotate.conf ntp.conf      smb.conf
/mnt/dos/rescuefiles# cd /mnt
/mnt# umount dos ; umount image
/mnt#
```

This session, in contrast to the Red Hat rescue session, displays files in color on a color monitor, displays pathnames at the prompt, and includes command-line history. As a system administrator, you will marvel at the versatility of tom'srtbt and will find many additional uses for this handy tool. Keep one in your toolkit. You can use it to turn almost any Intel PC into an instant, if limited, Linux computer.
