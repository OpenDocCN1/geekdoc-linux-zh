# LISTING 18.13 Section 21 of the /etc/nwserv.conf File—Print Queue Definition

```
# =================================================================
# Section 21: print queues (optional)
#
# Which of the printers connected to your Linux-box should be accessible
# from the DOS-clients?
# Multiple entries are allowed.
#
# .................................................................
#
# Syntax:
#
#   21      QUEUE_NAME      QUEUE_DIR      PRINT_COMMAND
#
# QUEUE_NAME: the name of the print queue on client-side (to make it
#             perfectly clear: _not_ the Linux-queue)
# QUEUE_DIR: spooling directory for the print-jobs; this directory must
#            exist before printing (_not_ the spooling-directories of
#            the Linux-lpd)
# PRINT_COMMAND: command used for serving the print-jobs under Linux
#                 (see "man lpr" and "man magicfilter" for details)
#
# Examples:
#   21      LASER      SYS://PRINT/L      lpr -Plaser
#   21      OCTOPUSS   SYS://PRINT/O      lpr -Php_deskjet
# .................................................................
21   LP   SYS://PRINT/LP   lpr
```

There are a number of other sections in the configuration file, however most of them are not pertinent to this discussion. They are described in the comments of the /etc/nwserv.conf file, which I encourage you to study. These sections define paths to various files used by the software, debugging options, and other facets of server operation.

# Starting the mars-nwe Server

Now that you have a configuration file, you are ready to start the server. On your Red Hat system, you can do this by using the mars-nwe script located in /etc/rc.d/init.d as follows:

```
/etc/rc.d/init.d/mars-nwe start
```
