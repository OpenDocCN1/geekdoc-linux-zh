var1 is equal to testvar1

+ [ -f /etc/bashrc ]

Now you can see exactly where the problem is. It is with the variable testvar3—it is not defined before the test takes place and thus it returns an error.

As you can see, the -x option can aid greatly in debugging shell scripts, especially when your scripts get large. When you are in the process of debugging your scripts, it never hurts to pass the -x option to bash.
