The Public Domain Korn Shell supports many of the same features found in bash and tcsh, such as the following:

+   - Wildcards
+   - Aliases
+   - Command-Line completion
+   - Input and Output Redirection
+   - Command history
+   - Pipelines
+   - Job control

The pdksh is great if you are a Korn shell user and you are looking for a free replacement that is available for Linux.

This chapter looked at shells under Red Hat Linux, with emphasis on the two most popular shells, bash and tcsh.
