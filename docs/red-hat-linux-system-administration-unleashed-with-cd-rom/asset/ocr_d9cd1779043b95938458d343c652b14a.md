# Note

You can bypass the control-panel and top-level Linuxconf screen and get to the user account configuration area by simply typing:

```
userconf
```

If you look at the tabs across the top of the screen in Figure 29.7, which appear as sections delimited by a horizontal bar in the text version, you will notice that there are three tabs from which to choose. Normal enables you to edit normal groups and accounts. Special Accounts enables you to edit POP, PPP, SLIP, and UUCP accounts. Policies enables you to set the account-related system policies. If you go into the Policies tab and choose Password & Account Policies, you will be able to edit all the default user creation information.

Under the Policies tab, you can choose Password & Account policies. Under this, you will find the parameters for setting password validation rules, which are as follows:

+   - Minimum length
+   - Minimum amount of non alpha char—These two features are used for systems that do not employ PAM to enforce password changing parameters. Red Hat uses PAM, so these should be ignored. For more information on configuring PAM to check the strength of passwords, see Chapter 25, “Security Principles.”
