# Checking Devices

The proc filesystem also provides mechanisms to query devices recognized by the Linux kernel. This information ranges from the IRQs used by various devices to the type and number of disk drives installed and much more. The following commands demonstrate the types of information available in the proc filesystem and how to examine it.

```
tschenk@quicksilver:~ [1040]$ cat /proc/cpuinfo
processor : 0
vendor_id : GenuineIntel
cpu family : 5
model : 2
model name : Pentium 75 - 200
stepping : 12
cpu MHz : 167.047402
fdiv_bug : no
hlt_bug : no
sep_bug : no
f00f_bug : yes
fpu : yes
fpu_exception : yes
cpuid level : 1
wp : yes
flags : fpu vme de pse tsc msr mce cx8
bogomips : 66.56
```

To determine the type of processor that a Linux system has, you can do as shown here and examine the contents of the /proc/cpuinfo file. The preceding example shows that this system recognizes one Pentium 166MHz processor.
