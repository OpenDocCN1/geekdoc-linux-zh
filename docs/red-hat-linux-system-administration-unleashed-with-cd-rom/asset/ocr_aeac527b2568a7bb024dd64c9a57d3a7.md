# TABLE 34.2 continued

| Field | Description |
|---|---|
| SIZE | The total size of a task including code, data, plus stack space in kbytes. |
| RSS | Amount of physical memory used by a task. |
| SHARE | Amount of shared memory used by a task. |
| STATE | Current CPU state of a task. The states can be S for sleeping, D for uninterrupted, R for running, T for stopped/traced, and Z for zombied. |
| TIME | The CPU time a task has used since it was started. |
| %CPU | The CPU time a task has used since the last update. |
| %MEM | A task's share of physical memory. |
| COMMAND | The task's command name. |

> **Note**
> 
> A task's command name is truncated if the tasks only have the program name in parentheses.
