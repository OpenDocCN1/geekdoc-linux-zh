# Partition Disks and Make Filesystems

Now that you are on the network, the remainder of the work can be done remotely. Because you have included sfdisk on your boot floppies and you are not currently using the hard drives, you can now partition the boot disk and make the filesystems and swap spaces you will need to proceed with the install. This is accomplished using the script in Listing 3.2, which connects to the machine you have booted from floppies, runs the sfdisk command to create partitions on the target host boot drive, and then runs mk2fs to create filesystems on the new partitions. In addition, if you have specified the creation of a swap partition, the script runs mkswap to initialize it.

#!/usr/bin/perl

use Getopt::Std;
use Net::Ping;

$USAGE = "Usage: dprepare -t host -p pfile -b bdev [-c]\n"
    . "or dprepare -h\n\n"
    . "  -t host    host to partition and create filesystems on\n"
    . "  -p pfile   name of file containing partition information\n"
    . "  -b bdev    device name of boot drive\n"
    . "  -c         check for badblocks when creating filesystems\n"
    . "  -h         print this usage statement\n";

# Parse the arguments
getopts('t:p:b:ch');

# Give the usage statement if the ask for it
if (defined $opt_h) {
    print $USAGE;
    exit 1;
}

# Print a usage statement if required arguments are missing
if ((!defined $opt_t) || (!defined $opt_p) || (!defined $opt_b)) {
    print "No target, partition file or boot device specified.\n";
    print $USAGE;
    exit 1;
}
