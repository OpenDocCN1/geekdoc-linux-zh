# Expressions

Expressions are a core concept in shell scripting. Simply put, an expression is a statement that has a value associated with it. That value can be used to control program flow. An expression can have two types of values: a true value or a false value. An example of an expression under bash is simply the value of a variable. A variable that has not been set will have a value of false when evaluated, whereas if that variable contains anything, it will have a value of true. Within a system administration environment, you probably want to track things like the number of files and the amount of disk space in use by some or all of your users. You could then warn them when they approach preset limits.

Testing the values of expressions and combinations of expressions is a common operation in shell scripts. The test utility is provided to determine the value of expressions, and bash provides operators for use in performing tests on files and strings.

# The test Utility

The test utility allows you to test the value of any expression. It has the following syntax:

```
$ test expression
```

test will return a zero if the expression evaluates to true, or it will return a non-zero value if the expression evaluates to false. The return value of test is generally used in control structures for branching purposes.
