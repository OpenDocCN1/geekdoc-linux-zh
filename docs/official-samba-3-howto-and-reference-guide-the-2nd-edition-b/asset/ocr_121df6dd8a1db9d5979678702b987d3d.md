# 44.2.1 Generating the Certificate Authority

In order to create the relevant certificates, we need to become our own Certificate Authority (CA). ² This is necessary, so we can sign the server certificate.

We will be using the OpenSSL ³ ⁴ software for this, which is included with every great Linux™ distribution.

TLS is used for many types of servers, but the instructions⁵ presented here, are tailored for OpenLDAP.

![](bbox=[0.08, 0.49, 0.87, 0.58])

First we need to generate the CA:

```
root# mkdir myCA
```

Move into that directory:

```
root# cd myCA
```
