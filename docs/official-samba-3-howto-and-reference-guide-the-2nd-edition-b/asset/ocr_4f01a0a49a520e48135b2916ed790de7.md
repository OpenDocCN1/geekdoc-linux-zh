# 38.1.2 Tcpdump

Tcpdump $ ^{1} $ was the first UNIX sniffer with SMB support. It is a command-line utility and now, its SMB support is somewhat lagging that of **ethereal** and **tethereal**.

# 38.1.3 Ethereal

Ethereal $ ^{2} $ is a graphical sniffer, available for both UNIX (Gtk) and Windows. Ethereal's SMB support is quite good. For details on the use of **ethereal**, read the well-written Ethereal User Guide.
