# 关于封面艺术作品

本书的封面艺术作品延续了“官方 Samba-3 操作指南与参考手册”第一版的自由主题。我们可以回首过去，质疑前辈们的动机。我们很少意识到，过去对我们欠下的任何答案，尽管我们可能如何看待那些在我们之前走过人生之路的人的行动，但我们必须对那些在过去保护我们自由的人感到自豪和感激。

信息技术的发展继续以惊人的速度前进。人性使我们去采纳和拥抱那些似乎能解决当下需求的新发展，但它们可能会在未来束缚住我们。在信息技术的简短历史中有很多这样的例子。MS-DOS 曾被视为一种解放用户摆脱大型计算机系统高昂运营成本束缚的工具，并使我们受益至今的快速进步成为可能。然而，今天我们倾向于轻视 MS-DOS，视其为一项过时的、束缚性的技术，属于最好被遗忘的时代。

近年来对 Windows 网络、Windows NT4 和 MS 活动目录的拥抱，在今天看来可能很现代和进步，但迟早会有更好的东西取代它们。当前对扩展身份管理解决方案和目录的痴迷并不出人意料。那一天终将到来，这些也将被评估，看似令人耳目一新和强大的东西，可能会更好地被识别为夜晚寒冷的风。无论前方有什么，反对进步都是不可想象的。

Samba 的开发正在向前推进。自 Samba 3.0.0 以来的变化令人惊叹，但许多用户希望看到更多更快的开发。近期发展的好处可以很快实现，但文档是打开潘多拉魔盒的必要条件。我们希望这本书能帮助网络管理员以最小的努力快速部署新功能。当你部署并从新启用功能中获益时，花点时间思考前方可能有什么。最重要的是，盘点 Samba 在你的世界中提供的选择自由，并享受无缝互操作性的新潜力。
