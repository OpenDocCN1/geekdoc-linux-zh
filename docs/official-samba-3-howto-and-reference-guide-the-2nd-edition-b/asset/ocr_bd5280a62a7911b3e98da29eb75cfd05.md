# 8.2.2 Joining a Domain: Windows 2000/XP Professional

Microsoft Windows NT/2000/XP Professional platforms can participate in domain security. This section steps through the process for making a Windows 2000/XP Professional machine a member of a domain security environment. It should be noted that this process is identical when joining a domain that is controlled by Windows NT4/2000x as well as a Samba PDC.

+   1. Click Start.
+   2. Right-click My Computer, then select Properties.
+   3. The opening panel is the same one that can be reached by clicking System on the Control Panel. See Figure 8.15.
+   4. Click the Computer Name tab. This panel shows the Computer Description, the Full computer name, and the Workgroup or Domain name. Clicking the Network ID button will launch the configuration wizard. Do not use this with Samba-3. If you wish to change the computer name or join or leave the domain, click the Change button. See Figure 8.16.
+   5. Click on Change. This panel shows that our example machine (TEMPTATION) is in a workgroup called WORKGROUP. We will join the domain called MID-EARTH. See Figure 8.17.
+   6. Enter the name MID-EARTH in the field below the domain radio button. This panel shows that our example machine (TEMPTATION) is set to join the domain called MID-EARTH. See Figure 8.18.
