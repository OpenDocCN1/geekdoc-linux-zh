```
root# /usr/local/samba/sbin/winbindd -B
```

I'm always paranoid and like to make sure the daemon is really running.

```
root# ps -ae | grep winbindd
```

This command should produce output like the following if the daemon is running.

```
3025 ?       00:00:00 winbindd
```

Now, for the real test, try to get some information about the users on your PDC:

```
root# /usr/local/samba/bin/wbinfo -u
```

This should echo back a list of users on your Windows users on your PDC. For example, I get the following response:

+   CEO\Administrator
+   CEO\burdell
+   CEO\Guest
+   CEO\jt-ad
+   CEO\krtbgt
+   CEO\TsInternetUser

Obviously, I have named my domain “CEO” and my winbind separator is “\”. You can do the same sort of thing to get group information from the PDC:

```
root# /usr/local/samba/bin/wbinfo -g
```

+   CEO\Domain Admins
+   CEO\Domain Users
+   CEO\Domain Guests
+   CEO\Domain Computers
+   CEO\Domain Controllers
+   CEO\Cert Publishers
+   CEO\Schema Admins
+   CEO\Enterprise Admins
+   CEO\Group Policy Creator Owners
