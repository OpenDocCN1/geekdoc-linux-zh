# ## 20.6.2.9 Running rpcclient with setdriver

Samba needs to know which printer owns which driver. Create a mapping of the driver to a printer, and store this information in Samba's memory. The **rpcclient setdriver** command achieves exactly this:

```
root# rpcclient -U'root\\xxxxx' -c 'setdriver dm9110 mydrivername' SAIMBA-CUPS
cmd = setdriver dm9110 mydrivername
```

Successfully set dm9110 to driver mydrivername.
