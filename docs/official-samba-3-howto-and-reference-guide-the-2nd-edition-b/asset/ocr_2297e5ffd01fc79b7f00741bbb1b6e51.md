# ### 21.11.4 Requirements for adddriver and setdriver to Succeed

From the man page (and from the quoted output of \texttt{cupsaddsmb} above) it becomes clear that you need to have certain conditions in order to make the manual uploading and initialing of the driver files succeed. The two \texttt{rpclient} subcommands \textbf{adddriver} and \textbf{setdriver} need to encounter the following preconditions to complete successfully:
