Remember, for browsing across subnets to work correctly, all machines, be they Windows 95, Windows NT, or Samba servers, must have the IP address of a WINS server given to them by a DHCP server or by manual configuration: for Windows 9x/Me and Windows NT/2000/XP, this is in the TCP/IP Properties, under Network settings; for Samba, this is in the **smb.conf** file.

It is possible to operate Samba-3 without NetBIOS over TCP/IP. If you do this, be warned that if used outside of MS ADS, this will Fargo network browsing support. ADS permits network browsing support through DNS, providing appropriate DNS records are inserted for all Samba servers.
