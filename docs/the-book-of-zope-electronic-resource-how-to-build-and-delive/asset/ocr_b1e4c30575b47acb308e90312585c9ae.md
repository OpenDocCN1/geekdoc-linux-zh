# REQUEST Object Attributes (continued)

| Attribute Name | Explanation | Example | Screen Output |
| - | - | - | - |
| cookies | Displays the values set as cookies in the form of a dictionary. | "REQUEST.cookies" | ('trees':; 'elZjTifZ3hANWP/VYUHOALEYIEA', 'dtpref_rows': '10', 'dtpref_calcs': '5') |
| form | The result is the values set by a form in dictionary format. | "REQUEST.form" (['fields']") | { 'field1': 'hello', 'myfield': 'you' } |
| has_key(name) | Returns 1 if the specified variable name is contained in the REQUEST; returns 0 if the specified variable is not contained in the REQUEST. | "REQUEST.has_key('U RLO')" "REQUEST.has_key('U RL9')" | 1 (because URL is contained in the REQUEST) 0 (because URL9 is not contained in the REQUEST) |
| set(name, value) | Sets a variable in REQUEST with the specified name and value. | "REQUEST.set('myvar','content of myvar')" | |
| get(name,default=[]) | Retrieves a variable by name from REQUEST and optionally allows you to specify a default value if the variable is not set. | "REQUEST.get('myvar',' '')" | The value stored in myvar or an empty string if myvar is not set |

# RESPONSE Object Attributes

| Name | Explanation |
| - | - |
| setStatus(status) | Sets the HTTP status code of a query; the argument can be an integer or a string (OK, Created, Accepted, NoContent, MovedPermanently, MovedTemporarily, NotModified, BadRequest, Unauthorized, Forbidden, NotFound, InternalError, NotImplemented, BadGateway); this will be converted into an integer value. (See "HTTP Status Codes below.") |
| setHeader(name, value) | Sets a HTTP-Return-Header-Name with a value and deletes any previous value set for the header. |
| get() | Gives the current HTTP.Status-Code an integer. (See "HTTP Status Codes below.") |
| setBase(base) | Sets the base URL for the returned document. |
| expireCookie(name) | Removes a http cookie from the browser. The response contains a HTTP-Header that removes the cookie called "name" if it exists by sending a new cookie with an elapsed expiration date. |
