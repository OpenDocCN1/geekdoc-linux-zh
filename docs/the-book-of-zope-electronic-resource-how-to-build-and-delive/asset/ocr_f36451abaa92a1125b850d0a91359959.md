# 4.2.3 Abbreviating Attributes

Two special attributes, name and expr, can be assigned to virtually any HTML tag. There is a standard way to abbreviate each. For example, we could abbreviate the use of name in our earlier example—which was shown as

```
<html-var name="AUTHENTICATED_USER" capitalize>
```

to

```
<html-var AUTHENTICATED_USER capitalize>
```

To use the abbreviated form, omit the name attribute label, the equals sign, and the quotation marks. The first piece of information in the tag is automatically regarded as the name's value. The expr attribute (used to evaluate complex expressions) takes a similar approach, as shown below:

```
<html-var expr="1+1">
```

is abbreviated

```
<html-var "1+1">
```

NOTE An expression must always be contained within quotation marks.

Because the quotation marks are retained, the term between the quotation marks is regarded as an expression of the expr attribute.

NOTE Although it is common to see these abbreviated notations for name and expr, they are discouraged in favor of the more explicit forms. Although choosing not to abbreviate requires more typing, the resulting code is easier to read and debug.
