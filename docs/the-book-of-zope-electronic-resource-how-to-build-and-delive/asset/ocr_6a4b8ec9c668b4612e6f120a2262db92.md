# 10.1.2 Creating Objects with ZClasses

Before we test our ZClass, we need to create a folder to contain our Book instances. Here's how:

+   1. Open the root folder and create a folder by selecting Folder from the add menu.
2. Enter Books in the Id field, remove both check marks from the checkboxes, and click Add.
3. Open your new folder and select Book from the add menu (or ZClass meta type specified in section 9.3.2).
4. The input form from the DTML method BookClass_addForm enters. Enter the data for a book and click Create, as shown in Figure 10-3.
