# #### String Constants

| Attribute | Constants |
| --- | --- |
| digits | The string 0123456789 |
| hexdigits | The string 0123456789abcdefABCDEF |
| lowercase | Produces a string that contains all lowercase letters, for example abcdefghijkmnopqrstuvwxyz |
| uppercase | Produces a string that contains all uppercase letters, for example ABCDEFHIJKLQRSTUVWXYZ |
| letters | Produces a string composed of the partial string lowercase and uppercase. |
| whitespace | Produces string that contains only characters regarded as white spaces, specifically: space, tab, line feed (line break), return, form feed (page break), and vertical tab.
