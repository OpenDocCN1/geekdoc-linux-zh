# 4.3.13 The MIME tag and the boundary Tag

Often you will need to email only text messages but also file attachments. To send attachments, you will need to use the MIME tag and one or more boundary tags, which are only permissible within the sendmail tag.

When you insert a MIME tag, the content of the message you are sending activates to multipart/mixed so that files can be attached to the email using the boundary tags. The MIME tag is a non-empty tag and contains the required boundary tags.

The start MIME tag must be inserted on the last line header with no spaces between it and the subject header. You can use the MIME attributes to specify the message properties. If you want to send only files but no message text, you can omit the MIME attributes, as shown below:

```
<html-var standard_html_header>
<html-sendmail host="MailHost">
from: martina@beehive.com
two: martina@beehive.com
subject: Requested
<html-mime type="text/plain" encode="7bit">
```

nA boundary tag for each file to be sent follows the message text, organizing its transport. The MIME and the boundary both use the same optional attributes, which are listed in Table 4-16. The file(s) to be sent are inserted in a var immediately after the boundary tag (there must not be any blank spaces).

# Table 4-16: Attributes for the MIME Tag and the boundary Tag

| Attribute | Function | Example |
| --- | --- | --- |
| type | Indicates the type and format of the data. The default value is application/octet stream. | Type="image/bmp" |
| disposition | Sets the content disposition of the following data. If the disposition is not specified in a MIME or boundary tag, the content disposition MIME header is not inserted into the message. | disposition="attachment" |
| name | Indicates the name of the file object to be attached. If the name is used in the MIME tag, the message is sent as attachment and not as standard text. | name="wordfile" |
| encode | Sets the encoding method for the files to be sent. The default value is base64, which is suitable for sending binary files to most mail clients. The following options are available: base64, uuencode, x-uuencode, quote-printable, u-xue, and 7bit. If set to 7bit, no encoding is applied. This is appropriate for textual document formats such as HTML. | |
