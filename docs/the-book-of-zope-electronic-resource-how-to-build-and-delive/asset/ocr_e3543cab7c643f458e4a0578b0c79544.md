+   4. The SQL statement sends the SQL statement to the database backend
using a database adapter.
5. The backend database executes the SQL statement and returns the results (if
any) to Zope via the database adapter.
6. The Z SQL method receives the results from the database adapter and
returns them to the form's target object.
7. The form's target object displays the results or takes action based on them.
