You can now start your web browser and access the Zope server by entering the following URL:

```
http://linuxserver.mycompany.com:8080
```

at which point the screen shown in Figure 1-4 should appear. Click the management screen link for the log-in screen shown in Figure 1-1.
Alternatively, you can enter:

```
http://linuxserver.mycompany.com:8080/manage
```

to directly access the log-in window and bypass the "Welcome to Zope" screen.
You have now installed a Zope server on your computer and, depending on the type of installation, you can access it via the Web or only through the local network.
