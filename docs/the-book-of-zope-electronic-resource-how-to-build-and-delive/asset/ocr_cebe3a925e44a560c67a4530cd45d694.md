# Zope Quick Start

Zope is a high-performance object-oriented platform for building dynamic web applications. Here are some quick things to get you started:

+   - Read The Manual: This document guides you through the whole process of learning Zope from logging on to mastering your web applications.

+   - There is a built-in Zope Tutorial with many simple tasks to help you learn Zope functionality from the add-lets. Click the Add button to begin working with the tutorial.

+   - Visit the main Documentation at zope.org, where you will find tutorials and community resources.

+   - Look at the FAQs about Zope: The faq lists are where you can get quick answers-help from a large community of Zope users from around the world.

+   - Browse and search the Internet: Our online system withed content on the various topics and features of Zope.

+   - Use the Zope Management Explorer: easy start with Zope right away. NOTE: Some versions of Internet Explorer (specifically IE 5.0 and early versions of IE 5.5) may have problems displaying Zope management pages. If you have these problems, try upgrading your IE installation to the latest release version, or use a different browser.

+   - Find out about Digital Creations: the publishers of Zope
