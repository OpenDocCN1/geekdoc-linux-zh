Let's look at Lines 24 through 28 in detail, which insert available photos for the Book. Because a Book is a folderish object, its images can be contained inside the Book itself.

To display images, we use a dtml-loop on the value returned by the method objectValues (Line 24). Remember that this method returns a list of the objects contained by a folder or folderish object, and the first dtml- (Line 14), which loops through the Book objects in the books folder, places each Book instance at the top of the namespace in turn. This means that our dtml- (Line 24) calls objectValues on the Book instance, whereas the first dtml- (Line 14) calls objectValues on the books folder (whichever folder this method is being called for).

As you can see in this example, the namespace has as much to do with the behavior of your DTML code as anything else. To avoid many errors and bugs in DTML code, pay close attention to the current state of the namespace stack.

This page uses dhtml-email to email you the customer's order. One special case is the select list in OrderForm_html:

```
<SELECT size="20" NAME="order:list">
```

This field differs from the rest because it has "list" at the end of it, which tells Zope to convert the value submitted from the browser into a list. In this case, this is the list of Book selected. Because the value for order is a list, we use dmlin to iterate it (Line 12) and look up the information about the Books selected (Line 13). (The lookup is necessary because only the ids are passed from the form to the Order_html method.). To retrieve the other properties of each Book, we use dml with sequence-item as its argument (which contains the id of each Book). Using the namespace, it returns the Book instance, and dwith puts the instance at the top of the namespace. In the dtml-block (Lines 14–19), simple dtml-var insert the property values of each Book instance.

## 10.4.3 Sending the Order

To email the customer's order to you, we add a mail host to the Books folder to specify the mail server responsible for sending the email. The mail host's management screen is shown in Figure 10-13.

![](img/43a28cce5475b2f487bf455365567fb6_219.png)

Enter a title to describe this object if you use it, enter the Internet name of the SMTP server you will use to deliver your mail. (If you don't know this information, check with your system administrator or check the configuration of your own email software). Then click on Add.
