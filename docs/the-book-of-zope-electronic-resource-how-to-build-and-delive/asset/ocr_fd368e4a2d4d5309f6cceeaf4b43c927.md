# 1.2.2 SQL = Structured Query Language

SQL, the Structured Query Language for databases, can also be used directly in Zope provided a suitable database adapter (DA) has been compiled beforehand. This feature allows database developers to decide how much program logic to store in the database and how much to store in the Zope server.

# 1.2.3 Python

Because Zope is mainly written using Python, it can communicate relatively easily with Python modules or programs. This feature gives Zone programmers instant access to hundreds of program modules that make it easy, for instance, to create PDF or graphics files.

# 1.3.1 Open Source Software

Zope differs significantly from commercial products. For one thing, nobody claims Zope is a product that you simply unpack, press a button, and have running with a mouse click. In fact, to date there is no thing as a ready-to-go, out-of-the-box CMS solution.

Two of Zope's major benefits in comparison with other content management systems are the facts that it is object-oriented and that it is an open source software. As object-oriented software, knowledge developed within an organization for a CMS can be quickly used to develop a portal or extranet.
