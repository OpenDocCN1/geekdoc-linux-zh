To create our homepage, we first create a folder (see Figure 8-2) called My_Homepage. When creating this folder, select both the create public interface and Create user folder options to automatically add an index_html DTML document and an acl_users folder.

We want to give our friend Egon special permissions to access functions unavailable to Anonymous users. To do so, we create a new user called Egon (with the role Friend and a user-defined password) in the User Folder (acl_users) for the My_Homepage folder, as shown in Figure 8-3. (To create the Friend role, use the folder's Security tab.)
