# ### 3.1 The Zope Tab Bar

The tab bar provides access to several interfaces you can use to configure Zope objects, specify basic settings, and so on. Its functions and tabs vary depending on the selected object and the permissions assigned to the current Zope user.
Let's have a look at the tab bar's basic functions.
