# In Line 4 ("for key in theDocsKey"), the terms "key" and "keys" play two

different roles: "key" is for the loop variable (which can have any permissible variable name
choose), whereas "keys" used in "theDocsKey" is a method of the dictionary
returns the keys as a list; you must use this method name for the loop to function correctly.

The dictionary's individual keys identify the desired ids for the DTML method-
ods (for example, standard_html_header), which are passed to the method
DocsToFolder using the "key" variable.

In our case, the values for each key are tuples. The first element of a tuple is
the DTML object created from the appropriate .dml file in the public subdire-
tory the project directory (created by calling the method GetDTML() defined
in Listing 15-2). The second element of each tuple indicates the title to be
to the DTML method in Zope (for example, "Website Standard Header").

To use the method addDocsToFolder() to create the desired DTML methods
in an instance of our project, we need to pass the instance as the value for the
argument Folder; you'll see when we actually call the method in the Website
product (See section 15.4.4).

In general, the method addDocsToFolder() does the following:

+   For each individual key passed in the dictionary
addDocsToFolder() attempts to read the corresponding .dml file. If the file
cannot be read, addDocsToFolder() assumes that the file does not exist at the
specified location, and an error message appears ("Can't find...").
