| Attribute | Function | Example | Output |
| --- | --- | --- | --- |

| act(number) | Presents a number as an octal number. | \..oct(5)", \..oct(8)" | 0x5 0x10 |
| ard(letter) | Returns the ASCII number "..ord('a')" of a character. | | 97 |
| math | See "The Math Module" under section 4.3.2.2; attributes are shown below. | | |
| whrandam | See "The Whrandam Module" under section 4.3.2.2; attributes are shown below. | | |
| string | See "The String Module" under section 4.3.2.2; attributes are shown below. | | |
| range[count[, step]] | Returns a list of count integers (generally used for looping) starting at start (default 0) and incrementing by step (default 1). | \..range(4) | [0,1,2,3] |
| raound(number, decimal places) | Rounds a number to a specified number of decimal places. | \..round(2.1234, 2)" | 2.12 |
