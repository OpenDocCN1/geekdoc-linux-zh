## 13.5 Classes and Methods

The following section will show how to define a class with your own attributes and methods how to derive (or instantiate) objects. The principle of inheritance will also be introduced.

### 13.5.1 Example: Creating a Class

A class definition is preceded by the class keyword, as follows:

```python
class animal:
```

The class definition can then be followed by a constructor method: `__init__()` (two underscores on each side). The constructor method is called every time an instance of the class is created and is often used to set up the new instance in an initial state. For example, instance variables can be initialized in a constructor method and, if necessary, used to set up an initial value, as shown in Listing 13-2. The def statement defines a Python method.

Listing 13-2: The Animal class with the constructor method `__init__`

```python
class animal:
    # Animal Class
    def __init__(self, age, gender):
        """Constructor Method"""
        self.age=age
        self.gender=gender
        self.awake=1
```

The constructor method shown in Listing 13-2 says that an age and a gender must be provided for each instance of the Animal class (Lines 3, 5, and 6). In addition, each argument is automatically regarded as awake (Line 7).

The first argument of the constructor, `self`, where Python passes the current instance of the class to the method. When the method needs to examine or manipulate the current instance of the class, you use the `self` argument as in Lines 5 through 7, where we assign three new attributes to the instance. The `self` argument is placed first in the argument list of the method; Python automatically passes this argument when it is called.

Lines 2 and 4 contain a special comment called a doc string, which describes the class and method. A triple-quoted string is normally used immediately after a class or method (as in Line 4 above) so that a multiline doc string be specified if necessary. The doc string is mandatory for a class's method to be accessible from Zope, and if it is not included, an error message appears if you attempt to call it from Zope.

Listing 13-3: The sleep() and wakeUp() methods for the Animal class

```python
def sleep(self):
    """The animal is sleeping"""
    self.awake=0
    print 'ZZZZZ'
def wakeUp(self):
    """The animal is awake"""
```

At this point, we can't do very much with the Animal class except to create Animal objects that have a name and a gender and are either awake or sleeping. This is simply not a detailed enough description of the real animal world.

### 13.5.1 Creating Subclasses

To better represent the real animal world, we must create additional classes, known as subclasses, of the Animal class. These subclasses assume all the attributes of the Animal class (including name, gender, awake, `__init__`, sleep, and wakeup) through *inheritance*, and can add their own attributes.

Subclasses inherit the attributes of their base class and expand upon them. Instances of different subclasses share particular attributes they inherit from the same base class.

Let's create two subclasses as an example: the Reptile class and the Bird class. Objects in both classes inherit the same basic attributes from the Animal class and will also have other, new attributes, such as fly and swim.

Subclasses are defined like base classes except that the name of the base class appears in parentheses after the class description.

The Reptile class is defined as shown in Listing 13-4.

Listing 13-4: The Reptile class: a subclass of the Animal class

```python
class reptile(animal):
    """Reptiles"""
    def swim(self):
        """The reptile swims"""
        if self.awake:
            print 'paddle paddle splish splash'
```

The Bird class is defined as shown in Listing 13-5.

Listing 13-5: The bird class: a subclass of the Animal class

```python
class bird(animal):
    """Bird"""
    def fly(self):
        """The bird flies"""
        if self.awake:
            print 'flap flutter'
```

### 13.5.2 Creating an Instance

To instantiate a class, we use the class name followed by parentheses containing the arguments. For example:

```python
my_animal = animal(5, 'female')
```

Once we have an instance, we can access its attributes using the dot notation:

```python
print my_animal.age
print my_animal.gender
```

We can also call the methods of the instance:

```python
my_animal.sleep()
my_animal.wakeUp()
```

## 14 SCRIPTING WITH PYTHON

Zope provides two facilities to integrate Python functions directly into Zope: Zope Python scripts and external methods. Using the techniques introduced in this chapter, you can code complex logic directly in Zope, such as DTML documents and methods.

### 14.1 Zope Python Scripts

Zope Python scripts are a feature of Zope 2.3 and newer. They allow you to include Python code directly inside Zope through the management screen, like DTML. Although there are some restrictions on the built-in functions and Python modules you can access, Python scripts are an extremely powerful way to code complex logic for your Zope application.

Some of the things you cannot do with Python scripts include accessing files on the file system, calling system programs, importing arbitrary modules, and calling restricted Python methods. To do these things you will still need to use an external method or Python product (described in section 14.2 and Chapter 15). You can, however, call any other unrestricted methods or objects, perform complex calculations or data manipulation, and import select Python modules.

### 14.1.1 Creating Python Scripts

You create a Python script as you do other Zope objects by using the folder's menu; in the menu, select Script (Python). On the form that appears, specify an id, an optional title, and an optional file containing the Python code to be uploaded to the script. Then click on the Add button to create the script object, as shown in Figure 14-1.

Once you have created your script, you should see the management screen shown in Figure 14-2. The first three management screen tabs—Edit, Bindings, and Test—are specific to Python scripts.
