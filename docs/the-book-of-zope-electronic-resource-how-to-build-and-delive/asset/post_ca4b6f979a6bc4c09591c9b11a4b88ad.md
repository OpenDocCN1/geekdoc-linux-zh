
## 12.3.3 Creating the Data Table with MySQL Monitor

You can create data tables in a database using either the MySQL monitor or using Zope. Because you have not connected Zope with MySQL, use the MySQL monitor to create the tables. (Section 12.3.5, "Establishing a MySQL Connection from Zope," discusses how to create tables in the MySQL database from Zope, without the MySQL monitor.)

User data will be stored in a table called "user," which should contain these fields:

| userid | zipcode |
| :--- | :--- |
| firstname | city |
| lastname | telephone |
| address | |

To create the user table, enter the following SQL statement:

```sql
CREATE TABLE user (
  userid INT(12) NOT NULL,
  firstname CHAR(20) NOT NULL,
  lastname CHAR(20) NOT NULL,
  address CHAR(20) NOT NULL,
  zipcode INT(5) NOT NULL,
  telephone CHAR(15) NOT NULL,
  PRIMARY KEY(userid)
);
```

The above SQL code creates the table user using the CREATE TABLE SQL statement. Lines 2–8 specify the fields in the table. The first column of each line is the field name, the second is the data type, and the last column describes any constraints on the table. The last line specifies that the field userid is the record's primary key—that is, its unique identifier. No two user records can have the same primary key value.

Now enter the command

```bash
mysql show tables;
```

to see whether the user table has been created properly. If it has, you should see the following:

| Tables in myDB |
| :--- |
| user |

1 row in set (0.00 sec)

## 12.3.4 Installing the Database Adapter ZMySQLDA

Before Zope can communicate with the myDB database, you must connect to the MySQL server using a database adapter, which is the interface between myDB and Zope. We will install the database adapter ZMySQLDA.

Before you begin your installation, download the files listed in Table 12-1, which includes ZMySQLDA, the database adapter itself, and the latest MySQL drivers.

To install ZMySQLDA under Linux, do the following:

- 1. Unpack the ZMySQLDA archive in the top directory of Zope installation. For example, if you installed Zope in the directory Zope-2.3, extract the archive into that directory. Extracting the archive creates a folder named "Zope-Directory/lib/python/Products/ZMySQLDA."
- 2. Unpack the MySQL drivers in the directory Zope-Directory/lib/python/Products. To do so, follow the installation instructions included with the product.
- 3. Restart Zope to make the changes effect.

## 12.3.6 Testing SQL Queries to Your Database

To test your database, formulate a query for the database to determine what records are contained in the user table. To do this, send the following SQL statement to the database:

```sql
select * from user
```

When you click the Test tab, you should see a screen like the one shown in Figure 12-4. In the Query field, enter the following SQL (as shown in Figure 12-4):

```sql
select * from user
```

Using this screen, you can submit SQL statements to your MySQL database from within Zope without having to switch to the MySQL Monitor.

![](img/43a28ce54752f48bf4553657fb6.png)

You can formulate various SQL statements in the Query field to query the database (as above), create a new table, or enter new data. And now that your database is connected to Zope, you can create the same table you created in Section 12.3.3 in the MySQL Monitor by entering the SQL statement for creating the user table in the Query field.
