# A.2.2.1 The in Tag

## Attributes for the in Tag

| Name | Explanation |
| --- | --- |
| name | The name of the variable that returns the sequence to be iterated. |
| expr | An expression that returns the sequence to be iterated. |
| mapping | The items of the sequence should be treated as mapping objects, such as dictionaries. Each key of each item is mapped to the namespace inside the block. |
| sort | The sort attribute is used to sort a sequence of objects before the sequence is iterated. The value attribute is the name of the attribute (or key if the mapping attribute is specified) according to which the items be sorted. |
| sort_expr | Like sort, allows the sequence to be sorted by the attribute or key name returned in an expression. This allows the sort order to be chosen at run time. |
| start | The name of a variable that specifies the starting sequence item of the current batch. If omitted, iteration starts at the first item. |
| size | The size of each batch of sequence items to iterate. If omitted, the entire sequence is iterated at once. |

| overlap | The number of items that overlap between batches. If omitted, there is no overlap. |
