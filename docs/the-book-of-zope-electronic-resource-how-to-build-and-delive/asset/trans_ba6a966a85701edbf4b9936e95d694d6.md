```html
<html-call "RESPONSE.redirect('index.html')">
```

如果用户未登录，`login_html` DHTML 方法将生成一个密码查询（如果用户已经登录，点击 [登录] 按钮将不会发生任何事情）。这是通过该 DHTML 方法的安全设置实现的。View（查看）权限被显式设置为仅“Manager（管理员）”和“User（用户）”，“Anonymous（匿名）”未获得此权限。
