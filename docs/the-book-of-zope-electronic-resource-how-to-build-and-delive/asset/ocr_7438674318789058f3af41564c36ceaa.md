# Table 4-1: Attributes for the var Tag

| Attribute | Function | Example | Output |
| --- | --- | --- | --- |
| null | Defines a string that will be output instead of "null". If the value for null is omitted, no text is inserted. | null="The result returns an empty list." | The result returns empty list. |
| missing | Defines a string to be inserted if the variable referred by name is not in the namespace. If the value for missing is omitted, no text is inserted. | missing = "Not found" | Not found |
| lower | Changes all letters to lowercase. | title_or_id lower | testpage |
| upper | Converts all letters to uppercase. | title_or_id upper | TESTPAGE |
| capitalize | Capitalizes the first letter. | AUTHENTICATED USER capitalize | Manager |
| html_quote | Characters significant in HTML are replaced with appropriate HTML entities. | teststring html_quote (teststring="<") | &lt; |
| url_quote | Characters not legal in URLs are properly escaped for insertion into values. | teststring url_quote (teststring="<") | %3c |
| size | Displays only the specified number of characters from a string. | teststring size=6 (teststring="How are you?") | How're... |
| elc | Specifies a string that is inserted instead of the omitted characters (used with size). | teststring size=6 etc="" (teststring="How are you?") | How're — |
| name* | See The "name Attribute" (section 4.3.1.2). | | |
| expr* | See The "expr Attribute" (section 4.3.1.3). | | |
| fmt* | See The "fmt Attribute" (section 4.3.1.4). | | |
