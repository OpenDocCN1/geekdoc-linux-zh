# 6.3.1.3 REQUEST.set for Creating Variables

To create a new user using this call, put the user's information into REQUEST
first, using the REQUEST.set command, which creates a variable in REQUEST
s saves the desired data into it. You can call this command from DTML as follows:

```
<dtml-call expr='REQUEST.set('name', 'Egon')'>
```

When call REQUEST.set, the variable name is entered first as a quoted
string value, followed by a comma and the variable's value (which in this case is
a quoted string).

With the name now set, all that REQUEST needs the password, the pass-
word confirmation, any applicable domains, and the role(s) for the new user.

The command looksหมือน for domains and roles because both
values are lists. A list is written as, comma-separated sequence of values between
square brackets ['item 1', 'item 2',...'item n']. The roles variable needs to be
set to a list of role names (as string values) for the user. Setting roles would be
coded as:

```
<dtml-call expr='REQUEST.set('roles', ['Manager', 'Owner'])'>
```

The complete code required to create a new user using DTML would look

<dtml-call expr='REQUEST.set('domains', []])'>
