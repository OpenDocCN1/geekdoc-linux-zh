If you specified a variable name for a namespace binding (see section 14.1.3 above), Zope will automatically pass any parameter values implicitly to the namespace when you call the Python script by name.

You can also use an expression to call a Python script with no parameter shown:

```
<html-var expr="pythonScript()">
```

However, if a parameter list was specified for the script, and you want to pass its values explicitly "..." notation must be used, with the parameter argument placed between the parenthesis as follows:

```
<html-var expr="pythonScript(arg1,arg2,...)">
```

In the above examples, the context-bound variable in the script will be set to whatever object is at the top of the DTML namespace. To specify a different object, use the dot notation when calling the script, which makes the script act as a method of the object specified. For example:

```
<html-call-expr="myObject.pythonScript(arg1,arg2,...)">
```

In the above example, the context variable would be bound to myObject when the script executes.

> NOTE For the above example to work, pythonScript must be in the acquisition path of myObject that myObject can acquire pythonScript from its namespace.
