## 1.5.3.6 Assign IP Addresses

You now need to assign an IP address to the Zserver, because you will no doubt want to access your Zope server using a specific WWW address at a later stage (for example, www.mycompany.com). To do this, either you or your ISP will need to enter this WWW address and the associated IP address in the name server entries.

For example, assume our web address is www.mycompany.com and our allocated IP address is 212.11.222.333. To assign this IP address to the Zserver, you'll need to make a number of changes to the start script, as discussed below.

## Start Script

The start script should look like this at present:

```
#! /bin/sh
reldir= dirname $0
PYTHONHOME= cd $reldir; pwd
export PYTHONHOME
Exec /usr/bin/python \
$PYTHONHOME/z2.py \
-D "$@"
```

Change this source code as follows:

```
#! /bin/sh
reld= cd reldir; pwd
PYTHONHOME=$PYTHONHOME
Exec /usr/bin/python \
  $PYTHONHOME/z2.py \
  -D "$8" -a 212.11.222.333 -f 8021 -u nobody -w 8080 -m
```

The following table explains the individual options:

| Option | Description |
| --- | --- |
| -a 212.11.222.333 | IP Address = 212.11.222.333 |
| -f 8021 | FTP to Port 2021 |
| -u nobody | Username = nobody |
| -w 8080 | HTTP Server on Port 8080 |
| -m | Monitor Server is switched off |

(For further information on the individual options, see the file z2.py in your Zope server directory.)
