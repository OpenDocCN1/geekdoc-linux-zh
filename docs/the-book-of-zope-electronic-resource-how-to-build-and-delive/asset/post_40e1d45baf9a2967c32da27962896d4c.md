- Select one or more searchable objects:
This list contains all searchable objects (ZCatalog, Z SQL methods) that can be acquired from the current folder (that is, those in the folder's namespace stack). You can select one or more searchable objects from this list.

- Report Id and Report Title:
These are the id and title of the search page to be created.

- Report Style:
This offers two options for presenting the results of the search: in tables or as records. The former displays each object found on a row of a table with each metadata element in its own column. The latter displays the metadata of each object on a line separated by commas.

- Search Input Id and Search Input Title:
Use these fields to specify the id and title for the search page, which is form for users to provide the criteria to search the ZCatalog.

## 11.3.3 Batch Size

The standard generated pages show 50 results per selected ZCatalog or Z SQL method. In other words, the standard batch size is 50. If there are more than 50 results, Next and Previous links appear, which allow you to navigate the results (as shown in Figure 11-16).

| Title | Meta type | Id | Base modification time | Data record id |
|---|---|---|---|---|
| Installed product Standard&CacheManagers | Product Standard&CacheManagers | 2000/05/20 22:30:31 GMT+2 | -44784125 |
| Installed product Size:Access | Product Size:Access | 2000/05/20 22:30:31 GMT+2 | -44784128 |

![](img/43a28cce5475b2f487bf455365567fb6_235_0.png)

Figure 11-16: Pages with displayed results and Previous and Next links

To change the number of results displayed, simply replace the batch size of 50 with the number of results you want displayed in the line of the result DTML method (and in other lines if there is more than one result object):

```html
<dtml-in ZCatalog size=50 start=query_start>
```

If you have several searchable objects, you may need to change the batch navigation logic by renaming the query_start variable for each (for example, query_start1, query_start2, and so on). The query_start variable determines the starting point for each batch displayed. Creating separate ones will prevent the next 50 results being displayed for each searchable object you want to display for only one object.

Remember to change the variables in all relevant locations in the source code. The other locations in addition to size in the in-tag include the Previous and Next links created.
