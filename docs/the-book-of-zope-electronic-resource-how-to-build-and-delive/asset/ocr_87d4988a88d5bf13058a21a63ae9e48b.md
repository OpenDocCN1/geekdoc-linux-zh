New keys and corresponding values can be directly assigned to a dictionary.
You can use the keys method of a dictionary to return a list of the dictionary's keys.
The table below shows how Python dictionaries are created and manipulated:

| Example | Result of Evaluation |
| --- | --- |
| { } | The dictionary is empty, and nothing is output to the screen. |
| {'Goethe':1, 'Schiller':2, 3:4} | {'Goethe':1, 'Schiller':2, 3:4} |
| {1:'ugh', 2:'inter':'net'} | {1:'ugh', 2:'inter':'net'} |
| d = {1:'fair', 2:'good'} | {1:'fair', 2:'good', 3:'excellent'} |
| d[3] = 'excellent' | |
| d = {1:'one', 2:'two', 3:'three'} | (The order is arbitrary). |
| d.keys() | [2,3,1] |
