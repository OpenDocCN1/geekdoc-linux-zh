Debugging is often a programmer's least favorite task. However, because everybody makes mistakes, the process of debugging is unavoidable for all programmers.

This chapter explores the general concept of debugging and then looks at two debugging topics specific to Zope.

# 16.1 Errors When Starting the Zope Server

When you start a Zope server, a number of errors may cause the Zope process to terminate or run incorrectly, as follows:

```
Error Value: Invalid python version
```

Explanation: The Zope server is incompatible with the Python version you are using. This error is specific to UNIX because, under UNIX or UNIX-like operating systems, Python is not integrated into Zope, and in this case, you are using a version of Python that is invalid for use with Zope.

Solution: Update your version of Python. (Windows versions of Zope are supplied with Python.)
