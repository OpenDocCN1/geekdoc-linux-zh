_searchable_arguments(self)
This method can be used only in Python, in products, or in external methods.
returns a dictionary with all searchable indexes: for example:

```

'meta_type': {'optional': 1},
'id': {'optional': 1},
'summary': {'optional': 1},
'bobobase_modification_time': {'optional': 1}}
```
