The following example displays a tree view containing all subordinate objects and additional image files inside Folder1.

```
| 1: | <dtml-var standard_html_header>
| 2: | <image Files/>
| 3: | <dtml-call expr="REQUEST.set('expand_all',1)">
| 4: | <dtml-tree name="Folder1" branches="objectValues">
| 5: | <dtml-if expr="meta_type == 'Image">
| 6: | <IMG SRC="dtml-var name="icon">
| 7: | <a href="dtml-var name="tree-item-url"><dtml-var name="id"></a>
| 8: | <dtml-else>
| 9: | <IMG SRC="dtml-var name="tree-var id">
| 10: | </dtml-if>
| 11: | </dtml-tree>
| 12: | <dtml-var standard_html_footer>
```

On Line 3, the `expand_all` variable is set to true by calling `REQUEST.set` to instruct the tree tag to expand all of its branches down to the leaves by default. The tree tag is opened (Line 4) and Folder1 is specified as the folder for the tree to recurse. The branches attribute of dtml-tree is set to objectValues (a method that returns all objects in a folder) in place of the default methodValues (which returns only folder objects).

Inside the tree body, we check to see if the current object is an image using dtml-if (Line 5) to test the value of its `meta_type`, an attribute of All Zone objects. If the object is an image, we display its icon and construct a link to it using the variable tree-item-url supplied by the tree tag (Lines 6 and 7); otherwise only the icon and object id are inserted (Line 9). The body of the tree tag is then closed (Line 11). Figure 4-10 shows the rendered output of the document.
