6. If everything worked, open the File menu and select New.

+   host The name of the Zope server you want to access.
port The port number on the Zope server.
site path The path, if the user only has access to a specific folder (for example: www.behive.de/PR/) or a slash (/) for the root folder.
username Your username.
password Your password.
