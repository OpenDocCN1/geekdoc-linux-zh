The Contents view lets you create, rename, copy, move, and delete objects using the buttons at the bottom of the screen, as follows:

+   * **Rename** Changes an object's id. See section 2.3.7, "Renaming Objects."
* **Cut** Moves objects. See section 2.3.10, "Moving Objects."
* **Copy** Copies objects. See section 2.3.8, "Copying Objects."
* **Paste** Pastes objects.
* **Delete** Deletes objects. See section 2.3.9, "Deleting Objects."
* **Import/Export** Imports (in Zope versions later than 2.2.2) or exports on object. See section 3.1.9, "The Import/Export Tab."
* **Select All** Selects all objects in the folder (in Zope versions later 2.2.2).

When you click a folder object, its Contents view appears; when you click a nonfolder object, the Edit screen appears. The Contents view's Add Objects menu lets you add new objects to the folder.

# 3.1.2 The Edit Tab and Edit Screen

You can edit nonfolder Zope objects on the Edit screen, including the title and source text of DTML methods and documents. You cannot edit objects such as images or files, though you can change their titles and upload newer versions of the object in most cases. Other objects have different edit screens corresponding to their specific contents.
