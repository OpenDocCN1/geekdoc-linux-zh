# 8.3.4 Assigning Permissions for login_html

Several permissions may be needed in order to successfully render a page. At the very least, the visitor must have the View permission for the object. However, since we have also formulated the method login_html as a redirect, the user does not actually see a new page if they click on the link (Login), which leads to login_html. Access to this serves only as a gateway to the special welcome page of index_html.

Initially, all users have the permission that allows them to access login_html as a result of Zope's automatic assignment of permissions to roles. The purpose of the login_html method, however, is to test the permissions of the current users and make them authenticate if they do not have the role Friend.

To accomplish this, the default permission assignment for login_html must be deactivated, by default, login_html acquires the View permission for the Anonymous role from the root folder. Once this is turned off neither Anonymous users or Friends are permitted to access login_html. If a user clicks on the Link, Zope attempts to display login_html and recognizes that the user does not have permission to login_html via View and requests authentication.
