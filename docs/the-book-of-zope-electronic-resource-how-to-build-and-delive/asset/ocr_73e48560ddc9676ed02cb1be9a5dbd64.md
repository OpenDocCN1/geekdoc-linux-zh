Users use the *third tier* when they view an object through the Internet published by a Zope server. Although current third tier users generally see only content, as Internet applications and users become increasingly more sophisticated, they will increasingly be able to contribute or control the look and feel of the website in some way. Because third tier users cannot see the Zope Management screen, the developer must create special custom interfaces in their applications to provide this functionality. Figure 4-2 shows document_2 as it appears in the third tier.

Figure 4-2: The third tier view of a DTML document

The DTML code for an object is programmed in the second tier's edit screen. When a DTML object is viewed in the third tier, Zope evaluates the object's DTML code and returns the resulting text to the user's web browser by *rendering*. Often, the text returned is HTML code (the code used to produce a standard web page), but it can also be plain text, XML, or any other textual document format. The important thing to understand is that DTML code is seen only by Zope and is never transmitted to the client user's web browser.
