# Listing 10-8: The DTml method Edit_html changes a book's properties

```python
1: <dtml-if name="save">
2: <dtml-call expr="propysheets.Book_description.manage_changeProperties(REQUEST)">
3: </dtml-if>
4: <dtml-call expr="RESPONSE.redirect(URL2 + '/admin/html">
```

This code is similar to part of code used in the BookClass_add constructor method we modified in Section 10.1.1. It works by first checking to see if the Save button on the form was pressed, using dtml-if to see if the save name is in the namespace (Line 1). If so, it calls the built-in method manage_changeProperties on the Book_description property sheet of the Book instance being edited (Line 2). Because this method is called in the context of this instance (by calling it after the URL of the Book), the book is at the top of the namespace. The built-in manage_changeProperties method changes the Book's property values to those passed in REQUEST from EditForm_html.

Finally redirect back up to the admin_html page. URL2 returns the URL of the folder containing the book instance, which is up two levels from this method call. For example, if the URL used to call Edit_html is

```
http://localhost:8080/Books/B09362/Edit_html
```

```python

```

The Delete_html method is similar to the Edit_html method. It first checks to see if the delete button on the form was pressed, using dtml-if to see if the delete name is in the namespace (Line 1). If so, it calls the built-in method manage_delete on the Book_description property sheet of the Book instance being deleted (Line 2). Finally, it redirects back up to the admin_html page. URL2 returns the URL of the folder containing the book instance, which is up two levels from this method call. For example, if the URL used to call Delete_html is
