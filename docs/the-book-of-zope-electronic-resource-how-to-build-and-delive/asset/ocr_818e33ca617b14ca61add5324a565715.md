This creates a file on your local computer containing the DTML source of the index_html DTML document.

FTP can also a convenient way to upload many objects into Zope (such as images, or Web pages) that reside as files on your computer. You can use mput command, for uploading an entire directory of files into Zope at once, rather than uploading them one at a time through the Zope management screen.

For more information on the available FTP commands, use the help command or see the Unix FTP manual (type ftp at the command prompt).
