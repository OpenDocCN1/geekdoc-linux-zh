
The following example displays a tree view containing all subordinate objects and additional image files inside Folder1.

```
| 1: | <dtml-var standard_html_header>
| 2: | <image Files/>
| 3: | <dtml-call expr="REQUEST.set('expand_all',1)">
| 4: | <dtml-tree name="Folder1" branches="objectValues">
| 5: | <dtml-if expr="meta_type == 'Image">
| 6: | <IMG SRC="dtml-var name="icon">
| 7: | <a href="dtml-var name="tree-item-url"><dtml-var name="id"></a>
| 8: | <dtml-else>
| 9: | <IMG SRC="dtml-var name="tree-var id">
| 10: | </dtml-if>
| 11: | </dtml-tree>
| 12: | <dtml-var standard_html_footer>
```

On Line 3, the `expand_all` variable is set to true by calling `REQUEST.set` to instruct the tree tag to expand all of its branches down to the leaves by default. The tree tag is opened (Line 4) and Folder1 is specified as the folder for the tree to recurse. The branches attribute of dtml-tree is set to objectValues (a method that returns all objects in a folder) in place of the default methodValues (which returns only folder objects).

Inside the tree body, we check to see if the current object is an image using dtml-if (Line 5) to test the value of its `meta_type`, an attribute of All Zone objects. If the object is an image, we display its icon and construct a link to it using the variable tree-item-url supplied by the tree tag (Lines 6 and 7); otherwise only the icon and object id are inserted (Line 9). The body of the tree tag is then closed (Line 11). Figure 4-10 shows the rendered output of the document.

## 4.3.12 The sendmail Tag

The sendmail tag sends electronic mail using the Standard Mail Transport Protocol (SMTP). One feature of the sendmail tag is that no text substitution is carried out, meaning that email is sent without rendering text into your document. Since the text of the email will not appear to the user viewing the page containing the sendmail tag, a message confirming that the email was sent should be included elsewhere in the page.

The sendmail tag requires four parameters: an SMTP host address or a Zope mailhost address; a recipient's address; the sender's address; and a subject.

The last three items may either be specified as attributes inside the tag (as customary) or can be placed in a header line format. A header line consists of the header followed by a colon, a space, and then the relevant data. The header of sendmail tag should include the following fields:

- To: [The address of the recipient]
- From: [The address of the sender comes next. This information is optional, although the header must not be omitted]
- Subject: [The subject of the email. This information is optional, although the header must not be omitted.]

The message text follows these parameters. There must be at least one blank line between the subject line and the message text.

The email is sent as soon as the sendmail tag is called. As a result, it is best to code the sending of email messages into a separate object that is called only for this purpose.

## 4.3.13 The MIME tag and boundary Tag

Often you will need to email only text but also file attachments. To send attachments, you will need to use the MIME tag and one more boundary tags. The MIME tag activates multipart/mixed so that files can be attached.

The start MIME tag must be inserted on the last line with no spaces between it and the subject. If you want to send only text, you can omit the MIME attributes, as shown below:

```
<html-var standard_html_header>
<html-sendmail host="MailHost">
from: martina@behive.com
to: martina@behive.com
subject: Requested
<html-mime type="text/plain" encode="7bit">
```

Here are the files you requested: a boundary tag for each file to be sent follows the message text, organizing its transport. The MIME and boundary both use the same optional attributes, which are listed in Table 4-16. The file(s) to be sent are inserted in a var immediately after the boundary tag (there must not be any blank spaces).
