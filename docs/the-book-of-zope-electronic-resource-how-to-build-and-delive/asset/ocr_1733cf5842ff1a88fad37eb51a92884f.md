# A.2.2 Client-Server Communication

# Request Object Attributes

| Attribute Name | Explanation | Example | Screen Output |
| --- | --- | --- | --- |
| AUTHENTICATED_USER | Displays the user object of the user currently logged in. Displays the "Anonymous User" if no user is logged in. | AUTHENTICATED_USER | manager |
| AUTHENTICATION_PATH | Displays the path of the acl_folders in which the current user is defined. | AUTHENTICATION_PATH | /Test/Folder1 (if the current user is defined in the acl_users-folder/Test/) |
| PARENTS | Returns highest-like object in the object hierarchy starting from the current document backward. PARENTS[-1] always refers to the root folder. | "PARENTS[0]['id']" "PARENTS[1]['title']" | GWS_Training Zope |
| PUBLISHED | The actual object published to the client by Zope. | PUBLISHED | <HTMLMethod instance at 9edddb8> |
| URL URL | Returns the full URL of the object requested by the client's web browser. | URL | http://localhost:80/Order/Test/in/dex_html |
| URL1-URLn | The path to the object up to the $n^{th}$ object above it in the path; used to create links to objects higher in the Zope hierarchy. | URL1 URL2 | http://localhost:80/Order/1 http://localhost:80/Order/1 |
| BASE0 | Returns the base of the URL requested. | BASE0 | http://localhost:80/80 |
| BASE1-BASEn | The URL path with n objects is added to the BASE. | BASE1 | http://localhost:80/Order/1 |
| HTTP_REFERER | The URL of the previous page on which the user clicked a link or a submit button to arrive at this page; useful for creating links to go back to the previous page. | HTTP_REFERER | URL of page linked to this one.|
