## 4.3.1.2 The name Attribute

The name attribute is used to obtain variable data from the DTML namespace. When this attribute is used, a variable is looked up by name and executed if it is a callable object (such as a DTML method); its value is passed to the relevant tag. In this way, the system can search for a graphic object and then display it, as shown again with the CompanyLogo name attribute:

```
<html-var name="CompanyLogo">
```

The following rules are imposed on names when they are used to access variable data using the name attribute:

- 1. They cannot begin with an underscore character (_).
- 2. They cannot contain characters that are significant to URLs, such as /, &, :,; and so on.

## 4.3.1.3 The expr attr Attribute

The expr attr is used to evaluate complex expressions. The attribute value—that is, the expression to be evaluated—must be enclosed in double quotation. (See Chapter 9 for a brief introduction to the expression syntax.)

## 4.3.2.1 Using the Namespace Variable for Lookups

The underscore variable can also be used to look up names in the namespace, a process called indirection. Indirection allows you to write code without specifying the name directly. Instead, you specify the name outside the code. For example, there is a property in the namespace called "message" with the value thankyou_message and a DTML method with that name. You could insert this DTML method using the following code:

```
<dtml-var expr="message">
```

Notice there are no quotes around message, which tells Zone to use the variable and look it up. In our example, the value is thankyou_message, so the DTML method is found and rendered. If the value of the message variable is different the next time this code is executed, it would insert different data. If the value of message is not the name of any variable, a Zone error will occur.

> The namespace object always attempts to call or execute the object referenced if it can. This behavior is the same as the name="" syntax. However, if you want to access an object and not just the result of calling it, using the _getitem() function, described below.
