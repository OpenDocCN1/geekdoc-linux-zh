# 1.5.2 Windows NT

Under Windows NT or 2000, you have the option of running Zope as a service, meaning that the Zope server will start up automatically when Windows starts so you don't have to start it manually. To set this option, click on Run as Win 32 service.

# 1.5.2.1 The Zope Service

If you are not using Windows NT or 2000, or you decide not to run the Zope server as a service, you will need to start the server manually by running the .bat file in the Zope directory. To do so, click on the file in Windows Explorer or open the Start menu, choose Run..., and type in the filename.

Once you have started the Zope server, you can begin working with Zope. To do so, simply open your web browser. By default, you access the Zope server using the following URL:

```
http://localhost:8080
```
