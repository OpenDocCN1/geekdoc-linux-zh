# 前言

## 这本书是给谁看的？

我们把这本书设计为初者的入门指南，同时也作为资深用户的更完整参考。我们希望它能让你更容易地了解 Zope，并成为你高效使用 Zope 的基础。以下内容将有用且重要，特别是对于后续章节：

- HTML 知识会有帮助。
- Python 知识对于后续章节是必要的。

## 本书涵盖哪个版本的 Zope？

本书涉及 Zope 2.3 版本。因此，我们建议你从 Zope 2.3 或更早版本开始，并以此书作为你的指南。
