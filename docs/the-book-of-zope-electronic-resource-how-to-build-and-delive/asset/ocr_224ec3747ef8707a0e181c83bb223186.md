# all_meta_types(self)

This method lists all metatypes, all entries from the Available Objects menu, in the form of a tuple. The individual tuple entries are dictionaries with the following-form:

```
{'permission': 'Add External Methods',
'name': 'External Method',
'product': 'ExternalMethod',
'action': 'manage_addProduct/ExternalMethod/methodAdd'}
```

# valid_roles(self)

This method returns all valid roles contained in the ZCatalog and the opposite folders.
