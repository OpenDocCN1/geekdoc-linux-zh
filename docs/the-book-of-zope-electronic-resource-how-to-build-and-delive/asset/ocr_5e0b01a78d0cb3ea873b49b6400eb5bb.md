# 15.4.2.2 Utility Functions

The sample product also needs the following utility functions:

+   - GetDTML(name)
- addDocsToFolder(theFolder, theDocs)

The method GetDTML(name) is a simplification of the method called "DTMLFile(name, globals())". It saves you from having to write globals() over and over again. The code for this method is as follows:

```
getDTML(name):
    return DTMLFile(name, globals())
```

The method addDocsToFolder(theFolder, theDocs) adds the .dtml files in the product directory as DTML methods in the Zope folder specified by the argument. In our example, theFolder represents a new instance of the product. When an instance is created, DTML methods are added to corresponding .dtml files stored in a subdirectory of the Website product. These DTML methods can then be customized in Zope to suit the needs of the particular website instance.

The code for the addDocsToFolder is shown in Listing 15.1.

# Listing 15.1: the addDocsToFolder() method

```
addDocsToFolder(theFolder, theDocs):
    """
    # Adding several DTML Methods in Zope
    """
    errs-String=String(IO)
    for key in theDocs.keys():
        id=key
        dtml.title=theDocs[key]
        try:
            dtml=open(dtml.raw).read()
        except:
            raise RuntimeError("Can't find " + dtml.raw")
        try:
            theFolder.manage_addDTMLMethod(id, title, file=thedtml)
        except:
            traceback.print_exc(file=errs)
    errs.seek(0)
    return errs.read()
```

This method requires as arguments a folder object and a dictionary (theDocs) listing the individual .dtml documents to be created. (See Table 15-2 for a list and descriptions of the .dtml files required for the sample product.)
