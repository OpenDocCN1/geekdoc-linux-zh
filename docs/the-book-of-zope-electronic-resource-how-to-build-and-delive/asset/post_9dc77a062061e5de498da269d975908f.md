## 9.3.6 Creating a Property Sheet

Once you have created your first ZClass, you will need to create a property sheet for it. In a property sheet, you define various characteristics (properties) to apply to the individual instances. Before creating a property sheet, take a few moments to consider exactly which properties the objects should have. Although you can always change a property's data type, once instances of ZClass have been created, this will be problematic. Changing a type in ZClass with instances does not remove the actual property value from the instances, although the property will no longer show up in property sheets.

To create a property sheet for the BookClass, the following:

1. Go to /Control_Panel/Products/Sales Then click BookClass.
2. Click Property Sheets on the tab bar of the management screen (see Figure 9-15).
3. As you can see, your current ZClass has no property sheets. Click Add Property Sheet to create one. A screen appears containing Id and Title.
4. In the Id field, enter Book_description; you can leave the Title field blank.
5. Click Add to create the property sheet Book_description.

You can now click your property sheet Book_description and specify individual properties for it.

### 9.3.6.1 Defining Properties in a Property Sheet

A property (attribute of an object) consists of an id and a default value, as well as a property type. The following property types are available (see section 3.1.6 for more information):

| Property Type | Description |
|---|---|
| boolean | A property with two discrete values: true or false. Represented the property sheet by a checkbox. |
| date | A date and time value that cannot be empty in the property sheet. This property shares all of the functionality of the DateTime and ZTime objects. (See Appendix A for more information on working with dates.) |
| float | A floating point number, often used to represent fractional or monetary values. Floats must always have a value assigned. |
| int | An integer, either positive or negative in value with no fractional part. The range of values may vary across different operating systems, but will always have a precision of at least 32 bits. Int properties will not allow empty value. |
| lines | A list of text strings with each list item on a separate line. Useful for multiple word keywords or an arbitrary number of values. |
| lang | An integer value without an upper or lower value range. Use this property for extremely large numbers that may exceed several billion in value. |
| string | A single line string of text of unlimited size. This is probably the most commonly used property type. |
| text | A multiline string of text of unlimited size. Uses a multiline text area on the property sheet, and is often used for long string values such as descriptions, or long passages of text data. |
