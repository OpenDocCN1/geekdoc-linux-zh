Often you may need to access attributes of objects, such as title or id, that have the same names as those of the object containing the DTML code or method. Because the current or containing object (depending on whether you are in a DTML document or method) is in the namespace stack, its names will match those of other objects we might want to access. To get around this, we can use the tag to temporarily alter the namespace stack to search for the desired object:

```
<dt-with name="someObject>
The title of someObject is: <dt-var name="title">
The size of someObject is: <dt-var name="get_size"> bytes
</dt-with>
```

Inside with the tag, the someObject is placed at the top of the namespace stack. This means that variable names will be sought in it first before the current or container object.
With tag inserts an additional namespace at the top of the namespace stack. The object whose namespace is inserted is defined in the start tag of the dt-with block. The tag body contains the instructions to be carried out and can also contain other tags.

```
<dt-with Object>
Instructions
</dt-with>
```

Here's how to access variables from subobjects not normally acquired by default:

```
<dt-with name="Subfolder">
The subfolder title is: <dt-var name="title">
</dt-with>
```

Also, with the aid of the underscore variable's namespace method, you can use dt-with to temporarily set a new variable—including a value at the top of the namespace stack. This can be used to store the value of a calculation for use within the block or to override the value of an existing variable in the namespace.

In the following fictional example, a function get_cost is called. This function looks up the cost of an item given its SKU number from an external database. The SKU number is passed from a CGI or HTML form variable. The get_cost function is complex and time consuming, so to increase the efficiency of our code, we store its value in a temporary variable named "cost". Further calculations and formatting will be performed on this value inside the block.
