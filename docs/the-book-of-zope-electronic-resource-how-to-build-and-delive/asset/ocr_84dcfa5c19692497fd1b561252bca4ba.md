# # 13.1 Data Types

To truly master Python, consult a good Python book (O'Reilly's Learning Python or New Riders' *Python Essential Reference*).
This section discusses the data types supported by Python and offers several simple examples, with each example accompanied by the corresponding result (the relevant screen output).

> The results shown in this section derive from output produced if you run the examples in Zope (for example, calling them from within DTML). If you try to test these examples in a pure Python environment, you may encounter differences.

Python supports the following basic data types:

+   - Numeric
- Sequential
- None

Python numeric types can be further divided into:

+   - Integer values
- Long-integer values
- Floating-point numbers
- Octal and hexadecimal numbers
- Complex numbers

Python sequential types include the following data types:

+   - Strings
- Lists
- Tuples
- Dictionaries
