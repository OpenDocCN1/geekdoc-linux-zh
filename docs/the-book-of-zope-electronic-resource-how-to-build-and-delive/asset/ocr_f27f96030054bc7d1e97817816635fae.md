The ownership of an object is especially important for executable objects such as DTML Methods or documents. When an executable is rendered (executing its code), the permissions granted to its owner's roles are used to determine the permissions available to the executing code. If the owner does not have sufficient permissions (via their roles) to execute the code in the object, the code cannot be run by any user, even if the user viewing the object has permissions (via their roles) to execute the code. This prevents so-called "Trojan Horse" attacks, where a user with lesser security privileges writes harmful code that they cannot execute, and then deceives a user with greater privileges into executing it for them.
