Using the tag you can, for example, iterate through the elements in a list in order to display them in a table. For example, consider the following code:

```
1: <dml-in exp=['Henderson', 'Jackson', 'Johnson', 'Jones', 'King', 'Smith']>
2: <dml-if name="sequence-start">
3: <table>
4: <tr>
5: <th>sequence-start?</th>
6: <th>sequence-end?</th></th>
7: <th>sequence-index</th>
8: <th>sequence-item</th>
9: </tr>
10: </dml-if>
11: <dml-if name="sequence-odd">
12: <tr bgcolor="#eeee">
13: <dml-else>
14: <tr>
15: </dml-if>
16: <td><dml-var name="sequence-start"></td>
17: <td><dml-var name="sequence-end"></td>
18: <td><dml-var name="sequence-index"></td>
19: <td><dml-var name="sequence-item"></td>
20: </tr>
21: </dml-if name="sequence-end">
22: </table>
23: </dml-if>
24: The sequence is empty.
25: </dml-in>
```

In this example, a list is passed as an expression to the starting in tag (Line 1). The tag first determines whether the list is empty (contains no items); if so, a message to this effect is output using the list tag (Lines 24 and 25). Otherwise, the code in the body is executed for each item in the list in turn.

When we start the list, dml sets the variable sequence-start to true. We test for this condition using dml-if (Line 2), and a table header is defined when it is true (3 through 9). For each item in the list, a row is added to the table containing values provided by some of the variables defined by the in tag. The dml-in variable is tested to determine whether to show the row (Line 11). If this value is true, the row is showed (Line 12), otherwise it is not (Line 14). When the last item of the list is iterated, dml sets the variable sequence-end to true. We test for this condition using dml-if (Line 21), and the table is closed when it is true. The rendered output of this code would look like Figure 4-7 viewed by a browser.

| | | 0 | Henderson |
| | | 1 | Jackson |
| | | 2 | Johnson |
| | | 3 | Jones |

## 4.3.10 Using the in Tag

Another useful function of in tag is its ability to repeatedly execute code. To do this, the in tag uses the range method, which can accept a maximum of three arguments: range(Startvalue, Endvalue, Interval).

If only one argument is specified, the argument is the end value, the start value is zero, and the interval is 1. Using this method a list of the numbers is created, and the resulting list can be run through the in tag. For example, calling range(5) creates a five-element list [0, 1, 2, 3, 4] so that you can use the in tag to define a loop to run the actions five times.

The following causes the line "Hello!" to be inserted ten times in the rendered output of a document:

```
<html-in "range(10)">
Hello!
</html-in>
```

## 4.3.11 The tree Tag

The tree tag is used to survey objects in their hierarchy and present them as a tree structure with collapsible branches and leaves. Thus, you can create a tree structure like the one used in the left-hand frame of the management interface. In the example in Figure 4-8, a folder named Folder1 contains several:

| Type Name | Size | Last Modified |
|---|---|---|
| Subfolder1 | | 2001-05-27 22:36 |
| Subfolder2 | | 2001-05-28 02:17 |
| acl_users (User Folder) | | 2001-05-27 22:06 |
| dml_document2 | 1 Kb | 2001-05-27 02:18 |

| dml_method2 | 1 Kb | 2001-05-27 22:19 |
| index_html | 1 Kb | 2001-05-27 22:06 |

Figure 4-8: The objects in Folder1

To create a simple tree structure, use the tree tag in a DTML method located in Folder1:

```
<dml-tree>
<dml-var name="id">
</dml-tree>
```

![](img/43a28cce5475b2f487bf455365567fb6_107_0.png)

Figure 4-9: A simple tree structure view

The tree in Figure 4-9 displays only objects located in the current folder and is visually less attractive than the one used by the management interface. The tree tag itself is very complex and accepts a wide variety of attributes that can be used to format a tree view. For example, to start a tree from a location other than the one the DTML method is located in, you must specify the name of the object from which the tree should start, like so:

```
<dml-tree name="Subfolder1">
```

The branches and branches_expr attributes are set as standard for the method tpValues. The method with which all objects and subobjects are found is called objectValues. These methods are defined for you in folder objects.

To make sure that both objects and their appropriate icons are displayed in the tree view, use the following code:

```html
<dt-tree>
<IMG SRC="-var name="icon"><dt-var name="id">
</dt-tree>
```
