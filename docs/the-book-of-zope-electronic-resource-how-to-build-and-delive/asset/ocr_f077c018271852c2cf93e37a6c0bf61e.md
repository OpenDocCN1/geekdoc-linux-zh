# 11.3.2 Batch Size

The standard generated pages show 50 results per selected ZCatalog or Z SQL method. In other words, the standard batch size is 50. If there are more than 50 results, Next and Previous links appear, which allow you to navigate the results (as shown in Figure 11-16).

| Title | Meta type | Id | Bobobase modification time | Data record id |
|---|---|---|---|--|
| Installed product Standard&CacheManagers | Product Standard&CacheManagers | 2001/05/20 22:30:33:11 GMT-2 | -44784125 |
| Installed product Size:Access | Product Size:Access | 2001/05/20 22:30:32:01 GMT-2 | -44784128 |

![](bbox=[0.198, 0.575, 0.315, 0.635])

Figure 11-16: Pages with two displayed results and Previous and Next links

To change the number of results displayed, simply replace the batch size of 50 with the number of results that you want displayed in the line of the result DTML method (and in other lines if there is more than one result object):

```
<dtml-in ZCatalog size=50 start=query_start>
```

If you have several searchable objects, you may need to change the batch navigation logic by renaming the query_start variable for each (for example, query_start1, query_start2, and so on).
