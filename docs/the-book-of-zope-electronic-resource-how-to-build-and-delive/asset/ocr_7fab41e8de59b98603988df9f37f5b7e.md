+   • A Zone permission called BookClass_add_permission. This creates a new security permission (available in the Security tab of folder objects) for adding instances of your ZClass.

+   • A factory object called BookClass_factory. This object adds an item to the add menu of folder objects for the book ZClass and instructs Zope to display BookClass_addForm when the menu is selected. It also associates the BookClass_add_permission with this action.

The two DTML methods Zone creates for you are intended only to assist you in getting started. You will learn how to modify these and add more functions in section 10.1, *Modifying the Constructor Methods.*
