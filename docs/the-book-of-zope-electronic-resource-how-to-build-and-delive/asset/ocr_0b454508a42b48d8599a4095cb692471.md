# # THE BOOK OF VMWARE

The Complete Guide to the VMware Workstation

by BRIAN WARD

This guide to VMware software, which allows users to run multiple OSs simultaneously on a single computer, was developed with VMware, Inc. and covers device emulation; guest OS configuration; networking and file transfers; and more. The CD-ROM includes a demo version of VMware for Linux and Windows, and copies of all discussed utilities.
