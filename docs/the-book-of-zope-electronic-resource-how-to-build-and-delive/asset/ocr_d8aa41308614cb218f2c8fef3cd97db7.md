A particular advantage of ZMS is its ability to edit DTML documents and methods. # # Summary

This chapter has shown you different ways to access data, such as DTML Documents or Image objects, in your Zope server so that you can work with them more like normal files.

Using these services: FTP, WebDAV, and XML-RPC, you can work with Zope outside of the confines of a web browser. Combined with development tools on your local machine, this can be a convenient way to perform development and content management tasks in Zope.
