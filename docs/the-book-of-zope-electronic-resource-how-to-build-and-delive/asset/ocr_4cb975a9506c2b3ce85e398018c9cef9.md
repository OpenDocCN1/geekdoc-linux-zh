An object derived from a class is called an *instance*. Instances created from a class can call all of the class's properties and methods, as you will see. Each instance represents an individual member of a class. For example, a CarClass would be an individual car, an instance of ApartmentClass a specific apartment, and so on. (For more information on classes, instances, and objects, see 2.3.1).
