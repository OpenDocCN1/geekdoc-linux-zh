# ### Table 4-11: Attributes for the in Tag

| Name | Explanation |
|---|---|
 name | The name of the variable that returns the sequence to be iterated. See "The Attribute" in section 4.3.1.2. |
| expr | An expression that returns the sequence to be iterated. See "The expr Attribute" in section 4.3.1.3. |
| sort | The sort attribute is used to sort a sequence of objects before the sequence is iterated. The value attribute is the name of the attribute (or the key if the mapping attribute is specified) according to the items are to be sorted. |
 start | The name of a variable that specifies the starting sequence item of the current batch. If this is amitted, iteration starts at the first item. |
| size | The size of each batch of items to iterate. If this is amitted, the entire sequence is iterated at once. |
| arphan | The number of items to expand the last batch to keep it from being too small. If this is amitted, this value defaults to 3. |
| overlap | The number of items that overlap between each batch. If this is amitted, there is no overlap. |
