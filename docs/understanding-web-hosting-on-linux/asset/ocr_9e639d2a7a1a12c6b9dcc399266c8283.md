# Updating Your System

Once your distribution is loaded, you're ready to go, right? Well, not. Like any software, Linux is constantly in a state of change. The kernel and application software are always being enhanced with additional features, and bugs in the current code are being squashed. The latest version of Red Hat has stable right out of the box, which might make you hesitate to install any, but the updates made to the software to improve security should push you toward keeping up-to-date. This is particularly true for the server you are currently configuring.

We discussed the importance of acquiring the updates to Red Hat and pointed you to the appropriate Web site where updates and instructions are available (www.redhat.com/errata), so we won't give you detailed instructions here. In any case, the method you'll use to update your system depends on many factors. If you purchased a retail version of Red Hat, you can use the update program to retrieve and apply the updates. You'll need to read about it in Red Hat's documents.

To update your system by hand, go to the Red Hat Web site and retrieve the update RPMs. While you are, read and print the updates for each package. The process is quite simple. You download an RPM, and once it's on your system, use the rpm program to install the package. Specific instructions are available with each package on Red Hat's site. Here is a quick summary of the rpm options used for updating a package:

+   - rpm -Fvh package_name.rpm "freshens" an already installed package. If you attempt to use this command on any package that isn't installed, nothing will happen.
