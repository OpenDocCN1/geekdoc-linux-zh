## The Submit Button

The submit button was mentioned earlier, but one trick we want to mention here is to simulate function keys with HTML submit buttons. In legacy midrange and mainframe applications, function keys are used to tell the program how to process the screen input. If you'd like the same facility in an HTML form, just specify several submit fields. The two submit buttons, for instance, add an item to or cancel the order, respectively.

```html
<INPUT TYPE="SUBMIT" NAME="Submit" VALUE="Add Item">
<INPUT TYPE="SUBMIT" NAME="Submit" VALUE="Cancel Order">
```

One, powerful input field needs to be described: the hidden field. Like subtle hidden fields, HTML hidden hidden field are not displayed to the user. They are explicitly for use by the server program. Typically, hidden fields are used in HTML to maintain application state, but you can use them for any reason you wish. Just keep in mind that the HTML form still needs to be sent over the Internet, so don't overcome them.
