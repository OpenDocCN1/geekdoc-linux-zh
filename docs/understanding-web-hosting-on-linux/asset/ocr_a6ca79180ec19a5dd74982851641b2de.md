You might want to check both desktop environments to which you like better. Red Hat seems to push Gnome, but KDE is reputed to be the easiest to convert to Windows. We use both, although we're leaning towards toward KDE. Keep in mind that running a desktop environment is entirely optional; if you have a memory-constrained system, you can run without one.

At this point, you're probably wondering what advantages X provides over its embedded-GUI equivalent. After all, the job of any GUI is to make it easy for you to do your work, and if you are used to the Windows environment, let's look, however, at some of the advantages of X.

First on last, of course, is the freedom of choosing which manager/desktop environment combination you want to use—including the choice to run none at all.
