# Stuff Happens

Things don't always work, so your code must be prepared to handle potential problems. Most of the JDBC methods generate objects called SQL exceptions when things go wrong. All of the JDBC method invocations had to be wrapped with Java try blocks. The init method's try blocks list errors using System.out.println, while the doGet method's try blocks list errors to the dynamically constructed HTML with out.println.
