# # UNDERSTANDING
 Web Hosting on Linux

The Linux operating system was initially created by Linus Torvalds, who began his work in 1991 and worked steadily until 1994 when Version 1.0 of the Linux Kernel was released. Developed under the General Public License, Linux source code is freely available to everyone, and Linux is therefore considered an excellent, low-cost alternative to more expensive operating systems. The Linux operating system may be used as an end-user platform as well as for a wide variety of purposes, including networking and software development.

By virtue of its functionality and availability, Linux has become quite popular. As a result, students around the world have been seeing Linux education. This book is a guide to setting up a complete Linux environment on Android. As you move through the text and the accompanying labs, you will build a system with a database management system, a Web server, and server-side Java.

And you'll understand how it works. Because the system is based on Linux, that of the open-source era, everything you learn here is applicable to any platform where Linux will run. These platforms include Apple hardware, Intel and Intel-compatible hardware, and, of course, the eServer by IBM.

Although there are many variations on how to pronounce the word "Linux," it is often pronounced with a short "i" and with the first syllable stressed, as in LI-nucks.
