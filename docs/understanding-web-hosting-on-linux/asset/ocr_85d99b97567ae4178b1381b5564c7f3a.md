Next on the agenda is the LILO configuration, LILO is short for "Linux Loader." A complete description of its purpose is in chapter 4. Once again, if you've installed to an empty drive, Red Hat will have thoughtfully selected everything for you. Note the check next to Create Boot Disk. The help text indicates that you should create it if you are not installing LILO on the master boot record or not installing it at all. To reiterate: Create it in any case. Once you've reviewed everything here, click Next.

Note: If you aren't installing to an empty disk, be sure to read the help text on the LILO Configuration screen, since a mistake here could cause a failure with any other operating systems that are sharing this drive.

If you have a network card installed, you'll get a Network Configuration screen. Then it is on the option to configure networking via DHCP, or if you unchecked that, the ability to manually configure your networking card. We are unable to make this determination for you;you'll need to consult with your technical support for the appropriate information.

New to Red Hat (as of 7.1) is the Firewall Configuration screen. The ability to add a firewall for a long time required the user to configure it manually. The 2.4 kernel, however, has a much-improved version of the firewalling software, so in an attempt to improve out-of-the-box security, Red Hat has to configure it as part of the installation. Network security and firewalls are beyond the scope of this book, but you have two choices. The first is to create no firewall at all, which is probably not the best choice unless your machine is on a corporate intranet that is already inside a firewall. The other choice is to select the medium-security firewall, then Customize to allow incoming connections, so that others may connect to your Web server. Once again, read the associated help text provided on screen to determine the best choice for you.

The next screen, Language Support Selection, allows you to add additional languages to the base language you chose when the installation program started. After checking that you, click Next.

Following language is the Time Zone Selection screen. In our opinion, you should select the hardware clock within your PC to use Greenwich Mean Time (GMT), Greenwich, England, which with the 0° longitudinal lines, also known as United Coordinated Time (UTC). Select the time zone in your clock will maintain time. Using this method, you'll never have to reset your computer's clock when the time changes to Daylight Savings Time. Linux will automatically make the conversion and forget it it. Given that a Linux box is expected to run non-stop for a long time (sometimes for more than a year), it's nice to have this feature.

Now you're coming the home stretch. You should be looking at an Account Configuration screen, divided into two sections. The first is to enter the password for the root user, which you'll duplicate in the Confirm box to ensure that you made no typographical errors. The second is a place for you to configure a regular system user.

Why would you want to create another user if you're the only one who is using this machine? It is a horrible idea to run normal operations as the root user. The root is the almighty being of this computer, and a request to delete everything from the root (/) without question. Linux inherits from its UNIX idea that, if you asked for it, you must want it. By creating another user account that lacks the capability to crash your system accidentally, you protect yourself from yourself. If you choose this advice, fine—don't say we didn't warn you.
