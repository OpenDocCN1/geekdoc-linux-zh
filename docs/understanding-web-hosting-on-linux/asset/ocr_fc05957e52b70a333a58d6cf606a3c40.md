Obviously, you'll need a Web server, and you'll probably also need an email server. Linux, unlike other operating systems, has its TCP/IP modules fully integrated. For serving and email, the various Linux distributions bundle the world-class open-source Apache HTTP server (www.apache.org) and sendmail (www.sendmail.org), along with many other Web-hosting products.

An important piece of software vital to the hosting of a robust site is a Web server. While Web servers (also known as HTTP servers) basically serve only static, unchanging Pages, Web applications work in association with HTTP servers to serve dynamically constructed, interactive pages. When a user's request for dynamic information comes into the HTTP server, it forwards the request to the Web server. The Web server, in turn, uses Java code to dynamically construct a Web page that responds to the user's request. The Web application server sends this forwards to the HTTP server, which sends it to the user's browser.

The cost of Web application servers is not a consideration for whether or not to use Linux because all Web applications (except Microsoft's Internet Server) run on all operating systems. IBM's WebSphere, for example, runs well not on all of IBM's operating systems (AS/400, OS/390, and AIX), also on Solaris, HPUNIX, and Linux. WebSphere's closest competitor, BEA's WebLogic, also runs on a variety of operating systems, including Linux. In addition, the open-source Web servers available, most notably Apache's Tomcat, run on many operating systems, including Linux.

# Support Costs

Having discounted hardware and software costs, the only real cost is support. The big question that companies have about "free" software is who is going to support it? For Linux, the answer is multifaceted. One source of support is the Linux user community, which, in 1997, was awarded "Best Technical Support" from InfoWorld. The Linux user community is made up of experts who are ready to freely help new Linux users. The community is accessible through a wide variety of newsgroups available from Usenet (www.usenet.com) and Internet Relay Chat (at www.irc.org).

Many corporate executives, however, want to put a a "suit and tie" on technical support. They want to pay to ensure the quality and availability of these services. Formal support for Linux is available from a variety of sources, the first and most obvious being the Linux distributors. These distributors, some of whom are shown in Table 1.1, sell installation CDs for Linux that come with bundled open source software, and a limited amount of phone and Web support. Most of these distributors also offer extended support programs. In fact, much of their revenue comes from technical support for Linux.
