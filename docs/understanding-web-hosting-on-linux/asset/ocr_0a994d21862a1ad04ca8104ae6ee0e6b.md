One other thing concerning HTML documentation: you aren't necessarily out of luck if you want to display
an HTML file but you aren't using a GUI. A text-based browser, Lynx, is with your Red Head
distribution and should be installed on your system. To read a document using this tool, use the command
lynx file:/directory/list/file.txt, where /directory/list/file.txt is the full path and name.

# Super Doc Site

The ultimate source for Linux documentation is the Linux Documentation Project (LDP),
over www.linuxdoc.org. The LDP is staffed by volunteers who have committed their free time to ensure
thorough, useful documentation is available for Linux. The existence of this project demonstrates the\variety of skills that are donated to the open-source movement. Although many LDP volunteers are
technical people, some are not software authors at all. Their forte is technical writing. These
individuals who write the documentation that concerns you. Perhaps you’ll decide to contribute
this project as you become more skilled with Linux.

If you have access to the Internet, you can go to the LDP site to investigate what's available. To start off, all
of the HOWTOs discussed in this chapter are there. So are the FAQs and manuals from the Red
H CDs. All three of these groups of documents need to be more up-to-date than those included on the Red
H CDs (since they are static)

In addition to HOWTOs, FAQs, and manuals, there are two other types of documents you might want
to look at the LDP. The first are guides. These are significantly longer than typical HOWTOs, so they
are given their own category. The other item of interest is a link to an online Linux e-zine, Linux Gazette.
The Gazette is published monthly, and is free. The LDP mirrors the Gazette and has all backs inside
available, in addition to the current one. This resource is worthy of your attention because it is so well
written and informative.

# Other Common Formats

Although text, manpages, info pages, and HTML are the most common document types with which you will
work, there are two others: the Portable Document Format (PDF) and PostScript. So that you have a
document of each type with which to work, use the following commands from a command:

```
man -t man > man.ps
ps2pdf man.ps man.pdf
```

The first command instructs man to output the manpage for itself in PostScript format and direct the
to the file man.ps. The second command runs a program that takes as input the PostScript file you just
created, and outputs a PDF version.
