# Table 12.1: Input/Output Redirectors

| Redirector | Function |
|---|---|
| >file | Redirects standard output to the specified file. |
| 2>file | Redirects standard error to the specified file. |
| >>file | Redirects standard output to the specified file, appending existing data. |
| 2>> | Redirects standard error to the specified file, appending existing data. |
| &file | Redirects both standard output and standard error to the specified file. |
| <file | Redirects standard input to the specified file. |
| <<text | Redirects standard input until a line matching is found. |
| cmd1 | cmd2 | Uses the standard output of cmd1 as input to cmd2. |

The following command will please a verbose list of the files in our home directory into a file called listome.txt.

```
$ ls -1 /home/donat > listome.txt
```

If the file did not exist before the execution of the command, it would have been created; if it already existed, its contents would have been overwritten. To append to a file, you can use the double less-than redirection operator: >>.

Suppose you want to add to listome.txt the files that exist in a subdirectory called java. You would use the following command:

```
$ ls -1 /home/donat/java >> listome.txt
```

However, the list doesn't differentiate the files in your home directory and the subdirectory of Java. To handle that, use the cat command to add a subdirectory header line to listome.txt. The cat command normally takes input from a file name argument, but if no file name is qualified, cat will use the standard input of the screen. The cat command's standard output, unless redirected, also lists to the scren.

To add that subdirectory header line with cat, use the following command, and after the text entry, press Ctrl-D:

```
$ cat >> listome.txt
The java subdirectory contents:^
```

Note that ^D is not added to the file; it represents the Ctrl-D keystroke combination that forces standard input to the cat command to close. Obviously, you have to re-execute all three commands in the proper sequence so that the subdirectory header precedes the output in the listome.txt file.
