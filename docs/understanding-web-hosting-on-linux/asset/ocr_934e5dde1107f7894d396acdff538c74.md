# History Repeats Itself

Another useful feature of bash is its ability to retrieve, edit, and re-execute previously entered commands. By simply pressing the Up arrow key, you retrieve the last command executed. If you keep pressing the Up arrow, bash will continue to retrieve the commands executed. If you are looking for commands past the terminal screen, use the Down arrow to go in reverse direction. Once you've retrieved the command you want, you can edit it with the help of the Home, End, Delete, Backspace, and arrow keys, and press enter to execute the modified command.

If you type two exclamation points, bash will retrieve and immediately execute the previously entered command. If you type one exclamation point followed by a number n, bash will retrieve and execute the command entered n times again. Perhaps the coolest feature of bash history, though, is the search-and-execution flow. If you type an execution point followed by a string, bash will scan history for the command that contained that string, and then execute it. Suppose you would like to use the `date` command to set your system date to equal that of an Internet time server. Instead of trying to remember the URL for the time server, you simply type the following:

+   - !?date

Bash pulls from history and executes something like this:

```
rdate -s tock.usno.navy.mil
```

To delve a little deeper into the mechanics of bash history, consider the results of the following command:

```
$ set | grep HIST
HISTFILE=/home/donat/.bash_history
HISTSIZE=1000
HISTSIZE=1000
```

The **set** command is discussed later in this chapter, but from the list, you can see that the user's personal history file is `/home/donat/.bash_history`. The history file is simply a text file, so you can open it with your favorite text editor or use `less` to display its contents:

```
$ less /home/donat/.bash_history
```

The history file will become especially handy when you start to create bash scripts to automate the execution of a series of bash commands under a single, home-grown, custom Linux command, as covered in the next chapter.
