The PanelServlet extends the HttpServlet class. PanelServlet declares its global fields—there is only one, globalCount. It is important to remember that the values of global fields (more appropriately called instance fields) are accessible to all Web requests that invoke the servlet, since one instance handles all Web request. There could be hundred different Web Clients using this same servlet instance, and they'd all referencing the same datum.

Instance or global variables are initialized in a special function called init. If your servlet contains an init function (if not required), the function is automatically invoked by the Web server the first time your servlet is invoked. That servlet instance is then used for all subsequent requests, the init method will not be invoked. PanelServlet's init method constructs an integer object, globalCount, which counts the number of times the servlet responds to a user request, initializing its value to 100. Your real-world business servlets will probably instantiate things like JDBC connection and prepared statements in function

# Get or Post

The doGet function defined after the init function runs every user request. The doGet has two parameters: HttpServletRequest and HttpServletResponse. The first parameter contains information about the request; the second contains the dynamically generated HTML response. Table 7.3 and 7.4 show a subset of the features available through HttpServletRequest and HttpServletResponse. It is worthwhile to study the Java documentation for these classes, however, because they have some powerful capabilities. Both of them, for instance, have methods that make using HTTP cookies a breeze (which are typically used to maintain application state).

# Table 7.3: HttpServletRequest Methods

| Method | Description |
| getCookies | Returns an array of cookie objects sent from the browser. |
| getMethod | Returns the HTTP request type, typically either a GET or a POST. |
| getHeader | Returns the value of HTTP headers. |
| getHeaderNames | Returns an array of all the HTTP headers included in the request. |
| getRemoteUser | Returns the user name, if the user has logged in using HTTP authentication. |
| getRemoteAddr | Returns the IP address of the user's Web browser. |
| getRequestURI | Returns the URL without the request parameters. |
| getSession | Returns a handle to a special object variable that maintains the application state for a user. |
| getContentLength | Returns the total length of the user's request parameters. |
| getContentType | Returns the type of content sent from the user. |
| getQueryString | Returns a string containing all the user's request parameters. |
| getParameter | Returns the value of a specific request parameter. |
