# # Data Types

The size of each variable type is an intrinsic part of the language. No matter what platform you are running Java on, the size of each data type is the same. This greatly improves the language's portability. There are eight variable types, shown in Table 7.1.

| Type | Size in Bytes | Default Value | Range |
|---|---|---|---|
| Integers (Non-fractional) | | | |
| int | 4 | 0 | -2,127,483,648 to 2,147,483,647 |
| short | 2 | | -32,768 to 32,767 |
| long | 8 | 0 | -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807 |
| byte | 1 | | -128 to 127 |
| Floating-point (Numbers with Fractional Parts) | | | |
| float | 4 | 0.0F | ±3.40282347E+38 |
| double | 8 | 0 | ±1.79769312486231570E+308 |
| char | 2 | '0x0' | 65,536 various characters |
| boolean | 1 | false | false or true |
