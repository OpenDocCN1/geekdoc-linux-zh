```
# cd /opt
# tar -xf where/ever/you/put/HTTPServer.linux.1.3.19.0.EN.tar
```

The tar utility will create a directory called IHS-1.3.19.0 and fill it with about half a dozen RPMs.

+   5. Change your working directory to IHS-1.3.19.0.

```
# cd IHS-1.3.19.0
```

+   6. For each of the RPMs, run the rpm utility in the following format:

```
# rpm -U -nodeps <rpm file name>
```

+   7. Start IBM's HTTP Server:

```
# /opt/IBMHTTPServer/bin/apachectl start
```

or

```
# /etc/rc.d/init.d/ibmhttpd start
```

+   8. Test IBM's HTTP Server:

```
http://127.0.0.1
```

+   9. Stop IBM's HTTP Server:

```
# /opt/IBMHTTPServer/bin/apachectl stop
```

or

```
# /etc/rc.d/init.d/ibmhttpd stop
```

Take note that under the /opt/IBMHTTPServer directory, you'll find the same conf, htd, and logs subdirectories as the standard Apache Web server.
