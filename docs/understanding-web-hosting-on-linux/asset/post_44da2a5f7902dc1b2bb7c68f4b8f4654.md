The last common document format is the Adobe PostScript format. You might have already heard the term "PostScript" in the context of a printer, so you might be confused with the concept of a file in PostScript format. Actually, PostScript is a programming language that was created for rendering documents. PostScript-capable printers are capable of executing the instructions presented to them in a PostScript file. By convention, PostScript files end with the extension .ps. Earlier in this chapter, you used to create a PostScript version of its manpage. Issue the following command to see what's going on behind the scenes:

```
more man.ps
```

A PostScript rendering engine recognizes a PostScript file by the string %PS-Adobe-x.x in the first line. The "x" is the version of the language used within the file. Since the PostScript version of the manpage isn't all that is interesting to view in its native format, let's see what it looks like rendered. Exit by pressing the Q key, and then issue this command:

```
ghostview man.ps
```

The ghostview program uses another program, gs, to render PostScript or PDF files and present the result on the screen. Like xpdf, ghostview provides the obligatory navigation icons with which you can page through the document. To exit ghostview, click the X in the upper-right corner of the window.
