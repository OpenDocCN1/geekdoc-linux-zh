# Table 7.4: HttpServletResponse Methods

| Method | Description |
| --- | --- |
| addCookie | Adds textual data in the HTTP request, which the user's browser will subsequently add to its cookies repository. |
| encodeRedirectURL | Encodes the specified URL for use in the sendRedirect method. |
| encodeURL | Stuffs the ID in the response URL. |
| sendError | Sends an error response to the client using the specified status code and a default message. |
| setHeader | Adds an HTTP response header with a name and values. |
| setStatus | Sets the status code for the HTTP response. |
| getCharacterEncoding | Returns the name of the character set used for the MIME body sent by this response. |
| getOutputStream | Returns a handle to a data stream that can be used to write binary response data. |
| getContentLength | Sets the length of the content server returns to the client. |
| setContentType | Sets the content type of the response server sends to the client, such as text/html. |

For right now, the most important function of the requestRequest variable is the getParameter function. This retrieves input values from the HTML form. Before discussing HTML forms, we need to decide the first two statements in PanelServlet's doGet function:

```
response.setContentType("text/html");
PrintWriter out = new PrintWriter(response.getOutputStream());
```

These are pretty much template code; any doGet function that you create should start with these two statements. Both of them use response, which you can think of as a handle to the HTML file containing to the user's request. The first statement, response.setContentType("text/html") says that the HTTP response to the client will contain text-based HTML. The next statement receives a handle to the output stream. It's sort of like setting a format in an RPG screen screen. PanelServlet uses the output to output an HTML response.

After setting the content and retrieving a handle to the HTML output stream, the doGet function then retrieves the user's HTML form input. By invoking the HttpServletRequest object the getParameter function. The code is fairly self-explanatory, that all of the input fields from the HTML form are retrieved. What you might find odd is if a user did not select one of the checkboxes, the parameter is not available to the servlet. Whenever the getParameter function cannot find a parameter with the name qualified, getParameter returns null for nothing. If you misspell the variable name or use incorrect capitalization, getParameter will also return a null.

Once all are retrieved, the doGet function increments the globalCount variable. The value of globalCount is used to the dynamically constructed HTML response. The response outputs the obligatory tags, such as <HTML>, <HEAD>, <TITLE>, and <body>, before it starts to echo the user's values. Note that the println function is passed the variable name and the HTML line break. The value for globalCount is then listed with the following statement:

```
out.println("This servlet accessed "+count+" times.<BR>");
```
