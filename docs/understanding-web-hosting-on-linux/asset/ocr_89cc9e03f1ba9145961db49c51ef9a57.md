You'll need more Java than an RDB to develop a Web site, however. You'll need a graphical desktop environment (like Windows), a Java integrated development environment, and editors for developing Web pages. Microsoft, of course, bundles the Windows desktop environment with its operating system. Since Linux, on the other hand, is about choice, there are numerous desktop environments available. As mentioned earlier, the two best-known are Gnome (www.gnome.org) and KDE (www.kde.com). Both are all the major Linux distribution CDs.

With a graphical desktop installed, you'll want an integrated development environment (IDE) for Java. A Java IDE allows you to type source code, compile it, and then debug before deploying it to your Web site. Once again, several powerful tools are available as free downloads, such as Sun's Forte for Java (http://java.sun.com/fortefij); IBM's VisualAge for Java (VAJ), Entry Edition (www.ibm.com/software/avajada/download.html); and Borland's JBuilder (www.borland.com/builder/). Note, however, that each of these free IDEs lacks some of the sophisticated features found in various commercial versions.

Up to this point, we've considered open-source or free software for developing and deploying a commercial Web site. To host a highly sophisticated Web site, you might want to look at commercial software. The open-source relational databases, for example, don't contain all of the features available in the commercial products of Sybase, Oracle, or IBM's DB2 UDB. Similarly, open-source Web application servers do not scale as well as IBM's WebSphere. BEA's WebLogic, and Sun's i. The three open-source Java IDEs just mentioned (VAJ, JBuilder, and Forte) have commercial versions that provide integration tools and wizards to simplify development and deployment of Web applications. # Open Source Is Not Free

With the wide availability of open-source tools, it's important to understand the open-source movement. Richard Stallman, an MIT scientist, missed the spirit of sharing source code that prevailed in the early days of UNIX. In 1984, Stallman began the GNU project (www.gnu.org), which had the mission statement of creating a free UNIX-like operating system. (The name is a recursive acronym that stands for "GNU's not UNIX.") The FSF seeks to promote free software and eliminate restrictions on its copying, redistribution, understanding, and modification.
