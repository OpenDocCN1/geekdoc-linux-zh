Our recommendation for partitioning a drive is shown in Figure 3.3. We have extended Red Hat's standard three-partition scheme with partitions for /usr/local, /opt, and /home. Before you commit to using this partitioning scheme, you must decide if your hard drive is large enough for it. Creating partitions for /home, /opt, and /usr/local is extremely flexible, but if your hard drive is too small, you'll undoubtedly end up making one partition too large (with lots of free space), at the expense of another partition, which will invariably run out of space.

Having discussed partitioning, we are ready to talk a bit about backup. The program you choose for backing up your system is up to. Several examples are included on the Red Hat Powertools, the old standby is called tar, which is short for "tape archive". A how-to on the use of this program isn't appropriate in this chapter, but we will mention that you don't need to back up your entire system. After all, you have a backup for the installation CDs. What you need to back up are the directories discussed, just as /etc, which contains all of the text-configuration files, and certain subdirectories of /var, depending on where your application software, such as a database, has configured to its files. The documentation provided with the application should indicate where it places information and should be the guide for your total backup strategy.

Occasionally, you'll need a copy that boots properly once Linux is installed. This happens during occur of installation when the BIOS reports the geometry of the hard drive, but when new equipment sometimes has trouble setting it. To protect yourself from this problem, you need to create a boot disk. At some point toward the end of the installation, you'll be asked if you wish to create one. Although it might be tempting to save a few minutes by declining the offer, we recommend that you do yourself a favor and perform the operation. Almost any problem with installation can be fixed simply when the system is up. If you can't get the system started, though, then you'll be kicking yourself because you didn't create the disk. Just do it.

# Installing, Configuring, and Testing

After you have read The Official Red Hat Linux 8.6 Installation Guide and have ignored our comments pertaining to partitioning and recovery, we are ready to start installing Linux. Although it is possible to perform an installation across a network via FTP, NFS (Network File System), or HTTP, we make the assumption that you have the installation CDs and are going to performing a local installation from a CD-ROM drive in your computer.

If your computer is capable of booting from CD, you are all set. If not, you'll have to create an installation diskette. To do that, take the Install CD #1 and a blank 1.4 Mb floppy disk to another computer that is running DOS or Windows. Insert the CD into the CD-ROM drive and, at command line, type the items as shown

```
C:> d (This assumes that your CD-ROM drive is drive D:)
D:\dosutils> cd dosutils
D:\dosutils> rewrite
ter disk image source file name: ..images/boot.img
Enter target drive a:
  Insert a formatted diskette into drive A: and press -ENTER-: [ENTER]
d:\dosutils> _
```

The file boot.img is a byte-for-byte copy of 1.44 Mb Red Hat installation diskette. The diskette is now created.

At this point, you may begin the installation. Power on your computer and insert CD #1 to the CD drive. If your computer cannot boot from the CD, insert the diskette you just created. In either case, press the Reset button, and you will see the screen shown in Figure 3.4. This screen allows you select a text-based or graphical installation, with other options you can ignore for now. If you are inquisitive, you might want to press F2 and read the information on the general screen. There is quite a bit of information on these screens that you might find useful not planned as with your installation.

![](img/069cd06404ac5e90171e6d857bf3ad28_49_0.png)

Figure 3.4:Initial screen presented by the Red Hat Installation CD.

Once you've examined the information presented on the help screens, press Enter to begin the installation program. The first screen that will require input from you is the Language Selection screen. If your computer supports graphics, you will be in the graphical installer, which you can identify by the identification of the "Man in the Red Hat" in the upper-left corner. If your machine does not support graphics, you will be in the text-based installation program. The main difference between the two is the location of the help text. With the graphical installer, the help text is on the left side of the screen, with the options at the right. The help text is available by pressing F1.

Additional information about the state of the installation script is available to you on other virtual consoles, because the Linux system treats them as separate devices without being actual hardware to support them. To switch between virtual consoles, use the key combination Ctrl-Alt-Fz, where z is a number between one and five. Others include virtual console 4-system messages; and virtual console 5 to see the installation log; press the key combination Ctrl-Alt-F3 from either installer. Press Ctrl-Alt-F7 to return to the graphical installer, or Ctrl-Alt-F1 for the text-based installer.
