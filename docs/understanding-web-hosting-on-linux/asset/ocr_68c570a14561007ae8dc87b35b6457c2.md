Microsoft's worst-case scenario came true. In late 2000, Lou Gerstner, IBM's chief executive officer, stated that IBM would spend $1 billion on Linux in 2001. Gerstner is quoted as saying, "Linux can do for business applications what the Internet did for networking and communications: making computing easier and free from proprietary operating systems."

IBM's billion dollars went a long way to changing the perceptions of many corporations that Linux was not adequate for commercial applications. There were two major problems with Linux as a business OS: the lack of quality symmetric multiprocessing (SMP) to improve speed and scalability, and the lack of a journaled file system (JFS) support to improve recoverability. (For more about JFS, see http://www.ibm.com/developers/library/jfs.html). Among many other Linux projects, IBM has been developing Linux solutions for both SMP and JFS. Both of these projects require a large base of code, and IBM contributed most of the code base required for them. Remember, because of the open-source licenses, any enhancements IBM makes to existing open-products are also open-source.

Besides contributing to open-source, IBM was one of the first software vendors to create Linux versions of its products. Today, you can run DB2 U, WebSphere, MQSeries, VisualAge for Java, and Tivoli on Linux.

IBM intends to make a return on its billion-dollar investment by selling its world-class eServers and DB2 U, Domino, Tivoli, and WebSphere. As an example of how IBM has already cached in Linux, in late 2000, Telia, the largest and telecommunications company in Scandinavia, replaced 70 servers with one IBM Zseries. With that zSeries machine, today today is able to easily start a new server in less than five minutes whenever it gets a new client. The IBM-Telia deal is worth about $3 million. Another example, Lawson signed a deal to sell 15,000 Linux computers, software, and support to a Japanese convenience-store chain.

Although Linux might lack business application software for things such as payroll, manufacturing, or sales, the best of Linux is not for business applications. Instead, it is for server applications like these:

+   1. Domain Name System (DNS)
2. FTP, mail, news, proxy, and search
3. File servers
4. The Apache HTTP server

# Universal OS

Linux is quickly becoming as the "universal OS" because, regardless of the operating system a company uses for its legacy applications, it uses Linux for its Web server. Linux-based Web server communicates with legacy applications and databases to retrieve the information required for Internet applications.

Large IT shops are beginning to host their Internet applications with Linux running in one or more partitions on their iSeries or zSeries machines, while continuing to run their legacy applications in LPAR running that platform's native operating system. Smaller IT shops are beginning to run their Linux-based Web sites on low-cost Intel-based machines, with their legacy applications running an Internet connection away. Regardless of which platform Linux is deployed, these companies are able to take advantage of Linux's integrated security features, the industry-standard Apache Web server, and either IBM's WebSphere bundle or Apache open-source Tomcat product for the Web application server.
