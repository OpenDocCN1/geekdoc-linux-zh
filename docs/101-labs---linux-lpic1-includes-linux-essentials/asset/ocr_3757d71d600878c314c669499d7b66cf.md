After a few seconds, you should see output indicating that `ntpd` has updated the system time, noting where it got the time from and what the offset adjustment was.

`ntpd` can be useful for updating the system time on every boot, sometimes before `ntpd` (the NTP daemon) takes over, or for synchronizing the time manually on servers that usually have restricted or no internet access. Beyond that, however, `ntpd` is recommended instead of running `ntpd` via `cron`.

**Notes**

`ntpd` is a command, mostly useful for debugging, that can be used to query NTP servers for various information.
