**Notes:**
Even though the LPIC exams focus on Linux, spend any time as a Linux professional and it is inevitable that you will at some point be asked to provide interoperability with other operating systems. Learning the basics of Windows and OS X, as well as Linux tools meant to interoperate with them (such as Samba), will assist you in this.
