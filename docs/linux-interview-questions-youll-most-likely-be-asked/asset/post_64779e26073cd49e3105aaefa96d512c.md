## Hardware

**1: What command displays hardware related kernel messages?**

- a) dmesg
- b) messages
- c) kmesg

**Answer:**
a) dmesg

**2: What command shows PCI card information?**

- a) show_pci
- b) lspci
- c) cat /var/log/messages

**Answer:**
b) lspci

**3: What does the command 'lsmod' do?**

- a) List currently loaded modules
- b) List available modules
- c) List unloaded modules

**Answer:**
a) List currently loaded modules

**4: What does the command 'insmod' do?**

- a) Show module information
- b) Show available modules
- c) Load an available module

**Answer:**
c) Load an available module

**5: What is the device name for the first SATA drive on a server?**

- a) /dev/hda
- b) /dev/sda
- c) /dev/disk1
- d) /dev/diska

**Answer:**
b) /dev/sda

**6: What is the device name for the first IDE drive on a server?**

- a) /dev/sda
- b) /dev/disk1
- c) /dev/diska
- d) /dev/hda

**Answer:**
d) /dev/hda

**7: Which two video card vendors require proprietary drivers for full hardware support?**

- a) Intel/Nvidia
- b) Nvidia/ATI
- c) ATI/Intel
- d) none of the above

**Answer:**
b) Nvidia/ATI

**8: Which device corresponds to the physical memory?**

- a) /dev/mem
- b) /dev/kmem
- c) /dev/memory
- d) /dev/umem

**Answer:**
b) /dev/kmem

**9: Which daemon checks the health status of hard drives?**

- a) SMARTD
- b) Ide-Status
- c) Watchdog Syslog

**Answer:**
a) SMARTD

**10: What command will install the required drivers for a Realtek 8139 based network card?**

**Answer:**
insmod rt8139 OR modprobe rt8139

**11: What two values are needed in order to properly setup a monitor?**

- a) hsync, esync
- b) hsync, vsync
- c) vsync, refresh rate
- d) refresh rate, bit depth

**Answer:**
b) hsync, vsync

**12: What is the maximum amount of addressable RAM that a 32-bit kernel will address?**

- a) 3.5 GB
- b) 3 GB
- c) 4 GB
- d) Up to 64GB, with PAE

**Answer:**
d) Up to 64GB, with PAE

**13: What is the most popular architecture, in use today?**

- a) i386
- b) i686
- c) x86_64
- d) ia64

**Answer:**
a) i386

**14: What command should you use to rebuild the modules.conf file?**

- a) depmod
- b) rmmod
- c) insmod

**Answer:**
a) depmod

**15: What device corresponds to the first serial device port, using the newer /proc layout?**

**Answer:**
/proc/ttyS0

**16: What file contains all filesystems that are available to be mounted, as well as all mount options?**

**Answer:**
```
/etc/fstab
```

**17: What mount option allows for better disk performance, by not recording the access time of each file?**

**Answer:**
```
noatime
```

**18: What command would you use to mount the partition /dev/sda1, which is formatted ext3, at /mnt/linux?**

**Answer:**
```
mount -t ext3 /dev/sda1 /mnt/linux
```

**19: What utility will allow you to create block-by-block copies of a disk, or save block-by-block copies of a disk?**

**Answer:**
```
dd
```

**20: What is the exact command to duplicate (block-by-block) the device /dev/sda to the device /dev/sdb?**

**Answer:**
```
dd if=/dev/sda of=/dev/sdb
```

**21: What is the exact command to store a block-by-block backup of the device /dev/sda, to the file /tmp/sda.img?**

**Answer:**
```
dd if=/dev/sda of=/tmp/sda.img
```

**22: How would you scan the filesystem (ext3) on /dev/sda1 for errors, assuming that the partition is unmounted, and that you want to run the scan interactively?**

**Answer:**
```
fsck /dev/sda1
```

**23: What utility can be used to configure filesystem parameters for ext2/ext3 filesystems?**

**Answer:**
tune2fs

## Red Hat Linux

**24: What is the proper command to list all installed RPM packages?**

- a) rpm -qa
- b) rpm -q
- c) rpm -list
- d) rpm -l

**Answer:**
a) rpm -qa

**25: Where is the default configuration file for Apache, under RHEL?**

- a) /etc/httpd/conf/httpd.conf
- b) /etc/apache2/conf/httpd.conf
- c) /etc/httpd/conf.d/httpd.conf
- d) /etc/httpd.conf

**Answer:**
a) /etc/httpd/conf/httpd.conf

**26: What is the ncurses-based utility to configure startup services?**

- a) sysv
- b) sysrq
- c) ntsysv
- d) rund
- e) initd

**Answer:**
c) ntsysv

**27: In what file will you find the version of Red Hat Linux installed?**

- a) /etc/redhat-version
- b) /etc/redhat-release
- c) /etc/redhat/version
- d) /etc/uname

**Answer:**
b) /etc/redhat-release

**28: What is the proper command to install the package 'httpd', and all of its dependencies?**

- a) rpm -i httpd-version.rpm
- b) yum install httpd
- c) yum install httpd-version.rpm
- d) yum search httpd | rpm -i

**Answer:**
b) yum install httpd

**29: What does the command 'yum clean all' do?**

**Answer:**
Remove cached packages, and headers

**30: Which utility will add startup symbolic links to the /etc/rc.d directory?**

- a) update-rc.d
- b) chkconfig
- c) init.d
- d) init-rc.d

**Answer:**
b) chkconfig

**31: True, or False: CentOS and RHEL function the same-utilities designed for one, freely work on the other.**

**Answer:**
True

**32: What is the default DNS server that comes with RHEL?**

**Answer:**
BIND

**33: Which of the following mail server software does NOT come with RHEL/CentOS:**

- a) Sendmail
- b) Postfix
- c) Exim
- d) Qmail

**Answer:**
d) Qmail
