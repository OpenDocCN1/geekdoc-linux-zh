# **119: Where is the default location for PHP's configuration file?**

+   a) `/etc/php/php.ini`  
+   b) `/etc/php.ini`  
+   c) `/etc/php.d/php.ini`  
+   d) `/etc/php5/php.ini`

**Answer:**
b) `/etc/php.ini`

# **120: What is the proper syntax to use for mysqladmin to backup the entire MySQL installation to the file `/root/mysql-backup.sql`?**

**Answer:**
mysqldump -u root --all-databases > `/root/mysql-backup.sql`

# **121: True or False: A backup of the `/var` directory will backup all MySQL databases.**

**Answer:**
True
