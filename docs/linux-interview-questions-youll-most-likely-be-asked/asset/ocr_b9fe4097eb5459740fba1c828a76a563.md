# 1: What command displays hardware related kernel
messages?

+   a) dmesg
+   b) messages
+   c) kmesg

**Answer:**
a) dmesg

# 2: What command shows PCI card information?

+   a) show_pci
+   b) lspci
+   c) cat /var/log/messages

**Answer:**
b) lspci
