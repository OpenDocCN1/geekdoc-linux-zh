## 97: 给出一个 iptables 命令示例，该命令将阻止所有网络接口上端口 25 的入站 TCP 流量。此规则应该是列表中的最后一条规则，它应该丢弃从外部主机接收到的 SYN 数据包。

**答案：**
```bash
/sbin/iptables -A INPUT -p tcp -dport 25 -j DROP
```

## 98: 给出一个 iptables 命令示例，当源地址为 209.181.6.8 时，阻止端口 25 的入站 TCP 流量。此规则应该是列表中的最后一条规则。

**答案：**
`/sbin/iptables -A INPUT -p tcp --dport 25 -s 209.181.6.8 -j DROP`

## 99: 给出一个 iptables 命令示例，在接口 eth0 上阻止所有 ICMP 流量。此规则应该是列表中的第一条规则。

**答案：**
`/sbin/iptables -I INPUT -p icmp -i eth0 -j DROP`

## 100: 给出一个 iptables 命令示例，将 eth0 上 TCP 端口 25 的所有流量重定向到另一台主机 192.168.0.5。此规则应该是链中的第一条规则。

**答案：**
`/sbin/iptables -I INPUT -p tcp --dport 25 -i eth0 -j DNAT --to 192.168.0.5`

## 101: 给出一个 iptables 命令示例，将 eth0 上 TCP 端口 8080 的所有流量重定向到主机 192.168.0.5 的端口 80。此规则应该是链中的最后一条规则。

**答案：**

```
/sbin/iptables -A INPUT -p tcp -dport 8080 -i eth0 -j DNAT --to 192.168.0.5:80
```

## 102: 哪个命令将所有 iptables 规则重置为默认策略？

## 103: 给出一个 iptables 命令示例，使用 RST 数据包阻止主机 192.168.0.1 在 TCP 端口 80 上的所有流量。此规则应该是链中的最后一条规则。

## 113: 为什么在网络层或内核层阻止主机比在应用层阻止主机总是更好？

**答案：**
更好的安全性（阻止被阻止的主机与服务器应用程序交互），以及更好的性能（在网络层阻止主机可以防止资源被将被忽略的请求（或给出 403 错误等）占用）。

**答案：**
`/sbin/iptables -t NAT -A POSTROUTING -o eth1 -j MASQUERADE`
