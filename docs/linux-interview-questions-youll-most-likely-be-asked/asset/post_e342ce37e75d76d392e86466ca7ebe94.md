
# **115: What is the iptables command to set the default incoming traffic policy to drop traffic not specifically allowed?**

**Answer:**

`/sbin/iptables -P INPUT DROP`

# **116: What is the iptables command to set the default outgoing traffic policy to allow traffic not specifically denied?**

**Answer:**

`/sbin/iptables -P OUTPUT ACCEPT`

# **117: What are the three main iptables chains?**

- a) INPUT, OUTPUT, FORWARD
- b) INPUT, OUTPUT, POSTROUTING
- c) INPUT, OUTPUT, DROP
- d) INPUT, OUTPUT, DENY

**Answer:** a) INPUT, OUTPUT, FORWARD

# 118: What is the command to list all iptables rules?

**Answer:**

```bash
/sbin/iptables -L
```

# Samba

**139: Where is the Samba configuration file typically found?**

**Answer:**

/etc/samba/smb.conf

**140: What two security authentication types are available with Samba?**

**Answer:**

security, user

**141: If a share has a “create mask” of “700”, what does that mean?**

**Answer:**

All files created will be “chmod 700”, meaning that the user will have full read, write, and execute privileges to the file, and everyone else will have no access to the file.

**142: What command would you use to create a Samba account for the user ‘tom’, assuming that ‘tom’ is already added as a user on the server itself?**

**Answer:**

`smbpasswd -a tom`

**143: If a user is presented with a login screen, when attempting to browse the server’s shares, what is the first thing you should do (assuming that the user’s username and password on their Windows computer matches that of the account they are trying to use on the Samba server)?**

**Answer:**

Reset the Samba password for the user, verify that the user account has been created (in /etc/passwd, for the local server).

**144: What does the following option: "SO_RCVBUF=8192 SO_SNDBUF=8192 socket options = TCP_NODELAY" do on a Samba server?**

**Answer:**

Increase Samba performance, by setting the sending and receiving buffer sizes.

145: True or False: By default, all printers on the local CUPS server are shared through Samba.

**Answer:** True

146: True or False: Samba permissions override any filesystem permissions.

**Answer:** False. Filesystem permissions will override any Samba permissions.

147: What is the best way to setup an advanced ACL for a file or directory that is stored on a Samba server?

**Answer:** By using a Windows computer. Samba currently has no method of setting up advanced ACL for files and directories.

148: True or False: By default, Samba will be configured to act as the domain "master", or domain server.

**Answer:** True. Samba will, by default, allow users to log into the server, and act as a domain “master”, or domain server.

**149: What share definition, created by most default installations, is typically set to "read only = yes","browsable = no", and "guest ok = no"?**

**Answer:**

[homes]

**150: What does 'valid users = @reception' mean?**

**Answer:**

That all users on the group 'reception' are allowed to access the share.
