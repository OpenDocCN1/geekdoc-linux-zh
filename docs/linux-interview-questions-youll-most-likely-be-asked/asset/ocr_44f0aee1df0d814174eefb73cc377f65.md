# 151: What command allows you to fine-tune the hard disk performance on a Linux server?

Answer: 

Hdparm

# 152: What is the exact command (from the above question) that will allow you to benchmark the hard disk drive /dev/sda?

Answer: 

hdparm -T /dev/sda

# 153: What command will allow you to view the amount of used, free, and cached RAM?

Answer: 

free
