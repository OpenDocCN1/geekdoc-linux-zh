# **96: What device needs to have a value of "1" to enable packet forwarding, between network interfaces?**

+   a) /proc/sys/net/ip/ip_forward

+   b) /dev/sys/net/ipv4/ip_forward

+   c) /proc/sys/net/ipv4/ip_forward

+   d) /proc/sys/net/ip_forward

**Answer:**

c) /proc/sys/net/ipv4/ip_forward

# **97: Give an example of an iptables command that will block incoming TCP traffic on port 25, on all network interfaces.**

This rule should be the last rule in the list, and it should drop the SYN packet that it recevies from an external host.

**Answer:**

```
```bash
/sbin/iptables -A INPUT -p tcp -dport 25 -j DROP
```
