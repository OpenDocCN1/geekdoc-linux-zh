**102: What command will reset all iptables rules to the default policy?**

Answer:

```
/sbin/iptables -F
```

**103: Give an example of an iptables command that will block all traffic on TCP port 80 to host 192.168.0.1, with a RSET packet. This rule should be the last rule in the chain.**

Answer:

```
/sbin/iptables -A INPUT -p tcp -dport 80 -s 192.168.0.1 -j
REJECT --reject-with tcp-reset
```
