# **112: What file controls which hosts are not all owed to connect to a Linux server, and is most commonly used by xinetd?**

**Answer:**

/etc/hosts.deny

# **113: Why is it always better to block hosts at the network, or kernel level, rather than at the application level?**

**Answer:**

Better security (preventing blocked hosts from interacting with the server application), and better performance (blocking hosts at the network level prevents tying up resources with requests that will be ignored (or given a 403 error, etc).

# **114: Which iptables command can be used to enable IP Masquerading, given that eth0 is the inside interface, and that eth1 is the outside interface?**

**Answer:**

/sbin/iptables -t NAT -A POSTROUTING -o eth1 -j MASQUERADE
