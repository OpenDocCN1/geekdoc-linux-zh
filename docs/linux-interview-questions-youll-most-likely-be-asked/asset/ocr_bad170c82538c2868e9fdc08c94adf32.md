146: True or False: Samba permissions override any filesystem permissions.

**Answer:**
False. Filesystem permissions will override any Samba permissions.

147: What is the best way to setup an advanced ACL for a file or directory that is stored on a Samba server?

**Answer:**
By using a Windows computer. Samba currently has no method of setting up advanced ACL for files and directories.
