# **130: Which of the following services must be restarted after a change in the PHP configuration?**

+   a) Apache

+   b) PHP

+   c) MySQL

+   d) PostgreSQL

**Answer:**

a) Apache

**131: What is the command to start MySQL into "Safe Mode", so that you can reset the root MySQL password?**

**Answer:**

```
mysqld_safe --skip-grant-tables
```

**132: What is the name of the CentOS package that gives MySQL support to PHP?**

**Answer:**

php-mysql
