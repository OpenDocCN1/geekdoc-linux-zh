16: **What file contains all filesystems that are available to be mounted, as well as all mount options?**

**Answer:**

```
/etc/fstab
```

17: **What mount option allows for better disk performance, by not recording the access time of each file?**

**Answer:**

```
noatime
```

18: **What command would you use to mount the partition /dev/sda1, which is formmatted ext3, at /mnt/linux?**

**Answer:**

```
mount -t ext3 /dev/sda1 /mnt/linux
```

19: **What utility will allow you to create block-by-block copies of a disk, or save block-by-block copies of a disk?**

**Answer:**

```
dd
```
