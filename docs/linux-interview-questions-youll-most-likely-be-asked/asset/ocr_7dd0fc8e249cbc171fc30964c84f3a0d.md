# 185: What is the 'TTL' setting on a DNS record for?

**Answer:**

“Time to Live”, or the time that a record is valid, in seconds. After the TTL period, the record expires, and DNS servers should no longer cache the response.

# 186: What is a SPF record used for?

**Answer:**

A domain-based anti-spam protection. It specifies which hosts are allowed to send mail for a domain.

# 187: What is the difference between DKIM, and SPF?

**Answer:**

DKIM digitally signs emails (to confirm that the mail message came from a mail server that is the authoritative mail server for that domain), SPF specifies which hosts are allowed to send mail on behalf of that domain. DKIM requires a software implementation on the sending server, SPF is purely a DNS record, requiring no further software installation.
