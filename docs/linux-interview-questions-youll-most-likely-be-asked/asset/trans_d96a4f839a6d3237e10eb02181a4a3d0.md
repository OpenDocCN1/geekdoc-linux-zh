

# **115: 将默认入站流量策略设置为丢弃未被明确允许的流量的 iptables 命令是什么？**

**答案：**

`/sbin/iptables -P INPUT DROP`

# **116: 将默认出站流量策略设置为允许未被明确拒绝的流量的 iptables 命令是什么？**

**答案：**

`/sbin/iptables -P OUTPUT ACCEPT`

# **117: iptables 的三个主要链是什么？**

- a) INPUT, OUTPUT, FORWARD
- b) INPUT, OUTPUT, POSTROUTING
- c) INPUT, OUTPUT, DROP
- d) INPUT, OUTPUT, DENY

**答案：** a) INPUT, OUTPUT, FORWARD

# 118: 列出所有 iptables 规则的命令是什么？

**答案：**

```bash
/sbin/iptables -L
```

# Samba

**139: Samba 配置文件通常在哪里找到？**

**答案：**

/etc/samba/smb.conf

**140: Samba 可用的两种安全身份验证类型是什么？**

**答案：**

security, user

**141: 如果共享具有“create mask”为“700”，这意味着什么？**

**答案：**

所有创建的文件都将执行“chmod 700”，这意味着该用户将对文件拥有完整的读、写和执行权限，而其他任何人都无法访问该文件。

**142: 假设用户 'tom' 已经作为用户添加到服务器本身，你应使用什么命令为用户 'tom' 创建 Samba 账户？**

**答案：**

`smbpasswd -a tom`

**143: 如果用户在尝试浏览服务器共享时遇到登录屏幕，你首先应该做什么（假设该用户 Windows 计算机上的用户名和密码与他们试图在 Samba 服务器上使用的账户匹配）？**

**答案：**

重置该用户的 Samba 密码，并验证用户账户是否已创建（在本地服务器的 /etc/passwd 中）。

**144: 以下选项在 Samba 服务器上有什么作用："SO_RCVBUF=8192 SO_SNDBUF=8192 socket options = TCP_NODELAY"？**

**答案：**

通过设置发送和接收缓冲区大小来提高 Samba 性能。

147: 为存储在 Samba 服务器上的文件或目录设置高级 ACL 的最佳方法是什么？

**答案：** 使用 Windows 计算机。Samba 目前没有为文件和目录设置高级 ACL 的方法。
