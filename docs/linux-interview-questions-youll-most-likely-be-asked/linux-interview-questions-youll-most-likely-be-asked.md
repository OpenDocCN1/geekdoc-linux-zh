## 硬件

**1：哪个命令显示与硬件相关的内核消息？**

- a) dmesg
- b) messages
- c) kmesg

**答案：**
a) dmesg

**2：哪个命令显示 PCI 卡信息？**

- a) show_pci
- b) lspci
- c) cat /var/log/messages

**答案：**
b) lspci

**3：命令 'lsmod' 的作用是什么？**

- a) 列出当前已加载的模块
- b) 列出可用的模块
- c) 列出未加载的模块

**答案：**
a) 列出当前已加载的模块

**4：命令 'insmod' 的作用是什么？**

- a) 显示模块信息
- b) 显示可用模块
- c) 加载一个可用模块

**答案：**
c) 加载一个可用模块

**5：服务器上第一块 SATA 驱动器的设备名称是什么？**

- a) /dev/hda
- b) /dev/sda
- c) /dev/disk1
- d) /dev/diska

**答案：**
b) /dev/sda

**6：服务器上第一块 IDE 驱动器的设备名称是什么？**

- a) /dev/sda
- b) /dev/disk1
- c) /dev/diska
- d) /dev/hda

**答案：**
d) /dev/hda

**7：哪两家显卡厂商需要专有驱动程序才能获得完整的硬件支持？**

- a) Intel/Nvidia
- b) Nvidia/ATI
- c) ATI/Intel
- d) 以上都不是

**答案：**
b) Nvidia/ATI

**8：哪个设备对应物理内存？**

- a) /dev/mem
- b) /dev/kmem
- c) /dev/memory
- d) /dev/umem

**答案：**
b) /dev/kmem

**9：哪个守护进程检查硬盘的健康状态？**

- a) SMARTD
- b) Ide-Status
- c) Watchdog Syslog

**答案：**
a) SMARTD

**10：哪个命令将安装基于 Realtek 8139 网卡所需的驱动程序？**

**答案：**
insmod rt8139 OR modprobe rt8139

**11：正确设置显示器需要哪两个值？**

- a) hsync, esync
- b) hsync, vsync
- c) vsync, 刷新率
- d) 刷新率, 位深

**答案：**
b) hsync, vsync

**12：32 位内核可寻址的最大 RAM 量是多少？**

- a) 3.5 GB
- b) 3 GB
- c) 4 GB
- d) 使用 PAE 可达 64GB

**答案：**
d) 使用 PAE 可达 64GB

**13：当今最流行的架构是什么？**

- a) i386
- b) i686
- c) x86_64
- d) ia64

**答案：**
a) i386

**14：你应该使用哪个命令重建 modules.conf 文件？**

- a) depmod
- b) rmmod
- c) insmod

**答案：**
a) depmod

**15：使用新的 /proc 布局，对应第一个串行设备端口的设备是什么？**

**答案：**
/proc/ttyS0

**16：哪个文件包含所有可挂载的文件系统以及所有挂载选项？**

**答案：**
```
/etc/fstab
```

**17：哪个挂载选项通过不记录每个文件的访问时间来提高磁盘性能？**

**答案：**
```
noatime
```

**18：你要将格式化为 ext3 的分区 /dev/sda1 挂载到 /mnt/linux，应该使用哪个命令？**

**答案：**
```
mount -t ext3 /dev/sda1 /mnt/linux
```

**19：哪个实用工具允许你逐块复制磁盘，或保存磁盘的逐块副本？**

**答案：**
```
dd
```

**20：将设备 /dev/sda 逐块复制到设备 /dev/sdb 的确切命令是什么？**

**答案：**
```
dd if=/dev/sda of=/dev/sdb
```

**21：将设备 /dev/sda 的逐块备份存储到文件 /tmp/sda.img 的确切命令是什么？**

**答案：**
```
dd if=/dev/sda of=/tmp/sda.img
```

**22：假设分区未挂载，且你想交互式地扫描 /dev/sda1 上的文件系统（ext3）错误，该如何操作？**

**答案：**
```
fsck /dev/sda1
```

**23：哪个实用工具可用于配置 ext2/ext3 文件系统的参数？**

**答案：**
tune2fs

答：你可能能够快速做出决策，但请务必同时传达你做出明智、全面决策的技能。讨论快速做出决策的重要性，以及你是如何做到的，同时强调每个决策首先需要信息充分。

6: 为什么你的技能与公司 $X$ 目标相匹配？

答：如果你在面试前已经调查过这家公司，回答这个问题应该不成问题。确定公司的几个主要目标，并解释你拥有的特定技能如何有助于这些目标。此外，思考你的经验和技能如何转化为帮助公司扩展这些目标并实现更远目标的方式。如果你的前一家公司有类似的目标，请举一个具体的例子说明你如何帮助公司达成该目标。

7: 你认为这份工作需要做什么？

答：请确保在面试前充分调查该职位。阅读你能找到的任何职位描述（最好直接来自雇主的网站或职位发布），并记录关键职责、义务和所需的经验。没有什么比一个完全不知道自己正在接受哪种工作面试的候选人更让面试官感到失望的了。

8: 关于这份工作或公司，你还有什么想了解的吗？

答：如果你事先已经了解了这家公司，这是一个绝佳的机会，可以展示你在面试前付出了努力去研究。询问关于公司的

使命与当前行业趋势的相关性，并与面试官进行有趣且相关的对话。此外，在离开之前，务必弄清楚你还需要了解的关于该职位的其他任何信息——这样，如果面试官带着录用通知打来电话，你就能从容应对。

### 9: 你认为自己是这个职位的最佳人选吗？

**回答：**

是的！请提供具体的细节，说明是什么让你具备了这个职位的任职资格，并确保讨论（并展示）你对新机会、该工作以及该公司的无拘无束的热情和 enthusiasm。

### 10: 你是如何为这次面试做准备的？

**回答：**

这个问题的关键在于确保你确实做了准备！务必在面试前研究过公司、他们的目标以及他们的服务，并尽可能多地了解该具体职位的信息。了解公司的历史以及当前组织中的关键人物也很有帮助。

### 11: 如果你被录用，你第一天会做什么？

**回答：**

虽然许多人会以一种乏味的方式回答这个问题，仅仅描述标准化的第一天流程，但这实际上是向面试官展示你为何会成为一个优秀雇员的好机会。除了参加培训或入职指南外，请强调你多么享受与主管和同事见面的机会，或者说明你会花大量时间提问并熟悉周围的新环境。

### 12: 你看过我们要公司的网站吗？

**回答：**

显然，你应该在来面试之前查看过公司的网站并做了一些初步研究。如果由于某种原因你没有这么做，也不要坦白承认，因为面试官可能会通过询问关于网站的具体问题来揭穿你。如果你确实查看过公司网站，现在是提起你在网站上看到的一些特别引起你兴趣的内容，或特别认同的价值观的合适时机。

### 13: 你简历上的 *X 经验* 与这个职位有什么关联？

**回答：**

许多申请者的简历上会有一些无法明确转化为当前所投职位内容的经验。但是，请做好准备应对关于这种看似不相关经验的提问，并准备一个回答，考虑到两种经历之间可能共享的相似技能集或训练。

### 14: 你为什么想要这个职位？

**回答：**

请保持回答的积极基调，聚焦于该具体工作的哪些方面能让你进一步提升技能、提供新的经验，或者成为你做自己特别喜爱之事的契机。不要告诉面试官你找工作时间很长，或者薪资非常有吸引力，否则你会显得缺乏动力且机会主义。

### 15: 你的背景与此职位有何相关性？

**回答：**

理想情况下，这在你的简历中应该显而易见。然而，如果你的经验与该职位的关联较为松散，请确保在面试前仔细研究了该工作和公司。这样，你就可以智能地将你现有的经验和技能与新职位所需的相似技能联系起来。具体解释你的技能如何转化，并使用诸如“准备”和“学习”等词汇来描述你的背景。将你即将担任的职位描述为一个“机会”以及“成长和发展的”契机。

### 16: 你如何看待我们公司的 X 使命？

**回答：**

在面试前研究过公司至关重要——如果你已经这样做了，这个问题就不会让你措手不及。最好的回答是简洁、切中要点，并展示你对当前使命的了解。提供几句简短的陈述，说明你为什么相信该使命的重要性，并指出你有兴趣获得在一个支持该使命的公司工作的机会。

### 17: 在工作中，你更希望拥有更大的权限还是更大的责任？

**回答：**

这两种选择各有利弊，你的面试官会更感兴趣看到你能为这个问题提供批判性的回答。获得更大的权限可能意味着更大的决策权，对于具有卓越领导能力的人来说很好；而更大的责任可能是那些希望在职业生涯中稳步晋升的人的一个成长机会。

### 18: 当小组中有人没有贡献公平份额时，你会怎么做？

**回答：**

如果你正在申请一个监督性职位，这个问题特别重要——解释你会如何识别问题，以及如何将个人拉到一边讨论其贡献。理解建立对话的过程很重要，这样你就可以向个人清楚地传达你的期望，给他们回应的机会，并明确需要改变什么。在此之后，与小组成员制定一个行动计划，以确保他们的贡献与其他成员持平。

### 19: 请告诉我一次你在权限之外做出决定的经历。

**回答：**

虽然对这个问题做出回答可能会让你看起来果断且自信，但它也可能让雇主认为你是一名有问题的员工。相反，最好稍微将问题重新聚焦到你承担额外责任的一个例子，因此不得不做出超出你正常权限的决定（但在特定情况下被授权的决定）。

讨论决策的重量如何影响你的决策过程，以及情境的结果。

### 20: 你愿意就争议事项找上级吗？

**回答：**

如果出现一个问题，雇主希望知道你会以及时且适当的方式处理它。强调你过去很少与上级发生争执，但如果情况发生，你完全自在可以讨论它与相关人士，以找到一个双方都满意的解决方案。

### 21: 如果你在上一个工作中负责，你会做哪些不同的事情？

**回答：**

无论你对事情如何能运行得更好有多少想法，或对前一家公司的管理有多少看法，在回答这个问题时都要保持积极态度。展示对如何处理某事以提高效率或改善销售的深思熟虑的反思是可以的，但务必确保你的所有建议都集中在让事情变得更好，而不是谈论消除浪费或负面的方式。

### 22: 你认为雇主应该表扬或奖励员工工作做得好吗？

**回答：**

完成一项艰难工作后的认可总是很棒的，但有些雇主可能会问这个问题来推断你是否是一个难伺候的员工。虽然你可能欣赏奖励或表扬，但重要的是向面试官传达你不需要 accolades（赞誉）就能自信地认为自己工作做得很好。如果你正在申请一个监督性职位，你将负责表扬其他员工，请突出表扬在提升团队士气方面的重要性。

### 23: 你认为领导者最重要的品质是什么？

**回答：**

在任何企业中，领导者都有许多重要的技能，这个问题的关键部分是解释为什么你选择突出强调的品质很重要。尝试选择一种品质，如沟通能力，或激励他人的能力，并将其与你在团队中展示该品质的具体实例联系起来。




## 24：请谈谈一次你遇到突发问题的经历。你是如何处理的？

**回答：**

关键在于你要表现出你在压力下具备资源利用能力和冷静理智的态度。面试官希望看到你能够系统地处理问题，并以有序的流程应对变化。清晰地概述情况，包括你所实施流程的所有解决方案和结果。

## 25：你能给我一个例子，说明你在上一份工作中是如何改善 X 目标的吗？

**回答：**

这里的关键是专注于你做出的那些为公司带来实际成果的改进。提高效率当然是业务中非常重要的一个因素，但雇主也在寻找具体的成果，例如销售额增加或费用削减。详尽地解释你的过程，尽可能提供具体的数字和证据，特别是在概述结果时。

## 26：请谈谈一次上级在项目上没有提供足够具体指导的经历。

**回答：**

虽然许多雇主希望员工在没有太多决策权的情况下遵循非常具体的指导方针，但同样重要的是要能够接手一个方向模糊的项目并自主执行。举例说明你提出的必要问题，并说明你是如何判断某个问题是必须向上级提问的，还是你可以自行决定的。

## 27：请谈谈一次你负责领导一个项目的经历。

**回答：**

引导面试官了解项目的整个流程，就像你对待团队任何成员那样。解释项目的目标、必要的步骤，以及你如何向团队分配任务。包括结果，以及你从这次领导机会中学到了什么。

## 28：请谈谈你向 former 雇主提出的一个建议，该建议后来被实施了。

**回答：**

雇主希望看到你关心公司的改进并尽自己的一份力——提供一个具体的例子，说明你做了什么来在前一份工作中创造积极的变化。解释你是如何想到这个点子的，你的上级是如何接受它的，以及当这个点子被实施时其他员工是怎么想的。

## 29：请谈谈一次你想到工作中某事可以更高效完成的方法。

**回答：**

专注于你想法的积极方面。重要的是不要以负面的形象描绘你的旧公司或老板，所以不要详细阐述某个系统是多么低效。相反，解释一种你看到提高生产力或简化流程的机会的情况，并解释你分步骤实施更好系统的过程。

## 30：你认为领导和管理人有什么区别——哪一个是你的更大优势？

**回答：**

确实有区别——领导者通常是很好的创意者，充满激情，有魅力，并具备组织和激励他人的能力；而管理者则是确保系统运行的人，促进其运作，做出权威决策，并对从总体成功到最细微决策的所有方面承担巨大责任。考虑哪种特质最适用于该职位，并解释你如何适合这个角色，提供你过去经历的具体例子。

## 31：你在领导角色中表现更好，还是在团队中作为成员表现更好？

**回答：**

重要的是要考虑面试官在你的职位中寻找什么样的特质，并表达你如何体现这个角色。如果你是领导者，突出你的优秀创意、驱动力和热情，以及激励周围他人行动的能力。如果你在团队中表现优异，专注于你对当前任务的投入、你的合作和沟通能力，以及你保持事情顺畅运行的能力。

## 32：请谈谈一次你发现工作中某事（你的或他人的）正在干扰生产力的经历——你是如何处理的？

**回答：**

尽量不要过多关注前一份工作的负面方面，而是选择一个你找到了积极且快速的解决方案以提高生产力的实例。关注你注意到机会的方式，你如何向主管提出解决方案，以及该改变是如何实施的（最重要的是，谈谈你如何领导这项变革倡议）。这是一个展示你解决问题能力的绝佳机会，同时也能体现你机智灵活和领导才能。

## 33：在一个目标和目标明确定义的工作中，你表现如何？

**回答：**

回答这个问题时重要的是考虑该职位——显然，如果你能在目标和目标明确定义的工作中表现出色最好（特别是如果你处于入门级或销售职位）。然而，如果你申请的职位具有领导角色或创造性方面，务必重点强调你额外喜欢开发和实施自己想法的挑战的方式。

## 34：在一个你拥有很大决策权的工作中，你表现如何？

**回答：**

面试官想知道，如果被录用，你不会成为那种需要 constantly 监督或每一步都寻求建议、权威或反馈的员工类型。

解释你在果断、富有成效的环境中工作良好，并且你期待在你的职位上采取主动。

## 35：如果你看到另一位员工做不诚实或不道德的事，你会怎么做？

**回答：**

在目睹另一位员工做不诚实的事情时，最好的做法总是按照公司针对此类情况的政策行事——如果你不知道这家公司的具体政策，你可以简单地表示你会根据政策并上报给合适的主管人员来处理。如果你知道公司的政策（例如，如果你正在寻求在自己公司内的晋升），最好根据政策具体概述你的行动。

## 36：请谈谈一次你自学了某件事，后来对你的职业生涯有帮助的经历。

**回答：**

这个问题很重要，因为它让面试官得以了解你对学习和进取的承诺。仅选择来自你个人生活的一个例子，并提供一个简短的故事，以你学到的教训结尾。然后，以清晰和详尽的方式解释这一教训如何转化为你职位上可用的技能或实践。

## 37：请谈谈一次你在工作发展项目想法的经历。

**回答：**

选择一个你发展的典型项目想法，这类项目你在新职位中可能会完成。概述你的想法来源，为确保其成功和相关性所做的研究类型，项目中包含的步骤，以及最终结果。提供具体的前后统计数据，以显示其成功。

## 38：请谈谈一次你在项目上冒险的经历。

**回答：**

无论风险是像承担资源或时间有限的主要项目那样复杂，还是仅仅是自愿承担一项超出你经验范围的任务，都要表现出你愿意走出舒适区并尝试新事物。提供具体的例子，说明你做的某件事为什么是有风险的，并解释你在这个过程中学到了什么——或者这如何为你后来在职业生涯中面临的工作目标做准备。

## 39：你会给想要进入这一领域的人什么建议？

**回答：**

这个问题让你成为专家——并将向面试官表明，你拥有与简历上的培训和教育相配套的知识与经验。提供你的知识作为建议，关于某人会遇到的一些意想不到的事情……


进入该领域时可能会遇到的情况，并且务必以积极的建议结尾，例如说明真正成功所需的热情或奉献。

## 40：你会如何对待消极的同事？

**答案：**

每个人都得应对消极的同事——而做到这一点的最佳方式就是保持积极。你可以尝试与同事建立关系或在某些方面与他们产生共鸣，但即使你的努力遭到冷遇，你也必须保持积极的态度。最重要的是，强调你绝不允许同事的负面情绪影响自己的工作或生产力。

## 41：如果你看到同事上网、看书等浪费公司时间，你会怎么做？

**答案：**

面试官希望看到你认识到员工浪费公司时间的危害，并且明白你不会对此轻视。解释你会如何遵守公司政策，无论是自己与同事谈话、直接向主管报告这种行为，还是与人力资源部门的人沟通。

## 42：你如何对待自己与其他员工之间的竞争？

**答案：**

健康的竞争可以是一件好事，最好将重点放在其积极的方面。不要提及自己与其他同事之间的冲突，而是专注于如何受他人出色工作的激励而保持动力，以及同事如何成为帮助你迈向新成功的强大支持网络。

## 43：什么时候可以跟同事社交？

**答案：**

这个问题有两个极端的答案（随时都可以，或者永远不行），大多数情况下，面试官希望看到你处于中间立场。与同事建立稳固的关系很重要，但绝不能以牺牲工作为代价。理想情况下，建立关系可以通过团队合作锻炼和特别项目实现，也可以在休息室进行。

## 44：告诉我上一次工作中发生重大变化时的情景，你是如何应对的。

**答案：**

提供情境的背景，包括旧系统、变化是什么、如何实施以及变化的结果，并包含你在每个步骤中的感受。确保你对旧系统的初始看法是中立的，并且随着新变化的每一步，你的兴奋程度逐渐增加，因为面试官会很高兴看到你的适应能力。

## 45：在分配任务时，你如何选择哪些任务交给哪些团队成员？

**答案：**

面试官希望通过这个问题了解你的思维过程，所以务必提供选择背后的详尽理由。解释你根据每个人的……

## 46：告诉我一次你不得不就你坚信的事情向同事或上级据理力争的经历。

**答案：**

虽然向面试官解释冲突情境可能很难，但这是展示你的热情、信念以及对所坚持之事奉上的绝佳机会。向面试官解释的不仅是情况本身，还要详细说明为什么站出来捍卫这个问题对你如此重要，以及你的同事或上级事后对你的反应——他们更尊重你了吗？不接受意见吗？思维开放吗？道歉了吗？

## 47：告诉我一次你帮别人完成工作的时候，即使那并不是“你的职责”。

**答案：**

虽然被要求分担别人的工作时可能会感到沮丧，但保持积极的态度去伸出援手是很重要的。面试官会看你是否具有团队精神，通过帮助他人完成他或她独自无法管理的任务，你既展示了对团队成功的乐于助人态度，也展示了自己的能力。

## 48：团队合作的挑战是什么？你如何应对？

**答案：**

团队合作有很多显而易见的挑战，例如处理不同的观点、协调个人的时间表，或适应难缠的同事。最好只关注一个挑战，比如团队成员错过截止日期或未能履行承诺，然后提供一个明确解决该问题的方案。例如，你可以组织每周的状态会议让团队讨论进度，或者分配更短的截止日期以确保长期截止日期按时完成。

## 49：你重视工作场所的多样性吗？

**答案：**

工作场所的多样性很重要，因为它有助于培养一种包容、平等且充满不同观点和背景的环境。务必展示你对这些问题的认识，并强调从他人经验中学习的重要性。

## 50：你会如何处理同事不接受他人多样性的情况？

**答案：**
