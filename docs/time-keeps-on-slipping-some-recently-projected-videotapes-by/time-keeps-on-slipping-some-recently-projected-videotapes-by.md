# 时光飞逝（亚历山大·克吕格近期放映录像带选）





亚历山大·克卢格1988年为德国电视节目《10点差一刻》制作的三部录像带，上月在白教堂美术馆展映。在此，玛丽娜·维施米特梳理了这些影片中交织的复杂拼贴：战时影像、广告与哲学内容，结合克卢格提出的“对抗性公共领域”概念展开分析。

新德国电影运动。这便是新批评派。克卢格曾有一句戏言，描述联邦德国对法国新浪潮的回应：“我们晚了两年才跟上，但我们把这条路走得足够透彻。”
这一现象也可置于当时大量涌现的民族小国电影运动的语境中观察，这类运动的特点在于坚持认为社会现实才是电影艺术（胶片魔法）的正当表现素材。同时主张影像可以且应当呈现自身的媒介属性，打乱类型与主题的常规搭配，明示自身是被建构的，进而也暗示了贯穿其中的社会与生产关系的建构性。

亚历山大·克卢格自20世纪60年代初便涉足电影创作，但如今他最为人熟知的身份是1972年与奥斯卡·内格特合著*公共领域与经验*的作者，以及以巴德尔-迈因霍夫集团为主题的拼盘电影*德国之秋*其中一集的导演。
从本雅明式的、主张用大众反电影切实推动对抗性公共领域形成的热忱，到二十五年后在德国私营地面频道深夜时段播出内容时那股“偷偷搞事”的愉悦劲头，这位现代主义通才（身份包括律师、批判理论家、科幻小说家、电影与录像创作者）做事从来都是彻底到底的。
不久前的白教堂美术馆电影项目，由伊恩·怀特与格哈德·里希特“图谱”展览联合策展，曾展映过克卢格的这部分作品。

这四部1988年制作的电视短片浓缩了克卢格的核心关切：
人与历史的互动会产生何种主体性？更准确地说，与历史影像的互动又会催生怎样的主体性？
表面上截然不同的时代与符号秩序之间存在怎样的联结？将它们强行并置能否让隐性的想象显形，让显性的常识荒诞化？
一个小小的视频生成的指示标记，对于解读档案影像而言又有多关键？

然而这些影片的作用不止于提供一份带有思辨性的德国二十世纪另类历史，也超越了影像与意识形态之间常见的说教式不稳定关系；每一部影片都是一个埋藏了多层密码的宝库，经得起一次甚至多次观看后仍会激发出全新的解读。
既然影片已经将广告、哲学、战时新闻短片，以及录像艺术现成特效的粗糙魅力精巧地拼贴在一起，涵盖了极为丰富的来源素材，要是它不具备这些特质才叫奇怪——不过它本身已经足够古怪了。

> **记忆拼贴/蒙太奇即为度量**
这三部影片《广告古董》《迅变之时》《你为什么哭泣，安东尼奥？》时长均在15至25分钟之间。
它们构成了一种类别于德国文化集体心智的论战式遐思，通过新老媒体——档案影像、静帧、文字，以及模拟录像操控技术不稳定、歪歪扭扭的介入——断断续续却极具吸引力地拼合而成。
互不兼容的时间观、事件与情绪的不断移位、即时历史化的理念，这些内容一方面来自影片的视觉内容与结构，另一方面也来自这些媒体形式相互竞争的表达指向——这些形式在项目首播时便已经是刻意的时代错位产物，在可塑的数字数据矩阵构成的永恒当下中，这种错位感只会更加强烈。
这种触感式的、困惑的观看体验凸显了透明化解读历史的不可能性：现成影像遭到了严重的篡改，指向（有时是字面意义上的，用可爱的箭头或圆圈标注出）人的能动性的介入——也就是在流传的历史陈词滥调中注入的创造性。
这带有一丝尼采式的意味：“任何文献记录都已经是评价”，尤其是当它唯一想记录的就只是自身*活泼的商品吸引力*时（《广告古董》）。
将影像与历史的关系问题化、揭示其现实效果的偶然性，这种批判如今看来已经有些老生常谈，它高度嵌入我们周遭的所见之物，几乎成为不言自明的常识。
但这种批判一旦被主流吸纳，也就被消解了。克卢格摒弃了后现代主义那种将影像的真实性声明一律抹平的做法——这种做法最终只会为统治工具镀上光鲜的外壳。
将可能性极低的时间段与影像格式并置，不仅不会消解意义，反而会催生出更多记忆与体验的可能性。
在*迅变之时*中有一段情节：一群时髦的当代德国知识女性在新年夜围坐在桌旁，微醺着试图记起贝多芬的*欢乐颂*的歌词。
她们执着却心不在焉的尝试，或许正是高雅文化所遭遇的再挪用的一个缩影：那首曾经以豪言壮语赞颂民族情感的歌曲，后来画面切到了上千人的日本合唱团演唱它的场景。
这一幕初看或许显得不协调，直到你意识到两国历史致命地纠缠在一起。
克卢格对历史记录的“大刀阔斧”改造，也运用了灵媒技术来消解时间，这也表明了他将电视称为“闹鬼水族箱”的这一旧绰号看得非常认真。
这里的异化审美手法同时呼应了“alienist”（早期对精神分析师的称呼）的双重含义：一是挖掘历史事件中被郑重置换的潜文本，二是作为一种媒介，通过在本时代制造“错误”的关联，传递另一种时代精神。
这些手法同时也从感官层面实现了“闹鬼”的效果：灵质式的影像合成、给档案静帧加的诡异彩色滤镜，以及在静帧中飘过的幽灵般的电脑生成图形。
如果影像是历史定见的认证者，那它同时也是历史定见被扭曲的特权场域。

## 理性的长眠
影片中那些具有德国特指的指涉，并不会因为扩散到更广泛的欧洲（极少涉及美国）语境中就被抹去——尽管*迅变之时*和*广告古董*拼贴了大量德国物质文化的残片，比如旧广告、海德格尔-阿伦特式的伤感叙事、纳粹的体育表演动作。
*你为什么哭泣，安东尼奥？*则反思了影响整个欧洲的时代性事件：张伯伦的绥靖政策、墨索里尼的上台、以及一战停战后的初期局势。
不过这些事件都是通过德国浪漫主义传统中的“诡异”视角来解读的。
这种解读方式还与法兰克福学派对克卢格的持久影响相结合，促使他将本雅明和阿多诺关于“法西斯主义将政治审美化”的论断，与对德国文化中非理性主义遗产的堂吉诃德式认知联系起来——另一位新德国电影运动的代表人物维尔纳·赫尔佐格也曾对这一遗产抱有同样的兴趣。
非理性被错误驯化的问题，是克卢格系统性强调的核心要点。
克卢格通过依次呈现的场景追溯法西斯主义的史前史：他将新年夜烟花的画面与盟军空袭的画面拼接得几乎一模一样，还在古老的占星图上标注了重大历史日期，图的正中央印着贝多芬的画像。
民族对神秘主义的偏好并不是问题的关键；克卢格更关注的是，战后的几十年里德国不愿面对自己近期历史的后果，他通过塑造那些在漫无目的的现代性进程中长期潜伏的假想非理性怪物，来讽刺这种回避态度。
对克卢格而言，这种做法将不可避免地引发一种认知：法西斯主义在社会民主主义的西德始终存在，也就是[被压抑者的回归]，这一现象受冷战现实政治的影响而不断扩散。
*你为什么哭泣，安东尼奥？*中出现了张伯伦前往意大利调停和平的场景，他陪同墨索里尼及其喽啰前往歌剧院。
演出的剧目是威尔第的《麦克白》。
影片字幕指出，张伯伦及其内阁都是理性主义者，不相信女巫的存在。
因此他们根本无法察觉到法西斯主义和国家社会主义的谋士们所带来的威胁。
他们也没有足够的历史眼光去解读灾难的预兆，反而持一种冷漠的态度，认为希特勒提出的“生存空间”理念，与被殖民统治的印度民众的激进教派主义并无太大区别。
之后一段旁白点出了这一历史断裂点，告诉我们绥靖政策“要么导向和平，这种情况下一以贯之地推行便是正确的；要么导向战争，那它从一开始就是错误的”。
后续内容还恋物般地执着于展示张伯伦与希特勒在一家宜人乡村酒店举行重大峰会的档案影像，还调用了战前和战后的纪念明信片，直观地还原二人的密会场景。
如果张伯伦不知道自己踏进的是怎样的漩涡，那么……

# 时间不断流逝（亚历山大·克吕格近期放映的录像作品）
纳粹主义对其自身而言从来都是透明的：推动这台杀戮机器的技术理性与偏执神秘主义的混合燃料起初极具韧性，但最终难逃覆灭——正如老苏联新闻片里防腐处理的列宁在葬礼上展现的僵尸式个人魅力，这一片段占据了*变化的时间（快版）*的大部分篇幅。此处的戈仑形象或许是一个具有启发性的模型。这些档案影像经克吕格精湛的手工技艺与马克思主义政治理念重新活化后，呈现出一种不死状态，但这并不比它们被判定为“有生命”时更甚——只有当我们能够把握其可读性、权威性的模棱两可本质时，活生生的经验才能真正对其发挥作用。戈仑同样是由边缘群体——东欧与中欧的意第绪小聚居区犹太人所催生的化身，是对统治空虚性的诺斯替式启示，也是一次试图挪用部分统治权力的想象性尝试。考虑到克吕格赋予批判性媒体实践的颠覆性潜能，以及通过构建可转译为主观与集体现实改造工具的对立意义星丛来揭穿体制叙事的做法，这些都极具深意。无论如何，确实有一种景观正在欧洲蔓延。

### 《前摄录影》
克吕格的影片中有一些片段，群众社会动员的奇观被消解为荒诞可笑的存在，大众类型片也被商业主义的病毒接种了针对自身滥情的疫苗。其中一个奇幻片段是纳粹时代的运动员们在完成“欢乐源自力量”的狂热仪式后，以精巧或许自发的方式组合成一个人体纳粹卐字标志；还有一组纳粹时代爱情片的精彩花絮，其中温柔时刻的画框从未脱离1930年代高级火柴与奢侈鞋履广告的图形植入。纳粹运动员们还遭到一家儿童教科书公司的广告侵扰，该广告突出了雅利安人完美主义学说与教育机构推销的自我提升主张之间的紧密关联；而热恋中的情侣则被提醒，在资本主义中，人类情感与消费品一样具有可替代性。
克吕格在1965年的文章《文字与电影》中评论道，他所设想的那种脱节式电影/文本实践存在一种风险，即沦为“总体艺术作品”。调动如此多的情感与话语路径来打造一种具有对抗性的新电影语言，在他眼中与纳粹的“总体艺术作品”有相似之处。一种既不复制幻象叙事形式，也不陷入非政治化“深层结构”抽象的电影，必须将自身塑造为意识建构工具，克吕格将此视为左翼与反动社会变革运动之间危如累卵的桥梁。法兰克福学派的核心命题认为，纳粹主义是资本主义的终极形态，因为它证明了自己能够调动整个生产过程（而非仅仅以自由民主国家那种零敲碎打的方式），在此处它象征性地对应着催生革命文化生产的欲望；但这一命题也预见了当下关于情感劳动、社会生产力被五花八门的“认知资本主义”与行政管理治理模式实际吸纳的讨论。
克吕格主张可能存在一种反生产性、一种“对抗性公共领域”，但他对这一设想大规模落地的前景似乎持矛盾态度，因为届时极权主义冲动可能会乘虚而入。这正是“对抗性”与“公共”这两个术语试图框定的两难困境：只要已建立的权力领域内存在顽固的异质阶层，它们就能发挥作用，在共识的顺畅流转中制造批判性断裂。但“对抗性”天然具有寄生性。当公共领域的托词如今已形同虚设，反生产性不得不内在于行政功能的原子化区域中零散运作，常常深藏于这些区域麻木不仁的缝隙之中时，会发生什么？如今的寄生性以不同的方式被中介，博弈的赌注已经发生转移。
1998年，亚历山大·克吕格在接受汉斯·乌尔里希·奥布里斯特采访时提到，“保守派对公共领域的兴趣”恰逢其相对过时的时刻。我们或许可以推测，在克吕格看来，此时对抗性公共领域的战略必要性或许已经需要推倒重来——毕竟它所对抗的公共领域，在权力的博弈计算中已不再重要。
2004年1月29日，亚历山大·克吕格的*你为什么哭，安东尼奥？*、*广告古董*与*变化的时间（快版）*作为伊恩·怀特策划的*格哈德·里希特电影计划*的一部分，在怀特柴普尔美术馆放映。相关的*格哈德·里希特——图集*展览将一直开放至2004年3月14日。克吕格为德国电视台制作的影片可供租赁或购买，请联系Electronic Arts Intermix。
