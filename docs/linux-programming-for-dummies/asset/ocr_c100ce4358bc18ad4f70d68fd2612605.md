In this case, the file drawer is really an archive file with your own name. Inside the archive file are all your other files that relate to your program.

Suppose that you're building the payroll program that I mention in the section, “Stopping Your Program in an Emergency,” earlier in this chapter. The program consists of a program file and subprograms, data files, and documentation files.

You can organize these files by creating subdirectories, or you can save them in an archive file by typing the following command:

```
ar q payroll_1_lib payroll1
```

The **q** command tells the computer to *append* the file *quickly* to the library file, while **payroll_1_lib** is the name of the library file, and **payroll1** is the file that the command places in the library file.

Whenever you want to use the payroll file, you ask your computer to retrieve it from the library file, as follows:

```
ar x payroll_1_lib payroll1
```

The **x** command tells the computer to *extract* the file from the library. After you finish with the file, you return it to the library by using the **r** command, as follows:

```
ar r payroll_1_lib payroll1..
```

# Pausing Your Program

You can make your program pause at any time by using the `sleep` command. This command temporarily stops the execution of your code until a specified number of seconds passes, as in the following example:

```
echo "How do you get 4 elephants into a compact car?"
sleep 10
echo "Two in the front, and two in the back"
```

In this example, your computer first asks a question, and then the program tells it to pause for ten seconds. Then the punch line appears on-screen. (That’s a sick one.)
