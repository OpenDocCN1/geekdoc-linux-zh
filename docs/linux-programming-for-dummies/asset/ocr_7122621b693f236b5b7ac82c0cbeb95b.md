+   4.  Modify the program in the preceding exercise. Add 100 to whatever amount the person enters into the keyboard.

```
#!/bin/bash
clear
echo "How much money do you want to make this year?"
read salary
let salary="$salary + 100"
```

```
#!/bin/bash
clear

let salary=$salary + 100

```
