### if

```
if [ condition ]
then
    instruction
fi
```

如果某个*条件*存在——即*条件*为真——您的程序将执行该指令。

### if elif

```
if [ condition_1 ]
then
    instruction_1
elif [ condition_2 ]
then
    instruction_2
fi
```

如果*condition_1*为真，您的程序将执行第一组指令。然而，如果*condition_1*为假，您的程序将判断*condition_2*是否为真。如果*condition_2*为真，您的程序将执行第二组指令。如果*condition_2*为假，您的程序将跳过第二组指令。

### if else

```
if [ condition ]
then
    instruction_1
else
    instruction_2
fi
```

如果*条件*为真，您的程序将执行第一组指令……但如果*条件*为假，则执行第二组指令。

### while

```
while [ condition ]
do
    instruction
done
```

*条件*必须是一个变量或表达式，其结果为真值或假值。
