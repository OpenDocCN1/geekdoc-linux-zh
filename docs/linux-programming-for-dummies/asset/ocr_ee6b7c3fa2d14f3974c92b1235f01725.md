> Keep in mind that the vi text editor commands are case sensitive, so you must use the commands in either upper- or lowercase as they appear in the table.

Table B-1 Commands for Moving through Text Line by Line

| Command | What It Does |
| :--- | :--- |
| nG | Moves to the line that you specify as n. If you specify no line, the cursor moves to the last line in the text. |
| n (# of lines to move) | Moves up the number of lines that you specify as n while remaining in the same column of the line. |
| n (# of lines to move) | Moves down the number of lines that you specify as n while remaining in the same column of the line. |
| H | Moves to the first line of the page shown on-screen. |
| M | Moves to the middle line of the page shown on-screen. |
| L | Moves to the last line of the page shown on-screen. |
| + or Enter | Moves to the first nowhite space on the next line. A nowhite space is a character that you can see in your text. A white-space character is a character that you can't see, such as a tab character. |
| - | Moves to the first nowhite space on the previous line. |
