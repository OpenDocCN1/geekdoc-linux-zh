My e-mail address is the same as your e-mail address, because both of us use the root user ID. My e-mail address, therefore, is root@mycomputer. I first create an e-mail and save the e-mail in a file with the name memol. You can call the file anything you like.

At the command prompt, I type the name of the mail utility, following it by the destination address and the name of the file that contains the e-mail message, as shown in the following example:

```
```
mail root@mycomputer < memol
```
```

The name of the mail utility is mail. (Not very creative is it?) A space separates mail from the destination address, which is root@mycomputer in this example. I use the less-than symbol (<) to tell the mail utility the name of the file that contains the e-mail message.

The geeks call the less-than symbol redirection of input. This term sounds confusing, but as is the case with many terms that you use in programming, this one is very easy to understand. Input refers to where the mail utility receives the e-mail.

If we leave out the less-than sign and memol, the mail utility assumes that you’re going to enter the e-mail message directly into the mail utility from the keyboard. You can do so, but you need to know the mail utility’s text-editing commands. (For more about mail text-editing commands, see the sidebar “Composing and editing e-mails by using the Linux mail utility” in this chapter.)

The less-than sign, however, tells the mail utility to get the e-mail message from the file memol instead of from the keyboard. In essence you’re redirecting words that you normally type from the keyboard to the file memol.

After you press the Enter key, the mail utility sends the file memol to the e-mail address root@mycomputer.

# Reading e-mail
