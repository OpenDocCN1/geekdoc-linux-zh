   fi
   mail -s $subject bob@mycomputer mary@mycomputer < $file
else
   echo "You did not enter the correct number of arguments."
fi

+   2. If four arguments pass, the program uses an *if* statement to determine whether the first argument is *-s*. If so, the program creates the variable *subject* and assigns the second argument ($2) to the variable.
