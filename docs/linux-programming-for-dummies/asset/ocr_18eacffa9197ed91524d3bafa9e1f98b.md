# Dividing two numbers by using the / operator

To divide two numbers, use the `/` (forward slash) operator, as in the following example:

```
```let TotalCom=500let Commision=5let Computers="$TotalCom / $Commision"```
```

`let TotalCom=500` tells the computer to create a variable by the name of TotalCom and to assign that variable the value 500.

`let Commision=5` tells the computer to create a variable by the name of Commision and to assign that variable the value 5.

`let Computers="$TotalCom / $Commision"` tells the computer to create a variable by the name of Computers and to assign it the value of TotalCom divided by the value of Commision. In this example, the value of Computers equals 500 / 5, or 100.

# Dividing by using the % operator

To divide two numbers and calculate the remainder, use the `%` (modulo) operator, as in the following example (and you probably get the idea by now, right?):

```
```let a=10let b=3let c="a % b"```
```

`let a=10` tells the computer to create a variable by the name of `a` and to assign that variable the value 10.

`let -=3` tells the computer to create a variable by the name of `b` and to assign that variable the value 3.

# Negating numbers by using the – operator

The `-` operator can transform a positive number into a negative number. This process is known as *negating a number* and you accomplish it by placing the `-` operator in front of any number or variable that contains a number, as in the following example:

```
```let AfterTaxes=-3000```
```

`let AfterTaxes=3000` tells the computer to create a variable by the name of `AfterTaxes` and to assign it the negative value of 3000. In this example, the value of `AfterTaxes` is -3000.
