# Chapter 4: Getting Indecisive with Variables

+   1. Say that you want to write a Linux program to keep track of your personal telephone list. Before you can solve this problem, you need to list all the pieces of information that you need to create the telephone list. What information do you include?
+      Answer: First name, last name, street, city, state, Zip code, home phone.
+   2. Each piece of information on your list in the preceding exercise you must identify in your program as a variable. Write down possible names of the variables that you can use for each piece of information on your list. (Remember the guidelines for naming Linux files.)
+      Answer: FName, LName, Street, City, State, Zip, Hphone.
+      Of course, your names may vary somewhat.
+   3. Which of these piece(s) of information can you use to look up a telephone number?
+      Answer: LName, FName.
+   4. Write the instruction that tells the computer to assign the name *Bob* to the FName variable.
+      declare FName="Bob"
+   5. Write the instruction that tells the computer to declare the FName and LName variables without assigning a value to these variables.
+      declare FName, LName
