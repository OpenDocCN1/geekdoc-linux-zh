# # Chapter 14: Getting Down with Subprograms

+   1. Create a subprogram with the name greeting that displays Hello and then create a program to call the greeting subprogram.
+   Program:
+   ```python
+   #!/bin/bash
+   greeting
+   ```
+   Subprogram: greeting
+   ```bash
+   echo "Hello"
+   ```
+   2. Write a subprogram with the name addition that adds 5 and 6 and then displays the results on-screen. Create a program to call the subprogram.
+   Program:
+   ```python
+   #!/bin/bash
+   addition
+   ```
+   Subprogram: addition
+   ```bash
+   let sum="5 + 6"
+   echo "$sum"
+   ```
+   3. Write a subprogram with the name name that displays Bobby. Write a program that displays Hello and then calls the subprogram.
+   Program:
+   ```python
+   #!/bin/bash
+   echo "Hello"
+   name
+   ```
+   Subprogram: name
+   ```bash
+   echo "Bobby"
+   ```
