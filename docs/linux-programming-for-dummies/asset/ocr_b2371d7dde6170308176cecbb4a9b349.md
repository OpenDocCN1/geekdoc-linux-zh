# Stopping $\nu i$ and saving changes

Starting $\nu i$ and entering text on the page is easy; Getting out of $\nu i$ is a little tricky. You can eject yourself from $\nu i$ in the following several ways if you’re in command mode:

+   ✓ Type :q to stop $\nu i$.
+   
+   If you haven’t saved your file, $\nu i$ prompts you to do so.
+   
+   ✓ Type ZZ to save your changes and to stop $\nu i$.
+   
+   ✓ Type :wq to save your changes and to stop $\nu i$.
+   
+   ✓ Type :q! to stop $\nu i$ without saving your changes.
