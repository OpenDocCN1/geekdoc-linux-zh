let c= "a % b" tells the computer to create a variable by the name of c and to assign it the value equal to the remainder of the value of a divided by the value of b. In this example, the value of c equals 10 % 3, or 1.

# ## Logical Operators

You use *logical operators* to tell the computer to evaluate *true* and *false* values. A true value is any value that’s not zero, and a false value is a zero. Table 6-2 shows the common logical operators.

**Table 6-2 Logical Operators**

| Operator | What It Does |
| :--- | :--- |
| ! | Reverses the logic, as in saying, “I hope *we’re* going to get a lot of rain today — *not*.” |
| && | Variable1 *and* Variable2, as in saying, “*Bob and Mary* are an item.” |
| \|\| | Variable1 *or* Variable2, as in asking, “*Is Mary or Sue* dating Bob?” |

# ## The ! (not) operator

Thanks to television, you have a new way of saying things today — for example: “I’m going to give you a 20 percent increase in pay — *not*.” Such a statement gets your hopes up and then slams reality in your face. The first part of the phrase leads you to believe that the statement is true. The speaker reverses this true meaning to a false meaning, however, by adding the simple word *not*.

You can change a true statement to false just as I did here by using the ! (*not*) operator.

You can also use the ! operator to change a false statement to true. Here’s an example:

```
$salary = 3000
```
