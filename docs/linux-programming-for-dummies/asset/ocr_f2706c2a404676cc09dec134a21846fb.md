# Chapter 12: Nested Loops and Quick Exits

+   1. Write a program that asks someone to enter his name and then end the program only if the person enters the word *stop*.

Hint: Use the *break* keyword to end the loop in the program.

```
#!/bin/bash
declare flag="go"
while [ "$flag" -eq "go" ]
do
    clear
    echo "Enter your name or type stop to end:"
    read friend
    if [ "$friend" -eq "stop" ]
    then
        break
    fi
done
```

+   2. Modify the preceding program to make the computer return to the top of the loop if the person enters the name *Tom*.

Hint: Use the *continue* keyword.

```
#!/bin/bash
declare flag="go"
while [ "$flag" -eq "go" ]
do
    clear
    echo "Enter your name or type stop to end:"
    read friend
    if [ "$friend" -eq "stop" ]
    then
        break
    fi
    if [ "$friend" -eq "Tom" ]
    then
        continue
    fi
done
```
