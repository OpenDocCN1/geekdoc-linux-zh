+   1. What's the difference between a file and a database?
+   a. A file stores data organized into fields.
+   b. A file is something that you use to break out of jail.
+   c. A database must store information in an organized format, but a file doesn't.
+   d. You use a file to hold data, while a database is what Data calls home in Star Trek: The Next Generation.

+   2. How can you copy only some data in a database file to another file?
+   a. Use the indirection operator.
+   b. Use a No. 2 pencil to copy the data from the screen.
+   c. No one would ever want to copy data from the database file.
+   d. Use the redirection operator.

+   Answers: 1) c. See “A File and a Database.” 2) d. See “Extract information to a file.”
