# ## Creating the Sidebar

The sidebar contains three main areas, each of which is then added to *bar.php* (which was loaded in *header.php*; refer to Example 8-3).

# ### Dealing with Dates

The first area of the sidebar displays the name and year of the month being viewed, and also provides arrows to allow the user to select the previous or next month. These arrows link to *view.php* and pass it a data GET variable with the month in the format `<month>-<year>`, such as *view.php?date=10-2005* (for October 2005).

The left arrow (*go to the previous month*) simply subtracts 1 from the current month, and the right arrow *adds 1 to the month* (*to go to the next month*). You also need to provide some code to deal with January and December. If the user is looking at 1-2005 (January 2005), the left arrow should link to 12-2004 (December 2004). Likewise, the right arrow for 12-2005 should link to 1-2006.

With all this in mind, *create bar.php* and add the following code:

        $month = date("n", mktime());
        $numdays = date("t", mktime());
