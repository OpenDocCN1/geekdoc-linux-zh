### Logging Out

Create a file called *userlogout.php* and add the code to log the user out, as shown in Example 9-5.

**EXAMPLE 9-5** The logout code unregisters the user’s session variables.

```php
<?php
session_start();
require('config.php');
session_unregister('SESS_USERNAME');
session_unregister('SESS_USERID');
header('Location: ' . $config_basedir . 'index.php');
?>
```

To prevent logging out both the user and admin out when both are logged in, this code does not destroy the session. The script simply unregisters the session variables, and they become inactive, logging out the user.
