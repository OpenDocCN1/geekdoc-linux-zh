# VIEWING EVENTS

The vast majority of calendars have a very similar interface. This interface typically includes a view of the entire month, with each day shown with its date. Usually, the days are represented as squares, and events on those days are positioned inside the squares. And, for usability, each day's events are normally listed in chronological order.
