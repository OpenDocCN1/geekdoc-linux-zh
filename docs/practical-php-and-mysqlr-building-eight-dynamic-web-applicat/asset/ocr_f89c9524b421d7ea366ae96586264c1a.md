# Practical PHP and MySQL

The pf_validate_number() function validates the category id GET variable that is passed to the page. If no id GET variable exists, the function redirects to the site's base URL.

Select the products from the database:

```
$validid = pf_validate_number($_GET['id'],
"redirect", $config_basedir);
require("header.php");
$productsql = "SELECT * FROM products WHERE cat_id = " . $_GET['id'] . ";";
$productres = mysql_query($productsql);
$numrows = mysql_num_rows($productres);
if($numrows == 0)
{
    echo "<h1>No products</h1>";
    echo "There are no products in this category.";
}
```
