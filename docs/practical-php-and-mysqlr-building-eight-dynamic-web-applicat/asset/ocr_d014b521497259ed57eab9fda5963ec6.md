# **Poking at $_FILES**

If you want to see what is in the `$_FILES` array, or any other variable or array for that matter, use print_r():

```
print_r($_FILES);
```

To access specific information from a specific array, use the following format:

```
$_FILES['array']['item']
```

For example, you could refer to the filename of the file in the userfile box that you added by using:

```
$_FILES['userfile']['name']
```
