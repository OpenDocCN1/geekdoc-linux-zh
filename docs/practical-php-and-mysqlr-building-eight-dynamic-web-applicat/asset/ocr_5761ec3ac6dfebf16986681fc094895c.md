# ADMINISTRATOR PAGES

The administration side of the shopping cart is very simple. The primary function for the admin is to view and confirm completed orders. When an order has been confirmed, the administrator has successfully sent out the product.

The first step is to provide an administrator login. Create a new file called *adminlogin.php* and add the following code:

