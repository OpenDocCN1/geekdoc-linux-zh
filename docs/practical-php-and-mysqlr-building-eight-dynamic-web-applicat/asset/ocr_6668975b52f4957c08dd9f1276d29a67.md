The header contains a `<h1>` tag that you can style:

```
#header h1 {
    font-size: 30px;
    text-transform: uppercase;
    letter-spacing: 0.3em;
    color: #fff;
}
```

In this example, you set the *font-size* and *color* and then used the *text-transform* feature to convert all the text inside the `<h1>` to uppercase letters. The *letter-spacing* instruction then sets the size of the spacing between the different letters.
