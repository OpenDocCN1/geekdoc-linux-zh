```
function include_header() {
    global $config_headerfile;
    if(file_exists($config_headerfile)) {
        include($config_headerfile);
    }
}
```

The function checks if `sconfig_headerfile` points to a legitimate file and then includes it if the file exists. This function is used in the different blocks inside the switch later. This function avoids the same problem of content already being sent when the page redirects.
