The delete SQL syntax is fairly simple: DELETE FROM<table> WHERE id =<the id of the thing you want to delete>. After the delete is made, the page redirects to the next level up in the page hierarchy. As an example, when you delete a topic, the forum topics page will be deleted. See Figure 5-12.
