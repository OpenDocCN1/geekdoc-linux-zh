# Displaying Questions

Questions and answers are the lifeblood of a FAQ site, and in this section, you create the code to display them. The functionality is spread across two pages. The first page (questions.php) displays a summary of the questions inside the topic, and the second page (answer.php) displays the answer and comments for that specific question.
