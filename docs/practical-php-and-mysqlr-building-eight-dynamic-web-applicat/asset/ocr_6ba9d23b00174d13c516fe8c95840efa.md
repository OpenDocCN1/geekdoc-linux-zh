# CONNECTING TO MYSQL IN PHP

With some core PHP experience and a database development behind you, now is the time to perform the all-important step of hooking the two together and connecting to the database in PHP. This involves you creating the database connection, then issuing a SQL query, and finally dealing with the results of the query in a way that makes sense in your Web application.

To actually connect to MySQL, PHP provides built-in support to make the connection, perform queries, and deal with the results. To do this, a number of PHP functions, prefixed with mysql\_, make the magic happen. Although these functions are very useful, there may a case in the future when you want to be able to use any one of a number of databases with your Web application. With this requirement, you would need to use a third-party database abstraction library, such as PEAR::DB or ADO DB. If you know you will be using MySQL for a specific project, however, the mysql\_ range of functions is perfectly suitable.
