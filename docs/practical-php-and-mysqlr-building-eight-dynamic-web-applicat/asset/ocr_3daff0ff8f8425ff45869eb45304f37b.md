# The *ratings* Table

+   -   **id.** Make this an INT and turn on `auto_increment`. Set this field as a primary key.
+   -   **user_id.** Make this an INT.
+   -   **story_id.** Make this an INT.
+   -   **rating.** Make this a TINYINT.

# Inserting Sample Data

With a solid set of tables ready to go, add some sample data. Remember, do not fill in a number in the **id** column; this will be handled by `auto_increment`. Feel free to add your own sample data or use the suggested information.
