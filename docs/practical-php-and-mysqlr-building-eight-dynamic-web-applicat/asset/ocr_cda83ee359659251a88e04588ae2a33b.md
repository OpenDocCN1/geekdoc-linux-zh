Inside the `<table>` tag is a series of `<tr>` tags, which represents table rows. In the first row, three `<th>` tags add the table headings. In the remaining rows, the main cells are added with `<td>` (table dimension) tags.

Finally, add the footer file:

```
</?php
require("footer.php");
?>
```

To apply the styles, you can theoretically style any of the different table tags (`<table>`, `<th>`, `<tr>`, and `<td>`). First, style the table:

```
table {
    border: thin solid #cccccc;
    background: #ffffff;
}
```

The main visual style you are adding here is a thin solid light gray border around the edge of the table. Now style the table headings:

```
th {
    letter-spacing: 2.5px;
    background: #eeeeee;
    color: #000000;
    text-transform: uppercase;
    text-align: center;
    border-top: thick solid #eeeeee;
    border-bottom: thin solid #cccccc;
}
```
