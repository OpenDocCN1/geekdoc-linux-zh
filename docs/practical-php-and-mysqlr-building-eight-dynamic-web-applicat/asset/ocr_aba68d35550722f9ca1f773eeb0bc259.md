# Ordered and Unordered Lists

Within HTML, Web developers often use ordered and unordered lists to create bullet points. To create a numbered list, you use the `<ol>` and `</ol>` ordered list tags. To create an unnumbered bullet point list, use the unordered `<ul>` and `</ul>` tags.

List items are placed inside `<li>` and `</li>` tags. An example of an unordered list is shown as follows:

```
<ul>
    <li>One item</li>
    <li>Another item</li>
</ul>
```
