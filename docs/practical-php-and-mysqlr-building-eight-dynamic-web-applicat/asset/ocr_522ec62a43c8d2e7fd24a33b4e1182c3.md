```
FROM messages, users WHERE messages.user_id
= users.id AND messages.topic_id = $validtopic
" . " ORDER BY messages.date";
$threadresult = mysql_query($threadsql);
```

In this code, you select all fields from the messages table and the username from the users table and then join users.id and messages.user_id in which the topic_id is equal to $validtopic.
