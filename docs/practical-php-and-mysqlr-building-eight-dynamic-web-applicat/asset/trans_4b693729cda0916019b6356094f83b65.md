**注意：价格格式化**

当你在数据库中使用 FLOAT 存储价格时，尾部的零默认会被移除。为了将价格重新格式化为带零的形式，请使用 PHP 函数 `sprintf()`。该函数接受两个参数：格式化字符串和要格式化的值。格式化字符串可以接受诸如 `%.2f` 这样的值，它要求浮点数保留两位小数（`.2`）（`f`）。

最后，显示并格式化 `dateends` 字段：

  strtotime($row['dateends'])) . "</td>";

}
