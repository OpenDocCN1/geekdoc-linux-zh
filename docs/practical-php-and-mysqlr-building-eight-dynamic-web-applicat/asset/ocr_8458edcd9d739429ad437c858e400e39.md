When understanding this code, it helps to put yourself in the position of the PHP interpreter and assume you have never sent the page before. The very start of this example contains the *if* statement. This line checks to see if the Submit button has been clicked. This is determined by checking if there is a GET variable with the same name as the Submit button (*submitbutt*).

In PHP, a number of special commands can be used to access certain types of variables. In this particular example, you are using *$_POST['submitbutt']* to refer to the *submitbutt* POST variable. If you were to use GET as the method, you also could use *$_GET['submitbutt']*.
