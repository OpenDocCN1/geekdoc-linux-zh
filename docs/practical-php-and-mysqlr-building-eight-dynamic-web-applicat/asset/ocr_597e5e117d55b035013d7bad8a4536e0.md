# *Styling the Side Bar*

Add the bar style webblog:

```
```
#bar {
    float: left;
    width: 200px;
    background: #eee;
    padding: 10px;
    margin-right: 30px;
    height: 100%;
}
```
```

You first set the `float` property to `left`. This property specifies that you want the content on the right to float around the edge of the area being styled. In this case, you float the bar `<div>` so that the main `<div>` appears on the right.

In addition to the `float`, the **width** is set to **200 pixels**, and the background color is set to light gray. You also set a margin of **30 pixels** on the right side, which adds some space between the bar and the main content.

Inside the bar is an image. Some browsers automatically put a rather ugly border around the image, so add a style definition to remove it:

```
```
img {
    border: 0;
}
