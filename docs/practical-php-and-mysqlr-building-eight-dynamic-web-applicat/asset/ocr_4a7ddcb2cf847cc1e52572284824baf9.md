# Signing Out the User

With the user now able to log in, you also need to give him the ability to log out—by destroying the session created on login. Create a new file called _logout.php_ and add the following code:

```
<?php

session_start();
session_destroy();
require("config.php");

header("Location: " . $config_basedir);
?>
```
