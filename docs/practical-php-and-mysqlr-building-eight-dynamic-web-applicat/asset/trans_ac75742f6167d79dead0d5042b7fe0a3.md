### 使用免费软件获取实际成果的实用、动手操作指南

《内格斯实况 Linux 系列》中的书籍旨在鼓励并挑战您在自由软件世界中更进一步。启动随每本书附带的光盘（DVD 或 CD），亲眼见证书中描述的 Linux 系统、应用程序和内容在您面前生动起来。

从新手开始，通过尝试示例，最终成长为专家，掌握该系列涵盖的众多主题，从构建 PHP/MySQL 网站到定制实况 CD 等等。完成学习后，您将知道如何自行使用、定制和重构该自由且开源的软件。

本系列的总策划是克里斯托弗·内格斯（Christopher Negus），他是《红帽 Linux 圣经》系列、《Linux 玩具》系列以及本系列标志性图书《实况 Linux CD》的畅销书作者。
