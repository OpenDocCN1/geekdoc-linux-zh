# Displaying RHEL 9 Applications Remotely (X11 Forwarding)

https://sourceforge.net/projects/vcxsrv/

Once the VcXsrv X server has been installed, an application named XLauch will appear on the desktop and in the start menu. Start XLauch and select a display option (the most flexible being the Multiple windows option which allows each client app to appear in its own window):

![](bbox=[0.298, 0.176, 0.75, 0.462])

Figure 17-1

Click the Next button to proceed through the remaining screens, accepting the default configuration settings. On the final screen, click the Finish button to start the X server. If the Windows Defender dialog appears, click the button to allow access to your chosen networks.

Once running, XLauch will appear in the taskbar and can be exited by right-clicking on the icon and selecting the Exit... menu option:

![](bbox=[0.365, 0.625, 0.685, 0.868])

Figure 17-2
