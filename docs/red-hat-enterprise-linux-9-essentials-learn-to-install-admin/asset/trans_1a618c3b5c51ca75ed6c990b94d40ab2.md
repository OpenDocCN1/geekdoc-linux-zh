如果您希望更改键盘、语言或时间和日期设置，请从主屏幕的本地化列中选择相应选项。在时间和日期屏幕上，选择与您地理位置相对应的选项。还提供了使用网络时间的选项，该选项会自动将系统与外部网络时间协议服务器同步。

由于安装是从本地媒体进行的，因此无需更改安装源设置。要从远程服务器上的媒体完成安装，

选择安装源，启用在网络上选项，然后指定安装媒体的位置和所使用的 URL 类型。安装媒体例如可以是安装在远程 Web 服务器上或使用 NFS 安装在本地网络上的系统上的 ISO 映像（NFS 文件共享的主题在题为“在 RHEL 9 上使用 NFS 与远程系统共享文件”的章节中进行了详细介绍），或远程存储库的 URL（存储库本质上是在线收集的构成操作系统的软件、包和应用程序的集合，可从中对本地系统进行安装）。

默认情况下，安装程序将执行 RHEL 9 的带 GUI 的服务器安装。这将包括运行操作系统和图形桌面环境所需的最小包。要选择不同的安装配置，请选择软件选择选项以显示下方所示的屏幕：

![](img/be1f159c3cc937d7b264dc5b134856dc_31_0.png)

图 3-10

使用左侧面板选择基本配置，并使用右侧面板添加系统启动后您知道需要的任何额外包。如果不需要桌面环境并且不确定要在系统上安装哪些包，请使用最小安装选项，并在系统启动后根据需要安装额外包。这可避免安装可能永远不需要的任何包。

安全策略选项允许在系统上安装额外的安全包，这些包允许对系统施加符合安全内容自动化协议（SCAP）标准的 安全限制。虽然从列表中选择配置文件会安装必要的包，但策略限制只有在运行的系统上启用后才会被强制执行。除非您为政府机构或要求此级别安全性的公司工作，否则在此屏幕上选择策略是可选的。

Kdump 功能在启用时会在系统崩溃时写入操作系统内核的状态。此转储文件可以帮助识别崩溃原因，但在启用时会占用系统内存。除非系统内存有限，否则可以将其保持在启用状态。

配置完基本设置后，下一步是决定如何对硬盘驱动器进行分区以容纳操作系统。

### 3.4 为 RHEL 9 分区磁盘

当选择 *Installation Destination* 选项时，安装程序将显示类似于下图 3-11 所示的屏幕：

![](img/be1f159c3cc937d7b264dc5b134856dc_32_0.png)

图 3-11

默认情况下，安装程序配置为使用当前选定磁盘驱动器上的可用空间自动安装操作系统并配置标准分区大小。如果磁盘以前包含另一个操作系统，这些现有分区将不会被删除，在 RHEL 9 安装后可能在驱动器上留下未使用的空间。要删除任何现有分区以便可以收回并供 RHEL 9 使用，请启用 *I would like to make additional space available* 选项并点击 *Done* 按钮以显示图 3-12 所示的对话框：

![](img/be1f159c3cc937d7b264dc5b134856dc_32_1.png)

图 3-12

要收回空间，请选择不再需要的分区并通过点击 *Delete* 按钮将其标记为删除。选择所有要删除的分区后，点击 *Reclaim Space* 按钮执行删除操作。收回的空间现在将由 RHEL 9 安装程序自动使用。

要手动配置磁盘布局，即可用空间如何分配，请将 *Storage Allocation* 设置从 *Automatic* 更改为 *Custom* 并点击 *Done* 以显示手动分区屏幕（图 3-13）：

![](img/be1f159c3cc937d7b264dc5b134856dc_33_0.png)

图 3-13

手动分区屏幕允许使用逻辑卷管理（LVM）或标准分区配置磁盘。LVM 是推荐的选项，因为它在系统运行后提供了管理分区大小的灵活性（LVM 在题为“*向 RHEL 9 卷组和逻辑卷添加新磁盘*”的章节中进行了详细介绍）。

选择分区方案后，最后一步是决定分区的大小和相应的文件系统挂载点。通常，*Click here to create them automatically* 选项提供的默认配置将满足大多数系统需求。但是，要手动创建分区并分配挂载点，请点击 + 按钮手动声明并分配每个分区。

### 3.5 磁盘加密

### 3.6 用户设置

在安装完成之前，您必须创建 root 密码和可选的用户账户。root 或超级用户账户是具有系统管理权限的特殊用户。虽然您通常会使用自己的账户登录系统，但您需要 root 权限来配置系统并执行其他管理任务。

选择 Root 密码选项并输入足够安全的密码。还提供锁定 root 账户使其无法访问的选项，以及允许通过密码身份验证通过远程连接到系统的远程连接访问 root 账户。一般建议将 root 账户保持解锁状态，但禁止使用密码访问通过远程 SSH 访问。如果需要远程 root 访问，应使用基于 SSH 密钥的身份验证来实现，我们将在本书“在 RHEL 9 上配置基于 SSH 密钥的身份验证”章节中介绍该主题。

接下来，选择用户创建选项并输入用户名和密码。如果您希望此用户能够使用 sudo 命令执行管理任务，还请启用将此用户设为管理员复选框。如果未启用此选项，用户必须使用 su 命令并输入 root 密码才能获得 root 权限（假设上面概述的锁定 root 账户的选项未启用）。如果您添加的用户需要执行管理任务，sudo 是推荐的选项，应启用该复选框。

### 3.7 注册系统

安装过程完成后且系统运行时，系统必须在安装任何更新或额外包之前向 Red Hat 注册。截至撰写本文时，未先注册即可安装 RHEL 9 的 ARM64 版本是可能的，但 X86_64 版本需要在安装前进行注册。要注册系统，请选择连接到 Red Hat 选项并根据您获得 RHEL 许可证的方式选择账户或激活密钥选项。输入信息后，点击注册按钮完成注册过程。
