# Software Repositories

You can download Linux software from many online sources. You can find sites for particular kinds of applications, such as GNOME and KDE, as well as for particular distributions, such as Red Hat. The Red Hat Network can automatically download and update software installed from RPM packages that make up the Red Hat distribution. Some sites are repositories for RPM packages, such as [rpmfind.net](rpmfind.net), and others like [freshmeat.net](freshmeat.net) refer you to original sites. A great many of the Open Source Linux projects can be found at [sourceforge.net](sourceforge.net). Here you will find detailed documentation and recent versions of software packages. For applications designed for the GNOME desktop, you can check [www.gnome.org](http://www.gnome.org), and you can find KDE applications at [apps.kde.com](apps.kde.com). For particular database and office applications, you can download software packages directly from the company's Web site, such as [www.oracle.com](http://www.oracle.com) for the Oracle database.
