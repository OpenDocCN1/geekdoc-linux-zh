You can also right-click the Back or Forward button to display this history list. To clear the history list, select Forget History in the Go menu. Nautilus also supports bookmarks, which can be displayed and edited using the Bookmarks menu. Clicking the Web Search icon will open the page of your specified favorite Web search engine, such as Yahoo or Google.
