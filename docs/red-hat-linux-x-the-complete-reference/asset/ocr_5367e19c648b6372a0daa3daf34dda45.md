```
FF05:0:0:0:0:0:101
```

To broadcast to all the hosts in a link-local scope you would use the broadcast address:

```
FF02:0:0:0:0:0:1
```

For a site-local scope, a local network, you would use:

```
FF05:0:0:0:0:0:2
```
