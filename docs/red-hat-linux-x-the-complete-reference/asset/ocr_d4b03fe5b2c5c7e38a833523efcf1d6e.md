Ethernet device configurations, which would include your IP address and netmask, are placed in the appropriate Ethernet device configuration file in the /etc/sysconfig/network-scripts directory. For example, the IP address and netmask used for the eth0 Ethernet device can be found in /etc/sysconfig/network-scripts/ifcfg-eth0. Local host settings are in /etc/sysconfig/network-scripts/ifcfg-lo.
