The following interfaces constitute the various functions that the VFS may perform, or ask a specific filesystem to perform, on a given inode:

+   int create(struct inode *dir, struct dirent *<span class="math">⟨</span>entry, int mode)  
+   The VFS calls this function with the create() and open() system calls to create a new inode associated with the given dirent object by the specified initial access mode.

+   struct dirent * Lookup(struct inode *dir, struct dirent *<span class="math">⟨</span>entry)  
+   This function searches a directory for an inode corresponding to a filename specified in the given dirent.

+   int link(struct dirent *old_dirent,  
+   struct inode *dir,  
+   struct dirent *<span class="math">⟨</span>entry)  
+   Invoked by the link() system call to create a hard link of the file old_dirent in the directory dir with the new filename dirent.

+   int unlink(struct inode *dir,  
+   struct dirent *<span class="math">⟨</span>entry)  
+   Called from the unlink() system call to remove the inode specified by the dirent entry from the directory dir.
