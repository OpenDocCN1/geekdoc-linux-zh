A call to capable () with a valid capabilities flag returns nonzero if the caller holds the specified capability and zero otherwise. For example, capable (CAP_SYS_NICE) checks whether the caller has the ability to modify nice values of other processes. By default, the superuser possesses all capabilities and nonroot processes none. For example, here is the reboot () system call. Note how its first step is ensuring that the calling process has the CAP_SYS_REBOOT. If that one conditional statement were removed, any process could reboot the system.

```

/* We only trust the superuser with rebooting the system. */

magic2 != LINUX_REBOOT_MAGIC2B &&
```
