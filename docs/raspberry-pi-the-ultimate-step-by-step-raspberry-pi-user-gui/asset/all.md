It is pretty easy to get the module installed and the design allows it to be set right on the Raspberry Pi GPIO pins. To stat you need to shut down the Pi and then open the case.

A simple solution is to cover the lights with electrical tape (white). It will reduce the brightness of the lights so they can be still be seen but not detract from the LedBorg.

As soon as the LedBorg is correctly installed and all other adjustments are mad the case can be closed. Before moving on to the next phase, turn the Pi back on and let it boot up.

First one has to find a suitable software package that come with the requisite drivers which allow access to the LedBorg from the command line and also has a GUI controller.  Just ensure that whichever package you select is compatible with the Raspberry Pi board that you have and the version of Raspbian that you have installed.
