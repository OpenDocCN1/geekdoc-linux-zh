# Detecting Raspberry Pi

There are also some tools you can use to identify a specific IoT device. For example, you can use a piece of software called Raspberry Pi Finder (developed by Adafruit) that gives you a very clean and easy-to-use interface to find out whether a Raspberry Pi is connected to your network:

Figure 10.18 – Raspberry Pi Finder

Another cool feature of this tool is that it is available on Windows, Mac, and Linux. For more information, you can visit their official sites:
