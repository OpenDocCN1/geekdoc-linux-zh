# Understanding cybersecurity vulnerabilities and threats 39

One of the best places to find vulnerabilities is the Common Vulnerability and Exposures (CVE) website, which you can view at https://cve.mitre.org/.

This website has more than 130,000 vulnerabilities that are present on almost all systems (including both software and hardware).

Now, let me ask you, have you ever checked whether your printer is vulnerable? Well, and there are more than 200 vulnerabilities related to printers on this page; some of them are related to denial of service, remote code execution, buffer overflow, and more. So, if you check whether the printers are manageable, do it now!

Do you or your company have a web page created in Joomla? If yes, you will be surprised to know that there are more 1,200 vulnerabilities that are related to Joomla and that is for Joomla because there are many more vulnerabilities for other CMS software:

> > Tip
Many the vulnerabilities are fixed through patches or updates (that is why it's important to keep your systems up to date). However, there are many others that might not have a patch and which you will need to perform some changes to the configuration in order to remove the vulnerability.
