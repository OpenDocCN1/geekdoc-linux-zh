# Introducing Wireshark 259

The following figure shows the output of a scan that we performed on a web page so you can become familiar with the capabilities of the tool and better understand them:

![](bbox=[0.125, 0.131, 0.875, 0.203])

Figure 8-17 – Wireshark scan results

Let's start by analyzing the outputs of the preceding figure. You will see that the very first packet is from your computer asking the DNS server for the IP of the web page. Here, you can validate that the request is going to the required DNS server – in our case it is going to 8. 8. 8. 8 (Google's DNS). If you notice another DNS you may be in the presence of a DNS attack that may reroute your traffic to malicious sites.

Once we get the IP from the DNS server, we start to see exchange of basic TCP packets. After that, we receive some HTTP packets (which is basically the web page that we requested), which is encrypted with an SSL certificate (HTTPS).

> Tip
You can easily sort the results by clicking on the column name of the column. For example, you can use the filter tab to sort all the packets captured by protocol.
