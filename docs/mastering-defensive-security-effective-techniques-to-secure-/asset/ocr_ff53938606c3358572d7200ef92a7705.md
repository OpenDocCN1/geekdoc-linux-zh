# SIFT Workstation

SIFT Workstation is a collection of free and open source forensic tools for performing detailed digital forensics. There are two ways to install it: one is by downloading a virtual machine that is ready to use, while the other is installing it directly on an Ubuntu machine:

![](bbox=[0.137, 0.222, 0.862, 0.523])

The preceding screenshot shows a VM installation of SIFT, which can be download from the SANS web page at https://www.sans.org/tools/sift-workstation.
