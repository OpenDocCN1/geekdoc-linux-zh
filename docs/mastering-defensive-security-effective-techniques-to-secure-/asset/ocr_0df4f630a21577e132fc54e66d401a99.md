# Managing services in systemd

Another way to manage the services is by systemd by using the following commands
we will use mysql service as an example):

+   Checking the status of a service (mysql):

```
systemctl status mysql
The following figure shows the output of the preceding command (inactive),
while Figure 7 shows the output when the service is active (running):
kali$: sudo systemctl status mysql
mysql.service - LSB: Start and stop the mysql database server daemon
Loaded: loaded (/etc/init.d/mysql; generated)
Active: inactive (dead) since Sun 2020-11-22 04:25:13 EST 7s ago
Docs: man:systemd-sys-generator(8)
```
