# Establishing mechanisms to validate compliance

As now, we have developed a framework to ensure you are aligned with any given regulation, but this is not a one-time effort. Instead, compliance is something that needs to be sustained over time, you need to put a mechanism in place to make sure that you are compliant and that you stay compliant over time.

The mechanisms used to test and verify compliance are called audits.

# Exploring, creating, and managing audits

At this point, we have reviewed concepts such as policies, regulations, and also a very cool defensive security strategy: Defense in Depth; however, all these policies, systems, strategies, and controls need to be tested to ensure they are giving the required results and that they are being implemented followed.

In simple words, an audit is a process to test the compliance level of a set of policies, regulations, or requirements.

Audits can be internal or external, let's take a quick look at both.

# Internal cybersecurity audits
