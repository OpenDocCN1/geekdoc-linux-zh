Using the master tool of network mapping – Nmap 245

5. Once installed, the script is very simple to run:

```
nmap -sV --script vulcan/scipag_vulcan/vulscan.nse
scanme.nmap.org
```

This script can also run against additional databases. To do that, add the following argument:

```
--script-args vulscandb=your_own_database
```

As mentioned, one of the cool features of nmap is that you can create your own scripts.

If you want to learn more about how to create your scripts, I highly recommend the book
Mastering the Nmap Scripting by Paulino Calderon, available from Packt.
