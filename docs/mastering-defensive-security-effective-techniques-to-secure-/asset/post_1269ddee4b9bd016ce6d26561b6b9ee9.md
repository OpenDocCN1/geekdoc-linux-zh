As mentioned, Nmap is great for auditing, and you may need to send these results to the server owner so they can take action. The good news is that you can use this simple command to export the nmap results to a .txt file so that you can easily send it to the server owner as an attachment:

```
nmap -A scanme.nmap.org >> server_audit.txt
```

As you can see in the following, the result of the preceding nmap command created a document server_audit.txt and saved it to your working directory, ready to include it in your audit

You can also target sections of your network by using an IP range. For example, the following command will scan all IPs from 192.168.0.1 to 192.168.0.100:

```
nmap -A -v 192.168.0.1-100
```

Note that we also included the -v (for verbose) parameter, which outputs additional information about the process of the scan.

# Enhancing Your Network Defensive Skills

> Tip
> By default, Nmap scans 1,000 ports, but you can increase, decrease, or specify that number by using parameters as -F (fast scan of fewer ports), -p (to specify the ports to scan), or -r (to scan all ports in consecutive order).

There are many more parameters that you can use with nmap. To explore them, simply type the following:

```
nmap --help
```

But there is more! nmap supports scripts created by the community to augment their capabilities, as explained in the next section.

# Nmap scripts

Let's review some of the best nmap scripts that you can leverage in defensive security.

# vulners

This script will make your life easier. It will provide you with Common Vulnerabilities and Exposures (CVEs) related to the open ports, services, and versions found in an Nmap scan.

> What is a CVE?
> In Chapter 2, Managing Threats, Vulnerabilities, and Risks, we talked about one of the best places to find vulnerabilities: the CVE site at https://cve.mitre.org/.

The magical script is called vulners and can be found on the following link: https://github.com/vulnersCom/nmap-vulners.

This script is loaded by default into the standard Nmap Scripting Engine (NSE) library, so there is no need to install it.

The command structure is very simple, so let's explain it:

```
nmap -sV --script vulners [--script-args mincvss=<arg_val>] <target>
```

First, we have the standard nmap command, then we use the -sV parameter because the script needs the version to properly gather the CVE.

Then we call the CVE by using the --script {script_name} parameter.

# Using the master tool of network mapping – Nmap

If we can use the mincvss script to limit the results to CVEs with a score greater than the value provided. An example is follows:

```
nmap -sV --script vulners scanme.nmap.org
```

Now, the script will look for all CVEs related to nmap result. Note that the script uses a huge database of more than 250 GB, so the scan may take some minutes to run.

# vulscan

This is another super cool script that will search for vulnerabilities related to the version found in nmap results.

By default, the script will look for vulnerabilities on the following databases:

- scypdb.csv - https://vuldb.com
- cve.csv - https://cve.mitre.org
- securityfocus.csv - https://www.securityfocus.com/bid/
- xforce.csv - https://exchange.xforce.ibmcloud.com/
- exploitdb.csv - https://www.exploit-db.com
- openvas.csv - http://www.openvas.org
- securitytracker.csv - https://www.securitytracker.com (end-of-life)
- osvdb.csv - http://www.osvdb.org (end-of-life)

Unfortunately, this script is not loaded by default. But no worries, here are the steps to easily install it in Kali Linux:

- 1. Navigate to the nmap scripts directory:

```bash
cd /usr/share/nmap/scripts/
```

- 2. Create a directory for the installation of the files:

```bash
sudo mkdir vulscan
```

- 3. Access the directory:

```bash
cd vulscan
```

- 4. Install the files:

```bash
git clone https://github.com/scipag/vulscan scipag_vulscan
vulscan
sudo ln -s ^pwd"/scipag_vulscan /usr/share/nmap/scripts/
vulscan/scipag_osvdb
```
