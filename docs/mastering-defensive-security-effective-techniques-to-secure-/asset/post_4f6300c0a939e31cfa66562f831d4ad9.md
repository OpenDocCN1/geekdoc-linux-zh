## Basic forensics

You can also automate the gathering of metadata from files with simple code. To achieve that task, we will use the os library because it provides a lot of useful metadata available, including:

- The last time the file was modified (st_mtime)
- The last time the file was accessed (st_atime)
- The creation time (st_ctime)
- The user identifier (st_uid)
- The group ID (st_gid)
- The file size (st_size)

Let's see an example. Go back to Python and write the following lines:

```
>>> import os
>>> stats = os.stat('secret01')
```

The output should give you all the information described (creation date, file owner, etc.), as illustrated in the following screenshot:

```
>>> import os
>>> stats = os.stat('secret01')
>>> print(stats)
os.stat_result(mode=33188, ino=263495, dev=205, nlink=1, uid=1000, gid=1000, size=0, atime=1630244244, mtime=1630244244)
```

Figure 17.9 – Metadata obtained from stat

If you want to discover more about this library, visit the following pages:

- https://docs.python.org/3/library/os.html
- https://docs.python.org/3/library/stat.html

> Tip Is the format of dates not familiar to you? Don't worry—you can use some libraries like datetime to convert the string to human-readable time.
