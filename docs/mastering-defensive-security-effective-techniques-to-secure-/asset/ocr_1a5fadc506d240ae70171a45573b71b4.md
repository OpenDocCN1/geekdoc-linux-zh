# Understanding the USB protocol

Every time you connect a USB device, it will first identify the speed of the device. Then, it will get the device descriptors, which, essentially, help with the identification of the device.

One of the descriptors is the USB class, which tells the computer what kind of device you are connecting to; for example, consider the following:

+   - Class 01h → audio device (as speakers)
- Class 03h → HID device (as a mouse, a keyboard, or a Rubber Ducky)
- Class 08h → mass storage (as a USB drive or an external hard drive)
