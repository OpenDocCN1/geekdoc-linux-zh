Normally, we would need to do an apt-get update, but since we just did it, we can go
directly to install Armitage:

```
sudo apt-get install armitage
```

Once it finishes, you should be able to start Armitage with the following command:

```
armitage
```

Then, you will get a prompt screen. Just leave the defaults and click on **Connect**, as seen in
t following figure:

![](bbox=[0.137, 0.305, 0.862, 0.584])

Figure 15.4 – Entering Armitage

Congratulations, at this point you have both **Metasploit** and **Armitage** up and running.
