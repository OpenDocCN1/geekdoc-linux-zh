# Using the master tool of network mapping – Nmap

If we can use the mincvc script to limit the results to CVEs with a score greater than the value provided. An example is follows:

```
nmap -sV --script vulners scanme.nmap.org
```

Now, the script will look for all CVEs related to nmap result. Note that the script uses a huge database of more than 250 GB, so the scan may take some minutes to run.
