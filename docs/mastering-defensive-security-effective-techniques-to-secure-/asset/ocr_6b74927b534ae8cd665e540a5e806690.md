# Searchploit

We talked in previous chapters about https://www.exploit-db.com/, which is a great database with over 44,000 exploits available to download. The website is great and it shows a lot of useful information in a friendly way, but searching for an exploit on the page, downloading it, and then executing it could be a bit time-consuming. Here is where **Searchploit** comes into play. Searchploit is a command-line tool included in Kali Linux that allows us to search for exploits on exploit-db and run them directly from the terminal; yes, that's easy!

Let's do a quick example. Imagine you added a Joomla server to your organization and you want to test it against known vulnerabilities. You can run the following command:

```
searchploit -t joomla
```

The -t option will just give us results in which word Joomla is the title of the exploit.

Now, imagine your boss asked you to install a YouTube plugin on your Joomla server. Then, let's see how we can find out about vulnerabilities related to that plugin:

```
kalisploit -t joomla youtube
```
