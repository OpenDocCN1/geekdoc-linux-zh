# Defense by layers

Here, you will use the inputs from the asset prioritization that we just created to develop the best-layered model based on your resources.

There is an ongoing debate about whether it is better to have one strong control or multiple good controls.

Let's look at some pros and cons of a sample scenario that you can draw your conclusions.

| Investment | Pros | Cons |
|---|---|--|
| All budget purchasing the best Firewall | -Top level security
>-Good Security features
>-Premium Service | -Single point of failure
>-No other layer to prevent an attack
>-A single vulnerability may have greater impact |
| Purchase of one basic Firewall, IPS, IDS and Backup | -Additional Security features
>-Less impact in case one is impacted by a Zero day.
>-Harder to perform reconnaissance,
>-Harder to clean traces | -The security of each layer may not be the best.
>-More effort to set up and configure properly
>-Harder to patch and maintain. |
