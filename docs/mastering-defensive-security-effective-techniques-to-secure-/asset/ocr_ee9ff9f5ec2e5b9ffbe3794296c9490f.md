# InsightVM

**InsightVM** is a tool developed by **Rapid7** and enables the assessment of cloud and virtual infrastructures to find vulnerabilities and perform an accurate risk assessment.

As seen in the following figure, the **default dashboard** provides you with a lot of information to keep you about your current vulnerabilities. For example, the dashboard serves as a visual reminder of the unsupported servers in your infrastructure:

![](bbox=[0.14, 0.241, 0.859, 0.706])

Figure 11.12 - InsightVM Default Dashboard

Another advantage of this tool is that you can use it to monitor other systems beyond your cloud, enabling you to have an all-in-one security dashboard.
