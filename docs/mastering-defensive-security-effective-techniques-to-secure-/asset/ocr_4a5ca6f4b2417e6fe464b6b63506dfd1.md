# Using OpenVAS

To execute OpenVAS, just type the following command:

```
sudo gvm-start
```

Notice that you can also start OpenVAS using the GUI of Kali Linux and browsing through the apps under **02 - Vulnerability Analysis**, as seen in the following screenshot:
