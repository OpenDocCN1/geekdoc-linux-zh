# The stealthy Plunder Bug LAN Tap

The LAN Tap is a very small (but powerful) device that enables an attacker to capture all
packets going through your network.

It comes with a USB Type-C connection to download in real time all *. pcap files to
smartphone for later analysis.

```
pcap files
This is a file format used to capture network traffic and is widely used by
siffing tools such as Wireshark. There are other programs such as tcpextract
and pcapflex that can extract files out of a .pcap file, which makes this type of
attack even more dangerous.
```
