> TipnWindows security updates come with two important documents that give a lot of information about the vulnerability. They are the security bulletin and a Microsoft Knowledge Base article, and they provide very useful insights about the vulnerability being fixed.

+   * Feature pack: New product functionality that is distributed to users before the upcoming full product release. Since these updates are related to new functionality and not to prevent or fix a given issue or bug, they are considered minor updates.
