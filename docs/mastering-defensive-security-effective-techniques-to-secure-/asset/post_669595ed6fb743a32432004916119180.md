## Introduction to digital forensics

Digital forensics (also known as cyber forensics) is the process used to collect, identify, secure, and store data from digital systems. However, we will focus on data that is used. Let's take a few minutes to review how.

## Forensics to recover deleted data

There is one part of forensics that is used from non-volatile media such as hard drives, but it is also possible to gather data from volatile memory as Random Access Memory (RAM).

Volatile versus non-volatile memory
Volatile memory such as RAM is a type of memory that only saves information while it is ON, while non-volatile memory such as hard drives can retain information over a long time, even when they have no. Therefore, gathering information from volatile memory is considered a complex task. Now, let's start by reviewing how to capture data.

## Recovering data from RAM

Due to the hardware nature of RAM, recovering data from RAM is considered a complex task. However, there is one tool and one method we can use to achieve this goal. Let's take a look.

## Microsoft COFEE

The Microsoft Computer Online Forensics Extractor (COFEE) toolkit was developed and distributed by Microsoft to help them collect digital evidence from digital systems.

The tool is loaded as a live USB and is composed of a Graphical User Interface (GUI) with more than 150 tools, including data stored on volatile memory (RAM).

A copy of this tool was supposedly leaked on the internet in 2009 and if you are interested in reviewing it, a simple Google search will give you the link to the WikiLeaks page to download it.

> Tip
> Remember that leaked versions of software may contain malicious content, so avoid running it on your main computer. Instead, try using a virtual sandbox and take all the necessary precautions if you decide to download and run this type of software.

## Cold boot attack

This is a super interesting way to gather data right from the RAM. Let me explain how it works:

- First, you need physical access to the computer.
2. Open the computer.
3. Cool down the RAM module (this can be done using a freeze spray).
4. Cut off the power of the machine.
5. Boot up the computer using a lightweight USB bootable Operating System (OS).
6. Perform a memory dump using any available memory dump software or script.

As illustrated in the following diagram, a limitation of this attack is that the amount of data that's recovered is proportional to the time required. This means that the faster you perform the dump, the more data you can recover.
