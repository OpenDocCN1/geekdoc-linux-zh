+   - Perform security tests to ensure that the minimum acceptable security level can be obtained with the DRP.

+   - If you have multiple locations, test access to the secondary servers/systems from all locations (you need to make sure that your employees working from a beach in Costa Rica can also access the secondary systems/servers).

+   - Test the durability (proposed on the DRP) over an extended period of time and during different seasons. For example, you might test a satellite internet connection, and it could work if the sky is clear, but it might not provide you with the required level of service during cloudy weather or a storm.

+   - Get the required approvals (from the CEO, CTO, and CFO) before publishing the DRP. CTO approval is key to ensure they agree with the technical decisions, CEO approval is key to ensure the DRP effectively covers the business, and CFO approval ensures that you have the budget to implement and execute.
