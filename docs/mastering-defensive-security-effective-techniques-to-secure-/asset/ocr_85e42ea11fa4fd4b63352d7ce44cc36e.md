# Security Level

Security level is currently impossible.

You can set the security level to low, medium, high or impossible. The security level changes the vulnerability level of DVWA.

+   - Low: This security level is completely vulnerable and has no security measures at all. It's use to use it as an example of how web vulnerabilities manifest through bad coding practices and to serve as a platform for security beginners.
- Medium: This setting is mainly to give an example to the user of bad security practices, the vulnerability may not allow the same extent of exploit as in the low level, but it is also a challenge to those who want to develop their own exploitation techniques.
- High: This level is an extension to the medium difficulty, with a mixture of harder or alternative bad practices to prevent attacks to secure the code.
- Impossible: This level is used to compare the security level of DVWA v1.9, which level was known as 'high'.
