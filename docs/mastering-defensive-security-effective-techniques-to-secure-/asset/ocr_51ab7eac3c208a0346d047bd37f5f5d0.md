# Intruder

**Intruder** is a vulnerability scanner that helps you to check the status of your cloud by checking more than 10,000 vulnerabilities and security checks. As seen in the following figure, the GUI is very intuitive and presents all the useful data in a single dashboard.

Additionally, it offers an option to sort the vulnerabilities based on criticality so you can always keep them in sight.

![](bbox=[0.119, 0.246, 0.841, 0.532])

Figure 11.13 – Intruder GUI

There are many more performance monitors as well as vulnerability scanners that you can check, which have their unique characteristics and features: **OpenVAS, Qualys Cloud Platform, AlienVault USM, Alibaba Website Threat Inspector, Amazon Inspector, Orca Security, Trend Micro Cloud One**, and many more.
