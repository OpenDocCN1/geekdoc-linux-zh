# Enabled services and ports

IoT devices may come with several services and ports enabled by default. Therefore, you must define which services should have internet access and which services should be intranet only.

For example, you may want a network printer to access the internet to get updates, remote management access and network printer services should be disabled if not in use (most of the time, an intranet printer is enough).
