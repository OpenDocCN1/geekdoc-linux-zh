In the sections category, you would be able to see advanced attributes of the malware, such as whether the file is writable, executable, shareable, or discardable (denoted by X symbol). Another common characteristic of malware that you can see in this self-modifying, which is a common attribute of morphing malware.

The file-header category also shows a very important piece of information about the file was compiled. Keep in mind that some malware has auto-compiling characteristics, so if you have a very recent date, you may be facing advanced auto-compiling malware.
