### 书籍出版信息

#### C.1 在线阅读

本书的当前版本可以在线以 HTML (http://lsbbook.gforge.freestandards.org/) 和 PDF (http://lsbbook.gforge.freestandards.org/lsb-book.pdf) 格式获取。

#### C.2 报告错误

LSB 通过 Bugzilla (http://bugs.linuxbase.org/) 接受问题报告和建议。

#### C.3 获取源代码

本书依据 GNU 自由文档许可证发布，其源代码可通过 CVS 在线获取：

```
CVSROOT=:pserver:anonymous@cvs.gforge.freestandards.org: \
/cvsroot/lsbbook
cvs -dCVSROOT login
cvs -dCVSROOT -z3 co lsbbook
```
