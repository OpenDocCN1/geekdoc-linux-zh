# **8.6  HOW TO GET YOUR FAVORITE INTERFACE ADDED TO THE LSB**

The LSB processes are designed to not get in the way of people wanting to contribute. If you have a candidate that you would like to see added to the standard, you can request that it be tracked as a candidate. If the work gets done to make the candidate fulfill the criteria, then it can be added. The only thing limiting when something can be added to the LSB is how quickly the criteria can be fulfilled. The LSB workgroup would love to see additional interfaces added and encourages all to participate.
