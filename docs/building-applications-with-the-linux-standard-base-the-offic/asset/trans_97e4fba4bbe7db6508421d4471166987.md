### B.1 术语表

- **申请人 (Applicant)**：正在进行产品认证过程的供应商。

- **认证 (Certification)**：关于符合某种商定标准的证明。有时并不提供完全的证明，而是提供一种保证。此外，可能存在可与已认证产品一起使用的徽标或标记。

- **认证协议 (Certification Agreement)**：申请人与认证机构之间的协议，该协议定义了认证服务，并包含申请人对认证服务条款的法律承诺。

- **认证机构 (Certification Authority)**：由自由标准组织（Free Standards Group）正式授权，负责管理 LSB 认证计划日常运营的机构。

- **认证登记册 (Certification Register)**：记录所有已认证产品的登记册，由认证机构维护，并通过互联网公开提供。

- **认证系统缺陷 (Certification System Deficiency)**：认证系统中已确认的错误，该错误正在阻碍认证过程。认证系统包括认证流程以及为实施认证而提供的信息系统。认证系统缺陷是问题报告的一种可能结果。

- **已认证产品 (Certified Product)**：已成功完成认证流程的产品或产品系列，认证机构已书面通知此类产品或产品系列的供应商认证已达成。

- **合规性 (Compliance)**：关于符合性的声明。

- **符合性 (Conformance)**：需求在规范中规定。它们是一套商定的规则，定义了满足规范的含义。

- **符合性需求 (Conformance Requirements)**：定义产品必须满足的强制性需求以及必须实现的任何选项，以被视为符合规范。

- **符合性声明 (Conformance Statement)**：描述产品满足符合性需求的具体方式（包括支持哪些可选功能）的书面声明集。它提供了已认证产品的精确标识，该产品的符合性得到保证。它还包括用于验证符合性的特定配置细节，足以重现任何适用测试的结果。

- **自由标准组织 (Free Standards Group, The)**：一家非营利公司，旨在通过开发、应用和推广标准来加速开源技术的使用和接受。

- **解释 (Interpretation)**：由规范权威机构做出的决定，阐述或细化自由标准组织规范或自由标准组织规范所引用的标准或规范的语义。解释是问题报告的一种可能结果。

- **LSB**：Linux 标准基础（Linux Standard Base）。这是一个历史名称，并未将 LSB 书面规范限制于任何特定的操作系统。

- **LSB 应用程序 (LSB Application)**：LSB 应用程序认证针对符合 LSB 书面规范的应用程序。LSB 应用程序是使用 LSB 运行时环境提供的服务的消费者。

- **LSB 开发环境 (LSB Development Environment)**：LSB 开发环境认证针对可以从源代码构建符合 LSB 应用程序的平台。提供 LSB 开发环境的平台无需提供 LSB 运行时环境。

- **LSB 国际化运行时环境 (LSB Internationalized Runtime Environment)**：LSB 国际化运行时环境认证针对提供符合 LSB 和 OpenII8N 规范的服务的平台。该平台必须在 LSB 国际化运行时环境产品标准注册之前或同时注册为符合 LSB 运行时环境产品标准。

- **LSB 运行时环境 (LSB Runtime Environment)**：LSB 运行时环境认证针对提供符合 LSB 书面规范的服务的平台。

- **OpenII8N**：自由标准组织的开放国际化计划。这以前被称为 LI18N/X 规范。

- **平台 (Platform)**：一种操作系统环境。它可以是由内核、库和实用程序组成的完整操作系统；它也可以是一个托管环境或提供等效功能的仿真。

- **问题报告 (Problem Report)**：关于规范、测试套件或认证系统的澄清、意图或正确性的问题，如果获得规范权威机构的接受，将分别被解决为解释、测试套件缺陷或认证系统缺陷。

- **产品标准 (Product Standard)**：规定特定类型产品符合性需求的文档，产品可在该计划中相对于此标准进行认证。每种要认证的产品类型将有一个产品标准，即分别用于 LSB 运行时环境、LSB 应用程序、LSB 开发环境和 LSB 国际化运行时环境。除了 LSB 国际化运行时环境产品标准外，对于由 LSB 书面规范规定的每种体系结构，将有一组这样的产品标准。

- **注册表 (Registration Form)**：申请人填写以申请特定产品认证的表格。表格包含有关申请人和待认证产品的信息。

- **规范权威机构 (Specification Authority)**：自由标准组织的一个工作组，负责开发、维护和解释适用的自由标准组织规范。

- **供应商 (Supplier)**：对自由标准组织认证计划中的产品感兴趣、正在申请认证或已认证产品的产品经销商。在供应商通过认证流程以获取产品认证的期间，该供应商被称为申请人。

- **测试套件缺陷 (Test Suite Deficiency)**：测试套件中已确认的错误，该错误导致其产生影响认证的错误结果代码。测试套件缺陷是问题报告的一种可能结果。

- **测试套件维护权威机构 (Test Suite Maintenance Authority)**：由自由标准组织授权维护测试套件的机构。

- **商标许可协议 (Trademark License Agreement)**：供应商与自由标准组织之间的协议，包含供应商对使用自由标准组织商标和自由标准组织认证计划的条件所做的法律承诺。
