# Developing LSB Applications

Linux distributions' conformance to standard ABIs and ELF is all about providing runtime environment stability and consistency for applications; however, operating system robustness is only half the equation for true compatibility. In addition to having an LSB Certified Runtime Environment, one needs competent Linux applications. Well-behaved applications that are generically Linux-compatible need to strictly use the prescribed public APIs and commands, generically package, and follow the FHS filesystem layout.
