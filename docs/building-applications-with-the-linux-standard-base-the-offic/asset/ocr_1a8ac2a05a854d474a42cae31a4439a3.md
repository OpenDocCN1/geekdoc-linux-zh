# 11.2.5.4  *Executing Test Binaries Directly*

It can sometimes be useful to execute test binaries directly (for example, if you want an easier way to attach a debugger). Although the source for the test cases is located in the /home/tset/test_sets/tsset, when they are built, the binaries are placed under an identical directory hierarchy under /home/tset/test_sets/TESTROOT/tsset.
