# 5.6 THREADS

Solaris provides a threading model under which all processes are based on threads called lightweight processes (LWP). In Solaris, a process will be associ ated with one or more LWP. In the case of Linux, all threads are based on processes and each thread will be mapped to a process.

Solaris supports not only its native threading model but also the POSIX threading model; POSIX threads are also supported on Linux. If an application uses the Solaris native thread model then the application needs a lot of rework before it can be ported.
