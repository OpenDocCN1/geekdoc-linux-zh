# 11.2.5.3  Rebuilding and Executing Test Cases

Once the TET/VSXgen framework has been configured and built you can (re)build and (re)execute any or all of the test cases. The file /home/tet/test_sets/scen. bld specifies the test cases that will be built and /home/tet/test_sets/scen. exec specifies those that will be executed.

Example 11.2 shows how to execute specific test cases by editing the scen. bld and scen. exec files. Before editing the files, you should back up both of them.
