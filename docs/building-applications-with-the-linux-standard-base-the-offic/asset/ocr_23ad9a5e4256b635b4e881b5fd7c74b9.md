# 11.2.6 Installing the Source of lsb-runtime-test

Complete the following steps to install the source version of lsb-runtime-test.

All test suite files are available on the LSB Download Web site.6

+   1. Download the source RPM.
+   
+   2. Install the RPM:
+   
+   # rpm -i lsb-runtime-test-version.src.rpm
+   
+   3. Copy the file lsb-runtime-tests-version.tar.gz to the /home/tet directory (or the directory where you want to install the test suite):
+   
+   # cp lsb-runtime-tests-version.tar.gz /home/tet
+   
+   4. Untar the file:
+   
+   tar xvfz lsb-runtime-tests-version.tar.gz
+   
+   5. Run install.sh from the directory where you unpacked the files:
+   
+   # ./install.sh
+   
+   The license information for all of the packages you installed is displayed followed by instructions on how to proceed further.
+   
+   6. Log out and log in as the user vxs0. You may need to first set the password for this account as it is not set to anything during the installation of the package.
+   
+   7. Build the test harness by running /home/tet/setup.sh:
+   
+   vxs0$ ./setup.sh
