# 3.8 O_LARGEFILE

When available, the LSB permits Linux implementations to set O_LARGEFILE with fcntl(3). Applications should set this flag explicitly when needed, and not expect the runtime to set it by default (Example 3.4).

# Example 3.4: O_LARGEFILE with fcntl(3) Function

```
#ifdef __USE_LARGEFILE64
int oflag = fcntl(fd, F_GETFL, 0);
if (oflag & O_LARGEFILE) {
debug("O_LARGEFILE was implicitly set"); // BAD
}
oflag |= O_LARGEFILE; // GOOD
fcntl(fd, F_SETFL, oflag);
#endif
```
