# 9.2 ARCHITECTURE-SPECIFIC ELF

ELF defines the linking interfaces for compiled application programs. The LSB has a database containing most of the ELF specifics for Linux. The LSB database (Figure 9.1) is what is used to build the Written Specification and the LSB tools.
