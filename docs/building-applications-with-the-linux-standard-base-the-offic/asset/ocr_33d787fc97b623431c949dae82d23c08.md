If you use `lsb-build-chroot` then the compiler will dynamically link all shared libraries available in the restricted environment, and fall back to static linking if only the static version of a library is present.

# 13.5 CASE STUDY: RSYNC

The `rsync` application is one of the programs in the LSB Application Battery. We use this program as an example of the types of problems that developers may encounter, and how to work around them when attempting to build an LSB-compliant binary.

We use the `lsbCC` build tool with `rsync` version 2.5.5. The source for `rsync` can be downloaded from the `rsync` Web site.³
