# 10.7 Downloading the LSB Written Specification

To obtain the LSB Written Specification go to the LSB Download Web page. ${ }^{1}$ You can obtain the specifications in Adobe Portable Document Format ( .pdf ), RichText Format (.rtf ), text (.txt ), or line-numbered text (lines .txt ). Table 10.1 represents the information that can be accessed via the World Wide Web.
