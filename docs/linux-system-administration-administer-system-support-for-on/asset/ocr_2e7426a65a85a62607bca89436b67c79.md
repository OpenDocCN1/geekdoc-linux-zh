```
$ sum d * h* i* s* 
43651  1 diskstuff 
37612  5 hardlink 
37612  5 inodes 
37612  5 symlink
```

You can easily write a script comparing the checksums of critical files to see if someone has accessed them. If there is any output, you know the files have been accessed.

```
#!/bin/sh
# compare checksums of the files in the /etc directory from yesterday
# move the previous day's checksum data to yesterdaysum
mv todaysum yesterdaysum
sum /etc/* > todaysum
diff yesterdaysum todaysum
```

The sum command does not work on a directory. See what happens when you try to run it on directories.

```
$ sum more*
sum: moreinfo: Is a directory
sum: morestuff: Is a directory
```

# The file Command

To see what type of file is in a directory, use the file command. From the file command following, you can't see any difference between the hardlink and the file inodes. However, you can differentiate directories, text files, and symbolic links.

```
$ file *
diskstuff: ASCII text
hardlink: English text
inodes: English text
moreinfo: directory
morestuff: directory
symlink: symbolic link to inodes
```

Here's another example from the / directory. You can see that the sticky bit is set on the /tmp directory, which enables other users to write to it. You can also see the kernels; they are recognized as x86 boot sector files.

```
$ file /*
/bin: directory
```
