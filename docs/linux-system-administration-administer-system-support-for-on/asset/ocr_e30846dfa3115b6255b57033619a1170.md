# Your Complete Guide to Maintaining
a Strong, Secure System

Find out everything you need to know to run a tight LINUX
system. Whether you're looking to look for your own computer or
maintaining a company-wide network, you'll quickly and easily
learn how to optimize and secure your system with the expert
guidance of Anne H. Carasik. From maximizing user access to
troubleshooting system errors to preventing break-ins, LINUX®
System Administration covers it all!

+   Inside, You'll Learn How To:
+   * Implement basic security when installing Slackware LINUX
+   * Allocate optimal disk space to run your system efficiently
+   * Set up disk drives and other peripherals
+   * Manage user accounts
+   * Secure passwords and permissions
+   * Tweak, patch, and hack the kernel
+   * Use system administration tools effectively
+   * Backup and recover data
+   * Integrate LINUX with other operating systems

# About the Author

Anne H. Carasik, currently an Information
Security Analyst for VeriSign, Inc., has worked in
the computer industry since 1992 with com-
paigns that include IBM, Northern Telecom
(Nortel), and Hewlett-Packard. Anne has been
active in UNIX- and Internet-related projects
since 1994, including the development and
teaching of courses; she has also worked as a
network systems engineer in Network Security
Services at International Network Services.
