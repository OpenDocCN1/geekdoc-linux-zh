# # Your Common Tools

When an account has a directory defined in its PATH, it has access to all the files in that directory (provided the permissions are set up properly). For example, many user accounts include /usr/local/bin in the PATH, as shown in Listing 5-2. Any executable in that directory is accessible by the user.
