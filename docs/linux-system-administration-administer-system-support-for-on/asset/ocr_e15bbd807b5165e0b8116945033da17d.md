# IN THIS PART

Part III goes into detail on Linux security. In keeping with the book’s mission to make security a forethought instead of an afterthought, this part offers strategies for securing your host that can point you in the right direction as a system administrator.

Chapter 8 shows how to manage user accounts properly – offering a way to plug one of the biggest and oldest security holes. Chapter 9 explains host security, examines the weapons available to hackers (such as Trojan horses) and advises how to protect against them. Chapter 10 is a look at disaster recovery, which includes preparing for emergencies, responses, and building back.
