# ## Booting Up

Starting up can begin in many ways. You can use a boot manager (such as those for OS/2 or NT) or use Loadlin to run Linux directly off of a DOS partition. Also, using boot options, you can pass the kernel to make sure all your hardware works properly.

![](bbox=[0.07, 0.76, 0.18, 0.84])

Refer to the HOWTO or mini-HOWTO files for each specific booting type listed on the CD-ROM.

With boot options, you can define additional hardware to be recognized by the kernel. You can also define more specific hardware and memory options, as well. The boot options only work if a driver is loaded directly into the kernel, and not as a module.
