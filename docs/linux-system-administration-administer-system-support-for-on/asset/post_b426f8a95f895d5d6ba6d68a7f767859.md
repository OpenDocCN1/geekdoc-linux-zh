
## Appendix B
### Linux USENET Newsgroups

If you're looking for a good place to discuss Linux and all sorts of Linux-related topics, USENET is the main place to go. However, please be aware when posting that your e-mail address may show up on some spambot, which is a program that sifts through USENET looking for e-mail addresses (you might want to tweak your e-mail address in the headers or install a spam filter).

Each newsgroup in this appendix is organized by topic.
