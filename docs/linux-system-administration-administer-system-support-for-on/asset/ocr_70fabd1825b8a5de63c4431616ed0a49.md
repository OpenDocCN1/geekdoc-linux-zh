If you want to see how all the processes are related, you can view the process tree by using the `pstree` command. This gives you a lot of information about processes, including the name, the PID, who owns it, and its load.

```
$ pstree
init+-4*[agetty]
 |\\-bash\\-man\\-less
 |\\-cardmgr
 |\\-crond
 |\\-gpm
 |\\-inetd
 |\\-kflushd
 |\\-klogd
 |\\-kswapd
 |\\-lpd
 |\\-4*[nfsiod]
 |\\-rpc.mountd
 |\\-rpc.nfsd
 |\\-rpc.portmap
 |\\-syslogd
 |\\-tcsh\\-vi\\---tcsh---pstree
 `\\-update
```
