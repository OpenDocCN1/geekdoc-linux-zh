+   14. Kernel hacking – Kernel hacking is tinkering with the kernel for optimization or increasing functionality. If you're a kernel hacker, this is the feature for you. The kernel profiling shows how often the CPU is accessed by a particular process so you can optimize the kernel. I'm not a programmer and have no reason to turn on kernel profiling. Unless you're running a developmental kernel and want to kernel hack, leave this stuff alone. It's especially not good for firewalls, routers, database servers, Web servers, or other production systems. Figure 6-16 shows the kernel hacking option screen.
