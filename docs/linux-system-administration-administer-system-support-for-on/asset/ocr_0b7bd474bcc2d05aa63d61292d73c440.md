Also note that the `/etc/passwd` file is still readable by everyone and the `/etc/shadow` file is only readable by root. Don’t change the permissions on the `/etc/shadow` file. This will disable any security on it and will defeat the purpose of creating an `/etc/shadow` file in the first place.

```
bash# ls -l /etc/passwd; ls -l /etc/shadow
-rw-r-r--  1 root    root        737 Jul 19 10:11 /etc/passwd
-r-----  1 root    root        550 Jul 19 10:11 /etc/shadow
```
