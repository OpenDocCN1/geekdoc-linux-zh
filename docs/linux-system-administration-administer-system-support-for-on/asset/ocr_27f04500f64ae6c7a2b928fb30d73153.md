What’s also nice is there’s an /etc/rc.d/rc.modules file. This is where you can decide which modules you’d like to load. In this case, we are loading modules for parallel port printing, SLIP, and PPP support.

If you want to enable automatic module loading, you’ll have to enable kernelld (uncomment the lines). This should let you load modules on the fly.

The /etc/rc.d/rc.modules file is shown in Listing 7–8.
