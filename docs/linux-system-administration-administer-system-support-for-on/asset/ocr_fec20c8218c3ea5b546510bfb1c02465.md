# Setting the Home Page

When you have your Web server configured the way you'd like, you can create a test home page. Before you actually do so, you'll want to create the directory public_html on your user account and set the correct permissions, like this:

```
$ mkdir ~/public_html
$ chmod 755 ~/public_html
$ cd ~/public_html
```

Now, you'll want to create a test Web page (use vi or your favorite editor):

```
$ vi index.html
```

Your page should have the basic contents of:

```
<html>
<pre>
Hello Whirled!
</pre>
</html>
```

Then set the permissions on the file:

```
$ chmod 755 index.html
```

When this is done, test your home page by opening up the URL http://localhost/~username/. You should see something like Figure 12-8.
