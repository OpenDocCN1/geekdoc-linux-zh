# Scan Well-Known Ports

Another common way a hacker gets access to your system is by scanning the ports. Two common utilities that work well on Linux systems are strobe and nmap.

# NMAP

The nmap scanner is a handy way to turn up well-known ports. It does so by scanning the /etc/services file. There are many options you can pass it to see what you can find. You can use different scan types (for example, by sending different types of packets). The nmap scanner works well on Linux and other UNIX operating systems.
