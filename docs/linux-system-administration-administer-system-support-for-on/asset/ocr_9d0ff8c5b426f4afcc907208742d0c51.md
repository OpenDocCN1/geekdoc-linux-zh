# TAPE DRIVES

The `rft` and `nrft` device files are tape drives. You can designate four of them (device numbers 0 to 3) at either location, as shown here:


# MASTER HARD DRIVE ON THE PRIMARY CONTROLLER

The following list shows the master hard drive on the primary controller. Its designation is `/dev/hda` (with partitions `/dev/hda1` to `/dev/hda16`), and it usually corresponds to the bootable hard drive on your PC.
