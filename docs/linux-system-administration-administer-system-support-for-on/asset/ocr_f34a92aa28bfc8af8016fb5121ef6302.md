The /bin directory lists most system binaries. This includes the user shells, basic file commands such as ls, mv, and cp; the basic mail command, and many process-related commands such as ps. These commands are for any user who needs them, not just the system administrator.

Listing 5-3 shows the contents of the Slackware /bin directory, which can differ in other UNIX operating systems.
