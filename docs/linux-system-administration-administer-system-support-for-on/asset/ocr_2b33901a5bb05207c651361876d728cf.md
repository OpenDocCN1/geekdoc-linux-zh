A group of processes can be set to run at a particular level; if the system goes to the next level, Linux runs the next set of processes. In this case, Linux has run levels 0 through 6.

# Run Levels 0 and 6

On Slackware Linux, run level 0 shuts down the system, whereas run level 6 reboots. At run level 0 or 6, all the file systems are unmounted, processes are killed, and swap is turned off. If this happens at run level 0, then the system halts. If it happens at run level 6, the system reboots. The processes for run level 0 or 6 are found in /etc/rc.d/rc.0.

To run Slackware Linux at any run level, just use the command telinit as shown here:
