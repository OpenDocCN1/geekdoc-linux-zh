> You need a recovery disk in case your system gets hosed by file corruption or by someone breaking in.

To create your root disk, use rawrite.exe in the rootdisks directory rootdsks to create the corresponding batch file to the root-disk file. In my case, I only need the basic color root disk. When I run the rawrite.exe file in the rootdsks directory, I get prompted for the compressed file I want to use, color.gz, and which I want to create the disk on (usually A:) like the one in Figure 1-2.
