# Networking Protocols

There are several different ways that computers can talk to each other. It’s the same way people talk to each other in different languages: English, Japanese, French, Hebrew, or Pig Latin. Computers use a protocol—a seven-layer set of agreed-upon standards—to establish correct operation for the devices on a network. One highly influential way of displaying network protocols is the OSI (Open Systems Interconnection) model, shown in Table 11-1.

**TABLE 11-1 THE OSI MODEL**

| Number | Layer | Example |
| :--- | :--- | :--- |
| 7 | Application | User interface, command line |
| 6 | Presentation | Data formats such as JPEG, MPEG, and text |
| 5 | Session | Zone Information Protocol (ZIP) |
| 4 | Transport | TCP and UDP |
| 3 | Network | IP, RIP, ICMP |
| 2 | Data | Ethernet, Token Ring |
| 1 | Physical | Cables, Network Interface Cards |
