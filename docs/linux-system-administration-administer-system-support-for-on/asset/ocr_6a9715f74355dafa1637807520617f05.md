When you work with files that are critical to the operation of your Linux system, be sure to test your find syntax before you specify that find execute powerful commands such as rm after it finds the files. You don't want to do anything so uncivilized as deleting /dev/hda...

Here's another practical example of find in action: If you want to remove all forward files you find, enter the following version of the find command:

```
# find / -name .forward -exec rm {};
```

This nice feature is really at its most powerful in shell scripts for backups, removal, or other operations that involve making particular changes to a specific group of files.
