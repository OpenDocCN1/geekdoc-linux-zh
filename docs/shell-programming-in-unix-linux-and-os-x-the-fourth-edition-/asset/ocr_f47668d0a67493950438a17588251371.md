```
# The hash Command

_General Format:_ `hash commands`

This command tells the shell to look for the specified commands and to remember what directories they are located in. If _commands_ is not specified, a list of the hashed commands is displayed.

If the format

```
```sh
hash -r
```
```

is used, the shell removes all commands from its hash list. Next time any command is executed, the shell uses its normal search methods to find the command.

| Examples | |
|---|---|
| `hash rolo whoq` | Add _rolo_ and _whoq_ to hash list |
| `hash` | Print hash list |
| `hash -r` | Remove hash list |
```
