variable is not defined or contains a NULL string, its value is assumed to be zero. So if we have
not assigned any value yet to the variable a, we can still use it in an integer expression:

```
```text
$ echo $a                         Variable a not set
$ echo $(( a = a + 1 ))           Equivalent to a = 0 + 1
$ 1
$ echo $a                         Now a contains 1
$
```
```

Note that assignment is a valid operator, and the value of the assignment is substituted in the
second echo command in the preceding example.

Parentheses are frequently useful inside expressions to force grouping, as in

```
```text
echo $((i = (i + 10) * 3))
```
```

If you want to perform an assignment without echo or some other command, you can move
the assignment before the arithmetic expression.

So to multiply the variable i by 5 and assign the result back to i you can write

```
```text
i=$(( i * 5 ))
```
```

Note that spaces are optional inside the double parentheses, but are not allowed when the
assignment is outside them.

A more succinct way to multiply $i by 5 is the following common notation, which would
appear within another statement:

```
```text
$(( i *= 5 ))
```
```

If you’re just adding 1 to the value, you can be even more succinct:

```
```text
$(( i++ ))
```
```

Finally, to test to see whether i is greater than or equal to 0 and less than or equal to 100, you
can write

```
```text
result=$(( i >= 0  &&  i <= 100 ))
```
```

which assigns result the value of 1 (true) if the expression is true or 0 (false) if it’s false:

```
```text
$ i=$(( 100 * 200 / 10 ))       If i is < 1000, set j = 0; otherwise 1
$ j=$(( i < 1000 ))              i is 2000, so j was set to 0
$ echo $i $j
2000 0
$
```
```
