it matches everything up to the tab (Alice Chebba) and stores it into register 1, and everything after the tab (973-555-2015) into register 2. The tab itself is lost because it’s not surrounded by parentheses in the regex. Then ed substitutes the characters that were matched (the entire line) with the contents of register 2 (973-555-2015), followed by a space, followed by the contents of register 1 (Alice Chebba).

```
973-555-2015 Alice Chebba
```
