# Other Features of the `cd` Command

The cd command seems straightforward, but it has a few tricks up its proverbial sleeve. For example, the - argument means “the previous directory” as a convenient shortcut:

```
```text
$ pwd
/usr/src/cmd
$ cd /usr/spool/uucp
$ pwd
/usr/spool/uucp
$ cd -
/usr/src/cmd                         cd to previous directory
                                     cd prints out name of new directory
$ cd -
/usr/spool/uucp
$
```
```

As you can see, cd - can be used to toggle between two directories with no effort at all.

The Korn shell’s cd command has the capability to substitute portions of the current directory’s path. (Neither Bash nor the POSIX standard shell support this feature)

The format is

```
```text
cd old new
