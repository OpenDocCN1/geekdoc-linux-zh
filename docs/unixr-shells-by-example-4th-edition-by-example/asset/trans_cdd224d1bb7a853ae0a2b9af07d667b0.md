## 9.20.2 TC Shell 命令行选项

TC shell可以接受许多命令行选项（也称为标志参数）来控制或修改其行为。命令行选项列于表9.27中。

## 表9.27 TC Shell 命令行选项

| 选项 | 含义 |
|---|---|
| - | 指定该shell为登录shell。 |
| -b | 强制“中断”选项处理。其后的任何shell参数将不被视为选项。剩余参数将不会被解释为shell选项。如果shell设置了用户ID，则必须包含此选项。 |
| -c | 如果 -c 后跟单个参数，则从该参数（一个文件名）读取命令。剩余参数放入argv shell变量中。 |
| -d | shell从 ~/.cshdirs 加载目录栈。 |
| -Dname[=value] | 将环境变量name设置为value。 |
| -e | 如果任何被调用的命令异常终止或产生非零退出状态，则shell退出。 |
| -f | 称为快速启动，因为启动新的TC shell时，shell会忽略 ~/.tcshrc。 |
| -F | shell使用fork(2)而不是vfork(2)来生成进程。（仅限Convex/OS） |
| -i | shell是交互式的，并提示输入，即使它看起来不是终端。如果输入和输出连接到终端，则此选项不是必需的。 |
| -l | 如果 -l 是唯一指定的标志，则shell是登录shell。 |
| -m | shell加载 ~/.tcshrc，即使它不属于有效用户。 |
| -n | 用于调试脚本。shell解析命令但不执行它们。 |
| -q | shell接受SIGQUIT信号，并在调试器下使用时表现出相应行为。作业控制被禁用。 |
| -s | 命令输入从标准输入获取。 |
| -t | shell读取并执行单行输入。可以使用反斜杠（\）转义该行末尾的换行符并继续到下一行。 |
| -v | 设置verbose shell变量，以便在历史替换后回显命令输入。用于调试shell脚本。 |
| -x | 设置echo shell变量，以便在执行前以及历史和变量替换后回显命令。用于调试shell脚本。 |
| -V | 在执行 ~/.tcshrc 文件之前设置verbose shell变量。 |
| -X | 在执行 ~/.tcshrc 文件之前设置echo shell变量。 |
