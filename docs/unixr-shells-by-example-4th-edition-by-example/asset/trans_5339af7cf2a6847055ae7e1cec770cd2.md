该操作是打印字段1和2。
模式可以与操作关联。记住，操作是用花括号括起来的语句。模式控制从第一个左花括号到第一个右花括号之间的操作。如果操作跟在模式后面，第一个左花括号必须与模式在同一行。模式永远不会被花括号括起来。

## 格式

```
pattern{ action statement; action statement; etc. }
    or
pattern{
    action statement
    action statement
}
```

## 示例 6.21

```
% nawk '/Tom/{print "Hello there, " $1}' employees
Hello there, Tom
```

## 解释

如果记录包含模式Tom，将打印字符串Hello there, Tom。

## 6.8 正则表达式

在awk中，正则表达式是一种由正斜杠括起来的字符构成的模式。awk支持使用正则表达式元字符（与egrep相同）以某种方式修改正则表达式。如果输入行中的字符串与正则表达式匹配，则结果条件为真，并且执行与该表达式关联的任何操作。如果未指定操作，且输入行与正则表达式匹配，则打印该记录。参见表6.5。

## 示例 6.22

```
% nawk '/Mary/' employees
Mary Adams 5346 11/4/63 28765
```

## 解释

employees文件中包含正则表达式模式Mary的所有行都会显示。

## 示例 6.23

```
% nawk '/Mary/{print $1, $2}' employees
Mary Adams
```

## 解释

employees文件中包含正则表达式模式Mary的所有行的第一个和第二个字段都会显示。

## 表6.5 awk正则表达式元字符

| 元字符 | 作用 |
|---|---|
| ^ | 匹配字符串的开头 |
| $ | 匹配字符串的结尾 |
| . | 匹配单个字符 |
| * | 匹配前一个字符的零个或多个 |
| + | 匹配前一个字符的一个或多个 |
| ? | 匹配前一个字符的零个或一个 |
| [ABC] | 匹配字符集合A、B或C中的任意一个字符 |
| [^ABC] | 匹配不在字符集合A、B或C中的任意一个字符 |
| [A-Z] | 匹配A到Z范围内的任意一个字符 |
| A|B | 匹配A或B |
| (AB)+ | 匹配一个或多个AB集合；例如AB、ABAB、ABABAB |
| \* | 匹配字面星号 |
| & | 在替换字符串中用于表示搜索字符串中找到的内容 |

表6.6中列出的元字符受大多数版本的grep和sed支持，但不受任何版本的awk支持。

## 表6.6 不支持的元字符

| 元字符 | 功能 |
|---|---|
| \< >\ | 单词锚点 |
| \( \) | 反向引用 |
| \{ \} | 重复 |

## 6.8 正则表达式

### 6.8.1 匹配整行

独立的正则表达式匹配整行上的模式，如果没有给出操作，将打印发生匹配的整行。正则表达式可以使用元字符锚定到行的开头。

```
% nawk '/Mary/' employees
Mary Adams     5346     11/4/63     28765
```

employees文件中以正则表达式Mary开头的所有行都会显示。

```
% nawk '/^[A-Z][a-z]+/' employees
Tom Jones      4424     5/12/66     543354
Mary Adams     5346     11/4/63     28765
Sally Chang    1654     7/22/54     650000
Billy Black    1683     9/23/44     336500
```

employees文件中以大写字母开头，后跟一个或多个小写字母，再后跟一个空格的所有行都会显示。

### 6.8.2 匹配运算符

匹配运算符，即波浪号（~），用于匹配记录或字段中的表达式。

```
% cat employees
Tom Jones      4424     5/12/66     543354
Mary Adams     5346     11/4/63     28765
Sally Chang    1654     7/22/54     650000
Billy Black    1683     9/23/44     336500

% nawk '$1 ~ /[Bb]ill/' employees
Billy Black    1683     9/23/44     336500
```

第一个字段中匹配Bill或bill的任何行都会显示。

```
% nawk '$1 ~ /[yY]s/' employees
Tom Jones      4424     5/12/66     543354
Mary Adams     5346     11/4/63     28765
```
