# The emacs Built-In Editor.

If you are using the emacs built-in editor, like vi, start at the command line. To start moving upward through the history file, press ^P. To move down, press ^N. Use emacs editing commands to change or correct text, then press Enter, and the command will be re-executed. See Table 9.14.

# Table 9.14 emacs Commands

| Command | Function |
|---|---|
| Ctrl-P | Move up history file |
| Ctrl-N | Move down history file |
| Esc < | Move to first line of history file |
| Esc > | Move to last line of history file |
| Ctrl-B | Move backward one character |
