
## Table 2.1 C and TC Shell Syntax and Constructs (continued)

| Syntax or construct | Description |
|---|---|
| **Wildcards** | There are some characters that are evaluated by the shell in a special way. They are called shell metacharacters or “wildcards.” These characters are neither numbers nor letters. For example, the `*`, `?`, and `[ ]` are used for filename expansion. The `!` is the history character; the `<`, `>`, `>>`, `&`, and `|` symbols are used for standard I/O redirection and pipes. To prevent these characters from being interpreted by the shell, they must be quoted with a backslash or quotation marks.<br><br>**EXAMPLE**<br><br>`rm *; ls ??; cat file[1-3]; !!`<br>`echo "How are you?"`<br>`echo Oh boy!` |
| **Displaying output** | To print output to the screen, the `echo` command is used. Wildcards must be escaped with either a backslash or matching quotation marks.<br><br>**EXAMPLE**<br><br>`echo "Hello to you!!"` |
| **Local variables** | Local variables are in scope for the current shell. When a script ends or the shell exits, they are no longer available; that is, they go out of scope. Local variables are set and assigned values.<br><br>**EXAMPLE**<br><br>`set variable_name = value`<br>`set name = "Tom Jones"` |
| **Global variables** | Global variables are called environment variables. They are set for the currently running shell and are available to any process spawned from that shell. They go out of scope when the script ends or the shell where they are defined exits.<br><br>**EXAMPLE**<br><br>`setenv VARIABLE_NAME value`<br>`setenv PRINTER Shakespeare` |
| **Extracting values from variables** | To extract the value from variables, a dollar sign is used.<br><br>**EXAMPLE**<br><br>`echo $variable_name`<br>`echo $name`<br>`echo $PRINTER` |
| **Reading user input** | The special variable `$<` reads a line of input from the user and assigns it to a variable.<br><br>**EXAMPLE**<br><br>`echo "What is your name?"`<br>`set name = $<` |
| **Arguments** | Arguments can be passed to a script from the command line. Two methods can be used to receive their values from within the script: positional parameters and the `argv` array.<br><br>**EXAMPLE**<br><br>`% scriptname arg1 arg2 arg3 ...`<br><br>Using positional parameters:<br>`echo $1 $2 $3` — arg1 is assigned to `$1`, arg2 to `$2`, etc.<br>`echo $*` — all the arguments<br><br>Using the `argv` array:<br>`echo $argv[1] $argv[2] $argv[3]`<br>`echo $argv[*]` — all the arguments<br>`echo $#argv` — the number of arguments |
| **Arrays** | An array is a list of words separated by whitespace. The list is enclosed in a set of parentheses.<br><br>The built-in `shift` command shifts off the left-hand word in the list.<br><br>Unlike C, the individual words are accessed by index values, which start at 1 rather than 0.<br><br>**EXAMPLE**<br><br>`set word_list = ( word1 word2 word3 )`<br><br>`set names = ( Tom Dick Harry Fred )`<br>`shift names` — removes Tom from the list<br><br>`echo $word_list[1]` — displays first element of the list<br>`echo $word_list[2]` — displays second element of the list<br>`echo $word_list` or `$word_list[*]` — displays all elements of the list<br>`echo $names[1]`<br>`echo $names[2]`<br>`echo $names[3]`<br>`echo $names` or `echo $names[*]` |
| **Command substitution** | To assign the output of a UNIX/Linux command to a variable, or use the output of a command in a string, the command is enclosed in backquotes.<br><br>**EXAMPLE**<br><br>`set variable_name=\`command\``<br>`echo $variable_name`<br><br>`set now = \`date\`` — The command in backquotes is executed and its output is assigned to the variable `now`<br>`echo $now`<br>`echo "Today is \`date\`"` — The output of the `date` command is inserted in the string |
| **Arithmetic** | Variables that will hold the results of an arithmetic computation must be preceded by an `@` symbol and a space. Only integer arithmetic is provided by this shell.<br><br>**EXAMPLE**<br><br>`@ n = 5 + 5`<br>`echo $n` |
| **Operators** | The C and TC shells support operators for testing strings and numbers similar to those found in the C language.<br><br>**EXAMPLE**<br><br>Equality:<br>`==`<br>`!=`<br><br>Relational:<br>`>` greater than<br>`>=` greater than or equal to<br>`<` less than<br>`<=` less than or equal to<br><br>Logical:<br>`&&` and<br>`||` or<br>`!` not |
| **Conditional statements** | The `if` construct is followed by an expression enclosed in parentheses. The operators are similar to C operators. The `then` keyword is placed after the closing parentheses. An `if` must end with an `endif`. An alternative to `if`/`else if` is the `switch` statement.<br><br>**EXAMPLE**<br><br>The `if` construct is:<br>`if ( expression ) then`<br>`block of statements`<br>`endif`<br><br>The `if`/`else` construct is:<br>`if ( expression ) then`<br>`block of statements`<br>`else`<br>`block of statements`<br>`endif`<br><br>The `if`/`else`/`else if` construct is:<br>`if ( expression ) then`<br>`block of statements`<br>`else if ( expression ) then`<br>`block of statements`<br>`else if ( expression ) then`<br>`block of statements`<br>`else`<br>`block of statements`<br>`endif` |
