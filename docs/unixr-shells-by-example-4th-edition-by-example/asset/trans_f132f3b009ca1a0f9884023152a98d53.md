

## 表10.2 快捷运算符

| 运算符 | 示例 | 等价于 |
|---|---|---|
| += | @ num += 2 | @ num = $num + 2 |
| -= | @ num -= 4 | @ num = $num - 4 |
| *= | @ num *= 3 | @ num = $num * 3 |
| /= | @ num /= 2 | @ num = $num / 2 |
| ++ | @ num++ | @ num = $num + 1 |
| -- | @ num-- | @ num = $num - 1 |

### 示例10.5

```
1
% @ sum = 4 + 6
echo $sum
10

2
% @ sum++
echo $sum
11

3
% @ sum += 3
echo $sum
14

4
% @ sum--
echo $sum
13

5
% @ n = 3+4
@: Badly formed number
```

### 说明

+   1. 变量sum被赋值为4加6的结果。（@符号后必须有一个空格。）
+   2. 变量sum自增1。
+   3. 变量sum自增3。
+   4. 变量sum自减1。
+   5. @符号后以及运算符两侧都需要有空格。

## 10.3.2 浮点算术

因为该shell不支持浮点算术，如果你需要更复杂的数学运算，可以使用UNIX实用程序。

如果你需要执行复杂的计算，bc和awk实用程序很有用。

### 示例10.6

（命令行）

```
1 set n=`echo "scale=3; 13 / 2" | bc`
echo $n
6.500
```

```
2 set product=`nawk -v x=2.45 -v y=3.124 'BEGIN{\nprintf "%.2f\n", x + y }'`
% echo $product
7.65
```

### 说明

1  echo命令的输出通过管道传给bc程序。将scale设置为3，即要打印的小数点右侧的有效数字位数。计算是将13除以2。整个管道命令用反引号括起来。将执行命令替换，并将输出赋给变量n。

2  awk程序从命令行传入的参数列表中获取其值。传给awk的每个参数都以-v开关开头；例如，-v x=2.45和-v y=3.124。数字相乘后，printf函数格式化并打印结果，精度为小数点右侧2位。输出赋给变量product。

## 10.4 调试脚本

C/TC shell脚本常常会因为一些简单的语法错误或逻辑错误而失败。表10.3提供了csh命令的选项，可帮助你调试程序。

## 表10.3 echo(-x)和verbose(-v)

| 选项 | 作用 |
|---|---|
| 作为csh和tcsh的选项 | |
| csh -x scriptname
tcsh -x scriptname | 在变量替换之后、执行之前显示脚本的每一行。 |
| csh -v scriptname
tcsh -v scriptname | 在执行之前，按你输入的原始形式显示脚本的每一行。 |
| csh -n scriptname
tcsh -n scriptname | 解释但不执行命令。 |
| 作为set命令的参数 | |
| set echo | 在变量替换之后、执行之前显示脚本的每一行。 |
| set verbose | 在执行之前，按你输入的原始形式显示脚本的每一行。 |

### 表10.3 echo(-x)和verbose(-v)（续）

| 选项 | 作用 |
|---|---|
| 作为脚本的第一行 | |
| #!/bin/csh -xv | 同时打开echo和verbose。这些选项可以单独调用，也可以 |
| #!/bin/tcsh -xv | 与其他csh调用参数组合使用。 |

### 示例10.7

（-v和-x选项）

```
1
% cat practice
#!/bin/csh
echo Hello $LOGNAME
echo The date is `date`
echo Your home shell is $SHELL
echo Good-bye $LOGNAME
```

```
2
% csh -v practice
echo Hello $LOGNAME
Hello ellie
echo The date is `date`
The date is Sun May 23 12:24:97 PDT 2004
echo Your login shell is $SHELL
Your login shell is /bin/csh
echo Good-bye $LOGNAME
Good-bye ellie
```

```
3
% csh -x practice
echo Hello ellie
Hello ellie
echo The date is `date`
date
The date is Sun May 23 12:24:15 PDT 2004
echo Your login shell is /bin/csh
Your login shell is /bin/csh
echo Good-bye ellie
Good-bye ellie
```

### 说明

+   1 显示了C shell脚本的内容。其中包含了变量和命令替换行，以便你了解echo和verbose之间的区别。
+   2 csh命令的-v选项会启用verbose功能。脚本的每一行都按脚本中输入的原始形式显示，然后执行该行。
+   3 csh命令的-x选项会启用echo功能。在完成变量和命令替换之后，脚本的每一行才会显示，然后执行该行。因为该功能让你可以检查命令和变量替换的结果是什么，所以它比verbose选项更常用。
