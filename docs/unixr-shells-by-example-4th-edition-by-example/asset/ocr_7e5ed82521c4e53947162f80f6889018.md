| Command substitution | Like the C/TC shells and the Bourne shell, the output of a UNIX/Linux command can be assigned to a variable, or used as the output of a command in a string, by enclosing the command in backquotes. The Bash shell also provides a new syntax. Instead of placing the command between backquotes, it is enclosed in a set of parentheses, preceded by a dollar sign.

**EXAMPLE**

`variable_name=`command`
`variable_name=$( command )`
`echo $variable_name`

`echo "Today is `date`"`
`echo "Today is $(date)"` |
| Arithmetic | The Bash shells support integer arithmetic. The `declare -i` command will declare an integer type variable. The Korn shell's `typeset` command can also be use for backward compatibility. Integer arithmetic can be performed on variables declared this way. Otherwise the `(( ))` (`let command`) syntax is used for arithmetic operations.

**EXAMPLE**

`declare -i variable_name      used for bash`
`typeset -i variable_name      can be used to be compatible with ksh`

`(( n=5 + 5 ))`
`echo $n` |
| Operators | The Bash shell uses the built-in test command operators to test numbers and strings, similar to C language operators.

**EXAMPLE**

Equality:                Logical:
`==`      equal to          `&&`      and
`!=`      not equal to      `||`      or
                              `!`       not

Relational:
`>`       greater than
`>=`      greater than, equal to
`<`       less than
`<=`      less than, equal to |
