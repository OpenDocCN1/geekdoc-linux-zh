# Table 15.4 Common Bourne Shell Error Messages (continued)

| Error Message | What Caused It | What It Means | How To Fix It |
|---|---|---|---|
| cannot shift | shift 2 | The shift built in command is used to shift positional parameters left. If there will not be at least two positional parameters left, the shift will fail. | set apples pears peaches; shift 2
(apples and pears will be shifted from the list) |
