## LAB 34: HISTORY

## 1. 你的 HISTSIZE 变量设置为多少？你的 HISTFILE 变量设置为多少？检查你的 .kshrc 文件，看 set -o vi 是否在那里。如果没有设置，在 .kshrc 文件中设置它并通过输入以下内容重新执行文件：

```

```

## 2. 在命令行输入以下命令：

```
ls
date
who
cal 2 1993
date +%T
```

输入 history 或 fc -l。这些命令做什么？以相反顺序打印你的历史列表。不带数字打印你的历史列表。打印当前命令和前五个命令。打印从第十个命令到现在的所有内容。打印从最近的 ls 命令到最近的 cal 命令之间的所有内容。

## 3. 使用 r 命令，重新执行最后一个命令。重新执行以字母 d 开头的最后一个命令。更改 cal 命令的年输出为 1897。更改 date 命令 +%T 参数以查找当前小时。

现在使用历史 Esc 序列，做以下事情：

- a. 打印以 a 开头的第一个文件。
- b. 打印以 a 开头的所有文件列表。
- c. 打印以 b 开头的第一个文件。
- d. 打印一个命令并对其进行注释。

## 8. 在命令行输入以下内容：

```

```
