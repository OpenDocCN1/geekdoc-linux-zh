# EXAMPLE 6.19

```
% cat employees
Tom Jones    4424  5/12/66  543354
Mary Adams   5346  11/4/63  28765
Sally Chang  1654  7/22/54  650000
Billy Black  1683  9/23/44  336500
```

(The Command Line)

```
1  awk '/Tom/' employees
Tom Jones  4424  5/12/66  543354
```

```
2  awk '$3 < 4000' employees
Sally Chang  1654  7/22/54  650000
Billy Black  1683  9/23/44  336500
```

# EXPLANATION

+   1 If the pattern Tom is matched in the input file, the record is printed. The default action is to print the line if no explicit action is specified. This is equivalent to awk '$0 ~/Tom/print $0;' employees
+   2 If the third field is less than 4000, the record is printed.

# 6.7.2 Actions

Actions are statements enclosed within curly braces and separated by semicolons.² If a pattern precedes an action, the pattern dictates when the action will be performed. Actions can be simple statements or complex groups of statements. Statements are separated by semicolons, or by a newline if placed on their own line.

# FORMAT

```
{ action }
```
