cat reads each filename in sequence and writes it on the standard output. If no input file is given, or if the argument - is encountered, cat reads from the standard input file.

# EXAMPLE A.9

```
1  cat /etc/passwd
2  cat -n file1 file2 >> file3
```

# EXPLANATION

+   1  Displays the contents of the /etc/passwd file.
+   2  Concatenates file1 and file2 and appends output to file3. The -n switch causes each line to be numbered.

# chfn—changes the finger information

```
chfn [ -f full-name ] [ -o office ] [ -p office-phone ]
     [ -h home-phone ] [ -u ] [ -v ] [ username ]
```

chfn is used to change your finger information. This information is stored in the /etc/passwd file, and is displayed by the finger program. The Linux finger command will display four pieces of information that can be changed by chfn: your real name, your work room and phone, and your home phone.

# chmod—changes the permissions mode of a file

```
chmod [ -fR ] mode filename...
chmod [ugoa [{ + | - | = }] [rwxlsStugo] ] filename...
```

chmod changes or assigns the mode of a file. The mode of a file specifies its permissions and other attributes. The mode may be absolute or symbolic.
