

## 表 2.1 C 和 TC Shell 语法和结构（续）

| Syntax or construct | Description |
|---|---|
| **Wildcards** | 有一些字符会被 shell 以特殊方式求值。它们被称为 shell 元字符或“通配符”。这些字符既不是数字也不是字母。例如，`*`、`?` 和 `[ ]` 用于文件名展开。`!` 是历史字符；`<`、`>`、`>>`、`&` 和 `|` 符号用于标准 I/O 重定向和管道。为了防止这些字符被 shell 解析，必须用反斜杠或引号将其引起来。<br><br>**EXAMPLE**<br><br>`rm *; ls ??; cat file[1-3]; !!`<br>`echo "How are you?"`<br>`echo Oh boy!` |
| **Displaying output** | 要将输出打印到屏幕，使用 `echo` 命令。通配符必须用反斜杠或匹配的引号进行转义。<br><br>**EXAMPLE**<br><br>`echo "Hello to you!!"` |
| **Local variables** | 局部变量的作用域为当前 shell。当脚本结束或 shell 退出时，它们不再可用；即，它们超出作用域。局部变量会被设置并赋予值。<br><br>**EXAMPLE**<br><br>`set variable_name = value`<br>`set name = "Tom Jones"` |
| **Global variables** | 全局变量称为环境变量。它们为当前运行的 shell 设置，并可供从该 shell 启动的任何进程使用。它们在脚本结束或定义它们的 shell 退出时超出作用域。<br><br>**EXAMPLE**<br><br>`setenv VARIABLE_NAME value`<br>`setenv PRINTER Shakespeare` |
| **Extracting values from variables** | 要从变量中提取值，使用美元符号。<br><br>**EXAMPLE**<br><br>`echo $variable_name`<br>`echo $name`<br>`echo $PRINTER` |
| **Reading user input** | 特殊变量 `$<` 从用户读取一行输入并将其分配给变量。<br><br>**EXAMPLE**<br><br>`echo "What is your name?"`<br>`set name = $<` |
| **Arguments** | 参数可以从命令行传递给脚本。在脚本内部接收其值有两种方法：位置参数和 `argv` 数组。<br><br>**EXAMPLE**<br><br>`% scriptname arg1 arg2 arg3 ...`<br><br>使用位置参数：<br>`echo $1 $2 $3` — arg1 分配给 `$1`，arg2 分配给 `$2`，以此类推。<br>`echo $*` — 所有参数<br><br>使用 `argv` 数组：<br>`echo $argv[1] $argv[2] $argv[3]`<br>`echo $argv[*]` — 所有参数<br>`echo $#argv` — 参数的个数 |
| **Arrays** | 数组是一个由空白分隔的词列表。列表用一组括号括起来。<br><br>内置的 `shift` 命令将列表中左侧的词移出。<br><br>与 C 不同，单个词是通过索引值访问的，索引从 1 开始而不是 0。<br><br>**EXAMPLE**<br><br>`set word_list = ( word1 word2 word3 )`<br><br>`set names = ( Tom Dick Harry Fred )`<br>`shift names` — 从列表中移除 Tom<br><br>`echo $word_list[1]` — 显示列表的第一个元素<br>`echo $word_list[2]` — 显示列表的第二个元素<br>`echo $word_list` 或 `$word_list[*]` — 显示列表的所有元素<br>`echo $names[1]`<br>`echo $names[2]`<br>`echo $names[3]`<br>`echo $names` 或 `echo $names[*]` |
| **Command substitution** | 要将 UNIX/Linux 命令的输出分配给变量，或在字符串中使用命令的输出，命令被反引号括起来。<br><br>**EXAMPLE**<br><br>`set variable_name=\`command\``<br>`echo $variable_name`<br><br>`set now = \`date\`` — 反引号中的命令被执行，其输出被分配给变量 `now`<br>`echo $now`<br>`echo "Today is \`date\`"` — `date` 命令的输出被插入到字符串中 |
| **Arithmetic** | 将保存算术计算结果的变量必须以 `@` 符号和空格为前缀。此 shell 仅提供整数算术。<br><br>**EXAMPLE**<br><br>`@ n = 5 + 5`<br>`echo $n` |
| **Operators** | C 和 TC shell 支持用于测试字符串和数字的操作符，与 C 语言中的类似。<br><br>**EXAMPLE**<br><br>相等：<br>`==`<br>`!=`<br><br>关系：<br>`>` 大于<br>`>=` 大于或等于<br>`<` 小于<br>`<=` 小于或等于<br><br>逻辑：<br>`&&` 与<br>`||` 或<br>`!` 非 |
| **Conditional statements** | `if` 结构后面跟着用括号括起来的表达式。操作符与 C 操作符类似。`then` 关键字放在闭合括号之后。`if` 必须以 `endif` 结束。`if`/`else if` 的替代方案是 `switch` 语句。<br><br>**EXAMPLE**<br><br>`if` 结构为：<br>`if ( expression ) then`<br>`block of statements`<br>`endif`<br><br>`if`/`else` 结构为：<br>`if ( expression ) then`<br>`block of statements`<br>`else`<br>`block of statements`<br>`endif`<br><br>`if`/`else`/`else if` 结构为：<br>`if ( expression ) then`<br>`block of statements`<br>`else if ( expression ) then`<br>`block of statements`<br>`else if ( expression ) then`<br>`block of statements`<br>`else`<br>`block of statements`<br>`endif` |
