| Variables: |  |  |  |  |

| Assigning variable attributes | setenv NAME Bob | NAME='Bob'; export NAME | declare or typeset | typeset |
| Assigning values to environment variables | setenv NAME Bob |  | export NAME='Bob' | export NAME='Bob' |
| Read-Only Variables: |  |  |  |  |
