dash option would be stored in $1, $2, and $3, respectively. But what if the user listed all of the options as one dash option, as in ls -1f? Now the -1f would all be assigned to $1 in the script. The getopts function makes it possible to process command-line options and arguments in the same way they are processed by the ls program. The getopts function will allow the runit program to process its arguments using any variety of combinations.

+   2. The program runit combines the options x and n and the number argument 200; filex is also an argument.
+   3. The program runit is invoked with the x and y options combined.
+   4. The program runit is invoked with the y and x options combined; the n option is passed separately, as is the number argument, 30.
