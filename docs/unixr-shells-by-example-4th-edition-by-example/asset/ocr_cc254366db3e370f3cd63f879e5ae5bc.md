# EXAMPLE 13.67

```
1  $ pathname=/home/1111iput/jake/.bashrc
2  $ echo ${pathname#/home}
   /1111iput/jake/.bashrc
```

# EXPLANATION

+   1  The local variable pathname is assigned /home/1111iput/jake/.bashrc.
+   2  The # removes the smallest leading portion of pathname containing the pattern /home; that is, /home is stripped from the beginning of the path variable.

# EXAMPLE 13.68

```
1  $ pathname=/home/1111iput/jake/.bashrc
2  $ echo ${pathname##/}
   .bashrc
```

# EXPLANATION

+   1  The local variable pathname is assigned /home/1111iput/jake/.bashrc.
+   2  The ## removes the largest leading portion of pathname containing zero or more characters up to and including the last slash; that is, it strips off /home/1111iput/jake from the path variable.

# EXAMPLE 13.69

```
1  $ name="Ebenezer Scrooge"
2  $ echo ${#name}
   16
```

# EXPLANATION

+   1  The variable name is assigned the string Ebenezer Scrooge.
+   2  The ${#variable} syntax displays the number of characters in the string assigned to the variable name. There are 16 characters in Ebenezer Scrooge.
