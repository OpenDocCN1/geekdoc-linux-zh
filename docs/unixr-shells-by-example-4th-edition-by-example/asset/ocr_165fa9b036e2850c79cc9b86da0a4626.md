# Common C/TC Shell Error Messages

mimics the C shell errors so closely so the chart serves to address both shells.

# Table 13.3 Common C/TC Shell Error Messages

| Error Message | What Caused It | What It Means | How to Fix It |
|---|---|---|---|
| " : Event not found. | echo "Now" | The exclamation mark (history character) must be escaped. Quotes will not protect it. | echo 'Now!' |
| @: Badly formed number. | set n = 5; @ n = 3 + 4 | Arithmetic can be performed only on whole numbers and there must be space surrounding arithmetic operators. | set n = 5; @ n = 3 + 4 |
| @++: Command not found. | @n++ | The @ sign must be followed by a space. | @ n++ |
| Ambiguous. | `date` | The backquotes are used for command substitution when the output of a command is being assigned to a variable or is part of a string. If the command is on a line by itself, it should not be enclosed in backquotes. TCB will give the error "Command not found". | echo `date` or set d = `date` |
| Bad : modifier in $ f(). | echo $ode:f | The :f is an invalid pathname expansion modifier. | echo $ode:t |
| Badly placed `()`. | echo (abc) | The parentheses are used to start a subshell. The whole command should be placed in () or the string should be quoted. | echo "(abc)" or ( echo abc ) etc. |
| echo: No match. | echo How are you? | The question mark is a shell metacharacter used in filename expansion. It represents one character in a filename. The shell will match you followed by the single character ? to a character named you? or if there isn't a file by that name, the error No match is displayed. | echo How are you? or echo How are you? |
