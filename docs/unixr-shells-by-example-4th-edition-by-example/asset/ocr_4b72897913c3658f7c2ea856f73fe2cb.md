# EXAMPLE 12.66

(The Script)

```
#!/bin/ksh
# Scriptname: todebug
1 name="Joe Blow"
2 if [[ $name = [Jj]* ]] then
    print Hi $name
fi
num=1
3 while (( num < 5 ))
do
4   (( num=num+1 ))
done
5 print The grand total is $num
```
