## 使用 emacs 编辑

## 绑定键。

bindkey 内置命令列出所有标准键绑定，包括 emacs 和 vi 的键绑定。键绑定分为四组：标准键绑定、替代键绑定、多字符键绑定和箭头键绑定。bindkey 命令还允许您更改键的当前绑定。

## 示例 9.81

```
1 > bindkey
Standard key bindings
"^B" -> is undefined
"^A" -> beginning-of-line
"^B" -> backward-char
"^C" -> tty-sigintr
"^D" -> list-or-eof
"^E" -> end-of-line
"^F" -> forward-char
"^L" -> clear-screen
"^M" -> newline
...
Alternative key bindings
"^B" -> is undefined
"^A" -> beginning-of-line
"^B" -> is undefined
"^C" -> tty-sigintr
"^D" -> list-choices
"^E" -> end-of-line
"^F" -> is undefined
...
Multi-character bindings
"^["A" -> up-history
"^["B" -> down-history
"^["C" -> forward-char
"^["D" -> backward-char
"^["OA" -> up-history
"^["OB" -> down-history
...
Arrow key bindings
down -> down-history
up -> up-history
left -> backward-char
right -> forward-char
```

bindkey 的 -l 选项列出编辑器命令及其作用。参见示例 9.84。

## 示例 9.84

```
> bindkey -l

backward-char
  Move back a character
backward-delete-char
  Delete the character behind cursor
```

bindkey 命令还可以显示单个键绑定的值，如示例 9.85 所示。默认情况下显示 emacs 映射，但使用 bindkey 的 -a 选项，则会显示 vi 键的替代映射。bindkey 的参数指定为一系列特殊字符来表示键序列，后跟要将键绑定到的编辑命令键。参见表 9.15 中这些键绑定字符的列表。您可以将键绑定到 emacs 或 vi 编辑器命令，也可绑定到 Linux 命令和字符串。

## 表 9.15 键绑定字符

| 字符 | 含义 |
|------------|---------|
| ^C | Ctrl-C |
| ^[ | Escape |
| ^? | Delete |
| \a | Ctrl-G（铃声） |
| \b | Ctrl-H（退格） |
| \e | Esc（转义） |
| \f | 换页 |
| \n | 换行 |
| \r | 回车 |

## 表 9.15 键绑定字符（续）

| 字符 | 含义 |
|------------|---------|
| \t | Tab |
| \v | Ctrl-K（垂直制表符） |
| \nn | ASCII 八进制数字 |

## 表 9.16 bindkey 选项

| bindkey | 列出所有键绑定 |
|---------|------------------------|
| bindkey -a | 允许替代键映射 |
| bindkey -d | 恢复默认绑定 |
| bindkey -e | 使用 emacs 绑定 |
| bindkey -l | 显示所有编辑命令及其含义 |
| bindkey -u | 显示使用信息 |
| bindkey -v | 使用 vi 键绑定 |
| bindkey key | 显示键的绑定 |
| bindkey key command | 将键绑定到 emacs 或 vi 命令 |
| bindkey -c key command | 将键绑定到 UNIX/Linux 命令 |
| bindkey -s key string | 将键绑定到字符串 |
| bindkey -r key | 移除键绑定 |

## 示例 9.85

```
1 > bindkey ^L
"^L" -> clear-screen
2 > bindkey ^C
"^C" -> tty-sigintr
3 > bindkey "j"
"j" -> self-insert-command
4 > bindkey -v
5 > bindkey -a "j"
"j" -> down-history
```

## 解释

1 使用 Ctrl 键（^L）的 bindkey 命令显示 Ctrl 键绑定到哪个命令。^L 会清除屏幕。
