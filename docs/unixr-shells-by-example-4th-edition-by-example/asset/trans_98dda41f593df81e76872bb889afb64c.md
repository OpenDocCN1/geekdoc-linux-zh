
位置参数10被引用为${10}。$#变量用于测试参数的数量，$*用于显示所有参数。位置参数可以使用set命令设置或重置。使用set命令时，先前设置的任何位置参数都会被清除。参见表14.2。

## 表14.2 位置参数

| 位置参数 | 它引用的内容 |
|---|---|
| $0 | 引用脚本的名称 |
| $# | 保存位置参数的个数 |
| $* | 列出所有位置参数 |
| $@ | 与$*相同，除非用双引号括起来 |
| "$*" | 展开为单个参数（例如 "$1 $2 $3"） |
| "$@" | 展开为单独的参数（例如 "$1" "$2" "$3"） |
| $1 ... ${10} | 引用各个位置参数 |

## 示例14.11

```
(The Script)
#!/bin/bash
# Scriptname: greetings2
echo "This script is called $0."
echo "$0 $1 and $2"
echo "The number of positional parameters is $#"
```

（命令行）

```
$ chmod +x greetings2
$ greetings2
This script is called greetings2.
greetings2 and
The number of positional parameters is
```

```
$ greetings2 Tommy
This script is called greetings2.
greetings2 Tommy and
The number of positional parameters is 1
```

```
$ greetings2 Tommy Kimberly
This script is called greetings2.
greetings2 Tommy and Kimberly
The number of positional parameters is 2
```

## 说明

- 1 在脚本greetings2中，位置参数$0引用脚本名，$1引用第一个命令行参数，$2引用第二个命令行参数。
- 2 greetings2脚本执行时没有传递任何参数。输出显示脚本名为greetings2（脚本中的$0），并且$1和$2从未被赋值；因此，它们的值为空，不会打印任何内容。
- 3 这次传递了一个参数Tommy。Tommy被赋给位置参数1。
- 4 输入了两个参数Tommy和Kimberly。Tommy被赋给$1，Kimberly被赋给$2。

## 14.4.2 set命令与位置参数

带参数的set命令会重置位置参数。³ 一旦重置，旧的参数列表将丢失。要取消设置所有位置参数，请使用set --。$0始终是脚本的名称。

## 示例14.12

```
(The Script)
#!/bin/bash
# Scriptname: args
# Script to test command-line arguments
1 echo The name of this script is $0.
2 echo The arguments are $*.
3 echo The first argument is $1.
4 echo The second argument is $2.
5 echo The number of arguments is $#.
6 oldargs=$*
7 set Jake Nicky Scott   # Reset the positional parameters
8 echo All the positional parameters are $*.
9 echo The number of positional parameters is $#.
10 echo "Good-bye for now, $1."
11 set $(date)           # Reset the positional parameters
12 echo The date is $2 $3, $6.
13 echo "The value of $oldargs is $oldargs."
14 set $oldargs
15 echo $1 $2 $3
```

> 3 记住，不带参数时，set命令会显示为此shell设置的所有变量，包括局部变量和导出变量。带选项时，set命令会打开或关闭shell控制选项，如-x和-v。

```
9 The number of positional parameters is 3.

```

## 说明

- 1 脚本的名称存储在$0变量中。
- 2 $*表示所有位置参数。
- 3 $1表示第一个位置参数（命令行参数）。
- 4 $2表示第二个位置参数。
- 5 $#是位置参数（命令行参数）的总数。
- 6 所有位置参数都保存在一个名为oldargs的变量中。
- 7 set命令允许你重置位置参数，清除旧列表。现在，$1是Jake，$2是Nicky，$3是Scott。
- 8 $*表示所有参数：Jake、Nicky和Scott。
- 9 $#表示参数的数量，即3。
- 10 $1是Jake。
- 11 命令替换执行后（即date命令被执行），位置参数被重置为date命令的输出。
- 12 显示$2、$3和$6的新值。
- 13 打印保存在oldargs中的值。
- 14 set命令根据存储在oldargs中的值创建位置参数。
- 15 显示前三个位置参数。
