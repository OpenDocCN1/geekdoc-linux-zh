

## 表13.14 bash环境变量（续）

| 变量名 | 含义 |
|---|---|
| HOSTTYPE | 自动设置为bash正在执行的机器类型。默认值取决于系统。 |
| IFS | 内部字段分隔符，通常为空格、制表符和换行符，用于对命令替换、循环结构中的列表以及读取输入所产生的单词进行字段拆分。 |
| IGNOREEOF | 控制shell在收到EOF字符作为唯一输入时的行为。如果设置了该变量，其值为bash退出前，在输入行开头连续输入的EOF字符数。如果该变量存在但没有数值，或没有值，则默认值为10。如果该变量不存在，则EOF表示shell输入的结束。此设置仅对交互式shell有效。 |
| INPUTRC | readline启动文件的文件名，覆盖默认的~/.inputrc。 |
| LANG | 用于确定未以LC_开头的变量专门选择的任何类别的区域设置。 |
| LC_ALL | 覆盖LANG及任何其他LC_变量的值。ᵃ |
| LC_COLLATE | 确定路径名扩展结果排序时使用的排序规则，以及匹配路径名和模式时范围表达式、等价类和排序序列的行为。ᵃ |
| LC_MESSAGES | 确定用于翻译前面带有$的双引号字符串的区域设置。ᵃ |
| LINENO | 每次引用该参数时，shell都会用一个十进制数字替换，该数字表示脚本或函数中当前的连续行号（从1开始）。 |
| MACHTYPE | 包含一个描述bash正在执行的系统的字符串。ᵃ |
| MAIL | 如果该参数设置为邮件文件的名称且未设置MAILPATH参数，则shell会通知用户指定文件中邮件的到达。 |
| MAIL_WARNING | 如果设置了该变量，并且bash检查的邮件文件自上次检查以来被访问过，则会打印消息“The mail in [存储邮件的文件名] has been read”。 |
| MAILCHECK | 该参数指定shell检查MAILPATH或MAIL参数指定的文件中邮件到达的时间间隔（以秒为单位）。默认值为600秒（10分钟）。如果设置为零，shell将在发出每个主提示符之前进行检查。 |
| MAILPATH | 冒号分隔的文件名列表。如果设置了该参数，shell会通知用户任何指定文件中邮件的到达。每个文件名后可以跟一个?和一条消息，当修改时间改变时会打印该消息。默认消息为“You have mail”。 |
| OLDPWD | 上一个工作目录。 |
| OPTARG | 由getopts内置命令处理的最后一个选项参数的值。 |
| OPTERR | 如果设置为1，则显示getopts内置命令的错误消息。 |
| OPTIND | 下一个要由getopts内置命令处理的参数的索引。 |
| OSTYPE | 自动设置为描述bash正在执行的操作系统的字符串。默认值取决于系统。 |
| PATH | 命令的搜索路径。它是shell查找命令的冒号分隔目录列表。默认路径取决于系统，由安装bash的管理员设置。常见值为/usr/gnu/bin:/usr/local/bin:/usr/ucb/bin:/usr/bin:。 |
| PIPESTATUS | 一个数组，包含管道中最近执行的前台作业中各进程的退出状态值列表。 |
| PPID | 父进程的进程ID。 |
| PROMPT_COMMAND | 分配给此变量的命令在主提示符显示之前执行。 |
| PS1 | 主提示符字符串，默认为$。 |
| PS2 | 次提示符字符串，默认为>。 |
| PS3 | 与select命令一起使用的选择提示符字符串，默认为#? |
| PS4 | 启用跟踪时使用的调试提示符字符串，默认为+。可以使用set -x启用跟踪。 |
| PWD | 当前工作目录；由cd设置。 |
| RANDOM | 每次引用该参数时，都会生成一个随机整数。可以通过给RANDOM赋值来初始化随机数序列。如果RANDOM被取消设置，它将失去其特殊属性，即使随后重新设置也是如此。 |
| REPLY | 当read未提供参数时设置。 |
| SECONDS | 每次引用SECONDS时，返回自shell调用以来的秒数。如果给SECONDS赋值，则后续引用返回的值是自赋值以来的秒数加上所赋的值。如果SECONDS被取消设置，它将失去其特殊属性，即使随后重新设置也是如此。 |
