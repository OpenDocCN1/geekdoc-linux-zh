# Extra

When VB.NET finds a Case that matches the value of the variable in the Select, the Case block runs and then jumps outside of the Select Case...End Select block. If two Case statements match the tested variable, only the first runs. You can use this to your advantage when making a set of Case statements. For example, if the first test is Case Is <= 5, you do not need to check in the following case statements for values five or below.

You can write complex cases by separating tests by commas. The Case Else statement provides a catchall for a value that does not meet any of the Case statements available. You make a Case Else the last Case before the End Select statement.

# Example:

```
Select Case myNumber
Case 1 To 4, 8, 16, Is > 32
...
Case Is < 1, 5 To 7, 9 To 15
...
End Select
```

# Example:

```
Select Case myString
Case Is <= "E"
...
Case "F" To "H"
...
Case Else
...
End Select
```
