# Extra

You can use the CustomColors property to both provide your own set of colors to the user or to store the user's own selection of colors. The variable type of the property is an integer array. You can use a For Each loop to run through the list and store the user's settings.

# Example:

```
ListBox1.Items.Clear()
Dim myColor As Integer
For Each myColor In ColorDialog1.CustomColors
    ListBox1.Items.Add(myColor)
Next
```

To store an entire set of new values into the CustomColors array, create a new array of size fifteen. Fill the sixteen values (0 to 15) and assign the array to the property.

# Example:

```
Dim counter As Integer
Dim red As Integer = 100
Dim newColors(15) As Integer
For counter = 0 To 15
    newColors(counter) = red
    red = red + 10
Next
ColorDialog1.CustomColors = newColors
```
