
## Bind a Control on a Form

When you access data, you often need to allow the user to edit that data. VB .NET provides functionality in each control to automatically connect its properties to data fields. You can use binding to very quickly connect a form to a database without having to write a significant amount of code.

There are two major types of binding: Simple and complex. Most controls support one or the other type. Simple binding connects a single field of a single record to a control property. For example, you can link the LastName field in a database to a text box for viewing and editing. Complex binding involves binding an entire set of data, be it a single field from a list of records, or an entire table of data.

Simple binding functions through a property called DataBindings in any control that supports it. The property stores a collection of Binding objects that link a property in the control to a DataSet field. Visual Basic .NET enables you to create the appropriate Binding object through the control’s property page. You simply select the field to bind to the control.

To work with a list of records with complex binding, you can use the ListBox, ComboBox, or CheckedListBox. Each displays a list of records that the DataSet provides. Set the DataSource property to a valid DataSet and the DisplayMember property to the field to display. Commonly, you use the ListBox and ComboBox controls to display a list of records to edit. See the section “Move through a Dataset” for information on choosing the active record.

The ErrorProvider control also uses complex binding to monitor a DataSet for errors. This control monitors the data in the field and automatically supplies the error icon beside a control that contains a binding to the field. For more information on ErrorProvider, see the section “Validate Data.”

### Bind a Simple Control

- In the Properties window, click the **+** to the left of (DataBindings).
- In the DataBindings section, click the property to which you want to bind data.
- Click **...** and then click the appropriate field to bind.

### Extra

If you create a DataSet, DataView, or DataTable component in code without using the visual designer, you may still want to bind it to a control. You can bind the component to the control using the properties discussed in this topic. For a simple object, add a new instance of the Binding class to the DataBindings collection property.

**Example:**

```vbnet
Dim myDataTable As New DataTable("MyTable")
myDataTable.Columns.Add("MyField")
Dim myData As DataRow = myDataTable.NewRow()
myData.Item("MyField") = "Test"
myDataTable.Rows.Add(myData)
Dim bindText As New Binding("Text", _
    myDataTable, "MyField")
TextBox1.DataBindings.Add(bindText)
```

You can bind complex controls like the DataGrid controls to data components without using the designer.

**Example:**

```vbnet
Dim myDataTable As New DataTable("MyTable")
myDataTable.Columns.Add("MyField")
Dim myData As DataRow = _
    myDataTable.NewRow()
myData.Item("MyField") = "Test"
myDataTable.Rows.Add(myData)
Dim myData2 As DataRow = _
    myDataTable.NewRow()
myData2.Item("MyField") = "Test Item 2"
myDataTable.Rows.Add(myData2)
DataGrid1.DataSource = myDataTable
```

### Bind a Complex Control

- Click the DataSource property for the control and select the appropriate table.
- Click the DisplayMember property to list.
- Press F5 to run your project.

The controls bind to the data set and display the first available record.

Note: See the section “Move through a Dataset” to allow changes and provide movement to controls.
