# Extra

You have the ability to create an entire node with children using the TreeNode class. Using this method allows you to set all of the properties of a Node before adding it to the control. Building a TreeNode also allows you to build an entire set of nodes and children before adding to the TreeView. This method is extremely useful when the program is already running, because adding the entire tree at the same time is much faster than adding items individually to the tree.

# Example:

```
Dim newNode As New System.Windows.Forms.TreeNode()
Dim newChildNode As New System.Windows.Forms.TreeNode()
newNode.Text = "Sample item"
newChildNode.Text = "Sample child node"
newNode.Nodes.Add(newChildNode)
TreeView1.Nodes.Add(newNode)
```
