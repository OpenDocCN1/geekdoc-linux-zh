# Apply It

You can access a list of DataRow objects available in a DataTable easily using the Select method of the table. The method returns an array of DataRow objects in the table. If you pass a filter string as the parameter to Select, the array contains only DataRow objects that match the criteria. Also, you can pass a sort expression as the second parameter to sort the array.

# TYPE THIS:

```
Private Sub GetRowsByFilter()
Dim dt As DataTable = DsNorthwind1.Tables("Orders")
' Get orders from the year 1998 and later.
Dim Expression As String = "OrderDate >= #1/1/98#"
Dim SortString As String = "Freight DESC"
Dim row As DataRow, selectedRows() As DataRow
selectedRows = dt.Select(Expression, SortString)
' Print the freight and name for the shipping address
ListBox1.Items.Clear()
For Each row In selectedRows
ListBox1.Items.Add(row.Item("Freight") & " - " & row.Item("Ship Name"))
Next
End Sub
```
