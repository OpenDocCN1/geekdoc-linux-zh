The purpose of all of the information within these packets is to help network equipment figure out how to direct packets from the source host to the destination host. Once the packet makes it to the destination host, it allows the host to decide whether it wants to accept it. The IP header specifies which host should receive it, and the TCP header specifies which application on the destination host should get the data (see Figure 25-3).
