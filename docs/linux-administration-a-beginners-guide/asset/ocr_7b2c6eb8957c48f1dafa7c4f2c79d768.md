# Windows NT Based Network

![](bbox=[0.04, 0.16, 0.96, 0.81])

Both networks are functionally equivalent: whatever NT can do, Linux can do as well. However, Linux can typically do this with fewer servers and can support Windows and Macintosh clients as well. This is accomplished with the Samba package for working with Windows clients, and Netataalk for working with Macintosh clients.
