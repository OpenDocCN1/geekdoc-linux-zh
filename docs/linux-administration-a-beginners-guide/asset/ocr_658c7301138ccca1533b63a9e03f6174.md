The last way is to search through the directory listing is using the file browser and double-clicking on the application name you want. This method is, of course, the most tedious, but it can be useful if you can't remember the name of the application. Common directories to check are /usr/bin, /usr/sbin, /bin, /sbin, and /usr/X11R6/bin.
