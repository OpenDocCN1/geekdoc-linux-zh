# ENABLING NFS

As of this writing, all distributions of Linux come with the NFS server installed, usually with NFS already enabled. If you aren't sure about your system, use the **kayes** tool. It will show NFS as started in runlevels 3 and 5.

If you aren't sure as to whether or not NFS is running, you can check by running **rpcinfo**, as follows:

```
[root@ford /root]# rpcinfo -p
```

You'll see something like the following if NFS is running on your system:

program  vers  proto  port
100000   2      tcp    111  rpcbind
100000   2      udp    111  rpcbind
100024   1      udp    965  status
100024   1      tcp    967  status
100011   1      udp    976  rquotad
100011   2      udp    976  rquotad
100005   1      udp    988  mountd
100005   1      tcp    990  mountd
100005   2      udp    993  mountd
100005   2      tcp    995  mountd
100005   3      udp    998  mountd
100005   3      tcp    1000 mountd
100003   2      udp    2049 nfs
100021   1      udp    1090 nlockmgr
100021   3      udp    1096 nlockmgr
100021   1      tcp    2597 nlockmgr
100021   3      tcp    2597 nlockmgr

If NFS isn't running, the entries for **nfs** and **mountd** will be missing.
To start NFS without having to reboot, enter this command:

```
[root@ford /root]# /etc/rc.d/init.d/nfs start
```

To stop NFS without having to shut down, enter this command:

```
[root@ford /root]# /etc/rc.d/init.d/nfs stop
```

If you have NFS enabled through **kayes**, NFS will automatically start up every time you boot the system.
