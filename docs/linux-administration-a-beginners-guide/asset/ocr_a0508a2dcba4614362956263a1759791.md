| Option | Description |
| :--- | :--- |
| `-1 vendorClassID` | Provides additional information for the DHCP server. The vendor class is a string that can be used to help the server classify the client into a particular group. By default, dhcpd sends `system name`, `system release`, and `machine type` as a string. |
| `-1 clientID` | Instead of sending the Ethernet address, you can force the client to send another identifier string. Most servers use the Ethernet address as an identifier, but there are exceptions. |
| `-h hostname` | Includes the specified host name in the DHCP messages sent by dhcpd. There are DHCP servers that can be configured to accept DHCP messages from a set list of clients. |
| `-H` | Forces dhcpd to set the host name to that specified by the server. The client does not do this by default. |
| `-k` | Terminates the currently running dhcpd daemon. |
| `-1 leasetime` | The requested number of seconds the client wants the DHCP lease. Of course, the server can reject this value and issue a lease less than the requested value. |
| `-r` | If invoked with this option, dhcpd will act like a BOOTP client. This is for the rare case that there is only a BOOTP client available, or for testing. |
| `-R` | By default, dhcpd will replace the `/etc/resolv.conf` file such that DNS resolution will be configured with the parameters returned by the server. There are situations for which you may not want this to happen. Specifying this option will prevent it. |
| `-t timeout` | The timeout is the number of seconds dhcpd will try to obtain an address. |
| `interface` | Specifies an interface to have dhcpd configure. If nothing is specified, dhcpd will configure the first Ethernet interface (eth0). |
