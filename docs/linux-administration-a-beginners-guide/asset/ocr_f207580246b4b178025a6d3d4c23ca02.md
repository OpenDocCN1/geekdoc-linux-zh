+   * Auth (113)
+   * X-Windows (ports 6000-6010)

To make things interesting, we don't want to block access to these services to people on our internal network, and we do want to allow ntp.ucseduc to contact our port 123 since we use it to synchronize our clocks. Furthermore, our IP address changes every time we dial up to the Internet. When we aren't connected, the ppp0 interface also goes away, so we need a script to automatically re-enable the rules when we start our connection and another script to flush these rules when we are done using our Internet connection.

The first script looks like this:

```
#!/bin/sh
# 
# Setup firewalling for ppp0 on tcp ports 111, 123, 23, 21, 
# 79, 113, and 6000-6010
# Also deny any incoming ICMP echo-reply packets.
# Use -l option so that all packets that match these criteria
# get logged.
# 

# There is /sbin/
iprc/sbin/ipchains

# Start by making sure there are not residual rules
SIRC -F - input

# Deny all outside portmapper requests (111)
SIRC -A - input -p tcp --destination-port 111 -j DENY - 1 -i ppp0

# Allow ntp.ucsd.edu to connect to our port 123 so long as it's
# originating port 123, Deny everyone else trying to contact
# our port 123
SIRC -A - input -s ntp.ucsd.edu 123 --destination-port 123 -j ALLOW - 1 -i ppp0
SIRC -A - input -p tcp --destination-port 123 -j DENY - 1 -i ppp0

# Deny telnet from everyone
SIRC -A - input -p tcp --destination-port 23 -j DENY - 1 -i ppp0

# Deny POP from everyone
SIRC -A - input -p tcp --destination-port 21 -j DENY - 1 -i ppp0

# Deny finger from everyone
SIRC -A - input -p tcp --destination-port 79 -j DENY - 1 -i ppp0

# Deny ident from everyone
SIRC -A - input -p tcp --destination-port 113 -j DENY - 1 -i ppp0

# Deny X-Windows from everyone
```
