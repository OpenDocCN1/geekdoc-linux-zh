**NOTE: Changes to default settings in /proc do not survive reboots. If you need to change a value permanently, edit your boot scripts so that the change is made at boot time. For example, to enable SYN Flood protection every time the system is booted, add the line echo "1" > /proc/sys/net/ipv4/tcp_syncookies to the end of your /etc/rc.d/rc.local file.**
