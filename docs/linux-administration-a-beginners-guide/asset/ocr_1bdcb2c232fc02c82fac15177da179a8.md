# Bulletin Directory Maintenance

Whenever a new user signs onto the system, he or she will receive every single bulletin that is in the bulletin directory. Obviously, it doesn't make sense to send the new person an announcement from the office party from last year, so be sure to do periodic housekeeping of the bulletins directory. Orderly naming of bulletin filenames should help you with this task.

Do note, however, that Qpoper will be confused if you reuse a bulletin number. Let's say you erase the second bulletin of the three you have in the system. You erase the second bulletin, but don't create a new bulletin to take the second bulletin's place in the alphabetical order. Instead, create a new bulletin number. If you're reusing our suggestion to make bulletin filenames with numbers, you'll want to be sure the next (fourth) bulletin starts with a 00004, even if you erased the second one (00002).

> **NOTE:** Bulletins are a great way to get a message out to all of your users, but this method requires that all of your users read mail using a POP mail reader. Depending on your site, this may not be possible. It's a good idea to verify this before using bulletins for universal announcements.

# Command Line Options for Qpoper

You can set some features of Qpoper on the command line. To do this, edit your */etc/inetd.conf* file so that these options appear at the end of the line. And remember to give the inetd daemon a kick with the `kill -HUP` command as described earlier in this chapter.
