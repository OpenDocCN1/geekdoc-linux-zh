+   The disk geometry in Cylinders/Heads/Sectors format
+   Total size of the disk
+   Amount of disk that has been allocated (partitioned)
+   Amount of available disk that can still be partitioned

In the middle of the screen are the menu choices for what you can do with Disk Druid.
These buttons are:

+   Add: Create a new partition.
+   Edit: Change the parameters on the highlighted partition.
+   Delete: Delete the highlighted partition.
+   Next: Commit changes to disk.
+   Back: Abort all changes made using Disk Druid and exit the program.

> NOTE:  The changes made within Disk Druid are not committed to disk until we click on the Next button.
