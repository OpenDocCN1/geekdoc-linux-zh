
## Red Hat Linux 6.1 on CD-ROM

### What's on the CD-ROM

The bonus CD-ROM included with *Linux Administration: A Beginner's Guide* contains the Publishers Edition of the Red Hat Linux 6.1 distribution for the Intel i386 (or better) platform. It comes with everything you need to install Red Hat Linux and start working with the operating system.

![](img/95b125a8bf06051f34d8aba73558b7eb_588_0.png)

For the full details on the installation process, see **Chapter 2: Installing Linux in a Server Configuration**. You can use this CD-ROM to install as many systems as you like.

For additional details about Red Hat Linux, visit Red Hat's Web site at http://www.redhat.com.

### Install, deploy, and administer Linux—on one workstation or an entire network

Get all the information you need to get up and running with any Linux distribution—Red Hat, Caldera, or SuSE. Whether you're moving to Linux from Windows NT or bringing Linux into your network topology, *Linux Administration: A Beginner's Guide* provides the in-depth coverage you need, including full details on Linux kernel 2.2. You'll learn to install and configure Linux, handle single host administration, set up Internet and Internet services, and implement networking technologies. Plus, eight pages of blueprints map out the key differences between administering Linux and Windows NT.

- Incorporate Linux into your network topology
- Install Linux in a server configuration
- Compile and configure Linux kernel 2.2
- Configure GNOME, KDE, X-Windows, and the shell
- Handle single host administration
- Configure and secure key Internet services, including DNS, FTP, HTTP, SMTP, POP, and SSH
- Provide intranet services, such as NFS, NIS, CIFS, LPD, and DHCP
- Set up a Network Interface Card (NIC), IP masquerading, proxies, and firewalls

Steve Shah is a contributing author to several UNIX and Linux publications. He is a UNIX developer since 1992 and has been working with Linux since 1994. In total, he has used UNIX and three flavors of Windows.
