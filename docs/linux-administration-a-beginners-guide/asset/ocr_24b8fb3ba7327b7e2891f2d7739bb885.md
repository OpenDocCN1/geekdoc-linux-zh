# Selecting a Mouse

You now can select the type of mouse you want to use with the X-Windows environment (X-Windows is Linux’s graphical user interface.) More than likely, the autoprober will have been able to identify what kind of mouse you have.

If you need to help Linux, simply pick your mouse type from the top menu box (see Figure 2-3). If you see the name brand of the mouse with a plus sign (+) to the left of it, clicking on the Plus sign will open a new level of choices for that particular brand.

If you have a serial mouse, you will also need to select the serial port it is using, which you can do in the lower box in the screen.
