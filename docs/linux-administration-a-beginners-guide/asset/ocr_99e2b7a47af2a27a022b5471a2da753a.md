Before we go through the actions that need specific parameters, let's define the parameter types in Table 25-2.

| Type of Parameter | Meaning |
| :--- | :--- |
| **Chain** | The name of the chain that the invocation of *ipchains* is going to work on. The three default chains are input, forward, and output. |
| **Rulespec** | The rule specification. The format of a rule specification is explained later in this section. |
| **Rulenum** | The number of the rule you want to work on. (This assumes the rule number already exists.) |
| **Target** | The action the kernel should take when it finds a packet that matches a rule listed in the chain: Valid targets are ACCEPT, REJECT, and DENY. ACCEPT means that the packet is allowed to pass through whatever chain it is currently being processed. DENY means the packet is dropped and the system simply pretends as if it never got it. REJECT is the friendly version of DENY: It refuses to accept the packet, but it sends an ICMP message to the sender indicating so. |
| **Options** | Additional modifiers that can be applied to each rule. These are, of course, not required. Options are discussed later in this section. |
