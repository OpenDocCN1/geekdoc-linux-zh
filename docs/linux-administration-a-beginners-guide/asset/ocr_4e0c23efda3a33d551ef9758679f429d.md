# ### Using ipchains

The ipchains program is a command-line tool that allows manipulation of packet filtering (also referred to as *firewalling*) chains. There are four types of chains: input chains, forwarding chains, output chains, and user-defined chains. Input chains are sets of rules that are applied to packets that enter the system from the network. Forwarding chains apply to packets that are passing through the Linux system when Linux is configured as a router. And of course, output chains apply to packets that are headed out of the system.
