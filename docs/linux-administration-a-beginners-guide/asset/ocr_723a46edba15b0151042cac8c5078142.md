# SUMMARY

LILO is Linux’s extremely flexible boot loader capable of starting not only Linux, but other operating systems as well, most notably the many variants of Windows. This chapter’s comparisons of LILO to the Windows, NT boot process may help you understand the LILO process. Part of what makes LILO so useful is its simplicity and its capacity to be automated.

In this chapter we covered the following key issues:

+   ▲ Working with the **/etc/lilo.conf** configuration file
+   ▮ Running LILO so that it can install itself onto the boot sector (MBR)
+   ■ The general startup process under Linux, including rc scripts
+   ★ The process of creating your own rc script

One final reminder: Like any crucial system component, LILO should be learned on a nonproduction system before taking your hand to it in a working environment. A mis-take made while working with any tool that affects the boot process, regardless of operating system, may be difficult to correct. Unless, of course, you like risk taking.
