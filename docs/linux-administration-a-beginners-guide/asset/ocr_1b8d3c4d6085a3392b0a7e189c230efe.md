Now use the rm command to remove the actual directory, like so:

```bash
[root@ford src]$ rm -rf sub-2.0.13
```

> **CAUTION:** The rm command, especially with the -rf parameter, is very dangerous. It recursively removes an entire directory without stopping to verify ANY of the files. Run as the root user, this has the potential to really cause problems on your system. Be very careful and make sure you are erasing what you mean to erase. There is no “undo” command.

# # SUMMARY

In this chapter, you learned how to install software under Linux using the RPM method and by compiling software yourself. Hopefully, this information should alleviate any fears you have of dealing with an open source system!

The key points to remember are

+   - The typical install command with RPM is rpm -i *packagename.rpm*.
+   - The typical upgrade command with RPM is rpm -U *packagename.rpm*.
+   - The typical package remove command with RPM is rpm -e *packagename*.
+   - Most source code is shipped as **tarballs**, which can be unpacked with the tar command.
+   - Once untarred, reading the documentation that comes with the package is very important.
+   - Configure the package with the ./configure command.
+   - Compile the software by running the make command.
+   - Install compiled software by running the make install command.
