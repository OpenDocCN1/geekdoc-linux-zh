+   4. Once you’ve entered all the information, click on the “Commit Changes”
+   button near the top of the screen.
+   5. To make the changes appear to any systems that browse your server, restart the
+   smbd daemon by going into the Status menu and clicking on the “Restart
+   smbd” button.

And that’s it. You should now be able to see this share from Windows clients brows-
ing the network.

# USING SMBCLIENT

The smclient program is a command-line tool that allows your Linux system to act as
a Windows client. You can use this utility to connect to other Samba servers or even to
real Windows NT servers. It’s a very flexible program and can be used to browse other
servers, send and retrieve files from them, or even print to them.

In this section we’ll show you how to do basic browsing, remote file access, and re-
move printer access with smclient. However, remember, that smclient is a very
flexible program, limited only by your imagination.

# Browsing a Server

With so many graphical interfaces around, we’ve come to equate browsing to mean
“point and click.” But when your intention is to simply find out what a server has to offer,
it’s not enough of a reason in itself to support an entire GUI.

Using smclient with the -L option allows you to view the offerings of an NT or
Samba server without having to use a GUI. Here’s the format of the command:

```
```  
[root@ford root]# smclient -L hostname
```

where hostname is the name of the server. For example, if we want to see what the host
ford has to offer, we type:
```

```
```  
[root@ford root]# smclient -L ford
