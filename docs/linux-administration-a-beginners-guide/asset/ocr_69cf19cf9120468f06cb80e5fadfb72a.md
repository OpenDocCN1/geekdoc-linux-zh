# Startup Scripts

Under DOS, we are used to having the autoexec.bat and config.sys files automatically run when we start the system up. Since DOS is a single-user system, the two programs not only perform system functions such as loading device drivers, but they also set up our working environment.

UNIX, on the other hand, is a multi-user environment. Each user is allowed to have her or her own configuration files so that the system appears to be customized for each particular user, even if other people are logged in at the same time. The configuration file comes in the form of shell script—a series of commands executed by the shell that starts when a user logs in. In the case of bash, it's the file .bashrc (Yes, there is a period in front of the filename—filenames preceded by periods, also called dot files, are hidden from normal directory listings unless the user uses a special option to list them.) You can think of shell scripts in the same light as batch files, except shell scripts can be much more capable. The .bashrc script in particular is similar in nature to that of autoexec.bat.

When you create a user's account, you should provide a default set of dot files to get the user started. If you use the tools that come with Linux, you don't need to worry about creating these files since the tools automatically do this for you.

# Mail

Creating a new user means not only creating the user's home directory and setting up the environment, it also means making it possible for the user to send and receive e-mail. Setting up a mailbox under Linux is quite easy, and if you use the tools that come with Linux to create the account, you don't even have to do this yourself!

Mailboxes are kept in the /var/spool/mail directory. Each user has a mailbox file that is based on his or her login name. Thus, if a user's login is jwom, his mailbox will be at /var/spool/mail/jwom. An empty mailbox is a zero-length file. All mailboxes should be owned by their respective owners with the permissions set such that others cannot read its contents. (See the chmod, chown, and chgrp commands in Chapter 6 for details on how to do all this.)

To create a zero-length file anywhere in the system, you simply use the touch command like so:

```
[root@ford /root]# touch myfile
```

This will create a new file called myfile in the current directory.
