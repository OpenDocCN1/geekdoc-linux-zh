**Syntax:** ChildPerUserID *number_of_child username groupname*
**Default setting:** None
**Context:** Virtual host

For example, in the following, the virtual host **www.afatcat.com** will be serviced by 10 Apache children who run under the username **mrbert** and group **wheel**:

```
```
ChildPerUserID 10 mrbert wheel
<VirtualHost 192.168.1.100>
ServerName www.afatcat.com
AssignUserID mrbert wheel

# # Other directives go here
#
</VirtualHost>

# ## ConnectionStatus

The *ConnectionStatus* directive sets if status information is internally stored or not. When set to on, modules that use status information will function properly.

**Syntax:** ConnectionStatus On | Off
**Default setting:** ConnectionStatus On
**Context:** Server config
