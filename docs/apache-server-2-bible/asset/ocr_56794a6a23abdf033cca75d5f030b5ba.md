| Attribute | Meaning |
| :--- | :--- |
| `recurse=true \| false` | This attribute determines whether a directory is automatically recursed or not. If set to true (or −1), all subdirectories are recursed; on the other hand, if it is set to false (or 0), the subdirectories are not traversed. Any numeric value in the range of −1 to 1000000 (excluding −1 and 0) dictates the depth of subdirectories that are recursed. For example `recurse=3` means that subdirectories up to level 3 depth are recursed. |
