# ## General Configuration Directives

The directives discussed in this section are fundamental in nature and generally apply to both the primary server (*server config context*) and the virtual servers (*virtual host context*).*

# ### AccessFileName

The AccessFileName directive specifies the name of the per-directory access con- trol file. The default setting (*htaccess*) makes Apache look for the .htaccess file each time an access request is made by a client system.

Syntax: AccessFileName filename [filename ...]

Default setting: AccessFileName .htaccess

Context: Server config, virtual host

For example, say that the DocumentRoot directive of an Apache-powered Web site called www.mycompany.com is set as DocumentRoot "/www/mycompany/public/ htdocs" and a Web browser requests http://www.mycompany.com/feedback. html. This causes Apache to search for the following access control files:

+   - /.htaccess
+   - /www/.htaccess
+   - /www/mycompany/.htaccess
+   - /www/mycompany/public/.htaccess
+   - /www/mycompany/public/htdocs/.htaccess

Only after Apache has checked for all of these files does it look for the *feedback.html* file. If this seems like a lot of disk I/O, it is! You can avoid all that nonsense by specifying the access filename with this directive.
