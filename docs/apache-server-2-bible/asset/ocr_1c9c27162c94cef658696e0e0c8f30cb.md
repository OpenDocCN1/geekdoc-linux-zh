# Simplifying the status display

The status page displayed by the `mod_status` module provides extra information that makes it unsuitable for using as a data file for any data analysis program. For example, if you want to create a graph from your server status data using a spread-sheet program, you need to clean up the data manually. However, the module provides a way for you to create machine-readable output from the same URL by modifying it using `?auto` as in `http://server/server-status?auto`.
