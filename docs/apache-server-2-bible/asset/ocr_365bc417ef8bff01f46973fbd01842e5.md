+   1.  Choose Start → Settings → Control Panel → Administration Tools → Services to display a screen similar to the one shown in Figure 20-8.

![](bbox=[0.23, 0.19, 0.85, 0.37])

+   2.  Double-click on the service name “Apache” and a dialog box appears, as shown in Figure 20-9.

![](bbox=[0.24, 0.45, 0.85, 0.77])

+   3.  Under the General tab you will see a drop-down menu labeled Startup type. Select **Automatic** (for automatic startup on reboot), **Manual** (for operator-assisted startup on reboot), or **Disabled** (to disabled on reboot) option.

+   4.  If you wish to start or stop the Apache service, click on the appropriate button.

+   5.  By default, Apache runs using the local system account under **Windows 2000** or **Windows NT**. If you wish to change this user ID to another one, click on the **Log On** tab and choose the **This account** option. Then enter the appropriate username and password. Make sure this username and password is a valid user credential on your Windows network.
