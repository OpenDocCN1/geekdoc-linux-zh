Another way to write the previous rule is

```
`/bin/ls -> +pinctstsdramcCM$H-l (Rulename= "OS Utilities", severity=100);`
```

However, the first method is preferred because it allows you to group many files and directories under a single rule. For example,

```
```
SEC_CRIT  = +pinctstsdramcCM$H -l;

(Rulename= "OS Utilities", severity=100)
{
	/bin/ls		-> $(SEC_CRIT);
	/bin/login		-> $(SEC_CRIT);
	/bin/ls		-> $(SEC_CRIT);
	/bin/mail		-> $(SEC_CRIT);
	/bin/more		-> $(SEC_CRIT);
	/bin/mt		-> $(SEC_CRIT);
	/bin/mv		-> $(SEC_CRIT);
	/bin/netstat	-> $(SEC_CRIT);
}
```
```

Here all the listed utilities fall under the same policy. Note the use of the SEC_CRIT variable, which is defined before it is used in the rule. This variable is set to `+pinctstsdramcCM$H-l` and substituted in the rule statements using `$(SEC_CRIT)`. This enables you to define a single variable with a set of properties that can be applied to a large group of files and/or directories. When you want to add or remove properties, you simply change the mask value of the variable; the change is reflected everywhere the variable is used.
