This file has two cmd calls:

```
<!--#exec cmd="/bin/date +%%/%%d/%%y" -->
<!--#exec cmd="/bin/ls -l ./*.html" -->
```

The first calls the Unix `/bin/date` utility with the argument `+%%/%%d/%%y`; the second calls the Unix `ls` utility with `./*.html` as the argument. The output of this file is shown in Figure 13-5.
