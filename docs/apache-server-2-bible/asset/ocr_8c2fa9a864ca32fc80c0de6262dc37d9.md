The very first line in this segment sets the content header. A Content-Type header is required. To determine how to display the contents sent by the server, the client uses this header. Because a CGI script generates the contents, it must tell the server what type of contents it is passing to the server for delivery to the client.

The CGI module provides a method called header(), which creates the appropriate Content-Type header. For example, $query->header; returns Content-Type: text/html; charset=ISO-8859-1. When the header() is called without a specific type parameter, it defaults to text/html Content-Type. However, if your script needed to output a different type, say text/plain, you can use the header(-type => 'text/plain') parameter instead. For example:

```
#!/usr/bin/perl
use CGI;
my $query = new CGI;
print $query->header(-type=>'image/gif');
open(GIF, "/tmp/weather.gif");
while(<GIF>){ print;}
close(GIF);
```
