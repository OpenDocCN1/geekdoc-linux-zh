# **Figure 23-2:** A sample load-balancing solution for www.domain.com

A request for `http://www.domain.com` is sent to the load balancer because `www.domain.com` resolves to the IP address of the load balancer. In other words, you must set up the DNS record to point `www.domain.com` to your load balancer system. The load balancer then decides which of the `www[i-N].domain.com` Web servers will respond to the request.
