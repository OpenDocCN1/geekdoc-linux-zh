+   2. Create a ReiserFS (reiserfs) file system on the new partition by using the `/sbin/mkreiserfs /dev/hda7` command.

+   3. Next create a mount point for the new file system. For example, I can create a mount point called `/jfs` by using the `mkdir /jfs` command.

+   4. Finally, mount the file system by using the `mount -t reiserfs /dev/hda7 /jfs` command. Now you can access it from `/jfs` mount point.

To see how a journaling file system stacks up against an ext2 file system, you can use the benchmark in the following section.
