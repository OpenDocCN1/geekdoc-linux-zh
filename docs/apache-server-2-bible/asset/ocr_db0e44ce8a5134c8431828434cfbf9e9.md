# Listing 17-2: /usr/bin/tomcatctl

```
#!/bin/sh

# Change the version number below if your
# JDK is not 1.3.0_02
# VERSION=1.3.0_02

export JAVA_HOME=/usr/java/jdk$VERSION
export PATH=${PATH}:${JAVA_HOME}/bin
export TOMCAT_HOME=/var/tomcat

/usr/bin/tomcat $1

# end
```

After this script is stored in /usr/bin and you have enabled execute permission by running the chmod 755 /usr/bin/tomcatctl command, you can start or stop Tomcat without worrying about the environment variables. For example, to start Tomcat you can run the tomcatctl start command; to stop run the tomcatctl stop command; and to run it in the foreground, run the tomcatctl run command.

The binary RPM package also installs the /etc/rc.d/init.d/tomcat script. This script is symbolically linked to the appropriate run-level so that Tomcat automatically starts and stops every time you reboot the system. However, the default value for JAVA_HOME and for the JDK path in /etc/rc.d/init.d/tomcat might not be appropriate for everyone. For example, the default values set in this script for these two variables are shown below:

```
export PATH=$PATH:/opt/IBMJava2-13/bin:/opt/IBMJava2-13/jre/bin
export JAVA_HOME=/opt/IBMJava2-13
```

These appear to be the RPM developer's own settings. If you followed my earlier instructions to download the JDK from Sun Microsystems's Web site, your installation path for the JDK will differ. So, be sure to modify these two settings in /etc/rc.d/init.d/tomcat script. For example, the correct values are:

```
export PATH=$PATH:/usr/java/jdk1.3.0_02/bin:/usr/java/jdk1.3.0_02/jre/bin
export JAVA_HOME=/usr/java/jdk1.3.0_02
```
