| Table B-1 | Commonly Used Meta Characters | Meta Characters | Purpose |
|---|---|---|---|
| \ | Matches any character (except newline character) | \ | Matches any character (except newline character) |
| ^ | Matches the start of the string | ^ | Matches the start of the string |
| $ | Matches the end of the string | $ | Matches the end of the string |
| \b | Matches a word boundary | \b | Matches a word boundary |
| x? | Matches 0 or 1 x's, where x is any regular expression | x? | Matches 0 or 1 x's, where x is any regular expression |
| x* | Matches 0 or more x's | x* | Matches 0 or more x's |
| x+ | Matches 1 or more x's | x+ | Matches 1 or more x's |
| foo\|bar | Matches one of foo or bar | foo\|bar | Matches one of foo or bar |
| [abc] | Matches any character in the set abc | [abc] | Matches any character in the set abc |
| [A-Z] | Matches any character in the range A to Z. | [A-Z] | Matches any character in the range A to Z. |
| [^xyz] | Matches any single character not in the set xyz | [^xyz] | Matches any single character not in the set xyz |
| \w | Matches an alphanumeric character (for instance, [a-zA-Z0-9_]) | \w | Matches an alphanumeric character (for instance, [a-zA-Z0-9_]) |
| \s | Matches a whitespace character | \s | Matches a whitespace character |
| \t | Tab character | \t | Tab character |
| \n | Newline character | \n | Newline character |
| \r | Return character | \r | Return character |
| \f | Form-feed character | \f | Form-feed character |
| \v | Vertical tab | \v | Vertical tab |
| \a | Bell character | \a | Bell character |
| \e | Escape character | \e | Escape character |
| \077 | Octal char | \077 | Octal char |
| \x9f | Hex char | \x9f | Hex char |
| \c[ | Control char | \c[ | Control char |
| \l | Lowercase next char | \l | Lowercase next char |
| \L | Lowercase till \E | \L | Lowercase till \E |
| \U | Uppercase till \E | \U | Uppercase till \E |
| \E | End case modifification | \E | End case modifification |
| \Q | Uppercase next char | \Q | Uppercase next char |
| \u | Quote metacharacters till \E | \u | Quote metacharacters till \E |
