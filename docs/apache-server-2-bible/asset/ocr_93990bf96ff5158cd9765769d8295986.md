This script outputs a special proxy server configuration for a host with the IP address 206.171.50.51; all other hosts get a different configuration. To access this proxy configuration, I can set up the Netscape Navigator or IE to point to this script at http://www.nftec.com/cgi-bin/proxy.pl. For example, in IE you can specify a URL such as the above as the automatic proxy configuration script address in Tools❙Internet Options❙Connections❙LAN Settings❙Use automatic configuration script option, except that you are asking the browser to request a CGI script instead of a .pac file. But because the script sends out the content-type of a .pac file, the browser has no quarrel about why it got the proxy configuration from a CGI script and not a .pac file. Although the example script does not do much, you can use similar scripts for complex proxy configurations.
