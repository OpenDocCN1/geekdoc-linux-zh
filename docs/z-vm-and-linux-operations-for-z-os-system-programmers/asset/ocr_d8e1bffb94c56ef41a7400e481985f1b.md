The bottom left corner of the vi window indicates which operating mode you are using (the area is blank if you are in command mode):

+   - -- REPLACE --

+   - -- INSERT --

Normally, vi starts in command mode. The filename is listed in the bottom left corner of the initial window until you input the first text.

Various utilities such as PuTTY¹, which is a free Telnet and secure shell (SSH) client for Windows and UNIX platforms, make vi easier to use. With PuTTY, for example, you can switch to insert mode from the other two modes. The Insert key also brings you from insert mode to replace mode.
