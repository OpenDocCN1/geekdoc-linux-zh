This demonstration provides ideas for using z/VMs virtualizition capabilities to manipulate device addresses as seen by z/OS. A possible scenario could be to have a relatively static hardware configuration (considering the IOCDS) for test z/OS images. By cloning a z/OS preconfigured system, you would be able to manipulate physical device addresses and their corresponding virtual addresses for each guest in z/VM, thus reducing the need for configuration changes.
