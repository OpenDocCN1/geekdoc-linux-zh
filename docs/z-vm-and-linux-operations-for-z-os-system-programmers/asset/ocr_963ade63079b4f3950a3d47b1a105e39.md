# Example 6-19 Enabling the network interface

```
[root@mb ase40 etc]# echo '0.0.0d20,0.0.0d21,0.0.0d22' > /sys/bus/ccwgroup/drivers/qeth/group
[root@mb ase40 etc]# echo 1 > /sys/devices/qeth/0.0.0d20/online
```
