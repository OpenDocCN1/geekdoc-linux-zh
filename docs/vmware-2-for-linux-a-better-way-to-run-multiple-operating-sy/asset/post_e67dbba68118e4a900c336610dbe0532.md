## Adjustments with the Configuration Editor

Take a few minutes to breeze through the Configuration Editor to verify the settings generated by the wizard and make adjustments, if necessary:

- 1. Open the Configuration Editor in the Settings menu.
- 2. Verify that the wizard created a Primary Master (P-M) IDE virtual disk in the Windows NT configuration directory of the size you created (it might appear to be one megabyte less than you specified) and a Secondary Master (S-M) CD-ROM, most likely pointing to /dev/cdrom.
- 3. If you want the virtual machine to have direct access to your serial or parallel ports, configure them now as described in Chapter 5, “Running VMware for the First Time.” Remember that serial ports start at /dev/ttyS0, and parallel ports start at /dev/lp0 on most Linux machines.
- 4. If your Linux PC has sound configured and running and you want the virtual machine to have sound access, click the Sound option, and then click Install in the sound configuration window.

> You might want to come back later and reassign /dev/cdrom to be a virtual SCSI CD-ROM drive, but because VMware does not support booting from a virtual SCSI CD-ROM, you should use the CD-ROM in IDE mode for now to install the OS.

Windows NT doesn't automatically install your sound driver, so you can leave it off for now if you so choose.

- 5. The wizard usually suggests a high memory value for Windows NT, but you might need to make adjustments up or down depending on your unique situation. Change the setting in the screen shown in Figure 11.5. Be sure you don't exceed VMware's maximum reserved memory allocation. Consider 48MB an absolute minimum to get any sort of performance from Windows NT.
- 6. Make changes in the Misc settings list, if necessary. Windows NT doesn't have the world's best APM support, so you might want to stick with VMware's built-in suspend/restore capabilities.
- 7. Click Save when finished in the Configuration Editor.

## Installing Windows NT 4 Workstation

Installing Windows NT is not significantly more complicated than Windows 95 or 98; in fact, in VMware, it's arguably easier than installing Windows 95:

Your Windows NT installation might be slightly different from what's detailed here. You may initially need to boot from a floppy, or you might see slightly different prompts, depending on what service pack the NT installation CD was created with. If things appear to be drastically different from what's outlined here, consult a Windows NT authority for help.

- 1. If you're not running VMware already, start it by typing `/usr/bin/vmware`, and select your Windows NT configuration when prompted at the screen shown in Figure 11.6.
- 2. Insert the Windows NT CD-ROM, and power on the virtual machine.

> After you start the power to the virtual machine, you can feel free to click Full Screen. Screen updates, and as a result the installation as a whole, will be much faster.

- 3. After a short while, you should see the trademark Microsoft blue text screen setup program, shown in Figure 11.7. Press Enter to proceed.

![](img/b2b6702758c230ce537468351fc8af15_226_0.png)

Figure 11.6 Double-click on the Windows NT configuration you just created to load the proper settings file.

![](img/b2b6702758c230ce537468351fc8af15_226_1.png)

Figure 11.7 Windows NT starts from a text-based installation screen.

- 4. The setup program should detect your virtual IDE CD-ROM drive. Ignore the prompt for additional device drivers, and press Enter to continue.
- 5. Because you are using a new virtual disk, setup claims your disk is "new or has been erased" and warns that installing Windows NT will destroy any data. You don't care, so proceed with the formatting and partitioning of the virtual drive by pressing C.
- 6. You are prompted to read and accept the Microsoft end-user license agreement. Read it and then press F8 to accept.
- 7. Setup makes some guesses about your hardware; items such as the keyboard and mouse are easy to detect, so it's right, you don't need to make any changes. Press Enter on The above list matches my computer to continue.
- 8. Windows NT doesn't use fdisk, but a custom text interface for partitioning disk drives. It creates one large partition on your virtual disk, which is a good configuration unless you have a special need. Press Enter on the partition you want to use for NT when you see a screen that resembles Figure 11.8.
- 9. Windows NT asks you to choose between the FAT and NTFS file system. NTFS is faster and works perfectly well in VMware, so use it unless you have a compelling reason to use FAT (such as you want to create a dual-boot configuration with DOS, Windows 3.1, or an early version of Windows 95 on your virtual drive).
- 10. Setup quickly formats the virtual disk and then asks for a directory to install the system to (\WINNT by default). Press Enter to proceed.

![](img/b2b6702758c230ce537468351fc8af15_227_0.png)

Figure 11.8 Windows NT must format and partition the virtual disk before the OS can be installed.
