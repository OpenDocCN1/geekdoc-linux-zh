## Adjustments with the Configuration Editor

The wizard is reliable, but not thorough. You should make a quick stop in the Configuration Editor to make a few minor adjustments before you launch the virtual machine and start the Windows installation:

- 1. Open the Configuration Editor in the Settings menu.
- 2. Verify that the wizard created a Primary Master (P-M) IDE virtual disk in the Linux configuration directory of the size you created (it might appear to be one megabyte less than you specified) and a Secondary Master (S-M) CD-ROM, most likely pointing to /dev/cdrom.

> You might want to come back later and reassign /dev/cdrom to be a virtual SCSI CD-ROM drive, but because VMware does not support booting from a virtual SCSI CD-ROM drive, your best bet is to install from a virtual IDE CD-ROM.

If you don’t check the Require shift option, and you ever need to shut down the virtual machine’s X server using Ctrl+Alt+Bksp, you’ll actually shut down the host’s X server!

- 7. Click Save when finished in the Configuration Editor.

## Installing Linux in a Virtual Machine

You’re ready to build a Linux redundancy machine, so to speak. This example uses the Open Circulation edition of Corel Linux OS: the version available for download over the Internet, bundled with Corel’s WordPerfect for Linux product, and in various other package deals:

Corel Linux OS is primarily aimed at single-user workstation computers and does not come with a great deal of server software. It does come with the basics (FTP, Web, and so on), but you have to look elsewhere for esoteric programs.

- 1. If you’re not already in VMware, start the program and load the Linux configuration defined in the previous section.
- 2. Insert the Corel Linux OS CD in the CD-ROM drive.
- 3. Power on the virtual machine.
