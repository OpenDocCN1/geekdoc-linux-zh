# # Chapter 5: Running VMware for the First Time

All you need to get a usable configuration, and it's much easier to adjust a few settings later than build them all from scratch.

For this example, I demonstrate setting up a Windows 98 guest operating system session. The procedure is virtually identical for any guest OS.

> > If you are skipping around in this book and have not yet read about VMware resource requirements in Chapter 3, "Equipping Your PC for VMware," now is an excellent time to do so.

+   1. Start the VMware Configuration Wizard by clicking on the File menu and then selecting Wizard. The welcome screen appears, and is shown in Figure 5.10.
+   
+   2. Click Next to advance to the guest OS selection screen.
+   
+   3. All of VMware's fully supported operating systems are listed, including an option for Other if you want to experiment. For this demonstration, choose Windows 98 from the Guest Operating System screen pictured in Figure 5.11, and click Next to continue.
+   
+   4. On the screen shown in Figure 5.12, VMware asks where you want to store configuration files related to this virtual machine. By default, VMware creates a directory named after the guest OS off of a vmware branch in your home directory, in this case '/home/[yourname]/vmware/win98/. If you decide to relocate it, don't forget your selection. Click Next when you are ready to proceed.'
