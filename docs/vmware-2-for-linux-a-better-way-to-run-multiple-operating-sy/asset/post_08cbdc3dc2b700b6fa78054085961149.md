
4. Select Windows 2000 from the list of guest operating system choices, and then click Next to proceed.

5. Enter a path to the new directory that will house the VMware configuration files as well as the virtual disk. By default, VMware asks to create a new directory called /vmware/win2000 off your home directory, although it might make more sense to be more specific about which edition (Server or Professional) you will run, as in /vmware/win2000pro or /vmware/win2000serv. See Figure 12.1 for an example.

6. VMware asks whether you want to create a new virtual disk or use an existing physical disk. Unless you are familiar with the advanced disk and configuration modes described in Appendix A, “Advanced VMware Configuration,” it is best to accept VMware’s offer to create a new virtual disk. Click Next.

> If you plan to do serious work with Windows 2000, it would behoove you to learn the concepts in Appendix A because Windows 2000 uses up space in a big hurry, particularly the Server version.

7. Enter a size for the new virtual disk. Although 2,000 is the default, you can go as high as 2,047MB, as shown in Figure 12.2. Remember that the disk grows as data is added, but you cannot change its maximum size later. Click Next to proceed.

8. VMware should detect your CD-ROM. Leave the default settings as is (to enable CD-ROM access and make it available when the virtual machine boots), and click Next.

9. VMware asks about floppy access. Unless you have a compelling reason to disable the floppy, leave this setting alone as well. Click Next.

10. The wizard asks how the virtual machine should be able to access the network (see Figure 12.3). If you plan to keep the Windows VM completely isolated, you can click No networking. If you have an Ethernet card installed and your PC is on a LAN, use Bridged networking, which lets the virtual machine share your Ethernet card and appear as a standalone computer on the network. Host-only networking allows Samba file sharing between the VM and your Linux PC (provided you installed the VMware Samba server at installation or have one of your own running), and Bridged and Host-only networking combines the two. If you have a LAN, stick with Bridged for now. If you do not, use Host-only or none. Click Next to reach the final step.

See Chapter 9, "Using Your Windows 95/98 Virtual Machine," and Appendix B, "File Sharing with Samba and NFS in VMware," for extended file sharing and networking tips for Windows.

## Adjustments with the Configuration Editor

Using the Configuration Editor with a Windows 2000 session is particularly important because the memory settings might be less than ideal, but rather than charge at the memory settings and neglect the rest, take the time to carefully check all the sections:

- 1. Open the Configuration Editor in the Settings menu.
- 2. Verify that the wizard created a Primary Master (P-M) IDE virtual disk in the Windows 2000 configuration directory of the size you created (it might appear to be one megabyte less than you specified) and a Secondary Master (S-M) CD-ROM, most likely pointing to /dev/cdrom.

> You might want to come back later and reassign /dev/cdrom to be a virtual SCSI CD-ROM drive, but because VMware does not support booting from a virtual SCSI CD-ROM, you should use the CD-ROM in IDE mode for now to install the OS.

- 3. If you want the virtual machine to have direct access to your serial or parallel ports, configure them now as described in Chapter 5, “Running VMware for the First Time.” Remember that serial ports start at /dev/ttyS0, and parallel ports start at /dev/lp0 on most Linux machines.
- 4. If your Linux PC has sound configured and running and you want the virtual machine to have sound access, click the Sound option and then click Install in the sound configuration window.
- 5. Unless you have an enormous amount of free RAM in your computer, I strongly recommend allocating every last drop of VMware’s reserved memory to your Windows 2000 session. Use the Memory Configuration screen shown in Figure 12.5.
- 6. The Misc settings area is mostly a matter of taste. Make changes as you see fit.
- 7. Click Save when finished in the Configuration Editor.
