When a game speaks of a "music card," that generally means it is looking for a MIDI device, and VMware's sound emulation does not provide MIDI. If you are playing a DOS game that asks you to configure separate "sound" and "music" cards, you need to set the music card to PC Speaker or Silence.

If you do have a problem with excessive speed, try using the program MOSLO.COM, which some classic collections include on CD-ROM. You can also download it from http://www.hp aa.com/moslo.

Finally, try to play games in full-screen mode. Video performance is much faster.

# Windows Gaming Configuration

Aside from the very obvious piece of advice (make sure you have installed VMware Tools and the custom video driver before you even dream of playing games in Windows!), you face a couple of configuration concerns if you want to play compatible Windows games through VMware.

In Windows, as long as you have the Windows SoundBlaster 16 driver loaded, audio should work more or less without fail unless the game requires DirectSound features. But the emulation layer between the virtual machine and your real Linux sound card is rather complex and time-consuming, and you might find that games with frequent sound effects or digitized speech stutter the sound, cause jerky video motion, or both. You might need to get selective about when you turn on sound and rely on text cues or subtitles more often than you might like.
