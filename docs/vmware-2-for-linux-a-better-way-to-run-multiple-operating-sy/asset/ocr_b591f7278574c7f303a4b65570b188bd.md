Corel Linux tries to eject the CD-ROM after you click OK, but it might fail if your Linux host has the CD-ROM mounted and won’t release it. You may need to manually type umount /mnt/cdrom at a terminal prompt on the host OS. Other Linux distributions might not automatically eject the CD-ROM, in which case you should do it yourself before rebooting. Otherwise, you’ll just boot off the CD-ROM and start the installation process all over again!
