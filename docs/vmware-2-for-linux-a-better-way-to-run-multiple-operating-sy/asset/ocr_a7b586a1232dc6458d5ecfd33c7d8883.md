+   2. Download the VICE source archive from http://www.cs.cmu.edu/~dsladic/vice/vice.html. It should be named vice-1.4.tar.gz, possibly with a newer version number. Place it in a convenient directory. (It can be, but does not have to be, the directory you created in Step 1.)

+   3. Open the archive with tar -xzvf vice-1.4.tar.gz. A new directory, vice-1.4, is created.

+   4. Change to that directory with cd vice-1.4.

+   5. VICE comes with a configure program. If you run configure with no options, VICE sets up to install the VICE emulators to /usr/local/bin. I recommend placing the files in the c64 directory you created in Step 1. Run ./configure --prefix=/c64 if you want to place the emulators in the new directory from Step 1 or just ./configure if you are content to place the emulators in /usr/local/bin. The screen fills with text while the configuration process runs.

> You might need to use the su command to become root for Steps 6 and 7.

+   6. Type make to begin the compile process.

+   7. Type make install to install the VICE emulators and support files.
