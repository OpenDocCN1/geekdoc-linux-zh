## Ethernet Adapters

Each virtual machine can have as many as three virtual network connections, although you are likely to need only one or two.

The wizard automatically configures Ethernet adapters based on the networking choice you made at the end of the wizard process (Bridged, Host, both, or neither).

If you passed on either the Bridged or Host networking, you can easily add it here by selecting the one you want from the Connection Type tool and clicking Install, on the window like the one shown in Figure 5.24. No configuration is necessary.

## Parallel Ports

Virtual parallel ports are handled in a similar fashion to serial ports. VMware can address up to two parallel ports, which can be either devices on the host PC or a file. Some advanced users might have reason to adjust the configuration screen shown in Figure 5.26 to direct parallel access to a file (for example, to capture a PostScript printing session that you want to take to a computer with a nicer printer), but for most purposes, stick with the real devices.

If you need parallel port access in your virtual machines, follow these steps:

- 1. Select an LPT device you want the virtual machine to have access to. It's a good idea, but not required, to add them in order.
- 2. Enter the complete path to the device driver. On most Linux PCs, the first parallel port (LPT1) is located at /dev/lp0, the second (LPT2) at /dev/lp1.
- 3. Leave the Bidirectional box checked unless you know your parallel port does not support bidirectional access or you were given a warning about the performance of your parallel port when you installed VMware.
- 4. Click Install to commit your change.
- 5. Save the new configuration by clicking Save at the bottom of the window. This also exits the Configuration Editor.

## Mouse

If you have a reasonably normal Linux installation, VMware should be able to automatically detect and use your mouse in a virtual machine. If VMware struggles to locate your mouse when you run a guest operating system, you might need to enter the type (PS/2 or serial, along with the brand) in the Mouse Type tool shown in Figure 5.27 and add the complete path to your mouse device in the text window.

## Sound

I've always been a little confused about why the Configuration Wizard starts but doesn't finish configuring sound for you. VMware automatically sets the proper device path for an Open Sound System (OSS) or a similarly supported Linux system sound device, and all you need to do is click on the Install button (see Figure 5.28) for it to work.

![](img/b2b6702758c230ce537468351fc8af15_95_1.png)

Figure 5.28

If you're concerned about the speed of your PC, don't activate sound in VMware until you've had a chance to install the operating system and gauge the speed. Sound is CPU intensive for VMware, and some operating systems, such as Windows 98, play a lot of it after they boot for the first time. You can always go back and click Install later if you feel comfortable with it.

## Memory

In the Memory configuration window shown in Figure 5.29, you can tweak the amount of RAM VMware decided to give to this particular virtual machine. Remember that VMware does not always assign the maximum available RAM to certain guest operating systems, so if you want to expand up to the total VMware RAM limit you determined in the global Host Reserved Memory, you are free to do so.

![](img/b2b6702758c230ce537468351fc8af15_96_0.png)

Remember that by expanding a single virtual machine up to the total limit of reserved memory, you make it tricky and probably unbearably slow to run more than one virtual machine at a time. Also, be sure not to exceed the recommended VMware memory limit.
