
11. Windows NT asks to perform a detailed damage scan of your hard disk, but it's pointless to do so on a new virtual disk. Press Esc to skip the check.

> If you're using a plain or raw disk, a check might be useful.

12. Setup copies the base install files to the drive. After it finishes, setup asks to reboot the computer. If you used a boot floppy, remove it. (Leave the CD-ROM in, though.) Press Enter to reboot.

> Windows NT can take a long time to reboot. Although it can sometimes hang during the reboot process, you should wait at least 4 to 5 minutes without disk activity before giving up and invoking a hard reset or power cycle in VMware. (Don't reset your Linux computer; just use the reset and power tools in VMware.)

13. After the reboot, the graphical setup program begins. Click Next to start the process.

14. When you are asked by the screen shown in Figure 11.9, a Typical installation is probably the best selection. All your virtual hardware should be properly recognized, and you will have all the device drivers you should ever need in VMware.

## Windows NT Setup

- Windows NT needs to install the complete network adapter
- Enter complete adapter for a network
- Select the network
- Your computer is connected to a network by an Ethernet adapter
- Your computer is connected to a network by a dial-up adapter
- Your computer uses a modem to connect to a network

![](img/b2b6702758c230ce537468351fc8af15_230_0.png)

Figure 11.11 Add an AMD PCNET adapter manually if Windows NT does not detect all of the virtual Ethernet cards you specified in the Configuration Wizard or Configuration Editor.

21. Windows NT automatically configures TCP/IP networking, which is sufficient for common networking tasks, including all the file sharing you are likely to do. If you plan to integrate with an IPX network or need NetBEUI, enable those options and click Next.

22. If you configured any network adapters, you see a special configuration window before NT networking setup completes. Figure 11.12 shows this window. Click 10Base-T Port and click Continue to return to the setup program.

![](img/b2b6702758c230ce537468351fc8af15_230_1.png)

Figure 11.12 The virtual Ethernet card has its own small configuration tool.

23. If you configured a second network adapter, another configuration window appears (see Figure 11.13). Leave all the settings as they are (except for the 10Base-T port option, which you should check), and click Continue.

![](img/b2b6702758c230ce537468351fc8af15_230_2.png)

Figure 11.13 If you use a second virtual Ethernet card, a larger configuration window appears.

24. When prompted about DHCP, select Yes if you are using host-only networking or if your LAN uses DHCP (for bridged networking). You can always change the settings later.

25. Setup installs various drivers and then asks to start the network. If you plan to use Samba file sharing (either with your Linux PC over host-only networking or with a "real" Windows PC), ensure that the Workgroup field matches. (For host-only, WORKGROUP is the default setting. See Appendix B for more information.) Do not use the Domain setting unless you are using this virtual machine on a real Windows NT Server network, and you are very sure you know what you're doing. Click Next when done.

26. Click Finish to wrap up the installation. You are asked to set the date, time, and time zone.

27. The Display Properties window appears. Leave the default in place (640×480, 16 colors); you can improve your lot later by installing VMware Tools.

28. After a great deal of disk activity, setup asks you to remove the CD-ROM and click to restart the computer. Remember that you might need to disconnect the CD-ROM from VMware and manually unmount the CD in Linux before you can eject it. Be sure to re-attach the CD-ROM after you remove the CD so you can read other discs, and then click Restart.

29. When the NT boot menu appears, press Enter on the top (default) setting. After the NT splash screen appears, press Ctrl+Alt+Del to sign on, and then enter the administrator password you assigned during the setup process.

![](img/b2b6702758c230ce537468351fc8af15_231_0.png)

Figure 11.14 Match the Workgroup setting with VMware's Samba server if you plan to use Samba over host-only networking.
