You will want to create a mountpoint such as /mnt/smb used in the example (just use the mkdir command, as in mkdir /mnt/smb). That mountpoint will contain the host filesystem after you mount the drive.

To mount a Samba share in a VMware Linux guest, the command syntax is

```
smbmount // <server hostname or IP address>/<shared drive name on server> <mount path> -u <valid SMB username on server>
```

On my system, that means the command is

```
smbmount //192.168.71.1/HostFS /mnt/smb -U jcompton
```

This mounts the root Linux host file system in the smbclient software on the guest after you are asked for a password. Use the password that matches the username, as configured with vmware-smbpasswd.

> If you log in to the guest with a username recognized as valid by the VMware Samba server, you can skip the -U <username> step.

After entering the password, change the working directory to the Samba filesystem mountpoint you created (cd /mnt/smb, or whatever you chose). You can perform any standard file operation as if the drive were directly connected to the virtual machine, as shown in Figure B.6.
