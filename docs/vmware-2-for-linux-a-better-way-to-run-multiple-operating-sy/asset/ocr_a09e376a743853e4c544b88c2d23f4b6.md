# Installing VMware Tools

It's always a good idea to start with a clean boot of the operating system before you begin the installation. If VMware is in full-screen mode, switch back to windowed mode by pressing Ctrl+Alt+Esc:

+   1. On the VMware application window, select Settings, VMware Tools Install.
+   2. If this is your first time installing VMware Tools, you might want to take the opportunity to read the online help when prompted.
+   3. Double-click My Computer and the Floppy icon. This opens the virtual floppy VMware mounted when you started the Tools install process.
+   4. Double-click the VMware Tools icon, shown in Figure 12.16.
