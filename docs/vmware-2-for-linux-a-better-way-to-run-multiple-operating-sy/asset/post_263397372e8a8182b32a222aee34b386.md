## Installing VMware Tools

It's always a good idea to start with a clean boot of the operating system before you begin the installation. If VMware is in full-screen mode, switch back to windowed mode by pressing Ctrl+Alt+Esc:

- 1. On the VMware application window, select Settings, VMware Tools Install.
- 2. If this is your first time installing VMware Tools, you might want to take the opportunity to read the online help when prompted.
- 3. Double-click My Computer and the Floppy icon. This opens the virtual floppy VMware mounted when you started the Tools install process.
- 4. Double-click the VMware Tools icon, shown in Figure 12.16.

![](img/b2b6702758c230ce537468351fc8af15_259_1.png)

Figure 12.16 VMware Tools is stored on a special virtual floppy disk.

5. Accept the default settings in the VMware Tools Installation Wizard and proceed with the installation.

6. When prompted to enable clear-text passwords, answer Yes. Although they aren't always strictly necessary to connect to a Linux-hosted Samba server, they make things much easier.

7. Let Windows 2000 restart the virtual machine when prompted.

> After the reboot, things get a little strange. Pay close attention to the next steps.

8. While Windows 2000 is booting, you should see a text window with instructions. Leave it alone for the time being. Then, the VMware SVGA controller is detected, and a Digital Signature warning appears, as shown in Figure 12.17. Click Yes to continue the installation.

9. Windows prompts you to insert a CD. Ignore it. Instead, re-enable VMware Tools Install from the Settings menu on the VMware window.

10. Click OK. Windows complains that it can't find the CD-ROM. In the Copy files from box, type A:\WIN32 and click OK. Windows 2000 finds the proper driver.

11. Click Finish to close the installation window.

12. Select Settings, Cancel VMware Tools Install on the VMware window, and then answer Yes to the dialog box in Windows 2000 to reboot the virtual machine.

13. After the reboot, you should see a tools icon in the system tray and signs of increased color depth on the Windows desktop.

14. Enter Display Properties (either through Control Panels or by right-clicking on the desktop and selecting Properties), and set your Windows desktop to the resolution you want to use. See Figure 12.18 for an example.
