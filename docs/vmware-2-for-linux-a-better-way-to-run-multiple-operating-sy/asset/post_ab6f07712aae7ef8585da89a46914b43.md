## Appendix A: Using Advanced VMware Configurations

Understanding advanced disk types

Understanding the virtual machine BIOS

Although it is possible to add a raw disk to your system from the Configuration Wizard, I recommend that you either edit an existing virtual machine configuration or complete the wizard and then go back and use the Configuration Editor to create the raw disk.

- 1. Open the virtual machine configuration in the Configuration Editor.
- 2. Find a free slot in the IDE or SCSI Drives section.

If you plan to boot from your raw disk, it is a good idea to use the Primary IDE (P-M) slot.

- 3. Set the Device Type to Raw Disk.
- 4. Type a name for your raw disk in the Name box. This will be the name of the “safe raw disk,” a small file stored in your VMware configuration directory that describes the layout of your hard drive to VMware. At this point, your screen should look much like Figure A.1.
- 5. Click Create Raw Disk. A new window should pop up, prompting you for the device name of the hard drive you want to use for the raw disk.
- 6. Type the name of the hard drive you want to use. Normally, this will have the form /dev/hda (where a can be b, c, d, or possibly higher) for IDE drives or /dev/sda (or sdb, sdc, and so on) for SCSI devices.

![](img/b2b6702758c230ce537468351fc8af15_390_0.png)

Figure A.1  The Configuration Editor lets you add raw disks to the virtual IDE or SCSI chain.

> The device name of the drive depends on what type of physical hard drive you use, not on whether you choose to configure it as a raw disk on the virtual IDE or SCSI controller.

7. The Raw Disk Editor appears, as shown in Figure A.2. The Editor shows all of the partitions present on the drive, along with three options: No Access, Read Only, and Read/Write.

![](img/b2b6702758c230ce537468351fc8af15_391_0.png)

Figure A.2 Use the Raw Disk Editor to control which partitions the virtual machine can access.

8. In general, you should give the virtual machine Read/Write access to the MBR, or Master Boot Record (especially if you plan to boot from the raw disk or further partition the drive inside a VMware guest), along with any partitions you plan to use in VMware. Set the rest to Read Only (if you want to try to give the virtual machine access to the partition but are afraid of data corruption) or No Access.

9. Click Save when finished.

10. You return to the Configuration Editor screen. Click Install to finalize the raw disk settings and ensure that VMware will see the drive when you power on the virtual machine. The editor should resemble Figure A.3 when you complete this step.

11. If you are curious about the layout of the safe raw disk file, the VMware documentation details how they are created and how they can be edited by hand. The safe raw disk files are plain text, which you can read with any editor or text viewer, such as more. A sample appears in Figure A.4.

12. Power on your virtual machine to start using the raw disk.

Figure A.3 After you click Install, VMware adds the raw disk you defined to the virtual machine setup.

![](img/b2b6702758c230ce537468351fc8af15_392_0.png)

Figure A.4 Feel free to look at the safe raw disk files, but don't make changes unless you are very sure of what you're doing.

![](img/b2b6702758c230ce537468351fc8af15_392_1.png)

What happens next depends on the rest of your virtual machine configuration. If, for example, you install a drive full of Windows data in your PC and add it as a raw disk in an existing Windows virtual machine, the new partitions should automatically be recognized and configured by Windows, as shown in Figure A.5.

Many Linux environments also automatically recognize and configure new hard drive partitions.

If your raw disk is blank, you need to use an OS installation CD or floppy to format and partition the drive. The strategies outlined in the OS-specific chapters of this book to format and install to virtual disks are essentially the same for raw disks.
