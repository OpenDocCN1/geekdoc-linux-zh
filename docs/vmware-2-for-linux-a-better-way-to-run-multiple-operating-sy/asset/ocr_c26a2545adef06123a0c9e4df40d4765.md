+   - Fit is used when VMware is displayed in a window on your Linux desktop. It snaps the virtual machine window to be large enough to display the entire virtual machine screen at once. If you resize the window to be too small, scroll bars appear so you can pan across the guest OS screen.
+   - Autofit tells VMware to always keep the virtual machine window large enough to show the entire guest OS screen, even if the guest OS changes its size. Unless you have low desktop resolution or a good reason to turn this off, you should keep this on whenever using VMware on the desktop.
+   - Toolbar toggles on and off the list of buttons (Power On, Reset, and so on).
+   - Status Bar toggles on and off the information at the bottom of the VMware screen. The status bar, shown in Figure 5.9, includes virtual LEDs to show when the virtual machine accesses a disk or its emulated Ethernet card.
+   - Icons replaces the text toolbar buttons with small icons.
