## Configuring the IIS FTP Server

To make IIS's FTP server useful for open-ended file sharing between the host and guest, follow these steps:

- 1. Add at least one user to the Windows NT system other than administrator, using the User Manager for Domains under Administrative Tools (Common) in the Programs Start menu.
- 2. Run the Internet Service Manager, found under Microsoft Internet Server (Common), on the Programs Start menu.
- 3. Double-click on the FTP service icon. An FTP management window will appear, like the one shown in Figure 11.30.
- 4. Turn off Allow Only Anonymous Connections on the main configuration tab.
- 5. Click on the Directories tab, and change the default path to C:\ (or a more useful directory path). You can add other paths if you have other drives or you do not want to open up such broad-ranging access. Write access is off by default; be sure to enable it if you want to be able to copy files to Windows NT via the NT FTP server. The end result should resemble Figure 11.31.
- 6. Be sure to apply all changes before closing any windows.

## Configuring the IIS Web Server

There is little to configure on the IIS Web server. You can probably start using it with the defaults, if you remember where you told IIS to look for HTML documents when you installed the system. (If not, just double-click on the WWW service icon in the Microsoft Internet Service Manager.)

## Conclusion

Based on circumstantial evidence (such as the fact that you bought this book!), I might conclude that you prefer Linux's high-power workstation and server capabilities to those of Windows NT. But VMware makes it easy to make that choice almost irrelevant, giving you the flexibility of both Linux and Windows NT simultaneously on your PC.

You can happily run Windows NT in VMware without delving into some of the more esoteric regions of NT configuration, while keeping Linux's familiar reliability in the wings as well.

Windows 2000 is the current reigning grandmaster of Microsoft operating systems. Whether you buy into the marketing message or not, it is an important operating system for Intel PCs and well worth VMware’s time to support. Whether it’s worth your time to run is up to you, but I’m here to help.

Windows 2000 blends the power of NT 4 with the comfort of Windows 95/98. The marriage is not yet a perfect one, and for serious Windows 2000 tasks, you should strongly consider investing in a good reference. By now, Windows 2000 has been around long enough that the literature is authoritative and thorough.

> You really need to be aware of just how resource-intensive Windows 2000 is. Although 2000 Professional can be installed in 64MB of virtual machine memory, it prefers more. Windows 2000 Server is not even supported under 128MB. That means you want to have more than 128MB of RAM installed in your Linux machine because 64MB usually has to be reserved for the overhead of Linux, Linux applications, and the VMware environment. Consider 192MB of total memory your bare minimum requirement to run Windows 2000 Server in VMware. 224MB is better. For this reason, you might find Windows NT 4 Server a better fit for VMware.
