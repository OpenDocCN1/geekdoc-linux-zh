# Plain Disks

Another option is an interesting compromise between virtual disks and raw disks. VMware calls them "plain disks," which is extremely inappropriate because they are in fact rather complicated.

Plain disks are formed by linking together several large files similar to virtual disks. You can also assign a plain disk to incorporate data from a real hard drive partition (similar to how raw disks work).

The advantage of plain disks is that they can be more than 2GB in size, and the large virtual disk files that make them up can be scattered across different local hard drives on your Linux PC. (Regular 2GB virtual disk files must fit entirely on a single partition.)

You need to do some digging in the VMware Configuration Editor if you want to use plain disks because there is presently no wizard-driven way to create them.

The major drawback to plain disks, other than the tricky setup, is that they immediately consume the entire amount of space you allocate to them, unlike a standard virtual disk, which grows as you add data.

> Plain disk support is considered experimental. You should familiarize yourself with VMware using virtual disks before you attempt to set up plain disks.
