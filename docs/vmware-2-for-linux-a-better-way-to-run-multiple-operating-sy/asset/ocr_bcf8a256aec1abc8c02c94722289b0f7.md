# # The Evolving Apple

The original Motorola 68000-series processor (referred to as the 68K) was dropped for the much faster PowerPC chip. Rather than cut off millions of loyal customers from its software investments, Apple included an invisible emulation layer that allowed PowerMac users to run most 68K software on the new CD and shipped 68K and PowerPC versions of its operating system on the same CD.

The current crop of Macintosh emulators for x86-based computers can emulate a 68K-based Macintosh, the pre-PowerMac variety, and as a result, you are limited to running only those versions of the MacOS and only those programs that support the 68K processor line.

That's the bad news. The good news is that there is an extremely large library of software for 68K Macs because developers continued to support the classic machines long after the first PowerMacs became available. Apple even included 68K support in early versions of MacOS 8. Although you will not be able to run some of the newest and most powerful Macintosh software, you do certainly not run out of material.

Remember that because your PC does not have a 68K chip inside it, your CPU has to do double-duty, emulating the precise characteristics of the Motorola chip while it runs Linux and the rest of your programs. Although a modern high-end PC system running an emulator can attain Macintosh speeds greater than any real 68K-based Macintosh ever could, you probably don't have to worry about slowing down programs, as you might in a DOS virtual machine. After you experiment with Macintosh emulation, you'll appreciate the advantages of a virtual machine that can share a common CPU without an emulation layer.
