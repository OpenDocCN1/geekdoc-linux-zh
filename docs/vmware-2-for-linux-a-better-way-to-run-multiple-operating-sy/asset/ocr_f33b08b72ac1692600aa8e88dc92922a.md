Undeniably, Linux has enjoyed much more of the spotlight than FreeBSD in recent years, but FreeBSD users benefit from their own ongoing development, including a Linux compatibility layer that can make the decision between operating systems largely a matter of taste. In general, over the past few years, what has been good for UNIX, Linux, or FreeBSD individually has been good for all three as a group.

# Preparing the Installation

If you are unfamiliar with FreeBSD, it might be best to go through a VMware installation with an OS you are more comfortable with. Even just a trial run using your current Linux CD is a fine way to get your feet wet.

The installation process is not much different from a typical Linux install.

# Running the Configuration Wizard

+   1. If you're not already in VMware, start the main program by typing /usr/bin/vmware at a command prompt.
+   2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
+   3. Click Next to clear the first greeting screen.
+   4. Select FreeBSD from the list of guest operating system choices shown in Figure 13.1, and then click Next to proceed.
+   5. VMware prompts you to enter the directory that will house the VMware configuration files as well as the virtual disk. By default, VMware asks to create a new directory called /vmware/freebsd off your home directory.
