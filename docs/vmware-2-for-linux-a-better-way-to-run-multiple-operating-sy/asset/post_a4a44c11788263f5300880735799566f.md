
+   1. Download the most recent Basilisk II for Linux RPM installation file from http://www.uni-mainz.de/~bauec002/B2Main.html, the home page of Basilisk II. The filename should have the format BasiliskII-0.8-1.1386.rpm, although the version number might be different.

> The next step might require that you first use the su command for root-level access.

+   2. Install Basilisk II with the command rpm -install BasiliskII-0.8-1.1386.rpm, substituting the proper version number if needed.

> The RPM places the main executable in /usr/bin, the document files in /usr/doc/BasiliskII-0.8, and shared device files in /usr/share/BasiliskII.

+   3. Create a new directory to hold Basilisk II-related files. You can choose to put it in a shared location, or in a subdirectory off your home directory, such as /home/jcompton/mac.

+   4. Place your Macintosh ROM image (see the section "Making Sense of Legalities" earlier in this chapter for details) in your new Basilisk II storage directory. Name it something easy to remember, such as ROM or basilisk.rom.

## Configuring Basilisk II

Although the Linux and Windows versions of Basilisk II are just about functionally equivalent, their configuration interfaces are quite a bit different. The Windows version has a thorough (but somewhat imposing) GUI configuration program, and the Linux version has a GUI configuration window that is much easier to use but offers fewer features.

> Basilisk II is technically capable of sharing an Ethernet connection with your PC. But the sharing driver does not seem to work properly in VMware, and the Linux version requires the use of the Basilisk II source code or the Linux etherapt system, both of which are advanced configuration options best left alone unless you are absolutely sure you need them. Consult the Basilisk II documentation for details.

### Configuring Basilisk II for Linux

Mercifully, recent versions of Basilisk II have added a GUI configuration interface as a front-end to its text-based configuration file.

+   1. Type BasiliskII at a command prompt to launch the emulator. The GUI configuration window should appear, as shown in Figure 17.9.

+   2. You should start with the first tab, Volumes. You need to create a hardfile (similar to a VMware virtual disk, except it immediately takes up all the requested space). Click the Create button, and create a hardfile in your Basilisk II files directory. Use a simple name, such as macdisk.HFV. (HFV is a common extension for Mac hardfiles.) The size of the disk is up to you, but I recommend at least 100MB.

![](img/b2b6702758c230ce537468351fc8af15_356_0.png)

Figure 17.9

3. The settings program should automatically add your hardfile to the Volumes list. Below the list is an entry for Unix Root. Basilisk II will mount your Linux file system as a drive in the Mac emulation, but you can specify where the initial mountpoint should be. You will probably select either / (to make the entire file system visible to the emulator) or your home directory, like /home/jcompton.

4. Under normal circumstances, leave the Boot From option alone. But if you ever need to reinstall the MacOS, or you want to force the emulation to boot from a certain CD, you might need to change it to CD-ROM.

5. You should never need to disable the CD-ROM unless a program is particularly picky about the CD-ROM being visible, or you plan to change CDs frequently for non-Macintosh purposes and don't want the emulated MacOS to complain.

6. The SCSI tab is only important if you want to attach a real Macintosh SCSI drive to your Linux SCSI controller, if you have one. If you do, you can point the Macintosh-emulated SCSI controller to the attached Macintosh drives, which should be located at /dev/sg0 (or a different unit number).

> Although the Windows version can also directly access a SCSI controller, there is no good reason to use this feature inside VMware, so for the purposes of this book, this feature is only relevant to the Linux version.

7. The Graphics/Sound tab, shown in Figure 17.10, lets you select the size of the MacOS window. (800x600 or 1024x768 are good choices if your monitor is large enough.) By default, Basilisk II loads in a window, but some X installations might let you use a full-screen mode. If in doubt, use Window mode.
