The default settings are actually quite nice, and appropriate for most users, but you might want to customize the settings, so it's a good idea to understand just what your choices are.

Changing the settings is as simple as clicking the checkmark box. You don't have to reboot, apply, or even close the VMware Tools window for changes to take effect; they work immediately.

# Release Input Focus

The first option is one half of what is, in my opinion, the neatest feature of VMware Tools. When the option Release input focus is enabled and you move the virtual machine's mouse pointer past the edge of the virtual desktop, the pointer is "given back" to Linux. In other words, input focus returns to Linux as soon as it looks like you want to use the mouse in Linux. You don't even have to click the Linux desktop first.

This feature is useful when you have VMware in a window and need to move between Linux and VMware quickly or often, and you don't want to get bogged down using the Ctrl+Alt+Esc key combination to release input focus from VMware. It can get frustrating if you're doing precision work in an art program near the borders of the screen or playing a game using the mouse.

This feature does nothing when the virtual machine is in full-screen mode; the virtual machine maintains input focus at all times until you press Ctrl+Alt+Esc.

# Capture Input Focus

Capture input focus is the match to Release input focus. When this option is turned on, VMware automatically grabs input focus as soon as you scroll the pointer inside the VMware window.

> It's only sensible to turn on Release input focus if this is active, because it's fairly inconvenient to use the Ctrl+Alt+Esc key combination to get the input focus back on Linux if your pointer accidentally strays into a VMware desktop.

This feature does nothing when the virtual machine is in full-screen mode because the mouse is always within the virtual machine until you exit full-screen mode by pressing Ctrl+Alt+Esc.
