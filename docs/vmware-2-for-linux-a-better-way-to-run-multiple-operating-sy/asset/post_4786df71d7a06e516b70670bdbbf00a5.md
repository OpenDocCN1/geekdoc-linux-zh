- 6. Seeing that you have an unformatted hard disk (never mind the fact that it’s really just a virtual disk), Windows Setup asks whether you want to configure the unallocated space. Let it do so.

> If you know you have special partitioning needs, instead of booting to Windows Setup, boot the PC with CD-ROM support and then run fdisk at the DOS prompt and create your own partitions on the virtual disk.

- 7. If you defined a hard drive larger than 512MB in size, Windows asks to turn on large disk support. You should enable this option unless you plan to do something elaborate such as create a dual-boot DOS partition that has access to all the Windows files.

- 8. Windows Setup reboots the virtual machine. If you are prompted to insert the Windows 98 boot disk in drive A: ignore it. The same two text menus appear, and again tell it to boot from CD-ROM and start Windows Setup from the CD-ROM. Setup then formats the virtual C: drive. See Figure 6.11 for proof.

- 9. Setup now performs the infamous Windows “routine check on your system”, shown in Figure 6.12. Nothing to worry about; Microsoft won’t be able to tell that you’re using VMware.

- 10. After the check, Windows finally starts the graphical portion of the installer, displayed in Figure 6.13. Click Continue.

> If you can't use your mouse in the setup program at this point, you might need to exit the virtual machine and check your mouse settings in the Configuration Editor. They should be set to autodetect, but if that doesn't work, switch them to describe the specific type of mouse you use.

- 11. Windows Setup loads and asks basic questions, such as which directory to install Windows in. (C:\WINDOWS is the default.) Because it is irrelevant to VMware, you can simply exercise your preference and best judgment on such matters.

![](img/b2b6702758c230ce537468351fc8af15_113_0.png)

Figure 6.13 It will be helpful to grab your mouse to finish installing Windows in VMware.

- 12. When Windows Setup is satisfied that you have an appropriate system with enough free disk space, you are prompted to select the type of installation, as seen in Figure 6.14. If in doubt, go with a Typical installation; although it’s the largest in terms of disk space, you minimize driver hassles later. If you know you don’t want particular components, use Custom, but take care not to remove too much.

![](img/b2b6702758c230ce537468351fc8af15_113_1.png)

Figure 6.14 The type of installation is largely up to you, but a Typical install will ensure that all the important system components are in place.

- 13. Setup then asks whether it should install drivers for common hardware components or show a list so you can choose. To maximize the ability to properly recognize the VMware hardware and minimize your need to go back to the Windows 98 CD-ROM later, stick with the common components.

- 14. On the Windows Identification screen (see Figure 6.15), name your Windows virtual machine whatever you like, and put it in the VMware workgroup.

- 15. Windows asks the first in a series of regional questions. Input the answers that best apply to you.

- 16. After telling Windows what country you are in, the installation begins in full force. You might want to minimize the VMware window and work on other programs in Linux because it will be installing for some time.

> Although you should feel free at any time to run other programs in Linux while a virtual machine is running, take care not to do anything that might crash the system, especially while installing a new guest OS. This is not a good time to install experimental software or debug a troublesome program.

- 17. Windows reboots after installing the bulk of the software to the virtual drive. Windows Setup then prepares to start Windows for real.

- 18. You are asked for your user information (answer appropriately), then given the Microsoft license agreement to read, and asked to enter the Windows 98 product key. Fill it out and click Next.
