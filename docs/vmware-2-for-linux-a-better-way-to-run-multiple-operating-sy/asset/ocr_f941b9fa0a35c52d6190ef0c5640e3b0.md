# Installing Peripheral Support

Unlike Windows, Linux, and FreeBSD, DOS doesn't make any appreciable effort to detect and configure devices connected to the virtual machine. Therefore, you need to spend a few minutes tightening up the DOS configuration files before you have a 100 percent working installation.

> Throughout the rest of the chapter, I advocate using a DOS-formatted floppy to transfer small files to the virtual machine. If you want to copy files to floppy while VMware is running, you need to use the Devices menu on the VMware window to disconnect the floppy when you plan to write to it from Linux. Reconnect the floppy to VMware when you want DOS to read from the disk.
