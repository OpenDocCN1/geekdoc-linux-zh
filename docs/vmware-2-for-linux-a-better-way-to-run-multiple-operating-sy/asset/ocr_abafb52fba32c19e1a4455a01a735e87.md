Although many experienced PC users already feel comfortable adjusting BIOS settings, both novices and veterans should understand what the VMware BIOS can and cannot do to customize a virtual machine.

To enter the VMware BIOS, press F2 at the VMware boot screen after powering up your virtual machine. The window of opportunity is fairly narrow, and you might want to tap the F2 key a few times to make sure the system acknowledges your request.

When you've succeeded, you should see the main BIOS screen, shown in Figure A.11.

# Using the BIOS Configuration Screens

Each of the six screens has a variety of configuration settings—both those you should be aware of in case you need to change them and those you should leave alone in nearly any situation.

# Adjusting the Main BIOS Screen

On the main BIOS screen, you will find:

+   - Time and Date—These settings should be read directly from your Linux system clock and as such should always be accurate. Only adjust if you have a very specific reason for doing so.

+   - Legacy Diskettes A: and B:—VMware should pass the proper settings, based on your virtual machine configuration, to the virtual machine.
