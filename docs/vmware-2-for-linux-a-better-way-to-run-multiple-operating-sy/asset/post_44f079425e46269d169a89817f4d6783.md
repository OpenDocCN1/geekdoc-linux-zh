It sure was silly when people camped outside computer stores waiting for the release of Windows 95. But it was the first truly successful attempt to bring a full-time GUI-based operating system to consumer PCs, and its mark is indelible. It is not at all surprising that even ardent Linux users have occasion to spend some time in Windows 95.

Windows 95 is as far back into operating-system history that VMware offers full support. Windows 3.1 support is stable but offers only limited graphic display, and support for MS-DOS and clones is stable but not 100 percent and suffers from restricted video modes.

### Choosing Between Windows 95 and Windows 98

Your gut instinct might be to stay as modern as you can and make Windows 98 your primary virtual machine operating system. There are some valid reasons to go with Win 95 instead, however:

- Lower price. Although it’s more difficult to find on store shelves, if you need to start from scratch and buy a Microsoft operating system, chances are that when you find Windows 95, it will cost less than Windows 98.
- Nearly equivalent. Although some programs run only on Windows 98, the vast majority of popular Windows software runs transparently between Windows 95 and 98. In fact, some of the major improvements to Windows 98, such as better USB support, are completely irrelevant in VMware.
- Lower resource requirements. Windows 95 can be reasonably run in 16MB of RAM. More is always better, of course, but it can be done. It also requires much less hard drive space for a basic install; you can even install it from floppies!
- Fewer bundled components. Some people really don’t like how Internet Explorer became tied to Windows 98. Windows 95 treats all browsers equally.
- Faster install. Because it’s just a whole lot smaller than Windows 98, it’s faster to get up and running.

Windows 95 went through a few different revisions over its three-year life. In general, any revision should be fine in VMware, although some Windows applications prefer Windows 95 Revision B (also known as OSR2) or greater.
