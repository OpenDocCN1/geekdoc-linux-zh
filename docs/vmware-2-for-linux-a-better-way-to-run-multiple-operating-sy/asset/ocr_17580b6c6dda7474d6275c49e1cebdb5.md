> If you have a PowerPC-based computer running Linux and are interested in a Macintosh virtual machine, keep your eyes on the SheepShaver project at http://www.sheepshaver.com. SheepShaver is a commercial PowerMac virtual machine for PowerPC-based BeOS computers. A port to PowerPC-based Linux systems is underway.

# Making Sense of Legalities

If you plan to emulate a Macintosh, you need to deal with a sticky legal issue first. When you run Windows in VMware, you need a legitimate licensed copy of the operating system; generally, the license is a code found on the CD jacket or an accompanying booklet.
