VMware would be woefully limited if it could only run a few Microsoft operating systems. With some Linux users happy to boast about how the OS runs on everything from old 386-based computers to Palm devices, it would be a real shame if it didn’t run on VMware.

Of course, it does, and rather well at that. Linux’s modular nature lends itself well to being hosted in a virtual machine, and VMware offers full support for most popular, mainstream Linux distributions as guest operating systems, as shown in Figure 10.1.

# Why Run Linux on Linux?

At first glance, it might seem silly. You already have Linux running on your PC. If you run it in VMware, you incur emulation overhead, plus you have to go through installing Linux and all your favorite applications again. Linux is a powerful multitasking OS. Why bother?
