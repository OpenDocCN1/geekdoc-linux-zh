> The device name of the drive depends on what type of physical hard drive you use, not on whether you choose to configure it as a raw disk on the virtual IDE or SCSI controller.

7. The Raw Disk Editor appears, as shown in Figure A.2. The Editor shows all of the partitions present on the drive, along with three options: No Access, Read Only, and Read/Write.

8. In general, you should give the virtual machine Read/Write access to the MBR, or Master Boot Record (especially if you plan to boot from the raw disk or further partition the drive inside a VMware guest), along with any partitions you plan to use in VMware. Set the rest to Read Only (if you want to try to give the virtual machine access to the partition but are afraid of data corruption) or No Access.

9. Click Save when finished.

10. You return to the Configuration Editor screen. Click Install to finalize the raw disk settings and ensure that VMware will see the drive when you power on the virtual machine. The editor should resemble Figure A.3 when you complete this step.

11. If you are curious about the layout of the safe raw disk file, the VMware documentation details how they are created and how they can be edited by hand. The safe raw disk files are plain text, which you can read with any editor or text viewer, such as more. A sample appears in Figure A.4.

12. Power on your virtual machine to start using the raw disk.
