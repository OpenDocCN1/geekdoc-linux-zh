If this happens, just click the correct entry to disconnect the drive, unmount the CD-ROM in the Linux host if necessary, make the disc change, and then re-connect the drive by clicking again.

> > This is one case where the Devices menu on the VMware window can be more helpful than using VMware Tools. If you have multiple CD-ROMs attached but don't know which is which, based on their IDE or SCSI addresses, use the Devices menu. That lists their Linux paths (such as /dev/cdrom) as well as their SCSI addresses. If you plan to keep your VMware configuration fairly consistent, you might want to keep down which CD-ROM drive is attached to which address on the device chain.

> > Input focus: Determines whether a virtual machine or the host Linux OS captures mouse and keyboard input. When you type into a VMware-hosted OS and application, VMware is said to have input focus.

# ## Using the Toolbox Options

The Options tab, shown in Figure 10.18, helps you fine-tune VMware's input focus settings.

+   1. Select an option to enable it.
+   2. Release input focus when the mouse leaves the virtual machine.
+   3. Capture input focus when the mouse enters the virtual machine.
+   4. Hold center when the virtual machine loses input focus.
+   5. Bring the virtual machine to top when a get input focus.
+   6. Allow copy and paste to top when a get input focus.
