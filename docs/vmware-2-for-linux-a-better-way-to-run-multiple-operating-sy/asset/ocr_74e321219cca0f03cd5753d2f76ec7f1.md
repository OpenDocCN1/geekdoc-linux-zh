# Installing Networking Support

Whenever possible, stick with swapping floppies and mounting the DOS virtual disk in Linux to transfer files. But if you want to get adventuresome, it is possible to do real networking on a DOS virtual machine.

LAN and Internet access under DOS is not an exact science, and the various tips, tricks, pitfalls, and workarounds could fill a book. If you plan to get serious about using network applications under DOS, you should visit http://www.tdisk.com and http://www.oldskool.org/~tvdog/internet.html. They both have comprehensive information on DOS Internet tools and configuration tips.

You can use a modem for SLIP or PPP access in DOS, but it's quite tricky. You need to make sure the virtual machine's COM1 is active. The Tvdog site will help guide you, but I recommend you let your Linux PC bear the brunt of your dial-up modem work.

The virtual Ethernet card requires a driver before it can run in DOS. You can download the PCNet Family packet driver from http://www.amd.com/products/npd/software/pcnet_family/drivers/pktdrv.html, or check out the /AMD NIC Drivers directory on the CD included with this book.

For some perverse reason, AMD has taken to archiving DOS programs with a program that requires Windows to decompress them. As such, you might find it rather frustrating just to get at the software you need to install networking. You need the services of a real Windows PC or a Windows virtual machine you can easily start and transfer programs from.

Here's the procedure:

+   1. Obtain the pktdrv.exe program from AMD or this book's CD, and uncompress it in a Windows virtual machine or on a Windows PC.
+   2. Copy the resulting programs to a floppy.
+   3. Load your DOS virtual machine and create a new directory, C:\AMD.
+   4. Copy the uncompressed files to the new directory on the virtual disk.
+   5. When you want to activate the Ethernet driver, type pcntpk.com int=0x60 from the C:\AMD directory.

> If you decide you want Ethernet access to load automatically when you start DOS, add the line c:\amd\pcntpk.com int=0x60 to the autoexec.bat file.
