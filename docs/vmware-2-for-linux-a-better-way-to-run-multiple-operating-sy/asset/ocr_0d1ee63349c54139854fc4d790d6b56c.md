# Installing Windows NT 4 Server

The step-by-step for a Windows NT 4 Server installation is virtually identical.

A few questions show up in the server installation that do not in the workstation version. The first is the choice of whether you want to use Per Server or Per Seat Windows NT networking licensing, shown in Figure 11.16. The decision must be left up to you, the needs of your network, and your available licenses if you plan to do any serious serving from the virtual machine.

The same applies to the Server Type prompt (see Figure 11.17). Unless you need to and know how to set up a Windows NT domain, stick with Stand-alone Server mode.
