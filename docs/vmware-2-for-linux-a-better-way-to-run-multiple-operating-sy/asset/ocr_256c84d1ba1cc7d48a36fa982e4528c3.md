# Time Synchronization

The time-synchronization option really deserves an "expert mode" flag. Unless you notice that the virtual machine's clock is consistently losing time, you should never need this function. Normally, the virtual machine should do a perfectly adequate job of telling time.

When the option is activated, the virtual machine compares its own clock against the host OS clock every second and "catches up" as needed. This problem is most likely to occur if you run multiple Windows virtual machines.

> Because this feature turns on a frequent system check, it can impact the performance of your virtual machine. If your virtual machine has a timekeeping problem, try not to use this option unless it's absolutely necessary.

# Managing Virtual Devices

To get the virtual machine operating system installed, you probably had to learn a little bit about disconnecting and attaching virtual devices to mount and change CD-ROMs. You can always do this through the Devices menu on the VMware window, but VMware Tools provides more convenient access.

By using the device settings in VMware Tools, you eliminate the need to switch input focus to Linux or exit full-screen mode.

There are two, equally effective ways to control virtual devices from inside a Windows virtual machine using the window shown in Figure 8.5:

+   - Double-click the VMware Tools icon in the system tray and then select the Devices tab.
+   - Right-click the VMware Tools icon in the system tray and then highlight the Devices option in the pop-up menu, shown in Figure 8.6.
