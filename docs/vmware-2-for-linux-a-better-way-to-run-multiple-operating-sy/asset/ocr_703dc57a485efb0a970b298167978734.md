# Installing a CD-ROM Driver

You can be forgiven if you’ve been spoiled by the easy CD-ROM access provided in Linux and Windows and by how easy it’s been to get virtual machines to see your CD-ROM drive. But back in the DOS days, it wasn’t quite load and go. You have to install and configure a CD-ROM driver, but the good news is that it’s easy to do.

> If you run DR DOS, this installer does not work properly. You can either extract and install the driver manually (the VMware documentation will help you) or rename the file c:\drdos\nwcdex.exe as c:\drdos\mscdex.exe.

+   1. On your Linux host, browse to http://www.mitsumi.com/enduser/1_drivers.html and download the file ide158.exe.
+   2. Transfer the file to the DOS virtual machine. Because the file is small, I recommend using a DOS-formatted floppy and using the common Linux MS-DOS disk access tools to copy the file. On most systems, typing mcopy ide158.exe a: at a Linux shell prompt does the trick.

> You could also mount the virtual DOS disk and copy the file that way using the vmware-mount.pl program as described in Chapters 9, “Using Your Windows 95/98 Virtual Machine,” and 10, “Installing Linux on VMware.”

+   3. Start the virtual machine. If the file is still on a floppy, copy it to a working directory, such as c:\vmware.
+   4. Run the program ide158.exe from the DOS virtual disk. An automatic file decompressor will run.
+   5. Run the program setupd.exe. A text menu should appear asking you to select a language.
+   6. The main CD-ROM installer window should appear (see Figure 14.10). Select Begin Installation.
+   7. You can safely accept the default when prompted for an installation directory.
+   8. After the installation finishes, reset the virtual machine. The CD-ROM driver is now active on drive D:.

When the reboot is complete, you should see new CD-ROM-related information in the DOS startup messages. To test the driver, simply insert a CD-ROM into the drive and type dir d: at the DOS prompt. Sample output is shown in Figure 14.11.
