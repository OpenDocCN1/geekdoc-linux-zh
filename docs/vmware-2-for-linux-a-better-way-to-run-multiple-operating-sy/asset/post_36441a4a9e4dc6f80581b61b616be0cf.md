## Sharing Files

Although VMware made a conscious effort not to use any proprietary file-sharing shortcuts when it designed its virtual machines, the built-in networking capabilities give you a number of choices. The most basic way to exchange files is over FTP, although there are more powerful and elaborate networking choices available. You can also read virtual disks directly from Linux, if they’re not in use by VMware.

> If you’re interested in sharing files over Samba (using SMB, the default Microsoft Networking file-sharing protocol), see Appendix B, “File Sharing with Samba and NFS in VMware.”

### Swapping Files over FTP

FTP can send as well as receive files, and you can limit access to certain directories and perform file maintenance such as renames and deletes; despite its age, it’s a wonderfully flexible file-sharing system.

Most Linux distributions leave an FTP server running by default, even on workstation-class systems. If you’ve disabled yours or never installed it, you should consult your distribution’s home page or your favorite Linux download site for a replacement.
