
Except for Send Ctrl-Alt-Del, all the features in the Power menu are duplicated in the command toolbar near the top of the VMware screen.

## Settings Menu

The Settings menu, shown in Figure 5.5, lets you tweak the configuration of both the current virtual machine and VMware in general:

![](img/b2b6702758c230ce537468351fc8af15_79_0.png)

Figure 5.5 The VMware Settings menu allows you to adjust VMware's configuration.

- Configuration Editor opens the VMware Configuration Editor for advanced adjustment of a virtual machine profile created in the Configuration Wizard.
- Show All Hints toggles VMware's pop-up hints on and off. Leave them on while you familiarize yourself with the software.
- Grab On Key Press is a checkmark-style item. When checked, it indicates that you want the virtual machine to take control of your mouse and keyboard when you press a key while the mouse pointer is within the virtual machine's video display window.
- Grab On Mouse Click is another checkmark entry. When checked, it indicates that you want the virtual machine to take control of your mouse and keyboard when you click inside the virtual machine's video display window.

If Grab On Key Press and Grab On Mouse Click are both off, the Grab button and Grab item in the Power menu are the only ways to gain control of the virtual machine.

- Host Reserved Memory, pictured in Figure 5.6, lets you allocate the total amount of memory available to all virtual machines. Individual virtual machine RAM allocation is handled in the Configuration Editor, but this window determines the maximum total RAM any number of virtual machines can use. You can usually leave the default settings alone. (VMware recommends a safe value, although you can decrease it if you like; increasing it is not recommended.)

Grab: When VMware takes control of your mouse and keyboard. Until you release control through a special keystroke (Ctrl+Alt+Esc by default), any typing or mouse movement is reported to the virtual machine instead of Linux.

![](img/b2b6702758c230ce537468351fc8af15_80_0.png)

Figure 5.6 VMware's global memory configuration window.

- VMware Tools Install mounts a special virtual floppy disk in the virtual machine's emulated floppy drive so that you can install VMware Tools on your guest operating system. More detail on VMware Tools is coming in the next chapter, but suffice it to say that you absolutely want to install them as soon as possible in any virtual machine.

## Devices Menu

The contents of the Devices menu (see Figure 5.7) change depending on how many virtual disks you attach to VMware. There should always be an entry for the virtual machine's RTC (Real Time Clock), as well as a list of every storage device (real or virtual) you have connected to the virtual machine.

![](img/b2b6702758c230ce537468351fc8af15_80_1.png)

Figure 5.7 You can disconnect or change the storage devices you have connected to a virtual machine on-the-fly.

The storage devices have two options: Disconnect and Disconnect and Edit. Disconnect makes the device temporarily invisible to VMware, and Disconnect and Edit also immediately brings up the Configuration Editor so that you may change the device you want to connect to VMware. After you have made changes in the Configuration Editor, the Disconnect command changes to Connect, and you can re-attach the drive to VMware.

![](img/b2b6702758c230ce537468351fc8af15_81_0.png)

In some configurations of the Linux host operating system, changing CD-ROMs might not work properly. If this happens, disconnect and then reconnect the CD-ROM device using this menu.

The RTC entry has only Disconnect. There is no reason why you should need to disconnect the RTC in normal operation; this option is mostly a debugging tool.

![](img/b2b6702758c230ce537468351fc8af15_81_1.png)

If the RTC is disconnected or otherwise unavailable to a Windows 98 guest, it may not be able to keep time properly in that virtual machine. The Sync Time option in VMware Tools can fix this problem.
