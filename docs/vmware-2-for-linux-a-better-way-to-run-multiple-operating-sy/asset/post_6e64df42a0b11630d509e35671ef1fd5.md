
## Running Amiga Programs Through UAE

With UAE ready to go, you should familiarize yourself with the UAE Control GUI. Although it unfortunately does not control every aspect of UAE’s configuration, it can help you make some important changes, especially on-the-fly as you try to maximize the performance of the emulator.

## Adjusting UAE Control

The first tab, Floppy disks (shown in Figure 18.3), controls up to four virtual floppy drives that can read ADF files. Use the Insert command to add a floppy to the Amiga, and use the eject button to virtually remove a disk. The Amiga, much like the Macintosh but unlike a PC and Linux computer, knows when a new disk is inserted. Unlike a Macintosh, however, Amiga disks can be ejected without asking permission from the operating system.

The second tab, CPU emulation, controls the type and speed of the virtual processor in UAE. For older games, use 68000. For newer games or productivity applications, use 68020 or 68020+68881. You should never have occasion to use 68010.

> Be aware that changing CPU types will reset the emulator, without warning.

The CPU speed setting affects how fast the Amiga runs. If you are running old games that require a 68000, you probably want to use the Approximate 68000/7MHz speed option for maximum accuracy. Some particularly stubborn games might require toggling the Slow but compatible option as well.

Games or applications not tied to a particular chip perform better with either the Optimize or Adjustable setting. Use the slider to adjust the priority of the CPU emulation in Adjustable mode. The CPU emulation tab appears in Figure 18.4.

## Using MAME Arcade Game Emulator for Linux

Emulators aren't just for re-creating one beige box computer on another. You can even emulate arcade games in Linux. One of the most popular (and comprehensive) arcade emulators is MAME, for Multi Arcade Machine Emulator.

With MAME, you can emulate more than 2,000 coin-op classics. Installing and configuring MAME is challenging but still possible for a novice.

## Installing MAME for Linux

MAME needs to be compiled before it will run on your computer. If you have a standard Linux distribution, this should not be a problem, but you might need to consult the MAME documentation for assistance if the process fails:

- 1. Download the latest version of XMAME from http://x.mame.net. The filename will have the form xmame-0.37b4.1.tgz.
- 2. Uncompress the archive with the command tar -zxvf xmame-0.37b4.1.tgz, replacing the version numbers as necessary. A new directory, named after the file, is created.
- 3. Change to the new directory (cd xmame-0.37b4.1).
- 4. Unfortunately, MAME does not include a handy configure program. However, the number of options you need to change is limited, and you can skip the step altogether if you are happy to accept that the xmame executable will be placed in /usr/games, with the xmame support files in /usr/games/lib/xmame. If you want these files placed elsewhere, you need to edit the file makefile.unix, and change the DESTDIR value to the new location for the MAME program and the XMAMEROOT value to the new location for the MAME support files.
- 5. To prepare the installation, type make -f makefile.unix. The screen fills with text. Do not be immediately alarmed if you see warning or even error messages.
- 6. To compile MAME, type make -f makefile.unix install. The executable file (called xmame.x11) is copied to the DESTDIR directory, or /usr/games by default.
- 7. You now need to create a place to store the MAME configuration files. Make a new directory located off your home directory called .xmame. (The command mkdir ~/.xmame should accomplish this.)
- 8. MAME comes with a sample configuration file, located at doc/xmamerc.dist inside the source code archive you dissolved in Step 2. Copy xmamerc.dist to the new .xmame directory you created, renaming it to simply xmamerc. (The command cp doc/xmamerc.dist ~/.xmame/xmamerc should accomplish this, from the same directory you used for Steps 5 and 6.)
- 9. You now need to obtain arcade ROM images. Place the .zip archives in /usr/games/lib/xmame, or wherever you defined XMAMEROOT to be. You do not need to unzip the archives. See http://www.vintagegaming.com/frames/mame/freeroms.html for a (short) list of freeware arcade ROMs.

> You might need to use the su command to become root for Steps 5 and 6.
