Windows NT doesn't automatically install your sound driver, so you can leave it off for now if you so choose.

+   5. The wizard usually suggests a high memory value for Windows NT, but you might need to make adjustments up or down depending on your unique situation. Consider 48MB an absolute minimum to get any sort of performance from Windows NT.
+   6. Make changes in the Misc settings list, if necessary. Windows NT doesn't have the world's best APM support, so you might want to stick with VMware's built-in suspend/restore capabilities.
