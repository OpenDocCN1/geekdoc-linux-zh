+   1. Download the most recent Basilisk II for Linux RPM installation file from http://www.uni-mainz.de/~bauec002/B2Main.html, the home page of Basilisk II. The filename should have the format BasiliskII-0.8-1.1386.rpm, although the version number might be different.

> The next step might require that you first use the su command for root-level access.

+   2. Install Basilisk II with the command rpm -install BasiliskII-0.8-1.1386.rpm, substituting the proper version number if needed.

> The RPM places the main executable in /usr/bin, the document files in /usr/doc/BasiliskII-0.8, and shared device files in /usr/share/BasiliskII.

+   3. Create a new directory to hold Basilisk II-related files. You can choose to put it in a shared location, or in a subdirectory off your home directory, such as /home/jcompton/mac.

+   4. Place your Macintosh ROM image (see the section "Making Sense of Legalities" earlier in this chapter for details) in your new Basilisk II storage directory. Name it something easy to remember, such as ROM or basilisk.rom.

# Installing Basilisk II for Windows

Basilisk II should be compatible with any VMware virtual machine running Windows 95 OSR2 or better, although it prefers (and is somewhat more stable under) NT 4 and 2000:

+   1. Boot your VMware virtual machine.

+   2. Download the latest Windows version of Basilisk II from the Basilisk II for Windows home page, http://www.nic.fi/~jpesonen/BasiliskII. (Note that you can also link to this page from the main Basilisk II page.) The filename should have the form BasiliskII_win32_18062000.zip, potentially with a different date code.
