VMware Tools是一个小应用程序，它在虚拟机内的客户操作系统（此处为Windows 95及更高版本）中运行。从技术上讲，运行VMware Tools是可选的，但强烈推荐运行，实际上没有任何理由不运行它。

本质上，这些工具是一个“粘合层”，将虚拟机与您的Linux PC更紧密地联系在一起，带来更好的性能，并让您更轻松地在虚拟机窗口和计算机的Linux端之间切换。毫不夸张地说，这些工具决定了VMware体验是尚可忍受还是卓越非凡。VMware只为其明确支持的操作系统提供VMware Tools；没有它，您对虚拟机工作方式的外部控制将会减少，图形性能也会受到影响。

您应该在确认Windows虚拟机运行正常后安装这些工具。安装后，每次启动Windows虚拟机时，VMware Tools和伴随的高分辨率视频驱动程序都会自动加载。

> 在本章中，我演示了VMware Tools在Windows 98中的使用。在Windows 95、NT 4和2000中的差异可以忽略不计。

## 访问VMware工具箱

VMware Tools会在Windows系统托盘中创建一个看起来像锤子和螺丝刀的小图标。参见图8.1。

图8.1 锤子和螺丝刀图标是VMware Tools的快捷方式。

有两种方法可以打开VMware Tools主窗口（如图8.2所示）：

- 双击系统托盘中的VMware Tools图标。
- 右键单击系统托盘中的VMware Tools图标，然后选择“主窗口”。
