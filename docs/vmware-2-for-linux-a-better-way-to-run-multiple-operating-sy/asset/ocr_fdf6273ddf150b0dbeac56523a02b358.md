# How Much Memory Is Enough?

Free memory is just as important as CPU power, if not more so. Unlike CPU time, VMware requests a specific, locked amount of memory for each virtual machine. And if you start to run low on memory, the Linux host might “thrash” wildly to the swap partition, which bogs down the entire system. That might continue endlessly until you can shut off a major memory consumer (such as VMware), but because swap access slows down the system, it makes it difficult to shut off programs…you see the problem.

VMware recommends 96 megabytes (MB) as a functional minimum. I say it’s 128MB. That gives you enough room to comfortably run Linux and XWindows without any compromises and leaves between 48MB and 64MB free for VMware. That’s enough to run most supported operating systems comfortably; it’s enough for at least a modest Windows NT 4 installation, although NT 4 would certainly prefer more. It’s probably not enough to make running Windows 2000 worthwhile, however.

It’s also probably only enough to run one virtual machine, unless you plan to run DOS or Windows 3.1, or you don’t mind putting Windows 95/98 or Linux VMs under some very serious resource constraints.

> You should never allocate more than your total system memory minus 64MB to all your VMware sessions combined, unless you’re a sadist and you want to see the Swap Thrash Monster destroy your computer’s performance.

Here’s a general guideline for how much memory above 96MB you should have in your computer to run a virtual machine for each OS. The lower bound will be sufficient, but the upper bound (or beyond) will ensure greater performance. Remember that if you plan to run more than one VM at a time, you should add the figures together to reach your total:

+   - Windows 95/98: 32-64+ MB
+   - Linux and FreeBSD: 32-96+ MB
+   - Windows NT 4 Workstation: 32-128+ MB
+   - Windows NT 4 Server: 48-128+ MB
+   - Windows 2000 Professional: 64-128+ MB
+   - Windows 2000 Server: 128-256+ MB

Let’s say you’re only interested in running a Windows 98 virtual machine. Thirty-two megabytes is enough to run Windows 98, but it is nicer to give it 64; that way, Windows won’t have to hit its own swap file nearly so often. You need 96MB just to get in the game, plus you need the extra 64MB to dedicate to the virtual machine, 96+64=160MB.
