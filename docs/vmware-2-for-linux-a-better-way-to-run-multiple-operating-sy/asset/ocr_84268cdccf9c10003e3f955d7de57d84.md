# Settings Menu

The Settings menu, shown in Figure 5.5, lets you tweak the configuration of both the current virtual machine and VMware in general:

![](bbox=[0.32, 0.38, 0.45, 0.55])

Figure 5.5 The VMware Settings menu allows you to adjust VMware's configuration.

+   - Configuration Editor opens the VMware Configuration Editor for advanced adjustment of a virtual machine profile created in the Configuration Wizard.
+   - Show All Hints toggles VMware's pop-up hints on and off. Leave them on while you familiarize yourself with the software.
+   - Grab On Key Press is a checkmark-style item. When checked, it indicates that you want the virtual machine to take control of your mouse and keyboard when you press a key while the mouse pointer is within the virtual machine's video display window.
+   - Grab On Mouse Click is another checkmark entry. When checked, it indicates that you want the virtual machine to take control of your mouse and keyboard when you click inside the virtual machine's video display window.

If Grab On Key Press and Grab On Mouse Click are both off, the Grab button and Grab item in the Power menu are the only ways to gain control of the virtual machine.

+   - Host Reserved Memory, pictured in Figure 5.6, lets you allocate the total amount of memory available to all virtual machines. Individual virtual machine RAM allocation is handled in the Configuration Editor, but this window determines the maximum total RAM any number of virtual machines can use. You can usually leave the default settings alone. (VMware recommends a safe value, although you can decrease it if you like; increasing it is not recommended.)

Grab: When VMware takes control of your mouse and keyboard. Until you release control through a special keystroke (Ctrl+Alt+Esc by default), any typing or mouse movement is reported to the virtual machine instead of Linux.
