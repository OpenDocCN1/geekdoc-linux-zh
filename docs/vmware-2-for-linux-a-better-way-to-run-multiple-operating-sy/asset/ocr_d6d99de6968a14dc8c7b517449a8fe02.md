# Preparing the Virtual Machine

If Windows 95 is handy and dandy, you need to create a new virtual machine.

> This installation sequence assumes you will be using a Windows install disk labeled "For Distribution with a new PC only" or similar. There are some minor differences in upgrade editions.

# Starting with the Wizard

Begin the Windows 95 virtual machine installation by creating a new VM configuration, starting with the Configuration Wizard.

+   1. If you're not already in VMware, start the main program by typing /user/bin/vmware at a command prompt.
+   2. Launch the VMware Configuration Wizard by clicking Wizard in the File menu.
+   3. Click Next to clear the first greeting screen. VMware presents the Guest OS selection screen, shown in Figure 7.2
+   4. Select Windows 95 from the list of guest operating system choices, and then click Next to proceed.
