Emulated computers also need disk access. Emulating a sophisticated, modern computer means it needs its own virtual hard drive, so you have to provide one. Most emulators use either a dedicated partition on one of your system drives or a file disk. File disks are slower but easier to configure and maintain.

Emulation is one of the most grueling tasks your computer can undertake. Just emulating a foreign CPU is a major undertaking and generally requires that your computer have a processor several times more powerful than the CPU you plan to emulate. If the emulated computer relies heavily on additional custom hardware, such as a special video chip, the power requirements increase even more. Because of its custom chips, it took years of development and Pentiums running at hundreds of MHz to devise an Amiga emulator that could consistently replicate the experience of using a 7MHz Amiga model built in 1987?

Emulation is very hard work for your PC. The more powerful your base system, the more likely you are to get fast emulation.

If you have a lot of other programs consuming memory and CPU resources on your computer, emulation will be slow. Try not to run your emulators on mission-critical servers!

For this reason, some old-style emulators for other computers came in a hardware and software combination that included a CPU on a custom expansion board. The most common example are the PC emulation boards that Macintosh and Amiga users bought years ago, which generally came with an Intel 486 or Pentium CPU.

# Virtual Machines

Virtual machines are a special breed of emulator. If you were to poll a group of computer scientists and emulation experts on the exact differences between an emulator and a virtual machine, you'd likely get several different answers. For real-world discussions, however, here's a rule of thumb to distinguish a virtual machine from an emulator: If an emulator does not have a CPU emulation component, but rather uses the host computer's CPU directly, then that emulator is a virtual machine.

The benefit of virtual machines over emulators should be immediately obvious. Accessing a CPU directly, instead of having to emulate one, provides an enormous speed benefit because there is no translation process: The emulated program runs on its native CPU at more or less the same speed it would if it were not running inside an emulator.

File disk: A very large file in a directory on the host OS, used by an emulator as a mock hard drive.

Virtual machine: An emulator that tries to replicate the operation of a complete computer system inside another of the same type, sharing a single CPU with the host operating system. Not to be confused with a "Java virtual machine," which is a different concept not covered in this book.
