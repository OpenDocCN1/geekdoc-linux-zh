+   - Use an official floppy or CD-ROM set of installation disks from Apple. This is by far the easiest and most reliable way to install MacOS 7 or 8 in Basilisk II.
+   - CD-ROM installations (popular since the middle releases of MacOS 7) allow you to boot directly from the CD, although any high-density floppy version of the OS should work as well.
+   - Download MacOS 7.5.3, available for free from Apple. This is considerably trickier and requires the use of a program called HFV Explorer to assemble the MacOS 7.5.3 disk images Apple provides into a hardfile. You also need a bootable MacOS floppy or disk image, which you have to obtain elsewhere. If you must use this method, see http://www.kearney.net/~mhoffman/BasiliskII/system753_tutorial/index.html for details.

> You might also be able to download a prepared hardfile image of MacOS 7.5.3 or earlier from a Basilisk II third-party support site. This is legally gray at best because although Apple permits users to download MacOS 7.5.3 and earlier in disk format from its site, it has not authorized individuals to create their own ready-to-run MacOS hardfiles.

However you choose to do it, installing MacOS is exceptionally easy, and the installer should hold your hand through the entire process. If you have the option, I recommend using MacOS 7.6 unless you have a compelling reason to move up to MacOS 8; 7.6 is less resource-intensive and runs the bulk of Macintosh software. Some very new titles use GUI routines that require MacOS 8, and you might also find it much easier to find 8 or 8.1 than 7.6, so that is a good second option.

If you are using a CD-ROM or real floppy-disk installation, you should be prompted to initialize and name your hardfile before you can proceed. This is normal.

After the install CD or floppy boots, you should see a standard Macintosh desktop, along with icons for the installation disk/CD, your hardfile, as well as either a UNIX or My Computer icon if you have enabled host file system access.

> MacOS versions less than 7.6 do not see the host file system at first. You need to install Apple File System Manager 1.2 if you use MacOS 7.0 through 7.5.3 if you want root file system access. You can download FSM 1.2 from ftp://ftp.apple.com/developer/Development_Kits/File_System_Manager.sit.hqx. You need to use a floppy disk to transfer the file between your PC and the Mac emulation.
