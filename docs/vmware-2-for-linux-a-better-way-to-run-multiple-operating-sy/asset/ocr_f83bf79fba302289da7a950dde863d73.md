+   If your resources are limited, especially if you are only using a single virtual disk on the server, you might want to use stripped-down Web activity logging or no logging at all. The Web Site tab in the Web Server Configuration properties contains the logging settings.

# Conclusion

Windows 2000 is a feature-rich operating system and arguably puts a greater strain on VMware and your host computer than any of the other operating systems you can install. It certainly requires the most powerful computer to get started.

By bringing Windows 2000 under the VMware wing, you can stay up to date with the latest developments in Microsoft-powered enterprise software, while retaining the core open standard flexibility of Linux. It's hard to imagine a more productive way to run your computer.
