# Carrying Out the Main Installation

Now that the virtual disk is properly prepared, you can begin the main installation of Windows 95:

+   1. At the DOS prompt, change to your virtual CD-ROM drive. This is usually D: or E:, depending on the setup of your virtual machine. Switch to the correct drive by typing d: or e: and pressing Enter, as appropriate.
+   2. Start the installation by typing setup and pressing Enter.
+   3. At the beginning of the installation, and later in the process, you see prompts about "performing routine checks." Simply do what the installer program asks at each occurrence.
