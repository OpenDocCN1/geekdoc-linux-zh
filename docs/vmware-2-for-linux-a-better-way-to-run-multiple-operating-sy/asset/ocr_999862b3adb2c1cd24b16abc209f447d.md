A number of things can go wrong during the installation, or more likely when you try to run an actual Windows program in Wine. The Wine FAQ at http://www.winehq.com/faq.html tries to account for most of the major problems, which usually revolve around Linux system components being either too old or too new for Wine. Generally, a workaround is provided.

# Using Wine to Run Windows Programs

When the wine.conf settings are complete, your PC is ready to run Wine. To test your installation, you should try to run a program known to work well in Wine, such as the standard Microsoft Paint program bundled with Windows:

+   1. Open a new command terminal in Linux.
+   2. Using the instructions in Chapter 9, use vmware-mount.pl to mount your Windows virtual disk on /mnt/vhd in your Linux file system.
+   3. Open another command terminal because the first one will be busy running vmware-mount.pl.
+   4. If you have a standard Windows installation, Paint is likely located at /mnt/vhd/Program Files/Accessories/mspaint.exe, but you might want to browse through the virtual disk to verify the path.
+   5. At the command terminal, type wine " /mnt/vhd/Program Files/Accessories/mspaint.exe". Substitute the correct path if you discover mspaint.exe is located elsewhere on your Windows virtual disk.

> Capitalization and the use of quotation marks are very important. Any time you run a program inside a Windows directory that uses spaces, you need to encompass the entire pathname in quotes.

+   6. Don't get discouraged if you see error messages: they're not uncommon, and not all error messages prevent the program from running properly. Because Wine is so developer-focused, it includes a lot of debugging messages.
+   7. After a short wait (it can be a minute or more, depending on the speed of your system), you should see the very familiar Microsoft Paint program appear, as it does in Figure 16.7. You can draw, rotate, color, and load and save files.
+   8. When you're finished, simply quit the program. Wine will exit, leaving you free to test another Windows program or move on to another project.
