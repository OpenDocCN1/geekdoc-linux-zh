Of course, there is still a catch. VMware sometimes has a difficult time sharing the 256-color palette between the Linux host and the Windows guest when a game starts re-allocating colors at will, and you might see screens that look to be full of garbage or wildly inaccurate colors. If this happens, switch out of full-screen mode, click on the Linux desktop, click on the VMware window, and then switch back to full-screen mode. This should correct the problem, although you might need to do it again every time the game changes its palette. It is inconvenient, but manageable.

## Conclusion

It's clear enough that VMware was not designed with gaming enthusiasts in mind, but it's also not out of the question to play games on VMware, either. Despite some glaring holes in game-related hardware compatibility, there are plenty of classics as well as some fairly recent titles that you can enjoy when you tire of the challenges of Samba networking and cross-platform application testing.

As for the limitations, there are two ways to look at it. If it means a lot to you to have better DOS and Windows game compatibility, tell VMware, Inc. about it. At the same time, there is also a small but growing commercial Linux game market, with mainstream Windows titles being ported very quickly to native Linux versions. This should, over time, reduce the sting considerably.

## Chapter 16: Using Wine with VMware

Wine is not an emulator

Installing Wine

Using Wine to run Windows programs

VMware provides an excellent platform to install the Windows operating system of your choice and run a wide range of Windows-compatible software.

But if you only need to load a single Windows application from time to time, waiting for VMware to load can become tiresome. Or you might be running an extremely resource-intensive program in Linux and do not have the large amount of free RAM VMware requires to run its virtual machine layer. In these cases, using Wine instead of VMware can provide the solution you need, without having to reboot into Windows or use a separate computer. See Wine in action in Figure 16.1.

Wine even provides partial DirectX emulation, something VMware has yet to master. That does not necessarily make it "better" than VMware for running Windows games, but it provides an alternative to try when VMware simply isn't up to the task.

Corel uses a modified version of Wine (an open-source project) as the basis for its WordPerfect Office suite; to a large degree, the code in the Linux version of each Office program is exactly the same as its Windows counterpart, but Wine intercedes to make the program work natively on a Linux PC. (See Figure 16.2.)

However, the fact that Wine does not boot a real Windows environment also makes installing Windows applications a major headache because new programs cannot always make the necessary adjustments to Windows system files and directories. This is where having VMware in your arsenal comes in handy because you can use VMware to provide a complete Windows environment for installation and then use Wine to run the program on an as-needed basis.

When Wine works well, it allows you to load a Windows 3.1, 95, 98, or NT application in a window on your Linux desktop. That application believes for all the world it is running on a Windows PC but has access to Linux's file system, fonts, and resources.

When Wine doesn't work as intended, the failure can show up in many forms. The application might simply not look quite right (with text, bitmaps, or icons rendered out of position or out of sight), might crash or quit during operation, or might simply not load properly.

When this happens, your choices are fairly limited. Although Wine has a wide variety of configuration options, most are not meant to be changed unless you are sure you know what you are doing. Your best bet is to reboot your Linux system before trying to relaunch the program in Wine. If that is unsuccessful, check the Windows application compatibility database at http://www.winehq.com. If your particular program is listed, you might find tips for adjusting your Wine configuration.
