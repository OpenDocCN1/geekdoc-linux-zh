## Testing the Installation

You've loaded what appears to be a working copy of Windows 95, but it's always a good idea to make sure the core is working properly before you get carried away on major tasks.

Until you install VMware Tools, video performance will be very slow. Still, you can run a couple of diagnostics on the new operating system to make sure everything is running smoothly:

- Check the Device Manager in the System Control Panel. Specifically, make sure you see the devices you expect to see, such as a virtual network card and sound card, if applicable. Also look for yellow exclamation points. As you can
see in Figure 7.17, you might get phantom IRQ conflicts on serial or printer ports because the virtual machine looks like it has all manner of I/O ports, even if you don’t assign any to the virtual machine. You can safely remove some or all of the unused ports, which should clear up the problem. See Figure 7.17 for an example of a benign alarm.

- Load a basic included app, such as WordPad, and use it for a few minutes, just to ensure that the operating system is stable. Type a short document, save it, and re-load it.

- If you have bridged networking enabled, use the built-in Telnet or FTP client in Windows to connect with a known address. If you’re using host-only networking, open Network Neighborhood and verify that you can see your Linux PC.

## Installing VMware Tools

When you’re satisfied that Windows 95 is running as it should, take the time to install VMware Tools. You’ll get much better graphics performance, as well as the ability to share the clipboard between Linux and the Windows VM:

> Because you need to access the VMware window toolbar, you need to do this operation in windowed mode, not full-screen mode. Remember, use Ctrl+Alt+Esc to return to windowed mode.
