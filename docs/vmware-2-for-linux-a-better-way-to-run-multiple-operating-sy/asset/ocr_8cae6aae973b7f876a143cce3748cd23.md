Alternately, if you have a fairly standard XFree86 setup, you should be able to make the changes manually. To edit your X configuration to include 8-bit (256-color) modes, follow these steps:

+   1. Locate your XF86Config file. Ninety-nine percent of the time, you will find it in /etc or /etc/X11.
+   
+   2. Edit the file. (You might need to use the su command to become root to have the right to edit or save your changes.)
+   
+   3. At the very bottom of the configuration file, you should see a listing for “accelerated servers,” along with an entry for your Linux PC’s video card. Look at the area marked Subsection “Display”.
+   
+   4. If you do not have 8-bit screen modes, chances are you have 16- or 24-bit depth modes instead. To add 8-bit modes, first copy and paste the lines between Subsection “Display” and EndSubsection just below the EndSubsection line.
+   
+   5. In the newly pasted subsection, change the Depth line to 8.
+   
+   6. In the newly pasted subsection, change the Modes entries to those appropriate to your video card. Be sure to enclose each entry in quotes, with a space between each one. A common entry might be “640x480” “800x600” “1024x768”.
+   
+   7. Re-start X using startx -- -bpp 8. As with DOS games, it’s better to play games in full-screen mode to optimize video performance.
